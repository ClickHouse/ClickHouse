Delta Lake tables with column mapping in the `id` (`mode_id`) and the `name` (`mode_name`) modes. Their columns
include structs inside arrays and maps: `array_of_structs`, `map_of_rows`.

The tables are the golden tables `table-with-columnmapping-mode-id` and `table-with-columnmapping-mode-name` of
delta-kernel-rs (`kernel/tests/golden_data`, commit `88ff5a9`, Apache License 2.0), originally generated by
`GoldenTables.scala` of https://github.com/delta-io/delta. `delta` is the table, and `expected` holds its expected
content as Parquet files. Checksum (`.crc`) and `_SUCCESS` files are removed.
