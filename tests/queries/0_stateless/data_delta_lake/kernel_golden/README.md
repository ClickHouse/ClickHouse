The golden Delta tables of delta-kernel-rs: https://github.com/delta-io/delta-kernel-rs/tree/main/kernel/tests/golden_data
(the archives `<table>.tar.zst` from commit 88ff5a9 of `contrib/delta-kernel-rs`, extracted, without `.crc` files of Spark,
`_SUCCESS` files and macOS metadata). They were generated by Spark with
https://github.com/delta-io/delta/blob/master/connectors/golden-tables/src/test/scala/io/delta/golden/GoldenTables.scala
Both projects are licensed under the Apache License 2.0.

Each `<table>` directory contains the Delta table in `delta/` and the expected data of its latest version,
written by Spark as Parquet, in `expected/`. Some tables have only one of them:

- `parquet-decimal-dictionaries`, `parquet-decimal-dictionaries-v2`, `parquet-decimal-type` have only `delta/`,
  because their expected data is large. The test compares them with the aggregates of the expected data.
- `time-travel-start`, `time-travel-start-start20`, `time-travel-schema-changes-a`, `time-travel-partition-changes-a`,
  `snapshot-data0`, `snapshot-data1`, `snapshot-data2`, `snapshot-data3`, `snapshot-data2-deleted` have only `expected/`,
  because these tables are the earlier versions of `time-travel-start-start20-start40`, `time-travel-schema-changes-b`,
  `time-travel-partition-changes-b` and `snapshot-repartitioned` (their logs are prefixes of the logs of these tables).
- The invalid tables (`deltalog-*`, `no-delta-log-folder`, `versions-not-contiguous`, `canonicalized-paths-*`) have only `delta/`.

Not included:

- `table-with-columnmapping-mode-id` and `table-with-columnmapping-mode-name`: they are in
  `data_delta_lake/column_mapping_nested` and tested by `05498_delta_lake_column_mapping_nested_struct_in_array_map`.
- `data-reader-partition-values`: the expected data is wrong (delta-kernel-rs skips this table).
- `parquet-decimal-dictionaries-v1`: large, and the same data as `parquet-decimal-dictionaries`.
- `checkpoint`, `delete-re-add-same-file-different-transactions`, `log-replay-special-characters-b`,
  `data-reader-absolute-paths-escaped-chars`, `deltalog-commit-info`, `update-deleted-directory`, `hive`:
  they have no data files or no expected data, and are not used as reader tests in delta-kernel-rs.

The tests are `*_delta_lake_kernel_golden_*.sh`.
