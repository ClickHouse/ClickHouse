# Iceberg tables from the tea test suite

The tables in this directory are copied from the test resources of lithium-tech/tea at commit
https://github.com/lithium-tech/tea/tree/267c6bc6f45b8cd22dc4c4823c8316a0467482ce/test/iceberg/warehouse
(Apache License 2.0, https://github.com/lithium-tech/tea/blob/main/LICENSE). The files are not modified.

- `gperov/test` (Spark, generated by `test/iceberg/gen/gperov_test.py`), `empty/empty` (no snapshots).
- `mydb/multiple_branches` (Spark, `create.sql`): a branch and a dropped column.
- `snapshot_selection` (Trino 481, `create.sql`): an empty snapshot and a snapshot with 8 rows.
- `unsupported_historical_schema`: a copy of the `snapshot_selection` metadata with an older schema, whose
  manifest lists stay in `s3a://warehouse/snapshot_selection`, outside the table location.
- `qa_etl_table_update_null` (Trino 471): an `UPDATE` with position deletes.

The expected results in the tests are taken from the upstream tests (`tea/smoke_test/iceberg_test.cpp`) and
from the generation scripts; the rest of the values are cross-checked with DuckDB.

Not included: `dangling_deletes`, `deletion_vectors` (identical copies of the iceberg-cxx tables in
`data_iceberg/iceberg_cxx`), `parquet/no_row_group_file_offset.parquet` (a single Parquet file, not a table).
