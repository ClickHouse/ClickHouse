## Диалоги {#conversations}

Чтобы начать новый диалог, нажмите значок создания сообщения в левой панели навигации.
Выберите нужного агента в селекторе Agent в левом верхнем углу окна диалога — по умолчанию выбран **ClickHouse Agent**.
Затем введите сообщение в поле ввода сообщения и отправьте его. Каждый диалог сохраняется в истории на боковой панели, и позже его можно снова открыть, переименовать или удалить.

Любое своё сообщение можно отредактировать прямо на месте — агент заново сгенерирует ответ, начиная с этого места в истории диалога.
Можно также заново сгенерировать только последний ответ агента, не отправляя сообщение повторно.

## Закладки {#bookmarks}

Добавьте сообщение или весь диалог в закладки, чтобы быстро вернуться к ним позже. Закладки видны только вам и сохраняются при переименовании диалога.

## Закреплённые беседы {#pinned-conversations}

Закрепите диалог, чтобы он всегда оставался вверху боковой панели, отдельно от истории ниже, сгруппированной по датам. Для этого откройте меню диалога (значок с тремя точками) на боковой панели и выберите **Pin**. Закреплённые беседы отображаются в разделе **Pinned** над группами **Today**, **Yesterday** и более ранними.

Чтобы открепить диалог, откройте то же меню и выберите **Unpin**.

## Ветвление {#forking}

Ветвление создаёт новый диалог, ответвляющийся от выбранного сообщения. С его помощью можно исследовать альтернативный путь, не затрагивая исходный диалог.
Доступны три режима ответвления:

* **Visible messages only** — копирует прямой путь до сообщения, от которого создаётся ответвление.
* **Include related branches** — копирует основной путь и все существующие ветви.
* **Include all to here** — копирует всё содержимое до сообщения, от которого создаётся ответвление.

Диалоги-ответвления независимы, поэтому изменения в них не переносятся в исходный диалог.

## Предоставление общего доступа к чатам {#sharing-chats}

Создайте ссылку на любой диалог, чтобы отправить его коллеге или сохранить для справки. Получатели видят диалог в режиме только для чтения, включая артефакты и видимые ветви. Ссылку можно в любой момент отозвать на панели управления общим доступом.

Изменения в существующих сообщениях отображаются в общей версии диалога, а сообщения, добавленные после создания ссылки, — нет.

Любой, кто открыл общую ссылку, может продолжить диалог в своём аккаунте, нажав **Continue this chat**. При этом диалог (включая просматриваемую ветвь) копируется в его историю как новый частный диалог, а ваш исходный диалог остаётся без изменений.

Чтобы поделиться диалогом, откройте его меню на боковой панели и выберите **Поделиться**:

## Сочетания клавиш {#keyboard-shortcuts}

Чтобы открыть справку по сочетаниям клавиш, нажмите `Cmd+Shift+/` (`Ctrl+Shift+/` в Windows и Linux) или выберите в меню аккаунта **Help** → **Сочетания клавиш**. Любое сочетание можно изменить: щёлкните строку в диалоговом окне, чтобы задать новую комбинацию, а чтобы вернуть исходные значения, нажмите **Reset all to defaults**.

Сочетания клавиш по умолчанию:

| Действие                        | macOS                 | Windows и Linux        |
| ------------------------------- | --------------------- | ---------------------- |
| Показать сочетания клавиш       | `Cmd+Shift+/`         | `Ctrl+Shift+/`         |
| Новый чат                       | `Cmd+Shift+O`         | `Ctrl+Shift+O`         |
| Перейти к полю ввода чата       | `Shift+Esc`           | `Shift+Esc`            |
| Загрузить файл                  | `Cmd+Shift+U`         | `Ctrl+Shift+U`         |
| Скопировать последний ответ     | `Cmd+Shift+;`         | `Ctrl+Shift+;`         |
| Отправить сообщение             | `Cmd+Enter`           | `Ctrl+Enter`           |
| Показать/скрыть боковую панель  | `Cmd+Shift+S`         | `Ctrl+Shift+S`         |
| Открыть выбор модели            | `Cmd+Shift+M`         | `Ctrl+Shift+M`         |
| Перейти к поиску                | `Cmd+/`               | `Ctrl+/`               |
| Открыть настройки               | `Cmd+Shift+,`         | `Ctrl+Shift+,`         |
| Добавить диалог в закладки      | `Cmd+Shift+B`         | `Ctrl+Shift+B`         |
| Остановить генерацию            | `Cmd+Shift+X`         | `Ctrl+Shift+X`         |
| Сгенерировать ответ заново      | `Cmd+Shift+E`         | `Ctrl+Shift+E`         |
| Изменить последнее сообщение    | `Cmd+Shift+I`         | `Ctrl+Shift+I`         |
| Продолжить ответ                | `Cmd+Shift+C`         | `Ctrl+Shift+C`         |
| Скопировать последний блок кода | `Cmd+Shift+K`         | `Ctrl+Shift+K`         |
| Прокрутить в начало             | `Cmd+Shift+Up`        | `Ctrl+Shift+Up`        |
| Прокрутить в конец              | `Cmd+Shift+Down`      | `Ctrl+Shift+Down`      |
| Архивировать диалог             | `Cmd+Shift+L`         | `Ctrl+Shift+L`         |
| Удалить диалог                  | `Cmd+Shift+Backspace` | `Ctrl+Shift+Backspace` |

Также можно назначить собственные сочетания клавиш для открытия панелей — например, агентов, промптов, файлов и закладок. По умолчанию для них сочетания не заданы.
