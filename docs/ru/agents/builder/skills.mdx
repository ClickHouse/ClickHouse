Навык — это готовый пакет инструкций для многократного использования, который агент может применять по мере необходимости. Используйте навыки для процедур, общих для разных агентов (руководство по фирменному стилю, чек-лист для ревью кода, регламент действий для конкретного рабочего процесса), вместо того чтобы дублировать инструкции в системном промпте каждого агента.

## Устройство навыка {#anatomy-of-a-skill}

Навык — это файл Markdown с небольшим заголовком метаданных:

```markdown
---
name: revenue-report
description: Generates the weekly revenue report using our standard segments
always-apply: false
user-invocable: true
---

When asked to generate a revenue report:
1. Filter to the requested period.
2. Apply the standard MRR formula:
     SUM(CASE
       WHEN billing_cycle = 'monthly' THEN amount
       WHEN billing_cycle = 'yearly'  THEN amount / 12
       ELSE 0
     END)
3. Break down by segment: Enterprise, Mid-Market, SMB.
4. Render the result as a Markdown table.
```

Наиболее важные параметры заголовка метаданных:

* **`name`** — идентификатор в формате kebab-case.
* **`description`** — краткое описание, по которому модель решает, когда этот навык применим. Это поле самое важное. Формулируйте его конкретно: из-за расплывчатых описаний может вызываться не тот навык.
* **`always-apply`** — при значении `true` навык подключается к каждому ходу диалога, а не выбирается по необходимости. Используйте этот параметр с осторожностью: навыки с always-apply расходуют контекст в каждом сообщении.
* **`user-invocable`** — при значении `true` (по умолчанию) навык отображается во всплывающей панели `$` для ручного выбора.

Вместе с навыком можно поставлять вспомогательные файлы — справочную документацию, примеры запросов, небольшие скрипты. Для этого загрузите архив `.zip`, содержащий `SKILL.md` и связанные с ним статические ресурсы.

## Использование навыка {#use-a-skill}

Агент может задействовать навык в диалоге тремя способами:

* **Вызов пользователем** — нажмите `$` в поле ввода сообщения и выберите навык во всплывающей панели. Содержимое навыка будет добавлено в контекст следующего хода.
* **Автоматический выбор моделью** — агент сам решает, когда применить навык, исходя из его поля `description`.
* **Always-apply** — навыки с такой настройкой добавляются в контекст на каждом ходе.

## Управление навыками {#manage-skills}

Панель «Навыки» в консоли Cloud позволяет создавать навыки прямо в интерфейсе, загружать файлы `.md` или `.zip`, а также выбирать, какие навыки активны для вашего пользователя. Созданные вами навыки по умолчанию активны. Чтобы убрать навык из всплывающей панели и каталога модели, не удаляя его, деактивируйте этот навык.

Навыками можно делиться с другими пользователями (см. [совместное использование и доступ](/ru/agents/sharing-and-access)).

## Навыки и инструкции {#skills-vs-instructions}

* **Инструкции агента** определяют, что представляет собой агент и как он ведёт себя в целом. Они действуют для этого агента постоянно.
* **Навыки** применяются ситуативно — только когда они уместны, и охватывают лишь конкретные рабочие процессы.

Используйте навык, если один и тот же набор пошаговых инструкций повторяется у нескольких агентов или если нужно, чтобы он срабатывал только на определённые запросы пользователей, а не на каждом ходе диалога.
