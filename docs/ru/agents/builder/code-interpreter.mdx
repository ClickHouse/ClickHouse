Интерпретатор кода позволяет агенту выполнять код в управляемой песочнице. Используйте его для вычислений, преобразования данных, конвертации форматов, построения графиков и любых других задач, которые проще решить с помощью кода, чем на естественном языке.

## Включение интерпретатора кода {#enable-it}

В Конструкторе агентов включите **Run Code** в разделе **Capabilities** и сохраните изменения. Агент сам решает, когда выполнять код, исходя из запроса пользователя и своих инструкций.

## Поддерживаемые языки {#supported-languages}

Песочница представляет собой Unix-среду с двумя средами выполнения общего назначения и несколькими утилитами командной оболочки:

* **Python 3** — используется по умолчанию для задач обработки данных.
* **Node.js (JavaScript)** — если агент предпочитает решать задачу на JS.
* **Bash** и **sh** — скрипты командной оболочки для объединения команд в цепочки и быстрых операций ввода-вывода.
* **AWK** и **sed** — построчная обработка текста.
* **bc** — вычисления с произвольной точностью.

Для разбора, преобразования данных и вычислений агенты в первую очередь используют Python.

<Tip>
  Прибегайте к инструментам командной оболочки только в тех случаях, когда задачу действительно удобнее решить однострочной командой.
</Tip>

## Файлы {#files}

Пользователи могут загружать файлы в диалог; интерпретатор кода получает к ним доступ в рабочем каталоге песочницы. Код также может сохранять выходные файлы (CSV, графики, архивы), которые появляются в диалоге в виде вложений, доступных для скачивания.

## Изоляция песочницы {#sandbox-isolation}

Каждый запуск выполняется в эфемерной песочнице без сетевого доступа и без постоянного хранилища. Сеансы не имеют общего состояния — переменные и файлы одного запуска не переносятся в следующий, если агент явно не загрузит их повторно.

Действуют ограничения ресурсов, зависящие от тарифного плана (память, количество файлов на запуск, ежемесячные квоты запросов). Ошибки и вывод stderr отображаются в диалоге вместе с stdout.

## Когда его использовать {#when-to-use-it}

Прибегайте к интерпретатору кода, когда для ответа нужны детерминированные вычисления, которые языковая модель не может надёжно выполнить одними лишь рассуждениями.
Типичные сценарии:

* Разбор CSV- или JSON‑файла, загруженного пользователем.
* Расчёт сводной статистики или быстрое моделирование.
* Преобразование данных между форматами (Parquet, JSON, CSV).
* Построение графика по результатам запроса.

<Tip>
  Не используйте его для задач, на которые модель может ответить, опираясь на контекст.
  Выполнение кода увеличивает задержку и расходует квоту.
</Tip>
