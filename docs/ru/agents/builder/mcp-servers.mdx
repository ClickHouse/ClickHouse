Model Context Protocol (MCP) — это открытый стандарт, позволяющий предоставлять модели ИИ доступ к инструментам и источникам данных. Подключив MCP-сервер к ClickHouse Agent, вы даёте агенту доступ ко всем возможностям, которые предоставляет этот сервер: системам отслеживания задач, бэкендам обсервабилити, внутренним API, сторонним SaaS-сервисам и любым другим системам с конечной точкой MCP.

## Подключение MCP-сервера {#attach-an-mcp-server}

В Конструкторе агентов откройте раздел **MCP-серверы** и нажмите **Добавить сервер**. Укажите URL сервера и настройки аутентификации, затем выберите, какие инструменты сервера будет использовать именно этот агент. Сохраните агента.

К одному агенту можно подключить несколько серверов. Каждый вызов инструмента записывается в диалоге, поэтому пользователи видят, какие действия выполнил агент.

## Транспорт {#transport}

ClickHouse Agents работает по протоколу Streamable HTTP — транспорту MCP промышленного уровня. Подключаемый сервер должен быть доступен по HTTP(S) из ClickHouse Cloud.

## Аутентификация {#authentication}

MCP-серверы могут требовать учётные данные. Agents поддерживает:

* **Bearer-токены** и другие статические заголовки — фиксированные значения, которые вы указываете при настройке сервера.
* **OAuth 2.0** — интерактивный процесс. Когда вы (или любой пользователь с доступом) впервые вызываете инструмент на сервере, в браузере открывается окно входа; токены управляются и обновляются автоматически.
* **Учётные данные per-user** — переменные в конфигурации сервера, значения которых подставляются из профиля вызывающего пользователя. Благодаря этому каждый пользователь аутентифицируется под собственной идентичностью, а не через общую служебную учётную запись.

Учётные данные, введённые пользователями, хранятся в зашифрованном виде и доступны только тому пользователю, который их ввёл. Учётные данные одного пользователя никогда не видны агентам, запущенным другим пользователем.

## Ограничения {#limits}

В рамках одного запуска агент может обращаться не более чем к 50 различным MCP-серверам и использовать не более 100 развёрнутых конфигураций инструментов на запрос. Если агенту требуется больше, разбейте его на [субагентов](/ru/agents/builder/subagents).
