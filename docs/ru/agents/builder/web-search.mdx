Веб-поиск позволяет агенту получать информацию из публичного интернета во время диалога. Используйте его, когда нужен актуальный ответ: например, о недавних выпусках, о документации, размещённой за пределами вашего сервиса, или для быстрой сверки с авторитетным источником.

## Включение {#enable-it}

В Конструкторе агентов включите **Веб-поиск** в разделе **Capabilities**. После этого агент сам решает, когда выполнять поиск, исходя из вопроса пользователя и своих инструкций. Агент выполняет поиск, извлекает содержимое найденных страниц и передаёт наиболее релевантную информацию обратно в контекст модели.

## Как работает цикл поиска {#how-a-search-round-works}

Каждый поиск проходит три стадии, которыми Cloud управляет за вас:

1. **Поиск** — запрос агента передаётся поисковому провайдеру, который возвращает URL-адреса страниц-кандидатов.
2. **Сбор данных** — релевантные страницы загружаются, и из них извлекается значимый текст.
3. **Переранжирование** — ранжировщик оценивает результаты, чтобы модель в первую очередь получала наиболее полезные из них.

В ответе агент ссылается на те URL-адреса, которые фактически использовал.

## Когда это использовать {#when-to-use-it}

* Поиск примечаний к выпуску или журналов изменений, которых нет в вашем сервисе.
* Проверка фактов по источнику, о котором модель может не знать.
* Загрузка публикации из общедоступного блога или документации в диалог для анализа.

Не используйте эту возможность для вопросов, на которые можно ответить с помощью ваших данных или собственных знаний модели: каждый цикл поиска увеличивает задержку.
