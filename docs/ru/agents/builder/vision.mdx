Функция Vision позволяет пользователям загружать изображения, чтобы агент мог их проанализировать. Агент передаёт изображение модели с поддержкой Vision, которая описывает его содержимое, составляет по нему сводку или отвечает на вопросы о том, что на нём изображено.

## Включение возможностей анализа изображений {#enable-it}

Vision работает только с моделями, которые поддерживают входные изображения. Если выбранная модель не может обрабатывать входные изображения, элемент управления для загрузки в редакторе сообщений становится неактивным. Чтобы снова его включить, переключитесь на модель с поддержкой Vision.

## Использование возможностей анализа изображений {#use-it}

Нажмите на значок скрепки в левом нижнем углу редактора сообщений и выберите **Upload to Provider**, чтобы прикрепить изображение — снимок экрана, фотографию, чарт или диаграмму. Затем задайте любой вопрос, для ответа на который нужно прочитать изображение: *«Что не так с этим планом запроса?»*, *«Перепиши текст с этого снимка экрана»* или *«Сравни эту панель мониторинга с данными за прошлую неделю»*.

Агент воспринимает изображение как часть контекста сообщения, поэтому в последующих вопросах в рамках того же хода можно ссылаться на его содержимое без повторной загрузки.

## Сочетание Vision с другими инструментами {#combine-with-other-tools}

Vision хорошо сочетается с [интерпретатором кода](/ru/agents/builder/code-interpreter) для анализа изображений — например, агент считывает числа со скриншота, а затем запускает код на Python, чтобы подсчитать итоги, — а также с [веб-поиском](/ru/agents/builder/web-search), если на изображении есть что-то, о чём модели нужно найти дополнительную информацию.
