Библиотека промптов позволяет сохранять и повторно использовать промпты на естественном языке, которые вам приходится вводить снова и снова. По сути, это набор сниппетов для поля ввода сообщения в чате. Они пригодятся, когда один и тот же аналитический вопрос или инструкция по форматированию повторяется в разных диалогах.

## Создание промпта {#create-a-prompt}

Откройте панель промптов с помощью значка **промптов** в левой панели навигации и нажмите кнопку **+**, чтобы открыть форму **Create Prompt**. Заполните поля:

* **Prompt Name** (обязательное) — название, которое отображается в элементе выбора. Выбирайте понятные названия: *«Еженедельно активные пользователи по регионам»* лучше, чем *«WAU»*.
* **Text** (обязательное) — сам текст, который будет вставлен в поле ввода сообщения.
* **Special variables** — нажмите кнопку **Special variables**, чтобы вставить плейсхолдеры, или введите маркеры вида `{{name}}` вручную. Перед вставкой элемент выбора попросит указать значения.
* **Category**, **Description**, **Command** (необязательные) — для упорядочивания библиотеки, текста предварительного просмотра в элементе выбора и команды быстрого вызова.

Затем нажмите **Create Prompt** в правом нижнем углу.

На панели промптов откройте меню **...** на карточке промпта и выберите **Preview**:

## Общий доступ к промптам {#share-prompts}

По умолчанию промпт доступен только создавшему его пользователю. Владелец может изменить область видимости промпта:

* **Определённые пользователи или группы** — любой указанный вами пользователь сможет найти и использовать промпт.
* **В масштабе всей организации** — все участники вашей организации ClickHouse Cloud смогут найти и использовать его.

Для промптов действует та же модель разрешений, что и для агентов. Полную матрицу ролей и их возможностей см. в разделе [Общий доступ и
права доступа](/ru/agents/sharing-and-access).

## Промпты, навыки и инструкции {#prompts-vs-skills-vs-instructions}

Промпты, навыки и инструкции агента добавляют текст в контекст модели, но различаются тем, кто их активирует и как долго они действуют.

* **Промпты** — текст, который вы сами вставляете в поле ввода сообщения и редактируете на каждом ходе.
* **[Навыки](/ru/agents/builder/skills)** — наборы инструкций, которые агент загружает самостоятельно, если считает их полезными для задачи.
* **Инструкции агента** — постоянный системный промпт агента, который применяется в каждом диалоге.

Промпт подходит, если вы хотите повторно использовать готовые формулировки, но каждый раз сами управлять текстом. Навык подходит, если агент должен
единообразно следовать одним и тем же рекомендациям в задачах определённого типа, а вам не нужно каждый раз вводить их вручную. Инструкции агента подходят, если поведение должно сохраняться на протяжении
всего времени жизни агента.
