## Как работает Memory {#how-it-works}

Параллельно с основным диалогом работает небольшой агент памяти. Он анализирует последние сообщения, определяет, что стоит запомнить, и сохраняет записи в отдельное хранилище для каждого пользователя (per-user).
В следующем диалоге эти записи доступны основному агенту как контекст, поэтому вам не придётся повторяться.

Для вас это выглядит как преемственность: достаточно один раз сообщить агенту, что вы предпочитаете вывод SQL в нижнем регистре и что ваш финансовый год заканчивается в марте, и в последующих диалогах это будет учитываться.

## Управление записями Memory {#manage-your-memories}

Чтобы открыть панель Memory, нажмите значок **Memories** (мозг) в левой панели навигации. На панели отображаются сохранённые записи Memory и элементы управления для создания, изменения, удаления и фильтрации записей.

Memory доступна только вам. Агенты других пользователей никогда не видят ваших записей, а ваши агенты не видят их записей.

### Создание записи Memory {#create-memory}

Нажмите кнопку **+** в верхней части панели, чтобы открыть диалоговое окно **Create Memory**. Введите **Ключ** (только строчные буквы и символы подчёркивания) и **Значение**, затем нажмите **Create**.

## Включение и отключение Memory {#toggle-memory}

Memory включается и отключается флажком **Использовать Memory** в верхней части панели Memory. Отключайте её, если обсуждаете конфиденциальные темы, которые не должны сохраняться, или ведёте разовые диалоги, где персонализация не нужна.

Когда Memory отключена, агент не читает данные из вашего хранилища Memory и не записывает их туда.

## Рекомендации по использованию Memory {#memory-best-practices}

Memory будет полезна для хранения следующих сведений:

* Устоявшиеся соглашения: предпочитаемые форматы дат, бизнес-определения, шаблоны именования.
* Контекст проекта: к какому сервису или базе данных вы обычно отправляете запросы, какие панели мониторинга для вас важны.
* Стиль общения: лаконичные или развёрнутые ответы, ответы с преобладанием кода или текста.

Memory не предназначена для использования в качестве базы данных. Например, в ней не стоит хранить большие объёмы справочных материалов.
Для этого лучше использовать [навык](/ru/agents/builder/skills) или включить материал в инструкции агента.
Memory также не предназначена для поиска по прошлым чатам — эту роль выполняет сама история диалога.
