<Info>
  На этой странице описана настройка MCP-сервера для поиска по документации ClickHouse. Чтобы вместо этого выполнять запросы к данным ClickHouse, используйте [MCP-сервер ClickHouse с открытым исходным кодом](/ru/guides/use-cases/ai-ml/MCP) или [удалённый MCP-сервер ClickHouse Cloud](/ru/products/cloud/features/ai-ml/remote-mcp).
</Info>

Выполняйте поиск по документации ClickHouse непосредственно из ИИ-инструментов с помощью Model Context Protocol (MCP).

<div id="connect-your-ai-tool">
  ## Подключите свой ИИ-инструмент
</div>

<Tabs>
  <Tab title="Claude Code" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claudecode-color.svg">
    Выполните в терминале:

    ```bash
    claude mcp add --transport http clickhouse-docs https://clickhouse.com/docs/mcp --scope user
    ```
  </Tab>

  <Tab title="Claude Desktop" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claude.svg">
    Добавьте в `claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex" icon="/images/logo-codex.svg">
    Выполните в терминале:

    ```bash
    codex mcp add clickhouse-docs --url https://clickhouse.com/docs/mcp
    ```
  </Tab>

  <Tab title="Cursor" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-cursor.png">
    Добавьте в `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Windsurf" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-windsurf.svg">
    Добавьте в `~/.codeium/windsurf/mcp_config.json`:

    ```json
    {
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
        }
      }
    }
    ```
  </Tab>
</Tabs>

<div id="add-clickhouse-skills">
  ## Добавьте навыки ClickHouse в своего агента для программирования
</div>

Установите навыки ClickHouse, чтобы ваш агент получил экспертные знания и рекомендации по работе с ClickHouse:

```bash
npx skills add https://clickhouse.com
```
