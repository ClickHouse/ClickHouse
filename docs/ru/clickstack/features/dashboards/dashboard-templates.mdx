ClickStack включает библиотеку готовых шаблонов панелей мониторинга, которые позволяют сразу получить представление о распространённых метриках инфраструктуры и приложений.

## Просмотр доступных шаблонов {#browsing-templates}

Чтобы просмотреть встроенную библиотеку шаблонов, перейдите в раздел **Панели мониторинга** и нажмите **Просмотреть шаблоны дашбордов**.

<div className="ch-image-lg">
  <Frame>
    ![Кнопка «Просмотреть шаблоны дашбордов»](/images/use-cases/observability/browse-dashboard-template.webp)
  </Frame>
</div>

Откроется галерея шаблонов, где они сгруппированы по категориям. Нажмите **Импортировать**, чтобы начать импорт этого шаблона.

<div className="ch-image-lg">
  <Frame>
    ![Галерея шаблонов дашбордов](/images/use-cases/observability/dashboard-template-gallery.webp)
  </Frame>

## Импорт шаблона {#importing-a-template}

Чтобы импортировать шаблон, для каждой визуализации на панели мониторинга нужно указать источник данных. Выберите источник данных из раскрывающегося списка для каждой визуализации, затем нажмите `Finish Import`.

### Метрики среды выполнения OTel {#otel-runtime-metrics}

Встроенные шаблоны метрик среды выполнения OTel предназначены для приложений, инструментированных с использованием [метрик среды выполнения OpenTelemetry](https://opentelemetry.io/docs/specs/semconv/runtime/).

| Шаблон                      | Описание                                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **.NET Runtime Metrics**    | Сборки мусора (GC), размер кучи, использование пула потоков и число сборок (assemblies) для приложений .NET |
| **Go Runtime Metrics**      | Число горутин, длительность пауз GC, использование кучи и статистика памяти для приложений Go               |
| **JVM Runtime Metrics**     | Память кучи и вне кучи, длительность GC, число потоков и загрузка классов для приложений на базе JVM        |
| **Node.js Runtime Metrics** | Задержка цикла событий, использование кучи, загрузка CPU и память V8 для приложений Node.js                 |

Примечания:

* В каждом шаблоне настроен [пользовательский фильтр](/ru/clickstack/features/dashboards/overview#custom-filters), отбирающий сервисы, у которых атрибут ресурса [`telemetry.sdk.language`](https://opentelemetry.io/docs/specs/semconv/registry/attributes/telemetry/#telemetry-sdk-language) соответствует среде выполнения панели мониторинга.
  * В средах с пользовательскими схемами таблиц метрик ClickHouse может потребоваться изменить этот фильтр так, чтобы он обращался к нужным столбцам Service Name и Resource Attributes.
  * В средах с большим объёмом данных время загрузки фильтра можно сократить, [материализовав](/ru/clickstack/managing/performance-tuning#materialize-frequently-queried-attributes) столбец `ResourceAttributes['telemetry.sdk.language']`.
* Шаблоны основаны на семантических соглашениях OTel (OTel Semantic Conventions), актуальных на момент публикации, и периодически обновляются вслед за спецификацией OTel. Для сервисов, инструментированных более старыми версиями OTel SDK, может потребоваться [отредактировать](/ru/clickstack/features/dashboards/overview#dashboards-editing-visualizations) визуализации, чтобы они использовали прежние имена метрик.
