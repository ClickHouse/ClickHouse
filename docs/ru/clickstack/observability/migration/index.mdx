Здесь описано, как перейти с Elastic Stack или Datadog на управляемый или самоуправляемый ClickHouse Observability. В руководствах рассматриваются планирование миграции, синтаксис поиска и адаптация существующего сбора телеметрии. Там, где сведения о подключении различаются, выберите вкладку для своего варианта развертывания.

| Технология                                                   | Описание                                                                                                                            |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| [Elastic Stack](/ru/clickstack/observability/migration/elastic) | Планирование перехода, преобразование поисковых запросов, перенос данных, агентов и инструментирования приложений                   |
| [Datadog](/ru/clickstack/observability/migration/datadog)       | Настройка существующих агентов Datadog для отправки телеметрии на управляемую конечную точку или в самоуправляемый приёмник Datadog |
