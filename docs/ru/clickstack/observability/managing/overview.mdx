<Note>
  В этом руководстве описывается полностью управляемый ClickHouse Observability. О самостоятельно управляемом ClickHouse Observability см. раздел [администрирование базы данных](/ru/clickstack/self-configured/managing/overview), где приведены рекомендации по сайзингу, срокам хранения, настройке схемы и эксплуатации в продакшн-среде, а также раздел [параметры конфигурации](/ru/clickstack/self-configured/managing/config), посвящённый настройкам источников.
</Note>

В разделе **Team Settings** можно управлять доступом к телеметрии, источниками, соединениями API и агентов, интеграциями, настройками запросов и разрешениями команды в ClickHouse Observability.

## Руководства по администрированию {#admin-guides}

| Руководство                                                            | Возможности                                                                                                                                                                    |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Параметры конфигурации](/ru/clickstack/observability/managing/config)    | Управление источниками и доступом коллекторов, поиск сведений о подключении для передачи телеметрии, настройка доступа для API и агентов, а также изменение настроек запросов. |
| [Ролевое управление доступом](/ru/clickstack/observability/managing/rbac) | Просмотр встроенных ролей, создание пользовательских ролей и настройка разрешений для панелей мониторинга, сохранённых поисков, источников и других ресурсов.                  |

## Отправка телеметрии {#sending-telemetry}

Чтобы подключить приложения и коллекторы, сначала получите сведения о подключении в разделе **Team Settings → Data → Управляемая телеметрия**, а затем воспользуйтесь [руководствами по ингестии](/ru/clickstack/observability/ingesting-data/overview).
