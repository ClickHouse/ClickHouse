Подключите свои конвейеры телеметрии и приложения к ClickHouse Observability с помощью решений наших партнёров по интеграции. В каждом руководстве описано, как настроить интеграцию для вашего развертывания.

| Раздел                                                                | Описание                                                                                                                                                                                    |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Bindplane](/ru/clickstack/observability/integration-partners/bindplane) | Bindplane — нативный для OpenTelemetry конвейер телеметрии с централизованным управлением коллекторами OpenTelemetry.                                                                       |
| [bitdrift](/ru/clickstack/observability/integration-partners/bitdrift)   | bitdrift — динамическая платформа обсервабилити для мобильных приложений, которая связывает телеметрию мобильных устройств с backend-трассировкой через контекст трассировки OpenTelemetry. |
| [Odigos](/ru/clickstack/observability/integration-partners/odigos)       | Odigos сочетает eBPF и OpenTelemetry, обеспечивая более глубокую распределённую трассировку при значительно меньших накладных расходах, чем у агентов, инструментирующих байт-код.          |
| [Telflo](/ru/clickstack/observability/integration-partners/telflo)       | Telflo — нативная для OpenTelemetry плоскость управления, которая централизует управление коллекторами и маршрутизацию телеметрии.                                                          |
