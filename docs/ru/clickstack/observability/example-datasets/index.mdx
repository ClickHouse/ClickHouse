Эти демонстрационные наборы данных и демо помогут вам начать работу с полностью управляемым ClickHouse Observability. Загрузите выборку данных, соберите журналы и метрики из своей среды или инструментируйте приложение, чтобы изучить трассировку и воспроизведение сеансов.

| Набор данных                                                                                           | Описание                                                                                                                                                                 |

| [Мониторинг Kubernetes](/ru/clickstack/observability/example-datasets/kubernetes)                         | Соберите журналы и метрики из кластера Kubernetes и отправьте их в свой управляемый сервис                                                                               |
| [Локальные данные](/ru/clickstack/observability/example-datasets/local-data)                              | Соберите локальные системные метрики и журналы и отправьте их на анализ в свой управляемый сервис                                                                        |
| [Демонстрация воспроизведения сеансов](/ru/clickstack/observability/example-datasets/session-replay)      | Инструментируйте демонстрационное веб-приложение для воспроизведения сеансов и просмотрите свои действия в ClickHouse Observability                                      |
| [Расширение Chrome](/ru/clickstack/observability/example-datasets/chrome-extension)                       | Внедрите браузерный SDK на любой веб-сайт с помощью расширения HyperDX для Chrome — без изменений в прикладном коде                                                      |
| [Синтетические данные с помощью otelgen](/ru/clickstack/observability/example-datasets/otelgen)           | Отправляйте синтетические журналы, трассировку и метрики на управляемую конечную точку приёма телеметрии с помощью `otelgen`                                             |
| [Синтетические данные с помощью telemetrygen](/ru/clickstack/observability/example-datasets/telemetrygen) | Отправляйте синтетические журналы, трассировку и метрики на управляемую конечную точку приёма телеметрии с помощью `telemetrygen`                                        |
| [HackerNews Analyzer](/ru/clickstack/observability/example-datasets/instrument-application)               | Инструментируйте приложение Node.js с помощью агента (или вручную) и отправьте журналы, трассировку, метрики и данные воспроизведения сеансов в ClickHouse Observability |
