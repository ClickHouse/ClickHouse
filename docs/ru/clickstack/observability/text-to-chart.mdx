Возможность Text-to-Chart в ClickHouse Observability позволяет создавать визуализации, просто описав обычным текстом, что вы хотите увидеть. Вместо того чтобы вручную выбирать метрики, фильтры и поля group-by, достаточно ввести промпт, например «Количество ошибок по сервисам за последние 3 дня», и ИИ-ассистент автоматически построит соответствующий чарт.

Эта возможность с помощью большой языковой модели (LLM) преобразует текстовый промпт в запрос, а затем строит визуализацию в [Обозревателе чартов](/ru/clickstack/observability/features/dashboards/overview#navigate-chart-explorer).

## Предварительные требования {#prerequisites}

Администратор команды должен включить функцию «Генеративный ИИ» в **Team Settings** в разделе **Configure Generative AI**. Инструкции см. в разделе [Включение генеративного ИИ](/ru/clickstack/observability/notebooks#enabling-generative-ai). Платформа управляет ИИ-моделями и провайдерами автоматически.

## Использование Text-to-Chart {#using-text-to-chart}

## Примеры промптов {#example-prompts}

Ниже приведены промпты для типичных сценариев работы с данными обсервабилити:

| Промпт                                            | Источник данных | Описание                                               |
| ------------------------------------------------- | --------------- | ------------------------------------------------------ |
| `Error count by service over time`                | Журналы         | Строит чарт частоты ошибок по сервисам                 |
| `Average request duration grouped by endpoint`    | Трассировки     | Показывает характер задержек для каждой конечной точки |
| `P99 latency by service`                          | Трассировки     | Выявляет хвостовую задержку по сервисам                |
| `Count of 5xx status codes over the last 6 hours` | Журналы         | Отслеживает динамику серверных ошибок                  |

В промптах можно ссылаться на любой столбец или атрибут, доступный в настроенных источниках данных. Чтобы ИИ построил нужный чарт, указывайте конкретные имена столбцов, фильтры и временные диапазоны.

## Ограничения {#limitations}

* В качестве источников данных поддерживаются только журналы и трассировки. Метрики Prometheus пока не поддерживаются.
* Точность чарта зависит от того, насколько ясно сформулирован промпт, и от структуры исходных данных. Если сгенерированный чарт не соответствует ожиданиям, попробуйте переформулировать промпт или явно указать имена столбцов.
