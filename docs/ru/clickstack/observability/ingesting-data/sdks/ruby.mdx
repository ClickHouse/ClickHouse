Используйте OpenTelemetry Ruby SDK для отправки трассировки в ClickHouse Observability.

## Настройка OpenTelemetry {#set-up-opentelemetry}

Следуйте официальным [инструкциям по настройке OpenTelemetry для Ruby](https://opentelemetry.io/docs/languages/ruby/getting-started/), чтобы инициализировать SDK и инструментировать приложение.

Настройте [экспорт OTLP по HTTP](https://opentelemetry.io/docs/languages/ruby/exporters/) для трассировки, используя приведённые ниже параметры соединения. Замените все примеры пунктов назначения из вышестоящей документации, в том числе переопределения конечных точек для отдельных сигналов.

## Настройка пункта назначения {#configure-destination}

<Tabs>
  <Tab title="Полностью управляемый">
    <BetaBadge label="Бета-версия" />

    Откройте в своём сервисе **Team Settings → Data → Managed Telemetry** и скопируйте **конечную точку OTLP HTTP** и **API key**. Укажите полную конечную точку HTTPS вместе с портом:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Самоуправляемый">
    Укажите конечную точку OTLP HTTP вашего коллектора и ключ ингестии. Если для коллектора не настроен TLS, используйте `http://` вместо `https://`. Подробнее о настройке коллектора см. в разделе [Загрузка данных с помощью OpenTelemetry](/ru/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Проверка ингестии {#verify-ingestion}

Запустите инструментированное приложение и создайте на нём нагрузку. В ClickHouse Observability выберите временной диапазон за последнее время и найдите имя сервиса вашего приложения в разделе Traces.

Сведения об устранении неполадок с инструментированием и экспортером см. в [документации OpenTelemetry для Ruby](https://opentelemetry.io/docs/languages/ruby/).
