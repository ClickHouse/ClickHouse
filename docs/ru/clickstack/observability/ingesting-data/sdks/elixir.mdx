Используйте OpenTelemetry Erlang/Elixir SDK для отправки данных трассировки в ClickHouse Observability.

<ClickStackIntegrates signals={['traces']} />

## Настройка OpenTelemetry {#set-up-opentelemetry}

Следуйте официальным [инструкциям по настройке OpenTelemetry для Erlang/Elixir](https://opentelemetry.io/docs/languages/erlang/getting-started/), чтобы инициализировать SDK и инструментировать приложение.

Настройте [экспорт OTLP по HTTP](https://opentelemetry.io/docs/languages/erlang/exporters/) для трассировки, используя приведённые ниже параметры соединения. Замените все примеры пунктов назначения из вышестоящих инструкций, в том числе переопределения конечных точек для отдельных сигналов.

## Настройка пункта назначения {#configure-destination}

<Tabs>
  <Tab title="Полностью управляемый">
    <BetaBadge label="Сервис в стадии бета-тестирования" />

    Откройте в своём сервисе раздел **Team Settings → Data → Managed Telemetry** и скопируйте **конечную точку OTLP по HTTP** и **API key**. Указывайте конечную точку HTTPS полностью, вместе с портом:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Самоуправляемый">
    Укажите конечную точку OTLP по HTTP вашего коллектора и ключ приёма данных. Если для коллектора не настроен TLS, используйте `http://` вместо `https://`. Подробнее о настройке коллектора см. в разделе [Загрузка данных с помощью OpenTelemetry](/ru/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Проверка ингестии {#verify-ingestion}

Запустите инструментированное приложение и создайте на нём нагрузку. В ClickHouse Observability выберите временной диапазон, охватывающий последние события, и найдите имя сервиса вашего приложения в разделе Traces.

Сведения об устранении неполадок с инструментированием и экспортером см. в [документации OpenTelemetry для Erlang/Elixir](https://opentelemetry.io/docs/languages/erlang/).
