Используйте OpenTelemetry Go SDK для отправки журналов, метрик и трассировки в ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Настройка OpenTelemetry {#set-up-opentelemetry}

Следуйте официальным [инструкциям по настройке OpenTelemetry для Go](https://opentelemetry.io/docs/languages/go/getting-started/), чтобы инициализировать SDK и инструментировать приложение.

Настройте [экспорт OTLP по HTTP](https://opentelemetry.io/docs/languages/go/exporters/) для сигналов, которые вы хотите отправлять, используя приведённые ниже параметры соединения. Замените все примеры пунктов назначения из вышестоящих инструкций, в том числе переопределения конечных точек для отдельных сигналов.

## Настройка пункта назначения {#configure-destination}

<Tabs>
  <Tab title="Полностью управляемый">
    <BetaBadge label="Сервис в стадии бета-тестирования" />

    Откройте в своём сервисе раздел **Team Settings → Data → Managed Telemetry** и скопируйте **конечную точку OTLP по HTTP** и **ключ API**. Укажите конечную точку HTTPS полностью, включая порт:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Самоуправляемый">
    Используйте конечную точку OTLP по HTTP вашего коллектора и ключ приёма данных. Если для коллектора не настроен TLS, укажите `http://` вместо `https://`. Инструкции по настройке коллектора см. в разделе [Загрузка данных с помощью OpenTelemetry](/ru/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Проверка ингестии {#verify-ingestion}

Запустите инструментированное приложение и создайте нагрузку. В ClickHouse Observability выберите недавний временной диапазон и найдите имя сервиса вашего приложения в разделе Logs или Traces. Если приложение отправляет метрики, подождите, пока завершится экспорт, и проверьте раздел Metrics.

Сведения об инструментировании и устранении неполадок с экспортером см. в [документации OpenTelemetry Go](https://opentelemetry.io/docs/languages/go/).
