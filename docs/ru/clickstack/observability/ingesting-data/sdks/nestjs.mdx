Используйте ClickStack Node.js SDK, чтобы собирать телеметрию из приложения NestJS и отправлять её в ClickHouse Observability. SDK поддерживает инструментирование запросов NestJS и перехватывает вывод в консоль.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Установка SDK {#install-sdk}

Требуется Node.js 22.15 или новее:

```shell
npm install @clickhouse/clickstack-node
```

## Настройка пункта назначения {#configure-destination}

<Tabs>
  <Tab title="Полностью управляемый">
    <BetaBadge label="Бета-версия" />

    Откройте в своём сервисе раздел **Team Settings → Data → Managed Telemetry** и скопируйте значения **конечная точка OTLP HTTP** и **API key**. Укажите полную конечную точку HTTPS вместе с портом:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Самоуправляемый">
    Укажите конечную точку OTLP HTTP вашего коллектора и ключ для ингестии. Если в коллекторе не настроен TLS, используйте `http://` вместо `https://`. О настройке коллектора см. раздел [Загрузка данных с помощью OpenTelemetry](/ru/clickstack/observability/ingesting-data/opentelemetry#self-managed).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Запуск приложения {#start-application}

Задайте переменную `OTEL_SERVICE_NAME`, чтобы идентифицировать приложение. Соберите приложение NestJS, а затем подключите SDK через предварительную загрузку перед скомпилированной точкой входа:

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

Замените `dist/main.js` на путь к результату вашей сборки. Если вы используете `ts-node` или другой транспайлер, перехватывающий `require`, укажите вместо этого `--require @clickhouse/clickstack-node/register`. Если вы собираете приложение в бандл, исключите из него SDK и инструментированные зависимости, оставив их внешними.

Вы можете по-прежнему использовать стандартный консольный логгер NestJS. Если вам нужен пользовательский логгер, используйте одну из поддерживаемых интеграций, например Winston или Pino. Подробнее о конфигурации и совместимости см. в [руководстве по Node.js](/ru/clickstack/observability/ingesting-data/sdks/nodejs).

## Проверка ингестии {#verify-ingestion}

Отправьте запрос к контроллеру и запишите сообщение в журнал. В ClickHouse Observability выберите недавний временной диапазон и найдите имя сервиса вашего приложения в разделах Logs и Traces. Метрики проверьте в разделе Metrics, выждав некоторое время, чтобы данные успели экспортироваться.
