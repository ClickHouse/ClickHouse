Используйте встроенную поддержку OpenTelemetry в Deno, чтобы отправлять журналы, метрики и трассировку в ClickHouse Observability. Ни ClickStack Node.js SDK, ни устаревший пакет логирования Deno для этого не нужны.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Настройка OpenTelemetry {#set-up-opentelemetry}

Чтобы инструментировать приложение, следуйте официальным [инструкциям по настройке OpenTelemetry для Deno](https://docs.deno.com/runtime/fundamentals/open_telemetry/). Настройте пункт назначения, как показано ниже, а затем включите встроенную интеграцию Deno при запуске приложения:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

Добавьте разрешения, необходимые вашему приложению. Замените все примеры пунктов назначения и настройки консольного экспортера из инструкций вышестоящего проекта, включая переопределения конечных точек для отдельных типов сигналов.

## Настройка пункта назначения {#configure-destination}

<Tabs>
  <Tab title="Полностью управляемый">
    <BetaBadge label="Бета-версия" />

    Откройте в своем сервисе **Team Settings → Data → Managed Telemetry** и скопируйте **конечную точку OTLP HTTP** и **ключ API**. Укажите полную конечную точку HTTPS вместе с портом:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Самоуправляемый">
    Укажите конечную точку OTLP HTTP вашего коллектора и ключ API для ингестии. Если для коллектора не настроен TLS, используйте `http://` вместо `https://`. Инструкции по настройке коллектора см. в разделе [Загрузка данных с помощью OpenTelemetry](/ru/clickstack/observability/ingesting-data/opentelemetry#self-managed).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Проверка ингестии {#verify-ingestion}

Запустите приложение и создайте на нём активность. В ClickHouse Observability выберите недавний временной диапазон и найдите имя сервиса вашего приложения в разделе журналов или трассировок. Раздел метрик проверьте позже, когда данные успеют экспортироваться.
