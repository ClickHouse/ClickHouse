## Подключение приложения {#connect-your-application}

1. Настройте инструментирование по руководству для вашего языка или платформы.
2. Выберите в этом руководстве пункт назначения:
   * **Полностью управляемый:** используйте управляемую конечную точку OTLP вашего сервиса и ключ API для приёма данных — они доступны в разделе **Team Settings → Data → Managed Telemetry**.
   * **Самоуправляемый:** используйте конечную точку OTLP вашего OpenTelemetry Collector и настроенный в нём ключ для приёма данных.
3. Создайте активность в приложении, а затем убедитесь, что ожидаемая телеметрия отображается в интерфейсе.

В отдельных руководствах приведены формат аутентификации и настройки экспортера для каждого SDK. В руководстве по Lambda также описан вариант со слоями OpenTelemetry, при котором телеметрия передаётся через локальный коллектор.
