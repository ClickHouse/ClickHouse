В этом руководстве описано, как инструментировать небольшое приложение на Node.js с помощью OpenTelemetry и отправлять его журналы, метрики, трассировки и записи воспроизведения сеансов в самостоятельно управляемый ClickHouse Observability. Серверная часть инструментируется без каких-либо изменений в исходном коде приложения.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) — это приложение на Node.js, которое выполняет запросы к набору данных HackerNews, размещённому в публичной демонстрационной среде ClickHouse. За каждым чартом, таблицей и полем поиска стоит реальный запрос к ClickHouse, поэтому любое действие пользователя порождает трассу, основным спаном которой является HTTPS-вызов от серверной части к ClickHouse.

Предполагается, что вы уже выполнили шаги из руководства [Настройка коллектора OpenTelemetry](/ru/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) и у вас запущен коллектор ClickStack, доступный с машины, на которой будет работать это приложение. **Убедитесь, что вы сохранили его конечную точку OTLP** и значение `OTLP_AUTH_TOKEN`, заданное при развертывании. Перед инструментированием эти значения нужно будет указать в `.env`.

## Предварительные требования {#prerequisites}

* Коллектор ClickStack, доступный с этой машины. Если вы ещё не развернули его, сначала выполните инструкции из руководства [Настройка коллектора OpenTelemetry](/ru/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* Конечная точка OTLP/HTTP этого коллектора (обычно порт `4318`) и заданный для него `OTLP_AUTH_TOKEN`. Укажите их в переменных `OTEL_EXPORTER_OTLP_ENDPOINT` и `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ и npm.

## Клонирование репозитория {#clone-the-repository}

Клонируйте репозиторий [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), установите зависимости и скопируйте шаблон файла env:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

На следующих шагах вы заполните файл `.env`, а затем инструментируете приложение из этого каталога.
