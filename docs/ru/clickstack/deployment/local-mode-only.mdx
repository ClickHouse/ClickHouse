Подобно [образу «всё в одном»](/ru/clickstack/deployment/all-in-one), этот комплексный Docker-образ включает все компоненты ClickStack:

* **ClickHouse**
* **Интерфейс ClickStack**
* **коллектор OpenTelemetry (OTel)** (предоставляет OTLP на портах `4317` и `4318`)
* **MongoDB** (для постоянного хранения состояния приложения)

**Однако в этом дистрибутиве интерфейса ClickStack аутентификация пользователей отключена**

<div id="suitable-for">
  ### Подходит для {#suitable-for}
</div>

* Демонстраций
* Отладки
* Разработки с использованием интерфейса ClickStack

## Шаги развертывания {#deployment-steps}

<br />

<Steps>
  <Step title="Развертывание с помощью Docker" id="deploy-with-docker">
    В локальном режиме интерфейс ClickStack разворачивается на порту 8080.

    ```shell
    docker run -p 8080:8080 clickhouse/clickstack-local:latest
    ```
  </Step>

  <Step title="Переход в интерфейс ClickStack" id="navigate-to-hyperdx-ui">
    Откройте [http://localhost:8080](http://localhost:8080), чтобы перейти в интерфейс ClickStack.

    **Создавать пользователя не потребуется, так как в этом режиме развертывания аутентификация отключена.**

    Подключитесь к собственному внешнему кластеру ClickHouse, например ClickHouse Cloud.

    <div className="ch-image-md">
      <Frame>
        ![Создание учетной записи](/images/use-cases/observability/hyperdx-2.webp)
      </Frame>
    </div>

    Создайте источник, оставив все значения по умолчанию, и укажите в поле `Table` значение `otel_logs`. Остальные настройки должны определиться автоматически, после чего можно нажать `Save New Source`.

    <div className="ch-image-md">
      <Frame>
        ![Создание источника логов](/images/use-cases/observability/hyperdx-logs.webp)
      </Frame>
    </div>
  </Step>
</Steps>
