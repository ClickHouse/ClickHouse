С помощью ClickStack можно анализировать трассировки запросов и метрики [Loom](https://github.com/ClickHouse/loom) — сервера Memory и поиска по коду для ИИ-агентов.

## Перед началом работы {#before-you-begin}

* Запущенный сервер Loom.
* [Развернутый ClickStack с открытым исходным кодом](/ru/clickstack/deployment/oss) с приёмником OTLP HTTP, доступным с сервера Loom.

## Как это работает {#how-it-works}

Loom экспортирует телеметрию в коллектор ClickStack OpenTelemetry по протоколу OTLP HTTP. Коллектор записывает телеметрию в ClickHouse, после чего она становится доступна в ClickStack.

## Настройка экспортера Loom {#configure-loom-exporter}

Ключ API для приёма данных ClickStack находится в разделе **Team Settings → API Keys**. Задайте следующие переменные окружения на сервере Loom, подставьте вместо URL и ключа из примера свои значения, а затем перезапустите Loom:

```bash
export LOOM_OTEL_EXPORTER=otlp
export LOOM_OTEL_EXPORTER_OTLP_ENDPOINT='http://clickstack-collector:4318'
export LOOM_OTEL_EXPORTER_OTLP_HEADERS='authorization=<YOUR_INGESTION_API_KEY>'
```

Укажите базовый URL коллектора, доступный из Loom. Loom добавляет к нему `/v1/traces` и `/v1/metrics`. Если Loom отправляет данные в промежуточный коллектор, укажите заголовки, которые ожидает этот приёмник, в виде пар `key=value`, разделённых запятыми. Если приёмнику заголовки не нужны, не указывайте настройку заголовков.

## Проверка телеметрии в ClickStack {#verify-telemetry}

Проверьте итоговые настройки экспортера Loom. Если сервер работает на другом хосте или порту, замените URL Loom из примера.

```bash
curl -sS 'http://localhost:7777/v1/health?include=otel'
```

Убедитесь, что `otel.mode` имеет значение `otlp`, а `otel.endpoint` указывает на настроенный URL коллектора.

Чтобы сгенерировать трассу, выполните запрос к Loom, например поиск в Memory. В ClickStack откройте **Поиск**, выберите источник **Трассировка** и задайте фильтр по имени сервиса `loom` (`service.name` в OpenTelemetry). Если задана переменная `LOOM_OTEL_SERVICE_NAME`, фильтруйте по её значению.
