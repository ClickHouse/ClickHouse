В этом руководстве показано, как инструментировать небольшое приложение на Node.js с помощью OpenTelemetry и отправлять его журналы, метрики, трассировку и воспроизведение сеансов в самостоятельно управляемый ClickHouse Observability. Бэкенд инструментируется без каких-либо изменений в исходном коде приложения.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) — приложение на Node.js, которое выполняет запросы к набору данных HackerNews, размещённому в публичной демо-среде ClickHouse. За каждым чартом, таблицей и полем поиска стоит реальный запрос к ClickHouse, поэтому любое действие пользователя порождает трассу, основной спан которой — HTTPS-вызов от бэкенда к ClickHouse.

Предполагается, что вы уже выполнили шаги из руководства [Настройка коллектора OpenTelemetry](/ru/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) и у вас запущен коллектор ClickStack, доступный с машины, на которой будет работать это приложение. **Обязательно сохраните его конечную точку OTLP** и значение `OTLP_AUTH_TOKEN`, заданное при развертывании. Перед инструментированием эти значения нужно будет указать в `.env`.

## Предварительные требования {#prerequisites}

* Коллектор ClickStack, доступный с этой машины. Если вы его ещё не развернули, сначала выполните инструкции из руководства [Настройка коллектора OpenTelemetry](/ru/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* Конечная точка OTLP/HTTP этого коллектора (обычно порт `4318`) и заданный для него `OTLP_AUTH_TOKEN`. Укажите их в `OTEL_EXPORTER_OTLP_ENDPOINT` и `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>` соответственно.
* Node 18+ и npm.

## Клонирование репозитория {#clone-the-repository}

Клонируйте репозиторий [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), установите зависимости и скопируйте шаблон файла переменных окружения:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

На следующих шагах вы заполните файл `.env`, а затем инструментируете приложение из этого каталога.
