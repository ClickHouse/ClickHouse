## Основные концепции ClickHouse {#core-concepts}

Для большинства задач администрирования необходимо понимать, как устроена лежащая в основе база данных ClickHouse. Прежде чем выполнять административные операции или работы, связанные с производительностью, рекомендуем ознакомиться с основными концепциями ClickHouse, перечисленными ниже.

| Концепция                              | Описание                                                                                                                                                                                      |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Таблицы**                            | Как источники данных соотносятся с базовыми таблицами ClickHouse. Таблицы ClickHouse в основном используют движок [`MergeTree`](/ru/reference/engines/table-engines/mergetree-family/mergetree). |
| **Части**                              | Как данные записываются в виде неизменяемых частей и со временем сливаются.                                                                                                                   |
| **Партиции**                           | Логические группы частей таблицы, упрощающие управление данными, выполнение запросов и оптимизацию.                                                                                           |
| **Слияния**                            | Фоновый процесс, который объединяет части, чтобы сократить число частей, затрагиваемых запросами, и поддерживать производительность.                                                          |
| **Гранулы**                            | Наименьшая единица данных, которая считывается или отсекается при выполнении запроса.                                                                                                         |
| **Первичные ключи (ключи сортировки)** | Как ключ `ORDER BY` определяет размещение данных на диске, сжатие и отсечение данных при выполнении запросов.                                                                                 |

Эти концепции лежат в основе производительности ClickHouse и помогут вам принимать взвешенные административные решения при управлении Самостоятельно управляемым ClickHouse Observability.
