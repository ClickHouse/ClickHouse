ClickHouse Observability — Self-managed целиком работает в **ClickHouse Cloud**: это полностью управляемый бэкенд для обсервабилити, в котором сохраняются та же модель данных ClickStack и тот же пользовательский опыт.

В этой модели **ClickHouse и интерфейс ClickStack** размещаются, обслуживаются и защищаются силами ClickHouse Cloud. Пользователь отвечает только за запуск **коллектора OpenTelemetry (OTel)**, который отправляет телеметрические данные в управляемый сервис.

### ClickHouse Cloud: движок {#clickhouse-cloud}

В основе ClickHouse Observability — Self-managed лежит ClickHouse Cloud — бессерверная версия ClickHouse, столбцовой базы данных, предназначенной для real-time аналитики в больших масштабах. ClickHouse Cloud обеспечивает ингестию данных обсервабилити и выполнение запросов к ним, предоставляя:

* Поиск по терабайтам событий менее чем за секунду
* Ингестию миллиардов high-cardinality записей в сутки
* Высокую степень сжатия данных обсервабилити — не менее чем в 10 раз
* Нативную поддержку полуструктурированных данных JSON с возможностью динамического изменения схемы
* Мощный SQL-движок с сотнями встроенных аналитических функций

ClickHouse Cloud обрабатывает данные обсервабилити как широкие события, что позволяет глубоко сопоставлять журналы, метрики и трассировки в единой структуре.

По сравнению с ClickHouse с открытым исходным кодом ClickHouse Cloud дает ряд преимуществ для обсервабилити:

* Автоматическое масштабирование вычислительных ресурсов независимо от хранилища
* Недорогое и практически неограниченное хранение данных на базе объектного хранилища
* Возможность [независимо изолировать рабочие нагрузки чтения и записи](/ru/clickstack/self-configured/managing/isolating-read-write) с помощью хранилищ (Warehouses).
* Встроенная аутентификация
* Автоматическое резервное копирование
* Средства обеспечения безопасности и соответствия требованиям
* Бесшовные обновления

### Коллектор OpenTelemetry: ингестия данных {#open-telemetry-collector-managed}

ClickHouse Observability — Self-managed включает предварительно настроенный коллектор OpenTelemetry (OTel) для приёма телеметрии открытым стандартизированным способом. Данные можно отправлять по протоколу OTLP через:

* gRPC (порт `4317`)
* HTTP (порт `4318`)

Коллектор экспортирует телеметрию в ClickHouse Cloud эффективными пакетами. Он поддерживает оптимизированные схемы таблиц для каждого источника данных, что обеспечивает масштабируемую производительность для всех типов сигналов.

### Интерфейс ClickStack {#hyperdx}

Интерфейс ClickStack — это пользовательский интерфейс ClickStack. Его возможности:

* Поиск на естественном языке и в стиле Lucene
* Просмотр поступающих данных в реальном времени (live tailing) для отладки
* Единое представление журналов, метрик и трассировок
* Воспроизведение сеансов для обсервабилити фронтенда
* Создание панелей мониторинга и настройка оповещений
* Интерфейс SQL-запросов для углублённого анализа

Интерфейс ClickStack, разработанный специально для ClickHouse, сочетает мощный поиск с интуитивно понятными рабочими процессами и позволяет быстро выявлять аномалии, расследовать проблемы и получать ценные выводы.

В ClickHouse Observability — Self-managed интерфейс интегрирован с системой аутентификации консоли ClickHouse Cloud.
