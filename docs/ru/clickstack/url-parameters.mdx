Страницы ClickStack можно открывать по глубоким ссылкам с параметрами запроса URL, чтобы сразу перейти к определенному поиску, панели мониторинга или панели из внешней системы (уведомления об оповещении, runbook, задачи CI, сообщения в чате и т. д.).

В примерах на этой странице используется `<YOUR_CLICKSTACK_URL>`. Замените его на URL вашего ClickStack — например, `http://localhost:8080` для локального развертывания с открытым исходным кодом.

<Note>
  Для удобства чтения в примерах параметры запроса показаны без URL-кодирования. При программном создании ссылок выполняйте URL-кодирование значения каждого параметра запроса.
</Note>

Сведения о параметрах сервиса ClickHouse Cloud и ссылках на блокноты см. в разделе [Глубокие ссылки ClickHouse Observability](/ru/clickstack/observability/url-parameters).

## Поиск — `/search` {#search}

Основное представление для поиска журналов и трассировок. Подробнее о синтаксисе поиска см. в разделе [Поиск](/ru/clickstack/features/search).

| Параметр        | Формат                                                                     | Описание                                                                                                                                                        |
| --------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`        | string                                                                     | Источник, в котором выполняется поиск: принимает ID источника или его **имя** (например, `Logs`). На этой странице поддерживаются только источники Log и Trace. |
| `where`         | string                                                                     | Текст фильтрующего запроса в синтаксисе Lucene или SQL (см. `whereLanguage`).                                                                                   |
| `whereLanguage` | `lucene` | `sql`                                                           | Язык запросов, на котором написан `where`.                                                                                                                      |
| `select`        | string                                                                     | Список SQL-столбцов и выражений для отображения в таблице результатов.                                                                                          |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | Структурированные фасетные фильтры, применяемые дополнительно к `where`.                                                                                        |
| `orderBy`       | string                                                                     | SQL-выражение сортировки для таблицы результатов.                                                                                                               |
| `mode`          | `results` | `delta` | `pattern`                                            | Активный режим анализа. `delta` доступен только для источников трассировок.                                                                                     |
| `isLive`        | `true` | `false`                                                           | Включен ли live tail (по умолчанию `true`).                                                                                                                     |
| `traceId`       | string                                                                     | Выполняет переход непосредственно к представлению trace waterfall для указанного ID трассировки.                                                                |
| `from`, `to`    | миллисекунды эпохи                                                         | Абсолютный временной диапазон. Если не указано, по умолчанию используется последние 15 минут.                                                                   |

Сохранённый поиск также можно открыть напрямую по адресу `/search/<savedSearchId>`.

### Пример: поиск ошибок сервиса `checkout` в источнике `Logs` за указанный временной диапазон {#example-search-errors}

```text
<YOUR_CLICKSTACK_URL>/search?source=Logs&from=1735689600000&to=1735693200000&where=level:error&filters=[{"type":"sql","condition":"ServiceName IN ('checkout')"}]
```

### Пример: переход сразу к представлению трассировки в виде водопада {#example-search-trace}

```text
<YOUR_CLICKSTACK_URL>/search?source=Traces&traceId=ba7217967eb90d040b7eb39f97ecc5c4
```

Список сохранённых поисков.

| Параметр | Формат | Описание                                                         |
| -------- | ------ | ---------------------------------------------------------------- |
| `tag`    | string | Фильтрует список, оставляя сохранённые поиски с указанным тегом. |

```text

```

## Панели мониторинга — `/dashboards/<dashboardId>` {#dashboards}

Сохранённая панель мониторинга. Не указывайте `<dashboardId>` (`/dashboards`), чтобы открыть временную несохранённую панель мониторинга. Подробнее о создании панелей мониторинга см. в разделе [Панели мониторинга](/ru/clickstack/features/dashboards/overview).

| Параметр            | Формат                                                                                                                              | Описание                                                                                                                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `from`, `to`        | миллисекунды эпохи                                                                                                                  | Временной диапазон, применяемый ко всем плиткам. Если не указан, по умолчанию используется диапазон за последние 15 минут.                                                                            |
| `where`             | string                                                                                                                              | Текст запроса фильтра на уровне панели мониторинга, применяемый ко всем плиткам.                                                                                                                      |
| `whereLanguage`     | `lucene` | `sql`                                                                                                                    | Язык запросов, на котором написан `where`.                                                                                                                                                            |
| `filters`           | JSON-массив записей со значениями фильтров                                                                                          | Значения, выбранные в [пользовательских фильтрах и переменных](/ru/clickstack/features/dashboards/overview#custom-filters) панели мониторинга. См. раздел [Значения фильтров](#dashboard-filter-values). |
| `granularity`       | `auto` | `30 second` | `1 minute` | `5 minute` | `10 minute` | `15 minute` | `30 minute` | `1 hour` | `12 hour` | `1 day` | `7 day` | Размер бакета для плиток временных рядов. `auto` выбирает размер бакета в зависимости от выбранного временного диапазона.                                                                             |
| `highlightedTileId` | string                                                                                                                              | Прокручивает страницу до указанной плитки и выделяет её — полезно при переходе по ссылке из оповещения.                                                                                                    |

### Значения фильтров {#dashboard-filter-values}

Параметр `filters` представляет собой JSON-массив. Каждая запись задаёт выбранные значения одного фильтра в одной из следующих форм:

| Запись                                                                                                            | Назначение                                                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `{"type":"variable","name":"<variableName>","values":["<value1>","<value2>"]}`                                    | Фильтры, являющиеся переменными: фильтры статических значений, значений SQL-запроса и значений меток PromQL, переменные источника данных и соединения, а также фильтры значений SQL-выражения с включённым параметром **Available as variable**. `name` — имя переменной фильтра.                             |
| `{"type":"adhoc","name":"<uniqueName>","conditions":[{"key":"<key>","operator":"<operator>","value":"<value>"}]}` | [Ad hoc-фильтры](/ru/clickstack/features/dashboards/overview#adhoc-filters). `name` — уникальное имя фильтра, а `operator` — один из операторов `=`, `!=`, `=~`, `!~`, `LIKE`, `NOT LIKE` или `IN`. `LIKE` и `NOT LIKE` применяются только к SQL-источникам: ad hoc-фильтры Prometheus игнорируют условия с ними. |
| `{"type":"sql","condition":"<expression> IN ('<value1>', '<value2>')"}`                                           | Фильтры значений SQL-выражения, не являющиеся переменными. Выражение в условии должно совпадать со значением **Filter expression** фильтра.                                                                                                                                                                    |

Действуют следующие правила:

* Запись переменной имеет приоритет над записью `sql`, относящейся к тому же фильтру. Ссылки, созданные до появления переменных и использующие записи `sql` для всех фильтров, продолжают работать.
* Для переменных источника данных и соединения в качестве значения можно указать **имя** источника или соединения вместо его ID. Сначала ищется точное совпадение имени, затем — без учёта регистра. Благодаря этому ссылки остаются стабильными в разных окружениях, где у одного и того же источника разные ID.
* Для фильтра с одиночным выбором используется только первое значение.
* Записи, которые не соответствуют ни одному фильтру на панели мониторинга или имеют некорректный формат, игнорируются.

### Пример: открыть панель мониторинга за указанный временной диапазон с выделенной плиткой {#example-dashboard-highlight}

Полезно, если нужно перейти из уведомления об оповещении сразу к плитке, вызвавшей его.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?from=1735689600000&to=1735693200000&highlightedTileId=chart-1
```

### Пример: выбор значений в фильтрах-переменных {#example-dashboard-variables}

Выбирает `checkout` и `payments` в фильтре с именем переменной `service`, а также `ERROR` в фильтре с именем переменной `severity`.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?filters=[{"type":"variable","name":"service","values":["checkout","payments"]},{"type":"variable","name":"severity","values":["ERROR"]}]
```

### Пример: выбор источника данных и соединения по имени {#example-dashboard-source-variable}

Выбирается источник `Production Logs` в переменной источника данных `logs` и соединение `Production` в переменной соединения `cluster`.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?filters=[{"type":"variable","name":"logs","values":["Production Logs"]},{"type":"variable","name":"cluster","values":["Production"]}]
```

### Пример: добавление условий в ad hoc-фильтр {#example-dashboard-adhoc}

Добавляет два условия в ad hoc-фильтр с уникальным именем `adhoc`: `ServiceName` равно `checkout` или `payments`, а `SeverityText` не равно `DEBUG`.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?filters=[{"type":"adhoc","name":"adhoc","conditions":[{"key":"ServiceName","operator":"IN","value":"checkout"},{"key":"ServiceName","operator":"IN","value":"payments"},{"key":"SeverityText","operator":"!=","value":"DEBUG"}]}]
```

## Chart Explorer — `/chart` {#chart-explorer}

Конструктор диаграмм для разового использования с возможностью поделиться результатом.

| Параметр     | Формат             | Описание                                                                                                                                            |
| ------------ | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config`     | JSON               | Полная конфигурация диаграммы (source, select, where, тип диаграммы и т. д.). Обычно создаётся с помощью ссылок «Share» в приложении, а не вручную. |
| `from`, `to` | миллисекунды эпохи | Временной диапазон. Если не указан, по умолчанию используется период за последние 15 минут.                                                         |

### Пример: откройте конфигурацию диаграммы задержки p99 за выбранный временной диапазон {#example-chart-config}

```text
<YOUR_CLICKSTACK_URL>/chart?granularity=auto&from=1785759381784&to=1785762981785&config={"name":"","select":[{"aggFn":"quantile","aggCondition":"","aggConditionLanguage":"lucene","valueExpression":"Duration","level":0.99,"alias":"p99"}],"where":"","whereLanguage":"lucene","displayType":"line","alignDateRangeToGranularity":true,"source":"68814eb5d40a9d0449afc1f2","connection":"68814b6fd40a9d0449afbe78","groupBy":"ServiceName"}
```

## Сервисы — `/services` {#services}

Панели мониторинга HTTP, базы данных и ошибок для отдельных сервисов.

| Параметр        | Формат                                                                     | Описание                                                                                      |
| --------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `tab`           | `http` | `database` | `errors`                                             | Отображаемая вложенная вкладка панели мониторинга сервиса. По умолчанию: `http`               |

| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | Значения панели фильтров панели мониторинга.                                                  |
| `from`, `to`    | миллисекунды эпохи                                                         | Временной диапазон. Если не указаны, по умолчанию используются последние 15 минут.            |
