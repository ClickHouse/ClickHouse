Действия в консоли записываются в журнал аудита. Пользователи, имеющие доступ, могут просматривать журнал и интегрировать его со своими системами логирования. Доступ к журналу аудита определяется разрешением **View audit logs** (`control-plane:organization:view-activities`):

* Пользователи с ролью организации Admin имеют доступ по умолчанию.
* Остальным пользователям консоли требуется доступ к организации, а также [пользовательская роль](/ru/products/cloud/guides/security/cloud-access-management/manage-custom-roles), включающая разрешение **View audit logs**.
* Ключам API требуется роль, включающая это же разрешение.

Описание всех разрешений см. в разделе [Роли и разрешения в консоли](/ru/products/cloud/reference/security/console-roles).

## Доступ к журналу консоли через интерфейс {#console-audit-log-ui}

<Steps>
  <Step title="Выберите организацию" id="select-org">
    В ClickHouse Cloud перейдите к сведениям о своей организации.

    <Image img="/images/cloud/security/activity_log1.webp" size="md" alt="Вкладка активности ClickHouse Cloud" border />

    <br />
  </Step>

  <Step title="Выберите аудит" id="select-audit">
    Выберите вкладку **Audit** в левом меню, чтобы увидеть, какие изменения были внесены в вашей организации ClickHouse Cloud, включая то, кто и когда их внес.

    На странице **Activity** отображается таблица со списком событий, зарегистрированных для вашей организации. По умолчанию этот список отсортирован в обратном хронологическом порядке (самое новое событие сверху). Чтобы изменить порядок сортировки, нажмите на заголовки столбцов. Каждый элемент таблицы содержит следующие поля:

    * **Activity:** Текстовое описание события
    * **User:** Пользователь, инициировавший событие
    * **IP Address:** Если применимо, в этом поле указан IP-адрес пользователя, инициировавшего событие
    * **Time:** Временная метка события

    <Image img="/images/cloud/security/activity_log2.webp" size="md" alt="Таблица активности ClickHouse Cloud" border />

    <br />
  </Step>

  <Step title="Используйте строку поиска" id="use-search-bar">
    Вы можете использовать строку поиска, чтобы отфильтровать события по различным критериям, например по имени сервиса или IP-адресу. Эту информацию также можно экспортировать в формате CSV для передачи или анализа во внешнем инструменте.
  </Step>
</Steps>
