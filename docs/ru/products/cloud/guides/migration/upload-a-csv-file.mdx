  <View title="Интерфейс Cloud">
    ClickHouse Cloud позволяет легко импортировать файлы и поддерживает
    следующие форматы:

    | Формат                          |
    | ------------------------------- |
    | `CSV`                           |
    | `CSVWithNamesAndTypes`          |
    | `CSVWithNames`                  |
    | `JSONEachRow`                   |
    | `TabSeparated`                  |
    | `TabSeparatedWithNames`         |
    | `TabSeparatedWithNamesAndTypes` |

    <Steps>
      <Step title="Загрузка файла" id="upload-file">
        На главной странице Cloud выберите свой сервис, как показано ниже:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_02](/images/cloud/migrate/csv_01.webp)
          </Frame>
        </div>

        Если сервис находится в режиме простоя, его нужно будет разбудить.

        Выберите `Data sources` на панели слева, как показано ниже:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_03](/images/cloud/migrate/csv_02.webp)
          </Frame>
        </div>

        Затем выберите `Upload a file` в правой части страницы источников данных:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_04](/images/cloud/migrate/csv_03.webp)
          </Frame>
        </div>

        Откроется диалоговое окно, в котором можно выбрать файл для
        вставки данных в таблицу вашего сервиса ClickHouse Cloud.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_04.webp)
          </Frame>
        </div>
      </Step>

      <Step title="Настройка таблицы" id="configure-table">
        После загрузки файла вы сможете настроить таблицу, в которую
        нужно вставить данные. Отображается предварительный просмотр таблицы с первыми тремя строками.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_08](/images/cloud/migrate/csv_08.webp)
          </Frame>
        </div>

        Теперь можно выбрать целевую таблицу. Доступные варианты:

        * новая таблица
        * существующая таблица

        <br />

        Можно указать базу данных, в которую нужно загрузить данные, а в случае
        новой таблицы — имя создаваемой таблицы. Также можно выбрать ключ сортировки:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_05.webp)
          </Frame>
        </div>

        Столбцы, прочитанные из файла, отображаются как `Source field`, и для каждого поля
        можно изменить:

        * выведенный тип
        * значение по умолчанию
        * делать ли столбец [Nullable](/ru/reference/data-types/nullable)

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_06](/images/cloud/migrate/csv_06.webp)
          </Frame>
        </div>

        <Info>
          **Исключение полей**

          Вы также можете удалить поле, если не хотите включать его в импорт
        </Info>

        Можно указать тип движка таблицы:

        * `MergeTree`
        * `ReplacingMergeTree`
        * `SummingMergeTree`
        * `Null`

        <br />

        Можно задать выражение ключа партиционирования и выражение
        первичного ключа.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_07](/images/cloud/migrate/csv_07.webp)
          </Frame>
        </div>

        Нажмите `Import to ClickHouse` (см. выше), чтобы импортировать данные. Импорт данных будет поставлен в очередь,
        о чём свидетельствует значок статуса `queued` в столбце `Status`, как показано ниже. Также можно нажать
        `Open as query` (см. выше), чтобы открыть запрос на вставку в консоли SQL. Этот запрос вставляет
        файл, загруженный в бакет S3, с помощью табличной функции `URL`.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_09](/images/cloud/migrate/csv_09.webp)
          </Frame>
        </div>

        Если задание завершится с ошибкой, в столбце `Status` вкладки
        `Data upload history` появится значок статуса `failed`. Нажмите `View Details`, чтобы узнать,
        почему загрузка не удалась. В зависимости от сообщения об ошибке может потребоваться изменить конфигурацию таблицы или очистить
        данные.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_11](/images/cloud/migrate/csv_10.webp)
          </Frame>
        </div>
      </Step>
    </Steps>
  </View>
