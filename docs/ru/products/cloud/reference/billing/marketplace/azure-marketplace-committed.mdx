Начните работу с ClickHouse Cloud на [Azure Marketplace](https://azuremarketplace.microsoft.com/en-us/marketplace/apps) по контракту с обязательствами. Такой контракт, также известный как Private Offer, позволяет клиентам взять на себя обязательство потратить определённую сумму на ClickHouse Cloud в течение определённого периода времени.

<div id="prerequisites">
  ## Необходимые условия {#prerequisites}
</div>

* Персональное предложение от ClickHouse на определённых договорных условиях.

## Порядок регистрации {#steps-to-sign-up}

1. Вам должно было прийти письмо со ссылкой для просмотра и принятия индивидуального предложения.

<br />

<div className="ch-image-md">
  <Frame>
    ![Письмо с индивидуальным предложением Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-1.webp)
  </Frame>
</div>

<br />

2. Нажмите ссылку **Review Private Offer** в письме. Откроется страница Azure Marketplace с подробностями индивидуального предложения.

<br />

<div className="ch-image-md">
  <Frame>
    ![Подробности индивидуального предложения в Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-2.webp)
  </Frame>
</div>

<br />

3. После принятия предложения откроется экран **Private Offer Management**. Подготовка предложения к покупке может занять у Azure некоторое время.

<br />

<div className="ch-image-md">
  <Frame>
    ![Страница Private Offer Management в Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-3.webp)
  </Frame>
</div>

<br />

<div className="ch-image-md">
  <Frame>
    ![Загрузка страницы Private Offer Management в Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-4.webp)
  </Frame>
</div>

<br />

4. Через несколько минут обновите страницу. Предложение должно стать доступным для покупки (**Purchase**).

<br />

<div className="ch-image-md">
  <Frame>
    ![Страница Private Offer Management в Azure Marketplace с доступной покупкой](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-5.webp)
  </Frame>
</div>

<br />

5. Нажмите **Purchase** — откроется выдвижная панель. Выполните следующие действия:

<br />

* Выберите подписку и группу ресурсов.
* Укажите имя подписки SaaS.
* Выберите тарифный план, на который у вас есть индивидуальное предложение. Сумма будет указана только для срока, на который создано индивидуальное предложение (например, 1 год). Для остальных сроков оплаты будет указана сумма $0.
* Укажите, нужна ли вам автоматическое продление оплаты. Если оно не выбрано, контракт завершится в конце расчётного периода, а ресурсы будут выведены из эксплуатации.
* Нажмите **Review + subscribe**.

<br />

<div className="ch-image-md">
  <Frame>
    ![Форма подписки Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-6.webp)
  </Frame>
</div>

<br />

6. На следующем экране проверьте все данные и нажмите **Subscribe**.

<br />

<div className="ch-image-md">
  <Frame>
    ![Подтверждение подписки Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-7.webp)
  </Frame>
</div>

<br />

7. На следующем экране появится сообщение **Your SaaS subscription in progress**.

<br />

<div className="ch-image-md">
  <Frame>
    ![Страница оформления подписки Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-8.webp)
  </Frame>
</div>

<br />

8. Когда подписка будет готова, нажмите **Configure account now**. Это критически важный шаг: он привязывает подписку Azure к организации ClickHouse Cloud в вашем аккаунте. Без него оформление подписки через маркетплейс не будет завершено.

<br />

<div className="ch-image-md">
  <Frame>
    ![Кнопка Configure account now в Azure Marketplace](/images/cloud/manage/billing/marketplace/azure-marketplace-committed-9.webp)
  </Frame>
</div>

<br />

9. Вы будете перенаправлены на страницу регистрации или входа в ClickHouse Cloud. Зарегистрируйте новый аккаунт или войдите в существующий. После входа будет создана новая организация, готовая к работе, оплата которой производится через Azure Marketplace.

10. Прежде чем продолжить, нужно ответить на несколько вопросов — указать адрес и сведения о компании.

<br />

<div className="ch-image-md">
  <Frame>
    ![Форма регистрационных данных ClickHouse Cloud](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
  </Frame>
</div>

<br />

11. После нажатия **Complete sign up** вы попадёте в свою организацию в ClickHouse Cloud. Там можно открыть экран биллинга и убедиться, что оплата производится через Azure Marketplace, а также создавать сервисы.

<br />

<br />

<div className="ch-image-sm">
  <Frame>
    ![Форма регистрационных данных ClickHouse Cloud](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-11.webp)
  </Frame>
</div>

<br />

<br />

<div className="ch-image-md">
  <Frame>
    ![Форма регистрационных данных ClickHouse Cloud](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-12.webp)
  </Frame>
</div>
