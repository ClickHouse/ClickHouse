В этом разделе описана модель ценообразования для коннекторов CDC (фиксация изменений данных) в ClickPipes.

<div id="cdc-oltp">
  ## OLTP CDC
</div>

| Коннектор        | Стадия доступности    | Статус тарификации                                                                                                                                                                                                                      |
| ---------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Postgres CDC** | Общедоступно (GA)     | Тарифицируется в соответствии с указанными [параметрами тарификации](#pricing-dimensions-oltp).                                                                                                                                         |
| **MySQL CDC**    | Публичная бета-версия | **Бесплатно** в период публичной бета-версии. Тарификация начнётся после перевода коннектора в статус общедоступного (GA) — **1 сентября 2026 года** — в соответствии с указанными [параметрами тарификации](#pricing-dimensions-oltp). |
| **MongoDB CDC**  | Публичная бета-версия | **Бесплатно** в период публичной бета-версии. Тарификация начнётся после перевода коннектора в статус общедоступного (GA) в соответствии с указанными [параметрами тарификации](#pricing-dimensions-oltp).                              |

<div id="pricing-dimensions-oltp">
  ### Параметры ценообразования
</div>

Стоимость коннекторов OLTP CDC рассчитывается по двум параметрам: [объёму данных](#data-volume-oltp) и [вычислительным ресурсам](#compute-oltp).

<div id="data-volume-oltp">
  #### Объём данных
</div>

Объём необработанных несжатых данных, считанных из потока репликации базы данных и загруженных в ClickHouse. Стоимость зависит от фазы ингестии:

* **Начальная загрузка / ресинхронизация**: На этом этапе коннектор получает и загружает согласованный снимок таблиц, выбранных для репликации. Это происходит при первом создании ClickPipe, добавлении новой таблицы в существующий ClickPipe или возникновении неисправимой ошибки, требующей повторной загрузки согласованного снимка.

* **Непрерывная репликация (CDC)**: На этом этапе коннектор получает текущие изменения в таблицах, выбранных для репликации, такие как вставки, обновления и удаления. Это происходит после завершения начальной загрузки и перехода ClickPipe в состояние `Running`.

| Фаза                                     | Стоимость  |
| ---------------------------------------- | ---------- |
| **Начальная загрузка / ресинхронизация** | $0.10 / GB |
| **Непрерывная репликация (CDC)**         | $0.20 / GB |

<div id="compute-oltp">
  #### Вычислительные ресурсы
</div>

Вычислительные единицы, выделенные **на сервис** для CDC ClickPipes, **совместно используются** всеми CDC ClickPipes в этом сервисе. Объём вычислительных ресурсов, выделяемых по умолчанию, зависит от уровня вашей организации.

| Уровень                          | Вычислительные единицы (CU)                     | Стоимость   |
| -------------------------------- | ----------------------------------------------- | ----------- |
| **Уровень Basic**                | 0.5 CU (1 vCPU, 4 ГБ оперативной памяти)/сервис | $0.10 / час |
| **Уровень Scale или Enterprise** | 1 CU (2 vCPU, 8 ГБ оперативной памяти)/сервис   | $0.20 / час |

Поскольку вычислительные ресурсы используются совместно, эта составляющая стоимости остаётся **фиксированной** для каждого сервиса по мере масштабирования использования CDC ClickPipes. Дополнительные вычислительные единицы можно выделить, [масштабировав сервис CDC ClickPipes](https://clickhouse.com/docs/cloud/manage/api/swagger#tag/ClickPipes/operation/clickPipeCdcScalingUpdate); стоимость при этом растёт линейно.

<div id="cost-breakdown-oltp">
  #### Ежемесячная разбивка затрат
</div>

##### Первый месяц {#cost-breakdown-first-month-oltp}

**Первоначальная загрузка** (однократно, тарифицируется по более низкой ставке):

$$(200 + 100) \text{ ГБ} \times \$0.10/\text{GB} = \$30$$

**Непрерывная репликация (CDC)**:

$$(100 + 50) \text{ ГБ} \times \$0.20/\text{GB} = \$30$$

**Вычисление** (общие для обоих ClickPipes, тарифицируется на каждый сервис):

$$1 \text{ вычислительная единица} \times \$0.20/\text{hr} \times 730 \text{ часов} = \$146$$

**Итого за первый месяц**:

$$\$30 \text{ (первоначальная загрузка)} + \$30 \text{ (CDC)} + \$146 \text{ (вычисление)} = \$206$$

##### Последующие месяцы {#cost-breakdown-following-months-oltp}

$$\$30 \text{ (CDC)} + \$146 \text{ (compute)} = \$176 \text{ в месяц}$$

Для CDC ClickPipes вычислительные ресурсы — это **фиксированная стоимость, общая для всех CDC ClickPipes** в рамках сервиса, независимо от типа коннектора. В этом примере добавление MySQL ClickPipe увеличило стоимость только за счёт **принимаемых данных**, но не за счёт дополнительных вычислительных ресурсов: то есть счёт растёт вместе с объёмом принимаемых данных, а не с количеством запущенных ClickPipes.

Чтобы избежать узких мест в производительности и эффективно использовать вычислительные ресурсы, выделенные сервису, рекомендуем реплицировать все таблицы из одного и того же экземпляра исходной базы данных через один ClickPipe — до тех пор, пока не появится веская причина разделить рабочую нагрузку между несколькими ClickPipes или увеличить масштаб.

<div id="faq-cdc">
  ## Часто задаваемые вопросы о CDC ClickPipes
</div>

<Accordion title="Могу ли я использовать кредиты ClickHouse Cloud для CDC ClickPipes?">
  Да. Стоимость ClickPipes входит в единую тарификацию ClickHouse Cloud. Все имеющиеся у вас
  кредиты платформы автоматически применяются и к использованию ClickPipes.
</Accordion>

<Accordion title="Каких дополнительных расходов на CDC ClickPipes следует ожидать в рамках моих текущих ежемесячных затрат на ClickHouse Cloud?">
  Влияние на стоимость существенно зависит от сценария использования, объёма данных и уровня организации. У большинства клиентов расходы увеличиваются на **5–25%** относительно базовых ежемесячных затрат на ClickHouse Cloud, хотя для сервисов с меньшими расходами этот показатель может быть выше. Важно отметить, что стоимость CDC ClickPipes масштабируется очень эффективно: вычислительные ресурсы распределяются между всеми CDC ClickPipes в одном сервисе, поэтому добавление новых ClickPipes лишь незначительно увеличивает расходы в зависимости от объёма принимаемых данных.

  Для коннекторов CDC ClickPipes, отмеченных как **бесплатные** в `Billing Status`, будущие расходы можно оценить по метрикам объёма данных в интерфейсе ClickPipes (**Метрики** &gt; **байты CDC** и **байты начальной загрузки**), а также через [совместимую с Prometheus конечную точку](/integrations/clickpipes/monitoring) ClickHouse Cloud.
</Accordion>

<Accordion title="Где можно увидеть расходы на CDC ClickPipes в счёте ClickHouse Cloud?">
  Расходы на CDC ClickPipes указаны в счёте ClickHouse Cloud отдельными строками с `Entity Type`, равным `clickpipe`, с разбивкой по измерениям тарификации (`ClickPipe Data Transfer ($)`, `ClickPipe Compute ($)`, `ClickPipe Initial Load and Resyncs ($)`).

  Для реконсиляции биллинга можно отслеживать метрики объёма данных в реальном времени в интерфейсе ClickPipes (**Метрики** &gt; **байты CDC** и **байты начальной загрузки**) или передавать их в существующий стек мониторинга с помощью [совместимой с Prometheus конечной точки](/integrations/clickpipes/monitoring) ClickHouse Cloud.
</Accordion>

<Accordion title="Не мешают ли CDC ClickPipes сервису ClickHouse Cloud переходить в состояние простоя?">
  Нет, но из-за непрерывного характера CDC сервис, вероятно, будет активироваться с настроенным интервалом синхронизации. CDC ClickPipes активирует сервис с настроенным интервалом синхронизации **только если** есть данные для приёма, в остальном сервис может переходить в состояние простоя как обычно. Если при очередной синхронизации нет данных для приёма, CDC ClickPipes **не** активирует сервис.
</Accordion>

<Accordion title="Будет ли взиматься плата, если я приостановлю CDC ClickPipe?">
  Да. С вас будет взиматься плата за **вычислительные** ресурсы, выделенные и распределяемые между всеми CDC ClickPipes в рамках сервиса. Пока пайп приостановлен, плата за объём данных не взимается, поскольку данные не принимаются.

  <Note>
    Не рекомендуется приостанавливать CDC ClickPipe на длительный срок, поскольку это может привести к невосстановимому состоянию из-за истечения срока хранения журнала репликации и/или негативно повлиять на работоспособность исходного источника данных.
  </Note>
</Accordion>

<Accordion title="Могу ли я масштабировать вычислительные ресурсы, выделенные для CDC ClickPipes в моём сервисе?">
  Вычислительные ресурсы, выделяемые по умолчанию для CDC ClickPipes, оптимизированы для обработки большинства рабочих нагрузок без необходимости масштабирования. Если вы заметите узкое место в использовании ресурсов, можно [масштабировать сервис CDC ClickPipes](https://clickhouse.com/docs/cloud/manage/api/swagger#tag/ClickPipes/operation/clickPipeCdcScalingUpdate). Стоимость вычислительных ресурсов линейно зависит от количества выделенных вычислительных единиц.
</Accordion>
