Связанный биллинг с Claude Platform позволяет клиентам, работающим одновременно с ClickHouse и Anthropic, относить все расходы на использование моделей Claude в продуктах ClickHouse Cloud, таких как [ClickHouse Agents](/ru/agents/index), напрямую на счёт собственной организации Claude.

Связанный биллинг с Claude Platform находится на стадии общедоступной предварительной версии и доступен всем организациям ClickHouse Cloud.

Организацию Claude достаточно один раз связать с организацией ClickHouse Cloud.
После этого Anthropic выставляет счета за использование моделей Claude вашей организацией ClickHouse Cloud на вашу организацию Claude — по её тарифам и в соответствии с её действующими условиями биллинга.
Благодаря этому вы можете использовать свои обязательства по расходам или согласованные тарифы, действующие в рамках договорённостей с Anthropic.

## Как работает биллинг {#how-billing-works}

Пока ваша организация Claude связана:

* Anthropic выставляет счета за использование моделей Claude в вашей организации ClickHouse Cloud вашей организации Claude: оплата списывается с её предоплаченного баланса или включается в её счёт на оплату.
* Действуют тарифы вашей организации Claude и все обязательства по расходам перед Anthropic.
* Запросы к моделям Claude от вашей организации направляются в Anthropic, а не к моделям Claude, размещённым в Amazon Bedrock.

Учитывайте следующее:

* Связанный биллинг распространяется на всё использование моделей Claude во всех продуктах ClickHouse Cloud.
* После включения связанного биллинга с Claude Platform для вашей организации в ClickHouse Cloud будут доступны только модели Claude.
* Промокредиты вашей организации Claude нельзя использовать для связанного биллинга.
* Связывание влияет только на то, как выставляются счета за использование Claude. Условия и договорённости об обработке данных, применимые к использованию Claude в ClickHouse Cloud, остаются прежними.
* При связывании можно задать месячный лимит расходов на использование Claude через ClickHouse Cloud. Когда расходы через ClickHouse Cloud достигают лимита, запросы к моделям Claude из ClickHouse Cloud приостанавливаются до следующего месяца или до тех пор, пока вы не повысите лимит.

Если не связывать организацию Claude, ничего не изменится: модели Claude в ClickHouse Cloud по-прежнему будут обслуживаться через Amazon Bedrock.

## Требования {#requirements}

* **Не включено соответствие требованиям HIPAA или PCI DSS.** Связанный биллинг с Claude Platform недоступен для организаций ClickHouse Cloud, в которых включено соответствие требованиям [HIPAA](/ru/products/cloud/reference/security/compliance-overview#hipaa-since-2024) или [PCI DSS](/ru/products/cloud/reference/security/compliance-overview#pci-service-provider-since-2025).
* **Роль в ClickHouse Cloud с правом связывать биллинг.** У вас должна быть роль Администратора в организации ClickHouse Cloud.
* **Роль в Claude с правом одобрять биллинг.** У вас должна быть роль Owner, Администратор или Billing в организации Claude.
* **Подходящая организация Claude.** Ваша организация Claude должна оплачивать использование API напрямую Anthropic — за счёт предоплаченных кредитов или по выставленным счетам на оплату. Связать нельзя организации Claude, оплачивающие услуги через облачный маркетплейс (AWS, Google Cloud или Azure), а также организации, у которых есть только подписка Claude.

## Мониторинг использования и расходов в Claude Console {#monitor-usage}

Чтобы узнать, во сколько вашей организации Claude обошлось использование Claude через ClickHouse Cloud, откройте страницу [Linked platforms](https://platform.claude.com/linked-platforms) в Claude Console и выберите **ClickHouse**. На этой странице отображаются:

* Организация Claude, на которую выставляются счета, дата её привязки и пользователь, одобривший привязку.
* **Spent this month**: сумма расходов через ClickHouse Cloud за текущий месяц в сравнении с ежемесячным лимитом расходов (если он задан). Лимит сбрасывается в первый день каждого месяца (UTC).
* **Link history**: все случаи привязки и отвязки организации с указанием пользователя, который их выполнил.

<div className="ch-image-sm">
  <Frame>
    ![Страница Linked platforms в Claude Console для ClickHouse со сведениями о подключении и индикатором Spent this month относительно ежемесячного лимита расходов](/images/cloud/linked-billing-claude-platform/07-claude-console-spend.webp)

Здесь же можно задать, повысить или удалить ежемесячный лимит расходов на использование Claude через ClickHouse Cloud, а также отвязать ClickHouse.

Общий **Monthly spend limit** вашей организации Claude, заданный в разделе [Spend limits](https://platform.claude.com/settings/billing#spend-limits) в Claude Console, также распространяется на использование Claude через ClickHouse Cloud.

## Отвязка организации Claude {#unlink}

Отвязать организацию можно с любой из сторон. Результат в каждом случае будет разным.

### Отвязка в ClickHouse Cloud {#unlink-in-clickhouse-cloud}

В разделе **Настройки организации** нажмите **Unlink** в блоке **Claude organization**.
ClickHouse Cloud вернётся к поведению по умолчанию: запросы к моделям Claude в вашей организации будут направляться в модели Claude, размещённые в Amazon Bedrock, а использование Claude больше не будет оплачиваться через вашу организацию Claude.
Вернуться к поведению по умолчанию можно только этим способом.

### Отвязка в Claude Console {#unlink-in-the-claude-console}

На странице [Linked platforms](https://platform.claude.com/linked-platforms) выберите **ClickHouse** и нажмите **Unlink**.
После этого ClickHouse Cloud больше не сможет использовать Claude от имени вашей организации, а Anthropic перестанет выставлять вашей организации Claude счета за новое использование Claude через ClickHouse Cloud.

<Warning>
  Отвязка в Claude Console не возвращает ClickHouse Cloud к поведению по умолчанию.
  Пока вы не выполните повторную привязку или явно не отвяжете организацию в разделе **настройки организации** в ClickHouse Cloud, запросы к моделям Claude из вашей организации ClickHouse Cloud будут завершаться ошибкой.
  Например, ClickHouse Agents отвечает сообщением `The model provider could not complete this request (status 403).`
</Warning>

<div className="ch-image-md">
  <Frame>
    ![Чат ClickHouse Agents с ошибкой The model provider could not complete this request (status 403)](/images/cloud/linked-billing-claude-platform/08-agents-403-error.webp)
  </Frame>
</div>

Затем в разделе **Claude organization** в **настройках организации** ClickHouse Cloud появится сообщение `The link was removed on the Claude side, or your Claude organization cannot be billed directly. Relink to continue.`

<div className="ch-image-md">
  <Frame>
    ![Раздел Claude organization с предупреждением о том, что привязка была удалена на стороне Claude, и кнопками Relink и Unlink](/images/cloud/linked-billing-claude-platform/06-link-removed.webp)
  </Frame>
</div>

Чтобы продолжить, выполните одно из следующих действий:

* Нажмите **Relink** и снова выполните [шаги привязки](#link-your-claude-organization), чтобы счета за использование Claude по-прежнему выставлялись вашей организации Claude.
* Нажмите **Unlink**, чтобы вернуться к поведению по умолчанию, при котором запросы к моделям Claude направляются к моделям Claude, размещённым в Amazon Bedrock.
