В этом документе перечислены модели в ClickHouse Cloud, к которым применяются отдельные условия сторонних разработчиков моделей.
Все используемые модели в настоящее время размещены в AWS Bedrock, а не у соответствующего разработчика модели.
Эти ссылки приведены для вашего удобства. Вы несете ответственность за соблюдение применимых условий для моделей и всех применимых политик использования.
