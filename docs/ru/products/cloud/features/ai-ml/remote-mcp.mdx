Не все пользователи взаимодействуют с ClickHouse через консоль Cloud.
Например, многие разработчики работают напрямую в своих любимых редакторах кода, через CLI-агенты или подключаются к базе данных с помощью собственных настроек, тогда как другие полагаются на универсальных ИИ-помощников, таких как Anthropic Claude, в большей части своей работы.
Этим пользователям и агентным рабочим нагрузкам, действующим от их имени, нужен способ безопасно получать доступ к ClickHouse Cloud и выполнять запросы без сложной настройки или собственной инфраструктуры.

Функция удалённого MCP-сервера в ClickHouse Cloud решает эту задачу, предоставляя стандартный интерфейс, который внешние агенты могут использовать для получения аналитического контекста.
MCP, или Model Context Protocol, — это стандарт структурированного доступа к данным для ИИ-приложений на базе LLM.
Благодаря этой интеграции внешние агенты могут просматривать базы данных и таблицы, изучать схемы и выполнять ограниченные запросы SELECT в режиме только для чтения.
Аутентификация осуществляется через OAuth 2.0 или с помощью [ключа API ClickHouse Cloud](/ru/cloud/manage/openapi). Сервер полностью управляется в ClickHouse Cloud, поэтому не требует настройки или обслуживания.

Это упрощает подключение агентных инструментов к ClickHouse и получение нужных им данных — для анализа, обобщения, генерации кода или исследования.

## Удаленный MCP-сервер и MCP-сервер с открытым исходным кодом {#remote-vs-oss}

ClickHouse предлагает два MCP-сервера.

|                    | Удаленный MCP-сервер (Cloud)                                                                                                                                        | MCP-сервер с открытым исходным кодом                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Источник**       | Полностью управляется ClickHouse Cloud                                                                                                                              | [mcp-clickhouse](https://github.com/ClickHouse/mcp-clickhouse) на GitHub |
| **Транспорт**      | HTTP с поддержкой стриминга (`https://mcp.clickhouse.cloud/mcp`)                                                                                                    | Локальный stdio                                                          |
| **Работает с**     | сервисами ClickHouse Cloud и Managed Postgres                                                                                                                       | Любым экземпляром ClickHouse (самоуправляемым или Cloud)                 |
| **Аутентификация** | OAuth 2.0 с вашими учетными данными ClickHouse Cloud или ключ API ClickHouse Cloud                                                                                  | Переменные окружения                                                     |
| **Инструменты**    | Инструменты для выполнения запросов, изучения схем, управления сервисами, мониторинга резервных копий, просмотра ClickPipes, данных биллинга и мониторинга Postgres | 3 инструмента: `run_select_query`, `list_databases`, `list_tables`       |
| **Настройка**      | Без установки. Укажите конечную точку для MCP-клиента и пройдите аутентификацию.                                                                                    | Установите и запустите сервер локально                                   |

Удаленный MCP-сервер обеспечивает наиболее полную интеграцию с ClickHouse Cloud, включая управление сервисами, мониторинг резервных копий, просмотр ClickPipes и данные биллинга, без необходимости управлять инфраструктурой.
Для самоуправляемых экземпляров ClickHouse см. [руководства по MCP-серверу с открытым исходным кодом](/ru/guides/use-cases/ai-ml/MCP/index).

## Включение удалённого MCP-сервера {#enabling}

Удалённый MCP-сервер нужно включить для каждого сервиса, прежде чем он сможет принимать соединения.
В консоли ClickHouse Cloud откройте свой сервис, нажмите кнопку **Connect**, выберите **MCP** и включите сервер.
Для включения или отключения удалённого MCP-сервера в сервисах ClickHouse требуется разрешение `control-plane:service:manage-mcp` (см. [Роли и разрешения в консоли](/ru/products/cloud/reference/security/console-roles#console-permissions)).
Для сервисов Managed Postgres откройте панель **Connect** нужного сервиса и включите параметр **Enable Model Context Protocol**. Реплики для чтения наследуют настройку MCP родительской базы данных.
Подробные инструкции со скриншотами см. в [руководстве по настройке](/ru/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server).

## Конечная точка {#endpoint}

После включения удаленный MCP-сервер будет доступен по адресу:

```text
https://mcp.clickhouse.cloud/mcp
```

## Аутентификация {#authentication}

Удалённый MCP-сервер поддерживает два метода аутентификации:

* **OAuth 2.0**: рекомендуется для интерактивных клиентов. При первом подключении MCP-клиент открывает окно браузера, в котором пользователь входит в систему с учётными данными ClickHouse Cloud. Доступ ограничен теми организациями и сервисами, к которым у аутентифицированного пользователя есть разрешение на доступ.
* **Ключ API ClickHouse Cloud**: предназначен для удалённых, headless- и автоматизированных сред, где OAuth-поток через браузер неприменим. Передайте ID ключа API и его секрет с помощью HTTP Basic-аутентификации:

  ```text
  Authorization: Basic base64(<key_id>:<key_secret>)
  ```

Доступ по ключу API определяется ролями, разрешениями и сроком действия, заданными для этого ключа. Используйте отдельный ключ с минимально необходимыми привилегиями и передавайте его через систему управления секретами. Кодирование Base64 не шифрует учётные данные, поэтому не коммитьте закодированное значение в систему контроля версий и не допускайте его попадания в журналы.

Пример настройки MCP-клиента в headless-среде см. в разделе [Аутентификация из headless-среды](/ru/products/cloud/features/ai-ml/mcp/remote-mcp#headless-mcp-client-authentication).

## Безопасность {#safety}

Все инструменты, предоставляемые удалённым MCP-сервером, доступны **только для чтения**. В метаданных MCP каждого инструмента указано `readOnlyHint: true`. Ни один инструмент не может изменять данные, менять конфигурацию сервиса или выполнять какие-либо разрушительные операции.

## Доступные инструменты {#available-tools}

Удалённый MCP-сервер предоставляет инструменты, сгруппированные по следующим категориям. Доступность инструментов зависит от метода аутентификации и включённых возможностей.

### Изучение запросов и схемы {#query-and-schema}

Эти инструменты позволяют агентам определять, какие данные доступны, и выполнять аналитические запросы.

| Tool               | Description                                                              | Parameters                                                                                                |
| ------------------ | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| `run_select_query` | Выполнить SELECT-запрос в режиме только для чтения к сервису ClickHouse. | `query`, корректный SELECT-запрос ClickHouse SQL; `serviceId`                                             |
| `list_databases`   | Вывести список всех баз данных, доступных в сервисе ClickHouse.          | `serviceId`                                                                                               |
| `list_tables`      | Вывести список всех таблиц в базе данных, включая определения столбцов.  | `serviceId`; `database`; необязательно `like` или `notLike` (шаблоны SQL LIKE для фильтрации имён таблиц) |

### Managed Postgres {#managed-postgres}

Эти инструменты позволяют выполнять запросы к сервисам Managed Postgres и отслеживать их работу. С помощью `get_organizations` найдите `organizationId`, затем с помощью `get_services_list` найдите сервис, у которого `serviceType` равен `postgres`, и используйте его `id` в качестве `serviceId`.

| Инструмент                                | Описание                                                                                                                                                                                            | Параметры                                                                                                                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run_postgres_select_query`               | Выполняет SQL-запрос только для чтения к сервису Postgres. Требует аутентификации OAuth; недоступен при использовании ключей API ClickHouse Cloud.                                                  | `organizationId`; `serviceId`; `query`; необязательно `database` (по умолчанию: `postgres`) и `timeoutSeconds` (1–3600, по умолчанию: 300)                                       |
| `list_postgres_slow_query_patterns`       | Возвращает список шаблонов медленных запросов с агрегированными метриками задержки, числа вызовов, строк, CPU, I/O, WAL и ошибок. Длительность указывается в микросекундах.                         | `organizationId`; `serviceId`; `fromDate`; `toDate`; необязательно `limit` (1–500, по умолчанию: 20), `offset`, `sortBy`, `sortOrder`, `dbName`, `dbUser`, `dbOperation` и `app` |
| `get_postgres_slow_query_pattern_details` | Возвращает до 10 последних выполнений шаблона запроса за последние 24 часа, а также агрегированные метрики, если они доступны.                                                                      | `organizationId`; `serviceId`; `queryId`; `dbName`; `dbUser`; `dbOperation`; необязательно `app`                                                                                 |
| `get_postgres_metrics`                    | Возвращает метрики time-series по CPU, памяти, диску, сети, соединениям, коэффициенту попаданий в кэш, транзакциям и ожиданиям. Для каждой метрики указываются единица измерения и серии с метками. | `organizationId`; `serviceId`; `fromDate`; `toDate`; необязательно `bucketSizeSeconds` (положительное целое число; если не указан, выбирается автоматически)                     |

Для `fromDate` и `toDate` используйте временные метки UTC с миллисекундной точностью, например `2026-11-03T00:00:00.000Z`. Начало интервала включается. Конец интервала для шаблонов медленных запросов включается с гранулярностью до минуты, а для метрик — исключается.

Чтобы изучить шаблон медленного запроса, передайте его `queryId`, `dbName`, `dbUser`, `dbOperation` и `app` из `list_postgres_slow_query_patterns` в `get_postgres_slow_query_pattern_details`. Для запросов без `application_name` передавайте пустую строку в `app`; если `app` не указан, учитываются все приложения.

### Организации {#organizations}

| Инструмент                 | Описание                                                                                  | Параметры        |
| -------------------------- | ----------------------------------------------------------------------------------------- | ---------------- |
| `get_organizations`        | Возвращает все организации ClickHouse Cloud, доступные аутентифицированному пользователю. | Нет              |
| `get_organization_details` | Возвращает сведения об одной организации.                                                 | `organizationId` |

### Сервисы {#services}

| Инструмент                  | Описание                                                                                                                 | Параметры                    |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| `get_services_list`   | Выводит список сервисов ClickHouse и Managed Postgres в организации с полем `serviceType`, указывающим тип каждого сервиса. | `organizationId`              |
| `get_service_details` | Возвращает сведения о сервисе ClickHouse или Managed Postgres, автоматически определяя его тип.                             | `organizationId`; `serviceId` |

### Резервные копии {#backups}

| Tool                               | Description                                                                                   | Parameters                                |
| ---------------------------------- | --------------------------------------------------------------------------------------------- | ----------------------------------------- |
| `list_service_backups`             | Возвращает список всех резервных копий сервиса, начиная с самых новых.                        | `organizationId`; `serviceId`             |
| `get_service_backup_details`       | Возвращает сведения об одной резервной копии.                                                 | `organizationId`; `serviceId`; `backupId` |
| `get_service_backup_configuration` | Возвращает конфигурацию резервного копирования для сервиса (расписание и параметры хранения). | `organizationId`; `serviceId`             |

### ClickPipes {#clickpipes}

| Инструмент        | Описание                                                 | Параметры                                    |
| ----------------- | -------------------------------------------------------- | -------------------------------------------- |
| `list_clickpipes` | Вывести список всех ClickPipes, настроенных для сервиса. | `organizationId`; `serviceId`                |
| `get_clickpipe`   | Вернуть сведения о конкретном ClickPipe.                 | `organizationId`; `serviceId`; `clickPipeId` |

### Биллинг {#billing}

| Инструмент              | Описание                                                                                                                                          | Параметры                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `get_organization_cost` | Получить данные о биллинге и расходах на использование для организации. Возвращает общую сумму и ежедневные записи о расходах по каждой сущности. | `organizationId`; необязательно `from_date` и `to_date` (YYYY-MM-DD, не более 31 дня) |
