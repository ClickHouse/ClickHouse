Возможности в общедоступной предварительной версии — это практически завершённые функции ClickHouse Cloud, которые уверенно движутся к общедоступности (GA). Они открыты для того, чтобы клиенты могли оставить отзывы, но ещё не перешли в стадию бета.

<Warning>
  Возможности в общедоступной предварительной версии могут меняться, и на них не распространяется стандартное SLA ClickHouse Cloud.
</Warning>

## Включение общедоступной предварительной версии {#enable-public-preview}

1. Войдите в консоль Cloud и выберите нужную организацию.
2. Откройте меню организации и выберите **Preview features**. Этот раздел также доступен на боковой панели организации.
3. Найдите нужную возможность, нажмите **Learn more**, чтобы ознакомиться с её требованиями и ограничениями, а затем включите её переключатель. Если переключатель неактивен, попросите администратора организации включить эту возможность.
4. Если есть ссылка на сервис **Go to...** или **View in...**, воспользуйтесь ею, чтобы начать работу с возможностью.

<Note>
  Доступность зависит от прав доступа вашей организации и хода поэтапного развёртывания возможности. Не все общедоступные предварительные версии доступны всем организациям. Чтобы проверить доступ, обратитесь в [Службу поддержки Cloud](https://clickhouse.com/support/program).
</Note>
