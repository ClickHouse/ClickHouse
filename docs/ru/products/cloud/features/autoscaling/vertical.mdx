Сервисы уровней Scale и Enterprise со стандартными профилями `1:4` поддерживают автомасштабирование на основе загрузки CPU и использования памяти. Показатели использования сервиса непрерывно отслеживаются в рамках окна ретроспективного анализа, на основе которого принимаются решения о масштабировании. Если эти показатели поднимаются выше или опускаются ниже определённых пороговых значений, сервис масштабируется соответствующим образом, чтобы соответствовать нагрузке.

<div id="configuring-vertical-auto-scaling">
  ## Настройка вертикального автоматического масштабирования
</div>

Участники организации с ролью **Admin** могут настраивать вертикальное автоматическое масштабирование для сервисов Scale и сервисов Enterprise со стандартными профилями `1:4`. Перейдите на вкладку **Настройки** вашего сервиса и задайте минимальный и максимальный объём памяти, а также параметры CPU, как показано ниже. Для сервисов Enterprise с пользовательскими профилями изменение размера по вертикали выполняется при содействии службы поддержки.

<Note>
  Сервисы Scale с одной репликой и сервисы Enterprise со стандартными профилями `1:4` поддерживают вертикальное автоматическое масштабирование. Для сервисов Enterprise с пользовательскими профилями изменение размера по вертикали выполняется при содействии службы поддержки. Сервисы уровня Basic имеют фиксированный размер и не могут масштабироваться.
</Note>

<Image img="/images/cloud/manage/AutoScaling.webp" size="lg" alt="Страница настроек масштабирования" border />

Задайте для реплик значение **Максимальный объём памяти** больше, чем **Минимальный объём памяти**. После этого сервис будет масштабироваться по мере необходимости в пределах этих значений. Эти настройки также доступны при первоначальном создании сервиса. Каждой реплике в вашем сервисе будет выделен одинаковый объём памяти и одинаковые ресурсы CPU.

Вы также можете задать одинаковые значения, фактически «закрепив» сервис за определённой конфигурацией. В этом случае сервис будет немедленно принудительно масштабирован до выбранного размера.

Важно учитывать, что это отключит любое автоматическое масштабирование кластера, и ваш сервис не будет защищён от роста использования CPU или памяти сверх заданных значений.

<Note>
  Для сервисов уровня Enterprise вертикальное автоматическое масштабирование поддерживается стандартными профилями `1:4`. Пользовательские профили не поддерживают ни вертикальное автоматическое масштабирование, ни ручное вертикальное масштабирование. Чтобы изменить размер по вертикали, обратитесь в службу поддержки.
</Note>
