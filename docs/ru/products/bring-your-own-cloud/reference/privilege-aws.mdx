На этой странице описаны разрешения, область действия и назначение каждой политики и роли IAM, которые ClickHouse BYOC использует в вашей учетной записи AWS. Общий обзор модели разрешений BYOC см. в разделе [Привилегии BYOC](/ru/products/bring-your-own-cloud/reference/privilege).

## Роль IAM для начальной настройки {#bootstrap-iam-role}

В таблице ниже описаны все политики роли IAM для начальной настройки `ClickHouseManagementRole`.

| Политика                                                                 | Разрешения                                                                                                                                                                                                                                                     | Область действия                                                                                                                                                                                                                                                                                                                                                                        | Назначение                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BasePolicy` (встроенная)                                                | Получение данных об идентичности вызывающего кода. Чтение квот сервиса и квот сервиса, установленных AWS по умолчанию.                                                                                                                                         | Все ресурсы. Только для чтения.                                                                                                                                                                                                                                                                                                                                                         | Проверки работоспособности и квот перед подготовкой ресурсов                                                                                                                                                                  |
| `ClickHouse-IAM-Base-Policy`                                             | Чтение ролей IAM, политик и профилей экземпляров. Передача ролей службам AWS. Создание ролей, связанных со службами. Создание провайдера OpenID Connect (OIDC) для кластера, добавление к нему тегов и его удаление.                                           | Чтение: все роли и политики IAM. Передача ролей: только роли BYOC с указанными именами (например, `*-k8s-worker`, `*-karpenter-node`, `*-CH-S3-Role`) и только в EKS, EKS Pod Identity и EC2. Сервисные роли (service-linked roles): только для EKS, групп узлов EKS и VPC Lattice. Провайдер OIDC: метка `clickhouse-byoc=true`, которую роль может добавить к любому провайдеру OIDC. | Чтение состояния IAM. Передача ролей BYOC сервисам EKS и EC2.                                                                                                                                                                 |
| `ClickHouse-IAM-Extended-Policy` (необязательная, по умолчанию включена) | Создание, изменение и удаление ролей IAM, политик и профилей экземпляров                                                                                                                                                                                       | Тег `clickhouse-byoc=true`, который роль может добавить к любой роли, политике или профилю экземпляра. Без ограничений: удаление роли из профиля экземпляра.                                                                                                                                                                                                                            | Создание дополнительных ролей (подробнее см. в следующем разделе). Эта политика не нужна, если вы [используете собственные роли IAM](/ru/products/bring-your-own-cloud/onboarding/customization-aws#customer-managed-iam-roles). |
| `ClickHouse-S3-Policy`                                                   | Создание бакетов. Чтение и изменение конфигурации бакета: метки, жизненный цикл, шифрование, права владения, блокировка публичного доступа и метрики. Просмотр списка объектов в бакете. Чтение и запись объектов не разрешены. Удаление бакетов не разрешено. | Только бакеты с именами `*.*.aws.clickhouse.cloud-shared`, `*.*.aws.clickhouse.cloud-backup` и `*.*.aws.clickhouse.cloud-monitoring`                                                                                                                                                                                                                                                    | Управление бакетами, в которых хранятся данные таблиц ClickHouse, резервные копии и данные мониторинга                                                                                                                        |
| `ClickHouse-EKS-Policy`                                                  | Создание, изменение и удаление кластеров EKS, дополнений, групп узлов и привязок Pod Identity. Чтение всех ресурсов EKS.                                                                                                                                       | Запись: только ресурсы, имена которых начинаются с `clickhouse-cloud-`. Чтение: все ресурсы EKS.                                                                                                                                                                                                                                                                                        | Управление кластером EKS, его дополнениями и группами узлов                                                                                                                                                                   |
| `ClickHouse-EC2-Policy`                                                  | Чтение данных EC2, Elastic Load Balancing и Auto Scaling. Запуск инстансов. Управление шаблонами запуска, сетевыми интерфейсами, группами безопасности, адресами Elastic IP и метками. Изменение атрибутов инстансов, сетевых интерфейсов и томов.             | Группы безопасности: метка `clickhouse-byoc=true` или `aws:eks:cluster-name` = `clickhouse-cloud-*`. Elastic IP и изменение меток: метка `clickhouse-byoc=true`, которую роль может добавить к любому ресурсу. Без ограничения области действия: инстансы, шаблоны запуска, сетевые интерфейсы и тома.                                                                                  | Управление узлами и группами безопасности, контролирующими сетевой доступ к кластеру                                                                                                                                          |

Эта политика не нужна, если вы [используете собственный VPC](/ru/products/bring-your-own-cloud/onboarding/customization-aws#customer-managed-vpc-aws).                                                                 |
| `ClickHouse-VPCPrivateLink-Policy`                                       | Создание, изменение и удаление сервисов конечных точек VPC                                                                                                                                                                                                     | Только ресурсы с тегом `clickhouse-byoc=true`                                                                                                                                                                                                                                                                                                                                           | Конечные точки AWS PrivateLink для ваших сервисов                                                                                                                                                                             |
| `ClickHouse-VPCLattice-Policy`                                           | Создание, изменение и удаление шлюзов ресурсов и конфигураций ресурсов VPC Lattice, а также наборов ресурсов для совместного доступа в AWS RAM. Чтение ресурсов VPC Lattice и AWS RAM.                                                                         | Запись: только ресурсы с меткой `clickhouse-byoc=true`. Чтение: все ресурсы VPC Lattice и AWS RAM.                                                                                                                                                                                                                                                                                      | Частный доступ к API EKS                                                                                                                                                                                                      |
| `ClickHouse-CloudWatch-Policy`                                           | Чтение CloudWatch Logs. Создание групп логов. Назначение меток группам логов и настройка срока хранения журналов в них.                                                                                                                                        | Создание: только с меткой `clickhouse-byoc=true`. Назначение меток и срока хранения: только для групп журналов `/aws/eks/clickhouse-cloud-*`. Чтение: все группы журналов.                                                                                                                                                                                                              | Журналы плоскости управления EKS                                                                                                                                                                                              |
| `ClickHouse-KMS-Policy` (необязательная, по умолчанию отключена)         | Чтение сведений о ключах. Создание разрешений на использование ключей.                                                                                                                                                                                         | Только ключи KMS в учетной записи AWS для ClickHouse BYOC                                                                                                                                                                                                                                                                                                                               | Шифрование Secret в EKS                                                                                                                                                                                                       |
| `ClickHouse-KMSTDE-Policy` (необязательная, по умолчанию отключена)      | Создание ключей KMS. Просмотр ключей и политик ключей. Включение ротации ключей. Добавление тегов к ключам. Шифрование, расшифрование, изменение политики ключа и удаление ключей не разрешены.                                                                | Метка `clickhouse-byoc=true`, которую роль может добавить к любому ключу, если это разрешено его политикой ключа                                                                                                                                                                                                                                                                        | Ключи для прозрачного шифрования данных (TDE)                                                                                                                                                                                 |

Точные тексты политик см. в [модуле Terraform](https://github.com/ClickHouse/terraform-byoc-onboarding/blob/main/modules/aws/main.tf) или в [шаблоне CloudFormation](https://s3.us-east-2.amazonaws.com/clickhouse-public-resources.clickhouse.cloud/cf-templates/byoc_v2.yaml).

## Дополнительные роли IAM, создаваемые контроллером {#additional-iam-roles-created-by-the-controller}

Помимо роли `ClickHouseManagementRole`, создаваемой через CloudFormation или Terraform, контроллер создает несколько дополнительных ролей для каждой BYOC infrastructure.
Каждая роль имеет префикс `<infra>-<region>-`, где `<infra>` — имя вашей BYOC infrastructure, а `<region>` — регион AWS.

| Роль                                       | Разрешения                                                                                                                                                                                                                                                         | Назначение                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `data-plane-mgmt`                          | Чтение EKS. Получение списка и удаление объектов, а также настройка шифрования, версионирования и жизненного цикла в бакетах BYOC. Чтение load balancer и групп Auto Scaling. Эту роль принимает сервис управления ClickHouse с использованием вашего внешнего ID. | Повседневное управление вашими сервисами ClickHouse и кластером                         |
| `k8s-control-plane`                        | Управляемые AWS политики `AmazonEKSClusterPolicy`, `AmazonEKSServicePolicy`, `AmazonEKSVPCResourceController`. Принять эту роль может только EKS.                                                                                                                  | Роль кластера EKS                                                                       |
| `k8s-worker`                               | Управляемые AWS политики `AmazonEKSWorkerNodePolicy`, `AmazonEKS_CNI_Policy`, `AmazonEC2ContainerRegistryReadOnly`. Принятие роли только для чтения для загрузки образов контейнеров ClickHouse. Принять эту роль может только EC2.                                | Роль системных узлов                                                                    |
| `karpenter-node` (роль и профиль инстанса) | То же, что и `k8s-worker`, плюс `AmazonSSMManagedInstanceCore`. Принять эту роль может только EC2.                                                                                                                                                                 | Роль узлов сервера ClickHouse и Keeper                                                  |
| `karpenter-controller`                     | Запуск и завершение инстансов EC2 с метками этого кластера. Чтение EC2 в регионе BYOC. Передача только роли `karpenter-node`. Чтение цен и параметров AMI для EKS.                                                                                                 | Karpenter: добавляет и удаляет узлы для ClickHouse                                      |
| `cluster-autoscaler`                       | Чтение групп Auto Scaling. Установка желаемой емкости и завершение инстансов в группах Auto Scaling.                                                                                                                                                               | Масштабирует системные группы узлов                                                     |
| `load-balancer-controller`                 | Политика AWS Load Balancer Controller, публикуемая AWS. Для изменения load balancer и целевых групп требуется метка `elbv2.k8s.aws/cluster` любого кластера. Без ограничения области: слушатели, правила, регистрация целей и метки.                               | Создает сетевые load balancer для конечных точек ваших сервисов                         |
| `ebs-csi-driver`                           | Политика драйвера EBS CSI, публикуемая AWS. Для удаления томов и снимков требуются метки драйвера.                                                                                                                                                                 | Диски для ClickHouse и Keeper                                                           |
| `CH-S3-Role`                               | Все действия S3, но только в пределах префиксов ClickHouse в общем бакете и бакете резервных копий BYOC. Принятие ролей, настроенных вами для доступа ClickHouse к S3. Принятие роли для отправки данных об использовании в ClickHouse.                            | Идентичность подов сервера ClickHouse. Чтение и запись данных таблиц и резервных копий. |
| `thanos`                                   | Получение списка, чтение, запись и удаление объектов в бакете мониторинга BYOC                                                                                                                                                                                     | Хранит метрики для мониторинга                                                          |
| `state-exporter`                           | Принятие роли ClickHouse. Других разрешений нет.                                                                                                                                                                                                                   | Отправляет в ClickHouse данные о состоянии инфраструктуры                               |
| `clickhouse-scraper`                       | Принятие роли ClickHouse. Других разрешений нет.                                                                                                                                                                                                                   | Отправляет в ClickHouse данные об использовании для биллинга                            |
| `kube-metric-forwarder-asc`                | Принятие роли ClickHouse. Других разрешений нет.                                                                                                                                                                                                                   | Отправляет метрики Kubernetes в ClickHouse для автоматического масштабирования          |

Точные документы политик см. в [модуле Terraform](https://github.com/ClickHouse/terraform-byoc-onboarding/blob/main/modules/aws-per-infra-iam/main.tf).
