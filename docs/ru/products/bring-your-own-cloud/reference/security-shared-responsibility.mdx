BYOC развертывает сервисы ClickHouse в вашем облачном аккаунте, распределяя обязанности по обеспечению безопасности между тремя сторонами: ClickHouse, вами и вашим облачным провайдером.
В таблице ниже указано распределение ответственности по восьми направлениям безопасности.

Дополнительные сведения о конкретных возможностях и настройках для выполнения ваших требований к безопасности см. на [trust.clickhouse.com](https://trust.clickhouse.com).
