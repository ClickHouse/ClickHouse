Вы можете изменять параметры конфигурации и управлять настройками инстанса ClickHouse Managed Postgres на вкладке **Настройки** в боковой панели.

## Действия сервиса и масштабирование {#service-actions}

<div className="ch-image-md">
  <Frame>
    ![Действия сервиса и масштабирование](/images/managed-postgres/service-actions.webp)
  </Frame>
</div>

Панель инструментов **Действия сервиса** содержит элементы управления для вашего инстанса ClickHouse Managed Postgres:

* **Сбросить пароль**: обновить пароль суперпользователя (только когда инстанс находится в состоянии `Running`)
* **Перезапустить**: перезапустить инстанс базы данных (только когда инстанс находится в состоянии `Running`)
* **Запустить**: повторно активировать [деактивированный](/ru/products/managed-postgres/pricing#service-deactivation) инстанс. Кнопка отображается только для деактивированного инстанса и остается неактивной, пока ваша организация не оплатит счет
* **Удалить**: удалить инстанс

Раздел **Масштабирование** позволяет менять типы инстансов основного и резервных узлов, увеличивая или уменьшая вычислительные ресурсы и объем хранилища.
Подробнее см. на [странице масштабирования](/ru/products/managed-postgres/scaling).

## Изменение параметров конфигурации {#changing-configuration}

<div className="ch-image-md">
  <Frame>
    ![Настройка параметров Postgres](/images/managed-postgres/postgres-parameters.webp)
  </Frame>
</div>

Чтобы изменить параметр, нажмите кнопку **Edit parameters**. Выберите параметры, которые нужно изменить, и задайте для них нужные значения. Когда изменения вас устроят, нажмите кнопку **Save Changes**.

Все изменения параметров конфигурации обычно сохраняются для инстанса в течение одной минуты. Для применения некоторых параметров требуется перезапуск базы данных. Эти изменения вступят в силу после следующего перезапуска, который можно вручную запустить на панели **действий сервиса**.

См. официальную [документацию](https://www.postgresql.org/docs/current/runtime-config.html) по параметрам конфигурации. Список доступных для настройки параметров скоро будет расширен. Пока что свяжитесь со [службой поддержки](https://clickhouse.com/support/program), чтобы запросить параметр, который сейчас не поддерживается.

## Запланированные обновления {#scheduled-upgrades}

В разделе **Configuration** также можно указать, когда к вашему инстансу применяется обслуживание платформы — минорные обновления версии PostgreSQL, обновления возможностей управляемого сервиса и патчи операционной системы. Нажмите **Configure schedule** в подразделе **Запланированные обновления**, чтобы выбрать двухчасовое окно по UTC и, при необходимости, дни недели, в которые допускается применение обновлений.

О доступных окнах, а также о том, что охватывает расписание и чего оно не охватывает, см. в разделе [запланированные обновления](/ru/products/managed-postgres/upgrades#scheduled-upgrades).
