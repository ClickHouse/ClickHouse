## Запустите или скачайте DbVisualizer {#start-or-download-dbvisualizer}

DbVisualizer доступен по адресу https://www.dbvis.com/download/

<Steps>
  <Step title="Соберите сведения о подключении" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Встроенное управление JDBC-драйверами" id="2-built-in-jdbc-driver-management">
    DbVisualizer включает самые актуальные JDBC-драйверы для ClickHouse. В него встроено полноценное управление JDBC-драйверами, которое обеспечивает доступ как к последним выпускам, так и к предыдущим версиям драйверов.

    <div className="ch-image-lg">

      </Frame>
    </div>
  </Step>

  <Step title="Подключение к ClickHouse" id="3-connect-to-clickhouse">
    Чтобы подключить базу данных в DbVisualizer, сначала нужно создать и настроить соединение с базой данных.

    1. Создайте новое соединение через **Database-&gt;Create Database Connection** и выберите драйвер для вашей базы данных во всплывающем меню.

    2. Откроется вкладка **Object View** для нового соединения.

    3. Введите имя соединения в поле **Name** и, при необходимости, описание соединения в поле **Notes**.

    4. Оставьте значение **Database Type** как **Auto Detect**.

    5. Если выбранный драйвер в **Driver Type** отмечен зелёной галочкой, он готов к использованию. Если зелёной галочки нет, возможно, вам потребуется настроить драйвер в **Диспетчере драйверов**.

    6. В оставшихся полях укажите сведения о Сервере базы данных.

    7. Нажмите кнопку **Ping Server**, чтобы проверить, можно ли установить сетевое соединение с указанным адресом и портом.

    8. Если результат Ping Server показывает, что Сервер доступен, нажмите **Connect**, чтобы подключиться к Серверу базы данных.

    <Tip>
      Если у вас возникают проблемы с соединением с базой данных, ознакомьтесь с [Fixing Connection Issues](https://www.dbvis.com/docs/ug/troubleshooting/fixing-connection-issues/) — там приведены полезные советы.
    </Tip>
  </Step>
</Steps>
