Confluent предоставляет три варианта интеграции с ClickHouse:

* [ClickHouse Connect Sink в Confluent Cloud](/ru/integrations/connectors/data-ingestion/kafka/confluent/confluent-cloud) — полностью управляемый коннектор
* [ClickHouse Connect Sink как Custom Connector в Confluent Cloud](/ru/integrations/connectors/data-ingestion/kafka/confluent/custom-connector) — в этом случае вы загружаете коннектор самостоятельно
* [коннектор HTTP Sink для Confluent Platform](/ru/integrations/connectors/data-ingestion/kafka/confluent/kafka-connect-http), который интегрирует Apache Kafka с API по HTTP или HTTPS

## Какой вариант Confluent Cloud выбрать? {#which-confluent-cloud-option-should-i-use}

В обоих первых вариантах в Confluent Cloud работает один и тот же ClickHouse Connect Sink. Разница лишь в том, кто управляет коннектором:

* **Полностью управляемый коннектор**: Confluent сам устанавливает и обновляет коннектор. Начните с этого варианта, если только вам не нужны возможности, которых в нём нет.
* **Custom Connector**: вы самостоятельно скачиваете релиз коннектора с [GitHub](https://github.com/ClickHouse/clickhouse-kafka-connect/releases) и загружаете его в Confluent Cloud. Выбирайте этот вариант, если вам нужна определённая версия коннектора или нужно переопределить настройки, которые в полностью управляемом коннекторе можно изменить только через обращение в службу поддержки Confluent. Custom Connectors доступны не во всех регионах AWS.
