<Note>
  Обратите внимание, что коннекторы Airbyte Source и Destination для ClickHouse сейчас находятся в альфа-статусе и не подходят для переноса больших наборов данных (&gt; 10 млн строк)
</Note>

<a href="https://www.airbyte.com/" target="_blank">Airbyte</a> — это платформа интеграции данных с открытым исходным кодом. Она позволяет создавать <a href="https://airbyte.com/blog/why-the-future-of-etl-is-not-elt-but-el" target="_blank">ELT</a>-конвейеры данных и включает более 140 готовых коннекторов. В этом пошаговом руководстве показано, как подключить Airbyte к ClickHouse в качестве пункта назначения и загрузить тестовый набор данных.

<Steps>
  <Step title="Скачайте и запустите Airbyte" id="1-download-and-run-airbyte">
    1. Airbyte работает в Docker и использует `docker-compose`. Обязательно скачайте и установите последние версии Docker.

    2. Разверните Airbyte: клонируйте официальный репозиторий Github и выполните `docker-compose up` в своём терминале:

       ```bash
       git clone https://github.com/airbytehq/airbyte.git --depth=1
       cd airbyte
       ./run-ab-platform.sh
       ```

    3. Когда в терминале появится баннер Airbyte, можно подключиться к <a href="http://localhost:8000" target="_blank">localhost:8000</a>

       <div className="ch-image-lg">
         <Frame>
           ![Баннер Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_01.webp)
         </Frame>
       </div>

    <Note>
      Также можно зарегистрироваться и использовать <a href="https://docs.airbyte.com/" target="_blank">Airbyte Cloud</a>
    </Note>
  </Step>

  <Step title="Добавьте ClickHouse в качестве пункта назначения" id="2-add-clickhouse-as-a-destination">
    В этом разделе показано, как добавить экземпляр ClickHouse в качестве пункта назначения.

    1. Запустите сервер ClickHouse (Airbyte совместим с ClickHouse версии `21.8.10.19` и выше) или войдите в свою учётную запись ClickHouse Cloud:

       ```bash
       clickhouse-server start
       ```

    2. В Airbyte откройте страницу «Destinations» и добавьте новый пункт назначения:

       <div className="ch-image-lg">
         <Frame>
           ![Добавление пункта назначения в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_02.webp)
         </Frame>
       </div>

    3. Выберите ClickHouse в раскрывающемся списке «Destination type» и заполните форму «Set up the destination», указав имя хоста и порты ClickHouse, имя базы данных, имя пользователя и пароль, а также укажите, используется ли SSL-соединение (эквивалент флага `--secure` в `clickhouse-client`):

       <div className="ch-image-lg">
         <Frame>
           ![Создание пункта назначения ClickHouse в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_03.webp)
         </Frame>
       </div>

    4. Поздравляем! Вы добавили ClickHouse в качестве пункта назначения в Airbyte.

    <Note>
      Чтобы использовать ClickHouse в качестве пункта назначения, пользователь, от имени которого выполняется подключение, должен иметь разрешения на создание баз данных и таблиц, а также на вставку строк. Рекомендуем создать для Airbyte отдельного пользователя (например, `my_airbyte_user`) со следующими разрешениями:

      ```sql
      CREATE USER 'my_airbyte_user'@'%' IDENTIFIED BY 'your_password_here';

      GRANT CREATE ON * TO my_airbyte_user;
      ```
    </Note>
  </Step>

  <Step title="Добавление набора данных в качестве источника" id="3-add-a-dataset-as-a-source">
    В качестве демонстрационного набора данных мы будем использовать <a href="/ru/get-started/sample-datasets/nyc-taxi" target="_blank">New York City Taxi Data</a> (на <a href="https://github.com/toddwschneider/nyc-taxi-data" target="_blank">Github</a>). В этом пошаговом руководстве мы возьмём подмножество этого набора данных за январь 2022 года.

    1. В Airbyte откройте страницу «Sources» и добавьте новый источник типа file.

       <div className="ch-image-lg">
         <Frame>
           ![Добавление источника в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_04.webp)
         </Frame>
       </div>

    2. Заполните форму «Set up the source»: задайте имя источника и укажите URL файла NYC Taxi за январь 2022 года (см. ниже). Обязательно выберите `parquet` в качестве формата файла, `HTTPS Public Web` в качестве Storage Provider и `nyc_taxi_2022` в качестве Dataset Name.

       ```text
       https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2022-01.parquet
       ```

       <div className="ch-image-lg">
         <Frame>
           ![Создание источника ClickHouse в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_05.webp)
         </Frame>
       </div>

    3. Поздравляем! Вы добавили файловый источник в Airbyte.
  </Step>

  <Step title="Установите соединение и загрузите набор данных в ClickHouse" id="4-create-a-connection-and-load-the-dataset-into-clickhouse">
    1. В Airbyte откройте страницу &quot;Connections&quot; и добавьте новое соединение

    <div className="ch-image-lg">
      <Frame>
        ![Добавление соединения в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_06.webp)
      </Frame>
    </div>

    2. Выберите &quot;Use existing source&quot; и укажите New York City Taxi Data, затем выберите &quot;Use existing destination&quot; и укажите свой экземпляр ClickHouse.

    3. Заполните форму &quot;Set up the connection&quot;: задайте периодичность репликации (Replication Frequency; в этом руководстве используется `manual`) и выберите `nyc_taxi_2022` в качестве потока для синхронизации. Убедитесь, что в поле Normalization выбрано значение `Normalized Tabular Data`.

    <div className="ch-image-lg">
      <Frame>
        ![Создание соединения в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_07.webp)
      </Frame>
    </div>

    4. Теперь, когда соединение создано, нажмите &quot;Sync now&quot;, чтобы запустить загрузку данных (поскольку для параметра Replication Frequency мы выбрали значение `Manual`)

    <div className="ch-image-lg">
      <Frame>
        ![Кнопка «Sync now» в Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_08.webp)
      </Frame>
    </div>

    5. Начнётся загрузка данных. Разверните панель, чтобы просмотреть журналы Airbyte и ход выполнения. После завершения операции в журналах появится сообщение `Completed successfully`:

    <div className="ch-image-lg">
      <Frame>
        ![Успешно завершено](/images/integrations/data-ingestion/etl-tools/airbyte_09.webp)
      </Frame>
    </div>

    6. Подключитесь к своему экземпляру ClickHouse с помощью любого удобного SQL-клиента и проверьте получившуюся таблицу:

       ```sql
       SELECT *
       FROM nyc_taxi_2022
       LIMIT 10
       ```
