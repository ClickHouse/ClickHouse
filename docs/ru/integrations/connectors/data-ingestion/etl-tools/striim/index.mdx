[Striim for ClickHouse](https://www.striim.com/docs/striimforclickhouse/en/introducing-striim-for-clickhouse.html) — полностью управляемый SaaS-сервис, который переносит в ClickHouse данные из баз данных, хранилищ данных, озёр данных и SaaS-приложений, в том числе из корпоративных источников, таких как Oracle, Microsoft SQL Server и Snowflake. Сначала загрузите существующие записи, а затем с помощью CDC (фиксации изменений данных) передавайте вставки, обновления и удаления в потоковом режиме, чтобы данные в ClickHouse оставались актуальными для AI-нагрузок, панелей мониторинга и приложений для работы с данными.

Striim for ClickHouse размещается в Striim Cloud на AWS. Сервис поддерживает регистрацию в режиме самообслуживания и ежемесячный биллинг по фактическому использованию без годовых обязательств. Зарегистрируйтесь на striim.com или через AWS Marketplace, активируйте 14-дневный бесплатный пробный период и создайте конвейер с помощью промпта на естественном языке, мастера настройки или конструктора потоков.

## Основные возможности {#key-features}

* **CDC (фиксация изменений данных) и первоначальная загрузка:** сначала загружаются существующие данные, после чего начинается непрерывная репликация вставок, обновлений и удалений в реальном времени. Автоматизированные мастера создания конвейеров помогают создать и связать обе фазы, а переход от первоначальной загрузки к CDC-репликации выполняется автоматически.
* **Компонент записи в ClickHouse:** движок таблицы выбирается для каждого конвейера (`MergeTree`, `ReplacingMergeTree`, `CollapsingMergeTree`, `CoalescingMergeTree` и другие). Striim создаёт целевые таблицы, обрабатывает обновления и удаления в соответствии с выбранным движком и задаёт ключи сортировки.
* **Работа со схемами:** автоматическое создание целевой схемы на основе исходной для поддерживаемых источников, а также распространение выбранных DDL-изменений (`CREATE TABLE`, `ADD COLUMN`, `ALTER TABLE ... MODIFY COLUMN`, `DROP COLUMN`, `DROP TABLE` и `TRUNCATE TABLE`) для поддерживаемых CDC-источников.
* **Обработка данных in-flight:** фильтрация, обогащение и преобразование данных на пути от источника к ClickHouse.
* **Операции с помощью ИИ:** Striim Clara AI — диалоговый ИИ-агент — создаёт конвейеры по описанию на естественном языке, сообщает о задержке и пропускной способности и объясняет причины сбоев. Перед развертыванием в продакшн проверяйте сгенерированный результат.
* **Частное сетевое подключение:** AWS PrivateLink, SSH-туннели и ограничение доступа к источникам и ClickHouse по списку разрешённых IP-адресов.
* **Мониторинг и оповещения:** встроенный мониторинг конвейеров и оповещения по электронной почте, в Slack, Microsoft Teams и веб-интерфейсе Striim.

## Особенности эксплуатации {#operational-considerations}

* Доставка выполняется с гарантией at-least-once. После перезапуска или восстановления уже записанные события могут быть записаны повторно. Итоговый набор записей зависит от движка таблицы (см. [Как данные попадают в ClickHouse](/ru/integrations/connectors/data-ingestion/etl-tools/striim/get-started#how-data-lands-in-clickhouse)).
* Изменение схемы не поддерживает переименование столбцов и изменение допустимости значений NULL, а также не применяется к целевым таблицам `AggregatingMergeTree`, `Replicated` и `Distributed`. Движки `VersionedCollapsingMergeTree` и `GraphiteMergeTree` не поддерживаются.
* Некоторые типы данных источника не имеют соответствия в ClickHouse и пропускаются при автоматическом создании схемы, например `SQL Server GEOGRAPHY`, `GEOMETRY`, `HIERARCHYID` и `SQL_VARIANT`; `Oracle BFILE`, `LONG`, `LONG RAW`, `SDO_GEOMETRY` и `UROWID`; `MySQL GEOMETRY` и `SET`.
