[Chartbrew](https://chartbrew.com) — это платформа для визуализации данных, которая позволяет создавать панели мониторинга и отслеживать данные в реальном времени. Она поддерживает несколько источников данных, включая ClickHouse, и предоставляет no-code интерфейс для создания диаграмм и отчётов.

## Цель {#goal}

В этом руководстве вы подключите Chartbrew к ClickHouse, выполните SQL-запрос и создадите визуализацию. В результате ваша панель мониторинга будет выглядеть примерно так:

  Если у вас нет датасета, с которым можно работать, вы можете добавить один из примеров. В этом руководстве используется датасет [UK Price Paid](/ru/get-started/sample-datasets/uk-price-paid).
</Tip>

<Steps>
  <Step title="Подготовьте сведения о подключении" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Подключение Chartbrew к ClickHouse" id="2-connect-chartbrew-to-clickhouse">
    1. Войдите в [Chartbrew](https://chartbrew.com/login) и перейдите на вкладку **Connections**.

    2. Нажмите **Create connection** и выберите **ClickHouse** в списке доступных баз данных.

       <div className="ch-image-lg">
         <Frame>
           ![Выбор подключения ClickHouse в Chartbrew](/images/integrations/data-visualization/chartbrew_02.webp)
         </Frame>
       </div>

    3. Введите сведения о подключении к вашей базе данных ClickHouse:

       * **Display Name**: имя, под которым подключение будет отображаться в Chartbrew.
       * **Host**: имя хоста или IP-адрес вашего сервера ClickHouse.
       * **Port**: обычно `8443` для HTTPS-соединений.
       * **Database Name**: база данных, к которой нужно подключиться.
       * **Username**: ваше имя пользователя ClickHouse.
       * **Password**: ваш пароль ClickHouse.

       <div className="ch-image-lg">
         <Frame>
           ![Настройки подключения ClickHouse в Chartbrew](/images/integrations/data-visualization/chartbrew_03.webp)
         </Frame>
       </div>

    4. Нажмите **Test connection**, чтобы убедиться, что Chartbrew может подключиться к ClickHouse.

    5. Если проверка прошла успешно, нажмите **Save connection**. Chartbrew автоматически получит схему из ClickHouse.

       <div className="ch-image-lg">
         <Frame>
           ![JSON-схема ClickHouse в Chartbrew](/images/integrations/data-visualization/chartbrew_04.webp)
         </Frame>
       </div>
  </Step>

  <Step title="Создать набор данных и выполнить SQL-запрос" id="3-create-a-dataset-and-run-a-sql-query">
    1. Нажмите кнопку **Create dataset** или перейдите на вкладку **Datasets**, чтобы создать набор данных.
    2. Выберите подключение к ClickHouse, созданное ранее.

    <div className="ch-image-lg">
      <Frame>
        ![Выбор подключения к ClickHouse для набора данных](/images/integrations/data-visualization/chartbrew_05.webp)
      </Frame>
    </div>

    Напишите SQL-запрос, который получает данные для визуализации. Например, следующий запрос вычисляет среднюю цену сделки по годам на основе набора данных `uk_price_paid`:

    ```sql
    SELECT toYear(date) AS year, avg(price) AS avg_price
    FROM uk_price_paid
    GROUP BY year
    ORDER BY year;
    ```

    <div className="ch-image-lg">
      <Frame>
        ![SQL-запрос ClickHouse в Chartbrew](/images/integrations/data-visualization/chartbrew_07.webp)
      </Frame>
    </div>

    Нажмите **Run query**, чтобы получить данные.

    Если вы не знаете, как составить запрос, воспользуйтесь **ИИ-ассистентом Chartbrew**: он сгенерирует SQL-запросы на основе схемы вашей базы данных.

    <div className="ch-image-lg">
      <Frame>
        ![ИИ-ассистент SQL для ClickHouse в Chartbrew](/images/integrations/data-visualization/chartbrew_06.webp)
      </Frame>
    </div>

    Когда данные будут получены, нажмите **Configure dataset**, чтобы настроить параметры визуализации.
  </Step>

  <Step title="Создать визуализацию" id="4-create-a-visualization">
    1. Задайте метрику (числовое значение) и измерение (категориальное значение) для визуализации.
    2. Просмотрите набор данных в режиме предварительного просмотра и убедитесь, что результаты запроса имеют правильную структуру.
    3. Выберите тип чарта (например, линейный график, столбчатую или круговую диаграмму) и добавьте его на панель мониторинга.
    4. Нажмите **Complete dataset**, чтобы завершить настройку.

    <div className="ch-image-lg">
      <Frame>
        ![Панель мониторинга Chartbrew с данными ClickHouse](/images/integrations/data-visualization/chartbrew_08.webp)
      </Frame>
    </div>

    Вы можете создать любое количество наборов данных для визуализации различных аспектов ваших данных. На их основе можно построить несколько панелей мониторинга для отслеживания разных метрик.

    <div className="ch-image-lg">
      <Frame>
        ![Панель мониторинга Chartbrew с данными ClickHouse](/images/integrations/data-visualization/chartbrew_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Автоматизация обновления данных" id="5-automate-data-updates">
    Чтобы данные на панели мониторинга всегда оставались актуальными, настройте расписание их автоматического обновления:

    1. Нажмите значок календаря рядом с кнопкой обновления набора данных.
    2. Задайте интервал обновления (например, каждый час или каждый день).
    3. Сохраните настройки, чтобы включить автоматическое обновление.

    <div className="ch-image-lg">
      <Frame>
        ![Настройки обновления набора данных в Chartbrew](/images/integrations/data-visualization/chartbrew_09.webp)
      </Frame>
    </div>
  </Step>
</Steps>
