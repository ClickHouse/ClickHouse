<div id="connecting-looker-studio-to-clickhouse">
  ## Подключение Looker Studio к ClickHouse
</div>

Сначала войдите в [Looker Studio](https://lookerstudio.google.com) под своим аккаунтом Google и создайте новый источник данных:

![Создание нового источника данных в интерфейсе Looker Studio](/images/integrations/data-visualization/looker_studio_01.webp)

<br />

Найдите официальный коннектор MySQL от Google (он называется просто **MySQL**):

![Поиск коннектора MySQL в списке коннекторов Looker Studio](/images/integrations/data-visualization/looker_studio_02.webp)

<br />

Укажите сведения о подключении. Обратите внимание, что порт интерфейса MySQL по умолчанию — 9004,
и он может отличаться в зависимости от конфигурации сервера.

![Указание сведений о MySQL-подключении к ClickHouse в Looker Studio](/images/integrations/data-visualization/looker_studio_03.webp)

<br />

Теперь у вас есть два варианта получения данных из ClickHouse. Во-первых, можно использовать функцию Table Browser:

![Использование Table Browser для выбора таблиц ClickHouse в Looker Studio](/images/integrations/data-visualization/looker_studio_04.webp)

<br />

Либо можно указать пользовательский запрос для получения данных:

![Использование пользовательского SQL-запроса для получения данных из ClickHouse в Looker Studio](/images/integrations/data-visualization/looker_studio_05.webp)

<br />

Наконец, вы увидите автоматически определённую структуру таблицы и при необходимости сможете скорректировать типы данных.

![Просмотр автоматически определённой структуры таблицы ClickHouse в Looker Studio](/images/integrations/data-visualization/looker_studio_06.webp)

<br />

Теперь можно перейти к изучению данных или созданию нового отчёта!

<div id="using-looker-studio-with-clickhouse-cloud">
  ## Использование Looker Studio с ClickHouse Cloud
</div>

При использовании ClickHouse Cloud сначала необходимо включить интерфейс MySQL. Это можно сделать в диалоговом окне подключения на вкладке &quot;MySQL&quot;.

![Включение интерфейса MySQL в настройках ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)

<br />

В интерфейсе Looker Studio выберите опцию &quot;Enable SSL&quot;. SSL-сертификат ClickHouse Cloud подписан [Let&#39;s Encrypt](https://letsencrypt.org/certificates/). Вы можете скачать этот корневой сертификат [здесь](https://letsencrypt.org/certs/isrgrootx1.pem).

![Настройка подключения Looker Studio с параметрами SSL для ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)

<br />

Остальные шаги такие же, как в предыдущем разделе выше.
