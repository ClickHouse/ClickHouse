## Подключение Looker Studio к ClickHouse {#connecting-looker-studio-to-clickhouse}

Сначала войдите в [Looker Studio](https://lookerstudio.google.com) с помощью своего аккаунта Google и создайте новый источник данных (Data Source):

<div className="ch-image-md">
  <Frame>
    ![Создание нового источника данных в интерфейсе Looker Studio](/images/integrations/data-visualization/looker_studio_01.webp)
  </Frame>
</div>

<br />

Найдите официальный коннектор MySQL от Google (он называется просто **MySQL**):

<div className="ch-image-md">
  <Frame>
    ![Поиск коннектора MySQL в списке коннекторов Looker Studio](/images/integrations/data-visualization/looker_studio_02.webp)
  </Frame>
</div>

<br />

Укажите сведения о подключении. Обратите внимание: по умолчанию интерфейс MySQL использует порт 9004,
но в зависимости от конфигурации сервера он может быть другим.

<div className="ch-image-md">
  <Frame>
    ![Указание сведений о подключении к ClickHouse через MySQL в Looker Studio](/images/integrations/data-visualization/looker_studio_03.webp)
  </Frame>
</div>

<br />

Получить данные из ClickHouse можно двумя способами. Первый — воспользоваться функцией Table Browser:

<div className="ch-image-md">
  <Frame>
    ![Выбор таблиц ClickHouse с помощью Table Browser в Looker Studio](/images/integrations/data-visualization/looker_studio_04.webp)
  </Frame>
</div>

<br />

Второй — указать пользовательский запрос для получения данных:

<div className="ch-image-md">
  <Frame>
    ![Получение данных из ClickHouse с помощью пользовательского SQL-запроса в Looker Studio](/images/integrations/data-visualization/looker_studio_05.webp)
  </Frame>
</div>

<br />

После этого отобразится считанная структура таблицы, и при необходимости вы сможете скорректировать типы данных.

<div className="ch-image-md">
  <Frame>
    ![Просмотр считанной структуры таблицы ClickHouse в Looker Studio](/images/integrations/data-visualization/looker_studio_06.webp)
  </Frame>
</div>

<br />

Теперь можно переходить к исследованию данных или созданию нового отчёта!

## Использование Looker Studio с ClickHouse Cloud {#using-looker-studio-with-clickhouse-cloud}

При использовании ClickHouse Cloud сначала необходимо включить интерфейс MySQL. Это можно сделать в диалоговом окне подключения на вкладке &quot;MySQL&quot;.

<div className="ch-image-md">
  <Frame>
    ![Включение интерфейса MySQL в настройках ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)
  </Frame>
</div>

<br />

В интерфейсе Looker Studio выберите опцию &quot;Enable SSL&quot;. SSL-сертификат ClickHouse Cloud подписан [Let&#39;s Encrypt](https://letsencrypt.org/certificates/). Вы можете скачать этот корневой сертификат [здесь](https://letsencrypt.org/certs/isrgrootx1.pem).

<div className="ch-image-md">
  <Frame>
    ![Настройка подключения Looker Studio с параметрами SSL для ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)
  </Frame>
</div>

<br />

Остальные шаги такие же, как в предыдущем разделе выше.
