[Splunk](https://www.splunk.com/) — это платформа для анализа данных и мониторинга.

Это дополнение позволяет сохранять [журналы аудита ClickHouse Cloud](/ru/products/cloud/reference/security/audit-logging) в Splunk. Для загрузки журналов аудита оно использует [ClickHouse Cloud API](/ru/products/cloud/features/admin-features/api/api-overview).

Это дополнение содержит только модульный ввод и не включает никаких дополнительных элементов интерфейса.

<div id="installation">
  # Установка {#installation}
</div>

## Для Splunk Enterprise {#for-splunk-enterprise}

Скачайте ClickHouse Cloud Audit Add-on for Splunk с [Splunkbase](https://splunkbase.splunk.com/app/7709).

<div className="ch-image-lg">
  <Frame>
    ![Сайт Splunkbase со страницей загрузки ClickHouse Cloud Audit Add-on for Splunk](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

В Splunk Enterprise перейдите в Apps -&gt; Manage, затем нажмите Install app from file.

<div className="ch-image-lg">
  <Frame>
    ![Интерфейс Splunk Enterprise: страница управления приложениями с пунктом Install app from file](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

Выберите архив, скачанный с Splunkbase, и нажмите Upload.

<div className="ch-image-lg">
  <Frame>
    ![Диалоговое окно установки приложения Splunk для загрузки дополнения ClickHouse](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

Если всё прошло успешно, в списке появится установленное приложение ClickHouse Audit logs. В противном случае проверьте журналы Splunkd на наличие ошибок.

<div id="modular-input-configuration">
  # Настройка модульного ввода {#modular-input-configuration}
</div>

Чтобы настроить модульный ввод, сначала вам понадобятся данные из вашего развертывания ClickHouse Cloud:

* идентификатор организации
* административный [API-ключ](/ru/products/cloud/features/admin-features/api/openapi)

## Получение информации из ClickHouse Cloud {#getting-information-from-clickhouse-cloud}

Войдите в [консоль ClickHouse Cloud](https://console.clickhouse.cloud/).

Перейдите в Organization -&gt; Organization details. Там вы сможете скопировать идентификатор организации.

<div className="ch-image-lg">
  <Frame>
    ![Консоль ClickHouse Cloud со страницей Organization details, на которой показан идентификатор организации](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

Затем в левом меню перейдите в раздел ключей API.

<div className="ch-image-lg">
  <Frame>
    ![Консоль ClickHouse Cloud с разделом ключей API в левом навигационном меню](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

Создайте ключ API, задайте ему понятное имя и выберите привилегии `Admin`. Нажмите Generate ключ API.

<div className="ch-image-lg">
  <Frame>
    ![Консоль ClickHouse Cloud с интерфейсом создания ключа API и выбранными привилегиями Admin](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

Сохраните ключ API и секрет в надежном месте.

<div className="ch-image-lg">
  <Frame>
    ![Консоль ClickHouse Cloud со сгенерированными ключом API и секретом, которые необходимо сохранить](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

## Настройка источника данных в Splunk {#configure-data-input-in-splunk}

Вернитесь в Splunk и перейдите в Settings -&gt; Data inputs.

<div className="ch-image-lg">
  <Frame>
    ![Интерфейс Splunk с меню Settings и пунктом Data inputs](/images/integrations/tools/data-integration/splunk/splunk_008.webp)
  </Frame>
</div>

Выберите источник данных ClickHouse Cloud Audit Logs.

<div className="ch-image-lg">
  <Frame>
    ![Страница Data inputs в Splunk с пунктом ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_009.webp)
  </Frame>
</div>

Нажмите «New», чтобы настроить новый экземпляр источника данных.

<div className="ch-image-lg">
  <Frame>
    ![Интерфейс Splunk для настройки нового источника данных ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_010.webp)
  </Frame>
</div>

Заполнив все поля, нажмите «Next».

<div className="ch-image-lg">
  <Frame>
    ![Страница настройки Splunk с заполненными параметрами источника данных ClickHouse](/images/integrations/tools/data-integration/splunk/splunk_011.webp)
  </Frame>
</div>

Источник данных настроен — теперь можно перейти к просмотру журналов аудита.
