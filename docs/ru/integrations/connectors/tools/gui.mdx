<Accordion title="agx">
  [agx](https://github.com/agnosticeng/agx) — настольное приложение на Tauri и SvelteKit с современным интерфейсом для изучения данных и выполнения запросов с помощью встроенного движка базы данных ClickHouse (chdb).

  * Использует ch-db при запуске нативного приложения.
  * Может подключаться к экземпляру ClickHouse при запуске веб-версии.
  * Редактор Monaco, в котором вы будете чувствовать себя как дома.
  * Множество постоянно развивающихся визуализаций данных.
</Accordion>

<Accordion title="ch-ui">
  [ch-ui](https://github.com/caioricciuti/ch-ui) — простое приложение на React.js с интерфейсом для баз данных ClickHouse, предназначенное для выполнения запросов и визуализации данных. Оно создано с использованием React и веб-клиента ClickHouse и предоставляет лаконичный и удобный интерфейс для работы с базами данных.

  Возможности:

  * Интеграция с ClickHouse: легко управляйте подключениями и выполняйте запросы.
  * Адаптивное управление вкладками: динамически управляйте несколькими вкладками, например вкладками запросов и таблиц.
  * Оптимизация производительности: использует Indexed DB для эффективного кэширования и управления состоянием.
  * Локальное хранение данных: все данные хранятся локально в браузере, что гарантирует, что они никуда не отправляются.
</Accordion>

<Accordion title="ChartDB">
  [ChartDB](https://chartdb.io) — бесплатный инструмент с открытым исходным кодом для визуализации и проектирования схем баз данных, включая ClickHouse, с помощью одного запроса. Он создан на React и предлагает удобный и понятный интерфейс, не требуя ни учётных данных базы данных, ни регистрации для начала работы.

  Возможности:

  * Визуализация схемы: мгновенно импортируйте и визуализируйте схему ClickHouse, включая ER-диаграммы с materialized view и обычными представлениями, с отображением связей с таблицами.
  * Экспорт DDL с помощью ИИ: легко генерируйте DDL-скрипты для более удобного управления схемой и её документирования.
  * Поддержка нескольких диалектов SQL: совместим с рядом SQL-диалектов, что делает его универсальным для различных сред баз данных.
  * Без регистрации и учётных данных: все возможности доступны прямо в браузере, что обеспечивает простоту и безопасность работы.

  [Исходный код ChartDB](https://github.com/chartdb/chartdb).
</Accordion>

<Accordion title="CHOps">
  [CHOps](https://ch-ops.io) — бесплатная веб-панель мониторинга с открытым исходным кодом, самоуправляемая, для администрирования и мониторинга кластеров ClickHouse. Она предоставляет браузерный интерфейс поверх HTTP-интерфейса ClickHouse для выполнения SQL, анализа медленных запросов, настройки оповещений, управления резервными копиями и управления доступом. Она работает с развёртываниями ClickHouse, доступными по HTTP. В настоящее время CHOps поддерживает ClickHouse 26.3 LTS; также работают другие недавние версии, хотя в них могут отсутствовать некоторые возможности.

  Возможности:

  * Редактор SQL с автодополнением, типами `EXPLAIN`, экспортом результатов в 22 форматах, профилировщиком запросов и временной шкалой метрик запросов.
  * Обзор кластера: монитор активных запросов с возможностью их остановки, аналитика и журнал запросов, анализ таблиц и частей, слияния и мутации, очередь распределённого DDL.
  * Пользовательские панели мониторинга с конструктором диаграмм, более чем 10 типами диаграмм и настраиваемыми сеточными макетами.
  * Мониторинг с воспроизведением в стиле DVR для покадрового просмотра исторических метрик.
  * Правила оповещений на основе SQL с проверкой пороговых значений и уведомлениями по электронной почте.
  * Управление доступом: управление пользователями и ролями ClickHouse, визуализация прав и редактирование профилей настроек.
  * Оркестрация резервного копирования и восстановления в S3-совместимое хранилище с обнаружением резервных копий и управлением профилями хранилища.
  * Инструменты для индексов: визуализация индексов пропуска данных, управление проекциями и создание вторичных индексов.
  * Средства просмотра журналов исключений, ошибок и текста с календарными тепловыми картами и фильтрованным поиском.
  * Развёртывается как единый самодостаточный бинарный файл, через Docker или из исходного кода.

  [Исходный код CHOps](https://github.com/Quantrail-Data/CH-Ops).
</Accordion>

<Accordion title="LibreDB Studio">
  [LibreDB Studio](https://github.com/libredb/libredb-studio) — самоуправляемая IDE для баз данных с лицензией MIT, работающая в браузере и развертываемая рядом с базой данных: в виде контейнера, чарта Helm, оператора OLM или npm-пакета, встроенного в другой продукт. Провайдер ClickHouse взаимодействует с документированным HTTP-интерфейсом на `8123`/`8443` и не требует драйверов.

  Возможности:

  * Редактор SQL на базе Monaco с автодополнением с учетом схемы, выполнением запросов в нескольких вкладках и отображением `EXPLAIN` в виде дерева плана.
  * Обозреватель схемы с виртуализированными сетками результатов, фильтрацией и экспортом в CSV/JSON.
  * Мониторинг на основе таблиц `system`: обзор сервера и размеры частей из `system.metrics`, `system.parts` и `system.disks`, завершенные запросы из `system.query_log`, выполняемые запросы из `system.processes` и возможность их завершения.
  * ClickHouse в одном интерфейсе с PostgreSQL, MySQL, Oracle, SQL Server, SQLite, MongoDB, Redis, Couchbase и Apache Druid, поэтому аналитическое хранилище и питающая его база данных OLTP находятся в одной вкладке браузера.
  * Единый вход OIDC, ролевой доступ и журнал аудита запросов — все это в сборке MIT.

  [Справочник провайдера ClickHouse для LibreDB Studio](https://github.com/libredb/libredb-studio/blob/main/docs/providers/clickhouse.md).
</Accordion>

<Accordion title="DataStoria">
  [DataStoria](https://github.com/FrankChen021/datastoria) — веб-консоль с поддержкой ИИ для управления несколькими кластерами ClickHouse из одного места.

  Возможности:

  * **Возможности на базе ИИ**: используйте естественный язык для изучения данных, оптимизации и исправления SQL-запросов, а также визуализации данных.
  * **Интеграция с официальными навыками агентов ClickHouse**: используйте [официальные рекомендации](https://github.com/ClickHouse/agent-skills), чтобы получать от ИИ рекомендации по оптимизации базы данных.
  * **Умная диагностика ошибок**: мгновенно находите синтаксические ошибки благодаря точному выделению строк и столбцов и одним щелчком получайте предложенные ИИ исправления.
  * **Анализ системных таблиц**: подробно изучайте `system.query_log`, `system.query_views_log`, `system.zookeeper`, `system.ddl_distributed_queue`, `system.part_log` и `system.processes` с помощью мощной панели мониторинга и фильтров, чтобы быстро оценить состояние кластера.
  * **Объяснение одним щелчком**: мгновенно разбирайте планы выполнения запросов с помощью визуальных представлений AST и конвейера.
  * **Граф зависимостей**: визуализируйте связи между таблицами и отслеживайте потоки данных через materialized view, таблицы Distributed и внешние системы.
  * **Мониторинг кластера**: отслеживайте все узлы с помощью метрик в реальном времени, операций слияния, состояния репликации, производительности запросов и многого другого.
  * **Конфиденциальность и безопасность**: все SQL-запросы выполняются непосредственно из браузера на вашем сервере ClickHouse, обеспечивая полную конфиденциальность.

  [Документация DataStoria](https://docs.datastoria.app).
</Accordion>

<Accordion title="ClickHouse Schema Flow Visualizer">
  [ClickHouse Schema Flow Visualizer](https://github.com/FulgerX2007/clickhouse-schemaflow-visualizer) — веб-приложение с открытым исходным кодом для визуализации связей между таблицами ClickHouse.
  Оно подключается к экземпляру ClickHouse, разбирает метаданные `system.tables` (типы движков, зависимости, SELECT-запросы materialized view) и отображает интерактивные диаграммы потоков данных на уровне таблиц вместе со связями на уровне столбцов, где на каждом ребре указано выражение преобразования. Для компоновки диаграмм используется Dagre, а рендеринг выполняется в виде обычного встроенного SVG — клиентский runtime для построения диаграмм не загружается.

  Возможности:

  * Просмотр баз данных и таблиц ClickHouse через интуитивно понятную боковую панель
  * Представление Data Flow: входящие источники и исходящие materialized view на уровне таблиц
  * Представление Relationships: сопоставление на уровне столбцов с разобранным выражением преобразования на каждом ребре (например, `toStartOfHour(scheduled_departure)`, `avgState(delay_minutes)`)
  * Значки и цветовое кодирование с учетом движков для `MergeTree`, `Replicated*`, `Distributed`, `MaterializedView` и `Dictionary`
  * Щелкните столбец в представлении Relationships, чтобы подсветить весь путь данных через конвейер
  * Фильтр в боковой панели в реальном времени и палитра команд `Ctrl+K` / `⌘K` для быстрого перехода к любой таблице, столбцу или движку
  * Необязательное наложение метаданных с отображением количества строк и размера на диске для каждой таблицы
  * Экспорт текущей диаграммы в виде самодостаточного HTML-файла
  * TLS‑соединение с ClickHouse с возможностью отключить проверку сертификата и использовать пользовательские сертификаты CA и клиента

  [ClickHouse Schema Flow Visualizer — исходный код](https://github.com/FulgerX2007/clickhouse-schemaflow-visualizer)
</Accordion>

<Accordion title="Grafana">

  «Grafana позволяет выполнять запросы к метрикам, визуализировать их, настраивать оповещения и понимать их независимо от места хранения. Создавайте, исследуйте и делитесь панелями мониторинга с командой, развивая культуру, основанную на данных. Сообщество доверяет и любит Grafana» — grafana.com.

  Плагин источника данных ClickHouse поддерживает ClickHouse в качестве серверной базы данных.
</Accordion>

<Accordion title="qryn">

  Возможности:

  * Поддержка нативных API Grafana для выполнения запросов, обработки, приёма, трассировки и оповещений без плагинов
  * Мощный конвейер для динамического поиска, фильтрации и извлечения данных из журналов, событий, трейсов и не только
  * API приёма и PUSH, прозрачно совместимые с LogQL, PromQL, InfluxDB, Elastic и многими другими
  * Готов к использованию с такими агентами, как Promtail, Grafana-Agent, Vector, Logstash, Telegraf и многими другими
</Accordion>

<Accordion title="DBeaver">
  [DBeaver](https://dbeaver.io/) — универсальный настольный клиент баз данных с поддержкой ClickHouse.

  Возможности:

  * Разработка запросов с подсветкой синтаксиса и автодополнением.
  * Список таблиц с фильтрами и поиском по метаданным.
  * Предпросмотр данных таблицы.
  * Полнотекстовый поиск.

  По умолчанию DBeaver не использует сеанс при подключении (например, CLI использует). Если вам требуется поддержка сеансов (например, чтобы задать настройки для своего сеанса), измените свойства подключения драйвера и задайте для `session_id` произвольную строку (внутри используется HTTP-соединение). После этого можно использовать любые настройки из окна запроса.
</Accordion>

<Accordion title="Граф таблиц ClickHouse">
  [ClickHouse table graph](https://github.com/mbaksheev/clickhouse-table-graph) — простой CLI-инструмент для визуализации зависимостей между таблицами ClickHouse. Инструмент получает связи между таблицами из `system.tables` и строит блок-схему зависимостей в формате [mermaid](https://mermaid.js.org/syntax/flowchart.html). С его помощью можно легко визуализировать зависимости между таблицами и понять поток данных в базе данных ClickHouse. Благодаря mermaid итоговая блок-схема выглядит привлекательно и её легко добавить в документацию Markdown.
</Accordion>

  * **Пороговые оповещения** - Правила для % памяти узла, памяти на запрос и долгих запросов с доставкой в Slack и по электронной почте — с приложенным автономным анализом первопричины при срабатывании.
  * **Полноценное рабочее пространство** - редактор SQL Monaco, обозреватель схем, представление выполняющихся запросов с возможностью завершения, встроенный мониторинг ClickHouse (разбивка памяти, части/слияния, отставание реплик, перцентили задержки) и импорт/экспорт данных.

  С открытым исходным кодом (Apache 2.0), ориентирован прежде всего на on-prem — все возможности входят в поставку, без платного уровня.

Он позволяет подключаться к ClickHouse, выполнять запросы к данным через универсальную консоль SQL, а также загружать данные из статических файлов и сторонних сервисов. TABLUM.IO позволяет представлять результаты в виде диаграмм и таблиц.

  Возможности:

  * ETL: загрузка данных из популярных баз данных, локальных и удалённых файлов, а также через вызовы API.
  * Универсальная консоль SQL с подсветкой синтаксиса и визуальным конструктором запросов.
  * Визуализация данных в виде диаграмм и таблиц.
  * Материализация данных и подзапросы.
  * Отправка отчётов в Slack, Telegram или по электронной почте.
  * Конвейерная обработка данных через собственный API.
  * Экспорт данных в форматах JSON, CSV, SQL, HTML.
  * Веб-интерфейс.

  TABLUM.IO можно запустить как самоуправляемое решение (в виде Docker-образа) или в облаке.

  Подробнее о продукте: [TABLUM.IO](https://tablum.io/)
</Accordion>

<Accordion title="CKMAN">
  [CKMAN](https://www.github.com/housepower/ckman) — инструмент для управления и мониторинга кластеров ClickHouse!

  Возможности:

  * Быстрое и удобное автоматизированное развертывание кластеров через браузерный интерфейс
  * Масштабирование кластеров
  * Балансировка нагрузки в кластере
  * Обновление кластера без остановки
  * Изменение конфигурации кластера через веб-страницу
  * Мониторинг узлов кластера и ZooKeeper
  * Мониторинг состояния таблиц и партиций, а также медленных SQL-команд
  * Удобная страница для выполнения SQL
</Accordion>

<Accordion title="1bench">
  [1bench](https://1bench.dev) — нативный настольный графический интерфейс для работы с несколькими базами данных с полноценной поддержкой ClickHouse: от обзора сервера и управления схемой до векторного поиска и просмотра больших наборов результатов.

  Возможности:

  * Обзор сервера при подключении — версия, время непрерывной работы, выполняющиеся запросы, активные слияния, размеры частей и хранилища, статус реплик, кластеры и узлы с первого взгляда.
  * Визуальный конструктор запросов (выбор столбцов, фильтры, сортировка, limit) вместе с редактором SQL Monaco с подсветкой синтаксиса и историей запросов для каждого подключения.
  * Визуальный мастер `CREATE TABLE` с поддержкой вариантов `MergeTree`, `ORDER BY`, `PARTITION BY`, `SETTINGS` и автоматического обёртывания в `Nullable()`.
  * Нативная поддержка типов ClickHouse — `Nullable`, `Array`, `LowCardinality`, вложенные объекты.
  * Поддержка векторного поиска — столбцы embedding типа `Array(Float32)` отображаются как компактные векторные ячейки, есть 2D-визуализация embedding и функция Find Similar через `cosineDistance`.
  * Встроенное редактирование данных в таблицах результатов с пакетным сохранением, а также экспорт и импорт CSV/JSON/SQL с использованием нативных форматов ClickHouse.
  * Варианты подключения: HTTP/HTTPS, SSH-туннель для частных кластеров за межсетевым экраном, а также необязательный режим только для чтения для безопасного просмотра в продакшне.
  * Работает с ClickHouse Cloud и в самоуправляемых развертываниях.
</Accordion>
