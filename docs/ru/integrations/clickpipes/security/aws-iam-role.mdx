Аутентификация с помощью роли AWS IAM позволяет ClickPipes обращаться к поддерживаемым источникам AWS без хранения ключей доступа AWS. Для этого нужно создать роль в учетной записи AWS, разрешить сервису ClickHouse Cloud принимать эту роль и выдать роли разрешения на доступ к источнику.

## Перед началом работы {#before-you-begin}

* Для аутентификации с помощью роли IAM ваш сервис ClickHouse Cloud должен быть развернут в AWS.
* Вам необходимы разрешения на создание и настройку ролей IAM в учетной записи AWS, которой принадлежит источник.
* Для аутентификации в базе данных RDS или Aurora также потребуются разрешения на включение аутентификации IAM в базе данных и настройку пользователя базы данных.

## Как это работает {#how-it-works}

1. Найдите **Service role ID (IAM)** для вашего сервиса ClickHouse Cloud в разделе **Settings → Network security information**. Этот ARN идентифицирует роль, от имени которой ClickPipes запрашивает доступ.
2. Создайте роль в своей учетной записи AWS и настройте для нее доверительные отношения, разрешив сервисной роли ClickHouse принимать эту роль.
3. Предоставьте этой роли разрешения, необходимые для вашего источника, следуя соответствующему руководству по настройке ниже.
4. Настройте ClickPipe на использование ARN созданной роли. При подключении к источнику ClickPipes принимает эту роль.

## Настройка политики доверия {#configure-trust-policy}

При создании роли в своей учетной записи AWS используйте следующую политику доверия. Замените `{ClickHouse_IAM_ARN}` на ARN из поля **Service role ID (IAM)** вашего сервиса ClickHouse Cloud:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "AWS": "{ClickHouse_IAM_ARN}"
      },
      "Action": "sts:AssumeRole"
    }
  ]
}
```

Для **аутентификации IAM в базах данных RDS и Aurora** разрешите в поле `Action` оба действия: `sts:AssumeRole` и `sts:TagSession`. Полная процедура настройки, включая создание пользователя базы данных с поддержкой IAM, описана в [руководстве по аутентификации IAM для конкретной базы данных](/ru/integrations/clickpipes/postgres/auth).

**Политика разрешений** роли, а также требования к имени роли (если они есть) зависят от источника. Чтобы настроить их, воспользуйтесь руководством для вашего источника ниже.
