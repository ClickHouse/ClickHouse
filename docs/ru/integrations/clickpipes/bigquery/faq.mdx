### Мой ClickPipe завершается с ошибкой «change history start time is before allowed time travel interval» {#time-travel-window-exceeded}

[`APPENDS`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#appends) и [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes) могут считывать изменения только в пределах [окна путешествия во времени](https://docs.cloud.google.com/bigquery/docs/time-travel) исходной таблицы, которое по умолчанию составляет семь дней. Если ClickPipe отстаёт сильнее, чем позволяет это окно, нужных ему изменений в BigQuery уже нет. Чтобы разблокировать ClickPipe, выполните его повторную синхронизацию (resync).
