## Предварительные требования {#pre-requisites}

* У вас должны быть права на управление [сервисными аккаунтами](https://docs.cloud.google.com/iam/docs/service-account-overview) и [ролями IAM](https://docs.cloud.google.com/iam/docs/roles-overview) в вашем проекте GCP, либо вам потребуется помощь администратора. Мы рекомендуем создать отдельный сервисный аккаунт с минимально необходимым набором [разрешений](/ru/integrations/clickpipes/bigquery/overview#permissions), следуя [официальной документации](https://docs.cloud.google.com/iam/docs/service-accounts-create).

* Для первоначальной загрузки требуется бакет Google Cloud Storage (GCS) в качестве промежуточного хранилища. Мы рекомендуем создать отдельный бакет для вашего ClickPipe, следуя [инструкциям Google Cloud](https://docs.cloud.google.com/storage/docs/creating-buckets).

* Для непрерывной репликации назначьте сервисному аккаунту [роль BigQuery Read Session User](/ru/integrations/clickpipes/bigquery/overview#bigquery) на уровне проекта. Перед выбором таблиц проверьте [требования к методу репликации](/ru/integrations/clickpipes/bigquery/overview#cdc).

<Steps>
  <Step title="Выберите источник данных" id="1-select-the-data-source">
    **1.** В ClickHouse Cloud в главном меню выберите **Источники данных** и нажмите **Создать ClickPipe**.

    <Image img="/images/integrations/data-ingestion/clickpipes/cp_step0.webp" alt="Выбор импорта" size="lg" border />

    **2.** Нажмите на карточку **BigQuery**.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/cp_step1.webp" alt="Выбор карточки BigQuery" size="lg" border />
  </Step>

  <Step title="Настройте соединение ClickPipe" id="2-setup-your-clickpipe-connection">
    Укажите сведения о подключении к проекту BigQuery. Если вы планируете выполнить первоначальную загрузку, укажите промежуточный GCS-бакет.

    **1.** Загрузите файл ключа `.json` сервисного аккаунта, созданного для ClickPipes. Убедитесь, что сервисному аккаунту предоставлен минимальный набор необходимых [разрешений](/ru/integrations/clickpipes/bigquery/overview#permissions).

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/cp_step2.webp" alt="Загрузка ключа сервисного аккаунта" size="lg" border />

    **2.** Выберите **режим репликации**: [только первоначальная загрузка](/ru/integrations/clickpipes/bigquery/overview#initial-load), **первоначальная загрузка + CDC** или **только CDC**. Если выбран режим CDC, укажите [метод на основе запросов или событий](/ru/integrations/clickpipes/bigquery/overview#cdc).

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/select-replication-mode.png" alt="Режимы репликации BigQuery: только первоначальная загрузка, первоначальная загрузка с CDC и только CDC" size="lg" border />

    **3.** Если вы планируете выполнить первоначальную загрузку, укажите путь к GCS-бакету для промежуточного хранения данных.

    **4.** Нажмите **Далее**, чтобы проверить введённые данные.
  </Step>

  <Step title="Настройте ClickPipe" id="3-configure-your-clickpipe">
    Задайте значения для выбранных этапов. Настройки первоначальной загрузки действуют только при импорте существующих данных через ClickPipe, а настройки CDC — только при последующей репликации изменений.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/configure-pipe.png" alt="Настройки BigQuery ClickPipe для интервала синхронизации, первоначальной загрузки и CDC" size="lg" border />

    | Настройка                                                   | Что она определяет                                                                                                                                                                                                                                                                                                                       |
    | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | Интервал синхронизации (в секундах)                         | Как часто ClickPipes проверяет каждую исходную таблицу на наличие новых изменений.                                                                                                                                                                                                                                                       |
    | Число параллельных потоков для первоначальной загрузки      | Максимальное число частей одной таблицы, которые ClickPipes загружает одновременно.                                                                                                                                                                                                                                                      |
    | Число строк в партиции снимка                               | Целевое число строк в каждой части первоначальной загрузки. Для больших таблиц ClickPipes может корректировать это значение.                                                                                                                                                                                                             |
    | Число таблиц снимка, загружаемых параллельно                | Максимальное число исходных таблиц, которые ClickPipes загружает одновременно.                                                                                                                                                                                                                                                           |
    | Число таблиц, обрабатываемых параллельно при CDC            | Максимальное число таблиц, данные из которых ClickPipes одновременно считывает и отправляет в ClickHouse.                                                                                                                                                                                                                                |
    | Защитный интервал CDC (в секундах)                          | Насколько раньше текущего времени BigQuery заканчивается период, охватываемый каждым запросом CDC. Благодаря этому недавно записанные данные успевают стать доступными до того, как ClickPipes их считает.                                                                                                                               |
    | Максимальное временное окно одного запроса CDC (в секундах) | Максимальный период времени, охватываемый одним запросом CDC. Более длительные периоды ClickPipes разбивает на отдельные запросы. Для репликации на основе событий задайте значение не более 86,400 секунд — [суточного ограничения](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions) BigQuery. |
  </Step>

  <Step title="Настройте таблицы" id="4-configure-tables">
    **1.** Выберите базу данных ClickHouse, в которую будут реплицироваться таблицы BigQuery. Можно выбрать существующую базу данных или создать новую.

    **2.** Выберите исходные таблицы. Для каждой таблицы можно изменить имя целевой таблицы и указать столбцы для репликации в разделе **Настройки столбцов**. В списке отображаются только датасеты, к которым у сервисного аккаунта есть доступ.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/select-table-settings.png" alt="Выбор исходной таблицы BigQuery и настройка имени целевой таблицы, водяной метки CDC, ключа сортировки и расширенных настроек" size="lg" border />

    **3.** Настройте CDC для каждой таблицы. На снимке экрана показаны настройки репликации на основе запросов. Выберите **столбец водяной метки CDC** типа `TIMESTAMP`, включите его в число реплицируемых столбцов и обновляйте его значение при каждом изменении строки. Для репликации на основе событий вместо этого выберите [`APPENDS`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#appends) или [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes). Для [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes) в исходной таблице требуется `enable_change_history = TRUE`.

    **4.** Проверьте **ключ сортировки**. Если строки могут обновляться или удаляться, выберите столбцы с неизменными значениями, которые однозначно определяют каждую строку. Для [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes) у исходной таблицы должен быть первичный ключ либо здесь необходимо задать ключ сортировки. ClickHouse использует ключ сортировки для организации данных при выполнении запросов; если он не задан, используется `tuple()`, а первичный индекс отсутствует.

    **5.** Откройте **Расширенные настройки**, чтобы выбрать **движок** таблицы ClickHouse или при необходимости задать ключ партиционирования для начальной загрузки. Этот ключ партиционирования не задаёт выражение `PARTITION BY` целевой таблицы.
  </Step>

  <Step title="Настройте разрешения" id="6-configure-permissions">
    Наконец, можно настроить разрешения для внутреннего пользователя ClickPipes.

    **Разрешения:** ClickPipes создаст отдельного пользователя для записи данных в целевую таблицу. Ему можно назначить пользовательскую или одну из предопределённых ролей:

    * `Full access`: полный доступ к кластеру. Необходима, если с целевой таблицей используются materialized views или словарь.
    * `Only destination`: разрешение только на вставку данных в целевую таблицу.
  </Step>

  <Step title="Завершите настройку" id="7-complete-setup">
    Нажмите **Create ClickPipe**, чтобы завершить настройку. После этого откроется страница обзора, где можно отслеживать ход первоначальной загрузки и просматривать подробную информацию о ваших BigQuery ClickPipes.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/cp_step5.webp" alt="Разрешения" size="lg" border />
  </Step>
</Steps>
