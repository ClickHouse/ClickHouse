Запросы CREATE создают, например, новые [базы данных](/ru/reference/statements/create/database), [таблицы](/ru/reference/statements/create/table) и [представления](/ru/reference/statements/create/view).

**Синтаксис**

```sql
CREATE DATABASE ...
CREATE TABLE ...
CREATE VIEW ...
CREATE DICTIONARY ...
CREATE FUNCTION ...
CREATE NAMED COLLECTION ...
CREATE USER | ROLE | ROW POLICY | MASKING POLICY | QUOTA | SETTINGS PROFILE ...
```

**Связанные материалы:** `ATTACH`, `DROP`, `CREATE TABLE`, `CREATE DATABASE`, `CREATE VIEW`, `CREATE DICTIONARY`
