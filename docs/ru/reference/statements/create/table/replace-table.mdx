<div id="overview">
  ## Обзор
</div>

Оператор `REPLACE` позволяет [атомарно](/ru/concepts/core-concepts/glossary#atomicity) обновлять таблицу.

<Note>
  Этот оператор поддерживается движками баз данных [`Atomic`](/ru/reference/engines/database-engines/atomic) и [`Replicated`](/ru/reference/engines/database-engines/replicated),
  которые являются движками баз данных по умолчанию в ClickHouse и ClickHouse Cloud соответственно.
</Note>

Обычно, если необходимо удалить данные из таблицы,
можно создать новую таблицу и заполнить её результатом оператора `SELECT`, исключающего ненужные данные,
а затем удалить старую таблицу и переименовать новую.
Этот подход показан в примере ниже:

```sql
CREATE TABLE myNewTable AS myOldTable;

INSERT INTO myNewTable
SELECT * FROM myOldTable
WHERE CounterID <12345;

DROP TABLE myOldTable;

RENAME TABLE myNewTable TO myOldTable;
```

Вместо описанного выше подхода можно также использовать `REPLACE` (при использовании движков базы данных по умолчанию), чтобы добиться того же результата:

```sql
REPLACE TABLE myOldTable
ENGINE = MergeTree()
ORDER BY CounterID
AS
SELECT * FROM myOldTable
WHERE CounterID <12345;
```

<div id="syntax">
  ## Синтаксис
</div>

```sql
{CREATE [OR REPLACE] | REPLACE} TABLE [db.]table_name
```

<Note>
  Для этого оператора также применимы все синтаксические формы оператора [`CREATE`](/ru/reference/statements/create/table). Вызов `REPLACE` для несуществующей таблицы приведёт к ошибке.
</Note>

<div id="examples">
  ## Примеры
</div>

<Tabs>
  <Tab title="Локально">
    Рассмотрим следующую таблицу:

    ```sql
    CREATE DATABASE base
    ENGINE = Atomic;

    CREATE OR REPLACE TABLE base.t1
    (
        n UInt64,
        s String
    )
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (1, 'test');

    SELECT * FROM base.t1;

    ┌─n─┬─s────┐
    │ 1 │ test │
    └───┴──────┘
    ```

    С помощью оператора `REPLACE` можно очистить все данные:

    ```sql
    CREATE OR REPLACE TABLE base.t1
    (
        n UInt64,
        s Nullable(String)
    )
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (2, null);

    SELECT * FROM base.t1;

    ┌─n─┬─s──┐
    │ 2 │ \N │
    └───┴────┘
    ```

    Или с помощью оператора `REPLACE` можно изменить структуру таблицы:

    ```sql
    REPLACE TABLE base.t1 (n UInt64)
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (3);

    SELECT * FROM base.t1;

    ┌─n─┐
    │ 3 │
    └───┘
    ```
  </Tab>

  <Tab title="Cloud">

    Или с помощью оператора `REPLACE` можно изменить структуру таблицы:
