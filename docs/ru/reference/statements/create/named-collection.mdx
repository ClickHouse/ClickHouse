Создаёт новую именованную коллекцию.

<Note>
  Именованные коллекции, созданные с помощью DDL, могут быть включены в некоторых сервисах ClickHouse Cloud. Обратитесь в службу поддержки, чтобы уточнить доступность.
</Note>

**Синтаксис**

```sql
CREATE [OR REPLACE] NAMED COLLECTION [IF NOT EXISTS] name [ON CLUSTER cluster] AS
key_name1 = 'some value' [[NOT] OVERRIDABLE],
key_name2 = 'some value' [[NOT] OVERRIDABLE],
key_name3 = 'some value' [[NOT] OVERRIDABLE],
...
```

`OR REPLACE` и `IF NOT EXISTS` нельзя использовать вместе. `CREATE OR REPLACE` для существующей коллекции
полностью заменяет её: ключи и флаги переопределяемости, которых нет в новом определении, удаляются.

**Пример**

```sql
CREATE NAMED COLLECTION foobar AS a = '1', b = '2' OVERRIDABLE;
CREATE OR REPLACE NAMED COLLECTION foobar AS a = '2', c = '3';
```
