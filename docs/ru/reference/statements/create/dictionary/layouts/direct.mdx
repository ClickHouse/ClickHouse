## прямой {#direct}

Словарь не хранится в памяти и при обработке запроса обращается напрямую к источнику.

Ключ словаря имеет тип [UInt64](/ru/reference/data-types/int-uint).

Выборочным является только lookup. `dictGet` и другие функции словарей запрашивают у источника только требуемые ключи, однако чтение словаря **как таблицы** не является выборкой по ключу: `SELECT ... FROM <dictionary> WHERE key IN (...)` считывает весь источник и лишь затем фильтрует результат, поскольку фильтр по ключу не проталкивается внутрь словаря. Используйте функции словарей, если вы хотите, чтобы источник запрашивался по определённым ключам.

Поддерживаются все типы [источников](/ru/reference/statements/create/dictionary/sources/overview#dictionary-sources), кроме локальных файлов.

Пример конфигурации:

<Tabs>
  <Tab title="DDL">
    ```sql
    LAYOUT(DIRECT())
    ```
  </Tab>

  <Tab title="Файл конфигурации">
    ```xml
    <layout>
      <direct />
    </layout>
    ```
  </Tab>
</Tabs>
