Изменяет настройки движка баз данных. Набор изменяемых настроек зависит от движка; не все движки и настройки допускают изменение после создания базы данных.

Этот оператор изменяет настройки движка баз данных, а не настройки сеанса или значения по умолчанию для таблиц в базе данных.

## Синтаксис {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

Используйте `ON CLUSTER`, чтобы выполнить оператор на всех хостах указанного кластера.
Для выполнения оператора требуется привилегия `ALTER DATABASE SETTINGS`.

## Поддерживаемые настройки {#supported-settings}

Сведения о настройках и ограничениях движка баз данных см. в его документации. Например:

* [`Atomic`](/ru/reference/engines/database-engines/atomic) и [`Ordinary`](/ru/reference/engines/database-engines/ordinary) поддерживают изменение `max_tables`.
* [`MaterializedPostgreSQL`](/ru/reference/engines/database-engines/materialized-postgresql) поддерживает изменение отдельных настроек репликации, например `materialized_postgresql_max_block_size`.
* [`DataLakeCatalog`](/ru/reference/engines/database-engines/datalake) поддерживает изменение отдельных настроек каталога; доступные настройки зависят от типа каталога.

Использование неподдерживаемого движка или настройки приводит к исключению.

## Пример {#example}

Измените максимальное количество таблиц в базе данных `Atomic`:

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

Установите для `max_tables` значение `0`, чтобы снять это ограничение на уровне базы данных:

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
