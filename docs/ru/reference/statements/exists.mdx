```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

Возвращает один столбец типа `UInt8`, содержащий значение `0`, если таблица или база данных не существуют, или `1`, если таблица существует в указанной базе данных.

## Форма с подзапросом {#subquery-form}

Оператор `EXISTS` проверяет, возвращает ли подзапрос хотя бы одну строку. Если результат подзапроса пуст, он возвращает `0`, в противном случае — `1`.

`EXISTS` можно использовать в предложении [`WHERE`](/ru/reference/statements/select/where). Подзапрос не может ссылаться на таблицы или столбцы внешнего запроса.

**Синтаксис**

```sql
EXISTS(subquery)
```

**Примеры**

Проверка того, возвращает ли подзапрос строки:

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

Используйте `EXISTS` в предложении `WHERE` с подзапросом, возвращающим несколько строк:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

Если подзапрос возвращает пустой результат, `EXISTS` возвращает `0`:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```
