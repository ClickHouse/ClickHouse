<div id="description">
  ## Описание
</div>

Содержит информацию о выполняющихся в данный момент слияниях и мутациях частей в таблицах семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных, в которой находится таблица.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `elapsed` ([Float64](/ru/reference/data-types/float)) — Время, прошедшее с начала слияния, в секундах.
* `progress` ([Float64](/ru/reference/data-types/float)) — Доля выполненной работы от 0 до 1.
* `num_parts` ([UInt64](/ru/reference/data-types/int-uint)) — Количество частей, подлежащих слиянию.
* `source_part_names` ([Array(String)](/ru/reference/data-types/array)) — Список имён исходных частей.
* `result_part_name` ([String](/ru/reference/data-types/string)) — Имя части, которая будет сформирована в результате слияния.
* `source_part_paths` ([Array(String)](/ru/reference/data-types/array)) — Список путей к исходным частям.
* `result_part_path` ([String](/ru/reference/data-types/string)) — Путь к части, которая будет сформирована в результате слияния.
* `partition_id` ([String](/ru/reference/data-types/string)) — Идентификатор партиции, в которой выполняется слияние.
* `partition` ([String](/ru/reference/data-types/string)) — Имя партиции.
* `is_mutation` ([UInt8](/ru/reference/data-types/int-uint)) — 1, если этот процесс представляет собой мутацию части.
* `total_size_bytes_compressed` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в слитых фрагментах.
* `total_size_bytes_uncompressed` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в слитых фрагментах.
* `total_size_marks` ([UInt64](/ru/reference/data-types/int-uint)) — Общее количество меток в слитых частях.
* `bytes_read_uncompressed` ([UInt64](/ru/reference/data-types/int-uint)) — Количество прочитанных несжатых байтов.
* `rows_read` ([UInt64](/ru/reference/data-types/int-uint)) — Количество прочитанных строк.
* `bytes_written_uncompressed` ([UInt64](/ru/reference/data-types/int-uint)) — Количество записанных несжатых байтов.
* `rows_written` ([UInt64](/ru/reference/data-types/int-uint)) — Количество записанных строк.
* `columns_written` ([UInt64](/ru/reference/data-types/int-uint)) — Количество записанных столбцов (для алгоритма Вертикального слияния).
* `memory_usage` ([UInt64](/ru/reference/data-types/int-uint)) — Потребление памяти процессом слияния.
* `thread_id` ([UInt64](/ru/reference/data-types/int-uint)) — Идентификатор потока процесса слияния.
* `merge_type` ([String](/ru/reference/data-types/string)) — Тип текущего слияния. Пусто, если это мутация.
* `merge_algorithm` ([String](/ru/reference/data-types/string)) — Алгоритм, используемый для текущего слияния. Пусто, если это мутация.
* `current_projection` ([String](/ru/reference/data-types/string)) — Имя проекции, которая в данный момент сливается или перестраивается. Пусто, если слияние не находится на стадии обработки проекции.
* `current_projection_progress` ([Float64](/ru/reference/data-types/float)) — Ход слияния текущей проекции от 0 до 1.
* `current_projection_parts_merging` ([UInt64](/ru/reference/data-types/int-uint)) — Количество частей проекции, сливаемых в данный момент.
* `current_projection_parts_remaining` ([UInt64](/ru/reference/data-types/int-uint)) — Количество частей, которые ещё предстоит слить для текущей проекции.
* `projections_completed` ([Array(String)](/ru/reference/data-types/array)) — Список проекций, уже слитых или перестроенных.
* `projections_remaining` ([Array(String)](/ru/reference/data-types/array)) — Список проекций, которые ещё необходимо слить или перестроить.
