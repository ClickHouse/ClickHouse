<div id="description">
  ## Описание
</div>

Содержит список структур словарей, поддерживаемых сервером, а также встроенную документацию для каждой структуры. Структура словаря определяет, как словарь хранится в памяти (или на диске) и как по нему выполняется поиск; она указывается в предложении `LAYOUT` запроса `CREATE DICTIONARY`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ru/reference/data-types/string)) — Имя структуры словаря, указанное в предложении LAYOUT.
* `is_complex` ([UInt8](/ru/reference/data-types/int-uint)) — Указывает, требуется ли для структуры составной ключ (ключ, состоящий из нескольких атрибутов или имеющий нецелочисленный тип).
* `description` ([String](/ru/reference/data-types/string)) — Описание назначения структуры словаря. Для структур, имеющих отдельную страницу документации, содержит полный текст этой страницы в Markdown; для остальных структур — краткое описание.
* `syntax` ([String](/ru/reference/data-types/string)) — Способ указания структуры в предложении LAYOUT запроса CREATE DICTIONARY.
* `examples` ([String](/ru/reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/reference/data-types/string)) — Версия ClickHouse, в которой структура впервые появилась, в формате major.minor.
* `related` ([Array(String)](/ru/reference/data-types/array)) — Имена связанных структур словарей.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Пример
</div>

```sql title="Query"
SELECT name, is_complex, syntax
FROM system.dictionary_layouts
WHERE name IN ('flat', 'hashed', 'complex_key_hashed')
ORDER BY name
```

```text title="Response"
┌─name───────────────┬─is_complex─┬─syntax───────────────────────────────────────────────────┐
│ complex_key_hashed │          1 │ LAYOUT(COMPLEX_KEY_HASHED())                             │
│ flat               │          0 │ LAYOUT(FLAT([INITIAL_ARRAY_SIZE n] [MAX_ARRAY_SIZE n]))  │
│ hashed             │          0 │ LAYOUT(HASHED())                                         │
└────────────────────┴────────────┴──────────────────────────────────────────────────────────┘
```
