<div id="description">
  ## Описание
</div>

Содержит информацию о доступных сертификатах и источниках их получения.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `version` ([Int32](/ru/reference/data-types/int-uint)) — Версия сертификата. Значения: 0 для v1, 1 для v2, 2 для v3.
* `serial_number` ([Nullable(String)](/ru/reference/data-types/nullable)) — Серийный номер сертификата, присвоенный центром сертификации.
* `signature_algo` ([Nullable(String)](/ru/reference/data-types/nullable)) — Алгоритм подписи, используемый центром сертификации для подписания этого сертификата.
* `issuer` ([Nullable(String)](/ru/reference/data-types/nullable)) — Issuer — уникальный идентификатор центра сертификации, выдавшего этот сертификат.
* `not_before` ([Nullable(String)](/ru/reference/data-types/nullable)) — Начало периода действия сертификата.
* `not_after` ([Nullable(String)](/ru/reference/data-types/nullable)) — Конец периода действия сертификата.
* `subject` ([Nullable(String)](/ru/reference/data-types/nullable)) — Subject — идентификатор владельца открытого ключа.
* `pkey_algo` ([Nullable(String)](/ru/reference/data-types/nullable)) — Алгоритм, с которым может использоваться открытый ключ.
* `path` ([String](/ru/reference/data-types/string)) — Путь к файлу или каталогу, содержащему этот сертификат.
* `default` ([UInt8](/ru/reference/data-types/int-uint)) — Сертификат находится в расположении сертификатов по умолчанию.
* `protocol` ([String](/ru/reference/data-types/string)) — Имя протокола, если сертификат получен из конфигурации TLS для конкретного протокола; в противном случае пустая строка.

{/*AUTOGENERATED_END*/}
