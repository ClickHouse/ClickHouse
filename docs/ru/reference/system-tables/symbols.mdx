## Описание {#description}

Содержит сведения для интроспекции бинарного файла `clickhouse`. Для доступа требуется привилегия introspection.
Эта таблица полезна только экспертам по C++ и инженерам ClickHouse.

## Столбцы {#columns}

* `symbol` ([String](/ru/reference/data-types/string)) — Имя символа в бинарном файле. Оно манглировано. Чтобы получить читаемое имя, можно применить demangle(symbol).
* `symbol_demangled` ([Nullable(String)](/ru/reference/data-types/nullable)) — Деманглированный символ, используемый для инструментирования XRay.
* `function_id` ([Nullable(Int32)](/ru/reference/data-types/nullable)) — Идентификатор функции в карте инструментирования XRay.
* `address_begin` ([UInt64](/ru/reference/data-types/int-uint)) — Начальный адрес символа в бинарном файле.
* `address_end` ([UInt64](/ru/reference/data-types/int-uint)) — Конечный адрес символа в бинарном файле.

## Пример {#example}

```sql
SELECT
    symbol,
    demangle(symbol) AS symbol_demangled,
    address_begin,
    address_end
FROM system.symbols
LIMIT 5
SETTINGS allow_introspection_functions = 1;
```
