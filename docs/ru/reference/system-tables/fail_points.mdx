## Описание {#description}

Содержит список всех доступных failpoint, зарегистрированных на сервере, а также их тип и сведения о том, включены ли они в данный момент.

В сборках с поддержкой failpoint (`USE_LIBFIU=1`) failpoint можно включать и отключать во время выполнения с помощью команд `SYSTEM ENABLE FAILPOINT` и `SYSTEM DISABLE FAILPOINT`. В сборках без поддержки failpoint эти команды недоступны, хотя сама таблица остаётся доступной.

`SYSTEM DISABLE ALL FAILPOINTS` отключает сразу все failpoint и возобновляет работу всех потоков, заблокированных на failpoint с возможностью паузы. Это удобно для возврата сервера в чистое состояние, когда неизвестно, что именно включено в данный момент.

## Столбцы {#columns}

* `name` ([String](/ru/reference/data-types/string)) — Имя failpoint.
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/ru/reference/data-types/enum)) — Тип failpoint: &#39;once&#39; срабатывает один раз, после чего автоматически отключается; &#39;regular&#39; срабатывает каждый раз; &#39;pauseable&#95;once&#39; один раз приостанавливает выполнение; &#39;pauseable&#39; приостанавливает выполнение каждый раз, пока оно не будет возобновлено.
* `enabled` ([UInt8](/ru/reference/data-types/int-uint)) — Указывает, включен ли failpoint в данный момент (1) или отключен (0).

## Пример {#example}

Для этого примера требуется сборка с поддержкой failpoint (`USE_LIBFIU=1`).

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```

```text title="Response"
┌─name──────────────────────────────────────┬─type────────────┬─enabled─┐
│ replicated_merge_tree_insert_retry_pause  │ pauseable_once  │       1 │
└───────────────────────────────────────────┴─────────────────┴─────────┘
```
