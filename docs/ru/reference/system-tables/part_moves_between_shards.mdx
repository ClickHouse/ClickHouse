<div id="description">
  ## Описание
</div>

Содержит сведения о частях, которые в данный момент перемещаются между сегментами, и о ходе этого перемещения.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных, в которой выполняется перемещение.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы, в которой выполняется перемещение.
* `task_name` ([String](/ru/reference/data-types/string)) — Имя задачи перемещения.
* `task_uuid` ([UUID](/ru/reference/data-types/uuid)) — Идентификатор задачи перемещения.
* `create_time` ([DateTime](/ru/reference/data-types/datetime)) — Время создания задачи.
* `part_name` ([String](/ru/reference/data-types/string)) — Имя перемещаемой части.
* `part_uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID перемещаемой части.
* `to_shard` ([String](/ru/reference/data-types/string)) — Имя целевого сегмента.
* `dst_part_name` ([String](/ru/reference/data-types/string)) — Имя результирующей части.
* `update_time` ([DateTime](/ru/reference/data-types/datetime)) — Время последнего обновления.
* `state` ([String](/ru/reference/data-types/string)) — Текущее состояние перемещения.
* `rollback` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, была ли операция отменена.
* `num_tries` ([UInt32](/ru/reference/data-types/int-uint)) — Количество попыток завершения операции.
* `last_exception` ([String](/ru/reference/data-types/string)) — Имя последнего исключения, если оно возникло.

{/*AUTOGENERATED_END*/}
