<div id="description">
  ## Описание
</div>

Содержит список всех HTTP-обработчиков, определённых в SQL с помощью [`CREATE HANDLER`](/ru/reference/statements/create/handler).

Для чтения этой таблицы требуется привилегия `SHOW HANDLERS`; без неё таблица отображается пустой. Секреты,
которые могут быть включены в запрос обработчика (например, учётные данные, передаваемые табличной функции), отображаются в
столбцах `query` и `create_query` только если пользователю разрешено видеть секреты (включены настройка сервера
`display_secrets_in_show_and_select` и настройка формата `format_display_secrets_in_show_and_select`,
а пользователь обладает привилегией `displaySecretsInShowAndSelect`); в противном случае они
маскируются, как и в `SHOW CREATE TABLE`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ru/reference/data-types/string)) — Имя обработчика.
* `protocol` ([Nullable(String)](/ru/reference/data-types/nullable)) — Компонуемый протокол, которым ограничен обработчик, или NULL, если обработчик активен на всех конечных точках HTTP (встроенных портах `http`/`https` и всех слушателях компонуемых протоколов типа HTTP).
* `url_match_type` ([String](/ru/reference/data-types/string)) — Способ сопоставления URL: точное совпадение, префикс или регулярное выражение.
* `url` ([String](/ru/reference/data-types/string)) — Шаблон URL, которому соответствует обработчик.
* `methods` ([Array(String)](/ru/reference/data-types/array)) — Разрешённые методы HTTP.
* `type` ([String](/ru/reference/data-types/string)) — Тип обработчика (поддерживается только `query`).
* `query` ([String](/ru/reference/data-types/string)) — SQL-запрос, выполняемый обработчиком. Секреты скрываются, если у пользователя нет прав на их просмотр.
* `create_query` ([String](/ru/reference/data-types/string)) — Оператор CREATE HANDLER. Секреты скрываются, если у пользователя нет прав на их просмотр.

{/*AUTOGENERATED_END*/}
