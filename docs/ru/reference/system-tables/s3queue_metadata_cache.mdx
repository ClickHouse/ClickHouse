## Описание {#description}

Содержит состояние метаданных S3Queue, хранящееся в памяти, и строки, обрабатываемые в данный момент для каждого файла.

## Столбцы {#columns}

* `zookeeper_path` ([String](/ru/reference/data-types/string)) — Путь в ZooKeeper к метаданным
* `file_path` ([String](/ru/reference/data-types/string)) — Путь к обрабатываемому файлу
* `file_name` ([String](/ru/reference/data-types/string)) — Имя обрабатываемого файла
* `rows_processed` ([UInt64](/ru/reference/data-types/int-uint)) — Количество обрабатываемых строк
* `status` ([String](/ru/reference/data-types/string)) — Статус обработки: Processed, Processing, Failed или None для файла, который известен кэшу, но не имеет состояния, например файла, обработка которого была сброшена. Значение `processing_observed_in_keeper_time`, отличное от NULL, означает, что статус `Processing` был не установлен процессором, удерживающим файл, а прочитан из Keeper
* `processing_start_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время начала обработки файла
* `processing_end_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время окончания обработки файла
* `exception` ([String](/ru/reference/data-types/string)) — Исключение, возникшее во время обработки. Всегда относится к последней попытке этого сервера и никогда — к исключению, которое Keeper хранит для файла
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время, когда процессору этого сервера не удалось взять файл и он прочитал статус `Processing` из Keeper вместо того, чтобы установить его самостоятельно. Обычно файл удерживается другим сервером, но он также может удерживаться процессором этого же сервера, который только что его взял. В любом случае `rows_processed`, `processing_start_time`, `processing_end_time` и `exception` описывают последнюю попытку этого сервера обработать файл, а не ту обработку, которая удерживает его сейчас
