## Описание {#description}

Таблица `system.delta_lake_metadata_log` фиксирует события доступа к метаданным и их разбора для таблиц Delta Lake, читаемых ClickHouse. Она содержит подробную информацию о каждом файле метаданных, что полезно для отладки, аудита и понимания того, как изменяется структура таблиц Delta.

В эту таблицу записывается каждый файл метаданных, прочитанный из таблиц Delta Lake. Она помогает пользователям проследить, как ClickHouse интерпретирует метаданные таблиц Delta, и диагностировать проблемы, связанные с изменением схемы, разрешением снимков или планированием запросов.

Эта таблица предназначена в первую очередь для отладки.

### Управление детализацией логирования {#controlling-log-verbosity}

Управлять тем, какие события метаданные записываются в лог, можно с помощью настройки [`delta_lake_log_metadata`](/ru/reference/settings/session-settings/delta-lake#delta_lake_log_metadata).

Чтобы записать все метаданные, используемые в текущем запросе:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

Эту таблицу можно безопасно очистить (TRUNCATE) или удалить (DROP) в любой момент.
