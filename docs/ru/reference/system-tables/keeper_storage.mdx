<div id="description">
  ## Описание
</div>

Таблица доступна только в развертываниях ClickHouse Keeper, использующих процесс `clickhouse server` (а не `clickhouse keeper`). Она содержит по одной строке для каждого узла дерева данных, хранящегося на локальном узле Keeper, включая системные узлы `/keeper`.

В отличие от `system.zookeeper`, эта таблица не отправляет запросы в кластер Keeper. Она напрямую считывает зафиксированное состояние локального Keeper из согласованного представления без блокировок, не влияя на обработку запросов. Для чтения таблицы не требуется условие пути; она возвращает всё дерево, поэтому подходит для запросов, сканирующих все узлы, например для поиска узлов с наибольшим числом дочерних узлов или наибольшим объёмом данных.

<div id="columns">
  ## Столбцы
</div>

* `path` ([String](/ru/reference/data-types/string)) — Абсолютный путь узла.
* `data` ([String](/ru/reference/data-types/string)) — Данные, хранящиеся в узле.
* `czxid` ([Int64](/ru/reference/data-types/int-uint)) — Идентификатор транзакции, создавшей узел.
* `mzxid` ([Int64](/ru/reference/data-types/int-uint)) — Идентификатор транзакции, последней изменившей узел.
* `ctime` ([DateTime64(3)](/ru/reference/data-types/datetime64)) — Время создания узла.
* `mtime` ([DateTime64(3)](/ru/reference/data-types/datetime64)) — Время последнего изменения узла.
* `version` ([Int32](/ru/reference/data-types/int-uint)) — Количество изменений данных узла.
* `cversion` ([Int32](/ru/reference/data-types/int-uint)) — Количество изменений дочерних узлов.
* `aversion` ([Int32](/ru/reference/data-types/int-uint)) — Количество изменений ACL узла.
* `ephemeral_owner` ([Int64](/ru/reference/data-types/int-uint)) — Идентификатор сеанса, которому принадлежит эфемерный узел; в противном случае — `0`.
* `data_length` ([UInt32](/ru/reference/data-types/int-uint)) — Размер данных узла в байтах.
* `num_children` ([Int32](/ru/reference/data-types/int-uint)) — Количество дочерних узлов.
* `pzxid` ([Int64](/ru/reference/data-types/int-uint)) — Идентификатор транзакции, последней добавившей или удалившей дочерние узлы.
* `seq_num` ([Int64](/ru/reference/data-types/int-uint)) — Счётчик, используемый для генерации имён последовательных дочерних узлов.
* `ttl` ([Int64](/ru/reference/data-types/int-uint)) — TTL узла в миллисекундах для TTL-узла; в противном случае — `0`.
* `acl_id` ([UInt32](/ru/reference/data-types/int-uint)) — Внутренний идентификатор ACL узла; `0`, если у узла нет ACL.

<div id="example">
  ## Пример
</div>

```sql
SELECT path, num_children, data_length
FROM system.keeper_storage
ORDER BY num_children DESC
LIMIT 3;
```

```text
┌─path──────────────┬─num_children─┬─data_length─┐
│ /                 │            3 │           0 │
│ /clickhouse/tasks │            2 │           0 │
│ /keeper           │            1 │           0 │
└───────────────────┴──────────────┴─────────────┘
```
