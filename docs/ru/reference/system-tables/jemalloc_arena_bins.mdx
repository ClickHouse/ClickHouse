## Описание {#description}

То же, что и `system.jemalloc_bins`, но с одной строкой на каждую пару (арена, bin) вместо агрегирования по аренам. Slab-блоки принадлежат одной арене, поэтому эта таблица позволяет локализовать фрагментацию в конкретной арене (включая отдельные арены для метаданных MergeTree, JIT и cache) и соединяется JOIN с `system.jemalloc_sampled_allocations` одновременно по `арене` и size class.

## Столбцы {#columns}

{/*AUTOGENERATED_START*/}

* `arena` ([UInt32](/ru/reference/data-types/int-uint)) — индекс арены. Связывается с `system.jemalloc_sampled_allocations.arena`.
* `purpose` ([String](/ru/reference/data-types/string)) — назначение выделенной долгоживущей арены: &#39;mergetree&#39; (метаданные part и таблиц), &#39;jit&#39;, &#39;cache&#39;. Пусто для арен общего назначения. Выделенные арены по своей природе содержат долгоживущие выделения памяти, поэтому из отчётов о фрагментации их обычно исключают.
* `index` ([UInt16](/ru/reference/data-types/int-uint)) — индекс bin в порядке возрастания размера.
* `large` ([UInt8](/ru/reference/data-types/int-uint)) — True для крупных выделений и False для мелких.
* `size` ([UInt64](/ru/reference/data-types/int-uint)) — размер выделений в этом bin.
* `allocations` ([Int64](/ru/reference/data-types/int-uint)) — количество выделений.
* `deallocations` ([Int64](/ru/reference/data-types/int-uint)) — количество освобождений памяти.
* `nregs` ([Int64](/ru/reference/data-types/int-uint)) — количество регионов на slab.
* `curslabs` ([Int64](/ru/reference/data-types/int-uint)) — текущее количество slab.
* `curregs` ([Int64](/ru/reference/data-types/int-uint)) — текущее количество регионов для данного size class.
* `slab_size` ([UInt64](/ru/reference/data-types/int-uint)) — размер каждого slab в байтах. Ноль для крупных size classes, которые не основаны на slab.
* `nonfull_slabs` ([Int64](/ru/reference/data-types/int-uint)) — текущее количество slab, содержащих хотя бы один свободный регион. Ноль для крупных size classes.

**Псевдонимы:**

* `availregs` — псевдоним для `nregs * curslabs`.
* `util` — псевдоним для `curregs / availregs`.
* `waste` — псевдоним для `greatest((curslabs * slab_size) - (curregs * size), 0)`.
