## Описание {#description}

Показывает текущие активные [наблюдения](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches), зарегистрированные этим сервером ClickHouse на узлах ZooKeeper (включая вспомогательные экземпляры ZooKeeper). Каждая строка соответствует одному наблюдению.

**Доступность**

`system.zookeeper_watches` существует только при настроенном ClickHouse Keeper или ZooKeeper. На серверах, где ни то, ни другое не настроено, таблица отсутствует, и запросы к ней завершатся ошибкой `UNKNOWN_TABLE`.

## Столбцы {#columns}

* `zookeeper_name` ([String](/ru/reference/data-types/string)) — Имя подключения к ZooKeeper («default» для основного подключения или имя вспомогательного подключения).
* `create_time` ([DateTime](/ru/reference/data-types/datetime)) — Время создания наблюдения.
* `create_time_microseconds` ([DateTime64(6)](/ru/reference/data-types/datetime64)) — Время создания наблюдения с микросекундной точностью.
* `path` ([String](/ru/reference/data-types/string)) — Путь в ZooKeeper, за которым ведётся наблюдение.
* `session_id` ([Int64](/ru/reference/data-types/int-uint)) — Идентификатор сеанса подключения, зарегистрировавшего наблюдение.
* `request_xid` ([Int64](/ru/reference/data-types/int-uint)) — XID запроса, создавшего наблюдение.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/ru/reference/data-types/enum)) — Операция, создавшая наблюдение.
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/ru/reference/data-types/enum)) — Тип наблюдения: Children (list), Exists или Data (get).
