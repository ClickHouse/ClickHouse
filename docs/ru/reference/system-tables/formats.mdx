<div id="description">
  ## Описание
</div>

Содержит список всех форматов, а также флаги, указывающие, подходит ли тот или иной формат для ввода/вывода и поддерживает ли он распараллеливание.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ru/reference/data-types/string)) — Название формата.
* `is_input` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, подходит ли формат для ввода данных.
* `is_output` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, подходит ли формат для вывода данных.
* `supports_parallel_parsing` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли формат параллельный парсинг.
* `supports_parallel_formatting` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли формат параллельное форматирование.
* `is_tty_friendly` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, обычно ли формат корректно отображается в терминале. Для других форматов CLI запросит подтверждение перед выводом.
* `content_type` ([String](/ru/reference/data-types/string)) — HTTP Content-Type, соответствующий выходному формату. Может зависеть от текущих настроек формата.
* `supports_random_access` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли формат произвольный доступ к входным данным.
* `has_schema_inference` ([UInt8](/ru/reference/data-types/int-uint)) — Формат может динамически определять схему по данным: из встроенного заголовка или метаданных либо из фрагмента данных.
* `has_external_schema` ([UInt8](/ru/reference/data-types/int-uint)) — Формат либо имеет фиксированную схему, либо принимает заранее определённую схему в собственном формате.
* `prefers_large_blocks` ([UInt8](/ru/reference/data-types/int-uint)) — Формат записывает более крупные блоки при выводе и формирует более крупные блоки при вводе.
* `supports_append` ([UInt8](/ru/reference/data-types/int-uint)) — Этот формат позволяет добавлять данные в существующий файл.
* `supports_subsets_of_columns` ([UInt8](/ru/reference/data-types/int-uint)) — Входной формат может распознавать отсутствие отдельных столбцов.
* `description` ([String](/ru/reference/data-types/string)) — Общее описание формата.
* `examples` ([String](/ru/reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/reference/data-types/string)) — Версия ClickHouse, в которой формат был впервые представлен, в формате major.minor.
* `related` ([Array(String)](/ru/reference/data-types/array)) — Названия связанных форматов.
