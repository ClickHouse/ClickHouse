<div id="description">
  ## Описание
</div>

Использование квоты текущим пользователем: сколько использовано и сколько осталось.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ru/reference/data-types/string)) — Имя квоты.
* `quota_key` ([String](/ru/reference/data-types/string)) — Значение ключа.
* `start_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время начала расчёта потребления ресурсов.
* `end_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время окончания расчёта потребления ресурсов.
* `duration` ([Nullable(UInt32)](/ru/reference/data-types/nullable)) — Длительность временного интервала для расчёта потребления ресурсов в секундах.
* `queries` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее количество выполненных запросов.
* `max_queries` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое общее количество запросов всех типов.
* `query_selects` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее количество выполненных SELECT-запросов.
* `max_query_selects` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество SELECT-запросов.
* `query_inserts` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее количество выполненных INSERT-запросов.
* `max_query_inserts` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество INSERT-запросов.
* `errors` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее количество запросов, завершившихся ошибкой.
* `max_errors` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество запросов, завершившихся ошибкой, за указанный период времени.
* `result_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее общее количество строк в результирующих наборах всех запросов за текущий период времени.
* `max_result_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое общее количество строк в результирующих наборах всех запросов за указанный период времени.
* `result_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее общее количество байтов в результирующих наборах всех запросов за текущий период времени.
* `max_result_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое общее количество байтов в результирующих наборах всех запросов за указанный период времени.
* `read_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее общее количество строк, прочитанных при выполнении всех запросов за текущий период времени.
* `max_read_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество строк для чтения при выполнении всех запросов за указанный период времени.
* `read_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее общее количество байтов, прочитанных при выполнении всех запросов за текущий период времени.
* `max_read_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество байтов для чтения при выполнении всех запросов за указанный период времени.
* `execution_time` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Текущее общее время (в наносекундах), затраченное на выполнение запросов за текущий период времени
* `max_execution_time` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Максимально допустимое время (в наносекундах) для выполнения всех запросов за указанный период времени
* `written_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее общее количество байтов, записанных при выполнении всех запросов за текущий период времени.
* `max_written_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество байтов для записи при выполнении всех запросов за указанный период времени.
* `failed_sequential_authentications` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее количество последовательных неудачных попыток аутентификации за текущий период времени.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество последовательных неудачных попыток аутентификации за указанный период времени.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Текущее максимальное количество выполнений одного нормализованного запроса за текущий период времени.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимально допустимое количество выполнений одного нормализованного запроса за указанный период времени.
