Содержит все гипотетические (what-if) индексы пропуска данных, определённые в текущем сеансе. См. [`CREATE HYPOTHETICAL INDEX`](/ru/reference/statements/hypothetical-index#create-hypothetical-index) и [`EXPLAIN WHATIF`](/ru/reference/statements/explain#explain-whatif).

Содержимое привязано к сеансу: каждое соединение видит только свои гипотетические индексы, а если в текущем сеансе не был создан ни один индекс, таблица пуста.

Текущие `(database, table)` определяются по UUID во время выполнения запроса, поэтому они отражают `RENAME TABLE`, а строки для удалённых таблиц скрываются автоматически.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы
* `name` ([String](/ru/reference/data-types/string)) — Имя индекса
* `type` ([String](/ru/reference/data-types/string)) — Тип индекса (minmax, set, bloom&#95;filter и т. д.)
* `type_full` ([String](/ru/reference/data-types/string)) — Выражение типа индекса с аргументами, например bloom&#95;filter(0.01)
* `expression` ([String](/ru/reference/data-types/string)) — Выражение индекса
* `granularity` ([UInt64](/ru/reference/data-types/int-uint)) — Гранулярность индекса

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Пример
</div>

```sql
CREATE HYPOTHETICAL INDEX i1 ON t (b) TYPE bloom_filter(0.01)  GRANULARITY 1;
CREATE HYPOTHETICAL INDEX i2 ON t (b) TYPE bloom_filter(0.001) GRANULARITY 1;

SELECT database, table, name, type, type_full, expression, granularity
FROM system.hypothetical_indexes;
```

```text
┌─database─┬─table─┬─name─┬─type─────────┬─type_full───────────┬─expression─┬─granularity─┐
│ default  │ t     │ i1   │ bloom_filter │ bloom_filter(0.01)  │ b          │           1 │
│ default  │ t     │ i2   │ bloom_filter │ bloom_filter(0.001) │ b          │           1 │
└──────────┴───────┴──────┴──────────────┴─────────────────────┴────────────┴─────────────┘
```

`type` — это имя базового типа, а `type_full` содержит аргументы, поэтому пользователи могут различать параметризованные варианты, такие как `bloom_filter(0.01)` и `bloom_filter(0.001)`.
