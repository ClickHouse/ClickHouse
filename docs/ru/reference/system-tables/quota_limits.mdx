<div id="description">
  ## Описание
</div>

Содержит информацию о максимальных значениях для всех интервалов всех квот. Одной квоте может соответствовать любое число строк или ни одной.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ru/reference/data-types/string)) — Имя квоты.
* `duration` ([UInt32](/ru/reference/data-types/int-uint)) — Продолжительность временного интервала для расчёта потребления ресурсов в секундах.
* `is_randomized_interval` ([UInt8](/ru/reference/data-types/int-uint)) — Булево значение. Указывает, рандомизирован ли интервал. Если интервал не рандомизирован, он всегда начинается в одно и то же время. Например, интервал в 1 минуту всегда начинается в минуту с целым номером (то есть может начаться в 11:20:00, но никогда не начинается в 11:20:01), а интервал в один день всегда начинается в полночь по UTC. Если интервал рандомизирован, первый интервал начинается в случайный момент времени, а последующие интервалы идут один за другим. Значения: 0 — интервал не рандомизирован, 1 — интервал рандомизирован.
* `max_queries` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное допустимое количество запросов всех типов за указанный период времени.
* `max_query_selects` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное допустимое количество SELECT-запросов за указанный период времени.
* `max_query_inserts` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное допустимое количество INSERT-запросов за указанный период времени.
* `max_errors` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное допустимое количество запросов, завершившихся ошибкой, за указанный период времени.
* `max_result_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное суммарное количество строк в результирующих наборах всех запросов за указанный период времени.
* `max_result_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное суммарное количество байтов в результирующих наборах всех запросов за указанный период времени.
* `max_read_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное количество строк, которое можно прочитать при выполнении всех запросов за указанный период времени.
* `max_read_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное количество байтов, которое можно прочитать при выполнении всех запросов за указанный период времени.
* `max_execution_time` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Максимальное время (в наносекундах), отведённое на выполнение всех запросов за указанный период времени
* `max_written_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное количество байтов, которое можно записать при выполнении всех запросов за указанный период времени.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное допустимое количество последовательных неудачных попыток аутентификации за указанный период времени.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальное количество выполнений одного нормализованного запроса за указанный период времени.
