## Описание {#description}

Эта таблица выводит сводную диагностическую информацию о ZooKeeper, а список узлов берётся из конфигурации.

**Доступность**

`system.zookeeper_info` существует только тогда, когда настроен ClickHouse Keeper или ZooKeeper. На серверах, где не настроен ни один из них, таблица отсутствует, и запросы к ней завершатся ошибкой `UNKNOWN_TABLE`.

## Столбцы {#columns}

* `zookeeper_cluster_name` ([String](/ru/reference/data-types/string)) — имя кластера ZooKeeper.
* `host` ([String](/ru/reference/data-types/string)) — hostname/IP узла ZooKeeper, к которому подключился ClickHouse.
* `port` ([UInt16](/ru/reference/data-types/int-uint)) — порт узла ZooKeeper, к которому подключился ClickHouse.
* `index` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — индекс узла ZooKeeper, к которому подключился ClickHouse. Индекс берётся из конфигурации ZooKeeper. Если соединение не установлено, этот столбец равен NULL.
* `is_connected` ([UInt8](/ru/reference/data-types/int-uint)) — установлено ли соединение с ZooKeeper.
* `is_readonly` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — режим только для чтения.
* `version` ([Nullable(String)](/ru/reference/data-types/nullable)) — версия ZooKeeper.
* `avg_latency` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — средняя latency.
* `max_latency` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — максимальная latency.
* `min_latency` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — минимальная latency.
* `packets_received` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество полученных packets.
* `packets_sent` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество отправленных packets.
* `outstanding_requests` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество необработанных requests.
* `server_state` ([Nullable(String)](/ru/reference/data-types/nullable)) — состояние сервера.
* `is_leader` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — является ли этот ZooKeeper leader.
* `znode_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество znode.
* `watch_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество наблюдений.
* `ephemerals_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество эфемерных узлов.
* `approximate_data_size` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — приблизительный размер данных.
* `followers` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — followers данного leader. Это поле предоставляется только leader.
* `synced_followers` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — синхронизированные followers данного leader. Это поле предоставляется только leader.
* `pending_syncs` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — ожидающие синхронизации у leader. Это поле предоставляется только leader.
* `open_file_descriptor_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество открытых file descriptor. Доступно только на платформах Unix.
* `max_file_descriptor_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — максимальное количество file descriptor. Доступно только на платформах Unix.
* `connections` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — соединения с ZooKeeper.
* `outstanding` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество необработанных операций ZooKeeper.
* `zxid` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — zxid ZooKeeper.
* `node_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — количество узлов в ZooKeeper.
* `snapshot_dir_size` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — размер каталога снимков ZooKeeper.
* `log_dir_size` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — размер каталога log ZooKeeper.
* `first_log_idx` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — индекс первой записи log ZooKeeper.
* `first_log_term` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — term первой записи log ZooKeeper.
* `last_log_idx` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — индекс последней записи log ZooKeeper.
* `last_log_term` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — term последней записи log ZooKeeper.
* `last_committed_idx` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — индекс последней зафиксированной записи ZooKeeper.
* `leader_committed_log_idx` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — индекс зафиксированной записи log у leader ZooKeeper.
* `target_committed_log_idx` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — целевой индекс зафиксированной записи log ZooKeeper.
* `last_snapshot_idx` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — индекс последнего снимка ZooKeeper.
