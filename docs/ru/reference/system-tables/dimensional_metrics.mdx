## Описание {#description}

Эта таблица содержит размерные метрики, которые можно вычислить мгновенно и экспортировать в формате Prometheus. Она всегда актуальна.

## Описания метрик {#metric_descriptions}

### merge_failures {#merge_failures}

Общее количество неудачных слияний с момента запуска.

### startup_scripts_failure_reason {#startup_scripts_failure_reason}

Указывает на сбои скриптов запуска по типу ошибки. При сбое скрипта запуска принимает значение 1 и помечается именем ошибки.

### merge_tree_parts {#merge_tree_parts}

Количество частей данных MergeTree с метками состояния части, типа части и признака того, является ли она частью проекции.

### `filesystem_cache_evictions_total` {#filesystem-cache-evictions-total}

Количество сегментов файла, вытесненных из файлового кэша, с меткой имени кэша. По умолчанию отключено; включается с помощью `expose_prometheus_eviction_metrics`.

### `filesystem_cache_evicted_bytes_total` {#filesystem-cache-evicted-bytes-total}

Общее количество байтов сегментов файла, вытесненных из файлового кэша, с меткой имени кэша. Отключено по умолчанию; включите с помощью `expose_prometheus_eviction_metrics`.

### `filesystem_cache_evictions_by_user_total` {#filesystem-cache-evictions-by-user-total}

Количество сегментов файла, вытесненных из файлового кэша, с метками «имя кэша» и «идентификатор пользователя». Отключено по умолчанию; включите с помощью `expose_prometheus_eviction_metrics` и `expose_prometheus_eviction_metrics_per_user`.

### `filesystem_cache_evicted_bytes_by_user_total` {#filesystem-cache-evicted-bytes-by-user-total}

Общее количество байтов сегментов файла, вытесненных из файлового кэша, с метками имени кэша и идентификатора пользователя. По умолчанию отключено; включите с помощью `expose_prometheus_eviction_metrics` и `expose_prometheus_eviction_metrics_per_user`.

### `object_storage_queue_failures_total` {#object-storage-queue-failures-total}

Количество сбоев `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) с метками базы данных, таблицы, стадии обработки (`read`, `set_processing`, `insert`, `commit`, `after_processing`) и кода ошибки. Для стадии `after_processing` значение равно количеству объектов, для которых действие `after_processing` (удаление, установка метки или перемещение) не завершилось.

### `object_storage_queue_permanently_failed_files_total` {#object-storage-queue-permanently-failed-files-total}

Количество файлов `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), обработка которых была окончательно прекращена после исчерпания попыток повтора (или при отключённых повторах), с метками базы данных и таблицы. Каждый такой файл содержит данные, которые никогда не будут обработаны.

### `object_storage_queue_newest_seen_object_timestamp_seconds` {#object-storage-queue-newest-seen-object-timestamp-seconds}

Unix-временная метка последнего изменения самого нового объекта, обнаруженного к настоящему моменту таблицей `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), с метками базы данных и таблицы. Серия удаляется при удалении или отсоединении таблицы. После переименования серия со старым именем сохраняется до перезапуска сервера.

### `object_storage_queue_newest_committed_object_timestamp_seconds` {#object-storage-queue-newest-committed-object-timestamp-seconds}

Unix-временная метка времени последнего изменения новейшего объекта, полностью обработанного на данный момент таблицей `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), с метками базы данных и таблицы. Серия удаляется при удалении или отсоединении таблицы. После переименования таблицы серия со старым именем сохраняется до перезапуска сервера.

### `object_storage_queue_processed_files_total` {#object-storage-queue-processed-files-total}

Количество файлов, закоммиченных как обработанные этой таблицей `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) на данном сервере, с метками базы данных и таблицы.

### `object_storage_queue_last_poll_timestamp_seconds` {#object-storage-queue-last-poll-timestamp-seconds}

Unix-временная метка момента, когда фоновый поток стриминга таблицы `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) на этом сервере в последний раз начал цикл поиска файлов для обработки или очередной пакет этого цикла; с метками базы данных и таблицы. Значение устанавливается в начале цикла (после того как таблица зарегистрировалась в Keeper как активная) и повторно перед каждым пакетом цикла, поэтому оно увеличивается и тогда, когда цикл не находит файлов или завершается с ошибкой, а также при длительном отставании обработки. Если регистрация не удалась, значение не увеличивается. Значение 0 означает, что таблица не выполняла опрос с момента запуска. Значение также не увеличивается, пока у таблицы нет готовых подключённых materialized view, пока стриминг остановлен или приостановлен либо отключён на сервере, поскольку в это время таблица не читает и не обрабатывает данные. Все потоки стриминга таблицы записывают одну и ту же серию, поэтому она отражает самый последний цикл любого из них. Серия удаляется при удалении или отсоединении таблицы. После переименования серия со старым именем сохраняется до перезапуска сервера.

### `system_log_flushes_total` {#system-log-flushes-total}

Количество попыток сбросить буфер системного журнала в оперативной памяти в его таблицу, с метками базы данных и таблицы системного журнала, а также результата (`success`, `failure`).

### `system_log_flushed_rows_total` {#system-log-flushed-rows-total}

Количество строк, записанных при успешных сбросах на диск системного журнала, с метками базы данных и таблицы этого системного журнала.

### `system_log_dropped_rows_total` {#system-log-dropped-rows-total}

Количество потерянных строк системного журнала с метками базы данных и таблицы системного журнала, а также причины: `queue_full` — для строк, которые не были приняты, поскольку буфер в оперативной памяти достиг предела `max_size_rows` (значение обновляется, когда буфер забирается для очередного сброса на диск), `flush_failed` — для строк, сброс которых на диск завершился ошибкой.

## Столбцы {#columns}

* `metric` ([String](/ru/reference/data-types/string)) — Имя метрики.
* `value` ([Float64](/ru/reference/data-types/float)) — Значение метрики.
* `description` ([String](/ru/reference/data-types/string)) — Описание метрики.
* `labels` ([Map(String, String)](/ru/reference/data-types/map)) — Метки метрики.

**Псевдонимы:**

* `name` — Псевдоним для `metric`.

## Пример {#example}

С помощью такого запроса можно экспортировать все размерные метрики в формате Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```
