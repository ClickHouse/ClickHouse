## Описание

Показывает символизированный профиль кучи jemalloc. Сначала выполните &#39;SYSTEM JEMALLOC FLUSH PROFILE&#39;, чтобы создать профиль.

## Столбцы

* `line` ([String](/ru/reference/data-types/string)) — Строка символизированного профиля кучи jemalloc.
