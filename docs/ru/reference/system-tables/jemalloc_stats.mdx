## Описание {#description}

Возвращает статистику jemalloc в виде одной строки с одним столбцом. Соответствует команде SYSTEM JEMALLOC STATS.

## Столбцы {#columns}

* `stats` ([String](/ru/reference/data-types/string)) — вывод статистики JEMalloc, полученный из malloc&#95;stats&#95;print.
