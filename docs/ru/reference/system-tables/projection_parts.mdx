<div id="description">
  ## Описание
</div>

Эта таблица содержит информацию о частях проекций таблиц семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types/string)) — Имя партиции.
* `name` ([String](/ru/reference/data-types/string)) — Имя части данных.
* `part_type` ([String](/ru/reference/data-types/string)) — Формат хранения части данных. Возможные значения: Wide (отдельный файл для каждого столбца) и Compact (один файл для всех столбцов).
* `parent_name` ([String](/ru/reference/data-types/string)) — Имя исходной (родительской) части данных.
* `parent_uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID исходной (родительской) части данных.
* `parent_part_type` ([String](/ru/reference/data-types/string)) — Формат хранения исходной (родительской) части данных.
* `active` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, активна ли часть данных. Активная часть данных используется в таблице; неактивная будет удалена. Неактивные части данных появляются после операций слияния и мутации.
* `marks` ([UInt64](/ru/reference/data-types/int-uint)) — Количество меток. Чтобы приблизительно определить количество строк в части данных, умножьте число меток на гранулярность индекса (обычно 8192). Это правило не работает при адаптивной гранулярности.
* `rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в части данных. Вспомогательные файлы, например файлы с метками, не учитываются.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в части данных. Вспомогательные файлы, например файлы с метками, не учитываются.
* `marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками.
* `parent_marks` ([UInt64](/ru/reference/data-types/int-uint)) — Количество меток в исходной (родительской) части.
* `parent_rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк в исходной (родительской) части.
* `parent_bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов исходной (родительской) части данных в байтах.
* `parent_data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в исходной (родительской) части данных.
* `parent_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в исходной (родительской) части данных.
* `parent_marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками в исходной (родительской) части данных.
* `modification_time` ([DateTime](/ru/reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно оно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/reference/data-types/datetime)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/reference/data-types/int-uint)) — Количество мест использования части данных. Значение больше 2 указывает, что часть данных используется в запросах или слияниях.
* `min_date` ([Date](/ru/reference/data-types/date)) — Минимальное значение ключа даты в части данных.
* `max_date` ([Date](/ru/reference/data-types/date)) — Максимальное значение ключа даты в части данных.
* `min_time` ([DateTime](/ru/reference/data-types/datetime)) — Минимальное значение ключа даты и времени в части данных.
* `max_time` ([дата и время](/ru/reference/data-types/datetime)) — Максимальное значение ключа даты и времени в части данных.
* `partition_id` ([String](/ru/reference/data-types/string)) — Идентификатор партиции.
* `min_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Минимальный номер частей данных, образующих текущую часть после слияния.
* `max_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Максимальный номер частей данных, образующих текущую часть после слияния.
* `level` ([UInt32](/ru/reference/data-types/int-uint)) — Глубина дерева слияния. Ноль означает, что текущая часть создана вставкой, а не слиянием других частей.
* `data_version` ([UInt64](/ru/reference/data-types/int-uint)) — Номер, используемый для определения мутаций, которые следует применить к части данных (мутаций с версией выше data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), используемый значениями первичного ключа.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), зарезервированный для значений первичного ключа.
* `is_frozen` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий на наличие резервной копии данных партиции. 1 — резервная копия существует. 0 — резервная копия отсутствует.
* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `engine` ([String](/ru/reference/data-types/string)) — Имя движка таблицы без параметров.
* `disk_name` ([String](/ru/reference/data-types/string)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/reference/data-types/string)) — Абсолютный путь к папке с файлами части данных.
* `hash_of_all_files` ([String](/ru/reference/data-types/string)) — sipHash128 сжатых файлов.
* `hash_of_uncompressed_files` ([String](/ru/reference/data-types/string)) — sipHash128 несжатых файлов (файлов с метками, файлом индекса и т. д.).
* `uncompressed_hash_of_compressed_files` ([String](/ru/reference/data-types/string)) — sipHash128 данных в сжатых файлах, как если бы они были несжатыми.
* `delete_ttl_info_min` ([дата и время](/ru/reference/data-types/datetime)) — Минимальное значение ключа даты и времени для правила TTL DELETE.
* `delete_ttl_info_max` ([дата и время](/ru/reference/data-types/datetime)) — Максимальное значение ключа даты и времени для правила TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — Массив выражений. Каждое выражение определяет правило TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Массив значений даты и времени. Каждый элемент описывает минимальное значение ключа для правила TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Массив значений даты и времени. Каждый элемент описывает максимальное значение ключа для правила TTL MOVE.
* `default_compression_codec` ([String](/ru/reference/data-types/string)) — Имя кодека, используемого для сжатия этой части данных, если для столбцов не указан явный кодек.
* `recompression_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — TTL-выражение.
* `recompression_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется для определения наличия хотя бы одной строки с истёкшим TTL.
* `recompression_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, истёк ли TTL у всех строк.
* `group_by_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — TTL-выражение.
* `group_by_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли хотя бы одна строка с истёкшим TTL.
* `group_by_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, истёк ли TTL у всех строк.
* `rows_where_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — TTL-выражение.
* `rows_where_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли хотя бы одна строка с истёкшим TTL.
* `rows_where_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, истёк ли TTL у всех строк.
* `is_broken` ([UInt8](/ru/reference/data-types/int-uint)) — Указывает, повреждена ли часть проекции.
* `exception_code` ([Int32](/ru/reference/data-types/int-uint)) — Сообщение об исключении, поясняющее состояние повреждённой части проекции.
* `exception` ([String](/ru/reference/data-types/string)) — Код исключения, поясняющий состояние повреждённой части проекции.

**Псевдонимы:**

* `bytes` — псевдоним для `bytes_on_disk`.
* `marks_size` — псевдоним для `marks_bytes`.
* `part_name` — псевдоним для `name`.
