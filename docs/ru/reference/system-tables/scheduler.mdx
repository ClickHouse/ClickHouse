<div id="description">
  ## Описание
</div>

Содержит информацию о [узлах планировщика](/ru/concepts/features/configuration/server-config/workload-scheduling#hierarchy), находящихся на локальном сервере, и их статусе.
Эту таблицу можно использовать для мониторинга. Таблица содержит по одной строке для каждого узла планировщика.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `resource` ([String](/ru/reference/data-types/string)) — Имя ресурса
* `path` ([String](/ru/reference/data-types/string)) — Путь к узлу планировщика в иерархии планирования этого ресурса
* `type` ([String](/ru/reference/data-types/string)) — Тип узла планировщика.
* `weight` ([Float64](/ru/reference/data-types/float)) — Вес узла, используемый родительским узлом типа `fair`.
* `priority` ([Int64](/ru/reference/data-types/int-uint)) — Приоритет узла, используемый родительским узлом типа &#39;priority&#39; (меньшее значение означает более высокий приоритет).
* `precedence` ([Int64](/ru/reference/data-types/int-uint)) — Старшинство узла, используемое родительскими узлами с разделением по пространству (память) для определения порядка допуска и вытеснения (меньшее значение означает более высокое старшинство).
* `is_active` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — Активен ли этот узел в данный момент: есть ли запросы ресурсов для извлечения из очереди и выполнены ли ограничения.
* `active_children` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Количество дочерних узлов в активном состоянии.
* `dequeued_requests` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество запросов ресурсов, извлечённых из очереди этого узла.
* `canceled_requests` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество отменённых запросов ресурсов этого узла.
* `rejected_requests` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество отклонённых запросов ресурсов этого узла.
* `dequeued_cost` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Сумма стоимостей (например, размера в байтах) всех запросов, извлечённых из очереди этого узла.
* `canceled_cost` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Сумма стоимостей (например, размера в байтах) всех отменённых запросов этого узла.
* `rejected_cost` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Сумма стоимостей (например, размера в байтах) всех отклонённых запросов этого узла.
* `busy_periods` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество деактиваций этого узла.
* `throughput` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Текущая средняя пропускная способность (стоимость извлечённых из очереди запросов в секунду).
* `vruntime` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Только для дочерних узлов `fair`. Виртуальное время выполнения узла, используемое алгоритмом SFQ для выбора следующего дочернего узла для обработки с соблюдением максиминной справедливости.
* `system_vruntime` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Только для узлов `fair`. Виртуальное время выполнения, соответствующее `vruntime` последнего обработанного запроса ресурса. Используется при активации дочернего узла как новое значение `vruntime`.
* `queue_length` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов `fifo`. Текущее количество запросов ресурсов в очереди.
* `queue_cost` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `fifo`. Сумма стоимостей (например, размера в байтах) всех запросов в очереди.
* `budget` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `fifo`. Количество доступных &#39;единиц стоимости&#39; для новых запросов ресурсов. Может появляться при расхождении между расчётной и фактической стоимостью запросов ресурсов (например, после сбоя чтения/записи)
* `is_satisfied` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — Только для узлов ограничений (например, `inflight_limit`). Равно `1`, если все ограничения этого узла выполнены.
* `inflight_requests` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `inflight_limit`. Количество запросов ресурсов, извлечённых из очереди этого узла и находящихся в состоянии использования.
* `inflight_cost` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `inflight_limit`. Сумма стоимостей (например, в байтах) всех запросов ресурсов, извлечённых из очереди этого узла и находящихся в состоянии использования.
* `max_requests` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `inflight_limit`. Верхний предел `inflight&#95;requests`, при котором происходит нарушение ограничения.
* `max_cost` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `inflight_limit`. Верхний предел inflight&#95;cost, при превышении которого нарушается ограничение.
* `max_speed` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Верхний предел пропускной способности в токенах в секунду.
* `max_burst` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Верхний предел количества токенов, доступных в ограничителе token-bucket.
* `throttling_us` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Общее количество микросекунд, в течение которых этот узел находился в состоянии ограничения скорости.
* `tokens` ([Nullable(Float64)](/ru/reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Количество токенов, доступных в данный момент в ограничителе token-bucket.
* `allocated` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Текущий объём ресурса, выделенный в этом узле.
* `allocations` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Текущее число активных выделений ресурса в этом узле.
* `updates` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число обновлений, переданных через этот узел.
* `increases` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число запросов на увеличение, одобренных этим узлом.
* `decreases` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число запросов на уменьшение, одобренных этим узлом.
* `admits` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число выделений, одобренных этим узлом.
* `removes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число выделений, удалённых из этого узла.
* `killers` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число вытеснений, инициированных этим узлом в связи с запросами на увеличение.
* `victims` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов с разделением по пространству. Общее число выделений, вытесненных из этого узла.
* `rejects` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов `allocation_queue`. Общее число выделений ресурса, отклонённых этим узлом.
* `pending` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Только для узлов `allocation_queue`. Текущее число ожидающих выделений ресурса в этом узле.

{/*AUTOGENERATED_END*/}
