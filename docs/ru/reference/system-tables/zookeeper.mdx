## Описание {#description}

Таблица существует только при настроенном ClickHouse Keeper или ZooKeeper. Таблица `system.zookeeper` предоставляет данные из кластеров Keeper, определённых в конфигурации.
Запрос должен содержать либо условие `path =`, либо условие `path IN` в предложении `WHERE`, как показано ниже. Это путь к дочерним узлам, данные которых вы хотите получить.

Запрос `SELECT * FROM system.zookeeper WHERE path = '/clickhouse'` выводит данные для всех дочерних узлов `/clickhouse`.
Чтобы вывести данные для всех корневых узлов, укажите path = &#39;/&#39;.
Если путь, указанный в `path`, не существует, будет сгенерировано исключение.

Запрос `SELECT * FROM system.zookeeper WHERE path IN ('/', '/clickhouse')` выводит данные для всех дочерних узлов узлов `/` и `/clickhouse`.
Если какой-либо путь, указанный в коллекции `path`, не существует, будет сгенерировано исключение.
Это можно использовать для выполнения батча запросов к путям Keeper.

Запрос `SELECT * FROM system.zookeeper WHERE path = '/clickhouse' AND zookeeperName = 'auxiliary_cluster'` выводит данные из кластера ZooKeeper `auxiliary_cluster`.
Если указанный `auxiliary_cluster` не существует, будет сгенерировано исключение.

## Столбцы {#columns}

* `name` ([String](/ru/reference/data-types/string)) — имя узла.
* `value` ([String](/ru/reference/data-types/string)) — значение узла.
* `zookeeperName` ([String](/ru/reference/data-types/string)) — имя основного или одного из вспомогательных кластеров ZooKeeper.
* `czxid` ([Int64](/ru/reference/data-types/int-uint)) — ID транзакции, создавшей узел.
* `mzxid` ([Int64](/ru/reference/data-types/int-uint)) — ID транзакции, последней изменившей узел.
* `ctime` ([DateTime](/ru/reference/data-types/datetime)) — время создания узла.
* `mtime` ([DateTime](/ru/reference/data-types/datetime)) — время последнего изменения узла.
* `version` ([Int32](/ru/reference/data-types/int-uint)) — версия узла: сколько раз узел изменялся.
* `cversion` ([Int32](/ru/reference/data-types/int-uint)) — количество добавленных или удалённых потомков.
* `aversion` ([Int32](/ru/reference/data-types/int-uint)) — количество изменений ACL.
* `ephemeralOwner` ([Int64](/ru/reference/data-types/int-uint)) — для эфемерных узлов — ID сеанса, которому принадлежит этот узел.
* `dataLength` ([Int32](/ru/reference/data-types/int-uint)) — размер значения.
* `numChildren` ([Int32](/ru/reference/data-types/int-uint)) — количество потомков.
* `pzxid` ([Int64](/ru/reference/data-types/int-uint)) — ID транзакции, последней удалившей или добавившей потомков.
* `path` ([String](/ru/reference/data-types/string)) — путь к узлу.
