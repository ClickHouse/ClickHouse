## Описание {#description}

Содержит список поддерживаемых сервером движков баз данных.

## Столбцы {#columns}

* `name` ([String](/ru/reference/data-types/string)) — Название движка базы данных.
* `description` ([String](/ru/reference/data-types/string)) — Общее описание того, что делает этот движок базы данных.
* `syntax` ([String](/ru/reference/data-types/string)) — Как движок базы данных указывается в предложении ENGINE запроса CREATE DATABASE.
* `examples` ([String](/ru/reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/reference/data-types/string)) — Версия ClickHouse, в которой этот движок базы данных был впервые представлен, в формате major.minor.
* `related` ([Array(String)](/ru/reference/data-types/array)) — Названия связанных движков баз данных.

## Пример {#example}

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

```text title="Response"
┌─name─────┐
│ Atomic   │
│ Ordinary │
└──────────┘
```
