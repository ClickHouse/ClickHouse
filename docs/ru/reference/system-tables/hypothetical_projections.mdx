Содержит список всех гипотетических (what-if) проекций, определённых в текущем сеансе. См. [`CREATE HYPOTHETICAL PROJECTION`](/ru/reference/statements/hypothetical-projection#create-hypothetical-projection) и [`EXPLAIN WHATIF`](/ru/reference/statements/explain#explain-whatif).

Содержимое ограничено рамками сеанса: каждое соединение видит только свои гипотетические проекции, а если в текущем сеансе ни одной проекции не создано, таблица пуста.

Текущие значения `(database, table)` определяются по UUID во время выполнения запроса, поэтому они учитывают `RENAME TABLE`, а записи для удалённых таблиц скрываются автоматически.

## Столбцы {#columns}

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — имя базы данных
* `table` ([String](/ru/reference/data-types/string)) — имя таблицы
* `name` ([String](/ru/reference/data-types/string)) — имя проекции
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ru/reference/data-types/enum)) — тип проекции
* `sorting_key` ([Array(String)](/ru/reference/data-types/array)) — ключ сортировки проекции
* `query` ([String](/ru/reference/data-types/string)) — SELECT-запрос проекции; пустой для формы INDEX ... TYPE ...
* `definition` ([String](/ru/reference/data-types/string)) — полное объявление проекции в исходном виде
* `settings` ([Map(String, String)](/ru/reference/data-types/map)) — настройки проекции из WITH SETTINGS

{/*AUTOGENERATED_END*/}

**Пример**

```sql
CREATE HYPOTHETICAL PROJECTION p_by_b ON t (SELECT a, b ORDER BY b);
SELECT name, type, sorting_key FROM system.hypothetical_projections;
```

```text
┌─name───┬─type───┬─sorting_key─┐
│ p_by_b │ Normal │ ['b']       │
└────────┴────────┴─────────────┘
```
