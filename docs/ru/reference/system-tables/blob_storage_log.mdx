## Описание {#description}

Содержит записи журнала с информацией о различных операциях объектного хранилища, таких как загрузка и удаление.

Эту таблицу можно в любой момент безопасно усечь (TRUNCATE) или удалить (DROP).

## Столбцы {#columns}

* `hostname` ([LowCardinality(String)](/ru/reference/data-types/lowcardinality)) — Имя хоста сервера, выполняющего запрос.
* `clickhouse_version` ([LowCardinality(String)](/ru/reference/data-types/lowcardinality)) — Версия сервера ClickHouse, создавшего строку.
* `system_processor` ([LowCardinality(String)](/ru/reference/data-types/lowcardinality)) — Архитектура CPU сервера ClickHouse, создавшего строку.
* `event_date` ([Date](/ru/reference/data-types/date)) — Дата события.
* `event_time` ([DateTime](/ru/reference/data-types/datetime)) — Время события.
* `event_time_microseconds` ([DateTime64(6)](/ru/reference/data-types/datetime64)) — Время события с точностью до микросекунд.
* `event_type` ([Enum8(&#39;Upload&#39; = 1, &#39;Delete&#39; = 2, &#39;MultiPartUploadCreate&#39; = 3, &#39;MultiPartUploadWrite&#39; = 4, &#39;MultiPartUploadComplete&#39; = 5, &#39;MultiPartUploadAbort&#39; = 6, &#39;Read&#39; = 7, &#39;Copy&#39; = 8)](/ru/reference/data-types/enum)) — Тип события. Возможные значения: &#39;Upload&#39;, &#39;Delete&#39;, &#39;MultiPartUploadCreate&#39;, &#39;MultiPartUploadWrite&#39;, &#39;MultiPartUploadComplete&#39;, &#39;MultiPartUploadAbort&#39;, &#39;Read&#39;, &#39;Copy&#39;
* `query_id` ([String](/ru/reference/data-types/string)) — Идентификатор запроса, связанного с событием, если применимо.
* `thread_id` ([UInt64](/ru/reference/data-types/int-uint)) — Идентификатор потока, выполняющего операцию.
* `thread_name` ([String](/ru/reference/data-types/string)) — Имя потока, выполняющего операцию.
* `disk_name` ([LowCardinality(String)](/ru/reference/data-types/lowcardinality)) — Имя соответствующего диска.
* `bucket` ([String](/ru/reference/data-types/string)) — Имя бакета.
* `remote_path` ([String](/ru/reference/data-types/string)) — Путь к удалённому ресурсу.
* `local_path` ([String](/ru/reference/data-types/string)) — Путь к файлу метаданных в локальной системе, который ссылается на удалённый ресурс.
* `source_bucket` ([String](/ru/reference/data-types/string)) — Для события &#39;Copy&#39; — имя бакета, из которого был скопирован объект. Для остальных событий пусто.
* `source_remote_path` ([String](/ru/reference/data-types/string)) — Для события &#39;Copy&#39; — путь к объекту, из которого были скопированы данные. Для остальных событий пусто.
* `data_size` ([UInt64](/ru/reference/data-types/int-uint)) — Размер данных, затронутых операцией.
* `elapsed_microseconds` ([UInt64](/ru/reference/data-types/int-uint)) — Время, затраченное на операцию, в микросекундах.
* `connection_id` ([UInt64](/ru/reference/data-types/int-uint)) — Идентификатор HTTP-соединения, через которое выполнялась операция; уникален в пределах процесса сервера. Группируйте по этому столбцу, чтобы отследить отдельное соединение: ОС повторно использует порты и inode сокетов сразу после закрытия сокета, поэтому по ним невозможно различить последовательные соединения. 0, если строку нельзя сопоставить с одним конкретным HTTP-запросом: операция не использовала HTTP-соединение; использовала несколько соединений — повторно выполненная запись регистрируется одной строкой, затраченное время в которой охватывает все попытки, и ни одно отдельное соединение её не описывает; или использовала один запрос совместно с другими строками — пакетное удаление записывает по одной строке `Delete` на каждый объект и привязывает соединение только к первой из них. Все столбцы `connection_*` имеют смысл только при ненулевом `connection_id`; в противном случае все они равны 0.
* `connection_local_port` ([UInt16](/ru/reference/data-types/int-uint)) — Локальный TCP-порт этого соединения. Уникален только среди сокетов, открытых в один и тот же момент; используйте его для сопоставления с дампом пакетов или строкой /proc/net/tcp, снятыми в тот же момент.
* `connection_socket_inode` ([UInt64](/ru/reference/data-types/int-uint)) — Inode сокета этого соединения, полученный через fstat. Та же оговорка, что и для порта: уникален, только пока сокет открыт. 0, если ОС не предоставляет inode для сокетов (как в macOS).
* `connection_requests` ([UInt32](/ru/reference/data-types/int-uint)) — Количество запросов, отправленных через это соединение до текущего. 0 означает, что это был первый запрос через соединение (при условии, что `connection_id` не равен 0).
* `connection_age_microseconds` ([UInt64](/ru/reference/data-types/int-uint)) — Время, прошедшее с момента установления TCP-сокета соединения. Сбрасывается при каждом переподключении, поэтому отражает время жизни сокета, а не объекта сеанса.
* `connection_idle_microseconds` ([UInt64](/ru/reference/data-types/int-uint)) — Время, в течение которого соединение бездействовало в пуле, прежде чем было выдано для этой операции. Равно 0 при первом запросе через соединение, а также если `connection_id` равен 0.
* `error_code` ([Int32](/ru/reference/data-types/int-uint)) — Код ошибки операции. 0, если ошибки не было.
* `error` ([String](/ru/reference/data-types/string)) — Сообщение об ошибке, связанное с событием, если применимо.

## Пример {#example}

Предположим, что в объектное хранилище загружается файл и при этом записывается событие:

```sql
SELECT * FROM system.blob_storage_log WHERE query_id = '7afe0450-504d-4e4b-9a80-cd9826047972' ORDER BY event_date, event_time_microseconds \G
```

```text
Row 1:
──────
hostname:                clickhouse.eu-central1.internal
event_date:              2023-10-31
event_time:              2023-10-31 16:03:40
event_time_microseconds: 2023-10-31 16:03:40.481437
event_type:              Upload
query_id:                7afe0450-504d-4e4b-9a80-cd9826047972
thread_id:               2381740
disk_name:               disk_s3
bucket:                  bucket1
remote_path:             rrr/kxo/tbnqtrghgtnxkzgtcrlutwuslgawe
local_path:              store/654/6549e8b3-d753-4447-8047-d462df6e6dbe/tmp_insert_all_1_1_0/checksums.txt
data_size:               259
error:
```

В этом примере операция загрузки была связана с запросом `INSERT` с идентификатором `7afe0450-504d-4e4b-9a80-cd9826047972`. Локальный файл метаданных `store/654/6549e8b3-d753-4447-8047-d462df6e6dbe/tmp_insert_all_1_1_0/checksums.txt` указывает на удалённый путь `rrr/kxo/tbnqtrghgtnxkzgtcrlutwuslgawe` в бакете `bucket1` на диске `disk_s3`; его размер составляет 259 байт.
