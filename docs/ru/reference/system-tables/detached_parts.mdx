<div id="purpose">
  ## Описание
</div>

Содержит информацию об отсоединённых частях таблиц [MergeTree](/ru/reference/engines/table-engines/mergetree-family/mergetree). Столбец `reason` указывает, по какой причине часть была отсоединена.

Для частей, отсоединённых пользователем, причина не указана. Такие части можно подключить командой [ALTER TABLE ATTACH PARTITION|PART](/ru/reference/statements/alter/partition#attach-partitionpart).

Описание остальных столбцов см. в [system.parts](/ru/reference/system-tables/parts).

Если имя части некорректно, значения некоторых столбцов могут быть `NULL`. Такие части можно удалить командой [ALTER TABLE DROP DETACHED PART](/ru/reference/statements/alter/partition#drop-detached-partitionpart).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных, которой принадлежит эта часть.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы, которой принадлежит эта часть.
* `partition_id` ([Nullable(String)](/ru/reference/data-types/nullable)) — Идентификатор партиции, которой принадлежит эта часть.
* `name` ([String](/ru/reference/data-types/string)) — Имя части.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `modification_time` ([DateTime](/ru/reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно соответствует времени выполнения операции detach.
* `disk` ([String](/ru/reference/data-types/string)) — Имя диска, на котором хранится эта часть данных.
* `path` ([String](/ru/reference/data-types/string)) — Путь на диске к файлу этой части данных.
* `reason` ([Nullable(String)](/ru/reference/data-types/nullable)) — Причина отсоединения этой части.
* `min_block_number` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Минимальный номер частей данных, из которых состоит текущая часть после слияния.
* `max_block_number` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Максимальный номер частей данных, из которых состоит текущая часть после слияния.
* `level` ([Nullable(UInt32)](/ru/reference/data-types/nullable)) — Глубина дерева слияний. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
