<div id="description">
  ## Описание
</div>

Содержит сведения о [словарях](/ru/reference/statements/create/dictionary).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных, содержащей словарь, созданный DDL-запросом. Для других словарей — пустая строка.
* `name` ([String](/ru/reference/data-types/string)) — Имя словаря.
* `uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID словаря.
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/ru/reference/data-types/enum)) — Статус словаря. Возможные значения: NOT&#95;LOADED — словарь сейчас не загружен в память, LOADED — словарь успешно загружен, FAILED — словарь не удалось загрузить из-за ошибки, LOADING — словарь сейчас загружается, LOADED&#95;AND&#95;RELOADING — словарь успешно загружен и сейчас перезагружается (частые причины: запрос SYSTEM RELOAD DICTIONARY, тайм-аут, изменение конфигурации словаря), FAILED&#95;AND&#95;RELOADING — словарь не удалось загрузить из-за ошибки, и сейчас выполняется повторная загрузка.
* `origin` ([String](/ru/reference/data-types/string)) — Путь к файлу конфигурации, описывающему словарь.
* `type` ([String](/ru/reference/data-types/string)) — Тип размещения словаря. Хранение словарей в памяти.
* `key.names` ([Array(String)](/ru/reference/data-types/array)) — Массив имён ключей, предоставляемых словарём.
* `key.types` ([Array(String)](/ru/reference/data-types/array)) — Соответствующий массив типов ключей, предоставляемых словарём.
* `attribute.names` ([Array(String)](/ru/reference/data-types/array)) — Массив имён атрибутов, предоставляемых словарём.
* `attribute.types` ([Array(String)](/ru/reference/data-types/array)) — Соответствующий массив типов атрибутов, предоставляемых словарём.
* `bytes_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объём оперативной памяти, выделенной для словаря.
* `hierarchical_index_bytes_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объём оперативной памяти, выделенной для иерархического индекса.
* `query_count` ([UInt64](/ru/reference/data-types/int-uint)) — Число запросов с момента загрузки словаря или последней успешной перезагрузки.
* `hit_rate` ([Float64](/ru/reference/data-types/float)) — Для кэширующих словарей — процент обращений, при которых значение находилось в кэше.
* `found_rate` ([Float64](/ru/reference/data-types/float)) — Процент обращений, при которых значение было найдено.
* `element_count` ([UInt64](/ru/reference/data-types/int-uint)) — Число элементов, хранящихся в словаре.
* `load_factor` ([Float64](/ru/reference/data-types/float)) — Процент заполнения словаря (для хешированного словаря — процент заполнения хеш-таблицы).
* `source` ([String](/ru/reference/data-types/string)) — Текстовое описание источника данных словаря.
* `lifetime_min` ([UInt64](/ru/reference/data-types/int-uint)) — Минимальное время жизни словаря в памяти, по истечении которого ClickHouse пытается перезагрузить словарь (если задан invalidate&#95;query — только при его изменении). Указывается в секундах.
* `lifetime_max` ([UInt64](/ru/reference/data-types/int-uint)) — Максимальное время жизни словаря в памяти, по истечении которого ClickHouse пытается перезагрузить словарь (если задан invalidate&#95;query — только при его изменении). Указывается в секундах.
* `loading_start_time` ([DateTime](/ru/reference/data-types/datetime)) — Время начала загрузки словаря.
* `last_successful_update_time` ([DateTime](/ru/reference/data-types/datetime)) — Время окончания загрузки или обновления словаря. Помогает отслеживать проблемы с источниками данных словарей и выяснять их причины.
* `error_count` ([UInt64](/ru/reference/data-types/int-uint)) — Число ошибок с момента последней успешной загрузки. Помогает отслеживать проблемы с источниками данных словарей и выяснять их причины.
* `loading_duration` ([Float32](/ru/reference/data-types/float)) — Длительность загрузки словаря.
* `last_exception` ([String](/ru/reference/data-types/string)) — Текст ошибки, возникшей при создании или перезагрузке словаря, если создать словарь не удалось.
* `comment` ([String](/ru/reference/data-types/string)) — Текст комментария к словарю.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Пример
</div>

Настройте словарь:

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

Убедитесь, что словарь загружен.

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
