## Описание {#description}

Эта таблица содержит предупреждения о сервере ClickHouse.
Предупреждения одного типа объединяются в одно.
Например, если число N присоединённых баз данных превышает настраиваемый порог T, вместо N отдельных записей отображается одна запись с текущим значением N.
Если текущее значение опускается ниже порога, запись удаляется из таблицы.

Поведение таблицы определяется следующими настройками:

* [max&#95;table&#95;num&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/ru/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/ru/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## Столбцы {#columns}

* `message` ([String](/ru/reference/data-types/string)) — Предупреждающее сообщение, выданное сервером ClickHouse.
* `message_format_string` ([LowCardinality(String)](/ru/reference/data-types/lowcardinality)) — Строка формата, использованная для форматирования сообщения.

## Примеры {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
