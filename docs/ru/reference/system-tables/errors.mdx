## Описание {#description}

Содержит коды ошибок и число их срабатываний.

Чтобы показать все возможные коды ошибок, включая те, которые не срабатывали, установите параметр [system&#95;events&#95;show&#95;zero&#95;values](/ru/reference/settings/session-settings/system#system_events_show_zero_values) равным 1.

## Столбцы {#columns}

* `name` ([String](/ru/reference/data-types/string)) — Имя ошибки (errorCodeToName).
* `code` ([Int32](/ru/reference/data-types/int-uint)) — Код ошибки.
* `value` ([UInt64](/ru/reference/data-types/int-uint)) — Количество раз, когда произошла эта ошибка.
* `last_error_time` ([DateTime](/ru/reference/data-types/datetime)) — Время, когда произошла последняя ошибка.
* `last_error_message` ([String](/ru/reference/data-types/string)) — Сообщение о последней ошибке.
* `last_error_format_string` ([String](/ru/reference/data-types/string)) — Строка формата для последней ошибки.
* `last_error_trace` ([Array(UInt64)](/ru/reference/data-types/array)) — Трассировка стека последней ошибки. На платформах ELF, кроме FreeBSD, адреса внутри основного бинарного файла ClickHouse сохраняются как физические смещения в файле, а остальные адреса — как адреса виртуальной памяти внутри процесса сервера ClickHouse.
* `remote` ([UInt8](/ru/reference/data-types/int-uint)) — Удалённое исключение (то есть полученное в ходе одного из распределённых запросов).
* `query_id` ([String](/ru/reference/data-types/string)) — Идентификатор запроса, вызвавшего ошибку (если доступен).

Счётчики некоторых ошибок могут увеличиваться даже при успешном выполнении запроса. Не рекомендуется использовать эту таблицу для мониторинга сервера, если только вы не уверены, что соответствующая ошибка не может быть ложноположительной.

## Пример {#example}

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
