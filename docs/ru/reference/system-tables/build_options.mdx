## Описание {#description}

Содержит информацию о параметрах сборки сервера ClickHouse.

## Столбцы {#columns}

* `name` ([String](/ru/reference/data-types/string)) — Название параметра сборки.
* `value` ([String](/ru/reference/data-types/string)) — Значение параметра сборки.

## Пример {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
