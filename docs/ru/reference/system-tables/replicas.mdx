<div id="description">
  ## Описание
</div>

Содержит информацию и статус реплицируемых таблиц, расположенных на локальном сервере.
Эту таблицу можно использовать для мониторинга. Таблица содержит по одной строке для каждой таблицы Replicated*.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID таблицы.
* `engine` ([String](/ru/reference/data-types/string)) — Имя движка таблицы.
* `is_leader` ([UInt8](/ru/reference/data-types/int-uint)) — Является ли реплика лидером. Несколько реплик могут одновременно быть лидерами. Реплике можно запретить становиться лидером с помощью настройки merge&#95;tree replicated&#95;can&#95;become&#95;leader. Лидеры отвечают за планирование фоновых слияний. Обратите внимание, что запись можно выполнять в любую доступную реплику с сеансом в ZK независимо от того, является ли она лидером.
* `can_become_leader` ([UInt8](/ru/reference/data-types/int-uint)) — Может ли реплика быть лидером.
* `is_readonly` ([UInt8](/ru/reference/data-types/int-uint)) — Находится ли реплика в режиме только для чтения. Этот режим включается, если в конфигурации отсутствуют разделы ClickHouse Keeper, при неизвестной ошибке во время повторной инициализации сеансов в ClickHouse Keeper, а также во время повторной инициализации сеанса в ClickHouse Keeper.
* `readonly_start_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Временная метка перехода реплики в режим только для чтения. NULL, если реплика не находится в этом режиме.
* `is_session_expired` ([UInt8](/ru/reference/data-types/int-uint)) — Истёк ли сеанс с ClickHouse Keeper. По сути, то же самое, что и `is_readonly`.
* `future_parts` ([UInt32](/ru/reference/data-types/int-uint)) — Количество частей данных, которые появятся в результате ещё не выполненных INSERT или слияний.
* `parts_to_check` ([UInt32](/ru/reference/data-types/int-uint)) — Количество частей данных в очереди на проверку. Часть помещается в очередь проверки, если есть подозрение, что она может быть повреждена.
* `zookeeper_name` ([String](/ru/reference/data-types/string)) — Имя кластера [Zoo]Keeper (возможно, вспомогательного), где хранятся метаданные таблицы
* `zookeeper_path` ([String](/ru/reference/data-types/string)) — Путь к данным таблицы в ClickHouse Keeper.
* `replica_name` ([String](/ru/reference/data-types/string)) — Имя реплики в ClickHouse Keeper. У разных реплик одной таблицы разные имена.
* `replica_path` ([String](/ru/reference/data-types/string)) — Путь к данным реплики в ClickHouse Keeper. То же, что конкатенация &#39;zookeeper&#95;path/replicas/replica&#95;path&#39;.
* `columns_version` ([Int32](/ru/reference/data-types/int-uint)) — Номер версии структуры таблицы. Указывает, сколько раз выполнялась операция ALTER. Если у реплик разные версии, это означает, что некоторые из них ещё не выполнили все операции ALTER.
* `queue_size` ([UInt32](/ru/reference/data-types/int-uint)) — Размер очереди ожидающих выполнения операций. К ним относятся вставка блоков данных, слияния и некоторые другие действия. Обычно совпадает с future&#95;parts.
* `inserts_in_queue` ([UInt32](/ru/reference/data-types/int-uint)) — Количество ожидающих выполнения вставок блоков данных. Вставки обычно реплицируются довольно быстро. Если это число велико, значит, что-то не так.
* `merges_in_queue` ([UInt32](/ru/reference/data-types/int-uint)) — Количество слияний, ожидающих выполнения. Иногда слияния выполняются долго, поэтому это значение может оставаться больше нуля длительное время.
* `part_mutations_in_queue` ([UInt32](/ru/reference/data-types/int-uint)) — Количество мутаций, ожидающих выполнения.
* `queue_oldest_time` ([DateTime](/ru/reference/data-types/datetime)) — Если `queue_size` больше 0, показывает, когда в очередь была добавлена самая старая операция.
* `inserts_oldest_time` ([DateTime](/ru/reference/data-types/datetime)) — См. `queue_oldest_time`.
* `merges_oldest_time` ([DateTime](/ru/reference/data-types/datetime)) — См. `queue_oldest_time`.
* `part_mutations_oldest_time` ([DateTime](/ru/reference/data-types/datetime)) — См. `queue_oldest_time`.
* `oldest_part_to_get` ([String](/ru/reference/data-types/string)) — Имя части, которую нужно получить с других реплик; берётся из самой старой записи GET&#95;PARTS в очереди репликации.
* `oldest_part_to_merge_to` ([String](/ru/reference/data-types/string)) — Имя результирующей части, полученное из самой старой записи MERGE&#95;PARTS в очереди репликации.
* `oldest_part_to_mutate_to` ([String](/ru/reference/data-types/string)) — Имя результирующей части, полученное из самой старой записи MUTATE&#95;PARTS в очереди репликации.
* `log_max_index` ([UInt64](/ru/reference/data-types/int-uint)) — Максимальный номер записи в журнале общей активности. Этот и следующие три столбца (`log_pointer`, `total_replicas`, `active_replicas`) имеют ненулевое значение только при наличии активного сеанса с ClickHouse Keeper.
* `log_pointer` ([UInt64](/ru/reference/data-types/int-uint)) — Максимальный номер записи в журнале общей активности, скопированной репликой в очередь выполнения, плюс один. Если log&#95;pointer значительно меньше log&#95;max&#95;index, это указывает на проблему.
* `last_queue_update` ([DateTime](/ru/reference/data-types/datetime)) — Время последнего обновления очереди.
* `absolute_delay` ([UInt64](/ru/reference/data-types/int-uint)) — Задержка текущей реплики в секундах.
* `total_replicas` ([UInt32](/ru/reference/data-types/int-uint)) — Общее количество известных реплик этой таблицы.
* `active_replicas` ([UInt32](/ru/reference/data-types/int-uint)) — Количество реплик этой таблицы, имеющих сеанс в ClickHouse Keeper (то есть функционирующих реплик).
* `lost_part_count` ([UInt64](/ru/reference/data-types/int-uint)) — Общее количество частей данных, потерянных всеми репликами таблицы с момента её создания. Значение сохраняется в ClickHouse Keeper и может только увеличиваться.
* `last_queue_update_exception` ([String](/ru/reference/data-types/string)) — Сообщение об исключении, возникающем, когда очередь содержит повреждённые записи. Особенно важно при нарушении ClickHouse обратной совместимости между версиями, когда записи журнала, созданные более новыми версиями, не могут быть разобраны старыми версиями.
* `zookeeper_exception` ([String](/ru/reference/data-types/string)) — Последнее сообщение об исключении, полученное при ошибке во время получения информации из ClickHouse Keeper.
* `replica_is_active` ([Map(String, UInt8)](/ru/reference/data-types/map)) — Соответствие между именем реплики и признаком её активности.

**Псевдонимы:**

* `readonly_duration` — псевдоним для `if(isNull(readonly_start_time), NULL, now() - readonly_start_time)`.

{/*AUTOGENERATED_END*/}
