## Описание

Содержит список всех SQL-команд ClickHouse.

## Столбцы

* `name` ([String](/ru/reference/data-types/string)) — Имя SQL-оператора.
* `syntax` ([String](/ru/reference/data-types/string)) — Синтаксис оператора.
* `description` ([String](/ru/reference/data-types/string)) — Описание оператора с примерами использования.
* `parent_name` ([String](/ru/reference/data-types/string)) — Имя охватывающего оператора, например SELECT для предложения WHERE. Для оператора верхнего уровня не заполняется.
* `related` ([Array(String)](/ru/reference/data-types/array)) — Имена связанных операторов.
