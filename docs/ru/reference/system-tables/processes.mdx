<div id="description">
  ## Описание
</div>

Эта системная таблица используется для выполнения запроса `SHOW PROCESSLIST`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/ru/reference/data-types/int-uint)) — Указывает, поступил ли этот запрос непосредственно от пользователя или был отправлен сервером ClickHouse в рамках выполнения распределённого запроса.
* `user` ([String](/ru/reference/data-types/string)) — Пользователь, выполнивший запрос. Учтите, что при распределённой обработке запросы отправляются на удалённые серверы от имени пользователя `default`. Это поле содержит имя пользователя для конкретного запроса, а не для исходного запроса, инициировавшего этот запрос.
* `query_id` ([String](/ru/reference/data-types/string)) — ID запроса, если задан.
* `address` ([IPv6](/ru/reference/data-types/ipv6)) — IP-адрес, с которого был выполнен запрос. То же относится к распределённой обработке. Чтобы определить, откуда изначально был выполнен распределённый запрос, просмотрите system.processes на сервере, инициировавшем запрос.
* `port` ([UInt16](/ru/reference/data-types/int-uint)) — Порт клиента, с которого был выполнен запрос.
* `initial_user` ([String](/ru/reference/data-types/string)) — Имя пользователя, выполнившего исходный запрос (для выполнения распределённого запроса).
* `initial_query_id` ([String](/ru/reference/data-types/string)) — ID исходного запроса (для выполнения распределённого запроса).
* `initial_address` ([IPv6](/ru/reference/data-types/ipv6)) — IP-адрес, с которого был запущен родительский запрос.
* `initial_port` ([UInt16](/ru/reference/data-types/int-uint)) — Порт клиента, использованный для выполнения родительского запроса.
* `interface` ([UInt8](/ru/reference/data-types/int-uint)) — Интерфейс, использованный для отправки запроса. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/ru/reference/data-types/string)) — Имя пользователя операционной системы, запускающего clickhouse-client.
* `client_hostname` ([String](/ru/reference/data-types/string)) — Имя хоста клиентской машины, на которой запущен clickhouse-client или другой TCP-клиент.
* `client_name` ([String](/ru/reference/data-types/string)) — Имя clickhouse-client или другого TCP-клиента.
* `client_agent` ([LowCardinality(String)](/ru/reference/data-types/lowcardinality)) — ИИ-агент для написания кода, вызвавший клиент (например, `claude-code`, `cursor`), определённый по переменным окружения. Пусто, если агент не обнаружен.
* `client_revision` ([UInt64](/ru/reference/data-types/int-uint)) — Ревизия clickhouse-client или другого TCP-клиента.
* `client_version_major` ([UInt64](/ru/reference/data-types/int-uint)) — Мажорная версия clickhouse-client или другого TCP-клиента.
* `client_version_minor` ([UInt64](/ru/reference/data-types/int-uint)) — Минорная версия clickhouse-client или другого TCP-клиента.
* `client_version_patch` ([UInt64](/ru/reference/data-types/int-uint)) — Компонент патча версии clickhouse-client или другого TCP-клиента.
* `http_method` ([UInt8](/ru/reference/data-types/int-uint)) — HTTP-метод, инициировавший запрос. Возможные значения: 0 — запрос был запущен через интерфейс TCP. 1 — использовался метод GET. 2 — использовался метод POST.
* `http_user_agent` ([String](/ru/reference/data-types/string)) — HTTP-заголовок UserAgent, переданный в HTTP-запросе.
* `http_referer` ([String](/ru/reference/data-types/string)) — HTTP-заголовок Referer, переданный в HTTP-запросе (содержит полный или частичный адрес страницы, выполнившей запрос).
* `forwarded_for` ([String](/ru/reference/data-types/string)) — HTTP-заголовок X-Forwarded-For, переданный в HTTP-запросе.
* `quota_key` ([String](/ru/reference/data-types/string)) — Ключ квоты, указанный в настройке quotas (см. keyed).
* `distributed_depth` ([UInt64](/ru/reference/data-types/int-uint)) — Количество внутренних перенаправлений запроса между серверными узлами.
* `elapsed` ([Float64](/ru/reference/data-types/float)) — Время в секундах с начала выполнения запроса.
* `is_cancelled` ([UInt8](/ru/reference/data-types/int-uint)) — Был ли запрос отменён.
* `is_all_data_sent` ([UInt8](/ru/reference/data-types/int-uint)) — Были ли все данные отправлены клиенту (то есть завершилось ли выполнение запроса на сервере).
* `read_rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк, прочитанных из таблицы. При распределённой обработке на запрашивающем сервере это общее значение для всех удалённых серверов.
* `read_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Количество несжатых байтов, прочитанных из таблицы. При распределённой обработке на запрашивающем сервере это общее значение для всех удалённых серверов.
* `total_rows_approx` ([UInt64](/ru/reference/data-types/int-uint)) — Приблизительное общее количество строк, которые необходимо прочитать. При распределённой обработке на запрашивающем сервере это общее значение для всех удалённых серверов. Может обновляться в ходе обработки запроса по мере обнаружения новых источников данных.
* `written_rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк, записанных в хранилище.
* `written_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Количество байтов, записанных в хранилище.
* `memory_usage` ([Int64](/ru/reference/data-types/int-uint)) — Объём оперативной памяти, используемой запросом. Может не включать некоторые типы выделенной памяти.
* `peak_memory_usage` ([Int64](/ru/reference/data-types/int-uint)) — Текущее пиковое использование памяти.
* `query` ([String](/ru/reference/data-types/string)) — Текст запроса. Для INSERT не включает вставляемые данные.
* `normalized_query_hash` ([UInt64](/ru/reference/data-types/int-uint)) — Числовое хеш-значение, одинаковое, например, для запросов, различающихся только значениями литералов.
* `query_kind` ([String](/ru/reference/data-types/string)) — Тип запроса — SELECT, INSERT и т. д.
* `thread_ids` ([Array(UInt64)](/ru/reference/data-types/array)) — Список идентификаторов всех потоков, участвовавших в выполнении этого запроса.
* `peak_threads_usage` ([UInt64](/ru/reference/data-types/int-uint)) — Максимальное количество потоков, одновременно выполнявших запрос.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ru/reference/data-types/map)) — ProfileEvents, рассчитанные для этого запроса.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ru/reference/data-types/map)) — Список изменённых настроек на уровне пользователя.
* `current_database` ([String](/ru/reference/data-types/string)) — Имя текущей базы данных.
* `is_internal` ([UInt8](/ru/reference/data-types/int-uint)) — Указывает, является ли запрос вспомогательным и выполняется ли он внутренне.

**Псевдонимы:**

* `ProfileEvents.Names` — Псевдоним `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — Псевдоним `mapValues(ProfileEvents)`.
* `Settings.Names` — Псевдоним `mapKeys(Settings)`.
* `Settings.Values` — Псевдоним `mapValues(Settings)`.

{/*AUTOGENERATED_END*/}
