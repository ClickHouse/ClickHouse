<div id="description">
  ## Описание
</div>

Содержит для каждого объекта метаданных AzureQueue текущее количество узлов со статусами обработанный, обрабатываемый и завершившийся с ошибкой, а также по запросу их содержимое. В отличие от system.azure&#95;queue&#95;metadata&#95;cache, которая отображает кэш в памяти, эта таблица считывает состояние непосредственно из Keeper.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/ru/reference/data-types/string)) — Путь к метаданным в ZooKeeper. Для очереди в дополнительном ZooKeeper это ключ фабрики `<zookeeper_name>:<path>`, а не непосредственный путь в Keeper.
* `processed_nodes_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Количество узлов в каталоге `processed` в Keeper. Задаётся только в режиме `unordered`: в режиме `ordered` нет отдельных узлов для обработанных файлов (см. `processed_path`), поэтому значение равно NULL.
* `processing_nodes_count` ([UInt64](/ru/reference/data-types/int-uint)) — Количество узлов в каталоге `processing` в Keeper
* `failed_nodes_count` ([UInt64](/ru/reference/data-types/int-uint)) — Количество узлов в каталоге `failed` в Keeper
* `processed_nodes` ([Map(String, String)](/ru/reference/data-types/map)) — Содержимое каталога `processed` в Keeper (имя узла -&gt; данные узла). Заполняется только в режиме `unordered`. Получается только при выборе этого столбца.
* `processing_nodes` ([Map(String, String)](/ru/reference/data-types/map)) — Содержимое каталога `processing` в Keeper (имя узла -&gt; данные узла). Получается только при выборе этого столбца.
* `failed_nodes` ([Map(String, String)](/ru/reference/data-types/map)) — Содержимое каталога `failed` в Keeper (имя узла -&gt; данные узла). Получается только при выборе этого столбца.
* `processed_path` ([Map(String, String)](/ru/reference/data-types/map)) — Последний обработанный путь для каждого указателя обработки в Keeper (относительный путь указателя -&gt; путь к последнему обработанному файлу). Заполняется только в режиме `ordered`; включает одиночный указатель, а также указатели для каждого бакета и каждой партиции. Получается только при выборе этого столбца.
