## Описание {#description}

Содержит информацию обо всех транзакциях, выполненных на текущем сервере.

**Доступность**

`system.transactions_info_log` создаётся только в том случае, если конфигурация сервера содержит секцию `transactions_info_log`. Кроме того, чтобы в таблице накапливались строки, транзакции должны быть включены настройкой `allow_experimental_transactions`. Без секции логирования запросы к таблице завершаются ошибкой `UNKNOWN_TABLE`; без экспериментальных транзакций настроенная таблица остаётся пустой.

```xml
<clickhouse>
    <allow_experimental_transactions>1</allow_experimental_transactions>
    <transactions_info_log>
        <database>system</database>
        <table>transactions_info_log</table>
        <partition_by>toYYYYMM(event_date)</partition_by>
        <flush_interval_milliseconds>7500</flush_interval_milliseconds>
    </transactions_info_log>
</clickhouse>
```

Эту таблицу можно безопасно очистить (TRUNCATE) или удалить (DROP) в любой момент.
