<div id="description">
  ## Описание
</div>

Содержит сведения о частях удалённых таблиц [MergeTree](/ru/reference/engines/table-engines/mergetree-family/mergetree) из [system.dropped&#95;tables](/ru/reference/system-tables/dropped_tables)

Схема этой таблицы совпадает со схемой [system.parts](/ru/reference/system-tables/parts)

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types/string)) — Идентификатор партиции (строковое представление, полученное из выражения ключа партиционирования).
* `name` ([String](/ru/reference/data-types/string)) — Имя части данных. По структуре имени части можно определить многие аспекты шаблонов данных, приёма и слияния. Формат имени части:

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * Определения:
    * `partition_id` — идентифицирует ключ партиционирования
    * `minimum_block_number` — идентифицирует минимальный номер блока в части. ClickHouse всегда объединяет непрерывные блоки
    * `maximum_block_number` — идентифицирует максимальный номер блока в части
    * `level` — увеличивается на единицу при каждом дополнительном слиянии части. Уровень 0 означает, что это новая часть, которая ещё не участвовала в слиянии. Важно помнить, что все части в ClickHouse неизменяемы
    * `data_version` — необязательное значение, увеличиваемое при мутации части (напомним: изменённые данные всегда записываются только в новую часть, поскольку части неизменяемы)
* `uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID части данных.
* `part_type` ([String](/ru/reference/data-types/string)) — Формат хранения части данных. Возможные значения: `Wide` — каждый столбец хранится в отдельном файле; `Compact` — все столбцы хранятся в одном файле. Формат хранения данных определяется настройками `min_bytes_for_wide_part` и `min_rows_for_wide_part` таблицы семейства MergeTree.
* `part_storage_type` ([String](/ru/reference/data-types/string)) — Тип `DataPartStorage`. Возможные значения: `Packed` — большинство файлов части хранится в одном архиве (проекции и несколько служебных файлов, например `txn_version.txt`, записываются отдельно); `Full` — каждый файл хранится отдельно.
* `active` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, активна ли часть данных. Если часть данных активна, она используется в таблице. В противном случае она будет удалена. Неактивные части данных появляются после операций слияния и мутаций.
* `marks` ([UInt64](/ru/reference/data-types/int-uint)) — Количество меток. Чтобы получить примерное количество строк в части данных, умножьте количество меток на гранулярность индекса (обычно 8192). Это не работает при адаптивной гранулярности.
* `rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк.
* `files` ([UInt64](/ru/reference/data-types/int-uint)) — Количество файлов в части данных.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в части данных. Вспомогательные файлы (например, файлы с метками) не учитываются.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в части данных. Вспомогательные файлы (например, файлы с метками) не учитываются.
* `primary_key_size` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), занимаемый значениями первичного ключа в файле primary.idx/cidx на диске.
* `marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками.
* `secondary_indices_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных вторичных индексов в части данных. Вспомогательные файлы (например, файлы с метками) не учитываются.
* `secondary_indices_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных вторичных индексов в части данных. Вспомогательные файлы (например, файлы с метками) не учитываются.
* `secondary_indices_marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками вторичных индексов.
* `modification_time` ([DateTime](/ru/reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/reference/data-types/datetime)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/reference/data-types/int-uint)) — Количество мест, где используется часть данных. Значение больше 2 указывает, что часть данных используется в запросах или слияниях.
* `min_date` ([Date](/ru/reference/data-types/date)) — Минимальное значение ключа даты в части данных.
* `max_date` ([Date](/ru/reference/data-types/date)) — Максимальное значение ключа даты в части данных.
* `min_time` ([DateTime](/ru/reference/data-types/datetime)) — Минимальное значение ключа даты и времени в части данных.
* `max_time` ([DateTime](/ru/reference/data-types/datetime)) — Максимальное значение ключа даты и времени в части данных.
* `partition_id` ([String](/ru/reference/data-types/string)) — Идентификатор партиции.
* `min_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Минимальный номер части данных, из которых состоит текущая часть после слияния.
* `max_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Максимальный номер части данных, из которых состоит текущая часть после слияния.
* `level` ([UInt32](/ru/reference/data-types/int-uint)) — Глубина дерева слияний. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
* `data_version` ([UInt64](/ru/reference/data-types/int-uint)) — Число, используемое для определения мутаций, которые следует применить к части данных (мутаций с версией выше data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types/int-uint)) — Объем памяти (в байтах), используемый значениями первичного ключа. Равен 0, если включен `primary_key_lazy_load` и ключ не загружен. При ненулевом значении байты хранятся в самой части и учитываются в `jemalloc.mergetree_arena.active_bytes`. Они НИКОГДА не учитываются в `PrimaryIndexCacheBytes`: для каждой части эти варианты взаимоисключающие — индекс находится либо в части (эта метрика), либо в общем `PrimaryIndexCache` (другая метрика), в зависимости от `primary_key_lazy_load` и `use_primary_key_cache`.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объем памяти (в байтах), зарезервированный для значений первичного ключа. Равен 0, если включен `primary_key_lazy_load` и ключ не загружен. При ненулевом значении учитывается в `jemalloc.mergetree_arena.active_bytes`. Сведения о связи с `PrimaryIndexCacheBytes` см. в примечании к `primary_key_bytes_in_memory`.
* `index_granularity_bytes_in_memory` ([UInt64](/ru/reference/data-types/int-uint)) — Объем памяти (в байтах), используемый значениями гранулярности индекса (равен 0 при primary&#95;key&#95;lazy&#95;load=1 и use&#95;primary&#95;key&#95;cache=1). При ненулевом значении байты принадлежат части и учитываются в `jemalloc.mergetree_arena.active_bytes`.
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объем памяти (в байтах), зарезервированный для значений гранулярности индекса (равен 0 при primary&#95;key&#95;lazy&#95;load=1 и use&#95;primary&#95;key&#95;cache=1). При ненулевом значении учитывается в `jemalloc.mergetree_arena.active_bytes`.
* `is_frozen` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий на наличие резервной копии данных партиции. 1 — резервная копия существует. 0 — резервная копия отсутствует. Подробнее см. FREEZE PARTITION.
* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `engine` ([String](/ru/reference/data-types/string)) — Имя движка таблицы без параметров.
* `disk_name` ([String](/ru/reference/data-types/string)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/reference/data-types/string)) — Абсолютный путь к папке с файлами части данных.
* `hash_of_all_files` ([String](/ru/reference/data-types/string)) — sipHash128 сжатых файлов.
* `hash_of_uncompressed_files` ([String](/ru/reference/data-types/string)) — sipHash128 несжатых файлов (файлов с метками, файла индекса и т. д.).
* `uncompressed_hash_of_compressed_files` ([String](/ru/reference/data-types/string)) — sipHash128 данных в сжатых файлах, как если бы они были несжатыми.
* `delete_ttl_info_min` ([DateTime](/ru/reference/data-types/datetime)) — Минимальное значение ключа даты и времени для правила TTL DELETE.
* `delete_ttl_info_max` ([DateTime](/ru/reference/data-types/datetime)) — Максимальное значение ключа даты и времени для правила TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — Массив выражений. Каждое выражение определяет правило TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Массив значений даты и времени. Каждый элемент описывает минимальное значение ключа для правила TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Массив значений даты и времени. Каждый элемент описывает максимальное значение ключа для правила TTL MOVE.
* `default_compression_codec` ([String](/ru/reference/data-types/string)) — Имя кодека, используемого для сжатия этой части данных, если для столбца не задан явный кодек или используется `CODEC(Default)`. При включённом `allow_experimental_adaptive_codec_selection` отдельные блоки таких столбцов могут использовать другие кодеки; см. [`mergeTreeCodecBlockCounts`](/ru/reference/functions/table-functions/mergeTreeCodecBlockCounts).
* `recompression_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — TTL-выражение.
* `recompression_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли хотя бы одна строка с истёкшим TTL.
* `recompression_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, у всех ли строк истёк TTL.
* `group_by_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — TTL-выражение.
* `group_by_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли хотя бы одна строка с истёкшим TTL.
* `group_by_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, у всех ли строк истёк TTL.
* `rows_where_ttl_info.expression` ([Array(String)](/ru/reference/data-types/array)) — TTL-выражение.
* `rows_where_ttl_info.min` ([Array(DateTime)](/ru/reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, есть ли хотя бы одна строка с истёкшим TTL.
* `rows_where_ttl_info.max` ([Array(DateTime)](/ru/reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в этой части. Используется, чтобы определить, у всех ли строк истёк TTL.
* `projections` ([Array(String)](/ru/reference/data-types/array)) — Список имён проекций, рассчитанных для этой части.
* `visible` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, видна ли эта часть для SELECT-запросов.
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ru/reference/data-types/tuple)) — Идентификатор транзакции, создавшей или пытающейся создать этот объект.
* `removal_tid_lock` ([UInt64](/ru/reference/data-types/int-uint)) — Хеш removal&#95;tid, используемый для блокировки объекта на время удаления.
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ru/reference/data-types/tuple)) — Идентификатор транзакции, удалившей или пытающейся удалить этот объект
* `creation_csn` ([UInt64](/ru/reference/data-types/int-uint)) — CSN транзакции, создавшей этот объект
* `removal_csn` ([UInt64](/ru/reference/data-types/int-uint)) — CSN транзакции, удалившей этот объект
* `has_lightweight_delete` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, содержит ли часть маску легковесного удаления.
* `last_removal_attempt_time` ([DateTime](/ru/reference/data-types/datetime)) — Время последней попытки сервера удалить эту часть.
* `removal_state` ([String](/ru/reference/data-types/string)) — Текущее состояние процесса удаления части.

**Псевдонимы:**

* `bytes` — псевдоним `bytes_on_disk`.
* `marks_size` — псевдоним `marks_bytes`.
* `part_name` — псевдоним `name`.
