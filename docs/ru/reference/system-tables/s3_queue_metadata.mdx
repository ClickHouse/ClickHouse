<div id="description">
  ## Описание
</div>

Содержит текущее количество узлов со статусами processed, processing и failed в Keeper для каждого объекта метаданных S3Queue, а также их содержимое по запросу. В отличие от system.s3queue&#95;metadata&#95;cache, в которой отображается кэш в памяти, эта таблица получает состояние непосредственно из Keeper.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/ru/reference/data-types/string)) — Путь к метаданным в ZooKeeper. Для очереди во вспомогательном ZooKeeper это ключ фабрики `<zookeeper_name>:<path>`, а не непосредственный путь в Keeper.
* `processed_nodes_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Количество узлов в каталоге `processed` в Keeper. Устанавливается только в режиме `unordered`: в режиме `ordered` нет отдельных узлов обработанных файлов (см. `processed_path`), поэтому значение равно NULL.
* `processing_nodes_count` ([UInt64](/ru/reference/data-types/int-uint)) — Количество узлов в каталоге `processing` в Keeper
* `failed_nodes_count` ([UInt64](/ru/reference/data-types/int-uint)) — Количество узлов в каталоге `failed` в Keeper
* `processed_nodes` ([Map(String, String)](/ru/reference/data-types/map)) — Содержимое каталога `processed` в Keeper (имя узла -&gt; данные узла). Заполняется только в режиме `unordered`. Получается только при выборе этого столбца.
* `processing_nodes` ([Map(String, String)](/ru/reference/data-types/map)) — Содержимое каталога `processing` в Keeper (имя узла -&gt; данные узла). Получается только при выборе этого столбца.
* `failed_nodes` ([Map(String, String)](/ru/reference/data-types/map)) — Содержимое каталога `failed` в Keeper (имя узла -&gt; данные узла). Получается только при выборе этого столбца.
* `processed_path` ([Map(String, String)](/ru/reference/data-types/map)) — Путь к последнему обработанному файлу для каждого указателя обработанных данных в Keeper (относительный путь указателя -&gt; путь к последнему обработанному файлу). Заполняется только в режиме `ordered`; содержит данные для единственного указателя, а также указателей для каждого бакета и каждой партиции. Получается только при выборе этого столбца.
