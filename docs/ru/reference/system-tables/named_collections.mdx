## Описание {#description}

Содержит список всех именованных коллекций, созданных SQL-запросом или разобранных из файла конфигурации.

## Столбцы {#columns}

* `name` ([String](/ru/reference/data-types/string)) — Имя коллекции.
* `collection` ([Map(String, String)](/ru/reference/data-types/map)) — Внутренние компоненты коллекции.
* `source` ([String](/ru/reference/data-types/string)) — Источник именованной коллекции.
* `create_query` ([String](/ru/reference/data-types/string)) — Запрос CREATE для именованной коллекции.
