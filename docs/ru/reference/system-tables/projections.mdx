## Описание {#description}

Содержит информацию о существующих проекциях во всех таблицах.

Значения в столбцах `total_rows`, `data_compressed_bytes` и `data_uncompressed_bytes` суммируются по активным частям данных таблицы, содержащим проекцию, поэтому они остаются нулевыми, пока проекция не будет построена — например, вставками, выполненными после её добавления, или запросом `ALTER TABLE ... MATERIALIZE PROJECTION`. Размер каждой части проекции можно узнать в [system.projection&#95;parts](/ru/operations/system-tables/projection_parts).

## Столбцы {#columns}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `name` ([String](/ru/reference/data-types/string)) — Имя проекции.
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ru/reference/data-types/enum)) — Тип проекции.
* `total_rows` ([UInt64](/ru/reference/data-types/int-uint)) — Общее количество строк.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер сжатых данных в байтах.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер распакованных данных в байтах.
* `sorting_key` ([Array(String)](/ru/reference/data-types/array)) — Ключ сортировки проекции.
* `query` ([String](/ru/reference/data-types/string)) — Запрос проекции.
* `settings` ([Map(String, String)](/ru/reference/data-types/map)) — Настройки проекции.
