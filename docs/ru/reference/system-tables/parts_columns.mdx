<div id="description">
  ## Описание
</div>

Содержит сведения о частях данных и столбцах таблиц [MergeTree](/ru/reference/engines/table-engines/mergetree-family/mergetree).
Каждая строка описывает одну часть данных.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types/string)) — Имя партиции.
* `name` ([String](/ru/reference/data-types/string)) — Имя части данных.
* `uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID части.
* `part_type` ([String](/ru/reference/data-types/string)) — Формат хранения части данных. Возможные значения: Wide — каждый столбец хранится в отдельном файле файловой системы; Compact — все столбцы хранятся в одном файле файловой системы.
* `active` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, активна ли часть данных. Активная часть данных используется в таблице, неактивная — удаляется. Неактивные части данных остаются после слияний.
* `marks` ([UInt64](/ru/reference/data-types/int-uint)) — Количество меток. Чтобы приблизительно определить количество строк в части данных, умножьте количество меток на гранулярность индекса (обычно 8192). Это правило не работает при адаптивной гранулярности.
* `rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в части данных без учёта вспомогательных файлов, например файлов с метками.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в части данных без учёта вспомогательных файлов, например файлов с метками.
* `marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками.
* `modification_time` ([DateTime](/ru/reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/reference/data-types/datetime)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/reference/data-types/int-uint)) — Количество мест, в которых используется часть данных. Значение больше 2 указывает на то, что часть данных используется в запросах или слияниях.
* `min_date` ([Date](/ru/reference/data-types/date)) — Минимальное значение столбца Date, если он включён в ключ партиционирования.
* `max_date` ([Date](/ru/reference/data-types/date)) — Максимальное значение столбца Date, если он включён в ключ партиционирования.
* `min_time` ([DateTime](/ru/reference/data-types/datetime)) — Минимальное значение столбца DateTime, если он включён в ключ партиционирования.
* `max_time` ([DateTime](/ru/reference/data-types/datetime)) — Максимальное значение столбца DateTime, если он включён в ключ партиционирования.
* `partition_id` ([String](/ru/reference/data-types/string)) — ID партиции.
* `min_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Минимальное количество частей данных, образующих текущую часть после слияния.
* `max_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Максимальное количество частей данных, образующих текущую часть после слияния.
* `level` ([UInt32](/ru/reference/data-types/int-uint)) — Глубина дерева слияний. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
* `data_version` ([UInt64](/ru/reference/data-types/int-uint)) — Номер, используемый для определения мутаций, которые следует применить к части данных (мутаций с версией выше data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), используемый значениями первичного ключа.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), зарезервированный для значений первичного ключа.
* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `engine` ([String](/ru/reference/data-types/string)) — Имя движка таблицы без параметров.
* `disk_name` ([String](/ru/reference/data-types/string)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/reference/data-types/string)) — Абсолютный путь к папке с файлами части данных.
* `column` ([String](/ru/reference/data-types/string)) — Имя столбца.
* `type` ([String](/ru/reference/data-types/string)) — Тип столбца.
* `column_position` ([UInt64](/ru/reference/data-types/int-uint)) — Порядковый номер столбца в таблице, начиная с 1.
* `default_kind` ([String](/ru/reference/data-types/string)) — Тип выражения (DEFAULT, MATERIALIZED, ALIAS) для значения по умолчанию или пустая строка, если оно не определено.
* `default_expression` ([String](/ru/reference/data-types/string)) — Выражение для значения по умолчанию или пустая строка, если оно не определено.
* `column_bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер столбца в байтах.
* `column_data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в столбце в байтах.
* `column_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в столбце в байтах.
* `column_marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер меток столбца в байтах.
* `column_modification_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время последнего изменения столбца.
* `column_ttl_min` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Минимальное значение вычисленного TTL-выражения столбца.
* `column_ttl_max` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Максимальное значение вычисленного TTL-выражения столбца.
* `statistics` ([Array(String)](/ru/reference/data-types/array)) — Статистика столбца.
* `estimates.min` ([Nullable(String)](/ru/reference/data-types/nullable)) — Оценочное минимальное значение столбца.
* `estimates.max` ([Nullable(String)](/ru/reference/data-types/nullable)) — Оценочное максимальное значение столбца.
* `estimates.cardinality` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Оценочная мощность столбца.
* `estimates.null_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Оценочное количество значений NULL в столбце.
* `estimates.default_count` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Оценочное количество строк со значением по умолчанию для хранения в столбце (NULL для столбцов с типом Nullable, 0 / &#39;&#39; / [] / ... для столбцов без Nullable). NULL, если базовая статистика недоступна.
* `serialization_kind` ([String](/ru/reference/data-types/string)) — Вид сериализации столбца
* `substreams` ([Array(String)](/ru/reference/data-types/array)) — Имена подпотоков, в которые сериализуется столбец
* `filenames` ([Array(String)](/ru/reference/data-types/array)) — Имена файлов для каждого подпотока столбца соответственно
* `subcolumns.names` ([Array(String)](/ru/reference/data-types/array)) — Имена подстолбцов столбца
* `subcolumns.types` ([Array(String)](/ru/reference/data-types/array)) — Типы подстолбцов столбца
* `subcolumns.serializations` ([Array(String)](/ru/reference/data-types/array)) — Виды сериализации подстолбцов столбца
* `subcolumns.bytes_on_disk` ([Array(UInt64)](/ru/reference/data-types/array)) — Размер в байтах каждого подстолбца
* `subcolumns.data_compressed_bytes` ([Array(UInt64)](/ru/reference/data-types/array)) — Размер сжатых данных каждого подстолбца в байтах
* `subcolumns.data_uncompressed_bytes` ([Array(UInt64)](/ru/reference/data-types/array)) — Размер распакованных данных каждого подстолбца в байтах
* `subcolumns.marks_bytes` ([Array(UInt64)](/ru/reference/data-types/array)) — Размер меток каждого подстолбца столбца в байтах

**Псевдонимы:**

* `bytes` — псевдоним `bytes_on_disk`.
* `marks_size` — псевдоним `marks_bytes`.
* `part_name` — псевдоним `name`.
