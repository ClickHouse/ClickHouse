<div id="description">
  ## Описание
</div>

Содержит список [учётных записей пользователей](/ru/concepts/features/security/access-rights#user-account-management), настроенных на сервере.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ru/reference/data-types/string)) — Имя пользователя.
* `id` ([UUID](/ru/reference/data-types/uuid)) — Идентификатор пользователя.
* `storage` ([String](/ru/reference/data-types/string)) — Путь к хранилищу пользователей. Настраивается параметром access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/ru/reference/data-types/array)) — Типы аутентификации. Пользователь может идентифицироваться без пароля, по паролю в открытом виде, по паролю, хешированному с помощью SHA256, двойного SHA-1 или bcrypt.
* `auth_params` ([Array(String)](/ru/reference/data-types/array)) — Параметры аутентификации в формате JSON в зависимости от auth&#95;type.
* `valid_until` ([Array(DateTime64(0))](/ru/reference/data-types/array)) — Дата и время истечения срока действия учетных данных пользователя, по одному для каждого метода аутентификации. Сохраненное значение представляет собой абсолютный момент времени, отображаемый в часовом поясе сервера или сеанса; значение `0` (эпоха Unix, отображаемая как `1970-01-01 00:00:00` на сервере в `UTC`) является специальным значением, означающим, что срок действия учетных данных не истекает.
* `auth_grants` ([Array(String)](/ru/reference/data-types/array)) — Для каждого метода аутентификации: ограничение прав доступа, заданное в предложении `GRANTS`, или пустая строка, если права доступа не ограничены.
* `host_ip` ([Array(String)](/ru/reference/data-types/array)) — IP-адреса хостов, которым разрешено подключаться к серверу ClickHouse.
* `host_names` ([Array(String)](/ru/reference/data-types/array)) — Имена хостов, которым разрешено подключаться к серверу ClickHouse.
* `host_names_regexp` ([Array(String)](/ru/reference/data-types/array)) — Регулярное выражение для имен хостов, которым разрешено подключаться к серверу ClickHouse.
* `host_names_like` ([Array(String)](/ru/reference/data-types/array)) — Имена хостов, которым разрешено подключаться к серверу ClickHouse, заданные с помощью предиката LIKE.
* `default_roles_all` ([UInt8](/ru/reference/data-types/int-uint)) — Указывает, что все предоставленные роли назначены пользователю по умолчанию.
* `default_roles_list` ([Array(String)](/ru/reference/data-types/array)) — Список предоставленных ролей, назначенных по умолчанию.
* `default_roles_except` ([Array(String)](/ru/reference/data-types/array)) — Все предоставленные роли, кроме перечисленных, назначены по умолчанию.
* `grantees_any` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, может ли пользователь с любой опцией grant выдавать ее кому угодно.
* `grantees_list` ([Array(String)](/ru/reference/data-types/array)) — Список пользователей или ролей, которым этот пользователь может выдавать опции grant.
* `grantees_except` ([Array(String)](/ru/reference/data-types/array)) — Список пользователей или ролей, которым этому пользователю запрещено выдавать опции grant.
* `default_database` ([String](/ru/reference/data-types/string)) — Имя базы данных по умолчанию для этого пользователя.
