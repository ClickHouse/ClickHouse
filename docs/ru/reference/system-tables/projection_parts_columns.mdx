<div id="description">
  ## Описание
</div>

Эта таблица содержит информацию о столбцах в частях проекций таблиц семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ru/reference/data-types/string)) — Имя партиции.
* `name` ([String](/ru/reference/data-types/string)) — Имя части данных.
* `part_type` ([String](/ru/reference/data-types/string)) — Формат хранения части данных.
* `parent_name` ([String](/ru/reference/data-types/string)) — Имя исходной (родительской) части данных.
* `parent_uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID исходной (родительской) части данных.
* `parent_part_type` ([String](/ru/reference/data-types/string)) — Формат хранения исходной (родительской) части данных.
* `active` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, активна ли часть данных.
* `marks` ([UInt64](/ru/reference/data-types/int-uint)) — Количество меток.
* `rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк.
* `bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в части данных. Вспомогательные файлы (например, файлы с метками) не учитываются.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в части данных. Вспомогательные файлы (например, файлы с метками) не учитываются.
* `marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками.
* `parent_marks` ([UInt64](/ru/reference/data-types/int-uint)) — Количество меток в исходной (родительской) части.
* `parent_rows` ([UInt64](/ru/reference/data-types/int-uint)) — Количество строк в исходной (родительской) части.
* `parent_bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер всех файлов исходной (родительской) части данных в байтах.
* `parent_data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в исходной (родительской) части данных.
* `parent_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер несжатых данных в исходной (родительской) части данных.
* `parent_marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер файла с метками в исходной (родительской) части данных.
* `modification_time` ([DateTime](/ru/reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/reference/data-types/datetime)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/reference/data-types/int-uint)) — Количество мест использования части данных. Значение больше 2 указывает на то, что часть данных используется в запросах или слияниях.
* `min_date` ([Date](/ru/reference/data-types/date)) — Минимальное значение для столбца Date, если он включён в ключ партиционирования.
* `max_date` ([Date](/ru/reference/data-types/date)) — Максимальное значение для столбца Date, если он включён в ключ партиционирования.
* `min_time` ([DateTime](/ru/reference/data-types/datetime)) — Минимальное значение для столбца DateTime, если он включён в ключ партиционирования.
* `max_time` ([DateTime](/ru/reference/data-types/datetime)) — Максимальное значение столбца DateTime, если он включён в ключ партиционирования.
* `partition_id` ([String](/ru/reference/data-types/string)) — Идентификатор партиции.
* `min_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Минимальное количество частей данных, из которых состоит текущая часть после слияния.
* `max_block_number` ([Int64](/ru/reference/data-types/int-uint)) — Максимальное количество частей данных, из которых состоит текущая часть после слияния.
* `level` ([UInt32](/ru/reference/data-types/int-uint)) — Глубина дерева слияния. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
* `data_version` ([UInt64](/ru/reference/data-types/int-uint)) — Число, используемое для определения мутаций, которые следует применить к части данных (мутации с версией выше data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), используемый значениями первичного ключа.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/reference/data-types/int-uint)) — Объём памяти (в байтах), зарезервированный для значений первичного ключа.
* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `engine` ([String](/ru/reference/data-types/string)) — Имя движка таблицы без параметров.
* `disk_name` ([String](/ru/reference/data-types/string)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/reference/data-types/string)) — Абсолютный путь к папке с файлами части данных.
* `column` ([String](/ru/reference/data-types/string)) — Имя столбца.
* `type` ([String](/ru/reference/data-types/string)) — Тип столбца.
* `column_position` ([UInt64](/ru/reference/data-types/int-uint)) — Порядковый номер столбца в таблице, начиная с 1.
* `default_kind` ([String](/ru/reference/data-types/string)) — Тип выражения (DEFAULT, MATERIALIZED, ALIAS) для значения по умолчанию или пустая строка, если оно не определено.
* `default_expression` ([String](/ru/reference/data-types/string)) — Выражение для значения по умолчанию или пустая строка, если оно не определено.
* `column_bytes_on_disk` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер столбца в байтах.
* `column_data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер сжатых данных в столбце в байтах.
* `column_data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Общий размер распакованных данных в столбце в байтах.
* `column_marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер столбца с метками в байтах.
* `column_modification_time` ([Nullable(DateTime)](/ru/reference/data-types/nullable)) — Время последнего изменения столбца.

**Псевдонимы:**

* `bytes` — псевдоним для `bytes_on_disk`.
* `marks_size` — псевдоним для `marks_bytes`.
* `part_name` — псевдоним для `name`.
