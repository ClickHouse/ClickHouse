<div id="description">
  ## Описание
</div>

Содержит информацию о кластерах, доступных в файле конфигурации, и входящих в них серверах.

<div id="Columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `cluster` ([String](/ru/reference/data-types/string)) — Имя кластера.
* `shard_num` ([UInt32](/ru/reference/data-types/int-uint)) — Номер сегмента в кластере, начиная с 1.
* `shard_name` ([String](/ru/reference/data-types/string)) — Имя сегмента в кластере.
* `shard_weight` ([UInt32](/ru/reference/data-types/int-uint)) — Относительный вес сегмента при записи данных.
* `internal_replication` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, входит ли этот хост в группу, способную самостоятельно реплицировать данные.
* `replica_num` ([UInt32](/ru/reference/data-types/int-uint)) — Номер реплики в сегменте, начиная с 1.
* `host_name` ([String](/ru/reference/data-types/string)) — Имя хоста, указанное в конфигурации.
* `host_address` ([String](/ru/reference/data-types/string)) — IP-адрес хоста, полученный из DNS.
* `port` ([UInt16](/ru/reference/data-types/int-uint)) — Порт для подключения к серверу.
* `is_local` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, является ли хост локальным.
* `user` ([String](/ru/reference/data-types/string)) — Имя пользователя для подключения к серверу.
* `default_database` ([String](/ru/reference/data-types/string)) — Имя базы данных по умолчанию.
* `errors_count` ([UInt32](/ru/reference/data-types/int-uint)) — Количество неудачных попыток этого хоста связаться с репликой.
* `slowdowns_count` ([UInt32](/ru/reference/data-types/int-uint)) — Количество замедлений, приведших к смене реплики при установлении соединения с хеджированными запросами.
* `estimated_recovery_time` ([UInt32](/ru/reference/data-types/int-uint)) — Количество секунд до обнуления счётчика ошибок реплики, после чего она будет считаться работающей в штатном режиме.
* `database_shard_name` ([String](/ru/reference/data-types/string)) — Имя сегмента базы данных `Replicated` (для кластеров, принадлежащих базе данных `Replicated`).
* `database_replica_name` ([String](/ru/reference/data-types/string)) — Имя реплики базы данных `Replicated` (для кластеров, принадлежащих базе данных `Replicated`).
* `is_shared_catalog_cluster` ([UInt8](/ru/reference/data-types/int-uint)) — Bool, указывающий, принадлежит ли кластер общему каталогу.
* `is_active` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — Статус реплики базы данных `Replicated` (для кластеров, принадлежащих базе данных `Replicated`): 1 означает &#39;реплика активна&#39;, 0 означает &#39;реплика неактивна&#39;, NULL означает &#39;неизвестно&#39;.
* `unsynced_after_recovery` ([Nullable(UInt8)](/ru/reference/data-types/nullable)) — Указывает, превышает ли отставание репликации реплики базы данных `Replicated` значение max&#95;replication&#95;lag&#95;to&#95;enqueue после создания или восстановления реплики.
* `replication_lag` ([Nullable(UInt32)](/ru/reference/data-types/nullable)) — Отставание репликации реплики базы данных `Replicated` (для кластеров, принадлежащих базе данных `Replicated`).
* `recovery_time` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Время восстановления реплики базы данных `Replicated` (для кластеров, принадлежащих базе данных `Replicated`), в миллисекундах.

**Псевдонимы:**

* `name` — Псевдоним для `cluster`.

{/*AUTOGENERATED_END*/}
