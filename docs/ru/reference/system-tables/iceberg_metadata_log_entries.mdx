## Описание {#description}

Эта системная таблица содержит файлы метаданных таблиц Iceberg, имеющихся в ClickHouse, — по одной строке на каждый файл метаданных. Если в ClickHouse нет таблиц Iceberg, она будет пустой.

## Столбцы {#columns}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `timestamp` ([DateTime64(3)](/ru/reference/data-types/datetime64)) — Дата и время, когда этот файл метаданных стал текущим.
* `file` ([String](/ru/reference/data-types/string)) — Путь к файлу метаданных.
* `latest_snapshot_id` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — ID последнего снимка на момент этого файла метаданных.
* `latest_schema_id` ([Nullable(Int32)](/ru/reference/data-types/nullable)) — ID схемы последнего снимка.
* `latest_sequence_number` ([Nullable(Int64)](/ru/reference/data-types/nullable)) — Порядковый номер последнего снимка.
