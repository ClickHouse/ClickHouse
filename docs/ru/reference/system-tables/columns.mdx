<div id="description">
  ## Описание
</div>

Содержит сведения о столбцах всех таблиц.

Эту таблицу можно использовать, чтобы получить сведения, аналогичные результату запроса [DESCRIBE TABLE](/ru/reference/statements/describe-table), но сразу для нескольких таблиц.

Столбцы из [временных таблиц](/ru/reference/statements/create/table/temporary-table) видны в `system.columns` только в том сеансе, в котором они были созданы. Они отображаются с пустым полем `database`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `name` ([String](/ru/reference/data-types/string)) — Имя столбца.
* `type` ([String](/ru/reference/data-types/string)) — Тип столбца.
* `position` ([UInt64](/ru/reference/data-types/int-uint)) — Порядковый номер столбца в таблице, начиная с 1.
* `default_kind` ([String](/ru/reference/data-types/string)) — Тип выражения (DEFAULT, MATERIALIZED, ALIAS) для значения по умолчанию либо пустая строка, если оно не задано.
* `default_expression` ([String](/ru/reference/data-types/string)) — Выражение для значения по умолчанию либо пустая строка, если оно не задано.
* `data_compressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер сжатых данных в байтах.
* `data_uncompressed_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер несжатых данных в байтах.
* `marks_bytes` ([UInt64](/ru/reference/data-types/int-uint)) — Размер меток в байтах.
* `comment` ([String](/ru/reference/data-types/string)) — Комментарий к столбцу либо пустая строка, если он не задан.
* `is_in_partition_key` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение партиционирования.
* `is_in_sorting_key` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение ключа сортировки.
* `is_in_primary_key` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение первичного ключа.
* `is_in_sampling_key` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение ключа выборки.
* `compression_codec` ([String](/ru/reference/data-types/string)) — Имя кодека сжатия.
* `character_octet_length` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Максимальная длина в байтах для двоичных, символьных или текстовых данных и изображений. В ClickHouse применимо только к типу данных FixedString. В остальных случаях возвращается значение NULL.
* `numeric_precision` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Точность приблизительных или точных числовых, целочисленных либо денежных данных. В ClickHouse это разрядность для целочисленных типов и десятичная точность для типов Decimal. В остальных случаях возвращается значение NULL.
* `numeric_precision_radix` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Основание системы счисления для точности приблизительных или точных числовых, целочисленных либо денежных данных. В ClickHouse это 2 для целочисленных типов и 10 для типов Decimal. В остальных случаях возвращается значение NULL.
* `numeric_scale` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Масштаб приблизительных или точных числовых, целочисленных либо денежных данных. В ClickHouse применимо только к типам Decimal. В остальных случаях возвращается значение NULL.
* `datetime_precision` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Десятичная точность типа данных DateTime64. Для других типов данных возвращается значение NULL.
* `serialization_hint` ([Nullable(String)](/ru/reference/data-types/nullable)) — Подсказка для выбора сериализации столбца при вставке на основе статистики.
* `statistics` ([String](/ru/reference/data-types/string)) — Типы статистики, созданной для этого столбца.

**Псевдонимы:**

* `column` — Псевдоним для `name`.

{/*AUTOGENERATED_END*/}
