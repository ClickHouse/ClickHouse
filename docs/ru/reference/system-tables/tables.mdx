<div id="description">
  ## Описание
</div>

Содержит метаданные всех таблиц, о которых знает сервер.

[Detached](/ru/reference/statements/detach) таблицы не отображаются в `system.tables`.

[Временные таблицы](/ru/reference/statements/create/table/temporary-table) видны в `system.tables` только в том сеансе, в котором они были созданы. Они отображаются с пустым значением поля `database` и включённым флагом `is_temporary`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ru/reference/data-types/string)) — Имя базы данных, в которой находится таблица.
* `name` ([String](/ru/reference/data-types/string)) — Имя таблицы.
* `uuid` ([UUID](/ru/reference/data-types/uuid)) — UUID таблицы (база данных Atomic).
* `engine` ([String](/ru/reference/data-types/string)) — Имя движка таблицы (без параметров).
* `is_temporary` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, является ли таблица временной.
* `data_paths` ([Array(String)](/ru/reference/data-types/array)) — Пути к данным таблицы в файловых системах.
* `metadata_path` ([String](/ru/reference/data-types/string)) — Путь к метаданным таблицы в файловой системе.
* `metadata_modification_time` ([DateTime](/ru/reference/data-types/datetime)) — Время последнего изменения метаданных таблицы.
* `metadata_version` ([Int32](/ru/reference/data-types/int-uint)) — Версия метаданных для таблицы ReplicatedMergeTree; для таблиц, не использующих ReplicatedMergeTree, — 0.
* `dependencies_database` ([Array(String)](/ru/reference/data-types/array)) — Зависимости базы данных.
* `dependencies_table` ([Array(String)](/ru/reference/data-types/array)) — Зависимости таблицы (materialized view, зависящие от текущей таблицы).
* `create_table_query` ([String](/ru/reference/data-types/string)) — Запрос, использованный для создания таблицы.
* `engine_full` ([String](/ru/reference/data-types/string)) — Параметры движка таблицы.
* `as_select` ([String](/ru/reference/data-types/string)) — SELECT-запрос для представления.
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/ru/reference/data-types/array)) — Параметры parameterized view.
* `partition_key` ([String](/ru/reference/data-types/string)) — Выражение ключа партиционирования, указанное в таблице.
* `sorting_key` ([String](/ru/reference/data-types/string)) — Выражение ключа сортировки, указанное в таблице.
* `primary_key` ([String](/ru/reference/data-types/string)) — Выражение первичного ключа, указанное в таблице.
* `sampling_key` ([String](/ru/reference/data-types/string)) — Выражение ключа выборки, указанное в таблице.
* `unique_key` ([String](/ru/reference/data-types/string)) — Выражение уникального ключа, указанное в таблице (предложение UNIQUE KEY).
* `skipping_indices_types` ([Array(String)](/ru/reference/data-types/array)) — Массив уникальных типов индексов пропуска данных, определённых для таблицы (например, minmax, set, bloom&#95;filter, ngrambf&#95;v1, tokenbf&#95;v1, text, vector&#95;similarity). Пуст для таблиц без индексов пропуска данных.
* `storage_policy` ([String](/ru/reference/data-types/string)) — Политика хранения. Применимо к таблицам, использующим движки MergeTree и Distributed.
* `total_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество строк, если точное число строк в таблице можно быстро определить; иначе NULL (включая нижележащую Buffer table).
* `total_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество байтов, если точное число байтов таблицы в хранилище можно быстро определить; иначе NULL (без учёта нижележащего хранилища). Если таблица хранит данные на диске, возвращается объём занятого дискового пространства (то есть сжатые данные). Если таблица хранит данные в памяти, возвращается приблизительное количество используемых байтов в памяти.
* `total_bytes_uncompressed` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество несжатых байтов, если точное количество байтов таблицы в хранилище можно быстро определить по контрольным суммам частей; иначе NULL (без учёта нижележащего хранилища, если оно есть).
* `parts` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество частей в этой таблице.
* `active_parts` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Количество активных частей в этой таблице.
* `total_marks` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество меток во всех частях этой таблицы.
* `active_on_fly_data_mutations` ([UInt64](/ru/reference/data-types/int-uint)) — Общее количество активных мутаций данных (UPDATE и DELETE), которые можно применить на лету.
* `active_on_fly_alter_mutations` ([UInt64](/ru/reference/data-types/int-uint)) — Общее количество активных ALTER-мутаций (MODIFY COLUMN), которые можно применить на лету.
* `active_on_fly_metadata_mutations` ([UInt64](/ru/reference/data-types/int-uint)) — Общее количество активных мутаций метаданных (RENAME), которые можно применить на лету.
* `columns_descriptions_cache_size` ([UInt64](/ru/reference/data-types/int-uint)) — Размер кеша описаний столбцов для таблиц семейства *MergeTree
* `lifetime_rows` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество строк, вставленных с момента запуска сервера (только для таблиц Buffer).
* `lifetime_bytes` ([Nullable(UInt64)](/ru/reference/data-types/nullable)) — Общее количество байтов, вставленных с момента запуска сервера (только для таблиц Buffer).
* `comment` ([String](/ru/reference/data-types/string)) — Комментарий к таблице.
* `has_own_data` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, хранит ли таблица данные на диске или только обращается к другому источнику.
* `loading_dependencies_database` ([Array(String)](/ru/reference/data-types/array)) — Зависимости загрузки базы данных (список объектов, которые должны быть загружены до текущего объекта).
* `loading_dependencies_table` ([Array(String)](/ru/reference/data-types/array)) — Зависимости загрузки таблицы (список объектов, которые должны быть загружены до текущего объекта).
* `loading_dependent_database` ([Array(String)](/ru/reference/data-types/array)) — Зависимая база данных при загрузке.
* `loading_dependent_table` ([Array(String)](/ru/reference/data-types/array)) — Зависимая таблица при загрузке.
* `target_database` ([String](/ru/reference/data-types/string)) — Для materialized view — база данных целевой таблицы, в которую записывает представление (цель `TO` или неявная таблица `.inner.*`). Для других движков значение пустое.
* `target_table` ([String](/ru/reference/data-types/string)) — Для materialized view — имя целевой таблицы, в которую записывает представление (цель `TO` или неявная таблица `.inner.*`). Для других движков значение пустое.
* `definer` ([String](/ru/reference/data-types/string)) — Имя определяющего пользователя безопасности SQL, используемого для таблицы.

**Псевдонимы:**

* `table` — псевдоним `name`.

{/*AUTOGENERATED_END*/}
