## Описание {#description}

<Warning>
  Интеграция CatBoost была удалена из ClickHouse, и таблица `system.models` больше не существует: запрос к ней завершается ошибкой `UNKNOWN_TABLE`. Эта страница сохранена ради опубликованной в ней документации; список существующих на сегодняшний день таблиц см. в [обзоре системных таблиц](/ru/reference/system-tables/overview).
</Warning>

Содержала список моделей CatBoost, загруженных в память `LibraryBridge`, вместе со временем их загрузки.

## Столбцы {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/ru/reference/data-types/string)) — Путь к обученной модели.
* `type` ([String](/ru/reference/data-types/string)) — Тип модели. В настоящее время поддерживается только catboost.
* `loading_start_time` ([DateTime](/ru/reference/data-types/datetime)) — Время начала загрузки модели.
* `loading_duration` ([Float32](/ru/reference/data-types/float)) — Время, затраченное на загрузку модели.
