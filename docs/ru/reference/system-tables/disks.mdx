<div id="description">
  ## Описание
</div>

Содержит информацию о дисках, определённых в [конфигурации сервера](/ru/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-multiple-volumes_configure).

<div id="columns">
  ## Столбцы
</div>

{/*АВТОМАТИЧЕСКИ_СГЕНЕРИРОВАНО_START*/}

* `name` ([String](/ru/reference/data-types/string)) — Имя диска в конфигурации сервера.
* `path` ([String](/ru/reference/data-types/string)) — Путь к точке монтирования в файловой системе.
* `free_space` ([UInt64](/ru/reference/data-types/int-uint)) — Свободное место на диске в байтах.
* `total_space` ([UInt64](/ru/reference/data-types/int-uint)) — Объём диска в байтах.
* `unreserved_space` ([UInt64](/ru/reference/data-types/int-uint)) — Свободное место, не занятое резервированиями (free&#95;space за вычетом размера резервирований, занятых выполняемыми операциями слияния, вставки и другими операциями записи на диск).
* `keep_free_space` ([UInt64](/ru/reference/data-types/int-uint)) — Объём дискового пространства в байтах, который должен оставаться свободным. Определяется параметром keep&#95;free&#95;space&#95;bytes в конфигурации диска.
* `type` ([String](/ru/reference/data-types/string)) — Тип диска, определяющий, где хранятся данные: в оперативной памяти, на локальном диске или в удалённом хранилище.
* `object_storage_type` ([String](/ru/reference/data-types/string)) — Тип объектного хранилища, если тип диска — object&#95;storage.
* `metadata_type` ([String](/ru/reference/data-types/string)) — Тип хранилища метаданных, если тип диска — object&#95;storage.
* `is_encrypted` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, показывающий, шифрует ли этот диск хранящиеся на нём данные.
* `is_read_only` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, что с этим диском можно выполнять только операции чтения.
* `is_write_once` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли диск однократную запись. Такой диск поддерживает BACKUP на него, но не поддерживает INSERT в таблицу семейства MergeTree на этом диске.
* `is_remote` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, какие операции с этим диском требуют сетевого взаимодействия.
* `is_broken` ([UInt8](/ru/reference/data-types/int-uint)) — Флаг, указывающий, повреждён ли диск. Повреждённые диски имеют 0 свободного места и не могут использоваться.
* `cache_path` ([String](/ru/reference/data-types/string)) — Путь к каталогу кэша на локальном диске, если диск поддерживает кэширование.
