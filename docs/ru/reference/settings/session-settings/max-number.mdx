Эти настройки доступны в [system.settings](/ru/reference/system-tables/settings) и автоматически генерируются из [исходного кода](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/Settings.cpp).

<div id="max_number_of_partitions_for_independent_aggregation">
  ## max_number_of_partitions_for_independent_aggregation
</div>

<SettingsInfoBlock type="UInt64" default_value="128" />

Максимальное количество партиций таблицы, для которых выполняется независимая агрегация. Используется в эвристике оценки стоимости параметра [allow&#95;aggregate&#95;partitions&#95;independently](/ru/reference/settings/session-settings/allow#allow_aggregate_partitions_independently).

<div id="max_number_of_partitions_for_independent_distinct">
  ## max_number_of_partitions_for_independent_distinct
</div>

<SettingsInfoBlock type="UInt64" default_value="128" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "128"},{"label": "Новая настройка: максимальное количество партиций, для которых применяется независимый `DISTINCT`."}]}]} />

Максимальное количество партиций в таблице, для которых применяется независимый `DISTINCT` по каждой партиции. Часть эвристики оценки стоимости [allow&#95;distinct&#95;partitions&#95;independently](/ru/reference/settings/session-settings/allow#allow_distinct_partitions_independently).

<div id="max_number_of_partitions_for_independent_window">
  ## max_number_of_partitions_for_independent_window
</div>

Максимальное количество партиций в таблице, для которых применяется независимое вычисление оконных функций по каждой партиции. Часть эвристики оценки стоимости [allow&#95;window&#95;partitions&#95;independently](/ru/reference/settings/session-settings/allow#allow_window_partitions_independently).
