Выбирает реализацию проверки UNIQUE KEY на пути записи. В настоящее время доступна только однопоточная
базовая реализация, поэтому `auto` и `simple` используют её.

Зарезервировано: эта настройка пока не имеет эффекта — её значение не считывается, пока не будет подключён путь
записи UNIQUE KEY INSERT, создающий проверку. Она объявлена сейчас, чтобы этот параметр поставлялся вместе с
реализацией.
