  ## filesystem_cache_verbose_logging
</div>

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "Новая настройка, управляющая сообщениями лога уровня TEST при каждом пополнении буфера чтения файлового кэша, которые ранее выводились безусловно, как только уровень логирования позволял их выводить."}]}]} />

Выводить сообщения лога уровня `TEST` при каждом пополнении буфера файлового кэша (состояние чтения, оставшийся объём данных для чтения, количество прочитанных байтов). Только для отладки: сообщения форматируются один раз для каждого чтения, поэтому включение этой настройки для запроса, выполняющего множество небольших кэшированных чтений, создаёт значительные накладные расходы на логирование. Сообщения всё равно видны только при уровне логирования `test` (см. `send_logs_level`).

<div id="filesystem_cache_wait_for_concurrent_download_timeout_milliseconds">
  ## filesystem_cache_wait_for_concurrent_download_timeout_milliseconds
</div>

<SettingsInfoBlock type="UInt64" default_value="1000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1000"},{"label": "Новая настройка, ограничивающая время ожидания чтением сегмента файла, загружаемого в файловый кэш параллельным запросом; при тайм-ауте чтение обходит кэш вместо бесконечного ожидания. Предыдущее значение 60000 соответствует прежнему поведению (один полный 60-секундный цикл ожидания загрузчика)."}]}]} />

Максимальное время ожидания сегмента файла, загружаемого в файловый кэш параллельным запросом. При достижении тайм-аута чтение обходит файловый кэш для этого диапазона и считывает данные напрямую из удалённого хранилища, а параллельная загрузка продолжает заполнять кэш. Значение `0` означает не ждать вовсе: немедленно обойти кэш, если нужный диапазон ещё не загружен. Уменьшение этого значения ограничивает tail latency чтений с попаданием в кэш, которые в противном случае ожидали бы загрузки другим запросом, ценой дополнительных запросов к удалённому хранилищу.
