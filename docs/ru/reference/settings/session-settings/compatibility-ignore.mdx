Эти настройки доступны в [system.settings](/ru/reference/system-tables/settings) и автоматически генерируются на основе [исходного кода](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/Settings.cpp).

## compatibility_ignore_auto_increment_in_create_table {#compatibility_ignore_auto_increment_in_create_table}

<SettingsInfoBlock type="Bool" default_value="0" />

Если установлено значение `true`, игнорирует ключевое слово AUTO&#95;INCREMENT в объявлении столбца; в противном случае возвращает ошибку. Это упрощает миграцию из MySQL

## compatibility_ignore_collation_in_create_table {#compatibility_ignore_collation_in_create_table}

<SettingsInfoBlock type="Bool" default_value="1" />

Если настройка включена, секция `COLLATE` в объявлении столбца в запросе `CREATE TABLE` принимается и игнорируется. Это позволяет выполнять определения таблиц, написанные для других СУБД, например MySQL, без их редактирования.

Если настройка отключена, запрос `CREATE TABLE`, в котором для столбца задана collation, генерирует исключение.
