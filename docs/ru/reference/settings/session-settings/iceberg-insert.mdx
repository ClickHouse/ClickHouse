Максимальный размер в байтах файла данных Parquet Iceberg при выполнении вставки.

Значение по умолчанию повторяет документированное значение по умолчанию свойства таблицы Iceberg `write.target-file-size-bytes` (512 МиБ),
см. https://iceberg.apache.org/docs/1.5.2/configuration/. Обратите внимание, что ClickHouse сравнивает это ограничение с несжатым
размером данных, записанных в файл к текущему моменту, тогда как свойство Iceberg задаёт целевой размер
итогового файла; кроме того, `iceberg_insert_max_rows_in_data_file` ограничивает файл независимо от его размера.
