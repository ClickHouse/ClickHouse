## distributed_plan_read_in_order {#distributed_plan_read_in_order}

<ExperimentalBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "0"},{"label": "Новая настройка, разрешающая оптимизацию чтения в порядке сортировки для `ORDER BY` в распределённом плане запроса: отсортированное чтение по ключу сортировки таблицы может пропустить сортировку и завершиться раньше. По умолчанию отключена: в настоящее время безопасны только структуры, в которых между чтением и сортировкой нет EXCHANGE."}]}]} />

Разрешает оптимизацию чтения в порядке сортировки для `ORDER BY` в распределённом плане запроса, чтобы отсортированное чтение по ключу сортировки таблицы могло пропустить сортировку и завершиться раньше вместо сканирования и сортировки.

По умолчанию отключено: преобразование, распределяющее сортировку, предполагает, что оборачиваемая им сортировка не зависит от того, что её входные данные уже упорядочены. Однако сортировка, которая от этого зависит, может получать строки через EXCHANGE, не сохраняющий порядок. В настоящее время безопасны только структуры, в которых между чтением и сортировкой нет EXCHANGE.

## distributed_plan_workers_provisioning_timeout_ms {#distributed_plan_workers_provisioning_timeout_ms}

<ExperimentalBadge />

<SettingsInfoBlock type="UInt64" default_value="10000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "10000"},{"label": "Новая настройка, ограничивающая время ожидания запроса до того, как арендованные воркеры без сохранения состояния станут доступны перед выполнением; значение `compatibility` ниже 26.9 восстанавливает прежнее поведение без ожидания."}]}]} />

Общее фактическое время в миллисекундах, которое запрос может затратить на подготовку воркеров без сохранения состояния перед выполнением: их аренду у службы обнаружения и проверку доступности. В пределах этого лимита запрос ожидает готовности арендованных воркеров; по его истечении запрос продолжает выполняться с воркерами, проверенными к этому моменту, или завершается ошибкой, если ни один из них не стал доступен. При нулевом значении выполняется только начальный проход аренды и проверки (без повторных попыток).
