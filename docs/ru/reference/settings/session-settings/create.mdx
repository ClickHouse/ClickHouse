## create_token_default_ttl_seconds {#create_token_default_ttl_seconds}

<SettingsInfoBlock type="UInt64" default_value="1800" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1800"},{"label": "Новая настройка, задающая время жизни токена, созданного командой `CREATE TOKEN` без явного указания `VALID UNTIL` или `VALID FOR`. Оператор новый, поэтому восстанавливать нечего — прежнего поведения не существовало, а прежним значением является само значение по умолчанию: `compatibility` с более старой версией не должна превращать токены в бессрочные."}]}]} />

Время жизни в секундах, назначаемое токену, который создан командой [`CREATE TOKEN`](/ru/reference/statements/create/token) без собственного `VALID UNTIL` или `VALID FOR`. По умолчанию это 30 минут, то есть токен, для которого не запрошен более长 длительный срок, живёт недолго.

Возможные значения:

* Положительное целое число — токен истекает через указанное число секунд после создания.
* 0 — токен без явно указанного `VALID UNTIL` или `VALID FOR` не истекает никогда.

Это лишь значение по умолчанию. Явно указанные в запросе `VALID UNTIL` или `VALID FOR` всегда имеют приоритет, в том числе `VALID UNTIL 'infinity'`, который создаёт бессрочный токен независимо от этой настройки.
