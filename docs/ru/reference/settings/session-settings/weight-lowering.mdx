## weight_lowering_cpu_seconds {#weight_lowering_cpu_seconds}

<SettingsInfoBlock type="Double" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "Новая настройка запроса: порог набранных CPU-секунд, после достижения которого вес запроса понижается в планировщике рабочей нагрузки `fair`."}]}]} />

Для планировщика рабочей нагрузки `fair`: как только запрос набирает указанное количество CPU-секунд, его вес понижается в `weight_lowering_factor` раз. Применяется к ресурсам CPU. Значение `0` (или любое отрицательное значение) отключает порог по CPU. Набранное время CPU — это обслуживание, выделенное планировщиком: оно учитывается в момент удовлетворения запроса на ресурс, а не по мере фактического расходования CPU, поэтому опережает реальное потребление не более чем на один квант (`cpu_slot_quantum_ns`) на каждый активный слот. Настройка имеет смысл только при включённом вытеснении слотов CPU (`cpu_slot_preemption = 1`, значение по умолчанию). Без вытеснения каждому слоту CPU приписывается фиксированная стоимость, а не реальное время CPU, поэтому этот порог, как и другие настройки CPU для `fair`, перестаёт отражать фактическое потребление CPU.

## weight_lowering_factor {#weight_lowering_factor}

<SettingsInfoBlock type="Double" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Новая настройка запроса: множитель, применяемый к весу запроса, когда тот превышает порог снижения веса в планировщике рабочей нагрузки `fair`."}]}]} />

Для планировщика рабочей нагрузки `fair`: как только запрос превышает любой из перечисленных ниже порогов `weight_lowering_*`, его эффективный вес однократно умножается на этот множитель (значения в интервале (0, 1) снижают вес, смещая планирование в пользу более коротких или более новых запросов). Пороги не суммируются: первый сработавший порог применяет снижение в полном объёме. Значение `1.0` отключает снижение. Значение ограничивается диапазоном `[0, 1]`, поэтому множитель может только снижать вес запроса и никогда не повышает его.
