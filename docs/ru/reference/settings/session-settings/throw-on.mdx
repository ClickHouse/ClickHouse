</div>

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "Новая настройка: генерировать исключение, если при определении секционирования в стиле Hive для таблицы в объектном хранилище не удаётся получить список объектов хранилища, вместо выполнения запроса без столбцов партиций Hive."}]}]} />

Генерировать исключение вместо записи предупреждения в журнал, если при определении секционирования в стиле Hive для таблицы в объектном хранилище не удаётся получить список объектов хранилища. Если настройка отключена, запрос выполняется без столбцов партиций Hive, что может изменить его результат.

<div id="throw_on_max_partitions_per_insert_block">
  ## throw_on_max_partitions_per_insert_block
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

Позволяет управлять поведением при достижении значения `max_partitions_per_insert_block`.

Возможные значения:

* `true`  - Когда блок вставки достигает `max_partitions_per_insert_block`, генерируется исключение.
* `false` - При достижении `max_partitions_per_insert_block` в журнал записывается предупреждение.

<Tip>
  Это может быть полезно, если вы хотите оценить влияние изменения [`max_partitions_per_insert_block`](/ru/reference/settings/session-settings/max-partitions#max_partitions_per_insert_block) на пользователей.
</Tip>
