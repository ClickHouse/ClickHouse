## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "Метод сжатия по умолчанию для обмена между client\/server и server\/server изменён с `LZ4` на `ZSTD` для снижения сетевого трафика."}]}]} />

Кодек для сжатия данных при обмене между client/server и server/server по собственному протоколу, ответа на HTTP-запрос, выполненный с `compress=1`, который использует тот же формат кадра, а также потокового обмена между задачами распределённого плана запроса (`make_distributed_plan`). Обмен через временные файлы использует кодек сервера по умолчанию.

Возможные значения:

* `NONE` — без сжатия.
* `LZ4` — использовать кодек LZ4.
* `LZ4HC` — использовать кодек LZ4HC.
* `ZSTD` — использовать кодек ZSTD.

**См. также**

* [network&#95;zstd&#95;compression&#95;level](/ru/reference/settings/session-settings/network#network_zstd_compression_level)

## network_zstd_compression_level {#network_zstd_compression_level}

<SettingsInfoBlock type="Int64" default_value="3" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "3"},{"label": "Уровень сжатия `ZSTD` для сети по умолчанию приведён в соответствие с новым уровнем сжатия на диске по умолчанию `ZSTD(3)`."}]}]} />

Задает уровень сжатия ZSTD. Используется только если для [network&#95;compression&#95;method](/ru/reference/settings/session-settings/network#network_compression_method) установлено значение `ZSTD`.

Возможные значения:

* Положительное целое число от 1 до 15.
