## use_statistics_for_min_max_aggregation {#use_statistics_for_min_max_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Новая настройка, позволяющая вычислять агрегации `min`, `max` и `count` без `GROUP BY` и фильтров по постатейной статистике столбцов тех частей, где она материализована, считывая только оставшиеся части. previous_value=false, поэтому `compatibility` с версиями до 26.9 оставляет оптимизацию отключенной и восстанавливает прежний план."}]}]} />

Вычисляет агрегации `min`, `max` и `count` по статистике столбцов отдельных частей вместо чтения данных.

Когда настройка включена, запрос вида `SELECT min(column), max(column), count() FROM table` без `GROUP BY` и фильтров
вычисляется по статистике столбцов (например, статистике MinMax, см. настройку MergeTree `auto_statistics_types`)
для тех частей данных, где она материализована, а читаются только оставшиеся части.

Возможные значения:

* 0 — отключено.
* 1 — включено.

## use_statistics_for_part_pruning {#use_statistics_for_part_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1"},{"label": "Новая настройка для использования статистики при отсечении частей во время выполнения запроса."}]}]} />

Использует статистику для отсеивания частей во время выполнения запроса.

Когда включено, отсечение частей в запросах SELECT использует статистику столбцов (например, статистику MinMax), чтобы исключать части, которые не могут содержать подходящие данные, до чтения каких-либо данных.

Возможные значения:

* 0 — Отключено.
* 1 — Включено.
