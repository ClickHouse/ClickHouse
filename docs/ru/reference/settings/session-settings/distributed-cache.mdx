## distributed_cache_client_id {#distributed_cache_client_id}

<CloudOnlyBadge />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": ""},{"label": "Новая настройка (только для CI-тестов), позволяющая переопределить идентификатор клиента распределённого кэша для каждого запроса."}]}, {"id": "row-2","items": [{"label": "26.8"},{"label": ""},{"label": "Новая настройка (только для CI-тестов), позволяющая переопределить идентификатор клиента распределённого кэша для каждого запроса."}]}]} />

Действует только в ClickHouse Cloud. Настройка используется только для CI-тестов: если она не пуста, то переопределяет настроенный в реестре идентификатор клиента распределённого кэша для запросов данного запроса. Позволяет тестам распределять данные по ограниченному набору идентификаторов клиентов, сохраняя одни и те же данные за одним и тем же идентификатором клиента. Требует включения `ci_mode` в конфигурации клиента распределённого кэша: если он не включён (что используется по умолчанию, в том числе в продакшне), запрос, выполняющий чтение или запись через распределённый кэш, завершается с ошибкой `SUPPORT_IS_DISABLED` вместо незаметного возврата к настроенному идентификатору клиента. Запросы, которые никогда не обращаются к распределённому кэшу, не затрагиваются, поэтому значение для них игнорируется.
