## use_iceberg_manifest_list_partition_pruning {#use_iceberg_manifest_list_partition_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Новая настройка, позволяющая пропускать manifest files Iceberg без чтения, если их сводки по партициям из manifest list не могут соответствовать фильтру запроса."}]}]} />

Пропускать целиком manifest files Iceberg без их чтения, если сводки по партициям в manifest list не могут соответствовать фильтру запроса. Требует включенной настройки [use&#95;iceberg&#95;partition&#95;pruning](/ru/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning) и даёт выигрыш только в том случае, когда manifest file содержит небольшое число различных значений партиций — именно такой результат даёт `rewriteManifests` с кластеризацией по столбцам партиции.

## use_iceberg_metadata_files_cache {#use_iceberg_metadata_files_cache}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.4"},{"label": "1"},{"label": "Новая настройка"}]}]} />

Если включено, табличная функция Iceberg и хранилище Iceberg могут использовать кэш файлов метаданных Iceberg.

Возможные значения:

* 0 - Отключено
* 1 - Включено
