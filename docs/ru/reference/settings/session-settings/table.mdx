## table_engine_read_through_distributed_cache {#table_engine_read_through_distributed_cache}

Действует только в ClickHouse Cloud. Разрешает чтение из distributed cache через движки таблиц и табличные функции (s3, azure, Iceberg, Delta Lake и т. д.). Значение `auto` (по умолчанию) означает, что чтение выполняется через distributed cache, если он используется для других операций чтения. Это определяется настройкой сервера `enable_read_through_distributed_cache` и настройкой `force_read_through_distributed_cache`. Ключом кэша служит ETag объекта, чтобы после перезаписи объекта по тому же адресу не возвращалась его устаревшая версия, либо неизменяемый идентификатор файла данных из записей таблицы (Iceberg, Delta Lake), что позволяет обойтись без запроса `HEAD`. Объект без сильного ETag или такого идентификатора читается напрямую из объектного хранилища. Напрямую также выполняются операции чтения, которые сервер кэша не может повторить: чтение из таблиц `url`, чтение через `s3` с `NOSIGN` или `headers`, чтение файлов данных с полным путём (поверхностный клон Delta Lake), а также чтение через `azure`, если значение настройки не равно `1`.
