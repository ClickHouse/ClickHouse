## obfuscate_markov_order {#obfuscate_markov_order}

<SettingsInfoBlock type="UInt64" default_value="5" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "5"},{"label": "Новая настройка: максимальный размер буфера контекста для устаревшей марковской модели табличной функции obfuscate."}]}]} />

Максимальный размер буфера контекста, используемый устаревшей марковской моделью в табличной функции `obfuscate`. Модель запоминает контексты, длина которых меньше этого значения, что сохраняет семантику автономного инструмента `clickhouse obfuscator`. Значение должно находиться в диапазоне `[1, 1000]`.
