## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "Новая облачная настройка"}]}]} />

Действует только в ClickHouse Cloud. Максимальный размер буфера, записываемого на серверы распределённого кэша, в расчёте на каждый буфер записи. Он не связан с буфером, который записывается в объектное хранилище: тот продолжает расти до размера загружаемой части. Если `0`, используется `DBMS_DEFAULT_BUFFER_SIZE` (1 МиБ). Буфер начинается с `adaptive_write_buffer_initial_size` и растёт до указанного размера только по мере записи потока, чтобы part не выделял его для каждого записываемого потока.
