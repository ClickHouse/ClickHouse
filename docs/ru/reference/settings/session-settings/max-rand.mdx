Максимально допустимое значение параметров формы распределения в функциях случайных распределений, таких как `randChiSquared`, `randStudentT` и `randFisherF`. Это позволяет избежать чрезмерно долгих вычислений при экстремальных значениях параметров. `0` отключает ограничение; значения, при которых сэмплер вообще не завершает работу, по-прежнему отклоняются.

Максимально допустимое число испытаний для функций случайных распределений, таких как `randBinomial` и `randNegativeBinomial`. Это предотвращает чрезмерно долгое время вычислений при большом числе испытаний. Значение `0` отключает ограничение, и значение настройки можно увеличить выше значения по умолчанию, за исключением `randBinomial` с вероятностью строго между 0 и 1: эта функция всегда отклоняет более 10^9 испытаний, поскольку в худшем случае стоимость формирования одной выборки пропорциональна числу испытаний с вероятностью, которая возрастает вместе с ним. Вероятности 0 и 1 не подпадают под это жёсткое ограничение, поскольку для них формирование выборки занимает постоянное время.
