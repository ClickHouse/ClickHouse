## read_from_filesystem_cache_if_exists_otherwise_bypass_cache {#read_from_filesystem_cache_if_exists_otherwise_bypass_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

Разрешает использовать файловый кэш в пассивном режиме — задействовать существующие записи кэша, но не добавлять в него новые. Если включить эту настройку для тяжёлых ad-hoc-запросов и оставить её отключённой для коротких запросов реального времени, это позволит избежать вытеснения данных из кэша такими запросами и повысить общую эффективность системы.

## read_from_filesystem_cache_if_exists_otherwise_cache_temporarily {#read_from_filesystem_cache_if_exists_otherwise_cache_temporarily}

<ExperimentalBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Новая экспериментальная настройка."}]}]} />

Использует файловый кэш как временный буфер для данных, которых в нём нет: при промахе данные считываются в кэш и отдаются из него, а когда они больше никем не удерживаются, кэш их удаляет — если только их не использовал считыватель или записывающий компонент, работающий вне этого режима. Поддерживается только экспериментальным `ReaderExecutor`; остальные считыватели работают в обход кэша. Настройка `read_from_filesystem_cache_if_exists_otherwise_bypass_cache` имеет более высокий приоритет.
