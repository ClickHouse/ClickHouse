## enable_parallel_single_level_merge {#enable_parallel_single_level_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "Новая настройка для распараллеливания окончательного слияния single-level хеш-таблиц агрегации путём разбиения пространства ключей на непересекающиеся хеш-партиции, которые потоки сливают независимо друг от друга."}]}]} />

Распараллеливает окончательное слияние single-level хеш-таблиц агрегации отдельных потоков. Пространство ключей разбивается на непересекающиеся партиции по хешу ключа, и каждая партиция сливается независимо: поток слияния перебирает все таблицы отдельных потоков и объединяет ключи, принадлежащие его партиции, поэтому два потока никогда не работают с одним и тем же ключом. Если настройка отключена, single-level таблицы сливаются последовательно в одном потоке. Агрегация по 8- и 16-битным ключам использует собственное параллельное слияние с разбиением по диапазонам независимо от этой настройки.

## enable_parallel_single_level_merge_by_index {#enable_parallel_single_level_merge_by_index}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "1"},{"label": "Новая настройка, позволяющая параллельному слиянию читать из single-level хеш-таблиц адаптивного агрегатора только ячейки каждой партиции с помощью индексов их ячеек вместо сканирования всех ячеек каждой таблицы для каждой партиции."}]}]} />

Позволяет параллельному слиянию single-level хеш-таблиц агрегации (см. `enable_parallel_single_level_merge`) читать таблицы адаптивного агрегатора (см. `enable_adaptive_aggregator`) с помощью индекса их ячеек, который каждый поток строит по завершении агрегирования. В результате для каждой партиции слияние читает из каждой таблицы только ячейки этой партиции. Если настройка отключена, слияние сканирует все ячейки каждой таблицы для каждой партиции.
