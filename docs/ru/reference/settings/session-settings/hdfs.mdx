## hdfs_create_new_file_on_insert {#hdfs_create_new_file_on_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

Включает или отключает создание нового файла при каждой вставке в таблицы с движком HDFS. Если параметр включен, при каждой вставке будет создаваться новый HDFS-файл с именем по следующему шаблону:

initial: `data.Parquet.gz` -&gt; `data.1.Parquet.gz` -&gt; `data.2.Parquet.gz` и т. д.

Возможные значения:

* 0 — запрос `INSERT` дописывает новые данные в конец файла.
* 1 — запрос `INSERT` создает новый файл.

## hdfs_skip_empty_files {#hdfs_skip_empty_files}

## hdfs_skip_hidden_files {#hdfs_skip_hidden_files}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Новая настройка: при получении списка файлов по глоб-шаблону пропускать файлы, у которых сегмент пути ниже префикса без глоб-шаблона начинается с `_` или `.`, — так же, как это делают другие считыватели экосистемы Hive. Включает или отключает пропуск скрытых путей при получении списка файлов по глоб-шаблону в таблицах с движком [HDFS](/ru/reference/engines/table-engines/integrations/hdfs). Скрытыми считаются файлы, у которых сегмент пути ниже префикса без глоб-шаблона начинается с `_` или `.`. Сегмент, содержащий `=`, является каталогом партиции (например, `_p=1` для столбца партиции `_p`) и скрытым не считается. Пишущие компоненты экосистемы Hive (Hive, Spark, Trino) размещают незавершённый вывод в промежуточном хранилище и записывают файлы-маркеры по таким путям (`_temporary/`, `.spark-staging-<id>/`, `_SUCCESS`), поэтому их чтение приводит к состоянию гонки с коммитом пишущей стороны. Сегменты внутри префикса без глоб-шаблона не проверяются. Таблицы с `partition_strategy = 'hive'` всегда пропускают скрытые пути независимо от этой настройки.

Возможные значения:

* 0 — читаются все файлы, совпадающие с глоб-шаблоном.
* 1 — файлы со скрытым сегментом пути ниже префикса без глоб-шаблона пропускаются.

## hdfs_truncate_on_insert {#hdfs_truncate_on_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

Включает или отключает усечение файла перед вставкой в таблицы движка HDFS. Если параметр отключён, при попытке выполнить вставку будет сгенерировано исключение, если файл в HDFS уже существует.

Возможные значения:

* 0 — запрос `INSERT` дописывает новые данные в конец файла.
* 1 — запрос `INSERT` заменяет существующее содержимое файла новыми данными.
