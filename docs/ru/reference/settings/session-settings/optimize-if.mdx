## optimize_if_chain_to_multiif {#optimize_if_chain_to_multiif}

<SettingsInfoBlock type="Bool" default_value="0" />

Заменяет цепочки if(cond1, then1, if(cond2, ...)) на multiIf. На данный момент это не дает преимуществ для числовых типов.

## optimize_if_transform_const_strings_to_lowcardinality {#optimize_if_transform_const_strings_to_lowcardinality}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Новая настройка, позволяющая оптимизировать результаты константных ветвей `if`\/`multiIf`\/`transform`, преобразуя их в `LowCardinality`. По умолчанию отключена."}]}]} />

Если настройка включена, функции `if`, `multiIf` и `transform` с константными строковыми ветвями результата (и значениями по умолчанию) возвращают `LowCardinality(String)` вместо `String`.
По умолчанию настройка отключена, поскольку построение словаря `LowCardinality` для каждого блока может оказаться медленнее, чем возврат обычного `String`, если словарь не используется повторно на последующих этапах.
Оптимизация не применяется, если всё выражение константное (то есть константными являются также условие или входные данные): константе `LowCardinality` ничего не даёт, а функции, ожидающие константные аргументы типа `String` (например, `arrayReduce`, `joinGet`, `tupleElement`), продолжают работать.

Все ветви результата должны быть константами, поэтому вложенная цепочка `if`, например `if(cond1, 'a', if(cond2, 'b', 'c'))`, по-прежнему возвращает обычный `String`: ветвь else внешнего `if` — это другой `if`, а не константа. Чтобы получить `LowCardinality(String)`, запишите выражение как `multiIf(cond1, 'a', cond2, 'b', 'c')`.

Эта настройка не действует, пока включена `optimize_if_transform_strings_to_enum`: переписывание в `Enum` имеет старшинство, и результат остаётся `String` (или `Nullable(String)`) даже для явной формы `multiIf`, приведённой выше.

## optimize_if_transform_strings_to_enum {#optimize_if_transform_strings_to_enum}

<SettingsInfoBlock type="Bool" default_value="0" />

Заменяет аргументы строкового типа в If и Transform на enum. По умолчанию отключено, так как может привести к несогласованным изменениям в распределённом запросе, из-за чего тот завершится с ошибкой.
