## opentelemetry_trace_stateless_worker_discovery {#opentelemetry_trace_stateless_worker_discovery}

<CloudOnlyBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "Новая настройка для сбора спанов OpenTelemetry по запросам к сервису автоматического обнаружения stateless-worker, которые выполняет запрос, чтобы подготовить и настроить воркеры."}]}]} />

Действует только в ClickHouse Cloud. Если запрос сам трассируется, собирает спаны OpenTelemetry по запросам, которые он отправляет сервису автоматического обнаружения stateless-worker, чтобы подготовить и настроить (арендовать) воркеры.
Спаны называются `StatelessWorkerDiscovery.<action>` и содержат атрибуты `clickhouse.discovery.action` и `clickhouse.discovery.status`.
