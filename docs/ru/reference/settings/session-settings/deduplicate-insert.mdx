  ## deduplicate_insert

Включает или отключает дедупликацию блоков при `INSERT INTO` (для таблиц Replicated*).
Этот параметр применяется как к синхронным, так и к асинхронным вставкам и переопределяет параметры `insert_deduplicate` и `async_insert_deduplicate`.
У этого параметра есть три возможных значения:

* disable — Дедупликация отключена для запроса `INSERT INTO`.
* enable — Дедупликация включена для запроса `INSERT INTO`.
* backward&#95;compatible&#95;choice — Дедупликация включается, если для соответствующего типа вставки включен `insert_deduplicate` или `async_insert_deduplicate`.

Для запросов `INSERT SELECT` сначала проверяется [`deduplicate_insert_select`](/ru/reference/settings/session-settings/deduplicate-insert#deduplicate_insert_select). Для дедупликации также требуется, чтобы целевая таблица вела журнал дедупликации; см. [replicated&#95;deduplication&#95;window](/ru/reference/settings/merge-tree-settings/replicated-deduplication-window#replicated_deduplication_window) и [non&#95;replicated&#95;deduplication&#95;window](/ru/reference/settings/merge-tree-settings/other#non_replicated_deduplication_window).

Включает или отключает дедупликацию блоков для `INSERT SELECT` (для таблиц Replicated*).
Для запросов `INSERT SELECT` эта настройка учитывается перед [`deduplicate_insert`](/ru/reference/settings/session-settings/deduplicate-insert#deduplicate_insert).
`SELECT` считается стабильным, если содержит `ORDER BY ALL`, а его конвейер завершается одним потоком. Непустой [`insert_deduplication_token`](/ru/reference/settings/session-settings/insert#insert_deduplication_token) является эквивалентной заменой стабильности.
У этой настройки есть четыре возможных значения:

* disable — Дедупликация для запроса `INSERT SELECT` отключена.
* force&#95;enable — Дедупликация для запроса `INSERT SELECT` включена независимо от `deduplicate_insert`. Если результат SELECT нестабилен и токен не указан, генерируется исключение.
* enable&#95;when&#95;possible — Дедупликация включается, если она включена настройкой `deduplicate_insert` и результат SELECT стабилен, в противном случае отключается.
* enable&#95;even&#95;for&#95;bad&#95;queries - Дедупликация включается, если она включена настройкой `deduplicate_insert`, независимо от того, стабилен ли результат SELECT. Если результат SELECT нестабилен, в журнал записывается сообщение, но запрос выполняется с дедупликацией. Этот параметр предназначен для обратной совместимости. Рекомендуется использовать другие варианты, так как этот может приводить к неожиданным результатам.
