## allow_experimental_nullable_tuple_type {#allow_experimental_nullable_tuple_type}

<BetaBadge />

**Псевдонимы**: `enable_nullable_tuple_type`

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.1"},{"label": "0"},{"label": "Новая экспериментальная настройка"}]}]} />

Разрешает создавать в таблицах столбцы типа [Nullable](/ru/reference/data-types/nullable) [Tuple](/ru/reference/data-types/tuple).
