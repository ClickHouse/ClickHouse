## allow_experimental_analyzer {#allow_experimental_analyzer}

**Псевдонимы**: `enable_analyzer`

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Настройка устарела: анализатор теперь обязателен, а прежний анализ запросов больше не поддерживается. Устарело с v26.9: анализатор больше нельзя отключить.

Анализатор — это инфраструктура для анализа и планирования запросов, используемая по умолчанию с версии v24.3. В v26.9 эта настройка зафиксирована на единственном поддерживаемом значении `1`, а настройка `compatibility` больше не возвращает прежнее поведение. В v26.10 анализ запросов, на который она переключала, был удалён. Для обратной совместимости значение `0` принимается, но заменяется на `1`, поэтому запросы, настройки сеанса, профили настроек и конфигурации клиентов, в которых по-прежнему задано `enable_analyzer = 0`, продолжают работать — но уже с анализатором. Чтобы сравнить поведение или производительность запроса с прежним анализом запросов, используйте версию ClickHouse старше v26.9.

## allow_experimental_parallel_reading_from_replicas {#allow_experimental_parallel_reading_from_replicas}

**Псевдонимы**: `enable_parallel_replicas`

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "24.10"},{"label": "0"},{"label": "Параллельные реплики с задачами чтения перешли на уровень бета. Настройка также доступна под псевдонимом `enable_parallel_replicas`."}]}]} />

Использовать до `max_parallel_replicas` реплик из каждого сегмента при выполнении запроса SELECT. Чтение распараллеливается и координируется динамически. 0 — отключено, 1 — включено, при сбое отключается без уведомления, 2 — включено, при сбое сгенерировать исключение

## allow_experimental_shuffle_query {#allow_experimental_shuffle_query}

<ExperimentalBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Новая настройка, разрешающая экспериментальную секцию `SHUFFLE` в `SELECT`-запросах."}]}]} />

Разрешает использование экспериментальной секции `SHUFFLE` в `SELECT`-запросах. `SHUFFLE` используется вместо `ORDER BY` и возвращает строки в случайном порядке с равномерным распределением.
