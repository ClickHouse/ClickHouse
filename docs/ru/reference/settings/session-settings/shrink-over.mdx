  ## shrink_over_allocated_columns_min_waste_bytes

Минимальный абсолютный объём неиспользуемой (зарезервированной, но не используемой) памяти в столбце в байтах, при котором его размер уменьшается до необходимого при INSERT. См. [shrink&#95;over&#95;allocated&#95;columns&#95;min&#95;waste&#95;ratio](/ru/reference/settings/session-settings/shrink-over#shrink_over_allocated_columns_min_waste_ratio).

Предотвращает перераспределение столбцов с небольшим избыточным выделением памяти, когда экономия памяти не оправдывает затрат.

<div id="shrink_over_allocated_columns_min_waste_ratio">
  ## shrink_over_allocated_columns_min_waste_ratio
</div>

<SettingsInfoBlock type="Float" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "Новая настройка для уменьшения чрезмерно выделенных столбцов при INSERT с целью снижения пикового потребления памяти. По умолчанию отключена (1.0)."}]}]} />

При INSERT чрезмерно выделенные столбцы (у которых объём зарезервированной памяти превышает объём используемой, например из-за роста столбцов переменной длины по степеням двойки) уменьшаются до необходимого размера перед затратными стадиями материализации и записи части, чтобы снизить пиковое потребление памяти.

Столбец уменьшается только при выполнении условия `allocatedBytes() > byteSize() * shrink_over_allocated_columns_min_waste_ratio` и если абсолютный объём неиспользуемой памяти составляет не менее `shrink_over_allocated_columns_min_waste_bytes`.

Возможные значения:

* Float больше 1.
* Значение меньше или равное 1 отключает уменьшение (значение по умолчанию `1.0` оставляет его отключённым).
