## optimize_min_max_from_files {#optimize_min_max_from_files}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Новая настройка для вычисления `min` \/ `max` по статистике фрагментов столбцов Parquet."}]}]} />

Включает или отключает вычисление `min` и `max` столбцов по статистике, сохранённой в файлах данных, без чтения самих данных. Используется для запросов без `GROUP BY` и без фильтров, в которых единственными агрегатными функциями являются `min` и `max` от столбцов таблицы. Применяется к табличной функции/движку `file` с форматом `Parquet` (кроме файлов внутри архивов) для столбцов с целыми числами (до 64 бит), датами, датами со временем и типом Decimal, если статистика фрагментов столбцов присутствует в каждой группе строк.

Возможные значения:

* 0 — Оптимизация отключена.
* 1 — Оптимизация включена.
