## use_page_cache_for_local_disks {#use_page_cache_for_local_disks}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "Новая настройка для использования кэша страниц в пространстве пользователя для локальных дисков"}]}]} />

Использовать кэш страниц в пространстве пользователя при чтении с локальных дисков. Применяется для тестирования и вряд ли даст заметный прирост производительности на практике. Требует `local_filesystem_read_method = 'pread'` или `'read'`. Не отключает кэш страниц ОС; для этого можно использовать `min_bytes_to_use_direct_io`. Влияет только на обычные таблицы, но не на табличную функцию `file()` и не на движок таблицы `File()`.

## use_page_cache_for_object_storage {#use_page_cache_for_object_storage}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "Новая настройка для использования кэша страниц в пространстве пользователя в табличных функциях объектного хранилища"}]}, {"id": "row-2","items": [{"label": "26.12"},{"label": "1"},{"label": "По умолчанию кэш страниц в пространстве пользователя используется для движков таблиц и табличных функций объектного хранилища, если страничный кэш настроен на сервере."}]}]} />

Использовать кэш страниц в пространстве пользователя при чтении из табличных функций объектного хранилища (s3, azure, hdfs, Iceberg, Delta Lake и т. д.) и движков таблиц (S3, Azure, HDFS, Iceberg, Delta Lake и т. д.). Настройка действует, только если кэш страниц в пространстве пользователя настроен на сервере (`page_cache_max_size`), и только для объектов с сильным ETag или с неизменяемой идентичностью, полученной из записей таблицы (файлы данных Iceberg и Delta Lake). Одновременно с файловым кэшем не используется. Вместе с distributed cache используется, только если дополнительно включена настройка `use_page_cache_with_distributed_cache`.

## use_page_cache_lookahead_for_text_index {#use_page_cache_lookahead_for_text_index}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Новая настройка"}]}]} />

Файлы текстового индекса, которые читаются не последовательно (словарь, списки вхождений, позиции), по умолчанию читаются через кэш страниц в пространстве пользователя с упреждающим чтением на один блок, чтобы после каждого чтения можно было повторно использовать удалённое соединение. Включите эту настройку, чтобы эти файлы, как и все остальные, использовали `page_cache_lookahead_blocks`.
