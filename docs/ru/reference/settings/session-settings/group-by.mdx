<div id="group_by_overflow_mode">
  ## group_by_overflow_mode
</div>

<SettingsInfoBlock type="OverflowModeGroupBy" default_value="throw" />

Определяет, что происходит, когда число уникальных ключей агрегации превышает лимит:

* `throw`: сгенерировать исключение
* `break`: остановить выполнение запроса и вернуть частичный результат
* `any`: продолжить агрегацию для ключей, попавших в набор, но не добавлять в него новые ключи.

Использование значения `any` позволяет выполнить приблизительный вариант GROUP BY. Качество
этого приближения зависит от статистической природы данных.

</div>

Для `enable_group_by_top_k_optimization`: количество строк, наблюдаемых каждым потоком агрегации перед заморозкой полной кучи top-K, которая пропустила менее 10 % входных строк и вытеснила меньше ключей, чем её вместимость. Замороженная куча означает, что агрегация продолжается так, как если бы оптимизация была отключена.

Фактическое окно как минимум вдвое превышает зарезервированный размер кучи, поэтому куча всегда успевает заполниться до оценки. `0` отключает эту заморозку (куча всё равно замораживается, если граничный набор равных значений разрастается сверх её размера).

Это не влияет на запросы `GROUP BY keys LIMIT K` без `ORDER BY`, для которых заморозка всегда отключена: план такого запроса содержит синтезированную сортировку, которая оправдана лишь пока куча ограничивает хеш-таблицу, поэтому заморозка кучи сделала бы план медленнее, чем без оптимизации.

<div id="group_by_two_level_threshold">
  ## group_by_two_level_threshold
</div>

<SettingsInfoBlock type="UInt64" default_value="100000" />

При каком количестве ключей начинается двухуровневая агрегация. 0 — порог не задан.

<div id="group_by_two_level_threshold_bytes">
  ## group_by_two_level_threshold_bytes
</div>

<SettingsInfoBlock type="UInt64" default_value="50000000" />

Минимальный размер состояния агрегации в байтах, при котором начинает использоваться двухуровневая агрегация. 0 — порог не задан. Двухуровневая агрегация используется, когда срабатывает хотя бы один из порогов.

<div id="group_by_use_nulls">
  ## group_by_use_nulls
</div>

<SettingsInfoBlock type="Bool" default_value="0" />

Изменяет способ обработки типов ключей агрегации в [секции GROUP BY](/ru/reference/statements/select/group-by).
Когда используются спецификаторы `ROLLUP`, `CUBE` или `GROUPING SETS`, некоторые ключи агрегации могут не участвовать в формировании отдельных строк результата.
Столбцы для этих ключей в соответствующих строках заполняются либо значением по умолчанию, либо `NULL` — в зависимости от этой настройки.

Возможные значения:

* 0 — Для заполнения отсутствующих значений используется значение по умолчанию для типа ключа агрегации.
* 1 — ClickHouse выполняет `GROUP BY` в соответствии со стандартом SQL. Типы ключей агрегации преобразуются в [Nullable](/ru/reference/data-types/nullable). Столбцы соответствующих ключей агрегации заполняются значением [NULL](/ru/reference/syntax#null) в строках, где эти ключи не использовались.
