## iceberg_compaction_max_bytes_to_merge {#iceberg_compaction_max_bytes_to_merge}

<SettingsInfoBlock type="UInt64" default_value="161061273600" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "161061273600"},{"label": "Новая настройка. Ограничивает общий размер файлов, участвующих в слиянии при компакции, аналогично тому, как это делает `max_bytes_to_merge_at_max_space_in_pool` для `MergeTree`."}]}]} />

Максимальный общий размер файлов данных, объединяемых одним слиянием при компакции таблицы Iceberg, — сумма их размеров в объектном хранилище.
Работает так же, как `max_bytes_to_merge_at_max_space_in_pool` для `MergeTree`: когда в фоновом пуле свободных слотов меньше, чем
`number_of_free_entries_in_pool_to_lower_max_size_of_merge`, лимит снижается до `max_bytes_to_merge_at_min_space_in_pool`
(обе настройки задаются в разделе `merge_tree` конфигурации).
Файлы партиции, не уместившиеся в лимит, объединяются последующими слияниями. Не распространяется на слияния, при которых применяются файлы позиционного удаления.
