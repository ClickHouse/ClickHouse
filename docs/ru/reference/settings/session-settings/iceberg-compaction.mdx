Количество слитых файлов данных, которое фоновая компактация Iceberg накапливает перед публикацией в новом снимке.

Результаты компактации в любом случае публикуются, когда кандидатов для компактации больше не остаётся, поэтому эта настройка ограничивает лишь то,
как долго уже слитые файлы остаются неопубликованными, пока компактация продолжает находить новую работу. `0` восстанавливает прежнее поведение:
публикацию только после того, как у компактации закончатся кандидаты. Это состояние никогда не достигается, пока таблица продолжает
получать новые файлы данных, поэтому каждый слитый результат записывается в объектное хранилище, но никогда не включается в снимок.

Максимальное число строк в файле данных Parquet Iceberg, создаваемом при компактации. По умолчанию задано максимальное значение, чтобы компактация объединяла подходящие файлы в минимально возможное число выходных файлов. Если установить значение выше размера, который компактация может фактически создать, каждый выходной файл будет оставаться меньше `iceberg_data_file_size_lower_threshold_compaction` и бесконечно выбираться повторно.
