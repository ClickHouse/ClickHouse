Эти настройки доступны в [system.settings](/ru/reference/system-tables/settings) и автоматически сгенерированы на основе [исходного файла](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/Settings.cpp).

## query_cache_compress_entries {#query_cache_compress_entries}

<SettingsInfoBlock type="Bool" default_value="1" />

Сжимает записи в [кэше запросов](/ru/concepts/features/performance/caches/query-cache). Снижает расход памяти кэша запросов ценой замедления записи в него и чтения из него.

Возможные значения:

* 0 - Отключено
* 1 - Включено

## query_cache_max_entries {#query_cache_max_entries}

<SettingsInfoBlock type="UInt64" default_value="0" />

Максимальное количество результатов запросов, которые текущий пользователь может хранить в [кэше запросов](/ru/concepts/features/performance/caches/query-cache) в памяти. 0 означает отсутствие ограничений.

Это ограничение не распространяется на кэш запросов на диске (настройка `query_cache_on_disk_cache_name`): количество его записей ограничивается размером базового файлового кэша.

Возможные значения:

* Неотрицательное целое число &gt;= 0.

## query_cache_max_size_in_bytes {#query_cache_max_size_in_bytes}

<SettingsInfoBlock type="UInt64" default_value="0" />

Максимальный объём памяти (в байтах), который текущий пользователь может выделить для [кэша запросов](/ru/concepts/features/performance/caches/query-cache) в памяти. 0 означает отсутствие ограничений.

Это ограничение не распространяется на кэш запросов на диске (настройка `query_cache_on_disk_cache_name`): общий объём его записей ограничивается размером базового файлового кэша.

Возможные значения:

* Положительное целое число &gt;= 0.

## query_cache_min_query_duration {#query_cache_min_query_duration}

<SettingsInfoBlock type="Milliseconds" default_value="0" />

Минимальная длительность выполнения запроса в миллисекундах, необходимая для сохранения его результата в [кэш запросов](/ru/concepts/features/performance/caches/query-cache).

Возможные значения:

* Неотрицательное целое число &gt;= 0.

## query_cache_min_query_runs {#query_cache_min_query_runs}

<SettingsInfoBlock type="UInt64" default_value="0" />

Минимальное количество выполнений `SELECT`-запроса, после которого его результат сохраняется в [кэше запросов](/ru/concepts/features/performance/caches/query-cache).

Возможные значения:

* Целое число &gt;= 0.

## query_cache_nondeterministic_function_handling {#query_cache_nondeterministic_function_handling}

<SettingsInfoBlock type="QueryResultCacheNondeterministicFunctionHandling" default_value="throw" />

Определяет, как [кэш запросов](/ru/concepts/features/performance/caches/query-cache) обрабатывает запросы `SELECT` с недетерминированными функциями, такими как `rand()` или `now()`.

Возможные значения:

* `'throw'` - сгенерировать исключение и не кэшировать результат запроса.
* `'save'` - кэшировать результат запроса.
* `'ignore'` - не кэшировать результат запроса и не генерировать исключение.

## query_cache_on_disk_cache_name {#query_cache_on_disk_cache_name}

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": ""},{"label": "Новая настройка для хранения записей кэша запросов на диске в именованном файловом кэше."}]}]} />

Имя файлового кэша (записи в разделе `filesystem_caches` конфигурации сервера), в котором хранятся на диске записи [кэша запросов](/ru/concepts/features/performance/caches/query-cache). Если имя задано (и включена настройка [use&#95;query&#95;cache](/ru/reference/settings/session-settings/use-query#use_query_cache)), результаты запросов дополнительно кэшируются в указанном файловом кэше и отдаются из него. Кэш запросов на диске вмещает больше данных, чем кэш запросов в памяти, сохраняется после перезапуска сервера и работает независимо от кэша запросов в памяти: настройки [enable&#95;reads&#95;from&#95;query&#95;cache&#95;on&#95;disk](/ru/reference/settings/session-settings/enable#enable_reads_from_query_cache_on_disk) и [enable&#95;writes&#95;to&#95;query&#95;cache&#95;on&#95;disk](/ru/reference/settings/session-settings/enable#enable_writes_to_query_cache_on_disk) управляют им отдельно от кэша запросов в памяти. Эти записи — обычные записи файлового кэша: они не защищены от удаления и вытесняются по тем же правилам, что и любые другие данные в нём. `SYSTEM CLEAR FILESYSTEM CACHE '<name>'` удаляет их вместе со всем остальным содержимым файлового кэша, а `SYSTEM CLEAR QUERY CACHE` удаляет записи кэша запросов на диске из файлового кэша, заданного этой настройкой, не затрагивая остальные данные. Для результатов запросов рекомендуется использовать отдельный файловый кэш.

Возможные значения:

* Пустая строка — кэш запросов на диске отключён
* Имя заранее настроенного файлового кэша

## query_cache_share_between_users {#query_cache_share_between_users}

<SettingsInfoBlock type="Bool" default_value="0" />

Если этот параметр включен, результаты `SELECT`-запросов, кэшированные в [кэше запросов](/ru/concepts/features/performance/caches/query-cache), могут быть доступны другим пользователям.
Не рекомендуется включать этот параметр по соображениям безопасности.

Возможные значения:

* 0 - Отключено
* 1 - Включено

## query_cache_squash_partial_results {#query_cache_squash_partial_results}

<SettingsInfoBlock type="Bool" default_value="1" />

Объединяет частичные блоки результатов в блоки размером [max&#95;block&#95;size](/ru/reference/settings/session-settings/max#max_block_size). Снижает производительность операций вставки в [кэш запросов](/ru/concepts/features/performance/caches/query-cache), но повышает степень сжатия записей кэша (см. [query&#95;cache&#95;compress-entries](/ru/reference/settings/session-settings/query-cache#query_cache_compress_entries)).

Возможные значения:

* 0 - Отключено
* 1 - Включено

## query_cache_system_table_handling {#query_cache_system_table_handling}

* Положительное целое число &gt;= 0.
