## cluster_for_parallel_replicas {#cluster_for_parallel_replicas}

Кластер сегмента, в котором находится текущий сервер

Значение по умолчанию в Cloud: `default`.

## cluster_function_process_archive_on_multiple_nodes {#cluster_function_process_archive_on_multiple_nodes}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "1"},{"label": "новая настройка"}]}]} />

Если установлено значение `true`, повышает производительность обработки архивов в кластерных функциях. Для совместимости, а также во избежание ошибок при обновлении до версии 25.7+ при использовании кластерных функций с архивами в более ранних версиях, следует установить значение `false`.

## cluster_function_wait_for_replica_ms {#cluster_function_wait_for_replica_ms}

<SettingsInfoBlock type="Milliseconds" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "Новая настройка"}]}]} />

Время, в течение которого initiator табличной функции `*Cluster` или параллельных реплик, работающих с объектным хранилищем, ожидает запроса задач от реплики, прежде чем передать назначенные ей файлы другим репликам. Значение `0` отключает ожидание.
