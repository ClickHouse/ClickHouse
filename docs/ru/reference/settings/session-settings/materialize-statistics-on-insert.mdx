Статистика строится и материализуется для вновь вставленных частей. Даже если отключено, статистика всё равно будет построена и сохранена во время слияний или с помощью явной команды MATERIALIZE STATISTICS. Затрагиваются только таблицы, текущий размер которых с учётом размера записываемого блока не превышает `materialize_statistics_on_insert_max_table_size`.
