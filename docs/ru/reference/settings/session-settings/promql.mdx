## promql_push_down_label_matchers {#promql_push_down_label_matchers}

<PrivatePreviewBadge />

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Новая настройка для копирования матчеров меток PromQL через бинарные операторы."}]}]} />

Копирует матчеры меток с одной стороны бинарного оператора PromQL в селекторы другой стороны — для тех меток, по которым оператор сопоставляет серии. Например, для `b / on(job) a{job="x"}` будут прочитаны только серии `b` с `job="x"`.
Матчер не копируется туда, где отфильтрованные им серии могли бы привести к тому, что Prometheus выдаст дублирующиеся серии: в сторону «one» оператора, если только она не является агрегацией по сопоставляемым меткам; в оператор между двумя векторами, кроме `and` и `unless`; а также через функцию над диапазоном или оператор со скаляром, если только на вход им не подаётся одна метрика, выбранная по имени.
Сравнение без `bool` сохраняет имя метрики, поэтому матчеры всегда проходят через него. Прочие функции и унарный минус блокируют передачу матчеров.
Скопированный матчер превращает селектор всей метрики в фильтрующий. Это может замедлить запросы к таблице [TimeSeries](/ru/reference/engines/table-engines/integrations/time-series) с `id`, кластеризованным по метрике (по умолчанию), если матчер оставляет большую часть серий метрики. Для таких запросов отключите эту настройку.
