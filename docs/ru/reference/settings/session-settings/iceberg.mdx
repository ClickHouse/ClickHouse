<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "4"},{"label": "Новая настройка, ограничивающая число файлов манифеста удалений Iceberg, декодируемых параллельно до чтения первой строки. До версии 26.8 манифесты декодировались по одному, при этом получение следующего уже выполнялось, поэтому `2` наиболее близко соответствует прежнему поведению, при котором суммарное время обмена с объектным хранилищем находилось на критическом пути до чтения первой строки."}]}]} />

Максимальное количество файлов манифеста удалений Iceberg, декодируемых параллельно во время выполнения запроса до чтения любого файла данных.

Все манифесты удалений должны быть декодированы до чтения любого файла данных, поэтому эта работа находится на критическом пути до возврата первой строки. Одновременное декодирование нескольких манифестов перекрывает как обмен с объектным хранилищем, так и отсечение данных на уровне строк.

Более высокие значения увеличивают пиковое потребление памяти при инициализации запроса, если кеш файлов метаданных Iceberg отключён или заполнен, поскольку каждый обрабатываемый манифест хранит собственное декодированное содержимое.

Значение должно быть больше нуля; `1` декодирует манифесты по одному.
