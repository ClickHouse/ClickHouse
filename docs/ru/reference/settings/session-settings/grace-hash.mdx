## grace_hash_join_initial_buckets {#grace_hash_join_initial_buckets}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "1"},{"label": "Настройка больше не является экспериментальной. Значение по умолчанию не изменилось."}]}]} />

Количество бакетов, с которого начинает работу алгоритм соединения `grace_hash`. Строки обеих таблиц распределяются по бакетам по хешу ключей соединения; в памяти хранится только один бакет, а остальные записываются на диск и соединяются позже. Когда бакет в памяти превышает ограничения памяти, количество бакетов удваивается, но не более чем до `grace_hash_join_max_buckets`.

Значение округляется вверх до степени двойки. Большее значение позволяет избежать перераспределения строк, если заранее известно, что правая таблица велика, но ценой большего количества временных файлов.
