Эти настройки доступны в [system.merge&#95;tree&#95;settings](/ru/reference/system-tables/merge_tree_settings) и автоматически создаются на основе исходного кода ClickHouse.

## fsync_after_insert {#fsync_after_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

Выполняет fsync для каждой вставленной части, чтобы к моменту подтверждения запроса `INSERT` данные были надёжно сохранены.
Снижает производительность вставки, особенно при использовании частей Wide.
См. также `group_fsync_before_insert_finish`.

## fsync_part_directory {#fsync_part_directory}

<SettingsInfoBlock type="Bool" default_value="0" />

Выполнять fsync для каталога части после всех операций с частью (записи, переименования и т. д.).
