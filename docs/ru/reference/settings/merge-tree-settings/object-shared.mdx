## object_shared_data_serialization_version {#object_shared_data_serialization_version}

<SettingsInfoBlock type="MergeTreeObjectSharedDataSerializationVersion" default_value="advanced" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.8"},{"label": "map"},{"label": "Добавлена настройка для управления версиями JSON-сериализации"}]}, {"id": "row-2","items": [{"label": "25.12"},{"label": "advanced"},{"label": "По умолчанию включена расширенная версия сериализации общих данных"}]}]} />

Версия сериализации общих данных в типе данных JSON.

Возможные значения:

* `map` - хранить общие данные как `Map(String, String)`
* `map_with_buckets` - хранить общие данные в виде нескольких отдельных столбцов `Map(String, String)`. Использование бакетов улучшает чтение отдельных путей из общих данных.
* `advanced` - специальная сериализация общих данных, разработанная для значительного улучшения чтения отдельных путей из общих данных.
  Обратите внимание, что эта сериализация увеличивает объем общих данных на диске, поскольку мы сохраняем много дополнительной информации.
* `advanced_chunked` - то же, что и `advanced`, но с поддержкой разбиения строк на меньшие фрагменты во время сериализации, чтобы снизить пиковое потребление памяти при слияниях JSON-столбцов с большим количеством уникальных путей. Размер фрагмента управляется настройкой [object&#95;shared&#95;data&#95;target&#95;chunk&#95;rows](/ru/reference/settings/merge-tree-settings/object-shared#object_shared_data_target_chunk_rows).

Количество бакетов для сериализаций `map_with_buckets`, `advanced` и `advanced_chunked` определяется настройками
[object&#95;shared&#95;data&#95;buckets&#95;for&#95;compact&#95;part](/ru/reference/settings/merge-tree-settings/object-shared#object_shared_data_buckets_for_compact_part)/[object&#95;shared&#95;data&#95;buckets&#95;for&#95;wide&#95;part](/ru/reference/settings/merge-tree-settings/object-shared#object_shared_data_buckets_for_wide_part).

Версия сериализации общих данных внутри типа JSON для небольших частей.
Часть данных считается небольшой, если она создана вставкой и включена настройка
[use&#95;object&#95;shared&#95;data&#95;serialization&#95;version&#95;for&#95;small&#95;parts&#95;on&#95;insert](/ru/reference/settings/merge-tree-settings/use#use_object_shared_data_serialization_version_for_small_parts_on_insert),
либо если размер её несжатых данных меньше значения
[min&#95;bytes&#95;for&#95;object&#95;shared&#95;data&#95;main&#95;serialization&#95;version](/ru/reference/settings/merge-tree-settings/min-bytes#min_bytes_for_object_shared_data_main_serialization_version).
Для остальных частей используется основная версия из [object&#95;shared&#95;data&#95;serialization&#95;version](/ru/reference/settings/merge-tree-settings/object-shared#object_shared_data_serialization_version).

Небольшие части вскоре снова подвергаются слиянию, поэтому для них не рекомендуется использовать сериализацию общих данных `advanced` или `advanced_chunked`:
она значительно замедляет вставки и слияния.

## object_shared_data_target_chunk_rows {#object_shared_data_target_chunk_rows}

<SettingsInfoBlock type="NonZeroUInt64" default_value="8192" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "8192"},{"label": "New setting"}]}]} />

Целевое количество строк во фрагменте при сериализации общих данных JSON в режиме `advanced_chunked`.
Это не жёсткое ограничение: если последний фрагмент окажется меньше половины целевого размера, он объединяется с предыдущим,
поэтому фактические размеры фрагментов находятся в диапазоне от `target/2` до `1.5 * target`.
Меньшие значения снижают пиковое потребление памяти при слияниях JSON-столбцов с большим числом уникальных путей — ценой увеличения количества фрагментов.
