Предпочтительная версия формата сериализации на диске для записи текстовых индексов.

Эта настройка задаёт предпочтение, а не строгое ограничение: если настроенная версия не может
представить индекс, автоматически выбирается более новая версия, способная это сделать, и
запись текстового индекса никогда не завершается сбоем из-за этой настройки.

Во время поэтапного обновления зафиксируйте формат с помощью настройки `compatibility` на уровне
профиля на уже обновлённых серверах, чтобы они продолжали записывать формат, который старые серверы всё ещё могут читать.

Возможные значения:

* `v0_initial` — Исходный формат. Не сохраняет тип кодека списка вхождений.
* `v1_with_codec` — Сохраняет тип кодека списка вхождений в заголовке текстового индекса.
* `v2_with_positions` — Сохраняет позиции токенов для индексов с `support_phrase_search`.
