## check_part_use_direct_io {#check_part_use_direct_io}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.12"},{"label": "1"},{"label": "Новая настройка. Проверка частей данных на локальных дисках с использованием direct I\/O в обход кэша страниц ОС."}]}]} />

При проверке части данных на локальном диске (`CHECK TABLE`, проверка части, которую не удалось прочитать,
пересчёт отсутствующих контрольных сумм) её файлы читаются с использованием direct I/O (параметр `O_DIRECT`)
в обход кэша страниц ОС, чтобы некорректные данные в страничном кэше не приводили к тому, что исправная часть выглядит повреждённой.
Части в хранилище Packed (см. `min_bytes_for_full_part_storage`) и часть, записанная командой `OPTIMIZE ... DRY RUN`,
по-прежнему читаются через страничный кэш.
Если файловая система не поддерживает direct I/O, файлы читаются через страничный кэш.

Отключите эту настройку, если прямое чтение выполняется медленнее, чем чтение через страничный кэш.
При прямом чтении всегда происходит обращение к устройству хранения, даже если данные уже закэшированы.
Например, на томе Amazon EBS проверка таблицы, которая помещается в страничный кэш, может выполняться в несколько раз медленнее.

## check_sample_column_is_correct {#check_sample_column_is_correct}

<SettingsInfoBlock type="Bool" default_value="1" />

Включает проверку при создании таблицы, что тип данных столбца для
сэмплирования или выражения для семплирования указан корректно. Тип данных должен быть одним из беззнаковых
[целочисленных типов](/ru/reference/data-types/int-uint): `UInt8`, `UInt16`,
`UInt32`, `UInt64`.

Возможные значения:

* `true`  — Проверка включена.
* `false` — Проверка отключена при создании таблицы.

Значение по умолчанию: `true`.

По умолчанию ClickHouse server проверяет при создании таблицы тип данных
столбца для сэмплирования или выражения для семплирования. Если у вас уже есть таблицы с
некорректным выражением для семплирования и вы не хотите, чтобы server сгенерировал исключение
во время запуска, установите `check_sample_column_is_correct` в `false`.
