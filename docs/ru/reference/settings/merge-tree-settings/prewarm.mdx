## prewarm_statistics_cache {#prewarm_statistics_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Новая настройка, позволяющая предварительно прогревать кэш статистики статистикой столбцов новых частей данных, а также при запуске. Кэш статистики теперь хранится отдельно для каждой части данных и каждого столбца, а не в виде снимка всей таблицы; настройки `refresh_statistics_interval` и `use_statistics_cache` устарели."}]}]} />

Если значение равно true, кэш статистики
предварительно прогревается: статистика столбцов частей данных загружается в него при вставках,
слияниях, загрузках с других реплик и при запуске сервера. Если настройка отключена, статистика части
загружается в кэш первым запросом, которому она нужна.
