Эти настройки относятся к серверу ClickHouse и автоматически сгенерированы на основе исходного кода ClickHouse.

## max_local_read_bandwidth_for_server {#max_local_read_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

Максимальная скорость локального чтения данных в байтах в секунду.

Ограничение распространяется на данные, читаемые с блочных устройств: операции чтения, обслуживаемые из кэша страниц ОС, не учитываются, если метод чтения позволяет их распознать (так происходит при используемом по умолчанию `local_filesystem_read_method = 'pread_threadpool'`, при `pread`, а также при чтении файлов файлового кэша).

<Note>
  Значение `0` означает отсутствие ограничений.
</Note>

## max_local_write_bandwidth_for_server {#max_local_write_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

Максимальная скорость локальной записи в байтах в секунду.

<Note>
  Значение `0` означает отсутствие ограничений.
</Note>
