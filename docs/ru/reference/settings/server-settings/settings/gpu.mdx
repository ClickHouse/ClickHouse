Эти настройки определяют конфигурацию сервера ClickHouse и автоматически генерируются из исходного кода ClickHouse.

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />Объём освобождённой памяти устройства, который стандартный пул памяти GPU удерживает у себя вместо того, чтобы возвращать его драйверу. При значении по умолчанию пул разрастается до пикового объёма, который требовался запросам, и остаётся таким до завершения работы сервера.

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />Максимальный объём освобождённой закреплённой (pinned) памяти хоста, который пул закреплённой памяти хоста GPU удерживает для повторного использования, не возвращая её системе.
