Эти настройки определяют конфигурацию сервера ClickHouse и автоматически сгенерированы из исходного кода ClickHouse.

## ai_function_max_thread_pool_free_size {#ai_function_max_thread_pool_free_size}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

Максимальное количество бездействующих резервных потоков, которые сохраняются в пуле потоков для запросов к поставщикам ИИ.

## ai_function_max_thread_pool_size {#ai_function_max_thread_pool_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1000" changeable_without_restart="Yes" />

Максимальное общее число потоков, используемых для запросов к поставщикам ИИ. Один поток обслуживает один запрос, поэтому эта настройка ограничивает число запросов к провайдерам ИИ, одновременно находящихся в обработке на всём сервере, с учётом всех SQL-запросов. [`ai_function_max_concurrent_requests_per_thread`](/ru/reference/settings/session-settings/ai-function#ai_function_max_concurrent_requests_per_thread) ограничивает долю этого лимита, приходящуюся на каждый поток запроса.

## ai_function_thread_pool_queue_size {#ai_function_thread_pool_queue_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />

Максимальное количество заданий, которые можно запланировать в пуле потоков для запросов к поставщикам ИИ.
