Эти настройки определяют конфигурацию сервера ClickHouse и автоматически сгенерированы на основе исходного кода ClickHouse.

## statistics_cache_policy {#statistics_cache_policy}

<SettingsInfoBlock type="String" default_value="SLRU" changeable_without_restart="No" />Название политики вытеснения для кэша статистики. Возможные значения: `LRU`, `SLRU`, `SIEVE`.

## statistics_cache_prewarm_ratio {#statistics_cache_prewarm_ratio}

<SettingsInfoBlock type="Double" default_value="0.95" changeable_without_restart="No" />Доля общего размера кэша статистики, заполняемая при предварительном прогреве.

## statistics_cache_size {#statistics_cache_size}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="Yes" />Максимальный размер кэша статистики столбцов для частей данных таблиц семейства MergeTree. Статистика кэшируется отдельно для каждой части данных и каждого столбца, загружается по требованию и объединяется на лету при выполнении каждого запроса.

## statistics_cache_size_ratio {#statistics_cache_size_ratio}

<SettingsInfoBlock type="Double" default_value="0.5" changeable_without_restart="No" />Размер защищённой очереди в кэше статистики (при использовании политики SLRU) относительно общего размера кэша.
