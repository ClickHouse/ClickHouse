Эти настройки используются для настройки сервера ClickHouse и автоматически генерируются на основе исходного кода ClickHouse.

## distributed_cache_apply_throttling_settings_from_client {#distributed_cache_apply_throttling_settings_from_client}

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />Следует ли кеш-серверу применять настройки throttling, полученные от клиента.

## distributed_cache_keep_up_free_connections_ratio {#distributed_cache_keep_up_free_connections_ratio}

<SettingsInfoBlock type="Float" default_value="0.1" changeable_without_restart="Нет" />Мягкий лимит на число активных соединений, которые distributed cache старается держать незанятыми. Когда число свободных соединений становится меньше distributed&#95;cache&#95;keep&#95;up&#95;free&#95;connections&#95;ratio * max&#95;connections, закрываются соединения с самой давней активностью, пока это число снова не превысит лимит.

## distributed_cache_warmer_max_bytes_in_queue {#distributed_cache_warmer_max_bytes_in_queue}

<SettingsInfoBlock type="UInt64" default_value="107374182400" changeable_without_restart="No" />Действует только в ClickHouse Cloud. Максимальный суммарный размер диапазонов, которые механизм прогрева кэша держит в очереди для диска без локального файлового кэша; при превышении этого предела самые старые диапазоны отбрасываются (при наличии локального кэша механизм прогрева кэша использует его `max_size`). Ноль означает отсутствие ограничений.

## distributed_cache_warmer_max_file_segment_size {#distributed_cache_warmer_max_file_segment_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="33554432" changeable_without_restart="No" />Действует только в ClickHouse Cloud. Размер диапазонов, которыми механизм прогрева кэша считывает полученную через fetch часть в distributed cache, если у диска этой части нет локального файлового кэша (при наличии локального кэша механизм прогрева использует собственный параметр `max_file_segment_size`).

## distributed_cache_warmer_max_segments_in_queue {#distributed_cache_warmer_max_segments_in_queue}

<SettingsInfoBlock type="UInt64" default_value="100000" changeable_without_restart="No" />Действует только в ClickHouse Cloud. Максимальное количество диапазонов, которые механизм прогрева кэша держит в очереди для диска без локального файлового кэша; при превышении этого значения самые старые диапазоны отбрасываются (при наличии локального кэша используется его параметр `max_elements`). Ноль означает отсутствие ограничения.

## distributed_cache_write_pool_size {#distributed_cache_write_pool_size}

<SettingsInfoBlock type="UInt64" default_value="100" changeable_without_restart="No" />Максимальное количество запросов на запись в distributed cache, которые могут одновременно выполняться в фоновых потоках (для всех запросов). Когда этот предел достигнут, запись в write-through cache пропускается (данные всё равно записываются в объектное хранилище), поэтому она не блокируется в ожидании слота и не создаёт неограниченное число потоков. Запись временных данных не использует фоновые потоки, и этот предел на неё не влияет.
