Эти настройки задают конфигурацию сервера ClickHouse и автоматически генерируются из исходного кода ClickHouse.

## totp_track_used_codes_in_keeper {#totp_track_used_codes_in_keeper}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

Обеспечивает однократное использование кодов одноразовых паролей на основе времени (TOTP) в пределах всех серверов, использующих общий ZooKeeper или ClickHouse Keeper, а не каждого сервера по отдельности.

Принятые коды записываются в Keeper по пути, заданному настройкой `totp_used_codes_keeper_path`: для каждого пользователя создаётся отдельный узел, имя которого — хеш SHA-256 от имени пользователя. Код, принятый одним сервером, отклоняется всеми остальными, а запись сохраняется после перезапуска серверов. Если эта настройка включена, Keeper должен быть настроен; пока Keeper недоступен, аутентификация с одноразовым паролем завершается ошибкой.

**Пример**

```xml
<totp_track_used_codes_in_keeper>1</totp_track_used_codes_in_keeper>
```

## totp_used_codes_keeper_path {#totp_used_codes_keeper_path}

<SettingsInfoBlock type="String" default_value="/clickhouse/access/one_time_passwords" changeable_without_restart="No" />

Путь в Keeper, по которому сохраняются принятые коды одноразовых паролей на основе времени (TOTP), если включена настройка `totp_track_used_codes_in_keeper`. Кластеры, использующие общий Keeper без chroot, должны указывать разные пути, иначе у пользователей с одинаковым именем в разных кластерах записи окажутся общими.

**Пример**

```xml
<totp_used_codes_keeper_path>/clickhouse/access/one_time_passwords</totp_used_codes_keeper_path>
```
