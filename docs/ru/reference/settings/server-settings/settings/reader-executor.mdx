Эти настройки конфигурируют ClickHouse server и генерируются автоматически из исходного кода ClickHouse.

## reader_executor_memory_pressure_critical_level_pct {#reader_executor_memory_pressure_critical_level_pct}

<SettingsInfoBlock type="UInt64" default_value="95" changeable_without_restart="Yes" />Порог давления на память, при котором экспериментальный `ReaderExecutor` переходит на уровень давления на память `Critical` — с самым агрессивным сокращением окна чтения. Правила, касающиеся областей действия, диапазона значений и порядка, описаны в `reader_executor_memory_pressure_elevated_level_pct`.

## reader_executor_memory_pressure_elevated_level_pct {#reader_executor_memory_pressure_elevated_level_pct}

<SettingsInfoBlock type="UInt64" default_value="75" changeable_without_restart="Yes" />Порог давления на память, выраженный в процентах от жёсткого лимита трекера памяти, при достижении которого экспериментальный `ReaderExecutor` переходит на уровень давления на память `Elevated` и начинает сокращать своё окно чтения. Пороги применяются независимо к трём областям действия — суммарной по серверу (`max_server_memory_usage`), по пользователю (`max_memory_usage_for_user`) и по запросу (`max_memory_usage`), — а reader берёт наибольшее из трёх значений, поэтому один запрос, приблизившийся к собственному лимиту, сократит своё окно даже при бездействующем сервере. Область действия без жёсткого лимита в расчёт не входит. Значение должно находиться в диапазоне `[1, 100]` и удовлетворять условию `elevated <= high <= critical`; тройка значений вне диапазона или с нарушенным порядком отклоняется при запуске и при выполнении `SYSTEM RELOAD CONFIG`. Ноль отклоняется, поскольку значение `elevated`, равное 0, переводило бы на уровень `Elevated` любую область, в том числе и ту, у которой жёсткого лимита нет.

## reader_executor_memory_pressure_high_level_pct {#reader_executor_memory_pressure_high_level_pct}

<SettingsInfoBlock type="UInt64" default_value="90" changeable_without_restart="Yes" />Порог давления на память, при котором экспериментальный `ReaderExecutor` переходит на уровень давления на память `High`. Правила, касающиеся области действия, диапазона значений и порядка, см. в `reader_executor_memory_pressure_elevated_level_pct`.
