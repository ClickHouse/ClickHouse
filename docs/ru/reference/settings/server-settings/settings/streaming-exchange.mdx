Эти настройки определяют конфигурацию сервера ClickHouse и автоматически сгенерированы на основе исходного кода ClickHouse.

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Размер параметра SO&#95;RCVBUF для сокетов потокового обмена в многостадийных распределённых запросах. 0 — значение по умолчанию, заданное ядром (автоматическая настройка TCP). Значение больше 0 ограничивает размер приёмного буфера каждого сокета (сверху он ограничен значением net.core.rmem&#95;max). Настройка считывается при установке каждого соединения, поэтому после перезагрузки конфигурации новое значение применяется только к новым соединениям.

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Размер параметра SO&#95;SNDBUF для сокетов потокового обмена в многостадийных распределённых запросах. 0 — значение ядра по умолчанию (автоматическая настройка TCP). Значение больше 0 ограничивает буфер отправки каждого сокета (сверху он ограничен значением net.core.wmem&#95;max), но при этом на каналах с высоким RTT пропускная способность потока ограничивается величиной sndbuf/RTT. Значение считывается для каждого соединения отдельно, поэтому после перезагрузки конфигурации оно применяется только к новым соединениям.
