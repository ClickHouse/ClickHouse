Вычисляет запрос Prometheus, используя данные из таблицы TimeSeries в заданном диапазоне моментов вычисления.

## Синтаксис {#syntax}

```sql
prometheusQueryRange('db_name', 'time_series_table', 'promql_query', start_time, end_time, step)
prometheusQueryRange(db_name.time_series_table, 'promql_query', start_time, end_time, step)
prometheusQueryRange('time_series_table', 'promql_query', start_time, end_time, step)
```

## Аргументы {#arguments}

* `db_name` - Имя базы данных, в которой находится таблица TimeSeries.
* `time_series_table` - Имя таблицы TimeSeries.
* `promql_query` - Запрос, записанный в [синтаксисе PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/).
* `start_time` - Время начала интервала вычисления с точностью не ниже миллисекунды.
* `end_time` - Время окончания интервала вычисления с точностью не ниже миллисекунды.
* `step` - Шаг, с которым перебирается время вычисления от `start_time` до `end_time` (включительно).

## Возвращаемое значение {#returned-value}

Функция возвращает разные столбцы в зависимости от типа результата запроса, переданного в параметре `promql_query`:

| Тип результата | Столбцы результата                                                                  | Пример                                              |
| -------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| vector         | tags Array(Tuple(String, String)), timestamp DateTime64(S, TZ), value Float64       | prometheusQuery(mytable, &#39;up&#39;)              |
| matrix         | tags Array(Tuple(String, String)), samples Array(Tuple(DateTime64(S, TZ), Float64)) | prometheusQuery(mytable, &#39;up[1m]&#39;)          |
| scalar         | timestamp DateTime64(S, TZ), value Float64                                          | prometheusQuery(mytable, &#39;1h30m&#39;)           |
| string         | timestamp DateTime64(S, TZ), value String                                           | prometheusQuery(mytable, &#39;&quot;abc&quot;&#39;) |

Значения всегда имеют тип `Float64` независимо от типа значений в таблице TimeSeries. Масштаб `S` временных меток совпадает с масштабом
временных меток в таблице, но не меньше 3 (миллисекунды). Часовой пояс `TZ` совпадает с часовым поясом `start_time` и `end_time`,
если они имеют тип `DateTime` или `DateTime64` с одним и тем же часовым поясом; в противном случае используется часовой пояс временных меток в таблице.

Столбец `samples` называется `time_series`, если таблица `TimeSeries` имеет [версию](/ru/reference/engines/table-engines/integrations/time-series#schema-versioning) 2 или ниже.

## Поддерживаемые возможности PromQL {#supported-promql-features}

### Селекторы {#selectors}

Мгновенные селекторы, селекторы диапазона, сопоставители меток (`=`, `!=`, `=~`, `!~`), модификаторы offset, модификаторы временной метки `@` и подзапросы.

### Функции {#functions}

| Категория          | Функции                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Диапазон           | `rate`, `irate`, `delta`, `idelta`, `increase`, `last_over_time`, `first_over_time`, `sum_over_time`, `avg_over_time`, `count_over_time`, `max_over_time`, `min_over_time`, `ts_of_max_over_time`, `ts_of_min_over_time`, `ts_of_last_over_time`, `ts_of_first_over_time`, `deriv`, `changes`, `resets`, `present_over_time`, `absent_over_time`, `quantile_over_time`, `stddev_over_time`, `stdvar_over_time`, `mad_over_time`, `predict_linear` |
| Математические     | `abs`, `sgn`, `floor`, `ceil`, `sqrt`, `exp`, `ln`, `log2`, `log10`, `rad`, `deg`, `round`, `clamp`, `clamp_min`, `clamp_max`, `min_of`, `max_of`                                                                                                                                                                                                                                                                                                 |
| Тригонометрические | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh`                                                                                                                                                                                                                                                                                                                                                    |
| Дата и время       | `day_of_week`, `day_of_month`, `days_in_month`, `day_of_year`, `minute`, `hour`, `month`, `year`                                                                                                                                                                                                                                                                                                                                                  |
| Метка              | `label_replace`, `label_join`                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Тип                | `scalar`, `vector`                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Гистограмма        | `histogram_quantile`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Другое             | `time`, `pi`, `absent`                                                                                                                                                                                                                                                                                                                                                                                                                            |

**Note**: `histogram_quantile` использует линейную интерполяцию для классических бакетов гистограммы (определяемых по метке `le`). Нативные гистограммы не поддерживаются. Аргумент `phi` (уровень квантиля) должен быть константным скаляром. Выражения, меняющиеся от шага к шагу, такие как `histogram_quantile(time() / 1000, ...)`, отклоняются с исключением `NOT_IMPLEMENTED`.

**Note**: `min_of(a, b)` и `max_of(a, b)` возвращают меньшее и большее из двух скалярных значений соответственно. Оба аргумента должны быть скалярами.

**Note**: `min_of`, `max_of`, `ts_of_min_over_time`, `ts_of_max_over_time`, `ts_of_last_over_time`, `first_over_time`, `ts_of_first_over_time` и `mad_over_time` — экспериментальные функции в Prometheus (там они включаются с помощью `--enable-feature=promql-experimental-functions`); ClickHouse вычисляет их без этого флага.

### Операторы {#operators}

Бинарные арифметические (`+`, `-`, `*`, `/`, `%`, `^`, `atan2`) и сравнительные (`==`, `!=`, `<`, `>`, `<=`, `>=` с необязательным `bool`) операторы с модификаторами `on()`/`ignoring()` и `group_left()`/`group_right()`.

Логические операторы множеств `and`, `or` и `unless` с модификаторами `on()`/`ignoring()`.

Унарные операторы `+` и `-`.

### Операторы агрегации {#aggregation-operators}

`sum`, `avg`, `min`, `max`, `count`, `count_values`, `stddev`, `stdvar`, `group`, `quantile`, `topk`, `bottomk`, `limitk` — с необязательными модификаторами `by()` и `without()`.

## Пример {#example}

```sql
SELECT * FROM prometheusQueryRange(mytable, 'rate(http_requests{job="prometheus"}[10m])[1h:10m]', now() - INTERVAL 10 MINUTES, now(), INTERVAL 1 MINUTE)
```
