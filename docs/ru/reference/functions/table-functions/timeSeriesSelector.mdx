Читает временные ряды из таблицы TimeSeries, отфильтрованные селектором, с временными метками в заданном интервале.
Эта функция похожа на [диапазонные селекторы](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors), но также используется для реализации [мгновенных селекторов](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors).

## Синтаксис {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## Аргументы {#arguments}

* `db_name` - Имя базы данных, в которой находится таблица TimeSeries.
* `time_series_table` - Имя таблицы TimeSeries.
* `instant_query` - Мгновенный селектор, записанный с использованием [синтаксиса PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors), без модификаторов `@` или `offset`.
* `min_time` - Начальная временная метка, включительно.
* `max_time` - Конечная временная метка, включительно.
* `return_columns` - Столбцы, в которых возвращаются отсчёты: `'samples'` или `'timestamp_and_value'` (см. ниже).

`min_time` и `max_time` могут задаваться с долями секунды, даже если временные метки в таблице имеют точность до целой секунды:
функция выбирает отсчёты, строго соответствующие условию `min_time <= timestamp <= max_time`, не округляя границы в соответствии с типом временных меток.

## Возвращаемое значение {#returned-value}

Функция возвращает столбец `id` с идентификаторами временных рядов, соответствующих указанному селектору, а также отсчёты
в столбцах, заданных аргументом `return_columns`:

* `'samples'` — столбец `samples` с отсчётами временного ряда в виде массива Tuple `(timestamp, value)`, отсортированного по временной метке.
  Отсчёты одного временного ряда могут возвращаться в нескольких строках, например по одной строке на каждый временной интервал таблицы samples.
  Чтобы объединить строки одного временного ряда, используйте агрегатную функцию `timeSeriesGroupArray`.
* `'timestamp_and_value'` — столбцы `timestamp` и `value` с одним отсчётом в каждой строке.

Таблица `TimeSeries` версии 11 и выше хранит корзины отсчётов в виде массивов, а таблицы более ранних версий хранят по одному отсчёту в строке.
Если запрошенные столбцы не соответствуют структуре таблицы, отсчёты преобразуются, что занимает дополнительное время; функции PromQL
запрашивают столбцы, соответствующие структуре таблицы.

Порядок возвращаемых данных не определён.

## Примеры {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
