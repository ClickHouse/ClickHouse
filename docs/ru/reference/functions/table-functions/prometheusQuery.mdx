Выполняет Prometheus-запрос по данным из таблицы TimeSeries.

## Синтаксис {#syntax}

```sql
prometheusQuery('db_name', 'time_series_table', 'promql_query', evaluation_time)
prometheusQuery(db_name.time_series_table, 'promql_query', evaluation_time)
prometheusQuery('time_series_table', 'promql_query', evaluation_time)
```

## Аргументы {#arguments}

* `db_name` - Имя базы данных, в которой находится таблица TimeSeries.
* `time_series_table` - Имя таблицы TimeSeries.
* `promql_query` - Запрос, написанный в [синтаксисе PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/).
* `evaluation_time` - Временная метка вычисления с точностью до миллисекунды или выше. Чтобы вычислить запрос на текущий момент, используйте `now()` в качестве `evaluation_time`.

## Возвращаемое значение {#returned-value}

Функция возвращает разные столбцы в зависимости от типа результата запроса, переданного через параметр `promql_query`:

| Тип результата | Столбцы результата                                                                  | Пример                                              |
| -------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| vector         | tags Array(Tuple(String, String)), timestamp DateTime64(S, TZ), value Float64       | prometheusQuery(mytable, &#39;up&#39;)              |
| matrix         | tags Array(Tuple(String, String)), samples Array(Tuple(DateTime64(S, TZ), Float64)) | prometheusQuery(mytable, &#39;up[1m]&#39;)          |
| scalar         | timestamp DateTime64(S, TZ), value Float64                                          | prometheusQuery(mytable, &#39;1h30m&#39;)           |
| string         | timestamp DateTime64(S, TZ), value String                                           | prometheusQuery(mytable, &#39;&quot;abc&quot;&#39;) |

Значения всегда имеют тип `Float64` независимо от типа значений в таблице TimeSeries. Масштаб `S` временных меток совпадает с масштабом
временных меток в таблице, но не может быть меньше 3 (точность до миллисекунд). Если `evaluation_time` имеет
тип `DateTime` или `DateTime64` с часовым поясом, используется его часовой пояс `TZ`; в противном случае — часовой пояс временных меток в таблице.

Столбец `samples` называется `time_series`, если таблица `TimeSeries` имеет [version](/ru/reference/engines/table-engines/integrations/time-series#schema-versioning) 2 или более раннюю.

## Поддерживаемые возможности PromQL {#supported-promql-features}

### Селекторы {#selectors}

Мгновенные селекторы, селекторы диапазона, сопоставители меток (`=`, `!=`, `=~`, `!~`), модификаторы `offset`, модификаторы временной метки `@` и подзапросы.

### Функции {#functions}

| Категория     | Функции                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Диапазон      | `rate`, `irate`, `delta`, `idelta`, `increase`, `last_over_time`, `first_over_time`, `sum_over_time`, `avg_over_time`, `count_over_time`, `max_over_time`, `min_over_time`, `ts_of_max_over_time`, `ts_of_min_over_time`, `ts_of_last_over_time`, `ts_of_first_over_time`, `deriv`, `changes`, `resets`, `present_over_time`, `absent_over_time`, `quantile_over_time`, `stddev_over_time`, `stdvar_over_time`, `mad_over_time`, `predict_linear` |
| Математика    | `abs`, `sgn`, `floor`, `ceil`, `sqrt`, `exp`, `ln`, `log2`, `log10`, `rad`, `deg`, `round`, `clamp`, `clamp_min`, `clamp_max`, `min_of`, `max_of`                                                                                                                                                                                                                                                                                                 |
| Тригонометрия | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh`                                                                                                                                                                                                                                                                                                                                                    |
| Дата и время  | `day_of_week`, `day_of_month`, `days_in_month`, `day_of_year`, `minute`, `hour`, `month`, `year`                                                                                                                                                                                                                                                                                                                                                  |
| Метка         | `label_replace`, `label_join`                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Тип           | `scalar`, `vector`                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Гистограмма   | `histogram_quantile`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Сортировка    | `sort`, `sort_desc`, `sort_by_label`, `sort_by_label_desc`                                                                                                                                                                                                                                                                                                                                                                                        |
| Другое        | `time`, `step`, `range`, `pi`, `absent`, `timestamp`                                                                                                                                                                                                                                                                                                                                                                                              |

**Note**: `histogram_quantile` использует линейную интерполяцию для классических бакетов гистограммы (обозначаемых меткой `le`). Нативные гистограммы не поддерживаются. Аргумент `phi` (уровень квантиля) должен быть константным скаляром. Выражения, которые меняются на каждом шаге, например `histogram_quantile(time() / 1000, ...)`, отклоняются с исключением `NOT_IMPLEMENTED`.

**Note**: `min_of(a, b)` и `max_of(a, b)` возвращают меньшее или большее из двух скалярных значений. Оба аргумента должны быть скалярами.

**Note**: Функции сортировки упорядочивают результат, только если они являются самой внешней функцией запроса. В любом другом месте функция сортировки ни на что не влияет, тогда как Prometheus сохраняет порядок, заданный вложенной функцией сортировки, как в `abs(sort_desc(x))`.

* `sort` и `sort_desc` упорядочивают результат по значению выборки, при этом `NaN` идут последними. Серии с равными значениями упорядочиваются по своим меткам.
* `sort_by_label` и `sort_by_label_desc` упорядочивают результат по значениям указанных меток, которые сравниваются в естественном порядке (`host2` перед `host10`). Серия без указанной метки упорядочивается так, как если бы значение метки было пустым. Серии с равными значениями этих меток упорядочиваются по всем своим меткам.

Этот порядок отличается от порядка в Prometheus в трёх случаях: числа, различающиеся только ведущими нулями (`7` и `007`), считаются равными; числа любой длины сравниваются как числа (Prometheus сравнивает число, выходящее за диапазон `Int64`, как текст); серия без указанной метки всегда располагается перед сериями, у которых она есть (в Prometheus её позиция зависит от порядка входных данных).

**Note**: `step`, `range`, `min_of`, `max_of`, `ts_of_min_over_time`, `ts_of_max_over_time`, `ts_of_last_over_time`, `ts_of_first_over_time`, `mad_over_time`, `sort_by_label` и `sort_by_label_desc` — экспериментальные функции в Prometheus (там они включаются с помощью `--enable-feature=promql-experimental-functions`); ClickHouse вычисляет их без необходимости указывать этот флаг.

### Операторы {#operators}

Все арифметические (`+`, `-`, `*`, `/`, `%`, `^`, `atan2`) и сравнительные (`==`, `!=`, `<`, `>`, `<=`, `>=` с необязательным модификатором `bool`) бинарные операторы, а также модификаторы `on()`/`ignoring()` и `group_left()`/`group_right()`.

Логические операторы множеств `and`, `or` и `unless` с модификаторами `on()`/`ignoring()`.

Унарные операторы `+` и `-`.

### Операторы агрегации {#aggregation-operators}

`sum`, `avg`, `min`, `max`, `count`, `count_values`, `stddev`, `stdvar`, `group`, `quantile`, `topk`, `bottomk`, `limitk` — с необязательными модификаторами `by()` и `without()`.

## Пример {#example}

```sql
SELECT * FROM prometheusQuery(mytable, 'rate(http_requests{job="prometheus"}[10m])[1h:10m]', now())
```
