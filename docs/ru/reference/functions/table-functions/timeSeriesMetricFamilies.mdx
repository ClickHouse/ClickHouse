`timeSeriesMetricFamilies(db_name.time_series_table)` — возвращает таблицу [семейств метрик](/ru/reference/engines/table-engines/integrations/time-series#metric-families-table), используемую таблицей `db_name.time_series_table` с движком [TimeSeries](/ru/reference/engines/table-engines/integrations/time-series), например:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

Следующие запросы эквивалентны:

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  Функция `timeSeriesMetricFamilies` имеет псевдоним `timeSeriesMetrics`, который сохранён для обратной совместимости.
</Note>
