`timeSeriesTimeRanges(db_name.time_series_table)` — возвращает таблицу [временных диапазонов](/ru/reference/engines/table-engines/integrations/time-series#time-ranges-table),
используемую таблицей `db_name.time_series_table` с движком таблицы [TimeSeries](/ru/reference/engines/table-engines/integrations/time-series), например:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

Следующие запросы эквивалентны:

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  Таблица *временных диапазонов* создаётся, если включена настройка `store_time_ranges`.
  В таблицах [версии](/ru/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 и более ранних столбцы `min_time` и `max_time`
  хранятся в таблице [меток](/ru/reference/engines/table-engines/integrations/time-series#tags-table).
</Note>
