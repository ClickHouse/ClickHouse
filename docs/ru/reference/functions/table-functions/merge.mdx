Создаёт временную таблицу [Merge](/ru/reference/engines/table-engines/special/merge).
Схема таблицы выводится из базовых таблиц путём объединения их столбцов и определения общих типов.
Доступны те же виртуальные столбцы, что и у движка таблицы [Merge](/ru/reference/engines/table-engines/special/merge).

## Синтаксис {#syntax}

```sql
merge(['db_name',] 'tables_regexp')
```

## Аргументы {#arguments}

| Аргумент        | Описание                                                                                                                                                                                                                                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | Возможные значения (необязательно, по умолчанию — `currentDatabase()`):<br />    - имя базы данных,<br />    - константное выражение, возвращающее строку с именем базы данных, например `currentDatabase()`,<br />    - `REGEXP(expression)`, где `expression` — регулярное выражение для сопоставления с именами БД. |
| `tables_regexp` | Регулярное выражение для сопоставления с именами таблиц в указанной БД или БД.                                                                                                                                                                                                                                         |

## Права доступа {#access-rights}

Таблицы, подходящие под шаблон, читаются по тем же правилам доступа, что и в движке таблицы [Merge](/ru/reference/engines/table-engines/special/merge#access-rights). Данные читаются только из тех подходящих таблиц, которые видны текущему пользователю, то есть на которые у него есть привилегия [`SHOW TABLES`](/ru/reference/statements/grant#show), и схема таблицы определяется только по ним. Подходящая таблица, которую пользователь не видит, пропускается без ошибки. Для определения схемы требуется привилегия [`SHOW COLUMNS`](/ru/reference/statements/grant#show) на таблицы, по которым она определяется. Для чтения подходящей таблицы, которую пользователь видит, требуется привилегия [`SELECT`](/ru/reference/statements/grant#select) на столбцы, читаемые запросом, иначе запрос завершается с ошибкой `ACCESS_DENIED`.
