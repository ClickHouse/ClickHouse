## IPv4CIDRToRange {#IPv4CIDRToRange}

Добавленный в: v20.1.0

Принимает IPv4-адрес и длину его префикса Classless Inter-Domain Routing (CIDR), а возвращает диапазон адресов подсети в виде кортежа из двух значений IPv4: первого и последнего адресов этой подсети.
Версию для IPv6 см. в [`IPv6CIDRToRange`](#IPv4CIDRToRange).

**Синтаксис**

```sql
IPv4CIDRToRange(ipv4, cidr)
```

**Аргументы**

* `ipv4` — адрес IPv4. [`IPv4`](/ru/reference/data-types/ipv4) или [`String`](/ru/reference/data-types/string)
* `cidr` — значение CIDR. [`UInt8`](/ru/reference/data-types/int-uint)

**Возвращаемое значение**

Возвращает кортеж из двух адресов IPv4, представляющих диапазон подсети. [`Tuple(IPv4, IPv4)`](/ru/reference/data-types/tuple)

**Примеры**

**Пример использования**

```sql title=Query
SELECT IPv4CIDRToRange(toIPv4('192.168.5.2'), 16);
```

```response title=Response
┌─IPv4CIDRToRange(toIPv4('192.168.5.2'), 16)─┐
│ ('192.168.0.0','192.168.255.255')          │
└────────────────────────────────────────────┘
```

## IPv4NumToString {#IPv4NumToString}

Добавленный в: v1.1.0

Преобразует 32-битное целое число в строковое представление IPv4-адреса в точечно-десятичной записи (формат A.B.C.D).
Интерпретирует входное значение в порядке байтов big-endian.

**Синтаксис**

```sql
IPv4NumToString(num)
```

**Псевдонимы**: `INET_NTOA`

**Аргументы**

* `num` — IPv4-адрес в виде числа UInt32. [`UInt32`](/ru/reference/data-types/int-uint)

**Возвращаемое значение**

Возвращает число, представляющее MAC-адрес, или `0`, если формат некорректен. [`String`](/ru/reference/data-types/string)

**Примеры**

**Пример использования**

```sql title=Query
SELECT IPv4NumToString(3232235521)
```

```response title=Response
192.168.0.1
```

```sql

```

**Аргументы**

* `num` — IPv4-адрес в формате числа UInt32. [`UInt32`](/ru/reference/data-types/int-uint)

**Возвращаемое значение**

Возвращает строковое представление IPv4-адреса, в котором последний октет заменён на xxx. [`String`](/ru/reference/data-types/string)

**Примеры**

**Базовый пример с агрегацией**

```sql title=Query
SELECT
    IPv4NumToStringClassC(ClientIP) AS k,
    count() AS c
FROM VALUES('ClientIP UInt32',
    (toUInt32(toIPv4('83.149.9.10'))), (toUInt32(toIPv4('83.149.9.11'))), (toUInt32(toIPv4('83.149.9.12'))),
    (toUInt32(toIPv4('217.118.81.5'))), (toUInt32(toIPv4('217.118.81.6'))),
    (toUInt32(toIPv4('213.87.129.1'))))
GROUP BY k
ORDER BY c DESC, k
```

```response title=Response
┌─k──────────────┬─c─┐
│ 83.149.9.xxx   │ 3 │
│ 217.118.81.xxx │ 2 │
│ 213.87.129.xxx │ 1 │
└────────────────┴───┘
```

## IPv6NumToString {#IPv6NumToString}

Добавленный в: v1.1.0

Преобразует IPv6-адрес из двоичного формата (FixedString(16)) в стандартное текстовое представление.
IPv4-отображённые IPv6-адреса выводятся в формате `::ffff:111.222.33.44`.

**Синтаксис**

```sql
IPv6NumToString(x)
```

**Псевдонимы**: `INET6_NTOA`

**Аргументы**

* `x` — IPv6-адрес в двоичном формате. [`FixedString(16)`](/ru/reference/data-types/fixedstring) или [`IPv6`](/ru/reference/data-types/ipv6)

**Возвращаемое значение**

Возвращает IPv6-адрес в виде строки в текстовом формате. [`String`](/ru/reference/data-types/string)

**Примеры**

**Пример использования**

```sql title=Query
SELECT IPv6NumToString(toFixedString(unhex('2A0206B8000000000000000000000011'), 16)) AS addr;
```

```response title=Response
┌─addr─────────┐
│ 2a02:6b8::11 │
└──────────────┘
```

**IPv6 в анализе hits**

```sql title=Query
CREATE TABLE hits_all (EventDate Date, ClientIP6 FixedString(16)) ENGINE = Memory;

INSERT INTO hits_all SELECT today(), IPv6StringToNum(addr) FROM VALUES('addr String',
    ('2a02:2168:aaa:bbbb::2'), ('2a02:2168:aaa:bbbb::2'), ('2a02:2168:aaa:bbbb::2'),
    ('2a02:6b8:0:fff::ff'), ('2a02:6b8:0:fff::ff'),
    ('::ffff:94.26.111.111'), ('::ffff:94.26.111.111'), ('::ffff:94.26.111.111'), ('::ffff:94.26.111.111'),
    ('::ffff:37.143.222.4'));

-- The addresses that are not an IPv4 address mapped into the IPv6 space.
SELECT
    IPv6NumToString(ClientIP6 AS k),
    count() AS c
FROM hits_all
WHERE EventDate = today() AND substring(ClientIP6, 1, 12) != unhex('00000000000000000000FFFF')
GROUP BY k
ORDER BY c DESC, k
LIMIT 10
```

```response title=Response
┌─IPv6NumToString(k)────┬─c─┐
│ 2a02:2168:aaa:bbbb::2 │ 3 │
│ 2a02:6b8:0:fff::ff    │ 2 │
└───────────────────────┴───┘
```

**IPv4-адреса, сопоставленные с IPv6**

```sql title=Query
-- Without the filter, the mapped IPv4 addresses show up as well.
SELECT
    IPv6NumToString(ClientIP6 AS k),
    count() AS c
FROM hits_all
WHERE EventDate = today()
GROUP BY k
ORDER BY c DESC, k
LIMIT 10
```

```response title=Response
┌─IPv6NumToString(k)────┬─c─┐
│ ::ffff:94.26.111.111  │ 4 │
│ 2a02:2168:aaa:bbbb::2 │ 3 │
│ 2a02:6b8:0:fff::ff    │ 2 │
│ ::ffff:37.143.222.4   │ 1 │
└───────────────────────┴───┘
```

## IPv6StringToNum {#IPv6StringToNum}

Добавленный в: v1.1.0

Преобразует IPv6-адрес из стандартного текстового представления в двоичный формат (`FixedString(16)`).
Принимает IPv4-отображённые IPv6-адреса в формате `::ffff:111.222.33.44.`.
Если IPv6-адрес имеет недопустимый формат, генерируется исключение.

Если входная строка содержит корректный IPv4-адрес, возвращается его IPv6-эквивалент.
HEX может быть записан в верхнем или нижнем регистре.

**Синтаксис**

```sql
IPv6StringToNum(string)
```

**Псевдонимы**: `INET6_ATON`

**Аргументы**

* `string` — строка с IPv6-адресом. [`String`](/ru/reference/data-types/string)

**Возвращаемое значение**

Возвращает IPv6-адрес в двоичном формате. [`FixedString(16)`](/ru/reference/data-types/fixedstring)

**Примеры**

**Базовый пример**

```sql title=Query
SELECT addr, cutIPv6(IPv6StringToNum(addr), 0, 0) FROM (SELECT ['127.0.0.1', '1111::ffff'] AS addr) ARRAY JOIN addr;
```

```response title=Response
┌─addr───────┬─cutIPv6(IPv6StringToNum(addr), 0, 0)─┐
│ 127.0.0.1  │ ::ffff:127.0.0.1                     │
│ 1111::ffff │ 1111::ffff                           │
└────────────┴──────────────────────────────────────┘
```

## cutIPv6 {#cutIPv6}

Добавленный в: v1.1.0

Принимает значение `FixedString(16)`, содержащее IPv6-адрес в бинарном формате.
Возвращает строку с адресом в текстовом формате, у которого удалено указанное количество байтов.

**Синтаксис**

```sql
cutIPv6(x, bytesToCutForIPv6, bytesToCutForIPv4)
```

**Аргументы**

* `x` — IPv6-адрес в бинарном формате. [`FixedString(16)`](/ru/reference/data-types/fixedstring) или [`IPv6`](/ru/reference/data-types/ipv6)
* `bytesToCutForIPv6` — количество байтов, удаляемых из IPv6. [`UInt8`](/ru/reference/data-types/int-uint)
* `bytesToCutForIPv4` — количество байтов, удаляемых из IPv4. [`UInt8`](/ru/reference/data-types/int-uint)

**Возвращаемое значение**

Возвращает строку с адресом IPv6 в текстовом формате, из которого удалены указанные байты. [`String`](/ru/reference/data-types/string)

**Примеры**

**Пример использования**

```sql title=Query
WITH
    IPv6StringToNum('2001:0DB8:AC10:FE01:FEED:BABE:CAFE:F00D') AS ipv6,
    IPv4ToIPv6(IPv4StringToNum('192.168.0.1')) AS ipv4
SELECT
    cutIPv6(ipv6, 2, 0),
    cutIPv6(ipv4, 0, 2)
```

```response title=Response
┌─cutIPv6(ipv6, 2, 0)─────────────────┬─cutIPv6(ipv4, 0, 2)─┐
│ 2001:db8:ac10:fe01:feed:babe:cafe:0 │ ::ffff:192.168.0.0  │
└─────────────────────────────────────┴─────────────────────┘
```

## ipcryptDecrypt {#ipcryptDecrypt}

Добавлено в: v26.10.0

<ExperimentalBadge />

<CloudNotSupportedBadge />

<Warning>
  Эта функция является экспериментальной и в будущих версиях может непредсказуемо измениться способами, нарушающими обратную совместимость.
  Чтобы включить её, установите `enable_ipcrypt = 1`.
</Warning>

Расшифровывает IP-адрес, ранее зашифрованный функцией `ipcryptEncrypt` с тем же ключом.
Для входного значения типа IPv4/IPv6 возвращается IPv6, для входного значения типа String — String (IPv4-отображённый адрес записывается в текстовом виде как IPv4, как и в эталонной реализации).

**Синтаксис**

```sql
ipcryptDecrypt(encrypted_ip, key)
```

**Аргументы**

* `encrypted_ip` — зашифрованный IP-адрес для расшифровки. [`IPv4`](/ru/reference/data-types/ipv4), [`IPv6`](/ru/reference/data-types/ipv6) или [`String`](/ru/reference/data-types/string)
* `key` — 16-байтовый ключ шифрования (необработанные байты или 32 символа в шестнадцатеричном представлении). Должен быть константой. [`String`](/ru/reference/data-types/string) или [`FixedString`](/ru/reference/data-types/fixedstring)

**Возвращаемое значение**

Расшифрованный IP-адрес. Для входного значения типа IPv4/IPv6 возвращается IPv6, для входного значения типа String — String. [`IPv6`](/ru/reference/data-types/ipv6) или [`String`](/ru/reference/data-types/string)

**Примеры**

**Обратимый обмен: шифрование с последующей расшифровкой**

```sql title=Query
SET enable_ipcrypt = 1;
SELECT ipcryptDecrypt(ipcryptEncrypt(toIPv4('192.168.1.1'), unhex('00112233445566778899aabbccddeeff')), unhex('00112233445566778899aabbccddeeff'))
```

```response title=Response
::ffff:192.168.1.1
```

Эта функция принимает как IPv4-, так и IPv6-адреса (и сети), представленные в виде строк. Она возвращает `0`, если IP-версия адреса и CIDR не совпадают.


## toIPv6OrZero {#toIPv6OrZero}

Добавленный в: v23.1.0

Преобразует входное значение в значение типа [IPv6](/ru/reference/data-types/ipv6), но в случае ошибки возвращает нулевой IPv6-адрес.
Аналогично [`toIPv6`](#toIPv6), но при ошибках преобразования возвращает нулевой IPv6-адрес (`::`) вместо того, чтобы генерировать исключение.

Поддерживаемые аргументы:

* Строковые представления IPv6-адресов в стандартной записи.
* Строковые представления IPv4-адресов (преобразуются в IPv4-mapped IPv6).
* Двоичные представления IPv6-адресов.

Неподдерживаемые аргументы (возвращают нулевой IPv6-адрес):

* Недопустимые форматы IP-адресов.
* Некорректные IPv6-адреса.
* Значения вне допустимого диапазона.

**Синтаксис**

```sql
toIPv6OrZero(x)
```

**Аргументы**

* `x` — Строковое представление IPv6-адреса или IPv4-адреса. [`String`](/ru/reference/data-types/string)

**Возвращаемое значение**

Возвращает IPv6-адрес в случае успеха, иначе — нулевой IPv6-адрес (`::`). [`IPv6`](/ru/reference/data-types/ipv6)

**Примеры**

**Пример использования**

```sql title=Query
SELECT
    toIPv6OrZero('2001:0db8:85a3:0000:0000:8a2e:0370:7334') AS valid_ipv6,
    toIPv6OrZero('invalid::ip') AS invalid_ipv6
```

```response title=Response
│ 2001:db8:85a3::8a2e:370:7334 │ ::           │
└──────────────────────────────┴──────────────┘
```
