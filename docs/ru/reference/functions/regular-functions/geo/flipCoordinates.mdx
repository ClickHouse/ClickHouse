## flipCoordinates {#flipcoordinates}

Функция `flipCoordinates` меняет местами координаты точки, Ring, Polygon или multipolygon. Это полезно, например, при преобразовании между системами координат, где порядок широты и долготы различается.

```sql
flipCoordinates(coordinates)
```

### Входные параметры {#input-parameters}

* `coordinates` — кортеж, представляющий точку `(x, y)`, или массив таких кортежей, представляющий Ring, Polygon или Multipolygon. Поддерживаются следующие входные типы:

  * [**Point**](/ru/reference/data-types/geo#point): кортеж `(x, y)`, где `x` и `y` — значения [Float64](/ru/reference/data-types/float).
  * [**Ring**](/ru/reference/data-types/geo#ring): массив точек `[(x1, y1), (x2, y2), ...]`.
  * [**Polygon**](/ru/reference/data-types/geo#polygon): массив Ring `[ring1, ring2, ...]`, где каждый Ring — массив точек.
  * [**Multipolygon**](/ru/reference/data-types/geo#multipolygon): массив Polygon `[polygon1, polygon2, ...]`.

  Координаты должны иметь тип `Float64`: записывайте целочисленные координаты в виде `10.` (или явно приводите их с помощью CAST), поскольку литерал вида `10` имеет тип `UInt8`.

### Возвращаемое значение {#returned-value}

Функция возвращает входные данные с поменянными местами координатами. Например:

* Точка `(x, y)` становится `(y, x)`.
* Ring `[(x1, y1), (x2, y2)]` становится `[(y1, x1), (y2, x2)]`.
* Вложенные структуры, такие как Polygon и Multipolygon, обрабатываются рекурсивно.

### Примеры {#examples}

#### Пример 1: Перестановка координат одной точки {#example-1}

```sql
SELECT flipCoordinates((10., 20.)) AS flipped_point
```

```text
┌─flipped_point─┐
│ (20,10)       │
└───────────────┘
```

#### Пример 2: Перестановка координат в массиве точек (Ring) {#example-2}

```sql
SELECT flipCoordinates([(10., 20.), (30., 40.)]) AS flipped_ring
```

```text
┌─flipped_ring──────┐
│ [(20,10),(40,30)] │
└───────────────────┘
```

#### Пример 3: Перестановка координат Polygon {#example-3}

```sql
SELECT flipCoordinates([[(10., 20.), (30., 40.)], [(50., 60.), (70., 80.)]]) AS flipped_polygon
```

```text
┌─flipped_polygon───────────────────────┐
│ [[(20,10),(40,30)],[(60,50),(80,70)]] │
└───────────────────────────────────────┘
```

#### Пример 4: Перестановка координат Multipolygon {#example-4}

```sql
SELECT flipCoordinates([[[(10., 20.), (30., 40.)]], [[(50., 60.), (70., 80.)]]]) AS flipped_multipolygon
```

```text
┌─flipped_multipolygon──────────────────────┐
│ [[[(20,10),(40,30)]],[[(60,50),(80,70)]]] │
└───────────────────────────────────────────┘
```
