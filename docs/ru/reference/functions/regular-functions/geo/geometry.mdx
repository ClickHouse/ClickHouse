## Geometry {#geometry}

Функции Geometry позволяют вычислять периметр и площадь для геометрических типов, таких как POLYGON, LINESTRING, MULTIPOLYGON, MULTILINESTRING, RING и POINT. Используйте геометрические объекты в типе Geometry. Если входное значение — `NULL`, все перечисленные ниже функции вернут 0.

## perimeterCartesian {#perimetercartesian}

Вычисляет периметр заданного объекта Geometry в декартовой (плоской) системе координат.

**Синтаксис**

```sql
perimeterCartesian(geom)
```

**Аргументы**

* `geom` — объект типа Geometry. [Geometry](/ru/reference/data-types/geo).

**Возвращаемые значения**

* Число — периметр объекта в единицах системы координат. [Float64](/ru/reference/data-types/float).

**Пример**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('POLYGON((0 0,1 0,1 1,0 1,0 0))');
SELECT perimeterCartesian(geom) FROM geo_dst;
```

```response title="Response"
┌─perimeterCartesian(geom)─┐
│ 4.0                      │
└──────────────────────────┘
```

## perimeterSpherical {#perimeterspherical}

Вычисляет периметр объекта Geometry на сфере.

**Синтаксис**

```sql
perimeterSpherical(geom)
```

**Аргументы**

* `geom` — объект типа Geometry. [Geometry](/ru/reference/data-types/geo).

**Возвращаемые значения**

* Число — периметр на сфере радиусом 1 в радианах (координаты задаются как долгота и широта в градусах). Чтобы получить длину, умножьте результат на радиус сферы, например на 6371, чтобы получить значение в километрах для Земли. [Float64](/ru/reference/data-types/float).

**Пример**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('LINESTRING(0 0,1 0,1 1,0 1,0 0)');
SELECT perimeterSpherical(geom) FROM geo_dst;
```

```response title="Response"
┌─perimeterSpherical(geom)─┐
│      0.06981051179132045 │
└──────────────────────────┘
```

## areaSpherical {#areaspherical}

Вычисляет площадь объекта типа Geometry на поверхности сферы.

**Синтаксис**

```sql
areaSpherical(geom)
```

**Аргументы**

* `geom` — Geometry. [Geometry](/ru/reference/data-types/geo).

**Возвращаемые значения**

* Число — площадь на сфере радиуса 1 в стерадианах (координаты — долгота и широта в градусах). Чтобы получить площадь, умножьте результат на квадрат радиуса сферы. [Float64](/ru/reference/data-types/float).

**Пример**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('POLYGON((0 0,1 0,1 1,0 1,0 0))');
SELECT areaSpherical(geom) FROM geo_dst;
```

```response title="Response"
┌─areaSpherical(geom)────┐
│ -0.0003046096848622019 │
└────────────────────────┘
```
