## sumKahan {#sumKahan}

Добавленный в: v1.1.0

Вычисляет сумму чисел с помощью [алгоритма компенсационного суммирования Кэхэна](https://en.wikipedia.org/wiki/Kahan_summation_algorithm).
Работает медленнее, чем функция [`sum`](/ru/reference/functions/aggregate-functions/sum).
Компенсация работает только для типов [Float](/ru/reference/data-types/float).
Для типов [Decimal](/ru/reference/data-types/decimal) и [Interval](/ru/reference/data-types/special-data-types/interval), основанных на целых числах, вместо этого используется точное суммирование с помощью `sum`.

**Синтаксис**

```sql
sumKahan(x)
```

**Аргументы**

* `x` — Входное значение. [`Integer`](/ru/reference/data-types/int-uint), [`Float`](/ru/reference/data-types/float), [`Decimal`](/ru/reference/data-types/decimal) или [`Interval`](/ru/reference/data-types/special-data-types/interval)

**Возвращаемое значение**

Возвращает сумму чисел. [`(U)Int*`](/ru/reference/data-types/int-uint), [`Float*`](/ru/reference/data-types/float), [`Decimal`](/ru/reference/data-types/decimal) или [`Interval`](/ru/reference/data-types/special-data-types/interval)

**Примеры**

**Демонстрация повышения точности с помощью суммирования по алгоритму Кэхэна**

```sql title=Query
SELECT sum(0.1), sumKahan(0.1) FROM numbers(10);
```

```response title=Response
┌───────────sum(0.1)─┬─sumKahan(0.1)─┐
│ 0.9999999999999999 │             1 │
└────────────────────┴───────────────┘
```
