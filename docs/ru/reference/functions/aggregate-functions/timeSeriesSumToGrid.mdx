## timeSeriesSumToGrid {#timeSeriesSumToGrid}

Добавлена в: v26.9.0

Агрегатная функция, которая принимает данные временного ряда в виде пар временных меток и значений и вычисляет по этим данным [аналог PromQL-функции sum&#95;over&#95;time](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) на регулярной временной сетке, заданной начальной временной меткой, конечной временной меткой и шагом. Для каждой точки сетки при вычислении суммы учитываются образцы, попадающие в заданное временное окно.

Образцы можно передавать в одной из трёх форм:

* в виде двух аргументов `timestamp` и `value`, где каждая строка содержит один образец;
* в виде двух массивов временных меток и значений, где каждая строка содержит целый временной ряд;
* в виде одного массива кортежей `(timestamp, value)`, где каждая строка содержит целый временной ряд.

Если у нескольких образцов совпадают временные метки, используется только один из них — образец с наибольшим значением. Значение NaN проигрывает любому другому значению, поэтому NaN используется только в том случае, если все образцы с этой временной меткой равны NaN.

<Warning>
  Эта функция доступна в закрытой предварительной версии. Чтобы включить её, установите `enable_time_series_aggregate_functions=true`.
</Warning>

**Синтаксис**

```sql
timeSeriesSumToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
timeSeriesSumToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples)
```

**Параметры**

* `start_timestamp` — Задаёт начало сетки. Также может быть дробным числом или строкой, содержащей число или дату и время в текстовом виде. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `end_timestamp` — Задаёт конец сетки. Также может быть дробным числом или строкой, содержащей число или дату и время в текстовом виде. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `grid_step` — Задаёт шаг сетки в секундах. Также может быть дробным числом или строкой, содержащей число или длительность, например &#39;15s&#39; или &#39;1m&#39;. [`UInt32`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `staleness` — Задаёт максимальную давность (в секундах) учитываемых образцов. Окно давности — это интервал, открытый слева и закрытый справа. Также может быть дробным числом или строкой, содержащей число или длительность, например &#39;15s&#39; или &#39;1m&#39;. [`UInt32`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)

**Аргументы**

* `timestamp` — Временная метка образца. Может передаваться как отдельные значения или как массивы. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Array(UInt32)`](/ru/reference/data-types/array) или [`Array(DateTime)`](/ru/reference/data-types/array) или [`Array(DateTime64)`](/ru/reference/data-types/array)
* `value` — Значение временного ряда, соответствующее временной метке. Может передаваться как отдельные значения или как массивы. [`Float*`](/ru/reference/data-types/float) или [`Array(Float*)`](/ru/reference/data-types/array)
* `samples` — Образцы временного ряда в виде массива Tuple `(timestamp, value)`, элементы которых имеют указанные выше типы временной метки и значения. Альтернатива передаче временных меток и значений двумя отдельными аргументами. [`Array(Tuple(T1, T2))`](/ru/reference/data-types/array)

**Возвращаемое значение**

Возвращает сумму значений на заданной сетке. Возвращаемый массив содержит по одному значению для каждой точки временной сетки. Если для точки сетки в окне нет ни одного образца, значение равно NULL. [`Array(Nullable(Float64))`](/ru/reference/data-types/array)

**Примеры**

**Базовое использование с отдельными парами «временная метка — значение»**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesSumToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesSumToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,2,5,9,7,4,5,18]                                                            │
└───────────────────────────────────────────────────────────────────────────────────────┘
```

**Использование массивов в качестве аргументов**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesSumToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesSumToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,2,5,9,7,4,5,18]                                                              │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
