## timeSeriesFirstToGrid {#timeSeriesFirstToGrid}

Добавлена в: v26.10.0

Агрегатная функция, которая принимает данные временных рядов в виде пар временных меток и значений и вычисляет по ним [аналог first&#95;over&#95;time из PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) на регулярной временной сетке, заданной начальной временной меткой, конечной временной меткой и шагом. Для каждой точки сетки результатом является значение самого раннего образца в пределах заданного временного окна.

Образцы можно передавать в одной из трёх форм:

* в виде двух аргументов `timestamp` и `value`, где каждая строка содержит один образец;
* в виде двух массивов временных меток и значений, где каждая строка содержит целый временной ряд;
* в виде одного массива значений типа Tuple `(timestamp, value)`, где каждая строка содержит целый временной ряд.

Если у нескольких образцов совпадает временная метка, используется только один из них — образец с наибольшим значением. Значение NaN уступает любому другому значению, поэтому NaN используется, только если все образцы с этой временной меткой равны NaN.

<Warning>
  Эта функция находится в закрытой предварительной версии. Чтобы включить её, установите `enable_time_series_aggregate_functions=true`.
</Warning>

**Синтаксис**

```sql
timeSeriesFirstToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(timestamp, value)
timeSeriesFirstToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(samples)
```

**Параметры**

* `start_timestamp` — Задаёт начало сетки. Также может быть дробным числом или строкой, содержащей число или дату и время в текстовом виде. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `end_timestamp` — Задаёт конец сетки. Также может быть дробным числом или строкой, содержащей число или дату и время в текстовом виде. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `grid_step` — Задаёт шаг сетки в секундах. Также может быть дробным числом или строкой, содержащей число или длительность, например &#39;15s&#39; или &#39;1m&#39;. [`UInt32`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `staleness_window` — Задаёт максимальную «давность» учитываемых образцов в секундах. Окно давности представляет собой интервал, открытый слева и закрытый справа. Также может быть дробным числом или строкой, содержащей число или длительность, например &#39;15s&#39; или &#39;1m&#39;. [`UInt32`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)

**Аргументы**

* `timestamp` — Временная метка образца. Может передаваться как отдельными значениями, так и массивами. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Array(UInt32)`](/ru/reference/data-types/array) или [`Array(DateTime)`](/ru/reference/data-types/array) или [`Array(DateTime64)`](/ru/reference/data-types/array)
* `value` — Значение временного ряда, соответствующее временной метке. Может передаваться как отдельными значениями, так и массивами. [`Float*`](/ru/reference/data-types/float) или [`Array(Float*)`](/ru/reference/data-types/array)
* `samples` — Образцы временного ряда, передаваемые в виде массива Tuple `(timestamp, value)`, где элементы Tuple имеют указанные выше типы временной метки и значения. Альтернатива передаче временных меток и значений двумя отдельными аргументами. [`Array(Tuple(T1, T2))`](/ru/reference/data-types/array)

**Возвращаемое значение**

Возвращает значения самых ранних образцов на заданной сетке; тип значений совпадает с типом `value`. Возвращаемый массив содержит по одному значению для каждой точки временной сетки. Если для данной точки сетки в окне нет ни одного образца, значение равно NULL. [`Array(Nullable(Float*))`](/ru/reference/data-types/array)

**Примеры**

**Вычисление значений first&#95;over&#95;time на сетке [90, 105, 120, 135, 150, 165, 180, 195, 210]**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to staleness window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    30 AS window_seconds  -- "staleness" window
SELECT timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,1,1,3,4,NULL,5,5]                                                            │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

**Тот же запрос с массивами в качестве аргументов**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    30 AS window_seconds
SELECT timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,1,1,3,4,NULL,5,5]                                                              │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```
