## sum {#sum}

Добавлена в: v1.1.0

Вычисляет сумму числовых значений или интервалов.

**Синтаксис**

```sql
sum(num)
```

**Аргументы**

* `num` — Столбец с числовыми значениями или интервалами. [`(U)Int*`](/ru/reference/data-types/int-uint) or [`Float*`](/ru/reference/data-types/float) or [`Decimal*`](/ru/reference/data-types/decimal) or [`Interval`](/ru/reference/data-types/special-data-types/interval)

**Возвращаемое значение**

Возвращает сумму значений. Для аргумента `Interval` результатом будет интервал в тех же единицах измерения, а при отсутствии входных данных — интервал нулевой длительности. [`(U)Int*`](/ru/reference/data-types/int-uint) or [`Float*`](/ru/reference/data-types/float) or [`Decimal*`](/ru/reference/data-types/decimal) or [`Interval`](/ru/reference/data-types/special-data-types/interval)

**Примеры**

**Вычисление суммы зарплат сотрудников**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**Общее время, затраченное на обработку запросов**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
