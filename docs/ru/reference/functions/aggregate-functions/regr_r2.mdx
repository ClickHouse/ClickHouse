## regr_r2 {#regr_r2}

Добавлено в: v26.9.0

Возвращает коэффициент детерминации для аппроксимации методом наименьших квадратов, то есть квадрат
коэффициента корреляции. Возвращает `nan`, если `x` является константой, и `1`, если `y` является константой.

**Синтаксис**

```sql
regr_r2(y, x)
```

**Псевдонимы**: `regrR2`

**Аргументы**

* `y` — зависимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)
* `x` — независимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)

**Возвращаемое значение**

Возвращает значение от 0 до 1. [`Float64`](/ru/reference/data-types/float)

**Примеры**

**Базовое использование**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
