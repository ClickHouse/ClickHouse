## regr_slope {#regr_slope}

Добавлено в: v26.9.0

Возвращает угловой коэффициент линии регрессии `y` по `x`, построенной методом наименьших квадратов:

$$
\frac{\Sigma{(x - \bar{x})(y - \bar{y})}}{\Sigma{(x - \bar{x})^2}}
$$

Возвращает `nan`, если `x` — константа, так как в этом случае линия регрессии вертикальна.

**Синтаксис**

```sql
regr_slope(y, x)
```

**Псевдонимы**: `regrSlope`

**Аргументы**

- `y` — Зависимая переменная. [`(U)Int*`](/reference/data-types/int-uint) или [`Float*`](/reference/data-types/float)
- `x` — Независимая переменная. [`(U)Int*`](/reference/data-types/int-uint) или [`Float*`](/reference/data-types/float)

**Возвращаемое значение**

Возвращает угловой коэффициент линии регрессии. [`Float64`](/reference/data-types/float)

**Примеры**

**Базовое использование**

```sql title=Query
SELECT regr_slope(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_slope(y, x)─┐
│                2 │
└──────────────────┘
```
