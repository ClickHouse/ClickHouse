## regr_count {#regr_count}

Добавлена в: v26.9.0

Подсчитывает строки, в которых ни `y`, ни `x` не равны `NULL`.

**Синтаксис**

```sql
regr_count(y, x)
```

**Псевдонимы**: `regrCount`

**Аргументы**

* `y` — зависимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)
* `x` — независимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)

**Возвращаемое значение**

Возвращает количество пар, не содержащих NULL. [`UInt64`](/ru/reference/data-types/int-uint)

**Примеры**

**Базовое использование**

```sql title=Query
SELECT regr_count(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_count(y, x)─┐
│                4 │
└──────────────────┘
```
