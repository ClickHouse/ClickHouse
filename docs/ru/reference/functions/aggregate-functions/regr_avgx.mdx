## regr_avgx {#regr_avgx}

Добавлено в: v26.9.0

Возвращает среднее значение независимой переменной.

Среднее вычисляется относительно одного из значений в данных, а не относительно нуля, поэтому для целочисленного столбца со значениями больше
2^53 результат может оказаться ближе к точному среднему, чем у функции [`avg`](/ru/reference/functions/aggregate-functions/avg),
которая делит сумму типа `Float64`.

**Синтаксис**

```sql
regr_avgx(y, x)
```

**Псевдонимы**: `regrAvgX`

**Аргументы**

* `y` — зависимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)
* `x` — независимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)

**Возвращаемое значение**

Возвращает среднее значение `x`. [`Float64`](/ru/reference/data-types/float)

**Примеры**

**Базовое использование**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
