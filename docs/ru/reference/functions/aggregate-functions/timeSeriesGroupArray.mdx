## timeSeriesGroupArray {#timeSeriesGroupArray}

Добавленный в: v25.8.0

Сортирует данные временных рядов по временной метке в порядке возрастания.

Образцы можно передавать в одной из трёх форм:

* в виде двух аргументов `timestamp` и `value`, где каждая строка содержит один образец;
* в виде двух массивов временных меток и значений, где каждая строка содержит целый временной ряд;
* в виде одного массива кортежей `(timestamp, value)`, где каждая строка содержит целый временной ряд. Эта форма имеет тот же тип, что и результат, что позволяет использовать функцию в типе данных `SimpleAggregateFunction`.

Если несколько образцов имеют одинаковую временную метку, используется только один из них — образец с наибольшим значением. Значение NaN уступает любому другому значению, поэтому используется только в том случае, если все образцы с этой временной меткой имеют значение NaN.

<Note>
  Эта функция является экспериментальной. Чтобы включить её, установите `allow_experimental_time_series_aggregate_functions=true`.
</Note>

**Синтаксис**

```sql
timeSeriesGroupArray(timestamp, value)
timeSeriesGroupArray(samples)
```

**Аргументы**

* `timestamp` — Временная метка точки. Может быть отдельным значением или массивом. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Array(UInt32)`](/ru/reference/data-types/array) или [`Array(DateTime)`](/ru/reference/data-types/array) или [`Array(DateTime64)`](/ru/reference/data-types/array)
* `value` — Значение временного ряда, соответствующее этой временной метке. Может быть отдельным значением или массивом. [`Float*`](/ru/reference/data-types/float) или [`Array(Float*)`](/ru/reference/data-types/array)
* `samples` — Образцы временного ряда, передаваемые в виде массива кортежей `(timestamp, value)`, где элементы кортежа имеют указанные выше типы временной метки и значения. [`Array(Tuple(T1, T2))`](/ru/reference/data-types/array)

**Возвращаемое значение**

Возвращает массив кортежей `(timestamp, value)`, отсортированный по временной метке по возрастанию. [`Array(Tuple(T1, T2))`](/ru/reference/data-types/array)

**Примеры**

**Базовое использование с отдельными значениями**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 140, 100]::Array(UInt32) AS timestamps,
    [1, 6, 8, 17, 19, 5]::Array(Float32) AS values
SELECT timeSeriesGroupArray(timestamp, value)
FROM
(
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesGroupArray(timestamp, value)─────┐
│ [(100,5),(110,1),(120,6),(130,8),(140,19)] │
└────────────────────────────────────────────┘
```

**Передача нескольких наборов временных меток и значений в виде массивов одинаковой длины**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 140, 100]::Array(UInt32) AS timestamps,
    [1, 6, 8, 17, 19, 5]::Array(Float32) AS values
SELECT timeSeriesGroupArray(timestamps, values);
```

```response title=Response
┌─timeSeriesGroupArray(timestamps, values)───┐
│ [(100,5),(110,1),(120,6),(130,8),(140,19)] │
└────────────────────────────────────────────┘
```
