## avg {#avg}

Добавлено в версии: v1.1.0

Вычисляет среднее арифметическое.

**Синтаксис**

```sql
avg(x)
```

**Аргументы**

* `x` — Входные значения. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal`](/ru/reference/data-types/decimal) или [`Date`](/ru/reference/data-types/date) или [`Date32`](/ru/reference/data-types/date32) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64(P)`](/ru/reference/data-types/datetime64) или [`Time`](/ru/reference/data-types/time) или [`Time64(P)`](/ru/reference/data-types/time64) или [`Interval`](/ru/reference/data-types/special-data-types/interval)

**Возвращаемое значение**

Возвращает среднее арифметическое. Для числовых значений `x` результат имеет тип `Float64`; если `x` пуст, возвращается `NaN`. Для значений даты, времени или интервала результат сохраняет тип `x`: среднее округляется до ближайшего значения, представимого в этом типе, а если `x` пуст, возвращается нулевое значение этого типа. [`Float64`](/ru/reference/data-types/float) или [`Date`](/ru/reference/data-types/date) или [`Date32`](/ru/reference/data-types/date32) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64(P)`](/ru/reference/data-types/datetime64) или [`Time`](/ru/reference/data-types/time) или [`Time64(P)`](/ru/reference/data-types/time64) или [`Interval`](/ru/reference/data-types/special-data-types/interval)

**Примеры**

**Базовое использование**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**Для пустой таблицы возвращается NaN**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**Среднее значение временного интервала**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
