<div id="timeSeriesDerivToGrid">
  ## timeSeriesDerivToGrid
</div>

Добавленный в: v25.6.0

Агрегатная функция, которая принимает данные временных рядов в виде пар временных меток и значений и вычисляет [производную в стиле PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#deriv) по этим данным на регулярной временной сетке, заданной начальной временной меткой, конечной временной меткой и шагом. Для каждой точки сетки при вычислении `deriv` учитываются выборки в пределах указанного временного окна.

Если несколько выборок имеют одинаковую временную метку, используется только одна из них — выборка с наибольшим значением. Значение NaN уступает любому другому значению, поэтому оно используется только в том случае, если все выборки с этой временной меткой имеют значение NaN.

<Note>
  Эта функция экспериментальная; чтобы включить её, задайте `allow_experimental_time_series_aggregate_functions=true`.
</Note>

**Синтаксис**

```sql
timeSeriesDerivToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
```

**Параметры**

* `start_timestamp` — Указывает начало сетки. При аргументе временной метки `DateTime64` также может быть дробным числом или строкой, содержащей число либо текст даты и времени. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `end_timestamp` — Указывает конец сетки. При аргументе временной метки `DateTime64` также может быть дробным числом или строкой, содержащей число либо текст даты и времени. [`UInt32`](/ru/reference/data-types/int-uint) или [`DateTime`](/ru/reference/data-types/datetime) или [`DateTime64`](/ru/reference/data-types/datetime64) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `grid_step` — Указывает шаг сетки в секундах. При аргументе временной метки `DateTime64` также может быть дробным числом или строкой, содержащей число либо длительность, например &#39;15s&#39; или &#39;1m&#39;. [`UInt32`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)
* `staleness` — Указывает максимально допустимую «устарелость» рассматриваемых отсчётов в секундах. Окно устарелости представляет собой интервал, открытый слева и закрытый справа. При аргументе временной метки `DateTime64` также может быть дробным числом или строкой, содержащей число либо длительность, например &#39;15s&#39; или &#39;1m&#39;. [`UInt32`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float) или [`Decimal*`](/ru/reference/data-types/decimal) или [`String`](/ru/reference/data-types/string)

**Аргументы**

* `timestamp` — Временная метка отсчёта. Может быть отдельным значением или массивом. - `value` — Значение временного ряда, соответствующее временной метке. Может быть отдельным значением или массивом.

**Возвращаемое значение**

Значения `deriv` на указанной сетке в виде `Array(Nullable(Float64))`. Возвращаемый массив содержит по одному значению для каждой точки временной сетки. Значение равно NULL, если в пределах окна недостаточно образцов для вычисления значения производной в конкретной точке сетки.

**Примеры**

**Вычислить значения производной на сетке [90, 105, 120, 135, 150, 165, 180, 195, 210]**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,0,0.1,0.11,0.1,NULL,NULL,0.15]                                               │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

**Тот же запрос с аргументами в виде массивов**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,0,0.1,0.11,0.1,NULL,NULL,0.15]                                                 │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```
