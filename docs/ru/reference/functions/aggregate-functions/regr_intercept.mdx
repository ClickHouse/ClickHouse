## regr_intercept {#regr_intercept}

Добавлено в: v26.9.0

Возвращает свободный член (точку пересечения с осью ординат) линейной регрессии `y` по `x`, построенной методом наименьших квадратов:

$$
\bar{y} - slope \cdot \bar{x}
$$

Возвращает `nan`, если `x` постоянен, поскольку в этом случае аппроксимирующая прямая вертикальна.

**Синтаксис**

```sql
regr_intercept(y, x)
```

**Псевдонимы**: `regrIntercept`

**Аргументы**

* `y` — зависимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)
* `x` — независимая переменная. [`(U)Int*`](/ru/reference/data-types/int-uint) или [`Float*`](/ru/reference/data-types/float)

**Возвращаемое значение**

Возвращает свободный член линии регрессии (точку её пересечения с осью Y). [`Float64`](/ru/reference/data-types/float)

**Примеры**

**Базовое использование**

```sql title=Query
SELECT regr_intercept(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_intercept(y, x)─┐
│                    0 │
└──────────────────────┘
```
