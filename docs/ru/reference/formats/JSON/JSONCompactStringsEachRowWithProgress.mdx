## Описание {#description}

Аналогично [`JSONCompactEachRowWithProgress`](/ru/reference/formats/JSON/JSONCompactEachRowWithProgress), но все значения преобразуются в строки. Использует те же виды объектов верхнего уровня (`meta`, `row`, `progress`, `totals`, `min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation`, а также `exception` верхнего уровня); полезная нагрузка `row` / `totals` / `min` / `max` по-прежнему представляет собой **массивы** с порядком элементов, соответствующим порядку столбцов, при этом каждый элемент сериализуется как строка.

Полное описание контракта объектов потока см. в [`JSONCompactEachRowWithProgress`](/ru/reference/formats/JSON/JSONCompactEachRowWithProgress) (`progress` может прийти раньше `meta`; если запрос содержит `LIMIT`, `rows_before_limit_at_least` — это оценка снизу, а не доказательство того, что строки были отброшены; `exception` записывается только при работе через HTTP с `http_write_exception_in_output_format=1`).

## Пример использования {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
