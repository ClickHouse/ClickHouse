## Описание {#description}

Отличается от `JSONEachRow`/`JSONStringsEachRow` тем, что ClickHouse передаёт каждое событие в потоке как отдельный объект JSON, а также выдаёт информацию о прогрессе выполнения запроса.

Все значения полей сериализуются как строки (включая составные типы): например, `arr` выводится как `"arr":"[0,1]"`, а не как вложенный JSON-массив. Скалярные значения также преобразуются в строки (`"num":"42"`).

Виды объектов верхнего уровня совпадают с [`JSONEachRowWithProgress`](/ru/reference/formats/JSON/JSONEachRowWithProgress) (`meta`, `row`, `progress`, `totals`/`min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation` и `exception` верхнего уровня). Полное описание контракта потока приведено на указанной странице: объект `progress` может прийти раньше `meta`; если запрос содержит `LIMIT`, `rows_before_limit_at_least` представляет собой оценку снизу (и не означает, что строки были отброшены); `exception` записывается только при работе через HTTP с `http_write_exception_in_output_format=1`.

## Пример использования {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
