## Описание {#description}

Выводит каждое значение на отдельной строке с указанием имени столбца. Этот формат удобен для вывода одной или нескольких строк, если каждая строка содержит большое количество столбцов.

Обратите внимание, что [`NULL`](/ru/reference/syntax) выводится как `ᴺᵁᴸᴸ`, чтобы его было проще отличить от строкового значения `NULL` и отсутствующего значения. JSON-столбцы форматируются в удобочитаемом виде, а `NULL` выводится как `null`, поскольку это допустимое значение JSON и его легко отличить от `"null"`.

## Пример использования {#example-usage}

Пример:

```sql
SELECT * FROM t_null FORMAT Vertical
```

```response
Row 1:
──────
x: 1
y: ᴺᵁᴸᴸ
```

По умолчанию непечатаемые управляющие символы (управляющие символы C0 `0x00`–`0x1F` и `DEL` `0x7F`) в значениях и именах столбцов отображаются соответствующими символами Unicode из блока &quot;Control Pictures&quot; (`U+2400`–`U+2421`). Благодаря этому они остаются видимыми и не поглощаются терминалом незаметно. Например, NUL отображается как `␀`:

```sql
SELECT 'string with a NUL \0 character' AS test FORMAT Vertical
```

```response
Row 1:
──────
test: string with a NUL ␀ character
```

`TAB`, перевод строки и `ESC` являются исключениями: они всегда выводятся как есть, поскольку терминал не поглощает их, а интерпретирует — символ табуляции перемещает курсор к следующей позиции табуляции, перевод строки начинает новую строку, а escape-последовательность ANSI позволяет передавать в данных визуализацию. Имя столбца — исключение из этого исключения: оно отображается в одну строку, поэтому перевод строки в имени заменяется так же, как и любой другой управляющий символ.

Чтобы вместо этого выводить управляющие символы без изменений, отключите [`output_format_pretty_display_control_characters`](/ru/reference/settings/formats#output_format_pretty_display_control_characters):

```sql
SELECT 'string with a NUL \0 character' AS test
FORMAT Vertical
SETTINGS output_format_pretty_display_control_characters = 0
```

В этом случае ответ содержит сам байт `NUL` в исходном виде. Терминал его не отображает, поэтому значение
выглядит так, будто этого символа просто нет.

Этот формат подходит только для вывода результата запроса, но не для разбора (получения данных для вставки в таблицу).
