> В этом руководстве объясняется, как использовать MCP-сервер ClickHouse с [Jan.ai](https://jan.ai/docs).

<Steps>
  <Step title="Установите Jan.ai" id="install-janai">
    Jan.ai — это альтернатива ChatGPT с открытым исходным кодом, которая работает полностью офлайн.
    Jan.ai можно скачать для [Mac](https://jan.ai/docs/desktop/install/mac), [Windows](https://jan.ai/docs/desktop/windows) или [Linux](https://jan.ai/docs/desktop/linux).

    Это нативное приложение, поэтому после загрузки его можно сразу запустить.
  </Step>

  <Step title="Добавьте LLM в Jan.ai" id="add-llm-to-janai">
    Модели включаются в меню настроек.

    Чтобы подключить OpenAI, укажите ключ API, как показано ниже:

    <div className="ch-image-md">
      <Frame>
        ![Включение моделей OpenAI](/images/use-cases/AI_ML/MCP/0_janai_openai.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Включите MCP-серверы" id="enable-mcp-servers">
    На момент написания этого руководства MCP-серверы являются экспериментальной возможностью Jan.ai.
    Чтобы их включить, активируйте переключатель экспериментальных возможностей:

    <div className="ch-image-md">
      <Frame>
        ![Включение MCP-серверов](/images/use-cases/AI_ML/MCP/1_janai_mcp_servers.webp)
      </Frame>
    </div>

    После этого в левом меню появится пункт `MCP servers`.
  </Step>

  <Step title="Настройте MCP-сервер ClickHouse" id="configure-clickhouse-mcp-server">
    Если открыть пункт меню `MCP servers`, отобразится список MCP-серверов, к которым можно подключиться:

    <div className="ch-image-md">
      <Frame>
        ![Список MCP-серверов](/images/use-cases/AI_ML/MCP/2_janai_mcp_servers_list.webp)
      </Frame>
    </div>

    По умолчанию все эти серверы отключены, но их можно включить с помощью переключателя.

    Чтобы установить MCP-сервер ClickHouse, нажмите значок `+` и заполните форму следующим образом:

    <div className="ch-image-md">
      <Frame>
        ![Добавление MCP-сервера](/images/use-cases/AI_ML/MCP/3_janai_add_mcp_server.webp)
      </Frame>
    </div>

    Затем включите ClickHouse Server с помощью переключателя, если он ещё не включён:

    <div className="ch-image-md">
      <Frame>
        ![Включение MCP-сервера](/images/use-cases/AI_ML/MCP/4_janai_toggle.webp)
      </Frame>
    </div>

    Теперь инструменты MCP-сервера ClickHouse будут доступны в окне чата:

    <div className="ch-image-md">
      <Frame>
        ![Инструменты MCP-сервера ClickHouse](/images/use-cases/AI_ML/MCP/5_jani_tools.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Общайтесь с MCP-сервером ClickHouse в Jan.ai" id="chat-to-clickhouse-mcp-server">
    Пора поговорить о данных, хранящихся в ClickHouse!
    Зададим вопрос:

    <div className="ch-image-md">
      <Frame>
        ![Вопрос](/images/use-cases/AI_ML/MCP/6_janai_question.webp)
      </Frame>
    </div>

    Перед вызовом инструмента Jan.ai запросит подтверждение:

    <div className="ch-image-md">
      <Frame>
        ![Подтверждение вызова инструмента](/images/use-cases/AI_ML/MCP/7_janai_tool_confirmation.webp)
      </Frame>
    </div>

    Затем отобразится список выполненных вызовов инструментов:

    <div className="ch-image-md">
      <Frame>
        ![Вызванные инструменты](/images/use-cases/AI_ML/MCP/8_janai_tools_called.webp)
      </Frame>
    </div>

    Если нажать на вызов инструмента, откроются его подробности:

    <div className="ch-image-md">
      <Frame>
        ![Развёрнутые вызовы инструментов](/images/use-cases/AI_ML/MCP/9_janai_tools_called_expanded.webp)
      </Frame>
    </div>

    Ниже отображается результат:

    <div className="ch-image-md">
      <Frame>
        ![Результат](/images/use-cases/AI_ML/MCP/10_janai_result.webp)
      </Frame>
    </div>
  </Step>
</Steps>
