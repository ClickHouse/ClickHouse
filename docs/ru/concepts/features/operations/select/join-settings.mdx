На этой странице перечислены настройки сеанса, влияющие на семантику, планирование, выполнение JOIN и потребление памяти. Для каждой настройки приведена ссылка на соответствующую запись в [справочнике по настройкам сеанса](/ru/reference/settings/session-settings), где указаны её значение по умолчанию и допустимые значения. Синтаксис и семантика JOIN описаны в [справочнике по предложению `JOIN`](/ru/reference/statements/select/join).

## Семантика и синтаксис {#semantics-and-syntax}

| Настройка                                                                                                                                                                              | Описание                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/ru/reference/settings/session-settings/join#join_default_strictness)                                                                                         | Задаёт строгость JOIN, для которого строгость явно не указана.                                                                                                  |
| [`any_join_distinct_right_table_keys`](/ru/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | Включает прежнее поведение `ANY INNER JOIN` и `ANY LEFT JOIN`, при котором `t1 ANY LEFT JOIN t2` и `t2 ANY RIGHT JOIN t1` могут возвращать разные результаты.   |
| [`join_any_take_last_row`](/ru/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | Определяет, какую строку берёт JOIN со строгостью `ANY` — первую или последнюю совпадающую, — если в правой таблице для ключа есть несколько совпадающих строк. |
| [`join_use_nulls`](/ru/reference/settings/session-settings/join#join_use_nulls)                                                                                                           | Определяет, чем заполняются столбцы строк без совпадения во внешнем JOIN: значениями по умолчанию или `NULL`.                                                   |
| [`semi_join_include_columns_from_both_sides`](/ru/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | Определяет, содержит ли результат `SEMI JOIN` столбцы обеих таблиц или только столбцы сохраняемой таблицы.                                                      |
| [`anti_join_include_columns_from_both_sides`](/ru/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | Определяет, содержит ли результат `ANTI JOIN` столбцы обеих таблиц или только столбцы сохраняемой таблицы.                                                      |
| [`cross_to_inner_join_rewrite`](/ru/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | Определяет, переписывается ли в `INNER JOIN` список таблиц через запятую или `CROSS JOIN` с условиями равенства в `WHERE`.                                      |
| [`allow_block_nested_loop_join`](/ru/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | Разрешает выполнять JOIN, секция `ON` которого не содержит равенства между таблицами, как блочный JOIN с вложенными циклами.                                    |
| [`enable_lateral_join`](/ru/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | Включает экспериментальный синтаксис `LATERAL JOIN`, при котором подзапрос в правой части JOIN может ссылаться на столбцы левой части.                          |
| [`single_join_prefer_left_table`](/ru/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | Если в одиночном JOIN идентификатор неоднозначен между двумя таблицами, относит его к левой таблице.                                                            |
| [`joined_subquery_requires_alias`](/ru/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | Требует, чтобы подзапросы и табличные функции в JOIN имели псевдонимы.                                                                                          |
| [`allow_dynamic_type_in_join_keys`](/ru/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | Разрешает ключи JOIN типа `Dynamic`.                                                                                                                            |
| [`analyzer_compatibility_join_using_top_level_identifier`](/ru/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | Сопоставляет имя столбца в `USING` с одноимённым псевдонимом в запросе, например с псевдонимом в списке `SELECT`.                                               |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/ru/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | Дополняет имена столбцов результата именами или псевдонимами таблиц в запросе с двумя и более JOIN, как это делал старый анализатор.                            |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/ru/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | Применяет модификатор `FINAL`, указанный для крайней левой таблицы JOIN, ко всем соединяемым таблицам, как в версиях до 26.6.                                   |

LIMIT n` ниже `LEFT` или `RIGHT` JOIN, если ключ сортировки ссылается только на столбцы сохраняемой стороны.                               |
| [`query_plan_propagate_predicate_across_join`](/ru/reference/settings/session-settings/query-plan#query_plan_propagate_predicate_across_join)                                      | Копирует условия фильтрации с одной стороны JOIN по равенству на другую через ключи JOIN.                                                                           |
| [`enable_join_transitive_predicates`](/ru/reference/settings/session-settings/enable-join#enable_join_transitive_predicates)                                                       | Выводит транзитивные условия равенства из существующих условий JOIN для оптимизатора порядка соединений.                                                            |
| [`use_join_disjunctions_push_down`](/ru/reference/settings/session-settings/use#use_join_disjunctions_push_down)                                                                   | Включает перемещение частей условий JOIN, соединённых через `OR`, вниз к соответствующим входам.                                                                    |

| [`query_plan_max_limit_for_join_lazy_indexing`](/ru/reference/settings/session-settings/query-plan#query_plan_max_limit_for_join_lazy_indexing)                                    | Задаёт максимальное значение `LIMIT`, при котором используется оптимизация ленивой индексации JOIN.                                                                 |

| [`enable_join_runtime_filters`](/ru/reference/settings/session-settings/enable-join#enable_join_runtime_filters)                                                                   | Включает фильтрацию проверяемой стороны JOIN по множеству ключей JOIN, собранному со стороны построения во время выполнения.                                        |

| [`enable_join_seal_gated_reading`](/ru/reference/settings/session-settings/enable-join#enable_join_seal_gated_reading)                                                             | Откладывает чтение проверяемой стороны hash JOIN до тех пор, пока не будет завершено построение фильтра времени выполнения на стороне построения.                   |

| [`join_runtime_filter_min_probe_rows`](/ru/reference/settings/session-settings/join-runtime#join_runtime_filter_min_probe_rows)                                                    | Задаёт оценочное количество строк проверяемой стороны, при достижении которого или меньшем значении фильтр времени выполнения JOIN не создаётся.                    |

## Ограничения памяти и сброс данных на диск {#memory-limits-and-spilling}

| Настройка                                                                                                                         | Описание                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`max_rows_in_join`](/ru/reference/settings/session-settings/max-rows#max_rows_in_join)                                              | Ограничивает количество строк в структуре данных правой таблицы JOIN.                                                                                                                         |
| [`max_bytes_in_join`](/ru/reference/settings/session-settings/max-bytes#max_bytes_in_join)                                           | Ограничивает размер в байтах структуры данных правой таблицы JOIN.                                                                                                                            |
| [`join_overflow_mode`](/ru/reference/settings/session-settings/join#join_overflow_mode)                                              | Определяет действие при достижении JOIN предела `max_rows_in_join` или `max_bytes_in_join`.                                                                                                   |
| [`default_max_bytes_in_join`](/ru/reference/settings/session-settings/default#default_max_bytes_in_join)                             | Задаёт максимальный размер правой таблицы, если ограничение необходимо, а `max_bytes_in_join` не задан.                                                                                       |
| [`max_bytes_before_external_join`](/ru/reference/settings/session-settings/max-bytes#max_bytes_before_external_join)                 | Задаёт размер правой таблицы в байтах, при котором JOIN, основанный на хешировании, начинает сбрасывать данные на диск.                                                                       |
| [`max_bytes_ratio_before_external_join`](/ru/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_join)     | Задаёт порог сброса на диск для JOIN, основанного на хешировании, в виде доли доступной памяти.                                                                                               |
| [`enable_adaptive_memory_spill_scheduler`](/ru/reference/settings/session-settings/enable#enable_adaptive_memory_spill_scheduler)    | Включает сброс данных на диск для подходящих процессоров, в том числе JOIN с поддержкой сброса, при нехватке памяти для запроса.                                                              |
| [`legacy_join_size_limits_trigger_spilling`](/ru/reference/settings/session-settings/other#legacy_join_size_limits_trigger_spilling) | Восстанавливает прежнее поведение, при котором `max_rows_in_join` и `max_bytes_in_join` не останавливают запрос, а приводят к дальнейшему сбросу на диск части JOIN, уже хранящейся на диске. |
| [`max_bytes_before_external_sort`](/ru/reference/settings/session-settings/max-bytes#max_bytes_before_external_sort)                 | Задаёт объём используемой памяти, при котором сортировка, в том числе сортировка в JOIN `full_sorting_merge`, начинает сбрасывать данные на диск.                                             |
| [`max_bytes_ratio_before_external_sort`](/ru/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_sort)     | Задаёт долю доступной памяти, при которой сортировка, в том числе сортировка в JOIN `full_sorting_merge`, начинает сбрасывать данные на диск.                                                 |
| [`cross_join_min_rows_to_compress`](/ru/reference/settings/session-settings/cross-join#cross_join_min_rows_to_compress)              | Задаёт количество строк, при котором блок `CROSS JOIN` или блочного JOIN с вложенными циклами сжимается в памяти.                                                                             |
| [`cross_join_min_bytes_to_compress`](/ru/reference/settings/session-settings/cross-join#cross_join_min_bytes_to_compress)            | Задаёт размер в байтах, при котором блок `CROSS JOIN` или блочного JOIN с вложенными циклами сжимается в памяти.                                                                              |
| [`temporary_files_codec`](/ru/reference/settings/session-settings/temporary-files#temporary_files_codec)                             | Задаёт кодек сжатия для временных файлов, которые операции сортировки и JOIN записывают на диск.                                                                                              |

| [`max_bytes_to_transfer`](/ru/reference/settings/session-settings/max-bytes#max_bytes_to_transfer)                                                                   | Ограничивает количество несжатых байтов, которые `GLOBAL IN` или `GLOBAL JOIN` передаёт на удалённые серверы или сохраняет во временной таблице.                        |

| [`distributed_plan_join_runtime_filters`](/ru/reference/settings/session-settings/distributed-plan#distributed_plan_join_runtime_filters)                            | Передаёт фильтры JOIN времени выполнения на стадии, которые читают проверяемую сторону в плане выполнения распределённого запроса.                                      |
| [`distributed_plan_max_rows_to_broadcast`](/ru/reference/settings/session-settings/distributed-plan#distributed_plan_max_rows_to_broadcast)                          | Задаёт максимальное количество строк, при котором распределённый планировщик на основе правил использует broadcast JOIN вместо JOIN с перераспределением данных.        |
