Выберите интерфейс, который лучше всего подходит для вашего сценария работы с ClickHouse. Для разработки приложений начните с официального клиента для языка программирования или драйвера. Для интерактивной работы используйте нативный или веб-инструмент. Для прямой интеграции используйте сетевой протокол. Перед подключением при необходимости настройте [сетевые порты](/ru/concepts/features/security/network-ports), [права доступа](/ru/concepts/features/security/access-rights) и [TLS](/ru/concepts/features/security/tls/configuring-tls).
