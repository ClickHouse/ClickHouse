Консоль SQL — это встроенный веб-интерфейс для выполнения запросов и исследования данных. Она доступна на любом HTTP-порту ClickHouse по пути `/ui`, например `http://localhost:8123/ui`.

<Note>
  Консоль SQL — экспериментальная возможность.
</Note>

## Обзор {#overview}

Консоль SQL — это одностраничное приложение (SPA), которое компилируется в статический bundle и встраивается непосредственно в бинарный файл ClickHouse, аналогично тому, как ClickStack встроен по пути `/clickstack`. Все статические ресурсы отдаются самим бинарным файлом ClickHouse — сторонние CDN не используются.

Чтобы открыть консоль, перейдите по пути `/ui` на любом HTTP-порту ClickHouse (например, `http://localhost:8123/ui`).

## Как отдаётся интерфейс {#how-it-is-served}

Bundle сжимается gzip на этапе сборки и встраивается с помощью `#embed`, поэтому каждый ответ от `/ui` содержит заголовок `Content-Encoding: gzip`. Поскольку Консоль SQL — это одностраничное приложение с маршрутизацией на стороне клиента (client-side), запросы к `/ui`, которые не соответствуют встроенному статическому ресурсу и не похожи на файл (т. е. не имеют расширения), переключаются на резервный вариант: в ответ отдаётся `index.html`. Запросы к путям, похожим на отсутствующие статические ресурсы (например, `/ui/nonexistent.js`), возвращают HTTP-статус `404 Not Found`.

Путь `/ui` сопоставляется либо точно, либо если за ним следует граница `/`, `?` или `#`, поэтому соседние маршруты, такие как `/uix`, не перехватываются механизмом перехода на резервный вариант SPA.

## Связь с другими веб-интерфейсами {#relationship-to-other-web-uis}

В состав ClickHouse входит несколько встроенных веб-интерфейсов, доступных через HTTP-порт:

* [`/play`](/ru/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql) — легковесный веб-интерфейс SQL.
* `/dashboard` — встроенные панели мониторинга.
* `/clickstack` — встроенный интерфейс ClickStack.
* `/ui` — Консоль SQL, описанная в этом разделе.

Ссылки на все эти интерфейсы есть на стартовой странице HTTP-сервера ClickHouse.

## Аутентификация {#authentication}

Консоль SQL проходит аутентификацию с использованием того же объекта `Session` и тех же проверок контроля доступа, что и HTTP-протокол. Для отдачи статических ресурсов интерфейса по адресу `/ui` аутентификация не требуется; запросы, отправляемые из интерфейса, аутентифицируются так же, как и любой другой HTTP-запрос.
