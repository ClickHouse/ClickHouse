Веб-интерфейс SQL (Play) — это встроенный браузерный интерфейс ClickHouse для выполнения запросов. Он доступен на любом HTTP-порту ClickHouse по пути `/play` (например, `http://localhost:8123/play`). В нём можно писать и выполнять запросы, просматривать результаты в виде таблицы или чарта, а также делиться запросом, скопировав его URL.

Весь интерфейс содержится в файле `programs/server/play.html` — единственной автономной странице, которую отдаёт непосредственно бинарный файл ClickHouse, без каких-либо фреймворков и этапа сборки. Исключение составляет лишь отрисовка чартов: библиотека `uPlot` для построения графиков подгружается по требованию со стороннего CDN при первом отображении результата в виде чарта, поэтому в развертываниях без доступа к интернету или с ограничениями на исходящий трафик чарты недоступны.

## Вкладки запросов {#query-tabs}

Вкладки позволяют держать несколько запросов под рукой одновременно, не жонглируя ими в одном редакторе и не полагаясь на историю браузера.

У каждой вкладки свои текст запроса, заголовок, параметры запроса и последний результат. Настройки соединения (URL, пользователь, пароль) остаются глобальными и общими для всех вкладок.

### Когда появляется панель вкладок {#when-the-tab-bar-appears}

Панель вкладок появляется после выполнения запроса или когда открыто больше одной вкладки. Единственная вкладка без результата выглядит точно так же, как страница до появления вкладок, поэтому панель вкладок не отображается, пока она вам не понадобится.

Активная вкладка визуально сливается со страницей: её фон повторяет цвет, вычисляемый по хешу запроса (тот же цвет, что уже используется для фона страницы), с градиентом, который в светлой теме насыщеннее вверху, а в тёмной — ярче. Неактивные вкладки окрашиваются в цвет, вычисляемый по хешу их собственного текста запроса, поэтому разные вкладки автоматически различаются по цвету.

### Создание, закрытие и переименование вкладок {#creating-closing-and-renaming-tabs}

* Чтобы создать новую вкладку, нажмите кнопку `[+]` справа от вкладок.
* Чтобы закрыть вкладку, нажмите на ней значок `x`.
* Новым вкладкам по умолчанию присваиваются имена `Query A`, `Query B` и т. д.
* Чтобы переименовать активную вкладку, щёлкните её заголовок и измените его прямо на месте; поле редактирования автоматически расширяется под длину текста.

### Переключение вкладок {#switching-tabs}

* Чтобы переключиться на неактивную вкладку, щёлкните по ней.
* Переключать вкладки можно также колесом мыши, наведя курсор на панель вкладок: прокрутка вверх переключает на вкладку слева, прокрутка вниз — на вкладку справа (если они есть). Поддерживается как вертикальная, так и горизонтальная прокрутка колесом.

Панель вкладок закреплена по горизонтали: при горизонтальной прокрутке страницы она остаётся у левого края, как и логотип ClickHouse внизу, а при вертикальной прокрутке уходит из видимой области вместе с остальным содержимым страницы.

### Сохранение данных и история браузера {#persistence-and-browser-history}

Рабочее пространство — вкладки, их заголовки, активная вкладка, порядок вкладок и небольшие снимки результатов — сохраняется в IndexedDB и восстанавливается при перезагрузке страницы. Сохранение данных выполняется по возможности: если IndexedDB недоступен, рабочее пространство хранит состояние в оперативной памяти только в пределах текущего сеанса.

Вкладки также интегрированы с History API браузера и с URL:

* В состоянии истории хранится активная вкладка, поэтому кнопки браузера «Назад» и «Вперёд» переключают вкладки.
* В URL добавляется параметр `tab=<name>`. При загрузке запрос и параметр `tab` из URL сверяются с сохранёнными вкладками: если вкладка с таким именем уже существует, используется она (а её запрос заменяется); если имя не найдено или не было задано, создаётся новая вкладка. Благодаря этому можно открыть URL с новым запросом, не потеряв собственные сохранённые вкладки.

## Режим блокнота {#notebook-mode}

Вкладку можно превратить в блокнот — упорядоченную последовательность ячеек с запросами и текстом, — добавив
ячейку кнопкой `[+]`, которая появляется под результатом. Режим блокнота включается для каждой вкладки отдельно. См.
[Режим блокнота в веб-интерфейсе](/ru/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook).

### Ограничения {#limitations}

Запрос продолжает выполняться, когда вы переключаетесь на другую вкладку. Индикаторы хода выполнения и потребления ресурсов продолжают
накапливать значения в фоне, а при повторном открытии вкладки она снова подхватывает это текущее состояние, поэтому индикаторы
продолжают отсчёт с текущих значений, а не начинают его заново почти с нуля. Закрытие вкладки, а также переход
назад или вперёд к другой записи истории останавливают запрос.

Для восстановления сохраняются снимки только небольших результатов. Большой результат (превышающий лимит размера снимка) или результат в виде изображения не сохраняется: после переключения вкладок или перезагрузки во вкладке остаётся запрос, но не отображённый результат; чтобы получить его снова, выполните запрос повторно. Это относится как к результатам отдельных запросов, так и к объединённому выводу при выполнении «Run all» (несколько запросов).
