[Model Context Protocol](https://www.anthropic.com/news/model-context-protocol) (MCP) — это открытый стандарт, который позволяет ИИ-ассистентам подключаться к внешним системам.
Он предоставляет моделям единый интерфейс для доступа к источникам данных, API, базам данных и инструментам, избавляя от необходимости создавать отдельную интеграцию для каждой пары «модель — сервис».

ИИ-приложению достаточно один раз реализовать MCP, чтобы подключаться к любому совместимому серверу.
Аналогичным образом MCP-сервер может предоставлять свои возможности любому совместимому клиенту.

## Архитектура {#architecture}

MCP использует клиент-серверную архитектуру:

* MCP-клиенты, такие как Claude Desktop, Cursor или VS Code, устанавливают соединения с MCP-серверами.
* MCP-серверы предоставляют инструменты и возможности через стандартизированный интерфейс.
* ИИ-модели при необходимости используют эти инструменты для доступа к внешним данным и функциональности.

## MCP-сервер ClickHouse {#clickhouse-mcp-server}

[MCP-сервер ClickHouse](https://github.com/ClickHouse/mcp-clickhouse) позволяет ИИ-ассистенту обнаруживать базы данных и таблицы, просматривать схемы и выполнять SQL-запросы к кластеру ClickHouse.
Набор инструментов, предоставляемых сервером, может различаться в зависимости от версии, поэтому названия инструментов, используемых в примерах, уточняйте в соответствующем руководстве по интеграции.

По умолчанию сервер разрешает только запросы на чтение.
Используйте отдельного пользователя ClickHouse только с теми разрешениями, которые необходимы ассистенту.

О подключении локального MCP-клиента см. раздел [Настройка MCP-сервера ClickHouse](/ru/guides/use-cases/ai-ml/MCP/claude-desktop).
Об управляемом удалённом сервере см. раздел [Удалённый сервер MCP в ClickHouse Cloud](/ru/products/cloud/features/ai-ml/remote-mcp).
