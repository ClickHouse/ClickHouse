ClickHouse предоставляет собственные метрики в текстовом формате Prometheus на выделенном порту, чтобы сервер Prometheus мог их собирать.

Если вам нужно хранить метрики Prometheus в ClickHouse и выполнять запросы к ним с помощью PromQL, см. раздел [HTTP API Prometheus и PromQL](/ru/concepts/features/connect-to-clickhouse/prometheus).

<Note>
  Если вы используете ClickHouse Cloud, метрики можно сделать доступными для Prometheus с помощью [интеграции с Prometheus](/ru/products/cloud/features/monitoring/prometheus).
</Note>

## Настройка порта для метрик {#configure-the-metrics-port}

Настройте выделенный порт, если серверу Prometheus требуется собирать собственные метрики ClickHouse:

```xml
<prometheus>
    <port>9363</port>
    <endpoint>/metrics</endpoint>
    <metrics>true</metrics>
    <asynchronous_metrics>true</asynchronous_metrics>
    <events>true</events>
    <errors>true</errors>
    <histograms>true</histograms>
    <dimensional_metrics>true</dimensional_metrics>
</prometheus>
```

## Настройка расширенных обработчиков {#configure-extended-handlers}

Раздел `<prometheus.handlers>` позволяет создавать расширенные обработчики на том же порту.
Этот раздел аналогичен [`<http_handlers>`](/ru/concepts/features/connect-to-clickhouse/protocols/http), но предназначен для протоколов prometheus:

```xml
<prometheus>
    <port>9363</port>
    <handlers>
        <my_rule_1>
            <url>/metrics</url>
            <handler>
                <type>expose_metrics</type>
                <metrics>true</metrics>
                <asynchronous_metrics>true</asynchronous_metrics>
                <events>true</events>
                <errors>true</errors>
                <histograms>true</histograms>
                <dimensional_metrics>true</dimensional_metrics>
                <labels>
                    <environment>production</environment>
                    <shard from_env="SHARD_NAME"></shard>
                </labels>
            </handler>
        </my_rule_1>
    </handlers>
</prometheus>
```

## Настройки {#settings}

Подробное описание этих настроек см. в [разделе Prometheus](/ru/reference/settings/server-settings/settings/other#prometheus) справочника настроек сервера.

| `port`                       | none         | Порт, через который предоставляются метрики ClickHouse.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `endpoint`                   | `/metrics`   | Конечная точка HTTP для сбора метрик. Начинается с `/`. Не следует использовать вместе с разделом `<handlers>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `url` / `headers` / `method` | none         | Фильтры для поиска обработчика, соответствующего запросу. Аналогичны одноимённым полям в разделе [`<http_handlers>`](/ru/concepts/features/connect-to-clickhouse/protocols/http).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `info`                       | true         | Предоставляет метрику типа gauge `ClickHouse_Info` с метками, идентифицирующими сервер (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `metrics`                    | true         | Предоставляет метрики из [`system.metrics`](/ru/reference/system-tables/metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `asynchronous_metrics`       | true         | Предоставляет метрики из [`system.asynchronous_metrics`](/ru/reference/system-tables/asynchronous_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `events`                     | true         | Предоставляет метрики из [`system.events`](/ru/reference/system-tables/events).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `errors`                     | true         | Предоставляет число ошибок из [`system.errors`](/ru/reference/system-tables/errors).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `histograms`                 | true         | Предоставляет метрики из [`system.histogram_metrics`](/ru/reference/system-tables/histogram_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `dimensional_metrics`        | true         | Предоставляет метрики из [`system.dimensional_metrics`](/ru/reference/system-tables/dimensional_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `labels`                     | none         | Постоянные метки, добавляемые к каждой предоставляемой метрике. Каждый дочерний элемент определяет одну метку: имя элемента задаёт имя метки (которое должно соответствовать шаблону `[a-zA-Z_][a-zA-Z0-9_]*`), а значение элемента — значение метки. В значениях меток поддерживаются стандартные подстановки конфигурации, например с помощью атрибута `from_env`. Имя метки отклоняется, если оно начинается с `__` (этот префикс зарезервирован Prometheus) или совпадает с именем метки, которую эта конечная точка уже выводит для одного из включённых разделов. Таким образом, набор зарезервированных имён зависит от того, какие данные экспортирует конечная точка: `le`, если включён `histograms`; метки `ClickHouse_Info` (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`), если включён `info`; а также все метки, используемые экспортируемыми семействами гистограмм или многомерных метрик (например, `group`, `direction` или `operation_type`), если включён `histograms` или `dimensional_metrics`. Поскольку набор зависит от фактически экспортируемых данных, одно и то же имя может быть допустимым для одной конечной точки и отклоняться для другой. |

## Проверьте конечную точку {#check-the-endpoint}

```bash
curl http://127.0.0.1:9363/metrics
```
