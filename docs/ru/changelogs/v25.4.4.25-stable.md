<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#79981](https://github.com/ClickHouse/ClickHouse/issues/79981): Исправлена десериализация дискриминаторов Variant в базовом формате в компактных частях. Проблема появилась в [https://github.com/ClickHouse/ClickHouse/pull/55518](https://github.com/ClickHouse/ClickHouse/pull/55518). [#79000](https://github.com/ClickHouse/ClickHouse/pull/79000) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#79715](https://github.com/ClickHouse/ClickHouse/issues/79715): Исправлено использование некорректных путей при переименовании базы данных Atomic. [#79569](https://github.com/ClickHouse/ClickHouse/pull/79569) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Бэкпортировано в [#80049](https://github.com/ClickHouse/ClickHouse/issues/80049): Исправлен результат SQL-функции `formatDateTime`, если за форматтером переменной длины (например, `%W`, то есть день недели `Monday`, `Tuesday` и т. д.) следует составной форматтер (форматтер, который выводит сразу несколько компонентов, например `%D`, то есть американскую дату `05/04/25`). [#79835](https://github.com/ClickHouse/ClickHouse/pull/79835) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#80113](https://github.com/ClickHouse/ClickHouse/issues/80113): IcebergS3 поддерживает оптимизацию для count, а IcebergS3Cluster — нет. В результате значение count(), возвращаемое в режиме кластера, может быть кратно числу реплик. [#79844](https://github.com/ClickHouse/ClickHouse/pull/79844) ([wxybear](https://github.com/wxybear)).
* Бэкпортировано в [#80078](https://github.com/ClickHouse/ClickHouse/issues/80078): Исправлена работа materialized views с UNION на новых репликах. [#80037](https://github.com/ClickHouse/ClickHouse/pull/80037) ([Samay Sharma](https://github.com/samay-sharma)).
* Бэкпортировано в [#80185](https://github.com/ClickHouse/ClickHouse/issues/80185): Исправлены предупреждения `Cannot find 'kernel' in '[...]/memory.stat'` в журнале ClickHouse (issue [#77410](https://github.com/ClickHouse/ClickHouse/issues/77410)). [#80129](https://github.com/ClickHouse/ClickHouse/pull/80129) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="not-for-changelog-insignificant">
  #### НЕ ДЛЯ ИЗМЕНЕНИЯ / НЕЗНАЧИТЕЛЬНО
</div>

* Бэкпортировано в [#79811](https://github.com/ClickHouse/ClickHouse/issues/79811): Улучшена интроспекция производительности при анализе индексов. [#79347](https://github.com/ClickHouse/ClickHouse/pull/79347) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#80222](https://github.com/ClickHouse/ClickHouse/issues/80222): `test_check_replicated_does_not_block_shutdown` сделан менее подверженным сбоям и более быстрым. [#79552](https://github.com/ClickHouse/ClickHouse/pull/79552) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#80099](https://github.com/ClickHouse/ClickHouse/issues/80099): `enable_user_name_access_type` не должен влиять на тип доступа `DEFINER`. [#80026](https://github.com/ClickHouse/ClickHouse/pull/80026) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#80202](https://github.com/ClickHouse/ClickHouse/issues/80202): Отключены проверки перегрузки CPU для всех тестов. [#80166](https://github.com/ClickHouse/ClickHouse/pull/80166) ([Alexander Gololobov](https://github.com/davenger)).
* Бэкпортировано в [#80230](https://github.com/ClickHouse/ClickHouse/issues/80230): По умолчанию отключена проверка перегрузки CPU в настройках сервера. [#80211](https://github.com/ClickHouse/ClickHouse/pull/80211) ([Alexander Gololobov](https://github.com/davenger)).
