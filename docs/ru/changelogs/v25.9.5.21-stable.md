<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#88511](https://github.com/ClickHouse/ClickHouse/issues/88511): исправлено чтение null-подстолбца `map` из типов `Variant`, которые не могут находиться внутри `Nullable`. [#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#88734](https://github.com/ClickHouse/ClickHouse/issues/88734): исключение `Poco::TimeoutException`, выбрасываемое из `Poco::Net::HTTPChunkedStreamBuf::readFromDevice`, приводит к аварийному завершению с SIGABRT. [#88668](https://github.com/ClickHouse/ClickHouse/pull/88668) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпортировано в [#88908](https://github.com/ClickHouse/ClickHouse/issues/88908): после восстановления реплика базы данных Replicated может надолго зависнуть, выводя сообщения вида `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)`; это исправлено. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#88892](https://github.com/ClickHouse/ClickHouse/issues/88892): исправлена проверка доступа для select к табличной функции `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#88942](https://github.com/ClickHouse/ClickHouse/issues/88942): исправлена ошибка в функции `reverseUTF8`. В предыдущих версиях она по ошибке разворачивала байты UTF-8 кодовых точек длиной 4. Это закрывает [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#88978](https://github.com/ClickHouse/ClickHouse/issues/88978): исключена проверка доступа `SET DEFINER <current_user>:definer` при создании представления с `SQL SECURITY DEFINER`. [#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#89083](https://github.com/ClickHouse/ClickHouse/issues/89083): это закрывает [#88081](https://github.com/ClickHouse/ClickHouse/issues/88081). [#88988](https://github.com/ClickHouse/ClickHouse/pull/88988) ([scanhex12](https://github.com/scanhex12)).
* Бэкпортировано в [#89026](https://github.com/ClickHouse/ClickHouse/issues/89026): исправлена деградация производительности при анализе индексов пропуска данных. [#89004](https://github.com/ClickHouse/ClickHouse/pull/89004) ([Anton Popov](https://github.com/CurtizJ)).
