<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#98402](https://github.com/ClickHouse/ClickHouse/issues/98402): табличная функция `loop` вызывала `inner_storage->read()` напрямую, в обход слоя интерпретатора, где применяются политики на уровне строк, привилегии на уровне столбца и другие проверки безопасности. Это позволяло пользователю, ограниченному политиками на уровне строк, читать все строки через `loop(table)`, даже если прямой SELECT возвращал ноль строк. [#97682](https://github.com/ClickHouse/ClickHouse/pull/97682) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#98310](https://github.com/ClickHouse/ClickHouse/issues/98310): исправлен некорректный результат запросов с FINAL при одновременном использовании индексов пропуска данных по первичному ключу и не по первичному ключу. [#98097](https://github.com/ClickHouse/ClickHouse/pull/98097) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#98352](https://github.com/ClickHouse/ClickHouse/issues/98352): для ответов watch в `aggregated_zookeeper_log` теперь устанавливается компонент `Watch` вместо того, чтобы оставлять его пустым. [#98202](https://github.com/ClickHouse/ClickHouse/pull/98202) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#98326](https://github.com/ClickHouse/ClickHouse/issues/98326): исправлен выход за границы массива в `ColumnConst::getExtremes`, который мог вызывать сбой при включенном `extremes = 1`. [#98263](https://github.com/ClickHouse/ClickHouse/pull/98263) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#98388](https://github.com/ClickHouse/ClickHouse/issues/98388): исправлено исключение LOGICAL&#95;ERROR &quot;Invalid binary search result in `MergeTreeSetIndex`&quot;, возникавшее при преобразовании `toDate` для столбцов ключа, содержащих данные, пересекающие границу 65535. [#98276](https://github.com/ClickHouse/ClickHouse/pull/98276) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
