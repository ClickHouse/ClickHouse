<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпортировано в [#100900](https://github.com/ClickHouse/ClickHouse/issues/100900): Добавлена сериализация Map по бакетам для столбцов типа Map в MergeTree (`map_serialization_version = 'with_buckets'`). Ключи разбиваются по хешу на бакеты, поэтому при чтении одного ключа (`m['key']`) считывается только один бакет, а не весь столбец, что даёт ускорение в 2–49 раз для обращений по одному ключу в зависимости от размера Map. Количество бакетов и стратегию разбиения по бакетам можно задавать с помощью новых настроек MergeTree: `map_serialization_version`, `max_buckets_in_map`, `map_buckets_strategy`, `map_buckets_coefficient` и `map_buckets_min_avg_size`. Настройка `map_serialization_version_for_zero_level_parts` позволяет сохранять базовую сериализацию для вставок, чтобы избежать дополнительных накладных расходов при записи, тогда как слитые части используют бакеты. Для `mapKeys/mapValues` поддерживаются индексы пропуска данных при сериализации Map по бакетам. Преобразование `optimize_functions_to_subcolumns` переписывает `m['key']` в чтение подстолбца для конкретного ключа при наличии бакетов. [#99200](https://github.com/ClickHouse/ClickHouse/pull/99200) ([Pavel Kruglov](https://github.com/Avogar)).

* Бэкпортировано в [#100866](https://github.com/ClickHouse/ClickHouse/issues/100866): исправлены combinators агрегатных функций `If`, `Distinct`, `DistinctIf`, `IfState ` с типом возвращаемого значения `Tuple` и одним или несколькими аргументами `Nullable`, из-за которых после появления `Nullable(Tuple)` было невозможно читать ранее сериализованные состояния. Закрывает [#98917](https://github.com/ClickHouse/ClickHouse/issues/98917). [#100826](https://github.com/ClickHouse/ClickHouse/pull/100826) ([Nihal Z. Miaji](https://github.com/nihalzp)).
