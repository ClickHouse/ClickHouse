<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#88220](https://github.com/ClickHouse/ClickHouse/issues/88220): исправлен сбой, при котором некоторые корректные пользовательские данные, записанные в столбец `AggregateFunction(quantileDD)`, могли вызывать бесконечную рекурсию во время слияний. [#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* Бэкпортировано в [#88598](https://github.com/ClickHouse/ClickHouse/issues/88598): исправлено определение схемы таблицы для табличной функции `url()`, когда настройка `parallel_replicas_for_cluster_functions` установлена в 1. [#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#88647](https://github.com/ClickHouse/ClickHouse/issues/88647): в больших кластерах с номерами узлов &gt; 10 высока вероятность сбоя при восстановлении с ошибкой `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again`. Узел `num_hosts` одновременно перезаписывается множеством хостов. Исправление делает настройку, управляющую количеством попыток, динамической. Закрывает [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721). [#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#88712](https://github.com/ClickHouse/ClickHouse/issues/88712): исправлен потенциальный сбой, вызванный одновременной мутацией базовых const-столбцов PREWHERE. [#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#88902](https://github.com/ClickHouse/ClickHouse/issues/88902): после восстановления реплика базы данных Replicated могла надолго зависать, выводя сообщения вида `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)`; это исправлено. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#88886](https://github.com/ClickHouse/ClickHouse/issues/88886): исправлена проверка прав доступа для select в табличной функции `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#89033](https://github.com/ClickHouse/ClickHouse/issues/89033): исправлена ошибка в функции `reverseUTF8`. В предыдущих версиях она ошибочно переворачивала байты кодовых точек UTF-8 длиной 4. Это закрывает [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
