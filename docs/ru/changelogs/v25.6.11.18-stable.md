* Бэкпортировано в [#86517](https://github.com/ClickHouse/ClickHouse/issues/86517): Исправлена логическая ошибка при динамическом изменении размера файлового кэша. Закрывает [#86122](https://github.com/ClickHouse/ClickHouse/issues/86122). [#86130](https://github.com/ClickHouse/ClickHouse/pull/86130) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#86945](https://github.com/ClickHouse/ClickHouse/issues/86945): Исправлен CAST из LowCardinality(Nullable(T)) в Dynamic. [#86365](https://github.com/ClickHouse/ClickHouse/pull/86365) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#86851](https://github.com/ClickHouse/ClickHouse/issues/86851): Исправлена ошибка `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` при чтении пустых blob-объектов из Azure Blob Storage для диска plain&#95;rewritable. [#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#86890](https://github.com/ClickHouse/ClickHouse/issues/86890): Исправлено отсутствие заголовка фрагмента, когда включен send&#95;chunk&#95;header и UDF вызывается через HTTP-протокол. * Бэкпортировано в [#86870](https://github.com/ClickHouse/ClickHouse/issues/86870): Исправлена логическая ошибка S3Queue &quot;Expected current processor {} to be equal to {}&quot;, возникавшая из-за истечения сеанса Keeper. * Бэкпортировано в [#86975](https://github.com/ClickHouse/ClickHouse/issues/86975): Исправлена проблема, из-за которой таблица с движком TimeSeries препятствовала созданию новой реплики в базе данных Replicated. * Бэкпортировано в [#86859](https://github.com/ClickHouse/ClickHouse/issues/86859): Исправлено выполнение запроса к `system.distributed_ddl_queue` в случаях, когда у задач отсутствуют определенные узлы Keeper.
