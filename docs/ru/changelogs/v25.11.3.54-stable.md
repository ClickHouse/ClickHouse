<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#91411](https://github.com/ClickHouse/ClickHouse/issues/91411): настройка `allow_statistics_optimize` теперь включена по умолчанию, поэтому оптимизатор JOIN будет использовать статистику столбцов. [#89332](https://github.com/ClickHouse/ClickHouse/pull/89332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#92303](https://github.com/ClickHouse/ClickHouse/issues/92303): разрешено неявное преобразование типов при приведении `Array` к `QBit`. Массивы целых чисел и чисел с плавающей точкой теперь можно напрямую вставлять в столбцы `QBit` без явного приведения типов. [#91846](https://github.com/ClickHouse/ClickHouse/pull/91846) ([Raufs Dunamalijevs](https://github.com/rienath)).
