<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпорт в [#86620](https://github.com/ClickHouse/ClickHouse/issues/86620): добавлена системная таблица `iceberg_metadata_log` для получения файлов метаданных Iceberg при выполнении операторов SELECT. [#86152](https://github.com/ClickHouse/ClickHouse/pull/86152) ([Konstantin Vedernikov](https://github.com/scanhex12)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпорт в [#86333](https://github.com/ClickHouse/ClickHouse/issues/86333): добавлен `allow_experimental_delta_lake_writes`. [#86180](https://github.com/ClickHouse/ClickHouse/pull/86180) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпорт в [#86493](https://github.com/ClickHouse/ClickHouse/issues/86493): добавлена возможность включать JSON-логирование только для определённого канала; для этого установите `logger.formatting.channel` в одно из значений `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпорт в [#86614](https://github.com/ClickHouse/ClickHouse/issues/86614): таблицы теперь корректно завершаются при восстановлении реплики базы данных. Некорректное завершение приводило к LOGICAL&#95;ERROR для некоторых движков таблиц во время восстановления реплики базы данных. [#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпорт в [#86386](https://github.com/ClickHouse/ClickHouse/issues/86386): при создании дисков из SQL теперь по умолчанию обрабатываются include&#39;ы из `/etc/metrika.xml`. [#86232](https://github.com/ClickHouse/ClickHouse/pull/86232) ([alekar](https://github.com/alekar)).
* Бэкпорт в [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653): исправлена ошибка `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` при чтении пустых blob-объектов из Azure Blob Storage для диска plain&#95;rewritable. [#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпорт в [#86457](https://github.com/ClickHouse/ClickHouse/issues/86457): исправлена ошибка в Materialized Views: MV могла не работать, если её создавали, удаляли, а затем снова создавали с тем же именем. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпорт в [#86468](https://github.com/ClickHouse/ClickHouse/issues/86468): исправлена утечка `MergesMutationsMemoryTracking` из-за таблиц `Buffer`, а также исправлен `query_views_log` для стриминга из `Kafka` (и других источников). [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпорт в [#86549](https://github.com/ClickHouse/ClickHouse/issues/86549): исправлено использование неинициализированной памяти в getSubcolumnType. [#86498](https://github.com/ClickHouse/ClickHouse/pull/86498) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпорт в [#86582](https://github.com/ClickHouse/ClickHouse/issues/86582): исключения при сбросе лога во время завершения работы теперь игнорируются, а сама процедура завершения стала безопаснее (чтобы избежать SIGSEGV). [#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
