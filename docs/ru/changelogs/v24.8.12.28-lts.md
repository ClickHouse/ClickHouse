<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпортировано в [#74316](https://github.com/ClickHouse/ClickHouse/issues/74316): когда `min_age_to_force_merge_seconds` и `min_age_to_force_merge_on_partition_only` одновременно включены, слияние частей игнорирует ограничение на максимальный размер в байтах. [#73656](https://github.com/ClickHouse/ClickHouse/pull/73656) ([Kai Zhu](https://github.com/nauu)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#74222](https://github.com/ClickHouse/ClickHouse/issues/74222): Устранена пауза после `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE`. Исправлено получение корректных настроек для планирования фоновых задач. [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Бэкпортировано в [#73889](https://github.com/ClickHouse/ClickHouse/issues/73889): Исправлена подготовка к squashing для столбца типа Dynamic и JSON-столбцов. Ранее в некоторых случаях новые типы могли вставляться в shared variant/общие данные, даже если лимит по типам/paths еще не был достигнут. [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#74435](https://github.com/ClickHouse/ClickHouse/issues/74435): Исправлен segfault, возникавший, когда источник словаря содержал функцию с некорректными данными. [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Бэкпортировано в [#74139](https://github.com/ClickHouse/ClickHouse/issues/74139): Исправлена возможная несогласованность данных в столбце типа Dynamic. Также исправлена возможная logical error `Nested columns sizes are inconsistent with local_discriminators column size`. [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#74527](https://github.com/ClickHouse/ClickHouse/issues/74527): Исправлен `NOT_FOUND_COLUMN_IN_BLOCK` в запросах с `FINAL` и `SAMPLE`. Исправлен некорректный результат в SELECT-запросах с `FINAL` из `CollapsingMergeTree`, а также включены оптимизации `FINAL`. [#73682](https://github.com/ClickHouse/ClickHouse/pull/73682) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#74138](https://github.com/ClickHouse/ClickHouse/issues/74138): Исправлена десериализация структуры Dynamic/Object. Это могло приводить к исключениям CANNOT&#95;READ&#95;ALL&#95;DATA. [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#74111](https://github.com/ClickHouse/ClickHouse/issues/74111): Исправлено [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078) (была нарушена поддержка S3 Express). [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* Бэкпортировано в [#74104](https://github.com/ClickHouse/ClickHouse/issues/74104): Диск, использующий метаданные plain&#95;rewritable, может совместно использоваться несколькими экземплярами сервера. Ожидается, что один экземпляр может читать объект метаданных, пока другой его изменяет. Ошибки object not found игнорируются при инициализации plain&#95;rewritable с хранилищем Azure — аналогично поведению, реализованному для S3. [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#74152](https://github.com/ClickHouse/ClickHouse/issues/74152): Исправлен случай, когда пользователь указывает именованные аргументы в движке таблицы Kafka. [#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Бэкпортировано в [#74173](https://github.com/ClickHouse/ClickHouse/issues/74173): Исправлен сбой при чтении подстолбца из сжатой таблицы с движком Memory. Исправлено [#74009](https://github.com/ClickHouse/ClickHouse/issues/74009). [#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat)).
