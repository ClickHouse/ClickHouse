<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#85306](https://github.com/ClickHouse/ClickHouse/issues/85306): исправлено отсутствие проверки TTL-столбцов в ключах сортировки для ALTER MODIFY ORDER BY. Теперь при операциях ALTER использование TTL-столбцов в предложениях ORDER BY корректно отклоняется, что предотвращает возможное повреждение таблицы. [#84536](https://github.com/ClickHouse/ClickHouse/pull/84536) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* Бэкпортировано в [#85381](https://github.com/ClickHouse/ClickHouse/issues/85381): исправлена очистка патч-частей в `ReplicatedMergeTree`. Ранее результат легковесного обновления мог временно не отображаться на реплике, пока с другой реплики не будет загружена слитая или мутированная часть, материализующая патч-части. [#85121](https://github.com/ClickHouse/ClickHouse/pull/85121) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#85246](https://github.com/ClickHouse/ClickHouse/issues/85246): исправлен `illegal_type_of_argument` в MV, когда типы различаются. [#85135](https://github.com/ClickHouse/ClickHouse/pull/85135) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#85236](https://github.com/ClickHouse/ClickHouse/issues/85236): исправлена ошибка `Not-ready Set` для `IN (subquery)` внутри настройки `additional_table_filters expression`. [#85210](https://github.com/ClickHouse/ClickHouse/pull/85210) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#85264](https://github.com/ClickHouse/ClickHouse/issues/85264): устранены лишние вызовы `getStatus()` при выполнении запросов SYSTEM DROP REPLICA. Исправлен случай, когда таблица удаляется в фоновом режиме и генерируется исключение `Shutdown for storage is called`. [#85220](https://github.com/ClickHouse/ClickHouse/pull/85220) ([Nikolay Degterinsky](https://github.com/evillique)).
