<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#90983](https://github.com/ClickHouse/ClickHouse/issues/90983): Из-за [https://github.com/ClickHouse/ClickHouse/pull/90311](https://github.com/ClickHouse/ClickHouse/pull/90311) формат статистики изменился, и при наличии статистики в старом формате сервер может аварийно завершиться. Этот PR устраняет сбой и будет генерировать исключение, если существующая статистика использует устаревший формат. Чтобы избежать исключения, следует выполнить `ALTER TABLE [db.]table MATERIALIZE STATISTICS ALL` для повторной генерации статистики&#96; и устранения проблемы. [#90904](https://github.com/ClickHouse/ClickHouse/pull/90904) ([Han Fei](https://github.com/hanfei1991)).
* Бэкпортировано в [#91193](https://github.com/ClickHouse/ClickHouse/issues/91193): Теперь при достижении `hard_limit` для HTTP-соединений клиентов будет генерироваться исключение `HTTP_CONNECTION_LIMIT_REACHED`. Для соединений с дисками это значение установлено в `20000`. [#91016](https://github.com/ClickHouse/ClickHouse/pull/91016) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#91254](https://github.com/ClickHouse/ClickHouse/issues/91254): Исправлено возможное голодание пула потоков при чтении образцов столбцов для JSON-столбцов с большим количеством подстолбцов: теперь учитывается настройка `merge_tree_use_prefixes_deserialization_thread_pool`, а не безусловно используется пул потоков. [#91208](https://github.com/ClickHouse/ClickHouse/pull/91208) ([Raufs Dunamalijevs](https://github.com/rienath)).
