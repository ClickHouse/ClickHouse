<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Бэкпортировано в [#80822](https://github.com/ClickHouse/ClickHouse/issues/80822): исправлен `bitNot()` для String, чтобы функция возвращала строку с нулевым терминатором. [#80791](https://github.com/ClickHouse/ClickHouse/pull/80791) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#80769](https://github.com/ClickHouse/ClickHouse/issues/80769): скорректированы значения совместимости для max&#95;merge&#95;delayed&#95;streams&#95;for&#95;parallel&#95;write. [#80760](https://github.com/ClickHouse/ClickHouse/pull/80760) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#81228](https://github.com/ClickHouse/ClickHouse/issues/81228): libarchive обновлён до версии 3.7.9 для устранения следующих уязвимостей: CVE-2024-20696 CVE-2025-25724 CVE-2024-48958 CVE-2024-57970 CVE-2025-1632 CVE-2024-48957 CVE-2024-48615. [#81174](https://github.com/ClickHouse/ClickHouse/pull/81174) ([larryluogit](https://github.com/larryluogit)).
* Бэкпортировано в [#81315](https://github.com/ClickHouse/ClickHouse/issues/81315): MemoryResidentWithoutPageCache отражает объём физической памяти, используемой серверным процессом, в байтах, без учёта кэша страниц в пространстве пользователя. Это даёт более точное представление о фактическом использовании памяти, когда задействован кэш страниц в пространстве пользователя. Если кэш страниц в пространстве пользователя отключён, это значение равно MemoryResident. [#81233](https://github.com/ClickHouse/ClickHouse/pull/81233) ([Jayme Bird](https://github.com/jaymebrd)).
