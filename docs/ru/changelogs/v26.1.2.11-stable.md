<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#95646](https://github.com/ClickHouse/ClickHouse/issues/95646): исправлено некорректное отсечение по первичному ключу и индексу пропуска данных для предикатов с `toWeek`, `toYearWeek`, `toStartOfWeek`, `toLastDayOfWeek` и `toDayOfWeek`, а также исправлены исключения в некоторых из этих функций для корректных запросов с `LowCardinality(String)`. [#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Бэкпортировано в [#95634](https://github.com/ClickHouse/ClickHouse/issues/95634): исправлен сбой при запуске `ReplicatedMergeTree`, вызванный одновременным удалением каталогов `delete_tmp_*`. [#94892](https://github.com/ClickHouse/ClickHouse/pull/94892) ([myeongjun](https://github.com/myeongjjun)).
* Бэкпортировано в [#95429](https://github.com/ClickHouse/ClickHouse/issues/95429): преобразование столбца теперь выполняется только один раз при получении содержимого списка и файлов `.avro` manifest. [#95164](https://github.com/ClickHouse/ClickHouse/pull/95164) ([Daniil Ivanik](https://github.com/divanik)).
* Бэкпортировано в [#95620](https://github.com/ClickHouse/ClickHouse/issues/95620): исправлена ошибка фильтра `prewhere`, вызванная lambda-выражениями в `prewhere`. [#95395](https://github.com/ClickHouse/ClickHouse/pull/95395) ([Xiaozhe Yu](https://github.com/wudidapaopao)).
* Бэкпортировано в [#95610](https://github.com/ClickHouse/ClickHouse/issues/95610): предотвращён возможный сбой в распределённых запросах при отмене. [#95466](https://github.com/ClickHouse/ClickHouse/pull/95466) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* Бэкпортировано в [#95699](https://github.com/ClickHouse/ClickHouse/issues/95699): исправлена логическая ошибка `There was an error: Cannot obtain error message`, возникавшая при одновременном ожидании распределённого DDL и удалении базы данных Replicated. Исправляет [#95539](https://github.com/ClickHouse/ClickHouse/issues/95539). [#95664](https://github.com/ClickHouse/ClickHouse/pull/95664) ([Alexander Tokmakov](https://github.com/tavplubix)).
