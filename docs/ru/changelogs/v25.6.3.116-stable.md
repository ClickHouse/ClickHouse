* Бэкпортировано в [#83343](https://github.com/ClickHouse/ClickHouse/issues/83343): немного ускорен QueryTreeHash. [#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#83207](https://github.com/ClickHouse/ClickHouse/issues/83207): разрешён ALTER UPDATE для столбцов JSON и типа Dynamic. [#82419](https://github.com/ClickHouse/ClickHouse/pull/82419) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#83015](https://github.com/ClickHouse/ClickHouse/issues/83015): улучшение Keeper: перемещение файлов changelog между дисками в фоновом потоке. Ранее перенос changelog на другой диск глобально блокировал Keeper до завершения операции. Это приводило к снижению производительности, если перенос занимал много времени (например, на S3-диск). [#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#83205](https://github.com/ClickHouse/ClickHouse/issues/83205): `SYSTEM RESTART REPLICA` может завершиться с ошибкой из-за проблем с подключением к ZooKeeper. Чтобы не терять эту таблицу из виду, теперь попытки повторяются до тех пор, пока таблица не будет создана. [#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#83270](https://github.com/ClickHouse/ClickHouse/issues/83270): исправлено неверное значение по умолчанию для опции `--reconnect` в `clickhouse-benchmark`. Оно было изменено по ошибке в [#79465](https://github.com/ClickHouse/ClickHouse/issues/79465). [#82677](https://github.com/ClickHouse/ClickHouse/pull/82677) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#82928](https://github.com/ClickHouse/ClickHouse/issues/82928): улучшение Keeper: поддержка отдельных разрешений для ACL world:anyone. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#83146](https://github.com/ClickHouse/ClickHouse/issues/83146): в `system.s3queue_log` добавлены столбцы `commit_time`, `commit_id`. [#83016](https://github.com/ClickHouse/ClickHouse/pull/83016) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#83184](https://github.com/ClickHouse/ClickHouse/issues/83184): предупреждения о неизвестных настройках в клиенте ClickHouse теперь объединяются и записываются в журнал в виде сводки. [#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc)).
* Бэкпортировано в [#83281](https://github.com/ClickHouse/ClickHouse/issues/83281): была некорректная проверка зависимостей для INSERT с MV, у которых были некорректные SELECT-запросы, из-за чего пользователь мог получить малопонятное `std::exception` вместо осмысленной ошибки с понятным объяснением. Теперь это исправлено. Исправляет: [#82889](https://github.com/ClickHouse/ClickHouse/issues/82889). [#83190](https://github.com/ClickHouse/ClickHouse/pull/83190) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпорт в [#82781](https://github.com/ClickHouse/ClickHouse/issues/82781): Исправлен анализ filter в случае, когда в запросе используется только константный столбец-псевдоним. Исправляет [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448). [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпорт в [#83148](https://github.com/ClickHouse/ClickHouse/issues/83148): Исправлен `DatabaseReplicated::getClusterImpl`. Если первый элемент (или элементы) в `hosts` имеет `id == DROPPED_MARK` и для того же сегмента нет других элементов, первый элемент `shards` будет пустым вектором, что приведет к `std::out_of_range`. [#82093](https://github.com/ClickHouse/ClickHouse/pull/82093) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпорт в [#83211](https://github.com/ClickHouse/ClickHouse/issues/83211): Исправлена деградация производительности в SummingMergeTree, появившаяся в 25.5 в [https://github.com/ClickHouse/ClickHouse/pull/79051](https://github.com/ClickHouse/ClickHouse/pull/79051). [#82130](https://github.com/ClickHouse/ClickHouse/pull/82130) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпорт в [#83217](https://github.com/ClickHouse/ClickHouse/issues/83217): Исправлена ошибка &quot;Context has expired&quot; для Iceberg. [#82146](https://github.com/ClickHouse/ClickHouse/pull/82146) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпорт в [#82946](https://github.com/ClickHouse/ClickHouse/issues/82946): Исправлены гонки данных в client (за счет отказа от использования глобального контекста) и overrides для `session_timezone` (ранее, если `session_timezone` был задан, например, в `users.xml`/параметрах client как непустой, а в контексте запроса — как пустой, использовалось значение из `users.xml`, что неверно; теперь у контекста запроса всегда будет приоритет над глобальным контекстом). [#82444](https://github.com/ClickHouse/ClickHouse/pull/82444) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпорт в [#82758](https://github.com/ClickHouse/ClickHouse/issues/82758): Исправлены случаи, когда parsing типа Time мог вызывать проблемы с msan. Это исправляет: [#82477](https://github.com/ClickHouse/ClickHouse/issues/82477). [#82514](https://github.com/ClickHouse/ClickHouse/pull/82514) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Бэкпорт в [#82739](https://github.com/ClickHouse/ClickHouse/issues/82739): Реализация настройки `use_skip_indexes_if_final_exact_mode` (introduced in 25.6) могла не выбрать подходящий диапазон в зависимости от настроек движка `MergeTree` / распределения данных. Теперь это исправлено. [#82667](https://github.com/ClickHouse/ClickHouse/pull/82667) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Бэкпорт в [#82737](https://github.com/ClickHouse/ClickHouse/issues/82737): Functions `trim{Left,Right,Both}` теперь поддерживают входные строки типа &quot;FixedString(N)&quot;. Например, `SELECT trimBoth(toFixedString('abc', 3), 'ac')` теперь работает. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпорт в [#82915](https://github.com/ClickHouse/ClickHouse/issues/82915): В AzureBlobStorage при native copy сравниваются методы аутентификации; если при этом возникает исключение, код теперь переключается на fallback к read and copy (то есть на не native copy). [#82693](https://github.com/ClickHouse/ClickHouse/pull/82693) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Бэкпортировано в [#82802](https://github.com/ClickHouse/ClickHouse/issues/82802): исправлена десериализация `groupArraySample`/`groupArrayLast` в случае пустых элементов (десериализация могла пропускать часть бинарных данных, если вход был пустым; это могло приводить к повреждению данных при чтении и ошибке UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER в протоколе TCP). Это не затрагивает числовые типы и типы дата-время. [#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
* Бэкпортировано в [#83572](https://github.com/ClickHouse/ClickHouse/issues/83572): исправлено резервное копирование пустой таблицы `Memory`, из-за которого восстановление из резервной копии завершалось ошибкой `BACKUP_ENTRY_NOT_FOUND`. [#82791](https://github.com/ClickHouse/ClickHouse/pull/82791) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#83114](https://github.com/ClickHouse/ClickHouse/issues/83114): исправлена устойчивость к исключениям при rewrite union/intersect/except&#95;default&#95;mode. Закрывает [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664). [#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#83263](https://github.com/ClickHouse/ClickHouse/issues/83263): исправлены гонки данных в Iceberg. [#82841](https://github.com/ClickHouse/ClickHouse/pull/82841) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#83224](https://github.com/ClickHouse/ClickHouse/issues/83224): оптимизация настройки `use_skip_indexes_if_final_exact_mode` (добавленная в 25.6) в зависимости от настроек движка `MergeTree` / распределения данных могла не выбирать подходящий диапазон-кандидат. Теперь это исправлено. [#82879](https://github.com/ClickHouse/ClickHouse/pull/82879) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Бэкпортировано в [#83291](https://github.com/ClickHouse/ClickHouse/issues/83291): устанавливается соль для данных аутентификации при парсинге из AST с типом SCRAM&#95;SHA256&#95;PASSWORD. [#82888](https://github.com/ClickHouse/ClickHouse/pull/82888) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Бэкпортировано в [#82997](https://github.com/ClickHouse/ClickHouse/issues/82997): при использовании реализации Database без кэширования метаданные соответствующей таблицы удаляются после возврата столбцов, и ссылка становится недействительной. [#82939](https://github.com/ClickHouse/ClickHouse/pull/82939) ([buyval01](https://github.com/buyval01)).
* Бэкпортировано в [#83029](https://github.com/ClickHouse/ClickHouse/issues/83029): исправлено изменение фильтра для запросов с выражением JOIN и таблицей с движком `Merge`. Исправляет [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092). [#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#83313](https://github.com/ClickHouse/ClickHouse/issues/83313): исправлена ошибка LOGICAL&#95;ERROR в QueryMetricLog: Mutex не может быть NULL. [#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#83086](https://github.com/ClickHouse/ClickHouse/issues/83086): исправлен некорректный вывод функции `formatDateTime`, когда форматтер `%f` используется вместе с форматтерами переменной длины (например, `%M`). [#83020](https://github.com/ClickHouse/ClickHouse/pull/83020) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#83242](https://github.com/ClickHouse/ClickHouse/issues/83242): Исправлена деградация производительности при включенном анализаторе, когда вторичные запросы всегда читают все столбцы из представлений VIEW. Исправляет [#81718](https://github.com/ClickHouse/ClickHouse/issues/81718). [#83036](https://github.com/ClickHouse/ClickHouse/pull/83036) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#83175](https://github.com/ClickHouse/ClickHouse/issues/83175): Исправлено вводящее в заблуждение сообщение об ошибке при восстановлении резервной копии на диске только для чтения. [#83051](https://github.com/ClickHouse/ClickHouse/pull/83051) ([Julia Kartseva](https://github.com/jkartseva)).
