<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#86730](https://github.com/ClickHouse/ClickHouse/issues/86730): Исправлена ошибка при выполнении `SYSTEM DROP REPLICA` для каталога с повреждёнными метаданными. [#86391](https://github.com/ClickHouse/ClickHouse/pull/86391) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#87427](https://github.com/ClickHouse/ClickHouse/issues/87427): Параметр `s3_slow_all_threads_after_retryable_error` отключён по умолчанию. [#87198](https://github.com/ClickHouse/ClickHouse/pull/87198) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#87155](https://github.com/ClickHouse/ClickHouse/issues/87155): Добавлена проверка, которая разрешает коррелированные подзапросы в предложении FROM только при использовании столбцов из внешнего запроса. Исправляет [#85469](https://github.com/ClickHouse/ClickHouse/issues/85469). Исправляет [#85402](https://github.com/ClickHouse/ClickHouse/issues/85402). [#85966](https://github.com/ClickHouse/ClickHouse/pull/85966) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#86953](https://github.com/ClickHouse/ClickHouse/issues/86953): Исправлено выполнение ALTER UPDATE для столбца с подстолбцом, используемым в материализованном выражении другого столбца. Ранее материализованный столбец с подстолбцом в своём выражении обновлялся некорректно. [#85985](https://github.com/ClickHouse/ClickHouse/pull/85985) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#87664](https://github.com/ClickHouse/ClickHouse/issues/87664): Исправлен detach/attach для таблиц движка базы данных Postgres со столбцами типов numeric/decimal. [#86480](https://github.com/ClickHouse/ClickHouse/pull/86480) ([Julian Maicher](https://github.com/jmaicher)).
* Бэкпортировано в [#87056](https://github.com/ClickHouse/ClickHouse/issues/87056): Исправлена запись NULL в общие данные JSON во входном формате RowBinary, а также добавлены дополнительные проверки в ColumnObject. [#86812](https://github.com/ClickHouse/ClickHouse/pull/86812) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#87053](https://github.com/ClickHouse/ClickHouse/issues/87053): Исправлено позиционирование в конце распакованного блока. [#86906](https://github.com/ClickHouse/ClickHouse/pull/86906) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#87637](https://github.com/ClickHouse/ClickHouse/issues/87637): Исправлен недетерминированный результат функции, вычисляемой в CTE внутри запроса. [#86967](https://github.com/ClickHouse/ClickHouse/pull/86967) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#87189](https://github.com/ClickHouse/ClickHouse/issues/87189): Исправлен возможный некорректный результат функции `uniqExact` с модификаторами `ROLLUP` и `CUBE`. [#87014](https://github.com/ClickHouse/ClickHouse/pull/87014) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#87415](https://github.com/ClickHouse/ClickHouse/issues/87415): EmbeddedRocksDB: путь должен находиться внутри user&#95;files. [#87109](https://github.com/ClickHouse/ClickHouse/pull/87109) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#87310](https://github.com/ClickHouse/ClickHouse/issues/87310): Исправлены таблицы KeeperMap, созданные до 25.1 и оставлявшие данные в ZooKeeper после запроса DROP. [#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#87164](https://github.com/ClickHouse/ClickHouse/issues/87164): Исправлено чтение массива с подстолбцом размеров массива при отложенной материализации. [#87139](https://github.com/ClickHouse/ClickHouse/pull/87139) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#87636](https://github.com/ClickHouse/ClickHouse/issues/87636): Исправлен некорректный учёт освобождений временных данных при отслеживании лимита `max_temporary_data_on_disk_size`, закрывает [#87118](https://github.com/ClickHouse/ClickHouse/issues/87118). [#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
* Бэкпортировано в [#87475](https://github.com/ClickHouse/ClickHouse/issues/87475): pathStartsWith теперь сопоставляет только пути, находящиеся под этим префиксом. [#87181](https://github.com/ClickHouse/ClickHouse/pull/87181) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#87459](https://github.com/ClickHouse/ClickHouse/issues/87459): Исправлена ошибка `LOGICAL_ERROR` &quot;Передан слишком большой размер в аллокатор&quot; в `JOIN`, вызванная смешением константных и неконстантных блоков. [#87231](https://github.com/ClickHouse/ClickHouse/pull/87231) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#87452](https://github.com/ClickHouse/ClickHouse/issues/87452): Для `s3_plain_rewritable` игнорируются только ошибки `not found`, что может привести к всевозможным проблемам. [#87426](https://github.com/ClickHouse/ClickHouse/pull/87426) ([Azat Khuzhin](https://github.com/azat)).
