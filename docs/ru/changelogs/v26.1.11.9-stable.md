<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#102655](https://github.com/ClickHouse/ClickHouse/issues/102655): исправлено Исключение LOGICAL&#95;ERROR в `ASTColumnsExceptTransformer::transform`. [#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#101418](https://github.com/ClickHouse/ClickHouse/issues/101418): исправлено использование неинициализированного значения в StringSearcher.h. [#100225](https://github.com/ClickHouse/ClickHouse/pull/100225) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#102677](https://github.com/ClickHouse/ClickHouse/issues/102677): исправлен сбой use-after-free в планировщике аренды CPU, когда таймер ожидания переживает воркер-поток, на чьи `ProfileEvents::Counters` он ссылается. [#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#102709](https://github.com/ClickHouse/ClickHouse/issues/102709): исправлена ошибка гонки SLRU в файловом кэше 26.1+, которая может приводить к логической ошибке при резервировании места. В отладочной сборке это также может приводить к срабатыванию assert: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#102750](https://github.com/ClickHouse/ClickHouse/issues/102750): исправлено завышение CurrentMetric у `NamedCollection` из-за `CREATE NAMED COLLECTION IF NOT EXISTS` для уже существующих коллекций, а также отсутствие инициализации для коллекций, загружаемых при запуске из config или SQL-хранилища. Закрывает [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507). [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#102795](https://github.com/ClickHouse/ClickHouse/issues/102795): ошибка в row policy, которая в некоторых особых случаях приводит к Исключению &#39;Not found column in block&#39;. [#102648](https://github.com/ClickHouse/ClickHouse/pull/102648) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Бэкпортировано в [#102743](https://github.com/ClickHouse/ClickHouse/issues/102743): исправлено бесконечное зависание `SYSTEM WAIT VIEW`, если refreshable materialized view удаляется во время ожидания. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
