<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Бэкпортировано в [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224): Включение расширенных общих данных для JSON по умолчанию. После этого изменения понизить версию до <25.8 будет невозможно, поскольку эти версии не смогут читать новые части данных с JSON-столбцом. Для безопасного обновления рекомендуется установить настройку `compatibility` на предыдущую версию или задать настройки MergeTree `dynamic_serialization_version='v2', object_serialization_version='v2'`. [#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061): Откат изменения «Allow INSERT into simple ALIAS columns» (откатывает ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154)). Это изменение не работает с пользовательскими форматами и не защищено настройкой. [#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#92711](https://github.com/ClickHouse/ClickHouse/issues/92711): Оптимизация агрегатной функции distinctJSONPaths — теперь она читает только JSON-пути из частей данных, а не весь JSON-столбец целиком. [#92196](https://github.com/ClickHouse/ClickHouse/pull/92196) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#92604](https://github.com/ClickHouse/ClickHouse/issues/92604): Добавлен столбец способа создания (implicit/explicit) в system.data_skipping_indices. [#92378](https://github.com/ClickHouse/ClickHouse/pull/92378) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#93377](https://github.com/ClickHouse/ClickHouse/issues/93377): Добавлен переход к копированию с возможностью чтения и записи для Azure Blob Storage при сбое нативного копирования с ошибкой BadRequest (например, недопустимый список блоков). Ранее это выполнялось только при ошибке Unauthorized, которая возникала при копировании blob между разными storage account. Однако иногда также встречается ошибка «The specified block list is invalid». Теперь условие обновлено: переход к режиму чтения и записи выполняется при любом сбое нативного копирования. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Бэкпортировано в [#93015](https://github.com/ClickHouse/ClickHouse/issues/93015): Добавлено логирование фоновых задач, выполняющихся медленнее среднего (`background_schedule_pool_log.duration_threshold_milliseconds=30`), для предотвращения избыточного журналирования задач. [#92965](https://github.com/ClickHouse/ClickHouse/pull/92965) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338): Добавлена поддержка типа Geometry для `flipCoordinates`. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).
* Бэкпортировано в [#93395](https://github.com/ClickHouse/ClickHouse/issues/93395): Улучшен пользовательский интерфейс SYSTEM INSTRUMENT ADD/REMOVE: используются строковые литералы для имён функций, изменения применяются ко всем совпадающим функциям, а также разрешено использование function_name в `REMOVE`. [#93345](https://github.com/ClickHouse/ClickHouse/pull/93345) ([Pablo Marcos](https://github.com/pamarcos)).
