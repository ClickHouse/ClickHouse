  ### Релиз ClickHouse v26.3.6.5-lts (76a4a77bb24) FIXME по сравнению с v26.3.5.12-lts (172e4255c5c)

<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпортировано в [#102253](https://github.com/ClickHouse/ClickHouse/issues/102253): добавлены асинхронные метрики памяти буферов приёма и передачи TCP в ядре (`sk_rmem_alloc`, `sk_wmem_alloc`) для сокетов пула HTTP-соединений, представляемые в виде процентилей p50/p75/p90/p95 и суммарных значений для каждой группы соединений. [#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#102296](https://github.com/ClickHouse/ClickHouse/issues/102296): Исправлена возможная логическая ошибка при чтении подстолбцов Map. Закрывает [#100769](https://github.com/ClickHouse/ClickHouse/issues/100769). Закрывает [#101336](https://github.com/ClickHouse/ClickHouse/issues/101336). [#101641](https://github.com/ClickHouse/ClickHouse/pull/101641) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#102267](https://github.com/ClickHouse/ClickHouse/issues/102267): Исправлена возможная ошибка гонки в SLRU в файловом кэше 26.1+, которая может приводить к логической ошибке при резервировании места. В отладочной сборке это также может приводить к failed assert: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#102174](https://github.com/ClickHouse/ClickHouse/issues/102174): Исправлено падение при обновлении UDF, вызванное тем, что `ZooKeeperRetriesControl` выполнял повторную попытку на stale (expired) сеансе ZooKeeper без его продления. [#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)).
