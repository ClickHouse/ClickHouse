<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#71713](https://github.com/ClickHouse/ClickHouse/issues/71713): `CLICKHOUSE_PASSWORD` экранируется для XML в entrypoint образа ClickHouse. [#69301](https://github.com/ClickHouse/ClickHouse/pull/69301) ([aohoyd](https://github.com/aohoyd)).
* Бэкпортировано в [#71666](https://github.com/ClickHouse/ClickHouse/issues/71666): Если пользователь/группа заданы как ID, `clickhouse su` завершается с ошибкой. Это исправление также добавляет поддержку `UID:GID`. ### Запись в документации для изменений, видимых пользователю. [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#71936](https://github.com/ClickHouse/ClickHouse/issues/71936): Обновление `HostResolver` 3 раза в течение периода `history`. [#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#71486](https://github.com/ClickHouse/ClickHouse/issues/71486): Исправлена проблема, из-за которой `Content-Encoding` не отправлялся в некоторых сжатых ответах. [#64802](https://github.com/ClickHouse/ClickHouse/issues/64802). [#68975](https://github.com/ClickHouse/ClickHouse/pull/68975) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#71462](https://github.com/ClickHouse/ClickHouse/issues/71462): Добавлено отсутствующее деэкранирование в named collections. Без этого исправления clickhouse-server не может запуститься. [#71308](https://github.com/ClickHouse/ClickHouse/pull/71308) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Бэкпортировано в [#71747](https://github.com/ClickHouse/ClickHouse/issues/71747): Проверка подозрительных и экспериментальных типов в подсказках типов JSON. [#71369](https://github.com/ClickHouse/ClickHouse/pull/71369) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#71604](https://github.com/ClickHouse/ClickHouse/issues/71604): Исправлена ошибка Invalid number of rows in Chunk в столбце Variant. [#71388](https://github.com/ClickHouse/ClickHouse/pull/71388) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#71826](https://github.com/ClickHouse/ClickHouse/issues/71826): Исправлен сбой в optimize&#95;rewrite&#95;array&#95;exists&#95;to&#95;has. [#71432](https://github.com/ClickHouse/ClickHouse/pull/71432) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71517](https://github.com/ClickHouse/ClickHouse/issues/71517): Исправлена возможная ошибка `Argument for function must be constant` (старый анализатор) в случае, когда arrayJoin, по-видимому, может появляться в условии `WHERE`. Регрессия после [https://github.com/ClickHouse/ClickHouse/pull/65414](https://github.com/ClickHouse/ClickHouse/pull/65414). [#71476](https://github.com/ClickHouse/ClickHouse/pull/71476) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#71551](https://github.com/ClickHouse/ClickHouse/issues/71551): Предотвращён сбой в SortCursor с 0 столбцами (старый анализатор). [#71494](https://github.com/ClickHouse/ClickHouse/pull/71494) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71614](https://github.com/ClickHouse/ClickHouse/issues/71614): Исправление в анализаторе, когда запрос внутри materialized view использует IN с CTE. Закрывает [#65598](https://github.com/ClickHouse/ClickHouse/issues/65598). [#71538](https://github.com/ClickHouse/ClickHouse/pull/71538) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#71566](https://github.com/ClickHouse/ClickHouse/issues/71566): Предотвращён сбой при использовании UDF в ограничении. [#71541](https://github.com/ClickHouse/ClickHouse/pull/71541) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71727](https://github.com/ClickHouse/ClickHouse/issues/71727): Возвращать 0 или символ по умолчанию вместо генерации ошибки в функциях bitShift в случае выхода за границы. [#71580](https://github.com/ClickHouse/ClickHouse/pull/71580) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#71876](https://github.com/ClickHouse/ClickHouse/issues/71876): Исправлен LOGICAL&#95;ERROR при выполнении ALTER с пустым tuple. Это исправляет [#71647](https://github.com/ClickHouse/ClickHouse/issues/71647). [#71679](https://github.com/ClickHouse/ClickHouse/pull/71679) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#71737](https://github.com/ClickHouse/ClickHouse/issues/71737): не преобразовывать константное множество в предикатах по столбцам партиции при использовании оператора NOT IN. [#71695](https://github.com/ClickHouse/ClickHouse/pull/71695) ([Eduard Karacharov](https://github.com/korowa)).
* Бэкпортировано в [#72002](https://github.com/ClickHouse/ClickHouse/issues/72002): исправлен сбой в подсветке синтаксиса в клиенте ClickHouse. Закрывает [#71864](https://github.com/ClickHouse/ClickHouse/issues/71864). [#71949](https://github.com/ClickHouse/ClickHouse/pull/71949) ([Nikolay Degterinsky](https://github.com/evillique)).

Переменные среды `CLICKHOUSE_UID/CLICKHOUSE_GID` объявлены устаревшими. Убрана обработка `CLICKHOUSE_DOCKER_RESTART_ON_EXIT` для соответствия требованиям.
