<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#97109](https://github.com/ClickHouse/ClickHouse/issues/97109): Исправлена возможная логическая ошибка при использовании `analyzer_compatibility_join_using_top_level_identifier` с несколькими JOIN. [#90010](https://github.com/ClickHouse/ClickHouse/pull/90010) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#96400](https://github.com/ClickHouse/ClickHouse/issues/96400): Исправлены возможные некорректные результаты запроса после легковесных обновлений в запросах `SELECT` при включенном кэше условий запроса. Исправляет [#90176](https://github.com/ClickHouse/ClickHouse/issues/90176). Исправляет [#90054](https://github.com/ClickHouse/ClickHouse/issues/90054). [#90204](https://github.com/ClickHouse/ClickHouse/pull/90204) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#91754](https://github.com/ClickHouse/ClickHouse/issues/91754): Исправлена проверка доступа для запросов `ALTER UPDATE`, когда табличная функция `remote` используется с `localhost` в качестве целевого хоста. [#90761](https://github.com/ClickHouse/ClickHouse/pull/90761) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#97815](https://github.com/ClickHouse/ClickHouse/issues/97815): Связанная issue: [#6365](https://github.com/ClickHouse/support-escalation/issues/6365). [#92339](https://github.com/ClickHouse/ClickHouse/pull/92339) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Бэкпортировано в [#97327](https://github.com/ClickHouse/ClickHouse/issues/97327): Убрана лишняя возможность пропуска проверки разрешений в запросах `ATTACH` для представления с безопасностью SQL. Это предотвращает потенциальное повышение привилегий, когда пользователь подключает представление с definer без проверки необходимого доступа. [#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#95814](https://github.com/ClickHouse/ClickHouse/issues/95814): Исправлен вывод типов для квалифицированных столбцов из исходных таблиц при использовании нескольких JOIN с предложением `USING`. Ранее последующие JOIN некорректно обновляли типы исходных столбцов до общего супертипа, даже если столбец не участвовал в этом JOIN (например, в `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` столбец `t2.a` используется только в первом JOIN, поэтому его тип должен быть супертипом `t1.a` и `t2.a`, без учета `t3.a`). Это могло приводить к логическим ошибкам или сбоям, когда функции ожидали одни типы столбцов, а в плане выполнения фактически оказывались другие. [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#95484](https://github.com/ClickHouse/ClickHouse/issues/95484): В табличной функции `mergeTreeProjection` отсутствовала проверка доступа, из-за чего пользователи без разрешения SELECT на таблицу (но с разрешениями на табличные функции) могли читать данные из ее проекций. Это исправление добавляет ту же проверку доступа, которая уже есть в `mergeTreeIndex` и `mergeTreeAnalyzeIndexes`. [#95480](https://github.com/ClickHouse/ClickHouse/pull/95480) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#96052](https://github.com/ClickHouse/ClickHouse/issues/96052): Исправлено укрупнение блоков в секционированных данных Delta Lake. [#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#96209](https://github.com/ClickHouse/ClickHouse/issues/96209): Исправлен пропуск путей в типе данных JSON. Ранее при `JSON(SKIP path)` пропускались все ключи JSON с префиксом `path`, даже такие, как `"pathpath"`, из-за чего при вставке могла происходить потеря данных для этих путей. Теперь это исправлено: пропускается только ключ `"path"`. [#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#96076](https://github.com/ClickHouse/ClickHouse/issues/96076): Исправлен период для глобальных профилировщиков (управляется параметрами `global_profiler_real_time_period_ns` и `global_profiler_cpu_time_period_ns`). Вместо заданного значения использовалось усечённое, из-за чего профилировщик пробуждался чаще, чем предполагалось. [#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#96538](https://github.com/ClickHouse/ClickHouse/issues/96538): Исправлен отзыв ролей по умолчанию. [#96103](https://github.com/ClickHouse/ClickHouse/pull/96103) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#97149](https://github.com/ClickHouse/ClickHouse/issues/97149): Исправлено некорректное поведение `AccessRights::contains` при частичном отзыве прав. [#96170](https://github.com/ClickHouse/ClickHouse/pull/96170) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#96276](https://github.com/ClickHouse/ClickHouse/issues/96276): Исправлена возможная взаимная блокировка в ProcessList. Это может происходить из-за инверсии блокировок, если трекер оверкоммита памяти срабатывает в момент добавления задачи в средство проверки отмены. [#96182](https://github.com/ClickHouse/ClickHouse/pull/96182) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#96555](https://github.com/ClickHouse/ClickHouse/issues/96555): Исправлен crash в старом анализаторе при JOIN и дублирующихся псевдонимах. [#96405](https://github.com/ClickHouse/ClickHouse/pull/96405) ([Ilya Golshtein](https://github.com/ilejn)).
* Бэкпортировано в [#96578](https://github.com/ClickHouse/ClickHouse/issues/96578): Исправлен livelock в потоке проверки отмены для запросов с высокими значениями `max_execution_time`. [#96450](https://github.com/ClickHouse/ClickHouse/pull/96450) ([Sergei Trifonov](https://github.com/serxa)).
* Бэкпортировано в [#96689](https://github.com/ClickHouse/ClickHouse/issues/96689): Добавлена проверка версии witness в bech32 во избежание переполнения буфера. [#96671](https://github.com/ClickHouse/ClickHouse/pull/96671) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#97202](https://github.com/ClickHouse/ClickHouse/issues/97202): Исправлено, что `min(timestamp)` возвращал эпоху (`1970-01-01`) через `_minmax_count_projection` после TTL merge, когда все строки в блоке отфильтровывались. [#96703](https://github.com/ClickHouse/ClickHouse/pull/96703) ([Raquel Barbadillo](https://github.com/rbarbadillo)).
* Бэкпортировано в [#96934](https://github.com/ClickHouse/ClickHouse/issues/96934): Исправлено Исключение `std::terminate` в `indexOfAssumeSorted` при вызове с несовместимыми типами (например, массив `IPv4` со значением поиска целочисленного типа). [#96877](https://github.com/ClickHouse/ClickHouse/pull/96877) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#97463](https://github.com/ClickHouse/ClickHouse/issues/97463): Исправлен SEGFAULT в supportsTrivialCountOptimization из-за разыменования null. [#97281](https://github.com/ClickHouse/ClickHouse/pull/97281) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#97434](https://github.com/ClickHouse/ClickHouse/issues/97434): Удалена проверка TABLE&#95;UUID&#95;MISMATCH для режима без анализатора. [#97323](https://github.com/ClickHouse/ClickHouse/pull/97323) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#97607](https://github.com/ClickHouse/ClickHouse/issues/97607): Исправлено возможное использование памяти после её освобождения в StorageKafka2. [#97520](https://github.com/ClickHouse/ClickHouse/pull/97520) ([Bharat Nallan](https://github.com/bharatnc)).
* Бэкпортировано в [#97952](https://github.com/ClickHouse/ClickHouse/issues/97952): Исправлена логическая ошибка, связанная с отсутствующим потоком при INSERT SELECT с JSON и бакетами в общих данных. Закрывает [#97331](https://github.com/ClickHouse/ClickHouse/issues/97331). [#97523](https://github.com/ClickHouse/ClickHouse/pull/97523) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#97597](https://github.com/ClickHouse/ClickHouse/issues/97597): Исправлено разыменование нулевого указателя при применении патч-частей во время легковесных обновлений. [#97583](https://github.com/ClickHouse/ClickHouse/pull/97583) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#97713](https://github.com/ClickHouse/ClickHouse/issues/97713): `BaseSettings::readBinary` передаёт индекс из `accessor.find` в `field_infos[]` без проверки специального значения «не найдено» (то есть `-1`), что может привести к выходу за границы `std::vector`. Проблему удалось выявить благодаря механизмам усиленной защиты libcxx. Вероятно, это происходило при десериализации плана запроса, когда более новый сервер отправлял настройку, неизвестную более старому серверу. Метод чтения на основе строк уже обрабатывает это корректно; в `readBinary` такой проверки не хватало. [#97585](https://github.com/ClickHouse/ClickHouse/pull/97585) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпортировано в [#97911](https://github.com/ClickHouse/ClickHouse/issues/97911): Исправлен некорректный результат при использовании алгоритма `grace_hash` с неравенственными JOIN, когда левый блок не может быть полностью обработан из-за ограничений на размер результата JOIN. [#97866](https://github.com/ClickHouse/ClickHouse/pull/97866) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#98072](https://github.com/ClickHouse/ClickHouse/issues/98072): Исправлено состояние гонки данных в клиенте ZooKeeper между sendThread и receiveThread. [#97887](https://github.com/ClickHouse/ClickHouse/pull/97887) ([Pablo Marcos](https://github.com/pamarcos)).

[#98147](https://github.com/ClickHouse/ClickHouse/pull/98147) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
