<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#101914](https://github.com/ClickHouse/ClickHouse/issues/101914): исправлена значительная регрессия производительности INSERT при `deduplicate_insert=enable` (по умолчанию начиная с 26.2) за счёт переноса вычисления хеша данных с этапа squashing в sink и использования батч-хеширования столбцов через `updateHashWithValueRange`, что сократило накладные расходы примерно с ~2.5s до ~0.5s для 5M строк и 22 столбцов. [#101494](https://github.com/ClickHouse/ClickHouse/pull/101494) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#101601](https://github.com/ClickHouse/ClickHouse/issues/101601): отслеживание памяти в Cgroupv2 теперь исключает `slab_reclaimable` из памяти ядра, что позволяет точнее оценивать объём невытесняемой памяти. [#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#101985](https://github.com/ClickHouse/ClickHouse/issues/101985): Исправлены ошибки &quot;Target table doesn&#39;t exist&quot; для materialized view с внутренними таблицами при асинхронном запуске, вызванные неверным порядком инициализации зависимостей. [#100946](https://github.com/ClickHouse/ClickHouse/pull/100946) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#102073](https://github.com/ClickHouse/ClickHouse/issues/102073): Исправлено обращение к памяти после выхода из области видимости при параллельной десериализации динамических paths типа `Object`, которое могло вызывать сбои при чтении таблиц с большим количеством динамических paths. [#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#102100](https://github.com/ClickHouse/ClickHouse/issues/102100): Исправлен некорректный результат работы функции `formatDateTime` с форматтером `%W` при некоторых (не стандартных) настройках форматирования. [#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#102028](https://github.com/ClickHouse/ClickHouse/issues/102028): Исправлена потеря registry UDF при истечении сеанса ZooKeeper во время периодического refresh — все пользовательские функции могли становиться недоступными, пока не завершится успешное полное обновление. [#101891](https://github.com/ClickHouse/ClickHouse/pull/101891) ([Nikita Fomichev](https://github.com/fm4v)).
* Бэкпортировано в [#102092](https://github.com/ClickHouse/ClickHouse/issues/102092): Токенизатор `splitByString` теперь отклоняет пустые строки в качестве разделителя. [#101928](https://github.com/ClickHouse/ClickHouse/pull/101928) ([Robert Schulze](https://github.com/rschu1ze)).
