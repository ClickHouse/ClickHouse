</div>

* Бэкпортировано в [#77947](https://github.com/ClickHouse/ClickHouse/issues/77947): Исправлен сбой из-за просроченного контекста в StorageS3(Azure)Queue. [#77720](https://github.com/ClickHouse/ClickHouse/pull/77720) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#78087](https://github.com/ClickHouse/ClickHouse/issues/78087): Скрыты учётные данные в движках таблиц RabbitMQ, Nats, Redis и AzureQueue. [#77755](https://github.com/ClickHouse/ClickHouse/pull/77755) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#78038](https://github.com/ClickHouse/ClickHouse/issues/78038): Исправлено неопределённое поведение при сравнении NaN в ArgMin/ArgMax. [#77756](https://github.com/ClickHouse/ClickHouse/pull/77756) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#78280](https://github.com/ClickHouse/ClickHouse/issues/78280): Исправлен возможный сбой при возникновении ошибки `NOT_FOUND_COLUMN_IN_BLOCK`. [#77854](https://github.com/ClickHouse/ClickHouse/pull/77854) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#78050](https://github.com/ClickHouse/ClickHouse/issues/78050): Отключён нечёткий поиск по истории в SSH-сервере (так как для него требуется skim). [#78002](https://github.com/ClickHouse/ClickHouse/pull/78002) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#78105](https://github.com/ClickHouse/ClickHouse/issues/78105): Исправлен промпт &quot;Запрошенный формат вывода {} — двоичный... Всё равно вывести его? [y/N]&quot;. [#78095](https://github.com/ClickHouse/ClickHouse/pull/78095) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#78116](https://github.com/ClickHouse/ClickHouse/issues/78116): Запрещено указывать пустой параметр запроса `session_id` для HTTP-интерфейса. [#78098](https://github.com/ClickHouse/ClickHouse/pull/78098) ([Alexey Katsman](https://github.com/alexkats)).
* Бэкпортировано в [#78136](https://github.com/ClickHouse/ClickHouse/issues/78136): Исправлен сбой в движке NATS. [#78108](https://github.com/ClickHouse/ClickHouse/pull/78108) ([Dmitry Novikov](https://github.com/dmitry-sles-novikov)).
* Бэкпортировано в [#78121](https://github.com/ClickHouse/ClickHouse/issues/78121): Больше не выполняется попытка создать history&#95;file во встроенном SSH-клиенте. [#78112](https://github.com/ClickHouse/ClickHouse/pull/78112) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#78147](https://github.com/ClickHouse/ClickHouse/issues/78147): Исправлено отображение некорректной информации в system.detached&#95;tables после запросов RENAME DATABASE или DROP TABLE. [#78126](https://github.com/ClickHouse/ClickHouse/pull/78126) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#78199](https://github.com/ClickHouse/ClickHouse/issues/78199): Исправлены проверки на слишком большое количество таблиц в базе данных Replicated после [https://github.com/ClickHouse/ClickHouse/pull/77274](https://github.com/ClickHouse/ClickHouse/pull/77274). Кроме того, проверка теперь выполняется до создания таблицы, чтобы избежать создания неучтённых узлов в ZooKeeper в случае RMT или KeeperMap. [#78127](https://github.com/ClickHouse/ClickHouse/pull/78127) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#78158](https://github.com/ClickHouse/ClickHouse/issues/78158): Функции `groupArray*` теперь выдают ошибку BAD&#95;ARGUMENTS для значения 0 типа Int в аргументе max&#95;size, как это уже сделано для UInt, вместо попытки выполнить функцию с этим значением. [#78140](https://github.com/ClickHouse/ClickHouse/pull/78140) ([Eduard Karacharov](https://github.com/korowa)).
* Бэкпортировано в [#78233](https://github.com/ClickHouse/ClickHouse/issues/78233): Предотвращён сбой в recoverLostReplica, если локальная таблица удалена до её отсоединения. [#78173](https://github.com/ClickHouse/ClickHouse/pull/78173) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#78239](https://github.com/ClickHouse/ClickHouse/issues/78239): Исправлен столбец &quot;alterable&quot; в system.s3&#95;queue&#95;settings, который всегда возвращал `false`. [#78187](https://github.com/ClickHouse/ClickHouse/pull/78187) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#78312](https://github.com/ClickHouse/ClickHouse/issues/78312): Исправлены сбои / некорректный результат для `mapFromArrays` в случае типа LowCardinality(Nullable) у массива ключей. [#78240](https://github.com/ClickHouse/ClickHouse/pull/78240) ([Eduard Karacharov](https://github.com/korowa)).
