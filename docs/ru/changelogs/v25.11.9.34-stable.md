<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#95286](https://github.com/ClickHouse/ClickHouse/issues/95286): Исправлена подстановка параметров запроса в методах аутентификации `CREATE USER` при использовании предложения ON CLUSTER. Параметры запроса в методах аутентификации (например, пароль) не подставлялись, из-за чего на удалённых узлах возникали ошибки UNKNOWN&#95;QUERY&#95;PARAMETER. [#92777](https://github.com/ClickHouse/ClickHouse/pull/92777) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* Бэкпортировано в [#95529](https://github.com/ClickHouse/ClickHouse/issues/95529): Резервные копии могли приводить к сбою сервера, если одновременно выполнялось много резервных копий, конфликтующих из-за одних и тех же файлов. [#93659](https://github.com/ClickHouse/ClickHouse/pull/93659) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#94973](https://github.com/ClickHouse/ClickHouse/issues/94973): Создание рабочей нагрузки внутри другой рабочей нагрузки, которая в данный момент используется, больше не вызывает сбой. [#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)).
* Бэкпортировано в [#95642](https://github.com/ClickHouse/ClickHouse/issues/95642): Исправлено некорректное отсечение по первичному ключу и индексу пропуска данных для предикатов с `toWeek`, `toYearWeek`, `toStartOfWeek`, `toLastDayOfWeek` и `toDayOfWeek`, а также исправлены исключения в некоторых из этих функций для корректных запросов с `LowCardinality(String)`. [#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Бэкпортировано в [#95629](https://github.com/ClickHouse/ClickHouse/issues/95629): Исправлен сбой при запуске `ReplicatedMergeTree`, вызванный одновременным удалением каталогов `delete_tmp_*`. [#94892](https://github.com/ClickHouse/ClickHouse/pull/94892) ([myeongjun](https://github.com/myeongjjun)).
* Бэкпортировано в [#95815](https://github.com/ClickHouse/ClickHouse/issues/95815): Исправлен вывод типов для квалифицированных столбцов из исходных таблиц при использовании нескольких JOIN с предложением `USING`. Ранее последующие JOIN некорректно обновляли типы базовых исходных столбцов до общего супертипа, даже если столбец не участвовал в этом JOIN (например, в `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` столбец `t2.a` используется только в первом JOIN, поэтому его тип должен быть супертипом `t1.a` и `t2.a`, без учёта `t3.a`). Это могло приводить к логическим ошибкам или сбоям, когда функции ожидали одни типы столбцов, а в плане выполнения фактически оказывались другие. [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#95425](https://github.com/ClickHouse/ClickHouse/issues/95425): Преобразование столбцов теперь выполняется только один раз при получении содержимого списка и файлов manifest .avro. [#95164](https://github.com/ClickHouse/ClickHouse/pull/95164) ([Daniil Ivanik](https://github.com/divanik)).
* Бэкпортировано в [#95382](https://github.com/ClickHouse/ClickHouse/issues/95382): Исправлен неточный учёт памяти при применении больших патч-частей после легковесных обновлений. Ранее применение больших патчей могло приводить к чрезмерному использованию памяти, из-за чего процесс сервера мог быть завершён OOM killer. [#95231](https://github.com/ClickHouse/ClickHouse/pull/95231) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#95572](https://github.com/ClickHouse/ClickHouse/issues/95572): Аргумент пароля табличной функции `redis` теперь маскируется в логах и системных таблицах (например, в `query_log`). [#95325](https://github.com/ClickHouse/ClickHouse/pull/95325) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#96392](https://github.com/ClickHouse/ClickHouse/issues/96392): Исправлена логическая ошибка, возникавшая в некоторых случаях при использовании отрицательного `LIMIT/OFFSET` в распределённых запросах. [#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Бэкпортировано в [#95606](https://github.com/ClickHouse/ClickHouse/issues/95606): Предотвращён возможный сбой в распределённых запросах при отмене. [#95466](https://github.com/ClickHouse/ClickHouse/pull/95466) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* Бэкпортировано в [#95546](https://github.com/ClickHouse/ClickHouse/issues/95546): Исправлена проверка зашифрованных дисков поверх plain&#95;rewritable (исправляет возможную ошибку `It is not possible to register multiple plain-rewritable disks with the same object storage prefix`). [#95470](https://github.com/ClickHouse/ClickHouse/pull/95470) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#95695](https://github.com/ClickHouse/ClickHouse/issues/95695): Исправлена логическая ошибка `There was an error: Cannot obtain error message`, возникавшая при ожидании distributed DDL и одновременном удалении базы данных Replicated. Исправляет [#95539](https://github.com/ClickHouse/ClickHouse/issues/95539). [#95664](https://github.com/ClickHouse/ClickHouse/pull/95664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#96053](https://github.com/ClickHouse/ClickHouse/issues/96053): Исправлено объединение партиционированных данных Delta Lake. [#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#96211](https://github.com/ClickHouse/ClickHouse/issues/96211): Исправлены skipping paths в типе JSON. Ранее при `JSON(SKIP path)` пропускались все JSON-ключи с префиксом `path`, даже такие ключи, как `"pathpath"`, поэтому это могло приводить к потере данных для этих путей во время вставки. Теперь это исправлено, и пропускается только ключ `"path"`. [#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#96078](https://github.com/ClickHouse/ClickHouse/issues/96078): Исправлен период для глобальных профилировщиков (управляется через `global_profiler_real_time_period_ns` и `global_profiler_cpu_time_period_ns`). Вместо заданного значения использовалось усечённое, из-за чего профилировщик пробуждался чаще, чем предполагалось. [#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#96155](https://github.com/ClickHouse/ClickHouse/issues/96155): Исправлено использование неинициализированного значения в `formatDateTime` с форматтерами нефиксированной ширины, например в стиле MySQL и JODA. [#96133](https://github.com/ClickHouse/ClickHouse/pull/96133) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#96278](https://github.com/ClickHouse/ClickHouse/issues/96278): Исправлена возможная взаимная блокировка в ProcessList. Это может происходить из-за возможной инверсии блокировок, если трекер оверкоммита памяти срабатывает в момент добавления задачи в cancellation checker. [#96182](https://github.com/ClickHouse/ClickHouse/pull/96182) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#96325](https://github.com/ClickHouse/ClickHouse/issues/96325): Исправлен `stack-use-after-scope` в индексе векторного сходства. [#96259](https://github.com/ClickHouse/ClickHouse/pull/96259) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#96530](https://github.com/ClickHouse/ClickHouse/issues/96530): Исправлена активная блокировка в потоке cancellation checker для запросов с высокими значениями `max_execution_time`. [#96450](https://github.com/ClickHouse/ClickHouse/pull/96450) ([Sergei Trifonov](https://github.com/serxa)).
* Бэкпортировано в [#96625](https://github.com/ClickHouse/ClickHouse/issues/96625): Исправлено исключение `LOGICAL_ERROR` в Parquet V3 native reader, если столбец фильтра `PREWHERE` содержит небулевы значения UInt8. [#96594](https://github.com/ClickHouse/ClickHouse/pull/96594) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#96691](https://github.com/ClickHouse/ClickHouse/issues/96691): Добавлена проверка witness version в bech32 во избежание переполнения буфера. [#96671](https://github.com/ClickHouse/ClickHouse/pull/96671) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#96917](https://github.com/ClickHouse/ClickHouse/issues/96917): Исправлена ошибка, из-за которой запросы `ALTER TABLE DROP COLUMN` завершались сбоем, если ранее для того же столбца уже было выполнено легковесное обновление. [#96861](https://github.com/ClickHouse/ClickHouse/pull/96861) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#96936](https://github.com/ClickHouse/ClickHouse/issues/96936): Исправлено исключение `std::terminate` в `indexOfAssumeSorted` при вызове с несовместимыми типами (например, для массива `IPv4` и целочисленного искомого значения). [#96877](https://github.com/ClickHouse/ClickHouse/pull/96877) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
