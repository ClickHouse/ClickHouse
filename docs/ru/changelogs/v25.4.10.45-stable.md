<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#83339](https://github.com/ClickHouse/ClickHouse/issues/83339): небольшое ускорение QueryTreeHash. [#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#83013](https://github.com/ClickHouse/ClickHouse/issues/83013): улучшение Keeper: перемещение файлов changelog между дисками в фоновом потоке. Ранее перемещение changelog на другой диск глобально блокировало Keeper до завершения операции. Это приводило к снижению производительности, если перемещение занимало много времени (например, на S3-диск). [#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#83203](https://github.com/ClickHouse/ClickHouse/issues/83203): `SYSTEM RESTART REPLICA` может завершаться с ошибкой из-за проблем с подключением к ZooKeeper. Чтобы не потерять эту таблицу, теперь мы повторяем попытки до тех пор, пока таблица не будет создана. [#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#83180](https://github.com/ClickHouse/ClickHouse/issues/83180): предупреждения о неизвестных настройках в клиенте ClickHouse объединены и записываются в журнал в виде сводки. [#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#83315](https://github.com/ClickHouse/ClickHouse/issues/83315): Исправлена ошибка &quot;Context has expired&quot; в Iceberg. [#82146](https://github.com/ClickHouse/ClickHouse/pull/82146) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#83255](https://github.com/ClickHouse/ClickHouse/issues/83255): Исправлено отключение выравнивания границ для кэшированного буфера в движках внешних таблиц. Ошибка появилась в [https://github.com/ClickHouse/ClickHouse/pull/81868](https://github.com/ClickHouse/ClickHouse/pull/81868). [#82493](https://github.com/ClickHouse/ClickHouse/pull/82493) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#82911](https://github.com/ClickHouse/ClickHouse/issues/82911): В AzureBlobStorage при нативном копировании сравниваются методы аутентификации; если в процессе возникает исключение, код теперь переключается на чтение и копирование (то есть на ненативное копирование). [#82693](https://github.com/ClickHouse/ClickHouse/pull/82693) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Бэкпортировано в [#83110](https://github.com/ClickHouse/ClickHouse/issues/83110): Исправлена устойчивость к исключениям при rewrite union/intersect/except&#95;default&#95;mode. Закрывает [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664). [#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#83328](https://github.com/ClickHouse/ClickHouse/issues/83328): Исправлены гонки данных в Iceberg. [#82841](https://github.com/ClickHouse/ClickHouse/pull/82841) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#83287](https://github.com/ClickHouse/ClickHouse/issues/83287): Задана соль для данных аутентификации при разборе из AST для типа SCRAM&#95;SHA256&#95;PASSWORD. [#82888](https://github.com/ClickHouse/ClickHouse/pull/82888) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Бэкпортировано в [#83025](https://github.com/ClickHouse/ClickHouse/issues/83025): Исправлено изменение filter для запросов с выражением JOIN и таблицей на хранилище `Merge`. Исправляет [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092). [#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#83309](https://github.com/ClickHouse/ClickHouse/issues/83309): Исправлен LOGICAL&#95;ERROR в QueryMetricLog: Mutex cannot be NULL. [#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#83238](https://github.com/ClickHouse/ClickHouse/issues/83238): Исправлена деградация производительности при включенном analyzer, когда вторичные запросы всегда читают все столбцы из VIEW. Исправляет [#81718](https://github.com/ClickHouse/ClickHouse/issues/81718). [#83036](https://github.com/ClickHouse/ClickHouse/pull/83036) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#83428](https://github.com/ClickHouse/ClickHouse/issues/83428): Исправлено вводящее в заблуждение сообщение об ошибке при восстановлении резервной копии на диске только для чтения. [#83051](https://github.com/ClickHouse/ClickHouse/pull/83051) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#83197](https://github.com/ClickHouse/ClickHouse/issues/83197): Не выполнять проверку циклических зависимостей при create table без зависимостей. Это устраняет деградацию производительности в сценариях с созданием тысяч таблиц, появившуюся в [https://github.com/ClickHouse/ClickHouse/pull/65405](https://github.com/ClickHouse/ClickHouse/pull/65405). [#83077](https://github.com/ClickHouse/ClickHouse/pull/83077) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#83403](https://github.com/ClickHouse/ClickHouse/issues/83403): Исправлен параметр `no_sign_request` для клиента S3. Его можно использовать, чтобы явно отключить подпись S3-запросов. Его также можно задать для отдельных конечных точек с помощью настроек для конечных точек. [#83379](https://github.com/ClickHouse/ClickHouse/pull/83379) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#83465](https://github.com/ClickHouse/ClickHouse/issues/83465): Исправлено исключение `TOO_DEEP_SUBQUERIES`, возникающее, когда определение CTE ссылается на другое табличное выражение с тем же именем. [#83413](https://github.com/ClickHouse/ClickHouse/pull/83413) ([Dmitry Novik](https://github.com/novikd)).
