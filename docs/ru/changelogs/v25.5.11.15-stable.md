<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#86107](https://github.com/ClickHouse/ClickHouse/issues/86107): Использование `distributed_depth` в качестве индикатора для *Cluster function было некорректным и могло приводить к дублированию данных; вместо него следует использовать `client_info.collaborate_with_initiator`. [#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#86264](https://github.com/ClickHouse/ClickHouse/issues/86264): Исправлена logical error при попытке выполнить `CREATE ... AS (SELECT * FROM s3Cluster(...))` с `DatabaseReplicated`. [#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#86037](https://github.com/ClickHouse/ClickHouse/issues/86037): Исправлена ошибка при восстановлении базы данных `Replicated`: если имя таблицы содержало символ `%`, во время восстановления таблица могла быть создана заново под другим именем. [#85987](https://github.com/ClickHouse/ClickHouse/pull/85987) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#86344](https://github.com/ClickHouse/ClickHouse/issues/86344): Исправлен crash во время ALTER UPDATE Nullable(JSON). [#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
