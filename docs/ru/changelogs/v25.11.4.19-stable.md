  ### Релиз ClickHouse v25.11.4.19-stable (2c64eff7334) FIXME по сравнению с v25.11.3.54-stable (2199c84bef3)

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Бэкпортировано в [#92120](https://github.com/ClickHouse/ClickHouse/issues/92120): Дополнение к [https://github.com/ClickHouse/ClickHouse/pull/88380](https://github.com/ClickHouse/ClickHouse/pull/88380). В этом PR отключение позиционных аргументов в проекциях отмечено как обратно несовместимое изменение. Кроме того, он добавляет настройку `enable_positional_arguments_for_projections`, чтобы обеспечить безопасное обновление кластера ClickHouse при наличии позиционных аргументов в проекциях. [#92007](https://github.com/ClickHouse/ClickHouse/pull/92007) ([Dmitry Novik](https://github.com/novikd)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#92571](https://github.com/ClickHouse/ClickHouse/issues/92571): Улучшено определение использования памяти запросом при выгрузке на диск во время агрегации/сортировки; оно стало более надежным. [#92500](https://github.com/ClickHouse/ClickHouse/pull/92500) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#92530](https://github.com/ClickHouse/ClickHouse/issues/92530): Исправлена возможная logical error в движке Log при чтении подстолбцов. Закрывает [#91710](https://github.com/ClickHouse/ClickHouse/issues/91710). [#91711](https://github.com/ClickHouse/ClickHouse/pull/91711) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92256](https://github.com/ClickHouse/ClickHouse/issues/92256): Добавлен механизм восстановления для JSON с дублирующимися путями в общих данных и динамических путях, что могло происходить из-за ошибки, исправленной в [https://github.com/ClickHouse/ClickHouse/pull/90816](https://github.com/ClickHouse/ClickHouse/pull/90816). [#91886](https://github.com/ClickHouse/ClickHouse/pull/91886) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92555](https://github.com/ClickHouse/ClickHouse/issues/92555): Кэшировать схему только для того файла в глоб-шаблонах, на основе которого она была выведена, а не для всех файлов при выводе схемы. Закрывает [#91745](https://github.com/ClickHouse/ClickHouse/issues/91745). [#92006](https://github.com/ClickHouse/ClickHouse/pull/92006) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92683](https://github.com/ClickHouse/ClickHouse/issues/92683): Освобождать поток запроса в insert select, чтобы избежать закрытия HTTP-соединения. [#92175](https://github.com/ClickHouse/ClickHouse/pull/92175) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#92707](https://github.com/ClickHouse/ClickHouse/issues/92707): Исправлен проход `count_distinct_optimization` по оконным функциям и по нескольким аргументам. [#92376](https://github.com/ClickHouse/ClickHouse/pull/92376) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#92431](https://github.com/ClickHouse/ClickHouse/issues/92431): Исправлен возможный crash в агрегатных функциях после MEMORY&#95;LIMIT&#95;EXCEEDED. [#92390](https://github.com/ClickHouse/ClickHouse/pull/92390) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#92674](https://github.com/ClickHouse/ClickHouse/issues/92674): Наследовать настройки информации о сериализации исходной части во время мутации в MergeTree. Это исправляет возможный некорректный результат запроса по изменённой части после изменений в сериализации типов данных. [#92419](https://github.com/ClickHouse/ClickHouse/pull/92419) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92622](https://github.com/ClickHouse/ClickHouse/issues/92622): Исправлен deadlock для SHOW CREATE DATABASE для базы данных Backup. [#92541](https://github.com/ClickHouse/ClickHouse/pull/92541) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#92665](https://github.com/ClickHouse/ClickHouse/issues/92665): Предотвращён crash в tokens() при NULL во втором аргументе. [#92586](https://github.com/ClickHouse/ClickHouse/pull/92586) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#92743](https://github.com/ClickHouse/ClickHouse/issues/92743): Исправлена ошибка в логике пропуска данных, из-за которой использование `not match(...)` в `WHERE` приводило к некорректным результатам. Закрывает [#92492](https://github.com/ClickHouse/ClickHouse/issues/92492). [#92726](https://github.com/ClickHouse/ClickHouse/pull/92726) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Бэкпортировано в [#92771](https://github.com/ClickHouse/ClickHouse/issues/92771): Не пытаться удалять временные каталоги при запуске, если таблица семейства MergeTree создана на диске только для чтения. [#92748](https://github.com/ClickHouse/ClickHouse/pull/92748) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#92803](https://github.com/ClickHouse/ClickHouse/issues/92803): исправлена ошибка &quot;Невозможно добавить действие в пустую ExpressionActionsChain&quot; для ALTER TABLE REWRITE PARTS (v2). [#92754](https://github.com/ClickHouse/ClickHouse/pull/92754) ([Azat Khuzhin](https://github.com/azat)).
