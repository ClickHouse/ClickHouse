<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#74804](https://github.com/ClickHouse/ClickHouse/issues/74804): устранена проблема безопасности, предотвращающая SQL-инъекции в табличных функциях PostgreSQL и SQLite. [#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#74386](https://github.com/ClickHouse/ClickHouse/issues/74386): исправлена логическая ошибка в s3queue при пометке файла как Failed. [#74216](https://github.com/ClickHouse/ClickHouse/pull/74216) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#74867](https://github.com/ClickHouse/ClickHouse/issues/74867): исправление в Keeper: исправлено чтение записей журнала с диска. [#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### Сборка/Тестирование/Улучшения упаковки
</div>

* Бэкпортировано в [#75285](https://github.com/ClickHouse/ClickHouse/issues/75285): улучшение, задающее ещё более строгие значения по умолчанию. Текущие настройки по умолчанию уже безопасны — чтобы опубликовать порты, пользователь должен явно указать соответствующий параметр. Но если для пользователя `default` не задан пароль через `CLICKHOUSE_PASSWORD` и/или не изменено имя пользователя через переменную окружения `CLICKHOUSE_USER`, он должен быть доступен только с локальной системы в качестве дополнительного уровня защиты. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
