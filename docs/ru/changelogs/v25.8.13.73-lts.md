<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#92306](https://github.com/ClickHouse/ClickHouse/issues/92306): в Https://github.com/clickhouse/clickhouse/pull/84477 были добавлены ограничения на select-запросы, которые можно использовать в запросах `insert select from s3cluster()` для параллельного распределённого выполнения. Это изменение позволяет использовать where, как и раньше. [#84611](https://github.com/ClickHouse/ClickHouse/pull/84611) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#91248](https://github.com/ClickHouse/ClickHouse/issues/91248): Исправлено потенциальное голодание пула потоков при чтении образцов столбцов для JSON-столбцов с большим количеством подстолбцов: теперь учитывается настройка `merge_tree_use_prefixes_deserialization_thread_pool`, а не всегда безусловно используется пул потоков. [#91208](https://github.com/ClickHouse/ClickHouse/pull/91208) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Бэкпортировано в [#92565](https://github.com/ClickHouse/ClickHouse/issues/92565): Повышена надёжность определения использования памяти запросом для spilling to disk во время агрегации/сортировки. [#92500](https://github.com/ClickHouse/ClickHouse/pull/92500) ([Azat Khuzhin](https://github.com/azat)).
