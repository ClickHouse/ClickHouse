<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#108450](https://github.com/ClickHouse/ClickHouse/issues/108450): Исправлено неверное количество строк при использовании `arrayJoin()` внутри `JOIN ON`: результат лишний раз умножался на длину массива. [#104785](https://github.com/ClickHouse/ClickHouse/pull/104785) ([Shaohua Wang](https://github.com/tiandiwonder)).
* Бэкпортировано в [#108263](https://github.com/ClickHouse/ClickHouse/issues/108263): Исправлена ошибка &quot;Too many marks&quot; для text index на пустой слитой части. [#106867](https://github.com/ClickHouse/ClickHouse/pull/106867) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#107911](https://github.com/ClickHouse/ClickHouse/issues/107911): Исправлен сбой (`Source column is not Map` / `SIGSEGV`) при слиянии sorted blocks, содержащих столбец `Variant` с вариантом `Map`, у которого локальный порядок хранения отличается от глобального. [#107011](https://github.com/ClickHouse/ClickHouse/pull/107011) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#108168](https://github.com/ClickHouse/ClickHouse/issues/108168): Исправлено возможное переполнение стека сервера (сбой) при чтении глубоко вложенной схемы или значения в форматах MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg и Paimon. Теперь такой глубоко вложенный вход отклоняется с исключением. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#108226](https://github.com/ClickHouse/ClickHouse/issues/108226): Исправлено переполнение буфера кучи (сбой сервера) в `windowFunnel` при финализации специально сформированного состояния агрегатной функции с типом события вне допустимого диапазона; этой уязвимостью мог воспользоваться любой пользователь, выполнив один `SELECT`. [#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* Бэкпортировано в [#108503](https://github.com/ClickHouse/ClickHouse/issues/108503): Свежий снимок, пересобранный внутри `update()`, уже получает текущие учетные данные C++ S3 client через `createBuilder`; теперь он сохраняется вместо того, чтобы отбрасываться при совпадении version, поэтому следующая операция ядра выполняется на движке со свежими учетными данными и не переживает TTL STS. [#107480](https://github.com/ClickHouse/ClickHouse/pull/107480) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Бэкпортировано в [#108239](https://github.com/ClickHouse/ClickHouse/issues/108239): Добавлены недостающие проверки границ при parsing ELF и DWARF. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#108162](https://github.com/ClickHouse/ClickHouse/issues/108162): Чтение данных Arrow/ArrowStream с пустыми столбцами `String`/`Binary`, созданными в Apache Arrow Java &lt; 19.0.0 (включая Apache Spark), больше не приводит к `INCORRECT_DATA`. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#108208](https://github.com/ClickHouse/ClickHouse/issues/108208): Исправлено поведение, при котором set индекс пропуска данных не отбрасывал granules для столбцов LowCardinality. [#107868](https://github.com/ClickHouse/ClickHouse/pull/107868) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#108308](https://github.com/ClickHouse/ClickHouse/issues/108308): Исправлен сбой (SIGSEGV в release builds, assertion о несоответствии типов в debug builds) в `has` для `Map` с ключом `Dynamic`, когда argument lookup имеет тип `LowCardinality`, например `has(map('a'::Dynamic, ...), toLowCardinality('b'))`. [#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#108398](https://github.com/ClickHouse/ClickHouse/issues/108398): Исправлена регрессия производительности для подстолбцов Map с PREWHERE. Закрывает [#107912](https://github.com/ClickHouse/ClickHouse/issues/107912). Причина: [https://github.com/ClickHouse/ClickHouse/pull/99200](https://github.com/ClickHouse/ClickHouse/pull/99200). [#107988](https://github.com/ClickHouse/ClickHouse/pull/107988) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#108136](https://github.com/ClickHouse/ClickHouse/issues/108136): Исправлена регрессия производительности при чтении столбцов `Dynamic` в несколько потоков. Причина: [https://github.com/ClickHouse/ClickHouse/pull/100730](https://github.com/ClickHouse/ClickHouse/pull/100730). Закрывает [#107942](https://github.com/ClickHouse/ClickHouse/issues/107942). [#107997](https://github.com/ClickHouse/ClickHouse/pull/107997) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#108200](https://github.com/ClickHouse/ClickHouse/issues/108200): Обработчики завершения батча в access cache теперь запускаются всегда, даже для пустого батча. [#108124](https://github.com/ClickHouse/ClickHouse/pull/108124) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#108322](https://github.com/ClickHouse/ClickHouse/issues/108322): Исправлено зависание refreshable materialized view, если соединение с ZooKeeper терялось в неподходящий момент. [#108234](https://github.com/ClickHouse/ClickHouse/pull/108234) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#108485](https://github.com/ClickHouse/ClickHouse/issues/108485): Скрыты секретные аргументы функций, таких как `encrypt`, `decrypt` и `HMAC`, в выводе `EXPLAIN actions`, `EXPLAIN header` и `EXPLAIN PIPELINE`, когда `format_display_secrets_in_show_and_select` отключён (по умолчанию). [#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#108780](https://github.com/ClickHouse/ClickHouse/issues/108780): Исправлена идентификация пользователя по `ssl_certificate`, чтобы один шаблон `*` соответствовал ровно одному компоненту имени (RFC 6125 6.4.3). Ранее шаблон в subject `CN` или `DNS:` SAN (например, `*.corp.example.com`) также соответствовал многометочным именам, таким как `evil.deep.corp.example.com`, что позволяло владельцу сертификата для более глубокого поддомена аутентифицироваться как пользователь с шаблоном. Сопоставление `URI:` SAN не изменилось. [#108472](https://github.com/ClickHouse/ClickHouse/pull/108472) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#108697](https://github.com/ClickHouse/ClickHouse/issues/108697): Исправлено раскрытие метаданных: `DESCRIBE loop('db', 'table')` и `DESCRIBE loop(<inner table function>)` обходили проверку доступа `SHOW COLUMNS` / source, что позволяло непривилегированному пользователю читать схему столбцов таблицы. [#108624](https://github.com/ClickHouse/ClickHouse/pull/108624) ([Groene AI](https://github.com/groeneai)).
