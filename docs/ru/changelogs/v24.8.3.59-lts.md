<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпортировано в [#68710](https://github.com/ClickHouse/ClickHouse/issues/68710): записи кэша запросов теперь можно удалять по тегу. Например, запись кэша запросов, созданную командой `SELECT 1 SETTINGS use_query_cache = true, query_cache_tag = 'abc'`, теперь можно удалить командой `SYSTEM DROP QUERY CACHE TAG 'abc'` (или, разумеется, просто `SYSTEM DROP QUERY CACHE`, чтобы очистить весь кэш запросов). [#68477](https://github.com/ClickHouse/ClickHouse/pull/68477) ([Michał Tabaszewski](https://github.com/pinsvin00)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#68973](https://github.com/ClickHouse/ClickHouse/issues/68973): Исправлена верхняя граница функции `fromModifiedJulianDay`. Она должна была быть `9999-12-31`, но по ошибке была установлена в `9999-01-01`. [#67583](https://github.com/ClickHouse/ClickHouse/pull/67583) ([PHO](https://github.com/depressed-pho)).
* Бэкпортировано в [#68818](https://github.com/ClickHouse/ClickHouse/issues/68818): Исправлено падение при фильтрации Parquet, возникавшее, когда типы данных в файле существенно отличались от запрошенных типов (например, `... FROM file('a.parquet', Parquet, 'x String')`, а в файле `x Int64`). Если это исправление недоступно, в качестве временного обходного решения используйте `input_format_parquet_filter_push_down = 0`. [#68131](https://github.com/ClickHouse/ClickHouse/pull/68131) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#68893](https://github.com/ClickHouse/ClickHouse/issues/68893): После [https://github.com/ClickHouse/ClickHouse/pull/61984](https://github.com/ClickHouse/ClickHouse/pull/61984) значение `schema_inference_make_columns_nullable=0` по-прежнему могло делать столбцы `Nullable` в форматах Parquet/Arrow. Это изменение было обратно несовместимым, и пользователи заметили изменение поведения. Этот PR возвращает прежнее поведение `schema_inference_make_columns_nullable=0` (столбец с типом Nullable больше не будет определяться автоматически) и вводит новое значение `auto` для этой настройки, при котором столбцы будут становиться `Nullable` только если данные содержат информацию о nullable. [#68298](https://github.com/ClickHouse/ClickHouse/pull/68298) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#68721](https://github.com/ClickHouse/ClickHouse/issues/68721): Исправляет [#50868](https://github.com/ClickHouse/ClickHouse/issues/50868). Небольшие константные значения DateTime64, возвращаемые вложенным подзапросом внутри распределённого запроса, ошибочно преобразовывались в NULL, что вызывало ошибки и могло приводить к некорректным результатам запроса. [#68323](https://github.com/ClickHouse/ClickHouse/pull/68323) ([Shankar](https://github.com/shiyer7474)).
* Бэкпортировано в [#69029](https://github.com/ClickHouse/ClickHouse/issues/69029): В distributed таблицы возвращены виртуальные столбцы ` _table` и `_database`. Они были доступны до версии 24.3. [#68672](https://github.com/ClickHouse/ClickHouse/pull/68672) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#68864](https://github.com/ClickHouse/ClickHouse/issues/68864): Исправлена возможная ошибка `Size of permutation (0) is less than required (...)` при перестановке Variant-столбца. [#68681](https://github.com/ClickHouse/ClickHouse/pull/68681) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#68854](https://github.com/ClickHouse/ClickHouse/issues/68854): Исправлена возможная ошибка `DB::Exception: Block structure mismatch in joined block stream: different columns:` с новым JSON-столбцом. [#68686](https://github.com/ClickHouse/ClickHouse/pull/68686) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#68790](https://github.com/ClickHouse/ClickHouse/issues/68790): Исправлена проблема с материализованными константными ключами при хешировании Map с Array в качестве ключей в функциях `sipHash(64/128)Keyed`. [#68731](https://github.com/ClickHouse/ClickHouse/pull/68731) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
