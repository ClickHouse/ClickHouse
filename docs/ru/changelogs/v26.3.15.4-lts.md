<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#108279](https://github.com/ClickHouse/ClickHouse/issues/108279): Исправлено возможное переполнение стека сервера (аварийное завершение) при чтении глубоко вложенной схемы или значения в форматах MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg и Paimon. Теперь такие глубоко вложенные входные данные отклоняются с исключением. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#108237](https://github.com/ClickHouse/ClickHouse/issues/108237): Добавлены недостающие проверки границ при парсинге Elf и DWARF. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#108157](https://github.com/ClickHouse/ClickHouse/issues/108157): Чтение данных Arrow/ArrowStream с пустыми столбцами `String`/`Binary`, созданными Apache Arrow Java &lt; 19.0.0 (включая Apache Spark), больше не приводит к исключению `INCORRECT_DATA`. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
