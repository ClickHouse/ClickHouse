<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#86504](https://github.com/ClickHouse/ClickHouse/issues/86504): добавлена возможность включать JSON-логирование только для определённого канала; для этого задайте `logger.formatting.channel` одним из следующих значений: `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#86112](https://github.com/ClickHouse/ClickHouse/issues/86112): Использование `distributed_depth` как индикатора *функции Cluster было некорректным и могло приводить к дублированию данных; вместо этого используйте `client_info.collaborate_with_initiator`. [#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#86266](https://github.com/ClickHouse/ClickHouse/issues/86266): Исправлена логическая ошибка при попытке выполнить `CREATE ... AS (SELECT * FROM s3Cluster(...))` с `DatabaseReplicated`. [#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#86163](https://github.com/ClickHouse/ClickHouse/issues/86163): Теперь Unity Catalog будет игнорировать схемы со странными типами данных для недельта-таблиц. Исправляет [#85699](https://github.com/ClickHouse/ClickHouse/issues/85699). [#85950](https://github.com/ClickHouse/ClickHouse/pull/85950) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#86291](https://github.com/ClickHouse/ClickHouse/issues/86291): При `FINAL` запросе с индексом пропуска данных возникало Исключение, если таблица (например, `ReplacingMergeTree`) была создана с настройкой `index_granularity_bytes = 0`. Теперь эта проблема исправлена. [#86147](https://github.com/ClickHouse/ClickHouse/pull/86147) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Бэкпортировано в [#86308](https://github.com/ClickHouse/ClickHouse/issues/86308): Исправлен сбой в случае смешивания const и non-const блоков в одном INSERT. [#86230](https://github.com/ClickHouse/ClickHouse/pull/86230) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#86348](https://github.com/ClickHouse/ClickHouse/issues/86348): Исправлен сбой во время ALTER UPDATE Nullable(JSON). [#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#86454](https://github.com/ClickHouse/ClickHouse/issues/86454): Исправлена ошибка в materialized view: MV могла не работать, если её создавали, удаляли, а затем снова создавали с тем же именем. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#86466](https://github.com/ClickHouse/ClickHouse/issues/86466): Исправлена утечка `MergesMutationsMemoryTracking` из-за таблиц `Buffer`, а также исправлен `query_views_log` для стриминга из `Kafka` (и других источников). [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
