<div id="improvement">
  #### Улучшения
</div>

* Бэкпорт в [#82417](https://github.com/ClickHouse/ClickHouse/issues/82417): добавлена поддержка временных меток Unix с дробной частью при best effort-парсинге DateTime64. [#78908](https://github.com/ClickHouse/ClickHouse/pull/78908) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпорт в [#82413](https://github.com/ClickHouse/ClickHouse/issues/82413): хеш-функции теперь поддерживают NULL внутри массивов, кортежей и map. (issues [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) and [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)). [#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпорт в [#81801](https://github.com/ClickHouse/ClickHouse/issues/81801): добавлено событие профиля `PageCacheReadBytes`. [#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпорт в [#82593](https://github.com/ClickHouse/ClickHouse/issues/82593): улучшение Keeper: добавлен новый параметр конфигурации `keeper_server.cleanup_old_and_ignore_new_acl`. Если он включен, ACL будут очищены у всех узлов, а ACL для новых запросов будут игнорироваться. Если цель — полностью удалить ACL с узлов, важно оставить этот параметр включенным до создания нового снимка. [#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпорт в [#82858](https://github.com/ClickHouse/ClickHouse/issues/82858): после [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) формат заголовков `X-ClickHouse-Progress` и `X-ClickHouse-Summary` был изменен так, чтобы опускать нулевые значения. Этот PR возвращает прежнее поведение только для `X-ClickHouse-Summary`, поскольку это выглядит более логично. [#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпорт в [#82924](https://github.com/ClickHouse/ClickHouse/issues/82924): улучшение Keeper: добавлена поддержка отдельных разрешений для ACL `world:anyone`. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (заметное пользователю некорректное поведение в официальном стабильном релизе)
</div>

* Бэкпортировано в [#82185](https://github.com/ClickHouse/ClickHouse/issues/82185): Исправлена логическая ошибка при материализации проекции, когда тип столбца был изменён на Nullable. [#80741](https://github.com/ClickHouse/ClickHouse/pull/80741) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#81811](https://github.com/ClickHouse/ClickHouse/issues/81811): Исправлена ошибка `Table does not exist` для распределённых запросов с протолкнутым предикатом (`allow_push_predicate_ast_for_distributed_subqueries=1`), когда исходная таблица отсутствует на инициаторе. Исправляет [#77281](https://github.com/ClickHouse/ClickHouse/issues/77281). [#80915](https://github.com/ClickHouse/ClickHouse/pull/80915) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#82014](https://github.com/ClickHouse/ClickHouse/issues/82014): Исправлен `Unknown table expression identifier` для `distributed_product_mode_local=local` при перекрёстной репликации. [#81162](https://github.com/ClickHouse/ClickHouse/pull/81162) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#82330](https://github.com/ClickHouse/ClickHouse/issues/82330): Исправлено выполнение `IN` с `transform_null_in=1` при NULL в левом аргументе и результате подзапроса без Nullable. [#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#82175](https://github.com/ClickHouse/ClickHouse/issues/82175): Отключена проверка экспериментальных/подозрительных типов при выполнении выражений default/materialize во время чтения из существующей таблицы. [#81618](https://github.com/ClickHouse/ClickHouse/pull/81618) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#82124](https://github.com/ClickHouse/ClickHouse/issues/82124): Исправлен `Context has expired` во время слияний, когда словарь использовался в TTL-выражении. [#81690](https://github.com/ClickHouse/ClickHouse/pull/81690) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#82323](https://github.com/ClickHouse/ClickHouse/issues/82323): В предыдущих версиях сервер возвращал избыточное содержимое для запросов к `/js`. Это закрывает [#61890](https://github.com/ClickHouse/ClickHouse/issues/61890). [#81895](https://github.com/ClickHouse/ClickHouse/pull/81895) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#82235](https://github.com/ClickHouse/ClickHouse/issues/82235): Ранее определения движка таблицы `MongoDB` могли включать компонент path в аргументе `host:port`, который молча игнорировался. Интеграция MongoDB отказывается загружать такие таблицы. С этим исправлением *мы разрешаем загружать такие таблицы и игнорируем компонент path*, если движок `MongoDB` имеет пять аргументов, используя имя database из аргументов. *Note:* Исправление не применяется к вновь создаваемым таблицам или запросам с table function `mongo`, а также к источникам словарей и именованным коллекциям. [#81942](https://github.com/ClickHouse/ClickHouse/pull/81942) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#82777](https://github.com/ClickHouse/ClickHouse/issues/82777): Исправлен анализ фильтра, когда в запросе используется только константный столбец-алиас. Исправляет [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448). [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#82550](https://github.com/ClickHouse/ClickHouse/issues/82550): Исправлены LOGICAL&#95;ERROR и последующий сбой при использовании одного и того же столбца в TTL для GROUP BY и SET. [#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#82153](https://github.com/ClickHouse/ClickHouse/issues/82153): Исправлена ошибка копирования/вставки в arraySimilarity, запрещено использование весов UInt32 и Int32. Обновлены тесты и документация. [#82103](https://github.com/ClickHouse/ClickHouse/pull/82103) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#82316](https://github.com/ClickHouse/ClickHouse/issues/82316): Исправлена ошибка `Not found column` для запросов с `arrayJoin` в условии `WHERE` и `IndexSet`. [#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#82558](https://github.com/ClickHouse/ClickHouse/issues/82558): Исправлена возможная взаимная блокировка для удалённых запросов, когда сервер испытывает нехватку памяти. [#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* Бэкпортировано в [#82521](https://github.com/ClickHouse/ClickHouse/issues/82521): Для токена AWS ECS добавлен срок действия, чтобы его можно было перезагружать. [#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#82577](https://github.com/ClickHouse/ClickHouse/issues/82577): Исправлено скрытие значений именованной коллекции в logs/query&#95;log. Закрывает [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405). [#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#82568](https://github.com/ClickHouse/ClickHouse/issues/82568): Исправлен возможный сбой в logging при завершении сеанса, так как user&#95;id иногда может быть пустым. [#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
* Бэкпортировано в [#82686](https://github.com/ClickHouse/ClickHouse/issues/82686): Исправлен `LOGICAL_ERROR` при анализе выражения ROW POLICY для коррелированных столбцов. [#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#82733](https://github.com/ClickHouse/ClickHouse/issues/82733): Функции `trim{Left,Right,Both}` теперь поддерживают входные строки типа &quot;FixedString(N)&quot;. Например, `SELECT trimBoth(toFixedString('abc', 3), 'ac')` теперь работает. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#82798](https://github.com/ClickHouse/ClickHouse/issues/82798): Исправлена десериализация `groupArraySample`/`groupArrayLast` в случае пустых элементов (десериализация могла пропустить часть бинарных данных, если входные данные были пустыми; это может привести к повреждению данных при чтении и к UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER в протоколе TCP). Это не затрагивает числовые типы и типы дата-время. [#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
