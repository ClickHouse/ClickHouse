<div id="improvement">
  #### Улучшения
</div>

* Выполнен бэкпорт в [#78853](https://github.com/ClickHouse/ClickHouse/issues/78853): теперь для ошибок при отправке в materialized view для StorageS3(Azure)Queue учитывается ограничение `loading_retries`. Ранее такие ошибки повторялись бесконечно. [#78313](https://github.com/ClickHouse/ClickHouse/pull/78313) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Выполнен бэкпорт в [#82411](https://github.com/ClickHouse/ClickHouse/issues/82411): хеш-функции теперь поддерживают NULL внутри массивов, кортежей и Map. (issues [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) и [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)). [#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* Выполнен бэкпорт в [#81612](https://github.com/ClickHouse/ClickHouse/issues/81612): используется `orc` 2.1.2. [#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Выполнен бэкпорт в [#81697](https://github.com/ClickHouse/ClickHouse/issues/81697): используется `grpc` 1.73.0. [#81629](https://github.com/ClickHouse/ClickHouse/pull/81629) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Выполнен бэкпорт в [#82592](https://github.com/ClickHouse/ClickHouse/issues/82592): улучшение Keeper: добавлен новый параметр конфигурации `keeper_server.cleanup_old_and_ignore_new_acl`. Если он включен, у всех узлов будут очищены ACL, а ACL для новых запросов будут игнорироваться. Если цель — полностью удалить ACL с узлов, важно оставить этот параметр включенным до создания нового снимка. [#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* Выполнен бэкпорт в [#82922](https://github.com/ClickHouse/ClickHouse/issues/82922): улучшение Keeper: добавлена поддержка отдельных разрешений для ACL world:anyone. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Выполнен бэкпорт в [#82328](https://github.com/ClickHouse/ClickHouse/issues/82328): Исправлено выполнение `IN` с `transform_null_in=1`, когда левый аргумент содержит NULL, а результат подзапроса не имеет типа Nullable. [#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* Выполнен бэкпорт в [#82775](https://github.com/ClickHouse/ClickHouse/issues/82775): Исправлен анализ фильтра, когда в запросе используется только константный столбец-алиас. Исправляет [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448). [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* Выполнен бэкпорт в [#82548](https://github.com/ClickHouse/ClickHouse/issues/82548): Исправлены LOGICAL&#95;ERROR и последующий сбой при использовании одного и того же столбца в TTL для GROUP BY и SET. [#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* Выполнен бэкпорт в [#82314](https://github.com/ClickHouse/ClickHouse/issues/82314): Исправлена ошибка `Not found column` для запросов с `arrayJoin` в условии `WHERE` и `IndexSet`. [#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Выполнен бэкпорт в [#82557](https://github.com/ClickHouse/ClickHouse/issues/82557): Исправлена возможная взаимная блокировка для удалённых запросов, когда сервер испытывает нехватку памяти. [#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* Выполнен бэкпорт в [#82519](https://github.com/ClickHouse/ClickHouse/issues/82519): Для токена AWS ECS добавлен срок действия, чтобы его можно было перезагружать. [#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Выполнен бэкпорт в [#82575](https://github.com/ClickHouse/ClickHouse/issues/82575): Исправлено скрытие значений именованной коллекции в logs/query&#95;log. Закрывает [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405). [#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Выполнен бэкпорт в [#82566](https://github.com/ClickHouse/ClickHouse/issues/82566): Исправлен возможный сбой в logging при завершении сеанса, так как `user_id` иногда может быть пустым. [#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
* Выполнен бэкпорт в [#82731](https://github.com/ClickHouse/ClickHouse/issues/82731): Functions `trim{Left,Right,Both}` теперь поддерживают входные строки типа &quot;FixedString(N)&quot;. Например, `SELECT trimBoth(toFixedString('abc', 3), 'ac')` теперь работает. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
