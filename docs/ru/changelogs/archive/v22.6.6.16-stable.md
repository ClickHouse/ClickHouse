<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Исправление ошибки (заметное для пользователей некорректное поведение в официальном стабильном релизе)
</div>

* Бэкпортировано в [#40162](https://github.com/ClickHouse/ClickHouse/issues/40162): исправлена ошибка, из-за которой HashMethodOneNumber возвращал неверное значение key, когда столбец был const. [#40020](https://github.com/ClickHouse/ClickHouse/pull/40020) ([Duc Canh Le](https://github.com/canhld94)).
* Бэкпортировано в [#40124](https://github.com/ClickHouse/ClickHouse/issues/40124): исправлена ошибка в collectFilesToSkip() — добавлены правильные расширения файлов (.idx или idx2) для индексов, подлежащих пересчёту, чтобы избежать некорректных hard links. Исправлено [#39896](https://github.com/ClickHouse/ClickHouse/issues/39896). [#40095](https://github.com/ClickHouse/ClickHouse/pull/40095) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Бэкпортировано в [#40209](https://github.com/ClickHouse/ClickHouse/issues/40209): исправлена недостаточная проверка аргументов в функциях шифрования (обнаружено query fuzzer). Это закрывает [#39987](https://github.com/ClickHouse/ClickHouse/issues/39987). [#40194](https://github.com/ClickHouse/ClickHouse/pull/40194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#40281](https://github.com/ClickHouse/ClickHouse/issues/40281): исправлен возможный segfault во входном формате CapnProto. Эта ошибка была обнаружена и отправлена через ClickHouse bug-bounty [program](https://github.com/ClickHouse/ClickHouse/issues/38986) пользователем *kiojj*. [#40241](https://github.com/ClickHouse/ClickHouse/pull/40241) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#40489](https://github.com/ClickHouse/ClickHouse/issues/40489): исправлена редкая ошибка с TTL столбца в семействе движков MergeTree: при повторном Вертикальном слиянии могла возникать ошибка `Cannot unlink file ColumnName.bin ... No such file or directory.`. [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
