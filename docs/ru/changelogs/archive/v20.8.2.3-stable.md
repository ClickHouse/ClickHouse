  ### Релиз ClickHouse v20.8.2.3-stable FIXME по сравнению с v20.7.1.4310-prestable
</div>

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Удалена поддержка формата ввода/вывода `ODBCDriver`. Это устаревший формат, который когда-то использовался для взаимодействия с ODBC-драйвером ClickHouse, но уже давно был заменён форматом `ODBCDriver2`. Исправлено в [#13629](https://github.com/ClickHouse/ClickHouse/issues/13629). [#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting)).
* Расширена настройка `parallel_distributed_insert_select`: добавлена возможность выполнять `INSERT` в локальную таблицу. Тип настройки изменён с `Bool` на `UInt64`, поэтому значения `false` и `true` больше не поддерживаются. Если эти значения указаны в конфигурации сервера, сервер не запустится. Пожалуйста, замените их на `0` и `1` соответственно. [#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat)).
* Теперь запрос `OPTIMIZE FINAL` не пересчитывает TTL для частей, добавленных до создания TTL. Используйте `ALTER TABLE ... MATERIALIZE TTL` один раз, чтобы вычислить их; после этого `OPTIMIZE FINAL` будет корректно обрабатывать TTL. Это поведение никогда не работало для реплицированных таблиц. [#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена поддержка движка базы данных `MaterializeMySQL`. Реализует [#4006](https://github.com/ClickHouse/ClickHouse/issues/4006). [#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена поддержка аутентификации Kerberos в Kafka с использованием библиотек `krb5` и `cyrus-sasl`. [#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn)).
* Добавлены типы `Int128`, `Int256`, `UInt256` и соответствующие функции для них. Семейство Decimal расширено типом Decimal256 (точность до 76 знаков). Новые типы доступны через настройку `allow_experimental_bigint_types`. [#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2)).
* Функция `position` теперь поддерживает необязательный аргумент `start_pos`. [#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir)).
* Добавлен оператор `ALTER SAMPLE BY`, позволяющий изменить предложение выборки таблицы. [#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird)).
* Добавлен новый необязательный раздел <user_directories> в основной конфигурационный файл. [#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar)).
* Добавлена функция `normalizeQuery`, заменяющая литералы, последовательности литералов и сложные псевдонимы плейсхолдерами. Добавлена функция `normalizedQueryHash`, возвращающая одинаковые 64-битные хеш-значения для похожих запросов. Это упрощает анализ журнала запросов. Закрывает [#11271](https://github.com/ClickHouse/ClickHouse/issues/11271). [#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлены реализации `quantileExactLow` и `quantileExactHigh` с соответствующими псевдонимами `medianExactLow` и `medianExactHigh`. [#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc)).
* Добавлена функция `defaultValueOfTypeName`, возвращающая значение по умолчанию для указанного типа. [#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz)).
* Добавлена функция `date_trunc`, усекающая значение даты/времени до указанной части даты/времени. [#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* Добавлена возможность указывать кодек сжатия `Default` для столбцов, соответствующих настройкам, заданным в `config.xml`. Реализует: [#9074](https://github.com/ClickHouse/ClickHouse/issues/9074). [#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin)).
* Добавлена настройка `min_index_granularity_bytes`, защищающая от случайного создания таблицы со слишком низким значением настройки `index_granularity_bytes`. [#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc)).
* Добавлена функция `countDigits(x)`, подсчитывающая количество десятичных цифр в целочисленном или десятичном столбце. Добавлена функция `isDecimalOverflow(d, [p])`, проверяющая, выходит ли значение в столбце Decimal за пределы его (или указанной) точности. [#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* При выполнении простых запросов `INSERT SELECT` автоматически устанавливаются `max_threads` в 1 или `max_insert_threads`, а `max_block_size` — в `min_insert_block_size_rows`. Связано с [#5907](https://github.com/ClickHouse/ClickHouse/issues/5907). [#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* Оптимизированы функции `has()`, `indexOf()` и `countEqual()` для `Array(LowCardinality(T))` и константных аргументов справа. [#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* Незначительно повышена производительность агрегации по ключам UInt8/UInt16. [#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлено быстрое завершение, если при сканировании частей превышен лимит `max_rows_to_read`. Цель этого изменения — пропускать сканирование диапазонов для всех выбранных частей, если уже ясно, что `max_rows_to_read` уже превышен. Это изменение особенно заметно для запросов по большому числу частей. [#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* Включена поддержка параллельных INSERT для движков таблиц `Null`, `Memory`, `Distributed` и `Buffer`. [#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Незначительно оптимизировано выполнение очень коротких запросов с LowCardinality. [#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).
