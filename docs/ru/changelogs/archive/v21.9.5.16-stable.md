* Бэкпортировано в [#29897](https://github.com/ClickHouse/ClickHouse/issues/29897): В запрос для получения индекса replica identity добавлен префикс &#39;p&#39; для партиционированной таблицы. [#29828](https://github.com/ClickHouse/ClickHouse/pull/29828) ([Shoh Jahon](https://github.com/Shohjahon)).
* Бэкпортировано в [#29943](https://github.com/ClickHouse/ClickHouse/issues/29943): Файлы zoneinfo обновлены до версии 2021c. [#29925](https://github.com/ClickHouse/ClickHouse/pull/29925) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#29775](https://github.com/ClickHouse/ClickHouse/issues/29775): Разрешено использовать материализованный столбец в качестве ключа сегментирования в distributed таблице, даже если `insert_allow_materialized_columns=0`:. [#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#29126](https://github.com/ClickHouse/ClickHouse/issues/29126): Исправлена ошибка в `clickhouse-keeper-converter`, которая может приводить к некорректной десериализации лога ZooKeeper. [#29071](https://github.com/ClickHouse/ClickHouse/pull/29071) ([小路](https://github.com/nicelulu)).
* Бэкпортировано в [#29972](https://github.com/ClickHouse/ClickHouse/issues/29972): Исправлено завершение работы `AccessControlManager`. Теперь после уничтожения `AccessControlManager` конфигурация больше не может быть перезагружена. Этот PR исправляет нестабильный тест [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html). [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#30052](https://github.com/ClickHouse/ClickHouse/issues/30052): Исправлено освобождение query ID и session ID в конце обработки запроса при обработке gRPC-вызова. Этот PR исправляет нестабильный тест [test&#95;grpc&#95;protocol/test.py::test&#95;session](https://clickhouse-test-reports.s3.yandex.net/0/1ac03811a2df9717fa7c633d1af03def821d24b6/integration_tests_\(memory\).html). [#29954](https://github.com/ClickHouse/ClickHouse/pull/29954) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#29055](https://github.com/ClickHouse/ClickHouse/issues/29055): Исправлено некорректное преобразование типа константы при использовании nullable или lowcardinality primary key. [#28636](https://github.com/ClickHouse/ClickHouse/pull/28636) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#29107](https://github.com/ClickHouse/ClickHouse/issues/29107): Исправлено ожидание мутации с `mutations_sync=2`. [#28889](https://github.com/ClickHouse/ClickHouse/pull/28889) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29815](https://github.com/ClickHouse/ClickHouse/issues/29815): Запрещено повторно использовать ранее заданные учетные данные в случае inter-server secret (раньше при INSERT через Buffer/Kafka в distributed таблицу с interserver secret, настроенным для этого кластера, для этого соединения мог повторно использоваться ранее заданный пользователь). [#29060](https://github.com/ClickHouse/ClickHouse/pull/29060) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29399](https://github.com/ClickHouse/ClickHouse/issues/29399): Клиенту (через TCP) теперь отправляется стандартная ошибка `Database doesn't exist error` (`UNKNOWN_DATABASE`) вместо `Attempt to read after eof` (`ATTEMPT_TO_READ_AFTER_EOF`). [#29229](https://github.com/ClickHouse/ClickHouse/pull/29229) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29356](https://github.com/ClickHouse/ClickHouse/issues/29356): Исправлено возможное исключение `Table columns structure in ZooKeeper is different from local table structure` при пересоздании или создании новых реплик `ReplicatedMergeTree`, если у одного из столбцов таблицы есть выражения по умолчанию с регистронезависимыми функциями. [#29266](https://github.com/ClickHouse/ClickHouse/pull/29266) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#29451](https://github.com/ClickHouse/ClickHouse/issues/29451): Исправлен сбой проверки assert в ReadBufferFromHDFS. Библиотека libhdfs3 обновлена, чтобы её можно было запускать в тестах в режиме debug. Закрывает [#29251](https://github.com/ClickHouse/ClickHouse/issues/29251). Закрывает [#27814](https://github.com/ClickHouse/ClickHouse/issues/27814). [#29276](https://github.com/ClickHouse/ClickHouse/pull/29276) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#29301](https://github.com/ClickHouse/ClickHouse/issues/29301): Исправлены тайм-ауты соединения (`send_timeout`/`receive_timeout`). [#29282](https://github.com/ClickHouse/ClickHouse/pull/29282) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29383](https://github.com/ClickHouse/ClickHouse/issues/29383): Удалена window function `nth_value`, так как она небезопасна с точки зрения использования памяти. Это закрывает [#29347](https://github.com/ClickHouse/ClickHouse/issues/29347). [#29348](https://github.com/ClickHouse/ClickHouse/pull/29348) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#29438](https://github.com/ClickHouse/ClickHouse/issues/29438): Исправлено некорректное завершение работы replicated access storage при ошибочной конфигурации. [#29388](https://github.com/ClickHouse/ClickHouse/pull/29388) ([Kevin Michel](https://github.com/kmichel-aiven)).
* Бэкпортировано в [#29489](https://github.com/ClickHouse/ClickHouse/issues/29489): Исправлена logical error `Cannot capture columns` в функциях greatest/least. Закрывает [#29334](https://github.com/ClickHouse/ClickHouse/issues/29334). [#29454](https://github.com/ClickHouse/ClickHouse/pull/29454) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#29536](https://github.com/ClickHouse/ClickHouse/issues/29536): исправлено возможное несоответствие структуры блоков (`Block structure mismatch`) в подзапросах с протолкнутым вниз предикатом `HAVING`. Исправляет [#29010](https://github.com/ClickHouse/ClickHouse/issues/29010). [#29475](https://github.com/ClickHouse/ClickHouse/pull/29475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#29592](https://github.com/ClickHouse/ClickHouse/issues/29592): в мост ODBC добавлены повторные попытки для ошибки Invalid cursor state. Это ошибка, допускающая повторную попытку. Закрывает [#29473](https://github.com/ClickHouse/ClickHouse/issues/29473). [#29518](https://github.com/ClickHouse/ClickHouse/pull/29518) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#29572](https://github.com/ClickHouse/ClickHouse/issues/29572): исправлена ошибка в проверке `pathStartsWith`, вызванная некорректным использованием `std::mismatch`: ` The behavior is undefined if the second range is shorter than the first range.`. [#29531](https://github.com/ClickHouse/ClickHouse/pull/29531) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#29630](https://github.com/ClickHouse/ClickHouse/issues/29630): исправлен редкий segfault в запросе `ALTER MODIFY` при использовании некорректного идентификатора таблицы в выражении `DEFAULT`, например `x.y.z...`. Исправляет [#29184](https://github.com/ClickHouse/ClickHouse/issues/29184). [#29573](https://github.com/ClickHouse/ClickHouse/pull/29573) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#29658](https://github.com/ClickHouse/ClickHouse/issues/29658): исправлена JIT-компиляция выражений с псевдонимами и вычислением выражений с коротким замыканием. Закрывает [#29403](https://github.com/ClickHouse/ClickHouse/issues/29403). [#29574](https://github.com/ClickHouse/ClickHouse/pull/29574) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#29751](https://github.com/ClickHouse/ClickHouse/issues/29751): после оптимизации push-down могло теряться условие в предикате фильтра. [#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#29849](https://github.com/ClickHouse/ClickHouse/issues/29849): исправлен одновременный доступ к `LowCardinality` во время `GROUP BY` (приводивший к SIGSEGV). [#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29909](https://github.com/ClickHouse/ClickHouse/issues/29909): исправлено некорректное приведение типов в запросе `ATTACH TABLE ... FROM 'path'`, когда вместо пути используется нестроковый литерал. Это могло приводить к чтению неинициализированной памяти. [#29790](https://github.com/ClickHouse/ClickHouse/pull/29790) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#29865](https://github.com/ClickHouse/ClickHouse/issues/29865): предотвращена ошибка `Timeout exceeded: elapsed 18446744073.709553 seconds`, которая в крайне редких случаях могла возникать, предположительно из-за ошибки в ядре. Исправляет [#29154](https://github.com/ClickHouse/ClickHouse/issues/29154). [#29811](https://github.com/ClickHouse/ClickHouse/pull/29811) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#30024](https://github.com/ClickHouse/ClickHouse/issues/30024): MaterializedMySQL: исправлена проблема, из-за которой при потере соединения с MySQL могла быть обработана только часть транзакции. [#29837](https://github.com/ClickHouse/ClickHouse/pull/29837) ([Håvard Kvålen](https://github.com/havardk)).
* Бэкпортировано в [#29878](https://github.com/ClickHouse/ClickHouse/issues/29878): Исправлена проверка пересоздания системных таблиц (не обнаруживались изменения в значениях enum). [#29857](https://github.com/ClickHouse/ClickHouse/pull/29857) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#30057](https://github.com/ClickHouse/ClickHouse/issues/30057): Исправлена потенциальная утечка ресурсов в механизме concurrent query limit для таблиц MergeTree, добавленном в [https://github.com/ClickHouse/ClickHouse/pull/19544](https://github.com/ClickHouse/ClickHouse/pull/19544). [#29879](https://github.com/ClickHouse/ClickHouse/pull/29879) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#30204](https://github.com/ClickHouse/ClickHouse/issues/30204): Исправлена гонка данных между `LogSink::writeMarks()` и `LogSource` в `StorageLog`. [#29946](https://github.com/ClickHouse/ClickHouse/pull/29946) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#30209](https://github.com/ClickHouse/ClickHouse/issues/30209): Исправлена возможная гонка данных между `FileChecker` и `StorageLog`/`StorageStripeLog`. [#29959](https://github.com/ClickHouse/ClickHouse/pull/29959) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#30070](https://github.com/ClickHouse/ClickHouse/issues/30070): Исправлен сбой при использовании sample с `tuple()`, закрывает [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004).
