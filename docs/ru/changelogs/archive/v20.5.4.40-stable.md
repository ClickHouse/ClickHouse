  ### Релиз ClickHouse v20.5.4.40-stable FIXME по сравнению с v20.5.3.27-stable
</div>

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#12929](https://github.com/ClickHouse/ClickHouse/issues/12929): исправлена регрессия производительности, появившаяся примерно в v19.3: &quot;[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) Индекс не используется для оператора IN с литералами&quot;. [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#12830](https://github.com/ClickHouse/ClickHouse/issues/12830): Исправлена проблема с производительностью запросов SELECT с `UNION`, вызванная неверным ограничением на общее число потоков. Исправляет [#12030](https://github.com/ClickHouse/ClickHouse/issues/12030). [#12103](https://github.com/ClickHouse/ClickHouse/pull/12103) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#12836](https://github.com/ClickHouse/ClickHouse/issues/12836): Исправлено поведение движка `SummingMergeTree`, который суммировал столбцы из ключа партиционирования. Добавлено исключение на случай явного определения суммируемых столбцов, пересекающихся со столбцами ключа партиционирования. Это исправляет [#7867](https://github.com/ClickHouse/ClickHouse/issues/7867). [#12173](https://github.com/ClickHouse/ClickHouse/pull/12173) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#12833](https://github.com/ClickHouse/ClickHouse/issues/12833): Исправлено поведение, при котором во время нескольких последовательных вставок в `StorageFile` заголовок для некоторых специальных типов записывался более одного раза. Это исправило [#6155](https://github.com/ClickHouse/ClickHouse/issues/6155). [#12197](https://github.com/ClickHouse/ClickHouse/pull/12197) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#12895](https://github.com/ClickHouse/ClickHouse/issues/12895): Kafka: исправлен SIGSEGV, возникавший, если в середине батча есть сообщение с ошибкой. [#12302](https://github.com/ClickHouse/ClickHouse/pull/12302) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#12905](https://github.com/ClickHouse/ClickHouse/issues/12905): Исправлены TOTALS/ROLLUP/CUBE для агрегатных функций с аргументами `-State` и `Nullable`. Это исправляет [#12163](https://github.com/ClickHouse/ClickHouse/issues/12163). [#12376](https://github.com/ClickHouse/ClickHouse/pull/12376) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#12907](https://github.com/ClickHouse/ClickHouse/issues/12907): Разрешено выполнять CLEAR для столбца, даже если существуют зависящие от него выражения DEFAULT. Это исправляет [#12333](https://github.com/ClickHouse/ClickHouse/issues/12333). [#12378](https://github.com/ClickHouse/ClickHouse/pull/12378) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#12909](https://github.com/ClickHouse/ClickHouse/issues/12909): Предотвращено исключение при использовании отрицательной константы или константы с плавающей точкой в условии предложения WHERE для таблиц с индексами. Это исправляет [#11905](https://github.com/ClickHouse/ClickHouse/issues/11905). [#12384](https://github.com/ClickHouse/ClickHouse/pull/12384) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#12897](https://github.com/ClickHouse/ClickHouse/issues/12897): Исправлено падение в JOIN со словарём, когда JOIN выполняется по выражению ключа словаря: `t JOIN dict ON expr(dict.id) = t.id`. Для этого случая отключена оптимизация JOIN со словарём. [#12458](https://github.com/ClickHouse/ClickHouse/pull/12458) ([Artem Zuikov](https://github.com/4ertus2)).
* Бэкпортировано в [#13004](https://github.com/ClickHouse/ClickHouse/issues/13004): Исправлена проблема с производительностью при чтении из компактных частей. [#12492](https://github.com/ClickHouse/ClickHouse/pull/12492) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#12892](https://github.com/ClickHouse/ClickHouse/issues/12892): Исправлено состояние гонки в таблицах Live View, которое могло приводить к дублированию данных. [#12519](https://github.com/ClickHouse/ClickHouse/pull/12519) ([vzakaznikov](https://github.com/vzakaznikov)).
* Бэкпортировано в [#12888](https://github.com/ClickHouse/ClickHouse/issues/12888): Теперь ClickHouse будет пересчитывать контрольные суммы для частей, если файл `checksums.txt` отсутствует. Ошибка присутствует с [#9827](https://github.com/ClickHouse/ClickHouse/issues/9827). [#12545](https://github.com/ClickHouse/ClickHouse/pull/12545) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#12873](https://github.com/ClickHouse/ClickHouse/issues/12873): Исправлена ошибка `Output of TreeExecutor is not sorted` для `OPTIMIZE DEDUPLICATE`. Исправляет [#11572](https://github.com/ClickHouse/ClickHouse/issues/11572). [#12613](https://github.com/ClickHouse/ClickHouse/pull/12613) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#12885](https://github.com/ClickHouse/ClickHouse/issues/12885): Исправлена возможная ошибка `Pipeline stuck` в запросах с внешней сортировкой. Исправляет [#12617](https://github.com/ClickHouse/ClickHouse/issues/12617). [#12618](https://github.com/ClickHouse/ClickHouse/pull/12618) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#12876](https://github.com/ClickHouse/ClickHouse/issues/12876): Улучшено сообщение об исключении в хранилище доступа к диску. [#12625](https://github.com/ClickHouse/ClickHouse/pull/12625) ([alesapin](https://github.com/alesapin)).

UPDATE` в неожиданных случаях (например, при вычитании из столбца UInt64). Исправляет [#7306](https://github.com/ClickHouse/ClickHouse/issues/7306). Исправляет [#4165](https://github.com/ClickHouse/ClickHouse/issues/4165). [#12633](https://github.com/ClickHouse/ClickHouse/pull/12633) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#12879](https://github.com/ClickHouse/ClickHouse/issues/12879): Добавлена поддержка функции `if` с аргументами `Array(UUID)`. Исправляет [#11066](https://github.com/ClickHouse/ClickHouse/issues/11066). [#12648](https://github.com/ClickHouse/ClickHouse/pull/12648) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
