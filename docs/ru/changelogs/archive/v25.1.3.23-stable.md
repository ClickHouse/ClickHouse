<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#75311](https://github.com/ClickHouse/ClickHouse/issues/75311): Исправлено аварийное завершение при разборе объявления JSON type, когда имя типа указано не в верхнем регистре. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75253](https://github.com/ClickHouse/ClickHouse/issues/75253): Если операция remove завершилась неудачно, состояние части возвращается из deleting обратно в устаревший. [#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#75409](https://github.com/ClickHouse/ClickHouse/issues/75409): Исправлено использование индексов (основного и вторичного) для столбцов `Array`, `Map` и `Nullable(..)` при включенном параметре `optimize_function_to_subcolumns`. Ранее индексы для этих столбцов могли игнорироваться. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#75461](https://github.com/ClickHouse/ClickHouse/issues/75461): Исправлена ошибка, приводившая к аварийному завершению при использовании CTE с Insert. [#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#75291](https://github.com/ClickHouse/ClickHouse/issues/75291): улучшены ещё более строгие настройки по умолчанию. Текущие значения по умолчанию и так безопасны — чтобы явно опубликовать порты, пользователь должен указать соответствующую опцию. Но если для пользователя `default` не задан пароль через переменную окружения `CLICKHOUSE_PASSWORD` и/или не изменено имя пользователя через переменную окружения `CLICKHOUSE_USER`, он в качестве дополнительной меры защиты должен быть доступен только из локальной системы. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
