<div id="clickhouse-release-v20614066-prestable-fixme-as-compared-to-v20513833-prestable">
  ### Релиз ClickHouse v20.6.1.4066-prestable FIXME по сравнению с версией v20.5.1.3833-prestable
</div>

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* `clickhouse-local` теперь по умолчанию использует уникальный временный каталог данных вместо текущего каталога, как было раньше. При необходимости каталог данных можно явно указать с помощью параметра `-- --path`. [#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена поддержка `Alter table drop replica replica_name`. Это исправляет [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* Добавлен новый in-memory формат частей для таблиц семейства `MergeTree`, в котором данные хранятся в памяти. Части записываются на диск при первом слиянии. Часть создается в in-memory формате, если ее размер в строках или байтах меньше порогов `min_rows_for_compact_part` и `min_bytes_for_compact_part`. Также доступна необязательная поддержка Write-Ahead-Log, которая включена по умолчанию и управляется настройкой `in_memory_parts_enable_wal`. [#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* Добавлен комбинатор -Distinct для агрегатных функций. [#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* Добавлена поддержка движка таблицы mongo(host:port, database, collection, user, password). [#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* Добавлено хранилище RabbitMQ. [#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлены настройки для явного включения отправки отчетов о сбоях команде разработки ClickHouse через [Sentry](https://sentry.io). [#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* Добавлен ORCBlockOutputFormat. [#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* Параметр конфигурации `max_thread_pool_size` для изменения максимального числа потоков в Global Thread Pool. [#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* Начальная реализация запроса `EXPLAIN`. Синтаксис: `EXPLAIN SELECT ...`. Это исправляет [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118). [#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Пути в метаданных S3 сделаны относительными, что упрощает работу с blob-объектами S3. [#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Добавлена поддержка ввода/вывода UUID в Avro. [#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Добавлен движок таблицы MongoDB в режиме только для чтения. Он позволяет читать плоские поля (примитивные типы, не Nested). [#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* Добавлена настройка для полей, отсутствующих в схеме Avro. [#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Добавлена функция `parseDateTimeBestEffortUS`. [#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 Добавлена поддержка ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST. [#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена функция initializedAggregation для инициализации агрегации по одному значению. [#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* Добавлена поддержка RIGHT и FULL JOIN с `set join_algorithm=partial_merge`. Поддерживается только strictness ALL (ANY, SEMI, ANTI, ASOF не поддерживаются). [#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* Реализован оператор ILIKE, аналогичный PostgreSQL, для [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710). [#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc)).
* Разрешено использовать типы Nullable в качестве ключей в таблицах семейства MergeTree. [#5319](https://github.com/ClickHouse/ClickHouse/issues/5319). [#12433](https://github.com/ClickHouse/ClickHouse/pull/12433) ([Amos Bird](https://github.com/amosbird)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Разрешено использовать direct&#95;io и mmap&#95;io для вторичных индексов, если заданы настройки `min_bytes_to_use_direct_io` или `min_bytes_to_use_mmap_io`. [#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлена оценка количества меток при чтении из MergeTree. Это необходимо для корректной обработки настроек `merge_tree_max_rows_to_use_cache`, `merge_tree_max_bytes_to_use_cache`, `merge_tree_min_rows_for_concurrent_read`, `merge_tree_min_bytes_for_concurrent_read`, `merge_tree_min_rows_for_seek`, `merge_tree_min_bytes_for_seek`. Теперь настройка `min_bytes_to_use_mmap_io` также применяется при чтении индекса и компактных частей в семействе движков таблиц MergeTree. [#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлена проблема &quot;[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) Index not used for IN operator with literals&quot; — регрессия производительности, появившаяся примерно в v19.3. [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).
* Инъективные функции внутри `uniq*()` удаляются, если `set optimize_injective_functions_inside_uniq=1`. [#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)).
* Добавлена оптимизация ORDER BY, которая переписывает `ORDER BY x, f(x)` в `ORDER by x`, если `set optimize_redundant_functions_in_order_by = 1`. [#12404](https://github.com/ClickHouse/ClickHouse/pull/12404) ([Artem Zuikov](https://github.com/4ertus2)).
* Для некоторых операций использование памяти снижено до 2 раз. [#12424](https://github.com/ClickHouse/ClickHouse/pull/12424) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### Улучшения
</div>

* Добавлена возможность задавать количество ошибок, игнорируемых при выборе реплик (`distributed_replica_error_ignore`). [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* Улучшена производительность &#39;ORDER BY&#39; и &#39;GROUP BY&#39; для префикса ключа сортировки. [#11696](https://github.com/ClickHouse/ClickHouse/pull/11696) ([Anton Popov](https://github.com/CurtizJ)).
* * Добавлен `optimize_skip_unused_shards_nesting` (позволяет управлять уровнем вложенности при оптимизации пропуска сегментов) - Добавлен `force_skip_optimize_shards_nesting` (позволяет управлять уровнем вложенности при проверке, были ли пропущены сегменты) - Устаревшим объявлен `force_optimize_skip_unused_shards_no_nested` (вместо него следует использовать `force_skip_optimize_shards_nesting`) - `optimize_skip_unused_shards` отключён, если `sharding&#95;key` содержит недетерминированную функцию (например, `rand()`; обратите внимание, что это ничего не меняет на стороне INSERT). [#11715](https://github.com/ClickHouse/ClickHouse/pull/11715) ([Azat Khuzhin](https://github.com/azat)).
* Добавлены многоверсионные метаданные для хранилищ без блокировок структуры. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* Немного ослаблена проверка строки подключения ODBC. Если hostname или username содержит только буквенно-цифровые символы, а также `.` и `-`, не заключайте его в фигурные скобки. Это необходимо, потому что некоторые ODBC Driver (например, PostgreSQL) не понимают hostname в фигурных скобках. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка разбора UUID без разделителей (в большинстве реализаций разделители всё равно всегда удаляются; это удобно при записи данных). [#11856](https://github.com/ClickHouse/ClickHouse/pull/11856) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена поддержка модификаторов `SIGNED` и `UNSIGNED` для стандартных целочисленных типов (`BIGINT`, `INT`, ...) для совместимости с MySQL. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
