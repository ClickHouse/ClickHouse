<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#32252](https://github.com/ClickHouse/ClickHouse/issues/32252): исправлен пропуск столбцов при записи Protobuf. Этот PR исправляет [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160), см. комментарий [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318. [#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#32346](https://github.com/ClickHouse/ClickHouse/issues/32346): исправлена ошибка при удалении ненужных столбцов в подзапросе. Если в запросе есть агрегатная функция без GROUP BY, её не следует удалять, даже если она не нужна. [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#32151](https://github.com/ClickHouse/ClickHouse/issues/32151): Исправлен сбой при использовании функции `dictGet` с типом для атрибута словаря, если тип — `Nullable`. Исправляет [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980). [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32093](https://github.com/ClickHouse/ClickHouse/issues/32093): Некоторые записи `GET_PART` могли зависать в очереди репликации, если часть была потеряна на всех репликах и в той же партиции не было других частей. Это исправлено для случаев, когда ключ партиционирования содержит только столбцы целочисленных типов или `Date[Time]`. Исправляет [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485). [#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32147](https://github.com/ClickHouse/ClickHouse/issues/32147): Исправлена ошибка `Directory ... already exists and is not empty` при отсоединении части. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32216](https://github.com/ClickHouse/ClickHouse/issues/32216): Количество активных реплик могло определяться некорректно при вставке с кворумом, если настройка `replicated_can_become_leader` отключена на некоторых репликах. Это исправлено. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32352](https://github.com/ClickHouse/ClickHouse/issues/32352): Исправлен сбой с SIGFPE в агрегатной функции `avgWeighted` с аргументом `Decimal`. Исправляет [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32393](https://github.com/ClickHouse/ClickHouse/issues/32393): Исправлены запросы `ALTER ... MATERIALIZE COLUMN ...` в случаях, когда тип данных выражения по умолчанию не совпадает с типом данных столбца. [#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
