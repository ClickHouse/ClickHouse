<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Бэкпортировано в [#49981](https://github.com/ClickHouse/ClickHouse/issues/49981): откат изменения &quot;`groupArray` returns cannot be nullable&quot; (из-за нарушения бинарной совместимости для `groupArray`/`groupArrayLast`/`groupArraySample` с типами `Nullable`, что, вероятно, приведет к `TOO_LARGE_ARRAY_SIZE` или `CANNOT_READ_ALL_DATA`). [#49971](https://github.com/ClickHouse/ClickHouse/pull/49971) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Исправлена ошибка «ключ не найден» для запросов с несколькими StorageJoin [#49137](https://github.com/ClickHouse/ClickHouse/pull/49137) ([vdimir](https://github.com/vdimir)).
* Исправлена ошибка фаззинга, при которой множество подзапроса не строилось при чтении из remote() [#49425](https://github.com/ClickHouse/ClickHouse/pull/49425) ([Alexander Gololobov](https://github.com/davenger)).
* Исправлена настройка базы данных Postgres [#49481](https://github.com/ClickHouse/ClickHouse/pull/49481) ([Mal Curtis](https://github.com/snikch)).
* Исправлена ошибка AsynchronousReadIndirectBufferFromRemoteFS при коротких seek-операциях [#49525](https://github.com/ClickHouse/ClickHouse/pull/49525) ([Michael Kolupaev](https://github.com/al13n321)).
* Исправлена ошибка в DISTINCT [#49628](https://github.com/ClickHouse/ClickHouse/pull/49628) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлено срабатывание assert в SpanHolder::finish() при использовании файберов [#49673](https://github.com/ClickHouse/ClickHouse/pull/49673) ([Kruglov Pavel](https://github.com/Avogar)).
* Исправлена проблема msan в randomStringUTF8(<нечётное число>) [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze)).
* Исправлено `is_prefix` в OptimizeRegularExpression [#49919](https://github.com/ClickHouse/ClickHouse/pull/49919) ([Han Fei](https://github.com/hanfei1991)).
* Исправлено кодирование IPv6 в Protobuf [#49933](https://github.com/ClickHouse/ClickHouse/pull/49933) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Устранена взаимная блокировка при запуске таблицы в потоке attach для `ReplicatedMergeTree` [#50026](https://github.com/ClickHouse/ClickHouse/pull/50026) ([Antonio Andelic](https://github.com/antonio2368)).
* Исправлено срабатывание assert в SpanHolder::finish() при использовании файберов, попытка 2 [#50034](https://github.com/ClickHouse/ClickHouse/pull/50034) ([Kruglov Pavel](https://github.com/Avogar)).
* Исправлена JIT-компиляция операции «не равно NaN» [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal)).
* Исправлено аварийное завершение при создании базы данных Replicated без аргументов [#50058](https://github.com/ClickHouse/ClickHouse/pull/50058) ([Azat Khuzhin](https://github.com/azat)).
* Исправлено аварийное завершение при использовании `multiIf` с константным условием и аргументами типа Nullable [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ)).
* Исправлен разбор метаданных Iceberg [#50232](https://github.com/ClickHouse/ClickHouse/pull/50232) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Исправлены ошибки в сокетах Poco в неблокирующем режиме; добавлена поддержка истинно неблокирующих сокетов [#50252](https://github.com/ClickHouse/ClickHouse/pull/50252) ([Kruglov Pavel](https://github.com/Avogar)).
* Исправлено преобразование типов из Date/Date32 в DateTime64 при выполнении запросов с индексом DateTime64 [#50280](https://github.com/ClickHouse/ClickHouse/pull/50280) ([Lucas Chang](https://github.com/lucas-tubi)).
* Исправлена взаимная блокировка в Keeper при возникновении исключения во время предварительной обработки запросов [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr)).
* Исправлено некорректное количество строк, возвращаемое таблицами семейства Log после TRUNCATE [#50585](https://github.com/ClickHouse/ClickHouse/pull/50585) ([flynn](https://github.com/ucasfl)).
* Исправлена ошибка при параллельном слиянии в `uniqExact` [#50590](https://github.com/ClickHouse/ClickHouse/pull/50590) ([Nikita Taranov](https://github.com/nickitat)).
* Устранено считывание всех столбцов из правой таблицы GLOBAL JOIN [#50721](https://github.com/ClickHouse/ClickHouse/pull/50721) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
