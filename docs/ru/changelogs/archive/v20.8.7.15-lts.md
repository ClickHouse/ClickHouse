<div id="clickhouse-release-v208715-lts-fixme-as-compared-to-v20866-lts">
  ### Релиз ClickHouse v20.8.7.15-lts FIXME по сравнению с v20.8.6.6-lts
</div>

<div id="improvement">
  #### Улучшения
</div>

* Выполнен бэкпорт в [#17029](https://github.com/ClickHouse/ClickHouse/issues/17029): добавлена возможность подключаться к защищённой конечной точке `clickhouse-server`, для которой требуется SNI. Это возможно, когда `clickhouse-server` размещён за TLS-прокси. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпорт в [#15676](https://github.com/ClickHouse/ClickHouse/issues/15676): Запрос завершается быстрее в случае исключения. При возникновении исключения выполнение на удалённых репликах отменяется. [#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпорт в [#17106](https://github.com/ClickHouse/ClickHouse/issues/17106): исправляет [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574), исправляет [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231), исправляет сбой удалённого запроса при использовании агрегатной функции с суффиксом &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпорт в [#16761](https://github.com/ClickHouse/ClickHouse/issues/16761): Исправляет optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order при max&#95;threads&gt;0 и выражении в ORDER BY. [#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпорт в [#16738](https://github.com/ClickHouse/ClickHouse/issues/16738): Исправлен оператор `IN` для нескольких столбцов и Tuple при включенной настройке `transform_null_in`. Исправляет [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310). [#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпорт в [#17021](https://github.com/ClickHouse/ClickHouse/issues/17021): Исправлен сбой при использовании `any` без аргументов. Это для [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Бэкпорт в [#16880](https://github.com/ClickHouse/ClickHouse/issues/16880): Прерывать multipart-загрузку, если в WriteBufferFromS3 не было записано данных. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Бэкпорт в [#16950](https://github.com/ClickHouse/ClickHouse/issues/16950): Предотвращает сбои сервера ClickHouse при использовании TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Бэкпорт в [#17077](https://github.com/ClickHouse/ClickHouse/issues/17077): Исправлена возможная ошибка `Illegal type of argument` для запросов с `ORDER BY`. Исправляет [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпорт в [#17007](https://github.com/ClickHouse/ClickHouse/issues/17007): Скрипт установки должен всегда создавать подкаталоги в папках config. Это актуально только для Docker build с пользовательским config. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Бэкпорт в [#17011](https://github.com/ClickHouse/ClickHouse/issues/17011): Исправлен возможный сбой сервера после `ALTER TABLE ... MODIFY COLUMN ... NewType`, когда `SELECT` содержит выражение `WHERE` по изменяемому столбцу, а изменение ещё не завершилось. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Бэкпорт в [#17040](https://github.com/ClickHouse/ClickHouse/issues/17040): Повторно разрешать IP-адрес для `format_avro_schema_registry_url` в случае ошибок. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17171](https://github.com/ClickHouse/ClickHouse/issues/17171): Исправлена ошибка, из-за которой запросы `ON CLUSTER` могли зависать навсегда в таблицах ReplicatedMergeTree, не являющихся лидерами. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
