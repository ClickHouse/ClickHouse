  ### Релиз ClickHouse v23.8.10.43-lts (a278225bba9) FIXME по сравнению с v23.8.9.54-lts (192a1d231fa)

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#58819](https://github.com/ClickHouse/ClickHouse/issues/58819): добавлен `SYSTEM JEMALLOC PURGE` для очистки неиспользуемых страниц jemalloc, а также `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` для управления профилем jemalloc, если включен профилировщик. В Keeper добавлена связанная с jemalloc команда 4LW: `jmst` для вывода статистики jemalloc, а также `jmfp`, `jmep`, `jmdp` для управления профилем jemalloc, если включен профилировщик. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#60286](https://github.com/ClickHouse/ClickHouse/issues/60286): для копирования файлов S3 добавлен GCP fallback на копирование через буфер на случай, если GCP возвращает `Internal Error` с HTTP-кодом ошибки `GATEWAY_TIMEOUT`. [#60164](https://github.com/ClickHouse/ClickHouse/pull/60164) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#59879](https://github.com/ClickHouse/ClickHouse/issues/59879): Если вы хотите запускать скрипты `initdb` при каждом запуске контейнера ClickHouse, следует задать переменную окружения CLICKHOUSE&#95;ALWAYS&#95;RUN&#95;INITDB&#95;SCRIPTS. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#57565](https://github.com/ClickHouse/ClickHouse/issues/57565): Фоновые слияния теперь корректно используют временное хранилище данных в кэше. [#57275](https://github.com/ClickHouse/ClickHouse/pull/57275) ([vdimir](https://github.com/vdimir)).
* Бэкпортировано в [#57476](https://github.com/ClickHouse/ClickHouse/issues/57476): Исправлены возможные некорректные индексы пропуска данных после материализации в компактных частях MergeTree. [#57352](https://github.com/ClickHouse/ClickHouse/pull/57352) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#58777](https://github.com/ClickHouse/ClickHouse/issues/58777): Исправлен двойной вызов destroy при генерации исключения в addBatchLookupTable8. [#58745](https://github.com/ClickHouse/ClickHouse/pull/58745) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#58856](https://github.com/ClickHouse/ClickHouse/issues/58856): Исправлен возможный сбой в функции JSONExtract при извлечении типа `LowCardinality(Nullable(T))`. [#58808](https://github.com/ClickHouse/ClickHouse/pull/58808) ([vdimir](https://github.com/vdimir)).
* Бэкпортировано в [#59194](https://github.com/ClickHouse/ClickHouse/issues/59194): Комбинация LIMIT BY и LIMIT могла приводить к некорректному результату в распределённых запросах (в том числе при использовании параллельных реплик). [#59153](https://github.com/ClickHouse/ClickHouse/pull/59153) ([Igor Nikonov](https://github.com/devcrafter)).
* Бэкпортировано в [#59429](https://github.com/ClickHouse/ClickHouse/issues/59429): Исправлена функция translate() для входных данных FixedString. Это могло приводить к сбоям, поскольку она возвращала столбец String (вместо ожидаемого FixedString). Проблема была обнаружена участником ClickHouse Bug Bounty Program YohannJardin. [#59356](https://github.com/ClickHouse/ClickHouse/pull/59356) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#60128](https://github.com/ClickHouse/ClickHouse/issues/60128): Исправлена ошибка `Read beyond last offset` для `AsynchronousBoundedReadBuffer`. [#59630](https://github.com/ClickHouse/ClickHouse/pull/59630) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#59836](https://github.com/ClickHouse/ClickHouse/issues/59836): Исправлено время начала для непервичных запросов. [#59662](https://github.com/ClickHouse/ClickHouse/pull/59662) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#59758](https://github.com/ClickHouse/ClickHouse/issues/59758): Исправлена функция leftPad / rightPad для входных данных FixedString. [#59739](https://github.com/ClickHouse/ClickHouse/pull/59739) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#60304](https://github.com/ClickHouse/ClickHouse/issues/60304): Исправлена ситуация, при которой сообщения не получали ни ack, ни nack. Если на этапе чтения и записи происходит исключение, сообщения получают nack. [#59775](https://github.com/ClickHouse/ClickHouse/pull/59775) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#60171](https://github.com/ClickHouse/ClickHouse/issues/60171): Исправлен сбой в cosineDistance с Nullable. [#60150](https://github.com/ClickHouse/ClickHouse/pull/60150) ([Raúl Marín](https://github.com/Algunenano)).
