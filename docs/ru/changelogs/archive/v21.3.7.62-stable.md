<div id="clickhouse-release-v213762-stable-fixme-as-compared-to-v213655-lts">
  ### Релиз ClickHouse v21.3.7.62-stable FIXME по сравнению с v21.3.6.55-lts

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#23014](https://github.com/ClickHouse/ClickHouse/issues/23014): значение `background_fetches_pool_size` установлено равным 8, что лучше подходит для использования в продакшне при частых небольших вставках или медленном кластере ZooKeeper. [#22945](https://github.com/ClickHouse/ClickHouse/pull/22945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#23081](https://github.com/ClickHouse/ClickHouse/issues/23081): увеличен порог максимального числа совпадений в результате функции `extractAllGroupsHorizontal`. [#23036](https://github.com/ClickHouse/ClickHouse/pull/23036) ([Vasily Nemkov](https://github.com/Enmk)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#23156](https://github.com/ClickHouse/ClickHouse/issues/23156): Исправлена ошибка, из-за которой время ожидания вспомогательных AWS-запросов могло быть неограниченным. [#22594](https://github.com/ClickHouse/ClickHouse/pull/22594) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Бэкпортировано в [#23033](https://github.com/ClickHouse/ClickHouse/issues/23033): Исправлена ошибка `Cannot find column in ActionsDAG result`, которая может возникать, если подзапрос использует `untuple`. Исправление для [#22290](https://github.com/ClickHouse/ClickHouse/issues/22290). [#22991](https://github.com/ClickHouse/ClickHouse/pull/22991) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#23075](https://github.com/ClickHouse/ClickHouse/issues/23075): Из подсказок в клиенте ClickHouse удалены несущественные детали. Это закрывает [#22158](https://github.com/ClickHouse/ClickHouse/issues/22158). [#23040](https://github.com/ClickHouse/ClickHouse/pull/23040) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#23170](https://github.com/ClickHouse/ClickHouse/issues/23170): Некоторые значения в ячейках таблицы в формате `Markdown` выравнивались по центру. Это исправлено. [#23096](https://github.com/ClickHouse/ClickHouse/pull/23096) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
