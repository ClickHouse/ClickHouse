<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Выполнен бэкпорт в [#55295](https://github.com/ClickHouse/ClickHouse/issues/55295): Ресурс с исходным кодом, включая сабмодули, собирается в специальной задаче сборки для Darwin. Его можно использовать для сборки ClickHouse без получения сабмодулей. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Выполнен бэкпорт в [#55368](https://github.com/ClickHouse/ClickHouse/issues/55368): Решена проблема с запуском автономного clickhouse-keeper из пакета clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Выполнен бэкпорт в [#55727](https://github.com/ClickHouse/ClickHouse/issues/55727): Исправлен Python-скрипт проверки интеграции для использования URL `gh api`; добавлен README для CI-тестов. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Исправлена взаимоблокировка при обновлении роли, назначенной через LDAP [#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* Исправлена фоновая загрузка в fs cache [#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Исправлено выполнение функций над разреженными столбцами [#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* Исправлено некорректное слияние Nested для SELECT FINAL FROM SummingMergeTree [#55276](https://github.com/ClickHouse/ClickHouse/pull/55276) ([Azat Khuzhin](https://github.com/azat)).
* Исправлена ошибка, из-за которой нельзя было удалить detached партицию в replicated merge tree поверх S3 без zero copy [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* Исправлен SIGSEGV в MergeSortingPartialResultTransform (из-за пустых фрагментов после remerge()) [#55335](https://github.com/ClickHouse/ClickHouse/pull/55335) ([Azat Khuzhin](https://github.com/azat)).
* Исправлено состояние гонки в CreatingSetsTransform (при ошибках) из-за выбрасывания общего исключения [#55338](https://github.com/ClickHouse/ClickHouse/pull/55338) ([Azat Khuzhin](https://github.com/azat)).
* Исправлена неудачная оптимизация (до определённой степени) [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлен разбор массивов в операторе CAST [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* Исправлена фильтрация по виртуальным столбцам с OR-фильтром в запросе [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* Исправлены проблемы с подключением к MongoDB [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* Уничтожение fiber в случае исключения в cancelBefore в AsyncTaskExecutor [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* Исправлен сбой в QueryNormalizer при циклических псевдонимах [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* Исправлена фильтрация по виртуальным столбцам с OR-фильтром в запросе (повторная отправка) [#55678](https://github.com/ClickHouse/ClickHouse/pull/55678) ([Azat Khuzhin](https://github.com/azat)).
