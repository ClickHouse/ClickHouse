  ### Релиз ClickHouse v20.8.6.6-lts FIXME по сравнению с версией v20.8.5.45-lts
</div>

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#16494](https://github.com/ClickHouse/ClickHouse/issues/16494): Исправлена ошибка в базе данных MySQL. Когда сервер MySQL, используемый как движок базы данных, недоступен, некоторые запросы вызывают Исключение, поскольку пытаются получить таблицы с отключенного сервера, хотя в этом нет необходимости. Например, запрос `SELECT ... FROM system.parts` должен работать только с таблицами семейства MergeTree и вообще не обращаться к базе данных MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#16816](https://github.com/ClickHouse/ClickHouse/issues/16816): Исправлено неконсистентное поведение, при котором часть возвращаемых данных могла отбрасываться, потому что множество для их фильтрации не было создано. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#16506](https://github.com/ClickHouse/ClickHouse/issues/16506): Исправлена обработка очень больших записей в очереди репликации. Очень большие записи могут появляться в ALTER-запросах, если структура таблицы чрезвычайно велика (около 1 МБ). Это исправляет [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#16472](https://github.com/ClickHouse/ClickHouse/issues/16472): Исправлен DROP TABLE для Distributed (с состоянием гонки при INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#16573](https://github.com/ClickHouse/ClickHouse/issues/16573): Исправлен быстрый рост метаданных при использовании MySQL Master -&gt; MySQL Slave -&gt; движка ClickHouse MaterializeMySQL и включенном `slave_parallel_worker` на MySQL Slave за счет корректного уменьшения множеств GTID. Это исправляет [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Бэкпортировано в [#16552](https://github.com/ClickHouse/ClickHouse/issues/16552): Теперь при разборе входных данных в формате AVRO LowCardinality удаляется из типа. Исправляет [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Бэкпортировано в [#16823](https://github.com/ClickHouse/ClickHouse/issues/16823): Исправлено [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#16892](https://github.com/ClickHouse/ClickHouse/issues/16892): Исправлены редкие скрытые сбои, возникавшие, когда был включен профилировщик запросов и ClickHouse был установлен на ОС с версией glibc, в которой (предположительно) есть некорректные асинхронные таблицы unwind для некоторых функций. Это исправляет [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Это исправляет [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
