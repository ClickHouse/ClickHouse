<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#58818](https://github.com/ClickHouse/ClickHouse/issues/58818): добавлена команда `SYSTEM JEMALLOC PURGE` для очистки неиспользуемых страниц jemalloc, а также `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` для управления профилем jemalloc, если включен профилировщик. В Keeper добавлены связанные с jemalloc команды 4LW: `jmst` для вывода статистики jemalloc, а также `jmfp`, `jmep`, `jmdp` для управления профилем jemalloc, если включен профилировщик. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#59877](https://github.com/ClickHouse/ClickHouse/issues/59877): Если вы хотите запускать скрипты initdb при каждом запуске контейнера ClickHouse, нужно задать переменную окружения CLICKHOUSE&#95;ALWAYS&#95;RUN&#95;INITDB&#95;SCRIPTS. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).
