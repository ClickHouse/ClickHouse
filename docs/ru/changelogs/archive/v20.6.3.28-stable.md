  ### Релиз ClickHouse v20.6.3.28-stable FIXME по сравнению с v20.6.2.15-prestable
</div>

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#13301](https://github.com/ClickHouse/ClickHouse/issues/13301): Функция `groupArrayMoving*` не работала для распределённых запросов. Её результат вычислялся в некорректном типе данных (без приведения к наиболее широкому типу). Функция `groupArrayMovingAvg` возвращала целое число, что было несовместимо с функцией `avg`. Это исправляет [#12568](https://github.com/ClickHouse/ClickHouse/issues/12568). [#12622](https://github.com/ClickHouse/ClickHouse/pull/12622) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#13029](https://github.com/ClickHouse/ClickHouse/issues/13029): CREATE USER IF NOT EXISTS теперь не генерирует исключение, если пользователь уже существует. Это исправляет [#12507](https://github.com/ClickHouse/ClickHouse/issues/12507). [#12646](https://github.com/ClickHouse/ClickHouse/pull/12646) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#12983](https://github.com/ClickHouse/ClickHouse/issues/12983): Исправлено дублирование столбцов для range hashed словаря, созданного из DDL-запроса. Это исправляет [#10605](https://github.com/ClickHouse/ClickHouse/issues/10605). [#12857](https://github.com/ClickHouse/ClickHouse/pull/12857) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#13222](https://github.com/ClickHouse/ClickHouse/issues/13222): Исправлены функции преобразования для DateTime64 с константным аргументом. [#13205](https://github.com/ClickHouse/ClickHouse/pull/13205) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#13245](https://github.com/ClickHouse/ClickHouse/issues/13245): Исправлен assert в функции `arrayElement` в случае, когда элементы массива имеют тип Nullable и индекс массива тоже имеет тип Nullable. Это исправляет [#12172](https://github.com/ClickHouse/ClickHouse/issues/12172). [#13224](https://github.com/ClickHouse/ClickHouse/pull/13224) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#13267](https://github.com/ClickHouse/ClickHouse/issues/13267): Исправлена функция if для nullable constexpr, используемого в качестве cond и не являющегося literal NULL. Исправляет [#12463](https://github.com/ClickHouse/ClickHouse/issues/12463). [#13226](https://github.com/ClickHouse/ClickHouse/pull/13226) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#13298](https://github.com/ClickHouse/ClickHouse/issues/13298): Исправлены потенциально низкая производительность и слегка некорректный результат для `uniqExact`, `topK`, `sumDistinct` и аналогичных агрегатных функций, вызываемых для типов Float со значениями NaN. Это также вызывало assert в debug build. Это исправляет [#12491](https://github.com/ClickHouse/ClickHouse/issues/12491). [#13254](https://github.com/ClickHouse/ClickHouse/pull/13254) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#13316](https://github.com/ClickHouse/ClickHouse/issues/13316): Сервер может аварийно завершиться, если пользователь передаст в функцию `h3ToChildren` специально сформированные аргументы. Это исправляет [#13275](https://github.com/ClickHouse/ClickHouse/issues/13275). [#13277](https://github.com/ClickHouse/ClickHouse/pull/13277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#13329](https://github.com/ClickHouse/ClickHouse/issues/13329): Исправлена возможная ошибка `Totals having transform was already added to pipeline` в случае запроса от отстающей реплики. [#13290](https://github.com/ClickHouse/ClickHouse/pull/13290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#13317](https://github.com/ClickHouse/ClickHouse/issues/13317): Исправлен сбой в `LEFT ASOF JOIN` с `join_use_nulls=1`. [#13291](https://github.com/ClickHouse/ClickHouse/pull/13291) ([Artem Zuikov](https://github.com/4ertus2)).
* Бэкпортировано в [#13375](https://github.com/ClickHouse/ClickHouse/issues/13375): Исправлен segfault при десериализации пустого состояния функцией `groupArrayMovingSum`. Исправляет [#13339](https://github.com/ClickHouse/ClickHouse/issues/13339). [#13341](https://github.com/ClickHouse/ClickHouse/pull/13341) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#13432](https://github.com/ClickHouse/ClickHouse/issues/13432): Исправлен PrettyCompactMonoBlock для clickhouse-local. Исправлены Extremes/totals в PrettyCompactMonoBlock. Исправляет [#7746](https://github.com/ClickHouse/ClickHouse/issues/7746). [#13394](https://github.com/ClickHouse/ClickHouse/pull/13394) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#13443](https://github.com/ClickHouse/ClickHouse/issues/13443): Исправлена ошибка `aggregate function any(x) is found inside another aggregate function in query` при использовании `SET optimize_move_functions_out_of_any = 1` и псевдонимов внутри `any()`. [#13419](https://github.com/ClickHouse/ClickHouse/pull/13419) ([Artem Zuikov](https://github.com/4ertus2)).
