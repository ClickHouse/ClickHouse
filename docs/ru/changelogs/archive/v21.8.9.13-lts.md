<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#29817](https://github.com/ClickHouse/ClickHouse/issues/29817): Разрешено использовать материализованный столбец в качестве ключа сегментирования distributed таблицы, даже если `insert_allow_materialized_columns=0`:. [#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#29973](https://github.com/ClickHouse/ClickHouse/issues/29973): Исправлено завершение работы `AccessControlManager`. Теперь после уничтожения AccessControlManager повторная загрузка конфигурации невозможна. Этот PR исправляет нестабильный тест [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html). [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#29676](https://github.com/ClickHouse/ClickHouse/issues/29676): Исправлено Вертикальное слияние частей проекций. Это исправляет [#29253](https://github.com/ClickHouse/ClickHouse/issues/29253). Этот PR также исправляет несколько проблем со слиянием и мутациями проекций, появившихся в [https://github.com/ClickHouse/ClickHouse/pull/25165](https://github.com/ClickHouse/ClickHouse/pull/25165). [#29337](https://github.com/ClickHouse/ClickHouse/pull/29337) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#29538](https://github.com/ClickHouse/ClickHouse/issues/29538): Исправлена возможная ошибка `Block structure mismatch` для подзапросов с протолкнутым предикатом `HAVING`. Исправляет [#29010](https://github.com/ClickHouse/ClickHouse/issues/29010). [#29475](https://github.com/ClickHouse/ClickHouse/pull/29475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#29589](https://github.com/ClickHouse/ClickHouse/issues/29589): В мост ODBC добавлены повторные попытки для ошибки Invalid cursor state. Это ошибка, для которой допустим повторный вызов. Закрывает [#29473](https://github.com/ClickHouse/ClickHouse/issues/29473). [#29518](https://github.com/ClickHouse/ClickHouse/pull/29518) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#29593](https://github.com/ClickHouse/ClickHouse/issues/29593): Исправлена ошибка в проверке `pathStartsWith`, вызванная некорректным использованием `std::mismatch`: ` The behavior is undefined if the second range is shorter than the first range.`. [#29531](https://github.com/ClickHouse/ClickHouse/pull/29531) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#29628](https://github.com/ClickHouse/ClickHouse/issues/29628): Исправлен редкий segfault в запросе `ALTER MODIFY` при использовании некорректного идентификатора таблицы в выражении `DEFAULT`, например `x.y.z...`. Исправляет [#29184](https://github.com/ClickHouse/ClickHouse/issues/29184). [#29573](https://github.com/ClickHouse/ClickHouse/pull/29573) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#29752](https://github.com/ClickHouse/ClickHouse/issues/29752): Условие в предикате фильтра могло теряться после push-down-оптимизации. [#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#29840](https://github.com/ClickHouse/ClickHouse/issues/29840): Исправлено некорректное поведение настройки `materialized_postgresql_tables_list` при перезапуске сервера. Обнаружено в [#28529](https://github.com/ClickHouse/ClickHouse/issues/28529). [#29686](https://github.com/ClickHouse/ClickHouse/pull/29686) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#29847](https://github.com/ClickHouse/ClickHouse/issues/29847): Исправлен одновременный доступ к `LowCardinality` при `GROUP BY` (приводит к SIGSEGV). [#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29911](https://github.com/ClickHouse/ClickHouse/issues/29911): Исправлено некорректное приведение типов в запросе `ATTACH TABLE ... FROM 'path'`, когда вместо path используется нестроковый литерал. Это могло приводить к чтению неинициализированной памяти. [#29790](https://github.com/ClickHouse/ClickHouse/pull/29790) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#29867](https://github.com/ClickHouse/ClickHouse/issues/29867): Предотвращена ошибка `Timeout exceeded: elapsed 18446744073.709553 seconds`, которая в крайне редких случаях могла возникать, предположительно из-за ошибки в ядре. Исправляет [#29154](https://github.com/ClickHouse/ClickHouse/issues/29154). [#29811](https://github.com/ClickHouse/ClickHouse/pull/29811) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#29877](https://github.com/ClickHouse/ClickHouse/issues/29877): Исправлена проверка пересоздания системных таблиц (не выявлялись изменения в значениях enum). [#29857](https://github.com/ClickHouse/ClickHouse/pull/29857) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#30210](https://github.com/ClickHouse/ClickHouse/issues/30210): Исправлена возможная гонка данных между `FileChecker` и `StorageLog`/`StorageStripeLog`. [#29959](https://github.com/ClickHouse/ClickHouse/pull/29959) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#30069](https://github.com/ClickHouse/ClickHouse/issues/30069): Исправлен сбой при sample по `tuple()`, закрывает [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004). [#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
* Бэкпортировано в [#30125](https://github.com/ClickHouse/ClickHouse/issues/30125): Удалённая база данных `Memory` могла вновь появиться после перезапуска сервера; это исправлено ([#29795](https://github.com/ClickHouse/ClickHouse/issues/29795)). Также добавлена настройка `force_remove_data_recursively_on_drop` как обходной путь для ошибки `Directory not empty` при удалении базы данных `Ordinary` (поскольку в облачной среде невозможно вручную удалить оставшиеся данные). [#30054](https://github.com/ClickHouse/ClickHouse/pull/30054) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#30263](https://github.com/ClickHouse/ClickHouse/issues/30263): В FlatDictionary и HashedDictionary исправлен расчёт `bytes&#95;allocated` для атрибутов Nullable. [#30238](https://github.com/ClickHouse/ClickHouse/pull/30238) ([Maksim Kita](https://github.com/kitaisreal)).
