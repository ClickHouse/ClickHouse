<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#74821](https://github.com/ClickHouse/ClickHouse/issues/74821): Исправлено редкое аварийное завершение refreshable materialized view при остановке сервера. [#73323](https://github.com/ClickHouse/ClickHouse/pull/73323) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#74808](https://github.com/ClickHouse/ClickHouse/issues/74808): Исправлена проблема безопасности, предотвращающая SQL-инъекцию в табличных функциях PostgreSQL и SQLite. [#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#75122](https://github.com/ClickHouse/ClickHouse/issues/75122): Исправлено аварийное завершение при вставке interval (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)). [#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* Бэкпортировано в [#75095](https://github.com/ClickHouse/ClickHouse/issues/75095): Исправлена работа запросов `INSERT SELECT` между таблицами со столбцами `Tuple` и включенной разреженной сериализацией. [#74698](https://github.com/ClickHouse/ClickHouse/pull/74698) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#75307](https://github.com/ClickHouse/ClickHouse/issues/75307): Исправлено аварийное завершение при разборе объявления JSON type, если имя типа задано не в верхнем регистре. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#74906](https://github.com/ClickHouse/ClickHouse/issues/74906): Исправление в Keeper: исправлено чтение записей журнала с диска. [#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#75170](https://github.com/ClickHouse/ClickHouse/issues/75170): Исправлено отсутствие полей `used_privileges` и `missing_privileges` в `query_log` для операций BACKUP и RESTORE. [#74887](https://github.com/ClickHouse/ClickHouse/pull/74887) ([Alexey Katsman](https://github.com/alexkats)).
* Бэкпортировано в [#74955](https://github.com/ClickHouse/ClickHouse/issues/74955): Исправлена ошибка FILE&#95;DOESNT&#95;EXIST, возникавшая во время слияния частей данных для таблицы с пустым столбцом в Azure Blob Storage. [#74892](https://github.com/ClickHouse/ClickHouse/pull/74892) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#75052](https://github.com/ClickHouse/ClickHouse/issues/75052): В HDFS обновляется билет krb при ошибке sasl во время запроса hdfs select. [#74930](https://github.com/ClickHouse/ClickHouse/pull/74930) ([inv2004](https://github.com/inv2004)).
* Бэкпортировано в [#75412](https://github.com/ClickHouse/ClickHouse/issues/75412): Состояние части возвращается из deleting обратно в устаревший, если операция remove завершилась неудачно. [#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#75405](https://github.com/ClickHouse/ClickHouse/issues/75405): Исправлено использование индексов (основного и вторичных) для столбцов `Array`, `Map` и `Nullable(..)` при включенной настройке `optimize_function_to_subcolumns`. Ранее индексы для этих столбцов могли игнорироваться. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#75458](https://github.com/ClickHouse/ClickHouse/issues/75458): Исправлена ошибка, вызывавшая аварийное завершение CTE с Insert. [#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).
* Бэкпортировано в [#75481](https://github.com/ClickHouse/ClickHouse/issues/75481): Скрыта конфиденциальная информация в табличных функциях `icebergS3`, `icebergAzure` и в движках таблиц. [#75378](https://github.com/ClickHouse/ClickHouse/pull/75378) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#75287](https://github.com/ClickHouse/ClickHouse/issues/75287): Улучшены ещё более строгие настройки по умолчанию. Текущие значения по умолчанию уже безопасны — пользователь должен явно указать параметр, чтобы опубликовать порты. Однако если для пользователя `default` не задан пароль через переменную окружения `CLICKHOUSE_PASSWORD` и/или не изменено имя пользователя через переменную окружения `CLICKHOUSE_USER`, он должен быть доступен только с локальной системы в качестве дополнительной меры защиты. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
