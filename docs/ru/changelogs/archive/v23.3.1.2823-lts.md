<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Смягчены ограничения на символы, разрешённые в authority URL в *domain*RFC()/netloc(). [#46841](https://github.com/ClickHouse/ClickHouse/pull/46841) ([Azat Khuzhin](https://github.com/azat)).
* Запрещено создавать таблицы на основе KafkaEngine с операторами DEFAULT/EPHEMERAL/ALIAS/MATERIALIZED для столбцов. [#47138](https://github.com/ClickHouse/ClickHouse/pull/47138) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* Удалена возможность «asynchronous connection drain». Связанные настройки и метрики также удалены. Это была внутренняя возможность, поэтому удаление не должно повлиять на пользователей, которые никогда о ней не слышали. [#47486](https://github.com/ClickHouse/ClickHouse/pull/47486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Добавлена поддержка 256-битного типа данных Decimal (более 38 цифр) в `arraySum`/`Min`/`Max`/`Avg`/`Product`, `arrayCumSum`/`CumSumNonNegative`, `arrayDifference`, создании массивов, операторе IN, параметрах запроса, `groupArrayMovingSum`, статистических функциях, `min`/`max`/`any`/`argMin`/`argMax`, PostgreSQL wire protocol, движке таблицы MySQL и функции, `sumMap`, `mapAdd`, `mapSubtract`, `arrayIntersect`. Добавлена поддержка больших целых чисел в `arrayIntersect`. Статистические агрегатные функции, использующие моменты (например, `corr` или различные `TTest`), будут использовать `Float64` в качестве внутреннего представления (до этого изменения они использовали `Decimal128`, но это не имело смысла), и эти функции могут возвращать `nan` вместо `inf` в случае бесконечной дисперсии. Некоторые функции поддерживали типы данных `Decimal256`, но в предыдущих версиях возвращали `Decimal128` — теперь это исправлено. Это закрывает [#47569](https://github.com/ClickHouse/ClickHouse/issues/47569). Это закрывает [#44864](https://github.com/ClickHouse/ClickHouse/issues/44864). Это закрывает [#28335](https://github.com/ClickHouse/ClickHouse/issues/28335). [#47594](https://github.com/ClickHouse/ClickHouse/pull/47594) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Параметры `backup_threads`/`restore_threads` сделаны настройками сервера. [#47881](https://github.com/ClickHouse/ClickHouse/pull/47881) ([Azat Khuzhin](https://github.com/azat)).
* Исправлена функция isIPv6String, которая могла выдавать ложноположительный результат в случае некорректного IPv6-адреса. Например, `1234::1234:` считался корректным IPv6-адресом. [#47895](https://github.com/ClickHouse/ClickHouse/pull/47895) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлен новый режим разделения работы между репликами с использованием настроек `parallel_replicas_custom_key` и `parallel_replicas_custom_key_filter_type`. Если cluster состоит из одного сегмента с несколькими репликами, случайным образом выбираются до `max_parallel_replicas` реплик, которые затем рассматриваются как сегменты. Для каждого сегмента к запросу на узле-инициаторе добавляется соответствующий фильтр перед его отправкой в сегмент. Если cluster состоит из нескольких сегментов, поведение будет таким же, как у `sample_key`, но с возможностью задать произвольный ключ. [#45108](https://github.com/ClickHouse/ClickHouse/pull/45108) ([Antonio Andelic](https://github.com/antonio2368)).
* Добавлена настройка запроса `partial_result_on_first_cancel`, позволяющая отмененному запросу (например, из-за Ctrl-C) возвращать частичный результат. [#45689](https://github.com/ClickHouse/ClickHouse/pull/45689) ([Alexey Perevyshin](https://github.com/alexX512)).
* Добавлена поддержка произвольных движков таблиц для временных таблиц, кроме движков Replicated и KeeperMap. Частично закрывает [#31497](https://github.com/ClickHouse/ClickHouse/issues/31497). [#46071](https://github.com/ClickHouse/ClickHouse/pull/46071) ([Roman Vasin](https://github.com/rvasin)).
* Добавлена репликация пользовательских SQL-функций с использованием ZooKeeper. [#46085](https://github.com/ClickHouse/ClickHouse/pull/46085) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Реализована `system.server_settings` (аналогично `system.settings`), которая будет содержать конфигурации сервера. [#46550](https://github.com/ClickHouse/ClickHouse/pull/46550) ([pufit](https://github.com/pufit)).
* Добавлена функция `WIDTH_BUCKET`. [#42974](https://github.com/ClickHouse/ClickHouse/issues/42974). [#46790](https://github.com/ClickHouse/ClickHouse/pull/46790) ([avoiderboi](https://github.com/avoiderboi)).
* Добавлены новые функции parseDateTime/parseDateTimeInJodaSyntax в соответствии с указанной строкой формата. parseDateTime разбирает строку в дату и время по синтаксису MySQL, а parseDateTimeInJodaSyntax — по синтаксису Joda. [#46815](https://github.com/ClickHouse/ClickHouse/pull/46815) ([李扬](https://github.com/taiyang-li)).
* В качестве структуры по умолчанию для табличной функции `null` используется `dummy UInt8`. Закрывает [#46930](https://github.com/ClickHouse/ClickHouse/issues/46930). [#47006](https://github.com/ClickHouse/ClickHouse/pull/47006) ([flynn](https://github.com/ucasfl)).
* Добавлена поддержка формата `Dec 15, 2021` для функции parseDateTimeBestEffort. Закрывает [#46816](https://github.com/ClickHouse/ClickHouse/issues/46816). [#47071](https://github.com/ClickHouse/ClickHouse/pull/47071) ([chen](https://github.com/xiedeyantu)).
* Добавлена функция ULIDStringToDateTime(). Закрывает [#46945](https://github.com/ClickHouse/ClickHouse/issues/46945). [#47087](https://github.com/ClickHouse/ClickHouse/pull/47087) ([Nikolay Degterinsky](https://github.com/evillique)).
* Добавлены настройки `http_wait_end_of_query` и `http_response_buffer_size`, соответствующие URL-параметрам `wait_end_of_query` и `buffer_size` для HTTP-интерфейса. [#47108](https://github.com/ClickHouse/ClickHouse/pull/47108) ([Vladimir C](https://github.com/vdimir)).
* Добавлена поддержка запроса `UNDROP TABLE`. Закрывает [#46811](https://github.com/ClickHouse/ClickHouse/issues/46811). [#47241](https://github.com/ClickHouse/ClickHouse/pull/47241) ([chen](https://github.com/xiedeyantu)).
* Добавлена таблица `system.marked_dropped_tables`, показывающая таблицы, которые были удалены из баз данных `Atomic`, но еще не были полностью удалены. [#47364](https://github.com/ClickHouse/ClickHouse/pull/47364) ([chen](https://github.com/xiedeyantu)).
* Добавлен `INSTR` как псевдоним `positionCaseInsensitive` для совместимости с MySQL. Закрывает [#47529](https://github.com/ClickHouse/ClickHouse/issues/47529). [#47535](https://github.com/ClickHouse/ClickHouse/pull/47535) ([flynn](https://github.com/ucasfl)).
* Добавлена функция `toDecimalString`, позволяющая преобразовывать числа в строку с фиксированной точностью. [#47838](https://github.com/ClickHouse/ClickHouse/pull/47838) ([Andrey Zvonov](https://github.com/zvonand)).
* Добавлен оператор &quot;REGEXP&quot; (по аналогии с операторами &quot;LIKE&quot;, &quot;IN&quot;, &quot;MOD&quot; и т. д.) для лучшей совместимости с MySQL. [#47869](https://github.com/ClickHouse/ClickHouse/pull/47869) ([Robert Schulze](https://github.com/rschu1ze)).
* Добавлена возможность выполнять конвейер чтения для словаря DIRECT с источником CLICKHOUSE в нескольких потоках. Чтобы включить это, установите `dictionary_use_async_executor=1` в разделе `SETTINGS` для источника в операторе `CREATE DICTIONARY`. [#47986](https://github.com/ClickHouse/ClickHouse/pull/47986) ([Vladimir C](https://github.com/vdimir)).
* Добавлена настройка MergeTree `max_number_of_mutatuins_for_replica`. Она ограничивает количество мутаций частей для каждой реплики указанным значением. Ноль означает отсутствие ограничения на количество мутаций для каждой реплики (хотя выполнение по-прежнему может ограничиваться другими настройками). [#48047](https://github.com/ClickHouse/ClickHouse/pull/48047) ([Vladimir C](https://github.com/vdimir)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Оптимизирована производительность агрегации по одному ключу Nullable. [#45772](https://github.com/ClickHouse/ClickHouse/pull/45772) ([LiuNeng](https://github.com/liuneng1994)).
* Реализовано использование индекса lowercase tokenbf&#95;v1 для hasTokenOrNull, hasTokenCaseInsensitive и hasTokenCaseInsensitiveOrNull. [#46252](https://github.com/ClickHouse/ClickHouse/pull/46252) ([ltrk2](https://github.com/ltrk2)).
* Оптимизирован универсальный SIMD StringSearcher за счёт поиска по первым двум символам. [#46289](https://github.com/ClickHouse/ClickHouse/pull/46289) ([Jiebin Sun](https://github.com/jiebinn)).
* System.detached&#95;parts может быть очень большой. — добавлено несколько источников с учётом ограничения на размер блока — в каждом блоке для вычисления размера части используется пул потоков iothread, то есть системные вызовы выполняются параллельно. [#46624](https://github.com/ClickHouse/ClickHouse/pull/46624) ([Sema Checherinda](https://github.com/CheSema)).
* Значение по умолчанию для `max_replicated_merges_in_queue` увеличено с 16 до 1000 для таблиц ReplicatedMergeTree. Это позволяет ускорить фоновые слияния на кластерах с очень большим числом реплик, например на кластерах с общим хранилищем в ClickHouse Cloud. [#47050](https://github.com/ClickHouse/ClickHouse/pull/47050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Резервные копии для большого числа файлов в предыдущих версиях были крайне медленными. [#47251](https://github.com/ClickHouse/ClickHouse/pull/47251) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка проталкивания фильтра в левую таблицу для JOIN с StorageJoin, StorageDictionary, StorageEmbeddedRocksDB. [#47280](https://github.com/ClickHouse/ClickHouse/pull/47280) ([Maksim Kita](https://github.com/kitaisreal)).
* Метки в памяти теперь сжимаются, благодаря чему используют в 3–6 раз меньше памяти. [#47290](https://github.com/ClickHouse/ClickHouse/pull/47290) ([Michael Kolupaev](https://github.com/al13n321)).
* Copier обновлён и теперь использует group by вместо distinct для получения списка партиций. Для больших таблиц это сократило время выполнения select с более чем 500 с до менее чем 1 с. [#47386](https://github.com/ClickHouse/ClickHouse/pull/47386) ([Clayton McClure](https://github.com/cmcclure-twilio)).
* Исправлена проблема [https://github.com/clickhouse/clickhouse/issues/46453](https://github.com/clickhouse/clickhouse/issues/46453). Bisect пометил [https://github.com/clickhouse/clickhouse/pull/35525](https://github.com/clickhouse/clickhouse/pull/35525) как изменение, вызвавшее проблему. Этот PR, по-видимому, отменяет изменения из того PR. [#47544](https://github.com/ClickHouse/ClickHouse/pull/47544) ([Ongkong](https://github.com/ongkong)).
* Исправлено избыточное чтение в запросах с `FINAL`. [#47801](https://github.com/ClickHouse/ClickHouse/pull/47801) ([Nikita Taranov](https://github.com/nickitat)).
* Значение `max_final_threads` теперь устанавливается равным числу ядер при запуске сервера (по тому же алгоритму, который используется для `max_threads`). Это улучшает параллелизм выполнения `final` на серверах с большим числом CPU. [#47915](https://github.com/ClickHouse/ClickHouse/pull/47915) ([Nikita Taranov](https://github.com/nickitat)).
* Чтобы повысить производительность, батчи в запросах на чтение больше не разбиваются. [#47978](https://github.com/ClickHouse/ClickHouse/pull/47978) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="improvement">
  #### Улучшения
</div>

* Добавлены функции для map: `mapFromArrays`, позволяющая создавать map из пары массивов. [#31125](https://github.com/ClickHouse/ClickHouse/pull/31125) ([李扬](https://github.com/taiyang-li)).
* Переработана отправка через Distributed, чтобы не использовать файловую систему в качестве очереди; вместо этого теперь используется очередь в памяти. [#45491](https://github.com/ClickHouse/ClickHouse/pull/45491) ([Azat Khuzhin](https://github.com/azat)).
* Добавлены отдельные привилегии для named collections (например, чтобы можно было выдавать доступ `SHOW/CREATE/ALTER/DROP named collection` только к определённым collections, а не ко всем сразу). Закрывает [#40894](https://github.com/ClickHouse/ClickHouse/issues/40894). Добавлен новый тип доступа `NAMED_COLLECTION_CONTROL`, который не выдаётся пользователю `default`, если он явно не добавлен в config пользователя (он требуется для выполнения `GRANT ALL`); кроме того, `show_named_collections` больше не нужно вручную указывать для пользователя `default`, чтобы у него были полные права доступа, как это было в 23.2. [#46241](https://github.com/ClickHouse/ClickHouse/pull/46241) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Теперь заголовки `X-ClickHouse-Query-Id` и `X-ClickHouse-Timezone` добавляются в ответ для всех запросов по HTTP-протоколу. Ранее это делалось только для запросов `SELECT`. [#46364](https://github.com/ClickHouse/ClickHouse/pull/46364) ([Anton Popov](https://github.com/CurtizJ)).
* Добавлена поддержка подключения к Replica Set через URI со списком host:port, а также поддержка опции `readPreference` в словарях MongoDB. Пример URI: mongodb://db0.example.com:27017,db1.example.com:27017,db2.example.com:27017/?replicaSet=myRepl&amp;readPreference=primary. [#46524](https://github.com/ClickHouse/ClickHouse/pull/46524) ([artem-yadr](https://github.com/artem-yadr)).
* Анализ projection заново реализован на основе query plan. Добавлена настройка `query_plan_optimize_projection=1` для переключения между старой и новой версиями. Исправляет [#44963](https://github.com/ClickHouse/ClickHouse/issues/44963). [#46537](https://github.com/ClickHouse/ClickHouse/pull/46537) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* По умолчанию в output format теперь используется Parquet v2 вместо v1. Добавлена настройка `output_format_parquet_version` для управления версией Parquet, возможные значения: `v1_0`, `v2_4`, `v2_6`, `v2_latest` (по умолчанию). [#46617](https://github.com/ClickHouse/ClickHouse/pull/46617) ([Kruglov Pavel](https://github.com/Avogar)).
* Не для changelog — часть [#42648](https://github.com/ClickHouse/ClickHouse/issues/42648). [#46632](https://github.com/ClickHouse/ClickHouse/pull/46632) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Разрешено игнорировать ошибки при записи в MATERILIZED VIEW (добавлена новая настройка `materialized_views_ignore_errors`, по умолчанию `false`, но для сброса логов в таблицы `system.*_log` она безусловно устанавливается в `true`). [#46658](https://github.com/ClickHouse/ClickHouse/pull/46658) ([Azat Khuzhin](https://github.com/azat)).
* `input&#95;format&#95;json&#95;ignore&#95;unknown&#95;keys&#95;in&#95;named&#95;tuple` теперь включена по умолчанию. [#46742](https://github.com/ClickHouse/ClickHouse/pull/46742) ([Kruglov Pavel](https://github.com/Avogar)).
* Теперь с помощью нового синтаксиса configuration можно настраивать Kafka topics, в имени которых есть точки. [#46752](https://github.com/ClickHouse/ClickHouse/pull/46752) ([Robert Schulze](https://github.com/rschu1ze)).
* Исправлены эвристики, проверяющие шаблоны hyperscan на наличие проблемных повторов. [#46819](https://github.com/ClickHouse/ClickHouse/pull/46819) ([Robert Schulze](https://github.com/rschu1ze)).
* Не сообщать о существовании узла ZK в system.errors, если block был создан другой репликой одновременно. [#46820](https://github.com/ClickHouse/ClickHouse/pull/46820) ([Raúl Marín](https://github.com/Algunenano)).
* Разрешить PREWHERE для Merge с разными выражениями DEFAULT для столбца. [#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* Увеличен лимит открытых файлов в `clickhouse-local`. Теперь он сможет читать из таблиц `web` на серверах с очень большим количеством ядер CPU. Не снижать скорость чтения из движка таблицы URL в случае слишком большого числа открытых файлов. Это закрывает [#46852](https://github.com/ClickHouse/ClickHouse/issues/46852). [#46853](https://github.com/ClickHouse/ClickHouse/pull/46853) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исключения, возникающие, когда не удаётся разобрать числа, теперь имеют более понятные сообщения. [#46917](https://github.com/ClickHouse/ClickHouse/pull/46917) ([Robert Schulze](https://github.com/rschu1ze)).
* Добавлено обновление `system.backups` после каждой обработанной задачи. [#46989](https://github.com/ClickHouse/ClickHouse/pull/46989) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* Разрешено преобразование типов в Native input format. Добавлена настройка `input_format_native_allow_types_conversion`, которая управляет этим поведением (включена по умолчанию). [#46990](https://github.com/ClickHouse/ClickHouse/pull/46990) ([Kruglov Pavel](https://github.com/Avogar)).
* Разрешено использование IPv4 в функции `range` для генерации диапазонов IP-адресов. [#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Изменения Role иногда не применялись автоматически до [https://github.com/ClickHouse/ClickHouse/pull/46772](https://github.com/ClickHouse/ClickHouse/pull/46772). Этот PR лишь добавляет тесты. [#47002](https://github.com/ClickHouse/ClickHouse/pull/47002) ([Ilya Golshtein](https://github.com/ilejn)).
* Улучшено сообщение об исключении, когда невозможно переместить part с одного volume/disk на другой. [#47032](https://github.com/ClickHouse/ClickHouse/pull/47032) ([alesapin](https://github.com/alesapin)).
* Добавлена поддержка типа `Bool` в функции `JSONType`. Ранее для bool values по ошибке возвращался тип `Null`. [#47046](https://github.com/ClickHouse/ClickHouse/pull/47046) ([Anton Popov](https://github.com/CurtizJ)).
* Использовать параметр &#95;request&#95;body для настройки предопределённых HTTP-запросов. [#47086](https://github.com/ClickHouse/ClickHouse/pull/47086) ([Constantine Peresypkin](https://github.com/pkit)).
* Удалено логирование пользовательской структуры disk. [#47103](https://github.com/ClickHouse/ClickHouse/pull/47103) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Разрешены вложенные пользовательские disks. Ранее пользовательские disks поддерживали только плоскую структуру disk. [#47106](https://github.com/ClickHouse/ClickHouse/pull/47106) ([Kseniia Sumarokova](https://github.com/kssenii)).

Это закрывает [#13541](https://github.com/ClickHouse/ClickHouse/issues/13541). [#47114](https://github.com/ClickHouse/ClickHouse/pull/47114) ([Kruglov Pavel](https://github.com/Avogar)).
