<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* * Исправлен учёт памяти для `OPTIMIZE TABLE`/слияний — теперь учитываются лимиты памяти запроса и сэмплирование для `OPTIMIZE TABLE`/слияний. [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* Использование `lcm`/`gcd` для чисел с плавающей точкой запрещено. [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* Побитовые функции (`bitAnd`, `bitOr` и т. д.) запрещены для аргументов типа с плавающей точкой. Теперь необходимо явно приводить их к целочисленному типу. [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### Новая возможность
</div>

* добавлена поддержка опции long в zstd для более эффективного сжатия столбцов типа String и экономии места. [#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * Добавлена поддержка сопоставления имён LDAP-групп и значений атрибутов в целом с локальными ролями для пользователей из каталогов пользователей LDAP. [#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* Тип данных `Nested` теперь поддерживает произвольные уровни вложенности. Добавлены подстолбцы сложных типов, такие как `size0` в `Array`, `null` в `Nullable` и имена элементов `Tuple`, которые можно читать без чтения всего столбца. [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* Добавлена поддержка аргумента `Tuple` для функций `argMin` и `argMax`. [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Добавлена поддержка `Nullable` для `FlatDictionary`, `HashedDictionary`, `ComplexKeyHashedDictionary`, `DirectDictionary`, `ComplexKeyDirectDictionary`, `RangeHashedDictionary`. [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* Запрещено использовать столбец с плавающей запятой в качестве ключа партиционирования; см.: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* Добавлена функция decodeXMLComponent для декодирования символов XML. `SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* Добавлен движок таблицы PostgreSQL (для select/insert, с поддержкой многомерных массивов), а также табличная функция. Добавлен источник словаря PostgreSQL. Добавлен движок базы данных PostgreSQL. [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлен синтаксис `SELECT ALL`. Закрывает [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706). [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* Добавлены три функции для типа данных map: 1. mapContains(map, key) — для проверки, содержит ли map.keys ключ из второго параметра. 2. mapKeys(map) — возвращает все ключи в формате Array 3. mapValues(map) — возвращает все значения в формате Array. [#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* Добавлена поддержка сочетания клавиш MetaKey+Enter в интерфейсе play. [#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* Функция formatDateTime поддерживает спецификатор %Q для форматирования даты в квартал. ... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* ... [#19261](https://github.com/ClickHouse/ClickHouse/pull/19261) ([RegulusZ](https://github.com/RegulusZ)).
* В system.query&#95;log добавлены имена объектов фабрик, созданных во время запроса. Закрывает [#18495](https://github.com/ClickHouse/ClickHouse/issues/18495). [#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлена математическая функция `sign`. [#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).
* Добавлены функции `parseDateTimeBestEffortUSOrZero`, `parseDateTimeBestEffortUSOrNull`. [#19712](https://github.com/ClickHouse/ClickHouse/pull/19712) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#19764](https://github.com/ClickHouse/ClickHouse/pull/19764) ([emhlbmc](https://github.com/emhlbmc)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Для подключений к S3 используется пул соединений, управляемый настройкой `s3_max_connections`. [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Функции `sumIf()` и `sum(if())` переписываются в `countIf()`, когда это логически эквивалентно. [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* Обновлён libcxx и используется нестабильный ABI для повышения производительности. [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* Ускорено удаление частей за счёт уменьшения числа системных вызовов `stat`. Это возвращает оптимизацию, которая существовала некоторое время назад. Интерфейс `IDisk` стал безопаснее. Это закрывает [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065). [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Ускорена агрегатная функция `sum`. Улучшение заметно только на синтетических бенчмарках и не слишком практично. [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка разделения шага `Filter` в плане запроса на пару `Expression + Filter`. Вместе с оптимизацией слияния `Expression + Expression` ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)) это может отложить вычисление некоторых выражений до шага после `Filter`. [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Снижена конкуренция за блокировки в нескольких слоях движка Buffer. [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* Незначительно снижена задержка сервера за счёт устранения доступа к конфигурации при каждом соединении. [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

[#19736](https://github.com/ClickHouse/ClickHouse/pull/19736) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
