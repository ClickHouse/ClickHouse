<div id="2022-changelog">
  # Журнал изменений за 2022 год
</div>

<div id="clickhouse-release-v217104-stable-fixme-as-compared-to-v21797-stable">
  ### Релиз ClickHouse v21.7.10.4-stable FIXME по сравнению с v21.7.9.7-stable
</div>

<div id="improvement">
  #### Улучшения
</div>

* Бэкпорт в [#28898](https://github.com/ClickHouse/ClickHouse/issues/28898): использование реального tmp-файла вместо предопределённого &quot;rows&#95;sources&quot; для вертикальных слияний. Это позволяет избежать создания лишних каталогов на tmp-дисках. [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпорт в [#27925](https://github.com/ClickHouse/ClickHouse/issues/27925): Исправлено приведение типов в стиле PostgreSQL (оператор `::`) для отрицательных чисел. [#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпорт в [#28752](https://github.com/ClickHouse/ClickHouse/issues/28752): Исправлено преобразование цепочки дизъюнкций в `IN` (управляется настройкой `optimize_min_equality_disjunction_chain_length`) в распределённых запросах с настройкой `legacy_column_name_of_tuple_literal = 0`. [#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователям, в официальном стабильном релизе)
</div>

* Бэкпорт в [#28509](https://github.com/ClickHouse/ClickHouse/issues/28509): Исправлена возможная утечка наблюдений в ZooKeeper при фоновой обработке очереди распределённой DDL. Закрывает [#26036](https://github.com/ClickHouse/ClickHouse/issues/26036). [#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпорт в [#28570](https://github.com/ClickHouse/ClickHouse/issues/28570): Исправлена ошибка, которая могла приводить к сообщению `Existing table metadata in ZooKeeper differs in sorting key expression.` после ALTER для `ReplicatedVersionedCollapsingMergeTree`. Исправляет [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515). [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#28598](https://github.com/ClickHouse/ClickHouse/issues/28598): Исправлена ошибка `There is no subcolumn` при SELECT из таблиц, в которых есть столбцы `Nested` и скалярные столбцы с точкой в имени и тем же префиксом, что и у `Nested` (например, `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`). [#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпорт в [#28742](https://github.com/ClickHouse/ClickHouse/issues/28742): Исправлен coredump при создании распределённых таблиц, если переданы неверные параметры. [#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* Бэкпорт в [#28788](https://github.com/ClickHouse/ClickHouse/issues/28788): Исправлено безобидное состояние гонки в ReplicatedMergeTreeQueue. Пользователю оно не должно быть заметно, но может приводить к трудноуловимым ошибкам. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#28947](https://github.com/ClickHouse/ClickHouse/issues/28947): Исправлено чтение подстолбцов из компактных частей. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпорт в [#28931](https://github.com/ClickHouse/ClickHouse/issues/28931): Исправлена работа функций для работы с массивами высшего порядка (`SIGSEGV` для `arrayCompact`/`ILLEGAL_COLUMN` для `arrayDifference`/`arrayCumSumNonNegative`) с константами. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
