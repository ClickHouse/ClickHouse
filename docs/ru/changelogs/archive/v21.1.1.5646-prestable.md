<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Запрещён `toUnixTimestamp(Date())` (раньше он просто возвращал представление `Date` в виде `UInt16`). [#17376](https://github.com/ClickHouse/ClickHouse/pull/17376) ([Azat Khuzhin](https://github.com/azat)).
* Удалены агрегатные функции `timeSeriesGroupSum`, `timeSeriesGroupRateSum`, потому что, как сказал один мой друг, они никогда не работали. Это исправляет [#16869](https://github.com/ClickHouse/ClickHouse/issues/16869). Если вам всё же удалось использовать эти функции, напишите письмо на clickhouse-feedback@yandex-team.com. [#17423](https://github.com/ClickHouse/ClickHouse/pull/17423) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Настройка `input_format_null_as_default` теперь по умолчанию включена. [#17525](https://github.com/ClickHouse/ClickHouse/pull/17525) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* По умолчанию значение `insert_quorum_parallel` установлено в 1. Это существенно удобнее, чем «последовательные» quorum inserts. Но если вы полагаетесь на sequential consistency, следует вернуть значение этой настройки обратно в ноль. [#17567](https://github.com/ClickHouse/ClickHouse/pull/17567) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Для `ALTER MODIFY SETTING` введено ограничение на изменение настроек хранилища, влияющих на части данных (`write_final_mark` и `enable_mixed_granularity_parts`). [#18306](https://github.com/ClickHouse/ClickHouse/pull/18306) ([Amos Bird](https://github.com/amosbird)).
* Проверяются ограничения настроек для настроек профиля из config. server не запустится, если `users.xml` содержит настройки, не удовлетворяющие соответствующим ограничениям. [#18486](https://github.com/ClickHouse/ClickHouse/pull/18486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Удалена функция `sumburConsistentHash`. Это закрывает [#18120](https://github.com/ClickHouse/ClickHouse/issues/18120). [#18656](https://github.com/ClickHouse/ClickHouse/pull/18656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлены операторы `DIV` и `MOD`. `DIV` реализует целочисленное деление. Это необходимо для совместимости с MySQL и для `sqllogictest`. Это закрывает [#18707](https://github.com/ClickHouse/ClickHouse/issues/18707). Это может привести к несовместимостям, если вы используете `DIV` или `MOD` в качестве имён столбцов или псевдонимов. В случае несовместимости указывайте псевдонимы после ключевого слова `AS` или заключайте идентификаторы в кавычки (либо двойные, либо обратные). [#18760](https://github.com/ClickHouse/ClickHouse/pull/18760) ([Du Chuan](https://github.com/spongedu)).

<div id="new-feature">
  #### Новая возможность
</div>

* Используется [https://github.com/lemire/fast&#95;float](https://github.com/lemire/fast_float) для разбора чисел с плавающей точкой. [#16787](https://github.com/ClickHouse/ClickHouse/pull/16787) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#16819](https://github.com/ClickHouse/ClickHouse/pull/16819) ([pronvis](https://github.com/pronvis)).
* Добавлен новый комбинатор агрегатных функций `-SimpleState` для создания типов SimpleAggregateFunction через запрос. Это полезно при определении MaterializedView на движке AggregatingMergeTree, а также пригодится для проекций. [#16853](https://github.com/ClickHouse/ClickHouse/pull/16853) ([Amos Bird](https://github.com/amosbird)).
* Добавлены агрегатные функции `mannWitneyUTest`, `studentTTest` и `welchTTest`. RankCorr немного переработан. [#16883](https://github.com/ClickHouse/ClickHouse/pull/16883) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлена настройка optimize&#95;on&#95;insert. Когда она включена, к вставленному блоку данных применяется то же преобразование, как если бы для этого блока было выполнено слияние (например, Replacing, Collapsing, Aggregating...). Эта настройка будет включена по умолчанию. Это может повлиять на поведение Materialized View и MaterializeMySQL (см. подробное описание). Это закрывает [#10683](https://github.com/ClickHouse/ClickHouse/issues/10683). [#16954](https://github.com/ClickHouse/ClickHouse/pull/16954) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлена поддержка сжатия/распаковки `*.zst`. Это позволяет использовать `*.zst` в функции `file()` и `Content-encoding: zstd` в HTTP-клиенте. Это закрывает [#16791 ](https://github.com/ClickHouse/ClickHouse/issues/16791). [#17144](https://github.com/ClickHouse/ClickHouse/pull/17144) ([Abi Palagashvili](https://github.com/fibersel)).
* * IP-словарь напрямую поддерживает типы `IPv4` / `IPv6`. [#17571](https://github.com/ClickHouse/ClickHouse/pull/17571) ([Vladimir C](https://github.com/vdimir)).
* связано: [#16176](https://github.com/ClickHouse/ClickHouse/issues/16176) Использование: `set limit = 10; set offset = 20;` эти две настройки будут влиять на SELECT-запрос так, как если бы к нему было добавлено `select * from ($your_original_select_query) tmp limit xxx offset xxx;`. [#17633](https://github.com/ClickHouse/ClickHouse/pull/17633) ([hexiaoting](https://github.com/hexiaoting)).
* Добавлены асинхронные метрики общего количества строк, байтов и частей в таблицах MergeTree. Это исправляет [#11714](https://github.com/ClickHouse/ClickHouse/issues/11714). [#17639](https://github.com/ClickHouse/ClickHouse/pull/17639) ([flynn](https://github.com/ucasfl)).
* Введён синтаксис `DETACH TABLE/VIEW ... PERMANENTLY`, чтобы после перезапуска таблица больше не появлялась автоматически (только по явному запросу). Таблицу по-прежнему можно снова подключить, используя короткий синтаксис ATTACH TABLE. Реализует [#5555](https://github.com/ClickHouse/ClickHouse/issues/5555). Исправляет [#13850](https://github.com/ClickHouse/ClickHouse/issues/13850). [#17642](https://github.com/ClickHouse/ClickHouse/pull/17642) ([filimonov](https://github.com/filimonov)).
* Добавлена новая таблица `system.distributed_ddl_queue`, которая отображает запросы в очереди DDL-воркера. [#17656](https://github.com/ClickHouse/ClickHouse/pull/17656) ([Bharat Nallan](https://github.com/bharatnc)).
* Добавлена функция `encodeXMLComponent` для экранирования символов при помещении строки в текстовый узел XML или в атрибут. [#17659](https://github.com/ClickHouse/ClickHouse/pull/17659) ([nauta](https://github.com/nautaa)).
* Теперь клиент ClickHouse поддерживает открытие EDITOR для редактирования команд. `Alt-Shift-E`. [#17665](https://github.com/ClickHouse/ClickHouse/pull/17665) ([Amos Bird](https://github.com/amosbird)).
* Добавлена поддержка протокола PROXYv1 для обёртывания нативного TCP-интерфейса. Разрешено использовать IP-адрес, переданный прокси, как ключ для квот (применяется к адресу PROXYv1 и к X-Forwarded-For из HTTP-интерфейса). Это полезно, если вы предоставляете доступ к ClickHouse только через доверенный proxy (например, CloudFlare), но хотите учитывать ресурсы пользователей по их исходным IP-адресам. Это исправляет [#17268](https://github.com/ClickHouse/ClickHouse/issues/17268). [#17707](https://github.com/ClickHouse/ClickHouse/pull/17707) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена возможность использовать пользовательский список TLD в функциях `firstSignificantSubdomainCustom`, `cutToFirstSignificantSubdomainCustom`. [#17748](https://github.com/ClickHouse/ClickHouse/pull/17748) ([Azat Khuzhin](https://github.com/azat)).
* В Clickhouse-benchmark добавлен параметр запроса. [#17832](https://github.com/ClickHouse/ClickHouse/pull/17832) ([Maksim Kita](https://github.com/kitaisreal)).
* Расширен синтаксис `OPTIMIZE ... DEDUPLICATE`, чтобы можно было явно указывать (или неявно, с помощью asterisk/преобразователей столбцов) список столбцов для проверки на дубликаты. ... [#17846](https://github.com/ClickHouse/ClickHouse/pull/17846) ([Vasily Nemkov](https://github.com/Enmk)).
* В MergeTreeSettings добавлены настройки `min_compress_block_size` и `max_compress_block_size`, которые имеют более высокий приоритет, чем глобальные настройки, и вступают в силу, когда заданы. Закрывает [13890](https://github.com/ClickHouse/ClickHouse/issues/13890). [#17867](https://github.com/ClickHouse/ClickHouse/pull/17867) ([flynn](https://github.com/ucasfl)).
* Реализован запрос `ATTACH TABLE name FROM 'path/to/data/' (col1 Type1, ...`. Он создаёт новую таблицу с указанной структурой и подключает данные таблицы из указанного каталога в `user_files`. [#17903](https://github.com/ClickHouse/ClickHouse/pull/17903) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Добавлены агрегатные функции `arrayMin`, `arrayMax`, `arrayAvg`. [#18032](https://github.com/ClickHouse/ClickHouse/pull/18032) ([Maksim Kita](https://github.com/kitaisreal)).
* Поддерживается оператор `SHOW SETTINGS` для вывода параметров из system.settings. Также поддерживаются `SHOW CHANGED SETTINGS` и условие `LIKE/ILIKE`. [#18056](https://github.com/ClickHouse/ClickHouse/pull/18056) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Добавлена возможность создавать таблицу через AS SELECT с указанием столбцов. Пример: `CREATE TABLE t1 (x String) ENGINE = Memory AS SELECT 1;`. [#18060](https://github.com/ClickHouse/ClickHouse/pull/18060) ([Maksim Kita](https://github.com/kitaisreal)).
* * Словарь IP поддерживает выборку по ключу. Решает [#18241](https://github.com/ClickHouse/ClickHouse/issues/18241). [#18480](https://github.com/ClickHouse/ClickHouse/pull/18480) ([Vladimir C](https://github.com/vdimir)).
* Реализованы запросы `REPLACE TABLE` и `CREATE OR REPLACE TABLE`. [#18521](https://github.com/ClickHouse/ClickHouse/pull/18521) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Добавлена функция `byteSize` для оценки несжатого размера её аргументов в памяти в байтах. Например, для аргумента UInt32 она вернёт константу 4, а для аргумента String — длину строки + 9. Функция может принимать несколько аргументов. Типичный вариант использования — `byteSize(*)`. [#18579](https://github.com/ClickHouse/ClickHouse/pull/18579) ([Ping Yu](https://github.com/pingyu)).
* В `system.part_log` добавлен столбец `query_id` для частей, созданных при вставке. Закрывает [#10097](https://github.com/ClickHouse/ClickHouse/issues/10097). [#18644](https://github.com/ClickHouse/ClickHouse/pull/18644) ([flynn](https://github.com/ucasfl)).
* Добавлена новая настройка хранилища `max_partitions_to_read` для таблиц семейства MergeTree. Она ограничивает максимальное количество партиций, к которым можно обратиться в одном запросе. Также добавлена пользовательская настройка `force_max_partition_limit` для принудительного применения этого ограничения. [#18712](https://github.com/ClickHouse/ClickHouse/pull/18712) ([Amos Bird](https://github.com/amosbird)).
* Функция `position` теперь поддерживает синтаксис `position(needle in haystack)` для совместимости с SQL. Это закрывает [#18701](https://github.com/ClickHouse/ClickHouse/issues/18701). ... [#18779](https://github.com/ClickHouse/ClickHouse/pull/18779) ([Jianmei Zhang](https://github.com/zhangjmruc)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Незначительно улучшена производительность парсинга чисел с плавающей запятой. [#16809](https://github.com/ClickHouse/ClickHouse/pull/16809) ([Maksim Kita](https://github.com/kitaisreal)).
* Улучшена производительность функции `repeat`. [#16937](https://github.com/ClickHouse/ClickHouse/pull/16937) ([satanson](https://github.com/satanson)).
* Устранена проблема с производительностью чтения из таблиц `Merge` при работе с огромным количеством таблиц `MergeTree`. Исправлено в [#7748](https://github.com/ClickHouse/ClickHouse/issues/7748). [#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).
* Теперь комбинатор `-If` дедвиртуализирован, а `count` корректно векторизован. Связано с [https://github.com/ClickHouse/ClickHouse/pull/17041](https://github.com/ClickHouse/ClickHouse/pull/17041). [#17043](https://github.com/ClickHouse/ClickHouse/pull/17043) ([Amos Bird](https://github.com/amosbird)).
* Улучшена производительность AggregatingMergeTree с SimpleAggregateFunction(String) в PK. [#17109](https://github.com/ClickHouse/ClickHouse/pull/17109) ([Azat Khuzhin](https://github.com/azat)).
* Добавлена настройка `remerge_sort_lowered_memory_bytes_ratio` (если использование памяти после remerge не уменьшается на эту величину, remerge будет отключён). [#17539](https://github.com/ClickHouse/ClickHouse/pull/17539) ([Azat Khuzhin](https://github.com/azat)).
* Ускорена реализация `IPv6CIDRToRange`. [#17569](https://github.com/ClickHouse/ClickHouse/pull/17569) ([Vladimir C](https://github.com/vdimir)).
* Для преобразования float в string теперь используется алгоритм dragonbox вместо ryu. [#17831](https://github.com/ClickHouse/ClickHouse/pull/17831) ([Maksim Kita](https://github.com/kitaisreal)).
* Оптимизировано чтение из StorageMemory. [#18052](https://github.com/ClickHouse/ClickHouse/pull/18052) ([Maksim Kita](https://github.com/kitaisreal)).
* Пустые блоки больше не отправляются в сегменты при синхронном INSERT в distributed таблицу. Это закрывает [#14571](https://github.com/ClickHouse/ClickHouse/issues/14571). [#18775](https://github.com/ClickHouse/ClickHouse/pull/18775) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `PODArray` заменён на `PODArrayWithStackMemory` в `AggregateFunctionWindowFunnelData` для повышения производительности функции `windowFunnel`. [#18817](https://github.com/ClickHouse/ClickHouse/pull/18817) ([flynn](https://github.com/ucasfl)).
* Добавлена опция `--no-system-table` для `clickhouse-local`, позволяющая запускать его без системных таблиц. Это позволяет избежать инициализации `DateLUT`, которая при запуске может занимать заметное время (десятки Milliseconds). [#18899](https://github.com/ClickHouse/ClickHouse/pull/18899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
