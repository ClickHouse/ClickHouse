<div id="clickhouse-release-v208144-lts-fixme-as-compared-to-v2081315-lts">
  ### Релиз ClickHouse v20.8.14.4-lts FIXME по сравнению с версией v20.8.13.15-lts
</div>

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#21235](https://github.com/ClickHouse/ClickHouse/issues/21235): Значением опции MYSQL&#95;OPT&#95;RECONNECT теперь можно управлять с помощью параметра &quot;opt&#95;reconnect&quot; в разделе config реплики MySQL. [#19998](https://github.com/ClickHouse/ClickHouse/pull/19998) ([Alexander Kazakov](https://github.com/Akazz)).
* Бэкпортировано в [#21203](https://github.com/ClickHouse/ClickHouse/issues/21203): При загрузке config для mysql source ClickHouse теперь перемешивает список реплик с одинаковым приоритетом, чтобы обеспечить выбор конечной точки MySQL по алгоритму round-robin. Это закрывает [#20629](https://github.com/ClickHouse/ClickHouse/issues/20629). [#20632](https://github.com/ClickHouse/ClickHouse/pull/20632) ([Alexander Kazakov](https://github.com/Akazz)).
* Бэкпортировано в [#21336](https://github.com/ClickHouse/ClickHouse/issues/21336): Источник словаря MySQL теперь будет повторно выполнять попытку при неожиданных сбоях соединения (Lost connection to MySQL server during query), которые иногда происходят в SSL/TLS‑соединениях. [#21237](https://github.com/ClickHouse/ClickHouse/pull/21237) ([Alexander Kazakov](https://github.com/Akazz)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#20950](https://github.com/ClickHouse/ClickHouse/issues/20950): Исправлена инвалидация set index, когда в подзапросе есть константные столбцы. Это исправляет [#17246](https://github.com/ClickHouse/ClickHouse/issues/17246). [#17249](https://github.com/ClickHouse/ClickHouse/pull/17249) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#20948](https://github.com/ClickHouse/ClickHouse/issues/20948): Исправлен сбой при чтении из таблицы `JOIN` с типами `LowCardinality`. Исправляет [#17228](https://github.com/ClickHouse/ClickHouse/issues/17228). [#17397](https://github.com/ClickHouse/ClickHouse/pull/17397) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#20903](https://github.com/ClickHouse/ClickHouse/issues/20903): Исправлена вставка столбца `LowCardinality` в таблицу с движком `TinyLog`. Исправляет [#18629](https://github.com/ClickHouse/ClickHouse/issues/18629). [#19010](https://github.com/ClickHouse/ClickHouse/pull/19010) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#20899](https://github.com/ClickHouse/ClickHouse/issues/20899): Исправлена ошибка, из-за которой при одновременном выполнении запросов `ALTER` и `DROP` могла происходить блокировка во время обработки таблицы ReplicatedMergeTree. [#19237](https://github.com/ClickHouse/ClickHouse/pull/19237) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#20892](https://github.com/ClickHouse/ClickHouse/issues/20892): Исправлено обращение к уже освобождённой памяти в CompressedWriteBuffer объекта Connection после отключения. [#19599](https://github.com/ClickHouse/ClickHouse/pull/19599) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#20888](https://github.com/ClickHouse/ClickHouse/issues/20888): Исправлена редкая ошибка, из-за которой некоторые реплицируемые операции (например, mutation) не могли обработать отдельные части после повреждения данных. Исправляет [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593). [#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#21049](https://github.com/ClickHouse/ClickHouse/issues/21049): Исправлено использование комбинатора `-Distinct` вместе с комбинатором `-State` в агрегатных функциях. [#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#21130](https://github.com/ClickHouse/ClickHouse/issues/21130): Исправлено поведение, при котором `ALTER MODIFY COLUMN` создавал mutation, заведомо завершающуюся ошибкой. [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#21159](https://github.com/ClickHouse/ClickHouse/issues/21159): Исправлено применение `input_format_null_as_default` для типов Nullable. Это исправляет [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116). [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#21378](https://github.com/ClickHouse/ClickHouse/issues/21378): Исправлена ошибка `Bad cast from type ... to DB::ColumnLowCardinality` при вставке в таблицу со столбцом `LowCardinality` из формата `Values`. Исправляет [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140). [#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
