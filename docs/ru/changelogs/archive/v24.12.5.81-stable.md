<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534): Исправлен расчёт размера в памяти для столбцов `LowCardinality`. [#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005): Выяснилось, что управление параллелизмом могло приводить к несправедливому распределению CPU между INSERT и SELECT. Когда все слоты CPU безусловно выделялись (без конкуренции) под INSERT с `max_threads` = 1, SELECT с высокими значениями `max_threads` работали медленно, поскольку фактически использовали только один поток. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535): Более точный учет настройки `max_joined_block_size_rows` для алгоритма JOIN `parallel_hash`. Это помогает избежать повышенного потребления памяти по сравнению с алгоритмом `hash`. [#74630](https://github.com/ClickHouse/ClickHouse/pull/74630) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#75844](https://github.com/ClickHouse/ClickHouse/issues/75844): Добавлены проверка и логирование при расшифровке и декомпрессии. [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#76046](https://github.com/ClickHouse/ClickHouse/issues/76046): Улучшение Keeper: для повышения производительности отключено вычисление дайджеста при коммите в хранилище в памяти. Его можно включить с помощью конфига `keeper_server.digest_enabled_on_commit`. При предварительной обработке запросов дайджест по-прежнему вычисляется. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#75709](https://github.com/ClickHouse/ClickHouse/issues/75709): Для совместимости отключена отправка настроек от сервера клиенту (`send_settings_to_client=false`) (позже эта возможность будет заново реализована в виде клиентской настройки для большего удобства использования). [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805): Добавлен конфиг `memory_worker_correct_memory_tracker`, позволяющий корректировать внутренний трекер памяти на основе информации из разных источников, периодически считываемой в фоновом потоке. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069): Добавлена метрика `MemoryTrackingUncorrected`, показывающая значение внутреннего глобального трекера памяти, не скорректированное по RSS. [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).

Эта уязвимость была обнаружена в рамках [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) Арсением Дугиным. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
