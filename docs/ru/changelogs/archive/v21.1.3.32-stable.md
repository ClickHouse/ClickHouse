<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#19654](https://github.com/ClickHouse/ClickHouse/issues/19654): исправлена проблема с преобразованием типов данных в движке MySQL ... [#18124](https://github.com/ClickHouse/ClickHouse/pull/18124) ([bo zeng](https://github.com/mis98zb)).
* Бэкпортировано в [#19423](https://github.com/ClickHouse/ClickHouse/issues/19423): отключена свертка констант для подзапросов на этапе анализа, если результат не может быть вычислен. [#18446](https://github.com/ClickHouse/ClickHouse/pull/18446) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#19458](https://github.com/ClickHouse/ClickHouse/issues/19458): исправлена ошибка `There is no checkpoint` при вставке данных через HTTP-интерфейс с использованием формата `Template` или `CustomSeparated`. Исправляет [#19021](https://github.com/ClickHouse/ClickHouse/issues/19021). [#19072](https://github.com/ClickHouse/ClickHouse/pull/19072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#19271](https://github.com/ClickHouse/ClickHouse/issues/19271): исправлена ошибка, из-за которой параллельные запросы `ALTER` и `DROP` могли зависать при обработке таблицы ReplicatedMergeTree. [#19237](https://github.com/ClickHouse/ClickHouse/pull/19237) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#19425](https://github.com/ClickHouse/ClickHouse/issues/19425): исправлена ошибка `Cannot convert column now64() because it is constant but values of constants are different in source and result`. Продолжение [#7156](https://github.com/ClickHouse/ClickHouse/issues/7156). [#19316](https://github.com/ClickHouse/ClickHouse/pull/19316) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#19456](https://github.com/ClickHouse/ClickHouse/issues/19456): исправлен возможный неправильный результат или segfault при агрегации, когда materialized view и его целевая таблица имеют разную структуру. Исправляет [#18063](https://github.com/ClickHouse/ClickHouse/issues/18063). [#19322](https://github.com/ClickHouse/ClickHouse/pull/19322) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#19554](https://github.com/ClickHouse/ClickHouse/issues/19554): исправлен столбец system.parts &#95;state (LOGICAL&#95;ERROR при запросе этого столбца из-за неверного порядка). [#19346](https://github.com/ClickHouse/ClickHouse/pull/19346) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#19506](https://github.com/ClickHouse/ClickHouse/issues/19506): добавлены тесты производительности для `cast`, `accurateCast`, `accurateCastOrNull`. [#19354](https://github.com/ClickHouse/ClickHouse/pull/19354) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#19471](https://github.com/ClickHouse/ClickHouse/issues/19471): - исправлено значение по умолчанию в типах JOIN с ненулевым значением по умолчанию (например, в некоторых Enum). Закрывает [#18197](https://github.com/ClickHouse/ClickHouse/issues/18197). [#19360](https://github.com/ClickHouse/ClickHouse/pull/19360) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#19438](https://github.com/ClickHouse/ClickHouse/issues/19438): исправлено возможное переполнение буфера в библиотеке Uber H3. См. [https://github.com/uber/h3/issues/392](https://github.com/uber/h3/issues/392). Это закрывает [#19219](https://github.com/ClickHouse/ClickHouse/issues/19219). [#19383](https://github.com/ClickHouse/ClickHouse/pull/19383) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#19485](https://github.com/ClickHouse/ClickHouse/issues/19485): В функциях encrypt/decrypt было возможно чтение неинициализированной памяти, если в качестве IV передавалась пустая строка. Это закрывает [#19391](https://github.com/ClickHouse/ClickHouse/issues/19391). [#19397](https://github.com/ClickHouse/ClickHouse/pull/19397) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#19615](https://github.com/ClickHouse/ClickHouse/issues/19615): Исправлена очень редкая ошибка, из-за которой мутация могла зависнуть после `DROP/DETACH/REPLACE/MOVE PARTITION`. В большинстве случаев она уже была частично исправлена в [#15537](https://github.com/ClickHouse/ClickHouse/issues/15537). [#19443](https://github.com/ClickHouse/ClickHouse/pull/19443) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#19507](https://github.com/ClickHouse/ClickHouse/issues/19507): Было возможно переполнение буфера при чтении памяти, если функция `addMonth` вызывалась со специально подобранными аргументами. Это исправляет [#19441](https://github.com/ClickHouse/ClickHouse/issues/19441). Это исправляет [#19413](https://github.com/ClickHouse/ClickHouse/issues/19413). [#19472](https://github.com/ClickHouse/ClickHouse/pull/19472) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#19539](https://github.com/ClickHouse/ClickHouse/issues/19539): Исправлен SIGSEGV при merge&#95;tree&#95;min&#95;rows&#95;for&#95;concurrent&#95;read/merge&#95;tree&#95;min&#95;bytes&#95;for&#95;concurrent&#95;read=0/UINT64&#95;MAX. [#19528](https://github.com/ClickHouse/ClickHouse/pull/19528) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#19640](https://github.com/ClickHouse/ClickHouse/issues/19640): Исправлено выражение id в запросе CREATE DICTIONARY. [#19571](https://github.com/ClickHouse/ClickHouse/pull/19571) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#19636](https://github.com/ClickHouse/ClickHouse/issues/19636): Запрос `DROP/DETACH TABLE table ON CLUSTER cluster SYNC` мог зависать; это исправлено. Исправляет [#19568](https://github.com/ClickHouse/ClickHouse/issues/19568). [#19572](https://github.com/ClickHouse/ClickHouse/pull/19572) ([Alexander Tokmakov](https://github.com/tavplubix)).

* Бэкпортировано в [#19738](https://github.com/ClickHouse/ClickHouse/issues/19738): Исправлен неверный результат функции `neighbor` для аргумента `LowCardinality`. Исправляет [#10333](https://github.com/ClickHouse/ClickHouse/issues/10333). [#19617](https://github.com/ClickHouse/ClickHouse/pull/19617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
