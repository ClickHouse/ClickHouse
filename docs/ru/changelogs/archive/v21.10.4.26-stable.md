<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#31731](https://github.com/ClickHouse/ClickHouse/issues/31731): улучшена производительность форматов вывода JSON и XML. [#31673](https://github.com/ClickHouse/ClickHouse/pull/31673) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#31573](https://github.com/ClickHouse/ClickHouse/issues/31573): лимит квоты не был достигнут, однако система считала, что он превышен. Этот PR исправляет [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователям, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#31518](https://github.com/ClickHouse/ClickHouse/issues/31518): Удалена функция not like из RPNElement. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* Бэкпортировано в [#31554](https://github.com/ClickHouse/ClickHouse/issues/31554): Исправлен `nullptr` в провайдере учетных данных STS для S3. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Бэкпортировано в [#31579](https://github.com/ClickHouse/ClickHouse/issues/31579): * Отключен `partial_merge_join_left_table_buffer_bytes`, пока не будет исправлена ошибка в этой оптимизации. См. [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)). * Удалена избыточная опция `partial_merge_join_optimizations`. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#31745](https://github.com/ClickHouse/ClickHouse/issues/31745): Запрос `RENAME TABLE` работал некорректно при попытке переименовать DDL-словарь в базе данных `Ordinary`; это исправлено. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#31794](https://github.com/ClickHouse/ClickHouse/issues/31794): Настройки `input_format_allow_errors_num` и `input_format_allow_errors_ratio` не работали при парсинге доменных типов, таких как `IPv4`; это исправлено. Исправляет [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686). [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#31830](https://github.com/ClickHouse/ClickHouse/issues/31830): Исправлена ошибка `there are no such cluster here` при выполнении запроса `ON CLUSTER`, если указанное имя кластера совпадает с именем базы данных `Replicated`. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#31815](https://github.com/ClickHouse/ClickHouse/issues/31815): Исправлено состояние гонки в формате вывода JSONEachRowWithProgress, когда данные и строки с прогрессом смешиваются в выводе. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#32016](https://github.com/ClickHouse/ClickHouse/issues/32016): Исправлена обработка псевдонимов в group by / order by / limit by при включенных позиционных аргументах. Закрывает [#31173](https://github.com/ClickHouse/ClickHouse/issues/31173). [#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#31762](https://github.com/ClickHouse/ClickHouse/issues/31762): Исправлено использование движка таблицы `Buffer` с типом `Map`. Исправляет [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546). [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#31892](https://github.com/ClickHouse/ClickHouse/issues/31892): Исправлена возможная ошибка assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` в формате TSKV. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#32031](https://github.com/ClickHouse/ClickHouse/issues/32031): Исправлено некорректное приведение типа Nullable при использовании первичного ключа Nullable. Это исправляет [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075). [#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird)).
* Выполнен бэкпорт в [#32074](https://github.com/ClickHouse/ClickHouse/issues/32074): исправлена ошибка в функции `transform` с аргументами типа `Decimal`. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* Выполнен бэкпорт в [#31939](https://github.com/ClickHouse/ClickHouse/issues/31939): - изменён путь конфигурации с `keeper_server.session_timeout_ms` на `keeper_server.coordination_settings.session_timeout_ms` при создании `KeeperTCPHandler` - то же самое для `operation_timeout`. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* Выполнен бэкпорт в [#31909](https://github.com/ClickHouse/ClickHouse/issues/31909): исправлена работа функций `empty` и `notEmpty` с аргументами типа `UUID`. Исправлено [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819). [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
