<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#39761](https://github.com/ClickHouse/ClickHouse/issues/39761): исправлено перемещение позиции чтения при чтении с зашифрованного диска. Этот PR исправляет [#38381](https://github.com/ClickHouse/ClickHouse/issues/38381). [#39687](https://github.com/ClickHouse/ClickHouse/pull/39687) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователям, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#39206](https://github.com/ClickHouse/ClickHouse/issues/39206): исправлено чтение разреженных столбцов из таблиц `MergeTree`, данные которых хранятся в S3. [#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#39381](https://github.com/ClickHouse/ClickHouse/issues/39381): исправлена ошибка `Not found column Type in block` в запросах SELECT с `PREWHERE` и оптимизациями чтения по порядку. [#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#39588](https://github.com/ClickHouse/ClickHouse/issues/39588): исправлены гонка данных и возможное переполнение буфера в куче в формате Avro. Закрывает [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094) Закрывает [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652). [#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#39610](https://github.com/ClickHouse/ClickHouse/issues/39610): исправлена ошибка с аргументом maxsplit для splitByChar, из-за которой он работал некорректно. [#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#39834](https://github.com/ClickHouse/ClickHouse/issues/39834): исправлено исключение `CANNOT_READ_ALL_DATA` при `local_filesystem_read_method=pread_threadpool`. Эта ошибка затрагивала только ядра Linux версий 5.9 и 5.10 согласно странице [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS). [#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
