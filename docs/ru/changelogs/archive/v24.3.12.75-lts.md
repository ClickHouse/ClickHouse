<div id="improvement">
  #### Улучшения

* Бэкпортировано в [#69607](https://github.com/ClickHouse/ClickHouse/issues/69607): Улучшен учёт памяти для cgroups v2, чтобы не учитывать объём, занимаемый страничным кэшем. [#65470](https://github.com/ClickHouse/ClickHouse/pull/65470) ([Nikita Taranov](https://github.com/nickitat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#69785](https://github.com/ClickHouse/ClickHouse/issues/69785): Исправлено Attach таблицы, когда `dbname` в pg содержит &quot;-&quot; в MaterializedPostgreSQL. [#62730](https://github.com/ClickHouse/ClickHouse/pull/62730) ([takakawa](https://github.com/takakawa)).
* Бэкпортировано в [#69461](https://github.com/ClickHouse/ClickHouse/issues/69461): Исправлено истечение срока действия записей в `RoleCache`. [#67748](https://github.com/ClickHouse/ClickHouse/pull/67748) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#68217](https://github.com/ClickHouse/ClickHouse/issues/68217): Исправлено разыменование NULL-указателя, вызванное специально сформированным запросом, из-за которого сервер аварийно завершался через hopEnd, hopStart, tumbleEnd и tumbleStart. [#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* Бэкпортировано в [#69437](https://github.com/ClickHouse/ClickHouse/issues/69437): После неожиданного перезапуска не удавалось запустить репликацию ReplicatedMergeTree из-за некорректной обработки part в состоянии covered-by-broken. [#68584](https://github.com/ClickHouse/ClickHouse/pull/68584) ([baolin](https://github.com/baolinhuang)).
* Бэкпортировано в [#69827](https://github.com/ClickHouse/ClickHouse/issues/69827): `ColumnsDescription::toString` теперь форматирует каждый столбец с использованием одного и того же объекта `IAST::FormatState`. В результате на диск и в ZooKeeper записываются единообразные метаданные столбцов. [#68733](https://github.com/ClickHouse/ClickHouse/pull/68733) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпортировано в [#69294](https://github.com/ClickHouse/ClickHouse/issues/69294): Исправлено слияние агрегированных данных для grouping sets. [#68744](https://github.com/ClickHouse/ClickHouse/pull/68744) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#70470](https://github.com/ClickHouse/ClickHouse/issues/70470): Исправлен бесконечный цикл после `restore replica` в ReplicatedMergeTree с zero copy. [#69293](https://github.com/ClickHouse/ClickHouse/pull/69293) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Бэкпортировано в [#69456](https://github.com/ClickHouse/ClickHouse/issues/69456): Исправлено неопределённое поведение, возникавшее, когда все попытки установить connection для вставок завершались неудачей. [#69390](https://github.com/ClickHouse/ClickHouse/pull/69390) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#69497](https://github.com/ClickHouse/ClickHouse/issues/69497): Исправлен `LOGICAL_ERROR` в функции `sqidDecode` ([#69450](https://github.com/ClickHouse/ClickHouse/issues/69450)). [#69451](https://github.com/ClickHouse/ClickHouse/pull/69451) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#69724](https://github.com/ClickHouse/ClickHouse/issues/69724): Сохранён исходный порядок условий при перемещении в prewhere. Ранее порядок мог меняться, что могло приводить к ошибкам в запросах, если порядок важен. [#69560](https://github.com/ClickHouse/ClickHouse/pull/69560) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#69668](https://github.com/ClickHouse/ClickHouse/issues/69668): Исправлена предварительная обработка мультизапросов Keeper после ошибки ZNOAUTH. [#69627](https://github.com/ClickHouse/ClickHouse/pull/69627) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#69792](https://github.com/ClickHouse/ClickHouse/issues/69792): getHyperrectangleForRowGroup больше не должен генерировать исключение, когда тип данных в файле Parquet нельзя преобразовать в запрошенный тип данных. Это решило проблему пользователя, когда в файле Parquet был тип данных Decimal64, а типом данных столбца был дата и время. [#69745](https://github.com/ClickHouse/ClickHouse/pull/69745) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпортировано в [#70089](https://github.com/ClickHouse/ClickHouse/issues/70089): Теперь безопасность SQL корректно работает с параметризованными представлениями. [#69984](https://github.com/ClickHouse/ClickHouse/pull/69984) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#70077](https://github.com/ClickHouse/ClickHouse/issues/70077): Закрывает [#69752](https://github.com/ClickHouse/ClickHouse/issues/69752). [#69985](https://github.com/ClickHouse/ClickHouse/pull/69985) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#70162](https://github.com/ClickHouse/ClickHouse/issues/70162): Исправлен некорректный LOGICAL&#95;ERROR при замене литералов в ranges. [#70122](https://github.com/ClickHouse/ClickHouse/pull/70122) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#70232](https://github.com/ClickHouse/ClickHouse/issues/70232): Добавлена проверка типа Nullable(Nothing) при ALTER TABLE MODIFY COLUMN/QUERY, чтобы предотвратить создание таблиц с таким типом данных. [#70123](https://github.com/ClickHouse/ClickHouse/pull/70123) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#70179](https://github.com/ClickHouse/ClickHouse/issues/70179): Исправлена гонка данных в методе decompress для ColumnObject/ColumnTuple, которая могла приводить к использованию памяти кучи после её освобождения. [#70137](https://github.com/ClickHouse/ClickHouse/pull/70137) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#70241](https://github.com/ClickHouse/ClickHouse/issues/70241): Исправлено отображение пароля в `system.query_log` для пользователей с методом аутентификации по паролю bcrypt. [#70148](https://github.com/ClickHouse/ClickHouse/pull/70148) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#70397](https://github.com/ClickHouse/ClickHouse/issues/70397): Исправлен сбой при некорректном использовании WITH FILL. [#70338](https://github.com/ClickHouse/ClickHouse/pull/70338) ([Raúl Marín](https://github.com/Algunenano)).
