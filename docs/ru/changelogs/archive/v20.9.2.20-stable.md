<div id="clickhouse-release-v209220-stable-fixme-as-compared-to-v20814513-prestable">
  ### Релиз ClickHouse v20.9.2.20-стабильный FIXME в сравнении с v20.8.1.4513-prestable
</div>

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена табличная функция `view`, которая превращает подзапрос в табличный объект. Это упрощает передачу запросов. Например, её можно использовать в табличных функциях remote/cluster. [#12567](https://github.com/ClickHouse/ClickHouse/pull/12567) ([Amos Bird](https://github.com/amosbird)).
* Теперь можно написать `select * apply(length) apply(max) from wide_string_table`, чтобы определить максимальную длину во всех строковых столбцах. Также доступны ещё два следующих варианта: [#14233](https://github.com/ClickHouse/ClickHouse/pull/14233) ([Amos Bird](https://github.com/amosbird)).
* Добавлена агрегатная функция RankCorrelationSpearman, которая вычисляет коэффициент ранговой корреляции. Продолжение [#11769](https://github.com/ClickHouse/ClickHouse/issues/11769). [#14411](https://github.com/ClickHouse/ClickHouse/pull/14411) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлена утилита для генерации базы данных по запросу. Продолжение [#10973](https://github.com/ClickHouse/ClickHouse/issues/10973). [#14442](https://github.com/ClickHouse/ClickHouse/pull/14442) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Оптимизированы запросы с LIMIT/LIMIT BY/ORDER BY для Distributed с GROUP BY sharding&#95;key (при включённых optimize&#95;skip&#95;unused&#95;shards и optimize&#95;distributed&#95;group&#95;by&#95;sharding&#95;key). [#10373](https://github.com/ClickHouse/ClickHouse/pull/10373) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">
  #### Улучшения
</div>

* Улучшения в StorageRabbitMQ: добавлена обработка сбоев connection и каналов, корректная обработка коммитов и сбоев вставки, улучшена работа exchange, добавлены долговечность queue, возможность возобновления queue и новые настройки queue. Исправлены тесты. [#12761](https://github.com/ClickHouse/ClickHouse/pull/12761) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлена авторизация Redis через requirepass. [#13688](https://github.com/ClickHouse/ClickHouse/pull/13688) ([Ivan Torgashov](https://github.com/it1804)).
* Добавлен аргумент precision для типа DateTime. [#13761](https://github.com/ClickHouse/ClickHouse/pull/13761) ([Winter Zhang](https://github.com/zhang2014)).
* Улучшена производительность Kafka engine за счет выделения отдельного потока для каждого consumer. Добавлен отдельный пул потоков для потоковых движков (таких как Kafka). [#13939](https://github.com/ClickHouse/ClickHouse/pull/13939) ([fastio](https://github.com/fastio)).
* Добавлен compression codec по умолчанию для частей в `system.part_log` с именем `default_compression_codec`. [#14116](https://github.com/ClickHouse/ClickHouse/pull/14116) ([alesapin](https://github.com/alesapin)).
* Wide integers из boost multiprecision заменены на реализацию из [https://github.com/cerevra/int](https://github.com/cerevra/int). [#14229](https://github.com/ClickHouse/ClickHouse/pull/14229) ([Artem Zuikov](https://github.com/4ertus2)).
* Primary key неявно преобразуется в NOT NULL в MaterializeMySQL (как в MySQL). Исправляет [#14114](https://github.com/ClickHouse/ClickHouse/issues/14114). [#14397](https://github.com/ClickHouse/ClickHouse/pull/14397) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена новая настройка system&#95;events&#95;show&#95;zero&#95;values, как предложено в [#11384](https://github.com/ClickHouse/ClickHouse/issues/11384). [#14404](https://github.com/ClickHouse/ClickHouse/pull/14404) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* Теперь обфускатор поддерживает тип UUID, как предложено в [#13163](https://github.com/ClickHouse/ClickHouse/issues/13163). [#14409](https://github.com/ClickHouse/ClickHouse/pull/14409) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* Создание sets для нескольких `JOIN` и `IN` теперь выполняется параллельно. Это может немного повысить производительность запросов с несколькими различными выражениями `IN subquery`. [#14412](https://github.com/ClickHouse/ClickHouse/pull/14412) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Теперь TTL будут применяться во время merge, если ранее они не были materialized. [#14438](https://github.com/ClickHouse/ClickHouse/pull/14438) ([alesapin](https://github.com/alesapin)).
* MySQL handler возвращает `OK` для запросов вида `SET @@var = value`. Такой оператор игнорируется. Это необходимо, потому что некоторые MySQL driver отправляют запрос `SET @@` для настройки после рукопожатия [#9336](https://github.com/ClickHouse/ClickHouse/issues/9336)#issuecomment-686222422 . [#14469](https://github.com/ClickHouse/ClickHouse/pull/14469) ([BohuTANG](https://github.com/BohuTANG)).
* Запрещен пустой аргумент time&#95;zone в функциях типа `toStartOf*`. [#14509](https://github.com/ClickHouse/ClickHouse/pull/14509) ([Bharat Nallan](https://github.com/bharatnc)).
* ... [#14523](https://github.com/ClickHouse/ClickHouse/pull/14523) ([BohuTANG](https://github.com/BohuTANG)).
* Выполнен бэкпорт в [#14873](https://github.com/ClickHouse/ClickHouse/issues/14873): разрешено использовать multi-volume storage configuration в движке Distributed. [#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
