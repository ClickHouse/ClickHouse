<div id="clickhouse-release-v21473-stable-fixme-as-compared-to-v214655-stable">

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#23971](https://github.com/ClickHouse/ClickHouse/issues/23971): Исправлена ошибка при восстановлении устаревшей реплики `ReplicatedMergeTree`. Некоторые обновления метаданных могли игнорироваться устаревшей репликой, если во время простоя реплики выполнялся запрос `ALTER`. [#23742](https://github.com/ClickHouse/ClickHouse/pull/23742) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#23819](https://github.com/ClickHouse/ClickHouse/issues/23819): Исправлен сбой, возникавший при одновременном применении `PREWHERE` и фильтра ROW POLICY при пустом результате. [#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#23816](https://github.com/ClickHouse/ClickHouse/issues/23816): Исправлено, что `CLEAR COLUMN` не работает, если на столбец ссылается materialized view. Закрывает [#23764](https://github.com/ClickHouse/ClickHouse/issues/23764). [#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
* Бэкпортировано в [#23831](https://github.com/ClickHouse/ClickHouse/issues/23831): Исправлена ошибка `Can't initialize pipeline with empty pipe` для запросов с `GLOBAL IN/JOIN` и `use_hedged_requests`. Исправляет [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431). [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#23930](https://github.com/ClickHouse/ClickHouse/issues/23930): Исправлена начальная загрузка поля обновления для составного ключа в HashedDictionary. Закрывает [#23800](https://github.com/ClickHouse/ClickHouse/issues/23800). [#23824](https://github.com/ClickHouse/ClickHouse/pull/23824) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#23957](https://github.com/ClickHouse/ClickHouse/issues/23957): Исправлен учёт метрик keys для словаря CACHE() с дубликатами в источнике (это приводило к переполнению `DictCacheKeysRequestedMiss`). [#23929](https://github.com/ClickHouse/ClickHouse/pull/23929) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#24003](https://github.com/ClickHouse/ClickHouse/issues/24003): Исправлен SIGSEGV для внешнего GROUP BY и строки переполнения (то есть для запросов вида `SELECT FROM GROUP BY WITH TOTALS SETTINGS max_bytes_before_external_group_by>0, max_rows_to_group_by>0, group_by_overflow_mode='any', totals_mode='before_having'`). [#23962](https://github.com/ClickHouse/ClickHouse/pull/23962) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#24188](https://github.com/ClickHouse/ClickHouse/issues/24188): Некоторые запросы `ALTER PARTITION` могли вызывать ошибки `Part A intersects previous part B` и `Unexpected merged part C intersecting drop range D` в очереди репликации. Это исправлено. Исправляет [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296). [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#24031](https://github.com/ClickHouse/ClickHouse/issues/24031): Исправлен сбой в MergeJoin, закрывает [#24010](https://github.com/ClickHouse/ClickHouse/issues/24010). [#24013](https://github.com/ClickHouse/ClickHouse/pull/24013) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#24141](https://github.com/ClickHouse/ClickHouse/issues/24141): Ошибка: `explain pipeline` с `select xxx final` показывает неверный pipeline: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* Бэкпортировано в [#24171](https://github.com/ClickHouse/ClickHouse/issues/24171): исправлена редкая ошибка, которая могла приводить к появлению частично инициализированной таблицы, способной обрабатывать запросы на запись (insert/alter и т. д.). Теперь такие таблицы будут переводиться в режим только для чтения. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#24215](https://github.com/ClickHouse/ClickHouse/issues/24215): исправлено состояние гонки, которое могло возникать в RBAC при высокой нагрузке. Этот PR исправляет [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090) и [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134). [#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#24243](https://github.com/ClickHouse/ClickHouse/issues/24243): исправлено аварийное завершение сервера из-за недоступности HDFS во время выполнения запроса. Закрывает [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117). [#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
