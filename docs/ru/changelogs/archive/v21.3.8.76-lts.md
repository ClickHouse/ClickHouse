<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#23396](https://github.com/ClickHouse/ClickHouse/issues/23396): если кортеж из NULL, например `(NULL, NULL)`, находится в левой части оператора `IN`, а в правой части — кортежи из значений, отличных от NULL, например `SELECT (NULL, NULL) IN ((0, 0), (3, 1))`, теперь возвращается 0 вместо генерации исключения о несовместимых типах. Такое выражение также может появляться в результате оптимизации запроса вида `SELECT (NULL, NULL) = (8, 0) OR (NULL, NULL) = (3, 2) OR (NULL, NULL) = (0, 0) OR (NULL, NULL) = (3, 1)`. Закрывает [#22017](https://github.com/ClickHouse/ClickHouse/issues/22017). [#22063](https://github.com/ClickHouse/ClickHouse/pull/22063) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#23272](https://github.com/ClickHouse/ClickHouse/issues/23272): отключены настройки `use_hedged_requests` и `async_socket_for_remote`, поскольку есть основания полагать, что они могут вызывать проблемы. [#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#23232](https://github.com/ClickHouse/ClickHouse/issues/23232): server мог не запускаться, если настройка `data_type_default_nullable` была включена в профиле default; это исправлено. Исправляет [#22573](https://github.com/ClickHouse/ClickHouse/issues/22573). [#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#23406](https://github.com/ClickHouse/ClickHouse/issues/23406): QueryAliasVisitor теперь отдает предпочтение alias для ASTWithAlias, если подзапрос был оптимизирован до константы. Исправляет [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924). Исправляет [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401). [#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#23381](https://github.com/ClickHouse/ClickHouse/issues/23381): исправлена ошибка `Not found column` при выборке из `MaterializeMySQL` с условием по ключевому столбцу. Исправляет [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432). [#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#23284](https://github.com/ClickHouse/ClickHouse/issues/23284): исправлено создание simple key dictionary из DDL, если primary key не является первым атрибутом. Исправляет [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236). [#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#23450](https://github.com/ClickHouse/ClickHouse/issues/23450): исправлено очень редкое состояние гонки (в распределенном режиме) между созданием и удалением таблиц ReplicatedMergeTree. Оно могло вызывать исключения вида `node doesn't exist` при попытке создать реплицируемую таблицу. Исправляет [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419). [#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#23500](https://github.com/ClickHouse/ClickHouse/issues/23500): исправлено возможное аварийное завершение, если от remote query был получен `unknown packet` (при включенном `async_socket_for_remote`). Возможно, исправляет [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167). [#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#23468](https://github.com/ClickHouse/ClickHouse/issues/23468): `ORDER BY` с `COLLATE` работал некорректно, если столбец входит в primary key (или является его монотонной функцией) и настройка `optimize_read_in_order` не отключена. Закрывает [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379). Обходной путь для более старых версий: отключить настройку `optimize_read_in_order`. [#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#23544](https://github.com/ClickHouse/ClickHouse/issues/23544): удалена поддержка `argMin` и `argMax` для одного аргумента `Tuple`. Код не был безопасен с точки зрения работы с памятью. Эта возможность была добавлена по ошибке и вводит пользователей в заблуждение. Позже эти функции могут вернуть под другими именами. Это исправляет [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) и отменяет [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359). [#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#23479](https://github.com/ClickHouse/ClickHouse/issues/23479): движок Kafka теперь может поддерживать сообщения в форматах `arrow` и `arrowstream`. [#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* Бэкпортировано в [#23499](https://github.com/ClickHouse/ClickHouse/issues/23499): исправление ошибки в агрегатной функции `deltaSum` в случае сброса Counter ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* Бэкпортировано в [#23493](https://github.com/ClickHouse/ClickHouse/issues/23493): Исправлена ошибка, не позволявшая выполнять приведение типа из пустого литерала массива к массиву с размерностью больше 1.
