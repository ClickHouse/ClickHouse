<div id="clickhouse-release-v21171-stable-fixme-as-compared-to-v211613-stable">
  ### Релиз ClickHouse v21.1.7.1-stable FIXME по сравнению с v21.1.6.13-stable

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпорт в [#21261](https://github.com/ClickHouse/ClickHouse/issues/21261): исправлено поведение, при котором значения default&#95;replica&#95;path и default&#95;replica&#95;name были бесполезны для движка Replicated(*)MergeTree, если для движка требовалось указать другие параметры. [#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy)).
* Бэкпорт в [#21155](https://github.com/ClickHouse/ClickHouse/issues/21155): исправлена ошибка, связанная с приведением tuple к map. Закрывает [#21029](https://github.com/ClickHouse/ClickHouse/issues/21029). [#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting)).
* Бэкпорт в [#21233](https://github.com/ClickHouse/ClickHouse/issues/21233): теперь мутации разрешены только для движков таблиц, которые их поддерживают (семейство MergeTree, Memory, MaterializedView). Для остальных движков будет выводиться более понятная ошибка. Исправляет [#21168](https://github.com/ClickHouse/ClickHouse/issues/21168). [#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#21428](https://github.com/ClickHouse/ClickHouse/issues/21428): исправлено падение в `EXPLAIN` для запроса с `UNION`. Исправляет [#20876](https://github.com/ClickHouse/ClickHouse/issues/20876), [#21170](https://github.com/ClickHouse/ClickHouse/issues/21170). [#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl)).
* Бэкпорт в [#21408](https://github.com/ClickHouse/ClickHouse/issues/21408): устранены лишние повторные подключения к ZooKeeper и возможность существования двух активных сеансов у одного сервера ClickHouse. Обе проблемы появились в [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678). [#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#21549](https://github.com/ClickHouse/ClickHouse/issues/21549): теперь запросы `ALTER MODIFY COLUMN` будут корректно применять изменения к ключу партиционирования, индексам пропуска, TTL и т. д. Исправляет [#13675](https://github.com/ClickHouse/ClickHouse/issues/13675). [#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#21377](https://github.com/ClickHouse/ClickHouse/issues/21377): исправлена ошибка `Bad cast from type ... to DB::ColumnLowCardinality` при вставке в таблицу со столбцом `LowCardinality` из формата `Values`. Исправляет [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140). [#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
