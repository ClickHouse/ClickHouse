<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#62188](https://github.com/ClickHouse/ClickHouse/issues/62188): StorageJoin со strictness `ANY` работает согласованно после перезагрузки. При вставке нескольких строк с одинаковым ключом приоритет будет у первой из них (раньше при загрузке таблицы она выбиралась случайным образом). закрывает [#51027](https://github.com/ClickHouse/ClickHouse/issues/51027). [#61972](https://github.com/ClickHouse/ClickHouse/pull/61972) ([vdimir](https://github.com/vdimir)).
* Бэкпортировано в [#62443](https://github.com/ClickHouse/ClickHouse/issues/62443): Клиент должен отправлять серверу заголовок &#39;Keep-Alive: timeout=X&#39;. Если клиент получает от сервера ответ с этим заголовком, он должен использовать значение от сервера. Также клиенту лучше не использовать соединение с почти истекшим сроком жизни, чтобы избежать гонки при закрытии соединения. [#62249](https://github.com/ClickHouse/ClickHouse/pull/62249) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#62666](https://github.com/ClickHouse/ClickHouse/issues/62666): хранилище S3 и резервные копии также должны использовать такие же настройки Keep-Alive по умолчанию, как и S3-диск. [#62648](https://github.com/ClickHouse/ClickHouse/pull/62648) ([Sema Checherinda](https://github.com/CheSema)).
