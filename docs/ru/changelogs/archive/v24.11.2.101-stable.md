<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#72704](https://github.com/ClickHouse/ClickHouse/issues/72704): При выполнении запроса с параллельными репликами и включенным локальным планом анализ индекса пропуска данных на воркерах пропускается. Координатор будет выбирать диапазоны чтения для воркеров на основе анализа индекса на своей стороне (на инициаторе запроса). [#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter)).
* Бэкпортировано в [#73035](https://github.com/ClickHouse/ClickHouse/issues/73035): Возвращена оптимизация чтения подстолбцов одного столбца в компактных частях из [https://github.com/ClickHouse/ClickHouse/pull/57631](https://github.com/ClickHouse/ClickHouse/pull/57631). Она была удалена случайно. [#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#72677](https://github.com/ClickHouse/ClickHouse/issues/72677): Улучшена оценка использования памяти кэшированными marks, чтобы снизить общее использование памяти кэша. [#72630](https://github.com/ClickHouse/ClickHouse/pull/72630) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#73065](https://github.com/ClickHouse/ClickHouse/issues/73065): Добавлена поддержка разбора ошибки GCS S3 `AuthenticationRequired`. [#72753](https://github.com/ClickHouse/ClickHouse/pull/72753) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#73057](https://github.com/ClickHouse/ClickHouse/issues/73057): Добавлены настройки S3-запросов `http_max_fields`, `http_max_field_name_size`, `http_max_field_value_size`; они используются при разборе ответов S3 API во время создания резервной копии или восстановления. [#72778](https://github.com/ClickHouse/ClickHouse/pull/72778) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#73454](https://github.com/ClickHouse/ClickHouse/issues/73454): В потоке очистки ObjectStorageQueueMetadata используются мультизапросы Keeper. [#73357](https://github.com/ClickHouse/ClickHouse/pull/73357) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#73435](https://github.com/ClickHouse/ClickHouse/issues/73435): Когда ClickHouse работает в cgroup, мы всё равно собираем общесистемные асинхронные метрики, связанные с системной нагрузкой, планированием процессов, памятью и т. д. Они могут быть полезным сигналом, если ClickHouse — единственный процесс на хосте с высоким потреблением ресурсов. [#73369](https://github.com/ClickHouse/ClickHouse/pull/73369) ([Nikita Taranov](https://github.com/nickitat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#73009](https://github.com/ClickHouse/ClickHouse/issues/73009): исправлены процессы-зомби после сбоя library bridge. [#71301](https://github.com/ClickHouse/ClickHouse/pull/71301) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Бэкпортировано в [#73487](https://github.com/ClickHouse/ClickHouse/issues/73487): операции `RESTORE` для сущностей доступа требовали больше разрешений, чем нужно, из-за необработанных частичных отзывов прав. Этот PR исправляет проблему. Закрывает [#71853](https://github.com/ClickHouse/ClickHouse/issues/71853). [#71958](https://github.com/ClickHouse/ClickHouse/pull/71958) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#73376](https://github.com/ClickHouse/ClickHouse/issues/73376): в create query для движков File/S3/URL/HDFS/Azure добавлено автоматически определённое имя формата. Ранее имя формата определялось при каждом перезапуске сервера, и если указанные data files были удалены, это приводило к ошибкам при запуске сервера. [#72108](https://github.com/ClickHouse/ClickHouse/pull/72108) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#72245](https://github.com/ClickHouse/ClickHouse/issues/72245): исправлена ошибка, из-за которой `min_age_to_force_merge_on_partition_only` зацикливался, пытаясь снова выполнить merge одной и той же партиции, уже слитой в одну часть, и при этом не выполнял merge партиций, состоящих из нескольких частей. [#72209](https://github.com/ClickHouse/ClickHouse/pull/72209) ([Christoph Wurm](https://github.com/cwurm)).
* Бэкпортировано в [#72529](https://github.com/ClickHouse/ClickHouse/issues/72529): исправлено несоответствие типов в нескольких случаях после применения `optimize_functions_to_subcolumns`. [#72394](https://github.com/ClickHouse/ClickHouse/pull/72394) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#72508](https://github.com/ClickHouse/ClickHouse/issues/72508): исправлен сбой при разборе запросов `BACKUP DATABASE db EXCEPT TABLES db.table`. [#72429](https://github.com/ClickHouse/ClickHouse/pull/72429) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#72955](https://github.com/ClickHouse/ClickHouse/issues/72955): запрещено создание пустого Variant. [#72454](https://github.com/ClickHouse/ClickHouse/pull/72454) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#72932](https://github.com/ClickHouse/ClickHouse/issues/72932): исправлена генерация запросов для follower-сервера в случае distributed query с ARRAY JOIN. Исправляет [#69276](https://github.com/ClickHouse/ClickHouse/issues/69276). [#72608](https://github.com/ClickHouse/ClickHouse/pull/72608) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#72852](https://github.com/ClickHouse/ClickHouse/issues/72852): исправлена несогласованность metadata при добавлении новой реплики в базу данных Replicated, содержащую таблицу, созданную с `flatten_nested=0`.
