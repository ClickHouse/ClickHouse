<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователям, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#38241](https://github.com/ClickHouse/ClickHouse/issues/38241): Исправлен возможный сбой в `Distributed` async insert при удалении реплики из конфигурации. [#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#39098](https://github.com/ClickHouse/ClickHouse/issues/39098): Любые выделения памяти внутри OvercommitTracker могут приводить к взаимной блокировке. Логирование было не слишком информативным, поэтому его решили просто удалить. Исправляет [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794). [#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#39078](https://github.com/ClickHouse/ClickHouse/issues/39078): Исправлена ошибка в файловом кэше, которая могла возникать в редком пограничном случае при достижении лимита ёмкости кэша. Закрывает [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066). [#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#39152](https://github.com/ClickHouse/ClickHouse/issues/39152): Исправлена ошибка `Block structure mismatch`, которая могла возникать при INSERT в таблицу с attached MATERIALIZED VIEW и включенной настройкой `extremes = 1`. Закрывает [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) и [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729). [#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#39274](https://github.com/ClickHouse/ClickHouse/issues/39274): Исправлена ошибка `Not found column Type in block` в запросах SELECT с `PREWHERE` и оптимизациями чтения по порядку. [#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#39369](https://github.com/ClickHouse/ClickHouse/issues/39369): Очередь RabbitMQ теперь объявляется без аргументов по умолчанию `x-max-length` и `x-overflow`. [#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* Бэкпортировано в [#39350](https://github.com/ClickHouse/ClickHouse/issues/39350): Исправлен некорректный запрос на получение таблиц PostgreSQL для движка базы данных PostgreSQL. Закрывает [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502). [#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
