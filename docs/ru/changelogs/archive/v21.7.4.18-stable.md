<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#26297](https://github.com/ClickHouse/ClickHouse/issues/26297): Исправлен некорректный `sequence_id` в пакетах протокола MySQL, которые ClickHouse отправляет при Исключении во время выполнения запроса. Это могло приводить к тому, что MySQL-клиент сбрасывал соединение с сервером ClickHouse. Исправляет [#21184](https://github.com/ClickHouse/ClickHouse/issues/21184). [#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#26356](https://github.com/ClickHouse/ClickHouse/issues/26356): Исправлена logical error в JOIN с totals, закрывает [#26017](https://github.com/ClickHouse/ClickHouse/issues/26017). [#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#26359](https://github.com/ClickHouse/ClickHouse/issues/26359): Исправлена редкая ошибка при восстановлении потерянной реплики, которая могла привести к расхождению реплик. [#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#26419](https://github.com/ClickHouse/ClickHouse/issues/26419): Исправлен возможный crash при входе под удалённым пользователем. Этот PR исправляет [#26073](https://github.com/ClickHouse/ClickHouse/issues/26073). [#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#26413](https://github.com/ClickHouse/ClickHouse/issues/26413): Исправлен бесконечный поток несоединённых block в `partial_merge_join`, закрывает [#26325](https://github.com/ClickHouse/ClickHouse/issues/26325). [#26374](https://github.com/ClickHouse/ClickHouse/pull/26374) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#26447](https://github.com/ClickHouse/ClickHouse/issues/26447): Исправлен один из сбоев msan, обнаруженных фаззингом. Исправляет [#22517](https://github.com/ClickHouse/ClickHouse/issues/22517). [#26428](https://github.com/ClickHouse/ClickHouse/pull/26428) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
