<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение в официальном стабильном релизе, заметное пользователям)
</div>

* Бэкпортировано в [#40542](https://github.com/ClickHouse/ClickHouse/issues/40542): Устранена потенциальная взаимная блокировка в WriteBufferFromS3 при сбое планирования задач. [#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#40450](https://github.com/ClickHouse/ClickHouse/issues/40450): Исправлена редкая ошибка с TTL столбца для семейства движков MergeTree: при повторном вертикальном слиянии могла возникать ошибка `Cannot unlink file ColumnName.bin ... No such file or directory.`. [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#40532](https://github.com/ClickHouse/ClickHouse/issues/40532): Резолвер прокси останавливался после первого успешного запроса к конечной точке. [#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#40624](https://github.com/ClickHouse/ClickHouse/issues/40624): Исправлена потенциальная потеря данных из-за ошибки в AWS SDK ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)). Ошибка могла возникать только при использовании ClickHouse с S3. [#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
