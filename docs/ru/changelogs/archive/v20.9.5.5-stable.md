  ### Релиз ClickHouse v20.9.5.5-stable FIXME по сравнению с v20.9.4.76-stable

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпорт в [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493): исправлена ошибка с базой данных MySQL. Когда сервер MySQL, используемый как движок базы данных, недоступен, некоторые запросы вызывают Исключение, потому что пытаются получить таблицы с недоступного сервера, хотя это не требуется. Например, запрос `SELECT ... FROM system.parts` должен работать только с таблицами семейства MergeTree и вообще не обращаться к базе данных MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпорт в [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817): исправлено неконсистентное поведение, при котором часть возвращаемых данных могла отбрасываться, потому что набор для их фильтрации не был создан. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпорт в [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508): исправлена обработка очень больших элементов в очереди репликации. Очень большие элементы могут появляться в ALTER-запросах, если структура таблицы чрезвычайно велика (около 1 МБ). Это исправляет [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпорт в [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474): исправлен DROP TABLE для Distributed (состояние гонки с INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпорт в [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571): исправлен быстрый рост метаданных при использовании MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine и включенном `slave_parallel_worker` на MySQL Slave за счет корректного сжатия GTID-наборов. Это исправляет [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Бэкпорт в [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554): теперь при разборе AVRO из входных данных LowCardinality удаляется из типа. Исправляет [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Бэкпорт в [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748): исправлено [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпорт в [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894): исправлены редкие аварийные завершения без сообщений, возникающие при включенном профилировщике запросов, если ClickHouse установлен на ОС с версией glibc, в которой (предположительно) есть некорректные асинхронные unwind-таблицы для некоторых функций. Это исправляет [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Это исправляет [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
