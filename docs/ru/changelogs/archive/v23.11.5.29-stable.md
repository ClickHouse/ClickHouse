<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#58815](https://github.com/ClickHouse/ClickHouse/issues/58815): Добавлена команда `SYSTEM JEMALLOC PURGE` для освобождения неиспользуемых страниц jemalloc, а также `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` для управления профилем jemalloc, если включен профилировщик. В Keeper добавлена связанная с jemalloc 4LW-команда: `jmst` для вывода статистики jemalloc, а также `jmfp`, `jmep`, `jmdp` для управления профилем jemalloc, если включен профилировщик. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#59234](https://github.com/ClickHouse/ClickHouse/issues/59234): Добавлена возможность игнорировать изменение схемы в движке таблицы Iceberg и читать все данные, используя схему, указанную пользователем при создании таблицы, либо последнюю схему, разобранную из метаданных при создании таблицы. Это делается с помощью настройки `iceberg_engine_ignore_schema_evolution`, которая по умолчанию отключена. Обратите внимание, что включение этой настройки может привести к некорректным результатам, поскольку в случае изменения схемы все файлы данных будут читаться с использованием одной и той же схемы. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
