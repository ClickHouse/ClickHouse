<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#75842](https://github.com/ClickHouse/ClickHouse/issues/75842): добавлены проверка и логирование при расшифровке и распаковке. [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#75804](https://github.com/ClickHouse/ClickHouse/issues/75804): добавлен параметр конфигурации `memory_worker_correct_memory_tracker`, позволяющий периодически корректировать внутренний трекер памяти на основе информации из разных источников, считываемой в фоновом потоке. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#75811](https://github.com/ClickHouse/ClickHouse/issues/75811): Корректно передаются настройки Native format при взаимодействии между клиентом и сервером. [#73924](https://github.com/ClickHouse/ClickHouse/pull/73924) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#74090](https://github.com/ClickHouse/ClickHouse/issues/74090): Исправлены неявные привилегии (раньше работали как подстановочный знак). [#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#75556](https://github.com/ClickHouse/ClickHouse/issues/75556): Исправлен сбой с запросом `INSERT INTO SELECT` через PostgreSQL interface на macOS (issue [#72938](https://github.com/ClickHouse/ClickHouse/issues/72938)). [#74231](https://github.com/ClickHouse/ClickHouse/pull/74231) ([Artem Yurov](https://github.com/ArtemYurov)).
* Бэкпортировано в [#75630](https://github.com/ClickHouse/ClickHouse/issues/75630): Исправлен сбой из-за uncaught exception в репликации PSQL. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#76103](https://github.com/ClickHouse/ClickHouse/issues/76103): Исправлена обработка nullsafe JOIN для типа данных LowCardinality Nullable. Ранее `JOIN ON` со сравнением nullsafe, таким как `IS NOT DISTINCT FROM`, `<=>` , `a IS NULL AND b IS NULL OR a == b`, работал некорректно со столбцами LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#75568](https://github.com/ClickHouse/ClickHouse/issues/75568): Исправление Keeper: предотвращена запись в поврежденные changelog при откате журналов. [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#75652](https://github.com/ClickHouse/ClickHouse/issues/75652): Замаскированы учетные данные движка таблицы azureblobstorage. [#75319](https://github.com/ClickHouse/ClickHouse/pull/75319) ([Garrett Thomas](https://github.com/garrettthomaskth)).
* Бэкпортировано в [#75744](https://github.com/ClickHouse/ClickHouse/issues/75744): Исправлен сбой в кэше Protobuf schema, который мог происходить при выводе в Protobuf format и параллельном запросе `SYSTEM DROP FORMAT SCHEMA CACHE`. [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#76096](https://github.com/ClickHouse/ClickHouse/issues/76096): Исправлена возможная ошибка `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes`, возникавшая при использовании подстолбцов JSON типа Array в JOIN по distributed таблицам. [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75854](https://github.com/ClickHouse/ClickHouse/issues/75854): Исправлено взаимодействие между allow&#95;feature&#95;tier и настройкой совместимости MergeTree. [#75635](https://github.com/ClickHouse/ClickHouse/pull/75635) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#75892](https://github.com/ClickHouse/ClickHouse/issues/75892): Исправлены редкие сбои при чтении из таблицы `MergeTree` после нескольких асинхронных запросов `RENAME` (с `alter_sync = 0`) между столбцами разных типов. [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#76157](https://github.com/ClickHouse/ClickHouse/issues/76157): перестроение projection при `ALTER MODIFY` её столбца PK. Ранее это могло приводить к ошибкам `CANNOT_READ_ALL_DATA` при выполнении `SELECT` после `ALTER MODIFY` столбца, используемого в PK projection. [#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75823](https://github.com/ClickHouse/ClickHouse/issues/75823): исправлено разыменование нулевого указателя в `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#76216](https://github.com/ClickHouse/ClickHouse/issues/76216): `clickhouse-library-bridge` позволяет открывать произвольные библиотеки из файловой системы, поэтому его безопасно запускать только в изолированной среде. Чтобы предотвратить уязвимость при запуске рядом с `clickhouse-server`, мы ограничим пути к библиотекам расположением, указанным в конфигурации. Эта уязвимость была обнаружена **Arseniy Dugin** в рамках [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986). [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
