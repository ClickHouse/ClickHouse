  ### Релиз ClickHouse v23.2.5.46-stable (b50faecbb12) FIXME по сравнению с v23.2.4.12-stable (8fe866cb035)

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#48164](https://github.com/ClickHouse/ClickHouse/issues/48164): исправлено исключение `UNKNOWN_TABLE` при ATTACH к materialized view, у которой есть недоступные зависимые таблицы. Это может быть полезно при попытке восстановить состояние из резервной копии. [#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#48216](https://github.com/ClickHouse/ClickHouse/issues/48216): sccache используется вместо ccache, а S3 — в качестве бэкенда кэша. [#46240](https://github.com/ClickHouse/ClickHouse/pull/46240) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#48256](https://github.com/ClickHouse/ClickHouse/issues/48256): Раньше образ `clickhouse/clickhouse-keeper` публиковался только с тегами `-alpine`, например `latest-alpine`. По предложению из [https://github.com/ClickHouse/examples/pull/2](https://github.com/ClickHouse/examples/pull/2) теперь он также будет публиковаться и без суффикса. [#48236](https://github.com/ClickHouse/ClickHouse/pull/48236) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
