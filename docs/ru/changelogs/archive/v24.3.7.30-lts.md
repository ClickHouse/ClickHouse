  ### Релиз ClickHouse v24.3.7.30-lts (c8a28cf4331) FIXME по сравнению с v24.3.6.48-lts (b2d33c3c45d)

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#68103](https://github.com/ClickHouse/ClickHouse/issues/68103): при разборе значений пользовательских настроек теперь различаются булевы значения и целые числа: `SET custom_a = true; SET custom_b = 1;`. [#62206](https://github.com/ClickHouse/ClickHouse/pull/62206) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#67931](https://github.com/ClickHouse/ClickHouse/issues/67931): Исправлена ошибка `Not-ready Set`, возникавшая после оптимизации `PREWHERE` для StorageMerge. [#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#68062](https://github.com/ClickHouse/ClickHouse/issues/68062): Исправлены булевы литералы в запросе, отправляемом во внешнюю базу данных (для движков вроде `PostgreSQL`). [#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* Бэкпортировано в [#67812](https://github.com/ClickHouse/ClickHouse/issues/67812): Относится только к экспериментальному типу данных Variant. Исправлен сбой при использовании типа Variant + AggregateFunction. [#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#67848](https://github.com/ClickHouse/ClickHouse/issues/67848): Исправляет [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026). Исключен обход неразрешенных аргументов табличной функции в `ReplaceTableNodeToDummyVisitor`. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#68271](https://github.com/ClickHouse/ClickHouse/issues/68271): Исправлена вставка в движки потокового типа (Kafka, RabbitMQ, NATS) через HTTP-интерфейс. [#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#67806](https://github.com/ClickHouse/ClickHouse/issues/67806): Исправлена повторная загрузка SQL UDF с UNION. Ранее перезапуск сервера мог сделать UDF недействительной. [#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#67834](https://github.com/ClickHouse/ClickHouse/issues/67834): Исправлено возможное переполнение стека в функции `JSONMergePatch`. Функция была переименована из `jsonMergePatch` в `JSONMergePatch`, потому что прежнее имя было неверным. Прежнее имя по-прежнему сохранено для совместимости. Улучшена диагностика ошибок в функции. Это закрывает [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304). [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#68206](https://github.com/ClickHouse/ClickHouse/issues/68206): Исправлен неверный результат `count()`, когда в предикате присутствует недетерминированная функция. [#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#68089](https://github.com/ClickHouse/ClickHouse/issues/68089): Исправлен расчет максимального мягкого лимита потоков в контейнеризированных окружениях, где ограничено число доступных CPU. [#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#68120](https://github.com/ClickHouse/ClickHouse/issues/68120): Исправлен пропуск незатронутых частей в мутациях с новым анализатором. Ранее при включенном анализаторе данные в части могли быть переписаны мутацией, даже если мутация не затрагивала эту часть согласно предикату. [#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
