  ### Релиз ClickHouse v20.8.4.11-lts FIXME по сравнению с v20.8.3.18-stable

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#15569](https://github.com/ClickHouse/ClickHouse/issues/15569): Теперь с помощью запроса `ALTER` можно изменять тип столбца версии в `VersionedCollapsingMergeTree`. [#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### Исправление ошибок
</div>

* Бэкпортировано в [#15017](https://github.com/ClickHouse/ClickHouse/issues/15017): Исправлен неверный порядок сортировки столбца `Nullable`. Исправляет [#14344](https://github.com/ClickHouse/ClickHouse/issues/14344). [#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#14823](https://github.com/ClickHouse/ClickHouse/issues/14823): Исправлено неверное определение монотонности при сужающем приведении `Int -> Int` для знаковых типов. Это могло приводить к некорректному результату запроса. Ошибка обнаружена в [#14513](https://github.com/ClickHouse/ClickHouse/issues/14513). [#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#15148](https://github.com/ClickHouse/ClickHouse/issues/15148): Исправлена проблема, при которой сервер мог зависать при запуске во время обращения к ZooKeeper, если конфигурационные файлы требовалось получить из ZK (с использованием параметра `from_zk`). Исправляет [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814). [#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Бэкпортировано в [#15251](https://github.com/ClickHouse/ClickHouse/issues/15251): Исправлена ошибка сегментирования в CacheDictionary [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837). [#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#14955](https://github.com/ClickHouse/ClickHouse/issues/14955): Исправлена ошибка `.metadata.tmp File exists` при использовании движка базы данных `MaterializeMySQL`. [#14898](https://github.com/ClickHouse/ClickHouse/pull/14898) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпортировано в [#14987](https://github.com/ClickHouse/ClickHouse/issues/14987): Добавлена публикация частот CPU для каждого логического ядра в `system.asynchronous_metrics`. Исправляет [#14923](https://github.com/ClickHouse/ClickHouse/issues/14923). [#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Бэкпортировано в [#14969](https://github.com/ClickHouse/ClickHouse/issues/14969): Исправлена работа проталкивания предикатов в случае, когда подзапрос содержит функцию finalizeAggregation. Исправляет [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847). [#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#15053](https://github.com/ClickHouse/ClickHouse/issues/15053): Теперь настройки `number_of_free_entries_in_pool_to_execute_mutation` и `number_of_free_entries_in_pool_to_lower_max_size_of_merge` могут быть равны `background_pool_size`. [#14975](https://github.com/ClickHouse/ClickHouse/pull/14975) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#15077](https://github.com/ClickHouse/ClickHouse/issues/15077): Исправлено аварийное завершение при RIGHT или FULL JOIN с join_algorithm='auto' в случае превышения лимита памяти, когда требовалась замена HashJoin на MergeJoin. [#15002](https://github.com/ClickHouse/ClickHouse/pull/15002) ([Artem Zuikov](https://github.com/4ertus2)).
* Бэкпортировано в [#15102](https://github.com/ClickHouse/ClickHouse/issues/15102): Исправлена ошибка `Cannot rename ... errno: 22, strerror: Invalid argument` при выполнении DDL-запросов в базе данных Atomic при запуске clickhouse-server в Docker на Mac OS. [#15024](https://github.com/ClickHouse/ClickHouse/pull/15024) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#15056](https://github.com/ClickHouse/ClickHouse/issues/15056): При вызове функции `bar` со специально подобранными аргументами было возможно переполнение буфера. Закрывает [#13926](https://github.com/ClickHouse/ClickHouse/issues/13926). [#15028](https://github.com/ClickHouse/ClickHouse/pull/15028) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#15049](https://github.com/ClickHouse/ClickHouse/issues/15049): Для сравнения String и FixedString уже используется дополненное сравнение (https://github.com/ClickHouse/ClickHouse/blob/master/src/Functions/FunctionsComparison.h#L333). Данный PR применяет ту же логику к сравнению полей, что исправляет использование FixedString в качестве первичных ключей. Исправляет [#14908](https://github.com/ClickHouse/ClickHouse/issues/14908). [#15033](https://github.com/ClickHouse/ClickHouse/pull/15033) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#15142](https://github.com/ClickHouse/ClickHouse/issues/15142): Исправлена ошибка `Data compressed with different methods` при `join_algorithm='auto'`. Тип LowCardinality теперь сохраняется для ключа JOIN левой таблицы при `join_algorithm='partial_merge'`. [#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2)).
* Бэкпортировано в [#15208](https://github.com/ClickHouse/ClickHouse/issues/15208): Скорректирован размер поля decimals в пакете определения столбца MySQL. [#15152](https://github.com/ClickHouse/ClickHouse/pull/15152) ([maqroll](https://github.com/maqroll)).
* Бэкпортировано в [#15222](https://github.com/ClickHouse/ClickHouse/issues/15222): Исправлена ошибка в движке таблицы `Buffer`, из-за которой после запроса `ALTER` не удавалось вставить данные новой структуры в `Buffer`. Исправляет [#15117](https://github.com/ClickHouse/ClickHouse/issues/15117). [#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin)).

Исправляет [#15214](https://github.com/ClickHouse/ClickHouse/issues/15214). [#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#15489](https://github.com/ClickHouse/ClickHouse/issues/15489): Исправлена ошибка «Unknown identifier» в GROUP BY, когда запрос содержит JOIN по таблице Merge. [#15242](https://github.com/ClickHouse/ClickHouse/pull/15242) ([Artem Zuikov](https://github.com/4ertus2)).
