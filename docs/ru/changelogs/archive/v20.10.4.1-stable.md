  ### Релиз ClickHouse v20.10.4.1-стабильный FIXME по сравнению с v20.10.3.30-стабильный

<div id="improvement">
  #### Улучшения
</div>

* Обходное решение для использования S3 с сервером nginx в качестве прокси. В настоящее время Nginx не принимает URL-адреса с пустым путём, такие как [http://domain.com?delete](http://domain.com?delete), однако стандартный aws-sdk-cpp создаёт именно такие URL-адреса. В этом коммите используется пропатченная версия aws-sdk-cpp, которая в таких случаях формирует URL-адреса с путём &quot;/&quot; — например, [http://domain.com/?delete](http://domain.com/?delete). [#16813](https://github.com/ClickHouse/ClickHouse/pull/16813) ([ianton-ru](https://github.com/ianton-ru)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#16492](https://github.com/ClickHouse/ClickHouse/issues/16492): Исправлен баг с базой данных MySQL. Когда сервер MySQL, используемый как движок базы данных, недоступен, некоторые запросы вызывают Исключение, потому что пытаются получить таблицы с отключенного сервера, хотя в этом нет необходимости. Например, запрос `SELECT ... FROM system.parts` должен работать только с таблицами семейства MergeTree и вообще не обращаться к базе данных MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#16710](https://github.com/ClickHouse/ClickHouse/issues/16710): Исправлено непоследовательное поведение, при котором часть возвращаемых данных могла отбрасываться, потому что набор для их фильтрации не был создан. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#16505](https://github.com/ClickHouse/ClickHouse/issues/16505): Исправлена обработка очень больших записей в очереди репликации. Такие записи могут появляться в ALTER-запросах, если структура таблицы чрезвычайно велика (около 1 MB). Это исправляет [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#16471](https://github.com/ClickHouse/ClickHouse/issues/16471): Исправлен DROP TABLE для Distributed (гонка с INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#16572](https://github.com/ClickHouse/ClickHouse/issues/16572): Исправлен быстрый рост метаданных при использовании MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine и включенном `slave_parallel_worker` на MySQL Slave за счет корректного сокращения множеств GTID.
