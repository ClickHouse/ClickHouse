<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#76048](https://github.com/ClickHouse/ClickHouse/issues/76048): Улучшение Keeper: для повышения производительности отключено вычисление digest при коммите в хранилище в памяти. Его можно включить с помощью config `keeper_server.digest_enabled_on_commit`. Digest по-прежнему вычисляется при предварительной обработке запросов. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#76315](https://github.com/ClickHouse/ClickHouse/issues/76315): Добавлена настройка сервера `throw_on_unknown_workload`, которая позволяет выбрать поведение для запроса, если настройке `workload` задано неизвестное значение: либо разрешить неограниченный доступ (по умолчанию), либо сгенерировать исключение `RESOURCE_ACCESS_DENIED`. Это полезно, если нужно принудительно включить планирование рабочих нагрузок для всех запросов. [#75999](https://github.com/ClickHouse/ClickHouse/pull/75999) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#76341](https://github.com/ClickHouse/ClickHouse/issues/76341): Добавлена проверка неподдерживаемых типов для некоторых хранилищ. [#74218](https://github.com/ClickHouse/ClickHouse/pull/74218) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#76362](https://github.com/ClickHouse/ClickHouse/issues/76362): Исправлены проблемы с выражениями, типы которых заданы через алиасы, в условии JOIN ON при использовании null-safe-сравнения. [#74970](https://github.com/ClickHouse/ClickHouse/pull/74970) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#75634](https://github.com/ClickHouse/ClickHouse/issues/75634): Исправлено аварийное завершение из-за необработанного исключения в PSQL-репликации. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#76246](https://github.com/ClickHouse/ClickHouse/issues/76246): Sasl может приводить к ошибке любого RPC-вызова; исправление позволяет повторно выполнить вызов, если истёк `krb5 ticker`. [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* Бэкпортировано в [#76161](https://github.com/ClickHouse/ClickHouse/issues/76161): Теперь проекция перестраивается при `ALTER MODIFY` её PK-столбца. Ранее это могло приводить к ошибкам `CANNOT_READ_ALL_DATA` при выполнении SELECT-запросов после `ALTER MODIFY` столбца, используемого в PK проекции. [#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#76261](https://github.com/ClickHouse/ClickHouse/issues/76261): В истории изменений настроек зафиксировано, что в v24.12 алгоритм JOIN parallel hash включён по умолчанию. Это означает, что ClickHouse продолжит выполнять JOIN с использованием непараллельного hash, если настроен уровень совместимости ниже v24.12. [#75870](https://github.com/ClickHouse/ClickHouse/pull/75870) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#76201](https://github.com/ClickHouse/ClickHouse/issues/76201): `clickhouse-library-bridge` позволяет открывать произвольные библиотеки из файловой системы, поэтому его безопасно запускать только в изолированной среде. Чтобы предотвратить уязвимость при запуске рядом с clickhouse-server, мы ограничим пути к библиотекам каталогом, указанным в конфигурации. Эта уязвимость была обнаружена **Arseniy Dugin** в рамках [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986). [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
