<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Изменено сравнение целых чисел и чисел с плавающей точкой в случаях, когда целое число не представимо точно в типе данных с плавающей точкой. В новой версии такое сравнение будет возвращать false, поскольку возникает ошибка округления. Пример: `9223372036854775808.0 != 9223372036854775808`, потому что число `9223372036854775808` нельзя точно представить в виде числа с плавающей точкой (и `9223372036854775808.0` округляется до `9223372036854776000.0`). В предыдущей версии сравнение показывало, что числа равны, поскольку при обратном преобразовании числа с плавающей точкой `9223372036854776000.0` в UInt64 получается `9223372036854775808`. Для справки: язык программирования Python также считает эти числа равными. Однако это поведение зависело от модели CPU (для некоторых чисел вне диапазона результаты различались на AMD64 и AArch64), поэтому мы сделали сравнение более точным. Теперь целые и числа с плавающей точкой считаются равными только в том случае, если целое число точно представимо в типе с плавающей точкой. [#22595](https://github.com/ClickHouse/ClickHouse/pull/22595) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Новая возможность
</div>

* Реализована функция `arrayFold(x1,...,xn,accum -> expression, array1,...,arrayn, init_accum)`, которая применяет выражение к каждому элементу массива (или набора параллельных массивов) и накапливает результат в аккумуляторе. [#21589](https://github.com/ClickHouse/ClickHouse/pull/21589) ([Dmitry Krylov](https://github.com/dmalkr)).
* * Добавлена поддержка Apple M1. [#21639](https://github.com/ClickHouse/ClickHouse/pull/21639) ([changvvb](https://github.com/changvvb)).
* Добавлена настройка `max_distributed_depth`, которая ограничивает глубину рекурсивных запросов к таблицам `Distributed`. Закрывает [#20229](https://github.com/ClickHouse/ClickHouse/issues/20229). [#21942](https://github.com/ClickHouse/ClickHouse/pull/21942) ([flynn](https://github.com/ucasfl)).
* Табличная функция, которая позволяет параллельно обрабатывать файлы из `s3` на множестве узлов указанного кластера. [#22012](https://github.com/ClickHouse/ClickHouse/pull/22012) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлена поддержка реплик в движке таблицы / табличной функции MySQL/PostgreSQL. Добавлено хранилище-обёртка поверх хранилищ MySQL / PostgreSQL для поддержки сегментов. Закрывает [#20969](https://github.com/ClickHouse/ClickHouse/issues/20969). [#22217](https://github.com/ClickHouse/ClickHouse/pull/22217) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Обновлены пути к конфигурациям модели catboost при перезагрузке конфигурации. [#22434](https://github.com/ClickHouse/ClickHouse/pull/22434) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлена новая настройка `non_replicated_deduplication_window` для дедупликации вставок в нереплицируемых MergeTree. [#22514](https://github.com/ClickHouse/ClickHouse/pull/22514) ([alesapin](https://github.com/alesapin)).
* В FlatDictionary добавлены параметры `initial_array_size`, `max_array_size`. [#22521](https://github.com/ClickHouse/ClickHouse/pull/22521) ([Maksim Kita](https://github.com/kitaisreal)).
* Добавлен запрос `ALTER TABLE ... FETCH PART ...`. Он похож на `FETCH PARTITION`, но загружает только одну часть. [#22706](https://github.com/ClickHouse/ClickHouse/pull/22706) ([jasong](https://github.com/songenjie)).
* Добавлена поддержка типа `Decimal256` в словарях. Закрывает [#20979](https://github.com/ClickHouse/ClickHouse/issues/20979). [#22960](https://github.com/ClickHouse/ClickHouse/pull/22960) ([Maksim Kita](https://github.com/kitaisreal)).
