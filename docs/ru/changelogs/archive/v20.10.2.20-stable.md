<div id="clickhouse-release-v2010220-stable-fixme-as-compared-to-v20914585-prestable">
  ### Релиз ClickHouse v20.10.2.20-stable FIXME по сравнению с v20.9.1.4585-prestable
</div>

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Добавлена поддержка вложенных многострочных комментариев `/* comment /* comment */ */` в SQL. Это соответствует стандарту SQL. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Изменено значение по умолчанию настройки `format_regexp_escaping_rule` (она связана с форматом `Regexp`) на `Raw` (то есть весь подшаблон читается как значение), чтобы поведение больше соответствовало ожиданиям пользователей. [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version` объявлен устаревшим. Удалена первая версия механизма переписывания JOIN. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена новая возможность: формат LineAsString, который принимает последовательность line, разделённых переводами строки, пробелами и/или запятыми. [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлена функция `formatReadableQuantity`. Она упрощает восприятие больших чисел. [#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* Добавлена возможность удалять свойства столбца и TTL таблицы. Введены запросы `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` и `ALTER TABLE REMOVE TTL`. Обе операции легковесны и выполняются на уровне метаданных. [#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* В таблицы `system.text_log`, `system.trace_log`, `system.query_log` и `system.query_thread_log` добавлено поле event&#95;time&#95;microseconds. [#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* Теперь поддерживается `WITH <identifier> AS (subquery) ... ` для объявления именованных подзапросов в контексте запроса. Это закрывает [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416). Это закрывает [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967). [#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* Теперь можно опускать аргументы для движка таблицы Replicated, если значения по умолчанию указаны в config. [#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* Добавлена табличная функция `null('structure')`. [#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* Добавлен инструмент обфускации запросов. Он позволяет делиться большим количеством запросов для более качественного тестирования. Это закрывает [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268). [#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлен формат `RawBLOB`. Он предназначен для ввода или вывода одного значения без какого-либо экранирования и разделителей. Это закрывает [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349). [#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправление [15350](https://github.com/ClickHouse/ClickHouse/issues/15350). [#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* Введена настройка `enable_global_with_statement`, которая распространяет операторы `WITH` из первого `SELECT` на другие запросы `SELECT` того же уровня, а также делает псевдонимы в операторах `WITH` видимыми для подзапросов. [#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* Добавлена функция `reinterpretAsUUID`, которая позволяет преобразовывать строку байтов в порядке big-endian в UUID. [#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Добавлены параллельные вставки с кворумом. Это закрывает [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601). [#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### Повышение производительности
</div>

* Улучшена производительность работы с 256-битными значениями за счёт использования `(u)int64_t` в качестве базового типа для длинных целых чисел. Изначально для длинных целых в качестве базового используются 8-битные типы. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* При запуске clickhouse-server с помощью `mlock` теперь блокируется в памяти только сегмент кода. В предыдущих версиях в памяти блокировались все отображённые области, включая отладочную информацию. Обычно отладочная информация выносится в отдельный файл, но если это не так, это приводило к дополнительному использованию 2..3 GiB памяти. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Раньше для группировки по одной фиксированной строке выбирался метод fixed key. Это не требуется, так как есть StringHashTable, которая выполняет аналогичную packedFix-оптимизацию для столбцов FixedString. Кроме того, по возможности следует использовать low&#95;cardinality&#95;key&#95;fixed&#95;string. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* Исправлен ошибочный выбор медленной универсальной реализации для `DateTime <op> DateTime`. Это исправляет [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153). [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* Используется один запрос S3 DeleteObjects вместо нескольких DeleteObject в цикле. Функциональность не изменилась, поэтому это покрывается существующими тестами, такими как integration/test&#95;log&#95;family&#95;s3. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* Ускорено 256-битное умножение. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* Улучшена производительность `quantileTDigest`. Это исправляет [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668). [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* Для хранения временных данных Вертикального слияния теперь явно используется временный disk. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
