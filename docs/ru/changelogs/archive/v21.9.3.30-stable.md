  # Журнал изменений за 2022 год
</div>

<div id="clickhouse-release-v219330-stable-fixme-as-compared-to-v219217-stable">
  ### Релиз ClickHouse v21.9.3.30-stable FIXME по сравнению с v21.9.2.17-stable
</div>

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#28897](https://github.com/ClickHouse/ClickHouse/issues/28897): использовать реальный tmp-файл вместо заранее заданного &quot;rows&#95;sources&quot; для вертикальных слияний. Это позволяет избежать создания лишних каталогов на tmp-дисках. [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#28815](https://github.com/ClickHouse/ClickHouse/issues/28815): Исправлен возможный сбой для `SELECT` с частично созданной агрегирующей проекцией в случае исключения. [#28700](https://github.com/ClickHouse/ClickHouse/pull/28700) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#28789](https://github.com/ClickHouse/ClickHouse/issues/28789): Исправлено безвредное состояние гонки в ReplicatedMergeTreeQueue. Пользователю оно не должно быть заметно, но может приводить к трудноуловимым ошибкам. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#28842](https://github.com/ClickHouse/ClickHouse/issues/28842): Исправлена компиляция выражений при вычислении с коротким замыканием. [#28821](https://github.com/ClickHouse/ClickHouse/pull/28821) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#28993](https://github.com/ClickHouse/ClickHouse/issues/28993): Исправлено состояние гонки между `DROP PART` и `REPLACE/MOVE PARTITION`, которое в редких случаях могло приводить к расхождению реплик. [#28864](https://github.com/ClickHouse/ClickHouse/pull/28864) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#28949](https://github.com/ClickHouse/ClickHouse/issues/28949): Исправлено чтение подстолбцов из компактных частей. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#28925](https://github.com/ClickHouse/ClickHouse/issues/28925): Исправлена ошибка с LowCardinality при вычислении функций с коротким замыканием. Закрывает [#28884](https://github.com/ClickHouse/ClickHouse/issues/28884). [#28887](https://github.com/ClickHouse/ClickHouse/pull/28887) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#28927](https://github.com/ClickHouse/ClickHouse/issues/28927): Исправлены функции высшего порядка для работы с массивами (`SIGSEGV` для `arrayCompact`/`ILLEGAL_COLUMN` для `arrayDifference`/`arrayCumSumNonNegative`) при использовании констант. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#29025](https://github.com/ClickHouse/ClickHouse/issues/29025): Исправлено количество потоков, используемых в подзапросе `GLOBAL IN` (он выполнялся в одном потоке начиная с исправления ошибки [#19414](https://github.com/ClickHouse/ClickHouse/issues/19414)). [#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="not-for-changelog-insignificant">
  #### НЕ ДЛЯ CHANGELOG / НЕЗНАЧИТЕЛЬНО

* Исправлена работа вложенных столбцов со столбцами не-массивов с тем же префиксом [2] [#28762](https://github.com/ClickHouse/ClickHouse/pull/28762) ([Anton Popov](https://github.com/CurtizJ)).
* Значение compiled&#95;expression&#95;cache&#95;size снижено до 128MB [#28816](https://github.com/ClickHouse/ClickHouse/pull/28816) ([Maksim Kita](https://github.com/kitaisreal)).
* Исправлен идентификатор dictGet в значении по умолчанию столбца. [#28863](https://github.com/ClickHouse/ClickHouse/pull/28863) ([Maksim Kita](https://github.com/kitaisreal)).
