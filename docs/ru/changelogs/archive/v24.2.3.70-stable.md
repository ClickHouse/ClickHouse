<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпорт в [#61453](https://github.com/ClickHouse/ClickHouse/issues/61453): исправлен возможный некорректный результат агрегатной функции `uniqExact`. [#61257](https://github.com/ClickHouse/ClickHouse/pull/61257) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпорт в [#61946](https://github.com/ClickHouse/ClickHouse/issues/61946): исправлен запрос ATTACH с предложением ON CLUSTER, когда база данных отсутствует на узле-инициаторе. Закрывает [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009). [#61365](https://github.com/ClickHouse/ClickHouse/pull/61365) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпорт в [#61846](https://github.com/ClickHouse/ClickHouse/issues/61846): исправлен возможный неверный результат агрегации с ключами Nullable. [#61393](https://github.com/ClickHouse/ClickHouse/pull/61393) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпорт в [#61591](https://github.com/ClickHouse/ClickHouse/issues/61591): ActionsDAG::split не может гарантировать, что &quot;выполнение сначала первой, а затем второй части на блоке эквивалентно выполнению исходного DAG&quot;. [#61458](https://github.com/ClickHouse/ClickHouse/pull/61458) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпорт в [#61648](https://github.com/ClickHouse/ClickHouse/issues/61648): async&#95;insert&#95;use&#95;adaptive&#95;busy&#95;timeout теперь корректно отключается при использовании настроек совместимости. [#61468](https://github.com/ClickHouse/ClickHouse/pull/61468) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпорт в [#61748](https://github.com/ClickHouse/ClickHouse/issues/61748): исправлены некорректные результаты при фильтрации `system.parts` или `system.parts_columns` по UUID. [#61479](https://github.com/ClickHouse/ClickHouse/pull/61479) ([Dan Wu](https://github.com/wudanzy)).
* Бэкпорт в [#61963](https://github.com/ClickHouse/ClickHouse/issues/61963): исправлены запросы `ALTER QUERY MODIFY SQL SECURITY`, чтобы они корректно переопределяли DDL таблицы. [#61480](https://github.com/ClickHouse/ClickHouse/pull/61480) ([pufit](https://github.com/pufit)).
* Бэкпорт в [#61699](https://github.com/ClickHouse/ClickHouse/issues/61699): исправлен аргумент `clickhouse-client -s`, который не работал из-за того, что был объявлен дважды. [#61530](https://github.com/ClickHouse/ClickHouse/pull/61530) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпорт в [#61578](https://github.com/ClickHouse/ClickHouse/issues/61578): исправлен поиск по строке с постоянной начальной позицией, который ранее мог приводить к повреждению памяти. [#61547](https://github.com/ClickHouse/ClickHouse/pull/61547) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпорт в [#62531](https://github.com/ClickHouse/ClickHouse/issues/62531): исправлена гонка данных между запросом `MOVE PARTITION` и слияниями, приводившая к появлению пересекающихся частей. [#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпорт в [#61860](https://github.com/ClickHouse/ClickHouse/issues/61860): исправлен сбой в `multiSearchAllPositionsCaseInsensitiveUTF8` при указании некорректной последовательности UTF-8. Пример: [#61714](https://github.com/ClickHouse/ClickHouse/issues/61714#issuecomment-2012768202). [#61749](https://github.com/ClickHouse/ClickHouse/pull/61749) ([pufit](https://github.com/pufit)).
* Бэкпорт в [#62242](https://github.com/ClickHouse/ClickHouse/issues/62242): исправлен пропуск ошибок разбора escape-последовательностей при разборе данных JSON при использовании настроек `input_format_allow_errors_num/ratio`. [#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#62218](https://github.com/ClickHouse/ClickHouse/issues/62218): Исправлен сбой в движке Merge, если у ROW POLICY отсутствует выражение. [#61971](https://github.com/ClickHouse/ClickHouse/pull/61971) ([Ilya Golshtein](https://github.com/ilejn)).
* Бэкпортировано в [#62342](https://github.com/ClickHouse/ClickHouse/issues/62342): Исправлена гонка данных для скаляров в Context. [#62305](https://github.com/ClickHouse/ClickHouse/pull/62305) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#62677](https://github.com/ClickHouse/ClickHouse/issues/62677): Исправлена ошибка сегментации при использовании движка таблицы Hive. См. [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154), [#62560](https://github.com/ClickHouse/ClickHouse/issues/62560). [#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#62639](https://github.com/ClickHouse/ClickHouse/issues/62639): Исправлена утечка памяти в groupArraySorted. Исправление [#62536](https://github.com/ClickHouse/ClickHouse/issues/62536). [#62597](https://github.com/ClickHouse/ClickHouse/pull/62597) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#63054](https://github.com/ClickHouse/ClickHouse/issues/63054): Исправлена ошибка в реализации кодека GCD, которая могла приводить к сбоям сервера. [#62853](https://github.com/ClickHouse/ClickHouse/pull/62853) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#63030](https://github.com/ClickHouse/ClickHouse/issues/63030): Исправлено некорректное поведение временных данных в cache в случае сбоя при создании базового каталога ключа кэша с ошибкой `no space left on device`. [#62925](https://github.com/ClickHouse/ClickHouse/pull/62925) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#63142](https://github.com/ClickHouse/ClickHouse/issues/63142): Исправлена некорректная оценка монотонности функции `abs`. [#63097](https://github.com/ClickHouse/ClickHouse/pull/63097) ([Duc Canh Le](https://github.com/canhld94)).
* Бэкпортировано в [#63183](https://github.com/ClickHouse/ClickHouse/issues/63183): Проверка корректности: ограничение значений вместо генерации исключения. [#63119](https://github.com/ClickHouse/ClickHouse/pull/63119) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#63176](https://github.com/ClickHouse/ClickHouse/issues/63176): Указание server&#95;name может помочь с недавно обнаруженной ошибкой SSL-рукопожатия при подключении к MongoDB Atlas: `Poco::Exception. Code: 1000, e.code() = 0, SSL Exception: error:10000438:SSL routines:OPENSSL_internal:TLSV1_ALERT_INTERNAL_ERROR`. [#63122](https://github.com/ClickHouse/ClickHouse/pull/63122) ([Alexander Gololobov](https://github.com/davenger)).
* Бэкпортировано в [#63191](https://github.com/ClickHouse/ClickHouse/issues/63191): Исправлена ошибка, из-за которой оператор `SQL SECURITY` появлялся во всех запросах `CREATE`, если включена настройка сервера `ignore_empty_sql_security_in_create_view_query=true` [https://github.com/ClickHouse/ClickHouse/pull/63134](https://github.com/ClickHouse/ClickHouse/pull/63134). [#63136](https://github.com/ClickHouse/ClickHouse/pull/63136) ([pufit](https://github.com/pufit)).
