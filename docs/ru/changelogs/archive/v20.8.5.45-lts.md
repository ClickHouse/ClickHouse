  ### Релиз ClickHouse v20.8.5.45-lts FIXME по сравнению с версией v20.8.4.11-lts
</div>

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#16146](https://github.com/ClickHouse/ClickHouse/issues/16146): Теперь запросы `ALTER ... ON CLUSTER` можно выполнять независимо от настройки `<internal_replication>` в конфигурации кластера. [#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#16310](https://github.com/ClickHouse/ClickHouse/issues/16310): Добавлена настройка allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards (разрешает использовать недетерминированные выражения, такие как rand() или dictGet(), в ключе сегментирования). [#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#15620](https://github.com/ClickHouse/ClickHouse/issues/15620): Теперь, если в ReplicatedMergeTree передаётся один параметр, генерируется ошибка вместо того, чтобы его игнорировать. [#15516](https://github.com/ClickHouse/ClickHouse/pull/15516) ([nvartolomei](https://github.com/nvartolomei)).
* Бэкпортировано в [#16203](https://github.com/ClickHouse/ClickHouse/issues/16203): Метрика `ReadonlyReplica` теперь уменьшается при отсоединении таблиц в режиме `только для чтения`. Это исправляет [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598). [#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)).
* Бэкпортировано в [#16230](https://github.com/ClickHouse/ClickHouse/issues/16230): Исправлена ошибка с глоб-шаблонами в table function S3: Region из URL не применялся к конфигурации клиента S3. [#15646](https://github.com/ClickHouse/ClickHouse/pull/15646) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Бэкпортировано в [#15871](https://github.com/ClickHouse/ClickHouse/issues/15871): Исправлена ошибка `Cannot add simple transform to empty Pipe`, возникавшая при чтении из таблицы `Buffer`, если её структура отличалась от структуры целевой таблицы. Это могло произойти, если целевая таблица возвращала пустой результат для запроса. Исправляет [#15529](https://github.com/ClickHouse/ClickHouse/issues/15529). [#15662](https://github.com/ClickHouse/ClickHouse/pull/15662) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#15772](https://github.com/ClickHouse/ClickHouse/issues/15772): Исправлено слишком низкое значение по умолчанию для настройки `max_replicated_logs_to_keep`, из-за которого реплики могли теряться слишком часто. Улучшен процесс восстановления потерянной реплики за счёт выбора для клонирования наиболее актуальной реплики. Кроме того, старые части потерянной реплики теперь не удаляются, а отсоединяются. [#15701](https://github.com/ClickHouse/ClickHouse/pull/15701) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#15738](https://github.com/ClickHouse/ClickHouse/issues/15738): Исправлена ошибка `Cannot find column`, которая могла возникать при вставке в `MATERIALIZED VIEW`, если запрос для `MV` содержал `ARRAY JOIN`. [#15717](https://github.com/ClickHouse/ClickHouse/pull/15717) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#15795](https://github.com/ClickHouse/ClickHouse/issues/15795): Исправлены некоторые случаи запросов, в которых выбирались только виртуальные столбцы. Ранее могло возникать исключение `Not found column _nothing in block`. Исправляет [#12298](https://github.com/ClickHouse/ClickHouse/issues/12298). [#15756](https://github.com/ClickHouse/ClickHouse/pull/15756) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#15900](https://github.com/ClickHouse/ClickHouse/issues/15900): Исправлено исключение `Block structure mismatch` в запросах `SELECT ... ORDER BY DESC`, выполнявшихся после запроса `ALTER MODIFY COLUMN`. Исправляет [#15800](https://github.com/ClickHouse/ClickHouse/issues/15800). [#15852](https://github.com/ClickHouse/ClickHouse/pull/15852) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#15925](https://github.com/ClickHouse/ClickHouse/issues/15925): Теперь будет генерироваться исключение, если `ALTER MODIFY COLUMN ... DEFAULT ...` содержит значение по умолчанию, несовместимое с типом столбца. Исправляет [#15854](https://github.com/ClickHouse/ClickHouse/issues/15854). [#15858](https://github.com/ClickHouse/ClickHouse/pull/15858) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#15920](https://github.com/ClickHouse/ClickHouse/issues/15920): Исправлены возможные взаимные блокировки в RBAC. [#15875](https://github.com/ClickHouse/ClickHouse/pull/15875) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#16168](https://github.com/ClickHouse/ClickHouse/issues/16168): Исправлен некорректный пустой результат для запроса к `Distributed`-таблице, если запрос содержит `WHERE`, `PREWHERE` и `GLOBAL IN`. Исправляет [#15792](https://github.com/ClickHouse/ClickHouse/issues/15792). [#15933](https://github.com/ClickHouse/ClickHouse/pull/15933) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#16355](https://github.com/ClickHouse/ClickHouse/issues/16355): Исправлен сбой `DROP TABLE IF EXISTS` с ошибкой `Table ... doesn't exist`, когда таблица одновременно переименовывается (для движка базы данных Atomic). Исправлен редкий deadlock при одновременном выполнении некоторых DDL-запросов с несколькими таблицами (например, `DROP DATABASE` и `RENAME TABLE`). Исправлен сбой `DROP/DETACH DATABASE` с ошибкой `Table ... doesn't exist` при одновременном выполнении `DROP/DETACH TABLE`. [#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#15968](https://github.com/ClickHouse/ClickHouse/issues/15968): Исправлен crash при сбое создания базы данных. [#15954](https://github.com/ClickHouse/ClickHouse/pull/15954) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпортировано в [#16025](https://github.com/ClickHouse/ClickHouse/issues/16025): Исправлена неоднозначность при разборе settings profiles: `CREATE USER ... SETTINGS profile readonly` теперь рассматривается как использование профиля с именем `readonly`, а не setting с именем `profile` с ограничением readonly. Это исправляет [#15628](https://github.com/ClickHouse/ClickHouse/issues/15628). [#15982](https://github.com/ClickHouse/ClickHouse/pull/15982) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#16219](https://github.com/ClickHouse/ClickHouse/issues/16219): Исправлены редкие segfault при вставке в MaterializedView или выборке из него при одновременном удалении целевой таблицы (для движка базы данных Atomic). [#15984](https://github.com/ClickHouse/ClickHouse/pull/15984) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#16029](https://github.com/ClickHouse/ClickHouse/issues/16029): Предотвращено зависание реплики на 5–10 минут, когда ошибка репликации возникает после периода неактивности. [#15987](https://github.com/ClickHouse/ClickHouse/pull/15987) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#16088](https://github.com/ClickHouse/ClickHouse/issues/16088): Разрешено использовать структуру direct для словарей с составными ключами. [#16007](https://github.com/ClickHouse/ClickHouse/pull/16007) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#16360](https://github.com/ClickHouse/ClickHouse/issues/16360): Исправлен parser имени collate и имени charset, а также добавлена поддержка `length = 0` для string type. [#16008](https://github.com/ClickHouse/ClickHouse/pull/16008) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпортировано в [#16141](https://github.com/ClickHouse/ClickHouse/issues/16141): Исправлено зависание запроса `ALTER MODIFY ... ORDER BY` для `ReplicatedVersionedCollapsingMergeTree`. Это исправляет [#15980](https://github.com/ClickHouse/ClickHouse/issues/15980). [#16011](https://github.com/ClickHouse/ClickHouse/pull/16011) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#16078](https://github.com/ClickHouse/ClickHouse/issues/16078): Исправлена регрессия [#15780](https://github.com/ClickHouse/ClickHouse/issues/15780), например, `indexOf([1, 2, 3], toLowCardinality(1))` теперь запрещён, хотя не должен быть. [#16038](https://github.com/ClickHouse/ClickHouse/pull/16038) ([Mike Kot](https://github.com/myrrc)).
* Бэкпортировано в [#16294](https://github.com/ClickHouse/ClickHouse/issues/16294): Исправлена работа `dictGet` в `sharding_key` (и аналогичных местах, то есть когда контекст функции хранится постоянно). [#16205](https://github.com/ClickHouse/ClickHouse/pull/16205) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#16233](https://github.com/ClickHouse/ClickHouse/issues/16233): Исправлен случай, когда память могла выделяться сверх лимита. Закрывает [#14560](https://github.com/ClickHouse/ClickHouse/issues/14560). [#16206](https://github.com/ClickHouse/ClickHouse/pull/16206) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#16325](https://github.com/ClickHouse/ClickHouse/issues/16325): Исправлена возможная утечка памяти при `GROUP BY` со строковыми ключами, вызванная ошибкой в реализации `TwoLevelStringHashTable`. [#16264](https://github.com/ClickHouse/ClickHouse/pull/16264) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#16375](https://github.com/ClickHouse/ClickHouse/issues/16375): Исправлен асинхронный `Distributed INSERT` с `prefer_localhost_replica=0` и `internal_replication`. [#16358](https://github.com/ClickHouse/ClickHouse/pull/16358) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#16431](https://github.com/ClickHouse/ClickHouse/issues/16431): Исправлена работа `GROUP BY` с модификаторами totals/rollup/cube и функциями min/max по ключам группировки. Исправляет [#16393](https://github.com/ClickHouse/ClickHouse/issues/16393). [#16397](https://github.com/ClickHouse/ClickHouse/pull/16397) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#16450](https://github.com/ClickHouse/ClickHouse/issues/16450): Исправлено двойное освобождение памяти в случае Исключения в функции `dictGet`. Это могло произойти, если словарь был загружен с ошибкой. [#16429](https://github.com/ClickHouse/ClickHouse/pull/16429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
