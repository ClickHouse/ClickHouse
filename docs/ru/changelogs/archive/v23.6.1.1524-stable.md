<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Удалена возможность `do_not_evict_index_and_mark_files` в fs-кэше. Эта возможность лишь ухудшала ситуацию. [#51253](https://github.com/ClickHouse/ClickHouse/pull/51253) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Удалена поддержка ALTER для экспериментального LIVE VIEW. [#51287](https://github.com/ClickHouse/ClickHouse/pull/51287) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена настройка `session_timezone`, которая используется как часовой пояс сеанса по умолчанию, если он не задан явно. [#44149](https://github.com/ClickHouse/ClickHouse/pull/44149) ([Andrey Zvonov](https://github.com/zvonand)).
* Добавлены движок базы данных overlay и представление каталога в виде базы данных. Этот коммит добавляет 4 базы данных: 1. DatabaseOverlay: реализует интерфейс IDatabase. Позволяет объединять несколько баз данных, например FileSystem и Memory. Внутри хранит вектор указателей на другие базы данных и поочередно проксирует им запросы, пока один из них не будет успешно выполнен. 2. DatabaseFilesystem: позволяет взаимодействовать с файлами, хранящимися в файловой системе, в режиме только для чтения. Внутри использует TableFunctionFile для неявной загрузки файла, когда пользователь запрашивает таблицу. Результат вызова TableFunctionFile кэшируется внутри для быстрого доступа. 3. DatabaseS3: позволяет взаимодействовать с хранилищем S3 в режиме только для чтения. Использует TableFunctionS3 для неявной загрузки таблицы из S3 4. DatabaseHDFS: позволяет взаимодействовать с хранилищем HDFS. Использует TableFunctionHDFS для неявной загрузки таблицы из HDFS. [#48821](https://github.com/ClickHouse/ClickHouse/pull/48821) ([alekseygolub](https://github.com/alekseygolub)).
* Добавлена новая настройка `use_mysql_types_in_show_columns`, изменяющая SQL-оператор `SHOW COLUMNS` так, чтобы при подключении клиента через порт совместимости MySQL отображались эквивалентные типы MySQL. [#49577](https://github.com/ClickHouse/ClickHouse/pull/49577) ([Thomas Panetti](https://github.com/tpanetti)).
* Добавлена опция `--rename_files_after_processing <pattern>`. Это исправляет [#34207](https://github.com/ClickHouse/ClickHouse/issues/34207). [#49626](https://github.com/ClickHouse/ClickHouse/pull/49626) ([alekseygolub](https://github.com/alekseygolub)).
* 1. Добавлен `TableFunctionRedis` 3. Добавлен движок таблицы Redis 4. Добавлен `RedisCommon`, содержащий инструменты и типы, связанные с Redis 5. Добавлена поддержка проталкивания фильтров `equals` и `in` в Redis. [#50150](https://github.com/ClickHouse/ClickHouse/pull/50150) ([JackyWoo](https://github.com/JackyWoo)).
* Добавлена возможность пропускать пустые файлы в табличных функциях file/s3/url/hdfs с помощью настроек `s3_skip_empty_files`, `hdfs_skip_empty_files`, `engine_file_skip_empty_files`, `engine_url_skip_empty_files`. [#50364](https://github.com/ClickHouse/ClickHouse/pull/50364) ([Kruglov Pavel](https://github.com/Avogar)).
* Клиент ClickHouse теперь можно запускать, указывая соединение вместо &quot;--host&quot;, &quot;--port&quot;, &quot;--user&quot; и т. д. [#50689](https://github.com/ClickHouse/ClickHouse/pull/50689) ([Alexey Gerasimchuck](https://github.com/Demilivor)).
* Кодек DEFLATE&#95;QPL теперь управляется через настройку сервера &quot;enable&#95;deflate&#95;qpl&#95;codec&quot; (по умолчанию: false) вместо настройки &quot;allow&#95;experimental&#95;codecs&quot;. Это переводит QPL&#95;DEFLATE в неэкспериментальный статус. [#50775](https://github.com/ClickHouse/ClickHouse/pull/50775) ([Robert Schulze](https://github.com/rschu1ze)).



<div id="performance-improvement">
  #### Повышение производительности
</div>

* Повышена производительность при включенном QueryProfiler за счет использования потоко-локального `timer_id` вместо глобального объекта. [#48778](https://github.com/ClickHouse/ClickHouse/pull/48778) ([Jiebin Sun](https://github.com/jiebinn)).
* Для повышения производительности переписан входной/выходной формат CapnProto. Имена столбцов Map и поля CapnProto теперь сопоставляются без учета регистра, исправлены чтение и запись полей вложенных структур. [#49752](https://github.com/ClickHouse/ClickHouse/pull/49752) ([Kruglov Pavel](https://github.com/Avogar)).
* Оптимизирована производительность записи Parquet в параллельных потоках. [#50102](https://github.com/ClickHouse/ClickHouse/pull/50102) ([Hongbin Ma](https://github.com/binmahone)).
* ### Запись в документации для пользовательских изменений Отключен `parallelize_output_from_storages` для обработки MATERIALIZED VIEW и хранилищ, содержащих только один блок. [#50214](https://github.com/ClickHouse/ClickHouse/pull/50214) ([Azat Khuzhin](https://github.com/azat)).
* Смержен PR https://github.com/ClickHouse/ClickHouse/pull/46558 (избежание обработки уже отсортированных данных). Исключена перестановка блока при сортировке, если блок уже отсортирован. [#50697](https://github.com/ClickHouse/ClickHouse/pull/50697) ([Maksim Kita](https://github.com/kitaisreal)).
* В предыдущих PR ([#50062](https://github.com/ClickHouse/ClickHouse/issues/50062), [#50307](https://github.com/ClickHouse/ClickHouse/issues/50307)) мы предложили шаблон оптимизации, который преобразует predicates с toYear/toYYYYMM в эквивалентную форму без converter. Это преобразование могло существенно повысить производительность некоторых рабочих нагрузок, таких как SSB. Однако, как указано в issue [#50628](https://github.com/ClickHouse/ClickHouse/issues/50628), эти два PR приводили к проблемам, которые могли вызывать неполные результаты запроса, поэтому они были отменены в [#50629](https://github.com/ClickHouse/ClickHouse/issues/50629). [#50951](https://github.com/ClickHouse/ClickHouse/pull/50951) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* Несколько list requests к ZooKeeper теперь выполняются параллельно, чтобы ускорить чтение из таблицы system.zookeeper. [#51042](https://github.com/ClickHouse/ClickHouse/pull/51042) ([Alexander Gololobov](https://github.com/davenger)).
* Ускорена инициализация lookup tables для DateTime и часовых поясов. Это должно сократить время запуска/подключения клиента ClickHouse, особенно в debug build, поскольку эта операция довольно затратна. [#51347](https://github.com/ClickHouse/ClickHouse/pull/51347) ([Alexander Gololobov](https://github.com/davenger)).
