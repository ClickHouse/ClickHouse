<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#46372](https://github.com/ClickHouse/ClickHouse/issues/46372): Исправлено чрезмерное использование памяти при вертикальных слияниях на неудалённом диске. Для удалённого диска учитывается `max_insert_delayed_streams_for_parallel_write`. [#46275](https://github.com/ClickHouse/ClickHouse/pull/46275) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#46357](https://github.com/ClickHouse/ClickHouse/issues/46357): Разрешено использовать алгоритм Вертикального слияния с частями в формате Compact. Это позволит ClickHouse server использовать значительно меньше памяти для фоновых операций. Закрывает [#46084](https://github.com/ClickHouse/ClickHouse/issues/46084). [#46282](https://github.com/ClickHouse/ClickHouse/pull/46282) ([Anton Popov](https://github.com/CurtizJ)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#45856](https://github.com/ClickHouse/ClickHouse/issues/45856): исправлено скачивание ZooKeeper, обновлена версия и оптимизирован размер образа. [#44853](https://github.com/ClickHouse/ClickHouse/pull/44853) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователям, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#45620](https://github.com/ClickHouse/ClickHouse/issues/45620): Ещё одно исправление для ошибки `Cannot read all data`, которая могла возникать при чтении словаря `LowCardinality` из remote fs. Исправляет [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709). [#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#45549](https://github.com/ClickHouse/ClickHouse/issues/45549): Исправлено исключение при выполнении `SELECT ... FROM system.dictionaries`, возникавшее при наличии словаря с некорректной структурой (например, с неверным типом в XML-конфиге). [#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
