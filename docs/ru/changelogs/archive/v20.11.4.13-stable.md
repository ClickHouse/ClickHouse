<div id="clickhouse-release-v2011413-stable-fixme-as-compared-to-v201133-stable">
  ### Релиз ClickHouse v20.11.4.13-stable FIXME по сравнению с v20.11.3.3-stable
</div>

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#17032](https://github.com/ClickHouse/ClickHouse/issues/17032): добавлена возможность подключаться к защищённой конечной точке `clickhouse-server`, требующей SNI. Это возможно, когда `clickhouse-server` размещён за TLS-прокси. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#17074](https://github.com/ClickHouse/ClickHouse/issues/17074): исправлены [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) и [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231), устранён сбой удалённого запроса при использовании агрегатной функции с суффиксом &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпортировано в [#17024](https://github.com/ClickHouse/ClickHouse/issues/17024): исправлен crash при использовании `any` без аргументов. Это для [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#16881](https://github.com/ClickHouse/ClickHouse/issues/16881): multipart-загрузка прерывается, если в WriteBufferFromS3 не было записано данных. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Бэкпортировано в [#16948](https://github.com/ClickHouse/ClickHouse/issues/16948): предотвращены crash ClickHouse server при использовании TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17076](https://github.com/ClickHouse/ClickHouse/issues/17076): исправлена возможная ошибка `Illegal type of argument` для запросов с `ORDER BY`. Исправляет [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#17010](https://github.com/ClickHouse/ClickHouse/issues/17010): скрипт установки должен всегда создавать подкаталоги в папках config. Это актуально только для Docker build с пользовательским config. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#16966](https://github.com/ClickHouse/ClickHouse/issues/16966): информация blame вычислялась некорректно в `clickhouse-git-import`. [#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#17014](https://github.com/ClickHouse/ClickHouse/issues/17014): исправлен возможный crash сервера после `ALTER TABLE ... MODIFY COLUMN ... NewType`, когда `SELECT` содержит предложение `WHERE` для изменяемого столбца, а изменение ещё не завершено. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#17039](https://github.com/ClickHouse/ClickHouse/issues/17039): повторно разрешать IP-адрес для `format_avro_schema_registry_url` в случае ошибок. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17093](https://github.com/ClickHouse/ClickHouse/issues/17093): исправлен неверный результат для больших целых чисел (128, 256 bit) при приведении из double. [#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc)).
* Бэкпортировано в [#17127](https://github.com/ClickHouse/ClickHouse/issues/17127): устранены лишние сетевые ошибки для удалённых запросов, которые могут быть отменены во время выполнения, например запросов с `LIMIT`. [#17006](https://github.com/ClickHouse/ClickHouse/pull/17006) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#17132](https://github.com/ClickHouse/ClickHouse/issues/17132): Исправлен сбой при выполнении запроса `CREATE TABLE ... AS some_table`, если `some_table` была создана с помощью `AS table_function()`. Исправляет [#16944](https://github.com/ClickHouse/ClickHouse/issues/16944). [#17072](https://github.com/ClickHouse/ClickHouse/pull/17072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#17170](https://github.com/ClickHouse/ClickHouse/issues/17170): Исправлена ошибка, из-за которой запросы `ON CLUSTER` могли зависать навсегда на нелидерных таблицах ReplicatedMergeTree. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
