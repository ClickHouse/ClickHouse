  #### Исправление ошибки (заметное пользователям некорректное поведение в официальном стабильном релизе)
</div>

* Бэкпортировано в [#44998](https://github.com/ClickHouse/ClickHouse/issues/44998): ещё одно исправление ошибки `Cannot read all data`, которая могла возникать при чтении словаря `LowCardinality` из remote fs. Исправляет [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709). [#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#45551](https://github.com/ClickHouse/ClickHouse/issues/45551): исправлено Исключение `SELECT ... FROM system.dictionaries`, возникавшее при наличии словаря с некорректной структурой (например, с неправильным типом в XML-конфигурации). [#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
