  #### Обратно несовместимое изменение

* Улучшена обработка переполнения в функции toDatetime. Если строка даты слишком велика, она будет преобразована в 1970. [#32898](https://github.com/ClickHouse/ClickHouse/pull/32898) ([HaiBo Li](https://github.com/marising)).
* arrayCompact теперь ведет себя как и другие функции высшего порядка: компактизация выполняется не для результатов лямбда-функции, а для исходного массива. Если вы используете в arrayCompact нетривиальные лямбда-функции, вы можете восстановить прежнее поведение, обернув аргументы arrayCompact в arrayMap. Закрывает [#34010](https://github.com/ClickHouse/ClickHouse/issues/34010) [#18535](https://github.com/ClickHouse/ClickHouse/issues/18535) [#14778](https://github.com/ClickHouse/ClickHouse/issues/14778). * Новый тип данных `Object(<schema_format>)`, поддерживающий хранение полуструктурированных данных (на данный момент только JSON). Данные записываются в такие типы в виде строки. Затем все пути извлекаются в соответствии с форматом полуструктурированных данных и записываются в отдельные столбцы с наиболее подходящими типами, способными хранить все их значения. К этим столбцам можно обращаться по именам, соответствующим путям в исходных данных, например `data.key1.key2` или с оператором приведения типов `data.key1.key2::Int64`. #### Повышение производительности

* Вызов `std::distance` на большом списке снижает производительность; вместо этого используется версия в `Node`, что требует дополнительных 80 МБ памяти на 1000w Nodes. Логика следующая: каждый `node` в списке имеет версию типа `size_t`, которая задаётся в методе `insert` или `insertOrReplace` с использованием переменной-члена класса `current_version`. Версия увеличивается только в методе `enableSnapshot`. При создании снимка вызывается `snapshotSizeWithVersion`, чтобы получить размер снимка и версию (`snapshot_up_to_version`). При обходе списка, если версия `node` меньше либо равна `snapshot_up_to_version`, он защищён от удаления; если версия `node` больше `snapshot_up_to_version`, с ним можно делать что угодно. [#34486](https://github.com/ClickHouse/ClickHouse/pull/34486) ([zhanglistar](https://github.com/zhanglistar)).
* Для compaction хранилища журнала в Nuraft требуется захватить внутреннюю блокировку, которая также используется в обычном процессе коммита, поэтому ненужные журналы удаляются в методе `compact` класса Changelog в фоновом потоке. Подробности см.: https://github.com/ClickHouse-Extras/NuRaft/blob/1707a7572aa66ec5d0a2dbe2bf5effa3352e6b2d/src/handle&#95;commit.cxx#L560. [#34534](https://github.com/ClickHouse/ClickHouse/pull/34534) ([zhanglistar](https://github.com/zhanglistar)).
* Последний снимок больше не удерживается в памяти; вместо этого он считывается при необходимости. Последовательное чтение достигает скорости свыше 200 MBps даже на HDD при использовании системного вызова `mmap`. Данные снимка записываются напрямую на диск с использованием метода сжатия без хранения в памяти ни исходных, ни сжатых данных. [#34584](https://github.com/ClickHouse/ClickHouse/pull/34584) ([zhanglistar](https://github.com/zhanglistar)).
* В MergeTree улучшена производительность вставки за счёт замены `std::stable_sort` на `pdqsort`. [#34750](https://github.com/ClickHouse/ClickHouse/pull/34750) ([Maksim Kita](https://github.com/kitaisreal)).
* Улучшена производительность функции агрегации `ANY` за счёт обработки батчей. [#34760](https://github.com/ClickHouse/ClickHouse/pull/34760) ([Raúl Marín](https://github.com/Algunenano)).
* Улучшена производительность функций `detectCharset `, `detectLanguageUnknown `. Улучшена производительность `DirectDictionary`, если dictionary source — `ClickHouse`. Улучшена производительность обработки queries с большим разделом `IN`. [#34888](https://github.com/ClickHouse/ClickHouse/pull/34888) ([Maksim Kita](https://github.com/kitaisreal)).
* Уменьшено количество блокировок при работе с соединением за счёт использования атомарной статистики. Обратите внимание, что эта статистика приблизительная. [#35010](https://github.com/ClickHouse/ClickHouse/pull/35010) ([zhanglistar](https://github.com/zhanglistar)).
