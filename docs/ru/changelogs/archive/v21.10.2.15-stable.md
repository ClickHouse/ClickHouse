<div id="bug-fix">

</div>

* Бэкпортировано в [#29776](https://github.com/ClickHouse/ClickHouse/issues/29776): Разрешено использовать материализованный столбец в качестве ключа сегментирования в distributed таблице, даже если `insert_allow_materialized_columns=0`:. [#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#28792](https://github.com/ClickHouse/ClickHouse/issues/28792): Исправлено преобразование цепочки дизъюнкций в `IN` (управляется настройкой `optimize_min_equality_disjunction_chain_length`) в распределённых запросах с настройкой `legacy_column_name_of_tuple_literal = 0`. [#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#29127](https://github.com/ClickHouse/ClickHouse/issues/29127): Исправлена ошибка в `clickhouse-keeper-converter`, которая может приводить к некорректной десериализации журнала ZooKeeper. [#29071](https://github.com/ClickHouse/ClickHouse/pull/29071) ([小路](https://github.com/nicelulu)).
* Бэкпортировано в [#29970](https://github.com/ClickHouse/ClickHouse/issues/29970): Исправлено завершение работы `AccessControlManager`. Теперь после уничтожения `AccessControlManager` повторная загрузка конфигурации невозможна. Этот PR исправляет нестабильный тест [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html). [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#30051](https://github.com/ClickHouse/ClickHouse/issues/30051): Исправлено освобождение query ID и session ID в конце обработки запроса при обработке вызова gRPC. Этот PR исправляет нестабильный тест [test&#95;grpc&#95;protocol/test.py::test&#95;session](https://clickhouse-test-reports.s3.yandex.net/0/1ac03811a2df9717fa7c633d1af03def821d24b6/integration_tests_\(memory\).html). [#29954](https://github.com/ClickHouse/ClickHouse/pull/29954) ([Vitaly Baranov](https://github.com/vitlibar)).
