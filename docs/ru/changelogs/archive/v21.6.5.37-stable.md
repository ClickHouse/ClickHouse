<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#25480](https://github.com/ClickHouse/ClickHouse/issues/25480): Исправлена ошибка «Missing columns» при JOIN с Distributed Materialized View. [#24870](https://github.com/ClickHouse/ClickHouse/pull/24870) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#25366](https://github.com/ClickHouse/ClickHouse/issues/25366): Исправлена сериализация разбитых вложенных сообщений в формате Protobuf. Этот PR исправляет [#24647](https://github.com/ClickHouse/ClickHouse/issues/24647). [#25000](https://github.com/ClickHouse/ClickHouse/pull/25000) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#25102](https://github.com/ClickHouse/ClickHouse/issues/25102): KILL MUTATION теперь различает разные таблицы (исправлена неожиданная ошибка `Cancelled mutating parts`). [#25025](https://github.com/ClickHouse/ClickHouse/pull/25025) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#25213](https://github.com/ClickHouse/ClickHouse/issues/25213): Исправлена ошибка, возникавшая при вставке подмножества столбцов с использованием формата CSVWithNames. Исправляет [#25129](https://github.com/ClickHouse/ClickHouse/issues/25129). [#25169](https://github.com/ClickHouse/ClickHouse/pull/25169) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#25352](https://github.com/ClickHouse/ClickHouse/issues/25352): Исправлена TOCTOU-ошибка в скрипте установки. [#25277](https://github.com/ClickHouse/ClickHouse/pull/25277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#25385](https://github.com/ClickHouse/ClickHouse/issues/25385): Исправлены некорректное поведение и отчёт UBSan для больших целых чисел. В предыдущих версиях `CAST(1e19 AS UInt128)` возвращал ноль. [#25279](https://github.com/ClickHouse/ClickHouse/pull/25279) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#25470](https://github.com/ClickHouse/ClickHouse/issues/25470): Исправлен `joinGetOrNull` для столбцов без NULL. Это исправляет [#24261](https://github.com/ClickHouse/ClickHouse/issues/24261). [#25288](https://github.com/ClickHouse/ClickHouse/pull/25288) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#25360](https://github.com/ClickHouse/ClickHouse/issues/25360): Исправлена ошибка `Bad cast from type DB::ColumnLowCardinality to DB::ColumnVector<char8_t>` для запросов, где аргумент `LowCardinality` использовался в IN (эта ошибка появилась в 21.6). Исправляет [#25187](https://github.com/ClickHouse/ClickHouse/issues/25187). [#25290](https://github.com/ClickHouse/ClickHouse/pull/25290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#25356](https://github.com/ClickHouse/ClickHouse/issues/25356): Исправлена логическая ошибка `Cannot sum Array/Tuple` в min/maxMap. [#25298](https://github.com/ClickHouse/ClickHouse/pull/25298) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#25436](https://github.com/ClickHouse/ClickHouse/issues/25436): Добавлена поддержка `SimpleAggregateFunction(LowCardinality)` для `SummingMergeTree`. Исправляет [#25134](https://github.com/ClickHouse/ClickHouse/issues/25134). [#25300](https://github.com/ClickHouse/ClickHouse/pull/25300) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#25363](https://github.com/ClickHouse/ClickHouse/issues/25363): При потере соединения с ZooKeeper таблица `ReplicatedMergeTree` могла дожидаться завершения фоновых операций перед попыткой переподключения. Это исправлено: теперь фоновые операции принудительно останавливаются. [#25306](https://github.com/ClickHouse/ClickHouse/pull/25306) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#25388](https://github.com/ClickHouse/ClickHouse/issues/25388): устранена возможность недетерминированного поведения функции `quantileDeterministic` и аналогичных ей. Закрывает [#20480](https://github.com/ClickHouse/ClickHouse/issues/20480). [#25313](https://github.com/ClickHouse/ClickHouse/pull/25313) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#25448](https://github.com/ClickHouse/ClickHouse/issues/25448): исправлена потеря условия `WHERE` при push-down-оптимизации выражений в плане запроса (настройка `query_plan_filter_push_down = 1` включена по умолчанию). Исправляет [#25368](https://github.com/ClickHouse/ClickHouse/issues/25368). [#25370](https://github.com/ClickHouse/ClickHouse/pull/25370) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#25407](https://github.com/ClickHouse/ClickHouse/issues/25407): исправлен преобразователь столбцов `REPLACE` при использовании в DDL — теперь форматированный запрос корректно заключается в кавычки. Исправляет [#23925](https://github.com/ClickHouse/ClickHouse/issues/23925). [#25391](https://github.com/ClickHouse/ClickHouse/pull/25391) ([Amos Bird](https://github.com/amosbird)).
