* Бэкпортировано в [#67713](https://github.com/ClickHouse/ClickHouse/issues/67713): Исправлена перезагрузка SQL UDF с UNION. Ранее перезапуск сервера мог привести к тому, что UDF становилась невалидной. [#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#67995](https://github.com/ClickHouse/ClickHouse/issues/67995): Добавлена проверка экспериментальных/подозрительных типов данных в ALTER ADD/MODIFY COLUMN. [#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### Критические исправления ошибок (crash, LOGICAL_ERROR, потеря данных, RBAC)
</div>

* Бэкпортировано в [#67818](https://github.com/ClickHouse/ClickHouse/issues/67818): Относится только к экспериментальному типу данных Variant. Исправлен crash при использовании типа Variant + AggregateFunction. [#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#67766](https://github.com/ClickHouse/ClickHouse/issues/67766): Исправлен crash в `uniq` и `uniqTheta ` с аргументом `tuple()`. Закрывает [#67303](https://github.com/ClickHouse/ClickHouse/issues/67303). [#67306](https://github.com/ClickHouse/ClickHouse/pull/67306) ([flynn](https://github.com/ucasfl)).
* Бэкпортировано в [#67854](https://github.com/ClickHouse/ClickHouse/issues/67854): Исправляет [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026). Исключён обход неразрешённых аргументов table function в `ReplaceTableNodeToDummyVisitor`. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#67840](https://github.com/ClickHouse/ClickHouse/issues/67840): Исправлено потенциальное переполнение стека в функции `JSONMergePatch`. Эта функция была переименована из `jsonMergePatch` в `JSONMergePatch`, поскольку прежнее имя было неверным. Прежнее имя по-прежнему сохранено для совместимости. Улучшена диагностика ошибок в функции. Закрывает [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304). [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
