  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#59425](https://github.com/ClickHouse/ClickHouse/issues/59425): Исправлена функция translate() для входных данных типа FixedString. Это могло приводить к аварийному завершению, поскольку возвращался столбец String (вместо ожидаемого FixedString). Эту ошибку обнаружил YohannJardin в рамках программы ClickHouse Bug Bounty Program. [#59356](https://github.com/ClickHouse/ClickHouse/pull/59356) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#59478](https://github.com/ClickHouse/ClickHouse/issues/59478): Исправлены трассировки стека для бинарных файлов без отладочных символов. [#59444](https://github.com/ClickHouse/ClickHouse/pull/59444) ([Azat Khuzhin](https://github.com/azat)).
