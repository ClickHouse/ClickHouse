<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Добавлена поддержка настраиваемого представления значения NULL для форматов ввода TSV/CSV. Исправлена десериализация Nullable(String) в форматах ввода TSV/CSV/JSONCompactStringsEachRow/JSONStringsEachRow. Соответственно, `output_format_csv_null_representation` и `output_format_tsv_null_representation` переименованы в `format_csv_null_representation` и `format_tsv_null_representation`. [#30497](https://github.com/ClickHouse/ClickHouse/pull/30497) ([Kruglov Pavel](https://github.com/Avogar)).
* JSON&#95;VALUE теперь возвращает строку без кавычек. Закрывает [#27965](https://github.com/ClickHouse/ClickHouse/issues/27965). [#31008](https://github.com/ClickHouse/ClickHouse/pull/31008) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Запрещен direct select для Kafka/RabbitMQ/FileLog. Его можно включить настройкой `stream_like_engine_allow_direct_select`. Direct select не будет разрешен даже при включенной настройке, если есть attached materialized view. Для Kafka и RabbitMQ direct select, если он разрешен, по умолчанию не будет выполнять коммит сообщений. Чтобы включить commits при direct select, пользователь должен использовать настройку уровня storage `kafka{rabbitmq}_commit_on_select=1` (по умолчанию `0`). cc @filimonov. [#31053](https://github.com/ClickHouse/ClickHouse/pull/31053) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Механизм «выбора лидера» удален из `ReplicatedMergeTree`, поскольку с версии 20.6 поддерживается несколько лидеров. Если вы обновляетесь с более старой версии и какая-либо реплика со старой версией является лидером, то после обновления сервер не сможет запуститься. Остановите реплики со старой версией, чтобы новая версия смогла запуститься. После этого понизить версию до версии ниже 20.6 будет невозможно. [#32140](https://github.com/ClickHouse/ClickHouse/pull/32140) ([Alexander Tokmakov](https://github.com/tavplubix)).
