<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#74823](https://github.com/ClickHouse/ClickHouse/issues/74823): Исправлен редкий сбой в refreshable materialized view во время остановки сервера. [#73323](https://github.com/ClickHouse/ClickHouse/pull/73323) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#74381](https://github.com/ClickHouse/ClickHouse/issues/74381): Исправлен `NOT_FOUND_COLUMN_IN_BLOCK` в запросах с `FINAL` и `SAMPLE`. Исправлен некорректный результат в `SELECT`-запросах с `FINAL` из `CollapsingMergeTree`, а также включены оптимизации `FINAL`. [#73682](https://github.com/ClickHouse/ClickHouse/pull/73682) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#74810](https://github.com/ClickHouse/ClickHouse/issues/74810): Исправлена уязвимость безопасности, предотвращающая SQL-инъекцию в table function `postgresql` и `sqlite`. [#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#74392](https://github.com/ClickHouse/ClickHouse/issues/74392): Исправлена logical error в `s3queue` при пометке файла как failed. [#74216](https://github.com/ClickHouse/ClickHouse/pull/74216) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#75124](https://github.com/ClickHouse/ClickHouse/issues/75124): Исправлен сбой при вставке interval (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)). [#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* Бэкпортировано в [#75097](https://github.com/ClickHouse/ClickHouse/issues/75097): Исправлены запросы `INSERT SELECT` между таблицами со столбцами `Tuple`, а также включена разреженная сериализация. [#74698](https://github.com/ClickHouse/ClickHouse/pull/74698) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#75309](https://github.com/ClickHouse/ClickHouse/issues/75309): Исправлен сбой при разборе объявления JSON type, когда type name указан не в верхнем регистре. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#74869](https://github.com/ClickHouse/ClickHouse/issues/74869): Исправление в Keeper: исправлено чтение записей журнала с диска. [#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#75076](https://github.com/ClickHouse/ClickHouse/issues/75076): Исправлено отсутствие полей `used_privileges` и `missing_privileges` в `query_log` для операций BACKUP и RESTORE. [#74887](https://github.com/ClickHouse/ClickHouse/pull/74887) ([Alexey Katsman](https://github.com/alexkats)).
* Бэкпортировано в [#74957](https://github.com/ClickHouse/ClickHouse/issues/74957): Исправлена ошибка FILE&#95;DOESNT&#95;EXIST, возникавшая при слиянии data parts для таблицы с пустым столбцом в Azure Blob Storage. [#74892](https://github.com/ClickHouse/ClickHouse/pull/74892) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#75054](https://github.com/ClickHouse/ClickHouse/issues/75054): В HDFS обновляется krb ticket при ошибке sasl во время запроса `hdfs` select. [#74930](https://github.com/ClickHouse/ClickHouse/pull/74930) ([inv2004](https://github.com/inv2004)).
* Бэкпортировано в [#75413](https://github.com/ClickHouse/ClickHouse/issues/75413): Состояние part&#39;s возвращается из deleting обратно в устаревший, если операция remove завершилась неудачей. [#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#75463](https://github.com/ClickHouse/ClickHouse/issues/75463): Исправлен сбой CTE при вставке. [#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).

<div id="buildtestingpackaging-improvement">
  #### Сборка/Тестирование/Улучшения упаковки
</div>

* Бэкпортировано в [#75289](https://github.com/ClickHouse/ClickHouse/issues/75289): улучшены ещё более строгие настройки по умолчанию. Текущие настройки по умолчанию уже безопасны — чтобы опубликовать порты, пользователь должен явно указать соответствующий параметр. Однако если для пользователя `default` не задан пароль через переменную окружения `CLICKHOUSE_PASSWORD` и/или не изменено имя пользователя через переменную окружения `CLICKHOUSE_USER`, он должен быть доступен только с локальной системы в качестве дополнительного уровня защиты. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
