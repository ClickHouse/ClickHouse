  ### Релиз ClickHouse v20.7.1.4310-prestable FIXME по сравнению с версией v20.6.1.4066-prestable
</div>

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Специальный вывод нулевых значений Date/DateTime в виде `0000-00-00` и `0000-00-00 00:00:00` объявлен устаревшим. [#12442](https://github.com/ClickHouse/ClickHouse/pull/12442) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Функция `modulo` (оператор `%`), если хотя бы один аргумент является числом с плавающей точкой, будет вычислять остаток от деления непосредственно для чисел с плавающей точкой, без преобразования обоих аргументов в целые числа. Это делает её поведение совместимым с большинством DBMS. Это также применимо к типам данных Date и DateTime. Добавлен alias `mod`. Закрывает [#7323](https://github.com/ClickHouse/ClickHouse/issues/7323). [#12585](https://github.com/ClickHouse/ClickHouse/pull/12585) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Новая возможность
</div>

* * Добавлена поддержка LDAP-аутентификации для предварительно настроенных пользователей (метод &quot;Simple Bind&quot;). [#11234](https://github.com/ClickHouse/ClickHouse/pull/11234) ([Denis Glazachev](https://github.com/traceon)).
* Добавлены функции mapAdd и mapSubtract для работы с maps на основе Tuple. [#11735](https://github.com/ClickHouse/ClickHouse/pull/11735) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Добавлена таблица `system.crash_log`, в которую собираются трассировки стека при фатальных ошибках. [#12316](https://github.com/ClickHouse/ClickHouse/pull/12316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена функция `bayesAB` для байесовского A/B-тестирования. [#12327](https://github.com/ClickHouse/ClickHouse/pull/12327) ([achimbab](https://github.com/achimbab)).

* Добавлена функция `formatRow`, которая позволяет преобразовывать произвольные expressions в строку в заданном формате. Она полезна для обработки вывода SQL и весьма универсальна в сочетании с функцией `columns`. [#12574](https://github.com/ClickHouse/ClickHouse/pull/12574) ([Amos Bird](https://github.com/amosbird)).
* Добавлена настройка `allow_non_metadata_alters`, которая ограничивает выполнение queries `ALTER`, изменяющих данные на disk. По умолчанию отключена. Закрывает [#11547](https://github.com/ClickHouse/ClickHouse/issues/11547). [#12635](https://github.com/ClickHouse/ClickHouse/pull/12635) ([alesapin](https://github.com/alesapin)).
* Добавлена поддержка функций `minMap` и `maxMap` в `SimpleAggregateFunction`. [#12662](https://github.com/ClickHouse/ClickHouse/pull/12662) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Добавлены HTTP-заголовки `X-ClickHouse-Database` и `X-ClickHouse-Format`, которые можно использовать для задания базы данных по умолчанию и формата вывода. [#12981](https://github.com/ClickHouse/ClickHouse/pull/12981) ([hcz](https://github.com/hczhcz)).
* Реализованы пользовательские настройки. [#13013](https://github.com/ClickHouse/ClickHouse/pull/13013) ([Vitaly Baranov](https://github.com/vitlibar)).
