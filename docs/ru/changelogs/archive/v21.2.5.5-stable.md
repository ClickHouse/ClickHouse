<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#20574](https://github.com/ClickHouse/ClickHouse/issues/20574): Исправлен сбой, который мог произойти при получении неизвестного пакета от remove query (добавлено в [#17868](https://github.com/ClickHouse/ClickHouse/issues/17868)). [#20547](https://github.com/ClickHouse/ClickHouse/pull/20547) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21006](https://github.com/ClickHouse/ClickHouse/issues/21006): Исправлена ошибка `Empty task was returned from async task queue` при отмене запроса. [#20881](https://github.com/ClickHouse/ClickHouse/pull/20881) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21132](https://github.com/ClickHouse/ClickHouse/issues/21132): Исправлено поведение, при котором `ALTER MODIFY COLUMN` создавал мутацию, заведомо завершающуюся ошибкой. [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#21251](https://github.com/ClickHouse/ClickHouse/issues/21251): - Заблокированы параллельные вставки в хранилище Join. [#21009](https://github.com/ClickHouse/ClickHouse/pull/21009) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#21069](https://github.com/ClickHouse/ClickHouse/issues/21069): Был возможен выход за границы памяти при форматировании специально сформированного значения типа `DateTime64`, выходящего за допустимый диапазон. Это закрывает [#20494](https://github.com/ClickHouse/ClickHouse/issues/20494). Это закрывает [#20543](https://github.com/ClickHouse/ClickHouse/issues/20543). [#21023](https://github.com/ClickHouse/ClickHouse/pull/21023) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#21160](https://github.com/ClickHouse/ClickHouse/issues/21160): Исправлено применение `input_format_null_as_default` для типов Nullable. Это исправляет [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116). [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#21228](https://github.com/ClickHouse/ClickHouse/issues/21228): Исправляет [#21112](https://github.com/ClickHouse/ClickHouse/issues/21112). Исправлена ошибка, которая могла приводить к дубликатам в запросе вставки (если один из обратных вызовов срабатывал слишком поздно). [#21138](https://github.com/ClickHouse/ClickHouse/pull/21138) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#21276](https://github.com/ClickHouse/ClickHouse/issues/21276): Исправлена ошибка с `join_use_nulls` и JOIN `TOTALS` из подзапросов. Это закрывает [#19362](https://github.com/ClickHouse/ClickHouse/issues/19362) и [#21137](https://github.com/ClickHouse/ClickHouse/issues/21137). [#21248](https://github.com/ClickHouse/ClickHouse/pull/21248) ([Vladimir C](https://github.com/vdimir)).
