<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#14361](https://github.com/ClickHouse/ClickHouse/issues/14361): Добавлена авторизация Redis с requirepass. [#13688](https://github.com/ClickHouse/ClickHouse/pull/13688) ([Ivan Torgashov](https://github.com/it1804)).
* Бэкпортировано в [#14875](https://github.com/ClickHouse/ClickHouse/issues/14875): Разрешено использовать конфигурацию хранилища с несколькими томами в движке Distributed. [#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#14080](https://github.com/ClickHouse/ClickHouse/issues/14080): Исправлен код состояния ответа конечной точки /replicas&#95;status при verbose=1. [#13722](https://github.com/ClickHouse/ClickHouse/pull/13722) ([javi santana](https://github.com/javisantana)).
* Бэкпортировано в [#14388](https://github.com/ClickHouse/ClickHouse/issues/14388): Исправлен оператор GRANT ALL при выполнении на неглобальном уровне. [#13987](https://github.com/ClickHouse/ClickHouse/pull/13987) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#14137](https://github.com/ClickHouse/ClickHouse/issues/14137): Исправлена функция pointInPolygon для случая, когда в качестве полигона используется константный двумерный массив. [#14079](https://github.com/ClickHouse/ClickHouse/pull/14079) ([Alexey Ilyukhov](https://github.com/livace)).
* Бэкпортировано в [#14292](https://github.com/ClickHouse/ClickHouse/issues/14292): Исправлен crash при INERT INTO в таблицу с движком Kafka из пустого результирующего набора с подзапросом. ... [#14203](https://github.com/ClickHouse/ClickHouse/pull/14203) ([Dongdong Yang](https://github.com/donge)).
* Бэкпортировано в [#14307](https://github.com/ClickHouse/ClickHouse/issues/14307): Исправлен segfault в `clickhouse-odbc-bridge` при получении схемы из некоторых внешних источников. Этот PR исправляет [#13861](https://github.com/ClickHouse/ClickHouse/issues/13861). [#14267](https://github.com/ClickHouse/ClickHouse/pull/14267) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#14342](https://github.com/ClickHouse/ClickHouse/issues/14342): Исправлен crash во время `ALTER` запроса для таблицы, созданной с помощью `AS table_function`. Исправляет [#14212](https://github.com/ClickHouse/ClickHouse/issues/14212). [#14326](https://github.com/ClickHouse/ClickHouse/pull/14326) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#14364](https://github.com/ClickHouse/ClickHouse/issues/14364): Выполнение запроса останавливается, если в самом `PipelineExecutor` произошло исключение. Это может предотвратить редкое зависание запроса. [#14334](https://github.com/ClickHouse/ClickHouse/pull/14334) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#14507](https://github.com/ClickHouse/ClickHouse/issues/14507): Выполнение запроса останавливается, если в самом `PipelineExecutor` произошло исключение. Это может предотвратить редкое зависание запроса. Продолжение [#14334](https://github.com/ClickHouse/ClickHouse/issues/14334). [#14402](https://github.com/ClickHouse/ClickHouse/pull/14402) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#14486](https://github.com/ClickHouse/ClickHouse/issues/14486): Исправлен bug, который приводит к неверному назначению слияний, если в таблице есть партиции с одной частью данных. [#14444](https://github.com/ClickHouse/ClickHouse/pull/14444) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#14482](https://github.com/ClickHouse/ClickHouse/issues/14482): Добавлена проверка переполнения размера массива в aggregate function `topK`. Без этой проверки пользователь может отправить запрос со специально подобранными параметрами, который приведёт к crash сервера. Это закрывает [#14452](https://github.com/ClickHouse/ClickHouse/issues/14452). [#14467](https://github.com/ClickHouse/ClickHouse/pull/14467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#14601](https://github.com/ClickHouse/ClickHouse/issues/14601): Исправлены редкие segfault в функциях с комбинатором -Resample, которые могли возникать в результате overflow при очень больших параметрах. [#14562](https://github.com/ClickHouse/ClickHouse/pull/14562) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#14728](https://github.com/ClickHouse/ClickHouse/issues/14728): Очистка каталога данных после исключений ZooKeeper во время CreateQuery для движка StorageReplicatedMergeTree. [#14563](https://github.com/ClickHouse/ClickHouse/pull/14563) ([Bharat Nallan](https://github.com/bharatnc)).
* Бэкпортировано в [#14665](https://github.com/ClickHouse/ClickHouse/issues/14665): Исправлен неверный результат умножения Decimal, вызванный неправильным масштабом Decimal у результирующего столбца. [#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)).
* Бэкпортировано в [#14806](https://github.com/ClickHouse/ClickHouse/issues/14806): Исправлена ошибка, из-за которой мутация `ALTER UPDATE` со столбцом Nullable в выражении присваивания и константным значением (например, `UPDATE x = 42`) приводит к некорректному значению в столбце или segfault. Исправляет [#13634](https://github.com/ClickHouse/ClickHouse/issues/13634), [#14045](https://github.com/ClickHouse/ClickHouse/issues/14045). [#14646](https://github.com/ClickHouse/ClickHouse/pull/14646) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#14720](https://github.com/ClickHouse/ClickHouse/issues/14720): Исправлено отсутствие имени базы данных по умолчанию в метаданных materialized view при выполнении `ALTER ... MODIFY QUERY`. [#14664](https://github.com/ClickHouse/ClickHouse/pull/14664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#14911](https://github.com/ClickHouse/ClickHouse/issues/14911): Исправлен SIGSEGV при попытке выполнить INSERT в StorageFile(fd). [#14887](https://github.com/ClickHouse/ClickHouse/pull/14887) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#14942](https://github.com/ClickHouse/ClickHouse/issues/14942): Исправлена проблема, из-за которой некоторые вызовы функции `extractAllGroups` могут вызывать ошибку &quot;Memory limit exceeded&quot;. Исправляет [#13383](https://github.com/ClickHouse/ClickHouse/issues/13383). [#14889](https://github.com/ClickHouse/ClickHouse/pull/14889) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
