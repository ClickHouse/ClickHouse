<div id="bug-fix">
  #### Bug Fix
</div>

* Бэкпортировано в [#25567](https://github.com/ClickHouse/ClickHouse/issues/25567): Хранилище Kafka теперь поддерживает сообщения в формате parquet. [#23412](https://github.com/ClickHouse/ClickHouse/pull/23412) ([Chao Ma](https://github.com/godliness)).
* Бэкпортировано в [#24554](https://github.com/ClickHouse/ClickHouse/issues/24554): Исправлен сбой сервера, возникавший при вставке данных через HTTP и приводивший к исключению. Исправляет [#23512](https://github.com/ClickHouse/ClickHouse/issues/23512). [#23643](https://github.com/ClickHouse/ClickHouse/pull/23643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#23833](https://github.com/ClickHouse/ClickHouse/issues/23833): Исправлена ошибка `Can't initialize pipeline with empty pipe` для запросов с `GLOBAL IN/JOIN` и `use_hedged_requests`. Исправляет [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431). [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#24703](https://github.com/ClickHouse/ClickHouse/issues/24703): Добавлена поддержка пустых HTTP headers. Исправляет [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901). [#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* Бэкпортировано в [#24702](https://github.com/ClickHouse/ClickHouse/issues/24702): Исправлено удаление партиции при наличии пересекающихся фиктивных частей. В редких случаях могут существовать части с версией мутации, превышающей текущий номер блока. [#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#24725](https://github.com/ClickHouse/ClickHouse/issues/24725): В сообщении "multipart/form-data" символы CRLF, предшествующие разделителю, теперь считаются его частью. Исправляет [#23905](https://github.com/ClickHouse/ClickHouse/issues/23905). [#24399](https://github.com/ClickHouse/ClickHouse/pull/24399) ([Ivan](https://github.com/abyss7)).
* Бэкпортировано в [#24826](https://github.com/ClickHouse/ClickHouse/issues/24826): - Исправлена взаимная блокировка, которая могла возникать при (повторном) сопоставлении ролей LDAP, когда группа LDAP сопоставлялась с несуществующей локальной ролью. [#24431](https://github.com/ClickHouse/ClickHouse/pull/24431) ([Denis Glazachev](https://github.com/traceon)).
* Бэкпортировано в [#25566](https://github.com/ClickHouse/ClickHouse/issues/25566): Исправлена некорректная монотонность функции toWeek. Исправляет [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422) . Ошибка была внесена в https://github.com/ClickHouse/ClickHouse/pull/5212 и впоследствии проявилась благодаря улучшенному механизму отсечения партиций. [#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#24700](https://github.com/ClickHouse/ClickHouse/issues/24700): Исправлено поведение, при котором запрос `SYSTEM RESTART REPLICA` или `SYSTEM SYNC REPLICA` обрабатывался бесконечно. Проблема была обнаружена на сервере с крайне малым объёмом оперативной памяти. [#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#24698](https://github.com/ClickHouse/ClickHouse/issues/24698): Включено чтение подстолбцов для distributed таблиц. [#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
* Исправлена проблема с таймаутом подключения к удалённому JDBC-мосту. Закрывает [#9609](https://github.com/ClickHouse/ClickHouse/issues/9609). [#24588](https://github.com/ClickHouse/ClickHouse/pull/24588) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#24771](https://github.com/ClickHouse/ClickHouse/issues/24771): Исправлена ошибка, которая могла приводить к зависанию клиента ZooKeeper внутри clickhouse-server. [#24721](https://github.com/ClickHouse/ClickHouse/pull/24721) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#24934](https://github.com/ClickHouse/ClickHouse/issues/24934): - Если соединение с ZooKeeper было потеряно и реплика была клонирована после его восстановления, очередь репликации могла содержать устаревшие записи. Исправлено. - Исправлен сбой, возникавший, когда очередь репликации содержала пересекающиеся виртуальные части. Это могло редко происходить при потере части данных. Теперь вместо завершения процесса в лог выводится сообщение об ошибке. [#24777](https://github.com/ClickHouse/ClickHouse/pull/24777) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#24850](https://github.com/ClickHouse/ClickHouse/issues/24850): Исправлена ошибка, при которой исключение `Mutation was killed` могло быть передано клиенту во время ожидания мутации, если мутация ещё не была загружена в память. [#24809](https://github.com/ClickHouse/ClickHouse/pull/24809) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#24917](https://github.com/ClickHouse/ClickHouse/issues/24917): Исправлена крайне редкая ошибка на серверах с малым объёмом памяти, которая могла приводить к невозможности выполнять слияния без перезапуска. Возможно, исправляет [#24603](https://github.com/ClickHouse/ClickHouse/issues/24603). [#24872](https://github.com/ClickHouse/ClickHouse/pull/24872) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#25185](https://github.com/ClickHouse/ClickHouse/issues/25185): Исправлена ошибка при объявлении диска S3 в корне бакета. Ранее выводилась следующая ошибка: ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):. [#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Бэкпортировано в [#24949](https://github.com/ClickHouse/ClickHouse/issues/24949): Исправлено возможное переполнение буфера кучи в Arrow. [#24922](https://github.com/ClickHouse/ClickHouse/pull/24922) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#25562](https://github.com/ClickHouse/ClickHouse/issues/25562): Исправлена крайне редкая ошибка `Tagging already tagged part` в очереди репликации при одновременном выполнении `alter move/replace partition`. Возможно, исправляет [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142). [#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#25367](https://github.com/ClickHouse/ClickHouse/issues/25367): Исправлена сериализация разделённых вложенных сообщений в Protobuf format. Данный PR исправляет [#24647](https://github.com/ClickHouse/ClickHouse/issues/24647). [#25000](https://github.com/ClickHouse/ClickHouse/pull/25000) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#25561](https://github.com/ClickHouse/ClickHouse/issues/25561): Исправлена ошибка, позволявшая создавать таблицы со столбцами, ссылающимися на самих себя, например `a UInt32 ALIAS a + 1` или `b UInt32 MATERIALIZED b`. Closes [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077). [#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar)).
