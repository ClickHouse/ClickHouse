<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#51235](https://github.com/ClickHouse/ClickHouse/issues/51235): Улучшен индикатор прогресса для табличных функций file/s3/hdfs/url: теперь используется размер фрагмента из исходных данных и инкрементальный подсчёт общего размера в каждом потоке. Исправлен индикатор прогресса для функций *Cluster. Закрывает [#47250](https://github.com/ClickHouse/ClickHouse/issues/47250). [#51088](https://github.com/ClickHouse/ClickHouse/pull/51088) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#51255](https://github.com/ClickHouse/ClickHouse/issues/51255): Отключена настройка кэша `do_not_evict_index_and_mark_files` (была включена в `23.5`). [#51222](https://github.com/ClickHouse/ClickHouse/pull/51222) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#51531](https://github.com/ClickHouse/ClickHouse/issues/51531): Большая инструкция `RUN` в Dockerfile разбита на несколько условных блоков меньшего размера. Необходимые инструменты устанавливаются по требованию в том же слое `RUN` и удаляются после использования. Обновление ОС выполняется только один раз в начале. Используется современный способ проверки подписанного репозитория. Базовый образ понижен до ubuntu:20.04 для устранения проблем со старыми версиями Docker. Обновлена версия golang для устранения уязвимостей. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#51572](https://github.com/ClickHouse/ClickHouse/issues/51572): Дополнение к [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504) — очистка была потеряна в процессе рефакторинга. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Query Cache: Исправлено некорректное приведение типа из ColumnConst в ColumnVector<char8_t> [#50704](https://github.com/ClickHouse/ClickHouse/pull/50704) ([Robert Schulze](https://github.com/rschu1ze)).
* Исправлен тип хэша параметров LDAP-сервера в записи кэша [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* В формате Parquet вместо выброса исключения теперь выполняется разбор большого целого числа из строки [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* PROJECTION не применяется, если включено чтение в порядке сортировки. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Исправлено состояние гонки в итераторе Azure Blob Storage [#50936](https://github.com/ClickHouse/ClickHouse/pull/50936) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* Исправлена неэффективная работа кэша запросов для SELECT с подзапросами [#51132](https://github.com/ClickHouse/ClickHouse/pull/51132) ([Robert Schulze](https://github.com/rschu1ze)).
* Исправлен сбой фаззера в ActionsDAG [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
