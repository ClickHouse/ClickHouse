<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Исправлена проверка недетерминированных функций в выражениях TTL. Ранее в некоторых случаях можно было создать выражение TTL с недетерминированными функциями, что впоследствии могло приводить к неопределённому поведению. Это исправляет [#37250](https://github.com/ClickHouse/ClickHouse/issues/37250). По умолчанию теперь запрещены выражения TTL, которые не зависят ни от одного столбца таблицы. Это ограничение можно снова снять с помощью `SET allow_suspicious_ttl_expressions = 1` или `SET compatibility = '23.11'`. Закрывает [#37286](https://github.com/ClickHouse/ClickHouse/issues/37286). [#51858](https://github.com/ClickHouse/ClickHouse/pull/51858) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Функция `arrayFold` удалена из-за ошибки. Это закрывает [#57816](https://github.com/ClickHouse/ClickHouse/issues/57816). Это закрывает [#57458](https://github.com/ClickHouse/ClickHouse/issues/57458). [#57836](https://github.com/ClickHouse/ClickHouse/pull/57836) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Удалена возможность использовать строку `is_deleted` в ReplacingMergeTree, а также модификатор `CLEANUP` для запроса OPTIMIZE. Это исправляет [#57930](https://github.com/ClickHouse/ClickHouse/issues/57930). Это закрывает [#54988](https://github.com/ClickHouse/ClickHouse/issues/54988). Это закрывает [#54570](https://github.com/ClickHouse/ClickHouse/issues/54570). Это закрывает [#50346](https://github.com/ClickHouse/ClickHouse/issues/50346). Это закрывает [#47579](https://github.com/ClickHouse/ClickHouse/issues/47579). Эту возможность необходимо удалить, поскольку она неудачна. Её нужно убрать как можно скорее, поскольку другого варианта нет. [#57932](https://github.com/ClickHouse/ClickHouse/pull/57932) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Настройка MergeTree `clean_deleted_rows` устарела и больше не оказывает никакого эффекта. Ключевое слово `CLEANUP` для `OPTIMIZE` по умолчанию запрещено (если только не включён `allow_experimental_replacing_merge_with_cleanup`). [#58267](https://github.com/ClickHouse/ClickHouse/pull/58267) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="new-feature">
  #### Новая возможность
</div>

* Разрешено отключать запрос HEAD перед запросом GET. [#54602](https://github.com/ClickHouse/ClickHouse/pull/54602) ([Fionera](https://github.com/fionera)).
* Добавлена HTTP-конечная точка для проверки готовности Keeper к приёму трафика. [#55876](https://github.com/ClickHouse/ClickHouse/pull/55876) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Добавлен режим &#39;union&#39; для schema inference. В этом режиме итоговая схема таблицы представляет собой объединение схем всех файлов (то есть схема определяется для каждого файла). Режим schema inference управляется настройкой `schema_inference_mode` с 2 возможными значениями — `default` и `union`. Закрывает [#55428](https://github.com/ClickHouse/ClickHouse/issues/55428). [#55892](https://github.com/ClickHouse/ClickHouse/pull/55892) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлена новая настройка `input_format_csv_try_infer_numbers_from_strings`, которая позволяет определять числа из строк в формате CSV. Закрывает [#56455](https://github.com/ClickHouse/ClickHouse/issues/56455). [#56859](https://github.com/ClickHouse/ClickHouse/pull/56859) ([Kruglov Pavel](https://github.com/Avogar)).
* Refreshable materialized views. [#56946](https://github.com/ClickHouse/ClickHouse/pull/56946) ([Michael Kolupaev](https://github.com/al13n321)).
* Добавлено больше предупреждений о количестве баз данных и таблиц. [#57375](https://github.com/ClickHouse/ClickHouse/pull/57375) ([凌涛](https://github.com/lingtaolf)).
* Добавлена новая команда mutation `ALTER TABLE <table> APPLY DELETED MASK`, которая позволяет принудительно применить маску, записанную при легковесном удалении, и удалить с диска строки, помеченные как удалённые. [#57433](https://github.com/ClickHouse/ClickHouse/pull/57433) ([Anton Popov](https://github.com/CurtizJ)).
* Добавлена новая SQL-функция `sqid` для генерации Sqids ([https://sqids.org/](https://sqids.org/)), пример: `SELECT sqid(125, 126)`. [#57512](https://github.com/ClickHouse/ClickHouse/pull/57512) ([Robert Schulze](https://github.com/rschu1ze)).
* Словарь со структурой `HASHED_ARRAY` (и `COMPLEX_KEY_HASHED_ARRAY`) поддерживает `SHARDS` аналогично `HASHED`. [#57544](https://github.com/ClickHouse/ClickHouse/pull/57544) ([vdimir](https://github.com/vdimir)).
* Добавлены асинхронные метрики для общего количества байт первичного ключа и общего количества байт первичного ключа, выделенных в памяти. [#57551](https://github.com/ClickHouse/ClickHouse/pull/57551) ([Bharat Nallan](https://github.com/bharatnc)).
* Таблица system.dropped&#95;tables&#95;parts содержит части таблиц из system.dropped&#95;tables (удалённых, но ещё не убранных таблиц). [#57555](https://github.com/ClickHouse/ClickHouse/pull/57555) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Добавлен `FORMAT_BYTES` как alias для `formatReadableSize`. [#57592](https://github.com/ClickHouse/ClickHouse/pull/57592) ([Bharat Nallan](https://github.com/bharatnc)).
* Добавлена функция SHA512&#95;256. [#57645](https://github.com/ClickHouse/ClickHouse/pull/57645) ([Bharat Nallan](https://github.com/bharatnc)).
* Разрешена передача необязательного SESSION&#95;TOKEN в табличную функцию `s3`. [#57850](https://github.com/ClickHouse/ClickHouse/pull/57850) ([Shani Elharrar](https://github.com/shanielh)).
* Предложение `ORDER BY` теперь поддерживает указание `ALL`, что означает, что ClickHouse сортирует по всем столбцам в предложении `SELECT`. Пример: `SELECT col1, col2 FROM tab WHERE [...] ORDER BY ALL`. [#57875](https://github.com/ClickHouse/ClickHouse/pull/57875) ([zhongyuankai](https://github.com/zhongyuankai)).
* Добавлены функции кодирования и декодирования punycode: `punycodeEncode()` и `punycodeDecode()`. [#57969](https://github.com/ClickHouse/ClickHouse/pull/57969) ([Robert Schulze](https://github.com/rschu1ze)).
* В этом PR реализован `PASTE JOIN`, который позволяет пользователям выполнять JOIN таблиц без условия `ON`. Пример: &#96;&#96;&#96; SQL SELECT * FROM ( SELECT number AS a FROM numbers(2) ) AS t1 PASTE JOIN ( SELECT number AS a FROM numbers(2) ORDER BY a DESC ) AS t2. [#57995](https://github.com/ClickHouse/ClickHouse/pull/57995) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Обработчик `/binary` открывает визуальный просмотрщик символов внутри бинарного файла ClickHouse. [#58211](https://github.com/ClickHouse/ClickHouse/pull/58211) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Копирование между S3-дисками переведено на server-side copy в S3 вместо копирования через буфер. Это ускоряет операции `BACKUP/RESTORE` и команду `clickhouse-disks copy`. [#56744](https://github.com/ClickHouse/ClickHouse/pull/56744) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* HashJoin теперь учитывает настройку `max_joined_block_size_rows` и не создаёт большие блоки для `ALL JOIN`. [#56996](https://github.com/ClickHouse/ClickHouse/pull/56996) ([vdimir](https://github.com/vdimir)).
* Память, используемая для агрегации, теперь освобождается раньше. Это может помочь избежать ненужной внешней агрегации. [#57691](https://github.com/ClickHouse/ClickHouse/pull/57691) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Улучшена производительность сериализации строк. [#57717](https://github.com/ClickHouse/ClickHouse/pull/57717) ([Maksim Kita](https://github.com/kitaisreal)).
* Добавлена поддержка тривиальной оптимизации count для таблиц с движком `Merge`. [#57867](https://github.com/ClickHouse/ClickHouse/pull/57867) ([skyoct](https://github.com/skyoct)).
* В некоторых случаях оптимизирована агрегация. [#57872](https://github.com/ClickHouse/ClickHouse/pull/57872) ([Anton Popov](https://github.com/CurtizJ)).
* Функция `hasAny()` теперь может использовать полнотекстовые skipping-индексы. [#57878](https://github.com/ClickHouse/ClickHouse/pull/57878) ([Jpnock](https://github.com/Jpnock)).
* Функция `if(cond, then, else)` (и её псевдоним `cond ? : then : else`) были оптимизированы для использования безветвленного вычисления. [#57885](https://github.com/ClickHouse/ClickHouse/pull/57885) ([zhanglistar](https://github.com/zhanglistar)).
* Во время обработки FINAL из таблицы семейства MergeTree выделяются диапазоны непересекающихся частей. Это позволяет избежать дополнительной логики FINAL для таких диапазонов. В случаях, когда количество дублирующихся значений с одним и тем же первичным ключом невелико, производительность будет почти такой же, как и без FINAL. Улучшена производительность чтения для MergeTree FINAL, когда установлена настройка `do_not_merge_across_partitions_select_final`. [#58120](https://github.com/ClickHouse/ClickHouse/pull/58120) ([Maksim Kita](https://github.com/kitaisreal)).
* MergeTree теперь автоматически определяет значение настройки `do_not_merge_across_partitions_select_final`, если выражение ключа партиционирования содержит только столбцы из выражения первичного ключа. [#58218](https://github.com/ClickHouse/ClickHouse/pull/58218) ([Maksim Kita](https://github.com/kitaisreal)).
* Ускорены MIN и MAX для native-типов. [#58231](https://github.com/ClickHouse/ClickHouse/pull/58231) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### Улучшения
</div>

* Исправлена обработка обновлённой конфигурации cluster при вставках в distributed таблицы. Когда список node в cluster динамически обновляется, Directory Monitor distributed таблицы не обнаруживает новый node, и для этого его нужно переназначить на новый node. [#42826](https://github.com/ClickHouse/ClickHouse/pull/42826) ([zhongyuankai](https://github.com/zhongyuankai)).
* Опция `--no-system-tables` заменена на ленивую загрузку виртуальных table системной database. [#55271](https://github.com/ClickHouse/ClickHouse/pull/55271) ([Azat Khuzhin](https://github.com/azat)).
* Clickhouse-test теперь выводит sn case, текущее время и имя case в рамках одного test case. [#55710](https://github.com/ClickHouse/ClickHouse/pull/55710) ([guoxiaolong](https://github.com/guoxiaolongzte)).
* Запрещено создавать replicated table с несогласованными параметрами merge. [#56833](https://github.com/ClickHouse/ClickHouse/pull/56833) ([Duc Canh Le](https://github.com/canhld94)).
* Реализована cache policy SLRU для файлового кэша. [#57076](https://github.com/ClickHouse/ClickHouse/pull/57076) ([Kseniia Sumarokova](https://github.com/kssenii)).
* В `system.tables` теперь показывается uncompressed size, полученный из checksums data parts [#56618](https://github.com/ClickHouse/ClickHouse/issues/56618). [#57186](https://github.com/ClickHouse/ClickHouse/pull/57186) ([Chen Lixiang](https://github.com/chenlx0)).
* Добавлен `skip_unavailable_shards` как setting для `Distributed` tables, аналогичный соответствующей setting на уровне запроса. Закрывает [#43666](https://github.com/ClickHouse/ClickHouse/issues/43666). [#57218](https://github.com/ClickHouse/ClickHouse/pull/57218) ([Gagan Goel](https://github.com/tntnatbry)).
* Function `substring()` (псевдонимы: `substr`, `mid`) теперь можно использовать с типами `Enum`. Ранее первый argument function должен был иметь тип `String` или `FixedString`. Это улучшает совместимость со сторонними инструментами, такими как Tableau, через MySQL interface. [#57277](https://github.com/ClickHouse/ClickHouse/pull/57277) ([Serge Klochkov](https://github.com/slvrtrn)).
* Улучшены подсказки в случаях, когда table не существует. [#57342](https://github.com/ClickHouse/ClickHouse/pull/57342) ([Bharat Nallan](https://github.com/bharatnc)).
* Разрешено переопределять настройки сервера `max_partition_size_to_drop` и `max_table_size_to_drop` во время выполнения запроса. [#57452](https://github.com/ClickHouse/ClickHouse/pull/57452) ([Jordi Villar](https://github.com/jrdi)).
* Добавлена поддержка флага только для чтения при connection к server ZooKeeper (исправляет [#53749](https://github.com/ClickHouse/ClickHouse/issues/53749)). [#57479](https://github.com/ClickHouse/ClickHouse/pull/57479) ([Mikhail Koviazin](https://github.com/mkmkme)).
* Исправлена возможная блокировка distributed-отправок из-за &quot;No such file or directory&quot; (при восстановлении batch с диска). Исправлены возможные проблемы с `error_count` из `system.distribution_queue` (если `distributed_directory_monitor_max_sleep_time_ms` &gt; 5min). Добавлено profile event для отслеживания ошибок асинхронных INSERT — `DistributedAsyncInsertionFailures`. [#57480](https://github.com/ClickHouse/ClickHouse/pull/57480) ([Azat Khuzhin](https://github.com/azat)).
* Лимит на количество connections на одну конечную точку для background fetches увеличен с `15` до значения setting `background_fetches_pool_size`. - setting уровня MergeTree `replicated_max_parallel_fetches_for_host` стала устаревшей - settings уровня MergeTree `replicated_fetches_http_connection_timeout`, `replicated_fetches_http_send_timeout` и `replicated_fetches_http_receive_timeout` перенесены на уровень server. - setting `keep_alive_timeout` добавлена в список settings уровня server. [#57523](https://github.com/ClickHouse/ClickHouse/pull/57523) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Теперь в определениях индексов (не первичного ключа) можно ссылаться на ALIAS-столбец (issue [#55650](https://github.com/ClickHouse/ClickHouse/issues/55650)). Пример: `CREATE TABLE tab(col UInt32, col_alias ALIAS col + 1, INDEX idx (col_alias) TYPE minmax) ENGINE = MergeTree ORDER BY col;`. [#57546](https://github.com/ClickHouse/ClickHouse/pull/57546) ([Robert Schulze](https://github.com/rschu1ze)).
* Функция `format()` теперь поддерживает произвольные типы аргументов (а не только аргументы `String` и `FixedString`). Это важно, например, для вычисления `SELECT format('The {0} to all questions is {1}', 'answer', 42)`. [#57549](https://github.com/ClickHouse/ClickHouse/pull/57549) ([Robert Schulze](https://github.com/rschu1ze)).
* Добавлена поддержка вычисляемых столбцов PostgreSQL и значений столбцов по умолчанию в `MaterializedPostgreSQL`. Закрывает [#40449](https://github.com/ClickHouse/ClickHouse/issues/40449). [#57568](https://github.com/ClickHouse/ClickHouse/pull/57568) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Разрешено применять некоторые изменения настроек конфигурации файлового кэша без перезапуска сервера. [#57578](https://github.com/ClickHouse/ClickHouse/pull/57578) ([Kseniia Sumarokova](https://github.com/kssenii)).

* Теперь функцию `date_trunc()` можно использовать с первым аргументом независимо от регистра. Поддерживаются оба варианта: `SELECT date_trunc('day', now())` и `SELECT date_trunc('DAY', now())`. [#57624](https://github.com/ClickHouse/ClickHouse/pull/57624) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Общее число ошибок, произошедших с момента последнего запуска сервера, теперь доступно как метрика `ClickHouseErrorMetric_ALL`. [#57627](https://github.com/ClickHouse/ClickHouse/pull/57627) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Разрешены узлы в конфигурации с from&#95;env/from&#95;zk и непустым элементом с replace=1. [#57628](https://github.com/ClickHouse/ClickHouse/pull/57628) ([Azat Khuzhin](https://github.com/azat)).
* Генерируется некорректный вывод, который невозможно разобрать как JSON. [#57646](https://github.com/ClickHouse/ClickHouse/pull/57646) ([Julia Kartseva](https://github.com/jkartseva)).
* При выборе частей для слияния теперь учитываются строки, помеченные легковесным удалением, если оно включено. [#57648](https://github.com/ClickHouse/ClickHouse/pull/57648) ([Zhuo Qiu](https://github.com/jewelzqiu)).
* Выполнение запросов к system.filesystem&#95;cache больше не требует большого объема памяти. [#57687](https://github.com/ClickHouse/ClickHouse/pull/57687) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Разрешено преобразование IPv6 в UInt128 и выполнение двоичной арифметики. [#57707](https://github.com/ClickHouse/ClickHouse/pull/57707) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Поддерживаются отрицательные позиционные аргументы. Закрывает [#57736](https://github.com/ClickHouse/ClickHouse/issues/57736). [#57741](https://github.com/ClickHouse/ClickHouse/pull/57741) ([flynn](https://github.com/ucasfl)).
