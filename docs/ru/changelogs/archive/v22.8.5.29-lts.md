<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#40817](https://github.com/ClickHouse/ClickHouse/issues/40817): параметр `show_addresses_in_stack_traces` был по ошибке отключен в стандартном `config.xml`. Теперь он удалён из конфигурации, поэтому по умолчанию параметр включён. [#40749](https://github.com/ClickHouse/ClickHouse/pull/40749) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#40944](https://github.com/ClickHouse/ClickHouse/issues/40944): исправлена проблема с передачей тайм-аутов MySQL для движка базы данных MySQL и табличной функции MySQL. Закрывает [#34168](https://github.com/ClickHouse/ClickHouse/issues/34168)?notification&#95;referrer&#95;id=NT&#95;kwDOAzsV57MzMDMxNjAzNTY5OjU0MjAzODc5. [#40751](https://github.com/ClickHouse/ClickHouse/pull/40751) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Исправление ошибки (заметное пользователю некорректное поведение в официальном стабильном релизе)
</div>

* Бэкпортировано в [#40866](https://github.com/ClickHouse/ClickHouse/issues/40866): - Исправлено аварийное завершение при разборе значений типа `Object`, содержащего массивы переменной размерности. [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* Бэкпортировано в [#40805](https://github.com/ClickHouse/ClickHouse/issues/40805): Во время вставки нового запроса в `ProcessList` происходят выделения памяти. Если в ходе этих выделений достигается лимит памяти, мы не можем использовать `OvercommitTracker`, потому что `ProcessList::mutex` уже захвачен. Исправляет [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611). [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#40777](https://github.com/ClickHouse/ClickHouse/issues/40777): Исправлена утечка памяти при записи в MV без контекста запроса (из Kafka/...). [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#41135](https://github.com/ClickHouse/ClickHouse/issues/41135): Исправлены права доступа для `DESCRIBE TABLE url()` и некоторых других `DESCRIBE TABLE <table_function>()`. [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#41242](https://github.com/ClickHouse/ClickHouse/issues/41242): Исправлена ошибка &quot;possible deadlock avoided&quot; при автоматическом преобразовании движка базы данных из Ordinary в Atomic. [#41146](https://github.com/ClickHouse/ClickHouse/pull/41146) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#41234](https://github.com/ClickHouse/ClickHouse/issues/41234): Исправлена фоновая очистка повреждённых отсоединённых частей. [#41190](https://github.com/ClickHouse/ClickHouse/pull/41190) ([Kseniia Sumarokova](https://github.com/kssenii)).
