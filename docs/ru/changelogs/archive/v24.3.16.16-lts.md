  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)

* Бэкпортировано в [#74802](https://github.com/ClickHouse/ClickHouse/issues/74802): Исправлена проблема безопасности, предотвращающая SQL-инъекции в табличных функциях postgresql и sqlite. [#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#74866](https://github.com/ClickHouse/ClickHouse/issues/74866): Исправление в Keeper: исправлено чтение записей журнала с диска. [#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#75283](https://github.com/ClickHouse/ClickHouse/issues/75283): Улучшены ещё более строгие настройки по умолчанию. Текущие значения по умолчанию уже безопасны — чтобы явно опубликовать порты, пользователь должен указать соответствующий параметр. Но если для пользователя `default` не задан пароль через переменную окружения `CLICKHOUSE_PASSWORD` и/или не изменено имя пользователя через переменную окружения `CLICKHOUSE_USER`, он должен быть доступен только с локальной системы в качестве дополнительного уровня защиты. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
