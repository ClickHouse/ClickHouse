<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Теперь снимки ClickHouse Keeper по умолчанию сжимаются кодеком `ZSTD`, а не с помощью пользовательского блочного сжатия LZ4 в ClickHouse. Это поведение можно отключить настройкой coordination `compress_snapshots_with_zstd_format` (она должна быть одинаковой на всех репликах quorum). Обратная несовместимость возникает довольно редко и возможна только в случае, когда новый узел отправляет снимок (это происходит при recovery) старому узлу, который не умеет читать снимки в формате ZSTD. [#29417](https://github.com/ClickHouse/ClickHouse/pull/29417) ([alesapin](https://github.com/alesapin)).
* Функция `bayesAB` удалена. Это закрывает [#26233](https://github.com/ClickHouse/ClickHouse/issues/26233). [#29934](https://github.com/ClickHouse/ClickHouse/pull/29934) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Удалена настройка таблицы семейства MergeTree `write_final_mark`. Теперь она всегда будет иметь значение `true`. [#30455](https://github.com/ClickHouse/ClickHouse/pull/30455) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Изменён порядок `json_path` и `json` в SQL-функции JSON (для корректности). Закрывает [#30449](https://github.com/ClickHouse/ClickHouse/issues/30449). [#30474](https://github.com/ClickHouse/ClickHouse/pull/30474) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Удалена настройка `odbc_max_field_size`, поскольку она больше не используется. Закрывает [#30413](https://github.com/ClickHouse/ClickHouse/issues/30413). [#30778](https://github.com/ClickHouse/ClickHouse/pull/30778) ([Kseniia Sumarokova](https://github.com/kssenii)).
