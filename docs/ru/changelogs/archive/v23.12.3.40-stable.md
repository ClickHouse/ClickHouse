<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#58660](https://github.com/ClickHouse/ClickHouse/issues/58660): При выполнении некоторых запросов, которым для чтения данных требуется большое число потоков, ранее возникала ошибка `"Paste JOIN requires sorted tables only"`. Теперь в таком случае число потоков уменьшается до 1. [#58608](https://github.com/ClickHouse/ClickHouse/pull/58608) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Бэкпортировано в [#58817](https://github.com/ClickHouse/ClickHouse/issues/58817): Добавлен `SYSTEM JEMALLOC PURGE` для очистки неиспользуемых страниц jemalloc, а также `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` для управления профилем jemalloc, если включен профилировщик. В Keeper добавлена связанная с jemalloc команда 4LW: `jmst` для дампа статистики jemalloc, а также `jmfp`, `jmep`, `jmdp` для управления профилем jemalloc, если включен профилировщик. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#59235](https://github.com/ClickHouse/ClickHouse/issues/59235): Добавлена возможность игнорировать изменение схемы в движке таблицы Iceberg и читать все данные, используя схему, заданную пользователем при создании таблицы, либо последнюю схему, разобранную из метаданных на момент создания таблицы. Это делается с помощью настройки `iceberg_engine_ignore_schema_evolution`, которая по умолчанию отключена. Обратите внимание, что включение этой настройки может привести к некорректным результатам, поскольку при изменении схемы все файлы данных будут читаться с использованием одной и той же схемы. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
