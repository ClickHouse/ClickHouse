<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#26854](https://github.com/ClickHouse/ClickHouse/issues/26854): ParallelFormattingOutputFormat: использование мьютекса для join с collector&#95;thread ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)). [#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#26938](https://github.com/ClickHouse/ClickHouse/issues/26938): данные больше не удаляются при остановке таблицы ReplicatedMergeTree, чтобы избежать рассогласования данных и метаданных. [#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* Бэкпортировано в [#26986](https://github.com/ClickHouse/ClickHouse/issues/26986): параметры aggregate function могли теряться при применении некоторых комбинаторов, вызывая исключения вида `Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported`. Это исправлено. Исправляет [#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) и [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433). [#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#26944](https://github.com/ClickHouse/ClickHouse/issues/26944): исправлена ошибка `Missing columns: 'xxx'`, возникавшая, когда столбец `DEFAULT` ссылался на другой нематериализованный столбец без выражения `DEFAULT`. Исправляет [#26591](https://github.com/ClickHouse/ClickHouse/issues/26591). [#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#26999](https://github.com/ClickHouse/ClickHouse/issues/26999): исправлено чтение пользовательских TLDs (обработка останавливалась при меньшем buffer или большем file). [#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#27029](https://github.com/ClickHouse/ClickHouse/issues/27029): теперь partition ID в запросах вида `ALTER TABLE ... PARTITION ID xxx` проверяется на корректность. Исправляет [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718). [#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#27050](https://github.com/ClickHouse/ClickHouse/issues/27050): [RFC] исправлен возможный стек мутаций из-за race condition с DROP&#95;RANGE. [#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#27105](https://github.com/ClickHouse/ClickHouse/issues/27105): исправлен разбор конфигурации `cache`, `complex_key_cache`, `ssd_cache`, `complex_key_ssd_cache`. Параметры `allow_read_expired_keys`, `max_update_queue_size`, `update_queue_push_timeout_milliseconds`, `query_wait_timeout_milliseconds` не разбирались для словарей с типом, отличным от `cache`. [#27032](https://github.com/ClickHouse/ClickHouse/pull/27032) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#27156](https://github.com/ClickHouse/ClickHouse/issues/27156): исправлена синхронизация в GRPCServer. Этот PR исправляет [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024). [#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#27261](https://github.com/ClickHouse/ClickHouse/issues/27261): в редких случаях таблица `system.detached_parts` могла содержать некорректную информацию о некоторых частях; это исправлено. Исправляет [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114). [#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
