<div id="improvement">
  #### Улучшения
</div>

* Бэкпорт в [#57668](https://github.com/ClickHouse/ClickHouse/issues/57668): Корректный вывод JSON/XML при возникновении исключения во время выполнения HTTP-запроса. Добавлена настройка `http_write_exception_in_output_format` для включения/отключения этого поведения (включена по умолчанию). [#52853](https://github.com/ClickHouse/ClickHouse/pull/52853) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпорт в [#58491](https://github.com/ClickHouse/ClickHouse/issues/58491): Исправлено преобразование запроса в запрос, совместимый с MySQL. Исправляет [#57253](https://github.com/ClickHouse/ClickHouse/issues/57253). Исправляет [#52654](https://github.com/ClickHouse/ClickHouse/issues/52654). Исправляет [#56729](https://github.com/ClickHouse/ClickHouse/issues/56729). [#56456](https://github.com/ClickHouse/ClickHouse/pull/56456) ([flynn](https://github.com/ucasfl)).
* Бэкпорт в [#57238](https://github.com/ClickHouse/ClickHouse/issues/57238): При получении части выполняется ожидание, пока эта часть не будет полностью зафиксирована на удалённой реплике. Лучше не отправлять часть в состоянии PreActive. В случае zero copy это обязательное ограничение. [#56808](https://github.com/ClickHouse/ClickHouse/pull/56808) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпорт в [#57655](https://github.com/ClickHouse/ClickHouse/issues/57655): Обработан случай SIGABRT при получении структуры таблицы PostgreSQL с пустым массивом. [#57618](https://github.com/ClickHouse/ClickHouse/pull/57618) ([Mikhail Kot](https://github.com/myrrc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#58324](https://github.com/ClickHouse/ClickHouse/issues/58324): Разворачивается только настоящий тип Nested, если flatten&#95;nested=1, а не все Array(Tuple). [#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#57395](https://github.com/ClickHouse/ClickHouse/issues/57395): Исправлен ALTER COLUMN с ALIAS, который ранее приводил к исключению `NO_SUCH_COLUMN_IN_TABLE`. Закрывает [#50927](https://github.com/ClickHouse/ClickHouse/issues/50927). [#56493](https://github.com/ClickHouse/ClickHouse/pull/56493) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#57449](https://github.com/ClickHouse/ClickHouse/issues/57449): Теперь ALTER столбцов, несовместимых со столбцами, используемыми в некоторых проекциях, запрещён. Ранее это могло приводить к некорректным данным. Это исправляет [#56932](https://github.com/ClickHouse/ClickHouse/issues/56932). Этот PR также разрешает RENAME столбцов индекса и улучшает текст исключения, добавляя понятную информацию о затронутых индексах или проекциях, из-за которых операция была запрещена. [#56948](https://github.com/ClickHouse/ClickHouse/pull/56948) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#57281](https://github.com/ClickHouse/ClickHouse/issues/57281): Исправлен segfault после ALTER UPDATE с Nullable MATERIALIZED столбцом. Закрывает [#42918](https://github.com/ClickHouse/ClickHouse/issues/42918). [#57147](https://github.com/ClickHouse/ClickHouse/pull/57147) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#57247](https://github.com/ClickHouse/ClickHouse/issues/57247): Исправлена некорректная оптимизация плана JOIN с частично материализованной обычной проекцией. Это исправляет [#57194](https://github.com/ClickHouse/ClickHouse/issues/57194). [#57196](https://github.com/ClickHouse/ClickHouse/pull/57196) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#57346](https://github.com/ClickHouse/ClickHouse/issues/57346): Исправлена метрика `ReadonlyReplica` для некоторых случаев (например, когда таблица не может быть инициализирована из-за разности между локальными данными и данными Keeper). [#57267](https://github.com/ClickHouse/ClickHouse/pull/57267) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#58434](https://github.com/ClickHouse/ClickHouse/issues/58434): Исправлена работа с буферами чтения в StreamingFormatExecutor; ранее это могло приводить к segfault в Kafka и других потоковых движках. [#57438](https://github.com/ClickHouse/ClickHouse/pull/57438) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#57539](https://github.com/ClickHouse/ClickHouse/issues/57539): Исправлен парсинг `SYSTEM STOP LISTEN TCP SECURE`. [#57483](https://github.com/ClickHouse/ClickHouse/pull/57483) ([joelynch](https://github.com/joelynch)).
* Бэкпортировано в [#57779](https://github.com/ClickHouse/ClickHouse/issues/57779): Конфигурация `<user_directories> <replicated> <zookeeper_path>/clickhouse/access/</zookeeper_path> </replicated> </user_directories>` sql &#96;&#96;&#96; show settings like &#39;ignore&#95;on&#95;cluster&#95;for&#95;replicated&#95;access&#95;entities&#95;queries&#39; ┌─name─────────────────────────────────────────────────────┬─type─┬─value─┐ │ ignore&#95;on&#95;cluster&#95;for&#95;replicated&#95;access&#95;entities&#95;queries │ bool │ 1 │ └──────────────────────────────────────────────────────────┴──────┴───────┘. [#57538](https://github.com/ClickHouse/ClickHouse/pull/57538) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Бэкпортировано в [#58256](https://github.com/ClickHouse/ClickHouse/issues/58256): system.kafka&#95;consumers теперь по умолчанию отключена (из-за возможной утечки памяти во время работы). [#57822](https://github.com/ClickHouse/ClickHouse/pull/57822) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#57923](https://github.com/ClickHouse/ClickHouse/issues/57923): Исправлен некорректный доступ к памяти в BLAKE3. [#57876](https://github.com/ClickHouse/ClickHouse/pull/57876) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#58084](https://github.com/ClickHouse/ClickHouse/issues/58084): Нормализованы имена функций в запросе `CREATE INDEX`. Позволяет избежать ошибок `Existing table metadata in ZooKeeper differs in skip indexes`, если при создании индекса использовался alias вместо канонического имени функции. [#57906](https://github.com/ClickHouse/ClickHouse/pull/57906) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#58110](https://github.com/ClickHouse/ClickHouse/issues/58110): Исправление в Keeper: лидер должен корректно завершать обработку запроса с ошибкой на этапе предварительной обработки, если он не инициализирован. [#58069](https://github.com/ClickHouse/ClickHouse/pull/58069) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#58155](https://github.com/ClickHouse/ClickHouse/issues/58155): Исправлено целочисленное переполнение в Poco::UTF32Encoding. [#58073](https://github.com/ClickHouse/ClickHouse/pull/58073) ([Andrey Fedotov](https://github.com/anfedotoff)).
* Бэкпортировано в [#58188](https://github.com/ClickHouse/ClickHouse/issues/58188): Параллельный парсинг для `JSONCompactEachRow` в предыдущих версиях мог работать некорректно. Это закрывает [#58180](https://github.com/ClickHouse/ClickHouse/issues/58180). [#58181](https://github.com/ClickHouse/ClickHouse/pull/58181) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#58301](https://github.com/ClickHouse/ClickHouse/issues/58301): Исправлен параллельный парсинг для JSONCompactEachRow. [#58250](https://github.com/ClickHouse/ClickHouse/pull/58250) ([Kruglov Pavel](https://github.com/Avogar)).
