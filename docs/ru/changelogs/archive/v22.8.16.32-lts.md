  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#48344](https://github.com/ClickHouse/ClickHouse/issues/48344): Использование sccache вместо ccache и S3 в качестве бэкенда для кэша. [#46240](https://github.com/ClickHouse/ClickHouse/pull/46240) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#48250](https://github.com/ClickHouse/ClickHouse/issues/48250): Образ `clickhouse/clickhouse-keeper` раньше публиковался только с тегами `-alpine`, например `latest-alpine`. Как было предложено в [https://github.com/ClickHouse/examples/pull/2](https://github.com/ClickHouse/examples/pull/2), теперь он также будет публиковаться и без суффикса. [#48236](https://github.com/ClickHouse/ClickHouse/pull/48236) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
