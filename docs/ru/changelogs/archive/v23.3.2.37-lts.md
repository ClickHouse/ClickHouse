<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#48459](https://github.com/ClickHouse/ClickHouse/issues/48459): форматтер &#39;%M&#39; в функции formatDateTime() теперь выводит название месяца вместо минут. Это приводит поведение в соответствие с MySQL. Предыдущее поведение можно восстановить с помощью настройки &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot;. [#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#48842](https://github.com/ClickHouse/ClickHouse/issues/48842): исправлена обработка некоторых настроек, связанных с MySQL, при использовании mysql словарь source + named collection. Закрывает [#48402](https://github.com/ClickHouse/ClickHouse/issues/48402). [#48759](https://github.com/ClickHouse/ClickHouse/pull/48759) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#49035](https://github.com/ClickHouse/ClickHouse/issues/49035): добавлен fallback на аутентификацию по паролю, если аутентификация с SSL-сертификатом пользователя завершилась неудачей. Закрывает [#48974](https://github.com/ClickHouse/ClickHouse/issues/48974). [#48989](https://github.com/ClickHouse/ClickHouse/pull/48989) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#48589](https://github.com/ClickHouse/ClickHouse/issues/48589): Обновлены часовые пояса. Обновлены следующие значения: Africa/Cairo, Africa/Casablanca, Africa/El&#95;Aaiun, America/Bogota, America/Cambridge&#95;Bay, America/Ciudad&#95;Juarez, America/Godthab, America/Inuvik, America/Iqaluit, America/Nuuk, America/Ojinaga, America/Pangnirtung, America/Rankin&#95;Inlet, America/Resolute, America/Whitehorse, America/Yellowknife, Asia/Gaza, Asia/Hebron, Asia/Kuala&#95;Lumpur, Asia/Singapore, Canada/Yukon, Egypt, Europe/Kirov, Europe/Volgograd, Singapore. [#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#48960](https://github.com/ClickHouse/ClickHouse/issues/48960): После недавнего обновления `dockerd` требует явного указания `--tlsverify=false` вместе с HTTP-портом. [#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Удалена возможность [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлено использование CPU в RabbitMQ (ухудшилось в 23.2 после [#44404](https://github.com/ClickHouse/ClickHouse/issues/44404)) [#48311](https://github.com/ClickHouse/ClickHouse/pull/48311) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Исправлен ThreadPool для DistributedSink, а также использован StrongTypedef для CurrentMetrics/ProfileEvents/StatusInfo, чтобы избежать дальнейших ошибок [#48314](https://github.com/ClickHouse/ClickHouse/pull/48314) ([Azat Khuzhin](https://github.com/azat)).
* Сброшен загрузчик для сегмента файла кэша в TemporaryFileStream [#48386](https://github.com/ClickHouse/ClickHouse/pull/48386) ([Vladimir C](https://github.com/vdimir)).
* Ошибка запуска ClickHouse при загрузке distributed таблицы, зависящей от словаря [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Исправлен возможный segfault в кэше [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Исправлена nested map для ключей типов IP и UUID [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Исправлена ошибка в Keeper, из-за которой узел иногда не создавался со схемой `auth` в ACL. [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Исправлено сравнение IPv4 с UInt [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
