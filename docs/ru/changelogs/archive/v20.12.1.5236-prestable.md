<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* При создании таблицы с движком `File` теперь принимаются пользовательские настройки, связанные с форматами файлов (например, `format_csv_delimiter`), в секции `SETTINGS`, и эти настройки используются во всех `INSERT` и `SELECT`. Настройки формата файлов, изменённые в текущем сеансе пользователя или в секции `SETTINGS` самого DML-запроса, больше не влияют на запрос. [#16591](https://github.com/ClickHouse/ClickHouse/pull/16591) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* По умолчанию включена настройка `use_compact_format_in_distributed_parts_names` (подробности см. в документации). [#16728](https://github.com/ClickHouse/ClickHouse/pull/16728) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлен новый синтаксис ALTER UPDATE/DELETE IN PARTITION. [#13403](https://github.com/ClickHouse/ClickHouse/pull/13403) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Добавлен движок StorageEmbeddedRocksdb. [#15073](https://github.com/ClickHouse/ClickHouse/pull/15073) ([sundyli](https://github.com/sundy-li)).
* Добавлен запрос `ALTER TABLE ... DROP|DETACH PART 'part_name'`. [#15511](https://github.com/ClickHouse/ClickHouse/pull/15511) ([nvartolomei](https://github.com/nvartolomei)).
* Появилась возможность изменять путь к файлу истории в `clickhouse-client` с помощью параметра `--history_file`. [#15960](https://github.com/ClickHouse/ClickHouse/pull/15960) ([Maksim Kita](https://github.com/kitaisreal)).
* Обновлено форматирование DateTime и DateTime64: теперь поддерживается строковый формат литерала Date. [#16040](https://github.com/ClickHouse/ClickHouse/pull/16040) ([Maksim Kita](https://github.com/kitaisreal)).
* Добавлена настройка `aggregate_functions_null_for_empty`; эта опция переписывает все агрегатные функции в запросе, добавляя к ним суффикс -OrNull. Исправляет [10273](https://github.com/ClickHouse/ClickHouse/issues/10273). [#16123](https://github.com/ClickHouse/ClickHouse/pull/16123) ([flynn](https://github.com/ucasfl)).
* Добавлена поддержка COLLATE для Nullable, LowCardinality, Array и Tuple, где вложенный тип — String. Также выполнен рефакторинг кода, связанного с collation, в ColumnString.cpp. [#16273](https://github.com/ClickHouse/ClickHouse/pull/16273) ([Kruglov Pavel](https://github.com/Avogar)).
* Появилась возможность распределять слияния между разными репликами. Добавлена настройка MergeTree `execute_merges_on_single_replica_time_threshold`. [#16424](https://github.com/ClickHouse/ClickHouse/pull/16424) ([filimonov](https://github.com/filimonov)).
* Добавлена поддержка сжатия и распаковки `*.xz`. Это позволяет использовать `*.xz` в функции `file()`. Закрывает [#8828](https://github.com/ClickHouse/ClickHouse/issues/8828). [#16578](https://github.com/ClickHouse/ClickHouse/pull/16578) ([Abi Palagashvili](https://github.com/fibersel)).
* Добавлены новые функции `cmath`: - acosh - asinh - atan2 - atanh - cosh - hypot - log1p - sinh. [#16636](https://github.com/ClickHouse/ClickHouse/pull/16636) ([Konstantin Malanchev](https://github.com/hombit)).
* Добавлена возможность по умолчанию задавать значение enum как его идентификатор в форматах TSV и CSV. [#16834](https://github.com/ClickHouse/ClickHouse/pull/16834) ([Kruglov Pavel](https://github.com/Avogar)).
* Новая функция tcpPort() возвращает TCP-порт, который прослушивает сервер. [#17134](https://github.com/ClickHouse/ClickHouse/pull/17134) ([Ivan](https://github.com/abyss7)).



<div id="performance-improvement">
  #### Повышение производительности
</div>

* Теперь партиции можно безопасно отбрасывать при точном совпадении. Полезный пример: предположим, что таблица разбита на партиции по `intHash64(x) % 100`, и запрос содержит условие именно по `intHash64(x) % 100`, а не по `x`. [#16253](https://github.com/ClickHouse/ClickHouse/pull/16253) ([Amos Bird](https://github.com/amosbird)).
* Используется алгоритм Floyd-Rivest; он должен лучше всего подходить для задач частичной сортировки в ClickHouse. Бенчмарки приведены в https://github.com/danlark1/miniselect и [здесь](https://drive.google.com/drive/folders/1DHEaeXgZuX6AJ9eByeZ8iQVQv0ueP8XM). [#16825](https://github.com/ClickHouse/ClickHouse/pull/16825) ([Daniel Kutenin](https://github.com/danlark1)).



<div id="improvement">
  #### Улучшения
</div>

* Добавлено описание подзапроса `VIEW` в `EXPLAIN`. Ограничена оптимизация проталкивания предикатов для `VIEW`. Добавлены локальные реплики `Distributed` в план запроса. [#14936](https://github.com/ClickHouse/ClickHouse/pull/14936) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Функция `indexOf()` теперь использует BloomFilter. [#14977](https://github.com/ClickHouse/ClickHouse/pull/14977) ([achimbab](https://github.com/achimbab)).
* Генерируется исключение с указанием необходимых привилегий синхронизации, если у пользователя MySQL для синхронизации заданы некорректные привилегии. [#15977](https://github.com/ClickHouse/ClickHouse/pull/15977) ([TCeason](https://github.com/TCeason)).
* Исправлено возможное переполнение стека при создании циклической зависимости materialized view. Закрывает [#15732](https://github.com/ClickHouse/ClickHouse/issues/15732). [#16048](https://github.com/ClickHouse/ClickHouse/pull/16048) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка SNI в HTTPS-соединениях с удалёнными ресурсами. Это позволяет подключаться к серверам Cloudflare, требующим SNI. Исправляет [#10055](https://github.com/ClickHouse/ClickHouse/issues/10055). [#16252](https://github.com/ClickHouse/ClickHouse/pull/16252) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Семейство движков `ReplicatedMergeTree` теперь использует отдельный пул потоков для загрузки реплицированных данных. Размер пула ограничивается настройкой `background_fetches_pool_size`, которую можно изменить с перезапуском сервера. Значение по умолчанию равно 3, то есть максимальное число параллельных загрузок равно 3 (что достаточно для использования сети 10G). Исправляет #520. [#16390](https://github.com/ClickHouse/ClickHouse/pull/16390) ([alesapin](https://github.com/alesapin)).
* Конфигурация `<auxiliary_zookeepers>` теперь может быть изменена в `config.xml` и перезагружена без перезапуска сервера. [#16627](https://github.com/ClickHouse/ClickHouse/pull/16627) ([Amos Bird](https://github.com/amosbird)).
* Разрешено переинтерпретирование между целыми числами и числами с плавающей точкой одинакового размера. Исправляет [16640](https://github.com/ClickHouse/ClickHouse/issues/16640). [#16657](https://github.com/ClickHouse/ClickHouse/pull/16657) ([flynn](https://github.com/ucasfl)).
* Добавлено обходное решение для использования S3 с nginx в качестве прокси. Nginx в настоящее время не принимает URL с пустым путём вида `http://domain.com?delete`, тогда как стандартный aws-sdk-cpp генерирует именно такие URL. В данном коммите используется патченная версия aws-sdk-cpp, которая в подобных случаях формирует URL с «/» в качестве пути, например `http://domain.com/?delete`. [#16709](https://github.com/ClickHouse/ClickHouse/pull/16709) ([ianton-ru](https://github.com/ianton-ru)).
* Удаляются пустые директории для асинхронной вставки при запуске движка Distributed. [#16729](https://github.com/ClickHouse/ClickHouse/pull/16729) ([Azat Khuzhin](https://github.com/azat)).
* Улучшение удобства использования: более информативные подсказки в сообщении об ошибке синтаксиса, когда выражение `CODEC` указано в неверном месте запроса `CREATE TABLE`. Исправляет [#12493](https://github.com/ClickHouse/ClickHouse/issues/12493). [#16768](https://github.com/ClickHouse/ClickHouse/pull/16768) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Улучшено сообщение об исключении при отсутствии конфигурации для distributed DDL. Исправляет [#5075](https://github.com/ClickHouse/ClickHouse/issues/5075). [#16769](https://github.com/ClickHouse/ClickHouse/pull/16769) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Настройка `use_compact_format_in_distributed_parts_names` теперь применяется для каждой вставки (с internal_replication). [#16788](https://github.com/ClickHouse/ClickHouse/pull/16788) ([Azat Khuzhin](https://github.com/azat)).
* Сервер отказывается запускаться с сообщением об исключении при некорректной конфигурации (отсутствует `metric_log`.`collect_interval_milliseconds`). [#16815](https://github.com/ClickHouse/ClickHouse/pull/16815) ([Ivan](https://github.com/abyss7)).
* Добавлена функция cutToFirstSignificantSubdomainWithWWW(). [#16845](https://github.com/ClickHouse/ClickHouse/pull/16845) ([Azat Khuzhin](https://github.com/azat)).
* Генерируется информативное сообщение об ошибке при выполнении ATTACH/DETACH TABLE <DICTIONARY>. До этого изменения команда `detach table <dict>` выполнялась, но приводила к некорректным метаданным в памяти. [#16885](https://github.com/ClickHouse/ClickHouse/pull/16885) ([Amos Bird](https://github.com/amosbird)).
* Удаляются пустые части после их отсечения алгоритмом TTL, мутации или схлопывания при слиянии. [#16895](https://github.com/ClickHouse/ClickHouse/pull/16895) ([Anton Popov](https://github.com/CurtizJ)).
* Добавлена возможность подключения к защищённой конечной точке `clickhouse-server`, требующей SNI. Это актуально, когда `clickhouse-server` размещён за TLS-прокси. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).
* Параметры `host` и `port` для `SOURCE(CLICKHOUSE(...))` теперь по умолчанию указывают на текущий экземпляр, а значение `user` по умолчанию установлено в `'default'`. [#16997](https://github.com/ClickHouse/ClickHouse/pull/16997) ([Vladimir C](https://github.com/vdimir)).
* Добавлена возможность выводить все строки в виде массива JSON в формате `JSONEachRow`, управляемая настройкой `output_format_json_array_of_rows`. [#17152](https://github.com/ClickHouse/ClickHouse/pull/17152) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Добавлена возможность форматировать именованные Tuple как объекты JSON при использовании форматов ввода/вывода JSON, управляемая настройкой `output_format_json_named_tuples_as_objects` (по умолчанию отключена). [#17175](https://github.com/ClickHouse/ClickHouse/pull/17175) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Исправлена грамматика в сообщениях об ошибках во входных форматах JSONEachRow, JSONCompactEachRow и RegexpRow. [#17205](https://github.com/ClickHouse/ClickHouse/pull/17205) ([nico piderman](https://github.com/sneako)).
