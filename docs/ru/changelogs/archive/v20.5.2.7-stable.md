  ### Релиз ClickHouse v20.5.2.7-stable FIXME в сравнении с v20.5.1.3833-prestable
</div>

<div id="new-feature">
  #### Новая возможность
</div>

* Реализована поддержка `Alter table drop replica replica_name`. Это исправляет [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).

<div id="improvement">
  #### Улучшения
</div>

* Добавлено количество ошибок, которые следует игнорировать при выборе реплик (`distributed_replica_error_ignore`). [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* Многоверсионные метаданные для хранилищ без блокировок структуры. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* Немного ослаблена проверка строки подключения ODBC. Если имя хоста или имя пользователя содержит только буквенно-цифровые символы, а также `.` и `-`, не заключайте его в фигурные скобки. Это необходимо, потому что некоторые ODBC Driver (например, PostgreSQL) не распознают имя хоста, заключённое в фигурные скобки. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка модификаторов `SIGNED` и `UNSIGNED` для стандартных целочисленных типов (`BIGINT`, `INT`, ...) для совместимости с MySQL. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Разрешено использовать `sumWithOverflow` как `SimpleAggregateFunction`. Закрывает [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053). [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Добавлена поддержка FixedString в функциях хеширования. [#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Исправлено неожиданное поведение запросов вида `SELECT *, xyz.*`, которые выполнялись успешно, хотя ожидалась ошибка. [#11753](https://github.com/ClickHouse/ClickHouse/pull/11753) ([hexiaoting](https://github.com/hexiaoting)).
* Исправлен неверный результат для `if()` с NULL в условии. [#11807](https://github.com/ClickHouse/ClickHouse/pull/11807) ([Artem Zuikov](https://github.com/4ertus2)).
* Исправлен учёт памяти через HTTP-интерфейс (это может быть существенно при `wait_end_of_query=1`). [#11840](https://github.com/ClickHouse/ClickHouse/pull/11840) ([Azat Khuzhin](https://github.com/azat)).
* Исправлено редкое аварийное завершение, вызванное использованием столбца `Nullable` в условии prewhere. Продолжение [#11608](https://github.com/ClickHouse/ClickHouse/issues/11608). [#11869](https://github.com/ClickHouse/ClickHouse/pull/11869) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#11965](https://github.com/ClickHouse/ClickHouse/issues/11965): исправлено потенциальное исключение с плавающей запятой при парсинге DateTime64. Это устраняет [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374). [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлено потенциальное исключение с плавающей запятой при парсинге DateTime64. Это устраняет [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374). [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#11963](https://github.com/ClickHouse/ClickHouse/issues/11963): для проверки прав доступа после оператора `USE database` теперь используется правильная текущая база данных. [#11920](https://github.com/ClickHouse/ClickHouse/pull/11920) ([Vitaly Baranov](https://github.com/vitlibar)).

Исправляет [#11985](https://github.com/ClickHouse/ClickHouse/issues/11985). [#12039](https://github.com/ClickHouse/ClickHouse/pull/12039) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
