  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#60983](https://github.com/ClickHouse/ClickHouse/issues/60983): исправлено переполнение буфера, которое может возникнуть, если злоумышленник заставит HTTP-сервер распаковывать данные с композицией кодеков и размером, вызывающим числовое переполнение. Исправлено переполнение буфера, которое может возникнуть внутри кодека NONE при некорректных входных данных. Обнаружено исследовательской группой TIANGONG через нашу [программу Bug Bounty](https://github.com/ClickHouse/ClickHouse/issues/38986). [#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#60986](https://github.com/ClickHouse/ClickHouse/issues/60986): функции SQL/JSON могли читать неинициализированную память. Закрывает [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017). Обнаружено фаззером. [#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#60816](https://github.com/ClickHouse/ClickHouse/issues/60816): исправлен сбой в arrayEnumerateRanked. [#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#60837](https://github.com/ClickHouse/ClickHouse/issues/60837): исправлен сбой при использовании input() в INSERT SELECT JOIN. Закрывает [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035). [#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#60911](https://github.com/ClickHouse/ClickHouse/issues/60911): предотвращён segfault, если при чтении из S3 пропускается слишком много ключей. [#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)).
