<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#59569](https://github.com/ClickHouse/ClickHouse/issues/59569): Теперь панель мониторинга понимает как сжатое, так и несжатое состояние фрагмента `#hash` в URL (обратная совместимость). Продолжение [#59124](https://github.com/ClickHouse/ClickHouse/issues/59124). [#59548](https://github.com/ClickHouse/ClickHouse/pull/59548) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#59776](https://github.com/ClickHouse/ClickHouse/issues/59776): Добавлены настройки `split_parts_ranges_into_intersecting_and_non_intersecting_final` и `split_intersecting_parts_ranges_into_layers_final`. Эти настройки нужны для отключения оптимизаций для запросов с `FINAL` и требуются только для отладки. [#59705](https://github.com/ClickHouse/ClickHouse/pull/59705) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#59726](https://github.com/ClickHouse/ClickHouse/issues/59726): Исправлено форматирование команд ALTER для настроек, специфичных для столбца. [#59445](https://github.com/ClickHouse/ClickHouse/pull/59445) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#59585](https://github.com/ClickHouse/ClickHouse/issues/59585): MAX теперь использует те же правила, что и permutation, для сложных типов. [#59498](https://github.com/ClickHouse/ClickHouse/pull/59498) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#59579](https://github.com/ClickHouse/ClickHouse/issues/59579): Исправлен граничный случай при передаче настройки `update_insert_deduplication_token_in_dependent_materialized_views`. Один граничный случай по-прежнему не охвачен из-за отсутствия таблиц в path:. [#59544](https://github.com/ClickHouse/ClickHouse/pull/59544) ([Jordi Villar](https://github.com/jrdi)).
* Бэкпортировано в [#59647](https://github.com/ClickHouse/ClickHouse/issues/59647): Исправлен некорректный результат arrayElement / map[] для пустого значения. [#59594](https://github.com/ClickHouse/ClickHouse/pull/59594) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#59639](https://github.com/ClickHouse/ClickHouse/issues/59639): Исправлен сбой в topK при слиянии пустых состояний. [#59603](https://github.com/ClickHouse/ClickHouse/pull/59603) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#59696](https://github.com/ClickHouse/ClickHouse/issues/59696): Сохранён алиас функции в RewriteSumFunctionWithSumAndCountVisitor. [#59658](https://github.com/ClickHouse/ClickHouse/pull/59658) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#59764](https://github.com/ClickHouse/ClickHouse/issues/59764): Исправлена работа функции leftPad / rightPad с входными данными типа FixedString. [#59739](https://github.com/ClickHouse/ClickHouse/pull/59739) ([Raúl Marín](https://github.com/Algunenano)).
