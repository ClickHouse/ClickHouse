<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#32688](https://github.com/ClickHouse/ClickHouse/issues/32688): лимит квоты считался не достигнутым, хотя фактически был превышен. Этот PR исправляет [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).
* Бэкпортировано в [#32343](https://github.com/ClickHouse/ClickHouse/issues/32343): исправлена ошибка при удалении ненужных столбцов в подзапросе. Если в запросе есть функция агрегации без GROUP BY, её не следует удалять, даже если она не нужна. [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

#### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)

* Бэкпортировано в [#32108](https://github.com/ClickHouse/ClickHouse/issues/32108): Исправлен сбой при выполнении ODBC-запроса с пустым результатом. Закрывает [#31465](https://github.com/ClickHouse/ClickHouse/issues/31465). [#31766](https://github.com/ClickHouse/ClickHouse/pull/31766) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#32150](https://github.com/ClickHouse/ClickHouse/issues/32150): Исправлен сбой при использовании функции `dictGet` с указанием типа для атрибута словаря, когда тип — `Nullable`. Исправляет [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980). [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32075](https://github.com/ClickHouse/ClickHouse/issues/32075): Исправлена ошибка в функции transform с аргументами типа Decimal. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* Бэкпортировано в [#31955](https://github.com/ClickHouse/ClickHouse/issues/31955): - При создании `KeeperTCPHandler` путь конфигурации изменён с `keeper_server.session_timeout_ms` на `keeper_server.coordination_settings.session_timeout_ms` - То же самое для `operation_timeout`. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* Бэкпортировано в [#32161](https://github.com/ClickHouse/ClickHouse/issues/32161): Некоторые записи `GET_PART` могут зависать в очереди репликации, если часть потеряна на всех репликах и в той же партиции нет других частей. Это исправлено для случаев, когда ключ партиционирования содержит только столбцы целочисленных типов или `Date[Time]`. Исправляет [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485). [#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32146](https://github.com/ClickHouse/ClickHouse/issues/32146): Исправлена ошибка `Directory ... already exists and is not empty` при отсоединении части. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32213](https://github.com/ClickHouse/ClickHouse/issues/32213): Число активных реплик могло определяться неверно при вставке с quorum, если настройка `replicated_can_become_leader` отключена на некоторых репликах. Это исправлено. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32312](https://github.com/ClickHouse/ClickHouse/issues/32312): Идентификаторы XML-словарей, используемые в запросе CREATE TABLE, при обновлении до более новой версии могут квалифицироваться в `default_database`. Закрывает [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963). [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32540](https://github.com/ClickHouse/ClickHouse/issues/32540): Некоторые записи в очереди репликации могут зависать на время `temporary_directories_lifetime` (по умолчанию 1 день) с ошибкой `Directory tmp_merge_<part_name>` или `Part ... (state Deleting) already exists, but it will be deleted soon`, либо с похожей ошибкой. Это исправлено. Исправляет [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32353](https://github.com/ClickHouse/ClickHouse/issues/32353): Исправлен сбой с SIGFPE в агрегатной функции `avgWeighted` с аргументом `Decimal`. Исправляет [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#33048](https://github.com/ClickHouse/ClickHouse/issues/33048): исправлено возможное Исключение при запуске хранилища RabbitMQ за счёт отложенного создания канала. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#32795](https://github.com/ClickHouse/ClickHouse/issues/32795): исправлен сбой при использовании fuzzBits с одним и тем же FixedString несколько раз, закрывает [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737). [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
