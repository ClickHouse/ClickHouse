<div id="bug-fix">
  #### Исправление ошибки
</div>

* бэкпорт в [#17198](https://github.com/ClickHouse/ClickHouse/issues/17198): устранены лишние сетевые ошибки для удалённых запросов, которые могут быть отменены во время выполнения, например запросов с `LIMIT`. [#17006](https://github.com/ClickHouse/ClickHouse/pull/17006) ([Azat Khuzhin](https://github.com/azat)).
* бэкпорт в [#17131](https://github.com/ClickHouse/ClickHouse/issues/17131): исправлено падение при выполнении запроса `CREATE TABLE ... AS some_table`, если `some_table` была создана с помощью `AS table_function()`. Исправляет [#16944](https://github.com/ClickHouse/ClickHouse/issues/16944). [#17072](https://github.com/ClickHouse/ClickHouse/pull/17072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* бэкпорт в [#17192](https://github.com/ClickHouse/ClickHouse/issues/17192): исправлено сравнение ColumnConst, приводившее к сбою. Этим исправлена проблема [#17088](https://github.com/ClickHouse/ClickHouse/issues/17088). [#17135](https://github.com/ClickHouse/ClickHouse/pull/17135) ([Amos Bird](https://github.com/amosbird)).
