<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Исправлено некорректное приведение типов из столбца LowCardinality при использовании выполнения функций с коротким замыканием [#43311](https://github.com/ClickHouse/ClickHouse/pull/43311) ([Kruglov Pavel](https://github.com/Avogar)).
* Исправлена проблема msan в randomStringUTF8(<нечётное число>) [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze)).
* Исправлена JIT-компиляция при сравнении с NaN (не равно) [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal)).
* Исправлено аварийное завершение при использовании `multiIf` с константным условием и аргументами, допускающими NULL [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ)).
* Исправлено преобразование типов из Date/Date32 в DateTime64 при выполнении запросов с индексом DateTime64 [#50280](https://github.com/ClickHouse/ClickHouse/pull/50280) ([Lucas Chang](https://github.com/lucas-tubi)).
* Исправлена взаимная блокировка в Keeper при возникновении исключения во время предварительной обработки запросов. [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr)).
* Исправлено возвращение неверного количества строк таблицами семейства Log после усечения [#50585](https://github.com/ClickHouse/ClickHouse/pull/50585) ([flynn](https://github.com/ucasfl)).
* Устранено считывание всех столбцов из правой таблицы GLOBAL JOIN. [#50721](https://github.com/ClickHouse/ClickHouse/pull/50721) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
