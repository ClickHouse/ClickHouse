<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530): Огромный `RUN` в Dockerfile разбит на несколько меньших условных блоков. Необходимые инструменты устанавливаются по мере необходимости в том же слое `RUN`, а затем удаляются. ОС обновляется только один раз, в самом начале. Использован современный способ проверки подписи репозитория. Базовый репозиторий переведён на ubuntu:20.04, чтобы устранить проблемы в старых версиях Docker. Версия Go обновлена для устранения уязвимостей. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570): Это продолжение [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504): изменения по очистке были потеряны во время рефакторинга. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Исправлен некорректный анализ индексов, когда бинарный оператор содержит константный аргумент null [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* Исправлено повторное подключение HTTPS-сеанса, если изменился IP-адрес целевого хоста [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Исправлено некорректное свёртывание констант [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлен тип хеша параметров LDAP-сервера в записи кэша [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* В формате Parquet вместо исключения теперь выполняется разбор большого целого числа из String [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* Проекция не применяется, если был включен режим read-in-order. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Исправлен сбой fuzzer в ActionsDAG [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
