<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Бэкпортировано в [#77183](https://github.com/ClickHouse/ClickHouse/issues/77183): по умолчанию отключена поддержка параллельных реплик, если анализатор отключён, независимо от настройки `compatibility`. Это поведение по-прежнему можно изменить, явно установив `parallel_replicas_only_with_analyzer` в `false`. [#77115](https://github.com/ClickHouse/ClickHouse/pull/77115) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпортировано в [#77358](https://github.com/ClickHouse/ClickHouse/issues/77358): добавлена настройка сервера `concurrent_threads_scheduler`, которая управляет распределением слотов CPU между параллельно выполняющимися запросами. Её можно установить в `round_robin` (прежнее поведение) или `fair_round_robin`, чтобы устранить проблему несправедливого распределения CPU между INSERT и SELECT. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#76999](https://github.com/ClickHouse/ClickHouse/issues/76999): Исправлена потеря данных, когда включён async insert и выполняется insert into ... from file ... с блоками разного размера: если размер первого блока &lt; async&#95;max&#95;size, а второго блока &gt; async&#95;max&#95;size, второй блок не вставляется. Эти данные остаются в `squashing`. [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* Бэкпортировано в [#76970](https://github.com/ClickHouse/ClickHouse/issues/76970): Исправлено исключение THERE&#95;IS&#95;NO&#95;COLUMN при выборе булевого литерала из distributed таблиц. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#77049](https://github.com/ClickHouse/ClickHouse/issues/77049): Исправлена обработка исключений при параллельной десериализации префиксов подстолбцов JSON. [#76809](https://github.com/ClickHouse/ClickHouse/pull/76809) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77260](https://github.com/ClickHouse/ClickHouse/issues/77260): Исправлено возможное аварийное завершение из-за некорректного отката JSON-столбца при ошибке во время async inserts. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77064](https://github.com/ClickHouse/ClickHouse/issues/77064): Исправлена сортировка значений `BFloat16`. Это закрывает [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487). Это закрывает [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669). [#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#77222](https://github.com/ClickHouse/ClickHouse/issues/77222): Исправлена ошибка с JSON и variant-подстолбцом за счёт добавления проверки, пропускающей эфемерные подстолбцы при проверке согласованности part. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Бэкпортировано в [#77250](https://github.com/ClickHouse/ClickHouse/issues/77250): Исправлено аварийное завершение при создании таблицы Kafka в случае исключения. [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77240](https://github.com/ClickHouse/ClickHouse/issues/77240): Добавлена поддержка нового JSON и подстолбцов в движках Kafka и RabbitMQ. [#77122](https://github.com/ClickHouse/ClickHouse/pull/77122) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77386](https://github.com/ClickHouse/ClickHouse/issues/77386): `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` теперь корректно возвращает `true` (вместо прежнего `false`). Это делает поведение согласованным с `Float32` и `Float64`. [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Бэкпортировано в [#77379](https://github.com/ClickHouse/ClickHouse/issues/77379): Исправлено имя партиции для значения Bool. Это было сломано в [https://github.com/ClickHouse/ClickHouse/pull/74533](https://github.com/ClickHouse/ClickHouse/pull/74533). [#77319](https://github.com/ClickHouse/ClickHouse/pull/77319) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77335](https://github.com/ClickHouse/ClickHouse/issues/77335): Исправлено сравнение между Tuple с элементами Nullable и строками. [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
