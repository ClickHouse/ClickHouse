<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#56581](https://github.com/ClickHouse/ClickHouse/issues/56581): предотвращено обращение к удалённому источнику данных для столбца `data_paths` в `system.tables`, если таблица создана с помощью табличной функции с явным описанием столбцов. [#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Бэкпортировано в [#56877](https://github.com/ClickHouse/ClickHouse/issues/56877): исправлен неполный результат запроса для `UNION` в табличной функции `view()`. [#56274](https://github.com/ClickHouse/ClickHouse/pull/56274) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#56409](https://github.com/ClickHouse/ClickHouse/issues/56409): запрещено добавление столбца типа `Object(JSON)` в существующую таблицу. Это закрывает: [#56095](https://github.com/ClickHouse/ClickHouse/issues/56095) Это закрывает: [#49944](https://github.com/ClickHouse/ClickHouse/issues/49944). [#56307](https://github.com/ClickHouse/ClickHouse/pull/56307) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#56756](https://github.com/ClickHouse/ClickHouse/issues/56756): исправлен segfault, вызванный исключением при инициализации Kerberos во время создания таблицы Kafka. Закрывает [#56073](https://github.com/ClickHouse/ClickHouse/issues/56073). [#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#56748](https://github.com/ClickHouse/ClickHouse/issues/56748): исправлена проблема, из-за которой движок таблицы RabbitMQ не мог подключиться к RabbitMQ по защищённому соединению. [#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* Бэкпортировано в [#56839](https://github.com/ClickHouse/ClickHouse/issues/56839): сервер аварийно завершался при распаковке повреждённых данных с использованием кодека `FPC`. Эта проблема была обнаружена в рамках [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) пользователем [https://twitter.com/malacupa](https://twitter.com/malacupa). [#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
