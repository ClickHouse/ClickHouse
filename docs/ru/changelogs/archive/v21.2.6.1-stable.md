  # Журнал изменений за 2022 год

<div id="clickhouse-release-v21261-stable-fixme-as-compared-to-v21255-stable">
  ### Релиз ClickHouse v21.2.6.1-stable FIXME по сравнению с версией v21.2.5.5-stable
</div>

<div id="bug-fix">
  #### Исправления ошибок
</div>

* Бэкпорт в [#21352](https://github.com/ClickHouse/ClickHouse/issues/21352): исправлено количество потоков для скалярных подзапросов и подзапросов для индекса (после [#19007](https://github.com/ClickHouse/ClickHouse/issues/19007) всегда использовался только один поток). Исправляет [#20457](https://github.com/ClickHouse/ClickHouse/issues/20457), [#20512](https://github.com/ClickHouse/ClickHouse/issues/20512). [#20550](https://github.com/ClickHouse/ClickHouse/pull/20550) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпорт в [#21262](https://github.com/ClickHouse/ClickHouse/issues/21262): исправлена проблема, из-за которой значения default&#95;replica&#95;path и default&#95;replica&#95;name не работали для движка Replicated(*)MergeTree, если для него требовалось указать другие параметры. [#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy)).
* Бэкпорт в [#21156](https://github.com/ClickHouse/ClickHouse/issues/21156): исправлена ошибка, связанная с приведением tuple к map. Закрывает [#21029](https://github.com/ClickHouse/ClickHouse/issues/21029). [#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting)).
* Бэкпорт в [#21234](https://github.com/ClickHouse/ClickHouse/issues/21234): теперь Мутации разрешены только для движков таблиц, которые их поддерживают (семейство MergeTree, Memory, MaterializedView). Для остальных движков будет выводиться более понятная ошибка. Исправляет [#21168](https://github.com/ClickHouse/ClickHouse/issues/21168). [#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#21427](https://github.com/ClickHouse/ClickHouse/issues/21427): исправлен сбой в `EXPLAIN` для запроса с `UNION`. Исправляет [#20876](https://github.com/ClickHouse/ClickHouse/issues/20876), [#21170](https://github.com/ClickHouse/ClickHouse/issues/21170). [#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl)).
* Бэкпорт в [#21301](https://github.com/ClickHouse/ClickHouse/issues/21301): исправлены лишние повторные подключения к ZooKeeper и возможность появления двух активных сеансов у одного сервера ClickHouse. Обе проблемы появились после [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678). [#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#21553](https://github.com/ClickHouse/ClickHouse/issues/21553): теперь запросы `ALTER MODIFY COLUMN` корректно учитывают изменения в ключе партиционирования, индексах пропуска данных, TTL и так далее. Исправляет [#13675](https://github.com/ClickHouse/ClickHouse/issues/13675). [#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin)).
* Бэкпорт в [#21380](https://github.com/ClickHouse/ClickHouse/issues/21380): исправлена ошибка `Bad cast from type ... to DB::ColumnLowCardinality` при вставке в таблицу со столбцом `LowCardinality` из формата `Values`. Исправляет [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140). [#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
