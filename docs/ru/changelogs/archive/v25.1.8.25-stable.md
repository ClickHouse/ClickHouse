<div id="new-feature">
  #### Новая возможность
</div>

* Бэкпортировано в [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357): добавлена настройка сервера `concurrent_threads_scheduler`, которая управляет распределением слотов CPU между параллельно выполняемыми запросами. Можно установить значение `round_robin` (прежнее поведение) или `fair_round_robin`, чтобы устранить проблему несправедливого распределения CPU между запросами `INSERT` и `SELECT`. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#77202](https://github.com/ClickHouse/ClickHouse/issues/77202): Ранее база данных Replicated могла выводить в журналы учетные данные, указанные в запросе. Это исправлено. Закрывает: [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123). [#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#76151](https://github.com/ClickHouse/ClickHouse/issues/76151): Настройки format теперь передаются при форматировании JSON как строки в Native format. [#75832](https://github.com/ClickHouse/ClickHouse/pull/75832) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#76968](https://github.com/ClickHouse/ClickHouse/issues/76968): Исправлено Исключение THERE&#95;IS&#95;NO&#95;COLUMN при выборке булева литерала из distributed таблиц. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#77256](https://github.com/ClickHouse/ClickHouse/issues/77256): Исправлено возможное аварийное завершение из-за некорректного отката JSON-столбца при ошибке во время async inserts. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77220](https://github.com/ClickHouse/ClickHouse/issues/77220): Исправлена ошибка в JSON с подстолбцом Variant: добавлена проверка, пропускающая эфемерные подстолбцы при проверке согласованности part. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Бэкпортировано в [#77248](https://github.com/ClickHouse/ClickHouse/issues/77248): Исправлено аварийное завершение при создании таблицы Kafka при возникновении исключения. [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#77384](https://github.com/ClickHouse/ClickHouse/issues/77384): `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` теперь корректно возвращает `true` (ранее `false`). Это делает поведение согласованным с `Float32` и `Float64`. [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Бэкпортировано в [#77333](https://github.com/ClickHouse/ClickHouse/issues/77333): Исправлено сравнение Tuple со строками при наличии внутри элементов Nullable. [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
