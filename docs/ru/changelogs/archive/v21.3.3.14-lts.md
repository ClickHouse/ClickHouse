<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#21644](https://github.com/ClickHouse/ClickHouse/issues/21644): исправлена проблема, из-за которой таблица S3 после обновления config продолжала использовать старые учетные данные. [#21457](https://github.com/ClickHouse/ClickHouse/pull/21457) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Бэкпортировано в [#21854](https://github.com/ClickHouse/ClickHouse/issues/21854): исправлена возможная ошибка ` Cannot find column`, возникавшая, когда `optimize_skip_unused_shards` включен и не используется ни одного сегмента. [#21579](https://github.com/ClickHouse/ClickHouse/pull/21579) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21687](https://github.com/ClickHouse/ClickHouse/issues/21687): исправлен `fsync_part_directory` для горизонтального merge. [#21642](https://github.com/ClickHouse/ClickHouse/pull/21642) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21796](https://github.com/ClickHouse/ClickHouse/issues/21796): исправлена отмена распределённых requests (например, простого `select` из нескольких сегментов с `limit`, то есть `select * from remote('127.{2,3}', system.numbers) limit 100`) при `async_socket_for_remote=1`. [#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21811](https://github.com/ClickHouse/ClickHouse/issues/21811): исправлена ошибка в движках таблиц ReplicatedMerge, из-за которой запрос `ALTER MODIFY COLUMN` не менял тип столбца Decimal, если его размер (32 bit или 64 bit) не менялся. [#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#21883](https://github.com/ClickHouse/ClickHouse/issues/21883): отменены изменения, связанные с пулами соединений S3. [#21737](https://github.com/ClickHouse/ClickHouse/pull/21737) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Бэкпортировано в [#21874](https://github.com/ClickHouse/ClickHouse/issues/21874): исправлен некорректный результат запроса (и возможный crash), который мог возникать, когда условие `WHERE` или `HAVING` проталкивалось перед `GROUP BY`. Исправляет [#21773](https://github.com/ClickHouse/ClickHouse/issues/21773). [#21841](https://github.com/ClickHouse/ClickHouse/pull/21841) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
