<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#71711](https://github.com/ClickHouse/ClickHouse/issues/71711): для CLICKHOUSE&#95;PASSWORD выполняется экранирование для XML в entrypoint образа clickhouse. [#69301](https://github.com/ClickHouse/ClickHouse/pull/69301) ([aohoyd](https://github.com/aohoyd)).
* Бэкпортировано в [#71662](https://github.com/ClickHouse/ClickHouse/issues/71662): если пользователь/группа указаны в виде ID, команда `clickhouse su` завершается с ошибкой. Этот патч также добавляет поддержку `UID:GID`. ### Запись в документации об изменениях, заметных пользователям. [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#65755](https://github.com/ClickHouse/ClickHouse/issues/65755): Исправлены ошибки `Expression nodes list expected 1 projection names` и `Unknown expression or identifier` для запросов с псевдонимами для `GLOBAL IN.`. [#64517](https://github.com/ClickHouse/ClickHouse/pull/64517) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#71600](https://github.com/ClickHouse/ClickHouse/issues/71600): Исправлена ошибка Invalid number of rows in Chunk with Variant column. [#71388](https://github.com/ClickHouse/ClickHouse/pull/71388) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#71842](https://github.com/ClickHouse/ClickHouse/issues/71842): Исправлено падение при использовании optimize&#95;rewrite&#95;array&#95;exists&#95;to&#95;has. [#71432](https://github.com/ClickHouse/ClickHouse/pull/71432) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71562](https://github.com/ClickHouse/ClickHouse/issues/71562): Предотвращено падение при использовании UDF в ограничении. [#71541](https://github.com/ClickHouse/ClickHouse/pull/71541) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71731](https://github.com/ClickHouse/ClickHouse/issues/71731): Функции bitShift теперь возвращают 0 или символ по умолчанию вместо ошибки при выходе за границы. [#71580](https://github.com/ClickHouse/ClickHouse/pull/71580) ([Pablo Marcos](https://github.com/pamarcos)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#71697](https://github.com/ClickHouse/ClickHouse/issues/71697): Добавлен вендоринг зависимостей Rust. [#62297](https://github.com/ClickHouse/ClickHouse/pull/62297) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71688](https://github.com/ClickHouse/ClickHouse/issues/71688): Улучшен Dockerfile.ubuntu для clickhouse-server. Переменные окружения `CLICKHOUSE_UID/CLICKHOUSE_GID` объявлены устаревшими. Удалена обработка `CLICKHOUSE_DOCKER_RESTART_ON_EXIT` для соответствия требованиям. Унифицирован запуск `clickhouse/clickhouse-server/clickhouse-keeper`, чтобы в одном месте не использовалось простое имя, а в другом — `/usr/bin/clickhouse*`. [#71573](https://github.com/ClickHouse/ClickHouse/pull/71573) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
