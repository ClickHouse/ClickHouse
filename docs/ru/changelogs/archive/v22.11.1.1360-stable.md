<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Семейство функций JSONExtract теперь будет пытаться приводить значения к запрошенному типу. [#41502](https://github.com/ClickHouse/ClickHouse/pull/41502) ([Márcio Martins](https://github.com/marcioapm)).

<div id="new-feature">
  #### Новая возможность
</div>

* * Добавлена функция `displayName`, закрывает [#36770](https://github.com/ClickHouse/ClickHouse/issues/36770). [#37681](https://github.com/ClickHouse/ClickHouse/pull/37681) ([hongbin](https://github.com/xlwh)).
* В `system.query_log` добавлены применённые политики на уровне строки. [#39819](https://github.com/ClickHouse/ClickHouse/pull/39819) ([Vladimir Chebotaryov](https://github.com/quickhouse)).
* Добавлены движки таблиц Hudi и DeltaLake в режиме только для чтения, только для таблиц на S3. [#41054](https://github.com/ClickHouse/ClickHouse/pull/41054) ([Daniil Rubin](https://github.com/rubin-do)).
* Добавлена команда 4LW `csnp` для ручного создания снимков. Кроме того, добавлен `lgif` для получения информации о Raft для конкретного узла (например, индекса последнего созданного снимка, индекса последней закоммиченной записи лога). [#41766](https://github.com/ClickHouse/ClickHouse/pull/41766) ([JackyWoo](https://github.com/JackyWoo)).
* Добавлена поддержка повторных попыток запросов Keeper при вставке в реплицируемые merge tree. Помимо отказоустойчивости, это должно улучшить пользовательский опыт: не возвращать пользователю ошибку при вставке, если Keeper перезапускается (например, из-за обновления). [#42607](https://github.com/ClickHouse/ClickHouse/pull/42607) ([Igor Nikonov](https://github.com/devcrafter)).
* Добавлена функция ascii, как в Spark: [https://spark.apache.org/docs/latest/api/sql/#ascii](https://spark.apache.org/docs/latest/api/sql/#ascii). [#42670](https://github.com/ClickHouse/ClickHouse/pull/42670) ([李扬](https://github.com/taiyang-li)).
* Добавлена функция pmod, которая возвращает неотрицательный результат операции modulo. [#42755](https://github.com/ClickHouse/ClickHouse/pull/42755) ([李扬](https://github.com/taiyang-li)).
* Опубликована функция `formatReadableDecimalSize`. [#42774](https://github.com/ClickHouse/ClickHouse/pull/42774) ([Alejandro](https://github.com/alexon1234)).
* Добавлено ограничение частоты S3-запросов PUT и GET в секунду. Для настройки ограничителя token bucket используются настройки `s3_max_get_rps`, `s3_max_get_burst`, `s3_max_put_rps`, `s3_max_put_burst`. Это можно использовать как с S3 ObjectStorage, так и с табличной функцией S3. Для разных S3-дисков или конечных точек можно настроить разные лимиты. [#43014](https://github.com/ClickHouse/ClickHouse/pull/43014) ([Sergei Trifonov](https://github.com/serxa)).
* Добавлены табличные функции hudi и deltaLake. [#43080](https://github.com/ClickHouse/ClickHouse/pull/43080) ([flynn](https://github.com/ucasfl)).
* Добавлена функция factorial, как в Impala или Spark. [#43110](https://github.com/ClickHouse/ClickHouse/pull/43110) ([李扬](https://github.com/taiyang-li)).
* Добавлена функция randCanonical, похожая на функцию rand в Spark или Impala. Функция генерирует псевдослучайные значения с независимым и одинаковым равномерным распределением в диапазоне [0, 1). [#43124](https://github.com/ClickHouse/ClickHouse/pull/43124) ([李扬](https://github.com/taiyang-li)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Сейчас единственные операторы с насыщением — And и Or, и это изменение затрагивает их код. [#42214](https://github.com/ClickHouse/ClickHouse/pull/42214) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* Функция `match` может использовать индекс, если условие задано по префиксу строки. Это закрывает [#37333](https://github.com/ClickHouse/ClickHouse/issues/37333). [#42458](https://github.com/ClickHouse/ClickHouse/pull/42458) ([clarkcaoliu](https://github.com/Clark0)).
* Исправлена низкая производительность JSONExtract с кортежами LowCardinality(String). [#42761](https://github.com/ClickHouse/ClickHouse/pull/42761) ([AlfVII](https://github.com/AlfVII)).
* Добавлена поддержка параллельного парсинга для входного формата LineAsString. Это даёт лишь небольшое повышение производительности. Это закрывает [#42502](https://github.com/ClickHouse/ClickHouse/issues/42502). [#42780](https://github.com/ClickHouse/ClickHouse/pull/42780) ([Kruglov Pavel](https://github.com/Avogar)).
* Повышение производительности Keeper: улучшена производительность коммита в случаях, когда у множества разных узлов есть незакоммиченные состояния. Это должно помочь в ситуациях, когда узел-follower не успевает синхронизироваться. [#42926](https://github.com/ClickHouse/ClickHouse/pull/42926) ([Antonio Andelic](https://github.com/antonio2368)).
* Распараллелено слияние состояний `uniqExact` для агрегации без ключа, то есть для запросов вида `SELECT uniqExact(number) FROM table`. Улучшение становится заметным, когда число уникальных ключей приближается к 10^6. Также немного оптимизирована производительность `uniq`. Это закрывает [#4510](https://github.com/ClickHouse/ClickHouse/issues/4510). [#43072](https://github.com/ClickHouse/ClickHouse/pull/43072) ([Nikita Taranov](https://github.com/nickitat)).

<div id="improvement">
  #### Улучшения
</div>

* Поддерживается тип `Object` внутри других типов, например `Array(JSON)`. [#36969](https://github.com/ClickHouse/ClickHouse/pull/36969) ([Anton Popov](https://github.com/CurtizJ)).
* Для полученной части удаляются перекрываемые части (чтобы избежать возможного роста задержек репликации). [#39737](https://github.com/ClickHouse/ClickHouse/pull/39737) ([Azat Khuzhin](https://github.com/azat)).
* ClickHouse Client и ClickHouse Local теперь по умолчанию показывают Прогресс даже в неинтерактивном режиме. Если доступен `/dev/tty`, Прогресс будет выводиться напрямую в терминал, без записи в stderr. Это позволяет видеть Прогресс, даже если stderr перенаправлен в файл, при этом файл не будет засоряться управляющими escape-последовательностями терминала. Прогресс можно отключить с помощью `--progress false`. Это закрывает [#32238](https://github.com/ClickHouse/ClickHouse/issues/32238). [#42003](https://github.com/ClickHouse/ClickHouse/pull/42003) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 1. Для интервалов теперь доступны операции сложения, вычитания и отрицания. Если типы интервалов различаются, они будут преобразованы в Tuple из этих типов. 2. К полю Date/DateTime можно прибавить кортеж интервалов или вычесть его из такого поля. 3. Добавлен парсинг интервалов разных типов, например: `INTERVAL '1 HOUR 1 MINUTE 1 SECOND'`. [#42195](https://github.com/ClickHouse/ClickHouse/pull/42195) ([Nikolay Degterinsky](https://github.com/evillique)).
* * В карту атомов ключевого условия добавлен `notLike`, чтобы условие вида `NOT LIKE 'prefix%'` могло использовать первичный индекс. [#42209](https://github.com/ClickHouse/ClickHouse/pull/42209) ([Duc Canh Le](https://github.com/canhld94)).
* Добавлена поддержка входных данных типа `FixedString` для функций кодирования base64. [#42285](https://github.com/ClickHouse/ClickHouse/pull/42285) ([ltrk2](https://github.com/ltrk2)).
* В `system.detached_parts` добавлены столбцы `bytes_on_disk` и `path`. Закрывает [#42264](https://github.com/ClickHouse/ClickHouse/issues/42264). [#42303](https://github.com/ClickHouse/ClickHouse/pull/42303) ([chen](https://github.com/xiedeyantu)).
* Улучшено использование структуры из таблицы вставки в табличных функциях: теперь у настройки `use_structure_from_insertion_table_in_table_functions` есть новое возможное значение — `2`, которое означает, что ClickHouse будет автоматически определять, можно ли использовать структуру из таблицы вставки. Закрывает [#40028](https://github.com/ClickHouse/ClickHouse/issues/40028). [#42320](https://github.com/ClickHouse/ClickHouse/pull/42320) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлена поддержка glob-шаблона `**` для рекурсивного обхода каталогов в filesystem и S3. Решает [#36316](https://github.com/ClickHouse/ClickHouse/issues/36316). [#42376](https://github.com/ClickHouse/ClickHouse/pull/42376) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* Добавлено маскирование паролей и секретных ключей как в `system.query_log`, так и в `/var/log/clickhouse-server/*.log`, а также в сообщениях об ошибках. [#42484](https://github.com/ClickHouse/ClickHouse/pull/42484) ([Vitaly Baranov](https://github.com/vitlibar)).
* В `query_info` добавлена новая переменная `limit`, указывающая, является ли запрос limit-trivial. Если да, приблизительное общее число строк будет скорректировано для последующей оценки. Закрывает [#7071](https://github.com/ClickHouse/ClickHouse/issues/7071). [#42580](https://github.com/ClickHouse/ClickHouse/pull/42580) ([Han Fei](https://github.com/hanfei1991)).
* Реализован `ATTACH` таблицы `MergeTree` для диска `s3_plain` (а также внесены некоторые исправления для `s3_plain`). [#42628](https://github.com/ClickHouse/ClickHouse/pull/42628) ([Azat Khuzhin](https://github.com/azat)).
* Исправлено отсутствие индикации прогресса для INSERT FROM INFILE. Закрывает [#42548](https://github.com/ClickHouse/ClickHouse/issues/42548). [#42634](https://github.com/ClickHouse/ClickHouse/pull/42634) ([chen](https://github.com/xiedeyantu)).
* Добавлена настройка `min_age_to_force_merge_on_partition_only` для оптимизации старых частей только на уровне всей партиции. [#42659](https://github.com/ClickHouse/ClickHouse/pull/42659) ([Antonio Andelic](https://github.com/antonio2368)).
* Алгоритм throttling изменён на token bucket. [#42665](https://github.com/ClickHouse/ClickHouse/pull/42665) ([Sergei Trifonov](https://github.com/serxa)).
* Выполнен рефакторинг FunctionTokens, чтобы задать максимальное число tokens, возвращаемых связанными функциями (по умолчанию отключено). [#42673](https://github.com/ClickHouse/ClickHouse/pull/42673) ([李扬](https://github.com/taiyang-li)).
* В `system.table_functions` добавлено новое поле `allow_readonly`, позволяющее использовать табличные функции в режиме только для чтения. Решает [#42414](https://github.com/ClickHouse/ClickHouse/issues/42414) Реализация: * В таблицу `system.table_functions` добавлено новое поле `allow_readonly`. * Обновлено использование нового поля `allow_readonly`, чтобы разрешить использование табличных функций в режиме только для чтения. Тестирование: * Добавлен тест для filesystem `tests/queries/0_stateless/02473_functions_in_readonly_mode.sh` Документация: * Обновлена английская документация по табличным функциям. [#42708](https://github.com/ClickHouse/ClickHouse/pull/42708) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* Разрешено использовать аргументы `Date32` в функциях formatDateTime и FROM&#95;UNIXTIME. [#42737](https://github.com/ClickHouse/ClickHouse/pull/42737) ([Roman Vasin](https://github.com/rvasin)).
* Обновлён tzdata до версии 2022f. В Мексике летнее время больше не будет применяться, кроме районов у границы с США: [https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html). Чиуауа переходит на постоянный UTC-6 с 2022-10-30. На Фиджи летнее время также больше не применяется. См. [https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) и [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209). [#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена событийная метрика `FailedAsyncInsertQuery` для async inserts. [#42814](https://github.com/ClickHouse/ClickHouse/pull/42814) ([Krzysztof Góralski](https://github.com/kgoralski)).
* Реализована оптимизация `read-in-order` на основе query plan. Она включена по умолчанию. Установите `query_plan_read_in_order = 0`, чтобы использовать предыдущую версию на основе AST. [#42829](https://github.com/ClickHouse/ClickHouse/pull/42829) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Для резервного копирования в S3 реализовано экспоненциальное увеличение размера загружаемой части. [#42833](https://github.com/ClickHouse/ClickHouse/pull/42833) ([Vitaly Baranov](https://github.com/vitlibar)).
* Когда задача merge постоянно занята, а места на диске недостаточно, полностью устаревшие части не могут быть выбраны и удалены, что приводит к нехватке места на диске. Идея заключается в том, что если срок действия всей части истёк, дополнительное место на диске для гарантии нормального выполнения TTL не требуется. [#42869](https://github.com/ClickHouse/ClickHouse/pull/42869) ([zhongyuankai](https://github.com/zhongyuankai)).
* Исправление ошибки: [#42856](https://github.com/ClickHouse/ClickHouse/issues/42856) — событие SAVEPOINT в binlog MySQL теперь игнорируется. [#42931](https://github.com/ClickHouse/ClickHouse/pull/42931) ([zzsmdfj](https://github.com/zzsmdfj)).
* Добавлена поддержка интерактивных параметров в запросах INSERT VALUES. [#43077](https://github.com/ClickHouse/ClickHouse/pull/43077) ([Nikolay Degterinsky](https://github.com/evillique)).
* Добавлена универсальная реализация для named collections с произвольной структурой, типа доступа и system.named&#95;collections. [#43147](https://github.com/ClickHouse/ClickHouse/pull/43147) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлены функция oss и StorageOSS (это удобно для пользователей). oss полностью совместим с S3. [#43155](https://github.com/ClickHouse/ClickHouse/pull/43155) ([zzsmdfj](https://github.com/zzsmdfj)).
* Улучшена диагностика ошибок при сборе информации, связанной с ОС, для таблицы `system.asynchronous_metrics`. [#43192](https://github.com/ClickHouse/ClickHouse/pull/43192) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Для `system.asynchronous_metrics` добавлена встроенная документация. Эта документация также экспортируется в Prometheus. Исправлена ошибка с метриками для `cache` disks — они вычислялись только для одного произвольного cache disk вместо всех. Это закрывает [#7644](https://github.com/ClickHouse/ClickHouse/issues/7644). [#43194](https://github.com/ClickHouse/ClickHouse/pull/43194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

Добавлены столбцы вместо псевдонимов (связано с [#9769](https://github.com/ClickHouse/ClickHouse/issues/9769)). Это улучшит совместимость с различными MySQL-клиентами. [#43198](https://github.com/ClickHouse/ClickHouse/pull/43198) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* Отключены табличные функции `deltaLake` и `hudi` в режиме только для чтения. [#43316](https://github.com/ClickHouse/ClickHouse/pull/43316) ([Antonio Andelic](https://github.com/antonio2368)).
