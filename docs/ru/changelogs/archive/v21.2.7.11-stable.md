<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#21206](https://github.com/ClickHouse/ClickHouse/issues/21206): Исправлена утечка метаданных при удалении таблицы семейства Replicated*MergeTree, использующей пользовательский кластер ZooKeeper (не по умолчанию). [#21119](https://github.com/ClickHouse/ClickHouse/pull/21119) ([fastio](https://github.com/fastio)).
* Бэкпортировано в [#21927](https://github.com/ClickHouse/ClickHouse/issues/21927): Исправлен разбор формата Avro для Kafka. Исправляет [#21437](https://github.com/ClickHouse/ClickHouse/issues/21437). [#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)).
* Бэкпортировано в [#21855](https://github.com/ClickHouse/ClickHouse/issues/21855): Исправлена возможная ошибка ` Cannot find column`, когда включён `optimize_skip_unused_shards` и не используется ни одного сегмента. [#21579](https://github.com/ClickHouse/ClickHouse/pull/21579) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21688](https://github.com/ClickHouse/ClickHouse/issues/21688): Исправлен `fsync_part_directory` для горизонтального слияния. [#21642](https://github.com/ClickHouse/ClickHouse/pull/21642) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21795](https://github.com/ClickHouse/ClickHouse/issues/21795): Исправлена отмена распределённых запросов (например, простого SELECT из нескольких сегментов с LIMIT, то есть `select * from remote('127.{2,3}', system.numbers) limit 100`) при `async_socket_for_remote=1`. [#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21879](https://github.com/ClickHouse/ClickHouse/issues/21879): Исправлены возможные сбои в агрегатных функциях с комбинатором Distinct при использовании двухуровневой агрегации. Это дополнительное исправление к [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365). Воспроизводится только в продакшн-среде. Тестового случая пока нет. cc @CurtizJ. [#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#21979](https://github.com/ClickHouse/ClickHouse/issues/21979): Отменён [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454), поскольку он мог приводить к значительному росту использования памяти при загрузке внешних словарей типа hashed. Это закрывает [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935). [#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#22140](https://github.com/ClickHouse/ClickHouse/issues/22140): В функции `decrypt` отсутствовала проверка минимального размера данных, зашифрованных в режиме AEAD. Это закрывает [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897). [#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
