<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#24189](https://github.com/ClickHouse/ClickHouse/issues/24189): Некоторые запросы `ALTER PARTITION` могли вызывать ошибки `Part A intersects previous part B` и `Unexpected merged part C intersecting drop range D` в очереди репликации. Это исправлено. Исправляет [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296). [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#24306](https://github.com/ClickHouse/ClickHouse/issues/24306): Исправлена работа с константным значением `DateTime` при сравнении со столбцом `DateTime64` в WHERE. ... [#24100](https://github.com/ClickHouse/ClickHouse/pull/24100) ([Vasily Nemkov](https://github.com/Enmk)).
* Бэкпортировано в [#24140](https://github.com/ClickHouse/ClickHouse/issues/24140): Ошибка: explain pipeline с `select xxx final` показывает неверный конвейер: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* Бэкпортировано в [#24190](https://github.com/ClickHouse/ClickHouse/issues/24190): Исправлена редкая ошибка, которая могла приводить к появлению частично инициализированной таблицы, способной обслуживать запросы на запись (insert/alter/и т. д.). Теперь такие таблицы будут переведены в режим только для чтения. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#24235](https://github.com/ClickHouse/ClickHouse/issues/24235): Исправлено состояние гонки, которое могло возникать в RBAC при высокой нагрузке. Этот PR исправляет [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090), [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134),. [#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#24244](https://github.com/ClickHouse/ClickHouse/issues/24244): Исправлено аварийное завершение работы сервера из-за того, что HDFS становился недоступен во время выполнения запроса. Закрывает [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117). [#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#24241](https://github.com/ClickHouse/ClickHouse/issues/24241): Исправлена опечатка в StorageMemory. Эта ошибка была внесена в [#15127](https://github.com/ClickHouse/ClickHouse/issues/15127), теперь она исправлена. Закрывает [#24192](https://github.com/ClickHouse/ClickHouse/issues/24192). [#24193](https://github.com/ClickHouse/ClickHouse/pull/24193) ([张中南](https://github.com/plugine)).
* Бэкпортировано в [#24353](https://github.com/ClickHouse/ClickHouse/issues/24353): Исправлена ошибка при перемещении Materialized View из базы данных Ordinary в Atomic (запрос `RENAME TABLE`). Теперь внутренняя таблица перемещается в новую базу данных вместе с Materialized View. Исправляет [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926). [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
