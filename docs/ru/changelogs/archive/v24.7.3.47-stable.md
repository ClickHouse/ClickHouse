* Бэкпортировано в [#67820](https://github.com/ClickHouse/ClickHouse/issues/67820): Исправлена возможная взаимная блокировка при отмене запроса с параллельными репликами. [#66905](https://github.com/ClickHouse/ClickHouse/pull/66905) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#67818](https://github.com/ClickHouse/ClickHouse/issues/67818): Относится только к экспериментальному типу данных Variant. Исправлен сбой при использовании типа Variant + AggregateFunction. [#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#67766](https://github.com/ClickHouse/ClickHouse/issues/67766): Исправлен сбой в `uniq` и `uniqTheta ` с аргументом `tuple()`. Закрывает [#67303](https://github.com/ClickHouse/ClickHouse/issues/67303). [#67306](https://github.com/ClickHouse/ClickHouse/pull/67306) ([flynn](https://github.com/ucasfl)).
* Бэкпортировано в [#67881](https://github.com/ClickHouse/ClickHouse/issues/67881): Корректно разбирается имя файла/URI, содержащее `::`, если это не архив. [#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#68613](https://github.com/ClickHouse/ClickHouse/issues/68613): Исправлено [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026). Исключён обход неразрешённых аргументов табличной функции в `ReplaceTableNodeToDummyVisitor`. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#67854](https://github.com/ClickHouse/ClickHouse/issues/67854): Исправлено [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026). Исключён обход неразрешённых аргументов табличной функции в `ReplaceTableNodeToDummyVisitor`. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#68278](https://github.com/ClickHouse/ClickHouse/issues/68278): Исправлена вставка в движки потокового типа (Kafka, RabbitMQ, NATS) через HTTP-интерфейс. [#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#68040](https://github.com/ClickHouse/ClickHouse/issues/68040): Исправлено создание представления с рекурсивным CTE. [#67587](https://github.com/ClickHouse/ClickHouse/pull/67587) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#68038](https://github.com/ClickHouse/ClickHouse/issues/68038): Исправлен сбой в `percent_rank`. Тип рамки окна по умолчанию для `percent_rank` изменён на `range unbounded preceding and unbounded following`. Теперь учитывается рамка окна по умолчанию для `IWindowFunction`, и оконные функции без явного определения рамки окна в SQL могут корректно распределяться по разным `WindowTransfomer`. [#67661](https://github.com/ClickHouse/ClickHouse/pull/67661) ([lgbo](https://github.com/lgbo-ustc)).
* Бэкпортировано в [#67713](https://github.com/ClickHouse/ClickHouse/issues/67713): Исправлена перезагрузка SQL UDF с UNION. Ранее после перезапуска сервера UDF могла стать некорректной. [#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#67840](https://github.com/ClickHouse/ClickHouse/issues/67840): Исправлено возможное переполнение стека в функции `JSONMergePatch`. Эта функция была переименована с `jsonMergePatch` в `JSONMergePatch`, поскольку прежнее имя было неверным. Прежнее имя по-прежнему сохранено для совместимости. Улучшена диагностика ошибок в функции. Это закрывает [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304). [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#67995](https://github.com/ClickHouse/ClickHouse/issues/67995): Добавлена проверка экспериментальных/подозрительных типов данных в ALTER ADD/MODIFY COLUMN. [#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#68224](https://github.com/ClickHouse/ClickHouse/issues/68224): Исправлен неверный результат `count()`, когда в предикате присутствует недетерминированная функция. [#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#68095](https://github.com/ClickHouse/ClickHouse/issues/68095): Исправлен расчёт максимального soft limit для числа потоков в контейнерных средах, где количество доступных CPU ограничено. [#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#68126](https://github.com/ClickHouse/ClickHouse/issues/68126): Исправлена логика пропуска незатронутых частей в мутациях с новым анализатором. Ранее при включенном анализаторе данные в части могли быть переписаны мутацией, даже если, согласно предикату, мутация не затрагивала эту часть. [#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#68223](https://github.com/ClickHouse/ClickHouse/issues/68223): Исправлено разыменование указателя NULL, вызванное специально сформированным запросом и приводившее к сбою сервера через hopEnd, hopStart, tumbleEnd и tumbleStart. [#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* Бэкпортировано в [#68175](https://github.com/ClickHouse/ClickHouse/issues/68175): Удалена некорректная оптимизация, убирающая сортировку в подзапросах, использующих `OFFSET`. Исправляет [#67906](https://github.com/ClickHouse/ClickHouse/issues/67906). [#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)).
* Бэкпортировано в [#68341](https://github.com/ClickHouse/ClickHouse/issues/68341): Попытка устранить сбой Postgres при отмене запроса. [#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#68398](https://github.com/ClickHouse/ClickHouse/issues/68398): Исправлено отсутствие режима sync replica в запросе `SYSTEM SYNC REPLICA`. [#68326](https://github.com/ClickHouse/ClickHouse/pull/68326) ([Duc Canh Le](https://github.com/canhld94)).
* Бэкпортировано в [#68669](https://github.com/ClickHouse/ClickHouse/issues/68669): исправлены ошибки `LOGICAL_ERROR`, возникавшие при применении функций `sipHash64Keyed`, `sipHash128Keyed` или `sipHash128ReferenceKeyed` к пустым массивам или кортежам. [#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)).
