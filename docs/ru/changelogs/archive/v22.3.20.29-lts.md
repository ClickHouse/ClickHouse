<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#46979](https://github.com/ClickHouse/ClickHouse/issues/46979): `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` теперь применяется ко всем репликам, поскольку `ALTER TABLE t MOVE` не реплицируется. [#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Исправлена некорректная рекурсия псевдонимов в QueryNormalizer [#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* Исправлены арифметические операции при оптимизации агрегатных вычислений [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* Исправлен отчёт MSan в функции `maxIntersections` [#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлены неверные результаты некоторых LIKE-поисков, когда шаблон LIKE содержит экранированные символы, которые не должны экранироваться [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
* Исправлена возможная взаимная блокировка в QueryStatus [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="not-for-changelog-insignificant">
  #### НЕ ДЛЯ ЖУРНАЛА ИЗМЕНЕНИЙ / НЕЗНАЧИТЕЛЬНЫЕ
</div>

* Обновлена типизация для новой версии PyGithub [#47123](https://github.com/ClickHouse/ClickHouse/pull/47123) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Добавлен ручной trigger для workflow релиза [#47302](https://github.com/ClickHouse/ClickHouse/pull/47302) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Добавлен защитный механизм для веток бэкпорта без созданного PR [#47760](https://github.com/ClickHouse/ClickHouse/pull/47760) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Существующие ревью перезаписываются только корректными значениями Reviews.STATES [#47789](https://github.com/ClickHouse/ClickHouse/pull/47789) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Короткий `return` перенесён перед большим block, улучшено логирование [#47822](https://github.com/ClickHouse/ClickHouse/pull/47822) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Исправлена tsan-ошибка lock-order-inversion [#47953](https://github.com/ClickHouse/ClickHouse/pull/47953) ([Kruglov Pavel](https://github.com/Avogar)).
