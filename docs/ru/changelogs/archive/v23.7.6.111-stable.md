* Бэкпортировано в [#54285](https://github.com/ClickHouse/ClickHouse/issues/54285): параметр `allow_remove_stale_moving_parts` включён по умолчанию. [#54260](https://github.com/ClickHouse/ClickHouse/pull/54260) ([vdimir](https://github.com/vdimir)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#55291](https://github.com/ClickHouse/ClickHouse/issues/55291): Ресурс с исходным кодом, включая подмодули, теперь собирается в специальной задаче сборки для Darwin. Его можно использовать для сборки ClickHouse без checkout подмодулей. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Бэкпортировано в [#54705](https://github.com/ClickHouse/ClickHouse/issues/54705): `changed_images.json` дополнен последним тегом из master для образов, которые не были изменены в pull request. [#54369](https://github.com/ClickHouse/ClickHouse/pull/54369) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#54683](https://github.com/ClickHouse/ClickHouse/issues/54683): Собирать и загружать их при каждом push нецелесообразно. [#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#55407](https://github.com/ClickHouse/ClickHouse/issues/55407): Решена проблема с запуском автономного clickhouse-keeper из пакета clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#55723](https://github.com/ClickHouse/ClickHouse/issues/55723): Исправлен Python-скрипт проверки integration: теперь он использует URL API gh; также добавлен Readme для CI-тестов. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
