<div id="clickhouse-release-v206215-prestable-fixme-as-compared-to-v20513833-prestable">
  ### Релиз ClickHouse v20.6.2.15-prestable FIXME по сравнению с v20.5.1.3833-prestable
</div>

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* `clickhouse-local` теперь по умолчанию использует собственный временный каталог данных вместо текущего каталога, как раньше. При необходимости каталог данных можно явно указать с помощью параметра `-- --path`. [#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена поддержка `Alter table drop replica replica_name`. Это исправляет [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* Добавлен новый формат частей in-memory в таблицах семейства `MergeTree`, который хранит данные в памяти. На диск части записываются при первом слиянии. Часть будет создана в формате in-memory, если ее размер в строках или байтах меньше пороговых значений `min_rows_for_compact_part` и `min_bytes_for_compact_part`. Также доступна опциональная поддержка журнала упреждающей записи (Write-Ahead-Log), включенная по умолчанию и управляемая настройкой `in_memory_parts_enable_wal`. [#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* Добавлен комбинатор -Distinct для агрегатных функций. [#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* Добавлена поддержка движка таблицы mongo(host:port, database, collection, user, password). [#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* Добавлено хранилище RabbitMQ. [#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлены настройки для отправки отчетов о сбоях команде разработки ClickHouse через [Sentry](https://sentry.io) по явному включению. [#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* Добавлен ORCBlockOutputFormat. [#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлена настройка `max_thread_pool_size` для изменения максимального числа потоков в Global Thread Pool. [#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* Начальная реализация запроса `EXPLAIN`. Синтаксис: `EXPLAIN SELECT ...`. Это исправляет [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118). [#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Пути в метаданных S3 сделаны относительными, что упрощает обработку blob-объектов S3. [#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Добавлена поддержка ввода/вывода UUID в Avro. [#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Добавлен движок таблицы MongoDB только для чтения. Позволяет читать плоские поля (примитивные типы, не вложенные). [#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* Добавлена настройка для полей, отсутствующих в схеме Avro. [#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Добавлена функция `parseDateTimeBestEffortUS`. [#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 Поддержка ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST. [#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена функция initializedAggregation для инициализации агрегации по одному значению. [#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* Добавлена поддержка RIGHT и FULL JOIN с `set join_algorithm=partial_merge`. Поддерживается только strictness ALL (ANY, SEMI, ANTI, ASOF не поддерживаются). [#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* Реализован оператор ILIKE, аналогичный PostgreSQL, для [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710). [#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Разрешено использовать direct&#95;io и mmap&#95;io для вторичных индексов, если заданы настройки `min_bytes_to_use_direct_io` или `min_bytes_to_use_mmap_io`. [#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлена оценка количества меток при чтении из MergeTree. Это необходимо для корректной обработки настроек `merge_tree_max_rows_to_use_cache`, `merge_tree_max_bytes_to_use_cache`, `merge_tree_min_rows_for_concurrent_read`, `merge_tree_min_bytes_for_concurrent_read`, `merge_tree_min_rows_for_seek`, `merge_tree_min_bytes_for_seek`. Теперь настройка `min_bytes_to_use_mmap_io` также применяется при чтении индекса и компактных частей в семействе движков таблиц MergeTree. [#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлена регрессия производительности, появившаяся примерно в v19.3: &quot;[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) Index not used for IN operator with literals&quot;. [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).
* Удаляются инъективные функции внутри `uniq*()`, если `set optimize_injective_functions_inside_uniq=1`. [#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)).

<div id="improvement">
  #### Улучшения
</div>

* Добавлена возможность задавать количество ошибок, игнорируемых при выборе реплик (`distributed_replica_error_ignore`). [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* Улучшена производительность &#39;ORDER BY&#39; и &#39;GROUP BY&#39; для префикса ключа сортировки. [#11696](https://github.com/ClickHouse/ClickHouse/pull/11696) ([Anton Popov](https://github.com/CurtizJ)).
* * Добавлен `optimize_skip_unused_shards_nesting` (позволяет управлять уровнем вложенности при оптимизации пропуска неиспользуемых сегментов) - Добавлен `force_skip_optimize_shards_nesting` (позволяет управлять уровнем вложенности при проверке того, были ли пропущены сегменты) - Объявлен устаревшим `force_optimize_skip_unused_shards_no_nested` (вместо него следует использовать `force_skip_optimize_shards_nesting`) - `optimize_skip_unused_shards` отключён, если `sharding&#95;key` содержит недетерминированную функцию (то есть `rand()`, обратите внимание, что это ничего не меняет для INSERT). [#11715](https://github.com/ClickHouse/ClickHouse/pull/11715) ([Azat Khuzhin](https://github.com/azat)).
* Добавлена мультиверсионность метаданных для хранилищ без блокировок структуры. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* Слегка ослаблена проверка строки подключения ODBC. Если hostname или username содержит только буквенно-цифровые символы, а также `.` и `-`, не заключайте его в фигурные скобки. Это необходимо, поскольку некоторые драйверы ODBC (например, PostgreSQL) не понимают hostname, заключённый в фигурные скобки. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка разбора UUID без разделителей (во многих реализациях разделители всегда удаляются, что упрощает запись данных для пользователей). [#11856](https://github.com/ClickHouse/ClickHouse/pull/11856) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена поддержка модификаторов `SIGNED` и `UNSIGNED` для стандартных целочисленных типов (`BIGINT`, `INT`, ...) для совместимости с MySQL. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Разрешено использовать `sumWithOverflow` как `SimpleAggregateFunction`. Закрывает [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053). [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).

* Переписан код оптимизации `optimize_arithmetic_operations_in_aggregate_functions`. [#11899](https://github.com/ClickHouse/ClickHouse/pull/11899) ([Artem Zuikov](https://github.com/4ertus2)).
* Улучшена конкатенация путей и исправлены пути с двойными слешами за счёт использования std::filesystem::path вместо std::string в `DatabaseOrdinary.cpp`. [#11900](https://github.com/ClickHouse/ClickHouse/pull/11900) ([Bharat Nallan](https://github.com/bharatnc)).
