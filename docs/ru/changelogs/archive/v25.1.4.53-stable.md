<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#75990](https://github.com/ClickHouse/ClickHouse/issues/75990): Было обнаружено, что управление параллелизмом может приводить к несправедливому распределению CPU между операциями INSERT и SELECT. Когда все слоты CPU безусловно выделяются (без конкуренции) операциям INSERT с `max_threads` = 1, операции SELECT с высокими значениями `max_threads` работают медленно, так как фактически используют только один поток. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#75918](https://github.com/ClickHouse/ClickHouse/issues/75918): Добавлена прямая поддержка `s3.endpoint` из конфига каталога в `DatabaseIceberg`. Закрывает [#74558](https://github.com/ClickHouse/ClickHouse/issues/74558). [#75375](https://github.com/ClickHouse/ClickHouse/pull/75375) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#75846](https://github.com/ClickHouse/ClickHouse/issues/75846): Добавлены проверки и логирование для расшифровки и распаковки. [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#75705](https://github.com/ClickHouse/ClickHouse/issues/75705): Для совместимости отключена отправка настроек с сервера клиенту (`send_settings_to_client=false`) (позже эта возможность будет заново реализована как настройка клиента для более удобного использования). [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#75801](https://github.com/ClickHouse/ClickHouse/issues/75801): Добавлен конфиг `memory_worker_correct_memory_tracker`, который позволяет периодически корректировать внутренний трекер памяти по информации из разных источников, считываемой в фоновом потоке. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#76070](https://github.com/ClickHouse/ClickHouse/issues/76070): Добавлена метрика `MemoryTrackingUncorrected`, показывающая значение внутреннего глобального трекера памяти, не скорректированного по RSS. [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)

* Бэкпортировано в [#75612](https://github.com/ClickHouse/ClickHouse/issues/75612): обеспечена корректная передача настроек формата Native при взаимодействии клиента и сервера. [#73924](https://github.com/ClickHouse/ClickHouse/pull/73924) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75560](https://github.com/ClickHouse/ClickHouse/issues/75560): исправлен сбой при выполнении запроса `INSERT INTO SELECT` через интерфейс PostgreSQL на macOS (issue [#72938](https://github.com/ClickHouse/ClickHouse/issues/72938)). [#74231](https://github.com/ClickHouse/ClickHouse/pull/74231) ([Artem Yurov](https://github.com/ArtemYurov)).
* Бэкпортировано в [#75779](https://github.com/ClickHouse/ClickHouse/issues/75779): Keeper: исправлен logical&#95;error, возникавший, если соединение разрывалось до его установления. [#74844](https://github.com/ClickHouse/ClickHouse/pull/74844) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#76085](https://github.com/ClickHouse/ClickHouse/issues/76085): исправлена обработка null-safe JOIN для типа данных LowCardinality Nullable. Ранее `JOIN ON` со сравнением null-safe, таким как `IS NOT DISTINCT FROM`, `<=>`, `a IS NULL AND b IS NULL OR a == b`, работал некорректно со столбцами LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#75572](https://github.com/ClickHouse/ClickHouse/issues/75572): исправление Keeper: предотвращена запись в поврежденные changelog при откате журналов. [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#75587](https://github.com/ClickHouse/ClickHouse/issues/75587): замаскированы credentials движка таблицы azureblobstorage. [#75319](https://github.com/ClickHouse/ClickHouse/pull/75319) ([Garrett Thomas](https://github.com/garrettthomaskth)).
* Бэкпортировано в [#75748](https://github.com/ClickHouse/ClickHouse/issues/75748): исправлен сбой в кэше схем Protobuf, который может возникать при выводе в формате Protobuf и параллельном выполнении запроса `SYSTEM DROP FORMAT SCHEMA CACHE`. [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75425](https://github.com/ClickHouse/ClickHouse/issues/75425): скрыта чувствительная информация для табличных функций и движков таблиц `icebergS3`, `icebergAzure`. [#75378](https://github.com/ClickHouse/ClickHouse/pull/75378) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#76100](https://github.com/ClickHouse/ClickHouse/issues/76100): исправлена возможная ошибка `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes`, возникающая при использовании подстолбцов JSON типа Array в JOIN по distributed таблицам. [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75858](https://github.com/ClickHouse/ClickHouse/issues/75858): исправлено взаимодействие между allow&#95;feature&#95;tier и настройкой compatibility для MergeTree. [#75635](https://github.com/ClickHouse/ClickHouse/pull/75635) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#75896](https://github.com/ClickHouse/ClickHouse/issues/75896): исправлены редкие сбои при чтении из таблицы `MergeTree` после нескольких асинхронных запросов `RENAME` (с `alter_sync = 0`) между столбцами разных типов. [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#75827](https://github.com/ClickHouse/ClickHouse/issues/75827): исправлено разыменование нулевого указателя в `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#75838](https://github.com/ClickHouse/ClickHouse/issues/75838): исправлено чтение неинициализированной памяти в функции `translate`. Закрывает [#75592](https://github.com/ClickHouse/ClickHouse/issues/75592). [#75794](https://github.com/ClickHouse/ClickHouse/pull/75794) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#75998](https://github.com/ClickHouse/ClickHouse/issues/75998): исправлена ошибка, из-за которой таблицы с неявно добавленными min-max индексами нельзя было скопировать в новую таблицу (issue [#75677](https://github.com/ClickHouse/ClickHouse/issues/75677)). [#75877](https://github.com/ClickHouse/ClickHouse/pull/75877) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
