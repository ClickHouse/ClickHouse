<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#65096](https://github.com/ClickHouse/ClickHouse/issues/65096): параметр `allow_experimental_join_condition` был по ошибке помечен как важный, из-за чего распределённые запросы в кластере со смешанными версиями могли выполняться некорректно. [#65008](https://github.com/ClickHouse/ClickHouse/pull/65008) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#65132](https://github.com/ClickHouse/ClickHouse/issues/65132): образ `unit-test` уменьшен в несколько раз. [#65102](https://github.com/ClickHouse/ClickHouse/pull/65102) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#64729](https://github.com/ClickHouse/ClickHouse/issues/64729): Исправлены запросы `CREATE TABLE AS` для таблиц с выражениями по умолчанию. [#64455](https://github.com/ClickHouse/ClickHouse/pull/64455) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#65061](https://github.com/ClickHouse/ClickHouse/issues/65061): Исправлены ошибки `Expression nodes list expected 1 projection names` и `Unknown expression or identifier` в запросах с псевдонимами для `GLOBAL IN.` Исправляет [#64445](https://github.com/ClickHouse/ClickHouse/issues/64445). [#64517](https://github.com/ClickHouse/ClickHouse/pull/64517) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#65088](https://github.com/ClickHouse/ClickHouse/issues/65088): Исправлено удаление выражений `WHERE` и `PREWHERE`, которые всегда имеют значение true (для нового analyzer). Исправляет [#64575](https://github.com/ClickHouse/ClickHouse/issues/64575). [#64695](https://github.com/ClickHouse/ClickHouse/pull/64695) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#64944](https://github.com/ClickHouse/ClickHouse/issues/64944): Исправлен OrderByLimitByDuplicateEliminationVisitor в подзапросах. [#64766](https://github.com/ClickHouse/ClickHouse/pull/64766) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#64873](https://github.com/ClickHouse/ClickHouse/issues/64873): Исправлено возможное некорректное отслеживание памяти в нескольких типах запросов: запросах, читающих данные из S3, запросах по HTTP-протоколу и асинхронных вставках. [#64844](https://github.com/ClickHouse/ClickHouse/pull/64844) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#64984](https://github.com/ClickHouse/ClickHouse/issues/64984): Исправлена ошибка `Block structure mismatch` для запросов, читающих с `PREWHERE` из materialized view, если в materialized view есть столбцы типов, отличных от столбцов исходной таблицы. Исправляет [#64611](https://github.com/ClickHouse/ClickHouse/issues/64611). [#64855](https://github.com/ClickHouse/ClickHouse/pull/64855) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#64976](https://github.com/ClickHouse/ClickHouse/issues/64976): Исправлен редкий сбой, возникающий, когда у таблицы есть TTL с подзапросом + replicated database + параллельные реплики + analyzer. Это действительно очень редкий случай, но, пожалуйста, не используйте TTL с подзапросами. [#64858](https://github.com/ClickHouse/ClickHouse/pull/64858) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#65074](https://github.com/ClickHouse/ClickHouse/issues/65074): Исправлен запрос `ALTER MODIFY COMMENT`, который перестал работать для parameterized VIEWs в [https://github.com/ClickHouse/ClickHouse/pull/54211](https://github.com/ClickHouse/ClickHouse/pull/54211). [#65031](https://github.com/ClickHouse/ClickHouse/pull/65031) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#65179](https://github.com/ClickHouse/ClickHouse/issues/65179): Исправлена ошибка `Unknown expression identifier` для удалённых запросов с `INTERPOLATE (alias)` (новый analyzer). Исправляет [#64636](https://github.com/ClickHouse/ClickHouse/issues/64636). [#65090](https://github.com/ClickHouse/ClickHouse/pull/65090) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#65163](https://github.com/ClickHouse/ClickHouse/issues/65163): Исправлен вынос арифметических операций из aggregation. В новом analyzer оптимизация применялась только один раз. Часть [#62245](https://github.com/ClickHouse/ClickHouse/issues/62245). [#65104](https://github.com/ClickHouse/ClickHouse/pull/65104) ([Dmitry Novik](https://github.com/novikd)).

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">

[#64769](https://github.com/ClickHouse/ClickHouse/pull/64769) ([pufit](https://github.com/pufit)).
