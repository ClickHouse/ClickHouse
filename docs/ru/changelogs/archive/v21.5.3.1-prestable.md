<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#23818](https://github.com/ClickHouse/ClickHouse/issues/23818): Исправлено аварийное завершение, когда `PREWHERE` и фильтр политики доступа на уровне строк одновременно применяются при пустом результате. [#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#23798](https://github.com/ClickHouse/ClickHouse/issues/23798): Исправлена проблема с тайм-аутом соединения для удалённого JDBC bridge. Закрывает [#9609](https://github.com/ClickHouse/ClickHouse/issues/9609). [#23771](https://github.com/ClickHouse/ClickHouse/pull/23771) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#23815](https://github.com/ClickHouse/ClickHouse/issues/23815): Исправлено, что `CLEAR COLUMN` не работает, если на него ссылается materialized view. Закрывает [#23764](https://github.com/ClickHouse/ClickHouse/issues/23764). [#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
* Бэкпортировано в [#23832](https://github.com/ClickHouse/ClickHouse/issues/23832): Исправлена ошибка `Can't initialize pipeline with empty pipe` для запросов с `GLOBAL IN/JOIN` и `use_hedged_requests`. Исправляет [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431). [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#23927](https://github.com/ClickHouse/ClickHouse/issues/23927): Исправлена первоначальная загрузка поля обновления для составного ключа в HashedDictionary. Закрывает [#23800](https://github.com/ClickHouse/ClickHouse/issues/23800). [#23824](https://github.com/ClickHouse/ClickHouse/pull/23824) ([Maksim Kita](https://github.com/kitaisreal)).
