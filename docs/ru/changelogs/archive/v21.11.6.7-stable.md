<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#32254](https://github.com/ClickHouse/ClickHouse/issues/32254): Исправлено пропускание столбцов при записи в Protobuf. Этот PR исправляет [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160), см. комментарий к [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318. [#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)).
* Бэкпортировано в [#32345](https://github.com/ClickHouse/ClickHouse/issues/32345): Исправлена ошибка при удалении ненужных столбцов в подзапросе. Если в запросе без GROUP BY есть агрегатная функция, не удалять её, даже если она не нужна. [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#32152](https://github.com/ClickHouse/ClickHouse/issues/32152): Исправлено аварийное завершение, возникавшее при использовании функции `dictGet` с типом для атрибута словаря, если тип — `Nullable`. Исправляет [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980). [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32298](https://github.com/ClickHouse/ClickHouse/issues/32298): Исправлено аварийное завершение рекурсивных пользовательских функций. Закрывает [#30856](https://github.com/ClickHouse/ClickHouse/issues/30856). [#31820](https://github.com/ClickHouse/ClickHouse/pull/31820) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32148](https://github.com/ClickHouse/ClickHouse/issues/32148): Исправлена ошибка `Directory ... already exists and is not empty` при detach части. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32212](https://github.com/ClickHouse/ClickHouse/issues/32212): Исправлен `CAST` из `Nullable` с `cast_keep_nullable` (ранее возникала ошибка `PARAMETER_OUT_OF_BOUND`, например для `toUInt32OrDefault(toNullable(toUInt32(1)))`). [#32080](https://github.com/ClickHouse/ClickHouse/pull/32080) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#32283](https://github.com/ClickHouse/ClickHouse/issues/32283): В Dictionaries исправлены случаи, когда `{condition}` не работает для пользовательских запросов к базе данных. [#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32482](https://github.com/ClickHouse/ClickHouse/issues/32482): Исправлен разбор `APPLY lambda`, который мог приводить к аварийному завершению клиента или сервера. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#32217](https://github.com/ClickHouse/ClickHouse/issues/32217): Число активных реплик могло определяться неверно при вставке с quorum, если настройка `replicated_can_become_leader` отключена на некоторых репликах. Это исправлено. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32311](https://github.com/ClickHouse/ClickHouse/issues/32311): Идентификаторы XML-словарей, используемые в запросе CREATE TABLE, при обновлении до более новой версии могут квалифицироваться через `default_database`. Закрывает [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963). [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#32354](https://github.com/ClickHouse/ClickHouse/issues/32354): Исправлено аварийное завершение с SIGFPE в агрегатной функции `avgWeighted` с аргументом `Decimal`. Исправляет [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#32392](https://github.com/ClickHouse/ClickHouse/issues/32392): Исправлены запросы `ALTER ... MATERIALIZE COLUMN ...` в случае, когда тип данных выражения по умолчанию не совпадает с типом данных столбца. [#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#32418](https://github.com/ClickHouse/ClickHouse/issues/32418): Исправлено поведение, при котором мутации, которым нечего делать, зависали (при включенной настройке `empty_result_for_aggregation_by_empty_set`). [#32358](https://github.com/ClickHouse/ClickHouse/pull/32358) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
