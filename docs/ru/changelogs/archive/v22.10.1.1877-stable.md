<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Переименованы команды кэша: `show caches` -&gt; `show filesystem caches`, `describe cache` -&gt; `describe filesystem cache`. [#41508](https://github.com/ClickHouse/ClickHouse/pull/41508) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Удалена поддержка секции `WITH TIMEOUT` для `LIVE VIEW`. Закрывает [#40557](https://github.com/ClickHouse/ClickHouse/issues/40557). [#42173](https://github.com/ClickHouse/ClickHouse/pull/42173) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Новая возможность
</div>

* В ClickHouse добавлена поддержка кода на Rust на примере библиотеки хеширования BLAKE3. [#33435](https://github.com/ClickHouse/ClickHouse/pull/33435) ([BoloniniD](https://github.com/BoloniniD)).
* Добавлена первоначальная реализация Kusto Query Language (MVP). [#37961](https://github.com/ClickHouse/ClickHouse/pull/37961) ([Yong Wang](https://github.com/kashwy)).
* * Реализована возможность ограничивать объём временных данных, хранящихся на диске, с помощью настроек `max_temporary_data_on_disk_size_for_user`/`max_temporary_data_on_disk_size_for_query`. [#40893](https://github.com/ClickHouse/ClickHouse/pull/40893) ([Vladimir C](https://github.com/vdimir)).
* Добавлена поддержка хеширования целых чисел Java в `javaHash`. [#41131](https://github.com/ClickHouse/ClickHouse/pull/41131) ([JackyWoo](https://github.com/JackyWoo)).
* Этот PR добавляет поддержку внутренней сборки OpenSSL, аналогично подмодулю BoringSSL. Для выбора между BoringSSL и OpenSSL используется флаг сборки ENABLE&#95;CH&#95;BUNDLE&#95;BORINGSSL. По умолчанию используется внутренняя сборка BoringSSL. [#41142](https://github.com/ClickHouse/ClickHouse/pull/41142) ([MeenaRenganathan22](https://github.com/MeenaRenganathan22)).
* Добавлена компонуемая конфигурация протокола. [#41198](https://github.com/ClickHouse/ClickHouse/pull/41198) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Добавлена поддержка OpenTelemetry для DDL с предложением ON CLUSTER (требуется, чтобы `distributed_ddl_entry_format_version` было установлено в 4). [#41484](https://github.com/ClickHouse/ClickHouse/pull/41484) ([Frank Chen](https://github.com/FrankChen021)).
* Добавлена настройка `format_json_object_each_row_column_for_object_name`, чтобы записывать/разбирать имя объекта как значение столбца в формате JSONObjectEachRow. [#41703](https://github.com/ClickHouse/ClickHouse/pull/41703) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлены функции кодирования/декодирования Morton Coding (ZCurve). [#41753](https://github.com/ClickHouse/ClickHouse/pull/41753) ([Constantine Peresypkin](https://github.com/pkit)).
* Реализована поддержка различных двоичных форматов UUID, включая два наиболее распространённых: стандартный big-endian и смешанный порядок байтов Microsoft, как указано в [RFC 4122](https://datatracker.ietf.org/doc/html/rfc4122#section-4.1.1). [#42108](https://github.com/ClickHouse/ClickHouse/pull/42108) ([ltrk2](https://github.com/ltrk2)).
* Добавлена агрегатная функция `analysisOfVariance` (`anova`) для выполнения статистического теста по нескольким группам наблюдений с нормальным распределением, чтобы определить, одинаково ли среднее значение у всех групп. Исходный PR [#37872](https://github.com/ClickHouse/ClickHouse/issues/37872). [#42131](https://github.com/ClickHouse/ClickHouse/pull/42131) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлена поддержка `SET setting_name = DEFAULT`. [#42187](https://github.com/ClickHouse/ClickHouse/pull/42187) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* * Добавлены URL-функции, соответствующие RFC. В их число входят: `cutToFirstSignificantSubdomainCustomRFC`, `cutToFirstSignificantSubdomainCustomWithWWWRFC`, `cutToFirstSignificantSubdomainRFC`, `cutToFirstSignificantSubdomainWithWWWRFC`, `domainRFC`, `domainWithoutWWWRFC`, `firstSignificantSubdomainCustomRFC`, `firstSignificantSubdomainRFC`, `portRFC`, `topLevelDomainRFC`. [#42274](https://github.com/ClickHouse/ClickHouse/pull/42274) ([Quanfa Fu](https://github.com/dentiscalprum)).
* Добавлены функции (`randUniform`, `randNormal`, `randLogNormal`, `randExponential`, `randChiSquared`, `randStudentT`, `randFisherF`, `randBernoulli`, `randBinomial`, `randNegativeBinomial`, `randPoisson` ) для генерации случайных значений согласно указанным распределениям. Закрывает [#21834](https://github.com/ClickHouse/ClickHouse/issues/21834). [#42411](https://github.com/ClickHouse/ClickHouse/pull/42411) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Реализован парсер выражений с учётом приоритета операторов, чтобы устранить проблемы с переполнением стека и уменьшить требуемый размер стека. [#34892](https://github.com/ClickHouse/ClickHouse/pull/34892) ([Nikolay Degterinsky](https://github.com/evillique)).
* Оптимизация DISTINCT in order теперь использует свойства сортировки потоков данных. Это улучшение позволяет выполнять упорядоченное чтение для DISTINCT, где это применимо (раньше для этого требовалось указывать ORDER BY по столбцам из DISTINCT). [#41014](https://github.com/ClickHouse/ClickHouse/pull/41014) ([Igor Nikonov](https://github.com/devcrafter)).
* ColumnVector: оптимизирован индекс UInt8 с использованием AVX512VBMI. [#41247](https://github.com/ClickHouse/ClickHouse/pull/41247) ([Guo Wangyang](https://github.com/guowangy)).
* Эксперименты по производительности **SSB** (Star Schema Benchmark) на платформе ICX (Intel Xeon Platinum 8380 CPU, 80 ядер, 160 потоков) показывают, что это изменение может дать прирост среднего геометрического QPS по всем подслучаям в **2.95x** раза. [#41675](https://github.com/ClickHouse/ClickHouse/pull/41675) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* Исправлено замедление в JSONExtract с кортежами LowCardinality(String). [#41726](https://github.com/ClickHouse/ClickHouse/pull/41726) ([AlfVII](https://github.com/AlfVII)).
* В сборки AArch64 добавлены привилегии ldapr. Это поддерживается на инстансах Graviton 2+, Azure и GCP. В clang-15 это появилось лишь [недавно](https://github.com/llvm/llvm-project/commit/9609b5daffe9fd28d83d83da895abc5113f76c24). [#41778](https://github.com/ClickHouse/ClickHouse/pull/41778) ([Daniel Kutenin](https://github.com/danlark1)).
* Повышена производительность при сравнении строк, когда один из аргументов — пустая константная строка. [#41870](https://github.com/ClickHouse/ClickHouse/pull/41870) ([Jiebin Sun](https://github.com/jiebinn)).
* Оптимизирован insertFrom для ColumnAggregateFunction, чтобы в некоторых случаях совместно использовать aggregate state. [#41960](https://github.com/ClickHouse/ClickHouse/pull/41960) ([flynn](https://github.com/ucasfl)).
* Смягчён порог срабатывания &quot;Too many parts&quot;. Это закрывает [#6551](https://github.com/ClickHouse/ClickHouse/issues/6551). Теперь ClickHouse позволит иметь больше частей в партиции, если средний размер части достаточно велик (не менее 10 GiB). Это позволяет хранить до PB данных в одной партиции одной таблицы на одном сервере, что возможно при использовании дисковых полок или Объектного хранилища. [#42002](https://github.com/ClickHouse/ClickHouse/pull/42002) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Повышена эффективность записи в AzureBlobStorage (`max_single_part_upload_size` теперь учитывается вместо записи одного блока на каждый размер буфера). О неэффективности упоминалось в [#41754](https://github.com/ClickHouse/ClickHouse/issues/41754). [#42041](https://github.com/ClickHouse/ClickHouse/pull/42041) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Идентификаторы потоков в списке процессов и query&#95;log сделаны уникальными, чтобы избежать лишних накладных расходов. [#42180](https://github.com/ClickHouse/ClickHouse/pull/42180) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### Улучшения
</div>

* Добавлена новая инфраструктура для анализа и планирования запросов в рамках настройки `allow_experimental_analyzer`. [#31796](https://github.com/ClickHouse/ClickHouse/pull/31796) ([Maksim Kita](https://github.com/kitaisreal)).
* * Добавлена поддержка выражения `(EXPLAIN SELECT ...)` в подзапросе. Запросы вида `SELECT * FROM (EXPLAIN PIPELINE SELECT col FROM TABLE ORDER BY col)` стали допустимыми. [#40630](https://github.com/ClickHouse/ClickHouse/pull/40630) ([Vladimir C](https://github.com/vdimir)).
* Изменение `async_insert_max_data_size` или `async_insert_busy_timeout_ms` в рамках запроса сейчас не имеет смысла и ухудшает пользовательский опыт. Например, пользователь хочет выполнять вставку данных редко, но у него нет доступа к конфигурации сервера, чтобы изменить настройки по умолчанию. [#40668](https://github.com/ClickHouse/ClickHouse/pull/40668) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Встроенный Keeper теперь всегда запускается в фоновом режиме, что позволяет ClickHouse запускаться без достижения кворума. [#40991](https://github.com/ClickHouse/ClickHouse/pull/40991) ([Antonio Andelic](https://github.com/antonio2368)).
* Улучшено чтение из удалённых файловых систем: размер пула потоков для чтения и записи сделан настраиваемым. Закрывает [#41070](https://github.com/ClickHouse/ClickHouse/issues/41070). [#41011](https://github.com/ClickHouse/ClickHouse/pull/41011) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Повторное установление нового соединения в случае истечения срока действия предыдущего стало более быстрым. Ранее существовала задача, которая по умолчанию запускалась раз в минуту, поэтому таблица могла оставаться в состоянии только для чтения примерно столько же времени. [#41092](https://github.com/ClickHouse/ClickHouse/pull/41092) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлена поддержка всех комбинаций комбинаторов в версионировании WindowTransform/arratReduce*/initializeAggregation/aggregate functions. Ранее комбинаторы вроде `ForEach/Resample/Map` в этих местах не работали, и их использование приводило к исключению вида `State function ... inserts results into non-state column`. [#41107](https://github.com/ClickHouse/ClickHouse/pull/41107) ([Kruglov Pavel](https://github.com/Avogar)).
* Теперь проекции можно использовать с репликацией с нулевым копированием. [#41147](https://github.com/ClickHouse/ClickHouse/pull/41147) ([alesapin](https://github.com/alesapin)).
* * Добавлена функция tryDecrypt, которая возвращает NULL, если расшифровка завершается с ошибкой (например, при использовании неверного ключа), вместо того чтобы сгенерировать исключение. [#41206](https://github.com/ClickHouse/ClickHouse/pull/41206) ([Duc Canh Le](https://github.com/canhld94)).
* Добавлен столбец `unreserved_space` в таблицу `system.disks`, чтобы проверять, сколько места на каждом диске не занято резервированиями. [#41254](https://github.com/ClickHouse/ClickHouse/pull/41254) ([filimonov](https://github.com/filimonov)).
* Добавлена поддержка заголовков авторизации S3 из аргументов AST. [#41261](https://github.com/ClickHouse/ClickHouse/pull/41261) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Добавлена настройка &#39;allow&#95;implicit&#95;no&#95;password&#39;, которая запрещает создавать пользователя без пароля, если явно не указано &#39;IDENTIFIED WITH no&#95;password&#39;. [#41341](https://github.com/ClickHouse/ClickHouse/pull/41341) ([Nikolay Degterinsky](https://github.com/evillique)).
* keeper-improvement: добавлена поддержка загрузки снимков в S3. Информацию о S3 можно задать в `keeper_server.s3_snapshot`. [#41342](https://github.com/ClickHouse/ClickHouse/pull/41342) ([Antonio Andelic](https://github.com/antonio2368)).
* Добавлена поддержка MultiRead в Keeper и внутреннем клиенте ZooKeeper. [#41410](https://github.com/ClickHouse/ClickHouse/pull/41410) ([Antonio Andelic](https://github.com/antonio2368)).
* Добавлена поддержка сравнения типа Decimal с литералом с плавающей точкой в операторе IN. [#41544](https://github.com/ClickHouse/ClickHouse/pull/41544) ([liang.huang](https://github.com/lhuang09287750)).
* В конфигурации кэша теперь можно использовать значения размера в удобочитаемом формате. [#41688](https://github.com/ClickHouse/ClickHouse/pull/41688) ([Kseniia Sumarokova](https://github.com/kssenii)).
* В логгере ошибок для входных форматов путь к файлу теперь проверяется на атаки обхода каталогов. [#41694](https://github.com/ClickHouse/ClickHouse/pull/41694) ([Kruglov Pavel](https://github.com/Avogar)).
* ClickHouse мог кэшировать устаревшие DNS-записи в течение некоторого времени (по умолчанию 15 секунд), пока кэш не обновится асинхронно. В течение этого периода ClickHouse всё равно мог пытаться установить соединение и выдавать ошибки. Это поведение исправлено. [#41707](https://github.com/ClickHouse/ClickHouse/pull/41707) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Добавлен интерактивный поиск по истории с помощью утилиты наподобие fzf (fzf/sk) для `clickhouse-client`/`clickhouse-local` (обратите внимание, что для дополнительной настройки поведения можно использовать `FZF_DEFAULT_OPTS`/`SKIM_DEFAULT_OPTIONS`). [#41730](https://github.com/ClickHouse/ClickHouse/pull/41730) ([Azat Khuzhin](https://github.com/azat)).
* Для клиента при подключении к защищённому серверу с недействительным сертификатом продолжение теперь разрешено только с флагом &#39;--accept-certificate&#39;. [#41743](https://github.com/ClickHouse/ClickHouse/pull/41743) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Добавлена функция &quot;tryBase58Decode()&quot;, аналогичная существующей функции &quot;tryBase64Decode()&quot;. [#41824](https://github.com/ClickHouse/ClickHouse/pull/41824) ([Robert Schulze](https://github.com/rschu1ze)).
* Улучшены сообщения при замене партиции с другим primary key. Исправляет [#34798](https://github.com/ClickHouse/ClickHouse/issues/34798). [#41838](https://github.com/ClickHouse/ClickHouse/pull/41838) ([Salvatore](https://github.com/tbsal)).
* При запуске вместо команды `clickhouse su` снова используется `sudo -u`, чтобы учитывать ограничения из `/etc/security/limits.conf`. [#41847](https://github.com/ClickHouse/ClickHouse/pull/41847) ([Eugene Konkov](https://github.com/ekonkov)).

* Не сообщать об исключении TABLE&#95;IS&#95;DROPPED, чтобы пропускать таблицу, если она была только что удалена. [#41908](https://github.com/ClickHouse/ClickHouse/pull/41908) ([AlfVII](https://github.com/AlfVII)).
* Улучшена опция enable&#95;extended&#95;results&#95;for&#95;datetime&#95;functions: теперь для функций toStartOfDay, toStartOfHour, toStartOfFifteenMinutes, toStartOfTenMinutes, toStartOfFiveMinutes, toStartOfMinute и timeSlot она возвращает результаты типа DateTime64. [#41910](https://github.com/ClickHouse/ClickHouse/pull/41910) ([Roman Vasin](https://github.com/rvasin)).

Закрывает [#41389](https://github.com/ClickHouse/ClickHouse/issues/41389). Закрывает [#42206](https://github.com/ClickHouse/ClickHouse/issues/42206). [#41912](https://github.com/ClickHouse/ClickHouse/pull/41912) ([Kruglov Pavel](https://github.com/Avogar)).

* Теперь можно писать `countState(*)` аналогично `count(*)`. Это закрывает [#9338](https://github.com/ClickHouse/ClickHouse/issues/9338). [#41983](https://github.com/ClickHouse/ClickHouse/pull/41983) ([Amos Bird](https://github.com/amosbird)).

* Добавлена возможность указывать в конфигурации Sentry произвольную строку в качестве имени окружения для более удобных отчетов. [#42037](https://github.com/ClickHouse/ClickHouse/pull/42037) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

[#42040](https://github.com/ClickHouse/ClickHouse/pull/42040) ([Anton Popov](https://github.com/CurtizJ)).

* Добавлена поддержка методов lz4, bz2 и snappy в &#39;Accept-Encoding&#39;. [#42071](https://github.com/ClickHouse/ClickHouse/pull/42071) ([Nikolay Degterinsky](https://github.com/evillique)).

* Улучшен процесс восстановления устаревшей реплики для `ReplicatedMergeTree`. Если у потерянной реплики есть части, отсутствующие на здоровой реплике, но эти части должны появиться в будущем согласно очереди репликации здоровой реплики, то потерянная реплика сохранит такие части вместо их отсоединения. [#42134](https://github.com/ClickHouse/ClickHouse/pull/42134) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Добавлена поддержка BACKUP в S3 с исходной структурой path/data. [#42232](https://github.com/ClickHouse/ClickHouse/pull/42232) ([Azat Khuzhin](https://github.com/azat)).
* Добавлена возможность использовать arguments типа Date32 для функции date&#95;diff. Исправлена проблема в функции date&#95;diff при использовании arguments типа DateTime64, когда начальная дата находится до Unix epoch, а конечная дата — после Unix epoch. [#42308](https://github.com/ClickHouse/ClickHouse/pull/42308) ([Roman Vasin](https://github.com/rvasin)).
* При upload больших частей в minio операция &#39;Complete Multipart Upload&#39; может занимать много времени. Minio отправляет heartbeat-сигналы каждые 10 секунд (см. Но ClickHouse завершает операцию по тайм-ауту раньше, потому что тайм-аут отправки/получения по умолчанию [set](https://github.com/ClickHouse/ClickHouse/blob/cc24fcd6d5dfb67f5f66f5483e986bd1010ad9cf/src/IO/S3/PocoHTTPClient.cpp#L123) в 5 секунд.
