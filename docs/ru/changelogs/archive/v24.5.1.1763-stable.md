<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* &quot;inverted indexes&quot; были переименованы в &quot;full-text indexes&quot; — это менее техническое и более понятное для пользователей название. Это также меняет внутренние метаданные таблиц и ломает таблицы с существующими (экспериментальными) inverted indexes. Перед обновлением удалите такие индексы, а после обновления создайте их заново. [#62884](https://github.com/ClickHouse/ClickHouse/pull/62884) ([Robert Schulze](https://github.com/rschu1ze)).
* Использование функций `neighbor`, `runningAccumulate`, `runningDifferenceStartingWithFirstValue`, `runningDifference` устарело (так как оно подвержено ошибкам). Вместо них следует использовать оконные функции. Чтобы снова их включить, установите `allow_deprecated_functions=1`. [#63132](https://github.com/ClickHouse/ClickHouse/pull/63132) ([Nikita Taranov](https://github.com/nickitat)).
* Запросы к `system.columns` будут работать быстрее при большом количестве столбцов, если право `SHOW TABLES` не выдано для многих баз данных или таблиц. Обратите внимание: в предыдущих версиях, если выдали `SHOW COLUMNS` для отдельных столбцов, не выдавая `SHOW TABLES` для соответствующих таблиц, таблица `system.columns` покажет эти столбцы, а в новой версии она полностью пропустит такую таблицу. Удалены сообщения трассировочного лога &quot;Access granted&quot; и &quot;Access denied&quot;, которые замедляли запросы. [#63439](https://github.com/ClickHouse/ClickHouse/pull/63439) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Новая возможность
</div>

* Добавлена поддержка функции AzureBlobStorage в сервере ClickHouse для использования Azure Workload Identity при аутентификации в Azure Blob Storage. Если в конфигурации задан параметр `use_workload_identity`, для аутентификации используется [workload identity](https://github.com/Azure/azure-sdk-for-cpp/tree/main/sdk/identity/azure-identity#authenticate-azure-hosted-applications). [#57881](https://github.com/ClickHouse/ClickHouse/pull/57881) ([Vinay Suryadevara](https://github.com/vinay92-ch)).
* Добавлена пакетная загрузка в StorageEmbeddedRocksDB за счёт создания и загрузки SST-файла вместо использования встроенной в rocksdb memtable. Это помогает увеличить скорость импорта, особенно для длительных запросов вставки в таблицы StorageEmbeddedRocksDB. Также добавлены настройки таблиц `StorageEmbeddedRocksDB`. [#59163](https://github.com/ClickHouse/ClickHouse/pull/59163) ([Duc Canh Le](https://github.com/canhld94)).
* Теперь пользователь может обрабатывать CRLF в формате TSV с помощью настройки `input_format_tsv_crlf_end_of_line`. Закрывает [#56257](https://github.com/ClickHouse/ClickHouse/issues/56257). [#59747](https://github.com/ClickHouse/ClickHouse/pull/59747) ([Shaun Struwig](https://github.com/Blargian)).
* Добавлен формат Form для чтения/записи одной записи в формате application/x-www-form-urlencoded. [#60199](https://github.com/ClickHouse/ClickHouse/pull/60199) ([Shaun Struwig](https://github.com/Blargian)).
* Добавлена возможность сжатия в CROSS JOIN. [#60459](https://github.com/ClickHouse/ClickHouse/pull/60459) ([p1rattttt](https://github.com/p1rattttt)).
* Новая настройка `input_format_force_null_for_omitted_fields`, которая принудительно задаёт значения NULL для пропущенных полей. [#60887](https://github.com/ClickHouse/ClickHouse/pull/60887) ([Constantine Peresypkin](https://github.com/pkit)).
* Добавлена поддержка JOIN с условиями неравенства, в которых используются столбцы как из левой, так и из правой таблицы. Например, `t1.y < t2.y`. Для включения: `SET allow_experimental_join_condition = 1`. [#60920](https://github.com/ClickHouse/ClickHouse/pull/60920) ([lgbo](https://github.com/lgbo-ustc)).
* Ранее наше хранилище S3 и табличная функция S3 не поддерживали выборку из архивных файлов. Добавлено решение, позволяющее перебирать файлы внутри архивов в S3. [#62259](https://github.com/ClickHouse/ClickHouse/pull/62259) ([Daniil Ivanik](https://github.com/divanik)).
* Добавлена поддержка условной функции `clamp`. [#62377](https://github.com/ClickHouse/ClickHouse/pull/62377) ([skyoct](https://github.com/skyoct)).
* Добавлен формат вывода npy. [#62430](https://github.com/ClickHouse/ClickHouse/pull/62430) ([豪肥肥](https://github.com/HowePa)).
* Добавлены SQL-функции `generateUUIDv7`, `generateUUIDv7ThreadMonotonic`, `generateUUIDv7NonMonotonic` (с различными компромиссами между монотонностью и производительностью) для генерации UUID версии 7, то есть UUID на основе временной метки, со случайным компонентом. Также добавлена новая функция `UUIDToNum` для извлечения байтов из UUID и новая функция `UUIDv7ToDateTime` для извлечения компонента временной метки из UUID версии 7. [#62852](https://github.com/ClickHouse/ClickHouse/pull/62852) ([Alexey Petrunyaka](https://github.com/pet74alex)).
* Бэкпортировано в [#64307](https://github.com/ClickHouse/ClickHouse/issues/64307): реализован тип Dynamic, который позволяет хранить значения любого типа без необходимости заранее знать их все. Тип Dynamic доступен при настройке `allow_experimental_dynamic_type`. См.: [#54864](https://github.com/ClickHouse/ClickHouse/issues/54864). [#63058](https://github.com/ClickHouse/ClickHouse/pull/63058) ([Kruglov Pavel](https://github.com/Avogar)).
* В StorageEmbeddedRocksDB добавлена пакетная загрузка за счёт создания и загрузки SST-файла вместо использования встроенной memtable RocksDB. Это помогает повысить скорость импорта, особенно для длительно выполняющихся запросов вставки в таблицы StorageEmbeddedRocksDB. Также добавлены настройки таблиц StorageEmbeddedRocksDB. [#63324](https://github.com/ClickHouse/ClickHouse/pull/63324) ([Duc Canh Le](https://github.com/canhld94)).
* Raw теперь является синонимом TSVRaw. [#63394](https://github.com/ClickHouse/ClickHouse/pull/63394) ([Unalian](https://github.com/Unalian)).
* Добавлена возможность выполнять CROSS JOIN с использованием временного файла, если размер превышает лимиты. [#63432](https://github.com/ClickHouse/ClickHouse/pull/63432) ([p1rattttt](https://github.com/p1rattttt)).
* В Linux и macOS, если стандартный вывод программы перенаправлен в файл с расширением, обозначающим сжатие, используется соответствующий метод сжатия, а не отсутствие сжатия (что делает поведение похожим на `INTO OUTFILE` ). [#63662](https://github.com/ClickHouse/ClickHouse/pull/63662) ([v01dXYZ](https://github.com/v01dXYZ)).
* Изменено предупреждение о большом количестве присоединённых таблиц, чтобы различать таблицы, представления и словари. [#64180](https://github.com/ClickHouse/ClickHouse/pull/64180) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Пропускается слияние блоков недавно созданных проекций при операциях `INSERT`. [#59405](https://github.com/ClickHouse/ClickHouse/pull/59405) ([Nikita Taranov](https://github.com/nickitat)).
* Строковые функции XXXUTF8 обрабатываются «по-ASCII», если входные строки состоят только из ASCII-символов. Вдохновлено [https://github.com/apache/doris/pull/29799](https://github.com/apache/doris/pull/29799). Общее ускорение составляет 1.07x~1.62x. Обратите внимание, что в некоторых случаях пиковое потребление памяти также снизилось. [#61632](https://github.com/ClickHouse/ClickHouse/pull/61632) ([李扬](https://github.com/taiyang-li)).
* Улучшена производительность глоб-шаблонов с выбором (`{}`) в StorageS3. [#62120](https://github.com/ClickHouse/ClickHouse/pull/62120) ([Andrey Zvonov](https://github.com/zvonand)).
* HostResolver хранит каждый IP-адрес по нескольку раз. Если у удалённого хоста несколько IP-адресов и по какой-то причине (например, из-за правил межсетевого экрана) доступ к одним IP разрешён, а к другим запрещён, то как неуспешная помечается только первая запись с запрещённым IP, и при каждой попытке эти IP могут выбираться снова (и снова завершаться неудачей). Даже если это исправить, каждые 120 секунд DNS-кэш сбрасывается, и эти IP могут быть выбраны снова. [#62652](https://github.com/ClickHouse/ClickHouse/pull/62652) ([Anton Ivashkin](https://github.com/ianton-ru)).
* Добавлена новая настройка `prefer_merge_sort_block_bytes`, чтобы управлять использованием памяти и ускорить сортировку при слиянии в 2 раза, когда столбцов много. [#62904](https://github.com/ClickHouse/ClickHouse/pull/62904) ([LiuNeng](https://github.com/liuneng1994)).
* `clickhouse-local` будет запускаться быстрее. В предыдущих версиях он по ошибке не удалял временные директории. Теперь удаляет. Это закрывает [#62941](https://github.com/ClickHouse/ClickHouse/issues/62941). [#63074](https://github.com/ClickHouse/ClickHouse/pull/63074) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Микрооптимизации для нового анализатора. [#63429](https://github.com/ClickHouse/ClickHouse/pull/63429) ([Raúl Marín](https://github.com/Algunenano)).
* Анализ индексов будет работать, если `DateTime` сравнивается с `DateTime64`. Это закрывает [#63441](https://github.com/ClickHouse/ClickHouse/issues/63441). [#63443](https://github.com/ClickHouse/ClickHouse/pull/63443) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Анализ индексов будет работать, если `DateTime` сравнивается с `DateTime64`. Это закрывает [#63441](https://github.com/ClickHouse/ClickHouse/issues/63441). [#63532](https://github.com/ClickHouse/ClickHouse/pull/63532) ([Raúl Marín](https://github.com/Algunenano)).
* Индексы типа `set` немного ускорены (примерно в 1.5 раза) за счёт удаления лишнего мусора. [#64098](https://github.com/ClickHouse/ClickHouse/pull/64098) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
