<div id="clickhouse-release-v213172-lts-fixme-as-compared-to-v213165-lts">
  ### Релиз ClickHouse v21.3.17.2-lts FIXME по сравнению с v21.3.16.5-lts

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#28647](https://github.com/ClickHouse/ClickHouse/issues/28647): исправлена редкая ошибка в `DROP PART`, из-за которой может возникать ошибка `Unexpected merged part intersects drop range`. [#27807](https://github.com/ClickHouse/ClickHouse/pull/27807) ([alesapin](https://github.com/alesapin)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#28569](https://github.com/ClickHouse/ClickHouse/issues/28569): Исправлена ошибка, которая может приводить к ошибке `Existing table metadata in ZooKeeper differs in sorting key expression.` после ALTER `ReplicatedVersionedCollapsingMergeTree`. Исправляет [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515). [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#28857](https://github.com/ClickHouse/ClickHouse/issues/28857): Исправлено безобидное состояние гонки в ReplicatedMergeTreeQueue. Оно не должно быть заметно пользователю, но может приводить к трудноуловимым ошибкам. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#28995](https://github.com/ClickHouse/ClickHouse/issues/28995): Исправлено чтение подстолбцов из компактных частей. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#28929](https://github.com/ClickHouse/ClickHouse/issues/28929): Исправлены функции высшего порядка для работы с массивами (`SIGSEGV` для `arrayCompact`/`ILLEGAL_COLUMN` для `arrayDifference`/`arrayCumSumNonNegative`) с константными аргументами. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
