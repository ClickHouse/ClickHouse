<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#60640](https://github.com/ClickHouse/ClickHouse/issues/60640): Исправлена ошибка в параллельной оптимизации запросов с `FINAL`, которая в редких случаях могла приводить к некорректному результату. [#60041](https://github.com/ClickHouse/ClickHouse/pull/60041) ([Maksim Kita](https://github.com/kitaisreal)).
* Бэкпортировано в [#61085](https://github.com/ClickHouse/ClickHouse/issues/61085): Исключён расчёт скалярных подзапросов для `CREATE TABLE`. Исправляет [#59795](https://github.com/ClickHouse/ClickHouse/issues/59795) и [#59930](https://github.com/ClickHouse/ClickHouse/issues/59930). Попытка заново реализовать [https://github.com/ClickHouse/ClickHouse/pull/57855](https://github.com/ClickHouse/ClickHouse/pull/57855). [#60464](https://github.com/ClickHouse/ClickHouse/pull/60464) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#61332](https://github.com/ClickHouse/ClickHouse/issues/61332): Исправлена взаимная блокировка при параллельном парсинге, когда из-за ошибок пропускается большое количество строк. [#60516](https://github.com/ClickHouse/ClickHouse/pull/60516) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#61010](https://github.com/ClickHouse/ClickHouse/issues/61010): Исправлена проблема с `max_query_size` для составных операторов KQL, таких как mv-expand. Связано с [#59626](https://github.com/ClickHouse/ClickHouse/issues/59626). [#60534](https://github.com/ClickHouse/ClickHouse/pull/60534) ([Yong Wang](https://github.com/kashwy)).
* Бэкпортировано в [#61002](https://github.com/ClickHouse/ClickHouse/issues/61002): Уменьшено количество читаемых строк из `system.numbers`. Исправляет [#59418](https://github.com/ClickHouse/ClickHouse/issues/59418). [#60546](https://github.com/ClickHouse/ClickHouse/pull/60546) ([JackyWoo](https://github.com/JackyWoo)).
* Бэкпортировано в [#60629](https://github.com/ClickHouse/ClickHouse/issues/60629): Числовые подсказки для типов Date больше не выводятся. [#60577](https://github.com/ClickHouse/ClickHouse/pull/60577) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#60793](https://github.com/ClickHouse/ClickHouse/issues/60793): Исправлено переполнение буфера, которое может возникнуть, если злоумышленник заставит HTTP-сервер распаковывать данные с композицией кодеков и размером, вызывающим числовое переполнение. Также исправлено переполнение буфера, которое могло возникать внутри кодека NONE при некорректных входных данных. Об ошибке сообщила исследовательская команда TIANGONG через нашу [программу Bug Bounty](https://github.com/ClickHouse/ClickHouse/issues/38986). [#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#60785](https://github.com/ClickHouse/ClickHouse/issues/60785): Функции SQL/JSON могли читать неинициализированную память. Это закрывает [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017). Найдено с помощью fuzzer. [#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#60805](https://github.com/ClickHouse/ClickHouse/issues/60805): Не устанавливать пользовательские metadata-заголовки AWS `x-amz-meta-*` в вызовах UploadPart и CompleteMultipartUpload. [#60748](https://github.com/ClickHouse/ClickHouse/pull/60748) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)).
* Бэкпортировано в [#60822](https://github.com/ClickHouse/ClickHouse/issues/60822): Исправлен сбой в arrayEnumerateRanked. [#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#60843](https://github.com/ClickHouse/ClickHouse/issues/60843): Исправлен сбой при использовании input() в INSERT SELECT JOIN. Закрывает [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035). [#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#60919](https://github.com/ClickHouse/ClickHouse/issues/60919): Исправлен сбой при изменении значения настройки `allow_experimental_analyzer` в подзапросах. [#60770](https://github.com/ClickHouse/ClickHouse/pull/60770) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#60906](https://github.com/ClickHouse/ClickHouse/issues/60906): Предотвращена ошибка сегментации, если при чтении из S3 пропускается слишком много ключей. [#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#61307](https://github.com/ClickHouse/ClickHouse/issues/61307): Исправлено несколько ошибок в groupArraySorted. [#61203](https://github.com/ClickHouse/ClickHouse/pull/61203) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#61295](https://github.com/ClickHouse/ClickHouse/issues/61295): Keeper: исправлена динамическая перенастройка автономного бинарного файла. [#61233](https://github.com/ClickHouse/ClickHouse/pull/61233) ([Antonio Andelic](https://github.com/antonio2368)).
