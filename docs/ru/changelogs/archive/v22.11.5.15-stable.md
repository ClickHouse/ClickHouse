  #### Исправление ошибки (заметное пользователю некорректное поведение в официальном стабильном релизе)
</div>

* Бэкпортировано в [#44999](https://github.com/ClickHouse/ClickHouse/issues/44999): Ещё одно исправление ошибки `Cannot read all data`, которая могла возникать при чтении словаря `LowCardinality` из remote fs. Исправляет [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709). [#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#45552](https://github.com/ClickHouse/ClickHouse/issues/45552): Исправлено исключение `SELECT ... FROM system.dictionaries`, возникавшее при наличии словаря с некорректной структурой (например, с неверным типом в XML-конфиге). [#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
