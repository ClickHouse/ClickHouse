<div id="clickhouse-release-v21246-stable-fixme-as-compared-to-v212315-stable">

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#20510](https://github.com/ClickHouse/ClickHouse/issues/20510): Исправлено поведение, при котором в случае поврежденного JSON предпринималась попытка прочитать в память весь файл, что приводило к исключению аллокатора. Исправляет [#19719](https://github.com/ClickHouse/ClickHouse/issues/19719). [#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#20575](https://github.com/ClickHouse/ClickHouse/issues/20575): Добавлена проверка на использование табличной функции `view` в списке выражений с генерацией ошибки. Это исправляет [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342). [#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#20486](https://github.com/ClickHouse/ClickHouse/issues/20486): Исправлен `LOGICAL_ERROR` для `join_use_nulls=1`, когда JOIN содержит const из SELECT. [#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#20535](https://github.com/ClickHouse/ClickHouse/issues/20535): Исправлен бесконечный цикл при распространении псевдонимов WITH в подзапросы. Это исправляет [#20388](https://github.com/ClickHouse/ClickHouse/issues/20388). [#20476](https://github.com/ClickHouse/ClickHouse/pull/20476) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#20615](https://github.com/ClickHouse/ClickHouse/issues/20615): Добавлены корректные проверки при разборе имен каталогов для async INSERT (исправляет SIGSEGV). [#20498](https://github.com/ClickHouse/ClickHouse/pull/20498) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#20887](https://github.com/ClickHouse/ClickHouse/issues/20887): Исправлен подзапрос с UNION DISTINCT и оператором LIMIT. Закрывает [#20597](https://github.com/ClickHouse/ClickHouse/issues/20597). [#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)).
* Бэкпортировано в [#20993](https://github.com/ClickHouse/ClickHouse/issues/20993): Исправлено использование комбинатора `-Distinct` с комбинатором `-State` в агрегатных функциях. [#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#20987](https://github.com/ClickHouse/ClickHouse/issues/20987): Запрос `USE database;` не работал при подключении к ClickHouse server через клиент MySQL 5.7; это исправлено. Исправляет [#18926](https://github.com/ClickHouse/ClickHouse/issues/18926). [#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)).
