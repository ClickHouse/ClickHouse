<div id="clickhouse-release-v209614-stable-fixme-as-compared-to-v20955-stable">
  ### Релиз ClickHouse v20.9.6.14-stable FIXME в сравнении с v20.9.5.5-stable
</div>

<div id="improvement">
  #### Улучшения
</div>

* Выполнен бэкпорт в [#17030](https://github.com/ClickHouse/ClickHouse/issues/17030): добавлена возможность подключаться к защищённой конечной точке `clickhouse-server`, требующей SNI. Это возможно, когда `clickhouse-server` размещён за TLS-прокси. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#15678](https://github.com/ClickHouse/ClickHouse/issues/15678): запрос завершается быстрее в случае исключения. Выполнение на удалённых репликах отменяется, если происходит исключение. [#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#17105](https://github.com/ClickHouse/ClickHouse/issues/17105): исправляет [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574), [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) и сбой удалённого запроса при использовании агрегатной функции с суффиксом &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпортировано в [#16759](https://github.com/ClickHouse/ClickHouse/issues/16759): исправляет optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order при max&#95;threads&gt;0 и выражении в ORDER BY. [#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#16740](https://github.com/ClickHouse/ClickHouse/issues/16740): исправлен оператор `IN` для нескольких столбцов и Tuple при включенной настройке `transform_null_in`. Исправляет [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310). [#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#17023](https://github.com/ClickHouse/ClickHouse/issues/17023): исправлено аварийное завершение при использовании `any` без аргументов. Это для [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#16879](https://github.com/ClickHouse/ClickHouse/issues/16879): прерывать multipart-загрузку, если в WriteBufferFromS3 не было записано данных. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Бэкпортировано в [#16945](https://github.com/ClickHouse/ClickHouse/issues/16945): предотвращает аварийное завершение сервера ClickHouse при использовании TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17078](https://github.com/ClickHouse/ClickHouse/issues/17078): исправлена возможная ошибка `Illegal type of argument` для запросов с `ORDER BY`. Исправляет [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#17009](https://github.com/ClickHouse/ClickHouse/issues/17009): скрипт установки должен всегда создавать подкаталоги в папках config. Это актуально только для Docker build с пользовательским config. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17013](https://github.com/ClickHouse/ClickHouse/issues/17013): исправлено возможное аварийное завершение сервера после `ALTER TABLE ... MODIFY COLUMN ... NewType`, когда у `SELECT` есть выражение `WHERE` по изменяемому столбцу, а alter ещё не завершён. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#17037](https://github.com/ClickHouse/ClickHouse/issues/17037): повторно разрешать IP-адрес для `format_avro_schema_registry_url` в случае ошибок. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Бэкпортирован в [#17172](https://github.com/ClickHouse/ClickHouse/issues/17172): исправлена ошибка, из-за которой запросы с `ON CLUSTER` могли зависать навсегда для нелидерских таблиц ReplicatedMergeTree. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
