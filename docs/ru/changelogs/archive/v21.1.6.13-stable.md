<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#20637](https://github.com/ClickHouse/ClickHouse/issues/20637): Исправлена редкая ошибка, из-за которой некоторые реплицируемые операции (например, мутация) не могли обработать отдельные части после повреждения данных. Исправляет [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593). [#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#20573](https://github.com/ClickHouse/ClickHouse/issues/20573): Исправлен сбой, который мог произойти при получении неизвестного пакета из remove query (ошибка появилась в [#17868](https://github.com/ClickHouse/ClickHouse/issues/17868)). [#20547](https://github.com/ClickHouse/ClickHouse/pull/20547) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21005](https://github.com/ClickHouse/ClickHouse/issues/21005): Исправлена ошибка &quot;Empty task was returned from async task queue&quot; при отмене запроса. [#20881](https://github.com/ClickHouse/ClickHouse/pull/20881) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#21131](https://github.com/ClickHouse/ClickHouse/issues/21131): Исправлено поведение, при котором `ALTER MODIFY COLUMN` создавал мутацию, которая заведомо завершалась ошибкой. [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#21250](https://github.com/ClickHouse/ClickHouse/issues/21250): - Заблокированы параллельные вставки в storage join. [#21009](https://github.com/ClickHouse/ClickHouse/pull/21009) ([Vladimir C](https://github.com/vdimir)).
* Бэкпортировано в [#21068](https://github.com/ClickHouse/ClickHouse/issues/21068): Был возможен выход за границы памяти при форматировании специально сформированного значения типа `DateTime64`, выходящего за допустимый диапазон. Это закрывает [#20494](https://github.com/ClickHouse/ClickHouse/issues/20494). Это закрывает [#20543](https://github.com/ClickHouse/ClickHouse/issues/20543). [#21023](https://github.com/ClickHouse/ClickHouse/pull/21023) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#21229](https://github.com/ClickHouse/ClickHouse/issues/21229): Исправляет [#21112](https://github.com/ClickHouse/ClickHouse/issues/21112). Исправлена ошибка, которая могла приводить к дубликатам при insert query (если один из обратных вызовов приходил немного позже, чем нужно). [#21138](https://github.com/ClickHouse/ClickHouse/pull/21138) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#21277](https://github.com/ClickHouse/ClickHouse/issues/21277): Исправлена ошибка с `join_use_nulls` и JOIN `TOTALS` из подзапросов. Это закрывает [#19362](https://github.com/ClickHouse/ClickHouse/issues/19362) и [#21137](https://github.com/ClickHouse/ClickHouse/issues/21137). [#21248](https://github.com/ClickHouse/ClickHouse/pull/21248) ([Vladimir C](https://github.com/vdimir)).
