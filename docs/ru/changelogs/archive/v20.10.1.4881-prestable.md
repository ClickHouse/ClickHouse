<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Добавлена поддержка вложенных многострочных комментариев `/* comment /* comment */ */` в SQL. Это соответствует стандарту SQL. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Изменено значение по умолчанию настройки `format_regexp_escaping_rule` (она связана с форматом `Regexp`) на `Raw` (то есть весь подшаблон считывается как значение), чтобы поведение больше соответствовало ожиданиям пользователей. [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version` объявлен устаревшим. Удалена первая версия механизма переписывания JOIN. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### Новая возможность
</div>

* Поддержка типов MySQL: `decimal` (как ClickHouse `Decimal`) и `datetime` с субсекундной точностью (как `DateTime64`). ... [#11512](https://github.com/ClickHouse/ClickHouse/pull/11512) ([Vasily Nemkov](https://github.com/Enmk)).
* Возможность включать fsync при вставках, слияниях и загрузках. [#11948](https://github.com/ClickHouse/ClickHouse/pull/11948) ([Anton Popov](https://github.com/CurtizJ)).
* Безопасное выполнение межкластерных запросов (с использованием initial&#95;user в качестве текущего пользователя запроса). [#13156](https://github.com/ClickHouse/ClickHouse/pull/13156) ([Azat Khuzhin](https://github.com/azat)).
* * Добавлена функция `mapPopulateSeries`. [#13166](https://github.com/ClickHouse/ClickHouse/pull/13166) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Пользователь может задавать настройки для хранилищ `ReplicatedMergeTree*` в разделе `<replicated_merge_tree>` файла конфигурации. Это работает аналогично разделу `<merge_tree>`. Для хранилищ `ReplicatedMergeTree*` настройки из `<merge_tree>` и `<replicated_merge_tree>` применяются совместно, но настройки из `<replicated_merge_tree>` имеют более высокий приоритет. Добавлена таблица `system.replicated_merge_tree_settings`. [#13573](https://github.com/ClickHouse/ClickHouse/pull/13573) ([Amos Bird](https://github.com/amosbird)).
* Добавлена новая возможность: формат LineAsString, который принимает последовательность line, разделённых символами новой строки, пробелами и/или запятыми. [#13846](https://github.com/ClickHouse/ClickHouse/pull/13846) ([hexiaoting](https://github.com/hexiaoting)).
* Добавлены новые настройки ограничения сложности запросов `max_rows_to_read_leaf`, `max_bytes_to_read_leaf` для распределённых запросов, чтобы ограничить максимальное число строк/байт, считываемых на листовых узлах. Ограничение применяется только к локальному чтению, **не включая** финальную стадию merge на корневом узле. [#14221](https://github.com/ClickHouse/ClickHouse/pull/14221) ([Roman Khavronenko](https://github.com/hagen1778)).
* Добавлены форматы JSONStrings, которые выводят данные в виде массивов строк. [#14333](https://github.com/ClickHouse/ClickHouse/pull/14333) ([hcz](https://github.com/hczhcz)).
* Теперь операторы INSERT могут содержать asterisk (или его варианты) с преобразователями столбцов в списке столбцов. [#14453](https://github.com/ClickHouse/ClickHouse/pull/14453) ([Amos Bird](https://github.com/amosbird)).
* Добавлен script для импорта git repository в ClickHouse. [#14471](https://github.com/ClickHouse/ClickHouse/pull/14471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена возможность указывать `TTL ... RECOMPRESS codec_name` для семейства движков таблиц MergeTree. [#14494](https://github.com/ClickHouse/ClickHouse/pull/14494) ([alesapin](https://github.com/alesapin)).
* В таблицы `system.asynchronous_metric_log` и `system.metric_log` добавлен event&#95;time&#95;microseconds. [#14514](https://github.com/ClickHouse/ClickHouse/pull/14514) ([Bharat Nallan](https://github.com/bharatnc)).

* Добавлена поддержка data type Decimal для MaterializedMySQL. [#14535](https://github.com/ClickHouse/ClickHouse/pull/14535) ([Winter Zhang](https://github.com/zhang2014)).
* Добавлена возможность настраивать представление NULL для выходного формата TSV. Оно управляется настройкой `output_format_tsv_null_representation`, значение которой по умолчанию — `\N`. Это закрывает [#9375](https://github.com/ClickHouse/ClickHouse/issues/9375). Обратите внимание, что эта настройка управляет только output format, а `\N` — единственное поддерживаемое представление NULL для input format TSV. [#14586](https://github.com/ClickHouse/ClickHouse/pull/14586) ([Kruglov Pavel](https://github.com/Avogar)).

Обе операции легковесные и выполняются на уровне metadata. [#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).

Это закрывает [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416). Это закрывает [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967). <div id="performance-improvement">
  #### Повышение производительности
</div>

* По умолчанию включены компактные части для небольших частей. Это позволит немного эффективнее обрабатывать частые вставки (в 4..100 раз). [#11913](https://github.com/ClickHouse/ClickHouse/pull/11913) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Улучшена производительность 256-битных значений за счёт использования (u)int64&#95;t в качестве базового типа для широких целых чисел. Изначально для широких целых чисел в качестве базового типа использовались 8-битные типы. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* При запуске clickhouse-server с помощью `mlock` блокируется только сегмент кода. В предыдущих версиях в памяти блокировались все отображённые области, включая отладочную информацию. Обычно отладочная информация выносится в отдельный файл, но если это не так, это приводило к увеличению использования памяти на 2..3 GiB. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Раньше для группировки по одному значению FixedString мы выбирали метод fixed key. Это не нужно, поскольку у нас есть StringHashTable, которая выполняет аналогичную оптимизацию packedFix для столбцов FixedString. И по возможности следует использовать low&#95;cardinality&#95;key&#95;fixed&#95;string. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* Исправлен ошибочный выбор медленной универсальной реализации для `DateTime <op> DateTime`. Исправлена [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153). [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* Используется один запрос S3 DeleteObjects вместо нескольких запросов DeleteObject в цикле. Изменений в функциональности нет, поэтому это покрывается существующими тестами, такими как integration/test&#95;log&#95;family&#95;s3. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* Ускорено 256-битное умножение. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* Улучшена производительность `quantileTDigest`. Исправлена [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668). [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* Явно используется временный диск для хранения временных данных Вертикального слияния. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).

Это также может быть полезно и в других сценариях использования. [#14513](https://github.com/ClickHouse/ClickHouse/pull/14513) ([Amos Bird](https://github.com/amosbird)).
