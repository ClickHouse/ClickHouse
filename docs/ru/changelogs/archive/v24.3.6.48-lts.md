  ### Релиз ClickHouse v24.3.6.48-lts (b2d33c3c45d) FIXME по сравнению с v24.3.5.46-lts (fe54cead6b6)

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### Критическое исправление ошибки (сбой, LOGICAL_ERROR, потеря данных, RBAC)
</div>

* Бэкпортировано в [#66889](https://github.com/ClickHouse/ClickHouse/issues/66889): исправлен неверный размер столбца с низкой кардинальностью при вызовах функций. [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#66687](https://github.com/ClickHouse/ClickHouse/issues/66687): исправлено предложение VALID UNTIL в определении пользователя, которое сбрасывалось после перезапуска. Закрывает [#66405](https://github.com/ClickHouse/ClickHouse/issues/66405). [#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#67497](https://github.com/ClickHouse/ClickHouse/issues/67497): исправлен сбой в DistributedAsyncInsert, если соединение пустое. [#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, видимое пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#66324](https://github.com/ClickHouse/ClickHouse/issues/66324): В кэш вывода схемы добавлены отсутствующие настройки `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples`, поскольку они могут изменять итоговую схему. Это предотвращает некорректные результаты вывода схемы при изменении этих настроек. [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#66151](https://github.com/ClickHouse/ClickHouse/issues/66151): Исправлена ошибка переполнения буфера в реализации `unbin`/`unhex`. [#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#66451](https://github.com/ClickHouse/ClickHouse/issues/66451): Исправлена ошибка в клиенте ZooKeeper: сеанс мог перейти в нерабочее состояние после получения аппаратной ошибки от ZooKeeper. Например, это могло произойти из-за &quot;soft memory limit&quot; в ClickHouse Keeper. [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#66222](https://github.com/ClickHouse/ClickHouse/issues/66222): Исправлена проблема в SumIfToCountIfVisitor при работе со знаковыми целыми числами. [#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#66676](https://github.com/ClickHouse/ClickHouse/issues/66676): Исправлена обработка ограничения для `system.numbers_mt`, когда индекс нельзя использовать. [#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#66602](https://github.com/ClickHouse/ClickHouse/issues/66602): Исправлено определение сервером ClickHouse максимального числа доступных ядер CPU, заданного через cgroups v2, если сервер работает в контейнере, например Docker. Подробнее: контейнеры часто запускают процесс в корневой cgroup с пустым именем. В таком случае ClickHouse игнорировал ограничения CPU, установленные через cgroups v2. [#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#66356](https://github.com/ClickHouse/ClickHouse/issues/66356): Исправлена ошибка `Not-ready set`, возникавшая при использовании в ограничении подзапроса с `IN`. [#66261](https://github.com/ClickHouse/ClickHouse/pull/66261) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#66970](https://github.com/ClickHouse/ClickHouse/issues/66970): Исправлена ошибка `Column identifier is already registered` при `group_by_use_nulls=true` и использовании нового анализатора. [#66400](https://github.com/ClickHouse/ClickHouse/pull/66400) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#66967](https://github.com/ClickHouse/ClickHouse/issues/66967): Исправлена ошибка `Cannot find column` в запросах с константным выражением в ключе `GROUP BY` при включенном новом анализаторе. [#66433](https://github.com/ClickHouse/ClickHouse/pull/66433) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#66718](https://github.com/ClickHouse/ClickHouse/issues/66718): Исправлен корректный учет памяти для `Allocator::realloc`. [#66548](https://github.com/ClickHouse/ClickHouse/pull/66548) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#66949](https://github.com/ClickHouse/ClickHouse/issues/66949): Исправлен некорректный результат для запросов с `WINDOW`. Это могло происходить, когда столбцы `PARTITION` имели разреженную сериализацию, а оконные функции выполнялись параллельно. [#66579](https://github.com/ClickHouse/ClickHouse/pull/66579) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#66946](https://github.com/ClickHouse/ClickHouse/issues/66946): Исправлена ошибка `Method getResultType is not supported for QUERY query node`, возникавшая, когда скалярный подзапрос использовался в качестве первого аргумента IN (с новым анализатором). [#66655](https://github.com/ClickHouse/ClickHouse/pull/66655) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#67629](https://github.com/ClickHouse/ClickHouse/issues/67629): Исправлена редкая взаимная блокировка в Context::getDDLWorker. [#66843](https://github.com/ClickHouse/ClickHouse/pull/66843) ([Alexander Gololobov](https://github.com/davenger)).
* Бэкпортировано в [#67193](https://github.com/ClickHouse/ClickHouse/issues/67193): TRUNCATE DATABASE приводил к остановке репликации, как если бы это был запрос DROP DATABASE; это исправлено. [#67129](https://github.com/ClickHouse/ClickHouse/pull/67129) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Бэкпортировано в [#67375](https://github.com/ClickHouse/ClickHouse/issues/67375): Исправлена ошибка `Cannot convert column because it is non constant in source stream but must be constant in result.` для запроса, читающего из таблицы `Merge` поверх таблицы `Distriburted` с одним сегментом. [#67146](https://github.com/ClickHouse/ClickHouse/pull/67146) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#67572](https://github.com/ClickHouse/ClickHouse/issues/67572): Исправлено выполнение вложенных функций с коротким замыканием. [#67520](https://github.com/ClickHouse/ClickHouse/pull/67520) ([Kruglov Pavel](https://github.com/Avogar)).
