<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Улучшена производительность запросов с явно заданными большими множествами. Добавлена настройка совместимости `legacy_column_name_of_tuple_literal`. Её имеет смысл установить в `true` при rolling update кластера с версии ниже 21.7 до любой более новой версии. В противном случае распределённые запросы с явно заданными множествами в условии `IN` могут завершаться ошибкой во время обновления. [#25371](https://github.com/ClickHouse/ClickHouse/pull/25371) ([Anton Popov](https://github.com/CurtizJ)).
* Изменение максимального размера буфера в clickhouse-keeper, несовместимое в обе стороны. Лучше сделать это сейчас (до продакшна), чем позже. [#25421](https://github.com/ClickHouse/ClickHouse/pull/25421) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### Новая возможность

Решает [#13458](https://github.com/ClickHouse/ClickHouse/issues/13458). [#13652](https://github.com/ClickHouse/ClickHouse/pull/13652) ([Mike Kot](https://github.com/myrrc)).

Это очень простой и быстрый оценщик quantile с относительной ошибкой не более 0.390625%. Это закрывает [#16641](https://github.com/ClickHouse/ClickHouse/issues/16641). [#23204](https://github.com/ClickHouse/ClickHouse/pull/23204) ([Ivan Novitskiy](https://github.com/RedClusive)).

* Добавлена новая булевый настройка `prefer_global_in_and_join`, которая по умолчанию преобразует все IN/JOIN в GLOBAL IN/JOIN. [#23434](https://github.com/ClickHouse/ClickHouse/pull/23434) ([Amos Bird](https://github.com/amosbird)).
* Добавлена функция `bitpositionToArray`. [#23843](https://github.com/ClickHouse/ClickHouse/pull/23843) ([kevin wan](https://github.com/MaxWk)).
* Добавлена aggregate function `segmentLengthSum`. [#24250](https://github.com/ClickHouse/ClickHouse/pull/24250) ([flynn](https://github.com/ucasfl)).
* Добавлена поддержка structs и maps в форматах Arrow/Parquet/ORC, а также словарей во входных и выходных форматах Arrow. Представлена новая настройка `output_format_arrow_low_cardinality_as_dictionary`. [#24341](https://github.com/ClickHouse/ClickHouse/pull/24341) ([Kruglov Pavel](https://github.com/Avogar)).
* Добавлена поддержка настройки `compile_expression` для AARCH64. [#24342](https://github.com/ClickHouse/ClickHouse/pull/24342) ([Maksim Kita](https://github.com/kitaisreal)).
* Теперь clickhouse-keeper поддерживает ACL `digest` в стиле ZooKeeper. [#24448](https://github.com/ClickHouse/ClickHouse/pull/24448) ([alesapin](https://github.com/alesapin)).
* Реализована функция `h3ToGeo`. [#24867](https://github.com/ClickHouse/ClickHouse/pull/24867) ([Bharat Nallan](https://github.com/bharatnc)).
* Теперь в query&#95;log есть два новых столбца: initial&#95;query&#95;start&#95;time / initial&#95;query&#95;start&#95;time&#95;microsecond, которые записывают время начала distributed query, если такой есть. [#25022](https://github.com/ClickHouse/ClickHouse/pull/25022) ([Amos Bird](https://github.com/amosbird)).
* В Dictionaries добавлена поддержка типа Array. [#25119](https://github.com/ClickHouse/ClickHouse/pull/25119) ([Maksim Kita](https://github.com/kitaisreal)).
* Добавлена функция `toJSONString` для сериализации столбцов в их JSON-представления. [#25164](https://github.com/ClickHouse/ClickHouse/pull/25164) ([Amos Bird](https://github.com/amosbird)).
* База данных ClickHouse, созданная с помощью MaterializeMySQL, теперь содержит все комментарии к столбцам из материализованной базы данных MySQL. [#25199](https://github.com/ClickHouse/ClickHouse/pull/25199) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* Добавлена функция `dateName`. Автор — [Daniil Kondratyev] (@dankondr). [#25372](https://github.com/ClickHouse/ClickHouse/pull/25372) ([Maksim Kita](https://github.com/kitaisreal)).
* Добавлена функция `bitPositionsToArray`. Закрывает [#23792](https://github.com/ClickHouse/ClickHouse/issues/23792). Автор — [Kevin Wan] (@MaxWk). [#25394](https://github.com/ClickHouse/ClickHouse/pull/25394) ([Maksim Kita](https://github.com/kitaisreal)).

* Добавлено отображение прогресса для движка таблицы File в clickhouse-local и для запроса INSERT в клиенте ClickHouse, когда данные передаются через stdin. Закрывает [#18209](https://github.com/ClickHouse/ClickHouse/issues/18209). [#23656](https://github.com/ClickHouse/ClickHouse/pull/23656) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Исправлена обработка конфликтов имён столбцов для storage join, закрывает [#20309](https://github.com/ClickHouse/ClickHouse/issues/20309). [#23769](https://github.com/ClickHouse/ClickHouse/pull/23769) ([Vladimir C](https://github.com/vdimir)).
* Добавлена возможность разделять распределённый батч при сбоях (например, из-за лимитов памяти или повреждений) с помощью `distributed_directory_monitor_split_batch_on_failure` (по умолчанию OFF). [#23864](https://github.com/ClickHouse/ClickHouse/pull/23864) ([Azat Khuzhin](https://github.com/azat)).
* Добавлена автономная символьная ссылка `clickhouse-keeper` на основной бинарный файл `clickhouse`. Теперь coordination можно запускать без основного ClickHouse server. [#24059](https://github.com/ClickHouse/ClickHouse/pull/24059) ([alesapin](https://github.com/alesapin)).
* Подавляются Исключения из кода logger. [#24069](https://github.com/ClickHouse/ClickHouse/pull/24069) ([Azat Khuzhin](https://github.com/azat)).
* Для запросов к `VIEW` теперь используются глобальные настройки. Исправлено поведение, при котором запросы к `VIEW` использовали локальные настройки, что приводило к ошибкам, если настройки в `CREATE VIEW` и `SELECT` различались. Сейчас `VIEW` не использует эти изменённые настройки, но вы по-прежнему можете передавать дополнительные настройки в секции `SETTINGS` запроса `CREATE VIEW`. Закрывает [#20551](https://github.com/ClickHouse/ClickHouse/issues/20551). [#24095](https://github.com/ClickHouse/ClickHouse/pull/24095) ([Vladimir C](https://github.com/vdimir)).
* Добавлены настройки (`connection_auto_close`/`connection_max_tries`/`connection_pool_size`) для движка хранения MySQL. [#24146](https://github.com/ClickHouse/ClickHouse/pull/24146) ([Azat Khuzhin](https://github.com/azat)).
* Исправлены завершающие пробелы в предложении FROM с подзапросами в многострочном режиме, а также слегка изменён вывод запросов, чтобы сделать его удобнее для чтения. [#24151](https://github.com/ClickHouse/ClickHouse/pull/24151) ([Azat Khuzhin](https://github.com/azat)).
* IPv4-адреса вида `127.0.1.1` теперь распознаются как локальные. Это спорное изменение, оно закрывает [#23504](https://github.com/ClickHouse/ClickHouse/issues/23504). Michael Filimonov протестирует эту возможность. [#24316](https://github.com/ClickHouse/ClickHouse/pull/24316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Исправлено разрешение IPv6-адресов (то есть исправлен `select * from remote('[::1]', system.one)`). [#24319](https://github.com/ClickHouse/ClickHouse/pull/24319) ([Azat Khuzhin](https://github.com/azat)).
* Теперь в query&#95;log есть два новых столбца: `initial_query_start_time / initial_query_start_time_microsecond`, которые записывают время начала распределенного запроса, если такой запрос есть. [#24388](https://github.com/ClickHouse/ClickHouse/pull/24388) ([Amos Bird](https://github.com/amosbird)).
* Большее число столбцов теперь переписывается в возможные алиасные выражения. Это может улучшить оптимизацию, например для проекций. [#24405](https://github.com/ClickHouse/ClickHouse/pull/24405) ([Amos Bird](https://github.com/amosbird)).
* Добавлена оптимизация, которая преобразует некоторые функции в чтение подстолбцов, чтобы уменьшить объем читаемых данных. Например, оператор `col IS NULL` преобразуется в чтение подстолбца `col.null`. Оптимизацию можно включить с помощью настройки `optimize_functions_to_subcolumns`. [#24406](https://github.com/ClickHouse/ClickHouse/pull/24406) ([Anton Popov](https://github.com/CurtizJ)).
* Исправлена гонка данных при завершении работы Keeper. [#24412](https://github.com/ClickHouse/ClickHouse/pull/24412) ([alesapin](https://github.com/alesapin)).
* Добавлена поддержка схемы Postgres для запросов вставки. Закрывает [#24149](https://github.com/ClickHouse/ClickHouse/issues/24149). [#24413](https://github.com/ClickHouse/ClickHouse/pull/24413) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Если SSDDictionary создается с помощью DDL-запроса, его можно создать только внутри каталога user&#95;files. [#24466](https://github.com/ClickHouse/ClickHouse/pull/24466) ([Maksim Kita](https://github.com/kitaisreal)).
* Парсер String-to-Int стал строже, поэтому `toInt64('+')` теперь будет выбрасывать исключение. [#24475](https://github.com/ClickHouse/ClickHouse/pull/24475) ([Amos Bird](https://github.com/amosbird)).
* Добавлена настройка MergeTree `max_parts_to_merge_at_once`, которая ограничивает количество частей, которые можно одновременно объединять в фоновом режиме. Не влияет на запрос `OPTIMIZE FINAL`. Исправляет [#1820](https://github.com/ClickHouse/ClickHouse/issues/1820). [#24496](https://github.com/ClickHouse/ClickHouse/pull/24496) ([alesapin](https://github.com/alesapin)).
* Исключено скрытие ошибок вроде `Limit for rows or bytes to read exceeded` для скалярных подзапросов. [#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).
* Добавлены две настройки Replicated*MergeTree: `max_replicated_fetches_network_bandwidth` и `max_replicated_sends_network_bandwidth`, которые позволяют ограничить максимальную скорость загрузки/отправки при репликации для таблицы. Добавлены две настройки для всего сервера (в профиле пользователя `default`): `max_replicated_fetches_network_bandwidth_for_server` и `max_replicated_sends_network_bandwidth_for_server`, которые ограничивают максимальную скорость репликации для всех таблиц. Настройки соблюдаются не идеально точно. По умолчанию отключены. Исправляет [#1821](https://github.com/ClickHouse/ClickHouse/issues/1821). [#24573](https://github.com/ClickHouse/ClickHouse/pull/24573) ([alesapin](https://github.com/alesapin)).
* Для `insert_distributed_sync` теперь учитывается `max_distributed_connections` (иначе на больших кластерах и при синхронной вставке может исчерпаться `max_thread_pool_size`). [#24754](https://github.com/ClickHouse/ClickHouse/pull/24754) ([Azat Khuzhin](https://github.com/azat)).
* Исправлена ошибка в движке базы данных `Replicated`, из-за которой в редких случаях одна из реплик могла пропустить поставленный в очередь DDL-запрос. [#24805](https://github.com/ClickHouse/ClickHouse/pull/24805) ([Alexander Tokmakov](https://github.com/tavplubix)).

* Разрешено использовать оператор `not in` при отсечении партиций. [#24894](https://github.com/ClickHouse/ClickHouse/pull/24894) ([Amos Bird](https://github.com/amosbird)).
* Улучшено логирование ошибок S3: при пустых ключах и бакетах больше не появляются двойные пробелы. [#24897](https://github.com/ClickHouse/ClickHouse/pull/24897) ([Vladimir Chebotarev](https://github.com/excitoon)).

[#25166](https://github.com/ClickHouse/ClickHouse/pull/25166) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
