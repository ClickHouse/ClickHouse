<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпорт в [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673): Если база данных уже инициализирована, при последующих запусках её не нужно инициализировать повторно. Это может решить проблему бесконечных перезапусков контейнера, если база данных не успевает загрузиться за 1000 попыток (актуально для очень больших баз данных и многоузловых конфигураций). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* Бэкпорт в [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293): Ресурс с исходным кодом, включая подмодули, собирается в специальной задаче сборки для Darwin. Его можно использовать для сборки ClickHouse без предварительного извлечения подмодулей. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Бэкпорт в [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366): Решена проблема с запуском автономного clickhouse-keeper из пакета clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпорт в [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725): Исправлен Python-скрипт проверки integration для использования URL gh api — также добавлен Readme для CI-тестов. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#55304](https://github.com/ClickHouse/ClickHouse/issues/55304): Исправлена ошибка &quot;Invalid number of rows in Chunk&quot; в MaterializedPostgreSQL (она могла возникать в PostgreSQL версии &gt;= 13). [#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#55018](https://github.com/ClickHouse/ClickHouse/issues/55018): Устаревшие настройки формата вынесены в отдельный раздел и используются вместе со всеми настройками формата, чтобы избежать исключений `Unknown setting` при использовании устаревших настроек формата. Закрывает [#54792](https://github.com/ClickHouse/ClickHouse/issues/54792) ### Запись в документации об изменениях, заметных пользователю. [#54855](https://github.com/ClickHouse/ClickHouse/pull/54855) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#55097](https://github.com/ClickHouse/ClickHouse/issues/55097): Кворум вставки мог ошибочно помечаться как достигнутый при повторных попытках Keeper во время ожидания кворума. Исправляет [#54543](https://github.com/ClickHouse/ClickHouse/issues/54543). [#55026](https://github.com/ClickHouse/ClickHouse/pull/55026) ([Igor Nikonov](https://github.com/devcrafter)).
* Бэкпортировано в [#55473](https://github.com/ClickHouse/ClickHouse/issues/55473): Предотвращено прикрепление партиций из таблиц, в которых определены другие индексы или проекции. [#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#55461](https://github.com/ClickHouse/ClickHouse/issues/55461): Если в конструкторе `ShellCommandSource` возникает исключение после запуска некоторых потоков `send_data_threads`, для них нужно вызвать join(), иначе в деструкторе `ThreadFromGlobalPool` будет вызван abort(). Исправляет [#55091](https://github.com/ClickHouse/ClickHouse/issues/55091). [#55103](https://github.com/ClickHouse/ClickHouse/pull/55103) ([Alexander Gololobov](https://github.com/davenger)).
* Бэкпортировано в [#55412](https://github.com/ClickHouse/ClickHouse/issues/55412): Исправлена взаимная блокировка при обновлении ролей, назначенных через LDAP, для несуществующих ролей ClickHouse. [#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* Бэкпортировано в [#55323](https://github.com/ClickHouse/ClickHouse/issues/55323): Исправлена ошибка фоновой загрузки в fs cache. [#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#55349](https://github.com/ClickHouse/ClickHouse/issues/55349): Исправлено выполнение функций для разреженных столбцов (исправляет ошибку `DB::Exception: isDefaultAt is not implemented for Function: while executing 'FUNCTION Capture`). [#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#55475](https://github.com/ClickHouse/ClickHouse/issues/55475): Исправлена проблема, из-за которой было невозможно удалить detached-партицию в семействе движков `ReplicatedMergeTree` поверх S3 (без репликации с нулевым копированием). Исправляет проблему [#55225](https://github.com/ClickHouse/ClickHouse/issues/55225). Исправлена ошибка с брошенными blob-объектами в S3 для сложных типов данных, таких как Arrays или столбцы Nested. Частично исправляет [#52393](https://github.com/ClickHouse/ClickHouse/issues/52393). Большое спасибо @alifirat за примеры. [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#55399](https://github.com/ClickHouse/ClickHouse/issues/55399): Оптимизация, добавленная год назад, оказалась некорректной. Это закрывает [#55272](https://github.com/ClickHouse/ClickHouse/issues/55272). [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#55437](https://github.com/ClickHouse/ClickHouse/issues/55437): исправлен разбор массивов в операторе приведения типов (`::`). [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#55635](https://github.com/ClickHouse/ClickHouse/issues/55635): исправлена фильтрация по виртуальным столбцам с OR-фильтром в запросе (фильтрация по `_part*` для `MergeTree`, по `_path`/`_file` для различных движков `File`/`HDFS`/... , по `_table` для `Merge`). [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#55445](https://github.com/ClickHouse/ClickHouse/issues/55445): исправлены проблемы с подключением, возникавшие с некоторыми версиями MongoDB. Закрывает [#55376](https://github.com/ClickHouse/ClickHouse/issues/55376), [#55232](https://github.com/ClickHouse/ClickHouse/issues/55232). [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#55534](https://github.com/ClickHouse/ClickHouse/issues/55534): исправлена возможная взаимная блокировка, вызванная неуничтоженным fiber в случае исключения при отмене асинхронной задачи. Закрывает [#55185](https://github.com/ClickHouse/ClickHouse/issues/55185). [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* Бэкпортировано в [#55747](https://github.com/ClickHouse/ClickHouse/issues/55747): исправлен сбой в QueryNormalizer при циклических псевдонимах. [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
