<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Настройка `enable_positional_arguments` теперь включена по умолчанию. Она позволяет выполнять запросы вида `SELECT ... ORDER BY 1, 2`, где 1 и 2 — это ссылки на элементы списка SELECT. Если вам нужно вернуть прежнее поведение, отключите эту настройку. [#38204](https://github.com/ClickHouse/ClickHouse/pull/38204) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Движок базы данных `Ordinary` и старый синтаксис определения хранилища для таблиц семейства `*MergeTree` объявлены устаревшими. По умолчанию создавать новые больше нельзя. Если база данных `system` использует движок `Ordinary`, при запуске сервера она будет автоматически преобразована в `Atomic`. Существуют настройки для сохранения прежнего поведения (`allow_deprecated_database_ordinary` и `allow_deprecated_syntax_for_merge_tree`), но в будущих релизах эти настройки могут быть удалены. [#38335](https://github.com/ClickHouse/ClickHouse/pull/38335) ([Alexander Tokmakov](https://github.com/tavplubix)).
* * По умолчанию принудительно включено переписывание JOIN через запятую в INNER JOIN (значение `cross_to_inner_join_rewrite = 2` установлено по умолчанию). Чтобы вернуть прежнее поведение, установите `cross_to_inner_join_rewrite = 1`. [#39326](https://github.com/ClickHouse/ClickHouse/pull/39326) ([Vladimir C](https://github.com/vdimir)).
* `format_csv_allow_single_quotes` теперь по умолчанию отключена. [#37096](https://github.com/ClickHouse/ClickHouse/issues/37096). [#39423](https://github.com/ClickHouse/ClickHouse/pull/39423) ([Kruglov Pavel](https://github.com/Avogar)).

Закрывает [#35693](https://github.com/ClickHouse/ClickHouse/issues/35693). [#37015](https://github.com/ClickHouse/ClickHouse/pull/37015) ([wuxiaobai24](https://github.com/wuxiaobai24)).

Этот PR вносит необходимые изменения, чтобы `host_regexp` применялся ко всем возможным PTR-ответам и проверялось, есть ли хотя бы одно совпадение. [#37827](https://github.com/ClickHouse/ClickHouse/pull/37827) ([Arthur Passos](https://github.com/arthurpassos)).
* Добавлена поддержка безопасной передачи hadoop rpc (hadoop.rpc.protection=privacy и hadoop.rpc.protection=integrity). [#37852](https://github.com/ClickHouse/ClickHouse/pull/37852) ([Peng Liu](https://github.com/michael1589)).
* Добавлена поддержка типа struct в `StorageHive`. [#38118](https://github.com/ClickHouse/ClickHouse/pull/38118) ([lgbo](https://github.com/lgbo-ustc)).
* Добавлены кодирование и декодирование Base58. [#38159](https://github.com/ClickHouse/ClickHouse/pull/38159) ([Andrey Zvonov](https://github.com/zvonand)).
* В интерфейс Play добавлена визуализация в виде диаграмм. [#38197](https://github.com/ClickHouse/ClickHouse/pull/38197) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Добавлена поддержка команды `alter` для таблицы `StorageHive`. [#38214](https://github.com/ClickHouse/ClickHouse/pull/38214) ([lgbo](https://github.com/lgbo-ustc)).
* Добавлен запрос `CREATE TABLE ... EMPTY AS SELECT`. Он автоматически выводит структуру таблицы из запроса SELECT, но не заполняет таблицу после создания. Решает [#38049](https://github.com/ClickHouse/ClickHouse/issues/38049). [#38272](https://github.com/ClickHouse/ClickHouse/pull/38272) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Добавлена новая настройка `implicit_transaction` для запуска автономных запросов внутри транзакции. Она автоматически обрабатывает как создание, так и завершение транзакции (через COMMIT, если запрос выполнен успешно, или ROLLBACK, если нет). [#38344](https://github.com/ClickHouse/ClickHouse/pull/38344) ([Raúl Marín](https://github.com/Algunenano)).
* Разрешена завершающая запятая в списке столбцов. Закрывает [#38425](https://github.com/ClickHouse/ClickHouse/issues/38425). [#38440](https://github.com/ClickHouse/ClickHouse/pull/38440) ([chen](https://github.com/xiedeyantu)).
* ClickHouse упакован в самораспаковывающийся исполняемый файл (путь programs/self-extracting). Добавлена новая цель сборки `self-extracting`. [#38447](https://github.com/ClickHouse/ClickHouse/pull/38447) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Добавлены настройки `additional_table_filters`. С помощью этой настройки можно указать дополнительное условие фильтрации для таблицы, которое будет применяться сразу после чтения. Пример: `select number, x, y from (select number from system.numbers limit 5) f any left join (select x, y from table_1) s on f.number = s.x settings additional_table_filters={'system.numbers : 'number != 3', 'table_1' : 'x != 2'}`. Добавлена настройка `additional_result_filter`, которая задает дополнительное условие фильтрации для результата запроса. Закрывает [#37918](https://github.com/ClickHouse/ClickHouse/issues/37918). [#38475](https://github.com/ClickHouse/ClickHouse/pull/38475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Добавлен выходной формат SQLInsert. Закрывает [#38441](https://github.com/ClickHouse/ClickHouse/issues/38441). [#38477](https://github.com/ClickHouse/ClickHouse/pull/38477) ([Kruglov Pavel](https://github.com/Avogar)).
* Загружаемый исполняемый файл clickhouse представляет собой сжатый самораспаковывающийся архив. [#38653](https://github.com/ClickHouse/ClickHouse/pull/38653) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Добавлена поддержка функции `isNullable`. Эта функция проверяет, является ли ее аргумент Nullable, и возвращает true(1) или false(0). Закрывает [#38611](https://github.com/ClickHouse/ClickHouse/issues/38611). [#38841](https://github.com/ClickHouse/ClickHouse/pull/38841) ([lokax](https://github.com/lokax)).
* Добавлены функции `translate(string, from_string, to_string)` и `translateUTF8(string, from_string, to_string)`. [#38935](https://github.com/ClickHouse/ClickHouse/pull/38935) ([Nikolay Degterinsky](https://github.com/evillique)).
* Добавлены настройка `compatibility` и системная таблица `system.settings_changes`, содержащая информацию об изменениях настроек между версиями ClickHouse. Закрывает [#35972](https://github.com/ClickHouse/ClickHouse/issues/35972). [#38957](https://github.com/ClickHouse/ClickHouse/pull/38957) ([Kruglov Pavel](https://github.com/Avogar)).
* В функцию tupleElement добавлен 3-й параметр, который возвращается, если в tuple нет соответствующего элемента. Работает только в том случае, если 2-й параметр имеет тип String. Закрывает [#38872](https://github.com/ClickHouse/ClickHouse/issues/38872). [#38989](https://github.com/ClickHouse/ClickHouse/pull/38989) ([lokax](https://github.com/lokax)).
* Добавлена поддержка функции parseTimedelta. Ее можно использовать так: &#96;&#96;&#96;sql # &#39; &#39;, &#39;;&#39;, &#39;-&#39;, &#39;+&#39;, &#39;,&#39;, &#39;:&#39; можно использовать в качестве разделителей, например &quot;1yr-2mo&quot;, &quot;2m:6s&quot; SELECT parseTimeDelta(&#39;1yr-2mo-4w + 12 days, 3 hours : 1 minute ; 33 seconds&#39;);. [#39071](https://github.com/ClickHouse/ClickHouse/pull/39071) ([jiahui-97](https://github.com/jiahui-97)).
* Добавлены параметры для ограничения операций IO с удаленным хранилищем: `max_remote_read_network_bandwidth_for_server` и `max_remote_write_network_bandwidth_for_server`. [#39095](https://github.com/ClickHouse/ClickHouse/pull/39095) ([Sergei Trifonov](https://github.com/serxa)).
* Добавлена настройка `send_logs_source_regexp`. Отправляет текстовые журналы сервера, соответствующие указанному regexp для имени источника журнала. Пустое значение означает все источники. [#39161](https://github.com/ClickHouse/ClickHouse/pull/39161) ([Amos Bird](https://github.com/amosbird)).
* OpenTelemetry теперь по умолчанию собирает traces без spans процессоров. Чтобы включить сбор spans процессоров, используйте настройку `opentelemetry_trace_processors`. [#39170](https://github.com/ClickHouse/ClickHouse/pull/39170) ([Ilya Yatsishin](https://github.com/qoega)).

<div id="performance-improvement">
  #### Повышение производительности
</div>

* Добавлен новый метод `local_filesystem_read_method` `io_uring`, основанный на асинхронной подсистеме Linux [io&#95;uring](https://kernel.dk/io_uring.pdf), который почти во всех случаях повышает производительность чтения по сравнению с методом `pread`, используемым по умолчанию. [#36103](https://github.com/ClickHouse/ClickHouse/pull/36103) ([Saulius Valatka](https://github.com/sauliusvl)).
* Оптимизация Distinct для отсортированных столбцов. Используется специализированное преобразование distinct, если входной поток отсортирован по столбцу или столбцам в distinct. Оптимизация может применяться к pre-distinct, final distinct или к обоим. Первоначальная реализация от @dimarub2000. [#37803](https://github.com/ClickHouse/ClickHouse/pull/37803) ([Igor Nikonov](https://github.com/devcrafter)).
* Добавлен оптимизированный с использованием VBMI `copyOverlap32Shuffle` для распаковки LZ4. [#37891](https://github.com/ClickHouse/ClickHouse/pull/37891) ([Guo Wangyang](https://github.com/guowangy)).
* Улучшена производительность `ORDER BY`, слияний `MergeTree` и оконных функций за счет использования батч-версии `BinaryHeap`. [#38022](https://github.com/ClickHouse/ClickHouse/pull/38022) ([Maksim Kita](https://github.com/kitaisreal)).
* Исправлена существенная регрессия производительности JOIN, появившаяся в [https://github.com/ClickHouse/ClickHouse/pull/35616](https://github.com/ClickHouse/ClickHouse/pull/35616). Интересно, что типичные запросы с JOIN, такие как запросы SSB, работали в 10 раз медленнее почти 3 месяца, и при этом никто не жаловался. [#38052](https://github.com/ClickHouse/ClickHouse/pull/38052) ([Amos Bird](https://github.com/amosbird)).
* Выполнен переход с библиотеки Intel hyperscan на vectorscan, что ускоряет многие операции сопоставления строк на платформах, отличных от x86. [#38171](https://github.com/ClickHouse/ClickHouse/pull/38171) ([Robert Schulze](https://github.com/rschu1ze)).
* Увеличен параллелизм шагов плана запроса, выполняемых после агрегации. [#38295](https://github.com/ClickHouse/ClickHouse/pull/38295) ([Nikita Taranov](https://github.com/nickitat)).
* Улучшена производительность вставки в столбцы типа `JSON`. [#38320](https://github.com/ClickHouse/ClickHouse/pull/38320) ([Anton Popov](https://github.com/CurtizJ)).
* Оптимизированы вставка и поиск в HashTable. [#38413](https://github.com/ClickHouse/ClickHouse/pull/38413) ([Nikita Taranov](https://github.com/nickitat)).
* Исправлена деградация производительности из [#32493](https://github.com/ClickHouse/ClickHouse/issues/32493). [#38417](https://github.com/ClickHouse/ClickHouse/pull/38417) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Улучшена производительность операции replicate для вектора столбца с использованием инструкций SIMD. Автор @zzachimed. [#38565](https://github.com/ClickHouse/ClickHouse/pull/38565) ([Maksim Kita](https://github.com/kitaisreal)).
* Функции Norm и Функции расстояния для массивов ускорены в 1.2-2 раза. [#38740](https://github.com/ClickHouse/ClickHouse/pull/38740) ([Alexander Gololobov](https://github.com/davenger)).
* Для запроса с ORDER BY (a, b) может быть сгенерирован менее эффективный план выполнения, чем для ORDER BY a, b. [#38873](https://github.com/ClickHouse/ClickHouse/pull/38873) ([Igor Nikonov](https://github.com/devcrafter)).
* Для Executable UDF, Executable Dictionary и Executable Storage устранено ожидание подпроцесса длительностью 1 секунду при его завершении. [#38929](https://github.com/ClickHouse/ClickHouse/pull/38929) ([Constantine Peresypkin](https://github.com/pkit)).
* * Pushdown фильтра в правую часть сортирующего JOIN. [#39123](https://github.com/ClickHouse/ClickHouse/pull/39123) ([Vladimir C](https://github.com/vdimir)).
* Оптимизирован доступ к system.stack&#95;trace. [#39177](https://github.com/ClickHouse/ClickHouse/pull/39177) ([Azat Khuzhin](https://github.com/azat)).
