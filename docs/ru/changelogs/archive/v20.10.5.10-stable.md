<div id="clickhouse-release-v2010510-stable-fixme-as-compared-to-v201041-stable">
  ### Релиз ClickHouse v20.10.5.10-stable FIXME по сравнению с v20.10.4.1-stable
</div>

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#17031](https://github.com/ClickHouse/ClickHouse/issues/17031): Добавлена возможность подключаться к защищённой конечной точке `clickhouse-server`, требующей SNI. Это возможно, если `clickhouse-server` размещён за TLS-прокси. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Исправление ошибки
</div>

* Бэкпортировано в [#17107](https://github.com/ClickHouse/ClickHouse/issues/17107): исправляет [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) и [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231), а также устраняет сбой удалённого запроса при использовании агрегатной функции с суффиксом &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Бэкпортировано в [#17022](https://github.com/ClickHouse/ClickHouse/issues/17022): исправлен сбой при использовании `any` без аргументов. Это относится к [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#16878](https://github.com/ClickHouse/ClickHouse/issues/16878): прерывает multipart-загрузку, если в WriteBufferFromS3 не были записаны данные. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Бэкпортировано в [#16949](https://github.com/ClickHouse/ClickHouse/issues/16949): предотвращает сбои ClickHouse server при использовании TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17075](https://github.com/ClickHouse/ClickHouse/issues/17075): исправлена возможная ошибка `Illegal type of argument` в запросах с `ORDER BY`. Исправляет [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#17008](https://github.com/ClickHouse/ClickHouse/issues/17008): скрипт установки должен всегда создавать подкаталоги в каталогах конфигурации. Это относится только к Docker-сборке с пользовательской конфигурацией. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#16967](https://github.com/ClickHouse/ClickHouse/issues/16967): информация blame вычислялась некорректно в `clickhouse-git-import`. [#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#17012](https://github.com/ClickHouse/ClickHouse/issues/17012): исправлен возможный сбой сервера после `ALTER TABLE ... MODIFY COLUMN ... NewType`, если в `SELECT` есть выражение `WHERE` по изменяемому столбцу, а изменение ещё не завершено. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#17038](https://github.com/ClickHouse/ClickHouse/issues/17038): повторно разрешает IP-адрес для `format_avro_schema_registry_url` в случае ошибок. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Бэкпортировано в [#17092](https://github.com/ClickHouse/ClickHouse/issues/17092): исправлен неверный результат для больших целых чисел (128, 256 бит) при приведении из double. [#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc)).
* Бэкпортировано в [#17169](https://github.com/ClickHouse/ClickHouse/issues/17169): исправлена ошибка, из-за которой запросы с `ON CLUSTER` могли зависать навсегда для нелидерных таблиц ReplicatedMergeTree. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
