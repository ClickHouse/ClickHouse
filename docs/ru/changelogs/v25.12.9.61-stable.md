<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#98182](https://github.com/ClickHouse/ClickHouse/issues/98182): Повышена производительность анализа текстового индекса для запросов с составными условиями, включающими как индексированные, так и неиндексированные столбцы. Ранее в таких случаях оптимизация раннего выхода при анализе индекса ошибочно отключалась. [#98096](https://github.com/ClickHouse/ClickHouse/pull/98096) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#99048](https://github.com/ClickHouse/ClickHouse/issues/99048): Разрешено использовать оптимизацию чтения по порядку и отсечение по первичному ключу, когда целевой тип `CAST` — `Nullable`, а преобразование монотонно; например, при `PRIMARY KEY x` ClickHouse может использовать оптимизацию чтения по порядку для `ORDER BY x::Nullable(UInt64)` и применять отсечение по первичному ключу для условий, таких как `WHERE x::Nullable(UInt64) > 500000`. [#98482](https://github.com/ClickHouse/ClickHouse/pull/98482) ([Nihal Z. Miaji](https://github.com/nihalzp)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#99101](https://github.com/ClickHouse/ClickHouse/issues/99101): Добавлена новая метрика `QueryNonInternal` для отслеживания количества выполняющихся не внутренних запросов. Эта метрика доступна как `ClickHouseMetrics_QueryNonInternal` и помогает операторам контролировать параллелизм запросов с учётом ограничения `max_concurrent_queries`, которое применяется только к не внутренним запросам. [#94284](https://github.com/ClickHouse/ClickHouse/pull/94284) ([Ashwath Singh](https://github.com/ashwath)).
* Бэкпортировано в [#100104](https://github.com/ClickHouse/ClickHouse/issues/100104): Добавлены события профиля `ObjectStorageListedObjects`, `ObjectStorageGlobFilteredObjects`, `ObjectStoragePredicateFilteredObjects` и `ObjectStorageReadObjects` для анализа работы конвейера перечисления и чтения файлов в объектном хранилище (S3, Azure и т. д.). [#99778](https://github.com/ClickHouse/ClickHouse/pull/99778) ([Sema Checherinda](https://github.com/CheSema)).
