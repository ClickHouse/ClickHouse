* Бэкпортировано в [#80771](https://github.com/ClickHouse/ClickHouse/issues/80771): скорректированы значения совместимости для max&#95;merge&#95;delayed&#95;streams&#95;for&#95;parallel&#95;write. [#80760](https://github.com/ClickHouse/ClickHouse/pull/80760) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#80963](https://github.com/ClickHouse/ClickHouse/issues/80963): Отключено проталкивание фильтра для предиката с недетерминированной функцией, если шаг плана запроса изменяет количество строк. Исправляет [#40273](https://github.com/ClickHouse/ClickHouse/issues/40273). [#80329](https://github.com/ClickHouse/ClickHouse/pull/80329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#81038](https://github.com/ClickHouse/ClickHouse/issues/81038): временная метка в таблице iceberg&#95;history теперь должна быть корректной. [#80711](https://github.com/ClickHouse/ClickHouse/pull/80711) ([Melvyn Peignon](https://github.com/melvynator)).
* Бэкпортировано в [#80755](https://github.com/ClickHouse/ClickHouse/issues/80755): Исправлено возможное аварийное завершение при сбое регистрации словаря (если `CREATE DICTIONARY` завершался ошибкой `CANNOT_SCHEDULE_TASK`, в реестре словарей мог остаться висячий указатель, что впоследствии приводило к аварийному завершению). [#80714](https://github.com/ClickHouse/ClickHouse/pull/80714) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#81143](https://github.com/ClickHouse/ClickHouse/issues/81143): Исправлен неверный тип результата функций сравнения для Tuple(Dynamic) и String, приводивший к логической ошибке. [#80728](https://github.com/ClickHouse/ClickHouse/pull/80728) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#80901](https://github.com/ClickHouse/ClickHouse/issues/80901): Исправлена ошибка `THERE_IS_NO_COLUMN` в distributed queries с `IN cte`. Исправляет [#75032](https://github.com/ClickHouse/ClickHouse/issues/75032). [#80757](https://github.com/ClickHouse/ClickHouse/pull/80757) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#80955](https://github.com/ClickHouse/ClickHouse/issues/80955): Исправлено чрезмерное количество файлов (что приводило к чрезмерному использованию памяти) при внешнем ORDER BY. [#80777](https://github.com/ClickHouse/ClickHouse/pull/80777) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#80872](https://github.com/ClickHouse/ClickHouse/issues/80872): Исправлено аварийное завершение в Kafka из-за того, что get&#95;member&#95;id() создавал std::string из NULL (вероятно, проблема возникала только при сбое connection к broker). [#80793](https://github.com/ClickHouse/ClickHouse/pull/80793) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#80912](https://github.com/ClickHouse/ClickHouse/issues/80912): Добавлено корректное ожидание consumers перед остановкой Kafka engine (активные consumers после остановки могут вызывать различные debug-assert&#39;ы, а также читать данные с brokers в фоновом режиме после удаления/отсоединения таблицы). [#80795](https://github.com/ClickHouse/ClickHouse/pull/80795) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#80936](https://github.com/ClickHouse/ClickHouse/issues/80936): Исправлен учёт памяти для кэша файлов метаданных Iceberg. [#80904](https://github.com/ClickHouse/ClickHouse/pull/80904) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#81061](https://github.com/ClickHouse/ClickHouse/issues/81061): Исправлено некорректное партиционирование с Nullable ключом партиционирования. [#80913](https://github.com/ClickHouse/ClickHouse/pull/80913) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Бэкпортировано в [#81099](https://github.com/ClickHouse/ClickHouse/issues/81099): Исправлена логическая ошибка во вложенных функциях с именованными окнами. [#80926](https://github.com/ClickHouse/ClickHouse/pull/80926) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Бэкпортировано в [#81003](https://github.com/ClickHouse/ClickHouse/issues/81003): исправлены экстремальные значения для столбцов Nullable и столбцов с плавающей точкой. [#80970](https://github.com/ClickHouse/ClickHouse/pull/80970) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Бэкпортировано в [#80987](https://github.com/ClickHouse/ClickHouse/issues/80987): исправлено возможное аварийное завершение при выполнении запроса к system.tables (вероятно, при нехватке памяти). [#80976](https://github.com/ClickHouse/ClickHouse/pull/80976) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#81010](https://github.com/ClickHouse/ClickHouse/issues/81010): исправлено атомарное переименование с truncate для файлов, у которых сжатие определяется по расширению файла. [#80979](https://github.com/ClickHouse/ClickHouse/pull/80979) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#81081](https://github.com/ClickHouse/ClickHouse/issues/81081): теперь ClickHouse будет игнорировать ошибки и неожиданные ответы от каталогов озёр данных в запросе `SHOW TABLES`. Исправляет [#79725](https://github.com/ClickHouse/ClickHouse/issues/79725). [#81046](https://github.com/ClickHouse/ClickHouse/pull/81046) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#81155](https://github.com/ClickHouse/ClickHouse/issues/81155): настройка date&#95;time&#95;input&#95;format теперь учитывается в кэше определения схемы. [#81052](https://github.com/ClickHouse/ClickHouse/pull/81052) ([Pavel Kruglov](https://github.com/Avogar)).
