<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#75642](https://github.com/ClickHouse/ClickHouse/issues/75642): Исправлено сообщение в журнале об ошибке сбоя init script в Docker, чтобы оно было понятнее. [#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* Бэкпортировано в [#75118](https://github.com/ClickHouse/ClickHouse/issues/75118): Исправлен сбой при вставке interval (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)). [#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* Бэкпортировано в [#75305](https://github.com/ClickHouse/ClickHouse/issues/75305): Исправлен сбой при разборе объявления JSON type, если имя типа указано не в верхнем регистре. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#76228](https://github.com/ClickHouse/ClickHouse/issues/76228): Исправлен сбой из-за uncaught exception в PSQL replication. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#76245](https://github.com/ClickHouse/ClickHouse/issues/76245): Sasl может приводить к сбою любого rpc-вызова; исправление позволяет повторить вызов, если истёк krb5 ticker. [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* Бэкпортировано в [#75403](https://github.com/ClickHouse/ClickHouse/issues/75403): Исправлено использование индексов (основного и secondary) для столбцов `Array`, `Map` и `Nullable(..)` при включенной настройке `optimize_function_to_subcolumns`. Ранее индексы для этих столбцов могли игнорироваться. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#76102](https://github.com/ClickHouse/ClickHouse/issues/76102): Исправлена обработка nullsafe JOIN для nullable-типа данных LowCardinality. Ранее `JOIN ON` со сравнением nullsafe, таким как `IS NOT DISTINCT FROM`, `<=>` , `a IS NULL AND b IS NULL OR a == b`, работал некорректно со столбцами LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#75566](https://github.com/ClickHouse/ClickHouse/issues/75566): Исправление Keeper: предотвращена запись в повреждённые changelog-файлы при откате журналов. [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#75742](https://github.com/ClickHouse/ClickHouse/issues/75742): Исправлен сбой в кеше схем Protobuf, который может возникать при выводе в формате Protobuf и параллельном выполнении запроса `SYSTEM DROP FORMAT SCHEMA CACHE`. [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#76094](https://github.com/ClickHouse/ClickHouse/issues/76094): Исправлена возможная ошибка `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes`, возникающая при использовании подстолбцов JSON типа Array в JOIN по distributed таблицам. [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#75890](https://github.com/ClickHouse/ClickHouse/issues/75890): Исправлены редкие сбои при чтении из таблицы `MergeTree` после нескольких асинхронных запросов `RENAME` (с `alter_sync = 0`) между столбцами разных типов. [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#75831](https://github.com/ClickHouse/ClickHouse/issues/75831): исправлено разыменование нулевого указателя в `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#76215](https://github.com/ClickHouse/ClickHouse/issues/76215): `clickhouse-library-bridge` позволяет открывать произвольные библиотеки из файловой системы, поэтому его безопасно запускать только в изолированной среде. Чтобы предотвратить уязвимость при запуске рядом с clickhouse-server, мы ограничим пути к библиотекам каталогом, указанным в конфигурации. Эта уязвимость была обнаружена в рамках [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) Арсением Дугиным. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### Улучшения сборки/тестирования/упаковки
</div>

* Бэкпортировано в [#76219](https://github.com/ClickHouse/ClickHouse/issues/76219): все действия, связанные с clickhouse-server, вынесены в функцию и выполняются только при запуске бинарного файла по умолчанию из `entrypoint.sh`. Это давно откладывавшееся улучшение было предложено в [#50724](https://github.com/ClickHouse/ClickHouse/issues/50724). В `clickhouse-extract-from-config` добавлен ключ `--users` для получения значений из `users.xml`. [#75643](https://github.com/ClickHouse/ClickHouse/pull/75643) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
