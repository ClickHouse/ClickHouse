<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#85683](https://github.com/ClickHouse/ClickHouse/issues/85683): Улучшена параллельная обработка файлов с использованием backend-соединения delta-kernel-rs. [#85642](https://github.com/ClickHouse/ClickHouse/pull/85642) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#86063](https://github.com/ClickHouse/ClickHouse/issues/86063): Представления, созданные эфемерными пользователями, теперь будут хранить копию реального пользователя и больше не будут становиться недействительными после удаления эфемерного пользователя. [#84763](https://github.com/ClickHouse/ClickHouse/pull/84763) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#85728](https://github.com/ClickHouse/ClickHouse/issues/85728): Добавлен флаг show&#95;data&#95;lake&#95;catalogs&#95;in&#95;system&#95;tables для управления добавлением таблиц озёр данных в system.tables; исправляет [#85384](https://github.com/ClickHouse/ClickHouse/issues/85384). [#85411](https://github.com/ClickHouse/ClickHouse/pull/85411) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Бэкпортировано в [#86251](https://github.com/ClickHouse/ClickHouse/issues/86251): Потоки S3-клиента в объектном хранилище S3 теперь замедляются при ошибках, допускающих повторную попытку. Это расширяет предыдущую настройку `backup_slow_all_threads_after_retryable_s3_error` на S3-диски и переименовывает её в более общую `s3_slow_all_threads_after_retryable_error`. [#85918](https://github.com/ClickHouse/ClickHouse/pull/85918) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#86503](https://github.com/ClickHouse/ClickHouse/issues/86503): Добавлена возможность включать JSON-логирование только для определённого канала; для этого установите `logger.formatting.channel` в одно из значений `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

* Бэкпортировано в [#84942](https://github.com/ClickHouse/ClickHouse/issues/84942): Закрывает [#81303](https://github.com/ClickHouse/ClickHouse/issues/81303). [#83892](https://github.com/ClickHouse/ClickHouse/pull/83892) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Бэкпортировано в [#85794](https://github.com/ClickHouse/ClickHouse/issues/85794): Исправлена запись JSON-путей со значениями NULL в формате RowBinary. [#83923](https://github.com/ClickHouse/ClickHouse/pull/83923) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#85881](https://github.com/ClickHouse/ClickHouse/issues/85881): Исправлено чтение столбца Variant с отложенной материализацией. [#84400](https://github.com/ClickHouse/ClickHouse/pull/84400) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#86056](https://github.com/ClickHouse/ClickHouse/issues/86056): Исправлен сбой сервера, возникавший, когда пользователь, созданный с `no_password`, пытался войти после изменения настройки сервера `allow_no_password` на 0. [#84426](https://github.com/ClickHouse/ClickHouse/pull/84426) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Бэкпортировано в [#85310](https://github.com/ClickHouse/ClickHouse/issues/85310): Теперь, если из таблицы удалены все TTL, MergeTree не будет выполнять никаких действий, связанных с TTL. [#84441](https://github.com/ClickHouse/ClickHouse/pull/84441) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#85304](https://github.com/ClickHouse/ClickHouse/issues/85304): Исправлено отсутствие проверки TTL-столбцов в ключах сортировки для ALTER MODIFY ORDER BY. Теперь TTL-столбцы корректно отклоняются при использовании в предложениях ORDER BY во время операций ALTER, что предотвращает возможное повреждение таблицы. [#84536](https://github.com/ClickHouse/ClickHouse/pull/84536) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* Бэкпортировано в [#85115](https://github.com/ClickHouse/ClickHouse/issues/85115): Добавлена проверка использования коррелированного подзапроса в распределённом контексте, чтобы избежать сбоя. Исправляет [#82205](https://github.com/ClickHouse/ClickHouse/issues/82205). [#85030](https://github.com/ClickHouse/ClickHouse/pull/85030) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#85269](https://github.com/ClickHouse/ClickHouse/issues/85269): Исправлено illegal&#95;type&#95;of&#95;argument в mv, когда типы различаются. [#85135](https://github.com/ClickHouse/ClickHouse/pull/85135) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#85234](https://github.com/ClickHouse/ClickHouse/issues/85234): Исправлен `Not-ready Set` для `IN (subquery)` внутри настройки `additional_table_filters expression`. [#85210](https://github.com/ClickHouse/ClickHouse/pull/85210) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

[#85220](https://github.com/ClickHouse/ClickHouse/pull/85220) ([Nikolay Degterinsky](https://github.com/evillique)).
