<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#99158](https://github.com/ClickHouse/ClickHouse/issues/99158): Запрещено удаление столбца, если его подстолбцы используются в выражениях default/alias других столбцов, а также задействован analyzer для default-выражений при alter drop column. [#98569](https://github.com/ClickHouse/ClickHouse/pull/98569) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Бэкпортировано в [#100080](https://github.com/ClickHouse/ClickHouse/issues/100080): Исправлено игнорирование TABLE&#95;UUID&#95;MISMATCH без analyzer. [#99380](https://github.com/ClickHouse/ClickHouse/pull/99380) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#100356](https://github.com/ClickHouse/ClickHouse/issues/100356): Исправлена некорректная оптимизация partition pruning для `toWeek()`, из-за которой запросы с `WHERE toWeek(date, mode) = N` возвращали пустой результат для недель 49–52 в таблицах, партицированных по `toYYYYMM(date)`. [#99542](https://github.com/ClickHouse/ClickHouse/pull/99542) ([Takumi Hara](https://github.com/takumihara)).
* Бэкпортировано в [#100168](https://github.com/ClickHouse/ClickHouse/issues/100168): ... [#100024](https://github.com/ClickHouse/ClickHouse/pull/100024) ([Shaohua Wang](https://github.com/tiandiwonder)).
* Бэкпортировано в [#100265](https://github.com/ClickHouse/ClickHouse/issues/100265): Исправлен редкий сбой при генерации исключения &quot;Memory Limit&quot; во время построения text index. [#100213](https://github.com/ClickHouse/ClickHouse/pull/100213) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#100342](https://github.com/ClickHouse/ClickHouse/issues/100342): Исправлено исключение `LOGICAL_ERROR` в запросах со столбцами `Dynamic`, CROSS JOIN и Runtime Filters, вызванное тем, что `ColumnVariant::filter` разделял указатели на variant column вместо их клонирования в ветке оптимизации `hasOnlyNulls`. Закрывает [https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147). [#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#100594](https://github.com/ClickHouse/ClickHouse/issues/100594): Исправлено исключение LOGICAL&#95;ERROR &quot;Stream ... not found&quot; при вставке в таблицу с вложенными столбцами `Array(JSON)` в часть Wide при `optimize_on_insert=0`. [#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#100887](https://github.com/ClickHouse/ClickHouse/issues/100887): Добавлена проверка paths записей файлов в metadata резервной копии, чтобы отклонять path traversal, абсолютные paths и пустые имена во время `RESTORE`. [#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#100725](https://github.com/ClickHouse/ClickHouse/issues/100725): Исправлены случаи NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK, когда часть projection SELECT содержит столбцы, отсутствующие в исходной части SELECT запроса. Закрывает [#100194](https://github.com/ClickHouse/ClickHouse/issues/100194). [#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Бэкпортировано в [#100918](https://github.com/ClickHouse/ClickHouse/issues/100918): Исправлен сбой server при использовании функции `has()` с PREWHERE/WHERE для ключа Tuple, содержащего элементы LowCardinality. [#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#100868](https://github.com/ClickHouse/ClickHouse/issues/100868): исправлены комбинаторы агрегатных функций `If`, `Distinct`, `DistinctIf`, `IfState ` с возвращаемым типом `Tuple` и одним или несколькими аргументами `Nullable`, которые не могли читать старые сериализованные состояния после появления `Nullable(Tuple)`. Закрывает [#98917](https://github.com/ClickHouse/ClickHouse/issues/98917). [#100826](https://github.com/ClickHouse/ClickHouse/pull/100826) ([Nihal Z. Miaji](https://github.com/nihalzp)).
