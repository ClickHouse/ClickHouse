<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#80466](https://github.com/ClickHouse/ClickHouse/issues/80466): Использование IColumn вместо Field в SingleValueDataGeneric. Это исправляет некорректные возвращаемые значения некоторых агрегатных функций, таких как `argMax`, для типов `Dynamic/Variant/JSON`. [#79166](https://github.com/ClickHouse/ClickHouse/pull/79166) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#80258](https://github.com/ClickHouse/ClickHouse/issues/80258): Исправляет ошибку AMBIGUOUS&#95;COLUMN&#95;NAME при ленивой материализации, когда до проекции для выполнения запроса не используется ни один столбец. Пример: SELECT * FROM t ORDER BY rand() LIMIT 5. [#79926](https://github.com/ClickHouse/ClickHouse/pull/79926) ([Igor Nikonov](https://github.com/devcrafter)).
* Бэкпортировано в [#80339](https://github.com/ClickHouse/ClickHouse/issues/80339): Исправлено чтение подстолбцов из движка Merge. [#80158](https://github.com/ClickHouse/ClickHouse/pull/80158) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#80506](https://github.com/ClickHouse/ClickHouse/issues/80506): Исправляет некорректную сериализацию вложенных числовых полей как строк в документах MongoDB. Убирает ограничение максимальной глубины для документов из MongoDB. [#80289](https://github.com/ClickHouse/ClickHouse/pull/80289) ([Kirill Nikiforov](https://github.com/allmazz)).
* Бэкпортировано в [#80402](https://github.com/ClickHouse/ClickHouse/issues/80402): Исправляет текстовое представление DateTime и DateTime64 для движка PostgreSQL. [#80301](https://github.com/ClickHouse/ClickHouse/pull/80301) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Бэкпортировано в [#80395](https://github.com/ClickHouse/ClickHouse/issues/80395): Исправляет ошибку `NOT_FOUND_COLUMN_IN_BLOCK`, вызванную оптимизацией проталкивания фильтра на этапе логического JOIN в случае, если выражение `ON` не является тривиальным равенством. Исправляет [#79647](https://github.com/ClickHouse/ClickHouse/issues/79647) Исправляет [#77848](https://github.com/ClickHouse/ClickHouse/issues/77848). [#80360](https://github.com/ClickHouse/ClickHouse/pull/80360) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
