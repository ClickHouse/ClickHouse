  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#102752](https://github.com/ClickHouse/ClickHouse/issues/102752): Исправлено завышение значения CurrentMetric для `NamedCollection` из-за `CREATE NAMED COLLECTION IF NOT EXISTS` на уже существующих коллекциях, а также отсутствие инициализации для коллекций, загружаемых из конфигурации или SQL-хранилища при запуске. Закрывает [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507). [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#102746](https://github.com/ClickHouse/ClickHouse/issues/102746): Исправлено бесконечное зависание `SYSTEM WAIT VIEW`, если refreshable materialized view удаляется во время ожидания. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
