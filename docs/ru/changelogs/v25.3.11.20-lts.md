  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#92181](https://github.com/ClickHouse/ClickHouse/issues/92181): Исправлено удаление неиспользуемых столбцов проекции при наличии `UNION`. Исправляет [#88180](https://github.com/ClickHouse/ClickHouse/issues/88180). [#88350](https://github.com/ClickHouse/ClickHouse/pull/88350) ([Sema Checherinda](https://github.com/CheSema)).
* Бэкпортировано в [#91390](https://github.com/ClickHouse/ClickHouse/issues/91390): Исправлена проверка привилегий с подстановочными знаками при частичном отзыве привилегий. Добавлено больше тестов. [#90922](https://github.com/ClickHouse/ClickHouse/pull/90922) ([pufit](https://github.com/pufit)).
* Бэкпортировано в [#91686](https://github.com/ClickHouse/ClickHouse/issues/91686): Исправлено чтение динамических подстолбцов из материализованных столбцов в мутациях. Закрывает [#90653](https://github.com/ClickHouse/ClickHouse/issues/90653). [#91040](https://github.com/ClickHouse/ClickHouse/pull/91040) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#91571](https://github.com/ClickHouse/ClickHouse/issues/91571): Сейчас этот параметр имеет значение false, поэтому при сбросе очереди async insert на удалённый сервер вставки всегда выполняются синхронно. Даже если для пользователя этот параметр установлен в True. [#91386](https://github.com/ClickHouse/ClickHouse/pull/91386) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#92131](https://github.com/ClickHouse/ClickHouse/issues/92131): Исправлен crash в `dictGetDescendants`, вызванный `NULL`, когда тип словаря поддерживает Hierarchy, но ни один столбец не является `HIERARCHICAL`. Закрывает [#92026](https://github.com/ClickHouse/ClickHouse/issues/92026). Закрывает [#92121](https://github.com/ClickHouse/ClickHouse/issues/92121). [#91420](https://github.com/ClickHouse/ClickHouse/pull/91420) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Бэкпортировано в [#91913](https://github.com/ClickHouse/ClickHouse/issues/91913): Исправлен LOGICAL&#95;ERROR в RecursiveCTEChunkGenerator. [#91827](https://github.com/ClickHouse/ClickHouse/pull/91827) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#92252](https://github.com/ClickHouse/ClickHouse/issues/92252): Добавлен механизм исправления для JSON с дублирующимся путём в общих данных и динамическими путями, что могло происходить из-за bug, исправленного в [https://github.com/ClickHouse/ClickHouse/pull/90816](https://github.com/ClickHouse/ClickHouse/pull/90816). [#91886](https://github.com/ClickHouse/ClickHouse/pull/91886) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92686](https://github.com/ClickHouse/ClickHouse/issues/92686): Исправлено кэширование схемы: в глоб-шаблонах она теперь кэшируется только для файла, по которому была определена, а не для всех файлов при определении схемы. Закрывает [#91745](https://github.com/ClickHouse/ClickHouse/issues/91745). [#92006](https://github.com/ClickHouse/ClickHouse/pull/92006) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92272](https://github.com/ClickHouse/ClickHouse/issues/92272): Исправлена замена UDF в формате. [#92210](https://github.com/ClickHouse/ClickHouse/pull/92210) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#92700](https://github.com/ClickHouse/ClickHouse/issues/92700): Исправлен проход `count_distinct_optimization` для оконных функций и нескольких аргументов. [#92376](https://github.com/ClickHouse/ClickHouse/pull/92376) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#92454](https://github.com/ClickHouse/ClickHouse/issues/92454): Исправлен возможный crash в агрегатных функциях после MEMORY&#95;LIMIT&#95;EXCEEDED. [#92390](https://github.com/ClickHouse/ClickHouse/pull/92390) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#92737](https://github.com/ClickHouse/ClickHouse/issues/92737): Исправлена ошибка в логике пропуска данных при использовании `not match(...)` в предложении `WHERE`, которая приводила к некорректным результатам. Закрывает [#92492](https://github.com/ClickHouse/ClickHouse/issues/92492). [#92726](https://github.com/ClickHouse/ClickHouse/pull/92726) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Бэкпортировано в [#92765](https://github.com/ClickHouse/ClickHouse/issues/92765): Не пытаться удалять временные каталоги при запуске, если таблица семейства MergeTree создана на диске только для чтения. [#92748](https://github.com/ClickHouse/ClickHouse/pull/92748) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
