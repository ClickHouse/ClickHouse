<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#94933](https://github.com/ClickHouse/ClickHouse/issues/94933): Добавлена принудительная очистка арен jemalloc в случае, если отношение размера грязных страниц к `max_server_memory_usage` превышает `memory_worker_purge_dirty_pages_threshold_ratio`. [#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)).
* Бэкпортировано в [#94729](https://github.com/ClickHouse/ClickHouse/issues/94729): Добавлена поддержка именованных коллекций, определяемых через SQL, в BACKUP/RESTORE для S3 и Azure Blob Storage. Закрывает [#94604](https://github.com/ClickHouse/ClickHouse/issues/94604). [#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#95166](https://github.com/ClickHouse/ClickHouse/issues/95166): Очистка грязных страниц jemalloc теперь выполняется в отдельном потоке, а не в основном потоке MemoryWorker. Если очистка выполняется медленно, это может задерживать обновление использования RSS, что может привести к принудительному завершению процесса из-за нехватки памяти. Добавлен новый параметр конфигурации `memory_worker_purge_total_memory_threshold_ratio`, чтобы запускать очистку грязных страниц на основе отношения общего использования памяти. [#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#94765](https://github.com/ClickHouse/ClickHouse/issues/94765): Исправлен результат JOIN, когда ключ JOIN на правой стороне является разреженным столбцом. Это закрывает [#92920](https://github.com/ClickHouse/ClickHouse/issues/92920). Я могу воспроизвести эту ошибку только с `set compatibility='23.3'`. Не уверен, стоит ли это бэкпортировать. [#93038](https://github.com/ClickHouse/ClickHouse/pull/93038) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#94886](https://github.com/ClickHouse/ClickHouse/issues/94886): Исправлено подключение БД Replicated, если межсерверный хост изменился после перезапуска. [#93779](https://github.com/ClickHouse/ClickHouse/pull/93779) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Бэкпортировано в [#94592](https://github.com/ClickHouse/ClickHouse/issues/94592): Исправлено преобразование типа к супертипу во время операции JOIN для хранилища `Join` с предложением `USING`. Исправляет [#91672](https://github.com/ClickHouse/ClickHouse/issues/91672). Исправляет [#78572](https://github.com/ClickHouse/ClickHouse/issues/78572). [#94000](https://github.com/ClickHouse/ClickHouse/pull/94000) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#94357](https://github.com/ClickHouse/ClickHouse/issues/94357): Исправлена некорректная проверка типизированных путей в JSON. Проверка была добавлена в [https://github.com/ClickHouse/ClickHouse/pull/92842](https://github.com/ClickHouse/ClickHouse/pull/92842) и может приводить к ошибке при запуске существующих таблиц. [#94070](https://github.com/ClickHouse/ClickHouse/pull/94070) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#95202](https://github.com/ClickHouse/ClickHouse/issues/95202): Исправлено, что оптимизация функций для подстолбцов не применялась к подстолбцам. [#94323](https://github.com/ClickHouse/ClickHouse/pull/94323) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#94718](https://github.com/ClickHouse/ClickHouse/issues/94718): Исправлен сбой во время оптимизации ANY LEFT JOIN, когда `isNotNull` вычисляется для отсутствующего столбца. [#94600](https://github.com/ClickHouse/ClickHouse/pull/94600) ([Molly](https://github.com/ggmolly)).
* Бэкпортировано в [#94813](https://github.com/ClickHouse/ClickHouse/issues/94813): Исправлены проблемы с разрешениями при операциях BACKUP/RESTORE. [#94617](https://github.com/ClickHouse/ClickHouse/pull/94617) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#94844](https://github.com/ClickHouse/ClickHouse/issues/94844): Исправляет [https://github.com/ClickHouse/clickhouse-core-incidents/issues/1250](https://github.com/ClickHouse/clickhouse-core-incidents/issues/1250). Вероятно, из-за путаницы `data_type` (который может быть `DataTypeNullable*`) приводится через `static_cast` к `DataTypeDateTime64*`. Вместо этого следует приводить `check_type` (переменную Nested type). [#94627](https://github.com/ClickHouse/ClickHouse/pull/94627) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпортировано в [#94796](https://github.com/ClickHouse/ClickHouse/issues/94796): Исправлен потенциально некорректный результат RIGHT JOIN при использовании сложных условий ON. Закрывает [#92913](https://github.com/ClickHouse/ClickHouse/issues/92913). [#94680](https://github.com/ClickHouse/ClickHouse/pull/94680) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#94786](https://github.com/ClickHouse/ClickHouse/issues/94786): Сохраняется постоянная гранулярность индекса (use&#95;const&#95;adaptive&#95;granularity) после Вертикального слияния. [#94725](https://github.com/ClickHouse/ClickHouse/pull/94725) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#95150](https://github.com/ClickHouse/ClickHouse/issues/95150): в функции `getURLHostRFC` отсутствовали проверки границ перед разыменованием указателей. При передаче пустой строки в `domainRFC` происходило чтение неинициализированной памяти, что вызывало ошибки MSan. [#94851](https://github.com/ClickHouse/ClickHouse/pull/94851) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#94994](https://github.com/ClickHouse/ClickHouse/issues/94994): исправлен режим только для чтения для зашифрованных дисков. [#94852](https://github.com/ClickHouse/ClickHouse/pull/94852) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#95034](https://github.com/ClickHouse/ClickHouse/issues/95034): исправлена логическая ошибка в дробном `LIMIT/OFFSET` при использовании старого analyzer с Distributed tables. Закрывает [#94712](https://github.com/ClickHouse/ClickHouse/issues/94712). [#94999](https://github.com/ClickHouse/ClickHouse/pull/94999) ([Ahmed Gouda](https://github.com/0xgouda)).
* Бэкпортировано в [#95215](https://github.com/ClickHouse/ClickHouse/issues/95215): исправлен crash, возникавший при некоторых условиях, когда runtime-фильтры JOIN включены по умолчанию. [#95000](https://github.com/ClickHouse/ClickHouse/pull/95000) ([Alexander Gololobov](https://github.com/davenger)).
