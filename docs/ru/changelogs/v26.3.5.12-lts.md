<div id="performance-improvement">
  #### Повышение производительности
</div>

* Бэкпортировано в [#101736](https://github.com/ClickHouse/ClickHouse/issues/101736): исправлена существенная регрессия производительности INSERT при `deduplicate_insert=enable` (по умолчанию начиная с 26.2) за счёт переноса вычисления хеша данных с этапа squashing в sink и использования батч-хеширования столбцов через `updateHashWithValueRange`, что позволило снизить накладные расходы примерно с ~2.5s до ~0.5s для 5M строк с 22 столбцами. [#101494](https://github.com/ClickHouse/ClickHouse/pull/101494) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#101949](https://github.com/ClickHouse/ClickHouse/issues/101949): Оптимизирована загрузка кэша при запуске сервера. [#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#102140](https://github.com/ClickHouse/ClickHouse/issues/102140): Обновлён внутренний `mongo-c-driver` с 2.2.2 до 2.2.3. [#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#101962](https://github.com/ClickHouse/ClickHouse/issues/101962): Исправлены неверные результаты, когда JOIN с оптимизацией shard-by-PK использует кэш условий запроса, а некоторые части отфильтровываются закэшированными условиями. [#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#101987](https://github.com/ClickHouse/ClickHouse/issues/101987): Исправлены ошибки &quot;Целевая таблица не существует&quot; для materialized view с внутренними таблицами при асинхронном запуске, вызванные неправильным порядком зависимостей при старте. [#100946](https://github.com/ClickHouse/ClickHouse/pull/100946) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#101563](https://github.com/ClickHouse/ClickHouse/issues/101563): Исправлен INSERT SELECT из кластера Delta Lake с replicated merge tree. [#101299](https://github.com/ClickHouse/ClickHouse/pull/101299) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Бэкпортировано в [#102076](https://github.com/ClickHouse/ClickHouse/issues/102076): Исправлено использование памяти после выхода из области видимости при параллельной десериализации динамических путей типа `Object`, что могло приводить к сбоям при чтении таблиц с большим количеством динамических путей. [#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#102102](https://github.com/ClickHouse/ClickHouse/issues/102102): Исправлен некорректный вывод функции `formatDateTime` с форматтером `%W` при определённых (не используемых по умолчанию) настройках форматирования. [#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* Бэкпортировано в [#102030](https://github.com/ClickHouse/ClickHouse/issues/102030): Исправлена потеря реестра UDF при истечении сеанса ZooKeeper во время периодического обновления — все Пользовательские функции могли становиться недоступными, пока не завершится успешное полное обновление. [#101891](https://github.com/ClickHouse/ClickHouse/pull/101891) ([Nikita Fomichev](https://github.com/fm4v)).
* Бэкпортировано в [#102094](https://github.com/ClickHouse/ClickHouse/issues/102094): Токенизатор `splitByString` теперь не принимает пустые строки-разделители. [#101928](https://github.com/ClickHouse/ClickHouse/pull/101928) ([Robert Schulze](https://github.com/rschu1ze)).
