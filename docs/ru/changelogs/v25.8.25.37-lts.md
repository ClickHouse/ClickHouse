<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#105448](https://github.com/ClickHouse/ClickHouse/issues/105448): исправлено неперехваченное исключение при фоновой перезагрузке именованных коллекций при использовании хранилища ZooKeeper. Закрывает [https://github.com/ClickHouse/clickhouse-private/issues/44180](https://github.com/ClickHouse/clickhouse-private/issues/44180). [#92717](https://github.com/ClickHouse/ClickHouse/pull/92717) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#107770](https://github.com/ClickHouse/ClickHouse/issues/107770): выполнена очистка `query_id` в HTTP-обработчике, чтобы предотвратить CRLF-инъекцию в заголовки ответа через заголовок `X-ClickHouse-Query-Id`. [#100500](https://github.com/ClickHouse/ClickHouse/pull/100500) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#105377](https://github.com/ClickHouse/ClickHouse/issues/105377): добавлена проверка переполнения стека в считывателе Avro при десериализации типов Nested. [#102417](https://github.com/ClickHouse/ClickHouse/pull/102417) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#105400](https://github.com/ClickHouse/ClickHouse/issues/105400): исправлен `RESTORE` реплицируемых таблиц `MergeTree`, чтобы при подключении восстановленных частей использовался `backup_restore_keeper_max_retries` вместо обычного бюджета повторных попыток Keeper для вставки. [#104610](https://github.com/ClickHouse/ClickHouse/pull/104610) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#105619](https://github.com/ClickHouse/ClickHouse/issues/105619): исправлено переполнение буфера кучи при чтении файлов Arrow или ArrowStream с поврежденными промежуточными смещениями в двоичном или строковом столбце, а также разыменование нулевого указателя при чтении столбцов Arrow с геотегами. [#105449](https://github.com/ClickHouse/ClickHouse/pull/105449) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#106483](https://github.com/ClickHouse/ClickHouse/issues/106483): исправлен SIGSEGV при чтении подстолбцов Dynamic из сжатой таблицы Memory после ALTER. Закрывает [#104901](https://github.com/ClickHouse/ClickHouse/issues/104901). [#105464](https://github.com/ClickHouse/ClickHouse/pull/105464) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#105967](https://github.com/ClickHouse/ClickHouse/issues/105967): исправлен SEGFAULT при десериализации `singleValueOrNull` для типа JSON. Закрывает [#103630](https://github.com/ClickHouse/ClickHouse/issues/103630). [#105535](https://github.com/ClickHouse/ClickHouse/pull/105535) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#106553](https://github.com/ClickHouse/ClickHouse/issues/106553): исправлено падение сервера (SIGSEGV), которое мог вызвать любой пользователь с правами `CREATE TABLE`, отправив `CREATE TABLE ... TO INNER UUID '...'` без предложения `ENGINE` по HTTP или через собственный протокол. Та же ошибка также приводила к падению клиента. Теперь парсер сообщает корректную ошибку `BAD_ARGUMENTS` вместо разыменования нулевого указателя. [#105579](https://github.com/ClickHouse/ClickHouse/pull/105579) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#106762](https://github.com/ClickHouse/ClickHouse/issues/106762): исправлено падение при вставке Tuple разного размера в одном выражении VALUES в столбец String. Закрывает [#101727](https://github.com/ClickHouse/ClickHouse/issues/101727). [#105582](https://github.com/ClickHouse/ClickHouse/pull/105582) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#106754](https://github.com/ClickHouse/ClickHouse/issues/106754): исправлено чтение за пределами буфера при десериализации Native для плоского столбца типа Dynamic. [#105666](https://github.com/ClickHouse/ClickHouse/pull/105666) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#105854](https://github.com/ClickHouse/ClickHouse/issues/105854): Исправлен сбой в табличной функции `mongodb`, хранилилище MongoDB и источнике словаря MongoDB, если имя collection пустое или содержит байты NUL. [#105776](https://github.com/ClickHouse/ClickHouse/pull/105776) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#106467](https://github.com/ClickHouse/ClickHouse/issues/106467): Исправлена ситуация, когда `system.dictionaries` возвращала 0 строк при частичном отзыве `SHOW DICTIONARIES`. [#106105](https://github.com/ClickHouse/ClickHouse/pull/106105) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#107967](https://github.com/ClickHouse/ClickHouse/issues/107967): Исправлены сбой и возможная ошибка `NOT_FOUND_COLUMN_IN_BLOCK` при использовании оптимизации на основе ограничений (`optimize_using_constraints`) с коррелированными подзапросами. [#106349](https://github.com/ClickHouse/ClickHouse/pull/106349) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#107348](https://github.com/ClickHouse/ClickHouse/issues/107348): Исправлены множественные чтения за пределами кучи в ридере формата Arrow IPC (`ArrowColumnToCHColumn`). Некорректный файл Arrow мог объявлять больше строк, чем содержат его буферы, задавать длины дочерних элементов list/struct/map, не согласованные с родительским элементом, передавать немонотонные offsets list или обрезать битмап валидности дочернего элемента, что приводило к чтению за пределами выделений в куче. Это было доступно любому пользователю с привилегией `SELECT` через `file()`, `format()`, table functions или входы ArrowFlight. Теперь все буферы данных, offsets, view-struct и validity-bitmap проверяются до любого доступа через raw pointer, а формы и offsets list/struct/map — на согласованность. [#106395](https://github.com/ClickHouse/ClickHouse/pull/106395) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#107839](https://github.com/ClickHouse/ClickHouse/issues/107839): Исправлены множественные проблемы с безопасностью памяти и исчерпанием ресурсов в ридерах форматов, достижимые через недоверенный ввод: чтение за пределами кучи при обработке длины уровней definition/repetition в `DataPageV2` native ридера Parquet, переполнение стека на файлах Parquet с глубоко вложенными схемами, а также выделения памяти, игнорировавшие `max_memory_usage` при parsing geometry GeoParquet WKB/WKT и строк/байтов Avro. [#106739](https://github.com/ClickHouse/ClickHouse/pull/106739) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#106786](https://github.com/ClickHouse/ClickHouse/issues/106786): Исправлено переполнение буфера кучи (сбой server) в `decodeHTMLComponent` при декодировании строк, содержащих расширяющиеся HTML-сущности `&nGt;` или `&nLt;`; проблема была достижима для любого пользователя с одним `SELECT`. [#106741](https://github.com/ClickHouse/ClickHouse/pull/106741) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#107275](https://github.com/ClickHouse/ClickHouse/issues/107275): Mutex больше не удерживается во время reads из ZooKeeper при refresh сущностей доступа. [#107097](https://github.com/ClickHouse/ClickHouse/pull/107097) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#108278](https://github.com/ClickHouse/ClickHouse/issues/108278): Исправлено возможное переполнение стека server (сбой) при чтении глубоко вложенной схемы или значения в форматах MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg и Paimon. Такой глубоко вложенный ввод теперь отклоняется с исключением. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#108220](https://github.com/ClickHouse/ClickHouse/issues/108220): Исправлено переполнение буфера кучи (сбой server) в `windowFunnel` при финализации специально сформированного состояния aggregate-function с типом события вне допустимого диапазона; проблема была достижима для любого пользователя с одним `SELECT`. [#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* Бэкпортировано в [#107712](https://github.com/ClickHouse/ClickHouse/issues/107712): Исправлен выход за нижнюю границу диапазона целого числа в парсере протокола PostgreSQL wire protocol: сообщение с полем длины меньше 4 приводило к переполнению при вычислении `size - 4` и к чрезмерному `resize`/`ignore`. [#107485](https://github.com/ClickHouse/ClickHouse/pull/107485) ([uwezkhan](https://github.com/uwezkhan)).
* Бэкпортировано в [#108236](https://github.com/ClickHouse/ClickHouse/issues/108236): Добавлены недостающие проверки границ при разборе ELF и DWARF. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#107874](https://github.com/ClickHouse/ClickHouse/issues/107874): Добавлены недостающие проверки границ в ORC reader. [#107580](https://github.com/ClickHouse/ClickHouse/pull/107580) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#107870](https://github.com/ClickHouse/ClickHouse/issues/107870): Исправлены две уязвимости обхода пути в протоколе fetch реплицируемых частей, из-за которых вредоносная реплика могла записывать файлы за пределами каталога части. [#107606](https://github.com/ClickHouse/ClickHouse/pull/107606) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#108649](https://github.com/ClickHouse/ClickHouse/issues/108649): Исправлен `RESTORE` для таблиц `ReplicatedMergeTree`, чтобы части с одинаковым содержимым из резервной копии сохранялись, а не молча дедуплицировались. [#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#108155](https://github.com/ClickHouse/ClickHouse/issues/108155): Чтение данных Arrow/ArrowStream с пустыми столбцами `String`/`Binary`, созданных в Apache Arrow Java &lt; 19.0.0 (включая Apache Spark), больше не приводит к `INCORRECT_DATA`. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#108302](https://github.com/ClickHouse/ClickHouse/issues/108302): Исправлен сбой (SIGSEGV в release-сборках, assertion о несоответствии типов в debug-сборках) в `has` для `Map` с ключом `Dynamic`, когда аргумент lookup имеет тип `LowCardinality`, например `has(map('a'::Dynamic, ...), toLowCardinality('b'))`. [#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* Бэкпортировано в [#108531](https://github.com/ClickHouse/ClickHouse/issues/108531): Скрыты секретные аргументы таких функций, как `encrypt`, `decrypt` и `HMAC`, в выводе `EXPLAIN actions`, `EXPLAIN header` и `EXPLAIN PIPELINE`, когда `format_display_secrets_in_show_and_select` отключён (по умолчанию). [#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
