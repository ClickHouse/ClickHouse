<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#82187](https://github.com/ClickHouse/ClickHouse/issues/82187): Исправлена логическая ошибка при материализации проекции, когда тип столбца был изменён на Nullable. [#80741](https://github.com/ClickHouse/ClickHouse/pull/80741) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#82332](https://github.com/ClickHouse/ClickHouse/issues/82332): Исправлено выполнение `IN` с `transform_null_in=1`, когда в левом аргументе используется null, а подзапрос возвращает результат без Nullable. [#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#82177](https://github.com/ClickHouse/ClickHouse/issues/82177): Отключена проверка экспериментальных/подозрительных типов при выполнении выражений default/materialize во время чтения из существующей таблицы. [#81618](https://github.com/ClickHouse/ClickHouse/pull/81618) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#82032](https://github.com/ClickHouse/ClickHouse/issues/82032): Исправлена проблема, из-за которой при обработке скалярного коррелированного подзапроса не читались необходимые столбцы. Исправляет [#81716](https://github.com/ClickHouse/ClickHouse/issues/81716). [#81805](https://github.com/ClickHouse/ClickHouse/pull/81805) ([Dmitry Novik](https://github.com/novikd)).
* Бэкпортировано в [#82324](https://github.com/ClickHouse/ClickHouse/issues/82324): В предыдущих версиях server возвращал избыточное содержимое в ответ на запросы к `/js`. Это закрывает [#61890](https://github.com/ClickHouse/ClickHouse/issues/61890). [#81895](https://github.com/ClickHouse/ClickHouse/pull/81895) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Бэкпортировано в [#82236](https://github.com/ClickHouse/ClickHouse/issues/82236): Ранее определения движка таблицы `MongoDB` могли включать компонент path в аргументе `host:port`, который молча игнорировался. Интеграция MongoDB отказывается загружать такие таблицы. С этим исправлением *разрешена загрузка таких таблиц с игнорированием компонента path*, если движок `MongoDB` имеет пять аргументов, при этом используется имя базы данных из аргументов. *Note:* Исправление не применяется к вновь создаваемым таблицам, запросам с table function `mongo`, а также к dictionary sources и named collections. [#81942](https://github.com/ClickHouse/ClickHouse/pull/81942) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#82098](https://github.com/ClickHouse/ClickHouse/issues/82098): Исправлено возможное аварийное завершение `Aggregator` в случае Исключение во время merge. [#82022](https://github.com/ClickHouse/ClickHouse/pull/82022) ([Nikita Taranov](https://github.com/nickitat)).
* Бэкпортировано в [#82552](https://github.com/ClickHouse/ClickHouse/issues/82552): Исправлены LOGICAL&#95;ERROR и последующее аварийное завершение при использовании одного и того же столбца в TTL для GROUP BY и SET. [#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* Бэкпортировано в [#82154](https://github.com/ClickHouse/ClickHouse/issues/82154): Исправлена ошибка copy-paste в `arraySimilarity`, из-за которой запрещалось использовать веса UInt32 и Int32. Обновлены тесты и документация. [#82103](https://github.com/ClickHouse/ClickHouse/pull/82103) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Бэкпортировано в [#82318](https://github.com/ClickHouse/ClickHouse/issues/82318): Исправлена ошибка `Not found column` для запросов с `arrayJoin` в условии `WHERE` и `IndexSet`. [#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Бэкпортировано в [#82262](https://github.com/ClickHouse/ClickHouse/issues/82262): Исправлена ошибка в интеграции с Glue catalog. Теперь ClickHouse может читать таблицы с вложенными типами данных, в которых некоторые подстолбцы содержат десятичные значения, например: `map<string, decimal(9, 2)>`. Исправляет [#81301](https://github.com/ClickHouse/ClickHouse/issues/81301). [#82114](https://github.com/ClickHouse/ClickHouse/pull/82114) ([alesapin](https://github.com/alesapin)).
* Бэкпортировано в [#82588](https://github.com/ClickHouse/ClickHouse/issues/82588): Исправлена ошибка в зависимостях таблиц, из-за которой materialized view пропускали запросы INSERT. [#82222](https://github.com/ClickHouse/ClickHouse/pull/82222) ([Nikolay Degterinsky](https://github.com/evillique)).
* Бэкпортировано в [#82523](https://github.com/ClickHouse/ClickHouse/issues/82523): Для токена AWS ECS добавлен срок действия, чтобы его можно было обновлять. [#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#82579](https://github.com/ClickHouse/ClickHouse/issues/82579): Исправлено скрытие значений named collection в логах/query&#95;log. Закрывает [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405). [#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#82570](https://github.com/ClickHouse/ClickHouse/issues/82570): Исправлено возможное аварийное завершение при logging во время завершения сеанса, поскольку user&#95;id иногда может быть пустым. [#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
