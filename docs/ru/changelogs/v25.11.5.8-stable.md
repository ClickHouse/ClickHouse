<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#92901](https://github.com/ClickHouse/ClickHouse/issues/92901): Исправлен возможный конфликт между столбцом и подстолбцом с одинаковым именем, который приводил к использованию неверной сериализации и сбоям запросов. Закрывает [#90219](https://github.com/ClickHouse/ClickHouse/issues/90219). Закрывает [#85161](https://github.com/ClickHouse/ClickHouse/issues/85161). [#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92988](https://github.com/ClickHouse/ClickHouse/issues/92988): Предотвращено аварийное завершение из-за чтения из отключённого `Connection`. [#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Бэкпортировано в [#92879](https://github.com/ClickHouse/ClickHouse/issues/92879): Исправлена логическая ошибка ` Failed to set file processing within 100 retries` в хранилище `S3Queue` в режиме `Ordered`. Теперь вместо неё выводится предупреждение. Эта ошибка могла возникать до версии 25.10, если истекал сеанс Keeper, однако в версиях 25.10+ она по-прежнему будет отображаться как предупреждение, поскольку теоретически её всё ещё можно получить при высоком параллелизме обработки в режиме `Ordered`. [#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#92943](https://github.com/ClickHouse/ClickHouse/issues/92943): Исправлено использование первичного индекса в легковесных обновлениях, содержащих предложение `IN` с подзапросами в предикате предложения `WHERE`. [#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#92962](https://github.com/ClickHouse/ClickHouse/issues/92962): Исправлена возможная ошибка `FILE_DOESNT_EXIST` после мутации разреженного столбца с `ratio_of_defaults_for_sparse_serialization=0.0`. Закрывает [#92633](https://github.com/ClickHouse/ClickHouse/issues/92633). [#92860](https://github.com/ClickHouse/ClickHouse/pull/92860) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#92934](https://github.com/ClickHouse/ClickHouse/issues/92934): Исправлено определение схемы Parquet в старом ридере Parquet (по умолчанию не используется), когда JSON-столбец идёт после столбца Tuple. Также исправлена ошибка старого ридера Parquet (по умолчанию не используется) при обработке пустых Tuple. [#92867](https://github.com/ClickHouse/ClickHouse/pull/92867) ([Michael Kolupaev](https://github.com/al13n321)).
* Бэкпортировано в [#93032](https://github.com/ClickHouse/ClickHouse/issues/93032): Исправлено возможное использование устаревших частей из-за гонки TOCTOU для разделяемых частей. [#93022](https://github.com/ClickHouse/ClickHouse/pull/93022) ([Azat Khuzhin](https://github.com/azat)).
