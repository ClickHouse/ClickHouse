  ### Релиз ClickHouse v24.8.6.70-lts (ddb8c219771) FIXME в сравнении с v24.8.5.115-lts (8c4cb00a384)

<div id="backward-incompatible-change">
  #### Обратно несовместимое изменение
</div>

* Бэкпортировано в [#71359](https://github.com/ClickHouse/ClickHouse/issues/71359): Исправлена возможная ошибка `No such file or directory`, вызванная неэкранированными специальными символами в файлах подстолбцов JSON. [#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### Улучшения
</div>

* Бэкпортировано в [#70680](https://github.com/ClickHouse/ClickHouse/issues/70680): Не выполнять проверку при синхронизации user&#95;directories из Keeper. [#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#71395](https://github.com/ClickHouse/ClickHouse/issues/71395): Не вызывать API объектного хранилища при перечислении каталогов, так как это может быть слишком затратно. Вместо этого хранить список имён файлов в памяти. Компромиссы — увеличение времени начальной загрузки и объёма памяти, необходимого для хранения имён файлов. [#70823](https://github.com/ClickHouse/ClickHouse/pull/70823) ([Julia Kartseva](https://github.com/jkartseva)).
* Бэкпортировано в [#71287](https://github.com/ClickHouse/ClickHouse/issues/71287): Сократить количество HEAD-запросов к API объектного хранилища на диске plain&#95;rewritable. [#70915](https://github.com/ClickHouse/ClickHouse/pull/70915) ([Julia Kartseva](https://github.com/jkartseva)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#70934](https://github.com/ClickHouse/ClickHouse/issues/70934): Исправлена некорректная оптимизация секции JOIN ON в случае проверки `IS NULL` внутри любой другой функции (например, `NOT`), что могло приводить к неверным результатам. Закрывает [#67915](https://github.com/ClickHouse/ClickHouse/issues/67915). [#68049](https://github.com/ClickHouse/ClickHouse/pull/68049) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Бэкпортировано в [#70735](https://github.com/ClickHouse/ClickHouse/issues/70735): Исправлено неожиданное исключение при передаче пустого кортежа в массиве. Это исправляет [#68618](https://github.com/ClickHouse/ClickHouse/issues/68618). [#68848](https://github.com/ClickHouse/ClickHouse/pull/68848) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#71138](https://github.com/ClickHouse/ClickHouse/issues/71138): Исправлена передача аргумента structure в s3Cluster. Ранее выражение `DEFAULT` столбца могло теряться при отправке запроса репликам в s3Cluster. [#69147](https://github.com/ClickHouse/ClickHouse/pull/69147) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#70561](https://github.com/ClickHouse/ClickHouse/issues/70561): Исправлен `getSubcolumn` для столбцов `LowCardinality` за счёт переопределения `useDefaultImplementationForLowCardinalityColumns`, чтобы метод возвращал `true`. [#69831](https://github.com/ClickHouse/ClickHouse/pull/69831) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Бэкпортировано в [#70903](https://github.com/ClickHouse/ClickHouse/issues/70903): Исключено повторное использование столбцов между разными именованными кортежами при вычислении функций `tuple`. Это исправляет [#70022](https://github.com/ClickHouse/ClickHouse/issues/70022). [#70103](https://github.com/ClickHouse/ClickHouse/pull/70103) ([Amos Bird](https://github.com/amosbird)).
* Бэкпортировано в [#70623](https://github.com/ClickHouse/ClickHouse/issues/70623): Исправлен segfault сервера при создании materialized view с двумя операторами SELECT и `INTERSECT`, например `CREATE MATERIALIZED VIEW v0 AS (SELECT 1) INTERSECT (SELECT 1);`. [#70264](https://github.com/ClickHouse/ClickHouse/pull/70264) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#70688](https://github.com/ClickHouse/ClickHouse/issues/70688): Исправлена возможная ошибка use-after-free в `SYSTEM DROP FORMAT SCHEMA CACHE FOR Protobuf`. [#70358](https://github.com/ClickHouse/ClickHouse/pull/70358) ([Azat Khuzhin](https://github.com/azat)).
* Бэкпортировано в [#70494](https://github.com/ClickHouse/ClickHouse/issues/70494): Исправлен crash во время GROUP BY по подстолбцу JSON-подобъекта. [#70374](https://github.com/ClickHouse/ClickHouse/pull/70374) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#70482](https://github.com/ClickHouse/ClickHouse/issues/70482): Не выполнять prefetch частей для вертикальных слияний, если часть не содержит строк. [#70452](https://github.com/ClickHouse/ClickHouse/pull/70452) ([Antonio Andelic](https://github.com/antonio2368)).
* Бэкпортировано в [#70556](https://github.com/ClickHouse/ClickHouse/issues/70556): Исправлен crash в предложении WHERE с лямбда-функциями. [#70464](https://github.com/ClickHouse/ClickHouse/pull/70464) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#70878](https://github.com/ClickHouse/ClickHouse/issues/70878): Исправлено создание таблицы с `CREATE ... AS table_function()` в базе данных `Replicated` при недоступном источнике table function на вторичной реплике. [#70511](https://github.com/ClickHouse/ClickHouse/pull/70511) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Бэкпортировано в [#70575](https://github.com/ClickHouse/ClickHouse/issues/70575): Игнорировать любой вывод при async insert с `wait_for_async_insert=1`. Закрывает [#62644](https://github.com/ClickHouse/ClickHouse/issues/62644). [#70530](https://github.com/ClickHouse/ClickHouse/pull/70530) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Бэкпортировано в [#71052](https://github.com/ClickHouse/ClickHouse/issues/71052): Игнорировать frozen&#95;metadata.txt при обходе каталога shadow из system.remote&#95;data&#95;paths. [#70590](https://github.com/ClickHouse/ClickHouse/pull/70590) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Бэкпортировано в [#70651](https://github.com/ClickHouse/ClickHouse/issues/70651): Исправлено создание оконных функций с сохранением состояния при работе с невыровненной памятью. [#70631](https://github.com/ClickHouse/ClickHouse/pull/70631) ([Raúl Marín](https://github.com/Algunenano)).
* Бэкпортировано в [#70757](https://github.com/ClickHouse/ClickHouse/issues/70757): Исправлены редкие сбои в запросах `SELECT` и слияниях после добавления столбца типа `Array` с непустым выражением по умолчанию. [#70695](https://github.com/ClickHouse/ClickHouse/pull/70695) ([Anton Popov](https://github.com/CurtizJ)).
* Бэкпортировано в [#70763](https://github.com/ClickHouse/ClickHouse/issues/70763): Исправлена бесконечная рекурсия при выводе proto-схемы с включённой опцией skip unsupported fields. [#70697](https://github.com/ClickHouse/ClickHouse/pull/70697) ([Raúl Marín](https://github.com/Algunenano)).
