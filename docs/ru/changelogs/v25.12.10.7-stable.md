<div id="improvement">
  #### Улучшения

* Бэкпортировано в [#100462](https://github.com/ClickHouse/ClickHouse/issues/100462): для потоков std внутри poco задано `this->exceptions(std::ios::badbit);`. [#96455](https://github.com/ClickHouse/ClickHouse/pull/96455) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Исправление ошибки (некорректное поведение, заметное пользователю, в официальном стабильном релизе)
</div>

* Бэкпортировано в [#99090](https://github.com/ClickHouse/ClickHouse/issues/99090): Исправлен доступ по имени к подстолбцу Tuple (например, `SELECT x.a` для `Tuple(a UUID, b Int32)`) во внешних таблицах, передаваемых через `--external` в `clickhouse-client`. Закрывает [#96925](https://github.com/ClickHouse/ClickHouse/issues/96925). [#98755](https://github.com/ClickHouse/ClickHouse/pull/98755) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#100488](https://github.com/ClickHouse/ClickHouse/issues/100488): Учетные данные в строках подключения JDBC, ODBC и NATS теперь маскируются в журнале запросов и в выводе `SHOW CREATE`, что предотвращает случайное раскрытие конфиденциальной информации. В строках подключения в формате URI (например, {scheme}://{user}:{password}@{host}) маскируется только часть с паролем, а остальное остается видимым для упрощения отладки. Настройка `nats_token` теперь тоже маскируется. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Бэкпортировано в [#100592](https://github.com/ClickHouse/ClickHouse/issues/100592): Исправлено исключение LOGICAL&#95;ERROR &quot;Stream ... not found&quot;, возникавшее при вставке в таблицу с вложенными столбцами `Array(JSON)` в частях Wide при `optimize_on_insert=0`. [#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
* Бэкпортировано в [#100722](https://github.com/ClickHouse/ClickHouse/issues/100722): Исправлены случаи NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK, когда часть SELECT в проекции содержит столбцы, которых нет в исходной части SELECT запроса. Закрывает [#100194](https://github.com/ClickHouse/ClickHouse/issues/100194). [#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
