<div id="description">
  ## Описание
</div>

Содержит сведения о количестве событий, произошедших в системе. Например, в таблице можно посмотреть, сколько запросов `SELECT` было обработано с момента запуска сервера ClickHouse.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/ru/sql-reference/data-types/string)) — Имя события.
* `value` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество произошедших событий.
* `description` ([String](/ru/sql-reference/data-types/string)) — Описание события.

**Псевдонимы:**

* `name` — Псевдоним `event`.

{/*AUTOGENERATED_END*/ }

```sql
SELECT * FROM system.events LIMIT 5
```
