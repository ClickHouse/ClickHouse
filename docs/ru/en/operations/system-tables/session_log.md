<div id="description">
  ## Описание
</div>

Содержит сведения обо всех успешных и неудачных событиях входа в систему и выхода из неё.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя хоста сервера, выполняющего запрос.
* `type` ([Enum8(&#39;LoginFailure&#39; = 0, &#39;LoginSuccess&#39; = 1, &#39;Logout&#39; = 2)](/ru/sql-reference/data-types/enum)) — Результат входа/выхода. Возможные значения: LoginFailure — ошибка входа. LoginSuccess — успешный вход. Logout — выход из системы.
* `auth_id` ([UUID](/ru/sql-reference/data-types/uuid)) — ID аутентификации, то есть UUID, который автоматически генерируется при каждом входе пользователя.
* `session_id` ([String](/ru/sql-reference/data-types/string)) — ID сеанса, который клиент передает через HTTP-интерфейс.
* `event_date` ([Date](/ru/sql-reference/data-types/date)) — Дата входа/выхода.
* `event_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время входа/выхода.
* `event_time_microseconds` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Время начала входа/выхода с точностью до микросекунд.
* `user` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Имя пользователя.
* `auth_type` ([Nullable(Enum8(&#39;NO&#95;PASSWORD&#39; = 0, &#39;PLAINTEXT&#95;PASSWORD&#39; = 1, &#39;SHA256&#95;PASSWORD&#39; = 2, &#39;DOUBLE&#95;SHA1&#95;PASSWORD&#39; = 3, &#39;LDAP&#39; = 4, &#39;KERBEROS&#39; = 5, &#39;SSL&#95;CERTIFICATE&#39; = 6, &#39;BCRYPT&#95;PASSWORD&#39; = 7, &#39;SSH&#95;KEY&#39; = 8, &#39;HTTP&#39; = 9, &#39;JWT&#39; = 10, &#39;SCRAM&#95;SHA256&#95;PASSWORD&#39; = 11, &#39;NO&#95;AUTHENTICATION&#39; = 12))](/ru/sql-reference/data-types/nullable)) — Тип аутентификации.
* `profiles` ([Array(LowCardinality(String))](/ru/sql-reference/data-types/array)) — Список профилей, заданных для всех ролей и/или пользователей.
* `roles` ([Array(LowCardinality(String))](/ru/sql-reference/data-types/array)) — Список ролей, к которым применяется профиль.
* `settings` ([Array(Tuple(LowCardinality(String), String))](/ru/sql-reference/data-types/array)) — Настройки, которые были изменены при входе/выходе клиента.
* `client_address` ([IPv6](/ru/sql-reference/data-types/ipv6)) — IP-адрес, который использовался для входа/выхода.
* `client_port` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Порт клиента, который использовался для входа/выхода.
* `interface` ([Enum8(&#39;TCP&#39; = 1, &#39;HTTP&#39; = 2, &#39;gRPC&#39; = 3, &#39;MySQL&#39; = 4, &#39;PostgreSQL&#39; = 5, &#39;Local&#39; = 6, &#39;TCP&#95;Interserver&#39; = 7, &#39;Prometheus&#39; = 8, &#39;Background&#39; = 9)](/ru/sql-reference/data-types/enum)) — Интерфейс, через который был выполнен вход.
* `client_hostname` ([String](/ru/sql-reference/data-types/string)) — Имя хоста клиентской машины, на которой запущен клиент ClickHouse или другой TCP-клиент.
* `client_name` ([String](/ru/sql-reference/data-types/string)) — Имя клиента ClickHouse или другого TCP-клиента.
* `client_revision` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Ревизия клиента ClickHouse или другого TCP-клиента.
* `client_version_major` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Мажорная версия клиента ClickHouse или другого TCP-клиента.
* `client_version_minor` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Минорная версия клиента ClickHouse или другого TCP-клиента.
* `client_version_patch` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Патч-версия клиента ClickHouse или другого TCP-клиента.
* `failure_reason` ([String](/ru/sql-reference/data-types/string)) — Сообщение исключения, содержащее причину ошибки входа/выхода.
* `certificate_subjects` ([Array(LowCardinality(String))](/ru/sql-reference/data-types/array)) — Список субъектов (Common Name и Subject Alternative Names) TLS-сертификата клиента, предъявленного в соединении, в формате &#39;CN:...&#39; / &#39;SAN:...&#39;. Пусто, если сертификат не был предъявлен.
* `certificate_serial` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Серийный номер TLS-сертификата клиента. Пусто, если сертификат не был предъявлен.
* `certificate_issuer` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Издатель TLS-сертификата клиента. Пусто, если сертификат не был предъявлен.
* `certificate_not_before` ([Nullable(DateTime64)](/ru/sql-reference/data-types/nullable)) — Время, начиная с которого TLS-сертификат клиента действителен. NULL, если сертификат не был предъявлен.
* `certificate_not_after` ([Nullable(DateTime64)](/ru/sql-reference/data-types/nullable)) — Время, после которого TLS-сертификат клиента становится недействительным. NULL, если сертификат не был предъявлен.

{/*AUTOGENERATED_END*/ }
