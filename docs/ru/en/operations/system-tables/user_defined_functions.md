<div id="description">
  ## Описание
</div>

Содержит статус загрузки, сведения об ошибках и метаданные конфигурации для [пользовательских функций (UDF)](/ru/sql-reference/functions/udf.md).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя UDF.
* `load_status` ([Enum8(&#39;Success&#39; = 0, &#39;Failed&#39; = 1)](/ru/sql-reference/data-types/enum)) — Статус загрузки. Возможные значения: Success — UDF загружена и готова к использованию, Failed — UDF не удалось загрузить (подробности см. в поле &#39;loading&#95;error&#95;message&#39;).
* `loading_error_message` ([String](/ru/sql-reference/data-types/string)) — Подробное сообщение об ошибке, если загрузка завершилась неудачно. Пусто, если загрузка выполнена успешно.
* `last_successful_update_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Временная метка последнего успешного обновления. NULL, если успешных обновлений ещё не было.
* `loading_duration_ms` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Время загрузки UDF в миллисекундах.
* `type` ([Enum8(&#39;executable&#39; = 0, &#39;executable&#95;pool&#39; = 1)](/ru/sql-reference/data-types/enum)) — Тип UDF: &#39;executable&#39; (один процесс) или &#39;executable&#95;pool&#39; (пул процессов).
* `command` ([String](/ru/sql-reference/data-types/string)) — Скрипт или команда, выполняемые для этой UDF.
* `format` ([String](/ru/sql-reference/data-types/string)) — Формат данных для ввода-вывода (например, &#39;TabSeparated&#39;, &#39;JSONEachRow&#39;).
* `return_type` ([String](/ru/sql-reference/data-types/string)) — Возвращаемый тип функции (например, &#39;String&#39;, &#39;UInt64&#39;).
* `return_name` ([String](/ru/sql-reference/data-types/string)) — Необязательный идентификатор возвращаемого значения. Пусто, если не настроен.
* `argument_types` ([Array(String)](/ru/sql-reference/data-types/array)) — Массив типов аргументов (например, [&#39;String&#39;, &#39;UInt64&#39;]).
* `argument_names` ([Array(String)](/ru/sql-reference/data-types/array)) — Массив имён аргументов. Для аргументов без имени используются пустые строки.
* `max_command_execution_time` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Максимальное время обработки блока данных в секундах. Только для типа &#39;executable&#95;pool&#39;.
* `command_termination_timeout` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Время в секундах до отправки SIGTERM процессу команды.
* `command_read_timeout` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Время чтения из stdout команды в миллисекундах.
* `command_write_timeout` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Время записи в stdin команды в миллисекундах.
* `pool_size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество экземпляров процесса команды. Только для типа &#39;executable&#95;pool&#39;.
* `send_chunk_header` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Нужно ли отправлять количество строк перед каждым фрагментом данных (булево значение).
* `execute_direct` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Выполнять ли команду напрямую (1) или через /bin/bash (0).
* `lifetime` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Интервал перезагрузки в секундах. 0 означает, что перезагрузка отключена.
* `deterministic` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Возвращает ли функция один и тот же результат для одних и тех же аргументов (булево значение).

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

Просмотрите все пользовательские функции (UDF) и статус их загрузки:

```sql
SELECT
    name,
    load_status,
    type,
    command,
    return_type,
    argument_types
FROM system.user_defined_functions
FORMAT Vertical;
```

```response
Row 1:
──────
name:           my_sum_udf
load_status:    Success
type:           executable
command:        /var/lib/clickhouse/user_scripts/sum.py
return_type:    UInt64
argument_types: ['UInt64','UInt64']
```

Найдите пользовательские функции (UDF), завершившиеся с ошибкой:

```sql
SELECT
    name,
    loading_error_message
FROM system.user_defined_functions
WHERE load_status = 'Failed';
```
