<div id="description">
  ## Описание
</div>

Содержит сведения о задачах из очередей репликации, хранящихся в ClickHouse Keeper или ZooKeeper, для таблиц семейства `ReplicatedMergeTree`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `replica_name` ([String](/ru/sql-reference/data-types/string)) — Имя реплики в ClickHouse Keeper. У разных реплик одной и той же таблицы разные имена.
* `position` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Позиция задачи в очереди.
* `node_name` ([String](/ru/sql-reference/data-types/string)) — Имя узла в ClickHouse Keeper.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип задачи в очереди, один из следующих: • GET&#95;PART — Получить часть с другой реплики, • ATTACH&#95;PART — Присоединить часть, возможно, из собственной реплики (если она найдена в папке detached). Это можно рассматривать как GET&#95;PART с некоторыми оптимизациями, поскольку они почти идентичны. • MERGE&#95;PARTS — Слить части. • DROP&#95;RANGE — Удалить части в указанной партиции в заданном числовом диапазоне. • CLEAR&#95;COLUMN — NOTE: Устарело. Удалить указанный столбец из указанной партиции. • CLEAR&#95;INDEX — NOTE: Устарело. Удалить указанный индекс из указанной партиции. • REPLACE&#95;RANGE — Удалить определённый диапазон частей и заменить его новыми. • MUTATE&#95;PART — Применить к части одну или несколько мутаций. • ALTER&#95;METADATA — Применить изменение ALTER в соответствии с глобальными путями /metadata и /columns.
* `create_time` ([дата и время](/ru/sql-reference/data-types/datetime)) — Дата и время, когда задача была отправлена на выполнение.
* `required_quorum` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Количество реплик, ожидающих подтверждённого завершения задачи. Этот столбец актуален только для задачи GET&#95;PARTS.
* `source_replica` ([String](/ru/sql-reference/data-types/string)) — Имя исходной реплики.
* `new_part_name` ([String](/ru/sql-reference/data-types/string)) — Имя новой части.
* `parts_to_merge` ([Array(String)](/ru/sql-reference/data-types/array)) — Имена частей для слияния или обновления.
* `is_detach` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, находится ли задача DETACH&#95;PARTS в очереди.
* `is_currently_executing` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, выполняется ли данная задача в настоящий момент.
* `num_tries` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Количество неудачных попыток выполнить задачу.
* `last_exception` ([String](/ru/sql-reference/data-types/string)) — Текст сообщения о последней возникшей ошибке (если она была).
* `last_exception_time` ([дата и время](/ru/sql-reference/data-types/datetime)) — Дата и время возникновения последней ошибки.
* `last_attempt_time` ([дата и время](/ru/sql-reference/data-types/datetime)) — Дата и время последней попытки выполнения задачи.
* `num_postponed` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Количество переносов задачи.
* `postpone_reason` ([String](/ru/sql-reference/data-types/string)) — Причина, по которой выполнение задачи было отложено.
* `last_postpone_time` ([дата и время](/ru/sql-reference/data-types/datetime)) — Дата и время, когда выполнение задачи было отложено в последний раз.
* `merge_type` ([String](/ru/sql-reference/data-types/string)) — Тип текущего слияния. Пусто, если это мутация.

{/*AUTOGENERATED_END*/ }
