<div id="description">
  ## Описание
</div>

Собирает встроенную документацию по унифицированным компонентам системы в одну таблицу. Каждая строка соответствует одной сущности (функции, движку таблицы, типу данных и т. д.) и содержит справочную документацию по этой сущности, отрендеренную в Markdown, — то же содержимое, которое публикуется на сайте и доступно через таблицы `system.*` для соответствующих видов сущностей.

`description` формируется из структурированных частей встроенной документации (`description`, `syntax`, аргументов, примеров и т. д.), поэтому в одном столбце содержится полная документация сущности. Псевдонимы отображаются как краткая ссылка на каноническую сущность, например ``Псевдоним `trunc`.``

Эта таблица в некотором смысле объединяет информацию, доступную в таблицах документации по отдельным видам сущностей ([`system.functions`](/ru/operations/system-tables/functions), [`system.table_engines`](/ru/operations/system-tables/table_engines), [`system.data_type_families`](/ru/operations/system-tables/data_type_families) и других). В частности, она предназначена для реализации интерактивной команды `help` в клиенте, но полезна и сама по себе.

Собираются следующие виды сущностей (в скобках показано значение столбца `type`):

* Функции (`Function`)
* Агрегатные функции (`Aggregate Function`)
* Табличные функции (`Table Function`)
* Движки таблиц (`Table Engine`)
* Движки баз данных (`Database Engine`)
* Типы данных (`Data Type`)
* Структуры словарей (`Dictionary Layout`)
* Источники словарей (`Dictionary Source`)
* Комбинаторы агрегатных функций (`Aggregate Function Combinator`)
* Типы индексов пропуска данных (`Data Skipping Index`)
* Типы дисков (`Disk Type`)
* Настройки (`Setting`)
* Настройки MergeTree (`MergeTree Setting`)
* Настройки сервера (`Server Setting`)
* Форматы (`Format`)
* Кодеки сжатия (`Compression Codec`)
* События профилирования (`Profile Event`)
* Текущие метрики (`Current Metric`)
* Асинхронные метрики (`Asynchronous Metric`)
* Системные таблицы (`System Table`)

Для настроек (любого вида) документация состоит из описания настройки, а также её типа и значения по умолчанию; устаревшие настройки не включаются. Для системных таблиц документация состоит из комментария к таблице и списка её столбцов (имени, типа и описания каждого).

Столбец `source` содержит путь к исходному файлу, в котором определена документация сущности, относительно корня репозитория. Для большинства сущностей он определяется автоматически в том месте, где создаётся объект документации (в месте регистрации компонента); для видов сущностей, документация которых целиком находится в одном исходном файле (например, настройки, события профилирования и текущие метрики), указывается этот файл.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя сущности, например `domainWithoutWWW` или `MergeTree`.
* `type` ([Enum8](/ru/sql-reference/data-types/enum)) — Тип сущности, например `Function` или `Table Engine`.
* `description` ([String](/ru/sql-reference/data-types/string)) — Справочная документация по сущности в формате Markdown, собранная из встроенной документации (то же содержимое, что публикуется на сайте), включая синтаксис, примеры и другие структурированные разделы, если они есть.
* `source` ([String](/ru/sql-reference/data-types/string)) — Путь к исходному файлу, в котором определена документация сущности, относительно корня репозитория. Пусто, если расположение исходного файла неизвестно.

<div id="example">
  ## Пример
</div>

Ознакомьтесь с документацией по конкретной сущности:

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

Одно и то же имя может относиться к нескольким типам сущностей (например, есть и табличная функция `file`, и источник словаря `file`), поэтому удобно искать такое имя сразу среди всех типов:

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

Подсчитайте количество описанных сущностей каждого типа:

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
