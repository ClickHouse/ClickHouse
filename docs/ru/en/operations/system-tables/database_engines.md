<div id="description">
  ## Описание
</div>

Содержит перечень движков баз данных, поддерживаемых сервером.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Название движка базы данных.
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание назначения движка базы данных.
* `syntax` ([String](/ru/sql-reference/data-types/string)) — Как движок базы данных задаётся в предложении ENGINE запроса CREATE DATABASE.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой движок базы данных был впервые представлен, в формате major.minor.
* `related` ([Array](/ru/sql-reference/data-types/array)([String](/ru/sql-reference/data-types/string))) — Названия связанных движков баз данных.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

```text title="Response"
┌─name─────┐
│ Atomic   │
│ Ordinary │
└──────────┘
```
