<div id="description">
  ## Описание
</div>

Эта таблица отсутствует, если данный узел не настроен на запуск in-process ClickHouse Keeper. Она содержит по одной строке для каждого участника кластера Raft, объединяя статическую топологию кластера (из конфигурации Raft) с позицией локального журнала самого узла.

Каждый узел заполняет ровно одно значение `last_log_index` — в строке, соответствующей его собственному `server_id`. Позиции журналов других узлов здесь не отображаются, поскольку они отслеживаются только на лидере, и это представление не является симметричным для всего кластера.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — идентификатор сервера Raft для этого участника кластера.
* `host` ([String](../../sql-reference/data-types/string.md)) — хост, разобранный из конечной точки (префикс перед последним двоеточием).
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — исходная конечная точка Raft в настроенном виде (`host:port`).
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — `true`, если этот участник является наблюдателем без права голоса, настроенным через `<can_become_leader>false</can_become_leader>`.
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — приоритет Raft для этого участника; при выборе лидера предпочтение отдается более высоким значениям.
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — `true`, если этот участник является текущим лидером Raft.
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — `true`, если эта строка описывает локальный узел Keeper.
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — наибольший индекс в локальном журнале Raft на этом узле. Заполняется только в строке, соответствующей текущему узлу (`is_self = true`); `NULL` для остальных строк.

{/*AUTOGENERATED_END*/ }
