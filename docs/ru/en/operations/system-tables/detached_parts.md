<div id="purpose">
  ## Описание
</div>

Содержит информацию об отсоединённых частях таблиц [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md). Столбец `reason` указывает, почему часть была отсоединена.

Для частей, отсоединённых пользователем, причина не указывается. Такие части можно присоединить командой [ALTER TABLE ATTACH PARTITION|PART](/ru/sql-reference/statements/alter/partition#attach-partitionpart).

Описание остальных столбцов см. в [system.parts](../../operations/system-tables/parts.md).

Если имя части некорректно, значения некоторых столбцов могут быть `NULL`. Такие части можно удалить командой [ALTER TABLE DROP DETACHED PART](/ru/sql-reference/statements/alter/partition#drop-detached-partitionpart).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных, к которой относится эта часть.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы, к которой относится эта часть.
* `partition_id` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Идентификатор партиции, к которой относится эта часть.
* `name` ([String](/ru/sql-reference/data-types/string)) — Имя части.
* `bytes_on_disk` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `modification_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно соответствует моменту, когда произошло отсоединение.
* `disk` ([String](/ru/sql-reference/data-types/string)) — Имя диска, на котором хранится эта часть данных.
* `path` ([String](/ru/sql-reference/data-types/string)) — Путь на диске к файлу этой части данных.
* `reason` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Причина, по которой эта часть была отсоединена.
* `min_block_number` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Минимальный номер частей данных, из которых после слияния состоит текущая часть.
* `max_block_number` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Максимальный номер частей данных, из которых после слияния состоит текущая часть.
* `level` ([Nullable(UInt32)](/ru/sql-reference/data-types/nullable)) — Глубина дерева слияния. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
