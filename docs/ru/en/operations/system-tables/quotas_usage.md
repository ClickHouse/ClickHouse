<div id="description">
  ## Описание
</div>

Использование квоты всеми пользователями.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/ru/sql-reference/data-types/string)) — Имя квоты.
* `quota_key` ([String](/ru/sql-reference/data-types/string)) — Значение ключа.
* `is_current` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Использование квоты для текущего пользователя.
* `start_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время начала расчета потребления ресурсов.
* `end_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время окончания расчета потребления ресурсов.
* `duration` ([Nullable(UInt32)](/ru/sql-reference/data-types/nullable)) — Длительность временного интервала для расчета потребления ресурсов в секундах.
* `queries` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее количество выполненных запросов.
* `max_queries` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов всех типов.
* `query_selects` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее количество выполненных запросов SELECT.
* `max_query_selects` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов SELECT.
* `query_inserts` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее количество выполненных запросов INSERT.
* `max_query_inserts` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов INSERT.
* `errors` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее количество запросов, завершившихся ошибкой.
* `max_errors` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов, завершившихся ошибкой, в течение указанного периода времени.
* `result_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее общее количество строк в результирующем наборе всех запросов за текущий период времени.
* `max_result_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое общее количество строк в результирующем наборе всех запросов в течение указанного периода времени.
* `result_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее общее количество байт в результирующем наборе всех запросов за текущий период времени.
* `max_result_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое общее количество байт в результирующем наборе всех запросов в течение указанного периода времени.
* `read_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее общее количество строк, прочитанных при выполнении всех запросов за текущий период времени.
* `max_read_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество строк, считываемых при выполнении всех запросов в течение указанного периода времени.
* `read_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее общее количество байт, прочитанных при выполнении всех запросов за текущий период времени.
* `max_read_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество байт, считываемых при выполнении всех запросов в течение указанного периода времени.
* `execution_time` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Текущее суммарное время (в наносекундах), затраченное на выполнение запросов за текущий период времени
* `max_execution_time` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое суммарное время (в наносекундах) на выполнение всех запросов в течение указанного периода времени
* `written_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее общее количество байт, записанных при выполнении всех запросов за текущий период времени.
* `max_written_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимальное количество байтов, которое может быть записано при выполнении всех запросов за указанный период времени.
* `failed_sequential_authentications` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее количество последовательных неудачных попыток аутентификации за текущий период времени.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимальное количество последовательных неудачных попыток аутентификации, допустимое за указанный период времени.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Текущее максимальное количество выполнений любого отдельного нормализованного запроса за текущий период времени.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимальное количество выполнений любого отдельного нормализованного запроса, допустимое за указанный период времени.
