<div id="description">
  ## Описание
</div>

Содержит историю значений памяти и метрик для отдельных запросов из таблицы `system.events`, периодически сбрасываемую на диск.

После запуска запроса данные собираются с периодичностью `query_metric_log_interval` миллисекунд (по умолчанию установлено значение 1000
). Данные также собираются при завершении запроса, если запрос выполняется дольше, чем `query_metric_log_interval`.
