<div id="description">
  ## Описание
</div>

Содержит список [учётных записей пользователей](../../guides/sre/user-management/index.md#user-account-management), заданных на сервере.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя пользователя.
* `id` ([UUID](/ru/sql-reference/data-types/uuid)) — Идентификатор пользователя.
* `storage` ([String](/ru/sql-reference/data-types/string)) — Путь к хранилищу пользователей. Настраивается параметром access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/ru/sql-reference/data-types/array)) — Показывает типы аутентификации. Существует несколько способов идентификации пользователя: без пароля, с паролем в открытом виде, с паролем, закодированным с помощью SHA256, с паролем, закодированным двойным SHA-1, или с паролем, закодированным с помощью bcrypt.
* `auth_params` ([Array(String)](/ru/sql-reference/data-types/array)) — Параметры аутентификации в формате JSON в зависимости от auth&#95;type.
* `valid_until` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Дата и время истечения срока действия учетных данных пользователя.
* `host_ip` ([Array(String)](/ru/sql-reference/data-types/array)) — IP-адреса хостов, которым разрешено подключаться к серверу ClickHouse.
* `host_names` ([Array(String)](/ru/sql-reference/data-types/array)) — Имена хостов, которым разрешено подключаться к серверу ClickHouse.
* `host_names_regexp` ([Array(String)](/ru/sql-reference/data-types/array)) — Регулярное выражение для имён хостов, которым разрешено подключаться к серверу ClickHouse.
* `host_names_like` ([Array(String)](/ru/sql-reference/data-types/array)) — Имена хостов, которым разрешено подключаться к серверу ClickHouse, заданные с помощью предиката LIKE.
* `default_roles_all` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, что для пользователя по умолчанию установлены все предоставленные роли.
* `default_roles_list` ([Array(String)](/ru/sql-reference/data-types/array)) — Список предоставленных ролей, назначаемых по умолчанию.
* `default_roles_except` ([Array(String)](/ru/sql-reference/data-types/array)) — Все предоставленные роли установлены по умолчанию, кроме перечисленных.
* `grantees_any` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, может ли пользователь с любой grant option выдать её кому угодно.
* `grantees_list` ([Array(String)](/ru/sql-reference/data-types/array)) — Список пользователей или ролей, которым этот пользователь может выдавать grant options.
* `grantees_except` ([Array(String)](/ru/sql-reference/data-types/array)) — Список пользователей или ролей, которым этому пользователю запрещено выдавать grant options.
* `default_database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных по умолчанию для этого пользователя.
