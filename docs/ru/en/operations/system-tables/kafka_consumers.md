<div id="description">
  ## Описание
</div>

Содержит информацию о потребителях Kafka.
Относится к [движку таблицы Kafka](../../engines/table-engines/integrations/kafka) (нативная интеграция ClickHouse)

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — База данных таблицы с движком Kafka.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы с движком Kafka.
* `consumer_id` ([String](/ru/sql-reference/data-types/string)) — Идентификатор консьюмера Kafka. Обратите внимание: у таблицы может быть несколько консьюмеров. Задаётся параметром `kafka_num_consumers`.
* `assignments.topic` ([Array(String)](/ru/sql-reference/data-types/array)) — Топик Kafka.
* `assignments.partition_id` ([Array(Int32)](/ru/sql-reference/data-types/array)) — Идентификатор партиции Kafka. Обратите внимание: партиция может быть назначена только одному консьюмеру.
* `assignments.current_offset` ([Array(Int64)](/ru/sql-reference/data-types/array)) — Текущее смещение.
* `assignments.intent_size` ([Array(Nullable(Int64))](/ru/sql-reference/data-types/array)) — Количество отправленных, но ещё не закоммиченных сообщений в новом StorageKafka.
* `exceptions.time` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Временные метки, когда были сгенерированы 10 последних исключений.
* `exceptions.text` ([Array(String)](/ru/sql-reference/data-types/array)) — Текст 10 последних исключений.
* `last_poll_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Временная метка последнего опроса.
* `num_messages_read` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество сообщений, прочитанных консьюмером.
* `last_commit_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Временная метка последнего опроса.
* `num_commits` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество коммитов консьюмера.
* `last_rebalance_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Временная метка последней перебалансировки Kafka.
* `num_rebalance_revocations` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество случаев, когда у консьюмера отзывались его партиции.
* `num_rebalance_assignments` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество случаев, когда консьюмеру назначались партиции в кластере Kafka.
* `is_currently_used` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, показывающий, используется ли консьюмер в данный момент.
* `last_used` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Время последнего использования этого консьюмера.
* `rdkafka_stat` ([String](/ru/sql-reference/data-types/string)) — Внутренняя статистика библиотеки. Установите `statistics_interval_ms` в 0, чтобы отключить; значение по умолчанию — 3000 (раз в три секунды).
* `dependencies` ([Array(Array(String))](/ru/sql-reference/data-types/array)) — Транзитивные зависимости базы данных.
* `missing_dependencies` ([Array(Array(String))](/ru/sql-reference/data-types/array)) — Отсутствующие транзитивные зависимости базы данных.

{/*AUTOGENERATED_END*/ }
