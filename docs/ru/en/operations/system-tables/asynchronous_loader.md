<div id="description">
  ## Описание
</div>

Содержит информацию и status о недавних асинхронных задачах (например, о загрузке таблиц). Таблица содержит одну строку для каждой задачи. Для визуализации информации из этой таблицы предусмотрен инструмент `utils/async_loader_graph`.

  ## Столбцы

* `job` ([String](/ru/sql-reference/data-types/string)) — Имя задачи (может быть неуникальным).
* `job_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Уникальный ID задачи.
* `dependencies` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Список ID задач, которые должны быть выполнены до этой задачи.

* `is_blocked` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Задача ожидает выполнения своих зависимостей.
* `is_ready` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Задача готова к выполнению и ожидает воркера.
* `elapsed` ([Float64](/ru/sql-reference/data-types/float)) — Секунды, прошедшие с начала выполнения. Ноль, если задача ещё не запущена. Общее время выполнения, если задача завершена.

* `pool` ([String](/ru/sql-reference/data-types/string)) — Имя пула `pool_id`.
* `priority` ([Int64](/ru/sql-reference/data-types/int-uint)) — Приоритет пула `pool_id`.
* `execution_pool_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — ID пула, в котором выполняется задача. До начала выполнения совпадает с изначально назначенным пулом.
* `execution_pool` ([String](/ru/sql-reference/data-types/string)) — Имя пула `execution_pool_id`.
* `execution_priority` ([Int64](/ru/sql-reference/data-types/int-uint)) — Приоритет пула `execution_pool_id`.

* `schedule_time` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Время, когда задача была создана и запланирована к выполнению (обычно вместе со всеми её зависимостями).
* `enqueue_time` ([Nullable(DateTime64(6))](/ru/sql-reference/data-types/nullable)) — Время, когда задача стала готовой и была помещена в очередь готовых задач своего пула. NULL, если задача ещё не готова.
* `start_time` ([Nullable(DateTime64(6))](/ru/sql-reference/data-types/nullable)) — Время, когда воркер извлекает задачу из очереди готовых задач и начинает её выполнение. NULL, если задача ещё не запущена.
* `finish_time` ([Nullable(DateTime64(6))](/ru/sql-reference/data-types/nullable)) — Время завершения выполнения задачи. NULL, если задача ещё не завершена.

Задача в ожидании может находиться в одном из следующих состояний:

* `is_executing` (`UInt8`) - Задача в данный момент выполняется воркером.
* `is_blocked` (`UInt8`) - Задача ожидает завершения зависимостей.
* `is_ready` (`UInt8`) - Задача готова к выполнению и ожидает воркера.
* `elapsed` (`Float64`) - Количество секунд, прошедших с начала выполнения. Ноль, если задача не запущена. Общее время выполнения, если задача завершена.

Каждая задача связана с определённым пулом и запускается в нём. У каждого пула есть постоянный приоритет и изменяемое максимальное число воркеров. Сначала выполняются задачи с более высоким приоритетом (то есть с меньшим значением `priority`). Ни одна задача с более низким приоритетом не запускается, пока есть хотя бы одна готовая к запуску или уже выполняющаяся задача с более высоким приоритетом. Приоритет задачи можно повысить (но нельзя понизить), явно повысив её приоритет. Например, задачи загрузки таблицы и запуска будут получать повышенный приоритет, если эта таблица требуется входящему запросу. Повысить приоритет задачи можно и во время её выполнения, но при этом задача не переносится из своего `execution_pool` в заново назначенный `pool`. Для создания новых задач задача использует `pool`, чтобы избежать инверсии приоритетов. Уже запущенные задачи не вытесняются задачами с более высоким приоритетом и после запуска всегда выполняются до конца.

* `pool_id` (`UInt64`) - ID пула, который в данный момент назначен задаче.

* `pool` (`String`) - Имя пула `pool_id`.

* `priority` (`Int64`) - Приоритет пула `pool_id`.

* `execution_pool_id` (`UInt64`) - ID пула, в котором выполняется задача. До начала выполнения совпадает с изначально назначенным пулом.

* `execution_pool` (`String`) - Имя пула `execution_pool_id`.

* `execution_priority` (`Int64`) - Приоритет пула `execution_pool_id`.

* `ready_seqno` (`Nullable(UInt64)`) - Не `NULL` для готовых задач. Воркер берёт следующую задачу для выполнения из очереди готовых задач своего пула. Если готовых задач несколько, выбирается задача с наименьшим значением `ready_seqno`.

* `waiters` (`UInt64`) - Число потоков, ожидающих эту задачу.

* `exception` (`Nullable(String)`) - Не `NULL` для задач, завершившихся с ошибкой или отменённых. Содержит сообщение об ошибке, возникшей при выполнении запроса, или ошибку, приведшую к отмене этой задачи, вместе с цепочкой отказов зависимостей с именами задач.

Моменты времени в течение жизненного цикла задачи:

* `schedule_time` (`DateTime64`) - Время, когда задача была создана и запланирована к выполнению (обычно вместе со всеми своими зависимостями).
* `enqueue_time` (`Nullable(DateTime64)`) - Время, когда задача стала готовой и была помещена в очередь готовых задач своего пула. `NULL`, если задача ещё не готова.
* `start_time` (`Nullable(DateTime64)`) - Время, когда воркер извлекает задачу из очереди готовых задач и начинает её выполнение. `NULL`, если задача ещё не запущена.
* `finish_time` (`Nullable(DateTime64)`) - Время завершения выполнения задачи. `NULL`, если задача ещё не завершена.
