<div id="description">
  ## Описание
</div>

Содержит сведения о максимальных значениях для всех интервалов всех квот. Одной квоте может соответствовать любое число строк или ни одной.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/ru/sql-reference/data-types/string)) — Имя квоты.
* `duration` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Длительность временного интервала для расчета потребления ресурсов, в секундах.
* `is_randomized_interval` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Булево значение. Показывает, является ли интервал случайным. Если интервал не является случайным, он всегда начинается в одно и то же время. Например, интервал в 1 минуту всегда начинается на целой минуте (то есть может начаться в 11:20:00, но никогда не начинается в 11:20:01), а интервал в 1 день всегда начинается в полночь по UTC. Если интервал является случайным, самый первый интервал начинается в случайный момент времени, а последующие интервалы идут один за другим. Значения: 0 — интервал не является случайным, 1 — интервал является случайным.
* `max_queries` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов всех типов, разрешенных к выполнению.
* `max_query_selects` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов SELECT, разрешенных к выполнению.
* `max_query_inserts` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов INSERT, разрешенных к выполнению.
* `max_errors` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество запросов, завершившихся ошибкой, в пределах указанного периода времени.
* `max_result_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое общее количество строк в результирующем наборе всех запросов в пределах указанного периода времени.
* `max_result_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое общее количество байтов в результирующем наборе всех запросов в пределах указанного периода времени.
* `max_read_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество строк, считываемых при выполнении всех запросов в пределах указанного периода времени.
* `max_read_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество байтов, считываемых при выполнении всех запросов в пределах указанного периода времени.
* `max_execution_time` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое время выполнения всех запросов (в наносекундах) в пределах указанного периода времени
* `max_written_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество байтов, записываемых при выполнении всех запросов в пределах указанного периода времени.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество последовательных неудачных попыток аутентификации в пределах указанного периода времени.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимально допустимое количество выполнений любого отдельного нормализованного запроса в пределах указанного периода времени.
