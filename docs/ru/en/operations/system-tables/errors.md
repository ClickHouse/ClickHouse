<div id="description">
  ## Описание
</div>

Содержит коды ошибок и количество случаев, когда они возникали.

Чтобы показать все возможные коды ошибок, включая те, которые не возникали, установите настройку [system&#95;events&#95;show&#95;zero&#95;values](../settings/settings.md#system_events_show_zero_values) в 1.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Название ошибки (errorCodeToName).
* `code` ([Int32](/ru/sql-reference/data-types/int-uint)) — Номер кода ошибки.
* `value` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество случаев возникновения этой ошибки.
* `last_error_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время возникновения последней ошибки.
* `last_error_message` ([String](/ru/sql-reference/data-types/string)) — Сообщение последней ошибки.
* `last_error_format_string` ([String](/ru/sql-reference/data-types/string)) — Строка формата последней ошибки.
* `last_error_trace` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Трассировка стека, представляющая собой список физических адресов, по которым расположены вызванные методы.
* `remote` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Удалённое исключение (то есть полученное в ходе одного из распределённых запросов).
* `query_id` ([String](/ru/sql-reference/data-types/string)) — Идентификатор запроса, вызвавшего ошибку (если доступен).

{/*AUTOGENERATED_END*/ }

:::note
Счётчики некоторых ошибок могут увеличиваться даже при успешном выполнении запроса. Не рекомендуется использовать эту таблицу для мониторинга сервера, если вы не уверены, что соответствующая ошибка не может оказаться ложноположительной.
:::

<div id="example">
  ## Пример
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
