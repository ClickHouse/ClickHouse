<div id="description">
  ## Описание
</div>

Эта таблица отсутствует, если данный узел не настроен на запуск внутрипроцессного ClickHouse Keeper. Она содержит по одной строке для каждого файла снимка Raft, отслеживаемого машиной состояний in-process Keeper, включая снимки, которые в данный момент принимаются от лидера.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `last_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Последний индекс лога, входящий в снимок.
* `path` ([String](../../sql-reference/data-types/string.md)) — Путь к файлу снимка на диске.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Имя диска, на котором хранится снимок.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Размер файла снимка на диске в байтах.
* `last_modified_at` ([дата и время](../../sql-reference/data-types/datetime.md)) — Время последнего изменения файла снимка.
* `is_received` ([Bool](../../sql-reference/data-types/boolean.md)) — `true`, если снимок в данный момент получается от лидера. Для таких строк значения `size_bytes` и `last_modified_at` отражают состояние частично записанного на текущий момент файла и могут быть занижены.
* `exists_on_disk` ([Bool](../../sql-reference/data-types/boolean.md)) — Указывает, присутствует ли файл снимка на диске в данный момент. Для завершённых снимков (`is_received` = `false`) это всегда `true`, если только файл не был удалён вне системы или не повреждён; для получаемых снимков (`is_received` = `true`) значение может быть `false`, пока не записан ни один байт.

{/*AUTOGENERATED_END*/ }

Пример:

```sql
SELECT * FROM system.keeper_snapshots ORDER BY last_log_index;
```

```text

│           1000 │ snapshot_1000.bin.zstd        │ default   │      32468 │ 2026-05-22 14:00:00 │ false       │ true           │
│           2000 │ snapshot_2000.bin.zstd        │ default   │      48217 │ 2026-05-22 14:15:00 │ false       │ true           │
└────────────────┴───────────────────────────────┴───────────┴────────────┴─────────────────────┴─────────────┴────────────────┘
```
