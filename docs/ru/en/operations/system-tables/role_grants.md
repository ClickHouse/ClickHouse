<div id="description">
  ## Описание
</div>

Содержит назначенные роли, выданные пользователям и ролям. Чтобы добавить записи в эту таблицу, используйте `GRANT role TO user`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `user_name` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Имя пользователя.
* `role_name` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Имя роли.
* `granted_role_name` ([String](/ru/sql-reference/data-types/string)) — Имя роли, выданной роли `role_name`. Чтобы выдать одну роль другой, используйте `GRANT role1 TO role2`.
* `granted_role_id` ([UUID](/ru/sql-reference/data-types/uuid)) — Идентификатор роли.
* `granted_role_is_default` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, показывающий, является ли `granted_role` ролью по умолчанию. Возможные значения: • 1 — `granted_role` является ролью по умолчанию, • 0 — `granted_role` не является ролью по умолчанию.
* `with_admin_option` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, показывающий, имеет ли `granted_role` привилегию `ADMIN OPTION`. Возможные значения: • 1 — Роль имеет привилегию `ADMIN OPTION`, • 0 — Роль не имеет привилегии `ADMIN OPTION`.

{/*AUTOGENERATED_END*/ }
