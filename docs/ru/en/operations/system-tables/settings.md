<div id="description">
  ## Описание
</div>

Содержит сведения о настройках сеанса текущего пользователя.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя настройки.
* `value` ([String](/ru/sql-reference/data-types/string)) — Значение настройки.
* `changed` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, была ли настройка явно задана в конфигурации или явно изменена.
* `description` ([String](/ru/sql-reference/data-types/string)) — Краткое описание настройки.
* `min` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Минимальное значение настройки, если оно задано через ограничения. Если у настройки нет минимального значения, содержит NULL.
* `max` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Максимальное значение настройки, если оно задано через ограничения. Если у настройки нет максимального значения, содержит NULL.
* `disallowed_values` ([Array(String)](/ru/sql-reference/data-types/array)) — Список недопустимых значений
* `readonly` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, может ли текущий пользователь изменить настройку: 0 — текущий пользователь может изменить настройку, 1 — текущий пользователь не может изменить настройку.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип значения, которое можно присвоить этой настройке.
* `default` ([String](/ru/sql-reference/data-types/string)) — Значение настройки по умолчанию.
* `alias_for` ([String](/ru/sql-reference/data-types/string)) — Имя исходной настройки, если эта настройка является псевдонимом другой настройки.
* `is_obsolete` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, является ли настройка устаревшей.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/ru/sql-reference/data-types/enum)) — Уровень поддержки этой возможности. Возможности ClickHouse распределены по уровням, которые различаются в зависимости от текущего состояния их
  разработки и ожиданий, которые можно связывать с их использованием:
  * PRODUCTION: Возможность стабильна, безопасна в использовании и не вызывает проблем при взаимодействии с другими возможностями уровня PRODUCTION.
  * BETA: Возможность стабильна и безопасна. Результат ее использования вместе с другими возможностями неизвестен, и корректность не гарантируется. Приветствуются тестирование и отчеты.
  * EXPERIMENTAL: Возможность находится в разработке. Предназначена только для разработчиков и энтузиастов ClickHouse. Возможность может как работать, так и не работать, и может быть удалена в любой момент.
  * OBSOLETE: Больше не поддерживается. Либо уже удалена, либо будет удалена в будущих выпусках.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

В следующем примере показано, как получить информацию о настройках, в имени которых содержится `min_i`.

```sql
SELECT *
FROM system.settings
WHERE name LIKE '%min_insert_block_size_%'
FORMAT Vertical
```

Использование `WHERE changed` может быть полезно, например, если вы хотите проверить:

* Правильно ли загружены и применяются настройки из файлов конфигурации.
* Какие настройки были изменены в текущем сеансе.

```sql
SELECT * FROM system.settings WHERE changed AND name='load_balancing'
```
