<div id="description">
  ## Описание
</div>

Содержит сведения о частях удалённых таблиц [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) из [system.dropped&#95;tables](./dropped_tables.md)

Схема этой таблицы совпадает со схемой таблицы [system.parts](./parts.md)

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/ru/sql-reference/data-types/string)) — Идентификатор партиции (строковое представление, сформированное на основе выражения ключа партиционирования таблицы).
* `name` ([String](/ru/sql-reference/data-types/string)) — Имя части данных. По структуре имени части можно определить многие характеристики данных, а также шаблоны приёма и слияния. Формат имени части следующий:

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * Определения:
    * `partition_id` - обозначает ключ партиционирования
    * `minimum_block_number` - обозначает минимальный номер блока в части. ClickHouse всегда выполняет слияние последовательных блоков
    * `maximum_block_number` - обозначает максимальный номер блока в части
    * `level` - увеличивается на единицу с каждым дополнительным слиянием части. Уровень 0 означает, что это новая часть, которая ещё не была слита. Важно помнить, что все части в ClickHouse всегда неизменяемы
    * `data_version` - необязательное значение, увеличивается при мутации части (ещё раз: изменённые мутацией данные всегда записываются только в новую часть, поскольку части неизменяемы)
* `uuid` ([UUID](/ru/sql-reference/data-types/uuid)) — UUID части данных.
* `part_type` ([String](/ru/sql-reference/data-types/string)) — Формат хранения части данных. Возможные значения: `Wide` — каждый столбец хранится в отдельном файле, `Compact` — все столбцы хранятся в одном файле. Формат хранения данных задаётся настройками `min_bytes_for_wide_part` и `min_rows_for_wide_part` таблицы семейства MergeTree.
* `active` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, активна ли часть данных. Если часть данных активна, она используется в таблице. В противном случае она будет удалена. Неактивные части данных появляются после операций слияния и мутаций.
* `marks` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество меток. Чтобы получить примерное количество строк в части данных, умножьте число меток на гранулярность индекса (обычно 8192) (эта подсказка не работает для адаптивной гранулярности).
* `rows` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество строк.
* `files` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество файлов в части данных.
* `bytes_on_disk` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер сжатых данных в части данных. Все вспомогательные файлы (например, файлы с метками) не включаются.
* `data_uncompressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер несжатых данных в части данных. Все вспомогательные файлы (например, файлы с метками) не включаются.
* `primary_key_size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объём памяти (в байтах), используемый значениями первичного ключа в файле primary.idx/cidx на диске.
* `marks_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер файла с метками.
* `secondary_indices_compressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер сжатых данных вторичных индексов в части данных. Все вспомогательные файлы (например, файлы с метками) не включаются.
* `secondary_indices_uncompressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер несжатых данных вторичных индексов в части данных. Все вспомогательные файлы (например, файлы с метками) не включаются.
* `secondary_indices_marks_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер файла с метками для вторичных индексов.
* `modification_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно оно соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Количество мест, в которых используется часть данных. Значение больше 2 указывает на то, что часть данных используется в запросах или слияниях.
* `min_date` ([Date](/ru/sql-reference/data-types/date)) — Минимальное значение ключа даты в части данных.
* `max_date` ([Date](/ru/sql-reference/data-types/date)) — Максимальное значение ключа даты в части данных.
* `min_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Минимальное значение ключа даты и времени в части данных.
* `max_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Максимальное значение ключа даты и времени в части данных.
* `partition_id` ([String](/ru/sql-reference/data-types/string)) — ID партиции.
* `min_block_number` ([Int64](/ru/sql-reference/data-types/int-uint)) — Минимальный номер частей данных, образующих текущую часть после слияния.
* `max_block_number` ([Int64](/ru/sql-reference/data-types/int-uint)) — Максимальный номер частей данных, образующих текущую часть после слияния.
* `level` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Глубина дерева слияния. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
* `data_version` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Число, используемое для определения того, какие мутации должны быть применены к части данных (мутации с версией выше, чем data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объем памяти (в байтах), используемый для значений первичного ключа. Будет равен 0, если `primary_key_lazy_load` включен и ключ не загружен.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объем памяти (в байтах), зарезервированный для значений первичного ключа. Будет равен 0, если `primary_key_lazy_load` включен и ключ не загружен.
* `index_granularity_bytes_in_memory` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объем памяти (в байтах), используемый для значений гранулярности индекса (будет равен 0 в случае primary&#95;key&#95;lazy&#95;load=1 и use&#95;primary&#95;key&#95;cache=1).
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объем памяти (в байтах), зарезервированный для значений гранулярности индекса (будет равен 0 в случае primary&#95;key&#95;lazy&#95;load=1 и use&#95;primary&#95;key&#95;cache=1).
* `is_frozen` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий на наличие резервной копии данных партиции. 1 — резервная копия существует. 0 — резервная копия не существует. Подробнее см. FREEZE PARTITION.
* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `engine` ([String](/ru/sql-reference/data-types/string)) — Имя движка таблицы без параметров.
* `disk_name` ([String](/ru/sql-reference/data-types/string)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/sql-reference/data-types/string)) — Абсолютный путь к папке с файлами части данных.
* `hash_of_all_files` ([String](/ru/sql-reference/data-types/string)) — sipHash128 сжатых файлов.
* `hash_of_uncompressed_files` ([String](/ru/sql-reference/data-types/string)) — sipHash128 несжатых файлов (файлов с marks, файлом индекса и т. д.).
* `uncompressed_hash_of_compressed_files` ([String](/ru/sql-reference/data-types/string)) — sipHash128 данных в сжатых файлах, как если бы они были несжатыми.
* `delete_ttl_info_min` ([DateTime](/ru/sql-reference/data-types/datetime)) — Минимальное значение ключа даты и времени для правила TTL DELETE.
* `delete_ttl_info_max` ([DateTime](/ru/sql-reference/data-types/datetime)) — Максимальное значение ключа даты и времени для правила TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/ru/sql-reference/data-types/array)) — Массив выражений. Каждое выражение задает правило TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Массив значений даты и времени. Каждый элемент описывает минимальное значение ключа для правила TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Массив значений даты и времени. Каждый элемент описывает максимальное значение ключа для правила TTL MOVE.
* `default_compression_codec` ([String](/ru/sql-reference/data-types/string)) — Имя кодека, используемого для сжатия этой части данных (если для столбцов не задан явный кодек).
* `recompression_ttl_info.expression` ([Array(String)](/ru/sql-reference/data-types/array)) — TTL-выражение.
* `recompression_ttl_info.min` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в пределах этой части. Используется, чтобы понять, есть ли хотя бы одна строка с истекшим TTL.
* `recompression_ttl_info.max` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в пределах этой части. Используется, чтобы понять, все ли строки имеют истекший TTL.
* `group_by_ttl_info.expression` ([Array(String)](/ru/sql-reference/data-types/array)) — TTL-выражение.
* `group_by_ttl_info.min` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в пределах этой части. Используется, чтобы понять, есть ли хотя бы одна строка с истекшим TTL.
* `group_by_ttl_info.max` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в пределах этой части. Используется, чтобы понять, все ли строки имеют истекший TTL.
* `rows_where_ttl_info.expression` ([Array(String)](/ru/sql-reference/data-types/array)) — TTL-выражение.
* `rows_where_ttl_info.min` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Минимальное значение вычисленного TTL-выражения в пределах этой части. Используется, чтобы понять, есть ли хотя бы одна строка с истекшим TTL.
* `rows_where_ttl_info.max` ([Array(DateTime)](/ru/sql-reference/data-types/array)) — Максимальное значение вычисленного TTL-выражения в пределах этой части. Используется, чтобы понять, все ли строки имеют истекший TTL.
* `projections` ([Array(String)](/ru/sql-reference/data-types/array)) — Список имён проекций, вычисленных для этой части.
* `visible` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, видна ли эта часть для запросов SELECT.
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ru/sql-reference/data-types/tuple)) — ID транзакции, которая создала или пытается создать этот объект.
* `removal_tid_lock` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Хеш `removal_tid`, используемый для блокировки объекта на удаление.
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ru/sql-reference/data-types/tuple)) — ID транзакции, которая удалила или пытается удалить этот объект
* `creation_csn` ([UInt64](/ru/sql-reference/data-types/int-uint)) — CSN транзакции, которая создала этот объект
* `removal_csn` ([UInt64](/ru/sql-reference/data-types/int-uint)) — CSN транзакции, которая удалила этот объект
* `has_lightweight_delete` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, есть ли у части маска легковесного удаления.
* `last_removal_attempt_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Последнее время, когда сервер пытался удалить эту часть.
* `removal_state` ([String](/ru/sql-reference/data-types/string)) — Текущее состояние процесса удаления части.

**Псевдонимы:**

* `bytes` — псевдоним для `bytes_on_disk`.
* `marks_size` — псевдоним для `marks_bytes`.
* `part_name` — псевдоним для `name`.
