<div id="description">
  ## Описание
</div>

Эта системная таблица используется для реализации запроса `SHOW PROCESSLIST`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `is_initial_query` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Указывает, поступил ли этот запрос непосредственно от пользователя или был создан ClickHouse server в рамках выполнения распределённого запроса.
* `user` ([String](/ru/sql-reference/data-types/string)) — Пользователь, выполнивший запрос. Имейте в виду, что при распределённой обработке запросы отправляются на удалённые серверы от имени default user. Это поле содержит имя пользователя для конкретного запроса, а не для запроса, который был инициирован этим запросом.
* `query_id` ([String](/ru/sql-reference/data-types/string)) — Query id, если задан.
* `address` ([IPv6](/ru/sql-reference/data-types/ipv6)) — IP-адрес, с которого был выполнен запрос. То же относится и к распределённой обработке. Чтобы определить, откуда изначально был отправлен distributed query, смотрите `system.processes` на сервере, отправившем запрос.
* `port` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Порт клиента, с которого был выполнен запрос.
* `initial_user` ([String](/ru/sql-reference/data-types/string)) — Имя пользователя, выполнившего initial query (для выполнения распределённого запроса).
* `initial_query_id` ([String](/ru/sql-reference/data-types/string)) — ID initial query (для выполнения распределённого запроса).
* `initial_address` ([IPv6](/ru/sql-reference/data-types/ipv6)) — IP-адрес, с которого был запущен родительский запрос.
* `initial_port` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Порт клиента, использованный для выполнения родительского запроса.
* `interface` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Интерфейс, через который был отправлен запрос. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/ru/sql-reference/data-types/string)) — Имя пользователя операционной системы, под которым запущен клиент ClickHouse.
* `client_hostname` ([String](/ru/sql-reference/data-types/string)) — Имя хоста клиентской машины, на которой запущен клиент ClickHouse или другой TCP-клиент.
* `client_name` ([String](/ru/sql-reference/data-types/string)) — Имя клиента ClickHouse или другого TCP-клиента.
* `client_agent` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — ИИ-агент для программирования, который вызвал клиент (например, `claude-code` или `cursor`); определяется по переменным окружения. Пусто, если агент не обнаружен.
* `client_revision` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Ревизия клиента ClickHouse или другого TCP-клиента.
* `client_version_major` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Мажорная версия клиента ClickHouse или другого TCP-клиента.
* `client_version_minor` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Минорная версия клиента ClickHouse или другого TCP-клиента.
* `client_version_patch` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Патч-версия клиента ClickHouse или другого TCP-клиента.
* `http_method` ([UInt8](/ru/sql-reference/data-types/int-uint)) — HTTP-метод, которым был инициирован запрос. Возможные значения: 0 — запрос был запущен через интерфейс TCP. 1 — использовался метод GET. 2 — использовался метод POST.
* `http_user_agent` ([String](/ru/sql-reference/data-types/string)) — HTTP-заголовок UserAgent, переданный в HTTP-запросе.
* `http_referer` ([String](/ru/sql-reference/data-types/string)) — HTTP-заголовок Referer, переданный в HTTP-запросе (содержит полный или частичный адрес страницы, отправляющей запрос).
* `forwarded_for` ([String](/ru/sql-reference/data-types/string)) — HTTP-заголовок X-Forwarded-For, переданный в HTTP-запросе.
* `quota_key` ([String](/ru/sql-reference/data-types/string)) — Ключ квоты, указанный в настройке quotas (см. keyed).
* `distributed_depth` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество внутренних пересылок запроса между Server nodes.
* `elapsed` ([Float64](/ru/sql-reference/data-types/float)) — Время в секундах с момента начала выполнения запроса.
* `is_cancelled` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Был ли запрос отменён.
* `is_all_data_sent` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Были ли все данные отправлены клиенту (то есть был ли запрос завершён на сервере).
* `read_rows` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество строк, прочитанных из таблицы. Для распределённой обработки на запрашивающем сервере это общее значение для всех удалённых серверов.
* `read_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество несжатых байтов, прочитанных из таблицы. Для распределённой обработки на запрашивающем сервере это общее значение для всех удалённых серверов.
* `total_rows_approx` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Приблизительное общее количество строк, которые должны быть прочитаны. Для распределённой обработки на запрашивающем сервере это общее значение для всех удалённых серверов. Оно может обновляться во время обработки запроса, когда становятся известны новые источники данных для обработки.
* `written_rows` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество строк, записанных в хранилище.
* `written_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество байтов, записанных в хранилище.
* `memory_usage` ([Int64](/ru/sql-reference/data-types/int-uint)) — Объём оперативной памяти, используемой запросом. Может не включать некоторые типы выделенной памяти.
* `peak_memory_usage` ([Int64](/ru/sql-reference/data-types/int-uint)) — Текущее пиковое использование памяти.
* `query` ([String](/ru/sql-reference/data-types/string)) — Текст запроса. Для INSERT не включает данные для вставки.
* `normalized_query_hash` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Числовое хеш-значение, одинаковое для запросов, различающихся только значениями литералов.
* `query_kind` ([String](/ru/sql-reference/data-types/string)) — Тип запроса — SELECT, INSERT и т. д.
* `thread_ids` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Список идентификаторов всех потоков, участвовавших в выполнении этого запроса.
* `peak_threads_usage` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Максимальное количество потоков, одновременно выполнявших запрос.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ru/sql-reference/data-types/map)) — ProfileEvents, вычисленные для этого запроса.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ru/sql-reference/data-types/map)) — Список изменённых настроек на уровне пользователя.
* `current_database` ([String](/ru/sql-reference/data-types/string)) — Имя текущей базы данных.
* `is_internal` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Указывает, является ли запрос вспомогательным и выполняется ли он внутренне.

**Псевдонимы:**

* `ProfileEvents.Names` — псевдоним для `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — псевдоним для `mapValues(ProfileEvents)`.
* `Settings.Names` — псевдоним для `mapKeys(Settings)`.
* `Settings.Values` — псевдоним для `mapValues(Settings)`.

{/*AUTOGENERATED_END*/ }
