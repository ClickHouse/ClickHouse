<div id="description">
  ## Описание
</div>

Эта таблица содержит одну строку и один столбец `dummy` типа UInt8 со значением 0.

Эта таблица используется, если в запросе `SELECT` не указано предложение `FROM`.

Она аналогична таблице `DUAL`, которая есть в других СУБД.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `dummy` ([UInt8](/ru/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql
SELECT * FROM system.one LIMIT 10;
```

┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
