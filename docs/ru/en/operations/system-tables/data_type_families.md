<div id="description">
  ## Описание
</div>

Содержит сведения о поддерживаемых [типах данных](../../sql-reference/data-types/index.md).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Название типа данных.
* `case_insensitive` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Свойство, показывающее, поддерживается ли регистронезависимый поиск по имени типа данных в запросе. Например, `Date` и `date` оба допустимы.
* `alias_to` ([String](/ru/sql-reference/data-types/string)) — Название типа данных, для которого `name` является псевдонимом.
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание типа данных.
* `syntax` ([String](/ru/sql-reference/data-types/string)) — Как тип данных записывается в запросе.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой этот тип данных впервые появился, в формате major.minor.
* `related` ([Array](/ru/sql-reference/data-types/array)([String](/ru/sql-reference/data-types/string))) — Названия связанных типов данных.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
