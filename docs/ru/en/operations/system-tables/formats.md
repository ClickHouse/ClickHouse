<div id="description">
  ## Описание
</div>

Содержит список всех форматов, а также сведения о том, подходит ли каждый формат для ввода/вывода и поддерживает ли он распараллеливание.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Название формата.
* `is_input` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, подходит ли формат для ввода данных.
* `is_output` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, подходит ли формат для вывода данных.
* `supports_parallel_parsing` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли формат параллельный парсинг.
* `supports_parallel_formatting` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли формат параллельное форматирование.
* `is_tty_friendly` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, корректно ли формат обычно отображается в терминале. Для других форматов CLI перед выводом запросит подтверждение.
* `content_type` ([String](/ru/sql-reference/data-types/string)) — HTTP Content-Type, соответствующий выходному формату. Может зависеть от текущих настроек формата.
* `supports_random_access` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, поддерживает ли формат произвольный доступ при вводе.
* `has_schema_inference` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Формат может динамически определять схему по данным (либо из встроенного заголовка/метаданных, либо из самого фрагмента данных).
* `has_external_schema` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Формат либо имеет фиксированную схему, либо принимает заранее заданную схему в собственном формате.
* `prefers_large_blocks` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Формат записывает более крупные блоки при выводе и формирует более крупные блоки при вводе.
* `supports_append` ([UInt8](/ru/sql-reference/data-types/int-uint)) — С этим форматом можно дописывать данные в один файл.
* `supports_subsets_of_columns` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Входной формат может распознавать отсутствие некоторых столбцов.
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание формата.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой формат был впервые представлен, в виде major.minor.
* `related` ([Array](/ru/sql-reference/data-types/array)([String](/ru/sql-reference/data-types/string))) — Названия связанных форматов.
