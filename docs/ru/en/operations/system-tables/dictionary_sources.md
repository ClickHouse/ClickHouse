<div id="description">
  ## Описание
</div>

Содержит список источников словарей, поддерживаемых сервером, а также встроенную документацию по каждому источнику. Источник словаря определяет, откуда загружаются данные словаря; он указывается в предложении `SOURCE` запроса `CREATE DICTIONARY`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Название источника словаря, как указано в предложении SOURCE.
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание назначения источника словаря.
* `syntax` ([String](/ru/sql-reference/data-types/string)) — Структура предложения SOURCE, используемого для указания источника. Обратите внимание, что для некоторых источников действует управление доступом, если словарь создаётся из DDL-запроса (а не из файла конфигурации сервера); подробности см. в `description` соответствующего источника.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой этот источник был впервые представлен, в формате major.minor.
* `related` ([Array](/ru/sql-reference/data-types/array)([String](/ru/sql-reference/data-types/string))) — Названия связанных источников словаря.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql title="Query"
SELECT name, syntax
FROM system.dictionary_sources
WHERE name IN ('clickhouse', 'file')
ORDER BY name
```

```text title="Response"
┌─name───────┬─syntax─────────────────────────────────────────────────────────────────────────┐
│ clickhouse │ SOURCE(CLICKHOUSE(host 'host' port 9000 user 'default' password '' db 'db' table 'table')) │
│ file       │ SOURCE(FILE(path '/path/to/file' format 'CSV'))                                  │
└────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
