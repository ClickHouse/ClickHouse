<div id="description">
  ## Описание
</div>

Эта системная таблица содержит историю снимков таблиц Iceberg, имеющихся в ClickHouse. Если в ClickHouse нет ни одной таблицы Iceberg, она будет пустой.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `made_current_at` ([Nullable(DateTime64(3))](/ru/sql-reference/data-types/nullable)) — Дата и время, когда этот снимок стал текущим.
* `snapshot_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Идентификатор снимка, используемый для его идентификации.
* `parent_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Идентификатор родительского снимка.
* `is_current_ancestor` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, является ли этот снимок предком текущего снимка.

{/*AUTOGENERATED_END*/ }
