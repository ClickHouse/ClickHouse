<div id="description">
  ## Описание
</div>

Содержит сведения об обычных и агрегатных функциях.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя функции.
* `is_aggregate` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Является ли функция агрегатной.
* `case_insensitive` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Можно ли использовать имя функции без учета регистра.
* `alias_to` ([String](/ru/sql-reference/data-types/string)) — Исходное имя функции, если имя функции является псевдонимом.
* `create_query` ([String](/ru/sql-reference/data-types/string)) — Устарело.
* `origin` ([Enum8(&#39;System&#39; = 0, &#39;SQLUserDefined&#39; = 1, &#39;ExecutableUserDefined&#39; = 2)](/ru/sql-reference/data-types/enum)) — Устарело.
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание назначения функции.
* `syntax` ([String](/ru/sql-reference/data-types/string)) — Сигнатура функции.
* `arguments` ([String](/ru/sql-reference/data-types/string)) — Аргументы функции.
* `parameters` ([String](/ru/sql-reference/data-types/string)) — Параметры функции (только для агрегатных функций).
* `returned_value` ([String](/ru/sql-reference/data-types/string)) — Что возвращает функция.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Пример использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой функция была впервые представлена.
* `categories` ([String](/ru/sql-reference/data-types/string)) — Категория функции.
* `deterministic` ([Nullable(UInt8)](/ru/sql-reference/data-types/int-uint)) — Возвращает ли функция один и тот же результат для одних и тех же аргументов. `NULL`, если это неизвестно (например, для агрегатных или пользовательских функций).
* `higher_order` ([Nullable(UInt8)](/ru/sql-reference/data-types/int-uint)) — Является ли функция функцией высшего порядка, то есть принимает ли она как минимум одно lambda-выражение в качестве аргумента (например, `arrayMap`, `arrayFilter`, `mapApply`). `NULL`, если это неизвестно.

{/*AUTOGENERATED_END*/ }
