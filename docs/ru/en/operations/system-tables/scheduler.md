<div id="description">
  ## Описание
</div>

Содержит информацию о [узлах планировщика](/ru/operations/workload-scheduling.md/#hierarchy), находящихся на локальном сервере, и их состоянии.
Эту таблицу можно использовать для мониторинга. Таблица содержит по одной строке для каждого узла планировщика.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `resource` ([String](/ru/sql-reference/data-types/string)) — Имя ресурса
* `path` ([String](/ru/sql-reference/data-types/string)) — Путь к узлу планировщика в этой иерархии планирования ресурсов
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип узла планировщика.
* `weight` ([Float64](/ru/sql-reference/data-types/float)) — Вес узла, используемый родительским узлом типа `fair`.
* `priority` ([Int64](/ru/sql-reference/data-types/int-uint)) — Приоритет узла, используемый родительским узлом типа &#39;priority&#39; (меньшее значение означает более высокий приоритет).
* `is_active` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Активен ли этот узел в данный момент — есть ли у него запросы ресурсов для извлечения из очереди и выполнены ли ограничения.
* `active_children` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество дочерних узлов в активном состоянии.
* `dequeued_requests` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество запросов ресурсов, извлечённых из очереди этого узла.
* `canceled_requests` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество запросов ресурсов, отменённых для этого узла.
* `dequeued_cost` ([Int64](/ru/sql-reference/data-types/int-uint)) — Сумма стоимостей (например, размера в байтах) всех запросов, извлечённых из очереди этого узла.
* `throughput` ([Float64](/ru/sql-reference/data-types/float)) — Текущая средняя пропускная способность (стоимость извлечённых из очереди запросов в секунду).
* `canceled_cost` ([Int64](/ru/sql-reference/data-types/int-uint)) — Сумма стоимостей (например, размера в байтах) всех запросов, отменённых для этого узла.
* `busy_periods` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество деактиваций этого узла.
* `vruntime` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Только для дочерних узлов `fair`. Виртуальное время выполнения узла, используемое алгоритмом SFQ для выбора следующего дочернего узла для обработки по принципу max-min fairness.
* `system_vruntime` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `fair`. Виртуальное время выполнения, показывающее `vruntime` последнего обработанного запроса ресурса. Используется при активации дочернего узла как новое значение `vruntime`.
* `queue_length` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `fifo`. Текущее количество запросов ресурсов в очереди.
* `queue_cost` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `fifo`. Сумма стоимостей (например, размера в байтах) всех запросов, находящихся в очереди.
* `budget` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `fifo`. Количество доступных &#39;единиц стоимости&#39; для новых запросов ресурсов. Может появляться в случае расхождения между оценочной и фактической стоимостью запросов ресурсов (например, после ошибки чтения/записи)
* `is_satisfied` ([Nullable(UInt8)](/ru/sql-reference/data-types/nullable)) — Только для узлов ограничений (например, `inflight_limit`). Равно `1`, если все ограничения этого узла выполнены.
* `inflight_requests` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `inflight_limit`. Количество запросов ресурсов, извлечённых из очереди этого узла и находящихся в обработке.
* `inflight_cost` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `inflight_limit`. Сумма стоимостей (например, в байтах) всех запросов ресурсов, извлечённых из очереди этого узла и находящихся в обработке.
* `max_requests` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `inflight_limit`. Верхний предел для inflight&#95;requests, при превышении которого возникает нарушение ограничения.
* `max_cost` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `inflight_limit`. Верхний предел для inflight&#95;cost, при превышении которого возникает нарушение ограничения.
* `max_speed` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Верхний предел пропускной способности в токенах в секунду.
* `max_burst` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Верхний предел числа токенов, доступных в throttler token-bucket.
* `throttling_us` ([Nullable(Int64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Общее количество микросекунд, в течение которых этот узел находился в режиме throttling.
* `tokens` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Только для узлов `bandwidth_limit`. Количество токенов, доступных в данный момент в token-bucket throttler.

{/*AUTOGENERATED_END*/ }
