<div id="description">
  ## Описание
</div>

Содержит информацию о настроенных пользовательских каталогах — каталогах в файловой системе, из которых серверу ClickHouse разрешено читать пользовательские данные.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя каталога.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип хранилища доступа, например users.xml, replicated, memory и т. д.
* `params` ([String](/ru/sql-reference/data-types/string)) — JSON с параметрами хранилища доступа.
* `precedence` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Порядок, в котором этот каталог объявлен в конфигурации. Этот же порядок используется, когда ClickHouse пытается найти пользователя или роль.

{/*AUTOGENERATED_END*/ }
