<div id="description">
  ## Описание
</div>

Описывает содержимое профиля настроек:

* Ограничения.
* Роли и пользователи, к которым применяются настройки.
* Родительские профили настроек.

<div id="columns">
  ## Столбцы
</div>

<!--AUTOGENERATED_START-->

* `profile_name` ([Nullable(String)](/sql-reference/data-types/nullable)) — Имя профиля настроек.
* `user_name` ([Nullable(String)](/sql-reference/data-types/nullable)) — Имя пользователя.
* `role_name` ([Nullable(String)](/sql-reference/data-types/nullable)) — Имя роли.
* `index` ([UInt64](/sql-reference/data-types/int-uint)) — Последовательный номер элемента профиля настроек.
* `setting_name` ([Nullable(String)](/sql-reference/data-types/nullable)) — Имя настройки.
* `value` ([Nullable(String)](/sql-reference/data-types/nullable)) — Значение настройки.
* `min` ([Nullable(String)](/sql-reference/data-types/nullable)) — Минимальное значение настройки. NULL, если не задано.
* `max` ([Nullable(String)](/sql-reference/data-types/nullable)) — Максимальное значение настройки. NULL, если не задано.
* `writability` ([Nullable(Enum8(&#39;WRITABLE&#39; = 0, &#39;CONST&#39; = 1, &#39;CHANGEABLE&#95;IN&#95;READONLY&#39; = 2))](/sql-reference/data-types/nullable)) — Свойство, указывающее, можно ли изменять настройку.
* `inherit_profile` ([Nullable(String)](/sql-reference/data-types/nullable)) — Родительский профиль для данного профиля настроек. NULL, если не задано. Профиль настроек наследует все значения настроек и ограничения (min, max, только для чтения) от своих родительских профилей.
