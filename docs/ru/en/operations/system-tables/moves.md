<div id="description">
  ## Описание
</div>

Таблица содержит информацию о выполняемых [перемещениях частей данных](/ru/sql-reference/statements/alter/partition#move-partitionpart) таблиц [MergeTree](/ru/engines/table-engines/mergetree-family/mergetree.md). Каждому перемещению части данных соответствует одна строка.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы, содержащей перемещаемую часть данных.
* `elapsed` ([Float64](/ru/sql-reference/data-types/float)) — Время (в секундах), прошедшее с начала перемещения части данных.
* `target_disk_name` ([String](/ru/sql-reference/data-types/string)) — Имя диска, на который перемещается часть данных.
* `target_disk_path` ([String](/ru/sql-reference/data-types/string)) — Путь к точке монтирования диска в файловой системе.
* `part_name` ([String](/ru/sql-reference/data-types/string)) — Имя перемещаемой части данных.
* `part_size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер части данных.
* `thread_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Идентификатор потока, выполняющего перемещение.

{/*AUTOGENERATED_END*/ }
