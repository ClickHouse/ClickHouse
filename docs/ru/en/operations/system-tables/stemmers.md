<div id="description">
  ## Описание
</div>

Показывает все доступные стеммеры.
Их можно использовать в функции [stem](../../sql-reference/functions/nlp-functions.md).

:::note Доступность
`system.stemmers` доступна только в сборках ClickHouse, скомпилированных с зависимостью `libstemmer` (`USE_LIBSTEMMER`). В сборках без неё эта таблица отсутствует, и запросы к ней завершатся ошибкой `UNKNOWN_TABLE`. Проверить, включена ли эта зависимость в вашей сборке, можно так:

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

Столбцы:

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — идентификатор стеммера Snowball (язык/алгоритм)

{/*AUTOGENERATED_END*/ }
