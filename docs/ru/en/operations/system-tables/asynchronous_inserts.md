<div id="description">
  ## Описание
</div>

Содержит информацию об ожидающих выполнения асинхронных вставках в очереди.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/ru/sql-reference/data-types/string)) — Текст запроса.
* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `format` ([String](/ru/sql-reference/data-types/string)) — Имя формата.
* `first_update` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Время первой вставки с точностью до микросекунд.
* `total_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество байтов, ожидающих в очереди.
* `entries.query_id` ([Array(String)](/ru/sql-reference/data-types/array)) — Массив Query id вставок, ожидающих в очереди.
* `entries.bytes` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Массив значений в байтах для каждой вставки, ожидающей в очереди.

{/*AUTOGENERATED_END*/ }
