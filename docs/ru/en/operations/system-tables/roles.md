<div id="description">
  ## Описание
</div>

Содержит информацию о настроенных [ролях](../../guides/sre/user-management/index.md#role-management).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — имя роли.
* `id` ([UUID](/ru/sql-reference/data-types/uuid)) — идентификатор роли.
* `storage` ([String](/ru/sql-reference/data-types/string)) — путь к хранилищу ролей. Настраивается с помощью параметра `access_control_path`.

{/*AUTOGENERATED_END*/ }
