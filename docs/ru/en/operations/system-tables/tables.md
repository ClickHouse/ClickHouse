<div id="description">
  ## Описание
</div>

Содержит метаданные всех таблиц, известных серверу.

[Отсоединённые](../../sql-reference/statements/detach.md) таблицы не отображаются в `system.tables`.

[Временные таблицы](../../sql-reference/statements/create/table.md#temporary-tables) видны в `system.tables` только в том сеансе, в котором они были созданы. Они отображаются с пустым полем `database` и включённым флагом `is_temporary`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных, в которой находится таблица.
* `name` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `uuid` ([UUID](/ru/sql-reference/data-types/uuid)) — UUID таблицы (база данных Atomic).
* `engine` ([String](/ru/sql-reference/data-types/string)) — Имя движка таблицы (без параметров).
* `is_temporary` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, является ли таблица временной.
* `data_paths` ([Array(String)](/ru/sql-reference/data-types/array)) — Пути к данным таблицы в файловых системах.
* `metadata_path` ([String](/ru/sql-reference/data-types/string)) — Путь к метаданным таблицы в файловой системе.
* `metadata_modification_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время последнего изменения метаданных таблицы.
* `metadata_version` ([Int32](/ru/sql-reference/data-types/int-uint)) — Версия метаданных для таблицы ReplicatedMergeTree; для таблиц, не использующих ReplicatedMergeTree, — 0.
* `dependencies_database` ([Array(String)](/ru/sql-reference/data-types/array)) — Зависимости базы данных.
* `dependencies_table` ([Array(String)](/ru/sql-reference/data-types/array)) — Зависимости таблицы (materialized view текущей таблицы).
* `create_table_query` ([String](/ru/sql-reference/data-types/string)) — Запрос, использованный для создания таблицы.
* `engine_full` ([String](/ru/sql-reference/data-types/string)) — Параметры движка таблицы.
* `as_select` ([String](/ru/sql-reference/data-types/string)) — Запрос SELECT для представления.
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/ru/sql-reference/data-types/array)) — Параметры parameterized view.
* `partition_key` ([String](/ru/sql-reference/data-types/string)) — Выражение ключа партиционирования, заданное в таблице.
* `sorting_key` ([String](/ru/sql-reference/data-types/string)) — Выражение ключа сортировки, заданное в таблице.
* `primary_key` ([String](/ru/sql-reference/data-types/string)) — Выражение первичного ключа, заданное в таблице.
* `sampling_key` ([String](/ru/sql-reference/data-types/string)) — Выражение ключа выборки, заданное в таблице.
* `storage_policy` ([String](/ru/sql-reference/data-types/string)) — Политика хранения. Актуально для таблиц, использующих движки MergeTree и Distributed.
* `total_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество строк, если точное количество строк в таблице можно быстро определить; в противном случае — NULL (включая нижележащую Buffer table).
* `total_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество байтов, если точный размер таблицы в хранилище можно быстро определить; в противном случае — NULL (не включает нижележащее хранилище). Если таблица хранит данные на диске, возвращает объём занятого места на диске (то есть в сжатом виде). Если таблица хранит данные в памяти, возвращает приблизительное количество используемых байтов в памяти.
* `total_bytes_uncompressed` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество несжатых байтов, если точное количество байтов можно быстро определить по part checksums для таблицы в хранилище; в противном случае — NULL (без учёта нижележащего хранилища, если оно есть).
* `parts` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество частей в этой таблице.
* `active_parts` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Количество активных частей в этой таблице.
* `total_marks` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество отметок во всех частях этой таблицы.
* `active_on_fly_data_mutations` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество активных мутаций данных (UPDATE и DELETE), которые можно применять на лету.
* `active_on_fly_alter_mutations` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество активных мутаций ALTER (MODIFY COLUMN), которые можно применять на лету.
* `active_on_fly_metadata_mutations` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество активных мутаций метаданных (RENAME), которые можно применять на лету.
* `columns_descriptions_cache_size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер кэша описаний столбцов для таблиц семейства *MergeTree
* `lifetime_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество строк, INSERTed с момента запуска server (только для Buffer tables).
* `lifetime_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Общее количество байтов, INSERTed с момента запуска server (только для Buffer tables).
* `comment` ([String](/ru/sql-reference/data-types/string)) — Комментарий к таблице.
* `has_own_data` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, хранит ли таблица собственные данные на disk или только обращается к другому source.
* `loading_dependencies_database` ([Array(String)](/ru/sql-reference/data-types/array)) — Зависимости загрузки для базы данных (список объектов, которые должны быть загружены до текущего объекта).
* `loading_dependencies_table` ([Array(String)](/ru/sql-reference/data-types/array)) — Зависимости загрузки для таблицы (список объектов, которые должны быть загружены до текущего объекта).
* `loading_dependent_database` ([Array(String)](/ru/sql-reference/data-types/array)) — Зависимая база данных для загрузки.
* `loading_dependent_table` ([Array(String)](/ru/sql-reference/data-types/array)) — Зависимая таблица для загрузки.
* `target_database` ([String](/ru/sql-reference/data-types/string)) — Для materialized view — база данных целевой таблицы, в которую записывает представление (цель `TO` или неявная таблица `.inner.*`). Для других движков пусто.
* `target_table` ([String](/ru/sql-reference/data-types/string)) — Для materialized view — имя целевой таблицы, в которую записывает представление (цель `TO` или неявная таблица `.inner.*`). Для других движков пусто.
* `definer` ([String](/ru/sql-reference/data-types/string)) — Имя пользователя-определителя, используемое для безопасности SQL этой таблицы.

**Псевдонимы:**

* `table` — псевдоним для `name`.
