<div id="systembackground_schedule_pool">
  # system.background_schedule_pool
</div>

<SystemTableCloud />

<div id="description">
  ## Описание
</div>

Содержит сведения о задачах в фоновых пулах планировщика. Фоновые пулы планировщика используются для выполнения периодических задач, таких как отправка данных в распределённые таблицы, сброс буферов и операции брокера сообщений.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `pool` ([String](/ru/sql-reference/data-types/string)) — Имя пула. Возможные значения: `schedule` — пул расписания общего назначения, `buffer_flush` — пул для сброса данных таблицы Buffer, `distributed` — пул для операций distributed таблицы, `message_broker` — пул для операций брокера сообщений.
* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `table_uuid` ([UUID](/ru/sql-reference/data-types/uuid)) — UUID таблицы.
* `query_id` ([String](/ru/sql-reference/data-types/string)) — Query ID (если сейчас выполняется). Примечание: это не реальный запрос, а случайно сгенерированный ID для сопоставления записей журнала в `system.text_log`.
* `elapsed_ms` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Время выполнения задачи (если сейчас выполняется).
* `log_name` ([String](/ru/sql-reference/data-types/string)) — Имя журнала для задачи.
* `deactivated` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Деактивирована ли задача (всегда false, так как деактивированные задачи удаляются из пула).
* `scheduled` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Запланирована ли задача к выполнению.
* `delayed` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Запланирована ли задача с задержкой.
* `executing` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Выполняется ли задача в данный момент.

{/*AUTOGENERATED_END*/ }
