<div id="description">
  ## Описание
</div>

Содержит список поддерживаемых сервером структур словарей, а также встроенную документацию для каждой из них. Структура словаря определяет, как словарь хранится в памяти (или на диске) и как выполняется поиск по нему; она задается в предложении `LAYOUT` запроса `CREATE DICTIONARY`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Название структуры словаря, как указано в предложении LAYOUT.
* `is_complex` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Требуется ли для этой структуры составной ключ (ключ, состоящий из нескольких атрибутов или имеющий нецелочисленный тип).
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание структуры словаря.
* `syntax` ([String](/ru/sql-reference/data-types/string)) — Как структура указывается в предложении LAYOUT запроса CREATE DICTIONARY.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой эта структура впервые появилась, в формате major.minor.
* `related` ([Array](/ru/sql-reference/data-types/array)([String](/ru/sql-reference/data-types/string))) — Названия связанных структур словаря.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql title="Query"
SELECT name, is_complex, syntax
FROM system.dictionary_layouts
WHERE name IN ('flat', 'hashed', 'complex_key_hashed')
ORDER BY name
```

```text title="Response"
┌─name───────────────┬─is_complex─┬─syntax───────────────────────────────────────────────────┐
│ complex_key_hashed │          1 │ LAYOUT(COMPLEX_KEY_HASHED())                             │
│ flat               │          0 │ LAYOUT(FLAT([INITIAL_ARRAY_SIZE n] [MAX_ARRAY_SIZE n]))  │
│ hashed             │          0 │ LAYOUT(HASHED())                                         │
└────────────────────┴────────────┴──────────────────────────────────────────────────────────┘
```
