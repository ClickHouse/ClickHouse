<div id="description">
  ## Описание
</div>

Показывает содержимое [кэша запросов](../query-cache.md).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/ru/sql-reference/data-types/string)) — Строка запроса.
* `query_id` ([String](/ru/sql-reference/data-types/string)) — Идентификатор запроса.
* `result_size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер записи кэша запросов.
* `tag` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Тег записи кэша запросов.
* `stale` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Указывает, является ли запись кэша запросов устаревшей.
* `shared` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Указывает, используется ли запись кэша запросов совместно несколькими пользователями.
* `compressed` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Указывает, сжата ли запись кэша запросов.
* `expires_at` ([DateTime](/ru/sql-reference/data-types/datetime)) — Момент, когда запись кэша запросов становится устаревшей.
* `key_hash` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Хэш строки запроса, используемый в качестве ключа для поиска записей кэша запросов.

{/*AUTOGENERATED_END*/ }
