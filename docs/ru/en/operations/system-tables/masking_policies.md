<div id="description">
  ## Описание
</div>

Содержит информацию обо всех политиках маскирования, определённых в системе.

Политики маскирования можно создавать и применять только в ClickHouse Cloud. В сборках с открытым исходным кодом таблица `system.masking_policies` всегда пуста, но она всё равно существует, чтобы запросы интроспекции, такие как `SHOW MASKING POLICIES`, работали и возвращали пустой результат, а не генерировали исключение.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string.md)) — Имя политики маскирования. Полный формат имени: `short_name ON database.table`.
* `short_name` ([String](/ru/sql-reference/data-types/string.md)) — Краткое имя политики маскирования. Например, если полное имя — `mask_email ON mydb.mytable`, то краткое имя — `mask_email`.
* `database` ([String](/ru/sql-reference/data-types/string.md)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string.md)) — Имя таблицы.
* `id` ([UUID](/ru/sql-reference/data-types/uuid.md)) — Идентификатор политики маскирования.
* `storage` ([String](/ru/sql-reference/data-types/string.md)) — Имя каталога, в котором хранится политика маскирования.
* `update_assignments` ([Nullable(String)](/ru/sql-reference/data-types/nullable.md)) — Присваивания в UPDATE, определяющие, как должны маскироваться данные. Например: `email = '***masked***', phone = '***-***-****'`.
* `where_condition` ([Nullable(String)](/ru/sql-reference/data-types/nullable.md)) — Необязательное предложение WHERE, указывающее, когда следует применять маскирование.
* `priority` ([Int64](/ru/sql-reference/data-types/int-uint.md)) — Приоритет применения нескольких политик маскирования. Сначала применяются политики с более высоким приоритетом. Значение по умолчанию — 0.
* `apply_to_all` ([UInt8](/ru/sql-reference/data-types/int-uint.md)) — Показывает, применяется ли политика маскирования ко всем roles и/или users. 1, если true, иначе 0.
* `apply_to_list` ([Array(String)](/ru/sql-reference/data-types/array.md)) — Список roles и/или users, к которым применяется политика маскирования.
* `apply_to_except` ([Array(String)](/ru/sql-reference/data-types/array.md)) — Политика маскирования применяется ко всем roles и/или users, кроме перечисленных. Заполняется только если `apply_to_all` равно 1.
