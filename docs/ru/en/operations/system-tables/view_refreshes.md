<div id="description">
  ## Описание
</div>

Информация о [Refreshable Materialized Views](../../sql-reference/statements/create/view.md#refreshable-materialized-view). Содержит все refreshable materialized view, независимо от того, выполняется ли обновление в данный момент.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных, в которой находится таблица.
* `view` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `uuid` ([UUID](/ru/sql-reference/data-types/uuid)) — UUID таблицы (база данных Atomic).
* `status` ([String](/ru/sql-reference/data-types/string)) — Текущее состояние обновления.
* `last_success_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время начала последнего успешного обновления. NULL, если с момента запуска сервера или создания таблицы успешных обновлений не было.
* `last_success_duration_ms` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Длительность последнего обновления.
* `last_refresh_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время, когда завершилась последняя попытка обновления (если это известно) или когда она началась (если это неизвестно или она все еще выполняется). NULL, если с момента запуска сервера или создания таблицы попыток обновления не было.
* `last_refresh_replica` ([String](/ru/sql-reference/data-types/string)) — Если включена координация, имя реплики, которая выполняет текущую попытку обновления (если обновление запущено) или выполнила предыдущую (если не запущено).
* `next_refresh_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время, на которое запланирован запуск следующего обновления. NULL, если время следующего обновления в данный момент неизвестно, например при ожидании зависимостей (status `WaitingForDependencies` или `MissingDependencies`).
* `exception` ([String](/ru/sql-reference/data-types/string)) — Сообщение об ошибке из предыдущей попытки, если она завершилась неудачно.
* `retry` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество неудачных попыток на данный момент для текущего обновления. Недоступно, если status — `RunningOnAnotherReplica`.
* `progress` ([Nullable(Float64)](/ru/sql-reference/data-types/nullable)) — Прогресс текущего выполняющегося или последнего завершенного обновления на данной реплике в диапазоне от 0 до 1. NULL, если status — `RunningOnAnotherReplica` или обновление не выполняется.
* `read_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Количество строк, прочитанных текущим выполняющимся или последним завершенным обновлением на данной реплике. NULL, если status — `RunningOnAnotherReplica`.
* `read_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Количество байтов, прочитанных текущим выполняющимся или последним завершенным обновлением на данной реплике. NULL, если status — `RunningOnAnotherReplica`
* `total_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Оценочное общее количество строк, которые должны быть прочитаны текущим выполняющимся или последним завершенным обновлением на данной реплике. NULL, если status — `RunningOnAnotherReplica`
* `written_rows` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Количество строк, записанных текущим выполняющимся или последним завершенным обновлением на данной реплике. NULL, если status — `RunningOnAnotherReplica`
* `written_bytes` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Количество байтов, записанных текущим выполняющимся или последним завершенным обновлением на данной реплике. NULL, если status — `RunningOnAnotherReplica`

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql
SELECT
    database,
    view,
    status,
    last_refresh_time,
    next_refresh_time
FROM system.view_refreshes

┌─database─┬─view───────────────────────┬─status────┬───last_refresh_time─┬───next_refresh_time─┐
│ default  │ hello_documentation_reader │ Scheduled │ 2023-12-01 01:24:00 │ 2023-12-01 01:25:00 │
└──────────┴────────────────────────────┴───────────┴─────────────────────┴─────────────────────┘
```
