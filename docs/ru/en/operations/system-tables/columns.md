<div id="description">
  ## Описание
</div>

Содержит информацию о столбцах всех таблиц.

Эту таблицу можно использовать, чтобы получить информацию, аналогичную запросу [DESCRIBE TABLE](../../sql-reference/statements/describe-table.md), но сразу по нескольким таблицам.

Столбцы из [временных таблиц](../../sql-reference/statements/create/table.md#temporary-tables) видны в `system.columns` только в тех сеансах, в которых они были созданы. Они отображаются с пустым полем `database`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `name` ([String](/ru/sql-reference/data-types/string)) — Имя столбца.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип столбца.
* `position` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Порядковый номер столбца в таблице, начиная с 1.
* `default_kind` ([String](/ru/sql-reference/data-types/string)) — Тип выражения (DEFAULT, MATERIALIZED, ALIAS) для значения по умолчанию или пустая строка, если оно не определено.
* `default_expression` ([String](/ru/sql-reference/data-types/string)) — Выражение для значения по умолчанию или пустая строка, если оно не определено.
* `data_compressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер сжатых данных в байтах.
* `data_uncompressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер распакованных данных в байтах.
* `marks_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер меток в байтах.
* `comment` ([String](/ru/sql-reference/data-types/string)) — Комментарий к столбцу или пустая строка, если он не определён.
* `is_in_partition_key` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение партиционирования.
* `is_in_sorting_key` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение ключа сортировки.
* `is_in_primary_key` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение первичного ключа.
* `is_in_sampling_key` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, входит ли столбец в выражение ключа выборки.
* `compression_codec` ([String](/ru/sql-reference/data-types/string)) — Имя кодека сжатия.
* `character_octet_length` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Максимальная длина в байтах для бинарных данных, символьных данных, текстовых данных и изображений. В ClickHouse имеет смысл только для типа данных FixedString. В противном случае возвращается значение NULL.
* `numeric_precision` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Точность приблизительных числовых данных, точных числовых данных, целочисленных данных или денежных данных. В ClickHouse это разрядность в битах для целочисленных типов и точность Decimal для типов Decimal. В противном случае возвращается значение NULL.
* `numeric_precision_radix` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Основание системы счисления для точности приблизительных числовых данных, точных числовых данных, целочисленных данных или денежных данных. В ClickHouse это 2 для целочисленных типов и 10 для типов Decimal. В противном случае возвращается значение NULL.
* `numeric_scale` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Масштаб приблизительных числовых данных, точных числовых данных, целочисленных данных или денежных данных. В ClickHouse имеет смысл только для типов Decimal. В противном случае возвращается значение NULL.
* `datetime_precision` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Десятичная точность типа данных DateTime64. Для других типов данных возвращается значение NULL.
* `serialization_hint` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Подсказка для столбца, помогающая выбрать сериализацию при вставке на основе статистики.
* `statistics` ([String](/ru/sql-reference/data-types/string)) — Типы статистики, созданные для этого столбца.

**Псевдонимы:**

* `column` — Псевдоним для `name`.

{/*AUTOGENERATED_END*/ }
