<div id="description">
  ## Описание
</div>

Содержит информацию о потоках, выполняющих запросы, например имя потока, время его запуска и длительность обработки запроса.

Чтобы включить логирование:

1. Настройте параметры в разделе [query&#95;thread&#95;log](/ru/operations/server-configuration-parameters/settings#query_thread_log).
2. Установите [log&#95;query&#95;threads](/ru/operations/settings/settings#log_query_threads) в 1.

Период сброса данных задается параметром `flush_interval_milliseconds` в разделе настроек сервера [query&#95;thread&#95;log](/ru/operations/server-configuration-parameters/settings#query_thread_log). Чтобы принудительно выполнить сброс, используйте запрос [SYSTEM FLUSH LOGS](/ru/sql-reference/statements/system#flush-logs).

ClickHouse не удаляет данные из таблицы автоматически. Подробнее см. в разделе [Introduction](/ru/operations/system-tables/overview#system-tables-introduction).

Вы можете использовать настройку [log&#95;queries&#95;probability](/ru/operations/settings/settings#log_queries_probability)), чтобы уменьшить число запросов, регистрируемых в таблице `query_thread_log`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя хоста сервера, выполняющего запрос.
* `event_date` ([Date](/ru/sql-reference/data-types/date)) — Дата, когда поток завершил выполнение запроса.
* `event_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Дата и время, когда поток завершил выполнение запроса.
* `event_time_microseconds` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Дата и время, когда поток завершил выполнение запроса, с точностью до микросекунд.
* `query_start_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время начала выполнения запроса.
* `query_start_time_microseconds` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Время начала выполнения запроса с точностью до микросекунд.
* `query_duration_ms` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Длительность выполнения запроса.
* `read_rows` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество прочитанных строк.
* `read_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество прочитанных байтов.
* `written_rows` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Для INSERT-запросов — количество записанных строк. Для других запросов значение столбца равно 0.
* `written_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Для INSERT-запросов — количество записанных байтов. Для других запросов значение столбца равно 0.
* `memory_usage` ([Int64](/ru/sql-reference/data-types/int-uint)) — Разность между объёмом выделенной и освобождённой памяти в контексте этого потока.
* `peak_memory_usage` ([Int64](/ru/sql-reference/data-types/int-uint)) — Максимальная разность между объёмом выделенной и освобождённой памяти в контексте этого потока.
* `thread_name` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя потока.
* `thread_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Внутренний идентификатор потока.
* `master_thread_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Исходный идентификатор начального потока в ОС.
* `current_database` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя текущей базы данных.
* `query` ([String](/ru/sql-reference/data-types/string)) — Строка запроса.
* `normalized_query_hash` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Хеш нормализованного запроса — с удалёнными константами и т. д.
* `is_initial_query` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Тип запроса. Возможные значения: 1 — запрос был инициирован клиентом, 0 — запрос был инициирован другим запросом для выполнения распределённого запроса.
* `connection_address` ([IPv6](/ru/sql-reference/data-types/ipv6)) — IP-адрес клиента, с которого было установлено соединение. При подключении через прокси это будет адрес прокси.
* `connection_port` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Порт клиента, с которого было установлено соединение. При подключении через прокси это будет порт прокси.
* `user` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя пользователя, инициировавшего текущий запрос.
* `query_id` ([String](/ru/sql-reference/data-types/string)) — Идентификатор запроса.
* `address` ([IPv6](/ru/sql-reference/data-types/ipv6)) — IP-адрес, использованный для выполнения запроса. При подключении через прокси и установленном `auth_use_forwarded_address` это будет адрес клиента, а не прокси.
* `port` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Порт клиента, который использовался для выполнения запроса. При подключении через прокси и если задан `auth_use_forwarded_address`, это будет порт клиента, а не прокси.
* `initial_user` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя пользователя, который выполнил начальный запрос (для выполнения распределённого запроса).
* `initial_query_id` ([String](/ru/sql-reference/data-types/string)) — ID начального запроса (для выполнения распределённого запроса).
* `initial_address` ([IPv6](/ru/sql-reference/data-types/ipv6)) — IP-адрес, с которого был запущен родительский запрос.
* `initial_port` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Порт клиента, который использовался для выполнения родительского запроса.
* `initial_query_start_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время начала выполнения начального запроса.
* `initial_query_start_time_microseconds` ([DateTime64(6)](/ru/sql-reference/data-types/datetime64)) — Время начала выполнения начального запроса
* `authenticated_user` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя пользователя, прошедшего аутентификацию в сеансе.
* `interface` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Интерфейс, из которого был инициирован запрос. Возможные значения: 1 — TCP, 2 — HTTP.
* `is_secure` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, показывающий, было ли соединение защищённым.
* `os_user` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя пользователя ОС, под которым запущен `clickhouse-client`.
* `client_hostname` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя хоста клиентской машины, на которой запущен `clickhouse-client` или другой TCP-клиент.
* `client_name` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя `clickhouse-client` или другого TCP-клиента.
* `client_agent` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — ИИ-агент для написания кода, который вызвал клиент (например, `claude-code` или `cursor`) и был определён по переменным окружения. Пусто, если агент не был обнаружен.
* `client_revision` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Ревизия `clickhouse-client` или другого TCP-клиента.
* `client_version_major` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Мажорная версия `clickhouse-client` или другого TCP-клиента.
* `client_version_minor` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Минорная версия `clickhouse-client` или другого TCP-клиента.
* `client_version_patch` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Патч-версия `clickhouse-client` или другого TCP-клиента.
* `script_query_number` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Последовательный номер запроса в скрипте с несколькими запросами.
* `script_line_number` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Номер строки в скрипте с несколькими запросами, на которой начинается текущий запрос.
* `http_method` ([UInt8](/ru/sql-reference/data-types/int-uint)) — HTTP-метод, которым был инициирован запрос. Возможные значения: 0 — запрос был запущен через интерфейс TCP, 1 — использовался метод GET., 2 — использовался метод POST.
* `http_user_agent` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Заголовок `User-Agent`, переданный в HTTP-запросе.
* `http_referer` ([String](/ru/sql-reference/data-types/string)) — HTTP-заголовок `Referer`, переданный в HTTP-запросе (содержит абсолютный или частичный адрес страницы, выполняющей запрос).
* `forwarded_for` ([String](/ru/sql-reference/data-types/string)) — HTTP-заголовок `X-Forwarded-For`, переданный в HTTP-запросе.
* `quota_key` ([String](/ru/sql-reference/data-types/string)) — «ключ квоты», указанный в настройке quotas.
* `distributed_depth` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Сколько раз запрос был перенаправлен между серверами.
* `revision` ([UInt32](/ru/sql-reference/data-types/int-uint)) — ревизия ClickHouse.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ru/sql-reference/data-types/map)) — ProfileEvents, измеряющие различные метрики для этого потока. Их описание можно найти в таблице system.events.

**Псевдонимы:**

* `ProfileEvents.Names` — псевдоним для `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — псевдоним для `mapValues(ProfileEvents)`.
