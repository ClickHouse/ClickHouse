<div id="description">
  ## Описание
</div>

Содержит список моделей CatBoost, загруженных в память LibraryBridge, а также время их загрузки.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `model_path` ([String](/ru/sql-reference/data-types/string)) — Путь к обученной модели.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип модели. Сейчас поддерживается только catboost.
* `loading_start_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время начала загрузки модели.
* `loading_duration` ([Float32](/ru/sql-reference/data-types/float)) — Время, затраченное на загрузку модели.

{/*AUTOGENERATED_END*/ }
