<div id="description">
  ## Описание
</div>

Содержит информацию о выделениях памяти, выполненных аллокатором jemalloc в различных классах размеров (bins), с агрегацией по всем аренам.
Эта статистика может быть не совсем точной из-за используемого в jemalloc локального кэширования на уровне потоков.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt16](/ru/sql-reference/data-types/int-uint)) — Индекс bin, отсортированного по размеру.
* `large` ([UInt8](/ru/sql-reference/data-types/int-uint)) — `true` для крупных выделений и `false` для малых.
* `size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер выделений в этом bin.
* `allocations` ([Int64](/ru/sql-reference/data-types/int-uint)) — Число выделений.
* `deallocations` ([Int64](/ru/sql-reference/data-types/int-uint)) — Число освобождений памяти.
* `nregs` ([Int64](/ru/sql-reference/data-types/int-uint)) — Число регионов в каждом slab.
* `curslabs` ([Int64](/ru/sql-reference/data-types/int-uint)) — Текущее число slab.
* `curregs` ([Int64](/ru/sql-reference/data-types/int-uint)) — Текущее число регионов для этого класса размеров.

**Псевдонимы:**

* `availregs` — Псевдоним для `nregs * curslabs`.
* `util` — Псевдоним для `curregs / availregs`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

Найдите размеры выделений, внесших наибольший вклад в текущее общее использование памяти.

```sql
SELECT
    *,
    allocations - deallocations AS active_allocations,
    size * active_allocations AS allocated_bytes
FROM system.jemalloc_bins
WHERE allocated_bytes > 0
ORDER BY allocated_bytes DESC
LIMIT 10
```
