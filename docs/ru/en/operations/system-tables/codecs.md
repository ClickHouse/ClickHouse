<div id="description">
  ## Описание
</div>

Содержит сведения о кодеках сжатия и шифрования.

Эту таблицу можно использовать для получения информации о доступных кодеках сжатия и шифрования

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя кодека.
* `method_byte` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Байт, указывающий кодек в сжатом файле.
* `is_compression` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Значение `true`, если этот кодек выполняет сжатие. В противном случае это может быть просто преобразование, помогающее сжатию.
* `is_generic_compression` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Кодек представляет собой универсальный алгоритм сжатия, такой как lz4 или zstd.
* `is_encryption` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Кодек выполняет шифрование.
* `is_timeseries_codec` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Кодек предназначен для временных рядов с числами с плавающей точкой.
* `is_experimental` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Кодек является экспериментальным.
* `description` ([String](/ru/sql-reference/data-types/string)) — Краткое описание кодека.

{/*AUTOGENERATED_END*/ }

  ## Пример
</div>

```sql title="Query"
SELECT * FROM system.codecs WHERE name='LZ4'
```
