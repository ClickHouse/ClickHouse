<div id="description">
  ## Описание
</div>

Эта системная таблица содержит метаданные отдельных файлов для таблиц Iceberg в ClickHouse: по одной строке для каждого файла данных или файла удаления, на который ссылается текущий снимок таблицы. Если в ClickHouse нет таблиц Iceberg, она будет пустой.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `snapshot_id` ([Int64](/ru/sql-reference/data-types/int-uint)) — ID снимка, в который был добавлен файл.
* `content` ([Enum8](/ru/sql-reference/data-types/enum)) — Тип содержимого файла: `DATA`, `POSITION_DELETE` или `EQUALITY_DELETE`.
* `file_path` ([String](/ru/sql-reference/data-types/string)) — Полный путь к файлу в хранилище.
* `file_format` ([String](/ru/sql-reference/data-types/string)) — Формат файла, например `'PARQUET'`.
* `record_count` ([Int64](/ru/sql-reference/data-types/int-uint)) — Количество записей в файле.
* `file_size_in_bytes` ([Int64](/ru/sql-reference/data-types/int-uint)) — Размер файла в байтах.
* `partition` ([String](/ru/sql-reference/data-types/string)) — Текстовое представление кортежа партиции.
* `schema_id` ([Int32](/ru/sql-reference/data-types/int-uint)) — ID схемы, определённый для этой записи манифеста.
* `sequence_number` ([Int64](/ru/sql-reference/data-types/int-uint)) — Порядковый номер, определённый для записи манифеста (всегда 0 для формата v1).
* `sort_order_id` ([Nullable(Int32)](/ru/sql-reference/data-types/nullable)) — ID порядка сортировки файла, если указан.
* `null_value_counts` ([Map(Int32, Int64)](/ru/sql-reference/data-types/map)) — Количество значений NULL по каждому столбцу (id столбца -&gt; количество).
* `column_sizes` ([Map(Int32, Int64)](/ru/sql-reference/data-types/map)) — Размер на диске в байтах для каждого столбца (id столбца -&gt; байты).
* `value_counts` ([Map(Int32, Int64)](/ru/sql-reference/data-types/map)) — Общее количество значений по каждому столбцу (id столбца -&gt; количество).
* `equality_ids` ([Array(Int32)](/ru/sql-reference/data-types/array)) — ID полей равенства для файлов удаления по равенству (пусто для файлов, не относящихся к этому типу удаления).
