<div id="description">
  ## Описание
</div>

Содержит свойства настроенных профилей настроек.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя профиля настроек.
* `id` ([UUID](/ru/sql-reference/data-types/uuid)) — Идентификатор профиля настроек.
* `storage` ([String](/ru/sql-reference/data-types/string)) — Путь к хранилищу профилей настроек. Задаётся в параметре `access_control_path`.
* `num_elements` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество элементов этого профиля в таблице `system.settings_profile_elements`.
* `apply_to_all` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, что профиль настроек задан для всех ролей и/или пользователей.
* `apply_to_list` ([Array(String)](/ru/sql-reference/data-types/array)) — Список ролей и/или пользователей, к которым применяется профиль настроек.
* `apply_to_except` ([Array(String)](/ru/sql-reference/data-types/array)) — Профиль настроек применяется ко всем ролям и/или пользователям, кроме перечисленных.

{/*AUTOGENERATED_END*/ }
