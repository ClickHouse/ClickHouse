<div id="description">
  ## Описание
</div>

Эта таблица содержит размерные метрики, которые можно вычислить мгновенно и экспортировать в формате Prometheus. Она всегда содержит актуальные данные.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/ru/sql-reference/data-types/string)) — Имя метрики.
* `value` ([Float64](/ru/sql-reference/data-types/float)) — Значение метрики.
* `description` ([String](/ru/sql-reference/data-types/string)) — Описание метрики.
* `labels` ([Map(String, String)](/ru/sql-reference/data-types/map)) — Метки метрики.

**Псевдонимы:**

* `name` — Псевдоним для `metric`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

Вы можете использовать следующий запрос, чтобы экспортировать все размерные метрики в формате Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## Описание метрик
</div>

<div id="merge_failures">
  ### merge_failures
</div>

Общее количество неуспешных слияний с момента запуска.

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

Показывает сбои стартовых скриптов по типам ошибок. При сбое стартового скрипта принимает значение 1; в качестве метки используется имя ошибки.

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

Количество частей данных MergeTree с метками по состоянию и типу части, а также по признаку того, является ли она частью проекции.

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

Количество сегментов файла, вытесненных из файлового кэша, с меткой имени кэша. По умолчанию отключено; включается с помощью `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

Общее количество байтов сегментов файла, вытесненных из файлового кэша; метка — имя кэша. По умолчанию отключено; включается с помощью `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

Количество сегментов файла, вытесненных из файлового кэша, с метками имени кэша и идентификатора пользователя. По умолчанию отключена; включите с помощью `expose_prometheus_eviction_metrics` и `expose_prometheus_eviction_metrics_per_user`.

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

Общее количество байтов сегментов файла, вытесненных из файлового кэша, с метками по имени кэша и идентификатору пользователя. По умолчанию отключено; включается с помощью `expose_prometheus_eviction_metrics` и `expose_prometheus_eviction_metrics_per_user`.
