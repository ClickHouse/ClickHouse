<div id="description">
  ## Описание
</div>

Содержит информацию обо всех записях файлового кэша для удалённых объектов.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `cache_name` ([String](/ru/sql-reference/data-types/string)) — Имя объекта файлового кэша. Может использоваться в командах `SYSTEM DESCRIBE FILESYSTEM CACHE <name>` и `SYSTEM DROP FILESYSTEM CACHE <name>`
* `cache_base_path` ([String](/ru/sql-reference/data-types/string)) — Путь к базовому каталогу, в котором хранятся все файлы кэша (для кэша, идентифицируемого по `cache_name`).
* `cache_path` ([String](/ru/sql-reference/data-types/string)) — Путь к конкретному файлу кэша, соответствующему сегменту в исходном файле
* `key` ([String](/ru/sql-reference/data-types/string)) — Ключ кэша для сегмента файла
* `file_segment_range_begin` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Смещение, соответствующее началу диапазона сегмента файла
* `file_segment_range_end` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Смещение, соответствующее концу диапазона сегмента файла (включительно)
* `size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер сегмента файла
* `state` ([String](/ru/sql-reference/data-types/string)) — Состояние сегмента файла (DOWNLOADED, DOWNLOADING, PARTIALLY&#95;DOWNLOADED, ...)
* `finished_download_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время, когда завершилась загрузка сегмента файла.
* `cache_hits` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество попаданий в кэш для соответствующего сегмента файла
* `references` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество ссылок на соответствующий сегмент файла. Значение 1 означает, что в данный момент его никто не использует (единственная существующая ссылка находится в самом хранилище кэша)
* `downloaded_size` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер загруженной части сегмента файла
* `kind` ([String](/ru/sql-reference/data-types/string)) — Вид сегмента файла (используется для различения сегментов файла, добавленных как часть &#39;Temporary data in cache&#39;)
* `unbound` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Внутренний флаг реализации
* `user_id` ([String](/ru/sql-reference/data-types/string)) — Идентификатор пользователя, создавшего сегмент файла
* `segment_type` ([String](/ru/sql-reference/data-types/string)) — Тип сегмента. Используется для разделения файлов данных (`.json`, `.txt` и т. д.) и файлов данных (`.bin`, mark files).
* `file_size` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Размер файла, которому принадлежит текущий сегмент файла
