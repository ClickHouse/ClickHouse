<div id="description">
  ## Описание
</div>

Содержит информацию о [распределённых DDL-запросах (предложение ON CLUSTER)](../../sql-reference/distributed-ddl.md), которые были выполнены на кластере.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `entry` ([String](/ru/sql-reference/data-types/string)) — Query id.
* `entry_version` ([Nullable(UInt8)](/ru/sql-reference/data-types/nullable)) — Версия записи.
* `initiator_host` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Хост, инициировавший операцию DDL.
* `initiator_port` ([Nullable(UInt16)](/ru/sql-reference/data-types/nullable)) — Порт, используемый инициатором.
* `cluster` ([String](/ru/sql-reference/data-types/string)) — Имя кластера; пусто, если не определено.
* `query` ([String](/ru/sql-reference/data-types/string)) — Выполненный запрос.
* `settings` ([Map(String, String)](/ru/sql-reference/data-types/map)) — Настройки, использованные в операции DDL.
* `query_create_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время создания запроса.
* `host` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Имя хоста.
* `port` ([Nullable(UInt16)](/ru/sql-reference/data-types/nullable)) — Порт хоста.
* `status` ([Nullable(Enum8(&#39;Inactive&#39; = 0, &#39;Active&#39; = 1, &#39;Finished&#39; = 2, &#39;Removing&#39; = 3, &#39;Unknown&#39; = 4))](/ru/sql-reference/data-types/nullable)) — Статус запроса.
* `exception_code` ([Nullable(UInt16)](/ru/sql-reference/data-types/nullable)) — Код исключения.
* `exception_text` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Сообщение об исключении.
* `query_finish_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время завершения запроса.
* `query_duration_ms` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Длительность выполнения запроса (в миллисекундах).

{/*AUTOGENERATED_END*/ }
