<div id="description">
  ## Описание
</div>

Содержит фильтры для конкретной таблицы, а также список ролей и/или пользователей, к которым должна применяться эта ROW POLICY.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя ROW POLICY.
* `short_name` ([String](/ru/sql-reference/data-types/string)) — Краткое имя ROW POLICY. Имена ROW POLICY являются составными, например: myfilter ON mydb.mytable. Здесь &#39;myfilter ON mydb.mytable&#39; — это имя ROW POLICY, а &#39;myfilter&#39; — её краткое имя.
* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы. Пусто, если политика задана для базы данных.
* `id` ([UUID](/ru/sql-reference/data-types/uuid)) — Идентификатор ROW POLICY.
* `storage` ([String](/ru/sql-reference/data-types/string)) — Имя каталога, в котором хранится ROW POLICY.
* `select_filter` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Выражение, используемое для фильтрации в запросах SELECT.
* `is_restrictive` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, ограничивает ли ROW POLICY доступ к строкам. Значения: • 0 — ROW POLICY определена с предложением `AS PERMISSIVE`, • 1 — ROW POLICY определена с предложением `AS RESTRICTIVE`.
* `apply_to_all` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, что ROW POLICY заданы для всех ролей и/или пользователей.
* `apply_to_list` ([Array(String)](/ru/sql-reference/data-types/array)) — Список ролей и/или пользователей, к которым применяются ROW POLICY.
* `apply_to_except` ([Array(String)](/ru/sql-reference/data-types/array)) — ROW POLICY применяются ко всем ролям и/или пользователям, кроме перечисленных.

{/*AUTOGENERATED_END*/ }
