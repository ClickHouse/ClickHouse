<div id="description">
  ## Описание
</div>

Содержит информацию о настройках таблиц [AzureQueue](../../engines/table-engines/integrations/azure-queue.md).
Доступно начиная с версии сервера `24.10`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — База данных таблицы, использующей движок AzureQueue.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы, использующей движок AzureQueue.
* `name` ([String](/ru/sql-reference/data-types/string)) — Имя настройки.
* `value` ([String](/ru/sql-reference/data-types/string)) — Значение настройки.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип настройки (строковое значение, зависящее от реализации).
* `changed` ([UInt8](/ru/sql-reference/data-types/int-uint)) — 1, если настройка была явно задана в конфигурации или явно изменена.
* `description` ([String](/ru/sql-reference/data-types/string)) — Описание настройки.
* `alterable` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Показывает, может ли текущий пользователь изменить настройку с помощью ALTER TABLE MODIFY SETTING: 0 — текущий пользователь не может изменить настройку, 1 — текущий пользователь может изменить настройку.

{/*AUTOGENERATED_END*/ }
