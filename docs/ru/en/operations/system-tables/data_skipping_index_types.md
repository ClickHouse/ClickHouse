<div id="description">
  ## Описание
</div>

Содержит список типов индексов пропуска данных, поддерживаемых сервером, а также встроенную документацию для каждого типа. Тип индекса пропуска данных указывается в `TYPE` при объявлении `INDEX` в запросе `CREATE TABLE` и позволяет ClickHouse пропускать гранулы, которые не могут удовлетворять условию запроса.

Обратите внимание, что в этой таблице перечислены доступные *типы* индексов, тогда как [`system.data_skipping_indices`](/ru/operations/system-tables/data_skipping_indices) содержит экземпляры индексов, определённые в существующих таблицах.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя типа индекса пропуска данных, указанное в TYPE при объявлении INDEX.
* `description` ([String](/ru/sql-reference/data-types/string)) — Общее описание того, что делает этот тип индекса пропуска данных.
* `syntax` ([String](/ru/sql-reference/data-types/string)) — Как индекс объявляется в предложении INDEX запроса CREATE TABLE.
* `examples` ([String](/ru/sql-reference/data-types/string)) — Примеры использования.
* `introduced_in` ([String](/ru/sql-reference/data-types/string)) — Версия ClickHouse, в которой этот тип индекса впервые появился, в формате major.minor.
* `related` ([Array](/ru/sql-reference/data-types/array)([String](/ru/sql-reference/data-types/string))) — Названия связанных типов индексов пропуска данных.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

```sql title="Query"
SELECT name, syntax
FROM system.data_skipping_index_types
WHERE name IN ('minmax', 'set')
ORDER BY name
```

```text title="Response"
┌─name───┬─syntax───────────────────────────────────────┐
│ minmax │ INDEX name expr TYPE minmax GRANULARITY n     │
│ set    │ INDEX name expr TYPE set(max_rows) GRANULARITY n │
└────────┴──────────────────────────────────────────────┘
```
