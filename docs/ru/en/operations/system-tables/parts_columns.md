<div id="description">
  ## Описание
</div>

Содержит сведения о частях и столбцах таблиц [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md).
Каждая строка описывает одну часть данных.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/ru/sql-reference/data-types/string)) — Имя партиции.
* `name` ([String](/ru/sql-reference/data-types/string)) — Имя части данных.
* `uuid` ([UUID](/ru/sql-reference/data-types/uuid)) — UUID части данных.
* `part_type` ([String](/ru/sql-reference/data-types/string)) — Формат хранения части данных. Возможные значения: Wide — каждый столбец хранится в отдельном файле в файловой системе, Compact — все столбцы хранятся в одном файле в файловой системе.
* `active` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Флаг, указывающий, активна ли часть данных. Если часть данных активна, она используется в таблице. В противном случае она удаляется. Неактивные части данных остаются после слияния.
* `marks` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество marks. Чтобы получить приблизительное количество строк в части данных, умножьте marks на гранулярность индекса (обычно 8192) (эта подсказка не работает для адаптивной гранулярности).
* `rows` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество строк.
* `bytes_on_disk` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер всех файлов части данных в байтах.
* `data_compressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер сжатых данных в части данных. Все вспомогательные файлы (например, файлы с marks) не включены.
* `data_uncompressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер несжатых данных в части данных. Все вспомогательные файлы (например, файлы с marks) не включены.
* `marks_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер файла с marks.
* `modification_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время изменения каталога с частью данных. Обычно это соответствует времени создания части данных.
* `remove_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время, когда часть данных стала неактивной.
* `refcount` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Количество мест, где используется часть данных. Значение больше 2 указывает на то, что часть данных используется в запросах или слияниях.
* `min_date` ([Date](/ru/sql-reference/data-types/date)) — Минимальное значение для столбца Date, если он входит в ключ партиционирования.
* `max_date` ([Date](/ru/sql-reference/data-types/date)) — Максимальное значение для столбца Date, если он входит в ключ партиционирования.
* `min_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Минимальное значение для столбца DateTime, если он входит в ключ партиционирования.
* `max_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Максимальное значение для столбца DateTime, если он входит в ключ партиционирования.
* `partition_id` ([String](/ru/sql-reference/data-types/string)) — ID партиции.
* `min_block_number` ([Int64](/ru/sql-reference/data-types/int-uint)) — Минимальный номер части данных, из которых после слияния была образована текущая часть.
* `max_block_number` ([Int64](/ru/sql-reference/data-types/int-uint)) — Максимальный номер части данных, из которых после слияния была образована текущая часть.
* `level` ([UInt32](/ru/sql-reference/data-types/int-uint)) — Глубина дерева слияния. Ноль означает, что текущая часть была создана вставкой, а не слиянием других частей.
* `data_version` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Номер, используемый для определения того, какие мутации должны быть применены к части данных (мутации с версией выше, чем data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объём памяти (в байтах), используемый значениями первичного ключа.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Объём памяти (в байтах), зарезервированный для значений первичного ключа.
* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `engine` ([String](/ru/sql-reference/data-types/string)) — Имя движка таблицы без параметров.
* `disk_name` ([String](/ru/sql-reference/data-types/string)) — Имя диска, на котором хранится часть данных.
* `path` ([String](/ru/sql-reference/data-types/string)) — Абсолютный путь к папке с файлами части данных.
* `column` ([String](/ru/sql-reference/data-types/string)) — Имя столбца.
* `type` ([String](/ru/sql-reference/data-types/string)) — Тип столбца.
* `column_position` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Порядковая позиция столбца в таблице, начиная с 1.
* `default_kind` ([String](/ru/sql-reference/data-types/string)) — Тип выражения (DEFAULT, MATERIALIZED, ALIAS) для значения по умолчанию или пустая строка, если он не задан.
* `default_expression` ([String](/ru/sql-reference/data-types/string)) — Выражение для значения по умолчанию или пустая строка, если оно не задано.
* `column_bytes_on_disk` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер столбца в байтах.
* `column_data_compressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер сжатых данных в столбце в байтах.
* `column_data_uncompressed_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер распакованных данных в столбце в байтах.
* `column_marks_bytes` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Размер меток столбца в байтах.
* `column_modification_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время последнего изменения столбца.
* `column_ttl_min` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Минимальное значение вычисленного TTL-выражения столбца.
* `column_ttl_max` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Максимальное значение вычисленного TTL-выражения столбца.
* `statistics` ([Array(String)](/ru/sql-reference/data-types/array)) — Статистика столбца.
* `estimates.min` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Оценочное минимальное значение столбца.
* `estimates.max` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Оценочное максимальное значение столбца.
* `estimates.cardinality` ([Nullable(UInt64)](/ru/sql-reference/data-types/nullable)) — Оценочная мощность столбца.
* `serialization_kind` ([String](/ru/sql-reference/data-types/string)) — Вид сериализации столбца
* `substreams` ([Array(String)](/ru/sql-reference/data-types/array)) — Имена подпотоков, в которые сериализуется столбец
* `filenames` ([Array(String)](/ru/sql-reference/data-types/array)) — Имена файлов для каждого подпотока столбца соответственно
* `subcolumns.names` ([Array(String)](/ru/sql-reference/data-types/array)) — Имена подстолбцов столбца
* `subcolumns.types` ([Array(String)](/ru/sql-reference/data-types/array)) — Типы подстолбцов столбца
* `subcolumns.serializations` ([Array(String)](/ru/sql-reference/data-types/array)) — Типы сериализации подстолбцов столбца
* `subcolumns.bytes_on_disk` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Размеры каждого подстолбца в байтах
* `subcolumns.data_compressed_bytes` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Размеры сжатых данных каждого подстолбца в байтах
* `subcolumns.data_uncompressed_bytes` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Размеры несжатых данных каждого подстолбца в байтах
* `subcolumns.marks_bytes` ([Array(UInt64)](/ru/sql-reference/data-types/array)) — Размеры меток каждого подстолбца столбца в байтах

**Псевдонимы:**

* `bytes` — псевдоним для `bytes_on_disk`.
* `marks_size` — псевдоним для `marks_bytes`.
* `part_name` — псевдоним для `name`.
