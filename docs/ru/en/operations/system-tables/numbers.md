<div id="description">
  ## Описание
</div>

Эта таблица содержит единственный столбец `number` типа UInt64, в котором содержатся почти все натуральные числа, начиная с нуля.

Эту таблицу можно использовать для тестов или если вам нужно выполнить поиск полным перебором.

Чтение из этой таблицы не распараллеливается.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `number` ([UInt64](/ru/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }
