<div id="description">
  ## Описание
</div>

Содержит сведения о доступных сертификатах и их источниках.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `version` ([Int32](/ru/sql-reference/data-types/int-uint)) — Версия сертификата. Значения: 0 для v1, 1 для v2, 2 для v3.
* `serial_number` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Серийный номер сертификата, присвоенный издателем.
* `signature_algo` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Алгоритм подписи — алгоритм, который издатель использовал для подписи этого сертификата.
* `issuer` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Издатель — уникальный идентификатор удостоверяющего центра, выдавшего этот сертификат.
* `not_before` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Начало периода времени, в течение которого этот сертификат действителен.
* `not_after` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Конец периода времени, в течение которого этот сертификат действителен.
* `subject` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Субъект — идентифицирует владельца открытого ключа.
* `pkey_algo` ([Nullable(String)](/ru/sql-reference/data-types/nullable)) — Алгоритм открытого ключа определяет, с каким алгоритмом может использоваться открытый ключ.
* `path` ([String](/ru/sql-reference/data-types/string)) — Путь к файлу или каталогу, содержащему этот сертификат.
* `default` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Сертификат находится в стандартном расположении сертификатов.
* `protocol` ([String](/ru/sql-reference/data-types/string)) — Имя протокола, если сертификат взят из TLS-конфигурации для конкретного протокола; в противном случае пусто.

{/*AUTOGENERATED_END*/ }
