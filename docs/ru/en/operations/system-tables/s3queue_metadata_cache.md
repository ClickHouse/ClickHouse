<div id="description">
  ## Описание
</div>

Содержит хранящееся в памяти состояние метаданных S3Queue и строки, обрабатываемые в данный момент для каждого файла.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/ru/sql-reference/data-types/string)) — Путь к метаданным в ZooKeeper
* `file_path` ([String](/ru/sql-reference/data-types/string)) — Путь к обрабатываемому файлу
* `file_name` ([String](/ru/sql-reference/data-types/string)) — Имя обрабатываемого файла
* `rows_processed` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Текущее количество обработанных строк
* `status` ([String](/ru/sql-reference/data-types/string)) — Статус обработки: Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время начала обработки файла
* `processing_end_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время окончания обработки файла
* `exception` ([String](/ru/sql-reference/data-types/string)) — Исключение, возникшее во время обработки

{/*AUTOGENERATED_END*/ }
