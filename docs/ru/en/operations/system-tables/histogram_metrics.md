<div id="description">
  ## Описание
</div>

В этой таблице содержатся метрики гистограммы, которые можно мгновенно вычислить и экспортировать в формате Prometheus. Она всегда содержит актуальные данные. Заменяет устаревшую `system.latency_log`.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/ru/sql-reference/data-types/string)) — имя метрики.
* `value` ([Float64](/ru/sql-reference/data-types/float)) — значение метрики.
* `description` ([String](/ru/sql-reference/data-types/string)) — описание метрики.
* `labels` ([Map(String, String)](/ru/sql-reference/data-types/map)) — метки метрик.

**Псевдонимы:**

* `name` — псевдоним `metric`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Пример
</div>

Вы можете использовать такой запрос, чтобы экспортировать все метрики гистограммы в формате Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'histogram' AS type
FROM system.histogram_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## Описание метрик
</div>

| Метрика                                                      | Описание                                                                                                                                 |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `keeper_response_time_ms_bucket`                             | Время ответа Keeper в миллисекундах.                                                                                                     |
| `keeper_client_queue_duration_milliseconds_bucket`           | Время, которое запросы тратят на ожидание постановки в очередь и пребывание в очереди перед обработкой клиентом Keeper, в миллисекундах. |
| `keeper_receive_request_time_milliseconds_bucket`            | Время на получение и разбор запроса от клиента в обработчике TCP Keeper, в миллисекундах.                                                |
| `keeper_dispatcher_requests_queue_time_milliseconds_bucket`  | Время, которое запрос проводит в очереди запросов диспетчера Keeper, в миллисекундах.                                                    |
| `keeper_write_pre_commit_time_milliseconds_bucket`           | Время на предварительную обработку запроса записи перед фиксацией в Raft, в миллисекундах.                                               |
| `keeper_write_commit_time_milliseconds_bucket`               | Время на обработку запроса записи после фиксации в Raft, в миллисекундах.                                                                |
| `keeper_dispatcher_responses_queue_time_milliseconds_bucket` | Время, которое ответ проводит в очереди ответов диспетчера Keeper, в миллисекундах.                                                      |
| `keeper_send_response_time_milliseconds_bucket`              | Время на отправку ответа клиенту в обработчике TCP Keeper (включая ожидание в очереди и запись в сокет), в миллисекундах.                |
| `keeper_read_wait_for_write_time_milliseconds_bucket`        | Время, в течение которого запрос чтения ждёт завершения зависящего от него запроса записи, в миллисекундах.                              |
| `keeper_read_process_time_milliseconds_bucket`               | Время на обработку запроса чтения в Keeper, в миллисекундах.                                                                             |
| `keeper_batch_size_elements_bucket`                          | Размер батча, отправляемого в Raft, в элементах.                                                                                         |
| `keeper_batch_size_bytes_bucket`                             | Размер батча, отправляемого в Raft, в байтах.                                                                                            |
| `filesystem_cache_evicted_segment_hits_bucket`               | Распределение числа попаданий в кэш для сегментов файла на момент их вытеснения, с меткой по имени кэша.                                 |
| `filesystem_cache_evicted_segment_size_bytes_bucket`         | Распределение размеров вытесненных сегментов файла в байтах, с меткой по имени кэша.                                                     |
| `filesystem_cache_evicted_segment_hits_by_user_bucket`       | Распределение числа попаданий в кэш для вытесненных сегментов файла, с метками по имени кэша и идентификатору пользователя.              |
| `filesystem_cache_evicted_segment_size_bytes_by_user_bucket` | Распределение размеров вытесненных сегментов файла в байтах, с метками по имени кэша и идентификатору пользователя.                      |
