<div id="description">
  ## Описание
</div>

Эта таблица отсутствует, если данный узел не настроен на запуск ClickHouse Keeper в том же процессе. Она содержит по одной строке для каждого файла журнала изменений Raft (`changelog_<from>_<to>.bin[.zstd]`), отслеживаемого встроенным хранилищем журналов Keeper, включая активный файл, в который сейчас дописываются данные.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `from_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Первый индекс журнала Raft в файле (включительно).
* `to_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Последний индекс журнала Raft, охватываемый именем файла (включительно). Для активного файла это целевое значение ротации, и оно может быть больше `last_entry_index`.
* `last_entry_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Наибольший индекс журнала, фактически дописанный в этот файл. `NULL`, если в активный файл ещё не было записано ни одной записи или файл повреждён.
* `entries` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Количество записей, дописанных в этот файл. `ALIAS` для `ifNull(last_entry_index - from_log_index + 1, 0)`.
* `path` ([String](../../sql-reference/data-types/string.md)) — Путь к файлу на диске.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Имя диска, на котором находится файл.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Размер файла на диске.
* `modification_time` ([дата и время](../../sql-reference/data-types/datetime.md)) — Время последнего изменения файла.
* `is_compressed` ([Bool](../../sql-reference/data-types/boolean.md)) — Полезная нагрузка файла сжата с помощью zstd.
* `active` ([Bool](../../sql-reference/data-types/boolean.md)) — В этот файл сейчас выполняется запись.
* `is_broken` ([Bool](../../sql-reference/data-types/boolean.md)) — При запуске обнаружена повреждённая конечная запись.

{/*AUTOGENERATED_END*/ }

Пример:

```sql
SELECT from_log_index, to_log_index, entries, path, active FROM system.keeper_changelogs ORDER BY from_log_index;
```

```text
┌─from_log_index─┬─to_log_index─┬─entries─┬─path───────────────────────────┬─active─┐
│              1 │         1000 │    1000 │ changelog_1_1000.bin.zstd      │ false  │
│           1001 │         2000 │     537 │ changelog_1001_2000.bin.zstd   │ true   │
└────────────────┴──────────────┴─────────┴────────────────────────────────┴────────┘
```
