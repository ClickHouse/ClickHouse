<div id="description">
  ## Описание
</div>

Содержит сведения о параметрах [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite), используемых в таблицах с движками [*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/ru/sql-reference/data-types/string)) — имя параметра graphite&#95;rollup.
* `rule_type` ([String](/ru/sql-reference/data-types/string)) — Тип правила. Возможные значения: RuleTypeAll = 0 — значение по умолчанию, с regex, совместимо со старой схемой; RuleTypePlain = 1 — обычные метрики, с regex, совместимо со старой схемой; RuleTypeTagged = 2 — метрики с тегами, с regex, совместимо со старой схемой; RuleTypeTagList = 3 — метрики с тегами, с regex (преобразуется в RuleTypeTagged из строки вида &#39;retention=10min ; env=(staging|prod)&#39;)
* `regexp` ([String](/ru/sql-reference/data-types/string)) — шаблон регулярного выражения для имени метрики.
* `function` ([String](/ru/sql-reference/data-types/string)) — имя агрегирующей функции.
* `age` ([UInt64](/ru/sql-reference/data-types/int-uint)) — минимальный возраст данных в секундах.
* `precision` ([UInt64](/ru/sql-reference/data-types/int-uint)) — насколько точно определяется возраст данных в секундах.
* `priority` ([UInt16](/ru/sql-reference/data-types/int-uint)) — приоритет шаблона.
* `is_default` ([UInt8](/ru/sql-reference/data-types/int-uint)) — является ли шаблон значением по умолчанию.
* `Tables.database` ([Array(String)](/ru/sql-reference/data-types/array)) — Массив имен баз данных для таблиц, использующих параметр `config_name`.
* `Tables.table` ([Array(String)](/ru/sql-reference/data-types/array)) — Массив имен таблиц, использующих параметр `config_name`.
