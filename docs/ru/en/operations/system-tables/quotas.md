<div id="description">
  ## Описание
</div>

Содержит сведения о [квотах](../../operations/system-tables/quotas.md).

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя квоты.
* `id` ([UUID](/ru/sql-reference/data-types/uuid)) — Идентификатор квоты.
* `storage` ([String](/ru/sql-reference/data-types/string)) — Хранилище квот. Возможные значения: &#39;users.xml&#39; — если квота настроена в файле users.xml, &#39;disk&#39; — если квота настроена SQL-запросом.
* `keys` ([Array(Enum8(&#39;user&#95;name&#39; = 1, &#39;ip&#95;address&#39; = 2, &#39;forwarded&#95;ip&#95;address&#39; = 3, &#39;client&#95;key&#39; = 4, &#39;normalized&#95;query&#95;hash&#39; = 7))](/ru/sql-reference/data-types/array)) — Ключ определяет, как должна разделяться квота. Если два соединения используют одну и ту же квоту и ключ, они совместно используют одинаковые объёмы ресурсов. Значения: [] — все пользователи совместно используют одну и ту же квоту, [&#39;user&#95;name&#39;] — соединения с одинаковым именем пользователя совместно используют одну и ту же квоту, [&#39;ip&#95;address&#39;] — соединения с одного и того же IP-адреса совместно используют одну и ту же квоту. [&#39;client&#95;key&#39;] — соединения с одинаковым ключом совместно используют одну и ту же квоту. Ключ должен быть явно передан клиентом. При использовании клиента ClickHouse передайте значение ключа в параметре --quota&#95;key или используйте параметр quota&#95;key в файле конфигурации клиента. При использовании HTTP-интерфейса используйте заголовок X-ClickHouse-Quota, [&#39;user&#95;name&#39;, &#39;client&#95;key&#39;] — соединения с одинаковым client&#95;key совместно используют одну и ту же квоту. Если ключ не передан клиентом, квота отслеживается для `user_name`, [&#39;client&#95;key&#39;, &#39;ip&#95;address&#39;] — соединения с одинаковым client&#95;key совместно используют одну и ту же квоту. Если ключ не передан клиентом, квота отслеживается для ip&#95;address.
* `durations` ([Array(UInt32)](/ru/sql-reference/data-types/array)) — Длины временных интервалов в секундах.
* `apply_to_all` ([UInt8](/ru/sql-reference/data-types/int-uint)) — Логическое значение. Показывает, к каким пользователям применяется квота. Значения: 0 — квота применяется к пользователям, указанным в apply&#95;to&#95;list. 1 — квота применяется ко всем пользователям, кроме перечисленных в apply&#95;to&#95;except.
* `apply_to_list` ([Array(String)](/ru/sql-reference/data-types/array)) — Список имён пользователей/ролей, к которым должна применяться квота.
* `apply_to_except` ([Array(String)](/ru/sql-reference/data-types/array)) — Список имён пользователей/ролей, к которым квота не должна применяться.
* `ipv4_prefix_bits` ([Nullable(UInt8)](/ru/sql-reference/data-types/nullable)) — Количество битов префикса для маскирования IPv4-адреса. Соединения из одной и той же подсети совместно используют одну и ту же квоту. Используется только тогда, когда key — `ip_address` или `forwarded_ip_address`.
* `ipv6_prefix_bits` ([Nullable(UInt8)](/ru/sql-reference/data-types/nullable)) — Количество битов префикса для маскирования IPv6-адреса. Соединения из одной и той же подсети совместно используют одну и ту же квоту. Используется только тогда, когда key — `ip_address` или `forwarded_ip_address`.
