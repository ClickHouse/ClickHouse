<div id="description">
  ## Описание
</div>

Содержит список всех именованных коллекций, которые были созданы SQL-запросом или получены при разборе файла конфигурации.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ru/sql-reference/data-types/string)) — Имя коллекции.
* `collection` ([Map(String, String)](/ru/sql-reference/data-types/map)) — Внутренние компоненты коллекции.
* `source` ([String](/ru/sql-reference/data-types/string)) — Источник именованной коллекции.
* `create_query` ([String](/ru/sql-reference/data-types/string)) — Запрос CREATE для именованной коллекции.
