<div id="description">
  ## Описание
</div>

Содержит информацию о слияниях и мутациях частей, выполняемых в данный момент для таблиц семейства MergeTree.

<div id="columns">
  ## Столбцы
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных, в которой находится таблица.
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы.
* `elapsed` ([Float64](/ru/sql-reference/data-types/float)) — Время, прошедшее с начала слияния (в секундах).
* `progress` ([Float64](/ru/sql-reference/data-types/float)) — Доля выполненной работы от 0 до 1.
* `num_parts` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество частей для слияния.
* `source_part_names` ([Array(String)](/ru/sql-reference/data-types/array)) — Список имён исходных частей.
* `result_part_name` ([String](/ru/sql-reference/data-types/string)) — Имя части, которая будет сформирована в результате слияния.
* `source_part_paths` ([Array(String)](/ru/sql-reference/data-types/array)) — Список путей для каждой исходной части.
* `result_part_path` ([String](/ru/sql-reference/data-types/string)) — Путь к части, которая будет сформирована в результате слияния.
* `partition_id` ([String](/ru/sql-reference/data-types/string)) — Идентификатор партиции, в которой происходит слияние.
* `partition` ([String](/ru/sql-reference/data-types/string)) — Имя партиции
* `is_mutation` ([UInt8](/ru/sql-reference/data-types/int-uint)) — 1, если этот процесс является мутацией части.
* `total_size_bytes_compressed` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер сжатых данных в слитых фрагментах.
* `total_size_bytes_uncompressed` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общий размер несжатых данных в слитых фрагментах.
* `total_size_marks` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Общее количество marks в слитых частях.
* `bytes_read_uncompressed` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество прочитанных байтов в несжатом виде.
* `rows_read` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество прочитанных строк.
* `bytes_written_uncompressed` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество записанных байтов в несжатом виде.
* `rows_written` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество записанных строк.
* `columns_written` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество записанных столбцов (для алгоритма Вертикального слияния).
* `memory_usage` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Использование памяти процессом слияния.
* `thread_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — ID потока процесса слияния.
* `merge_type` ([String](/ru/sql-reference/data-types/string)) — Тип текущего слияния. Пусто, если это мутация.
* `merge_algorithm` ([String](/ru/sql-reference/data-types/string)) — Алгоритм, используемый в текущем слиянии. Пусто, если это мутация.

{/*AUTOGENERATED_END*/ }
