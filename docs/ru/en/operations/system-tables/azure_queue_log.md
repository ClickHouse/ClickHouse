Содержит записи журнала с информацией о файлах, обработанных движком AzureQueue.

Таблицу можно безопасно очистить командой TRUNCATE или удалить в любой момент.

Столбцы:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ru/sql-reference/data-types/lowcardinality)) — Имя хоста
* `event_date` ([Date](/ru/sql-reference/data-types/date)) — Дата записи этой строки лога
* `event_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время записи этой строки лога
* `database` ([String](/ru/sql-reference/data-types/string)) — Имя базы данных, в которой находится таблица очереди (`S3Queue` или `AzureQueue`).
* `table` ([String](/ru/sql-reference/data-types/string)) — Имя таблицы очереди (`S3Queue` или `AzureQueue`).
* `uuid` ([String](/ru/sql-reference/data-types/string)) — UUID таблицы очереди (`S3Queue` или `AzureQueue`).
* `file_name` ([String](/ru/sql-reference/data-types/string)) — Имя обрабатываемого файла.
* `rows_processed` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Количество обработанных строк.
* `status` ([Enum8(&#39;Processed&#39; = 0, &#39;Failed&#39; = 1)](/ru/sql-reference/data-types/enum)) — Статус обрабатываемого файла.
* `processing_start_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время начала обработки файла.
* `processing_end_time` ([Nullable(DateTime)](/ru/sql-reference/data-types/nullable)) — Время окончания обработки файла.
* `exception` ([String](/ru/sql-reference/data-types/string)) — Сообщение об исключении, если оно возникло.
* `commit_id` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Идентификатор транзакции, в которой был выполнен коммит этого файла.
* `commit_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время коммита файла в Keeper (со статусом Failed или Processed).
* `transaction_start_time` ([DateTime](/ru/sql-reference/data-types/datetime)) — Время начала всей транзакции обработки.
* `get_object_time_ms` ([UInt64](/ru/sql-reference/data-types/int-uint)) — Время, потребовавшееся для поиска объекта в объектном хранилище.
