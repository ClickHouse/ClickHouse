<div id="overview">
  ## Обзор
</div>

:::note
Профили настроек на основе XML и [файлы конфигурации](/ru/operations/configuration-files) в настоящее время не
поддерживаются в ClickHouse Cloud. Чтобы задать настройки для вашего
сервиса ClickHouse Cloud, необходимо использовать [профили настроек, управляемые с помощью SQL](/ru/operations/access-rights#settings-profiles-management).
:::

Существует несколько основных групп настроек ClickHouse:

* Глобальные настройки сервера
* Настройки сеанса
* Настройки запроса
* Настройки фоновых операций

Глобальные настройки применяются по умолчанию, если не переопределены на следующих уровнях. Настройки сеанса можно задать с помощью профилей, конфигурации пользователя и команд SET. Настройки запроса можно указать в предложении `SETTINGS`; они применяются к отдельным запросам. Настройки фоновых операций применяются к мутациям, слияниям и, возможно, другим операциям, выполняемым асинхронно в фоновом режиме.

<div id="see-non-default-settings">
  ## Просмотр настроек, отличающихся от значений по умолчанию
</div>

Чтобы посмотреть, какие настройки были изменены по сравнению со значениями по умолчанию, можно выполнить запрос к таблице
`system.settings`:

```sql
SELECT name, value FROM system.settings WHERE changed
```

Если ни один параметр не отличается от значения по умолчанию, ClickHouse
ничего не вернёт.

Чтобы проверить значение конкретного параметра, можно указать `name`
параметра в запросе:

```sql
SELECT name, value FROM system.settings WHERE name = 'max_threads'
```

Результат будет примерно таким:

```response
┌─name────────┬─value───┐
│ max_threads │ auto(8) │
└─────────────┴─────────┘

1 row in set. Elapsed: 0.002 sec.
```
