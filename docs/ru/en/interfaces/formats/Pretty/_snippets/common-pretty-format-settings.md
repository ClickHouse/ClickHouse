---
title: Общие настройки формата Pretty
---

{/* Примечание: этот файл используется как фрагмент во всех файлах, где он импортируется */ }

Следующие настройки являются общими для всех форматов `Pretty`:

| Настройка                                                                                                                                                          | Описание                                                                                                                                                                                                                                                 | По умолчанию |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [`output_format_pretty_max_rows`](/ru/operations/settings/settings-formats.md/#output_format_pretty_max_rows)                                                         | Ограничение на количество строк для форматов Pretty.                                                                                                                                                                                                     | `10000`      |
| [`output_format_pretty_max_column_pad_width`](/ru/operations/settings/settings-formats.md/#output_format_pretty_max_column_pad_width)                                 | Максимальная ширина выравнивания для всех значений в столбце в форматах Pretty.                                                                                                                                                                          | `250`        |
| [`output_format_pretty_max_value_width`](/ru/operations/settings/settings-formats.md/#output_format_pretty_max_value_width)                                           | Максимальная ширина значения, отображаемого в форматах Pretty. Если значение превышает её, оно будет обрезано.                                                                                                                                           | `10000`      |
| [`output_format_pretty_color`](/ru/operations/settings/settings-formats.md/#output_format_pretty_color)                                                               | Использовать ANSI-последовательности экранирования для цветного вывода в форматах Pretty.                                                                                                                                                                | `true`       |
| [`output_format_pretty_grid_charset`](/ru/operations/settings/settings-formats.md/#output_format_pretty_grid_charset)                                                 | Набор символов для вывода границ таблицы. Доступные наборы символов: ASCII, UTF-8.                                                                                                                                                                       | `UTF-8`      |
| [`output_format_pretty_row_numbers`](/ru/operations/settings/settings-formats.md/#output_format_pretty_row_numbers)                                                   | Добавлять номера строк перед каждой строкой в формате вывода Pretty.                                                                                                                                                                                     | `true`       |
| [`output_format_pretty_display_footer_column_names`](/ru/operations/settings/settings-formats.md/#output_format_pretty_display_footer_column_names)                   | Показывать имена столбцов в нижнем колонтитуле, если таблица содержит много строк.                                                                                                                                                                       | `true`       |
| [`output_format_pretty_display_footer_column_names_min_rows`](/ru/operations/settings/settings-formats.md/#output_format_pretty_display_footer_column_names_min_rows) | Задает минимальное количество строк, при котором отображается нижний колонтитул, если включен параметр [`output_format_pretty_display_footer_column_names`](/ru/operations/settings/settings-formats.md/#output_format_pretty_display_footer_column_names). | `50`         |
