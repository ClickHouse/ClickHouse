<div id="description">
  ## Описание
</div>

Похож на формат [`RowBinaryWithNamesAndTypes`](./RowBinaryWithNamesAndTypes.md), но перед каждой ячейкой добавляется дополнительный байт, который указывает, следует ли использовать значение `DEFAULT` для столбца, — точно так же, как в формате [`RowBinaryWithDefaults`](./RowBinaryWithDefaults.md). Такое сочетание поддерживает `INSERT` при изменении схемы: отправитель может опускать столбцы в заголовке (тогда для них используется `DEFAULT` целевого столбца), а для любого столбца, который всё же передаётся, можно помечать отдельные ячейки как «использовать `DEFAULT` столбца», не смешивая это с `NULL`.

Этот формат используется только для ввода.

<div id="wire-format">
  ## Формат передачи данных
</div>

Заголовок идентичен [`RowBinaryWithNamesAndTypes`](./RowBinaryWithNamesAndTypes.md):

1. `VarUInt` с количеством столбцов `N`.
2. `N` строк `String` с префиксом длины, содержащих имена столбцов.
3. `N` типов столбцов — либо текстовые имена, либо компактное двоичное кодирование; это определяется настройками `output_format_binary_encode_types_in_binary_format` / `input_format_binary_decode_types_in_binary_format`.

После заголовка каждая строка состоит из `N` ячеек. Для каждой ячейки:

* Один байт-маркер `UInt8`.
  * `0x01` — использовать выражение `DEFAULT` целевого столбца. Байты значения после этого не следуют.
  * `0x00` — далее следует значение, сериализованное с помощью сериализатора `RowBinary` для типа столбца. Для `Nullable(T)` байты значения начинаются с null-байта `Nullable` (`0` для non-NULL, `1` для NULL), затем идёт внутреннее значение, если оно не равно NULL.

<div id="defaults-vs-null">
  ## Значения по умолчанию и NULL
</div>

Маркер значения по умолчанию на уровне ячейки и встроенный `null-байт` типа `Nullable` независимы друг от друга. Столбец `Nullable(UInt32) DEFAULT 42` можно передавать в каждой строке тремя разными способами:

| Байты     | Смысл                                                          |
| --------- | -------------------------------------------------------------- |
| `01`      | Использовать `DEFAULT 42`.                                     |
| `00 01`   | Ветка значения, затем `NULL` через тип `Nullable`.             |
| `00 00 …` | Ветка значения, затем внутреннее значение, отличное от `NULL`. |

<div id="schema-evolution">
  ## Изменение схемы
</div>

| Случай                                                                   | Поведение                                                                                                                                                                                                |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Столбец полностью отсутствует в заголовке файла                          | Заполняется в целевой таблице через `insertDefaultsForNotSeenColumns`; зависит от параметра `defaults_for_omitted_fields`.                                                                               |
| Столбец присутствует в заголовке, маркер ячейки `0x01`                   | `insertDefault` для каждой строки.                                                                                                                                                                       |
| Столбец присутствует в заголовке, маркер ячейки `0x00`                   | Значение разбирается обычным образом.                                                                                                                                                                    |
| В заголовке есть дополнительный столбец, отсутствующий в целевой таблице | Молча отбрасывается при `input_format_skip_unknown_fields = 1` (сначала считывается маркер; если `0x01`, больше ничего не происходит; если `0x00`, типизированное значение разбирается и отбрасывается). |

<div id="example-usage">
  ## Пример использования
</div>

```sql title="Query"
SELECT * FROM format(
    'RowBinaryWithNamesAndTypesAndDefaults',
    'x Nullable(UInt32) DEFAULT 42',
    unhex('01' || '0178' || '10' || hex('Nullable(UInt32)') || '01')
);
```

```response title="Response"
┌──x─┐
│ 42 │
└────┘
```

* Заголовок содержит один столбец с именем `x` типа `Nullable(UInt32)`.
* Единственная ячейка использует маркер `0x01`, что означает &quot;использовать `DEFAULT 42`&quot;.
