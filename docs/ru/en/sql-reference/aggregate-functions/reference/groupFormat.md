Форматирует строки в каждой группе в выходном формате и возвращает отформатированные данные в виде строки. Похожа на `formatRow`, но работает со всей группой и может использовать форматы, работающие с блоками.

:::warning
Все строки каждой группы накапливаются в памяти до формирования отформатированной строки. Для групп с очень большим количеством строк это может привести к значительному использованию памяти. Рассмотрите возможность использовать `LIMIT` внутри подзапросов или разбивать большие группы, чтобы контролировать использование памяти.
:::

<div id="syntax">
  ## Синтаксис
</div>

```sql
groupFormat(format)(x, y, ...)
```

<div id="parameters">
  ## Параметры
</div>

* `format` — Название выходного формата, например `JSONEachRow`, `CSV`, `TabSeparated`.

<div id="arguments">
  ## Аргументы
</div>

* `x, y, ...` — Выражения, которые нужно форматировать в виде строк. Требуется как минимум один аргумент.

<div id="returned-value">
  ## Возвращаемое значение
</div>

* Значение типа [String](../../data-types/string.md), содержащее отформатированный вывод для группы.

:::note
Имена столбцов в отформатированном выводе генерируются как `c1`, `c2`, ... в порядке аргументов.

Порядок отформатированных строк не гарантируется.

Настройки формата запроса (например, `format_csv_delimiter` или `output_format_json_quote_64bit_integers`) фиксируются при инициализации агрегатной функции и затем используются для формирования вывода. Настройка `output_format_write_statistics` всегда принудительно отключается, поэтому отформатированная строка никогда не содержит раздела статистики.
:::

<div id="null-handling">
  ## Обработка NULL
</div>

Как и `groupArray` и `groupConcat`, `groupFormat` пропускает строку, если хотя бы один из его аргументов равен `NULL`; такие строки не попадают в форматированный вывод. Если аргумент имеет тип Nullable, результирующий тип — `Nullable(String)`, а группа, в которой пропущены все строки, — так же как и нетипизированный literal `NULL` аргумента типа `Nullable(Nothing)` — возвращает `NULL` через универсальный комбинатор `Null`.

```sql
SELECT groupFormat('JSONEachRow')(if(number = 0, NULL, number))
FROM numbers(3);
-- {"c1":1}
-- {"c1":2}
```

<div id="examples">
  ## Примеры
</div>

<div id="example-json">
  ### Базовое использование с JSONEachRow
</div>

```sql
SELECT groupFormat('JSONEachRow')(number, toString(number))
FROM numbers(3);
```

Результат:

```text
{"c1":0,"c2":"0"}
{"c1":1,"c2":"1"}
{"c1":2,"c2":"2"}
```
