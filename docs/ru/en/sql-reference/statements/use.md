```sql
USE [DATABASE] db
```

Позволяет задать текущую базу данных для сеанса.

Текущая база данных используется при поиске таблиц, если база данных не указана явно в запросе через точку перед именем таблицы.

Этот запрос нельзя выполнить при использовании HTTP-протокола, поскольку в нём отсутствует понятие сеанса.
