Пример настроек:

<Tabs>
  <TabItem value="ddl" label="DDL" default>
    ```sql
    SOURCE(REDIS(
        host 'localhost'
        port 6379
        storage_type 'simple'
        db_index 0
    ))
    ```
  </TabItem>

  <TabItem value="xml" label="Файл конфигурации">
    ```xml
    <source>
        <redis>
            <host>localhost</host>
            <port>6379</port>
            <storage_type>simple</storage_type>
            <db_index>0</db_index>
        </redis>
    </source>
    ```
  </TabItem>
</Tabs>

<br />

Поля настроек:

| Настройка      | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `host`         | Хост Redis.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `port`         | Порт сервера Redis.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `storage_type` | Структура внутреннего хранилища Redis, используемого для работы с ключами. `simple` использует простую плоскую структуру ключ-значение и поддерживает структуры simple-key, а также структуры complex-key с одним столбцом (например, `complex_key_cache` и `complex_key_direct`). `hash_map` использует хеш Redis и требуется для составных complex-key; при этом ожидается ровно два столбца ключа. Столбцы ключа должны иметь целочисленный или строковый тип. Структуры с диапазонами не поддерживаются. Значение по умолчанию — `simple`. Необязательно. |
| `db_index`     | Числовой индекс логической базы данных Redis. Значение по умолчанию — `0`. Необязательно.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
