---
title: "Фрагмент: словари в Cloud"
---

:::tip
Если вы используете словарь с ClickHouse Cloud, для создания словарей используйте опцию DDL-запроса и создавайте словарь от имени пользователя `default`.
Также проверьте список поддерживаемых источников словарей в [руководстве по совместимости с Cloud](/ru/whats-new/cloud-compatibility).
:::
