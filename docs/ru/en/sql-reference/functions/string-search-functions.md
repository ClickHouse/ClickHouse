Все функции в этом разделе по умолчанию выполняют поиск с учетом регистра. Для регистронезависимого поиска обычно предусмотрены отдельные варианты функций.

:::note
Регистронезависимый поиск следует правилам преобразования в нижний и верхний регистр английского языка. Например, прописная `i` в английском языке — это
`I`, тогда как в турецком — `İ`; для языков, отличных от английского, результаты могут быть неожиданными.
:::

Функции в этом разделе также предполагают, что строка, в которой выполняется поиск (в этом разделе обозначается как `haystack`), и поисковая строка (в этом разделе обозначается как `needle`) представляют собой текст в однобайтовой кодировке. Если это предположение
нарушено, исключение не генерируется, а результаты не определены. Поиск по строкам в кодировке UTF-8 обычно реализован в отдельных вариантах
функций. Аналогично, если используется вариант функции для UTF-8, а входные строки не являются текстом в кодировке UTF-8, исключение не генерируется, а
результаты не определены. Обратите внимание, что автоматическая нормализация Unicode не выполняется, однако для этого можно использовать
функции [normalizeUTF8*()](/ru/sql-reference/functions/string-functions#normalizeUTF8NFC).

[Общие строковые функции](string-functions.md) и [функции замены в строках](string-replace-functions.md) описаны отдельно.
