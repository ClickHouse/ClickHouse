Эти функции реализуют шифрование и расшифровку данных с помощью алгоритма AES (Advanced Encryption Standard).

Длина ключа зависит от режима шифрования: `16`, `24` и `32` байта для режимов `-128-`, `-196-` и `-256-` соответственно.

Длина вектора инициализации всегда равна 16 байтам (байты сверх 16 игнорируются).
