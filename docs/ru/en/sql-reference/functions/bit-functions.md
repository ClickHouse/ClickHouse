Битовые функции работают с любой парой типов из `UInt8`, `UInt16`, `UInt32`, `UInt64`, `Int8`, `Int16`, `Int32`, `Int64`, `Float32` или `Float64`. Некоторые функции также поддерживают типы `String` и `FixedString`.

Тип результата — целое число с количеством битов, равным максимальному количеству битов среди аргументов. Если хотя бы один из аргументов является знаковым, результат также будет знаковым числом. Если аргумент является числом с плавающей запятой, он приводится к Int64.
