Создает временную таблицу [Merge](../../engines/table-engines/special/merge.md).
Схема таблицы выводится из базовых таблиц с использованием объединения их столбцов и определения общих типов.
Доступны те же виртуальные столбцы, что и для движка таблицы [Merge](../../engines/table-engines/special/merge.md).

<div id="syntax">
  ## Синтаксис
</div>

```sql
merge(['db_name',] 'tables_regexp')
```

<div id="arguments">
  ## Аргументы
</div>

| Аргумент        | Описание                                                                                                                                                                                                                                                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | Возможные значения (необязательно, по умолчанию — `currentDatabase()`):<br />    - имя базы данных,<br />    - константное выражение, возвращающее строку с именем базы данных, например `currentDatabase()`,<br />    - `REGEXP(expression)`, где `expression` — регулярное выражение для сопоставления имён баз данных. |
| `tables_regexp` | Регулярное выражение для сопоставления имён таблиц в указанной базе данных или базах данных.                                                                                                                                                                                                                              |
