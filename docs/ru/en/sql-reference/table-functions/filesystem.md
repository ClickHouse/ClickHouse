<div id="filesystem-table-function">
  # Табличная функция filesystem
</div>

<CloudNotSupportedBadge />

Рекурсивно обходит каталог и возвращает таблицу с метаданными файлов (пути, размеры, типы, разрешения, время последнего изменения) и, при необходимости, содержимым файлов.

В режиме `clickhouse-server` путь должен находиться в каталоге [user&#95;files&#95;path](/ru/operations/server-configuration-parameters/settings.md#user_files_path). Символические ссылки внутри `user_files_path`, указывающие за его пределы, отслеживаются, но возвращаются только те записи, путь к которым (через символическую ссылку) начинается с `user_files_path`.

В режиме `clickhouse-local` ограничений на пути нет.

<div id="syntax">
  ## Синтаксис
</div>

```sql
filesystem([path])
```

<div id="arguments">
  ## Аргументы
</div>

| Параметр | Описание                                                                                                                                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `path`   | Каталог, содержимое которого нужно вывести списком. Может быть абсолютным путём (в режиме сервера должен находиться внутри `user_files_path`) или путём относительно `user_files_path`. Если пуст или не указан, по умолчанию используется `user_files_path`. |

<div id="returned_columns">
  ## Возвращаемые столбцы
</div>

| Столбец             | Type                       | Описание                                                                                                                                                                                                                                                                  |
| ------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `path`              | `String`                   | Каталог, содержащий элемент (без имени самого файла или каталога).                                                                                                                                                                                                        |
| `name`              | `String`                   | Имя файла или каталога (последний компонент пути).                                                                                                                                                                                                                        |
| `file`              | `String` (ALIAS of `name`) | Псевдоним столбца `name`.                                                                                                                                                                                                                                                 |
| `type`              | `Enum8`                    | Тип файла: `'none'`, `'not_found'`, `'regular'`, `'directory'`, `'symlink'`, `'block'`, `'character'`, `'fifo'`, `'socket'`, `'unknown'`.                                                                                                                                 |
| `size`              | `Nullable(UInt64)`         | Размер файла в байтах (для обычных файлов). `NULL` для файлов, не являющихся обычными (каталогов, символических ссылок и т. д.), а также при ошибке.                                                                                                                    |
| `depth`             | `UInt16`                   | Глубина рекурсии. `0` — для самого запрошенного каталога и его непосредственных дочерних элементов, `1` — для элементов на один уровень глубже, и так далее.                                                                                                              |
| `modification_time` | `Nullable(DateTime64(6))`  | Время последнего изменения с точностью до микросекунды. `NULL` при ошибке.                                                                                                                                                                                                |
| `is_symlink`        | `Bool`                     | Является ли элемент символической ссылкой.                                                                                                                                                                                                                                |
| `content`           | `Nullable(String)`         | Содержимое файла (для обычных файлов). `NULL` для файлов, не являющихся обычными (каталогов, символических ссылок и т. д.). Ошибки чтения приводят к исключению. Чтение этого столбца запускает фактический файловый ввод-вывод, поэтому не выбирайте его без необходимости. |
| `owner_read`        | `Bool`                     | У владельца есть разрешение на чтение.                                                                                                                                                                                                                                    |
| `owner_write`       | `Bool`                     | У владельца есть разрешение на запись.                                                                                                                                                                                                                                    |
| `owner_exec`        | `Bool`                     | У владельца есть разрешение на выполнение.                                                                                                                                                                                                                                |
| `group_read`        | `Bool`                     | У группы есть разрешение на чтение.                                                                                                                                                                                                                                       |
| `group_write`       | `Bool`                     | У группы есть разрешение на запись.                                                                                                                                                                                                                                       |
| `group_exec`        | `Bool`                     | У группы есть разрешение на выполнение.                                                                                                                                                                                                                                   |
| `others_read`       | `Bool`                     | У остальных есть разрешение на чтение.                                                                                                                                                                                                                                    |
| `others_write`      | `Bool`                     | У остальных есть разрешение на запись.                                                                                                                                                                                                                                    |
| `others_exec`       | `Bool`                     | У остальных есть разрешение на выполнение.                                                                                                                                                                                                                                |
| `set_gid`           | `Bool`                     | Бит Set-GID.                                                                                                                                                                                                                                                              |
| `set_uid`           | `Bool`                     | Бит Set-UID.                                                                                                                                                                                                                                                              |
| `sticky_bit`        | `Bool`                     | Sticky-бит.                                                                                                                                                                                                                                                               |

Вычисляются только те столбцы, которые фактически используются в запросе, поэтому выбор подмножества столбцов (особенно без `content`) работает эффективно.

<div id="examples">
  ## Примеры
</div>

<div id="list-files">
  ### Список файлов в user_files
</div>

```sql
SELECT name, type, size, depth
FROM filesystem()
ORDER BY name;
```

<div id="find-large-files">
  ### Поиск больших файлов
</div>

```sql
SELECT path, name, size
FROM filesystem()
WHERE type = 'regular' AND size > 1000000
ORDER BY size DESC;
```

<div id="read-contents">
  ### Прочитать содержимое файла
</div>

```sql
SELECT name, content
FROM filesystem('my_directory')
WHERE name LIKE '%.csv';
```

<div id="list-immediate">
  ### Показать только непосредственные дочерние элементы
</div>

```sql
SELECT name, type
FROM filesystem('my_directory')
WHERE depth = 0;
```
