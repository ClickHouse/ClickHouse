Табличные функции — это способы построения таблиц.

{/*AUTOGENERATED_START*/ }

{/*AUTOGENERATED_END*/ }

<div id="usage">
  ## Использование
</div>

Табличные функции можно использовать в операторе [`FROM`](../../sql-reference/statements/select/from.md)
запроса `SELECT`. Например, с помощью табличной функции `file` можно выполнить `SELECT` данных из файла на вашем локальном
компьютере.

```bash title="Query"
echo "1, 2, 3" > example.csv
```

```text title="Response"
./clickhouse client
:) SELECT * FROM file('example.csv')
┌─c1─┬─c2─┬─c3─┐
│  1 │  2 │  3 │
└────┴────┴────┘
```

Вы также можете использовать табличные функции для создания временной таблицы, доступной
только в рамках текущего запроса. Например:

```sql title="Query"
SELECT * FROM generateSeries(1,5);
```

```response title="Response"
┌─generate_series─┐
│               1 │
│               2 │
│               3 │
│               4 │
│               5 │
└─────────────────┘
```

Таблица удаляется по завершении запроса.

Табличные функции можно использовать для создания таблиц, используя следующий синтаксис:

```sql title="Query"
CREATE TABLE [IF NOT EXISTS] [db.]table_name AS table_function()
```

Например:

```sql title="Query"
CREATE TABLE series AS generateSeries(1, 5);
SELECT * FROM series;
```

```response title="Response"
┌─generate_series─┐
│               1 │
│               2 │
│               3 │
│               4 │
│               5 │
└─────────────────┘
```

Наконец, табличные функции можно использовать для `INSERT` данных в таблицу. Например,
мы можем снова воспользоваться табличной функцией `file`, чтобы записать содержимое таблицы, созданной в предыдущем примере,
в файл на диске:

```sql title="Query"
INSERT INTO FUNCTION file('numbers.csv', 'CSV') SELECT * FROM series;
```

```bash title="Query"
cat numbers.csv
1
2
3
4
5
```

:::note
Нельзя использовать табличные функции, если параметр [allow&#95;ddl](/ru/operations/settings/settings#allow_ddl) отключён.
:::
