При записи данных в таблицу `Null` они игнорируются.
При чтении из таблицы `Null` возвращается пустой результат.

Движок таблицы `Null` полезен при преобразовании данных, когда после преобразования исходные данные больше не нужны.
Для этого можно создать materialized view поверх таблицы `Null`.
Данные, записанные в таблицу, будут использованы представлением, а исходные необработанные данные будут отброшены.
