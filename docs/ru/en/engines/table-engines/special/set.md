В ClickHouse Cloud, если ваш сервис был создан с версией ниже 25.4, вам потребуется установить совместимость как минимум на 25.4 с помощью `SET compatibility=25.4`.
:::

Набор данных, который всегда хранится в оперативной памяти. Предназначен для использования в правой части оператора `IN` (см. раздел «Операторы IN»).

Вы можете использовать `INSERT`, чтобы вставлять данные в таблицу. Новые элементы будут добавляться в набор данных, а дубликаты — игнорироваться.
Но выполнять `SELECT` из таблицы нельзя. Единственный способ получить данные — использовать таблицу в правой части оператора `IN`.

Данные всегда находятся в оперативной памяти. При `INSERT` блоки вставленных данных также записываются в каталог таблицы на диске. При запуске сервера эти данные загружаются в оперативную память. Иными словами, после перезапуска данные сохраняются.

При аварийном перезапуске сервера блок данных на диске может быть утерян или повреждён. В последнем случае может потребоваться вручную удалить файл с повреждёнными данными.

  ### Ограничения и настройки
</div>

При создании таблицы используются следующие настройки:

<div id="persistent">
  #### Persistent
</div>

Отключает персистентность для движков таблиц Set и [JOIN](/ru/engines/table-engines/special/join).

Снижает накладные расходы на I/O. Подходит для сценариев, в которых важна производительность и не требуется персистентность.

Возможные значения:

* 1 — Включено.
* 0 — Отключено.

Значение по умолчанию: `1`.
