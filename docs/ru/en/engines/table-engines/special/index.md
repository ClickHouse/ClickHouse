Существуют три основные категории движков таблиц:

* [Семейство движков MergeTree](../../../engines/table-engines/mergetree-family/index.md) для основного использования в продакшне.
* [Семейство движков Log](../../../engines/table-engines/log-family/index.md) для небольших объёмов временных данных.
* [Движки таблиц для интеграций](../../../engines/table-engines/integrations/index.md).

Остальные движки имеют уникальное назначение и пока не объединены в семейства, поэтому они отнесены к этой &quot;специальной&quot; категории.
