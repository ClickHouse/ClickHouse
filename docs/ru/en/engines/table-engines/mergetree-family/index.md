Движки таблиц семейства MergeTree лежат в основе возможностей хранения данных в ClickHouse. Они предоставляют большую часть возможностей, связанных с отказоустойчивостью и высокопроизводительным доступом к данным: столбцовое хранение, пользовательское партиционирование, разреженный первичный индекс, вторичные индексы пропуска данных и т. д.

Базовый движок таблицы [MergeTree](../../../engines/table-engines/mergetree-family/mergetree.md) можно считать движком таблицы по умолчанию для одноузловых экземпляров ClickHouse, поскольку он универсален и подходит для широкого круга сценариев использования.

Для использования в продакшне [ReplicatedMergeTree](../../../engines/table-engines/mergetree-family/replication.md) — оптимальный выбор, поскольку он добавляет высокую доступность ко всем возможностям обычного движка MergeTree. Дополнительное преимущество — автоматическая дедупликация данных при ингестии, поэтому ПО может безопасно повторить попытку, если во время вставки возникла проблема с сетью.

Все остальные движки семейства MergeTree добавляют дополнительные возможности для конкретных сценариев использования. Обычно это реализуется как дополнительная фоновая обработка данных.

Основной недостаток движков MergeTree в том, что они довольно тяжеловесны. Поэтому обычно их используют в небольшом количестве. Если вам нужно много небольших таблиц, например для временных данных, рассмотрите [семейство движков Log](../../../engines/table-engines/log-family/index.md).
