<div id="shared-database-engine">
  # Движок базы данных Shared
</div>

Движок базы данных `Shared` работает совместно с Shared Catalog и управляет базами данных, таблицы которых используют движки таблиц без сохранения состояния, такие как [`SharedMergeTree`](/ru/cloud/reference/shared-merge-tree).
Эти движки таблиц не сохраняют состояние на диске и совместимы с динамическими вычислительными средами.

Движок базы данных `Shared` в Cloud устраняет зависимость от локальных дисков.
Это полностью работающий в памяти движок, которому требуются только CPU и память.

<div id="how-it-works">
  ## Как это работает?
</div>

Движок базы данных `Shared` хранит все определения баз данных и таблиц в централизованном Shared Catalog на базе Keeper. Вместо записи на локальный диск он поддерживает единое глобальное состояние с версиями, общее для всех вычислительных узлов.

Каждый узел отслеживает только последнюю применённую версию и при запуске загружает актуальное состояние без необходимости использовать локальные файлы или выполнять ручную настройку.

<div id="syntax">
  ## Синтаксис
</div>

Для конечных пользователей использование Shared Catalog и движка базы данных Shared не требует дополнительной настройки. Создание базы данных выполняется как обычно:

```sql
CREATE DATABASE my_database;
```

ClickHouse Cloud автоматически назначает базам данных движок базы данных Shared. Любые таблицы, созданные в такой базе данных с использованием движков без сохранения состояния, автоматически используют возможности репликации и координации Shared Catalog.
