У нас есть множество материалов, которые помогут вам начать работу и разобраться, как работает ClickHouse:

* Чтобы попробовать ClickHouse, ничего не устанавливая, зарегистрируйтесь для бесплатного [пробного периода ClickHouse Cloud](https://clickhouse.cloud/signUp?loc=docs-get-started-sample-datasets) или выполняйте запросы в [Песочнице ClickHouse](/ru/get-started/sample-datasets/playground), доступной только для чтения.
* Если вы предпочитаете запустить ClickHouse самостоятельно, ознакомьтесь с нашим руководством [Быстрый старт](/ru/get-started/setup/install).
* Если вы не знаете, с чего начать изучение, попробуйте руководство [Данные о такси Нью-Йорка](/ru/get-started/sample-datasets/nyc-taxi), посвященное анализу набора данных о поездках на такси в Нью-Йорке, — или выберите любое из руководств ниже.
