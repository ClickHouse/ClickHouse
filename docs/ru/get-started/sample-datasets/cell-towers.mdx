## Геопространственный анализ базовых станций {#geospatial-analysis-with-cell-towers}

В этом руководстве вы загрузите данные базовых станций `OpenCelliD` в `ClickHouse Cloud`, дополните их словарём стран, найдёте станции в Германии и визуализируете их с помощью `ClickHouse Agents`.

<Steps>
  <Step title="Загрузите пример данных">
    В `ClickHouse Cloud` откройте **Load data**, выберите **Cell Towers** в **Sample data** и загрузите набор. Каждая строка `cell_towers` — базовая станция; `lon` и `lat` содержат её координаты.

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="Выполните запросы и обогащение">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;

    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="Используйте геоданные">
    `ClickHouse` предоставляет [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon). Создайте `germany`, вставьте контур континентальной Германии из [английского руководства](/get-started/sample-datasets/cell-towers#germany-polygon) и подсчитайте станции внутри полигона:

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    Результат — примерно `2.62 million`.
  </Step>
  <Step title="Необязательно: визуализируйте данные с ClickHouse Agents">
    Это необязательный пример запуска: `ClickHouse Agents` — бета-функциональность, управляемая моделью, поэтому план, используемые инструменты и результат могут различаться между запусками. Откройте **ClickHouse agents** и отправьте: "Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables".

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="Чат ClickHouse Agent, создающий сетку плотности базовых станций Германии"/>

    В одном запуске агент нашёл MCC Германии, подсчитал станции, сгруппировал их в ячейки `0.1°` и нарисовал контур на карте.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="Тепловая карта плотности базовых станций Германии"/>
  </Step>
</Steps>
