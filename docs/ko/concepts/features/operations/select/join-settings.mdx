이 페이지에서는 JOIN의 의미 체계, 계획 수립, 실행 및 메모리 사용에 영향을 주는 세션 설정(Session Settings)을 소개합니다. 각 설정에는 [세션 설정 참고 문서](/ko/reference/settings/session-settings)의 해당 항목 링크가 연결되어 있으며, 해당 문서에서 기본값과 허용되는 값을 확인할 수 있습니다. JOIN의 구문과 의미 체계는 [`JOIN` 절 참고 문서](/ko/reference/statements/select/join)를 참조하십시오.

## 의미 체계와 구문 {#semantics-and-syntax}

| 설정                                                                                                                                                                                     | 설명                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/ko/reference/settings/session-settings/join#join_default_strictness)                                                                                         | 엄격성을 명시하지 않은 JOIN에 적용할 엄격성을 설정합니다.                                                                                               |
| [`any_join_distinct_right_table_keys`](/ko/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | `ANY INNER JOIN` 및 `ANY LEFT JOIN`의 레거시 동작을 활성화합니다. 이 동작에서는 `t1 ANY LEFT JOIN t2`와 `t2 ANY RIGHT JOIN t1`이 서로 다른 결과를 반환할 수 있습니다. |
| [`join_any_take_last_row`](/ko/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | 오른쪽 테이블(right table)에 하나의 키와 일치하는 행이 여러 개 있을 때, `ANY` 엄격성의 JOIN이 첫 번째 일치 행과 마지막 일치 행 중 어느 것을 가져올지 선택합니다.                         |
| [`join_use_nulls`](/ko/reference/settings/session-settings/join#join_use_nulls)                                                                                                           | 외부 JOIN에서 일치 항목이 없는 행의 컬럼을 기본값으로 채울지 `NULL`로 채울지 제어합니다.                                                                          |
| [`semi_join_include_columns_from_both_sides`](/ko/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | `SEMI JOIN`의 결과에 두 테이블의 컬럼을 모두 노출할지, 보존되는 테이블의 컬럼만 노출할지 제어합니다.                                                                   |
| [`anti_join_include_columns_from_both_sides`](/ko/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | `ANTI JOIN`의 결과에 두 테이블의 컬럼을 모두 노출할지, 보존되는 테이블의 컬럼만 노출할지 제어합니다.                                                                   |
| [`cross_to_inner_join_rewrite`](/ko/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | 쉼표로 구분된 테이블 목록 또는 `WHERE`에 동등 조건이 있는 `CROSS JOIN`을 `INNER JOIN`으로 재작성할지 제어합니다.                                                   |
| [`allow_block_nested_loop_join`](/ko/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | `ON` 부분에 테이블 간 동등 조건이 없는 JOIN을 블록 중첩 루프 조인으로 실행할 수 있도록 허용합니다.                                                                    |
| [`enable_lateral_join`](/ko/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | Experimental `LATERAL JOIN` 구문을 활성화합니다. 이 구문에서는 JOIN 오른쪽의 서브쿼리가 왼쪽의 컬럼을 참조할 수 있습니다.                                              |
| [`single_join_prefer_left_table`](/ko/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | 단일 JOIN에서 두 테이블 중 어느 쪽을 가리키는지 모호한 식별자를 왼쪽 테이블의 것으로 해석합니다.                                                                        |
| [`joined_subquery_requires_alias`](/ko/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | JOIN에 사용되는 서브쿼리와 테이블 함수에 반드시 별칭을 지정하도록 합니다.                                                                                      |
| [`allow_dynamic_type_in_join_keys`](/ko/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | `Dynamic` 타입의 JOIN 키를 허용합니다.                                                                                                     |
| [`analyzer_compatibility_join_using_top_level_identifier`](/ko/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | `USING`의 컬럼명을 쿼리 내에서 이름이 같은 별칭(예: `SELECT` 목록의 별칭)으로 해석합니다.                                                                      |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/ko/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | JOIN이 2개 이상인 쿼리에서 이전 분석기와 마찬가지로 결과 컬럼명을 테이블 이름 또는 별칭으로 한정합니다.                                                                    |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/ko/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | 26.6 이전 버전과 마찬가지로 JOIN의 가장 왼쪽 테이블에 지정된 `FINAL` 수정자를 조인된 모든 테이블에 적용합니다.                                                           |

| [`enable_join_fixed_hash_table_conversion`](/ko/reference/settings/session-settings/enable-join#enable_join_fixed_hash_table_conversion)         | 키가 값의 범위가 작은 단일 정수이면 JOIN의 해시 테이블을 평면 배열로 변환하는 기능을 활성화합니다.                                                                                                                                                                                                                             |
| [`enable_join_key_only_hash_tables`](/ko/reference/settings/session-settings/enable-join#enable_join_key_only_hash_tables)                       | `LEFT ANTI` JOIN과 오른쪽 테이블의 컬럼을 선택하지 않는 `LEFT SEMI` JOIN에서 JOIN 키만 저장하는 해시 테이블을 사용하도록 활성화합니다.                                                                                                                                                                                           |

L2 캐시에 들어가는 해시 테이블은 원래의 키를 그대로 사용하지만, 이 값이 0이면 모든 JOIN에서 키를 패킹합니다. |

| [`joined_block_split_single_row`](/ko/reference/settings/session-settings/joined#joined_block_split_single_row)                                  | 일치 항목이 많은 왼쪽 테이블의 한 행에 대한 해시 JOIN 결과를 여러 블록으로 분할할 수 있도록 허용합니다.                                                                                                                                                                                                                         |

| [`enable_lazy_columns_replication`](/ko/reference/settings/session-settings/enable#enable_lazy_columns_replication)                              | JOIN 결과(result)의 컬럼에 대해 지연 복제를 활성화합니다. 이를 통해 동일한 행(rows)이 메모리에 여러 번 복사되지 않도록 합니다.                                                                                                                                                                                                      |
