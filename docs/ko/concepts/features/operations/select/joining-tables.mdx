이 개요에서는 JOIN 유형과 엄격성(strictness)을 설명합니다. 전체 구문은 [`JOIN` 절 참고 문서](/ko/reference/statements/select/join)를 참조하십시오. 구체적인 최적화 지침과 단계별 예시는 [JOIN 최소화 및 최적화](/ko/concepts/best-practices/minimize-optimize-joins)를 참조하십시오.

## JOIN 유형과 엄격성 {#join-types-and-strictness}

모든 JOIN에는 유형과 엄격성이 있습니다. 유형은 일치 항목이 없는 행 중 어떤 행을 결과(result)에 포함할지 결정하고, 엄격성은 각 행에 대해 반환할 일치 항목의 개수를 결정합니다. JOIN을 실행할 수 있는 알고리즘은 이 두 가지에 따라 달라집니다. 전체 구문과 그 밖의 `SEMI`, `ANTI`, `CROSS`, `PASTE` JOIN에 대한 내용은 [`JOIN` 절 참고](/ko/reference/statements/select/join#supported-types-of-join) 문서를 참조하십시오.

### `INNER JOIN` {#inner-join}

<div className="ch-image-sm">
  <Frame>
    ![INNER JOIN의 벤 다이어그램: 조인 키가 일치하는 왼쪽 테이블 행과 오른쪽 테이블(right table) 행의 교집합만 일치하는 행들의 카테시안 곱 형태로 반환됩니다](/images/guides/join-algorithms/inner-join.png)
  </Frame>
</div>

`INNER JOIN`은 조인 키가 일치하는 각 행 쌍마다 왼쪽 행의 컬럼과 오른쪽 행의 컬럼을 결합하여 반환합니다. 한 행에 일치 항목이 여러 개 있으면 모든 일치 항목이 반환되므로, 결과(result)에는 키가 같은 행들의 카테시안 곱이 포함됩니다. `INNER` 키워드는 생략할 수 있습니다.

### `LEFT`, `RIGHT`, `FULL OUTER JOIN` {#outer-join}

<div className="ch-image-lg">
  <Frame>
    ![LEFT, RIGHT, FULL OUTER JOIN의 벤 다이어그램: 각각 일치하는 행의 카테시안 곱에 더해 왼쪽 테이블, 오른쪽 테이블 또는 두 테이블 모두에서 일치하지 않는 행을 반환합니다](/images/guides/join-algorithms/outer-join.png)
  </Frame>
</div>

외부 조인(outer JOIN)은 `INNER JOIN`과 동일한 행을 반환하고, 일치하지 않는 행도 함께 반환합니다.

* `LEFT OUTER JOIN`은 일치하는 항목이 없는 왼쪽 테이블의 각 행도 반환하며, 이때 오른쪽 테이블의 컬럼은 기본값으로 채워집니다.
* `RIGHT OUTER JOIN`은 일치하는 항목이 없는 오른쪽 테이블의 각 행도 반환하며, 이때 왼쪽 테이블의 컬럼은 기본값으로 채워집니다.
* `FULL OUTER JOIN`은 두 테이블 모두에서 일치하지 않는 행을 반환합니다.

[`join_use_nulls`](/ko/reference/settings/session-settings/join#join_use_nulls) 설정을 사용하면 ClickHouse가 기본값 대신 `NULL`을 반환합니다. `OUTER` 키워드는 생략할 수 있습니다.

### `ALL` 및 `ANY` 엄격성 {#all-and-any-strictness}

<div className="ch-image-lg">
  <Frame>
    ![LEFT, RIGHT, INNER ANY JOIN의 벤 다이어그램: 모두 카테시안 곱 없이 일치하는 행을 반환하며, LEFT와 RIGHT는 각각 왼쪽 테이블 또는 오른쪽 테이블에서 일치하지 않는 행도 함께 반환합니다](/images/guides/join-algorithms/any-join.png)
  </Frame>
</div>

`ALL` 엄격성에서는 앞서 JOIN 유형에서 설명한 대로 JOIN이 모든 일치 항목을 반환합니다. `ANY` 엄격성에서는 JOIN이 각 행에 대해 일치 항목을 최대 1개만 반환하며 카테시안 곱을 생성하지 않습니다.

* `LEFT ANY JOIN`은 왼쪽의 각 행을 한 번씩 반환하며, 이때 일치하는 오른쪽 행 하나 또는 기본값을 결합합니다.
* `RIGHT ANY JOIN`은 오른쪽의 각 행을 한 번씩 반환하며, 이때 일치하는 왼쪽 행 하나 또는 기본값을 결합합니다.
* `INNER ANY JOIN`은 일치 항목이 있는 행만 반환하며, 두 테이블의 각 행을 최대 한 번만 사용합니다.

일치하는 행이 여러 개일 때 `ANY`가 그중 어떤 행을 반환할지는 정의되어 있지 않습니다. [`join_any_take_last_row`](/ko/reference/settings/session-settings/join#join_any_take_last_row) 설정을 사용하면 선택되는 행을 바꿀 수 있습니다. `ANY FULL` JOIN은 지원되지 않습니다. 쿼리에 엄격성을 지정하지 않으면 [`join_default_strictness`](/ko/reference/settings/session-settings/join#join_default_strictness) 설정이 적용됩니다.

다음은 `LEFT ANY JOIN` 쿼리 예시입니다. 오른쪽 테이블에는 키 `2`와 `3`에 대해 각각 2개의 행이 있습니다.

```sql
WITH
    left_table AS (SELECT * FROM VALUES('c UInt32', 1, 2, 3)),
    right_table AS (SELECT * FROM VALUES('c UInt32', 2, 2, 3, 3, 4))
SELECT
    l.c AS l_c,
    r.c AS r_c
FROM left_table AS l
LEFT ANY JOIN right_table AS r ON l.c = r.c;
```

```response
┌─l_c─┬─r_c─┐
│   1 │   0 │
│   2 │   2 │
│   3 │   3 │
└─────┴─────┘
```

`ALL` 엄격성을 사용하면 키 `2`와 `3`이 각각 오른쪽 테이블의 행 2개와 일치하므로, 동일한 쿼리가 5개의 행을 반환합니다. `INNER ANY JOIN`을 사용하면 키 `2`와 `3`에 해당하는 행만 반환됩니다.

### `ASOF JOIN` {#asof-join}

<div className="ch-image-sm">
  <Frame>
    ![ASOF JOIN의 벤 다이어그램: 조인 키가 정확히 일치하지 않는 행도 조인되며, 카테시안 곱 없이 각 행마다 가장 가까운 일치 항목을 반환합니다](/images/guides/join-algorithms/asof-join.png)
  </Frame>
</div>

`ASOF JOIN`은 정확한 일치 항목이 없는 행을 조인합니다. ClickHouse에서 `ASOF`는 `INNER` 또는 `LEFT` JOIN과 함께 사용하는 엄격성입니다. `ON` 절에는 동등 조건과 함께, `>`, `>=`, `<`, `<=` 중 하나를 사용하는 가장 가까운 일치 조건이 정확히 하나 포함됩니다. ClickHouse는 각 왼쪽 행마다 동등 조건을 만족하는 오른쪽 행 중에서 가장 가까운 일치 조건상 가장 가까운 행을 선택합니다. 각 왼쪽 행은 최대 하나의 오른쪽 행과 조인됩니다.

`ASOF JOIN`은 주로 시계열 데이터에 사용됩니다. 다음 쿼리는 각 거래를 거래 시각 또는 그 이전의 동일 종목 호가 중 가장 최근 호가와 조인합니다:

```sql
WITH
    trades AS (SELECT * FROM VALUES('symbol String, volume UInt32, time DateTime',
        ('ABC', 200, '2023-02-22 14:09:05'),
        ('ABC', 300, '2023-02-22 14:09:28'))),
    quotes AS (SELECT * FROM VALUES('symbol String, time DateTime, price Decimal(10, 2)',
        ('ABC', '2023-02-22 14:09:00', 32.11),
        ('ABC', '2023-02-22 14:09:10', 32.12),
        ('ABC', '2023-02-22 14:09:20', 32.15),
        ('ABC', '2023-02-22 14:09:30', 32.20)))
SELECT
    t.symbol,
    t.volume,
    t.time AS trade_time,
    q.time AS closest_quote_time,
    q.price AS quote_price,
    t.volume * q.price AS final_price
FROM trades AS t
ASOF LEFT JOIN quotes AS q ON t.symbol = q.symbol AND t.time >= q.time
ORDER BY trade_time;
```

```response
┌─symbol─┬─volume─┬──────────trade_time─┬──closest_quote_time─┬─quote_price─┬─final_price─┐
│ ABC    │    200 │ 2023-02-22 14:09:05 │ 2023-02-22 14:09:00 │       32.11 │        6422 │
│ ABC    │    300 │ 2023-02-22 14:09:28 │ 2023-02-22 14:09:20 │       32.15 │        9645 │
└────────┴────────┴─────────────────────┴─────────────────────┴─────────────┴─────────────┘
```

`14:09:05`의 거래는 `14:09:00`의 호가와 조인되고, `14:09:28`의 거래는 `14:09:20`의 호가와 조인됩니다. `14:09:10`과 `14:09:30`의 호가는 어느 거래에 대해서도 가장 가까운 이전 호가에 해당하지 않습니다.

가장 가까운 일치 컬럼에서 지원하는 컬럼 타입과 `USING` 구문은 [ASOF JOIN 사용법](/ko/reference/statements/select/join#asof-join-usage)을 참조하십시오.
