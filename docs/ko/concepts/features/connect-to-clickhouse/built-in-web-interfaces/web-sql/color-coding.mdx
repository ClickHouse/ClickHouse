내장 웹 SQL UI(`play.html`, 모든 ClickHouse HTTP 포트의 [`/play`](/ko/concepts/features/connect-to-clickhouse/protocols/http) 경로에서 제공)는 결과 셀에 색상을 입혀 컬럼 내의 패턴을 한눈에 파악할 수 있도록 해 줍니다. 색상 코딩 모드는 컬럼마다 따로 지정되며, 각각 독립적으로 전환할 수 있습니다.

## 모드 전환 {#switching-the-mode}

모든 열 머리글(column header)의 오른쪽에는 🌈 아이콘이 표시됩니다. 이 아이콘을 클릭하면 해당 컬럼에서 사용할 수 있는 모드가 차례로 전환됩니다. 호버가 가능한 포인터(마우스)를 사용하는 기기에서는 머리글에 마우스를 올렸을 때만 아이콘이 표시되므로 평소에는 방해가 되지 않습니다. 호버 기능이 없는 터치 기기 및 기타 정밀도가 낮은 포인터 기기에서는 아이콘을 바로 탭할 수 있도록 항상 표시됩니다.

컬럼에서 제공하는 모드는 컬럼의 유형에 따라 달라집니다.

* 숫자 컬럼과 `Date`/`DateTime`/`Date32`/`DateTime64` 컬럼은 `bar` → `heatmap` → `categorical` → `none` 순서로 순환합니다.
* 그 밖의 모든 컬럼은 `none`과 `categorical` 사이에서 전환됩니다.

기본 모드는 숫자 컬럼이 `bar`이고, 날짜 및 시간 컬럼을 포함한 그 밖의 모든 컬럼은 `none`입니다.

## 모드 {#modes}

* **`bar`** — 셀 안에 값에 비례하는 수평 막대를 그립니다. 숫자 컬럼은 막대가 0 기준값에서 시작해 늘어나며, `Date`/`DateTime` 컬럼은 타임스탬프에서 0 기준값이 의미가 없으므로 대신 컬럼의 `min`..`max` 범위를 기준으로 표시됩니다.
* **`heatmap`** — 컬럼의 최솟값과 최댓값 사이로 스케일링한 값을 색상으로 나타내어 셀 배경 전체를 채웁니다.
* **`categorical`** — 셀 값을 해시하여 얻은 색상으로 셀 배경을 채웁니다. 따라서 같은 값은 같은 색상으로, 다른 값은 다른 색상으로 표시됩니다. 모든 컬럼 타입에서 사용할 수 있습니다.
* **`none`** — 색상 코딩을 적용하지 않습니다.

`Date`, `DateTime`, `Date32`, `DateTime64` 컬럼은 시간 값을 기준으로 색상이 지정됩니다. 이 값은 UTC로 파싱되므로 스케일은 보는 사람의 브라우저 시간대와 관계없이 동일합니다.

`heatmap` 및 `categorical` 배경색은 `oklch` 색 공간을 사용합니다. 테마별로 명도와 채도는 고정하고 색상만 달리하므로, 라이트 테마와 다크 테마 모두에서 셀 텍스트를 쉽게 읽을 수 있습니다. 행이 여러 줄에 걸쳐 표시되는 경우에도 배경은 셀 전체를 채웁니다.

## 선택 시 범주형 강조 {#categorical-emphasis}

`categorical` 모드에서 셀을 선택하면 같은 값을 가진 다른 셀들이 강조되어 더 굵은 글꼴과 최대 대비 텍스트 색상(다크 테마에서는 완전한 흰색, 라이트 테마에서는 완전한 검은색)으로 표시됩니다. 선택한 셀 자체는 강조되지 않습니다. 따라서 특정 값이 컬럼의 다른 어느 위치에 나타나는지 쉽게 확인할 수 있습니다.

## 영속화 {#persistence}

선택한 모드는 컬럼별로 페이지 URL과 브라우저 이력에 기록되므로, 페이지를 다시 로드하거나 링크를 공유하거나 뒤로/앞으로 이동해도 그대로 유지됩니다. URL과 이력 상태를 간결하게 유지하기 위해 기본값이 아닌 선택만 저장됩니다.

[고정 열(Pinned Column)](/ko/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/pinned-columns)과 마찬가지로 모드는 색상이 적용되는 결과에 귀속됩니다. 즉, 모드는 쿼리 탭에 귀속되며, [노트북](/ko/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook) 탭에서는 개별 셀에 귀속됩니다. 한 번의 `Run all`(다중 쿼리) 실행으로 생성된 테이블은 모드를 공유하지만, 다른 셀과 다른 탭은 각자의 모드를 유지합니다.

## 제한 사항 {#limitations}

* 세로(전치) 단일 행 레이아웃에서는 색상 코딩이 표시되지 않습니다.
* `DateTime64(9)` 값 간의 1마이크로초 미만 차이는 그라데이션에서 시각적으로 의미가 없으므로 색상 스케일에서 구분되지 않습니다.
