내장 웹 SQL UI(`play.html`, 모든 ClickHouse HTTP 포트의 [`/play`](/ko/concepts/features/connect-to-clickhouse/protocols/http) 경로에서 제공)에서는 테이블의 나머지 부분을 가로로 스크롤하는 동안에도 결과(result)에서 선택한 컬럼을 계속 화면에 표시할 수 있습니다. 고정 열(Pinned Column)은 스크롤되어 사라지지 않고 결과 영역의 가까운 쪽 가장자리에 고정됩니다. 따라서 식별자, 이름, 날짜와 같은 기준 컬럼을 현재 보고 있는 오른쪽 끝 컬럼과 함께 계속 확인할 수 있습니다.

## 컬럼 고정하기 {#pinning-a-column}

모든 컬럼 머리글(column header)의 왼쪽에는 📌 압정 아이콘이 표시됩니다. 이 아이콘을 클릭하면 컬럼이 고정되고, 다시 클릭하면 고정이 해제됩니다. 이 아이콘은 실제 버튼이므로 키보드 사용자도 Tab 키로 이동하여 키보드로 토글할 수 있으며, 보조 기술에도 고정 상태를 전달합니다.

마우스처럼 호버가 가능한 포인터를 사용하는 기기에서는 머리글에 포인터를 올려놓거나 토글에 포커스가 있을 때만 아이콘이 표시되므로, 평소에는 방해가 되지 않습니다. 반면 호버 기능이 없는 터치 기기 등 정밀도가 낮은 포인터를 사용하는 기기에서는 아이콘을 바로 탭할 수 있도록 항상 표시됩니다. 고정된 컬럼에서는 컬럼이 고정되어 있음을 알 수 있도록 아이콘이 항상 선명하게 표시됩니다.

## 열 고정을 사용할 수 있는 경우 {#when-pinning-is-available}

열 고정(pinning)은 테이블이 가로로 스크롤될 만큼 넓은 경우에만 제공됩니다. 전체 테이블이 뷰포트 안에 모두 들어가면 스크롤할 대상이 없으므로 고정 토글이 비활성화되고 키보드 탭 순서에서도 제외됩니다. 결과(result)를 가로로 스크롤할 수 있게 되면(결과가 넓거나, 창이 좁거나, 스트리밍 결과가 가로로 늘어나는 경우) 즉시 토글이 활성화됩니다.

## 스크롤 시 고정 컬럼의 동작 방식 {#how-a-pinned-column-behaves-when-scrolling}

고정 컬럼(Pinned Column)은 가로 스크롤 시 콘텐츠와 함께 이동하다가 뷰포트를 벗어나려는 시점에 가까운 쪽 가장자리에 고정되어 계속 표시됩니다. 왼쪽에 있는 컬럼은 왼쪽 가장자리에, 오른쪽에 있는 컬럼은 오른쪽 가장자리에 고정됩니다. 고정 컬럼이 여러 개이면 원래 순서대로 가장자리에 나란히 쌓이며, 각 컬럼은 테두리로 스크롤되는 콘텐츠와 구분됩니다. 고정된 셀은 그 아래로 스크롤되는 일반 셀 위에 표시되며 선택된 셀도 예외가 아닙니다. 따라서 고정된 셀의 내용은 항상 읽을 수 있습니다.

## 결과 단위로 공유 {#shared-across-a-result}

고정은 컬럼명을 기준으로 관리되며, 하나의 결과(result)에 속한 모든 결과 테이블(result table)에서 공유됩니다. `Run all`(다중 쿼리)로 실행하면 SQL 문마다 테이블이 하나씩 렌더링되며, 이 테이블들은 모두 동일한 고정된 열 집합을 공유합니다. 이는 per-column [색상 코딩 모드](/ko/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/color-coding)가 공유되는 방식과 같습니다. 이 테이블 중 하나에서 `id`라는 컬럼을 고정하면 다른 테이블의 `id` 컬럼은 물론, 같은 컬럼을 반환하는 동일 쿼리를 이후에 다시 실행할 때도 `id` 컬럼이 계속 고정됩니다.

고정된 열 집합은 해당 결과에 귀속됩니다. 즉, 쿼리 탭 단위로 관리되며, [노트북](/ko/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook) 탭에서는 개별 셀 단위로 관리됩니다. 따라서 한 셀에서 컬럼을 고정해도 다른 셀과 다른 탭의 고정 상태에는 영향을 주지 않으며, 각각 독립적으로 유지됩니다.

## 영속화 {#persistence}

고정된 열 집합은 페이지 URL, 브라우저 이력, 그리고 해당 셀의 결과(result) 스냅샷에 기록되므로, 페이지를 다시 로드하거나 링크를 공유하거나 뒤로/앞으로 이동해도 그대로 유지됩니다. 현재 편집기가 열려 있지 않은 셀에서 고정을 설정하거나 해제하면 해당 셀에 저장된 사본도 함께 갱신되므로, 다시 로드한 후에도 상태가 유지됩니다. 데이터를 간결하게 유지하기 위해 고정된 컬럼만 저장되며, 빈 집합은 URL이나 이력 상태에 아무것도 추가하지 않습니다.

## 제한 사항 {#limitations}

* 세로(전치) 단일 행 레이아웃에는 가로 스크롤되는 컬럼이 없으므로 열 고정을 사용할 수 없습니다.
