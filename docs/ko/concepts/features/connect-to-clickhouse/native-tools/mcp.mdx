[모델 컨텍스트 프로토콜](https://www.anthropic.com/news/model-context-protocol)(MCP)은 AI 어시스턴트를 외부 시스템에 연결할 수 있게 해 주는 개방형 표준입니다.
MCP는 모델과 서비스의 조합마다 사용자 정의 통합을 따로 구현하지 않아도, 모델이 데이터 소스, API, 데이터베이스, 도구에 액세스할 수 있는 일관된 인터페이스를 제공합니다.

AI 애플리케이션은 MCP를 한 번만 구현하면 호환되는 모든 서버에 연결할 수 있습니다.
마찬가지로 MCP 서버는 호환되는 모든 클라이언트에 자신의 기능을 제공할 수 있습니다.

## 아키텍처 {#architecture}

MCP는 다음과 같은 클라이언트-서버 아키텍처를 따릅니다.

* Claude Desktop, Cursor, VS Code와 같은 MCP 클라이언트는 MCP 서버에 연결합니다.
* MCP 서버는 표준화된 인터페이스를 통해 도구와 기능을 제공합니다.
* AI 모델은 필요할 때 제공된 도구를 사용하여 외부 데이터와 기능에 액세스합니다.

GitHub에서 커뮤니티가 관리하는 [MCP 클라이언트](https://github.com/punkpeye/awesome-mcp-clients) 및 [MCP 서버](https://github.com/punkpeye/awesome-mcp-servers) 모음을 확인할 수 있습니다.

[ClickHouse Loom은 코딩 에이전트를 위한 공유 메모리를 제공합니다](https://loom.clickhouse.com/docs/use-cases/agent-memory). 이 기능은 자체 호스팅 MCP 서버를 통해 제공됩니다.
세션(Sessions)이 바뀌어도 프로젝트의 결정 사항을 유지하고, 저장된 교훈을 인덱싱된 코드에 연결합니다.

## ClickHouse MCP 서버 {#clickhouse-mcp-server}

[ClickHouse MCP 서버](https://github.com/ClickHouse/mcp-clickhouse)를 사용하면 AI 어시스턴트가 ClickHouse 클러스터의 데이터베이스와 테이블을 탐색하고, 스키마(schema)를 확인하며, SQL 쿼리를 실행할 수 있습니다.
서버가 제공하는 도구는 버전에 따라 다를 수 있으므로, 예시에서 사용하는 도구 이름은 해당 통합 가이드를 참조하십시오.

서버는 기본적으로 읽기 전용 쿼리만 허용합니다.
어시스턴트에 필요한 권한만 부여한 전용 ClickHouse 사용자를 사용하십시오.

로컬 MCP 클라이언트를 연결하려면 [ClickHouse MCP 서버 설정](/ko/guides/use-cases/ai-ml/MCP/claude-desktop)을 참조하십시오.
관리형 원격 서버를 사용하려면 [ClickHouse Cloud의 원격 MCP 서버](/ko/products/cloud/features/ai-ml/remote-mcp)를 참조하십시오.

<Tip>
  **Agent Skills**

  [ClickHouse Agent Skills 리포지토리](https://github.com/ClickHouse/agent-skills)는 스키마 설계, 쿼리 최적화(query optimization), 데이터 수집 패턴 등 ClickHouse 전용 전문 지식을 AI 코딩 에이전트에 더해 주는 패키지형 지침을 제공합니다.
</Tip>
