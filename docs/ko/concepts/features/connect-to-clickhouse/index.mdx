ClickHouse 사용 방식에 가장 적합한 인터페이스를 선택하십시오. 애플리케이션을 개발한다면 공식 언어별 클라이언트나 드라이버부터 시작하십시오. 대화형 작업에는 네이티브 도구나 웹 기반 도구를 사용하고, 직접 통합하려면 네트워크 프로토콜을 사용하십시오. 연결하기 전에 필요에 따라 [네트워크 포트](/ko/concepts/features/security/network-ports), [접근 권한](/ko/concepts/features/security/access-rights), [TLS](/ko/concepts/features/security/tls/configuring-tls)를 구성하십시오.
