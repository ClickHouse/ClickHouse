AWS의 ClickHouse BYOC는 VPC 피어링과 AWS PrivateLink를 포함해 2가지 프라이빗 연결 옵션을 지원합니다.

<div id="common-prerequisites">
  ## 사전 요구 사항 {#common-prerequisites}
</div>

VPC 피어링과 PrivateLink에 공통으로 필요한 단계입니다.

### ClickHouse BYOC용 프라이빗 로드 밸런서 활성화 {#step-enable-private-load-balancer-for-clickhouse-byoc}

ClickHouse Cloud 콘솔에서 BYOC 인프라의 **프라이빗 로드 밸런서**를 활성화하십시오.

  <Frame>
    ![BYOC 프라이빗 로드 밸런서 활성화](/images/cloud/reference/byoc-private-load-balancer.webp)

## VPC 피어링 설정 {#aws-vpc-peering}

ClickHouse BYOC의 VPC 피어링을 생성하거나 삭제하려면 다음 단계를 따르십시오.

<Steps>
  <Step title="피어링 연결 생성" id="step-1-create-a-peering-connection">
    1. ClickHouse BYOC 계정의 VPC Dashboard로 이동합니다.
    2. Peering Connections를 선택합니다.
    3. Create Peering Connection을 클릭합니다.
    4. VPC Requester를 ClickHouse VPC ID로 설정합니다.
    5. VPC Accepter를 대상 VPC ID로 설정합니다. (해당하는 경우 다른 계정을 선택합니다)
    6. Create Peering Connection을 클릭합니다.

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 피어링 연결 생성](/images/cloud/reference/byoc-vpcpeering-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="피어링 연결 요청 수락" id="step-2-accept-the-peering-connection-request">
    피어링 계정으로 이동한 다음, (VPC -&gt; Peering connections -&gt; Actions -&gt; Accept request) 페이지에서 이 VPC 피어링 요청을 승인할 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 피어링 연결 수락](/images/cloud/reference/byoc-vpcpeering-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="ClickHouse VPC 라우트 테이블에 대상 추가" id="step-3-add-destination-to-clickhouse-vpc-route-tables">
    ClickHouse BYOC 계정에서 다음을 수행합니다.

    1. VPC Dashboard에서 Route Tables를 선택합니다.
    2. ClickHouse VPC ID를 검색합니다. 프라이빗 서브넷에 연결된 각 라우트 테이블을 편집합니다.
    3. Routes 탭 아래의 Edit 버튼을 클릭합니다.
    4. Add another route를 클릭합니다.
    5. Destination에 대상 VPC의 CIDR 범위를 입력합니다.
    6. Target에 “Peering Connection”과 피어링 연결 ID를 선택합니다.

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 라우트 테이블 추가](/images/cloud/reference/byoc-vpcpeering-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="대상 VPC 라우트 테이블에 대상 추가" id="step-4-add-destination-to-the-target-vpc-route-tables">
    피어링된 AWS 계정에서 다음을 수행합니다.

    1. VPC Dashboard에서 Route Tables를 선택합니다.
    2. 대상 VPC ID를 검색합니다.
    3. Routes 탭 아래의 Edit 버튼을 클릭합니다.
    4. Add another route를 클릭합니다.
    5. Destination에 ClickHouse VPC의 CIDR 범위를 입력합니다.
    6. Target에 “Peering Connection”과 피어링 연결 ID를 선택합니다.

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 라우트 테이블 추가](/images/cloud/reference/byoc-vpcpeering-4.webp)
      </Frame>
    </div>
  </Step>

  <Step title="피어링된 VPC 액세스를 허용하도록 보안 그룹 편집" id="step-5-edit-security-group-to-allow-peered-vpc-access">
    ClickHouse BYOC 계정에서 피어링된 VPC의 트래픽을 허용하도록 보안 그룹 설정을 업데이트해야 합니다. 피어링된 VPC의 CIDR 범위를 포함하는 인바운드 규칙 추가를 요청하려면 ClickHouse 지원팀에 문의하십시오.

    ***

    이제 피어링된 VPC에서 ClickHouse 서비스에 액세스할 수 있어야 합니다.
  </Step>
</Steps>

ClickHouse에 비공개로 액세스하려면, 사용자 피어링 VPC에서 안전하게 연결할 수 있도록 프라이빗 로드 밸런서와 엔드포인트가 프로비저닝됩니다. 프라이빗 엔드포인트는 퍼블릭 엔드포인트 형식을 따르며 `-private` 접미사가 붙습니다. 예시:

* **퍼블릭 엔드포인트**: `h5ju65kv87.mhp0y4dmph.us-west-2.aws.clickhouse-byoc.com`
* **Private endpoint**: `h5ju65kv87-private.mhp0y4dmph.us-west-2.aws.clickhouse-byoc.com`

선택 사항으로, 피어링이 정상적으로 작동하는 것을 확인한 후 ClickHouse BYOC의 퍼블릭 로드 밸런서 제거를 요청할 수 있습니다.

<div id="setup-privatelink">
  ## PrivateLink 설정 {#setup-privatelink}
</div>

AWS PrivateLink를 사용하면 VPC 피어링이나 인터넷 게이트웨이 없이 ClickHouse BYOC 서비스에 안전하게 비공개로 연결할 수 있습니다. 모든 트래픽은 AWS 네트워크 내에서만 흐르므로 공용 인터넷을 거치지 않습니다.

<Note>
  **리전 간 연결.** ClickHouse 콘솔의 **Enable private link** 토글은 엔드포인트 서비스를 프로비저닝하며 **동일 리전**의 consumer만 지원합니다. AWS는 기본적으로 엔드포인트 서비스의 리전 간 액세스를 비활성화하며, ClickHouse 콘솔에서는 이를 관리하지 않습니다. 클라이언트가 다른 리전에 있는 경우 직접 활성화해야 합니다. 엔드포인트 서비스는 BYOC 계정에 있으므로 자체 AWS 콘솔에서 consumer 리전을 **Supported regions** 목록에 추가하십시오(아래 3단계 참조). ClickHouse는 이 값을 변경하거나 재설정하지 않습니다. AWS 리전 간 데이터 전송 요금이 적용됩니다.
</Note>

<Steps>
  <Step title="ClickHouse 콘솔에서 Private Link 활성화" id="step-1-enable-private-link">
    <Note>
      사전 요구 사항으로 **프라이빗 로드 밸런서**가 활성화되어 있는지 확인하십시오.
    </Note>

    <div className="ch-image-md">
      <Frame>
        ![BYOC PrivateLink 활성화](/images/cloud/reference/byoc-privatelink.webp)
      </Frame>
    </div>
  </Step>

  <Step title={<>엔드포인트의 <code>서비스 이름</code>을 확인하십시오</>} id="step-2-obtain-endpoint-service-name">
    1. ClickHouse Cloud 콘솔에서 PrivateLink로 연결하려는 서비스의 설정 페이지로 이동합니다.
    2. &quot;프라이빗 엔드포인트 설정&quot;을 클릭합니다.
    3. 열린 플라이아웃에서 `Service name` 값을 복사합니다. 이 값은 다음 단계에서 사용합니다. (PrivateLink를 활성화한 후 값이 생성되기까지 다소 시간이 걸릴 수 있습니다.)

       <div className="ch-image-md">
         <Frame>
           ![프라이빗 엔드포인트](/images/cloud/security/aws-privatelink-pe-create.webp)
         </Frame>
       </div>
  </Step>

  <Step title="네트워크에 엔드포인트 생성" id="step-3-create-endpoint">
    1. **사용자 소유의 AWS 콘솔**(즉, 클라이언트 애플리케이션이 있는 AWS 계정)을 열고 VPC → Endpoints → Create endpoints로 이동합니다.

    2. &quot;Endpoint services that use NLBs and GWLBs&quot;를 선택하고 이전 단계에서 확인한 `Service name`을 입력합니다.

    3. &quot;Verify service&quot;를 클릭합니다.

       <div className="ch-image-md">
         <Frame>
           ![AWS PrivateLink 엔드포인트 설정](/images/cloud/security/aws-privatelink-endpoint-settings.webp)
         </Frame>
       </div>

    4. (선택 사항) PrivateLink를 통해 cross-region 연결을 구성하려면 &quot;Cross region endpoint&quot; 체크박스를 선택하고 서비스 리전을 지정합니다. 서비스 리전은 BYOC 인프라가 생성된 리전입니다. 이와 함께 다음 작업도 수행합니다.
       1. **BYOC AWS 콘솔**(즉, BYOC 인프라가 생성된 AWS 계정)을 열고 VPC → Endpoint services → `clickhouse-cloud-infra-xxx` → Supported regions로 이동합니다.
       2. 클라이언트 애플리케이션이 실행 중인 리전을 지원 리전 목록에 추가합니다. 기본적으로는 해당 BYOC 인프라의 리전만 지원됩니다. 여러 리전에서 연결하려면 리전을 여러 개 추가할 수 있으며, ClickHouse는 이 값을 변경하거나 초기화하지 않습니다.

          <div className="ch-image-md">
            <Frame>
              ![AWS PrivateLink Cross Region 엔드포인트 설정](/images/cloud/reference/byoc-privatelink-aws-cross-region.webp)
            </Frame>
          </div>

    5. VPC와 서브넷을 선택합니다(가용 영역당 서브넷 하나씩 선택하는 것을 권장합니다).

       <div className="ch-image-md">
         <Frame>
           ![VPC 및 서브넷 선택](/images/cloud/security/aws-privatelink-select-vpc-and-subnets.webp)
         </Frame>
       </div>

    6. **중요**: 엔드포인트의 &quot;Private DNS names&quot;를 활성화하십시오. Private DNS가 올바르게 작동하려면 이 설정이 반드시 필요합니다.
       BYOC 엔드포인트용 Private DNS(`*.vpce.{subdomain}` 형식)는 AWS PrivateLink에 기본 제공되는 &quot;Private DNS names&quot; 기능을 활용합니다. Route53 레코드는 필요하지 않으며, 다음 조건이 충족되면 DNS 해석이 자동으로 이루어집니다.
       * &quot;Private DNS names&quot;가 활성화되어 있고
       * &quot;DNS Hostnames&quot;가 활성화되어 있는 경우

         (VPC Settings → DNS resolution and DNS hostnames에서 설정)

         이렇게 하면 `vpce` 하위 도메인을 사용하는 연결이 별도의 DNS 구성 없이 PrivateLink 엔드포인트를 통해 자동으로 라우팅됩니다.

    7. (선택 사항) 보안 그룹/태그를 할당합니다.
       <Note>
         보안 그룹에서 `443`, `8443`, `9440` 포트가 허용되어 있는지 확인하십시오.
       </Note>

    8. &quot;Create endpoint&quot;를 클릭하고 엔드포인트가 생성될 때까지 잠시 기다립니다.

    9. 엔드포인트가 생성되면 `Endpoint ID` 값을 복사합니다. 이 값은 다음 단계에서 사용합니다.

       <div className="ch-image-md">
         <Frame>
           ![VPC 엔드포인트 ID](/images/cloud/security/aws-privatelink-vpc-endpoint-id.webp)
         </Frame>
       </div>
  </Step>

  <Step title="엔드포인트 연결을 승인하십시오" id="step-4-approve-endpoint-connection">
    1. **BYOC VPC 콘솔**을 다시 열고 Endpoint services → `clickhouse-cloud-infra-xxx` → Endpoint connections로 이동합니다.
    2. 사용자 VPC에서 생성한 연결 요청을 찾은 다음 &quot;Accept endpoint connection request&quot;를 클릭하여 요청을 승인합니다.

       <div className="ch-image-md">
         <Frame>
           ![BYOC PrivateLink 승인](/images/cloud/reference/byoc-privatelink-2.webp)
         </Frame>
       </div>
  </Step>

  <Step title={<>ClickHouse 서비스 허용 목록에 <code>엔드포인트 ID</code>를 추가하십시오</>} id="step-5-add-endpoint-id-to-services-allow-list">
    1. ClickHouse Cloud 콘솔에서 PrivateLink를 통해 연결하려는 서비스의 설정 페이지로 이동합니다.
    2. &quot;프라이빗 엔드포인트 설정&quot;을 클릭합니다.
    3. 열린 플라이아웃에서 이전 단계에서 얻은 `Endpoint ID`를 입력하고, 필요한 경우 설명도 입력합니다.
    4. &quot;Create endpoint&quot;를 클릭합니다.

    <Note>
      기존 PrivateLink 연결에서의 액세스를 허용하려면 기존 엔드포인트 드롭다운 메뉴를 사용하십시오.
      드롭다운에는 동일한 인프라 내 서비스에 대한 기존 PrivateLink 연결이 표시됩니다.
    </Note>

    <div className="ch-image-md">
      <Frame>
        ![프라이빗 엔드포인트 필터](/images/cloud/security/aws-privatelink-pe-filters.webp)
      </Frame>
    </div>
  </Step>

  <Step title="PrivateLink로 인스턴스에 액세스" id="step-6-connect-via-privatelink">
    1. ClickHouse Cloud 콘솔에서 서비스의 설정 페이지로 이동하세요.
    2. &quot;프라이빗 엔드포인트 설정&quot;을 클릭하세요.
    3. 열린 플라이아웃에서 `DNS name`을 복사하세요.

       <div className="ch-image-md">
         <Frame>
           ![Private Endpoint DNS 이름](/images/cloud/security/aws-privatelink-pe-dns-name.webp)
         </Frame>
       </div>

       PrivateLink를 통한 ClickHouse 서비스 액세스는 다음 두 가지 수준에서 제어됩니다.

       1. **Istio 인가 정책(Authorization Policy)**: BYOC 인프라 내에서 ClickHouse가 관리하는 서비스 수준의 인가 정책입니다.
       2. **VPC 엔드포인트 보안 그룹**: VPC 엔드포인트에 연결된 보안 그룹이 VPC 내에서 해당 엔드포인트를 사용할 수 있는 리소스를 제어합니다.

       <Note>
         프라이빗 로드 밸런서의 &quot;Enforce inbound rules on PrivateLink traffic&quot; 기능은 비활성화되어 있으므로, 액세스는 Istio 인가 정책과 VPC 엔드포인트의 보안 그룹으로만 제어됩니다.
       </Note>
  </Step>
</Steps>
