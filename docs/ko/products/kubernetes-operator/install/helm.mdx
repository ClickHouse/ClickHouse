이 가이드에서는 Helm 차트를 사용해 ClickHouse Operator를 설치하는 방법을 안내합니다.

## 사전 요구 사항 {#prerequisites}

* Kubernetes 클러스터 v1.28.0 이상
* helm v3.0 이상
* 클러스터와 통신하도록 구성된 kubectl

## Helm 설치 {#install-helm}

Helm이 설치되어 있지 않다면:

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
```

설치 여부를 확인하세요:

```bash
helm version
```

## Operator 설치 {#install-the-operator}

<Note>
  기본적으로 Helm 차트는 웹훅이 활성화된 ClickHouse Operator를 배포하며, cert-manager가 설치되어 있어야 합니다.
</Note>

```bash
helm install cert-manager oci://quay.io/jetstack/charts/cert-manager -n cert-manager --create-namespace --set crds.enabled=true
```

### OCI Helm 리포지토리에서 {#from-oci-helm-repository}

최신 릴리스를 설치하세요

```bash
    helm install clickhouse-operator oci://ghcr.io/clickhouse/clickhouse-operator-helm \
       --create-namespace \
       -n clickhouse-operator-system
```

특정 Operator 버전 설치하기

```bash
    helm install clickhouse-operator oci://ghcr.io/clickhouse/clickhouse-operator-helm \
       --create-namespace \
       -n clickhouse-operator-system \
       --set manager.image.tag=<operator version>
```

### 로컬 차트에서 {#from-local-chart}

리포지토리를 복제한 후 로컬 차트에서 설치합니다:

```bash
git clone https://github.com/ClickHouse/clickhouse-operator.git
cd clickhouse-operator
helm install clickhouse-operator ./dist/chart
```

### 특정 네임스페이스 감시 {#watch-namespaces}

기본적으로 연산자는 모든 네임스페이스를 감시합니다. 감시 범위를 제한하려면 `controller.watchNamespaces`를 설정하세요.
각 항목은 템플릿으로 렌더링되므로 `{{ .Release.Namespace }}`는 릴리스 네임스페이스로 해석되며,
정적 네임스페이스와 함께 지정할 수 있습니다:

```yaml
controller:
  watchNamespaces:
    - "{{ .Release.Namespace }}"
    - team-a
```

명령줄에서 `--set`은 중괄호를 리스트 구문으로 해석하므로 `--set-json`(Helm v3.10 이상)을 사용하십시오:
`--set-json 'controller.watchNamespaces=["{{ .Release.Namespace }}"]'`.

네임스페이스 범위의 RBAC로 릴리스 네임스페이스만 감시하려면 다음과 같이 설정하십시오:

```yaml
controller:
  watchNamespaces:
    - "{{ .Release.Namespace }}"
rbac:
  namespaced: true
```

`rbac.namespaced: true`로 설정하면 manager의 권한이 릴리스 네임스페이스의 Role/RoleBinding으로 생성되므로,
다른 네임스페이스를 감시하려면 클러스터 범위의 RBAC(기본값)가 필요합니다.

### 구성 옵션 {#configuration-options}

고급 구성 옵션은 Helm 차트의 [values.yaml](https://github.com/ClickHouse/clickhouse-operator/blob/main/dist/chart/values.yaml) 파일을 참조하세요.
