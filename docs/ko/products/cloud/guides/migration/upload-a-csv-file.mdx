<Visibility for="humans">
  <View title="Cloud UI">
    ClickHouse Cloud에서는 파일을 손쉽게 가져올 수 있으며, 다음
    포맷을 지원합니다:

    | 포맷                              |
    | ------------------------------- |
    | `CSV`                           |
    | `CSVWithNamesAndTypes`          |
    | `CSVWithNames`                  |
    | `JSONEachRow`                   |
    | `TabSeparated`                  |
    | `TabSeparatedWithNames`         |
    | `TabSeparatedWithNamesAndTypes` |

    <Steps>
      <Step title="파일 업로드" id="upload-file">
        Cloud 홈페이지에서 아래와 같이 서비스를 선택하십시오:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_02](/images/cloud/migrate/csv_01.webp)
          </Frame>
        </div>

        서비스가 유휴 상태라면 먼저 서비스를 깨워야 합니다.

        아래와 같이 왼쪽 탭에서 `Data sources`를 선택하십시오:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_03](/images/cloud/migrate/csv_02.webp)
          </Frame>
        </div>

        다음으로 데이터 소스 페이지 오른쪽에서 `Upload a file`을 선택하십시오:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_04](/images/cloud/migrate/csv_03.webp)
          </Frame>
        </div>

        파일 대화 상자가 열리면 클라우드 서비스의 테이블에 삽입할 데이터가 담긴
        파일을 선택하십시오.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_04.webp)
          </Frame>
        </div>
      </Step>

      <Step title="테이블 구성" id="configure-table">
        파일 업로드가 완료되면 데이터를 삽입할 테이블을 구성할 수
        있습니다. 처음 3개 행으로 구성된 테이블 미리보기가 표시됩니다.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_08](/images/cloud/migrate/csv_08.webp)
          </Frame>
        </div>

        이제 대상 테이블(destination table)을 선택할 수 있습니다. 선택 가능한 옵션은 다음과 같습니다:

        * 새 테이블
        * 기존 테이블

        <br />

        데이터를 업로드할 데이터베이스를 지정할 수 있으며, 새 테이블을 선택한 경우
        생성할 테이블의 이름도 지정할 수 있습니다. 정렬 키도 선택할 수 있습니다:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_05.webp)
          </Frame>
        </div>

        파일에서 읽은 컬럼은 `Source field`로 표시되며, 각 필드에 대해 다음 항목을
        변경할 수 있습니다:

        * 추론된 데이터 타입(inferred type)
        * 기본값
        * 컬럼의 [널 허용(Nullable)](/ko/reference/data-types/nullable) 여부

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_06](/images/cloud/migrate/csv_06.webp)
          </Frame>
        </div>

        <Info>
          **필드 제외**

          가져오지 않으려는 필드는 제거할 수도 있습니다.
        </Info>

        사용할 테이블 엔진 유형을 지정할 수 있습니다:

        * `MergeTree`
        * `ReplacingMergeTree`
        * `SummingMergeTree`
        * `Null`

        <br />

        파티셔닝 키 표현식과 기본 키(primary key)
        표현식도 지정할 수 있습니다.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_07](/images/cloud/migrate/csv_07.webp)
          </Frame>
        </div>

        데이터를 가져오려면 `Import to ClickHouse`(위 그림 참조)를 클릭하십시오. 아래와 같이 데이터 가져오기 작업이 큐에 추가되며,
        `Status` 컬럼에 `queued` 상태 배지가 표시됩니다. `Open as query`(위 그림 참조)를 클릭하면 SQL 콘솔에서 삽입 쿼리(insert query)를 열 수도 있습니다. 이 쿼리는
        `URL` 테이블 함수를 사용하여 S3 버킷에 업로드된 파일을 삽입합니다.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_09](/images/cloud/migrate/csv_09.webp)
          </Frame>
        </div>

        작업이 실패하면 `Data upload history` 탭의 `Status` 컬럼에
        `failed` 상태 배지가 표시됩니다. 업로드 실패 원인을 자세히 확인하려면
        `View Details`를 클릭하십시오. 실패한 삽입의 오류 메시지에 따라 테이블 구성을 수정하거나
        데이터를 정리해야 할 수도 있습니다.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_11](/images/cloud/migrate/csv_10.webp)
          </Frame>
        </div>
      </Step>
    </Steps>
  </View>
