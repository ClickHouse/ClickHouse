이 문서는 별도의 제3자 모델 개발자 약관이 적용되는 ClickHouse Cloud의 모델을 나열합니다.
현재 사용되는 모든 모델은 해당 모델 개발자가 아니라 Amazon Bedrock에서 호스팅되고 있습니다.
단, [Claude Platform 연결 청구](/ko/products/cloud/features/ai-ml/linked-billing-claude-platform)는 예외입니다. Claude 조직이 연결되어 있는 동안에는 해당 조직의 Claude 모델 요청이 Amazon Bedrock이 아닌 Anthropic으로 전송됩니다.
이 링크는 편의를 위해 제공됩니다. 적용되는 모델 약관 및 관련 사용 정책의 컴플라이언스를 준수할 책임은 사용자에게 있습니다.
