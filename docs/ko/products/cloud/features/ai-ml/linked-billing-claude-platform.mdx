Claude Platform 연결 청구(Linked billing)를 사용하면 ClickHouse와 Anthropic을 모두 이용하는 고객은 [ClickHouse Agents](/ko/agents/index) 등 ClickHouse Cloud 제품 전반에서 발생하는 모든 Claude 모델 사용량을 자신의 Claude 조직으로 직접 청구받을 수 있습니다.

Claude Platform 연결 청구는 공개 미리 보기 단계이며 모든 ClickHouse Cloud 조직에서 사용할 수 있습니다.

Claude 조직을 ClickHouse Cloud 조직에 한 번만 연결하면 됩니다.
연결 이후에는 Anthropic이 ClickHouse Cloud 조직의 Claude 모델 사용량을 해당 Claude 조직의 요율과 기존 청구 약관에 따라 Claude 조직으로 청구합니다.
따라서 Anthropic과 체결한 약정 지출액이나 협상된 요율을 그대로 활용할 수 있습니다.

## 청구 방식 {#how-billing-works}

Claude 조직이 연결되어 있는 동안에는 다음과 같이 청구됩니다.

* Anthropic은 ClickHouse Cloud 조직에서 발생한 Claude 모델 사용량을 Claude 조직에 청구하며, 해당 금액은 선불 잔액에서 차감되거나 인보이스에 포함됩니다.
* Claude 조직의 요금과 Anthropic과 체결한 약정 지출액이 적용됩니다.
* 조직의 Claude 모델 요청은 Amazon Bedrock에서 호스팅되는 Claude 모델이 아닌 Anthropic으로 전송됩니다.

다음 사항에 유의하십시오.

* 연결 청구는 모든 ClickHouse Cloud 제품에서 발생하는 Claude 모델 사용량 전체에 적용됩니다.
* 조직에 Claude Platform 연결 청구가 활성화되면 ClickHouse Cloud에서는 Claude 모델만 사용할 수 있습니다.
* Claude 조직의 프로모션 크레딧은 연결 청구에 사용할 수 없습니다.
* 연결은 Claude 사용량의 청구 방식만 변경합니다. ClickHouse Cloud에서 Claude를 사용할 때 적용되는 약관이나 데이터 처리 방식은 변경되지 않습니다.
* 연결 시 ClickHouse Cloud를 통한 Claude 사용량에 월별 지출 한도를 설정할 수 있습니다. ClickHouse Cloud를 통해 발생한 지출이 한도에 도달하면 다음 달이 되거나 한도를 상향할 때까지 ClickHouse Cloud의 Claude 모델 요청이 중단됩니다.

Claude 조직을 연결하지 않으면 기존과 동일하게 ClickHouse Cloud의 Claude 모델은 계속 Amazon Bedrock에서 제공됩니다.

## 요구 사항 {#requirements}

* **HIPAA 또는 PCI DSS 컴플라이언스가 활성화되어 있지 않아야 합니다.** [HIPAA](/ko/products/cloud/reference/security/compliance-overview#hipaa-since-2024) 또는 [PCI DSS](/ko/products/cloud/reference/security/compliance-overview#pci-service-provider-since-2025) 컴플라이언스가 활성화된 ClickHouse Cloud 조직에서는 Claude Platform 연결 청구 기능을 사용할 수 없습니다.
* **청구를 연결할 수 있는 ClickHouse Cloud 역할이 필요합니다.** ClickHouse Cloud 조직에서 관리자 역할이 있어야 합니다.
* **청구를 승인할 수 있는 Claude 역할이 필요합니다.** Claude 조직에서 소유자, 관리자 또는 결제 역할이 있어야 합니다.
* **자격 요건을 충족하는 Claude 조직이 필요합니다.** Claude 조직은 선불 크레딧 또는 인보이스 청구 방식으로 API 사용 요금을 Anthropic에 직접 지불하고 있어야 합니다. 클라우드 마켓플레이스(AWS, Google Cloud 또는 Azure)를 통해 청구되는 Claude 조직이나 Claude 구독 플랜만 보유한 조직은 연결할 수 없습니다.

    **Link your Claude organization**을 클릭하십시오.

## Claude 콘솔에서 사용량 및 지출 모니터링 {#monitor-usage}

ClickHouse Cloud를 통한 Claude 사용으로 Claude 조직에 발생한 비용을 확인하려면 Claude 콘솔에서 [Linked platforms](https://platform.claude.com/linked-platforms)를 열고 **ClickHouse**를 선택하십시오. 이 페이지에는 다음 정보가 표시됩니다.

* 비용이 청구되는 Claude 조직, 연결 시점, 연결을 승인한 사용자
* **Spent this month**: 이번 달 ClickHouse Cloud를 통해 발생한 지출 금액입니다. 월별 지출 한도를 설정한 경우 해당 한도 대비 금액으로 표시됩니다. 한도는 매월 1일(UTC)에 초기화됩니다.
* **Link history**: 조직의 연결 및 연결 해제 시점과 각 작업을 수행한 사용자

이 페이지에서는 ClickHouse Cloud를 통한 Claude 사용의 월별 지출 한도를 설정, 상향 또는 제거하거나 ClickHouse 연결을 해제할 수도 있습니다.

Claude 콘솔의 [Spend limits](https://platform.claude.com/settings/billing#spend-limits)에서 설정한 Claude 조직 전체의 **월별 지출 한도**도 ClickHouse Cloud를 통한 Claude 사용에 적용됩니다.

## Claude 조직 연결 해제 {#unlink}

연결은 어느 쪽에서든 해제할 수 있으며, 해제하는 쪽에 따라 결과가 다릅니다.

### ClickHouse Cloud에서 연결 해제 {#unlink-in-clickhouse-cloud}

**조직 설정**의 **Claude organization** 섹션에서 **Unlink**를 클릭하십시오.
그러면 ClickHouse Cloud가 기본 동작으로 돌아갑니다. 조직의 Claude 모델 요청은 Amazon Bedrock에 호스팅된 Claude 모델로 전송되며, Claude 사용량은 더 이상 Claude 조직에 청구되지 않습니다.
기본 동작으로 돌아가려면 이 방법을 사용해야 합니다.

### Claude 콘솔에서 연결 해제 {#unlink-in-the-claude-console}

[Linked platforms](https://platform.claude.com/linked-platforms) 페이지에서 **ClickHouse**를 선택하고 **Unlink**를 클릭하십시오.
이후 ClickHouse Cloud는 더 이상 조직을 대신하여 Claude를 사용할 수 없으며, Anthropic은 ClickHouse Cloud를 통해 발생하는 새로운 Claude 사용량을 더 이상 Claude 조직에 청구하지 않습니다.

<Warning>
  Claude 콘솔에서 연결을 해제해도 ClickHouse Cloud가 기본 동작으로 돌아가지는 않습니다.
  다시 연결하거나 ClickHouse Cloud **조직 설정**에서 명시적으로 연결을 해제하기 전까지는 ClickHouse Cloud 조직에서 보내는 Claude 모델 요청이 모두 실패합니다.
  예를 들어 ClickHouse Agents는 `The model provider could not complete this request (status 403).`라고 응답합니다.
</Warning>

<div className="ch-image-md">
  <Frame>
    ![The model provider could not complete this request (status 403) 오류가 표시된 ClickHouse Agents 채팅](/images/cloud/linked-billing-claude-platform/08-agents-403-error.webp)
  </Frame>
</div>

이후 ClickHouse Cloud **조직 설정**의 **Claude organization** 섹션에 `The link was removed on the Claude side, or your Claude organization cannot be billed directly. Relink to continue.` 메시지가 표시됩니다.

<div className="ch-image-md">
  <Frame>
    ![Claude 측에서 연결이 해제되었다는 경고와 Relink 및 Unlink 버튼이 표시된 Claude organization 섹션](/images/cloud/linked-billing-claude-platform/06-link-removed.webp)
  </Frame>
</div>

계속하려면 다음 중 하나를 수행하십시오.

* Claude 사용량을 계속 Claude 조직에 청구하려면 **Relink**를 클릭하고 [연결 단계](#link-your-claude-organization)를 다시 진행하십시오.
* 기본 동작으로 돌아가려면 **Unlink**를 클릭하십시오. 기본 동작에서는 Claude 모델 요청이 Amazon Bedrock에서 호스팅되는 Claude 모델로 전달됩니다.
