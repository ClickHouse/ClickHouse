공개 미리 보기 기능은 대부분 완성된 ClickHouse Cloud 기능으로, 정식 출시(일반 제공, GA)를 앞두고 있습니다. 고객 피드백을 수렴하기 위해 제공되며, 아직 베타 단계에는 이르지 않았습니다.

<Warning>
  공개 미리 보기 기능은 변경될 수 있으며, 표준 ClickHouse Cloud SLA가 적용되지 않습니다.
</Warning>

## 공개 미리 보기 활성화 {#enable-public-preview}

1. 클라우드 콘솔에 로그인한 후 해당 조직을 선택하십시오.
2. 조직 메뉴를 열고 **Preview features**를 선택하십시오. 조직 사이드바에서도 이 메뉴로 이동할 수 있습니다.
3. 사용하려는 기능을 찾아 **Learn more**를 선택하여 요구 사항과 제한 사항을 확인한 다음, 스위치를 켜십시오. 스위치가 비활성화되어 있으면 조직 관리자에게 기능 활성화를 요청하십시오.
4. **Go to...** 또는 **View in...** 서비스 링크가 제공되는 경우 이 링크를 통해 기능을 바로 사용할 수 있습니다.

<Note>
  사용 가능 여부는 조직의 액세스 권한과 기능의 롤아웃 상태에 따라 달라집니다. 모든 공개 미리 보기가 모든 조직에 제공되는 것은 아닙니다. 액세스 권한을 확인하려면 [Cloud 지원](https://clickhouse.com/support/program)에 문의하십시오.
</Note>
