ClickHouse Cloud는 전송되는 데이터의 인바운드와 아웃바운드 트래픽을 계량합니다.
여기에는 ClickHouse Cloud로 들어오고 나가는 모든 데이터와 동일 리전 내
및 리전 간 데이터 전송이 포함됩니다. 이 사용량은 서비스 수준에서 추적됩니다. 이
사용량을 기준으로 고객에게 데이터 전송 요금이 부과되며, 해당 금액은 월별 청구서에
추가됩니다.

ClickHouse Cloud는 다음 항목에 대해 요금을 부과합니다.

* ClickHouse Cloud에서 퍼블릭 인터넷으로 나가는 데이터 아웃바운드 트래픽. 여기에는 다른
  클라우드 제공업체의 다른 리전으로 전송되는 경우도 포함됩니다.
* 동일한 클라우드 제공업체 내 다른 리전으로 나가는 데이터 아웃바운드 트래픽.

동일 리전 내 데이터 전송이나 Private Link/Private
Service Connect 사용 및 데이터 전송에는 요금이 부과되지 않습니다. 다만, 사용자에게
적절하게 요금을 부과하는 데 영향을 미치는 사용 패턴이 확인될 경우, 추가적인
데이터 전송 요금 기준을 도입할 권리를 보유합니다.

참고: Private Link/Private Service Connect 사용에는 Cloud Service Provider(CSP) 요금이 적용됩니다. 최신 정보는 CSP의 가격 페이지를 참조하십시오.

데이터 전송 요금은 Cloud Service Provider(CSP)와 리전에 따라 달라집니다.
퍼블릭 인터넷 아웃바운드 트래픽 요금은 출발 리전만을 기준으로 산정됩니다.
리전 간(또는 교차 리전) 요금은 출발 리전과 대상
리전 모두에 따라 달라집니다.

## Managed Postgres {#managed-postgres}

ClickHouse Managed Postgres의 퍼블릭 인터넷 및 리전 간 데이터 아웃바운드 트래픽에는 이 페이지에 안내된 요금이 청구됩니다. 데이터 전송은 대상 IP가 클라우드 제공업체에서 공개한 IP 범위에 속하는지에 따라 분류됩니다. 대상 IP가 해당 리전의 공개 IP 범위에 속하지 않으면, 대상이 동일한 클라우드 제공업체에 호스팅되어 있더라도 해당 트래픽은 퍼블릭 인터넷 아웃바운드 트래픽으로 계량됩니다. 자체 IP 블록(BYOIP)을 사용하는 피어가 대표적인 예입니다. 이러한 피어에 연결하는 경우 분류를 검토할 수 있도록 [지원팀](https://clickhouse.com/support/program)에 문의하십시오.

Managed Postgres에서 ClickHouse Cloud로 데이터를 복제하는 데 사용되는 [ClickPipes](/ko/products/managed-postgres/clickpipes) 컴퓨트는 무료입니다. Managed Postgres에서 ClickPipes로 나가는 아웃바운드 트래픽은 다른 데이터 전송과 동일한 방식으로 계량됩니다. 두 서비스가 동일 리전에 있으면 요금이 부과되지 않습니다. 리전 간 복제에는 해당 리전 간 요금제 등급의 요금이, 다른 클라우드 제공업체의 ClickHouse Cloud 서비스로 복제하는 경우에는 퍼블릭 인터넷 요금이 청구됩니다.

데이터 전송 비용을 줄이려면 가능한 한 애플리케이션과 Managed Postgres를 동일한 클라우드 제공업체의 동일 리전에 배치하십시오.

**데이터 전송 비용을 최소화하기 위한 모범 사례**

데이터를 인바운드 또는 아웃바운드 트래픽으로 전송할 때
데이터 전송 비용을 최소화하기 위해 염두에 두어야 할 몇 가지 패턴이 있습니다.

1. ClickHouse Cloud로 데이터를 보내거나 외부로 내보낼 때는 가능한 경우
   Compression을 사용하여 전송되는 데이터 양과 그에 따른 비용을 최소화하십시오.

2. 네이티브 프로토콜을 통해 비인라인 값으로 INSERT를 수행할 때
   (예: `INSERT INTO [TABLE] FROM INFILE [FILE] FORMAT NATIVE`), ClickHouse
   클라이언트는 데이터를 패킹하기 위해 서버에서 메타데이터를 가져옵니다. 메타데이터가
   `INSERT` payload보다 크면, 직관과 달리 서버 관점에서는
   인바운드보다 아웃바운드 트래픽이 더 크게 보일 수 있습니다. 이를 허용할 수 없다면,
   `VALUES` 구문으로 데이터를 인라인하거나 HTTP protocol을 사용하는 방안을
   고려하십시오.

아래 표는 클라우드 제공업체와 리전에 따라, 퍼블릭
인터넷 또는 교차 리전으로의 아웃바운드 트래픽에 대한 데이터 전송 요금이 어떻게 달라지는지 보여줍니다.

<Note>
  ClickHouse Cloud는 출발 리전과
  대상 리전에 따라 요금제 등급 1부터 요금제 등급 4까지의 요금제 등급 기준으로 리전 간 사용량을 계량합니다.
  아래 표는 리전 간 데이터 전송의 각 조합에 대한 요금제 등급을 보여줍니다. ClickHouse Cloud의 Billing usage
  화면에서는 데이터 전송 사용량이 요금제 등급별로 구분되어 표시됩니다.
</Note>
