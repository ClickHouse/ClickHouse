PAYG(사용량 기반 과금) Public Offer를 통해 [Azure Marketplace](https://azuremarketplace.microsoft.com/en-us/marketplace/apps)에서 ClickHouse Cloud를 시작하세요.

## 사전 요구 사항 {#prerequisites}

* 청구 관리자가 구매 권한을 활성화한 Azure 프로젝트가 필요합니다.
* Azure Marketplace에서 ClickHouse Cloud를 구독하려면 구매 권한이 있는 계정으로 로그인한 후 적절한 프로젝트를 선택해야 합니다.

1. [Azure Marketplace](https://azuremarketplace.microsoft.com/en-us/marketplace/apps)로 이동하여 ClickHouse Cloud를 검색하십시오. 마켓플레이스에서 상품을 구매하려면 로그인되어 있어야 합니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-1.webp)
  </Frame>
</div>

<br />

2. 제품 목록 페이지에서 **Get It Now**를 클릭하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-2.webp)
  </Frame>
</div>

<br />

3. 다음 화면에서 이름, 이메일, 위치 정보를 입력해야 합니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-3.webp)
  </Frame>
</div>

<br />

4. 다음 화면에서 **Subscribe**를 클릭하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-4.webp)
  </Frame>
</div>

<br />

5. 다음 화면에서 구독(subscription), 리소스 그룹, 리소스 그룹 위치를 선택하십시오. 리소스 그룹 위치가 ClickHouse Cloud에서 서비스를 시작하려는 위치와 같을 필요는 없습니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-5.webp)
  </Frame>
</div>

<br />

6. 또한 구독 이름을 입력하고 제공되는 옵션 중에서 청구 기간을 선택해야 합니다. **Recurring billing**은 켜거나 끌 수 있습니다. &quot;off&quot;로 설정하면 청구 기간이 끝날 때 계약이 종료되고 리소스가 해제됩니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-6.webp)
  </Frame>
</div>

<br />

7. **&quot;Review + subscribe&quot;**&#xB97C; 클릭하십시오.

8. 다음 화면에서 모든 내용이 올바른지 확인한 후 **Subscribe**를 클릭하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-7.webp)
  </Frame>
</div>

<br />

9. 이 시점에서는 ClickHouse Cloud의 Azure 구독에 가입한 상태일 뿐, 아직 ClickHouse Cloud에서 계정을 설정하지는 않았습니다. ClickHouse Cloud가 Azure 구독에 바인드되어 Azure 마켓플레이스를 통해 청구가 올바르게 이루어지려면 이후 단계를 반드시 진행해야 합니다.

<br />

<div className="ch-image-md">

  </Frame>
</div>

<br />

10. Azure 설정이 완료되면 **Configure account now** 버튼이 활성화됩니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-9.webp)
  </Frame>
</div>

<br />

11. **Configure account now**를 클릭하십시오.

<br />

아래와 같이 계정 구성 방법이 안내된 이메일을 받게 됩니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-10.webp)
  </Frame>
</div>

<br />

12. ClickHouse Cloud 가입 또는 로그인 페이지로 리디렉션됩니다. ClickHouse Cloud로 이동한 후 기존 계정으로 로그인하거나 새 계정으로 가입할 수 있습니다. 이 단계는 ClickHouse Cloud 조직을 Azure Marketplace 청구에 바인드하는 데 매우 중요합니다.

13. 신규 사용자라면 비즈니스에 관한 몇 가지 기본 정보도 입력해야 합니다. 아래 스크린샷을 참조하십시오.

<br />

<div className="ch-image-md">

  </Frame>
</div>

<br />
