약정형 계약을 통해 [AWS Marketplace](https://aws.amazon.com/marketplace)에서 ClickHouse Cloud를 시작하세요.
약정형 계약은 Private Offer라고도 하며, 고객이 일정 기간 동안 ClickHouse Cloud에 일정 금액을 지출하기로 약정할 수 있도록 합니다.

<div id="prerequisites">
  ## 사전 요구 사항 {#prerequisites}
</div>

* 특정 계약 약관에 따른 ClickHouse의 Private Offer.
* ClickHouse 조직을 약정 지출 오퍼에 연결하려면 해당 조직의 관리자여야 합니다.

AWS에서 약정형 계약을 조회하고 수락하는 데 필요한 권한:

* AWS 관리형 정책을 사용하는 경우 다음 권한이 필요합니다:
  * `AWSMarketplaceRead-only`, `AWSMarketplaceManageSubscriptions`
  * 또는 `AWSMarketplaceFullAccess`
* AWS 관리형 정책을 사용하지 않는 경우 다음 권한이 필요합니다:
  * IAM 작업 `aws-marketplace:ListPrivateListings` 및 `aws-marketplace:ViewSubscriptions`

## 가입 단계 {#steps-to-sign-up}

<Steps>
  <Step title="비공개 제안 수락" id="private-offer-accept">
    비공개 제안을 검토하고 수락할 수 있는 링크가 포함된 이메일을 받으셨을 것입니다.

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace 비공개 제안 이메일](/images/cloud/reference/mp_committed_spend_1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="제안 검토 링크" id="review-offer-link">
    이메일에서 Review Offer 링크를 클릭하십시오.
    비공개 제안 세부 정보가 표시된 AWS Marketplace 페이지로 이동합니다.
  </Step>

  <Step title="계정 설정" id="setup-your-account">
    AWS 포털에서 구독 절차를 완료한 후 **&quot;계정을 설정하세요&quot;**&#xB97C; 클릭하십시오.
    이 시점에서 반드시 ClickHouse Cloud로 리디렉션되어 새 계정을 등록하거나 기존 계정으로 로그인해야 합니다.
    이 단계를 완료하지 않으면 AWS Marketplace 계약을 ClickHouse Cloud에 연결할 수 없습니다.

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace 비공개 제안 이메일](/images/cloud/reference/mp_committed_spend_2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Cloud에 로그인" id="login-cloud">
    ClickHouse Cloud로 리디렉션되면 기존 계정으로 로그인하거나 새 계정을 등록할 수 있습니다.
    이 단계는 ClickHouse Cloud 조직을 AWS Marketplace 청구에 바인드하는 데 필요합니다.

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace 비공개 제안 이메일](/images/cloud/reference/mp_committed_spend_3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="신규 사용자 등록" id="register">
    ClickHouse Cloud 신규 사용자라면 페이지 하단의 &quot;Register&quot;를 클릭하십시오.
    새 사용자를 생성하고 이메일을 인증하라는 안내가 표시됩니다.
    이메일 인증 후에는 ClickHouse Cloud 로그인 페이지를 닫고 [https://console.clickhouse.cloud](https://console.clickhouse.cloud)에서 새 사용자 이름으로 로그인할 수 있습니다.

    신규 사용자는 비즈니스에 관한 몇 가지 기본 정보도 입력해야 합니다.
    아래 스크린샷을 참고하십시오.

    <div className="ch-image-md">
      <Frame>
        ![비즈니스 정보 입력](/images/cloud/reference/mp_committed_spend_4.png)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![비즈니스 정보 입력](/images/cloud/reference/mp_committed_spend_5.png)
      </Frame>
    </div>

    기존 ClickHouse Cloud 사용자라면 기존 자격 증명으로 로그인하면 됩니다.
  </Step>

  <Step title="청구할 조직 생성 또는 선택" id="create-select-org-to-bill">
    로그인에 성공하면 이 마켓플레이스 계약으로 청구할 조직을 새로 생성할지, 기존 조직을 선택할지 결정할 수 있습니다.

    <div className="ch-image-md">
      <Frame>
        ![이 구독으로 청구할 조직 생성 또는 선택](/images/cloud/reference/mp_committed_spend_6.webp)
      </Frame>
    </div>

    이 단계를 완료하면 조직이 AWS 약정 지출 계약에 연결되며, 모든 사용량은 AWS 계정을 통해 청구됩니다.
    ClickHouse UI에서 조직의 결제 페이지를 열어 청구가 AWS Marketplace에 정상적으로 연결되었는지 확인할 수 있습니다.

    <div className="ch-image-md">
      <Frame>
        ![설정 완료 확인](/images/cloud/reference/mp_committed_spend_7.webp)
      </Frame>
    </div>

    문제가 발생하면 언제든지 [지원팀](https://clickhouse.com/support/program)에 문의하십시오.
  </Step>
</Steps>
