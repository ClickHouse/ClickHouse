[AWS Marketplace](https://aws.amazon.com/marketplace)에서 PAYG(사용량 기반 과금) Public Offer를 통해 ClickHouse Cloud를 시작하세요.

<div id="prerequisites">
  ## 사전 요구 사항 {#prerequisites}
</div>

* 청구 관리자가 구매 권한을 활성화한 AWS 계정.
* 구매하려면 이 계정으로 AWS Marketplace에 로그인한 상태여야 합니다.
* ClickHouse 조직을 subscription에 연결하려면 해당 조직의 관리자여야 합니다.

## 가입 단계 {#steps-to-sign-up}

<Steps>
  <Step title="ClickHouse Cloud - Pay as you go 검색" id="search-payg">
    [AWS Marketplace](https://aws.amazon.com/marketplace)로 이동하여 &quot;ClickHouse Cloud - Pay As You Go&quot;를 검색하십시오.

    <div className="ch-image-lg">
      <Frame>
        ![AWS Marketplace에서 ClickHouse 검색](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="구매 옵션 보기" id="purchase-options">
    [제품 페이지](https://aws.amazon.com/marketplace/pp/prodview-p4gwofrqpkltu)를 클릭한 다음 **구매 옵션 보기**를 클릭하십시오.

    <div className="ch-image-lg">
      <Frame>
        ![AWS Marketplace 구매 옵션 보기](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="구독" id="subscribe">
    다음 화면에서 구독을 클릭하십시오.

    <div className="ch-image-lg">
      <Frame>
        ![AWS Marketplace 구독](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="계정 설정" id="set-up-your-account">
    이 시점에서는 아직 설정이 완료되지 않았으며, ClickHouse Cloud 조직의 요금도 아직 마켓플레이스를 통해 청구되지 않습니다. 마켓플레이스 subscription에서 계정을 설정하세요를 클릭하여 ClickHouse Cloud로 이동한 다음 설정을 완료해야 합니다.

    <div className="ch-image-lg">
      <Frame>
        ![계정을 설정하세요](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-4.webp)
      </Frame>
    </div>

    ClickHouse Cloud로 리디렉션되면 기존 계정으로 로그인하거나 새 계정으로 가입할 수 있습니다. 이 단계는 ClickHouse Cloud 조직을 AWS Marketplace 결제와 연동하기 위한 것이므로 매우 중요합니다.

    <Info>
      **신규 ClickHouse Cloud 사용자**

      신규 ClickHouse Cloud 사용자라면 아래 단계를 따르십시오.
    </Info>

    <Accordion title="신규 사용자를 위한 단계">
      신규 ClickHouse Cloud 사용자라면 페이지 하단의 Register를 클릭하십시오. 새 사용자를 생성하고 이메일을 인증하라는 안내가 표시됩니다. 이메일 인증을 마친 후에는 ClickHouse Cloud 로그인 페이지를 닫고 https://console.clickhouse.cloud 에서 새 사용자 이름으로 로그인하면 됩니다.

      <div className="ch-image-md">
        <Frame>
          ![ClickHouse Cloud 가입](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-5.webp)
        </Frame>
      </div>

      <Info>
        **신규 사용자**

        비즈니스에 대한 몇 가지 기본 정보도 입력해야 합니다. 아래 스크린샷을 참조하십시오.
      </Info>

      <div className="ch-image-md">
        <Frame>
          ![시작하기 전에](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
        </Frame>
      </div>

      <div className="ch-image-md">
        <Frame>
          ![시작하기 전에(계속)](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
        </Frame>
      </div>
    </Accordion>

    기존 ClickHouse Cloud 사용자라면 기존 자격 증명으로 로그인하기만 하면 됩니다.
  </Step>

  <Step title="조직에 마켓플레이스 구독 추가" id="add-marketplace-subscription">
    로그인하면 이 마켓플레이스 subscription으로 요금을 청구할 새 조직을 생성하거나, 기존 조직을 선택하여 이 subscription으로 청구되도록 할 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![마켓플레이스 subscription 추가](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
      </Frame>
    </div>

    새 ClickHouse 계정을 등록하는 경우 자동으로 생성된 기본 조직이 표시되며, 이 조직에 마켓플레이스 subscription을 연결할 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![기본 조직을 AWS Marketplace subscription에 연결](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-13.webp)
      </Frame>
    </div>

    이 단계를 완료하면 조직이 해당 AWS subscription에 연결되며, 모든 사용량은 AWS 계정을 통해 청구됩니다.

    ClickHouse UI의 조직 결제 페이지에서 청구가 AWS Marketplace에 정상적으로 연결되었는지 확인할 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![결제 페이지 확인](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-9.webp)
      </Frame>
    </div>
  </Step>
</Steps>
