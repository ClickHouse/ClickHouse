약정 계약을 통해 [GCP Marketplace](https://console.cloud.google.com/marketplace)에서 ClickHouse Cloud를 시작하세요. 약정 계약은 Private Offer라고도 하며, 고객이 일정 기간 동안 ClickHouse Cloud에 일정 금액을 지출하기로 약정할 수 있도록 합니다.

<div id="prerequisites">
  ## 사전 요구 사항 {#prerequisites}
</div>

* 특정 계약 약관을 기반으로 한 ClickHouse의 Private Offer.

## 가입 단계 {#steps-to-sign-up}

1. 비공개 제안을 검토하고 수락할 수 있는 링크가 포함된 이메일을 받으셨을 것입니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 비공개 제안 이메일](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-1.webp)
  </Frame>
</div>

<br />

2. 이메일에서 **Review Offer** 링크를 클릭하십시오. 비공개 제안 세부 정보가 표시된 GCP Marketplace 페이지로 이동합니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 제안 요약](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-2.webp)
  </Frame>
</div>

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 요금 요약](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-3.webp)
  </Frame>
</div>

<br />

3. 비공개 제안 세부 정보를 검토하고 모든 내용이 올바르면 **Accept**를 클릭하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 수락 페이지](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-4.webp)
  </Frame>
</div>

<br />

4. **Go to product page**를 클릭하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 수락 확인](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-5.webp)
  </Frame>
</div>

<br />

5. **Manage on provider**를 클릭하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace ClickHouse Cloud 페이지](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-6.webp)
  </Frame>
</div>

<br />

이 시점에서 반드시 ClickHouse Cloud로 이동하여 가입하거나 로그인해야 합니다. 이 단계를 완료하지 않으면 GCP Marketplace 구독을 ClickHouse Cloud에 연결할 수 없습니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 웹사이트 이탈 확인 모달 대화 상자](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-7.webp)
  </Frame>
</div>

<br />

6. ClickHouse Cloud로 리디렉션되면 기존 계정으로 로그인하거나 새 계정을 등록할 수 있습니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 로그인 페이지](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
  </Frame>
</div>

<br />

ClickHouse Cloud를 처음 사용하는 경우 페이지 하단의 **Register**를 클릭하십시오. 새 사용자를 생성하고 이메일을 인증하라는 안내가 표시됩니다. 이메일 인증을 마친 후에는 ClickHouse Cloud 로그인 페이지를 벗어나 [https://console.clickhouse.cloud](https://console.clickhouse.cloud)에서 새 사용자 이름으로 로그인할 수 있습니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 페이지](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
  </Frame>
</div>

<br />

신규 사용자는 비즈니스에 관한 몇 가지 기본 정보도 입력해야 합니다. 아래 스크린샷을 참고하십시오.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 가입 정보 양식](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
  </Frame>
</div>

<br />

기존 ClickHouse Cloud 사용자는 기존 자격 증명으로 로그인하면 됩니다.

7. 로그인에 성공하면 새 ClickHouse Cloud 조직이 생성됩니다. 이 조직은 GCP 결제 계정에 연결되며, 모든 사용량은 GCP 계정을 통해 청구됩니다.

8. 로그인한 후 청구가 실제로 GCP Marketplace에 연결되어 있는지 확인하고 ClickHouse Cloud 리소스 설정을 시작할 수 있습니다.

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 로그인 페이지](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-5.webp)
  </Frame>
</div>

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 새 서비스 페이지](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-11.webp)
  </Frame>
</div>

<br />

9. 가입 확인 이메일이 발송됩니다.

<br />

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 확인 이메일](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-6.webp)
  </Frame>
</div>

<br />

<br />

문제가 발생하면 언제든지 [지원팀](https://clickhouse.com/support/program)에 문의하십시오.
