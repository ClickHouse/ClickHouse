공식 C# 클라이언트는 HTTP 또는 네이티브 TCP 프로토콜을 통해 ClickHouse에 연결합니다.
두 클라이언트 모두 `ClickHouse.Driver` NuGet 패키지로 제공됩니다.

## HTTP {#http}

HTTP 클라이언트는 상위 수준의 스레드 안전 `ClickHouseClient` API와 ORM에서 사용하는 ADO.NET API를 제공합니다.
.NET 6.0 이상을 대상으로 하며 대부분의 애플리케이션에 권장됩니다.

다음 기능이 필요하면 HTTP 클라이언트를 사용하세요.

* ADO.NET 또는 ORM;
* CSV, JSONEachRow, Parquet 또는 원시 스트림의 입력과 출력;
* bearer 인증 또는 사용자 정의 HTTP 헤더;
* 사용자 정의 매개변수 유형 결정, 매개변수 포맷 지정 또는 읽기 변환;
* 쿼리별 데이터베이스 또는 역할;
* 향상된 `JSON` 처리 성능. TCP 클라이언트는 `JSON` 값을 텍스트로만 전송할 수 있습니다.

[HTTP 클라이언트 문서 읽기](./http).

## Native TCP {#native-tcp}

네이티브 TCP 클라이언트는 실험적 기능이며, 공개 API는 향후 릴리스에서 변경될 수 있습니다. 이 클라이언트는
열 지향 블록 읽기, 네이티브 압축, 풀링된 연결, 고정 세션을 지원하는 `ClickHouseTcpClient` API를 제공하며,
.NET 8.0 이상을 대상으로 합니다.

다음과 같은 기능이 필요하다면 네이티브 TCP 클라이언트를 사용하세요.

* 더 나은 성능(특히 데이터를 컬럼 단위로 처리할 때)
* 열 지향 데이터 블록
* 지속 연결
* `OpenSessionAsync`를 통한 고정 세션
* 진행 상황, 프로필, 로그, 합계, 극값 콜백
* ClickHouse로의 W3C 추적 컨텍스트 전파

[네이티브 TCP 클라이언트 문서 보기](./tcp).
