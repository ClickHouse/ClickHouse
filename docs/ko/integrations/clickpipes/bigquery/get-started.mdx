## 사전 요구 사항 {#pre-requisites}

* GCP 프로젝트에서 [서비스 계정](https://docs.cloud.google.com/iam/docs/service-account-overview) 및 [IAM 역할](https://docs.cloud.google.com/iam/docs/roles-overview)을 관리할 수 있는 권한이 있어야 합니다. 해당 권한이 없으면 관리자에게 지원을 요청하십시오. [공식 문서](https://docs.cloud.google.com/iam/docs/service-accounts-create)를 참고하여 필요한 최소한의 [권한](/ko/integrations/clickpipes/bigquery/overview#permissions)만 부여된 전용 서비스 계정을 생성하는 것이 좋습니다.

* 초기 적재에는 스테이징용 Google Cloud Storage (GCS) 버킷이 필요합니다. [Google Cloud 안내](https://docs.cloud.google.com/storage/docs/creating-buckets)를 참고하여 ClickPipe 전용 버킷을 생성하는 것이 좋습니다.

* 지속적 복제를 사용하려면 프로젝트에서 서비스 계정에 [BigQuery Read Session User 역할](/ko/integrations/clickpipes/bigquery/overview#bigquery)을 부여하십시오. 테이블을 선택하기 전에 [복제 방식의 요구 사항](/ko/integrations/clickpipes/bigquery/overview#cdc)을 확인하십시오.

<Steps>
  <Step title="데이터 소스를 선택하세요" id="1-select-the-data-source">
    **1.** ClickHouse Cloud의 기본 탐색 메뉴에서 **Data sources**를 선택한 후 **Create ClickPipe**를 클릭하십시오.

    <Image img="/images/integrations/data-ingestion/clickpipes/cp_step0.webp" alt="가져오기 선택" size="lg" border />

    **2.** **BigQuery** 타일을 클릭하십시오.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/cp_step1.webp" alt="BigQuery 타일 선택" size="lg" border />
  </Step>

  <Step title="ClickPipe 연결을 설정하세요" id="2-setup-your-clickpipe-connection">
    BigQuery 프로젝트의 연결 정보를 입력하세요. 초기 적재를 실행하는 경우 스테이징용 GCS 버킷도 지정하세요.

    **1.** ClickPipes용으로 생성한 서비스 계정의 `.json` 키를 업로드하세요. 서비스 계정에 [필요한 최소 권한](/ko/integrations/clickpipes/bigquery/overview#permissions)이 부여되어 있는지 확인하세요.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/cp_step2.webp" alt="서비스 계정 키 업로드" size="lg" border />

    **2.** **복제 모드**로 [초기 적재만](/ko/integrations/clickpipes/bigquery/overview#initial-load), **초기 적재 + CDC**, **CDC만** 중 하나를 선택하세요. CDC 모드를 선택한 경우 [쿼리 기반 또는 이벤트 기반 방식](/ko/integrations/clickpipes/bigquery/overview#cdc)을 선택하세요.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/select-replication-mode.png" alt="BigQuery 복제 모드 옵션: 초기 적재만, 초기 적재 + CDC, CDC만" size="lg" border />

    **3.** 초기 적재를 실행하는 경우 스테이징 데이터용 GCS 버킷 경로를 입력하세요.

    **4.** **다음**을 클릭하여 입력한 정보를 검사하세요.
  </Step>

  <Step title="ClickPipe를 설정하세요" id="3-configure-your-clickpipe">
    선택한 단계에 해당하는 값을 다음과 같이 설정하세요. 초기 적재 설정은 ClickPipe가 기존 데이터를 가져올 때만 적용되고, CDC 설정은 이후 변경 사항을 계속 복제할 때만 적용됩니다.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/configure-pipe.png" alt="동기화 간격, 초기 적재, CDC에 대한 BigQuery ClickPipe 설정" size="lg" border />

    | 설정                     | 제어하는 항목                                                                                                                                                                                                            |
    | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
    | 동기화 간격(초)              | ClickPipes가 각 원본 테이블의 새 변경 사항을 확인하는 주기입니다.                                                                                                                                                                         |
    | 초기 적재 병렬 스레드 수         | ClickPipes가 한 테이블에서 동시에 적재할 수 있는 파트의 최대 수입니다.                                                                                                                                                                      |
    | 스냅샷의 파티션당 행 수          | 초기 적재 시 각 파트의 목표 행 수입니다. 테이블이 크면 ClickPipes가 이 값을 조정할 수 있습니다.                                                                                                                                                      |
    | 스냅샷의 병렬 테이블 수          | ClickPipes가 동시에 적재할 수 있는 원본 테이블의 최대 수입니다.                                                                                                                                                                          |
    | CDC의 병렬 테이블 수          | ClickPipes가 동시에 읽어 ClickHouse로 전송할 수 있는 테이블의 최대 수입니다.                                                                                                                                                              |
    | CDC 안전 여유 시간(초)        | 각 CDC 쿼리의 종료 시점을 현재 BigQuery 시간보다 얼마나 앞당길지 지정합니다. 최근에 기록된 데이터를 ClickPipes가 읽기 전에 사용할 수 있게 될 시간을 확보하기 위한 설정입니다.                                                                                                     |
    | CDC 단일 쿼리의 최대 시간 범위(초) | CDC 쿼리 하나가 처리하는 최대 시간 범위입니다. ClickPipes는 더 긴 기간을 여러 쿼리로 나눕니다. 이벤트 기반 복제에서는 BigQuery의 [1일 제한](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions)에 맞춰 이 값을 86,400초 이하로 유지하세요. |
  </Step>

  <Step title="테이블 구성" id="4-configure-tables">
    **1.** BigQuery 테이블이 복제될 ClickHouse 데이터베이스를 선택하세요. 기존 데이터베이스를 선택하거나 새로 만들 수 있습니다.

    **2.** 원본 테이블을 선택하세요. 각 대상 테이블의 이름을 변경하고 **컬럼 설정**에서 복제할 컬럼을 선택할 수 있습니다. 목록에는 서비스 계정이 접근할 수 있는 데이터세트만 표시됩니다.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/select-table-settings.png" alt="BigQuery 원본 테이블을 선택하고 대상 테이블 이름, CDC 워터마크, 정렬 키, 고급 설정을 구성합니다" size="lg" border />

    **3.** 각 테이블의 CDC 옵션을 설정하세요. 스크린샷에는 쿼리 기반 설정이 표시되어 있습니다. `TIMESTAMP` 타입의 **CDC 워터마크 컬럼**을 선택해 복제할 컬럼에 포함하고, 행이 변경될 때마다 해당 컬럼의 값을 갱신하세요. 이벤트 기반 복제에서는 대신 [`APPENDS`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#appends) 또는 [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes)를 선택하세요. [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes)를 사용하려면 원본 테이블에 `enable_change_history = TRUE`가 설정되어 있어야 합니다.

    **4.** **정렬 키**를 확인하세요. 행이 갱신되거나 삭제될 수 있다면 각 행을 식별할 수 있는, 값이 변하지 않는 컬럼을 선택하세요. [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes)를 사용하려면 원본 테이블에 기본 키가 있거나 여기서 정렬 키를 설정해야 합니다. ClickHouse는 정렬 키를 기준으로 데이터를 정렬해 쿼리에 활용합니다. 정렬 키가 없으면 `tuple()`을 사용하며 프라이머리 인덱스가 생성되지 않습니다.

    **5.** **고급 설정**을 열어 ClickHouse 테이블의 **엔진**이나 초기 적재에 사용할 선택적 파티셔닝 키를 지정하세요. 여기서 지정하는 파티셔닝 키는 대상 테이블의 `PARTITION BY` 표현식을 설정하지 않습니다.
  </Step>

  <Step title="권한 설정" id="6-configure-permissions">
    마지막으로 ClickPipes 내부 사용자의 권한을 설정할 수 있습니다.

    **권한:** ClickPipes는 대상 테이블에 데이터를 쓰는 전용 사용자를 생성합니다. 이 내부 사용자에게 custom 역할이나 사전 정의된 역할 중 하나를 지정할 수 있습니다.

    * `Full access`: 클러스터에 대한 전체 액세스 권한을 부여합니다. 대상 테이블에 materialized view 또는 딕셔너리를 사용하는 경우 필요합니다.
    * `Only destination`: 대상 테이블에 대한 삽입 권한만 부여합니다.
  </Step>

  <Step title="설정을 완료하세요" id="7-complete-setup">
    **Create ClickPipe**를 클릭하여 설정을 완료하세요. 개요 페이지로 이동하면 초기 적재 진행 상황을 확인하고, BigQuery ClickPipes를 클릭하여 세부 정보를 볼 수 있습니다.

    <Image img="/images/integrations/data-ingestion/clickpipes/bigquery/cp_step5.webp" alt="권한" size="lg" border />
  </Step>
</Steps>
