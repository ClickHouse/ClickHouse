[Splunk](https://www.splunk.com/)은 데이터 분석 및 모니터링 플랫폼입니다.

이 애드온을 사용하면 [ClickHouse Cloud 감사 로그](/ko/products/cloud/reference/security/audit-logging)를 Splunk에 저장할 수 있습니다. [ClickHouse Cloud API](/ko/products/cloud/features/admin-features/api/api-overview)를 사용해 감사 로그를 다운로드합니다.

이 애드온에는 모듈형 입력만 포함되어 있으며, 추가 UI는 제공되지 않습니다.

<div id="installation">
  # 설치 {#installation}
</div>

## Splunk Enterprise용 {#for-splunk-enterprise}

[Splunkbase](https://splunkbase.splunk.com/app/7709)에서 ClickHouse Cloud Audit Add-on for Splunk를 다운로드하십시오.

<div className="ch-image-lg">
  <Frame>
    ![ClickHouse Cloud Audit Add-on for Splunk 다운로드 페이지가 표시된 Splunkbase 웹사이트](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

Splunk Enterprise에서 Apps -&gt; Manage로 이동한 다음 Install app from file을 클릭하십시오.

<div className="ch-image-lg">
  <Frame>
    ![Install app from file 옵션이 있는 Apps 관리 페이지가 표시된 Splunk Enterprise 인터페이스](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

Splunkbase에서 다운로드한 압축 파일을 선택하고 Upload를 클릭하십시오.

<div className="ch-image-lg">
  <Frame>
    ![ClickHouse 애드온을 업로드하는 Splunk 앱 설치 대화 상자](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

설치가 정상적으로 완료되면 ClickHouse Audit logs 애플리케이션이 설치된 것을 확인할 수 있습니다. 설치되지 않았다면 Splunkd 로그에서 오류를 확인하십시오.

<div id="modular-input-configuration">
  # 모듈형 입력 구성 {#modular-input-configuration}
</div>

모듈형 입력을 구성하려면 먼저 ClickHouse Cloud 배포 환경에서 다음 정보를 확인해야 합니다:

* 조직 ID
* 관리자 [API 키](/ko/products/cloud/features/admin-features/api/openapi)

## ClickHouse Cloud에서 정보 가져오기 {#getting-information-from-clickhouse-cloud}

[ClickHouse Cloud 콘솔](https://console.clickhouse.cloud/)에 로그인합니다.

조직 -&gt; 조직 details로 이동합니다. 여기에서 조직 ID를 복사할 수 있습니다.

<div className="ch-image-lg">
  <Frame>
    ![조직 ID가 표시된 조직 details 페이지를 보여주는 ClickHouse Cloud 콘솔](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

그런 다음 왼쪽 메뉴에서 API Keys로 이동합니다.

<div className="ch-image-lg">
  <Frame>
    ![왼쪽 탐색 메뉴의 API Keys 섹션을 보여주는 ClickHouse Cloud 콘솔](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

API Key를 생성하고, 알아보기 쉬운 이름을 지정한 다음 `Admin` 권한을 선택합니다. Generate API Key를 클릭합니다.

<div className="ch-image-lg">
  <Frame>
    ![관리자 권한이 선택된 API Key 생성 인터페이스를 보여주는 ClickHouse Cloud 콘솔](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

API Key와 secret을 안전한 곳에 저장합니다.

<div className="ch-image-lg">
  <Frame>
    ![저장해야 할 생성된 API Key와 secret을 보여주는 ClickHouse Cloud 콘솔](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

## Splunk에서 데이터 입력 구성 {#configure-data-input-in-splunk}

  <Frame>
    ![Data inputs 옵션이 포함된 Settings 메뉴를 보여주는 Splunk 인터페이스](/images/integrations/tools/data-integration/splunk/splunk_008.webp)
  </Frame>
</div>

ClickHouse Cloud Audit Logs 데이터 입력을 선택합니다.

<div className="ch-image-lg">
  <Frame>
    ![ClickHouse Cloud Audit Logs 옵션을 보여주는 Splunk Data inputs 페이지](/images/integrations/tools/data-integration/splunk/splunk_009.webp)
  </Frame>
</div>

&quot;New&quot;를 클릭하여 새 데이터 입력 인스턴스를 구성합니다.

<div className="ch-image-lg">
  <Frame>
    ![새 ClickHouse Cloud Audit Logs 데이터 입력을 구성하는 Splunk 인터페이스](/images/integrations/tools/data-integration/splunk/splunk_010.webp)
  </Frame>
</div>

모든 정보를 입력한 후 Next를 클릭합니다.

<div className="ch-image-lg">
  <Frame>

  </Frame>
</div>

입력 구성이 완료되었습니다. 이제 감사 로그를 살펴볼 수 있습니다.

# 사용 {#usage}

모듈형 입력은 데이터를 Splunk에 저장합니다. 데이터를 보려면 Splunk의 일반 검색 화면을 사용할 수 있습니다.
