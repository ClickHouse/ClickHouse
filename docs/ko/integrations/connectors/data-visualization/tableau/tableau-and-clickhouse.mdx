ClickHouse는 공식 Tableau 커넥터를 제공하며,
이는 [Tableau Exchange](https://exchange.tableau.com/products/1064)에서 확인할 수 있습니다.
이 커넥터는 ClickHouse의 고급 [JDBC 드라이버](/ko/integrations/language-clients/java/jdbc)를 기반으로 합니다.

이 커넥터를 사용하면 Tableau에서 ClickHouse 데이터베이스와 테이블을 데이터 소스로 사용할 수 있습니다. 이 기능을 사용하려면,
아래 설정 가이드를 따르십시오.

<div id="setup-required-prior-usage">
  ## 사용 전에 필요한 설정 {#setup-required-prior-usage}
</div>

1. 연결 정보를 준비합니다
   <ConnectionDetails />

2. <a href="https://www.tableau.com/products/desktop/download" target="_blank">Tableau
   desktop</a>를 다운로드하여 설치합니다.

3. 호환되는 버전의 <a href="https://github.com/ClickHouse/clickhouse-java/releases/" target="_blank">ClickHouse JDBC 드라이버</a>를 다운로드하려면 `clickhouse-tableau-connector-jdbc` 지침을 따르십시오.

<Note>
  [clickhouse-jdbc-X.X.X-all-dependencies.jar](https://github.com/ClickHouse/clickhouse-java/releases) JAR 파일을 다운로드해야 합니다. 이 파일은 버전 `0.9.2`부터 제공됩니다.
</Note>

4. JDBC 드라이버를 다음 폴더에 저장합니다(OS에 따라 다르며, 폴더가 없으면 생성할 수 있습니다).
   * macOS: `~/Library/Tableau/Drivers`
   * Windows: `C:\Program Files\Tableau\Drivers`
5. Tableau에서 ClickHouse 데이터 소스를 구성한 후 데이터 시각화를 만들어 보십시오!

## Tableau에서 ClickHouse 데이터 소스(data source) 구성하기 {#configure-a-clickhouse-data-source-in-tableau}

이제 `clickhouse-jdbc` 드라이버를 설치하고 설정했으므로, ClickHouse의 **TPCD** 데이터베이스에 연결되는 데이터 소스를 Tableau에서 정의하는 방법을 살펴보겠습니다.

1. Tableau를 시작합니다. (이미 실행 중이라면 다시 시작합니다.)

2. 왼쪽 메뉴의 **To a Server** 섹션에서 **More**를 클릭합니다. 사용 가능한 커넥터 목록에서 **ClickHouse by ClickHouse**를 검색합니다:

<div className="ch-image-md">
  <Frame>
    ![ClickHouse by ClickHouse 옵션이 강조 표시된 커넥터 선택 메뉴가 보이는 Tableau 연결 화면](/images/integrations/data-visualization/tableau_connecttoserver.webp)
  </Frame>
</div>

<br />

<Note>
  커넥터 목록에 **ClickHouse by ClickHouse** 커넥터가 보이지 않습니까? Tableau Desktop 버전이 오래되어 그럴 수 있습니다.
  이 경우 Tableau Desktop 애플리케이션을 업그레이드하거나 [커넥터를 수동으로 설치](#install-the-connector-manually)하는 방법을 고려해 보십시오.
</Note>

3. **ClickHouse by ClickHouse**를 클릭하면 다음 대화 상자가 표시됩니다:

<div className="ch-image-md">
  <Frame>
    ![ClickHouse JDBC 커넥터 세부 정보와 설치 버튼이 표시된 Tableau 커넥터 설치 대화 상자](/images/integrations/data-visualization/tableau_connector_details.webp)
  </Frame>
</div>

<br />

4. **Install and Restart Tableau**를 클릭합니다. 애플리케이션을 다시 시작합니다.
5. 다시 시작하면 커넥터의 전체 이름이 `ClickHouse JDBC by ClickHouse, Inc.`로 표시됩니다. 이를 클릭하면 다음 대화 상자가 표시됩니다:

<div className="ch-image-md">
  <Frame>
    ![서버, 포트, 데이터베이스, 사용자 이름 및 비밀번호 필드가 표시된 Tableau의 ClickHouse 연결 대화 상자](/images/integrations/data-visualization/tableau_connector_dialog.webp)
  </Frame>
</div>

<br />

6. 연결 정보를 입력합니다:

   | Setting  | Value                                 |
   | -------- | ------------------------------------- |
   | Server   | **접두사나 접미사 없이 ClickHouse 호스트를 입력합니다** |
   | Port     | **8443**                              |
   | Database | **default**                           |
   | Username | **default**                           |
   | Password | ******                                |

<Note>
  ClickHouse Cloud를 사용하는 경우 보안 연결을 위해 SSL 체크박스를 활성화해야 합니다.
</Note>

<br />

<Note>
  ClickHouse 데이터베이스 이름은 **TPCD**이지만, 위 대화 상자에서는 **Database**를 **default**로 설정한 뒤
  다음 단계에서 **Schema**로 **TPCD**를 선택해야 합니다. (이는 커넥터의 버그 때문일 가능성이 있으므로 이 동작은
  바뀔 수 있지만, 현재로서는 데이터베이스로 **default**를 사용해야 합니다.)
</Note>

7. **Sign In** 버튼을 클릭하면 새 Tableau 통합 문서가 표시됩니다:

<div className="ch-image-md">
  <Frame>
    ![데이터베이스 선택 옵션이 표시된 초기 연결 화면을 보여주는 새 Tableau 통합 문서](/images/integrations/data-visualization/tableau_newworkbook.webp)
  </Frame>
</div>

<br />

8. **Schema** 드롭다운에서 **TPCD**를 선택하면 **TPCD**의 테이블 목록이 표시됩니다:

<div className="ch-image-md">
  <Frame>
    ![CUSTOMER, LINEITEM, NATION, ORDERS 등 TPCD 데이터베이스 테이블이 표시된 Tableau 스키마 선택 화면](/images/integrations/data-visualization/tableau_tpcdschema.webp)
  </Frame>
</div>

<br />

이제 Tableau에서 시각화를 만들 준비가 되었습니다!

## Tableau에서 시각화 만들기 {#building-visualizations-in-tableau}

이제 Tableau에 ClickHouse 데이터 소스(data source)가 구성되었으므로 데이터를 시각화해 보겠습니다...

1. **CUSTOMER** 테이블을 통합 문서로 드래그하십시오. 컬럼은 표시되지만 데이터 테이블은 비어 있습니다:

<div className="ch-image-md">
  <Frame>
    ![CUSTOMER 테이블을 캔버스로 드래그하여 열 머리글은 표시되지만 데이터는 없는 Tableau 통합 문서](/images/integrations/data-visualization/tableau_workbook1.webp)
  </Frame>
</div>

<br />

2. **Update Now** 버튼을 클릭하면 **CUSTOMER**의 행 100개가 테이블에 채워집니다.

3. **ORDERS** 테이블을 통합 문서로 드래그한 다음, **Custkey**를 두 테이블 간의 관계(Relationship) 필드로 설정하십시오:

<div className="ch-image-md">
  <Frame>
    ![Custkey 필드를 사용하여 CUSTOMER와 ORDERS 테이블 간의 연결을 보여주는 Tableau 관계 편집기](/images/integrations/data-visualization/tableau_workbook2.webp)
  </Frame>
</div>

<br />

4. 이제 **ORDERS** 테이블과 **LINEITEM** 테이블이 서로 연결된 데이터 소스가 준비되었으므로,
   이 관계를 활용해 데이터에 관한 다양한 질문에 답할 수 있습니다. 통합 문서 하단의 **Sheet 1** 탭을 선택하십시오.

<div className="ch-image-md">
  <Frame>
    ![분석에 사용할 수 있는 ClickHouse 테이블의 차원(dimensions)과 측정값을 보여주는 Tableau 워크시트](/images/integrations/data-visualization/tableau_workbook3.webp)
  </Frame>
</div>

<br />

5. 연도별로 특정 품목이 얼마나 주문되었는지 알고 싶다고 가정해 보겠습니다. **ORDERS**의 **OrderDate**를
   **Columns** 섹션(수평 필드)으로 드래그한 다음, **LINEITEM**의 **Quantity**를 **Rows**로 드래그하십시오. Tableau에서
   다음과 같은 선 차트가 생성됩니다:

<div className="ch-image-sm">
  <Frame>
    ![ClickHouse 데이터에서 연도별 주문 수량을 보여주는 Tableau 선 차트](/images/integrations/data-visualization/tableau_workbook4.webp)
  </Frame>
</div>

<br />

그다지 흥미로운 선 차트는 아니지만, 이 데이터셋은 쿼리 성능(query performance) 테스트용으로 스크립트를 통해 생성되었기 때문에
TCPD 데이터의 시뮬레이션된 주문에는 변동이 크지 않습니다.

6. 분기별 및 배송 모드별(항공, 우편, 선박, 트럭 등) 평균 주문 금액(달러 기준)을 알고 싶다고
   가정해 보겠습니다:

   * **New Worksheet** 탭을 클릭하여 새 시트를 만드십시오
   * **ORDERS**의 **OrderDate**를 **Columns**로 드래그하고 **Year**를 **Quarter**로 변경하십시오
   * **LINEITEM**의 **Shipmode**를 **Rows**로 드래그하십시오

다음과 같은 화면이 표시됩니다:

<div className="ch-image-sm">

  </Frame>
</div>

<br />

7. **Abc** 값은 메트릭을 테이블로 드래그하기 전까지 자리를 채우는 역할만 합니다. *
   *ORDERS**의 **Totalprice**를 테이블로 드래그하십시오. 기본 계산 방식은 **Totalprices**의 **SUM**입니다:

<div className="ch-image-md">
  <Frame>
    ![분기 및 배송 모드별 총 가격 합계를 보여주는 Tableau 크로스탭](/images/integrations/data-visualization/tableau_workbook6.webp)
  </Frame>

8. **SUM**을 클릭하고 **Measure**를 **Average**로 변경하십시오. 같은 드롭다운 메뉴에서 **Format**을 선택하여
   **Numbers**를 **Currency (Standard)**&#xB85C; 변경하십시오:

  </Frame>
</div>

수고하셨습니다! Tableau를 ClickHouse에 성공적으로 연결했습니다. 이제 ClickHouse 데이터를 분석하고 시각화할 수 있는
무궁무진한 가능성이 열렸습니다.

<div id="install-the-connector-manually">
  ## 커넥터를 수동으로 설치하기 {#install-the-connector-manually}
</div>

기본으로 커넥터가 포함되어 있지 않은 구버전 Tableau Desktop을 사용하는 경우, 다음 단계에 따라 수동으로 설치할 수 있습니다.

1. [Tableau Exchange](https://exchange.tableau.com/products/1064)에서 최신 taco 파일을 다운로드합니다
2. taco 파일을 다음 위치에 저장합니다
   * macOS: `~/Documents/My Tableau Repository/Connectors`
   * Windows: `C:\Users\[Windows User]\Documents\My Tableau Repository\Connectors`
3. Tableau Desktop을 다시 시작합니다. 설치가 성공적으로 완료되었다면 `New Data Source` 섹션에서 커넥터를 확인할 수 있습니다.
