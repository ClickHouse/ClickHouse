## Looker Studio를 ClickHouse에 연결하기 {#connecting-looker-studio-to-clickhouse}

먼저 Google 계정으로 [Looker Studio](https://lookerstudio.google.com)에 로그인한 후 새 데이터 소스를 생성하십시오:

<div className="ch-image-md">
  <Frame>
    ![Looker Studio 인터페이스에서 새 데이터 소스 생성](/images/integrations/data-visualization/looker_studio_01.webp)
  </Frame>
</div>

<br />

Google에서 제공하는 공식 MySQL 커넥터(이름: **MySQL**)를 검색하십시오:

<div className="ch-image-md">
  <Frame>
    ![Looker Studio 커넥터 목록에서 MySQL 커넥터 검색](/images/integrations/data-visualization/looker_studio_02.webp)
  </Frame>
</div>

<br />

연결 정보를 입력하십시오. MySQL 인터페이스의 기본 포트는 9004이며,
서버 구성에 따라 다를 수 있습니다.

<div className="ch-image-md">
  <Frame>
    ![Looker Studio에서 ClickHouse MySQL 연결 정보 입력](/images/integrations/data-visualization/looker_studio_03.webp)
  </Frame>
</div>

<br />

ClickHouse에서 데이터를 가져오는 방법은 두 가지입니다. 첫 번째는 Table Browser 기능을 사용하는 방법입니다:

<div className="ch-image-md">
  <Frame>
    ![Looker Studio에서 Table Browser로 ClickHouse 테이블 선택](/images/integrations/data-visualization/looker_studio_04.webp)
  </Frame>
</div>

<br />

또는 사용자 정의 쿼리를 작성하여 데이터를 가져올 수도 있습니다:

<div className="ch-image-md">
  <Frame>
    ![Looker Studio에서 사용자 정의 SQL 쿼리로 ClickHouse 데이터 가져오기](/images/integrations/data-visualization/looker_studio_05.webp)
  </Frame>
</div>

<br />

마지막으로, 자동으로 검사된 테이블 구조(table structure)를 확인하고 필요하면 데이터 타입을 조정하십시오.

<div className="ch-image-md">
  <Frame>
    ![Looker Studio에서 검사된 ClickHouse 테이블 구조 확인](/images/integrations/data-visualization/looker_studio_06.webp)
  </Frame>
</div>

<br />

이제 데이터를 탐색하거나 새 보고서를 만들 수 있습니다!

## ClickHouse Cloud에서 Looker Studio 사용 {#using-looker-studio-with-clickhouse-cloud}

ClickHouse Cloud를 사용하는 경우 먼저 MySQL 인터페이스를 활성화해야 합니다. 연결 대화상자의 &quot;MySQL&quot; 탭에서 활성화할 수 있습니다.

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 설정에서 MySQL 인터페이스 활성화](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)
  </Frame>
</div>

<br />

Looker Studio UI에서 &quot;Enable SSL&quot; 옵션을 선택합니다. ClickHouse Cloud의 SSL 인증서는 [Let&#39;s Encrypt](https://letsencrypt.org/certificates/)가 서명한 인증서입니다. 이 루트 인증서는 [여기](https://letsencrypt.org/certs/isrgrootx1.pem)에서 다운로드할 수 있습니다.

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud SSL 설정이 적용된 Looker Studio 연결 구성](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)
  </Frame>
</div>

<br />
