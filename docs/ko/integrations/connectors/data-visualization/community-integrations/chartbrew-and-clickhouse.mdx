[Chartbrew](https://chartbrew.com)은 대시보드를 만들고 데이터를 실시간으로 모니터링할 수 있는 데이터 시각화 플랫폼입니다. ClickHouse를 포함한 여러 데이터 소스를 지원하며, 차트와 보고서를 코드 없이 만들 수 있는 노코드 인터페이스를 제공합니다.

## 목표 {#goal}

이 가이드에서는 Chartbrew를 ClickHouse에 연결하고, SQL 쿼리를 실행한 뒤 시각화를 만듭니다. 완료되면 대시보드는 다음과 비슷한 모습이 됩니다:

<div className="ch-image-lg">
  <Frame>
    ![Chartbrew 대시보드](/images/integrations/data-visualization/chartbrew_01.webp)
  </Frame>
</div>

<Tip>
  **데이터 추가**

  사용할 데이터셋이 없다면 예시 중 하나를 추가할 수 있습니다. 이 가이드에서는 [UK Price Paid](/ko/get-started/sample-datasets/uk-price-paid) 데이터셋을 사용합니다.
</Tip>

<Steps>
  <Step title="연결 정보를 준비하십시오" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Chartbrew를 ClickHouse에 연결" id="2-connect-chartbrew-to-clickhouse">
    1. [Chartbrew](https://chartbrew.com/login)에 로그인한 후 **Connections** 탭으로 이동하십시오.

    2. **Create connection**을 클릭하고 사용 가능한 데이터베이스 옵션 중에서 **ClickHouse**를 선택하십시오.

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew에서 ClickHouse 연결 선택](/images/integrations/data-visualization/chartbrew_02.webp)
         </Frame>
       </div>

    3. ClickHouse 데이터베이스의 연결 정보를 입력하십시오.

       * **Display Name**: Chartbrew에서 연결을 식별하는 데 사용할 이름입니다.
       * **Host**: ClickHouse 서버의 호스트명 또는 IP 주소입니다.
       * **Port**: HTTPS 연결에서는 일반적으로 `8443`을 사용합니다.
       * **Database Name**: 연결할 데이터베이스입니다.
       * **Username**: ClickHouse 사용자 이름입니다.
       * **Password**: ClickHouse 비밀번호입니다.

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew의 ClickHouse 연결 설정](/images/integrations/data-visualization/chartbrew_03.webp)
         </Frame>
       </div>

    4. **Test connection**을 클릭하여 Chartbrew가 ClickHouse에 연결할 수 있는지 확인하십시오.

    5. 테스트에 성공하면 **Save connection**을 클릭하십시오. Chartbrew가 ClickHouse에서 스키마(schema)를 자동으로 가져옵니다.

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew의 ClickHouse JSON 스키마](/images/integrations/data-visualization/chartbrew_04.webp)
         </Frame>
       </div>
  </Step>

  <Step title="데이터셋 생성 및 SQL 쿼리(SQL query) 실행" id="3-create-a-dataset-and-run-a-sql-query">
    1. **Create dataset** 버튼을 클릭하거나 **Datasets** 탭으로 이동하여 데이터셋을 생성하십시오.
    2. 앞에서 생성한 ClickHouse 연결(Connection)을 선택하십시오.

    <div className="ch-image-lg">
      <Frame>
        ![데이터셋에 사용할 ClickHouse 연결 선택](/images/integrations/data-visualization/chartbrew_05.webp)
      </Frame>
    </div>

    시각화할 데이터를 조회하는 SQL 쿼리(SQL query)를 작성하십시오. 예를 들어, 다음 쿼리는 `uk_price_paid` 데이터셋에서 연도별 평균 거래 가격을 계산합니다.

    ```sql
    SELECT toYear(date) AS year, avg(price) AS avg_price
    FROM uk_price_paid
    GROUP BY year
    ORDER BY year;
    ```

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew의 ClickHouse SQL 쿼리](/images/integrations/data-visualization/chartbrew_07.webp)
      </Frame>
    </div>

    **Run query**를 클릭하여 데이터를 가져오십시오.

    쿼리 작성 방법을 잘 모를 때는 **Chartbrew의 AI 어시스턴트**를 사용하여 데이터베이스 스키마(database schema)를 바탕으로 SQL 쿼리(SQL query)를 생성할 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew의 ClickHouse AI SQL 어시스턴트](/images/integrations/data-visualization/chartbrew_06.webp)
      </Frame>
    </div>

    데이터를 가져온 후 **Configure dataset**을 클릭하여 시각화 매개변수를 설정하십시오.
  </Step>

  <Step title="시각화 만들기" id="4-create-a-visualization">
    1. 시각화에 사용할 메트릭(숫자 값)과 차원(범주형 값)을 정의합니다.
    2. 데이터셋을 미리 보고 쿼리 결과(query results)가 올바르게 구조화되었는지 확인합니다.
    3. 차트 유형(예: 선 차트, 막대 차트, 파이 차트)을 선택한 후 대시보드에 추가합니다.
    4. **Complete dataset**을 클릭하여 설정을 마칩니다.

    <div className="ch-image-lg">
      <Frame>
        ![ClickHouse 데이터가 표시된 Chartbrew 대시보드](/images/integrations/data-visualization/chartbrew_08.webp)
      </Frame>
    </div>

    데이터 세트(datasets)는 필요한 만큼 생성하여 데이터의 다양한 측면을 시각화할 수 있습니다. 또한 이러한 데이터 세트로 여러 대시보드를 구성하여 다양한 메트릭을 추적할 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![ClickHouse 데이터가 표시된 Chartbrew 대시보드](/images/integrations/data-visualization/chartbrew_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="데이터 갱신(updates) 자동화" id="5-automate-data-updates">
    대시보드를 항상 최신 상태로 유지하려면 데이터 자동 갱신 일정을 설정하십시오.

    1. 데이터셋 갱신 버튼 옆의 캘린더 아이콘을 클릭합니다.
    2. 업데이트 간격(예: 매시간, 매일)을 구성합니다.
    3. 설정을 저장하면 자동 갱신이 활성화됩니다.

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew 데이터셋 갱신 설정](/images/integrations/data-visualization/chartbrew_09.webp)
      </Frame>
    </div>
  </Step>
</Steps>
