dbt는 새로운 엔진 위에서 재구축되고 있으며, ClickHouse는 그 출발점부터 함께하고 있습니다. 이제 ClickHouse는 dbt OSS와 dbt v2 모두에서 새로운 Rust 기반 dbt 엔진과 함께 동작하며, 처음으로 dbt platform에서 ClickHouse에 연결할 수 있습니다. 기존 프로젝트를 변경할 필요는 없습니다. 현재 dbt Core 1.x에서 실행되는 모델, 테스트, 프로필이 새 엔진에서도 그대로 실행되며, 달라지는 것은 바이너리뿐입니다.

ClickHouse는 dbt OSS, dbt v2 및 dbt platform을 지원하는 최초의 커뮤니티 어댑터입니다. dbt의 퍼스트파티 어댑터가 ClickHouse와 함께 출시되고 있으며, dbt Labs 외부에서는 ClickHouse가 처음입니다. dbt Core 1.x Python 어댑터인 `dbt-clickhouse`는 중단되지 않습니다. dbt 1.x 릴리스에 맞춰 최신 상태로 유지하며, 두 어댑터를 병행하여 관리합니다.

<Warning>
  **베타 단계이며, 아직 일반 제공(GA) 상태가 아닙니다.** dbt OSS 및 dbt v2용 ClickHouse 어댑터는 베타 단계이며, dbt platform 연결은 비공개 베타 단계입니다. dbt Core 1.x 어댑터인 `dbt-clickhouse`는 일반 제공(GA) 상태이며 프로덕션 환경에서의 사용이 지원됩니다. 이 페이지의 내용은 이에 영향을 주지 않습니다.
</Warning>

<Note>
  **dbt Core 1.x 문서는 dbt OSS 및 dbt v2에도 적용됩니다.** 새 어댑터는 두 엔진에서 동일하게 동작합니다. 다른 dbt 페이지에 설명된 프로필, 모델 구성, 머티리얼라이즈, 매크로는 dbt OSS, dbt v2 및 dbt platform에서 변경 없이 동작합니다. 예외 사항은 아래의 [v1 대 v2 동등성](#parity) 표에 정리되어 있습니다.
</Note>

<Note>
  **dbt OSS**는 v2 엔진의 오픈소스(Apache 2.0) 빌드입니다. dbt v2 및 dbt platform과의 관계는 [용어 및 제공 범위](#terminology)를 참조하십시오.
</Note>

dbt v2 어댑터는 2026년 9월에 릴리스된 dbt Core 1.x 버전의 어댑터인 `dbt-clickhouse` 1.10.3과 기능 동등성을 갖추고 있으며, 일부 예외 사항은 [v1 대 v2 동등성](#parity) 섹션에 정리되어 있습니다.

#### dbt platform에서 ClickHouse 사용해 보기 {#request-access}

비공개 베타 테스트에 관심이 있다면 [dbt Labs 비공개 베타 양식](https://docs.google.com/forms/d/e/1FAIpQLScjHwRchnKarq_RpNM7hATjphNFxqBEePmAwRtSpMWG1snGHA/viewform)을 통해 신청하십시오. 이 양식은 dbt Labs가 운영하므로, 제출한 정보는 ClickHouse가 아닌 dbt Labs로 전달됩니다. 기능이 활성화되면 dbt 문서의 [Connect ClickHouse](https://docs.getdbt.com/docs/platform/connect-data-platform/connect-clickhouse)를 참고하여 연결을 설정하십시오.

## 용어 및 제공 현황 {#terminology}

dbt는 여러 형태로 제공되며, 동일한 어댑터가 둘 이상의 형태에서 실행될 수 있습니다. 아래 표는 각 명칭과 현재 ClickHouse 지원 수준을 설명합니다.

| 용어               | 설명                                                                                                                                                                                                               | ClickHouse 지원 상태 및 사용 방법                                                                                                                                                                                                                                                                  |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **dbt Core 1.x** | Python 기반 dbt 엔진으로, 오픈 소스(Apache 2.0)입니다. ClickHouse 어댑터는 `dbt-clickhouse`이며, [ClickHouse GitHub organization](https://github.com/ClickHouse/dbt-clickhouse)에서 유지 관리되고 `dbt-core`와 함께 설치됩니다.                     | **일반 제공, 유지 관리 중.** dbt v2와 병행하여 계속 릴리스됩니다.                                                                                                                                                                                                                                               |
| **dbt OSS**      | dbt 엔진을 Rust로 전면 재작성한 버전으로, 오픈 소스(Apache 2.0)입니다. 이 새 버전에는 v1의 모든 기능과 여러 성능 개선 사항이 포함되어 있습니다.                                                                                                                    | **베타.** dbt 문서의 [dbt v2 업그레이드 가이드](https://docs.getdbt.com/docs/dbt-versions/core-upgrade/upgrading-to-v2)와 [v2용 ClickHouse 설정 페이지](https://docs.getdbt.com/docs/local/connect-data-platform/clickhouse-setup?version=2)를 참고하십시오. ClickHouse 어댑터는 dbt 바이너리에 포함되어 제공되므로 별도로 설치할 패키지가 없습니다. |
| **dbt v2**       | dbt OSS에 dbt Labs의 추가 기능이 더해진 형태입니다. SQL 이해, 정적 분석, LSP, VS Code 확장 기능, 컬럼 인식 등을 제공합니다. 클로즈드 소스이며 [dbt Product Licensing Agreement](https://www.getdbt.com/dbt-fusion-engine-license-agreement)에 따라 라이선스가 부여됩니다. | **베타.** 어댑터는 v2 바이너리에서 실행되지만, 새로운 SQL 기능은 아직 ClickHouse에서 사용할 수 없습니다.                                                                                                                                                                                                                     |
| **dbt platform** | 호스팅형 dbt로, 이전 명칭은 dbt Cloud입니다. Studio IDE, 예약 작업, 환경, Catalog, Semantic Layer를 제공합니다. 이 플랫폼은 dbt v2만 실행하므로, 플랫폼에서 ClickHouse를 사용한다는 것은 v2 어댑터를 사용한다는 의미입니다.                                                     | **프라이빗 베타.** [액세스 요청 방법](#request-access)을 참고하십시오. 설정 방법은 dbt 문서의 [Connect ClickHouse](https://docs.getdbt.com/docs/platform/connect-data-platform/connect-clickhouse)를 참고하십시오.                                                                                                           |

## 현재 상태 세부 정보 {#v2-adapter-status}

베타는 v2 어댑터가 [v1 대 v2 동등성](#parity) 섹션에 나열된 몇 가지 예외를 제외하고 `dbt-clickhouse` 1.10.3과 기능 동등성을 갖추었음을 의미합니다. 먼저 개발 또는 스테이징 환경에서 dbt v2를 평가하십시오. 프로젝트가 대기 중인 기능에 의존하거나 일반 제공 릴리스 수준의 보장이 필요하다면 운영 환경은 dbt Core 1.x로 유지할 것을 권장합니다.

**다음 단계**: 남은 예외 사항을 해소하고, 새로운 `dbt-clickhouse` 릴리스가 나올 때마다 v2에도 반영하는 것입니다. 베타 이후에도 나머지 [dbt v2 전용 기능](#v2-functionality) 작업을 계속 진행할 예정입니다.

일반 제공은 로드맵에 포함되어 있습니다. dbt Labs와 함께 일정을 조율하고 있으며, 준비가 완료되면 이 페이지를 업데이트하겠습니다.

### 베타 범위에서 제외되는 항목 {#out-of-scope}

ClickHouse SQL 인텔리전스(정적 분석, LSP, 컬럼 인식), Semantic Layer, 추가 dbt platform 인증 방식 등 v2 전용 기능은 베타 범위에 포함되지 않습니다. 이러한 기능의 현재 상태는 [dbt v2 전용 기능](#v2-functionality)에서 확인하십시오.

### v1 대 v2 기능 동등성 {#parity}

아래 표는 `dbt-clickhouse`(v1)에서 제공되는 기능과 dbt v2 어댑터에서의 지원 상태를 비교한 것입니다. 참고 사항에 별도로 명시하지 않은 한, 나열된 모든 기능은 v1에서 지원됩니다. 상태 컬럼은 dbt v2를 기준으로 하며, dbt OSS에도 동일하게 적용됩니다. 비교 기준은 `dbt-clickhouse` 1.10.3입니다. 부분 지원 또는 Not yet으로 표시된 행과 [v2에서 지원 계획 없음](#not-planned)에 나열된 동작을 제외하면, 이 버전에서 제공하는 모든 기능이 v2에서 동작합니다.

#### v2에서 지원 예정이 없는 항목 {#not-planned}

일부 v1 동작은 v2에 포함되지 않았으며 앞으로도 포함되지 않습니다. 위의 동등성 표에는 계획된 작업만 포함되도록 이러한 동작은 사용 가능한 대안과 함께 여기에 별도로 정리합니다.

| 기능                                            | v1에서의 동작                                          | 지원 예정이 없는 이유                                                                                                                                                                                                                                                              |
| --------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `verify: false`                               | TLS 인증서 유효성 검사를 건너뜁니다.                            | 암호화는 유지되지만 인증이 빠지므로, 통신 경로상의 누구나 서버를 가장하여 자격 증명을 탈취할 수 있습니다. v2는 항상 인증서를 검사하며 이 키는 무시합니다. 클라이언트가 신뢰하는 인증 기관(CA)이 서명한 인증서를 사용하십시오. v2에서 이 기능이 필요한 경우 이슈를 등록하십시오.                                                                                                           |
| `sync_request_timeout`, `compress_block_size` | 네이티브 프로토콜 클라이언트를 구성합니다.                           | 네이티브 프로토콜 클라이언트는 v1에만 있습니다. v2는 HTTP 전용인 ADBC 드라이버로 연결하므로 이 키로 구성할 대상이 없습니다.                                                                                                                                                                                              |
| 소스의 `database:`                               | 소스에 `schema:`가 없을 때 소스의 ClickHouse 데이터베이스를 지정합니다. | v2는 이 키를 무시하고 소스를 `<source name>.<table>`로 해석하므로, 모델이 `Database <source name> does not exist` 오류와 함께 실패합니다. 대신 소스에 `schema: <database>`를 지정하십시오. 이 방식은 두 엔진 모두에서 동작합니다.                                                                                                   |
| 26.7 미만 ClickHouse 서버의 `UUID` 컬럼              | 모든 쿼리에서 `UUID` 컬럼을 반환할 수 있습니다.                    | v2는 쿼리 결과(query results)를 Arrow 형식으로 받는데, 26.7 미만 서버는 `UUID`를 Arrow로 변환할 수 없습니다. 따라서 `UUID` 컬럼을 반환하는 `SELECT`는 `The type 'UUID' ... is not supported for conversion into Arrow data format` 오류와 함께 실패합니다. 이는 서버 측 제한 사항이며 어댑터에서 우회할 방법이 없습니다. ClickHouse 26.7 이상을 사용하십시오. |

### dbt v2 전용 기능 {#v2-functionality}

dbt v2에는 dbt Core 1.x에 없는 새로운 기능이 추가되었습니다. 이러한 기능은 베타 범위에 포함되지 않으며 추후 제공될 예정입니다. 대부분은 엔진이 SQL 방언(SQL dialect)을 이해하는 것을 전제로 하는데, ClickHouse용 방언은 아직 없으며 현재 개발 중입니다. 범례는 위와 동일하며, 진행 중인 작업은 <Badge color="blue">In progress</Badge>로 표시합니다. 진행 상황은 [ClickHouse/dbt-clickhouse#736](https://github.com/ClickHouse/dbt-clickhouse/issues/736)에서 확인할 수 있습니다.

| 기능                                               | 설명                                                                                                     | dbt v2                                  | 비고                                                                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 엔진의 ClickHouse SQL 방언                            | 아래 정적 기능의 기반이 되는 방언 인식 SQL 파싱입니다.                                                                      | <Badge color="red">Not yet</Badge>      | 계획되어 있습니다.                                                                                                                                                             |

| dbt platform의 열 수준(column-level) 데이터 계보(lineage) | 실행 산출물을 기반으로 생성되는 컬럼 데이터 계보 뷰입니다.                                                                      | <Badge color="yellow">부분 지원</Badge>     | `dbt_project.yml`에서 식별자 인용을 비활성화한 경우에만 렌더링됩니다. 플랫폼의 폴백 파서가 백틱으로 인용된 이름을 처리하지 못하기 때문입니다([dbt-labs/dbt#16646](https://github.com/dbt-labs/dbt/issues/16646)).            |
