[Striim for ClickHouse](https://www.striim.com/docs/striimforclickhouse/en/introducing-striim-for-clickhouse.html)는 Oracle, Microsoft SQL Server, Snowflake 같은 엔터프라이즈 소스를 비롯해 데이터베이스, 데이터 웨어하우스(data warehouse), 데이터 레이크(data lakes), SaaS 애플리케이션의 데이터를 ClickHouse로 가져오는 완전 관리형 SaaS입니다. 기존 레코드를 먼저 로드한 다음 변경 데이터 캡처(Change Data Capture, CDC)로 삽입, 갱신(updates), 삭제(deletes)를 스트리밍하여 AI 워크로드(workloads), 대시보드, 데이터 애플리케이션에서 사용하는 ClickHouse 데이터를 항상 최신 상태로 유지할 수 있습니다.

Striim for ClickHouse는 AWS의 Striim Cloud에서 호스팅되며, 셀프서비스 가입과 사용량 기반 월별 청구 방식을 제공하고 연간 약정이 필요하지 않습니다. striim.com 또는 AWS Marketplace에서 가입하여 14일 무료 체험판을 시작한 다음, 자연어 프롬프트, 마법사 또는 플로 디자이너로 파이프라인을 빌드하십시오.

## 주요 기능 {#key-features}

* **변경 데이터 캡처(Change Data Capture) 및 초기 적재(initial load):** 기존 데이터를 적재한 뒤 삽입, 갱신(updates), 삭제(deletes)를 지속적으로 반영하는 실시간 복제(real-time replication)로 전환합니다. 자동화된 파이프라인 마법사로 두 단계를 생성하고 연결할 수 있으며, 초기 적재가 끝나면 CDC 복제로 자동 전환됩니다.
* **ClickHouse writer:** 파이프라인별로 테이블 엔진(`MergeTree`, `ReplacingMergeTree`, `CollapsingMergeTree`, `CoalescingMergeTree` 등)을 선택할 수 있습니다. Striim은 대상 테이블을 생성하고, 선택한 엔진에 맞게 갱신 및 삭제를 처리하며, 정렬 키를 설정합니다.
* **스키마(schema) 처리:** 지원되는 소스에서는 소스 스키마를 기반으로 대상 스키마를 자동 생성하며, 지원되는 CDC 소스에서는 일부 DDL 변경 사항(`CREATE TABLE`, `ADD COLUMN`, `ALTER TABLE ... MODIFY COLUMN`, `DROP COLUMN`, `DROP TABLE`, `TRUNCATE TABLE`)을 전파합니다.
* **전송 중 처리:** 소스와 ClickHouse 사이에서 데이터를 필터링, 보강, 변환합니다.
* **AI 지원 운영:** 대화형 AI 에이전트인 Striim Clara AI는 자연어 설명을 바탕으로 파이프라인을 구축하고, 지연 시간과 처리량을 보고하며, 장애 원인을 설명합니다. 운영 환경에 배포하기 전에 생성된 결과물을 반드시 검토하십시오.
* **프라이빗 연결:** 소스 및 ClickHouse와의 연결에 AWS PrivateLink, SSH 터널, IP 허용 목록을 지원합니다.
* **모니터링 및 알림:** 파이프라인 모니터링 기능이 내장되어 있으며, 이메일, Slack, Microsoft Teams, Striim 웹 UI로 알림을 보냅니다.

## 활용 사례 {#use-cases}

| **활용 사례**      | **Striim for ClickHouse의 활용 방식**                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 실시간 분석         | CDC 리더가 ClickHouse 테이블을 항상 최신 상태로 유지하므로, 대화형 대시보드에 마지막 배치 사이클이 아닌 불과 몇 초 전의 활동까지 반영됩니다.                                   |
| AI 에이전트 및 RAG  | 벡터 검색이나 MCP 서버에서 사용하는 테이블을 포함한 ClickHouse 테이블을 최신 상태로 유지하므로, 에이전트가 최신 운영 데이터를 읽을 수 있습니다.                                  |
| 피처 스토어 및 모델 추론 | 사기 탐지나 개인화처럼 거의 실시간으로 점수를 산출하는 모델에 맞춰 엔터티 수준의 피처를 최신 상태로 유지합니다.                                                           |

| 관측성            | 데이터베이스 로그와 애플리케이션 로그를 텔레메트리와 동일한 ClickHouse 인스턴스로 스트리밍하므로, 두 데이터를 함께 쿼리할 수 있습니다. ClickStack 및 OpenTelemetry 기반 수집을 보완합니다. |

## 운영 고려 사항 {#operational-considerations}

* 전달은 최소 1회(at-least-once) 방식으로 보장됩니다. 재시작 또는 복구 후에는 이미 기록된 이벤트가 다시 기록될 수 있습니다. 이에 따른 최종 데이터 레코드는 테이블 엔진에 따라 달라집니다([ClickHouse에 데이터가 적재되는 방식](/ko/integrations/connectors/data-ingestion/etl-tools/striim/get-started#how-data-lands-in-clickhouse) 참조).
* 스키마 진화(Schema Evolution)는 컬럼 이름 변경이나 NULL 허용 여부 변경을 지원하지 않으며, `AggregatingMergeTree`, `Replicated`, `Distributed` 대상에는 적용되지 않습니다. `VersionedCollapsingMergeTree`와 `GraphiteMergeTree`는 지원되지 않습니다.
* 일부 소스 유형은 ClickHouse 타입에 매핑되지 않으므로 자동 스키마 생성 시 건너뜁니다. 예를 들어 `SQL Server GEOGRAPHY`, `GEOMETRY`, `HIERARCHYID`, `SQL_VARIANT`; `Oracle BFILE`, `LONG`, `LONG RAW`, `SDO_GEOMETRY`, `UROWID`; `MySQL GEOMETRY`, `SET` 등이 이에 해당합니다.
