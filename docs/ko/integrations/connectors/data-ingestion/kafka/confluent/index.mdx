Confluent는 ClickHouse와 통합할 수 있는 다음 3가지 옵션을 제공합니다.

* [Confluent Cloud의 ClickHouse Connect Sink](/ko/integrations/connectors/data-ingestion/kafka/confluent/confluent-cloud) - 완전 관리형 커넥터
* [Confluent Cloud의 Custom Connector 방식 ClickHouse Connect Sink](/ko/integrations/connectors/data-ingestion/kafka/confluent/custom-connector) - 커넥터를 직접 업로드하는 방식
* [Confluent Platform용 HTTP Sink 커넥터](/ko/integrations/connectors/data-ingestion/kafka/confluent/kafka-connect-http) - HTTP 또는 HTTPS를 통해 Apache Kafka를 API와 통합

## 어떤 Confluent Cloud 옵션을 사용해야 합니까? {#which-confluent-cloud-option-should-i-use}

앞의 두 옵션은 모두 Confluent Cloud에서 동일한 ClickHouse Connect Sink를 실행합니다. 차이점은 커넥터를 누가 관리하는가입니다.

* **완전 관리형 커넥터(Fully managed connector)**: Confluent가 커넥터 설치와 업그레이드를 대신 처리합니다. 완전 관리형 커넥터에서 제공하지 않는 기능이 필요한 것이 아니라면 이 옵션으로 시작하십시오.
* **Custom Connector**: [GitHub](https://github.com/ClickHouse/clickhouse-kafka-connect/releases)에서 커넥터 릴리스를 다운로드하여 Confluent Cloud에 직접 업로드합니다. 특정 버전의 커넥터가 필요하거나, 완전 관리형 커넥터에서는 Confluent 지원 케이스를 통해서만 변경할 수 있는 설정을 재정의하려는 경우에 사용하십시오. Custom Connector는 일부 AWS 리전에서만 사용할 수 있습니다.
