에이전트 마켓플레이스에서는 조직 내 다른 사용자가 공유한 에이전트를 둘러보고, 검색하고, 실행할 수 있습니다. 관리자가 조직 전체에 게시한 에이전트도 여기에 포함됩니다. 왼쪽 사이드바에서 **에이전트 마켓플레이스** 옵션을 클릭하여 엽니다.

## 둘러보기 {#browse}

에이전트는 *General*, *Human Resources*, *Research &amp; Development*, *Finance*, *IT*, *Sales* 등의 카테고리로 분류됩니다. 마켓플레이스 상단의 탭에서 카테고리를 전환할 수 있습니다. 각 에이전트 카드에는 이름, 아이콘, 에이전트가 속한 카테고리가 표시됩니다.

검색창에서 이름이나 키워드로 전체 카테고리의 에이전트를 검색할 수 있습니다.

## 에이전트 열기 {#open-an-agent}

에이전트 카드를 클릭하면 해당 에이전트의 상세 보기가 열립니다. 여기에서 다음 작업을 수행할 수 있습니다.

* **Start Chat** - 에이전트와 새 채팅을 시작합니다.
* **Pin** - 에이전트를 즐겨찾기에 추가하여 빠르게 액세스할 수 있습니다.
* **Copy link** - 에이전트로 바로 이동하는 직접 링크를 공유합니다.

## 직접 게시하기 {#publish-your-own}

마켓플레이스에서 에이전트가 검색되도록 하려면 [공유 및 접근](/ko/agents/sharing-and-access) 패널에서 적절한 범위로 공유하십시오. 공개 수준은 다음과 같습니다.

* **프라이빗** - 본인만 볼 수 있으며, 마켓플레이스에는 표시되지 않습니다.
* **사용자 또는 그룹과 공유** - 지정한 보안 주체에게만 표시되며, 해당 사용자의 마켓플레이스에 나타납니다.
* **조직 전체** - 조직의 모든 구성원에게 표시됩니다. 단, 관리자가 설정한 마켓플레이스 권한이 적용됩니다.

게시하기 전에 에이전트의 카테고리를 지정하고 명확한 설명을 작성하십시오. 이 필드는 검색과 카테고리별 탐색에 모두 활용됩니다.

## 관리자 제어 {#admin-controls}

조직 관리자는 다음 작업을 수행할 수 있습니다.

* 마켓플레이스에 표시되는 카테고리 구성을 관리합니다.
* 개별 에이전트를 조직 전체 보기로 승격합니다.
* 역할별로 마켓플레이스 액세스를 허용하거나 제한합니다.

권한(permission) 모델은 [공유 및 접근](/ko/agents/sharing-and-access)을 참조하십시오.
