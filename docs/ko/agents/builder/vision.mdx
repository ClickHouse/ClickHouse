비전 기능을 사용하면 사용자가 이미지를 업로드하여 에이전트에게 분석을 맡길 수 있습니다. 에이전트는 이미지를 이미지 인식 지원 모델에 전달하고, 이 모델은 이미지 내용을 설명 또는 요약하거나 이미지에 관한 질문에 답변합니다.

## 이미지 이해 기능 활성화 {#enable-it}

비전은 이미지 입력을 지원하는 모델에서만 작동합니다. 선택한 모델이 이미지 입력을 처리할 수 없으면 메시지 작성 영역의 업로드 버튼이 비활성화됩니다. 업로드 버튼을 다시 활성화하려면 이미지 인식 지원 모델로 전환하십시오.

## 이미지 이해 기능 사용하기 {#use-it}

메시지 작성 영역 왼쪽 하단의 클립 아이콘을 클릭하고 **Upload to Provider**를 선택하여 스크린샷, 사진, 차트, 다이어그램 등의 이미지를 첨부하십시오. 그런 다음 이미지를 읽어야 답할 수 있는 질문을 입력하면 됩니다. 예: *&quot;이 쿼리 실행 계획(query plan)에 어떤 문제가 있습니까?&quot;*, *&quot;이 스크린샷의 텍스트를 받아 적어 주십시오.&quot;*, *&quot;이 대시보드를 지난주 대시보드와 비교해 주십시오.&quot;*

에이전트는 이미지를 메시지 컨텍스트의 일부로 처리합니다. 따라서 같은 턴의 후속 질문에서는 이미지를 다시 업로드하지 않아도 앞서 확인한 이미지 내용을 참조할 수 있습니다.

## 비전을 다른 도구와 함께 사용하기 {#combine-with-other-tools}

비전은 [코드 인터프리터](/ko/agents/builder/code-interpreter)와 함께 사용하면 이미지 기반 분석에 효과적입니다. 예를 들어, 에이전트가 스크린샷에서 숫자를 읽어 낸 다음 Python을 실행하여 합계를 계산할 수 있습니다. 또한 이미지에 모델이 찾아봐야 하는 내용이 포함되어 있다면 [웹 검색](/ko/agents/builder/web-search)과 함께 사용하는 것도 좋습니다.
