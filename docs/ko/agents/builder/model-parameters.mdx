모델 매개변수는 에이전트가 사용할 모델과 해당 모델의 응답 생성 방식을 제어합니다.
**에이전트 빌더** 탭의 **모델** 제목 아래에서 **모델 선택**을 클릭하십시오.
**모델 매개변수** 창이 열립니다.

## provider 및 모델 {#provider-and-model}

* **provider** - 사용할 업스트림 LLM 제공업체를 선택합니다.
* **모델** - 해당 제공업체에서 사용할 모델을 선택합니다. 모델마다 강점이 다릅니다. 계획 수립 비중이 큰 작업에는 대형 추론 모델이, 일상적인 쿼리에는 더 빠른 소형 모델이 적합합니다.

**provider**와 **모델**은 모두 필수 항목입니다. 패널의 나머지 항목은 선택한 모델이 지원하는 기능에 따라 달라집니다.

## 컨텍스트 및 출력 제한 {#context-and-output-limits}

* **Max Context Tokens** - 에이전트가 모델에 전송하는 전체 컨텍스트의 상한을 설정합니다. 모델의 기본값을 사용하려면 **System**으로 그대로 두십시오. 비용을 줄이려면 값을 낮추고, 대용량 입력을 바탕으로 추론해야 하는 에이전트라면 값을 높이십시오.
* **Max Output Tokens** - 에이전트 응답의 크기 상한을 설정합니다. **System**으로 설정하면 모델의 기본값이 사용됩니다. 응답이 너무 길면 값을 낮추고, 응답이 중간에 잘린다면 값을 높이십시오.
* **File Token Limit** - 업로드된 파일 하나가 컨텍스트에서 차지할 수 있는 토큰 수의 상한을 설정합니다. 사용자가 대용량 파일을 첨부하더라도 해당 파일이 대화의 나머지 내용을 밀어내지 않도록 하려는 경우에 유용합니다.

## 샘플링 {#sampling}

* **샘플링 온도** - 무작위성을 조절합니다. 값이 높을수록(0.7–1.0) 더 무작위적인 결과가 생성되고, 값이 낮을수록(0.0–0.3) 더 집중적이고 결정적인 결과가 생성됩니다. 이 값과 Top P 중 하나만 조정하는 것을 권장합니다.
* **Top P** - 뉴클리어스 샘플링(nucleus sampling)입니다. 모델이 출력할 토큰을 선택하는 방식을 바꿉니다.
* **Top K** - 각 간격에서 확률이 가장 높은 상위 K개의 토큰으로 샘플링 범위를 제한합니다. 일부 서비스 제공업체에서만 지원되며, 샘플링 온도와는 다른 측면에서 결정성을 제어합니다.

특정 동작을 목표로 조정하는 경우가 아니라면 슬라이더를 기본값 근처로 두십시오. 작은 변경은 결과에 거의 영향을 주지 않으며, 큰 변경은 출력 품질을 떨어뜨릴 수 있습니다.

## 추론 제어 {#reasoning-controls}

확장 추론 기능을 제공하는 모델에서 사용할 수 있습니다. 제공되는 항목은 provider에 따라 다릅니다.

* **추론** - 모델의 확장 추론 모드를 켜거나 끕니다. 켜면 모델이 최종 답변을 내기 전에 내부 추론 토큰을 생성합니다. 일반적으로 어려운 작업에서 정확도가 향상되지만, 그만큼 지연 시간과 토큰 사용량이 늘어납니다.
* **추론 Budget** - 추론 단계에 사용할 토큰 예산을 설정합니다. 모델은 이 토큰 수를 모두 소진하면 추론을 멈추고 답변합니다.
* **Effort** - 추론 강도를 대략적으로 조절하는 항목입니다(**Auto**, low, medium, high). 추론 토큰 예산을 직접 노출하지 않는 추론 모델에서 사용됩니다.
* **Thought Visibility** - 모델의 추론 내용을 사용자에게 인라인으로 표시할지, 접힌 보기로 숨길지, 아니면 아예 생략할지를 제어합니다.

## 대화 동작 {#conversation-behavior}

* **Resend Files** - 켜면 이전 턴에서 첨부한 파일을 이후 매 턴마다 다시 전송하여 모델이 해당 파일을 놓치지 않도록 합니다. 대화가 짧거나 모델이 대화를 진행하면서 파일을 요약하고 있다면 이 옵션을 꺼서 토큰을 절약하십시오.
* **Use Prompt Caching** - provider가 지원하는 경우 프롬프트에서 재사용 가능한 부분을 캐시합니다. 지침과 도구 설명이 여러 턴에 걸쳐 반복되는 대화에서 비용과 지연 시간을 줄일 수 있습니다.
* **웹 검색** - 지원되는 모델에서 provider 네이티브 웹 검색을 켜거나 끕니다. 이 기능은 [웹 검색 도구](/ko/agents/builder/web-search)와 다릅니다. 웹 검색 도구는 provider 기능이 아니라 에이전트의 도구 중 하나로 실행됩니다.

## 초기화 {#reset}

패널 하단의 **모델 매개변수 초기화**를 클릭하면 모든 필드가 시스템 기본값으로 복원됩니다. 충분히 실험해 본 뒤 처음 상태에서 다시 시작하려면 이 기능을 사용하십시오.
