이미지 생성 기능을 사용하면 에이전트가 텍스트 프롬프트를 바탕으로 새 이미지를 생성하거나 사용자가 업로드한 이미지를 편집할 수 있습니다. 에이전트는 요청 내용과 사용 가능한 컨텍스트에 따라 생성과 편집 중 적합한 작업을 선택합니다.

## 이미지 생성 활성화 {#enable-it}

이미지 생성은 Capabilities 섹션이 아니라 에이전트 빌더의 **Add Tools** 모달 대화 상자에서 추가합니다. 에이전트 빌더 패널 하단의 **Add Tools**를 클릭한 다음, **OpenAI Image Tools**, **DALL-E-3**, **Stable Diffusion** 등의 이미지 모델 도구 중 하나를 추가하십시오. 에이전트는 요청에 맞는 도구를 자동으로 선택하며, 지침에서 사용할 도구를 제한할 수도 있습니다.

## 생성 {#generation}

사용자가 이미지를 요청하면 에이전트는 프롬프트를 전달하여 생성 도구를 호출하고, 생성된 이미지를 인라인으로 반환합니다. 에이전트는 해당 이미지에 대한 참조를 컨텍스트에 유지하므로, 같은 대화 안에서 이미지를 설명하거나 재사용할 수 있습니다.

## 편집 {#editing}

사용자가 이미지를 업로드한 뒤 색상 변경, 객체 추가, 구도 확장과 같은 수정을 요청하면 에이전트는 도구의 편집 변형을 호출합니다. 출력 결과는 요청에 따라 해당 영역을 대체하거나 원본 이미지를 확장합니다.

## 참고 {#notes}

* 생성된 이미지는 별도의 비전 분석으로 자동 전달되지 않습니다. 에이전트가 이미지를 *해석*하게 하려면 사용자가 업로드한 이미지에 [비전](/ko/agents/builder/vision)을 사용하십시오.
* provider의 콘텐츠 정책이 적용됩니다. provider의 정책을 위반하는 프롬프트에는 이미지 대신 오류가 반환됩니다.
