Model Context Protocol(MCP)은 AI 모델에 도구와 데이터 소스를 노출하기 위한 개방형 표준입니다. ClickHouse Agent에 MCP 서버를 연결하면 에이전트는 해당 서버가 노출하는 모든 기능에 액세스할 수 있습니다. 이슈 트래커, 관측성 백엔드, 내부 API, 타사 SaaS는 물론 MCP 엔드포인트를 제공하는 것이라면 무엇이든 해당됩니다.

## MCP 서버 연결 {#attach-an-mcp-server}

에이전트 빌더에서 **MCP 서버** 섹션을 열고 **서버 추가**를 클릭하십시오. 서버의 URL과 인증 설정을 입력한 다음, 이 에이전트가 사용할 서버 도구를 선택하십시오. 마지막으로 에이전트를 저장하십시오.

하나의 에이전트에 여러 서버를 연결할 수 있습니다. 에이전트가 호출하는 각 도구는 대화에 로그로 기록되므로 사용자는 에이전트가 수행한 작업을 확인할 수 있습니다.

## 전송 방식 {#transport}

ClickHouse Agents는 프로덕션급 MCP 전송 방식인 Streamable HTTP를 사용합니다. 연결할 서버는 ClickHouse Cloud에서 HTTP(S)로 연결할 수 있어야 합니다.

## 인증 {#authentication}

MCP 서버에는 자격 증명이 필요할 수 있습니다. Agents는 다음 방식을 지원합니다.

* **Bearer 토큰** 및 기타 정적 헤더 - 서버를 구성할 때 지정하는 고정 값입니다.
* **OAuth 2.0** - 대화형 흐름입니다. 본인(또는 액세스 권한이 있는 사용자)이 서버의 도구를 처음 호출하면 브라우저에 로그인 창이 열리며, 이후 토큰은 자동으로 관리 및 갱신됩니다.
* **사용자별 자격 증명(Per-user credentials)** - 서버 구성의 변수가 호출한 사용자의 프로필 값으로 대체됩니다. 따라서 각 사용자는 공유 서비스 계정 대신 자신의 아이덴티티로 인증합니다.

사용자가 제공한 자격 증명은 암호화되어 저장되며, 해당 자격 증명을 입력한 사용자에게만 적용됩니다. 한 사용자의 자격 증명은 다른 사용자의 에이전트 실행에 절대 노출되지 않습니다.

## 제한 {#limits}

에이전트 실행 1회에서는 요청당 서로 다른 MCP 서버 대상을 최대 50개, 확장된 도구 구성을 최대 100개까지 참조할 수 있습니다. 이보다 많은 대상이나 구성이 필요한 에이전트는 [서브에이전트](/ko/agents/builder/subagents)로 분할하십시오.
