Cloud 콘솔에서 사용자 정의 에이전트를 구축하고, 서비스에 자연어 쿼리를 실행해 보세요.

## 사전 요구 사항 {#prerequisites}

* 쿼리를 실행할 수 있는 ClickHouse Cloud 서비스가 필요합니다.
* 에이전트 빌더에서 **에이전트 만들기** 옵션을 사용할 수 있어야 합니다. 이 옵션이 보이지 않으면 [공유 및 접근](/ko/agents/sharing-and-access)에 설명된 대로 관리자 설정에서 에이전트 생성 권한을 부여해 달라고 조직 관리자에게 요청하십시오.

## 에이전트 빌드하기 {#build-the-agent}

<Steps>
  <Step title="ClickHouse Agents 실행" id="launch-agents">
    클라우드 서비스의 왼쪽 사이드바에서 **ClickHouse agents**를 클릭하여 에이전트 런치패드를 엽니다. 그런 다음 **Launch ClickHouse agents**를 클릭하여 에이전트 빌더를 엽니다.

    <div className="ch-image-lg">
      <Frame>
        ![ClickHouse agents (Beta)가 선택된 클라우드 서비스 내비게이션과 Launch ClickHouse agents 버튼이 있는 런치패드](/images/cloud/agent-builder/launch-ch-agents.webp)
      </Frame>
    </div>
  </Step>

  <Step title="에이전트 생성" id="create-the-agent">
    에이전트 빌더에서 왼쪽 패널 상단의 **Create New Agent**를 클릭한 후 다음 핵심 필드를 입력합니다.

    * **Name** - 에이전트를 식별하는 짧은 이름입니다.
    * **Description** - 에이전트의 용도에 대한 설명으로, 팀원에게 표시됩니다.
    * **Category** - 에이전트의 범주입니다. 조직에 사용자 지정 범주가 없다면 `General`로 그대로 두어도 됩니다.
    * **Instructions** - 시스템 프롬프트로, 에이전트의 역할, 답변해야 할 질문, 준수해야 할 비즈니스 규칙을 기술합니다.
    * **Model** - 드롭다운에서 모델을 선택합니다.

    <div className="ch-image-lg">
      <Frame>
        ![Create New Agent 드롭다운, 양식 필드(Name, Description, Category, Instructions, Model), Capabilities 섹션이 표시된 에이전트 빌더 패널](/images/cloud/agent-builder/agent-builder.webp)
      </Frame>
    </div>
  </Step>

  <Step title="기능 및 도구 연결" id="attach-tools">
    에이전트의 기능과 도구는 두 곳에서 설정합니다.

    메인 패널의 **Capabilities** — [Run Code](/ko/agents/builder/code-interpreter), [Web Search](/ko/agents/builder/web-search), File Context, Artifacts, [MCP Servers](/ko/agents/builder/mcp-servers), [Skills](/ko/agents/builder/skills) 등 자체 제공 기능입니다. 에이전트에 필요한 항목의 토글을 켜세요.

    <div className="ch-image-sm">
      <Frame>
        ![Run Code, Web Search, File Context, Artifacts, MCP Servers, Skills 토글이 표시된 에이전트 빌더 패널의 Capabilities 섹션](/images/cloud/agent-builder/capabilities.webp)
      </Frame>
    </div>

    패널 하단의 **Add Tools** 버튼에서 추가하는 **Tools** — [이미지 생성](/ko/agents/builder/image-generation), [비전](/ko/agents/builder/vision), 검색 API, 외부 서비스 등 타사 통합입니다.

    <div className="ch-image-sm">
      <Frame>
        ![Add Tools 버튼이 강조 표시된 에이전트 빌더 패널 하단](/images/cloud/agent-builder/tools-button.webp)
      </Frame>
    </div>

    **Add Tools**를 클릭하면 카탈로그를 둘러볼 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![Google, OpenAI Image Tools, Wolfram, DALL-E-3, Tavily Search, Calculator, Stable Diffusion 등 타사 통합이 그리드로 표시된 Agent Tools 모달 대화 상자](/images/cloud/agent-builder/tools-modal.webp)
      </Frame>
    </div>

    [하위 에이전트](/ko/agents/builder/subagents)는 **Advanced settings**에서 구성합니다. 자세한 내용은 하위 에이전트 페이지를 참조하세요.

    연결된 기능과 도구는 언제든지 변경할 수 있습니다.
  </Step>

  <Step title="쿼리 실행" id="run-a-query">
    에이전트를 저장하고 새 대화를 연 다음, 에이전트 선택기에서 해당 에이전트를 선택합니다. *&quot;이번 주 행 수 기준 상위 10개 테이블은 무엇입니까?&quot;*&#xC640; 같은 질문을 입력하면 에이전트가 계획을 세우고 필요에 따라 도구를 호출한 뒤 답변을 반환합니다.

    <div className="ch-image-lg">
      <Frame>
        !['이번 주 행 수 기준 상위 10개 테이블은 무엇입니까?'라는 질문과 에이전트의 응답이 표시된 채팅 화면 — 전체 서비스에서 행 수 기준 상위 10개 테이블의 순위를 매긴 마크다운 표와 그 아래의 Key Observations](/images/cloud/agent-builder/chat-query.webp)
      </Frame>
    </div>
  </Step>
</Steps>
