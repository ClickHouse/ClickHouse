## 대화 {#conversations}

왼쪽 탐색 메뉴에서 작성 아이콘을 클릭하여 새 대화를 시작합니다.
대화 창 왼쪽 상단의 에이전트 셀렉터 대화 상자에서 사용할 에이전트를 선택합니다. 기본적으로 **ClickHouse Agent**가 선택되어 있습니다.
이제 컴포저에 메시지를 입력하고 전송을 누릅니다. 각 대화는 사이드바 이력에 저장되며, 나중에 다시 열거나 이름을 변경하거나 삭제할 수 있습니다.

작성한 메시지는 그 자리에서 바로 편집할 수 있으며, 그러면 에이전트가 대화 이력의 해당 지점부터 응답을 다시 생성합니다.
메시지를 다시 전송하지 않고 에이전트의 마지막 응답만 다시 생성할 수도 있습니다.

## 북마크 {#bookmarks}

메시지나 대화 전체를 북마크해 두면 나중에 빠르게 찾을 수 있습니다. 북마크는 본인에게만 표시되며, 대화 이름을 변경해도 그대로 유지됩니다.

## 고정된 대화 {#pinned-conversations}

대화를 고정하면 아래에 날짜별로 그룹화된 대화 이력과 분리되어 사이드바 상단에 계속 표시됩니다. 사이드바에서 해당 대화의 옵션 메뉴(점 3개 아이콘)를 열고 **Pin**을 선택하십시오. 고정된 대화는 **Today**, **Yesterday** 및 그 이전 그룹 위에 있는 **Pinned** 섹션에 모아서 표시됩니다.

고정을 해제하려면 같은 메뉴를 열고 **Unpin**을 선택하십시오.

## 분기 {#forking}

분기는 특정 메시지에서 갈라져 나온 새 대화를 만듭니다. 이 기능을 사용하면 원래 스레드에 영향을 주지 않고 다른 경로를 탐색할 수 있습니다.
사용할 수 있는 대화 분기 모드는 3가지입니다.

* **Visible messages only** - 분기한 메시지까지 이어지는 직접 경로를 복사합니다.
* **Include related branches** - 기본 경로와 함께 기존의 모든 분기를 복사합니다.
* **Include all to here** - 분기한 메시지까지의 모든 내용을 복사합니다.

분기된 대화는 독립적이므로 변경 사항이 원래 대화에 동기화되지 않습니다.

## 채팅 공유 {#sharing-chats}

모든 대화에 대해 공유 링크를 생성하여 팀원에게 보내거나 나중에 참고할 수 있도록 저장할 수 있습니다. 링크를 받은 사람은 산출물과 표시된 분기를 포함한 대화를 읽기 전용으로 볼 수 있습니다. 링크는 공유 대시보드에서 언제든지 철회할 수 있습니다.

기존 메시지를 편집한 내용은 공유 화면에 반영되지만, 링크를 생성한 이후에 추가된 메시지는 반영되지 않습니다.

공유 링크를 보는 사람은 누구나 **Continue this chat**을 클릭하여 자신의 계정에서 대화를 이어갈 수 있습니다. 이때 현재 보고 있는 분기를 포함한 대화가 해당 사용자의 이력에 새로운 비공개 대화로 복사되며, 원본 대화는 그대로 유지됩니다.

대화를 공유하려면 사이드바에서 해당 대화의 메뉴를 열고 **공유**를 선택하십시오.

## 키보드 단축키 {#keyboard-shortcuts}

키보드 단축키 목록은 `Cmd+Shift+/`(Windows 및 Linux에서는 `Ctrl+Shift+/`)를 누르거나 계정 메뉴의 **Help** → **키보드 단축키**에서 열 수 있습니다. 모든 단축키는 원하는 대로 변경할 수 있습니다. 대화 상자에서 행을 클릭하면 새 키 조합을 기록할 수 있으며, 원래대로 되돌리려면 **Reset all to defaults**를 클릭하십시오.

기본 단축키는 다음과 같습니다.

| 작업              | macOS                 | Windows 및 Linux        |
| --------------- | --------------------- | ---------------------- |
| 키보드 단축키 표시      | `Cmd+Shift+/`         | `Ctrl+Shift+/`         |
| 새 채팅            | `Cmd+Shift+O`         | `Ctrl+Shift+O`         |
| 채팅 입력창으로 포커스 이동 | `Shift+Esc`           | `Shift+Esc`            |
| 파일 업로드          | `Cmd+Shift+U`         | `Ctrl+Shift+U`         |
| 마지막 응답 복사       | `Cmd+Shift+;`         | `Ctrl+Shift+;`         |
| 메시지 전송          | `Cmd+Enter`           | `Ctrl+Enter`           |
| 사이드바 표시/숨기기     | `Cmd+Shift+S`         | `Ctrl+Shift+S`         |
| 모델 선택기 열기       | `Cmd+Shift+M`         | `Ctrl+Shift+M`         |
| 검색창으로 포커스 이동    | `Cmd+/`               | `Ctrl+/`               |
| 설정 열기           | `Cmd+Shift+,`         | `Ctrl+Shift+,`         |
| 대화 북마크          | `Cmd+Shift+B`         | `Ctrl+Shift+B`         |
| 생성 중지           | `Cmd+Shift+X`         | `Ctrl+Shift+X`         |
| 응답 다시 생성        | `Cmd+Shift+E`         | `Ctrl+Shift+E`         |
| 마지막 메시지 편집      | `Cmd+Shift+I`         | `Ctrl+Shift+I`         |
| 응답 계속 생성        | `Cmd+Shift+C`         | `Ctrl+Shift+C`         |
| 마지막 코드 블록 복사    | `Cmd+Shift+K`         | `Ctrl+Shift+K`         |
| 맨 위로 스크롤        | `Cmd+Shift+Up`        | `Ctrl+Shift+Up`        |
| 맨 아래로 스크롤       | `Cmd+Shift+Down`      | `Ctrl+Shift+Down`      |
| 대화 보관           | `Cmd+Shift+L`         | `Ctrl+Shift+L`         |
| 대화 삭제           | `Cmd+Shift+Backspace` | `Ctrl+Shift+Backspace` |

에이전트, 프롬프트, 파일, 북마크 등의 패널을 여는 단축키도 직접 할당할 수 있습니다. 이러한 패널에는 기본 단축키가 지정되어 있지 않습니다.
