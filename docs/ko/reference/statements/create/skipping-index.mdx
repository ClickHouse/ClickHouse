도입 버전: v22.7.0

`MergeTree` 엔진 계열의 테이블에 [데이터 건너뛰기 인덱스(data skipping index)](/ko/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-data_skipping-indexes)를 추가합니다. [`ALTER TABLE ... ADD INDEX`](/ko/reference/statements/alter/skipping-index#add-index)를 독립형 형식으로 제공하는 SQL 문이며, 동일한 `ALTER ADD INDEX` 권한(privilege)이 필요합니다.

## 구문 {#syntax}

```sql
CREATE [UNIQUE] INDEX [IF NOT EXISTS] name ON [db.]table [ON CLUSTER cluster] expression TYPE type [GRANULARITY value]
```

* `expression` - 인덱싱할 표현식이며, 괄호로 묶을 수도 있습니다. 괄호로 묶은 목록 `(expr1, expr2, ...)`은 `CREATE TABLE`의 `INDEX name (expr1, expr2, ...)`과 마찬가지로 모든 표현식을 대상으로 하나의 인덱스를 생성합니다.
* `TYPE type [GRANULARITY value]` - `CREATE TABLE`의 `INDEX` 절과 같습니다. [스킵 인덱스 유형](/ko/reference/engines/table-engines/mergetree-family/mergetree#skip-index-types)을 참조하십시오.
* `IF NOT EXISTS` - 테이블에 이름이 `name`인 인덱스가 이미 있으면 쿼리는 아무 작업도 수행하지 않습니다.

`ADD INDEX`와 마찬가지로 이 SQL 문은 테이블 메타데이터만 변경합니다. 테이블에 이미 있는 데이터에 대한 인덱스를 빌드하려면 [`ALTER TABLE ... MATERIALIZE INDEX`](/ko/reference/statements/alter/skipping-index#materialize-index)를 실행하십시오.

## SQL 호환성 {#sql-compatibility}

다른 데이터베이스 시스템과의 호환성을 위해 다음과 같이 동작합니다.

* 괄호로 묶인 목록에서 표현식 뒤에 오는 `ASC`와 `DESC`는 무시됩니다.
* `CREATE UNIQUE INDEX`는 [`create_index_ignore_unique`](/ko/reference/settings/session-settings/create#create_index_ignore_unique)가 `1`이 아니면 거부됩니다. 이 설정이 `1`이면 `UNIQUE`는 무시되고 일반 인덱스가 생성됩니다.
* `TYPE`이 없는 `CREATE INDEX`는 [`allow_create_index_without_type`](/ko/reference/settings/session-settings/allow#allow_create_index_without_type)이 `1`이 아니면 거부됩니다. 이 설정이 `1`이면 쿼리는 아무 작업도 수행하지 않습니다.

## 예시 {#example}

```sql title="Query"
CREATE TABLE t (id UInt64, s String) ENGINE = MergeTree ORDER BY id;
INSERT INTO t SELECT number, toString(number) FROM numbers(1000);
CREATE INDEX idx_s ON t (s) TYPE bloom_filter GRANULARITY 1;
ALTER TABLE t MATERIALIZE INDEX idx_s SETTINGS mutations_sync = 1;
SELECT name, type, expr, granularity FROM system.data_skipping_indices WHERE database = currentDatabase() AND table = 't';
```

```text title="Response"
┌─name──┬─type─────────┬─expr─┬─granularity─┐
│ idx_s │ bloom_filter │ s    │           1 │
└───────┴──────────────┴──────┴─────────────┘
```
