## direct {#direct}

딕셔너리는 메모리에 저장되지 않으며, 요청을 처리할 때 소스에 직접 접근합니다.

딕셔너리 키는 [UInt64](/ko/reference/data-types/int-uint) 타입입니다.

조회(lookup)만 선택적으로 동작합니다. `dictGet` 및 기타 딕셔너리 함수는 요청된 키에 대해서만 소스를 쿼리하지만, 딕셔너리를 **테이블처럼** 읽는 것은 키 기반 조회가 아닙니다. `SELECT ... FROM <dictionary> WHERE key IN (...)`는 키 필터가 딕셔너리 내부로 푸시다운되지 않기 때문에, 소스 전체를 읽은 뒤 결과를 필터링합니다. 특정 키에 대해 소스를 쿼리하려면 딕셔너리 함수를 사용하십시오.

로컬 파일을 제외한 모든 유형의 [소스](/ko/reference/statements/create/dictionary/sources/overview#dictionary-sources)를 지원합니다.

구성 예시:

<Tabs>
  <Tab title="DDL">
    ```sql
    LAYOUT(DIRECT())
    ```
  </Tab>

  <Tab title="설정 파일">
    ```xml
    <layout>
      <direct />
    </layout>
    ```
  </Tab>
</Tabs>
