사용자 또는 Role에 할당할 수 있는 [설정 프로필](/ko/concepts/features/security/access-rights#settings-profiles-management)을 생성합니다.

구문:

```sql
CREATE SETTINGS PROFILE [IF NOT EXISTS | OR REPLACE] name1 [, name2 [,...]]
    [ON CLUSTER cluster_name]
    [IN access_storage_type]
    [SETTINGS variable [= value] [MIN [=] min_value] [MAX [=] max_value] [CONST|READONLY|WRITABLE|CHANGEABLE_IN_READONLY] | INHERIT 'profile_name'] [,...]
    [TO {{role1 | user1 [, role2 | user2 ...]} | NONE | ALL | ALL EXCEPT {role1 | user1 [, role2 | user2 ...]}}]
```

`ON CLUSTER` 절을 사용하면 클러스터 전체에 설정 프로필을 생성할 수 있습니다. 자세한 내용은 [분산 DDL](/ko/reference/statements/distributed-ddl)을 참조하십시오.

`CREATE SETTINGS PROFILE`에는 [CREATE SETTINGS PROFILE](/ko/reference/statements/grant#access-management) 권한이 필요합니다. `OR REPLACE`는 동일한 이름의 기존 프로필을 해당 프로필이 적용된 Role 정보까지 포함하여 폐기하므로, 추가로 [DROP SETTINGS PROFILE](/ko/reference/statements/grant#access-management) 권한이 필요합니다. `DROP SETTINGS PROFILE` 권한은 프로필의 존재 여부와 관계없이 필요하므로, 이 SQL 문을 사용하여 어떤 프로필이 존재하는지 알아낼 수는 없습니다.

## 예시 {#example}

사용자를 생성하세요:

```sql
CREATE USER robin IDENTIFIED BY 'password';
```

`max_memory_usage` 설정의 값과 제약 조건을 지정한 `max_memory_usage_profile` 설정 프로필을 생성하고, 이를 사용자 `robin`에 할당합니다:

```sql
CREATE
SETTINGS PROFILE max_memory_usage_profile SETTINGS max_memory_usage = 100000001 MIN 90000000 MAX 110000000
TO robin
```
