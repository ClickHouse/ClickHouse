```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

단일 `UInt8` 유형의 컬럼을 반환하며, 테이블 또는 데이터베이스가 존재하지 않으면 값 `0`을, 지정된 데이터베이스에 테이블이 존재하면 값 `1`을 포함합니다.

## 서브쿼리 형식 {#subquery-form}

`EXISTS` 연산자는 서브쿼리가 행을 하나라도 반환하는지 확인합니다. 서브쿼리 결과가 비어 있으면 `0`을, 그렇지 않으면 `1`을 반환합니다.

`EXISTS`는 [`WHERE`](/ko/reference/statements/select/where) 절에서 사용할 수 있습니다. 서브쿼리에서는 외부 쿼리의 테이블이나 컬럼을 참조할 수 없습니다.

**구문**

```sql
EXISTS(subquery)
```

**예시**

서브쿼리가 행을 반환하는지 확인합니다:

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

여러 행을 반환하는 서브쿼리와 함께 `WHERE` 절에서 `EXISTS`를 사용합니다:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

서브쿼리 결과가 비어 있으면 `EXISTS`는 `0`을 반환합니다:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```

**관련 항목:** `SHOW`, `DESCRIBE TABLE`, `CREATE`
