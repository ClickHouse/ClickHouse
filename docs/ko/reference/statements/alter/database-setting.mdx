데이터베이스 엔진의 설정을 변경합니다. 변경 가능한 설정은 엔진마다 다르며, 데이터베이스를 생성한 후에는 일부 엔진이나 설정을 수정하지 못할 수도 있습니다.

이 SQL 문은 데이터베이스 엔진 설정을 변경하며, 세션 설정(Session Settings)이나 데이터베이스 내 테이블(tables)의 기본값은 변경하지 않습니다.

## 구문 {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

지정된 클러스터의 모든 호스트에서 SQL 문을 실행하려면 `ON CLUSTER`를 사용하십시오.
이 SQL 문을 실행하려면 `ALTER DATABASE SETTINGS` 권한(privilege)이 필요합니다.

## 지원되는 설정 {#supported-settings}

각 데이터베이스 엔진의 설정과 제한 사항은 해당 엔진의 문서를 참조하십시오. 예를 들면 다음과 같습니다.

* [`Atomic`](/ko/reference/engines/database-engines/atomic) 및 [`Ordinary`](/ko/reference/engines/database-engines/ordinary)는 `max_tables` 변경을 지원합니다.
* [`MaterializedPostgreSQL`](/ko/reference/engines/database-engines/materialized-postgresql)은 `materialized_postgresql_max_block_size` 등 일부 복제 설정의 변경을 지원합니다.
* [`DataLakeCatalog`](/ko/reference/engines/database-engines/datalake)는 일부 카탈로그(Catalog) 설정의 변경을 지원하며, 사용 가능한 설정은 카탈로그 유형에 따라 다릅니다.

지원되지 않는 엔진이나 설정을 사용하면 예외가 발생합니다.

## 예시 {#example}

`Atomic` 데이터베이스의 최대 테이블 수를 변경합니다:

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

데이터베이스 수준의 이 제한을 해제하려면 `max_tables`를 `0`으로 설정하십시오.

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
