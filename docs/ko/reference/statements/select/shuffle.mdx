`SHUFFLE` 절은 쿼리 결과(query result)의 행(rows)을 균등한 무작위 순서로 반환합니다. 이 절은 [ORDER BY](/ko/reference/statements/select/order-by) 절 대신 사용하며, ORDER BY 절과 함께 사용할 수 없습니다.

`ORDER BY rand()`와 동일한 결과를 반환하지만, O(n * log(n))이 아닌 O(n) 시간에 동작합니다.

`SHUFFLE`은 `LIMIT` 없이 사용하여 모든 행의 순서를 무작위로 섞거나, `LIMIT n`과 함께 사용하여 `n`개 행의 균등 무작위 표본(sample)을 추출할 수 있습니다(추출된 행도 무작위 순서로 반환됩니다). `LIMIT n`을 사용하면 각 스트림이 `n`개의 행만 유지하므로, 쿼리 결과의 행 수와 관계없이 메모리 사용량(memory usage)은 O(n)입니다. `OFFSET`과 `LIMIT BY`는 `ORDER BY`와 함께 사용할 때와 동일하게 사용할 수 있습니다.

<Note>
  이 기능은 실험적 기능입니다. [`allow_experimental_shuffle_query`](/ko/reference/settings/session-settings#allow_experimental_shuffle_query) 설정으로 활성화하십시오.
</Note>

## 구현 세부 사항 {#implementation-details}

무작위 선택은 필요한 시점에 이루어집니다. 즉, 행에 대한 무작위 값을 미리 생성하거나 저장하지 않습니다. `LIMIT`이 없으면 각 행은 `max_threads`개의 스트림 중 무작위로 선택된 하나로 전송되고, 각 스트림은 Fisher-Yates 알고리즘으로 병렬로 셔플(shuffle)되며(CPU 캐시에 들어가는 크기의 파트 단위로), 이후 스트림들이 하나로 이어 붙여집니다. `LIMIT n`이 있으면 각 스트림은 저장소 샘플링(reservoir sampling)을 통해 `n`개 행의 균등 무작위 표본(sample)을 유지합니다. 이 방식은 표본에 포함될 수 없는 행을 살펴보지 않고 건너뛰며, 이후 표본들을 머지합니다. 이때 각 스트림에서 가져올 행 수는 스트림별 행 수를 대상으로 한 비복원 샘플링으로 결정됩니다. 분산 쿼리(Distributed Query)에서는 원격 서버가 데이터를 셔플하고 행에 정렬된 무작위 키를 부여하며, initiator는 셔플된 스트림을 이 키를 기준으로 머지합니다. 이 과정에는 O(1) 메모리만 필요합니다.

`LIMIT`이 없으면 `SHUFFLE`은 모든 행을 메모리에 유지합니다. `ORDER BY`와 달리 데이터를 디스크로 유출하지 않습니다.

무작위 값이 쿼리의 다른 곳에서 사용되지 않고 외부 정렬(sorting)이 비활성화되어 있으면 `ORDER BY rand()`와 `ORDER BY rand64()`를 `SHUFFLE`과 같은 방식으로 실행할 수 있습니다(`query_plan_use_shuffle_for_order_by_rand` 설정). 외부 정렬이 구성되어 있으면 유한한 `LIMIT`이 있더라도 이 최적화는 비활성화됩니다. 표본이 여전히 메모리를 초과할 수 있지만 `SHUFFLE`은 디스크로 유출할 수 없기 때문입니다. 유한한 `LIMIT`이 지정된 `ORDER BY rand64()`는 무작위 값의 모든 비트를 보존하기 위해 정렬 방식을 그대로 사용합니다.

## 예시 {#examples}

```sql
SET allow_experimental_shuffle_query = 1;

SELECT number FROM numbers(5) SHUFFLE;
```

```text
┌─number─┐
│      3 │
│      0 │
│      4 │
│      1 │
│      2 │
└────────┘
```

무작위로 추출한 3개 행의 표본(sample):

```sql
SELECT number FROM numbers(1000000) SHUFFLE LIMIT 3;
```

```text
┌─number─┐
│ 493721 │
│  20857 │
│ 871324 │
└────────┘
```

`SHUFFLE`은 `FROM` 절 뒤에서 키워드로 사용됩니다. `shuffle`을 테이블 별칭으로 사용하려면 `AS shuffle`로 작성하세요.
