## async_insert_deduplicate {#async_insert_deduplicate}

<SettingsInfoBlock type="Bool" default_value="0" />

복제된 테이블(Replicated Table)에서 async INSERT 쿼리의 삽입 블록에 대해 중복 제거를 수행할지 지정합니다.

이 설정은 [`deduplicate_insert`](/ko/reference/settings/session-settings/deduplicate-insert#deduplicate_insert)가 `backward_compatible_choice`로 설정된 경우에만 적용됩니다.

## async_insert_select_as_async_insert {#async_insert_select_as_async_insert}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "`INSERT ... SELECT` 쿼리에 대해 비동기 삽입을 기본적으로 활성화합니다."}]}]} />

`async_insert`가 활성화되어 있고 쿼리가 조건을 충족할 때(종속 뷰가 없는 `MergeTree` 계열 대상 테이블에 작은 블록 하나를 삽입하는 경우), 사용자가 실행한 `INSERT ... SELECT`에서 비동기 삽입 큐를 사용할 수 있는지 여부를 지정합니다. 비활성화하면 `INSERT ... SELECT`는 `async_insert` 설정과 관계없이 항상 동기적으로 실행됩니다. 내부 삽입(갱신 가능 구체화 뷰, `POPULATE`, `CREATE TABLE ... AS SELECT`)은 이 설정과 무관하게 항상 동기적으로 실행됩니다.
