## validate_group_by_all_key_types {#validate_group_by_all_key_types}

`GROUP BY ALL`이 `SELECT` 표현식을 확장하여 만드는 그룹화 키를 [allow&#95;suspicious&#95;types&#95;in&#95;group&#95;by](/ko/reference/settings/session-settings/allow-suspicious#allow_suspicious_types_in_group_by)에 따라 검사할지 여부를 제어합니다. 이 설정을 비활성화하면 26.7 이전 버전의 동작, 즉 `GROUP BY ALL`로 작성된 [Variant](/ko/reference/data-types/variant) 또는 [Dynamic](/ko/reference/data-types/dynamic) 키(예: 타입이 지정되지 않은 JSON 하위 경로를 그룹화 키로 사용하는 경우)를 허용하는 동작이 복원됩니다. 이 설정은 분석기가 활성화된 경우(`enable_analyzer = 1`, 기본값)에만 적용됩니다. 구 분석기에서는 26.7 이전에도 그러한 키가 거부되었으므로 복원할 동작이 없습니다. 명시적인 `GROUP BY`는 이 설정의 영향을 받지 않고 어느 경우에도 그러한 키를 계속 거부합니다. 따라서 이 설정은 명시적인 `GROUP BY`에서도 그러한 키를 허용하는 `allow_suspicious_types_in_group_by`보다 적용 범위가 좁습니다.

가능한 값:

* 0 - `GROUP BY ALL`이 확장하여 만드는 키 타입에 대해 유효성 검사를 수행하지 않습니다.
* 1 - 명시적인 `GROUP BY`가 자체 키를 검사하는 것과 마찬가지로 유효성 검사를 수행합니다.

## validate_polygons {#validate_polygons}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "20.4"},{"label": "1"},{"label": "기본적으로 `pointInPolygon` 함수에서 유효하지 않은 다각형에 대해 잘못된 결과를 반환할 수 있는 대신 예외를 발생시킵니다"}]}]} />

가능한 값:

* 0 — 예외 발생이 비활성화됩니다. `pointInPolygon`은 유효하지 않은 다각형을 허용하며, 이에 대해 잘못된 결과를 반환할 수 있습니다.
* 1 — 예외 발생이 활성화됩니다.
