스레드별 단일 수준 집계 해시 테이블의 최종 머지를 병렬화합니다. 키 공간은 키 해시를 기준으로 서로 겹치지 않는 파티션으로 분할되며, 각 파티션은 독립적으로 머지됩니다. 머지 스레드는 모든 스레드별 테이블을 순회하며 자신의 파티션에 속하는 키를 결합하므로, 두 스레드가 동일한 키를 동시에 처리하지 않습니다. 이 설정을 끄면 단일 수준 테이블은 하나의 스레드에서 순차적으로 머지됩니다. 8비트 및 16비트 키로 집계하는 경우에는 이 설정과 관계없이 자체 범위 파티션 기반 병렬 머지가 유지됩니다.
