## delta_lake_accurate_write_cast {#delta_lake_accurate_write_cast}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "새로운 설정: 기록되는 값을 Delta 쓰기 스키마 타입으로 CAST할 때, 대상 타입에 맞지 않는 값을 조용히 잘라내는 대신 예외를 발생시키는 정확한 CAST를 사용합니다. 26.9 미만의 `compatibility`에서는 예외를 발생시키지 않는 일반 CAST가 사용됩니다."}]}]} />

DeltaLake 테이블에 기록할 때, 각 값을 Delta 쓰기 스키마 타입으로 CAST하되 값이 대상 타입에 맞지 않으면 예외를 발생시키는 정확한 CAST를 사용합니다. 반면 일반 CAST는 값을 조용히 잘라냅니다(예: Delta `byte` 컬럼에 `300`을 기록하는 경우). 예외를 발생시키지 않는 일반 CAST를 사용하려면 `false`로 설정하거나 26.9 미만의 `compatibility` 설정을 사용하십시오.
