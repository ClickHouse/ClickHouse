## enable_software_prefetch_in_aggregation {#enable_software_prefetch_in_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

`GROUP BY` 실행 중 해시 테이블 셀에 대한 소프트웨어 프리페치를 활성화합니다. 프리페치는 집계 해시 테이블이 CPU 캐시에 모두 들어가지 않을 때 메모리 지연 시간을 감춰 주므로, 해시 테이블이 L2 캐시 크기보다 커진 경우에만 사용됩니다.

## enable_software_prefetch_in_join {#enable_software_prefetch_in_join}

<SettingsInfoBlock type="Bool" default_value="1" />

큰 해시 테이블에서 메모리 접근 지연 시간을 줄이기 위해 해시 조인 프로브 단계에서 소프트웨어 프리페치 사용을 활성화합니다.
