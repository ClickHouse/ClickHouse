## max_local_read_bandwidth {#max_local_read_bandwidth}

<SettingsInfoBlock type="UInt64" default_value="0" />

로컬 읽기의 초당 최대 바이트 수입니다.

이 제한은 블록 장치에서 읽은 데이터에 적용됩니다. OS 페이지 캐시에서 처리된 읽기는 읽기 방식이 이를 감지할 수 있는 경우 집계되지 않습니다. 기본값인 `local_filesystem_read_method = 'pread_threadpool'`와 `pread`, 그리고 파일 시스템 캐시 파일 읽기가 이러한 경우에 해당합니다.

## max_local_write_bandwidth {#max_local_write_bandwidth}

<SettingsInfoBlock type="UInt64" default_value="0" />

로컬 쓰기의 초당 최대 바이트 수입니다.
