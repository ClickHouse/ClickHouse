## use_iceberg_manifest_list_partition_pruning {#use_iceberg_manifest_list_partition_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

manifest 목록의 파티션 요약이 쿼리 필터와 일치할 수 없는 Iceberg manifest 파일은 읽지 않고 전체를 건너뜁니다. [use&#95;iceberg&#95;partition&#95;pruning](/ko/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning)이 활성화되어 있어야 하며, manifest 파일에 포함된 고유 파티션 값의 수가 적을 때만 효과가 있습니다. 이러한 형태는 파티션 컬럼을 기준으로 클러스터링한 `rewriteManifests`가 생성합니다.

## use_iceberg_table_statistics_ndv {#use_iceberg_table_statistics_ndv}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "JOIN 재정렬을 위해 `metadata.json`의 테이블 통계에서 Iceberg 컬럼의 고유 값(distinct values) 개수를 가져오는 새로운 설정입니다."}]}]} />

[`use_datalake_metadata_statistics`](/ko/reference/settings/session-settings/use#use_datalake_metadata_statistics)가 활성화되어 있으면, 매니페스트 파일에 고유 값(distinct values) 개수 정보가 없는 Iceberg 컬럼에 대해 `metadata.json`의 테이블 통계에서 해당 개수를 가져옵니다. 이 값은 Spark `compute_table_stats` 또는 Trino `ANALYZE`가 기록한, 해당 컬럼 하나만을 대상으로 하는 `apache-datasketches-theta-v1` 블롭의 `ndv` 속성입니다. 읽는 스냅샷을 기준으로 계산된 블롭만 사용됩니다. 이 값은 JOIN 재정렬과 조건 추정에만 사용되며, 쿼리 결과(query results)에는 영향을 주지 않습니다.
