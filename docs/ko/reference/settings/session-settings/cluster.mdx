## cluster_for_parallel_replicas {#cluster_for_parallel_replicas}

현재 서버가 속한 세그먼트의 클러스터

Cloud 기본값: `default`.

## cluster_function_process_archive_on_multiple_nodes {#cluster_function_process_archive_on_multiple_nodes}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "1"},{"label": "새로운 설정"}]}]} />

`true`로 설정하면 cluster function에서 아카이브를 처리할 때 성능이 향상됩니다. 이전 버전에서 아카이브와 함께 cluster function을 사용하는 경우, 25.7+로 업그레이드하는 동안 compatibility를 유지하고 오류를 방지하려면 `false`로 설정해야 합니다.

## cluster_function_wait_for_replica_ms {#cluster_function_wait_for_replica_ms}

<SettingsInfoBlock type="Milliseconds" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "새로운 설정"}]}]} />

`*Cluster` 테이블 함수 또는 객체 스토리지에 대한 병렬 레플리카의 initiator가 특정 레플리카에 할당된 파일을 다른 레플리카에 넘기기 전에 해당 레플리카의 작업 요청을 기다리는 시간입니다. `0`이면 대기를 비활성화합니다.
