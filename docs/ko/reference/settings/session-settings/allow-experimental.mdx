## allow_experimental_analyzer {#allow_experimental_analyzer}

**별칭**: `enable_analyzer`

<SettingsInfoBlock type="Bool" default_value="1" />

v26.9부터 사용되지 않음(obsolete): 분석기는 더 이상 비활성화할 수 없습니다.

분석기는 v24.3부터 기본으로 사용되어 온 쿼리 분석 및 계획 수립 인프라입니다. v26.9에서 이 설정은 지원되는 유일한 값인 `1`로 고정되었으며, `compatibility` 설정으로도 되돌릴 수 없습니다. v26.10에서는 이 설정으로 전환하던 이전 쿼리 분석이 제거되었습니다. 이전 버전과의 호환성을 위해 `0`으로 설정해도 허용되지만 값은 `1`로 대체됩니다. 따라서 여전히 `enable_analyzer = 0`을 지정하는 쿼리, 세션 설정, 설정 프로필, 클라이언트 구성도 분석기가 활성화된 상태로 계속 작동합니다. 이전 쿼리 분석과 쿼리의 동작이나 성능을 비교하려면 v26.9보다 이전 ClickHouse 버전을 사용하십시오.

## allow_experimental_hash_functions {#allow_experimental_hash_functions}

## allow_experimental_parallel_reading_from_replicas {#allow_experimental_parallel_reading_from_replicas}

**별칭**: `enable_parallel_replicas`

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "24.10"},{"label": "0"},{"label": "읽기 작업 기반 병렬 레플리카 기능이 베타 단계로 전환되었습니다. 이 설정은 `enable_parallel_replicas`라는 별칭으로도 사용할 수 있습니다."}]}]} />

각 세그먼트에서 SELECT 쿼리 실행 시 최대 `max_parallel_replicas`개의 레플리카를 사용합니다. 읽기는 병렬로 수행되며 동적으로 조정됩니다. 0 - 비활성화, 1 - 활성화, 실패 시 조용히 비활성화, 2 - 활성화, 실패 시 예외를 발생시킴

## allow_experimental_shuffle_query {#allow_experimental_shuffle_query}

<ExperimentalBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "`SELECT` 쿼리에서 실험적 `SHUFFLE` 절을 활성화하는 새로운 설정입니다."}]}]} />

`SELECT` 쿼리에서 실험적 `SHUFFLE` 절 사용을 허용합니다. `SHUFFLE`은 `ORDER BY` 대신 사용하며, 행(rows)을 균등 분포의 무작위 순서로 반환합니다.
