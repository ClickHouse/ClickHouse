## enable_lightweight_update {#enable_lightweight_update}

**별칭**: `allow_experimental_lightweight_update`

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.8"},{"label": "1"},{"label": "경량 업데이트가 베타 상태로 변경되었습니다. 'allow_experimental_lightweight_update' 설정의 별칭이 추가되었습니다."}]}, {"id": "row-2","items": [{"label": "25.5"},{"label": "0"},{"label": "새로운 설정입니다. 당시에는 설정 이름이 `allow_experimental_lightweight_update`였으며, 현재는 이 설정의 별칭으로 사용됩니다."}]}]} />

경량 업데이트를 허용합니다. 경량 업데이트는 뮤테이션처럼 데이터 파트 전체를 다시 쓰지 않고, 갱신된 값만 패치 파트에 씁니다.

비활성화하면 `UPDATE` 문은 예외를 발생시킵니다. 또한 `ALTER TABLE ... UPDATE` 및 경량 `DELETE`(lightweight `DELETE`)는 `alter_update_mode` 또는 `lightweight_delete_mode`에서 경량 업데이트를 요청하더라도 이를 사용하지 않습니다(`lightweight_force` 또는 `lightweight_update_force`로 설정된 경우에는 예외를 발생시킵니다).
