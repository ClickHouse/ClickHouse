## min_bytes_before_external_group_by {#min_bytes_before_external_group_by}

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "새로운 설정: 외부 `GROUP BY`가 스레드 하나의 집계 상태(aggregation state)를 디스크에 기록하기 전에 도달해야 하는 최소 크기입니다. 이미 임계값을 초과한 쿼리가 모든 블록을 각각 별도의 파일로 기록하는 것을 방지합니다."}]}]} />

외부 `GROUP BY`가 스레드 하나의 집계 상태(aggregation state)를 디스크에 기록하기 전에 도달해야 하는 최소 크기(바이트)입니다.

큰 테이블을 보유한 해시 조인처럼 다른 연산자(operators)로 인해 쿼리의 메모리 사용량이 `max_bytes_before_external_group_by` 또는 `max_bytes_ratio_before_external_group_by`를 초과하면, 이 설정이 없을 때 각 스레드는 집계하는 블록마다 작은 파일을 하나씩 디스크에 기록합니다. 이렇게 생성된 수많은 작은 파일을 다시 읽어 들이는 데 드는 메모리가 쓰기 작업으로 절약한 메모리보다 더 큽니다. 이 설정을 사용하면 각 스레드는 자신의 상태가 지정된 크기에 도달할 때까지 집계를 계속한 후, 이를 하나의 파일로 기록합니다.

임계값을 초과하여 사용되는 메모리는 최대 이 값에 스레드 수를 곱한 크기로 제한됩니다.

가능한 값:

* 양의 정수(바이트 단위 크기).
* `0` — 최솟값 없음. 임계값에 도달하는 즉시 상태를 기록합니다.

## min_bytes_to_use_direct_io {#min_bytes_to_use_direct_io}

<SettingsInfoBlock type="UInt64" default_value="0" />

스토리지 디스크에 direct I/O로 접근하는 데 필요한 최소 데이터 용량입니다.

ClickHouse는 테이블에서 데이터를 읽을 때 이 설정을 사용합니다. 읽어야 할 모든 데이터의 총 스토리지 용량이 `min_bytes_to_use_direct_io`바이트를 초과하면 ClickHouse는 `O_DIRECT` 옵션을 사용해 스토리지 디스크에서 데이터를 읽습니다.

가능한 값:

* 0 — direct I/O가 비활성화됩니다.
* 양의 정수.

## min_bytes_to_use_mmap_io {#min_bytes_to_use_mmap_io}

<SettingsInfoBlock type="UInt64" default_value="0" />

이 설정은 Experimental 상태입니다. 커널에서 사용자 공간으로 데이터를 복사하지 않고 대용량 파일을 읽기 위한 최소 메모리 크기를 설정합니다. [mmap/munmap](https://en.wikipedia.org/wiki/Mmap)은 느리므로 권장 임계값은 약 64 MB입니다. 이 설정은 대용량 파일에만 의미가 있으며, 데이터가 페이지 캐시에 있을 때만 도움이 됩니다.

가능한 값:

* 양의 정수입니다.
* 0 — 대용량 파일을 커널에서 사용자 공간으로 데이터를 복사하는 방식으로만 읽습니다.
