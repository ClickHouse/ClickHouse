이러한 설정은 [system.settings](/ko/reference/system-tables/settings)에서 확인할 수 있으며, [source](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/Settings.cpp)에서 자동 생성됩니다.

## compatibility_ignore_auto_increment_in_create_table {#compatibility_ignore_auto_increment_in_create_table}

<SettingsInfoBlock type="Bool" default_value="0" />

값이 true이면 컬럼 선언에서 AUTO&#95;INCREMENT keyword를 무시하고, 그렇지 않으면 오류를 반환합니다. 이 설정은 MySQL에서 마이그레이션을 간소화합니다.

## compatibility_ignore_collation_in_create_table {#compatibility_ignore_collation_in_create_table}

<SettingsInfoBlock type="Bool" default_value="1" />

활성화하면 `CREATE TABLE` 쿼리의 컬럼 선언에 포함된 `COLLATE` 절을 허용하되 무시합니다. 이를 통해 MySQL 등 다른 데이터베이스 시스템용으로 작성된 테이블 정의(table definition)를 수정하지 않고 그대로 실행할 수 있습니다.

비활성화하면 컬럼에 데이터 정렬(Collation)이 지정된 `CREATE TABLE` 쿼리 실행 시 예외를 발생시킵니다.
