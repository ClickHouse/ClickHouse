## iceberg_compaction_max_bytes_to_merge {#iceberg_compaction_max_bytes_to_merge}

<SettingsInfoBlock type="UInt64" default_value="161061273600" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "161061273600"},{"label": "새 설정입니다. `MergeTree`에서 `max_bytes_to_merge_at_max_space_in_pool`과 같은 방식으로 컴팩션 머지 대상 파일의 총 크기를 제한합니다."}]}]} />

Iceberg 테이블(Iceberg table)의 컴팩션 머지 1회에서 머지되는 데이터 파일의 최대 총 크기이며, 객체 스토리지 기준 파일 크기의 합계입니다.
`MergeTree`의 `max_bytes_to_merge_at_max_space_in_pool`과 동일하게 동작합니다. 백그라운드 풀의 사용 가능한 슬롯 수가
`number_of_free_entries_in_pool_to_lower_max_size_of_merge`보다 적으면 제한 값이 `max_bytes_to_merge_at_min_space_in_pool`로 낮아집니다
(두 설정 모두 구성의 `merge_tree` 섹션에 있습니다).
파티션에서 한도를 초과하여 포함되지 못한 파일은 이후 머지에서 처리됩니다. 포지션 삭제 파일을 적용하는 머지에는 이 설정이 적용되지 않습니다.
