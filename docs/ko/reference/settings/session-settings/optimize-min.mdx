## optimize_min_max_from_files {#optimize_min_max_from_files}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Parquet 컬럼 청크 통계에서 `min` \/ `max`를 계산하는 새로운 설정입니다."}]}]} />

집계 함수로 테이블 컬럼의 `min`과 `max`만 사용하고 `GROUP BY`와 필터가 없는 쿼리에서, 데이터를 읽는 대신 데이터 파일에 저장된 통계를 이용해 컬럼의 `min`과 `max`를 계산하는 기능을 활성화하거나 비활성화합니다. 이 설정은 `Parquet` 포맷을 사용하는 테이블 함수/엔진 `file`에 적용되며(아카이브 내부의 파일은 제외), 모든 row group에 컬럼 청크 통계가 존재하는 정수(integer)(최대 64비트), 날짜, 날짜-시간 및 decimal 컬럼이 대상입니다.

가능한 값:

* 0 - 최적화 비활성화.
* 1 - 최적화 활성화.
