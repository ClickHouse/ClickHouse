## iceberg_insert_max_bytes_in_data_file {#iceberg_insert_max_bytes_in_data_file}

<SettingsInfoBlock type="UInt64" default_value="536870912" />

삽입 작업 시 Iceberg Parquet 데이터 파일의 최대 바이트 수입니다.

기본값은 Iceberg 테이블 속성 `write.target-file-size-bytes`의 문서화된 기본값(512 MiB)을 따릅니다.
https://iceberg.apache.org/docs/1.5.2/configuration/ 을 참조하십시오. 단, ClickHouse는 이 제한을 지금까지
파일에 기록된 데이터의 압축되지 않은 크기와 비교하는 반면, Iceberg 속성은 최종 생성되는 파일의 크기를 기준으로
한다는 점에 유의하십시오. 또한 `iceberg_insert_max_rows_in_data_file`은 파일 크기와는 별개로 파일을 제한합니다.
