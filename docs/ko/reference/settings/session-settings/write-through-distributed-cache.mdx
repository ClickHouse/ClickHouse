## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "새로운 Cloud 설정"}]}]} />

ClickHouse Cloud에서만 효과가 있습니다. 쓰기 버퍼당 Distributed Cache 서버에 기록되는 버퍼의 최대 크기입니다. 객체 스토리지에 기록되는 버퍼와는 별개이며, 그 버퍼는 업로드 part 크기까지 계속 커집니다. 0이면 `DBMS_DEFAULT_BUFFER_SIZE`(1 MiB)가 사용됩니다. 버퍼는 `adaptive_write_buffer_initial_size` 크기로 시작하여 스트림이 기록되는 동안에만 이 크기까지 커지므로, part가 기록하는 모든 스트림에 대해 미리 할당하지 않습니다.
