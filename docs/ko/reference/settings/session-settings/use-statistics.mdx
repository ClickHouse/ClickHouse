## use_statistics_for_min_max_aggregation {#use_statistics_for_min_max_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "`GROUP BY`와 필터가 없는 `min`, `max`, `count` 집계(aggregations)를 통계가 구체화된(materialized) 파트에서는 파트별 컬럼 통계(Column Statistics)로 처리하고 나머지 파트만 읽도록 하는 새로운 설정입니다. previous_value=false이므로 26.9 이전 버전에 대한 `compatibility` 설정에서는 이 최적화가 비활성화되고 기존 계획이 복원됩니다."}]}]} />

데이터를 읽는 대신 파트별 컬럼 통계(Column Statistics)로 `min`, `max`, `count` 집계(aggregations)를 처리합니다.

활성화하면 `GROUP BY`와 필터가 없는 `SELECT min(column), max(column), count() FROM table` 형태의 쿼리를 통계가 구체화된(materialized) 데이터 파트에서는 컬럼 통계(Column Statistics)(예: MinMax 통계, `auto_statistics_types` MergeTree 설정 참조)로 처리하고, 나머지 파트만 읽습니다.
`count()`는 `use_statistics_for_sum_avg_aggregation`의 집계(aggregations)와 함께 사용될 때에도 통계로 처리됩니다.

가능한 값:

* 0 — 비활성화.
* 1 — 활성화.

## use_statistics_for_part_pruning {#use_statistics_for_part_pruning}

쿼리 실행 중 파트를 필터링하는 데 통계를 사용합니다.

활성화하면 SELECT 쿼리의 프루닝에서 컬럼 통계(Column Statistics)(예: MinMax 통계)를 사용하여, 데이터를 읽기 전에 일치하는 데이터를 포함할 수 없는 파트를 제외합니다.

가능한 값:

* 0 — 비활성화됨.
* 1 — 활성화됨.

## use_statistics_for_sum_avg_aggregation {#use_statistics_for_sum_avg_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "1"},{"label": "`GROUP BY`와 필터가 없는 `sum`, `avg`, `sumCount`, `count(column)` 집계(aggregations)를 파트별 컬럼 통계(Column Statistics)로 처리하는 새로운 설정입니다. previous_value=false이므로 `compatibility`를 26.11 이전 버전으로 설정하면 최적화가 비활성화된 상태로 유지되고 기존 실행 계획이 복원됩니다."}]}]} />

`Nullable` 또는 `LowCardinality`가 아닌 정수(integer) 및 `Decimal` 컬럼에 대해 `GROUP BY`와 필터 없이 수행되는 `sum`, `avg`, `sumCount` 집계(aggregations)를,
컬럼 통계(Column Statistics)가 구체화된(materialized) 데이터 파트에서는 파트별 컬럼 통계(Column Statistics)(`basic` 통계 유형, `MergeTree` 설정인
`auto_statistics_types` 참조)로 처리하고, 나머지
파트만 읽습니다. 이러한 파트에서 `Nullable` 또는 `LowCardinality`가 아닌 컬럼의 `count(column)`은 행(rows) 수로 처리됩니다.
결과(result)는 데이터를 직접 읽었을 때와 정확히 동일합니다.

가능한 값:

* 0 — 비활성화됨.
* 1 — 활성화됨.
