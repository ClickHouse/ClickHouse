## opentelemetry_trace_stateless_worker_discovery {#opentelemetry_trace_stateless_worker_discovery}

<CloudOnlyBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "쿼리가 worker를 프로비저닝하기 위해 보내는 상태 비저장 워커 디스커버리 서비스 요청에 대한 OpenTelemetry 스팬을 수집하는 새로운 설정입니다."}]}]} />

ClickHouse Cloud에서만 적용됩니다. 쿼리 자체가 추적되고 있는 경우, 해당 쿼리가 worker를 프로비저닝(임대)하기 위해 보내는 상태 비저장 워커 디스커버리 서비스 요청의 OpenTelemetry 스팬을 수집합니다.
스팬의 이름은 `StatelessWorkerDiscovery.<action>` 형식이며, `clickhouse.discovery.action` 및 `clickhouse.discovery.status` 속성을 포함합니다.
