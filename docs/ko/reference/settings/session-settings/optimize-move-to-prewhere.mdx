## optimize_move_to_prewhere {#optimize_move_to_prewhere}

<SettingsInfoBlock type="Bool" default_value="1" />

[SELECT](/ko/reference/statements/select/index) 쿼리에서 자동 [PREWHERE](/ko/reference/statements/select/prewhere) 최적화의 사용 여부를 설정합니다.

[*MergeTree](/ko/reference/engines/table-engines/mergetree-family/index) 테이블에서만 작동합니다.

가능한 값:

* 0 — 자동 `PREWHERE` 최적화가 비활성화됩니다.
* 1 — 자동 `PREWHERE` 최적화가 활성화됩니다.

## optimize_move_to_prewhere_if_final {#optimize_move_to_prewhere_if_final}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "FINAL이 포함된 쿼리에서 자동 PREWHERE 최적화를 기본적으로 활성화합니다. 정렬 키에만 의존하면서 쿼리 내에서 결정적인 조건만 이동하므로 결과에는 영향이 없습니다. `compatibility`를 26.10 미만으로 설정하면 이전 동작으로 돌아갑니다."}]}]} />

[FINAL](/ko/reference/statements/select/from#final-modifier) 수정자가 있는 [SELECT](/ko/reference/statements/select/index) 쿼리에서 자동 [PREWHERE](/ko/reference/statements/select/prewhere) 최적화의 사용 여부를 설정합니다.

정렬 키에만 의존하면서 쿼리 내에서 결정적인 조건만 이동하므로,
`FINAL`의 결과에는 영향이 없습니다.

[*MergeTree](/ko/reference/engines/table-engines/mergetree-family/index) 테이블에서만 작동합니다.

가능한 값:

* 0 — `FINAL` 수정자가 있는 `SELECT` 쿼리에서 자동 `PREWHERE` 최적화가 비활성화됩니다.
* 1 — `FINAL` 수정자가 있는 `SELECT` 쿼리에서 자동 `PREWHERE` 최적화가 활성화됩니다.
