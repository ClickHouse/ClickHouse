## create_token_default_ttl_seconds {#create_token_default_ttl_seconds}

<SettingsInfoBlock type="UInt64" default_value="1800" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1800"},{"label": "명시적인 `VALID UNTIL` 또는 `VALID FOR` 절 없이 `CREATE TOKEN`으로 생성된 토큰의 유효 기간을 지정하는 새로운 설정입니다. 이 SQL 문은 새로 도입되었으므로 복원할 이전 동작이 없으며, 이전 값은 기본값 자체입니다. 이전 버전과의 `compatibility`를 적용하더라도 토큰이 만료되지 않게 되어서는 안 됩니다."}]}]} />

자체 `VALID UNTIL` 또는 `VALID FOR` 절을 지정하지 않는 [`CREATE TOKEN`](/ko/reference/statements/create/token)으로 생성된 토큰에 부여되는 유효 기간(초)입니다. 기본값은 30분이므로 더 긴 유효 기간을 지정하지 않은 토큰은 단기간만 유효합니다.

가능한 값:

* 양의 정수 — 토큰은 생성된 후 지정된 초가 지나면 만료됩니다.
* 0 — 명시적 절이 없는 토큰은 만료되지 않습니다.

이는 기본값일 뿐입니다. 쿼리에 명시된 `VALID UNTIL` 또는 `VALID FOR` 절이 항상 우선하며, 이 설정과 관계없이 만료되지 않는 토큰을 생성하는 `VALID UNTIL 'infinity'`도 여기에 포함됩니다.
