## obfuscate_markov_order {#obfuscate_markov_order}

<SettingsInfoBlock type="UInt64" default_value="5" />

`obfuscate` 테이블 함수의 레거시 마르코프 모델에서 사용하는 최대 컨텍스트 버퍼 크기입니다. 모델은 이 값보다 짧은 컨텍스트를 기록하므로 독립형 `clickhouse obfuscator` 도구의 의미 체계가 그대로 유지됩니다. 값은 `[1, 1000]` 범위여야 합니다.
