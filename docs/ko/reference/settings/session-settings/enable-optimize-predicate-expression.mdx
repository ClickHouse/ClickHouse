## enable_optimize_predicate_expression_to_final_subquery {#enable_optimize_predicate_expression_to_final_subquery}

<SettingsInfoBlock type="Bool" default_value="1" />

원격 서버로 전송되는 쿼리가 `FINAL`을 사용하는 경우, 해당 쿼리에 원래 쿼리의 필터(filter)를 추가할 수 있도록 허용합니다(예: `Distributed` 테이블에서 읽는 경우). 이를 통해 원격 서버가 반환하는 데이터의 양을 줄일 수 있습니다.

비활성화하면 이러한 쿼리에 필터(filter)가 추가되지 않으며, 필터(filter)는 원격 서버로부터 데이터를 수신한 후에만 적용됩니다.
