## iceberg_data_file_size_lower_threshold_compaction {#iceberg_data_file_size_lower_threshold_compaction}

<SettingsInfoBlock type="UInt64" default_value="402653184" />

이 값보다 작은 데이터 파일이 compaction 대상으로 선택됩니다.

기본값은 Iceberg 테이블 속성 `write.target-file-size-bytes`의 문서화된 기본값(512 MiB)에 `0.75`를 곱한 값이며,
이는 `rewrite_data_files` 프로시저가 `min-file-size-bytes` 옵션을 도출하는 방식과 동일합니다.
https://iceberg.apache.org/docs/1.5.2/configuration/ 를 참조하십시오.
