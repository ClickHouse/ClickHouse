이 설정은 ClickHouse 서버를 구성하며 ClickHouse 소스에서 자동 생성됩니다.

## reader_executor_memory_pressure_critical_level_pct {#reader_executor_memory_pressure_critical_level_pct}

<SettingsInfoBlock type="UInt64" default_value="95" changeable_without_restart="Yes" />실험적 `ReaderExecutor`가 `Critical` 메모리 압력 수준, 즉 읽기 윈도우를 가장 공격적으로 축소하는 단계로 진입하는 메모리 압력 임계값입니다. 적용 범위, 값의 range 및 순서 규칙은 `reader_executor_memory_pressure_elevated_level_pct`를 참조하십시오.

## reader_executor_memory_pressure_elevated_level_pct {#reader_executor_memory_pressure_elevated_level_pct}

<SettingsInfoBlock type="UInt64" default_value="75" changeable_without_restart="Yes" />메모리 트래커의 하드 메모리 제한 대비 백분율로 지정하는 메모리 압력 임계값입니다. 이 임계값에 도달하면 실험적 `ReaderExecutor`가 `Elevated` 메모리 압력 수준으로 진입하고 읽기 윈도우를 축소하기 시작합니다. 임계값은 서버 전체(`max_server_memory_usage`), 사용자(`max_memory_usage_for_user`), 쿼리(`max_memory_usage`)의 3개 범위에 각각 독립적으로 적용되며, reader는 이 중 가장 높은 값을 사용합니다. 따라서 서버가 유휴 상태이더라도 자체 제한에 근접한 쿼리는 윈도우를 축소합니다. 하드 메모리 제한이 없는 범위는 아무런 영향을 미치지 않습니다. 값은 `[1, 100]` 범위에 있어야 하며 `elevated <= high <= critical`을 충족해야 합니다. 범위를 벗어나거나 순서가 올바르지 않은 세 값은 시작 시와 `SYSTEM RELOAD CONFIG` 실행 시 거부됩니다. `elevated`가 0이면 하드 메모리 제한이 없는 범위를 포함한 모든 범위가 `Elevated` 상태가 되므로 0은 허용되지 않습니다.

## reader_executor_memory_pressure_high_level_pct {#reader_executor_memory_pressure_high_level_pct}

<SettingsInfoBlock type="UInt64" default_value="90" changeable_without_restart="Yes" />실험적 `ReaderExecutor`가 `High` 메모리 압력 수준에 진입하는 메모리 압력 임계값입니다. 범위 및 순서 규칙은 `reader_executor_memory_pressure_elevated_level_pct`를 참조하십시오.
