이 설정은 ClickHouse 서버를 구성하며, ClickHouse 소스 코드에서 자동 생성됩니다.

## totp_track_used_codes_in_keeper {#totp_track_used_codes_in_keeper}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

시간 기반 일회용 비밀번호(TOTP) 코드의 1회 사용 제한을 서버별로 적용하지 않고, 동일한 ZooKeeper 또는 ClickHouse Keeper를 공유하는 모든 서버에 걸쳐 적용합니다.

허용된 코드는 Keeper에서 `totp_used_codes_keeper_path`로 설정된 경로 아래에 기록되며, 사용자마다 사용자 이름의 SHA-256 해시를 이름으로 하는 노드가 하나씩 생성됩니다. 따라서 한 서버에서 허용된 코드는 다른 모든 서버에서 거부되며, 이 기록은 서버를 재시작해도 유지됩니다. 이 설정을 활성화하려면 Keeper가 구성되어 있어야 하며, Keeper를 사용할 수 없는 동안에는 일회용 비밀번호를 이용한 인증이 실패합니다.

**예시**

```xml
<totp_track_used_codes_in_keeper>1</totp_track_used_codes_in_keeper>
```

## totp_used_codes_keeper_path {#totp_used_codes_keeper_path}

<SettingsInfoBlock type="String" default_value="/clickhouse/access/one_time_passwords" changeable_without_restart="No" />

`totp_track_used_codes_in_keeper`가 활성화되어 있을 때, 승인된 시간 기반 일회용 비밀번호(TOTP) 코드가 기록되는 Keeper 내 경로입니다. chroot 없이 하나의 Keeper를 공유하는 클러스터(Clusters)는 서로 다른 경로를 사용해야 합니다. 그렇지 않으면 서로 다른 클러스터에 있는 같은 이름의 사용자가 기록을 공유하게 됩니다.

**예시**

```xml
<totp_used_codes_keeper_path>/clickhouse/access/one_time_passwords</totp_used_codes_keeper_path>
```
