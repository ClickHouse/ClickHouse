이 설정은 ClickHouse 서버 구성에 사용되며 ClickHouse 소스에서 자동 생성됩니다.

<div id="enable_azure_sdk_logging">
  ## enable_azure_sdk_logging
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Azure sdk의 로깅을 활성화합니다.

<div id="enable_read_through_distributed_cache">
  ## enable_read_through_distributed_cache
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />ClickHouse Cloud에서만 적용됩니다. Distributed Cache에서 읽기를 허용합니다. 이 서버 수준 스위치는 재시작 없이 적용되므로 자체 쿼리 프로필이 없는 백그라운드 작업(머지, 뮤테이션, `Buffer` 테이블 플러시)에도 적용됩니다. 개별 쿼리는 `force_read_through_distributed_cache` 설정을 통해 이 설정과 다르게 동작하도록 지정할 수 있습니다.

<div id="enable_silk_runtime">
  ## enable_silk_runtime
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />silk fiber 런타임에 대한 실험적 지원을 활성화합니다. 서버 시작 시 silk fiber scheduler를 초기화하여 이를 지원하는 하위 시스템이 fiber에서 job을 실행할 수 있도록 합니다.

<div id="enable_webterminal">
  ## enable_webterminal
</div>

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />`/webterminal` HTTP 엔드포인트에서 웹 터미널 인터페이스를 활성화합니다. WebSocket을 통해 브라우저에서 대화형 `clickhouse-client` 세션을 제공합니다. `false`로 설정하면 `/webterminal` 요청에 대해 HTTP 상태 `403 Forbidden`을 반환합니다.

<div id="enable_write_through_distributed_cache">
  ## enable_write_through_distributed_cache
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />ClickHouse Cloud에서만 적용됩니다. Distributed Cache에 쓰기를 허용합니다(S3 쓰기도 Distributed Cache에서 수행합니다). 재시작 없이 적용되는 서버 수준 스위치이므로, 자체 쿼리 프로필이 없는 백그라운드 작업(머지, 뮤테이션, `Buffer` 테이블 플러시)에도 적용됩니다. 개별 쿼리는 `force_write_through_distributed_cache` 설정을 통해 이 설정과 다르게 지정할 수 있습니다.
