이 설정들은 ClickHouse 서버를 구성하며, ClickHouse 소스 코드에서 자동 생성됩니다.

## statistics_cache_policy {#statistics_cache_policy}

<SettingsInfoBlock type="String" default_value="SLRU" changeable_without_restart="No" />통계 캐시의 eviction 정책 이름입니다. 가능한 값: `LRU`, `SLRU`, `SIEVE`.

## statistics_cache_prewarm_ratio {#statistics_cache_prewarm_ratio}

<SettingsInfoBlock type="Double" default_value="0.95" changeable_without_restart="No" />예열 시 채울 통계 캐시의 비율로, 전체 크기 대비 비율입니다.

## statistics_cache_size {#statistics_cache_size}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="Yes" />MergeTree 엔진 계열 테이블의 데이터 파트에 대한 컬럼 통계(Column Statistics) 캐시의 최대 크기입니다. 통계는 데이터 파트와 컬럼 단위로 캐시되며, 필요할 때 로드되어 쿼리마다 실행 중에 동적으로 머지됩니다.

## statistics_cache_size_ratio {#statistics_cache_size_ratio}

<SettingsInfoBlock type="Double" default_value="0.5" changeable_without_restart="No" />통계 캐시의 전체 크기 대비 보호 큐(SLRU 정책 사용 시)의 크기 비율입니다.
