이 설정은 ClickHouse 서버를 구성하는 설정으로, ClickHouse 소스 코드에서 자동 생성됩니다.

## amber_connections_hard_limit {#amber_connections_hard_limit}

<SettingsInfoBlock type="UInt64" default_value="200000" changeable_without_restart="No" />이 제한에 도달하면 연결 생성 시도 시 예외가 발생합니다. 하드 제한을 해제하려면 0으로 설정하십시오. 이 제한은 Amber 연결에 적용됩니다.

## amber_connections_rcvbuf {#amber_connections_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="204800" changeable_without_restart="Yes" />Amber 연결에 사용되는 SO&#95;RCVBUF 옵션의 크기입니다. 기본값은 204800(200 KB)입니다. 객체 스토리지는 동일 리전 내에서 접근하며, 이때 대역폭-지연 곱(bandwidth-delay product)은 100 KB보다 훨씬 작습니다. 따라서 작은 상한값으로도 최대 처리량을 낼 수 있으며, 커널 자동 튜닝을 사용할 때 할당되는 소켓당 수 MiB 크기의 버퍼를 피할 수 있습니다. 수신 버퍼에 고정 크기 대신 커널 TCP 자동 조정을 사용하려면 0으로 설정하십시오. 참고: 이 설정을 다시 0으로 변경해도 자동 튜닝은 새로 생성되는 연결에만 다시 적용됩니다. 기존의 풀링된 연결(pooled connections)은 재생성될 때까지 고정된 버퍼 크기를 유지합니다.

## amber_connections_sndbuf {#amber_connections_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Amber 연결에 사용되는 SO&#95;SNDBUF 옵션의 크기입니다. 0보다 큰 값으로 설정하면 송신 버퍼에 대한 커널 TCP 자동 조정을 재정의합니다. 0 = 커널 기본값(자동 튜닝). 참고: 이 설정을 다시 0으로 변경해도 자동 튜닝은 새로 생성되는 연결에만 복원됩니다. 기존 풀링된 연결(pooled connections)은 재생성될 때까지 고정된 버퍼 크기를 그대로 유지합니다.

## amber_connections_soft_limit {#amber_connections_soft_limit}

<SettingsInfoBlock type="UInt64" default_value="5000" changeable_without_restart="No" />이 제한을 초과하는 연결은 TTL(time to live)이 훨씬 짧아집니다. 이 제한은 Amber 연결에 적용됩니다.

## amber_connections_store_limit {#amber_connections_store_limit}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="No" />재사용을 위해 풀에 보관되는 유휴 상태 연결의 최대 개수입니다. 저장된 연결 수가 이 값에 도달하면 이후의 연결은 보관되지 않고 사용 후 초기화됩니다. 이 제한은 사용 중인 연결에는 적용되지 않습니다. 연결 캐시를 비활성화하려면 0으로 설정하십시오. 이 제한은 Amber 연결에 적용됩니다.

## amber_connections_warn_limit {#amber_connections_warn_limit}

<SettingsInfoBlock type="UInt64" default_value="8000" changeable_without_restart="No" />사용 중인 연결 수가 이 제한값을 초과하면 경고 메시지가 로그에 기록됩니다. 이 제한은 Amber 연결에 적용됩니다.
