이 설정은 ClickHouse 서버를 구성하며, ClickHouse 소스 코드에서 자동으로 생성됩니다.

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />멀티 스테이지 분산 쿼리에서 사용하는 스트리밍 exchange 소켓의 SO&#95;RCVBUF 옵션 크기입니다. 0이면 커널 기본값(TCP 자동 튜닝)을 사용합니다. 0보다 큰 값을 지정하면 소켓별 수신 버퍼의 상한이 설정되며, 이 값은 net.core.rmem&#95;max로 상한값이 제한됩니다. 이 설정은 연결마다 읽히므로 구성을 다시 로드하면 새 연결에만 적용됩니다.

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />멀티 스테이지 분산 쿼리에서 사용하는 스트리밍 exchange 소켓의 SO&#95;SNDBUF 옵션 크기입니다. 0은 커널 기본값(TCP 자동 튜닝)을 의미합니다. 0보다 큰 값을 지정하면 소켓별 송신 버퍼의 상한이 설정되지만(net.core.wmem&#95;max로 상한값이 제한됨), RTT가 높은 링크에서는 스트림 처리량이 sndbuf/RTT로 제한됩니다. 이 설정은 연결마다 읽히므로 구성을 다시 로드해도 새 연결에만 적용됩니다.
