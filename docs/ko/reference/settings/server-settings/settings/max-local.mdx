이 설정은 ClickHouse 서버를 구성하기 위한 것이며 ClickHouse 소스에서 자동 생성됩니다.

## max_local_read_bandwidth_for_server {#max_local_read_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

로컬 읽기의 초당 최대 속도(바이트)입니다.

이 제한은 블록 장치에서 읽은 데이터에 적용됩니다. OS 페이지 캐시에서 처리되는 읽기는 읽기 방식이 이를 감지할 수 있다면 집계에서 제외됩니다(기본값인 `local_filesystem_read_method = 'pread_threadpool'`와 `pread`, 그리고 파일 시스템 캐시 파일 읽기가 이에 해당합니다).

<Note>
  값이 `0`이면 무제한을 의미합니다.
</Note>

## max_local_write_bandwidth_for_server {#max_local_write_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

로컬 쓰기의 최대 속도입니다. 단위는 초당 바이트입니다.

<Note>
  값이 `0`이면 무제한입니다.
</Note>
