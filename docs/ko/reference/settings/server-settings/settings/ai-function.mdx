이 설정은 ClickHouse 서버를 구성하며, ClickHouse 소스 코드에서 자동 생성됩니다.

## ai_function_max_thread_pool_free_size {#ai_function_max_thread_pool_free_size}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

AI 프로바이더 요청용 스레드 풀에 유지할 유휴 상태 대기 스레드의 최대 개수입니다.

## ai_function_max_thread_pool_size {#ai_function_max_thread_pool_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1000" changeable_without_restart="Yes" />

AI 프로바이더에 요청을 보내는 데 사용할 수 있는 스레드의 최대 총개수입니다. 스레드 하나가 요청 하나를 담당하므로, 이 설정은 모든 쿼리를 합쳐 서버 전체에서 동시에 처리 중일 수 있는 AI 프로바이더 요청 수의 상한이 됩니다. 각 쿼리 스레드가 이 중 사용할 수 있는 몫은 [`ai_function_max_concurrent_requests_per_thread`](/ko/reference/settings/session-settings/ai-function#ai_function_max_concurrent_requests_per_thread)로 제한됩니다.

## ai_function_thread_pool_queue_size {#ai_function_thread_pool_queue_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />

AI 프로바이더로 보내는 요청을 처리하는 스레드 풀에 예약할 수 있는 최대 작업 수입니다.
