이 설정은 ClickHouse 서버를 구성하며, ClickHouse 소스 코드에서 자동 생성됩니다.

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />GPU의 기본 메모리 풀이 해제된 디바이스 메모리를 드라이버에 반환하지 않고 보유하는 양입니다. 기본값을 사용하면 풀은 쿼리의 최대 사용량까지 커진 뒤 서버가 종료될 때까지 그 크기를 유지합니다.

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />GPU의 고정 호스트 메모리(pinned host memory) 풀이 해제된 고정 호스트 메모리를 시스템에 반환하지 않고 재사용을 위해 보관할 수 있는 최대 크기입니다.
