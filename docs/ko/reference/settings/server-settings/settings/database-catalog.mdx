이 설정들은 ClickHouse 서버를 구성하며 ClickHouse 소스에서 자동 생성됩니다.

## database_catalog_drop_error_cooldown_sec {#database_catalog_drop_error_cooldown_sec}

<SettingsInfoBlock type="UInt64" default_value="5" changeable_without_restart="No" />테이블 삭제에 실패한 경우, ClickHouse는 이 시간 동안 대기한 후 작업을 다시 시도합니다.

## database_catalog_drop_table_concurrency {#database_catalog_drop_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="16" changeable_without_restart="No" />테이블 삭제에 사용되는 스레드 풀의 크기입니다.

## database_catalog_shutdown_table_concurrency {#database_catalog_shutdown_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="No" />서버가 중지될 때 테이블 종료에 사용되는 스레드 풀의 크기입니다. 0이면 스레드 수가 코어 수와 같음을 의미합니다.

## database_catalog_unused_dir_cleanup_period_sec {#database_catalog_unused_dir_cleanup_period_sec}

<SettingsInfoBlock type="UInt64" default_value="86400" changeable_without_restart="No" />`store/` 디렉터리의 불필요한 잔여 파일을 정리하던 백그라운드 작업의 매개변수로, 해당 작업의 스케줄링 주기를 지정합니다. 이 설정은 사용 중단 권고 상태이며 아무런 효과가 없습니다. 해당 작업은 제거되었으며, ClickHouse는 `store/`에 있는 사용되지 않는 디렉터리를 자동으로 숨기거나 제거하지 않습니다.

## database_catalog_unused_dir_hide_timeout_sec {#database_catalog_unused_dir_hide_timeout_sec}

<SettingsInfoBlock type="UInt64" default_value="3600" changeable_without_restart="No" />`store/` 디렉터리의 불필요한 잔여 파일을 정리하던 백그라운드 작업의 매개변수로, 해당 작업이 사용되지 않는 디렉터리의 모든 접근 권한을 철회하기까지의 시간을 지정했습니다. 이 설정은 사용 중단 권고 상태이며 아무런 효과가 없습니다. 해당 작업은 제거되었으며, ClickHouse는 `store/` 내의 사용되지 않는 디렉터리를 자동으로 숨기거나 제거하지 않습니다.

## database_catalog_unused_dir_rm_timeout_sec {#database_catalog_unused_dir_rm_timeout_sec}

<SettingsInfoBlock type="UInt64" default_value="2592000" changeable_without_restart="No" />`store/` 디렉터리에서 불필요한 잔여 파일을 정리하던 백그라운드 작업의 매개변수로, 이 작업이 사용되지 않는 디렉터리를 제거하기까지 기다리는 시간입니다. 이 설정은 사용 중단 권고 상태이며 아무런 효과가 없습니다. 해당 작업은 제거되었으며, ClickHouse는 `store/`에 있는 사용되지 않는 디렉터리를 자동으로 숨기거나 제거하지 않습니다.
