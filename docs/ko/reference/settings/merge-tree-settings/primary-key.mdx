이러한 설정은 [system.merge&#95;tree&#95;settings](/ko/reference/system-tables/merge_tree_settings)에서 확인할 수 있으며, ClickHouse 소스 코드에서 자동으로 생성됩니다.

## primary_key_compress_block_size {#primary_key_compress_block_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="65536" />

새로 생성되거나 재작성된 데이터 파트에 압축된 프라이머리 키(primary key) 인덱스를 기록할 때 사용하는 블록의 크기(비압축 바이트 기준)입니다. `compress_primary_key`가 활성화된 경우에만 적용됩니다. 이 설정은 압축 프레이밍과 버퍼링만 제어하며, 프라이머리 키나 인덱스 세분화 수준(index granularity)은 변경하지 않습니다.

## primary_key_compression_codec {#primary_key_compression_codec}

<SettingsInfoBlock type="String" default_value="ZSTD(3)" />

프라이머리 키에 사용되는 압축 인코딩입니다. 프라이머리 키는 충분히 작고 캐시되므로
기본 압축은 ZSTD(3)입니다.

## primary_key_lazy_load {#primary_key_lazy_load}

<SettingsInfoBlock type="Bool" default_value="1" />

테이블 초기화 시가 아니라
처음 사용할 때 프라이머리 키를 메모리에 로드합니다. 이렇게 하면
테이블 수가 많은 경우 메모리를 절약할 수 있습니다.

## primary_key_ratio_of_unique_prefix_values_to_skip_suffix_columns {#primary_key_ratio_of_unique_prefix_values_to_skip_suffix_columns}

<SettingsInfoBlock type="Float" default_value="0.9" />

데이터 파트에서 프라이머리 키 컬럼의 값이 최소
이 비율만큼 변경되면, 다음 컬럼은 메모리에 로드하지 않고 건너뜁니다. 이렇게 하면
프라이머리 키의 불필요한 컬럼을 로드하지 않아 메모리 사용량을 절약할 수
있습니다.
