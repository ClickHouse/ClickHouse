## prewarm_statistics_cache {#prewarm_statistics_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "새 데이터 파트의 컬럼 통계(Column Statistics)를 사용해 통계 캐시를 예열하며, 서버 시작 시에도 예열하는 새로운 설정입니다. 이제 통계 캐시는 전체 테이블의 스냅샷이 아닌 데이터 파트 및 컬럼 단위로 관리되며, `refresh_statistics_interval` 및 `use_statistics_cache` 설정은 더 이상 사용되지 않습니다."}]}]} />

true로 설정하면 삽입, 머지, 페치 시점과 서버 시작 시
데이터 파트의 컬럼 통계를 로딩하여 통계 캐시를
예열합니다. 이 설정을 사용하지 않으면 파트의 통계는
해당 통계가 필요한 첫 번째 쿼리가 실행될 때 캐시에 로드됩니다.
