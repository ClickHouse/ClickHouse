## materialize_skip_indexes_on_merge {#materialize_skip_indexes_on_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.1"},{"label": "1"},{"label": "새로운 설정"}]}]} />

활성화하면 머지 시 새 파트에 대한 스키핑 인덱스를 생성하여 저장합니다.
그렇지 않으면 명시적인 [MATERIALIZE INDEX](/ko/reference/statements/alter/skipping-index#materialize-index)
또는 [INSERT 시](/ko/reference/settings/session-settings/materialize#materialize_skip_indexes_on_insert) 생성하여 저장할 수 있습니다.

더 세밀하게 제어하려면 [exclude&#95;materialize&#95;skip&#95;indexes&#95;on&#95;merge](/ko/reference/settings/merge-tree-settings/exclude#exclude_materialize_skip_indexes_on_merge)도 참고하십시오.

## materialize_statistics_on_merge {#materialize_statistics_on_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.1"},{"label": "1"},{"label": "새로운 설정"}]}]} />

활성화하면 머지 시 새 파트에 대한 통계를 생성하여 저장합니다.
그렇지 않으면 명시적으로 [MATERIALIZE STATISTICS](/ko/reference/statements/alter/statistics)를 실행하거나
[INSERT 시](/ko/reference/settings/session-settings/materialize-statistics-on-insert#materialize_statistics_on_insert)에 생성하여 저장할 수 있습니다.

## materialize_ttl_recalculate_only {#materialize_ttl_recalculate_only}

<SettingsInfoBlock type="Bool" default_value="0" />

활성화하면 `MATERIALIZE TTL`은 작업 중에 만료된 데이터를 제거하지 않고, 각 데이터 파트(data part)에 저장된 `TTL` 메타데이터만 다시 계산합니다. 비활성화하면 일반적인 TTL 머티리얼라이즈 과정에서 구성된 행, 컬럼 또는 `GROUP BY` TTL 동작이 일반적으로 적용됩니다. 단, 행 TTL만 있고 `ttl_only_drop_parts`가 활성화된 테이블에서는 `TTL` 메타데이터를 다시 계산한 뒤 완전히 만료된 파트만 삭제합니다.
