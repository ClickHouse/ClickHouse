이 설정은 [system.merge&#95;tree&#95;settings](/ko/reference/system-tables/merge_tree_settings)에서 확인할 수 있으며 ClickHouse 소스에서 자동 생성됩니다.

## fsync_after_insert {#fsync_after_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

삽입된 각 파트마다 fsync를 수행하여 `INSERT` 쿼리에 대한 확인 응답이 반환될 때 데이터가 영구적으로 저장되도록 합니다. 삽입 성능이 저하되며, 특히 wide 파트에서 두드러집니다.
`group_fsync_before_insert_finish`도 참고하십시오.

## fsync_part_directory {#fsync_part_directory}

<SettingsInfoBlock type="Bool" default_value="0" />

모든 파트 작업(쓰기, 이름 변경 등)이 완료된 후 파트 디렉터리에 fsync를 수행합니다.
