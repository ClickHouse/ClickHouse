이 설정은 [system.merge&#95;tree&#95;settings](/ko/reference/system-tables/merge_tree_settings)에서 확인할 수 있으며, ClickHouse 소스에서 자동으로 생성됩니다.

## marks_compress_block_size {#marks_compress_block_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="65536" />

새로 생성되거나 재작성된 데이터 파트의 압축 마크 파일을 기록할 때 사용하는 블록 크기(비압축 바이트 기준)입니다. `compress_marks`가 활성화된 경우에만 적용됩니다. 이 설정은 압축 프레이밍과 버퍼링을 제어할 뿐, 인덱스 세분화 수준(index granularity)은 변경하지 않습니다.

## marks_compression_codec {#marks_compression_codec}

<SettingsInfoBlock type="String" default_value="ZSTD(3)" />

마크에 사용되는 압축 인코딩입니다. 마크는 충분히 작고 캐시되므로
기본 압축은 ZSTD(3)입니다.
