## format_regexp_escaping_rule {#format_regexp_escaping_rule}

<SettingsInfoBlock type="EscapingRule" default_value="Raw" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "20.10"},{"label": "Raw"},{"label": "사용자가 기대하는 동작에 더 가깝게 하기 위해 Regexp 포맷의 기본 이스케이프 규칙으로 Raw를 사용합니다"}]}]} />

`format_regexp`가 생성하는 각 캡처 그룹을 대상 컬럼 타입으로 파싱하는 방식을 지정합니다. 이스케이프 처리되지 않은 텍스트에는 `Raw`(기본값), TSV 스타일 이스케이프 처리에는 `Escaped`, Values 스타일의 따옴표로 묶인 필드에는 `Quoted`, CSV 필드에는 `CSV`, JSON 값에는 `JSON`을 사용하십시오. 이 설정은 정규식이 행과 일치한 후에 적용되며, 정규식 자체는 변경하지 않습니다.

## format_regexp_skip_unmatched {#format_regexp_skip_unmatched}

<SettingsInfoBlock type="Bool" default_value="0" />
