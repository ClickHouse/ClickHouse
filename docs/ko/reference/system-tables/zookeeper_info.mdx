## 설명 {#description}

이 테이블은 ZooKeeper에 대한 종합적인 내부 검사 정보를 출력하며, 노드 정보는 구성에서 가져옵니다.

**가용성**

`system.zookeeper_info`는 ClickHouse Keeper 또는 ZooKeeper가 구성된 경우에만 존재합니다. 둘 중 어느 것도 구성되지 않은 서버에서는 이 테이블이 존재하지 않으며, 해당 테이블에 대한 쿼리는 `UNKNOWN_TABLE` 오류로 실패합니다.

## 컬럼 {#columns}

* `zookeeper_cluster_name` ([String](/ko/reference/data-types/string)) — ZooKeeper 클러스터의 이름입니다.
* `host` ([String](/ko/reference/data-types/string)) — ClickHouse가 연결된 ZooKeeper 노드의 호스트명/IP입니다.
* `port` ([UInt16](/ko/reference/data-types/int-uint)) — ClickHouse가 연결된 ZooKeeper 노드의 포트입니다.
* `index` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — ClickHouse가 연결된 ZooKeeper 노드의 인덱스입니다. 이 인덱스는 ZooKeeper 구성에서 가져옵니다. 연결되어 있지 않으면 이 컬럼은 NULL입니다.
* `is_connected` ([UInt8](/ko/reference/data-types/int-uint)) — ZooKeeper 연결 여부입니다.
* `is_readonly` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — readonly 여부입니다.
* `version` ([Nullable(String)](/ko/reference/data-types/nullable)) — ZooKeeper 버전입니다.
* `avg_latency` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 평균 지연 시간입니다.
* `max_latency` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 최대 지연 시간입니다.
* `min_latency` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 최소 지연 시간입니다.
* `packets_received` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 수신한 패킷 수입니다.
* `packets_sent` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 전송한 패킷 수입니다.
* `outstanding_requests` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 처리 대기 중인 요청 수입니다.
* `server_state` ([Nullable(String)](/ko/reference/data-types/nullable)) — 서버 상태입니다.
* `is_leader` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — 해당 ZooKeeper가 리더인지 여부입니다.
* `znode_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — znode 수입니다.
* `watch_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — watch 수입니다.
* `ephemerals_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ephemeral 노드 수입니다.
* `approximate_data_size` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 대략적인 데이터 크기입니다.
* `followers` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 리더의 팔로워 수입니다. 이 필드는 리더에서만 노출됩니다.
* `synced_followers` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 리더와 동기화된 팔로워 수입니다. 이 필드는 리더에서만 노출됩니다.
* `pending_syncs` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 리더의 대기 중인 동기화 수입니다. 이 필드는 리더에서만 노출됩니다.
* `open_file_descriptor_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 열린 file descriptor 수입니다. Unix 플랫폼에서만 사용할 수 있습니다.
* `max_file_descriptor_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 최대 file descriptor 수입니다. Unix 플랫폼에서만 사용할 수 있습니다.
* `connections` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper 연결 수입니다.
* `outstanding` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 처리 대기 항목 수입니다.
* `zxid` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — ZooKeeper zxid입니다.
* `node_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper 노드 수입니다.
* `snapshot_dir_size` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper snapshot 디렉터리 크기입니다.
* `log_dir_size` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper log 디렉터리 크기입니다.
* `first_log_idx` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 첫 번째 log 인덱스입니다.
* `first_log_term` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 첫 번째 log term입니다.
* `last_log_idx` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 마지막 log 인덱스입니다.
* `last_log_term` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 마지막 log term입니다.
* `last_committed_idx` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper에서 마지막으로 커밋된 인덱스입니다.
* `leader_committed_log_idx` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper 리더가 커밋한 log 인덱스입니다.
* `target_committed_log_idx` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 목표 커밋 log 인덱스입니다.
* `last_snapshot_idx` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — ZooKeeper의 마지막 snapshot 인덱스입니다.
