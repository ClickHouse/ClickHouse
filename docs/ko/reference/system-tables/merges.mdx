<div id="description">
  ## 설명
</div>

현재 진행 중인 MergeTree 엔진 계열 테이블의 머지 및 파트 뮤테이션 정보를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ko/reference/data-types/string)) — 테이블이 있는 데이터베이스의 이름입니다.
* `table` ([String](/ko/reference/data-types/string)) — 테이블 이름입니다.
* `elapsed` ([Float64](/ko/reference/data-types/float)) — 머지가 시작된 후 경과한 시간(초)입니다.
* `progress` ([Float64](/ko/reference/data-types/float)) — 완료된 작업의 비율이며, 0에서 1 사이의 값입니다.
* `num_parts` ([UInt64](/ko/reference/data-types/int-uint)) — 머지할 파트 수입니다.
* `source_part_names` ([Array(String)](/ko/reference/data-types/array)) — 소스 파트 이름 목록입니다.
* `result_part_name` ([String](/ko/reference/data-types/string)) — 머지 결과로 생성될 파트의 이름입니다.
* `source_part_paths` ([Array(String)](/ko/reference/data-types/array)) — 각 소스 파트의 경로 목록입니다.
* `result_part_path` ([String](/ko/reference/data-types/string)) — 머지 결과로 생성될 파트의 경로입니다.
* `partition_id` ([String](/ko/reference/data-types/string)) — 머지가 진행 중인 파티션의 식별자입니다.
* `partition` ([String](/ko/reference/data-types/string)) — 파티션 이름입니다.
* `is_mutation` ([UInt8](/ko/reference/data-types/int-uint)) — 이 프로세스가 파트 뮤테이션이면 1입니다.
* `total_size_bytes_compressed` ([UInt64](/ko/reference/data-types/int-uint)) — 병합된 청크의 압축된 데이터 총 크기입니다.
* `total_size_bytes_uncompressed` ([UInt64](/ko/reference/data-types/int-uint)) — 병합된 청크의 압축된 데이터 총 크기입니다.
* `total_size_marks` ([UInt64](/ko/reference/data-types/int-uint)) — 병합된 파트의 마크 총수입니다.
* `bytes_read_uncompressed` ([UInt64](/ko/reference/data-types/int-uint)) — 압축 해제된 상태로 읽은 바이트 수입니다.
* `rows_read` ([UInt64](/ko/reference/data-types/int-uint)) — 읽은 행 수입니다.
* `bytes_written_uncompressed` ([UInt64](/ko/reference/data-types/int-uint)) — 압축 해제된 상태로 쓴 바이트 수입니다.
* `rows_written` ([UInt64](/ko/reference/data-types/int-uint)) — 쓴 행 수입니다.
* `columns_written` ([UInt64](/ko/reference/data-types/int-uint)) — 쓴 컬럼 수입니다(수직 병합 알고리즘용).
* `memory_usage` ([UInt64](/ko/reference/data-types/int-uint)) — 머지 프로세스의 메모리 사용량입니다.
* `thread_id` ([UInt64](/ko/reference/data-types/int-uint)) — 머지 프로세스의 스레드 ID입니다.
* `merge_type` ([String](/ko/reference/data-types/string)) — 현재 머지의 유형입니다. 뮤테이션이면 비어 있습니다.
* `merge_algorithm` ([String](/ko/reference/data-types/string)) — 현재 머지에 사용되는 알고리즘입니다. 뮤테이션이면 비어 있습니다.
* `current_projection` ([String](/ko/reference/data-types/string)) — 현재 머지되거나 재구축 중인 프로젝션의 이름입니다. 프로젝션 머지 단계가 아니면 비어 있습니다.
* `current_projection_progress` ([Float64](/ko/reference/data-types/float)) — 현재 프로젝션 머지의 진행률이며, 0에서 1 사이의 값입니다.
* `current_projection_parts_merging` ([UInt64](/ko/reference/data-types/int-uint)) — 현재 머지 중인 프로젝션 파트 수입니다.
* `current_projection_parts_remaining` ([UInt64](/ko/reference/data-types/int-uint)) — 현재 프로젝션에서 머지해야 할 남은 프로젝션 파트 수입니다.
* `projections_completed` ([Array(String)](/ko/reference/data-types/array)) — 현재까지 머지되거나 재구축된 프로젝션 목록입니다.
* `projections_remaining` ([Array(String)](/ko/reference/data-types/array)) — 아직 머지하거나 재구축해야 하는 프로젝션 목록입니다.

{/*AUTOGENERATED_END*/}
