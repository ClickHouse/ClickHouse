<div id="description">
  ## 설명
</div>

사용 가능한 모든 집계 함수 조합자의 목록을 포함하며, 이러한 조합자는 집계 함수에 적용되어 동작 방식을 변경할 수 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ko/reference/data-types/string)) — 조합자의 이름입니다.
* `is_internal` ([UInt8](/ko/reference/data-types/int-uint)) — 이 조합자가 내부 용도로만 사용되는지 여부입니다.
* `description` ([String](/ko/reference/data-types/string)) — 조합자가 수행하는 작업에 대한 개략적인 설명입니다.
* `syntax` ([String](/ko/reference/data-types/string)) — 조합자를 집계 함수 이름에 적용하는 방법입니다.
* `examples` ([String](/ko/reference/data-types/string)) — 사용 예시입니다.
* `introduced_in` ([String](/ko/reference/data-types/string)) — 조합자가 처음 도입된 ClickHouse 버전으로, major.minor 형식입니다.
* `related` ([Array(String)](/ko/reference/data-types/array)) — 관련 조합자의 이름입니다.

{/*AUTOGENERATED_END*/}
