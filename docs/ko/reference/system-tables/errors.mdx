## 설명 {#description}

각 오류 코드가 발생한 횟수를 포함합니다.

발생하지 않은 오류 코드까지 포함해 가능한 모든 오류 코드를 표시하려면 설정 [system&#95;events&#95;show&#95;zero&#95;values](/ko/reference/settings/session-settings/system#system_events_show_zero_values)를 1로 설정하십시오.

## 컬럼 {#columns}

* `name` ([String](/ko/reference/data-types/string)) — 오류 이름(errorCodeToName)입니다.
* `code` ([Int32](/ko/reference/data-types/int-uint)) — 오류 코드 번호입니다.
* `value` ([UInt64](/ko/reference/data-types/int-uint)) — 이 오류가 발생한 횟수입니다.
* `last_error_time` ([DateTime](/ko/reference/data-types/datetime)) — 마지막 오류가 발생한 시간입니다.
* `last_error_message` ([String](/ko/reference/data-types/string)) — 마지막 오류 메시지입니다.
* `last_error_format_string` ([String](/ko/reference/data-types/string)) — 마지막 오류의 포맷 문자열입니다.
* `last_error_trace` ([Array(UInt64)](/ko/reference/data-types/array)) — 마지막 오류의 스택 트레이스입니다. FreeBSD를 제외한 ELF 플랫폼에서는 메인 ClickHouse 바이너리 내부의 주소가 물리적 파일 오프셋으로 저장되며, 바이너리 외부의 프레임(공유 라이브러리, JIT 코드)은 0으로 저장됩니다.
* `remote` ([UInt8](/ko/reference/data-types/int-uint)) — 원격 예외입니다(즉, 분산 쿼리 중 하나에서 수신된 예외).
* `query_id` ([String](/ko/reference/data-types/string)) — 오류를 일으킨 쿼리의 ID입니다(있는 경우).
* `last_error_symbols` ([Array(LowCardinality(String))](/ko/reference/data-types/array)) — last&#95;error&#95;trace에 대응하는 디맹글링된 심볼 이름입니다.
* `last_error_lines` ([Array(LowCardinality(String))](/ko/reference/data-types/array)) — last&#95;error&#95;trace에 대응하는 파일 이름과 줄 번호입니다.

일부 오류의 카운터는 쿼리가 성공적으로 실행되는 중에도 증가할 수 있습니다. 해당 오류가 오탐(false positive)이 아님을 확신할 수 없는 경우에는 서버 모니터링 용도로 이 테이블을 사용하지 않는 것이 좋습니다.

`last_error_symbols`와 `last_error_lines`는 바이너리의 심볼 테이블과 디버그 정보를 기반으로 해석됩니다.
`last_error_symbols`는 심볼 테이블을 사용할 수 있는 환경(Linux 및 macOS 빌드)이라면 어디서나 채워집니다.
`last_error_lines`에는 DWARF 디버그 정보가 추가로 필요합니다. 이 정보는 Linux에서는 바이너리에서 직접 읽고, macOS에서는 같은 위치에 있는 `.dSYM` bundle에서 읽습니다. 따라서 디버그 정보를 사용할 수 없으면 이 컬럼은 비어 있습니다. 내부 검사를 지원하지 않는 플랫폼(예: FreeBSD)에서는 두 배열 모두 비어 있습니다.

## 예시 {#example}

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
