## 설명 {#description}

ClickHouse 서버의 빌드 옵션 정보를 포함합니다.

## 컬럼 {#columns}

* `name` ([String](/ko/reference/data-types/string)) — 빌드 옵션의 이름입니다.
* `value` ([String](/ko/reference/data-types/string)) — 빌드 옵션의 값입니다.

## 예시 {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
