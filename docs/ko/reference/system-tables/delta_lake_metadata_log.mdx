## 설명 {#description}

Delta 메타데이터 파일의 내용을 포함합니다.

이 테이블은 언제든지 안전하게 TRUNCATE하거나 삭제할 수 있습니다.

## 컬럼 {#columns}

{/*AUTOGENERATED_START*/}

* `hostname` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 쿼리를 실행하는 서버의 호스트명입니다.
* `clickhouse_version` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 해당 행을 생성한 ClickHouse 서버의 버전입니다.
* `system_processor` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 해당 행을 생성한 ClickHouse 서버의 CPU 아키텍처입니다.
* `event_date` ([Date](/ko/reference/data-types/date)) — 항목의 날짜입니다.
* `event_time` ([DateTime](/ko/reference/data-types/datetime)) — 이벤트 발생 시간입니다.
* `query_id` ([String](/ko/reference/data-types/string)) — 쿼리 ID입니다.
* `table_path` ([String](/ko/reference/data-types/string)) — 테이블 경로입니다.
* `file_path` ([String](/ko/reference/data-types/string)) — 파일 경로입니다.
* `content` ([String](/ko/reference/data-types/string)) — JSON 포맷의 콘텐츠입니다.
