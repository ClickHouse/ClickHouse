## 설명 {#description}

`system.delta_lake_metadata_log` 테이블은 ClickHouse가 읽는 Delta Lake 테이블의 메타데이터 액세스 및 파싱 이벤트를 기록합니다. 각 메타데이터 파일에 대한 상세 정보를 제공하므로 디버깅, 감사, Delta 테이블 구조의 변화 파악에 유용합니다.

이 테이블은 Delta Lake 테이블에서 읽은 모든 메타데이터 파일을 기록합니다. 이를 통해 ClickHouse가 Delta 테이블 메타데이터를 어떻게 해석하는지 추적하고, 스키마 진화, 스냅샷 결정, 쿼리 계획 수립과 관련된 문제를 진단할 수 있습니다.

이 테이블은 주로 디버깅 목적으로 사용됩니다.

### 로그 상세 수준 제어 {#controlling-log-verbosity}

[`delta_lake_log_metadata`](/ko/reference/settings/session-settings/delta-lake#delta_lake_log_metadata) 설정을 사용하여 어떤 메타데이터 이벤트를 기록할지 제어할 수 있습니다.

현재 쿼리에서 사용된 모든 메타데이터를 기록하려면 다음과 같이 실행하십시오:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

이 테이블은 언제든지 TRUNCATE하거나 삭제해도 안전합니다.

## 컬럼 {#columns}

* `hostname` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 쿼리를 실행하는 서버의 호스트명입니다.
* `clickhouse_version` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 해당 행을 생성한 ClickHouse 서버의 버전입니다.
* `system_processor` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 해당 행을 생성한 ClickHouse 서버의 CPU 아키텍처입니다.
* `event_date` ([Date](/ko/reference/data-types/date)) — 항목의 날짜입니다.
* `event_time` ([DateTime](/ko/reference/data-types/datetime)) — 이벤트 발생 시간입니다.
* `query_id` ([String](/ko/reference/data-types/string)) — 쿼리 ID입니다.
* `table_path` ([String](/ko/reference/data-types/string)) — 테이블 경로입니다.
* `file_path` ([String](/ko/reference/data-types/string)) — 파일 경로입니다.
* `content` ([String](/ko/reference/data-types/string)) — JSON 포맷의 콘텐츠입니다.
