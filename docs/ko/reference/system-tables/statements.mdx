<div id="description">
  ## 설명
</div>

ClickHouse에서 사용하는 모든 SQL 문 목록입니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ko/reference/data-types/string)) — SQL 문의 이름입니다.
* `syntax` ([String](/ko/reference/data-types/string)) — SQL 문의 구문입니다.
* `description` ([String](/ko/reference/data-types/string)) — 사용 예시를 포함한 SQL 문의 기능 설명입니다.
* `parent_name` ([String](/ko/reference/data-types/string)) — 상위 SQL 문의 이름입니다. 예를 들어 WHERE 절의 상위 문은 SELECT입니다. 최상위 SQL 문의 경우 비어 있습니다.
* `related` ([Array(String)](/ko/reference/data-types/array)) — 관련 SQL 문의 이름입니다.

{/*AUTOGENERATED_END*/}
