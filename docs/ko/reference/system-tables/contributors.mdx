## 설명 {#description}

기여자에 대한 정보를 포함합니다. 순서는 쿼리 실행 시점마다 무작위로 결정됩니다.

## 컬럼 {#columns}

* `name` ([String](/ko/reference/data-types/string)) — git log에 기록된 기여자(author) 이름입니다.

## 예시 {#example}

```sql
SELECT * FROM system.contributors LIMIT 10
```

```text
┌─name─────────────┐
│ Olga Khvostikova │
│ Max Vetrov       │
│ LiuYangkuan      │
│ svladykin        │
│ zamulla          │
│ Šimon Podlipský  │
│ BayoNet          │
│ Ilya Khomutov    │
│ Amy Krishnevsky  │
│ Loud_Scream      │
└──────────────────┘
```

테이블에서 직접 확인하려면 다음 쿼리를 사용합니다:

```sql
SELECT * FROM system.contributors WHERE name = 'Olga Khvostikova'
```

```text
┌─name─────────────┐
│ Olga Khvostikova │
└──────────────────┘
```
