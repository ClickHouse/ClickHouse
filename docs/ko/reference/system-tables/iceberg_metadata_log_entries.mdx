## 설명 {#description}

이 시스템 테이블에는 ClickHouse에 있는 Iceberg 테이블(Iceberg tables)의 메타데이터 파일 정보가 저장되며, 메타데이터 파일 하나당 하나의 행이 생성됩니다. ClickHouse에 Iceberg 테이블이 없으면 이 테이블은 비어 있습니다.

## 컬럼 {#columns}

* `database` ([String](/ko/reference/data-types/string)) — 데이터베이스 이름입니다.
* `table` ([String](/ko/reference/data-types/string)) — 테이블 이름입니다.
* `timestamp` ([DateTime64(3)](/ko/reference/data-types/datetime64)) — 이 메타데이터 파일이 현재 메타데이터 파일로 지정된 날짜 및 시간입니다.
* `file` ([String](/ko/reference/data-types/string)) — 메타데이터 파일의 경로입니다.
* `latest_snapshot_id` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 이 메타데이터 파일 기준 최신 스냅샷의 ID입니다.
* `latest_schema_id` ([Nullable(Int32)](/ko/reference/data-types/nullable)) — 최신 스냅샷의 스키마 ID입니다.
* `latest_sequence_number` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — 최신 스냅샷의 시퀀스 번호입니다.
