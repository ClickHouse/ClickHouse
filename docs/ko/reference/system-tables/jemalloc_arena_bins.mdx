## 설명 {#description}

`system.jemalloc_bins`와 동일하지만, arena 단위로 집계하지 않고 (arena, 빈) 조합별로 한 행씩 제공합니다. 슬랩은 단일 arena에 속하므로, 이 테이블을 사용하면 특정 arena(MergeTree 메타데이터, JIT, cache 전용 arena 포함)에서 발생한 단편화를 찾아낼 수 있으며, `arena`와 크기 클래스를 함께 기준으로 `system.jemalloc_sampled_allocations`와 조인할 수 있습니다.

## 컬럼 {#columns}

{/*AUTOGENERATED_START*/}

* `arena` ([UInt32](/ko/reference/data-types/int-uint)) — arena의 인덱스입니다. `system.jemalloc_sampled_allocations.arena`와 조인됩니다.
* `purpose` ([String](/ko/reference/data-types/string)) — 전용 장기 유지 arena의 용도입니다. &#39;mergetree&#39;(파트 및 테이블 메타데이터), &#39;jit&#39;, &#39;cache&#39;가 해당합니다. 범용 arena에서는 비어 있습니다. 전용 arena는 설계상 장기 유지 할당을 보유하므로 단편화 보고서에서 일반적으로 제외됩니다.
* `index` ([UInt16](/ko/reference/data-types/int-uint)) — 크기순으로 정렬된 빈의 인덱스입니다.
* `large` ([UInt8](/ko/reference/data-types/int-uint)) — 대규모 할당이면 True, 소규모 할당이면 False입니다.
* `size` ([UInt64](/ko/reference/data-types/int-uint)) — 이 빈에 속한 할당의 크기입니다.
* `allocations` ([Int64](/ko/reference/data-types/int-uint)) — 할당 수입니다.
* `deallocations` ([Int64](/ko/reference/data-types/int-uint)) — 메모리 할당 해제 수입니다.
* `nregs` ([Int64](/ko/reference/data-types/int-uint)) — 슬랩당 영역 수입니다.
* `curslabs` ([Int64](/ko/reference/data-types/int-uint)) — 현재 슬랩 수입니다.
* `curregs` ([Int64](/ko/reference/data-types/int-uint)) — 이 크기 클래스의 현재 영역 수입니다.
* `slab_size` ([UInt64](/ko/reference/data-types/int-uint)) — 각 슬랩의 바이트 단위 크기입니다. 슬랩 기반이 아닌 대규모 크기 클래스에서는 0입니다.
* `nonfull_slabs` ([Int64](/ko/reference/data-types/int-uint)) — 하나 이상의 빈 영역을 포함하는 현재 슬랩 수입니다. 대규모 크기 클래스에서는 0입니다.

**별칭:**

* `availregs` — `nregs * curslabs`의 별칭입니다.
* `util` — `curregs / availregs`의 별칭입니다.
* `waste` — `greatest((curslabs * slab_size) - (curregs * size), 0)`의 별칭입니다.
