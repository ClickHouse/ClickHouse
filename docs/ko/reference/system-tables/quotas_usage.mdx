  ## 설명

모든 사용자의 QUOTA 사용량입니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ko/reference/data-types/string)) — QUOTA 이름입니다.
* `quota_key` ([String](/ko/reference/data-types/string)) — 키 값입니다.
* `is_current` ([UInt8](/ko/reference/data-types/int-uint)) — 현재 사용자의 QUOTA 사용량입니다.
* `start_time` ([Nullable(DateTime)](/ko/reference/data-types/nullable)) — 리소스 사용량 계산 시작 시간입니다.
* `end_time` ([Nullable(DateTime)](/ko/reference/data-types/nullable)) — 리소스 사용량 계산 종료 시간입니다.
* `duration` ([Nullable(UInt32)](/ko/reference/data-types/nullable)) — 리소스 사용량을 계산하는 시간 인터벌의 길이(초)입니다.
* `queries` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 실행된 쿼리 수입니다.
* `max_queries` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 실행이 허용된 모든 타입의 쿼리 최대 수입니다.
* `query_selects` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 실행된 SELECT 쿼리 수입니다.
* `max_query_selects` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 실행이 허용된 SELECT 쿼리의 최대 수입니다.
* `query_inserts` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 실행된 INSERT 쿼리 수입니다.
* `max_query_inserts` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 실행이 허용된 INSERT 쿼리의 최대 수입니다.
* `errors` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 오류가 발생한 쿼리 수입니다.
* `max_errors` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 허용되는 오류 발생 쿼리의 최대 수입니다.
* `result_rows` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 모든 쿼리 결과 집합의 총 행 수입니다.
* `max_result_rows` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 모든 쿼리 결과 집합에서 허용되는 총 행 수의 최대값입니다.
* `result_bytes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 모든 쿼리 결과 집합의 총 바이트 수입니다.
* `max_result_bytes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 모든 쿼리 결과 집합에서 허용되는 총 바이트 수의 최대값입니다.
* `read_rows` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 모든 쿼리 실행 중 읽은 총 행 수입니다.
* `max_read_rows` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 모든 쿼리 실행 중 읽을 수 있는 최대 행 수입니다.
* `read_bytes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 모든 쿼리 실행 중 읽은 총 바이트 수입니다.
* `max_read_bytes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 모든 쿼리 실행 중 읽을 수 있는 최대 바이트 수입니다.
* `execution_time` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — 현재 기간 내 쿼리 실행에 소요된 총 시간(나노초)입니다.
* `max_execution_time` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 모든 쿼리 실행에 허용되는 최대 시간(나노초)입니다.
* `written_bytes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 모든 쿼리 실행 중 기록된 총 바이트 수입니다.
* `max_written_bytes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 모든 쿼리 실행 중 기록할 수 있는 최대 바이트 수입니다.
* `failed_sequential_authentications` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 연속 인증 실패 횟수입니다.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 허용되는 연속 인증 실패의 최대 횟수입니다.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 현재 기간 내 단일 정규화된 쿼리의 최대 실행 횟수입니다.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 지정된 기간 내 단일 정규화된 쿼리에 허용되는 최대 실행 횟수입니다.
