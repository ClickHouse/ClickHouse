## 설명 {#description}

이 테이블은 ClickHouse 서버에 대한 경고를 보여줍니다.
동일한 유형의 경고는 하나의 경고로 합쳐집니다.
예를 들어 attached 상태인 데이터베이스 수 N이 구성 가능한 임계값 T를 초과하면, N개의 개별 항목 대신 현재 값 N을 담은 단일 항목이 표시됩니다.
현재 값이 임계값 아래로 내려가면 해당 항목은 테이블에서 제거됩니다.

이 테이블은 다음 설정으로 구성할 수 있습니다:

* [max&#95;table&#95;num&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/ko/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/ko/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## 컬럼 {#columns}

* `message` ([String](/ko/reference/data-types/string)) — ClickHouse 서버에서 생성한 경고 메시지입니다.
* `message_format_string` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 메시지 형식 지정에 사용된 포맷 문자열입니다.

## 예시 {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
