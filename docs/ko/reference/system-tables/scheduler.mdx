<div id="description">
  ## 설명
</div>

로컬 server에 있는 [스케줄링 노드](/ko/concepts/features/configuration/server-config/workload-scheduling#hierarchy)의 정보와 상태를 담고 있습니다.
이 table은 모니터링에 사용할 수 있습니다. 각 스케줄링 노드마다 하나의 행이 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `resource` ([String](/ko/reference/data-types/string)) — 리소스 이름
* `path` ([String](/ko/reference/data-types/string)) — 이 리소스 스케줄링 계층 내 스케줄링 노드의 경로
* `type` ([String](/ko/reference/data-types/string)) — 스케줄링 노드의 유형
* `weight` ([Float64](/ko/reference/data-types/float)) — `fair` 유형의 상위 노드에서 사용하는 노드 가중치
* `priority` ([Int64](/ko/reference/data-types/int-uint)) — &#39;priority&#39; 유형의 상위 노드에서 사용하는 노드 우선순위(값이 낮을수록 우선순위가 높음)
* `precedence` ([Int64](/ko/reference/data-types/int-uint)) — space-shared(메모리) 상위 노드에서 승인 및 축출 순서를 정하는 데 사용하는 노드 precedence(값이 낮을수록 precedence가 높음)
* `is_active` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — 이 노드가 현재 활성 상태인지 여부입니다. 활성 상태란 큐에서 꺼낼 리소스 요청이 있고 제약 조건이 충족되었음을 의미합니다.
* `active_children` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 활성 상태인 하위 노드 수
* `dequeued_requests` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 이 노드에서 큐에서 꺼낸 리소스 요청의 총수
* `canceled_requests` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 이 노드에서 취소된 리소스 요청의 총수
* `rejected_requests` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 이 노드에서 거부된 리소스 요청의 총수
* `dequeued_cost` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — 이 노드에서 큐에서 꺼낸 모든 요청의 비용(예: 바이트 단위 크기) 합계
* `canceled_cost` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — 이 노드에서 취소된 모든 요청의 비용(예: 바이트 단위 크기) 합계
* `rejected_cost` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — 이 노드에서 거부된 모든 요청의 비용(예: 바이트 단위 크기) 합계
* `busy_periods` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — 이 노드가 비활성화된 총횟수
* `throughput` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — 현재 평균 처리량(초당 큐에서 꺼낸 비용)
* `vruntime` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — `fair` 노드의 하위 노드에만 적용됩니다. SFQ 알고리즘이 최대-최소 공정 방식으로 다음에 처리할 하위 노드를 선택하는 데 사용하는 노드의 가상 런타임입니다.
* `system_vruntime` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — `fair` 노드에만 적용됩니다. 마지막으로 처리된 리소스 요청의 `vruntime`을 나타내는 가상 런타임입니다. 하위 노드 활성화 시 `vruntime`의 새 값으로 사용됩니다.
* `queue_length` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — `fifo` 노드에만 적용됩니다. 현재 큐에 있는 리소스 요청 수입니다.
* `queue_cost` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `fifo` 노드에만 적용됩니다. 큐에 있는 모든 요청의 비용(예: 바이트 단위 크기) 합계입니다.
* `budget` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `fifo` 노드에만 적용됩니다. 새 리소스 요청에 사용할 수 있는 &#39;비용 단위&#39; 수입니다. 리소스 요청의 예상 비용과 실제 비용이 불일치할 때(예: 읽기/쓰기 실패 후) 나타날 수 있습니다.
* `is_satisfied` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — 제약 조건 노드(예: `inflight_limit`)에만 적용됩니다. 이 노드의 모든 제약 조건이 충족되면 `1`입니다.
* `inflight_requests` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `inflight_limit` 노드에만 적용됩니다. 이 노드에서 큐에서 꺼냈으며 현재 활용 중인 리소스 요청 수입니다.
* `inflight_cost` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `inflight_limit` 노드에만 적용됩니다. 이 노드에서 큐에서 꺼냈으며 현재 활용 중인 모든 리소스 요청의 비용(예: 바이트) 합계입니다.
* `max_requests` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `inflight_limit` 노드에만 적용됩니다. 제약 조건 위반을 유발하는 `inflight_requests`의 상한입니다.
* `max_cost` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `inflight_limit` 노드에만 해당합니다. 제약 조건 위반을 유발하는 inflight&#95;cost의 상한입니다.
* `max_speed` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — `bandwidth_limit` 노드에만 해당합니다. 초당 토큰 수로 표현한 대역폭의 상한입니다.
* `max_burst` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — `bandwidth_limit` 노드에만 해당합니다. 토큰 버킷 스로틀러에서 사용할 수 있는 토큰 수의 상한입니다.
* `throttling_us` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — `bandwidth_limit` 노드에만 해당합니다. 이 노드가 스로틀링 상태였던 총 마이크로초 수입니다.
* `tokens` ([Nullable(Float64)](/ko/reference/data-types/nullable)) — `bandwidth_limit` 노드에만 해당합니다. 토큰 버킷 스로틀러에서 현재 사용할 수 있는 토큰 수입니다.
* `allocated` ([Nullable(Int64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드 아래에 현재 할당된 리소스 양입니다.
* `allocations` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드 아래에서 현재 실행 중인 리소스 할당 수입니다.
* `updates` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드를 통해 전파된 업데이트의 총횟수입니다.
* `increases` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드가 승인한 증가 요청의 총횟수입니다.
* `decreases` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드가 승인한 감소 요청의 총횟수입니다.
* `admits` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드가 승인한 할당의 총횟수입니다.
* `removes` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드에서 제거된 할당의 총횟수입니다.
* `killers` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드의 증가 요청으로 인해 시작된 축출 작업의 총횟수입니다.
* `victims` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — space-shared 노드에만 해당합니다. 이 노드에서 축출된 할당의 총횟수입니다.
* `rejects` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — `allocation_queue` 노드에만 해당합니다. 이 노드에서 거부된 리소스 할당의 총횟수입니다.
* `pending` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — `allocation_queue` 노드에만 해당합니다. 이 노드에서 대기 중인 리소스 할당의 현재 수입니다.
