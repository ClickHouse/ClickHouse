<div id="description">
  ## 설명
</div>

서버에서 지원하는 테이블 엔진과 각 엔진의 기능 지원 정보를 설명합니다.

이 표에는 다음 컬럼이 포함되어 있으며, 컬럼 타입은 대괄호 안에 표시됩니다.

{/*AUTOGENERATED_START*/}

* `name` ([String](/ko/reference/data-types/string)) — 테이블 엔진의 이름입니다.
* `supports_settings` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 SETTINGS 절을 지원하는지 나타내는 플래그입니다.
* `supports_skipping_indices` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 스킵 인덱스를 지원하는지 나타내는 플래그입니다.
* `supports_projections` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 프로젝션을 지원하는지 나타내는 플래그입니다.
* `supports_sort_order` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 PARTITION&#95;BY, PRIMARY&#95;KEY, ORDER&#95;BY, SAMPLE&#95;BY 절을 지원하는지 나타내는 플래그입니다.
* `supports_ttl` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 TTL을 지원하는지 나타내는 플래그입니다.
* `supports_replication` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 데이터 복제를 지원하는지 나타내는 플래그입니다.
* `supports_deduplication` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 데이터 중복 제거를 지원하는지 나타내는 플래그입니다.
* `supports_parallel_insert` ([UInt8](/ko/reference/data-types/int-uint)) — 테이블 엔진이 병렬 삽입을 지원하는지 나타내는 플래그입니다(max&#95;insert&#95;threads 설정 참조).
* `description` ([String](/ko/reference/data-types/string)) — 테이블 엔진의 기능을 설명합니다. 전용 문서 페이지가 있는 엔진에는 해당 페이지의 전체 Markdown 본문이 포함되며, 나머지 엔진에는 간략한 요약이 포함됩니다.
* `syntax` ([String](/ko/reference/data-types/string)) — 테이블 생성 시 테이블 엔진을 사용하는 방법입니다. 대부분의 엔진에서는 CREATE TABLE 쿼리의 ENGINE 절이지만, 다양한 유형의 뷰나 Loop 엔진과 같은 일부 엔진은 CREATE VIEW 또는 테이블 함수에서의 SELECT처럼 다른 형식으로 사용됩니다.
* `examples` ([String](/ko/reference/data-types/string)) — 사용 예시입니다.
* `introduced_in` ([String](/ko/reference/data-types/string)) — 테이블 엔진이 처음 도입된 ClickHouse 버전이며, major.minor 형식으로 표시됩니다.
* `related` ([Array(String)](/ko/reference/data-types/array)) — 관련 테이블 엔진의 이름입니다.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 예시
</div>

```sql title="Query"
SELECT
    name,
    supports_settings,
    supports_skipping_indices,
    supports_sort_order,
    supports_ttl,
    supports_replication,
    supports_deduplication,
    supports_parallel_insert
FROM system.table_engines
WHERE name IN ('Kafka', 'MergeTree', 'ReplicatedCollapsingMergeTree')
```
