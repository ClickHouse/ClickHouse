## 설명 {#description}

이 ClickHouse 서버가 ZooKeeper 노드(보조 ZooKeeper 인스턴스 포함)에 등록한 현재 활성 [watch](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches)를 표시합니다. 각 행은 watch 1개를 나타냅니다.

**가용성**

`system.zookeeper_watches`는 ClickHouse Keeper 또는 ZooKeeper가 구성되어 있을 때만 존재합니다. 둘 중 어느 것도 구성되지 않은 서버에서는 이 테이블이 존재하지 않으며, 해당 테이블에 대한 쿼리는 `UNKNOWN_TABLE` 오류로 실패합니다.

## 컬럼 {#columns}

* `zookeeper_name` ([String](/ko/reference/data-types/string)) — ZooKeeper 연결 이름입니다(기본 연결은 &quot;default&quot;, 보조 연결은 해당 이름 사용).
* `create_time` ([DateTime](/ko/reference/data-types/datetime)) — watch가 생성된 시간입니다.
* `create_time_microseconds` ([DateTime64(6)](/ko/reference/data-types/datetime64)) — watch가 마이크로초 정밀도로 생성된 시간입니다.
* `path` ([String](/ko/reference/data-types/string)) — watch가 설정된 ZooKeeper 경로입니다.
* `session_id` ([Int64](/ko/reference/data-types/int-uint)) — watch를 등록한 연결의 세션 ID입니다.
* `request_xid` ([Int64](/ko/reference/data-types/int-uint)) — watch를 생성한 요청의 XID입니다.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/ko/reference/data-types/enum)) — watch를 생성한 작업입니다.
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/ko/reference/data-types/enum)) — watch 유형입니다: Children(list), Exists 또는 Data(get).
