<div id="description">
  ## 설명
</div>

구성 파일에서 사용할 수 있는 클러스터와 해당 클러스터에 속한 서버 정보를 포함합니다.

<div id="Columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `cluster` ([String](/ko/reference/data-types/string)) — 클러스터 이름입니다.
* `shard_num` ([UInt32](/ko/reference/data-types/int-uint)) — 클러스터 내 세그먼트 번호로, 1부터 시작합니다.
* `shard_name` ([String](/ko/reference/data-types/string)) — 클러스터 내 세그먼트 이름입니다.
* `shard_weight` ([UInt32](/ko/reference/data-types/int-uint)) — 데이터 쓰기 시 세그먼트의 상대적 가중치입니다.
* `internal_replication` ([UInt8](/ko/reference/data-types/int-uint)) — 이 호스트가 자체적으로 데이터를 복제할 수 있는 앙상블에 속하는지를 나타내는 플래그입니다.
* `replica_num` ([UInt32](/ko/reference/data-types/int-uint)) — 세그먼트 내 레플리카 번호로, 1부터 시작합니다.
* `host_name` ([String](/ko/reference/data-types/string)) — 구성에 지정된 호스트 이름입니다.
* `host_address` ([String](/ko/reference/data-types/string)) — DNS에서 얻은 호스트 IP 주소입니다.
* `port` ([UInt16](/ko/reference/data-types/int-uint)) — 서버 연결에 사용할 포트입니다.
* `is_local` ([UInt8](/ko/reference/data-types/int-uint)) — 호스트가 로컬 호스트인지를 나타내는 플래그입니다.
* `user` ([String](/ko/reference/data-types/string)) — 서버 연결에 사용할 사용자 이름입니다.
* `default_database` ([String](/ko/reference/data-types/string)) — 기본 데이터베이스 이름입니다.
* `errors_count` ([UInt32](/ko/reference/data-types/int-uint)) — 이 호스트가 레플리카에 연결하지 못한 횟수입니다.
* `slowdowns_count` ([UInt32](/ko/reference/data-types/int-uint)) — 헤지 요청으로 연결을 설정하는 동안 레플리카 변경을 유발한 지연 횟수입니다.
* `estimated_recovery_time` ([UInt32](/ko/reference/data-types/int-uint)) — 레플리카 오류 횟수가 0으로 초기화되어 정상 상태로 간주될 때까지 남은 시간(초)입니다.
* `database_shard_name` ([String](/ko/reference/data-types/string)) — `Replicated` 데이터베이스 세그먼트 이름입니다(`Replicated` 데이터베이스에 속한 클러스터에 해당).
* `database_replica_name` ([String](/ko/reference/data-types/string)) — `Replicated` 데이터베이스 레플리카 이름입니다(`Replicated` 데이터베이스에 속한 클러스터에 해당).
* `is_shared_catalog_cluster` ([UInt8](/ko/reference/data-types/int-uint)) — 클러스터가 Shared Catalog에 속하는지를 나타내는 Bool입니다.
* `is_active` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — Replicated 데이터베이스 레플리카의 상태입니다(Replicated 데이터베이스에 속한 클러스터에 해당). 1은 &#39;레플리카가 온라인 상태&#39;, 0은 &#39;레플리카가 오프라인 상태&#39;, NULL은 &#39;알 수 없음&#39;을 의미합니다.
* `unsynced_after_recovery` ([Nullable(UInt8)](/ko/reference/data-types/nullable)) — 레플리카를 생성하거나 복구한 후 Replicated 데이터베이스 레플리카의 복제 지연이 max&#95;replication&#95;lag&#95;to&#95;enqueue보다 큰지를 나타냅니다.
* `replication_lag` ([Nullable(UInt32)](/ko/reference/data-types/nullable)) — `Replicated` 데이터베이스 레플리카의 복제 지연입니다(Replicated 데이터베이스에 속한 클러스터에 해당).
* `recovery_time` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — `Replicated` 데이터베이스 레플리카의 복구 시간이며, 밀리초 단위입니다(Replicated 데이터베이스에 속한 클러스터에 해당).

**별칭:**

* `name` — `cluster`의 별칭입니다.

{/*AUTOGENERATED_END*/}
