<div id="description">
  ## 설명
</div>

`config.xml`에 지정된 서버의 전역 설정 정보를 포함합니다.
이 테이블에는 고정된 구조를 가진 지원되는 중첩 설정도 포함하며, 목록과 같은 동적 섹션은 포함하지 않습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ko/reference/data-types/string)) — 서버 설정 이름입니다.
* `value` ([String](/ko/reference/data-types/string)) — 서버 설정 값입니다.
* `default` ([String](/ko/reference/data-types/string)) — 서버 설정 기본값입니다.
* `changed` ([UInt8](/ko/reference/data-types/int-uint)) — config.xml에서 설정이 지정되었는지 나타냅니다.
* `description` ([String](/ko/reference/data-types/string)) — 서버 설정에 대한 간략한 설명입니다.
* `type` ([String](/ko/reference/data-types/string)) — 서버 설정 값의 유형입니다.
* `changeable_without_restart` ([Enum8(&#39;No&#39; = 0, &#39;IncreaseOnly&#39; = 1, &#39;DecreaseOnly&#39; = 2, &#39;Yes&#39; = 3)](/ko/reference/data-types/enum)) — 런타임에 설정을 변경할 수 있는지 나타냅니다.
* `is_obsolete` ([UInt8](/ko/reference/data-types/int-uint)) — 설정이 더 이상 사용되지 않는 항목인지 나타냅니다.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 예시
</div>

```sql
SELECT *
FROM system.server_settings
WHERE name LIKE '%thread_pool%'
```

`WHERE changed`는 예를 들어 설정 파일의 설정이 올바르게 로드되어
실제로 사용되고 있는지 확인할 때 유용합니다.
