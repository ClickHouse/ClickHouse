<div id="description">
  ## 설명
</div>

이 시스템 테이블은 `SHOW PROCESSLIST` 쿼리 구현에 사용됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/ko/reference/data-types/int-uint)) — 이 쿼리가 사용자가 직접 실행한 것인지, 아니면 분산 쿼리 실행 중 ClickHouse 서버에서 실행된 것인지를 나타냅니다.
* `user` ([String](/ko/reference/data-types/string)) — 쿼리를 실행한 사용자입니다. 분산 처리에서는 쿼리가 default 사용자로 원격 서버에 전송된다는 점에 유의하십시오. 이 필드에는 이 쿼리가 시작한 쿼리가 아닌, 해당 쿼리의 사용자 이름이 포함됩니다.
* `query_id` ([String](/ko/reference/data-types/string)) — 정의된 경우 쿼리 ID입니다.
* `address` ([IPv6](/ko/reference/data-types/ipv6)) — 쿼리가 실행된 IP 주소입니다. 분산 처리에서도 동일합니다. 분산 쿼리가 원래 실행된 위치를 추적하려면 쿼리 요청 서버의 system.processes를 확인하십시오.
* `port` ([UInt16](/ko/reference/data-types/int-uint)) — 쿼리가 실행된 클라이언트 포트입니다.
* `initial_user` ([String](/ko/reference/data-types/string)) — 원본 쿼리를 실행한 사용자의 이름입니다(분산 쿼리 실행).
* `initial_query_id` ([String](/ko/reference/data-types/string)) — 원본 쿼리의 ID입니다(분산 쿼리 실행).
* `initial_address` ([IPv6](/ko/reference/data-types/ipv6)) — 부모 쿼리가 시작된 IP 주소입니다.
* `initial_port` ([UInt16](/ko/reference/data-types/int-uint)) — 부모 쿼리를 실행하는 데 사용된 클라이언트 포트입니다.
* `interface` ([UInt8](/ko/reference/data-types/int-uint)) — 쿼리 전송에 사용된 인터페이스입니다. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/ko/reference/data-types/string)) — clickhouse-client를 실행하는 운영 체제 사용자 이름입니다.
* `client_hostname` ([String](/ko/reference/data-types/string)) — clickhouse-client 또는 다른 TCP 클라이언트가 실행되는 클라이언트 머신의 호스트명입니다.
* `client_name` ([String](/ko/reference/data-types/string)) — clickhouse-client 또는 다른 TCP 클라이언트의 이름입니다.
* `client_agent` ([LowCardinality(String)](/ko/reference/data-types/lowcardinality)) — 환경 변수에서 감지된, 클라이언트를 호출한 AI 코딩 에이전트입니다(예: `claude-code`, `cursor`). 에이전트가 감지되지 않으면 비어 있습니다.
* `client_revision` ([UInt64](/ko/reference/data-types/int-uint)) — clickhouse-client 또는 다른 TCP 클라이언트의 revision입니다.
* `client_version_major` ([UInt64](/ko/reference/data-types/int-uint)) — clickhouse-client 또는 다른 TCP 클라이언트의 주 버전입니다.
* `client_version_minor` ([UInt64](/ko/reference/data-types/int-uint)) — clickhouse-client 또는 다른 TCP 클라이언트의 부 버전입니다.
* `client_version_patch` ([UInt64](/ko/reference/data-types/int-uint)) — clickhouse-client 또는 다른 TCP 클라이언트 버전의 패치 구성 요소입니다.
* `http_method` ([UInt8](/ko/reference/data-types/int-uint)) — 쿼리를 시작한 HTTP 메서드입니다. 가능한 값: 0 — TCP 인터페이스에서 쿼리가 시작되었습니다. 1 — GET 메서드가 사용되었습니다. 2 — POST 메서드가 사용되었습니다.
* `http_user_agent` ([String](/ko/reference/data-types/string)) — HTTP 쿼리에서 전달된 HTTP 헤더 UserAgent입니다.
* `http_referer` ([String](/ko/reference/data-types/string)) — HTTP 쿼리에서 전달된 HTTP 헤더 Referer입니다(쿼리를 실행한 페이지의 전체 또는 일부 주소를 포함함).
* `forwarded_for` ([String](/ko/reference/data-types/string)) — HTTP 쿼리에서 전달된 HTTP 헤더 X-Forwarded-For입니다.
* `quota_key` ([String](/ko/reference/data-types/string)) — 쿼터 설정에서 지정한 쿼터 키입니다(keyed 참조).
* `distributed_depth` ([UInt64](/ko/reference/data-types/int-uint)) — 쿼리가 내부적으로 서버 노드 간에 재전송된 횟수입니다.
* `elapsed` ([Float64](/ko/reference/data-types/float)) — 요청 실행이 시작된 후 경과한 시간(초)입니다.
* `is_cancelled` ([UInt8](/ko/reference/data-types/int-uint)) — 쿼리가 취소되었는지 여부입니다.
* `is_all_data_sent` ([UInt8](/ko/reference/data-types/int-uint)) — 모든 데이터가 클라이언트로 전송되었는지 여부입니다(즉, 서버에서 쿼리 처리가 완료되었는지 여부).
* `read_rows` ([UInt64](/ko/reference/data-types/int-uint)) — 테이블에서 읽은 행 수입니다. 분산 처리 시 요청 서버에서는 모든 원격 서버의 합계입니다.
* `read_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 테이블에서 읽은 비압축 바이트 수입니다. 분산 처리 시 요청 서버에서는 모든 원격 서버의 합계입니다.
* `total_rows_approx` ([UInt64](/ko/reference/data-types/int-uint)) — 읽어야 할 총 행 수의 추정치입니다. 분산 처리 시 요청 서버에서는 모든 원격 서버의 합계입니다. 처리할 새 소스가 확인되면 요청 처리 중에 업데이트될 수 있습니다.
* `written_rows` ([UInt64](/ko/reference/data-types/int-uint)) — 스토리지에 기록된 행 수입니다.
* `written_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 스토리지에 기록된 바이트 수입니다.
* `memory_usage` ([Int64](/ko/reference/data-types/int-uint)) — 쿼리가 사용하는 RAM 크기입니다. 일부 유형의 전용 메모리는 포함되지 않을 수 있습니다.
* `peak_memory_usage` ([Int64](/ko/reference/data-types/int-uint)) — 현재까지의 최대 메모리 사용량입니다.
* `query` ([String](/ko/reference/data-types/string)) — 쿼리 텍스트입니다. INSERT의 경우 삽입할 데이터는 포함하지 않습니다.
* `normalized_query_hash` ([UInt64](/ko/reference/data-types/int-uint)) — 리터럴 값만 다른 쿼리에서는 동일한 값을 갖는 등의 숫자 해시값입니다.
* `query_kind` ([String](/ko/reference/data-types/string)) — 쿼리 유형입니다. 예: SELECT, INSERT
* `thread_ids` ([Array(UInt64)](/ko/reference/data-types/array)) — 이 쿼리에 참여한 모든 스레드의 식별자 목록입니다.
* `peak_threads_usage` ([UInt64](/ko/reference/data-types/int-uint)) — 쿼리를 실행한 동시 스레드의 최대 수입니다.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ko/reference/data-types/map)) — 이 쿼리에 대해 계산된 ProfileEvents입니다.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ko/reference/data-types/map)) — 수정된 사용자 수준 설정 목록입니다.
* `current_database` ([String](/ko/reference/data-types/string)) — 현재 데이터베이스의 이름입니다.
* `is_internal` ([UInt8](/ko/reference/data-types/int-uint)) — 내부적으로 실행되는 보조 쿼리인지 여부를 나타냅니다.

**별칭:**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)`의 별칭입니다.
* `ProfileEvents.Values` — `mapValues(ProfileEvents)`의 별칭입니다.
* `Settings.Names` — `mapKeys(Settings)`의 별칭입니다.
* `Settings.Values` — `mapValues(Settings)`의 별칭입니다.

{/*AUTOGENERATED_END*/}
