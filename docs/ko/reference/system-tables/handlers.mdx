<div id="description">
  ## 설명
</div>

[`CREATE HANDLER`](/ko/reference/statements/create/handler)를 통해 생성된 모든 SQL 정의 HTTP 핸들러의 목록을 포함합니다.

이 테이블을 읽으려면 `SHOW HANDLERS` 권한이 필요합니다. 이 권한이 없으면 테이블이 비어 있는 것으로 표시됩니다. 핸들러의 쿼리에
포함될 수 있는 시크릿(예: 테이블 함수에 전달되는 자격 증명)은 사용자가 시크릿을 볼 수 있는 경우에만
`query` 및 `create_query` 컬럼에 표시됩니다(`display_secrets_in_show_and_select` 서버 설정 및 `format_display_secrets_in_show_and_select` 포맷
설정이 활성화되고 사용자에게 `displaySecretsInShowAndSelect` 권한이 있는 경우). 그렇지 않으면
`SHOW CREATE TABLE`과 마찬가지로 마스킹됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ko/reference/data-types/string)) — 핸들러 이름입니다.
* `protocol` ([Nullable(String)](/ko/reference/data-types/nullable)) — 핸들러가 제한되는 조합형 프로토콜입니다. 핸들러가 모든 HTTP 엔드포인트(내장 `http`/`https` 포트 및 모든 HTTP 유형 조합형 프로토콜 리스너)에서 활성화된 경우 NULL입니다.
* `url_match_type` ([String](/ko/reference/data-types/string)) — URL 일치 방식입니다. exact, prefix 또는 regexp입니다.
* `url` ([String](/ko/reference/data-types/string)) — 핸들러가 일치시키는 URL 패턴입니다.
* `methods` ([Array(String)](/ko/reference/data-types/array)) — 허용되는 HTTP 메서드입니다.
* `type` ([String](/ko/reference/data-types/string)) — 핸들러 유형입니다(`query`만 지원합니다).
* `query` ([String](/ko/reference/data-types/string)) — 핸들러가 실행하는 SQL 쿼리입니다. 사용자가 시크릿을 볼 권한이 없는 경우 숨겨집니다.
* `create_query` ([String](/ko/reference/data-types/string)) — CREATE HANDLER 문입니다. 사용자가 시크릿을 볼 권한이 없는 경우 숨겨집니다.

{/*AUTOGENERATED_END*/}
