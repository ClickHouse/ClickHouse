## 설명 {#description}

<Warning>
  CatBoost 통합은 ClickHouse에서 제거되었으며 `system.models`는 더 이상 존재하지 않습니다. 이 테이블을 쿼리하면 `UNKNOWN_TABLE` 오류가 발생합니다. 이 페이지는 과거에 게시된 문서를 보존하기 위해 유지되고 있습니다. 현재 존재하는 테이블은 [시스템 테이블 개요](/ko/reference/system-tables/overview)를 참조하십시오.
</Warning>

`LibraryBridge`의 메모리에 로드된 CatBoost 모델 목록과 로드된 시각을 담고 있었습니다.

## 컬럼 {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/ko/reference/data-types/string)) — 학습된 모델의 경로.
* `type` ([String](/ko/reference/data-types/string)) — 모델 유형. 현재는 catboost만 지원됩니다.
* `loading_start_time` ([DateTime](/ko/reference/data-types/datetime)) — 모델 로딩이 시작된 시간.
* `loading_duration` ([Float32](/ko/reference/data-types/float)) — 모델 로딩에 걸린 시간.

{/*AUTOGENERATED_END*/}
