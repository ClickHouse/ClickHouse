현재 세션에 정의된 모든 가상(what-if) PROJECTION을 나열합니다. [`CREATE HYPOTHETICAL PROJECTION`](/ko/reference/statements/hypothetical-projection#create-hypothetical-projection) 및 [`EXPLAIN WHATIF`](/ko/reference/statements/explain#explain-whatif)를 참조하십시오.

이 테이블의 내용은 세션 범위로 한정됩니다. 각 연결은 자신의 가상 PROJECTION만 볼 수 있으며, 현재 세션에서 생성한 것이 없으면 테이블은 비어 있습니다.

현재의 `(database, table)`은 쿼리 시점에 UUID로 해석되므로 `RENAME TABLE`이 그대로 반영되며, 삭제된 테이블의 항목은 자동으로 숨겨집니다.

## 컬럼 {#columns}

{/*AUTOGENERATED_START*/}

* `database` ([String](/ko/reference/data-types/string)) — 데이터베이스 이름
* `table` ([String](/ko/reference/data-types/string)) — 테이블 이름
* `name` ([String](/ko/reference/data-types/string)) — PROJECTION 이름
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ko/reference/data-types/enum)) — PROJECTION 유형
* `sorting_key` ([Array(String)](/ko/reference/data-types/array)) — PROJECTION 정렬 키
* `query` ([String](/ko/reference/data-types/string)) — PROJECTION SELECT 쿼리이며, INDEX ... TYPE ... 형식에서는 비어 있습니다
* `definition` ([String](/ko/reference/data-types/string)) — 작성된 그대로의 전체 PROJECTION 선언
* `settings` ([Map(String, String)](/ko/reference/data-types/map)) — WITH SETTINGS로 지정된 PROJECTION 설정

{/*AUTOGENERATED_END*/}

**예시**

```sql
CREATE HYPOTHETICAL PROJECTION p_by_b ON t (SELECT a, b ORDER BY b);
SELECT name, type, sorting_key FROM system.hypothetical_projections;
```

```text
┌─name───┬─type───┬─sorting_key─┐
│ p_by_b │ Normal │ ['b']       │
└────────┴────────┴─────────────┘
```
