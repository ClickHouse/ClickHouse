<div id="description">
  ## 설명
</div>

[system.dropped&#95;tables](/ko/reference/system-tables/dropped_tables)에 있는 삭제된 [MergeTree](/ko/reference/engines/table-engines/mergetree-family/mergetree) 테이블의 파트 정보를 포함합니다

이 테이블의 스키마(schema)는 [system.parts](/ko/reference/system-tables/parts)와 동일합니다

<div id="columns">
  ## 컬럼
</div>

{/*자동 생성 시작*/}

* `partition` ([String](/ko/reference/data-types/string)) — 파티션 식별자(테이블 파티션 키 표현식에서 파생된 문자열 형식).
* `name` ([String](/ko/reference/data-types/string)) — 데이터 파트의 이름입니다. 파트 이름 구조를 통해 데이터, 수집 및 머지 패턴과 관련된 다양한 정보를 파악할 수 있습니다. 파트 이름 포맷은 다음과 같습니다:

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * 정의:
    * `partition_id` - 파티션 키를 식별합니다
    * `minimum_block_number` - 파트의 최소 블록 번호를 식별합니다. ClickHouse는 항상 연속된 블록을 머지합니다
    * `maximum_block_number` - 파트의 최대 블록 번호를 식별합니다
    * `level` - 파트에 머지가 추가로 수행될 때마다 1씩 증가합니다. 수준이 0이면 아직 머지되지 않은 새 파트임을 나타냅니다. ClickHouse의 모든 파트는 항상 불변이라는 점을 기억해야 합니다
    * `data_version` - 파트가 변형될 때 증가하는 선택적 값입니다(파트는 불변이므로 변형된 데이터는 항상 새 파트에만 기록됩니다)
* `uuid` ([UUID](/ko/reference/data-types/uuid)) — 데이터 파트의 UUID입니다.
* `part_type` ([String](/ko/reference/data-types/string)) — 데이터 파트의 저장 포맷입니다. 가능한 값: `Wide` — 각 컬럼이 별도의 파일에 저장됨, `Compact` — 모든 컬럼이 하나의 파일에 저장됨. 데이터 저장 포맷은 MergeTree 테이블의 `min_bytes_for_wide_part` 및 `min_rows_for_wide_part` 설정으로 제어됩니다.
* `part_storage_type` ([String](/ko/reference/data-types/string)) — `DataPartStorage`의 유형입니다. 가능한 값: `Packed` - 대부분의 파트 파일이 하나의 아카이브에 저장됨(프로젝션 및 `txn_version.txt`와 같은 일부 서비스 파일은 별도로 기록됨), `Full` - 각 파일이 별도로 저장됨.
* `active` ([UInt8](/ko/reference/data-types/int-uint)) — 데이터 파트가 활성 상태인지 나타내는 플래그입니다. 활성 상태인 데이터 파트는 테이블에서 사용됩니다. 그렇지 않으면 삭제될 예정입니다. 비활성 데이터 파트는 머지 및 변이 작업 후에 나타납니다.
* `marks` ([UInt64](/ko/reference/data-types/int-uint)) — 마크 수입니다. 데이터 파트의 대략적인 행 수를 구하려면 마크 수에 인덱스 세분화 수준(일반적으로 8192)을 곱하십시오(이 힌트는 적응형 세분화 수준에서는 작동하지 않습니다).
* `rows` ([UInt64](/ko/reference/data-types/int-uint)) — 행 수입니다.
* `files` ([UInt64](/ko/reference/data-types/int-uint)) — 데이터 파트의 파일 수입니다.
* `bytes_on_disk` ([UInt64](/ko/reference/data-types/int-uint)) — 모든 데이터 파트 파일의 총 크기(바이트)입니다.
* `data_compressed_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 데이터 파트의 압축 데이터 총 크기입니다. 보조 파일(예: 마크 파일)은 포함되지 않습니다.
* `data_uncompressed_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 데이터 파트의 비압축 데이터 총 크기입니다. 보조 파일(예: 마크 파일)은 포함되지 않습니다.
* `primary_key_size` ([UInt64](/ko/reference/data-types/int-uint)) — 디스크의 primary.idx/cidx 파일에서 기본 키 값이 사용하는 메모리 양(바이트)입니다.
* `marks_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 마크 파일의 크기입니다.
* `secondary_indices_compressed_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 데이터 파트의 보조 인덱스 압축 데이터 총 크기입니다. 보조 파일(예: 마크 파일)은 포함되지 않습니다.
* `secondary_indices_uncompressed_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 데이터 파트의 보조 인덱스 비압축 데이터 총 크기입니다. 보조 파일(예: 마크 파일)은 포함되지 않습니다.
* `secondary_indices_marks_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 보조 인덱스의 마크 파일 크기입니다.
* `modification_time` ([DateTime](/ko/reference/data-types/datetime)) — 데이터 파트가 있는 디렉터리가 수정된 시간입니다. 일반적으로 데이터 파트 생성 시간과 일치합니다.
* `remove_time` ([DateTime](/ko/reference/data-types/datetime)) — 데이터 파트가 비활성 상태가 된 시간입니다.
* `refcount` ([UInt32](/ko/reference/data-types/int-uint)) — 데이터 파트가 사용되는 위치 수입니다. 값이 2보다 크면 데이터 파트가 쿼리 또는 머지에 사용되고 있음을 나타냅니다.
* `min_date` ([Date](/ko/reference/data-types/date)) — 데이터 파트의 날짜 키 최솟값입니다.
* `max_date` ([Date](/ko/reference/data-types/date)) — 데이터 파트의 날짜 키 최댓값입니다.
* `min_time` ([DateTime](/ko/reference/data-types/datetime)) — 데이터 파트의 날짜 및 시간 키 최솟값입니다.
* `max_time` ([DateTime](/ko/reference/data-types/datetime)) — 데이터 파트의 날짜 및 시간 키 최댓값입니다.
* `partition_id` ([String](/ko/reference/data-types/string)) — 파티션 ID입니다.
* `min_block_number` ([Int64](/ko/reference/data-types/int-uint)) — 머지 후 현재 파트를 구성하는 데이터 파트의 최소 번호입니다.
* `max_block_number` ([Int64](/ko/reference/data-types/int-uint)) — 머지 후 현재 파트를 구성하는 데이터 파트의 최대 번호입니다.
* `level` ([UInt32](/ko/reference/data-types/int-uint)) — 머지 트리의 깊이입니다. 0은 현재 파트가 다른 파트를 머지하여 생성된 것이 아니라 삽입으로 생성되었음을 의미합니다.
* `data_version` ([UInt64](/ko/reference/data-types/int-uint)) — 데이터 파트에 적용할 뮤테이션을 결정하는 데 사용되는 번호입니다(`data_version`보다 높은 버전의 뮤테이션).
* `primary_key_bytes_in_memory` ([UInt64](/ko/reference/data-types/int-uint)) — 기본 키 값에 사용되는 메모리 양(바이트)입니다. `primary_key_lazy_load`가 활성화되어 있고 키가 로드되지 않은 경우 0입니다. 0이 아닌 경우 해당 바이트는 파트 자체에 있으며 `jemalloc.mergetree_arena.active_bytes`에 հաշվ հաշվ됩니다. `PrimaryIndexCacheBytes`에는 절대 포함되지 않습니다. 파트별로 두 항목은 상호 배타적입니다. `primary_key_lazy_load` 및 `use_primary_key_cache`에 따라 인덱스는 파트(이 메트릭) 또는 공유 `PrimaryIndexCache`(다른 메트릭)에 존재합니다.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ko/reference/data-types/int-uint)) — 기본 키 값용으로 예약된 메모리 양(바이트)입니다. `primary_key_lazy_load`가 활성화되어 있고 키가 로드되지 않은 경우 0입니다. 0이 아닌 경우 `jemalloc.mergetree_arena.active_bytes`에 포함됩니다. `PrimaryIndexCacheBytes`와의 관계는 `primary_key_bytes_in_memory`의 참고 사항을 참조하십시오.
* `index_granularity_bytes_in_memory` ([UInt64](/ko/reference/data-types/int-uint)) — 인덱스 세분화 수준 값에 사용되는 메모리 양(바이트)입니다(`primary_key_lazy_load=1` 및 `use_primary_key_cache=1`인 경우 0입니다). 0이 아닌 경우 해당 바이트는 파트가 소유하며 `jemalloc.mergetree_arena.active_bytes`에 հաշվ հաշվ됩니다.
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ko/reference/data-types/int-uint)) — 인덱스 세분화 수준 값용으로 예약된 메모리 양(바이트)입니다(`primary_key_lazy_load=1` 및 `use_primary_key_cache=1`인 경우 0입니다). 0이 아닌 경우 `jemalloc.mergetree_arena.active_bytes`에 포함됩니다.
* `is_frozen` ([UInt8](/ko/reference/data-types/int-uint)) — 파티션 데이터 백업이 존재함을 나타내는 플래그입니다. 1이면 백업이 존재하고, 0이면 존재하지 않습니다. 자세한 내용은 FREEZE PARTITION을 참조하십시오.
* `database` ([String](/ko/reference/data-types/string)) — 데이터베이스 이름입니다.
* `table` ([String](/ko/reference/data-types/string)) — 테이블 이름입니다.
* `engine` ([String](/ko/reference/data-types/string)) — 매개변수를 제외한 테이블 엔진 이름입니다.
* `disk_name` ([String](/ko/reference/data-types/string)) — 데이터 파트를 저장하는 디스크 이름입니다.
* `path` ([String](/ko/reference/data-types/string)) — 데이터 파트 파일이 있는 폴더의 절대 경로입니다.
* `hash_of_all_files` ([String](/ko/reference/data-types/string)) — 압축된 파일의 sipHash128입니다.
* `hash_of_uncompressed_files` ([String](/ko/reference/data-types/string)) — 압축되지 않은 파일(마크, 인덱스 파일 등)의 sipHash128입니다.
* `uncompressed_hash_of_compressed_files` ([String](/ko/reference/data-types/string)) — 압축 파일을 압축 해제한 것으로 간주했을 때의 데이터 sipHash128입니다.
* `delete_ttl_info_min` ([DateTime](/ko/reference/data-types/datetime)) — TTL DELETE 규칙의 날짜 및 시간 키 최솟값입니다.
* `delete_ttl_info_max` ([DateTime](/ko/reference/data-types/datetime)) — TTL DELETE 규칙의 날짜 및 시간 키 최댓값입니다.
* `move_ttl_info.expression` ([Array(String)](/ko/reference/data-types/array)) — 표현식 배열입니다. 각 표현식은 TTL MOVE 규칙을 정의합니다.
* `move_ttl_info.min` ([Array(DateTime)](/ko/reference/data-types/array)) — 날짜 및 시간 값 배열입니다. 각 요소는 TTL MOVE 규칙의 최소 키 값을 나타냅니다.
* `move_ttl_info.max` ([Array(DateTime)](/ko/reference/data-types/array)) — 날짜 및 시간 값 배열입니다. 각 요소는 TTL MOVE 규칙의 최대 키 값을 나타냅니다.
* `default_compression_codec` ([String](/ko/reference/data-types/string)) — 컬럼에 명시적으로 지정된 코덱이 없거나 `CODEC(Default)`를 사용하는 경우 이 데이터 파트를 압축하는 데 사용되는 코덱의 이름입니다. `allow_experimental_adaptive_codec_selection`을 사용하면 이러한 컬럼의 개별 블록에서 다른 코덱을 사용할 수 있습니다. [`mergeTreeCodecBlockCounts`](/ko/reference/functions/table-functions/mergeTreeCodecBlockCounts)를 참조하십시오.
* `recompression_ttl_info.expression` ([Array(String)](/ko/reference/data-types/array)) — TTL 표현식입니다.
* `recompression_ttl_info.min` ([Array(DateTime)](/ko/reference/data-types/array)) — 이 파트에서 계산된 TTL 표현식의 최솟값입니다. TTL이 만료된 행이 하나 이상 있는지 확인하는 데 사용됩니다.
* `recompression_ttl_info.max` ([Array(DateTime)](/ko/reference/data-types/array)) — 이 파트에서 계산된 TTL 표현식의 최댓값입니다. 모든 행의 TTL이 만료되었는지 확인하는 데 사용됩니다.
* `group_by_ttl_info.expression` ([Array(String)](/ko/reference/data-types/array)) — TTL 표현식입니다.
* `group_by_ttl_info.min` ([Array(DateTime)](/ko/reference/data-types/array)) — 이 파트에서 계산된 TTL 표현식의 최솟값입니다. TTL이 만료된 행이 하나 이상 있는지 확인하는 데 사용됩니다.
* `group_by_ttl_info.max` ([Array(DateTime)](/ko/reference/data-types/array)) — 이 파트에서 계산된 TTL 표현식의 최댓값입니다. 모든 행의 TTL이 만료되었는지 확인하는 데 사용됩니다.
* `rows_where_ttl_info.expression` ([Array(String)](/ko/reference/data-types/array)) — TTL 표현식입니다.
* `rows_where_ttl_info.min` ([Array(DateTime)](/ko/reference/data-types/array)) — 이 파트에서 계산된 TTL 표현식의 최솟값입니다. TTL이 만료된 행이 하나 이상 있는지 확인하는 데 사용됩니다.
* `rows_where_ttl_info.max` ([Array(DateTime)](/ko/reference/data-types/array)) — 이 파트에서 계산된 TTL 표현식의 최댓값입니다. 모든 행의 TTL이 만료되었는지 확인하는 데 사용됩니다.
* `projections` ([Array(String)](/ko/reference/data-types/array)) — 이 파트에 대해 계산된 프로젝션 이름 목록입니다.
* `visible` ([UInt8](/ko/reference/data-types/int-uint)) — 이 파트가 SELECT 쿼리에 표시되는지 나타내는 플래그입니다.
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ko/reference/data-types/tuple)) — 이 객체를 생성했거나 생성하려는 트랜잭션의 ID입니다.
* `removal_tid_lock` ([UInt64](/ko/reference/data-types/int-uint)) — 객체 제거를 위해 객체를 잠그는 데 사용되는 removal&#95;tid의 해시입니다.
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ko/reference/data-types/tuple)) — 이 객체를 제거했거나 제거하려는 트랜잭션의 ID입니다.
* `creation_csn` ([UInt64](/ko/reference/data-types/int-uint)) — 이 객체를 생성한 트랜잭션의 CSN입니다.
* `removal_csn` ([UInt64](/ko/reference/data-types/int-uint)) — 이 객체를 제거한 트랜잭션의 CSN입니다.
* `has_lightweight_delete` ([UInt8](/ko/reference/data-types/int-uint)) — 파트에 경량한 삭제 마스크가 있는지 나타내는 플래그입니다.
* `last_removal_attempt_time` ([DateTime](/ko/reference/data-types/datetime)) — 서버가 이 파트의 삭제를 마지막으로 시도한 시간입니다.
* `removal_state` ([String](/ko/reference/data-types/string)) — 파트 삭제 프로세스의 현재 상태입니다.
