## 설명 {#description}

모든 테이블에 존재하는 프로젝션(projection)에 대한 정보를 포함합니다.

`total_rows`, `data_compressed_bytes`, `data_uncompressed_bytes` 컬럼은 해당 프로젝션(projection)을 포함하는 테이블의 활성 데이터 파트(active parts)를 기준으로 합산한 값입니다. 따라서 프로젝션(projection)이 구축되기 전까지는 0입니다. 프로젝션(projection)은 프로젝션(projection)을 추가한 이후에 수행된 삽입이나 `ALTER TABLE ... MATERIALIZE PROJECTION` 등을 통해 구축됩니다. 각 프로젝션(projection) 파트의 크기는 [system.projection&#95;parts](/ko/operations/system-tables/projection_parts)를 참조하십시오.

## 컬럼 {#columns}

* `database` ([String](/ko/reference/data-types/string)) — 데이터베이스 이름.
* `table` ([String](/ko/reference/data-types/string)) — 테이블 이름.
* `name` ([String](/ko/reference/data-types/string)) — 프로젝션(projection) 이름.
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ko/reference/data-types/enum)) — 프로젝션(projection) 유형.
* `total_rows` ([UInt64](/ko/reference/data-types/int-uint)) — 전체 행 수.
* `data_compressed_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 압축된 데이터의 크기(바이트).
* `data_uncompressed_bytes` ([UInt64](/ko/reference/data-types/int-uint)) — 압축 해제된 데이터의 크기(바이트).
* `sorting_key` ([Array(String)](/ko/reference/data-types/array)) — 프로젝션(projection) 정렬 키.
* `query` ([String](/ko/reference/data-types/string)) — 프로젝션(projection) 쿼리.
* `settings` ([Map(String, String)](/ko/reference/data-types/map)) — 프로젝션(projection) 설정.
