## 설명 {#description}

파일별 S3Queue 메타데이터의 인메모리 상태와 현재 처리 중인 행을 포함합니다.

## 컬럼 {#columns}

* `zookeeper_path` ([String](/ko/reference/data-types/string)) — 메타데이터가 저장된 ZooKeeper 경로
* `file_path` ([String](/ko/reference/data-types/string)) — 처리 중인 파일의 경로
* `file_name` ([String](/ko/reference/data-types/string)) — 처리 중인 파일의 이름
* `rows_processed` ([UInt64](/ko/reference/data-types/int-uint)) — 현재 처리 중인 행 수
* `status` ([String](/ko/reference/data-types/string)) — 처리 상태: Processed, Processing, Failed, 또는 캐시가 알고는 있지만 상태 정보가 없는 파일(예: 처리가 초기화된 파일)의 경우 None. `processing_observed_in_keeper_time`이 널이 아니라면, `Processing` 상태가 해당 파일을 점유한 프로세서가 설정한 것이 아니라 Keeper에서 읽어온 것임을 의미합니다
* `processing_start_time` ([Nullable(DateTime)](/ko/reference/data-types/nullable)) — 파일 처리가 시작된 시간
* `processing_end_time` ([Nullable(DateTime)](/ko/reference/data-types/nullable)) — 파일 처리가 완료된 시간
* `exception` ([String](/ko/reference/data-types/string)) — 처리 중 발생한 예외. 항상 이 서버의 마지막 시도에서 발생한 예외이며, Keeper가 해당 파일에 대해 저장한 예외가 아닙니다
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/ko/reference/data-types/nullable)) — 이 서버의 프로세서가 파일을 점유하지 못해 `Processing` 상태를 직접 설정하지 않고 Keeper에서 읽어온 시간. 일반적으로 해당 파일은 다른 서버가 점유하고 있지만, 방금 파일을 가져간 이 서버의 다른 프로세서가 점유하고 있을 수도 있습니다. 어느 경우든 `rows_processed`, `processing_start_time`, `processing_end_time`, `exception`은 현재 파일을 점유하고 있는 처리가 아니라 이 서버가 해당 파일을 처리하려 했던 마지막 시도를 나타냅니다
