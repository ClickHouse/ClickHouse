<div id="description">
  ## 설명
</div>

각 AzureQueue 메타데이터 객체에 대해 Keeper의 처리 완료, 처리 중, 실패 노드의 현재 수와 필요에 따라 해당 내용을 포함합니다. 인메모리 캐시를 표시하는 system.azure&#95;queue&#95;metadata&#95;cache와 달리, 이 테이블은 Keeper에서 상태를 직접 읽습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/ko/reference/data-types/string)) — 메타데이터가 저장된 ZooKeeper의 경로입니다. 보조 ZooKeeper의 큐에서는 원시 Keeper 경로가 아니라 팩토리 키 `<zookeeper_name>:<path>`를 사용합니다.
* `processed_nodes_count` ([Nullable(UInt64)](/ko/reference/data-types/nullable)) — Keeper의 `processed` 디렉터리에 있는 노드 수입니다. `unordered` 모드에서만 설정됩니다. `ordered` 모드에서는 파일별 처리 완료 노드가 없으므로(`processed_path` 참조) 값은 NULL입니다.
* `processing_nodes_count` ([UInt64](/ko/reference/data-types/int-uint)) — Keeper의 `processing` 디렉터리에 있는 노드 수입니다.
* `failed_nodes_count` ([UInt64](/ko/reference/data-types/int-uint)) — Keeper의 `failed` 디렉터리에 있는 노드 수입니다.
* `processed_nodes` ([Map(String, String)](/ko/reference/data-types/map)) — Keeper의 `processed` 디렉터리 내용(노드 이름 -&gt; 노드 데이터)입니다. `unordered` 모드에서만 채워집니다. 이 컬럼을 선택한 경우에만 가져옵니다.
* `processing_nodes` ([Map(String, String)](/ko/reference/data-types/map)) — Keeper의 `processing` 디렉터리 내용(노드 이름 -&gt; 노드 데이터)입니다. 이 컬럼을 선택한 경우에만 가져옵니다.
* `failed_nodes` ([Map(String, String)](/ko/reference/data-types/map)) — Keeper의 `failed` 디렉터리 내용(노드 이름 -&gt; 노드 데이터)입니다. 이 컬럼을 선택한 경우에만 가져옵니다.
* `processed_path` ([Map(String, String)](/ko/reference/data-types/map)) — Keeper에서 처리 완료 포인터별 마지막 처리 경로(상대 포인터 경로 -&gt; 마지막 처리된 파일 경로)입니다. 단일 포인터, 버킷별 포인터, 파티션별 포인터를 포함하는 `ordered` 모드에서만 채워집니다. 이 컬럼을 선택한 경우에만 가져옵니다.

{/*AUTOGENERATED_END*/}
