<div id="description">
  ## 설명
</div>

`PostgreSQLWire` 포맷은 PostgreSQL wire 프로토콜의 결과 집합 부분을 직렬화합니다. 컬럼명과 타입이 포함된
`RowDescription` 메시지 뒤에 각 결과 행마다 `DataRow` 메시지 하나를 작성합니다.
값은 텍스트 표현을 사용하며, `NULL` 값에는 프로토콜의 null 필드 인코딩을 사용하고, 불리언 값은
`t` 또는 `f`로 작성됩니다.

이는 ClickHouse의
[PostgreSQL 인터페이스](/ko/concepts/features/interfaces/postgresql)를 통해 연결된 클라이언트를 위한 출력 전용 바이너리 형식입니다. 인터페이스는 `PostgreSQLWire`를 세션
기본값으로 설정하고, 쿼리에 명시적인 `FORMAT` 절이 없으면 이를 사용합니다. 명시적인 절은 기본값을 재정의하며,
다른 출력 형식으로는 유효한 PostgreSQL 결과 집합을 생성할 수 없습니다. 인터페이스는
인증, 명령 완료, 쿼리 준비 완료 메시지 등 주변 프로토콜 메시지를 작성합니다. `PostgreSQLWire`는
쿼리 결과를 독립형 파일로 표시하거나 저장하기 위한 용도가 아닙니다.

<div id="example-usage">
  ## 사용 예시
</div>

PostgreSQL 인터페이스를 활성화한 후 호환되는 클라이언트로 쿼리를 실행합니다.

```shell
psql -p 9005 -h 127.0.0.1 -U default -d default \
    -c "SELECT number, number % 2 = 0 AS even FROM numbers(3)"
```

쿼리에 `FORMAT` 절이 지정되지 않았으므로 인터페이스는 `PostgreSQLWire` 포맷으로 결과를 전송합니다.

<div id="format-settings">
  ## 포맷 설정
</div>

`PostgreSQLWire`는 개별 값에 표준 텍스트 직렬화 설정을 사용합니다. 포맷 자체에 특화된 설정은 없으며,
Boolean 값은 항상 PostgreSQL의 `t` 및 `f` 표현으로 직렬화됩니다.
