<div id="description">
  ## 설명
</div>

`MySQLWire` 포맷은 쿼리 결과를 MySQL wire-protocol 결과 세트로 직렬화합니다. 컬럼 수와
컬럼 정의를 기록한 다음 각 결과 행에 대해 프로토콜 행 패킷 하나를 기록하고, 마지막으로 `EOF` 또는 `OK` 패킷을 기록합니다. 행
패킷은 일반 쿼리에는 텍스트 프로토콜을, prepared statement에는 바이너리 프로토콜을 사용합니다.

이 포맷은 ClickHouse의 [MySQL 인터페이스](/ko/concepts/features/interfaces/mysql)를 통해 연결된
클라이언트에서만 사용하는 출력 전용 바이너리 포맷입니다. 인터페이스는 `MySQLWire`를 자동으로 선택하고
클라이언트 capability 및 패킷 시퀀스 번호와 같은 프로토콜 상태를 제공합니다. 쿼리 결과를 독립형 파일로 표시하거나
저장하는 용도로는 사용할 수 없습니다.

<div id="example-usage">
  ## 사용 예시
</div>

MySQL 인터페이스를 활성화한 후 호환되는 클라이언트로 쿼리를 실행합니다:

```shell
mysql --protocol tcp -h 127.0.0.1 -u default -P 9004 default \
    -e "SELECT number, number * 2 AS doubled FROM numbers(3)"
```

인터페이스는 `MySQLWire`를 사용해 결과를 전송하며, `FORMAT MySQLWire` 절을 명시적으로 지정할 필요는 없습니다. MySQL 인터페이스에서는 다른 출력 포맷을 명시적으로 지정할 수 없습니다.

<div id="format-settings">
  ## 포맷 설정
</div>

사용자가 구성할 수 있는 포맷 설정은 없습니다. MySQL 인터페이스는 클라이언트
handshake 및 실행되는 명령에서 필요한 설정을 가져옵니다.
