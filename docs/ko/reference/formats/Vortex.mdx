## 설명 {#description}

[Vortex](https://vortex.dev/)는 Apache Arrow와 호환되는 압축된 데이터를 위한 확장 가능한 열 지향 파일 포맷으로,
빠른 스캔(Scan)과 랜덤 액세스에 최적화되어 있습니다. ClickHouse는 Vortex 파일 읽기와 쓰기를 모두 지원합니다.

## 데이터 타입 매핑 {#data-types-matching-vortex}

아래 표는 `INSERT` 및 `SELECT` 쿼리에서 사용되는 Vortex 데이터 타입과 이에 대응하는 ClickHouse [데이터 타입](/ko/reference/data-types/index)을 보여줍니다.

| Vortex 데이터 타입 (`INSERT`) | ClickHouse 데이터 타입                                                                         | Vortex 데이터 타입 (`SELECT`)                                          |
| ------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `Bool`                   | [Bool](/ko/reference/data-types/boolean)                                                     | `Bool`                                                            |
| `I8`, `U8`               | [Int8/UInt8](/ko/reference/data-types/int-uint)                                              | `I8`, `U8`                                                        |
| `I16`, `U16`             | [Int16/UInt16](/ko/reference/data-types/int-uint)                                            | `I16`, `U16`                                                      |
| `I32`, `U32`             | [Int32/UInt32](/ko/reference/data-types/int-uint)                                            | `I32`, `U32`                                                      |
| `I64`, `U64`             | [Int64/UInt64](/ko/reference/data-types/int-uint)                                            | `I64`, `U64`                                                      |
| `F32`                    | [Float32](/ko/reference/data-types/float)                                                    | `F32`                                                             |
| `F64`                    | [Float64](/ko/reference/data-types/float)                                                    | `F64`                                                             |
| `Utf8`, `Binary`         | [String](/ko/reference/data-types/string)                                                    | `Utf8` (`output_format_vortex_string_as_string = 0`인 경우 `Binary`) |
| `Binary`                 | [FixedString](/ko/reference/data-types/fixedstring)                                          | `Binary`                                                          |
| `Decimal`                | [Decimal](/ko/reference/data-types/decimal)                                                  | `Decimal`                                                         |
| `vortex.date`            | [Date32](/ko/reference/data-types/date32)                                                    | `vortex.date`                                                     |
| `vortex.timestamp`       | [DateTime](/ko/reference/data-types/datetime)/[DateTime64](/ko/reference/data-types/datetime64) | `vortex.timestamp`                                                |
| `vortex.time`            | [Time64](/ko/reference/data-types/time64)                                                    | `vortex.time`                                                     |
| `List`                   | [Array](/ko/reference/data-types/array)                                                      | `List`                                                            |
| `Struct`                 | [Tuple](/ko/reference/data-types/tuple)                                                      | `Struct`                                                          |
| `Null`                   | [Nullable(Nothing)](/ko/reference/data-types/special-data-types/nothing)                     | `Null`                                                            |

그 밖의 타입은 지원되지 않습니다. 특히 [Map](/ko/reference/data-types/map),
[Int128/UInt128/Int256/UInt256](/ko/reference/data-types/int-uint), [IPv6](/ko/reference/data-types/ipv6)
및 [Interval](/ko/reference/data-types/special-data-types/interval) 컬럼은 Vortex 파일에 쓸 수 없습니다.
[String](/ko/reference/data-types/string) 컬럼은 `Utf8`로 기록되며, Vortex는 이를 `Binary`보다
더 효율적으로 압축합니다. Vortex는 `Utf8` 값이 유효한 UTF-8일 것을 요구하지만 ClickHouse 문자열은 임의의
바이트 시퀀스이므로, 유효한 UTF-8이 아닌 값을 쓰면 예외가 발생합니다.
`output_format_vortex_string_as_string = 0`으로 설정하면 문자열은 대신 `Binary`로 기록됩니다. Vortex에는
고정 크기 바이너리 타입이 없으므로 [FixedString](/ko/reference/data-types/fixedstring)은 항상 `Binary`로 기록되며,
스키마 추론 시 [String](/ko/reference/data-types/string)으로 다시 읽힙니다.
[LowCardinality](/ko/reference/data-types/lowcardinality) 컬럼은 기반 타입으로 기록됩니다
(딕셔너리 인코딩 등 각종 인코딩은 Vortex가 자체적으로 적응형으로 선택합니다).
[DateTime](/ko/reference/data-types/datetime) 컬럼은 초 단위 정밀도의 `vortex.timestamp`로 기록되므로,
소수 자릿수(scale)가 0인 [DateTime64](/ko/reference/data-types/datetime64)로 다시 읽힙니다.
`vortex.timestamp`는 소수 자릿수가 아닌 단위를 가지므로, 단위로 정확히 표현되는 소수 자릿수인
0, 3, 6, 9만 스키마 추론 후에도 유지됩니다. 그 밖의 소수 자릿수는 바로 위의 더 큰 단위로 기록되어
해당 단위의 소수 자릿수로 추론됩니다. 따라서 [DateTime64](/ko/reference/data-types/datetime64)`(1)`과 `(2)`는
`DateTime64(3)`으로, `(4)`와 `(5)`는 `DateTime64(6)`으로, `(7)`과 `(8)`은 `DateTime64(9)`로 다시 읽힙니다. 값은
재조정되므로 의미가 그대로 유지되며, 선언된 소수 자릿수만 커집니다. 타입을 명시적으로 지정하면
원래 타입 그대로 다시 읽힙니다. [Time64](/ko/reference/data-types/time64)에도 동일하게 적용됩니다.
`vortex.time`은 하루 중 시각을 나타내지만, ClickHouse의 [Time/Time64](/ko/reference/data-types/time64)는 음수 값과
24시간 이상의 값도 저장할 수 있습니다. 이러한 값을 쓰면 잘못된 값을 기록하는 대신 예외가 발생합니다.
Vortex에는 IP 주소용 타입이 없으므로 [IPv4](/ko/reference/data-types/ipv4) 컬럼은 `U32`로 기록되며,
스키마 추론 시 [UInt32](/ko/reference/data-types/int-uint)로 다시 읽힙니다. 이러한 컬럼을 `IPv4`로 다시 읽으려면
타입을 명시적으로 지정하십시오: `SELECT * FROM file('data.vortex', Vortex, 'ip IPv4')`.

ClickHouse 테이블(table) 컬럼의 데이터 타입은 대응하는 Vortex 데이터 필드의 타입과 일치하지 않아도 됩니다.
데이터를 삽입할 때 ClickHouse는 위 표에 따라 데이터 타입을 해석한 다음, 데이터를
ClickHouse 테이블 컬럼에 설정된 데이터 타입으로 [캐스팅](/ko/reference/functions/regular-functions/type-conversion-functions#CAST)합니다.

## 사용 예시 {#example-usage}

다음과 같이 Vortex 파일에서 데이터를 조회할 수 있습니다:

```sql
SELECT * FROM file('data.vortex');
```

다음과 같이 Vortex 파일에 데이터를 쓸 수도 있습니다:

```sql
SELECT * FROM numbers(3) INTO OUTFILE 'numbers.vortex' FORMAT Vortex;
```

## 포맷 설정 {#format-settings}

| 설정                                      | 설명                                                                                                                                                                                                                                                                                                                                      | 기본값  |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| `input_format_vortex_filter_push_down`  | `WHERE` 조건 중 변환 가능한 부분을 스캔(Scan) 단계로 푸시다운하여, 선택적인 쿼리가 더 적은 데이터를 읽고 디코딩하도록 합니다. 스캔 내부에서는 조건 중 변환된 부분만 적용됩니다. 일부만 변환 가능한 조건은 일치하는 행을 하나도 빠뜨리지 않는 더 넓은 조건으로 확장되므로 일치하지 않는 행도 읽고 디코딩될 수 있으며, ClickHouse는 이후에 전체 필터(filter)를 다시 적용합니다. 현재 푸시다운은 최상위 정수(integer), floating-point, 문자열/바이너리, `Bool`, `Date`, `Date32`, `DateTime64` 컬럼을 지원합니다. | `1`  |
| `input_format_vortex_preserve_order`    | 파일에 저장된 순서대로 행을 반환합니다. 기본적으로 파일의 행 분할 단위는 병렬로 디코딩되고 준비되는 즉시 반환되므로 행 순서가 보장되지 않습니다. 이 설정을 활성화하면 느린 분할 단위가 처리될 때까지 그 뒤의 분할 단위가 대기합니다.                                                                                                                                                                                                     | `0`  |
| `output_format_vortex_string_as_string` | [String](/ko/reference/data-types/string) 컬럼을 `Binary` 대신 `Utf8`로 씁니다. 유효한 UTF-8이 아닌 값이 있으면 예외를 발생시킵니다. 이러한 데이터를 `Binary`로 쓰려면 이 설정을 비활성화하십시오.                                                                                                                                                                                             | `1`  |
| `max_parsing_threads`                   | Vortex 파일을 디코딩하는 스레드 수입니다(하나의 쿼리가 병렬로 읽는 파일들이 공유합니다). `1`로 설정하면 스레드 풀이 비활성화되며, 이 경우 파일은 쿼리 파이프라인(query pipeline)의 스레드에서 `read` 내부에서 읽힙니다.                                                                                                                                                                                               | 코어 수 |
| `max_download_threads`                  | 파일을 읽는 스레드 수입니다. `0`으로 설정하면 읽기 작업이 디코딩 스레드를 공유합니다.                                                                                                                                                                                                                                                                                      | `4`  |

다른 컬럼형 포맷과 마찬가지로 쿼리에서 사용하는 컬럼만 파일에서 읽으며,
파일에 없는 컬럼은 기본값으로 채워집니다.

## 성능 {#performance}

파일은 병렬로 읽힙니다. 스캔(Scan)은 파일을 행 범위(요청된 컬럼의 청크 경계에 맞춰 정렬되며, 각 범위는 최대 100 000개 행)로
분할하고, 각 범위는 동시에 읽히고 필터링 및 디코딩됩니다.
디코딩은 `Parquet` 리더가 사용하는 것과 동일한 풀에서 최대 `max_parsing_threads`개의 스레드로 실행되고,
읽기는 최대 `max_download_threads`개의 스레드로 실행되며, 디코딩된 청크를
ClickHouse 컬럼으로 변환하는 작업은 해당 청크를 디코딩한 스레드에서 수행됩니다. 청크는 준비되는 즉시
반환되므로 `input_format_vortex_preserve_order`를 설정하지 않으면 행 순서가 보장되지 않습니다. 파일 내에서
서로 가까이 위치한 세그먼트의 읽기는 하나의 요청으로 머지됩니다(로컬
파일은 최대 4 MiB, 원격 스토리지는 최대 16 MiB). 필터(filter) 푸시다운을 사용하면 선택도가 높은 쿼리에서
읽고 디코딩하는 데이터의 양이 줄어듭니다.
