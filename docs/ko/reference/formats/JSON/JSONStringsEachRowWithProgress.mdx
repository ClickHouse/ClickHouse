## 설명 {#description}

`JSONEachRow`/`JSONStringsEachRow`와 달리 ClickHouse는 각 이벤트를 별도의 JSON 객체로 스트리밍하며 진행 상황 정보도 제공합니다.

모든 필드 값은 복합 타입을 포함해 문자열로 직렬화됩니다. 예를 들어 `arr`는 중첩된 JSON 배열이 아니라 `"arr":"[0,1]"`로 출력됩니다. 스칼라 값도 마찬가지로 문자열로 변환됩니다(`"num":"42"`).

최상위 객체의 종류는 [`JSONEachRowWithProgress`](/ko/reference/formats/JSON/JSONEachRowWithProgress)와 동일합니다(`meta`, `row`, `progress`, `totals`/`min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation`, 최상위 `exception`). 전체 스트림 규약은 해당 페이지를 참조하십시오. `progress` 객체는 `meta`보다 먼저 도착할 수 있습니다. 쿼리(query)에 `LIMIT`이 포함되면 `rows_before_limit_at_least`는 하한 추정치이며, 행(row)이 제외되었다는 의미는 아닙니다. `exception`은 `http_write_exception_in_output_format=1`로 설정된 HTTP 경로에서만 기록됩니다.

## 사용 예시 {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
