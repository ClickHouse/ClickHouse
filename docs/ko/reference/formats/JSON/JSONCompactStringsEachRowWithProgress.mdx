## 설명 {#description}

[`JSONCompactEachRowWithProgress`](/ko/reference/formats/JSON/JSONCompactEachRowWithProgress)와 비슷하지만, 모든 값이 문자열로 변환됩니다. 최상위 객체 종류(`meta`, `row`, `progress`, `totals`, `min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation`, 최상위 `exception`)도 동일하게 사용합니다. `row` / `totals` / `min` / `max` payload는 컬럼 순서대로 나열된 **배열** 형태를 그대로 유지하며, 각 원소는 문자열로 직렬화됩니다.

스트림 객체 계약 전체에 대해서는 [`JSONCompactEachRowWithProgress`](/ko/reference/formats/JSON/JSONCompactEachRowWithProgress)를 참고하십시오(`progress`가 `meta`보다 먼저 도착할 수 있습니다. `rows_before_limit_at_least`는 쿼리에 `LIMIT`이 포함된 경우의 하한 추정값일 뿐, 행이 삭제되었다는 증거가 아닙니다. `exception`은 `http_write_exception_in_output_format=1`이 설정된 HTTP 경로에서만 기록됩니다).

## 사용 예시 {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
