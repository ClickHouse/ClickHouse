## 설명 {#description}

각 값을 지정된 컬럼 이름과 함께 별도의 줄에 출력합니다. 이 포맷은 각 행이 많은 수의 컬럼으로 이루어져 있을 때, 한두 개의 행만 출력하는 데 편리합니다.

문자열 값 `NULL`과 값이 없음을 더 쉽게 구분할 수 있도록 [`NULL`](/ko/reference/syntax)은 `ᴺᵁᴸᴸ`로 출력됩니다. JSON 컬럼은 보기 좋게 포맷되어 출력되며, `NULL`은 유효한 JSON 값이고 `"null"`과도 쉽게 구분되므로 `null`로 출력됩니다.

## 사용 예시 {#example-usage}

예시:

```sql
SELECT * FROM t_null FORMAT Vertical
```

```response
Row 1:
──────
x: 1
y: ᴺᵁᴸᴸ
```

기본적으로 값과 컬럼명에 포함된 출력 불가능한 제어 문자(C0 제어 문자 `0x00`–`0x1F` 및 `DEL` `0x7F`)는 해당하는 유니코드 &quot;Control Pictures&quot;(`U+2400`–`U+2421`) 문자로 표시됩니다. 따라서 이러한 문자가 터미널에서 아무런 표시 없이 사라지지 않고 계속 보이게 됩니다. 예를 들어 NUL은 `␀`로 표시됩니다.

```sql
SELECT 'string with a NUL \0 character' AS test FORMAT Vertical
```

```response
Row 1:
──────
test: string with a NUL ␀ character
```

`TAB`, 줄 바꿈, `ESC`는 예외입니다. 이 문자들은 터미널이 무시하지 않고 해석하므로 항상 그대로 출력됩니다. 탭은 다음 탭 위치로 커서를 이동시키고, 줄 바꿈은 줄을 나누며, ANSI 이스케이프 시퀀스는 데이터에 시각화 효과를 담을 수 있게 해 줍니다. 단, 컬럼명은 이 예외에서 다시 제외됩니다. 컬럼명은 한 줄로 렌더링되므로, 이름에 포함된 줄 바꿈은 다른 제어 문자와 마찬가지로 대체됩니다.

제어 문자를 있는 그대로 출력하려면 [`output_format_pretty_display_control_characters`](/ko/reference/settings/formats#output_format_pretty_display_control_characters)를 비활성화하십시오.

```sql
SELECT 'string with a NUL \0 character' AS test
FORMAT Vertical
SETTINGS output_format_pretty_display_control_characters = 0
```

이 경우 응답에는 해당 문자 대신 원시 `NUL` 바이트가 그대로 포함됩니다. 터미널은 이 바이트를 표시하지 않으므로, 값을
보면 마치 해당 문자가 아예 빠진 것처럼 보입니다.

이 포맷은 쿼리 결과를 출력하는 용도로만 적합하며, 파싱(테이블에 삽입할 데이터를 읽어 들이는 작업)에는 적합하지 않습니다.
