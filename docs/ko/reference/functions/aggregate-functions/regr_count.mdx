## regr_count {#regr_count}

도입 버전: v26.9.0

`y`와 `x`가 모두 `NULL`이 아닌 행의 개수를 셉니다.

**구문**

```sql
regr_count(y, x)
```

**별칭**: `regrCount`

**인수**

* `y` — 종속 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)
* `x` — 독립 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)

**반환 값**

NULL이 아닌 값 쌍의 개수를 반환합니다. [`UInt64`](/ko/reference/data-types/int-uint)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_count(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_count(y, x)─┐
│                4 │
└──────────────────┘
```
