<div id="gini">
  ## gini
</div>

도입 버전: v26.8.0

유한한 음이 아닌 숫자 값으로 구성된 컬럼의 [지니 계수](https://en.wikipedia.org/wiki/Gini_coefficient)를 계산합니다. 지니 계수는 분포의 부등 정도를 나타내는 지표입니다.

결과는 `0`(완전한 동등: 모든 값이 같음)부터 `n`이 증가함에 따라 `1`에 가까워지는 최댓값(완전한 부등: 하나의 값이 전체를 차지하고 나머지는 0임) 사이의 값을 가집니다. `n`개 값으로 구성된 유한 표본의 최댓값은 `(n - 1) / n`입니다.

전달된 모든 값은 입력 유형으로 수집한 후, 수치적으로 안정적인 최종 계산 전에 정렬됩니다. 계수는 정규화된 인접 쌍 간 차이로 계산되며 `Float64`로 반환되므로 `Float64` 정밀도로 반올림됩니다. 따라서 이 함수는 전달된 값의 개수가 `n`일 때 `O(n)` 메모리를 사용합니다. `NaN` 값은 건너뛰며, 무한 값과 음수 값은 허용되지 않습니다.

**구문**

```sql
gini(expr)
```

**인수**

* `expr` — 유한한 음이 아닌 숫자 값을 생성하는 표현식입니다. [`(U)Int*`](/ko/reference/data-types/int-uint), [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal`](/ko/reference/data-types/decimal)

**반환 값**

지니 계수입니다. 값이 2개 미만이거나 값의 합이 0이면 `NaN`을 반환합니다. [`Float64`](/ko/reference/data-types/float)

**예시**

**모든 값이 같은 경우**

```sql title=Query
SELECT gini(x) FROM (SELECT 100 AS x FROM numbers(10));
```

```response title=Response
┌─gini(x)─┐
│       0 │
└─────────┘
```

**편향된 분포**

```sql title=Query
SELECT gini(x) FROM (SELECT number AS x FROM numbers(10));
```

```response title=Response
┌─────────────gini(x)─┐
│ 0.36666666666666664 │
└─────────────────────┘
```
