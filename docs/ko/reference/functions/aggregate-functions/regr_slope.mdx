## regr_slope {#regr_slope}

도입 버전: v26.9.0

`x`에 대한 `y`의 최소제곱 적합(least-squares fit) 직선의 기울기를 반환합니다.

$$
\frac{\Sigma{(x - \bar{x})(y - \bar{y})}}{\Sigma{(x - \bar{x})^2}}
$$

`x`가 상수이면 적합된 직선이 수직이 되므로 `nan`을 반환합니다.

**구문**

```sql
regr_slope(y, x)
```

**별칭**: `regrSlope`

**인수**

- `y` — 종속 변수입니다. [`(U)Int*`](/reference/data-types/int-uint) 또는 [`Float*`](/reference/data-types/float)
- `x` — 독립 변수입니다. [`(U)Int*`](/reference/data-types/int-uint) 또는 [`Float*`](/reference/data-types/float)

**반환 값**

회귀선의 기울기를 반환합니다. [`Float64`](/reference/data-types/float)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_slope(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```
