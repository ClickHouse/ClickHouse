## timeSeriesQuantileToGrid {#timeSeriesQuantileToGrid}

도입 버전: v26.9.0

타임스탬프와 값의 쌍으로 이루어진 시계열 데이터를 입력받아, 시작 타임스탬프, 종료 타임스탬프, 간격으로 정의되는 규칙적인 시간 그리드에서 [PromQL `quantile_over_time`](https://prometheus.io/docs/prometheus/latest/querying/functions/#quantile_over_time) 함수를 계산하는 집계 함수입니다. 그리드의 각 지점마다 지정된 시간 윈도우 내의 샘플을 사용하여 분위수를 계산합니다. 분위수는 `quantileExactInclusive`와 마찬가지로 R-7(포함) 방식으로 계산됩니다. 다만 `quantileExactInclusive`는 NaN 샘플을 건너뛰지만, 이 함수는 건너뛰지 않습니다. Prometheus와 마찬가지로 NaN 샘플은 유지되며 모든 실제 값보다 앞에 정렬됩니다. 따라서 `[1, NaN, 2]` 윈도우의 중앙값은 `1`이며, 모든 샘플이 NaN인 윈도우의 결과는 NaN입니다.

분위수 수준은 샘플 다음의 마지막 인수로 지정합니다. 모든 그리드 지점에 공통으로 적용되는 하나의 숫자 또는 그리드 지점마다 하나의 숫자를 갖는 배열로 지정할 수 있습니다. 이 값은 모든 행에서 동일해야 합니다. Prometheus와 마찬가지로 수준이 0보다 작으면 `-Inf`, 1보다 크면 `+Inf`를 반환하며, 수준이 NaN이면 윈도우에 샘플이 있는 모든 그리드 지점에서 NaN을 반환합니다.

<Note>
  이 함수는 비공개 프리뷰 상태입니다. `enable_time_series_aggregate_functions=true`를 설정하여 활성화하십시오.
</Note>

**구문**

```sql
timeSeriesQuantileToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value, phi)
timeSeriesQuantileToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples, phi)
```

**매개변수**

* `start_timestamp` — 그리드의 시작 지점을 지정합니다. 소수를 사용하거나, 숫자 또는 날짜-시간 텍스트가 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)
* `end_timestamp` — 그리드의 끝 지점을 지정합니다. 소수를 사용하거나, 숫자 또는 날짜-시간 텍스트가 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)
* `grid_step` — 그리드 간격을 초 단위로 지정합니다. 소수를 사용하거나, 숫자 또는 &#39;15s&#39;, &#39;1m&#39;과 같은 기간이 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)
* `staleness` — 계산에 포함할 샘플의 최대 &quot;staleness&quot;를 초 단위로 지정합니다. staleness 윈도우는 왼쪽이 열리고 오른쪽이 닫힌 인터벌입니다. 소수를 사용하거나, 숫자 또는 &#39;15s&#39;, &#39;1m&#39;과 같은 기간이 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)

**인수**

* `timestamp` — 샘플의 타임스탬프입니다. 개별 값 또는 배열로 지정할 수 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Array(UInt32)`](/ko/reference/data-types/array) 또는 [`Array(DateTime)`](/ko/reference/data-types/array) 또는 [`Array(DateTime64)`](/ko/reference/data-types/array)
* `value` — 타임스탬프에 대응하는 시계열 값입니다. 개별 값 또는 배열로 지정할 수 있습니다. [`Float*`](/ko/reference/data-types/float) 또는 [`Array(Float*)`](/ko/reference/data-types/array)
* `samples` — `(timestamp, value)` 튜플의 배열로 전달되는 시계열 샘플입니다. 튜플 원소의 타입은 위에 나열된 타임스탬프 및 값의 타입과 같습니다. 타임스탬프와 값을 두 개의 인수로 각각 전달하는 대신 사용할 수 있습니다. [`Array(Tuple(T1, T2))`](/ko/reference/data-types/array)
* `phi` — 분위수 수준으로, 일반적으로 [0, 1] 범위의 값입니다. 전체 그리드에 적용되는 단일 숫자이거나, 그리드 지점마다 숫자 하나씩을 담은 배열입니다. 모든 행에서 동일해야 합니다. [`Float*`](/ko/reference/data-types/float) 또는 [`UInt8/16/32/64`](/ko/reference/data-types/int-uint) 또는 [`Int8/16/32/64`](/ko/reference/data-types/int-uint) 또는 [`Array(Float*)`](/ko/reference/data-types/array) 또는 [`Array(UInt8/16/32/64)`](/ko/reference/data-types/array) 또는 [`Array(Int8/16/32/64)`](/ko/reference/data-types/array)

**반환 값**

지정된 그리드에서 값의 phi-분위수를 반환합니다. 반환되는 배열에는 시간 그리드 지점마다 값이 하나씩 포함됩니다. 특정 그리드 지점의 윈도우 내에 샘플이 없으면 해당 값은 NULL이 됩니다. [`Array(Nullable(Float64))`](/ko/reference/data-types/array)
