## avg {#avg}

도입 버전: v1.1.0

산술 평균을 계산합니다.

**구문**

```sql
avg(x)
```

**인수**

* `x` — 입력값입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal`](/ko/reference/data-types/decimal) 또는 [`Date`](/ko/reference/data-types/date) 또는 [`Date32`](/ko/reference/data-types/date32) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64(P)`](/ko/reference/data-types/datetime64) 또는 [`Time`](/ko/reference/data-types/time) 또는 [`Time64(P)`](/ko/reference/data-types/time64) 또는 [`Interval`](/ko/reference/data-types/special-data-types/interval)

**반환 값**

산술 평균을 반환합니다. `x`가 숫자형이면 결과는 `Float64`이고, `x`가 비어 있으면 `NaN`을 반환합니다. `x`가 날짜, 시간 또는 인터벌이면 결과는 `x`와 같은 타입으로 반환됩니다. 평균은 표현 가능한 가장 가까운 값으로 반올림되며, `x`가 비어 있으면 해당 타입의 0 값을 반환합니다. [`Float64`](/ko/reference/data-types/float) 또는 [`Date`](/ko/reference/data-types/date) 또는 [`Date32`](/ko/reference/data-types/date32) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64(P)`](/ko/reference/data-types/datetime64) 또는 [`Time`](/ko/reference/data-types/time) 또는 [`Time64(P)`](/ko/reference/data-types/time64) 또는 [`Interval`](/ko/reference/data-types/special-data-types/interval)

**예시**

**기본 사용법**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**빈 테이블은 NaN을 반환합니다**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**인터벌의 평균**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
