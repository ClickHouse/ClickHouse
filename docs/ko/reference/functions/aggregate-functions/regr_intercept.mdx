## regr_intercept {#regr_intercept}

도입 버전: v26.9.0

`x`에 대한 `y`의 최소제곱 적합(least-squares fit)에서 절편을 반환합니다.

$$
\bar{y} - slope \cdot \bar{x}
$$

`x`가 상수이면 적합된 선이 수직이 되므로 `nan`을 반환합니다.

**구문**

```sql
regr_intercept(y, x)
```

**별칭**: `regrIntercept`

**인수**

* `y` — 종속 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)
* `x` — 독립 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)

**반환 값**

회귀선의 절편을 반환합니다. [`Float64`](/ko/reference/data-types/float)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_intercept(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_intercept(y, x)─┐
│                    0 │
└──────────────────────┘
```
