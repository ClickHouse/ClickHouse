## regr_r2 {#regr_r2}

도입 버전: v26.9.0

최소제곱 적합(least-squares fit)의 결정 계수, 즉 상관 계수의 제곱을 반환합니다.
`x`가 상수이면 `nan`을, `y`가 상수이면 `1`을 반환합니다.

**구문**

```sql
regr_r2(y, x)
```

**별칭**: `regrR2`

**인수**

* `y` — 종속 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)
* `x` — 독립 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)

**반환 값**

0에서 1 사이의 값을 반환합니다. [`Float64`](/ko/reference/data-types/float)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
