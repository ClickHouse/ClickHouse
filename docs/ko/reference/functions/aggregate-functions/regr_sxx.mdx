## regr_sxx {#regr_sxx}

도입 버전: v26.9.0

독립 변수의 편차 제곱합을 반환합니다.

$$
\Sigma{(x - \bar{x})^2}
$$

**구문**

```sql
regr_sxx(y, x)
```

**별칭**: `regrSXX`

**인수**

- `y` — 종속 변수. [`(U)Int*`](/reference/data-types/int-uint) 또는 [`Float*`](/reference/data-types/float)
- `x` — 독립 변수. [`(U)Int*`](/reference/data-types/int-uint) 또는 [`Float*`](/reference/data-types/float)

**반환 값**

평균을 기준으로 한 `x`의 편차 제곱합을 반환합니다. [`Float64`](/reference/data-types/float)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_sxx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_sxx(y, x)─┐
│              5 │
└────────────────┘
```
