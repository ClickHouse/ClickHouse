## regr_avgy {#regr_avgy}

도입 버전: v26.9.0

종속 변수의 평균을 반환합니다.

0이 아니라 데이터에 포함된 값을 기준으로 계산하므로, 2^53을 넘는 정수 컬럼에서는 `Float64` 합계를 나누는
[`avg`](/ko/reference/functions/aggregate-functions/avg)보다
정확한 평균에 더 가까운 값을 얻을 수 있습니다.

**구문**

```sql
regr_avgy(y, x)
```

**별칭**: `regrAvgY`

**인수**

* `y` — 종속 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)
* `x` — 독립 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)

**반환 값**

`y`의 평균을 반환합니다. [`Float64`](/ko/reference/data-types/float)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_avgy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgy(y, x)─┐
│               5 │
└─────────────────┘
```
