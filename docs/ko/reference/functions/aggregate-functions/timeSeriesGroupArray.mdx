## timeSeriesGroupArray {#timeSeriesGroupArray}

지원 시작 버전: v25.8.0

타임스탬프 기준으로 시계열 데이터를 오름차순으로 정렬합니다.

샘플은 다음 3가지 형식 중 하나로 전달할 수 있습니다.

* 각 행에 단일 샘플이 포함되는 두 인수 `timestamp` 및 `value` 형식
* 각 행에 전체 시계열이 포함되는 타임스탬프 배열과 값 배열 2개 형식
* 각 행에 전체 시계열이 포함되는 `(timestamp, value)` 튜플의 단일 배열 형식. 이 형식은 결과와 동일한 타입이므로 `SimpleAggregateFunction` 데이터 타입에서 이 함수를 사용할 수 있습니다.

여러 샘플의 타임스탬프가 같으면 가장 큰 값을 가진 샘플 하나만 사용됩니다. NaN 값은 다른 모든 값보다 우선순위가 낮으므로, 해당 타임스탬프의 모든 샘플이 NaN인 경우에만 NaN 값이 사용됩니다.

<Note>
  이 함수는 실험적 기능이므로 `allow_experimental_time_series_aggregate_functions=true`를 설정하여 활성화하십시오.
</Note>

**구문**

```sql
timeSeriesGroupArray(timestamp, value)
timeSeriesGroupArray(samples)
```

**인수**

* `timestamp` — 샘플의 타임스탬프입니다. 개별 값 또는 배열일 수 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Array(UInt32)`](/ko/reference/data-types/array) 또는 [`Array(DateTime)`](/ko/reference/data-types/array) 또는 [`Array(DateTime64)`](/ko/reference/data-types/array)
* `value` — 해당 타임스탬프에 대응하는 시계열 값입니다. 개별 값 또는 배열일 수 있습니다. [`Float*`](/ko/reference/data-types/float) 또는 [`Array(Float*)`](/ko/reference/data-types/array)
* `samples` — 위에 나열된 타임스탬프 및 값 타입의 원소를 갖는 `(timestamp, value)` 튜플 배열로 전달되는 시계열 샘플입니다. [`Array(Tuple(T1, T2))`](/ko/reference/data-types/array)

**반환 값**

타임스탬프 기준 오름차순으로 정렬된 튜플 배열 `(timestamp, value)`을 반환합니다. [`Array(Tuple(T1, T2))`](/ko/reference/data-types/array)

**예시**

**개별 값을 사용한 기본 사용법**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 140, 100]::Array(UInt32) AS timestamps,
    [1, 6, 8, 17, 19, 5]::Array(Float32) AS values
SELECT timeSeriesGroupArray(timestamp, value)
FROM
(
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesGroupArray(timestamp, value)─────┐
│ [(100,5),(110,1),(120,6),(130,8),(140,19)] │
└────────────────────────────────────────────┘
```

**동일한 크기의 배열로 여러 개의 타임스탬프와 값을 전달하기**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 140, 100]::Array(UInt32) AS timestamps,
    [1, 6, 8, 17, 19, 5]::Array(Float32) AS values
SELECT timeSeriesGroupArray(timestamps, values);
```

```response title=Response
┌─timeSeriesGroupArray(timestamps, values)───┐
│ [(100,5),(110,1),(120,6),(130,8),(140,19)] │
└────────────────────────────────────────────┘
```
