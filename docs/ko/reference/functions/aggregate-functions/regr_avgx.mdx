## regr_avgx {#regr_avgx}

도입 버전: v26.9.0

독립 변수의 평균을 반환합니다.

0이 아니라 데이터에 포함된 값 하나를 기준으로 계산하므로, 2^53을 초과하는 정수 컬럼에서는 `Float64` 합계를 나누어 계산하는
[`avg`](/ko/reference/functions/aggregate-functions/avg)보다 정확한 평균에 더 가까운 결과를 얻을 수 있습니다.

**구문**

```sql
regr_avgx(y, x)
```

**별칭**: `regrAvgX`

**인수**

* `y` — 종속 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)
* `x` — 독립 변수입니다. [`(U)Int*`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float)

**반환 값**

`x`의 평균을 반환합니다. [`Float64`](/ko/reference/data-types/float)

**예시**

**기본 사용법**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
