## timeSeriesTimestampOfLastToGrid {#timeSeriesTimestampOfLastToGrid}

도입 버전: v26.10.0

타임스탬프와 값의 쌍으로 이루어진 시계열 데이터를 입력으로 받아, 시작 타임스탬프, 종료 타임스탬프, 간격으로 정의되는 규칙적인 시간 그리드에서 [PromQL 방식의 ts&#95;of&#95;last&#95;over&#95;time](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time)을 계산하는 집계 함수입니다. 그리드의 각 지점마다 지정된 시간 윈도우 내에서 가장 최근 샘플의 타임스탬프를 결과로 반환합니다.

샘플은 다음 세 가지 형식 중 하나로 전달할 수 있습니다:

* `timestamp`와 `value` 두 개의 인수로 전달하는 방식: 각 행에 하나의 샘플이 담깁니다.
* 타임스탬프 배열과 값 배열, 두 개의 배열로 전달하는 방식: 각 행에 하나의 시계열 전체가 담깁니다.
* `(timestamp, value)` 튜플로 이루어진 하나의 배열로 전달하는 방식: 각 행에 하나의 시계열 전체가 담깁니다.

여러 샘플의 타임스탬프가 동일하면 그중 값이 가장 큰 샘플 하나만 사용됩니다. NaN 값은 다른 어떤 값보다도 우선순위가 낮으므로, 해당 타임스탬프의 모든 샘플이 NaN인 경우에만 NaN 값이 사용됩니다.

<Warning>
  이 함수는 비공개 프리뷰 단계이며, `enable_time_series_aggregate_functions=true`로 설정하여 활성화할 수 있습니다.
</Warning>

**구문**

```sql
timeSeriesTimestampOfLastToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(timestamp, value)
timeSeriesTimestampOfLastToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(samples)
```

**매개변수**

* `start_timestamp` — 그리드의 시작 시점을 지정합니다. 소수를 사용하거나, 숫자 또는 날짜-시간 텍스트가 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)
* `end_timestamp` — 그리드의 종료 시점을 지정합니다. 소수를 사용하거나, 숫자 또는 날짜-시간 텍스트가 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)
* `grid_step` — 그리드의 간격을 초 단위로 지정합니다. 소수를 사용하거나, 숫자 또는 &#39;15s&#39;, &#39;1m&#39;과 같은 기간이 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)
* `staleness_window` — 가장 최근 샘플의 최대 staleness를 초 단위로 지정합니다. 소수를 사용하거나, 숫자 또는 &#39;15s&#39;, &#39;1m&#39;과 같은 기간이 담긴 문자열을 사용할 수도 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`Float*`](/ko/reference/data-types/float) 또는 [`Decimal*`](/ko/reference/data-types/decimal) 또는 [`String`](/ko/reference/data-types/string)

**인수**

* `timestamp` — 샘플의 타임스탬프입니다. 개별 값 또는 배열을 사용할 수 있습니다. [`UInt32`](/ko/reference/data-types/int-uint) 또는 [`DateTime`](/ko/reference/data-types/datetime) 또는 [`DateTime64`](/ko/reference/data-types/datetime64) 또는 [`Array(UInt32)`](/ko/reference/data-types/array) 또는 [`Array(DateTime)`](/ko/reference/data-types/array) 또는 [`Array(DateTime64)`](/ko/reference/data-types/array)
* `value` — 타임스탬프에 대응하는 시계열 값입니다. 개별 값 또는 배열을 사용할 수 있습니다. [`Float*`](/ko/reference/data-types/float) 또는 [`Array(Float*)`](/ko/reference/data-types/array)
* `samples` — `(timestamp, value)` 튜플의 배열로 전달되는 시계열 샘플입니다. 각 튜플 원소의 타입은 위에 나열된 타임스탬프 및 값 타입과 같습니다. 타임스탬프와 값을 별도의 두 인수로 전달하는 대신 사용할 수 있습니다. [`Array(Tuple(T1, T2))`](/ko/reference/data-types/array)

**반환 값**

지정된 그리드에서 가장 최근 샘플의 타임스탬프를 `timestamp`와 동일한 타입으로 반환합니다. 반환되는 배열에는 시간 그리드의 각 지점마다 하나의 값이 포함됩니다. 특정 그리드 지점의 윈도우 내에 샘플이 없으면 해당 값은 NULL입니다. [`Array(Nullable(UInt32))`](/ko/reference/data-types/array) or [`Array(Nullable(DateTime))`](/ko/reference/data-types/array) or [`Array(Nullable(DateTime64))`](/ko/reference/data-types/array)

**예시**

**그리드(grid) [90, 105, 120, 135, 150, 165, 180, 195, 210]에서 ts&#95;of&#95;last&#95;over&#95;time 값 계산하기**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to staleness window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    30 AS window_seconds  -- "staleness" window
SELECT timeSeriesTimestampOfLastToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

