`timeSeriesTimeRanges(db_name.time_series_table)` - [TimeSeries](/ko/reference/engines/table-engines/integrations/time-series) 테이블 엔진을 사용하는 테이블 `db_name.time_series_table`의
[시간 범위](/ko/reference/engines/table-engines/integrations/time-series#time-ranges-table) 테이블을 반환합니다. 예를 들면 다음과 같습니다:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

다음 쿼리는 서로 동등합니다:

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  *시간 범위(time ranges)* 테이블은 `store_time_ranges` 설정이 활성화된 경우에만 존재합니다.
  [버전](/ko/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 이하의 테이블에서는 `min_time` 및 `max_time` 컬럼이
  [태그](/ko/reference/engines/table-engines/integrations/time-series#tags-table) 테이블에 저장됩니다.
</Note>
