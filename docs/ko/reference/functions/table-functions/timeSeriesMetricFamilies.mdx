`timeSeriesMetricFamilies(db_name.time_series_table)` - 테이블 엔진이 [TimeSeries](/ko/reference/engines/table-engines/integrations/time-series) 엔진인 테이블 `db_name.time_series_table`이 사용하는 [metric families](/ko/reference/engines/table-engines/integrations/time-series#metric-families-table) 테이블을 반환합니다:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES metric_families_table
```

이 함수는 *metric families* 테이블이 내부 테이블인 경우에도 동작합니다:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

다음 쿼리들은 서로 동일합니다:

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  `timeSeriesMetricFamilies` 함수에는 하위 호환성을 위해 유지되는 `timeSeriesMetrics` 별칭이 있습니다.
</Note>
