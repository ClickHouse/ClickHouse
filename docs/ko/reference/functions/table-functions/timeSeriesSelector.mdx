셀렉터로 필터링되고 타임스탬프가 지정된 인터벌 내에 있는 TimeSeries 테이블에서 시계열을 읽어옵니다.
이 함수는 [range selectors](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors)와 유사하지만, [instant selectors](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors)를 구현하는 데에도 사용됩니다.

## 구문 {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## 인수 {#arguments}

* `db_name` - TimeSeries 테이블이 있는 데이터베이스 이름입니다.
* `time_series_table` - TimeSeries 테이블 이름입니다.
* `instant_query` - `@` 또는 `offset` 수정자 없이 [PromQL 구문](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors)으로 작성된 instant 셀렉터입니다.
* `min_time` - 시작 타임스탬프이며, 해당 값도 포함됩니다.
* `max_time` - 종료 타임스탬프이며, 해당 값도 포함됩니다.
* `return_columns` - 샘플을 반환할 컬럼으로, `'samples'` 또는 `'timestamp_and_value'` 중 하나입니다. 자세한 내용은 아래를 참조하십시오.

테이블의 타임스탬프가 정수 초 단위이더라도 `min_time`과 `max_time`에는 소수 초를 지정할 수 있습니다.
이 함수는 경계를 타임스탬프 유형에 맞춰 반올림하지 않고, `min_time <= timestamp <= max_time` 조건을 정확히 만족하는 샘플을 선택합니다.

## 반환 값 {#returned-value}

이 함수는 지정된 셀렉터와 일치하는 시계열의 식별자(identifiers)를 담은 `id` 컬럼과 함께, `return_columns` 인수로 선택한 컬럼에 샘플을
담아 반환합니다.

* `'samples'` - 시계열의 샘플을 타임스탬프 기준으로 정렬된 `(timestamp, value)` 튜플 배열(Array of Tuples)로 담은 `samples` 컬럼입니다.
  하나의 시계열에 속한 샘플은 여러 행(rows)에 나뉘어 반환될 수 있습니다. 예를 들어 샘플 테이블(Samples Table)의 시간 버킷(time bucket)마다 1개의 행으로 반환될 수 있습니다.
  하나의 시계열에 속한 행을 머지하려면 집계 함수 `timeSeriesGroupArray`를 사용하십시오.
* `'timestamp_and_value'` - 행마다 샘플 1개를 담은 `timestamp` 컬럼과 `value` 컬럼입니다.

버전 11 이상의 `TimeSeries` 테이블은 샘플 버킷을 배열로 저장하며, 이전 버전의 테이블은 행마다 샘플 1개를 저장합니다.
요청한 컬럼이 테이블의 레이아웃(layout)과 다르면 샘플을 변환해야 하므로 시간이 다소 소요됩니다. PromQL 함수는
테이블의 레이아웃(layout)과 일치하는 컬럼을 요청합니다.

반환되는 데이터의 순서는 보장되지 않습니다.

## 예시 {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
