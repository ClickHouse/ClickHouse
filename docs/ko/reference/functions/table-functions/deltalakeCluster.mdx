이것은 [deltaLake](/ko/reference/functions/table-functions/deltalake) 테이블 함수의 확장입니다.

지정된 클러스터의 여러 노드에서 Amazon S3의 [Delta Lake](https://github.com/delta-io/delta) 테이블 파일을 병렬로 처리할 수 있습니다. initiator 노드는 클러스터의 모든 노드에 연결을 생성하고 각 파일을 동적으로 분배합니다. worker 노드는 initiator에 다음으로 처리할 작업을 요청해 처리합니다. 이 과정은 모든 작업이 완료될 때까지 반복됩니다.

## 구문 {#syntax}

```sql
deltaLakeCluster(cluster_name, url [,aws_access_key_id, aws_secret_access_key] [,format] [,structure] [,compression] [,extra_credentials])
deltaLakeCluster(cluster_name, named_collection[, option=value [,..]])

deltaLakeS3Cluster(cluster_name, url [,aws_access_key_id, aws_secret_access_key] [,format] [,structure] [,compression] [,extra_credentials])
deltaLakeS3Cluster(cluster_name, named_collection[, option=value [,..]])

deltaLakeAzureCluster(cluster_name, connection_string|storage_account_url, container_name, blobpath, [,account_name], [,account_key] [,format] [,compression_method])
deltaLakeAzureCluster(cluster_name, storage_account_url, container_name, blobpath, extra_credentials(client_id=, tenant_id=) [,format] [,compression_method])
deltaLakeAzureCluster(cluster_name, named_collection[, option=value [,..]])
```

`deltaLakeS3Cluster`는 `deltaLakeCluster`의 별칭이며, 둘 다 S3에 사용됩니다.

## 인수 {#arguments}

* `cluster_name` — 원격 및 로컬 서버의 주소 집합과 연결 매개변수를 구성하는 데 사용되는 클러스터 이름입니다.
* 나머지 모든 인수에 대한 설명은 해당 [deltaLake](/ko/reference/functions/table-functions/deltalake) 테이블 함수의 인수 설명과 동일합니다.
* 선택 사항인 `extra_credentials` 매개변수를 사용해 ClickHouse Cloud에서 역할 기반 접근을 위한 `role_arn`을 전달할 수 있습니다. 구성 단계는 [Secure S3](/ko/products/cloud/guides/data-sources/accessing-s3-data-securely)를 참조하십시오.
* Azure(`deltaLakeAzureCluster`)에서는 `extra_credentials`가 워크로드 아이덴티티(workload identity)용 `client_id`와 `tenant_id`를 받으며, `account_name` / `account_key`와 함께 사용할 수 없습니다. 또한 프로세스에 `AZURE_FEDERATED_TOKEN_FILE`이 설정되어 있어야 합니다(명시적으로 전달하지 않는 경우 `AZURE_TENANT_ID` / `AZURE_CLIENT_ID`도 설정해야 하며, `AZURE_AUTHORITY_HOST`는 선택 사항입니다). 워크로드 아이덴티티는 서버 자체의 아이덴티티를 사용하므로 기본적으로 거부됩니다. 쿼리를 실행하는 세션 또는 해당 세션의 설정 프로파일(Settings Profile)에서 `allow_server_credentials_in_user_queries`를 활성화하십시오.

## 반환 값 {#returned-value}

S3에 있는 지정된 Delta Lake 테이블의 클러스터에서 데이터를 읽기 위한, 지정된 구조의 테이블입니다.

## 가상 컬럼(Virtual Columns) {#virtual-columns}

* `_path` — 파일 경로입니다. 유형: `LowCardinality(String)`.
* `_file` — 파일 이름입니다. 유형: `LowCardinality(String)`.
* `_size` — 파일 크기(바이트)입니다. 유형: `Nullable(UInt64)`. 파일 크기를 알 수 없으면 값은 `NULL`입니다.
* `_time` — 파일의 마지막 수정 시각입니다. 유형: `Nullable(DateTime)`. 시각을 알 수 없으면 값은 `NULL`입니다.
* `_etag` — 파일의 etag입니다. 유형: `LowCardinality(String)`. etag를 알 수 없으면 값은 `NULL`입니다.
