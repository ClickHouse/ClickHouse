지정된 클러스터의 여러 노드를 사용해 [Azure Blob Storage](https://azure.microsoft.com/en-us/products/storage/blobs)의 파일을 병렬로 처리할 수 있습니다. initiator 노드에서는 클러스터의 모든 노드에 대한 연결을 생성하고, S3 파일 경로의 별표(*)를 확장한 뒤 각 파일을 동적으로 분배합니다. worker 노드에서는 처리할 다음 작업을 initiator에 요청해 처리합니다. 이 과정은 모든 작업이 완료될 때까지 반복됩니다.
이 테이블 함수는 [s3Cluster function](/ko/reference/functions/table-functions/s3Cluster)과 유사합니다.

## 구문 {#syntax}

<Tabs>
  <Tab title="연결 문자열">
    자격 증명이 연결 문자열(Connection String)에 포함되어 있으므로 `account_name`/`account_key`를 별도로 지정할 필요가 없습니다.

    ```sql
    azureBlobStorageCluster(cluster_name, connection_string, container_name, blobpath [, format, compression, structure])
    ```
  </Tab>

  <Tab title="스토리지 계정 URL">
    `account_name`과 `account_key`를 별도의 인수로 지정해야 합니다.

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, account_name, account_key [, format, compression, structure])
    ```
  </Tab>

  <Tab title="Workload Identity">
    `extra_credentials`를 통해 Azure Workload Identity를 사용합니다. `account_name` / `account_key`와 함께 사용할 수 없으며, `connection_string`이 아닌 `storage_account_url`을 지정해야 합니다.

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, extra_credentials(client_id=, tenant_id=) [, format, compression, structure])
    ```

    Workload Identity는 서버 자체의 아이덴티티를 사용하므로 기본적으로 허용되지 않습니다. 쿼리를 실행하는 세션 또는 해당 세션의 설정 프로파일(Settings Profile)에서 `allow_server_credentials_in_user_queries`를 활성화하십시오.
  </Tab>
</Tabs>

## 인수 {#arguments}

| 인수                    | 설명                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cluster_name`        | 원격 및 로컬 서버의 주소 집합과 연결 매개변수를 구성하는 데 사용되는 클러스터의 이름입니다.                                                                                                                                                                                                                                                                                                                                                                                                 |
| `connection_string`   | 내장된 인증 정보(계정 이름 + 계정 키 또는 SAS 토큰)가 포함된 연결 문자열(Connection String)입니다. 이 형식을 사용하는 경우 `account_name`과 `account_key`를 별도로 전달하면 **안 되며**, `client_id` / `tenant_id`도 사용할 수 없습니다. [연결 문자열(Connection String) 구성](https://learn.microsoft.com/en-us/azure/storage/common/storage-configure-connection-string?toc=%2Fazure%2Fstorage%2Fblobs%2Ftoc.json\&bc=%2Fazure%2Fstorage%2Fblobs%2Fbreadcrumb%2Ftoc.json#configure-a-connection-string-for-an-azure-storage-account)을 참조하십시오. |
| `storage_account_url` | 스토리지 계정 엔드포인트 URL입니다(예: `https://<account>.blob.core.windows.net/`). 이 형식을 사용하는 경우 `account_name`과 `account_key`를 전달하거나, Workload Identity를 사용하려면 `extra_credentials(client_id=, tenant_id=)`를 전달하십시오.                                                                                                                                                                                                                                                   |
| `container_name`      | Container 이름                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `blobpath`            | 파일 경로입니다. readonly 모드에서는 다음 wildcards를 지원합니다: `*`, `**`, `?`, `{abc,def}` 및 `{N..M}`. 여기서 `N`, `M`은 숫자이고 `'abc'`, `'def'`는 문자열입니다.                                                                                                                                                                                                                                                                                                                       |
| `account_name`        | 스토리지 계정 이름입니다. SAS 또는 Workload Identity 없이 `storage_account_url`을 사용하는 경우 **필수**이며, `connection_string` 또는 `extra_credentials`와 함께 전달하면 **안 됩니다**.                                                                                                                                                                                                                                                                                                       |
| `account_key`         | 스토리지 계정 키입니다. SAS 또는 Workload Identity 없이 `storage_account_url`을 사용하는 경우 **필수**이며, `connection_string` 또는 `extra_credentials`와 함께 전달하면 **안 됩니다**.                                                                                                                                                                                                                                                                                                        |
| `format`              | 파일의 [포맷](/ko/reference/formats/index)입니다.                                                                                                                                                                                                                                                                                                                                                                                                                |
| `compression`         | 지원되는 값: `none`, `gzip/gz`, `deflate`, `brotli/br`, `xz/LZMA`, `zstd/zst`, `lz4`, `bz2`, `snappy`. 기본적으로 파일 확장자를 기준으로 압축을 자동 감지합니다. (`auto`로 설정한 것과 같습니다.) `snappy`의 경우 wire 형식은 [snappy&#95;mode](/ko/reference/settings/session-settings/other#snappy_mode) 설정으로 선택됩니다(기본값은 `basic`).                                                                                                                                                                   |
| `structure`           | 테이블 구조입니다. 포맷은 `'column1_name column1_type, column2_name column2_type, ...'`입니다.                                                                                                                                                                                                                                                                                                                                                                         |
| `extra_credentials`   | Azure Workload Identity 인증에 사용할 `client_id`와 `tenant_id`를 지정합니다. `account_name` / `account_key`와 함께 사용할 수 없으며, `connection_string`이 아닌 `storage_account_url`과 함께 사용해야 합니다. 클러스터의 모든 노드에 `AZURE_FEDERATED_TOKEN_FILE`이 설정되어 있어야 합니다.                                                                                                                                                                                                                      |

## 반환 값 {#returned-value}

지정된 파일의 데이터를 읽거나 쓰기 위한 지정된 구조의 테이블입니다.

## 예시 {#examples}

[AzureBlobStorage](/ko/reference/engines/table-engines/integrations/azureBlobStorage) 테이블 엔진과 마찬가지로, 로컬에서 Azure Storage를 개발할 때 Azurite 에뮬레이터를 사용할 수 있습니다. 자세한 내용은 [여기](https://learn.microsoft.com/en-us/azure/storage/common/storage-use-azurite?tabs=docker-hub%2Cblob-storage)에서 확인하십시오. 아래에서는 Azurite가 호스트명 `azurite1`에서 사용 가능하다고 가정합니다.

`cluster_simple` 클러스터의 모든 노드를 사용하여 파일 `test_cluster_*.csv`의 개수를 조회합니다:

```sql
SELECT count(*) FROM azureBlobStorageCluster(
        'cluster_simple', 'http://azurite1:10000/devstoreaccount1', 'testcontainer', 'test_cluster_count.csv', 'devstoreaccount1',
        'Eby8vdM02xNOcqFlqUwJPLlmEtlCDXJ1OUzFT50uSRZ6IFsuFq2UVErCz4I6tq/K1SZFPTOtr/KBHBeksoGMGw==', 'CSV',
        'auto', 'key UInt64')
```
