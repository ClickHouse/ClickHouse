[#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva)).
* [#88302](https://github.com/ClickHouse/ClickHouse/issues/88302)로 백포트: 복사 및 컨테이너 생성 기능에서 발생하는 &#39;Content-Length&#39; 관련 수정 사항을 포함하도록 Azure SDK를 업데이트합니다. [#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#88783](https://github.com/ClickHouse/ClickHouse/issues/88783)로 백포트: `GLOBAL IN`으로 인해 발생하는 메모리 누수를 수정합니다 ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)). [#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94)).
* [#88766](https://github.com/ClickHouse/ClickHouse/issues/88766)로 백포트: 부팅 시 자동으로 시작되도록 `clickhouse-keeper`의 `postinstall` 스크립트에 단계를 추가합니다. [#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan)).
