  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)

* [#108450](https://github.com/ClickHouse/ClickHouse/issues/108450)에 백포트됨: `JOIN ON` 내부에서 사용된 `arrayJoin()`이 잘못된 행 수를 반환하던 문제를 수정했습니다. 결과에 배열 길이가 한 번 더 곱해지고 있었습니다. [#104785](https://github.com/ClickHouse/ClickHouse/pull/104785) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#108263](https://github.com/ClickHouse/ClickHouse/issues/108263)에 백포트됨: 빈 병합된 파트의 텍스트 인덱스에서 발생하던 &quot;Too many marks&quot; 문제를 수정했습니다. [#106867](https://github.com/ClickHouse/ClickHouse/pull/106867) ([Azat Khuzhin](https://github.com/azat)).
* [#107911](https://github.com/ClickHouse/ClickHouse/issues/107911)에 백포트됨: 전역 순서와 로컬 저장 순서가 다른 `Map` variant를 포함한 `Variant` 컬럼이 들어 있는 정렬된 block을 머지하는 과정에서 발생하던 크래시(`Source column is not Map` / `SIGSEGV`)를 수정했습니다. [#107011](https://github.com/ClickHouse/ClickHouse/pull/107011) ([Groene AI](https://github.com/groeneai)).
* [#108168](https://github.com/ClickHouse/ClickHouse/issues/108168)에 백포트됨: MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg 및 Paimon 포맷에서 매우 깊게 중첩된 스키마 또는 값을 읽을 때 발생할 수 있던 서버 스택 오버플로우(크래시)를 수정했습니다. 이제 이렇게 깊게 중첩된 입력은 예외와 함께 거부됩니다. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* [#108226](https://github.com/ClickHouse/ClickHouse/issues/108226)에 백포트됨: 범위를 벗어난 이벤트 유형이 포함된 조작된 집계 함수 상태를 finalize할 때 `windowFunnel`에서 발생하던 힙 버퍼 오버플로(server crash)를 수정했습니다. 이 문제는 임의의 사용자가 단일 `SELECT`만으로 유발할 수 있었습니다. [#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* [#108503](https://github.com/ClickHouse/ClickHouse/issues/108503)에 백포트됨: `update()` 내부에서 다시 빌드된 새 snapshot은 이미 `createBuilder`를 통해 C++ S3 클라이언트의 현재 자격 증명을 반영하므로, 버전이 일치할 경우 이를 버리지 않고 유지하도록 했습니다. 이에 따라 다음 커널 작업은 새 자격 증명이 반영된 engine에서 실행되며 STS TTL을 넘기지 않습니다. [#107480](https://github.com/ClickHouse/ClickHouse/pull/107480) ([Elmi Ahmadov](https://github.com/ahmadov)).
* [#108239](https://github.com/ClickHouse/ClickHouse/issues/108239)에 백포트됨: Elf 및 DWARF 파싱에 누락된 경계 검사를 추가했습니다. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108162](https://github.com/ClickHouse/ClickHouse/issues/108162)에 백포트됨: Apache Arrow Java &lt; 19.0.0(Apache Spark 포함)에서 생성된 빈 `String`/`Binary` 컬럼이 포함된 Arrow/ArrowStream 데이터를 읽을 때 더 이상 `INCORRECT_DATA` 예외가 발생하지 않습니다. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
* [#108208](https://github.com/ClickHouse/ClickHouse/issues/108208)에 백포트됨: set 스킵 인덱스가 LowCardinality 컬럼에서 그래뉼을 프루닝하지 못하던 문제를 수정했습니다. [#107868](https://github.com/ClickHouse/ClickHouse/pull/107868) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108308](https://github.com/ClickHouse/ClickHouse/issues/108308)에 백포트됨: lookup 인수가 `LowCardinality`일 때 `Dynamic` 키를 가진 `Map`에 대한 `has`에서 발생하던 크래시(release build에서는 SIGSEGV, debug build에서는 type-mismatch assertion)를 수정했습니다. 예: `has(map('a'::Dynamic, ...), toLowCardinality('b'))`. [#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* [#108398](https://github.com/ClickHouse/ClickHouse/issues/108398)에 백포트됨: PREWHERE가 있는 Map 서브컬럼의 성능 회귀를 수정했습니다. [#107912](https://github.com/ClickHouse/ClickHouse/issues/107912)를 해결합니다. 원인: [https://github.com/ClickHouse/ClickHouse/pull/99200](https://github.com/ClickHouse/ClickHouse/pull/99200). [#107988](https://github.com/ClickHouse/ClickHouse/pull/107988) ([Pavel Kruglov](https://github.com/Avogar)).
* [#108136](https://github.com/ClickHouse/ClickHouse/issues/108136)에 백포트됨: 여러 스레드로 `Dynamic` 컬럼을 읽을 때 발생하는 성능 회귀를 수정했습니다. 원인: [https://github.com/ClickHouse/ClickHouse/pull/100730](https://github.com/ClickHouse/ClickHouse/pull/100730). [#107942](https://github.com/ClickHouse/ClickHouse/issues/107942)를 해결합니다. [#107997](https://github.com/ClickHouse/ClickHouse/pull/107997) ([Pavel Kruglov](https://github.com/Avogar)).
* [#108200](https://github.com/ClickHouse/ClickHouse/issues/108200)에 백포트됨: 빈 배치에서도 액세스 캐시의 batch-finished 핸들러를 항상 실행하도록 수정했습니다. [#108124](https://github.com/ClickHouse/ClickHouse/pull/108124) ([Azat Khuzhin](https://github.com/azat)).
* [#108322](https://github.com/ClickHouse/ClickHouse/issues/108322)에 백포트됨: 잘못된 시점에 ZooKeeper 연결이 끊기면 갱신 가능 구체화 뷰가 멈추는 문제를 수정했습니다. [#108234](https://github.com/ClickHouse/ClickHouse/pull/108234) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108485](https://github.com/ClickHouse/ClickHouse/issues/108485)에 백포트됨: `format_display_secrets_in_show_and_select`가 비활성화되어 있을 때(기본값) `EXPLAIN actions`, `EXPLAIN header`, `EXPLAIN PIPELINE` 출력에서 `encrypt`, `decrypt`, `HMAC` 등의 함수에 대한 시크릿 인수를 숨기도록 수정했습니다. [#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
* [#108780](https://github.com/ClickHouse/ClickHouse/issues/108780)에 백포트됨: 단일 `*` 와일드카드가 정확히 하나의 이름 구성 요소에만 일치하도록 `ssl_certificate` 사용자 식별을 수정했습니다(RFC 6125 6.4.3). 이전에는 `CN` 또는 `DNS:` SAN subject의 와일드카드(예: `*.corp.example.com`)가 `evil.deep.corp.example.com` 같은 다중 레이블 이름에도 일치하여, 더 깊은 하위 도메인용 certificate 보유자가 와일드카드 사용자로 인증할 수 있었습니다. `URI:` SAN 일치는 변경되지 않았습니다. [#108472](https://github.com/ClickHouse/ClickHouse/pull/108472) ([Groene AI](https://github.com/groeneai)).
* [#108697](https://github.com/ClickHouse/ClickHouse/issues/108697)에 백포트됨: `DESCRIBE loop('db', 'table')` 및 `DESCRIBE loop(<inner table function>)`가 `SHOW COLUMNS` / source 액세스 검사를 우회하여, 권한이 없는 사용자가 테이블의 컬럼 schema를 읽을 수 있었던 metadata 노출 문제를 수정했습니다. [#108624](https://github.com/ClickHouse/ClickHouse/pull/108624) ([Groene AI](https://github.com/groeneai)).
