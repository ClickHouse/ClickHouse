[#81233](https://github.com/ClickHouse/ClickHouse/pull/81233) ([Jayme Bird](https://github.com/jaymebrd)).
* [#81411](https://github.com/ClickHouse/ClickHouse/issues/81411)에 백포트됨: 저널링 파일 시스템에서는 `mkdir`가 디스크에 영구 저장되는 파일 시스템 저널에 기록됩니다. 디스크가 느리면 이 작업에 시간이 오래 걸릴 수 있습니다. 따라서 이를 reserve lock 범위 밖으로 이동하는 것이 타당합니다. [#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#81488](https://github.com/ClickHouse/ClickHouse/issues/81488)에 백포트됨: `krb5` 1.21.3-final을 사용합니다. [#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81480](https://github.com/ClickHouse/ClickHouse/issues/81480)에 백포트됨: `orc` 2.1.2를 사용합니다. [#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).

* [#81803](https://github.com/ClickHouse/ClickHouse/issues/81803)에 백포트됨: profile event `PageCacheReadBytes`를 추가했습니다. [#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#81932](https://github.com/ClickHouse/ClickHouse/issues/81932)에 백포트됨: 파일 시스템 캐시에서 발생하는 logical error &quot;Having zero bytes but range is not finished&quot;를 수정하려고 시도합니다. [#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)).
