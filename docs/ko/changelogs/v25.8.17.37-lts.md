* [#95814](https://github.com/ClickHouse/ClickHouse/issues/95814)에 백포트됨: 여러 조인에서 `USING` 절을 사용할 때 원본 테이블의 한정된 컬럼에 대한 타입 추론을 수정했습니다. 이전에는 후속 조인이 해당 조인에 포함되지 않은 컬럼에 대해서도 기반 원본 컬럼의 타입을 common supertype으로 잘못 갱신했습니다(예: `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)`에서 `t2.a` 컬럼은 첫 번째 조인에만 사용되므로, 해당 타입은 `t3.a`를 제외한 `t1.a`와 `t2.a`의 supertype이어야 합니다). 이 문제로 인해 함수가 execution plan에 실제로 나타나는 컬럼 타입과 다른 타입을 기대할 경우 logical error 또는 크래시가 발생할 수 있었습니다. [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
