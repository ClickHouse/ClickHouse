<div id="improvement">
  #### 개선 사항
</div>

* [#78853](https://github.com/ClickHouse/ClickHouse/issues/78853)에 백포트됨: StorageS3(Azure)Queue에서 materialized view로 푸시할 때 발생하는 오류에 `loading_retries` 제한이 적용됩니다. 이전에는 이러한 오류가 무기한 재시도되었습니다. [#78313](https://github.com/ClickHouse/ClickHouse/pull/78313) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#82411](https://github.com/ClickHouse/ClickHouse/issues/82411)에 백포트됨: 이제 해시 함수가 배열, 튜플, 맵 내부의 NULL도 지원합니다. (이슈 [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) 및 [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)). [#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* [#81612](https://github.com/ClickHouse/ClickHouse/issues/81612)에 백포트됨: `orc` 2.1.2를 사용합니다. [#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81697](https://github.com/ClickHouse/ClickHouse/issues/81697)에 백포트됨: `grpc` 1.73.0을 사용합니다. [#81629](https://github.com/ClickHouse/ClickHouse/pull/81629) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#82592](https://github.com/ClickHouse/ClickHouse/issues/82592)에 백포트됨: Keeper 개선 사항: 새 config `keeper_server.cleanup_old_and_ignore_new_acl`을 추가합니다. 활성화하면 모든 노드의 ACL이 제거되고, 새 요청의 ACL은 무시됩니다. 노드에서 ACL을 완전히 제거하는 것이 목적이라면 새 snapshot이 생성될 때까지 이 config를 활성화된 상태로 유지하는 것이 중요합니다. [#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* [#82922](https://github.com/ClickHouse/ClickHouse/issues/82922)에 백포트됨: Keeper 개선 사항: world:anyone ACL에 대한 특정 권한을 지원합니다. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#82328](https://github.com/ClickHouse/ClickHouse/issues/82328)에 백포트됨: 왼쪽 인수에 null이 있고 서브쿼리 결과가 널 허용되지 않을 때 `transform_null_in=1`을 사용하는 `IN` 실행 문제를 수정했습니다. [#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* [#82775](https://github.com/ClickHouse/ClickHouse/issues/82775)에 백포트됨: 쿼리에서 상수 별칭 컬럼만 사용할 때 filter 분석 문제를 수정했습니다. [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448)을 수정합니다. [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* [#82548](https://github.com/ClickHouse/ClickHouse/issues/82548)에 백포트됨: TTL의 GROUP BY와 SET에 동일한 컬럼을 사용할 때 발생하는 LOGICAL&#95;ERROR 및 그에 따른 크래시를 수정했습니다. [#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* [#82314](https://github.com/ClickHouse/ClickHouse/issues/82314)에 백포트됨: `WHERE` 조건에서 `IndexSet`과 함께 `arrayJoin`을 사용하는 쿼리에서 발생하는 `Not found column` 오류를 수정했습니다. [#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#82557](https://github.com/ClickHouse/ClickHouse/issues/82557)에 백포트됨: 서버가 메모리 압박 상태일 때 원격 쿼리에서 발생할 수 있는 교착 상태 문제를 수정했습니다. [#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* [#82519](https://github.com/ClickHouse/ClickHouse/issues/82519)에 백포트됨: 다시 로드할 수 있도록 AWS ECS 토큰에 만료 시간을 추가했습니다. [#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#82575](https://github.com/ClickHouse/ClickHouse/issues/82575)에 백포트됨: logs/query&#95;log에서 명명된 컬렉션 값이 숨겨지지 않던 문제를 수정했습니다. [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405)를 해결합니다. [#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#82566](https://github.com/ClickHouse/ClickHouse/issues/82566)에 백포트됨: `user_id`가 때때로 비어 있을 수 있어 세션 종료 중 로깅에서 발생할 수 있는 크래시를 수정했습니다. [#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
* [#82731](https://github.com/ClickHouse/ClickHouse/issues/82731)에 백포트됨: 이제 함수 `trim{Left,Right,Both}`가 &quot;FixedString(N)&quot; 유형의 입력 문자열을 지원합니다. 예를 들어 `SELECT trimBoth(toFixedString('abc', 3), 'ac')`가 이제 동작합니다. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
