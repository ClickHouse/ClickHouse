* [#97329](https://github.com/ClickHouse/ClickHouse/issues/97329)에서 백포트됨: SQL Security가 적용된 뷰에 대한 `ATTACH` 쿼리에서 불필요한 권한 검사 생략을 제거했습니다. 이로써 필요한 접근 권한을 검증하지 않은 채 사용자가 definer가 있는 뷰를 attach할 때 발생할 수 있는 잠재적인 권한 상승을 방지합니다. [#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)).
* [#95816](https://github.com/ClickHouse/ClickHouse/issues/95816)에서 백포트됨: 여러 조인에서 `USING` 절을 사용할 때 원본 테이블의 한정된 컬럼에 대한 타입 추론을 수정했습니다. 이전에는 해당 컬럼이 그 조인에 사용되지 않았더라도, 후속 조인이 기반 원본 컬럼의 타입을 공통 상위 타입으로 잘못 갱신했습니다(예: `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)`에서 `t2.a` 컬럼은 첫 번째 조인에만 사용되므로 `t3.a`를 제외한 `t1.a`와 `t2.a`의 상위 타입이어야 합니다). 이로 인해 함수가 실행 계획에 실제로 나타나는 컬럼 타입과 다른 타입을 예상할 경우 logical error 또는 크래시가 발생할 수 있었습니다. [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#96394](https://github.com/ClickHouse/ClickHouse/issues/96394)에서 백포트됨: 분산 쿼리에서 음수 `LIMIT/OFFSET`를 사용할 때 일부 경우 발생하던 logical error를 수정했습니다. [#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#96220](https://github.com/ClickHouse/ClickHouse/issues/96220)에서 백포트됨: JSON 배열에 `tupleElement`를 적용하는 과정에서 발생하던 크래시를 수정했습니다. [#95581](https://github.com/ClickHouse/ClickHouse/issues/95581)을 닫습니다. [#95647](https://github.com/ClickHouse/ClickHouse/pull/95647) ([Pavel Kruglov](https://github.com/Avogar)).
* [#96054](https://github.com/ClickHouse/ClickHouse/issues/96054)에서 백포트됨: 파티션된 delta lake 데이터의 squashing을 수정했습니다. [#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#96084](https://github.com/ClickHouse/ClickHouse/issues/96084)에서 백포트됨: 빈 MergeTree 테이블에서 `direct` 조인 알고리즘을 사용할 때 발생할 수 있던 `NOT_SUPPORTED` 오류를 수정했습니다. [#95935](https://github.com/ClickHouse/ClickHouse/pull/95935) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#96213](https://github.com/ClickHouse/ClickHouse/issues/96213)에서 백포트됨: JSON 데이터 타입의 스키핑 경로를 수정했습니다. 이전에는 `JSON(SKIP path)`를 사용할 때 접두사가 `path`인 모든 JSON 키가 스키핑되어 `"pathpath"` 같은 키도 제외되었고, 그 결과 삽입 시 이러한 경로의 데이터가 손실될 수 있었습니다. 이제는 `"path"` 키만 스키핑됩니다. [#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* [#96080](https://github.com/ClickHouse/ClickHouse/issues/96080)에서 백포트됨: 전역 프로파일러의 주기(`global_profiler_real_time_period_ns` 및 `global_profiler_cpu_time_period_ns`로 제어됨)를 수정했습니다. 설정된 값 대신 잘린 값이 사용되어 프로파일러가 의도보다 더 자주 깨어나는 문제가 있었습니다.
