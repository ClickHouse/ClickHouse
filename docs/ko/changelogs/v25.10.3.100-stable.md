* [#90640](https://github.com/ClickHouse/ClickHouse/issues/90640)에 백포트됨: S3 library가 XML Response를 파싱할 때 발생하는 네트워크 오류에 대해 재시도하도록 했습니다. [#90216](https://github.com/ClickHouse/ClickHouse/pull/90216) ([Sema Checherinda](https://github.com/CheSema)).
* [#90728](https://github.com/ClickHouse/ClickHouse/issues/90728)에 백포트됨: guardrails limits에 가까워질 때 표시되는 warning messages를 업데이트해 현재 값과 throw 값을 보여주도록 했습니다. [#90438](https://github.com/ClickHouse/ClickHouse/pull/90438) ([Nikita Fomichev](https://github.com/fm4v)).
