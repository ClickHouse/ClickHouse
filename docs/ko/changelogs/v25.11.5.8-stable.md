* [#92901](https://github.com/ClickHouse/ClickHouse/issues/92901)에서 백포트됨: 동일한 이름의 컬럼과 서브컬럼 사이에서 발생할 수 있는 충돌로 인해 잘못된 serialization이 사용되고 쿼리가 실패하는 문제를 수정했습니다. [#90219](https://github.com/ClickHouse/ClickHouse/issues/90219)를 닫습니다. [#85161](https://github.com/ClickHouse/ClickHouse/issues/85161)를 닫습니다. [#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92988](https://github.com/ClickHouse/ClickHouse/issues/92988)에서 백포트됨: 연결이 끊어진 `Connection`에서 읽는 도중 발생하는 크래시를 방지합니다. [#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#92879](https://github.com/ClickHouse/ClickHouse/issues/92879)에서 백포트됨: `Ordered` 모드의 `S3Queue` 스토리지에서 발생하는 논리 오류 ` Failed to set file processing within 100 retries`를 수정했습니다. 이제 이 오류는 경고로 대체됩니다. 이 오류는 Keeper session이 만료되면 25.10 버전 이전에도 발생할 수 있었지만, `Ordered` 모드에서 처리 동시성이 높은 경우 이 오류가 이론적으로 여전히 발생할 수 있으므로 25.10+ 버전에서도 계속 경고로 처리됩니다. [#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#92943](https://github.com/ClickHouse/ClickHouse/issues/92943)에서 백포트됨: 프레디케이트의 `WHERE` 절에 서브쿼리가 포함된 `IN` 절이 있는 경량 업데이트에서 프라이머리 인덱스 사용을 수정했습니다. [#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* [#92962](https://github.com/ClickHouse/ClickHouse/issues/92962)에서 백포트됨: `ratio_of_defaults_for_sparse_serialization=0.0`인 희소 컬럼의 mutation 이후 `FILE_DOESNT_EXIST` 오류가 발생할 수 있는 문제를 수정했습니다. [#92633](https://github.com/ClickHouse/ClickHouse/issues/92633)를 닫습니다. [#92860](https://github.com/ClickHouse/ClickHouse/pull/92860) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92934](https://github.com/ClickHouse/ClickHouse/issues/92934)에서 백포트됨: JSON 컬럼이 Tuple 컬럼 뒤에 오는 경우 기존 Parquet 리더(기본적으로 사용되지 않음)의 Parquet 스키마 추론을 수정했습니다. 또한 빈 튜플에서 기존 Parquet 리더(기본적으로 사용되지 않음)가 실패하는 문제도 수정했습니다. [#92867](https://github.com/ClickHouse/ClickHouse/pull/92867) ([Michael Kolupaev](https://github.com/al13n321)).
* [#93032](https://github.com/ClickHouse/ClickHouse/issues/93032)에서 백포트됨: shared 파트에 대한 TOCTOU 경쟁 상태로 인해 오래된 파트가 사용될 수 있는 문제를 수정했습니다. [#93022](https://github.com/ClickHouse/ClickHouse/pull/93022) ([Azat Khuzhin](https://github.com/azat)).
