[#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva)).
* [#88537](https://github.com/ClickHouse/ClickHouse/issues/88537)에 백포트됨: Iceberg SELECT의 성능 추적을 위한 정보를 추가했습니다. [#87903](https://github.com/ClickHouse/ClickHouse/pull/87903) ([Daniil Ivanik](https://github.com/divanik)).
* [#88300](https://github.com/ClickHouse/ClickHouse/issues/88300)에 백포트됨: copy 및 create container 기능에서 확인된 &#39;Content-Length&#39; 관련 수정 사항을 포함하도록 azure sdk를 업데이트했습니다. [#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#88742](https://github.com/ClickHouse/ClickHouse/issues/88742)에 백포트됨: 구성 `keeper_server.coordination_settings.check_node_acl_on_remove`를 추가했습니다. 활성화하면 각 node를 삭제하기 전에 해당 node 자체와 parent node의 ACL을 모두 검증합니다. 그렇지 않으면 parent node의 ACL만 검증합니다. [#88513](https://github.com/ClickHouse/ClickHouse/pull/88513) ([Antonio Andelic](https://github.com/antonio2368)).
* [#88781](https://github.com/ClickHouse/ClickHouse/issues/88781)에 백포트됨: `GLOBAL IN`으로 인한 메모리 누수를 수정했습니다 ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)). [#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94)).
* [#88764](https://github.com/ClickHouse/ClickHouse/issues/88764)에 백포트됨: `clickhouse-keeper`의 postinstall script에 부팅 시 자동 시작을 활성화하는 단계를 추가했습니다. [#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan)).
