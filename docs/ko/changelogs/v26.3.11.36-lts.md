<div id="improvement">
  #### 개선 사항
</div>

* [#104034](https://github.com/ClickHouse/ClickHouse/issues/104034)에 백포트됨: `FINAL` 이후에 적용되도록 미루는 ROW POLICY가 정렬 키 컬럼에만 의존하고 결정적인 경우, 해당 ROW POLICY의 지연 적용을 건너뛰고, 그로 인해 강제되던 `PREWHERE` 지연도 함께 건너뛰도록 했습니다. [#102884](https://github.com/ClickHouse/ClickHouse/pull/102884) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#104384](https://github.com/ClickHouse/ClickHouse/issues/104384)에 백포트됨: 갱신 가능 구체화 뷰가 계속 갱신되는 경우에도, 전역 상태가 아니라 스냅샷된 테이블의 상태를 기준으로 판단하도록 하여 백업의 안정성을 개선했습니다. [#103384](https://github.com/ClickHouse/ClickHouse/pull/103384) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#104702](https://github.com/ClickHouse/ClickHouse/issues/104702)에 백포트됨: 대용량 비ASCII 데이터 집합(예: 텍스트 인덱스 빌드 중)을 처리할 때 누적된 출력 버퍼가 2 GiB를 초과하면 발생하던 `lowerUTF8` / `upperUTF8` 예외를 수정하고, 지나치게 긴 단일 행은 명확한 오류 메시지와 함께 거부하도록 했습니다. [#104229](https://github.com/ClickHouse/ClickHouse/pull/104229) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#105063](https://github.com/ClickHouse/ClickHouse/issues/105063)에 백포트됨: 새로운 설정 `defer_partition_pruning_after_final`(기본값 `1`)을 추가하여, 26.3에서 도입된 `FINAL`에서 파티션 프루닝을 건너뛰는 동작을 opt-out할 수 있게 했습니다. 이 값을 `0`으로 설정하면 26.3 이전의 파티션 프루닝 동작으로 복원되며, 동일한 PK의 행이 여러 파티션에 걸쳐 존재할 수 없는 이벤트 로그 워크로드에서는 성능이 크게 향상됩니다. `compatibility = '26.2'`로 설정하면 자동으로 `0`으로 전환됩니다. [#104705](https://github.com/ClickHouse/ClickHouse/pull/104705) ([Nikita Fomichev](https://github.com/fm4v)).

[#104009](https://github.com/ClickHouse/ClickHouse/pull/104009) ([Shaohua Wang](https://github.com/tiandiwonder)).
