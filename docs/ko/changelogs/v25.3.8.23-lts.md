<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#88220](https://github.com/ClickHouse/ClickHouse/issues/88220)에 백포트됨: `AggregateFunction(quantileDD)` 컬럼에 들어가는 일부 유효한 사용자 제출 데이터로 인해 머지가 무한 재귀에 빠지면서 크래시가 발생할 수 있던 문제를 수정합니다. [#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* [#88598](https://github.com/ClickHouse/ClickHouse/issues/88598)에 백포트됨: `parallel_replicas_for_cluster_functions` 설정이 1로 설정된 경우 `url()` 테이블 함수의 테이블 스키마를 확인하는 문제를 수정합니다. [#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#88647](https://github.com/ClickHouse/ClickHouse/issues/88647)에 백포트됨: 노드 수가 10개를 초과하는 대규모 클러스터에서는 `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again` 오류와 함께 복원에 실패할 가능성이 높았습니다. 이는 여러 호스트가 동시에 `num_hosts` 노드를 덮어쓰기 때문입니다. 이 수정으로 시도 횟수를 제어하는 설정이 동적으로 동작하도록 변경되었습니다. [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721)을 해결합니다. [#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#88712](https://github.com/ClickHouse/ClickHouse/issues/88712)에 백포트됨: 기반 const PREWHERE 컬럼의 동시 mutation으로 인해 발생할 수 있는 잠재적 크래시를 수정합니다. [#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).
* [#88902](https://github.com/ClickHouse/ClickHouse/issues/88902)에 백포트됨: 복구 후 복제된 데이터베이스 레플리카가 `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)`와 같은 메시지를 출력하며 오랫동안 멈춘 상태로 남아 있을 수 있던 문제를 수정했습니다. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#88886](https://github.com/ClickHouse/ClickHouse/issues/88886)에 백포트됨: `loop` 테이블 함수에 대한 select 시 접근 검증 문제를 수정합니다. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* [#89033](https://github.com/ClickHouse/ClickHouse/issues/89033)에 백포트됨: `reverseUTF8` 함수의 버그를 수정합니다. 이전 버전에서는 길이가 4인 UTF-8 code point의 바이트 순서를 잘못 뒤집었습니다. 이로써 [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913)을 해결합니다. [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
