[#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).

* [#95815](https://github.com/ClickHouse/ClickHouse/issues/95815)에서 백포트됨: 여러 조인과 함께 `USING` clause를 사용할 때 원본 테이블에서 테이블명이 지정된 컬럼에 대한 타입 추론을 수정했습니다. 이전에는 후속 조인이 해당 컬럼이 그 조인에 포함되지 않았더라도 기반 원본 컬럼의 타입을 공통 상위 타입으로 잘못 갱신했습니다(예: `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)`에서 `t2.a` 컬럼은 첫 번째 조인에만 사용되므로, 그 타입은 `t3.a`를 제외한 `t1.a`와 `t2.a`의 상위 타입이어야 합니다). 이 문제는 함수가 실행 계획에 실제로 나타나는 컬럼 타입과 다른 타입을 기대할 때 논리 오류나 크래시로 이어질 수 있었습니다. [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#95425](https://github.com/ClickHouse/ClickHouse/issues/95425)에서 백포트됨: manifest `.avro` 목록 및 파일 내용을 가져오는 동안 컬럼 변환이 한 번만 수행되도록 했습니다. [#95164](https://github.com/ClickHouse/ClickHouse/pull/95164) ([Daniil Ivanik](https://github.com/divanik)).
* [#95382](https://github.com/ClickHouse/ClickHouse/issues/95382)에서 백포트됨: 경량 업데이트 후 큰 패치 파트를 적용할 때 부정확한 메모리 계산을 수정했습니다. 이전에는 큰 패치를 적용하면 과도한 메모리 사용량이 발생해 서버 프로세스가 OOM killer에 의해 종료될 수 있었습니다. [#95231](https://github.com/ClickHouse/ClickHouse/pull/95231) ([Anton Popov](https://github.com/CurtizJ)).
