<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224)에 백포트되었습니다: JSON에 대한 고급 공유 데이터(advanced shared data)를 기본적으로 활성화합니다. 이 변경 이후에는 25.8 미만 버전으로의 다운그레이드가 불가능합니다. 해당 버전들은 JSON 컬럼이 포함된 새로운 데이터 파트를 읽을 수 없기 때문입니다. 안전한 업그레이드를 위해 `compatibility` 설정을 이전 버전으로 지정하거나, MergeTree 설정 `dynamic_serialization_version='v2', object_serialization_version='v2'`를 지정하는 것을 권장합니다. [#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061)에 백포트되었습니다: "단순 ALIAS 컬럼에 대한 INSERT 허용"을 되돌립니다 (ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154) 되돌리기). 해당 기능은 커스텀 포맷과 호환되지 않으며, 설정으로 제어되지 않습니다. [#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* [#92711](https://github.com/ClickHouse/ClickHouse/issues/92711)에 백포트되었습니다: `distinctJSONPaths` 집계 함수를 최적화하여 JSON 컬럼 전체가 아닌 데이터 파트에서 JSON 경로만 읽도록 개선합니다. [#92196](https://github.com/ClickHouse/ClickHouse/pull/92196) ([Pavel Kruglov](https://github.com/Avogar)).

* [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338)에 백포트되었습니다: `flipCoordinates`에서 geometry 타입을 지원합니다. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).
* [#93395](https://github.com/ClickHouse/ClickHouse/issues/93395)에 백포트되었습니다: SYSTEM INSTRUMENT ADD/REMOVE의 사용자 경험을 개선합니다. 함수 이름에 String 리터럴을 사용하고, 일치하는 모든 함수에 패치를 적용하며, `REMOVE`에서 function_name 사용을 허용합니다. [#93345](https://github.com/ClickHouse/ClickHouse/pull/93345) ([Pablo Marcos](https://github.com/pamarcos))."
