* [#98402](https://github.com/ClickHouse/ClickHouse/issues/98402)에서 백포트됨: `loop` 테이블 함수가 행 정책(row policies), 컬럼 수준 권한 부여, 기타 보안 검사가 적용되는 인터프리터 계층을 우회해 `inner_storage->read()`를 직접 호출하고 있었습니다. 이로 인해 행 정책으로 제한된 사용자가 직접 SELECT에서는 0개의 행만 반환되더라도 `loop(table)`를 통해 모든 행을 읽을 수 있었습니다. [#97682](https://github.com/ClickHouse/ClickHouse/pull/97682) ([pufit](https://github.com/pufit)).
* [#98310](https://github.com/ClickHouse/ClickHouse/issues/98310)에서 백포트됨: 프라이머리 키(primary key) 스킵 인덱스와 프라이머리 키가 아닌 스킵 인덱스를 함께 사용할 때 FINAL 쿼리에서 잘못된 결과가 반환되던 문제를 수정했습니다. [#98097](https://github.com/ClickHouse/ClickHouse/pull/98097) ([Raúl Marín](https://github.com/Algunenano)).
* [#98352](https://github.com/ClickHouse/ClickHouse/issues/98352)에서 백포트됨: `aggregated_zookeeper_log`에서 watch 응답의 `Watch` component를 비워 두는 대신 설정하도록 했습니다. [#98202](https://github.com/ClickHouse/ClickHouse/pull/98202) ([Antonio Andelic](https://github.com/antonio2368)).
* [#98326](https://github.com/ClickHouse/ClickHouse/issues/98326)에서 백포트됨: `extremes = 1`이 활성화된 경우 크래시를 일으킬 수 있었던 `ColumnConst::getExtremes`의 범위 밖 접근 문제를 수정했습니다. [#98263](https://github.com/ClickHouse/ClickHouse/pull/98263) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#98388](https://github.com/ClickHouse/ClickHouse/issues/98388)에서 백포트됨: 65535 경계를 넘는 데이터를 가진 키 컬럼에서 `toDate` 변환으로 인해 트리거되던 &quot;Invalid binary search result in `MergeTreeSetIndex`&quot; LOGICAL&#95;ERROR 예외를 수정했습니다. [#98276](https://github.com/ClickHouse/ClickHouse/pull/98276) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
