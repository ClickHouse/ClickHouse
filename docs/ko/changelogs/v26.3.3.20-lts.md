* [#101224](https://github.com/ClickHouse/ClickHouse/issues/101224)에 백포트됨: 비동기 삽입 쿼리가 `query_log` 및 클라이언트 출력에서 `written_rows`, `read_rows`, `result_rows`를 0으로 보고하는 문제를 수정했습니다. [#99879](https://github.com/ClickHouse/ClickHouse/pull/99879) ([Sema Checherinda](https://github.com/CheSema)).
* [#100891](https://github.com/ClickHouse/ClickHouse/issues/100891)에 백포트됨: `RESTORE` 중 경로 순회, 절대 경로, 빈 이름을 차단할 수 있도록 백업 메타데이터의 파일 엔트리 경로를 검증합니다. [#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* [#101394](https://github.com/ClickHouse/ClickHouse/issues/101394)에 백포트됨: 비동기 삽입(TCP)과 HTTP를 통한 모든 삽입에서 `DateTime` 값을 parsing할 때 `session_timezone`이 무시되는 문제를 수정했습니다. [#100647](https://github.com/ClickHouse/ClickHouse/pull/100647) ([Sema Checherinda](https://github.com/CheSema)).
* [#100922](https://github.com/ClickHouse/ClickHouse/issues/100922)에 백포트됨: LowCardinality 요소를 포함한 튜플 키에 대해 PREWHERE/WHERE와 함께 `has()` 함수를 사용할 때 서버 크래시가 발생하는 문제를 수정했습니다. [#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* [#101187](https://github.com/ClickHouse/ClickHouse/issues/101187)에 백포트됨: 서버 종료 중 딕셔너리를 loading할 때 발생하는 null 포인터 역참조 segfault를 수정했습니다. `Context::getUserDefinedSQLObjectsStorage`(`user_defined_sql_objects_storage`를 역참조함)는 메인 스레드가 `Context::shutdown`을 호출해 `user_defined_sql_objects_storage`를 null로 설정하는 동시에 딕셔너리 스레드에서도 호출됩니다. `Context::shutdown`을 실행하기 전에 딕셔너리 로더에서 향후 업데이트를 비활성화하고, 현재 실행 중인 딕셔너리 쿼리를 종료하며, 딕셔너리 loading 스레드를 join해야 합니다. 이는 일반 쿼리에서 처리하는 방식과 유사합니다. [#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#101091](https://github.com/ClickHouse/ClickHouse/issues/101091)에 백포트됨: 입력에 ASCII가 아닌 바이트가 포함될 때 `ULIDStringToDateTime`에서 발생하는 buffer 오버플로우를 수정했습니다. [#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101015](https://github.com/ClickHouse/ClickHouse/issues/101015)에 백포트됨: 널 허용 튜플 배열에서 `intDiv`/`intDivOrZero`가 예외를 발생시키는 문제를 수정했습니다. 예: `SELECT intDiv([divide((1, 2), ... AND NULL)], 2)`. [#100895](https://github.com/ClickHouse/ClickHouse/pull/100895) ([Raúl Marín](https://github.com/Algunenano)).
* [#101250](https://github.com/ClickHouse/ClickHouse/issues/101250)에 백포트됨: `StorageAlias`의 정의를 저장하기 전에 engine 인수를 평가하도록 하여 `currentDatabase()`와 같은 표현식이 데이터베이스에 저장되기 전에 literal로 해석되도록 했습니다. [#100902](https://github.com/ClickHouse/ClickHouse/pull/100902) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#101140](https://github.com/ClickHouse/ClickHouse/issues/101140)에 백포트됨: 텍스트 검색 인덱스를 튜플 subquery가 포함된 `IN` 절과 함께 사용할 때(예: `WHERE (id, str) IN (SELECT (id, str) FROM ...)`) 또는 subquery의 컬럼 수가 `IN` 왼쪽 튜플과 일치하지 않을 때 발생하던 크래시를 수정했습니다. [#100959](https://github.com/ClickHouse/ClickHouse/pull/100959) ([Anton Popov](https://github.com/CurtizJ)).
* [#101080](https://github.com/ClickHouse/ClickHouse/issues/101080)에 백포트됨: `Nullable(Tuple)` 도입 이후 하나 이상의 `Nullable` 인수가 있는 `sumCountOrDefault` 집계 함수가 이전에 직렬화된 state를 읽지 못하던 문제를 수정했습니다. [#100882](https://github.com/ClickHouse/ClickHouse/issues/100882)를 해결합니다. [#101021](https://github.com/ClickHouse/ClickHouse/pull/101021) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#101169](https://github.com/ClickHouse/ClickHouse/issues/101169)에 백포트됨: PREWHERE가 있는 프로젝션을 `ORDER BY ... LIMIT`와 함께 사용할 때 `optimizeLazyMaterialization`에서 발생하던 예외를 수정했습니다. [#101115](https://github.com/ClickHouse/ClickHouse/pull/101115) ([Anton Popov](https://github.com/CurtizJ)).
* [#101349](https://github.com/ClickHouse/ClickHouse/issues/101349)에 백포트됨: `list`와 `read` 사이에 원격 객체가 덮어써져 이전에는 오래된 객체 메타데이터가 생성되었고, 그 결과 cache에서 `Having zero bytes, ...` `logical error`로 이어질 수 있던 문제를 수정했습니다. [#101219](https://github.com/ClickHouse/ClickHouse/pull/101219) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#101373](https://github.com/ClickHouse/ClickHouse/issues/101373)에 백포트됨: ... [#101230](https://github.com/ClickHouse/ClickHouse/pull/101230) ([Kseniia Sumarokova](https://github.com/kssenii)).
