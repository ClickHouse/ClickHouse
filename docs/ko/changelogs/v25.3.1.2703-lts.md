  ### ClickHouse 릴리스 v25.3.1.2703-lts (b684e195f96) FIXME v25.3.1.1-new (217f67ec3ad) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 복제된 데이터베이스에서는 TRUNCATE DATABASE를 허용하지 않습니다. [#76651](https://github.com/ClickHouse/ClickHouse/pull/76651) ([Bharat Nallan](https://github.com/bharatnc)).
* `compatibility` 설정과 관계없이 분석기가 비활성화되면 기본적으로 병렬 레플리카도 비활성화됩니다. `parallel_replicas_only_with_analyzer`를 `false`로 명시적으로 설정하면 이 동작을 계속 변경할 수 있습니다. [#77115](https://github.com/ClickHouse/ClickHouse/pull/77115) ([Igor Nikonov](https://github.com/devcrafter)).
* 더 이상 설정값으로 `NaN` 또는 `inf`와 같은 부동소수점 값을 사용할 수 없습니다. [#77546](https://github.com/ClickHouse/ClickHouse/pull/77546) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).

<div id="new-feature">
  #### 새 기능
</div>

* 로컬 파일 시스템 캐시를 사용하지 않는 원격 가상 파일 시스템에 데이터가 저장된 경우에 유용하도록, OS 페이지 캐시에 의존하지 않고 프로세스 내 메모리에 데이터를 캐시할 수 있는 사용자 공간 페이지 캐시의 새로운 구현이 추가되었습니다. [#70509](https://github.com/ClickHouse/ClickHouse/pull/70509) ([Michael Kolupaev](https://github.com/al13n321)).
* [#77924](https://github.com/ClickHouse/ClickHouse/issues/77924)에 백포트됨: 낮은 카디널리티 Decimal 데이터 타입을 지원하고 [#72256](https://github.com/ClickHouse/ClickHouse/issues/72256)을 수정했습니다. [#72833](https://github.com/ClickHouse/ClickHouse/pull/72833) ([zhanglistar](https://github.com/zhanglistar)).
* 동시 쿼리 간 CPU 슬롯이 분배되는 방식을 제어하는 `concurrent_threads_scheduler` 서버 설정이 추가되었습니다. `round_robin`(기존 동작) 또는 `fair_round_robin`으로 설정할 수 있으며, INSERT와 SELECT 간 CPU 분배가 불공정한 문제를 해결합니다. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).
* `arraySymmetricDifference` 함수가 추가되었습니다. 이 함수는 여러 배열 인수에서 모든 인수에 공통으로 나타나지 않는 모든 요소를 반환합니다. 예시: `SELECT arraySymmetricDifference([1, 2], [2, 3])`는 `[1, 3]`을 반환합니다. (issue [#61673](https://github.com/ClickHouse/ClickHouse/issues/61673)). [#76231](https://github.com/ClickHouse/ClickHouse/pull/76231) ([Filipp Abapolov](https://github.com/pheepa)).
* `estimatecompressionratio` 집계 함수가 추가되었습니다. [#70801](https://github.com/ClickHouse/ClickHouse/issues/70801)을 참조하십시오. [#76661](https://github.com/ClickHouse/ClickHouse/pull/76661) ([Tariq Almawash](https://github.com/talmawash)).
* `FilterTransformPassedRows` 및 `FilterTransformPassedBytes` 프로필 이벤트는 쿼리 실행 중 필터링된 행 수와 바이트 수를 보여줍니다. [#76662](https://github.com/ClickHouse/ClickHouse/pull/76662) ([Onkar Deshpande](https://github.com/onkar)).
* 블록체인 구현, 특히 EVM 기반 시스템에서 일반적으로 사용되는 `keccak256` hash function이 추가되었습니다. [#76669](https://github.com/ClickHouse/ClickHouse/pull/76669) ([Arnaud Briche](https://github.com/arnaudbriche)).
* 이 기능으로 클라이언트 요청의 헤더 중 외부 HTTP authenticator로 전달할 헤더 목록을 정의할 수 있게 되었습니다. [#77054](https://github.com/ClickHouse/ClickHouse/pull/77054) ([inv2004](https://github.com/inv2004)).
* 새로운 함수 3개가 추가되었습니다. 사양에 따른 `icebergTruncate` [https://iceberg.apache.org/spec/#truncate-transform-details](https://iceberg.apache.org/spec/#truncate-transform-details), `toYearNumSinceEpoch`, `toMonthNumSinceEpoch`입니다. `Iceberg` 엔진의 파티션 프루닝에서 `truncate` 변환도 지원합니다. [#77403](https://github.com/ClickHouse/ClickHouse/pull/77403) ([alesapin](https://github.com/alesapin)).
* [#77975](https://github.com/ClickHouse/ClickHouse/issues/77975)에 백포트됨: `JSON` 데이터 타입은 프로덕션 환경에서 사용할 준비가 되었습니다. [https://jsonbench.com/](https://jsonbench.com/)을 참조하십시오. `Dynamic` 및 `Varaint` 데이터 타입도 프로덕션 환경에서 사용할 준비가 되었습니다. [#77785](https://github.com/ClickHouse/ClickHouse/pull/77785) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="experimental-feature">
  #### 실험적 기능
</div>

* 동적 클러스터 자동 디스커버리 지원을 추가했습니다. 이는 기존 *노드* 자동 디스커버리 기능을 확장한 것입니다. 이제 ClickHouse는 `<multicluster_root_path>`를 사용해 공통 ZooKeeper 경로 아래에서 새로운 &#95;클러스터&#95;를 자동으로 감지하고 등록할 수 있습니다. [#76001](https://github.com/ClickHouse/ClickHouse/pull/76001) ([Anton Ivashkin](https://github.com/ianton-ru)).
* 새로운 설정 `enable_replacing_merge_with_cleanup_for_min_age_to_force_merge`를 통해, 구성 가능한 시간 제한이 지난 후 전체 파티션에 대해 자동 정리 머지를 수행할 수 있도록 했습니다. [#76440](https://github.com/ClickHouse/ClickHouse/pull/76440) ([Christoph Wurm](https://github.com/cwurm)).
* AWS S3 및 로컬 파일 시스템의 DeltaLake 테이블에 대해 [Unity Catalog](https://www.databricks.com/product/unity-catalog) 지원을 추가했습니다. [#76988](https://github.com/ClickHouse/ClickHouse/pull/76988) ([alesapin](https://github.com/alesapin)).
* Iceberg 테이블용 AWS Glue 서비스 catalog와의 실험적 통합을 도입했습니다. [#77257](https://github.com/ClickHouse/ClickHouse/pull/77257) ([alesapin](https://github.com/alesapin)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 코드 일부 위치에 `preserve_most` 속성을 적용합니다. [#67778](https://github.com/ClickHouse/ClickHouse/pull/67778) ([Nikita Taranov](https://github.com/nickitat)).
* 반복되는 조건을 사용하는 쿼리의 성능을 높이기 위해 쿼리 조건 캐시를 구현했습니다. 조건을 만족하지 않는 데이터 구간의 범위를 메모리에 임시 인덱스로 저장합니다. 이후 쿼리에서는 이 인덱스를 사용합니다. 해결 [#67768](https://github.com/ClickHouse/ClickHouse/issues/67768) ### 사용자에게 표시되는 변경 사항에 대한 문서 항목. [#69236](https://github.com/ClickHouse/ClickHouse/pull/69236) ([zhongyuankai](https://github.com/zhongyuankai)).
* [#70502](https://github.com/ClickHouse/ClickHouse/issues/70502)의 테스트에 따라 산술 계산에서 Int256과 UInt256을 clang 내장 i256으로 대체합니다. [#73658](https://github.com/ClickHouse/ClickHouse/pull/73658) ([李扬](https://github.com/taiyang-li)).
* 일부 경우(예: 빈 배열 컬럼)에는 데이터 파트에 빈 파일이 포함될 수 있습니다. 테이블이 메타데이터 스토리지와 객체 스토리지가 분리된 디스크에 있는 경우, ObjectStorage에 빈 blob을 쓰지 않고 이러한 파일에 대해서는 메타데이터만 저장할 수 있습니다. [#75860](https://github.com/ClickHouse/ClickHouse/pull/75860) ([Alexander Gololobov](https://github.com/davenger)).
* Decimal32/Decimal64/DateTime64의 min/max 성능을 개선합니다. [#76570](https://github.com/ClickHouse/ClickHouse/pull/76570) ([李扬](https://github.com/taiyang-li)).
* 파트 제거 시 캐시에서 데이터를 적극적으로 제거합니다. 데이터 양이 더 적은 경우 캐시가 최대 크기까지 커지지 않도록 합니다. [#76641](https://github.com/ClickHouse/ClickHouse/pull/76641) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이제 쿼리 컴파일(설정 `compile_expressions`) 시 머신 유형을 고려합니다. 이에 따라 이러한 쿼리의 속도가 크게 향상됩니다. [#76753](https://github.com/ClickHouse/ClickHouse/pull/76753) ([Robert Schulze](https://github.com/rschu1ze)).
* [#77880](https://github.com/ClickHouse/ClickHouse/issues/77880)에 백포트됨: arraySort를 최적화합니다. [#76850](https://github.com/ClickHouse/ClickHouse/pull/76850) ([李扬](https://github.com/taiyang-li)).
* [#77961](https://github.com/ClickHouse/ClickHouse/issues/77961)에 백포트됨: 머지와 같이 캐시가 수동적으로 사용되는 경우 `filesystem_cache_prefer_bigger_buffer_size`를 비활성화합니다. [#77898](https://github.com/ClickHouse/ClickHouse/pull/77898) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="improvement">
  #### 개선 사항
</div>

* 병렬 레플리카가 활성화된 경우 테이블 함수를 해당 `-Cluster` 대안으로 대체합니다. [#65024](https://github.com/ClickHouse/ClickHouse/issues/65024)를 수정했습니다. [#70659](https://github.com/ClickHouse/ClickHouse/pull/70659) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* tuple 컬럼의 필드에 대해 대소문자를 구분하지 않는 컬럼 매칭을 적용하도록 수정했습니다. [https://github.com/apache/incubator-gluten/issues/8324](https://github.com/apache/incubator-gluten/issues/8324)를 해결했습니다. [#73780](https://github.com/ClickHouse/ClickHouse/pull/73780) ([李扬](https://github.com/taiyang-li)).
* 이제 Gorilla codec의 매개변수는 항상 `.sql` 파일의 테이블 메타데이터에 저장됩니다. 이 변경은 [#70072](https://github.com/ClickHouse/ClickHouse/issues/70072)를 해결했습니다. [#74814](https://github.com/ClickHouse/ClickHouse/pull/74814) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#77949](https://github.com/ClickHouse/ClickHouse/issues/77949)에 백포트됨: SSH protocol 지원을 다시 활성화했습니다. 일부 치명적인 취약점을 수정하여 더 이상 사용자 지정 pager를 사용하거나 `server-logs-file`을 지정할 수 없도록 했습니다. 기본적으로 환경 변수를 통해 클라이언트 옵션을 전달하는 기능도 비활성화했습니다(`config.xml`의 `ssh-server.enable_client_options_passing`을 통해서는 여전히 가능합니다). progress table, 쿼리 취소, completion, profile events progress, stdin, `send_logs_level` 옵션을 지원합니다. 이 변경은 [#74340](https://github.com/ClickHouse/ClickHouse/issues/74340)을 해결했습니다. [#74989](https://github.com/ClickHouse/ClickHouse/pull/74989) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* parsing 기능을 개선했습니다(시퀀스 ID parsing: manifest 파일의 시퀀스 식별자를 parse하는 기능 추가 AND Avro metadata parsing: 향후 개선 사항까지 쉽게 확장할 수 있도록 Avro metadata parser를 재설계). [#75010](https://github.com/ClickHouse/ClickHouse/pull/75010) ([Daniil Ivanik](https://github.com/divanik)).
* gauge/counter 메트릭 유형을 지원합니다. 하지만 일부 메트릭(예: Keeper에 대한 request의 응답 시간)에는 이것만으로 충분하지 않으므로 히스토그램 메트릭 유형 지원이 필요합니다. 이 interface는 Prometheus client와 매우 유사하며, 값에 해당하는 버킷의 counter를 증가시키려면 `observe(value)`를 호출하기만 하면 됩니다. 히스토그램 메트릭은 system.histogram&#95;metrics를 통해 노출됩니다. [#75736](https://github.com/ClickHouse/ClickHouse/pull/75736) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* system.opentelemetry&#95;span&#95;log의 기본 ORDER BY에서 trace&#95;id를 제거합니다. [#75907](https://github.com/ClickHouse/ClickHouse/pull/75907) ([Azat Khuzhin](https://github.com/azat)).
* 이제 암호화(XML 속성 `encrypted_by`)를 모든 설정 파일(config.xml, users.xml, 중첩된 설정 파일)에 적용할 수 있습니다. 이전에는 최상위 `config.xml` 파일에서만 동작했습니다. [#75911](https://github.com/ClickHouse/ClickHouse/pull/75911) ([Mikhail Gorshkov](https://github.com/mgorshkov)).
* 출력 컬럼이 left table에 연결된 경우 join을 in subquery로 변환하려면 먼저 uniqueness 단계가 필요하므로, 해당 단계가 나중에 추가될 때까지 기본적으로 비활성화했습니다. [#75942](https://github.com/ClickHouse/ClickHouse/pull/75942) ([Shichao Jin](https://github.com/jsc0218)).
* `system.warnings` 테이블을 개선하고, 추가·업데이트·제거할 수 있는 일부 동적 warning messages를 추가합니다. [#76029](https://github.com/ClickHouse/ClickHouse/pull/76029) ([Bharat Nallan](https://github.com/bharatnc)).
* 이 PR로 인해 모든 `DROP` 작업은 순서상 먼저 와야 하므로 `ALTER USER user1 ADD PROFILES a, DROP ALL PROFILES` 쿼리는 실행할 수 없게 됩니다. [#76242](https://github.com/ClickHouse/ClickHouse/pull/76242) ([pufit](https://github.com/pufit)).
* SYNC REPLICA에 대한 다양한 개선 사항(더 나은 오류 메시지, 향상된 테스트, sanity check). [#76307](https://github.com/ClickHouse/ClickHouse/pull/76307) ([Azat Khuzhin](https://github.com/azat)).
* 백업 중 S3로의 multipart copy가 Access Denied로 실패하는 경우 올바른 폴백을 사용하도록 했습니다. 자격 증명이 서로 다른 버킷 간에 백업을 수행할 때 multi part copy에서 Access Denied 오류가 발생할 수 있습니다. [#76515](https://github.com/ClickHouse/ClickHouse/pull/76515) ([Antonio Andelic](https://github.com/antonio2368)).
* ClickHouse 서버 종료를 더 빠르게 개선했습니다(2.5초 지연 제거). [#76550](https://github.com/ClickHouse/ClickHouse/pull/76550) ([Azat Khuzhin](https://github.com/azat)).
* librdkafka를 버전 2.8.0으로 업그레이드하고 Kafka 테이블의 종료 시퀀스를 개선해 테이블 삭제 및 서버 재시작 중 지연을 줄였습니다. 이제 `engine=Kafka`는 테이블이 삭제될 때 더 이상 consumer group을 명시적으로 떠나지 않습니다. 대신 consumer는 비활성 상태가 `session_timeout_ms`(기본값: 45초) 동안 지속된 뒤 자동으로 제거될 때까지 그룹에 남아 있습니다. [#76621](https://github.com/ClickHouse/ClickHouse/pull/76621) ([filimonov](https://github.com/filimonov)).
* S3 요청 설정의 검증을 수정했습니다. [#76658](https://github.com/ClickHouse/ClickHouse/pull/76658) ([Vitaly Baranov](https://github.com/vitlibar)).
* ReadBufferFromS3 및 기타 원격 읽기 buffer에서 과도한 할당이 발생하지 않도록 개선해 메모리 사용량을 절반으로 줄였습니다. [#76692](https://github.com/ClickHouse/ClickHouse/pull/76692) ([Sema Checherinda](https://github.com/CheSema)).
* `server_settings` 또는 `settings` 같은 system table에는 유용한 `default` 값 컬럼이 있습니다. `merge_tree_settings`와 `replicated_merge_tree_settings`에만 이 컬럼이 활성화되어 있지 않았습니다. [#76942](https://github.com/ClickHouse/ClickHouse/pull/76942) ([Diego Nieto](https://github.com/lesandie)).
* `CurrentMetrics::QueryPreempted`와 동일한 로직을 사용하는 `ProfileEvents::QueryPreempted`를 추가했습니다. [#77015](https://github.com/ClickHouse/ClickHouse/pull/77015) ([VicoWu](https://github.com/VicoWu)).
* 이전에는 복제된 데이터베이스가 쿼리에 지정된 자격 증명을 로그에 출력할 수 있었습니다. 이 동작을 수정했습니다. 다음 이슈를 해결합니다: [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123). [#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* zstd를 1.5.5에서 1.5.7로 올렸으며, 이 버전에는 상당한 [성능 개선](https://github.com/facebook/zstd/releases/tag/v1.5.7)이 포함되어 있습니다. [#77137](https://github.com/ClickHouse/ClickHouse/pull/77137) ([Pradeep Chhetri](https://github.com/chhetripradeep)).
* plain&#95;rewritable disk에 대해 ALTER TABLE DROP PARTITION을 허용합니다. [#77138](https://github.com/ClickHouse/ClickHouse/pull/77138) ([Julia Kartseva](https://github.com/jkartseva)).
