<div id="performance-improvement">
  #### 성능 개선
</div>

* [#101736](https://github.com/ClickHouse/ClickHouse/issues/101736)에 백포트됨: `deduplicate_insert=enable`(26.2부터 기본값)일 때 발생하던 심각한 INSERT 성능 회귀를 수정했습니다. 이를 위해 데이터 해시 계산을 squashing 단계에서 싱크로 미루고 `updateHashWithValueRange`를 사용한 배치 컬럼 해싱을 적용하여, 22개 컬럼의 500만 행에서 오버헤드를 약 2.5초에서 약 0.5초로 줄였습니다. [#101494](https://github.com/ClickHouse/ClickHouse/pull/101494) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 개선 사항
</div>

* [#101949](https://github.com/ClickHouse/ClickHouse/issues/101949): server 시작 시 cache 로딩을 최적화하는 변경이 백포트되었습니다. [#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102140](https://github.com/ClickHouse/ClickHouse/issues/102140): 내부 mongo-c-driver를 2.2.2에서 2.2.3으로 업데이트하는 변경이 백포트되었습니다. [#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#101962](https://github.com/ClickHouse/ClickHouse/issues/101962)에 백포트됨: JOIN에서 shard-by-PK 최적화가 쿼리 조건 캐시를 사용하고 일부 파트가 캐시된 조건으로 필터링될 때 잘못된 결과가 나오는 문제를 수정했습니다. [#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* [#101987](https://github.com/ClickHouse/ClickHouse/issues/101987)에 백포트됨: 시작 의존성 순서가 잘못되어 비동기 시작 중 내부 테이블이 있는 구체화된 뷰(Materialized View)에서 발생하던 &quot;Target table doesn&#39;t exist&quot; 오류를 수정했습니다. [#100946](https://github.com/ClickHouse/ClickHouse/pull/100946) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#101563](https://github.com/ClickHouse/ClickHouse/issues/101563)에 백포트됨: delta lake 클러스터에서 복제된 MergeTree로 insert-select를 수행할 때 발생하던 문제를 수정했습니다. [#101299](https://github.com/ClickHouse/ClickHouse/pull/101299) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102076](https://github.com/ClickHouse/ClickHouse/issues/102076)에 백포트됨: `Object` type 동적 경로의 병렬 역직렬화에서 use-after-scope 문제를 수정했습니다. 이 문제는 동적 경로가 많은 테이블을 읽을 때 크래시를 일으킬 수 있었습니다. [#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102102](https://github.com/ClickHouse/ClickHouse/issues/102102)에 백포트됨: 특정 formatting 설정(기본값이 아닌 설정)에서 formatter `%W`를 사용하는 함수 `formatDateTime`의 출력이 잘못되는 문제를 수정했습니다. [#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* [#102030](https://github.com/ClickHouse/ClickHouse/issues/102030)에 백포트됨: 주기적 갱신 중 ZooKeeper session이 만료되면 UDF registry가 손실되는 문제를 수정했습니다. 이로 인해 full refresh가 성공할 때까지 모든 사용자 정의 함수가 사용 불가 상태가 될 수 있었습니다. [#101891](https://github.com/ClickHouse/ClickHouse/pull/101891) ([Nikita Fomichev](https://github.com/fm4v)).
* [#102094](https://github.com/ClickHouse/ClickHouse/issues/102094)에 백포트됨: 이제 `splitByString` 토크나이저는 빈 구분자 문자열을 허용하지 않습니다. [#101928](https://github.com/ClickHouse/ClickHouse/pull/101928) ([Robert Schulze](https://github.com/rschu1ze)).
