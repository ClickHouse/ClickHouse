<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#108281](https://github.com/ClickHouse/ClickHouse/issues/108281)에서 백포트되었습니다: JDBC, ODBC 및 NATS 연결 문자열의 자격 증명은 이제 쿼리 로그와 `SHOW CREATE` 출력에서 마스킹되어 민감한 정보가 우발적으로 노출되는 것을 방지합니다. URI 스타일 연결 문자열(예: {scheme}://{user}:{password}@{host})의 경우 비밀번호 부분만 마스킹되며, 디버깅 편의를 위해 나머지 부분은 그대로 표시됩니다. 이제 `nats_token` 설정도 마스킹됩니다. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#108446](https://github.com/ClickHouse/ClickHouse/issues/108446)에서 백포트됨: `JOIN ON` 내부에서 사용된 `arrayJoin()`이 잘못된 행 수를 반환하던 문제를 수정했습니다. 결과에 배열 길이가 한 번 더 곱해지고 있었습니다. [#104785](https://github.com/ClickHouse/ClickHouse/pull/104785) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#107482](https://github.com/ClickHouse/ClickHouse/issues/107482)에서 백포트됨: 벡터 검색 쿼리에서 vector index를 사용하면서 `minmax` 같은 다른 스킵 인덱스와 `use_skip_indexes_on_data_read = 1`을 함께 사용할 때 발생하던 예외를 수정했습니다. [#106473](https://github.com/ClickHouse/ClickHouse/pull/106473) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#108259](https://github.com/ClickHouse/ClickHouse/issues/108259)에서 백포트됨: 비어 있는 병합된 파트의 text index에서 발생하던 &quot;Too many marks&quot; 문제를 수정했습니다. [#106867](https://github.com/ClickHouse/ClickHouse/pull/106867) ([Azat Khuzhin](https://github.com/azat)).
* [#108170](https://github.com/ClickHouse/ClickHouse/issues/108170)에서 백포트됨: `UNION`/`INTERSECT`/`EXCEPT`의 한 브랜치가 `Sparse`로 직렬화된 컬럼을 읽고, 다른 브랜치가 같은 컬럼을 전체 컬럼으로 읽을 때(예: materialized view로 푸시할 때) 발생하던 `Block structure mismatch in UnionStep stream` logical error를 수정했습니다(debug/새니타이저 빌드에서는 server abort, 릴리스 빌드에서는 `Code: 49`). [#107041](https://github.com/ClickHouse/ClickHouse/pull/107041) ([Groene AI](https://github.com/groeneai)).
* [#108222](https://github.com/ClickHouse/ClickHouse/issues/108222)에서 백포트됨: 범위를 벗어난 이벤트 유형이 포함된 조작된 aggregate-function 상태를 finalize할 때 `windowFunnel`에서 발생하던 힙 버퍼 오버플로(서버 크래시)를 수정했습니다. 이 문제는 단일 `SELECT`만으로도 누구나 악용할 수 있었습니다. [#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* [#108501](https://github.com/ClickHouse/ClickHouse/issues/108501)에서 백포트됨: `update()` 내부에서 다시 빌드한 새 snapshot은 이미 `createBuilder`를 통해 C++ S3 클라이언트의 현재 자격 증명을 캡처하므로, 버전이 일치할 때 이를 폐기하지 않고 유지하도록 했습니다. 이렇게 하면 다음 커널 작업이 새 자격 증명이 반영된 engine에서 실행되어 STS TTL을 넘겨 유지되지 않습니다. [#107480](https://github.com/ClickHouse/ClickHouse/pull/107480) ([Elmi Ahmadov](https://github.com/ahmadov)).
* [#108638](https://github.com/ClickHouse/ClickHouse/issues/108638)에서 백포트됨: `ReplicatedMergeTree` 테이블의 `RESTORE`를 수정하여 backup의 중복 콘텐츠 파트가 조용히 deduplicate되지 않고 유지되도록 했습니다. [#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* [#108203](https://github.com/ClickHouse/ClickHouse/issues/108203)에서 백포트됨: set 스킵 인덱스가 LowCardinality 컬럼에 대해 그래뉼을 프루닝하지 못하던 문제를 수정했습니다. [#107868](https://github.com/ClickHouse/ClickHouse/pull/107868) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108304](https://github.com/ClickHouse/ClickHouse/issues/108304)에서 백포트됨: lookup 인수가 `LowCardinality`일 때 `Dynamic` 키를 가진 `Map`에 대한 `has`에서 발생하던 크래시(릴리스 빌드에서는 SIGSEGV, debug 빌드에서는 type-mismatch assertion)를 수정했습니다. 예: `has(map('a'::Dynamic, ...), toLowCardinality('b'))`. [#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* [#108196](https://github.com/ClickHouse/ClickHouse/issues/108196)에서 백포트됨: 비어 있는 batch에서도 access cache의 batch-finished handlers가 항상 실행되도록 했습니다. [#108124](https://github.com/ClickHouse/ClickHouse/pull/108124) ([Azat Khuzhin](https://github.com/azat)).
* [#108320](https://github.com/ClickHouse/ClickHouse/issues/108320)에 백포트됨: 잘못된 시점에 ZooKeeper 연결이 끊기면 갱신 가능 구체화 뷰가 멈추는 문제를 수정했습니다. [#108234](https://github.com/ClickHouse/ClickHouse/pull/108234) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108481](https://github.com/ClickHouse/ClickHouse/issues/108481)에 백포트됨: `format_display_secrets_in_show_and_select`가 비활성화된 경우(기본값) `EXPLAIN actions`, `EXPLAIN header`, `EXPLAIN PIPELINE` 출력에서 `encrypt`, `decrypt`, `HMAC` 등의 함수에 대한 시크릿 인수를 숨기도록 수정했습니다. [#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
* [#108693](https://github.com/ClickHouse/ClickHouse/issues/108693)에 백포트됨: `DESCRIBE loop('db', 'table')` 및 `DESCRIBE loop(<inner table function>)`가 `SHOW COLUMNS` / 소스 접근 검사를 우회해 권한이 없는 사용자가 테이블의 컬럼 스키마를 읽을 수 있었던 메타데이터 노출 문제를 수정했습니다. [#108624](https://github.com/ClickHouse/ClickHouse/pull/108624) ([Groene AI](https://github.com/groeneai)).
