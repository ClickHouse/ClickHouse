  #### 성능 개선

* [#92312](https://github.com/ClickHouse/ClickHouse/issues/92312)에 백포트됨: Https://github.com/clickhouse/clickhouse/pull/84477에서 병렬 분산 실행을 위해 `insert select from s3cluster()` 쿼리에서 사용할 수 있는 select 쿼리에 대한 제약 조건을 추가했습니다. 이 변경으로 기존에 가능했던 where를 다시 사용할 수 있게 되었습니다. [#84611](https://github.com/ClickHouse/ClickHouse/pull/84611) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="improvement">
  #### 개선 사항
</div>

* [#93375](https://github.com/ClickHouse/ClickHouse/issues/93375)에서 백포트됨: Azure Blob Storage에서 네이티브 복사가 `BadRequest`로 실패할 경우(예: 잘못된 block list) 읽기-쓰기 복사로 폴백합니다. 이전에는 서로 다른 스토리지 계정 간에 blob을 복사할 때 발생하는 인증되지 않음 오류에 대해서만 이렇게 처리했습니다. 하지만 &quot;The specified block list is invalid&quot; 오류도 간헐적으로 발생합니다. 이에 따라 이제는 네이티브 복사가 실패하는 모든 경우에 읽기 및 쓰기 방식으로 폴백하도록 조건을 업데이트했습니다. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#93336](https://github.com/ClickHouse/ClickHouse/issues/93336)에서 백포트됨: `flipCoordinates`에서 geometry type을 지원합니다. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#93123](https://github.com/ClickHouse/ClickHouse/issues/93123)에 백포트됨: 와일드카드 권한 부여에 대한 접근 권한 검사에서 잘못된 로직을 수정했습니다. 이전 시도인 [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928)은 치명적인 취약점을 해결했지만, 지나치게 제한적으로 적용되어 무관한 revoke로 인해 일부 와일드카드 `GRANT` SQL 문이 실패하는 문제가 있었습니다. [#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* [#93222](https://github.com/ClickHouse/ClickHouse/issues/93222)에 백포트됨: JSON에서 경로 &#39;skip&#39;에 대한 type hint 생성 문제를 수정했습니다. [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731)을 해결합니다. [#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93182](https://github.com/ClickHouse/ClickHouse/issues/93182)에 백포트됨: ALTER를 통해 `ratio_of_defaults_for_sparse_serialization` 설정을 `1.0`으로 변경한 뒤, 희소 컬럼 mutation 후 `FILE_DOESNT_EXIST` 오류가 발생할 수 있는 문제를 수정했습니다. [#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93046](https://github.com/ClickHouse/ClickHouse/issues/93046)에 백포트됨: WHERE에서 `not materialize(...)` 또는 `not CAST(...)`를 사용할 때 데이터 스키핑 로직에 버그가 있어 잘못된 결과가 발생하는 문제를 수정했습니다. [#88536](https://github.com/ClickHouse/ClickHouse/issues/88536)을 해결합니다. [#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#93057](https://github.com/ClickHouse/ClickHouse/issues/93057)에 백포트됨: 분산 쿼리를 사전 취소한 뒤 연결이 손상된 상태로 남는 문제를 수정했습니다. [#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)).
* [#93311](https://github.com/ClickHouse/ClickHouse/issues/93311)에 백포트됨: 머지 중 프로젝션을 다시 빌드할 때 사용되지 않는 컬럼을 제거합니다. 이를 통해 메모리 사용량을 줄이고 임시 파트를 덜 생성합니다. [#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
