* [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653)에 백포트됨: plain&#95;rewritable 디스크에서 Azure blob storage의 빈 blob을 읽을 때 발생하던 `416 The range specified is invalid for the current size of the resource.
