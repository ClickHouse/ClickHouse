* [#95806](https://github.com/ClickHouse/ClickHouse/issues/95806)에 백포트: 여러 조인을 `USING` 절과 함께 사용할 때 원본 테이블의 한정된 컬럼에 대한 타입 추론을 수정했습니다. 이전에는 해당 컬럼이 그 조인에 관여하지 않았더라도, 후속 조인이 기반 원본 컬럼의 타입을 공통 supertype으로 잘못 갱신했습니다(예: `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)`에서는 `t2.a` 컬럼이 첫 번째 조인에만 사용되므로, 그 타입은 `t1.a`와 `t2.a`의 supertype이어야 하며 `t3.a`는 제외되어야 합니다). 이 문제로 인해 실행 계획(Execution Plan)에 실제로 나타나는 컬럼 타입과 함수가 기대하는 타입이 달라질 경우 logical error나 크래시가 발생할 수 있었습니다.
