<div id="improvement">
  #### 개선 사항
</div>

* [#102324](https://github.com/ClickHouse/ClickHouse/issues/102324)에 백포트됨: 서버 환경 변수에 대한 접근을 방지하기 위해 내장 클라이언트(SSH 및 WebSocket 프로토콜)에서 AI SQL 생성(`??` 명령)을 비활성화했습니다. [#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#102339](https://github.com/ClickHouse/ClickHouse/issues/102339)에 백포트됨: result table이 웹 컴포넌트로 리팩터링된 후 play.html web UI에서 컬럼 크기 조정이 올바르게 동작하도록 수정했습니다. [#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#101947](https://github.com/ClickHouse/ClickHouse/issues/101947)에 백포트됨: server 시작 시 cache loading을 최적화했습니다. [#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102138](https://github.com/ClickHouse/ClickHouse/issues/102138)에 백포트됨: 내부 mongo-c-driver를 2.2.2에서 2.2.3으로 업데이트했습니다. [#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#102277](https://github.com/ClickHouse/ClickHouse/issues/102277)에 백포트됨: `addStreams` 중 스트림 생성자가 예외를 발생시켜 `column_streams`에 null 항목이 남는 경우 `MergeTreeDataPartWriterWide::cancel`에서 발생하는 SIGSEGV를 수정했습니다. [#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102265](https://github.com/ClickHouse/ClickHouse/issues/102265)에 백포트됨: 파일 시스템 캐시 26.1+의 SLRU 경쟁 상태 버그를 수정했습니다. 이 버그는 공간 예약 logical error를 유발할 수 있습니다. 디버그 build에서는 다음과 같은 assert 실패로 이어질 수도 있습니다: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102172](https://github.com/ClickHouse/ClickHouse/issues/102172)에 백포트됨: `ZooKeeperRetriesControl`가 오래된(만료된) ZooKeeper session을 갱신하지 않은 채 retry하면서 발생하던 UDF 갱신 크래시를 수정했습니다. [#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)).
* [#102237](https://github.com/ClickHouse/ClickHouse/issues/102237)에 백포트됨: WHERE 절이 있는 VIEW를 쿼리할 때 내부 쿼리에서 VIEW metadata와 다른 타입의 컬럼(예: `join_use_nulls`를 사용하는 LEFT JOIN의 Nullable)을 생성하면 발생하던 크래시(SIGSEGV)를 수정했습니다. [#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
