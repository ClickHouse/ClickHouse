<div id="improvement">
  #### 개선 사항
</div>

* [#104213](https://github.com/ClickHouse/ClickHouse/issues/104213)에 백포트됨: 쿼리 구조는 유지하면서 식별자와 리터럴을 무작위 플레이스홀더로 대체해 SQL 쿼리 문자열을 난독화하는 SQL 함수 `obfuscateQuery` 및 `obfuscateQueryWithSeed`를 추가했습니다. 또한 짧은 식별자와 지나치게 큰 정수 리터럴에 대한 쿼리 난독화의 특수한 경우도 수정했습니다. [#101027](https://github.com/ClickHouse/ClickHouse/pull/101027) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#104224](https://github.com/ClickHouse/ClickHouse/issues/104224)에 백포트됨: `MATERIALIZED` CTE가 포함된 쿼리를 실행할 때 발생하는 메모리 누수를 수정했습니다. [#104153](https://github.com/ClickHouse/ClickHouse/pull/104153) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#104211](https://github.com/ClickHouse/ClickHouse/issues/104211)에 백포트됨: stream 할당이 실패할 때 `MergeTreeDataPartWriterCompact::cancel`에서 발생하는 정의되지 않은 동작을 수정했습니다. [#101292](https://github.com/ClickHouse/ClickHouse/pull/101292) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#104151](https://github.com/ClickHouse/ClickHouse/issues/104151)에 백포트됨: row policies/additional&#95;table&#95;filters 사용 시 단순 LIMIT 최적화를 비활성화했습니다(병렬 인덱스 분석을 허용하기 위해). [#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* [#104244](https://github.com/ClickHouse/ClickHouse/issues/104244)에 백포트됨: 26.x에서 한 분기에 `Decimal` 결과 유형과 `Decimal`이 아닌 리터럴(정수 또는 부동소수점)이 함께 사용된 JIT 컴파일 `if` 및 `multiIf`가 아무 경고 없이 실제보다 `10^scale`배 작은 값을 반환하던 데이터 정확성 회귀를 수정했습니다. 느린(non-JIT) 경로는 영향을 받지 않았습니다. 영향을 받는 버전의 우회 방법: `SET compile_expressions = 0`. [#103809](https://github.com/ClickHouse/ClickHouse/pull/103809) ([Groene AI](https://github.com/groeneai)).
* [#104147](https://github.com/ClickHouse/ClickHouse/issues/104147)에 백포트됨: 25.12 이전의 deserialize+serialize 사이클로 저장된 `alpha_size`가 증가한 `AggregateFunction(topK(N), String)` 컬럼을 읽을 때 발생하는 `SIZES_OF_ARRAYS_DONT_MATCH`를 수정했습니다. [#104002](https://github.com/ClickHouse/ClickHouse/pull/104002) ([Raúl Marín](https://github.com/Algunenano)).
* [#104195](https://github.com/ClickHouse/ClickHouse/issues/104195)에 백포트됨: `quantileTiming` 상태를 deserialize하는 동안 발생하던 경계 밖 쓰기 문제를 수정했습니다. [#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
