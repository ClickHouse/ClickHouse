<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#98752](https://github.com/ClickHouse/ClickHouse/issues/98752)에 백포트됨: 기본적으로 async insert를 활성화합니다. 이제 ClickHouse는 모든 소규모 삽입을 기본적으로 배칭합니다. 이 설정은 compatibility에서 지정합니다. `compatibility=<version less than 26.2>`로 설정하면 기본값은 이전 값인 `false`가 됩니다. async inserts는 여러 수준에서 비활성화하거나 활성화할 수 있습니다. 사용자 프로필 구성에서, session에서, 쿼리에서, 또는 MergeTree table에서 설정할 수 있습니다. [#97590](https://github.com/ClickHouse/ClickHouse/pull/97590) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 개선 사항
</div>

* [#98785](https://github.com/ClickHouse/ClickHouse/issues/98785)에 백포트됨: 새로운 설정 `allow_nullable_tuple_in_extracted_subcolumns`은 `Tuple`, `Variant`, `Dynamic`, `JSON`에서 추출한 `Tuple(...)` 서브컬럼을 `Nullable(Tuple(...))`로 반환할지(`NULL`은 누락된 행) 또는 `Tuple(...)`로 반환할지(누락된 행에는 기본 `Tuple` 값) 제어합니다. 이 설정은 기본적으로 비활성화되어 있으며, 값을 변경하려면 서버를 재시작해야 합니다. [#97299](https://github.com/ClickHouse/ClickHouse/pull/97299) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#98481](https://github.com/ClickHouse/ClickHouse/issues/98481)에 백포트됨: jemalloc의 `lg_prof_sample`을 제어하고 이를 `jemalloc.prof.lg_sample` 비동기 메트릭으로 노출하는 서버 설정 `jemalloc_profiler_sampling_rate`를 추가했습니다. [#97945](https://github.com/ClickHouse/ClickHouse/pull/97945) ([Antonio Andelic](https://github.com/antonio2368)).
* [#98488](https://github.com/ClickHouse/ClickHouse/issues/98488)에 백포트됨: 다중 요청 내 각 하위 요청을 개별적으로 집계하여 실제 Keeper 워크로드를 더 잘 파악할 수 있도록 새로운 프로파일 이벤트 `KeeperRequestTotalWithSubrequests`를 추가했습니다. 기존 `KeeperRequestTotal` 이벤트는 계속해서 각 다중 요청을 단일 요청으로 계산합니다. [#98348](https://github.com/ClickHouse/ClickHouse/pull/98348) ([Antonio Andelic](https://github.com/antonio2368)).
* [#98749](https://github.com/ClickHouse/ClickHouse/issues/98749)에 백포트됨: 분산 인덱스 분석에는 &quot;활성 상태&quot;(즉, 연결 가능한)의 레플리카만 참여합니다. [#98521](https://github.com/ClickHouse/ClickHouse/pull/98521) ([Azat Khuzhin](https://github.com/azat)).
