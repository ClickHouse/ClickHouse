* [#108279](https://github.com/ClickHouse/ClickHouse/issues/108279)에 백포트되었습니다: MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg 및 Paimon 포맷에서 매우 깊게 중첩된 스키마 또는 값을 읽을 때 발생할 수 있던 서버 스택 오버플로우(크래시) 문제를 수정했습니다. 이제 이렇게 깊게 중첩된 입력은 예외와 함께 거부됩니다. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* [#108237](https://github.com/ClickHouse/ClickHouse/issues/108237)에 백포트되었습니다: Elf 및 DWARF 파싱에 누락되어 있던 경계 검사(bounds checks)를 추가했습니다. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108157](https://github.com/ClickHouse/ClickHouse/issues/108157)에 백포트되었습니다: Apache Arrow Java &lt; 19.0.0(Apache Spark 포함)으로 생성된 빈 `String`/`Binary` 컬럼이 있는 Arrow/ArrowStream 데이터를 읽을 때 더 이상 `INCORRECT_DATA`를 throw하지 않습니다. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
