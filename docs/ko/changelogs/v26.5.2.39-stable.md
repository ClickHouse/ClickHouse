* [#106038](https://github.com/ClickHouse/ClickHouse/issues/106038)에 백포트됨: 설정 `show_data_lake_catalogs_in_system_tables`의 이름이 `show_remote_databases_in_system_tables`로 변경되었으며 적용 범위도 넓어졌습니다. 값이 0(기본값)인 경우 데이터 레이크 카탈로그뿐 아니라 `MySQL` 및 `PostgreSQL` 데이터베이스도 `system.tables`, `system.columns`, `system.completions`에서 숨겨집니다. 이전 설정 이름도 별칭(alias)으로 유지됩니다. [#104416](https://github.com/ClickHouse/ClickHouse/pull/104416) ([Pablo Marcos](https://github.com/pamarcos)).

[#102570](https://github.com/ClickHouse/ClickHouse/pull/102570) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

[#106108](https://github.com/ClickHouse/ClickHouse/pull/106108) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#105806](https://github.com/ClickHouse/ClickHouse/issues/105806)에서 백포트됨: `INSERT INTO FUNCTION hdfs(...)`를 통해 HDFS에 Parquet(및 ORC, Arrow 등 트레일러를 포함하는 다른 포맷)을 쓸 때 발생하던 데이터 손상을 수정했습니다. 26.1부터 `WriteBufferFromHDFS`가 `finalize()` 시 작업 버퍼를 플러시하지 않아 각 파일의 마지막 최대 `DBMS_DEFAULT_BUFFER_SIZE`바이트가 조용히 유실되었으며, 여기에는 Parquet `PAR1` 푸터도 포함되었습니다. 이러한 파일을 읽으면 `Not a Parquet file (wrong magic bytes at the end of file)`가 반환되었습니다. [#103268](https://github.com/ClickHouse/ClickHouse/pull/103268) ([Groene AI](https://github.com/groeneai)).
* [#105755](https://github.com/ClickHouse/ClickHouse/issues/105755)에서 백포트됨: 이제 `LEFT ANTI JOIN`은 일치하지 않는 행에 대해 왼쪽 키 값을 복제하는 대신, 기본값이 설정된 오른쪽 조인 키 컬럼을 올바르게 반환합니다. 이전에는 `SELECT a.x AS l, b.x AS r FROM a LEFT ANTI JOIN b ON a.x = b.x`가 일치하지 않는 행에 대해 기본값(`Int32`의 경우 `0`, `String`의 경우 `''`, `Nullable`의 경우 `NULL`)을 반환해야 하지만 `r = a.x`를 반환할 수 있었습니다. 영향받은 것은 조인 키 컬럼뿐이었고, 키가 아닌 오른쪽 컬럼은 이미 기본값으로 올바르게 처리되고 있었습니다. 동일한 버그는 옵티마이저가 좌우를 바꾼 경우 `RIGHT ANTI JOIN`에서도 발생했습니다. [#99959](https://github.com/ClickHouse/ClickHouse/issues/99959) 닫음. [#105278](https://github.com/ClickHouse/ClickHouse/pull/105278) ([Groene AI](https://github.com/groeneai)).
* [#105670](https://github.com/ClickHouse/ClickHouse/issues/105670)에서 백포트됨: `catalog_type = 'glue'`로 설정된 `DataLakeCatalog` 데이터베이스에서 장시간 실행되는 `INSERT ... SELECT` 및 기타 읽기 작업은, 테이블 메타데이터 로드 시점에 가져온 STS 세션 자격 증명의 만료 시간이 지나면 `Code: 117. DB::Exception: IOError: Code: 499. DB::Exception: Unable to parse ExceptionName: ExpiredToken Message: The provided token has expired. (S3_ERROR) ... While executing ParquetBlockInputFormat: While executing ReadFromObjectStorage. (INCORRECT_DATA)`와 함께 실패합니다. [#105381](https://github.com/ClickHouse/ClickHouse/pull/105381) ([Pratima Patel](https://github.com/pratimapatel2008)).
* [#105768](https://github.com/ClickHouse/ClickHouse/issues/105768)에서 백포트됨: 일부 경우 `ARRAY JOIN`과 함께 사용할 때 음수 `LIMIT BY`에서 발생하는 logical error를 수정했습니다. [#105403](https://github.com/ClickHouse/ClickHouse/pull/105403) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#105622](https://github.com/ClickHouse/ClickHouse/issues/105622)에서 백포트됨: 바이너리 또는 문자열 컬럼에서 중간 offsets가 손상된 Arrow 또는 ArrowStream 파일을 읽을 때 발생하는 heap-buffer-overflow와, geo 태그가 지정된 Arrow 컬럼을 읽을 때 발생하는 null-pointer 역참조를 수정했습니다. [#105449](https://github.com/ClickHouse/ClickHouse/pull/105449) ([Raúl Marín](https://github.com/Algunenano)).
* [#105884](https://github.com/ClickHouse/ClickHouse/issues/105884)에서 백포트됨: 기본 인수가 `Nullable` 표현식이고, 찾은 딕셔너리 키와 찾지 못한 딕셔너리 키가 섞여 있으며 `short_circuit_function_evaluation`이 활성화된 경우 `dictGetOrDefault`가 `CANNOT_INSERT_NULL_IN_ORDINARY_COLUMN`을 발생시키는 문제를 수정했습니다. [#104901](https://github.com/ClickHouse/ClickHouse/issues/104901) 닫음. [#105464](https://github.com/ClickHouse/ClickHouse/pull/105464) ([Pavel Kruglov](https://github.com/Avogar)).

WITH ROLLUP`, `WITH CUBE`, 또는 `WITH TOTALS`와 함께 널 허용 인수를 사용할 때 `uniqStateOrNull` / `uniqStateOrDefault` / `uniqOrNullState`(및 `uniq`에 대한 유사한 combinator 체인)에서 발생하는 server segfault를 수정했습니다.
