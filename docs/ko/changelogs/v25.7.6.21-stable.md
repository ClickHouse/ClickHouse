* [#86504](https://github.com/ClickHouse/ClickHouse/issues/86504)에 백포트됨: 특정 채널에서만 JSON 로깅을 활성화할 수 있는 기능을 추가했습니다. 이를 위해 `logger.formatting.channel`을 `syslog`/`console`/`errorlog`/`log` 중 하나로 설정하십시오. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#86112](https://github.com/ClickHouse/ClickHouse/issues/86112)에 백포트됨: `distributed_depth`를 *Cluster 함수의 지표로 사용하는 것은 잘못되었으며, 데이터 중복이 발생할 수 있습니다. 대신 `client_info.collaborate_with_initiator`를 사용하십시오. [#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#86266](https://github.com/ClickHouse/ClickHouse/issues/86266)에 백포트됨: `DatabaseReplicated`에서 `CREATE ... AS (SELECT * FROM s3Cluster(...))`를 시도할 때 발생하는 논리 오류를 수정했습니다. [#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#86163](https://github.com/ClickHouse/ClickHouse/issues/86163)에 백포트됨: 이제 Unity Catalog는 non-delta 테이블에서는 비정상적인 데이터 타입이 포함된 스키마를 무시합니다. [#85699](https://github.com/ClickHouse/ClickHouse/issues/85699)를 수정합니다. [#85950](https://github.com/ClickHouse/ClickHouse/pull/85950) ([alesapin](https://github.com/alesapin)).
* [#86291](https://github.com/ClickHouse/ClickHouse/issues/86291)에 백포트됨: 테이블(예: `ReplacingMergeTree`)이 setting `index_granularity_bytes = 0`으로 생성된 경우, 스킵 인덱스가 있는 `FINAL` 쿼리에서 예외가 발생했습니다. 이제 이 예외가 수정되었습니다. [#86147](https://github.com/ClickHouse/ClickHouse/pull/86147) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#86308](https://github.com/ClickHouse/ClickHouse/issues/86308)에 백포트됨: 하나의 INSERT에 const 블록과 non-const 블록이 함께 있는 경우 발생하는 크래시를 수정했습니다. [#86230](https://github.com/ClickHouse/ClickHouse/pull/86230) ([Azat Khuzhin](https://github.com/azat)).
* [#86348](https://github.com/ClickHouse/ClickHouse/issues/86348)에 백포트됨: ALTER UPDATE Nullable(JSON) 수행 중 발생하는 크래시를 수정했습니다. [#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86454](https://github.com/ClickHouse/ClickHouse/issues/86454)에 백포트됨: materialized view의 버그를 수정했습니다. MV를 생성한 뒤 삭제하고 같은 이름으로 다시 생성하면 동작하지 않을 수 있었습니다. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#86466](https://github.com/ClickHouse/ClickHouse/issues/86466)에 백포트됨: `Buffer` 테이블로 인해 발생하던 `MergesMutationsMemoryTracking` 누수를 수정하고, `Kafka`(및 기타)에서 스트리밍할 때의 `query_views_log`도 수정했습니다. [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
