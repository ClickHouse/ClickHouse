* [#76228](https://github.com/ClickHouse/ClickHouse/issues/76228)에서 백포트: PSQL 복제에서 처리되지 않은 예외로 인해 발생하는 크래시를 수정했습니다. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* [#76245](https://github.com/ClickHouse/ClickHouse/issues/76245)에서 백포트: Sasl은 어떤 RPC 호출에서든 실패할 수 있으므로, 이번 수정으로 krb5 ticket이 만료된 경우 호출을 재시도할 수 있습니다. [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* [#75403](https://github.com/ClickHouse/ClickHouse/issues/75403)에서 백포트: `optimize_function_to_subcolumns` 설정이 활성화된 상태에서 `Array`, `Map`, `Nullable(..)` 컬럼에 대한 인덱스(기본 및 보조) 사용을 수정했습니다. 이전에는 이러한 컬럼의 인덱스가 무시될 수 있었습니다. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* [#76102](https://github.com/ClickHouse/ClickHouse/issues/76102)에서 백포트: LowCardinality 널 허용 데이터 타입에 대한 null-safe JOIN 처리를 수정했습니다. 이전에는 `IS NOT DISTINCT FROM`, `<=>` , `a IS NULL AND b IS NULL OR a == b`와 같은 null-safe 비교를 사용하는 JOIN ON이 LowCardinality 컬럼에서 올바르게 동작하지 않았습니다. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#75566](https://github.com/ClickHouse/ClickHouse/issues/75566)에서 백포트: Keeper 수정: 로그를 롤백할 때 손상된 changelog에 쓰지 않도록 했습니다. [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75742](https://github.com/ClickHouse/ClickHouse/issues/75742)에서 백포트: Protobuf 포맷 출력과 `SYSTEM DROP FORMAT SCHEMA CACHE` 쿼리가 병렬로 실행되는 동안 발생할 수 있는 Protobuf 스키마 캐시 크래시를 수정했습니다. [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* [#76094](https://github.com/ClickHouse/ClickHouse/issues/76094)에서 백포트: Array 타입의 JSON 서브컬럼이 분산 테이블에 대한 JOIN에 사용될 때 발생할 수 있는 `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes` 오류를 수정했습니다. [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75890](https://github.com/ClickHouse/ClickHouse/issues/75890)에서 백포트: 서로 다른 타입의 컬럼 사이에서 여러 비동기 `RENAME` 쿼리(`alter_sync = 0`)를 수행한 뒤 `MergeTree` 테이블을 읽을 때 드물게 발생하던 크래시를 수정했습니다. [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* [#75831](https://github.com/ClickHouse/ClickHouse/issues/75831)에 백포트됨: `DistinctSortedStreamTransform`의 null 포인터 역참조 문제를 수정했습니다. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* [#76215](https://github.com/ClickHouse/ClickHouse/issues/76215)에 백포트됨: `clickhouse-library-bridge`는 파일 시스템에서 임의의 라이브러리를 열 수 있으므로 격리된 환경 내부에서만 실행하는 것이 안전합니다. `clickhouse-server`와 가까운 환경에서 실행할 때 발생할 수 있는 취약점을 방지하기 위해, 라이브러리 경로를 구성에서 제공된 위치로 제한할 예정입니다. 이 취약점은 **Arseniy Dugin**이 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986)을 통해 발견했습니다. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
