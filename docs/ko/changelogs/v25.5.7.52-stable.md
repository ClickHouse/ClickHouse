<div id="improvement">
  #### 개선 사항
</div>

* [#83014](https://github.com/ClickHouse/ClickHouse/issues/83014)에 백포트됨: Keeper 개선: 백그라운드 스레드에서 디스크 간 changelog 파일을 이동합니다. 이전에는 changelog를 다른 디스크로 이동하면 이동이 완료될 때까지 Keeper 전체 동작이 차단되었습니다. 이동에 오랜 시간이 걸리는 경우(예: S3 디스크로 이동) 성능 저하로 이어졌습니다. [#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)).
* [#83268](https://github.com/ClickHouse/ClickHouse/issues/83268)에 백포트됨: `clickhouse-benchmark`의 `--reconnect` 옵션에 설정된 잘못된 기본값을 수정했습니다. 이 값은 [#79465](https://github.com/ClickHouse/ClickHouse/issues/79465)에서 실수로 변경되었습니다. [#82677](https://github.com/ClickHouse/ClickHouse/pull/82677) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#83152](https://github.com/ClickHouse/ClickHouse/issues/83152)에 백포트됨: `system.s3queue_log`에 `commit_time`, `commit_id` 컬럼을 추가했습니다. [#83016](https://github.com/ClickHouse/ClickHouse/pull/83016) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#83634](https://github.com/ClickHouse/ClickHouse/issues/83634)에 백포트됨: `distributed_ddl_output_mode='*_only_active'`일 때 `max_replication_lag_to_enqueue`보다 복제 지연이 큰 새 레플리카 또는 복구된 레플리카는 기다리지 않도록 했습니다. 이렇게 하면 초기화 또는 복구를 마친 뒤 새 레플리카가 활성화되었지만, 초기화 중에 대량의 복제 로그가 누적된 경우 `DDL task is not finished on some hosts`를 방지하는 데 도움이 됩니다. 또한 복제 로그가 `max_replication_lag_to_enqueue` 미만으로 내려갈 때까지 기다리는 `SYSTEM SYNC DATABASE REPLICA STRICT` 쿼리를 추가했습니다. [#83302](https://github.com/ClickHouse/ClickHouse/pull/83302) ([Alexander Tokmakov](https://github.com/tavplubix)).
