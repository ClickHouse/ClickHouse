* [#87742](https://github.com/ClickHouse/ClickHouse/issues/87742)에서 백포트됨: GeoParquet로 인해 클라이언트 프로토콜 오류가 발생하던 문제를 수정했습니다. [#84020](https://github.com/ClickHouse/ClickHouse/pull/84020) ([Michael Kolupaev](https://github.com/al13n321)).
* [#87387](https://github.com/ClickHouse/ClickHouse/issues/87387)에서 백포트됨: 데이터베이스 이름의 오타 교정 힌트를 생성할 때 접근 권한을 확인하도록 수정했습니다. [#85371](https://github.com/ClickHouse/ClickHouse/pull/85371) ([Dmitry Novik](https://github.com/novikd)).
* [#87668](https://github.com/ClickHouse/ClickHouse/issues/87668)에서 백포트됨: 숫자/Decimal 컬럼이 있는 Postgres 데이터베이스 엔진 테이블의 detach/attach 문제를 수정했습니다. [#86480](https://github.com/ClickHouse/ClickHouse/pull/86480) ([Julian Maicher](https://github.com/jmaicher)).
* [#87639](https://github.com/ClickHouse/ClickHouse/issues/87639)에서 백포트됨: CTE에서 계산된 함수 결과가 쿼리에서 비결정적으로 처리되던 문제를 수정했습니다. [#86967](https://github.com/ClickHouse/ClickHouse/pull/86967) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#87808](https://github.com/ClickHouse/ClickHouse/issues/87808)에서 백포트됨: 이제 checkHeaders 함수가 제공된 헤더를 올바르게 검증하고 금지된 헤더를 거부합니다. 원저자: Michael Anastasakis (@michael-anastasakis). [#87172](https://github.com/ClickHouse/ClickHouse/pull/87172) ([Raúl Marín](https://github.com/Algunenano)).
* [#87813](https://github.com/ClickHouse/ClickHouse/issues/87813)에서 백포트됨: 다른 `MergeTree` 테이블을 읽는 서브쿼리와 함께 사용할 때 발생하던 경량 업데이트 문제를 수정했습니다. [#87285](https://github.com/ClickHouse/ClickHouse/pull/87285) ([Anton Popov](https://github.com/CurtizJ)).
* [#87730](https://github.com/ClickHouse/ClickHouse/issues/87730)에서 백포트됨: Buffer 테이블에 대한 select 및 insert 접근 검증 문제를 수정했습니다. [#87545](https://github.com/ClickHouse/ClickHouse/pull/87545) ([pufit](https://github.com/pufit)).
* [#87771](https://github.com/ClickHouse/ClickHouse/issues/87771)에서 백포트됨: View 또는 Materialized View의 SELECT 설정으로 전역 server settings가 덮어써질 수 있던 버그를 수정했습니다. 이 문제는 해당 view가 비동기로 삭제되고 백그라운드 정리가 끝나기 전에 server가 재시작된 경우 발생할 수 있었습니다. [#87603](https://github.com/ClickHouse/ClickHouse/pull/87603) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#87795](https://github.com/ClickHouse/ClickHouse/issues/87795)에서 백포트됨: 오른쪽 행 목록을 사용하지 않을 때 HashJoin 알고리즘에서 출력 block 생성이 잘못되던 문제를 수정했습니다. [#87401](https://github.com/ClickHouse/ClickHouse/issues/87401)을 수정합니다. [#87699](https://github.com/ClickHouse/ClickHouse/pull/87699) ([Dmitry Novik](https://github.com/novikd)).
