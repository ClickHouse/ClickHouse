<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#93844](https://github.com/ClickHouse/ClickHouse/issues/93844)에 백포트됨: 일부 경우 이름에 점이 포함된 컬럼에서 서브컬럼을 읽을 때 발생하던 문제를 수정했습니다. [#81261](https://github.com/ClickHouse/ClickHouse/issues/81261), [#82058](https://github.com/ClickHouse/ClickHouse/issues/82058), [#88169](https://github.com/ClickHouse/ClickHouse/issues/88169)을 해결합니다. [#87205](https://github.com/ClickHouse/ClickHouse/pull/87205) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94156](https://github.com/ClickHouse/ClickHouse/issues/94156)에 백포트됨: 분석기에서 컬럼 별칭의 동적 서브컬럼 해석 문제를 수정했습니다. 이전에는 컬럼 별칭의 동적 서브컬럼이 `getSubcolumn`으로 래핑되어 일부 경우 전혀 해석되지 않을 수 있었습니다. [#91434](https://github.com/ClickHouse/ClickHouse/issues/91434)를 해결합니다. [#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)).
* [#95348](https://github.com/ClickHouse/ClickHouse/issues/95348)에 백포트됨: 재시작 후 interserver 호스트가 변경된 경우 Replicated DB를 ATTACH할 때 발생하던 문제를 수정했습니다. [#93779](https://github.com/ClickHouse/ClickHouse/pull/93779) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#94354](https://github.com/ClickHouse/ClickHouse/issues/94354)에 백포트됨: JSON의 타입이 지정된 경로에 대한 잘못된 검사를 수정했습니다. 이 검사는 [https://github.com/ClickHouse/ClickHouse/pull/92842](https://github.com/ClickHouse/ClickHouse/pull/92842)에서 도입되었으며, 기존 테이블 시작 시 오류를 유발할 수 있습니다. [#94070](https://github.com/ClickHouse/ClickHouse/pull/94070) ([Pavel Kruglov](https://github.com/Avogar)).
* [#95199](https://github.com/ClickHouse/ClickHouse/issues/95199)에 백포트됨: 함수를 서브컬럼으로 최적화하는 기능이 서브컬럼에 적용되지 않던 문제를 수정했습니다. [#94323](https://github.com/ClickHouse/ClickHouse/pull/94323) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94925](https://github.com/ClickHouse/ClickHouse/issues/94925)에 백포트됨: 누락된 컬럼에서 `isNotNull`을 평가할 때 ANY LEFT JOIN 최적화 중 발생하는 크래시를 수정했습니다. [#94600](https://github.com/ClickHouse/ClickHouse/pull/94600) ([Molly](https://github.com/ggmolly)).
* [#94829](https://github.com/ClickHouse/ClickHouse/issues/94829)에 백포트됨: BACKUP/RESTORE 작업의 권한 관련 문제를 수정했습니다. [#94617](https://github.com/ClickHouse/ClickHouse/pull/94617) ([Pablo Marcos](https://github.com/pamarcos)).
* [#95636](https://github.com/ClickHouse/ClickHouse/issues/95636)에 백포트됨: `toWeek`, `toYearWeek`, `toStartOfWeek`, `toLastDayOfWeek`, `toDayOfWeek`가 포함된 프레디케이트에 대해 잘못된 프라이머리 키(primary key) 및 스킵 인덱스(skip index) 프루닝을 수정하고, `LowCardinality(String)`을 사용하는 유효한 쿼리에서 이 함수들 중 일부가 예외를 발생시키던 문제도 수정했습니다. [#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#95147](https://github.com/ClickHouse/ClickHouse/issues/95147)에 백포트됨: `getURLHostRFC` 함수에서 포인터를 역참조하기 전에 경계 검사가 누락되어 있었습니다. 빈 문자열이 `domainRFC`에 전달되면 초기화되지 않은 메모리를 읽어 MSan 오류를 유발할 수 있었습니다. [#94851](https://github.com/ClickHouse/ClickHouse/pull/94851) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#95569](https://github.com/ClickHouse/ClickHouse/issues/95569)에 백포트됨: 이제 `Redis` 테이블 함수의 password 인수는 로그와 시스템 테이블(예: `query_log`)에서 마스킹됩니다. [#95325](https://github.com/ClickHouse/ClickHouse/pull/95325) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
