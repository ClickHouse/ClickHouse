* [#101929](https://github.com/ClickHouse/ClickHouse/issues/101929)에 백포트됨: libarchive를 3.8.5에서 3.8.6으로 업데이트했습니다. [#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)).
* [#101864](https://github.com/ClickHouse/ClickHouse/issues/101864)에 백포트됨: curl을 8.18에서 8.19로 업데이트했습니다. [#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)

[#84856](https://github.com/ClickHouse/ClickHouse/issues/84856) 및 [#82974](https://github.com/ClickHouse/ClickHouse/issues/82974)를 해결합니다. [#89429](https://github.com/ClickHouse/ClickHouse/pull/89429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#94969](https://github.com/ClickHouse/ClickHouse/issues/94969)에 백포트됨: 현재 사용 중인 workload 내부에서 다른 workload를 생성해도 더 이상 크래시가 발생하지 않습니다. [#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)).
* [#96287](https://github.com/ClickHouse/ClickHouse/issues/96287)에 백포트됨: CTE로 폴딩된 상수에 대한 쿼리 조건 캐시 hash 충돌을 수정했습니다. 이 문제로 인해 잘못된 쿼리 결과가 반환될 수 있었습니다. [#96060](https://github.com/ClickHouse/ClickHouse/issues/96060)을 닫습니다. [#96172](https://github.com/ClickHouse/ClickHouse/pull/96172) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#102653](https://github.com/ClickHouse/ClickHouse/issues/102653)에 백포트됨: `ASTColumnsExceptTransformer::transform`에서 발생하는 LOGICAL&#95;ERROR 예외를 수정했습니다. [#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* [#100487](https://github.com/ClickHouse/ClickHouse/issues/100487)에서 백포트됨: JDBC, ODBC 및 NATS connection string의 자격 증명이 이제 쿼리 로그와 `SHOW CREATE` 출력에서 마스킹되어 민감한 정보가 실수로 노출되는 것을 방지합니다. URI 형식 connection string(예: {scheme}://{user}:{password}@{host})의 경우 password 부분만 마스킹되며, 나머지 부분은 debugging이 쉽도록 계속 표시됩니다. 이제 `nats_token` 설정도 마스킹됩니다. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#101470](https://github.com/ClickHouse/ClickHouse/issues/101470)에 백포트됨: Keeper에서 읽기 요청이 멈춰 session이 시간 초과될 수 있는 버그를 수정했습니다. 이 문제는 같은 server에서 서로 관련 없는 다른 session이 정확히 좋지 않은 시점에 종료될 경우 발생할 수 있었습니다. [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* [#99963](https://github.com/ClickHouse/ClickHouse/issues/99963)에 백포트됨: 분석기의 성능 저하를 수정했습니다. `ARRAY JOIN`에서 사용되지 않는 컬럼을 제거합니다. [#99587](https://github.com/ClickHouse/ClickHouse/pull/99587) ([Dmitry Novik](https://github.com/novikd)).
* [#100338](https://github.com/ClickHouse/ClickHouse/issues/100338)에 백포트됨: cross join 및 runtime filter가 포함된 `Dynamic` 컬럼 관련 쿼리에서 발생하던 `LOGICAL_ERROR` 예외를 수정했습니다. 원인은 `hasOnlyNulls` 최적화 경로에서 `ColumnVariant::filter`가 variant 컬럼 포인터를 복제하지 않고 공유했던 데 있습니다. [https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147)을 닫습니다. [#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100885](https://github.com/ClickHouse/ClickHouse/issues/100885)에 백포트됨: `RESTORE` 중 경로 순회(path traversal), 절대 경로, 빈 이름을 거부하도록 backup metadata의 파일 항목 경로를 검증합니다. [#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* [#100916](https://github.com/ClickHouse/ClickHouse/issues/100916)에 백포트됨: LowCardinality 요소를 포함한 Tuple 키에 대해 PREWHERE/WHERE와 함께 `has()` 함수를 사용할 때 발생하던 server 크래시를 수정했습니다. [#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* [#101528](https://github.com/ClickHouse/ClickHouse/issues/101528)에 백포트됨: 일부 catalogs에서 `select * from system.databases` 쿼리 결과의 `SETTINGS` 섹션에 일부 시크릿이 표시될 수 있습니다. 이 PR은 이러한 동작을 방지합니다. [#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102619](https://github.com/ClickHouse/ClickHouse/issues/102619)에 백포트됨: 연결 풀의 use-after-free로 인해 s3Cluster 및 분산 쿼리에서 발생하던 segfault를 수정했습니다. [#100837](https://github.com/ClickHouse/ClickHouse/pull/100837) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101085](https://github.com/ClickHouse/ClickHouse/issues/101085)에 백포트됨: 입력에 비ASCII 바이트가 포함될 때 `ULIDStringToDateTime`에서 발생하던 buffer 오버플로우를 수정했습니다. [#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
