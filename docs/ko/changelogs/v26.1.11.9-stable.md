* [#102655](https://github.com/ClickHouse/ClickHouse/issues/102655)에 백포트됨: `ASTColumnsExceptTransformer::transform`의 LOGICAL&#95;ERROR 예외를 수정했습니다. [#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* [#101418](https://github.com/ClickHouse/ClickHouse/issues/101418)에 백포트됨: StringSearcher.h에서 초기화되지 않은 값을 사용하는 문제를 수정했습니다. [#100225](https://github.com/ClickHouse/ClickHouse/pull/100225) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#102677](https://github.com/ClickHouse/ClickHouse/issues/102677)에 백포트됨: 대기 타이머가 참조 중인 `ProfileEvents::Counters`를 보유한 worker thread보다 더 오래 유지될 때 CPU lease scheduler에서 발생하는 use-after-free 크래시를 수정했습니다. [#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102709](https://github.com/ClickHouse/ClickHouse/issues/102709)에 백포트됨: 파일 시스템 캐시 26.1+의 SLRU 경쟁 상태 버그를 수정했습니다. 이 문제는 공간 예약 logical error로 이어질 수 있습니다. debug build에서는 다음과 같은 assert 실패로도 이어질 수 있습니다: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102750](https://github.com/ClickHouse/ClickHouse/issues/102750)에 백포트됨: 기존 컬렉션에 대해 `CREATE NAMED COLLECTION IF NOT EXISTS`를 실행할 때 `NamedCollection` CurrentMetric이 과도하게 집계되는 문제와, 시작 시 구성 또는 SQL storage에서 로드된 컬렉션에 대해 초기화되지 않는 문제를 수정했습니다. [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507)을 닫습니다. [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* [#102795](https://github.com/ClickHouse/ClickHouse/issues/102795)에 백포트됨: 일부 특수한 경우 &#39;Not found column in block&#39; 예외가 발생하는 행 정책 관련 버그를 수정했습니다. [#102648](https://github.com/ClickHouse/ClickHouse/pull/102648) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#102743](https://github.com/ClickHouse/ClickHouse/issues/102743)에 백포트됨: 대기 중에 갱신 가능 구체화 뷰가 삭제되면 `SYSTEM WAIT VIEW`가 무기한 대기 상태에 머무는 문제를 수정했습니다. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
