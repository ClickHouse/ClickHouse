<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 기본적으로 JSON 포맷에서 64비트 정수를 따옴표로 감싸지 않도록 변경합니다. [#74079](https://github.com/ClickHouse/ClickHouse/pull/74079) ([Pavel Kruglov](https://github.com/Avogar)).
* JSON에서 타입이 서로 다른 값으로 이루어진 배열은 이름 없는 `Tuple` 대신 `Array(Dynamic)`으로 추론합니다. 이전 동작을 사용하려면 `input_format_json_infer_array_of_dynamic_from_array_of_different_types` 설정을 비활성화하십시오. [#80859](https://github.com/ClickHouse/ClickHouse/pull/80859) ([Pavel Kruglov](https://github.com/Avogar)).
* 일관성과 단순성을 위해 S3 지연 시간 메트릭을 히스토그램으로 변경합니다. [#82305](https://github.com/ClickHouse/ClickHouse/pull/82305) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 점이 포함된 식별자가 복합 식별자로 파싱되는 것을 방지하기 위해 기본 표현식에서 해당 식별자를 backticks로 감싸야 합니다. [#83162](https://github.com/ClickHouse/ClickHouse/pull/83162) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* lazy materialization은 분석기와 함께 사용할 때만 활성화됩니다. 이는 분석기 없이 유지보수해야 하는 상황을 피하기 위한 것이며, 경험상 분석기 없이 사용할 경우 일부 문제가 있습니다(예: conditions에서 `indexHint()`를 사용하는 경우). [#83791](https://github.com/ClickHouse/ClickHouse/pull/83791) ([Igor Nikonov](https://github.com/devcrafter)).
* 기본적으로 Parquet 출력 형식에서 `Enum` 타입의 값을 `ENUM` 논리 타입의 `BYTE_ARRAY`로 기록합니다. [#84169](https://github.com/ClickHouse/ClickHouse/pull/84169) ([Pavel Kruglov](https://github.com/Avogar)).
* 기본적으로 MergeTree setting `write_marks_for_substreams_in_compact_parts`를 활성화합니다. 이 설정은 새로 생성된 Compact 파트에서 서브컬럼 읽기 성능을 크게 향상시킵니다. 25.5 미만 버전의 서버는 새 Compact 파트를 읽을 수 없습니다. [#84171](https://github.com/ClickHouse/ClickHouse/pull/84171) ([Pavel Kruglov](https://github.com/Avogar)).
* 이전 `concurrent_threads_scheduler`의 기본값은 `round_robin`이었지만, 많은 수의 단일 스레드 쿼리(예: INSERT)가 있을 때 공정하지 않은 것으로 드러났습니다. 이 변경으로 인해 더 안전한 대안인 `fair_round_robin` scheduler가 기본값이 됩니다. [#84747](https://github.com/ClickHouse/ClickHouse/pull/84747) ([Sergei Trifonov](https://github.com/serxa)).
* ClickHouse는 PostgreSQL 스타일의 Heredoc 구문 `$tag$ string contents... $tag$`를 지원하며, 이는 dollar-quoted string literal이라고도 합니다. 이전 버전에서는 tag에 대한 제약이 더 적어 문장 부호와 공백을 포함한 임의의 문자를 사용할 수 있었습니다. 이로 인해 달러 문자로 시작할 수 있는 식별자와 파싱상 모호성이 발생했습니다. 한편 PostgreSQL은 tag에 단어 문자만 허용합니다. 이 문제를 해결하기 위해 이제 Heredoc tag에는 단어 문자만 포함할 수 있도록 제한합니다. [#84731](https://github.com/ClickHouse/ClickHouse/issues/84731)을 해결합니다. [#84846](https://github.com/ClickHouse/ClickHouse/pull/84846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `azureBlobStorage`, `deltaLakeAzure`, `icebergAzure` 함수가 `AZURE` permission을 올바르게 검증하도록 업데이트되었습니다. 이제 모든 클러스터 변형 함수(`-Cluster` 함수)는 해당 비클러스터 함수에 대해 permission을 검증합니다. 또한 `icebergLocal` 및 `deltaLakeLocal` 함수는 이제 `FILE` permission 검사도 강제합니다. [#84938](https://github.com/ClickHouse/ClickHouse/pull/84938) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 기본적으로 allow&#95;dynamic&#95;metadata&#95;for&#95;data&#95;lakes 설정(테이블 엔진 수준 설정)을 활성화합니다. [#85044](https://github.com/ClickHouse/ClickHouse/pull/85044) ([Daniil Ivanik](https://github.com/divanik)).

<div id="new-feature">
  #### 새 기능
</div>

* Merge 테이블뿐만 아니라 모든 테이블에서 &#95;table 가상 컬럼을 지원합니다. [#63665](https://github.com/ClickHouse/ClickHouse/pull/63665) ([Xiaozhe Yu](https://github.com/wudidapaopao)).
* Kafka와 같은 엔진에서 들어오는 오류 메시지를 보관하기 위한 시스템 테이블입니다. [#68873](https://github.com/ClickHouse/ClickHouse/pull/68873) ([Ilya Golshtein](https://github.com/ilejn)).
* 이 PR에서는 ReplicatedMergeTree의 기존 복원 기능과 유사하게, 복제된 데이터베이스의 데이터베이스 레플리카 복원 기능을 도입합니다. [#73100](https://github.com/ClickHouse/ClickHouse/pull/73100) ([Konstantin Morozov](https://github.com/k-morozov)).
* 다음을 추가하여 [ArrowFlight RPC](https://arrow.apache.org/docs/format/Flight.html) 프로토콜 지원을 구현합니다. - 새로운 테이블 함수 `arrowflight()`: `SELECT * FROM arrowflight('host:port', 'dataset_name')`. [#74184](https://github.com/ClickHouse/ClickHouse/pull/74184) ([zakr600](https://github.com/zakr600)).
* PostgreSQL 프로토콜 `COPY` 명령을 지원합니다. [#74344](https://github.com/ClickHouse/ClickHouse/pull/74344) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* PromQL 방언에 대한 기본 지원이 추가되었습니다. 이를 사용하려면 clickhouse-client에서 `dialect='promql'`을 설정하고, `promql_table_name='X'` 설정으로 TimeSeries 테이블을 지정한 뒤, `rate(ClickHouseProfileEvents_ReadCompressedBytes[1m])[5m:1m]`와 같은 쿼리를 실행하십시오. 또한 PromQL 쿼리를 SQL로 감싸서 사용할 수도 있습니다: `SELECT * FROM prometheusQuery('up', ...);`. 현재는 `rate`, `delta`, `increase` 함수만 지원합니다. 단항/이항 연산자는 지원하지 않습니다. HTTP API도 지원하지 않습니다. [#75036](https://github.com/ClickHouse/ClickHouse/pull/75036) ([Vitaly Baranov](https://github.com/vitlibar)).
* Hive 파티션 스타일 쓰기를 지원하고 읽기 구현을 리팩터링합니다(Hive 파티션 컬럼은 더 이상 가상이 아닙니다). [#76802](https://github.com/ClickHouse/ClickHouse/pull/76802) ([Arthur Passos](https://github.com/arthurpassos)).
* ZooKeeper 연결의 이력 정보를 저장하는 `zookeeper_connection_log` 시스템 테이블을 추가합니다. [#79494](https://github.com/ClickHouse/ClickHouse/pull/79494) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 서버 설정 `cpu_slot_preemption`은 워크로드에 대해 선점형 CPU 스케줄링을 활성화하고, 워크로드 간 CPU time을 max-min 공정 방식으로 할당하도록 보장합니다. CPU 스로틀링을 위한 새로운 workload settings `max_cpus`, `max_cpu_share`, `max_burst_cpu_seconds`도 추가되었습니다. 자세한 내용은 [https://clickhouse.com/docs/operations/workload-scheduling#cpu&#95;scheduling](https://clickhouse.com/docs/operations/workload-scheduling#cpu_scheduling)을 참조하십시오. [#80879](https://github.com/ClickHouse/ClickHouse/pull/80879) ([Sergei Trifonov](https://github.com/serxa)).
* 설정된 쿼리 수 또는 시간 임계값에 도달하면 TCP connection을 종료합니다. [#68000](https://github.com/ClickHouse/ClickHouse/issues/68000)을 해결합니다. [#81472](https://github.com/ClickHouse/ClickHouse/pull/81472) ([Kenny Sun](https://github.com/hwabis)).
* 병렬 레플리카에서 프로젝션 읽기를 지원합니다. 프로젝션 지원 활성화 여부를 제어하기 위한 새로운 설정 `parallel_replicas_support_projection`이 추가되었습니다. 구현을 단순화하기 위해 프로젝션 지원은 `parallel_replicas_local_plan`이 활성화된 경우에만 사용할 수 있습니다. [#82807](https://github.com/ClickHouse/ClickHouse/pull/82807) ([zoomxi](https://github.com/zoomxi)).
* DESCRIBE (SELECT ...) 외에 DESCRIBE SELECT도 지원합니다. [#82947](https://github.com/ClickHouse/ClickHouse/pull/82947) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* mysql&#95;port와 postgresql&#95;port에 보안 연결을 강제합니다. [#82962](https://github.com/ClickHouse/ClickHouse/pull/82962) ([tiandiwonder](https://github.com/tiandiwonder)).
* Iceberg TableEngine에서 position delete를 지원합니다. [#83094](https://github.com/ClickHouse/ClickHouse/pull/83094) ([Daniil Ivanik](https://github.com/divanik)).
* 이제 `JSONExtractCaseInsensitive`(및 `JSONExtract`의 다른 변형)를 사용해 JSON 키를 대소문자 구분 없이 lookup할 수 있습니다. [#83770](https://github.com/ClickHouse/ClickHouse/pull/83770) ([Alistair Evans](https://github.com/alistairjevans)).
* 이제 AI 기반 SQL 생성 기능은 사용 가능한 경우 환경 변수 ANTHROPIC&#95;API&#95;KEY 및 OPENAI&#95;API&#95;KEY에서 자동으로 값을 추론할 수 있습니다. 이를 통해 이 기능을 구성 없이 사용할 수 있는 옵션을 제공합니다. [#83787](https://github.com/ClickHouse/ClickHouse/pull/83787) ([Kaushik Iska](https://github.com/iskakaushik)).
* `system.completions` 테이블을 도입했습니다. [#81889](https://github.com/ClickHouse/ClickHouse/issues/81889)를 해결합니다. [#83833](https://github.com/ClickHouse/ClickHouse/pull/83833) ([|2ustam](https://github.com/RuS2m)).
* CREATE 시 Iceberg 쓰기를 지원합니다. [#83927](https://github.com/ClickHouse/ClickHouse/issues/83927)를 해결합니다. [#83983](https://github.com/ClickHouse/ClickHouse/pull/83983) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 쓰기 작업용 Glue catalog를 지원합니다. [#84136](https://github.com/ClickHouse/ClickHouse/pull/84136) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 새 함수 `nowInBlock64`를 추가했습니다. 예시 사용법: `SELECT nowInBlock64(6)`는 `2025-07-29 17:09:37.775725`를 반환합니다. [#84178](https://github.com/ClickHouse/ClickHouse/pull/84178) ([Halersson Paris](https://github.com/halersson)).
* AzureBlobStorage에 `extra_credentials`를 추가해 client&#95;id 및 tenant&#95;id로 인증할 수 있습니다. [#84235](https://github.com/ClickHouse/ClickHouse/pull/84235) ([Pablo Marcos](https://github.com/pamarcos)).
* DateTime 값을 UUIDv7로 변환하는 함수 `dateTimeToUUIDv7`를 추가했습니다. 예시 사용법: `SELECT dateTimeToUUIDv7(toDateTime('2025-08-15 18:57:56'))`는 `0198af18-8320-7a7d-abd3-358db23b9d5c`를 반환합니다. [#84319](https://github.com/ClickHouse/ClickHouse/pull/84319) ([samradovich](https://github.com/samradovich)).
* `timeSeriesDerivToGrid` 및 `timeSeriesPredictLinearToGrid` 집계 함수를 추가했습니다. 이 함수들은 지정된 시작 timestamp, 종료 timestamp, 그리고 간격으로 정의된 시간 그리드에 맞춰 데이터를 재샘플링하며, 각각 PromQL-like `deriv` 및 `predict_linear`를 계산합니다. [#84328](https://github.com/ClickHouse/ClickHouse/pull/84328) ([Stephen Chi](https://github.com/stephchi0)).
* mysql protocol용 C# 클라이언트를 지원합니다. 이 변경으로 [#83992](https://github.com/ClickHouse/ClickHouse/issues/83992)가 해결됩니다. [#84397](https://github.com/ClickHouse/ClickHouse/pull/84397) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 새 구문 `GRANT READ ON S3('s3://foo/.*') TO user`를 추가했습니다. [#84503](https://github.com/ClickHouse/ClickHouse/pull/84503) ([pufit](https://github.com/pufit)).
* 새 출력 형식으로 `Hash`를 추가했습니다. 이 형식은 결과의 모든 컬럼과 행에 대해 단일 hash value를 계산합니다. 예를 들어 데이터 전송이 병목인 사용 사례에서는 결과의 &quot;fingerprint&quot;를 계산하는 데 유용합니다. 예시: `SELECT arrayJoin(['abc', 'def']), 42 FORMAT Hash`는 `e5f9e676db098fdb9530d2059d8c23ef`를 반환합니다. [#84607](https://github.com/ClickHouse/ClickHouse/pull/84607) ([Robert Schulze](https://github.com/rschu1ze)).
* 쓰기용 Iceberg REST 카탈로그. [#84684](https://github.com/ClickHouse/ClickHouse/pull/84684) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Keeper Multi 쿼리에서 임의의 watch를 설정할 수 있는 기능을 추가했습니다. [#84964](https://github.com/ClickHouse/ClickHouse/pull/84964) ([Mikhail Artemenko](https://github.com/Michicosun)).

* merge-on-read 포맷의 Iceberg에서 ALTER DELETE 뮤테이션을 지원합니다. [#85549](https://github.com/ClickHouse/ClickHouse/pull/85549) ([Konstantin Vedernikov](https://github.com/scanhex12)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* `azureBlobStorage` 테이블 엔진: 가능하면 관리형 아이덴티티 인증 토큰을 캐시하고 재사용하여 스로틀링을 방지합니다. [#79860](https://github.com/ClickHouse/ClickHouse/pull/79860) ([Nick Blakely](https://github.com/niblak)).
* 메모리 효율적인 집계 중 일부 버킷을 순서와 관계없이 전송할 수 있도록 하는 새 로직(설정 `enable_producing_buckets_out_of_order_in_aggregation`로 제어되며 기본적으로 활성화됨)이 추가되었습니다. 일부 집계 버킷의 머지에 다른 버킷보다 훨씬 더 오랜 시간이 걸릴 경우, 그동안 initiator가 더 높은 버킷 ID를 가진 버킷을 머지할 수 있어 성능이 향상됩니다. 단점은 메모리 사용량이 다소 증가할 수 있다는 점이지만(큰 수준은 아닐 것으로 예상됨), [#80179](https://github.com/ClickHouse/ClickHouse/pull/80179) ([Nikita Taranov](https://github.com/nickitat)).
* 새로운 Parquet 리더 구현입니다. 전반적으로 더 빠르며 페이지 수준의 filter pushdown과 PREWHERE를 지원합니다. 현재는 Experimental입니다. 활성화하려면 설정 `input_format_parquet_use_native_reader_v3`를 사용하십시오. [#82789](https://github.com/ClickHouse/ClickHouse/pull/82789) ([Michael Kolupaev](https://github.com/al13n321)).
* 해시 조인 메인 루프 외부에서 `max_joined_block_rows`를 처리합니다. ALL JOIN의 성능이 약간 향상됩니다. [#83216](https://github.com/ClickHouse/ClickHouse/pull/83216) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Azure blob storage용 curl HTTP 클라이언트를 poco HTTP 클라이언트로 대체했습니다. 이 클라이언트들에 대해 S3 설정을 반영한 여러 설정도 도입했습니다. Azure와 S3 모두에 대해 더 공격적인 연결 timeout도 도입했습니다. Azure profile events와 메트릭에 대한 내부 검사도 개선했습니다. 새 클라이언트는 기본적으로 활성화되며, Azure Blob Storage 기반 콜드 쿼리의 지연 시간을 크게 줄여 줍니다. 이전 `Curl` 클라이언트는 `azure_sdk_use_native_client=false` 설정으로 다시 사용할 수 있습니다.
