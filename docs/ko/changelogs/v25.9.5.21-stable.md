[#88668](https://github.com/ClickHouse/ClickHouse/pull/88668) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).

[#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#88892](https://github.com/ClickHouse/ClickHouse/issues/88892)에 백포트됨: `loop` 테이블 함수에 대한 select 접근 검증을 수정했습니다. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* [#88942](https://github.com/ClickHouse/ClickHouse/issues/88942)에 백포트됨: `reverseUTF8` 함수의 버그를 수정했습니다. 이전 버전에서는 길이가 4인 UTF-8 코드 포인트의 바이트를 잘못 뒤집고 있었습니다. 이로써 [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913)이 해결되었습니다. [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#88978](https://github.com/ClickHouse/ClickHouse/issues/88978)에 백포트됨: SQL SECURITY DEFINER를 사용해 VIEW를 생성할 때 `SET DEFINER <current_user>:definer` 접근 권한을 검사하지 않도록 했습니다. [#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit)).
