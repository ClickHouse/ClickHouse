<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#102296](https://github.com/ClickHouse/ClickHouse/issues/102296)에 백포트됨: 맵 서브컬럼을 읽는 중 발생할 수 있는 논리 오류를 수정했습니다. [#100769](https://github.com/ClickHouse/ClickHouse/issues/100769)를 해결했습니다. [#101336](https://github.com/ClickHouse/ClickHouse/issues/101336)를 해결했습니다. [#101641](https://github.com/ClickHouse/ClickHouse/pull/101641) ([Pavel Kruglov](https://github.com/Avogar)).
* [#102267](https://github.com/ClickHouse/ClickHouse/issues/102267)에 백포트됨: 파일 시스템 캐시 26.1+에서 SLRU 경쟁 상태 버그를 수정했습니다. 이 버그는 공간 예약 중 논리 오류를 일으킬 수 있습니다. 디버그 빌드에서는 다음 assert 실패로 이어질 수도 있습니다: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102174](https://github.com/ClickHouse/ClickHouse/issues/102174)에 백포트됨: `ZooKeeperRetriesControl`이 만료된 ZooKeeper 세션을 갱신하지 않은 채 재시도하면서 발생하는 UDF 갱신 크래시를 수정했습니다. [#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)).
