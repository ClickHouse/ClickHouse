<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#79981](https://github.com/ClickHouse/ClickHouse/issues/79981)에서 백포트됨: compact 파트에서 basic 포맷의 variant 판별자 역직렬화 문제를 수정했습니다. 이 문제는 [https://github.com/ClickHouse/ClickHouse/pull/55518](https://github.com/ClickHouse/ClickHouse/pull/55518)에서 도입되었습니다. [#79000](https://github.com/ClickHouse/ClickHouse/pull/79000) ([Pavel Kruglov](https://github.com/Avogar)).
* [#79715](https://github.com/ClickHouse/ClickHouse/issues/79715)에서 백포트됨: Atomic 데이터베이스의 이름을 변경할 때 잘못된 경로를 사용하는 문제를 수정했습니다. [#79569](https://github.com/ClickHouse/ClickHouse/pull/79569) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#80049](https://github.com/ClickHouse/ClickHouse/issues/80049)에서 백포트됨: 가변 길이 포매터(예: `%W`, 즉 요일 `Monday` `Tuesday` 등) 다음에 복합 포매터(한 번에 여러 구성 요소를 출력하는 포매터, 예: `%D`, 즉 미국식 날짜 `05/04/25`)가 올 때 SQL 함수 `formatDateTime`의 결과가 잘못되는 문제를 수정했습니다. [#79835](https://github.com/ClickHouse/ClickHouse/pull/79835) ([Robert Schulze](https://github.com/rschu1ze)).
* [#80113](https://github.com/ClickHouse/ClickHouse/issues/80113)에서 백포트됨: IcebergS3는 count 최적화를 지원하지만 IcebergS3Cluster는 지원하지 않습니다. 그 결과 클러스터 모드에서는 반환되는 `count()` 결과가 레플리카 수의 배수가 될 수 있습니다. [#79844](https://github.com/ClickHouse/ClickHouse/pull/79844) ([wxybear](https://github.com/wxybear)).
* [#80078](https://github.com/ClickHouse/ClickHouse/issues/80078)에서 백포트됨: UNION이 포함된 materialized views가 새 레플리카에서 올바르게 동작하도록 수정했습니다. [#80037](https://github.com/ClickHouse/ClickHouse/pull/80037) ([Samay Sharma](https://github.com/samay-sharma)).
* [#80185](https://github.com/ClickHouse/ClickHouse/issues/80185)에서 백포트됨: ClickHouse 로그에 표시되는 경고 `Cannot find 'kernel' in '[...]/memory.stat'`를 수정했습니다(이슈 [#77410](https://github.com/ClickHouse/ClickHouse/issues/77410)). [#80129](https://github.com/ClickHouse/ClickHouse/pull/80129) ([Robert Schulze](https://github.com/rschu1ze)).
