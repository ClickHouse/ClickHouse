<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#74222](https://github.com/ClickHouse/ClickHouse/issues/74222)에 백포트됨: `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` 이후 일시 중지가 발생하지 않도록 수정했습니다. 백그라운드 작업 스케줄링에 올바른 설정을 가져오도록 했습니다. [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#73889](https://github.com/ClickHouse/ClickHouse/issues/73889)에 백포트됨: Dynamic 및 JSON 컬럼의 squashin 준비 과정을 수정했습니다. 이전에는 일부 경우 타입/경로 제한에 도달하지 않았더라도 shared variant/shared data에 새 타입이 삽입될 수 있었습니다. [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74435](https://github.com/ClickHouse/ClickHouse/issues/74435)에 백포트됨: 딕셔너리 소스에 잘못된 데이터가 포함된 함수가 있을 때 발생하는 segfault를 수정했습니다. [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#74139](https://github.com/ClickHouse/ClickHouse/issues/74139)에 백포트됨: Dynamic 컬럼에서 발생할 수 있는 데이터 불일치를 수정했습니다. `Nested columns sizes are inconsistent with local_discriminators column size` 논리 오류가 발생할 가능성도 수정했습니다. [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74527](https://github.com/ClickHouse/ClickHouse/issues/74527)에 백포트됨: `FINAL` 및 `SAMPLE`이 포함된 쿼리에서 발생하던 `NOT_FOUND_COLUMN_IN_BLOCK`을 수정했습니다. `CollapsingMergeTree`에서 `FINAL`을 사용하는 SELECT 쿼리의 잘못된 결과를 수정하고 `FINAL` 최적화를 활성화했습니다. [#73682](https://github.com/ClickHouse/ClickHouse/pull/73682) ([Anton Popov](https://github.com/CurtizJ)).
* [#74138](https://github.com/ClickHouse/ClickHouse/issues/74138)에 백포트됨: Dynamic/Object 구조의 역직렬화를 수정했습니다. 이 문제는 CANNOT&#95;READ&#95;ALL&#95;DATA 예외로 이어질 수 있었습니다. [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74111](https://github.com/ClickHouse/ClickHouse/issues/74111)에 백포트됨: [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078)을 수정했습니다(S3 Express Support가 동작하지 않던 문제). [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* [#74104](https://github.com/ClickHouse/ClickHouse/issues/74104)에 백포트됨: plain&#95;rewritable 메타데이터를 사용하는 디스크는 여러 서버 인스턴스 간에 공유될 수 있습니다. 한 인스턴스가 메타데이터 객체를 읽는 동안 다른 인스턴스가 이를 수정하는 상황이 발생할 수 있습니다. Azure storage에서 plain&#95;rewritable를 초기화하는 동안 발생하는 객체 없음 오류는 S3에 구현된 동작과 유사하게 무시됩니다. [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* [#74152](https://github.com/ClickHouse/ClickHouse/issues/74152)에 백포트됨: 사용자가 Kafka 테이블 엔진에서 키워드 인수를 지정하는 경우를 수정했습니다. [#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#74173](https://github.com/ClickHouse/ClickHouse/issues/74173)에 백포트됨: 압축된 Memory 엔진 테이블에서 서브컬럼을 읽을 때 발생하는 크래시를 수정했습니다. [#74009](https://github.com/ClickHouse/ClickHouse/issues/74009)을 수정했습니다. [#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat)).
