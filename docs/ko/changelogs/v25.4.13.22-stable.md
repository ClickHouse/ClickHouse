<div id="improvement">
  #### 개선 사항

* [#84033](https://github.com/ClickHouse/ClickHouse/issues/84033)에 백포트됨: cgroup 정보(해당하는 경우, 즉 `memory_worker_use_cgroup`이 설정되어 있고 cgroups를 사용할 수 있는 경우)를 사용해 메모리 추적기(`memory_worker_correct_memory_tracker`)를 보정합니다. [#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#83140](https://github.com/ClickHouse/ClickHouse/issues/83140)에 백포트됨: `lowCardinalityKeys` 함수에서 공유 딕셔너리의 무관한 파트를 사용하지 않도록 했습니다. [#83118](https://github.com/ClickHouse/ClickHouse/pull/83118) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#84105](https://github.com/ClickHouse/ClickHouse/issues/84105)에 백포트됨: Avro 스키마 레지스트리 authentication 세부 정보가 사용자에게 노출되거나 로그에 남지 않도록 마스킹했습니다. [#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#83913](https://github.com/ClickHouse/ClickHouse/issues/83913)에 백포트됨: MergeTree 테이블이 `add_minmax_index_for_numeric_columns=1` 또는 `add_minmax_index_for_string_columns=1`로 생성된 경우, 이후 ALTER 작업 중 인덱스가 구체화되면서 새 레플리카에서 복제된 데이터베이스가 올바르게 초기화되지 않는 문제를 수정했습니다. [#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#83872](https://github.com/ClickHouse/ClickHouse/issues/83872)에 백포트됨: 이름 충돌이 있는 경우 새 분석기가 WITH 절에서 바깥쪽 별칭을 참조할 수 있도록 이전 버전과의 호환성 설정을 도입했습니다. 이 변경으로 [#82700](https://github.com/ClickHouse/ClickHouse/issues/82700)을 해결합니다. [#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* [#84090](https://github.com/ClickHouse/ClickHouse/issues/84090)에 백포트됨: 백업에서 복원할 때 definer 사용자가 백업되지 않을 수 있으며, 이 경우 전체 백업을 사용할 수 없게 됩니다. 이를 해결하기 위해 복원 중 대상 테이블 생성 시의 권한 검사를 미루고, 런타임에만 검사하도록 했습니다. [#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* [#84268](https://github.com/ClickHouse/ClickHouse/issues/84268)에 백포트됨: 쿼리 조건 캐시를 재귀 CTE와 함께 사용할 때 잘못된 결과가 발생하던 문제를 수정했습니다(문제 [#81506](https://github.com/ClickHouse/ClickHouse/issues/81506)). [#84026](https://github.com/ClickHouse/ClickHouse/pull/84026) ([zhongyuankai](https://github.com/zhongyuankai)).
