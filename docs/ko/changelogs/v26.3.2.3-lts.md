  #### 새 기능

* [#100900](https://github.com/ClickHouse/ClickHouse/issues/100900)에서 백포트되었습니다: MergeTree의 맵 컬럼에 버킷 직렬화(`map_serialization_version = 'with_buckets'`)가 추가되었습니다. 키를 해시 기반 버킷으로 분할하므로 단일 키(`m['key']`)를 읽을 때 전체 컬럼 대신 하나의 버킷만 읽으면 되어, 맵 크기에 따라 단일 키 lookup 속도가 2~49배 향상됩니다. 버킷 수와 버킷팅 전략은 새로운 MergeTree 설정인 `map_serialization_version`, `max_buckets_in_map`, `map_buckets_strategy`, `map_buckets_coefficient`, `map_buckets_min_avg_size`로 제어할 수 있습니다. `map_serialization_version_for_zero_level_parts` 설정을 사용하면 삽입 시 쓰기 오버헤드를 피하기 위해 기본 직렬화를 유지하면서, 병합된 파트에는 버킷을 사용할 수 있습니다. `mapKeys/mapValues`에 대한 스킵 인덱스는 버킷 직렬화와 함께 지원됩니다. `optimize_functions_to_subcolumns` 단계는 버킷을 사용할 수 있을 때 `m['key']`를 키별 서브컬럼 읽기로 재작성합니다. [#99200](https://github.com/ClickHouse/ClickHouse/pull/99200) ([Pavel Kruglov](https://github.com/Avogar)).

[#98917](https://github.com/ClickHouse/ClickHouse/issues/98917)을 해결합니다. [#100826](https://github.com/ClickHouse/ClickHouse/pull/100826) ([Nihal Z. Miaji](https://github.com/nihalzp)).
