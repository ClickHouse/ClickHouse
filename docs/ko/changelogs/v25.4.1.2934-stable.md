<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* `allow_materialized_view_with_bad_select`가 `false`인 경우 materialized view의 모든 컬럼이 대상 테이블과 일치하는지 확인합니다. [#74481](https://github.com/ClickHouse/ClickHouse/pull/74481) ([Christoph Wurm](https://github.com/cwurm)).
* 음수 날짜/DateTime 인수와 함께 `dateTrunc`를 사용할 때 발생하는 문제를 수정합니다. [#77622](https://github.com/ClickHouse/ClickHouse/pull/77622) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 기존 MongoDB 통합이 제거되었습니다. 서버 설정 `use_legacy_mongodb_integration`은 폐기되어 이제 아무 작업도 하지 않습니다. [#77895](https://github.com/ClickHouse/ClickHouse/pull/77895) ([Robert Schulze](https://github.com/rschu1ze)).
* 파티션 또는 정렬 키에 사용되는 컬럼은 집계에서 제외하도록 SummingMergeTree 검증을 개선합니다. [#78022](https://github.com/ClickHouse/ClickHouse/pull/78022) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).



<div id="new-feature">
  #### 새 기능
</div>

* [#79232](https://github.com/ClickHouse/ClickHouse/issues/79232)에 백포트됨: 지정된 컬럼에 대해 CREATE 쿼리에서 명시적으로 정의하지 않은 경우 기본 압축 코덱을 지정하는 새로운 옵션이 MergeTree SETTINGS에 추가되었습니다. 이 변경으로 [#42005](https://github.com/ClickHouse/ClickHouse/issues/42005)가 해결됩니다. [#66394](https://github.com/ClickHouse/ClickHouse/pull/66394) ([gvoelfin](https://github.com/gvoelfin)).
* 분산 쿼리에 대해 쿼리 계획을 serialize합니다. 새로운 설정 `serialize_query_plan`이 추가되었습니다. 활성화하면 `Distributed` 테이블의 쿼리는 원격 쿼리 실행에 serialize된 쿼리 계획을 사용합니다. 이에 따라 TCP protocol에 새로운 패킷 유형이 도입되며, 이 패킷의 처리를 허용하려면 서버 설정에 `<process_query_plan_packet>true</process_query_plan_packet>`를 추가해야 합니다. [#69652](https://github.com/ClickHouse/ClickHouse/pull/69652) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 특정 timestamp 기준으로 Iceberg 테이블을 쿼리하는 설정이 추가되었습니다. [#71072](https://github.com/ClickHouse/ClickHouse/pull/71072) ([Brett Hoerner](https://github.com/bretthoerner)).
* 낮은 카디널리티 Decimal 데이터 타입을 지원하고 [#72256](https://github.com/ClickHouse/ClickHouse/issues/72256)를 수정했습니다. [#72833](https://github.com/ClickHouse/ClickHouse/pull/72833) ([zhanglistar](https://github.com/zhanglistar)).
* AzureBlobStorage용 DeltaLake 테이블 엔진을 지원합니다. [#68043](https://github.com/ClickHouse/ClickHouse/issues/68043)를 수정했습니다. [#74541](https://github.com/ClickHouse/ClickHouse/pull/74541) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* clickhouse client 연결에 사용할 소스 IP 주소를 설정하는 `bind&#95;host` 설정이 추가되었습니다. [#74741](https://github.com/ClickHouse/ClickHouse/pull/74741) ([Todd Yocum](https://github.com/toddyocum)).
* system.tables에 `parametrized&#95;view&#95;parameters`가 도입되었습니다. https://github.com/clickhouse/clickhouse/issues/66756 이 해결되었습니다. [#75112](https://github.com/ClickHouse/ClickHouse/pull/75112) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* 데이터베이스 comment 변경이 가능해졌습니다. [#73351](https://github.com/ClickHouse/ClickHouse/issues/73351)을 해결합니다. ### 사용자 대상 변경 사항에 대한 문서 항목. [#75622](https://github.com/ClickHouse/ClickHouse/pull/75622) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* [#79361](https://github.com/ClickHouse/ClickHouse/issues/79361)에 백포트됨: WHERE 절의 `EXISTS` 표현식 인수로 연관된 서브쿼리를 지원합니다. [#72459](https://github.com/ClickHouse/ClickHouse/issues/72459)를 해결합니다. [#76078](https://github.com/ClickHouse/ClickHouse/pull/76078) ([Dmitry Novik](https://github.com/novikd)).
* Scram SHA256 및 postgres wire auth를 업데이트했습니다. [#76839](https://github.com/ClickHouse/ClickHouse/pull/76839) ([scanhex12](https://github.com/scanhex12)).
* manifest files/list와 metadata.json을 하나의 cache에 저장하는 `IcebergMetadataFilesCache`를 지원합니다. [#77156](https://github.com/ClickHouse/ClickHouse/pull/77156) ([Han Fei](https://github.com/hanfei1991)).
* 함수 `arrayLevenshteinDistance`, `arrayLevenshteinDistanceWeighted`, `arraySimilarity`가 추가되었습니다. [#77187](https://github.com/ClickHouse/ClickHouse/pull/77187) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 이전 특정 시점에 존재했던 Iceberg 테이블의 상태를 쿼리할 수 있습니다. [#77439](https://github.com/ClickHouse/ClickHouse/pull/77439) ([Daniil Ivanik](https://github.com/divanik)).
* workload용 CPU slot scheduling이 추가되었습니다. 자세한 내용은 https://clickhouse.com/docs/operations/workload-scheduling#cpu&#95;scheduling 를 참조하십시오. [#77595](https://github.com/ClickHouse/ClickHouse/pull/77595) ([Sergei Trifonov](https://github.com/serxa)).
* 이제 hasAll() 함수에서 tokenbf&#95;v1, ngrambf&#95;v1 전문 텍스트 스킵 인덱스를 활용할 수 있습니다. [#77662](https://github.com/ClickHouse/ClickHouse/pull/77662) ([UnamedRus](https://github.com/UnamedRus)).
* `JSON` 데이터 타입은 프로덕션 환경에서 사용할 수 있습니다. https://jsonbench.com/을 참조하십시오. `Dynamic` 및 `Varaint` 데이터 타입도 프로덕션 환경에서 사용할 수 있습니다. [#77785](https://github.com/ClickHouse/ClickHouse/pull/77785) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 역직렬화된 벡터 유사성 인덱스를 위한 인메모리 캐시가 추가되었습니다. 이에 따라 반복적인 근사 최근접 이웃(ANN) 검색 쿼리가 더 빨라질 수 있습니다. 새 캐시의 크기는 서버 설정 `vector_similarity_index_cache_size` 및 `vector_similarity_index_cache_max_entries`로 제어됩니다. 이 기능은 이전 릴리스의 스킵 인덱스 캐시 기능을 대체합니다. [#77905](https://github.com/ClickHouse/ClickHouse/pull/77905) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#79343](https://github.com/ClickHouse/ClickHouse/issues/79343)에서 백포트됨: TBD. [#78041](https://github.com/ClickHouse/ClickHouse/pull/78041) ([Igor Nikonov](https://github.com/devcrafter)).
* UTF8 버전의 sparseGrams 및 sparseGramsHashes 함수가 추가되었습니다. 작성자: [scanhex12](https://github.com/scanhex12). [#78176](https://github.com/ClickHouse/ClickHouse/pull/78176) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* `toInterval` 함수가 추가되었습니다. 이 함수는 2개의 인수(value 및 unit)를 받아 값을 특정 `Interval` 타입으로 변환합니다. [#78723](https://github.com/ClickHouse/ClickHouse/pull/78723) ([Andrew Davis](https://github.com/pulpdrew)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* lazy projection으로 사용되지 않는 컬럼을 읽지 않도록 하여 성능을 최적화했습니다. [#55518](https://github.com/ClickHouse/ClickHouse/pull/55518) ([Xiaozhe Yu](https://github.com/wudidapaopao)).
* `NativeORCBlockInputFormat`에 async io prefetch를 지원하여 원격 io 지연 시간을 숨김으로써 전체 성능을 개선했습니다. 테스트 사례에서는 최대 1.47배까지 빨라질 수 있습니다. [#70534](https://github.com/ClickHouse/ClickHouse/pull/70534) ([李扬](https://github.com/taiyang-li)).
* 성능 향상을 위해 async inserts에서 사용하는 메모리를 사전 할당합니다. [#74945](https://github.com/ClickHouse/ClickHouse/pull/74945) ([Ilya Golshtein](https://github.com/ilejn)).
* 불필요한 null 맵 할당을 피하기 위해 wrapInNullable에 사소한 최적화를 적용했습니다. [#76489](https://github.com/ClickHouse/ClickHouse/pull/76489) ([李扬](https://github.com/taiyang-li)).
* arraySort를 최적화했습니다. [#76850](https://github.com/ClickHouse/ClickHouse/pull/76850) ([李扬](https://github.com/taiyang-li)).
* `col->insertFrom()` 호출을 de-virtualization하여 JOIN result 생성 속도를 높였습니다. [#77350](https://github.com/ClickHouse/ClickHouse/pull/77350) ([Alexander Gololobov](https://github.com/davenger)).
* 동일한 part의 마크를 머지한 뒤 한 번에 쿼리 조건 캐시에 기록하여 lock 사용을 줄입니다. [#77377](https://github.com/ClickHouse/ClickHouse/pull/77377) ([zhongyuankai](https://github.com/zhongyuankai)).
* bracket expansion이 1개 있는 쿼리에 대해 s3Cluster 성능을 최적화했습니다. [#77686](https://github.com/ClickHouse/ClickHouse/pull/77686) ([Tomáš Hromada](https://github.com/gyfis)).
* 단일 널 허용 또는 low-cardinality 컬럼에 대한 order by를 최적화했습니다. [#77789](https://github.com/ClickHouse/ClickHouse/pull/77789) ([李扬](https://github.com/taiyang-li)).
* 머지와 같이 캐시가 수동적으로 사용될 때는 `filesystem_cache_prefer_bigger_buffer_size`를 비활성화합니다. [#77898](https://github.com/ClickHouse/ClickHouse/pull/77898) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Iceberg에 단순 count 최적화를 구현했습니다. 이제 `count()`가 있고 filter가 없는 쿼리는 더 빨라집니다. [#77639](https://github.com/ClickHouse/ClickHouse/issues/77639)을 닫습니다. [#78090](https://github.com/ClickHouse/ClickHouse/pull/78090) ([alesapin](https://github.com/alesapin)).
* 컬럼의 `lower_bound` 및 `uppert_bound` 값을 기반으로 하는 Iceberg data pruning을 지원합니다. [#77638](https://github.com/ClickHouse/ClickHouse/issues/77638)을 수정합니다. [#78242](https://github.com/ClickHouse/ClickHouse/pull/78242) ([alesapin](https://github.com/alesapin)).
* NativeReader의 메모리 사용량을 최적화했습니다. [#78442](https://github.com/ClickHouse/ClickHouse/pull/78442) ([Azat Khuzhin](https://github.com/azat)).
* 사소한 최적화: CAST가 필요한 경우 `count(if())`를 countIf로 재작성하지 않습니다. [#78564](https://github.com/ClickHouse/ClickHouse/issues/78564)를 닫습니다. [#78565](https://github.com/ClickHouse/ClickHouse/pull/78565) ([李扬](https://github.com/taiyang-li)).
* [#79163](https://github.com/ClickHouse/ClickHouse/issues/79163)에 백포트됨: 이제 병렬 레플리카가 활성화된 읽기에서는 작업 크기를 결정할 때 레플리카 수를 사용합니다. 이를 통해 읽을 데이터 양이 아주 많지 않을 때 레플리카 간 작업 분배가 더 나아집니다. [#78695](https://github.com/ClickHouse/ClickHouse/pull/78695) ([Nikita Taranov](https://github.com/nickitat)).
* [#79190](https://github.com/ClickHouse/ClickHouse/issues/79190)에 백포트됨: 가능하면 filter query plan 단계의 동등 조건을 JOIN 조건으로 머지하여 이를 해시 테이블 키로 사용할 수 있도록 합니다. [#78877](https://github.com/ClickHouse/ClickHouse/pull/78877) ([Dmitry Novik](https://github.com/novikd)).



<div id="improvement">
  #### 개선 사항
</div>

* `multiRead`를 사용할 수 있는 곳에서는 단일 `get` 요청 사용을 제거해 Keeper 요청 수를 줄였습니다. 레플리카 수가 늘어날 경우 이러한 요청이 Keeper에 상당한 부하를 줄 수 있었습니다. [#56862](https://github.com/ClickHouse/ClickHouse/pull/56862) ([Nikolay Degterinsky](https://github.com/evillique)).
* 서버가 과부하 상태이면 쿼리를 거부합니다. 판단은 대기 시간(`OSCPUWaitMicroseconds`)과 busy time(`OSCPUVirtualTimeMicroseconds`)의 비율을 기준으로 합니다. 이 비율이 `min_os_cpu_wait_time_ratio_to_throw`와 `max_os_cpu_wait_time_ratio_to_throw` 사이이면 일정 확률로 쿼리를 중단합니다(둘 다 쿼리 수준 설정). [#63206](https://github.com/ClickHouse/ClickHouse/pull/63206) ([Alexey Katsman](https://github.com/alexkats)).
* 이제 갱신 가능 구체화 뷰의 갱신이 `system.query_log`에 기록됩니다. [#71333](https://github.com/ClickHouse/ClickHouse/pull/71333) ([Michael Kolupaev](https://github.com/al13n321)).
* [#79175](https://github.com/ClickHouse/ClickHouse/issues/79175)에 백포트됨: `--path` 명령줄 인수를 지정하면 `clickhouse-local`이 재시작 후에도 데이터베이스를 유지합니다. 이 변경으로 [#50647](https://github.com/ClickHouse/ClickHouse/issues/50647)이 해결되었습니다. 이 변경으로 [#49947](https://github.com/ClickHouse/ClickHouse/issues/49947)이 해결되었습니다. [#71722](https://github.com/ClickHouse/ClickHouse/pull/71722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 모든 유형의 복제된 작업에 백오프 로직을 활성화했습니다. 이를 통해 CPU 사용량, 메모리 사용량, 로그 파일 크기를 줄일 수 있습니다. `max_postpone_time_for_failed_replicated_fetches_ms`, `max_postpone_time_for_failed_replicated_merges_ms`, `max_postpone_time_for_failed_replicated_tasks_ms`라는 새로운 설정을 추가했으며, 이는 `max_postpone_time_for_failed_mutations_ms`와 유사합니다. [#74576](https://github.com/ClickHouse/ClickHouse/pull/74576) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 두 부분 모두에서 JOIN 키가 PK의 prefix인 경우 JOIN에 동적 세그먼트 분할을 사용합니다. 이 최적화는 `query_plan_join_shard_by_pk_ranges` 설정으로 활성화할 수 있으며(기본값은 비활성화), [#74733](https://github.com/ClickHouse/ClickHouse/pull/74733) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* SSH protocol 지원을 다시 활성화했습니다. 몇 가지 치명적인 취약점을 수정하여 더 이상 사용자 지정 pager를 사용하거나 `server-logs-file`을 지정할 수 없도록 했습니다. 기본적으로 환경 변수를 통해 클라이언트 옵션을 전달하는 기능도 비활성화했습니다(`config.xml`의 `ssh-server.enable_client_options_passing`을 통해서는 여전히 가능합니다). progress 테이블, 쿼리 취소, completion, profile events progress, stdin 및 `send_logs_level` 옵션을 지원합니다. 이 변경으로 다음 이슈가 해결되었습니다: [#74340](https://github.com/ClickHouse/ClickHouse/issues/74340). [#74989](https://github.com/ClickHouse/ClickHouse/pull/74989) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* readonly MergeTree 테이블에서 갱신을 지원합니다. [#76467](https://github.com/ClickHouse/ClickHouse/pull/76467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `system.errors`에 `query_id`를 추가했습니다. 관련 티켓: [#75815](https://github.com/ClickHouse/ClickHouse/issues/75815). [#76581](https://github.com/ClickHouse/ClickHouse/pull/76581) ([Vladimir Baikov](https://github.com/bkvvldmr)).
* View에서 JSON 타입 및 서브컬럼 읽기를 지원합니다. [#76903](https://github.com/ClickHouse/ClickHouse/pull/76903) ([Pavel Kruglov](https://github.com/Avogar)).
* UInt128을 IPv6로 변환하는 기능을 추가했습니다. 이를 통해 IPv6에서 `bitAnd` 연산과 산술 연산을 수행한 뒤 다시 IPv6로 변환할 수 있습니다. [#76752](https://github.com/ClickHouse/ClickHouse/issues/76752)를 해결합니다. 또한 IPv6에 대한 `bitAnd` 연산 결과도 다시 IPv6로 변환할 수 있습니다. 참조: https://github.com/ClickHouse/ClickHouse/pull/57707. [#76928](https://github.com/ClickHouse/ClickHouse/pull/76928) ([Muzammil Abdul Rehman](https://github.com/muzammilar)).
* 기본적으로 Variant 타입 내부의 텍스트 형식에서 특수 Bool 값을 파싱하지 않도록 변경했습니다. setting `allow_special_bool_values_inside_variant`를 사용해 활성화할 수 있습니다. [#76974](https://github.com/ClickHouse/ClickHouse/pull/76974) ([Pavel Kruglov](https://github.com/Avogar)).
* 세션 수준 및 서버 수준에서 낮은 우선순위 쿼리의 작업별 대기 시간을 구성할 수 있도록 지원합니다. [#77013](https://github.com/ClickHouse/ClickHouse/pull/77013) ([VicoWu](https://github.com/VicoWu)).
* PostgreSQL의 CHARACTER, CHAR, BPCHAR에 FixedString을 사용합니다. [#77304](https://github.com/ClickHouse/ClickHouse/pull/77304) ([Pablo Marcos](https://github.com/pamarcos)).
* 데이터베이스가 메타데이터 파일을 저장하기 위해 원격 디스크를 사용할 수 있도록 지원합니다. [#77365](https://github.com/ClickHouse/ClickHouse/pull/77365) ([Tuan Pham Anh](https://github.com/tuanpach)).
* JSON 데이터 타입 값에 대한 비교를 구현했습니다. 이제 JSON 객체를 Map과 유사하게 비교할 수 있습니다. [#77397](https://github.com/ClickHouse/ClickHouse/pull/77397) ([Pavel Kruglov](https://github.com/Avogar)).
