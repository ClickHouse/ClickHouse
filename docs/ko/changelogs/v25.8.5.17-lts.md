<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#87312](https://github.com/ClickHouse/ClickHouse/issues/87312)에 백포트: 25.1 이전에 생성된 KeeperMap 테이블에서 `DROP` 쿼리 후 ZooKeeper에 데이터가 남아 있던 문제를 수정했습니다. [#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#87168](https://github.com/ClickHouse/ClickHouse/issues/87168)에 백포트: 지연 실행 머티리얼라이즈에서 배열 크기 서브컬럼이 있는 배열을 읽을 때 발생하던 문제를 수정했습니다. [#87139](https://github.com/ClickHouse/ClickHouse/pull/87139) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87394](https://github.com/ClickHouse/ClickHouse/issues/87394)에 백포트: `max_temporary_data_on_disk_size` 제한 추적에서 임시 데이터 메모리 해제가 잘못 집계되던 문제를 수정했으며, [#87118](https://github.com/ClickHouse/ClickHouse/issues/87118)을 해결합니다. [#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
* [#87329](https://github.com/ClickHouse/ClickHouse/issues/87329)에 백포트: 비연관 `EXISTS`에서 잘못된 결과가 나올 수 있는 문제를 수정했습니다. 이 문제는 [https://github.com/ClickHouse/ClickHouse/pull/85481](https://github.com/ClickHouse/ClickHouse/pull/85481)에서 도입된 `execute_exists_as_scalar_subquery=1`로 인해 발생했으며 `25.8`에 영향을 줍니다. [#86415](https://github.com/ClickHouse/ClickHouse/issues/86415)를 수정합니다. [#87207](https://github.com/ClickHouse/ClickHouse/pull/87207) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#87437](https://github.com/ClickHouse/ClickHouse/issues/87437)에 백포트: const 블록과 non-const 블록이 섞여 `JOIN`에서 발생하던 &quot;Too large size passed to allocator&quot; `LOGICAL_ERROR`를 수정했습니다. [#87231](https://github.com/ClickHouse/ClickHouse/pull/87231) ([Azat Khuzhin](https://github.com/azat)).
