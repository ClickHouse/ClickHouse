  ### ClickHouse 릴리스 v26.2.9.9-안정 (94b91bf8dcf) FIXME v26.2.8.15-안정 (5f35e27d1a1) 대비

<div id="performance-improvement">
  #### 성능 개선
</div>

* [#101914](https://github.com/ClickHouse/ClickHouse/issues/101914)에 백포트됨: `deduplicate_insert=enable`일 때(26.2부터 기본값) 발생한 중대한 INSERT 성능 회귀를 수정했습니다. 이를 위해 데이터 hash 계산을 squashing 단계가 아니라 싱크 단계로 미루고 `updateHashWithValueRange`를 사용한 배치 컬럼 hashing을 적용해, 22개 컬럼으로 구성된 500만 행 기준 오버헤드를 약 2.5초에서 약 0.5초로 줄였습니다. [#101494](https://github.com/ClickHouse/ClickHouse/pull/101494) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 개선 사항
</div>

* [#101601](https://github.com/ClickHouse/ClickHouse/issues/101601)에 백포트됨: Cgroupv2 메모리 추적에서 이제 커널 메모리 계산 시 `slab_reclaimable`을 제외하여, 회수 불가능한 메모리 사용량을 더 정확하게 측정할 수 있습니다. [#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#101985](https://github.com/ClickHouse/ClickHouse/issues/101985)에 백포트됨: 시작 의존성 순서가 잘못되어 비동기 시작 중 내부 테이블이 있는 구체화된 뷰(Materialized View)에서 &quot;Target table doesn&#39;t exist&quot; 오류가 발생하던 문제를 수정했습니다. [#100946](https://github.com/ClickHouse/ClickHouse/pull/100946) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#102073](https://github.com/ClickHouse/ClickHouse/issues/102073)에 백포트됨: `Object` 타입 동적 경로의 병렬 역직렬화 과정에서 use-after-scope 문제를 수정했으며, 이 문제는 동적 경로가 많은 테이블을 읽을 때 크래시를 일으킬 수 있었습니다. [#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102100](https://github.com/ClickHouse/ClickHouse/issues/102100)에 백포트됨: 특정(기본값이 아닌) 포맷 설정에서 formatter `%W`를 사용할 때 함수 `formatDateTime`의 출력이 잘못되던 문제를 수정했습니다. [#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* [#102028](https://github.com/ClickHouse/ClickHouse/issues/102028)에 백포트됨: 주기적 갱신 중 ZooKeeper 세션이 만료되면 UDF 레지스트리가 손실되는 문제를 수정했습니다 — 전체 갱신(full refresh)이 성공할 때까지 모든 사용자 정의 함수를 사용할 수 없게 될 수 있었습니다. [#101891](https://github.com/ClickHouse/ClickHouse/pull/101891) ([Nikita Fomichev](https://github.com/fm4v)).
* [#102092](https://github.com/ClickHouse/ClickHouse/issues/102092)에 백포트됨: 이제 `splitByString` 토크나이저는 빈 구분자 문자열을 허용하지 않습니다. [#101928](https://github.com/ClickHouse/ClickHouse/pull/101928) ([Robert Schulze](https://github.com/rschu1ze)).
