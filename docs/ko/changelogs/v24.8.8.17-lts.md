<div id="improvement">
  #### 개선 사항

* [#72060](https://github.com/ClickHouse/ClickHouse/issues/72060)에 백포트됨: Dictionary 스토리지, 딕셔너리 테이블 함수, 또는 딕셔너리 자체에 직접 SELECT를 수행해 딕셔너리에서 데이터를 조회할 때, 이제 해당 딕셔너리에 대한 `SELECT` 권한 또는 `dictGet` 권한만 있으면 충분합니다. 이는 ACL 우회를 방지하려는 이전의 시도와도 부합합니다: [https://github.com/ClickHouse/ClickHouse/pull/57362](https://github.com/ClickHouse/ClickHouse/pull/57362) 및 [https://github.com/ClickHouse/ClickHouse/pull/65359](https://github.com/ClickHouse/ClickHouse/pull/65359). 또한 후자의 변경 사항이 이전 버전과 호환되도록 합니다. [#72051](https://github.com/ClickHouse/ClickHouse/pull/72051) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#71981](https://github.com/ClickHouse/ClickHouse/issues/71981)에 백포트됨: [이 이슈](https://github.com/ClickHouse/ClickHouse/pull/59946#issuecomment-1943653197) 이후 운영 환경에서 `metadata_version` node 값이 `0`이면서 동시에 해당 테이블의 `metadata` node 버전과도 일치하지 않는 테이블 레플리카가 꽤 많이 존재합니다. 이로 인해 해당 레플리카에서 `alter` 쿼리가 실패합니다. [#69274](https://github.com/ClickHouse/ClickHouse/pull/69274) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#72142](https://github.com/ClickHouse/ClickHouse/issues/72142)에 백포트됨: Keeper를 사용할 수 없을 때 발생할 수 있는 데이터 손실을 방지하기 위해, part를 zero-copy 디스크로 이동하기 전에 zero-copy 공유 잠금을 획득하도록 했습니다. [#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72038](https://github.com/ClickHouse/ClickHouse/issues/72038)에 백포트됨: 프라이머리 키가 DateTime64 타입인 WHERE 조건에서 `toDayOfWeek`에 대해 발생하는 예외를 수정했습니다. [#71849](https://github.com/ClickHouse/ClickHouse/pull/71849) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#72032](https://github.com/ClickHouse/ClickHouse/issues/72032)에 백포트됨: 첫 번째 인수가 상수일 때 `ORDER BY`에 이진 단조 함수를 사용하는 `MergeTree` 테이블에서 발생하는 `Illegal type` 오류를 수정했습니다. [#71941](https://github.com/ClickHouse/ClickHouse/issues/71941)을 해결합니다. [#71966](https://github.com/ClickHouse/ClickHouse/pull/71966) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#72155](https://github.com/ClickHouse/ClickHouse/issues/72155)에 백포트됨: subquery 내부에서 사용하는 EXPLAIN AST에서는 SELECT 쿼리만 허용합니다. 다른 유형의 쿼리는 &#39;Bad cast from type DB::ASTCreateQuery to DB::ASTSelectWithUnionQuery&#39; 또는 `Inconsistent AST formatting`과 같은 논리 오류를 유발합니다. [#71982](https://github.com/ClickHouse/ClickHouse/pull/71982) ([Pavel Kruglov](https://github.com/Avogar)).
* [#72114](https://github.com/ClickHouse/ClickHouse/issues/72114)에 백포트됨: `format_alter_commands_with_parentheses`가 활성화된 경우 `MOVE PARTITION ... TO TABLE ...` alter 명령의 formatting을 수정했습니다. [#72080](https://github.com/ClickHouse/ClickHouse/pull/72080) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
