<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#100460](https://github.com/ClickHouse/ClickHouse/issues/100460)에서 백포트됨: 이제 JDBC, ODBC, NATS connection string의 자격 증명은 쿼리 로그와 `SHOW CREATE` 출력에서 마스킹되어 민감한 정보가 실수로 노출되는 것을 방지합니다. URI 형식의 connection string(예: {scheme}://{user}:{password}@{host})에서는 디버깅이 쉽도록 나머지 부분은 그대로 표시하고 password 부분만 마스킹합니다. 이제 `nats_token` 설정도 마스킹됩니다. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#100082](https://github.com/ClickHouse/ClickHouse/issues/100082)에서 백포트됨: 분석기를 사용하지 않을 때 `TABLE_UUID_MISMATCH`가 무시되던 문제를 수정했습니다. [#99380](https://github.com/ClickHouse/ClickHouse/pull/99380) ([Azat Khuzhin](https://github.com/azat)).
* [#100060](https://github.com/ClickHouse/ClickHouse/issues/100060)에서 백포트됨: 25.10에서 이후 버전으로 암시적 minmax 인덱스가 있는 복제된 테이블(Replicated Table)을 업그레이드할 때 발생하던 호환성 문제를 수정했습니다. [#99392](https://github.com/ClickHouse/ClickHouse/pull/99392) ([Raúl Marín](https://github.com/Algunenano)).
* [#100317](https://github.com/ClickHouse/ClickHouse/issues/100317)에서 백포트됨: 텍스트 인덱스 분석에서 부정 함수(`notEquals`, `notLike`, `notIn`) 지원을 제거했습니다. 이 함수들은 어떤 그래뉼도 건너뛸 수 없었기 때문에, 이들에 대해 인덱스를 분석하는 것은 이점 없이 오버헤드만 추가했습니다. [#99393](https://github.com/ClickHouse/ClickHouse/pull/99393) ([Anton Popov](https://github.com/CurtizJ)).
* [#100106](https://github.com/ClickHouse/ClickHouse/issues/100106)에서 백포트됨: `DETACH/ATTACH TABLE` 쿼리 후 data part가 손상된 것으로 드물게 잘못 표시되어 detach되던 문제를 수정했습니다. [#99529](https://github.com/ClickHouse/ClickHouse/pull/99529) ([Anton Popov](https://github.com/CurtizJ)).
* [#100358](https://github.com/ClickHouse/ClickHouse/issues/100358)에서 백포트됨: `toYYYYMM(date)`로 파티션된 테이블에서 `WHERE toWeek(date, mode) = N` 쿼리가 49~52주차에 빈 결과를 반환하던 `toWeek()`의 잘못된 파티션 프루닝을 수정했습니다. [#99542](https://github.com/ClickHouse/ClickHouse/pull/99542) ([Takumi Hara](https://github.com/takumihara)).
* [#99750](https://github.com/ClickHouse/ClickHouse/issues/99750)에서 백포트됨: 로컬 파일에서 Google 자격 증명을 읽는 것을 금지했습니다. 이 설정은 파일 경로를 알고 있으면 다른 자격 증명도 읽을 수 있게 하므로 안전하지 않습니다. [#99584](https://github.com/ClickHouse/ClickHouse/pull/99584) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#100316](https://github.com/ClickHouse/ClickHouse/issues/100316)에서 백포트됨: 전처리기가 있는 텍스트 인덱스에서 `IN` 함수가 포함된 프레디케이트 분석을 수정했습니다. 또한 텍스트 인덱스에서 검색된 토큰 간 충돌을 수정했으며, 이 문제는 잘못된 결과를 초래할 수 있었습니다. [#99755](https://github.com/ClickHouse/ClickHouse/pull/99755) ([Anton Popov](https://github.com/CurtizJ)).
* [#100099](https://github.com/ClickHouse/ClickHouse/issues/100099)에서 백포트됨: `pointwiseAddInplace`에서 alias된 Roaring 비트맵에 대한 self-XOR로 인해 `NumericIndexedVector` aggregate state에 짝수 정수 상수를 곱할 때 발생하던 assertion failure 문제(디버그 빌드에서는 예외, 릴리스 빌드에서는 잘못된 결과)를 수정했습니다. [#99976](https://github.com/ClickHouse/ClickHouse/pull/99976) ([Desel72](https://github.com/Desel72)).
* [#100285](https://github.com/ClickHouse/ClickHouse/issues/100285)에서 백포트됨: 부분 문자열 매칭을 지원하지 않는 토크나이저(`array`, `splitByString`)에서 `startsWith` 및 `endsWith` 함수와 함께 텍스트 인덱스가 잘못 사용되던 문제를 수정했습니다. 이전에는 이러한 토크나이저가 잘못된 결과를 조용히 생성해, 인덱스가 일치하는 행이 포함된 그래뉼을 건너뛸 가능성이 있었습니다. [#100151](https://github.com/ClickHouse/ClickHouse/pull/100151) ([Anton Popov](https://github.com/CurtizJ)).
* [#100267](https://github.com/ClickHouse/ClickHouse/issues/100267)에서 백포트됨: 텍스트 인덱스를 빌드하는 동안 &quot;Memory Limit&quot; 예외가 발생할 경우 드물게 발생하던 크래시를 수정했습니다. [#100213](https://github.com/ClickHouse/ClickHouse/pull/100213) ([Anton Popov](https://github.com/CurtizJ)).
* [#100258](https://github.com/ClickHouse/ClickHouse/issues/100258)에 백포트됨: `IN` 절이 포함된 프레디케이트에 대해 `mapValues`를 기반으로 구축된 텍스트 인덱스를 분석하는 과정에서 발생하던 &quot;Not-ready Set is passed as the second argument&quot; 오류를 수정했습니다. [#100224](https://github.com/ClickHouse/ClickHouse/pull/100224) ([Anton Popov](https://github.com/CurtizJ)).
* [#100344](https://github.com/ClickHouse/ClickHouse/issues/100344)에 백포트됨: 크로스 조인 및 런타임 필터가 포함된 `Dynamic` 컬럼 관련 쿼리에서 발생하던 `LOGICAL_ERROR` 예외를 수정했습니다. 이 문제는 `hasOnlyNulls` 최적화 경로에서 `ColumnVariant::filter`가 variant 컬럼 포인터를 복제하지 않고 공유했기 때문에 발생했습니다. [https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147)을 닫습니다. [#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100553](https://github.com/ClickHouse/ClickHouse/issues/100553)에 백포트됨: `delta_lake_snapshot_start_version` 없이 `delta_lake_snapshot_end_version`만 설정된 경우, `BAD_ARGUMENTS` 오류를 발생시키는 대신 그대로 무시되던 복사-붙여넣기 버그를 수정했습니다. [#100454](https://github.com/ClickHouse/ClickHouse/pull/100454) ([Mohammad Lareb Zafar](https://github.com/zlareb1)).

[#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
