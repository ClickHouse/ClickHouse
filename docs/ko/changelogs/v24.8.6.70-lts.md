<div id="clickhouse-release-v248670-lts-ddb8c219771-fixme-as-compared-to-v2485115-lts-8c4cb00a384">
  ### ClickHouse 릴리스 v24.8.6.70-lts (ddb8c219771) FIXME v24.8.5.115-lts (8c4cb00a384)와 비교
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#71359](https://github.com/ClickHouse/ClickHouse/issues/71359)에서 백포트됨: JSON 서브컬럼용 파일에서 특수 문자가 이스케이프되지 않아 발생할 수 있는 `No such file or directory` 오류를 수정했습니다. [#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### 개선 사항
</div>

* [#70680](https://github.com/ClickHouse/ClickHouse/issues/70680)에 백포트됨: Keeper에서 user&#95;directories를 동기화할 때 검증하지 않습니다. [#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* [#71395](https://github.com/ClickHouse/ClickHouse/issues/71395)에 백포트됨: 디렉터리를 나열할 때 객체 스토리지 API를 호출하지 않습니다. 비용 효율이 낮을 수 있기 때문입니다. 대신 파일 이름 목록을 메모리에 저장합니다. 그에 따른 절충점은 초기 적재 시간이 늘어나고 파일 이름을 저장하는 데 필요한 메모리가 증가한다는 점입니다. [#70823](https://github.com/ClickHouse/ClickHouse/pull/70823) ([Julia Kartseva](https://github.com/jkartseva)).
* [#71287](https://github.com/ClickHouse/ClickHouse/issues/71287)에 백포트됨: plain&#95;rewritable 디스크에서 객체 스토리지 HEAD API 요청 수를 줄입니다. [#70915](https://github.com/ClickHouse/ClickHouse/pull/70915) ([Julia Kartseva](https://github.com/jkartseva)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#70934](https://github.com/ClickHouse/ClickHouse/issues/70934)에서 백포트됨: `IS NULL` 검사가 `NOT` 같은 다른 함수 아래에 있을 때 잘못된 결과를 초래할 수 있는 JOIN ON 절 최적화 문제를 수정합니다. [#67915](https://github.com/ClickHouse/ClickHouse/issues/67915)를 닫습니다. [#68049](https://github.com/ClickHouse/ClickHouse/pull/68049) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#70735](https://github.com/ClickHouse/ClickHouse/issues/70735)에서 백포트됨: 배열에 빈 튜플을 전달할 때 발생하는 예기치 않은 예외를 수정합니다. 이로써 [#68618](https://github.com/ClickHouse/ClickHouse/issues/68618)을 해결합니다. [#68848](https://github.com/ClickHouse/ClickHouse/pull/68848) ([Amos Bird](https://github.com/amosbird)).
* [#71138](https://github.com/ClickHouse/ClickHouse/issues/71138)에서 백포트됨: s3Cluster에서 structure argument가 전파되지 않는 문제를 수정합니다. 이전에는 s3Cluster에서 쿼리를 레플리카로 전송할 때 컬럼의 `DEFAULT` 표현식이 누락될 수 있었습니다. [#69147](https://github.com/ClickHouse/ClickHouse/pull/69147) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70561](https://github.com/ClickHouse/ClickHouse/issues/70561)에서 백포트됨: `useDefaultImplementationForLowCardinalityColumns`가 `true`를 반환하도록 재정의해 `LowCardinality` 컬럼의 `getSubcolumn` 문제를 수정합니다. [#69831](https://github.com/ClickHouse/ClickHouse/pull/69831) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#70903](https://github.com/ClickHouse/ClickHouse/issues/70903)에서 백포트됨: `tuple` 함수를 평가할 때 서로 다른 이름이 지정된 Tuple 사이에서 컬럼을 재사용하지 않도록 수정합니다. 이로써 [#70022](https://github.com/ClickHouse/ClickHouse/issues/70022)를 해결합니다. [#70103](https://github.com/ClickHouse/ClickHouse/pull/70103) ([Amos Bird](https://github.com/amosbird)).

[#70264](https://github.com/ClickHouse/ClickHouse/pull/70264) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#70688](https://github.com/ClickHouse/ClickHouse/issues/70688)에서 백포트됨: `SYSTEM DROP FORMAT SCHEMA CACHE FOR Protobuf`에서 발생할 수 있는 use-after-free 문제를 수정합니다. [#70358](https://github.com/ClickHouse/ClickHouse/pull/70358) ([Azat Khuzhin](https://github.com/azat)).
* [#70494](https://github.com/ClickHouse/ClickHouse/issues/70494)에서 백포트됨: GROUP BY JSON 하위 객체 subcolumn 처리 중 발생하는 크래시를 수정합니다. [#70374](https://github.com/ClickHouse/ClickHouse/pull/70374) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70482](https://github.com/ClickHouse/ClickHouse/issues/70482)에서 백포트됨: 파트에 행이 없으면 수직 병합 시 해당 파트를 프리페치하지 않도록 수정합니다. [#70452](https://github.com/ClickHouse/ClickHouse/pull/70452) ([Antonio Andelic](https://github.com/antonio2368)).
* [#70556](https://github.com/ClickHouse/ClickHouse/issues/70556)에서 백포트됨: WHERE에서 람다 함수를 사용할 때 발생하는 크래시를 수정합니다. [#70464](https://github.com/ClickHouse/ClickHouse/pull/70464) ([Raúl Marín](https://github.com/Algunenano)).
* [#70878](https://github.com/ClickHouse/ClickHouse/issues/70878)에서 백포트됨: `Replicated` 데이터베이스에서 보조 레플리카의 테이블 함수 소스를 사용할 수 없을 때 `CREATE ... AS table_function()`으로 테이블을 생성하는 문제를 수정합니다. [#70511](https://github.com/ClickHouse/ClickHouse/pull/70511) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#70575](https://github.com/ClickHouse/ClickHouse/issues/70575)에서 백포트됨: `wait_for_async_insert=1`로 async insert를 수행할 때 모든 출력을 무시합니다.
