* [#100462](https://github.com/ClickHouse/ClickHouse/issues/100462)에서 백포트됨: poco 내부의 std 스트림에 `this->exceptions(std::ios::badbit);`를 설정하도록 변경했습니다. [#96455](https://github.com/ClickHouse/ClickHouse/pull/96455) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#99090](https://github.com/ClickHouse/ClickHouse/issues/99090)에 백포트됨: `clickhouse-client`에서 `--external`로 전달된 외부 테이블에 대해 이름으로 Tuple 서브컬럼에 접근하는 기능(예: `Tuple(a UUID, b Int32)`의 `SELECT x.a`)을 수정했습니다. [#96925](https://github.com/ClickHouse/ClickHouse/issues/96925)를 해결합니다. [#98755](https://github.com/ClickHouse/ClickHouse/pull/98755) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100488](https://github.com/ClickHouse/ClickHouse/issues/100488)에 백포트됨: JDBC, ODBC, NATS 연결 문자열의 자격 증명은 이제 쿼리 로그와 `SHOW CREATE` 출력에서 마스킹되어 민감한 정보가 실수로 노출되는 것을 방지합니다. URI 형식의 연결 문자열(예: {scheme}://{user}:{password}@{host})에서는 비밀번호 부분만 마스킹되며, 나머지 부분은 디버깅을 쉽게 할 수 있도록 계속 표시됩니다. 이제 `nats_token` 설정도 마스킹됩니다. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#100592](https://github.com/ClickHouse/ClickHouse/issues/100592)에 백포트됨: `optimize_on_insert=0`일 때 wide 파트에서 중첩된 `Array(JSON)` 컬럼이 있는 테이블에 데이터를 삽입할 때 발생하는 LOGICAL&#95;ERROR 예외 &quot;Stream ... not found&quot;를 수정했습니다. [#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100722](https://github.com/ClickHouse/ClickHouse/issues/100722)에 백포트됨: projection의 SELECT 부분에 쿼리의 원래 SELECT 부분에는 없는 컬럼이 있을 때 발생하는 NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK 사례를 수정했습니다. [#100194](https://github.com/ClickHouse/ClickHouse/issues/100194)를 해결합니다. [#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
