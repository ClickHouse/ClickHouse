  #### 하위 호환되지 않는 변경 사항

* [#106045](https://github.com/ClickHouse/ClickHouse/issues/106045)에서 백포트됨: 설정 `show_data_lake_catalogs_in_system_tables`의 이름이 `show_remote_databases_in_system_tables`로 변경되었고 적용 범위도 확장되었습니다. 값이 0(기본값)인 경우에는 데이터 레이크 카탈로그뿐 아니라 `MySQL` 및 `PostgreSQL` 데이터베이스도 `system.tables`, `system.columns`, `system.completions`에서 숨겨집니다. 기존 설정 이름은 alias로 유지됩니다. [#104416](https://github.com/ClickHouse/ClickHouse/pull/104416) ([Pablo Marcos](https://github.com/pamarcos)).

<div id="new-feature">
  #### 새 기능
</div>

* [#104562](https://github.com/ClickHouse/ClickHouse/issues/104562)에 백포트됨: 갱신 가능 구체화 뷰에 `SYSTEM PAUSE VIEW [db.]name` 및 `SYSTEM PAUSE VIEWS` 쿼리가 추가되었습니다. `SYSTEM STOP VIEW`와 달리 `SYSTEM PAUSE VIEW`는 현재 실행 중인 갱신을 중단하지 않습니다. 즉, 진행 중인 갱신은 완료되며 이후 갱신만 방지됩니다. 이 상태는 `SYSTEM START VIEW` 또는 `SYSTEM START VIEWS`로 해제할 수 있으며, 이제 이 쿼리들은 중지 상태와 일시 중지 상태를 모두 일관되게 해제합니다. [#103252](https://github.com/ClickHouse/ClickHouse/pull/103252) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

[#103268](https://github.com/ClickHouse/ClickHouse/pull/103268) ([Groene AI](https://github.com/groeneai)).
* [#105668](https://github.com/ClickHouse/ClickHouse/issues/105668)에 백포트됨: `catalog_type = 'glue'`가 설정된 `DataLakeCatalog` 데이터베이스에서 장시간 실행되는 `INSERT ... (INCORRECT_DATA)`와 함께 실패하던 문제를 수정했습니다. [#105381](https://github.com/ClickHouse/ClickHouse/pull/105381) ([Pratima Patel](https://github.com/pratimapatel2008)).
* [#105977](https://github.com/ClickHouse/ClickHouse/issues/105977)에 백포트되었습니다: `TYPE set(N)` 스킵 인덱스가 있는 `SELECT`에서 `WHERE` 절의 조건식 결과 타입이 `Float`, `BFloat16` 또는 기타 비정수 타입(예: `WHERE c0 + 0.1` 또는 `WHERE log(c0)`)일 때 발생하던 `BAD_ARGUMENTS` 예외 &quot;It&#39;s a bug!
