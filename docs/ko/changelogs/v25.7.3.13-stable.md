<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#85306](https://github.com/ClickHouse/ClickHouse/issues/85306)에서 백포트됨: ALTER MODIFY ORDER BY가 정렬 키의 TTL 컬럼을 검증하지 않던 문제를 수정했습니다. 이제 ALTER 작업 중 ORDER BY 절에서 TTL 컬럼을 사용하면 올바르게 거부되어 잠재적인 테이블 손상을 방지합니다. [#84536](https://github.com/ClickHouse/ClickHouse/pull/84536) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* [#85381](https://github.com/ClickHouse/ClickHouse/issues/85381)에서 백포트됨: `ReplicatedMergeTree`에서 patch parts 정리 문제를 수정했습니다. 이전에는 patch parts를 구체화하는 머지된 또는 mutation이 적용된 파트를 다른 레플리카에서 다운로드할 때까지 경량 업데이트 결과가 해당 레플리카에 일시적으로 보이지 않을 수 있었습니다. [#85121](https://github.com/ClickHouse/ClickHouse/pull/85121) ([Anton Popov](https://github.com/CurtizJ)).
* [#85246](https://github.com/ClickHouse/ClickHouse/issues/85246)에서 백포트됨: MV에서 타입이 다를 때 발생하는 illegal&#95;type&#95;of&#95;argument 문제를 수정했습니다. [#85135](https://github.com/ClickHouse/ClickHouse/pull/85135) ([Sema Checherinda](https://github.com/CheSema)).
* [#85236](https://github.com/ClickHouse/ClickHouse/issues/85236)에서 백포트됨: `additional_table_filters expression` 설정 내 `IN (subquery)`에서 발생하는 `Not-ready Set` 문제를 수정했습니다. [#85210](https://github.com/ClickHouse/ClickHouse/pull/85210) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#85264](https://github.com/ClickHouse/ClickHouse/issues/85264)에서 백포트됨: SYSTEM DROP REPLICA 쿼리 중 불필요한 `getStatus()` 호출을 제거했습니다. 이로써 테이블이 백그라운드에서 삭제될 때 `Shutdown for storage is called` 예외가 발생하던 문제도 수정되었습니다. [#85220](https://github.com/ClickHouse/ClickHouse/pull/85220) ([Nikolay Degterinsky](https://github.com/evillique)).
