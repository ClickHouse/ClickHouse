<div id="improvement">
  #### 개선 사항

* [#84035](https://github.com/ClickHouse/ClickHouse/issues/84035)에서 백포트됨: cgroup 정보(해당하는 경우, 즉 `memory_worker_use_cgroup`이 설정되어 있고 cgroup을 사용할 수 있는 경우)를 사용해 memory tracker를 조정합니다(`memory_worker_correct_memory_tracker`). [#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#84107](https://github.com/ClickHouse/ClickHouse/issues/84107)에서 백포트됨: Avro 스키마 레지스트리 인증 정보가 사용자에게 노출되거나 로그에 기록되지 않도록 마스킹합니다. [#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#83915](https://github.com/ClickHouse/ClickHouse/issues/83915)에서 백포트됨: MergeTree 테이블을 `add_minmax_index_for_numeric_columns=1` 또는 `add_minmax_index_for_string_columns=1`로 생성한 뒤, 이후 ALTER 작업 중 인덱스가 구체화되면 새 레플리카에서 복제된 데이터베이스가 정상적으로 초기화되지 않는 문제를 수정했습니다. [#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#83873](https://github.com/ClickHouse/ClickHouse/issues/83873)에서 백포트됨: 이름 충돌이 발생하는 경우 새로운 분석기가 WITH 절에서 바깥쪽 alias를 참조할 수 있도록 이전 버전과의 호환성 설정을 도입했습니다. [#82700](https://github.com/ClickHouse/ClickHouse/issues/82700)을 수정합니다. [#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* [#84091](https://github.com/ClickHouse/ClickHouse/issues/84091)에서 백포트됨: Backup에서 복원할 때 definer 사용자가 백업되지 않을 수 있으며, 이 경우 전체 백업을 사용할 수 없게 될 수 있습니다. 이를 해결하기 위해 복원 중 대상 테이블 생성 시 권한 검사를 미루고, 런타임에만 검사하도록 했습니다. [#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* [#84124](https://github.com/ClickHouse/ClickHouse/issues/84124)에서 백포트됨: 드물게 `MATERIALIZE COLUMN` 쿼리로 인해 `checksums.txt`에 예기치 않은 파일이 생기고, 결국 분리된 데이터 파트가 발생할 수 있는 버그를 수정했습니다. [#84007](https://github.com/ClickHouse/ClickHouse/pull/84007) ([alesapin](https://github.com/alesapin)).
