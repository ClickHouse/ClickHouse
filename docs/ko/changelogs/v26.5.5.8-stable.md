<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#108869](https://github.com/ClickHouse/ClickHouse/issues/108869)에 백포트됨: 순환 의존성이 있는 테이블이 포함된 백업을 `RESTORE`하는 중 서버가 중단되던 문제를 수정했습니다. [#103824](https://github.com/ClickHouse/ClickHouse/pull/103824) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108903](https://github.com/ClickHouse/ClickHouse/issues/108903)에 백포트됨: 분리(disjunction, 부분 프레디케이트) 푸시다운 최적화가 JOIN에 의해 타입이 확장된 `USING` 키 위로 조건을 푸시할 때 발생하던 논리 오류(`Unexpected return type from equals. Expected Nullable(UInt8). Got UInt8`)를 수정했습니다. 또한 알 수 없는 식별자를 참조하는 상수 폴딩 가능한 `if`/`multiIf` 분기가 포함된 `JOIN ... USING` 쿼리에서 식별자를 해석하는 과정 중 분석기에서 발생하던 서버 크래시(세그멘테이션 폴트)도 수정했습니다. [#107407](https://github.com/ClickHouse/ClickHouse/pull/107407) ([Groene AI](https://github.com/groeneai)).
* [#108643](https://github.com/ClickHouse/ClickHouse/issues/108643)에 백포트됨: `ReplicatedMergeTree` 테이블의 `RESTORE`를 수정하여, 백업에 포함된 중복 내용의 파트가 조용히 중복 제거되지 않고 그대로 보존되도록 했습니다. [#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* [#108748](https://github.com/ClickHouse/ClickHouse/issues/108748)에 백포트됨: 이제 `_distance` 컬럼에서 SELECT하는 벡터 검색 쿼리는 `LOGICAL_ERROR`로 실패하는 대신 적절한 오류를 반환합니다. [#108423](https://github.com/ClickHouse/ClickHouse/pull/108423) ([Robert Schulze](https://github.com/rschu1ze)).
* [#108667](https://github.com/ClickHouse/ClickHouse/issues/108667)에 백포트됨: 여러 개의 부분적으로 구체화된 텍스트 인덱스에서의 직접 읽기 문제를 수정했습니다. [#108607](https://github.com/ClickHouse/ClickHouse/pull/108607) ([Anton Popov](https://github.com/CurtizJ)).
* [#108825](https://github.com/ClickHouse/ClickHouse/issues/108825)에 백포트됨: `LowCardinality(FixedString)`(또는 `LowCardinality(Nullable(FixedString))`) 키 컬럼이 키 식에서 함수로 감싸진 경우, 예를 들어 `WHERE k = 'literal'`와 함께 `PARTITION BY sipHash64(k) % N`처럼 사용할 때 파티션 및 기본 키 프루닝이 조용히 비활성화되던 문제를 수정했습니다. 이런 쿼리는 프루닝되는 대신 모든 파티션을 스캔했습니다. [#108777](https://github.com/ClickHouse/ClickHouse/pull/108777) ([Groene AI](https://github.com/groeneai)).
* [#108907](https://github.com/ClickHouse/ClickHouse/issues/108907)에 백포트됨: 살아 있는 레플리카 수가 과반수보다 적을 때 `insert_quorum = 'auto'`가 삽입을 미리 거부하지 않던 문제를 수정했습니다. 이제 이러한 삽입은 로컬 파트를 기록한 뒤 나중에 `UNKNOWN_STATUS_OF_INSERT`로 시간 초과되는 대신, 즉시 `TOO_FEW_LIVE_REPLICAS`로 실패합니다. [#108800](https://github.com/ClickHouse/ClickHouse/pull/108800) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
