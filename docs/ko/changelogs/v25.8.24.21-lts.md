[#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#104148](https://github.com/ClickHouse/ClickHouse/issues/104148)에 백포트됨: row policies/additional&#95;table&#95;filters 사용 시 단순 LIMIT 최적화를 비활성화했습니다(병렬 인덱스 분석을 허용하기 위함). [#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* [#104210](https://github.com/ClickHouse/ClickHouse/issues/104210)에 백포트됨: materialized view가 없는 일반 INSERT는 더 이상 과도한 ConcurrencyControl 슬롯과 스레드를 요청하지 않습니다(`max_insert_threads` 대신 `max_threads` 사용). 이를 통해 INSERT 처리량이 높은 클러스터에서 CC 슬롯 고갈과 스레드 수 급증을 방지합니다. [#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).
* [#104613](https://github.com/ClickHouse/ClickHouse/issues/104613)에 백포트됨: ClickHouse, MySQL, PostgreSQL 및 XDBC 딕셔너리 소스에서 `clone() const`가 동일한 `invalidate_query_response` 문자열을 읽고 `isModified() const`가 여기에 쓰는 경우 발생하는 데이터 레이스를 수정했습니다. [#103277](https://github.com/ClickHouse/ClickHouse/pull/103277) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#105212](https://github.com/ClickHouse/ClickHouse/issues/105212)에 백포트됨: `AggregateFunction` 상태에 정수를 곱할 때(예: `quantilesExactState(...) * N`) 발생하는 heap-use-after-free를 수정했습니다. exponentiation-by-squaring 루프가 상태를 자기 자신과 머지하고 있었으며, 이는 집계 함수의 `merge`가 내부 저장소를 재할당할 경우 정의되지 않은 동작입니다. STID 0988-40af를 해결합니다. [#103536](https://github.com/ClickHouse/ClickHouse/pull/103536) ([Groene AI](https://github.com/groeneai)).
