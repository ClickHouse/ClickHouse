<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#108866](https://github.com/ClickHouse/ClickHouse/issues/108866)에 백포트됨: 순환 의존성이 있는 테이블이 포함된 백업을 `RESTORE`하는 중 발생하던 서버 중단 문제를 수정했습니다. [#103824](https://github.com/ClickHouse/ClickHouse/pull/103824) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108847](https://github.com/ClickHouse/ClickHouse/issues/108847)에 백포트됨: 이제 증분 백업은 `.backup` 메타데이터 파일의 `<base_backup>` 로케이터에 `S3` 자격 증명을 저장하지 않습니다. `use_same_s3_credentials_for_base_backup = 1`로 생성했거나, 이 백업 로케이터와 일치하는 명시적 기준 백업 자격 증명으로 생성한 백업은 시크릿이 아닌 마커를 저장하며 복원 시 추가 설정 없이 복원됩니다. 서로 다른 명시적 기준 백업 자격 증명이나 추가 기준 백업 인증 인수로 생성한 백업은 `base_backup` 설정과 함께 `RESTORE`에 이를 전달해야 합니다. 이전 버전에서 내장 자격 증명으로 생성한 백업도 계속 복원할 수 있습니다. [#107357](https://github.com/ClickHouse/ClickHouse/pull/107357) ([Pablo Marcos](https://github.com/pamarcos)).
* [#107889](https://github.com/ClickHouse/ClickHouse/issues/107889)에 백포트됨: `MySQL Connector/J` 8.2.0 이상(9.x 포함)에서 MySQL 인터페이스를 사용할 수 없던 문제를 수정했습니다. 이제 `OK` 패킷의 `info` 필드가 MySQL 서버와 동일하게 길이 인코딩되므로 JDBC 드라이버가 연결할 수 있습니다. [#107693](https://github.com/ClickHouse/ClickHouse/pull/107693) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#108763](https://github.com/ClickHouse/ClickHouse/issues/108763)에 백포트됨: `ssl_certificate` 사용자 식별을 수정하여 단일 `*` 와일드카드가 정확히 하나의 이름 구성 요소에만 일치하도록 했습니다(RFC 6125 6.4.3). 이전에는 `CN` 또는 `DNS:` SAN 주체의 와일드카드(예: `*.corp.example.com`)가 `evil.deep.corp.example.com` 같은 여러 레이블 이름과도 일치해, 더 깊은 하위 도메인용 인증서 보유자가 와일드카드 사용자로 인증할 수 있었습니다. `URI:` SAN 일치 방식은 변경되지 않았습니다. [#108472](https://github.com/ClickHouse/ClickHouse/pull/108472) ([Groene AI](https://github.com/groeneai)).
* [#108896](https://github.com/ClickHouse/ClickHouse/issues/108896)에 백포트됨: `max_parser_depth`를 큰 값으로 설정했을 때 `[[[ ... ]]]` 또는 `array(array( ... ))` 같은 깊게 중첩된 표현식으로 인해 발생하던 서버 크래시(스택 오버플로우)를 수정했습니다. [#108493](https://github.com/ClickHouse/ClickHouse/pull/108493) ([Raúl Marín](https://github.com/Algunenano)).
* [#109141](https://github.com/ClickHouse/ClickHouse/issues/109141)에 백포트됨: `GROUPING SETS`, `ROLLUP` 또는 `CUBE`를 `max_threads > 1`과 함께 사용할 때 `uniqExact` 집계 상태를 병합하는 과정에서 발생하던 세그멘테이션 폴트를 수정했습니다. [#108928](https://github.com/ClickHouse/ClickHouse/pull/108928) ([Raúl Marín](https://github.com/Algunenano)).
