* [#90983](https://github.com/ClickHouse/ClickHouse/issues/90983)에 백포트됨: [https://github.com/ClickHouse/ClickHouse/pull/90311](https://github.com/ClickHouse/ClickHouse/pull/90311)로 인해 통계 포맷이 변경되어, 이전 포맷의 통계가 있으면 server가 크래시될 수 있습니다. 이 PR은 해당 크래시를 수정하고, 기존 통계가 레거시 포맷을 사용하는 경우 예외를 발생시킵니다. 예외를 방지하려면 `ALTER TABLE [db.]table MATERIALIZE STATISTICS ALL`를 실행하여 통계를 다시 생성해야 합니다. [#90904](https://github.com/ClickHouse/ClickHouse/pull/90904) ([Han Fei](https://github.com/hanfei1991)).
* [#91193](https://github.com/ClickHouse/ClickHouse/issues/91193)에 백포트됨: 이제 http 클라이언트 연결의 `hard_limit`에 도달하면 `HTTP_CONNECTION_LIMIT_REACHED` 예외가 발생합니다. 디스크 연결의 경우 이 값은 `20000`으로 설정됩니다. [#91016](https://github.com/ClickHouse/ClickHouse/pull/91016) ([Sema Checherinda](https://github.com/CheSema)).
* [#91254](https://github.com/ClickHouse/ClickHouse/issues/91254)에 백포트됨: 많은 서브컬럼이 있는 JSON 컬럼의 컬럼 샘플을 읽을 때, 스레드 풀을 무조건 사용하는 대신 `merge_tree_use_prefixes_deserialization_thread_pool` 설정을 따르도록 하여 잠재적인 스레드 풀 기아 현상을 수정했습니다. [#91208](https://github.com/ClickHouse/ClickHouse/pull/91208) ([Raufs Dunamalijevs](https://github.com/rienath)).
