<div id="improvement">
  #### 개선 사항
</div>

* [#101603](https://github.com/ClickHouse/ClickHouse/issues/101603)에 백포트됨: 이제 Cgroupv2 메모리 추적에서 커널 메모리 계산 시 `slab_reclaimable`을 제외하므로, 회수 불가능한 메모리 사용량을 더 정확하게 측정할 수 있습니다. [#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)).
* [#101868](https://github.com/ClickHouse/ClickHouse/issues/101868)에 백포트됨: 이제 text index는 일반 제공 상태이며 `compatibility` 설정과 관계없이 계속 활성화된 상태를 유지하므로, 백업 복원 중이거나 compatibility mode로 실행 중일 때 예기치 않게 비활성화되는 일을 방지합니다. [#101518](https://github.com/ClickHouse/ClickHouse/pull/101518) ([Nikita Fomichev](https://github.com/fm4v)).
* [#101862](https://github.com/ClickHouse/ClickHouse/issues/101862)에 백포트됨: libarchive를 3.8.5에서 3.8.6으로 올렸습니다. [#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)).
* [#101856](https://github.com/ClickHouse/ClickHouse/issues/101856)에 백포트됨: curl을 8.18에서 8.19로 올렸습니다. [#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#101461](https://github.com/ClickHouse/ClickHouse/issues/101461)에 백포트됨: Keeper에서 읽기 요청이 멈춰 세션 시간 초과를 유발할 수 있던 버그를 수정했습니다. 이 문제는 동일한 서버에서 서로 관련 없는 다른 세션이 정확히 맞물리지 않는 시점에 종료될 때 발생할 수 있었습니다. [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* [#101689](https://github.com/ClickHouse/ClickHouse/issues/101689)에 백포트됨: vector similarity search 중 `sorted_buffer_gt::insert()`에서 발생해 크래시를 일으키거나 메모리를 조용히 손상시킬 수 있던 usearch의 heap-buffer-overflow를 수정했습니다. [#100537](https://github.com/ClickHouse/ClickHouse/pull/100537) ([Dustin Healy](https://github.com/dustinhealy)).
* [#101633](https://github.com/ClickHouse/ClickHouse/issues/101633)에 백포트됨: 소수점 이하 초 자릿수가 18자리를 초과하는 datetime 문자열을 파싱할 때 `parseDateTimeBestEffort`에서 발생하던 정의되지 않은 동작(undefined behavior, signed integer 오버플로우)을 수정했습니다. [#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* [#101364](https://github.com/ClickHouse/ClickHouse/issues/101364)에 백포트됨: JIT 컴파일이 활성화된 경우(컴파일 임계값 도달 후) `Decimal` 컬럼에서 `MAX`/`MIN` 집계 함수가 잘못된 결과를 반환하던 문제를 수정했습니다. [#101203](https://github.com/ClickHouse/ClickHouse/pull/101203) ([Raúl Marín](https://github.com/Algunenano)).
* [#101625](https://github.com/ClickHouse/ClickHouse/issues/101625)에 백포트됨: 쿼리가 Dynamic 맵(Map) 타입을 포함하는 Tuple 컬럼과 해당 subcolumn을 동시에 읽을 때 발생하던 서버 크래시(Logical error: &quot;Variant ... is empty&quot;)를 수정했습니다(예: `SELECT ... WHERE NOT ignore(*, mapKeys(t.m))`). [#101448](https://github.com/ClickHouse/ClickHouse/pull/101448) ([Groene AI](https://github.com/groeneai)).
