<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 함수 `geoToH3()`는 이제 입력을 (lat, lon,res) 순서로 받습니다(기하 함수의 표준 순서). 기존 결과 순서인 (lon, lat,res)를 유지하려면 설정 `geotoh3_lon_lat_input_order = true`를 지정할 수 있습니다. [#78852](https://github.com/ClickHouse/ClickHouse/pull/78852) ([Pratima Patel](https://github.com/pratimapatel2008)).
* `full_text` 인덱스 유형이 `gin`으로 이름이 변경되었습니다. 이는 PostgreSQL 및 다른 데이터베이스에서 더 익숙한 용어를 따른 것입니다. 기존 `full_text` 인덱스는 계속 로드할 수 있지만, 검색에 사용하려고 하면 예외를 발생시키며(대신 `gin` 인덱스를 제안) 사용할 수 없습니다. [#79024](https://github.com/ClickHouse/ClickHouse/pull/79024) ([Robert Schulze](https://github.com/rschu1ze)).
* 파일 시스템 캐시의 동적 크기 조정을 허용하는 파일 시스템 캐시 설정 `allow_dynamic_cache_resize`를 추가했습니다. 기본값은 `false`입니다. 이유: 특정 환경(ClickHouse Cloud)에서는 모든 스케일링 이벤트가 프로세스 재시작을 통해 발생하므로, 동작을 더 세밀하게 제어하고 안전장치로도 활용할 수 있도록 이 기능을 명시적으로 비활성화된 상태로 두기 위함입니다. 이 PR이 하위 호환되지 않는 변경 사항으로 표시된 이유는, 이전 버전에서는 별도 설정 없이 동적 캐시 크기 조정이 기본적으로 동작했기 때문입니다. [#79148](https://github.com/ClickHouse/ClickHouse/pull/79148) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 레거시 인덱스 유형 `annoy` 및 `usearch` 지원을 제거했습니다. 두 유형 모두 오랫동안 스텁 상태였기 때문에, 이 레거시 인덱스를 사용하려는 모든 시도는 어차피 오류를 반환했습니다. 아직 `annoy` 및 `usearch` 인덱스가 있다면 삭제하십시오. [#79802](https://github.com/ClickHouse/ClickHouse/pull/79802) ([Robert Schulze](https://github.com/rschu1ze)).
* `format_alter_commands_with_parentheses` server setting을 제거했습니다. 이 설정은 24.2에서 도입되었으며 기본적으로 비활성화되어 있었습니다. 25.2부터는 기본적으로 활성화되었습니다. 새 포맷을 지원하지 않는 LTS 버전이 더 이상 없으므로 이 설정을 제거할 수 있습니다. [#79970](https://github.com/ClickHouse/ClickHouse/pull/79970) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).

<div id="new-feature">
  #### 새 기능
</div>

* CREATE 쿼리에서 해당 컬럼의 기본 압축 코덱을 명시적으로 정의하지 않은 경우 사용할 기본 압축 코덱을 지정하는 새 옵션을 MergeTree SETTINGS에 추가했습니다. 이로써 [#42005](https://github.com/ClickHouse/ClickHouse/issues/42005)가 해결되었습니다. [#66394](https://github.com/ClickHouse/ClickHouse/pull/66394) ([gvoelfin](https://github.com/gvoelfin)).
* [https://github.com/ClickHouse/ClickHouse/pull/71943](https://github.com/ClickHouse/ClickHouse/pull/71943)의 후속 작업입니다. 이 PR에서는 Time/Time64 데이터 타입을 구현했습니다. 새 데이터 타입인 Time (HHH:MM:SS) 및 Time64 (HHH:MM:SS.`<fractional>`)와 몇 가지 기본 CAST 함수, 그리고 다른 데이터 타입과 상호작용하는 함수들을 구현했습니다. 또한 CAST 함수에 toTime 함수가 필요해 기존 함수 이름을 toTime에서 toTimeWithFixedDate로 변경했습니다. [#75735](https://github.com/ClickHouse/ClickHouse/pull/75735) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* WHERE 절의 `EXISTS` 표현식 인수로 상관 서브쿼리를 지원합니다. 이로써 [#72459](https://github.com/ClickHouse/ClickHouse/issues/72459)가 해결되었습니다. [#76078](https://github.com/ClickHouse/ClickHouse/pull/76078) ([Dmitry Novik](https://github.com/novikd)).
* 이제 복제된 MergeTree 테이블에 대한 Distributed INSERT SELECT가 병렬 레플리카를 효율적으로 활용해, 각 노드에서 서로 다른 데이터를 선택하고 독립적으로 삽입함으로써 INSERT를 병렬화합니다. [#78041](https://github.com/ClickHouse/ClickHouse/pull/78041) ([Igor Nikonov](https://github.com/devcrafter)).
* system.iceberg&#95;history 테이블을 추가했습니다. [#78244](https://github.com/ClickHouse/ClickHouse/pull/78244) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* getServerSetting 및 getMergeTreeSetting 함수를 추가했습니다. 이로써 [https://github.com/clickhouse/clickhouse/issues/78318](https://github.com/clickhouse/clickhouse/issues/78318)이 해결되었습니다. [#78439](https://github.com/ClickHouse/ClickHouse/pull/78439) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* `version-hint.text` 파일을 활용할 수 있는 새로운 `iceberg_enable_version_hint` 설정을 추가했습니다. [#78594](https://github.com/ClickHouse/ClickHouse/pull/78594) ([Arnaud Briche](https://github.com/arnaudbriche)).
* `LIKE` 키워드로 필터링해 데이터베이스의 특정 테이블만 TRUNCATE할 수 있도록 했습니다. [#78597](https://github.com/ClickHouse/ClickHouse/pull/78597) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 이제 `clickhouse-local`(및 축약 alias인 `ch`)은 처리할 입력 데이터가 있을 때 암시적 `FROM table`을 사용합니다. 이로써 [#65023](https://github.com/ClickHouse/ClickHouse/issues/65023)가 해결되었습니다. 또한 `--input-format`이 지정되지 않았고 일반 파일을 처리하는 경우 clickhouse-local에서 포맷 추론이 활성화되었습니다. [#79085](https://github.com/ClickHouse/ClickHouse/pull/79085) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [`icebergHash`](https://iceberg.apache.org/spec/#appendix-b-32-bit-hash-requirements) 및 [`icebergBucketTransform`](https://iceberg.apache.org/spec/#bucket-transform-details) 함수를 추가했습니다. [`bucket transfom`](https://iceberg.apache.org/spec/#partitioning)으로 파티셔닝된 `Iceberg` 테이블에서 데이터 파일 프루닝을 지원합니다. [#79262](https://github.com/ClickHouse/ClickHouse/pull/79262) ([Daniil Ivanik](https://github.com/divanik)).
* 무작위 데이터나 암호화된 데이터로 보이는 값을 찾기 위해 `stringBytesUniq` 및 `stringBytesEntropy` 함수를 추가했습니다. [#79350](https://github.com/ClickHouse/ClickHouse/pull/79350) ([Sachin Kumar Singh](https://github.com/sachinkumarsingh092)).
* MergeTree 계열 테이블에서 `_part_starting_offset` 가상 컬럼을 지원합니다. 이 컬럼은 현재 파트 목록을 바탕으로 쿼리 시점에 계산된, 앞선 모든 파트의 누적 행 수를 나타냅니다. 누적 값은 쿼리 실행 내내 유지되며 파트 프루닝 이후에도 계속 유효합니다. 이 동작을 지원하도록 관련 내부 로직도 리팩터링되었습니다. [#79417](https://github.com/ClickHouse/ClickHouse/pull/79417) ([Amos Bird](https://github.com/amosbird)).
* geo parquet를 지원합니다. 이로써 [#75317](https://github.com/ClickHouse/ClickHouse/issues/75317)이 해결되었습니다. [#79777](https://github.com/ClickHouse/ClickHouse/pull/79777) ([scanhex12](https://github.com/scanhex12)).
* base32 인코딩/디코딩 기능이 추가되었습니다. [#79809](https://github.com/ClickHouse/ClickHouse/pull/79809) ([Joanna Hulboj](https://github.com/jh0x)).
* ClickHouse 벡터 검색이 이제 프리필터링(pre-filtering)과 포스트필터링(post-filtering)을 모두 지원하며, 더 세밀한 제어를 위한 관련 설정도 제공합니다. (issue [#78161](https://github.com/ClickHouse/ClickHouse/issues/78161)). [#79854](https://github.com/ClickHouse/ClickHouse/pull/79854) ([Shankar Iyer](https://github.com/shankar-iyer)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 보조 인덱스의 표현식을 여러 그래뉼에 걸쳐 한 번에 평가하도록 하여 성능을 높였습니다. [#64109](https://github.com/ClickHouse/ClickHouse/pull/64109) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 오른쪽 테이블의 크기가 임계값보다 작을 때 `hash` 알고리즘으로 폴백되도록 하는 임계값(`parallel_hash_join_threshold` 설정으로 제어)을 도입했습니다. [#76185](https://github.com/ClickHouse/ClickHouse/pull/76185) ([Nikita Taranov](https://github.com/nickitat)).
* 데이터를 병렬로 INSERT할 수 있게 하여 S3Queue/AzureQueue의 성능을 개선했습니다(`parallel_inserts=true` 큐 설정으로 활성화 가능). 이전에는 S3Queue/AzureQueue가 파이프라인의 첫 단계(다운로드, 파싱)만 병렬로 처리할 수 있었고, INSERT는 단일 스레드로 수행되었습니다. 또한 `INSERT`는 거의 항상 병목이었습니다. 이제 `processing_threads_num`에 따라 거의 선형적으로 확장됩니다. [#77671](https://github.com/ClickHouse/ClickHouse/pull/77671) ([Azat Khuzhin](https://github.com/azat)).
* 개별 서브컬럼을 읽을 수 있도록 Compact 파트 포맷을 변경하여 각 substream에 대한 마크를 저장합니다. 기존 Compact 포맷도 계속 읽기에서 지원되며, MergeTree 설정 `write_marks_for_substreams_in_compact_parts`를 사용해 쓰기에도 활성화할 수 있습니다. compact parts 스토리지가 변경되므로 더 안전한 업그레이드를 위해 기본적으로 비활성화되어 있습니다. 다음 릴리스 중 하나에서 기본으로 활성화될 예정입니다. [#77940](https://github.com/ClickHouse/ClickHouse/pull/77940) ([Pavel Kruglov](https://github.com/Avogar)).
* 새로운 설정이 도입되었습니다: `use_skip_indexes_in_final_exact_mode`. `ReplacingMergeTree` 테이블에 대한 쿼리에 FINAL 절이 있으면, 스킵 인덱스를 기반으로 테이블 ranges만 읽을 경우 잘못된 결과가 나올 수 있습니다. 이 설정을 사용하면 스킵 인덱스가 반환한 프라이머리 키 ranges와 겹치는 더 새로운 파트를 스캔하여 올바른 결과를 반환할 수 있습니다. 0으로 설정하면 비활성화되고, 1로 설정하면 활성화됩니다. [#78350](https://github.com/ClickHouse/ClickHouse/pull/78350) ([Shankar Iyer](https://github.com/shankar-iyer)).
* 이제 병렬 레플리카가 활성화된 읽기에서 작업 크기를 결정할 때 레플리카 수를 사용합니다. 이를 통해 읽어야 할 데이터 양이 많지 않을 때 레플리카 간 작업 분배가 더 좋아집니다. [#78695](https://github.com/ClickHouse/ClickHouse/pull/78695) ([Nikita Taranov](https://github.com/nickitat)).
* 분산 집계의 최종 단계에서 `uniqExact` state를 병렬로 머지할 수 있도록 했습니다. [#78703](https://github.com/ClickHouse/ClickHouse/pull/78703) ([Nikita Taranov](https://github.com/nickitat)).
* 키가 있는 집계에서 `uniqExact` state를 병렬로 머지할 때 발생할 수 있는 성능 저하를 수정했습니다. [#78724](https://github.com/ClickHouse/ClickHouse/pull/78724) ([Nikita Taranov](https://github.com/nickitat)).
* Azure 스토리지에 대한 List Blobs API 호출 수를 줄였습니다. [#78860](https://github.com/ClickHouse/ClickHouse/pull/78860) ([Julia Kartseva](https://github.com/jkartseva)).
* 가능하면 filter query plan 단계의 동등 조건을 JOIN 조건에 병합하여 이를 해시 테이블 키로 사용할 수 있도록 했습니다. [#78877](https://github.com/ClickHouse/ClickHouse/pull/78877) ([Dmitry Novik](https://github.com/novikd)).
* regex 대신 `extractKeyValuePairs`를 사용해 hive path 파싱 성능을 개선했습니다. [#79067](https://github.com/ClickHouse/ClickHouse/pull/79067) ([Arthur Passos](https://github.com/arthurpassos)).
* 병렬 레플리카를 사용하는 분산 INSERT SELECT의 성능 문제를 수정했습니다. [#79441](https://github.com/ClickHouse/ClickHouse/pull/79441) ([Azat Khuzhin](https://github.com/azat)).
* 서브컬럼이 포함된 조건을 prewhere로 이동할 수 있도록 했습니다. [#79489](https://github.com/ClickHouse/ClickHouse/pull/79489) ([Pavel Kruglov](https://github.com/Avogar)).
* `LogSeriesLimiter`가 생성될 때마다 정리를 수행하지 않도록 하여, 높은 동시성 시나리오에서 lock 경합과 성능 회귀를 방지했습니다. [#79864](https://github.com/ClickHouse/ClickHouse/pull/79864) ([filimonov](https://github.com/filimonov)).
* 기본적으로 `compile_expressions`(일반 표현식 일부를 위한 JIT 컴파일러)를 활성화합니다. 이로써 [#51264](https://github.com/ClickHouse/ClickHouse/issues/51264), [#56386](https://github.com/ClickHouse/ClickHouse/issues/56386), [#66486](https://github.com/ClickHouse/ClickHouse/issues/66486)가 해결됩니다. [#79907](https://github.com/ClickHouse/ClickHouse/pull/79907) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 단순 `count` 최적화를 통해 쿼리 속도를 높입니다. [#79945](https://github.com/ClickHouse/ClickHouse/pull/79945) ([Raúl Marín](https://github.com/Algunenano)).
* `convertDecimalsImpl`에 `__attribute__((always_inline))`를 추가합니다. [#79999](https://github.com/ClickHouse/ClickHouse/pull/79999) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 기본적으로 `input_format_parquet_bloom_filter_push_down`을 true로 설정합니다. 또한 설정 변경 이력의 오류를 수정합니다. [#80058](https://github.com/ClickHouse/ClickHouse/pull/80058) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* `--path` 명령줄 인수를 지정하면 `clickhouse-local`은 재시작 후에도 데이터베이스를 유지합니다. 이로써 [#50647](https://github.com/ClickHouse/ClickHouse/issues/50647)이 해결됩니다. 이로써 [#49947](https://github.com/ClickHouse/ClickHouse/issues/49947)도 해결됩니다. [#71722](https://github.com/ClickHouse/ClickHouse/pull/71722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 객체 스토리지 클러스터 테이블 함수(예: `s3Cluster`)는 이제 캐시 지역성을 개선하기 위해 일관 해시를 기준으로 읽기용 파일을 레플리카에 할당합니다. [#77326](https://github.com/ClickHouse/ClickHouse/pull/77326) ([Andrej Hoos](https://github.com/adikus)).

[#58224](https://github.com/ClickHouse/ClickHouse/issues/58224)와 함께 사용할 수 있으며 [https://github.com/ClickHouse/ClickHouse/pull/63207](https://github.com/ClickHouse/ClickHouse/pull/63207) 개선에도 도움이 될 수 있습니다. [#78429](https://github.com/ClickHouse/ClickHouse/pull/78429) ([Amos Bird](https://github.com/amosbird)).
