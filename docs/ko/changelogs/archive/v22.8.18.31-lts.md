<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 단락 평가(short circuit) 함수 실행 시 LowCardinality 컬럼에서 잘못된 형 변환이 발생하는 문제를 수정하였습니다. [#43311](https://github.com/ClickHouse/ClickHouse/pull/43311) ([Kruglov Pavel](https://github.com/Avogar)).
* `randomStringUTF8(<홀수>)` 호출 시 발생하는 msan 문제를 수정하였습니다. [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze)).
* JIT 컴파일에서 NaN 불일치 비교 오류를 수정하였습니다. [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal)).
* `multiIf`에서 상수 조건과 널 허용 인수를 사용할 때 발생하는 크래시를 수정하였습니다. [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ)).
* DateTime64 인덱스로 쿼리 시 Date/Date32에서 DateTime64로의 유형 변환 오류를 수정하였습니다. [#50280](https://github.com/ClickHouse/ClickHouse/pull/50280) ([Lucas Chang](https://github.com/lucas-tubi)).
* 요청 전처리 중 예외 발생 시 Keeper에서 교착 상태(deadlock)가 발생하는 문제를 수정하였습니다. [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr)).
* TRUNCATE 후 Log 계열 테이블이 잘못된 행 수를 반환하는 문제를 수정하였습니다. [#50585](https://github.com/ClickHouse/ClickHouse/pull/50585) ([flynn](https://github.com/ucasfl)).
* GLOBAL JOIN의 오른쪽 테이블에서 모든 컬럼을 읽지 않도록 수정하였습니다. [#50721](https://github.com/ClickHouse/ClickHouse/pull/50721) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
