  # 2022년 변경 로그
</div>

<div id="clickhouse-release-v21228-stable-fixme-as-compared-to-v21115646-prestable">
  ### ClickHouse 릴리스 v21.2.2.8-안정 FIXME: v21.1.1.5646-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* * `OPTIMIZE TABLE`/머지의 메모리 추적을 수정했습니다. `OPTIMIZE TABLE`/머지에 쿼리 메모리 제한과 샘플링이 반영되도록 했습니다. [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* 부동소수점 값에 대한 `lcm`/`gcd` 사용을 금지했습니다. [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* 비트 단위 함수(`bitAnd`, `bitOr` 등)는 부동소수점 인수에 사용할 수 없습니다. 이제 명시적으로 정수로 형변환해야 합니다. [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 새 기능
</div>

* 공간 절약을 위해 String 컬럼의 압축률을 높일 수 있도록 zstd long 옵션 지원을 추가했습니다. [#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * LDAP user 디렉터리의 사용자에 대해 LDAP 그룹 이름과 일반적인 속성 값을 로컬 역할에 매핑하는 기능이 추가되었습니다. [#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* 데이터 타입 `Nested`가 이제 임의 수준의 중첩을 지원합니다. 또한 `Array`의 `size0`, `Nullable`의 `null`, `Tuple` 요소 이름과 같은 복합 타입의 서브컬럼이 도입되어 전체 컬럼을 읽지 않고도 읽을 수 있습니다. [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* `argMin` 및 `argMax` 함수에 튜플 인수 지원을 추가했습니다. [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* `FlatDictionary`, `HashedDictionary`, `ComplexKeyHashedDictionary`, `DirectDictionary`, `ComplexKeyDirectDictionary`, `RangeHashedDictionary`에 `Nullable` 지원을 추가했습니다. [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* 부동소수점 컬럼을 파티션 키로 사용하는 것을 금지했습니다. 관련 내용: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* XML 문자를 디코딩하는 `decodeXMLComponent` 함수를 추가했습니다. `SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* PostgreSQL 테이블 엔진(SELECT/삽입 모두 지원하며 다차원 배열도 지원)을 추가했으며, 테이블 함수로도 제공합니다. PostgreSQL 딕셔너리 소스를 추가했습니다. PostgreSQL 데이터베이스 엔진을 추가했습니다. [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `SELECT ALL` 구문을 추가했습니다. [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706)을 해결했습니다. [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* 맵 데이터 타입을 위한 세 가지 함수를 추가했습니다: 1. `mapContains(map, key)`는 `map.keys`에 두 번째 매개변수 `key`가 포함되어 있는지 확인합니다. 2. `mapKeys(map)`는 모든 키를 `Array` 포맷으로 반환합니다. 3. `mapValues(map)`는 모든 값을 `Array` 포맷으로 반환합니다. [#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* 실행 UI에서 MetaKey+Enter 단축키 바인딩을 지원합니다. [#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* `formatDateTime` 함수가 날짜를 분기 형식으로 포맷하기 위한 `%Q` 수정자를 지원합니다. ... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* ... [#19261](https://github.com/ClickHouse/ClickHouse/pull/19261) ([RegulusZ](https://github.com/RegulusZ)).
* 쿼리 중 생성된 팩토리 객체 이름을 system.query&#95;log에 추가합니다. [#18495](https://github.com/ClickHouse/ClickHouse/issues/18495)를 해결했습니다. [#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `sign` 수학 함수를 추가했습니다. [#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).
* `parseDateTimeBestEffortUSOrZero`, `parseDateTimeBestEffortUSOrNull` 함수를 추가했습니다. [#19712](https://github.com/ClickHouse/ClickHouse/pull/19712) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#19764](https://github.com/ClickHouse/ClickHouse/pull/19764) ([emhlbmc](https://github.com/emhlbmc)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* `s3_max_connections` 설정으로 제어되는 S3 연결용 연결 풀을 사용하도록 개선했습니다. [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 논리적으로 동등한 경우 `sumIf()` 및 `sum(if())` 함수를 `countIf()` 함수로 재작성합니다. [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* 더 나은 성능을 위해 libcxx를 업데이트하고 불안정한 ABI를 사용합니다. [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* `stat` syscall 수를 줄여 파트 제거 속도를 높였습니다. 이는 한동안 있던 최적화를 복원한 것입니다. 또한 `IDisk` 인터페이스의 안전성도 향상했습니다. 이로써 [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065)가 해결되었습니다. [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 집계 함수 `sum`의 속도를 높였습니다. 이 개선은 합성 벤치마크에서만 확인되며, 실용성은 크지 않습니다. [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 쿼리 계획의 `Filter` 단계를 `Expression + Filter` 쌍으로 분할할 수 있도록 지원합니다. `Expression + Expression` 병합 최적화([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458))와 함께 사용하면 `Filter` 단계 이후 일부 표현식의 실행을 지연시킬 수 있습니다. [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Buffer 엔진의 여러 계층에서 잠금 경합을 줄였습니다. [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* 연결이 생성될 때마다 구성에 접근하던 동작을 제거해 서버 지연 시간을 약간 개선했습니다. [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* `LIVE VIEW` 테이블 생성 시 `WITH ... [AND] [PERIODIC] REFRESH [interval_in_sec]` 절을 지원하도록 추가되었습니다. [#14822](https://github.com/ClickHouse/ClickHouse/pull/14822) ([vzakaznikov](https://github.com/vzakaznikov)).
* * optimize&#95;alias&#95;column&#95;prediction(기본적으로 활성화)을 추가했습니다. 이 기능은 다음을 수행합니다. * 파티션 프루닝과 보조 인덱스를 사용한 데이터 스키핑 시 WHERE 절의 별칭 컬럼을 올바르게 반영합니다. * optimize&#95;trivial&#95;count의 단순 count 쿼리에서 WHERE 절의 별칭 컬럼을 올바르게 반영합니다. * optimize&#95;aggregation&#95;in&#95;order/optimize&#95;read&#95;in&#95;order에 대해 GROUP BY/ORDER BY의 별칭 컬럼을 올바르게 반영합니다. [#16995](https://github.com/ClickHouse/ClickHouse/pull/16995) ([sundyli](https://github.com/sundy-li)).
* S3에서 전역 리전을 활용할 수 있도록 AWS C++ SDK를 업데이트했습니다. [#17870](https://github.com/ClickHouse/ClickHouse/pull/17870) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 테이블 함수 `cluster`에 대한 삽입을 지원하며, 테이블 함수 `remote`와 `cluster` 모두에서 세그먼트 분할 키를 지정해 노드 간 데이터 분산을 지원합니다. [#16752](https://github.com/ClickHouse/ClickHouse/issues/16752)를 해결했습니다. [#18264](https://github.com/ClickHouse/ClickHouse/pull/18264) ([flynn](https://github.com/ucasfl)).
* `EXISTS VIEW` 구문을 지원합니다. [#18552](https://github.com/ClickHouse/ClickHouse/pull/18552) ([Du Chuan](https://github.com/spongedu)).
* librdkafka를 v1.6.0-RC2로 업데이트했습니다. [#18668](https://github.com/ClickHouse/ClickHouse/issues/18668) 문제를 수정했습니다. [#18671](https://github.com/ClickHouse/ClickHouse/pull/18671) ([filimonov](https://github.com/filimonov)).
* CTE에 추가 별칭을 지정할 수 있도록 했습니다. `enable_global_with_statement = 1`일 때 동일한 수준의 서브쿼리에 CSE를 전파합니다. 이 변경으로 [#17378](https://github.com/ClickHouse/ClickHouse/issues/17378) 문제가 해결됩니다. 이 변경으로 [https://github.com/ClickHouse/ClickHouse/pull/16575#issuecomment-753416235](https://github.com/ClickHouse/ClickHouse/pull/16575#issuecomment-753416235)도 해결됩니다. [#18684](https://github.com/ClickHouse/ClickHouse/pull/18684) ([Amos Bird](https://github.com/amosbird)).
* bitmapTransform, bitmapSubsetInRange, bitmapSubsetLimit, bitmapContains 함수에 [UInt8, UInt16, UInt32, UInt64] 인수 타입 지원을 추가했습니다. 이 변경으로 [#18713](https://github.com/ClickHouse/ClickHouse/issues/18713)을 해결했습니다. [#18791](https://github.com/ClickHouse/ClickHouse/pull/18791) ([sundyli](https://github.com/sundy-li)).
* 접두사 기반 S3 엔드포인트 설정을 추가했습니다. [#18812](https://github.com/ClickHouse/ClickHouse/pull/18812) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 집계 함수 상태가 있는 테이블의 RIGHT 및 FULL JOIN 관련 문제를 수정했습니다. 이전 버전에서는 `cloneResized` 메서드 관련 예외가 발생했습니다. [#18818](https://github.com/ClickHouse/ClickHouse/pull/18818) ([templarzq](https://github.com/templarzq)).
* * 전송 전에 송신 측에서 분산 batch의 block별 checksum을 확인합니다(파일을 두 번 읽지 않아도 되며, 읽는 동안 checksum이 검증됩니다). 이렇게 하면 수신 측에서 `INSERT`가 멈추는 현상(송신 측의 잘린 .bin 파일로 인해 발생)을 방지할 수 있습니다. - batch `INSERT`를 위해 .bin 파일을 두 번 읽지 않도록 개선했습니다(기존에는 squashing을 고려해 행 수/바이트 수를 계산하기 위해 필요했지만, 이제 이 정보가 header에 포함되며 하위 호환성도 유지됩니다). [#18853](https://github.com/ClickHouse/ClickHouse/pull/18853) ([Azat Khuzhin](https://github.com/azat)).
* 긴 이름을 `?`로 마스킹하지 않고 쿼리를 정규화할 수 있도록 `normalizeQueryKeepNames` 및 `normalizedQueryHashKeepNames`를 추가했습니다. 이를 통해 복잡한 query log를 더 효과적으로 분석할 수 있습니다. [#18910](https://github.com/ClickHouse/ClickHouse/pull/18910) ([Amos Bird](https://github.com/amosbird)).
* Docker image: clickhouse-server 엔트리포인트에 여러 개선 사항을 적용했습니다. [#18954](https://github.com/ClickHouse/ClickHouse/pull/18954) ([filimonov](https://github.com/filimonov)).
* 매우 큰 문자열로 데이터를 삽입할 때 발생하던 `PeekableReadBuffer: Memory limit exceed` 오류를 수정했습니다. [#18690](https://github.com/ClickHouse/ClickHouse/issues/18690)을 수정합니다. [#18979](https://github.com/ClickHouse/ClickHouse/pull/18979) ([Alexander Tokmakov](https://github.com/tavplubix)).
* clickhouse-server image에서 clickhouse 사용자 및 그룹의 uid/gid를 고정값(101)으로 명시적으로 설정했습니다. [#19096](https://github.com/ClickHouse/ClickHouse/pull/19096) ([filimonov](https://github.com/filimonov)).
* 특정 NaN 인수로 함수 `bar`를 호출할 때 발생하는 예외 메시지가 이전 버전에서는 다소 오해의 소지가 있었습니다. 이 변경으로 [#19088](https://github.com/ClickHouse/ClickHouse/issues/19088)을 수정합니다. [#19107](https://github.com/ClickHouse/ClickHouse/pull/19107) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 재시작 없이 `max_server_memory_usage`를 변경할 수 있도록 했습니다. 이로써 [#18154](https://github.com/ClickHouse/ClickHouse/issues/18154)가 해결되었습니다. [#19186](https://github.com/ClickHouse/ClickHouse/pull/19186) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Pretty 형식에서 `IPv4` 데이터 타입 값의 정렬이 잘못되던 문제를 수정했습니다. 기존에는 왼쪽이 아니라 오른쪽으로 정렬되었습니다. 이로써 [#19184](https://github.com/ClickHouse/ClickHouse/issues/19184)가 해결되었습니다. [#19339](https://github.com/ClickHouse/ClickHouse/pull/19339) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Docker를 임의의 uid로 실행할 수 있도록 했습니다. [#19374](https://github.com/ClickHouse/ClickHouse/pull/19374) ([filimonov](https://github.com/filimonov)).
* MergeTree 파트의 유형(Wide/Compact/InMemory)에 대한 메트릭을 추가했습니다. [#19381](https://github.com/ClickHouse/ClickHouse/pull/19381) ([Azat Khuzhin](https://github.com/azat)).
* MySQL 호환성을 개선했습니다. [#19387](https://github.com/ClickHouse/ClickHouse/pull/19387) ([Daniil Kondratyev](https://github.com/dankondr)).
* `system.query_log`, `system.processes` 등에 `http_referer` 필드를 추가했습니다. 이로써 [#19389](https://github.com/ClickHouse/ClickHouse/issues/19389)가 해결되었습니다. [#19390](https://github.com/ClickHouse/ClickHouse/pull/19390) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `toIPv6` 함수가 `IPv4` 주소를 파싱할 수 있도록 했습니다. [#19518](https://github.com/ClickHouse/ClickHouse/pull/19518) ([Bharat Nallan](https://github.com/bharatnc)).
* `.debug` 파일의 새 위치를 사용할 수 있도록 지원합니다. 이 변경으로 [#19348](https://github.com/ClickHouse/ClickHouse/issues/19348)을 수정합니다. [#19520](https://github.com/ClickHouse/ClickHouse/pull/19520) ([Amos Bird](https://github.com/amosbird)).
* 맵 데이터 타입에 대해 `length`/`empty`/`notEmpty` 함수를 사용할 수 있도록 하여 맵의 키 개수를 반환하게 했습니다. [#19530](https://github.com/ClickHouse/ClickHouse/pull/19530) ([李扬](https://github.com/taiyang-li)).
* 함수 `multiIf`에서 상수 결과를 지원합니다. [#19533](https://github.com/ClickHouse/ClickHouse/pull/19533) ([Maksim Kita](https://github.com/kitaisreal)).
* 읽기 시 체크섬 검증을 비활성화하는 옵션을 추가했습니다. 프로덕션에서는 절대 사용해서는 안 됩니다. 비활성화해도 어떤 이점도 기대하지 마십시오. 실험 및 벤치마크에만 사용할 수 있습니다. 이 설정은 MergeTree 엔진 계열의 테이블에만 적용됩니다. 다른 테이블 엔진과 네트워크를 통해 데이터를 수신할 때는 체크섬이 항상 검증됩니다. 확인한 바에 따르면 성능 차이는 없거나 0.5% 미만입니다. [#19588](https://github.com/ClickHouse/ClickHouse/pull/19588) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 속성 파싱 중 발생하는 딕셔너리 오류 메시지를 개선했습니다. [#19678](https://github.com/ClickHouse/ClickHouse/pull/19678) ([Maksim Kita](https://github.com/kitaisreal)).
* 비복제 MergeTree에서 드물게 발생하던 `max_number_of_merges_with_ttl_in_pool` 한도 초과 문제(TTL이 있는 머지가 더 많이 할당될 수 있음)를 수정했습니다. [#19708](https://github.com/ClickHouse/ClickHouse/pull/19708) ([alesapin](https://github.com/alesapin)).
