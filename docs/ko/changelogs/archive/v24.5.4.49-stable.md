<div id="improvement">
  #### 개선 사항
</div>

* [#65886](https://github.com/ClickHouse/ClickHouse/issues/65886)에 백포트됨: Global Thread 풀에 충분한 수의 스레드가 있도록 Keeper를 항상 시작합니다. [#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94)).
* [#65304](https://github.com/ClickHouse/ClickHouse/issues/65304)에 백포트됨: CSV 형식에서 튜플을 처리하고 해석하는 ClickHouse의 기존 동작을 복원했습니다. 이 변경은 사실상 [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994)를 되돌리는 것이며, 일부 설정에서만 사용할 수 있습니다: `output_format_csv_serialize_tuple_into_separate_columns`, `input_format_csv_deserialize_separate_columns_into_tuple`, `input_format_csv_try_infer_strings_from_quoted_tuples`. [#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#65896](https://github.com/ClickHouse/ClickHouse/issues/65896)에 백포트됨: Keeper에서 cgroup CPU 제한을 준수합니다. [#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 치명적 오동작 수정 (크래시, LOGICAL_ERROR, 데이터 손실, RBAC)
</div>

* [#65287](https://github.com/ClickHouse/ClickHouse/issues/65287)에 백포트됨: UniqInjectiveFunctionsEliminationPass 및 uniqCombined에서 발생하던 크래시를 수정했습니다. [#65188](https://github.com/ClickHouse/ClickHouse/pull/65188) ([Raúl Marín](https://github.com/Algunenano)).
* [#65374](https://github.com/ClickHouse/ClickHouse/issues/65374)에 백포트됨: 세션 종료 중 digest 불일치를 유발하는 ClickHouse Keeper의 버그를 수정했습니다. [#65198](https://github.com/ClickHouse/ClickHouse/pull/65198) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#65437](https://github.com/ClickHouse/ClickHouse/issues/65437)에 백포트됨: 기존 분석기에서 `QUALIFY` 절을 금지했습니다. 기존 분석기는 `QUALIFY`를 무시했기 때문에 뮤테이션에서 예기치 않은 데이터 삭제로 이어질 수 있었습니다. [#65356](https://github.com/ClickHouse/ClickHouse/pull/65356) ([Dmitry Novik](https://github.com/novikd)).
* [#65450](https://github.com/ClickHouse/ClickHouse/issues/65450)에 백포트됨: Distinct combinator에 올바른 메모리 정렬을 사용하도록 수정했습니다. 이전에는 combinator 사용 시 잘못된 메모리 할당으로 인해 크래시가 발생할 수 있었습니다. [#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)).
* [#65712](https://github.com/ClickHouse/ClickHouse/issues/65712)에 백포트됨: maxIntersections에서 발생하던 크래시를 수정했습니다. [#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#65331](https://github.com/ClickHouse/ClickHouse/issues/65331)에 백포트됨: 아직 복원되지 않은 definer로 MV를 생성해 backup으로부터의 복원이 차단될 때 발생하는 크래시 루프를 수정했습니다. [#64595](https://github.com/ClickHouse/ClickHouse/pull/64595) ([pufit](https://github.com/pufit)).
* [#64835](https://github.com/ClickHouse/ClickHouse/issues/64835)에 백포트됨: 표현식이 포함된 TTL이 동작하지 않을 수 있는 버그를 수정했습니다. [#64694](https://github.com/ClickHouse/ClickHouse/pull/64694) ([alesapin](https://github.com/alesapin)).
* [#65542](https://github.com/ClickHouse/ClickHouse/issues/65542)에 백포트됨: `ALTER TABLE ... ON CLUSTER ... MODIFY SQL SECURITY` 수행 시 발생하는 크래시를 수정했습니다. [#64957](https://github.com/ClickHouse/ClickHouse/pull/64957) ([pufit](https://github.com/pufit)).
* [#65580](https://github.com/ClickHouse/ClickHouse/issues/65580)에 백포트됨: AccessControl 종료 중 발생하는 크래시를 수정하기 위해 명시적 종료를 추가했습니다. [#64993](https://github.com/ClickHouse/ClickHouse/pull/64993) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#65618](https://github.com/ClickHouse/ClickHouse/issues/65618)에 백포트됨: 순환 alias가 있는 경우 쿼리 실행 시간이 무한정 길어질 수 있는 문제를 수정했습니다. [#64849](https://github.com/ClickHouse/ClickHouse/issues/64849)를 수정합니다. [#65081](https://github.com/ClickHouse/ClickHouse/pull/65081) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65617](https://github.com/ClickHouse/ClickHouse/issues/65617)에 백포트됨: 새 분석기에서 집계 함수 이름이 재작성되는 문제를 수정했습니다. [#65110](https://github.com/ClickHouse/ClickHouse/pull/65110) ([Dmitry Novik](https://github.com/novikd)).
* [#65732](https://github.com/ClickHouse/ClickHouse/issues/65732)에 백포트됨: `uniq*` 함수의 인수에서 injective 함수를 재귀적으로 제거하도록 수정했습니다. 이전에는 올바르게 동작했지만 새 분석기에서 문제가 발생했습니다. [#65140](https://github.com/ClickHouse/ClickHouse/pull/65140) ([Duc Canh Le](https://github.com/canhld94)).
* [#65265](https://github.com/ClickHouse/ClickHouse/issues/65265)에 백포트됨: Hashed 및 Hashed&#95;Array 딕셔너리의 단락 평가(short-circuit evaluation)에서 발생하는 버그를 수정했습니다. 이 문제로 초기화되지 않은 숫자를 읽어 다양한 오류가 발생할 수 있었습니다. [#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)).
* [#65663](https://github.com/ClickHouse/ClickHouse/issues/65663)에 백포트됨: `read-in-order` 최적화가 활성화된 경우 `FINAL`이 포함된 쿼리에서 `non-intersecting-parts` 최적화를 비활성화했습니다. 이 문제로 잘못된 쿼리 결과가 반환될 수 있었습니다. 우회 방법으로, 이 수정이 머지되기 전에는 `do_not_merge_across_partitions_select_final` 및 `split_parts_ranges_into_intersecting_and_non_intersecting_final`을 비활성화하십시오. [#65505](https://github.com/ClickHouse/ClickHouse/pull/65505) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65788](https://github.com/ClickHouse/ClickHouse/issues/65788)에 백포트됨: MergeJoin의 버그를 수정했습니다. 희소 직렬화의 컬럼이 필요한 변환이 수행되지 않았음에도 해당 Nested 유형의 컬럼으로 처리될 수 있었습니다. [#65632](https://github.com/ClickHouse/ClickHouse/pull/65632) ([Nikita Taranov](https://github.com/nickitat)).
* [#65812](https://github.com/ClickHouse/ClickHouse/issues/65812)에 백포트됨: `parseDateTime` 함수에서 `%F` 및 `%D` 플레이스홀더와 관련된 잘못된 예외를 수정했습니다. [#65768](https://github.com/ClickHouse/ClickHouse/pull/65768) ([Antonio Andelic](https://github.com/antonio2368)).
* [#65828](https://github.com/ClickHouse/ClickHouse/issues/65828)에 백포트됨: 기존 분석기와 `dictGetOrDefault`를 사용할 때 단락 평가 로직의 버그를 수정했습니다. [#65802](https://github.com/ClickHouse/ClickHouse/pull/65802) ([jsc0218](https://github.com/jsc0218)).
