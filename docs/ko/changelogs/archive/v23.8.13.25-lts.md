<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)

* [#62898](https://github.com/ClickHouse/ClickHouse/issues/62898)에 백포트됨: zero-copy 복제(실험적 기능)의 버그를 수정했습니다. 이 버그는 REPLACE/MOVE PARTITION 이후 `The specified key does not exist` 오류와 데이터 손실을 일으킬 수 있었습니다. 디스크 간 TTL 이동 작업에서도 비슷한 문제가 발생할 수 있습니다. [#54193](https://github.com/ClickHouse/ClickHouse/pull/54193) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#61964](https://github.com/ClickHouse/ClickHouse/issues/61964)에 백포트됨: initiator 노드에 데이터베이스가 없을 때 ON CLUSTER 절이 포함된 ATTACH 쿼리 문제를 수정했습니다. [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009)를 닫습니다. [#61365](https://github.com/ClickHouse/ClickHouse/pull/61365) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#62527](https://github.com/ClickHouse/ClickHouse/issues/62527)에 백포트됨: `MOVE PARTITION` 쿼리와 머지 작업 사이의 data race로 인해 intersecting parts가 발생하는 문제를 수정했습니다. [#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#62238](https://github.com/ClickHouse/ClickHouse/issues/62238)에 백포트됨: `input_format_allow_errors_num/ratio` 설정을 사용할 때 JSON 데이터 parsing 중 escape sequence parsing 오류를 건너뛰는 동작을 수정했습니다. [#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar)).
* [#62673](https://github.com/ClickHouse/ClickHouse/issues/62673)에 백포트됨: Hive 테이블 엔진 사용 시 segmentation fault가 발생하는 문제를 수정했습니다. 참고: [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154), [#62560](https://github.com/ClickHouse/ClickHouse/issues/62560). [#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)).
