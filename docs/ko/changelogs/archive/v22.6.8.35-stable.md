<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 보이는 오동작)
</div>

* [#41282](https://github.com/ClickHouse/ClickHouse/issues/41282)에 백포트됨: WITH 문으로 도입된, 사용되지 않는 알 수 없는 컬럼 관련 문제를 수정합니다. 이 변경은 [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812)를 수정합니다. [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* [#40905](https://github.com/ClickHouse/ClickHouse/issues/40905)에 백포트됨: 작업 scheduling 실패 시 WriteBufferFromS3에서 발생할 수 있는 잠재적인 데드락을 수정합니다. [#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)).
* [#40864](https://github.com/ClickHouse/ClickHouse/issues/40864)에 백포트됨: - 가변 차원 배열을 포함하는 `Object` 타입 값을 파싱하는 중 발생하는 크래시를 수정합니다. [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* [#40803](https://github.com/ClickHouse/ClickHouse/issues/40803)에 백포트됨: 새 쿼리를 `ProcessList`에 삽입하는 동안 메모리 할당이 발생합니다. 이 과정에서 memory limit에 도달하면 `ProcessList::mutex`를 이미 획득한 상태이므로 `OvercommitTracker`를 사용할 수 없습니다. [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)을 수정합니다. [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* [#40891](https://github.com/ClickHouse/ClickHouse/issues/40891)에 백포트됨: 쿼리 Context 없이 MV로 푸시할 때(Kafka/...에서) 발생하는 메모리 누수를 수정합니다. [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* [#41133](https://github.com/ClickHouse/ClickHouse/issues/41133)에 백포트됨: `DESCRIBE TABLE url()` 및 일부 다른 `DESCRIBE TABLE <table_function>()`에 대한 접근 권한을 수정합니다. [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#41360](https://github.com/ClickHouse/ClickHouse/issues/41360)에 백포트됨: 디스크 객체 스토리지에서 발생하는 잘못된 logical error `Expected relative path`를 수정합니다. [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246)와 관련이 있습니다. [#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#41357](https://github.com/ClickHouse/ClickHouse/issues/41357)에 백포트됨: MsgPack 포맷에서 UUID 삽입 전에 컬럼 타입 검사를 추가합니다. [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
