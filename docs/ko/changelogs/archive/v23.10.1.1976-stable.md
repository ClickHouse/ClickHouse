  ### ClickHouse 릴리스 v23.10.1.1976-안정 (13adae0e42f) FIXME v23.9.1.1854-안정 (8f9a227de1f) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* S3Queue 스토리지를 완전히 재작성했습니다. ZooKeeper에 정보를 유지하는 방식을 변경해 ZooKeeper 요청 수를 줄였고, 상태가 변경되지 않는 것이 확실한 경우에는 ZooKeeper 상태 캐싱을 추가했으며, S3에서 폴링하는 프로세스도 덜 공격적으로 동작하도록 개선했습니다. 또한 추적된 파일의 TTL 및 max set 유지 방식도 변경했으며, 이제 이는 백그라운드 프로세스로 처리됩니다. `system.s3queue` 및 `system.s3queue_log` 테이블이 추가되었습니다. [#54998](https://github.com/ClickHouse/ClickHouse/issues/54998)을 종료합니다. [#54422](https://github.com/ClickHouse/ClickHouse/pull/54422) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 손상된 데이터 파트를 자동으로 제거하는 옵션은 더 이상 제공되지 않습니다. 이 변경으로 [#55174](https://github.com/ClickHouse/ClickHouse/issues/55174)가 종료됩니다. [#55184](https://github.com/ClickHouse/ClickHouse/pull/55184) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 더 이상 오래된 인메모리 데이터 파트를 write-ahead log에서 읽을 수 없습니다. 이전에 인메모리 파트를 구성한 경우 업그레이드 전에 제거해야 합니다. [#55186](https://github.com/ClickHouse/ClickHouse/pull/55186) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Meilisearch와의 통합을 제거했습니다. 이유: 이전 0.18 버전하고만 호환되었기 때문입니다. 최신 Meilisearch 버전에서는 protocol이 변경되어 더 이상 동작하지 않습니다. 참고: 이 기능을 다시 복구할 수 있도록 도와주시면 감사하겠습니다. [#55189](https://github.com/ClickHouse/ClickHouse/pull/55189) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* directory monitor 개념의 이름을 background INSERT로 변경했습니다. 모든 `*directory_monitor*` 설정의 이름이 `distributed_background_insert*`로 변경되었습니다. **이전 버전과의 호환성은 유지되어야 합니다** (기존 설정이 alias로 추가되었기 때문입니다). [#55978](https://github.com/ClickHouse/ClickHouse/pull/55978) ([Azat Khuzhin](https://github.com/azat)).
* send&#95;timeout과 receive&#95;timeout이 혼동되지 않도록 수정했습니다. [#56035](https://github.com/ClickHouse/ClickHouse/pull/56035) ([Azat Khuzhin](https://github.com/azat)).
* 단위가 서로 다른 시간 인터벌을 비교하면 예외를 발생시킵니다. 이 변경으로 [#55942](https://github.com/ClickHouse/ClickHouse/issues/55942)가 종료됩니다. 이전에는 단위와 무관하게 내부 숫자값을 비교하는 동작에 경우에 따라 의존했을 수 있습니다. [#56090](https://github.com/ClickHouse/ClickHouse/pull/56090) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 새 기능
</div>

* 동일한 길이의 여러 배열에 람다 함수를 적용하고, 결과를 누산기에 모으는 함수 &quot;arrayFold(x1, ..., xn, accum -&gt; expression, array1, ..., arrayn, init&#95;accum)&quot;를 추가했습니다. [#49794](https://github.com/ClickHouse/ClickHouse/pull/49794) ([Lirikl](https://github.com/Lirikl)).
* 데이터 시각화를 위한 다운샘플링에 [Largest-Triangle-Three-Buckets](https://skemman.is/bitstream/1946/15343/3/SS_MSthesis.pdf) 알고리즘을 사용하는 집계 함수 lttb를 추가했습니다. [#53145](https://github.com/ClickHouse/ClickHouse/pull/53145) ([Sinan](https://github.com/sinsinan)).
* 쿼리 `CHECK TABLE`의 성능과 사용성이 개선되었습니다(진행률 업데이트 전송, 취소 가능). `CHECK TABLE ... PART 'part_name'`를 사용해 특정 part를 검사하는 기능도 지원합니다. [#53404](https://github.com/ClickHouse/ClickHouse/pull/53404) ([vdimir](https://github.com/vdimir)).
* 함수 `jsonMergePatch`를 추가했습니다. JSON 데이터를 문자열로 다룰 때, JSON 객체를 나타내는 이러한 문자열들을 병합해 단일 JSON 객체를 담은 하나의 문자열을 만들 수 있습니다. [#54364](https://github.com/ClickHouse/ClickHouse/pull/54364) ([Memo](https://github.com/Joeywzr)).
* 입력 배열에서 k개 요소의 샘플을 반환하는 새로운 SQL 함수 &quot;arrayRandomSample(arr, k)&quot;를 추가했습니다. 이전에는 이와 유사한 기능을 &quot;SELECT arrayReduce(&#39;groupArraySample(3)&#39;, range(10))&quot;와 같이 덜 편리한 구문으로만 구현할 수 있었습니다. [#54391](https://github.com/ClickHouse/ClickHouse/pull/54391) ([itayisraelov](https://github.com/itayisraelov)).
* ClickHouse 서버에 대한 요청에 사용된 HTTP 요청 헤더 값을 가져오는 새 함수 `getHttpHeader`를 추가했습니다. 요청이 HTTP protocol을 통해 수행되지 않았거나 해당 헤더가 없으면 빈 문자열을 반환합니다. [#54813](https://github.com/ClickHouse/ClickHouse/pull/54813) ([凌涛](https://github.com/lingtaolf)).
* 최소값/최대값 기준으로만 집계할 수 있게 해 주는 -ArgMin/-ArgMax 집계 조합자를 도입했습니다. 사용 예시는 [#54818](https://github.com/ClickHouse/ClickHouse/issues/54818)에서 확인할 수 있습니다. 이 PR에서는 조합자도 전용 폴더로 재구성했습니다. [#54947](https://github.com/ClickHouse/ClickHouse/pull/54947) ([Amos Bird](https://github.com/amosbird)).
* `SYSTEM DROP SCHEMA FORMAT CACHE [FOR Protobuf]`를 사용해 Protobuf 형식의 캐시를 삭제할 수 있도록 했습니다. [#55064](https://github.com/ClickHouse/ClickHouse/pull/55064) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* 외부 HTTP Basic 인증자를 추가했습니다. [#55199](https://github.com/ClickHouse/ClickHouse/pull/55199) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 부호 없는 정수의 바이트 순서를 뒤집는 함수 `byteSwap`를 추가했습니다. 이는 특히 IPv4처럼 내부적으로 부호 없는 정수로 표현되는 타입의 값을 뒤집는 데 유용합니다. [#55211](https://github.com/ClickHouse/ClickHouse/pull/55211) ([Priyansh Agrawal](https://github.com/Priyansh121096)).
* SQL 쿼리 문자열의 포맷된 버전(여러 줄로 구성될 수 있음)을 반환하는 함수 `formatQuery()`를 추가했습니다. 같은 작업을 수행하지만 반환되는 문자열에 줄바꿈이 포함되지 않는 함수 `formatQuerySingleLine()`도 추가했습니다. [#55239](https://github.com/ClickHouse/ClickHouse/pull/55239) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* ELF 실행 파일/라이브러리/object file에서 디버그 심볼을 읽는 DWARF 입력 형식을 추가했습니다. [#55450](https://github.com/ClickHouse/ClickHouse/pull/55450) ([Michael Kolupaev](https://github.com/al13n321)).
* RabbitMQ, NATS 및 FileLog 엔진에서 파싱되지 않은 레코드와 오류를 저장할 수 있도록 지원합니다. ClickHouse가 새 레코드를 파싱하지 못할 때 채워지는 가상 컬럼 `_error` 및 `_raw_message`(NATS 및 RabbitMQ용), `_raw_record`(FileLog용)를 추가합니다. 이 동작은 `kafka_handle_error_mode`와 유사하게 NATS에서는 스토리지 설정 `nats_handle_error_mode`, RabbitMQ에서는 `rabbitmq_handle_error_mode`, FileLog에서는 `handle_error_mode`로 제어됩니다. 값이 `default`로 설정되면 ClickHouse가 레코드를 파싱하지 못할 때 예외가 발생하고, `stream`으로 설정되면 오류와 원시 레코드가 가상 컬럼에 저장됩니다. [#36035](https://github.com/ClickHouse/ClickHouse/issues/36035)을 닫습니다. [#55477](https://github.com/ClickHouse/ClickHouse/pull/55477) ([Kruglov Pavel](https://github.com/Avogar)).
* Keeper 클라이언트 개선 사항: 특정 경로 아래의 모든 하위 노드 수를 반환하는 get&#95;all&#95;children&#95;number 명령을 추가합니다. [#55485](https://github.com/ClickHouse/ClickHouse/pull/55485) ([guoxiaolong](https://github.com/guoxiaolongzte)).
* 테이블 키에 공간 채우기 곡선이 있는 경우(예: `ORDER BY mortonEncode(x, y)`), 해당 인수에 대한 조건(예: `x >= 10 AND x <= 20 AND y >= 20 AND y <= 30`)을 인덱싱에 사용할 수 있습니다. 이 분석을 활성화하거나 비활성화하는 설정 `analyze_index_with_space_filling_curves`가 추가되었습니다. 이는 [#41195](https://github.com/ClickHouse/ClickHouse/issues/41195)를 닫습니다. [#4538](https://github.com/ClickHouse/ClickHouse/issues/4538)의 후속 작업입니다. [#6286](https://github.com/ClickHouse/ClickHouse/issues/6286)의 후속 작업입니다. [#28130](https://github.com/ClickHouse/ClickHouse/issues/28130)의 후속 작업입니다. [#41753](https://github.com/ClickHouse/ClickHouse/issues/41753)의 후속 작업입니다. [#55642](https://github.com/ClickHouse/ClickHouse/pull/55642) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* EmbeddedRocksDB 스토리지에서 `count()` 근사를 사용하기 위한 설정 `optimize_trivial_approximate_count_query`를 추가합니다. StorageJoin에 대해서도 trivial count를 활성화합니다. [#55806](https://github.com/ClickHouse/ClickHouse/pull/55806) ([Duc Canh Le](https://github.com/canhld94)).
* Keeper 클라이언트 개선 사항: 경로 아래의 직접 하위 노드 수를 반환하는 get&#95;direct&#95;children&#95;number 명령을 추가합니다. [#55898](https://github.com/ClickHouse/ClickHouse/pull/55898) ([xuzifu666](https://github.com/xuzifu666)).
* 기존 구문 `SHOW SETTINGS`의 더 간단한 버전인 `SHOW SETTING setting_name` 구문을 추가합니다. [#55979](https://github.com/ClickHouse/ClickHouse/pull/55979) ([Maksim Kita](https://github.com/kitaisreal)).
* 이 PR은 Npy format으로 데이터를 ClickHouse에 전달할 수 있는 기능을 제공합니다. &#96;&#96;&#96; SELECT * FROM file(&#39;example&#95;array.npy&#39;, Npy). [#55982](https://github.com/ClickHouse/ClickHouse/pull/55982) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 이 PR은 `force_optimize_projection_name`이라는 새로운 설정을 구현하며, projection 이름을 인수로 받습니다. 값이 비어 있지 않은 문자열로 설정되면 ClickHouse는 이 projection이 쿼리에서 최소 한 번 이상 사용되는지 확인합니다. [#55331](https://github.com/ClickHouse/ClickHouse/issues/55331)을 닫습니다. [#56134](https://github.com/ClickHouse/ClickHouse/pull/56134) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 병렬 스트림 처리를 가능하게 하기 위해, 윈도우 함수를 평가한 뒤에도 스트림 수를 유지하는 옵션 `query_plan_preserve_num_streams_after_window_functions`를 추가했습니다. [#50771](https://github.com/ClickHouse/ClickHouse/pull/50771) ([frinkr](https://github.com/frinkr)).
* 데이터가 작을 때 더 많은 `num_streams`를 해제합니다. [#53867](https://github.com/ClickHouse/ClickHouse/pull/53867) ([Jiebin Sun](https://github.com/jiebinn)).
* RoaringBitmaps를 직렬화 전에 최적화합니다. [#55044](https://github.com/ClickHouse/ClickHouse/pull/55044) ([UnamedRus](https://github.com/UnamedRus)).
* 역인덱스의 포스팅 리스트가 이제 내부 비트맵에 대해 가능한 한 가장 작은 표현을 사용하도록 최적화되었습니다. 데이터의 반복성에 따라 역인덱스의 공간 활용을 크게 줄일 수 있습니다. [#55069](https://github.com/ClickHouse/ClickHouse/pull/55069) ([Harry Lee](https://github.com/HarryLeeIBM)).
* Context 잠금 경합을 수정하여, 짧게 실행되는 동시 쿼리가 많은 경우 성능을 크게 개선했습니다. [#55121](https://github.com/ClickHouse/ClickHouse/pull/55121) ([Maksim Kita](https://github.com/kitaisreal)).
* 역인덱스 생성 성능을 30% 개선했습니다. 이는 `std::unordered_map`을 `absl::flat_hash_map`으로 대체해 달성했습니다. [#55210](https://github.com/ClickHouse/ClickHouse/pull/55210) ([Harry Lee](https://github.com/HarryLeeIBM)).
* ORC 필터 푸시다운(행 그룹 수준)을 지원합니다. [#55330](https://github.com/ClickHouse/ClickHouse/pull/55330) ([李扬](https://github.com/taiyang-li)).
* 임시 파일이 많은 경우 외부 집계의 성능을 개선했습니다. [#55489](https://github.com/ClickHouse/ClickHouse/pull/55489) ([Maksim Kita](https://github.com/kitaisreal)).
* 마크를 반복해서 로드하지 않도록, 보조 인덱스용 마크 캐시의 기본 크기를 합리적으로 설정했습니다. [#55654](https://github.com/ClickHouse/ClickHouse/pull/55654) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 스킵 인덱스를 읽을 때 불필요하게 인덱스 그래뉼을 재구성하지 않도록 했습니다. 이는 [#55653](https://github.com/ClickHouse/ClickHouse/issues/55653)#issuecomment-1763766009를 해결합니다. [#55683](https://github.com/ClickHouse/ClickHouse/pull/55683) ([Amos Bird](https://github.com/amosbird)).
* Set의 요소 타입이 컬럼 타입과 정확히 일치하지 않을 때 함수 `IN`의 성능을 개선하기 위해, 실행 중 Set의 CAST 함수를 캐시합니다. [#55712](https://github.com/ClickHouse/ClickHouse/pull/55712) ([Duc Canh Le](https://github.com/canhld94)).
* `ColumnVector::insertMany`와 `ColumnVector::insertManyFrom`의 성능을 개선했습니다. [#55714](https://github.com/ClickHouse/ClickHouse/pull/55714) ([frinkr](https://github.com/frinkr)).
* ... 맵에서 값을 가져오는 작업은 매우 자주 사용됩니다. 실제로는 동일한 맵 컬럼 내에서 키 구조가 대체로 같기 때문에, 다음 행의 키 위치를 예측해 비교 횟수를 줄일 수 있습니다. [#55929](https://github.com/ClickHouse/ClickHouse/pull/55929) ([lgbo](https://github.com/lgbo-ustc)).
* ... 일부 경우 구조체 필드 프루닝이 동작하지 않는 문제를 수정했습니다. 예를 들어 &#96;&#96;&#96;sql INSERT INTO FUNCTION file(&#39;test&#95;parquet&#95;struct&#39;, Parquet, &#39;x Tuple(a UInt32, b UInt32, c String)&#39;) SELECT tuple(number, rand(), concat(&#39;testxxxxxxx&#39; toString(number))) FROM numbers(10);. [#56117](https://github.com/ClickHouse/ClickHouse/pull/56117) ([lgbo](https://github.com/lgbo-ustc)).

<div id="improvement">
  #### 개선 사항
</div>

* Kusto Query Language 방언 지원의 두 번째 부분입니다. [1단계 구현 ](https://github.com/ClickHouse/ClickHouse/pull/37961)이 병합되었습니다. [#42510](https://github.com/ClickHouse/ClickHouse/pull/42510) ([larryluogit](https://github.com/larryluogit)).
* Op processors ID는 raw ptrs를 UInt64로 캐스팅한 값입니다. 이를 더 보기 좋은 형식으로 출력합니다. [#48852](https://github.com/ClickHouse/ClickHouse/pull/48852) ([Vlad Seliverstov](https://github.com/behebot)).
* lifetime 필드가 설정된 direct 딕셔너리는 생성 시 거부되도록 합니다. 수정: [#27861](https://github.com/ClickHouse/ClickHouse/issues/27861). [#49043](https://github.com/ClickHouse/ClickHouse/pull/49043) ([Rory Crispin](https://github.com/RoryCrispin)).
* `ALTER TABLE t DROP PARTITION`와 같은 파티션 관련 쿼리에서 매개변수를 허용합니다. [#49449](https://github.com/ClickHouse/ClickHouse/issues/49449)를 닫습니다. [#49516](https://github.com/ClickHouse/ClickHouse/pull/49516) ([Nikolay Degterinsky](https://github.com/evillique)).
* 1. zookeeper&#95;connection 관련 코드를 리팩터링합니다. 2. zookeeper&#95;connection에 xid라는 새 컬럼을 추가합니다. [#50702](https://github.com/ClickHouse/ClickHouse/pull/50702) ([helifu](https://github.com/helifu)).
* 읽을 행 수 추정치를 바탕으로 쿼리 실행에 사용되는 병렬 레플리카 수를 조정할 수 있는 기능을 추가합니다. [#51692](https://github.com/ClickHouse/ClickHouse/pull/51692) ([Raúl Marín](https://github.com/Algunenano)).
* 이제 `async_socket_for_remote` 모드(기본값)에서 실행되는 분산 쿼리는 `max_threads` 제한을 준수합니다. 이전에는 일부 쿼리가 과도한 수의 스레드(최대 `max_distributed_connections`)를 생성해 서버 성능 문제를 일으킬 수 있었습니다. [#53504](https://github.com/ClickHouse/ClickHouse/pull/53504) ([filimonov](https://github.com/filimonov)).
