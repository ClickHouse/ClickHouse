<div id="improvement">
  #### 개선 사항
</div>

* [#48459](https://github.com/ClickHouse/ClickHouse/issues/48459)에 백포트됨: 이제 `formatDateTime()` 함수의 Formatter &#39;%M&#39;은 분이 아니라 월 이름을 출력합니다. 이로써 MySQL과 동작이 일관되게 됩니다. 이전 동작은 setting &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot;을 사용해 복원할 수 있습니다. [#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).
* [#48842](https://github.com/ClickHouse/ClickHouse/issues/48842)에 백포트됨: mysql 딕셔너리 소스 + 명명된 컬렉션에서 일부 mysql 관련 설정이 처리되지 않던 문제를 수정합니다. [#48402](https://github.com/ClickHouse/ClickHouse/issues/48402)를 닫습니다. [#48759](https://github.com/ClickHouse/ClickHouse/pull/48759) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#49035](https://github.com/ClickHouse/ClickHouse/issues/49035)에 백포트됨: SSL 사용자 인증서를 사용한 인증이 실패한 경우 password authentication으로 폴백하도록 추가합니다. [#48974](https://github.com/ClickHouse/ClickHouse/issues/48974)를 닫습니다. [#48989](https://github.com/ClickHouse/ClickHouse/pull/48989) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 기능 하나를 제거했습니다 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* rabbitmq의 CPU 사용량 문제를 수정했습니다([#44404](https://github.com/ClickHouse/ClickHouse/issues/44404) 이후 23.2에서 악화됨) [#48311](https://github.com/ClickHouse/ClickHouse/pull/48311) ([Kseniia Sumarokova](https://github.com/kssenii)).
* DistributedSink의 스레드 풀을 수정하고, 추가 오류를 방지하기 위해 CurrentMetrics/ProfileEvents/StatusInfo에 StrongTypedef를 사용하도록 했습니다 [#48314](https://github.com/ClickHouse/ClickHouse/pull/48314) ([Azat Khuzhin](https://github.com/azat)).
* TemporaryFileStream에서 cache file segment용 downloader를 재설정했습니다 [#48386](https://github.com/ClickHouse/ClickHouse/pull/48386) ([Vladimir C](https://github.com/vdimir)).
* 딕셔너리에 의존하는 분산 테이블을 로딩할 때 발생하는 ClickHouse 시작 오류를 수정했습니다 [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* cache에서 발생할 수 있는 segfault를 수정했습니다 [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* IP 및 UUID 타입의 키에 대한 중첩 맵을 수정했습니다 [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* ACL에서 간헐적으로 node가 `auth` scheme으로 생성되지 않는 Keeper 버그를 수정했습니다 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* IPv4를 UInt와 비교할 수 있도록 수정했습니다 [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
