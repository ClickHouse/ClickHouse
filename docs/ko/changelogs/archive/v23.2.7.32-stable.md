<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 다중 StorageJoin을 사용하는 쿼리에서 키를 찾을 수 없는 오류를 수정하였습니다. [#49137](https://github.com/ClickHouse/ClickHouse/pull/49137) ([vdimir](https://github.com/vdimir)).
* 오래된 파트 로딩 시 발생하는 경쟁 조건을 수정하였습니다. [#49223](https://github.com/ClickHouse/ClickHouse/pull/49223) ([Alexander Tokmakov](https://github.com/tavplubix)).
* DISTINCT의 버그를 수정하였습니다. [#49628](https://github.com/ClickHouse/ClickHouse/pull/49628) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* randomStringUTF8(<홀수>)에서 발생하는 msan 문제를 수정하였습니다. [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze)).
* protobuf에서 IPv6 인코딩 오류를 수정하였습니다. [#49933](https://github.com/ClickHouse/ClickHouse/pull/49933) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `ReplicatedMergeTree`의 attach 스레드에서 테이블 시작 시 발생하는 교착 상태를 방지하였습니다. [#50026](https://github.com/ClickHouse/ClickHouse/pull/50026) ([Antonio Andelic](https://github.com/antonio2368)).
* JIT 컴파일에서 NaN 불일치 비교 오류를 수정하였습니다. [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal)).
* 상수 조건 및 널 허용 인수와 함께 `multiIf`를 사용할 때 발생하는 크래시를 수정하였습니다. [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ)).
* 요청 전처리 중 예외 발생 시 Keeper 교착 상태를 수정하였습니다. [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr)).
