<div id="clickhouse-release-v2493128-stable-9a816c73dd4-fixme-as-compared-to-v249242-stable-de7c791a2ea">
  ### ClickHouse 릴리스 v24.9.3.128-안정 (9a816c73dd4) FIXME v24.9.2.42-안정 (de7c791a2ea) 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#71361](https://github.com/ClickHouse/ClickHouse/issues/71361)에 백포트됨: JSON 서브컬럼용 파일에서 이스케이프되지 않은 특수 문자로 인해 발생할 수 있는 `No such file or directory` 오류를 수정했습니다. [#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="new-feature">
  #### 새 기능
</div>

* [#71318](https://github.com/ClickHouse/ClickHouse/issues/71318)에 백포트됨: 각 인증 메서드별로 자체 만료 날짜를 설정할 수 있도록 하고, 사용자 엔터티에서는 제거했습니다. [#70090](https://github.com/ClickHouse/ClickHouse/pull/70090) ([Arthur Passos](https://github.com/arthurpassos)).

<div id="improvement">
  #### 개선 사항
</div>

* [#70681](https://github.com/ClickHouse/ClickHouse/issues/70681)에서 백포트됨: Keeper에서 user&#95;directories를 동기화할 때 유효성 검사를 수행하지 않도록 했습니다. [#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* [#71668](https://github.com/ClickHouse/ClickHouse/issues/71668)에서 백포트됨: user/group이 ID로 지정되면 `clickhouse su`가 실패하던 문제를 수정하여 `UID:GID`도 허용합니다. ### 사용자 대상 변경 사항에 대한 문서 항목. [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#71938](https://github.com/ClickHouse/ClickHouse/issues/71938)에서 백포트됨: `history` 주기 동안 `HostResolver`를 3회 업데이트합니다. [#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#70936](https://github.com/ClickHouse/ClickHouse/issues/70936)에 백포트됨: `IS NULL` 검사가 다른 함수(예: `NOT`) 아래에 있는 경우 잘못된 결과를 초래할 수 있는 JOIN ON 절 최적화 오류를 수정했습니다. [#67915](https://github.com/ClickHouse/ClickHouse/issues/67915)를 해결했습니다. [#68049](https://github.com/ClickHouse/ClickHouse/pull/68049) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#70441](https://github.com/ClickHouse/ClickHouse/issues/70441)에 백포트됨: PostgreSQL 엔진의 FixedString 컬럼에 삽입하는 동안 발생하는 크래시를 수정했습니다. [#69584](https://github.com/ClickHouse/ClickHouse/pull/69584) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70563](https://github.com/ClickHouse/ClickHouse/issues/70563)에 백포트됨: `useDefaultImplementationForLowCardinalityColumns`가 `true`를 반환하도록 재정의해 `LowCardinality` 컬럼에서 `getSubcolumn` 문제를 수정했습니다. [#69831](https://github.com/ClickHouse/ClickHouse/pull/69831) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#70871](https://github.com/ClickHouse/ClickHouse/issues/70871)에 백포트됨: `tuple` 함수를 평가할 때 서로 다른 이름이 지정된 Tuple 간에 컬럼이 재사용되지 않도록 했습니다. 이 수정으로 [#70022](https://github.com/ClickHouse/ClickHouse/issues/70022)가 해결됩니다. [#70103](https://github.com/ClickHouse/ClickHouse/pull/70103) ([Amos Bird](https://github.com/amosbird)).
* [#70434](https://github.com/ClickHouse/ClickHouse/issues/70434)에 백포트됨: JSON 컬럼에서 발생할 수 있는 크래시를 수정했습니다. [#70172](https://github.com/ClickHouse/ClickHouse/pull/70172) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70309](https://github.com/ClickHouse/ClickHouse/issues/70309)에 백포트됨: arrayMin 및 arrayMax의 여러 문제를 수정했습니다. [#70207](https://github.com/ClickHouse/ClickHouse/pull/70207) ([Raúl Marín](https://github.com/Algunenano)).
* [#70625](https://github.com/ClickHouse/ClickHouse/issues/70625)에 백포트됨: 두 개의 SELECT와 `INTERSECT`가 포함된 materialized view를 생성할 때 발생하는 server segfault를 수정했습니다. 예: `CREATE MATERIALIZED VIEW v0 AS (SELECT 1) INTERSECT (SELECT 1);`. [#70264](https://github.com/ClickHouse/ClickHouse/pull/70264) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#70347](https://github.com/ClickHouse/ClickHouse/issues/70347)에 백포트됨: 시작 스크립트가 전역 설정을 변경하지 않도록 했습니다. 이전에는 시작 스크립트에서 설정을 변경하면 전역적으로 적용되었습니다. [#70310](https://github.com/ClickHouse/ClickHouse/pull/70310) ([Antonio Andelic](https://github.com/antonio2368)).

* [#70373](https://github.com/ClickHouse/ClickHouse/issues/70373)에 백포트됨: WITH FILL을 잘못 사용할 때 발생하는 크래시를 수정했습니다. [#70338](https://github.com/ClickHouse/ClickHouse/pull/70338) ([Raúl Marín](https://github.com/Algunenano)).

* [#70496](https://github.com/ClickHouse/ClickHouse/issues/70496)에 백포트됨: JSON 하위 객체 서브컬럼으로 GROUP BY할 때 발생하는 크래시를 수정했습니다. [#70374](https://github.com/ClickHouse/ClickHouse/pull/70374) ([Pavel Kruglov](https://github.com/Avogar)).
