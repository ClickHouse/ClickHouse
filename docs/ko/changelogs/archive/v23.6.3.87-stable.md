<div id="performance-improvement">
  #### 성능 개선
</div>

* [#52751](https://github.com/ClickHouse/ClickHouse/issues/52751)에 백포트됨: 프라이머리 키(primary keys)를 무효화하는 잘못된 프로젝션 분석을 수정했습니다. 이 문제는 `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1`인 경우에만 발생합니다. 이 변경은 [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823)을 수정합니다. 이 변경은 [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173)도 수정합니다. [#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#52911](https://github.com/ClickHouse/ClickHouse/issues/52911)에 백포트됨: `clickhouse-server` 패키지에 `clickhouse-keeper-client` 심볼릭 링크를 추가했습니다. [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53023](https://github.com/ClickHouse/ClickHouse/issues/53023)에 백포트됨: inline cache를 Docker 이미지에 패키징할 때 가끔 이상한 부작용이 발생합니다. 현재는 전혀 사용하지 않으므로 제거해도 무방합니다. [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53290](https://github.com/ClickHouse/ClickHouse/issues/53290)에 백포트됨: compiler의 프로파일 데이터(`-ftime-trace`)를 ClickHouse Cloud에 업로드합니다. [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) 이후 두 번째 시도입니다. [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#53465](https://github.com/ClickHouse/ClickHouse/issues/53465)에 백포트됨: `clickhouse start` 명령에서 환경 매개변수를 유지합니다. [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962)를 수정합니다. [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
