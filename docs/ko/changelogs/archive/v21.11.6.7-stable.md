* [#32152](https://github.com/ClickHouse/ClickHouse/issues/32152)에 백포트됨: 타입이 `Nullable`인 딕셔너리 속성에 대해 타입을 지정해 함수 `dictGet`을 사용할 때 발생하던 크래시를 수정했습니다. [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)을 수정합니다. [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32298](https://github.com/ClickHouse/ClickHouse/issues/32298)에 백포트됨: 재귀적인 사용자 정의 함수에서 발생하던 크래시를 수정했습니다. [#30856](https://github.com/ClickHouse/ClickHouse/issues/30856)을 닫습니다. [#31820](https://github.com/ClickHouse/ClickHouse/pull/31820) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32148](https://github.com/ClickHouse/ClickHouse/issues/32148)에 백포트됨: part를 detach할 때 발생하던 `Directory ... already exists and is not empty` 오류를 수정했습니다. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32212](https://github.com/ClickHouse/ClickHouse/issues/32212)에 백포트됨: `cast_keep_nullable` 사용 시 `Nullable`에서 `CAST`가 동작하지 않던 문제를 수정했습니다(이전에는 예를 들어 `toUInt32OrDefault(toNullable(toUInt32(1)))`에서 `PARAMETER_OUT_OF_BOUND` 오류가 발생했습니다). [#32080](https://github.com/ClickHouse/ClickHouse/pull/32080) ([Azat Khuzhin](https://github.com/azat)).
* [#32283](https://github.com/ClickHouse/ClickHouse/issues/32283)에 백포트됨: 사용자 지정 데이터베이스 쿼리에서 `{condition}`이 동작하지 않던 경우의 Dictionaries 문제를 수정했습니다. [#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32482](https://github.com/ClickHouse/ClickHouse/issues/32482)에 백포트됨: 클라이언트/서버 크래시로 이어질 수 있던 `APPLY lambda` 구문 분석 문제를 수정했습니다. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32217](https://github.com/ClickHouse/ClickHouse/issues/32217)에 백포트됨: 일부 레플리카에서 설정 `replicated_can_become_leader`가 비활성화된 경우, quorum으로 삽입할 때 활성 레플리카 수가 잘못 판단될 수 있던 문제를 수정했습니다. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32311](https://github.com/ClickHouse/ClickHouse/issues/32311)에 백포트됨: table create query에서 사용되는 XML dictionaries 식별자가 더 새로운 버전으로 업그레이드하는 과정에서 `default_database`로 한정될 수 있던 문제를 수정했습니다. [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)을 닫습니다. [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32354](https://github.com/ClickHouse/ClickHouse/issues/32354)에 백포트됨: `Decimal` 인수가 있는 집계 함수 `avgWeighted`에서 SIGFPE와 함께 발생하던 크래시를 수정했습니다. [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)을 수정합니다. [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32392](https://github.com/ClickHouse/ClickHouse/issues/32392)에 백포트됨: 기본 표현식의 데이터 타입이 컬럼의 데이터 타입과 다를 때 `ALTER ... MATERIALIZE COLUMN ...` 쿼리가 동작하지 않던 문제를 수정했습니다. [#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
* [#32418](https://github.com/ClickHouse/ClickHouse/issues/32418)에 백포트됨: 수행할 작업이 없는 뮤테이션이 멈춰 있던 동작을 수정했습니다(설정 `empty_result_for_aggregation_by_empty_set`이 활성화된 경우). [#32358](https://github.com/ClickHouse/ClickHouse/pull/32358) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
