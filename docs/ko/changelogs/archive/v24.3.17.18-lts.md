* [#75640](https://github.com/ClickHouse/ClickHouse/issues/75640)에서 백포트: docker init script의 실패 로그 메시지를 더 명확하게 이해할 수 있도록 수정했습니다. [#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* [#76227](https://github.com/ClickHouse/ClickHouse/issues/76227)에서 백포트: PSQL 복제 중 처리되지 않은 예외로 인해 발생하는 크래시를 수정했습니다. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* [#76101](https://github.com/ClickHouse/ClickHouse/issues/76101)에서 백포트: LowCardinality 널 허용 데이터 타입에 대한 null-safe JOIN 처리를 수정했습니다. 이전에는 `IS NOT DISTINCT FROM`, `<=>`, `a IS NULL AND b IS NULL OR a == b`와 같은 null-safe 비교를 사용하는 JOIN ON이 LowCardinality 컬럼에서 올바르게 동작하지 않았습니다. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#75830](https://github.com/ClickHouse/ClickHouse/issues/75830)에서 백포트: `DistinctSortedStreamTransform`에서 발생하는 null 포인터 역참조를 수정했습니다. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
