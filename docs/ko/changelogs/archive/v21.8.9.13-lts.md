<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">

* [#29676](https://github.com/ClickHouse/ClickHouse/issues/29676)에 백포트됨: 프로젝션 파트의 수직 병합을 수정했습니다. 이 변경으로 [#29253](https://github.com/ClickHouse/ClickHouse/issues/29253)이 해결됩니다. 또한 이 PR은 [https://github.com/ClickHouse/ClickHouse/pull/25165](https://github.com/ClickHouse/ClickHouse/pull/25165)에서 도입된 여러 프로젝션 머지/mutation 문제도 수정합니다. [#29337](https://github.com/ClickHouse/ClickHouse/pull/29337) ([Amos Bird](https://github.com/amosbird)).
* [#29538](https://github.com/ClickHouse/ClickHouse/issues/29538)에 백포트됨: 푸시다운된 `HAVING` 프레디케이트가 있는 서브쿼리에서 발생할 수 있는 `Block structure mismatch`를 수정했습니다. [#29010](https://github.com/ClickHouse/ClickHouse/issues/29010)을 해결합니다. [#29475](https://github.com/ClickHouse/ClickHouse/pull/29475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29589](https://github.com/ClickHouse/ClickHouse/issues/29589)에 백포트됨: ODBC bridge에 Invalid cursor state 오류에 대한 재시도를 추가했습니다. 이는 재시도 가능한 오류입니다. [#29473](https://github.com/ClickHouse/ClickHouse/issues/29473)을 닫습니다. [#29518](https://github.com/ClickHouse/ClickHouse/pull/29518) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29593](https://github.com/ClickHouse/ClickHouse/issues/29593)에 백포트됨: `std::mismatch` 사용 방식에 버그가 있어 `pathStartsWith` 검사 로직의 버그를 수정했습니다: ` The behavior is undefined if the second range is shorter than the first range.`. [#29531](https://github.com/ClickHouse/ClickHouse/pull/29531) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29628](https://github.com/ClickHouse/ClickHouse/issues/29628)에 백포트됨: `DEFAULT` 표현식에서 `x.y.z...`와 같은 잘못된 테이블 식별자를 사용할 때 `ALTER MODIFY` 쿼리에서 드물게 발생하는 segfault를 수정했습니다. [#29184](https://github.com/ClickHouse/ClickHouse/issues/29184)를 해결합니다. [#29573](https://github.com/ClickHouse/ClickHouse/pull/29573) ([alesapin](https://github.com/alesapin)).
* [#29752](https://github.com/ClickHouse/ClickHouse/issues/29752)에 백포트됨: 푸시다운 최적화 후 필터 프레디케이트의 조건이 사라질 수 있었습니다. [#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29840](https://github.com/ClickHouse/ClickHouse/issues/29840)에 백포트됨: 서버 재시작 시 `materialized_postgresql_tables_list` 설정의 잘못된 동작을 수정했습니다. [#28529](https://github.com/ClickHouse/ClickHouse/issues/28529)에서 발견되었습니다. [#29686](https://github.com/ClickHouse/ClickHouse/pull/29686) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29847](https://github.com/ClickHouse/ClickHouse/issues/29847)에 백포트됨: `GROUP BY` 중 `LowCardinality`에 대한 동시 접근 문제를 수정했습니다(SIGSEGV로 이어짐). [#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* [#29911](https://github.com/ClickHouse/ClickHouse/issues/29911)에 백포트됨: 경로 대신 문자열이 아닌 리터럴을 사용할 때 `ATTACH TABLE ... FROM 'path'` 쿼리에서 발생하는 잘못된 cast를 수정했습니다. 이 문제는 초기화되지 않은 메모리를 읽게 할 수 있습니다. [#29790](https://github.com/ClickHouse/ClickHouse/pull/29790) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#29867](https://github.com/ClickHouse/ClickHouse/issues/29867)에 백포트됨: 매우 드물게, 커널 버그로 추정되는 문제로 인해 발생할 수 있는 `Timeout exceeded: elapsed 18446744073.709553 seconds` 오류를 방지합니다. [#29154](https://github.com/ClickHouse/ClickHouse/issues/29154)를 수정합니다. [#29811](https://github.com/ClickHouse/ClickHouse/pull/29811) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#29877](https://github.com/ClickHouse/ClickHouse/issues/29877)에 백포트됨: 시스템 테이블 재생성 검사 수정(enum 값 변경을 감지하지 못하는 문제). [#29857](https://github.com/ClickHouse/ClickHouse/pull/29857) ([Azat Khuzhin](https://github.com/azat)).
* [#30210](https://github.com/ClickHouse/ClickHouse/issues/30210)에 백포트됨: `FileChecker`와 `StorageLog`/`StorageStripeLog` 사이에서 발생할 수 있는 데이터 레이스를 수정합니다. [#29959](https://github.com/ClickHouse/ClickHouse/pull/29959) ([Azat Khuzhin](https://github.com/azat)).
* [#30069](https://github.com/ClickHouse/ClickHouse/issues/30069)에 백포트됨: `tuple()`로 인해 sample이 크래시되는 문제를 수정하고, [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004)를 닫습니다. [#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
* [#30125](https://github.com/ClickHouse/ClickHouse/issues/30125)에 백포트됨: 삭제된 `Memory` 데이터베이스가 server 재시작 후 다시 나타날 수 있던 문제를 수정했습니다([#29795](https://github.com/ClickHouse/ClickHouse/issues/29795)). 또한 `Ordinary` 데이터베이스 삭제 시 `Directory not empty` 오류에 대한 우회책으로 `force_remove_data_recursively_on_drop` 설정을 추가했습니다(Cloud 환경에서는 남은 데이터를 수동으로 제거할 수 없기 때문입니다). [#30054](https://github.com/ClickHouse/ClickHouse/pull/30054) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30263](https://github.com/ClickHouse/ClickHouse/issues/30263)에 백포트됨: FlatDictionary 및 HashedDictionary에서 널 허용 속성의 bytes&#95;allocated 계산을 수정합니다. [#30238](https://github.com/ClickHouse/ClickHouse/pull/30238) ([Maksim Kita](https://github.com/kitaisreal)).
