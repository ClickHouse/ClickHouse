<div id="clickhouse-release-v20614066-prestable-fixme-as-compared-to-v20513833-prestable">
  ### ClickHouse 릴리스 v20.6.1.4066-prestable FIXME, v20.5.1.3833-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 이제 `clickhouse-local`은 이전처럼 현재 디렉터리를 사용하지 않고, 기본적으로 고유한 임시 데이터 디렉터리를 사용합니다. 필요한 경우 `-- --path` 옵션으로 데이터 디렉터리를 명시적으로 지정할 수 있습니다. [#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### 새 기능
</div>

* `Alter table drop replica replica_name` 지원을 추가했습니다. 이로써 [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080) 문제가 수정되었습니다. [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* `MergeTree` 계열 테이블에 데이터를 메모리에 저장하는 새로운 인메모리 포맷의 파트를 추가했습니다. 파트는 첫 번째 머지 시 디스크에 기록됩니다. 행 수 또는 바이트 수가 임계값 `min_rows_for_compact_part` 및 `min_bytes_for_compact_part`보다 작으면 파트가 인메모리 포맷으로 생성됩니다. 또한 선택적으로 Write-Ahead-Log도 지원하며, 기본적으로 활성화되어 있고 `in_memory_parts_enable_wal` 설정으로 제어됩니다. [#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* 집계 함수에 -Distinct combinator를 추가했습니다. [#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* table engine `mongo(host:port, database, collection, user, password)`를 지원합니다. [#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* RabbitMQ 스토리지를 추가했습니다. [#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [Sentry](https://sentry.io)를 통해 ClickHouse 코어 팀에 크래시 리포트를 전송하는 옵트인 설정을 추가했습니다. [#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* ORCBlockOutputFormat을 추가했습니다. [#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* Global Thread 풀의 최대 스레드 수를 변경하기 위한 `max_thread_pool_size` 구성을 추가했습니다. [#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* `EXPLAIN` 쿼리의 초기 구현을 추가했습니다. 구문: `EXPLAIN SELECT ...`. 이로써 [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118) 문제가 수정되었습니다. [#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* S3 메타데이터의 경로를 상대 경로로 변경하여 S3 blobs를 더 쉽게 처리할 수 있도록 했습니다. [#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Avro UUID 입력/출력을 지원합니다. [#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* 읽기 전용 MongoDB 테이블 엔진을 추가했습니다. 평면 필드(Primitive 타입, Nested 제외)를 읽을 수 있습니다. [#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* Avro schema에서 찾을 수 없는 필드에 대한 설정을 추가했습니다. [#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* `parseDateTimeBestEffortUS` 함수를 추가했습니다. [#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST를 지원합니다. [#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* 단일 값을 기반으로 집계를 초기화하는 `initializedAggregation` 함수를 추가했습니다. [#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* `set join_algorithm=partial_merge`에서 RIGHT 및 FULL JOIN을 지원합니다. ALL 엄격성만 지원하며, ANY, SEMI, ANTI, ASOF는 지원하지 않습니다. [#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710)에 대한 PostgreSQL과 유사한 ILIKE 연산자 구현. [#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc)).
* MergeTree 테이블의 키로 널 허용 타입을 허용. [#5319](https://github.com/ClickHouse/ClickHouse/issues/5319). [#12433](https://github.com/ClickHouse/ClickHouse/pull/12433) ([Amos Bird](https://github.com/amosbird)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 설정 `min_bytes_to_use_direct_io` 또는 `min_bytes_to_use_mmap_io`가 구성된 경우, 보조 인덱스에 `direct_io` 및 `mmap_io`를 사용할 수 있도록 했습니다. [#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree를 읽는 동안 마크 수를 추정하는 방식을 수정했습니다. 이는 설정 `merge_tree_max_rows_to_use_cache`, `merge_tree_max_bytes_to_use_cache`, `merge_tree_min_rows_for_concurrent_read`, `merge_tree_min_bytes_for_concurrent_read`, `merge_tree_min_rows_for_seek`, `merge_tree_min_bytes_for_seek`를 올바르게 처리하는 데 필요합니다. 이제 설정 `min_bytes_to_use_mmap_io`는 MergeTree 테이블 엔진 계열에서 인덱스와 compact 파트를 읽을 때에도 적용됩니다. [#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* v19.3 무렵에 도입된 성능 회귀, 즉 &quot;[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) 리터럴이 있는 IN 연산자에 인덱스가 사용되지 않음&quot; 문제를 수정했습니다. [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).
* `set optimize_injective_functions_inside_uniq=1`인 경우 `uniq*()` 내부의 injective 함수를 제거합니다. [#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)).
* `set optimize_redundant_functions_in_order_by = 1`인 경우 `ORDER BY x, f(x)`를 `ORDER by x`로 재작성하는 ORDER BY 최적화를 추가했습니다. [#12404](https://github.com/ClickHouse/ClickHouse/pull/12404) ([Artem Zuikov](https://github.com/4ertus2)).
* 일부 작업의 메모리 사용량을 최대 2배까지 줄였습니다. [#12424](https://github.com/ClickHouse/ClickHouse/pull/12424) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* 레플리카 선택 시 무시할 오류 수를 지정하는 기능(`distributed_replica_error_ignore`)을 추가했습니다. [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* 정렬 키의 접두사(prefix)를 사용하는 &#39;ORDER BY&#39; 및 &#39;GROUP BY&#39;의 성능을 개선했습니다. [#11696](https://github.com/ClickHouse/ClickHouse/pull/11696) ([Anton Popov](https://github.com/CurtizJ)).
* * `optimize_skip_unused_shards_nesting` 추가(세그먼트 스키핑 최적화의 중첩 수준을 제어할 수 있음) - `force_skip_optimize_shards_nesting` 추가(세그먼트가 스키핑되었는지 확인하는 중첩 수준을 제어할 수 있음) - `force_optimize_skip_unused_shards_no_nested` 지원 중단(대신 `force_skip_optimize_shards_nesting`을 사용해야 함) - sharding&#95;key에 비결정적 함수(예: `rand()`)가 있으면 `optimize_skip_unused_shards`를 비활성화함(즉, INSERT 측에는 아무런 변경이 없음). [#11715](https://github.com/ClickHouse/ClickHouse/pull/11715) ([Azat Khuzhin](https://github.com/azat)).
* 구조 잠금 없이 스토리지에 대한 다중 버전 메타데이터를 지원합니다. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* ODBC connection string 검증을 약간 완화했습니다. 호스트명 또는 사용자 이름에 `.` 및 `-`를 포함한 단어 문자만 있으면 중괄호로 감싸지 않습니다. 일부 ODBC 드라이버(예: PostgreSQL)는 호스트명이 중괄호로 둘러싸여 있으면 이를 올바르게 처리하지 못하기 때문에 필요합니다. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 구분자 없이 UUID를 파싱하는 기능을 지원합니다(대부분의 구현에서는 구분자를 항상 제거하므로, 사용자가 데이터를 쓰는 데 도움이 됩니다). [#11856](https://github.com/ClickHouse/ClickHouse/pull/11856) ([Winter Zhang](https://github.com/zhang2014)).
* MySQL과의 호환성을 위해 표준 정수 타입(`BIGINT`, `INT`, ...)의 `SIGNED` 및 `UNSIGNED` 수정자를 지원합니다. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `sumWithOverflow`를 `SimpleAggregateFunction`으로 사용할 수 있도록 했습니다. [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053)을 해결합니다. [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 해싱 함수에 FixedString 지원을 추가했습니다. [#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).
* `optimize_arithmetic_operations_in_aggregate_functions` 최적화를 위한 코드를 재작성했습니다. [#11899](https://github.com/ClickHouse/ClickHouse/pull/11899) ([Artem Zuikov](https://github.com/4ertus2)).
* `DatabaseOrdinary.cpp`에서 `std::string` 대신 `std::filesystem::path`를 사용해 경로 연결을 개선하고 슬래시가 두 번 들어간 경로를 수정했습니다. [#11900](https://github.com/ClickHouse/ClickHouse/pull/11900) ([Bharat Nallan](https://github.com/bharatnc)).
* 기존 regular 스타일은 더 이상 사용을 권장하지 않으며, 새로운 globalVariable 메서드를 사용합니다 [#11832](https://github.com/ClickHouse/ClickHouse/issues/11832). [#11901](https://github.com/ClickHouse/ClickHouse/pull/11901) ([BohuTANG](https://github.com/BohuTANG)).
* [issue 9797](https://github.com/ClickHouse/ClickHouse/issues/9797) 관련입니다. [#11923](https://github.com/ClickHouse/ClickHouse/pull/11923) ([flynn](https://github.com/ucasfl)).
* 이제 `system.tables`는 Memory 및 Buffer 테이블 엔진에 대해 컬럼 용량도 고려하므로, resident memory 크기를 더 잘 추정할 수 있습니다. [#11935](https://github.com/ClickHouse/ClickHouse/pull/11935) ([Max Akhmedov](https://github.com/zlobober)).
* CPU 주파수를 system.asynchronous&#95;metrics에 추가했습니다. 메트릭 수집 주기를 구성 가능하게 했습니다. [#11972](https://github.com/ClickHouse/ClickHouse/pull/11972) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Enum 데이터 타입에 더 많은 요소를 추가하는 것과 같은 파티션 키의 &quot;메타데이터 전용&quot; ALTER를 수행할 수 있도록 했습니다. 이 변경으로 [#7513](https://github.com/ClickHouse/ClickHouse/issues/7513)이 수정됩니다. [#11973](https://github.com/ClickHouse/ClickHouse/pull/11973) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* load&#95;balancing에 레플리카 우선순위를 추가했습니다(로드 밸런싱 우선순위를 수동으로 지정할 수 있습니다). [#11995](https://github.com/ClickHouse/ClickHouse/pull/11995) ([Azat Khuzhin](https://github.com/azat)).
* MySQL 엔진에서 Enum 타입 읽기를 지원합니다 [#3985](https://github.com/ClickHouse/ClickHouse/issues/3985). [#11996](https://github.com/ClickHouse/ClickHouse/pull/11996) ([BohuTANG](https://github.com/BohuTANG)).
* DiskS3에 단일 part 업로드를 구현했습니다. [#12026](https://github.com/ClickHouse/ClickHouse/pull/12026) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 불필요한 S3 로깅 수준을 TRACE로 낮췄습니다. [#12067](https://github.com/ClickHouse/ClickHouse/pull/12067) ([Vladimir Chebotarev](https://github.com/excitoon)).

* 이 설정을 사용하면 그리드 출력에 사용할 문자 인코딩을 선택할 수 있습니다(utf8 또는 ascii). [#12372](https://github.com/ClickHouse/ClickHouse/pull/12372) ([Sabyanin Maxim](https://github.com/s-mx)).
* &#39;MySQL server has gone away&#39; 대신 자세한 예외 메시지를 클라이언트에 기록합니다. [#12383](https://github.com/ClickHouse/ClickHouse/pull/12383) ([BohuTANG](https://github.com/BohuTANG)).
