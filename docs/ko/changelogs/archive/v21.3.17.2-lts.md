<div id="bug-fix">

* [#28647](https://github.com/ClickHouse/ClickHouse/issues/28647): 백포트됨. `DROP PART`에서 드물게 발생하던 버그를 수정했으며, 이 버그는 `Unexpected merged part intersects drop range` 오류를 유발할 수 있습니다. [#27807](https://github.com/ClickHouse/ClickHouse/pull/27807) ([alesapin](https://github.com/alesapin)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)
</div>

* [#28569](https://github.com/ClickHouse/ClickHouse/issues/28569)에 백포트됨: `ReplicatedVersionedCollapsingMergeTree`에 ALTER를 수행한 후 `Existing table metadata in ZooKeeper differs in sorting key expression.` 오류가 발생할 수 있는 버그를 수정했습니다. [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515)를 해결합니다. [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* [#28857](https://github.com/ClickHouse/ClickHouse/issues/28857)에 백포트됨: ReplicatedMergeTreeQueue의 무해한 경쟁 상태(race condition)를 수정했습니다. 사용자에게 직접 드러나지는 않지만, 미묘한 버그로 이어질 수 있습니다. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* [#28995](https://github.com/ClickHouse/ClickHouse/issues/28995)에 백포트됨: compact 파트에서 서브컬럼을 읽는 문제를 수정했습니다. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* [#28929](https://github.com/ClickHouse/ClickHouse/issues/28929)에 백포트됨: 상수와 함께 사용할 때 고차 배열 함수에서 발생하던 문제(`arrayCompact`에서는 `SIGSEGV`, `arrayDifference`/`arrayCumSumNonNegative`에서는 `ILLEGAL_COLUMN`)를 수정했습니다. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
