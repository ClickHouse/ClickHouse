<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 집계 함수에서 IP 타입 해싱의 이전 버전과의 호환성을 복원했습니다 [#50551](https://github.com/ClickHouse/ClickHouse/pull/50551) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* MathUnary의 segfault를 수정했습니다 [#51499](https://github.com/ClickHouse/ClickHouse/pull/51499) ([Ilya Yatsishin](https://github.com/qoega)).
* &#39;IN&#39; 조건을 PREWHERE로 이동할 때 발생하는 문제를 수정했습니다 [#51610](https://github.com/ClickHouse/ClickHouse/pull/51610) ([Alexander Gololobov](https://github.com/davenger)).
* `parseSipHashKey`에서 빈 컬럼을 읽을 때 발생하는 문제를 수정했습니다 [#51804](https://github.com/ClickHouse/ClickHouse/pull/51804) ([Nikita Taranov](https://github.com/nickitat)).
* refcount를 `execute` 대신 `RemoveManyObjectStorageOperation::finalize`에서 확인하도록 변경했습니다 [#51954](https://github.com/ClickHouse/ClickHouse/pull/51954) ([vdimir](https://github.com/vdimir)).
* 매개변수화된 UDF를 허용합니다 [#51964](https://github.com/ClickHouse/ClickHouse/pull/51964) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
