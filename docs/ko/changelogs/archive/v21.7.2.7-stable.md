* [#25833](https://github.com/ClickHouse/ClickHouse/issues/25833)에서 백포트됨: `Date`에서 `DateTime`(또는 `DateTime64`)으로 `CAST`할 때 `DateTime` 유형의 시간대가 사용되지 않던 문제를 수정했습니다. 이 문제는 `Date`와 `DateTime` 간 비교에도 영향을 줄 수 있습니다. `Date`와 `DateTime`의 공통 유형을 추론할 때도 해당 시간대가 사용되지 않았습니다. 이로 인해 `if` 함수와 배열 생성 결과에 영향이 있었습니다. [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)을 종료합니다. [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25766](https://github.com/ClickHouse/ClickHouse/issues/25766)에서 백포트됨: uint8이 아닌 유형을 사용하는 PREWHERE에서 assertion 문제를 수정하고 [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589)를 종료합니다. [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* [#25954](https://github.com/ClickHouse/ClickHouse/issues/25954)에서 백포트됨: TTL 표현식에 포함되는 컬럼의 `ALTER MODIFY COLUMN` 문제를 수정했습니다. [#25554](https://github.com/ClickHouse/ClickHouse/pull/25554) ([Anton Popov](https://github.com/CurtizJ)).
