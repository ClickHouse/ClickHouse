<div id="improvement">

<div id="bug-fix">
  #### 오동작

* [#31368](https://github.com/ClickHouse/ClickHouse/issues/31368)에 백포트됨: 부분 revoke를 사용할 때 SHOW GRANTS가 올바르게 동작하지 않던 문제를 수정했습니다. 이 PR은 [#31138](https://github.com/ClickHouse/ClickHouse/issues/31138)을 수정합니다. [#31249](https://github.com/ClickHouse/ClickHouse/pull/31249) ([Vitaly Baranov](https://github.com/vitlibar)).

#### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동

* [#30914](https://github.com/ClickHouse/ClickHouse/issues/30914)에 백포트됨: `TO` 및 `FROM`이 설정되어 있고 결과 집합에 행이 없는 경우 발생하던 `ORDER BY ... WITH FILL` 문제를 수정했습니다. [#30888](https://github.com/ClickHouse/ClickHouse/pull/30888) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)
</div>

* [#28756](https://github.com/ClickHouse/ClickHouse/issues/28756)에 백포트됨: 모든 키 컬럼을 사용하지 않을 때 발생하는 NOT-IN 인덱스 최적화 문제를 수정했습니다. 이 변경으로 [#28120](https://github.com/ClickHouse/ClickHouse/issues/28120)이 해결됩니다. [#28315](https://github.com/ClickHouse/ClickHouse/pull/28315) ([Amos Bird](https://github.com/amosbird)).
* [#30825](https://github.com/ClickHouse/ClickHouse/issues/30825)에 백포트됨: PREWHERE 사용 시 &quot;Column is not under aggregate function and not in GROUP BY&quot; 문제가 발생하는 현상을 수정했습니다. (해결: [#28461](https://github.com/ClickHouse/ClickHouse/issues/28461)) [#28502](https://github.com/ClickHouse/ClickHouse/pull/28502) ([Azat Khuzhin](https://github.com/azat)).
* [#29175](https://github.com/ClickHouse/ClickHouse/issues/29175)에 백포트됨: IN에 여러 컬럼이 포함된 외부 데이터베이스(예: MySQL) 쿼리를 수정했습니다(예: `(k,v) IN ((1, 2))`). (단, `clickhouse-copier`는 tuple 요소의 alias를 사용하므로 일부 하위 호환성 문제가 있습니다.) [#28888](https://github.com/ClickHouse/ClickHouse/pull/28888) ([Azat Khuzhin](https://github.com/azat)).
* [#30610](https://github.com/ClickHouse/ClickHouse/issues/30610)에 백포트됨: WITH FILL이 포함된 ORDER BY의 잘못된 최적화를 수정했습니다. 이 변경으로 [#28908](https://github.com/ClickHouse/ClickHouse/issues/28908)이 종료됩니다. 이 변경으로 [#26049](https://github.com/ClickHouse/ClickHouse/issues/26049)도 종료됩니다. [#28910](https://github.com/ClickHouse/ClickHouse/pull/28910) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#30767](https://github.com/ClickHouse/ClickHouse/issues/30767)에 백포트됨: 새 레플리카를 추가하는 동안 복제된 데이터베이스에서 DDL 쿼리가 멈추는 문제를 수정했습니다. [#29328](https://github.com/ClickHouse/ClickHouse/pull/29328) ([Kevin Michel](https://github.com/kmichel-aiven)).
* [#30205](https://github.com/ClickHouse/ClickHouse/issues/30205)에 백포트됨: `StorageLog`에서 `LogSink::writeMarks()`와 `LogSource` 사이에 발생하는 data race를 수정했습니다. [#29946](https://github.com/ClickHouse/ClickHouse/pull/29946) ([Azat Khuzhin](https://github.com/azat)).
* [#30463](https://github.com/ClickHouse/ClickHouse/issues/30463)에 백포트됨: 함수 `initializeAggregation`에서 널 허용 인수를 지원합니다. [#30177](https://github.com/ClickHouse/ClickHouse/pull/30177) ([Anton Popov](https://github.com/CurtizJ)).
* [#30655](https://github.com/ClickHouse/ClickHouse/issues/30655)에 백포트됨: `[I]LIKE` 함수를 수정했습니다. [#28661](https://github.com/ClickHouse/ClickHouse/issues/28661)을 종료합니다. [#30244](https://github.com/ClickHouse/ClickHouse/pull/30244) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#30289](https://github.com/ClickHouse/ClickHouse/issues/30289)에 백포트됨: ComplexKeyHashedDictionary 및 ComplexKeySparseHashedDictionary의 layout 구성에서 `preallocate` 옵션을 파싱하는 문제를 수정했습니다. [#30246](https://github.com/ClickHouse/ClickHouse/pull/30246) ([Maksim Kita](https://github.com/kitaisreal)).
* [#30525](https://github.com/ClickHouse/ClickHouse/issues/30525)에 백포트됨: REPLACE PARTITION 실행 중 session이 만료될 때 발생할 수 있는 segfault를 수정했습니다. [#30432](https://github.com/ClickHouse/ClickHouse/pull/30432) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `parallel_view_processing`의 예외 처리를 수정했습니다. 이 변경으로 해당 기능이 활성화된 상태에서 materialized view 처리 도중 &quot;Memory limit exceeded ...&quot;와 같은 예외가 발생하는 드문 예외 상황에서 문제를 해결하고 크래시를 방지합니다. [#30472](https://github.com/ClickHouse/ClickHouse/pull/30472) ([filimonov](https://github.com/filimonov)).
* [#30585](https://github.com/ClickHouse/ClickHouse/issues/30585)에 백포트됨: * 동일한 테이블에 대한 scalar subquery가 있는 ALTER에서 발생하는 deadlock을 수정했으며, [#30461](https://github.com/ClickHouse/ClickHouse/issues/30461)을 해결합니다. [#30492](https://github.com/ClickHouse/ClickHouse/pull/30492) ([Vladimir C](https://github.com/vdimir)).
* [#30607](https://github.com/ClickHouse/ClickHouse/issues/30607)에 백포트됨: Limit push down 최적화로 인해 `Cannot find column` 오류가 발생할 수 있었습니다. [#30438](https://github.com/ClickHouse/ClickHouse/issues/30438)을 수정합니다. [#30562](https://github.com/ClickHouse/ClickHouse/pull/30562) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#30753](https://github.com/ClickHouse/ClickHouse/issues/30753)에 백포트됨: `positionCaseInsensitiveUTF8`, `countSubstringsCaseInsensitiveUTF8` 같은 UTF8 문자열의 대소문자를 구분하지 않는 검색 함수는 실제로 일치하지 않는 부분 문자열을 찾을 수 있었으며, 이 문제를 수정했습니다. [#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30710](https://github.com/ClickHouse/ClickHouse/issues/30710)에 백포트됨: PREWHERE가 항상 true인 경우 PREWHERE와 WHERE를 함께 사용할 때의 문제를 수정했습니다. [#30668](https://github.com/ClickHouse/ClickHouse/pull/30668) ([Azat Khuzhin](https://github.com/azat)).
* [#30770](https://github.com/ClickHouse/ClickHouse/issues/30770)에 백포트됨: non-replicated `MergeTree`에서 `REPLACE/MOVE PARTITION`과 백그라운드 머지 사이의 race condition을 수정했습니다. 이 문제로 인해 이동되거나 대체된 데이터의 일부가 파티션에 남아 있을 수 있었습니다. [#29327](https://github.com/ClickHouse/ClickHouse/issues/29327)을 수정합니다. [#30717](https://github.com/ClickHouse/ClickHouse/pull/30717) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30857](https://github.com/ClickHouse/ClickHouse/issues/30857)에 백포트됨: `ReplicatedMergeTree`에서 ZooKeeper 경로로부터 auxiliary ZooKeeper 이름을 추출할 때의 모호성을 수정했습니다. 이전에는 ZooKeeper 경로에 콜론이 포함되어 있으면 server가 `Unknown auxiliary ZooKeeper name` 오류와 함께 시작되지 않을 수 있었습니다. [#29052](https://github.com/ClickHouse/ClickHouse/issues/29052)을 수정합니다. 또한 슬래시로 시작하지 않는 ZooKeeper 경로를 지정하는 것이 허용되었지만, 이제는 Deprecated되었으며 이러한 경로를 사용하는 새 테이블은 생성할 수 없습니다. auxiliary ZooKeeper 이름에도 슬래시와 콜론은 사용할 수 없습니다. [#30822](https://github.com/ClickHouse/ClickHouse/pull/30822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30925](https://github.com/ClickHouse/ClickHouse/issues/30925)에 백포트됨: 피연산자가 2개를 초과하는 경우 AND/OR 표현식에서 Set 인덱스가 사용되지 않는 문제를 수정했습니다. 이 변경은 [#30416](https://github.com/ClickHouse/ClickHouse/issues/30416)을 수정합니다. [#30887](https://github.com/ClickHouse/ClickHouse/pull/30887) ([Amos Bird](https://github.com/amosbird)).
* [#31151](https://github.com/ClickHouse/ClickHouse/issues/31151)에 백포트됨: ATTACH PARTITION ... FROM 및 MOVE PARTITION ...의 경우 max&#95;partition&#95;size&#95;to&#95;drop 검사를 건너뜁니다. [#30995](https://github.com/ClickHouse/ClickHouse/pull/30995) ([Amr Alaa](https://github.com/amralaa-MSFT)).
* [#31040](https://github.com/ClickHouse/ClickHouse/issues/31040)에 백포트됨: `formatRow` 함수를 행 포맷이 아닌 포맷과 함께 사용하면 segfault가 발생했습니다. 따라서 이러한 포맷에서는 이 함수를 사용할 수 없도록 했습니다(의미가 없기 때문입니다). [#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31132](https://github.com/ClickHouse/ClickHouse/issues/31132)에 백포트됨: 따옴표로 묶인 식별자가 있는 JSONValue/Query를 수정했습니다. 이제 JSON path에 공백을 포함할 수 있습니다. [#30971](https://github.com/ClickHouse/ClickHouse/issues/30971)을 해결합니다. [#31003](https://github.com/ClickHouse/ClickHouse/pull/31003) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#31372](https://github.com/ClickHouse/ClickHouse/issues/31372)에 백포트됨: 별칭과 WHERE를 사용하는 StorageMerge를 수정했습니다(이전에는 전혀 작동하지 않았습니다). [#28802](https://github.com/ClickHouse/ClickHouse/issues/28802)을 해결합니다. [#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii)).
