<div id="bug-fix">
  #### 오동작
</div>

* [#16202](https://github.com/ClickHouse/ClickHouse/issues/16202)에 백포트됨: 읽기 전용 테이블을 detach할 때 `ReadonlyReplica` 메트릭을 감소시키도록 수정했습니다. 이 변경으로 [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598)을 해결합니다. [#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)).
* [#16177](https://github.com/ClickHouse/ClickHouse/issues/16177)에 백포트됨: 첫 번째 시도가 실패한 경우 part를 다른 디스크/볼륨으로 이동할 수 있도록 수정했습니다. [#15723](https://github.com/ClickHouse/ClickHouse/pull/15723) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#16323](https://github.com/ClickHouse/ClickHouse/issues/16323)에 백포트됨: 테이블 이름이 동시에 변경될 때(`Atomic` 데이터베이스 엔진) `DROP TABLE IF EXISTS`가 `Table ... doesn't exist` 오류와 함께 실패하던 문제를 수정했습니다. 여러 테이블에 대한 일부 DDL 쿼리(예: `DROP DATABASE`, `RENAME TABLE`)를 동시에 실행할 때 드물게 발생하던 데드락을 수정했습니다. `DROP/DETACH TABLE`을 동시에 실행할 때 `DROP/DETACH DATABASE`가 `Table ... doesn't exist`와 함께 실패하던 문제를 수정했습니다. [#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#16359](https://github.com/ClickHouse/ClickHouse/issues/16359)에 백포트됨: collate name 및 charset name 파서를 수정하고 `String` type에 대해 `length = 0`을 지원하도록 했습니다. [#16008](https://github.com/ClickHouse/ClickHouse/pull/16008) ([Winter Zhang](https://github.com/zhang2014)).
* [#16299](https://github.com/ClickHouse/ClickHouse/issues/16299)에 백포트됨: 세그먼트 분할 키(`sharding_key`)와 유사하게 함수 Context가 영구적으로 저장되는 위치에서 `dictGet`이 동작하지 않던 문제를 수정했습니다. [#16205](https://github.com/ClickHouse/ClickHouse/pull/16205) ([Azat Khuzhin](https://github.com/azat)).
* [#16234](https://github.com/ClickHouse/ClickHouse/issues/16234)에 백포트됨: 제한과 무관하게 메모리가 과도하게 할당될 수 있던 문제를 수정했습니다. 이 변경으로 [#14560](https://github.com/ClickHouse/ClickHouse/issues/14560)을 해결합니다. [#16206](https://github.com/ClickHouse/ClickHouse/pull/16206) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#16327](https://github.com/ClickHouse/ClickHouse/issues/16327)에 백포트됨: 문자열 키를 사용하는 `GROUP BY` 중 발생할 수 있던 메모리 누수를 수정했습니다. 원인은 `TwoLevelStringHashTable` 구현의 오류였습니다. [#16264](https://github.com/ClickHouse/ClickHouse/pull/16264) ([Amos Bird](https://github.com/amosbird)).
* [#16374](https://github.com/ClickHouse/ClickHouse/issues/16374)에 백포트됨: `prefer_localhost_replica=0` 및 `internal_replication` 사용 시 비동기 분산 `INSERT`가 올바르게 동작하지 않던 문제를 수정했습니다. [#16358](https://github.com/ClickHouse/ClickHouse/pull/16358) ([Azat Khuzhin](https://github.com/azat)).
* [#16419](https://github.com/ClickHouse/ClickHouse/issues/16419)에 백포트됨: 합계/롤업/cube 수식어와 group by 키에 대한 min/max 함수를 함께 사용할 때 group by가 올바르게 동작하지 않던 문제를 수정했습니다. [#16393](https://github.com/ClickHouse/ClickHouse/issues/16393)을 해결합니다. [#16397](https://github.com/ClickHouse/ClickHouse/pull/16397) ([Anton Popov](https://github.com/CurtizJ)).
* [#16448](https://github.com/ClickHouse/ClickHouse/issues/16448)에 백포트됨: 함수 `dictGet`에서 예외가 발생할 경우 이중 해제가 발생하던 문제를 수정했습니다. 딕셔너리가 오류와 함께 로드된 경우 발생할 수 있었습니다. [#16429](https://github.com/ClickHouse/ClickHouse/pull/16429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
