<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오동작)
</div>

* [#41283](https://github.com/ClickHouse/ClickHouse/issues/41283)에 백포트: WITH 문으로 도입된, 사용되지 않는 알 수 없는 컬럼 문제를 수정했습니다. 이로써 [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812)를 해결합니다. [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* [#40865](https://github.com/ClickHouse/ClickHouse/issues/40865)에 백포트: - 가변 차원 배열을 포함하는 `Object` 타입 값을 파싱하는 동안 발생하는 크래시를 수정했습니다. [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* [#40804](https://github.com/ClickHouse/ClickHouse/issues/40804)에 백포트: 새 쿼리를 `ProcessList`에 삽입하는 동안 메모리 할당이 발생합니다. 이 할당 과정에서 memory limit에 도달하면 `ProcessList::mutex`를 이미 획득한 상태이므로 `OvercommitTracker`를 사용할 수 없습니다. [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)을 해결합니다. [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* [#40810](https://github.com/ClickHouse/ClickHouse/issues/40810)에 백포트: [#40595](https://github.com/ClickHouse/ClickHouse/issues/40595)에서 `/etc/hosts`의 이름-주소 해석과 함께 `host_regexp` 기능이 제대로 동작하지 않는다고 보고되었으며, 이를 수정했습니다. [#40769](https://github.com/ClickHouse/ClickHouse/pull/40769) ([Arthur Passos](https://github.com/arthurpassos)).
* [#41134](https://github.com/ClickHouse/ClickHouse/issues/41134)에 백포트: `DESCRIBE TABLE url()` 및 일부 다른 `DESCRIBE TABLE <table_function>()`에 대한 접근 권한을 수정했습니다. [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#41617](https://github.com/ClickHouse/ClickHouse/issues/41617)에 백포트: 집계 함수 조합자에서 발생할 수 있는 segfault, use-heap-after-free 및 메모리 누수를 수정했습니다. [#40848](https://github.com/ClickHouse/ClickHouse/issues/40848)를 닫습니다. [#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41666](https://github.com/ClickHouse/ClickHouse/issues/41666)에 백포트: subquery에 `OFFSET` 절이 있고 바깥쪽 쿼리에 `WHERE` 절이 있는 경우 잘못된 결과를 반환할 수 있었으며, 이를 수정했습니다. [#40416](https://github.com/ClickHouse/ClickHouse/issues/40416)을 해결합니다. [#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#41361](https://github.com/ClickHouse/ClickHouse/issues/41361)에 백포트: 디스크 객체 스토리지에서 발생하는 잘못된 logical error `Expected relative path`를 수정했습니다. [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246)와 관련이 있습니다. [#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#41358](https://github.com/ClickHouse/ClickHouse/issues/41358)에 백포트: MsgPack 포맷에서 UUID 삽입 전에 컬럼 타입 검사를 추가했습니다. [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41808](https://github.com/ClickHouse/ClickHouse/issues/41808)에 백포트: Native 형식의 악의적인 데이터로 인해 크래시가 발생할 수 있었습니다. [#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41805](https://github.com/ClickHouse/ClickHouse/issues/41805)에 백포트됨: 집계 함수 `categorialInformationValue`의 속성이 잘못 정의되어 있어 런타임에 null 포인터 역참조가 발생할 수 있었습니다. 이로써 [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443)가 해결되었습니다. [#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41505](https://github.com/ClickHouse/ClickHouse/issues/41505)에 백포트됨: Apache `ORC` 포맷으로 데이터를 쓰는 과정에서 버퍼 오버런이 발생할 수 있었습니다. [#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41644](https://github.com/ClickHouse/ClickHouse/issues/41644)에 백포트됨: `ORDER BY`와 `1500 <= LIMIT <= max_block_size`를 사용하는 쿼리에서 상위 일부 행이 누락된 잘못된 결과가 반환될 수 있었습니다. [#41182](https://github.com/ClickHouse/ClickHouse/issues/41182)를 해결했습니다. [#41576](https://github.com/ClickHouse/ClickHouse/pull/41576) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41641](https://github.com/ClickHouse/ClickHouse/issues/41641)에 백포트됨: `OFFSET`이 있는 쿼리에서 발생할 수 있는 `pipeline stuck` 예외를 수정했습니다. 이 오류는 `enable_optimize_predicate_expression = 0`이고 `WHERE` 절에 항상 false인 조건이 있을 때 발견되었습니다. [#41383](https://github.com/ClickHouse/ClickHouse/issues/41383)를 해결했습니다. [#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41900](https://github.com/ClickHouse/ClickHouse/issues/41900)에 백포트됨: `optimize_monotonous_functions_in_order_by` 설정이 활성화된 `Merge` 테이블에서 `SELECT`할 때 발생할 수 있는 크래시를 수정했습니다. [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269)를 해결했습니다. [#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
