<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#72865](https://github.com/ClickHouse/ClickHouse/issues/72865)에 백포트됨: 이제 테이블 엔진인 Kafka, NATS, RabbitMQ는 `SOURCES` 계층 구조에서 각각 별도의 권한 부여로 적용됩니다. 이러한 엔진 유형으로 테이블을 생성하는 `default` 이외의 데이터베이스 사용자에게 해당 권한을 부여하십시오. [#71250](https://github.com/ClickHouse/ClickHouse/pull/71250) ([Christoph Wurm](https://github.com/cwurm)).

<div id="new-feature">
  #### 새 기능
</div>

* [#74317](https://github.com/ClickHouse/ClickHouse/issues/74317)에서 백포트됨: `min_age_to_force_merge_seconds`와 `min_age_to_force_merge_on_partition_only`가 모두 활성화된 경우, 파트 병합에서 최대 바이트 제한을 무시합니다. [#73656](https://github.com/ClickHouse/ClickHouse/pull/73656) ([Kai Zhu](https://github.com/nauu)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* [#72595](https://github.com/ClickHouse/ClickHouse/issues/72595)에 백포트됨: 병렬 레플리카를 사용하고 로컬 계획이 활성화된 상태에서 쿼리를 실행할 때 워커에서는 스킵 인덱스 분석을 수행하지 않습니다. 코디네이터는 자체 측(쿼리 initiator)에서 수행한 인덱스 분석을 바탕으로 워커가 읽을 범위를 선택합니다. [#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter)).
* [#73033](https://github.com/ClickHouse/ClickHouse/issues/73033)에 백포트됨: [https://github.com/ClickHouse/ClickHouse/pull/57631](https://github.com/ClickHouse/ClickHouse/pull/57631)의 Compact 파트에서 단일 컬럼의 서브컬럼을 읽는 최적화를 다시 적용합니다. 이 최적화는 실수로 삭제되었습니다. [#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)).
