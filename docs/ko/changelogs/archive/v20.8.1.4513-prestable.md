  ### v20.7.1.4310-prestable과 비교한 ClickHouse 릴리스 v20.8.1.4513-prestable FIXME

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* `ODBCDriver` 입력/출력 포맷 지원을 제거했습니다. 이 포맷은 한때 ClickHouse ODBC 드라이버와 통신하는 데 사용되었으나 이미 Deprecated된 포맷이며, 현재는 오래전에 `ODBCDriver2` 포맷으로 대체되었습니다. [#13629](https://github.com/ClickHouse/ClickHouse/issues/13629)을 해결합니다. [#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting)).
* `parallel_distributed_insert_select` 설정을 확장하여 로컬 테이블에 `INSERT`를 실행하는 옵션을 추가했습니다. 이 설정의 유형이 `Bool`에서 `UInt64`로 변경되어 이제 `false`와 `true` 값은 더 이상 지원되지 않습니다. 서버 구성에 이러한 값이 있으면 server가 시작되지 않습니다. 각각 `0`과 `1`로 대체하십시오. [#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat)).
* 이제 `OPTIMIZE FINAL` 쿼리는 TTL이 생성되기 전에 추가된 파트의 TTL을 다시 계산하지 않습니다. 이를 계산하려면 `ALTER TABLE ... MATERIALIZE TTL`을 한 번 실행하십시오. 이후에는 `OPTIMIZE FINAL`이 TTL을 올바르게 평가합니다. 이 동작은 복제된 테이블에서는 원래 작동하지 않았습니다. [#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### 새 기능
</div>

* `MaterializeMySQL` 데이터베이스 엔진을 지원합니다. [#4006](https://github.com/ClickHouse/ClickHouse/issues/4006) 구현. [#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014)).
* `krb5` 및 `cyrus-sasl` 라이브러리를 사용한 Kafka의 Kerberos 인증을 지원합니다. [#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn)).
* `Int128`, `Int256`, `UInt256` 타입 및 관련 함수를 추가합니다. Decimal256(최대 76자리 정밀도)으로 Decimal을 확장합니다. 새 타입은 `allow_experimental_bigint_types` 설정을 통해 사용할 수 있습니다. [#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2)).
* `position` 함수에 선택적 `start_pos` 인수가 추가되었습니다. [#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir)).
* 테이블의 샘플 절을 변경할 수 있는 `ALTER SAMPLE BY` 구문을 추가합니다. [#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird)).
* 메인 구성에 새로운 선택적 섹션 <user_directories>를 추가합니다. [#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar)).
* 리터럴, 리터럴 시퀀스, 복잡한 별칭을 플레이스홀더로 대체하는 `normalizeQuery` 함수를 추가합니다. 유사한 쿼리에 대해 동일한 64비트 해시 값을 반환하는 `normalizedQueryHash` 함수를 추가합니다. 쿼리 로그 분석에 활용할 수 있습니다. [#11271](https://github.com/ClickHouse/ClickHouse/issues/11271) 해결. [#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantileExactLow` 및 `quantileExactHigh` 구현을 추가하고, 각각 `medianExactLow` 및 `medianExactHigh`를 별칭으로 제공합니다. [#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc)).
* 지정된 타입의 기본값을 반환하는 `defaultValueOfTypeName` 함수를 추가합니다. [#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz)).
* 날짜/시간 값을 지정된 날짜/시간 단위로 절삭하는 `date_trunc` 함수를 추가합니다. [#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* `config.xml`에 지정된 설정에 대응하는 컬럼에 `Default` 압축 코덱을 지정할 수 있는 기능을 추가합니다. [#9074](https://github.com/ClickHouse/ClickHouse/issues/9074) 구현. [#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin)).
* `index_granularity_bytes` 설정값이 지나치게 낮은 테이블을 실수로 생성하는 것을 방지하는 `min_index_granularity_bytes` 설정을 추가합니다. [#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc)).
* 정수 또는 Decimal 컬럼의 십진수 자릿수를 계산하는 `countDigits(x)` 함수를 추가합니다. Decimal 컬럼의 값이 해당(또는 지정된) 정밀도를 초과하는지 확인하는 `isDecimalOverflow(d, [p])` 함수를 추가합니다. [#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 단순한 `INSERT SELECT` 쿼리를 수행할 때 `max_threads`를 1 또는 `max_insert_threads`로 자동 설정하고, `max_block_size`를 `min_insert_block_size_rows`로 설정하도록 했습니다. [#5907](https://github.com/ClickHouse/ClickHouse/issues/5907)과 관련이 있습니다. [#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* `Array(LowCardinality(T))`와 상수 우변 인수에 대해 `has()`, `indexOf()`, `countEqual()` 함수를 최적화했습니다. [#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* UInt8/UInt16 키에 대한 집계 성능을 소폭 개선했습니다. [#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 파트 스캔 중 `max_rows_to_read` 제한을 초과하면 즉시 실패 처리하도록 했습니다. 이 변경의 목적은 `max_rows_to_read`가 이미 초과된 것이 분명한 경우, 선택된 모든 파트에 대한 범위 스캔을 건너뛰는 것입니다. 이 변경은 많은 파트를 대상으로 하는 쿼리에서 특히 효과가 큽니다. [#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* 테이블 엔진 `Null`, `Memory`, `Distributed`, `Buffer`에서 병렬 INSERT를 활성화했습니다. [#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* LowCardinality를 사용하는 매우 짧은 쿼리를 소폭 최적화했습니다. [#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).

* MergeTree Write-Ahead-Log(WAL) dump 도구를 추가했습니다. [#13640](https://github.com/ClickHouse/ClickHouse/pull/13640) ([BohuTANG](https://github.com/BohuTANG)).
* 배열이 필드처럼 조작될 때 쿼리가 지나치게 느려지는 문제를 방지합니다. 대신 예외를 발생시킵니다. [#13753](https://github.com/ClickHouse/ClickHouse/pull/13753) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 1. [GTID-Based Replication](https://dev.mysql.com/doc/refman/5.7/en/replication-gtids-concepts.html) 추가: 복제 토폴로지가 변경되어도 작동하며, MySQL 5.6/5.7/8.0에서 지원되고 권장됩니다. 2. BIT/SET 필드 유형 지원 추가 3. varchar 유형 메타 길이 버그 수정. [#13820](https://github.com/ClickHouse/ClickHouse/pull/13820) ([BohuTANG](https://github.com/BohuTANG)).
* `lgamma` 함수의 data race를 수정했습니다. 이 경쟁 상태는 `tsan`에서만 포착되었으며, 실제로는 부작용이 발생하지 않았습니다. [#13842](https://github.com/ClickHouse/ClickHouse/pull/13842) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

[#13868](https://github.com/ClickHouse/ClickHouse/pull/13868) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* TabSeparatedRow 포맷의 NULL 값에 대한 오류 메시지를 개선했습니다. [#13906](https://github.com/ClickHouse/ClickHouse/pull/13906) ([jiang tao](https://github.com/tomjiang1987)).
* 긴 쿼리에서 잘못된 오류가 발생하던 문제를 수정했습니다. 올바른 쿼리임에도 `Max query size exceeded`가 아니라 구문 오류가 발생할 수 있었습니다. [#13928](https://github.com/ClickHouse/ClickHouse/pull/13928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 비정상적으로 작고 손상된 메시지를 수신했을 때 Kafka 테이블 엔진이 메시지 처리를 중단하던 AvroConfluent 포맷의 오류를 수정했습니다. [#13941](https://github.com/ClickHouse/ClickHouse/pull/13941) ([Gervasio Varela](https://github.com/gervarela)).
* -Resample combinator의 제한을 100만으로 늘렸습니다. [#13947](https://github.com/ClickHouse/ClickHouse/pull/13947) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 조건부 집계 함수(예: `avgIf`, `sumIf`, `maxIf`)는 입력 행이 없고 널 허용 인수를 사용하는 경우 `NULL`을 반환해야 합니다. [#13964](https://github.com/ClickHouse/ClickHouse/pull/13964) ([Winter Zhang](https://github.com/zhang2014)).
* 매우 작은 블록이 매우 많이 있는 상태로 생성된 경우 Memory 테이블의 성능을 약간 개선했습니다(그럴 가능성은 낮습니다). 아이디어 제안자: [Mark Papadakis](https://github.com/markpapadakis). [#14043](https://github.com/ClickHouse/ClickHouse/issues/14043)를 해결합니다. [#14056](https://github.com/ClickHouse/ClickHouse/pull/14056) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `toDeicmal256()`를 수정하고 Decimal에서 Float로 변환할 때 발생할 수 있는 잠재적인 성능 회귀를 해결하려고 시도했습니다. [#14110](https://github.com/ClickHouse/ClickHouse/pull/14110) ([Artem Zuikov](https://github.com/4ertus2)).
* 이제 `ALTER TABLE table_name FETCH PARTITION partition_expr FROM 'zk://<host>:<port>/path-in-zookeeper'`를 사용할 수 있습니다. 이는 데이터를 새 클러스터로 전송할 때 유용합니다. [#14155](https://github.com/ClickHouse/ClickHouse/pull/14155) ([Amos Bird](https://github.com/amosbird)).
