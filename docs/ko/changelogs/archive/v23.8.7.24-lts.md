<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#56581](https://github.com/ClickHouse/ClickHouse/issues/56581)에 백포트됨: 명시적 컬럼 설명을 사용하는 테이블 함수로 테이블을 생성한 경우, `system.tables`의 `data_paths` 컬럼이 원격 데이터 소스를 참조하지 않도록 했습니다. [#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#56877](https://github.com/ClickHouse/ClickHouse/issues/56877)에 백포트됨: `view()` 테이블 함수에서 `UNION`의 쿼리 결과가 불완전하게 반환되던 문제를 수정했습니다. [#56274](https://github.com/ClickHouse/ClickHouse/pull/56274) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#56409](https://github.com/ClickHouse/ClickHouse/issues/56409)에 백포트됨: 기존 테이블에 `Object(JSON)` 유형의 컬럼을 추가하지 못하도록 했습니다. 다음 이슈를 해결합니다: [#56095](https://github.com/ClickHouse/ClickHouse/issues/56095), [#49944](https://github.com/ClickHouse/ClickHouse/issues/49944). [#56307](https://github.com/ClickHouse/ClickHouse/pull/56307) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#56756](https://github.com/ClickHouse/ClickHouse/issues/56756)에 백포트됨: Kafka 테이블 생성 중 Kerberos 초기화에서 예외가 발생할 때 segfault가 발생하던 문제를 수정했습니다. [#56073](https://github.com/ClickHouse/ClickHouse/issues/56073)를 해결합니다. [#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#56748](https://github.com/ClickHouse/ClickHouse/issues/56748)에 백포트됨: RabbitMQ 테이블 엔진이 보안 연결을 통해 RabbitMQ에 연결할 수 없던 문제를 수정했습니다. [#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* [#56839](https://github.com/ClickHouse/ClickHouse/issues/56839)에 백포트됨: 잘못된 형식의 데이터를 `FPC` 코덱으로 압축 해제할 때 서버가 크래시되는 문제가 있었습니다. 이 문제는 [https://twitter.com/malacupa](https://twitter.com/malacupa)가 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986)을 통해 발견했습니다. [#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
