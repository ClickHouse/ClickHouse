<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#52850](https://github.com/ClickHouse/ClickHouse/issues/52850)에 백포트됨: 동적 디스크에 이름이 있는 경우, 디스크 함수 인수에서 `disk = disk(name = 'disk_name'`, ...) 형식으로 지정해야 합니다. 이전 버전에서는 `disk = disk_<disk_name>(...)` 형식으로 지정할 수 있었지만, 이제는 더 이상 지원되지 않습니다. [#52820](https://github.com/ClickHouse/ClickHouse/pull/52820) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#52913](https://github.com/ClickHouse/ClickHouse/issues/52913)에 백포트됨: clickhouse-server 패키지에 `clickhouse-keeper-client` 심볼릭 링크를 추가했습니다. [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* Nullable(IPv4)에 대한 이항 산술 연산을 수정했습니다 [#51642](https://github.com/ClickHouse/ClickHouse/pull/51642) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 딕셔너리 속성에서 IPv4 및 IPv6를 지원합니다 [#51756](https://github.com/ClickHouse/ClickHouse/pull/51756) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 필요할 때 ares 채널을 초기화하고 해제하도록 수정했습니다. [#52634](https://github.com/ClickHouse/ClickHouse/pull/52634) ([Arthur Passos](https://github.com/arthurpassos)).
* 희소 컬럼 인수가 하나인 함수 `tuple`에서 발생하는 크래시를 수정했습니다 [#52659](https://github.com/ClickHouse/ClickHouse/pull/52659) ([Anton Popov](https://github.com/CurtizJ)).
* Keeper 재구성 중 발생하는 데이터 레이스를 수정했습니다 [#52804](https://github.com/ClickHouse/ClickHouse/pull/52804) ([Antonio Andelic](https://github.com/antonio2368)).
* clickhouse-keeper: poll()를 사용하는 server 구현을 수정했습니다 [#52833](https://github.com/ClickHouse/ClickHouse/pull/52833) ([Andy Fiddaman](https://github.com/citrus-it)).
