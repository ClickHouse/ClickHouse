* [#26191](https://github.com/ClickHouse/ClickHouse/issues/26191)에 백포트됨: remote()에서 함수 없이 컬럼을 사용하는 `sharding_key` 관련 문제를 수정했습니다(이전에는 `select * from remote('127.1', system.one, dummy)` 실행 시 `Unknown column: dummy, there are only columns .` 오류가 발생했습니다). [#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* [#26109](https://github.com/ClickHouse/ClickHouse/issues/26109)에 백포트됨: ZooKeeper 클라이언트의 `abort`로 인해 드물게 server가 크래시되는 문제를 수정했습니다. [#25813](https://github.com/ClickHouse/ClickHouse/issues/25813)을 해결합니다. [#26079](https://github.com/ClickHouse/ClickHouse/pull/26079) ([alesapin](https://github.com/alesapin)).
* [#26142](https://github.com/ClickHouse/ClickHouse/issues/26142)에 백포트됨: `validate_polygons` 설정이 꺼져 있을 때 `pointInPolygon`에서 발생할 수 있는 크래시를 수정했습니다. [#26113](https://github.com/ClickHouse/ClickHouse/pull/26113) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26170](https://github.com/ClickHouse/ClickHouse/issues/26170)에 백포트됨: LowCarinality 컬럼에서 `joinGet` 관련 문제를 수정하고, [#25993](https://github.com/ClickHouse/ClickHouse/issues/25993)을 해지했습니다. [#26118](https://github.com/ClickHouse/ClickHouse/pull/26118) ([Vladimir C](https://github.com/vdimir)).
* [#26206](https://github.com/ClickHouse/ClickHouse/issues/26206)에 백포트됨: `untuple` 표현식을 2개 이상 사용할 때 발생할 수 있는 크래시를 수정했습니다. [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26229](https://github.com/ClickHouse/ClickHouse/issues/26229)에 백포트됨: `system.stack_trace` 테이블의 `thread_name` 컬럼에서 불필요한 줄바꿈을 제거했습니다. 이 변경으로 [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124)가 수정됩니다. [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 존재하지 않는 원격 디렉터리를 순회할 때 예외를 발생시키는 문제를 수정했습니다. [#26296](https://github.com/ClickHouse/ClickHouse/pull/26296) ([ianton-ru](https://github.com/ianton-ru)).
