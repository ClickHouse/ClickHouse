#### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)

* [#32680](https://github.com/ClickHouse/ClickHouse/issues/32680)에 백포트됨: 파트를 detach할 때 예기치 않게 프로젝션이 제거되는 문제를 수정했습니다. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* [#32285](https://github.com/ClickHouse/ClickHouse/issues/32285)에 백포트됨: 사용자 지정 데이터베이스 쿼리에서 `{condition}`이 동작하지 않는 경우가 있던 Dictionaries 문제를 수정했습니다. [#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32730](https://github.com/ClickHouse/ClickHouse/issues/32730)에 백포트됨: 클라이언트/서버 크래시로 이어질 수 있던 &#39;APPLY lambda&#39; 파싱 문제를 수정했습니다. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32313](https://github.com/ClickHouse/ClickHouse/issues/32313)에 백포트됨: table create query에서 사용되는 XML dictionaries 식별자가 새 버전으로 업그레이드하는 동안 `default_database`로 한정될 수 있습니다. [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)을 닫습니다. [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32539](https://github.com/ClickHouse/ClickHouse/issues/32539)에 백포트됨: 일부 복제 큐 항목이 `temporary_directories_lifetime`(기본값 1일) 동안 `Directory tmp_merge_<part_name>` 또는 `Part ... (state Deleting) already exists, but it will be deleted soon` 같은 오류와 함께 멈춰 있을 수 있던 문제를 수정했습니다. [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)을 해결합니다. [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32709](https://github.com/ClickHouse/ClickHouse/issues/32709)에 백포트됨: 아직 구체화되지 않은 스킵 인덱스를 사용하려는 쿼리에서 발생하던 실패를 수정했습니다. [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) 및 [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343)을 해결합니다. [#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* [#32567](https://github.com/ClickHouse/ClickHouse/issues/32567)에 백포트됨: `JoinCommon::removeColumnNullability`에서 발생하는 크래시를 수정하고 [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458)을 닫습니다. [#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* [#32794](https://github.com/ClickHouse/ClickHouse/issues/32794)에 백포트됨: 동일한 FixedString을 fuzzBits와 함께 여러 번 사용할 때 발생하는 크래시를 수정하고 [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)을 닫습니다. [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
* [#33182](https://github.com/ClickHouse/ClickHouse/issues/33182)에 백포트됨: `MySQL` 엔진을 사용하는 데이터베이스가 MySQL server에 연결할 수 없으면 서버 시작에 실패할 수 있던 문제를 수정했습니다. [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441)을 해결합니다. [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#33655](https://github.com/ClickHouse/ClickHouse/issues/33655)에 백포트됨: HA 네임노드 주소를 사용할 수 없게 하던 HDFS URL 검사 문제를 수정했습니다. 이 버그는 [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042)에서 도입되었습니다. [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
