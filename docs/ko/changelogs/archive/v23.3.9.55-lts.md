<div id="performance-improvement">
  #### 성능 개선
</div>

* [#52213](https://github.com/ClickHouse/ClickHouse/issues/52213)에 백포트됨: 삽입된 데이터가 없으면 `ANY` 해시 조인에 블록을 저장하지 않도록 수정했습니다. [#48633](https://github.com/ClickHouse/ClickHouse/pull/48633) ([vdimir](https://github.com/vdimir)).
* [#52826](https://github.com/ClickHouse/ClickHouse/issues/52826)에 백포트됨: 기본 키(primary key)를 무효화하는 잘못된 프로젝션 분석을 수정했습니다. 이 문제는 `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1`로 설정된 경우에만 발생합니다. 이 수정으로 [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823) 문제가 해결됩니다. 이 수정으로 [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173) 문제도 해결됩니다. [#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#53019](https://github.com/ClickHouse/ClickHouse/issues/53019)에 백포트됨: 인라인 캐시를 Docker 이미지에 포함하면 때때로 이상한 부작용이 발생합니다. 어차피 전혀 사용하지 않으므로 제거해도 무방합니다. [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53288](https://github.com/ClickHouse/ClickHouse/issues/53288)에 백포트됨: 컴파일러의 프로파일 데이터(`-ftime-trace`)를 ClickHouse Cloud에 업로드합니다. [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) 이후 두 번째 시도입니다. [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#53461](https://github.com/ClickHouse/ClickHouse/issues/53461)에 백포트됨: `clickhouse start` 명령에서 환경 매개변수를 유지합니다. [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962)를 수정합니다. [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* 정렬 전에 함수를 이동하는 최적화 관련 문제를 수정했습니다. [#51481](https://github.com/ClickHouse/ClickHouse/pull/51481) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* FINAL에 대한 Pipe::unitePipes의 Block 구조 불일치를 수정했습니다. [#51492](https://github.com/ClickHouse/ClickHouse/pull/51492) ([Nikita Taranov](https://github.com/nickitat)).
* Nullable(IPv4)에 대한 이항 산술 연산을 수정했습니다. [#51642](https://github.com/ClickHouse/ClickHouse/pull/51642) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* IPv4와 IPv6를 딕셔너리 속성으로 지원합니다. [#51756](https://github.com/ClickHouse/ClickHouse/pull/51756) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 윈도우 함수의 Tuple에 대한 ORDER BY 문제를 수정했습니다. [#52145](https://github.com/ClickHouse/ClickHouse/pull/52145) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 시간 인터벌에 대한 표현식 Template을 비활성화했습니다. [#52335](https://github.com/ClickHouse/ClickHouse/pull/52335) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 빈 needle과 컬럼 haystack에서 `countSubstrings()`가 멈추는 문제를 수정했습니다. [#52409](https://github.com/ClickHouse/ClickHouse/pull/52409) ([Sergei Trifonov](https://github.com/serxa)).
* Buffer 엔진에 삽입할 때 발생하던 문제를 수정했습니다. [#52440](https://github.com/ClickHouse/ClickHouse/pull/52440) ([Vasily Nemkov](https://github.com/Enmk)).
* AnyHash 구현이 규격을 준수하지 않던 문제를 수정했습니다. [#52448](https://github.com/ClickHouse/ClickHouse/pull/52448) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 필요할 때만 ares 채널을 초기화하고 종료하도록 했습니다. [#52634](https://github.com/ClickHouse/ClickHouse/pull/52634) ([Arthur Passos](https://github.com/arthurpassos)).
* 희소 컬럼 인수가 하나인 함수 `tuple`에서 발생하는 크래시를 수정했습니다. [#52659](https://github.com/ClickHouse/ClickHouse/pull/52659) ([Anton Popov](https://github.com/CurtizJ)).
* clickhouse-keeper: poll()을 사용하는 server 구현을 수정했습니다. [#52833](https://github.com/ClickHouse/ClickHouse/pull/52833) ([Andy Fiddaman](https://github.com/citrus-it)).
* SHOW CREATE MYSQL TABLE에서 비밀번호가 노출되는 문제를 수정했습니다. [#52962](https://github.com/ClickHouse/ClickHouse/pull/52962) ([Duc Canh Le](https://github.com/canhld94)).
* 일반 PROJECTION의 AST 포맷이 잘못되던 문제를 수정했습니다. [#53347](https://github.com/ClickHouse/ClickHouse/pull/53347) ([Amos Bird](https://github.com/amosbird)).
* system.table SELECT 쿼리 중 지연 실행 데이터베이스를 로딩하는 문제를 수정했습니다. [#53372](https://github.com/ClickHouse/ClickHouse/pull/53372) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 병렬 FINAL이 포함된 쿼리에서 컬럼 순서가 잘못되는 문제를 수정했습니다. [#53489](https://github.com/ClickHouse/ClickHouse/pull/53489) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* interpolate 표현식이 SELECT 표현식에서 동일한 이름으로 alias된 값 대신 source 컬럼을 사용하는 문제를 수정했습니다. [#53572](https://github.com/ClickHouse/ClickHouse/pull/53572) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
