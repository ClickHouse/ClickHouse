<div id="performance-improvement">
  #### 성능 개선
</div>

* [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534)에 백포트됨: `LowCardinality` 컬럼의 메모리 내 크기 계산을 수정했습니다. [#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)).
* [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005)에 백포트됨: 동시성 제어로 인해 INSERT와 SELECT 사이의 CPU 분배가 불공정해질 수 있는 문제가 확인되었습니다. 경쟁이 없는 경우에도 모든 CPU 슬롯이 `max_threads` = 1인 INSERT에 무조건 할당되면, `max_threads` 값이 큰 SELECT는 스레드 1개만 사용하게 되어 성능이 저하될 수 있습니다. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

  #### 개선 사항

* [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535)에 백포트됨: `parallel_hash` JOIN 알고리즘에서 `max_joined_block_size_rows` 설정값을 더 정확하게 반영합니다. 이를 통해 `hash` 알고리즘 대비 메모리 사용량이 증가하는 것을 방지하는 데 도움이 됩니다. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).

[#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805)에 백포트됨: 백그라운드 스레드가 주기적으로 읽는 여러 소스의 정보를 사용해 내부 memory tracker를 보정할 수 있도록 `memory_worker_correct_memory_tracker` 구성을 추가합니다. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069)에 백포트됨: RSS로 보정되지 않은 내부 전역 memory tracker의 값을 보여주는 `MemoryTrackingUncorrected` 메트릭을 추가합니다. [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).
