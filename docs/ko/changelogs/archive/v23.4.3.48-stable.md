<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#49981](https://github.com/ClickHouse/ClickHouse/issues/49981)에 백포트됨: &quot;`groupArray` returns cannot be nullable&quot; 되돌림 (`Nullable` 타입의 `groupArray`/`groupArrayLast`/`groupArraySample`에서 바이너리 호환성이 깨져 `TOO_LARGE_ARRAY_SIZE` 또는 `CANNOT_READ_ALL_DATA`가 발생할 가능성이 높기 때문). [#49971](https://github.com/ClickHouse/ClickHouse/pull/49971) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 다중 StorageJoin 쿼리에서 키를 찾을 수 없는 오류 수정 [#49137](https://github.com/ClickHouse/ClickHouse/pull/49137) ([vdimir](https://github.com/vdimir)).
* remote()에서 읽을 때 서브쿼리 집합이 빌드되지 않는 퍼즈 버그 수정 [#49425](https://github.com/ClickHouse/ClickHouse/pull/49425) ([Alexander Gololobov](https://github.com/davenger)).
* Postgres 데이터베이스 설정 수정 [#49481](https://github.com/ClickHouse/ClickHouse/pull/49481) ([Mal Curtis](https://github.com/snikch)).
* 짧은 탐색(seek) 시 AsynchronousReadIndirectBufferFromRemoteFS가 중단되는 문제 수정 [#49525](https://github.com/ClickHouse/ClickHouse/pull/49525) ([Michael Kolupaev](https://github.com/al13n321)).
* DISTINCT의 버그 수정 [#49628](https://github.com/ClickHouse/ClickHouse/pull/49628) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 파이버(fiber) 사용 시 SpanHolder::finish()의 어설션 오류 수정 [#49673](https://github.com/ClickHouse/ClickHouse/pull/49673) ([Kruglov Pavel](https://github.com/Avogar)).
* randomStringUTF8(<홀수>)에서 발생하는 msan 문제 수정 [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze)).
* OptimizeRegularExpression에서 `is_prefix` 수정 [#49919](https://github.com/ClickHouse/ClickHouse/pull/49919) ([Han Fei](https://github.com/hanfei1991)).
* protobuf에서 IPv6 인코딩 수정 [#49933](https://github.com/ClickHouse/ClickHouse/pull/49933) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `ReplicatedMergeTree`의 ATTACH 스레드에서 테이블 시작 시 교착 상태(deadlock) 방지 [#50026](https://github.com/ClickHouse/ClickHouse/pull/50026) ([Antonio Andelic](https://github.com/antonio2368)).
* 파이버(fiber) 사용 시 SpanHolder::finish()의 어설션 오류 수정 시도 2 [#50034](https://github.com/ClickHouse/ClickHouse/pull/50034) ([Kruglov Pavel](https://github.com/Avogar)).
* JIT 컴파일에서 NaN 불일치 수정 [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal)).
* 인수 없이 복제된 데이터베이스 사용 시 크래시 수정 [#50058](https://github.com/ClickHouse/ClickHouse/pull/50058) ([Azat Khuzhin](https://github.com/azat)).
* `multiIf`에서 상수 조건 및 널 허용 인수 사용 시 크래시 수정 [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ)).
* Iceberg 메타데이터 파싱 수정 [#50232](https://github.com/ClickHouse/ClickHouse/pull/50232) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 논블로킹(non-blocking) 모드에서 Poco 소켓의 버그 수정 및 진정한 논블로킹 소켓 사용으로 전환 [#50252](https://github.com/ClickHouse/ClickHouse/pull/50252) ([Kruglov Pavel](https://github.com/Avogar)).
* DateTime64 인덱스로 쿼리 시 Date/Date32에서 DateTime64로의 유형 변환 수정 [#50280](https://github.com/ClickHouse/ClickHouse/pull/50280) ([Lucas Chang](https://github.com/lucas-tubi)).
* 요청 전처리 중 예외 발생 시 Keeper 교착 상태(deadlock) 수정 [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr)).
* TRUNCATE 후 Log 계열 테이블이 잘못된 행 수를 반환하는 버그 수정 [#50585](https://github.com/ClickHouse/ClickHouse/pull/50585) ([flynn](https://github.com/ucasfl)).
* `uniqExact` 병렬 머지의 버그 수정 [#50590](https://github.com/ClickHouse/ClickHouse/pull/50590) ([Nikita Taranov](https://github.com/nickitat)).
* GLOBAL JOIN의 오른쪽 테이블에서 모든 컬럼을 읽지 않도록 수정 [#50721](https://github.com/ClickHouse/ClickHouse/pull/50721) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
