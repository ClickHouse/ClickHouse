<div id="performance-improvement">
  #### 성능 개선
</div>

* [#76700](https://github.com/ClickHouse/ClickHouse/issues/76700)에 백포트됨: 옵티마이저가 JOIN 양측을 스왑하는 경우 `ConcurrentHashJoin`에서 발생하던 중복 사전 할당 문제를 수정했습니다. [#75149](https://github.com/ClickHouse/ClickHouse/pull/75149) ([Nikita Taranov](https://github.com/nickitat)).
* [#76696](https://github.com/ClickHouse/ClickHouse/issues/76696)에 백포트됨: `max_rows_in_join = max_bytes_in_join = 0`일 때 `parallel_hash`에서 발생하던 불필요한 경합 문제를 수정했습니다. [#75155](https://github.com/ClickHouse/ClickHouse/pull/75155) ([Nikita Taranov](https://github.com/nickitat)).

<div id="improvement">
  #### 개선 사항
</div>

* [#76437](https://github.com/ClickHouse/ClickHouse/issues/76437)에 백포트됨: `postgresql` 또는 `mysql` 테이블 함수에서 `localhost:1234/handle`과 같은 엔드포인트를 파싱할 수 있도록 합니다. 이 변경으로 [https://github.com/ClickHouse/ClickHouse/pull/52503](https://github.com/ClickHouse/ClickHouse/pull/52503)에서 도입된 회귀가 수정됩니다. [#75944](https://github.com/ClickHouse/ClickHouse/pull/75944) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#76609](https://github.com/ClickHouse/ClickHouse/issues/76609)에 백포트됨: 백업 중 S3로의 multipart copy가 Access Denied로 실패할 경우 올바른 폴백을 사용합니다. multipart copy는 서로 다른 자격 증명을 사용하는 버킷 간에 백업할 때 Access Denied 오류를 발생시킬 수 있습니다. [#76515](https://github.com/ClickHouse/ClickHouse/pull/76515) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#76142](https://github.com/ClickHouse/ClickHouse/issues/76142)에 백포트됨: forwarded&#95;for 필드의 일부 IPv6 주소(예: ::ffff:1.1.1.1)가 잘못 해석되어 예외와 함께 클라이언트 연결이 끊어지는 문제를 수정했습니다. [#75133](https://github.com/ClickHouse/ClickHouse/pull/75133) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#76395](https://github.com/ClickHouse/ClickHouse/issues/76395)에 백포트됨: NumRowsCache의 total&#95;number&#95;of&#95;rows를 계산할 때 key&#95;condition을 지정하지 않도록 검사합니다. [#75164](https://github.com/ClickHouse/ClickHouse/pull/75164) ([Daniil Ivanik](https://github.com/divanik)).
* [#76529](https://github.com/ClickHouse/ClickHouse/issues/76529)에 백포트됨: materialized view가 URL 엔진에 기록할 때 연결 문제가 발생해도 `materialized_views_ignore_errors` 설정을 따르도록 수정했습니다. [#75679](https://github.com/ClickHouse/ClickHouse/pull/75679) ([Christoph Wurm](https://github.com/cwurm)).
* [#76540](https://github.com/ClickHouse/ClickHouse/issues/76540)에 백포트됨: `UNION ALL`이 포함된 일부 쿼리에서 발생하는 `Block structure mismatch in QueryPipeline stream` 오류를 수정했습니다. [#75715](https://github.com/ClickHouse/ClickHouse/pull/75715) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#76475](https://github.com/ClickHouse/ClickHouse/issues/76475)에 백포트됨: `ALTER RENAME`에 `CREATE USER` grant가 필요하다고 잘못 검사하던 문제를 수정했습니다. [#74372](https://github.com/ClickHouse/ClickHouse/issues/74372)를 해결합니다. [#76241](https://github.com/ClickHouse/ClickHouse/pull/76241) ([pufit](https://github.com/pufit)).
* [#76403](https://github.com/ClickHouse/ClickHouse/issues/76403)에 백포트됨: `WHERE` 조건에 `pointInPolygon` 함수가 있을 때 인덱스 분석에서 발생하는 논리 오류를 수정했습니다. [#76360](https://github.com/ClickHouse/ClickHouse/pull/76360) ([Anton Popov](https://github.com/CurtizJ)).
* [#76484](https://github.com/ClickHouse/ClickHouse/issues/76484)에 백포트됨: 시그널 핸들러에서 메모리 할당을 제거했습니다. [#76446](https://github.com/ClickHouse/ClickHouse/pull/76446) ([Nikita Taranov](https://github.com/nickitat)).
