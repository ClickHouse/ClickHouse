<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항

* * 하위 호환되지 않는 변경 사항:. [#23934](https://github.com/ClickHouse/ClickHouse/pull/23934) ([hexiaoting](https://github.com/hexiaoting)).

<div id="new-feature">
  #### 새 기능
</div>

* 사용자 지정 설정을 `default`로 재설정하고 테이블의 메타데이터에서 제거하는 기능을 추가했습니다. 이를 통해 시스템/구성의 기본값을 알지 못해도 변경 사항을 롤백할 수 있습니다. [#14449](https://github.com/ClickHouse/ClickHouse/issues/14449)를 해결합니다. [#17769](https://github.com/ClickHouse/ClickHouse/pull/17769) ([xjewer](https://github.com/xjewer)).
* MaterializedPostgreSQL 테이블 엔진과 데이터베이스 엔진을 추가했습니다. 데이터베이스 엔진을 사용하면 전체 데이터베이스 또는 데이터베이스 테이블의 부분 집합을 복제할 수 있습니다. [#20470](https://github.com/ClickHouse/ClickHouse/pull/20470) ([Kseniia Sumarokova](https://github.com/kssenii)).
* SQLJSON 표준의 일부를 지원합니다. [#24148](https://github.com/ClickHouse/ClickHouse/pull/24148) ([l1tsolaiki](https://github.com/l1tsolaiki)).
* CPU 사용량, 디스크 사용량, 메모리 사용량, IO, 네트워크, 파일, load average, CPU 주파수, 열 센서, EDAC 카운터, 시스템 uptime에 관한 공통 시스템 메트릭을 `system.asynchronous_metrics` 및 `system.asynchronous_metric_log`에 수집하고, scheduling jitter 및 메트릭 수집에 소요된 시간에 대한 메트릭도 추가했습니다. 이는 ClickHouse에서 `atop`처럼 동작하며, 추가 도구가 설치되어 있지 않아도 모니터링 데이터를 얻을 수 있게 해줍니다. 이 변경으로 [#9430](https://github.com/ClickHouse/ClickHouse/issues/9430)를 해결합니다. [#24416](https://github.com/ClickHouse/ClickHouse/pull/24416) ([Yegor Levankov](https://github.com/elevankoff)).
* `DISTINCT ON (columns)` 표현식 지원을 추가했으며, [#25404](https://github.com/ClickHouse/ClickHouse/issues/25404)를 해결합니다. [#25589](https://github.com/ClickHouse/ClickHouse/pull/25589) ([Zijie Lu](https://github.com/TszKitLo40)).
* * `mapAdd` 및 `mapSubtract` 함수에서 맵(Map) 타입을 지원합니다. * `mapAdd` 및 `mapSubtract` 함수에서 (U)Int128, U(Int256) 타입을 지원합니다. [#25596](https://github.com/ClickHouse/ClickHouse/pull/25596) ([Ildus Kurbangaliev](https://github.com/ildus)).
* bin/unbin 함수 지원을 추가했습니다. [#25609](https://github.com/ClickHouse/ClickHouse/pull/25609) ([zhaoyu](https://github.com/zxc111)).
* 기존 스킵 인덱스에 대한 정보를 담고 있는 `system.data_skipping_indices` 테이블을 도입했습니다. [#7659](https://github.com/ClickHouse/ClickHouse/issues/7659)를 해결합니다. [#25693](https://github.com/ClickHouse/ClickHouse/pull/25693) ([Dmitry Novik](https://github.com/novikd)).
* [https://github.com/ClickHouse/ClickHouse/pull/12073](https://github.com/ClickHouse/ClickHouse/pull/12073)에 이어, indices 목록의 맨 앞에 인덱스를 추가할 수 있도록 ADD INDEX 명령에 FIRST 키워드를 추가했습니다. [#25904](https://github.com/ClickHouse/ClickHouse/pull/25904) ([xjewer](https://github.com/xjewer)).
* `EXPLAIN PIPELINE graph = 1` 쿼리가 주어지면 web UI에서 pipelines를 그래프로 렌더링합니다. [#26067](https://github.com/ClickHouse/ClickHouse/pull/26067) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 새 함수 `leftPad()`, `rightPad()`, `leftPadUTF8()`, `rightPadUTF8()`를 추가했습니다. [#26075](https://github.com/ClickHouse/ClickHouse/pull/26075) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* `compile_aggregate_expressions` 설정이 활성화된 경우 집계 함수를 컴파일하는 옵션이 추가되었습니다. [#24789](https://github.com/ClickHouse/ClickHouse/pull/24789) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="improvement">
  #### 개선 사항
</div>

* `StorageMerge`의 `Database` 인수가 정규식을 지원합니다. 이로써 #776이 해결됩니다. [#25064](https://github.com/ClickHouse/ClickHouse/pull/25064) ([flynn](https://github.com/ucasfl)).
* JSONExtract를 사용해 문자열이 아닌 요소도 문자열로 추출할 수 있습니다. 이는 [#25414](https://github.com/ClickHouse/ClickHouse/issues/25414)를 위한 변경입니다. [#25452](https://github.com/ClickHouse/ClickHouse/pull/25452) ([Amos Bird](https://github.com/amosbird)).
* 백그라운드 작업 실행(머지, 뮤테이션, fetches)용 풀의 스레드 수를 변경할 수 있도록 구성을 동적으로 다시 로드하는 기능을 지원합니다. [#25548](https://github.com/ClickHouse/ClickHouse/pull/25548) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* StorageS3 및 StorageHDFS에서 TRUNCATE TABLE을 지원합니다. [#25530](https://github.com/ClickHouse/ClickHouse/issues/25530)이 해결되었습니다. [#25550](https://github.com/ClickHouse/ClickHouse/pull/25550) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `NetworkReceiveElapsedMicroseconds` 메트릭이 INSERT를 위해 클라이언트의 데이터를 기다리는 데 소요된 시간을 올바르게 포함하도록 수정했습니다. 이로써 [#9958](https://github.com/ClickHouse/ClickHouse/issues/9958)이 해결됩니다. [#25602](https://github.com/ClickHouse/ClickHouse/pull/25602) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ALTER TABLE ... DETACH`와 백그라운드 머지 사이에서 발생할 수 있는 논리적 race condition을 수정했습니다. [#25605](https://github.com/ClickHouse/ClickHouse/pull/25605) ([Azat Khuzhin](https://github.com/azat)).
* 조인에서 구체화된 컬럼과 별칭 컬럼을 지원하며, [#13274](https://github.com/ClickHouse/ClickHouse/issues/13274)를 해결합니다. [#25634](https://github.com/ClickHouse/ClickHouse/pull/25634) ([Vladimir C](https://github.com/vdimir)).
* MaterializeMySQL이 이제 `ENUM` 데이터 타입을 지원합니다. [#25676](https://github.com/ClickHouse/ClickHouse/pull/25676) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* `ReplicatedMergeTree`에서 `DROP PARTITION` 및 `TRUNCATE` 수행 시 해당 파티션에서 이미 실행 중인 머지를 취소합니다. [#17151](https://github.com/ClickHouse/ClickHouse/issues/17151)이 해결되었습니다. [#25684](https://github.com/ClickHouse/ClickHouse/pull/25684) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 시스템 로그 테이블(`system.query_log`, `system.query_thread_log`, `system.processes`, `system.opentelemetry_span_log`)의 키-값 dictionaries에 `Map` 데이터 타입을 사용합니다. 이전 쿼리와의 호환성을 위해 가상 컬럼을 생성합니다. [#18698](https://github.com/ClickHouse/ClickHouse/issues/18698)이 해결되었습니다. 작성자: @hexiaoting, @sundy-li. [#25773](https://github.com/ClickHouse/ClickHouse/pull/25773) ([Maksim Kita](https://github.com/kitaisreal)).
* 빈 집합에서 GROUP BY 상수의 동작이 일관되지 않던 문제를 수정했습니다. [#6842](https://github.com/ClickHouse/ClickHouse/issues/6842)가 해결되었습니다. [#25786](https://github.com/ClickHouse/ClickHouse/pull/25786) ([Kseniia Sumarokova](https://github.com/kssenii)).
* MySQL Engine이 이제 MySQL과 ClickHouse 간 컬럼 comment 교환을 지원합니다. [#25795](https://github.com/ClickHouse/ClickHouse/pull/25795) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* Merge() storage에서 &quot;No available columns&quot; 문제를 수정했습니다. [#25801](https://github.com/ClickHouse/ClickHouse/pull/25801) ([Azat Khuzhin](https://github.com/azat)).
* 작업 디렉터리를 읽을 수 없는 경우에도 clickhouse-client를 시작할 수 있도록 했습니다. [#25817](https://github.com/ClickHouse/ClickHouse/pull/25817) ([ianton-ru](https://github.com/ianton-ru)).
* ReplicatedMergeTree 테이블의 손실된 파트 처리 기능을 개선했습니다. ReplicationQueue에서 드물게 발생하는 불일치를 수정했습니다. 사용자에게는 아무런 변화도 보이지 않습니다. [#10368](https://github.com/ClickHouse/ClickHouse/issues/10368)을 수정했습니다. [#25820](https://github.com/ClickHouse/ClickHouse/pull/25820) ([alesapin](https://github.com/alesapin)).
* `DROP PART` 이후 또는 빈 파트가 백그라운드에서 삭제된 후에 intersecting parts가 발생할 수 있는 극히 드문 버그를 수정했습니다. [#25884](https://github.com/ClickHouse/ClickHouse/pull/25884) ([alesapin](https://github.com/alesapin)).
* 이력 파일을 readline 포맷에서 replxx 포맷으로 변환했습니다. [#25888](https://github.com/ClickHouse/ClickHouse/pull/25888) ([Azat Khuzhin](https://github.com/azat)).
* JSON 추출에서 LowCardinality, Decimal 및 UUID를 지원합니다. [#24606](https://github.com/ClickHouse/ClickHouse/issues/24606)을 종료합니다. [#25900](https://github.com/ClickHouse/ClickHouse/pull/25900) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 이름이 `"null"`인 컬럼이 포함된 쿼리(`backticks` 또는 큰따옴표로 지정해야 함)와 ON CLUSTER를 지원합니다. 이로써 [#24035](https://github.com/ClickHouse/ClickHouse/issues/24035)가 종료됩니다. [#25907](https://github.com/ClickHouse/ClickHouse/pull/25907) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 잘못된 Date를 parse하려고 할 때 exception이 올바르게 발생하도록 수정했습니다. 이로써 [#6481](https://github.com/ClickHouse/ClickHouse/issues/6481)이 종료됩니다. [#25909](https://github.com/ClickHouse/ClickHouse/pull/25909) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 매개변수화된 집계 함수의 매개변수로 literals뿐 아니라 임의의 상수 표현식(예: `1 + 2`)도 허용합니다. 또한 이를 통해 `{param:UInt8}`와 같은 매개변수화된 쿼리의 쿼리 매개변수를 매개변수화된 집계 함수의 매개변수로 사용할 수 있습니다. 이로써 [#11607](https://github.com/ClickHouse/ClickHouse/issues/11607)이 종료됩니다. [#25910](https://github.com/ClickHouse/ClickHouse/pull/25910) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantiles*` 함수가 `aggregate_functions_null_for_empty`와 함께 작동할 수 있도록 했습니다. 이로써 [#25892](https://github.com/ClickHouse/ClickHouse/issues/25892)가 종료됩니다. [#25919](https://github.com/ClickHouse/ClickHouse/pull/25919) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Centos 8처럼 `systemd`를 사용하는 시스템에서 `sudo service clickhouse-server start`가 작동하도록 했습니다. 이로써 [#14298](https://github.com/ClickHouse/ClickHouse/issues/14298)가 종료됩니다. 이로써 [#17799](https://github.com/ClickHouse/ClickHouse/issues/17799)가 종료됩니다. [#25921](https://github.com/ClickHouse/ClickHouse/pull/25921) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Nested` 데이터 타입에서 유니코드(예: 중국어, 키릴 문자) 구성 요소를 지원합니다. 이로써 [#25594](https://github.com/ClickHouse/ClickHouse/issues/25594)가 종료됩니다. [#25923](https://github.com/ClickHouse/ClickHouse/pull/25923) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* JOIN된 테이블에서 복잡한 따옴표 식별자를 허용합니다. 이로써 [#17861](https://github.com/ClickHouse/ClickHouse/issues/17861)이 종료됩니다. [#25924](https://github.com/ClickHouse/ClickHouse/pull/25924) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `optimize_move_to_prewhere_if_final` 설정을 추가했습니다. 쿼리에 `FINAL`이 있으면 `optimize_move_to_prewhere`와 `optimize_move_to_prewhere_if_final`이 모두 활성화된 경우에만 `move_to_prewhere` 최적화가 활성화됩니다. [#8684](https://github.com/ClickHouse/ClickHouse/issues/8684)를 종료합니다. [#25940](https://github.com/ClickHouse/ClickHouse/pull/25940) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 네트워크 상호작용에 대한 계측을 확장했습니다. recv/send 바이트용 카운터를 추가하고, recvs/sends용 게이지를 추가했습니다. 누락된 문서도 보완했습니다. 이 변경으로 [#5897](https://github.com/ClickHouse/ClickHouse/issues/5897)이 해결되었습니다. [#25962](https://github.com/ClickHouse/ClickHouse/pull/25962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Web UI: 값이 URL처럼 보이면 링크를 자동으로 생성합니다. [#25965](https://github.com/ClickHouse/ClickHouse/pull/25965) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* mysql 프로토콜에서 `SET SQL_SELECT_LIMIT` 쿼리 관련 오류를 수정했습니다. 이 변경으로 [#17115](https://github.com/ClickHouse/ClickHouse/issues/17115)가 해결되었습니다. [#25972](https://github.com/ClickHouse/ClickHouse/pull/25972) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `empty` 및 `notEmpty` 함수에 `UUID` 유형 인수 지원을 추가했습니다. `UUID`가 모두 0이면(nil UUID) 비어 있는 것으로 간주됩니다. 이 변경으로 [#3446](https://github.com/ClickHouse/ClickHouse/issues/3446)이 해결되었습니다. [#25974](https://github.com/ClickHouse/ClickHouse/pull/25974) ([zhaoyu](https://github.com/zxc111)).
* `bin` 및 `hex` 함수에 AggregateFunction 유형 인수 지원을 추가했습니다. [#26094](https://github.com/ClickHouse/ClickHouse/pull/26094) ([zhaoyu](https://github.com/zxc111)).
* 복합 키를 사용하는 딕셔너리에서 복합 키에 속성이 하나만 있는 경우, `dictGet`, `dictHas` 함수에서 키 표현식을 tuple로 감싸지 않아도 되도록 했습니다. [#26130](https://github.com/ClickHouse/ClickHouse/pull/26130) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix">
  #### 오동작
</div>

* `Date`에서 `DateTime`(또는 `DateTime64`)으로 `CAST`할 때 `DateTime` 타입의 시간대가 사용되지 않던 문제를 수정했습니다. 이 문제는 `Date`와 `DateTime` 간 비교에도 영향을 줄 수 있습니다. 또한 `Date`와 `DateTime`의 공통 타입을 추론할 때도 해당 시간대가 사용되지 않았습니다. 이로 인해 `if` 함수와 배열 구성 결과가 영향을 받았습니다. [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)을 해결합니다. [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* uint8이 아닌 타입을 사용하는 PREWHERE에서 발생하는 assertion 문제를 수정하고, [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589)를 해결합니다. [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* TTL 표현식에 사용되는 컬럼의 `ALTER MODIFY COLUMN` 문제를 수정했습니다. [#25554](https://github.com/ClickHouse/ClickHouse/pull/25554) ([Anton Popov](https://github.com/CurtizJ)).
* 일부 경우에 dict join이 느려지는 문제를 수정하고, [#24209](https://github.com/ClickHouse/ClickHouse/issues/24209)를 해결합니다. [#25618](https://github.com/ClickHouse/ClickHouse/pull/25618) ([Vladimir C](https://github.com/vdimir)).
* StorageMerge가 별칭(alias)이 있는 테이블에도 접근할 수 있도록 했습니다. [#6051](https://github.com/ClickHouse/ClickHouse/issues/6051)을 해결합니다. [#25694](https://github.com/ClickHouse/ClickHouse/pull/25694) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 파트에서 첫 실행 이후 `TTL` 실행이 거부되는 `GROUP BY` 표현식이 포함된 `TTL` 버그를 수정했습니다. [#25743](https://github.com/ClickHouse/ClickHouse/pull/25743) ([alesapin](https://github.com/alesapin)).
