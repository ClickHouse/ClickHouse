* [#29260](https://github.com/ClickHouse/ClickHouse/issues/29260)에 백포트됨: 널 허용 또는 LowCardinality 프라이머리 키를 사용할 때 발생하는 잘못된 상수 유형 변환을 수정했습니다. [#28636](https://github.com/ClickHouse/ClickHouse/pull/28636) ([Amos Bird](https://github.com/amosbird)).
* [#29026](https://github.com/ClickHouse/ClickHouse/issues/29026)에 백포트됨: `GLOBAL IN` 서브쿼리에서 사용되는 스레드 수를 수정했습니다([#19414](https://github.com/ClickHouse/ClickHouse/issues/19414) 오동작 수정 이후 단일 스레드로 실행되고 있었습니다). [#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29194](https://github.com/ClickHouse/ClickHouse/issues/29194)에 백포트됨: Avro 입력 형식에서 LowCardinality(Nullable) 유형의 컬럼에 삽입할 때 발생하는 segfault를 수정했습니다. [#29132](https://github.com/ClickHouse/ClickHouse/pull/29132) ([Kruglov Pavel](https://github.com/Avogar)).
* [#29360](https://github.com/ClickHouse/ClickHouse/issues/29360)에 백포트됨: 테이블 컬럼 중 하나에 대소문자를 구분하지 않는 함수가 포함된 기본 표현식이 있을 때, `ReplicatedMergeTree`의 레플리카를 다시 만들거나 새로 생성하는 과정에서 발생할 수 있는 `Table columns structure in ZooKeeper is different from local table structure` Exception을 수정했습니다. [#29266](https://github.com/ClickHouse/ClickHouse/pull/29266) ([Anton Popov](https://github.com/CurtizJ)).
* [#29300](https://github.com/ClickHouse/ClickHouse/issues/29300)에 백포트됨: 연결 타임아웃(`send_timeout`/`receive_timeout`)을 수정했습니다. [#29282](https://github.com/ClickHouse/ClickHouse/pull/29282) ([Azat Khuzhin](https://github.com/azat)).
* [#30042](https://github.com/ClickHouse/ClickHouse/issues/30042)에 백포트됨: 푸시다운 최적화 이후 필터 프레디케이트의 조건이 손실될 수 있던 문제를 수정했습니다. [#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29848](https://github.com/ClickHouse/ClickHouse/issues/29848)에 백포트됨: `GROUP BY` 중 `LowCardinality`에 대한 동시 접근 문제를 수정했습니다(SIGSEGV로 이어질 수 있음). [#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* [#30066](https://github.com/ClickHouse/ClickHouse/issues/30066)에 백포트됨: `tuple()`로 인해 sample이 크래시되는 문제를 수정했으며, [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004)를 해결합니다. [#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
* [#30332](https://github.com/ClickHouse/ClickHouse/issues/30332)에 백포트됨: * 여러 조인에서 숫자로 시작하는 식별자를 허용합니다. [#30230](https://github.com/ClickHouse/ClickHouse/pull/30230) ([Vladimir C](https://github.com/vdimir)).
* [#30379](https://github.com/ClickHouse/ClickHouse/issues/30379)에 백포트됨: replaceRegexpAll 오동작을 수정했습니다. [#30292](https://github.com/ClickHouse/ClickHouse/pull/30292) ([Memo](https://github.com/Joeywzr)).
