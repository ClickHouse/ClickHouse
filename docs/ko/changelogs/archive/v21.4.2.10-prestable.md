<div id="clickhouse-release-v214210-prestable-fixme-as-compared-to-v21316185-prestable">

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* `system.dictionaries` 테이블의 `keys` 컬럼이 `key.names` 및 `key.types` 컬럼으로 대체되었습니다. 또한 `system.dictionaries` 테이블의 `key.names`, `key.types`, `attribute.names`, `attribute.types` 컬럼은 딕셔너리를 로드하지 않아도 됩니다. [#21884](https://github.com/ClickHouse/ClickHouse/pull/21884) ([Maksim Kita](https://github.com/kitaisreal)).
* 사용자 지정 top-level domain 목록에 포함된 3수준 이상의 도메인에 대해 `cutToFirstSignificantSubdomainCustom()`/`firstSignificantSubdomainCustom()`가 잘못된 결과를 반환하던 문제를 수정했습니다. 이러한 사용자 지정 top-level domain과 일치하는 입력 도메인에서는 3수준 도메인이 첫 번째 유의미한 도메인으로 간주되었습니다. 이제 이 문제가 수정되었습니다. 이 변경으로 인해, 예를 들어 이 함수가 세그먼트 분할 키에 사용되는 경우 비호환성이 발생할 수 있습니다. [#21946](https://github.com/ClickHouse/ClickHouse/pull/21946) ([Azat Khuzhin](https://github.com/azat)).
* `toStartOfIntervalFunction`은 시간 인터벌을 자정 기준으로 정렬합니다(이전 버전에서는 Unix epoch 시작 시점 기준으로 정렬됨). 예를 들어 `toStartOfInterval(x, INTERVAL 11 HOUR)`는 하루를 세 개의 인터벌, 즉 00:00:00..10:59:59, 11:00:00..21:59:59, 22:00:00..23:59:59로 나눕니다. 이 동작이 실제 사용 사례에 더 적합합니다. 이 변경으로 [#9510](https://github.com/ClickHouse/ClickHouse/issues/9510)이 해결되었습니다. [#22060](https://github.com/ClickHouse/ClickHouse/pull/22060) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="new-feature">
  #### 새 기능
</div>

* `DateTime64`의 범위를 확장해 1925년부터 2283년까지의 날짜를 올바르게 지원합니다. 제로 날짜(`1970-01-01`) 부근의 `DateTime` 지원도 개선했습니다. ... [#9404](https://github.com/ClickHouse/ClickHouse/pull/9404) ([Vasily Nemkov](https://github.com/Enmk)).
* * 사전 구성된 사용자 및 HTTP 요청에 대한 Kerberos 인증(GSS-SPNEGO) 지원이 추가되었습니다. [#14995](https://github.com/ClickHouse/ClickHouse/pull/14995) ([Denis Glazachev](https://github.com/traceon)).
* S3 storage에서 ReplicatedMergeTree용 zero-copy 복제를 지원합니다. [#16240](https://github.com/ClickHouse/ClickHouse/pull/16240) ([ianton-ru](https://github.com/ianton-ru)).
* `RangeHashedDictionary`에서 `dictHas` 함수를 지원합니다. [#6680](https://github.com/ClickHouse/ClickHouse/issues/6680)을 수정했습니다. [#19816](https://github.com/ClickHouse/ClickHouse/pull/19816) ([Maksim Kita](https://github.com/kitaisreal)).
* JOIN에 대해 암시적 키 타입 변환을 지원합니다. [#18567](https://github.com/ClickHouse/ClickHouse/issues/18567)을 닫습니다. [#19885](https://github.com/ClickHouse/ClickHouse/pull/19885) ([Vladimir C](https://github.com/vdimir)).
* 복제에 사용되는 HTTP 연결의 timeout을 다른 HTTP timeout과 별도로 사용자 지정할 수 있도록 했습니다. [#20088](https://github.com/ClickHouse/ClickHouse/pull/20088) ([nvartolomei](https://github.com/nvartolomei)).
* `ComplexKeyCache`, `SSDCache`, `SSDComplexKeyCache` 딕셔너리에 비동기 업데이트를 추가했습니다. `Cache`, `ComplexKeyCache`, `SSDCache`, `SSDComplexKeyCache` 딕셔너리에서 널 허용 타입을 지원합니다. `dictGet`, `dictGetOrDefault` 함수에서 여러 속성을 fetch하는 기능을 추가했습니다. [#21517](https://github.com/ClickHouse/ClickHouse/issues/21517)을 수정했습니다. [#20595](https://github.com/ClickHouse/ClickHouse/pull/20595) ([Maksim Kita](https://github.com/kitaisreal)).
* `system.query_log`의 해당 쿼리에 대해 `query_kind` 컬럼에 `Grant,` `Revoke`, `System` 값을 추가했습니다 ... [#21102](https://github.com/ClickHouse/ClickHouse/pull/21102) ([Vasily Nemkov](https://github.com/Enmk)).
* 새로운 SQL 명령 ALTER TABLE &#39;table&#95;name&#39; UNFREEZE [PARTITION &#39;part&#95;expr&#39;] WITH NAME &#39;backup&#95;name&#39;를 추가했습니다. [#21142](https://github.com/ClickHouse/ClickHouse/pull/21142) ([Pavel Kovalenko](https://github.com/Jokser)).
* ExecutablePool 딕셔너리 소스를 추가했습니다. [#14528](https://github.com/ClickHouse/ClickHouse/issues/14528)을 닫습니다. [#21321](https://github.com/ClickHouse/ClickHouse/pull/21321) ([Maksim Kita](https://github.com/kitaisreal)).
* * 주어진 CIDR 네트워크 프리픽스에 IPv4 또는 IPv6 주소가 포함되는지 확인하는 함수 `isIPAddressInRange`를 추가했습니다. [#21329](https://github.com/ClickHouse/ClickHouse/pull/21329) ([PHO](https://github.com/depressed-pho)).
* `MergeTree*` 엔진에 `_partition_id` virtual 컬럼을 추가했습니다. `_partition_id`를 사용해 파티션을 가지치기할 수 있습니다. 파티션 ID 문자열을 계산하는 `partitionID()` 함수도 추가했습니다. [#21401](https://github.com/ClickHouse/ClickHouse/pull/21401) ([Amos Bird](https://github.com/amosbird)).
* `system.clusters`에 새 컬럼 `slowdowns_count`를 추가했습니다. hedged requests를 사용할 때, 해당 레플리카의 응답이 느려 다른 레플리카로 전환한 횟수를 보여줍니다. 또한 `system.clusters`에 `errors_count`의 실제 값도 표시합니다. [#21480](https://github.com/ClickHouse/ClickHouse/pull/21480) ([Kruglov Pavel](https://github.com/Avogar)).
* 형식이 지정된 쿼리의 각 줄 끝에 백슬래시를 추가할 수 있는 clickhouse-format용 `--backslash` 옵션을 추가했습니다. [#21494](https://github.com/ClickHouse/ClickHouse/pull/21494) ([flynn](https://github.com/ucasfl)).
* CREATE/ALTER USER 명령에 새로운 선택적 GRANTEES 절을 추가했습니다. [#21641](https://github.com/ClickHouse/ClickHouse/pull/21641) ([Vitaly Baranov](https://github.com/vitlibar)).
* `zookeeper-dump-tree`에 `ctime` 옵션을 추가했습니다. 노드 생성 시간을 덤프할 수 있습니다. [#21842](https://github.com/ClickHouse/ClickHouse/pull/21842) ([Ilya](https://github.com/HumanUser)).
* &#39;dictGet&#39;, &#39;dictHas&#39; 함수는 DDL로 생성된 딕셔너리에서 데이터베이스 이름이 지정되지 않은 경우 현재 데이터베이스 이름을 사용합니다. [#21632](https://github.com/ClickHouse/ClickHouse/issues/21632)을 해결합니다. [#21859](https://github.com/ClickHouse/ClickHouse/pull/21859) ([Maksim Kita](https://github.com/kitaisreal)).
* `PolygonDictionary` 속성에 `Nullable` 타입을 지원합니다. [#21890](https://github.com/ClickHouse/ClickHouse/pull/21890) ([Maksim Kita](https://github.com/kitaisreal)).
* 테이블 함수 `dictionary`를 추가했습니다. `Dictionary` 엔진과 동일하게 동작합니다. [#21560](https://github.com/ClickHouse/ClickHouse/issues/21560)을 해결합니다. [#21910](https://github.com/ClickHouse/ClickHouse/pull/21910) ([Maksim Kita](https://github.com/kitaisreal)).
* `DateTime` 또는 `DateTime64` 데이터 타입의 시간대 이름을 반환하는 `timezoneOf` 함수를 추가했습니다. 이는 [#9959](https://github.com/ClickHouse/ClickHouse/issues/9959)를 해결하지 않습니다. 또한 함수 이름의 불일치를 수정하기 위해 `timezone`, `timeZone`, `toTimezone`, `toTimeZone`, `timezoneOf`, `timeZoneOf` 별칭을 추가했습니다. [#22001](https://github.com/ClickHouse/ClickHouse/pull/22001) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 별칭 대신 원래 컬럼 이름을 사용하기 위한 `prefer_column_name_to_alias` 설정을 추가했습니다. 일반적인 데이터베이스의 alias 규칙과의 호환성을 높이기 위해 필요합니다. 이는 [#9715](https://github.com/ClickHouse/ClickHouse/issues/9715) 및 [#9887](https://github.com/ClickHouse/ClickHouse/issues/9887) 관련 변경입니다. [#22044](https://github.com/ClickHouse/ClickHouse/pull/22044) ([Amos Bird](https://github.com/amosbird)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* `CSVWithNames` 및 `TSVWithNames` 포맷에서 병렬 파싱을 지원합니다. 이 변경으로 [#21085](https://github.com/ClickHouse/ClickHouse/issues/21085)가 해결되었습니다. [#21149](https://github.com/ClickHouse/ClickHouse/pull/21149) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `memcpy`를 다른 구현으로 교체해 성능을 개선했습니다. 이 변경으로 [#18583](https://github.com/ClickHouse/ClickHouse/issues/18583)가 해결되었습니다. [#21520](https://github.com/ClickHouse/ClickHouse/pull/21520) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* clickhouse-local 및 그 외 전반에서 병렬 포맷팅을 지원합니다. [#21630](https://github.com/ClickHouse/ClickHouse/pull/21630) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `SELECT ... FINAL ... WHERE`와 같은 쿼리의 성능을 최적화했습니다. 이제 `FINAL`이 포함된 쿼리에서는 sorting key에 있는 컬럼을 `PREWHERE`로 이동할 수 있습니다. ... [#21830](https://github.com/ClickHouse/ClickHouse/pull/21830) ([foolchi](https://github.com/foolchi)).
* `max_rows_to_group_by`가 작고 `group_by_overflow_mode='any'`인 경우 `GROUP BY` 성능을 개선했습니다. [#21856](https://github.com/ClickHouse/ClickHouse/pull/21856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 코덱 `NONE` 사용 시 불필요한 데이터 복사를 방지합니다. 코덱 `NONE`은 대체로 거의 쓸모가 없으므로 항상 압축(`LZ4`가 기본값)을 사용하는 것을 권장합니다. 일반적인 인식과 달리 압축을 비활성화해도 성능이 개선되지 않을 수 있으며, 오히려 반대 효과가 날 수도 있습니다. `NONE` 코덱이 유용한 경우도 일부 있습니다. 예: 데이터가 압축되지 않는 경우, 합성 벤치마크. [#22145](https://github.com/ClickHouse/ClickHouse/pull/22145) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `min_bytes_to_use_mmap_io` 설정을 사용해 읽는 파일에 대한 캐시를 추가합니다. 이 설정값이 작을 때 빈번한 mmap/munmap 호출과 그에 따른 페이지 폴트를 피할 수 있어 상당한(2배 이상) 성능 개선 효과를 냅니다. 다만 mmap IO에는 운영 환경(production)에서 신뢰성을 떨어뜨릴 수 있는 큰 단점이 있습니다(예: 결함이 있는 디스크에서 hung 또는 SIGBUS 발생, 제어하기 어려운 메모리 사용량). 그럼에도 벤치마크에는 유용합니다. [#22206](https://github.com/ClickHouse/ClickHouse/pull/22206) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 64 MiB 이상의 파일 범위에 대해 mmap IO 읽기를 활성화합니다(`min_bytes_to_use_mmap_io` 설정). 이는 중간 수준의 성능 개선으로 이어질 수 있습니다. [#22326](https://github.com/ClickHouse/ClickHouse/pull/22326) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="improvement">
  #### 개선 사항
</div>

* 새로운 MergeTree 설정 `min_bytes_to_rebalance_partition_over_jbod`를 도입했습니다. 이 설정을 사용하면 JBOD 볼륨의 여러 디스크에 새 파트를 균형 있게 할당할 수 있습니다. [#16481](https://github.com/ClickHouse/ClickHouse/pull/16481) ([Amos Bird](https://github.com/amosbird)).
* 정렬 키 순서에 따른 집계 성능을 개선했습니다(`optimize_aggregation_in_order` 설정이 활성화된 경우). [#19401](https://github.com/ClickHouse/ClickHouse/pull/19401) ([Anton Popov](https://github.com/CurtizJ)).
* MaterializeMySQL: `_version` 컬럼에 minmax 스키핑 인덱스를 추가했습니다. [#20382](https://github.com/ClickHouse/ClickHouse/pull/20382) ([Stig Bakken](https://github.com/stigsb)).
* `optimize_on_insert` 설정이 활성화된 경우 INSERT 시 빈 파트를 생성하지 않도록 했습니다. [#20304](https://github.com/ClickHouse/ClickHouse/issues/20304)을 수정했습니다. [#20387](https://github.com/ClickHouse/ClickHouse/pull/20387) ([Kruglov Pavel](https://github.com/Avogar)).
* * `CROSS JOIN`을 `INNER JOIN`으로 재작성할 수 있는 경우를 더 많이 지원합니다. [#20392](https://github.com/ClickHouse/ClickHouse/pull/20392) ([Vladimir C](https://github.com/vdimir)).
* MaterializeMySQL: 연결이 끊어지면 MySQL에 다시 연결을 시도합니다. [#20961](https://github.com/ClickHouse/ClickHouse/pull/20961) ([Håvard Kvålen](https://github.com/havardk)).
* 데이터 타입 `Map`에서 정수 키 지원을 개선했습니다. [#21157](https://github.com/ClickHouse/ClickHouse/pull/21157) ([Anton Popov](https://github.com/CurtizJ)).
* 마지막 쿼리 뒤에 여분의 공백이나 주석이 있어도 예외를 발생시키지 않도록 clickhouse-format을 개선했으며, 데이터가 있는 `ASTInsertQuery`를 포맷할 때는 읽기 쉬운 메시지와 함께 예외를 더 일찍 발생시키도록 했습니다. [#21311](https://github.com/ClickHouse/ClickHouse/pull/21311) ([flynn](https://github.com/ucasfl)).
* graphite 롤업 구성에서 Age와 Precision은 보존 기간이 늘어날수록 함께 증가해야 합니다. 이제 이를 검사하며, 잘못된 구성은 예외를 발생시킵니다. [#21496](https://github.com/ClickHouse/ClickHouse/pull/21496) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* `optimize_skip_unused_shards`의 세그먼트 분할 키 값 수를 제한하는 설정 `optimize_skip_unused_shards_limit`을 추가했습니다. [#21512](https://github.com/ClickHouse/ClickHouse/pull/21512) ([Azat Khuzhin](https://github.com/azat)).
* `system.errors`에 `last_error_time`/`last_error_message`/`last_error_stacktrace`/`remote` 컬럼을 추가했습니다. [#21529](https://github.com/ClickHouse/ClickHouse/pull/21529) ([Azat Khuzhin](https://github.com/azat)).
* PODArray가 요소 크기가 16의 약수도 배수도 아니도록 생성된 경우 버퍼 오버플로우가 발생할 수 있었습니다. 현재 릴리스에는 해당 버그가 존재하지 않습니다. [#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* * 분산 DDL 쿼리에 쿼리 및 세션 설정이 전파되도록 했습니다. 이를 활성화하려면 `distributed_ddl_entry_format_version`을 2로 설정하십시오. - `distributed_ddl_output_mode` 설정이 추가되었습니다. 지원되는 모드: `none`, `throw`(기본값), `null_status_on_timeout`, `never_throw`. - `Replicated` 데이터베이스 엔진에 대한 여러 수정 및 개선 사항이 포함되었습니다. [#21535](https://github.com/ClickHouse/ClickHouse/pull/21535) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 구성이 업데이트된 경우에만 클러스터를 업데이트합니다. [#21685](https://github.com/ClickHouse/ClickHouse/pull/21685) ([Kruglov Pavel](https://github.com/Avogar)).
* PostgreSQL 딕셔너리 소스의 레플리카 우선순위를 지원합니다. [#21710](https://github.com/ClickHouse/ClickHouse/pull/21710) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#21701](https://github.com/ClickHouse/ClickHouse/issues/21701)을 해결합니다. PostgreSQL storage/table-function에서 기본이 아닌 테이블 스키마를 지원합니다. [#21711](https://github.com/ClickHouse/ClickHouse/pull/21711) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Web UI에서 `Array` 및 `Map` 데이터 타입의 표시 형식을 개선했습니다. [#21798](https://github.com/ClickHouse/ClickHouse/pull/21798) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* DiskS3(개발 중인 실험적 기능). 대상이 비어 있지 않고 캐시 디스크를 사용하는 경우 디렉터리를 이동할 수 없던 버그를 수정했습니다. [#21837](https://github.com/ClickHouse/ClickHouse/pull/21837) ([Pavel Kovalenko](https://github.com/Jokser)).
* PostgreSQL table/database 엔진과 딕셔너리 소스에 연결 풀을 추가했습니다. [#21444](https://github.com/ClickHouse/ClickHouse/issues/21444)를 해결합니다. [#21839](https://github.com/ClickHouse/ClickHouse/pull/21839) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 프로파일 이벤트 HedgedRequestsChangeReplica를 추가하고, 데이터 읽기 timeout 단위를 초에서 밀리초로 변경했습니다. [#21886](https://github.com/ClickHouse/ClickHouse/pull/21886) ([Kruglov Pavel](https://github.com/Avogar)).
