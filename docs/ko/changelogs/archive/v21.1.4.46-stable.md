<div id="bug-fix">
  #### 오동작
</div>

* [#19983](https://github.com/ClickHouse/ClickHouse/issues/19983)에 백포트됨: `ON CLUSTER` 쿼리를 실행하는 백그라운드 스레드가 삭제된 복제된 테이블이 처리되기를 기다리다가 멈출 수 있던 문제를 수정했습니다. [#19684](https://github.com/ClickHouse/ClickHouse/pull/19684) ([yiguolei](https://github.com/yiguolei)).
* [#20238](https://github.com/ClickHouse/ClickHouse/issues/20238)에 백포트됨: 여러 개의 clickhouse-copier를 실행할 때 조각을 대상 테이블로 이동하는 작업이 실패할 수 있는 버그를 수정했습니다. [#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* [#20074](https://github.com/ClickHouse/ClickHouse/issues/20074)에 백포트됨: `dictGet()`를 포함한 기본 표현식이 있는 테이블로 서버를 시작할 때 발생하던 문제를 수정했습니다. 이제 딕셔너리를 로드하지 않고도 `dictGet()`의 반환 타입을 가져올 수 있습니다. [#19805](https://github.com/ClickHouse/ClickHouse/pull/19805) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#19997](https://github.com/ClickHouse/ClickHouse/issues/19997)에 백포트됨: - 인수 타입이 Int32를 제외한 임의의 정수 타입의 `Nullable(T)`일 때 함수 `fromModifiedJulianDay`에서 발생하는 segfault를 수정했습니다. [#19959](https://github.com/ClickHouse/ClickHouse/pull/19959) ([PHO](https://github.com/depressed-pho)).
* [#20122](https://github.com/ClickHouse/ClickHouse/issues/20122)에 백포트됨: MaterializeMySQL: 여러 테이블을 업데이트하는 SQL 문의 복제를 수정했습니다. [#20066](https://github.com/ClickHouse/ClickHouse/pull/20066) ([Håvard Kvålen](https://github.com/havardk)).
* [#20297](https://github.com/ClickHouse/ClickHouse/issues/20297)에 백포트됨: * StorageJoin의 버그를 수정했습니다. [#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* [#20390](https://github.com/ClickHouse/ClickHouse/issues/20390)에 백포트됨: `MongoDB` 테이블 엔진은 이제 데이터를 읽을 때만 연결을 설정합니다. `ATTACH TABLE`은 더 이상 연결을 시도하지 않습니다. [#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#20148](https://github.com/ClickHouse/ClickHouse/issues/20148)에 백포트됨: `if` 함수가 포함된 쿼리에서 then/else 분기 결과의 `Tuple` 타입으로 인해 발생하던 서버 크래시를 수정했습니다. `Tuple` 타입은 `Array` 또는 다른 복합 타입을 포함해야 합니다. [#18356](https://github.com/ClickHouse/ClickHouse/issues/18356)를 수정합니다. [#20133](https://github.com/ClickHouse/ClickHouse/pull/20133) ([alesapin](https://github.com/alesapin)).
* [#20327](https://github.com/ClickHouse/ClickHouse/issues/20327)에 백포트됨: 종료 중 구성을 다시 로드할 때 드물게 발생하던 서버 크래시를 수정했습니다. [#19689](https://github.com/ClickHouse/ClickHouse/issues/19689)를 수정합니다. [#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* [#20331](https://github.com/ClickHouse/ClickHouse/issues/20331)에 백포트됨: `*CollapsingMergeTree` 및 `ReplacingMergeTree` 테이블 엔진의 버전 컬럼에는 `DROP` 또는 `RENAME`만 허용하도록 제한했습니다. [#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* [#20363](https://github.com/ClickHouse/ClickHouse/issues/20363)에 백포트됨: `ReplicatedMergeTree` 테이블 엔진 계열에서 실패한 백그라운드 작업에 대한 재시도가 지나치게 자주 발생하던 문제를 수정했습니다. 이로 인해 로깅이 지나치게 상세해지고 CPU 부하가 증가할 수 있었습니다. [#20203](https://github.com/ClickHouse/ClickHouse/issues/20203)를 수정합니다. [#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* [#20378](https://github.com/ClickHouse/ClickHouse/issues/20378)에 백포트되었습니다: scale이 서로 다른 두 상수 Decimal 간 이항 연산의 결과가 잘못되는 문제를 수정했습니다. [#20283](https://github.com/ClickHouse/ClickHouse/issues/20283)를 수정했습니다. [#20339](https://github.com/ClickHouse/ClickHouse/pull/20339) ([Maksim Kita](https://github.com/kitaisreal)).
* [#20375](https://github.com/ClickHouse/ClickHouse/issues/20375)에 백포트되었습니다: `join_use_nulls=1`에서 NULL 역참조 문제를 수정했습니다. [#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)).
* [#20359](https://github.com/ClickHouse/ClickHouse/issues/20359)에 백포트되었습니다: RANGE&#95;HASHED() 딕셔너리에서 잘못된 역참조가 발생하지 않도록 했습니다. [#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)).
