<div id="clickhouse-release-v201121-stable-fixme-as-compared-to-v201014881-prestable">
  ### ClickHouse 릴리스 v20.11.2.1-안정 FIXME, v20.10.1.4881-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 데이터가 충분하지 않을 경우 rankCorr 함수가 nan을 반환하도록 변경했습니다 [#16124](https://github.com/ClickHouse/ClickHouse/issues/16124). [#16135](https://github.com/ClickHouse/ClickHouse/pull/16135) ([hexiaoting](https://github.com/hexiaoting)).
* 집계 함수 `boundingRatio`, `rankCorr`, `retention`, `timeSeriesGroupSum`, `timeSeriesGroupRateSum`, `windowFunnel`이 잘못하여 대소문자를 구분하지 않도록 처리되어 있었습니다. 이제 설계대로 이들 함수 이름은 대소문자를 구분합니다. SQL 표준에 명시되었거나 다른 DBMS와의 호환성을 위해 만들어진 함수, 또는 이와 유사한 함수만 대소문자를 구분하지 않아야 합니다. [#16407](https://github.com/ClickHouse/ClickHouse/pull/16407) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ANALYZE` 및 `AST` 쿼리를 제거하고, 이제 전체 기능을 갖춘 `EXPLAIN` 쿼리에 포함되므로 `enable_debug_queries` 설정을 obsolete 처리했습니다. [#16536](https://github.com/ClickHouse/ClickHouse/pull/16536) ([Ivan](https://github.com/abyss7)).
* 키(정렬 키, 프라이머리 키, 파티션 키 등)에서 `AggregateFunction`과 같은 비교할 수 없는 데이터 타입의 사용을 제한합니다. [#16601](https://github.com/ClickHouse/ClickHouse/pull/16601) ([alesapin](https://github.com/alesapin)).
* `distributed_ddl` 구성 섹션에 `profile`이 지정된 경우, 서버 시작 시 이 프로필이 `default` 프로필의 설정을 덮어쓸 수 있었습니다. 이 문제를 수정했으며, 이제 분산 DDL 쿼리의 설정은 전역 서버 설정에 영향을 주지 않아야 합니다. [#16635](https://github.com/ClickHouse/ClickHouse/pull/16635) ([Alexander Tokmakov](https://github.com/tavplubix)).

* 멀티 디스크 구성의 volume에 `disable_merges` 옵션이 추가되었습니다. [#13956](https://github.com/ClickHouse/ClickHouse/pull/13956) ([Vladimir Chebotarev](https://github.com/excitoon)).

[#14195](https://github.com/ClickHouse/ClickHouse/pull/14195) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Single protobuf Message를 한 번에 읽고 쓸 수 있도록 지원합니다(길이 구분 기호 없음). [#15199](https://github.com/ClickHouse/ClickHouse/pull/15199) ([filimonov](https://github.com/filimonov)).
* 시간 delta를 사람이 읽기 쉬운 문자열로 포맷하는 `formatReadableTimeDelta` 함수가 추가되었습니다 ... [#15497](https://github.com/ClickHouse/ClickHouse/pull/15497) ([Filipe Caixeta](https://github.com/filipecaixeta)).
* `tid` 및 `logTrace` 함수가 추가되었습니다. 이로써 [#9434](https://github.com/ClickHouse/ClickHouse/issues/9434)가 해결되었습니다. [#15803](https://github.com/ClickHouse/ClickHouse/pull/15803) ([flynn](https://github.com/ucasfl)).
* clickhouse-client에 새 옵션 `print_query_id`가 추가되었습니다. 이 옵션은 클라이언트가 생성한 현재 쿼리 id를 사용해 임의의 문자열을 생성하는 데 도움이 됩니다. [#15809](https://github.com/ClickHouse/ClickHouse/pull/15809) ([Amos Bird](https://github.com/amosbird)).
* CREATE TABLE 쿼리의 컬럼 목록에서 primary key를 지정할 수 있습니다. [#15823](https://github.com/ClickHouse/ClickHouse/pull/15823) ([Maksim Kita](https://github.com/kitaisreal)).

[#15855](https://github.com/ClickHouse/ClickHouse/pull/15855) ([hexiaoting](https://github.com/hexiaoting)).

* `max&#95;concurrent&#95;queries&#95;for&#95;all&#95;users` 설정이 추가되었습니다. 사용 사례는 [#6636](https://github.com/ClickHouse/ClickHouse/issues/6636)을 참조하십시오. [#16154](https://github.com/ClickHouse/ClickHouse/pull/16154) ([nvartolomei](https://github.com/nvartolomei)).

* named tuple을 평탄화하여 SELECT 목록에 새 컬럼을 추가할 수 있는 특수 함수 `untuple`이 추가되었습니다. [#16242](https://github.com/ClickHouse/ClickHouse/pull/16242) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `toUUIDOrNull`, `toUUIDOrZero` CAST 함수가 추가되었습니다. [#16337](https://github.com/ClickHouse/ClickHouse/pull/16337) ([Maksim Kita](https://github.com/kitaisreal)).
* 현재 실행 중인 백그라운드 페치를 보여주는 `system.replicated_fetches` 테이블이 추가되었습니다. [#16428](https://github.com/ClickHouse/ClickHouse/pull/16428) ([alesapin](https://github.com/alesapin)).
* * `errorCodeToName()` 함수 - 오류의 변수명을 반환합니다 (`query&#95;log` 및 유사한 항목 분석에 유용함) - `system.errors` 테이블 - 오류가 몇 번 발생했는지 보여줍니다 (`system_events_show_zero_values`를 따름). [#16438](https://github.com/ClickHouse/ClickHouse/pull/16438) ([Azat Khuzhin](https://github.com/azat)).
* alpine 기반으로 Docker image를 생성할 수 있게 되었습니다. 사전 컴파일된 바이너리와 Ubuntu 20.04의 glibc 구성 요소를 사용합니다. [#16479](https://github.com/ClickHouse/ClickHouse/pull/16479) ([filimonov](https://github.com/filimonov)).
* `log_queries_min_query_duration_ms`가 추가되었습니다. 이 설정값보다 실행 시간이 긴 쿼리만 `query_log`/`query_thread_log`에 기록됩니다(즉, MySQL의 `slow_query_log`와 유사합니다). [#16529](https://github.com/ClickHouse/ClickHouse/pull/16529) ([Azat Khuzhin](https://github.com/azat)).
* > `farmFingerprint64` 함수를 추가했습니다. [#16570](https://github.com/ClickHouse/ClickHouse/pull/16570) ([Jacob Hayes](https://github.com/JacobHayes)).
* 이제 쿼리 매개변수를 통해 식별자를 전달할 수 있습니다. 또한 이러한 매개변수는 테이블 객체나 컬럼으로 사용할 수 있습니다. [#3815](https://github.com/ClickHouse/ClickHouse/issues/3815). [#16594](https://github.com/ClickHouse/ClickHouse/pull/16594) ([Amos Bird](https://github.com/amosbird)).
* MergeTree BloomFilter 인덱스에 큰 정수(UInt256, Int128, Int256) 및 UUID 데이터 타입 지원이 추가되었습니다. [#16642](https://github.com/ClickHouse/ClickHouse/pull/16642) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 해시 테이블을 미리 할당해 hashed/sparse&#95;hashed 딕셔너리 로딩 속도를 높였습니다. [#15454](https://github.com/ClickHouse/ClickHouse/pull/15454) ([Azat Khuzhin](https://github.com/azat)).
* SELECT FINAL에서 파티션 간 파트를 머지하지 않도록 했습니다. [#15938](https://github.com/ClickHouse/ClickHouse/pull/15938) ([Kruglov Pavel](https://github.com/Avogar)).
* MergeTree 테이블 엔진에서 머지 할당 성능을 개선했습니다. 사용자에게는 눈에 띄지 않는 변경입니다. [#16191](https://github.com/ClickHouse/ClickHouse/pull/16191) ([alesapin](https://github.com/alesapin)).
* 논리 함수의 성능을 약간 개선했습니다. [#16347](https://github.com/ClickHouse/ClickHouse/pull/16347) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantileMerge`의 성능을 개선했습니다. 이전 버전에서는 지나치게 느렸습니다. 이 변경으로 [#1463](https://github.com/ClickHouse/ClickHouse/issues/1463) 문제가 해결되었습니다. [#16643](https://github.com/ClickHouse/ClickHouse/pull/16643) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `-OrNull` 및 `-OrDefault` 집계 함수의 성능을 개선했습니다. [#16661](https://github.com/ClickHouse/ClickHouse/pull/16661) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
