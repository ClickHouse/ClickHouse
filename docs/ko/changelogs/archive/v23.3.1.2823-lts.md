  ### ClickHouse 릴리스 v23.3.1.2823-lts (46e85357ce2) FIXME v23.2.1.2537-stable (52bf836e03a) 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* URL authority의 *domain*RFC()/netloc()에서 허용되는 기호 제약을 완화합니다. [#46841](https://github.com/ClickHouse/ClickHouse/pull/46841) ([Azat Khuzhin](https://github.com/azat)).
* 컬럼에 DEFAULT/EPHEMERAL/ALIAS/MATERIALIZED SQL 문이 있는 KafkaEngine 기반 테이블의 생성을 금지합니다. [#47138](https://github.com/ClickHouse/ClickHouse/pull/47138) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* &quot;asynchronous connection drain&quot; 기능이 제거되었습니다. 관련 설정과 메트릭도 함께 제거되었습니다. 내부 기능이었으므로, 이 기능을 알지 못했던 사용자에게는 이번 제거가 영향을 주지 않아야 합니다. [#47486](https://github.com/ClickHouse/ClickHouse/pull/47486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `arraySum`/`Min`/`Max`/`Avg`/`Product`, `arrayCumSum`/`CumSumNonNegative`, `arrayDifference`, 배열 생성, IN 연산자, 쿼리 매개변수, `groupArrayMovingSum`, 통계 함수, `min`/`max`/`any`/`argMin`/`argMax`, PostgreSQL wire 프로토콜, MySQL 테이블 엔진 및 함수, `sumMap`, `mapAdd`, `mapSubtract`, `arrayIntersect`에서 256비트 Decimal 데이터 타입(38자리를 초과하는 값)을 지원합니다. `arrayIntersect`에는 큰 정수 지원도 추가합니다. 모멘트를 포함하는 통계 집계 함수(`corr` 또는 여러 `TTest` 등)는 내부 표현으로 `Float64`를 사용합니다(이 변경 전에는 `Decimal128`을 사용했지만 실익이 없었습니다). 또한 분산이 무한대인 경우 이러한 함수는 `inf` 대신 `nan`을 반환할 수 있습니다. 일부 함수는 `Decimal256` 데이터 타입을 허용하면서도 이전 버전에서는 `Decimal128`을 반환했는데, 이제 수정되었습니다. 이 변경으로 [#47569](https://github.com/ClickHouse/ClickHouse/issues/47569)가 해결됩니다. 이 변경으로 [#44864](https://github.com/ClickHouse/ClickHouse/issues/44864)가 해결됩니다. 이 변경으로 [#28335](https://github.com/ClickHouse/ClickHouse/issues/28335)가 해결됩니다. [#47594](https://github.com/ClickHouse/ClickHouse/pull/47594) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* backup&#95;threads/restore&#95;threads를 server settings으로 지정합니다. [#47881](https://github.com/ClickHouse/ClickHouse/pull/47881) ([Azat Khuzhin](https://github.com/azat)).
* 잘못된 IPv6 address에 대해 거짓 양성 결과를 반환할 수 있던 isIPv6String 함수를 수정합니다. 예를 들어 `1234::1234:`가 유효한 IPv6 address로 간주되었습니다. [#47895](https://github.com/ClickHouse/ClickHouse/pull/47895) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="new-feature">
  #### 새 기능
</div>

* 설정 `parallel_replicas_custom_key` 및 `parallel_replicas_custom_key_filter_type`를 사용해 레플리카에서 작업을 분할하는 새 모드를 추가했습니다. 클러스터가 단일 세그먼트와 여러 레플리카로 구성된 경우, 최대 `max_parallel_replicas`개까지 무작위로 선택해 세그먼트로 취급합니다. 각 세그먼트에는 해당 필터를 이니시에이터에서 쿼리에 추가한 뒤 세그먼트로 전송합니다. 클러스터가 여러 세그먼트로 구성된 경우에는 임의의 키를 정의할 수 있다는 점을 제외하면 `sample_key`와 동일하게 동작합니다. [#45108](https://github.com/ClickHouse/ClickHouse/pull/45108) ([Antonio Andelic](https://github.com/antonio2368)).
* 취소된 쿼리(예: Ctrl-C로 취소된 경우)가 부분 결과를 반환할 수 있도록 하는 쿼리 설정 `partial_result_on_first_cancel`을 추가했습니다. [#45689](https://github.com/ClickHouse/ClickHouse/pull/45689) ([Alexey Perevyshin](https://github.com/alexX512)).
* Replicated 및 KeeperMap 엔진을 제외한 임의의 테이블 엔진을 임시 테이블에서 사용할 수 있도록 지원을 추가했습니다. [#31497](https://github.com/ClickHouse/ClickHouse/issues/31497)를 부분적으로 해결합니다. [#46071](https://github.com/ClickHouse/ClickHouse/pull/46071) ([Roman Vasin](https://github.com/rvasin)).
* ZooKeeper를 사용한 사용자 정의 SQL 함수 복제를 추가했습니다. [#46085](https://github.com/ClickHouse/ClickHouse/pull/46085) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 서버 구성을 포함하는 `system.server_settings`(`system.settings`와 유사)를 구현했습니다. [#46550](https://github.com/ClickHouse/ClickHouse/pull/46550) ([pufit](https://github.com/pufit)).
* `WIDTH_BUCKET` 함수를 도입했습니다. [#42974](https://github.com/ClickHouse/ClickHouse/issues/42974). [#46790](https://github.com/ClickHouse/ClickHouse/pull/46790) ([avoiderboi](https://github.com/avoiderboi)).
* 지정된 포맷 문자열에 따라 parseDateTime/parseDateTimeInJodaSyntax 함수를 추가했습니다. parseDateTime은 MySQL 문법으로 문자열을 DateTime으로 파싱하고, parseDateTimeInJodaSyntax는 Joda 문법으로 파싱합니다. [#46815](https://github.com/ClickHouse/ClickHouse/pull/46815) ([李扬](https://github.com/taiyang-li)).
* 테이블 함수 `null`의 기본 구조로 `dummy UInt8`을 사용합니다. [#46930](https://github.com/ClickHouse/ClickHouse/issues/46930)를 해결합니다. [#47006](https://github.com/ClickHouse/ClickHouse/pull/47006) ([flynn](https://github.com/ucasfl)).
* parseDateTimeBestEffort 함수에서 `Dec 15, 2021` 형식 지원을 추가했습니다. [#46816](https://github.com/ClickHouse/ClickHouse/issues/46816)를 해결합니다. [#47071](https://github.com/ClickHouse/ClickHouse/pull/47071) ([chen](https://github.com/xiedeyantu)).
* `ULIDStringToDateTime()` 함수를 추가했습니다. [#46945](https://github.com/ClickHouse/ClickHouse/issues/46945)를 해결합니다. [#47087](https://github.com/ClickHouse/ClickHouse/pull/47087) ([Nikolay Degterinsky](https://github.com/evillique)).
* HTTP 인터페이스의 URL 파라미터 `wait_end_of_query` 및 `buffer_size`에 대응하는 설정 `http_wait_end_of_query`와 `http_response_buffer_size`를 추가했습니다. [#47108](https://github.com/ClickHouse/ClickHouse/pull/47108) ([Vladimir C](https://github.com/vdimir)).
* `UNDROP TABLE` 쿼리 지원을 추가했습니다. [#46811](https://github.com/ClickHouse/ClickHouse/issues/46811)를 해결합니다. [#47241](https://github.com/ClickHouse/ClickHouse/pull/47241) ([chen](https://github.com/xiedeyantu)).
* `Atomic` 데이터베이스에서 삭제되었지만 아직 완전히 제거되지 않은 테이블을 보여주는 `system.marked_dropped_tables` 테이블을 추가했습니다. [#47364](https://github.com/ClickHouse/ClickHouse/pull/47364) ([chen](https://github.com/xiedeyantu)).
* MySQL 호환성을 위해 `INSTR`를 `positionCaseInsensitive`의 별칭으로 추가했습니다. [#47529](https://github.com/ClickHouse/ClickHouse/issues/47529)을 해결했습니다. [#47535](https://github.com/ClickHouse/ClickHouse/pull/47535) ([flynn](https://github.com/ucasfl)).
* 숫자를 고정 정밀도의 문자열로 변환할 수 있는 `toDecimalString` 함수를 추가했습니다. [#47838](https://github.com/ClickHouse/ClickHouse/pull/47838) ([Andrey Zvonov](https://github.com/zvonand)).
* MySQL과의 호환성을 개선하기 위해 &quot;LIKE&quot;, &quot;IN&quot;, &quot;MOD&quot; 등과 유사한 연산자 &quot;REGEXP&quot;를 추가했습니다. [#47869](https://github.com/ClickHouse/ClickHouse/pull/47869) ([Robert Schulze](https://github.com/rschu1ze)).
* CLICKHOUSE 소스를 사용하는 DIRECT 딕셔너리에서 읽기 파이프라인을 여러 스레드로 실행할 수 있도록 했습니다. 활성화하려면 `CREATE DICTIONARY` 문에서 소스의 `SETTINGS` 절에 `dictionary_use_async_executor=1`을 설정하십시오. [#47986](https://github.com/ClickHouse/ClickHouse/pull/47986) ([Vladimir C](https://github.com/vdimir)).
* MergeTree 설정 `max_number_of_mutatuins_for_replica`를 추가했습니다. 이 설정은 레플리카당 파트 뮤테이션 수를 지정한 값으로 제한합니다. 0은 레플리카당 뮤테이션 수에 제한이 없음을 의미합니다(실행은 여전히 다른 설정에 의해 제한될 수 있습니다). [#48047](https://github.com/ClickHouse/ClickHouse/pull/48047) ([Vladimir C](https://github.com/vdimir)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 단일 널 허용 키에 대한 집계 성능을 최적화했습니다. [#45772](https://github.com/ClickHouse/ClickHouse/pull/45772) ([LiuNeng](https://github.com/liuneng1994)).
* hasTokenOrNull, hasTokenCaseInsensitive, hasTokenCaseInsensitiveOrNull에 대해 소문자 tokenbf&#95;v1 인덱스 활용을 구현했습니다. [#46252](https://github.com/ClickHouse/ClickHouse/pull/46252) ([ltrk2](https://github.com/ltrk2)).
* 처음 두 문자를 먼저 검색하도록 범용 SIMD `StringSearcher`를 최적화했습니다. [#46289](https://github.com/ClickHouse/ClickHouse/pull/46289) ([Jiebin Sun](https://github.com/jiebinn)).
* System.detached&#95;parts가 매우 커질 수 있었습니다. - 블록 크기 제한을 고려해 여러 소스를 추가했습니다 - 각 블록에서는 io 스레드 풀을 사용해 파트 크기를 계산합니다. 즉, syscall을 병렬로 수행합니다. [#46624](https://github.com/ClickHouse/ClickHouse/pull/46624) ([Sema Checherinda](https://github.com/CheSema)).
* ReplicatedMergeTree 테이블의 `max_replicated_merges_in_queue` 기본값을 16에서 1000으로 늘렸습니다. 이를 통해 ClickHouse Cloud의 공유 스토리지가 있는 클러스터처럼 레플리카 수가 매우 많은 클러스터에서 백그라운드 머지 작업을 더 빠르게 수행할 수 있습니다. [#47050](https://github.com/ClickHouse/ClickHouse/pull/47050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이전 버전에서는 파일 수가 많은 backups의 속도가 믿기 어려울 정도로 느렸습니다. [#47251](https://github.com/ClickHouse/ClickHouse/pull/47251) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* StorageJoin, StorageDictionary, StorageEmbeddedRocksDB를 사용하는 JOIN에서 왼쪽 테이블에 대한 filter push down을 지원합니다. [#47280](https://github.com/ClickHouse/ClickHouse/pull/47280) ([Maksim Kita](https://github.com/kitaisreal)).
* 이제 메모리 내 마크가 압축되어 메모리 사용량이 3~6배 감소했습니다. [#47290](https://github.com/ClickHouse/ClickHouse/pull/47290) ([Michael Kolupaev](https://github.com/al13n321)).
* 파티션 목록을 가져올 때 distinct 대신 group by를 사용하도록 copier를 업데이트했습니다. 큰 테이블에서는 이 변경으로 select 시간이 500초 초과에서 1초 미만으로 줄었습니다. [#47386](https://github.com/ClickHouse/ClickHouse/pull/47386) ([Clayton McClure](https://github.com/cmcclure-twilio)).
* [https://github.com/clickhouse/clickhouse/issues/46453](https://github.com/clickhouse/clickhouse/issues/46453)를 해결했습니다. bisect는 [https://github.com/clickhouse/clickhouse/pull/35525](https://github.com/clickhouse/clickhouse/pull/35525)를 문제가 있는 변경으로 표시했습니다. 이 PR은 해당 PR의 변경 사항을 되돌리는 것으로 보입니다. [#47544](https://github.com/ClickHouse/ClickHouse/pull/47544) ([Ongkong](https://github.com/ongkong)).
* `FINAL`이 포함된 쿼리에서 과도한 읽기를 수정했습니다. [#47801](https://github.com/ClickHouse/ClickHouse/pull/47801) ([Nikita Taranov](https://github.com/nickitat)).
* `max_final_threads`는 서버 시작 시 코어 수로 설정됩니다(`max_threads`에 사용하는 것과 동일한 알고리즘 기준). 이를 통해 CPU 수가 많은 서버에서 `final` 실행의 동시성이 향상됩니다. [#47915](https://github.com/ClickHouse/ClickHouse/pull/47915) ([Nikita Taranov](https://github.com/nickitat)).
* 성능 향상을 위해 읽기 요청에서 batches가 분할되지 않도록 했습니다. [#47978](https://github.com/ClickHouse/ClickHouse/pull/47978) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="improvement">
  #### 개선 사항
</div>

* 맵 관련 함수를 추가했습니다. `mapFromArrays`를 사용하면 한 쌍의 배열로 맵을 생성할 수 있습니다. [#31125](https://github.com/ClickHouse/ClickHouse/pull/31125) ([李扬](https://github.com/taiyang-li)).
* 파일 시스템을 큐로 사용하는 방식을 피하도록 분산 전송을 재작성하고, 대신 인메모리 큐를 사용합니다. [#45491](https://github.com/ClickHouse/ClickHouse/pull/45491) ([Azat Khuzhin](https://github.com/azat)).
* 이름이 지정된 컬렉션에 대해 개별적인 권한 부여를 허용합니다(예: 모든 컬렉션에 한 번에 부여하는 대신 특정 컬렉션에만 `SHOW/CREATE/ALTER/DROP named collection` 접근 권한을 부여할 수 있습니다). [#40894](https://github.com/ClickHouse/ClickHouse/issues/40894)를 해결합니다. 새 접근 유형 `NAMED_COLLECTION_CONTROL`을 추가했으며, 사용자 구성에 명시적으로 추가하지 않는 한 `default` 사용자에게는 부여되지 않습니다(`GRANT ALL`을 수행하려면 필요함). 또한 23.2와 달리, 이제 `default` 사용자가 전체 접근 권한을 갖기 위해 `show_named_collections`를 수동으로 지정할 필요가 없습니다. [#46241](https://github.com/ClickHouse/ClickHouse/pull/46241) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 이제 HTTP protocol을 통한 모든 쿼리의 응답에 `X-ClickHouse-Query-Id` 및 `X-ClickHouse-Timezone` headers가 추가됩니다. 이전에는 `SELECT` 쿼리에만 추가되었습니다. [#46364](https://github.com/ClickHouse/ClickHouse/pull/46364) ([Anton Popov](https://github.com/CurtizJ)).
* host:port 목록이 포함된 URI를 통해 Replica Set에 연결하는 기능과 MongoDB Dictionaries에서 `readPreference` 옵션 지원을 추가했습니다. 예시 URI: mongodb://db0.example.com:27017,db1.example.com:27017,db2.example.com:27017/?replicaSet=myRepl&amp;readPreference=primary. [#46524](https://github.com/ClickHouse/ClickHouse/pull/46524) ([artem-yadr](https://github.com/artem-yadr)).
* 쿼리 계획을 기반으로 PROJECTION 분석을 다시 구현했습니다. 이전 버전과 새 버전 간에 전환할 수 있도록 설정 `query_plan_optimize_projection=1`을 추가했습니다. [#44963](https://github.com/ClickHouse/ClickHouse/issues/44963)을 수정합니다. [#46537](https://github.com/ClickHouse/ClickHouse/pull/46537) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 기본적으로 출력 형식에서 Parquet 포맷 v1 대신 v2를 사용합니다. Parquet 버전을 제어하는 설정 `output_format_parquet_version`을 추가했으며, 가능한 값은 `v1_0`, `v2_4`, `v2_6`, `v2_latest`(기본값)입니다. [#46617](https://github.com/ClickHouse/ClickHouse/pull/46617) ([Kruglov Pavel](https://github.com/Avogar)).
* changelog에 포함되지 않음 - [#42648](https://github.com/ClickHouse/ClickHouse/issues/42648)의 일부입니다. [#46632](https://github.com/ClickHouse/ClickHouse/pull/46632) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* MATERILIZED VIEW로 푸시하는 동안 오류를 무시할 수 있도록 했습니다(새 설정 `materialized_views_ignore_errors` 추가, 기본값은 `false`이지만 `system.*_log` 테이블로 로그를 플러시할 때는 무조건 `true`로 설정됩니다). [#46658](https://github.com/ClickHouse/ClickHouse/pull/46658) ([Azat Khuzhin](https://github.com/azat)).
* 기본적으로 input&#95;format&#95;json&#95;ignore&#95;unknown&#95;keys&#95;in&#95;named&#95;tuple을 활성화합니다. [#46742](https://github.com/ClickHouse/ClickHouse/pull/46742) ([Kruglov Pavel](https://github.com/Avogar)).
* 이제 새 구성 구문을 사용해 이름에 마침표가 포함된 Kafka topics를 구성할 수 있습니다. [#46752](https://github.com/ClickHouse/ClickHouse/pull/46752) ([Robert Schulze](https://github.com/rschu1ze)).
* 문제가 있는 반복을 검사하는 hyperscan 패턴 휴리스틱을 수정했습니다. [#46819](https://github.com/ClickHouse/ClickHouse/pull/46819) ([Robert Schulze](https://github.com/rschu1ze)).
* 다른 레플리카가 동시에 block을 생성한 경우에는 ZK 노드가 존재한다는 내용을 system.errors에 보고하지 않도록 했습니다. [#46820](https://github.com/ClickHouse/ClickHouse/pull/46820) ([Raúl Marín](https://github.com/Algunenano)).
* 컬럼의 DEFAULT 표현식이 서로 다른 Merge에 대해 PREWHERE를 허용합니다. [#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
