* [#31518](https://github.com/ClickHouse/ClickHouse/issues/31518)에서 백포트됨: `not like` 함수를 RPNElement로 옮깁니다. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* [#31554](https://github.com/ClickHouse/ClickHouse/issues/31554)에서 백포트됨: S3용 STS 자격 증명 provider에서 `nullptr` 문제를 해결했습니다. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#31579](https://github.com/ClickHouse/ClickHouse/issues/31579)에서 백포트됨: * 이 최적화의 버그가 수정될 때까지 `partial_merge_join_left_table_buffer_bytes`를 비활성화합니다. [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)를 참조하십시오. * 중복된 옵션 `partial_merge_join_optimizations`를 제거합니다. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* [#31745](https://github.com/ClickHouse/ClickHouse/issues/31745)에서 백포트됨: `Ordinary` 데이터베이스에서 DDL 딕셔너리의 이름을 변경하려고 할 때 `RENAME TABLE` 쿼리가 잘못 동작하던 문제를 수정했습니다. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31794](https://github.com/ClickHouse/ClickHouse/issues/31794)에서 백포트됨: `IPv4`와 같은 도메인 타입을 파싱할 때 설정 `input_format_allow_errors_num` 및 `input_format_allow_errors_ratio`가 동작하지 않던 문제를 수정했습니다. [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686)을 수정합니다. [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31830](https://github.com/ClickHouse/ClickHouse/issues/31830)에서 백포트됨: 지정한 cluster 이름이 `Replicated` 데이터베이스의 이름인 경우 `ON CLUSTER` 쿼리 실행 시 `there are no such cluster here` 오류가 발생하던 문제를 수정했습니다. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31815](https://github.com/ClickHouse/ClickHouse/issues/31815)에서 백포트됨: 출력에서 데이터와 진행률 선이 섞일 때 JSONEachRowWithProgress 출력 형식에서 발생하는 race를 수정했습니다. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32016](https://github.com/ClickHouse/ClickHouse/issues/32016)에서 백포트됨: 위치 인수가 활성화된 경우 group by / order by / limit by alias 관련 문제를 수정했습니다. [#31173](https://github.com/ClickHouse/ClickHouse/issues/31173)을 닫습니다. [#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#31762](https://github.com/ClickHouse/ClickHouse/issues/31762)에서 백포트됨: `Map` 타입에서 `Buffer` 테이블 엔진을 사용할 때의 문제를 수정했습니다. [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546)을 수정합니다. [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* [#31892](https://github.com/ClickHouse/ClickHouse/issues/31892)에서 백포트됨: TSKV 포맷에서 발생할 수 있는 assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` 문제를 수정했습니다. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32031](https://github.com/ClickHouse/ClickHouse/issues/32031)에서 백포트됨: 널 허용 프라이머리 키(primary key)를 사용할 때 널 허용 타입에 대한 잘못된 cast를 수정했습니다. 이 변경으로 [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075)를 수정합니다. [#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird)).
* [#32074](https://github.com/ClickHouse/ClickHouse/issues/32074)에 백포트됨: `Decimal` 인수를 사용하는 `transform` 함수의 버그를 수정했습니다. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* [#31939](https://github.com/ClickHouse/ClickHouse/issues/31939)에 백포트됨: - `KeeperTCPHandler`를 생성할 때 구성 경로를 `keeper_server.session_timeout_ms`에서 `keeper_server.coordination_settings.session_timeout_ms`로 변경했습니다 - `operation_timeout`도 동일하게 변경했습니다. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* [#31909](https://github.com/ClickHouse/ClickHouse/issues/31909)에 백포트됨: `UUID` 유형 인수를 받는 함수 `empty` 및 `notEmpty`를 수정했습니다. [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819)를 해결합니다. [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
