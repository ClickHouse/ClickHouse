<div id="improvement">
  #### 개선 사항
</div>

* 백포트됨 [#58660](https://github.com/ClickHouse/ClickHouse/issues/58660): 데이터 읽기에 많은 streams가 필요한 일부 쿼리를 실행할 때 이전에는 `"Paste JOIN requires sorted tables only"` 오류가 발생했습니다. 이제는 이런 경우 streams 수를 1로 조정합니다. [#58608](https://github.com/ClickHouse/ClickHouse/pull/58608) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 백포트됨 [#58817](https://github.com/ClickHouse/ClickHouse/issues/58817): 사용되지 않는 jemalloc 페이지를 purge하기 위한 `SYSTEM JEMALLOC PURGE`와, 프로파일러가 활성화된 경우 jemalloc profile을 제어하기 위한 `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE`을 추가했습니다. 또한 Keeper에 jemalloc 관련 4LW 명령을 추가했습니다. jemalloc 통계를 dump하는 `jmst`와, 프로파일러가 활성화된 경우 jemalloc profile을 제어하는 `jmfp`, `jmep`, `jmdp`입니다. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* 백포트됨 [#59235](https://github.com/ClickHouse/ClickHouse/issues/59235): Iceberg 테이블 엔진에서 schema evolution을 무시하고, 테이블 생성 시 사용자가 지정한 스키마 또는 테이블 생성 시 metadata에서 파싱된 최신 스키마를 사용해 모든 데이터를 읽을 수 있도록 했습니다. 이는 기본적으로 비활성화되어 있는 `iceberg_engine_ignore_schema_evolution` 설정으로 제어됩니다. 이 설정을 활성화하면 스키마가 변경된 경우에도 모든 data files를 동일한 스키마로 읽게 되므로 잘못된 결과가 나올 수 있습니다. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
