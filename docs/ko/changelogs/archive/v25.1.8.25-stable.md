<div id="new-feature">

* [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357)에 백포트됨: 동시 쿼리 간에 CPU 슬롯이 분배되는 방식을 제어하는 `concurrent_threads_scheduler` 서버 설정이 추가되었습니다. `round_robin`(이전 동작) 또는 `fair_round_robin`으로 설정할 수 있으며, INSERT와 SELECT 간의 CPU 분배가 불공정한 문제를 해결할 수 있습니다. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).
