[#21481](https://github.com/ClickHouse/ClickHouse/issues/21481) 해결. [#21498](https://github.com/ClickHouse/ClickHouse/pull/21498) ([flynn](https://github.com/ucasfl)).
* [#22319](https://github.com/ClickHouse/ClickHouse/issues/22319)에 백포트됨: 외부 데이터베이스 엔진(MySQL, PostgreSQL)에 대한 쿼리의 WHERE 절에서 조인된 테이블의 알 수 없는 컬럼을 제거합니다. [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614) 해결, [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) 해결(중복), [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) 해결(중복). [#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)).
* [#22241](https://github.com/ClickHouse/ClickHouse/issues/22241)에 백포트됨: 스칼라 서브쿼리의 인덱스 분석을 수정했습니다. 이로써 [#21717](https://github.com/ClickHouse/ClickHouse/issues/21717) 문제가 해결되며, 이 문제는 [https://github.com/ClickHouse/ClickHouse/pull/18896](https://github.com/ClickHouse/ClickHouse/pull/18896)에서 도입되었습니다. [#21766](https://github.com/ClickHouse/ClickHouse/pull/21766) ([Amos Bird](https://github.com/amosbird)).
* [#22150](https://github.com/ClickHouse/ClickHouse/issues/22150)에 백포트됨: WriteBufferFromS3의 오류 처리와 로깅을 개선했습니다. [#21836](https://github.com/ClickHouse/ClickHouse/pull/21836) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#22468](https://github.com/ClickHouse/ClickHouse/issues/22468)에 백포트됨: 드물게 `CollapsingMergeTree`의 머지 과정에서 `index_granularity + 1`개의 행이 있는 그래뉼이 생성될 수 있습니다. 이 때문에 [#18928](https://github.com/ClickHouse/ClickHouse/issues/18928)에서 추가된 내부 검사(21.2 및 21.3에 영향)가 `Incomplete granules are not allowed while blocks are granules size` 오류와 함께 실패할 수 있습니다. 이 오류로 인해 파트가 머지되지 않았습니다. [#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#22203](https://github.com/ClickHouse/ClickHouse/issues/22203)에 백포트됨: Docker entrypoint: `LOG_PATH`가 비어 있을 때 `.`에 대해 chown을 수행하지 않도록 했습니다. [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100) 해결. [#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* [#22261](https://github.com/ClickHouse/ClickHouse/issues/22261)에 백포트됨: 문제가 있는 Linux 커널에서는 `async_socket_for_remote`/`use_hedged_requests`를 비활성화했습니다. [#22109](https://github.com/ClickHouse/ClickHouse/pull/22109) ([Azat Khuzhin](https://github.com/azat)).
* [#22281](https://github.com/ClickHouse/ClickHouse/issues/22281)에 백포트됨: `ReplicatedMergeTree` 테이블 엔진의 `OPTIMIZE` 및 `ALTER` 쿼리 대기 처리를 수정했습니다. 이제 테이블이 분리된 상태이거나 재시작된 경우에도 쿼리가 멈추지 않습니다. [#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* [#22265](https://github.com/ClickHouse/ClickHouse/issues/22265)에 백포트됨: 백그라운드 스레드 풀의 이름을 수정했습니다. [#22122](https://github.com/ClickHouse/ClickHouse/pull/22122) ([fastio](https://github.com/fastio)).
* [#22262](https://github.com/ClickHouse/ClickHouse/issues/22262)에 백포트됨: `JOIN`에서 `TOTALS` 및 `arrayJoin` 사용 시 발생하던 `Invalid number of rows in Chunk` 오류를 수정했습니다. [#19303](https://github.com/ClickHouse/ClickHouse/issues/19303)을 닫습니다. [#22129](https://github.com/ClickHouse/ClickHouse/pull/22129) ([Vladimir C](https://github.com/vdimir)).
* [#22316](https://github.com/ClickHouse/ClickHouse/issues/22316)에 백포트됨: 구성에 `http_port`가 없을 때의 docker entrypoint를 수정했습니다. [#22132](https://github.com/ClickHouse/ClickHouse/pull/22132) ([Ewout](https://github.com/devwout)).
* [#22313](https://github.com/ClickHouse/ClickHouse/issues/22313)에 백포트됨: `use_hedged_requests=0` 및 `async_socket_for_remote=1` 사용 시 쿼리 취소 문제를 수정했습니다. [#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* [#22366](https://github.com/ClickHouse/ClickHouse/issues/22366)에 백포트됨: 이제 이미 포함된 part에 mutate를 수행하려고 할 때 ClickHouse가 `LOGICAL_ERROR` 예외를 발생시키지 않습니다. [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013)을 수정합니다. [#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* [#22562](https://github.com/ClickHouse/ClickHouse/issues/22562)에 백포트됨: HTTP 청크 크기를 제한하지 않도록 수정했습니다. [#21907](https://github.com/ClickHouse/ClickHouse/issues/21907)을 수정합니다. [#22322](https://github.com/ClickHouse/ClickHouse/pull/22322) ([Ivan](https://github.com/abyss7)).
* [#22531](https://github.com/ClickHouse/ClickHouse/issues/22531)에 백포트됨: `tokenbf_v1` 전체 텍스트 인덱스에서 읽기 중 버퍼 오버플로우가 발생할 수 있었습니다. 초과된 바이트는 사용되지 않지만, 드문 경우 읽기 작업이 크래시로 이어질 수 있습니다. 이로써 [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233)을 닫습니다. [#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
