<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 이제 `ALTER TABLE ATTACH PART[ITION]` 명령을 처리하는 레플리카는 다른 레플리카에서 데이터를 가져오기 전에 자신의 `detached/` 폴더를 먼저 확인합니다. 구현 세부 사항으로는 복제 로그에 새로운 명령 `ATTACH_PART`가 도입되었습니다. 파트는 체크섬으로 검색하고 비교합니다. [#18978](https://github.com/ClickHouse/ClickHouse/pull/18978) ([Mike Kot](https://github.com/myrrc)).
* `system.dictionaries` 테이블의 컬럼 `keys`가 `key.names` 및 `key.types` 컬럼으로 대체되었습니다. 또한 `system.dictionaries` 테이블의 `key.names`, `key.types`, `attribute.names`, `attribute.types` 컬럼은 딕셔너리가 로드되어 있지 않아도 사용할 수 있습니다. [#21884](https://github.com/ClickHouse/ClickHouse/pull/21884) ([Maksim Kita](https://github.com/kitaisreal)).
* 사용자 지정 최상위 도메인 목록에 포함된 3단계 이상 도메인에서 `cutToFirstSignificantSubdomainCustom()`/`firstSignificantSubdomainCustom()`가 잘못된 결과를 반환하던 문제가 수정되었습니다. 이러한 사용자 지정 최상위 도메인과 일치하는 입력 도메인에서는 3단계 하위 도메인이 첫 번째 유의미한 하위 도메인으로 간주되고 있었습니다. 이제 이 문제가 수정되었습니다. 이 변경으로 인해 예를 들어 해당 함수가 세그먼트 분할 키에 사용되는 경우 호환성 문제가 발생할 수 있습니다. [#21946](https://github.com/ClickHouse/ClickHouse/pull/21946) ([Azat Khuzhin](https://github.com/azat)).
* `toStartOfIntervalFunction`은 이제 시간 인터벌을 자정 기준으로 정렬합니다(이전 버전에서는 Unix epoch 시작점 기준으로 정렬되었습니다). 예를 들어 `toStartOfInterval(x, INTERVAL 11 HOUR)`는 하루를 00:00:00..10:59:59, 11:00:00..21:59:59, 22:00:00..23:59:59의 세 인터벌로 나눕니다. 이 동작이 실제 사용에 더 적합합니다. 이로써 [#9510](https://github.com/ClickHouse/ClickHouse/issues/9510)이 해결됩니다. [#22060](https://github.com/ClickHouse/ClickHouse/pull/22060) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* S3 스토리지에서 ReplicatedMergeTree용 zero-copy 복제를 지원합니다. [#16240](https://github.com/ClickHouse/ClickHouse/pull/16240) ([ianton-ru](https://github.com/ianton-ru)).

* `ComplexKeyCache`, `SSDCache`, `SSDComplexKeyCache` 딕셔너리에 비동기 업데이트를 추가했습니다. `Cache`, `ComplexKeyCache`, `SSDCache`, `SSDComplexKeyCache` 딕셔너리에 널 허용 타입 지원을 추가했습니다. `dictGet`, `dictGetOrDefault` 함수에서 여러 속성을 가져오는 기능을 추가했습니다. [#21517](https://github.com/ClickHouse/ClickHouse/issues/21517) 문제를 수정했습니다. [#20595](https://github.com/ClickHouse/ClickHouse/pull/20595) ([Maksim Kita](https://github.com/kitaisreal)).
* `system.query_log`의 해당 쿼리에 대해 `query_kind` 컬럼에 `Grant,` `Revoke`, `System` 값을 추가했습니다 ... [#21102](https://github.com/ClickHouse/ClickHouse/pull/21102) ([Vasily Nemkov](https://github.com/Enmk)).
* 새로운 SQL 명령 ALTER TABLE &#39;table&#95;name&#39; UNFREEZE [PARTITION &#39;part&#95;expr&#39;] WITH NAME &#39;backup&#95;name&#39;를 추가했습니다. [#21142](https://github.com/ClickHouse/ClickHouse/pull/21142) ([Pavel Kovalenko](https://github.com/Jokser)).
* ExecutablePool 딕셔너리 소스를 추가했습니다. [#14528](https://github.com/ClickHouse/ClickHouse/issues/14528)을 닫습니다. [#21321](https://github.com/ClickHouse/ClickHouse/pull/21321) ([Maksim Kita](https://github.com/kitaisreal)).
* * 지정된 CIDR 네트워크 접두사에 IPv4 또는 IPv6 주소가 포함되어 있는지 확인하는 함수 `isIPAddressInRange`를 추가했습니다. [#21329](https://github.com/ClickHouse/ClickHouse/pull/21329) ([PHO](https://github.com/depressed-pho)).
* `MergeTree*` 엔진에 `_partition_id` 가상 컬럼을 추가했습니다. `_partition_id`를 사용해 파티션 가지치기를 수행할 수 있습니다. 파티션 ID 문자열을 계산하는 `partitionID()` 함수도 추가했습니다. [#21401](https://github.com/ClickHouse/ClickHouse/pull/21401) ([Amos Bird](https://github.com/amosbird)).
* `system.clusters`에 새 컬럼 `slowdowns_count`를 추가했습니다. hedged requests를 사용할 때, 해당 레플리카의 응답이 느려 다른 레플리카로 전환한 횟수를 표시합니다. 또한 `system.clusters`에서 `errors_count`의 실제 값도 표시합니다. [#21480](https://github.com/ClickHouse/ClickHouse/pull/21480) ([Kruglov Pavel](https://github.com/Avogar)).
* clickhouse-format에 `--backslash` 옵션을 추가했습니다. 이 옵션을 사용하면 포맷된 쿼리의 각 줄 끝에 백슬래시를 추가할 수 있습니다. [#21494](https://github.com/ClickHouse/ClickHouse/pull/21494) ([flynn](https://github.com/ucasfl)).
* CREATE/ALTER USER 명령에 새로운 선택적 절인 GRANTEES를 추가했습니다. [#21641](https://github.com/ClickHouse/ClickHouse/pull/21641) ([Vitaly Baranov](https://github.com/vitlibar)).
* `zookeeper-dump-tree`에 `ctime` 옵션을 추가했습니다. 노드 생성 시간을 덤프할 수 있습니다. [#21842](https://github.com/ClickHouse/ClickHouse/pull/21842) ([Ilya](https://github.com/HumanUser)).
* &#39;dictGet&#39;, &#39;dictHas&#39; 함수는 DDL로 생성된 딕셔너리에서 데이터베이스 이름이 지정되지 않은 경우 현재 데이터베이스 이름을 사용합니다. [#21632](https://github.com/ClickHouse/ClickHouse/issues/21632)를 해결했습니다. [#21859](https://github.com/ClickHouse/ClickHouse/pull/21859) ([Maksim Kita](https://github.com/kitaisreal)).
* `PolygonDictionary` 속성에서 `Nullable` 타입을 지원합니다. [#21890](https://github.com/ClickHouse/ClickHouse/pull/21890) ([Maksim Kita](https://github.com/kitaisreal)).
* 테이블 함수 `dictionary`를 추가했습니다. `Dictionary` 엔진과 동일하게 동작합니다. [#21560](https://github.com/ClickHouse/ClickHouse/issues/21560)을 해결했습니다. [#21910](https://github.com/ClickHouse/ClickHouse/pull/21910) ([Maksim Kita](https://github.com/kitaisreal)).
* `DateTime` 또는 `DateTime64` 데이터 타입의 시간대 이름을 반환하는 `timezoneOf` 함수를 추가했습니다. 이는 [#9959](https://github.com/ClickHouse/ClickHouse/issues/9959)를 해결하지 않습니다. 함수 이름의 불일치를 수정해 `timezone`, `timeZone`과 함께 `toTimezone`, `toTimeZone`, `timezoneOf`, `timeZoneOf` 별칭도 추가했습니다. [#22001](https://github.com/ClickHouse/ClickHouse/pull/22001) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 별칭 대신 원래 컬럼 이름을 사용하기 위한 `prefer_column_name_to_alias` 설정을 추가했습니다. 일반적인 데이터베이스의 별칭 규칙과의 호환성을 높이기 위해 필요합니다. 이는 [#9715](https://github.com/ClickHouse/ClickHouse/issues/9715) 및 [#9887](https://github.com/ClickHouse/ClickHouse/issues/9887)를 위한 것입니다. [#22044](https://github.com/ClickHouse/ClickHouse/pull/22044) ([Amos Bird](https://github.com/amosbird)).
* `dictGetHierarchy`, `dictIsIn` 함수의 성능을 개선했습니다. `dictGetChildren(dictionary, key)`, `dictGetDescendants(dictionary, key, level)` 함수도 추가했습니다. `dictGetChildren` 함수는 모든 하위 항목의 인덱스를 배열로 반환합니다. 이는 `dictGetHierarchy`의 역변환입니다. `dictGetDescendants` 함수는 `dictGetChildren`을 재귀적으로 `level`번 적용한 것과 같이 모든 하위 항목을 반환합니다. `level` 값이 0이면 무한대와 같습니다. [#14656](https://github.com/ClickHouse/ClickHouse/issues/14656)를 해결했습니다. [#22096](https://github.com/ClickHouse/ClickHouse/pull/22096) ([Maksim Kita](https://github.com/kitaisreal)).
* 함수 `dictGetOrNull`이 추가되었습니다. 이 함수는 `dictGet`과 유사하지만, 딕셔너리에서 키를 찾을 수 없으면 `Null`을 반환합니다. [#22375](https://github.com/ClickHouse/ClickHouse/issues/22375)를 해결합니다. [#22413](https://github.com/ClickHouse/ClickHouse/pull/22413) ([Maksim Kita](https://github.com/kitaisreal)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* `CSVWithNames` 및 `TSVWithNames` 포맷에 대한 병렬 파싱을 지원합니다. 이로써 [#21085](https://github.com/ClickHouse/ClickHouse/issues/21085)가 해결되었습니다. [#21149](https://github.com/ClickHouse/ClickHouse/pull/21149) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `memcpy`를 다른 구현으로 대체해 성능을 개선했습니다. 이로써 [#18583](https://github.com/ClickHouse/ClickHouse/issues/18583)가 해결되었습니다. [#21520](https://github.com/ClickHouse/ClickHouse/pull/21520) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* clickhouse-local 및 그 밖의 모든 곳에서 병렬 포맷팅을 지원합니다. [#21630](https://github.com/ClickHouse/ClickHouse/pull/21630) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `SELECT ... FINAL ... WHERE`와 같은 쿼리의 성능을 최적화했습니다. 이제 `FINAL`이 포함된 쿼리에서는 정렬 키에 포함된 컬럼을 `PREWHERE`로 이동할 수 있습니다. ... [#21830](https://github.com/ClickHouse/ClickHouse/pull/21830) ([foolchi](https://github.com/foolchi)).
* `max_rows_to_group_by`가 작고 `group_by_overflow_mode='any'`인 경우 `GROUP BY` 성능을 개선했습니다. [#21856](https://github.com/ClickHouse/ClickHouse/pull/21856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 코덱 `NONE` 사용 시 불필요한 데이터 복사를 방지합니다. 코덱 `NONE`은 대부분의 경우 거의 쓸모가 없으므로, 항상 압축을 사용하는 것을 권장합니다(`LZ4`가 기본값입니다). 일반적인 인식과 달리 압축을 비활성화해도 성능이 향상되지 않을 수 있으며, 오히려 반대 효과가 날 수도 있습니다. `NONE` 코덱은 일부 경우에 유용합니다. - 데이터가 압축되지 않는 경우 - 합성 벤치마크의 경우 [#22145](https://github.com/ClickHouse/ClickHouse/pull/22145) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `min_bytes_to_use_mmap_io` 설정으로 읽는 파일에 대한 캐시를 추가했습니다. 이로써 mmap/munmap 호출이 빈번하게 발생하는 것과 그에 따른 페이지 폴트를 피할 수 있어, 설정값이 작을 때 성능이 크게(2배 이상) 향상됩니다. mmap IO는 운영 환경에서 신뢰성을 떨어뜨릴 수 있는 큰 단점이 있다는 점에 유의하십시오(예: 결함이 있는 디스크에서 hung 또는 SIGBUS 발생, 제어하기 어려운 메모리 사용량). 그럼에도 불구하고 벤치마크에서는 유용합니다. [#22206](https://github.com/ClickHouse/ClickHouse/pull/22206) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 64 MiB 이상의 파일 범위에 대해 mmap IO 읽기를 활성화했습니다(`min_bytes_to_use_mmap_io` 설정). 이는 어느 정도 성능 향상으로 이어질 수 있습니다. [#22326](https://github.com/ClickHouse/ClickHouse/pull/22326) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="improvement">
  #### 개선 사항
</div>

* 정렬 키 순서에 따른 집계 성능을 개선했습니다(`optimize_aggregation_in_order` 설정이 활성화된 경우). [#19401](https://github.com/ClickHouse/ClickHouse/pull/19401) ([Anton Popov](https://github.com/CurtizJ)).
* MaterializeMySQL: &#95;version 컬럼에 minmax 스키핑 인덱스를 추가했습니다. [#20382](https://github.com/ClickHouse/ClickHouse/pull/20382) ([Stig Bakken](https://github.com/stigsb)).
* `optimize_on_insert` 설정이 활성화된 경우 INSERT 시 빈 파트를 생성하지 않도록 했습니다. [#20304](https://github.com/ClickHouse/ClickHouse/issues/20304)를 수정했습니다. [#20387](https://github.com/ClickHouse/ClickHouse/pull/20387) ([Kruglov Pavel](https://github.com/Avogar)).
* * `CROSS JOIN`을 `INNER JOIN`으로 재작성할 수 있는 사례를 더 많이 지원합니다. [#20392](https://github.com/ClickHouse/ClickHouse/pull/20392) ([Vladimir C](https://github.com/vdimir)).
* MaterializeMySQL: 연결이 끊어지면 MySQL에 다시 연결을 시도합니다. [#20961](https://github.com/ClickHouse/ClickHouse/pull/20961) ([Håvard Kvålen](https://github.com/havardk)).
* 데이터 타입 `Map`에서 정수 키 지원을 개선했습니다. [#21157](https://github.com/ClickHouse/ClickHouse/pull/21157) ([Anton Popov](https://github.com/CurtizJ)).
* 마지막 쿼리 뒤에 여분의 공백이나 주석이 있어도 clickhouse-format이 예외를 발생시키지 않도록 개선했으며, 데이터가 있는 `ASTInsertQuery` 포맷을 처리할 때는 이해하기 쉬운 메시지와 함께 예외를 조기에 발생시키도록 했습니다. [#21311](https://github.com/ClickHouse/ClickHouse/pull/21311) ([flynn](https://github.com/ucasfl)).
* graphite 롤업 구성에서 Age와 Precision은 보존 기간이 진행될수록 증가해야 합니다. 이제 이를 검사하며, 잘못된 구성은 예외를 발생시킵니다. [#21496](https://github.com/ClickHouse/ClickHouse/pull/21496) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* `optimize_skip_unused_shards`의 세그먼트 분할 키 값 개수를 제한하는 설정 `optimize_skip_unused_shards_limit`를 추가했습니다. [#21512](https://github.com/ClickHouse/ClickHouse/pull/21512) ([Azat Khuzhin](https://github.com/azat)).
* `visitParam/visitParamExtract{UInt, Int, Bool, Float, Raw, String}`의 별칭으로 `simpleJSONExtract/simpleJSONHas`를 추가했습니다. [#21383](https://github.com/ClickHouse/ClickHouse/issues/21383)를 수정했습니다. [#21519](https://github.com/ClickHouse/ClickHouse/pull/21519) ([fastio](https://github.com/fastio)).
* `system.errors`에 `last_error_time`/`last_error_message`/`last_error_stacktrace`/`remote` 컬럼을 추가했습니다. [#21529](https://github.com/ClickHouse/ClickHouse/pull/21529) ([Azat Khuzhin](https://github.com/azat)).
* PODArray가 요소 크기가 16의 약수도 배수도 아니도록 인스턴스화되면 버퍼 오버플로우가 발생할 수 있었습니다. 현재 릴리스에는 해당 버그가 없습니다. [#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* * 분산 DDL 쿼리에도 쿼리 및 세션 설정이 전파되도록 했습니다. 이를 활성화하려면 `distributed_ddl_entry_format_version`을 2로 설정하십시오. - `distributed_ddl_output_mode` 설정이 추가되었습니다. 지원되는 모드는 `none`, `throw`(기본값), `null_status_on_timeout`, `never_throw`입니다. - `Replicated` 데이터베이스 엔진에 여러 수정 및 개선 사항이 적용되었습니다.
