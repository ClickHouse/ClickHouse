  ### ClickHouse 릴리스 v24.5.1.1763-안정 (647c154a94d) FIXME, v24.4.1.2088-안정 (6d4b31322d1) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 더 기술적이지 않고 사용자 친화적인 이름으로 &quot;inverted indexes&quot;를 &quot;full-text indexes&quot;로 변경했습니다. 이 변경으로 내부 테이블 메타데이터도 바뀌며, 기존의 (experimental) inverted indexes가 있는 테이블은 호환되지 않게 됩니다. 업그레이드 전에 해당 인덱스를 삭제하고, 업그레이드 후 다시 생성하십시오. [#62884](https://github.com/ClickHouse/ClickHouse/pull/62884) ([Robert Schulze](https://github.com/rschu1ze)).
* 함수 `neighbor`, `runningAccumulate`, `runningDifferenceStartingWithFirstValue`, `runningDifference`의 사용이 Deprecated되었습니다(오류를 유발하기 쉽기 때문입니다). 대신 적절한 윈도우 함수를 사용해야 합니다. 다시 활성화하려면 `allow_deprecated_functions=1`을 설정하십시오. [#63132](https://github.com/ClickHouse/ClickHouse/pull/63132) ([Nikita Taranov](https://github.com/nickitat)).
* 컬럼 수가 매우 많고 `SHOW TABLES` 권한이 부여되지 않은 데이터베이스나 테이블도 많은 경우, `system.columns`에 대한 쿼리가 더 빠르게 동작합니다. 이전 버전에서는 해당 테이블에 `SHOW TABLES`를 부여하지 않고 개별 컬럼에 `SHOW COLUMNS`를 부여하면 `system.columns` 테이블에 해당 컬럼이 표시되었지만, 새 버전에서는 그 테이블 전체를 건너뜁니다. 또한 쿼리를 느리게 만들던 trace log 메시지 &quot;Access granted&quot; 및 &quot;Access denied&quot;를 제거했습니다. [#63439](https://github.com/ClickHouse/ClickHouse/pull/63439) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 새 기능
</div>

* ClickHouse 서버의 AzureBlobStorage 함수에서 Azure blob storage 인증에 Azure Workload Identity를 사용할 수 있도록 지원을 추가했습니다. 구성에 `use_workload_identity` 매개변수를 설정하면 인증에 [workload identity](https://github.com/Azure/azure-sdk-for-cpp/tree/main/sdk/identity/azure-identity#authenticate-azure-hosted-applications)를 사용합니다. [#57881](https://github.com/ClickHouse/ClickHouse/pull/57881) ([Vinay Suryadevara](https://github.com/vinay92-ch)).
* rocksdb의 내장 memtable에 의존하는 대신 SST 파일을 생성하고 수집하여 StorageEmbeddedRocksDB에 대량 적재를 도입했습니다. 이를 통해 가져오기 속도가 향상되며, 특히 StorageEmbeddedRocksDB 테이블에 대한 장시간 실행되는 삽입 쿼리에서 효과적입니다. 또한 `StorageEmbeddedRocksDB` 테이블 설정도 추가했습니다. [#59163](https://github.com/ClickHouse/ClickHouse/pull/59163) ([Duc Canh Le](https://github.com/canhld94)).
* 이제 `input_format_tsv_crlf_end_of_line` 설정을 사용해 TSV 포맷에서 CRLF를 파싱할 수 있습니다. [#56257](https://github.com/ClickHouse/ClickHouse/issues/56257)를 해결합니다. [#59747](https://github.com/ClickHouse/ClickHouse/pull/59747) ([Shaun Struwig](https://github.com/Blargian)).
* application/x-www-form-urlencoded 포맷으로 단일 레코드를 읽고 쓸 수 있는 Form Format을 추가했습니다. [#60199](https://github.com/ClickHouse/ClickHouse/pull/60199) ([Shaun Struwig](https://github.com/Blargian)).
* CROSS JOIN에서 압축을 사용할 수 있는 기능을 추가했습니다. [#60459](https://github.com/ClickHouse/ClickHouse/pull/60459) ([p1rattttt](https://github.com/p1rattttt)).
* 생략된 필드에 NULL 값을 강제로 적용하는 새로운 설정 `input_format_force_null_for_omitted_fields`를 추가했습니다. [#60887](https://github.com/ClickHouse/ClickHouse/pull/60887) ([Constantine Peresypkin](https://github.com/pkit)).
* 왼쪽 테이블과 오른쪽 테이블의 컬럼이 모두 포함된 부등 조건을 사용하는 join을 지원합니다. 예: `t1.y < t2.y`. 사용하려면 `SET allow_experimental_join_condition = 1`을 설정하십시오. [#60920](https://github.com/ClickHouse/ClickHouse/pull/60920) ([lgbo](https://github.com/lgbo-ustc)).
* 이전에는 S3 storage와 S3 테이블 함수에서 아카이브 파일을 대상으로 select하는 기능을 지원하지 않았습니다. 이제 S3의 아카이브 내부 파일을 순회할 수 있습니다. [#62259](https://github.com/ClickHouse/ClickHouse/pull/62259) ([Daniil Ivanik](https://github.com/divanik)).
* 조건 함수 `clamp` 지원을 추가했습니다. [#62377](https://github.com/ClickHouse/ClickHouse/pull/62377) ([skyoct](https://github.com/skyoct)).
* npy 출력 형식을 추가했습니다. [#62430](https://github.com/ClickHouse/ClickHouse/pull/62430) ([豪肥肥](https://github.com/HowePa)).
* version 7 UUID, 즉 무작위 구성 요소를 포함한 타임스탬프 기반 UUID를 생성하는 SQL 함수 `generateUUIDv7`, `generateUUIDv7ThreadMonotonic`, `generateUUIDv7NonMonotonic`(단조성/성능 절충이 서로 다름)을 추가했습니다. 또한 UUID에서 바이트를 추출하는 새 함수 `UUIDToNum`과 UUID version 7에서 타임스탬프 구성 요소를 추출하는 새 함수 `UUIDv7ToDateTime`도 추가했습니다. [#62852](https://github.com/ClickHouse/ClickHouse/pull/62852) ([Alexey Petrunyaka](https://github.com/pet74alex)).
* [#64307](https://github.com/ClickHouse/ClickHouse/issues/64307)에 백포트됨: 미리 모든 타입을 알지 못해도 내부에 어떤 타입의 값이든 저장할 수 있는 Dynamic 데이터 타입을 구현했습니다. Dynamic type은 `allow_experimental_dynamic_type` 설정으로 사용할 수 있습니다. 참고: [#54864](https://github.com/ClickHouse/ClickHouse/issues/54864). [#63058](https://github.com/ClickHouse/ClickHouse/pull/63058) ([Kruglov Pavel](https://github.com/Avogar)).
* rocksdb 내장 memtable에 의존하는 대신 SST 파일을 생성해 적재하는 방식의 대량 적재를 StorageEmbeddedRocksDB에 도입했습니다. 이는 특히 StorageEmbeddedRocksDB 테이블에 대한 장시간 실행되는 insert 쿼리의 적재 속도를 높이는 데 도움이 됩니다. 또한 StorageEmbeddedRocksDB 테이블 설정도 추가했습니다. [#63324](https://github.com/ClickHouse/ClickHouse/pull/63324) ([Duc Canh Le](https://github.com/canhld94)).
* TSVRaw의 동의어로 Raw를 추가했습니다. [#63394](https://github.com/ClickHouse/ClickHouse/pull/63394) ([Unalian](https://github.com/Unalian)).
* 크기가 한도를 초과하는 경우 임시 파일에서 CROSS JOIN을 수행할 수 있는 기능을 추가했습니다. [#63432](https://github.com/ClickHouse/ClickHouse/pull/63432) ([p1rattttt](https://github.com/p1rattttt)).
* Linux 및 MacOS에서 프로그램의 STDOUT이 압축 확장자가 있는 파일로 리디렉션된 경우, 압축을 사용하지 않는 대신 해당 압축 방식을 사용하도록 변경했습니다(`INTO OUTFILE`과 유사하게 동작함). [#63662](https://github.com/ClickHouse/ClickHouse/pull/63662) ([v01dXYZ](https://github.com/v01dXYZ)).
* attached 상태인 테이블 수가 많을 때 표시되는 경고를 변경해 테이블, 뷰, 딕셔너리를 구분할 수 있도록 했습니다. [#64180](https://github.com/ClickHouse/ClickHouse/pull/64180) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* `INSERT` 시 새로 생성된 projection 블록의 머지를 건너뜁니다. [#59405](https://github.com/ClickHouse/ClickHouse/pull/59405) ([Nikita Taranov](https://github.com/nickitat)).
* 입력 문자열이 모두 ASCII 문자이면 XXXUTF8 문자열 함수를 &quot;ASCII 방식으로&quot; 처리합니다. [https://github.com/apache/doris/pull/29799](https://github.com/apache/doris/pull/29799)에서 아이디어를 얻었습니다. 전반적으로 1.07배~1.62배 빨라집니다. 일부 경우에는 최대 메모리 사용량도 감소했습니다. [#61632](https://github.com/ClickHouse/ClickHouse/pull/61632) ([李扬](https://github.com/taiyang-li)).
* StorageS3에서 선택(`{}`) 글롭 패턴의 성능을 개선했습니다. [#62120](https://github.com/ClickHouse/ClickHouse/pull/62120) ([Andrey Zvonov](https://github.com/zvonand)).
* HostResolver에는 각 IP 주소가 여러 번 포함됩니다. 원격 호스트에 여러 IP가 있고 어떤 이유로든(예: 방화벽 규칙) 일부 IP는 접근이 허용되고 다른 IP는 금지된 경우, 금지된 IP 중 첫 번째 항목만 Failed로 표시되어 이후 시도에서도 해당 IP들이 다시 선택되어 또 실패할 수 있습니다. 또한 이 문제를 수정하더라도 120초마다 DNS cache가 삭제되므로 IP가 다시 선택될 수 있습니다. [#62652](https://github.com/ClickHouse/ClickHouse/pull/62652) ([Anton Ivashkin](https://github.com/ianton-ru)).
* 컬럼이 많을 때 메모리 사용량을 제어하고 머지 중 정렬 속도를 2배 높일 수 있도록 새 구성 `prefer_merge_sort_block_bytes`를 추가했습니다. [#62904](https://github.com/ClickHouse/ClickHouse/pull/62904) ([LiuNeng](https://github.com/liuneng1994)).
* `clickhouse-local`의 시작 속도가 더 빨라집니다. 이전 버전에서는 실수로 임시 디렉터리를 삭제하지 않았지만, 이제는 삭제합니다. 이로써 [#62941](https://github.com/ClickHouse/ClickHouse/issues/62941)이 해결됩니다. [#63074](https://github.com/ClickHouse/ClickHouse/pull/63074) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 새 분석기에 대한 미세 최적화를 적용했습니다. [#63429](https://github.com/ClickHouse/ClickHouse/pull/63429) ([Raúl Marín](https://github.com/Algunenano)).
* `DateTime`을 `DateTime64`와 비교할 때도 인덱스 분석이 작동합니다. 이로써 [#63441](https://github.com/ClickHouse/ClickHouse/issues/63441)이 해결됩니다. [#63443](https://github.com/ClickHouse/ClickHouse/pull/63443) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `DateTime`을 `DateTime64`와 비교할 때도 인덱스 분석이 작동합니다. 이로써 [#63441](https://github.com/ClickHouse/ClickHouse/issues/63441)이 해결됩니다. [#63532](https://github.com/ClickHouse/ClickHouse/pull/63532) ([Raúl Marín](https://github.com/Algunenano)).
* `set` 유형 인덱스에서 불필요한 요소를 제거해 성능을 소폭(약 1.5배) 개선했습니다. [#64098](https://github.com/ClickHouse/ClickHouse/pull/64098) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* 맵은 이제 `Float32`, `Float64`, `Array(T)`, `Map(K,V)`, `Tuple(T1, T2, ...)`를 키로 사용할 수 있습니다. [#54537](https://github.com/ClickHouse/ClickHouse/issues/54537)을 해결했습니다. [#59318](https://github.com/ClickHouse/ClickHouse/pull/59318) ([李扬](https://github.com/taiyang-li)).
* 테두리 보존과 컬럼 너비 변경을 지원하는 여러 줄 문자열. [#59940](https://github.com/ClickHouse/ClickHouse/pull/59940) ([Volodyachan](https://github.com/Volodyachan)).
* rabbitmq가 손상된 메시지에 대해 nack를 수행하도록 개선했습니다. [#45350](https://github.com/ClickHouse/ClickHouse/issues/45350)을 해결했습니다. [#60312](https://github.com/ClickHouse/ClickHouse/pull/60312) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 디버그 정보를 해석하는 동안 비동기 stack unwinding(예: sampling query profiler 사용 시)에서 발생하던 크래시를 수정했습니다. 이로써 [#60460](https://github.com/ClickHouse/ClickHouse/issues/60460)을 해결했습니다. [#60468](https://github.com/ClickHouse/ClickHouse/pull/60468) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* disk와 storage 사례에서 s3 오류 &#39;no key&#39;에 대해 서로 다른 메시지를 제공하도록 했습니다. [#61108](https://github.com/ClickHouse/ClickHouse/pull/61108) ([Sema Checherinda](https://github.com/CheSema)).
* 파일 시스템 캐시(4부)에서의 경합을 줄였습니다. 백그라운드에서 추가 eviction을 수행해 파일 시스템 캐시가 한도까지 가득 차지 않도록 유지할 수 있습니다(`keep_free_space_size(elements)_ratio`로 제어). 이를 통해 쿼리의 공간 예약(`tryReserve` 메서드)에 가해지는 부담을 줄일 수 있습니다. 또한 가능한 한 lock free 방식으로 수행되므로 일반적인 캐시 사용을 차단하지 않습니다. [#61250](https://github.com/ClickHouse/ClickHouse/pull/61250) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 진행률 표시줄이 `system.zeros`, `system.zeros_mt`에 대해 LIMIT를 사용하는 단순한 쿼리(이미 `system.numbers` 및 `system.numbers_mt`에서는 동작함)와 `generateRandom` 테이블 함수에서도 동작합니다. 추가로 전체 레코드 수가 `max_rows_to_read` 제한보다 크면 더 일찍 예외를 발생시킵니다. 이로써 [#58183](https://github.com/ClickHouse/ClickHouse/issues/58183)을 해결했습니다. [#61823](https://github.com/ClickHouse/ClickHouse/pull/61823) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* YAML Merge Key를 지원합니다. [#62685](https://github.com/ClickHouse/ClickHouse/pull/62685) ([Azat Khuzhin](https://github.com/azat)).
* 비결정적 함수가 Replicated source와 함께 사용될 때 표시되는 오류 메시지를 개선했습니다. [#62896](https://github.com/ClickHouse/ClickHouse/pull/62896) ([Grégoire Pineau](https://github.com/lyrixx)).
* `remote`의 Distributed over Distributed에 대한 interserver secret를 수정했습니다. [#63013](https://github.com/ClickHouse/ClickHouse/pull/63013) ([Azat Khuzhin](https://github.com/azat)).
