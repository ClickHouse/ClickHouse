* [#32151](https://github.com/ClickHouse/ClickHouse/issues/32151)에서 백포트: 데이터 타입이 `Nullable`일 때 딕셔너리 속성에 타입을 지정한 함수 `dictGet`을 사용하면 발생하던 크래시를 수정했습니다. [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)을 수정합니다. [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32093](https://github.com/ClickHouse/ClickHouse/issues/32093)에서 백포트: 모든 레플리카에서 파트가 손실되고 동일한 파티션에 다른 파트가 없는 경우, 일부 `GET_PART` 항목이 복제 큐에서 멈춰 있을 수 있습니다. 이 문제는 파티션 키에 정수 타입 컬럼 또는 `Date[Time]`만 포함된 경우 수정되었습니다. [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485)을 수정합니다. [#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32147](https://github.com/ClickHouse/ClickHouse/issues/32147)에서 백포트: 파트를 detach할 때 발생하던 `Directory ... already exists and is not empty` 오류를 수정했습니다. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32216](https://github.com/ClickHouse/ClickHouse/issues/32216)에서 백포트: 일부 레플리카에서 `replicated_can_become_leader` 설정이 비활성화된 경우, quorum으로 삽입할 때 활성 레플리카 수가 잘못 계산될 수 있던 문제를 수정했습니다. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32352](https://github.com/ClickHouse/ClickHouse/issues/32352)에서 백포트: `Decimal` 인수를 사용하는 집계 함수 `avgWeighted`에서 SIGFPE와 함께 발생하던 크래시를 수정했습니다. [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)을 수정합니다. [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32393](https://github.com/ClickHouse/ClickHouse/issues/32393)에서 백포트: 기본 표현식의 데이터 타입이 컬럼의 데이터 타입과 일치하지 않는 경우 `ALTER ... MATERIALIZE COLUMN ...` 쿼리의 문제를 수정했습니다. [#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
