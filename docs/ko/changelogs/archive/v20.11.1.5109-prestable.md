  ### ClickHouse 릴리스 v20.11.1.5109-prestable FIXME, v20.10.1.4881-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 데이터가 충분하지 않은 경우 `rankCorr` 함수가 nan을 반환하도록 변경했습니다 [#16124](https://github.com/ClickHouse/ClickHouse/issues/16124). [#16135](https://github.com/ClickHouse/ClickHouse/pull/16135) ([hexiaoting](https://github.com/hexiaoting)).
* 집계 함수 `boundingRatio`, `rankCorr`, `retention`, `timeSeriesGroupSum`, `timeSeriesGroupRateSum`, `windowFunnel` 이 잘못하여 대소문자를 구분하지 않도록 처리되고 있었습니다. 이제 설계에 맞게 함수 이름이 대소문자를 구분하도록 수정되었습니다. SQL 표준에 정의되어 있거나 다른 DBMS와의 호환성을 위해 만들어진 함수, 또는 이와 유사한 함수만 대소문자를 구분하지 않아야 합니다. [#16407](https://github.com/ClickHouse/ClickHouse/pull/16407) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ANALYZE` 및 `AST` 쿼리를 제거하고, 이제 전체 기능을 갖춘 `EXPLAIN` 쿼리에 포함되므로 `enable_debug_queries` 설정을 더 이상 사용되지 않음으로 변경했습니다. [#16536](https://github.com/ClickHouse/ClickHouse/pull/16536) ([Ivan](https://github.com/abyss7)).
* 키(정렬 키, 프라이머리 키, 파티션 키 등)에서 `AggregateFunction` 과 같은 비교할 수 없는 데이터 타입의 사용을 제한했습니다. [#16601](https://github.com/ClickHouse/ClickHouse/pull/16601) ([alesapin](https://github.com/alesapin)).
* `distributed_ddl` 구성 섹션에 `profile` 이 지정된 경우, 서버 시작 시 이 프로필이 `default` 프로필의 설정을 덮어쓸 수 있었습니다. 이 문제가 수정되어 이제 분산 DDL 쿼리의 설정이 전역 서버 설정에 영향을 주지 않습니다. [#16635](https://github.com/ClickHouse/ClickHouse/pull/16635) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="new-feature">
  #### 새 기능
</div>

* 멀티 디스크 구성의 volume에 `disable_merges` 옵션이 추가되었습니다. [#13956](https://github.com/ClickHouse/ClickHouse/pull/13956) ([Vladimir Chebotarev](https://github.com/excitoon)).

[#14195](https://github.com/ClickHouse/ClickHouse/pull/14195) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 단일 protobuf message를 length-delimiter 없이 한 번에 읽고 쓸 수 있도록 지원합니다. [#15199](https://github.com/ClickHouse/ClickHouse/pull/15199) ([filimonov](https://github.com/filimonov)).
* 시간 delta를 사람이 읽기 쉬운 문자열로 포맷하는 함수 `formatReadableTimeDelta`가 추가되었습니다... [#15497](https://github.com/ClickHouse/ClickHouse/pull/15497) ([Filipe Caixeta](https://github.com/filipecaixeta)).
* `tid` 및 `logTrace` 함수가 추가되었습니다. 이로써 [#9434](https://github.com/ClickHouse/ClickHouse/issues/9434)가 해결되었습니다. [#15803](https://github.com/ClickHouse/ClickHouse/pull/15803) ([flynn](https://github.com/ucasfl)).
* clickhouse-client에 새 옵션 `print_query_id`가 추가되었습니다. 이 옵션은 클라이언트가 생성한 현재 Query id를 사용해 임의의 문자열을 생성하는 데 도움이 됩니다. [#15809](https://github.com/ClickHouse/ClickHouse/pull/15809) ([Amos Bird](https://github.com/amosbird)).
* CREATE TABLE 쿼리의 컬럼 목록에서 프라이머리 키를 지정할 수 있도록 지원합니다. [#15823](https://github.com/ClickHouse/ClickHouse/pull/15823) ([Maksim Kita](https://github.com/kitaisreal)).
* date&#95;time&#95;output&#95;format setting이 추가되었습니다. [#15845](https://github.com/ClickHouse/ClickHouse/pull/15845) ([Maksim Kita](https://github.com/kitaisreal)).
* ORDER BY가 있는 SELECT 쿼리에서 `OFFSET offset_row_count {ROW | ROWS} FETCH {FIRST | NEXT} fetch_row_count {ROW | ROWS} {ONLY | WITH TIES}`가 구현되었습니다. 관련 issue: [#15367](https://github.com/ClickHouse/ClickHouse/issues/15367). [#15855](https://github.com/ClickHouse/ClickHouse/pull/15855) ([hexiaoting](https://github.com/hexiaoting)).
* Welch의 t-test에 사용되는 p-value를 계산하는 집계 함수가 추가되었습니다. [#15874](https://github.com/ClickHouse/ClickHouse/pull/15874) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* max&#95;concurrent&#95;queries&#95;for&#95;all&#95;users setting이 추가되었습니다. 사용 사례는 [#6636](https://github.com/ClickHouse/ClickHouse/issues/6636)을 참조하십시오. [#16154](https://github.com/ClickHouse/ClickHouse/pull/16154) ([nvartolomei](https://github.com/nvartolomei)).
* ClickHouse에 간단한 web UI가 추가되었습니다. [#16158](https://github.com/ClickHouse/ClickHouse/pull/16158) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* named tuple을 평탄화하여 SELECT 목록에 새 컬럼을 추가할 수 있는 특수 함수 `untuple`이 추가되었습니다. [#16242](https://github.com/ClickHouse/ClickHouse/pull/16242) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* toUUIDOrNull, toUUIDOrZero CAST 함수가 추가되었습니다. [#16337](https://github.com/ClickHouse/ClickHouse/pull/16337) ([Maksim Kita](https://github.com/kitaisreal)).
* 현재 실행 중인 백그라운드 페치를 보여주는 `system.replicated_fetches` 테이블이 추가되었습니다. [#16428](https://github.com/ClickHouse/ClickHouse/pull/16428) ([alesapin](https://github.com/alesapin)).
* * `errorCodeToName()` 함수 - 오류의 변수명을 반환합니다 (`query&#95;log` 및 유사한 로그를 분석할 때 유용함) - `system.errors` 테이블 - 오류 발생 횟수를 표시합니다 (`system_events_show_zero_values`를 따름). [#16438](https://github.com/ClickHouse/ClickHouse/pull/16438) ([Azat Khuzhin](https://github.com/azat)).
* Alpine 기반의 Docker image를 생성하는 기능이 추가되었습니다. 미리 컴파일된 바이너리와 Ubuntu 20.04의 glibc 구성 요소를 사용합니다. [#16479](https://github.com/ClickHouse/ClickHouse/pull/16479) ([filimonov](https://github.com/filimonov)).
* `log_queries_min_query_duration_ms`가 추가되었습니다. 이 설정값보다 오래 걸린 쿼리만 `query_log`/`query_thread_log`에 기록됩니다(즉, MySQL의 `slow_query_log`와 유사합니다). [#16529](https://github.com/ClickHouse/ClickHouse/pull/16529) ([Azat Khuzhin](https://github.com/azat)).
* > farmFingerprint64 함수를 추가했습니다. [#16570](https://github.com/ClickHouse/ClickHouse/pull/16570) ([Jacob Hayes](https://github.com/JacobHayes)).
* 이제 쿼리 매개변수를 통해 식별자를 전달할 수 있습니다. 또한 이러한 매개변수는 테이블 객체나 컬럼 식별자로 사용할 수 있습니다. [#3815](https://github.com/ClickHouse/ClickHouse/issues/3815). [#16594](https://github.com/ClickHouse/ClickHouse/pull/16594) ([Amos Bird](https://github.com/amosbird)).
* MergeTree BloomFilter 인덱스에 대형 정수 타입(UInt256, Int128, Int256) 및 UUID 데이터 타입 지원이 추가되었습니다. [#16642](https://github.com/ClickHouse/ClickHouse/pull/16642) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 해시 테이블을 미리 할당해 hashed/sparse&#95;hashed 딕셔너리 로딩 속도를 높였습니다. [#15454](https://github.com/ClickHouse/ClickHouse/pull/15454) ([Azat Khuzhin](https://github.com/azat)).
* SELECT FINAL에서 파티션 간 파트를 머지하지 않도록 했습니다. [#15938](https://github.com/ClickHouse/ClickHouse/pull/15938) ([Kruglov Pavel](https://github.com/Avogar)).
* MergeTree 테이블 엔진에서 머지 할당 성능을 개선했습니다. 사용자에게는 보이지 않는 변경입니다. [#16191](https://github.com/ClickHouse/ClickHouse/pull/16191) ([alesapin](https://github.com/alesapin)).
* 논리 함수의 성능을 소폭 개선했습니다. [#16347](https://github.com/ClickHouse/ClickHouse/pull/16347) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantileMerge`의 성능을 개선했습니다. 이전 버전에서는 지나치게 느렸습니다. 이 변경으로 [#1463](https://github.com/ClickHouse/ClickHouse/issues/1463)가 해결되었습니다. [#16643](https://github.com/ClickHouse/ClickHouse/pull/16643) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `-OrNull` 및 `-OrDefault` 집계 함수의 성능을 개선했습니다. [#16661](https://github.com/ClickHouse/ClickHouse/pull/16661) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* `CREATE TABLE table AS table_function(...)` 쿼리에서 컬럼 목록을 명시적으로 지정할 수 있도록 합니다. [#9249](https://github.com/ClickHouse/ClickHouse/issues/9249), [#14214](https://github.com/ClickHouse/ClickHouse/issues/14214)를 수정합니다. [#14295](https://github.com/ClickHouse/ClickHouse/pull/14295) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 이제 단순한 `count` 최적화가 약간 더 복잡해집니다. 정확한 파티션 표현식을 포함하는 프레디케이트도 최적화할 수 있습니다. 또한 `max_parallel_replicas > 1`일 때 잘못된 `count`를 반환하는 [#11092](https://github.com/ClickHouse/ClickHouse/issues/11092)도 수정합니다. [#15074](https://github.com/ClickHouse/ClickHouse/pull/15074) ([Amos Bird](https://github.com/amosbird)).
* CSV, TSV 및 JSON 입력 형식에서 enum 값을 해당 id로 파싱할 수 있도록 지원합니다. [#15685](https://github.com/ClickHouse/ClickHouse/pull/15685) ([vivarum](https://github.com/vivarum)).
* `zookeeper-dump-tree` 도구에 재연결 기능을 추가합니다. [#15711](https://github.com/ClickHouse/ClickHouse/pull/15711) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 오해의 소지가 있는 결과가 나올 가능성을 줄이기 위해 `MemoryTrackingInBackground*` 메트릭을 제거합니다. 이 변경으로 [#15684](https://github.com/ClickHouse/ClickHouse/issues/15684)도 수정됩니다. [#15813](https://github.com/ClickHouse/ClickHouse/pull/15813) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 일부 로그 메시지의 수준을 `information`에서 `debug`로 변경하여 모든 쿼리마다 정보 메시지가 표시되지 않도록 합니다. 이로써 [#5293](https://github.com/ClickHouse/ClickHouse/issues/5293)가 종료됩니다. [#15816](https://github.com/ClickHouse/ClickHouse/pull/15816) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 구성 오류가 있는 경우(`connections_with_failover_max_tries`가 0으로 설정된 경우) 쿼리가 멈추는 문제(무한 루프)를 수정합니다. [#15876](https://github.com/ClickHouse/ClickHouse/pull/15876) ([Azat Khuzhin](https://github.com/azat)).
* 사용성을 높이기 위해 `db_generator`에 boost::program&#95;options를 추가했습니다. 이로써 [#15940](https://github.com/ClickHouse/ClickHouse/issues/15940)이 종료됩니다. [#15973](https://github.com/ClickHouse/ClickHouse/pull/15973) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Postgres와의 호환성을 위해 `INTERVAL '1 hour'`를 `INTERVAL 1 HOUR`와 동일하게 취급합니다. 이 변경으로 [#15637](https://github.com/ClickHouse/ClickHouse/issues/15637)도 수정됩니다. [#15978](https://github.com/ClickHouse/ClickHouse/pull/15978) ([flynn](https://github.com/ucasfl)).
* MergeTree 테이블 엔진 계열의 백그라운드 작업 처리 구현을 단순화합니다. 사용자에게 눈에 띄는 변경 사항은 없습니다. [#15983](https://github.com/ClickHouse/ClickHouse/pull/15983) ([alesapin](https://github.com/alesapin)).
* 복합 키를 사용하는 Redis 딕셔너리에 cache layout 지원을 추가합니다. [#15985](https://github.com/ClickHouse/ClickHouse/pull/15985) ([Anton Popov](https://github.com/CurtizJ)).
* 제안 로딩 때문에 종료 시 `clickhouse-client`가 중단될 수 있는 드문 문제를 수정합니다. 이 변경으로 [#16035](https://github.com/ClickHouse/ClickHouse/issues/16035)도 수정됩니다. [#16047](https://github.com/ClickHouse/ClickHouse/pull/16047) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이제 클러스터 구성의 `<internal_replication>` 설정과 관계없이 `ALTER ... ON CLUSTER` 쿼리를 실행할 수 있습니다. [#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)).
* * HTTP를 통한 쿼리의 memory&#95;profiler&#95;step/max&#95;untracked&#95;memory를 수정했습니다(테스트 포함). 또한 xml 구성에서 이 값을 전역으로 조정해도 소용이 없는데, 해당 설정은 실제로 적용되지 않고 기본값(4MB)만 [사용되기](https://github.com/ClickHouse/ClickHouse/blob/17731245336d8c84f75e4c0894c5797ed7732190/src/Common/ThreadStatus.h#L104) 때문입니다. - HTTP 쿼리의 최상위 ThreadStatus에 대한 query&#95;id를 수정했습니다(query&#95;id를 읽은 후 QueryScope를 초기화하도록 변경). [#16101](https://github.com/ClickHouse/ClickHouse/pull/16101) ([Azat Khuzhin](https://github.com/azat)).
* allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards를 추가했습니다(세그먼트 분할 키에서 `rand()` 또는 `dictGet()` 같은 비결정적 함수를 허용하기 위해). [#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).
* DROP DATABASE에 대해 database&#95;atomic&#95;wait&#95;for&#95;drop&#95;and&#95;detach&#95;synchronously/NO DELAY/SYNC를 추가했습니다. [#16127](https://github.com/ClickHouse/ClickHouse/pull/16127) ([Azat Khuzhin](https://github.com/azat)).
* 중첩 데이터 타입(Nested 데이터 타입)(예: named tuple)을 하위 타입으로 지원하도록 추가했습니다. [#15587](https://github.com/ClickHouse/ClickHouse/issues/15587)을 수정합니다. [#16262](https://github.com/ClickHouse/ClickHouse/pull/16262) ([Ivan](https://github.com/abyss7)).
* 시스템에 tmp 폴더가 없는 경우(chroot, 잘못된 구성 등) clickhouse-local이 현재 디렉터리에 임시 하위 폴더를 생성합니다. [#16280](https://github.com/ClickHouse/ClickHouse/pull/16280) ([filimonov](https://github.com/filimonov)).
