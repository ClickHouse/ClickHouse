<div id="improvement">
  #### 개선 사항
</div>

* [#51235](https://github.com/ClickHouse/ClickHouse/issues/51235)에 백포트됨: 소스 데이터의 청크 크기를 활용하고 각 스레드에서 증분 방식으로 전체 크기를 집계하여 file/s3/hdfs/url 테이블 함수의 진행률 표시줄을 개선합니다. *Cluster 함수의 진행률 표시줄 오류를 수정합니다. [#47250](https://github.com/ClickHouse/ClickHouse/issues/47250) 종료. [#51088](https://github.com/ClickHouse/ClickHouse/pull/51088) ([Kruglov Pavel](https://github.com/Avogar)).
* [#51255](https://github.com/ClickHouse/ClickHouse/issues/51255)에 백포트됨: 캐시 설정 `do_not_evict_index_and_mark_files`를 비활성화합니다(`23.5`에서 활성화되어 있었음). [#51222](https://github.com/ClickHouse/ClickHouse/pull/51222) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#51531](https://github.com/ClickHouse/ClickHouse/issues/51531)에 백포트됨: Dockerfile의 대형 `RUN` 명령을 더 작은 조건부 명령으로 분리합니다. 필요한 도구는 동일한 `RUN` 레이어에서 필요 시 설치하고 이후 제거합니다. OS 업그레이드는 초기에 한 번만 수행합니다. 서명된 리포지토리 검증에 최신 방식을 사용합니다. 구버전 Docker에서 발생하는 문제를 해결하기 위해 기본 이미지를 ubuntu:20.04로 다운그레이드합니다. golang 취약점 해결을 위해 golang 버전을 업그레이드합니다. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#51572](https://github.com/ClickHouse/ClickHouse/issues/51572)에 백포트됨: [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504)의 후속 작업으로, 리팩토링 과정에서 정리 작업이 누락되었습니다. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 쿼리 캐시: ColumnConst에서 ColumnVector<char8_t>로의 잘못된 캐스트 수정 시도 [#50704](https://github.com/ClickHouse/ClickHouse/pull/50704) ([Robert Schulze](https://github.com/rschu1ze)).
* 캐시 항목 내 LDAP 서버 파라미터 해시의 유형 오류 수정 [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* Parquet 포맷에서 예외를 발생시키는 대신 String으로부터 큰 정수를 파싱하는 폴백 처리 추가 [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* read-in-order가 활성화된 경우 PROJECTION을 적용하지 않도록 수정. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Azure blob storage 이터레이터의 경쟁 조건(race condition) 수정 [#50936](https://github.com/ClickHouse/ClickHouse/pull/50936) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 서브쿼리가 포함된 SELECT에서 쿼리 캐시가 제대로 동작하지 않는 문제 수정 [#51132](https://github.com/ClickHouse/ClickHouse/pull/51132) ([Robert Schulze](https://github.com/rschu1ze)).
* ActionsDAG에서 퍼저 실패 수정 [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
