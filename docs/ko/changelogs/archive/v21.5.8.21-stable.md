  ### ClickHouse 릴리스 v21.5.8.21-안정 FIXME(v21.5.7.9-안정 대비)

<div id="bug-fix">
  #### 오동작
</div>

* [#25849](https://github.com/ClickHouse/ClickHouse/issues/25849)에 백포트됨: `Date`에서 `DateTime`(또는 `DateTime64`)으로 `CAST`할 때 `DateTime` 타입의 시간대가 사용되지 않던 문제를 수정했습니다. 이 문제는 `Date`와 `DateTime` 사이의 비교에도 영향을 줄 수 있습니다. `Date`와 `DateTime`의 공통 타입을 추론할 때도 해당 시간대가 사용되지 않았습니다. 이로 인해 함수 `if`와 배열 구성 결과에 영향이 있었습니다. [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)을 해결합니다. [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25679](https://github.com/ClickHouse/ClickHouse/issues/25679)에 백포트됨: 난수 생성기 상태의 역직렬화 버그를 수정했습니다. 이 버그로 인해 `AggregateFunction(groupArraySample(N), T))`와 같은 일부 데이터 타입이 비결정적으로 동작할 수 있었습니다. [#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25556](https://github.com/ClickHouse/ClickHouse/issues/25556)에 백포트됨: 다른 집계 함수의 집계 함수 상태를 집계해 집계 함수 상태를 계산할 때 발생할 수 있는 잠재적 크래시를 수정했습니다(실제 사용 사례는 아닙니다). [#24523](https://github.com/ClickHouse/ClickHouse/issues/24523)을 참고하십시오. [#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25767](https://github.com/ClickHouse/ClickHouse/issues/25767)에 백포트됨: PREWHERE에서 non-uint8 타입을 사용할 때 발생하는 assertion 문제를 수정했으며, [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589)를 해결합니다. [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* [#25636](https://github.com/ClickHouse/ClickHouse/issues/25636)에 백포트됨: `WITH TOTALS` 및 `WITH FILL` 쿼리에서 잘못된 합계가 반환되던 문제를 수정했습니다. [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872)를 해결합니다. [#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* [#25653](https://github.com/ClickHouse/ClickHouse/issues/25653)에 백포트됨: 쿼리 없이 `EXPLAIN AST`를 실행할 때 발생하는 null pointer dereference를 수정했습니다. [#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25715](https://github.com/ClickHouse/ClickHouse/issues/25715)에 백포트됨: 드물게 소스 파티션이 비어 있으면 `REPLACE PARTITION`이 무시될 수 있던 문제를 수정했습니다. [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869)를 해결합니다. [#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25695](https://github.com/ClickHouse/ClickHouse/issues/25695)에 백포트됨: 데이터베이스 간에 `Distributed` 테이블을 이동할 때 발생하던 `No such file or directory` 오류를 수정했습니다. [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971)를 해결합니다. [#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25754](https://github.com/ClickHouse/ClickHouse/issues/25754)에 백포트됨: cluster 구성을 다시 로드하는 동시에 `system.clusters`를 쿼리할 때 발생하는 data race를 수정했습니다. [#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)).
