<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)
</div>

* [#31204](https://github.com/ClickHouse/ClickHouse/issues/31204)에서 백포트됨: hdfs URL 구조에 대한 추가 검사를 도입하여, 잘못된 hdfs URL로 인해 debug server에서 발생하던 abort와 release server에서 발생하던 `DB::Exception: std::out_of_range: basic_string` 오류를 수정했습니다. [#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31253](https://github.com/ClickHouse/ClickHouse/issues/31253)에서 백포트됨: 일부 coordination 로그가 손실되고 최신 로그보다 더 새로운 snapshot이 있는 경우 시작하지 못할 수 있던 Keeper의 버그를 수정했습니다. [#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)).
* [#31521](https://github.com/ClickHouse/ClickHouse/issues/31521)에서 백포트됨: `not like` 함수를 RPNElement로 옮겼습니다. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* [#31552](https://github.com/ClickHouse/ClickHouse/issues/31552)에서 백포트됨: S3용 STS 자격 증명 provider에서 발생하던 `nullptr` 문제를 해결했습니다. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#31582](https://github.com/ClickHouse/ClickHouse/issues/31582)에서 백포트됨: * 이 최적화의 버그가 수정될 때까지 `partial_merge_join_left_table_buffer_bytes`를 비활성화했습니다. [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)를 참조하십시오. * 중복된 옵션 `partial_merge_join_optimizations`를 제거했습니다. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* [#31599](https://github.com/ClickHouse/ClickHouse/issues/31599)에서 백포트됨: 컬럼 이름에만 잘못된 UTF-8 시퀀스가 포함된 경우 생성되던 잘못된 JSON을 수정했습니다. [#31534](https://github.com/ClickHouse/ClickHouse/pull/31534) ([Kevin Michel](https://github.com/kmichel-aiven)).
* [#31779](https://github.com/ClickHouse/ClickHouse/issues/31779)에서 백포트됨: `Ordinary` 데이터베이스에서 DDL 딕셔너리의 이름을 변경하려고 할 때 `RENAME TABLE` 쿼리가 잘못 동작하던 문제를 수정했습니다. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31790](https://github.com/ClickHouse/ClickHouse/issues/31790)에서 백포트됨: `IPv4`와 같은 도메인 타입을 parsing할 때 설정 `input_format_allow_errors_num` 및 `input_format_allow_errors_ratio`가 동작하지 않던 문제를 수정했습니다. [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686)를 수정합니다. [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31829](https://github.com/ClickHouse/ClickHouse/issues/31829)에서 백포트됨: 지정된 cluster 이름이 `Replicated` 데이터베이스 이름인 경우 `ON CLUSTER` 쿼리 실행 시 발생하던 `there are no such cluster here` 오류를 수정했습니다. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31813](https://github.com/ClickHouse/ClickHouse/issues/31813)에서 백포트됨: 출력에서 데이터와 progress 행이 섞일 때 JSONEachRowWithProgress 출력 형식에서 발생하던 race를 수정했습니다. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31761](https://github.com/ClickHouse/ClickHouse/issues/31761)에서 백포트됨: `Map` 타입에서 `Buffer` 테이블 엔진을 사용할 때의 문제를 수정했습니다. [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546)를 수정합니다. [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* [#31890](https://github.com/ClickHouse/ClickHouse/issues/31890)에 백포트됨: TSKV 포맷에서 발생할 수 있는 assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` 문제를 수정했습니다. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31910](https://github.com/ClickHouse/ClickHouse/issues/31910)에 백포트됨: `UUID` 유형의 인수를 받는 함수 `empty` 및 `notEmpty`를 수정했습니다. [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819) 문제를 해결했습니다. [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
