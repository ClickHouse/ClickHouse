<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 메타데이터 캐시 기능은 더 이상 권장되지 않습니다. 이 기능은 실험적 기능이며, 지금까지 한 번도 사용된 적이 없습니다. 또한 위험합니다: [#51182](https://github.com/ClickHouse/ClickHouse/issues/51182). `system.merge_tree_metadata_cache` 시스템 테이블을 제거합니다. 메타데이터 캐시는 이 버전에서 아직 사용할 수 있지만 곧 제거될 예정입니다. 이 변경으로 [#39197](https://github.com/ClickHouse/ClickHouse/issues/39197)가 종료됩니다. [#51303](https://github.com/ClickHouse/ClickHouse/pull/51303) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 동적 디스크에 이름이 있는 경우, 디스크 함수 인수에서 `disk = disk(name = 'disk_name'`, ...) 형태로 지정해야 합니다. 이전 버전에서는 `disk = disk_<disk_name>(...)` 형태로 지정할 수 있었지만, 이제는 더 이상 지원되지 않습니다. [#52820](https://github.com/ClickHouse/ClickHouse/pull/52820) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `clickhouse-benchmark`는 `--concurrency`를 1보다 크게 지정해 실행하면 연결을 병렬로 설정합니다. 이전에는 유럽에서 미국으로 1000개의 동시 연결로 실행할 경우 사실상 사용할 수 없었습니다. 또한 지연 시간이 높은 연결에 대한 QPS 계산을 바로잡았습니다. 하위 호환되지 않는 변경 사항: `clickhouse-benchmark`의 JSON 출력 옵션이 제거되었습니다. 이 옵션을 사용해 왔다면, 우회 방법으로 `system.query_log`에서 JSON 포맷으로 데이터를 추출할 수도 있습니다. [#53293](https://github.com/ClickHouse/ClickHouse/pull/53293) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `event_time_microseconds` 컬럼이 있어 중복되므로, `system.text_log`에서 `microseconds` 컬럼을 제거하고 `system.metric_log`에서 `milliseconds` 컬럼을 제거했습니다. [#53601](https://github.com/ClickHouse/ClickHouse/pull/53601) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 스토리지 `S3Queue` 메타데이터의 ZooKeeper 경로를 변경했습니다. [#54137](https://github.com/ClickHouse/ClickHouse/pull/54137) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* AArch64, PowerPC, SystemZ, RISCV에 대해 JIT 컴파일을 활성화합니다. [#38217](https://github.com/ClickHouse/ClickHouse/pull/38217) ([Maksim Kita](https://github.com/kitaisreal)).
* 이 패치는 머지 전에 모든 hashset을 병렬로 처리하는 메서드를 제공합니다. [#50748](https://github.com/ClickHouse/ClickHouse/pull/50748) ([Jiebin Sun](https://github.com/jiebinn)).
* aggregationmethodserialized를 사용할 때 널 허용 String 키의 집계 성능을 최적화합니다. [#51399](https://github.com/ClickHouse/ClickHouse/pull/51399) ([LiuNeng](https://github.com/liuneng1994)).
* ICX 장치(Intel Xeon Platinum 8380 CPU, 80코어, 160스레드)에서 수행한 **SSB** 성능 실험에 따르면, 실험적 분석기가 활성화된 경우 이 변경으로 **기하평균 QPS**가 **8.5%** 개선될 수 있습니다. 자세한 내용은 아래와 같습니다: ![image](https://github.com/ClickHouse/ClickHouse/assets/26588299/4e58bf8b-d276-408d-ad45-38c82d3cb918). [#52091](https://github.com/ClickHouse/ClickHouse/pull/52091) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* Parquet 필터 pushdown. 즉, Parquet 파일을 읽을 때 WHERE 조건과 각 컬럼의 최소/최대값을 기반으로 row group(파일의 청크)을 건너뜁니다. 특히 파일이 특정 컬럼 기준으로 대체로 정렬되어 있다면, 해당 컬럼의 짧은 범위로 필터링하는 쿼리가 훨씬 더 빨라집니다. [#52951](https://github.com/ClickHouse/ClickHouse/pull/52951) ([Michael Kolupaev](https://github.com/al13n321)).
* UniqExactSet에서 모든 hashSet이 singleLevel인 경우 머지를 최적화합니다. [#52973](https://github.com/ClickHouse/ClickHouse/pull/52973) ([Jiebin Sun](https://github.com/jiebinn)).
* StorageJoin: 모든 컬럼을 포함한 clone 해시 조인을 생성하지 않습니다. [#53046](https://github.com/ClickHouse/ClickHouse/pull/53046) ([Duc Canh Le](https://github.com/canhld94)).
* Parquet에서 작은 row group을 함께 배칭해 읽기를 최적화합니다. [#53069](https://github.com/ClickHouse/ClickHouse/issues/53069)을 해결합니다. [#53281](https://github.com/ClickHouse/ClickHouse/pull/53281) ([Kruglov Pavel](https://github.com/Avogar)).
* 성능 향상을 위해 Arrow 없이 네이티브 ORC 입력 형식을 구현합니다. [#53324](https://github.com/ClickHouse/ClickHouse/pull/53324) ([李扬](https://github.com/taiyang-li)).
* 대시보드가 서버에 데이터 압축을 요청하도록 하며, 이는 느린 인터넷 연결에서 넓은 시간 범위를 다룰 때 유용합니다. 예를 들어 86400개의 포인트가 있는 차트 하나는 압축하지 않으면 1.5 MB이고, `br`로 압축하면 60 KB가 될 수 있습니다. [#53569](https://github.com/ClickHouse/ClickHouse/pull/53569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 대부분의 입력 형식에서 파일 대상 count를 최적화합니다. [#44334](https://github.com/ClickHouse/ClickHouse/issues/44334)을 해결합니다. [#53637](https://github.com/ClickHouse/ClickHouse/pull/53637) ([Kruglov Pavel](https://github.com/Avogar)).
* BACKUP 및 RESTORE에 대한 스레드 풀 활용을 개선합니다. [#53649](https://github.com/ClickHouse/ClickHouse/pull/53649) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 클라이언트 성능 check에서 불필요한 지연 요소를 제거합니다. [#53695](https://github.com/ClickHouse/ClickHouse/pull/53695) ([Raúl Marín](https://github.com/Algunenano)).
