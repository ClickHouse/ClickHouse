<div id="improvement">
  #### 개선 사항

* [#65463](https://github.com/ClickHouse/ClickHouse/issues/65463)에 백포트됨: 인증서를 다시 로드하는 동안 certificate chain도 함께 다시 로드합니다. [#61671](https://github.com/ClickHouse/ClickHouse/pull/61671) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* [#65882](https://github.com/ClickHouse/ClickHouse/issues/65882)에 백포트됨: Keeper가 시작될 때 Global Thread 풀에 항상 충분한 수의 스레드가 있도록 합니다. [#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94)).
* [#65302](https://github.com/ClickHouse/ClickHouse/issues/65302)에 백포트됨: CSV 형식에서 튜플을 처리하고 해석하는 ClickHouse의 동작을 이전 방식으로 되돌렸습니다. 이 변경은 사실상 [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994)를 되돌리는 것이며, `output_format_csv_serialize_tuple_into_separate_columns`, `input_format_csv_deserialize_separate_columns_into_tuple`, `input_format_csv_try_infer_strings_from_quoted_tuples`의 몇 가지 설정에서만 사용할 수 있습니다. [#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#65892](https://github.com/ClickHouse/ClickHouse/issues/65892)에 백포트됨: Keeper에서 cgroup CPU 제한을 준수하도록 했습니다. [#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)).

* [#65446](https://github.com/ClickHouse/ClickHouse/issues/65446)에 백포트됨: Distinct combinator에 올바른 메모리 정렬을 적용했습니다. 이전에는 combinator 사용 시 잘못된 메모리 할당으로 인해 크래시가 발생할 수 있었습니다. [#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)).
* [#65708](https://github.com/ClickHouse/ClickHouse/issues/65708)에 백포트됨: maxIntersections에서 발생하는 크래시를 수정했습니다. [#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#65352](https://github.com/ClickHouse/ClickHouse/issues/65352)에서 백포트: StatusFile의 ~WriteBufferFromFileDescriptor에서 uncaught exception 발생 시 abort가 발생할 수 있는 문제를 수정했습니다. [#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)).
* [#65327](https://github.com/ClickHouse/ClickHouse/issues/65327)에서 백포트: 아직 복원되지 않은 definer로 MV를 생성해 backup에서 복원하는 작업이 차단될 때 발생하는 크래시 루프를 수정했습니다. [#64595](https://github.com/ClickHouse/ClickHouse/pull/64595) ([pufit](https://github.com/pufit)).
* [#65538](https://github.com/ClickHouse/ClickHouse/issues/65538)에서 백포트: `ALTER TABLE ... ON CLUSTER ... MODIFY SQL SECURITY` 실행 시 발생하는 크래시를 수정했습니다. [#64957](https://github.com/ClickHouse/ClickHouse/pull/64957) ([pufit](https://github.com/pufit)).
* [#65576](https://github.com/ClickHouse/ClickHouse/issues/65576)에서 백포트: AccessControl 종료 중 발생하는 크래시를 수정하고 명시적 shutdown을 추가했습니다. [#64993](https://github.com/ClickHouse/ClickHouse/pull/64993) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#65159](https://github.com/ClickHouse/ClickHouse/issues/65159)에서 백포트: 산술 연산을 집계 밖으로 밀어내는 최적화를 수정했습니다. 새 분석기에서는 이 최적화가 한 번만 적용되었습니다. [#65104](https://github.com/ClickHouse/ClickHouse/pull/65104) ([Dmitry Novik](https://github.com/novikd)).
* [#65615](https://github.com/ClickHouse/ClickHouse/issues/65615)에서 백포트: 새 분석기에서 집계 함수 이름을 재작성하는 과정의 문제를 수정했습니다. [#65110](https://github.com/ClickHouse/ClickHouse/pull/65110) ([Dmitry Novik](https://github.com/novikd)).
* [#65728](https://github.com/ClickHouse/ClickHouse/issues/65728)에서 백포트: `uniq*` 함수의 인수에서 injective 함수를 재귀적으로 제거하도록 수정했습니다. 이전에는 올바르게 동작했지만 새 분석기에서 깨졌습니다. [#65140](https://github.com/ClickHouse/ClickHouse/pull/65140) ([Duc Canh Le](https://github.com/canhld94)).
* [#65261](https://github.com/ClickHouse/ClickHouse/issues/65261)에서 백포트: Hashed 및 Hashed&#95;Array 딕셔너리의 단락 평가(short-circuit evaluation) 버그를 수정했습니다. 이 문제로 초기화되지 않은 숫자를 읽어 다양한 오류가 발생할 수 있었습니다. [#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)).
* [#65667](https://github.com/ClickHouse/ClickHouse/issues/65667)에서 백포트: `read-in-order` 최적화가 활성화된 경우 `FINAL`이 포함된 쿼리에서 `non-intersecting-parts` 최적화를 비활성화했습니다. 이로 인해 잘못된 쿼리 결과가 발생할 수 있었습니다. 임시 해결책으로, 이 수정이 머지되기 전에는 `do_not_merge_across_partitions_select_final` 및 `split_parts_ranges_into_intersecting_and_non_intersecting_final`을 비활성화하십시오. [#65505](https://github.com/ClickHouse/ClickHouse/pull/65505) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65784](https://github.com/ClickHouse/ClickHouse/issues/65784)에서 백포트: MergeJoin의 버그를 수정했습니다. 희소 직렬화의 컬럼이 필요한 변환이 수행되지 않았는데도 해당 Nested 유형의 컬럼으로 처리될 수 있었습니다. [#65632](https://github.com/ClickHouse/ClickHouse/pull/65632) ([Nikita Taranov](https://github.com/nickitat)).
* [#65929](https://github.com/ClickHouse/ClickHouse/issues/65929)에서 백포트: `PostgreSQL`에서 읽는 쿼리의 경우 ClickHouse 쿼리가 종료되면 내부 `PostgreSQL` 쿼리도 취소하도록 수정했습니다. 그렇지 않으면 내부 `PostgreSQL` 쿼리가 끝날 때까지 ClickHouse 쿼리를 취소할 수 없었습니다. [#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)).
* [#65824](https://github.com/ClickHouse/ClickHouse/issues/65824)에서 백포트: 이전 분석기와 `dictGetOrDefault`를 사용할 때 단락 평가 로직의 버그를 수정했습니다. [#65802](https://github.com/ClickHouse/ClickHouse/pull/65802) ([jsc0218](https://github.com/jsc0218)).
