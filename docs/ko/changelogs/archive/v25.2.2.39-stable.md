  ### ClickHouse 릴리스 v25.2.2.39-안정 (a1200cff50a) FIXME, v25.2.1.3085-안정 (09989205d6f)와 비교

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#77183](https://github.com/ClickHouse/ClickHouse/issues/77183)에서 백포트됨: `compatibility` 설정과 관계없이 분석기가 비활성화된 경우 기본적으로 병렬 레플리카가 비활성화됩니다. `parallel_replicas_only_with_analyzer`를 명시적으로 `false`로 설정하면 이 동작은 여전히 변경할 수 있습니다. [#77115](https://github.com/ClickHouse/ClickHouse/pull/77115) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="new-feature">
  #### 새 기능
</div>

* [#77358](https://github.com/ClickHouse/ClickHouse/issues/77358)에서 백포트됨: 동시 실행되는 쿼리 간에 CPU 슬롯이 분배되는 방식을 제어하는 `concurrent_threads_scheduler` 서버 설정이 추가되었습니다. `round_robin`(이전 동작) 또는 `fair_round_robin`으로 설정할 수 있으며, INSERT와 SELECT 사이의 CPU 분배가 불공정한 문제를 해결합니다. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#76999](https://github.com/ClickHouse/ClickHouse/issues/76999)에 백포트됨: async insert를 활성화한 상태에서 block 크기가 서로 다른 `insert into ... from file ...`를 사용할 때 발생하던 데이터 손실을 수정했습니다. 첫 번째 block 크기가 `async_max_size`보다 작고 두 번째 block이 `async_max_size`보다 크면, 두 번째 block이 삽입되지 않고 해당 데이터가 `squashing`에 남아 있었습니다. [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* [#76970](https://github.com/ClickHouse/ClickHouse/issues/76970)에 백포트됨: 분산 테이블에서 불리언 리터럴을 선택할 때 발생하는 THERE&#95;IS&#95;NO&#95;COLUMN 예외를 수정했습니다. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

* [#77260](https://github.com/ClickHouse/ClickHouse/issues/77260)에 백포트됨: async inserts 중 오류 발생 시 JSON 컬럼이 잘못 롤백되어 발생할 수 있는 크래시를 수정했습니다. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77064](https://github.com/ClickHouse/ClickHouse/issues/77064)에 백포트됨: `BFloat16` 값 정렬 문제를 수정했습니다. 이 변경으로 [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487)이 해결되었습니다. 또한 [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669)도 해결되었습니다. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
