<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 설정 `print_pretty_type_names`가 기본적으로 활성화됩니다. 이전 동작을 유지하려면 이 설정을 끄거나 `SET compatibility = '23.12'`를 설정할 수 있습니다. [#57726](https://github.com/ClickHouse/ClickHouse/pull/57726) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree 설정 `clean_deleted_rows`는 더 이상 효과가 없으며, 사용 중단(Deprecated)되었습니다. `OPTIMIZE`의 `CLEANUP` 키워드는 기본적으로 허용되지 않습니다(`allow_experimental_replacing_merge_with_cleanup`가 활성화된 경우는 예외). [#58316](https://github.com/ClickHouse/ClickHouse/pull/58316) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 함수 `reverseDNSQuery`는 더 이상 사용할 수 없습니다. 이로써 [#58368](https://github.com/ClickHouse/ClickHouse/issues/58368)이 해결되었습니다. [#58369](https://github.com/ClickHouse/ClickHouse/pull/58369) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 설정 파일의 access control을 개선하기 위한 여러 변경 사항이 활성화됩니다. 이러한 변경 사항은 동작에 영향을 미치므로 `config.xml`의 `access_control_improvements` 섹션을 확인하십시오. 확신이 없다면 설정 파일의 값은 이전 버전과 동일하게 유지하십시오. [#58584](https://github.com/ClickHouse/ClickHouse/pull/58584) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `PASTE JOIN`에서 서브쿼리에 별칭 없이도 쿼리를 허용합니다. [#58654](https://github.com/ClickHouse/ClickHouse/pull/58654) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* NaN 값이 있는 `sumMapFiltered`를 수정했습니다. 이제 NaN 값은 무작위가 아니라 끝에 배치되며, 다른 어떤 값과도 다른 것으로 간주됩니다. 또한 `-0`은 `0`과 같은 값으로 처리됩니다. 0 값은 버려지므로 `-0` 값도 함께 버려집니다. [#58959](https://github.com/ClickHouse/ClickHouse/pull/58959) ([Raúl Marín](https://github.com/Algunenano)).
* 함수 `visibleWidth`는 문서에 설명된 대로 동작합니다. 이전 버전에서는 `lengthUTF8` 함수처럼 문자열 serialization 이후 code point 수만 단순히 계산했으며, 너비가 0인 문자, 결합 문자, 전각 문자, 탭, 삭제 문자는 고려하지 않았습니다. 이제 이에 맞게 동작이 변경되었습니다. 이전 동작을 유지하려면 `function_visible_width_behavior`를 `0`으로 설정하거나 `compatibility`를 `23.12` 이하로 설정하십시오. [#59022](https://github.com/ClickHouse/ClickHouse/pull/59022) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 다음 두 버그가 수정될 때까지 Kusto 방언이 비활성화됩니다: [#59037](https://github.com/ClickHouse/ClickHouse/issues/59037) 및 [#59036](https://github.com/ClickHouse/ClickHouse/issues/59036). [#59305](https://github.com/ClickHouse/ClickHouse/pull/59305) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="new-feature">
  #### 새로운 기능
</div>

* 대상 테이블의 파티션 표현식이 파트를 재파티셔닝하거나 분할하지 않는 경우, 서로 다른 파티션 표현식을 가진 테이블의 파티션을 ATTACH할 수 있게 되었습니다. [#39507](https://github.com/ClickHouse/ClickHouse/pull/39507) ([Arthur Passos](https://github.com/arthurpassos)).
* 비동기 메트릭을 업데이트하는 `SYSTEM RELOAD ASYNCHRONOUS METRICS` 구문이 추가되었습니다. 주로 테스트 및 개발 환경에서 유용합니다. [#53710](https://github.com/ClickHouse/ClickHouse/pull/53710) ([Robert Schulze](https://github.com/rschu1ze)).
* 일부 설정(현재 `min_compress_block_size` 및 `max_compress_block_size`)을 컬럼 수준에서 지정할 수 있게 되었으며, 이 경우 테이블 수준 설정보다 우선 적용됩니다. 예시: `CREATE TABLE tab (col String SETTINGS (min_compress_block_size = 81920, max_compress_block_size = 163840)) ENGINE = MergeTree ORDER BY tuple();`. [#55201](https://github.com/ClickHouse/ClickHouse/pull/55201) ([Duc Canh Le](https://github.com/canhld94)).
* `quantileDDSketch` 집계 함수와 이에 대응하는 `quantilesDDSketch` 및 `medianDDSketch`가 추가되었습니다. DDSketch(https://www.vldb.org/pvldb/vol12/p2195-masson.pdf)를 기반으로 합니다. ### 사용자 대상 변경 사항 문서 항목. [#56342](https://github.com/ClickHouse/ClickHouse/pull/56342) ([Srikanth Chekuri](https://github.com/srikanthccv)).
* 시계열을 계절 성분, 추세 성분, 잔차 성분으로 분해하는 `seriesDecomposeSTL()` 함수가 추가되었습니다. [#57078](https://github.com/ClickHouse/ClickHouse/pull/57078) ([Bhavna Jindal](https://github.com/bhavnajindal)).
* MaterializedMySQL를 위한 MySQL Binlog 클라이언트가 도입되었습니다. 단일 binlog 연결로 여러 데이터베이스를 처리할 수 있습니다. [#57323](https://github.com/ClickHouse/ClickHouse/pull/57323) ([Val Doroshchuk](https://github.com/valbok)).
* Intel QuickAssist Technology (QAT)는 하드웨어 가속 압축 및 암호화를 제공합니다. ClickHouse에 QAT를 활용한 zstd 압축을 지원하는 새로운 압축 코덱 `ZSTD_QAT`가 추가되었습니다. 이 코덱은 [Intel의 QATlib](https://github.com/intel/qatlib)와 [Intel의 QAT ZSTD Plugin](https://github.com/intel/QAT-ZSTD-Plugin)을 사용합니다. 현재는 압축만 하드웨어 가속이 지원되며(QAT 초기화 실패 시 소프트웨어 폴백이 동작), 압축 해제는 항상 소프트웨어로 실행됩니다. [#57509](https://github.com/ClickHouse/ClickHouse/pull/57509) ([jasperzhu](https://github.com/jinjunzh)).
* S3 디스크의 오브젝트 스토리지 키 생성 방식이 새롭게 구현되었습니다. 이제 디스크 설명의 `key_template` 옵션에서 `re2` 정규식 문법으로 포맷을 정의할 수 있습니다. [#57663](https://github.com/ClickHouse/ClickHouse/pull/57663) ([Sema Checherinda](https://github.com/CheSema)).
* `system.dropped_tables_parts` 테이블에는 `system.dropped_tables`에 속한 파트(삭제되었으나 아직 제거되지 않은 테이블의 파트)가 포함됩니다. [#58038](https://github.com/ClickHouse/ClickHouse/pull/58038) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 여러 데이터 타입의 합집합을 나타내는 Variant 데이터 타입이 구현되었습니다. `Variant(T1, T2, ..., TN)` 타입은 각 행이 `T1`, `T2`, ..., `TN` 중 하나의 타입 값을 갖거나, 어느 타입도 아닌 경우(`NULL` 값)를 의미합니다. Variant 타입은 `allow_experimental_variant_type` 설정을 통해 사용할 수 있습니다. 참고: [#54864](https://github.com/ClickHouse/ClickHouse/issues/54864). [#58047](https://github.com/ClickHouse/ClickHouse/pull/58047) ([Kruglov Pavel](https://github.com/Avogar)).
* 테이블에 attached 상태인 materialized view의 수를 제한하는 `max_materialized_views_size_for_table` 설정이 추가되었습니다. [#58068](https://github.com/ClickHouse/ClickHouse/pull/58068) ([zhongyuankai](https://github.com/zhongyuankai)).
* `clickhouse-format` 개선 사항: * `VALUES`를 포함한 INSERT 쿼리 지원 * 주석 지원(`--comments` 옵션으로 출력) * 긴 쿼리만 여러 줄로 포맷하는 `--max_line_length` 옵션 지원. [#58246](https://github.com/ClickHouse/ClickHouse/pull/58246) ([vdimir](https://github.com/vdimir)).
* 비활성 레플리카 대기를 건너뛸 수 있는 `distributed_ddl_output_mode`의 `null_status_on_timeout_only_active` 및 `throw_only_active` 모드가 추가되었습니다. [#58350](https://github.com/ClickHouse/ClickHouse/pull/58350) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `system.database_engines` 테이블이 추가되었습니다. [#58390](https://github.com/ClickHouse/ClickHouse/pull/58390) ([Bharat Nallan](https://github.com/bharatnc)).
* SYSTEM SYNC REPLICA LIGHTWEIGHT 쿼리에 FROM <Replicas> 수정자가 추가되었습니다. FROM 수정자를 사용하면 지정된 소스 레플리카, 그리고 ZooKeeper에 등록되지 않았거나 `source_replica`가 비어 있는 레플리카에 대해서만 페치 및 드롭 범위 완료를 기다립니다. [#58393](https://github.com/ClickHouse/ClickHouse/pull/58393) ([Jayme Bird](https://github.com/jaymebrd)).
* 하위 배열을 계산하는 `arrayShingles()` 함수가 추가되었습니다. 예: `arrayShingles([1, 2, 3, 4, 5], 3)`은 `[[1,2,3],[2,3,4],[3,4,5]]`를 반환합니다. [#58396](https://github.com/ClickHouse/ClickHouse/pull/58396) ([Zheng Miao](https://github.com/zenmiao7)).
* IDNA 표준에 따라 국제 도메인 이름을 ASCII 표현으로 변환하는 데 유용한 `punycodeEncode()`, `punycodeDecode()`, `idnaEncode()`, `idnaDecode()` 함수가 추가되었습니다. [#58454](https://github.com/ClickHouse/ClickHouse/pull/58454) ([Robert Schulze](https://github.com/rschu1ze)).
* 문자열 유사도 함수 `dramerauLevenshteinDistance()`, `jaroSimilarity()`, `jaroWinklerSimilarity()`가 추가되었습니다. [#58531](https://github.com/ClickHouse/ClickHouse/pull/58531) ([Robert Schulze](https://github.com/rschu1ze)).
* 출력 압축 수준을 변경하는 `output_format_compression_level` 설정과, 출력 압축 방식이 `zstd`인 경우 압축 윈도우 크기를 명시적으로 지정하고 장거리 모드를 활성화하는 `output_format_compression_zstd_window_log` 설정이 추가되었습니다. `INTO OUTFILE` 및 `file`, `url`, `hdfs`, `s3`, `azureBlobStorage` 테이블 함수에 쓰기 시 적용됩니다. [#58539](https://github.com/ClickHouse/ClickHouse/pull/58539) ([Duc Canh Le](https://github.com/canhld94)).
* 출력 대상이 터미널이 아닌 경우 Pretty 포맷에서 ANSI escape sequences를 자동으로 비활성화합니다. `output_format_pretty_color` 설정에 새로운 `auto` 모드가 추가되었습니다. [#58614](https://github.com/ClickHouse/ClickHouse/pull/58614) ([Shaun Struwig](https://github.com/Blargian)).
* `update_insert_deduplication_token_in_dependent_materialized_views` 설정이 추가되었습니다. 이 설정을 활성화하면 종속 materialized view에 데이터를 삽입할 때 테이블 식별자를 기반으로 삽입 중복 제거 토큰을 업데이트합니다. [#59165](https://github.com/ClickHouse/ClickHouse/issues/59165) 해결. [#59238](https://github.com/ClickHouse/ClickHouse/pull/59238) ([Maksim Kita](https://github.com/kitaisreal)).





<div id="performance-improvement">
  #### 성능 개선
</div>

* 캐시 친화성을 높인 final 구현입니다. 동작 변경에 대한 참고: 이전에는 단일 스트림으로 읽는 `FINAL` 수정자가 있는 쿼리(예: `max_threads=1`)가 `ORDER BY` 절을 명시하지 않아도 정렬된 출력을 생성했습니다. 이 동작은 `enable_vertical_final = true`일 때 더 이상 적용되지 않으며, 이 설정이 기본값입니다. [#54366](https://github.com/ClickHouse/ClickHouse/pull/54366) ([Duc Canh Le](https://github.com/canhld94)).
* 입력이 array(map)/array(array(num)/array(array(string))/array(bigint)/array(decimal)인 경우 배열 요소 함수를 최적화했습니다. 기존 구현에서는 재할당이 지나치게 많이 발생했습니다. 이 최적화로 속도가 약 6배 향상되며, 특히 입력 타입이 array(map)일 때 효과가 큽니다. [#56403](https://github.com/ClickHouse/ClickHouse/pull/56403) ([李扬](https://github.com/taiyang-li)).
* 불필요한 데이터 추가 복사를 피하기 위해 S3에서 읽을 때 `Poco::BasicBufferedStreamBuf` 추상화, 즉 `ReadBufferFromIStream`을 우회하도록 했습니다. [#56961](https://github.com/ClickHouse/ClickHouse/pull/56961) ([Nikita Taranov](https://github.com/nickitat)).
* Compact 파트에서 하나의 컬럼에서 둘 이상의 subcolumn을 읽을 때 해당 컬럼을 한 번만 읽도록 했습니다. [#57631](https://github.com/ClickHouse/ClickHouse/pull/57631) ([Kruglov Pavel](https://github.com/Avogar)).
* sum(column + literal) 함수의 AST를 재작성했습니다. [#57853](https://github.com/ClickHouse/ClickHouse/pull/57853) ([Jiebin Sun](https://github.com/jiebinn)).
* 이제 `match()` 함수 평가에서 스킵 인덱스 `ngrambf_v1` 및 `tokenbf_v1`를 활용합니다. [#57882](https://github.com/ClickHouse/ClickHouse/pull/57882) ([凌涛](https://github.com/lingtaolf)).
* 병렬 레플리카의 기본 coordinator를 더 나은 cache locality를 위해 재작성했습니다(동일한 마크 범위는 거의 항상 동일한 레플리카에 할당됨). work stealing 중에도 consistent hashing을 사용하므로 더 나은 테일 지연 시간이 기대됩니다. 100개의 레플리카에서 선형 확장성이 확인되었습니다. [#57968](https://github.com/ClickHouse/ClickHouse/pull/57968) ([Nikita Taranov](https://github.com/nickitat)).
* MergeTree FINAL에서 동일한 non-L0 파트의 행끼리는 비교하지 않도록 했습니다. [#58142](https://github.com/ClickHouse/ClickHouse/pull/58142) ([Duc Canh Le](https://github.com/canhld94)).
* iota 호출(배열을 연속된 숫자로 채우는 작업)을 더 빠르게 했습니다. [#58271](https://github.com/ClickHouse/ClickHouse/pull/58271) ([Raúl Marín](https://github.com/Algunenano)).
* 이제 `match()` 함수 평가에서 역색인(inverted indices)을 활용합니다. [#58284](https://github.com/ClickHouse/ClickHouse/pull/58284) ([凌涛](https://github.com/lingtaolf)).
* 숫자형이 아닌 타입의 MIN/MAX를 더 빠르게 했습니다. [#58334](https://github.com/ClickHouse/ClickHouse/pull/58334) ([Raúl Marín](https://github.com/Algunenano)).
* 키 없는 집계에 JIT 컴파일을 활성화했습니다. [#41461](https://github.com/ClickHouse/ClickHouse/issues/41461)을 해결합니다. 원래 이슈는 [#53757](https://github.com/ClickHouse/ClickHouse/issues/53757)입니다. [#58440](https://github.com/ClickHouse/ClickHouse/pull/58440) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* AVX2(및 BMI2)까지 지원하는 Intel server에서 수행한 **OnTime** 성능 실험 결과, 이 변경은 핫스팟인 ***DB::MergeTreeRangeReader::ReadResult::optimize***&#xC758; 사이클 비율을 각각 **11.48%에서 1.09%로**, **8.09%에서 0.67%로** 낮춤으로써, 다른 항목에는 영향을 주지 않으면서 **Q2**와 **Q3**의 QPS를 각각 **5.0%**, **3.7%** 향상시킬 수 있음을 보여줍니다. [#58800](https://github.com/ClickHouse/ClickHouse/pull/58800) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* `clickhouse-local`에서 스레드를 하나 덜 사용하도록 했습니다. [#58968](https://github.com/ClickHouse/ClickHouse/pull/58968) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 분산 쿼리에서 대규모 `uniqExact` 집계 상태를 병렬로 머지합니다. [#59009](https://github.com/ClickHouse/ClickHouse/pull/59009) ([Nikita Taranov](https://github.com/nickitat)).
* `MergeTree` 테이블을 읽을 때 메모리 사용량이 감소합니다. [#59290](https://github.com/ClickHouse/ClickHouse/pull/59290) ([Anton Popov](https://github.com/CurtizJ)).
* 수직 병합 시 메모리 사용량이 감소합니다. [#59340](https://github.com/ClickHouse/ClickHouse/pull/59340) ([Anton Popov](https://github.com/CurtizJ)).





<div id="improvement">
  #### 개선 사항
</div>

* macOS에서 MySQL/MariaDB를 활성화합니다. 이는 [#21191](https://github.com/ClickHouse/ClickHouse/issues/21191)을 해결합니다. [#46316](https://github.com/ClickHouse/ClickHouse/pull/46316) ([Robert Schulze](https://github.com/rschu1ze)).
* 앞에 0이 붙은 숫자를 8진수로 해석하지 않도록 합니다. [#55575](https://github.com/ClickHouse/ClickHouse/pull/55575) ([Joanna Hulboj](https://github.com/jh0x)).
* std ostream 기반 HTTP 출력 버퍼링을 CH Buffer로 대체합니다. 인터페이스에 대한 바이트 집계 메트릭도 추가합니다. [#56064](https://github.com/ClickHouse/ClickHouse/pull/56064) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
