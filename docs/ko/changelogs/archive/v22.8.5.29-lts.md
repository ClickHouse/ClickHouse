<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 보이는 오동작)
</div>

* [#40866](https://github.com/ClickHouse/ClickHouse/issues/40866)에 백포트됨: 가변 차원 배열을 포함하는 `Object` 유형 값을 파싱하는 중 발생하는 크래시를 수정했습니다. [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* [#40805](https://github.com/ClickHouse/ClickHouse/issues/40805)에 백포트됨: 새 쿼리를 `ProcessList`에 삽입할 때 메모리 할당이 발생합니다. 이 할당 과정에서 메모리 제한에 도달하면 `ProcessList::mutex`를 이미 획득한 상태이므로 `OvercommitTracker`를 사용할 수 없습니다. [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)을 해결합니다. [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* [#40777](https://github.com/ClickHouse/ClickHouse/issues/40777)에 백포트됨: 쿼리 Context 없이(Kafka/...에서) MV로 푸시할 때 발생하는 메모리 누수를 수정했습니다. [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* [#41135](https://github.com/ClickHouse/ClickHouse/issues/41135)에 백포트됨: `DESCRIBE TABLE url()` 및 일부 다른 `DESCRIBE TABLE <table_function>()`의 접근 권한을 수정했습니다. [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#41242](https://github.com/ClickHouse/ClickHouse/issues/41242)에 백포트됨: 데이터베이스 엔진을 Ordinary에서 Atomic으로 자동 변환하는 과정에서 발생하던 &quot;possible deadlock avoided&quot; 오류를 수정했습니다. [#41146](https://github.com/ClickHouse/ClickHouse/pull/41146) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#41234](https://github.com/ClickHouse/ClickHouse/issues/41234)에 백포트됨: 손상된 분리된 파트의 백그라운드 정리 작업을 수정했습니다. [#41190](https://github.com/ClickHouse/ClickHouse/pull/41190) ([Kseniia Sumarokova](https://github.com/kssenii)).
