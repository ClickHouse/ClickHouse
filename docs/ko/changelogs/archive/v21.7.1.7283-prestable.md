<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 명시적으로 정의된 대규모 Set을 사용하는 쿼리의 성능을 개선했습니다. 호환성 설정 `legacy_column_name_of_tuple_literal`를 추가했습니다. 21.7 미만 버전의 클러스터를 그보다 높은 버전으로 롤링 업데이트하는 동안에는 이 값을 `true`로 설정하는 것이 좋습니다. 그렇지 않으면 업데이트 중 `IN` 절에서 명시적으로 정의된 Set이 포함된 분산 쿼리가 실패할 수 있습니다. [#25371](https://github.com/ClickHouse/ClickHouse/pull/25371) ([Anton Popov](https://github.com/CurtizJ)).
* clickhouse-keeper의 최대 buffer 크기에 상·하위 호환되지 않는 변경이 있습니다. 나중에 적용하는 것보다 지금, 즉 production 전에 적용하는 편이 더 낫습니다. [#25421](https://github.com/ClickHouse/ClickHouse/pull/25421) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### 새 기능
</div>

* HDFS 기반 VFS 지원을 추가했습니다. [#11058](https://github.com/ClickHouse/ClickHouse/pull/11058) ([overshov](https://github.com/overshov)).
* 데이터는 (아마도) 남아 있지만 ZooKeeper 메타데이터가 손실된 경우 복제된 테이블(Replicated Table)을 복원하는 방법을 제공합니다. [#13458](https://github.com/ClickHouse/ClickHouse/issues/13458)을 해결합니다. [#13652](https://github.com/ClickHouse/ClickHouse/pull/13652) ([Mike Kot](https://github.com/myrrc)).
* `flow analysis`에 유용한 `sequenceNextNode()` 함수를 구현했습니다. [#19766](https://github.com/ClickHouse/ClickHouse/pull/19766) ([achimbab](https://github.com/achimbab)).
* 구성 로더에 YAML 구성 지원을 추가했습니다. 이 변경으로 [#3607](https://github.com/ClickHouse/ClickHouse/issues/3607)이 해결되었습니다. [#21858](https://github.com/ClickHouse/ClickHouse/pull/21858) ([BoloniniD](https://github.com/BoloniniD)).
* `dateName` 함수를 추가했습니다. [#23085](https://github.com/ClickHouse/ClickHouse/pull/23085) ([Daniil Kondratyev](https://github.com/dankondr)).
* `quantileBFloat16` 집계 함수와 해당 `quantilesBFloat16`, `medianBFloat16`을 추가했습니다. 상대 오차가 0.390625%를 넘지 않는 매우 단순하고 빠른 분위수 추정기입니다. 이 변경으로 [#16641](https://github.com/ClickHouse/ClickHouse/issues/16641)이 해결되었습니다. [#23204](https://github.com/ClickHouse/ClickHouse/pull/23204) ([Ivan Novitskiy](https://github.com/RedClusive)).
* `Join` 테이블 엔진에서 `ALTER DELETE` 쿼리를 지원합니다. [#23260](https://github.com/ClickHouse/ClickHouse/pull/23260) ([foolchi](https://github.com/foolchi)).
* 모든 IN/JOIN을 기본적으로 GLOBAL IN/JOIN으로 처리하는 새로운 boolean 설정 `prefer_global_in_and_join`을 추가했습니다. [#23434](https://github.com/ClickHouse/ClickHouse/pull/23434) ([Amos Bird](https://github.com/amosbird)).
* `bitpositionToArray` 함수를 추가했습니다. [#23843](https://github.com/ClickHouse/ClickHouse/pull/23843) ([kevin wan](https://github.com/MaxWk)).
* 집계 함수 `segmentLengthSum`을 추가했습니다. [#24250](https://github.com/ClickHouse/ClickHouse/pull/24250) ([flynn](https://github.com/ucasfl)).
* Arrow/Parquet/ORC에서 struct와 맵을, Arrow 입력/출력 포맷에서 딕셔너리를 지원합니다. 새로운 설정 `output_format_arrow_low_cardinality_as_dictionary`도 도입했습니다. [#24341](https://github.com/ClickHouse/ClickHouse/pull/24341) ([Kruglov Pavel](https://github.com/Avogar)).
* AARCH64에서 `compile_expression` 설정을 지원합니다. [#24342](https://github.com/ClickHouse/ClickHouse/pull/24342) ([Maksim Kita](https://github.com/kitaisreal)).
* 이제 clickhouse-keeper가 ZooKeeper와 유사한 `digest` ACL을 지원합니다. [#24448](https://github.com/ClickHouse/ClickHouse/pull/24448) ([alesapin](https://github.com/alesapin)).
* `h3ToGeo` 함수를 구현했습니다. [#24867](https://github.com/ClickHouse/ClickHouse/pull/24867) ([Bharat Nallan](https://github.com/bharatnc)).
* 이제 query&#95;log에 분산 쿼리가 있는 경우 해당 시작 시간을 기록하는 두 개의 새로운 컬럼 initial&#95;query&#95;start&#95;time / initial&#95;query&#95;start&#95;time&#95;microsecond가 추가되었습니다. [#25022](https://github.com/ClickHouse/ClickHouse/pull/25022) ([Amos Bird](https://github.com/amosbird)).
* Dictionaries에 배열(Array) 유형 지원이 추가되었습니다. [#25119](https://github.com/ClickHouse/ClickHouse/pull/25119) ([Maksim Kita](https://github.com/kitaisreal)).
* 컬럼을 JSON 표현으로 직렬화할 수 있도록 `toJSONString` 함수를 추가했습니다. [#25164](https://github.com/ClickHouse/ClickHouse/pull/25164) ([Amos Bird](https://github.com/amosbird)).
* MaterializeMySQL로 생성된 ClickHouse 데이터베이스에 이제 구체화된 MySQL 데이터베이스의 모든 컬럼 주석이 포함됩니다. [#25199](https://github.com/ClickHouse/ClickHouse/pull/25199) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* `dateName` 함수를 추가했습니다. 작성자: [Daniil Kondratyev] (@dankondr). [#25372](https://github.com/ClickHouse/ClickHouse/pull/25372) ([Maksim Kita](https://github.com/kitaisreal)).
* `bitPositionsToArray` 함수를 추가했습니다. [#23792](https://github.com/ClickHouse/ClickHouse/issues/23792)를 해결합니다. 작성자: [Kevin Wan] (@MaxWk). [#25394](https://github.com/ClickHouse/ClickHouse/pull/25394) ([Maksim Kita](https://github.com/kitaisreal)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* (변경 로그에서 제거) 실험적 압축 라이브러리를 통합하고 테스트했습니다. `allow_experimental_codecs` 플래그로 사용할 수 있습니다. 이로써 [#16775](https://github.com/ClickHouse/ClickHouse/issues/16775)가 해결되었습니다. [#17847](https://github.com/ClickHouse/ClickHouse/pull/17847) ([Abi Palagashvili](https://github.com/fibersel)).
* RabbitMQ 큐가 비어 있을 때 읽기 시도를 다시 예약하도록 지수형 백오프를 추가했습니다. [#24340](https://github.com/ClickHouse/ClickHouse/issues/24340)이 해결되었습니다. [#24415](https://github.com/ClickHouse/ClickHouse/pull/24415) ([Kseniia Sumarokova](https://github.com/kssenii)).
* bloom&#95;filter 유형의 인덱스는 상수 배열과 함께 `hasAny` 함수를 사용하는 표현식에 사용할 수 있습니다. 이로써 [#24291](https://github.com/ClickHouse/ClickHouse/issues/24291)가 해결되었습니다. [#24900](https://github.com/ClickHouse/ClickHouse/pull/24900) ([Vasily Nemkov](https://github.com/Enmk)).



<div id="improvement">
  #### 개선 사항
</div>

* 여러 개의 S3 볼륨에서 zero-copy 복제를 수정했습니다([#22679](https://github.com/ClickHouse/ClickHouse/issues/22679) 수정). [#22864](https://github.com/ClickHouse/ClickHouse/pull/22864) ([ianton-ru](https://github.com/ianton-ru)).
* 분산 쿼리에서 LIMIT를 push down할 수 있는 기능을 추가했습니다. [#23027](https://github.com/ClickHouse/ClickHouse/pull/23027) ([Azat Khuzhin](https://github.com/azat)).
* `Distributed` 테이블에 INSERT할 때 `insert_allow_materialized_columns`(materialized 컬럼 허용)을 적용하도록 했습니다. [#23349](https://github.com/ClickHouse/ClickHouse/pull/23349) ([Azat Khuzhin](https://github.com/azat)).
* 이 PR에서 수정할 모든 버그를 여기에 나열할 예정입니다. [#23518](https://github.com/ClickHouse/ClickHouse/pull/23518) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 데이터가 stdin으로 전달될 때 clickhouse-local의 File 테이블 엔진과 clickhouse-client의 INSERT 쿼리에서 진행 상황을 표시합니다. [#18209](https://github.com/ClickHouse/ClickHouse/issues/18209)을 닫습니다. [#23656](https://github.com/ClickHouse/ClickHouse/pull/23656) ([Kseniia Sumarokova](https://github.com/kssenii)).
* storage join의 컬럼 이름 충돌을 처리하고 [#20309](https://github.com/ClickHouse/ClickHouse/issues/20309)를 닫습니다. [#23769](https://github.com/ClickHouse/ClickHouse/pull/23769) ([Vladimir C](https://github.com/vdimir)).
* 실패 시(예: 메모리 한도 초과, 손상 등) 분산 Batch를 분할하는 기능을 `distributed_directory_monitor_split_batch_on_failure`로 추가했습니다(기본값은 OFF). [#23864](https://github.com/ClickHouse/ClickHouse/pull/23864) ([Azat Khuzhin](https://github.com/azat)).
* 기본 `clickhouse` binary에 독립 실행형 `clickhouse-keeper` 심볼릭 링크를 추가했습니다. 이제 기본 ClickHouse 서버 없이 coordination을 실행할 수 있습니다. [#24059](https://github.com/ClickHouse/ClickHouse/pull/24059) ([alesapin](https://github.com/alesapin)).
* 로거 코드에서 발생하는 예외를 억제합니다. [#24069](https://github.com/ClickHouse/ClickHouse/pull/24069) ([Azat Khuzhin](https://github.com/azat)).
* `VIEW`에 대한 쿼리에 전역 설정을 사용합니다. `VIEW`에 대한 쿼리가 로컬 설정을 사용하던 동작을 수정했으며, `CREATE VIEW`와 `SELECT`의 설정이 서로 다를 경우 발생하던 오류를 해결했습니다. 현재 `VIEW`는 이러한 수정된 설정을 사용하지 않지만, `CREATE VIEW` 쿼리의 `SETTINGS` 섹션에서 추가 설정을 계속 전달할 수 있습니다. [#20551](https://github.com/ClickHouse/ClickHouse/issues/20551)를 닫습니다. [#24095](https://github.com/ClickHouse/ClickHouse/pull/24095) ([Vladimir C](https://github.com/vdimir)).
* MySQL storage engine용 설정(`connection_auto_close`/`connection_max_tries`/`connection_pool_size`)을 추가했습니다. [#24146](https://github.com/ClickHouse/ClickHouse/pull/24146) ([Azat Khuzhin](https://github.com/azat)).
* 여러 줄 모드에서 서브쿼리가 있는 FROM 절의 후행 공백을 수정하고, 쿼리 출력도 더 읽기 쉽게 약간 개선했습니다. [#24151](https://github.com/ClickHouse/ClickHouse/pull/24151) ([Azat Khuzhin](https://github.com/azat)).
* `127.0.1.1`과 같은 IPv4 address를 로컬로 인식합니다. 이는 논란의 여지가 있으며 [#23504](https://github.com/ClickHouse/ClickHouse/issues/23504)를 닫습니다. Michael Filimonov가 이 기능을 테스트할 예정입니다. [#24316](https://github.com/ClickHouse/ClickHouse/pull/24316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* IPv6 address 확인(resolve)을 수정했습니다(예: `select * from remote('[::1]', system.one)` 수정). [#24319](https://github.com/ClickHouse/ClickHouse/pull/24319) ([Azat Khuzhin](https://github.com/azat)).
* 이제 query&#95;log에 새 컬럼 2개(`initial_query_start_time / initial_query_start_time_microsecond`)가 추가되었습니다. 이 컬럼은 분산 쿼리가 있는 경우 해당 쿼리의 시작 시각을 기록합니다. [#24388](https://github.com/ClickHouse/ClickHouse/pull/24388) ([Amos Bird](https://github.com/amosbird)).
* 더 많은 컬럼을 가능한 별칭 표현식으로 재작성합니다. 이를 통해 프로젝션과 같은 최적화를 더 효과적으로 수행할 수 있습니다. [#24405](https://github.com/ClickHouse/ClickHouse/pull/24405) ([Amos Bird](https://github.com/amosbird)).
* 일부 함수를 서브컬럼 읽기로 변환해 읽는 데이터 양을 줄이는 최적화가 추가되었습니다. 예를 들어 `col IS NULL` 구문은 서브컬럼 `col.null`을 읽도록 변환됩니다. 이 최적화는 `optimize_functions_to_subcolumns` 설정으로 활성화할 수 있습니다. [#24406](https://github.com/ClickHouse/ClickHouse/pull/24406) ([Anton Popov](https://github.com/CurtizJ)).
* Keeper 종료 시 발생하는 data race를 수정했습니다. [#24412](https://github.com/ClickHouse/ClickHouse/pull/24412) ([alesapin](https://github.com/alesapin)).
* 삽입 쿼리에서 Postgres 스키마를 지원합니다. [#24149](https://github.com/ClickHouse/ClickHouse/issues/24149)를 해결합니다. [#24413](https://github.com/ClickHouse/ClickHouse/pull/24413) ([Kseniia Sumarokova](https://github.com/kssenii)).
* SSDDictionary를 DDL 쿼리로 생성하는 경우 `user_files` 디렉터리 내부에서만 생성할 수 있습니다. [#24466](https://github.com/ClickHouse/ClickHouse/pull/24466) ([Maksim Kita](https://github.com/kitaisreal)).
* String-to-Int parser를 더 엄격하게 만들어 `toInt64('+')` 호출 시 예외가 발생하도록 했습니다. [#24475](https://github.com/ClickHouse/ClickHouse/pull/24475) ([Amos Bird](https://github.com/amosbird)).
* MergeTree 설정 `max_parts_to_merge_at_once`를 추가했습니다. 이 설정은 백그라운드에서 한 번에 머지할 수 있는 파트 수를 제한합니다. `OPTIMIZE FINAL` 쿼리에는 영향을 주지 않습니다. [#1820](https://github.com/ClickHouse/ClickHouse/issues/1820)을 해결합니다. [#24496](https://github.com/ClickHouse/ClickHouse/pull/24496) ([alesapin](https://github.com/alesapin)).
* 스칼라 서브쿼리에서 `Limit for rows or bytes to read exceeded` 같은 오류가 숨겨지지 않도록 했습니다. [#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).
* 2개의 Replicated*MergeTree 설정 `max_replicated_fetches_network_bandwidth` 및 `max_replicated_sends_network_bandwidth`를 추가했습니다. 이 설정은 테이블의 replicated fetches/sends 최대 속도를 제한할 수 있게 합니다. 또한 서버 전체에 적용되는 설정 2개(`default` 사용자 profile 내)인 `max_replicated_fetches_network_bandwidth_for_server` 및 `max_replicated_sends_network_bandwidth_for_server`도 추가했습니다. 이 설정은 모든 테이블의 복제 최대 속도를 제한합니다. 설정값이 완벽하게 정확히 적용되지는 않습니다. 기본적으로는 비활성화되어 있습니다. [#1821](https://github.com/ClickHouse/ClickHouse/issues/1821)을 해결합니다. [#24573](https://github.com/ClickHouse/ClickHouse/pull/24573) ([alesapin](https://github.com/alesapin)).
* `insert_distributed_sync`가 `max_distributed_connections`를 따르도록 했습니다(그렇지 않으면 대규모 cluster에서 동기 삽입 시 `max_thread_pool_size`가 고갈될 수 있습니다). [#24754](https://github.com/ClickHouse/ClickHouse/pull/24754) ([Azat Khuzhin](https://github.com/azat)).
* `Replicated` 데이터베이스 엔진에서 일부 레플리카가 큐에 추가된 DDL 쿼리를 건너뛸 수 있던 드문 버그를 수정했습니다. [#24805](https://github.com/ClickHouse/ClickHouse/pull/24805) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 일부 쿼리에는 다중 패스 의미 분석이 필요합니다. 이 경우 `IN`에 대해 이미 만들어진 Set을 재사용하도록 시도합니다. [#24874](https://github.com/ClickHouse/ClickHouse/pull/24874) ([Amos Bird](https://github.com/amosbird)).
* 파티션 프루닝에서 `not in` 연산자를 사용할 수 있도록 했습니다. [#24894](https://github.com/ClickHouse/ClickHouse/pull/24894) ([Amos Bird](https://github.com/amosbird)).
* S3 오류 로깅이 개선되어, key와 버킷이 비어 있을 때 더 이상 공백이 두 번 들어가지 않습니다. [#24897](https://github.com/ClickHouse/ClickHouse/pull/24897) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 분산 쿼리에서 `optimize_skip_unused_shards=1`인 경우 `(sharding key) IN (one-element-tuple)`와 같은 조건으로 세그먼트를 건너뛸 수 있도록 허용합니다. (여러 요소를 가진 튜플은 이미 지원되었지만, 단일 요소 튜플은 literal로 파싱되어 동작하지 않았습니다.) [#24930](https://github.com/ClickHouse/ClickHouse/pull/24930) ([Amos Bird](https://github.com/amosbird)).
* 런타임에 Linux 버전을 감지합니다 (`async_socket_for_remote`/`use_hedged_requests`에 필요한 중첩 epoll이 정상 동작하도록 하기 위함이며, 그렇지 않으면 원격 쿼리가 멈출 수 있습니다). [#25067](https://github.com/ClickHouse/ClickHouse/pull/25067) ([Azat Khuzhin](https://github.com/azat)).
* background schedule pool의 크기를 128로 늘렸습니다(`background_schedule_pool_size` 설정). 이를 통해 ZooKeeper 연결이 느릴 때 복제 큐가 멈추는 현상을 방지할 수 있습니다. [#25072](https://github.com/ClickHouse/ClickHouse/pull/25072) ([alesapin](https://github.com/alesapin)).
* IDN host(예: `example.рф`)에 대한 topLevelDomain()을 수정했습니다. 이전에는 이러한 host에 대해 빈 문자열을 반환했습니다. [#25103](https://github.com/ClickHouse/ClickHouse/pull/25103) ([Azat Khuzhin](https://github.com/azat)).
* 서버 시작 시 잘못된 partition ID를 가진 파트는 제거되지 않고 항상 분리되었습니다. [#25070](https://github.com/ClickHouse/ClickHouse/issues/25070). [#25166](https://github.com/ClickHouse/ClickHouse/pull/25166) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
