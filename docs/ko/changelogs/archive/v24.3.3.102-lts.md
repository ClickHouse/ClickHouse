  #### 개선 사항

* [#62188](https://github.com/ClickHouse/ClickHouse/issues/62188)에 백포트됨: 엄격성 `ANY`를 사용하는 StorageJoin이 다시 로드된 후에도 일관되게 동작합니다. 동일한 키를 가진 여러 행이 삽입되면 첫 번째 행의 우선순위가 더 높아집니다(이전에는 테이블 로드 시 무작위로 선택되었습니다). [#51027](https://github.com/ClickHouse/ClickHouse/issues/51027) 해결. [#61972](https://github.com/ClickHouse/ClickHouse/pull/61972) ([vdimir](https://github.com/vdimir)).
* [#62443](https://github.com/ClickHouse/ClickHouse/issues/62443)에 백포트됨: 클라이언트는 서버에 &#39;Keep-Alive: timeout=X&#39; 헤더를 전송해야 합니다. 클라이언트가 서버로부터 해당 헤더가 포함된 응답을 받으면 서버의 값을 사용해야 합니다. 또한 클라이언트는 연결 종료 경쟁 상태를 피하기 위해 만료가 임박한 connection을 사용하지 않는 것이 좋습니다. [#62249](https://github.com/ClickHouse/ClickHouse/pull/62249) ([Sema Checherinda](https://github.com/CheSema)).
* [#62666](https://github.com/ClickHouse/ClickHouse/issues/62666)에 백포트됨: S3 storage와 백업에도 S3 디스크와 동일한 기본 keep alive 설정이 필요합니다. [#62648](https://github.com/ClickHouse/ClickHouse/pull/62648) ([Sema Checherinda](https://github.com/CheSema)).
