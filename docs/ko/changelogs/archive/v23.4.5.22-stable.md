<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530)에 백포트됨: Dockerfile의 큰 `RUN`을 더 작은 조건부 구문으로 분할했습니다. 필요한 도구는 동일한 `RUN` 레이어에서 필요할 때만 설치하고, 이후 제거합니다. OS는 시작 시 한 번만 upgrade합니다. 서명된 리포지토리를 확인할 때 최신 방식을 사용합니다. 오래된 Docker 버전에서 발생하는 문제를 해결하기 위해 기본 리포지토리를 ubuntu:20.04로 downgrade했습니다. golang 취약점을 해결하기 위해 golang 버전을 upgrade했습니다. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570)에 백포트됨: 이는 [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504)의 후속 수정으로, 리팩터링 과정에서 정리 작업이 누락되었습니다. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오동작)
</div>

* 이항 연산자에 NULL 상수 인수가 포함된 경우 인덱스 분석이 잘못되던 문제를 수정했습니다 [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* 대상 호스트 IP가 변경되었을 때 HTTPS 세션이 재연결되지 않던 문제를 수정했습니다 [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 상수 폴딩이 잘못 수행되던 문제를 수정했습니다 [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 캐시 항목에서 LDAP 서버 파라미터 hash의 유형을 수정했습니다 [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* Parquet 포맷에서 예외를 발생시키는 대신 String에서 큰 정수를 파싱하도록 폴백합니다 [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* read-in-order가 활성화된 경우 프로젝션을 적용하지 않도록 했습니다. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* ActionsDAG에서 퍼저 실패 문제를 수정했습니다 [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
