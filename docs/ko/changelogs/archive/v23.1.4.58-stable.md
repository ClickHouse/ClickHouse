<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 보이는 오동작)
</div>

* [#46228](https://github.com/ClickHouse/ClickHouse/issues/46228)에 백포트됨: `c-ares` 주변에서 몇 건의 segfault가 보고되었습니다. 최근 관찰된 모든 스택 트레이스는 `std::unodered_set<>`에 삽입하는 과정에서 실패합니다. 이 문제의 근본 원인을 찾은 것으로 보이며, 처리되지 않은 쿼리와 관련된 것으로 보입니다. 이 PR 이전에는 CH가 `c-ares` 채널의 파일 디스크립터를 기다리기 위해 `poll`을 호출했습니다. [poll docs](https://man7.org/linux/man-pages/man2/poll.2.html)에 따르면 음수 반환값은 오류가 발생했음을 의미합니다. 그래서 실행을 중단하고 실패를 반환했습니다. 문제는 시스템 인터럽트가 발생한 경우에도 `poll`이 음수 값을 반환한다는 점입니다. 시스템 인터럽트는 처리가 실패했거나 종료되었음을 의미하지 않지만, 음수 값을 검사하고 있었기 때문에 어쨌든 중단했습니다. 실행이 중단되면 전체 스택이 파괴되며, 여기에는 c-ares 콜백의 `void *` 매개변수로 전달된 `std::unordered_set<std::string>`도 포함됩니다. c-ares가 request를 완료하면 콜백이 호출되고, 그 과정에서 유효하지 않은 메모리 주소에 접근해 segfault가 발생할 수 있습니다. [#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos)).
* [#46967](https://github.com/ClickHouse/ClickHouse/issues/46967)에 백포트됨: 이전 버전과의 호환성 - &quot;INSERT ... VALUES ...&quot; 표현식에 필요하므로 UInt64에서 IPv4로의 암시적 축소 변환을 허용합니다. [#45865](https://github.com/ClickHouse/ClickHouse/pull/45865) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#46220](https://github.com/ClickHouse/ClickHouse/issues/46220)에 백포트됨: compact 파트에서 여러 수준의 존재하지 않는 nested 컬럼을 읽을 때 발생하는 문제를 수정했습니다. [#46045](https://github.com/ClickHouse/ClickHouse/pull/46045) ([Azat Khuzhin](https://github.com/azat)).
* [#46751](https://github.com/ClickHouse/ClickHouse/issues/46751)에 백포트됨: 도메인 IP 타입(IPv4, IPv6)을 네이티브로 대체하는 변경([https://github.com/ClickHouse/ClickHouse/pull/43221](https://github.com/ClickHouse/ClickHouse/pull/43221))에 대한 후속 수정입니다. [#46087](https://github.com/ClickHouse/ClickHouse/pull/46087) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#46448](https://github.com/ClickHouse/ClickHouse/issues/46448)에 백포트됨: 포맷 `VALUES`로 전송된 잘못된 데이터가 있는 비동기 삽입에서 발생할 수 있는 `LOGICAL_ERROR`를 수정했습니다. [#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ)).
* [#46680](https://github.com/ClickHouse/ClickHouse/issues/46680)에 백포트됨: 함수 `arrayMap`에서 상수 `LowCardinality` 인수를 잘못 처리하던 문제를 수정했습니다. 이 버그는 릴리스 빌드에서는 segfault를, 디버그 빌드에서는 논리 오류 `Bad cast`를 유발할 수 있었습니다. [#46569](https://github.com/ClickHouse/ClickHouse/pull/46569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46873](https://github.com/ClickHouse/ClickHouse/issues/46873)에 백포트됨: `Map` 데이터 타입의 버그를 수정했습니다. 이로써 [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855)가 해결됩니다. [#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46956](https://github.com/ClickHouse/ClickHouse/issues/46956)에 백포트됨: 부분 문자열 검색으로 변환되며 따옴표로 묶인 비-LIKE 메타문자를 포함하는 LIKE 프레디케이트의 결과를 수정했습니다. [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
