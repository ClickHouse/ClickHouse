<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 중첩 타입에서 의심스럽거나 Experimental 상태인 타입을 검증합니다. 이전에는 Array/Tuple/Map과 같은 중첩 타입에서 이러한 타입(JSON 제외)을 검증하지 않았습니다. [#59385](https://github.com/ClickHouse/ClickHouse/pull/59385) ([Kruglov Pavel](https://github.com/Avogar)).
* 정렬 절 `ORDER BY ALL`(v23.12에 도입됨)이 `ORDER BY *`로 대체되었습니다. 이전 구문은 `all`이라는 컬럼이 있는 테이블에서 오류를 일으키기 쉬웠습니다. [#59450](https://github.com/ClickHouse/ClickHouse/pull/59450) ([Robert Schulze](https://github.com/rschu1ze)).
* 설정 `extract_kvp_max_pairs_per_row`의 이름을 `extract_key_value_pairs_max_pairs_per_row`로 변경합니다. 이 버그(설정 이름에 불필요한 약어를 사용한 문제)는 https://github.com/ClickHouse/ClickHouse/pull/43606 에서 도입되었습니다. 이 설정의 문서도 수정합니다. [#59683](https://github.com/ClickHouse/ClickHouse/pull/59683) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 설정 `extract_kvp_max_pairs_per_row`의 이름을 `extract_key_value_pairs_max_pairs_per_row`로 변경합니다. 이 버그(설정 이름에 불필요한 약어를 사용한 문제)는 https://github.com/ClickHouse/ClickHouse/pull/43606 에서 도입되었습니다. 이 설정의 문서도 수정합니다. [#59960](https://github.com/ClickHouse/ClickHouse/pull/59960) ([jsc0218](https://github.com/jsc0218)).
* 스레드 수와 block 크기에 대한 점검 검사를 추가합니다. [#60138](https://github.com/ClickHouse/ClickHouse/pull/60138) ([Raúl Marín](https://github.com/Algunenano)).



<div id="new-feature">
  #### 새 기능
</div>

* QUOTA에 최대 연속 로그인 실패 횟수를 추가했습니다. [#54737](https://github.com/ClickHouse/ClickHouse/pull/54737) ([Alexey Gerasimchuck](https://github.com/Demilivor)).
* View/Materialized View에서 definer 사용자를 지정할 수 있는 새 구문을 추가했습니다. 이를 통해 기반 테이블에 대한 명시적인 권한 부여 없이도 뷰에서 select/insert를 실행할 수 있습니다. [#54901](https://github.com/ClickHouse/ClickHouse/pull/54901) ([pufit](https://github.com/pufit)).
* AzureBlobStorage용 Backup &amp; Restore 지원으로 [#50747](https://github.com/ClickHouse/ClickHouse/issues/50747)이 해결되었습니다. [#56988](https://github.com/ClickHouse/ClickHouse/pull/56988) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 서로 다른 종류의 MergeTree 테이블을 Replicated 엔진으로 자동 변환하는 기능을 구현했습니다. 테이블의 데이터 디렉터리(`/clickhouse/store/xxx/xxxyyyyy-yyyy-yyyy-yyyy-yyyyyyyyyyyy/`)에 빈 `convert_to_replicated` 파일을 생성하면 다음 서버 시작 시 해당 테이블이 자동으로 변환됩니다. [#57798](https://github.com/ClickHouse/ClickHouse/pull/57798) ([Kirill](https://github.com/kirillgarbar)).
* 테이블 함수 `mergeTreeIndex`를 추가했습니다. 이 함수는 `MergeTree` 테이블의 인덱스와 마크 파일 내용을 나타냅니다. 내부 검사에 사용할 수 있습니다. 구문: `mergeTreeIndex(database, table, [with_marks = true])`이며, 여기서 `database.table`은 `MergeTree` 엔진을 사용하는 기존 테이블입니다. [#58140](https://github.com/ClickHouse/ClickHouse/pull/58140) ([Anton Popov](https://github.com/CurtizJ)).
* Tukey의 fences 알고리즘을 사용해 시계열 데이터의 이상치를 탐지하는 함수 `seriesOutliersTukey`를 추가했습니다. [#58632](https://github.com/ClickHouse/ClickHouse/pull/58632) ([Bhavna Jindal](https://github.com/bhavnajindal)).
* 이제 `format_template_row`의 대안으로 `format_schema_rows_template`를 사용해 쿼리에서 직접 템플릿 문자열을 지정할 수 있습니다. [#31363](https://github.com/ClickHouse/ClickHouse/issues/31363)을 종료했습니다. [#59088](https://github.com/ClickHouse/ClickHouse/pull/59088) ([Shaun Struwig](https://github.com/Blargian)).
* `file/s3/hdfs/url/azureBlobStorage` 엔진에서 포맷을 알 수 없는 경우 스키마 추론 중에 파일 포맷을 자동으로 감지하도록 시도합니다. [#50576](https://github.com/ClickHouse/ClickHouse/issues/50576)을 종료했습니다. [#59092](https://github.com/ClickHouse/ClickHouse/pull/59092) ([Kruglov Pavel](https://github.com/Avogar)).
* 각 행에 대해 variant 유형 이름을 담은 Enum을 반환하는 함수 `variantType`을 추가했습니다. [#59398](https://github.com/ClickHouse/ClickHouse/pull/59398) ([Kruglov Pavel](https://github.com/Avogar)).
* 비어 있는 파티션과 관련된 ZooKeeper 노드를 제거하는 쿼리 `ALTER TABLE table FORGET PARTITION partition`를 추가했습니다. [#59507](https://github.com/ClickHouse/ClickHouse/pull/59507) ([Sergei Trifonov](https://github.com/serxa)).
* NATS 테이블 엔진에서 JWT 자격 증명 파일을 지원합니다. [#59543](https://github.com/ClickHouse/ClickHouse/pull/59543) ([Nickolaj Jepsen](https://github.com/nickolaj-jepsen)).
* 새 집계 함수 `groupArrayIntersect`를 제공합니다. 후속 작업: [#49862](https://github.com/ClickHouse/ClickHouse/issues/49862). [#59598](https://github.com/ClickHouse/ClickHouse/pull/59598) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* DNS 문제를 디버깅하는 데 유용할 수 있는 `system.dns_cache` 테이블을 구현했습니다. [#59856](https://github.com/ClickHouse/ClickHouse/pull/59856) ([Kirill Nikiforov](https://github.com/allmazz)).
* 코덱 `LZ4HC`에 새로운 레벨 2가 추가되었습니다. 이 레벨은 압축률이 다소 낮아지는 대신, 기존 최소 레벨 3보다 더 빠릅니다. 이전 버전에서는 `LZ4HC(2)` 이하는 `LZ4HC(3)`와 동일하게 동작했습니다. 작성자: [Cyan4973](https://github.com/Cyan4973). [#60090](https://github.com/ClickHouse/ClickHouse/pull/60090) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* DNS 문제 디버깅에 유용한 `system.dns&#95;cache` 테이블이 구현되었습니다. 새로운 서버 설정 `dns&#95;cache&#95;max&#95;size`도 추가되었습니다. [#60257](https://github.com/ClickHouse/ClickHouse/pull/60257) ([Kirill Nikiforov](https://github.com/allmazz)).
* `merge(['db_name', ] 'tables_regexp')` 형태로 `merge` 테이블 함수의 단일 인수 버전을 지원합니다. [#60372](https://github.com/ClickHouse/ClickHouse/pull/60372) ([豪肥肥](https://github.com/HowePa)).
* View/Materialized View에서 definer 사용자를 지정할 수 있는 새로운 구문이 추가되었습니다. 이를 통해 기반 테이블에 대한 명시적인 권한 부여 없이도 뷰를 통해 조회/삽입을 수행할 수 있습니다. [#60439](https://github.com/ClickHouse/ClickHouse/pull/60439) ([pufit](https://github.com/pufit)).

<div id="improvement">
  #### 개선 사항
</div>

* 분석기에서 매개변수화된 뷰(parameterized view)를 지원하도록 추가했으며, `CREATE PARAMETERIZED VIEW`는 분석하지 않도록 했습니다. 또한 기존 매개변수화된 뷰 로직도 리팩터링하여 `CREATE PARAMETERIZED VIEW`를 분석하지 않도록 했습니다. [#54211](https://github.com/ClickHouse/ClickHouse/pull/54211) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 프로젝션이 손상되었더라도 데이터 파트(data part)를 손상된 것으로 간주하지 않도록 했습니다. [#56593](https://github.com/ClickHouse/ClickHouse/issues/56593)를 해결했습니다. [#56864](https://github.com/ClickHouse/ClickHouse/pull/56864) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `dictGetOrDefault` 함수에 단락 평가 기능을 추가했습니다. [#52098](https://github.com/ClickHouse/ClickHouse/issues/52098)를 해결했습니다. [#57767](https://github.com/ClickHouse/ClickHouse/pull/57767) ([jsc0218](https://github.com/jsc0218)).
* 이제 `DEFAULT` 또는 `MATERIALIZED` 표현식이 있는 컬럼에서 `ALTER COLUMN MATERIALIZE`를 실행하면 올바른 값이 기록됩니다. 즉, 기본값이 있는 기존 파트에는 기본값이 기록되고, 기본값이 아닌 값이 있는 기존 파트에는 기본값이 아닌 값이 기록됩니다. 이전에는 모든 기존 파트에 기본값이 기록되었습니다. [#58023](https://github.com/ClickHouse/ClickHouse/pull/58023) ([Duc Canh Le](https://github.com/canhld94)).
* 백오프 로직(예: 지수형)을 활성화했습니다. 이를 통해 CPU 사용량, 메모리 사용량, 로그 파일 크기를 줄일 수 있습니다. [#58036](https://github.com/ClickHouse/ClickHouse/pull/58036) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* InitialQuery 집계를 개선했습니다. [#58195](https://github.com/ClickHouse/ClickHouse/pull/58195) ([Unalian](https://github.com/Unalian)).
* 음수 위치 인수를 지원합니다. [#57736](https://github.com/ClickHouse/ClickHouse/issues/57736)를 해결했습니다. [#58292](https://github.com/ClickHouse/ClickHouse/pull/58292) ([flynn](https://github.com/ucasfl)).
* 비동기 삽입 타임아웃의 자동 조정을 구현했습니다. 다음 설정이 도입되었습니다: async&#95;insert&#95;poll&#95;timeout&#95;ms, async&#95;insert&#95;use&#95;adaptive&#95;busy&#95;timeout, async&#95;insert&#95;busy&#95;timeout&#95;min&#95;ms, async&#95;insert&#95;busy&#95;timeout&#95;max&#95;ms, async&#95;insert&#95;busy&#95;timeout&#95;increase&#95;rate, async&#95;insert&#95;busy&#95;timeout&#95;decrease&#95;rate. [#58486](https://github.com/ClickHouse/ClickHouse/pull/58486) ([Julia Kartseva](https://github.com/jkartseva)).
* `storage_configuration`에서 `volume_priority`를 정의할 수 있도록 했습니다. [#58533](https://github.com/ClickHouse/ClickHouse/pull/58533) ([Andrey Zvonov](https://github.com/zvonand)).
* T64 코덱에서 Date32 타입을 지원하도록 추가했습니다. [#58738](https://github.com/ClickHouse/ClickHouse/pull/58738) ([Hongbin Ma (Mahone)](https://github.com/binmahone)).
* 병렬 레플리카에서 `LEFT JOIN`, `ALL INNER JOIN`, 그리고 단순 서브쿼리를 지원합니다(분석기에서만). 새로운 설정 `parallel_replicas_prefer_local_join`은 로컬 `JOIN` 실행(기본값)과 `GLOBAL JOIN` 중에서 선택합니다. 모든 테이블은 `cluster_for_parallel_replicas`의 모든 레플리카에 존재해야 합니다. 새로운 설정 `min_external_table_block_size_rows` 및 `min_external_table_block_size_bytes`는 임시 테이블로 전송되는 작은 블록을 합쳐(squash) 더 크게 만드는 데 사용됩니다(분석기에서만). [#58916](https://github.com/ClickHouse/ClickHouse/pull/58916) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 여러 항목이 있는 타입에서 후행 쉼표를 허용합니다. [#59119](https://github.com/ClickHouse/ClickHouse/pull/59119) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* `S3Queue` 테이블 엔진에서 병렬 및 분산 처리를 사용할 수 있습니다. 분산 처리에는 `s3queue_total_shards_num` 설정(기본값 `1`)을 사용하십시오. 이전에는 Ordered 처리 모드에서 `s3queue_processing_threads_num` 설정을 사용할 수 없었지만, 이제는 사용할 수 있습니다. 경고: Ordered 모드에서 `s3queue_processing_threads_num`(각 세그먼트별 처리 스레드 수) 및 `s3queue_total_shards_num` 설정은 metadata 저장 방식에 영향을 줍니다(`max_processed_file` 노드 수가 `s3queue_processing_threads_num * s3queue_total_shards_num`와 같아짐). 따라서 이 값들은 모든 세그먼트에서 동일해야 하며, 세그먼트가 하나라도 생성된 이후에는 변경할 수 없습니다. [#59167](https://github.com/ClickHouse/ClickHouse/pull/59167) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `recoverLostReplica` 수행 중 `DatabaseReplicated`에서 테이블을 동시에 생성할 수 있습니다. [#59277](https://github.com/ClickHouse/ClickHouse/pull/59277) ([Konstantin Bogdanov](https://github.com/thevar1able)).
