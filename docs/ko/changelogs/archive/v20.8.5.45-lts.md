* [#16146](https://github.com/ClickHouse/ClickHouse/issues/16146)에 백포트됨: 이제 클러스터 구성의 `<internal_replication>` 설정과 무관하게 `ALTER ... ON CLUSTER` 쿼리를 실행할 수 있습니다. [#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)).
* [#16310](https://github.com/ClickHouse/ClickHouse/issues/16310)에 백포트됨: allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards를 추가했습니다(세그먼트 분할 키에서 `rand()` 또는 `dictGet()` 같은 비결정적 함수를 허용하기 위해). [#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).

[#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)).
* [#16230](https://github.com/ClickHouse/ClickHouse/issues/16230)에서 백포트됨: S3 테이블 함수의 글롭 패턴 관련 버그를 수정했습니다. URL의 리전이 S3 클라이언트 구성에 적용되지 않던 문제입니다. [#15646](https://github.com/ClickHouse/ClickHouse/pull/15646) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#15871](https://github.com/ClickHouse/ClickHouse/issues/15871)에서 백포트됨: 대상 테이블과 구조가 다른 `Buffer` 테이블을 읽는 중 발생하던 `Cannot add simple transform to empty Pipe` 오류를 수정했습니다. 대상 테이블이 쿼리에 빈 결과를 반환하는 경우 이 문제가 발생할 수 있었습니다. [#15529](https://github.com/ClickHouse/ClickHouse/issues/15529)를 해결합니다. [#15662](https://github.com/ClickHouse/ClickHouse/pull/15662) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#15772](https://github.com/ClickHouse/ClickHouse/issues/15772)에서 백포트됨: `max_replicated_logs_to_keep` 설정의 기본값이 너무 낮아 레플리카가 지나치게 자주 손실될 수 있던 문제를 수정했습니다. 가장 최신 상태의 레플리카를 선택해 복제하도록 하여 손실된 레플리카 복구 과정을 개선했습니다. 또한 손실된 레플리카에서 오래된 파트를 제거하지 않고 detach하도록 했습니다. [#15701](https://github.com/ClickHouse/ClickHouse/pull/15701) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#15738](https://github.com/ClickHouse/ClickHouse/issues/15738)에서 백포트됨: `MV`용 쿼리에 `ARRAY JOIN`이 포함된 경우 `MATERIALIZED VIEW`에 삽입할 때 발생할 수 있는 `Cannot find column` 오류를 수정했습니다. [#15717](https://github.com/ClickHouse/ClickHouse/pull/15717) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#15795](https://github.com/ClickHouse/ClickHouse/issues/15795)에서 백포트됨: 가상 컬럼만 선택하는 일부 쿼리의 문제를 수정했습니다. 이전에는 `Not found column _nothing in block` 예외가 발생할 수 있었습니다. [#12298](https://github.com/ClickHouse/ClickHouse/issues/12298)를 해결합니다. [#15756](https://github.com/ClickHouse/ClickHouse/pull/15756) ([Anton Popov](https://github.com/CurtizJ)).
* [#15900](https://github.com/ClickHouse/ClickHouse/issues/15900)에서 백포트됨: `ALTER MODIFY COLUMN` 쿼리 실행 후 수행된 `SELECT ... ORDER BY DESC` 쿼리에서 발생하던 `Block structure mismatch` 예외를 수정했습니다. [#15800](https://github.com/ClickHouse/ClickHouse/issues/15800)를 해결합니다. [#15852](https://github.com/ClickHouse/ClickHouse/pull/15852) ([alesapin](https://github.com/alesapin)).
* [#15925](https://github.com/ClickHouse/ClickHouse/issues/15925)에서 백포트됨: 이제 `ALTER MODIFY COLUMN ... DEFAULT ...`의 기본값이 컬럼 타입과 호환되지 않으면 예외가 발생합니다. [#15854](https://github.com/ClickHouse/ClickHouse/issues/15854)를 해결합니다. [#15858](https://github.com/ClickHouse/ClickHouse/pull/15858) ([alesapin](https://github.com/alesapin)).

[#15792](https://github.com/ClickHouse/ClickHouse/issues/15792)를 해결합니다. [#15933](https://github.com/ClickHouse/ClickHouse/pull/15933) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#16355](https://github.com/ClickHouse/ClickHouse/issues/16355)에 백포트됨: 테이블 이름이 동시에 변경되는 경우(atomic 데이터베이스 엔진) `Table ... doesn't exist` 오류와 함께 `DROP TABLE IF EXISTS`가 실패하는 문제를 수정했습니다. 여러 테이블에 대한 일부 DDL 쿼리(예: `DROP DATABASE`, `RENAME TABLE`)를 동시에 실행할 때 드물게 발생하던 데드락을 수정했습니다. `DROP/DETACH TABLE`을 동시에 실행할 때 `Table ... doesn't exist` 오류와 함께 `DROP/DETACH DATABASE`가 실패하는 문제를 수정했습니다. [#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#15968](https://github.com/ClickHouse/ClickHouse/issues/15968)에 백포트됨: 데이터베이스 생성 실패 시 발생하는 크래시를 수정했습니다. [#15954](https://github.com/ClickHouse/ClickHouse/pull/15954) ([Winter Zhang](https://github.com/zhang2014)).

[#15982](https://github.com/ClickHouse/ClickHouse/pull/15982) ([Vitaly Baranov](https://github.com/vitlibar)).
