<div id="improvement">
  #### 개선 사항

* [#68103](https://github.com/ClickHouse/ClickHouse/issues/68103)로 백포트됨: 사용자 지정 설정의 값을 파싱할 때 boolean과 정수를 구분하도록 개선: `SET custom_a = true; SET custom_b = 1;`. [#62206](https://github.com/ClickHouse/ClickHouse/pull/62206) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#67931](https://github.com/ClickHouse/ClickHouse/issues/67931)에 백포트됨: StorageMerge의 `PREWHERE` 최적화 후 발생하는 `Not-ready Set` 오류를 수정했습니다. [#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#68062](https://github.com/ClickHouse/ClickHouse/issues/68062)에 백포트됨: 외부 데이터베이스(예: `PostgreSQL`)로 전송되는 쿼리의 Boolean 리터럴을 수정했습니다. [#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* [#67812](https://github.com/ClickHouse/ClickHouse/issues/67812)에 백포트됨: 실험적 Variant 데이터 타입에만 해당합니다. Variant + AggregateFunction 타입에서 발생하는 크래시를 수정했습니다. [#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* [#67848](https://github.com/ClickHouse/ClickHouse/issues/67848)에 백포트됨: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)을 수정합니다. `ReplaceTableNodeToDummyVisitor`에서 아직 해결되지 않은 테이블 함수 인수 순회를 방지합니다. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* [#68271](https://github.com/ClickHouse/ClickHouse/issues/68271)에 백포트됨: HTTP 인터페이스를 통해 스트림 계열 엔진(Kafka, RabbitMQ, NATS)에 삽입할 때 발생하는 문제를 수정했습니다. [#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#67806](https://github.com/ClickHouse/ClickHouse/issues/67806)에 백포트됨: UNION이 포함된 SQL UDF를 다시 로드할 때의 문제를 수정했습니다. 이전에는 서버를 재시작하면 UDF가 무효가 될 수 있었습니다. [#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* [#67834](https://github.com/ClickHouse/ClickHouse/issues/67834)에 백포트됨: `JSONMergePatch` 함수의 잠재적인 스택 오버플로우를 수정했습니다. 이전 이름이 잘못되었기 때문에 이 함수 이름을 `jsonMergePatch`에서 `JSONMergePatch`로 변경했습니다. 이전 이름도 호환성을 위해 계속 유지됩니다. 함수의 오류 진단도 개선했습니다. 이 변경으로 [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304)가 해결됩니다. [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#68206](https://github.com/ClickHouse/ClickHouse/issues/68206)에 백포트됨: 프레디케이트에 비결정적 함수가 있을 때 `count()` 결과가 잘못되는 문제를 수정했습니다. [#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#68089](https://github.com/ClickHouse/ClickHouse/issues/68089)에 백포트됨: 사용 가능한 CPU 수가 제한된 컨테이너 환경에서 최대 thread 소프트 리밋 계산을 수정했습니다. [#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* [#68120](https://github.com/ClickHouse/ClickHouse/issues/68120)에 백포트됨: 새 분석기에서 뮤테이션 수행 시 변경되지 않은 파트를 스키핑하지 못하던 문제를 수정했습니다. 이전에는 분석기가 활성화된 경우, 프레디케이트상 뮤테이션이 해당 파트에 영향을 주지 않더라도 파트의 데이터가 뮤테이션에 의해 재작성될 수 있었습니다. [#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
