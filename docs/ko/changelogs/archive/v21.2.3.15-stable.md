<div id="bug-fix">
  #### 오동작
</div>

* 백포트됨 [#20241](https://github.com/ClickHouse/ClickHouse/issues/20241): 여러 `clickhouse-copier`를 실행할 때 조각을 대상 테이블로 이동하지 못해 실패할 수 있던 문제를 수정했습니다. [#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* 백포트됨 [#20296](https://github.com/ClickHouse/ClickHouse/issues/20296): * StorageJoin의 오동작을 수정했습니다. [#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* 백포트됨 [#20389](https://github.com/ClickHouse/ClickHouse/issues/20389): 이제 `MongoDB` 테이블 엔진은 데이터를 읽을 때만 연결을 설정합니다. `ATTACH TABLE`은 더 이상 연결을 시도하지 않습니다. [#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* 백포트됨 [#20270](https://github.com/ClickHouse/ClickHouse/issues/20270): `INSERT SELECT`에서 사용할 때 CTE 관련 문제를 수정했습니다. 이 변경으로 [#20187](https://github.com/ClickHouse/ClickHouse/issues/20187), [#20195](https://github.com/ClickHouse/ClickHouse/issues/20195)도 함께 해결됩니다. [#20211](https://github.com/ClickHouse/ClickHouse/pull/20211) ([Amos Bird](https://github.com/amosbird)).
* 백포트됨 [#20329](https://github.com/ClickHouse/ClickHouse/issues/20329): 종료 중 구성을 다시 불러오는 과정에서 드물게 발생하던 server 크래시를 수정했습니다. [#19689](https://github.com/ClickHouse/ClickHouse/issues/19689)를 수정합니다. [#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* 백포트됨 [#20324](https://github.com/ClickHouse/ClickHouse/issues/20324): 수직 병합을 지원하지 않는 `MergeTree` 테이블 엔진 계열에서 수직 병합 중 발생하던 예외를 수정했습니다. [#20259](https://github.com/ClickHouse/ClickHouse/issues/20259)를 수정합니다. [#20279](https://github.com/ClickHouse/ClickHouse/pull/20279) ([alesapin](https://github.com/alesapin)).
* 백포트됨 [#20333](https://github.com/ClickHouse/ClickHouse/issues/20333): `*CollapsingMergeTree` 및 `ReplacingMergeTree` 테이블 엔진의 버전 컬럼에는 `DROP` 또는 `RENAME`만 허용하도록 제한했습니다. [#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* 백포트됨 [#20365](https://github.com/ClickHouse/ClickHouse/issues/20365): `ReplicatedMergeTree` 테이블 엔진 계열에서 실패한 백그라운드 작업에 대한 재시도가 지나치게 자주 발생하던 문제를 수정했습니다. 이로 인해 로깅이 과도하게 상세해지고 CPU 부하가 증가할 수 있었습니다. [#20203](https://github.com/ClickHouse/ClickHouse/issues/20203)를 수정합니다. [#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* 백포트됨 [#20379](https://github.com/ClickHouse/ClickHouse/issues/20379): scale이 서로 다른 두 상수 Decimal 사이의 이항 연산에서 잘못된 결과가 나오던 문제를 수정했습니다. [#20283](https://github.com/ClickHouse/ClickHouse/issues/20283)를 수정합니다. [#20339](https://github.com/ClickHouse/ClickHouse/pull/20339) ([Maksim Kita](https://github.com/kitaisreal)).
* 백포트됨 [#20376](https://github.com/ClickHouse/ClickHouse/issues/20376): `join_use_nulls=1`에서 발생하던 null 역참조를 수정했습니다. [#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)).
* 백포트됨 [#20361](https://github.com/ClickHouse/ClickHouse/issues/20361): `RANGE_HASHED()` 딕셔너리에서 잘못된 역참조가 발생하지 않도록 수정했습니다. [#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)).
