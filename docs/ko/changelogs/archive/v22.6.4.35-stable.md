<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)

* [#38242](https://github.com/ClickHouse/ClickHouse/issues/38242)에 백포트됨: 구성에서 레플리카를 제거할 때 `Distributed` async insert에서 발생할 수 있는 크래시를 수정했습니다. [#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#38865](https://github.com/ClickHouse/ClickHouse/issues/38865)에 백포트됨: 병렬 read buffer 사용 시 s3 seekable 읽기를 수정했습니다. (쿼리 중 메모리 사용량에 영향을 주던 문제입니다.) [#38258](https://github.com/ClickHouse/ClickHouse/issues/38258)를 해결했습니다. [#38802](https://github.com/ClickHouse/ClickHouse/pull/38802) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#38853](https://github.com/ClickHouse/ClickHouse/issues/38853)에 백포트됨: `simdjson`을 업데이트했습니다. 이 변경으로 [#38621](https://github.com/ClickHouse/ClickHouse/issues/38621)을 해결했습니다. [#38838](https://github.com/ClickHouse/ClickHouse/pull/38838) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#38942](https://github.com/ClickHouse/ClickHouse/issues/38942)에 백포트됨: 초 단위 설정 프로필을 수정했습니다. [#38896](https://github.com/ClickHouse/ClickHouse/pull/38896) ([Raúl Marín](https://github.com/Algunenano)).
* [#39063](https://github.com/ClickHouse/ClickHouse/issues/39063)에 백포트됨: OvercommitTracker 내부의 메모리 할당은 교착 상태를 유발할 수 있습니다. 로깅이 충분한 정보를 제공하지 않으므로 로깅을 제거했습니다. [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794)를 해결했습니다. [#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* [#39077](https://github.com/ClickHouse/ClickHouse/issues/39077)에 백포트됨: 파일 시스템 캐시 용량이 한계에 도달하는 상황과 겹치는 일부 예외적인 경우에 발생할 수 있는 파일 시스템 캐시 버그를 수정했습니다. [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066)를 해결했습니다. [#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#39151](https://github.com/ClickHouse/ClickHouse/issues/39151)에 백포트됨: attached 상태인 MATERIALIZED VIEW가 연결되어 있고 설정 `extremes = 1`이 활성화된 테이블에 INSERT할 때 발생할 수 있는 오류 `Block structure mismatch`를 수정했습니다. [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) 및 [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729)를 해결했습니다. [#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#39275](https://github.com/ClickHouse/ClickHouse/issues/39275)에 백포트됨: `PREWHERE` 및 순서대로 읽기 최적화가 적용된 SELECT 쿼리에서 발생하는 오류 `Not found column Type in block`를 수정했습니다. [#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#39371](https://github.com/ClickHouse/ClickHouse/issues/39371)에 백포트됨: 기본 인수 `x-max-length` 및 `x-overflow` 없이 RabbitMQ 큐를 선언하도록 수정했습니다. [#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* [#39352](https://github.com/ClickHouse/ClickHouse/issues/39352)에 백포트됨: PostgreSQL 데이터베이스 엔진에서 PostgreSQL 테이블을 가져오는 쿼리가 잘못되던 문제를 수정했습니다. [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502)를 해결했습니다. [#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
