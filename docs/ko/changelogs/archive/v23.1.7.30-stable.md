* [#48585](https://github.com/ClickHouse/ClickHouse/issues/48585)에 백포트됨: 시간대를 업데이트했습니다. 다음 항목이 업데이트되었습니다: Africa/Cairo, Africa/Casablanca, Africa/El&#95;Aaiun, America/Bogota, America/Cambridge&#95;Bay, America/Ciudad&#95;Juarez, America/Godthab, America/Inuvik, America/Iqaluit, America/Nuuk, America/Ojinaga, America/Pangnirtung, America/Rankin&#95;Inlet, America/Resolute, America/Whitehorse, America/Yellowknife, Asia/Gaza, Asia/Hebron, Asia/Kuala&#95;Lumpur, Asia/Singapore, Canada/Yukon, Egypt, Europe/Kirov, Europe/Volgograd, Singapore. [#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#48958](https://github.com/ClickHouse/ClickHouse/issues/48958)에 백포트됨: 최근 업데이트 이후 `dockerd`는 http 포트와 함께 `--tlsverify=false`를 명시적으로 지정해야 합니다. [#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* limit이 있는 grace hash join에서 발생하는 경쟁 상태를 수정했습니다 [#47153](https://github.com/ClickHouse/ClickHouse/pull/47153) ([Vladimir C](https://github.com/vdimir)).
* projection이 포함된 explain graph를 수정했습니다 [#47473](https://github.com/ClickHouse/ClickHouse/pull/47473) ([flynn](https://github.com/ucasfl)).
* polygonsSymDifferenceCartesian에서 발생하는 크래시를 수정했습니다 [#47702](https://github.com/ClickHouse/ClickHouse/pull/47702) ([pufit](https://github.com/pufit)).
* 기능 하나를 제거했습니다 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 딕셔너리에 의존하는 분산 테이블을 로드할 때 발생하는 ClickHouse 시작 오류를 수정했습니다 [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* cache에서 발생할 수 있는 segfault를 수정했습니다 [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* IP 및 UUID 타입 키에 대한 중첩 맵 관련 문제를 수정했습니다 [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* ACL에서 scheme `auth`로 노드가 생성되지 않는 경우가 간헐적으로 발생하던 Keeper 버그를 수정했습니다. [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* IPv4를 UInt와 비교할 수 있도록 수정했습니다 [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
