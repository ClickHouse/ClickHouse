<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#55671](https://github.com/ClickHouse/ClickHouse/issues/55671)에 백포트됨: 데이터베이스가 이미 초기화된 경우 이후 실행 시 다시 초기화할 필요가 없습니다. 이 변경으로 데이터베이스가 1000번의 시도 안에 로드되지 않을 때 컨테이너가 무한 재시작되는 문제를 해결할 수 있습니다(매우 큰 데이터베이스 및 다중 node 구성과 관련). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* [#55734](https://github.com/ClickHouse/ClickHouse/issues/55734)에 백포트됨: 통합 check Python script가 `gh api url`을 사용하도록 수정하고, CI 테스트용 Readme를 추가했습니다. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
* [#55829](https://github.com/ClickHouse/ClickHouse/issues/55829)에 백포트됨: tgz의 sha512를 확인하고, Keeper에는 적절한 리포지토리를 사용하며, tarball package용 TGZ.sha512 파일에는 파일명만 기록합니다. [#31473](https://github.com/ClickHouse/ClickHouse/issues/31473)의 선행 조건입니다. [#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* zero-copy 없이 S3 기반의 복제된 MergeTree에서 분리된 파티션을 삭제할 수 없던 문제를 수정했습니다. [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* 순환 alias가 있을 때 QueryNormalizer에서 발생하던 크래시를 수정했습니다. [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* 희소 컬럼에서 윈도우 함수가 올바르게 동작하지 않던 문제를 수정했습니다. [#55895](https://github.com/ClickHouse/ClickHouse/pull/55895) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
