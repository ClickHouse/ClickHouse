* [#54683](https://github.com/ClickHouse/ClickHouse/issues/54683)에 백포트됨: 매번 push할 때마다 이를 빌드하고 업로드하는 것은 그만한 가치가 없습니다. [#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55407](https://github.com/ClickHouse/ClickHouse/issues/55407)에 백포트됨: `clickhouse-server` 패키지에서 standalone `clickhouse-keeper`를 실행할 때 발생하는 이슈를 해결합니다. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55723](https://github.com/ClickHouse/ClickHouse/issues/55723)에 백포트됨: gh api url을 사용하도록 integration check Python script를 수정하고 CI tests용 Readme를 추가합니다. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
