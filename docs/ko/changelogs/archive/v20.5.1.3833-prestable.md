  ### v20.4.1.3177-프리스테이블과 비교한 ClickHouse 릴리스 v20.5.1.3833-프리스테이블 FIXME

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* `experimental_use_processors` 설정을 제거했습니다. 이제 기본적으로 활성화됩니다. [#10924](https://github.com/ClickHouse/ClickHouse/pull/10924) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `input_format_with_names_use_header` 설정이 기본적으로 활성화됩니다. 이 변경은 입력 형식 `-WithNames` 및 `-WithNamesAndTypes`의 파싱에 영향을 줍니다. [#10937](https://github.com/ClickHouse/ClickHouse/pull/10937) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* user-level setting이 잘못된 위치에 지정된 경우를 확인하는 검사 항목을 추가했습니다. user-level settings는 특정 사용자 profile에 대해 `users.xml`의 `<profile>` 섹션 내부에 지정해야 하며(기본 설정은 `<default>`), 그렇지 않으면 로그에 예외 메시지를 남기고 server가 시작되지 않습니다. 이 변경은 [#9051](https://github.com/ClickHouse/ClickHouse/issues/9051)을 수정합니다. 이 검사를 건너뛰려면 설정을 올바른 위치로 옮기거나 `config.xml`에 `<skip_check_for_incorrect_settings>1</skip_check_for_incorrect_settings>`를 추가할 수 있습니다. [#11449](https://github.com/ClickHouse/ClickHouse/pull/11449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* COUNT(DISTINCT) 및 `uniq` 집계 함수 family가 널 허용이 아닌 결과를 반환하도록 변경했습니다. 전달된 값이 모두 NULL이면 대신 0을 반환합니다. 이는 SQL 호환성을 향상합니다. [#11661](https://github.com/ClickHouse/ClickHouse/pull/11661) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="new-feature">
  #### 새 기능

[#10232](https://github.com/ClickHouse/ClickHouse/pull/10232) ([Margarita Konnova [MARK]](https://github.com/margaritiko)).
* PostgreSQL wire 프로토콜을 구현했습니다. [#10242](https://github.com/ClickHouse/ClickHouse/pull/10242) ([Movses Elbakian](https://github.com/MovElb)).
* FINAL이 있는 SELECT는 병렬로 실행됩니다. 사용되는 스레드 수를 제한하기 위한 `max_final_threads` 설정도 추가했습니다. [#10463](https://github.com/ClickHouse/ClickHouse/pull/10463) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

* WHERE 절의 조건을 만족하는 만료된 행의 부분 집합을 삭제하는 기능을 추가했습니다. 또한 GROUP BY 절에 지정된 집계 결과로 만료된 행을 대체하는 기능도 추가했습니다. [#10537](https://github.com/ClickHouse/ClickHouse/pull/10537) ([expl0si0nn](https://github.com/expl0si0nn)).
* (Linux 전용) 이제 ClickHouse 서버는 쿼리별 시스템 메트릭(CPU 및 I/O용)을 수집하기 위해 `clickhouse` 바이너리에 CAP&#95;NET&#95;ADMIN capability가 부여되지 않은 경우 ProcfsMetricsProvider로 폴백을 시도합니다. [#10544](https://github.com/ClickHouse/ClickHouse/pull/10544) ([Alexander Kazakov](https://github.com/Akazz)).
* * Arrow IPC File 포맷(입력 및 출력) 추가 - Parquet 입력 형식에서 `resetParser()`가 올바르게 작동하지 않던 문제 수정 - RandomAccessFiles용 ORC에 zero-copy 최적화 추가 - 입력 Parquet 및 ORC 포맷에 누락된 halffloat 유형 추가 ... [#10580](https://github.com/ClickHouse/ClickHouse/pull/10580) ([Zhanna](https://github.com/FawnD2)).
* 4 MiB보다 더 세밀한 세분화 수준으로 메모리를 프로파일링할 수 있게 했습니다. 무작위 메모리 할당/해제를 포착하는 샘플링 메모리 프로파일러도 추가했습니다. [#10598](https://github.com/ClickHouse/ClickHouse/pull/10598) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 줄바꿈, 공백 및/또는 쉼표로 구분된 JSON 객체 시퀀스를 허용하는 새 입력 형식 `JSONAsString`을 추가했습니다. [#10607](https://github.com/ClickHouse/ClickHouse/pull/10607) ([Kruglov Pavel](https://github.com/Avogar)).
* 데이터를 저장하거나 캐싱하지 않고, 각 쿼리마다 source에서 모든 데이터를 직접 로드하는 새 레이아웃 `direct`를 추가했습니다. [#10622](https://github.com/ClickHouse/ClickHouse/pull/10622) ([Artem Streltsov](https://github.com/kekekekule)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 테이블 sorting key를 고려한 GROUP BY 최적화. [#9113](https://github.com/ClickHouse/ClickHouse/pull/9113) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* 집계 함수 밖으로 산술 연산을 꺼내는 새로운 최적화. [#10047](https://github.com/ClickHouse/ClickHouse/pull/10047) ([Ruslan](https://github.com/kamalov-ruslan)).
* 이 기능은 GROUP BY 절에서 다른 키에 대한 함수를 제거합니다. [#10051](https://github.com/ClickHouse/ClickHouse/pull/10051) ([Victor Grishanin](https://github.com/xPoSx)).
* 최적의 함수 구현을 선택해 디스패치할 수 있도록 런타임 CPU 감지를 추가했습니다. 여러 타깃에 대한 codegeneration 지원도 추가했습니다. 이로써 [#1017](https://github.com/ClickHouse/ClickHouse/issues/1017)이 해결됩니다. [#10058](https://github.com/ClickHouse/ClickHouse/pull/10058) ([DimasKovas](https://github.com/DimasKovas)).
* 서브쿼리에서 중복된 ORDER BY와 DISTINCT를 제거합니다. [#10067](https://github.com/ClickHouse/ClickHouse/pull/10067) ([Mikhail Malafeev](https://github.com/demo-99)).
* MergeJoin에서 left table의 더 큰 파트를 정렬합니다. 왼쪽 block을 메모리에 버퍼링합니다. 왼쪽 block 버퍼 크기를 관리하기 위해 `partial_merge_join_left_table_buffer_bytes` 설정을 추가했습니다. [#10601](https://github.com/ClickHouse/ClickHouse/pull/10601) ([Artem Zuikov](https://github.com/4ertus2)).
* 외부 딕셔너리를 읽는 함수는 호출할 때마다 딕셔너리를 가져오고 접근 권한을 확인하는 작업을 한 번만 수행합니다. [#10928](https://github.com/ClickHouse/ClickHouse/pull/10928) ([Vitaly Baranov](https://github.com/vitlibar)).
* 불필요한 일부 데이터 이동 작업을 제거해 radix sort를 개선했습니다. [#10981](https://github.com/ClickHouse/ClickHouse/pull/10981) ([Arslan Gumerov](https://github.com/g-arslan)).
* `sum` 집계 함수를 사용하고 GROUP BY 키가 없는 쿼리가 훨씬 더 빠르게 실행되도록 개선했습니다. [#10992](https://github.com/ClickHouse/ClickHouse/pull/10992) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 기본적으로 clickhouse binary에 mlock을 활성화합니다. 이렇게 하면 높은 IO 부하에서 clickhouse executable이 페이지 아웃되는 것을 방지할 수 있습니다. [#11139](https://github.com/ClickHouse/ClickHouse/pull/11139) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ORDER BY`와 작은 `LIMIT`(`max_block_size`보다 작은 경우)가 있는 쿼리의 성능을 개선했습니다. [#11171](https://github.com/ClickHouse/ClickHouse/pull/11171) ([Provet](https://github.com/Provet)).
* 작은 blocks가 생성될 때(병렬 parsing에서 일반적인 경우) INSERT SELECT 또는 clickhouse-client를 통한 INSERT 쿼리의 성능을 개선했습니다. 이로써 [#11275](https://github.com/ClickHouse/ClickHouse/issues/11275)가 해결됩니다. DEFAULT 필드에서 CONSTRAINT가 동작하지 않던 문제를 수정했습니다. 이로써 [#11273](https://github.com/ClickHouse/ClickHouse/issues/11273)가 해결됩니다. TEMPORARY tables에서 CONSTRAINTS가 무시되던 문제를 수정했습니다. 이로써 [#11274](https://github.com/ClickHouse/ClickHouse/issues/11274)가 해결됩니다. [#11276](https://github.com/ClickHouse/ClickHouse/pull/11276) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Pretty 형식을 사용할 때 interactive mode에서 `clickhouse-client`의 성능을 개선했습니다. 이전 버전에서는 UTF-8 string의 표시 너비를 계산하는 데 상당한 시간이 소요될 수 있었습니다. 이로써 [#11323](https://github.com/ClickHouse/ClickHouse/issues/11323)가 해결됩니다. [#11323](https://github.com/ClickHouse/ClickHouse/pull/11323) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 모든 연산을 &quot;any&quot; 함수 밖으로 꺼내는 새로운 최적화. [#11529](https://github.com/ClickHouse/ClickHouse/pull/11529) ([Ruslan](https://github.com/kamalov-ruslan)).
* AggregatingMergeTree의 머지 속도를 개선합니다. 이는 1년도 더 전에 [#4348](https://github.com/ClickHouse/ClickHouse/issues/4348) (버전 19.3)에서 도입된 성능 저하를 수정합니다. [#11534](https://github.com/ClickHouse/ClickHouse/pull/11534) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 여러 레플리카가 머지, 뮤테이션, 파티션 삭제, 이동 및 대체 작업을 동시에 할당할 수 있도록 합니다. 이로써 [#10367](https://github.com/ClickHouse/ClickHouse/issues/10367)이 해결됩니다. [#11639](https://github.com/ClickHouse/ClickHouse/pull/11639) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이 최적화는 SELECT 절에서 GROUP BY 키에 대한 min/max/any 집계 함수를 제거합니다. [#11667](https://github.com/ClickHouse/ClickHouse/pull/11667) ([Victor Grishanin](https://github.com/xPoSx)).
