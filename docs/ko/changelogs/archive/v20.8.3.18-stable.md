<div id="bug-fix">
  #### 오동작
</div>

* [#14600](https://github.com/ClickHouse/ClickHouse/issues/14600)에 백포트됨: 매우 큰 매개변수에서 발생한 오버플로우로 인해 결과에 드물게 나타날 수 있었던 combinator `-Resample`이 적용된 함수의 segfault를 수정했습니다. [#14562](https://github.com/ClickHouse/ClickHouse/pull/14562) ([Anton Popov](https://github.com/CurtizJ)).
* [#14727](https://github.com/ClickHouse/ClickHouse/issues/14727)에 백포트됨: StorageReplicatedMergeTree 엔진의 CreateQuery 중 ZooKeeper 예외가 발생한 후 데이터 디렉터리를 정리하도록 수정했습니다. [#14563](https://github.com/ClickHouse/ClickHouse/pull/14563) ([Bharat Nallan](https://github.com/bharatnc)).
* [#14653](https://github.com/ClickHouse/ClickHouse/issues/14653)에 백포트됨: `lc->isNullable()`와 `ls->getDictionaryPtr()->isNullable()` 모두 올바른 결과를 반환하지 않았기 때문에 검사 로직을 추가했습니다. [#14591](https://github.com/ClickHouse/ClickHouse/pull/14591) ([Mike Kot](https://github.com/myrrc)).
* [#14666](https://github.com/ClickHouse/ClickHouse/issues/14666)에 백포트됨: 결과 컬럼의 decimal scale이 잘못되어 발생하던 Decimal 곱셈 결과 오류를 수정했습니다. [#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)).
* [#14793](https://github.com/ClickHouse/ClickHouse/issues/14793)에 백포트됨: assignment 표현식과 상수 값(예: `UPDATE x = 42`)에 널 허용 컬럼이 있는 `ALTER UPDATE` mutation으로 인해 컬럼에 잘못된 값이 기록되거나 segfault가 발생하던 문제를 수정했습니다. [#13634](https://github.com/ClickHouse/ClickHouse/issues/13634), [#14045](https://github.com/ClickHouse/ClickHouse/issues/14045)를 해결합니다. [#14646](https://github.com/ClickHouse/ClickHouse/pull/14646) ([alesapin](https://github.com/alesapin)).
* [#14722](https://github.com/ClickHouse/ClickHouse/issues/14722)에 백포트됨: `ALTER ... MODIFY QUERY` 실행 시 materialized view의 metadata에서 default database name이 누락되던 문제를 수정했습니다. [#14664](https://github.com/ClickHouse/ClickHouse/pull/14664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#14910](https://github.com/ClickHouse/ClickHouse/issues/14910)에 백포트됨: StorageFile(fd)에 INSERT를 시도할 때 발생하던 SIGSEGV를 수정했습니다. [#14887](https://github.com/ClickHouse/ClickHouse/pull/14887) ([Azat Khuzhin](https://github.com/azat)).
* [#14943](https://github.com/ClickHouse/ClickHouse/issues/14943)에 백포트됨: `extractAllGroups` 함수의 일부 호출에서 &quot;Memory limit exceeded&quot; 오류가 발생할 수 있던 문제를 수정했습니다. 이 변경으로 [#13383](https://github.com/ClickHouse/ClickHouse/issues/13383)도 해결됩니다. [#14889](https://github.com/ClickHouse/ClickHouse/pull/14889) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
