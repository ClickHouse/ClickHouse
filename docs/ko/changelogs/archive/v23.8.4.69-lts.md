<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673)에 백포트됨: 데이터베이스가 이미 초기화된 경우, 이후 실행 시 다시 초기화할 필요가 없습니다. 이는 데이터베이스가 1000번의 시도 안에 로드되지 않을 때 컨테이너가 무한 재시작되는 문제를 해결할 가능성이 있습니다(매우 큰 데이터베이스 및 다중 노드 구성에서 해당). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293)에 백포트됨: submodule이 포함된 소스 코드를 Darwin 전용 build 작업에서 빌드합니다. 이를 사용하면 submodule을 체크아웃하지 않고도 ClickHouse를 빌드할 수 있습니다. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366)에 백포트됨: clickhouse-server package에서 standalone clickhouse-keeper를 실행할 때 발생하는 문제를 해결했습니다. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725)에 백포트됨: gh API URL을 사용하도록 통합 check용 Python script를 수정하고, CI 테스트용 README를 추가했습니다. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* 백포트됨 [#55304](https://github.com/ClickHouse/ClickHouse/issues/55304): MaterializedPostgreSQL에서 `Invalid number of rows in Chunk` 오류를 수정했습니다(PostgreSQL 버전 &gt;= 13에서 발생할 수 있었습니다). [#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 백포트됨 [#55018](https://github.com/ClickHouse/ClickHouse/issues/55018): 사용 중단된 포맷 설정을 별도 섹션으로 옮기고, 이를 전체 포맷 설정과 함께 사용하도록 하여 사용 중단된 포맷 설정 사용 시 `Unknown setting` 예외가 발생하지 않도록 했습니다. [#54792](https://github.com/ClickHouse/ClickHouse/issues/54792) 해결. ### 사용자 대상 변경 사항에 대한 문서 항목. [#54855](https://github.com/ClickHouse/ClickHouse/pull/54855) ([Kruglov Pavel](https://github.com/Avogar)).
* 백포트됨 [#55097](https://github.com/ClickHouse/ClickHouse/issues/55097): quorum을 기다리는 동안 Keeper 재시도가 발생하면 삽입 quorum이 잘못 충족된 것으로 표시될 수 있던 문제를 수정했습니다. [#54543](https://github.com/ClickHouse/ClickHouse/issues/54543) 수정. [#55026](https://github.com/ClickHouse/ClickHouse/pull/55026) ([Igor Nikonov](https://github.com/devcrafter)).
* 백포트됨 [#55473](https://github.com/ClickHouse/ClickHouse/issues/55473): 동일한 인덱스나 프로젝션이 정의되지 않은 테이블에서 파티션을 ATTACH하지 못하도록 했습니다. [#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 백포트됨 [#55461](https://github.com/ClickHouse/ClickHouse/issues/55461): 일부 `send_data_threads`가 시작된 뒤 `ShellCommandSource` 생성자에서 예외가 발생하면 해당 스레드를 `join()`해야 하며, 그렇지 않으면 `ThreadFromGlobalPool` destructor에서 abort()가 트리거됩니다. [#55091](https://github.com/ClickHouse/ClickHouse/issues/55091) 수정. [#55103](https://github.com/ClickHouse/ClickHouse/pull/55103) ([Alexander Gololobov](https://github.com/davenger)).
* 백포트됨 [#55412](https://github.com/ClickHouse/ClickHouse/issues/55412): 존재하지 않는 ClickHouse 역할에 대한 LDAP 할당 역할 업데이트에서 발생하는 데드락을 수정했습니다. [#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* 백포트됨 [#55323](https://github.com/ClickHouse/ClickHouse/issues/55323): fs cache의 백그라운드 다운로드 문제를 수정했습니다. [#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 백포트됨 [#55349](https://github.com/ClickHouse/ClickHouse/issues/55349): 희소 컬럼에서 함수 실행 시 발생하던 문제를 수정했습니다(`DB::Exception: isDefaultAt is not implemented for Function: while executing 'FUNCTION Capture` 오류 수정). [#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* 백포트됨 [#55475](https://github.com/ClickHouse/ClickHouse/issues/55475): S3 기반의 `ReplicatedMergeTree` 엔진 계열에서( zero-copy 복제 없음) 분리된 파티션을 삭제할 수 없던 문제를 수정했습니다. [#55225](https://github.com/ClickHouse/ClickHouse/issues/55225) 수정. 배열 또는 Nested 컬럼과 같은 복잡한 데이터 타입에서 S3에 방치된 블롭이 남는 버그를 수정했습니다.
