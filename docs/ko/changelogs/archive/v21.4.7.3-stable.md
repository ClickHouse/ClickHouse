<div id="bug-fix">
  #### 오동작 수정
</div>

* [#23971](https://github.com/ClickHouse/ClickHouse/issues/23971)에 백포트됨: 오래된 `ReplicatedMergeTree` 레플리카 복구 과정의 버그를 수정했습니다. 레플리카의 다운타임 중 `ALTER` 쿼리가 실행되면 오래된 레플리카가 일부 메타데이터 업데이트를 무시할 수 있었습니다. [#23742](https://github.com/ClickHouse/ClickHouse/pull/23742) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23819](https://github.com/ClickHouse/ClickHouse/issues/23819)에 백포트됨: 결과가 비어 있을 때 `PREWHERE`와 row policy 필터가 동시에 적용되면 발생하는 크래시를 수정했습니다. [#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* [#23816](https://github.com/ClickHouse/ClickHouse/issues/23816)에 백포트됨: materialized view에서 참조되는 경우 `CLEAR COLUMN`이 작동하지 않던 문제를 수정했습니다. [#23764](https://github.com/ClickHouse/ClickHouse/issues/23764)를 해결했습니다. [#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
* [#23831](https://github.com/ClickHouse/ClickHouse/issues/23831)에 백포트됨: `GLOBAL IN/JOIN`과 `use_hedged_requests`를 사용하는 쿼리에서 발생하는 `Can't initialize pipeline with empty pipe` 오류를 수정했습니다. [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431)을 해결했습니다. [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23930](https://github.com/ClickHouse/ClickHouse/issues/23930)에 백포트됨: HashedDictionary 복합 키 update field의 초기 적재 문제를 수정했습니다. [#23800](https://github.com/ClickHouse/ClickHouse/issues/23800)을 해결했습니다. [#23824](https://github.com/ClickHouse/ClickHouse/pull/23824) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23957](https://github.com/ClickHouse/ClickHouse/issues/23957)에 백포트됨: source에 중복이 있는 CACHE() dictionary에서 keys 메트릭 집계가 잘못되던 문제를 수정했습니다(`DictCacheKeysRequestedMiss` 오버플로우 발생). [#23929](https://github.com/ClickHouse/ClickHouse/pull/23929) ([Azat Khuzhin](https://github.com/azat)).
* [#24003](https://github.com/ClickHouse/ClickHouse/issues/24003)에 백포트됨: external GROUP BY와 overflow 행에서 발생하는 SIGSEGV를 수정했습니다(예: `SELECT FROM GROUP BY WITH TOTALS SETTINGS max_bytes_before_external_group_by>0, max_rows_to_group_by>0, group_by_overflow_mode='any', totals_mode='before_having'` 같은 쿼리). [#23962](https://github.com/ClickHouse/ClickHouse/pull/23962) ([Azat Khuzhin](https://github.com/azat)).
* [#24188](https://github.com/ClickHouse/ClickHouse/issues/24188)에 백포트됨: 일부 `ALTER PARTITION` 쿼리로 인해 복제 큐에서 `Part A intersects previous part B` 및 `Unexpected merged part C intersecting drop range D` 오류가 발생할 수 있었습니다. 이 문제를 수정했습니다. [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296)을 해결했습니다. [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24031](https://github.com/ClickHouse/ClickHouse/issues/24031)에 백포트됨: MergeJoin에서 발생하던 크래시를 수정했으며, [#24010](https://github.com/ClickHouse/ClickHouse/issues/24010)을 해결했습니다. [#24013](https://github.com/ClickHouse/ClickHouse/pull/24013) ([Vladimir C](https://github.com/vdimir)).
* [#24141](https://github.com/ClickHouse/ClickHouse/issues/24141)에 백포트됨: 버그: `select xxx final`에 대해 explain pipeline을 실행하면 잘못된 pipeline이 표시됩니다: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* [#24171](https://github.com/ClickHouse/ClickHouse/issues/24171)에 백포트됨: 드물게 부분적으로만 초기화된 테이블이 쓰기 요청(insert/alter 등)을 처리할 수 있게 되는 버그를 수정했습니다. 이제 이러한 테이블은 readonly 모드가 됩니다. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* [#24215](https://github.com/ClickHouse/ClickHouse/issues/24215)에 백포트됨: 고부하 상황에서 RBAC에 발생할 수 있는 경쟁 상태를 수정했습니다. 이 PR은 [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090), [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134)를 수정합니다. [#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#24243](https://github.com/ClickHouse/ClickHouse/issues/24243)에 백포트됨: 쿼리 실행 중 hdfs에 접근할 수 없게 되면서 발생하는 비정상적인 server 종료를 수정했습니다. [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117)을 해결합니다. [#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
