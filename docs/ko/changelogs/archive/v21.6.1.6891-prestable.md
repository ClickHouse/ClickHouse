<div id="clickhouse-release-v21616891-prestable-fixme-as-compared-to-v21516601-prestable">
  ### ClickHouse 릴리스 v21.6.1.6891-prestable FIXME, v21.5.1.6601-prestable 대비

<div id="new-feature">
  #### 새 기능
</div>

* MergeTree* 테이블에 PROJECTION 지원을 추가했습니다. [#20202](https://github.com/ClickHouse/ClickHouse/pull/20202) ([Amos Bird](https://github.com/amosbird)).
* `indexHint` 함수를 다시 추가했습니다. 이는 [#21238](https://github.com/ClickHouse/ClickHouse/issues/21238) 관련 변경입니다. [https://github.com/ClickHouse/ClickHouse/pull/9542](https://github.com/ClickHouse/ClickHouse/pull/9542)를 되돌리고, [#9540](https://github.com/ClickHouse/ClickHouse/issues/9540)을 수정합니다. [#21304](https://github.com/ClickHouse/ClickHouse/pull/21304) ([Amos Bird](https://github.com/amosbird)).
* 1. 집계 함수 sumCount를 추가했습니다. 이 함수는 sum과 count, 두 개의 필드로 구성된 튜플을 반환합니다. [#21337](https://github.com/ClickHouse/ClickHouse/pull/21337) ([hexiaoting](https://github.com/hexiaoting)).
* Docker 환경에서 정상적으로 작동하는, 보안 수준이 더 낮은 S3용 IMDS 자격 증명 공급자를 추가했습니다. [#21852](https://github.com/ClickHouse/ClickHouse/pull/21852) ([Vladimir Chebotarev](https://github.com/excitoon)).
* * 타임스탬프를 저장해 머지 중에도 순서를 유지하면서 연속된 행 사이의 차이를 합산하는 새로운 집계 함수 `deltaSumTimestamp`. [#21888](https://github.com/ClickHouse/ClickHouse/pull/21888) ([Russ Frank](https://github.com/rf)).
* * LDAP: Active Directory 그룹을 ClickHouse 역할에 매핑할 때 사용할 수 있도록 user DN 감지 기능을 구현했습니다. [#22228](https://github.com/ClickHouse/ClickHouse/pull/22228) ([Denis Glazachev](https://github.com/traceon)).
* 새로운 함수 `arrayProduct`를 도입했습니다. 이 함수는 배열을 매개변수로 받아 배열의 모든 요소를 곱한 값을 반환합니다. 이슈 [#21613](https://github.com/ClickHouse/ClickHouse/issues/21613)를 종료했습니다. [#22242](https://github.com/ClickHouse/ClickHouse/pull/22242) ([hexiaoting](https://github.com/hexiaoting)).
* `EXPLAIN PIPELINE` 쿼리에 `indexes` 설정(boolean, 기본적으로 비활성화)을 추가했습니다. 활성화하면 적용된 각 인덱스에 대해 사용된 인덱스, 필터링된 파트 수, 그래뉼 수를 표시합니다. `MergeTree*` 테이블에서 지원됩니다. [#22352](https://github.com/ClickHouse/ClickHouse/pull/22352) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `EXPLAIN PLAN` 쿼리에 `json` 설정(boolean, 기본값 0)을 추가했습니다. 활성화하면 쿼리 출력이 단일 `JSON` 행으로 제공됩니다. 불필요한 escaping을 피하려면 `TSVRaw` 포맷을 사용하는 것이 좋습니다. [#23082](https://github.com/ClickHouse/ClickHouse/pull/23082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `SYSTEM QUERY RELOAD MODEL`, `SYSTEM QUERY RELOAD MODELS`를 추가했습니다. [#18722](https://github.com/ClickHouse/ClickHouse/issues/18722)를 종료했습니다. [#23182](https://github.com/ClickHouse/ClickHouse/pull/23182) ([Maksim Kita](https://github.com/kitaisreal)).
* LocalServer용 진행률 표시줄을 추가하고, 이를 Client와 Local에서 공통으로 사용하도록 통합했습니다. [#23196](https://github.com/ClickHouse/ClickHouse/pull/23196) ([Egor Savin](https://github.com/Amesaru)).
* DatabaseMemory에서 DDL 딕셔너리를 지원합니다. [#22354](https://github.com/ClickHouse/ClickHouse/issues/22354)를 종료했습니다. `DETACH DICTIONARY PERMANENTLY` 지원을 추가했습니다. atomic 데이터베이스 엔진에서 `EXCHANGE DICTIONARIES`를 지원합니다. `RENAME DICTIONARY`를 사용해 데이터베이스 간 딕셔너리를 이동할 수 있도록 지원을 추가했습니다. [#23436](https://github.com/ClickHouse/ClickHouse/pull/23436) ([Maksim Kita](https://github.com/kitaisreal)).
* URL 테이블 함수에서 세그먼트처럼 동작하는 글롭 `{...}`와 구분자 `|`를 사용하는 failover 옵션을 허용합니다. [#17181](https://github.com/ClickHouse/ClickHouse/issues/17181)를 종료했습니다. [#23446](https://github.com/ClickHouse/ClickHouse/pull/23446) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `insert_null_as_default` = 1이면 `INSERT ... SELECT` 및 `INSERT ... SELECT ... UNION ALL ...` 쿼리에서 NULL 대신 기본값을 삽입합니다. [#22832](https://github.com/ClickHouse/ClickHouse/issues/22832)를 종료했습니다. [#23524](https://github.com/ClickHouse/ClickHouse/pull/23524) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 테이블 comment를 구현했습니다. [#23225](https://github.com/ClickHouse/ClickHouse/issues/23225)를 종료했습니다. [#23548](https://github.com/ClickHouse/ClickHouse/pull/23548) ([flynn](https://github.com/ucasfl)).
* 새로운 함수 `arrayProduct`를 도입했습니다. 이 함수는 배열을 매개변수로 받아 배열의 모든 요소를 곱한 값을 반환합니다. [#21613](https://github.com/ClickHouse/ClickHouse/issues/21613)를 종료했습니다. [#23782](https://github.com/ClickHouse/ClickHouse/pull/23782) ([Maksim Kita](https://github.com/kitaisreal)).
* Postgres와 유사한 캐스트 연산자(`::`)를 추가했습니다. 예: `[1, 2]::Array(UInt8)`, `0.1::Decimal(4, 4)`, `number::UInt16`. [#23871](https://github.com/ClickHouse/ClickHouse/pull/23871) ([Anton Popov](https://github.com/CurtizJ)).
* ... [#23910](https://github.com/ClickHouse/ClickHouse/pull/23910) ([Xiang Zhou](https://github.com/javainthinking)).
* 함수 `splitByRegexp`를 추가했습니다. [#24077](https://github.com/ClickHouse/ClickHouse/pull/24077) ([abel-cheng](https://github.com/abel-cheng)).
* `system.stack_trace`에 `thread_name` 컬럼을 추가했습니다. 이로써 [#23256](https://github.com/ClickHouse/ClickHouse/issues/23256)가 해결되었습니다. [#24124](https://github.com/ClickHouse/ClickHouse/pull/24124) ([abel-cheng](https://github.com/abel-cheng)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* `compile_expressions` 설정이 기본적으로 활성화됩니다. 이 설정이 활성화되면 단순한 함수와 연산자의 조합이 런타임에 LLVM을 사용해 네이티브 코드로 컴파일됩니다. [#8482](https://github.com/ClickHouse/ClickHouse/pull/8482) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ORC 입력 형식은 전체 테이블을 한 번에 메모리로 읽는 대신 stripe 단위로 읽도록 개선되었습니다. 파일 크기가 매우 큰 경우 메모리 사용량이 크게 증가하는 문제를 줄입니다. [#23102](https://github.com/ClickHouse/ClickHouse/pull/23102) ([Chao Ma](https://github.com/godliness)).
* `re2` 라이브러리를 업데이트했습니다. 정규식 일치 성능이 개선되었습니다. 또한 이 PR에서는 gcc-11과의 호환성도 추가했습니다. [#24196](https://github.com/ClickHouse/ClickHouse/pull/24196) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### 개선 사항
</div>

* Arrow, Parquet 및 ORC 포맷에서 데이터를 삽입하고 조회할 때 배열(Array) 데이터 타입을 지원합니다. [#21770](https://github.com/ClickHouse/ClickHouse/pull/21770) ([taylor12805](https://github.com/taylor12805)).
* MySQL 테이블 엔진, 딕셔너리 소스 및 MaterializeMySQL의 소규모 데이터 fetch를 위해 설정 `external_storage_max_read_rows` 및 `external_storage_max_read_rows`를 추가했습니다. [#22697](https://github.com/ClickHouse/ClickHouse/pull/22697) ([TCeason](https://github.com/TCeason)).
* S3에서 HTTP 연결이 끊어질 경우 재시도하도록 지원합니다. [#22988](https://github.com/ClickHouse/ClickHouse/pull/22988) ([Vladimir Chebotarev](https://github.com/excitoon)).
* clickhouse-client의 대화형 모드에서 데이터 중간에 진행률 표시줄이 나타나 터미널에 표시된 데이터 일부를 덮어쓸 수 있던 문제를 수정했습니다. 이로써 [#19283](https://github.com/ClickHouse/ClickHouse/issues/19283)를 해결했습니다. [#23050](https://github.com/ClickHouse/ClickHouse/pull/23050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* DiskS3에 대해 MergeTree 파트를 &#39;detached&#39; 디렉터리로 복원할 수 있는 기능을 추가했습니다. [#23112](https://github.com/ClickHouse/ClickHouse/pull/23112) ([Pavel Kovalenko](https://github.com/Jokser)).
* 분산 테이블에 쓸 때 사용할 수 없는 레플리카는 건너뜁니다. [#23152](https://github.com/ClickHouse/ClickHouse/pull/23152) ([Amos Bird](https://github.com/amosbird)).
* `join_use_nulls`에서 LowCardinality의 null 허용을 지원하며, [#15101](https://github.com/ClickHouse/ClickHouse/issues/15101)을 해결합니다. [#23237](https://github.com/ClickHouse/ClickHouse/pull/23237) ([Vladimir C](https://github.com/vdimir)).
* 문제를 일으킬 수 있다는 근거가 있어 설정 `use_hedged_requests` 및 `async_socket_for_remote`를 비활성화했습니다. [#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantile(s)TDigest`를 수정했습니다. tdunning/t-digest 3.2+에 따라 singleton centroid를 특별 처리하도록 추가했습니다. 또한 이전 버전 알고리즘 구현에서 centroid가 과도하게 압축되던 버그도 수정했습니다. [#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).
* `MySQL` 스토리지에서 데이터베이스 이름 대신 빈 문자열을 지정할 수 있도록 했습니다. 이 경우 쿼리에는 기본 데이터베이스가 사용됩니다. 이전 버전에서는 SELECT 쿼리에서만 동작했으며, INSERT도 지원하도록 추가했습니다. 이로써 [#19281](https://github.com/ClickHouse/ClickHouse/issues/19281)를 해결했습니다. 이는 `Sphinx` 또는 기타 MySQL 호환 외부 데이터베이스와 작업할 때 유용할 수 있습니다. [#23319](https://github.com/ClickHouse/ClickHouse/pull/23319) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* min&#95;bytes&#95;to&#95;use&#95;mmap&#95;io를 기본적으로 비활성화했습니다. [#23322](https://github.com/ClickHouse/ClickHouse/pull/23322) ([Azat Khuzhin](https://github.com/azat)).
* 사용자가 실수로 `max_distributed_connections` 값을 0으로 설정하는 잘못된 구성을 적용하면, `Distributed` 테이블에 대한 모든 쿼리에서 &quot;logical error&quot;를 포함한 메시지와 함께 예외가 발생했습니다. 하지만 이는 실제로 예상된 동작이지 logical error는 아니므로 예외 메시지가 다소 부정확했습니다. 또한 logical error가 절대 발생하지 않도록 보장하는 CI 환경의 검사도 트리거했습니다. 이제 `max_distributed_connections`가 0으로 잘못 구성된 경우 이를 가능한 최소값(1)으로 처리합니다. [#23348](https://github.com/ClickHouse/ClickHouse/pull/23348) ([Azat Khuzhin](https://github.com/azat)).
* 명시적으로 지정되지 않은 경우 `DateTime` 연산에서 기본 시간대를 유지합니다. 예를 들어, 시간대가 없는 `DateTime` 타입 값에 1초를 더하면 결과도 여전히 시간대가 없는 `DateTime`입니다. 이전 버전에서는 반환된 데이터 타입에 기본 시간대 값이 명시적으로 포함되어 DateTime(&#39;something&#39;)이 되었습니다. 이 변경으로 [#4854](https://github.com/ClickHouse/ClickHouse/issues/4854)가 해결됩니다. [#23392](https://github.com/ClickHouse/ClickHouse/pull/23392) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이전에는 SQL 비호환성으로 인해 MySQL 5.7.9를 지원하지 않았습니다. 이제 MySQL 매개변수 검증은 MaterializeMySQL에 맡깁니다. [#23413](https://github.com/ClickHouse/ClickHouse/pull/23413) ([TCeason](https://github.com/TCeason)).
* 새로운 `SYSTEM RESTART DISK` SQL 명령을 통해 런타임에 S3 디스크 설정을 변경할 수 있습니다. [#23429](https://github.com/ClickHouse/ClickHouse/pull/23429) ([Pavel Kovalenko](https://github.com/Jokser)).
* OPTIMIZE에 `lock&#95;acquire&#95;timeout&#95;for&#95;background&#95;operations`를 적용합니다. [#23623](https://github.com/ClickHouse/ClickHouse/pull/23623) ([Azat Khuzhin](https://github.com/azat)).
* 대형 정수를 production 환경에서 사용할 수 있도록 개선했습니다. `UInt128` 데이터 타입을 지원합니다. `Decimal256` 데이터 타입의 알려진 문제를 수정했습니다. Dictionaries에서 대형 정수를 지원합니다. 대형 정수에 대해 `gcd`/`lcm` 함수를 지원합니다. 배열 검색 및 조건 함수에서 대형 정수를 지원합니다. `LowCardinality(UUID)`를 지원합니다. `generateRandom` 테이블 함수와 `clickhouse-obfuscator`에서 대형 정수를 지원합니다. 스칼라 서브쿼리에서 `UUID`를 반환할 때 발생하는 오류를 수정했습니다. 이 변경으로 [#7834](https://github.com/ClickHouse/ClickHouse/issues/7834)가 해결됩니다. 이 변경으로 [#23936](https://github.com/ClickHouse/ClickHouse/issues/23936)가 해결됩니다. 이 변경으로 [#4176](https://github.com/ClickHouse/ClickHouse/issues/4176)가 해결됩니다. 이 변경으로 [#24018](https://github.com/ClickHouse/ClickHouse/issues/24018)가 해결됩니다. 이 변경으로 [#17828](https://github.com/ClickHouse/ClickHouse/issues/17828)가 해결됩니다. 하위 호환되지 않는 변경 사항: `UUID` 타입 값은 정수와 비교할 수 없습니다. 예를 들어 `uuid != 0` 대신 `uuid != '00000000-0000-0000-0000-000000000000'`를 사용하십시오. [#23631](https://github.com/ClickHouse/ClickHouse/pull/23631) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree 테이블 계열에 `_partition_value` 가상 컬럼을 추가했습니다. 이를 사용하면 결정론적인 방식으로 파티션 프루닝을 수행할 수 있습니다. 이는 뮤테이션용 파티션 매처를 구현하는 데 필요합니다. [#23673](https://github.com/ClickHouse/ClickHouse/pull/23673) ([Amos Bird](https://github.com/amosbird)).
* `async_socket_for_remote`를 기본적으로 활성화합니다. [#23683](https://github.com/ClickHouse/ClickHouse/pull/23683) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* ZooKeeper 세션이 만료된 `ReplicatedMergeTree` 테이블이 있을 때, `select_sequential_consistency`가 활성화된 상태에서 `system.tables`로 일부 테이블의 메타데이터를 조회하면 다음 오류가 발생합니다: `Session expired (Session expired): While executing Tables`. [#23793](https://github.com/ClickHouse/ClickHouse/pull/23793) ([Fuwang Hu](https://github.com/fuwhu)).
* S3 스토리지 및 디스크에 `region` 매개변수를 추가했습니다. [#23846](https://github.com/ClickHouse/ClickHouse/pull/23846) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 서로 다른 로깅 채널별로 서로 다른 로그 레벨을 구성할 수 있도록 했습니다. [#19569](https://github.com/ClickHouse/ClickHouse/issues/19569)를 해결합니다. [#23857](https://github.com/ClickHouse/ClickHouse/pull/23857) ([filimonov](https://github.com/filimonov)).
* `system.distribution_queue`에 `broken_data_files`/`broken_data_compressed_bytes`를 추가했습니다. 손상된 것으로 표시된 분산 테이블에 대한 비동기 삽입 파일 수 메트릭(`BrokenDistributedFilesToInsert`)도 추가했습니다. [#23885](https://github.com/ClickHouse/ClickHouse/pull/23885) ([Azat Khuzhin](https://github.com/azat)).
* 테이블 설정 `rabbitmq_queue_settings_list`를 통해 특정 큐 설정을 추가할 수 있도록 했습니다. ([#23737](https://github.com/ClickHouse/ClickHouse/issues/23737), [#23918](https://github.com/ClickHouse/ClickHouse/issues/23918) 해결). 또한 사용자가 RabbitMQ Setup 전체를 제어할 수 있도록 했습니다. 테이블 설정 `rabbitmq_queue_consume`를 `1`로 설정하면 RabbitMQ 테이블 엔진은 지정된 큐에만 연결하며, exchange, queues, bindings 선언과 같은 RabbitMQ consumer 측 Setup은 수행하지 않습니다. ([#21757](https://github.com/ClickHouse/ClickHouse/issues/21757) 해결). RabbitMQ 테이블이 삭제될 때 적절히 정리되도록 개선하여, 테이블이 직접 생성한 경우 해당 테이블이 선언한 큐와 바인딩된 모든 exchange를 삭제합니다. [#23887](https://github.com/ClickHouse/ClickHouse/pull/23887) ([Kseniia Sumarokova](https://github.com/kssenii)).
