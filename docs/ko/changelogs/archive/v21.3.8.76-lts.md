<div id="improvement">
  #### 개선 사항
</div>

* [#23396](https://github.com/ClickHouse/ClickHouse/issues/23396)에 백포트됨: NULL로만 이루어진 튜플(예: `(NULL, NULL)`)이 `IN` 연산자의 왼쪽에 있고, 오른쪽에 non-NULL 값으로 이루어진 튜플들(예: `SELECT (NULL, NULL) IN ((0, 0), (3, 1))`)이 있을 때, 호환되지 않는 타입 관련 예외를 발생시키는 대신 0을 반환하도록 했습니다. 이 표현식은 `SELECT (NULL, NULL) = (8, 0) OR (NULL, NULL) = (3, 2) OR (NULL, NULL) = (0, 0) OR (NULL, NULL) = (3, 1)`과 같은 구문이 최적화되는 과정에서도 나타날 수 있습니다. 이로써 [#22017](https://github.com/ClickHouse/ClickHouse/issues/22017)이 해결되었습니다. [#22063](https://github.com/ClickHouse/ClickHouse/pull/22063) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23272](https://github.com/ClickHouse/ClickHouse/issues/23272)에 백포트됨: 문제를 일으킬 수 있다는 정황이 있어 설정 `use_hedged_requests`와 `async_socket_for_remote`를 비활성화했습니다. [#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### 오동작 수정
</div>

* [#23232](https://github.com/ClickHouse/ClickHouse/issues/23232)에 백포트됨: default profile에서 `data_type_default_nullable` setting이 enabled된 경우 server 시작에 실패할 수 있던 문제를 수정했습니다. [#22573](https://github.com/ClickHouse/ClickHouse/issues/22573)을 수정합니다. [#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23406](https://github.com/ClickHouse/ClickHouse/issues/23406)에 백포트됨: subquery가 상수로 최적화된 경우 ASTWithAlias에 대해 alias를 우선 사용하도록 QueryAliasVisitor를 수정했습니다. [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924)를 수정합니다. [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401)를 수정합니다. [#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23381](https://github.com/ClickHouse/ClickHouse/issues/23381)에 백포트됨: key column에 조건을 지정해 `MaterializeMySQL`에서 select할 때 발생하던 `Not found column` 오류를 수정했습니다. [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432)를 수정합니다. [#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23284](https://github.com/ClickHouse/ClickHouse/issues/23284)에 백포트됨: primary key가 첫 번째 속성이 아닐 때 DDL로 simple key dictionary를 생성하지 못하던 문제를 수정했습니다. [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236)를 수정합니다. [#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23450](https://github.com/ClickHouse/ClickHouse/issues/23450)에 백포트됨: ReplicatedMergeTree table의 생성과 삭제 사이에 발생하는 매우 드문 (distributed) race condition을 수정했습니다. 이 문제로 인해 복제된 table을 생성하려고 할 때 `node doesn't exist`와 같은 Exception이 발생할 수 있었습니다. [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419)를 수정합니다. [#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23500](https://github.com/ClickHouse/ClickHouse/issues/23500)에 백포트됨: remote query에서 (`async_socket_for_remote`가 enabled된 상태에서) `unknown packet`을 수신했을 때 발생할 수 있는 크래시를 수정했습니다. 아마도 [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167)를 수정합니다. [#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23468](https://github.com/ClickHouse/ClickHouse/issues/23468)에 백포트됨: 컬럼이 primary key에 포함되어 있거나(또는 그 단조 함수인 경우) `optimize_read_in_order` setting이 꺼져 있지 않으면 `COLLATE`와 함께 사용하는 `ORDER BY`가 올바르게 동작하지 않던 문제를 수정했습니다. 이 변경으로 [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379)가 종료됩니다. 이전 버전에서의 우회 방법: `optimize_read_in_order` setting을 끄십시오. [#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23544](https://github.com/ClickHouse/ClickHouse/issues/23544)에 백포트됨: 단일 `Tuple` 인수에 대한 `argMin` 및 `argMax` 지원을 제거했습니다. 해당 코드는 메모리 안전성이 없었습니다. 이 기능은 실수로 추가되었고 사용자에게 혼란을 줄 수 있었습니다. 이 함수들은 나중에 다른 이름으로 다시 도입될 수 있습니다. 이 변경은 [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384)를 수정하고 [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359)를 되돌립니다. [#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23479](https://github.com/ClickHouse/ClickHouse/issues/23479)에 백포트됨: Kafka 스토리지가 `arrow` 및 `arrowstream` 포맷의 메시지를 지원합니다. [#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* [#23499](https://github.com/ClickHouse/ClickHouse/issues/23499)에 백포트됨: Counter 리셋 상황에서 `deltaSum` 집계 함수의 오동작 수정 ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
