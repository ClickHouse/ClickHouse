<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 정수가 부동소수점 데이터 타입으로 정확하게 표현되지 않는 경우, 정수와 부동소수점 수의 비교 방식이 변경되었습니다. 새 버전에서는 반올림 오류가 발생하므로 비교 결과로 false를 반환합니다. 예시: `9223372036854775808.0 != 9223372036854775808`. 이는 `9223372036854775808`이라는 수를 부동소수점 수로는 정확하게 표현할 수 없기 때문입니다(즉 `9223372036854775808.0`은 `9223372036854776000.0`으로 반올림됨). 하지만 이전 버전에서는 이 비교가 두 수를 같다고 판단했습니다. 부동소수점 수 `9223372036854776000.0`을 다시 UInt64로 변환하면 `9223372036854775808`이 되기 때문입니다. 참고로 Python 프로그래밍 언어에서도 이 수들은 같다고 취급됩니다. 다만 이 동작은 CPU 모델에 따라 달라졌으며(일부 범위 밖 숫자에서는 AMD64와 AArch64의 결과가 서로 다름), 이에 따라 비교를 더 정확하게 변경했습니다. 이제 정수와 부동소수점 수는 정수가 부동소수점 타입으로 정확하게 표현될 수 있는 경우에만 같다고 취급됩니다. [#22595](https://github.com/ClickHouse/ClickHouse/pull/22595) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 새 기능
</div>

* 각 배열의 요소(또는 병렬 배열 집합의 각 요소)에 표현식을 적용하고 결과를 누산기에 축적하는 함수 `arrayFold(x1,...,xn,accum -> expression, array1,...,arrayn, init_accum)`를 구현했습니다. [#21589](https://github.com/ClickHouse/ClickHouse/pull/21589) ([Dmitry Krylov](https://github.com/dmalkr)).
* * Apple m1을 지원합니다. [#21639](https://github.com/ClickHouse/ClickHouse/pull/21639) ([changvvb](https://github.com/changvvb)).
* `Distributed` 테이블에 대한 재귀 쿼리의 깊이를 제한하는 설정 `max_distributed_depth`를 추가했습니다. [#20229](https://github.com/ClickHouse/ClickHouse/issues/20229)을 해결했습니다. [#21942](https://github.com/ClickHouse/ClickHouse/pull/21942) ([flynn](https://github.com/ucasfl)).
* 지정된 cluster의 여러 노드에서 `s3`의 파일을 병렬로 처리할 수 있는 테이블 함수를 추가했습니다. [#22012](https://github.com/ClickHouse/ClickHouse/pull/22012) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* MySQL/PostgreSQL 테이블 엔진 / 테이블 함수에서 레플리카를 지원합니다. 세그먼트를 지원하기 위해 MySQL / PostgreSQL 스토리지 위에 wrapper storage를 추가했습니다. [#20969](https://github.com/ClickHouse/ClickHouse/issues/20969)을 해결했습니다. [#22217](https://github.com/ClickHouse/ClickHouse/pull/22217) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 구성 다시 로드 시 catboost model config의 경로를 업데이트했습니다. [#22434](https://github.com/ClickHouse/ClickHouse/pull/22434) ([Kruglov Pavel](https://github.com/Avogar)).
* 비복제 MergeTree 삽입의 중복 제거를 위한 새로운 설정 `non_replicated_deduplication_window`를 추가했습니다. [#22514](https://github.com/ClickHouse/ClickHouse/pull/22514) ([alesapin](https://github.com/alesapin)).
* FlatDictionary에 `initial_array_size`, `max_array_size` 옵션을 추가했습니다. [#22521](https://github.com/ClickHouse/ClickHouse/pull/22521) ([Maksim Kita](https://github.com/kitaisreal)).
* `ALTER TABLE ... FETCH PART ...` 쿼리를 추가했습니다. `FETCH PARTITION`과 비슷하지만 part 하나만 fetch합니다. [#22706](https://github.com/ClickHouse/ClickHouse/pull/22706) ([jasong](https://github.com/songenjie)).
* 딕셔너리에서 `Decimal256` 유형을 지원합니다. [#20979](https://github.com/ClickHouse/ClickHouse/issues/20979)을 해결했습니다. [#22960](https://github.com/ClickHouse/ClickHouse/pull/22960) ([Maksim Kita](https://github.com/kitaisreal)).

* 성능 향상을 위해 함수 정렬을 추가했습니다. [#21431](https://github.com/ClickHouse/ClickHouse/pull/21431) ([Daniel Kutenin](https://github.com/danlark1)).
* 분산 쿼리에서 IN 절 오른쪽 부분의 값 중 세그먼트에 속하지 않는 값은 제외합니다(`optimize_skip_unused_shards_rewrite_in` 기준, 기본적으로 활성화되어 있지만 여전히 `optimize_skip_unused_shards`가 필요함). [#21511](https://github.com/ClickHouse/ClickHouse/pull/21511) ([Azat Khuzhin](https://github.com/azat)).
* localhost와 네이티브 프로토콜로 통신할 때(`clickhouse-client` 또는 분산 쿼리의 server 간 통신) 기본적으로 압축을 비활성화합니다. 일부 가져오기/내보내기 작업의 성능이 향상될 수 있습니다. 이 변경으로 [#22234](https://github.com/ClickHouse/ClickHouse/issues/22234)가 해결됩니다. [#22237](https://github.com/ClickHouse/ClickHouse/pull/22237) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 로컬 파일이 아닌 소스(예: URL)에서 `ArrowStream` 입력 형식을 읽을 때의 성능을 개선합니다. [#22673](https://github.com/ClickHouse/ClickHouse/pull/22673) ([nvartolomei](https://github.com/nvartolomei)).
* AVX2용 dynamic dispatch를 통해 `intDiv`의 성능을 개선합니다. 이 변경으로 [#22314](https://github.com/ClickHouse/ClickHouse/issues/22314)가 해결됩니다. [#23000](https://github.com/ClickHouse/ClickHouse/pull/23000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
