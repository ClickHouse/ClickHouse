<div id="clickhouse-release-v21115646-prestable-fixme-as-compared-to-v201215236-prestable">
  ### ClickHouse 릴리스 v21.1.1.5646-prestable FIXME v20.12.1.5236-prestable 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* `toUnixTimestamp(Date())` 사용을 금지했습니다(이전에는 단순히 Date의 UInt16 표현을 반환했습니다). [#17376](https://github.com/ClickHouse/ClickHouse/pull/17376) ([Azat Khuzhin](https://github.com/azat)).
* 아는 사람이 이 함수들은 한 번도 제대로 동작한 적이 없다고 해서 집계 함수 `timeSeriesGroupSum`, `timeSeriesGroupRateSum`을 제거했습니다. 이 변경으로 [#16869](https://github.com/ClickHouse/ClickHouse/issues/16869)가 수정됩니다. 이 함수들을 문제없이 사용하고 있었다면 clickhouse-feedback@yandex-team.com으로 이메일을 보내주십시오. [#17423](https://github.com/ClickHouse/ClickHouse/pull/17423) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 설정 `input_format_null_as_default`가 기본적으로 활성화됩니다. [#17525](https://github.com/ClickHouse/ClickHouse/pull/17525) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `insert_quorum_parallel`의 기본값을 1로 설정했습니다. 이는 &quot;sequential&quot; quorum 삽입보다 훨씬 사용하기 편리합니다. 다만 순차 일관성에 의존하는 경우에는 이 설정을 다시 0으로 되돌려야 합니다. [#17567](https://github.com/ClickHouse/ClickHouse/pull/17567) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 데이터 파트에 영향을 미치는 스토리지 설정(`write_final_mark`, `enable_mixed_granularity_parts`)은 `ALTER MODIFY SETTING`으로 변경할 수 없도록 제한했습니다. [#18306](https://github.com/ClickHouse/ClickHouse/pull/18306) ([Amos Bird](https://github.com/amosbird)).
* 구성의 profile 설정에 대해 설정 제약 조건을 검사합니다. users.xml에 해당 제약 조건을 충족하지 않는 설정이 포함되어 있으면 server가 시작되지 않습니다. [#18486](https://github.com/ClickHouse/ClickHouse/pull/18486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `sumburConsistentHash` 함수를 제거했습니다. 이 변경으로 [#18120](https://github.com/ClickHouse/ClickHouse/issues/18120)이 종료됩니다. [#18656](https://github.com/ClickHouse/ClickHouse/pull/18656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `DIV` 및 `MOD` 연산자를 추가했습니다. `DIV`는 정수 나눗셈을 수행합니다. 이는 MySQL 호환성과 `sqllogictest`를 위해 필요합니다. 이 변경으로 [#18707](https://github.com/ClickHouse/ClickHouse/issues/18707)이 종료됩니다. DIV 또는 MOD를 컬럼 이름이나 alias로 사용 중이면 비호환성이 발생할 수 있습니다. 비호환성이 있는 경우 alias를 AS 키워드 뒤에 쓰거나 식별자를 따옴표(큰따옴표 또는 백쿼트)로 감싸십시오. [#18760](https://github.com/ClickHouse/ClickHouse/pull/18760) ([Du Chuan](https://github.com/spongedu)).

<div id="new-feature">
  #### 새 기능
</div>

* 부동소수점 수를 파싱하기 위해 [https://github.com/lemire/fast&#95;float](https://github.com/lemire/fast_float)을 사용합니다. [#16787](https://github.com/ClickHouse/ClickHouse/pull/16787) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#16819](https://github.com/ClickHouse/ClickHouse/pull/16819) ([pronvis](https://github.com/pronvis)).
* 쿼리를 통해 SimpleAggregateFunction 타입을 생성할 수 있는 새로운 집계 조합자 `-SimpleState`를 추가했습니다. 이는 AggregatingMergeTree 엔진의 MaterializedView를 정의할 때 유용하며, 프로젝션에도 도움이 됩니다. [#16853](https://github.com/ClickHouse/ClickHouse/pull/16853) ([Amos Bird](https://github.com/amosbird)).
* `mannWitneyUTest`, `studentTTest`, `welchTTest` 집계 함수를 추가했습니다. RankCorr도 일부 리팩터링했습니다. [#16883](https://github.com/ClickHouse/ClickHouse/pull/16883) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `optimize&#95;on&#95;insert` 설정을 추가했습니다. 활성화하면 삽입된 데이터 블록에 대해, 해당 블록에서 머지가 수행된 것과 동일한 변환을 적용합니다(예: Replacing, 축약, Aggregating...). 이 설정은 기본적으로 활성화됩니다. 이는 Materialized View와 MaterializeMySQL 동작에 영향을 줄 수 있습니다(자세한 설명 참조). 이로써 [#10683](https://github.com/ClickHouse/ClickHouse/issues/10683)가 해결됩니다. [#16954](https://github.com/ClickHouse/ClickHouse/pull/16954) ([Kruglov Pavel](https://github.com/Avogar)).
* `*.zst` 압축/압축 해제 지원을 추가했습니다. 이를 통해 `file()` 함수에서 `*.zst`를 사용하고 HTTP 클라이언트에서 `Content-encoding: zstd`를 사용할 수 있습니다. 이로써 [#16791 ](https://github.com/ClickHouse/ClickHouse/issues/16791)가 해결됩니다. [#17144](https://github.com/ClickHouse/ClickHouse/pull/17144) ([Abi Palagashvili](https://github.com/fibersel)).
* * IP 딕셔너리가 `IPv4` / `IPv6` 타입을 직접 지원합니다. [#17571](https://github.com/ClickHouse/ClickHouse/pull/17571) ([Vladimir C](https://github.com/vdimir)).
* 관련: [#16176](https://github.com/ClickHouse/ClickHouse/issues/16176) 사용법: `set limit = 10; set offset = 20;` 이 두 설정은 `select * from ($your_original_select_query) tmp limit xxx offset xxx;`가 추가된 것과 같은 방식으로 SELECT 쿼리에 영향을 줍니다. [#17633](https://github.com/ClickHouse/ClickHouse/pull/17633) ([hexiaoting](https://github.com/hexiaoting)).
* MergeTree 테이블의 전체 행 수, 바이트 수, 파트 수에 대한 비동기 메트릭을 추가했습니다. 이 수정은 [#11714](https://github.com/ClickHouse/ClickHouse/issues/11714)를 해결합니다. [#17639](https://github.com/ClickHouse/ClickHouse/pull/17639) ([flynn](https://github.com/ucasfl)).
* `DETACH TABLE/VIEW ... PERMANENTLY` 구문을 도입하여 재시작 후 테이블이 자동으로 다시 나타나지 않도록 했습니다(명시적으로 요청한 경우에만 다시 나타납니다). 테이블은 여전히 짧은 구문인 ATTACH TABLE을 사용해 다시 ATTACH할 수 있습니다. [#5555](https://github.com/ClickHouse/ClickHouse/issues/5555)를 구현했습니다. [#13850](https://github.com/ClickHouse/ClickHouse/issues/13850)을 수정했습니다. [#17642](https://github.com/ClickHouse/ClickHouse/pull/17642) ([filimonov](https://github.com/filimonov)).
* DDL worker 큐의 쿼리를 표시하는 `system.distributed_ddl_queue`라는 새 테이블을 추가했습니다. [#17656](https://github.com/ClickHouse/ClickHouse/pull/17656) ([Bharat Nallan](https://github.com/bharatnc)).
* 문자열을 XML 텍스트 노드나 속성에 넣을 수 있도록 문자를 이스케이프하는 함수 `encodeXMLComponent`를 추가했습니다. [#17659](https://github.com/ClickHouse/ClickHouse/pull/17659) ([nauta](https://github.com/nautaa)).
* 이제 clickhouse-client에서 명령을 편집하기 위해 EDITOR를 여는 기능을 지원합니다. `Alt-Shift-E`. [#17665](https://github.com/ClickHouse/ClickHouse/pull/17665) ([Amos Bird](https://github.com/amosbird)).
* 네이티브 TCP 인터페이스를 감싸기 위한 PROXYv1 프로토콜 지원을 추가했습니다. 프록시를 통해 전달된 IP 주소를 기준으로 쿼터를 적용할 수 있습니다(PROXYv1 주소와 HTTP 인터페이스의 X-Forwarded-For에 적용). 이는 ClickHouse 접근을 신뢰할 수 있는 프록시(예: CloudFlare)를 통해서만 제공하면서도, 원래 IP 주소를 기준으로 사용자 리소스를 집계하려는 경우에 유용합니다. 이 수정은 [#17268](https://github.com/ClickHouse/ClickHouse/issues/17268)을 해결합니다. [#17707](https://github.com/ClickHouse/ClickHouse/pull/17707) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 함수 `firstSignificantSubdomainCustom`, `cutToFirstSignificantSubdomainCustom`에서 사용자 지정 TLD 목록을 사용할 수 있는 기능을 추가했습니다. [#17748](https://github.com/ClickHouse/ClickHouse/pull/17748) ([Azat Khuzhin](https://github.com/azat)).
* Clickhouse-benchmark에 쿼리 매개변수를 추가했습니다. [#17832](https://github.com/ClickHouse/ClickHouse/pull/17832) ([Maksim Kita](https://github.com/kitaisreal)).
* `OPTIMIZE ... DEDUPLICATE` 구문을 확장하여, 중복 검사 대상 컬럼 목록을 명시적으로 또는 애스터리스크/컬럼 변환기를 통한 암시적 방식으로 지정할 수 있도록 했습니다. ... [#17846](https://github.com/ClickHouse/ClickHouse/pull/17846) ([Vasily Nemkov](https://github.com/Enmk)).
* MergeTreeSettings에 `min_compress_block_size` 및 `max_compress_block_size` 설정을 추가했습니다. 이 설정은 전역 설정보다 우선순위가 높으며, 설정된 경우 적용됩니다. [13890](https://github.com/ClickHouse/ClickHouse/issues/13890)를 해결합니다. [#17867](https://github.com/ClickHouse/ClickHouse/pull/17867) ([flynn](https://github.com/ucasfl)).
* `ATTACH TABLE name FROM 'path/to/data/' (col1 Type1, ...` 쿼리를 구현했습니다. 이 쿼리는 지정한 구조로 새 테이블을 생성하고 `user_files`의 지정된 디렉터리에서 테이블 데이터를 ATTACH합니다. [#17903](https://github.com/ClickHouse/ClickHouse/pull/17903) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `arrayMin`, `arrayMax`, `arrayAvg` 집계 함수가 추가되었습니다. [#18032](https://github.com/ClickHouse/ClickHouse/pull/18032) ([Maksim Kita](https://github.com/kitaisreal)).
* system.settings의 매개변수를 표시하는 `SHOW SETTINGS` 문을 지원합니다. `SHOW CHANGED SETTINGS` 및 `LIKE/ILIKE` 절도 지원합니다. [#18056](https://github.com/ClickHouse/ClickHouse/pull/18056) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* 컬럼을 지정하여 create table as select를 사용할 수 있습니다. 예: `CREATE TABLE t1 (x String) ENGINE = Memory AS SELECT 1;`. [#18060](https://github.com/ClickHouse/ClickHouse/pull/18060) ([Maksim Kita](https://github.com/kitaisreal)).
* * IP 딕셔너리가 키 조회를 지원합니다. [#18241](https://github.com/ClickHouse/ClickHouse/issues/18241)를 해결합니다. [#18480](https://github.com/ClickHouse/ClickHouse/pull/18480) ([Vladimir C](https://github.com/vdimir)).
* `REPLACE TABLE` 및 `CREATE OR REPLACE TABLE` 쿼리를 구현했습니다. [#18521](https://github.com/ClickHouse/ClickHouse/pull/18521) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 메모리에서 인수의 비압축 바이트 크기를 추정하는 함수 `byteSize`를 추가했습니다. 예를 들어 `UInt32` 인수에는 상수 4를 반환하고, `String` 인수에는 문자열 길이 + 9를 반환합니다. 이 함수는 여러 인수를 받을 수 있습니다. 일반적인 사용 예는 `byteSize(*)`입니다. [#18579](https://github.com/ClickHouse/ClickHouse/pull/18579) ([Ping Yu](https://github.com/pingyu)).
* 삽입된 파트에 대해 `system.part_log`에 `query_id` 컬럼을 추가했습니다. [#10097](https://github.com/ClickHouse/ClickHouse/issues/10097)을 해결합니다. [#18644](https://github.com/ClickHouse/ClickHouse/pull/18644) ([flynn](https://github.com/ucasfl)).
* 이제 MergeTree 엔진 계열 테이블용 새 스토리지 설정 `max_partitions_to_read`를 사용할 수 있습니다. 이 설정은 하나의 쿼리에서 접근할 수 있는 최대 파티션 수를 제한합니다. 이 제약을 강제하기 위한 사용자 설정 `force_max_partition_limit`도 추가했습니다. [#18712](https://github.com/ClickHouse/ClickHouse/pull/18712) ([Amos Bird](https://github.com/amosbird)).
* 함수 `position`이 이제 SQL 호환성을 위해 `position(needle in haystack)` 구문을 지원합니다. 이로써 [#18701](https://github.com/ClickHouse/ClickHouse/issues/18701)이 해결됩니다. ... [#18779](https://github.com/ClickHouse/ClickHouse/pull/18779) ([Jianmei Zhang](https://github.com/zhangjmruc)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 부동소수점 파싱 성능을 약간 개선했습니다. [#16809](https://github.com/ClickHouse/ClickHouse/pull/16809) ([Maksim Kita](https://github.com/kitaisreal)).
* `repeat` 함수의 성능을 개선했습니다. [#16937](https://github.com/ClickHouse/ClickHouse/pull/16937) ([satanson](https://github.com/satanson)).
* 매우 많은 `MergeTree` 테이블에 걸친 `Merge` 테이블 읽기 성능을 개선했습니다. [#7748](https://github.com/ClickHouse/ClickHouse/issues/7748)를 해결합니다. [#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).
* 이제 `-If` combinator에 devirtualization이 적용되고, `count`도 올바르게 vectorization됩니다. 관련 내용은 [https://github.com/ClickHouse/ClickHouse/pull/17041](https://github.com/ClickHouse/ClickHouse/pull/17041)를 참조하십시오. [#17043](https://github.com/ClickHouse/ClickHouse/pull/17043) ([Amos Bird](https://github.com/amosbird)).
* PK에서 `SimpleAggregateFunction(String)`을 사용하는 AggregatingMergeTree의 성능을 개선했습니다. [#17109](https://github.com/ClickHouse/ClickHouse/pull/17109) ([Azat Khuzhin](https://github.com/azat)).
* `remerge_sort_lowered_memory_bytes_ratio` 설정을 추가했습니다 (`remerge` 후 메모리 사용량이 이 비율만큼 줄어들지 않으면 `remerge`가 비활성화됩니다). [#17539](https://github.com/ClickHouse/ClickHouse/pull/17539) ([Azat Khuzhin](https://github.com/azat)).
* `IPv6CIDRToRange` 구현 속도를 높였습니다. [#17569](https://github.com/ClickHouse/ClickHouse/pull/17569) ([Vladimir C](https://github.com/vdimir)).
* 부동소수점을 문자열로 변환할 때 ryu 대신 dragonbox 알고리즘을 사용합니다. [#17831](https://github.com/ClickHouse/ClickHouse/pull/17831) ([Maksim Kita](https://github.com/kitaisreal)).
* StorageMemory 읽기를 최적화했습니다. [#18052](https://github.com/ClickHouse/ClickHouse/pull/18052) ([Maksim Kita](https://github.com/kitaisreal)).
* 분산 테이블에 동기식 INSERT를 수행할 때 세그먼트로 빈 블록을 보내지 않도록 했습니다. 이 변경으로 [#14571](https://github.com/ClickHouse/ClickHouse/issues/14571)이 해결됩니다. [#18775](https://github.com/ClickHouse/ClickHouse/pull/18775) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `AggregateFunctionWindowFunnelData`에서 `PODArray`를 `PODArrayWithStackMemory`로 대체해 `windowFunnel` 함수의 성능을 개선했습니다. [#18817](https://github.com/ClickHouse/ClickHouse/pull/18817) ([flynn](https://github.com/ucasfl)).
* 시스템 테이블 없이 실행할 수 있도록 `clickhouse-local`에 `--no-system-table` 옵션을 추가했습니다. 이를 통해 시작 시 눈에 띄는 시간(수십 밀리초)이 걸릴 수 있는 `DateLUT` 초기화를 피할 수 있습니다. [#18899](https://github.com/ClickHouse/ClickHouse/pull/18899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* * 메모리 사용량을 줄이고, 일부 사례에서 성능을 개선했으며, 버그를 수정한 새로운 IP 딕셔너리 구현입니다. [#16804](https://github.com/ClickHouse/ClickHouse/pull/16804) ([Vladimir C](https://github.com/vdimir)).
* 환경 변수, `~/.aws`, `AssumeRole`을 사용한 S3 클라이언트의 적절한 인증을 추가했습니다. [#16856](https://github.com/ClickHouse/ClickHouse/pull/16856) ([Vladimir Chebotarev](https://github.com/excitoon)).
* HTTP 프록시 및 HTTPS S3 엔드포인트 구성을 지원하도록 했습니다. [#16861](https://github.com/ClickHouse/ClickHouse/pull/16861) ([Pavel Kovalenko](https://github.com/Jokser)).
* `-OrNull` combinator를 `-If`, `-Merge`, `-MergeState`, `-State` combinator와 함께 사용할 경우 `-OrNull`을 앞에 두어야 합니다. [#16935](https://github.com/ClickHouse/ClickHouse/pull/16935) ([flynn](https://github.com/ucasfl)).
* * 여러 ZooKeeper 클러스터를 위한 구성을 추가했습니다. [#17070](https://github.com/ClickHouse/ClickHouse/pull/17070) ([fastio](https://github.com/fastio)).
* * S3 스토리지 요청 시 HTTP 리디렉션 제한(`s3_max_redirects`)을 추가했습니다. [#17220](https://github.com/ClickHouse/ClickHouse/pull/17220) ([ianton-ru](https://github.com/ianton-ru)).
* 이제 set 인덱스가 `GLOBAL IN`과 함께 동작합니다. 이로써 [#17232](https://github.com/ClickHouse/ClickHouse/issues/17232), [#5576](https://github.com/ClickHouse/ClickHouse/issues/5576)가 수정되었습니다. [#17253](https://github.com/ClickHouse/ClickHouse/pull/17253) ([Amos Bird](https://github.com/amosbird)).
* bigint 변환에서 발생할 수 있는 스택 오버플로우를 방지합니다. Big integer는 실험적 기능입니다. [#17269](https://github.com/ClickHouse/ClickHouse/pull/17269) ([flynn](https://github.com/ucasfl)).
