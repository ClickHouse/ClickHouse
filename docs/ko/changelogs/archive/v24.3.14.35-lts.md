[#64517](https://github.com/ClickHouse/ClickHouse/pull/64517) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#71600](https://github.com/ClickHouse/ClickHouse/issues/71600)에 백포트됨: Variant 컬럼이 있는 청크에서 발생하는 `Invalid number of rows in Chunk` 오류를 수정했습니다. [#71388](https://github.com/ClickHouse/ClickHouse/pull/71388) ([Pavel Kruglov](https://github.com/Avogar)).
* [#71842](https://github.com/ClickHouse/ClickHouse/issues/71842)에 백포트됨: optimize&#95;rewrite&#95;array&#95;exists&#95;to&#95;has 사용 시 발생하는 크래시를 수정했습니다. [#71432](https://github.com/ClickHouse/ClickHouse/pull/71432) ([Raúl Marín](https://github.com/Algunenano)).
* [#71562](https://github.com/ClickHouse/ClickHouse/issues/71562)에 백포트됨: 제약 조건에서 UDF를 사용할 때 크래시가 발생하지 않도록 했습니다. [#71541](https://github.com/ClickHouse/ClickHouse/pull/71541) ([Raúl Marín](https://github.com/Algunenano)).
* [#71731](https://github.com/ClickHouse/ClickHouse/issues/71731)에 백포트됨: bitShift 함수에서 범위를 벗어난 경우 오류를 발생시키는 대신 0 또는 기본 문자를 반환하도록 수정했습니다. [#71580](https://github.com/ClickHouse/ClickHouse/pull/71580) ([Pablo Marcos](https://github.com/pamarcos)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#71697](https://github.com/ClickHouse/ClickHouse/issues/71697)에 백포트됨: Rust 의존성을 벤더링했습니다. [#62297](https://github.com/ClickHouse/ClickHouse/pull/62297) ([Raúl Marín](https://github.com/Algunenano)).
* [#71688](https://github.com/ClickHouse/ClickHouse/issues/71688)에 백포트됨: clickhouse-server Dockerfile.ubuntu를 개선했습니다. `CLICKHOUSE_UID/CLICKHOUSE_GID` 환경 변수는 더 이상 사용을 권장하지 않습니다. 요구 사항을 준수하기 위해 `CLICKHOUSE_DOCKER_RESTART_ON_EXIT` 처리를 제거했습니다. 한 곳에서는 경로 없이, 다른 곳에서는 `/usr/bin/clickhouse*`를 사용하는 일이 없도록 `clickhouse/clickhouse-server/clickhouse-keeper` 실행 방식을 일관되게 정리했습니다. [#71573](https://github.com/ClickHouse/ClickHouse/pull/71573) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
