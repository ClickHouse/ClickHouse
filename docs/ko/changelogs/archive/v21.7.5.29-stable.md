<div id="bug-fix">
  #### 오동작
</div>

* [#26787](https://github.com/ClickHouse/ClickHouse/issues/26787)에 백포트됨: 내부 버퍼 끝에 이스케이프 시퀀스가 있는 경우 zstd 압축 해제가 올바르게 동작하지 않던 문제를 수정했습니다. [#26013](https://github.com/ClickHouse/ClickHouse/issues/26013)를 해결했습니다. [#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26487](https://github.com/ClickHouse/ClickHouse/issues/26487)에 백포트됨: 컬럼 별칭을 다시 쓴 후 이름 확인이 잘못되던 문제를 수정했습니다. 이 변경으로 [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432)를 해결했습니다. [#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird)).
* [#26615](https://github.com/ClickHouse/ClickHouse/issues/26615)에 백포트됨: 딕셔너리 이름이나 데이터베이스 이름이 따옴표로 묶인 경우 `CREATE DICTIONARY` 쿼리에서 발생하던 문제를 수정했습니다. [#26491](https://github.com/ClickHouse/ClickHouse/issues/26491)를 해결했습니다. [#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal)).
* [#26606](https://github.com/ClickHouse/ClickHouse/issues/26606)에 백포트됨: rabbitmq setup이 시작되지 않은 경우 rabbitmq 종료 시 발생하던 크래시를 수정했습니다. [#26504](https://github.com/ClickHouse/ClickHouse/issues/26504)를 해결했습니다. [#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26612](https://github.com/ClickHouse/ClickHouse/issues/26612)에 백포트됨: clickhouse-server Docker 엔트리포인트에서 `chown` 명령 검사 내용을 업데이트했습니다. 이 변경으로 Kubernetes에서 클러스터 파드 재시작이 실패하거나 시간 초과되던 버그를 수정했습니다. [#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix)).
* [#26647](https://github.com/ClickHouse/ClickHouse/issues/26647)에 백포트됨: groupBitmapAnd/Or/Xor의 잘못된 함수 이름을 수정했습니다. 이를 수정했습니다. [#26557](https://github.com/ClickHouse/ClickHouse/pull/26557) ([Amos Bird](https://github.com/amosbird)).
* [#26704](https://github.com/ClickHouse/ClickHouse/issues/26704)에 백포트됨: 윈도우 함수에서 발생할 수 있는 nullptr 역참조를 수정했습니다. 이 변경으로 [#25276](https://github.com/ClickHouse/ClickHouse/issues/25276)를 해결했습니다. [#26668](https://github.com/ClickHouse/ClickHouse/pull/26668) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* [#26772](https://github.com/ClickHouse/ClickHouse/issues/26772)에 백포트됨: 때때로 SET ROLE이 올바르게 동작하지 않던 문제를 수정했습니다. [#26707](https://github.com/ClickHouse/ClickHouse/pull/26707) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#26907](https://github.com/ClickHouse/ClickHouse/issues/26907)에 백포트됨: library-bridge ids 로딩을 수정했습니다. [#26834](https://github.com/ClickHouse/ClickHouse/pull/26834) ([Kseniia Sumarokova](https://github.com/kssenii)).
