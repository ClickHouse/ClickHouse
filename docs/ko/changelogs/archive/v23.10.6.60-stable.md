<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* `flatten_nested=1`인 경우 모든 배열(Tuple)이 아니라 실제 Nested type만 평탄화합니다 [#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* ALIAS가 있는 ALTER COLUMN을 수정했습니다 [#56493](https://github.com/ClickHouse/ClickHouse/pull/56493) ([Nikolay Degterinsky](https://github.com/evillique)).
* projection 컬럼에 대한 호환되지 않는 ALTER를 방지합니다 [#56948](https://github.com/ClickHouse/ClickHouse/pull/56948) ([Amos Bird](https://github.com/amosbird)).
* 널 허용 Nullable MATERIALIZED 컬럼으로 ALTER UPDATE를 수행한 후 발생하는 segfault를 수정했습니다 [#57147](https://github.com/ClickHouse/ClickHouse/pull/57147) ([Nikolay Degterinsky](https://github.com/evillique)).
* 일반 projection이 부분적으로만 materialized된 경우의 잘못된 JOIN 계획 최적화를 수정했습니다 [#57196](https://github.com/ClickHouse/ClickHouse/pull/57196) ([Amos Bird](https://github.com/amosbird)).
* 모든 경우에서 `ReadonlyReplica` 메트릭을 수정했습니다 [#57267](https://github.com/ClickHouse/ClickHouse/pull/57267) ([Antonio Andelic](https://github.com/antonio2368)).
* 백그라운드 머지가 캐시에서 임시 데이터 저장소를 올바르게 사용하도록 수정했습니다 [#57275](https://github.com/ClickHouse/ClickHouse/pull/57275) ([vdimir](https://github.com/vdimir)).
* MergeTree 뮤테이션이 소스 파트의 인덱스 세분화 수준을 재사용하도록 수정했습니다 [#57352](https://github.com/ClickHouse/ClickHouse/pull/57352) ([Maksim Kita](https://github.com/kitaisreal)).
* 부분적으로 const인 컬럼에 대한 jsonMergePatch 함수를 수정했습니다 [#57379](https://github.com/ClickHouse/ClickHouse/pull/57379) ([Nikolay Degterinsky](https://github.com/evillique)).
* StreamingFormatExecutor에서 read buffer 처리 문제를 수정했습니다 [#57438](https://github.com/ClickHouse/ClickHouse/pull/57438) ([Kruglov Pavel](https://github.com/Avogar)).
* 버그 수정: SYSTEM STOP LISTEN TCP SECURE를 올바르게 파싱합니다 [#57483](https://github.com/ClickHouse/ClickHouse/pull/57483) ([joelynch](https://github.com/joelynch)).
* 복제된 접근 엔터티를 관리하기 위한 grant/revoke 쿼리에서 ON CLUSTER 절을 무시합니다.  [#57538](https://github.com/ClickHouse/ClickHouse/pull/57538) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* system.kafka&#95;consumers를 기본적으로 비활성화합니다(실시간 메모리 누수 가능성 때문) [#57822](https://github.com/ClickHouse/ClickHouse/pull/57822) ([Azat Khuzhin](https://github.com/azat)).
* BLAKE3(Rust)에서 잘못된 메모리 접근을 수정했습니다 [#57876](https://github.com/ClickHouse/ClickHouse/pull/57876) ([Raúl Marín](https://github.com/Algunenano)).
* CREATE INDEX에서 함수 이름을 정규화합니다 [#57906](https://github.com/ClickHouse/ClickHouse/pull/57906) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Keeper에서 잘못된 전처리를 수정했습니다 [#58069](https://github.com/ClickHouse/ClickHouse/pull/58069) ([Antonio Andelic](https://github.com/antonio2368)).
* Poco::UTF32Encoding의 정수 오버플로우를 수정했습니다 [#58073](https://github.com/ClickHouse/ClickHouse/pull/58073) ([Andrey Fedotov](https://github.com/anfedotoff)).
* JSONCompactEachRow에 대한 병렬 파싱을 제거했습니다 [#58181](https://github.com/ClickHouse/ClickHouse/pull/58181) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* 손상된 분리된 파트가 있는 레플리카를 삭제한 후 blobs가 유실되는 문제를 수정했습니다 [#58333](https://github.com/ClickHouse/ClickHouse/pull/58333) ([Alexander Tokmakov](https://github.com/tavplubix)).
