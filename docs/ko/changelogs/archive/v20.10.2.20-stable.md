<div id="clickhouse-release-v2010220-stable-fixme-as-compared-to-v20914585-prestable">
  ### ClickHouse 릴리스 v20.10.2.20-stable FIXME, v20.9.1.4585-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* SQL에서 중첩된 여러 줄 주석 `/* comment /* comment */ */`을 지원하도록 추가했습니다. 이는 SQL 표준을 따릅니다. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 사용자가 기대하는 동작에 더 가깝게 만들기 위해 `format_regexp_escaping_rule` 설정(`Regexp` 포맷 관련)의 기본값을 `Raw`로 변경했습니다(`Raw`는 전체 하위 패턴을 하나의 값으로 읽는다는 의미입니다). [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version`을 더 이상 사용하지 않도록 했습니다. 조인 재작성기의 첫 번째 버전을 제거했습니다. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### 새 기능
</div>

* `LineAsString` 포맷을 추가했습니다. 이 포맷은 줄바꿈, 공백 및/또는 쉼표로 구분된 선 시퀀스를 허용합니다. [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `formatReadableQuantity` 함수를 추가했습니다. 큰 숫자를 사람이 읽기 쉬운 형태로 표현할 때 유용합니다. [#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* 컬럼 속성과 테이블 TTL을 제거하는 기능을 추가했습니다. `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` 및 `ALTER TABLE REMOVE TTL` 쿼리를 도입했습니다. 두 작업 모두 경량 작업이며 메타데이터 수준에서 실행됩니다. [#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* `system.text_log`, `system.trace_log`, `system.query_log`, `system.query_thread_log` 테이블에 `event_time_microseconds` 필드를 도입했습니다. [#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* 이제 쿼리 컨텍스트에서 이름 있는 서브쿼리를 정의할 수 있도록 `WITH <identifier> AS (subquery) ... `를 지원합니다. 이 변경으로 [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416)이 해결됩니다. 이 변경으로 [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967)이 해결됩니다. [#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* 구성에 기본값이 지정된 경우 Replicated 테이블 엔진의 인수를 생략할 수 있도록 했습니다. [#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* 테이블 함수 `null('structure')`를 추가했습니다. [#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* 쿼리 난독화 도구를 추가했습니다. 이를 통해 더 나은 테스트를 위해 더 많은 쿼리를 공유할 수 있습니다. 이 변경으로 [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268)이 해결됩니다. [#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `RawBLOB` 포맷을 추가했습니다. 이 포맷은 이스케이프 및 구분 기호 없이 단일 값을 입력하거나 출력하기 위한 것입니다. 이 변경으로 [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349)이 해결됩니다. [#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [15350](https://github.com/ClickHouse/ClickHouse/issues/15350)을 수정했습니다. [#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* 첫 번째 SELECT의 `WITH` 문을 같은 수준의 다른 SELECT 쿼리로 전파하고, `WITH` 문의 별칭을 서브쿼리에서 사용할 수 있게 하는 `enable_global_with_statement` 설정을 도입했습니다. [#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* 빅엔디언 바이트 문자열을 UUID로 변환할 수 있는 `reinterpretAsUUID` 함수를 추가했습니다. [#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 병렬 quorum 삽입을 추가했습니다. 이 변경으로 [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601)이 해결됩니다. [#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* 와이드 정수의 기본 타입으로 `(u)int64_t`를 사용해 256비트 연산 성능을 개선했습니다. 기존 와이드 정수는 기본 타입으로 8비트 타입을 사용합니다. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* clickhouse-server 시작 시 `mlock`은 코드 세그먼트에만 적용합니다. 이전 버전에서는 디버그 정보를 포함해 매핑된 모든 영역을 메모리에 잠갔습니다. 디버그 정보는 보통 별도 파일로 분리되지만, 그렇지 않은 경우 메모리 사용량이 2~3 GiB 증가했습니다. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이전에는 하나의 FixedString으로 그룹화할 때 fixed key 메서드를 선택했습니다. 하지만 FixedString 컬럼에 대해 유사한 packedFix 최적화를 수행하는 StringHashTable이 있으므로 이는 불필요합니다. 가능하다면 low&#95;cardinality&#95;key&#95;fixed&#95;string을 사용해야 합니다. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* `DateTime <op> DateTime`이 느린 일반 구현을 잘못 선택하던 문제를 수정했습니다. 이 변경으로 [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153)를 해결합니다. [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* 반복문에서 여러 개의 DeleteObject를 사용하는 대신 S3 DeleteObjects request 1개를 사용합니다. 기능 변경은 없으므로 integration/test&#95;log&#95;family&#95;s3 같은 기존 테스트로 검증됩니다. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* 256비트 곱셈 속도를 개선했습니다. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* `quantileTDigest` 성능을 개선합니다. 이 변경으로 [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668)을 해결합니다. [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* 수직 병합 임시 데이터를 저장할 때 임시 디스크를 명시적으로 사용합니다. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).



<div id="improvement">
  #### 개선 사항
</div>

* `QueryMemoryLimitExceeded` 이벤트를 추가했습니다. 이로써 [#14589](https://github.com/ClickHouse/ClickHouse/issues/14589)가 해결되었습니다. [#14647](https://github.com/ClickHouse/ClickHouse/pull/14647) ([fastio](https://github.com/fastio)).
* 함수에 대해 디버그 정보 없이 빌드할 수 있는 옵션을 제공하여 하위 호환성을 깨는 변경을 수정했습니다. [#14657](https://github.com/ClickHouse/ClickHouse/pull/14657) ([Mike Kot](https://github.com/myrrc)).
* ZooKeeper 구성을 동적으로 다시 로드할 수 있습니다. [#14678](https://github.com/ClickHouse/ClickHouse/pull/14678) ([sundyli](https://github.com/sundy-li)).
* 분산 DDL을 병렬로 실행할 수 있습니다. [#14684](https://github.com/ClickHouse/ClickHouse/pull/14684) ([Azat Khuzhin](https://github.com/azat)).
* ZooKeeper `exists` watch로 인해 발생할 수 있는 잠재적 메모리 누수를 수정했습니다. [#14693](https://github.com/ClickHouse/ClickHouse/pull/14693) ([hustnn](https://github.com/hustnn)).
* `MaterializeMySQL` 데이터베이스 엔진에서 발생하던 &quot;Packet payload is not fully read&quot; 오류를 수정했습니다. [#14696](https://github.com/ClickHouse/ClickHouse/pull/14696) ([BohuTANG](https://github.com/BohuTANG)).
* 음수의 큰 정수값으로 호출했을 때 `bitShiftLeft()`에서 발생하는 크래시를 수정했습니다. [#14697](https://github.com/ClickHouse/ClickHouse/pull/14697) ([Artem Zuikov](https://github.com/4ertus2)).
* 머지 점검을 개선하기 위해 system.merges 테이블에 `merge_algorithm`을 추가했습니다. [#14705](https://github.com/ClickHouse/ClickHouse/pull/14705) ([Amos Bird](https://github.com/amosbird)).
* FunctionBinaryArithmetic의 DecimalBinaryOperation Template에서 생성되는 불필요한 코드가 줄어들었습니다. [#14743](https://github.com/ClickHouse/ClickHouse/pull/14743) ([Artem Zuikov](https://github.com/4ertus2)).
* 이제 columns를 사용해 컬럼 목록을 래핑한 뒤 컬럼 변환기를 적용할 수 있습니다. [#14775](https://github.com/ClickHouse/ClickHouse/pull/14775) ([Amos Bird](https://github.com/amosbird)).
* StorageJoin 및 StorageSet의 영속성 비활성화를 지원하며, 이 기능은 `disable_set_and_join_persistency` 설정으로 제어됩니다. 또한 이 PR은 [#6318](https://github.com/ClickHouse/ClickHouse/issues/6318) 이슈를 해결했습니다. [#14776](https://github.com/ClickHouse/ClickHouse/pull/14776) ([vxider](https://github.com/Vxider)).
* `query_start_time` 및 `query_start_time_microseconds`를 동일한 timespec에서 생성합니다. [#14831](https://github.com/ClickHouse/ClickHouse/pull/14831) ([Bharat Nallan](https://github.com/bharatnc)).
* Distributed 스토리지에서 다중 볼륨 스토리지 구성을 사용할 수 있습니다. [#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
* `EXPLAIN` 결과에 `SET` 및 `JOIN`의 서브쿼리를 표시합니다. [#14856](https://github.com/ClickHouse/ClickHouse/pull/14856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 첫 번째 레플리카를 명시적으로 지정할 수 있는 `load_balancing_first_offset` 쿼리 설정을 제공합니다. 이 설정은 `FIRST_OR_RANDOM` load balancing 전략과 함께 사용되며, 이를 통해 레플리카 워크로드를 제어할 수 있습니다. [#14867](https://github.com/ClickHouse/ClickHouse/pull/14867) ([Amos Bird](https://github.com/amosbird)).
* 분산 테이블에서 SETTINGS와 함께 SELECT를 실행할 때 발생하던 과도한 설정 제약 조건 위반을 수정했습니다. [#14876](https://github.com/ClickHouse/ClickHouse/pull/14876) ([Amos Bird](https://github.com/amosbird)).
* 이전 삭제 시도가 ZooKeeper 세션 만료로 실패한 경우에도 Replicated 테이블을 삭제할 수 있습니다. 이로써 [#11891](https://github.com/ClickHouse/ClickHouse/issues/11891)이 수정되었습니다. [#14926](https://github.com/ClickHouse/ClickHouse/pull/14926) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* 뮤테이션 수행 시 키 제약 조건을 무시합니다. 이 PR이 없으면 `force_index_by_date = 1` 또는 `force_primary_key = 1`일 때 뮤테이션을 수행할 수 없습니다. [#14973](https://github.com/ClickHouse/ClickHouse/pull/14973) ([Amos Bird](https://github.com/amosbird)).
* 데이터 파트 삽입 시 TTL 이동을 비활성화하는 옵션을 추가했습니다. [#15000](https://github.com/ClickHouse/ClickHouse/pull/15000) ([Pavel Kovalenko](https://github.com/Jokser)).
* `Atomic` 데이터베이스 엔진을 기본으로 활성화했습니다. [#15003](https://github.com/ClickHouse/ClickHouse/pull/15003) ([Alexander Tokmakov](https://github.com/tavplubix)).
* CAST의 인수 개수가 잘못되었을 때 올바른 예외 메시지를 표시합니다. 이로써 [#13992](https://github.com/ClickHouse/ClickHouse/issues/13992)가 해결됩니다. [#15029](https://github.com/ClickHouse/ClickHouse/pull/15029) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### 버그 수정
</div>

* 결과 컬럼의 소수 자릿수가 잘못 계산되어 Decimal 곱셈 결과가 틀리게 되는 오류를 수정하였습니다. [#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)).
* 일부 AST 방문자의 전제 조건이 깨지지 않도록 쿼리를 ASTFunction의 인수 목록에 삽입하도록 수정하였습니다. [#14608](https://github.com/ClickHouse/ClickHouse/issues/14608) 수정. [#14611](https://github.com/ClickHouse/ClickHouse/pull/14611) ([Amos Bird](https://github.com/amosbird)).
* 할당 표현식에 Nullable 컬럼과 상수 값(예: `UPDATE x = 42`)을 사용하는 `ALTER UPDATE` 뮤테이션이 컬럼에 잘못된 값을 저장하거나 segfault를 유발하는 버그를 수정하였습니다. [#13634](https://github.com/ClickHouse/ClickHouse/issues/13634), [#14045](https://github.com/ClickHouse/ClickHouse/issues/14045) 수정.
