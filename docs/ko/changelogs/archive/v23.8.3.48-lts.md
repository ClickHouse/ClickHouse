<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#54974](https://github.com/ClickHouse/ClickHouse/issues/54974)에 백포트됨: PREWHERE 최적화 중 복합 조건 actions DAG가 중간 단계의 출력 컬럼을 잃어버리고, 그 컬럼이 이후 단계 중 일부의 입력 컬럼으로 필요한 경우 발생하던 문제를 수정했습니다. [#53492](https://github.com/ClickHouse/ClickHouse/pull/53492) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#54996](https://github.com/ClickHouse/ClickHouse/issues/54996)에 백포트됨: `prefer_localhost_replica=1`일 때 병렬 레플리카가 로컬 레플리카에서만 전부 실행되거나 잘못된 결과를 생성하던 문제를 수정했습니다. 이로써 [#54276](https://github.com/ClickHouse/ClickHouse/issues/54276) 문제가 해결됩니다. [#54334](https://github.com/ClickHouse/ClickHouse/pull/54334) ([Igor Nikonov](https://github.com/devcrafter)).
* [#54516](https://github.com/ClickHouse/ClickHouse/issues/54516)에 백포트됨: S3 테이블 함수에서 발생할 수 있는 &#39;URI contains invalid characters&#39; 오류를 수정했습니다. [#54345](https://github.com/ClickHouse/ClickHouse/issues/54345)를 닫습니다. [#54373](https://github.com/ClickHouse/ClickHouse/pull/54373) ([Kruglov Pavel](https://github.com/Avogar)).
* [#54418](https://github.com/ClickHouse/ClickHouse/issues/54418)에 백포트됨: `analysisOfVariance`의 group number 인수를 처리할 때 오버플로우를 검사하여 크래시를 방지합니다. 이 크래시는 WINGFUZZ를 사용해 발견되었습니다. [#54385](https://github.com/ClickHouse/ClickHouse/pull/54385) ([Antonio Andelic](https://github.com/antonio2368)).
* [#54527](https://github.com/ClickHouse/ClickHouse/issues/54527)에 백포트됨: [#54135](https://github.com/ClickHouse/ClickHouse/issues/54135)에 설명된 버그를 재현합니다. [#54430](https://github.com/ClickHouse/ClickHouse/pull/54430) ([Sema Checherinda](https://github.com/CheSema)).
* [#54854](https://github.com/ClickHouse/ClickHouse/issues/54854)에 백포트됨: variant aggregate states를 사용할 때 잘못된 집계 프로젝션 최적화를 수정했습니다. 이 최적화는 의도치 않게 활성화되었지만, [https://github.com/ClickHouse/ClickHouse/pull/39420](https://github.com/ClickHouse/ClickHouse/pull/39420) 이후 `DataTypeAggregateFunction` 비교가 정규화되므로 제대로 구현되지 않았습니다. 이로써 [#54406](https://github.com/ClickHouse/ClickHouse/issues/54406) 문제가 수정됩니다. [#54480](https://github.com/ClickHouse/ClickHouse/pull/54480) ([Amos Bird](https://github.com/amosbird)).
* [#54599](https://github.com/ClickHouse/ClickHouse/issues/54599)에 백포트됨: input&#95;format&#95;with&#95;names&#95;use&#95;header가 비활성화된 상태에서 컬럼 부분 집합을 읽을 때 WithNames 포맷에서 발생하는 파싱 오류를 수정했습니다. [#52591](https://github.com/ClickHouse/ClickHouse/issues/52591)를 닫습니다. [#54513](https://github.com/ClickHouse/ClickHouse/pull/54513) ([Kruglov Pavel](https://github.com/Avogar)).
* [#54594](https://github.com/ClickHouse/ClickHouse/issues/54594)에 백포트됨: 버전 23.5부터 zero-copy 복제가 ZooKeeper와 S3에 일부 불필요한 데이터를 남길 수 있었습니다. mutation이 적용된 오래된 파트를 제거할 때 이런 일이 발생할 수 있습니다. 이 문제는 `Failed to get mutation parent on {} for part {}, refusing to remove blobs` 로그 메시지로 나타납니다. [#54550](https://github.com/ClickHouse/ClickHouse/pull/54550) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#54627](https://github.com/ClickHouse/ClickHouse/issues/54627)에 백포트됨: `ColumnUnique`에서 공유 변수에 대한 비동기화 쓰기를 수정했습니다. [#54575](https://github.com/ClickHouse/ClickHouse/pull/54575) ([Nikita Taranov](https://github.com/nickitat)).
* [#54625](https://github.com/ClickHouse/ClickHouse/issues/54625)에 백포트됨: `ColumnDecimal`의 직렬화를 수정했습니다. [#54601](https://github.com/ClickHouse/ClickHouse/pull/54601) ([Nikita Taranov](https://github.com/nickitat)).
* [#54945](https://github.com/ClickHouse/ClickHouse/issues/54945)에 백포트됨: ORDER BY 사용 시 가상 컬럼(예: &#95;file)에 잘못된 값이 표시되던 문제를 수정했습니다. [#54811](https://github.com/ClickHouse/ClickHouse/pull/54811) ([Michael Kolupaev](https://github.com/al13n321)).
* [#54872](https://github.com/ClickHouse/ClickHouse/issues/54872)에 백포트됨: Keeper 수정: 종료 중 segfault가 발생하지 않도록 콜백에서 변수를 올바르게 capture하도록 수정했습니다. [#54841](https://github.com/ClickHouse/ClickHouse/pull/54841) ([Antonio Andelic](https://github.com/antonio2368)).
* [#54950](https://github.com/ClickHouse/ClickHouse/issues/54950)에 백포트됨: 테이블의 파티션 키가 Enum 유형 확장을 통해 ALTER된 경우 발생하는 프로젝션 최적화 오류를 수정했습니다. 이 수정에서는 파티션 키가 변경될 때 `minmax_count_projection`을 다시 빌드합니다. 이로써 [#54941](https://github.com/ClickHouse/ClickHouse/issues/54941)도 해결됩니다. [#54943](https://github.com/ClickHouse/ClickHouse/pull/54943) ([Amos Bird](https://github.com/amosbird)).
