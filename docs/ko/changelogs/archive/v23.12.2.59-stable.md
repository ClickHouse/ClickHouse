<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#58389](https://github.com/ClickHouse/ClickHouse/issues/58389)에 백포트되었습니다: MergeTree 설정 `clean_deleted_rows`는 더 이상 사용이 권장되지 않으며 이제 아무런 효과도 없습니다. `OPTIMIZE`의 `CLEANUP` keyword는 기본적으로 허용되지 않습니다(`allow_experimental_replacing_merge_with_cleanup`가 enabled된 경우 제외). [#58316](https://github.com/ClickHouse/ClickHouse/pull/58316) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* flatten&#95;nested=1일 때 모든 Array(Tuple)이 아니라 실제 Nested type만 평탄화하도록 수정 [#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* StreamingFormatExecutor에서 read buffer 처리 관련 문제를 수정 [#57438](https://github.com/ClickHouse/ClickHouse/pull/57438) ([Kruglov Pavel](https://github.com/Avogar)).
* 손상된 분리된 파트가 있는 레플리카를 삭제한 후 blobs가 유실되는 문제를 수정 [#58333](https://github.com/ClickHouse/ClickHouse/pull/58333) ([Alexander Tokmakov](https://github.com/tavplubix)).
* graphite 테이블에 집계 함수가 없을 때 발생하는 segfault를 수정 [#58453](https://github.com/ClickHouse/ClickHouse/pull/58453) ([Duc Canh Le](https://github.com/canhld94)).
* LIMIT만 있는 쿼리에서는 MergeTreePrefetchedReadPool을 비활성화 [#58505](https://github.com/ClickHouse/ClickHouse/pull/58505) ([Maksim Kita](https://github.com/kitaisreal)).
