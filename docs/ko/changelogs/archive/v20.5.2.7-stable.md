<div id="clickhouse-release-v20527-stable-fixme-as-compared-to-v20513833-prestable">
  ### ClickHouse 릴리스 v20.5.2.7-안정 FIXME v20.5.1.3833-prestable 대비
</div>

<div id="new-feature">
  #### 새 기능
</div>

* `Alter table drop replica replica_name` 지원이 추가되었습니다. 이 변경으로 [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080) 문제가 해결되었습니다. [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).

<div id="improvement">
  #### 개선 사항
</div>

* 레플리카 선택 시 무시할 오류 수를 추가했습니다(`distributed_replica_error_ignore`). [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* 구조 잠금 없이 storages에 대한 다중 버전 메타데이터를 지원합니다. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* ODBC 연결 문자열에 대한 유효성 검사를 약간 완화했습니다. 호스트명 또는 사용자 이름이 `.` 및 `-`를 포함한 단어 문자만으로 이루어진 경우 중괄호로 감싸지 않습니다. 일부 ODBC 드라이버(예: PostgreSQL)는 호스트명이 중괄호로 둘러싸여 있으면 이를 처리하지 못하기 때문입니다. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MySQL과의 호환성을 위해 표준 정수 타입(`BIGINT`, `INT`, ...)의 `SIGNED` 및 `UNSIGNED` 수정자를 지원합니다. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `sumWithOverflow`를 `SimpleAggregateFunction`으로 사용할 수 있도록 했습니다. [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053)를 해결했습니다. [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Hashing 함수에 FixedString 지원을 추가했습니다. [#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).

<div id="bug-fix">
  #### 오동작
</div>

* `SELECT *, xyz.*`와 같은 쿼리에서 오류가 발생해야 하는데도 성공하던 예기치 않은 동작을 수정했습니다. [#11753](https://github.com/ClickHouse/ClickHouse/pull/11753) ([hexiaoting](https://github.com/hexiaoting)).
* 조건에 NULL이 있을 때 `if()`가 잘못된 결과를 반환하던 문제를 수정했습니다. [#11807](https://github.com/ClickHouse/ClickHouse/pull/11807) ([Artem Zuikov](https://github.com/4ertus2)).
* HTTP 인터페이스를 통한 메모리 사용량 집계 문제를 수정했습니다(`wait_end_of_query=1`일 때 영향이 클 수 있습니다). [#11840](https://github.com/ClickHouse/ClickHouse/pull/11840) ([Azat Khuzhin](https://github.com/azat)).
* prewhere 조건에서 `Nullable` 컬럼을 사용할 때 드물게 발생하던 크래시를 수정했습니다. [#11608](https://github.com/ClickHouse/ClickHouse/issues/11608)의 후속 수정입니다. [#11869](https://github.com/ClickHouse/ClickHouse/pull/11869) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#11965](https://github.com/ClickHouse/ClickHouse/issues/11965)에 백포트됨: DateTime64를 파싱할 때 발생할 수 있는 부동소수점 예외를 수정했습니다. 이 수정으로 [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374)가 해결됩니다. [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* DateTime64를 파싱할 때 발생할 수 있는 부동소수점 예외를 수정했습니다. 이 수정으로 [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374)가 해결됩니다. [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#11963](https://github.com/ClickHouse/ClickHouse/issues/11963)에 백포트됨: `USE database` 구문 뒤에 접근 권한을 확인할 때 올바른 현재 데이터베이스를 사용하도록 수정했습니다. [#11920](https://github.com/ClickHouse/ClickHouse/pull/11920) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#12059](https://github.com/ClickHouse/ClickHouse/issues/12059)에 백포트됨: `Nullable` 컬럼이 포함된 튜플 비교가 잘못되던 문제를 수정했습니다. 이 수정으로 [#11985](https://github.com/ClickHouse/ClickHouse/issues/11985)가 해결됩니다. [#12039](https://github.com/ClickHouse/ClickHouse/pull/12039) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* serverless 환경용 간단한 GitHub 후크 스크립트를 추가했습니다. [#11605](https://github.com/ClickHouse/ClickHouse/pull/11605) ([alesapin](https://github.com/alesapin)).
* 가능하면 치명적 오류 발생 시 로그를 클라이언트로 전송하도록 했습니다. 이에 따라 테스트 결과의 가독성이 높아집니다. [#11826](https://github.com/ClickHouse/ClickHouse/pull/11826) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
