<div id="bug-fix">
  #### 오동작 수정
</div>

* [#26283](https://github.com/ClickHouse/ClickHouse/issues/26283)에 백포트됨: UInt64가 아닌 타입에서 `optimize_skip_unused_shards_rewrite_in`을 수정했습니다(잘못된 세그먼트를 선택하거나 `Cannot infer type of an empty tuple` 또는 `Function tuple requires at least one argument` 오류가 발생할 수 있음). [#25798](https://github.com/ClickHouse/ClickHouse/pull/25798) ([Azat Khuzhin](https://github.com/azat)).
* [#26587](https://github.com/ClickHouse/ClickHouse/issues/26587)에 백포트됨: `MaterializeMySQL`에서 조회할 때 발생하던 `Not found column ...` 및 `Missing column ...` 오류를 수정했습니다. [#23708](https://github.com/ClickHouse/ClickHouse/issues/23708), [#24830](https://github.com/ClickHouse/ClickHouse/issues/24830), [#25794](https://github.com/ClickHouse/ClickHouse/issues/25794)를 해결합니다. [#25822](https://github.com/ClickHouse/ClickHouse/pull/25822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26190](https://github.com/ClickHouse/ClickHouse/issues/26190)에 백포트됨: remote()에서 함수 없이 컬럼으로 지정한 sharding&#95;key를 수정했습니다(이전에는 `select * from remote('127.1', system.one, dummy)`가 `Unknown column: dummy, there are only columns .` 오류를 일으켰음). [#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* [#26284](https://github.com/ClickHouse/ClickHouse/issues/26284)에 백포트됨: prewhere와 함께 일반 projection을 사용할 때 발생할 수 있는 헤더 불일치를 수정했습니다. 이 변경으로 [#26020](https://github.com/ClickHouse/ClickHouse/issues/26020)을 해결합니다. [#26038](https://github.com/ClickHouse/ClickHouse/pull/26038) ([Amos Bird](https://github.com/amosbird)).
* [#26298](https://github.com/ClickHouse/ClickHouse/issues/26298)에 백포트됨: 쿼리 실행 중 예외가 발생했을 때 ClickHouse가 전송하는 MySQL 프로토콜 패킷의 잘못된 `sequence_id`를 수정했습니다. 이 문제로 인해 MySQL 클라이언트가 ClickHouse 서버와의 연결을 재설정할 수 있습니다. [#21184](https://github.com/ClickHouse/ClickHouse/issues/21184)를 해결합니다. [#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26204](https://github.com/ClickHouse/ClickHouse/issues/26204)에 백포트됨: `untuple` 표현식을 2개 이상 사용할 때 발생할 수 있는 크래시를 수정했습니다. [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26228](https://github.com/ClickHouse/ClickHouse/issues/26228)에 백포트됨: `system.stack_trace` 테이블의 `thread_name` 컬럼에서 불필요한 줄바꿈을 제거했습니다. 이 변경으로 [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124)를 해결합니다. [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26358](https://github.com/ClickHouse/ClickHouse/issues/26358)에 백포트됨: 합계가 포함된 join에서 발생하는 logical error를 수정했으며, [#26017](https://github.com/ClickHouse/ClickHouse/issues/26017)을 해결합니다. [#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir)).
* [#26788](https://github.com/ClickHouse/ClickHouse/issues/26788)에 백포트됨: 내부 buffer 끝에 escape sequences가 있는 경우의 zstd 압축 해제 문제를 수정했습니다. [#26013](https://github.com/ClickHouse/ClickHouse/issues/26013)을 해결합니다. [#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26360](https://github.com/ClickHouse/ClickHouse/issues/26360)에 백포트됨: 유실된 레플리카 복구 과정에서 드물게 발생하여 레플리카가 서로 달라질 수 있는 버그를 수정했습니다. [#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26452](https://github.com/ClickHouse/ClickHouse/issues/26452)에 백포트됨: 여러 컬럼에 대한 `optimize_distributed_group_by_sharding_key`를 수정했습니다(`optimize_skip_unused_shards=1`/`allow_nondeterministic_optimize_skip_unused_shards=1`이고 세그먼트 분할 키 표현식에 여러 컬럼이 포함된 경우 잘못된 결과가 발생함). [#26353](https://github.com/ClickHouse/ClickHouse/pull/26353) ([Azat Khuzhin](https://github.com/azat)).

[#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar)).
