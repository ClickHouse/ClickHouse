  ### ClickHouse 릴리스 v22.7.1.2484-안정 (f4f05ec786a) FIXME v22.6.1.1985-안정 (7000c4e0033) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 기본적으로 `enable_positional_arguments` 설정을 활성화했습니다. 이 설정을 사용하면 1과 2가 SELECT 절을 참조하는 `SELECT ... ORDER BY 1, 2`와 같은 쿼리를 사용할 수 있습니다. 이전 동작으로 되돌리려면 이 설정을 비활성화하십시오. [#38204](https://github.com/ClickHouse/ClickHouse/pull/38204) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Ordinary` 데이터베이스 엔진과 `*MergeTree` 테이블의 이전 스토리지 정의 구문은 더 이상 권장되지 않습니다. 기본적으로 새로 생성할 수 없습니다. `system` 데이터베이스가 `Ordinary` 엔진을 사용하면 서버 시작 시 자동으로 `Atomic`으로 변환됩니다. 이전 동작을 유지하기 위한 설정(`allow_deprecated_database_ordinary` 및 `allow_deprecated_syntax_for_merge_tree`)이 있지만, 이러한 설정은 향후 릴리스에서 제거될 수 있습니다. [#38335](https://github.com/ClickHouse/ClickHouse/pull/38335) ([Alexander Tokmakov](https://github.com/tavplubix)).
* * 기본적으로 쉼표 join을 inner join으로 재작성하도록 강제합니다(기본값 `cross_to_inner_join_rewrite = 2` 설정). 이전 동작을 사용하려면 `cross_to_inner_join_rewrite = 1`로 설정하십시오. [#39326](https://github.com/ClickHouse/ClickHouse/pull/39326) ([Vladimir C](https://github.com/vdimir)).
* 기본적으로 `format_csv_allow_single_quotes`를 비활성화했습니다. [#37096](https://github.com/ClickHouse/ClickHouse/issues/37096). [#39423](https://github.com/ClickHouse/ClickHouse/pull/39423) ([Kruglov Pavel](https://github.com/Avogar)).

[#37827](https://github.com/ClickHouse/ClickHouse/pull/37827) ([Arthur Passos](https://github.com/arthurpassos)).

* `StorageHive`에 구조체 타입 지원을 추가했습니다. [#38118](https://github.com/ClickHouse/ClickHouse/pull/38118) ([lgbo](https://github.com/lgbo-ustc)).
* Base58 인코딩/디코딩을 추가했습니다. [#38159](https://github.com/ClickHouse/ClickHouse/pull/38159) ([Andrey Zvonov](https://github.com/zvonand)).

* `StorageHive` 테이블에서 `alter` 명령을 지원합니다. [#38214](https://github.com/ClickHouse/ClickHouse/pull/38214) ([lgbo](https://github.com/lgbo-ustc)).
* `CREATE TABLE ... EMPTY AS SELECT` 쿼리를 추가했습니다. 이 쿼리는 SELECT 쿼리에서 테이블 구조를 자동으로 추론하지만, 생성 후 테이블을 채우지는 않습니다. [#38049](https://github.com/ClickHouse/ClickHouse/issues/38049)를 해결합니다. [#38272](https://github.com/ClickHouse/ClickHouse/pull/38272) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 독립 실행형 쿼리를 트랜잭션 내에서 실행하기 위한 새로운 설정 `implicit_transaction`을 추가했습니다. 이 설정은 트랜잭션의 생성과 종료(쿼리가 성공하면 COMMIT, 실패하면 ROLLBACK)를 모두 자동으로 처리합니다. [#38344](https://github.com/ClickHouse/ClickHouse/pull/38344) ([Raúl Marín](https://github.com/Algunenano)).
* 컬럼 목록에서 후행 쉼표를 허용합니다. [#38425](https://github.com/ClickHouse/ClickHouse/issues/38425)를 해결합니다. [#38440](https://github.com/ClickHouse/ClickHouse/pull/38440) ([chen](https://github.com/xiedeyantu)).
* clickhouse를 자체 압축 해제 실행형 파일(path programs/self-extracting)로 압축합니다. 새로운 build 대상 &#39;self-extracting&#39;이 추가되었습니다. [#38447](https://github.com/ClickHouse/ClickHouse/pull/38447) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `additional_table_filters` 설정이 도입되었습니다. 이 설정을 사용하면 읽은 직후 바로 적용되는 테이블의 추가 필터링 조건을 지정할 수 있습니다. 예시: `select number, x, y from (select number from system.numbers limit 5) f any left join (select x, y from table_1) s on f.number = s.x settings additional_table_filters={'system.numbers : 'number != 3', 'table_1' : 'x != 2'}`. 또한 쿼리 결과에 적용할 추가 필터링 조건을 지정하는 `additional_result_filter` 설정도 도입되었습니다. [#37918](https://github.com/ClickHouse/ClickHouse/issues/37918)을 해결했습니다. [#38475](https://github.com/ClickHouse/ClickHouse/pull/38475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* SQLInsert 출력 형식을 추가했습니다. [#38441](https://github.com/ClickHouse/ClickHouse/issues/38441)을 해결했습니다. [#38477](https://github.com/ClickHouse/ClickHouse/pull/38477) ([Kruglov Pavel](https://github.com/Avogar)).
* 다운로드 가능한 ClickHouse 실행 파일은 압축된 자체 압축 해제 형식입니다. [#38653](https://github.com/ClickHouse/ClickHouse/pull/38653) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `isNullable` 함수를 지원합니다. 이 함수는 인수가 널 허용인지 확인하고 true(1) 또는 false(0)을 반환합니다. [#38611](https://github.com/ClickHouse/ClickHouse/issues/38611)을 해결했습니다. [#38841](https://github.com/ClickHouse/ClickHouse/pull/38841) ([lokax](https://github.com/lokax)).
* `translate(string, from_string, to_string)` 및 `translateUTF8(string, from_string, to_string)` 함수를 추가했습니다. [#38935](https://github.com/ClickHouse/ClickHouse/pull/38935) ([Nikolay Degterinsky](https://github.com/evillique)).
* `compatibility` 설정과 ClickHouse 버전별 설정 변경 정보를 담고 있는 `system.settings_changes` 시스템 테이블(system table)을 추가했습니다. [#35972](https://github.com/ClickHouse/ClickHouse/issues/35972)을 해결했습니다. [#38957](https://github.com/ClickHouse/ClickHouse/pull/38957) ([Kruglov Pavel](https://github.com/Avogar)).
* tuple에 멤버가 없을 때 반환할 3번째 매개변수를 tupleElement 함수에 추가했습니다. 이는 2번째 매개변수의 유형이 String인 경우에만 작동합니다. [#38872](https://github.com/ClickHouse/ClickHouse/issues/38872)를 해결했습니다. [#38989](https://github.com/ClickHouse/ClickHouse/pull/38989) ([lokax](https://github.com/lokax)).
* parseTimedelta 함수를 지원합니다. 다음과 같이 사용할 수 있습니다 &#96;&#96;&#96;sql # 구분자로 &#39; &#39;, &#39;;&#39;, &#39;-&#39;, &#39;+&#39;, &#39;,&#39;, &#39;:&#39;를 사용할 수 있습니다. 예: &quot;1yr-2mo&quot;, &quot;2m:6s&quot; SELECT parseTimeDelta(&#39;1yr-2mo-4w + 12 days, 3 hours : 1 minute ; 33 seconds&#39;);. [#39071](https://github.com/ClickHouse/ClickHouse/pull/39071) ([jiahui-97](https://github.com/jiahui-97)).
* 원격 스토리지의 IO 작업을 제한하는 옵션 `max_remote_read_network_bandwidth_for_server` 및 `max_remote_write_network_bandwidth_for_server`를 추가했습니다. [#39095](https://github.com/ClickHouse/ClickHouse/pull/39095) ([Sergei Trifonov](https://github.com/serxa)).
* `send_logs_source_regexp` 설정을 추가했습니다. 지정한 regexp와 일치하는 로그 소스 이름을 가진 server 텍스트 logs를 전송합니다. 비어 있으면 모든 소스를 의미합니다. [#39161](https://github.com/ClickHouse/ClickHouse/pull/39161) ([Amos Bird](https://github.com/amosbird)).
* 이제 OpenTelemetry는 기본적으로 Processors 스팬 없이 traces를 수집합니다. Processors 스팬 수집을 활성화하려면 `opentelemetry_trace_processors` 설정을 사용하십시오. [#39170](https://github.com/ClickHouse/ClickHouse/pull/39170) ([Ilya Yatsishin](https://github.com/qoega)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 비동기 Linux [io&#95;uring](https://kernel.dk/io_uring.pdf) 서브시스템을 기반으로 하는 새로운 `local_filesystem_read_method` 메서드 `io_uring`을 추가하여, 기본 `pread` 메서드와 비교해 거의 모든 경우에서 읽기 성능을 개선했습니다. [#36103](https://github.com/ClickHouse/ClickHouse/pull/36103) ([Saulius Valatka](https://github.com/sauliusvl)).
* 정렬된 컬럼에 대한 distinct 최적화를 추가했습니다. 입력 스트림이 distinct 대상 컬럼을 기준으로 정렬되어 있으면 특화된 distinct 변환을 사용합니다. 이 최적화는 pre-distinct, final distinct 또는 둘 다에 적용될 수 있습니다. 초기 구현: @dimarub2000. [#37803](https://github.com/ClickHouse/ClickHouse/pull/37803) ([Igor Nikonov](https://github.com/devcrafter)).
* LZ4 압축 해제를 위해 VBMI에 최적화된 copyOverlap32Shuffle을 추가했습니다. [#37891](https://github.com/ClickHouse/ClickHouse/pull/37891) ([Guo Wangyang](https://github.com/guowangy)).
* `BinaryHeap`의 배치 버전을 사용해 `ORDER BY`, `MergeTree` 머지, 윈도우 함수의 성능을 개선했습니다. [#38022](https://github.com/ClickHouse/ClickHouse/pull/38022) ([Maksim Kita](https://github.com/kitaisreal)).
* [https://github.com/ClickHouse/ClickHouse/pull/35616](https://github.com/ClickHouse/ClickHouse/pull/35616)에서 도입된 심각한 join 성능 회귀를 수정했습니다. ssb 쿼리와 같은 일반적인 join 쿼리가 거의 3개월 동안 10배 느려졌는데도 아무도 문제를 제기하지 않았다는 점은 흥미롭습니다. [#38052](https://github.com/ClickHouse/ClickHouse/pull/38052) ([Amos Bird](https://github.com/amosbird)).
* Intel hyperscan 라이브러리에서 vectorscan으로 마이그레이션했습니다. 이를 통해 x86 이외 플랫폼에서 많은 문자열 매칭의 속도가 빨라집니다. [#38171](https://github.com/ClickHouse/ClickHouse/pull/38171) ([Robert Schulze](https://github.com/rschu1ze)).
* 집계 후 실행되는 쿼리 계획 단계의 병렬성을 높였습니다. [#38295](https://github.com/ClickHouse/ClickHouse/pull/38295) ([Nikita Taranov](https://github.com/nickitat)).
* `JSON` 유형의 컬럼에 대한 삽입 성능을 개선했습니다. [#38320](https://github.com/ClickHouse/ClickHouse/pull/38320) ([Anton Popov](https://github.com/CurtizJ)).
* HashTable에서 삽입 및 lookup을 최적화했습니다. [#38413](https://github.com/ClickHouse/ClickHouse/pull/38413) ([Nikita Taranov](https://github.com/nickitat)).
* [#32493](https://github.com/ClickHouse/ClickHouse/issues/32493)로 인한 성능 저하를 수정했습니다. [#38417](https://github.com/ClickHouse/ClickHouse/pull/38417) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* SIMD 명령어를 사용한 컬럼 벡터 복제 성능을 개선했습니다. 작성자: @zzachimed. [#38565](https://github.com/ClickHouse/ClickHouse/pull/38565) ([Maksim Kita](https://github.com/kitaisreal)).
* 배열에 대한 Norm 및 Distance functions의 속도가 1.2~2배 빨라졌습니다. [#38740](https://github.com/ClickHouse/ClickHouse/pull/38740) ([Alexander Gololobov](https://github.com/davenger)).
* ORDER BY (a, b)가 있는 쿼리에서는 ORDER BY a, b보다 덜 효율적인 실행 계획이 생성될 수 있습니다. [#38873](https://github.com/ClickHouse/ClickHouse/pull/38873) ([Igor Nikonov](https://github.com/devcrafter)).
* Executable UDF, Executable Dictionary, Executable Storage poll 서브프로세스에서 종료 시 1초 동안 대기하던 문제를 수정했습니다. [#38929](https://github.com/ClickHouse/ClickHouse/pull/38929) ([Constantine Peresypkin](https://github.com/pkit)).
* * 정렬 join의 오른쪽 입력에 filter pushdown을 적용했습니다. [#39123](https://github.com/ClickHouse/ClickHouse/pull/39123) ([Vladimir C](https://github.com/vdimir)).
* system.stack&#95;trace 접근을 최적화했습니다. [#39177](https://github.com/ClickHouse/ClickHouse/pull/39177) ([Azat Khuzhin](https://github.com/azat)).
