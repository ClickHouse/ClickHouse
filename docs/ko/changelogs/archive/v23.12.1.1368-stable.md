  ### ClickHouse 릴리스 v23.12.1.1368-안정 (a2faa65b080) FIXME v23.11.1.2711-안정 (05bc8ef1e02)와 비교

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* TTL 표현식의 비결정적 함수 검사 로직을 수정했습니다. 이전에는 일부 경우 비결정적 함수가 포함된 TTL 표현식을 생성할 수 있었고, 이로 인해 이후 undefined 동작이 발생할 수 있었습니다. 이 변경으로 [#37250](https://github.com/ClickHouse/ClickHouse/issues/37250)을 수정했습니다. 기본적으로 테이블의 어떤 컬럼에도 의존하지 않는 TTL 표현식은 허용되지 않습니다. `SET allow_suspicious_ttl_expressions = 1` 또는 `SET compatibility = '23.11'`를 설정하면 다시 허용할 수 있습니다. [#37286](https://github.com/ClickHouse/ClickHouse/issues/37286)을 종료합니다. [#51858](https://github.com/ClickHouse/ClickHouse/pull/51858) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* bug로 인해 함수 `arrayFold`를 제거했습니다. 이 변경으로 [#57816](https://github.com/ClickHouse/ClickHouse/issues/57816)을 종료합니다. 이 변경으로 [#57458](https://github.com/ClickHouse/ClickHouse/issues/57458)도 종료합니다. [#57836](https://github.com/ClickHouse/ClickHouse/pull/57836) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ReplacingMergeTree의 `is_deleted` 행 기능과 OPTIMIZE 쿼리의 `CLEANUP` 수정자를 제거했습니다. 이 변경으로 [#57930](https://github.com/ClickHouse/ClickHouse/issues/57930)을 수정했습니다. 이 변경으로 [#54988](https://github.com/ClickHouse/ClickHouse/issues/54988)을 종료합니다. 이 변경으로 [#54570](https://github.com/ClickHouse/ClickHouse/issues/54570)도 종료합니다. 이 변경으로 [#50346](https://github.com/ClickHouse/ClickHouse/issues/50346)도 종료합니다. 이 변경으로 [#47579](https://github.com/ClickHouse/ClickHouse/issues/47579)도 종료합니다. 이 기능은 바람직하지 않기 때문에 제거해야 합니다. 다른 선택지가 없으므로 가능한 한 빨리 제거해야 합니다. [#57932](https://github.com/ClickHouse/ClickHouse/pull/57932) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree setting `clean_deleted_rows`는 Deprecated 상태이며, 이제 더 이상 아무런 효과가 없습니다. `OPTIMIZE`의 `CLEANUP` keyword는 기본적으로 허용되지 않습니다(`allow_experimental_replacing_merge_with_cleanup`가 enabled된 경우는 예외). [#58267](https://github.com/ClickHouse/ClickHouse/pull/58267) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="new-feature">
  #### 새 기능
</div>

* GET 요청 전에 HEAD 요청을 비활성화할 수 있습니다. [#54602](https://github.com/ClickHouse/ClickHouse/pull/54602) ([Fionera](https://github.com/fionera)).
* Keeper가 트래픽을 수신할 준비가 되었는지 확인하는 HTTP 엔드포인트를 추가합니다. [#55876](https://github.com/ClickHouse/ClickHouse/pull/55876) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 스키마 추론을 위한 `union` 모드를 추가합니다. 이 모드에서는 결과 테이블 스키마가 모든 파일 스키마의 합집합이 됩니다(즉, 각 파일별로 스키마를 추론함). 스키마 추론 모드는 `schema_inference_mode` 설정으로 제어되며, 가능한 값은 `default`와 `union`의 2가지입니다. [#55428](https://github.com/ClickHouse/ClickHouse/issues/55428)을 해결합니다. [#55892](https://github.com/ClickHouse/ClickHouse/pull/55892) ([Kruglov Pavel](https://github.com/Avogar)).
* CSV 형식에서 문자열로부터 숫자를 추론할 수 있게 하는 새로운 설정 `input_format_csv_try_infer_numbers_from_strings`를 추가합니다. [#56455](https://github.com/ClickHouse/ClickHouse/issues/56455)를 해결합니다. [#56859](https://github.com/ClickHouse/ClickHouse/pull/56859) ([Kruglov Pavel](https://github.com/Avogar)).
* 갱신 가능 구체화 뷰. [#56946](https://github.com/ClickHouse/ClickHouse/pull/56946) ([Michael Kolupaev](https://github.com/al13n321)).
* 데이터베이스와 테이블 수에 대한 경고를 더 추가합니다. [#57375](https://github.com/ClickHouse/ClickHouse/pull/57375) ([凌涛](https://github.com/lingtaolf)).
* 새로운 mutation 명령 `ALTER TABLE <table> APPLY DELETED MASK`를 추가했습니다. 이 명령은 경량한 삭제로 기록된 마스크의 적용을 강제하고, 삭제로 표시된 rows를 디스크에서 제거할 수 있게 합니다. [#57433](https://github.com/ClickHouse/ClickHouse/pull/57433) ([Anton Popov](https://github.com/CurtizJ)).
* Sqids([https://sqids.org/](https://sqids.org/))를 생성하는 새로운 SQL 함수 `sqid`를 추가했습니다. 예시: `SELECT sqid(125, 126)`. [#57512](https://github.com/ClickHouse/ClickHouse/pull/57512) ([Robert Schulze](https://github.com/rschu1ze)).
* `HASHED_ARRAY`(및 `COMPLEX_KEY_HASHED_ARRAY`) layout의 딕셔너리가 `HASHED`와 마찬가지로 `SHARDS`를 지원합니다. [#57544](https://github.com/ClickHouse/ClickHouse/pull/57544) ([vdimir](https://github.com/vdimir)).
* 메모리 내 전체 프라이머리 키 바이트 수와 전체 할당된 프라이머리 키 바이트 수에 대한 비동기 메트릭을 추가합니다. [#57551](https://github.com/ClickHouse/ClickHouse/pull/57551) ([Bharat Nallan](https://github.com/bharatnc)).
* `system.dropped_tables_parts` 테이블에는 `system.dropped_tables` 테이블의 파트(삭제되었지만 아직 제거되지 않은 테이블)가 포함됩니다. [#57555](https://github.com/ClickHouse/ClickHouse/pull/57555) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `FORMAT_BYTES`를 `formatReadableSize`의 alias로 추가합니다. [#57592](https://github.com/ClickHouse/ClickHouse/pull/57592) ([Bharat Nallan](https://github.com/bharatnc)).
* `SHA512_256` 함수를 추가합니다. [#57645](https://github.com/ClickHouse/ClickHouse/pull/57645) ([Bharat Nallan](https://github.com/bharatnc)).
* 선택적 `SESSION_TOKEN`을 `s3` 테이블 함수에 전달할 수 있습니다. [#57850](https://github.com/ClickHouse/ClickHouse/pull/57850) ([Shani Elharrar](https://github.com/shanielh)).
* 이제 `ORDER BY` 절에서 `ALL` 지정을 지원합니다. 이는 ClickHouse가 `SELECT` 절의 모든 컬럼을 기준으로 정렬한다는 뜻입니다. 예시: `SELECT col1, col2 FROM tab WHERE [...] ORDER BY ALL`. [#57875](https://github.com/ClickHouse/ClickHouse/pull/57875) ([zhongyuankai](https://github.com/zhongyuankai)).
* punycode 인코딩/디코딩 함수 `punycodeEncode()` 및 `punycodeDecode()`가 추가되었습니다. [#57969](https://github.com/ClickHouse/ClickHouse/pull/57969) ([Robert Schulze](https://github.com/rschu1ze)).
* 이 PR은 사용자가 `ON` 절 없이 테이블을 조인할 수 있도록 `PASTE JOIN` 구현을 재현합니다. 예시: &#96;&#96;&#96; SQL SELECT * FROM ( SELECT number AS a FROM numbers(2) ) AS t1 PASTE JOIN ( SELECT number AS a FROM numbers(2) ORDER BY a DESC ) AS t2. [#57995](https://github.com/ClickHouse/ClickHouse/pull/57995) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* `/binary` 핸들러는 ClickHouse 바이너리 내부의 심볼을 시각적으로 보여주는 뷰어를 엽니다. [#58211](https://github.com/ClickHouse/ClickHouse/pull/58211) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 버퍼를 거치지 않고 S3 서버 측 복사를 사용해 S3 디스크 간 복사를 수행하도록 개선했습니다. `BACKUP/RESTORE` 작업과 `clickhouse-disks copy` 명령의 성능이 향상됩니다. [#56744](https://github.com/ClickHouse/ClickHouse/pull/56744) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* HashJoin이 `max_joined_block_size_rows` 설정을 준수하여 `ALL JOIN`에서 큰 블록을 생성하지 않도록 했습니다. [#56996](https://github.com/ClickHouse/ClickHouse/pull/56996) ([vdimir](https://github.com/vdimir)).
* 집계에 사용하는 메모리를 더 일찍 해제하도록 개선했습니다. 이를 통해 불필요한 외부 집계를 피할 수 있습니다. [#57691](https://github.com/ClickHouse/ClickHouse/pull/57691) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 문자열 직렬화 성능을 개선했습니다. [#57717](https://github.com/ClickHouse/ClickHouse/pull/57717) ([Maksim Kita](https://github.com/kitaisreal)).
* `Merge` 엔진 테이블에 대해 trivial count 최적화를 지원합니다. [#57867](https://github.com/ClickHouse/ClickHouse/pull/57867) ([skyoct](https://github.com/skyoct)).
* 일부 경우 집계를 최적화했습니다. [#57872](https://github.com/ClickHouse/ClickHouse/pull/57872) ([Anton Popov](https://github.com/CurtizJ)).
* 이제 `hasAny()` 함수가 전문 검색 스킵 인덱스를 활용할 수 있습니다. [#57878](https://github.com/ClickHouse/ClickHouse/pull/57878) ([Jpnock](https://github.com/Jpnock)).
* `if(cond, then, else)` 함수(및 그 별칭인 `cond ? : then : else`)가 분기 없는 평가를 사용하도록 최적화되었습니다. [#57885](https://github.com/ClickHouse/ClickHouse/pull/57885) ([zhanglistar](https://github.com/zhanglistar)).
* FINAL 처리 중 MergeTree 테이블에서 서로 겹치지 않는 파트 범위를 추출합니다. 이를 통해 이러한 파트 범위에 대해서는 추가 FINAL 로직을 피할 수 있습니다. 동일한 프라이머리 키를 가진 중복 값의 수가 적으면 성능이 FINAL을 사용하지 않을 때와 거의 같아집니다. `do_not_merge_across_partitions_select_final` 설정이 지정된 경우 MergeTree FINAL의 읽기 성능을 개선합니다. [#58120](https://github.com/ClickHouse/ClickHouse/pull/58120) ([Maksim Kita](https://github.com/kitaisreal)).
* 파티션 키 표현식에 프라이머리 키 표현식의 컬럼만 포함된 경우, MergeTree가 `do_not_merge_across_partitions_select_final` 설정을 자동으로 유추합니다. [#58218](https://github.com/ClickHouse/ClickHouse/pull/58218) ([Maksim Kita](https://github.com/kitaisreal)).
* 네이티브 타입에서 MIN 및 MAX 성능을 향상했습니다. [#58231](https://github.com/ClickHouse/ClickHouse/pull/58231) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### 개선 사항
</div>

* 분산 테이블에 대한 삽입이 업데이트된 cluster 구성을 올바르게 처리하도록 개선했습니다. cluster 노드 목록이 동적으로 업데이트되면 분산 테이블의 Directory Monitor가 새 노드를 감지하지 못하므로, 이를 감지하려면 Directory Monitor를 다시 초기화해야 합니다. [#42826](https://github.com/ClickHouse/ClickHouse/pull/42826) ([zhongyuankai](https://github.com/zhongyuankai)).
* `--no-system-tables`를 system 데이터베이스의 가상 테이블을 지연 로딩하는 방식으로 대체했습니다. [#55271](https://github.com/ClickHouse/ClickHouse/pull/55271) ([Azat Khuzhin](https://github.com/azat)).
* Clickhouse-test가 단일 테스트 케이스에서 case sn, 현재 시간, case 이름을 출력합니다. [#55710](https://github.com/ClickHouse/ClickHouse/pull/55710) ([guoxiaolong](https://github.com/guoxiaolongzte)).
* 일관되지 않은 머지 파라미터로 복제된 테이블을 생성할 수 없도록 했습니다. [#56833](https://github.com/ClickHouse/ClickHouse/pull/56833) ([Duc Canh Le](https://github.com/canhld94)).
* 파일 시스템 캐시에 SLRU cache policy를 구현했습니다. [#57076](https://github.com/ClickHouse/ClickHouse/pull/57076) ([Kseniia Sumarokova](https://github.com/kssenii)).
* data parts의 checksums에서 얻은 `system.tables`의 압축되지 않은 크기를 표시합니다. [#56618](https://github.com/ClickHouse/ClickHouse/issues/56618). [#57186](https://github.com/ClickHouse/ClickHouse/pull/57186) ([Chen Lixiang](https://github.com/chenlx0)).
* 해당 쿼리 수준 설정과 유사한 `Distributed` tables용 설정으로 `skip_unavailable_shards`를 추가했습니다. [#43666](https://github.com/ClickHouse/ClickHouse/issues/43666)를 해결합니다. [#57218](https://github.com/ClickHouse/ClickHouse/pull/57218) ([Gagan Goel](https://github.com/tntnatbry)).
* 이제 함수 `substring()`(aliases: `substr`, `mid`)를 `Enum` 유형과 함께 사용할 수 있습니다. 이전에는 첫 번째 함수 인수가 `String` 또는 `FixedString` 유형의 값이어야 했습니다. 이를 통해 MySQL interface를 통한 Tableau와 같은 타사 도구와의 호환성이 향상됩니다. [#57277](https://github.com/ClickHouse/ClickHouse/pull/57277) ([Serge Klochkov](https://github.com/slvrtrn)).
* 테이블이 존재하지 않을 때 더 유용한 힌트를 제공합니다. [#57342](https://github.com/ClickHouse/ClickHouse/pull/57342) ([Bharat Nallan](https://github.com/bharatnc)).
* 쿼리 시점에 `max_partition_size_to_drop` 및 `max_table_size_to_drop` server settings를 재정의할 수 있도록 허용합니다. [#57452](https://github.com/ClickHouse/ClickHouse/pull/57452) ([Jordi Villar](https://github.com/jrdi)).
* ZooKeeper 서버에 연결할 때 읽기 전용 플래그를 지원하도록 추가했습니다([#53749](https://github.com/ClickHouse/ClickHouse/issues/53749) 수정). [#57479](https://github.com/ClickHouse/ClickHouse/pull/57479) ([Mikhail Koviazin](https://github.com/mkmkme)).
* &quot;No such file or directory&quot;로 인해 분산 전송이 멈출 수 있는 문제를 수정했습니다(디스크에서 배치를 복구하는 동안). `system.distribution_queue`의 `error_count`와 관련된 잠재적 문제도 수정했습니다(`distributed_directory_monitor_max_sleep_time_ms`가 5분 초과인 경우). async INSERT 실패를 추적하기 위한 profile event `DistributedAsyncInsertionFailures`를 도입했습니다. [#57480](https://github.com/ClickHouse/ClickHouse/pull/57480) ([Azat Khuzhin](https://github.com/azat)).
* 백그라운드 페치에 대해 endpoint당 연결 수 제한을 `15`에서 `background_fetches_pool_size` 설정 값으로 상향했습니다. - MergeTree 수준 설정 `replicated_max_parallel_fetches_for_host`는 obsolete 상태가 되었습니다. - MergeTree 수준 설정 `replicated_fetches_http_connection_timeout`, `replicated_fetches_http_send_timeout`, `replicated_fetches_http_receive_timeout`은 서버 수준으로 이동했습니다. - `keep_alive_timeout` 설정이 서버 수준 설정 목록에 추가되었습니다. [#57523](https://github.com/ClickHouse/ClickHouse/pull/57523) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 이제 인덱스(프라이머리 키가 아닌) 정의에서 ALIAS 컬럼을 참조할 수 있습니다(issue [#55650](https://github.com/ClickHouse/ClickHouse/issues/55650)). 예시: `CREATE TABLE tab(col UInt32, col_alias ALIAS col + 1, INDEX idx (col_alias) TYPE minmax) ENGINE = MergeTree ORDER BY col;`. [#57546](https://github.com/ClickHouse/ClickHouse/pull/57546) ([Robert Schulze](https://github.com/rschu1ze)).
* 이제 `format()` 함수가 임의의 인수 타입을 지원합니다(기존에는 `String` 및 `FixedString` 인수만 지원). 이는 `SELECT format('The {0} to all questions is {1}', 'answer', 42)`를 계산할 때 중요합니다. [#57549](https://github.com/ClickHouse/ClickHouse/pull/57549) ([Robert Schulze](https://github.com/rschu1ze)).
* `MaterializedPostgreSQL`에서 PostgreSQL 생성 컬럼과 기본 컬럼 값을 지원합니다. [#40449](https://github.com/ClickHouse/ClickHouse/issues/40449)을 닫습니다. [#57568](https://github.com/ClickHouse/ClickHouse/pull/57568) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 일부 파일 시스템 캐시 구성 설정 변경을 서버 재시작 없이 적용할 수 있습니다. [#57578](https://github.com/ClickHouse/ClickHouse/pull/57578) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 빈 배열로 PostgreSQL 테이블 구조를 가져올 때 발생하는 sigabrt 사례를 처리합니다. [#57618](https://github.com/ClickHouse/ClickHouse/pull/57618) ([Mike Kot (Михаил Кот)](https://github.com/myrrc)).
* 이제 `date_trunc()` 함수의 첫 번째 인수는 대소문자를 구분하지 않고 사용할 수 있습니다. 이제 `SELECT date_trunc('day', now())`와 `SELECT date_trunc('DAY', now())`를 모두 지원합니다. [#57624](https://github.com/ClickHouse/ClickHouse/pull/57624) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 마지막 서버 재시작 이후 발생한 총 오류 수를 `ClickHouseErrorMetric_ALL` 메트릭으로 노출합니다. [#57627](https://github.com/ClickHouse/ClickHouse/pull/57627) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* from&#95;env/from&#95;zk가 있고 replace=1인 비어 있지 않은 요소를 포함한 구성의 노드를 허용합니다. [#57628](https://github.com/ClickHouse/ClickHouse/pull/57628) ([Azat Khuzhin](https://github.com/azat)).
