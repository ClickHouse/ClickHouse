<div id="performance-improvement">
  #### 성능 개선
</div>

* [#46372](https://github.com/ClickHouse/ClickHouse/issues/46372)에서 백포트됨: 비원격 디스크에서 수직 병합 시 메모리 사용량이 과도하게 커지는 문제를 수정했습니다. 원격 디스크에서는 `max_insert_delayed_streams_for_parallel_write`를 준수하도록 했습니다. [#46275](https://github.com/ClickHouse/ClickHouse/pull/46275) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#46357](https://github.com/ClickHouse/ClickHouse/issues/46357)에서 백포트됨: Compact 포맷의 파트에도 수직 병합 알고리즘을 사용할 수 있도록 했습니다. 이에 따라 ClickHouse 서버가 백그라운드 작업에서 훨씬 적은 메모리를 사용할 수 있게 됩니다. 이로써 [#46084](https://github.com/ClickHouse/ClickHouse/issues/46084)가 해결됩니다. [#46282](https://github.com/ClickHouse/ClickHouse/pull/46282) ([Anton Popov](https://github.com/CurtizJ)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#45856](https://github.com/ClickHouse/ClickHouse/issues/45856)에 백포트됨: ZooKeeper 다운로드를 수정하고, 버전을 업데이트했으며, 이미지 크기를 최적화했습니다. [#44853](https://github.com/ClickHouse/ClickHouse/pull/44853) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 보이는 오동작)
</div>

* [#45620](https://github.com/ClickHouse/ClickHouse/issues/45620)에 백포트됨: remote fs에서 `LowCardinality` 딕셔너리를 읽는 중 발생할 수 있는 `Cannot read all data` 오류에 대한 추가 수정입니다. [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709)를 해결합니다. [#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#45549](https://github.com/ClickHouse/ClickHouse/issues/45549)에 백포트됨: 구조가 잘못된 딕셔너리(예: XML 구성에서 유형이 잘못된 경우)가 있을 때 발생하는 `SELECT ... FROM system.dictionaries` 예외를 수정합니다. [#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
