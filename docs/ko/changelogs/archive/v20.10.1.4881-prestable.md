<div id="clickhouse-release-v201014881-prestable-fixme-as-compared-to-v20914585-prestable">
  ### ClickHouse 릴리스 v20.10.1.4881-prestable FIXME, v20.9.1.4585-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* SQL에서 중첩된 여러 줄 주석 `/* comment /* comment */ */`을 지원합니다. 이는 SQL 표준을 따릅니다. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `format_regexp_escaping_rule` 설정(`Regexp` 포맷 관련)의 기본값을 `Raw`로 변경했습니다. 이는 전체 하위 패턴을 하나의 값으로 읽는다는 의미이며, 동작을 사용자가 일반적으로 기대하는 방식에 더 가깝게 맞추기 위한 것입니다. [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version`을 더 이상 사용하지 않도록 했습니다. 조인 재작성기의 첫 번째 버전을 제거했습니다. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### 새 기능
</div>

* MySQL 타입 지원: `decimal`(ClickHouse `Decimal`로) 및 하위 초 정밀도의 `datetime`(`DateTime64`로). ... [#11512](https://github.com/ClickHouse/ClickHouse/pull/11512) ([Vasily Nemkov](https://github.com/Enmk)).
* 삽입, 머지 및 fetch 작업에서 fsync를 활성화할 수 있습니다. [#11948](https://github.com/ClickHouse/ClickHouse/pull/11948) ([Anton Popov](https://github.com/CurtizJ)).
* 클러스터 간 쿼리 실행을 안전하게 보호합니다(`initial&#95;user`를 현재 쿼리 사용자로 사용). [#13156](https://github.com/ClickHouse/ClickHouse/pull/13156) ([Azat Khuzhin](https://github.com/azat)).
* * `mapPopulateSeries` 함수를 추가했습니다. [#13166](https://github.com/ClickHouse/ClickHouse/pull/13166) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 구성 파일의 `<replicated_merge_tree>` 섹션에서 `ReplicatedMergeTree*` 스토리지의 설정을 지정할 수 있도록 했습니다. 이는 `<merge_tree>` 섹션과 비슷하게 동작합니다. `ReplicatedMergeTree*` 스토리지에는 `<merge_tree>`와 `<replicated_merge_tree>`의 설정이 함께 적용되며, `<replicated_merge_tree>`의 설정이 더 높은 우선순위를 가집니다. `system.replicated_merge_tree_settings` 테이블도 추가했습니다. [#13573](https://github.com/ClickHouse/ClickHouse/pull/13573) ([Amos Bird](https://github.com/amosbird)).
* 새 기능 추가: 줄바꿈, 공백 및/또는 쉼표로 구분된 선의 시퀀스를 허용하는 LineAsString 포맷을 추가했습니다. [#13846](https://github.com/ClickHouse/ClickHouse/pull/13846) ([hexiaoting](https://github.com/hexiaoting)).
* 분산 쿼리에서 리프 노드가 읽을 수 있는 최대 행 수/바이트 수를 제한하기 위한 새로운 query complexity 제한 설정 `max_rows_to_read_leaf`, `max_bytes_to_read_leaf`를 추가했습니다. 이 제한은 루트 노드의 최종 머지 단계를 **제외하고** 로컬 읽기에만 적용됩니다. [#14221](https://github.com/ClickHouse/ClickHouse/pull/14221) ([Roman Khavronenko](https://github.com/hagen1778)).
* 데이터를 문자열 배열 형태로 출력하는 JSONStrings 포맷을 추가했습니다. [#14333](https://github.com/ClickHouse/ClickHouse/pull/14333) ([hcz](https://github.com/hczhcz)).
* 이제 insert statements의 컬럼 목록에서 컬럼 변환기와 함께 애스터리스크(또는 그 변형)를 사용할 수 있습니다. [#14453](https://github.com/ClickHouse/ClickHouse/pull/14453) ([Amos Bird](https://github.com/amosbird)).
* git 리포지토리를 ClickHouse로 가져오는 script를 추가했습니다. [#14471](https://github.com/ClickHouse/ClickHouse/pull/14471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree 테이블 엔진 family에 대해 `TTL ... RECOMPRESS codec_name`를 지정할 수 있는 기능을 추가했습니다. [#14494](https://github.com/ClickHouse/ClickHouse/pull/14494) ([alesapin](https://github.com/alesapin)).
* `system.asynchronous_metric_log` 및 `system.metric_log` 테이블에 event&#95;time&#95;microseconds를 추가했습니다. [#14514](https://github.com/ClickHouse/ClickHouse/pull/14514) ([Bharat Nallan](https://github.com/bharatnc)).
* 새 기능 추가: SHOW DATABASES LIKE &#39;xxx&#39;. [#14521](https://github.com/ClickHouse/ClickHouse/pull/14521) ([hexiaoting](https://github.com/hexiaoting)).
* MaterializedMySQL에서 Decimal 데이터 타입을 지원합니다. [#14535](https://github.com/ClickHouse/ClickHouse/pull/14535) ([Winter Zhang](https://github.com/zhang2014)).
* TSV 출력 형식에 대해 NULL 표현을 구성 가능하게 했습니다. 이는 기본값이 `\N`인 `output_format_tsv_null_representation` 설정으로 제어됩니다. 이 변경으로 [#9375](https://github.com/ClickHouse/ClickHouse/issues/9375)가 해결되었습니다. 이 설정은 출력 형식에만 적용되며, TSV 입력 형식에서 지원되는 NULL 표현은 `\N`뿐이라는 점에 유의하십시오. [#14586](https://github.com/ClickHouse/ClickHouse/pull/14586) ([Kruglov Pavel](https://github.com/Avogar)).
* 새 기능 추가: 줄바꿈, 공백 및/또는 쉼표로 구분된 선의 시퀀스를 허용하는 LineAsString 포맷을 추가했습니다. [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `formatReadableQuantity` 함수를 추가했습니다. 큰 숫자를 사람이 읽기 쉽게 표시할 때 유용합니다. [#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* 컬럼 속성과 테이블 TTL을 제거하는 기능을 추가했습니다. `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` 및 `ALTER TABLE REMOVE TTL` 쿼리를 도입했습니다. 두 작업 모두 lightweight하며 metadata 수준에서 수행됩니다. [#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* `system.text_log`, `system.trace_log`, `system.query_log`, `system.query_thread_log` 테이블에 `event&#95;time&#95;microseconds` 필드를 추가했습니다. [#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* 이제 쿼리 Context에서 이름이 지정된 서브쿼리를 도입할 수 있도록 `WITH <identifier> AS (subquery) ... `를 지원합니다. 이로써 [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416)과 [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967)이 해결되었습니다. [#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* 구성에 기본값이 지정된 경우 Replicated 테이블 엔진의 인수를 생략할 수 있도록 했습니다. [#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* 테이블 함수 `null('structure')`를 추가했습니다. [#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* 쿼리 난독화 도구를 추가했습니다. 이를 통해 테스트 품질 향상을 위해 더 많은 쿼리를 공유할 수 있습니다. 이로써 [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268)이 해결되었습니다. [#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `RawBLOB` 포맷을 추가했습니다. 이 포맷은 이스케이프 및 구분 기호 없이 단일 값을 입력하거나 출력하기 위한 것입니다. 이로써 [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349)가 해결되었습니다. [#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [15350](https://github.com/ClickHouse/ClickHouse/issues/15350)을 수정했습니다. [#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* 첫 번째 select의 `WITH` SQL 문을 동일 수준의 다른 select 쿼리로 전파하고, `WITH` SQL 문의 alias를 서브쿼리에서 참조할 수 있게 하는 `enable_global_with_statement` 설정을 도입했습니다. [#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* big-endian 바이트 문자열을 UUID로 변환할 수 있는 `reinterpretAsUUID` 함수를 추가했습니다. [#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 병렬 quorum 삽입을 추가했습니다. 이로써 [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601)이 해결되었습니다. [#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* 작은 파트에 대해 compact 파트를 기본으로 활성화했습니다. 이에 따라 빈번한 삽입을 약간 더 효율적으로 처리할 수 있습니다(4..100배). [#11913](https://github.com/ClickHouse/ClickHouse/pull/11913) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* wide integers의 기본 타입으로 8-bit 타입 대신 (u)int64&#95;t를 사용해 256-bit 연산 성능을 개선했습니다. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* clickhouse-server 시작 시에는 `mlock`으로 code segment만 잠급니다. 이전 버전에서는 debug info를 포함해 매핑된 모든 영역이 메모리에 잠겨 있었습니다. debug info는 보통 별도 파일로 분리되지만, 그렇지 않은 경우 메모리 사용량이 2..3 GiB 증가했습니다. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이전에는 하나의 fixed string으로 group by할 때 fixed key 메서드를 선택했습니다. 하지만 FixedString 컬럼에 대해 유사한 packedFix 최적화를 수행하는 StringHashTable이 있으므로 이는 불필요합니다. 또한 가능하면 low&#95;cardinality&#95;key&#95;fixed&#95;string을 사용해야 합니다. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* `DateTime <op> DateTime`에서 실수로 느린 일반 구현이 선택되던 문제를 수정했습니다. 이로써 [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153)가 해결됩니다. [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* 반복문에서 여러 DeleteObject를 사용하는 대신 하나의 S3 DeleteObjects request를 사용합니다. 기능 변경은 없으므로 integration/test&#95;log&#95;family&#95;s3와 같은 기존 테스트로 검증됩니다. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* 256-bit 곱셈 성능을 개선했습니다. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* `quantileTDigest` 성능을 개선했습니다. 이로써 [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668)가 해결됩니다. [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* 수직 병합 임시 데이터를 저장할 때 임시 디스크를 명시적으로 사용합니다. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).



<div id="improvement">
  #### 개선 사항
</div>

* 중복 `block`이 로컬에 없는 레플리카(즉, 다른 레플리카에서 아직 fetch하지 않은 상태)에 기록되는 경우, 이를 무시하지 않고 로컬에도 기록하여 정상적으로 복제된 경우와 동일한 효과를 내도록 했습니다. [#11684](https://github.com/ClickHouse/ClickHouse/pull/11684) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* compact 파트에서 사용자 지정 코덱을 지원합니다. [#12183](https://github.com/ClickHouse/ClickHouse/pull/12183) ([Anton Popov](https://github.com/CurtizJ)).
* 이제 joinGet이 다중 키 lookup을 지원합니다. [#12418](https://github.com/ClickHouse/ClickHouse/issues/12418)의 후속 작업입니다. [#13015](https://github.com/ClickHouse/ClickHouse/pull/13015) ([Amos Bird](https://github.com/amosbird)).
* VALUES 형식의 인라인 데이터가 포함된 INSERT에서, 줄바꿈뿐 아니라 세미콜론도 데이터 종료 기호로 지원합니다. [#12288](https://github.com/ClickHouse/ClickHouse/issues/12288)을 닫습니다. [#13192](https://github.com/ClickHouse/ClickHouse/pull/13192) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 이제 SYSTEM RELOAD CONFIG는 reload에 실패하면 예외를 발생시키고, 이전 users.xml을 계속 사용합니다. 백그라운드 주기 reload 역시 실패하면 이전 users.xml을 계속 사용합니다. [#14492](https://github.com/ClickHouse/ClickHouse/pull/14492) ([Vitaly Baranov](https://github.com/vitlibar)).
* DiskS3에 대한 접근 검사 건너뛰기 옵션을 추가했습니다. [#14497](https://github.com/ClickHouse/ClickHouse/pull/14497) ([Pavel Kovalenko](https://github.com/Jokser)).
* ClickHouse는 partition expr과 key expr을 서로 다르게 처리합니다. partition expr은 관련 컬럼이 포함된 minmax 인덱스를 구성하는 데 사용되고, primary key expr은 expr로 저장됩니다. 경우에 따라 사용자는 `partition by i / 1000`처럼 더 거친 단위로 테이블을 파티션할 수 있습니다. 하지만 binary 연산자는 단조적이지 않으므로, 이 PR은 이 문제를 수정하려고 합니다. 다른 사용 사례에도 도움이 될 수 있습니다. [#14513](https://github.com/ClickHouse/ClickHouse/pull/14513) ([Amos Bird](https://github.com/amosbird)).
* 쿼리 포맷의 일부 후행 공백을 수정했습니다. [#14595](https://github.com/ClickHouse/ClickHouse/pull/14595) ([Azat Khuzhin](https://github.com/azat)).
* `QueryMemoryLimitExceeded` 이벤트를 추가했습니다. 이로써 [#14589](https://github.com/ClickHouse/ClickHouse/issues/14589)가 닫힙니다. [#14647](https://github.com/ClickHouse/ClickHouse/pull/14647) ([fastio](https://github.com/fastio)).
* 함수에 대해 디버그 정보 없이 build할 수 있는 옵션을 제공하여 하위 호환되지 않는 변경을 수정했습니다. [#14657](https://github.com/ClickHouse/ClickHouse/pull/14657) ([Mike Kot](https://github.com/myrrc)).
* ZooKeeper 구성을 동적으로 reload할 수 있습니다. [#14678](https://github.com/ClickHouse/ClickHouse/pull/14678) ([sundyli](https://github.com/sundy-li)).
* 분산 DDL의 병렬 실행을 허용합니다. [#14684](https://github.com/ClickHouse/ClickHouse/pull/14684) ([Azat Khuzhin](https://github.com/azat)).
* ZooKeeper exists watch로 인해 발생할 수 있는 메모리 누수 가능성을 수정했습니다. [#14693](https://github.com/ClickHouse/ClickHouse/pull/14693) ([hustnn](https://github.com/hustnn)).
* `MaterializeMySQL` 데이터베이스 엔진에서 발생하던 &quot;Packet payload is not fully read&quot; 오류를 수정했습니다. [#14696](https://github.com/ClickHouse/ClickHouse/pull/14696) ([BohuTANG](https://github.com/BohuTANG)).
* 음수의 큰 정수로 호출했을 때 `bitShiftLeft()`에서 발생하던 크래시를 수정했습니다. [#14697](https://github.com/ClickHouse/ClickHouse/pull/14697) ([Artem Zuikov](https://github.com/4ertus2)).
* 머지 점검을 개선하기 위해 system.merges 테이블에 `merge_algorithm`을 추가했습니다. [#14705](https://github.com/ClickHouse/ClickHouse/pull/14705) ([Amos Bird](https://github.com/amosbird)).
* FunctionBinaryArithmetic의 DecimalBinaryOperation 템플릿에서 생성되는 불필요한 코드가 줄어들었습니다. [#14743](https://github.com/ClickHouse/ClickHouse/pull/14743) ([Artem Zuikov](https://github.com/4ertus2)).
* 이제 `columns`를 사용해 컬럼 목록을 감싼 뒤 컬럼 변환기를 적용할 수 있습니다. [#14775](https://github.com/ClickHouse/ClickHouse/pull/14775) ([Amos Bird](https://github.com/amosbird)).
* StorageJoin 및 StorageSet의 영속성을 비활성화하는 기능을 지원하며, 이 기능은 `disable_set_and_join_persistency` 설정으로 제어됩니다. 또한 이 PR은 [#6318](https://github.com/ClickHouse/ClickHouse/issues/6318) 이슈를 해결했습니다. [#14776](https://github.com/ClickHouse/ClickHouse/pull/14776) ([vxider](https://github.com/Vxider)).
* `query_start_time` 및 `query_start_time_microseconds`를 동일한 timespec으로부터 생성합니다. [#14831](https://github.com/ClickHouse/ClickHouse/pull/14831) ([Bharat Nallan](https://github.com/bharatnc)).
* 분산(Distributed) 스토리지에서 멀티 볼륨 스토리지 구성을 사용할 수 있도록 했습니다. [#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
