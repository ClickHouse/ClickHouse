<div id="clickhouse-release-v22112542-prestable-fixme-as-compared-to-v211219017-prestable">
  ### ClickHouse 릴리스 v22.1.1.2542-prestable FIXME, v21.12.1.9017-prestable 대비
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 공유 데이터용 zero-copy 마크의 ZooKeeper 경로를 변경했습니다. 이름이 변경된 파트의 마크를 ZooKeeper에서 제거할 때 발생하던 문제를 수정했습니다. [#32061](https://github.com/ClickHouse/ClickHouse/pull/32061) ([ianton-ru](https://github.com/ianton-ru)).
* * 스칼라 서브쿼리를 반영했습니다. 이 변경으로 스칼라 서브쿼리에서 읽은 행도 이제 query&#95;log에 보고됩니다. 스칼라 서브쿼리가 캐시되는 경우(반복되거나 여러 행에 대해 호출되는 경우) 읽은 행 수는 한 번만 계산됩니다. 이 변경으로 스칼라 서브쿼리 실행 중에도 쿼리를 KILL하고 진행 상황을 보고할 수 있습니다. [#32271](https://github.com/ClickHouse/ClickHouse/pull/32271) ([Raúl Marín](https://github.com/Algunenano)).
* `left`, `right`, `leftUTF8`, `rightUTF8` 함수를 추가했습니다. 음수 OFFSET(문자열 끝을 기준으로 한 OFFSET)에서 `substringUTF8` 함수 구현의 오류를 수정했습니다. `left` 및 `right` 함수는 이전에는 파서에 구현되어 있었습니다. 업그레이드 참고 사항: 클러스터에 서로 다른 버전의 clickhouse-server가 포함되어 있으면 alias 없이 `left` 또는 `right` 함수를 사용하는 분산 쿼리에서 예외가 발생할 수 있습니다. 클러스터 업그레이드 중 이 오류가 발생하면 모든 노드의 버전이 같아지도록 업그레이드를 완료해야 합니다. 또한 이 문제를 방지하려면 쿼리의 컬럼에 alias(`AS something`)를 추가할 수 있습니다. [#33407](https://github.com/ClickHouse/ClickHouse/pull/33407) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 새 기능
</div>

* 희소 serialization을 구현했습니다. 기본값(0)이 많은 컬럼의 경우 디스크 공간 사용량을 줄이고 일부 쿼리 성능을 개선할 수 있습니다. `ratio_of_defaults_for_sparse_serialization`을 설정하면 활성화할 수 있습니다. 기본값 개수와 전체 값 개수의 비율이 해당 임계값을 초과하면 해당 컬럼에 대해 희소 serialization이 동적으로 선택됩니다. serialization(기본 또는 희소)은 각 파트의 각 컬럼마다 고정되지만, 파트마다 달라질 수 있습니다. [#22535](https://github.com/ClickHouse/ClickHouse/pull/22535) ([Anton Popov](https://github.com/CurtizJ)).
* GROUP BY grouping sets (a, b, (a, b))와 같은 grouping sets 함수를 추가했습니다. [#26869](https://github.com/ClickHouse/ClickHouse/pull/26869) ([taylor12805](https://github.com/taylor12805)).
* 분산 쿼리 중 세그먼트 내의 모든 레플리카에서 읽을 수 있는 기능을 추가했습니다. 이를 활성화하려면 `allow_experimental_parallel_reading_from_replicas=true`로 설정하고 `max_parallel_replicas`를 임의의 숫자로 지정하십시오. 이로써 [#26748](https://github.com/ClickHouse/ClickHouse/issues/26748)이 해결됩니다. [#29279](https://github.com/ClickHouse/ClickHouse/pull/29279) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 호스트 및 포트 구성이 변경되면 서버를 시작하거나 중지합니다. [#30549](https://github.com/ClickHouse/ClickHouse/pull/30549) ([Kevin Michel](https://github.com/kmichel-aiven)).
* comment와 함께 모든 종류의 view를 생성할 수 있습니다. ... [#31062](https://github.com/ClickHouse/ClickHouse/pull/31062) ([Vasily Nemkov](https://github.com/Enmk)).
* ClickHouse에서 Apache Hive에 액세스할 수 있도록 Hive 테이블 엔진을 구현했습니다. 관련 RFC: [#29245](https://github.com/ClickHouse/ClickHouse/issues/29245). [#31104](https://github.com/ClickHouse/ClickHouse/pull/31104) ([李扬](https://github.com/taiyang-li)).
* * Zoo/Keeper를 통한 클러스터 자동 디스커버리. [#31442](https://github.com/ClickHouse/ClickHouse/pull/31442) ([Vladimir C](https://github.com/vdimir)).
* AWS S3 기반 디스크와 유사한 방식으로 Azure Blob Storage 기반 디스크 지원을 추가했습니다. 현재 구현은 모든 기본적인 디스크 작업을 지원합니다. [#31505](https://github.com/ClickHouse/ClickHouse/pull/31505) ([Jakub Kuklis](https://github.com/jkuklis)).
* * MaterializedMySQL 테이블 스키마를 사용자 지정할 수 있는 &quot;TABLE OVERRIDE&quot; 기능을 추가했습니다. [#32325](https://github.com/ClickHouse/ClickHouse/pull/32325) ([Stig Bakken](https://github.com/stigsb)).
* 입력 형식에 대한 데이터 스키마 추론을 구현합니다. 테이블 함수 `file`, `url`, `s3`, `hdfs`와 `clickhouse-local`의 매개변수에서 구조를 생략하거나 `auto`만 지정할 수 있습니다. 또한 테이블 엔진 `File`, `HDFS`, `S3`, `URL`, `Merge`, `Buffer`, `Distributed`, `ReplicatedMergeTree`에 대한 CREATE 쿼리에서도 구조를 생략할 수 있습니다(새 레플리카를 추가하는 경우). [#32455](https://github.com/ClickHouse/ClickHouse/pull/32455) ([Kruglov Pavel](https://github.com/Avogar)).
* MaterializedPostgreSQL에 TABLE OVERRIDE 절 지원을 추가합니다. RFC: [#31480](https://github.com/ClickHouse/ClickHouse/issues/31480). [#32749](https://github.com/ClickHouse/ClickHouse/pull/32749) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `EXPLAIN TABLE OVERRIDE` 쿼리를 추가합니다. [#32836](https://github.com/ClickHouse/ClickHouse/pull/32836) ([Stig Bakken](https://github.com/stigsb)).
* `SET` 쿼리 또는 HTTP request의 쿼리 매개변수를 사용해 잘못된 setting이 정의된 경우, 오류 메시지에 해당 setting 문자열과 유사한 제안이 포함됩니다(있는 경우). [#32946](https://github.com/ClickHouse/ClickHouse/pull/32946) ([Antonio Andelic](https://github.com/antonio2368)).
* 집계 함수 `cramersV`, `cramersVBiasCorrected`, `theilsU`, `contingency`를 추가합니다. 이 함수들은 범주형 값 사이의 종속성(연관성의 척도)을 계산합니다. 이 함수들은 모두 교차표(값 쌍에 대한 histogram)를 사용해 구현됩니다. 숫자일 필요가 없는 임의의 이산 값에 대한 상관계수와 비슷하다고 생각할 수 있습니다. [#33366](https://github.com/ClickHouse/ClickHouse/pull/33366) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `arrayLast` 함수를 추가했습니다. [#33390](https://github.com/ClickHouse/ClickHouse/issues/33390)을 해결합니다. [#33415](https://github.com/ClickHouse/ClickHouse/pull/33415) ([Maksim Kita](https://github.com/kitaisreal)).
* MONTHNAME 함수를 추가합니다. [#33436](https://github.com/ClickHouse/ClickHouse/pull/33436) ([usurai](https://github.com/usurai)).
* 파일 확장자를 자동으로 감지합니다. [#30918](https://github.com/ClickHouse/ClickHouse/issues/30918)을 해결합니다. [#33443](https://github.com/ClickHouse/ClickHouse/pull/33443) ([zhongyuankai](https://github.com/zhongyuankai)).
* `arrayLastIndex` 함수를 추가했습니다. [#33465](https://github.com/ClickHouse/ClickHouse/pull/33465) ([Maksim Kita](https://github.com/kitaisreal)).
* 새로운 h3 기타 함수 `h3DegsToRads`, `h3RadsToDegs`, `h3HexAreaKm2`, `h3CellAreaM2`, `h3CellAreaRads2`를 추가합니다. [#33479](https://github.com/ClickHouse/ClickHouse/pull/33479) ([Bharat Nallan](https://github.com/bharatnc)).
* file/hdfs/s3/url 테이블 함수와 HDFS/S3/URL 테이블 엔진에서 파일 확장자를 기준으로 포맷을 감지합니다. [#33565](https://github.com/ClickHouse/ClickHouse/pull/33565) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 의미 있는 수준의 변경은 아닙니다. 극히 드물게 모든 레플리카에서 데이터 파트가 손실되는 경우, 일부 데이터 파트가 병합된 후 후속 쿼리에서 파티션 프루닝 시 건너뛰는 파티션 수가 다소 줄어들 수 있습니다. 이는 거의 영향을 미치지 않습니다. [#32220](https://github.com/ClickHouse/ClickHouse/pull/32220) ([Azat Khuzhin](https://github.com/azat)).
* `reinterpret` 함수의 성능이 소폭 개선되었습니다. [#32587](https://github.com/ClickHouse/ClickHouse/pull/32587) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 문자열 속성이 있는 딕셔너리에 할당되는 메모리를 줄였습니다. [#33466](https://github.com/ClickHouse/ClickHouse/pull/33466) ([Maksim Kita](https://github.com/kitaisreal)).
* 파서에서 지수적 백트래킹이 발생하지 않도록 했습니다. 이로써 [#20158](https://github.com/ClickHouse/ClickHouse/issues/20158)가 해결되었습니다. [#33481](https://github.com/ClickHouse/ClickHouse/pull/33481) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* 이제 1970-01-01 00:00:00 이전 시간을 생성하는 date time 변환 함수는 오버플로우 대신 0으로 포화됩니다. [#29953](https://github.com/ClickHouse/ClickHouse/pull/29953) ([Amos Bird](https://github.com/amosbird)).
* `StorageExecutable`, `StorageExecutablePool`, `ExecutableDictionary`, `ExecutablePoolDictionary`, `ExecutableUserDefinedFunctions`에 `command_read_timeout`, `command_write_timeout` 설정을 추가했습니다. `command_read_timeout` 설정은 명령의 stdout에서 데이터를 읽는 timeout을 밀리초 단위로 제어합니다. `command_write_timeout` 설정은 명령의 stdin에 데이터를 쓰는 timeout을 밀리초 단위로 제어합니다. `ExecutableUserDefinedFunction`, `ExecutableDictionary`, `StorageExecutable`에 `command_termination_timeout` 설정을 추가했습니다. `ExecutableUserDefinedFunction`에 `execute_direct` 설정을 추가했으며, 기본값은 true입니다. `ExecutableDictionary`, `ExecutablePoolDictionary`에 `execute_direct` 설정을 추가했으며, 기본값은 false입니다. [#30957](https://github.com/ClickHouse/ClickHouse/pull/30957) ([Maksim Kita](https://github.com/kitaisreal)).
* 단일 part PROJECTION 머티리얼라이즈를 최적화했습니다. 이 변경으로 [#31669](https://github.com/ClickHouse/ClickHouse/issues/31669)가 해결됩니다. [#31885](https://github.com/ClickHouse/ClickHouse/pull/31885) ([Amos Bird](https://github.com/amosbird)).
