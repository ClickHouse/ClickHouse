<div id="new-feature">
  #### 새 기능
</div>

* (운영 환경용으로는 아직 준비되지 않았으며, 실험적 기능에 포함됨) `MemoryTracker`에 메모리 오버커밋을 추가했습니다. 소프트 메모리 제한을 나타내는 메모리 제한용 `guaranteed` 설정도 추가했습니다. 하드 메모리 제한에 도달하면 `MemoryTracker`는 가장 많이 오버커밋된 쿼리를 취소하려고 시도합니다. 새로운 설정 `memory_usage_overcommit_max_wait_microseconds`는 한 쿼리가 다른 쿼리가 중지될 때까지 얼마나 오래 기다릴 수 있는지를 지정합니다. [#28375](https://github.com/ClickHouse/ClickHouse/issues/28375)를 해결합니다. [#31182](https://github.com/ClickHouse/ClickHouse/pull/31182) ([Dmitry Novik](https://github.com/novikd)).
* 이 설정을 사용하면 MergeTree/ReplicatedMergeTree에서 사용자 정의 중복 제거 방식을 지정할 수 있습니다. 이 설정이 제공되면 block ID를 생성할 때 데이터 다이제스트 대신 이 값이 사용됩니다. 따라서 예를 들어 각 INSERT SQL 문에 이 설정의 고유한 값을 지정하면, 동일하게 삽입된 데이터가 중복 제거되는 것을 방지할 수 있습니다. 다음을 해결합니다: [#7461](https://github.com/ClickHouse/ClickHouse/issues/7461). [#32304](https://github.com/ClickHouse/ClickHouse/pull/32304) ([Igor Nikonov](https://github.com/devcrafter)).
* INSERT SQL 문에 DEFAULT 키워드 지원을 추가했습니다. [#6331](https://github.com/ClickHouse/ClickHouse/issues/6331)을 해결합니다. [#33141](https://github.com/ClickHouse/ClickHouse/pull/33141) ([Andrii Buriachevskyi](https://github.com/0over)).
* ttest에 신뢰구간을 추가했습니다. [#33260](https://github.com/ClickHouse/ClickHouse/pull/33260) ([achimbab](https://github.com/achimbab)).
* File/S3/HDFS 엔진에서 삽입 시 새 파일을 생성할 수 있도록 지원을 추가했습니다. HDFS에서는 파일 덮어쓰기를 허용합니다. 기본적으로 S3에서 파일을 덮어쓰려고 하면 예외를 발생시킵니다. suffix가 있는 포맷에서는 파일에 데이터를 추가하려고 하면 예외를 발생시킵니다. [#31640](https://github.com/ClickHouse/ClickHouse/issues/31640) 해결 [#31622](https://github.com/ClickHouse/ClickHouse/issues/31622) 해결 [#23862](https://github.com/ClickHouse/ClickHouse/issues/23862) 해결 [#15022](https://github.com/ClickHouse/ClickHouse/issues/15022) 해결 [#16674](https://github.com/ClickHouse/ClickHouse/issues/16674) 해결. [#33302](https://github.com/ClickHouse/ClickHouse/pull/33302) ([Kruglov Pavel](https://github.com/Avogar)).
* `h3ToCenterChild` 함수를 추가했습니다. [#33313](https://github.com/ClickHouse/ClickHouse/pull/33313) ([Bharat Nallan](https://github.com/bharatnc)).
* 텍스트 분류용 머지 함수를 추가했습니다. [#23271](https://github.com/ClickHouse/ClickHouse/issues/23271)을 참조하십시오. [#33314](https://github.com/ClickHouse/ClickHouse/pull/33314) ([Nikolay Degterinsky](https://github.com/evillique)).
* meanZTest를 구현했습니다. [#33354](https://github.com/ClickHouse/ClickHouse/pull/33354) ([achimbab](https://github.com/achimbab)).
* * bitSlice 함수를 추가했습니다. [#33360](https://github.com/ClickHouse/ClickHouse/pull/33360) ([RogerYK](https://github.com/RogerYK)).
* 새로운 h3 기타 함수 `edgeLengthKm`,`exactEdgeLengthKm`,`exactEdgeLengthM`,`exactEdgeLengthRads`,`numHexagons`를 추가했습니다. [#33621](https://github.com/ClickHouse/ClickHouse/pull/33621) ([Bharat Nallan](https://github.com/bharatnc)).
* `DEGREES` 및 `RADIANS` 함수를 추가했습니다. [#33769](https://github.com/ClickHouse/ClickHouse/pull/33769) ([Bharat Nallan](https://github.com/bharatnc)).
* 매개변수 `--host`가 여러 호스트를 받을 수 있습니다. 이 중 하나를 사용할 수 없으면 클라이언트가 다음 호스트에 연결을 시도합니다. [#33824](https://github.com/ClickHouse/ClickHouse/pull/33824) ([Filippov Denis](https://github.com/DF5HSE)).
* 파일 이름을 기준으로 clickhouse-local에서 포맷을 감지합니다. [#33829](https://github.com/ClickHouse/ClickHouse/pull/33829) ([Kruglov Pavel](https://github.com/Avogar)).
* 풀의 유효하지 않은 객체를 재할당하는 데 사용되는 새 메서드 `expire()`를 PoolBase에 추가했습니다. [#34076](https://github.com/ClickHouse/ClickHouse/pull/34076) ([lgbo](https://github.com/lgbo-ustc)).
* 테이블 함수 `format(format_name, data)`를 추가했습니다. [#34125](https://github.com/ClickHouse/ClickHouse/pull/34125) ([Kruglov Pavel](https://github.com/Avogar)).
* 기본 테이블 엔진을 생성할 수 있도록 했습니다. [#34187](https://github.com/ClickHouse/ClickHouse/pull/34187) ([Ilya Yatsishin](https://github.com/qoega)).
* `EPHEMERAL` 컬럼 지정자를 `CREATE TABLE` 쿼리에 추가했습니다. [#9436](https://github.com/ClickHouse/ClickHouse/issues/9436)을 해결했습니다. [#34424](https://github.com/ClickHouse/ClickHouse/pull/34424) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* S3에 대한 삽입 및 머지 시에는 가능하면 파일을 병렬로 씁니다. [#33291](https://github.com/ClickHouse/ClickHouse/pull/33291) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 키에 인터벌이 많은 경우 RangeHashedDictionary의 성능을 개선합니다. [#23821](https://github.com/ClickHouse/ClickHouse/issues/23821)을 수정합니다. [#33516](https://github.com/ClickHouse/ClickHouse/pull/33516) ([Maksim Kita](https://github.com/kitaisreal)).
* 메모리 비교를 가속화하기 위해 `memcmpSmall` 함수에 x86 avx512 지원을 추가합니다. 이 기능은 ClickHouse를 직접 컴파일한 경우에만 동작합니다. [#33706](https://github.com/ClickHouse/ClickHouse/pull/33706) ([hanqf-git](https://github.com/hanqf-git)).
* MV 실행에 스칼라 캐시를 다시 도입하고 재구성합니다. [#33958](https://github.com/ClickHouse/ClickHouse/pull/33958) ([Raúl Marín](https://github.com/Algunenano)).
* ORDER BY tuple을 ORDER BY 컬럼과 거의 같은 속도로 처리할 수 있도록 합니다. 여러 컬럼에 대한 ORDER BY에는 특별한 최적화가 있습니다: [https://github.com/ClickHouse/ClickHouse/pull/10831](https://github.com/ClickHouse/ClickHouse/pull/10831) . 이 최적화를 tuple 컬럼에도 적용하는 것이 유리합니다. [#34060](https://github.com/ClickHouse/ClickHouse/pull/34060) ([Amos Bird](https://github.com/amosbird)).
* `ExecuteScalarSubqueriesMatcher::visit`의 잠재적인 hot-path를 소폭 개선합니다. 이전에는 함수가 호출될 때마다 `std::set<String>`가 생성되었습니다. [#34128](https://github.com/ClickHouse/ClickHouse/pull/34128) ([Federico Rodriguez](https://github.com/fedrod)).
* `Regexp` 포맷의 성능을 소폭 개선합니다. [#34202](https://github.com/ClickHouse/ClickHouse/pull/34202) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* sort 대신 nth&#95;element를 사용해 quantilesExact{Low,High}를 최적화했습니다. [#34287](https://github.com/ClickHouse/ClickHouse/pull/34287) ([Daniel Kutenin](https://github.com/danlark1)).
* `LineAsString` 포맷의 성능을 개선했습니다. 이 변경으로 [#34303](https://github.com/ClickHouse/ClickHouse/issues/34303)이 해결되었습니다. [#34306](https://github.com/ClickHouse/ClickHouse/pull/34306) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 데이터 파트(data parts) 로딩 속도를 높였습니다. 이전에는 병렬화되지 않았기 때문에 `part_loading_threads` 설정이 효과가 없었습니다. [#4699](https://github.com/ClickHouse/ClickHouse/issues/4699)를 참조하십시오. [#34310](https://github.com/ClickHouse/ClickHouse/pull/34310) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `_file` 및 `_path` 가상 컬럼(파일 계열 테이블 엔진에서)이 `LowCardinality`로 변경되어 여러 파일에 대한 쿼리가 더 빨라집니다. 이 변경으로 [#34300](https://github.com/ClickHouse/ClickHouse/issues/34300)이 해결되었습니다. [#34317](https://github.com/ClickHouse/ClickHouse/pull/34317) ([flynn](https://github.com/ucasfl)).
* `mapPopulateSeries` 함수의 성능을 개선했습니다. 이 변경으로 [#33944](https://github.com/ClickHouse/ClickHouse/issues/33944)가 해결되었습니다. [#34318](https://github.com/ClickHouse/ClickHouse/pull/34318) ([Maksim Kita](https://github.com/kitaisreal)).
* snapshot 수행 시 불필요한 list iterator를 수집하는 데 vector를 사용하도록 변경했으며, 이후 clearOutdatedNodes에서는 list 대신 vector만 순회하면 되므로 더 빠릅니다. [#34484](https://github.com/ClickHouse/ClickHouse/pull/34484) ([zhanglistar](https://github.com/zhanglistar)).
* URL, S3, File, HDFS 테이블 함수에 삽입할 때의 성능을 개선했습니다. 이 변경으로 [#34348](https://github.com/ClickHouse/ClickHouse/issues/34348)이 해결되었습니다. [#34510](https://github.com/ClickHouse/ClickHouse/pull/34510) ([Maksim Kita](https://github.com/kitaisreal)).
* [https://github.com/eBay/NuRaft/issues/209](https://github.com/eBay/NuRaft/issues/209)에 따르면, 해당 메서드에는 잠금을 걸 필요가 없습니다. [#34523](https://github.com/ClickHouse/ClickHouse/pull/34523) ([zhanglistar](https://github.com/zhanglistar)).

* 함수 `hex`, `bin`에 `UUID` 데이터 타입 지원이 추가되었습니다. [#32170](https://github.com/ClickHouse/ClickHouse/pull/32170) ([Frank Chen](https://github.com/FrankChen021)).

* Keeper 성능을 개선하고 여러 메모리 누수를 수정했습니다. [#33329](https://github.com/ClickHouse/ClickHouse/pull/33329) ([alesapin](https://github.com/alesapin)).
* CPU quota에 cgroup 제한을 반영합니다. [#33342](https://github.com/ClickHouse/ClickHouse/pull/33342) ([JaySon](https://github.com/JaySon-Huang)).
* Decimal과 Float 간 이항 산술 연산(plus, minus, multiply, division, least, greates)을 지원합니다. [#33355](https://github.com/ClickHouse/ClickHouse/pull/33355) ([flynn](https://github.com/ucasfl)).

[#21647](https://github.com/ClickHouse/ClickHouse/issues/21647)를 해결합니다. 할당 바이트 계산을 수정했습니다. `ComplexKeyHashedDictionary`의 `system.dictionaries`에 표시되는 type name도 수정했습니다. [#33927](https://github.com/ClickHouse/ClickHouse/pull/33927) ([Maksim Kita](https://github.com/kitaisreal)).
