  ### ClickHouse 릴리스 v24.12.1.1614-안정 (a6d2b2e35b2) FIXME, v24.12.1.1-new (e4c9b022237) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 함수 `greatest`와 `least`는 이제 NULL 입력 값을 무시합니다. 이전에는 인수 중 하나가 NULL이면 NULL을 반환했습니다. 예를 들어 `SELECT greatest(1, 2, NULL)`는 이제 2를 반환합니다. 이 변경으로 동작이 PostgreSQL과 호환됩니다. [#65519](https://github.com/ClickHouse/ClickHouse/pull/65519) ([kevinyhzou](https://github.com/KevinyhZou)).
* Poco driver 기반의 레거시 MongoDB 통합이 제거되었습니다. 서버 설정 `use_legacy_mongodb_integration`은 폐기되었으며 더 이상 아무런 효과가 없습니다. [#71997](https://github.com/ClickHouse/ClickHouse/pull/71997) ([Kirill Nikiforov](https://github.com/allmazz)).



<div id="new-feature">
  #### 새 기능
</div>

* MergeTree 테이블을 ReplicatedMergeTree로, 또는 그 반대로 ATTACH할 수 있는 쿼리가 추가되었습니다. [#65401](https://github.com/ClickHouse/ClickHouse/pull/65401) ([Kirill](https://github.com/kirillgarbar)).
* 지정된 테이블의 모든 파트, 또는 테이블을 지정하지 않은 경우 모든 테이블의 프라이머리 인덱스를 로드하는 `SYSTEM LOAD PRIMARY KEY` 명령이 구현되었습니다. 이 기능은 벤치마크 수행 및 쿼리 실행 중 불필요한 지연 시간 방지에 유용합니다. [#66252](https://github.com/ClickHouse/ClickHouse/pull/66252) ([ZAWA&#95;ll](https://github.com/Zawa-ll)).
* 지정된 테이블의 모든 파트, 또는 테이블을 지정하지 않은 경우 모든 테이블의 프라이머리 인덱스를 로드하는 `SYSTEM LOAD PRIMARY KEY` SQL 문이 추가되었습니다. 이 기능은 벤치마킹 및 쿼리 실행 중 불필요한 지연 시간 방지에 유용합니다. [#67733](https://github.com/ClickHouse/ClickHouse/pull/67733) ([ZAWA&#95;ll](https://github.com/Zawa-ll)).
* [Iceberg 데이터 스토리지](https://iceberg.apache.org/spec/#file-system-operations) 포맷은 테이블 스키마 변경을 위한 다양한 옵션을 제공합니다. 이번 변경에서는 컬럼 순서, 컬럼 이름, 단순 유형 확장이 변경된 Iceberg 포맷 테이블 읽기 기능이 구현되었습니다. [#69445](https://github.com/ClickHouse/ClickHouse/pull/69445) ([Daniil Ivanik](https://github.com/divanik)).
* `DateTime64`를 초 단위 고정 정밀도의 `Int64` 값으로 변환하는 `toUnixTimestamp64Second` 함수가 추가되었습니다. 이를 통해 1970년 1월 1일 목요일 00:00:00 UTC 이전 날짜에 대한 음수 값 반환이 지원됩니다. [#70597](https://github.com/ClickHouse/ClickHouse/pull/70597) ([zhanglistar](https://github.com/zhanglistar)).
* 원본 테이블의 프로젝션 및 보조 인덱스가 대상 테이블의 부분 집합인 경우 ATTACH를 허용하는 새로운 설정 `enforce_index_structure_match_on_partition_manipulation`이 추가되었습니다. [#70602](https://github.com/ClickHouse/ClickHouse/issues/70602) 해결. [#70603](https://github.com/ClickHouse/ClickHouse/pull/70603) ([zwy991114](https://github.com/zwy991114)).
* `cast` 함수의 출력이 Apache Spark와 달라 gluten 프로젝트에서 차이가 발생하는 문제가 있었습니다(https://github.com/apache/incubator-gluten/issues/7602 참조). 이번 변경에서 Spark 텍스트 출력 형식 지원 기능이 추가되었으며, 기본적으로는 비활성화 상태입니다. [#70957](https://github.com/ClickHouse/ClickHouse/pull/70957) ([zhanglistar](https://github.com/zhanglistar)).
* MergeTree 정렬 키에서 내림차순 정렬을 지원하는 새로운 설정 `allow_experimental_reverse_key`가 도입되었습니다. 이 기능은 시계열 분석, 특히 TopN 쿼리에 유용합니다. 사용 예시: &#96;&#96;&#96;sql CREATE TABLE example ( time DateTime, key Int32, value String ) ENGINE = MergeTree ORDER BY (time DESC, key); -- &#39;time&#39; 필드 내림차순 정렬 SETTINGS allow&#95;experimental&#95;reverse&#95;key = 1;. [#71095](https://github.com/ClickHouse/ClickHouse/pull/71095) ([Amos Bird](https://github.com/amosbird)).
* Iceberg REST 카탈로그 통합이 추가되었습니다. [#71542](https://github.com/ClickHouse/ClickHouse/pull/71542) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 쿼리 계획에서 조인의 내부(빌드) 테이블로 사용할 측을 선택하는 옵션이 추가되었습니다. `query_plan_join_swap_table` 설정으로 제어하며, `auto`로 설정할 수 있습니다. 이 모드에서 ClickHouse는 행 수가 가장 적은 테이블을 자동으로 선택합니다. [#71577](https://github.com/ClickHouse/ClickHouse/pull/71577) ([Vladimir Cherkasov](https://github.com/vdimir)).
* `ALTER USER {ADD|MODIFY|DROP SETTING}`, `ALTER USER {ADD|DROP PROFILE}` 구문이 추가되었으며, `ALTER ROLE` 및 `ALTER PROFILE`에도 동일하게 적용됩니다. [#72050](https://github.com/ClickHouse/ClickHouse/pull/72050) ([pufit](https://github.com/pufit)).
* Precision-Recall 곡선의 AUC(Area Under the Curve)를 계산하는 `arrayPrAUC` 함수가 추가되었습니다. [#72073](https://github.com/ClickHouse/ClickHouse/pull/72073) ([Emmanuel](https://github.com/emmanuelsdias)).
* `MergeTree` 테이블의 프라이머리 인덱스 캐시가 추가되었습니다(테이블 설정 `use_primary_key_cache`로 활성화 가능). 지연 로드 및 캐시가 활성화된 경우, 프라이머리 인덱스는 메모리에 영구적으로 유지되는 대신 필요 시 캐시에 로드됩니다(마크 캐시와 유사). 또한 데이터 파트의 삽입/머지/페치 및 테이블 재시작 시 프라이머리 인덱스를 예열하는 기능이 추가되었습니다(설정 `prewarm_primary_key_cache`로 활성화 가능). [#72102](https://github.com/ClickHouse/ClickHouse/pull/72102) ([Anton Popov](https://github.com/CurtizJ)).
* [#73593](https://github.com/ClickHouse/ClickHouse/issues/73593)에 백포트됨: `SELECT` 및 `VIEW` SQL 문에서 별칭(alias)을 지원합니다. 예: `SELECT b FROM (SELECT number, number*2 FROM numbers(2)) AS x (a, b);`. 이를 통해 TPC-H 쿼리 15를 수정 없이 실행할 수 있습니다. [#72480](https://github.com/ClickHouse/ClickHouse/pull/72480) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 배열 유형을 위한 `indexOfAssumeSorted` 함수가 추가되었습니다. 오름차순(비내림차순)으로 정렬된 배열에서의 검색을 최적화합니다. [#72517](https://github.com/ClickHouse/ClickHouse/pull/72517) ([Eric Kurbanov](https://github.com/erickurbanov)).
* 집계 함수 `groupConcat`의 선택적 두 번째 인수로 구분자를 지정할 수 있게 되었습니다. [#72540](https://github.com/ClickHouse/ClickHouse/pull/72540) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* HTTP 응답 헤더를 사용자 정의할 수 있는 새로운 설정 `http_response_headers`가 추가되었습니다. 예를 들어, 데이터베이스에 저장된 이미지를 브라우저에서 렌더링하도록 지정할 수 있습니다. [#59620](https://github.com/ClickHouse/ClickHouse/issues/59620) 해결. [#72656](https://github.com/ClickHouse/ClickHouse/pull/72656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Int64` Unix 타임스탬프 값을 `DateTime64`로 변환하는 `fromUnixTimestamp64Second` 함수가 추가되었습니다. [#73146](https://github.com/ClickHouse/ClickHouse/pull/73146) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 객체 스토리지 디스크에서 `clickhouse disks remove --recursive`의 메모리 사용량이 감소하였습니다. [#67323](https://github.com/ClickHouse/ClickHouse/pull/67323) ([Kirill](https://github.com/kirillgarbar)).
* 더 많은 표현식에 대해 JIT 컴파일을 활성화하였습니다: abs/bitCount/sign/modulo/pmod/isNull/isNotNull/assumeNotNull/to(U)Int*/toFloat*, 비교 함수(=, <, >, >=, <=), 논리 함수(and, or). [#70598](https://github.com/ClickHouse/ClickHouse/pull/70598) ([李扬](https://github.com/taiyang-li)).
* 이제 `join_algorithm` 설정이 `default`로 지정된 경우, 적용 가능하면 `parallel_hash` 알고리즘이 사용됩니다. `parallel_hash`를 사용할 수 없는 경우에는 기존의 두 대안(`direct` 및 `hash`)이 계속 고려됩니다. [#70788](https://github.com/ClickHouse/ClickHouse/pull/70788) ([Nikita Taranov](https://github.com/nickitat)).
* 조인 시 사용되는 해시 테이블 수를 줄이기 위해 `WHERE` 및 `ON` 표현식에서 공통 표현식을 추출하는 옵션이 추가되었습니다. `optimize_extract_common_expressions = 1`로 활성화할 수 있습니다. [#71537](https://github.com/ClickHouse/ClickHouse/pull/71537) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* `LowCardinality(String)`을 사용하는 `SELECT`에서 인덱스를 활용할 수 있도록 지원합니다. [#71598](https://github.com/ClickHouse/ClickHouse/pull/71598) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 병렬 레플리카와 로컬 플랜이 활성화된 상태에서 쿼리를 실행할 때, 워커에서의 인덱스 분석을 건너뜁니다. 코디네이터(쿼리 이니시에이터)가 자체적으로 인덱스 분석을 수행하여 워커가 읽을 범위를 결정합니다. [#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter)).
* https://github.com/ClickHouse/ClickHouse/pull/57631 에서 실수로 삭제된, Compact 파트에서 단일 컬럼의 서브컬럼을 읽는 최적화를 복원하였습니다. [#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)).
* 비교기에서 가상 함수 호출을 제거하여 `LowCardinality(String)` 컬럼의 정렬 속도를 향상시켰습니다. [#72337](https://github.com/ClickHouse/ClickHouse/pull/72337) ([Alexander Gololobov](https://github.com/davenger)).
* 일부 단순 데이터 타입에 대해 argMin/Max 함수를 최적화하였습니다. [#72350](https://github.com/ClickHouse/ClickHouse/pull/72350) ([alesapin](https://github.com/alesapin)).
* 메모리 트래커의 공유 잠금 처리를 최적화하여 잠금 경합을 줄였습니다. [#72375](https://github.com/ClickHouse/ClickHouse/pull/72375) ([Jiebin Sun](https://github.com/jiebinn)).
* 새로운 설정 `use_async_executor_for_materialized_views`가 추가되었습니다. materialized view 쿼리를 비동기 및 멀티스레드 방식으로 실행하며, INSERT 중 뷰 처리 속도를 향상시킬 수 있으나 메모리 사용량이 증가할 수 있습니다. [#72497](https://github.com/ClickHouse/ClickHouse/pull/72497) ([alesapin](https://github.com/alesapin)).
* `max_size_to_preallocate_for_aggregation`, `max_size_to_preallocate_for_joins` 설정의 기본값이 `10^12`로 추가 상향되어, 더 많은 경우에 최적화가 적용됩니다. [#72555](https://github.com/ClickHouse/ClickHouse/pull/72555) ([Nikita Taranov](https://github.com/nickitat)).
* 집계 함수 상태의 역직렬화 성능이 향상되었습니다(`AggregateFunction` 데이터 타입 및 분산 쿼리에서). `RowBinary` 포맷의 파싱 성능도 소폭 개선되었습니다. [#72818](https://github.com/ClickHouse/ClickHouse/pull/72818) ([Anton Popov](https://github.com/CurtizJ)).

<div id="improvement">
  #### 개선 사항
</div>

* 새로운 취소 로직 추가: `CancellationChecker`가 시작된 모든 쿼리의 timeout을 확인하고, timeout에 도달하면 쿼리를 중지합니다. [#69880](https://github.com/ClickHouse/ClickHouse/pull/69880) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* `allow_experimental_join_condition` 설정을 제거하여 비등가 조건이 기본적으로 허용됩니다. [#69910](https://github.com/ClickHouse/ClickHouse/pull/69910) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 이제 서버 구성(users.xml)의 설정이 클라이언트에도 적용됩니다. 포맷 설정(예: `date_time_output_format`)에 유용합니다. [#71178](https://github.com/ClickHouse/ClickHouse/pull/71178) ([Michael Kolupaev](https://github.com/al13n321)).
* [#71227](https://github.com/ClickHouse/ClickHouse/issues/71227) 문제가 수정되었습니다. [#71286](https://github.com/ClickHouse/ClickHouse/pull/71286) ([Arthur Passos](https://github.com/arthurpassos)).
* 서버/사용자의 메모리 사용량에 따라 `GROUP BY`/`ORDER BY`를 자동으로 디스크 기반 처리로 전환합니다. `max_bytes_ratio_before_external_group_by`/`max_bytes_ratio_before_external_sort` 쿼리 설정으로 제어합니다. [#71406](https://github.com/ClickHouse/ClickHouse/pull/71406) ([Azat Khuzhin](https://github.com/azat)).
* 이제 함수 `translate`는 `from` 인수에 `to` 인수보다 문자가 더 많이 포함된 경우 문자 삭제를 지원합니다. 예시: `SELECT translate('clickhouse', 'clickhouse', 'CLICK')`는 이제 `CLICK`을 반환합니다. [#71441](https://github.com/ClickHouse/ClickHouse/pull/71441) ([shuai.xu](https://github.com/shuai-xu)).
* Object에서 JSON으로 ALTER를 지원합니다. [#71784](https://github.com/ClickHouse/ClickHouse/pull/71784) ([Pavel Kruglov](https://github.com/Avogar)).
* 읽는 동안 메모리 사용량을 줄이기 위해 `MergeTreeReadPoolParallelReplicasInOrder`에서 ranges를 분할합니다. [#72173](https://github.com/ClickHouse/ClickHouse/pull/72173) ([JIaQi](https://github.com/JiaQiTang98)).
* 분산 `INSERT ... SELECT`의 계획을 수립할 때 `prefer_locahost_replica`를 반영합니다. [#72190](https://github.com/ClickHouse/ClickHouse/pull/72190) ([filimonov](https://github.com/filimonov)).
* 문제는 [여기에 설명되어 있습니다](https://github.com/ClickHouse/ClickHouse/issues/72091). Azure Iceberg Writer는 사양을 위반하는 Iceberg metadata files(및 manifest files)를 생성합니다. 이 PR에서는 v1 Iceberg 포맷 metadata를 v2 reader로 읽으려는 처리를 추가했으며(해당 Writer가 이런 방식으로 기록하기 때문입니다), manifest 파일에 해당 field가 생성되지 않았을 때 오류를 발생시키도록 했습니다. [#72277](https://github.com/ClickHouse/ClickHouse/pull/72277) ([Daniil Ivanik](https://github.com/divanik)).
* JSON/Dynamic/Variant 타입을 실험적 기능에서 베타로 이동합니다. [#72294](https://github.com/ClickHouse/ClickHouse/pull/72294) ([Pavel Kruglov](https://github.com/Avogar)).
* 이제 쿼리에서 `UNION [ALL]`을 사용하는 `CREATE MATERIALIZED VIEW`가 허용됩니다. 동작은 `JOIN`이 있는 materialized view와 동일합니다. **`SELECT` 표현식의 첫 번째 테이블만 삽입 트리거로 동작**하며, 다른 모든 테이블은 무시됩니다. [#72347](https://github.com/ClickHouse/ClickHouse/pull/72347) ([alesapin](https://github.com/alesapin)).
* 삽입된 batch 내에 파티션 키 값이 하나만 있는 경우 MergeTree로의 삽입 속도를 개선합니다. [#72348](https://github.com/ClickHouse/ClickHouse/pull/72348) ([alesapin](https://github.com/alesapin)).
* 이전에는 `/utils` 폴더에 있던 데다 소스에서 수동 컴파일이 필요했던 모든 소형 유틸리티가 이제 메인 ClickHouse bundle에 포함됩니다. 이로써 [#72404](https://github.com/ClickHouse/ClickHouse/issues/72404)가 해결됩니다. [#72426](https://github.com/ClickHouse/ClickHouse/pull/72426) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 백업에서 복원하는 동안 테이블을 병렬로 생성하도록 구현했습니다. 이 PR 이전에는 `RESTORE` 명령이 항상 단일 스레드에서 테이블을 생성했기 때문에, 많은 테이블이 포함된 백업에서는 속도가 느릴 수 있었습니다. [#72427](https://github.com/ClickHouse/ClickHouse/pull/72427) ([Vitaly Baranov](https://github.com/vitlibar)).
* system.metrics에 새로운 MergeTreeIndexGranularityInternalArraysTotalSize 메트릭을 추가했습니다. 이 메트릭은 메모리 사용량이 매우 높아지는 문제에 취약한 대규모 데이터셋을 가진 인스턴스를 찾는 데 필요합니다. [#72490](https://github.com/ClickHouse/ClickHouse/pull/72490) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
