<div id="bug-fix">
  #### 오동작
</div>

* [#21644](https://github.com/ClickHouse/ClickHouse/issues/21644)에 백포트됨: 구성 업데이트 후에도 S3 테이블이 이전 자격 증명을 계속 유지하던 문제를 수정했습니다. [#21457](https://github.com/ClickHouse/ClickHouse/pull/21457) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* [#21854](https://github.com/ClickHouse/ClickHouse/issues/21854)에 백포트됨: `optimize_skip_unused_shards`가 활성화되어 있고 사용되는 세그먼트가 0개일 때 발생할 수 있는 ` Cannot find column` 오류를 수정했습니다. [#21579](https://github.com/ClickHouse/ClickHouse/pull/21579) ([Azat Khuzhin](https://github.com/azat)).
* [#21687](https://github.com/ClickHouse/ClickHouse/issues/21687)에 백포트됨: 수평 머지에서 fsync&#95;part&#95;directory를 수정했습니다. [#21642](https://github.com/ClickHouse/ClickHouse/pull/21642) ([Azat Khuzhin](https://github.com/azat)).
* [#21796](https://github.com/ClickHouse/ClickHouse/issues/21796)에 백포트됨: `async_socket_for_remote=1`에서 분산 요청 취소 동작(예: limit가 있는 여러 세그먼트에 대한 단순 select, 즉 `select * from remote('127.{2,3}', system.numbers) limit 100`)을 수정했습니다. [#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* [#21811](https://github.com/ClickHouse/ClickHouse/issues/21811)에 백포트됨: `ALTER MODIFY COLUMN` 쿼리에서 Decimal 컬럼의 크기(32 bit 또는 64 bit)가 바뀌지 않으면 유형이 변경되지 않던 ReplicatedMerge 테이블 엔진의 버그를 수정했습니다. [#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* [#21883](https://github.com/ClickHouse/ClickHouse/issues/21883)에 백포트됨: S3 연결 풀 변경을 되돌렸습니다. [#21737](https://github.com/ClickHouse/ClickHouse/pull/21737) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#21874](https://github.com/ClickHouse/ClickHouse/issues/21874)에 백포트됨: `WHERE` 또는 `HAVING` 조건이 `GROUP BY` 이전에 푸시다운될 때 발생할 수 있는 잘못된 쿼리 결과(및 크래시 가능성)를 수정했습니다. [#21773](https://github.com/ClickHouse/ClickHouse/issues/21773)를 수정합니다. [#21841](https://github.com/ClickHouse/ClickHouse/pull/21841) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
