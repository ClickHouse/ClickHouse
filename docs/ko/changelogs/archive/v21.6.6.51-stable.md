<div id="bug-fix">
  #### 오동작 수정
</div>

* [#25850](https://github.com/ClickHouse/ClickHouse/issues/25850)에 백포트됨: `Date`에서 `DateTime`(또는 `DateTime64`)으로 `CAST`할 때 `DateTime` 타입의 시간대를 사용하지 않던 문제를 수정했습니다. 이 문제는 `Date`와 `DateTime` 간 비교에도 영향을 줄 수 있었습니다. `Date`와 `DateTime`의 공통 타입을 추론할 때도 해당 시간대를 사용하지 않았습니다. 이로 인해 함수 `if`와 배열 생성 결과에 영향을 주었습니다. [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)을 해결합니다. [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25677](https://github.com/ClickHouse/ClickHouse/issues/25677)에 백포트됨: 난수 생성기 상태의 역직렬화 버그를 수정했습니다. 이 버그로 인해 `AggregateFunction(groupArraySample(N), T))`와 같은 일부 데이터 타입이 비결정적으로 동작할 수 있었습니다. [#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25535](https://github.com/ClickHouse/ClickHouse/issues/25535)에 백포트됨: DiskS3에서 파일을 읽을 때 발생할 수 있는 &#39;Cannot read from istream at offset 0&#39; 오류를 수정했습니다. [#24885](https://github.com/ClickHouse/ClickHouse/pull/24885) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#25557](https://github.com/ClickHouse/ClickHouse/issues/25557)에 백포트됨: 다른 집계 함수의 집계 함수 상태를 집계해 집계 함수 상태를 계산할 때 발생할 수 있는 크래시 가능성을 수정했습니다(실용적인 사용 사례는 아닙니다). [#24523](https://github.com/ClickHouse/ClickHouse/issues/24523)을 참고하십시오. [#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25506](https://github.com/ClickHouse/ClickHouse/issues/25506)에 백포트됨: copier의 작업 구성에 sharding&#95;key가 없을 때 발생하는 segfault를 수정했습니다. [#25419](https://github.com/ClickHouse/ClickHouse/pull/25419) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#25765](https://github.com/ClickHouse/ClickHouse/issues/25765)에 백포트됨: uint8이 아닌 타입의 PREWHERE에서 발생하는 assertion을 수정했으며, [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589)를 해결합니다. [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* [#25635](https://github.com/ClickHouse/ClickHouse/issues/25635)에 백포트됨: `WITH TOTALS` 및 `WITH FILL` 쿼리의 잘못된 합계를 수정했습니다. [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872)를 해결합니다. [#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* [#25652](https://github.com/ClickHouse/ClickHouse/issues/25652)에 백포트됨: 쿼리 없이 `EXPLAIN AST`를 실행할 때 발생하는 널 포인터 역참조를 수정했습니다. [#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25717](https://github.com/ClickHouse/ClickHouse/issues/25717)에 백포트됨: 드물게 원본 파티션이 비어 있으면 `REPLACE PARTITION`이 무시될 수 있던 문제를 수정했습니다. [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869)를 해결합니다. [#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25696](https://github.com/ClickHouse/ClickHouse/issues/25696)에 백포트됨: 데이터베이스 간에 `Distributed` 테이블을 이동할 때 발생하던 `No such file or directory` 오류를 수정했습니다. [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971)를 해결합니다. [#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25755](https://github.com/ClickHouse/ClickHouse/issues/25755)에 백포트: `system.clusters`를 쿼리하는 동시에 클러스터 구성을 다시 로드할 때 발생하는 데이터 레이스를 수정했습니다. [#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)).
