<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* BoringSSL 모듈이 공식 FIPS 준수 버전으로 업데이트되었습니다. 이로써 ClickHouse는 FIPS를 준수하게 되었습니다. [#35914](https://github.com/ClickHouse/ClickHouse/pull/35914) ([삭제된 사용자](https://github.com/ghost)).
* 이제 백그라운드 머지, 뮤테이션 및 `OPTIMIZE`는 `SelectedRows` 및 `SelectedBytes` 메트릭을 더 이상 증가시키지 않습니다. 이전과 마찬가지로 `MergedRows` 및 `MergedUncompressedBytes`는 계속 증가합니다. [#37040](https://github.com/ClickHouse/ClickHouse/pull/37040) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

* CREATE TABLE에서 collations를 파싱하고, 예외를 발생시키거나 무시할 수 있습니다. closes [#35892](https://github.com/ClickHouse/ClickHouse/issues/35892). [#36271](https://github.com/ClickHouse/ClickHouse/pull/36271) ([yuuch](https://github.com/yuuch)).
* JSONEachRow의 alias로 JSONLines 및 NDJSON을 추가합니다. Closes [#36303](https://github.com/ClickHouse/ClickHouse/issues/36303). [#36327](https://github.com/ClickHouse/ClickHouse/pull/36327) ([flynn](https://github.com/ucasfl)).
* parts&#95;to&#95;delay&#95;insert 및 parts&#95;to&#95;throw&#95;insert를 쿼리 수준 설정으로 지정합니다. 이 값이 정의되어 있으면 테이블 수준 설정을 재정의할 수 있습니다. [#36371](https://github.com/ClickHouse/ClickHouse/pull/36371) ([Memo](https://github.com/Joeywzr)).
* temporary table에서 총 행 수와 총 바이트 수를 표시할 수 있습니다. [#36401](https://github.com/ClickHouse/ClickHouse/issues/36401). [#36439](https://github.com/ClickHouse/ClickHouse/pull/36439) ([chen](https://github.com/xiedeyantu)).
* 새로운 hash function인 wyHash64를 추가했습니다. [#36467](https://github.com/ClickHouse/ClickHouse/pull/36467) ([olevino](https://github.com/olevino)).
* 윈도 함수 nth&#95;value가 추가되었습니다. [#36601](https://github.com/ClickHouse/ClickHouse/pull/36601) ([Nikolay](https://github.com/ndchikin)).
* MySQLDump 입력 형식을 추가합니다. dump에서 하나의 테이블에 속한 INSERT 쿼리의 모든 데이터를 읽습니다. 테이블이 2개 이상이면 기본적으로 첫 번째 테이블의 데이터를 읽습니다. [#36667](https://github.com/ClickHouse/ClickHouse/pull/36667) ([Kruglov Pavel](https://github.com/Avogar)).
* 새로운 단일 binary 기반 진단 도구입니다. [#36705](https://github.com/ClickHouse/ClickHouse/pull/36705) ([Dale McDiarmid](https://github.com/gingerwizard)).
* **Description:** 원격 파일 접근 request에 대한 system table을 집계하는 데 사용되며, storage and compute separation 시나리오에서 성능 변동의 원인을 분석하는 데 도움이 됩니다. 현재 system table structure는 다음과 같습니다. 쿼리가 원격 파일의 세그먼트를 읽으면 기록이 생성됩니다. 읽기 유형에는 **READ&#95;FROM&#95;FS&#95;AND&#95;DOWNLOADED&#95;TO&#95;CACHE、READ&#95;FROM&#95;CACHE、READ&#95;FROM&#95;FS&#95;BYPASSING&#95;CACHE**가 있으며, 이를 통해 쿼리가 cache에서 세그먼트에 접근했는지 아니면 원격 파일에서 접근했는지 확인할 수 있습니다. [#36802](https://github.com/ClickHouse/ClickHouse/pull/36802) ([Han Shukai](https://github.com/KinderRiven)).
* `h3Line`, `h3Distance`, `h3HexRing` 함수를 추가합니다. [#37030](https://github.com/ClickHouse/ClickHouse/pull/37030) ([Bharat Nallan](https://github.com/bharatnc)).
* 관련 issue - [#35101](https://github.com/ClickHouse/ClickHouse/issues/35101). [#37033](https://github.com/ClickHouse/ClickHouse/pull/37033) ([qieqieplus](https://github.com/qieqieplus)).
* system.certificates 테이블이 추가되었습니다. [#37142](https://github.com/ClickHouse/ClickHouse/pull/37142) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* 정렬 컬럼 비교자에 JIT 컴파일을 적용하여 ORDER BY, MergeJoin, MergeTree에 대한 삽입 성능을 개선했습니다. [#34469](https://github.com/ClickHouse/ClickHouse/pull/34469) ([Maksim Kita](https://github.com/kitaisreal)).
* 첫 번째 커밋에서는 인라인 임계값을 높입니다. 이후 커밋에서는 성능 향상이 확인된 경우에 한해 인라이닝으로 쿼리를 개선합니다. 이를 통해 컴파일 시간과 바이너리 크기를 늘리지 않으면서 프로그램을 최적화할 수 있습니다. [#34544](https://github.com/ClickHouse/ClickHouse/pull/34544) ([Daniel Kutenin](https://github.com/danlark1)).
* OR LIKE 연쇄 표현식을 multiMatchAny로 재작성합니다. 제대로 동작한다는 확신이 더 생기면 활성화할 예정입니다. [#34932](https://github.com/ClickHouse/ClickHouse/pull/34932) ([Daniel Kutenin](https://github.com/danlark1)).
* &#39;select countDistinct(a) from t&#39;를 &#39;select count(1) from (select a from t groupBy a)&#39;로 재작성합니다. [#35993](https://github.com/ClickHouse/ClickHouse/pull/35993) ([zhanglistar](https://github.com/zhanglistar)).
* `system.asynchronous_metric_log`의 구조를 변경했습니다. 차지하는 공간이 약 10배 줄어듭니다. 이로써 [#36357](https://github.com/ClickHouse/ClickHouse/issues/36357)가 해결됩니다. `event_time_microseconds` 필드는 불필요하여 제거되었습니다. [#36360](https://github.com/ClickHouse/ClickHouse/pull/36360) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 기본 `HashJoin`은 오른쪽 테이블의 행을 삽입할 때 스레드 안전하지 않아 단일 스레드로 실행됩니다. 오른쪽 테이블이 크면 CPU 사용률이 낮아 조인 과정이 매우 느려집니다. [#36415](https://github.com/ClickHouse/ClickHouse/pull/36415) ([lgbo](https://github.com/lgbo-ustc)).
* 경로에 글롭 패턴이 있고 일치하는 디렉터리에 많은 파일이 포함된 경우, 스토리지 `File` 및 테이블 함수 `file`의 읽기 성능을 개선했습니다. [#36647](https://github.com/ClickHouse/ClickHouse/pull/36647) ([Anton Popov](https://github.com/CurtizJ)).
* 입력 형식 `HiveText`에 병렬 파싱을 적용하여 로컬 파일을 읽을 때 HiveText 파싱 속도를 2배 높일 수 있습니다. [#36650](https://github.com/ClickHouse/ClickHouse/pull/36650) ([李扬](https://github.com/taiyang-li)).
* 뮤텍스 범위를 줄여 파일 디스크립터 캐시의 성능을 개선했습니다. [#36682](https://github.com/ClickHouse/ClickHouse/pull/36682) ([Anton Kozlov](https://github.com/tonickkozlov)).
* 이 PR은 WindowView의 `WATCH` 쿼리를 개선합니다: 1. `fire_condition` 신호를 호출하여 쿼리 결과 제공 지연 시간을 줄입니다. 2. `isCancelled()`를 더 자주 확인하여 쿼리 취소 작업(ctrl-c)을 더 빠르게 처리합니다. [#37226](https://github.com/ClickHouse/ClickHouse/pull/37226) ([vxider](https://github.com/Vxider)).
* GROUP BY 표현식 없이 사용할 때 `avg`, `sum` 집계 함수의 성능을 개선했습니다. [#37257](https://github.com/ClickHouse/ClickHouse/pull/37257) ([Maksim Kita](https://github.com/kitaisreal)).
* 동적 디스패치를 사용하여 단항 산술 함수(`bitCount`, `bitNot`, `abs`, `intExp2`, `intExp10`, `negate`, `roundAge`, `roundDuration`, `roundToExp2`, `sign`)의 성능을 개선했습니다. [#37289](https://github.com/ClickHouse/ClickHouse/pull/37289) ([Maksim Kita](https://github.com/kitaisreal)).

* JSON 객체에 대한 스키마 추론을 개선했습니다. [#36207](https://github.com/ClickHouse/ClickHouse/pull/36207) ([Kruglov Pavel](https://github.com/Avogar)).
* 쿼럼 없이 클러스터를 재구성할 수 있는 강제 복구(force recovery) 지원을 추가했습니다. [#36258](https://github.com/ClickHouse/ClickHouse/pull/36258) ([Antonio Andelic](https://github.com/antonio2368)).

[#36281](https://github.com/ClickHouse/ClickHouse/pull/36281) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
