<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#72150](https://github.com/ClickHouse/ClickHouse/issues/72150)에 백포트됨: 이 PR에서는 `RESTORE ON CLUSTER`가 복원된 파트를 각 `ReplicatedMergeTree` 테이블에 ATTACH하기 전에, 해당 테이블이 readonly 상태에서 벗어날 때까지 기다리도록 변경했습니다. 이전에는 기다리지 않았기 때문에 테이블 시작 중 다른 레플리카를 확인하는 시점과 거의 동시에 일부 파트를 ATTACH하려고 시도할 수 있었습니다. 드물게는 이 문제로 인해 `RESTORE ON CLUSTER` 중 일부 파트가 아예 attached 상태가 되지 않을 수 있었습니다. [#62207](https://github.com/ClickHouse/ClickHouse/pull/62207) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#72408](https://github.com/ClickHouse/ClickHouse/issues/72408)에 백포트됨: `ATTACH PART` 쿼리 중 중복 제거된 파트가 더 이상 `attaching_` 접두사가 붙은 상태로 남지 않습니다. [#65636](https://github.com/ClickHouse/ClickHouse/pull/65636) ([Kirill](https://github.com/kirillgarbar)).
* [#71979](https://github.com/ClickHouse/ClickHouse/issues/71979)에 백포트됨: [이 이슈](https://github.com/ClickHouse/ClickHouse/pull/59946#issuecomment-1943653197) 이후 production 환경에는 `metadata_version` node 값이 `0`이면서 동시에 해당 테이블의 `metadata` node 버전과 다른 테이블 레플리카가 꽤 많이 존재합니다. 이로 인해 해당 레플리카에서 `alter` 쿼리가 실패합니다. [#69274](https://github.com/ClickHouse/ClickHouse/pull/69274) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#72396](https://github.com/ClickHouse/ClickHouse/issues/72396)에 백포트됨: 명명된 컬렉션에 누락되어 있던 unescaping을 추가했습니다. 이 수정이 없으면 clickhouse-server가 시작되지 않습니다. [#71308](https://github.com/ClickHouse/ClickHouse/pull/71308) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#73354](https://github.com/ClickHouse/ClickHouse/issues/73354)에 백포트됨: 구버전 PostgreSQL에서 발생하는 `column "attgenerated" does not exist` 오류를 수정하고 [#60651](https://github.com/ClickHouse/ClickHouse/issues/60651)도 해결했습니다. [#71396](https://github.com/ClickHouse/ClickHouse/pull/71396) ([0xMihalich](https://github.com/0xMihalich)).
* [#72141](https://github.com/ClickHouse/ClickHouse/issues/72141)에 백포트됨: Keeper를 사용할 수 없을 때 발생할 수 있는 데이터 손실을 방지하기 위해, 파트를 zero-copy 디스크로 이동하기 전에 zero-copy shared lock을 획득합니다. [#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72153](https://github.com/ClickHouse/ClickHouse/issues/72153)에 백포트됨: subquery 내부에서 사용되는 EXPLAIN AST에서는 SELECT 쿼리만 허용합니다. 다른 유형의 쿼리는 `Bad cast from type DB::ASTCreateQuery to DB::ASTSelectWithUnionQuery` 또는 `Inconsistent AST formatting` 같은 logical error를 일으킵니다. [#71982](https://github.com/ClickHouse/ClickHouse/pull/71982) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74382](https://github.com/ClickHouse/ClickHouse/issues/74382)에 백포트됨: `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` 이후 일시 중지되는 현상을 방지합니다. background 작업 scheduling에 올바른 설정을 가져오도록 했습니다. [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72112](https://github.com/ClickHouse/ClickHouse/issues/72112)에 백포트됨: `format_alter_commands_with_parentheses`가 enabled된 경우 `MOVE PARTITION ... TO TABLE ...` alter 명령의 formatting을 수정합니다. [#72080](https://github.com/ClickHouse/ClickHouse/pull/72080) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#72249](https://github.com/ClickHouse/ClickHouse/issues/72249)에서 백포트됨: `min_age_to_force_merge_on_partition_only`가 이미 단일 파트로 머지된 동일한 파티션에 대해 반복적으로 머지를 시도하다가 멈추고, 여러 파트가 있는 파티션은 머지하지 않던 버그를 수정했습니다. [#72209](https://github.com/ClickHouse/ClickHouse/pull/72209) ([Christoph Wurm](https://github.com/cwurm)).
