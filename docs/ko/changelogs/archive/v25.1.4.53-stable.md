<div id="performance-improvement">
  #### 성능 개선
</div>

* [#75990](https://github.com/ClickHouse/ClickHouse/issues/75990)에 백포트되었습니다: 동시성 제어로 인해 INSERT와 SELECT 간 CPU가 불공정하게 분배될 수 있는 문제가 확인되었습니다. 모든 CPU 슬롯이 INSERT에 무조건(경합 없이) 할당되고 `max_threads` = 1로 설정된 경우, `max_threads` 값이 큰 SELECT는 단일 스레드만 사용하게 되어 성능이 크게 저하됩니다. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).
