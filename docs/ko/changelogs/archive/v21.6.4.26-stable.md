* [#25186](https://github.com/ClickHouse/ClickHouse/issues/25186)에 백포트됨: 버킷 루트에 S3 디스크를 선언할 때 발생하는 오동작을 수정했습니다. 이전에는 다음과 같은 오류가 보고되었습니다: ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):. [#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#25023](https://github.com/ClickHouse/ClickHouse/issues/25023)에 백포트됨: 분산 쿼리의 limit/offset 설정을 수정했습니다(원격 노드에서는 무시됨). [#24940](https://github.com/ClickHouse/ClickHouse/pull/24940) ([Azat Khuzhin](https://github.com/azat)).
* [#25049](https://github.com/ClickHouse/ClickHouse/issues/25049)에 백포트됨: `alter move/replace partition` 동시 실행 중 복제 큐에서 극히 드물게 발생하는 `Tagging already tagged part` 오류를 수정했습니다. [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142) 수정 가능성 있음. [#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin)).
* [#25081](https://github.com/ClickHouse/ClickHouse/issues/25081)에 백포트됨: **비어 있지 않은** `GROUP BY` 키를 가진 집계 프로젝션을 사용하여 **빈** 키로 `GROUP BY` 쿼리를 실행할 때 잘못된 결과가 반환되는 문제를 수정했습니다. [#25055](https://github.com/ClickHouse/ClickHouse/pull/25055) ([Amos Bird](https://github.com/amosbird)).
* [#25107](https://github.com/ClickHouse/ClickHouse/issues/25107)에 백포트됨: `a UInt32 ALIAS a + 1` 또는 `b UInt32 MATERIALIZED b`와 같이 컬럼이 자기 자신을 참조하는 테이블을 생성할 수 있는 오동작을 수정했습니다. [#24910](https://github.com/ClickHouse/ClickHouse/issues/24910), [#24292](https://github.com/ClickHouse/ClickHouse/issues/24292) 수정. [#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin)).
* [#25106](https://github.com/ClickHouse/ClickHouse/issues/25106)에 백포트됨: mapContains에서 상수 맵을 사용할 때 `empty column was returned by function mapContains` 오류가 발생하는 오동작을 수정했습니다. [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077) 종료. [#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar)).
* [#25143](https://github.com/ClickHouse/ClickHouse/issues/25143)에 백포트됨: CROSS JOIN과 `joined_subquery_requires_alias = 0`을 사용하는 쿼리에서 발생하는 크래시를 수정했습니다. [#24011](https://github.com/ClickHouse/ClickHouse/issues/24011) 수정. [#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25157](https://github.com/ClickHouse/ClickHouse/issues/25157)에 백포트됨: 파티션 키에 `UUID`를 사용하는 테이블에서 21.5로 업데이트 후 파트가 손실될 수 있는 문제를 수정했습니다. (파티션 키에 `UUID` 사용은 권장하지 않습니다.) [#25070](https://github.com/ClickHouse/ClickHouse/issues/25070) 수정. [#25127](https://github.com/ClickHouse/ClickHouse/pull/25127) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25182](https://github.com/ClickHouse/ClickHouse/issues/25182)에 백포트됨: `FINAL`을 사용하는 `SELECT`에서 테이블의 프로젝션을 사용하지 않도록 수정했습니다. 아직 지원되지 않는 기능입니다. [#25163](https://github.com/ClickHouse/ClickHouse/pull/25163) ([Amos Bird](https://github.com/amosbird)).
