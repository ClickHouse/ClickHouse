  ### ClickHouse 릴리스 v21.11.8.4-안정 FIXME(v21.11.7.9-안정 대비)
</div>

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)
</div>

* [#32679](https://github.com/ClickHouse/ClickHouse/issues/32679)에 백포트됨: 파트를 detach할 때 projection이 예기치 않게 제거되는 문제를 수정했습니다. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* [#32543](https://github.com/ClickHouse/ClickHouse/issues/32543)에 백포트됨: 일부 복제 큐 항목이 `temporary_directories_lifetime`(기본값 1일) 동안 `Directory tmp_merge_<part_name>` 또는 `Part ... (state Deleting) already exists, but it will be deleted soon` 등의 오류와 함께 멈춰 있을 수 있었습니다. 이 문제를 수정했습니다. [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)도 해결했습니다. [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32769](https://github.com/ClickHouse/ClickHouse/issues/32769)에 백포트됨: 순차 키에서 sparse&#95;hashed dict의 성능 문제(잘못된 해시 함수)를 수정했습니다. [#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* [#32635](https://github.com/ClickHouse/ClickHouse/issues/32635)에 백포트됨: DROP TABLE과 INSERT가 병렬로 수행될 때 테이블 lifetime(즉, 발생 가능한 use-after-free) 문제를 수정했습니다. [#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* [#32633](https://github.com/ClickHouse/ClickHouse/issues/32633)에 백포트됨: 채널 생성을 지연시켜 RabbitMQ storage 시작 시 발생할 수 있는 예외를 수정했습니다. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32891](https://github.com/ClickHouse/ClickHouse/issues/32891)에 백포트됨: materialized view의 대상이 JOIN 또는 Set 테이블일 때 발생하는 LOGICAL&#95;ERROR를 수정했습니다. [#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* [#32792](https://github.com/ClickHouse/ClickHouse/issues/32792)에 백포트됨: 동일한 FixedString을 여러 번 사용해 fuzzBits를 사용할 때 발생하는 크래시를 수정했으며, [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)도 해결했습니다. [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
