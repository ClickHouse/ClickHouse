  ### ClickHouse 릴리스 v20.9.5.5-안정 FIXME(v20.9.4.76-안정 대비)

<div id="bug-fix">
  #### 오동작
</div>

* [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493)에 백포트됨: MySQL 데이터베이스 관련 버그를 수정했습니다. 데이터베이스 엔진으로 사용하는 MySQL 서버가 중단되면, 일부 쿼리가 불필요하게 비활성화된 서버에서 테이블 목록을 가져오려고 시도해 예외가 발생하던 문제입니다. 예를 들어 `SELECT ... FROM system.parts` 쿼리는 MergeTree 테이블에 대해서만 동작해야 하며, MySQL 데이터베이스에는 전혀 접근하지 않아야 합니다. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817)에 백포트됨: 필터링에 사용할 Set이 생성되지 않아 반환 데이터의 일부가 누락될 수 있던 비일관적인 동작을 수정했습니다. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508)에 백포트됨: 복제 큐의 매우 큰 항목을 처리하는 문제를 수정했습니다. 테이블 구조가 극도로 큰 경우(1MB에 가까운 경우), ALTER 쿼리에서 매우 큰 항목이 생길 수 있습니다. 이 변경으로 [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307)을 수정합니다. [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474)에 백포트됨: 분산 엔진의 DROP TABLE 문제를 수정했습니다(INSERT와 경쟁 상태가 발생할 수 있었음). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571)에 백포트됨: MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine 구성을 사용하고 MySQL Slave에서 `slave_parallel_worker`가 활성화된 경우, GTID Set을 올바르게 축소해 메타데이터가 급격히 증가하던 문제를 수정했습니다. 이 변경으로 [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951)을 수정합니다. [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554)에 백포트됨: 이제 입력에서 AVRO를 파싱할 때 유형에서 LowCardinality를 제거합니다. [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188)을 수정합니다. [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748)에 백포트됨: [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081)을 수정했습니다. [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894)에 백포트됨: query profiler가 활성화된 상태에서, 일부 함수의 비동기 언와인드 테이블(asynchronous unwind tables)이 손상된 것으로 보이는 glibc 버전이 포함된 OS에 ClickHouse를 설치한 경우 드물게 발생하던 무증상 크래시를 수정했습니다. 이 변경으로 [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301)을 수정합니다. 이 변경으로 [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098)도 수정합니다. [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
