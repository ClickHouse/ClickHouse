* [#32890](https://github.com/ClickHouse/ClickHouse/issues/32890)에 백포트됨: 구체화된 뷰(materialized view)의 대상이 JOIN 또는 SET 테이블인 경우 발생하는 LOGICAL&#95;ERROR를 수정했습니다. [#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* [#33183](https://github.com/ClickHouse/ClickHouse/issues/33183)에 백포트됨: `MySQL` 엔진을 사용하는 데이터베이스가 MySQL server에 연결할 수 없으면 서버가 시작에 실패할 수 있던 문제를 수정했습니다. [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441)을 해결합니다. [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32904](https://github.com/ClickHouse/ClickHouse/issues/32904)에 백포트됨: 실행 중인 뮤테이션이 너무 많거나 메모리 사용량이 높은 경우 `MergeTree` 테이블 엔진이 일부 뮤테이션을 조용히 건너뛸 수 있던 문제를 수정했습니다. [#17882](https://github.com/ClickHouse/ClickHouse/issues/17882)를 해결합니다. [#32814](https://github.com/ClickHouse/ClickHouse/pull/32814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#33047](https://github.com/ClickHouse/ClickHouse/issues/33047)에 백포트됨: 원격 파일 시스템의 비동기 읽기를 위한 lazy seek 최적화를 수정했습니다. [#32803](https://github.com/ClickHouse/ClickHouse/issues/32803)을 해결합니다. [#32835](https://github.com/ClickHouse/ClickHouse/pull/32835) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32932](https://github.com/ClickHouse/ClickHouse/issues/32932)에 백포트됨: [#32487](https://github.com/ClickHouse/ClickHouse/issues/32487)을 해결합니다. [#32914](https://github.com/ClickHouse/ClickHouse/pull/32914) ([Vladimir C](https://github.com/vdimir)).
* [#32962](https://github.com/ClickHouse/ClickHouse/issues/32962)에 백포트됨: `replaceRegexpAll` 함수의 리그레션을 수정했습니다. 일치한 부분 문자열이 비어 있을 때 함수가 잘못 동작하던 문제입니다. 이 변경으로 [#32777](https://github.com/ClickHouse/ClickHouse/issues/32777)을 해결합니다. 이 변경으로 [#30245](https://github.com/ClickHouse/ClickHouse/issues/30245)을 해결합니다. [#32945](https://github.com/ClickHouse/ClickHouse/pull/32945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#33067](https://github.com/ClickHouse/ClickHouse/issues/33067)에 백포트됨: HA 네임노드 주소를 사용할 수 없었던 hdfs URL 검사를 수정했습니다. 이 오동작은 [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042)에서 도입되었습니다. [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
* [#33100](https://github.com/ClickHouse/ClickHouse/issues/33100)에 백포트됨: cancel&#95;http&#95;readonly&#95;queries&#95;on&#95;client&#95;close에서 발생하던 Context 누수를 수정했습니다(즉, 서버에 업로드된 외부 테이블과 기타 리소스가 누수되는 문제). [#32982](https://github.com/ClickHouse/ClickHouse/pull/32982) ([Azat Khuzhin](https://github.com/azat)).
* [#33123](https://github.com/ClickHouse/ClickHouse/issues/33123)에 백포트됨: `local_filesystem_read_prefetch` 또는 `remote_filesystem_read_prefetch`가 활성화된 상태에서 `LowCardinality` 컬럼을 읽을 때 발생하는 오류 `Invalid version for SerializationLowCardinality key column`을 수정했습니다. [#33046](https://github.com/ClickHouse/ClickHouse/pull/33046) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
