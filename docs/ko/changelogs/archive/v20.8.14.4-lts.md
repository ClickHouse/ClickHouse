* [#21235](https://github.com/ClickHouse/ClickHouse/issues/21235)에서 백포트됨: 이제 mysql 레플리카의 구성 섹션에 있는 &quot;opt&#95;reconnect&quot; 매개변수로 MYSQL&#95;OPT&#95;RECONNECT 옵션 값을 제어할 수 있습니다. [#19998](https://github.com/ClickHouse/ClickHouse/pull/19998) ([Alexander Kazakov](https://github.com/Akazz)).
* [#21203](https://github.com/ClickHouse/ClickHouse/issues/21203)에서 백포트됨: mysql 소스 구성을 로드할 때 ClickHouse는 mysql endpoint 선택 시 라운드 로빈 로직이 제대로 동작하도록 동일한 우선순위를 가진 레플리카 목록을 무작위로 섞습니다. 이로써 [#20629](https://github.com/ClickHouse/ClickHouse/issues/20629)가 해결됩니다. [#20632](https://github.com/ClickHouse/ClickHouse/pull/20632) ([Alexander Kazakov](https://github.com/Akazz)).
* [#21336](https://github.com/ClickHouse/ClickHouse/issues/21336)에서 백포트됨: 이제 MySQL 딕셔너리 소스는 SSL/TLS 연결에서 가끔 발생하는 예기치 않은 연결 실패(Lost connection to MySQL server during query)에 대해 재시도합니다. [#21237](https://github.com/ClickHouse/ClickHouse/pull/21237) ([Alexander Kazakov](https://github.com/Akazz)).
