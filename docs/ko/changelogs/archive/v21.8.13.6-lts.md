#### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)

* [#32108](https://github.com/ClickHouse/ClickHouse/issues/32108)에 백포트됨: odbc 쿼리에서 결과가 비어 있을 때 발생하는 크래시를 수정했습니다. [#31465](https://github.com/ClickHouse/ClickHouse/issues/31465)를 종료합니다. [#31766](https://github.com/ClickHouse/ClickHouse/pull/31766) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32150](https://github.com/ClickHouse/ClickHouse/issues/32150)에 백포트됨: 타입이 `Nullable`일 때 딕셔너리 속성에 대해 타입이 지정된 함수 `dictGet`을 사용하면 발생하는 크래시를 수정했습니다. [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)를 해결합니다. [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32075](https://github.com/ClickHouse/ClickHouse/issues/32075)에 백포트됨: Decimal 인수가 있는 `transform` 함수 관련 버그를 수정했습니다. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* [#31955](https://github.com/ClickHouse/ClickHouse/issues/31955)에 백포트됨: - `KeeperTCPHandler`를 생성할 때 구성 경로를 `keeper_server.session_timeout_ms`에서 `keeper_server.coordination_settings.session_timeout_ms`로 변경했습니다 - `operation_timeout`도 동일하게 변경했습니다. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* [#32161](https://github.com/ClickHouse/ClickHouse/issues/32161)에 백포트됨: 모든 레플리카에서 파트가 손실되고 같은 파티션에 다른 파트가 없는 경우, 일부 `GET_PART` 항목이 복제 큐에서 멈출 수 있습니다. 이 문제는 파티션 키에 정수 타입의 컬럼만 포함되거나 `Date[Time]`만 포함되는 경우 수정되었습니다. [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485)를 해결합니다. [#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32146](https://github.com/ClickHouse/ClickHouse/issues/32146)에 백포트됨: 파트를 detach할 때 발생하는 `Directory ... already exists and is not empty` 오류를 수정했습니다. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32213](https://github.com/ClickHouse/ClickHouse/issues/32213)에 백포트됨: 일부 레플리카에서 설정 `replicated_can_become_leader`가 비활성화된 경우, quorum으로 삽입할 때 활성 레플리카 수가 잘못 판단될 수 있습니다. 이 문제가 수정되었습니다. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32312](https://github.com/ClickHouse/ClickHouse/issues/32312)에 백포트됨: 테이블 생성 쿼리에서 사용되는 XML dictionaries 식별자가 더 새로운 버전으로 upgrade하는 동안 `default_database`로 한정될 수 있습니다. [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)를 종료합니다. [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32540](https://github.com/ClickHouse/ClickHouse/issues/32540)에 백포트됨: 일부 복제 큐 항목이 `temporary_directories_lifetime`(기본값 1일) 동안 `Directory tmp_merge_<part_name>` 또는 `Part ... (state Deleting) already exists, but it will be deleted soon` 같은 오류와 함께 멈출 수 있습니다. 이 문제가 수정되었습니다. [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)를 해결합니다. [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32353](https://github.com/ClickHouse/ClickHouse/issues/32353)에 백포트됨: `Decimal` 인수가 있는 집계 함수 `avgWeighted`에서 SIGFPE로 인해 발생하는 크래시를 수정했습니다. [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)를 해결합니다. [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#33048](https://github.com/ClickHouse/ClickHouse/issues/33048)에 백포트됨: 채널 생성을 지연시켜 RabbitMQ 스토리지 시작 시 발생할 수 있는 예외를 수정했습니다. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32795](https://github.com/ClickHouse/ClickHouse/issues/32795)에 백포트됨: 동일한 FixedString에 `fuzzBits`를 여러 번 사용할 때 발생하는 크래시를 수정하고, [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)을 종료했습니다. [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
