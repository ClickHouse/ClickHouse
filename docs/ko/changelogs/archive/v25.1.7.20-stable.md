<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#76997](https://github.com/ClickHouse/ClickHouse/issues/76997)에 백포트됨: async insert를 활성화한 상태에서 block 크기가 서로 다른 `insert into ... from file ...`를 수행할 때, 첫 번째 block 크기가 &lt; async&#95;max&#95;size이고 두 번째 block 크기가 &gt; async&#95;max&#95;size이면 두 번째 block이 삽입되지 않아 발생하던 데이터 손실 문제를 수정했습니다. 해당 데이터는 `squashing`에 남아 있었습니다. [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* [#76675](https://github.com/ClickHouse/ClickHouse/issues/76675)에 백포트됨: 병렬 hash에서 `used_flag` 초기화를 수정했습니다. 이 문제는 서버 크래시를 유발할 수 있었습니다. [#76580](https://github.com/ClickHouse/ClickHouse/pull/76580) ([Nikita Taranov](https://github.com/nickitat)).
* [#76833](https://github.com/ClickHouse/ClickHouse/issues/76833)에 백포트됨: 출력 write buffer를 최종화하기 전에 플러시하도록 수정했습니다. `JSONEachRowWithProgressRowOutputFormat` 등 일부 출력 형식의 최종화 중 발생하던 `LOGICAL_ERROR`를 수정했습니다. [#76726](https://github.com/ClickHouse/ClickHouse/pull/76726) ([Antonio Andelic](https://github.com/antonio2368)).
* [#77062](https://github.com/ClickHouse/ClickHouse/issues/77062)에 백포트됨: `BFloat16` 값의 정렬을 수정했습니다. 이로써 [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487)이 해결되었습니다. 이로써 [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669)도 해결되었습니다. [#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
