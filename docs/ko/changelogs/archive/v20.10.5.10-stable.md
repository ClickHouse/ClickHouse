<div id="improvement">
  #### 개선 사항
</div>

* [#17031](https://github.com/ClickHouse/ClickHouse/issues/17031)에 백포트되었습니다: SNI가 필요한 `clickhouse-server`의 보안 엔드포인트에 연결할 수 있게 했습니다. 이는 `clickhouse-server`가 TLS 프록시 뒤에서 호스팅되는 경우 가능합니다. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

[#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).

* [#16949](https://github.com/ClickHouse/ClickHouse/issues/16949)에 백포트되었습니다: TimeSeriesGroupSum을 사용할 때 ClickHouse 서버 크래시를 방지합니다. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).

[#16580](https://github.com/ClickHouse/ClickHouse/issues/16580)을 수정합니다. [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17008](https://github.com/ClickHouse/ClickHouse/issues/17008)에 백포트되었습니다: 설치 스크립트가 config 폴더에 하위 디렉터리를 항상 생성하도록 수정합니다. 이는 사용자 지정 구성을 사용하는 Docker build에만 해당합니다. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* [#16967](https://github.com/ClickHouse/ClickHouse/issues/16967)에 백포트되었습니다: `clickhouse-git-import`에서 blame 정보가 올바르게 계산되지 않던 문제를 수정합니다. [#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#17012](https://github.com/ClickHouse/ClickHouse/issues/17012)에 백포트되었습니다: `ALTER TABLE ... MODIFY COLUMN ... NewType` 이후, `SELECT`에 변경 중인 컬럼에 대한 `WHERE` 표현식이 있고 ALTER가 아직 완료되지 않았을 때 발생할 수 있는 서버 크래시를 수정합니다. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
