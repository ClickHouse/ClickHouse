* [#68252](https://github.com/ClickHouse/ClickHouse/issues/68252)에서 백포트됨: 서브쿼리를 사용해 필터링할 때 일부 시스템 테이블에서 발생하던 `Not-ready Set` 오류를 수정했습니다. [#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* [#68064](https://github.com/ClickHouse/ClickHouse/issues/68064)에서 백포트됨: 외부 데이터베이스(예: `PostgreSQL`)로 전송되는 쿼리의 Boolean 리터럴을 수정했습니다. [#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* [#68158](https://github.com/ClickHouse/ClickHouse/issues/68158)에서 백포트됨: 서버 간 시크릿에 대한 cluster()를 수정했습니다(이전과 같이 초기 사용자를 유지). [#66364](https://github.com/ClickHouse/ClickHouse/pull/66364) ([Azat Khuzhin](https://github.com/azat)).
* [#68115](https://github.com/ClickHouse/ClickHouse/issues/68115)에서 백포트됨: Variant 서브컬럼을 읽는 중 발생할 수 있는 PARAMETER&#95;OUT&#95;OF&#95;BOUND 오류를 수정했습니다. [#66659](https://github.com/ClickHouse/ClickHouse/pull/66659) ([Kruglov Pavel](https://github.com/Avogar)).
* [#67886](https://github.com/ClickHouse/ClickHouse/issues/67886)에서 백포트됨: 파일 이름/URI에 `::`가 포함되어 있고 아카이브가 아닌 경우에도 올바르게 parse하도록 수정했습니다. [#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368)).
* [#68272](https://github.com/ClickHouse/ClickHouse/issues/68272)에서 백포트됨: HTTP 인터페이스를 통해 stream 계열 엔진(Kafka, RabbitMQ, NATS)에 삽입할 때의 문제를 수정했습니다. [#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#67807](https://github.com/ClickHouse/ClickHouse/issues/67807)에서 백포트됨: UNION 사용 시 SQL UDF를 다시 로드하는 문제를 수정했습니다. 이전에는 서버를 재시작하면 UDF가 무효 상태가 될 수 있었습니다. [#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* [#67836](https://github.com/ClickHouse/ClickHouse/issues/67836)에서 백포트됨: `JSONMergePatch` 함수에서 발생할 수 있는 스택 오버플로우를 수정했습니다. 이전 이름이 잘못되었기 때문에 이 함수의 이름을 `jsonMergePatch`에서 `JSONMergePatch`로 변경했습니다. 이전 이름도 호환성을 위해 계속 유지됩니다. 이 함수의 오류 진단도 개선했습니다. 이로써 [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304)가 해결되었습니다. [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#67991](https://github.com/ClickHouse/ClickHouse/issues/67991)에서 백포트됨: ALTER ADD/MODIFY COLUMN에서 Experimental/의심스러운 데이터 타입을 검증하도록 했습니다. [#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68207](https://github.com/ClickHouse/ClickHouse/issues/68207)에서 백포트됨: 프레디케이트에 비결정적 함수가 있을 때 `count()` 결과가 잘못되는 문제를 수정했습니다. [#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#68091](https://github.com/ClickHouse/ClickHouse/issues/68091)에서 백포트됨: 사용 가능한 CPU 수가 제한된 컨테이너 환경에서 최대 thread 소프트 리밋 계산을 수정했습니다. [#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* [#68122](https://github.com/ClickHouse/ClickHouse/issues/68122)에 백포트됨: 새 분석기에서 뮤테이션 수행 시 변경되지 않은 파트를 스키핑하지 못하던 문제를 수정했습니다. 이전에는 분석기가 활성화된 경우, 프레디케이트상 해당 파트에 뮤테이션이 영향을 주지 않더라도 그 파트의 데이터가 뮤테이션으로 재작성될 수 있었습니다. [#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
