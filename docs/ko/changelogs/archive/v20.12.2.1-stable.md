<div id="clickhouse-release-v201221-stable-fixme-as-compared-to-v201115109-prestable">
  ### ClickHouse 릴리스 v20.12.2.1-stable FIXME, v20.11.1.5109-prestable 대비 변경 사항
</div>

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* `File` 엔진을 사용하는 테이블을 생성할 때 `SETTINGS` 절에서 파일 포맷 관련 사용자 설정(예: `format_csv_delimiter`)을 허용하고, 모든 `INSERT` 및 `SELECT`에 이 설정을 사용합니다. 현재 사용자 세션에서 변경된 파일 포맷 설정이나 DML 쿼리 자체의 `SETTINGS` 절에서 지정한 설정은 더 이상 해당 쿼리에 영향을 주지 않습니다. [#16591](https://github.com/ClickHouse/ClickHouse/pull/16591) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 기본적으로 `use_compact_format_in_distributed_parts_names`를 활성화했습니다(자세한 내용은 참고 문서를 확인하십시오). [#16728](https://github.com/ClickHouse/ClickHouse/pull/16728) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 새 기능
</div>

* 새로운 ALTER UPDATE/DELETE IN PARTITION 구문을 추가했습니다. [#13403](https://github.com/ClickHouse/ClickHouse/pull/13403) ([Vladimir Chebotarev](https://github.com/excitoon)).
* StorageEmbeddedRocksdb 엔진을 추가했습니다. [#15073](https://github.com/ClickHouse/ClickHouse/pull/15073) ([sundyli](https://github.com/sundy-li)).
* `ALTER TABLE ... DROP|DETACH PART 'part_name'` 쿼리를 도입했습니다. [#15511](https://github.com/ClickHouse/ClickHouse/pull/15511) ([nvartolomei](https://github.com/nvartolomei)).
* `clickhouse-client`에서 `--history_file` 매개변수를 사용해 이력 파일 경로를 변경할 수 있도록 했습니다. [#15960](https://github.com/ClickHouse/ClickHouse/pull/15960) ([Maksim Kita](https://github.com/kitaisreal)).
* DateTime, DateTime64 포맷이 문자열 Date 리터럴 포맷을 허용하도록 업데이트했습니다. [#16040](https://github.com/ClickHouse/ClickHouse/pull/16040) ([Maksim Kita](https://github.com/kitaisreal)).
* `aggregate_functions_null_for_empty` 설정을 추가했습니다. 이 옵션은 쿼리의 모든 집계 함수를 `-OrNull` 접미사가 추가된 형태로 재작성합니다. [10273](https://github.com/ClickHouse/ClickHouse/issues/10273)을 수정했습니다. [#16123](https://github.com/ClickHouse/ClickHouse/pull/16123) ([flynn](https://github.com/ucasfl)).
* 중첩 타입이 String인 경우 Nullable, LowCardinality, Array, Tuple에 대한 COLLATE 지원을 추가했습니다. 또한 ColumnString.cpp의 콜레이션 관련 코드를 리팩터링했습니다. [#16273](https://github.com/ClickHouse/ClickHouse/pull/16273) ([Kruglov Pavel](https://github.com/Avogar)).
* 서로 다른 레플리카 간에 머지를 분산할 수 있게 했습니다. `execute_merges_on_single_replica_time_threshold` MergeTree 설정을 도입했습니다. [#16424](https://github.com/ClickHouse/ClickHouse/pull/16424) ([filimonov](https://github.com/filimonov)).
* `*.xz` 압축/압축 해제 지원을 추가했습니다. 이제 `file()` 함수에서 `*.xz`를 사용할 수 있습니다. 이 변경으로 [#8828](https://github.com/ClickHouse/ClickHouse/issues/8828)가 해결되었습니다. [#16578](https://github.com/ClickHouse/ClickHouse/pull/16578) ([Abi Palagashvili](https://github.com/fibersel)).
* 새로운 `cmath` 함수를 추가했습니다: - acosh - asinh - atan2 - atanh - cosh - hypot - log1p - sinh. [#16636](https://github.com/ClickHouse/ClickHouse/pull/16636) ([Konstantin Malanchev](https://github.com/hombit)).
* TSV 및 CSV 형식에서 기본적으로 enum 값을 해당 id로 입력할 수 있도록 했습니다. [#16834](https://github.com/ClickHouse/ClickHouse/pull/16834) ([Kruglov Pavel](https://github.com/Avogar)).
* 새로운 tcpPort() 함수는 이 서버가 수신 대기 중인 TCP 포트를 반환합니다. [#17134](https://github.com/ClickHouse/ClickHouse/pull/17134) ([Ivan](https://github.com/abyss7)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* 이제 정확히 일치하는 조건으로 파티션을 안전하게 프루닝할 수 있습니다. 유용한 사례: 테이블(table)이 intHash64(x) % 100으로 파티셔닝되어 있고, 쿼리에 x가 아니라 intHash64(x) % 100 자체에 대한 조건이 그대로 포함되어 있다고 가정합니다. [#16253](https://github.com/ClickHouse/ClickHouse/pull/16253) ([Amos Bird](https://github.com/amosbird)).
* Floyd-Rivest 알고리즘을 사용합니다. ClickHouse의 partial sorting 사용 사례에는 이 알고리즘이 가장 적합합니다. 벤치마크는 https://github.com/danlark1/miniselect 및 [여기](https://drive.google.com/drive/folders/1DHEaeXgZuX6AJ9eByeZ8iQVQv0ueP8XM)에 있습니다. [#16825](https://github.com/ClickHouse/ClickHouse/pull/16825) ([Daniel Kutenin](https://github.com/danlark1)).
* [#17589](https://github.com/ClickHouse/ClickHouse/issues/17589)에 백포트됨: `MergeTree` 테이블이 매우 많은 환경에서 `Merge` 테이블 읽기 성능을 개선했습니다. [#7748](https://github.com/ClickHouse/ClickHouse/issues/7748)를 해결합니다. [#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).



<div id="improvement">
  #### 개선 사항
</div>

* `EXPLAIN`에 `VIEW` 서브쿼리 설명을 추가하였습니다. `VIEW`에 대한 Limit push down 최적화를 제한하였습니다. 쿼리 계획에 `Distributed`의 로컬 레플리카를 추가하였습니다. [#14936](https://github.com/ClickHouse/ClickHouse/pull/14936) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `indexOf()`가 BloomFilter를 사용하도록 변경하였습니다. [#14977](https://github.com/ClickHouse/ClickHouse/pull/14977) ([achimbab](https://github.com/achimbab)).
* MySQL 동기화 사용자에게 잘못된 권한이 있을 경우, 올바른 동기화 권한에 대한 예외를 발생시키도록 하였습니다. [#15977](https://github.com/ClickHouse/ClickHouse/pull/15977) ([TCeason](https://github.com/TCeason)).
* materialized view가 순환 참조를 형성할 경우 발생할 수 있는 스택 오버플로우를 수정하였습니다. [#15732](https://github.com/ClickHouse/ClickHouse/issues/15732) 이슈를 종료합니다. [#16048](https://github.com/ClickHouse/ClickHouse/pull/16048) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 원격 리소스에 대한 HTTPS 연결에서 SNI를 지원합니다. 이를 통해 SNI가 필요한 Cloudflare 서버에 연결할 수 있습니다. [#10055](https://github.com/ClickHouse/ClickHouse/issues/10055) 이슈를 수정합니다. [#16252](https://github.com/ClickHouse/ClickHouse/pull/16252) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 이제 `ReplicatedMergeTree` 엔진 계열은 복제 fetch 작업에 별도의 스레드 풀을 사용합니다. 풀 크기는 `background_fetches_pool_size` 설정으로 제한되며, 서버를 재시작하여 조정할 수 있습니다. 기본값은 3으로, 최대 병렬 fetch 수가 3임을 의미합니다(10G 네트워크 활용 가능). #520 이슈를 수정합니다. [#16390](https://github.com/ClickHouse/ClickHouse/pull/16390) ([alesapin](https://github.com/alesapin)).
* 이제 `<auxiliary_zookeepers>` 구성을 `config.xml`에서 변경한 후 서버 재시작 없이 다시 로드할 수 있습니다. [#16627](https://github.com/ClickHouse/ClickHouse/pull/16627) ([Amos Bird](https://github.com/amosbird)).
* 크기가 동일한 정수와 부동소수점 간의 reinterpret를 허용합니다. [16640](https://github.com/ClickHouse/ClickHouse/issues/16640) 이슈를 수정합니다. [#16657](https://github.com/ClickHouse/ClickHouse/pull/16657) ([flynn](https://github.com/ucasfl)).
* nginx 서버를 프록시로 사용하여 S3에 접근할 때의 임시 해결책입니다. nginx는 현재 `http://domain.com?delete`와 같이 경로가 없는 URL을 허용하지 않지만, 기본 aws-sdk-cpp는 이러한 형태의 URL을 생성합니다. 이 커밋은 패치된 aws-sdk-cpp 버전을 사용하여 해당 경우에 `http://domain.com/?delete`와 같이 "/"를 경로로 포함한 URL을 생성하도록 합니다. [#16709](https://github.com/ClickHouse/ClickHouse/pull/16709) ([ianton-ru](https://github.com/ianton-ru)).
* 분산 엔진 시작 시 async 삽입용 빈 디렉터리를 제거합니다. [#16729](https://github.com/ClickHouse/ClickHouse/pull/16729) ([Azat Khuzhin](https://github.com/azat)).
* 사용성 개선: `CREATE TABLE` 쿼리에서 `CODEC` 표현식의 위치가 잘못된 경우 구문 오류 메시지에 더 유용한 제안을 표시합니다. [#12493](https://github.com/ClickHouse/ClickHouse/issues/12493) 이슈를 수정합니다. [#16768](https://github.com/ClickHouse/ClickHouse/pull/16768) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 분산 DDL 구성이 없을 때 더 명확한 예외 메시지를 표시합니다. [#5075](https://github.com/ClickHouse/ClickHouse/issues/5075) 이슈를 수정합니다. [#16769](https://github.com/ClickHouse/ClickHouse/pull/16769) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `internal_replication`을 사용하는 각 삽입 작업에 `use_compact_format_in_distributed_parts_names`를 적용합니다. [#16788](https://github.com/ClickHouse/ClickHouse/pull/16788) ([Azat Khuzhin](https://github.com/azat)).
* 잘못된 구성이 제공된 경우(`metric_log`.`collect_interval_milliseconds` 누락 등) 서버가 예외 메시지를 출력하고 시작을 거부합니다. [#16815](https://github.com/ClickHouse/ClickHouse/pull/16815) ([Ivan](https://github.com/abyss7)).
* `cutToFirstSignificantSubdomainWithWWW()` 함수를 추가하였습니다. [#16845](https://github.com/ClickHouse/ClickHouse/pull/16845) ([Azat Khuzhin](https://github.com/azat)).
* ATTACH/DETACH TABLE <DICTIONARY> 수행 시 유용한 오류 메시지를 표시합니다. 이 PR 이전에는 `detach table <dict>`가 동작하였으나 메모리 내 메타데이터가 잘못된 형태로 남는 문제가 있었습니다. [#16885](https://github.com/ClickHouse/ClickHouse/pull/16885) ([Amos Bird](https://github.com/amosbird)).
* TTL, 뮤테이션, 또는 collapsing 머지 알고리즘에 의해 정리된 빈 파트를 제거합니다. [#16895](https://github.com/ClickHouse/ClickHouse/pull/16895) ([Anton Popov](https://github.com/CurtizJ)).
* SNI가 필요한 `clickhouse-server` 보안 엔드포인트에 연결할 수 있도록 합니다. `clickhouse-server`가 TLS 프록시 뒤에 위치한 경우에 활용할 수 있습니다. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).
* `SOURCE(CLICKHOUSE(...))`의 기본 `host` 및 `port` 매개변수를 현재 인스턴스로, 기본 `user` 값을 `'default'`로 설정합니다. [#16997](https://github.com/ClickHouse/ClickHouse/pull/16997) ([Vladimir C](https://github.com/vdimir)).
* `JSONEachRow` 포맷에서 모든 행을 JSON 배열로 출력하는 기능을 추가하였습니다. `output_format_json_array_of_rows` 설정으로 제어됩니다. [#17152](https://github.com/ClickHouse/ClickHouse/pull/17152) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* JSON 입력/출력 포맷 사용 시 이름이 지정된 Tuple을 JSON 객체로 포맷할 수 있도록 허용합니다. `output_format_json_named_tuples_as_objects` 설정으로 제어되며, 기본적으로 비활성화되어 있습니다. [#17175](https://github.com/ClickHouse/ClickHouse/pull/17175) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* JSONEachRow, JSONCompactEachRow, RegexpRow 입력 형식의 오류 메시지에 포함된 문법 오류를 수정하였습니다. [#17205](https://github.com/ClickHouse/ClickHouse/pull/17205) ([nico piderman](https://github.com/sneako)).
