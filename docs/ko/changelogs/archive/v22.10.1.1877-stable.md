  # 2022년 변경 로그
</div>

<div id="clickhouse-release-v221011877-stable-98ab5a3c189-fixme-as-compared-to-v22912603-stable-3030d4c7ff0">
  ### ClickHouse 릴리스 v22.10.1.1877-안정 (98ab5a3c189) FIXME v22.9.1.2603-안정 (3030d4c7ff0) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* cache 명령의 이름을 변경했습니다: `show caches` -&gt; `show filesystem caches`, `describe cache` -&gt; `describe filesystem cache`. [#41508](https://github.com/ClickHouse/ClickHouse/pull/41508) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `LIVE VIEW`의 `WITH TIMEOUT` 섹션에 대한 지원을 제거했습니다. 이로써 [#40557](https://github.com/ClickHouse/ClickHouse/issues/40557)가 종료되었습니다. [#42173](https://github.com/ClickHouse/ClickHouse/pull/42173) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 새 기능
</div>

* BLAKE3 해시 함수 라이브러리를 예시로 사용해 ClickHouse에 Rust 코드 지원을 추가했습니다. [#33435](https://github.com/ClickHouse/ClickHouse/pull/33435) ([BoloniniD](https://github.com/BoloniniD)).
* Kusto Query Language의 초기 구현(MVP)입니다. [#37961](https://github.com/ClickHouse/ClickHouse/pull/37961) ([Yong Wang](https://github.com/kashwy)).
* * 설정 `max_temporary_data_on_disk_size_for_user`/`max_temporary_data_on_disk_size_for_query`를 사용해 디스크에 저장되는 임시 데이터의 크기를 제한할 수 있도록 지원합니다. [#40893](https://github.com/ClickHouse/ClickHouse/pull/40893) ([Vladimir C](https://github.com/vdimir)).
* `javaHash`에서 Java 정수 해싱을 지원합니다. [#41131](https://github.com/ClickHouse/ClickHouse/pull/41131) ([JackyWoo](https://github.com/JackyWoo)).
* 이 PR은 BoringSSL 서브모듈과 마찬가지로 OpenSSL 자체 빌드를 지원하기 위한 것입니다. BoringSSL과 OpenSSL 중에서 선택하려면 빌드 플래그 ENABLE&#95;CH&#95;BUNDLE&#95;BORINGSSL을 사용합니다. 기본적으로는 BoringSSL 자체 빌드가 사용됩니다. [#41142](https://github.com/ClickHouse/ClickHouse/pull/41142) ([MeenaRenganathan22](https://github.com/MeenaRenganathan22)).
* 조합 가능한 프로토콜 구성이 추가되었습니다. [#41198](https://github.com/ClickHouse/ClickHouse/pull/41198) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* ON CLUSTER DDL에 OpenTelemetry 지원을 추가합니다(`distributed_ddl_entry_format_version`을 4로 설정해야 합니다). [#41484](https://github.com/ClickHouse/ClickHouse/pull/41484) ([Frank Chen](https://github.com/FrankChen021)).
* JSONObjectEachRow 포맷에서 객체 이름을 컬럼 값으로 쓰고 파싱할 수 있도록 `format_json_object_each_row_column_for_object_name` 설정을 추가합니다. [#41703](https://github.com/ClickHouse/ClickHouse/pull/41703) ([Kruglov Pavel](https://github.com/Avogar)).
* Morton Coding(ZCurve) 인코딩/디코딩 함수를 추가합니다. [#41753](https://github.com/ClickHouse/ClickHouse/pull/41753) ([Constantine Peresypkin](https://github.com/pkit)).
* 가장 널리 사용되는 2가지 UUID 바이너리 형식, 즉 기본 big-endian과 [RFC 4122](https://datatracker.ietf.org/doc/html/rfc4122#section-4.1.1)에 지정된 Microsoft의 mixed-endian을 지원하도록 구현했습니다. [#42108](https://github.com/ClickHouse/ClickHouse/pull/42108) ([ltrk2](https://github.com/ltrk2)).
* 정규 분포를 따르는 여러 그룹의 관측값을 대상으로 통계 검정을 수행하여 모든 그룹의 평균이 같은지 여부를 확인하는 집계 함수 `analysisOfVariance`(`anova`)를 추가했습니다. 원본 PR [#37872](https://github.com/ClickHouse/ClickHouse/issues/37872). [#42131](https://github.com/ClickHouse/ClickHouse/pull/42131) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `SET setting_name = DEFAULT` 지원을 추가합니다. [#42187](https://github.com/ClickHouse/ClickHouse/pull/42187) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* * RFC를 준수하는 `URL` 함수를 추가했습니다. 포함된 함수는 다음과 같습니다: `cutToFirstSignificantSubdomainCustomRFC`, `cutToFirstSignificantSubdomainCustomWithWWWRFC`, `cutToFirstSignificantSubdomainRFC`, `cutToFirstSignificantSubdomainWithWWWRFC`, `domainRFC`, `domainWithoutWWWRFC`, `firstSignificantSubdomainCustomRFC`, `firstSignificantSubdomainRFC`, `portRFC`, `topLevelDomainRFC`. [#42274](https://github.com/ClickHouse/ClickHouse/pull/42274) ([Quanfa Fu](https://github.com/dentiscalprum)).
* 지정된 분포에 따라 난수를 생성하는 함수(`randUniform`, `randNormal`, `randLogNormal`, `randExponential`, `randChiSquared`, `randStudentT`, `randFisherF`, `randBernoulli`, `randBinomial`, `randNegativeBinomial`, `randPoisson` )가 추가되었습니다. 이 변경으로 [#21834](https://github.com/ClickHouse/ClickHouse/issues/21834)가 해결되었습니다. [#42411](https://github.com/ClickHouse/ClickHouse/pull/42411) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 스택 오버플로우 문제를 해결하고 필요한 스택 크기를 줄이기 위해 연산자 precedence 요소 파서를 구현했습니다. [#34892](https://github.com/ClickHouse/ClickHouse/pull/34892) ([Nikolay Degterinsky](https://github.com/evillique)).
* DISTINCT in order 최적화에서 데이터 스트림의 sorting 속성을 활용하도록 개선했습니다. 이 개선으로 적용 가능한 경우 DISTINCT에 대해 순서대로 읽기를 사용할 수 있습니다(이전에는 DISTINCT의 컬럼에 대해 ORDER BY를 지정해야 했습니다). [#41014](https://github.com/ClickHouse/ClickHouse/pull/41014) ([Igor Nikonov](https://github.com/devcrafter)).
* ColumnVector: AVX512VBMI를 사용해 UInt8 인덱스를 최적화했습니다. [#41247](https://github.com/ClickHouse/ClickHouse/pull/41247) ([Guo Wangyang](https://github.com/guowangy)).
* ICX 장치(Intel Xeon Platinum 8380 CPU, 80코어, 160스레드)에서 수행한 **SSB**(Star Schema Benchmark) 성능 실험에 따르면, 이 변경으로 모든 하위 사례의 QPS 기하평균이 **2.95배** 향상될 수 있습니다. [#41675](https://github.com/ClickHouse/ClickHouse/pull/41675) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* LowCardinality(String) 튜플에서 JSONExtract가 느려지는 문제를 수정했습니다. [#41726](https://github.com/ClickHouse/ClickHouse/pull/41726) ([AlfVII](https://github.com/AlfVII)).
* AArch64 builds에 ldapr capability를 추가했습니다. 이는 Graviton 2+, Azure 및 GCP 인스턴스에서 지원됩니다. clang-15에 비교적 최근에 [추가된](https://github.com/llvm/llvm-project/commit/9609b5daffe9fd28d83d83da895abc5113f76c24) 기능입니다. [#41778](https://github.com/ClickHouse/ClickHouse/pull/41778) ([Daniel Kutenin](https://github.com/danlark1)).
* 문자열을 비교할 때 한 인수가 빈 상수 문자열인 경우의 성능을 개선했습니다. [#41870](https://github.com/ClickHouse/ClickHouse/pull/41870) ([Jiebin Sun](https://github.com/jiebinn)).
* 일부 경우 ColumnAggregateFunction의 insertFrom이 aggregate state를 공유하도록 최적화했습니다. [#41960](https://github.com/ClickHouse/ClickHouse/pull/41960) ([flynn](https://github.com/ucasfl)).
* &quot;Too many parts&quot; 임계값을 완화했습니다. 이로써 [#6551](https://github.com/ClickHouse/ClickHouse/issues/6551)이 해결됩니다. 이제 평균 파트 크기가 충분히 큰 경우(최소 10 GiB) ClickHouse는 하나의 파티션에 더 많은 파트를 허용합니다. 따라서 디스크 셸프나 객체 스토리지를 사용하면 단일 서버의 단일 테이블 내 단일 파티션에 최대 페타바이트 규모의 데이터를 저장할 수 있습니다. [#42002](https://github.com/ClickHouse/ClickHouse/pull/42002) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* AzureBlobStorage에 대한 쓰기를 더 효율적으로 개선했습니다(`buffer size`마다 block을 하나씩 쓰는 대신 `max_single_part_upload_size`를 따릅니다). 이 비효율성은 [#41754](https://github.com/ClickHouse/ClickHouse/issues/41754)에서 언급되었습니다. [#42041](https://github.com/ClickHouse/ClickHouse/pull/42041) ([Kseniia Sumarokova](https://github.com/kssenii)).
* process list와 query&#95;log의 thread id를 고유하게 만들어 불필요한 낭비를 방지했습니다. [#42180](https://github.com/ClickHouse/ClickHouse/pull/42180) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 개선 사항
</div>

* `allow_experimental_analyzer` 설정 아래에 쿼리 분석 및 계획 수립을 위한 새로운 인프라를 추가했습니다. [#31796](https://github.com/ClickHouse/ClickHouse/pull/31796) ([Maksim Kita](https://github.com/kitaisreal)).
* * 서브쿼리에서 표현식 `(EXPLAIN SELECT ...)`을 지원합니다. 이제 `SELECT * FROM (EXPLAIN PIPELINE SELECT col FROM TABLE ORDER BY col)`와 같은 쿼리도 유효합니다. [#40630](https://github.com/ClickHouse/ClickHouse/pull/40630) ([Vladimir C](https://github.com/vdimir)).
* 현재 쿼리 범위에서 `async_insert_max_data_size` 또는 `async_insert_busy_timeout_ms`를 변경해도 의미가 없으며, 이는 사용자 경험을 저하시킵니다. 예를 들어, 데이터를 드물게 삽입하려는 사용자가 기본 설정을 조정할 수 있도록 서버 구성에 접근할 수 없는 경우가 있습니다. [#40668](https://github.com/ClickHouse/ClickHouse/pull/40668) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 내장 Keeper는 항상 백그라운드에서 시작되므로, ClickHouse는 정족수(quorum)를 달성하지 못해도 시작할 수 있습니다. [#40991](https://github.com/ClickHouse/ClickHouse/pull/40991) ([Antonio Andelic](https://github.com/antonio2368)).
* 원격 파일 시스템에서의 읽기를 개선하고, 읽기/쓰기용 스레드 풀 크기를 구성 가능하게 했습니다. [#41070](https://github.com/ClickHouse/ClickHouse/issues/41070)을 해결합니다. [#41011](https://github.com/ClickHouse/ClickHouse/pull/41011) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 기존 연결(connection)이 만료된 경우 새 연결을 더 신속하게 다시 설정하도록 개선했습니다. 이전에는 기본적으로 1분마다 실행되는 작업이 있었기 때문에 table이 그 정도 시간 동안 readonly 상태로 남아 있을 수 있었습니다. [#41092](https://github.com/ClickHouse/ClickHouse/pull/41092) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* WindowTransform/arratReduce*/initializeAggregation/aggregate functions의 버전 관리에서 모든 combinator 조합을 지원합니다. 이전에는 `ForEach/Resample/Map`과 같은 combinator가 이러한 위치에서 동작하지 않았으며, 이를 사용하면 `State function ... inserts results into non-state column`과 같은 오류가 발생했습니다. [#41107](https://github.com/ClickHouse/ClickHouse/pull/41107) ([Kruglov Pavel](https://github.com/Avogar)).
* 이제 프로젝션을 zero-copy 복제와 함께 사용할 수 있습니다. [#41147](https://github.com/ClickHouse/ClickHouse/pull/41147) ([alesapin](https://github.com/alesapin)).
* * 복호화에 실패할 경우(예: 잘못된 key로 복호화하는 경우) 예외를 발생시키는 대신 NULL을 반환하는 `tryDecrypt` 함수를 추가했습니다. [#41206](https://github.com/ClickHouse/ClickHouse/pull/41206) ([Duc Canh Le](https://github.com/canhld94)).
* 디스크별로 예약으로 점유되지 않은 공간의 크기를 확인할 수 있도록 `system.disks` 테이블에 `unreserved_space` 컬럼을 추가했습니다. [#41254](https://github.com/ClickHouse/ClickHouse/pull/41254) ([filimonov](https://github.com/filimonov)).
* AST 인수에서 S3 인증 헤더를 지원합니다. [#41261](https://github.com/ClickHouse/ClickHouse/pull/41261) ([Kseniia Sumarokova](https://github.com/kssenii)).
* &#39;IDENTIFIED WITH no&#95;password&#39;를 명시적으로 지정하지 않으면 비밀번호 없는 USER를 생성할 수 없도록 하는 설정 &#39;allow&#95;implicit&#95;no&#95;password&#39;를 추가했습니다. [#41341](https://github.com/ClickHouse/ClickHouse/pull/41341) ([Nikolay Degterinsky](https://github.com/evillique)).
* keeper-improvement: S3로 스냅샷을 업로드하는 기능을 추가했습니다. S3 정보는 `keeper_server.s3_snapshot` 내에 정의할 수 있습니다. [#41342](https://github.com/ClickHouse/ClickHouse/pull/41342) ([Antonio Andelic](https://github.com/antonio2368)).
* Keeper 및 내부 ZooKeeper 클라이언트에 MultiRead 지원을 추가했습니다. [#41410](https://github.com/ClickHouse/ClickHouse/pull/41410) ([Antonio Andelic](https://github.com/antonio2368)).
* IN Operator에서 Decimal 유형과 부동소수점 리터럴을 비교할 수 있도록 지원을 추가했습니다. [#41544](https://github.com/ClickHouse/ClickHouse/pull/41544) ([liang.huang](https://github.com/lhuang09287750)).
* cache 구성에서 사람이 읽기 쉬운 크기 형식의 값을 허용합니다. [#41688](https://github.com/ClickHouse/ClickHouse/pull/41688) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 입력 포맷용 오류 로거에서 경로 탐색(path traversal) 공격을 방지하기 위해 파일 경로를 검사합니다. [#41694](https://github.com/ClickHouse/ClickHouse/pull/41694) ([Kruglov Pavel](https://github.com/Avogar)).
* ClickHouse는 cache가 비동기로 갱신되기 전까지 일정 시간(기본값 15초) 오래된 DNS 항목을 cache할 수 있었습니다. 이 기간 동안 ClickHouse는 여전히 연결을 시도해 오류를 발생시킬 수 있었습니다. 이 동작을 수정했습니다. [#41707](https://github.com/ClickHouse/ClickHouse/pull/41707) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `clickhouse-client`/`clickhouse-local`에 fzf 계열 유틸리티(fzf/sk)를 사용한 대화형 이력 검색 기능을 추가했습니다(동작을 추가로 구성하려면 `FZF_DEFAULT_OPTS`/`SKIM_DEFAULT_OPTIONS`를 사용할 수 있습니다). [#41730](https://github.com/ClickHouse/ClickHouse/pull/41730) ([Azat Khuzhin](https://github.com/azat)).
* 잘못된 certificate로 보안 server에 연결하는 클라이언트는 &#39;--accept-certificate&#39; 플래그를 지정한 경우에만 계속 진행할 수 있도록 했습니다. [#41743](https://github.com/ClickHouse/ClickHouse/pull/41743) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 기존 함수 &quot;tryBase64Decode()&quot;와 유사한 함수 &quot;tryBase58Decode()&quot;를 추가했습니다. [#41824](https://github.com/ClickHouse/ClickHouse/pull/41824) ([Robert Schulze](https://github.com/rschu1ze)).
* 서로 다른 primary key로 파티션을 대체할 때 표시되는 피드백을 개선했습니다. [#34798](https://github.com/ClickHouse/ClickHouse/issues/34798)를 수정했습니다. [#41838](https://github.com/ClickHouse/ClickHouse/pull/41838) ([Salvatore](https://github.com/tbsal)).
* `/etc/security/limits.conf`의 limits를 준수할 수 있도록 시작 시 `clickhouse su` 명령을 다시 `sudo -u`로 바꿨습니다. [#41847](https://github.com/ClickHouse/ClickHouse/pull/41847) ([Eugene Konkov](https://github.com/ekonkov)).
* 병렬 파싱을 수정했습니다. 이제 segmentator가 max&#95;block&#95;size를 확인합니다. [#41852](https://github.com/ClickHouse/ClickHouse/pull/41852) ([Vitaly Baranov](https://github.com/vitlibar)).
* 테이블이 방금 삭제된 경우 이를 건너뛰기 위해 TABLE&#95;IS&#95;DROPPED Exception을 보고하지 않도록 개선했습니다. [#41908](https://github.com/ClickHouse/ClickHouse/pull/41908) ([AlfVII](https://github.com/AlfVII)).
* enable&#95;extended&#95;results&#95;for&#95;datetime&#95;functions 옵션을 개선하여 toStartOfDay, toStartOfHour, toStartOfFifteenMinutes, toStartOfTenMinutes, toStartOfFiveMinutes, toStartOfMinute, timeSlot 함수가 DateTime64 타입의 결과를 반환하도록 했습니다. [#41910](https://github.com/ClickHouse/ClickHouse/pull/41910) ([Roman Vasin](https://github.com/rvasin)).
* 텍스트 포맷의 DateTime 타입 추론을 개선했습니다. 이제 `date_time_input_format` 설정을 따르며, 숫자를 timestamp로 간주해 datetime을 추론하지 않습니다. [#41389](https://github.com/ClickHouse/ClickHouse/issues/41389), [#42206](https://github.com/ClickHouse/ClickHouse/issues/42206)을 해결했습니다. [#41912](https://github.com/ClickHouse/ClickHouse/pull/41912) ([Kruglov Pavel](https://github.com/Avogar)).
* `perform_ttl_move_on_insert`=false로 삽입할 때 표시되던 혼동을 주는 경고를 제거했습니다. [#41980](https://github.com/ClickHouse/ClickHouse/pull/41980) ([Vitaly Baranov](https://github.com/vitlibar)).
* 이제 사용자가 `count(*)`와 마찬가지로 `countState(*)`도 작성할 수 있습니다. 이 변경으로 [#9338](https://github.com/ClickHouse/ClickHouse/issues/9338)이 해결되었습니다. [#41983](https://github.com/ClickHouse/ClickHouse/pull/41983) ([Amos Bird](https://github.com/amosbird)).
