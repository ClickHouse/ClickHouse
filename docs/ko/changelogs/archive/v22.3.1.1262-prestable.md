<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* toDatetime 함수의 오버플로우 동작을 개선했습니다. 날짜 문자열이 매우 큰 경우 1970으로 변환됩니다. [#32898](https://github.com/ClickHouse/ClickHouse/pull/32898) ([HaiBo Li](https://github.com/marising)).
* arrayCompact가 다른 고차 함수처럼 동작하도록 변경했습니다. 즉, 람다 함수 결과가 아니라 원본 배열에 대해 compaction을 수행합니다. arrayCompact에서 단순하지 않은 람다 함수를 사용 중인 경우 arrayCompact의 인수를 arrayMap으로 감싸면 이전 동작을 복원할 수 있습니다. 다음 issue를 해결합니다: [#34010](https://github.com/ClickHouse/ClickHouse/issues/34010) [#18535](https://github.com/ClickHouse/ClickHouse/issues/18535) [#14778](https://github.com/ClickHouse/ClickHouse/issues/14778). [#34795](https://github.com/ClickHouse/ClickHouse/pull/34795) ([Alexandre Snarskii](https://github.com/snar)).



<div id="new-feature">
  #### 새 기능
</div>

* 반정형 데이터(현재는 JSON만 지원) 저장을 지원하는 새로운 데이터 타입 `Object(<schema_format>)`이 추가되었습니다. 데이터는 문자열로 해당 타입에 기록되며, 이후 반정형 데이터의 포맷에 따라 모든 경로가 추출되어 해당 값을 저장하기에 가장 적합한 타입의 별도 컬럼에 기록됩니다. 이 컬럼들은 원본 데이터의 경로와 일치하는 이름으로 조회할 수 있습니다. 예: `data.key1.key2` 또는 캐스트 연산자 사용 시 `data.key1.key2::Int64`. [#23932](https://github.com/ClickHouse/ClickHouse/pull/23932) ([Anton Popov](https://github.com/CurtizJ)).
* SSL로 연결된 사용자의 X.509 인증서를 통한 인증을 지원합니다. [#31484](https://github.com/ClickHouse/ClickHouse/pull/31484) ([eungenue](https://github.com/eungenue)).
* 관련 이슈: [#30715](https://github.com/ClickHouse/ClickHouse/issues/30715). 맵(Map) 타입을 위한 세 가지 함수가 추가되었습니다: 1. mapReplace(map1, map2) - map1의 키 값을 map2의 대응하는 키 값으로 대체하고, map1에 없는 map2의 키를 추가합니다. 2. mapFilter 3. mapMap. mapFilter와 mapMap은 고차 함수로, 두 개의 인수를 받습니다. 첫 번째 인수는 k, v 쌍을 갖는 람다 함수이고, 두 번째 인수는 맵(Map) 타입 컬럼입니다. [#33698](https://github.com/ClickHouse/ClickHouse/pull/33698) ([hexiaoting](https://github.com/hexiaoting)).
* S3 디스크에 대한 로컬 캐시가 추가되었습니다. [#28961](https://github.com/ClickHouse/ClickHouse/issues/28961) 해결. [#33717](https://github.com/ClickHouse/ClickHouse/pull/33717) ([Kseniia Sumarokova](https://github.com/kssenii)).
* * 배열에 대한 startsWith 및 endsWith 함수가 추가되었습니다. [#33982](https://github.com/ClickHouse/ClickHouse/issues/33982) 해결. [#34368](https://github.com/ClickHouse/ClickHouse/pull/34368) ([usurai](https://github.com/usurai)).
* Arrow 컬럼과 DateTime64 간의 상호 변환이 구현되었습니다. [#8280](https://github.com/ClickHouse/ClickHouse/issues/8280) 및 [#28574](https://github.com/ClickHouse/ClickHouse/issues/28574) 해결. [#34561](https://github.com/ClickHouse/ClickHouse/pull/34561) ([李扬](https://github.com/taiyang-li)).
* clickhouse-local에 CPU/메모리 메트릭이 추가되었습니다. [#34545](https://github.com/ClickHouse/ClickHouse/issues/34545) 해결. [#34605](https://github.com/ClickHouse/ClickHouse/pull/34605) ([李扬](https://github.com/taiyang-li)).
* 테이블 함수 file/hdfs/s3/url에 데이터를 삽입할 때 스키마 추론을 지원합니다. [#34732](https://github.com/ClickHouse/ClickHouse/pull/34732) ([Kruglov Pavel](https://github.com/Avogar)).
* 서버 구성에 `<allow_plaintext_password>` 및 `<allow_no_password>` 설정이 새로 추가되었습니다. 이 설정은 보안에 취약한 AUTH&#95;TYPE인 plaintext-password 및 no&#95;password를 활성화하거나 비활성화합니다. 기본값은 true로, authType Plaintext&#95;password 및 NO&#95;password가 허용됩니다. [#34738](https://github.com/ClickHouse/ClickHouse/pull/34738) ([Heena Bansal](https://github.com/HeenaBansal2009)).
* 새로운 테이블 함수 `hive`가 추가되었습니다. 사용법은 다음과 같습니다: `hive('<hive metastore url>', '<hive database>', '<hive table name>', '<columns definition>', '<partition columns>')` 예시: ``SELECT * FROM hive('thrift://hivetest:9083', 'test', 'demo', '`id` Nullable(String), `score` Nullable(Int32), `day` Nullable(String)', 'day')``. [#34946](https://github.com/ClickHouse/ClickHouse/pull/34946) ([lgbo](https://github.com/lgbo-ustc)).

* Play UI의 테마 선택 우선순위가 다음과 같이 변경되었습니다: * &#39;theme&#39; GET 매개변수 * localStorage의 &#39;theme&#39; * OS 설정에 따름 (이전에는 동작하지 않았음). [#35068](https://github.com/ClickHouse/ClickHouse/pull/35068) ([peledni](https://github.com/peledni)).

<div id="performance-improvement">
  #### 성능 개선
</div>

* 큰 리스트에서 `std::distance`를 호출하면 성능이 저하되므로, 더 많은 메모리를 사용하는 대신 Node에 버전을 두는 방식으로 대체했습니다(노드 1000만 개당 80MB). 로직은 다음과 같습니다. 리스트의 각 노드는 `size_t` 타입의 버전을 가지며, `insert` 또는 `insertOrReplace` 메서드에서 클래스 멤버 변수 `current_version`을 사용해 설정합니다. 버전은 `enableSnapshot` 메서드에서만 증가합니다. 스냅샷을 수행할 때는 `snapshotSizeWithVersion`을 호출해 스냅샷 크기와 버전(`snapshot_up_to_version`)을 가져옵니다. 리스트를 순회할 때 노드 버전이 `snapshot_up_to_version`보다 작거나 같으면 삭제되지 않도록 보호하고, 노드 버전이 `snapshot_up_to_version`보다 크면 해당 노드에 대해서는 어떤 작업이든 수행할 수 있습니다. [#34486](https://github.com/ClickHouse/ClickHouse/pull/34486) ([zhanglistar](https://github.com/zhanglistar)).
* Nuraft의 로그 저장소 컴팩션은 일반적인 커밋 프로세스에서도 사용하는 내부 잠금을 획득해야 하므로, Changelog 클래스의 `compact` 메서드에서 불필요한 로그를 백그라운드 스레드로 삭제합니다. 자세한 내용은 다음을 참조하십시오: https://github.com/ClickHouse-Extras/NuRaft/blob/1707a7572aa66ec5d0a2dbe2bf5effa3352e6b2d/src/handle&#95;commit.cxx#L560. [#34534](https://github.com/ClickHouse/ClickHouse/pull/34534) ([zhanglistar](https://github.com/zhanglistar)).
* 최신 스냅샷을 메모리에 유지하지 않고, 필요할 때 스냅샷을 읽도록 변경했습니다. 순차 읽기는 `mmap` 시스템 호출을 사용하면 HDD에서도 200MBps 이상의 속도로 빠르게 수행됩니다. 또한 원본 데이터와 압축된 데이터를 메모리에 유지하지 않고, 압축 방식을 사용해 스냅샷 데이터를 직접 디스크에 기록합니다. [#34584](https://github.com/ClickHouse/ClickHouse/pull/34584) ([zhanglistar](https://github.com/zhanglistar)).
* `std::stable_sort`를 `pdqsort`로 대체해 MergeTree의 삽입 성능을 개선했습니다. [#34750](https://github.com/ClickHouse/ClickHouse/pull/34750) ([Maksim Kita](https://github.com/kitaisreal)).
* batch 단위로 처리해 `ANY` 집계 함수의 성능을 개선했습니다. [#34760](https://github.com/ClickHouse/ClickHouse/pull/34760) ([Raúl Marín](https://github.com/Algunenano)).
* `detectCharset `, `detectLanguageUnknown ` 함수의 성능을 개선했습니다. 딕셔너리 소스가 `ClickHouse`인 경우 `DirectDictionary`의 성능을 개선했습니다. 큰 `IN` 구문이 포함된 쿼리 처리 성능을 개선했습니다. [#34888](https://github.com/ClickHouse/ClickHouse/pull/34888) ([Maksim Kita](https://github.com/kitaisreal)).
* atomic stat를 사용해 connection에서 사용하는 잠금을 줄였습니다. 이는 근사 통계값이라는 점에 유의하십시오. [#35010](https://github.com/ClickHouse/ClickHouse/pull/35010) ([zhanglistar](https://github.com/zhanglistar)).

[#32977](https://github.com/ClickHouse/ClickHouse/issues/32977)에서 언급됨. [#34487](https://github.com/ClickHouse/ClickHouse/pull/34487) ([zzsmdfj](https://github.com/zzsmdfj)).

* `encodeURLComponent`, `encodeURLFormComponent` 함수를 추가하였습니다. [#31092](https://github.com/ClickHouse/ClickHouse/issues/31092) 종료. [#34607](https://github.com/ClickHouse/ClickHouse/pull/34607) ([zzsmdfj](https://github.com/zzsmdfj)).
