<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 기본적으로 `async_load_databases`를 완전히 활성화합니다(`config.xml`을 업그레이드하지 않은 설치도 포함). [#74772](https://github.com/ClickHouse/ClickHouse/pull/74772) ([Azat Khuzhin](https://github.com/azat)).
* `JSONCompactEachRowWithProgress` 및 `JSONCompactStringsEachRowWithProgress` 포맷을 추가합니다. [#69989](https://github.com/ClickHouse/ClickHouse/issues/69989)의 후속 작업입니다. `JSONCompactWithNames` 및 `JSONCompactWithNamesAndTypes`는 더 이상 &quot;합계&quot;를 출력하지 않습니다. 이는 구현상의 실수였던 것으로 보입니다. [#75037](https://github.com/ClickHouse/ClickHouse/pull/75037) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* alter 명령 목록을 명확히 구분할 수 있도록 `format_alter_operations_with_parentheses`의 기본값을 true로 변경합니다(https://github.com/ClickHouse/ClickHouse/pull/59532 참조). 이 변경으로 인해 24.3 이전 클러스터와의 복제가 중단됩니다. 이전 릴리스를 사용하는 클러스터를 업그레이드하는 경우 서버 구성에서 이 설정을 끄거나 먼저 24.3으로 업그레이드하십시오. [#75302](https://github.com/ClickHouse/ClickHouse/pull/75302) ([Raúl Marín](https://github.com/Algunenano)).
* 캐시 구성의 설정을 검증합니다. 이전에는 존재하지 않는 설정이 무시되었지만, 이제는 오류를 발생시키므로 해당 설정을 제거해야 합니다. [#75452](https://github.com/ClickHouse/ClickHouse/pull/75452) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 정규식을 사용한 로그 메시지 필터링 기능을 제거합니다. 이 구현에서 데이터 레이스가 발생했기 때문에 제거해야 합니다. [#75577](https://github.com/ClickHouse/ClickHouse/pull/75577) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).



<div id="new-feature">
  #### 새 기능
</div>

* 동일한 쿼리에서 여러 grace JOIN의 총 메모리 사용량을 모니터링하고, `MEMORY_LIMIT_EXCEEDED`를 방지하기 위해 외부 스토리지로 스필을 적응적으로 트리거할 수 있는 새로운 설정 `enable_adaptive_memory_spill_scheduler`가 추가되었습니다. [#72728](https://github.com/ClickHouse/ClickHouse/pull/72728) ([lgbo](https://github.com/lgbo-ustc)).
* 두 문자열의 일부를 비교하는 새로운 문자열 비교 함수 `stringCompare`가 추가되었습니다. 예시: `SELECT stringCompare('Saxony', 'Anglo-Saxon', 0, 6, 5) AS result`는 &quot;문자열 &#39;Saxon&#39;과 &#39;Anglo-Saxon&#39;의 6바이트를 사전식 순서로 비교하되, 첫 번째 문자열은 오프셋 0부터, 두 번째 문자열은 오프셋 5부터 시작한다&quot;는 의미입니다. [#74070](https://github.com/ClickHouse/ClickHouse/pull/74070) ([lgbo](https://github.com/lgbo-ustc)).
* 완료되지 않은(백그라운드 프로세스에서 아직 구체화되지 않은) 뮤테이션을 제출 직후 `SELECT` 쿼리 실행 중 즉시 적용할 수 있는 기능이 추가되었습니다. 이 기능은 `apply_mutations_on_fly`를 설정해 활성화할 수 있습니다. [#74877](https://github.com/ClickHouse/ClickHouse/pull/74877) ([Anton Popov](https://github.com/CurtizJ)).
* `toStartOfInterval`의 DateTime 인수가 음수일 때 발생하던 일부 예기치 않은 사례를 수정했습니다. 이를 위해 `toStartOfIntervalAllowNegative`라는 새 함수를 구현했으며, 이 함수는 거의 동일하게 동작하지만 Date32/DateTime64만 반환합니다. [#74933](https://github.com/ClickHouse/ClickHouse/pull/74933) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 새로운 함수 `initialQueryStartTime`이 추가되었습니다. 이 함수는 현재 쿼리의 시작 시간을 반환합니다. 분산 쿼리에서는 모든 세그먼트에서 값이 동일합니다. [#75087](https://github.com/ClickHouse/ClickHouse/pull/75087) ([Roman Lomonosov](https://github.com/lomik)).
* 백업에서 테이블/데이터베이스를 즉시 ATTACH할 수 있는 새로운 데이터베이스 엔진 `DatabaseBackup`이 추가되었습니다. [#75725](https://github.com/ClickHouse/ClickHouse/pull/75725) ([Maksim Kita](https://github.com/kitaisreal)).
* 데이터베이스 레이어 없이 테이블을 ATTACH할 수 있는 기능이 추가되었습니다(UUID hack 회피). [#75788](https://github.com/ClickHouse/ClickHouse/pull/75788) ([Azat Khuzhin](https://github.com/azat)).
* 라이선스 문제로 v24.10에서 제거되었던 QPL 코덱을 복원했습니다. [#76021](https://github.com/ClickHouse/ClickHouse/pull/76021) ([Konstantin Bogdanov](https://github.com/thevar1able)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* `materialize ttl`에서 `ttl_only_drop_parts` 설정 적용을 다시 도입했습니다. TTL을 다시 계산하는 데 필요한 컬럼만 읽고, 파트를 빈 파트로 교체하는 방식으로 삭제합니다. [#72751](https://github.com/ClickHouse/ClickHouse/pull/72751) ([Andrey Zvonov](https://github.com/zvonand)).
* `LowCardinality` 컬럼의 메모리 내 크기 계산을 수정했습니다. [#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)).
* S3의 Wide 파트에서 전체 JSON 컬럼 읽기 성능을 개선했습니다. 서브컬럼 프리픽스 역직렬화를 위한 프리페치, 역직렬화된 프리픽스 캐시, 서브컬럼 프리픽스의 병렬 역직렬화를 추가하여 구현했습니다. `SELECT data FROM table`과 같은 쿼리에서는 S3에서 JSON 컬럼 읽기 속도가 4배, `SELECT data FROM table LIMIT 10`과 같은 쿼리에서는 약 10배 향상됩니다. [#74827](https://github.com/ClickHouse/ClickHouse/pull/74827) ([Pavel Kruglov](https://github.com/Avogar)).
* 옵티마이저가 join 양측을 스왑하는 경우 `ConcurrentHashJoin`의 이중 사전 할당 문제를 수정했습니다. [#75149](https://github.com/ClickHouse/ClickHouse/pull/75149) ([Nikita Taranov](https://github.com/nickitat)).
* `max_rows_in_join = max_bytes_in_join = 0`일 때 `parallel_hash`에서 발생하던 불필요한 경합을 수정했습니다. [#75155](https://github.com/ClickHouse/ClickHouse/pull/75155) ([Nikita Taranov](https://github.com/nickitat)).
* 일부 join 시나리오에서 성능을 소폭 개선했습니다. 출력 행 수를 미리 계산하고, 이를 위한 메모리를 미리 확보합니다. [#75376](https://github.com/ClickHouse/ClickHouse/pull/75376) ([Alexander Gololobov](https://github.com/davenger)).
* `plain_rewritable` 메타데이터 파일은 작아서 큰 기본 버퍼가 필요하지 않습니다. 주어진 경로에 맞는 크기의 쓰기 버퍼를 사용해 많은 활성 파트가 있을 때 메모리 활용도를 개선했습니다. ### 사용자 대상 변경 사항에 대한 문서 항목입니다. [#75758](https://github.com/ClickHouse/ClickHouse/pull/75758) ([Julia Kartseva](https://github.com/jkartseva)).
* 동시성 제어가 INSERT와 SELECT 사이에서 CPU를 불공정하게 배분할 수 있음이 확인되었습니다. 경쟁이 없는 상황에서는 모든 CPU 슬롯이 `max_threads` = 1인 INSERT에 무조건 할당되어, `max_threads` 값이 큰 SELECT도 단일 스레드만 사용하게 되어 성능이 저하될 수 있습니다. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).
* [#76849](https://github.com/ClickHouse/ClickHouse/issues/76849)에 백포트되었습니다: 파트 제거 시 캐시에서 데이터를 적극적으로 축출합니다. 데이터 양이 더 적을 경우 캐시가 최대 크기까지 커지지 않도록 합니다. [#76641](https://github.com/ClickHouse/ClickHouse/pull/76641) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* 메모리 사용량을 줄이기 위해 블록을 가능한 한 빨리 해제합니다. [#65647](https://github.com/ClickHouse/ClickHouse/pull/65647) ([lgbo](https://github.com/lgbo-ustc)).
* `processors_profile_log` 테이블에 TTL 30일의 기본 구성이 적용되었습니다. [#66139](https://github.com/ClickHouse/ClickHouse/pull/66139) ([Ilya Yatsishin](https://github.com/qoega)).
* S3 요청의 첫 번째 바이트 읽기/쓰기 및 연결 시간을 추적하기 위한 지연 시간 버킷을 도입하였습니다. 수집된 데이터를 활용하여 근사 백분위수를 계산하고 타임아웃을 조정하는 데 활용할 수 있습니다. [#69783](https://github.com/ClickHouse/ClickHouse/pull/69783) ([Alexey Katsman](https://github.com/alexkats)).
* `Executable` 스토리지에 전달되는 쿼리가 더 이상 단일 스레드 실행으로 제한되지 않습니다. [#70084](https://github.com/ClickHouse/ClickHouse/pull/70084) ([yawnt](https://github.com/yawnt)).
* Parquet 블룸 필터와 min/max 인덱스를 함께 평가합니다. 데이터가 [1, 2, 4, 5]일 때 `x = 3 or x > 5`와 같은 조건을 올바르게 지원하기 위해 필요합니다. [#71383](https://github.com/ClickHouse/ClickHouse/pull/71383) ([Arthur Passos](https://github.com/arthurpassos)).
* 클러스터 구성에서 샤드 이름 지정을 허용합니다. [#72276](https://github.com/ClickHouse/ClickHouse/pull/72276) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* `a<b and b<c and c<5`와 같은 쿼리에서 필터 성능 향상을 위해 새로운 비교 조건(a<5 and b<5)을 자동으로 생성합니다. [#73164](https://github.com/ClickHouse/ClickHouse/pull/73164) ([Shichao Jin](https://github.com/jsc0218)).
* `Nullable(JSON)` 유형을 지원합니다. [#73556](https://github.com/ClickHouse/ClickHouse/pull/73556) ([Pavel Kruglov](https://github.com/Avogar)).
* SQLite의 유형 매핑을 수정합니다(정수 유형은 `int64`로, 부동소수점은 `float64`로). [#73853](https://github.com/ClickHouse/ClickHouse/pull/73853) ([Joanna Hulboj](https://github.com/jh0x)).
* Prometheus remote write 응답 성공 상태를 200/OK에서 204/NoContent로 변경합니다. [#74170](https://github.com/ClickHouse/ClickHouse/pull/74170) ([Michael Dempsey](https://github.com/bluestealth)).
* 서버를 재시작하지 않고 `max_remote_read_network_bandwidth_for_serve` 및 `max_remote_write_network_bandwidth_for_server`를 실시간으로 재로드하는 기능을 추가합니다. [#74206](https://github.com/ClickHouse/ClickHouse/pull/74206) ([Kai Zhu](https://github.com/nauu)).
* 기본값 및 구체화된 표현식에서 서브컬럼을 지원합니다. [#74403](https://github.com/ClickHouse/ClickHouse/pull/74403) ([Pavel Kruglov](https://github.com/Avogar)).
* `dfs.client.use.datanode.hostname` libhdfs3 구성 옵션 지원을 추가하였습니다. [#74635](https://github.com/ClickHouse/ClickHouse/pull/74635) ([Mikhail Tiukavkin](https://github.com/freshertm)).
* Backup 생성 시 blob 경로를 사용하여 체크섬을 계산할 수 있도록 지원합니다. [#74729](https://github.com/ClickHouse/ClickHouse/pull/74729) ([Vitaly Baranov](https://github.com/vitlibar)).
* ALTER TABLE FETCH PARTITION에서 파티션 파트를 병렬로 가져옵니다(스레드 풀 크기는 `max_fetch_partition_thread_pool_size`로 제어됩니다). [#74978](https://github.com/ClickHouse/ClickHouse/pull/74978) ([Azat Khuzhin](https://github.com/azat)).
* `system.query_cache`에 쿼리 ID 컬럼을 추가하였습니다(이슈 [#68205](https://github.com/ClickHouse/ClickHouse/issues/68205)). [#74982](https://github.com/ClickHouse/ClickHouse/pull/74982) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).

* 데이터베이스 엔진 `Iceberg`에서 카탈로그 자격 증명 설정을 숨깁니다. [#74559](https://github.com/ClickHouse/ClickHouse/issues/74559) 해결. [#75080](https://github.com/ClickHouse/ClickHouse/pull/75080) ([Kseniia Sumarokova](https://github.com/kssenii)).

* 설정 `min_chunk_bytes_for_parallel_parsing`은 더 이상 0으로 설정할 수 없습니다. [#71110](https://github.com/ClickHouse/ClickHouse/issues/71110) 수정. [#75239](https://github.com/ClickHouse/ClickHouse/pull/75239) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

* `DatabaseIceberg`의 카탈로그 구성에서 `s3.endpoint`를 네이티브로 지원합니다. [#74558](https://github.com/ClickHouse/ClickHouse/issues/74558) 해결. [#75375](https://github.com/ClickHouse/ClickHouse/pull/75375) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `SYSTEM DROP REPLICA`를 실행하는 사용자에게 충분한 권한이 없을 경우 오류를 명시적으로 표시합니다. [#75377](https://github.com/ClickHouse/ClickHouse/pull/75377) ([Bharat Nallan](https://github.com/bharatnc)).
* 시스템 로그의 플러시 실패 횟수에 대한 ProfileEvent를 추가합니다. [#75466](https://github.com/ClickHouse/ClickHouse/pull/75466) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

[#75472](https://github.com/ClickHouse/ClickHouse/pull/75472) ([Vitaly Orlov](https://github.com/orloffv)).
