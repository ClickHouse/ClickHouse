<div id="clickhouse-release-v217104-stable-fixme-as-compared-to-v21797-stable">
  ### ClickHouse 릴리스 v21.7.10.4-안정, v21.7.9.7-안정 대비 FIXME
</div>

<div id="improvement">
  #### 개선 사항
</div>

* [#28898](https://github.com/ClickHouse/ClickHouse/issues/28898)에 백포트됨: 수직 병합에서 미리 정의된 &quot;rows&#95;sources&quot; 대신 실제 tmp 파일을 사용하도록 변경했습니다. 이렇게 하면 tmp 디스크에 불필요한 디렉터리가 생성되는 것을 방지할 수 있습니다. [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix">
  #### 오동작
</div>

* [#27925](https://github.com/ClickHouse/ClickHouse/issues/27925)에 백포트됨: 음수에서 PostgreSQL 스타일 CAST(`::` 연산자)가 올바르게 처리되지 않던 문제를 수정. [#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* [#28752](https://github.com/ClickHouse/ClickHouse/issues/28752)에 백포트됨: 설정 `legacy_column_name_of_tuple_literal = 0`인 분산 쿼리에서, 설정 `optimize_min_equality_disjunction_chain_length`로 제어되는 논리합 체인의 `IN` 변환을 수정. [#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)
</div>

* [#28509](https://github.com/ClickHouse/ClickHouse/issues/28509)에 백포트됨: 분산 DDL 큐를 백그라운드에서 처리하는 동안 발생할 수 있는 ZooKeeper watch 누수를 수정했습니다. [#26036](https://github.com/ClickHouse/ClickHouse/issues/26036) 해결. [#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#28570](https://github.com/ClickHouse/ClickHouse/issues/28570)에 백포트됨: `ReplicatedVersionedCollapsingMergeTree`를 ALTER한 뒤 `Existing table metadata in ZooKeeper differs in sorting key expression.` 오류가 발생할 수 있는 버그를 수정했습니다. [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515) 수정. [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* [#28598](https://github.com/ClickHouse/ClickHouse/issues/28598)에 백포트됨: `Nested` 컬럼이 있고, 이름에 점이 포함되며 `Nested`와 동일한 접두사를 갖는 스칼라 컬럼이 있는 테이블에서 SELECT할 때 발생하는 `There is no subcolumn` 오류를 수정했습니다(예: `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`). [#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* [#28742](https://github.com/ClickHouse/ClickHouse/issues/28742)에 백포트됨: 전달된 매개변수가 잘못되었을 때 분산 테이블 생성 중 발생하는 코어 덤프를 수정했습니다. [#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* [#28788](https://github.com/ClickHouse/ClickHouse/issues/28788)에 백포트됨: ReplicatedMergeTreeQueue의 경미한 race condition을 수정했습니다. 사용자에게 직접 드러나지는 않지만, 미묘한 버그로 이어질 수 있습니다. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* [#28947](https://github.com/ClickHouse/ClickHouse/issues/28947)에 백포트됨: compact 파트에서 서브컬럼을 읽는 문제를 수정했습니다. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* [#28931](https://github.com/ClickHouse/ClickHouse/issues/28931)에 백포트됨: 상수와 함께 사용할 때 고차 배열 함수에서 발생하는 문제를 수정했습니다(`arrayCompact`에서 `SIGSEGV`, `arrayDifference`/`arrayCumSumNonNegative`에서 `ILLEGAL_COLUMN`). [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
