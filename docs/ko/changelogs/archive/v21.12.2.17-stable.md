#### 오동작 (공식 안정 릴리스에서 사용자에게 드러나는 오작동)

* [#32681](https://github.com/ClickHouse/ClickHouse/issues/32681)에 백포트됨: 파트를 detach할 때 프로젝션이 예기치 않게 제거되는 문제를 수정했습니다. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* [#32483](https://github.com/ClickHouse/ClickHouse/issues/32483)에 백포트됨: 클라이언트/서버 크래시로 이어질 수 있던 &#39;APPLY lambda&#39; 파싱 문제를 수정했습니다. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32542](https://github.com/ClickHouse/ClickHouse/issues/32542)에 백포트됨: 일부 복제 큐 항목이 `temporary_directories_lifetime`(기본값 1일) 동안 `Directory tmp_merge_<part_name>` 또는 `Part ... (state Deleting) already exists, but it will be deleted soon` 같은 오류와 함께 멈춰 있을 수 있었습니다. 이 문제를 수정했습니다. [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)을 해결합니다. [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32710](https://github.com/ClickHouse/ClickHouse/issues/32710)에 백포트됨: 아직 구체화되지 않은 스킵 인덱스를 사용하려는 쿼리에서 발생하던 실패를 수정했습니다. [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) 및 [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343)을 해결합니다. [#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* [#32569](https://github.com/ClickHouse/ClickHouse/issues/32569)에 백포트됨: `JoinCommon::removeColumnNullability`의 크래시를 수정하고, [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458)를 종료했습니다. [#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* [#32770](https://github.com/ClickHouse/ClickHouse/issues/32770)에 백포트됨: 순차 키에서 sparse&#95;hashed dict의 성능 문제(잘못된 hash function)를 수정했습니다. [#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* [#32634](https://github.com/ClickHouse/ClickHouse/issues/32634)에 백포트됨: DROP TABLE과 INSERT가 병렬로 수행될 때의 table lifetime 문제(즉, use-after-free 가능성)를 수정했습니다. [#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* [#32632](https://github.com/ClickHouse/ClickHouse/issues/32632)에 백포트됨: channel 생성을 지연시켜 RabbitMQ storage 시작 시 발생할 수 있는 Exception을 수정했습니다. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32733](https://github.com/ClickHouse/ClickHouse/issues/32733)에 백포트됨: 함수 `file`의 매우 좋지 않은 코드를 수정했습니다. [#32640](https://github.com/ClickHouse/ClickHouse/pull/32640) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#32793](https://github.com/ClickHouse/ClickHouse/issues/32793)에 백포트됨: 동일한 FixedString에 fuzzBits를 여러 번 사용했을 때 발생하는 크래시를 수정하고, [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)를 종료했습니다. [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
