<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* 이제 ClickHouse Keeper 스냅샷은 사용자 정의 ClickHouse LZ4 블록 압축 대신 기본적으로 `ZSTD` 코덱으로 압축됩니다. 이 동작은 `compress_snapshots_with_zstd_format` coordination 설정으로 비활성화할 수 있습니다(모든 quorum 레플리카에서 동일한 값이어야 합니다). 하위 호환되지 않는 경우는 매우 드물며, 새 node가 스냅샷을 이전 node로 전송할 때만 발생할 수 있습니다(recovery 시 발생). 이 경우 이전 node는 ZSTD 포맷의 스냅샷을 읽을 수 없습니다. [#29417](https://github.com/ClickHouse/ClickHouse/pull/29417) ([alesapin](https://github.com/alesapin)).
* Function `bayesAB`가 제거되었습니다. 이로써 [#26233](https://github.com/ClickHouse/ClickHouse/issues/26233)이 해결되었습니다. [#29934](https://github.com/ClickHouse/ClickHouse/pull/29934) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree 테이블 설정 `write_final_mark`가 제거되었습니다. 이 값은 항상 `true`입니다. [#30455](https://github.com/ClickHouse/ClickHouse/pull/30455) ([Kseniia Sumarokova](https://github.com/kssenii)).
* SQL JSON 함수에서 json&#95;path와 json의 순서가 변경되었습니다(올바른 순서로 수정). 이로써 [#30449](https://github.com/ClickHouse/ClickHouse/issues/30449)가 해결되었습니다. [#30474](https://github.com/ClickHouse/ClickHouse/pull/30474) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 더 이상 사용되지 않으므로 설정 `odbc_max_field_size`가 제거되었습니다. 이로써 [#30413](https://github.com/ClickHouse/ClickHouse/issues/30413)가 해결되었습니다. [#30778](https://github.com/ClickHouse/ClickHouse/pull/30778) ([Kseniia Sumarokova](https://github.com/kssenii)).

* system.tables에 `table` alias를, system.databases에 `database` alias를 추가했습니다. [#29677](https://github.com/ClickHouse/ClickHouse/issues/29677). [#29882](https://github.com/ClickHouse/ClickHouse/pull/29882) ([kevin wan](https://github.com/MaxWk)).

[#29697](https://github.com/ClickHouse/ClickHouse/issues/29697)가 해결되었습니다. [#29896](https://github.com/ClickHouse/ClickHouse/pull/29896) ([Maksim Kita](https://github.com/kitaisreal)).

* FreeBSD aarch64를 지원합니다. [#29952](https://github.com/ClickHouse/ClickHouse/pull/29952) ([MikaelUrankar](https://github.com/MikaelUrankar)).
* `tokens` 함수를 추가했습니다. 이 함수는 영숫자가 아닌 ASCII 문자를 구분자로 사용해 문자열을 tokens으로 분할할 수 있습니다. [#29981](https://github.com/ClickHouse/ClickHouse/pull/29981) ([Maksim Kita](https://github.com/kitaisreal)).
* 새로운 JSONExtractKeys 함수를 추가했습니다 ... [#30056](https://github.com/ClickHouse/ClickHouse/pull/30056) ([Vitaly Orlov](https://github.com/orloffv)).
* `HashedArray` 딕셔너리 유형을 추가했습니다. [#30236](https://github.com/ClickHouse/ClickHouse/issues/30236)가 해결되었습니다. [#30242](https://github.com/ClickHouse/ClickHouse/pull/30242) ([Maksim Kita](https://github.com/kitaisreal)).
* ClickHouse Keeper의 노드 구성(`.xml` 파일)을 변경할 수 있는 기능을 추가했습니다. [#30372](https://github.com/ClickHouse/ClickHouse/pull/30372) ([alesapin](https://github.com/alesapin)).
* `compiled_expression_cache_elements_size` 설정을 사용해 CompiledExpressionCache 요소 크기를 제한합니다. [#30667](https://github.com/ClickHouse/ClickHouse/pull/30667) ([Maksim Kita](https://github.com/kitaisreal)).
* 지정된 pattern과 일치하는 요소만 남긴 맵을 가져오는 새 함수 `mapExtractKeyLike`를 추가했습니다. [#30793](https://github.com/ClickHouse/ClickHouse/pull/30793) ([凌涛](https://github.com/lingtaolf)).
* `Memory` 데이터베이스의 테이블에 대해 `ALTER TABLE`을 지원합니다. [#30866](https://github.com/ClickHouse/ClickHouse/pull/30866) ([Alexander Tokmakov](https://github.com/tavplubix)).



<div id="performance-improvement">
  #### 성능 개선
</div>

* * 더 높은 성능을 제공하는 `popcnt/ctz` 기반의 개선된 구현을 사용해 필터 연산의 분기 위주 코드를 제거했습니다. [#29881](https://github.com/ClickHouse/ClickHouse/pull/29881) ([Jun Jin](https://github.com/vesslanjin)).
* * X86&#95;64 기능을 활용하기 위해 AVX2/AVX512 명령어를 사용해 필터 연산을 가속화했습니다. [#30014](https://github.com/ClickHouse/ClickHouse/pull/30014) ([jasperzhu](https://github.com/jinjunzh)).
* 활성화된 설정 `optimize_aggregation_in_order`에서 프라이머리 키(primary key) 순서 집계의 성능을 개선했습니다. [#30266](https://github.com/ClickHouse/ClickHouse/pull/30266) ([Anton Popov](https://github.com/CurtizJ)).
* ColumnDecimal의 필터 연산 성능을 개선했습니다. [#30431](https://github.com/ClickHouse/ClickHouse/pull/30431) ([Jun Jin](https://github.com/vesslanjin)).
* Dictionaries에서 여러 스레드를 통한 읽기를 지원합니다. [#30500](https://github.com/ClickHouse/ClickHouse/pull/30500) ([Maksim Kita](https://github.com/kitaisreal)).
* * SSE/AVX2/AVX512 명령어를 사용해 올인원 필터 비트마스크 생성 함수의 성능을 개선했습니다. [#30670](https://github.com/ClickHouse/ClickHouse/pull/30670) ([jasperzhu](https://github.com/jinjunzh)).
* `clickhouse-client`에서 `INTO OUTFILE`을 사용하는 쿼리는 여러 스레드를 사용합니다. `INTO OUTFILE` 사용 시 진행률 표시줄이 깜빡이는 문제를 수정했습니다. 이로써 [#30873](https://github.com/ClickHouse/ClickHouse/issues/30873)이 해결됩니다. 이로써 [#30872](https://github.com/ClickHouse/ClickHouse/issues/30872)가 해결됩니다. [#30886](https://github.com/ClickHouse/ClickHouse/pull/30886) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="improvement">
  #### 개선 사항
</div>

* 쿼리에서 숫자를 바이너리 리터럴로 작성할 수 있도록 지원합니다. 예시: `SELECT 0b001;`. [#29304](https://github.com/ClickHouse/ClickHouse/pull/29304) ([Maksim Kita](https://github.com/kitaisreal)).
* `clickhouse-benchmark`에 원본 쿼리&#95;id를 전달합니다(이전에는 `clickhouse-benchmark`를 통해 원격 쿼리를 실행하면 각 세그먼트의 쿼리가 `initial_query_id`를 통해 원본 쿼리와 연결되지 않았습니다). [#29364](https://github.com/ClickHouse/ClickHouse/pull/29364) ([Azat Khuzhin](https://github.com/azat)).
* freeze 시 메모리에 있던 part가 손실되는 문제를 수정했습니다. [#29376](https://github.com/ClickHouse/ClickHouse/pull/29376) ([Mo Xuan](https://github.com/mo-avatar)).
* `use_skip_indexes` 설정을 추가했습니다. [#29405](https://github.com/ClickHouse/ClickHouse/pull/29405) ([Maksim Kita](https://github.com/kitaisreal)).
* 런타임 중 `max_concurrent_queries`에 대한 구성 변경 사항을 적용합니다(재시작할 필요 없음). [#29414](https://github.com/ClickHouse/ClickHouse/pull/29414) ([Raúl Marín](https://github.com/Algunenano)).
* `isNull`/`isNotNull`을 `IS NULL`/`IS NOT NULL`로 변환합니다(외부 DB, 예: MySQL). [#29446](https://github.com/ClickHouse/ClickHouse/pull/29446) ([Azat Khuzhin](https://github.com/azat)).
* 쿼리별 메모리 프로파일러를 전역으로 활성화했습니다(`memory&#95;profiler&#95;step=4MiB`로 설정). [#29455](https://github.com/ClickHouse/ClickHouse/pull/29455) ([Azat Khuzhin](https://github.com/azat)).
* 외부 DB(예: MySQL)에 대해 `IS NULL`/`IS NOT NULL` 지원을 추가했습니다. [#29463](https://github.com/ClickHouse/ClickHouse/pull/29463) ([Azat Khuzhin](https://github.com/azat)).
* 중첩된 서브쿼리가 있는 뮤테이션에서 발생하던 `There is no query or query context has expired` 오류를 수정했습니다. 테이블이 복제된 상태이고 `allow_nondeterministic_mutations` 설정이 비활성화되어 있으면 뮤테이션에서 서브쿼리를 허용하지 않습니다. [#29495](https://github.com/ClickHouse/ClickHouse/pull/29495) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 프로젝션 이름에 대한 불필요한 제한을 제거했습니다. 이제 프로젝션 이름은 `tmp_`로 시작할 수 있습니다. [#29520](https://github.com/ClickHouse/ClickHouse/pull/29520) ([Amos Bird](https://github.com/amosbird)).
