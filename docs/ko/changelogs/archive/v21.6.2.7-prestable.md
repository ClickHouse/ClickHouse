<div id="bug-fix">
  #### 오동작
</div>

* [#24567](https://github.com/ClickHouse/ClickHouse/issues/24567)에 백포트됨: 파티션 키에서 사용할 때 이전 `modulo` 함수 버전을 사용하도록 수정했습니다. [#23508](https://github.com/ClickHouse/ClickHouse/issues/23508)을 해결합니다. [#24157](https://github.com/ClickHouse/ClickHouse/pull/24157) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#24367](https://github.com/ClickHouse/ClickHouse/issues/24367)에 백포트됨: StorageMemory의 mutation 실패 문제를 해결하기 위해 `max_threads = 1`로 설정했습니다. [#24274](https://github.com/ClickHouse/ClickHouse/issues/24274)을 해결합니다. [#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)).
* [#24383](https://github.com/ClickHouse/ClickHouse/issues/24383)에 백포트됨: 빈 HTTP 헤더를 허용합니다. [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901)을 해결합니다. [#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* [#24365](https://github.com/ClickHouse/ClickHouse/issues/24365)에 백포트됨: Ordinary 데이터베이스에서 Atomic 데이터베이스로 구체화된 뷰(Materialized View)를 이동할 때(`RENAME TABLE` 쿼리) 발생하던 버그를 수정했습니다. 이제 내부 테이블도 구체화된 뷰(Materialized View)와 함께 새 데이터베이스로 이동됩니다. [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926)을 해결합니다. [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24510](https://github.com/ClickHouse/ClickHouse/issues/24510)에 백포트됨: intersect fake 파트가 있을 때 발생하는 파티션 삭제 문제를 수정했습니다. 드문 경우 현재 블록 번호보다 큰 mutation 버전을 가진 파트가 있을 수 있습니다. [#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* [#24542](https://github.com/ClickHouse/ClickHouse/issues/24542)에 백포트됨: toWeek 함수의 잘못된 단조성을 수정했습니다. 이 수정으로 [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422)가 해결됩니다. 이 버그는 [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212)에서 도입되었으며, 이후 더 정교한 파티션 프루너로 인해 드러났습니다. [#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* [#24556](https://github.com/ClickHouse/ClickHouse/issues/24556)에 백포트됨: `SYSTEM RESTART REPLICA` 또는 `SYSTEM SYNC REPLICA` 쿼리가 무한히 처리되는 문제를 수정했습니다. 이 문제는 RAM이 극히 적은 서버에서 발견되었습니다. [#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#24597](https://github.com/ClickHouse/ClickHouse/issues/24597)에 백포트됨: `CREATE .. AS SELECT` 쿼리에서 튜플 사용 문제를 수정했습니다. [#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)).
* [#24600](https://github.com/ClickHouse/ClickHouse/issues/24600)에 백포트됨: 분산 테이블에서 서브컬럼 읽기를 지원합니다. [#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
