<div id="improvement">
  #### 개선 사항
</div>

* [#46914](https://github.com/ClickHouse/ClickHouse/issues/46914)에 백포트됨: 컬럼의 DEFAULT 표현식이 서로 다른 경우에도 Merge에서 PREWHERE를 허용합니다. [#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* [#47022](https://github.com/ClickHouse/ClickHouse/issues/47022)에 백포트됨: `range()`에서 IPv4를 허용합니다. [#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

<div id="bug-fix">
  #### 오동작
</div>

* [#46828](https://github.com/ClickHouse/ClickHouse/issues/46828)에 백포트됨: 일부 경우 여러 PREWHERE에서 누적된 결합 PREWHERE 컬럼에 이전 단계의 0값이 포함되지 않았습니다. 이에 대한 수정으로, 마지막 단계가 아닌 2개 이상의 단계에서 해당 필터가 적용되지 않았음이 확인된 경우 최종 필터를 적용하도록 했습니다. [#46785](https://github.com/ClickHouse/ClickHouse/pull/46785) ([Alexander Gololobov](https://github.com/davenger)).

<div id="buildtestingpackaging-improvement">
  #### 빌드/테스트/패키징 개선 사항
</div>

* [#47062](https://github.com/ClickHouse/ClickHouse/issues/47062)에 백포트됨: 구형 배포판(예: Amazon Linux 2) 및 ARM 환경에서 glibc 2.28 심볼을 찾을 수 없어 server 시작 시 발생하던 오류를 수정했습니다. [#47008](https://github.com/ClickHouse/ClickHouse/pull/47008) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 오동작 (공식 안정 릴리스에서 사용자에게 보이는 오동작)
</div>

* [#46895](https://github.com/ClickHouse/ClickHouse/issues/46895)에 백포트됨: `ReplicatedMergeTree` 테이블과 `Atomic` 데이터베이스에서 `DROP TABLE` 쿼리를 자동 재시도하는 과정의 버그를 수정했습니다. 드물게는 DROP 도중 ZooKeeper session이 만료되고, 동시에 ZooKeeper에 동일한 경로를 사용하는 새로운 복제된 테이블이 병렬로 생성되면 `Can't get data for node /zk_path/log_pointer` 및 `The specified key does not exist` 오류가 발생할 수 있었습니다. [#46384](https://github.com/ClickHouse/ClickHouse/pull/46384) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#46865](https://github.com/ClickHouse/ClickHouse/issues/46865)에 백포트됨: `Map` 데이터 타입의 버그를 수정했습니다. 이로써 [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855)가 해결됩니다. [#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46958](https://github.com/ClickHouse/ClickHouse/issues/46958)에 백포트됨: substring 검색으로 변환되고, 따옴표로 감싼 non-LIKE 메타문자를 포함하는 LIKE 프레디케이트의 결과가 잘못되던 문제를 수정했습니다. [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
