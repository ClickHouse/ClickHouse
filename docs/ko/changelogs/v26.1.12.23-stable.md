  ### ClickHouse 릴리스 v26.1.12.23-안정 (e5aa07a1b9a) FIXME v26.1.11.9-안정 (1784404a5ac) 대비

<div id="backward-incompatible-change">
  #### 하위 호환되지 않는 변경 사항
</div>

* [#103351](https://github.com/ClickHouse/ClickHouse/issues/103351)에 백포트됨: HTTP 연결의 인증 전 메모리 사용량을 제한하기 위해 기본 `http_max_fields`를 1,000,000에서 1,000으로, `http_max_field_name_size`를 128 KB에서 4 KB로 낮췄습니다. `http_max_request_header_size` 및 `http_headers_read_timeout` 설정도 추가했습니다. 이전의 더 높은 제한값을 사용하던 사용자는 설정을 통해 이를 복원할 수 있습니다. [#103285](https://github.com/ClickHouse/ClickHouse/pull/103285) ([Sema Checherinda](https://github.com/CheSema)).

<div id="new-feature">
  #### 새 기능
</div>

* [#103501](https://github.com/ClickHouse/ClickHouse/issues/103501)에 백포트됨: S3 GET 요청의 연결 수명 주기와 사용된 바이트 수를 관찰할 수 있도록 `s3_read_request_duration_microseconds` 및 `s3_read_request_bytes` 히스토그램 메트릭을 추가했습니다. 이 메트릭은 `system.histogram_metrics`와 Prometheus 엔드포인트에서 확인할 수 있습니다. [#102058](https://github.com/ClickHouse/ClickHouse/pull/102058) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">

* [#103378](https://github.com/ClickHouse/ClickHouse/issues/103378)에 백포트됨: `max_network_bandwidth_for_user`/`max_network_bandwidth_for_all_users`를 원격 파일 시스템 읽기/쓰기 작업에 적용합니다. [#103080](https://github.com/ClickHouse/ClickHouse/pull/103080) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 버그 수정(공식 안정 릴리스에서 사용자에게 보이는 오작동)
</div>

* [#103374](https://github.com/ClickHouse/ClickHouse/issues/103374)에 백포트: 지연 실행 컬럼 복제(`enable_lazy_columns_replication`)로 생성된 `ColumnReplicated` 컬럼이 늦게 도착한 입력과 함께 머지 정렬 파이프라인으로 유입될 때, 머지 알고리즘에서 발생하던 크래시(`Logical error: isConst/isSparse/isReplicated assertTypeEquality`)를 수정했습니다. [#101036](https://github.com/ClickHouse/ClickHouse/pull/101036) ([Groene AI](https://github.com/groeneai)).
* [#103185](https://github.com/ClickHouse/ClickHouse/issues/103185)에 백포트: JSON 컬럼에 생성된 MinMax 인덱스에서 잘못된 극값을 사용해 잘못된 쿼리 결과가 반환되던 문제를 수정했습니다. [#101700](https://github.com/ClickHouse/ClickHouse/issues/101700)을 해결했습니다. [#101918](https://github.com/ClickHouse/ClickHouse/pull/101918) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103146](https://github.com/ClickHouse/ClickHouse/issues/103146)에 백포트: 여러 개의 동시 `CREATE TABLE IF NOT EXISTS` 쿼리가 Shared 데이터베이스의 동일한 `S3Queue` 테이블을 대상으로 할 때 발생하던 `LOGICAL_ERROR` 예외를 수정했습니다. [#102610](https://github.com/ClickHouse/ClickHouse/pull/102610) ([Nikita Taranov](https://github.com/nickitat)).
* [#103003](https://github.com/ClickHouse/ClickHouse/issues/103003)에 백포트: 구성에 정의된 정적 클러스터에 일시적으로 살아 있는 노드가 없을 때 ClusterDiscovery에서 발생하던 서버 예외를 수정했습니다. [#102661](https://github.com/ClickHouse/ClickHouse/pull/102661) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102970](https://github.com/ClickHouse/ClickHouse/issues/102970)에 백포트: 시간대 조정 후 오버플로우가 발생하는 경우의 잘못된 날짜 데이터 타입 추론을 수정했습니다. [#102601](https://github.com/ClickHouse/ClickHouse/issues/102601)을 해결했습니다. [#102674](https://github.com/ClickHouse/ClickHouse/pull/102674) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103302](https://github.com/ClickHouse/ClickHouse/issues/103302)에 백포트: 바이너리 인코딩된 데이터 타입에서 평탄화된 Dynamic 타입 직렬화를 수정했습니다. [#101911](https://github.com/ClickHouse/ClickHouse/issues/101911)을 해결했습니다. [#102692](https://github.com/ClickHouse/ClickHouse/pull/102692) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103493](https://github.com/ClickHouse/ClickHouse/issues/103493)에 백포트: socket 계층의 short write를 Poco `BufferedStreamBuf::flushBuffer`가 처리하지 못해, 재시도되어야 할 S3 요청이 대신 `ios_base::clear: unspecified iostream_category error`로 실패하던 문제를 수정했습니다. [#102894](https://github.com/ClickHouse/ClickHouse/pull/102894) ([Sema Checherinda](https://github.com/CheSema)).
* [#103224](https://github.com/ClickHouse/ClickHouse/issues/103224)에 백포트: 경량한 삭제 이후 `minmax_count_projection` 및 단순 `COUNT(*)` 최적화가, 경량한 삭제 마스크가 있는 모든 파트가 머지되어 사라진 뒤에도 영구적으로 비활성화되던 문제를 수정했습니다. [#102900](https://github.com/ClickHouse/ClickHouse/pull/102900) ([Anton Popov](https://github.com/CurtizJ)).
* [#103020](https://github.com/ClickHouse/ClickHouse/issues/103020)에 백포트: 새로운 분석기에서 row policy OR 체인을 IN으로 최적화했습니다. [#102915](https://github.com/ClickHouse/ClickHouse/pull/102915) ([Azat Khuzhin](https://github.com/azat)).
* [#103237](https://github.com/ClickHouse/ClickHouse/issues/103237)에 백포트: materialized view가 없는 일반 INSERT가 더 이상 과도한 ConcurrencyControl 슬롯과 스레드(`max_insert_threads` 대신 `max_threads`)를 요청하지 않도록 수정하여, INSERT 처리량이 높은 클러스터에서 CC 슬롯 고갈과 스레드 수 급증을 방지합니다. [#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).
* [#103326](https://github.com/ClickHouse/ClickHouse/issues/103326)에 백포트: `HMAC` SQL 함수에서 시크릿 키를 숨기도록 수정했습니다. [#102927](https://github.com/ClickHouse/ClickHouse/issues/102927)을 수정했습니다. [#102997](https://github.com/ClickHouse/ClickHouse/pull/102997) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#103201](https://github.com/ClickHouse/ClickHouse/issues/103201)에 백포트: 커널 OOM을 방지하기 위해 `MEMORY_LIMIT_EXCEEDED` 예외를 발생시킬 수 있도록 ArrowMemoryPool을 다시 도입했습니다. [#102999](https://github.com/ClickHouse/ClickHouse/pull/102999) ([Azat Khuzhin](https://github.com/azat)).
* [#103359](https://github.com/ClickHouse/ClickHouse/issues/103359)에 백포트: 인증 전 TCP Hello 패킷 문자열을 64 KB로 제한하고 전체 핸드셰이크 시간을 제한하는 `handshake_timeout_milliseconds` 서버 설정을 추가하여, 인증되지 않은 클라이언트가 과도한 메모리를 소비하거나 스레드를 무기한 점유하지 못하도록 했습니다. [#103284](https://github.com/ClickHouse/ClickHouse/pull/103284) ([Sema Checherinda](https://github.com/CheSema)).

* [#103635](https://github.com/ClickHouse/ClickHouse/issues/103635)에 백포트: `url` 테이블 함수에서 `_time` 컬럼을 채우도록 수정했습니다. [#103437](https://github.com/ClickHouse/ClickHouse/pull/103437) ([Nikita Taranov](https://github.com/nickitat)).
