ClickHouse Observability — 자가 관리형은 전적으로 **ClickHouse Cloud** 내에서 실행되며, 동일한 ClickStack 데이터 모델과 사용자 경험을 그대로 유지하면서 완전 관리형 관측성 백엔드를 제공합니다.

이 모델에서는 ClickHouse Cloud가 **ClickHouse와 ClickStack UI**의 호스팅, 운영 및 보안을 담당합니다. 사용자는 관리형 서비스로 텔레메트리 데이터를 전송하는 **OpenTelemetry(OTel) collector**만 실행하면 됩니다.

### ClickHouse Cloud: 엔진 {#clickhouse-cloud}

ClickHouse Observability — 자가 관리형의 핵심은 ClickHouse Cloud입니다. ClickHouse Cloud는 대규모 실시간 분석을 위해 설계된 컬럼 지향 데이터베이스인 ClickHouse의 서버리스 버전입니다. ClickHouse Cloud는 관측성 데이터의 수집과 쿼리를 담당하며, 다음과 같은 기능을 제공합니다.

* 테라바이트 규모의 이벤트를 대상으로 하는 sub-second 검색
* 하루 수십억 건에 달하는 high-cardinality 레코드 수집
* 관측성 데이터 기준 최소 10배 이상의 높은 압축률
* 반정형 JSON 데이터를 네이티브로 지원하여 동적 스키마 진화(Schema Evolution) 가능
* 수백 개의 내장 분석 함수(analytical functions)를 갖춘 강력한 SQL 엔진

ClickHouse Cloud는 관측성 데이터를 와이드 이벤트로 처리하므로, 하나의 통합 구조 안에서 로그, 메트릭, trace를 심층적으로 연관 분석할 수 있습니다.

또한 ClickHouse Cloud는 ClickHouse 오픈 소스의 기능 외에도 관측성 측면에서 다음과 같은 이점을 제공합니다.

* 저장소와 독립적인 컴퓨트 자동 확장
* 객체 스토리지 기반의 저비용, 사실상 무제한 보존 기간
* 웨어하우스(warehouse)를 활용한 [읽기 및 쓰기 워크로드(workloads)의 독립적 격리](/ko/clickstack/self-configured/managing/isolating-read-write)
* 통합 인증
* 자동 백업
* 보안 및 컴플라이언스 기능
* 중단 없는 업그레이드

### OpenTelemetry collector: 데이터 수집 {#open-telemetry-collector-managed}

ClickHouse Observability — 자가 관리형에는 개방적이고 표준화된 방식으로 텔레메트리를 수집할 수 있도록 미리 구성된 OpenTelemetry(OTel) collector가 포함되어 있습니다. 데이터는 다음 방식을 통해 OTLP 프로토콜로 전송할 수 있습니다.

* gRPC (포트 `4317`)
* HTTP (포트 `4318`)

collector는 텔레메트리를 효율적인 배치 단위로 묶어 ClickHouse Cloud로 내보냅니다. 또한 데이터 소스별로 최적화된 테이블 스키마(table schema)를 지원하여 모든 신호 유형에서 확장 가능한 성능을 보장합니다.

**아키텍처의 이 구성 요소는 사용자가 관리합니다**

### ClickStack UI: 인터페이스 {#hyperdx}

ClickStack UI는 ClickStack의 사용자 인터페이스로, 다음 기능을 제공합니다.

* 자연어 및 Lucene 스타일 검색
* 실시간 디버깅을 위한 라이브 테일링(Live tailing)
* 로그, 메트릭, trace 통합 뷰
* 프론트엔드 관측성을 위한 세션 리플레이
* 대시보드 생성 및 알림 구성
* 고급 분석을 위한 SQL 쿼리(SQL query) 인터페이스

ClickHouse 전용으로 설계된 ClickStack UI는 강력한 검색 기능과 직관적인 워크플로를 결합하여 이상 징후를 발견하고 이슈를 조사하며 인사이트를 빠르게 얻을 수 있도록 지원합니다.

ClickHouse Observability — 자가 관리형에서는 UI가 ClickHouse Cloud 콘솔 인증 시스템과 통합되어 있습니다.
