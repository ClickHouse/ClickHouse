이 가이드에서는 OpenTelemetry로 소규모 Node.js 애플리케이션을 계측하고, 이 애플리케이션의 로그, 메트릭, trace, 세션 다시 보기를 자체 관리형 ClickHouse Observability로 전송하는 과정을 안내합니다. 백엔드는 애플리케이션 소스 코드를 전혀 수정하지 않고 계측합니다.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)는 퍼블릭 ClickHouse 데모에 호스팅된 HackerNews 데이터셋을 쿼리하는 Node.js 앱입니다. 모든 차트, 테이블, 검색 상자가 실제 ClickHouse 쿼리(Query)로 동작하므로, 모든 상호작용마다 백엔드에서 ClickHouse로 나가는 HTTPS 호출을 주요 스팬으로 하는 트레이스가 생성됩니다.

이 가이드는 [OpenTelemetry Collector 설정](/ko/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)을 완료했고, 이 애플리케이션을 실행할 머신에서 연결할 수 있는 ClickStack 수집기가 실행 중이라고 가정합니다. **해당 수집기의 OTLP 엔드포인트와** 배포 시 설정한 `OTLP_AUTH_TOKEN`을 **반드시 기록해 두십시오**. 계측을 시작하기 전에 이 값들을 `.env`에 입력합니다.

## 사전 요구 사항 {#prerequisites}

* 이 머신에서 연결할 수 있는 ClickStack 수집기가 필요합니다. 아직 배포하지 않았다면 먼저 [OpenTelemetry Collector 설정](/ko/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) 가이드를 참고하십시오.
* 해당 collector의 OTLP/HTTP 엔드포인트(일반적으로 포트 `4318`)와 collector에 설정한 `OTLP_AUTH_TOKEN`이 필요합니다. 이 값을 각각 `OTEL_EXPORTER_OTLP_ENDPOINT`와 `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`에 지정하십시오.
* Node 18 이상과 npm이 필요합니다.

## 리포지토리 클론하기 {#clone-the-repository}

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)를 클론하고 의존성을 설치한 다음, env 템플릿 파일을 복사하십시오:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

이후 단계에서 `.env` 파일을 작성한 다음, 이 디렉터리에서 애플리케이션을 계측합니다.
