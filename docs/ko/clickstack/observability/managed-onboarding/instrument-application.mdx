이 가이드에서는 소규모 Node.js 애플리케이션을 OpenTelemetry로 계측하고, 해당 애플리케이션의 로그, 메트릭, 트레이스, 세션 다시 보기를 자체 관리형 ClickHouse Observability로 전송하는 과정을 안내합니다. 백엔드는 애플리케이션 소스 코드를 전혀 변경하지 않고 계측합니다.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)는 공개 ClickHouse 데모에 호스팅된 HackerNews 데이터셋을 쿼리하는 Node.js 앱입니다. 모든 차트, 테이블, 검색 상자가 실제 ClickHouse 쿼리(Query)로 동작하므로, 모든 상호작용마다 백엔드에서 ClickHouse로 보내는 HTTPS 호출을 주 스팬으로 하는 트레이스가 생성됩니다.

이 가이드는 [OpenTelemetry Collector 설정](/ko/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)을 완료했고, ClickStack 수집기가 실행 중이며 이 애플리케이션을 실행할 머신에서 해당 수집기에 연결할 수 있다는 것을 전제로 합니다. **수집기의 OTLP 엔드포인트와 배포 시 설정한 `OTLP_AUTH_TOKEN`을 반드시 기록해 두십시오.** 계측을 시작하기 전에 이 값들을 `.env`에 입력합니다.

## 사전 요구 사항 {#prerequisites}

* 이 머신에서 연결할 수 있는 ClickStack 수집기가 필요합니다. 아직 배포하지 않았다면 먼저 [OpenTelemetry Collector 설정](/ko/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) 가이드를 따르십시오.
* 해당 collector의 OTLP/HTTP 엔드포인트(일반적으로 포트 `4318`)와 collector에 설정한 `OTLP_AUTH_TOKEN`이 필요합니다. 이 값을 각각 `OTEL_EXPORTER_OTLP_ENDPOINT`와 `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`에 사용하십시오.
* Node 18 이상과 npm이 필요합니다.

## 리포지토리 클론하기 {#clone-the-repository}

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)를 클론한 후 의존성을 설치하고 env 템플릿 파일을 복사하십시오.

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

`.env` 파일은 이후 단계에서 작성하며, 계측 작업은 이 디렉터리에서 진행합니다.
