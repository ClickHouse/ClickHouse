## 애플리케이션 연결 {#connect-your-application}

1. 사용하는 언어 또는 플랫폼에 맞는 가이드에 따라 instrumentation을 구성하십시오.
2. 해당 가이드에서 대상을 선택하십시오.
   * **완전 관리형:** 서비스의 관리형 OTLP 엔드포인트와 수집 API Key를 사용하십시오. 이 정보는 **팀 설정 → 데이터 → Managed Telemetry**에서 확인할 수 있습니다.
   * **자가 관리형:** OpenTelemetry Collector의 OTLP 엔드포인트와 구성된 수집 키를 사용하십시오.
3. 애플리케이션에서 활동을 발생시킨 다음, UI에서 예상한 텔레메트리가 표시되는지 확인하십시오.

각 가이드에서는 SDK별 인증 포맷과 익스포터 설정을 안내합니다. Lambda 가이드에서는 로컬 Collector를 거쳐 텔레메트리를 전달하는 OpenTelemetry 계층 옵션도 함께 안내합니다.
