OpenTelemetry Ruby SDK를 사용하여 ClickHouse Observability로 trace를 전송합니다.

<ClickStackIntegrates signals={['traces']} />

## OpenTelemetry 설정 {#set-up-opentelemetry}

공식 [OpenTelemetry Ruby 설정 지침](https://opentelemetry.io/docs/languages/ruby/getting-started/)에 따라 SDK를 초기화하고 애플리케이션을 계측하십시오.

아래 연결 설정을 사용하여 trace용 [HTTP 기반 OTLP 내보내기](https://opentelemetry.io/docs/languages/ruby/exporters/)를 구성하십시오. 업스트림 지침에 나오는 예시 대상은 신호별 엔드포인트 재정의를 포함하여 모두 아래 설정으로 대체하십시오.

## 대상 구성 {#configure-destination}

<Tabs>
  <Tab title="완전 관리형">
    <BetaBadge label="베타 서비스" />

    서비스에서 **팀 설정 → 데이터 → Managed Telemetry**를 열고 **OTLP HTTP 엔드포인트**와 **API Key**를 복사하십시오. 엔드포인트는 포트를 포함한 전체 HTTPS 주소를 그대로 사용하십시오.

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="자가 관리형">
    collector의 OTLP HTTP 엔드포인트와 수집 key를 사용하십시오. collector에 TLS가 구성되어 있지 않다면 `https://` 대신 `http://`를 사용하십시오. collector 설정 방법은 [OpenTelemetry를 사용한 데이터 수집](/ko/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)을 참조하십시오.

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## 수집 확인 {#verify-ingestion}

계측된 애플리케이션을 실행하고 활동을 발생시키십시오. ClickHouse Observability에서 최근 시간 범위를 선택한 다음, trace에서 애플리케이션의 서비스 이름을 찾으십시오.

계측 및 익스포터 관련 문제 해결 방법은 [OpenTelemetry Ruby 문서](https://opentelemetry.io/docs/languages/ruby/)를 참조하십시오.
