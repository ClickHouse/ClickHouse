OpenTelemetry를 사용하여 React Native 애플리케이션의 JavaScript 계층에서 ClickHouse Observability로 트레이스를 전송합니다.

<ClickStackIntegrates signals={['traces']} />

## OpenTelemetry 설정 {#set-up-opentelemetry}

공식 [OpenTelemetry React Native 데모](https://opentelemetry.io/docs/demo/services/react-native-app/)와 해당 [instrumentation 소스 코드](https://github.com/open-telemetry/opentelemetry-demo/tree/main/src/react-native-app)를 참고하여 추적을 초기화하고 네트워크 요청을 계측하십시오.

이 데모는 OpenTelemetry JavaScript 패키지를 사용하는데, 이 패키지는 React Native를 공식적으로 지원하지 않습니다. 애플리케이션에서 사용하는 React Native 및 OpenTelemetry 버전과 호환되는지 확인하십시오.

## 대상 구성 {#configure-destination}

데모의 로컬 익스포터 구성을 아래 대상 구성으로 대체하십시오. 업스트림 설정의 스팬 프로세서에서 이 익스포터를 사용하십시오. 익스포터 URL에는 반드시 `/v1/traces`가 포함되어야 합니다.

<Tabs>
  <Tab title="완전 관리형">
    <BetaBadge label="베타 제공" />

    서비스에서 **팀 설정 → 데이터 → Managed Telemetry**를 열고 **OTLP HTTP 엔드포인트**와 **API Key**를 복사하십시오. 포트를 포함한 전체 HTTPS 엔드포인트를 그대로 사용하고 끝에 `/v1/traces`를 추가하십시오.

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_OTEL_ENDPOINT:4318/v1/traces',
      headers: {
        Authorization: 'Bearer YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>

  <Tab title="자가 관리형">
    collector의 OTLP HTTP 엔드포인트와 수집 키를 사용하십시오. 디바이스에서 collector에 연결할 수 있어야 합니다. collector 설정 방법은 [OpenTelemetry로 데이터 수집하기](/ko/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)를 참조하십시오.

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_COLLECTOR_HOST:4318/v1/traces',
      headers: {
        Authorization: 'YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>
</Tabs>

## 수집 확인 {#verify-ingestion}

디바이스 또는 시뮬레이터에서 애플리케이션을 실행하고 네트워크 요청을 보내십시오. ClickHouse Observability에서 최근 시간 범위를 선택한 다음 Traces에서 애플리케이션의 서비스 이름을 찾으십시오.

instrumentation에 대한 자세한 내용과 React Native 호환성 문제를 우회하는 방법은 [OpenTelemetry React Native 데모](https://opentelemetry.io/docs/demo/services/react-native-app/)를 참조하십시오. 익스포터 옵션은 [OpenTelemetry JavaScript 익스포터 문서](https://opentelemetry.io/docs/languages/js/exporters/)를 참조하십시오.
