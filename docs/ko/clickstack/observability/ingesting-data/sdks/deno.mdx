Deno에 내장된 OpenTelemetry 지원 기능을 사용하여 로그, 메트릭, 트레이스를 ClickHouse Observability로 전송합니다. ClickStack Node.js SDK나 레거시 Deno 로깅 패키지는 필요하지 않습니다.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## OpenTelemetry 설정 {#set-up-opentelemetry}

공식 [Deno OpenTelemetry 설정 지침](https://docs.deno.com/runtime/fundamentals/open_telemetry/)에 따라 애플리케이션을 계측하십시오. 아래와 같이 대상을 구성한 다음, 애플리케이션을 시작할 때 Deno의 내장 통합을 활성화하십시오:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

애플리케이션에 필요한 권한을 추가하십시오. 업스트림 지침에 나오는 예시 대상이나 콘솔 익스포터 설정은 신호별 엔드포인트 재정의까지 포함하여 모두 실제 값으로 바꾸십시오.

## 대상 구성 {#configure-destination}

<Tabs>
  <Tab title="완전 관리형">
    <BetaBadge label="베타 서비스" />

    서비스에서 **팀 설정 → 데이터 → Managed Telemetry**를 열고 **OTLP HTTP 엔드포인트**와 **API Key**를 복사하십시오. 엔드포인트는 포트를 포함한 전체 HTTPS 주소를 사용하십시오.

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="자가 관리형">
    collector의 OTLP HTTP 엔드포인트와 수집 key를 사용하십시오. collector에 TLS가 구성되어 있지 않으면 `https://` 대신 `http://`를 사용하십시오. collector 설정 방법은 [OpenTelemetry를 사용한 데이터 수집](/ko/clickstack/observability/ingesting-data/opentelemetry#self-managed)을 참조하십시오.

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## 수집 확인 {#verify-ingestion}

애플리케이션을 시작하고 활동을 발생시키십시오. ClickHouse Observability에서 최근 시간 범위를 선택한 후 로그(Logs) 또는 트레이스(Traces)에서 애플리케이션의 서비스 이름을 찾으십시오. 메트릭(Metrics)은 내보내기가 완료될 때까지 잠시 기다린 후 확인하십시오.
