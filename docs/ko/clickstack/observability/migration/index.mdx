Elastic Stack 또는 Datadog에서 관리형 또는 자가 관리형 ClickHouse Observability로 마이그레이션(migration)하는 방법을 안내합니다. 이 가이드에서는 마이그레이션 계획, 검색 구문, 기존 텔레메트리 수집 방식을 조정하는 방법을 다룹니다. 배포 환경에 따라 연결 정보가 다른 경우 해당 배포 환경의 탭을 선택하십시오.

| 기술                                                           | 설명                                                                |
| ------------------------------------------------------------ | ----------------------------------------------------------------- |
| [Elastic Stack](/ko/clickstack/observability/migration/elastic) | 전환 계획 수립, 검색 쿼리 변환, 데이터·에이전트·애플리케이션 instrumentation 마이그레이션        |
| [Datadog](/ko/clickstack/observability/migration/datadog)       | 기존 Datadog 에이전트가 관리형 엔드포인트 또는 자가 관리형 Datadog 수신기로 텔레메트리를 전송하도록 구성 |
