ClickHouse Observability는 원시 SQL(Raw SQL) 쿼리 기반의 시각화를 지원합니다. 이를 통해 대시보드 수준의 시간 범위, 필터, 차트 렌더링 기능은 그대로 활용하면서 쿼리 로직을 완전히 제어할 수 있습니다.

SQL 기반 시각화는 기본 제공되는 차트 탐색기만으로는 부족할 때 유용합니다. 예를 들어 여러 테이블을 조인하거나, 차트 빌더에서 지원되지 않는 복잡한 집계(aggregations)를 구성해야 할 때 활용할 수 있습니다.

## SQL 기반 시각화 만들기 {#creating-a-raw-sql-chart}

SQL 기반 시각화를 만들려면 대시보드 타일 편집기를 열고 **SQL**을 선택하십시오.

<div className="ch-image-lg">
  <Frame>
    ![쿼리 지침과 매크로가 표시된 SQL 시각화 편집기](/images/clickstack/observability-sql-editor.png)
  </Frame>
</div>

이후 다음 단계를 진행하십시오.

1. 쿼리를 실행할 **연결**을 선택합니다.
2. 필요한 경우 **소스**를 선택합니다. 소스를 선택하면 `$__filters` 매크로를 통해 대시보드 수준 필터를 차트에 적용할 수 있으며, 쿼리에서 `$__sourceTable`을 사용할 수 있습니다.
3. 편집기에서 SQL 쿼리(SQL query)를 작성합니다. 쿼리 매개변수와 매크로를 사용하면 대시보드의 시간 범위, 필터, 변수와 연동할 수 있습니다.
4. **실행**을 클릭하여 결과를 미리 확인한 다음 **저장**을 클릭하여 시각화를 저장합니다.

연결과 소스는 [연결 변수 또는 데이터 소스 변수](/ko/clickstack/observability/features/dashboards/overview#source-connection-variables)로 지정할 수도 있습니다. 이 경우 타일이 쿼리할 연결 또는 소스를 대시보드 뷰어가 직접 선택합니다.

## 쿼리 매개변수 {#query-parameters}

[쿼리 매개변수](/ko/reference/syntax#defining-and-using-query-parameters)를 사용하면 SQL에서 대시보드의 현재 시간 범위와 세분화 수준을 참조할 수 있습니다. 쿼리 매개변수는 ClickHouse의 매개변수화된 쿼리 구문(query syntax)인 `{paramName:Type}` 형식을 따릅니다.

### 사용 가능한 매개변수 {#available-parameters}

사용할 수 있는 매개변수는 차트 유형에 따라 다릅니다.

**시계열(Time Series) 차트(누적 막대 차트 포함):**

| 매개변수                            | 유형    | 설명                                         |
| ------------------------------- | ----- | ------------------------------------------ |
| `{startDateMilliseconds:Int64}` | Int64 | 대시보드 날짜 범위의 시작 시점(epoch 기준 밀리초)            |
| `{endDateMilliseconds:Int64}`   | Int64 | 대시보드 날짜 범위의 종료 시점(epoch 기준 밀리초)            |
| `{intervalSeconds:Int64}`       | Int64 | 시간 버킷(time bucket) 크기(초 단위, 세분화 수준에 따라 결정) |
| `{intervalMilliseconds:Int64}`  | Int64 | 시간 버킷 크기(밀리초 단위, 세분화 수준에 따라 결정)            |

**테이블, 파이, 숫자 차트:**

| 매개변수                            | 유형    | 설명                              |
| ------------------------------- | ----- | ------------------------------- |
| `{startDateMilliseconds:Int64}` | Int64 | 대시보드 날짜 범위의 시작 시점(epoch 기준 밀리초) |
| `{endDateMilliseconds:Int64}`   | Int64 | 대시보드 날짜 범위의 종료 시점(epoch 기준 밀리초) |

## 매크로 {#macros}

매크로(Macros)는 자주 사용하는 ClickHouse SQL 표현식(Expressions)으로 확장되는 단축 표기입니다. 매크로는 `$__` 접두사로 시작하며, 쿼리가 ClickHouse로 전송되기 전에 해당 표현식으로 대체됩니다.

### 시간 경계 매크로 {#time-boundary-macros}

이 매크로들은 대시보드의 시작 시간 또는 종료 시간을 나타내는 ClickHouse 표현식을 반환합니다. 인수는 받지 않습니다.

| 매크로              | 확장 결과                                                                 | 컬럼 타입      |
| ---------------- | --------------------------------------------------------------------- | ---------- |
| `$__fromTime`    | `toDateTime(fromUnixTimestamp64Milli({startDateMilliseconds:Int64}))` | DateTime   |
| `$__toTime`      | `toDateTime(fromUnixTimestamp64Milli({endDateMilliseconds:Int64}))`   | DateTime   |
| `$__fromTime_ms` | `fromUnixTimestamp64Milli({startDateMilliseconds:Int64})`             | DateTime64 |
| `$__toTime_ms`   | `fromUnixTimestamp64Milli({endDateMilliseconds:Int64})`               | DateTime64 |
| `$__interval_s`  | `{intervalSeconds:Int64}`                                             | Int64      |

### 시간 필터 매크로 {#time-filter-macros}

이 매크로는 컬럼을 대시보드 시간 범위로 필터링하는 `WHERE` 절 프래그먼트를 생성합니다.

| 매크로                                   | 설명                                        |
| ------------------------------------- | ----------------------------------------- |
| `$__timeFilter(column)`               | `DateTime` 컬럼을 대시보드 시간 범위로 필터링합니다         |
| `$__timeFilter_ms(column)`            | `DateTime64`(밀리초) 컬럼을 대시보드 시간 범위로 필터링합니다  |
| `$__dateFilter(column)`               | `Date` 컬럼을 대시보드 시간 범위로 필터링합니다             |
| `$__dateTimeFilter(dateCol, timeCol)` | 별도의 `Date` 컬럼과 `DateTime` 컬럼을 사용하여 필터링합니다 |
| `$__dt(dateCol, timeCol)`             | `$__dateTimeFilter`의 별칭입니다                |

`$__timeFilter(TimestampTime)`의 **확장 예시**:

```sql
TimestampTime >= toDateTime(fromUnixTimestamp64Milli({startDateMilliseconds:Int64}))
AND TimestampTime <= toDateTime(fromUnixTimestamp64Milli({endDateMilliseconds:Int64}))
```

### 시간 간격 매크로 {#time-interval-macros}

이 매크로는 타임스탬프 컬럼을 대시보드의 세분화 수준에 맞는 인터벌 단위로 버킷화합니다. 주로 시계열 차트의 `SELECT` 및 `GROUP BY` 절(clauses)에서 사용합니다. 이 매크로는 누적 막대 차트를 포함한 **시계열** 시각화에서만 사용할 수 있습니다.

| 매크로                          | 설명                                                      |
| ---------------------------- | ------------------------------------------------------- |
| `$__timeInterval(column)`    | `DateTime` 컬럼을 `intervalSeconds` 단위의 인터벌로 버킷화합니다        |
| `$__timeInterval_ms(column)` | `DateTime64` 컬럼을 `intervalMilliseconds` 단위의 인터벌로 버킷화합니다 |

`$__timeInterval(TimestampTime)`의 **확장 예시**:

```sql
toStartOfInterval(toDateTime(TimestampTime), INTERVAL {intervalSeconds:Int64} second)
```

### 대시보드 필터 매크로 {#dashboard-filter-macro}

| 매크로              | 설명                                                                                                                                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `$__filters`     | 대시보드 수준의 필터 조건(Filter Conditions)으로 대체됩니다(소스 선택 필요)                                                                                                                                                      |
| `$__sourceTable` | `default.otel_logs`와 같이 정규화된 전체 이름의 선택한 소스 테이블로 대체됩니다. 메트릭 소스에는 `$__sourceTable(<metric type>)`을 사용하며, 여기서 메트릭 유형은 `gauge`, `histogram`, `sum`, `summary`, `exponential histogram` 중 하나입니다. 소스 선택이 필요합니다 |

차트에서 **소스**가 선택되어 있고 대시보드 필터가 활성 상태이면 `$__filters`는 해당하는 SQL `WHERE` 조건으로 확장됩니다. 소스가 선택되지 않았거나 적용된 필터가 없으면 `(1=1)`로 확장되므로 언제든 `WHERE` 절에 안전하게 포함할 수 있습니다.

`$__filters`는 **브로드캐스트 필터 조건**이 활성화된 SQL 표현식 값 필터의 선택 항목과, 타일의 소스에 적용되는 [애드혹 필터](/ko/clickstack/observability/features/dashboards/overview#adhoc-filters)의 조건을 적용합니다. 변수로 노출된 필터는 아래에서 설명하는 것처럼 명시적으로 참조합니다.

### 대시보드 변수 매크로 {#dashboard-variables}

대시보드 필터(filter)를 [변수로 사용할 수 있는](/ko/clickstack/observability/features/dashboards/overview#dashboard-variables) 경우(**Available as variable**이 활성화된 SQL 표현식(SQL expression) 값 필터, 또는 정적 값, SQL 쿼리(SQL query) 값, PromQL 레이블 값 필터), 선택한 값을 쿼리의 어느 위치에서나 참조할 수 있습니다. 이 매크로는 변수를 하나 이상 선언한 대시보드에 속한 타일에서만 사용할 수 있습니다.

| 매크로                                           | 설명                                                                                                 |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `$__filter($<variable>)`                      | `variable`에 선택된 값이 있으면 `toString(<filter expression>) IN ($variable)`로 확장되고, 그렇지 않으면 `1=1`로 확장됩니다. |
| `$__filter(<expression>, $<variable>)`        | `variable`에 선택된 값이 있으면 `<expression> IN ($variable)`로 확장되고, 그렇지 않으면 `1=1`로 확장됩니다.                  |
| `$__conditionalAll(<condition>, $<variable>)` | 변수에 선택된 값이 있으면 `<condition>`으로 확장되고, 그렇지 않으면 `1=1`로 확장됩니다.                                         |

변수 값은 `$name` 또는 `${name}` 형태로 직접 삽입할 수도 있으며, 필요에 따라 포맷을 지정할 수 있습니다. 사용 가능한 포맷은 `${name:sqlstring}`(기본값), `${name:csv}`, `${name:regex}`입니다. 기본 포맷에서는 값을 선택하기 전까지 직접 참조가 `NULL`로 렌더링되므로, 프레디케이트가 들어가야 하는 위치에서는 위의 매크로를 사용하는 것이 좋습니다.

## 쿼리 결과(query results)를 차트로 표시하는 방식 {#how-results-are-plotted}

UI는 컬럼 타입을 기준으로 결과 컬럼을 차트 요소에 자동으로 매핑합니다. 매핑 규칙은 차트 유형마다 다릅니다.

### 시계열 차트 {#line-and-stacked-bar-charts}

| 역할        | 컬럼 타입                         | 설명                                          |
| --------- | ----------------------------- | ------------------------------------------- |
| **타임스탬프** | 첫 번째 `Date` 또는 `DateTime` 컬럼  | x축으로 사용됩니다.                                 |
| **시계열 값** | 모든 숫자형 컬럼                     | 각 숫자형 컬럼이 별도의 시계열로 표시됩니다. 일반적으로 집계 값입니다.    |
| **그룹 이름** | `String`, `Map` 또는 `Array` 컬럼 | 선택 사항입니다. 그룹 값이 서로 다른 행은 각각 별도의 시계열로 표시됩니다. |

### 파이 차트 {#pie-chart}

| 역할         | 컬럼 타입                         | 설명                              |
| ---------- | ----------------------------- | ------------------------------- |
| **조각 값**   | 첫 번째 숫자형 컬럼                   | 각 조각의 크기를 결정합니다.                |
| **조각 레이블** | `String`, `Map` 또는 `Array` 컬럼 | 선택 사항. 중복 없는 값 각각이 조각 레이블이 됩니다. |

### 숫자 차트 {#number-chart}

| 역할     | 컬럼 타입       | 설명                            |
| ------ | ----------- | ----------------------------- |
| **숫자** | 첫 번째 숫자형 컬럼 | 첫 번째 숫자형 컬럼의 첫 번째 행 값이 표시됩니다. |

### 테이블 차트 {#table-chart}

모든 결과(result) 컬럼이 테이블 컬럼으로 그대로 표시됩니다.

## 예시 {#examples}

<Info>
  **예시 테이블 이름(Table Names)**

  예시에서는 `otel_logs`와 `otel_traces`를 사용합니다. 사용 중인 데이터에 맞게 테이블 이름과 컬럼 이름을 변경하십시오. [play-clickstack.clickhouse.com](https://play-clickstack.clickhouse.com)에서 예시를 실행할 때는 `otel_v2.otel_logs` 또는 `otel_v2.otel_traces`를 사용하십시오.
</Info>

### 시계열 차트 — 서비스별 시간대별 로그 수 {#example-line-chart}

이 쿼리는 서비스별 로그 이벤트 수를 집계하며, 대시보드의 세분화 수준에 맞춘 시간 간격 단위로 묶습니다.

```sql
SELECT
  toStartOfInterval(TimestampTime, INTERVAL {intervalSeconds:Int64} second) AS ts,
  ServiceName,
  count() AS count
FROM otel_logs
WHERE TimestampTime >= fromUnixTimestamp64Milli({startDateMilliseconds:Int64})
  AND TimestampTime < fromUnixTimestamp64Milli({endDateMilliseconds:Int64})
  AND $__filters
GROUP BY ServiceName, ts
ORDER BY ts ASC
```

* `ts`(`DateTime`)는 x축 타임스탬프로 사용됩니다.
* `count`(숫자형)는 시계열 값으로 표시됩니다.
* `ServiceName`(문자열)은 서비스마다 별도의 선을 생성합니다.

### 시계열 차트 — 매크로 사용 {#example-line-chart-macros}

같은 쿼리를 매크로로 간결하게 작성하면 다음과 같습니다.

```sql
SELECT
  $__timeInterval(TimestampTime) AS ts,
  ServiceName,
  count() AS count
FROM otel_logs
WHERE $__timeFilter(TimestampTime)
  AND $__filters
GROUP BY ServiceName, ts
ORDER BY ts ASC
```

### 시계열 차트 — 대시보드 변수 사용 {#example-line-chart-variables}

`ServiceName`에 대한 `service` 변수와 `SeverityText`에 대한 `severity` 변수가 있는 대시보드에서 이 쿼리는 차트를 현재 선택된 서비스로 한정하고, 선택된 심각도는 제외합니다. 두 매크로는 해당 변수에 선택된 값이 없으면 `1=1`로 확장되므로, 뷰어가 값을 선택하기 전까지 차트는 필터링되지 않은 상태로 렌더링됩니다.

```sql
SELECT
  $__timeInterval(TimestampTime) AS ts,
  count() AS count
FROM otel_logs
WHERE $__timeFilter(TimestampTime)
  AND $__filter(ServiceName, $service)
  AND $__conditionalAll(SeverityText NOT IN ($severity), $severity)
GROUP BY ts
ORDER BY ts ASC
```

### 누적 막대 차트 — 심각도별 오류 수 {#example-stacked-bar}

```sql
SELECT
  $__timeInterval(TimestampTime) AS ts,
  lower(SeverityText),
  count() AS count
FROM otel_logs
WHERE $__timeFilter(TimestampTime)
  AND lower(SeverityText) IN ('error', 'warn')
  AND $__filters
GROUP BY SeverityText, ts
ORDER BY ts ASC
```

### 테이블 차트 — 가장 느린 엔드포인트 상위 10개 {#example-table}

```sql
SELECT
  SpanName AS endpoint,
  avg(Duration) / 1000 AS avg_duration_ms,
  count() AS request_count
FROM otel_traces
WHERE $__timeFilter(Timestamp)
  AND $__filters
GROUP BY SpanName
ORDER BY avg_duration_ms DESC
LIMIT 10
```

### 파이 차트 — 서비스별 요청 분포 {#example-pie}

```sql
SELECT
  ServiceName,
  count() AS request_count
FROM otel_traces
WHERE $__timeFilter(Timestamp)
  AND $__filters
GROUP BY ServiceName
```

* `request_count`(숫자형)는 각 조각의 크기를 결정합니다.
* `ServiceName`(문자열)은 각 조각의 레이블로 사용됩니다.

### 숫자 차트 — 총 오류 수 {#example-number}

```sql
SELECT
  count() AS total_errors
FROM otel_logs
WHERE $__timeFilter(TimestampTime)
  AND SeverityText = 'error'
  AND $__filters
```

첫 번째 행(First row)의 단일 숫자 값인 `total_errors`가 표시됩니다.

## 참고 {#notes}

* SQL 기반 시각화는 `readonly` 모드가 활성화된 상태로 실행되므로 `SELECT` 쿼리만 허용됩니다.
* SQL 기반 시각화마다 쿼리는 하나만 지원되며, 여러 쿼리는 지원되지 않습니다.
* SQL 편집기는 쿼리 매개변수와 매크로 모두에 대해 자동 완성 기능을 제공합니다.
* SQL 기반 시각화에 대시보드 필터를 적용하려면 소스를 선택해야 합니다. 정확한 필터링을 위해 쿼리 대상 테이블과 일치하는 소스를 선택하세요.
* 대시보드 변수에는 소스가 필요하지 않습니다. 변수 값은 타일 자체의 소스가 아니라 대시보드의 필터 드롭다운에서 가져옵니다.
* 대시보드 변수를 참조하는 SQL 타일의 알림은 대시보드에서 선택한 값이 아니라 모든 변수가 비어 있는 상태를 기준으로 평가됩니다.
