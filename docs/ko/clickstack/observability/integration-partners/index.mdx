다음 통합 파트너를 통해 텔레메트리 파이프라인과 애플리케이션을 ClickHouse Observability에 연결하십시오. 각 가이드에서는 배포 환경에 맞게 통합을 구성하는 방법을 설명합니다.

| 섹션                                                                    | 설명                                                                                             |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [Bindplane](/ko/clickstack/observability/integration-partners/bindplane) | Bindplane은 OpenTelemetry 수집기를 중앙에서 관리할 수 있는 OpenTelemetry 네이티브 텔레메트리 파이프라인입니다.                 |
| [bitdrift](/ko/clickstack/observability/integration-partners/bitdrift)   | bitdrift는 OpenTelemetry 트레이스 컨텍스트를 통해 모바일 원격 측정 데이터를 백엔드 트레이스에 연결하는 모바일 애플리케이션용 동적 관측성 플랫폼입니다. |
| [Odigos](/ko/clickstack/observability/integration-partners/odigos)       | Odigos는 eBPF와 OpenTelemetry를 결합하여 바이트코드 에이전트보다 훨씬 낮은 오버헤드로 더 심층적인 분산 트레이스를 제공합니다.              |
| [Telflo](/ko/clickstack/observability/integration-partners/telflo)       | Telflo는 collector 관리와 텔레메트리 라우팅을 중앙에서 처리하는 OpenTelemetry 네이티브 컨트롤 플레인입니다.                      |
