이 샘플 데이터 세트와 데모를 활용하여 완전 관리형 ClickHouse Observability를 시작할 수 있습니다. 샘플 데이터를 로드하거나, 사용 중인 환경에서 로그와 메트릭을 수집하거나, 애플리케이션을 계측하여 트레이스와 세션 리플레이를 살펴보십시오.

| 데이터셋                                                                                     | 설명                                                                                       |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [샘플 데이터](/ko/clickstack/observability/example-datasets/sample-data)                         | 데모 환경의 로그, 트레이스, 메트릭이 포함된 샘플 데이터셋을 로드합니다                                                 |
| [Kubernetes 모니터링](/ko/clickstack/observability/example-datasets/kubernetes)                 | Kubernetes 클러스터에서 로그와 메트릭을 수집하여 관리형 서비스로 전송합니다                                           |
| [로컬 데이터](/ko/clickstack/observability/example-datasets/local-data)                          | 로컬 시스템 메트릭과 로그를 수집한 후 관리형 서비스로 전송하여 분석합니다                                                |
| [세션 리플레이 데모](/ko/clickstack/observability/example-datasets/session-replay)                  | 데모 웹 애플리케이션에 세션 리플레이를 위한 계측을 적용하고 ClickHouse Observability에서 사용자 상호작용을 확인합니다             |
| [Chrome 확장 프로그램](/ko/clickstack/observability/example-datasets/chrome-extension)            | HyperDX Chrome 확장 프로그램을 사용하여 애플리케이션 코드를 변경하지 않고도 모든 웹사이트에 브라우저 SDK를 주입합니다                |
| [otelgen을 사용한 합성 데이터](/ko/clickstack/observability/example-datasets/otelgen)                | `otelgen`을 사용하여 합성 로그, 트레이스, 메트릭을 관리형 텔레메트리 엔드포인트로 전송합니다                                 |
| [telemetrygen을 사용한 합성 데이터](/ko/clickstack/observability/example-datasets/telemetrygen)      | `telemetrygen`을 사용하여 합성 로그, 트레이스, 메트릭을 관리형 텔레메트리 엔드포인트로 전송합니다                            |
| [HackerNews Analyzer](/ko/clickstack/observability/example-datasets/instrument-application) | 에이전트를 사용하거나 수동으로 Node.js 앱을 계측하고 로그, 트레이스, 메트릭, 세션 리플레이를 ClickHouse Observability로 전송합니다 |
