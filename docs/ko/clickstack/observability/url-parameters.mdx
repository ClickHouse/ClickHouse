URL 쿼리 매개변수를 사용한 딥 링크로 ClickHouse Observability 페이지를 열 수 있습니다. 이를 통해 외부 시스템(경보 알림, 런북, CI 작업, 채팅 메시지 등)에서 특정 검색, 대시보드 또는 패널로 바로 이동할 수 있습니다.

이 페이지의 예시에서는 `<YOUR_CLICKSTACK_URL>`을 사용합니다. 이 값을 사용 중인 관측성 UI의 기준 URL로 대체하십시오.

<Note>
  가독성을 위해 예시의 쿼리 매개변수는 URL 인코딩하지 않은 상태로 표시합니다. 프로그래밍 방식으로 링크를 생성할 때는 각 쿼리 매개변수 값을 URL 인코딩하십시오.
</Note>

<Info>
  **클라우드 서비스 ID 매개변수**

  Cloud UI를 사용할 때 링크를 여는 인증된 사용자가 둘 이상의 ClickHouse 클라우드 서비스에 대한 사용 권한을 가지고 있다면, 로드할 ClickHouse 클라우드 서비스를 식별할 수 있도록 링크에 `?chcServiceId=` 매개변수를 포함해야 합니다.

  예시: 특정 클라우드 서비스에서 검색 열기

  ```text
  https://hyperdx.clickhouse.cloud/search?chcServiceId=abc123
  ```
</Info>

## 검색 — `/search` {#search}

기본 로그/트레이스 검색 뷰입니다. 검색 구문에 대한 자세한 내용은 [검색](/ko/clickstack/observability/features/search)을 참조하십시오.

| 매개변수            | 포맷                                                                         | 설명                                                                                    |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `source`        | 문자열                                                                     | 검색할 소스입니다. 소스 ID 또는 소스 **이름**(예: `Logs`)을 지정할 수 있습니다. 이 페이지에서는 로그 소스와 트레이스 소스만 지원됩니다. |
| `where`         | 문자열                                                                     | Lucene 또는 SQL 구문으로 작성한 필터 쿼리 텍스트(query text)입니다(`whereLanguage` 참조).                  |
| `whereLanguage` | `lucene` | `sql`                                                           | `where`에 사용된 쿼리 언어(query language)입니다.                                                |
| `select`        | 문자열                                                                     | 결과 테이블(Results Table)에 표시할 SQL 컬럼/표현식 목록입니다.                                          |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | `where`와 함께 추가로 적용되는 구조화된 패싯 필터입니다.                                                   |
| `orderBy`       | 문자열                                                                     | 결과 테이블에 적용할 SQL 정렬 표현식입니다.                                                            |
| `mode`          | `results` | `delta` | `pattern`                                            | 현재 활성화된 분석 모드입니다. `delta`는 트레이스 소스에서만 사용할 수 있습니다.                                     |
| `isLive`        | `true` | `false`                                                           | 라이브 테일 활성화 여부입니다(기본값 `true`).                                                         |
| `traceId`       | 문자열                                                                     | 지정한 트레이스 ID의 트레이스 워터폴 뷰로 바로 이동합니다.                                                    |
| `from`, `to`    | 에포크 기준 밀리초                                                                 | 절대 시간 범위입니다. 생략하면 최근 15분이 기본값으로 적용됩니다.                                                |

저장된 검색은 `/search/<savedSearchId>`에서 바로 열 수도 있습니다.

### 예시: 특정 시간 범위에서 `Logs` 소스의 `checkout` 서비스 오류 검색 {#example-search-errors}

```text
<YOUR_CLICKSTACK_URL>/search?source=Logs&from=1735689600000&to=1735693200000&where=level:error&filters=[{"type":"sql","condition":"ServiceName IN ('checkout')"}]
```

### 예시: 트레이스의 워터폴 뷰로 바로 이동하기 {#example-search-trace}

```text
<YOUR_CLICKSTACK_URL>/search?source=Traces&traceId=ba7217967eb90d040b7eb39f97ecc5c4
```

## 저장된 검색 — `/search/list` {#saved-searches}

저장된 검색 목록입니다.

| 매개변수  | 포맷  | 설명                           |
| ----- | --- | ---------------------------- |
| `tag` | 문자열 | 이 태그가 지정된 저장된 검색만 목록에 표시합니다. |

### 예시: `production` 태그가 지정된 저장된 검색 목록 조회 {#example-saved-searches-tag}

```text
<YOUR_CLICKSTACK_URL>/search/list?tag=production
```

## 대시보드 — `/dashboards/<dashboardId>` {#dashboards}

저장된 대시보드입니다. `<dashboardId>`를 생략하면(`/dashboards`) 저장되지 않은 임시 대시보드가 열립니다. 대시보드 구성에 대한 자세한 내용은 [대시보드](/ko/clickstack/observability/features/dashboards/overview)를 참조하십시오.

| 매개변수                | 포맷                                                                                                                                  | 설명                                                               |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `from`, `to`        | 에포크 기준 밀리초                                                                                                                          | 모든 타일에 적용되는 시간 범위입니다. 생략하면 기본값으로 최근 15분이 적용됩니다.                  |
| `where`             | 문자열                                                                                                                                 | 모든 타일에 공통으로 적용되는 대시보드 수준의 필터 쿼리 텍스트(query text)입니다.              |
| `whereLanguage`     | `lucene` | `sql`                                                                                                                    | `where`를 작성하는 데 사용한 쿼리 언어(query language)입니다.                    |
| `filters`           | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]`                                                          | 구조화된 대시보드 필터 값입니다. 이 예시는 `ServiceName` 필터 드롭다운에서 두 개의 항목을 선택합니다. |
| `granularity`       | `auto` | `30 second` | `1 minute` | `5 minute` | `10 minute` | `15 minute` | `30 minute` | `1 hour` | `12 hour` | `1 day` | `7 day` | 시계열 타일의 버킷 크기입니다. `auto`는 선택한 시간 범위에 맞춰 버킷 크기를 자동으로 결정합니다.       |
| `highlightedTileId` | 문자열                                                                                                                                 | 특정 타일로 스크롤한 뒤 해당 타일을 강조 표시합니다. 알림에서 링크로 연결할 때 유용합니다.             |

### 예시: 특정 타일을 강조 표시한 상태로 특정 시간 범위의 대시보드 열기 {#example-dashboard-highlight}

경보 알림에서 해당 알림을 발생시킨 타일로 바로 연결할 때 유용합니다.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?from=1735689600000&to=1735693200000&highlightedTileId=chart-1
```

## 차트 탐색기 — `/chart` {#chart-explorer}

공유 가능한 임시(ad-hoc) 차트 빌더입니다.

| 매개변수         | 포맷         | 설명                                                                                         |
| ------------ | ---------- | ------------------------------------------------------------------------------------------ |
| `config`     | JSON       | 전체 차트 구성(소스, select, where, 차트 유형 등)입니다. 일반적으로 직접 작성하기보다는 앱 내 &quot;공유&quot; 링크를 통해 생성됩니다. |
| `from`, `to` | 에포크 기준 밀리초 | 시간 범위입니다. 생략하면 기본값으로 최근 15분이 적용됩니다.                                                        |

### 예시: 특정 시간 범위의 p99 지연 시간 차트 구성 열기 {#example-chart-config}

```text
<YOUR_CLICKSTACK_URL>/chart?granularity=auto&from=1785759381784&to=1785762981785&config={"name":"","select":[{"aggFn":"quantile","aggCondition":"","aggConditionLanguage":"lucene","valueExpression":"Duration","level":0.99,"alias":"p99"}],"where":"","whereLanguage":"lucene","displayType":"line","alignDateRangeToGranularity":true,"source":"68814eb5d40a9d0449afc1f2","connection":"68814b6fd40a9d0449afbe78","groupBy":"ServiceName"}
```

## 알림 — `/alerts` {#alerts}

| `tag`     | 문자열 | 태그로 필터링합니다.                        |

## 세션 리플레이 — `/sessions` {#session-replay}

세션 리플레이 탐색 및 재생 기능입니다. 기능에 대한 자세한 내용은 [세션 리플레이](/ko/clickstack/observability/features/session-replay)를 참조하십시오.

| 매개변수            | 포맷               | 설명                                           |
| --------------- | ---------------- | -------------------------------------------- |
| `sessionSource` | 문자열           | 세션 소스 ID 또는 이름입니다.                           |
| `where`         | 문자열           | 세션 목록에 적용할 필터 쿼리 텍스트입니다.                     |
| `whereLanguage` | `lucene` | `sql` | `where`에 사용된 쿼리 언어입니다.                       |
| `from`, `to`    | 에포크 기준 밀리초       | 세션 목록의 시간 범위입니다. 생략하면 기본값으로 최근 15분이 적용됩니다.   |
| `sid`           | 문자열           | 지정한 ID의 세션을 엽니다.                             |
| `sfrom`, `sto`  | 에포크 기준 밀리초       | 열린 세션의 시간 윈도우(time window)입니다(`sid`와 함께 사용). |

### 예시: 특정 시간 범위의 세션 다시 보기 탐색 {#example-sessions-time-range}

```text
<YOUR_CLICKSTACK_URL>/sessions?from=1735689600000&to=1735693200000
```

### 예시: 기록된 시간 윈도우(time window)로 특정 세션 리플레이 열기 {#example-sessions-open}

```text
<YOUR_CLICKSTACK_URL>/sessions?sid=6712abf0e4b0f2a1c3d4e5f6&sfrom=1735689600000&sto=1735690200000
```

## 서비스 맵 — `/service-map` {#service-map}

기능에 대한 자세한 내용은 [서비스 맵](/ko/clickstack/observability/service-maps)을 참조하십시오.

| 매개변수             | 포맷          | 설명                                                        |
| ---------------- | ----------- | --------------------------------------------------------- |
| `source`         | 문자열         | 트레이스 소스 ID 또는 이름입니다.                                      |
| `samplingFactor` | 정수(integer) | 트레이스 샘플링 제수입니다(`1` = 트레이스의 100%, `2` = 50%, `4` = 25% 등). |
| `from`, `to`     | 에포크 기준 밀리초  | 시간 범위입니다. 생략하면 기본값인 최근 15분이 적용됩니다.                        |

### 예시: 특정 시간 범위의 서비스 맵 보기 {#example-service-map}

```text
<YOUR_CLICKSTACK_URL>/service-map?from=1735689600000&to=1735693200000
```

## 서비스 — `/services` {#services}

서비스별 HTTP, 데이터베이스, 오류 대시보드입니다.

| 매개변수            | 포맷                                                                         | 설명                                                                    |
| --------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `tab`           | `http` | `database` | `errors`                                             | 표시할 서비스 대시보드 하위 탭입니다. 기본값: `http`                                     |
| `source`        | 문자열                                                                        | 트레이스 소스 ID입니다.                                                        |
| `service`       | 문자열                                                                        | 선택한 서비스 이름입니다.                                                        |
| `where`         | 문자열                                                                        | 필터 쿼리 텍스트(query text)입니다.                                             |
| `whereLanguage` | `lucene` | `sql`                                                           | `where`를 작성하는 데 사용한 쿼리 언어(query language)입니다(이 페이지에서는 기본값이 `sql`입니다). |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | 대시보드 필터 바의 값입니다.                                                      |
| `from`, `to`    | 에포크 기준 밀리초                                                                 | 시간 범위입니다. 생략하면 최근 15분이 기본값으로 적용됩니다.                                   |

### 예시: 특정 시간 범위의 서비스 데이터베이스 대시보드 보기 {#example-services-database}

```text
<YOUR_CLICKSTACK_URL>/services?tab=database&service=checkout&from=1735689600000&to=1735693200000
```

### 예시: 서비스의 오류 대시보드 보기 {#example-services-errors}

```text
<YOUR_CLICKSTACK_URL>/services?tab=errors&service=payments
```

## Kubernetes — `/kubernetes` {#kubernetes}

| 매개변수                                   | 포맷                               | 설명                                                           |
| -------------------------------------- | -------------------------------- | ------------------------------------------------------------ |
| `logSource`, `metricSource`            | 문자열                              | 로그 및 메트릭 소스 ID입니다. 둘 중 하나만 지정하면 나머지는 기본적으로 상호 연관된 소스로 설정됩니다. |
| `tab`                                  | 예: `pods`, `nodes`, `namespaces` | 활성 하위 뷰입니다.                                                  |
| `q`                                    | 문자열                              | 리소스 목록에 적용할 Lucene 쿼리입니다.                                    |
| `podName`, `nodeName`, `namespaceName` | 문자열                              | 특정 파드, 노드 또는 네임스페이스의 상세 정보 패널을 엽니다.                          |
| `from`, `to`                           | 에포크 기준 밀리초                       | 시간 범위입니다. 생략하면 기본적으로 최근 15분으로 설정됩니다.                         |

### 예시: 특정 파드의 상세 정보 패널 열기 {#example-kubernetes-pod}

```text
<YOUR_CLICKSTACK_URL>/kubernetes?tab=pods&podName=checkout-7d9f8b5c-2xk9p
```
