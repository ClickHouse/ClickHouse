<Note>
  이 가이드에서는 완전 관리형 ClickHouse Observability를 다룹니다. 자체 관리형 ClickHouse Observability의 용량 산정, 보존 기간, 스키마(schema) 튜닝 및 운영 환경 관련 지침은 [데이터베이스 관리](/ko/clickstack/self-configured/managing/overview)를, 소스 설정은 [구성 옵션](/ko/clickstack/self-configured/managing/config)을 참조하십시오.
</Note>

ClickHouse Observability의 **팀 설정**에서 텔레메트리 액세스, 소스, API 및 에이전트 연결, 통합, 쿼리 설정(query settings), 팀 권한을 관리할 수 있습니다.

## 관리 가이드 {#admin-guides}

| 가이드                                                    | 수행할 수 있는 작업                                                                                      |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| [구성 옵션](/ko/clickstack/observability/managing/config)     | 소스 및 collector 액세스를 관리하고, 텔레메트리 연결 정보를 확인하고, API 및 에이전트 액세스를 구성하고, 쿼리 설정(query settings)을 조정합니다. |
| [역할 기반 접근 제어](/ko/clickstack/observability/managing/rbac) | 기본 제공 역할을 확인하고, 사용자 정의 역할을 생성하고, 대시보드, 저장된 검색, 소스 등의 리소스에 대한 권한을 구성합니다.                          |

## 텔레메트리 전송 {#sending-telemetry}

애플리케이션과 collector를 연결하려면 먼저 **팀 설정 → 데이터 → Managed Telemetry**에서 연결 정보를 확인한 다음, [수집 가이드](/ko/clickstack/observability/ingesting-data/overview)에 따라 진행하십시오.
