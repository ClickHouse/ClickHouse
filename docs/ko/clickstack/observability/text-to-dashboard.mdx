Text-to-Dashboard는 모니터링하려는 대상을 일상적인 언어로 설명하면 이를 바탕으로 대시보드를 생성합니다. AI가 사용 가능한 데이터를 분석하여 관련 타일을 구성한 다음, 바로 열어서 편집할 수 있는 대시보드로 저장합니다.

단일 차트만 생성하려면 [Text-to-Chart](/ko/clickstack/observability/text-to-chart)를 사용하세요.

## 사전 요구 사항 {#prerequisites}

* ClickHouse Observability 서비스에 데이터가 있어야 합니다.
* 팀 관리자가 [생성형 AI를 활성화](/ko/clickstack/observability/notebooks#enabling-generative-ai)해야 합니다.
* 사용자에게 할당된 역할에 AI 노트북 사용 권한과 대시보드 생성 권한이 있어야 합니다.

## 대시보드 생성 {#generate-a-dashboard}

<Steps>
  <Step title="대시보드 생성 열기" id="open-dashboard-generation">
    사이드바에서 **Dashboards**를 선택하십시오. **New Dashboard**를 열고 **Generate with AI**를 선택하십시오.
  </Step>

  <Step title="대시보드 설명 작성" id="describe-the-dashboard">
    **Generate dashboard with AI**에 대시보드를 통해 답을 얻고자 하는 질문을 설명하십시오. 관련 서비스, 데이터 소스, 필드, 차트 유형도 함께 적으십시오. 예를 들면 다음과 같습니다.

    > Create a dashboard using the Logs source. Show total log count, log volume over time, and log counts grouped by severity. Use the dashboard time filter for every tile.

    <div className="ch-image-lg">
      <Frame>
        ![로그 볼륨, 서비스별 오류, 자주 발생하는 오류 메시지를 설명하는 프롬프트가 입력된 Generate dashboard with AI 대화 상자](/images/clickstack/observability-text-to-dashboard-prompt.png)
      </Frame>
    </div>

    **Generate dashboard**를 선택하십시오.
  </Step>

  <Step title="노트북에서 생성 과정 확인" id="follow-dashboard-generation">
    요청 내용이 담긴 AI 노트북이 열립니다. AI는 사용 가능한 소스와 데이터를 살펴보고 대시보드를 생성한 뒤 노트북에 결과를 보고합니다. 누락된 데이터나 요청한 대시보드와 달라진 부분에 대한 설명이 있다면 검토하십시오.
  </Step>

  <Step title="대시보드 열기 및 검토" id="review-generated-dashboard">
    노트북 응답에 있는 대시보드 링크를 클릭하십시오. 생성된 대시보드는 자동으로 저장되며 **Dashboards**에서도 열 수 있습니다.

    <div className="ch-image-lg">
      <Frame>
        ![ClickHouse Observability에서 전체 로그 수, 시간에 따른 로그 볼륨, 심각도별 로그 수를 보여주는 AI 생성 대시보드](/images/clickstack/observability-text-to-dashboard-result.png)
      </Frame>
    </div>

    선택된 소스, 필터(filter), 집계(aggregations), 시간 범위를 확인하십시오. 차트가 원래 질문에 대한 답을 제공하는지, 대시보드 시간 필터(filter)를 변경하면 차트에 반영되는지도 확인하십시오. 표준 [대시보드 컨트롤](/ko/clickstack/observability/features/dashboards/overview)을 사용하여 타일과 레이아웃(layout)을 편집할 수 있습니다.

    결과를 다듬으려면 서비스 필터(filter) 추가나 차트 그룹화 변경처럼 구체적인 후속 요청을 노트북에 이어서 입력하십시오.
  </Step>
</Steps>

## 프롬프트 예시 {#example-prompts}

다음 프롬프트를 서비스에서 사용할 수 있는 데이터에 맞게 수정하여 사용하십시오.

* **로그 모니터링:** &quot;시간대별 로그 볼륨, 서비스별 오류 발생 횟수, 가장 자주 발생하는 오류 메시지를 보여주는 대시보드를 만들어 주세요.&quot;
* **서비스 성능:** &quot;Traces 소스를 사용하여 checkout 서비스의 대시보드를 만들고, 엔드포인트별 요청량, 오류율, p95 지연 시간을 표시해 주세요.&quot;
* **집중 조사:** &quot;결제 실패에 대한 대시보드를 만들어 주세요. 시간대별 발생 빈도를 보여주고 서비스 및 오류 메시지별로 세분화해 주세요.&quot;

스키마(schema)만으로는 의미가 명확하지 않은 필드나 속성은 사용할 이름을 직접 명시하십시오. 또한 데이터에서 오류나 실패를 식별하는 기준도 지정하십시오.

## 생성된 결과 검토 {#review-generated-results}

AI가 생성한 대시보드에는 잘못된 쿼리나 가정이 포함되어 있을 수 있습니다. 운영 관련 의사 결정에 활용하기 전에 각 타일을 검토하십시오. 차트가 비어 있다면 데이터가 누락되었거나, 필터(filter) 조건이 지나치게 엄격하거나, 선택한 시간 범위에 일치하는 이벤트가 없는 것일 수 있습니다.
