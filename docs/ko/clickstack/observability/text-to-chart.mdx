ClickHouse Observability의 Text-to-Chart 기능을 사용하면 보고 싶은 내용을 일반 텍스트로 설명하는 것만으로 시각화를 생성할 수 있습니다. 메트릭, 필터, group-by 필드를 직접 선택할 필요 없이 &quot;지난 3일간 서비스별 오류 발생 횟수&quot;와 같은 프롬프트를 입력하면 AI 어시스턴트가 해당 차트를 자동으로 생성합니다.

이 기능은 대규모 언어 모델(LLM)을 사용해 텍스트 프롬프트를 쿼리로 변환한 다음, [차트 탐색기](/ko/clickstack/observability/features/dashboards/overview#navigate-chart-explorer)에서 시각화를 구성합니다.

## 사전 요구 사항 {#prerequisites}

팀 관리자가 **팀 설정**의 **Configure Generative AI**에서 생성형 AI를 활성화해야 합니다. 자세한 방법은 [생성형 AI 활성화](/ko/clickstack/observability/notebooks#enabling-generative-ai)를 참조하십시오. AI 모델과 서비스 제공업체는 플랫폼에서 자동으로 관리합니다.

## 예시 프롬프트 {#example-prompts}

다음 프롬프트는 관측성 데이터를 다룰 때 흔히 사용하는 활용 사례를 보여 줍니다.

| 프롬프트                                              | 데이터 소스 | 설명                       |
| ------------------------------------------------- | ------ | ------------------------ |
| `Error count by service over time`                | 로그     | 서비스별 오류 발생 빈도를 차트로 표시합니다 |
| `Average request duration grouped by endpoint`    | trace   | 엔드포인트별 지연 시간 패턴을 보여 줍니다  |
| `P99 latency by service`                          | trace   | 서비스 전반의 테일 지연 시간을 파악합니다  |
| `Count of 5xx status codes over the last 6 hours` | 로그     | 서버 오류 추이를 추적합니다          |

프롬프트에서는 구성된 데이터 소스(data sources)에 있는 모든 컬럼 또는 속성을 참조할 수 있습니다. AI가 원하는 차트를 정확히 생성할 수 있도록 구체적인 컬럼 이름(Column Names), 필터, 시간 범위를 포함하십시오.

## 제한 사항 {#limitations}

* 데이터 소스로는 로그와 trace만 지원됩니다. Prometheus 메트릭은 아직 지원되지 않습니다.
* 차트의 정확도는 프롬프트가 얼마나 명확한지, 그리고 기반 데이터의 구조가 어떠한지에 따라 달라집니다. 생성된 차트가 예상과 다르면 프롬프트를 바꿔 표현하거나 컬럼 이름(Column Names)을 명시적으로 지정해 보십시오.
