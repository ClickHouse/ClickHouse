<Note>
  **자가 관리형 경로를 선택했습니다**

  [자가 관리형 환경](/ko/clickstack/self-configured/overview)을 사용하여 ClickHouse Observability를 직접 설정하는 방식을 선택했습니다. 이 경로에서는 OpenTelemetry collector를 직접 실행하고, ClickHouse Cloud 서비스로의 수집을 관리하며, 스키마(schema)를 튜닝하고, 웨어하우스(warehouses)를 사용하여 수집 워크로드와 쿼리 워크로드를 분리합니다. 자세한 내용은 [OpenTelemetry collector](/ko/clickstack/self-configured/ingesting-data/collector), [성능 튜닝](/ko/clickstack/self-configured/managing/performance-tuning), [읽기 및 쓰기 워크로드 분리](/ko/clickstack/self-configured/managing/isolating-read-write)를 참조하십시오.

  ClickHouse가 수집, 스키마(schemas), 컴퓨트를 대신 처리하는 서버리스 환경을 원한다면 기본 ClickHouse Observability 환경을 사용하고 [OpenTelemetry로 애플리케이션 계측하기](/ko/clickstack/managed-onboarding/instrument-application-serverless)를 따르십시오.
</Note>

이 가이드에서는 소규모 Node.js 애플리케이션을 OpenTelemetry로 계측하고, 애플리케이션의 로그, 메트릭, trace, 세션 다시 보기를 직접 실행하는 collector를 통해 ClickHouse Observability로 전송하는 과정을 안내합니다. 백엔드는 애플리케이션 소스 코드를 변경하지 않고 계측합니다.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)는 공개 ClickHouse 데모에 호스팅된 HackerNews 데이터셋을 쿼리하는 Node.js 앱입니다. 모든 차트, 테이블, 검색 상자가 실제 ClickHouse 쿼리(Query)로 동작하므로, 모든 상호작용에서 trace가 생성되며 이 trace의 주요 span은 백엔드에서 ClickHouse로 보내는 HTTPS 호출입니다.

이 가이드는 [OpenTelemetry Collector 설정](/ko/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)을 완료했으며, 이 애플리케이션을 실행할 머신에서 연결할 수 있는 ClickStack 수집기가 실행 중이라고 가정합니다. **해당 수집기의 OTLP 엔드포인트**와 배포 시 설정한 `OTLP_AUTH_TOKEN`을 **반드시 기록해 두십시오**. 계측을 시작하기 전에 이 값들을 `.env`에 입력합니다.

## 사전 요구 사항 {#prerequisites}

* 이 머신에서 접근할 수 있는 ClickStack 수집기. 아직 배포하지 않았다면 먼저 [OpenTelemetry Collector 설정](/ko/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)을 따르십시오.
* 해당 collector의 OTLP/HTTP 엔드포인트(일반적으로 포트 `4318`)와 여기에 설정한 `OTLP_AUTH_TOKEN`. 이를 `OTEL_EXPORTER_OTLP_ENDPOINT` 및 `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`으로 사용하십시오.
* Node 18+와 npm.

## 리포지토리 복제 {#clone-the-repository}

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) 리포지토리를 복제하고 의존성을 설치한 후 env 템플릿을 복사합니다:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

다음 단계에서 `.env`를 작성한 후 이 디렉터리에서 애플리케이션 계측을 수행합니다.
