[올인원 이미지](/ko/clickstack/deployment/all-in-one)와 마찬가지로, 이 포괄적인 Docker 이미지는 모든 ClickStack 구성 요소를 포함합니다:

* **ClickHouse**
* **ClickStack UI**
* **OpenTelemetry (OTel) collector** (포트 `4317` 및 `4318`에서 OTLP를 노출)
* **MongoDB** (애플리케이션 상태를 영구적으로 저장하기 위한 용도)

**다만, 이 ClickStack UI 배포판에서는 사용자 인증이 비활성화되어 있습니다**

<div id="suitable-for">
  ### 적합한 용도 {#suitable-for}
</div>

* 데모
* 디버깅
* ClickStack UI를 사용하는 개발 환경

## 배포 단계 {#deployment-steps}

<br />

<Steps>
  <Step title="Docker로 배포" id="deploy-with-docker">
    로컬 모드에서는 ClickStack UI가 8080 포트에 배포됩니다.

    ```shell
    docker run -p 8080:8080 clickhouse/clickstack-local:latest
    ```
  </Step>

  <Step title="ClickStack UI로 이동" id="navigate-to-hyperdx-ui">
    [http://localhost:8080](http://localhost:8080)에 접속하여 ClickStack UI를 엽니다.

    **이 배포 모드에서는 인증이 활성화되어 있지 않으므로 사용자를 생성하라는 화면이 표시되지 않습니다.**

    ClickHouse Cloud와 같이 직접 운영하는 외부 ClickHouse 클러스터에 연결하십시오.

    <div className="ch-image-md">
      <Frame>
        ![로그인 생성](/images/use-cases/observability/hyperdx-2.webp)
      </Frame>
    </div>

    소스를 생성하고 모든 기본값을 그대로 둔 채 `Table` 필드에 `otel_logs` 값을 입력하십시오. 나머지 설정은 모두 자동으로 감지되므로 바로 `Save New Source`를 클릭하면 됩니다.

    <div className="ch-image-md">
      <Frame>
        ![로그 소스 생성](/images/use-cases/observability/hyperdx-logs.webp)
      </Frame>
    </div>
  </Step>
</Steps>
