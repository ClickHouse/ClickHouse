ClickHouse를 시작하고 작동 방식을 이해하는 데 도움이 되는 다양한 자료가 준비되어 있습니다:

* 아무것도 설치하지 않고 ClickHouse를 사용해 보려면 무료 [ClickHouse Cloud 체험판](https://clickhouse.cloud/signUp?loc=docs-get-started-sample-datasets)에 가입하거나 읽기 전용 [ClickHouse playground](/ko/get-started/sample-datasets/playground)에서 쿼리를 실행해 보세요.
* ClickHouse를 직접 실행하려면 [Quick Start](/ko/get-started/setup/install)를 따라 하세요.
* 학습을 어디서 시작할지 고민된다면 뉴욕시 택시 운행 데이터셋을 분석하는 [뉴욕 택시 데이터](/ko/get-started/sample-datasets/nyc-taxi) 튜토리얼을 살펴보거나 아래 튜토리얼 중 하나를 선택하세요.
