## 기지국 데이터 세트를 사용한 지리 공간 분석 {#geospatial-analysis-with-cell-towers}

이 가이드에서는 `OpenCelliD` 기지국 데이터를 `ClickHouse Cloud`에 로드하고 국가 사전으로 보강한 뒤, 독일 내 기지국을 조회하여 `ClickHouse Agents`로 시각화합니다.

<Steps>
  <Step title="샘플 데이터 로드">
    `ClickHouse Cloud`에서 **Load data**를 열고 **Sample data**의 **Cell Towers**를 로드합니다. `cell_towers`의 각 행은 기지국이며 `lon`, `lat`는 좌표입니다.

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="조회 및 보강">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;

    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="지리 데이터 사용">
    `ClickHouse`의 [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon)을 사용합니다. `germany`를 만들고 [영문 가이드](/get-started/sample-datasets/cell-towers#germany-polygon)의 독일 본토 윤곽을 삽입합니다.

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    결과는 약 `2.62 million`입니다.
  </Step>
  <Step title="선택 사항: ClickHouse Agents로 시각화">
    이는 선택 사항인 실행 예시입니다. `ClickHouse Agents`는 모델 기반 베타 기능이므로 계획, 사용하는 도구, 출력은 실행마다 달라질 수 있습니다. **ClickHouse agents**를 열고 "Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables"를 보냅니다.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="독일 기지국 밀도 격자를 만드는 ClickHouse Agent 채팅"/>

    한 실행에서는 에이전트가 독일 MCC를 찾고 기지국을 세어 `0.1°` 격자로 묶은 후 지도에 윤곽을 그렸습니다.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="독일 기지국 밀도 히트맵"/>
  </Step>
</Steps>
