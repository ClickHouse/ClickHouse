### SQL 콘솔로 데이터 추가하기 {#add-data-using-the-sql-console}

        대부분의 데이터베이스 관리 시스템(database management system)과 마찬가지로 ClickHouse는 테이블(tables)을 **데이터베이스** 단위로 논리적으로 그룹화합니다. ClickHouse에서 새 데이터베이스를 생성하려면 [`CREATE DATABASE`](/ko/reference/statements/create/database) 명령을 사용하십시오.

        ```sql
        CREATE DATABASE IF NOT EXISTS helloworld
        ```

        다음 명령을 실행하여 `helloworld` 데이터베이스에 `my_first_table`이라는 이름의 테이블을 생성하세요:

        ```sql
        CREATE TABLE helloworld.my_first_table
        (
            user_id UInt32,
            message String,
            timestamp DateTime,
            metric Float32
        )
        ENGINE = MergeTree()
        PRIMARY KEY (user_id, timestamp)
        ```

        위 예시에서 `my_first_table`은 4개의 컬럼으로 구성된 [`MergeTree`](/ko/reference/engines/table-engines/mergetree-family/mergetree) 테이블입니다:

        * `user_id`:  32비트 부호 없는 정수([UInt32](/ko/reference/data-types/int-uint))
        * `message`: [String](/ko/reference/data-types/string) 데이터 타입으로, 다른 데이터베이스 시스템의 `VARCHAR`, `BLOB`, `CLOB` 등의 타입을 대체합니다.
        * `timestamp`: 특정 시점을 나타내는 [DateTime](/ko/reference/data-types/datetime) 값
        * `metric`: 32비트 부동 소수점 수([Float32](/ko/reference/data-types/float))

        <Info>
          **테이블 엔진**

          테이블 엔진은 다음 사항을 결정합니다.

          * 데이터를 저장하는 방식과 위치
          * 지원되는 쿼리 유형
          * 데이터 복제 여부

          <br />

          테이블 엔진은 종류가 다양하지만, 단일 노드 ClickHouse 서버에서 간단한 테이블을 사용한다면 대개 [`MergeTree`](/ko/reference/engines/table-engines/mergetree-family/mergetree)를 선택하면 됩니다.
        </Info>

#### 기본 키(primary keys) 간단히 알아보기 {#a-brief-intro-to-primary-keys}

        본격적으로 진행하기 전에 ClickHouse에서 기본 키(primary keys)가 어떻게 동작하는지 먼저 이해해야 합니다(기본 키의 구현 방식은
        예상과 다르게 느껴질 수 있습니다!):

        * ClickHouse의 기본 키(primary keys)는 테이블의 각 행마다 ***고유하지 않습니다***

        ClickHouse 테이블(table)의 프라이머리 키는 데이터가 디스크에 기록될 때의 정렬 방식을 결정합니다. 8,192개의 행(rows) 또는 10MB의
        데이터(**인덱스 세분성(index granularity)**&#xC774;라고 함)마다 프라이머리 키 인덱스 파일(index file)에 엔트리가 하나씩 생성됩니다. 이러한 세분화 수준 개념을 통해
        메모리에 쉽게 들어가는 **희소 인덱스(sparse index)**&#xAC00; 만들어지며, 그래뉼은 `SELECT` 쿼리 실행 중에 처리되는 최소 단위의
        컬럼 데이터(Column Data) 스트라이프를 나타냅니다.

        프라이머리 키는 `PRIMARY KEY` 매개변수를 사용하여 정의할 수 있습니다. `PRIMARY KEY`를 지정하지 않고 테이블을 정의하면,
        `ORDER BY` 절에 지정된 튜플이 프라이머리 키가 됩니다. `PRIMARY KEY`와 `ORDER BY`를 모두 지정하면 프라이머리 키는 정렬 순서(sort order)의 부분 집합이어야 합니다.

        프라이머리 키는 정렬 키이기도 하며, `(user_id, timestamp)`로 구성된 튜플입니다.  따라서 각
        컬럼 파일(Column File)에 저장된 데이터는 먼저 `user_id` 기준으로, 그다음 `timestamp` 기준으로 정렬됩니다.

        ClickHouse 핵심 개념에 대한 심층 분석은 [&quot;핵심 개념&quot;](/ko/concepts/core-concepts/index)을 참조하십시오.

#### 테이블에 데이터 삽입 {#insert-data-into-your-table}

        ClickHouse에서도 익숙한 [`INSERT INTO TABLE`](/ko/reference/statements/insert-into) 명령을 사용할 수 있지만, [`MergeTree`](/ko/reference/engines/table-engines/mergetree-family/mergetree) 테이블에 삽입할 때마다 저장소에 **파트**(part)가 하나씩 생성된다는 점을 반드시 알아두어야 합니다.

        <Tip>
          **ClickHouse 권장 사항**

          배치당 많은 수의 행(rows)을 삽입하십시오. 한 번에 수만 개에서 수백만 개에 이르는
          행을 삽입해도 좋습니다. ClickHouse는 이 정도 규모의 데이터를 손쉽게 처리하므로 걱정하지 않아도 됩니다. 오히려 서비스로 보내는 쓰기 요청 수가 줄어들어 [비용을 절감](/ko/concepts/best-practices/selecting-an-insert-strategy#batch-inserts-if-synchronous)할 수 있습니다.
        </Tip>

        <br />

        간단한 예시라도 한 번에 여러 행을 삽입해 보겠습니다.

        ```sql
        INSERT INTO helloworld.my_first_table (user_id, message, timestamp, metric) VALUES
            (101, 'Hello, ClickHouse!',                                 now(),       -1.0    ),
            (102, 'Insert a lot of rows per batch',                     yesterday(), 1.41421 ),
            (102, 'Sort your data based on your commonly-used queries', today(),     2.718   ),
            (101, 'Granules are the smallest chunks of data read',      now() + 5,   3.14159 )
        ```

        <Note>
          `timestamp` 컬럼의 값은 다양한 [**Date**](/ko/reference/data-types/date) 및 [**DateTime**](/ko/reference/data-types/datetime) 함수를 사용하여 채워집니다. ClickHouse에는 수백 개의 유용한 함수가 있으며, 자세한 내용은 [**함수** 섹션에서 확인할 수 있습니다](/ko/reference/functions/index).
        </Note>

        정상적으로 적용되었는지 확인합니다.

        ```sql
        SELECT * FROM helloworld.my_first_table
        ```

### ClickHouse Client로 데이터 추가 {#add-data-using-the-clickhouse-client}

        [**clickhouse client**](/ko/concepts/features/interfaces/client)라는 명령줄 도구를 사용하여 ClickHouse Cloud 서비스에 연결할 수도 있습니다. 왼쪽 메뉴에서 `Connect`를 클릭하면 연결 정보를 확인할 수 있습니다. 대화 상자의 드롭다운에서 `Native`를 선택하세요:

        <div className="ch-image-lg">
          <Frame>
            ![clickhouse client 연결 정보](/images/_snippets/client_details.webp)
          </Frame>
        </div>

        <br />

        1. [ClickHouse](/ko/get-started/setup/self-managed/quick-install)를 설치하십시오.

        2. 호스트명, 사용자 이름, 비밀번호를 실제 값으로 바꾼 후 다음 명령을 실행하십시오.

        ```bash
        ./clickhouse client --host HOSTNAME.REGION.CSP.clickhouse.cloud \
        --secure --port 9440 \
        --user default \
        --password <password>
        ```

        스마일 얼굴 프롬프트가 표시되면 쿼리를 실행할 준비가 된 것입니다!

        ```response
        :)
        ```

        3. 다음 쿼리를 실행해 직접 확인해 보십시오:

        <br />

        ```sql
        SELECT *
        FROM helloworld.my_first_table
        ORDER BY timestamp
        ```

        응답이 보기 좋은 테이블 포맷으로 반환됩니다.

        ```response
        ┌─user_id─┬─message────────────────────────────────────────────┬───────────timestamp─┬──metric─┐
        │     102 │ Insert a lot of rows per batch                     │ 2022-03-21 00:00:00 │ 1.41421 │
        │     102 │ Sort your data based on your commonly-used queries │ 2022-03-22 00:00:00 │   2.718 │
        │     101 │ Hello, ClickHouse!                                 │ 2022-03-22 14:04:09 │      -1 │
        │     101 │ Granules are the smallest chunks of data read      │ 2022-03-22 14:04:14 │ 3.14159 │
        └─────────┴────────────────────────────────────────────────────┴─────────────────────┴─────────┘

        4 rows in set. Elapsed: 0.008 sec.
        ```

        4. [`FORMAT`](/ko/reference/statements/select/format) 절을 추가하여 [ClickHouse에서 지원하는 다양한 출력 형식](/ko/reference/formats/index) 중 하나를 지정합니다:

        <br />

        ```sql
        SELECT *
        FROM helloworld.my_first_table
        ORDER BY timestamp
        FORMAT TabSeparated
        ```

        위 쿼리의 출력은 탭으로 구분된 형식으로 반환됩니다:

        ```response
        Query id: 3604df1c-acfd-4117-9c56-f86c69721121

        102 Insert a lot of rows per batch      2022-03-21 00:00:00     1.41421
        102 Sort your data based on your commonly-used queries  2022-03-22 00:00:00     2.718
        101 Hello, ClickHouse!  2022-03-22 14:04:09     -1
        101 Granules are the smallest chunks of data read       2022-03-22 14:04:14     3.14159

        4 rows in set. Elapsed: 0.005 sec.
        ```

        5. `clickhouse client`를 종료하려면 **exit** 명령을 입력하십시오.

        <br />

        ```bash
        exit
        ```

### 파일 업로드 {#upload-a-file}

        데이터베이스를 처음 사용할 때 흔히 하는 작업 중 하나는 이미 파일로 가지고 있는 데이터를 삽입하는 것입니다. 온라인에 삽입해 볼 수 있는
        클릭스트림 샘플 데이터가 준비되어 있으며, 이 데이터에는 사용자 ID, 방문한 URL,
        이벤트 타임스탬프가 포함되어 있습니다.

        `data.csv`라는 CSV 파일에 다음과 같은 텍스트가 있다고 가정합니다.

        ```bash title="data.csv"
        102,This is data in a file,2022-02-22 10:43:28,123.45
        101,It is comma-separated,2022-02-23 00:00:00,456.78
        103,Use FORMAT to specify the format,2022-02-21 10:43:30,678.90
        ```

        1. 다음 명령은 `my_first_table`에 데이터를 삽입합니다:

        <br />

        ```bash
        ./clickhouse client --host HOSTNAME.REGION.CSP.clickhouse.cloud \
        --secure --port 9440 \
        --user default \
        --password <password> \
        --query='INSERT INTO helloworld.my_first_table FORMAT CSV' < data.csv
        ```

        2. 이제 SQL 콘솔에서 쿼리를 실행하면 테이블에 새 행(rows)이 추가된 것을 확인할 수 있습니다:
