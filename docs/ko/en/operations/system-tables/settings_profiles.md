<div id="description">
  ## 설명
</div>

구성된 설정 프로필의 속성이 포함됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 설정 프로필 이름입니다.
* `id` ([UUID](/ko/sql-reference/data-types/uuid)) — 설정 프로필 ID입니다.
* `storage` ([String](/ko/sql-reference/data-types/string)) — 설정 프로필 저장소의 경로입니다. `access_control_path` 매개변수에서 구성합니다.
* `num_elements` ([UInt64](/ko/sql-reference/data-types/int-uint)) — `system.settings_profile_elements` 테이블에서 이 프로필에 해당하는 요소 수입니다.
* `apply_to_all` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 모든 역할 및/또는 사용자에 이 설정 프로필이 설정되어 있음을 나타냅니다.
* `apply_to_list` ([Array(String)](/ko/sql-reference/data-types/array)) — 이 설정 프로필이 적용되는 역할 및/또는 사용자 목록입니다.
* `apply_to_except` ([Array(String)](/ko/sql-reference/data-types/array)) — 나열된 항목을 제외한 모든 역할 및/또는 사용자에 이 설정 프로필이 적용됩니다.

{/*AUTOGENERATED_END*/ }
