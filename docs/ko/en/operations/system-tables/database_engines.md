<div id="description">
  ## 설명
</div>

서버에서 지원하는 데이터베이스 엔진 목록입니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 엔진의 이름입니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 엔진이 수행하는 작업에 대한 개괄적인 설명입니다.
* `syntax` ([String](/ko/sql-reference/data-types/string)) — CREATE DATABASE 쿼리의 ENGINE 절에서 데이터베이스 엔진을 지정하는 방법입니다.
* `examples` ([String](/ko/sql-reference/data-types/string)) — 사용 예시입니다.
* `introduced_in` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 엔진이 처음 도입된 ClickHouse 버전이며, 형식은 major.minor입니다.
* `related` ([배열](/ko/sql-reference/data-types/array)([String](/ko/sql-reference/data-types/string))) — 관련된 데이터베이스 엔진의 이름입니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

```text title="Response"
┌─name─────┐
│ Atomic   │
│ Ordinary │
└──────────┘
```
