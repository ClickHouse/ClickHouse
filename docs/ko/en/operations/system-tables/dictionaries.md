<div id="description">
  ## 설명
</div>

[딕셔너리](../../sql-reference/statements/create/dictionary/overview.md)에 대한 정보를 제공합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — DDL query로 생성된 딕셔너리를 포함하는 데이터베이스의 이름입니다. 다른 딕셔너리의 경우 빈 문자열입니다.
* `name` ([String](/ko/sql-reference/data-types/string)) — 딕셔너리 이름입니다.
* `uuid` ([UUID](/ko/sql-reference/data-types/uuid)) — 딕셔너리 UUID입니다.
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/ko/sql-reference/data-types/enum)) — 딕셔너리 상태입니다. 가능한 값: NOT&#95;LOADED — 사용되지 않아 딕셔너리가 로드되지 않은 상태, LOADED — 딕셔너리가 성공적으로 로드된 상태, FAILED — 오류로 인해 딕셔너리를 로드할 수 없는 상태, LOADING — 딕셔너리를 현재 로드하는 중인 상태, LOADED&#95;AND&#95;RELOADING — 딕셔너리가 성공적으로 로드되었으며 현재 다시 로드하는 중인 상태(주요 원인: SYSTEM RELOAD DICTIONARY 쿼리, timeout, 딕셔너리 구성 변경), FAILED&#95;AND&#95;RELOADING — 오류로 인해 딕셔너리를 로드하지 못했으며 현재 다시 로드하는 중인 상태입니다.
* `origin` ([String](/ko/sql-reference/data-types/string)) — 딕셔너리를 설명하는 설정 파일의 경로입니다.
* `type` ([String](/ko/sql-reference/data-types/string)) — 딕셔너리 할당 유형입니다. 메모리에 딕셔너리를 저장합니다.
* `key.names` ([Array(String)](/ko/sql-reference/data-types/array)) — 딕셔너리가 제공하는 키 이름의 배열입니다.
* `key.types` ([Array(String)](/ko/sql-reference/data-types/array)) — 딕셔너리가 제공하는 해당 키 타입의 배열입니다.
* `attribute.names` ([Array(String)](/ko/sql-reference/data-types/array)) — 딕셔너리가 제공하는 속성 이름의 배열입니다.
* `attribute.types` ([Array(String)](/ko/sql-reference/data-types/array)) — 딕셔너리가 제공하는 해당 속성 타입의 배열입니다.
* `bytes_allocated` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 딕셔너리에 할당된 RAM 크기입니다.
* `hierarchical_index_bytes_allocated` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 계층형 인덱스에 할당된 RAM 크기입니다.
* `query_count` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 딕셔너리가 로드된 이후 또는 마지막으로 성공적으로 재시작된 이후의 쿼리 수입니다.
* `hit_rate` ([Float64](/ko/sql-reference/data-types/float)) — cache 딕셔너리의 경우, 값이 cache에 존재했던 사용 비율입니다.
* `found_rate` ([Float64](/ko/sql-reference/data-types/float)) — 값을 찾은 사용 비율입니다.
* `element_count` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 딕셔너리에 저장된 항목 수입니다.
* `load_factor` ([Float64](/ko/sql-reference/data-types/float)) — 딕셔너리가 채워진 비율입니다(해시된 딕셔너리의 경우 해시 테이블이 채워진 비율).
* `source` ([String](/ko/sql-reference/data-types/string)) — 딕셔너리의 데이터 소스를 설명하는 텍스트입니다.
* `lifetime_min` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 메모리 내 딕셔너리의 최소 lifetime이며, 이 시간이 지나면 ClickHouse가 딕셔너리 다시 로드를 시도합니다(`invalidate&#95;query`가 설정된 경우 변경된 경우에만 시도). 초 단위로 설정됩니다.
* `lifetime_max` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 메모리 내 딕셔너리의 최대 lifetime이며, 이 시간이 지나면 ClickHouse가 딕셔너리 다시 로드를 시도합니다(`invalidate&#95;query`가 설정된 경우 변경된 경우에만 시도). 초 단위로 설정됩니다.
* `loading_start_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 딕셔너리 로드를 시작한 시각입니다.
* `last_successful_update_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 딕셔너리 로드 또는 업데이트가 완료된 시각입니다. 딕셔너리 소스의 문제를 모니터링하고 원인을 조사하는 데 도움이 됩니다.
* `error_count` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 마지막으로 성공적으로 로드된 이후 발생한 오류 수입니다. 딕셔너리 소스의 문제를 모니터링하고 원인을 조사하는 데 도움이 됩니다.
* `loading_duration` ([Float32](/ko/sql-reference/data-types/float)) — 딕셔너리 로딩 시간입니다.
* `last_exception` ([String](/ko/sql-reference/data-types/string)) — 딕셔너리를 생성할 수 없는 경우, 딕셔너리 생성 또는 다시 로드 중 발생한 오류 텍스트입니다.
* `comment` ([String](/ko/sql-reference/data-types/string)) — 딕셔너리에 대한 comment 텍스트입니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

딕셔너리를 다음과 같이 구성합니다:

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

딕셔너리가 로드되었는지 확인하십시오.

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
