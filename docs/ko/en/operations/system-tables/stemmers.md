<div id="description">
  ## 설명
</div>

사용 가능한 모든 스템머를 표시합니다.
함수 [stem](../../sql-reference/functions/nlp-functions.md)에서 사용할 수 있습니다.

:::note 사용 가능 여부
`system.stemmers`는 `libstemmer` 종속성(`USE_LIBSTEMMER`)을 포함해 컴파일된 ClickHouse 빌드에만 존재합니다. 이 종속성이 없는 빌드에서는 테이블이 존재하지 않으며, 이에 대해 쿼리하면 `UNKNOWN_TABLE` 오류가 발생합니다. 빌드에서 이 기능이 활성화되어 있는지는 다음과 같이 확인할 수 있습니다.

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

컬럼:

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — Snowball 어간 추출기(언어/알고리즘)의 식별자

{/*AUTOGENERATED_END*/ }
