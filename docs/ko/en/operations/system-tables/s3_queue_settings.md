<div id="description">
  ## 설명
</div>

[S3Queue](../../engines/table-engines/integrations/s3queue.md) 테이블의 설정 정보를 제공합니다. 서버 버전 `24.10`부터 사용할 수 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — S3Queue engine을 사용하는 테이블의 데이터베이스.
* `table` ([String](/ko/sql-reference/data-types/string)) — S3Queue engine을 사용하는 테이블 이름.
* `name` ([String](/ko/sql-reference/data-types/string)) — 설정 이름.
* `value` ([String](/ko/sql-reference/data-types/string)) — 설정 값.
* `type` ([String](/ko/sql-reference/data-types/string)) — 설정 유형(구현별 문자열 값).
* `changed` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 설정이 구성에서 명시적으로 정의되었거나 명시적으로 변경된 경우 1입니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 설정 설명.
* `alterable` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 현재 사용자가 ALTER TABLE MODIFY SETTING을 통해 해당 설정을 변경할 수 있는지 나타냅니다: 0 — 현재 사용자는 설정을 변경할 수 없음, 1 — 현재 사용자는 설정을 변경할 수 있음.

{/*AUTOGENERATED_END*/ }
