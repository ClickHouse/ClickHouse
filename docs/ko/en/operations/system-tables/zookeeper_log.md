<div id="description">
  ## 설명
</div>

이 테이블에는 ZooKeeper 서버로 보내는 요청의 매개변수와 서버로부터 받은 응답에 대한 정보가 포함됩니다.

요청의 경우에는 요청 매개변수가 있는 컬럼만 채워지고, 나머지 컬럼은 기본값(`0` 또는 `NULL`)으로 채워집니다. 응답이 도착하면 응답 데이터가 다른 컬럼에 추가됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ko/sql-reference/data-types/lowcardinality)) — 쿼리를 실행하는 서버의 호스트명입니다.
* `type` ([Enum8(&#39;Request&#39; = 1, &#39;Response&#39; = 2, &#39;Finalize&#39; = 3)](/ko/sql-reference/data-types/enum)) — ZooKeeper 클라이언트의 이벤트 유형입니다. 다음 값 중 하나를 가질 수 있습니다: Request — 요청이 전송됨, Response — 응답이 수신됨, Finalize — 연결이 끊어져 응답을 받지 못함.
* `event_date` ([Date](/ko/sql-reference/data-types/date)) — 이벤트가 발생한 날짜입니다.
* `event_time` ([DateTime64(6)](/ko/sql-reference/data-types/datetime64)) — 이벤트가 발생한 날짜와 시간입니다.
* `thread_id` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 이 요청을 실행한 스레드의 ID입니다.
* `query_id` ([String](/ko/sql-reference/data-types/string)) — 이 요청이 실행된 범위의 쿼리 ID입니다.
* `address` ([IPv6](/ko/sql-reference/data-types/ipv6)) — 요청을 보내는 데 사용된 ZooKeeper server의 IP 주소입니다.
* `port` ([UInt16](/ko/sql-reference/data-types/int-uint)) — 요청을 보내는 데 사용된 ZooKeeper server의 포트입니다.
* `session_id` ([Int64](/ko/sql-reference/data-types/int-uint)) — 각 연결에 대해 ZooKeeper server가 설정하는 session ID입니다.
* `duration_microseconds` ([UInt64](/ko/sql-reference/data-types/int-uint)) — ZooKeeper가 요청을 처리하는 데 걸린 시간입니다.
* `xid` ([Int64](/ko/sql-reference/data-types/int-uint)) — session 내 요청의 ID입니다. 일반적으로 순차적인 요청 번호입니다. 요청 행과 여기에 대응하는 응답/finalize 행에서 동일합니다.
* `has_watch` ([UInt8](/ko/sql-reference/data-types/int-uint)) — watch가 설정되었는지 여부입니다.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/ko/sql-reference/data-types/enum)) — 요청 또는 응답의 유형입니다.
* `path` ([String](/ko/sql-reference/data-types/string)) — 요청에 지정된 ZooKeeper node의 경로이며, 요청에 경로를 지정할 필요가 없으면 빈 문자열입니다.
* `data` ([String](/ko/sql-reference/data-types/string)) — ZooKeeper node에 기록된 데이터입니다(SET 및 CREATE 요청의 경우 요청이 기록하려는 내용이고, GET 요청에 대한 응답의 경우 읽은 내용임). 또는 빈 문자열입니다.
* `is_ephemeral` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 생성되는 ZooKeeper node가 ephemeral인지 여부입니다.
* `is_sequential` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 생성되는 ZooKeeper 노드가 sequential로 생성되는지 여부입니다.
* `version` ([Nullable(Int32)](/ko/sql-reference/data-types/nullable)) — 실행 시 request가 기대하는 ZooKeeper 노드의 버전입니다. CHECK, SET, REMOVE request에서 지원됩니다(version을 검사하지 않는 request에서는 -1이고, 버전 검사를 지원하지 않는 다른 request에서는 NULL입니다).
* `requests_size` ([UInt32](/ko/sql-reference/data-types/int-uint)) — multi request에 포함된 request 수입니다(여러 개의 연속된 일반 request로 구성되어 원자적으로 실행되는 특수 request입니다). multi request에 포함된 모든 request는 동일한 xid를 가집니다.
* `request_idx` ([UInt32](/ko/sql-reference/data-types/int-uint)) — multi request에 포함된 request의 번호입니다(multi request의 경우 0, 그다음부터 순서대로 1입니다).
* `zxid` ([Int64](/ko/sql-reference/data-types/int-uint)) — ZooKeeper transaction ID입니다. request가 성공적으로 실행되면 ZooKeeper server가 응답으로 발급하는 일련번호입니다(request가 실행되지 않았거나, 오류를 반환했거나, 클라이언트가 request 실행 여부를 알 수 없는 경우 0입니다).
* `error` ([Nullable(Enum8(&#39;ZNOWATCHER&#39; = -121, &#39;ZNOTREADONLY&#39; = -119, &#39;ZSESSIONMOVED&#39; = -118, &#39;ZNOTHING&#39; = -117, &#39;ZCLOSING&#39; = -116, &#39;ZAUTHFAILED&#39; = -115, &#39;ZINVALIDACL&#39; = -114, &#39;ZINVALIDCALLBACK&#39; = -113, &#39;ZSESSIONEXPIRED&#39; = -112, &#39;ZNOTEMPTY&#39; = -111, &#39;ZNODEEXISTS&#39; = -110, &#39;ZNOCHILDRENFOREPHEMERALS&#39; = -108, &#39;ZBADVERSION&#39; = -103, &#39;ZNOAUTH&#39; = -102, &#39;ZNONODE&#39; = -101, &#39;ZAPIERROR&#39; = -100, &#39;ZOUTOFMEMORY&#39; = -10, &#39;ZINVALIDSTATE&#39; = -9, &#39;ZBADARGUMENTS&#39; = -8, &#39;ZOPERATIONTIMEOUT&#39; = -7, &#39;ZUNIMPLEMENTED&#39; = -6, &#39;ZMARSHALLINGERROR&#39; = -5, &#39;ZCONNECTIONLOSS&#39; = -4, &#39;ZDATAINCONSISTENCY&#39; = -3, &#39;ZRUNTIMEINCONSISTENCY&#39; = -2, &#39;ZSYSTEMERROR&#39; = -1, &#39;ZOK&#39; = 0))](/ko/sql-reference/data-types/nullable)) — 오류 코드입니다. 가능한 값은 많으며, 여기에는 그중 일부만 나와 있습니다. ZOK — request가 성공적으로 실행됨, ZCONNECTIONLOSS — connection이 끊어짐, ZOPERATIONTIMEOUT — request 실행 timeout이 만료됨, ZSESSIONEXPIRED — session이 만료됨, NULL — request가 완료됨.
* `watch_type` ([Nullable(Enum8(&#39;NOTWATCHING&#39; = -2, &#39;SESSION&#39; = -1, &#39;CREATED&#39; = 1, &#39;DELETED&#39; = 2, &#39;CHANGED&#39; = 3, &#39;CHILD&#39; = 4))](/ko/sql-reference/data-types/nullable)) — watch event의 유형입니다(`op_num = Watch`인 응답의 경우). 그 외 응답에서는 NULL입니다.
* `watch_state` ([Nullable(Enum16(&#39;AUTH&#95;FAILED&#39; = -113, &#39;EXPIRED&#95;SESSION&#39; = -112, &#39;CONNECTING&#39; = 1, &#39;ASSOCIATING&#39; = 2, &#39;CONNECTED&#39; = 3, &#39;READONLY&#39; = 5, &#39;NOTCONNECTED&#39; = 999))](/ko/sql-reference/data-types/nullable)) — watch event의 상태입니다(`op_num = Watch`인 응답의 경우). 그 외 응답에서는 NULL입니다.
* `path_created` ([String](/ko/sql-reference/data-types/string)) — 생성된 ZooKeeper node의 경로입니다(CREATE request에 대한 response). node가 sequential로 생성된 경우 `path`와 다를 수 있습니다.
* `stat_czxid` ([Int64](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node를 생성한 변경의 zxid입니다.
* `stat_mzxid` ([Int64](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node를 마지막으로 수정한 변경의 zxid입니다.
* `stat_pzxid` ([Int64](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node의 children을 마지막으로 수정한 변경의 transaction ID입니다.
* `stat_version` ([Int32](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node의 데이터 변경 횟수입니다.
* `stat_cversion` ([Int32](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node의 children 변경 횟수입니다.
* `stat_dataLength` ([Int32](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node의 데이터 field 길이입니다.
* `stat_numChildren` ([Int32](/ko/sql-reference/data-types/int-uint)) — 이 ZooKeeper node의 children 수입니다.
* `children` ([Array(String)](/ko/sql-reference/data-types/array)) — child ZooKeeper node 목록입니다(LIST request에 대한 response).

{/*AUTOGENERATED_END*/ }
