<div id="description">
  ## 설명
</div>

이 노드가 in-process ClickHouse Keeper를 실행하도록 구성되지 않은 경우 이 테이블은 존재하지 않습니다. 이 테이블에는 각 Raft 클러스터 멤버별로 1개의 행이 있으며, 정적 클러스터 토폴로지(Raft 구성에서 가져옴)와 로컬 노드 자체의 로그 위치가 함께 담겨 있습니다.

각 노드는 정확히 하나의 `last_log_index` 값만 채웁니다. 즉, 자체 `server_id`와 일치하는 행입니다. peer의 로그 위치는 여기에는 표시되지 않습니다. 해당 정보는 leader에서만 추적되며, 그 뷰는 클러스터 전체에서 대칭적이지 않기 때문입니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — 이 클러스터 멤버의 Raft 서버 ID입니다.
* `host` ([String](../../sql-reference/data-types/string.md)) — endpoint에서 파싱한 호스트입니다(마지막 콜론 앞의 prefix).
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — 구성에 지정된 원본 Raft endpoint입니다(`host:port`).
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — 이 멤버가 투표권이 없는 observer이고 `<can_become_leader>false</can_become_leader>`로 구성된 경우 `true`입니다.
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — 이 멤버의 Raft 우선순위입니다. leader election 중에는 값이 높을수록 우선됩니다.
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — 이 멤버가 현재 Raft leader인 경우 `true`입니다.
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — 이 행이 로컬 Keeper 노드를 나타내는 경우 `true`입니다.
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — 이 노드의 로컬 Raft 로그 저장소에 있는 가장 높은 로그 인덱스입니다. 현재 노드에 해당하는 행(`is_self = true`)에만 채워지며, 다른 행에서는 `NULL`입니다.

{/*AUTOGENERATED_END*/ }
