<div id="description">
  ## 설명
</div>

서버에서 지원하는 데이터 스키핑 인덱스 유형 목록과 각 타입에 대한 내장된 문서를 포함합니다. 데이터 스키핑 인덱스 유형은 `CREATE TABLE` 쿼리에서 `INDEX` 선언의 `TYPE`에 지정하며, 이를 통해 ClickHouse는 쿼리 조건과 일치할 수 없는 그래뉼을 건너뛸 수 있습니다.

이 테이블에는 사용 가능한 인덱스 *타입*이 나열되어 있지만, [`system.data_skipping_indices`](/ko/operations/system-tables/data_skipping_indices)에는 기존 테이블에 정의된 개별 인덱스 인스턴스가 나열되어 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — INDEX 선언의 TYPE에 지정되는 데이터 스키핑 인덱스 유형의 이름입니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 데이터 스키핑 인덱스 유형의 동작을 개괄적으로 설명합니다.
* `syntax` ([String](/ko/sql-reference/data-types/string)) — CREATE TABLE 쿼리의 INDEX 절에서 인덱스를 선언하는 방식입니다.
* `examples` ([String](/ko/sql-reference/data-types/string)) — 사용 예시입니다.
* `introduced_in` ([String](/ko/sql-reference/data-types/string)) — 인덱스 유형이 처음 도입된 ClickHouse 버전이며, 형식은 major.minor입니다.
* `related` ([배열](/ko/sql-reference/data-types/array)([String](/ko/sql-reference/data-types/string))) — 관련 데이터 스키핑 인덱스 유형의 이름입니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

```sql title="Query"
SELECT name, syntax
FROM system.data_skipping_index_types
WHERE name IN ('minmax', 'set')
ORDER BY name
```

```text title="Response"
┌─name───┬─syntax───────────────────────────────────────┐
│ minmax │ INDEX name expr TYPE minmax GRANULARITY n     │
│ set    │ INDEX name expr TYPE set(max_rows) GRANULARITY n │
└────────┴──────────────────────────────────────────────┘
```
