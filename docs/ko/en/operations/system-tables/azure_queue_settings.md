<div id="description">
  ## 설명
</div>

[AzureQueue](../../engines/table-engines/integrations/azure-queue.md) 테이블의 설정 정보를 포함합니다.
`24.10` server 버전부터 지원됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — AzureQueue 엔진을 사용하는 테이블의 데이터베이스입니다.
* `table` ([String](/ko/sql-reference/data-types/string)) — AzureQueue 엔진을 사용하는 테이블의 이름입니다.
* `name` ([String](/ko/sql-reference/data-types/string)) — 설정 이름입니다.
* `value` ([String](/ko/sql-reference/data-types/string)) — 설정 값입니다.
* `type` ([String](/ko/sql-reference/data-types/string)) — 설정 유형입니다(구현에 따라 달라지는 문자열 값).
* `changed` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 설정이 구성에서 명시적으로 정의되었거나 명시적으로 변경된 경우 1입니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 설정 설명입니다.
* `alterable` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 현재 사용자가 ALTER TABLE MODIFY SETTING을 통해 설정을 변경할 수 있는지 여부를 나타냅니다: 0 — 현재 사용자는 설정을 변경할 수 없습니다, 1 — 현재 사용자는 설정을 변경할 수 있습니다.

{/*AUTOGENERATED_END*/ }
