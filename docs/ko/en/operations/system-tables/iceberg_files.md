<div id="description">
  ## 설명
</div>

이 시스템 테이블(system table)에는 ClickHouse에 존재하는 Iceberg 테이블의 파일별 메타데이터가 들어 있으며, 각 테이블의 현재 스냅샷(current snapshot)에서 참조하는 데이터 파일 또는 삭제 파일마다 1개의 행이 있습니다. ClickHouse에 Iceberg 테이블이 하나도 없으면 이 테이블은 비어 있게 됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 이름.
* `table` ([String](/ko/sql-reference/data-types/string)) — 테이블 이름.
* `snapshot_id` ([Int64](/ko/sql-reference/data-types/int-uint)) — 파일이 추가된 시점의 스냅샷 ID.
* `content` ([Enum8](/ko/sql-reference/data-types/enum)) — 파일 콘텐츠 종류: `DATA`, `POSITION_DELETE` 또는 `EQUALITY_DELETE`.
* `file_path` ([String](/ko/sql-reference/data-types/string)) — 파일의 확인된 스토리지 경로.
* `file_format` ([String](/ko/sql-reference/data-types/string)) — 파일 포맷(예: `'PARQUET'`).
* `record_count` ([Int64](/ko/sql-reference/data-types/int-uint)) — 파일 내 레코드 수.
* `file_size_in_bytes` ([Int64](/ko/sql-reference/data-types/int-uint)) — 파일 크기(바이트).
* `partition` ([String](/ko/sql-reference/data-types/string)) — 파티션 튜플의 텍스트 표현.
* `schema_id` ([Int32](/ko/sql-reference/data-types/int-uint)) — 이 매니페스트 항목에 대해 확인된 schema ID.
* `sequence_number` ([Int64](/ko/sql-reference/data-types/int-uint)) — 매니페스트 항목의 확인된 시퀀스 번호(포맷 v1에서는 항상 0).
* `sort_order_id` ([Nullable(Int32)](/ko/sql-reference/data-types/nullable)) — 지정된 경우 파일의 정렬 순서 ID.
* `null_value_counts` ([Map(Int32, Int64)](/ko/sql-reference/data-types/map)) — 컬럼별 NULL 값 개수(컬럼 ID -&gt; 개수).
* `column_sizes` ([Map(Int32, Int64)](/ko/sql-reference/data-types/map)) — 컬럼별 디스크상 크기(바이트)(컬럼 ID -&gt; 바이트).
* `value_counts` ([Map(Int32, Int64)](/ko/sql-reference/data-types/map)) — 컬럼별 전체 값 개수(컬럼 ID -&gt; 개수).
* `equality_ids` ([Array(Int32)](/ko/sql-reference/data-types/array)) — equality delete 파일의 equality 필드 ID(비-equality-delete 파일에서는 비어 있음).
