<div id="description">
  ## 설명
</div>

사용 가능한 모든 토크나이저를 표시합니다.
이 토크나이저는 함수 [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens), [hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens), [hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens) 및 [텍스트 인덱스](../../engines/table-engines/mergetree-family/textindexes.md)에서 사용할 수 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 토크나이저 이름

{/*AUTOGENERATED_END*/ }

  ## 예시
</div>

```sql
SELECT * FROM system.tokenizers;
```
