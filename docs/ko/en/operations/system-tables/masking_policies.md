<div id="description">
  ## 설명
</div>

시스템에 정의된 모든 마스킹 정책에 대한 정보를 포함합니다.

마스킹 정책은 ClickHouse Cloud에서만 생성하고 적용할 수 있습니다. 오픈소스 빌드에서는 `system.masking_policies` 테이블이 항상 비어 있지만, `SHOW MASKING POLICIES`와 같은 내부 검사 쿼리가 예외를 발생시키지 않고 빈 결과를 반환할 수 있도록 이 테이블은 계속 존재합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string.md)) — 마스킹 정책의 이름입니다. 전체 이름 형식은 `short_name ON database.table`입니다.
* `short_name` ([String](/ko/sql-reference/data-types/string.md)) — 마스킹 정책의 축약 이름입니다. 예를 들어 전체 이름이 `mask_email ON mydb.mytable`이면 축약 이름은 `mask_email`입니다.
* `database` ([String](/ko/sql-reference/data-types/string.md)) — 데이터베이스 이름입니다.
* `table` ([String](/ko/sql-reference/data-types/string.md)) — 테이블 이름입니다.
* `id` ([UUID](/ko/sql-reference/data-types/uuid.md)) — 마스킹 정책 ID입니다.
* `storage` ([String](/ko/sql-reference/data-types/string.md)) — 마스킹 정책이 저장된 디렉터리 이름입니다.
* `update_assignments` ([Nullable(String)](/ko/sql-reference/data-types/nullable.md)) — 데이터를 어떻게 마스킹할지 정의하는 UPDATE 할당식입니다. 예: `email = '***masked***', phone = '***-***-****'`.
* `where_condition` ([Nullable(String)](/ko/sql-reference/data-types/nullable.md)) — 마스킹을 적용할 시점을 지정하는 선택적 WHERE 조건입니다.
* `priority` ([Int64](/ko/sql-reference/data-types/int-uint.md)) — 여러 마스킹 정책을 적용할 때의 우선순위입니다. 우선순위가 높은 정책부터 먼저 적용됩니다. 기본값은 0입니다.
* `apply_to_all` ([UInt8](/ko/sql-reference/data-types/int-uint.md)) — 마스킹 정책이 모든 역할 및/또는 사용자에게 적용되는지 여부를 나타냅니다. 참이면 1, 그렇지 않으면 0입니다.
* `apply_to_list` ([Array(String)](/ko/sql-reference/data-types/array.md)) — 마스킹 정책이 적용되는 역할 및/또는 사용자 목록입니다.
* `apply_to_except` ([Array(String)](/ko/sql-reference/data-types/array.md)) — 나열된 항목을 제외한 모든 역할 및/또는 사용자에게 마스킹 정책이 적용됩니다. `apply_to_all`이 1인 경우에만 값이 설정됩니다.

{/*AUTOGENERATED_END*/ }
