<div id="description">
  ## 설명
</div>

모든 포맷 목록과 함께, 각 포맷이 입력/출력에 적합한지 여부와 병렬화(parallelization) 지원 여부를 나타내는 플래그를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 포맷 이름.
* `is_input` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 해당 포맷이 데이터 입력에 적합한지 나타내는 플래그입니다.
* `is_output` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 해당 포맷이 데이터 출력에 적합한지 나타내는 플래그입니다.
* `supports_parallel_parsing` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 해당 포맷이 병렬 파싱을 지원하는지 나타내는 플래그입니다.
* `supports_parallel_formatting` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 해당 포맷이 병렬 포맷팅을 지원하는지 나타내는 플래그입니다.
* `is_tty_friendly` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 해당 포맷이 일반적으로 터미널에서 문제없이 표시되는지 나타내는 플래그입니다. 다른 포맷의 경우 출력 전에 CLI가 확인을 요청합니다.
* `content_type` ([String](/ko/sql-reference/data-types/string)) — 출력 형식에 해당하는 HTTP Content-Type입니다. 현재 포맷 설정에 따라 달라질 수 있습니다.
* `supports_random_access` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 해당 포맷이 입력에서 임의 접근을 지원하는지 나타내는 플래그입니다.
* `has_schema_inference` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 이 포맷은 데이터로부터 스키마를 동적으로 판별할 수 있습니다(내장된 헤더/메타데이터 또는 데이터 조각에서 판별).
* `has_external_schema` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 이 포맷은 고정된 스키마를 가지거나 자체 포맷에서 미리 정의된 스키마를 받습니다.
* `prefers_large_blocks` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 이 포맷은 출력 시 더 큰 블록을 기록하고 입력 시 더 큰 블록을 생성합니다.
* `supports_append` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 이 포맷에서는 단일 파일에 추가할 수 있습니다.
* `supports_subsets_of_columns` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 입력 포맷은 특정 컬럼이 생략된 경우를 인식할 수 있습니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 해당 포맷에 대한 개괄적인 설명입니다.
* `examples` ([String](/ko/sql-reference/data-types/string)) — 사용 예시.
* `introduced_in` ([String](/ko/sql-reference/data-types/string)) — 해당 포맷이 처음 도입된 ClickHouse 버전으로, 형식은 major.minor입니다.
* `related` ([Array](/ko/sql-reference/data-types/array)([String](/ko/sql-reference/data-types/string))) — 관련 포맷의 이름입니다.
