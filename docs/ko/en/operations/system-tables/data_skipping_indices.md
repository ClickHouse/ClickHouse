<div id="description">
  ## 설명
</div>

모든 테이블에 있는 데이터 스키핑 인덱스 정보를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 이름.
* `table` ([String](/ko/sql-reference/data-types/string)) — 테이블 이름.
* `name` ([String](/ko/sql-reference/data-types/string)) — 인덱스 이름.
* `type` ([String](/ko/sql-reference/data-types/string)) — 인덱스 유형.
* `type_full` ([String](/ko/sql-reference/data-types/string)) — CREATE 문의 인덱스 유형 표현식.
* `expr` ([String](/ko/sql-reference/data-types/string)) — 인덱스 계산용 표현식.
* `creation` ([Enum8(&#39;Explicit&#39; = 0, &#39;Implicit&#39; = 1)](/ko/sql-reference/data-types/enum)) — 인덱스가 암시적으로 생성되었는지 여부(add&#95;minmax&#95;index&#95;for&#95;numeric&#95;columns 또는 이와 유사한 방식을 통해)
* `granularity` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 블록의 그래뉼 수.
* `data_compressed_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 압축된 데이터의 크기(바이트).
* `data_uncompressed_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 압축 해제된 데이터의 크기(바이트).
* `marks_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 마크의 크기(바이트).

{/*AUTOGENERATED_END*/ }
