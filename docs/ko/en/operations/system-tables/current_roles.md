<div id="description">
  ## 설명
</div>

현재 사용자의 활성 역할이 들어 있습니다. `SET ROLE` 명령은 이 테이블의 내용을 변경합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/ko/sql-reference/data-types/string)) — 역할 이름.
* `with_admin_option` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 역할에 ADMIN OPTION 권한이 있으면 1입니다.
* `is_default` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 기본 역할로 설정되어 있으면 1입니다.
