<div id="description">
  ## 설명
</div>

모든 테이블의 컬럼 정보를 포함합니다.

이 테이블을 사용하면 [DESCRIBE TABLE](../../sql-reference/statements/describe-table.md) 쿼리와 유사한 정보를 여러 테이블에 대해 한 번에 가져올 수 있습니다.

[임시 테이블](../../sql-reference/statements/create/table.md#temporary-tables)의 컬럼은 생성된 세션에서만 `system.columns`에 표시됩니다. 이들은 `database` 필드가 비어 있는 상태로 표시됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 이름.
* `table` ([String](/ko/sql-reference/data-types/string)) — 테이블 이름.
* `name` ([String](/ko/sql-reference/data-types/string)) — 컬럼 이름.
* `type` ([String](/ko/sql-reference/data-types/string)) — 컬럼 타입.
* `position` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 테이블에서 컬럼의 순서상 위치로, 1부터 시작합니다.
* `default_kind` ([String](/ko/sql-reference/data-types/string)) — 기본값의 표현식 유형(DEFAULT, MATERIALIZED, ALIAS)이며, 정의되지 않은 경우 빈 문자열입니다.
* `default_expression` ([String](/ko/sql-reference/data-types/string)) — 기본값 표현식이며, 정의되지 않은 경우 빈 문자열입니다.
* `data_compressed_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 압축된 데이터의 크기(바이트).
* `data_uncompressed_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 압축 해제된 데이터의 크기(바이트).
* `marks_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 마크의 크기(바이트).
* `comment` ([String](/ko/sql-reference/data-types/string)) — 컬럼에 대한 주석이며, 정의되지 않은 경우 빈 문자열입니다.
* `is_in_partition_key` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 컬럼이 파티션 표현식에 포함되는지 나타내는 플래그입니다.
* `is_in_sorting_key` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 컬럼이 정렬 키 표현식에 포함되는지 나타내는 플래그입니다.
* `is_in_primary_key` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 컬럼이 프라이머리 키 표현식에 포함되는지 나타내는 플래그입니다.
* `is_in_sampling_key` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 컬럼이 샘플링 키 표현식에 포함되는지 나타내는 플래그입니다.
* `compression_codec` ([String](/ko/sql-reference/data-types/string)) — 압축 코덱 이름.
* `character_octet_length` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 바이너리 데이터, 문자 데이터, 텍스트 데이터 및 이미지의 최대 길이(바이트)입니다. ClickHouse에서는 FixedString 데이터 타입에만 의미가 있습니다. 그 외에는 NULL 값이 반환됩니다.
* `numeric_precision` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 근사 숫자 데이터, 정확한 숫자 데이터, 정수 데이터 또는 통화 데이터의 정밀도입니다. ClickHouse에서는 정수 타입의 비트 폭과 Decimal 타입의 정밀도를 의미합니다. 그 외에는 NULL 값이 반환됩니다.
* `numeric_precision_radix` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 근사 숫자 데이터, 정확한 숫자 데이터, 정수 데이터 또는 통화 데이터의 정밀도를 나타내는 수 체계의 밑수입니다. ClickHouse에서는 정수 타입은 2, Decimal 타입은 10입니다. 그 외에는 NULL 값이 반환됩니다.
* `numeric_scale` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 근사 숫자 데이터, 정확한 숫자 데이터, 정수 데이터 또는 통화 데이터의 스케일입니다. ClickHouse에서는 Decimal 타입에만 의미가 있습니다. 그 외에는 NULL 값이 반환됩니다.
* `datetime_precision` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — DateTime64 데이터 타입의 Decimal 정밀도입니다. 다른 데이터 타입에서는 NULL 값이 반환됩니다.
* `serialization_hint` ([Nullable(String)](/ko/sql-reference/data-types/nullable)) — 통계에 따라 삽입 시 직렬화를 선택할 수 있도록 컬럼에 제공되는 힌트입니다.
* `statistics` ([String](/ko/sql-reference/data-types/string)) — 이 컬럼에 생성된 통계의 타입입니다.

**별칭:**

* `column` — `name`의 별칭입니다.

{/*AUTOGENERATED_END*/ }
