<div id="description">
  ## 설명
</div>

사용 가능한 모든 집계 함수 조합자의 목록입니다. 이 조합자는 집계 함수에 적용하여 동작 방식을 변경할 수 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 조합자의 이름입니다.
* `is_internal` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 이 조합자가 내부 용도로만 사용되는지 여부입니다.
