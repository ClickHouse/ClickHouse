<div id="description">
  ## 설명
</div>

시스템에서 발생한 이벤트 수에 관한 정보를 제공합니다. 예를 들어 이 테이블에서는 ClickHouse 서버가 시작된 이후 처리된 `SELECT` 쿼리 수를 확인할 수 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/ko/sql-reference/data-types/string)) — 이벤트 이름입니다.
* `value` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 발생한 이벤트 수입니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 이벤트 설명입니다.

**별칭:**

* `name` — `event`의 별칭입니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

```sql
SELECT * FROM system.events LIMIT 5
```
