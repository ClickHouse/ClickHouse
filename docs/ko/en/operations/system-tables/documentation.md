<div id="description">
  ## 설명
</div>

시스템의 공통 구성 요소에 대한 내장 문서를 하나의 테이블에 모읍니다. 각 행은 하나의 엔터티(함수, 테이블 엔진, 데이터 유형 등)에 해당하며, 해당 엔터티의 참고 문서를 Markdown으로 렌더링한 내용을 담고 있습니다. 이는 웹사이트에 게시되고 종류별 `system.*` 테이블을 통해 제공되는 콘텐츠와 동일합니다.

`description`은 내장 문서의 구조화된 부분(`description`, `syntax`, 인자, 예제 등)으로 조합되므로, 하나의 컬럼에 엔터티의 전체 문서가 담깁니다. 별칭은 정식 엔터티에 대한 짧은 참조로 렌더링됩니다. 예: ``Alias of `trunc`.``

이 테이블은 일종의 통합된 형태로, 종류별 문서 테이블([`system.functions`](/ko/operations/system-tables/functions), [`system.table_engines`](/ko/operations/system-tables/table_engines), [`system.data_type_families`](/ko/operations/system-tables/data_type_families) 등)에서 제공되는 정보를 모아 둡니다. 특히 클라이언트의 대화형 `help` 명령을 지원하기 위한 용도이지만, 그 자체로도 유용합니다.

다음과 같은 종류의 엔터티가 수집됩니다(`type` 컬럼의 값은 괄호 안에 표시됨):

* 함수 (`Function`)
* 집계 함수 (`Aggregate Function`)
* 테이블 함수 (`Table Function`)
* 테이블 엔진 (`Table Engine`)
* 데이터베이스 엔진 (`Database Engine`)
* 데이터 유형 (`Data Type`)
* 딕셔너리 레이아웃 (`Dictionary Layout`)
* 딕셔너리 소스 (`Dictionary Source`)
* 집계 함수 조합자 (`Aggregate Function Combinator`)
* 데이터 스키핑 인덱스 유형 (`Data Skipping Index`)
* 디스크 유형 (`Disk Type`)
* 설정 (`Setting`)
* MergeTree 설정 (`MergeTree Setting`)
* 서버 설정 (`Server Setting`)
* 포맷 (`Format`)
* 압축 코덱 (`Compression Codec`)
* 프로파일 이벤트 (`Profile Event`)
* 현재 메트릭 (`Current Metric`)
* 비동기 메트릭 (`Asynchronous Metric`)
* 시스템 테이블 (`System Table`)

설정(종류와 무관하게)의 문서는 설정 설명과 해당 유형 및 기본값으로 구성되며, 더 이상 사용되지 않는 설정은 제공되지 않습니다. 시스템 테이블의 문서는 테이블 주석과 컬럼 목록(각 컬럼의 이름, 유형, 설명)으로 구성됩니다.

`source` 컬럼에는 엔터티 문서가 정의된 소스 파일의 경로가 담기며, 리포지토리 루트를 기준으로 한 상대 경로입니다. 대부분의 엔터티는 문서 객체가 생성되는 위치(구성 요소의 등록 위치)에서 자동으로 수집됩니다. 각 종류가 각각 하나의 소스 파일에서 문서화되는 경우(예: 설정, 프로파일 이벤트, 현재 메트릭)에는 해당 파일이 사용됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 엔터티의 이름입니다. 예: `domainWithoutWWW`, `MergeTree`.
* `type` ([Enum8](/ko/sql-reference/data-types/enum)) — 엔터티의 유형입니다. 예: `Function`, `Table Engine`.
* `description` ([String](/ko/sql-reference/data-types/string)) — 엔터티의 참고 문서로, Markdown으로 렌더링되며 내장 문서(웹사이트에 게시된 것과 동일한 내용)를 바탕으로 구성됩니다. 해당 문서에는 구문, 예시 및 기타 구조화된 부분이 포함될 수 있습니다.
* `source` ([String](/ko/sql-reference/data-types/string)) — 엔터티 문서가 정의된 소스 파일의 경로로, 리포지토리 루트를 기준으로 한 상대 경로입니다. 소스 위치를 알 수 없으면 비어 있습니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

특정 엔터티에 대한 문서를 참조하십시오:

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

같은 이름이 여러 종류의 엔터티를 가리킬 수 있으므로(예를 들어 `file` 테이블 함수와 `file` 딕셔너리 소스가 모두 있음), 모든 종류에서 해당 이름을 조회할 수 있으면 편리합니다:

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

각 Kind의 문서화된 엔터티 수를 계산합니다:

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
