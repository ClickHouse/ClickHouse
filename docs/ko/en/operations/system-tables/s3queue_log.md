S3Queue 엔진에서 처리한 파일 정보가 담긴 로그 항목을 포함합니다.

이 테이블은 언제든지 TRUNCATE하거나 삭제해도 안전합니다.

컬럼:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ko/sql-reference/data-types/lowcardinality)) — 호스트명
* `event_date` ([Date](/ko/sql-reference/data-types/date)) — 이 로그 행이 기록된 이벤트 날짜
* `event_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 이 로그 행이 기록된 이벤트 시각
* `database` ([String](/ko/sql-reference/data-types/string)) — 큐 테이블(`S3Queue` 또는 `AzureQueue`)이 속한 데이터베이스의 이름
* `table` ([String](/ko/sql-reference/data-types/string)) — 큐 테이블(`S3Queue` 또는 `AzureQueue`)의 이름
* `uuid` ([String](/ko/sql-reference/data-types/string)) — 큐 테이블(`S3Queue` 또는 `AzureQueue`)의 UUID
* `file_name` ([String](/ko/sql-reference/data-types/string)) — 처리 중인 파일의 이름
* `rows_processed` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 처리된 행 수
* `status` ([Enum8(&#39;Processed&#39; = 0, &#39;Failed&#39; = 1)](/ko/sql-reference/data-types/enum)) — 처리 파일의 상태
* `processing_start_time` ([Nullable(DateTime)](/ko/sql-reference/data-types/nullable)) — 파일 처리 시작 시각
* `processing_end_time` ([Nullable(DateTime)](/ko/sql-reference/data-types/nullable)) — 파일 처리 종료 시각
* `exception` ([String](/ko/sql-reference/data-types/string)) — 예외 발생 시의 예외 메시지
* `commit_id` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 이 파일이 커밋된 트랜잭션의 ID
* `commit_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — Keeper에서 파일이 커밋된 시각(실패 또는 처리 완료 상태로)
* `transaction_start_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 전체 처리 트랜잭션이 시작된 시각
* `get_object_time_ms` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 객체 스토리지에서 객체를 찾는 데 걸린 시간

{/*AUTOGENERATED_END*/ }
