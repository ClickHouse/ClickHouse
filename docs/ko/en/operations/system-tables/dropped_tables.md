<div id="description">
  ## 설명
</div>

`drop table`이 실행되었지만 아직 데이터 정리가 이루어지지 않은 테이블에 대한 정보를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt32](/ko/sql-reference/data-types/int-uint)) — marked&#95;dropped&#95;tables 큐 내 인덱스입니다.
* `database` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 이름입니다.
* `table` ([String](/ko/sql-reference/data-types/string)) — 테이블 이름입니다.
* `uuid` ([UUID](/ko/sql-reference/data-types/uuid)) — 테이블 UUID입니다.
* `engine` ([String](/ko/sql-reference/data-types/string)) — 테이블 엔진 이름입니다.
* `metadata_dropped_path` ([String](/ko/sql-reference/data-types/string)) — metadata&#95;dropped 디렉터리 내 테이블 메타데이터 파일의 경로입니다.
* `table_dropped_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 테이블 데이터 삭제를 다음으로 시도하도록 예약된 시간입니다. 일반적으로 테이블이 삭제된 시각에 `database_atomic_delay_before_drop_table_sec`를 더한 시간입니다.

{/*AUTOGENERATED_END*/ }
