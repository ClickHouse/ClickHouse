<div id="description">
  ## 설명
</div>

세그먼트로 전송 대기 중인 로컬 파일에 대한 정보를 포함합니다. 이러한 로컬 파일에는 비동기 모드에서 분산 테이블에 새 데이터를 삽입할 때 생성된 새 파트가 들어 있습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 이름입니다.
* `table` ([String](/ko/sql-reference/data-types/string)) — 테이블 이름입니다.
* `data_path` ([String](/ko/sql-reference/data-types/string)) — 로컬 파일이 있는 폴더의 경로입니다.
* `is_blocked` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 로컬 파일의 서버 전송이 차단되었는지 나타내는 플래그입니다.
* `error_count` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 오류 수입니다.
* `data_files` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 폴더 내 로컬 파일 수입니다.
* `data_compressed_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 로컬 파일에 있는 압축 데이터의 크기(바이트)입니다.
* `broken_data_files` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 오류로 인해 손상된 것으로 표시된 파일 수입니다.
* `broken_data_compressed_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 손상된 파일에 있는 압축 데이터의 크기(바이트)입니다.
* `last_exception` ([String](/ko/sql-reference/data-types/string)) — 마지막으로 발생한 오류에 대한 텍스트 메시지입니다(있는 경우).
* `last_exception_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 마지막 예외가 발생한 시간입니다.

{/*AUTOGENERATED_END*/ }
