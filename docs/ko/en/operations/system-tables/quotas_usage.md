  ## 설명

모든 사용자의 QUOTA 사용량입니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/ko/sql-reference/data-types/string)) — Quota 이름입니다.
* `quota_key` ([String](/ko/sql-reference/data-types/string)) — 키 값입니다.
* `is_current` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 현재 사용자의 할당량 사용량입니다.
* `start_time` ([Nullable(DateTime)](/ko/sql-reference/data-types/nullable)) — 리소스 활용을 계산하기 위한 시작 시간입니다.
* `end_time` ([Nullable(DateTime)](/ko/sql-reference/data-types/nullable)) — 리소스 활용을 계산하기 위한 종료 시간입니다.
* `duration` ([Nullable(UInt32)](/ko/sql-reference/data-types/nullable)) — 리소스 활용을 계산하기 위한 시간 인터벌의 길이로, 초 단위입니다.
* `queries` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 실행된 쿼리 수입니다.
* `max_queries` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 실행이 허용된 모든 유형의 쿼리 수의 최댓값입니다.
* `query_selects` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 실행된 SELECT 쿼리 수입니다.
* `max_query_selects` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 실행이 허용된 SELECT 쿼리 수의 최댓값입니다.
* `query_inserts` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 실행된 INSERT 쿼리 수입니다.
* `max_query_inserts` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 실행이 허용된 INSERT 쿼리 수의 최댓값입니다.
* `errors` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 오류가 발생한 쿼리의 현재 수입니다.
* `max_errors` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 오류가 발생할 수 있는 쿼리 수의 최댓값입니다.
* `result_rows` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 모든 쿼리 결과 집합의 총 행 수입니다.
* `max_result_rows` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 모든 쿼리 결과 집합의 총 행 수 최댓값입니다.
* `result_bytes` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 모든 쿼리 결과 집합의 총 바이트 수입니다.
* `max_result_bytes` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 모든 쿼리 결과 집합의 총 바이트 수 최댓값입니다.
* `read_rows` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 모든 쿼리 실행 중 읽은 총 행 수입니다.
* `max_read_rows` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 모든 쿼리 실행 중 읽을 수 있는 행 수의 최댓값입니다.
* `read_bytes` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 모든 쿼리 실행 중 읽은 총 바이트 수입니다.
* `max_read_bytes` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 모든 쿼리 실행 중 읽을 수 있는 바이트 수의 최댓값입니다.
* `execution_time` ([Nullable(Float64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 쿼리 실행에 소요된 총 시간(나노초)입니다
* `max_execution_time` ([Nullable(Float64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내 모든 쿼리 실행에 허용되는 최대 시간(나노초)입니다
* `written_bytes` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 모든 쿼리 실행 중 기록된 총 바이트 수입니다.
* `max_written_bytes` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 모든 쿼리 실행 중 기록될 수 있는 최대 바이트 수입니다.
* `failed_sequential_authentications` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 연속된 인증 실패의 현재 횟수입니다.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 연속 인증 실패의 최대 횟수입니다.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 현재 주기 내 단일 정규화 쿼리의 현재 최대 실행 횟수입니다.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ko/sql-reference/data-types/nullable)) — 지정된 주기 내에 허용되는 단일 정규화 쿼리의 최대 실행 횟수입니다.
