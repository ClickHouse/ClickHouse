<div id="description">
  ## 설명
</div>

이 시스템 테이블은 `SHOW PROCESSLIST` 쿼리를 구현하는 데 사용됩니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `is_initial_query` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 이 쿼리가 사용자로부터 직접 들어온 것인지, 아니면 분산 쿼리 실행 과정에서 ClickHouse 서버가 생성한 것인지를 나타냅니다.
* `user` ([String](/ko/sql-reference/data-types/string)) — 쿼리를 실행한 사용자입니다. 분산 처리에서는 쿼리가 원격 서버로 `default` 사용자로 전송된다는 점에 유의하십시오. 이 필드에는 이 쿼리가 시작한 쿼리의 사용자가 아니라, 해당 쿼리 자체의 사용자명이 들어 있습니다.
* `query_id` ([String](/ko/sql-reference/data-types/string)) — 정의되어 있는 경우 쿼리 ID입니다.
* `address` ([IPv6](/ko/sql-reference/data-types/ipv6)) — 쿼리가 실행된 클라이언트의 IP 주소입니다. 분산 처리에서도 동일합니다. 분산 쿼리가 원래 어디에서 실행되었는지 추적하려면, 쿼리 요청을 보낸 서버의 system.processes를 확인하십시오.
* `port` ([UInt16](/ko/sql-reference/data-types/int-uint)) — 쿼리가 실행된 클라이언트 포트입니다.
* `initial_user` ([String](/ko/sql-reference/data-types/string)) — 원본 쿼리를 실행한 사용자의 이름입니다(분산 쿼리 실행).
* `initial_query_id` ([String](/ko/sql-reference/data-types/string)) — 원본 쿼리의 ID입니다(분산 쿼리 실행).
* `initial_address` ([IPv6](/ko/sql-reference/data-types/ipv6)) — 상위 쿼리가 시작된 클라이언트의 IP 주소입니다.
* `initial_port` ([UInt16](/ko/sql-reference/data-types/int-uint)) — 상위 쿼리를 실행할 때 사용된 클라이언트 포트입니다.
* `interface` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 쿼리 전송에 사용된 인터페이스입니다. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/ko/sql-reference/data-types/string)) — `clickhouse-client`를 실행하는 운영체제 사용자명입니다.
* `client_hostname` ([String](/ko/sql-reference/data-types/string)) — `clickhouse-client` 또는 다른 TCP 클라이언트가 실행되는 클라이언트 머신의 호스트명입니다.
* `client_name` ([String](/ko/sql-reference/data-types/string)) — `clickhouse-client` 또는 다른 TCP 클라이언트의 이름입니다.
* `client_agent` ([LowCardinality(String)](/ko/sql-reference/data-types/lowcardinality)) — 클라이언트를 호출한 AI 코딩 에이전트입니다(예: `claude-code` 또는 `cursor`). 환경 변수에서 감지되며, 에이전트가 감지되지 않으면 비어 있습니다.
* `client_revision` ([UInt64](/ko/sql-reference/data-types/int-uint)) — `clickhouse-client` 또는 다른 TCP 클라이언트의 revision입니다.
* `client_version_major` ([UInt64](/ko/sql-reference/data-types/int-uint)) — `clickhouse-client` 또는 다른 TCP 클라이언트의 major version입니다.
* `client_version_minor` ([UInt64](/ko/sql-reference/data-types/int-uint)) — `clickhouse-client` 또는 다른 TCP 클라이언트의 minor version입니다.
* `client_version_patch` ([UInt64](/ko/sql-reference/data-types/int-uint)) — `clickhouse-client` 또는 다른 TCP 클라이언트 버전의 patch 구성 요소입니다.
* `http_method` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 쿼리를 시작한 HTTP 메서드입니다. 가능한 값: 0 — 쿼리가 TCP 인터페이스에서 시작되었습니다. 1 — GET 메서드가 사용되었습니다. 2 — POST 메서드가 사용되었습니다.
* `http_user_agent` ([String](/ko/sql-reference/data-types/string)) — HTTP 쿼리에서 전달된 UserAgent HTTP header입니다.
* `http_referer` ([String](/ko/sql-reference/data-types/string)) — HTTP 쿼리에서 전달된 Referer HTTP header입니다(쿼리를 실행한 페이지의 전체 또는 일부 주소를 포함합니다).
* `forwarded_for` ([String](/ko/sql-reference/data-types/string)) — HTTP 쿼리에서 전달된 X-Forwarded-For HTTP header입니다.
* `quota_key` ([String](/ko/sql-reference/data-types/string)) — 쿼터 설정에서 지정된 quota key입니다(keyed 참조).
* `distributed_depth` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 서버 노드 사이에서 내부적으로 쿼리가 재전송된 횟수입니다.
* `elapsed` ([Float64](/ko/sql-reference/data-types/float)) — 요청 실행이 시작된 후 경과한 시간(초)입니다.
* `is_cancelled` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 쿼리가 취소되었는지 여부입니다.
* `is_all_data_sent` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 모든 데이터가 클라이언트로 전송되었는지 여부입니다(즉, 서버에서 쿼리 실행이 완료되었음을 의미합니다).
* `read_rows` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 테이블에서 읽은 행 수입니다. 분산 처리에서는 요청을 보낸 server에서 이 값이 모든 원격 server의 총합을 나타냅니다.
* `read_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 테이블에서 읽은 비압축 바이트 수입니다. 분산 처리에서는 요청을 보낸 server에서 이 값이 모든 원격 server의 총합을 나타냅니다.
* `total_rows_approx` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 읽어야 하는 전체 행 수의 대략적인 값입니다. 분산 처리에서는 요청을 보낸 server에서 이 값이 모든 원격 server의 총합을 나타냅니다. 처리할 새로운 데이터 소스가 확인되면 요청 처리 중에 이 값이 갱신될 수 있습니다.
* `written_rows` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 스토리지에 기록된 행 수입니다.
* `written_bytes` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 스토리지에 기록된 바이트 수입니다.
* `memory_usage` ([Int64](/ko/sql-reference/data-types/int-uint)) — 쿼리가 사용하는 RAM 양입니다. 일부 전용 메모리 유형은 포함되지 않을 수 있습니다.
* `peak_memory_usage` ([Int64](/ko/sql-reference/data-types/int-uint)) — 현재 메모리 사용량의 최대치입니다.
* `query` ([String](/ko/sql-reference/data-types/string)) — 쿼리 텍스트입니다. INSERT의 경우 삽입할 데이터는 포함되지 않습니다.
* `normalized_query_hash` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 숫자 해시 값으로, 리터럴 값만 다른 쿼리들에서는 동일합니다.
* `query_kind` ([String](/ko/sql-reference/data-types/string)) — SELECT, INSERT 등 쿼리의 유형입니다.
* `thread_ids` ([Array(UInt64)](/ko/sql-reference/data-types/array)) — 이 쿼리에 참여한 모든 스레드 식별자 목록입니다.
* `peak_threads_usage` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 쿼리를 실행한 동시 스레드 수의 최댓값입니다.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ko/sql-reference/data-types/map)) — 이 쿼리에 대해 계산된 ProfileEvents입니다.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ko/sql-reference/data-types/map)) — 수정된 사용자 수준 설정 목록입니다.
* `current_database` ([String](/ko/sql-reference/data-types/string)) — 현재 데이터베이스의 이름입니다.
* `is_internal` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 내부적으로 실행된 보조 쿼리인지 여부를 나타냅니다.

**별칭:**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)`의 별칭입니다.
* `ProfileEvents.Values` — `mapValues(ProfileEvents)`의 별칭입니다.
* `Settings.Names` — `mapKeys(Settings)`의 별칭입니다.
* `Settings.Values` — `mapValues(Settings)`의 별칭입니다.
