<div id="description">
  ## 설명
</div>

AzureQueue 메타데이터와 파일별 현재 처리 중인 행에 대한 인메모리 상태를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/ko/sql-reference/data-types/string)) — 메타데이터의 ZooKeeper 경로
* `file_path` ([String](/ko/sql-reference/data-types/string)) — 처리 중인 파일의 파일 경로
* `file_name` ([String](/ko/sql-reference/data-types/string)) — 처리 중인 파일의 이름
* `rows_processed` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 현재까지 처리된 행 수
* `status` ([String](/ko/sql-reference/data-types/string)) — 처리 상태: Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/ko/sql-reference/data-types/nullable)) — 파일 처리가 시작된 시간
* `processing_end_time` ([Nullable(DateTime)](/ko/sql-reference/data-types/nullable)) — 파일 처리가 종료된 시간
* `exception` ([String](/ko/sql-reference/data-types/string)) — 처리 중 발생한 예외

{/*AUTOGENERATED_END*/ }
