<div id="description">
  ## 설명
</div>

각 복제된 데이터베이스 레플리카에 대한 정보를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ko/sql-reference/data-types/string)) — 복제된 데이터베이스의 이름입니다.
* `is_readonly` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 데이터베이스 레플리카가 읽기 전용 모드인지 여부입니다.
* `max_log_ptr` ([Int32](/ko/sql-reference/data-types/int-uint)) — 일반 활동 로그의 최대 entry 번호입니다.
* `replica_name` ([String](/ko/sql-reference/data-types/string)) — ClickHouse Keeper의 레플리카 이름입니다.
* `replica_path` ([String](/ko/sql-reference/data-types/string)) — ClickHouse Keeper에 있는 레플리카 데이터의 경로입니다.
* `zookeeper_path` ([String](/ko/sql-reference/data-types/string)) — ClickHouse Keeper에 있는 데이터베이스 데이터의 경로입니다.
* `shard_name` ([String](/ko/sql-reference/data-types/string)) — 클러스터 내 세그먼트의 이름입니다.
* `log_ptr` ([Int32](/ko/sql-reference/data-types/int-uint)) — 레플리카가 실행 큐에 복사한 일반 활동 로그의 최대 entry 번호에 1을 더한 값입니다.
* `total_replicas` ([UInt32](/ko/sql-reference/data-types/int-uint)) — 이 데이터베이스에 대해 알려진 전체 레플리카 수입니다.
* `zookeeper_exception` ([String](/ko/sql-reference/data-types/string)) — ClickHouse Keeper에서 정보를 가져오는 중 오류가 발생했을 때의 마지막 예외 메시지입니다.
* `is_session_expired` ([UInt8](/ko/sql-reference/data-types/int-uint)) — ClickHouse Keeper와의 세션이 만료되었는지 여부입니다. 기본적으로 `is_readonly`와 같습니다.

{/*AUTOGENERATED_END*/ }
