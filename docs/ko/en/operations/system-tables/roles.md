<div id="description">
  ## 설명
</div>

구성된 [역할](../../guides/sre/user-management/index.md#role-management) 정보를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 역할 이름.
* `id` ([UUID](/ko/sql-reference/data-types/uuid)) — 역할 ID.
* `storage` ([String](/ko/sql-reference/data-types/string)) — 역할 저장소 경로. `access_control_path` 매개변수에서 설정됩니다.
