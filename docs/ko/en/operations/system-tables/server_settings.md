<div id="description">
  ## 설명
</div>

`config.xml`에 지정된 서버의 전역 설정 정보를 포함합니다.
현재 이 테이블에는 `config.xml`의 최상위 계층에 있는 설정만 표시되며, 중첩된 구성(예: [로거](../../operations/server-configuration-parameters/settings.md#logger))은 지원하지 않습니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 서버 설정 이름입니다.
* `value` ([String](/ko/sql-reference/data-types/string)) — 서버 설정 값입니다.
* `default` ([String](/ko/sql-reference/data-types/string)) — 서버 설정 기본값입니다.
* `changed` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 설정이 config.xml에 지정되었는지 여부를 표시합니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 서버 설정에 대한 간단한 설명입니다.
* `type` ([String](/ko/sql-reference/data-types/string)) — 서버 설정 값의 유형입니다.
* `changeable_without_restart` ([Enum8(&#39;No&#39; = 0, &#39;IncreaseOnly&#39; = 1, &#39;DecreaseOnly&#39; = 2, &#39;Yes&#39; = 3)](/ko/sql-reference/data-types/enum)) — 설정을 런타임에 변경할 수 있는지 여부를 표시합니다.
* `is_obsolete` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 설정이 더 이상 사용되지 않는지 여부를 표시합니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

```sql
SELECT *
FROM system.server_settings
WHERE name LIKE '%thread_pool%'
```

예를 들어, 설정 파일의 설정이 올바르게 로드되어 실제로 사용되고 있는지 확인할 때 `WHERE changed`를 사용하면 유용합니다.

{/* */ }

```sql
SELECT * FROM system.server_settings WHERE changed AND name='max_thread_pool_size'
```
