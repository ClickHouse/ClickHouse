<div id="description">
  ## 설명
</div>

지원되는 [데이터 타입](../../sql-reference/data-types/index.md) 정보를 제공합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 데이터 타입 이름입니다.
* `case_insensitive` ([UInt8](/ko/sql-reference/data-types/int-uint)) — 쿼리에서 데이터 타입 이름을 대소문자를 구분하지 않고 사용할 수 있는지 보여주는 속성입니다. 예를 들어 `Date`와 `date`는 모두 유효합니다.
* `alias_to` ([String](/ko/sql-reference/data-types/string)) — `name`의 별칭 대상인 데이터 타입 이름입니다.
* `description` ([String](/ko/sql-reference/data-types/string)) — 데이터 타입에 대한 개괄적인 설명입니다.
* `syntax` ([String](/ko/sql-reference/data-types/string)) — 쿼리에서 데이터 타입을 표기하는 방식입니다.
* `examples` ([String](/ko/sql-reference/data-types/string)) — 사용 예시입니다.
* `introduced_in` ([String](/ko/sql-reference/data-types/string)) — 해당 데이터 타입이 처음 도입된 ClickHouse 버전이며, 형식은 major.minor입니다.
* `related` ([Array](/ko/sql-reference/data-types/array)([String](/ko/sql-reference/data-types/string))) — 관련 데이터 타입 이름입니다.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
