<div id="description">
  ## 설명
</div>

이 테이블에는 즉시 계산할 수 있으며 Prometheus 포맷으로 내보낼 수 있는 히스토그램 메트릭이 포함되어 있습니다. 항상 최신 상태를 유지합니다. 사용이 권장되지 않는 `system.latency_log`를 대체합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/ko/sql-reference/data-types/string)) — 메트릭 이름.
* `value` ([Float64](/ko/sql-reference/data-types/float)) — 메트릭 값.
* `description` ([String](/ko/sql-reference/data-types/string)) — 메트릭 설명.
* `labels` ([Map(String, String)](/ko/sql-reference/data-types/map)) — 메트릭 레이블.

**별칭:**

* `name` — `metric`의 별칭.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

다음과 같은 쿼리를 사용하면 모든 히스토그램 메트릭을 Prometheus 포맷으로 내보낼 수 있습니다.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'histogram' AS type
FROM system.histogram_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## 메트릭 설명
</div>

| 메트릭                                                          | 설명                                                                          |
| ------------------------------------------------------------ | --------------------------------------------------------------------------- |
| `keeper_response_time_ms_bucket`                             | Keeper의 응답 시간으로, 밀리초 단위입니다.                                                 |
| `keeper_client_queue_duration_milliseconds_bucket`           | 요청이 큐에 추가되기를 기다리고, Keeper 클라이언트에서 처리되기 전에 큐에서 대기하는 시간으로, 밀리초 단위입니다.         |
| `keeper_receive_request_time_milliseconds_bucket`            | Keeper TCP 핸들러에서 클라이언트의 요청을 수신하고 구문 분석하는 데 걸리는 시간으로, 밀리초 단위입니다.             |
| `keeper_dispatcher_requests_queue_time_milliseconds_bucket`  | 요청이 Keeper 디스패처 요청 큐에서 대기하는 시간으로, 밀리초 단위입니다.                                |
| `keeper_write_pre_commit_time_milliseconds_bucket`           | Raft commit 전에 쓰기 요청을 전처리하는 데 걸리는 시간으로, 밀리초 단위입니다.                          |
| `keeper_write_commit_time_milliseconds_bucket`               | Raft commit 후에 쓰기 요청을 처리하는 데 걸리는 시간으로, 밀리초 단위입니다.                           |
| `keeper_dispatcher_responses_queue_time_milliseconds_bucket` | 응답이 Keeper 디스패처 응답 큐에서 대기하는 시간으로, 밀리초 단위입니다.                                |
| `keeper_send_response_time_milliseconds_bucket`              | Keeper TCP 핸들러에서 클라이언트에 응답을 보내는 데 걸리는 시간(큐 대기 및 socket 쓰기 포함)으로, 밀리초 단위입니다. |
| `keeper_read_wait_for_write_time_milliseconds_bucket`        | 읽기 요청이 의존하는 쓰기 요청이 완료될 때까지 기다리는 시간으로, 밀리초 단위입니다.                            |
| `keeper_read_process_time_milliseconds_bucket`               | Keeper에서 읽기 요청을 처리하는 데 걸리는 시간으로, 밀리초 단위입니다.                                 |
| `keeper_batch_size_elements_bucket`                          | Raft로 전송되는 Batch 크기로, 요소 수 단위입니다.                                           |
| `keeper_batch_size_bytes_bucket`                             | Raft로 전송되는 Batch 크기로, 바이트 단위입니다.                                            |
| `filesystem_cache_evicted_segment_hits_bucket`               | 파일 세그먼트가 제거되는 시점의 캐시 적중 횟수 분포로, 캐시 이름별로 구분됩니다.                              |
| `filesystem_cache_evicted_segment_size_bytes_bucket`         | 제거된 파일 세그먼트의 바이트 크기 분포로, 캐시 이름별로 구분됩니다.                                     |
| `filesystem_cache_evicted_segment_hits_by_user_bucket`       | 제거된 파일 세그먼트의 캐시 적중 횟수 분포로, 캐시 이름과 사용자 ID별로 구분됩니다.                           |
| `filesystem_cache_evicted_segment_size_bytes_by_user_bucket` | 제거된 파일 세그먼트의 바이트 크기 분포로, 캐시 이름과 사용자 ID별로 구분됩니다.                             |
