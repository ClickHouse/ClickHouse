<div id="description">
  ## 설명
</div>

이 테이블에는 값이 0인 `dummy` UInt8 컬럼 1개만 있는 행 1개가 들어 있습니다.

`SELECT` 쿼리에 `FROM` 절이 지정되지 않으면 이 테이블이 사용됩니다.

이는 다른 DBMS에서 볼 수 있는 `DUAL` 테이블과 유사합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `dummy` ([UInt8](/ko/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 예시
</div>

```sql
SELECT * FROM system.one LIMIT 10;
```

```response
┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
```
