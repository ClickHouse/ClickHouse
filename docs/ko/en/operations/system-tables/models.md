<div id="description">
  ## 설명
</div>

LibraryBridge의 메모리에 로드된 CatBoost 모델 목록과 각 모델이 로드된 시각을 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `model_path` ([String](/ko/sql-reference/data-types/string)) — 학습된 모델의 경로입니다.
* `type` ([String](/ko/sql-reference/data-types/string)) — 모델 유형입니다. 현재는 catboost만 지원합니다.
* `loading_start_time` ([DateTime](/ko/sql-reference/data-types/datetime)) — 모델 로딩이 시작된 시각입니다.
* `loading_duration` ([Float32](/ko/sql-reference/data-types/float)) — 모델을 로드하는 데 걸린 시간입니다.
