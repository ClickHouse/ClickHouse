<div id="description">
  ## 설명
</div>

특정 테이블(table)에 대한 필터와 이 ROW POLICY를 사용해야 하는 역할 및/또는 사용자의 목록을 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — ROW POLICY의 이름입니다.
* `short_name` ([String](/ko/sql-reference/data-types/string)) — ROW POLICY의 축약 이름입니다. ROW POLICY의 이름은 복합 형태이며, 예를 들면 다음과 같습니다: myfilter ON mydb.mytable. 여기서 &#39;myfilter ON mydb.mytable&#39;은 ROW POLICY의 이름이고, &#39;myfilter&#39;은 축약 이름입니다.
* `database` ([String](/ko/sql-reference/data-types/string)) — 데이터베이스 이름입니다.
* `table` ([String](/ko/sql-reference/data-types/string)) — 테이블 이름입니다. 데이터베이스에 대한 정책이면 비어 있습니다.
* `id` ([UUID](/ko/sql-reference/data-types/uuid)) — ROW POLICY ID입니다.
* `storage` ([String](/ko/sql-reference/data-types/string)) — ROW POLICY이 저장된 디렉터리의 이름입니다.
* `select_filter` ([Nullable(String)](/ko/sql-reference/data-types/nullable)) — SELECT 쿼리에서 필터링에 사용되는 표현식입니다.
* `is_restrictive` ([UInt8](/ko/sql-reference/data-types/int-uint)) — ROW POLICY이 행에 대한 접근을 제한하는지 여부를 나타냅니다. 값: • 0 — ROW POLICY이 `AS PERMISSIVE` 절로 정의되었습니다. • 1 — ROW POLICY이 `AS RESTRICTIVE` 절로 정의되었습니다.
* `apply_to_all` ([UInt8](/ko/sql-reference/data-types/int-uint)) — ROW POLICY이 모든 역할 및/또는 사용자에 적용되도록 설정되었음을 나타냅니다.
* `apply_to_list` ([Array(String)](/ko/sql-reference/data-types/array)) — ROW POLICY이 적용되는 역할 및/또는 사용자의 목록입니다.
* `apply_to_except` ([Array(String)](/ko/sql-reference/data-types/array)) — 나열된 항목을 제외한 모든 역할 및/또는 사용자에게 ROW POLICY이 적용됩니다.

{/*AUTOGENERATED_END*/ }
