  ## 설명

SQL 쿼리로 생성되었거나 설정 파일에서 파싱된 모든 이름이 지정된 컬렉션 목록을 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 컬렉션 이름입니다.
* `collection` ([Map(String, String)](/ko/sql-reference/data-types/map)) — 컬렉션 내부 정보입니다.
* `source` ([String](/ko/sql-reference/data-types/string)) — 명명된 컬렉션의 소스입니다.
* `create_query` ([String](/ko/sql-reference/data-types/string)) — 명명된 컬렉션을 생성하는 CREATE 쿼리입니다.
