<div id="description">
  ## 설명
</div>

구성된 사용자 디렉터리(user directories), 즉 ClickHouse 서버가 사용자 제공 데이터를 읽을 수 있도록 허용된 파일 시스템상의 디렉터리에 대한 정보를 포함합니다.

<div id="columns">
  ## 컬럼
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ko/sql-reference/data-types/string)) — 디렉터리의 이름입니다.
* `type` ([String](/ko/sql-reference/data-types/string)) — 액세스 저장소의 유형입니다. 예: users.xml, replicated, memory 등입니다.
* `params` ([String](/ko/sql-reference/data-types/string)) — 액세스 저장소의 매개변수가 포함된 JSON입니다.
* `precedence` ([UInt64](/ko/sql-reference/data-types/int-uint)) — 이 디렉터리가 구성에 선언된 순서입니다. ClickHouse가 사용자 또는 역할을 찾을 때도 동일한 순서가 사용됩니다.

{/*AUTOGENERATED_END*/ }
