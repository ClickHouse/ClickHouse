<div id="untuple">
  ## untuple
</div>

호출되는 위치에서 [tuple](/ko/sql-reference/data-types/tuple) 요소를 구문적으로 치환합니다.

결과 컬럼 이름은 구현에 따라 달라질 수 있으며, 추후 변경될 수 있습니다. `untuple` 이후의 특정 컬럼 이름은 가정하지 마십시오.

**구문**

```sql
untuple(x)
```

`EXCEPT` 표현식을 사용하면 쿼리 결과에서 컬럼을 제외할 수 있습니다.

**인수**

* `x` — `tuple` 함수, 컬럼 또는 요소들로 이루어진 튜플입니다. [Tuple](../data-types/tuple.md).

**반환 값**

* 없음.

**예시**

입력 테이블:

```text
┌─key─┬─v1─┬─v2─┬─v3─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 20 │ 40 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 65 │ 70 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 30 │ 20 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 12 │  7 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 50 │ 70 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴────┴────┴───────────┘
```

`Tuple` 타입 컬럼을 `untuple` 함수의 매개변수로 사용하는 예시:

```sql title="Query"
SELECT untuple(v6) FROM kv;
```

```text title="Response"
┌─_ut_1─┬─_ut_2─┐
│    33 │ ab    │
│    44 │ cd    │
│    55 │ ef    │
│    66 │ gh    │
│    77 │ kl    │
└───────┴───────┘
```

`EXCEPT` 표현식 사용 예시:

```sql title="Query"
SELECT untuple((* EXCEPT (v2, v3),)) FROM kv;
```

```text title="Response"
┌─key─┬─v1─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴───────────┘
```
