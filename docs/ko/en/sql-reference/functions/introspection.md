이 장에서 설명하는 함수를 사용하면 쿼리 프로파일링을 위해 [ELF](https://en.wikipedia.org/wiki/Executable_and_Linkable_Format)와 [DWARF](https://en.wikipedia.org/wiki/DWARF)를 검사할 수 있습니다.

:::note
이 함수는 실행 속도가 느리며, 보안 측면에서 고려가 필요할 수 있습니다.
:::

인트로스펙션 함수가 올바르게 동작하려면 다음을 수행하십시오.

* `clickhouse-common-static-dbg` package를 설치하십시오.

* [allow&#95;introspection&#95;functions](../../operations/settings/settings.md#allow_introspection_functions) 설정을 1로 지정하십시오.

  보안상의 이유로 인트로스펙션 함수는 기본적으로 비활성화되어 있습니다.

ClickHouse는 프로파일러 보고서를 [trace&#95;log](/ko/operations/system-tables/trace_log) 시스템 테이블에 저장합니다. 테이블과 프로파일러가 올바르게 구성되어 있는지 확인하십시오.
