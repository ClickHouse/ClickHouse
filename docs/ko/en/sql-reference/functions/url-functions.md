  ## 개요
</div>

:::note
이 섹션에 언급된 함수는 최대 성능을 위해 최적화되어 있으며, 대부분 RFC-3986 표준을 따르지 않습니다.
RFC-3986을 구현한 함수는 함수 이름 끝에 `RFC`가 붙으며, 일반적으로 더 느립니다.
:::

공개 등록 도메인을 다룰 때 사용자 문자열이나 `@` 기호가 포함되지 않은 경우에는 일반적으로 비-`RFC` 함수 변형을 사용할 수 있습니다.
아래 표는 URL에서 각 `RFC` 및 비-`RFC` 변형이 어떤 기호를 parse할 수 있는지(`✔`) 또는 없는지(`✗`)를 보여줍니다.

| 기호          | non-`RFC` | `RFC` |   |
| ----------- | --------- | ----- | - |
| &#39; &#39; | ✗         | ✗     |   |
| \t          | ✗         | ✗     |   |
| &lt;        | ✗         | ✗     |   |
| &gt;        | ✗         | ✗     |   |
| %           | ✗         | ✔*    |   |
| &#123;      | ✗         | ✗     |   |
| &#125;      | ✗         | ✗     |   |
|             |           | ✗     | ✗ |
| &#92;&#92;  | ✗         | ✗     |   |
| ^           | ✗         | ✗     |   |
| ~           | ✗         | ✔*    |   |
| [           | ✗         | ✗     |   |
| ]           | ✗         | ✔     |   |
| ;           | ✗         | ✔*    |   |
| =           | ✗         | ✔*    |   |
| &amp;       | ✗         | ✔*    |   |

`*`로 표시된 기호는 RFC 3986의 하위 구분 기호(sub-delimiters)이며, `@` 기호 뒤에 오는 사용자 정보에 허용됩니다.

URL 함수에는 두 가지 타입이 있습니다.

* URL의 일부를 추출하는 함수. 해당 부분이 URL에 없으면 빈 문자열을 반환합니다.
* URL의 일부를 제거하는 함수. URL에 해당하는 부분이 없으면 URL은 변경되지 않습니다.

:::
