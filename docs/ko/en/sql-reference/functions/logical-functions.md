아래 함수는 임의의 숫자 타입 인수에 대해 논리 연산을 수행합니다.
이 함수는 [`UInt8`](../data-types/int-uint.md) 형식의 `0` 또는 `1`을 반환하며, 일부 경우에는 `NULL`을 반환합니다.

인수로 전달된 0은 `false`로 간주되며, 0이 아닌 값은 `true`로 간주됩니다.
