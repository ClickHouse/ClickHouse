이 섹션의 모든 함수는 인수를 0개 또는 1개 받습니다. 인수는 제공되더라도 [공통 하위 표현식
제거](/ko/sql-reference/functions/overview#common-subexpression-elimination)를 방지하는 용도로만 사용됩니다. 따라서 동일한 난수
함수를 같은 행에서 두 번 실행해도 서로 다른 난수 값을 반환합니다.

관련 콘텐츠

* 가이드: [ClickHouse에서 무작위 데이터 생성하기](/ko/guides/generating-test-data)
* 블로그: [ClickHouse에서 무작위 데이터 생성하기](https://clickhouse.com/blog/generating-random-test-distribution-data-for-clickhouse)

:::note
난수는 암호학적 목적이 아닌 알고리즘으로 생성됩니다.
:::

:::note
아래 문서는 `system.functions` 시스템 테이블에서 생성되었습니다.
:::
