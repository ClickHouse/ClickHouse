해시 함수는 요소를 결정론적 의사 난수 방식으로 섞는 데 사용할 수 있습니다.

Simhash는 해시 함수로, 서로 가까운(유사한) 인수에 대해 가까운 해시 값을 반환합니다.

대부분의 해시 함수는 타입에 관계없이 임의 개수의 인수를 받습니다.

:::note
NULL의 해시값은 NULL입니다. 널 허용(Nullable) 컬럼의 non-NULL 해시값을 얻으려면 이를 튜플로 감싸십시오:

```sql
SELECT cityHash64(tuple(NULL))
```

:::

:::note
테이블 전체 내용의 hash를 계산하려면 `sum(cityHash64(tuple(*)))`(또는 다른 hash function)를 사용하십시오. `tuple`은 NULL 값을 가진 행이 제외되지 않도록 합니다. `sum`은 행의 순서에 영향을 받지 않도록 합니다.
:::
