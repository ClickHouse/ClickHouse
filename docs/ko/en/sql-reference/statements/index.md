사용자는 SQL 문을 사용해 ClickHouse를 이용합니다. ClickHouse는 [SELECT](select/index.md), [CREATE](create/index.md)와 같은 일반적인 SQL 문을 지원할 뿐 아니라 [KILL](kill.md), [OPTIMIZE](optimize.md)와 같은 특수한 SQL 문도 제공합니다.
