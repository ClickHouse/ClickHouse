ClickHouse는 ClickHouse에 연결할 수 있는 다양한 네이티브 클라이언트와 인터페이스를 제공합니다.

자세한 내용은 아래 페이지를 참조하십시오.

| Section                                              | Summary                                                   |
| ---------------------------------------------------- | --------------------------------------------------------- |
| [clickhousectl](/ko/interfaces/cli)                     | ClickHouse용 CLI입니다. 로컬 및 Cloud를 지원합니다.                    |
| [ClickHouse Client](/ko/interfaces/client)              | command-line 옵션과 설정 파일을 지원하는 네이티브 command-line client입니다. |
| [Drivers &amp; Interfaces](/ko/interfaces/overview)     | 다양한 네트워크 인터페이스, 라이브러리, 시각적 인터페이스를 제공합니다.                  |
| [SQL Console](/ko/integrations/sql-clients/sql-console) | ClickHouse Cloud에서 데이터를 빠르고 쉽게 다룰 수 있는 방법입니다.             |
| [Web SQL UI (Play)](/ko/interfaces/web-sql)             | ClickHouse가 `/play`에서 제공하는 브라우저 기반 내장 SQL 인터페이스입니다.       |
