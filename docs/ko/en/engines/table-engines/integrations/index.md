ClickHouse는 테이블 엔진(table engines)을 비롯해 외부 시스템과 통합할 수 있는 다양한 수단을 제공합니다. 다른 모든 테이블 엔진과 마찬가지로 구성은 `CREATE TABLE` 또는 `ALTER TABLE` 쿼리를 사용해 수행합니다. 이렇게 구성된 통합은 사용자 관점에서는 일반 테이블처럼 보이지만, 이에 대한 쿼리는 외부 시스템으로 프록시되어 전달됩니다. 이러한 투명한 쿼리 방식은 사용할 때마다 별도의 쿼리 메서드를 써야 하는 딕셔너리나 테이블 함수 같은 다른 통합 방식에 비해 이 접근 방식의 주요 장점 중 하나입니다.
