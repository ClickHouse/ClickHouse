MergeTree 엔진 계열의 테이블 엔진은 ClickHouse 데이터 저장 기능의 핵심입니다. 이 엔진들은 복원력과 고성능 데이터 조회를 위한 대부분의 기능을 제공합니다. 예를 들어 열 지향 저장, 사용자 지정 파티셔닝, 희소 프라이머리 인덱스, 보조 데이터 스키핑 인덱스 등이 있습니다.

기본 [MergeTree](../../../engines/table-engines/mergetree-family/mergetree.md) 테이블 엔진은 단일 노드 ClickHouse 인스턴스의 기본 테이블 엔진으로 볼 수 있습니다. 다양한 사용 사례에 폭넓게 활용할 수 있고 실용적이기 때문입니다.

프로덕션 환경에서는 [ReplicatedMergeTree](../../../engines/table-engines/mergetree-family/replication.md)를 사용하는 것이 좋습니다. 일반 MergeTree 엔진의 모든 기능에 고가용성을 추가하기 때문입니다. 추가로, 데이터 수집 시 자동 데이터 중복 제거 기능도 제공하므로 삽입 중 네트워크 문제가 발생한 경우 소프트웨어가 안전하게 재시도할 수 있습니다.

MergeTree 엔진 계열의 다른 모든 엔진은 특정 사용 사례를 위한 추가 기능을 제공합니다. 보통 이러한 기능은 백그라운드에서 추가 데이터 조작을 수행하는 방식으로 구현됩니다.

MergeTree 엔진의 주요 단점은 다소 무겁다는 점입니다. 따라서 일반적으로 이런 엔진을 너무 많이 사용하지는 않습니다. 예를 들어 임시 데이터용으로 작은 테이블이 많이 필요하다면 [Log engine family](../../../engines/table-engines/log-family/index.md)를 고려하십시오.
