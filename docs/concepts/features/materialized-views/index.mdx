<Card title="Incremental materialized view" href="/concepts/features/materialized-views/incremental-materialized-view">
  Learn about the incremental materialized view which allows you to shift the cost of computation from query time to insert time, resulting in faster `SELECT` queries.
</Card>

<Card title="Refreshable materialized view" href="/concepts/features/materialized-views/cascading-materialized-views">
  Learn about the refreshable materialized view. They allow periodic execution of the query over the full dataset - the results of which are stored in a target table for querying.
</Card>

<Card title="Cascading materialized views" horizontal>
  Learn how to chain multiple materialized views together to build incremental data transformations.
</Card>
