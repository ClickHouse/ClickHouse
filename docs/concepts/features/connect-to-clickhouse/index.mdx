Choose the interface that best fits how you use ClickHouse. For application development, start with an official language client or driver. For interactive work, use a native or web-based tool. For direct integrations, use a network protocol. Before connecting, configure [network ports](/concepts/features/security/network-ports), [access rights](/concepts/features/security/access-rights), and [TLS](/concepts/features/security/tls/configuring-tls) as needed.
