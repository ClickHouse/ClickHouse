## Description {#description}

Contains information about existing data skipping indices in all the tables.

The `times_evaluated`, `granules_evaluated`, `granules_dropped` and `last_used_time` columns contain cumulative usage statistics of each index, similar to PostgreSQL's `pg_stat_user_indexes`. An index with `times_evaluated = 0` was never useful for any query since server start, which makes these columns the primary tool for finding unused indexes. The counters are kept in memory per server and are reset on server restart; on a cluster, aggregate them across replicas (for example, via `clusterAllReplicas`). A reading step counts as an evaluation only when the index was actually applied: queries whose filter cannot use the index do not change the counters, and neither does `EXPLAIN`. Skip indexes evaluated with the `per_part_index_stats` setting enabled are not counted.

## Columns {#columns}

<!--AUTOGENERATED_START-->
- `database` ([String](/sql-reference/data-types/string)) — Database name.
- `table` ([String](/sql-reference/data-types/string)) — Table name.
- `name` ([String](/sql-reference/data-types/string)) — Index name.
- `type` ([String](/sql-reference/data-types/string)) — Index type.
- `type_full` ([String](/sql-reference/data-types/string)) — Index type expression from create statement.
- `expr` ([String](/sql-reference/data-types/string)) — Expression for the index calculation.
- `creation` ([Enum8('Explicit' = 0, 'Implicit' = 1)](/sql-reference/data-types/enum)) — Whether the index was created implicitly (via add_minmax_index_for_numeric_columns or similar)
- `granularity` ([UInt64](/sql-reference/data-types/int-uint)) — The number of granules in the block.
- `data_compressed_bytes` ([UInt64](/sql-reference/data-types/int-uint)) — The size of compressed data, in bytes.
- `data_uncompressed_bytes` ([UInt64](/sql-reference/data-types/int-uint)) — The size of decompressed data, in bytes.
- `marks_bytes` ([UInt64](/sql-reference/data-types/int-uint)) — The size of marks, in bytes.
- `times_evaluated` ([UInt64](/sql-reference/data-types/int-uint)) — How many executed reading steps evaluated this index. In-memory counter per server, reset on server restart.
- `granules_evaluated` ([UInt64](/sql-reference/data-types/int-uint)) — Total number of granules this index was evaluated on. In-memory counter per server, reset on server restart.
- `granules_dropped` ([UInt64](/sql-reference/data-types/int-uint)) — Total number of granules this index dropped. In-memory counter per server, reset on server restart.
- `last_used_time` ([Nullable(DateTime)](/sql-reference/data-types/nullable)) — Time of the last evaluation of this index. NULL if the index was never evaluated since server start.
<!--AUTOGENERATED_END-->
