## Description {#description}

Contains the [column statistics](../../engines/table-engines/mergetree-family/mergetree.md#column-statistics)
stored in data parts of [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) tables.
Each row describes one column of one data part that has statistics; parts and columns without
statistics do not appear.

The values reflect the moment the statistics were built. In particular, rows removed by
lightweight deletes are not reflected, and statistics invalidated by a column type change
(`ALTER TABLE ... MODIFY COLUMN`) are not shown until they are rebuilt.

Querying this table without an `active` condition returns outdated parts as well.
It is recommended to filter by `database` and `table`: reading statistics of a part
may require disk access, so an unfiltered query on a server with many parts can be slow.

## Columns {#columns}

<!--AUTOGENERATED_START-->
- `database` ([String](/sql-reference/data-types/string)) — Name of the database.
- `table` ([String](/sql-reference/data-types/string)) — Name of the table.
- `engine` ([String](/sql-reference/data-types/string)) — Name of the table engine without parameters.
- `partition_id` ([String](/sql-reference/data-types/string)) — ID of the partition the data part belongs to.
- `name` ([String](/sql-reference/data-types/string)) — Name of the data part.
- `active` ([UInt8](/sql-reference/data-types/int-uint)) — Flag that indicates whether the data part is active. If a data part is active, it's used in a table. Otherwise, it's deleted. Inactive data parts remain after merging.
- `column` ([String](/sql-reference/data-types/string)) — Name of the column.
- `type` ([String](/sql-reference/data-types/string)) — Column type.
- `statistics` ([Array(String)](/sql-reference/data-types/array)) — Types of statistics present for the column in this data part, e.g. ['MinMax','Uniq'].
- `rows` ([UInt64](/sql-reference/data-types/int-uint)) — The number of rows the statistics were built over. May exceed the current number of rows in the data part if rows were removed by lightweight deletes after the statistics had been built.
- `min` ([Nullable(String)](/sql-reference/data-types/nullable)) — The minimum value of the column recorded in the statistics (from 'basic' or 'minmax' statistics), rendered as a string. NULL if not available.
- `max` ([Nullable(String)](/sql-reference/data-types/nullable)) — The maximum value of the column recorded in the statistics (from 'basic' or 'minmax' statistics), rendered as a string. NULL if not available.
- `cardinality` ([Nullable(UInt64)](/sql-reference/data-types/nullable)) — Estimated number of distinct values of the column (from 'uniq' statistics). NULL if not available.
- `null_count` ([Nullable(UInt64)](/sql-reference/data-types/nullable)) — The number of NULL values of the column recorded in the statistics (from 'basic' statistics on a Nullable column). NULL if not available.

**Aliases:**

- `part_name` — Alias for `name`.
<!--AUTOGENERATED_END-->

## Example {#example}

```sql
SELECT *
FROM system.part_statistics
WHERE database = 'default' AND table = 'hits' AND active
LIMIT 1
FORMAT Vertical;
```
