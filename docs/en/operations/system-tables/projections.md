## Description {#description}

Contains information about existing projections in all tables.

The `times_chosen` and `last_chosen_time` columns contain cumulative usage statistics of each projection. A projection with `times_chosen = 0` was never picked for any query since server start, which helps to find unused projections. The counters are kept in memory per server and are reset on server restart; on a cluster, aggregate them across replicas (for example, via `clusterAllReplicas`). A projection counts as chosen when a query reads from it instead of the table, or when it is used for part-level filtering; projections that were only analyzed as candidates do not count, and neither does `EXPLAIN`. Implicit projections (such as the internal min-max count projection) are not tracked.

## Columns {#columns}

<!--AUTOGENERATED_START-->
- `database` ([String](/sql-reference/data-types/string)) — Database name.
- `table` ([String](/sql-reference/data-types/string)) — Table name.
- `name` ([String](/sql-reference/data-types/string)) — Projection name.
- `type` ([Enum8('Normal' = 0, 'Aggregate' = 1)](/sql-reference/data-types/enum)) — Projection type.
- `sorting_key` ([Array(String)](/sql-reference/data-types/array)) — Projection sorting key.
- `query` ([String](/sql-reference/data-types/string)) — Projection query.
- `settings` ([Map(String, String)](/sql-reference/data-types/map)) — Projection settings.
- `times_chosen` ([UInt64](/sql-reference/data-types/int-uint)) — How many executed reading steps chose this projection: read it instead of the table or used it for part-level filtering. In-memory counter per server, reset on server restart.
- `last_chosen_time` ([Nullable(DateTime)](/sql-reference/data-types/nullable)) — Time when this projection was last chosen. NULL if the projection was never chosen since server start.
<!--AUTOGENERATED_END-->
