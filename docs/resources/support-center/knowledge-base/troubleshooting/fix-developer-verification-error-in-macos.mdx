## Fix the developer verification error in macOS {#fix-the-developer-verification-error-in-macos}

By default, macOS will not run an application or tool downloaded from the Internet unless it is signed by an identified developer and notarized by Apple.

The macOS builds of ClickHouse are signed with the Developer ID of ClickHouse Inc. and notarized by Apple, starting with the 26.7.4 release (and in every 26.8 and later release). They are published on the [GitHub releases page](https://github.com/ClickHouse/ClickHouse/releases) as `clickhouse-macos.zip` (Intel) and `clickhouse-macos-aarch64.zip` (Apple silicon), and the Homebrew cask installs them. If you use one of these, macOS runs `clickhouse` without any warning, and you don't need anything from this article.

You may still see the error if you run an unsigned binary that macOS has quarantined, for example:

- an older ClickHouse release installed with Homebrew - run `brew upgrade --cask clickhouse` to get the signed one;
- the self-extracting `clickhouse-macos` or `clickhouse-macos-aarch64` binary from the GitHub releases page, downloaded with a web browser - download the `.zip` file of the same release instead;
- a release older than 26.7.4, downloaded with a web browser.

The binary installed with `curl https://clickhouse.com/ | sh` is not signed, but `curl` does not quarantine the files it downloads, so macOS runs it without this error.

When attempting to run a quarantined `clickhouse` binary, you may see this error:

<Image img="/images/knowledgebase/fix-the-developer-verification-error-in-macos/dev-verification-error.webp" size="md" alt="MacOS developer verification error dialog" border />

If you can't switch to a signed build, remove the binary from the quarantine, either in System Settings or in the terminal.

## System Settings process {#system-settings-process}

1. Try to run the `clickhouse` binary once, so that macOS shows the error above and records the blocked binary.
1. Open **System Settings**.
1. Navigate to **Privacy & Security**:

    <Image img="/images/knowledgebase/fix-the-developer-verification-error-in-macos/privacy-and-security-default-view.webp" size="md" alt="MacOS Privacy & Security settings default view" border />

1. Scroll down to the **Security** section to find a message saying that _"clickhouse-macos-aarch64" was blocked from use because it is not from an identified developer_.
1. Click **Allow Anyway** (**Open Anyway** in recent macOS versions).

    <Image img="/images/knowledgebase/fix-the-developer-verification-error-in-macos/privacy-and-security-screen-allow-anyway.webp" size="md" alt="MacOS Privacy & Security settings showing Allow Anyway button" border />

1. Enter your macOS user password.

You should now be able to run `clickhouse` commands in your terminal. macOS may ask you to confirm once more on the next run.

## Terminal process {#terminal-process}

If the button in System Settings doesn't fix the issue, or you prefer the command line, remove the quarantine attribute from the binary with `xattr`.

If `clickhouse` is in your `PATH`, find out where it is:

```shell
which clickhouse
```

This should output something like:

```shell
/opt/homebrew/bin/clickhouse
```

Remove `clickhouse` from the quarantine by running `xattr -d com.apple.quarantine` followed by the path from the previous command:

```shell
xattr -d com.apple.quarantine /opt/homebrew/bin/clickhouse
```

You should now be able to run the `clickhouse` executable:

```shell
clickhouse
```

This should output something like:

```shell
Use one of the following commands:
clickhouse local [args]
clickhouse client [args]
clickhouse benchmark [args]
...
```
