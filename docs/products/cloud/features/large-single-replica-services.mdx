Large single-replica services let you run a ClickHouse Cloud service with one compute replica while using the configurable compute resources available on the Scale and Enterprise tiers. Unlike fixed-size Basic tier services, these services support vertical scaling.

## Availability {#availability}

Large single-replica services are available on the Scale and Enterprise tiers. Basic tier services also use a single replica, but are fixed at `8 GiB` or `12 GiB` of total memory and don't support vertical or horizontal scaling.

On the Scale and Enterprise tiers, you can create a primary or secondary service with one replica without contacting support. Services in a [warehouse](/products/cloud/features/infrastructure/warehouses) scale independently.

## When to use a single-replica service {#when-to-use-a-single-replica-service}

A large single-replica service can reduce compute costs for workloads that need more CPU or memory than a Basic tier service but don't require compute redundancy. It can also be useful for development, testing, batch processing, and other non-critical workloads.

<Warning>
Single-replica services have reduced availability and aren't recommended for production workloads that require high availability. Use at least two replicas for high availability.
</Warning>

## Scaling {#scaling}

Single-replica services on the Scale and Enterprise tiers support the same scaling controls as other services on those tiers:

- [Vertical autoscaling](/products/cloud/features/autoscaling/vertical) adjusts CPU and memory within the minimum and maximum resources you configure.
- [Horizontal scaling](/products/cloud/features/autoscaling/horizontal) lets you scale out to multiple replicas and scale back in to one replica.

Enterprise tier services with standard `1:4` profiles support vertical autoscaling. Custom Enterprise profiles don't support vertical autoscaling or manual vertical scaling through the Cloud Console, but support can scale them vertically.

## Service limits {#service-limits}

The Basic tier limits of `100` databases and `500` tables apply only to single-replica services in that tier. Single-replica services on the Scale and Enterprise tiers use the standard service guardrails. For details, see [Usage limits](/products/cloud/guides/best-practices/usagelimits).
