Public preview features are largely complete ClickHouse Cloud capabilities on a clear path to general availability (GA). They are available for customer feedback, but are not yet beta.

<Warning>
Public preview features may change and are not covered by the standard ClickHouse Cloud SLA.
</Warning>

## Enable public preview {#enable-public-preview}

1. Sign in to the Cloud console and select the correct organization.
2. Open the organization menu and select **Preview features**. You can also access it from the organization sidebar.
3. Find the feature, select **Learn more** to review its requirements and limitations, and then turn on its switch. If the switch is disabled, ask an organization admin to enable the feature.
4. Where available, use the **Go to...** or **View in...** service link to start using the feature.

<Note>
Availability depends on your organization's access and the feature's rollout. Not every public preview is available to every organization. Contact [Cloud Support](https://clickhouse.com/support/program) to check access.
</Note>
