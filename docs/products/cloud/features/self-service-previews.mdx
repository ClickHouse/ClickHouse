Use the **Preview features** page in ClickHouse Cloud to enable available public preview features and request access to available private preview features.

<Warning>
Preview features are still in development. They may change and are not covered by the standard ClickHouse Cloud SLA.
</Warning>

## Available preview features {#available-preview-features}

This list is sourced from ClickHouse Cloud and stays current as previews are added, changed, or removed.

<Note>

</Note>

## Enable public preview {#enable-public-preview}

1. Sign in to the Cloud console and select the correct organization.
2. Open the organization menu and select **Preview features**. You can also access it from the organization sidebar.
3. Find the feature, select **Learn more** to review its requirements and limitations, and then turn on its switch. If the switch is disabled, ask an organization admin to enable the feature.
4. Where available, use the **Go to...** or **View in...** service link to start using the feature.
5. To share feedback, select **Give feedback** next to the feature, choose **Thumbs up** if you would use the feature or **Thumbs down** if you would not, optionally add details in the text form and opt in to being contacted about the feedback, and select **Send feedback**.

## Enable private preview {#enable-private-preview}

1. Find the private preview feature and select **Learn more** to review its requirements and limitations.
2. Select **Request access**. This submits an access request; it does not enable the feature immediately. ClickHouse Cloud confirms when the request has been received.
3. After your request is approved and access is enabled, use the **Go to...** or **View in...** service link, where available, to start using the feature.
4. To share feedback, select **Give feedback** next to the feature, choose **Thumbs up** if you would use the feature or **Thumbs down** if you would not, optionally add details in the text form and opt in to being contacted about the feedback, and select **Send feedback**.
