# 2026 Changelog

### ClickHouse release v26.3.31.5-lts (45643f435eb) FIXME as compared to v26.3.30.9-lts (a7132c33074)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#117568](https://github.com/ClickHouse/ClickHouse/issues/117568): Fix a `Bad cast from type DB::ColumnSparse to DB::ColumnString` logical error (server abort in debug and sanitizer builds) when `groupConcat` is applied to a `Tuple` whose `String` element is stored sparse. [#108790](https://github.com/ClickHouse/ClickHouse/pull/108790) ([Groene AI](https://github.com/groeneai)).
* Backported in [#117867](https://github.com/ClickHouse/ClickHouse/issues/117867): Fixed a privilege-escalation gap where the `executable` table function did not enforce the `TABLE ENGINE ON Executable` grant. With `table_engines_require_grant` enabled, a user denied `CREATE TABLE ... ENGINE = Executable` could still run the same server-side script via `SELECT ... FROM executable(...)`. It now requires `GRANT TABLE ENGINE ON Executable`, matching `CREATE TABLE`. [#109331](https://github.com/ClickHouse/ClickHouse/pull/109331) ([Groene AI](https://github.com/groeneai)).
* Backported in [#114968](https://github.com/ClickHouse/ClickHouse/issues/114968): Fixed wrong results when a hash join has a single `LowCardinality` key of a type wider than 8 bytes (`UInt128`, `Int128`, `UInt256`, `Int256`, and their `Nullable` variants). Such a join silently returned rows whose key values are not equal. [#113230](https://github.com/ClickHouse/ClickHouse/pull/113230) ([Groene AI](https://github.com/groeneai)).
* Backported in [#118018](https://github.com/ClickHouse/ClickHouse/issues/118018): Fix a path traversal on `RESTORE`. A backup metadata entry whose `<name>` was not already in normal form, for example one containing `//` or fewer `..` than the depth of its own directory prefix, was validated in normalized form but stored verbatim, so restoring the part wrote the entry outside the part's directory while `RESTORE` reported success. Such names are now rejected with `INSECURE_PATH`. [#117371](https://github.com/ClickHouse/ClickHouse/pull/117371) ([Groene AI](https://github.com/groeneai)).
