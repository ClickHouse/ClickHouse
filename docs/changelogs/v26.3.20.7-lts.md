# 2026 Changelog

### ClickHouse release v26.3.20.7-lts (22647405581) FIXME as compared to v26.3.19.3-lts (5a1dec715af)

#### Improvement
* Backported in [#115214](https://github.com/ClickHouse/ClickHouse/issues/115214): The hive partitioning sample path for object storage tables (e.g. `S3`) is resolved on the first use of the table instead of `CREATE`/`ATTACH`, so an unreachable endpoint no longer blocks table creation and server startup. [#111842](https://github.com/ClickHouse/ClickHouse/pull/111842) ([Nikolay Degterinsky](https://github.com/evillique)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#115419](https://github.com/ClickHouse/ClickHouse/issues/115419): Fixed `singleValueOrNullMerge` returning a concrete value instead of `NULL` when merging a state that had already observed multiple distinct values. [#105734](https://github.com/ClickHouse/ClickHouse/pull/105734) ([Minh Vu](https://github.com/fallintoplace)).
* Backported in [#115284](https://github.com/ClickHouse/ClickHouse/issues/115284): Fixes cases where row policy was not used for MergeTree Projections during query execution. [#112329](https://github.com/ClickHouse/ClickHouse/pull/112329) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Backported in [#115208](https://github.com/ClickHouse/ClickHouse/issues/115208): Fix `DROP TABLE` and `SYSTEM STOP VIEW` hanging when a Refreshable Materialized View is blocked while planning its refresh query. [#113188](https://github.com/ClickHouse/ClickHouse/pull/113188) ([Nikolay Degterinsky](https://github.com/evillique)).
* Backported in [#115367](https://github.com/ClickHouse/ClickHouse/issues/115367): Disable distributed index analysis with projections (wrong results). [#115132](https://github.com/ClickHouse/ClickHouse/pull/115132) ([Azat Khuzhin](https://github.com/azat)).

#### Build/Testing/Packaging Improvement
* Backported in [#114700](https://github.com/ClickHouse/ClickHouse/issues/114700): Update `libssh` to 0.12.0. [#108329](https://github.com/ClickHouse/ClickHouse/pull/108329) ([Konstantin Bogdanov](https://github.com/thevar1able)).
