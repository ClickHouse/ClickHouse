# 2026 Changelog

### ClickHouse release v26.3.69.4-lts (414926d4672) FIXME as compared to v26.3.68.5-lts (e595b9ecc65)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#133352](https://github.com/ClickHouse/ClickHouse/issues/133352): Fixed a permanent `DROP TABLE` hang and memory leak after a query using a materialized CTE failed. The table stayed stuck in the drop queue until the server was restarted. [#113397](https://github.com/ClickHouse/ClickHouse/pull/113397) ([Shaohua Wang](https://github.com/tiandiwonder)).
* Backported in [#133196](https://github.com/ClickHouse/ClickHouse/issues/133196): Fix a crash (double free) when an allocation failed, e.g. because of the memory limit, while an aggregate function used as a window function moved to a new partition or frame, or while an aggregate function with the `-ArgMin` / `-ArgMax` combinator reset its state for a new extreme value. [#132755](https://github.com/ClickHouse/ClickHouse/pull/132755) ([Raúl Marín](https://github.com/Algunenano)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#133405](https://github.com/ClickHouse/ClickHouse/issues/133405): This patch changes the `isRemote` outcome for `DiskObjectStorage` over local object storage and improves local paths check for complex disks. [#110665](https://github.com/ClickHouse/ClickHouse/pull/110665) ([Mikhail Artemenko](https://github.com/Michicosun)).
