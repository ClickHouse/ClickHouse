# 2026 Changelog

### ClickHouse release v26.3.64.3-lts (3386d2ee171) FIXME as compared to v26.3.63.123-lts (f4eb235f165)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#131247](https://github.com/ClickHouse/ClickHouse/issues/131247): Fixed `ssd_cache` and `complex_key_ssd_cache` dictionaries that share a `PATH` returning each other's values from `dictGet`, and `Cache data corrupted` errors in queries that run during `SYSTEM RELOAD DICTIONARY` of an SSD cache dictionary. Each dictionary instance now creates its own cache file instead of truncating the file another instance may still be reading. [#122465](https://github.com/ClickHouse/ClickHouse/pull/122465) ([Groene AI](https://github.com/groeneai)).
* Backported in [#131648](https://github.com/ClickHouse/ClickHouse/issues/131648): Fix a crash and wrong query results when a table has a column literally named `mapKeys(m)` or `mapValues(m)` with a `bloom_filter` index on it. [#130814](https://github.com/ClickHouse/ClickHouse/pull/130814) ([Elmi Ahmadov](https://github.com/ahmadov)).
