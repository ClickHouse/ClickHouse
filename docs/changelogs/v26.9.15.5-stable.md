# 2026 Changelog

### ClickHouse release v26.9.15.5-stable (968d6e50d95) FIXME as compared to v26.9.14.10-stable (42bc9542943)

#### Performance Improvement
* Backported in [#124998](https://github.com/ClickHouse/ClickHouse/issues/124998): Faster sorted-stream processing on a multi-column key whose leading column has long runs, in `LIMIT BY`, negative `LIMIT BY`, `DISTINCT` in order, window functions (peer groups and `PARTITION BY` boundaries), `full_sorting_merge` and `partial_merge` `JOIN`, and `ReplacingMergeTree` `FINAL` without vertical `FINAL`: the run of a key prefix is now found once instead of again for every group in it. The query from [#123700](https://github.com/ClickHouse/ClickHouse/issues/123700) is about 3.5x faster. [#123808](https://github.com/ClickHouse/ClickHouse/pull/123808) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124897](https://github.com/ClickHouse/ClickHouse/issues/124897): Fix corrupted shared data of nested `JSON` objects after a failed attempt to parse a value during insert. It could lead to errors like `Unexpected version of JSON type binary encoding` or `Unknown type code` when reading the data after merges or when serializing it in binary formats. [#123898](https://github.com/ClickHouse/ClickHouse/pull/123898) ([Rory Shanks](https://github.com/rorylshanks)).
* Backported in [#124904](https://github.com/ClickHouse/ClickHouse/issues/124904): Fixed a query failing with an exception like `Cannot parse UInt64 from String` on a table with a text index on `mapKeys` or `JSONAllPaths`, when the predicate cannot be evaluated on the value of a missing map key or JSON path. [#124612](https://github.com/ClickHouse/ClickHouse/pull/124612) ([Anton Popov](https://github.com/CurtizJ)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#124949](https://github.com/ClickHouse/ClickHouse/issues/124949): Use `castStorage` for the `Join` row policy check in the legacy analyzer. [#124441](https://github.com/ClickHouse/ClickHouse/pull/124441) ([Vladimir Cherkasov](https://github.com/vdimir)).
