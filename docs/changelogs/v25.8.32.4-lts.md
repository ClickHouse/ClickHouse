# 2026 Changelog

### ClickHouse release v25.8.32.4-lts (46297556f3a) FIXME as compared to v25.8.31.9-lts (95bde92a2c1)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Fixed a use-after-free when a `LEFT JOIN` to a dictionary with `join_algorithm = 'direct'` had a join key that is serialized `Sparse`. `getColumnVectorData` returned a `PaddedPODArray` reference into a column owned only by a function-local `ColumnPtr`, so the dictionary lookup read freed memory. [#114814](https://github.com/ClickHouse/ClickHouse/pull/114814) ([Groene AI](https://github.com/groeneai)).
* Backported in [#115468](https://github.com/ClickHouse/ClickHouse/issues/115468): Fixed wrong results for `SELECT count(arrayJoin(arr))` with the default `optimize_trivial_count_query = 1`. The stored row count was returned instead of the number of array elements, and on `file()` and `url()` the query returned `0`. Closes [#115123](https://github.com/ClickHouse/ClickHouse/issues/115123). [#115227](https://github.com/ClickHouse/ClickHouse/pull/115227) ([Groene AI](https://github.com/groeneai)).
