# 2026 Changelog

### ClickHouse release v26.8.22.13-lts (cc72af4d4e9) FIXME as compared to v26.8.21.10-lts (e9b8ef33ed7)

#### Performance Improvement
* Backported in [#124732](https://github.com/ClickHouse/ClickHouse/issues/124732): ArrayElement and arraySlice now read lazily replicated arrays (produced by ARRAY JOIN and JOIN when enable_lazy_columns_replication is enabled) directly, without materializing them. This greatly reduces memory usage and improves performance of queries that index or slice a large array. [#112304](https://github.com/ClickHouse/ClickHouse/pull/112304) ([Diego Gomes Tomé](https://github.com/diegomestre2)).

#### Improvement
* Backported in [#124616](https://github.com/ClickHouse/ClickHouse/issues/124616): `bloom_filter` and text indexes are now used when a `Nullable` indexed column is cast to the non-`Nullable` type, such as `CAST(x, 'String')` or `json.path::String`. A query that would throw on a NULL value may not throw when the index skips the granules with NULL. [#124220](https://github.com/ClickHouse/ClickHouse/pull/124220) ([Anton Popov](https://github.com/CurtizJ)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124711](https://github.com/ClickHouse/ClickHouse/issues/124711): Fix reading bucketed runtime `Map` values from `JSON` columns using `advanced` shared-data serialization. [#118577](https://github.com/ClickHouse/ClickHouse/pull/118577) ([Rory Shanks](https://github.com/rorylshanks)).
* Backported in [#124848](https://github.com/ClickHouse/ClickHouse/issues/124848): Fix a possible heap buffer overflow on malformed responses from blob storage. [#119054](https://github.com/ClickHouse/ClickHouse/pull/119054) ([Arsen Muk](https://github.com/arsenmuk)).
* Backported in [#124836](https://github.com/ClickHouse/ClickHouse/issues/124836): Fix DeltaLake stats pruning with Date cast. [#119184](https://github.com/ClickHouse/ClickHouse/pull/119184) ([Arsen Muk](https://github.com/arsenmuk)).
* Backported in [#124250](https://github.com/ClickHouse/ClickHouse/issues/124250): Fix `EXPLAIN PLAN actions = 1` printing a secret function argument (for example the key of `HMAC` or `encrypt`) in cleartext when its value came from a subquery or from the other side of a JOIN. [#120371](https://github.com/ClickHouse/ClickHouse/pull/120371) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Backported in [#124627](https://github.com/ClickHouse/ClickHouse/issues/124627): Fix `INSERT` failing with `ILLEGAL_FINAL` or `SAMPLING_NOT_SUPPORTED` when a materialized view applies `FINAL` or `SAMPLE` to its own source table inside a subquery. Regression in [#122345](https://github.com/ClickHouse/ClickHouse/issues/122345). [#123514](https://github.com/ClickHouse/ClickHouse/pull/123514) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* Backported in [#124693](https://github.com/ClickHouse/ClickHouse/issues/124693): Fix a rare server crash (`SIGSEGV` in `mongoc_log`) when a MongoDB dictionary source or `MongoDB` table was created while another thread created the first MongoDB connection in the process. Messages logged by the MongoDB driver now go to the server log. [#124235](https://github.com/ClickHouse/ClickHouse/pull/124235) ([Vladimir Cherkasov](https://github.com/vdimir)).

#### Build/Testing/Packaging Improvement
* Backported in [#124663](https://github.com/ClickHouse/ClickHouse/issues/124663): CRoaring v5.2.3 exposes `internal_validate()` on the C++ `RoaringBitmap` wrappers, so RoaringBitmap data can be validated. [#124043](https://github.com/ClickHouse/ClickHouse/pull/124043) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#124756](https://github.com/ClickHouse/ClickHouse/issues/124756): Update `cctz` to 2026e. [#124249](https://github.com/ClickHouse/ClickHouse/pull/124249) ([Actuele AI](https://github.com/actueleai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#124783](https://github.com/ClickHouse/ClickHouse/issues/124783): Add test coverage for arrayElement compute-on-nested branches and simplify its type dispatch. [#114346](https://github.com/ClickHouse/ClickHouse/pull/114346) ([Diego Gomes Tomé](https://github.com/diegomestre2)).
* Backported in [#124811](https://github.com/ClickHouse/ClickHouse/issues/124811): Fixed a `LOGICAL_ERROR` in `arraySlice` on a `QBit` column replicated by `ARRAY JOIN` or a `JOIN`. [#120224](https://github.com/ClickHouse/ClickHouse/pull/120224) ([Groene AI](https://github.com/groeneai)).
