# 2026 Changelog

### ClickHouse release v26.9.38.8-stable (ec4e9eb591f) FIXME as compared to v26.9.37.5-stable (55b049682ce)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#133735](https://github.com/ClickHouse/ClickHouse/issues/133735): Fix the logical error `No set is registered for key` for a `SELECT` that reads a `Distributed` table through a `Merge` table or the `merge` table function and whose `GROUP BY`, `DISTINCT` or `LIMIT BY` key contains an `IN`-family function. [#117817](https://github.com/ClickHouse/ClickHouse/pull/117817) ([Groene AI](https://github.com/groeneai)).
* Backported in [#133652](https://github.com/ClickHouse/ClickHouse/issues/133652): Fixed `NOT_FOUND_COLUMN_IN_BLOCK` when merging a table that has a rows `TTL` together with a move (`TO DISK`, `TO VOLUME`) or recompression (`RECOMPRESS`) `TTL` over a different column. [#121536](https://github.com/ClickHouse/ClickHouse/pull/121536) ([Murphy](https://github.com/murphy-4o)).
* Backported in [#133679](https://github.com/ClickHouse/ClickHouse/issues/133679): Fixed `toUTCTimestamp` (`to_utc_timestamp`) returning a time one hour off for local times in the hours around a daylight saving time change, for both `DateTime` and `DateTime64`. It now converts a local time as `toDateTime(s, time_zone)` does, also a local time that happens twice or does not exist. Closes [#128266](https://github.com/ClickHouse/ClickHouse/issues/128266). [#128744](https://github.com/ClickHouse/ClickHouse/pull/128744) ([Groene AI](https://github.com/groeneai)).
* Backported in [#133751](https://github.com/ClickHouse/ClickHouse/issues/133751): Fixed a table with the `keeper_path` of another `S3Queue` or `AzureQueue` making it delete, move or tag its source files. The source must now match, and these actions need the `WRITE` grant. [#129383](https://github.com/ClickHouse/ClickHouse/pull/129383) ([Samuel Krempaský](https://github.com/NIKTONIKTO717)).
* Backported in [#133757](https://github.com/ClickHouse/ClickHouse/issues/133757): Fix a crash and incorrect results in the `CapnProto` format when the schema contains groups or named unions declared inline in a struct (`g :group { ... }`, `u :union { ... }`). [#133530](https://github.com/ClickHouse/ClickHouse/pull/133530) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

#### Build/Testing/Packaging Improvement
* Backported in [#133779](https://github.com/ClickHouse/ClickHouse/issues/133779): Fix a ppc64le bug where the bundled libunwind's `unw_getcontext` left callee-saved vector registers byte-swapped, which could make `clickhouse-server` fail to start intermittently. [#129808](https://github.com/ClickHouse/ClickHouse/pull/129808) ([Shichao Jin](https://github.com/jsc0218)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#131243](https://github.com/ClickHouse/ClickHouse/issues/131243): Fix SIGSEGV (in <26.10) when format_schema query reads a MongoDB table. [#131055](https://github.com/ClickHouse/ClickHouse/pull/131055) ([Azat Khuzhin](https://github.com/azat)).
