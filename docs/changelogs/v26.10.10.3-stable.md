# 2026 Changelog

### ClickHouse release v26.10.10.3-stable (875446283b0) FIXME as compared to v26.10.9.12-stable (bdfa0e7723a)

#### Performance Improvement
* Backported in [#133418](https://github.com/ClickHouse/ClickHouse/issues/133418): Automatic parallel replicas (`automatic_parallel_replicas_mode = 1`) no longer builds the plan with parallel replicas on every execution of a query whose last build ended without a decision: the execution after the first such build builds it again at once, and from then on one in every `automatic_parallel_replicas_undecided_retry_after_executions + 1` executions (default 10) does. [#130565](https://github.com/ClickHouse/ClickHouse/pull/130565) ([Nikita Taranov](https://github.com/nickitat)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#133311](https://github.com/ClickHouse/ClickHouse/issues/133311): Make `04413_documentation_no_indented_lines` linear in the number of lines. [#127390](https://github.com/ClickHouse/ClickHouse/pull/127390) ([Christoph Viebig](https://github.com/cv4g)).
