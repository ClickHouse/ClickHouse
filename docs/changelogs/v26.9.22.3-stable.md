# 2026 Changelog

### ClickHouse release v26.9.22.3-stable (3aba10ed64f) FIXME as compared to v26.9.21.9-stable (2a96c27fd3b)

#### Performance Improvement
* Backported in [#126580](https://github.com/ClickHouse/ClickHouse/issues/126580): An equality with a `Bool` value that no statistics can estimate, such as `WHERE j.f = false` on a JSON path, a `Bool` column without statistics, or `IN` with a `Bool` set, is now estimated to match half of the rows per value instead of 1%, so a join on such a filtered table builds its hash table from the smaller side again. [#125467](https://github.com/ClickHouse/ClickHouse/pull/125467) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#126618](https://github.com/ClickHouse/ClickHouse/issues/126618): Fixed crashes of the interactive line editor of `clickhouse-client` and `clickhouse-local`, which also crashed the server when used through the web terminal or an SSH session: after a history search that found nothing on an edited recalled query, when the prompt or the line given to an Alt-R history search contained a tab, when leaving a history search with a double-width character in the prompt (for example in the server's `display_name`), and on Ctrl-W or Alt-. after some non-ASCII characters. Closes [#126008](https://github.com/ClickHouse/ClickHouse/issues/126008). [#126120](https://github.com/ClickHouse/ClickHouse/pull/126120) ([Groene AI](https://github.com/groeneai)).
