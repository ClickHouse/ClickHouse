# 2026 Changelog

### ClickHouse release v26.10.12.13-stable (7c5cdd4d8bd) FIXME as compared to v26.10.11.12-stable (270407b6b9c)

#### Performance Improvement
* Backported in [#134067](https://github.com/ClickHouse/ClickHouse/issues/134067): Read columns of Compact part in the order of the file (to avoid backward seeks). [#131439](https://github.com/ClickHouse/ClickHouse/pull/131439) ([Azat Khuzhin](https://github.com/azat)).
* Backported in [#133926](https://github.com/ClickHouse/ClickHouse/issues/133926): `ORDER BY ... LIMIT` whose sorted input blocks are smaller than `max_block_size` re-merges its accumulated blocks again, as in 26.9, instead of switching the re-merge off after its first run, so its peak memory no longer grows with the input. On the query from [#131716](https://github.com/ClickHouse/ClickHouse/issues/131716) the peak goes from 1.38 GB back to about 260 MB, as in 26.8. `max_bytes_before_remerge_sort` now counts only the blocks accumulated since the previous re-merge, unless a spill to disk is due. Closes [#131716](https://github.com/ClickHouse/ClickHouse/issues/131716). [#132538](https://github.com/ClickHouse/ClickHouse/pull/132538) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#134058](https://github.com/ClickHouse/ClickHouse/issues/134058): Fix wrong results after external GROUP BY and max_rows_to_group_by>0 (can lead to excessive spills with `max_rows_to_group_by>0` and `group_by_overflow_mode=any`, but only in case of spilling limit is small). [#126249](https://github.com/ClickHouse/ClickHouse/pull/126249) ([Azat Khuzhin](https://github.com/azat)).
* Backported in [#133355](https://github.com/ClickHouse/ClickHouse/issues/133355): Iceberg tables created or written through `DataLakeCatalog` with `catalog_type = 'glue'` now register their columns in the Glue table definition, so they can be queried by Athena and other Glue consumers. Previously the Glue entry had an empty column list and Athena failed with `COLUMN_NOT_FOUND: Relation contains no accessible columns`. [#126924](https://github.com/ClickHouse/ClickHouse/pull/126924) ([Melvyn Peignon](https://github.com/melvynator)).
* Backported in [#133680](https://github.com/ClickHouse/ClickHouse/issues/133680): Fixed `toUTCTimestamp` (`to_utc_timestamp`) returning a time one hour off for local times in the hours around a daylight saving time change, for both `DateTime` and `DateTime64`. It now converts a local time as `toDateTime(s, time_zone)` does, also a local time that happens twice or does not exist. Closes [#128266](https://github.com/ClickHouse/ClickHouse/issues/128266). [#128744](https://github.com/ClickHouse/ClickHouse/pull/128744) ([Groene AI](https://github.com/groeneai)).
* Backported in [#133752](https://github.com/ClickHouse/ClickHouse/issues/133752): Fixed a table with the `keeper_path` of another `S3Queue` or `AzureQueue` making it delete, move or tag its source files. The source must now match, and these actions need the `WRITE` grant. [#129383](https://github.com/ClickHouse/ClickHouse/pull/129383) ([Samuel Krempaský](https://github.com/NIKTONIKTO717)).
* Backported in [#133899](https://github.com/ClickHouse/ClickHouse/issues/133899): Fix data loss in other subcolumns of a `Nested` column when a column TTL expires values of one of its subcolumns. [#129438](https://github.com/ClickHouse/ClickHouse/pull/129438) ([Lazizbek Ergashev](https://github.com/lazerg)).
* Backported in [#133758](https://github.com/ClickHouse/ClickHouse/issues/133758): Fix a crash and incorrect results in the `CapnProto` format when the schema contains groups or named unions declared inline in a struct (`g :group { ... }`, `u :union { ... }`). [#133530](https://github.com/ClickHouse/ClickHouse/pull/133530) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Backported in [#133852](https://github.com/ClickHouse/ClickHouse/issues/133852): `ATTACH MASKING POLICY` is no longer accepted as a query. It skipped the checks of `CREATE MASKING POLICY`. [#133748](https://github.com/ClickHouse/ClickHouse/pull/133748) ([Nikolay Degterinsky](https://github.com/evillique)).
* Backported in [#133884](https://github.com/ClickHouse/ClickHouse/issues/133884): The secret first key argument of "keyed" SipHash SQL functions is now masked in `system.query_log`. [#133828](https://github.com/ClickHouse/ClickHouse/pull/133828) ([Robert Schulze](https://github.com/rschu1ze)).

#### Build/Testing/Packaging Improvement
* Backported in [#133780](https://github.com/ClickHouse/ClickHouse/issues/133780): Fix a ppc64le bug where the bundled libunwind's `unw_getcontext` left callee-saved vector registers byte-swapped, which could make `clickhouse-server` fail to start intermittently. [#129808](https://github.com/ClickHouse/ClickHouse/pull/129808) ([Shichao Jin](https://github.com/jsc0218)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#134057](https://github.com/ClickHouse/ClickHouse/issues/134057): Do not consult the query condition cache under a masking policy. [#130148](https://github.com/ClickHouse/ClickHouse/pull/130148) ([Groene AI](https://github.com/groeneai)).
