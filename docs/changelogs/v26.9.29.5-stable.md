# 2026 Changelog

### ClickHouse release v26.9.29.5-stable (7dc8252760c) FIXME as compared to v26.9.28.166-stable (81a8d8988c2)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#130294](https://github.com/ClickHouse/ClickHouse/issues/130294): Fix a crash and wrong `TYPE_MISMATCH` or `CANNOT_CONVERT_TYPE` errors when `contingencyState`, `cramersVState`, `cramersVBiasCorrectedState` or `theilsUState` is used as a window function and its result goes through a spill to disk, a `CAST`, or a distributed query plan. `contingencyMapMerge` and the other `-MapMerge` functions of this family now work as window functions. [#128685](https://github.com/ClickHouse/ClickHouse/pull/128685) ([Alexander Gololobov](https://github.com/davenger)).
* Backported in [#131650](https://github.com/ClickHouse/ClickHouse/issues/131650): Fix a crash and wrong query results when a table has a column literally named `mapKeys(m)` or `mapValues(m)` with a `bloom_filter` index on it. [#130814](https://github.com/ClickHouse/ClickHouse/pull/130814) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#131646](https://github.com/ClickHouse/ClickHouse/issues/131646): On a cluster without an interserver secret, remote nodes now apply the row policies of the roles set by `SET ROLE` on the initiator, not of the default roles of the user. Original fix by @fm4v. [#131300](https://github.com/ClickHouse/ClickHouse/pull/131300) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#131502](https://github.com/ClickHouse/ClickHouse/issues/131502): Fix a server crash on a `Decimal` parameter with a scale above the maximum precision. [#131343](https://github.com/ClickHouse/ClickHouse/pull/131343) ([Konstantin Bogdanov](https://github.com/thevar1able)).
