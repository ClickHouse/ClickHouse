# 2026 Changelog

### ClickHouse release v26.9.32.8-stable (2a495269fe9) FIXME as compared to v26.9.31.21-stable (0ca4ad747b9)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#132548](https://github.com/ClickHouse/ClickHouse/issues/132548): Prevent impersonation via forged SECONDARY_QUERY on secret clusters. [#130362](https://github.com/ClickHouse/ClickHouse/pull/130362) ([Vitaly Baranov](https://github.com/vitlibar)).
* Backported in [#132385](https://github.com/ClickHouse/ClickHouse/issues/132385): Projections no longer provide `_block_number`, `_block_offset` and `_row_exists` unless they store them, so queries reading these columns use the main table. Previously the values came from the projection part, which caused wrong results and made incremental refreshable materialized views (`APPEND INCREMENTAL`) silently skip source rows. [#130515](https://github.com/ClickHouse/ClickHouse/pull/130515) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Backported in [#132471](https://github.com/ClickHouse/ClickHouse/issues/132471): The error of AI functions for an insecure endpoint no longer contains the endpoint of the named collection, which could carry a secret not visible to the user. [#131438](https://github.com/ClickHouse/ClickHouse/pull/131438) ([George Larionov](https://github.com/george-larionov)).
* Backported in [#132241](https://github.com/ClickHouse/ClickHouse/issues/132241): Fix a possible out-of-bounds read in the `Parquet` reader when `PREWHERE` filters out a whole page of a `PLAIN`-encoded string column read through a conversion (e.g. to `Geometry`). [#131797](https://github.com/ClickHouse/ClickHouse/pull/131797) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#132373](https://github.com/ClickHouse/ClickHouse/issues/132373): `SYSTEM SYNC DATABASE REPLICA` without `ON CLUSTER` now requires the `SYSTEM SYNC DATABASE REPLICA` grant on the database. Before, any user could run it. [#131893](https://github.com/ClickHouse/ClickHouse/pull/131893) ([Lazizbek Ergashev](https://github.com/lazerg)).
* Backported in [#132402](https://github.com/ClickHouse/ClickHouse/issues/132402): Fix an asynchronous `INSERT ... FROM INFILE` sent directly to the server opening the file on the server before the query was rejected. [#132305](https://github.com/ClickHouse/ClickHouse/pull/132305) ([Sema Checherinda](https://github.com/CheSema)).
* Backported in [#132461](https://github.com/ClickHouse/ClickHouse/issues/132461): Fix a server crash when deserializing a malformed aggregate state that contains a `LowCardinality(String)` value. [#132322](https://github.com/ClickHouse/ClickHouse/pull/132322) ([Raúl Marín](https://github.com/Algunenano)).
