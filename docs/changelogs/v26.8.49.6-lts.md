# 2026 Changelog

### ClickHouse release v26.8.49.6-lts (9c34133c0b8) FIXME as compared to v26.8.48.11-lts (db229ef0275)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#134788](https://github.com/ClickHouse/ClickHouse/issues/134788): Fixed the `LOGICAL_ERROR` `Reading from materialized CTE '...' before its materialization completed` raised by a lightweight `UPDATE`, or a lightweight `DELETE` in `lightweight_update_force` mode, whose predicate contains an `IN` subquery that defines a materialized CTE, when the set is built at run time. [#119489](https://github.com/ClickHouse/ClickHouse/pull/119489) ([Dmitry Novik](https://github.com/novikd)).
* Backported in [#134802](https://github.com/ClickHouse/ClickHouse/issues/134802): With `access_control_improvements.readonly_restricts_set_role` enabled, `SET DEFAULT ROLE` is now refused in `readonly` mode as well as `SET ROLE`. Previously a readonly session could change its own default roles and so start the next session with another role. [#133762](https://github.com/ClickHouse/ClickHouse/pull/133762) ([Vadim Skipin](https://github.com/vadimskipin)).
* Backported in [#134888](https://github.com/ClickHouse/ClickHouse/issues/134888): Fixed a heap-use-after-free in text index queries over overlapping parts, for example in a `FINAL` query with `use_skip_indexes_if_final_exact_mode = 0`. [#134226](https://github.com/ClickHouse/ClickHouse/pull/134226) ([Groene AI](https://github.com/groeneai)).

#### Build/Testing/Packaging Improvement
* Backported in [#134746](https://github.com/ClickHouse/ClickHouse/issues/134746): Update `krb5` from 1.22.2-final to 1.22.3-final. [#133845](https://github.com/ClickHouse/ClickHouse/pull/133845) ([Actuele AI](https://github.com/actueleai)).
* Backported in [#134796](https://github.com/ClickHouse/ClickHouse/issues/134796): Update `zstd` to v1.6.0. [#134248](https://github.com/ClickHouse/ClickHouse/pull/134248) ([Actuele AI](https://github.com/actueleai)).
