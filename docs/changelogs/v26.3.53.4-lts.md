# 2026 Changelog

### ClickHouse release v26.3.53.4-lts (d8af9de0b15) FIXME as compared to v26.3.52.9-lts (fe8ff5d492a)

#### Backward Incompatible Change
* Backported in [#125986](https://github.com/ClickHouse/ClickHouse/issues/125986): Overriding a key that is stored in a named collection now requires `SHOW NAMED COLLECTIONS SECRETS` on that collection. This also applies to overrides through an alias (including flat `kafka_*` settings over nested `kafka.*` keys), through a `SETTINGS` clause of a table engine or table function, and through keys in a dictionary source (checked when the dictionary is created). Resolving a relative `url` stored in a named collection against `s3_base` or `url_base` also counts as an override of `url`. Adding a key that the collection does not store remains allowed, and keys marked `NOT OVERRIDABLE` cannot be overridden. The `allow_named_collection_override_by_default` setting is obsolete. Existing tables whose `SETTINGS` or alias arguments override a `NOT OVERRIDABLE` key cannot be loaded after the upgrade, and the server does not start: before upgrading, recreate such tables without the override, or make the key overridable. [#123133](https://github.com/ClickHouse/ClickHouse/pull/123133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125819](https://github.com/ClickHouse/ClickHouse/issues/125819): Fixed loading, short `ATTACH`, and `UNDROP TABLE` for existing SQL-defined S3 disks whose endpoints are absent from `remote_url_allow_hosts`; new full-definition `CREATE` and `ATTACH` still reject disallowed endpoints. [#124930](https://github.com/ClickHouse/ClickHouse/pull/124930) ([Alexey Bakharew](https://github.com/alexbakharew)).
* Backported in [#125977](https://github.com/ClickHouse/ClickHouse/issues/125977): Fixed a possible segmentation fault when reading an Avro `map` into a `Map` column (for example `Map(DateTime, String)`) with the `AvroConfluent` format, including Kafka tables. Closes [#125457](https://github.com/ClickHouse/ClickHouse/issues/125457). [#125505](https://github.com/ClickHouse/ClickHouse/pull/125505) ([Groene AI](https://github.com/groeneai)).
