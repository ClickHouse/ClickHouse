# 2026 Changelog

### ClickHouse release v26.3.41.4-lts (bc541fda593) FIXME as compared to v26.3.40.16-lts (7a43e67d13f)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#123572](https://github.com/ClickHouse/ClickHouse/issues/123572): Fixed `SYSTEM SYNC TRANSACTION LOG` (local, non-`ON CLUSTER` form) not checking the `SYSTEM_SYNC_TRANSACTION_LOG` privilege. The `ON CLUSTER` form already required it via `getRequiredAccessForDDLOnCluster`, but the local execution path skipped `checkAccess`, so a user without the grant could run the command when experimental transactions were enabled. [#112441](https://github.com/ClickHouse/ClickHouse/pull/112441) ([Azhar Izzannada E](https://github.com/azharizz)).
* Backported in [#123736](https://github.com/ClickHouse/ClickHouse/issues/123736): Fix `LOGICAL_ERROR` `Cannot capture column N because it has incompatible type` when a materialized view with a lambda over an `Array(Tuple(...))` column receives a block while the source table's column type is being changed by `ALTER TABLE ... MODIFY COLUMN`. [#122345](https://github.com/ClickHouse/ClickHouse/pull/122345) ([Jimmy Aguilar Mena](https://github.com/Ergus)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#123668](https://github.com/ClickHouse/ClickHouse/issues/123668): Hide a `Backup` locator named like a `COLUMNS` matcher in `EXPLAIN AST` instead of throwing. [#122870](https://github.com/ClickHouse/ClickHouse/pull/122870) ([Groene AI](https://github.com/groeneai)).
