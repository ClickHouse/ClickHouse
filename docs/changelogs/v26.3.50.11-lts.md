# 2026 Changelog

### ClickHouse release v26.3.50.11-lts (94a03bb074b) FIXME as compared to v26.3.49.3-lts (53d2d2f4176)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125428](https://github.com/ClickHouse/ClickHouse/issues/125428): The collections of the Native protocol — the settings and the query parameters of a query, the client information, the granted roles and the table-status lists — are now bounded, so a small packet can no longer make the server allocate memory for data that has not arrived. [#117015](https://github.com/ClickHouse/ClickHouse/pull/117015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#125367](https://github.com/ClickHouse/ClickHouse/issues/125367): Fix reading bucketed runtime `Map` values from `JSON` columns using `advanced` shared-data serialization. [#118577](https://github.com/ClickHouse/ClickHouse/pull/118577) ([Rory Shanks](https://github.com/rorylshanks)).
* Backported in [#125356](https://github.com/ClickHouse/ClickHouse/issues/125356): Mask secrets in the queries that a cluster-mode `QueryRunner` table writes to `system.query_log` as well as in queries executed as startup scripts. [#118978](https://github.com/ClickHouse/ClickHouse/pull/118978) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Backported in [#125370](https://github.com/ClickHouse/ClickHouse/issues/125370): Fixed a crash on a query with a deeply nested `Dynamic` or `JSON` constant. [#120885](https://github.com/ClickHouse/ClickHouse/pull/120885) ([Pavel Kruglov](https://github.com/Avogar)).
* Backported in [#124656](https://github.com/ClickHouse/ClickHouse/issues/124656): Reject malformed serialized `groupBitmap` states with `INCORRECT_DATA` instead of failing later during bitmap operations. [#124049](https://github.com/ClickHouse/ClickHouse/pull/124049) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#125300](https://github.com/ClickHouse/ClickHouse/issues/125300): Fixed excessive memory usage when loading a data part with a corrupted `columns_substreams.txt`; such a part is now detached as broken. [#124157](https://github.com/ClickHouse/ClickHouse/pull/124157) ([Murphy](https://github.com/murphy-4o)).
* Backported in [#125355](https://github.com/ClickHouse/ClickHouse/issues/125355): Update `mongo-c-driver` to 2.5.5, fixing an out-of-bounds write during MongoDB connection monitoring reconnects (CVE-2026-96746). [#124282](https://github.com/ClickHouse/ClickHouse/pull/124282) ([Actuele AI](https://github.com/actueleai)).
* Backported in [#125479](https://github.com/ClickHouse/ClickHouse/issues/125479): Fixed a heap use-after-free in the `s3`, `azureBlobStorage`, `hdfs` and other object storage table functions and engines when an exception (for example `MEMORY_LIMIT_EXCEEDED`) was thrown while creating the reader of a file in a row input format such as `CSV`. [#125090](https://github.com/ClickHouse/ClickHouse/pull/125090) ([Groene AI](https://github.com/groeneai)).
* Backported in [#125483](https://github.com/ClickHouse/ClickHouse/issues/125483): Fixed a server crash, wrong results or a rejected query in `ORDER BY ... WITH FILL ... INTERPOLATE` when one `INTERPOLATE` expression has to be converted to its target's type and another item reads the same column or literal, for example `INTERPOLATE (a AS b, b AS a)` with targets of different types. [#125129](https://github.com/ClickHouse/ClickHouse/pull/125129) ([Groene AI](https://github.com/groeneai)).

#### Build/Testing/Packaging Improvement
* Backported in [#125335](https://github.com/ClickHouse/ClickHouse/issues/125335): Update `thrift` to v0.25.0. [#124280](https://github.com/ClickHouse/ClickHouse/pull/124280) ([Actuele AI](https://github.com/actueleai)).
