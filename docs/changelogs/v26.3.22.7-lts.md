# 2026 Changelog

### ClickHouse release v26.3.22.7-lts (ff4a967c271) FIXME as compared to v26.3.21.7-lts (eab23fa14e8)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#114797](https://github.com/ClickHouse/ClickHouse/issues/114797): Fixed a use-after-free when a `JOIN` with `join_algorithm = 'direct'` onto a dictionary was given a join key that is stored with sparse serialization. `getColumnVectorData` returned a reference to a temporary column, so the dictionary lookup read freed memory: release builds could return wrong results and debug or sanitizer builds aborted. [#112327](https://github.com/ClickHouse/ClickHouse/pull/112327) ([Groene AI](https://github.com/groeneai)).
* Backported in [#115438](https://github.com/ClickHouse/ClickHouse/issues/115438): Reject corrupted/malicious dictionary where `lcp` exceeds the previous token or `lcp + data_size` overflows, before the buffer write. [#114155](https://github.com/ClickHouse/ClickHouse/pull/114155) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#116147](https://github.com/ClickHouse/ClickHouse/issues/116147): Fixed a row policy bypass where the mergeTreeIndex table function exposed primary key and minmax index values of the rows hidden by a SELECT row policy on the source table; reading mergeTreeIndex for a table with a row policy is now denied. [#115304](https://github.com/ClickHouse/ClickHouse/pull/115304) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Backported in [#115728](https://github.com/ClickHouse/ClickHouse/issues/115728): Fixed a bug in the function `formatRowNoNewline` that could produce incorrect results or a logical error when a row is formatted to an empty result. [#115669](https://github.com/ClickHouse/ClickHouse/pull/115669) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#116110](https://github.com/ClickHouse/ClickHouse/issues/116110): Add Objects' paths to deduplication hashing, preventing incorrect deduplication. [#115866](https://github.com/ClickHouse/ClickHouse/pull/115866) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#115240](https://github.com/ClickHouse/ClickHouse/issues/115240): This patch: 1. Removes the global error screen (blue screen) and replaces it with a note above the dashboards. In this approach, on any error, already fetched graphs will not be hidden. 2. Dashboard now opens the graphs view immediately. 3. Reload button and any other button can be pressed during runtime refresh - this will cancel all in-flight queries and start a new refresh with the new configuration immediately. 4. Newly added graphs do not trigger a full page refresh; only new graphs will be fetched. [#115019](https://github.com/ClickHouse/ClickHouse/pull/115019) ([Mikhail Artemenko](https://github.com/Michicosun)).
