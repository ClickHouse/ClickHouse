# 2026 Changelog

### ClickHouse release v26.7.29.12-stable (a178cd3046b) FIXME as compared to v26.7.28.6-stable (6bd009abe0d)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125429](https://github.com/ClickHouse/ClickHouse/issues/125429): The collections of the Native protocol — the settings and the query parameters of a query, the client information, the granted roles and the table-status lists — are now bounded, so a small packet can no longer make the server allocate memory for data that has not arrived. [#117015](https://github.com/ClickHouse/ClickHouse/pull/117015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#124710](https://github.com/ClickHouse/ClickHouse/issues/124710): Fix reading bucketed runtime `Map` values from `JSON` columns using `advanced` shared-data serialization. [#118577](https://github.com/ClickHouse/ClickHouse/pull/118577) ([Rory Shanks](https://github.com/rorylshanks)).
* Backported in [#125357](https://github.com/ClickHouse/ClickHouse/issues/125357): Mask secrets in the queries that a cluster-mode `QueryRunner` table writes to `system.query_log` as well as in queries executed as startup scripts. [#118978](https://github.com/ClickHouse/ClickHouse/pull/118978) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Backported in [#125088](https://github.com/ClickHouse/ClickHouse/issues/125088): Fixed `TRUNCATE TABLE` of an `Alias` table whose target is a `MergeTree` failing with `DEADLOCK_AVOIDED` when the alias is being read concurrently, while the same statement against the target table succeeds immediately. The lock for `TRUNCATE` is now chosen and taken on the table that executes the truncate, so an `Alias` follows its target's engine. [#119105](https://github.com/ClickHouse/ClickHouse/pull/119105) ([Groene AI](https://github.com/groeneai)).
* Backported in [#125371](https://github.com/ClickHouse/ClickHouse/issues/125371): Fixed a crash on a query with a deeply nested `Dynamic` or `JSON` constant. [#120885](https://github.com/ClickHouse/ClickHouse/pull/120885) ([Pavel Kruglov](https://github.com/Avogar)).
* Backported in [#125472](https://github.com/ClickHouse/ClickHouse/issues/125472): Fixed `use_skip_indexes = 0` also disabling part pruning by the partition-key min-max index (since 26.5), which made such queries read every part of the table. [#123403](https://github.com/ClickHouse/ClickHouse/pull/123403) ([Ashish Kumar Choubey](https://github.com/aschoube)).
* Backported in [#124657](https://github.com/ClickHouse/ClickHouse/issues/124657): Reject malformed serialized `groupBitmap` states with `INCORRECT_DATA` instead of failing later during bitmap operations. [#124049](https://github.com/ClickHouse/ClickHouse/pull/124049) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#125301](https://github.com/ClickHouse/ClickHouse/issues/125301): Fixed excessive memory usage when loading a data part with a corrupted `columns_substreams.txt`; such a part is now detached as broken. [#124157](https://github.com/ClickHouse/ClickHouse/pull/124157) ([Murphy](https://github.com/murphy-4o)).
* Backported in [#125358](https://github.com/ClickHouse/ClickHouse/issues/125358): Update `mongo-c-driver` to 2.5.5, fixing an out-of-bounds write during MongoDB connection monitoring reconnects (CVE-2026-96746). [#124282](https://github.com/ClickHouse/ClickHouse/pull/124282) ([Actuele AI](https://github.com/actueleai)).

#### Build/Testing/Packaging Improvement
* Backported in [#125336](https://github.com/ClickHouse/ClickHouse/issues/125336): Update `thrift` to v0.25.0. [#124280](https://github.com/ClickHouse/ClickHouse/pull/124280) ([Actuele AI](https://github.com/actueleai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#125363](https://github.com/ClickHouse/ClickHouse/issues/125363): Integration-test harness: tolerate non-UTF-8 bytes when decoding captured container output, so a single bad byte no longer aborts cluster teardown and the sanitizer scan, and honor `shutdown(ignore_sanitizer=True)` in the `docker.log` fallback scan. [#118195](https://github.com/ClickHouse/ClickHouse/pull/118195) ([Groene AI](https://github.com/groeneai)).
