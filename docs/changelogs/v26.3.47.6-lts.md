# 2026 Changelog

### ClickHouse release v26.3.47.6-lts (929410fbc12) FIXME as compared to v26.3.46.2-lts (283fb567c9b)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124838](https://github.com/ClickHouse/ClickHouse/issues/124838): Fixed `Expected UInt64 column for __grouping_set, got BLOB` and `ColumnBLOB should be converted to a regular column before usage` logical errors on a distributed query executed on a shard with `enable_parallel_blocks_marshalling` (enabled by default), for example with `GROUP BY GROUPING SETS` over a cluster that has a local replica, or when reading a `Merge` table that spans a local and a distributed table. `BlocksMarshallingStep` is no longer added to plans whose blocks are consumed in the same process. [#111997](https://github.com/ClickHouse/ClickHouse/pull/111997) ([Groene AI](https://github.com/groeneai)).
* Backported in [#124888](https://github.com/ClickHouse/ClickHouse/issues/124888): Fixes `DeltaLake` tables returning too few rows when the `WHERE` predicate contains a sub-expression the delta-kernel predicate translator cannot handle, positioned under a `NOT`. Such a sub-expression is now reported to delta-kernel as an explicit unknown predicate instead of as the end of the child iterator, which used to silently truncate the enclosing conjunction. [#112652](https://github.com/ClickHouse/ClickHouse/pull/112652) ([Groene AI](https://github.com/groeneai)).
* Backported in [#124851](https://github.com/ClickHouse/ClickHouse/issues/124851): Fix a possible heap buffer overflow on malformed responses from blob storage. [#119054](https://github.com/ClickHouse/ClickHouse/pull/119054) ([Arsen Muk](https://github.com/arsenmuk)).

#### Build/Testing/Packaging Improvement
* Backported in [#124661](https://github.com/ClickHouse/ClickHouse/issues/124661): CRoaring v5.2.3 exposes `internal_validate()` on the C++ `RoaringBitmap` wrappers, so RoaringBitmap data can be validated. [#124043](https://github.com/ClickHouse/ClickHouse/pull/124043) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#124754](https://github.com/ClickHouse/ClickHouse/issues/124754): Update `cctz` to 2026e. [#124249](https://github.com/ClickHouse/ClickHouse/pull/124249) ([Actuele AI](https://github.com/actueleai)).
