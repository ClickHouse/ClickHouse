# 2026 Changelog

### ClickHouse release v26.3.60.2-lts (b55e4897caa) FIXME as compared to v26.3.59.10-lts (4f0c8c19d30)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#127360](https://github.com/ClickHouse/ClickHouse/issues/127360): Keeper no longer pre-allocates memory for the array size declared in a request (for example the ACL list in `Create`) before it reads the array elements. Before this fix, a small malformed request could cause a large memory allocation. [#126914](https://github.com/ClickHouse/ClickHouse/pull/126914) ([Antonio Andelic](https://github.com/antonio2368)).
