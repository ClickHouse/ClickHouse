# 2026 Changelog

### ClickHouse release v26.3.42.3-lts (d8ab7375308) FIXME as compared to v26.3.41.4-lts (bc541fda593)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#123773](https://github.com/ClickHouse/ClickHouse/issues/123773): Fix an out-of-bounds read when deserializing a `uniqTheta` state shorter than 24 bytes, for instance from `CAST(<string> AS AggregateFunction(uniqTheta, ...))`. [#119598](https://github.com/ClickHouse/ClickHouse/pull/119598) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#123819](https://github.com/ClickHouse/ClickHouse/issues/123819): Fix a buffer over-read on the sequential read path from Azure Blob Storage: an endpoint that answers a ranged request with more data than was requested could deliver bytes from outside the requested range to the caller. The end of a read is now decided by the locally set right bound, not by the `Content-Length` of the response, and a read is pinned to the listed generation of the blob with `If-Match`, so an object replaced during a read fails with `AZURE_OBJECT_CHANGED_DURING_READ` instead of being truncated (new setting `azure_validate_etag_on_read`, enabled by default). [#120910](https://github.com/ClickHouse/ClickHouse/pull/120910) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
