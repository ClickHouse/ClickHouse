# 2026 Changelog

### ClickHouse release v26.8.44.3-lts (46094a8d754) FIXME as compared to v26.8.43.13-lts (d7fd1bf9ae8)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#133466](https://github.com/ClickHouse/ClickHouse/issues/133466): Fixed a logical error (`Method == not implemented for AST`) raised by a `SET` of a custom setting that already held an AST value such as `disk(type = 's3', ...)`. Assigning such a setting a second time in one session, or clamping a nested `SETTINGS` clause against it, reached a comparison that was never implemented. `FieldFromASTImpl` now implements equality over the formatted value. [#118993](https://github.com/ClickHouse/ClickHouse/pull/118993) ([Groene AI](https://github.com/groeneai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#133409](https://github.com/ClickHouse/ClickHouse/issues/133409): This patch changes the `isRemote` outcome for `DiskObjectStorage` over local object storage and improves local paths check for complex disks. [#110665](https://github.com/ClickHouse/ClickHouse/pull/110665) ([Mikhail Artemenko](https://github.com/Michicosun)).
