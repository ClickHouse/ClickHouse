# 2026 Changelog

### ClickHouse release v26.3.19.3-lts (5a1dec715af) FIXME as compared to v26.3.18.32-lts (bb40d836b15)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#115089](https://github.com/ClickHouse/ClickHouse/issues/115089): `RESTORE` now fsyncs the restored part files when the destination table has `fsync_after_insert` enabled, so a restored part is as durable against power loss as an inserted one. Previously restored files were only written and closed (never fsynced), so a power loss right after `RESTORE` returned `RESTORED` could leave the parts torn and the table empty. [#111378](https://github.com/ClickHouse/ClickHouse/pull/111378) ([Groene AI](https://github.com/groeneai)).

#### Build/Testing/Packaging Improvement
* Use curl 8.21.0. [#115211](https://github.com/ClickHouse/ClickHouse/pull/115211) ([Konstantin Bogdanov](https://github.com/thevar1able)).
