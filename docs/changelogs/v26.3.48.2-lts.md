#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125054](https://github.com/ClickHouse/ClickHouse/issues/125054): Fixed a crash (stack overflow) when reading an Avro file with an explicit structure that does not read a field nested through a long chain of named types, or a field of a recursive type holding deeply nested data such as a long linked list.
