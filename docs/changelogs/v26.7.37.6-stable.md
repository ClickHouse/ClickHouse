# 2026 Changelog

### ClickHouse release v26.7.37.6-stable (b490194cd6d) FIXME as compared to v26.7.36.9-stable (d6f71b56b61)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125886](https://github.com/ClickHouse/ClickHouse/issues/125886): Creating a FileLog tables now require READ and WRITE privileges, analogous to File tables. [#125701](https://github.com/ClickHouse/ClickHouse/pull/125701) ([Robert Schulze](https://github.com/rschu1ze)).
* Backported in [#126730](https://github.com/ClickHouse/ClickHouse/issues/126730): Fixed a server crash (or missing rows in the view, with a `Null` source table) on `INSERT` into the source table of a materialized view when a row policy or `additional_table_filters` of a table read by the view references the source table, e.g. `USING x IN src`. [#125893](https://github.com/ClickHouse/ClickHouse/pull/125893) ([Groene AI](https://github.com/groeneai)).
* Backported in [#127160](https://github.com/ClickHouse/ClickHouse/issues/127160): Fix a stack overflow on a deeply nested query plan received in the `QueryPlan` packet of the native protocol. [#126548](https://github.com/ClickHouse/ClickHouse/pull/126548) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#126795](https://github.com/ClickHouse/ClickHouse/issues/126795): Fix a stack overflow on a Protobuf schema with a very long chain of nested messages. [#126550](https://github.com/ClickHouse/ClickHouse/pull/126550) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#127177](https://github.com/ClickHouse/ClickHouse/issues/127177): Fixes a crash in estimateCompressionRatio with codecs DoubleDelta and Gorilla. [#127139](https://github.com/ClickHouse/ClickHouse/pull/127139) ([Robert Schulze](https://github.com/rschu1ze)).
