# 2026 Changelog

### ClickHouse release v26.8.37.168-lts (40e366b2afb) FIXME as compared to v26.8.36.3-lts (b47359294fe)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#131322](https://github.com/ClickHouse/ClickHouse/issues/131322): Fixed `optimize_rewrite_aggregate_function_with_if` (enabled by default) turning a short-circuit-guarded aggregate such as `sum(if(number = 0, 0, intDiv(42, number)))` into a query failure: the rewritten `sumIf(intDiv(42, number), number != 0)` evaluates its argument for every row, so the guarded expression ran on the rows the condition excluded and threw. The rewrite is now refused when the lifted branch relies on short-circuit evaluation. Closes [#85784](https://github.com/ClickHouse/ClickHouse/issues/85784). [#118697](https://github.com/ClickHouse/ClickHouse/pull/118697) ([Groene AI](https://github.com/groeneai)).
