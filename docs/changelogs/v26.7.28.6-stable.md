# 2026 Changelog

### ClickHouse release v26.7.28.6-stable (6bd009abe0d) FIXME as compared to v26.7.27.3-stable (44090b70c21)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124852](https://github.com/ClickHouse/ClickHouse/issues/124852): Fix a possible heap buffer overflow on malformed responses from blob storage. [#119054](https://github.com/ClickHouse/ClickHouse/pull/119054) ([Arsen Muk](https://github.com/arsenmuk)).
* Backported in [#125016](https://github.com/ClickHouse/ClickHouse/issues/125016): Fixed a query failing with an exception like `Cannot parse UInt64 from String` on a table with a text index on `mapKeys` or `JSONAllPaths`, when the predicate cannot be evaluated on the value of a missing map key or JSON path. [#124612](https://github.com/ClickHouse/ClickHouse/pull/124612) ([Anton Popov](https://github.com/CurtizJ)).
* Backported in [#125125](https://github.com/ClickHouse/ClickHouse/issues/125125): Fixed slow planning of queries with skip indexes on tables with many parts and pending patch parts of lightweight updates. [#124931](https://github.com/ClickHouse/ClickHouse/pull/124931) ([Anton Popov](https://github.com/CurtizJ)).

#### Build/Testing/Packaging Improvement
* Backported in [#124662](https://github.com/ClickHouse/ClickHouse/issues/124662): CRoaring v5.2.3 exposes `internal_validate()` on the C++ `RoaringBitmap` wrappers, so RoaringBitmap data can be validated. [#124043](https://github.com/ClickHouse/ClickHouse/pull/124043) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#124755](https://github.com/ClickHouse/ClickHouse/issues/124755): Update `cctz` to 2026e. [#124249](https://github.com/ClickHouse/ClickHouse/pull/124249) ([Actuele AI](https://github.com/actueleai)).
