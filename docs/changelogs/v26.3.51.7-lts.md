# 2026 Changelog

### ClickHouse release v26.3.51.7-lts (c36b897f01f) FIXME as compared to v26.3.50.11-lts (94a03bb074b)

#### Improvement
* Backported in [#125539](https://github.com/ClickHouse/ClickHouse/issues/125539): Added a server setting `access_control_improvements.readonly_restricts_set_role`, `false` by default. When enabled, `SET ROLE` is refused with error code `READONLY` in a session or query whose `readonly` setting is not zero. Previously `SET ROLE` was the only identity-changing statement that `readonly` did not refuse. [#118021](https://github.com/ClickHouse/ClickHouse/pull/118021) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125628](https://github.com/ClickHouse/ClickHouse/issues/125628): Fix a credential written in cleartext to `system.query_log` and the server log when a `key = value` argument precedes the positional arguments of the `mongodb`, `redis`, `remote`, `arrowFlight` and `ytsaurus` table functions or the `MongoDB`, `Redis`, `Remote`, `ArrowFlight`, `ExternalDistributed` and `YTsaurus` table engines. A positional argument after a named one is now always hidden, and the value of a named-collection override whose key is written as an expression is hidden for every such engine. [#122770](https://github.com/ClickHouse/ClickHouse/pull/122770) ([Raúl Marín](https://github.com/Algunenano)).
* Fix a security issue where an unauthenticated TCP client could probe table existence and replication status via the interserver protocol. Such a request now gets a response that does not depend on the state of the tables. The new server setting `interserver_tables_status_allow_unauthenticated` restores the previous behavior. [#124840](https://github.com/ClickHouse/ClickHouse/pull/124840) ([Shaohua Wang](https://github.com/tiandiwonder)).
* Backported in [#125641](https://github.com/ClickHouse/ClickHouse/issues/125641): Free prefetched messages when StorageKafka2 partitions move between consumers, preventing per-partition memory growth until restart. [#125076](https://github.com/ClickHouse/ClickHouse/pull/125076) ([Aparajita Pandey](https://github.com/aparajita31pandey)).
* Fixed escaping of string literals when a predicate is pushed down to PostgreSQL. [#125704](https://github.com/ClickHouse/ClickHouse/pull/125704) ([Shaohua Wang](https://github.com/tiandiwonder)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#125430](https://github.com/ClickHouse/ClickHouse/issues/125430): Use shared lock for throttler getters in `Context`. [#108816](https://github.com/ClickHouse/ClickHouse/pull/108816) ([Antonio Andelic](https://github.com/antonio2368)).
