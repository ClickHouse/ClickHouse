#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#126617](https://github.com/ClickHouse/ClickHouse/issues/126617): Fixed crashes of the interactive line editor of `clickhouse-client` and `clickhouse-local`, which also crashed the server when used through the web terminal or an SSH session: after a history search that found nothing on an edited recalled query, when the prompt or the line given to an Alt-R history search contained a tab, when leaving a history search with a double-width character in the prompt (for example in the server's `display_name`), and on Ctrl-W or Alt-. after some non-ASCII characters. Closes [#126008](https://github.com/ClickHouse/ClickHouse/issues/126008). [#126120](https://github.com/ClickHouse/ClickHouse/pull/126120) ([Groene AI](https://github.com/groeneai)).
