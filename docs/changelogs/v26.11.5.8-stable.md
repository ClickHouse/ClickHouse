# 2026 Changelog

### ClickHouse release v26.11.5.8-stable (fad9c4f1ed9) FIXME as compared to v26.11.4.11-stable (60a00ce41cf)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#135063](https://github.com/ClickHouse/ClickHouse/issues/135063): Fix excessive I/O during mutation and lightweight DELETE prechecks on tables with bucketed `Map` serialization by allowing `m['key']` predicates to be rewritten to Map key subcolumns. [#130291](https://github.com/ClickHouse/ClickHouse/pull/130291) ([Rushikesh Sudhir Kulkarni](https://github.com/Rushikesh1911)).
* Backported in [#135070](https://github.com/ClickHouse/ClickHouse/issues/135070): Fixed background merges and `OPTIMIZE` of a table that has a column TTL on an `ALIAS` or `EPHEMERAL` column: once the TTL was due, they failed with `There is no physical column ... in table. (NO_SUCH_COLUMN_IN_TABLE)` and the merge was retried forever. Closes [#134006](https://github.com/ClickHouse/ClickHouse/issues/134006). [#134279](https://github.com/ClickHouse/ClickHouse/pull/134279) ([Groene AI](https://github.com/groeneai)).
* Backported in [#135088](https://github.com/ClickHouse/ClickHouse/issues/135088): Fix dictionaries with a remote ClickHouse source over `Distributed` with a cluster secret. [#134753](https://github.com/ClickHouse/ClickHouse/pull/134753) ([Azat Khuzhin](https://github.com/azat)).
* Backported in [#135034](https://github.com/ClickHouse/ClickHouse/issues/135034): A deeply nested PromQL query terminated the server with a segmentation fault. Now such queries fail with `TOO_DEEP_RECURSION` error. `bool`, `group_left`, `group_right`, `on`, `ignoring`, `atan2` are not allowed as unquoted metric names anymore. `(` after `group_left`/`group_right` always starts the label list, so `group_left (b + c)` is now a syntax error. The workaround is to explicitly specify the empty list, e.g. `group_left() (b + c)`. [#134787](https://github.com/ClickHouse/ClickHouse/pull/134787) ([Kirill Shokhin](https://github.com/kirillshokhin)).
* Backported in [#134989](https://github.com/ClickHouse/ClickHouse/issues/134989): A table of a `Filesystem` database is now required to be a file inside the directory of the database. [#134818](https://github.com/ClickHouse/ClickHouse/pull/134818) ([Alexander Tokmakov](https://github.com/tavplubix)).

#### Build/Testing/Packaging Improvement
* Backported in [#135116](https://github.com/ClickHouse/ClickHouse/issues/135116): Update `mongo-c-driver` from 2.5.8 to 2.5.10. [#133662](https://github.com/ClickHouse/ClickHouse/pull/133662) ([Actuele AI](https://github.com/actueleai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#135096](https://github.com/ClickHouse/ClickHouse/issues/135096): Apply the memory limit of `05828_remerge_sort_memory_bounded` only to the queries under test. [#134360](https://github.com/ClickHouse/ClickHouse/pull/134360) ([Groene AI](https://github.com/groeneai)).
