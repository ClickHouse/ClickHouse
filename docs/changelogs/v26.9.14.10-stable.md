# 2026 Changelog

### ClickHouse release v26.9.14.10-stable (42bc9542943) FIXME as compared to v26.9.13.15-stable (4b131779967)

#### Improvement
* Backported in [#124617](https://github.com/ClickHouse/ClickHouse/issues/124617): `bloom_filter` and text indexes are now used when a `Nullable` indexed column is cast to the non-`Nullable` type, such as `CAST(x, 'String')` or `json.path::String`. A query that would throw on a NULL value may not throw when the index skips the granules with NULL. [#124220](https://github.com/ClickHouse/ClickHouse/pull/124220) ([Anton Popov](https://github.com/CurtizJ)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124712](https://github.com/ClickHouse/ClickHouse/issues/124712): Fix reading bucketed runtime `Map` values from `JSON` columns using `advanced` shared-data serialization. [#118577](https://github.com/ClickHouse/ClickHouse/pull/118577) ([Rory Shanks](https://github.com/rorylshanks)).
* Backported in [#124837](https://github.com/ClickHouse/ClickHouse/issues/124837): Fix DeltaLake stats pruning with Date cast. [#119184](https://github.com/ClickHouse/ClickHouse/pull/119184) ([Arsen Muk](https://github.com/arsenmuk)).
* Backported in [#124251](https://github.com/ClickHouse/ClickHouse/issues/124251): Fix `EXPLAIN PLAN actions = 1` printing a secret function argument (for example the key of `HMAC` or `encrypt`) in cleartext when its value came from a subquery or from the other side of a JOIN. [#120371](https://github.com/ClickHouse/ClickHouse/pull/120371) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Backported in [#124629](https://github.com/ClickHouse/ClickHouse/issues/124629): Fix `INSERT` failing with `ILLEGAL_FINAL` or `SAMPLING_NOT_SUPPORTED` when a materialized view applies `FINAL` or `SAMPLE` to its own source table inside a subquery. Regression in [#122345](https://github.com/ClickHouse/ClickHouse/issues/122345). [#123514](https://github.com/ClickHouse/ClickHouse/pull/123514) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* Backported in [#124694](https://github.com/ClickHouse/ClickHouse/issues/124694): Fix a rare server crash (`SIGSEGV` in `mongoc_log`) when a MongoDB dictionary source or `MongoDB` table was created while another thread created the first MongoDB connection in the process. Messages logged by the MongoDB driver now go to the server log. [#124235](https://github.com/ClickHouse/ClickHouse/pull/124235) ([Vladimir Cherkasov](https://github.com/vdimir)).

#### Build/Testing/Packaging Improvement
* Backported in [#124665](https://github.com/ClickHouse/ClickHouse/issues/124665): CRoaring v5.2.3 exposes `internal_validate()` on the C++ `RoaringBitmap` wrappers, so RoaringBitmap data can be validated. [#124043](https://github.com/ClickHouse/ClickHouse/pull/124043) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Backported in [#124757](https://github.com/ClickHouse/ClickHouse/issues/124757): Update `cctz` to 2026e. [#124249](https://github.com/ClickHouse/ClickHouse/pull/124249) ([Actuele AI](https://github.com/actueleai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#124730](https://github.com/ClickHouse/ClickHouse/issues/124730): Fixed a `LOGICAL_ERROR` in `arraySlice` on a `QBit` column replicated by `ARRAY JOIN` or a `JOIN`. [#120224](https://github.com/ClickHouse/ClickHouse/pull/120224) ([Groene AI](https://github.com/groeneai)).
