# 2026 Changelog

### ClickHouse release v26.8.40.7-lts (f20555c09af) FIXME as compared to v26.8.39.19-lts (ed6dc0f3556)

#### Improvement
* Backported in [#132044](https://github.com/ClickHouse/ClickHouse/issues/132044): `ReplicatedMergeTree` now removes old deduplication blocks from Keeper in batches of `TryRemove` requests instead of one `Remove` request per block. This reduces the number of Raft entries in Keeper for tables with many replicas. [#128645](https://github.com/ClickHouse/ClickHouse/pull/128645) ([Antonio Andelic](https://github.com/antonio2368)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#132384](https://github.com/ClickHouse/ClickHouse/issues/132384): Projections no longer provide `_block_number`, `_block_offset` and `_row_exists` unless they store them, so queries reading these columns use the main table. Previously the values came from the projection part, which caused wrong results and made incremental refreshable materialized views (`APPEND INCREMENTAL`) silently skip source rows. [#130515](https://github.com/ClickHouse/ClickHouse/pull/130515) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Backported in [#132470](https://github.com/ClickHouse/ClickHouse/issues/132470): The error of AI functions for an insecure endpoint no longer contains the endpoint of the named collection, which could carry a secret not visible to the user. [#131438](https://github.com/ClickHouse/ClickHouse/pull/131438) ([George Larionov](https://github.com/george-larionov)).
* Backported in [#132372](https://github.com/ClickHouse/ClickHouse/issues/132372): `SYSTEM SYNC DATABASE REPLICA` without `ON CLUSTER` now requires the `SYSTEM SYNC DATABASE REPLICA` grant on the database. Before, any user could run it. [#131893](https://github.com/ClickHouse/ClickHouse/pull/131893) ([Lazizbek Ergashev](https://github.com/lazerg)).
* Backported in [#132401](https://github.com/ClickHouse/ClickHouse/issues/132401): Fix an asynchronous `INSERT ... FROM INFILE` sent directly to the server opening the file on the server before the query was rejected. [#132305](https://github.com/ClickHouse/ClickHouse/pull/132305) ([Sema Checherinda](https://github.com/CheSema)).
* Backported in [#132460](https://github.com/ClickHouse/ClickHouse/issues/132460): Fix a server crash when deserializing a malformed aggregate state that contains a `LowCardinality(String)` value. [#132322](https://github.com/ClickHouse/ClickHouse/pull/132322) ([Raúl Marín](https://github.com/Algunenano)).
