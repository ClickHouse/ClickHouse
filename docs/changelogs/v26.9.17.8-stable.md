# 2026 Changelog

### ClickHouse release v26.9.17.8-stable (d3f97a8b309) FIXME as compared to v26.9.16.11-stable (1cb9dbb0c11)

#### Improvement
* Backported in [#125259](https://github.com/ClickHouse/ClickHouse/issues/125259): Restore min/max pruning of Iceberg data files for a `Decimal(38, 38)` column. A manifest bound of magnitude above roughly 0.7 cannot be widened inside `Int128` and was dropped, which left the column without a min/max condition; it is now saturated at the largest magnitude the precision allows, which is still outside every value the file can hold. [#119712](https://github.com/ClickHouse/ClickHouse/pull/119712) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#125271](https://github.com/ClickHouse/ClickHouse/issues/125271): The collections of the Native protocol — the settings and the query parameters of a query, the client information, the granted roles and the table-status lists — are now bounded, so a small packet can no longer make the server allocate memory for data that has not arrived. [#117015](https://github.com/ClickHouse/ClickHouse/pull/117015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#125373](https://github.com/ClickHouse/ClickHouse/issues/125373): Fixed a crash on a query with a deeply nested `Dynamic` or `JSON` constant. [#120885](https://github.com/ClickHouse/ClickHouse/pull/120885) ([Pavel Kruglov](https://github.com/Avogar)).
* Backported in [#125266](https://github.com/ClickHouse/ClickHouse/issues/125266): Fix `NOT_IMPLEMENTED` for an outer `JOIN` with `join_algorithm = 'full_sorting_merge'` when `optimize_and_compare_chain` derived a condition on the preserved side of the join from the `ON` clause. [#124233](https://github.com/ClickHouse/ClickHouse/pull/124233) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Backported in [#125360](https://github.com/ClickHouse/ClickHouse/issues/125360): Update `mongo-c-driver` to 2.5.5, fixing an out-of-bounds write during MongoDB connection monitoring reconnects (CVE-2026-96746). [#124282](https://github.com/ClickHouse/ClickHouse/pull/124282) ([Actuele AI](https://github.com/actueleai)).

#### Build/Testing/Packaging Improvement
* Backported in [#125338](https://github.com/ClickHouse/ClickHouse/issues/125338): Update `thrift` to v0.25.0. [#124280](https://github.com/ClickHouse/ClickHouse/pull/124280) ([Actuele AI](https://github.com/actueleai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#125175](https://github.com/ClickHouse/ClickHouse/issues/125175): Fixed a crash on `INSERT` into a `MergeTree` table when a materialized view over it reads the same table from a correlated subquery, `IN <table>` or a non-leftmost table of an `IN` subquery. [#124740](https://github.com/ClickHouse/ClickHouse/pull/124740) ([Groene AI](https://github.com/groeneai)).
