# 2026 Changelog

### ClickHouse release v26.8.46.6-lts (60beb0f96b7) FIXME as compared to v26.8.45.6-lts (be540b388f4)

#### Performance Improvement
* Backported in [#134065](https://github.com/ClickHouse/ClickHouse/issues/134065): Read columns of Compact part in the order of the file (to avoid backward seeks). [#131439](https://github.com/ClickHouse/ClickHouse/pull/131439) ([Azat Khuzhin](https://github.com/azat)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#133761](https://github.com/ClickHouse/ClickHouse/issues/133761): Fixed a table with the `keeper_path` of another `S3Queue` or `AzureQueue` making it delete, move or tag its source files. The source must now match, and these actions need the `WRITE` grant. [#129383](https://github.com/ClickHouse/ClickHouse/pull/129383) ([Samuel Krempaský](https://github.com/NIKTONIKTO717)).
* Backported in [#133755](https://github.com/ClickHouse/ClickHouse/issues/133755): Fix a crash and incorrect results in the `CapnProto` format when the schema contains groups or named unions declared inline in a struct (`g :group { ... }`, `u :union { ... }`). [#133530](https://github.com/ClickHouse/ClickHouse/pull/133530) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

#### Build/Testing/Packaging Improvement
* Backported in [#133778](https://github.com/ClickHouse/ClickHouse/issues/133778): Fix a ppc64le bug where the bundled libunwind's `unw_getcontext` left callee-saved vector registers byte-swapped, which could make `clickhouse-server` fail to start intermittently. [#129808](https://github.com/ClickHouse/ClickHouse/pull/129808) ([Shichao Jin](https://github.com/jsc0218)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#131242](https://github.com/ClickHouse/ClickHouse/issues/131242): Fix SIGSEGV (in <26.10) when format_schema query reads a MongoDB table. [#131055](https://github.com/ClickHouse/ClickHouse/pull/131055) ([Azat Khuzhin](https://github.com/azat)).
