# 2026 Changelog

### ClickHouse release v26.9.10.4-stable (01c3dd9dfbb) FIXME as compared to v26.9.9.28-stable (2363840e077)

#### Performance Improvement
* Backported in [#123759](https://github.com/ClickHouse/ClickHouse/issues/123759): Enabled the text index posting lists cache by default (`use_text_index_postings_cache`). Previously each query used a private cache capped at 100 MiB, which on large tables caused posting lists and phrase search results to be recomputed several times within a single query; a 4-token phrase query on a 1B-row table went from 19 s to 0.12 s. The cache is bounded by the `text_index_postings_cache_size` server setting (2 GiB by default). [#120677](https://github.com/ClickHouse/ClickHouse/pull/120677) ([Nikita Fomichev](https://github.com/fm4v)).

#### Improvement
* Backported in [#123728](https://github.com/ClickHouse/ClickHouse/issues/123728): Skip indexes (`bloom_filter`, `tokenbf_v1`, `ngrambf_v1`, `minmax`) and the primary key are now used when the indexed column is wrapped into a conversion that does not change its value, such as `toLowCardinality`, `toNullable` or a `CAST` to `Nullable` or `LowCardinality`. [#123239](https://github.com/ClickHouse/ClickHouse/pull/123239) ([Anton Popov](https://github.com/CurtizJ)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#123733](https://github.com/ClickHouse/ClickHouse/issues/123733): Fix an out-of-bounds read when deserializing a `uniqTheta` state shorter than 24 bytes, for instance from `CAST(<string> AS AggregateFunction(uniqTheta, ...))`. [#119598](https://github.com/ClickHouse/ClickHouse/pull/119598) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
