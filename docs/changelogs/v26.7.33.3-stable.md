# 2026 Changelog

### ClickHouse release v26.7.33.3-stable (f2596795884) FIXME as compared to v26.7.32.7-stable (cd652d7b774)

#### Backward Incompatible Change
* Backported in [#125779](https://github.com/ClickHouse/ClickHouse/issues/125779): Connections to MySQL (the `mysql` table function, the `MySQL` table and database engines, and `MySQL` dictionaries) that set `ssl_ca` or `ssl_ca_pem` now verify the server certificate chain and host name, after updating `mariadb-connector-c` to v3.4.10. Previously the CA was not enforced, so a connection to a server whose certificate is signed by another CA, or whose certificate does not list the host name or IP address used to connect, succeeded and now fails with `self-signed certificate in certificate chain` or `Hostname verification failed`. Before upgrading, make sure the configured CA signs the MySQL server certificate and that the certificate lists the host name or IP address ClickHouse connects to. [#119510](https://github.com/ClickHouse/ClickHouse/pull/119510) ([Actuele AI](https://github.com/actueleai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#126279](https://github.com/ClickHouse/ClickHouse/issues/126279): Requesting SSH-key authentication over the native protocol no longer reveals whether the named user exists, or how it authenticates, before its signature is checked. [#121704](https://github.com/ClickHouse/ClickHouse/pull/121704) ([Shaohua Wang](https://github.com/tiandiwonder)).
