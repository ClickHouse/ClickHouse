# 2026 Changelog

### ClickHouse release v26.3.43.4-lts (1942a36ca0d) FIXME as compared to v26.3.42.3-lts (d8ab7375308)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#123978](https://github.com/ClickHouse/ClickHouse/issues/123978): Fixed `BACKUP` to `AzureBlobStorage`: copying a data file inside a backup wrote the destination object outside the backup directory. Backup object existence checks on `S3` destinations now use exact `HeadObject` requests instead of prefix listing, preventing false matches of similarly-prefixed keys. [#107153](https://github.com/ClickHouse/ClickHouse/pull/107153) ([Pablo Marcos](https://github.com/pamarcos)).
* Backported in [#123972](https://github.com/ClickHouse/ClickHouse/issues/123972): Add more path validations. [#123099](https://github.com/ClickHouse/ClickHouse/pull/123099) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Backported in [#123986](https://github.com/ClickHouse/ClickHouse/issues/123986): Fixed a segmentation fault or `std::length_error` when reading `TSV` formats with `input_format_tsv_crlf_end_of_line = 1` if an escape sequence ended exactly at the end of a read buffer. [#123861](https://github.com/ClickHouse/ClickHouse/pull/123861) ([Groene AI](https://github.com/groeneai)).
