# 2026 Changelog

### ClickHouse release v26.3.70.5-lts (bf0deed7c0d) FIXME as compared to v26.3.69.4-lts (414926d4672)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#133465](https://github.com/ClickHouse/ClickHouse/issues/133465): Fixed a logical error (`Method == not implemented for AST`) raised by a `SET` of a custom setting that already held an AST value such as `disk(type = 's3', ...)`. Assigning such a setting a second time in one session, or clamping a nested `SETTINGS` clause against it, reached a comparison that was never implemented. `FieldFromASTImpl` now implements equality over the formatted value. [#118993](https://github.com/ClickHouse/ClickHouse/pull/118993) ([Groene AI](https://github.com/groeneai)).
* Backported in [#133650](https://github.com/ClickHouse/ClickHouse/issues/133650): Fixed `NOT_FOUND_COLUMN_IN_BLOCK` when merging a table that has a rows `TTL` together with a move (`TO DISK`, `TO VOLUME`) or recompression (`RECOMPRESS`) `TTL` over a different column. [#121536](https://github.com/ClickHouse/ClickHouse/pull/121536) ([Murphy](https://github.com/murphy-4o)).
* Backported in [#133568](https://github.com/ClickHouse/ClickHouse/issues/133568): Fix `NOT_FOUND_COLUMN_IN_BLOCK` and wrong results when a `GROUP BY` key is used inside an `if` chain with `optimize_if_chain_to_multiif = 1`, or is a tuple used in `ORDER BY` (for example `if(1, tuple(a), tuple(0)) AS k ... GROUP BY k ORDER BY k`). With `group_by_use_nulls = 1`, such an `if` key returned its value instead of `NULL` in `ROLLUP`, `CUBE` and `GROUPING SETS` subtotal rows. Closes [#125803](https://github.com/ClickHouse/ClickHouse/issues/125803). Closes [#125804](https://github.com/ClickHouse/ClickHouse/issues/125804). [#125828](https://github.com/ClickHouse/ClickHouse/pull/125828) ([Groene AI](https://github.com/groeneai)).
* Backported in [#133583](https://github.com/ClickHouse/ClickHouse/issues/133583): Removed the background task that cleaned up unused directories in `store/`. With `async_load_databases` enabled, it could revoke all access rights from the data directory of an attached table (queries to the table failed with `Permission denied`) and delete the directory 30 days later. It could also delete the data of a table that was recoverable with `ATTACH TABLE ... UUID` after a power loss. Unused directories in `store/` are now left untouched. The server settings `database_catalog_unused_dir_hide_timeout_sec`, `database_catalog_unused_dir_rm_timeout_sec`, and `database_catalog_unused_dir_cleanup_period_sec` are obsolete and have no effect. [#133464](https://github.com/ClickHouse/ClickHouse/pull/133464) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
