# 2026 Changelog

### ClickHouse release v26.3.23.7-lts (19fdace0b54) FIXME as compared to v26.3.22.7-lts (ff4a967c271)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#115912](https://github.com/ClickHouse/ClickHouse/issues/115912): Fixes `has`, `indexOf`, `countEqual`, `mapContainsKey`, `mapContainsValue` and `Map` subscript returning "not found" for a constant `LowCardinality` needle equal to the element type's default value, such as an empty `String` or a zero number. [#114624](https://github.com/ClickHouse/ClickHouse/pull/114624) ([Groene AI](https://github.com/groeneai)).
* Backported in [#115536](https://github.com/ClickHouse/ClickHouse/issues/115536): Fix propagation of query settings and NULL handling in `accurateCastOrDefault`. [#114912](https://github.com/ClickHouse/ClickHouse/pull/114912) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#116061](https://github.com/ClickHouse/ClickHouse/issues/116061): Fixed a hang when dropping a `TimeSeries` table whose name sorts lexicographically below its inner tables' names, for example `` DROP TABLE `-ts` `` or dropping a materialized view declared with `ENGINE = TimeSeries`. The drop self-deadlocked on the DDL guard and could not be cancelled with `KILL QUERY`. [#114953](https://github.com/ClickHouse/ClickHouse/pull/114953) ([Groene AI](https://github.com/groeneai)).
* Backported in [#116264](https://github.com/ClickHouse/ClickHouse/issues/116264): Fixed a bypass of settings constraints: `SET <name> = DEFAULT` reset a setting without checking the constraints from the user's profile, so a `MIN`/`MAX`/`CONST` constraint could be escaped by resetting the setting instead of assigning to it, and a session could leave readonly mode with `SET readonly = DEFAULT`. [#115334](https://github.com/ClickHouse/ClickHouse/pull/115334) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#116350](https://github.com/ClickHouse/ClickHouse/issues/116350): Validate the states of the `stochasticLinearRegression`, `stochasticLogisticRegression`, `groupUniqArray`, `groupArrayIntersect` and `topK` aggregate functions and of the `Resample` combinator on deserialization: a malformed state could be read out of bounds. [#115701](https://github.com/ClickHouse/ClickHouse/pull/115701) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#115927](https://github.com/ClickHouse/ClickHouse/issues/115927): Do not return uninitialized memory in the result of a binary string literal whose length is not a multiple of eight, and from the LZ4 decompressor when a compressed block has no body. [#115704](https://github.com/ClickHouse/ClickHouse/pull/115704) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
