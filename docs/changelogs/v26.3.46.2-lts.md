#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124692](https://github.com/ClickHouse/ClickHouse/issues/124692): Fix a rare server crash (`SIGSEGV` in `mongoc_log`) when a MongoDB dictionary source or `MongoDB` table was created while another thread created the first MongoDB connection in the process.
