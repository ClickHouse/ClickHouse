# 2026 Changelog

### ClickHouse release v26.7.34.3-stable (26600ba25f1) FIXME as compared to v26.7.33.3-stable (f2596795884)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#126239](https://github.com/ClickHouse/ClickHouse/issues/126239): Fixed `ORDER BY ... LIMIT` over a column of an `Interval` type (or `Nullable`, `LowCardinality`, `Tuple` or `Array` of one) failing with `TYPE_MISMATCH` when `use_top_k_dynamic_filtering` is enabled, which is the default. Closes [#125197](https://github.com/ClickHouse/ClickHouse/issues/125197). [#125221](https://github.com/ClickHouse/ClickHouse/pull/125221) ([Groene AI](https://github.com/groeneai)).
* Backported in [#126399](https://github.com/ClickHouse/ClickHouse/issues/126399): The setting `http_zlib_compression_level` now applies only to the `gzip` and `deflate` HTTP response compression. The level of other methods (`zstd`, `lz4`, `br`, `xz`, `bz2`) is controlled by `output_format_compression_level`. Previously, a level suitable for zlib was passed to every method, which could make `lz4` unexpectedly slow or make `xz` fail. [#125899](https://github.com/ClickHouse/ClickHouse/pull/125899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
