# 2026 Changelog

### ClickHouse release v26.9.33.10-stable (f5ed966e633) FIXME as compared to v26.9.32.8-stable (2a495269fe9)

#### Performance Improvement
* Backported in [#132676](https://github.com/ClickHouse/ClickHouse/issues/132676): Removing data parts from a disk with `metadata_type = plain_rewritable` (cleanup of outdated parts, `TRUNCATE`, `DROP PARTITION`, `DROP TABLE`) no longer copies every file of the part to a temporary object before deleting it, and no longer holds the disk metadata lock for those copies. The part directory is removed with one batched delete request. Closes [#123275](https://github.com/ClickHouse/ClickHouse/issues/123275). [#123303](https://github.com/ClickHouse/ClickHouse/pull/123303) ([Groene AI](https://github.com/groeneai)).

#### Improvement
* Backported in [#132692](https://github.com/ClickHouse/ClickHouse/issues/132692): Credentials in the URL of a `url` wildcard expanded from HTTP index pages (`allow_url_wildcard_from_index_pages`), or of a `web_index` disk, are now masked in the errors about an index page redirected to a different origin and about an index page over `max_http_index_page_size`. [#126184](https://github.com/ClickHouse/ClickHouse/pull/126184) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#132648](https://github.com/ClickHouse/ClickHouse/issues/132648): `ATTACH TABLE ... AS REPLICATED` and `ATTACH TABLE ... AS NOT REPLICATED` now check the `TABLE ENGINE` grant on the engine the table is converted to before changing anything. Previously a query refused for this grant had already rewritten the stored definition of the detached table, so a later `ATTACH TABLE` loaded it with the new engine. [#128995](https://github.com/ClickHouse/ClickHouse/pull/128995) ([Nikolai Ovchinnikov](https://github.com/kolsha)).
* Backported in [#132646](https://github.com/ClickHouse/ClickHouse/issues/132646): When `http_forbid_headers` forbids `Authorization`, Basic credentials that would be sent in that header are now refused too: the userinfo of `url`, `urlCluster` and `URL` table URLs (including url wildcards and `web` disks), `credentials` of `HTTP` dictionaries created by DDL, the userinfo of `format_avro_schema_registry_url`, and `user`/`password` of the `Elasticsearch` engine. Before, only an explicit `Authorization` header was refused. [#129850](https://github.com/ClickHouse/ClickHouse/pull/129850) ([Groene AI](https://github.com/groeneai)).
* Backported in [#132664](https://github.com/ClickHouse/ClickHouse/issues/132664): Fix server termination when outdated data parts cannot be scheduled for loading, e.g. when the global thread pool is exhausted. [#130816](https://github.com/ClickHouse/ClickHouse/pull/130816) ([Nikolay Degterinsky](https://github.com/evillique)).
* Backported in [#132618](https://github.com/ClickHouse/ClickHouse/issues/132618): Fixed a type confusion (possible crash or out-of-bounds read) triggered by a client sending a column with a `Sparse` or `Replicated` serialization kind, or a `Tuple` with a `Replicated` element, in data over the native protocol. [#130895](https://github.com/ClickHouse/ClickHouse/pull/130895) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Backported in [#132771](https://github.com/ClickHouse/ClickHouse/issues/132771): Fixed parsing of decimal text with an exponent close to the `Int32` limits: values such as `1e2147483647` were read as `0` instead of being rejected as too big. [#131373](https://github.com/ClickHouse/ClickHouse/pull/131373) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#132735](https://github.com/ClickHouse/ClickHouse/issues/132735): The `URL ... is not allowed in configuration file, see <remote_url_allow_hosts>` error now shows only the host and port of the URL, so secrets in its path or query string are no longer exposed. [#132160](https://github.com/ClickHouse/ClickHouse/pull/132160) ([George Larionov](https://github.com/george-larionov)).

#### Build/Testing/Packaging Improvement
* Backported in [#132680](https://github.com/ClickHouse/ClickHouse/issues/132680): Update `wasmtime` to v50.0.1. [#128834](https://github.com/ClickHouse/ClickHouse/pull/128834) ([Konstantin Bogdanov](https://github.com/thevar1able)).
