# 2026 Changelog

### ClickHouse release v26.7.16.2-stable (92c4ed09b4b) FIXME as compared to v26.7.15.52-stable (2213c0b278e)

#### Improvement
* Backported in [#122539](https://github.com/ClickHouse/ClickHouse/issues/122539): TLS CA certificates configured with `openSSL.server.caConfig` / `openSSL.client.caConfig` (and `caConfig` of composable `protocols`) are now reloaded without a restart when the file changes or on `SYSTEM RELOAD CONFIG`, in the same way as `certificateFile` and `privateKeyFile`. This makes it possible to rotate the CA that is used to verify clients, other servers and Keeper nodes (including Raft connections between Keepers) without restarting anything. [#117387](https://github.com/ClickHouse/ClickHouse/pull/117387) ([James](https://github.com/sanjams2)).
