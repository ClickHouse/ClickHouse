# 2026 Changelog

### ClickHouse release v26.8.47.5-lts (0fc40a59a74) FIXME as compared to v26.8.46.6-lts (60beb0f96b7)

#### Performance Improvement
* Backported in [#134083](https://github.com/ClickHouse/ClickHouse/issues/134083): Add the `RabbitMQ` table setting `rabbitmq_max_idle_producer_connections`, which keeps idle connections with their channels open and reuses them across `INSERT` queries. This removes the connection setup from every insert, which is especially costly for materialized views that fire often, including when they write no rows. The default `0` keeps the previous behavior. [#127611](https://github.com/ClickHouse/ClickHouse/pull/127611) ([David Mischke](https://github.com/davimi)).

#### Improvement
* Backported in [#134313](https://github.com/ClickHouse/ClickHouse/issues/134313): Add AI function request time, retry backoff time, and prompt-cache token counts to `ProfileEvents`. Include cached Anthropic input tokens in total input usage and query quotas. [#122559](https://github.com/ClickHouse/ClickHouse/pull/122559) ([Ravi Kumar L](https://github.com/upman)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#134235](https://github.com/ClickHouse/ClickHouse/issues/134235): The `CGroupMaxCPU` asynchronous metric now takes the effective cpuset of the cgroup into account, as the minimum of the CPU quota and the number of CPUs in the cpuset. Previously it was not reported for containers with exclusive CPUs and no CFS quota, such as Kubernetes pods with the `static` CPU manager policy (where `cpu.max` is `max` since Kubernetes 1.35), and `CGroupUserTimeNormalized` and `CGroupSystemTimeNormalized` were missing as well. [#132862](https://github.com/ClickHouse/ClickHouse/pull/132862) ([dilu-ch](https://github.com/dilu-ch)).
* Backported in [#133881](https://github.com/ClickHouse/ClickHouse/issues/133881): The secret first key argument of "keyed" SipHash SQL functions is now masked in `system.query_log`. [#133828](https://github.com/ClickHouse/ClickHouse/pull/133828) ([Robert Schulze](https://github.com/rschu1ze)).
