# 2026 Changelog

### ClickHouse release v26.9.30.7-stable (a43649d33fb) FIXME as compared to v26.9.29.5-stable (7dc8252760c)

#### Backward Incompatible Change
* Backported in [#131778](https://github.com/ClickHouse/ClickHouse/issues/131778): Settings of type `Seconds` (for example `max_execution_time` or `lock_acquire_timeout`) now reject a negative value with `BAD_ARGUMENTS`. A negative `max_execution_time` meant no limit and passed a `MAX` constraint; a value whose microseconds round to `2^63` (for example `9223372036854.775`) was stored as a large negative number; it is rejected too. Before upgrading, remove negative values of these settings from configuration files, settings profiles, users and table definitions, and let `Distributed` async insert queues drain; otherwise the server can fail to start, a user or table fails to load, or a queued insert is never sent. [#131269](https://github.com/ClickHouse/ClickHouse/pull/131269) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#131558](https://github.com/ClickHouse/ClickHouse/issues/131558): Fixed a use-after-free on reading a Delta Lake table with column mapping in which a column is stored under the name of another column (for example, after column mapping is enabled on an existing table and columns are renamed), when the columns are requested in a particular order, such as `SELECT k_old, k`. [#131029](https://github.com/ClickHouse/ClickHouse/pull/131029) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#131882](https://github.com/ClickHouse/ClickHouse/issues/131882): Check the scale of a `Decimal` value before formatting it as text, so a value with an out-of-range scale produces an exception instead of undefined behavior. [#131366](https://github.com/ClickHouse/ClickHouse/pull/131366) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#131804](https://github.com/ClickHouse/ClickHouse/issues/131804): Fix a possible crash of the `Template` input format when the format string for the result set does not contain `${data}`. Now it is an error. [#131730](https://github.com/ClickHouse/ClickHouse/pull/131730) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#131843](https://github.com/ClickHouse/ClickHouse/issues/131843): Fix a one-byte heap overflow when reading a `String` state of `any`/`min`/`max` (and similar) aggregate functions in an old format that ends without the zero terminator. Original fix by @motsc. [#131795](https://github.com/ClickHouse/ClickHouse/pull/131795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#131839](https://github.com/ClickHouse/ClickHouse/issues/131839): Fix a possible crash when restoring a backup from a zip archive with a password if an encrypted entry of the archive is smaller than the encryption header. [#131806](https://github.com/ClickHouse/ClickHouse/pull/131806) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
