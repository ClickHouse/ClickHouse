# 2026 Changelog

### ClickHouse release v26.9.24.8-stable (eb9d89e2a30) FIXME as compared to v26.9.23.15-stable (8b433c1d42f)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#126964](https://github.com/ClickHouse/ClickHouse/issues/126964): Fixed a query silently returning fewer rows after an unrelated `JOIN` had run: a join runtime filter (`enable_join_runtime_filters`) moved into a read's `PREWHERE` made the read record a "no matching rows" verdict in the query condition cache for granules, or Parquet row groups, whose rows only that runtime filter had removed. Such a read no longer populates the cache. [#119823](https://github.com/ClickHouse/ClickHouse/pull/119823) ([Groene AI](https://github.com/groeneai)).
* Backported in [#126711](https://github.com/ClickHouse/ClickHouse/issues/126711): Mask credentials embedded in HTTP URIs. [#120407](https://github.com/ClickHouse/ClickHouse/pull/120407) ([Han Fei](https://github.com/hanfei1991)).
* Backported in [#127049](https://github.com/ClickHouse/ClickHouse/issues/127049): Fix a stack overflow on a deeply nested query plan received in the `QueryPlan` packet of the native protocol. [#126548](https://github.com/ClickHouse/ClickHouse/pull/126548) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#127024](https://github.com/ClickHouse/ClickHouse/issues/127024): Fix use-after-free in complex key `ssd_cache` dictionaries when the cache file wraps around its partitions. Fix `CANNOT_READ_ALL_DATA` when reading long values of `ssd_cache` dictionaries from the cache file. [#126553](https://github.com/ClickHouse/ClickHouse/pull/126553) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#127076](https://github.com/ClickHouse/ClickHouse/issues/127076): Fixed `count()` with `WHERE d = toDate32('1900-01-01')` (or `!=`) over a MergeTree `Date32` column returning the number of `1970-01-01` rows when `optimize_trivial_count_with_sparsity_filter` is enabled (the default since 26.8). Closes [#126856](https://github.com/ClickHouse/ClickHouse/issues/126856). [#126942](https://github.com/ClickHouse/ClickHouse/pull/126942) ([Groene AI](https://github.com/groeneai)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

* Backported in [#126974](https://github.com/ClickHouse/ClickHouse/issues/126974): Remove object addresses from NATS, io_uring and HDFS messages. [#126741](https://github.com/ClickHouse/ClickHouse/pull/126741) ([Raúl Marín](https://github.com/Algunenano)).
* Backported in [#127087](https://github.com/ClickHouse/ClickHouse/issues/127087): Remove object addresses from logical error messages. [#126748](https://github.com/ClickHouse/ClickHouse/pull/126748) ([Raúl Marín](https://github.com/Algunenano)).
