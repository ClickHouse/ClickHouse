# 2026 Changelog

### ClickHouse release v26.7.25.6-stable (062f1949e4f) FIXME as compared to v26.7.24.8-stable (47aaf76ac61)

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#124514](https://github.com/ClickHouse/ClickHouse/issues/124514): Tables in a database with `lazy_load_tables` were missing from `system.parts`, `system.replicas` and related system tables, and refused by replica commands, after a restart. [#121332](https://github.com/ClickHouse/ClickHouse/pull/121332) ([Nikolay Degterinsky](https://github.com/evillique)).
* Backported in [#124398](https://github.com/ClickHouse/ClickHouse/issues/124398): Fix a server abort when reading an Iceberg table whose sort order names a transform ClickHouse cannot parse (e.g. `bucket[xyz]`); ClickHouse now ignores that sort-order hint and keeps the table readable. [#121687](https://github.com/ClickHouse/ClickHouse/pull/121687) ([Ilias](https://github.com/iliasabk)).
* Backported in [#124335](https://github.com/ClickHouse/ClickHouse/issues/124335): Fix `UNKNOWN_IDENTIFIER` in the analyzer when a table is referenced as `database.table` in `FROM` or `JOIN` and another table expression in the same query uses that database name as its alias, for example `FROM db.t1 AS db INNER JOIN db.t2 AS t ON ...`. Closes [#122239](https://github.com/ClickHouse/ClickHouse/issues/122239). [#124262](https://github.com/ClickHouse/ClickHouse/pull/124262) ([Dmitry Novik](https://github.com/novikd)).
* Backported in [#124458](https://github.com/ClickHouse/ClickHouse/issues/124458): Fixed wrong results when a `WHERE` clause mixing `AND` and `OR` was evaluated with skip indexes (`use_skip_indexes_for_disjunctions`, enabled by default). If a `minmax` or `set` index could not evaluate one atom of the predicate for a granule, the per-atom verdicts recorded for that granule were shifted, so one atom's verdict was applied to another and granules holding matching rows were skipped. [#124303](https://github.com/ClickHouse/ClickHouse/pull/124303) ([Groene AI](https://github.com/groeneai)).
