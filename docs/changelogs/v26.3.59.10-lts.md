# 2026 Changelog

### ClickHouse release v26.3.59.10-lts (4f0c8c19d30) FIXME as compared to v26.3.58.5-lts (62a7db9a8ff)

#### Performance Improvement
* Backported in [#127250](https://github.com/ClickHouse/ClickHouse/issues/127250): Combine I/O cost with selectivity in PREWHERE condition ordering. It fixes performance regression in PREWHERE execution in some cases introduced after https://github.com/ClickHouse/ClickHouse/pull/101275. Part of [#110462](https://github.com/ClickHouse/ClickHouse/issues/110462). [#110695](https://github.com/ClickHouse/ClickHouse/pull/110695) ([Pavel Kruglov](https://github.com/Avogar)).

#### Improvement
* Backported in [#127234](https://github.com/ClickHouse/ClickHouse/issues/127234): Fix a possible crash or out-of-bounds memory access when reading from HDFS if a DataNode or NameNode sends malformed responses. [#126546](https://github.com/ClickHouse/ClickHouse/pull/126546) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#127161](https://github.com/ClickHouse/ClickHouse/issues/127161): Fix a second-factor bypass in the MySQL protocol: a user configured with `plaintext_password` or `double_sha1_password` plus a time-based one-time password could authenticate with the password alone, because the `mysql_native_password` auth response was verified without checking the TOTP. Such users are now switched to the `sha256_password` plugin and must append the one-time password to the password, like `password+123456`. [#117407](https://github.com/ClickHouse/ClickHouse/pull/117407) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Backported in [#127247](https://github.com/ClickHouse/ClickHouse/issues/127247): Fixed a crash caused by a stack overflow when a deeply nested JSON document was parsed into a `JSON` column or passed to the `JSONExtract` family of functions. Such documents are now rejected with the `TOO_DEEP_RECURSION` error. [#120887](https://github.com/ClickHouse/ClickHouse/pull/120887) ([Pavel Kruglov](https://github.com/Avogar)).
* Backported in [#125885](https://github.com/ClickHouse/ClickHouse/issues/125885): Creating a FileLog tables now require READ and WRITE privileges, analogous to File tables. [#125701](https://github.com/ClickHouse/ClickHouse/pull/125701) ([Robert Schulze](https://github.com/rschu1ze)).
* Backported in [#127159](https://github.com/ClickHouse/ClickHouse/issues/127159): Fix a stack overflow on a deeply nested query plan received in the `QueryPlan` packet of the native protocol. [#126548](https://github.com/ClickHouse/ClickHouse/pull/126548) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#127101](https://github.com/ClickHouse/ClickHouse/issues/127101): Fix `polygonConvexHullCartesian` returning garbage for a polygon with an empty exterior ring and a non-empty interior ring. [#127015](https://github.com/ClickHouse/ClickHouse/pull/127015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#127176](https://github.com/ClickHouse/ClickHouse/issues/127176): Fixes a crash in estimateCompressionRatio with codecs DoubleDelta and Gorilla. [#127139](https://github.com/ClickHouse/ClickHouse/pull/127139) ([Robert Schulze](https://github.com/rschu1ze)).
* Fix a table failing to load on server start when its TTL `RECOMPRESS CODEC` has a codec chain that is rejected by the codec chain checks added in a previous patch release. [#127150](https://github.com/ClickHouse/ClickHouse/pull/127150) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
