# 2026 Changelog

### ClickHouse release v26.8.33.10-lts (4ca42662d1a) FIXME as compared to v26.8.32.14-lts (dc83db6f660)

#### Performance Improvement
* Backported in [#126579](https://github.com/ClickHouse/ClickHouse/issues/126579): An equality with a `Bool` value that no statistics can estimate, such as `WHERE j.f = false` on a JSON path, a `Bool` column without statistics, or `IN` with a `Bool` set, is now estimated to match half of the rows per value instead of 1%, so a join on such a filtered table builds its hash table from the smaller side again. [#125467](https://github.com/ClickHouse/ClickHouse/pull/125467) ([Groene AI](https://github.com/groeneai)).

#### Improvement
* Backported in [#126910](https://github.com/ClickHouse/ClickHouse/issues/126910): A `JOIN` whose `ON` condition has a constant-false conjunct now works with the experimental `parallel_replicas_plan_based` setting when the join uses `grace_hash`, spills to disk, or runs with `join_use_nulls = 1`, instead of terminating the server or failing with `NOT_FOUND_COLUMN_IN_BLOCK`. [#126204](https://github.com/ClickHouse/ClickHouse/pull/126204) ([Groene AI](https://github.com/groeneai)).

#### Bug Fix (user-visible misbehavior in an official stable release)
* Backported in [#126710](https://github.com/ClickHouse/ClickHouse/issues/126710): Mask credentials embedded in HTTP URIs. [#120407](https://github.com/ClickHouse/ClickHouse/pull/120407) ([Han Fei](https://github.com/hanfei1991)).
* Backported in [#125887](https://github.com/ClickHouse/ClickHouse/issues/125887): Creating a FileLog tables now require READ and WRITE privileges, analogous to File tables. [#125701](https://github.com/ClickHouse/ClickHouse/pull/125701) ([Robert Schulze](https://github.com/rschu1ze)).
* Backported in [#126909](https://github.com/ClickHouse/ClickHouse/issues/126909): Fixed a heap-use-after-free in the view dependency graph after renaming a materialized view whose query selects from itself. `CREATE MATERIALIZED VIEW` and `ALTER TABLE ... MODIFY QUERY` now reject a query that makes a materialized view select from itself. [#126292](https://github.com/ClickHouse/ClickHouse/pull/126292) ([Groene AI](https://github.com/groeneai)).
* Backported in [#127023](https://github.com/ClickHouse/ClickHouse/issues/127023): Fix use-after-free in complex key `ssd_cache` dictionaries when the cache file wraps around its partitions. Fix `CANNOT_READ_ALL_DATA` when reading long values of `ssd_cache` dictionaries from the cache file. [#126553](https://github.com/ClickHouse/ClickHouse/pull/126553) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Backported in [#127075](https://github.com/ClickHouse/ClickHouse/issues/127075): Fixed `count()` with `WHERE d = toDate32('1900-01-01')` (or `!=`) over a MergeTree `Date32` column returning the number of `1970-01-01` rows when `optimize_trivial_count_with_sparsity_filter` is enabled (the default since 26.8). Closes [#126856](https://github.com/ClickHouse/ClickHouse/issues/126856). [#126942](https://github.com/ClickHouse/ClickHouse/pull/126942) ([Groene AI](https://github.com/groeneai)).
* Backported in [#127103](https://github.com/ClickHouse/ClickHouse/issues/127103): Fix `polygonConvexHullCartesian` returning garbage for a polygon with an empty exterior ring and a non-empty interior ring. [#127015](https://github.com/ClickHouse/ClickHouse/pull/127015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

#### NOT FOR CHANGELOG / INSIGNIFICANT

[#113599](https://github.com/ClickHouse/ClickHouse/pull/113599) ([Groene AI](https://github.com/groeneai)).
