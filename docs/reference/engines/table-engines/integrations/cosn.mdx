The `COSN` engine provides integration with [Tencent Cloud Object Storage (COS)](https://www.tencentcloud.com/products/cos) through its Amazon S3-compatible API. It shares the implementation, parameters, and settings of the [`S3`](/reference/engines/table-engines/integrations/s3) table engine; see that engine's documentation for the full description, parameters, examples, and settings.

**Syntax**

```sql
ENGINE = COSN(url [, NOSIGN | access_key_id, secret_access_key [, session_token]] [, format] [, compression])
```
