Data skipping indexes are secondary indexes on `MergeTree`-family tables that let queries skip granules that provably cannot match. See the [`MergeTree` documentation](/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-data_skipping-indexes) for how indexes are declared and used, and [ALTER TABLE ... ADD INDEX](/reference/statements/alter/skipping-index) for managing them. The available index types:

| Type | Description |
|-----|-----|
| [`bloom_filter`](/reference/engines/table-engines/mergetree-family/skipping-indexes/bloom_filter) | A Bloom filter over the values of the index expression, for speeding up equality and IN conditions on columns, including Array and Map elements. |
| [`hypothesis`](/reference/engines/table-engines/mergetree-family/skipping-indexes/hypothesis) | Deprecated and no longer supported. It is retained only so that tables which still reference it can be attached. |
| [`minmax`](/reference/engines/table-engines/mergetree-family/skipping-indexes/minmax) | Stores the minimum and maximum values of the index expression for each granule, allowing granules to be skipped when a query's range condition cannot match. |
| [`ngrambf_v1`](/reference/engines/table-engines/mergetree-family/skipping-indexes/ngrambf_v1) | A Bloom filter over all n-grams of the index expression's string values, for speeding up LIKE, IN, equality and similar searches on substrings. |
| [`set`](/reference/engines/table-engines/mergetree-family/skipping-indexes/set) | Stores up to `max_rows` distinct values of the index expression per granule (0 means unlimited), allowing granules to be skipped for equality and IN conditions. |
| [`sparse_grams`](/reference/engines/table-engines/mergetree-family/skipping-indexes/sparse_grams) | A Bloom filter over the sparse n-grams of the index expression's string values, for speeding up substring searches. |
| [`text`](/reference/engines/table-engines/mergetree-family/skipping-indexes/text) | A full-text (inverted) index over the tokens of a string column, for speeding up text search functions such as `hasToken`, `hasAnyTokens`, `hasAllTokens`, and `hasPhrase`. |
| [`tokenbf_v1`](/reference/engines/table-engines/mergetree-family/skipping-indexes/tokenbf_v1) | A Bloom filter over the tokens (words) of the index expression's string values, for speeding up searches of whole tokens. |
| [`vector_similarity`](/reference/engines/table-engines/mergetree-family/skipping-indexes/vector_similarity) | An approximate nearest-neighbour index over a vector column (built using HNSW), for speeding up `ORDER BY <distance_function>(vector, reference) LIMIT n` queries. |
