Modifies an existing SQL cluster catalog shard: shard-level properties and the list of replica endpoints.

Requires [`cluster_metadata`](/operations/sql-clusters#configuration) and the `CREATE SHARD` privilege.

## Syntax {#syntax}

```sql
ALTER SHARD [IF EXISTS] name
    MODIFY PROPERTIES (name = value [, ...])
  | ADD REPLICA endpoint
  | DROP REPLICA endpoint
  | REPLACE from_list TO to_list
      [, REPLACE from_list TO to_list ...]
      [MODIFY PROPERTIES (name = value [, ...])]
[ON CLUSTER cluster_name]
[SYNC]
```

## Notes {#notes}

- `MODIFY PROPERTIES` accepts only shard-level keys: `weight`, `internal_replication`.
- `ADD REPLICA` attaches an existing endpoint; create the endpoint with `CREATE ENDPOINT` first.
- `DROP REPLICA` removes the endpoint from the shard list without dropping the endpoint. The last replica cannot be dropped.
- `REPLACE ... TO ...` remaps endpoints pairwise; both lists must have the same length.

## Examples {#examples}

```sql
ALTER SHARD shard_01 MODIFY PROPERTIES (weight = 7, internal_replication = true);

ALTER SHARD shard_01 ADD REPLICA replica_03;

ALTER SHARD shard_01 DROP REPLICA replica_02;

ALTER SHARD shard_01 REPLACE replica_01 TO replica_03
    MODIFY PROPERTIES (weight = 1);
```
