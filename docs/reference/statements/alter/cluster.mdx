Modifies membership and optional properties of an existing SQL-managed cluster.

Requires [`cluster_metadata`](/guides/oss/deployment-and-scaling/sql-clusters#configuration) and the `CREATE CLUSTER` privilege.

## Syntax {#syntax}

```sql
ALTER CLUSTER [IF EXISTS] name
    ADD SHARD shard [, ...]
  | DROP SHARD shard [, ...]
  | REPLACE from_list TO to_list
      [, REPLACE from_list TO to_list ...]
      [MODIFY PROPERTIES (name = value [, ...])]
[ON CLUSTER cluster_name]
[SYNC]
```

## Notes {#notes}

- `ADD SHARD` appends existing SQL shards (`CREATE SHARD`).
- `DROP SHARD` removes members; the last member cannot be dropped.
- `REPLACE ... TO ...` remaps members pairwise; both lists must have the same length.
- Optional trailing `MODIFY PROPERTIES` accepts cluster-level keys: `secret`, `allow_distributed_ddl_queries`.
- `ALTER CLUSTER ... MODIFY SHARD` and `ALTER CLUSTER ... RENAME SHARD` are not implemented yet. Use `ALTER SHARD` for shard options.

## Examples {#examples}

```sql
ALTER CLUSTER analytics ADD SHARD shard_03;

ALTER CLUSTER analytics DROP SHARD shard_02;

ALTER CLUSTER analytics REPLACE shard_01 TO shard_03
    MODIFY PROPERTIES (secret = 'new-secret');
```
