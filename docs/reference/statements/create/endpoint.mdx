Creates a SQL cluster catalog endpoint: connection parameters for one remote ClickHouse host used by `CREATE SHARD`.

Requires [`cluster_metadata`](/operations/sql-clusters#configuration) in the server configuration and the `CREATE ENDPOINT` privilege.

## Syntax {#syntax}

```sql
CREATE ENDPOINT [IF NOT EXISTS] name
PROPERTIES (name = value [, ...])
[SYNC]
```

## Properties {#properties}

| Property | Required | Default | Description |
| --- | --- | --- | --- |
| `host` | Yes | — | IPv4, IPv6, or hostname |
| `port` | Yes | — | TCP port (`1`–`65535`) |
| `user` | No | `default` | User for the connection |
| `password` | No | empty | Password |
| `secure` | No | `false` | Use SSL/TLS |
| `compression` | No | `true` | Enable compression |
| `priority` | No | `1` | Load-balancing priority |
| `bind_host` | No | empty | Source bind address |
| `default_database` | No | empty | Default database on the remote host |

## Example {#example}

```sql
CREATE ENDPOINT replica_01 PROPERTIES (
    host = 'ch1.example.com',
    port = 9000,
    user = 'default',
    password = 'secret',
    secure = 0
);
```
