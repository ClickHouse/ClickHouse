Creates a SQL cluster catalog shard: an ordered list of endpoints (replicas) with optional weight and internal replication settings.

Requires [`cluster_metadata`](/operations/sql-clusters#configuration) in the server configuration and the `CREATE SHARD` privilege. Each replica name must already exist as an endpoint (`CREATE ENDPOINT`).

## Syntax {#syntax}

```sql
CREATE SHARD [IF NOT EXISTS] name
    REPLICA endpoint [, ...]
  | REPLICA (endpoint [, ...])
  | (endpoint [, ...])
[PROPERTIES (name = value [, ...])]
[ON CLUSTER cluster_name]
[SYNC]
```

## Properties {#properties}

| Property | Required | Default | Description |
| --- | --- | --- | --- |
| `weight` | No | `1` | Relative write weight (`1`–`4294967295`) |
| `internal_replication` | No | `false` | Same meaning as `<internal_replication>` in `remote_servers` |

Only shard-level keys are allowed here. Replica connection keys (`host`, `port`, …) belong on `CREATE ENDPOINT`.

## Examples {#examples}

```sql
CREATE SHARD shard_01 REPLICA replica_01, replica_02;

CREATE SHARD shard_01 REPLICA (replica_01, replica_02)
    PROPERTIES (weight = 1, internal_replication = true);

CREATE SHARD shard_01 (replica_01, replica_02);
```
