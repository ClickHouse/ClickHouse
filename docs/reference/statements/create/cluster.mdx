Creates a SQL-managed cluster from existing SQL shards. After materialization, the cluster is available like a `remote_servers` cluster (for example for `Distributed` tables, the `cluster` table function, and `ON CLUSTER` DDL).

Requires [`cluster_metadata`](/operations/sql-clusters#configuration) in the server configuration and the `CREATE CLUSTER` privilege. Every member must already exist as a SQL shard (`CREATE SHARD`).

## Syntax {#syntax}

```sql
CREATE CLUSTER [IF NOT EXISTS] name (shard [, ...])
[PROPERTIES (name = value [, ...])]
[ON CLUSTER cluster_name]
[SYNC]
```

## Properties {#properties}

| Property | Required | Default | Description |
| --- | --- | --- | --- |
| `secret` | No | empty | Inter-node secret for Distributed / interserver authentication |
| `allow_distributed_ddl_queries` | No | `true` | Whether distributed DDL is allowed on this cluster |

## Examples {#examples}

```sql
CREATE CLUSTER analytics (shard_01, shard_02);

CREATE CLUSTER analytics (shard_01, shard_02)
    PROPERTIES (
        secret = 'interserver-secret',
        allow_distributed_ddl_queries = true
    );
```
