## Description {#description}

[Portable Game Notation](https://en.wikipedia.org/wiki/Portable_Game_Notation) (`PGN`) is the standard
text format for recording chess games. A `PGN` file is a sequence of games, and every game consists of:

1. **Tags**: metadata about the game, one `[TagName "TagValue"]` pair per line;
2. **Move text**: the moves of the game in standard algebraic notation, optionally interleaved with move
   numbers, comments, variations and numeric annotation glyphs, and terminated by the result.

Each game is read as one row.
