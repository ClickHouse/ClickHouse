## toMicrosecond {#toMicrosecond}

Introduced in: v25.7.0

Returns the microsecond component (0-999999) of a `DateTime64` value.
    

**Syntax**

```sql
toMicrosecond(datetime)
```

**Aliases**: `MICROSECOND`

**Arguments**

- `datetime` — Date with time to get the microsecond from. [`DateTime64`](/reference/data-types/datetime64)

**Returned value**

Returns the microsecond in the second (0 - 999999) of `datetime`. [`UInt32`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT toMicrosecond(toDateTime64('2023-04-21 10:20:30.456789', 6));
```

```response title=Response
┌─toMicrosecond(toDateTime64('2023-04-21 10:20:30.456789', 6))─┐
│                                                       456789 │
└──────────────────────────────────────────────────────────────┘
```
