## toNanosecond {#toNanosecond}

Introduced in: v25.7.0

Returns the nanosecond component (0-999999999) of a `DateTime64` value.
    

**Syntax**

```sql
toNanosecond(datetime)
```

**Aliases**: `NANOSECOND`

**Arguments**

- `datetime` — Date with time to get the nanosecond from. [`DateTime64`](/reference/data-types/datetime64)

**Returned value**

Returns the nanosecond in the second (0 - 999999999) of `datetime`. [`UInt32`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT toNanosecond(toDateTime64('2023-04-21 10:20:30.123456789', 9));
```

```response title=Response
┌─toNanosecond(toDateTime64('2023-04-21 10:20:30.123456789', 9))─┐
│                                                      123456789 │
└────────────────────────────────────────────────────────────────┘
```
