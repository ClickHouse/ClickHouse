## today {#today}

Introduced in: v1.1.0

Returns the current date at moment of query analysis. Same as `toDate(now())`.

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
today()
```

**Aliases**: `current_date`, `curdate`

**Arguments**

- None.

**Returned value**

Returns the current date [`Date`](/reference/data-types/date)

**Examples**

**Usage example**

```sql title=Query
SELECT today() AS today, curdate() AS curdate, current_date() AS current_date FORMAT Pretty
```
