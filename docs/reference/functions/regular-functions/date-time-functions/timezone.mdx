## timezone {#timezone}

Introduced in: v21.4.0

Returns the time zone name of the current session or converts a time zone
offset or name to a canonical time zone name.
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
timezone()
```

**Aliases**: `timeZone`

**Arguments**

- None.

**Returned value**

Returns the canonical time zone name as a [`String`](/reference/data-types/string)

**Examples**

**Usage example**

```sql title=Query
SELECT timezone()
```

```response title=Response
┌─timezone()───────┐
│ Europe/Amsterdam │
└──────────────────┘
```
