## toFloat64OrZero {#toFloat64OrZero}

Introduced in: v1.1.0

Converts an input value to a value of type [Float64](/reference/data-types/float) but returns `0` in case of an error.
Like [`toFloat64`](/reference/functions/regular-functions/type-conversion-functions/toFloat64) but returns `0` instead of throwing an exception on conversion errors.

See also:
- [`toFloat64`](/reference/functions/regular-functions/type-conversion-functions/toFloat64).
- [`toFloat64OrNull`](/reference/functions/regular-functions/type-conversion-functions/toFloat64OrNull).
- [`toFloat64OrDefault`](/reference/functions/regular-functions/type-conversion-functions/toFloat64OrDefault).
    

**Syntax**

```sql
toFloat64OrZero(x)
```

**Arguments**

- `x` — A string representation of a number. [`String`](/reference/data-types/string)

**Returned value**

Returns a 64-bit Float value if successful, otherwise `0`. [`Float64`](/reference/data-types/float)

**Examples**

**Usage example**

```sql title=Query
SELECT
    toFloat64OrZero('42.7'),
    toFloat64OrZero('abc')
FORMAT Vertical
```

```response title=Response
Row 1:
──────
toFloat64OrZero('42.7'): 42.7
toFloat64OrZero('abc'):  0
```
