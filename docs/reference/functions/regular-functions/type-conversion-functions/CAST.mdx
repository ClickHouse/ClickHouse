## CAST {#CAST}

Introduced in: v1.1.0

Converts a value to a specified data type.
Unlike the reinterpret function, CAST tries to generate the same value in the target type.
If that is not possible, an exception is raised.
    

**Syntax**

```sql
CAST(x, T)
or CAST(x AS T)
or x::T
```

**Arguments**

- `x` — A value of any type. [`Any`](/reference/data-types/index)
- `T` — The target data type. [`String`](/reference/data-types/string)

**Returned value**

Returns the converted value with the target data type. [`Any`](/reference/data-types/index)

**Examples**

**Basic usage**

```sql title=Query
SELECT CAST(42, 'String')
```

```response title=Response
┌─CAST(42, 'String')─┐
│ 42                 │
└────────────────────┘
```

**Using AS syntax**

```sql title=Query
SELECT CAST('2025-01-01' AS Date)
```

```response title=Response
┌─CAST('2025-01-01', 'Date')─┐
│                 2025-01-01 │
└────────────────────────────┘
```

**Using :: syntax**

```sql title=Query
SELECT '123'::UInt32
```

```response title=Response
┌─CAST('123', 'UInt32')─┐
│                   123 │
└───────────────────────┘
```
