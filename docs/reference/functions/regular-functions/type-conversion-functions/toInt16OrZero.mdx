## toInt16OrZero {#toInt16OrZero}

Introduced in: v1.1.0

Like [`toInt16`](/reference/functions/regular-functions/type-conversion-functions/toInt16), this function converts an input value to a value of type [Int16](/reference/data-types/int-uint) but returns `0` in case of an error.

Supported arguments:
- String representations of (U)Int*.

Unsupported arguments (return `0`):
- String representations of Float* values, including `NaN` and `Inf`.
- String representations of binary and hexadecimal values, e.g. `SELECT toInt16OrZero('0xc0fe');`.

<Note>
If the input value cannot be represented within the bounds of [Int16](/reference/data-types/int-uint), overflow or underflow of the result occurs.
This is not considered an error.
</Note>

See also:
- [`toInt16`](/reference/functions/regular-functions/type-conversion-functions/toInt16).
- [`toInt16OrNull`](/reference/functions/regular-functions/type-conversion-functions/toInt16OrNull).
- [`toInt16OrDefault`](/reference/functions/regular-functions/type-conversion-functions/toInt16OrDefault).
    

**Syntax**

```sql
toInt16OrZero(x)
```

**Arguments**

- `x` — A String representation of a number. [`String`](/reference/data-types/string)

**Returned value**

Returns a value of type Int16, otherwise `0` if the conversion is unsuccessful. [`Int16`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT
    toInt16OrZero('16'),
    toInt16OrZero('abc')
FORMAT Vertical
```

```response title=Response
Row 1:
──────
toInt16OrZero('16'): 16
toInt16OrZero('abc'): 0
```
