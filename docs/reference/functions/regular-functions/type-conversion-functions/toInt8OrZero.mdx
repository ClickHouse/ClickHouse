## toInt8OrZero {#toInt8OrZero}

Introduced in: v1.1.0

Like [`toInt8`](/reference/functions/regular-functions/type-conversion-functions/toInt8), this function converts an input value to a value of type [Int8](/reference/data-types/int-uint) but returns `0` in case of an error.

Supported arguments:
- String representations of (U)Int*.

Unsupported arguments (return `0`):
- String representations of Float* values, including `NaN` and `Inf`.
- String representations of binary and hexadecimal values, e.g. `SELECT toInt8OrZero('0xc0fe');`.

<Note>
If the input value cannot be represented within the bounds of [Int8](/reference/data-types/int-uint), overflow or underflow of the result occurs.
This is not considered an error.
</Note>

See also:
- [`toInt8`](/reference/functions/regular-functions/type-conversion-functions/toInt8).
- [`toInt8OrNull`](/reference/functions/regular-functions/type-conversion-functions/toInt8OrNull).
- [`toInt8OrDefault`](/reference/functions/regular-functions/type-conversion-functions/toInt8OrDefault).
    

**Syntax**

```sql
toInt8OrZero(x)
```

**Arguments**

- `x` — A String representation of a number. [`String`](/reference/data-types/string)

**Returned value**

Returns a value of type Int8, otherwise `0` if the conversion is unsuccessful. [`Int8`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT
    toInt8OrZero('8'),
    toInt8OrZero('abc')
FORMAT Vertical
```

```response title=Response
Row 1:
──────
toInt8OrZero('8'): 8
toInt8OrZero('abc'): 0
```
