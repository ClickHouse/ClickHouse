## toUInt64OrNull {#toUInt64OrNull}

Introduced in: v1.1.0

Like [`toUInt64`](/reference/functions/regular-functions/type-conversion-functions/toUInt64), this function converts an input value to a value of type [`UInt64`](/reference/data-types/int-uint) but returns `NULL` in case of an error.

Supported arguments:
- String representations of (U)Int*.

Unsupported arguments (return `NULL`):
- String representations of Float* values, including `NaN` and `Inf`.
- String representations of binary and hexadecimal values, e.g. `SELECT toUInt64OrNull('0xc0fe');`.

<Note>
If the input value cannot be represented within the bounds of [`UInt64`](/reference/data-types/int-uint), overflow or underflow of the result occurs.
This is not considered an error.
</Note>

See also:
- [`toUInt64`](/reference/functions/regular-functions/type-conversion-functions/toUInt64).
- [`toUInt64OrZero`](/reference/functions/regular-functions/type-conversion-functions/toUInt64OrZero).
- [`toUInt64OrDefault`](/reference/functions/regular-functions/type-conversion-functions/toUInt64OrDefault).
    

**Syntax**

```sql
toUInt64OrNull(x)
```

**Arguments**

- `x` — A String representation of a number. [`String`](/reference/data-types/string)

**Returned value**

Returns a value of type UInt64, otherwise `NULL` if the conversion is unsuccessful. [`UInt64`](/reference/data-types/int-uint) or [`NULL`](/reference/syntax#null)

**Examples**

**Usage example**

```sql title=Query
SELECT
    toUInt64OrNull('64'),
    toUInt64OrNull('abc')
FORMAT Vertical
```

```response title=Response
Row 1:
──────
toUInt64OrNull('64'):  64
toUInt64OrNull('abc'): \N
```
