## toDateTime64OrNull {#toDateTime64OrNull}

Introduced in: v20.1.0

Converts an input value to a value of type `DateTime64` but returns `NULL` if an invalid argument is received.
The same as `toDateTime64` but returns `NULL` if an invalid argument is received.
An integer argument is interpreted as a Unix timestamp in whole seconds and produces `NULL` if it is out of range of the `DateTime64` type.
    

**Syntax**

```sql
toDateTime64OrNull(x[, precision[, timezone]])
```

**Arguments**

- `x` — A string representation of a date with time and subsecond precision, or an integer Unix timestamp. [`String`](/reference/data-types/string) or [`(U)Int8/16/32/64`](/reference/data-types/int-uint)
- `precision` — Optional. The subsecond precision of the returned value. [`UInt8`](/reference/data-types/int-uint)
- `timezone` — Optional. Time zone of the returned value. [`String`](/reference/data-types/string)

**Returned value**

Returns a DateTime64 value if successful, otherwise `NULL`. [`DateTime64`](/reference/data-types/datetime64) or [`NULL`](/reference/syntax#null)

**Examples**

**Usage example**

```sql title=Query
SELECT toDateTime64OrNull('2025-12-30 13:44:17.123'), toDateTime64OrNull('invalid')
```
