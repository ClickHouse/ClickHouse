## toTimeOrNull {#toTimeOrNull}

Introduced in: v1.1.0

Converts an input value to a value of type Time but returns `NULL` in case of an error.
Like [`toTime`](/reference/functions/regular-functions/type-conversion-functions/toTime) but returns `NULL` instead of throwing an exception on conversion errors.

See also:
- [`toTime`](/reference/functions/regular-functions/type-conversion-functions/toTime)
- [`toTimeOrZero`](/reference/functions/regular-functions/type-conversion-functions/toTimeOrZero)
    

**Syntax**

```sql
toTimeOrNull(x)
```

**Arguments**

- `x` — A string representation of a time. [`String`](/reference/data-types/string)

**Returned value**

Returns a Time value if successful, otherwise `NULL`. [`Time`](/reference/data-types/time) or [`NULL`](/reference/syntax#null)

**Examples**

**Usage example**

```sql title=Query
SELECT toTimeOrNull('12:30:45'), toTimeOrNull('invalid')
```

```response title=Response
│                 12:30:45 │                    ᴺᵁᴸᴸ │
└──────────────────────────┴─────────────────────────┘
```
