## toUInt256OrZero {#toUInt256OrZero}

Introduced in: v20.8.0

Like [`toUInt256`](/reference/functions/regular-functions/type-conversion-functions/toUInt256), this function converts an input value to a value of type [`UInt256`](/reference/data-types/int-uint) but returns `0` in case of an error.

Supported arguments:
- String representations of (U)Int*.

Unsupported arguments (return `0`):
- String representations of Float* values, including `NaN` and `Inf`.
- String representations of binary and hexadecimal values, e.g. `SELECT toUInt256OrZero('0xc0fe');`.

<Note>
If the input value cannot be represented within the bounds of [`UInt256`](/reference/data-types/int-uint), overflow or underflow of the result occurs.
This is not considered an error.
</Note>

See also:
- [`toUInt256`](/reference/functions/regular-functions/type-conversion-functions/toUInt256).
- [`toUInt256OrNull`](/reference/functions/regular-functions/type-conversion-functions/toUInt256OrNull).
- [`toUInt256OrDefault`](/reference/functions/regular-functions/type-conversion-functions/toUInt256OrDefault).
    

**Syntax**

```sql
toUInt256OrZero(x)
```

**Arguments**

- `x` — A String representation of a number. [`String`](/reference/data-types/string)

**Returned value**

Returns a value of type UInt256, otherwise `0` if the conversion is unsuccessful. [`UInt256`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT
    toUInt256OrZero('256'),
    toUInt256OrZero('abc')
FORMAT Vertical
```

```response title=Response
Row 1:
──────
toUInt256OrZero('256'): 256
toUInt256OrZero('abc'): 0
```
