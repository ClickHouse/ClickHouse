## toTime64 {#toTime64}

Introduced in: v25.6.0

Converts an input value to type [Time64](/reference/data-types/time64).
Supports conversion from String, FixedString, DateTime64, or numeric types representing seconds since midnight.
Provides sub-second precision for time values, up to `scale` fractional digits.
    

**Syntax**

```sql
toTime64(x, scale)
```

**Arguments**

- `x` — Input value to convert. [`String`](/reference/data-types/string) or [`FixedString`](/reference/data-types/fixedstring) or [`DateTime64`](/reference/data-types/datetime64) or [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)
- `scale` — Precision (number of fractional digits, `0`–`9`) of the resulting `Time64`. [`(U)Int*`](/reference/data-types/int-uint)

**Returned value**

Returns the converted value with the requested `scale`. [`Time64`](/reference/data-types/time64)

**Examples**

**String to Time64 conversion**

```sql title=Query
SET enable_time_time64_type = 1;
SELECT toTime64('14:30:25.123456', 6)
```

```response title=Response
14:30:25.123456
```

**DateTime64 to Time64 conversion**

```sql title=Query
SET enable_time_time64_type = 1;
SELECT toTime64(toDateTime64('2025-04-15 14:30:25.123456', 6), 6)
```

```response title=Response
14:30:25.123456
```

**Float (seconds since midnight) to Time64 conversion**

```sql title=Query
SET enable_time_time64_type = 1;
SELECT toTime64(52225.123456, 6)
```

```response title=Response
14:30:25.123456
```
