## toUInt128OrNull {#toUInt128OrNull}

Introduced in: v21.6.0

Like [`toUInt128`](/reference/functions/regular-functions/type-conversion-functions/toUInt128), this function converts an input value to a value of type [`UInt128`](/reference/data-types/int-uint) but returns `NULL` in case of an error.

Supported arguments:
- String representations of (U)Int*.

Unsupported arguments (return `NULL`):
- String representations of Float* values, including `NaN` and `Inf`.
- String representations of binary and hexadecimal values, e.g. `SELECT toUInt128OrNull('0xc0fe');`.

<Note>
If the input value cannot be represented within the bounds of [`UInt128`](/reference/data-types/int-uint), overflow or underflow of the result occurs.
This is not considered an error.
</Note>

See also:
- [`toUInt128`](/reference/functions/regular-functions/type-conversion-functions/toUInt128).
- [`toUInt128OrZero`](/reference/functions/regular-functions/type-conversion-functions/toUInt128OrZero).
- [`toUInt128OrDefault`](/reference/functions/regular-functions/type-conversion-functions/toUInt128OrDefault).
    

**Syntax**

```sql
toUInt128OrNull(x)
```

**Arguments**

- `x` — A String representation of a number. [`String`](/reference/data-types/string)

**Returned value**

Returns a value of type UInt128, otherwise `NULL` if the conversion is unsuccessful. [`UInt128`](/reference/data-types/int-uint) or [`NULL`](/reference/syntax#null)

**Examples**

**Usage example**

```sql title=Query
SELECT
    toUInt128OrNull('128'),
    toUInt128OrNull('abc')
FORMAT Vertical
```

```response title=Response
Row 1:
──────
toUInt128OrNull('128'): 128
toUInt128OrNull('abc'): \N
```
