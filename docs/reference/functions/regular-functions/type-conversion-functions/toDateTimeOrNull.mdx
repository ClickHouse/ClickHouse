## toDateTimeOrNull {#toDateTimeOrNull}

Introduced in: v1.1.0

Converts an input value to a value of type `DateTime` but returns `NULL` if an invalid argument is received.
The same as [`toDateTime`](/reference/functions/regular-functions/type-conversion-functions/toDateTime) but returns `NULL` if an invalid argument is received.
An integer argument is interpreted as a Unix timestamp and produces `NULL` if it is out of range of the `DateTime` type.
    

**Syntax**

```sql
toDateTimeOrNull(x[, timezone])
```

**Arguments**

- `x` — A string representation of a date with time, or an integer Unix timestamp. [`String`](/reference/data-types/string) or [`(U)Int8/16/32/64`](/reference/data-types/int-uint)
- `timezone` — Optional. Time zone of the returned value. [`String`](/reference/data-types/string)

**Returned value**

Returns a `DateTime` value if successful, otherwise `NULL`. [`DateTime`](/reference/data-types/datetime) or [`NULL`](/reference/syntax#null)

**Examples**

**Usage example**

```sql title=Query
SELECT toDateTimeOrNull('2025-12-30 13:44:17'), toDateTimeOrNull('invalid')
```

```response title=Response
┌─toDateTimeOrNull('2025-12-30 13:44:17')─┬─toDateTimeOrNull('invalid')─┐
│                     2025-12-30 13:44:17 │                        ᴺᵁᴸᴸ │
└─────────────────────────────────────────┴─────────────────────────────┘
```

**Integer argument with a time zone**

```sql title=Query
SELECT toDateTimeOrNull(1583851242, 'Asia/Shanghai'), toDateTimeOrNull(4294967296)
```

```response title=Response
┌─toDateTimeOrNull(1583851242, 'Asia/Shanghai')─┬─toDateTimeOrNull(4294967296)─┐
│                           2020-03-10 22:40:42 │                         ᴺᵁᴸᴸ │
└───────────────────────────────────────────────┴──────────────────────────────┘
```
