## getSetting {#getSetting}

Introduced in: v20.7.0

Returns the current value of a setting.

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
getSetting(setting_name)
```

**Arguments**

- `setting_Name` — The setting name. [`const String`](/reference/data-types/string)

**Returned value**

Returns the setting's current value. [`Any`](/reference/data-types/index)

**Examples**

**Usage example**

```sql title=Query
SELECT getSetting('enable_analyzer');
SET enable_analyzer = false;
SELECT getSetting('enable_analyzer');
```

```response title=Response
┌─getSetting('⋯_analyzer')─┐
│ true                     │
└──────────────────────────┘
┌─getSetting('⋯_analyzer')─┐
│ false                    │
└──────────────────────────┘
```
