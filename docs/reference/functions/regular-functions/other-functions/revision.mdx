## revision {#revision}

Introduced in: v22.7.0

Returns the current ClickHouse server revision.
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
revision()
```

**Arguments**

- None.

**Returned value**

Returns the current ClickHouse server revision. [`UInt32`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT revision()
```

```response title=Response
┌─revision()─┐
│      54485 │
└────────────┘
```
