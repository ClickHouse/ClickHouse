## rowNumberInAllBlocks {#rowNumberInAllBlocks}

Introduced in: v1.1.0

Returns a unique row number for each row processed.
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
rowNumberInAllBlocks()
```

**Arguments**

- None.

**Returned value**

Returns the ordinal number of the row in the data block starting from `0`. [`UInt64`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT rowNumberInAllBlocks()
FROM
(
    SELECT *
    FROM system.numbers_mt
    LIMIT 10
)
SETTINGS max_block_size = 2
```
