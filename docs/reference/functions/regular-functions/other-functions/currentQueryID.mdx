## currentQueryID {#currentQueryID}

Introduced in: v25.2.0

Returns current Query id.

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
currentQueryID()
```

**Aliases**: `current_query_id`

**Arguments**

- None.

**Returned value**

**Examples**

**Example**

```sql title=Query
SELECT currentQueryID();
```
