## defaultRoles {#defaultRoles}

Introduced in: v21.9.0

Returns an array of default roles for the current user.
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
defaultRoles()
```

**Arguments**

- None.

**Returned value**

Returns an array of default roles for the current user. [`Array(String)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT defaultRoles();
```
