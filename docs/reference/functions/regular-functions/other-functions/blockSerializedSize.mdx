## blockSerializedSize {#blockSerializedSize}

Introduced in: v20.3.0

Returns the uncompressed size in bytes of a block of values on disk.

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
blockSerializedSize(x1[, x2[, ...]])
```

**Arguments**

- `x1[, x2, ...]` — Any number of values for which to get the uncompressed size of the block. [`Any`](/reference/data-types/index)

**Returned value**

Returns the number of bytes that will be written to disk for a block of values without compression. [`UInt64`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT blockSerializedSize(maxState(1)) AS x;
```

```response title=Response
┌─x─┐
│ 2 │
└───┘
```
