## currentDatabase {#currentDatabase}

Introduced in: v1.1.0

Returns the name of the current database.
Useful in table engine parameters of `CREATE TABLE` queries where you need to specify the database.

Also see the [`SET` statement](/reference/statements/use).
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
currentDatabase()
```

**Aliases**: `current_database`, `DATABASE`, `SCHEMA`

**Arguments**

- None.

**Returned value**

Returns the current database name. [`String`](/reference/data-types/string)

**Examples**

**Usage example**

```sql title=Query
SELECT currentDatabase()
```
