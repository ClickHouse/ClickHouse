## getServerSetting {#getServerSetting}

Introduced in: v25.6.0

Returns the currently set value, given a server setting name.
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
getServerSetting(setting_name')
```

**Arguments**

- `setting_name` — The server setting name. [`String`](/reference/data-types/string)

**Returned value**

Returns the server setting's current value. [`Any`](/reference/data-types/index)

**Examples**

**Usage example**

```sql title=Query
SELECT getServerSetting('allow_use_jemalloc_memory');
```

```response title=Response
┌─getServerSetting('allow_use_jemalloc_memory')─┐
│ true                                          │
└───────────────────────────────────────────────┘
```
