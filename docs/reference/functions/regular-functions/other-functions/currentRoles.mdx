## currentRoles {#currentRoles}

Introduced in: v21.9.0

Returns an array of the roles which are assigned to the current user.
    

<Note>
This function is non-deterministic: it can return different results for the same arguments.
</Note>

**Syntax**

```sql
currentRoles()
```

**Arguments**

- None.

**Returned value**

Returns an array of the roles which are assigned to the current user. [`Array(String)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT currentRoles();
```
