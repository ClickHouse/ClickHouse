## ignore {#ignore}

Introduced in: v1.1.0

Accepts arbitrary arguments and unconditionally returns `0`.
    

**Syntax**

```sql
ignore(x)
```

**Arguments**

- `x` — An input value which is unused and passed only so as to avoid a syntax error. [`Any`](/reference/data-types/index)

**Returned value**

Always returns `0`. [`UInt8`](/reference/data-types/int-uint)

**Examples**

**Usage example**

```sql title=Query
SELECT ignore(0, 'ClickHouse', NULL)
```

```response title=Response
│                             0 │
└───────────────────────────────┘
```
