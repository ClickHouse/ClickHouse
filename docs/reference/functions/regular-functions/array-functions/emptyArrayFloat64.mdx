## emptyArrayFloat64 {#emptyArrayFloat64}

Introduced in: v1.1.0

Returns an empty Float64 array

**Syntax**

```sql
emptyArrayFloat64()
```

**Arguments**

- None.

**Returned value**

An empty Float64 array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayFloat64()
```

```response title=Response
[]
```
