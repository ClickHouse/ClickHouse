## emptyArrayString {#emptyArrayString}

Introduced in: v1.1.0

Returns an empty String array

**Syntax**

```sql
emptyArrayString()
```

**Arguments**

- None.

**Returned value**

An empty String array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayString()
```

```response title=Response
[]
```
