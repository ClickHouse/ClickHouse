## emptyArrayInt8 {#emptyArrayInt8}

Introduced in: v1.1.0

```sql

```

**Arguments**

- None.

**Returned value**

An empty Int8 array. [`Array(T)`](/reference/data-types/array)

**Usage example**

```sql title=Query
SELECT emptyArrayInt8()
```
