## emptyArrayDateTime {#emptyArrayDateTime}

Introduced in: v1.1.0

Returns an empty DateTime array

**Syntax**

```sql
emptyArrayDateTime()
```

**Arguments**

- None.

**Returned value**

An empty DateTime array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayDateTime()
```

```response title=Response
[]
```
