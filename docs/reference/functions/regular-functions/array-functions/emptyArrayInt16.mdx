## emptyArrayInt16 {#emptyArrayInt16}

Introduced in: v1.1.0

**Syntax**

```sql
emptyArrayInt16()
```

**Arguments**

- None.

**Returned value**

An empty Int16 array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayInt16()
```
