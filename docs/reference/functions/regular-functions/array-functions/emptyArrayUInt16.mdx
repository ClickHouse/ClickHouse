## emptyArrayUInt16 {#emptyArrayUInt16}

Introduced in: v1.1.0

Returns an empty UInt16 array

**Syntax**

```sql
emptyArrayUInt16()
```

**Arguments**

- None.

**Returned value**

An empty UInt16 array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayUInt16()
```

```response title=Response
[]
```
