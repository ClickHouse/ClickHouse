## replicate {#replicate}

Introduced in: v1.1.0

Creates an array with a single value.

**Syntax**

```sql
replicate(x, arr)
```

**Arguments**

- `x` — The value to fill the result array with. [`Any`](/reference/data-types/index)
- `arr` — An array. [`Array(T)`](/reference/data-types/array)

**Returned value**

Returns an array of the same length as `arr` filled with value `x`. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT replicate(1, ['a', 'b', 'c']);
```

```response title=Response
┌─replicate(1, ['a', 'b', 'c'])───┐
│ [1, 1, 1]                       │
└─────────────────────────────────┘
```
