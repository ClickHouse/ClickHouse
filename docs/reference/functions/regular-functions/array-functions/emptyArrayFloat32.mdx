## emptyArrayFloat32 {#emptyArrayFloat32}

Introduced in: v1.1.0

Returns an empty Float32 array

**Syntax**

```sql
emptyArrayFloat32()
```

**Arguments**

- None.

**Returned value**

An empty Float32 array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayFloat32()
```

```response title=Response
[]
```
