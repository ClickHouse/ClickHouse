## emptyArrayUInt8 {#emptyArrayUInt8}

Introduced in: v1.1.0

Returns an empty UInt8 array

**Syntax**

```sql
emptyArrayUInt8()
```

**Arguments**

- None.

**Returned value**

An empty UInt8 array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayUInt8()
```

[]
