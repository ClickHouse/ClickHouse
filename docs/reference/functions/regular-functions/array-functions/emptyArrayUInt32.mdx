## emptyArrayUInt32 {#emptyArrayUInt32}

Introduced in: v1.1.0

Returns an empty UInt32 array

**Syntax**

```sql
emptyArrayUInt32()
```

**Arguments**

- None.

**Returned value**

An empty UInt32 array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayUInt32()
```

```response title=Response
[]
```
