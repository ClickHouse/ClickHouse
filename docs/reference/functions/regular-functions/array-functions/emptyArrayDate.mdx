## emptyArrayDate {#emptyArrayDate}

Introduced in: v1.1.0

Returns an empty Date array

**Syntax**

```sql
emptyArrayDate()
```

**Arguments**

- None.

**Returned value**

An empty Date array. [`Array(T)`](/reference/data-types/array)

**Examples**

**Usage example**

```sql title=Query
SELECT emptyArrayDate()
```

```response title=Response
[]
```
