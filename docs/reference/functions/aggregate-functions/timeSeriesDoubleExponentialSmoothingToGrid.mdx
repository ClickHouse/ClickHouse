## timeSeriesDoubleExponentialSmoothingToGrid {#timeSeriesDoubleExponentialSmoothingToGrid}

Introduced in: v26.10.0

Aggregate function that takes time series data as pairs of timestamps and values and calculates [PromQL-like double_exponential_smoothing](https://prometheus.io/docs/prometheus/latest/querying/functions/#double_exponential_smoothing) (Holt-Winters double exponential smoothing) from this data on a regular time grid described by start timestamp, end timestamp and step. For each point on the grid the samples within the specified time window are smoothed using the smoothing factor and trend factor, and the last smoothed value is returned.

The smoothing factor and the trend factor follow the samples as the last two arguments: each is either one number used at every grid point, or an array with one number per grid point. Each must be the same in every row. Like in Prometheus, a factor outside the open interval (0, 1) is an error for a grid point whose window has samples, and a NaN factor is not an error.

<Note>
This function is in private preview, enable it by setting `enable_time_series_aggregate_functions=true`.
</Note>
    

**Syntax**

```sql
timeSeriesDoubleExponentialSmoothingToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value, smoothing_factor, trend_factor)
```

**Parameters**

- `start_timestamp` — Specifies start of the grid. [`UInt32`](/reference/data-types/int-uint) or [`DateTime`](/reference/data-types/datetime)
- `end_timestamp` — Specifies end of the grid. [`UInt32`](/reference/data-types/int-uint) or [`DateTime`](/reference/data-types/datetime)
- `grid_step` — Specifies step of the grid in seconds. [`UInt32`](/reference/data-types/int-uint)
- `staleness` — Specifies the maximum staleness in seconds of the considered samples. The staleness window is a left-open and right-closed interval. [`UInt32`](/reference/data-types/int-uint)

**Arguments**

- `timestamp` — Timestamp of the sample. Can be individual values or arrays. [`UInt32`](/reference/data-types/int-uint) or [`DateTime`](/reference/data-types/datetime) or [`Array(UInt32)`](/reference/data-types/array) or [`Array(DateTime)`](/reference/data-types/array)
- `value` — Value of the time series corresponding to the timestamp. Can be individual values or arrays. [`Float*`](/reference/data-types/float) or [`Array(Float*)`](/reference/data-types/array)
- `smoothing_factor` — Smoothing factor for the level, in the open interval (0, 1): either one number for the whole grid or an array with one number per grid point. Must be the same in every row. [`Float*`](/reference/data-types/float) or [`UInt8/16/32/64`](/reference/data-types/int-uint) or [`Int8/16/32/64`](/reference/data-types/int-uint) or [`Array(Float*)`](/reference/data-types/array) or [`Array(UInt8/16/32/64)`](/reference/data-types/array) or [`Array(Int8/16/32/64)`](/reference/data-types/array)
- `trend_factor` — Smoothing factor for the trend, in the open interval (0, 1): either one number for the whole grid or an array with one number per grid point. Must be the same in every row. [`Float*`](/reference/data-types/float) or [`UInt8/16/32/64`](/reference/data-types/int-uint) or [`Int8/16/32/64`](/reference/data-types/int-uint) or [`Array(Float*)`](/reference/data-types/array) or [`Array(UInt8/16/32/64)`](/reference/data-types/array) or [`Array(Int8/16/32/64)`](/reference/data-types/array)

**Returned value**

Returns the smoothed value within the window on the specified grid. The returned array contains one value for each time grid point. The value is NULL if there are fewer than two samples within the window for a particular grid point. [`Array(Nullable(Float64))`](/reference/data-types/array)
