## mode {#mode}

Introduced in: v26.10.0

Returns the most frequent non-NULL value in a group.

If multiple values have the same maximum frequency, any of them may be returned. The result is non-deterministic in case of ties.

**Syntax**

```sql
mode(x)
```

**Arguments**

- `x` — Expression. [`Any`](/reference/data-types/index)

**Returned value**

Returns the most frequent value. The return type matches the input type.

**Examples**

**Usage example**

```sql title=Query
SELECT mode(x)
FROM values('x UInt8', (1), (2), (2), (3));
```

```response title=Response
┌─mode(x)─┐
│       2 │
└─────────┘
```

**Tied values**

```sql title=Query
SELECT mode(x) IN (1, 2)
FROM values('x UInt8', (1), (1), (2), (2));
```

```response title=Response
┌─mode(x) IN (1, 2)─┐
│                 1 │
└───────────────────┘
```
