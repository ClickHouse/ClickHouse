## regr_count {#regr_count}

Introduced in: v26.9.0

Counts the rows where neither `y` nor `x` is `NULL`.

**Syntax**

```sql
regr_count(y, x)
```

**Aliases**: `regrCount`

**Arguments**

- `y` — Dependent variable. [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)
- `x` — Independent variable. [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)

**Returned value**

Returns the number of non-null pairs. [`UInt64`](/reference/data-types/int-uint)

**Examples**

**Basic usage**

```sql title=Query
SELECT regr_count(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_count(y, x)─┐
│                4 │
└──────────────────┘
```
