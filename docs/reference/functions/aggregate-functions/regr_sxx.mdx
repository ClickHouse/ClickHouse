## regr_sxx {#regr_sxx}

Introduced in: v26.9.0

Returns the sum of squares of the independent variable:

$$
\Sigma{(x - \bar{x})^2}
$$
             

**Syntax**

```sql
regr_sxx(y, x)
```

**Aliases**: `regrSXX`

**Arguments**

- `y` — Dependent variable. [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)
- `x` — Independent variable. [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)

**Returned value**

Returns the sum of squares of `x` around its mean. [`Float64`](/reference/data-types/float)

**Examples**

**Basic usage**

```sql title=Query
SELECT regr_sxx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_sxx(y, x)─┐
│              5 │
└────────────────┘
```
