## regr_avgx {#regr_avgx}

Introduced in: v26.9.0

Returns the mean of the independent variable.

It is taken around a value from the data rather than around zero, so for an integer column past
2^53 it can be closer to the exact mean than [`avg`](/reference/functions/aggregate-functions/avg),
which divides a `Float64` sum.
             

**Syntax**

```sql
regr_avgx(y, x)
```

**Aliases**: `regrAvgX`

**Arguments**

- `y` — Dependent variable. [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)
- `x` — Independent variable. [`(U)Int*`](/reference/data-types/int-uint) or [`Float*`](/reference/data-types/float)

**Returned value**

Returns the mean of `x`. [`Float64`](/reference/data-types/float)

**Examples**

**Basic usage**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
