## Description {#description}

Settings of every table as they are actually in effect, which need not be the values its `CREATE` query states.
The `source` column tells where each value came from.
For the settings an engine supports, see [`system.engine_settings`](/reference/system-tables/engine_settings).

An engine that keeps no settings of its own reports only what the table's `SETTINGS` clause states - plain object storage (`S3`, `GCS`, `AzureBlobStorage`, `HDFS`), `File` and `URL` among them.
A setting known only from that clause has an empty `default`, `type` and `description` unless the engine lists it in `system.engine_settings`.

Which values of `source` can appear depends on the engine: only `MergeTree` family tables report `compatibility`, only `S3Queue` and `AzureQueue` report `shared_metadata`, and `File`, `URL` and the plain object storage engines report only `definition`.
A value an engine adjusts while it runs, and does not write back to its settings, is reported as `other`.

A table is shown to a user who has the `SHOW TABLES` privilege on it.
The [`SHOW TABLE SETTINGS`](/reference/statements/show#show-table-settings) statement reads this table for one table.

## Columns {#columns}

`DESCRIBE TABLE system.table_settings` lists the columns with their descriptions.

## Example {#example}

```sql
CREATE TABLE tbl (a UInt64) ENGINE = MergeTree ORDER BY a SETTINGS index_granularity = 4096;
SELECT name, value, source FROM system.table_settings WHERE database = currentDatabase() AND table = 'tbl' AND changed;
```
