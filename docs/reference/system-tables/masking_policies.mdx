## Description {#description}

Contains information about all masking policies defined in the system.

Masking policies can only be created and applied in ClickHouse Cloud. In open-source builds the `system.masking_policies` table is always empty, but it is still present so that introspection queries such as `SHOW MASKING POLICIES` work and return an empty result instead of throwing.

## Columns {#columns}

{/*AUTOGENERATED_START*/}
- `name` ([String](/reference/data-types/string)) — Name of a masking policy.
- `short_name` ([String](/reference/data-types/string)) — Short name of a masking policy. Names of masking policies are compound, for example: mask_email ON mydb.mytable. Here 'mask_email ON mydb.mytable' is the name of the masking policy, and 'mask_email' is its short name.
- `database` ([String](/reference/data-types/string)) — Database name.
- `table` ([String](/reference/data-types/string)) — Table name.
- `id` ([UUID](/reference/data-types/uuid)) — Masking policy ID.
- `storage` ([String](/reference/data-types/string)) — Name of the directory where the masking policy is stored.
- `update_assignments` ([Nullable(String)](/reference/data-types/nullable)) — UPDATE assignments that define how data should be masked, for example: email = '***masked***', phone = '***-***-****'. NULL if not set.
- `where_condition` ([Nullable(String)](/reference/data-types/nullable)) — Optional condition selecting the rows the mask is applied to. NULL if not set.
- `priority` ([Int64](/reference/data-types/int-uint)) — Priority of the masking policy. Policies with higher priority are applied first.
- `apply_to_all` ([UInt8](/reference/data-types/int-uint)) — Shows that the masking policy is set for all roles and/or users.
- `apply_to_list` ([Array(String)](/reference/data-types/array)) — List of the roles and/or users to which the masking policy is applied.
- `apply_to_except` ([Array(String)](/reference/data-types/array)) — The masking policy is applied to all roles and/or users except the listed ones.
{/*AUTOGENERATED_END*/}
