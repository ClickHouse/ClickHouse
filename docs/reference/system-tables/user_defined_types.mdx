## Description {#description}

Contains a list of all user-defined types created with
[`CREATE TYPE`](/reference/statements/create/type).

## Columns {#columns}

- `name` ([String](/reference/data-types/string)) — Name of the user-defined type.
- `base_type_ast_string` ([String](/reference/data-types/string)) — The base type the user-defined type expands to.
- `type_parameters_ast_string` ([Nullable](/reference/data-types/nullable)([String](/reference/data-types/string))) — The formal parameters of a parameterized type, or `NULL` if the type has none.
- `input_expression` ([Nullable](/reference/data-types/nullable)([String](/reference/data-types/string))) — The `INPUT` expression recorded with the type, if any.
- `output_expression` ([Nullable](/reference/data-types/nullable)([String](/reference/data-types/string))) — The `OUTPUT` expression recorded with the type, if any.
- `default_expression` ([Nullable](/reference/data-types/nullable)([String](/reference/data-types/string))) — The `DEFAULT` expression recorded with the type, if any.
- `create_query_string` ([String](/reference/data-types/string)) — The `CREATE TYPE` query that was used to create the type.

**Example**

```sql
CREATE TYPE KeyValue(K, V) AS Tuple(K, V);
SELECT name, base_type_ast_string, type_parameters_ast_string FROM system.user_defined_types;
```

```text
┌─name─────┬─base_type_ast_string─┬─type_parameters_ast_string─┐
│ KeyValue │ Tuple(K, V)          │ K, V                       │
└──────────┴──────────────────────┴────────────────────────────┘
```
