## Description {#description}

Contains information about existing projections in all tables.

The `total_rows`, `data_compressed_bytes` and `data_uncompressed_bytes` columns are summed over the active parts of the table that contain the projection, so they are zero until the projection is built, for example by inserts made after it was added or by `ALTER TABLE ... MATERIALIZE PROJECTION`. For the size of each projection part, see [system.projection_parts](/operations/system-tables/projection_parts).

## Columns {#columns}

- `database` ([String](/reference/data-types/string)) — Database name.
- `table` ([String](/reference/data-types/string)) — Table name.
- `name` ([String](/reference/data-types/string)) — Projection name.
- `type` ([Enum8('Normal' = 0, 'Aggregate' = 1)](/reference/data-types/enum)) — Projection type.
- `total_rows` ([UInt64](/reference/data-types/int-uint)) — Total number of rows.
- `data_compressed_bytes` ([UInt64](/reference/data-types/int-uint)) — The size of compressed data, in bytes.
- `data_uncompressed_bytes` ([UInt64](/reference/data-types/int-uint)) — The size of decompressed data, in bytes.
- `sorting_key` ([Array(String)](/reference/data-types/array)) — Projection sorting key.
- `query` ([String](/reference/data-types/string)) — Projection query.
- `settings` ([Map(String, String)](/reference/data-types/map)) — Projection settings.
