## Description {#description}

Contains SQL endpoint definitions from the cluster catalog (`CREATE ENDPOINT`), including which SQL shards reference each endpoint.

Requires [`cluster_metadata`](/operations/sql-clusters#configuration). Passwords are masked unless secret display settings and privileges allow showing them.

## Columns {#columns}

- `name` ([String](/reference/data-types/string)) — Name of the SQL endpoint (`CREATE ENDPOINT`).
- `host` ([String](/reference/data-types/string)) — Remote host of the endpoint.
- `port` ([UInt16](/reference/data-types/int-uint)) — TCP port of the endpoint.
- `user` ([String](/reference/data-types/string)) — User for the endpoint connection.
- `password` ([String](/reference/data-types/string)) — Password for the endpoint connection (masked without secret access).
- `secure` ([UInt8](/reference/data-types/int-uint)) — Whether SSL/TLS is enabled for the endpoint.
- `compression` ([UInt8](/reference/data-types/int-uint)) — Whether compression is enabled for the endpoint.
- `priority` ([Int64](/reference/data-types/int-uint)) — Load-balancing priority of the endpoint.
- `bind_host` ([String](/reference/data-types/string)) — Optional source bind host for the endpoint.
- `default_database` ([String](/reference/data-types/string)) — Optional default database for the endpoint.
- `bound_shards` ([Array(String)](/reference/data-types/array)) — SQL shard names that reference this endpoint.

## Example {#example}

```sql
SELECT name, host, port, secure, bound_shards
FROM system.endpoints
ORDER BY name;
```
