## Description {#description}

Contains a list of currently logged-in sessions, one row per active connection.

## Columns {#columns}

{/*AUTOGENERATED_START*/}
- `hostname` ([LowCardinality(String)](/reference/data-types/lowcardinality)) — Hostname of the server executing the query.
- `auth_id` ([UUID](/reference/data-types/uuid)) — Authentication ID, which is a UUID that is automatically generated each time user logins.
- `session_id` ([String](/reference/data-types/string)) — Session ID that is passed by client via HTTP interface.
- `event_date` ([Date](/reference/data-types/date)) — Login date.
- `event_time` ([DateTime](/reference/data-types/datetime)) — Login time.
- `event_time_microseconds` ([DateTime64(6)](/reference/data-types/datetime64)) — Login starting time with microseconds precision.
- `elapsed` ([Float64](/reference/data-types/float)) — The time in seconds since the session is established.
- `current_query_id` ([String](/reference/data-types/string)) — ID of the query currently executing in this session, if any.
- `user` ([Nullable(String)](/reference/data-types/nullable)) — User name.
- `auth_type` ([Nullable(Enum8('NO_PASSWORD' = 0, 'PLAINTEXT_PASSWORD' = 1, 'SHA256_PASSWORD' = 2, 'DOUBLE_SHA1_PASSWORD' = 3, 'LDAP' = 4, 'KERBEROS' = 5, 'SSL_CERTIFICATE' = 6, 'BCRYPT_PASSWORD' = 7, 'SSH_KEY' = 8, 'HTTP' = 9, 'JWT' = 10, 'SCRAM_SHA256_PASSWORD' = 11, 'NO_AUTHENTICATION' = 12))](/reference/data-types/nullable)) — The authentication type.
- `roles` ([Array(LowCardinality(String))](/reference/data-types/array)) — The list of roles to which the profile is applied.
- `profiles` ([Array(LowCardinality(String))](/reference/data-types/array)) — The list of profiles set for all roles and/or users.
- `settings` ([Array(Tuple(LowCardinality(String), String))](/reference/data-types/array)) — Settings that are changed when the client logged in.
- `quotas` ([Array(Tuple(LowCardinality(String), LowCardinality(String)))](/reference/data-types/array)) — Quotas that are bound to this session.
- `client_address` ([IPv6](/reference/data-types/ipv6)) — The IP address that is used to log in.
- `client_port` ([UInt16](/reference/data-types/int-uint)) — The client port that is used to log in.
- `interface` ([Enum8('TCP' = 1, 'HTTP' = 2, 'gRPC' = 3, 'MySQL' = 4, 'PostgreSQL' = 5, 'Local' = 6, 'TCP_Interserver' = 7, 'Prometheus' = 8, 'Background' = 9, 'ArrowFlight' = 10)](/reference/data-types/enum)) — The interface from which the login is initiated.
- `http_user_agent` ([String](/reference/data-types/string)) — The HTTP User-Agent header, if the session is established over HTTP.
- `client_hostname` ([String](/reference/data-types/string)) — The hostname of the client machine where the clickhouse-client or another TCP client is run.
- `client_name` ([String](/reference/data-types/string)) — The clickhouse-client or another TCP client name.
- `client_revision` ([UInt32](/reference/data-types/int-uint)) — Revision of the clickhouse-client or another TCP client.
- `client_version_major` ([UInt32](/reference/data-types/int-uint)) — The major version of the clickhouse-client or another TCP client.
- `client_version_minor` ([UInt32](/reference/data-types/int-uint)) — The minor version of the clickhouse-client or another TCP client.
- `client_version_patch` ([UInt32](/reference/data-types/int-uint)) — Patch component of the clickhouse-client or another TCP client version.
- `certificate_subjects` ([Array(LowCardinality(String))](/reference/data-types/array)) — The list of subjects (Common Name and Subject Alternative Names) of the TLS client certificate presented on the connection, in the form 'CN:...' / 'SAN:...'. Empty if no certificate is presented.
- `certificate_serial` ([LowCardinality(String)](/reference/data-types/lowcardinality)) — Serial number of the TLS client certificate. Empty if no certificate is presented.
- `certificate_issuer` ([LowCardinality(String)](/reference/data-types/lowcardinality)) — Issuer of the TLS client certificate. Empty if no certificate is presented.
- `certificate_not_before` ([Nullable(DateTime64(0, 'UTC'))](/reference/data-types/nullable)) — Time from which the TLS client certificate is valid. NULL if no certificate is presented.
- `certificate_not_after` ([Nullable(DateTime64(0, 'UTC'))](/reference/data-types/nullable)) — Time after which the TLS client certificate expires. NULL if no certificate is presented.
