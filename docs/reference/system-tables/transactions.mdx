## Description {#description}

Contains a list of transactions and their state.

**Availability**

`system.transactions` is created only when the `allow_experimental_transactions` server configuration option is enabled. By default, the table does not exist and queries against it will fail with `UNKNOWN_TABLE`. Enable it in the server configuration with:

```xml
<clickhouse>
    <allow_experimental_transactions>1</allow_experimental_transactions>
</clickhouse>
```

## Columns {#columns}

- `tid` ([Tuple(UInt64, UInt64, UUID)](/reference/data-types/tuple)) — The identifier of the transaction.
- `tid_hash` ([UInt64](/reference/data-types/int-uint)) — The hash of the identifier.
- `elapsed` ([Float64](/reference/data-types/float)) — The amount of time the transaction being processed.
- `is_readonly` ([UInt8](/reference/data-types/int-uint)) — The flag which shows whether the transaction has executed any write operation.
- `state` ([Enum8('RUNNING' = 0, 'COMMITTING' = 1, 'COMMITTED' = 2, 'ROLLED_BACK' = 3)](/reference/data-types/enum)) — The state of the transaction. Possible values: RUNNING, COMMITTING, COMMITTED, ROLLED_BACK.
