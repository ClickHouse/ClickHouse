## Description {#description}

Contains information about the ClickHouse server's build options.

## Columns {#columns}

- `name` ([String](/reference/data-types/string)) — Name of the build option.
- `value` ([String](/reference/data-types/string)) — Value of the build option.

## Example {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
