## Description {#description}

Contains SQL shard definitions from the cluster catalog (`CREATE SHARD`), including replica endpoint names and which SQL clusters reference each shard.

Requires [`cluster_metadata`](/operations/sql-clusters#configuration).

## Columns {#columns}

- `name` ([String](/reference/data-types/string)) — Name of the SQL shard (`CREATE SHARD`).
- `endpoints` ([Array(String)](/reference/data-types/array)) — Ordered list of endpoint names referenced by this shard.
- `weight` ([UInt32](/reference/data-types/int-uint)) — Shard weight used when this shard is part of a SQL cluster.
- `internal_replication` ([UInt8](/reference/data-types/int-uint)) — Whether distributed writes use internal replication for this shard when used in a SQL cluster.
- `referenced_by_clusters` ([Array(String)](/reference/data-types/array)) — SQL cluster names that reference this shard as a member.

## Example {#example}

```sql
SELECT name, endpoints, weight, internal_replication, referenced_by_clusters
FROM system.shards
ORDER BY name;
```
