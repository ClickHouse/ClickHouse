## Description {#description}

This system table contains the metadata files of Iceberg tables existing in ClickHouse, with one row per metadata file. It will be empty if you don't have any Iceberg tables in ClickHouse.

## Columns {#columns}

- `database` ([String](/reference/data-types/string)) — Database name.
- `table` ([String](/reference/data-types/string)) — Table name.
- `timestamp` ([DateTime64(3)](/reference/data-types/datetime64)) — Date & time when this metadata file was made current.
- `file` ([String](/reference/data-types/string)) — Path of the metadata file.
- `latest_snapshot_id` ([Nullable(UInt64)](/reference/data-types/nullable)) — Id of the latest snapshot at the time of this metadata file.
- `latest_schema_id` ([Nullable(Int32)](/reference/data-types/nullable)) — Schema id of the latest snapshot.
- `latest_sequence_number` ([Nullable(Int64)](/reference/data-types/nullable)) — Sequence number of the latest snapshot.
