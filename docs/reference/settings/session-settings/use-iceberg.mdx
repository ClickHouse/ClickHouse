## use_iceberg_manifest_list_partition_pruning {#use_iceberg_manifest_list_partition_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "New setting to skip Iceberg manifest files whose manifest-list partition summaries cannot match the query filter, without reading them."}]}]}/>

Skip whole Iceberg manifest files whose partition summaries in the manifest list cannot match the query filter, without reading them. Requires [use_iceberg_partition_pruning](/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning) to be enabled and only helps when a manifest file holds few distinct partition values, which is what `rewriteManifests` clustered by the partition columns produces.

## use_iceberg_manifest_statistics {#use_iceberg_manifest_statistics}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "New setting to estimate the rows and column statistics of Iceberg reads for join reordering from manifest files."}]}]}/>

With [`use_statistics`](/reference/settings/session-settings/use-statistics#use_statistics) enabled, estimate an Iceberg read for join reordering from the manifest files of its data files left after partition and min-max pruning by the query filter, without reading data: the rows from their `record_count`, and the number of distinct values, min/max and NULL fraction of the columns it returns from their identity partition values, value bounds and NULL counts. The filter, `PREWHERE` and row policy of the read are estimated on these statistics, as for MergeTree tables with column statistics; if no requested column has statistics, a filter that prunes no file gives no estimate, as for MergeTree tables without them. The row estimate is exact without a filter and without delete files. Pruning by the filter requires [use_iceberg_partition_pruning](/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning) to be enabled.
