These settings are available in [system.merge_tree_settings](/reference/system-tables/merge_tree_settings) and are autogenerated from ClickHouse source.

## fsync_after_insert {#fsync_after_insert}
<SettingsInfoBlock type="Bool" default_value="0" />

Do fsync for every inserted part, so the data is durable when the `INSERT` query
is acknowledged. Decreases performance of inserts, especially with wide parts.
See also `group_fsync_before_insert_finish`.

## fsync_part_directory {#fsync_part_directory}
<SettingsInfoBlock type="Bool" default_value="0" />

Do fsync for part directory after all part operations (writes, renames, etc.).
