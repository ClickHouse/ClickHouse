## merge_checkpoints_min_bytes {#merge_checkpoints_min_bytes}

<ExperimentalBadge/>
<SettingsInfoBlock type="UInt64" default_value="10737418240" />
<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "10737418240"},{"label": "New setting for durable merge checkpoints"}]}]}/>

The minimum total size of the source parts of a merge, in bytes, to checkpoint it with `enable_merge_checkpoints`.
Smaller merges are not checkpointed: they are cheap to repeat.

## merge_checkpoints_min_interval_seconds {#merge_checkpoints_min_interval_seconds}

<ExperimentalBadge/>
<SettingsInfoBlock type="Seconds" default_value="60" />
<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "60"},{"label": "New setting for durable merge checkpoints"}]}]}/>

The minimum time between two checkpoints of a merge with `enable_merge_checkpoints`.
A vertical merge always checkpoints once its key columns are merged. After that, it checkpoints after a completed column
only when this much time has passed since its previous checkpoint.

## merge_use_batch_sorting_queue {#merge_use_batch_sorting_queue}
<SettingsInfoBlock type="Bool" default_value="0" />
<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "New setting to use the batch sorting queue for ordinary `MergeTree` merges."}]}]}/>

Use the batch sorting queue to reduce per-row queue overhead when merging sorted streams.

Only applies to merges that do not change rows, i.e. plain `MergeTree`
(`Ordinary` merge mode). It has no effect on engines with merge-time
semantics such as `ReplacingMergeTree`, `CollapsingMergeTree`,
`SummingMergeTree`, `AggregatingMergeTree`, `CoalescingMergeTree`,
`GraphiteMergeTree` and `VersionedCollapsingMergeTree`, which keep using the
default queue regardless of this setting.

## merge_workload {#merge_workload}

Used to regulate how resources are utilized and shared between merges and
other workloads. Specified value is used as `workload` setting value for
background merges of this table. If not specified (empty string), then
server setting `merge_workload` is used instead.
