These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />The size of the SO_RCVBUF option for streaming exchange sockets of multi-stage distributed queries. 0 = kernel default (TCP autotuning). A value greater than 0 caps the per-socket receive buffer (clamped by net.core.rmem_max). Read per connection, so a config reload applies to new connections only.

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />The size of the SO_SNDBUF option for streaming exchange sockets of multi-stage distributed queries. 0 = kernel default (TCP autotuning). A value greater than 0 caps the per-socket send buffer (clamped by net.core.wmem_max), at the cost of capping the stream at sndbuf/RTT on high-RTT links. Read per connection, so a config reload applies to new connections only.
