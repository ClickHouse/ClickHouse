## database_catalog_drop_error_cooldown_sec {#database_catalog_drop_error_cooldown_sec}

<SettingsInfoBlock type="UInt64" default_value="5" changeable_without_restart="No" />In case of a failed table drop, ClickHouse will wait for this time-out before retrying the operation.

## database_catalog_drop_table_concurrency {#database_catalog_drop_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="16" changeable_without_restart="No" />The size of the threadpool used for dropping tables.

## database_catalog_shutdown_table_concurrency {#database_catalog_shutdown_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="No" />The size of the threadpool used for shutting down tables when the server is stopping. Zero means the number of threads is equal to the number of cores.

## database_catalog_unused_dir_cleanup_period_sec {#database_catalog_unused_dir_cleanup_period_sec}

<SettingsInfoBlock type="UInt64" default_value="86400" changeable_without_restart="No" />Parameter of the background task that cleaned up garbage from the `store/` directory: the scheduling period of the task. The setting is deprecated and has no effect: the task was removed, and ClickHouse never hides or removes unused directories in `store/` automatically.

<SettingsInfoBlock type="UInt64" default_value="3600" changeable_without_restart="No" />Parameter of the background task that cleaned up garbage from the `store/` directory: the time after which the task revoked all access rights from an unused directory.
