These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## gpu_expression_kernel_cache_elements_size {#gpu_expression_kernel_cache_elements_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />The maximum number of kernels in the cache of the kernels that the GPU engine compiles for expressions. The change takes effect without a restart.

## gpu_expression_kernel_cache_size {#gpu_expression_kernel_cache_size}

<SettingsInfoBlock type="UInt64" default_value="268435456" changeable_without_restart="Yes" />The maximum size, in bytes of the PTX, of the cache of the kernels that the GPU engine compiles for expressions. The kernels over the limit are unloaded from the device. The change takes effect without a restart.

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />The amount of freed device memory that the GPU's default memory pool keeps instead of returning it to the driver. With the default, the pool grows to the peak of the queries and stays there until the server shuts down.

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />The maximum size of freed pinned host memory that the GPU's pool of pinned host memory keeps for reuse instead of returning it to the system.
