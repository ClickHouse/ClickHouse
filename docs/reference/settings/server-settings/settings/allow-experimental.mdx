These settings configure the ClickHouse server and are autogenerated from ClickHouse source.

## allow_experimental_cluster_discovery {#allow_experimental_cluster_discovery}

<SettingsInfoBlock type="String" default_value="" changeable_without_restart="No" />Cluster discovery is no longer experimental and is always enabled for clusters with the `discovery` section in `remote_servers`. The setting is deprecated and has no effect. It is kept as a `String` so that any previously accepted value, including an empty tag, is still accepted.

## allow_experimental_executable_udf_drivers {#allow_experimental_executable_udf_drivers}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Enable experimental support for drivers for executable user-defined functions, declared via `user_defined_executable_function_drivers_config`. A driver turns a user code snippet supplied in `CREATE FUNCTION ... ENGINE = DriverName(...) AS '...'` into a runnable executable UDF.

## allow_experimental_webassembly_udf {#allow_experimental_webassembly_udf}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Enable experimental support for WebAssembly UDFs

## allow_experimental_webterminal {#allow_experimental_webterminal}

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />Former (experimental) name of `enable_webterminal`. Still honored for backward compatibility when `enable_webterminal` is not set. The setting is deprecated.
