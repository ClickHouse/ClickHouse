The `UNIQUE` predicate tests whether a subquery result contains no duplicate rows. It returns `1` if all rows are distinct, and `0` if any duplicates exist. An empty subquery is considered vacuously unique and returns `1`.

`UNIQUE` can also be used in a [WHERE](/reference/statements/select/where) clause.

**Syntax**

```sql
UNIQUE(subquery)
```

**Arguments**

- `subquery` — A subquery whose rows are checked for uniqueness.

**Returned value**

- `1` if all rows in the subquery are distinct.
- `0` if any duplicate rows exist.

Type: [UInt8](/reference/data-types/int-uint).

**NULL handling**

Per the SQL standard, rows containing `NULL` in any column are never considered duplicates. Two rows are duplicates only when every corresponding column value is non-null and equal. This means a subquery returning only `NULL` rows is considered unique.

**Equality of values**

Rows are compared the same way as by [DISTINCT](/reference/statements/select/distinct) and `GROUP BY`. In particular, floating-point values are compared by their binary representation: `0.0` and `-0.0` are different values, and two `NaN` values with the same representation are equal.

**Implementation details**

Internally, `UNIQUE(subquery)` is rewritten to the scalar subquery `SELECT count() = uniqExact(*) FROM (subquery) WHERE isNotNull(c1) AND isNotNull(c2) AND ...`, where `c1`, `c2`, etc. are the projected columns. Rows containing `NULL` in any column are filtered out before comparison. The remaining row count is compared against the number of distinct rows — if they are equal, all rows are unique.

Like any scalar subquery, `UNIQUE` can be correlated with the outer query:

```sql title="Query"
SELECT n, UNIQUE(SELECT number % n FROM numbers(3)) AS u FROM (SELECT arrayJoin([1, 2, 5]) AS n) ORDER BY n;
```

```text title="Response"
┌─n─┬─u─┐
│ 1 │ 0 │
│ 2 │ 0 │
│ 5 │ 1 │
└───┴───┘
```

**Example**

All distinct rows:

```sql title="Query"
SELECT UNIQUE(SELECT number FROM numbers(5));
```

```text title="Response"
┌─result─┐
│      1 │
└────────┘
```

Duplicate rows present:

```sql title="Query"
SELECT UNIQUE(SELECT number % 3 FROM numbers(6));
```

```text title="Response"
┌─result─┐
│      0 │
└────────┘
```

Usage in a `WHERE` clause:

```sql title="Query"
SELECT 'has unique rows' WHERE UNIQUE(SELECT number FROM numbers(3));
```

```text title="Response"
┌─'has unique rows'─┐
│ has unique rows   │
└───────────────────┘
```
