Disks define where ClickHouse stores data: local filesystems, object storage, caches, or encrypted wrappers. They are declared in the [server configuration or with the `disk` function](/concepts/features/configuration/server-config/storing-data), and shown in the [`system.disks`](/reference/system-tables/disks) table. The available disk types:

| Type | Description |
|-----|-----|
| [`azure_blob_storage`](/reference/disks/azure_blob_storage) | A disk backed by Microsoft Azure Blob Storage. Retained for compatibility; equivalent to `object_storage` with `object_storage_type = azure_blob_storage`. |
| [`cache`](/reference/disks/cache) | Wraps another disk with a local filesystem cache, caching data read from a remote disk on local storage to speed up repeated reads. |
| [`encrypted`](/reference/disks/encrypted) | Wraps another disk and transparently encrypts and decrypts data using AES, so that data at rest is encrypted on the underlying disk. |
| [`hdfs`](/reference/disks/hdfs) | A disk backed by the Apache Hadoop Distributed File System (HDFS). Retained for compatibility; equivalent to `object_storage` with `object_storage_type = hdfs`. |
| [`local`](/reference/disks/local) | Stores data on the local filesystem at a configured path. This is the default disk used when no disks are configured. |
| [`local_blob_storage`](/reference/disks/local_blob_storage) | A disk backed by a local directory treated as object storage. Retained for compatibility; equivalent to `object_storage` with `object_storage_type = local`. |
| [`object_storage`](/reference/disks/object_storage) | A disk backed by object storage. The concrete backend (S3, Azure Blob Storage, HDFS, local, or web) is selected by the `object_storage_type` parameter. |
| [`s3`](/reference/disks/s3) | A disk backed by Amazon S3 (or S3-compatible) object storage. Retained for compatibility; equivalent to `object_storage` with `object_storage_type = s3`. |
| [`s3_plain`](/reference/disks/s3_plain) | An S3-backed disk that stores objects under their plain paths without separate ClickHouse metadata. Mostly read-only, used for backups. Retained for compatibility. |
| [`s3_plain_rewritable`](/reference/disks/s3_plain_rewritable) | A variant of `s3_plain` that supports rewrites, storing object metadata in the object storage itself. Retained for compatibility. |
| [`s3_with_keeper`](/reference/disks/s3_with_keeper) | An S3-backed disk that keeps its metadata in ClickHouse Keeper instead of on a local metadata disk. The `keeper` metadata storage is available only in ClickHouse Cloud builds; in other builds, creating a disk of this type fails with an `unknown metadata storage type: keeper` error. Retained for compatibility. |
| [`web`](/reference/disks/web) | A read-only disk backed by a static website: a directory of exported table parts served over HTTP. Retained for compatibility; equivalent to `object_storage` with `object_storage_type = web`. |
