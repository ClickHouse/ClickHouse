A disk backed by object storage. The concrete backend (S3, Azure Blob Storage, HDFS, local, or web) is selected by the `object_storage_type` parameter.

## Syntax {#syntax}

```sql
disk(type = object_storage, object_storage_type = s3, metadata_type = local, endpoint = '...')
```
