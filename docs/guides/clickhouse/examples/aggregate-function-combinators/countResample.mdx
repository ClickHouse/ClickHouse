## Description {#description}

The [`Resample`](/reference/functions/aggregate-functions/combinators#-resample)
combinator can be applied to the [`count`](/reference/functions/aggregate-functions/count)
aggregate function to bucket rows by a resampling key column and return, for each
bucket, the number of rows whose count argument is non-null.

## Syntax {#syntax}

```sql
countResample(start, end, step)(count_arg, resampling_key)
```

The three parameters in the first argument list define the bucketing over `resampling_key`:

- `start` — lower bound of the range, inclusive.
- `end` — upper bound of the range, exclusive. Rows with `resampling_key >= end` are dropped.
- `step` — width of each bucket. The number of returned buckets is `ceil((end - start) / step)`.

The second argument list is passed through to `count`:

- `count_arg` — the column or expression counted per bucket. Rows where this value is null are not counted.
- `resampling_key` — the column whose value places each row into a bucket.

The result is an array with one element per bucket, in ascending order of `start`.

## Example usage {#example-usage}

### Basic example {#basic-example}

Let's look at an example. We'll create a table which contains the `name`, `age` and
`wage` of employees, and we'll insert some data into it:

```sql
CREATE TABLE employee_data
(
    name String,
    age UInt8,
    wage Float32
)
ENGINE = MergeTree()
ORDER BY tuple()

INSERT INTO employee_data (name, age, wage) VALUES
    ('John', 16, 10.0),
    ('Alice', 30, 15.0),
    ('Mary', 35, 8.0),
    ('Evelyn', 48, 11.5),
    ('David', 62, 9.9),
    ('Brian', 60, 16.0);
```

Let's count all the people whose age lies in the intervals `[30, 60)` and `[60, 75)`.
Because `age` is a `UInt8`, these intervals cover ages `30–59` and `60–74`.
The arguments `(30, 75, 30)` set `start = 30`, `end = 75`, and `step = 30`,
producing two buckets. The second argument list `(name, age)` counts `name`
per bucket, using `age` as the resampling key.

```sql
SELECT countResample(30, 75, 30)(name, age) AS amount FROM employee_data
```

```response
┌─amount─┐
│ [3,2]  │
└────────┘
```

The first bucket (`[30, 60)`) contains Alice, Mary, and Evelyn; the second bucket
(`[60, 75)`) contains David and Brian. John is excluded because his age is below
`start`.
