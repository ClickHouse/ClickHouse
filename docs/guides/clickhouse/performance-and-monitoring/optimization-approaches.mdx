Use evidence from query logs, controlled comparisons, and query plans to evaluate optimization approaches that address the measured bottleneck.

## Before you begin {#before-you-begin}

Begin with a repeatable baseline and a hypothesis about the bottleneck. If you have not identified one yet, start with [Diagnose slow queries](/guides/clickhouse/performance-and-monitoring/diagnose-slow-queries) and [Isolate query bottlenecks](/guides/clickhouse/performance-and-monitoring/isolate-query-bottlenecks).

## How it works {#how-it-works}

Use the optimization framework to decide whether to reduce the data footprint, improve filtering, or move repeatable work to ingestion time.

## Match the evidence to an intervention {#match-the-evidence-to-an-intervention}

Map timing differences, rows and bytes read, memory usage, profile events, and the physical plan to the part of the query or table design that warrants further investigation.
