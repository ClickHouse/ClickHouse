English documentation is stored in the Mintlify `.mdx` files directly under `docs/`.
Generated translations under locale directories such as `docs/ja`, `docs/es`, and `docs/ru`
must not be edited directly.

For structured reference surfaces such as functions, settings, engines, formats, and system
tables, update the documentation embedded in the source registration. The nightly generator
updates content inside `{/*AUTOGENERATED_START*/}` and `{/*AUTOGENERATED_END*/}` markers.
Edit Mintlify pages directly only for content outside generated regions.
