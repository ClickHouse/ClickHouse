نوع تعدادي يتكوّن من قيم مسمّاة.

يمكن تعريف القيم المسمّاة على هيئة أزواج `'string' = integer` أو كأسماء `'string'`. لا يخزّن ClickHouse سوى الأرقام، لكنه يدعم إجراء العمليات على هذه القيم من خلال أسمائها.

يدعم ClickHouse ما يلي:

* `Enum` بعرض 8 بت. يمكن أن يحتوي على ما يصل إلى 256 قيمة مُعدّدة ضمن النطاق `[-128, 127]`.
* `Enum` بعرض 16 بت. يمكن أن يحتوي على ما يصل إلى 65536 قيمة مُعدّدة ضمن النطاق `[-32768, 32767]`.

يختار ClickHouse تلقائيًا نوع `Enum` عند إدراج البيانات. ويمكنك أيضًا استخدام النوعين `Enum8` أو `Enum16` لضمان حجم التخزين المطلوب.

<div id="usage-examples">
  ## أمثلة الاستخدام
</div>

هنا ننشئ جدولًا بعمود من النوع `Enum8('hello' = 1, 'world' = 2)`:

```sql
CREATE TABLE t_enum
(
    x Enum('hello' = 1, 'world' = 2)
)
ENGINE = TinyLog
```

وبالمثل، يمكنك حذف الأرقام. سيعيّن ClickHouse أرقامًا متتالية تلقائيًا. وتُعيَّن الأرقام بدءًا من 1 افتراضيًا.

```sql
CREATE TABLE t_enum
(
    x Enum('hello', 'world')
)
ENGINE = TinyLog
```

يمكنك أيضًا تحديد رقم ابتدائي مسموح به للاسم الأول.

```sql
CREATE TABLE t_enum
(
    x Enum('hello' = 1, 'world')
)
ENGINE = TinyLog
```

```sql
CREATE TABLE t_enum
(
    x Enum8('hello' = -129, 'world')
)
ENGINE = TinyLog
```

```text
Exception on server:
Code: 69. DB::Exception: Value -129 for element 'hello' exceeds range of Enum8.
```

لا يمكن للعمود `x` تخزين إلا القيم المُدرجة في تعريف النوع: `'hello'` أو `'world'`. إذا حاولت حفظ أي قيمة أخرى، فسيُطلق ClickHouse استثناءً. ويُختار الحجم 8 بت لهذا `Enum` تلقائيًا.

```sql
INSERT INTO t_enum VALUES ('hello'), ('world'), ('hello')
```

```text
Ok.
```

```sql
INSERT INTO t_enum VALUES('a')
```

```text
Exception on client:
Code: 49. DB::Exception: Unknown element 'a' for type Enum('hello' = 1, 'world' = 2)
```

عند الاستعلام عن البيانات من الجدول، يعرض ClickHouse القيم النصية من `Enum`.

```sql
SELECT * FROM t_enum
```

```text
┌─x─────┐
│ hello │
│ world │
│ hello │
└───────┘
```

إذا كنت بحاجة إلى رؤية المكافئات الرقمية للصفوف، فعليك تحويل قيمة `Enum` باستخدام CAST إلى نوع عدد صحيح.

```sql
SELECT CAST(x, 'Int8') FROM t_enum
```

```text
┌─CAST(x, 'Int8')─┐
│               1 │
│               2 │
│               1 │
└─────────────────┘
```

لإنشاء قيمة من النوع Enum داخل استعلام، تحتاج أيضًا إلى استخدام `CAST`.

```sql
SELECT toTypeName(CAST('a', 'Enum(\'a\' = 1, \'b\' = 2)'))
```

```text
┌─toTypeName(CAST('a', 'Enum(\'a\' = 1, \'b\' = 2)'))─┐
│ Enum8('a' = 1, 'b' = 2)                             │
└─────────────────────────────────────────────────────┘
```

<div id="general-rules-and-usage">
  ## القواعد العامة والاستخدام
</div>

يُخصَّص لكل قيمة رقم ضمن النطاق `-128 ... 127` في `Enum8`، أو ضمن النطاق `-32768 ... 32767` في `Enum16`. يجب أن تكون جميع السلاسل النصية والأرقام مختلفة. ويُسمح بسلسلة نصية فارغة. إذا جرى تحديد هذا النوع (في تعريف جدول)، فيمكن أن تأتي الأرقام بأي ترتيب. ومع ذلك، لا يهم هذا الترتيب.

لا يمكن أن تكون السلسلة النصية ولا القيمة الرقمية في `Enum` هي [NULL](../../sql-reference/syntax.md).

يمكن تضمين `Enum` ضمن النوع [Nullable](../../sql-reference/data-types/nullable.md). لذا، إذا أنشأت جدولًا باستخدام الاستعلام

```sql
CREATE TABLE t_enum_nullable
(
    x Nullable( Enum8('hello' = 1, 'world' = 2) )
)
ENGINE = TinyLog
```

يمكنه تخزين `NULL` أيضًا، وليس فقط `'hello'` و`'world'`.

```sql
INSERT INTO t_enum_nullable VALUES('hello'),('world'),(NULL)
```

في RAM، يُخزَّن عمود `Enum` بالطريقة نفسها التي تُخزَّن بها القيم الرقمية المناظرة من النوعين `Int8` أو `Int16`.

عند القراءة بصيغة نصية، يفسّر ClickHouse القيمة على أنها سلسلة نصية ويبحث عن السلسلة المناظرة لها ضمن مجموعة قيم Enum. وإذا لم يعثر عليها، يُطلَق استثناء. وعند القراءة بتنسيق نصي، تُقرأ السلسلة النصية ويُبحث عن القيمة الرقمية المناظرة لها. ويُطلَق استثناء إذا لم يُعثر عليها.
وعند الكتابة بصيغة نصية، تُكتَب القيمة كسلسلة نصية مناظرة لها. وإذا كانت بيانات العمود تحتوي على قيم غير صالحة (أرقام لا تنتمي إلى المجموعة الصالحة)، يُطلَق استثناء. وعند القراءة والكتابة بالصيغة الثنائية، يعمل ذلك بالطريقة نفسها المتبعة مع نوعَي البيانات Int8 وInt16.
القيمة الافتراضية الضمنية هي القيمة ذات الرقم الأصغر.

أثناء `ORDER BY` و`GROUP BY` و`IN` و`DISTINCT` وما إلى ذلك، تتصرف قيم Enum بالطريقة نفسها التي تتصرف بها الأرقام المناظرة لها. فعلى سبيل المثال، يقوم ORDER BY بترتيبها رقميًا. كما تعمل عوامل المساواة والمقارنة مع قيم Enum بالطريقة نفسها التي تعمل بها مع القيم الرقمية الأساسية.

لا يمكن مقارنة قيم Enum بالأرقام. ويمكن مقارنتها بسلسلة نصية ثابتة. وإذا لم تكن السلسلة النصية المُقارَن بها قيمة صالحة لـ Enum، فسيُطلَق استثناء. ويكون عامل التشغيل `IN` مدعومًا عندما يكون Enum في الطرف الأيسر ومجموعة من السلاسل النصية في الطرف الأيمن. وتمثل هذه السلاسل النصية قيم Enum المناظرة.

معظم العمليات الرقمية وعمليات السلاسل النصية غير معرّفة لقيم Enum، مثل إضافة رقم إلى Enum أو ربط سلسلة نصية به.
ومع ذلك، يوفّر Enum دالة `toString` مضمّنة تُرجِع قيمته النصية.

يمكن أيضًا تحويل قيم Enum إلى أنواع رقمية باستخدام الدالة `toT`، حيث إن T نوع رقمي. وعندما يطابق T النوع الرقمي الأساسي لـ enum، يكون هذا التحويل بلا تكلفة.
ويمكن تغيير نوع Enum دون تكلفة باستخدام ALTER، إذا اقتصر التغيير على مجموعة القيم فقط. كما يمكن إضافة أعضاء Enum وإزالتهم باستخدام ALTER (وتكون الإزالة آمنة فقط إذا لم تُستخدم القيمة المُزالة مطلقًا في الجدول). وكإجراء احترازي، فإن تغيير القيمة الرقمية لعضو Enum مُعرَّف مسبقًا سيؤدي إلى إطلاق استثناء.

وباستخدام ALTER، يمكن تغيير Enum8 إلى Enum16 أو العكس، تمامًا كما في تغيير Int8 إلى Int16.

<div id="add-enum-values">
  ## إضافة قيم إلى enum
</div>

توجد صيغة مختصرة لإضافة قيم جديدة إلى enum باستخدام ALTER [MODIFY COLUMN ADD ENUM VALUES](../../sql-reference/statements/alter/column.md#modify-column-add-enum-values)

```sql
CREATE TABLE enum
(
    x Enum('One' = 1, 'Two', 'Three')
) ENGINE = Memory;
ALTER TABLE enum MODIFY COLUMN x ADD ENUM VALUES ('Zero' = 0, 'Four' = 4);
SHOW CREATE TABLE enum;
```

```text
┌─statement────────────────────────────────────────────────────────────────┐
│CREATE TABLE default.enum                                                 │
│(                                                                         │
│    `x` Enum8('Zero' = 0, 'One' = 1, 'Two' = 2, 'Three' = 3, 'Four' = 4)  │
│)                                                                         │
│ENGINE = Memory                                                           │
└──────────────────────────────────────────────────────────────────────────┘
```
