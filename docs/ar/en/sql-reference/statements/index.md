يتعامل المستخدمون مع ClickHouse باستخدام تعليمات SQL. يدعم ClickHouse تعليمات SQL الشائعة مثل [SELECT](select/index.md) و[CREATE](create/index.md)، كما يوفّر تعليمات متخصصة مثل [KILL](kill.md) و[OPTIMIZE](optimize.md).
