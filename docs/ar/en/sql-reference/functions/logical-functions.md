تنفّذ الدوال أدناه عمليات منطقية على وسيطات من أي نوع رقمي.
وتُرجع إما `0` أو `1` على هيئة [`UInt8`](../data-types/int-uint.md)، أو `NULL` في بعض الحالات.

تُعدّ القيمة صفر `false` عند استخدامها كوسيطة، بينما تُعدّ القيم غير الصفرية `true`.
