تعمل دوال uniqTheta على كائنَي uniqThetaSketch لإجراء عمليات على المجموعات مثل ∪ / ∩ / × (الاتحاد/التقاطع/الفرق)، وتُرجع كائن uniqThetaSketch جديدًا يحتوي على النتيجة.

يُنشأ كائن uniqThetaSketch باستخدام دالة التجميع uniqTheta مع اللاحقة ‎-State.

UniqThetaSketch هي بنية بيانات تُخزّن مجموعات من القيم التقريبية.
لمزيد من المعلومات، راجع: [Theta Sketch Framework](https://datasketches.apache.org/docs/Theta/ThetaSketches.html#theta-sketch-framework).

<div id="uniqthetaunion">
  ## uniqThetaUnion
</div>

كائنان من نوع uniqThetaSketch لإجراء عملية الاتحاد (عملية على المجموعات ∪)، والنتيجة كائن uniqThetaSketch جديد.

```sql
uniqThetaUnion(uniqThetaSketch,uniqThetaSketch)
```

**الوسائط**

* `uniqThetaSketch` – كائن.

**مثال**

```sql
SELECT finalizeAggregation(uniqThetaUnion(a, b)) AS a_union_b, finalizeAggregation(a) AS a_cardinality, finalizeAggregation(b) AS b_cardinality
FROM
(SELECT arrayReduce('uniqThetaState',[1,2]) AS a, arrayReduce('uniqThetaState',[2,3,4]) AS b );
```

```text
┌─a_union_b─┬─a_cardinality─┬─b_cardinality─┐
│         4 │             2 │             3 │
└───────────┴───────────────┴───────────────┘
```

<div id="uniqthetaintersect">
  ## uniqThetaIntersect
</div>

كائنان من نوع uniqThetaSketch لإجراء عملية التقاطع (عملية على المجموعات ∩)، والنتيجة كائن uniqThetaSketch جديد.

```sql
uniqThetaIntersect(uniqThetaSketch,uniqThetaSketch)
```

**الوسائط**

* `uniqThetaSketch` – كائن uniqThetaSketch.

**مثال**

```sql
SELECT finalizeAggregation(uniqThetaIntersect(a, b)) AS a_intersect_b, finalizeAggregation(a) AS a_cardinality, finalizeAggregation(b) AS b_cardinality
FROM
(SELECT arrayReduce('uniqThetaState',[1,2]) AS a, arrayReduce('uniqThetaState',[2,3,4]) AS b );
```

```text
┌─a_intersect_b─┬─a_cardinality─┬─b_cardinality─┐
│             1 │             2 │             3 │
└───────────────┴───────────────┴───────────────┘
```

<div id="uniqthetanot">
  ## uniqThetaNot
</div>

كائنان من نوع uniqThetaSketch لإجراء حساب a&#95;not&#95;b (عملية على المجموعات ×)، والنتيجة كائن uniqThetaSketch جديد.

```sql
uniqThetaNot(uniqThetaSketch,uniqThetaSketch)
```

**الوسائط**

* `uniqThetaSketch` – كائن uniqThetaSketch.

**مثال**

```sql
SELECT finalizeAggregation(uniqThetaNot(a, b)) AS a_not_b, finalizeAggregation(a) AS a_cardinality, finalizeAggregation(b) AS b_cardinality
FROM
(SELECT arrayReduce('uniqThetaState',[2,3,4]) AS a, arrayReduce('uniqThetaState',[1,2]) AS b );
```

```text
┌─a_not_b─┬─a_cardinality─┬─b_cardinality─┐
│       2 │             3 │             2 │
└─────────┴───────────────┴───────────────┘
```
