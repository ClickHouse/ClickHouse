يمكن استخدام دوال التجزئة لخلط العناصر خلطًا شبه عشوائيًا حتميًا.

‏Simhash هي دالة تجزئة تُرجع قيم hash متقاربة للوسائط المتقاربة (المتشابهة).

تقبل معظم دوال التجزئة أي عدد من الوسائط من أي أنواع.

:::note
قيمة تجزئة NULL هي NULL. للحصول على قيمة hash غير NULL لعمود Nullable، لفّه داخل tuple:

```sql
SELECT cityHash64(tuple(NULL))
```

:::

:::note
لحساب قيمة hash لكامل محتويات table، استخدم `sum(cityHash64(tuple(*)))` (أو أي hash function أخرى). تضمن `tuple` عدم تخطي rows التي تحتوي على قيم NULL. وتضمن `sum` أن ترتيب rows لا يهم.
:::
