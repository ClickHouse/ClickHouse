تقبل معظم الدوال في هذا القسم وسيطة اختيارية للمنطقة الزمنية، مثل `Europe/Amsterdam`. في هذه الحالة، تُستخدَم المنطقة الزمنية المحددة بدلًا من المنطقة الزمنية المحلية (default).

**مثال**

```sql
SELECT
    toDateTime('2016-06-15 23:00:00') AS time,
    toDate(time) AS date_local,
    toDate(time, 'Asia/Yekaterinburg') AS date_yekat,
    toString(time, 'US/Samoa') AS time_samoa
```

```text
┌────────────────time─┬─date_local─┬─date_yekat─┬─time_samoa──────────┐
│ 2016-06-15 23:00:00 │ 2016-06-15 │ 2016-06-16 │ 2016-06-15 09:00:00 │
└─────────────────────┴────────────┴────────────┴─────────────────────┘
```

:::note
لضمان التوافق مع معيار SQL، يمكن استخدام الدوال التالية من دون أقواس: `NOW` و`CURRENT_TIMESTAMP` و`LOCALTIME` و`LOCALTIMESTAMP` و`TODAY` و`CURRENT_DATE`.
:::
