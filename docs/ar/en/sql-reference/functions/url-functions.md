<div id="overview">
  ## نظرة عامة
</div>

:::note
الدوال المذكورة في هذا القسم مُحسّنة لتحقيق أعلى أداء، وفي معظم الحالات لا تلتزم بمعيار RFC-3986.
أما الدوال التي تطبّق RFC-3986، فيُلحق `RFC` باسمها، وتكون أبطأ عمومًا.
:::

يمكنك عادةً استخدام صيغ الدوال غير `RFC` عند العمل مع النطاقات المسجّلة علنًا التي لا تتضمن معلومات مستخدم ولا الرمز `@`.
يوضح الجدول أدناه الرموز التي يمكن (`✔`) أو لا يمكن (`✗`) تحليلها في URL باستخدام صيغ `RFC` وغير `RFC` المقابلة:

| الرمز       | non-`RFC` | `RFC` |   |
| ----------- | --------- | ----- | - |
| &#39; &#39; | ✗         | ✗     |   |
| \t          | ✗         | ✗     |   |
| &lt;        | ✗         | ✗     |   |
| &gt;        | ✗         | ✗     |   |
| %           | ✗         | ✔*    |   |
| &#123;      | ✗         | ✗     |   |
| &#125;      | ✗         | ✗     |   |
|             |           | ✗     | ✗ |
| &#92;&#92;  | ✗         | ✗     |   |
| ^           | ✗         | ✗     |   |
| ~           | ✗         | ✔*    |   |
| [           | ✗         | ✗     |   |
| ]           | ✗         | ✔     |   |
| ;           | ✗         | ✔*    |   |
| =           | ✗         | ✔*    |   |
| &amp;       | ✗         | ✔*    |   |

الرموز المعلَّمة بـ `*` هي محددات فرعية وفق RFC 3986، ويُسمح بها في معلومات المستخدم التي تأتي بعد الرمز `@`.

هناك نوعان من دوال URL:

* دوال تستخرج أجزاءً من URL. وإذا لم يكن الجزء المطلوب موجودًا في URL، فستُعاد سلسلة فارغة.
* دوال تزيل جزءًا من URL. وإذا لم يكن في URL ما يماثل ذلك، فسيبقى URL دون تغيير.

:::note
الدوال أدناه مُولَّدة من جدول النظام `system.functions`.
:::
