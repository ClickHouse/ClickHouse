<div id="untuple">
  ## untuple
</div>

يجري استبدالًا نحويًا لعناصر [tuple](/ar/sql-reference/data-types/tuple) في موضع الاستدعاء.

تعتمد أسماء أعمدة النتيجة على التنفيذ، وهي عرضة للتغيير. لا تفترض أسماء أعمدة معيّنة بعد `untuple`.

**البنية**

```sql
untuple(x)
```

يمكنك استخدام التعبير `EXCEPT` لاستثناء الأعمدة من نتيجة الاستعلام.

**المعاملات**

* `x` — دالة `tuple`، أو عمود، أو tuple من العناصر. [Tuple](../data-types/tuple.md).

**القيمة المعادة**

* None.

**أمثلة**

جدول الإدخال:

```text
┌─key─┬─v1─┬─v2─┬─v3─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 20 │ 40 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 65 │ 70 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 30 │ 20 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 12 │  7 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 50 │ 70 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴────┴────┴───────────┘
```

مثال على استخدام عمود من النوع `Tuple` كمعامل للدالة `untuple`:

```sql title="Query"
SELECT untuple(v6) FROM kv;
```

```text title="Response"
┌─_ut_1─┬─_ut_2─┐
│    33 │ ab    │
│    44 │ cd    │
│    55 │ ef    │
│    66 │ gh    │
│    77 │ kl    │
└───────┴───────┘
```

مثال لاستخدام تعبير `EXCEPT`:

```sql title="Query"
SELECT untuple((* EXCEPT (v2, v3),)) FROM kv;
```

```text title="Response"
┌─key─┬─v1─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴───────────┘
```
