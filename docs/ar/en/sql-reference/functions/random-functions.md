تقبل جميع الدوال في هذا القسم صفرًا أو وسيطة واحدة. والاستخدام الوحيد للوسيطة (إن وُجدت) هو منع [حذف التعبيرات الفرعية
المشتركة](/ar/sql-reference/functions/overview#common-subexpression-elimination)، بحيث يعيد تنفيذان مختلفان للدالة العشوائية نفسها ضمن الصف
نفسه قيمًا عشوائية مختلفة.

محتوى ذو صلة

* الدليل: [توليد بيانات عشوائية في ClickHouse](/ar/guides/generating-test-data)
* المدونة: [توليد بيانات عشوائية في ClickHouse](https://clickhouse.com/blog/generating-random-test-distribution-data-for-clickhouse)

:::note
تُولَّد الأرقام العشوائية باستخدام خوارزميات غير مخصّصة للتشفير.
:::

:::note
يُولَّد التوثيق أدناه من جدول النظام `system.functions`.
:::
