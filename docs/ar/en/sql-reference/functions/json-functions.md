<div id="types-of-functions">
  ## أنواع دوال JSON
</div>

هناك مجموعتان من الدوال لتحليل JSON:

* [`simpleJSON*` (`visitParam*`)](#simplejson-visitparam-functions) وهي مصممة لتحليل مجموعة فرعية محدودة من JSON بسرعة فائقة.
* [`JSONExtract*`](#jsonextract-functions) وهي مصممة لتحليل JSON العادي.

<div id="simplejson-visitparam-functions">
  ### دوال `simpleJSON` (`visitParam`)
</div>

يوفّر ClickHouse دوال خاصة للتعامل مع JSON المبسّط. وتعتمد جميع دوال JSON هذه على افتراضات صارمة بشأن الشكل الذي يمكن أن يكون عليه JSON. وهي تحاول تنفيذ الحد الأدنى الممكن من المعالجة لإنجاز المهمة بأسرع وقت ممكن.

تُفترض الافتراضات التالية:

1. يجب أن يكون اسم الحقل (وسيطة الدالة) ثابتًا.
2. يجب أن يكون اسم الحقل مُرمَّزًا في JSON بصيغة معيارية ما. على سبيل المثال: `simpleJSONHas('{"abc":"def"}', 'abc') = 1`, لكن `simpleJSONHas('{"\\u0061\\u0062\\u0063":"def"}', 'abc') = 0`
3. يُبحث عن الحقول في أي مستوى من مستويات التداخل، من دون تمييز. وإذا وُجدت عدة حقول متطابقة، فتُستخدم أول مطابقة.
4. لا يحتوي JSON على محارف مسافات خارج السلاسل النصية الحرفية.

<div id="jsonextract-functions">
  ### دوال JSONExtract
</div>

تعتمد هذه الدوال على [simdjson](https://github.com/lemire/simdjson)، وقد صُممت لتلبية متطلبات تحليل JSON الأكثر تعقيدًا.

<div id="case-insensitive-jsonextract-functions">
  ### دوال JSONExtract غير حساس لحالة الأحرف
</div>

تُجري هذه الدوال مطابقة للمفاتيح مع تجاهل حالة الأحرف وفق ASCII عند استخراج القيم من كائنات JSON.
وتعمل تمامًا مثل نظيراتها الحساسة لحالة الأحرف، باستثناء أن مفاتيح الكائنات تُطابَق دون مراعاة حالة الأحرف.
وعند تطابق عدة مفاتيح تختلف فقط في حالة الأحرف، تُعاد أول مطابقة.

:::note
قد يكون أداء هذه الدوال أقل من نظيراتها الحساسة لحالة الأحرف، لذا استخدم دوال JSONExtract العادية إن أمكن.
:::
