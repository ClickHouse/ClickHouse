تُستخدم دوال الجداول لإنشاء الجداول.

{/*AUTOGENERATED_START*/ }

{/*AUTOGENERATED_END*/ }

<div id="usage">
  ## الاستخدام
</div>

يمكن استخدام دوال الجداول في عبارة [`FROM`](../../sql-reference/statements/select/from.md)
ضمن استعلام `SELECT`. على سبيل المثال، يمكنك استخدام `SELECT` لاستخراج البيانات من ملف على جهازك
المحلي باستخدام دالة الجدول `file`.

```bash title="Query"
echo "1, 2, 3" > example.csv
```

```text title="Response"
./clickhouse client
:) SELECT * FROM file('example.csv')
┌─c1─┬─c2─┬─c3─┐
│  1 │  2 │  3 │
└────┴────┴────┘
```

يمكنك أيضًا استخدام دوال الجداول لإنشاء جدول مؤقت لا يكون متاحًا
إلا ضمن الاستعلام الحالي. على سبيل المثال:

```sql title="Query"
SELECT * FROM generateSeries(1,5);
```

```response title="Response"
┌─generate_series─┐
│               1 │
│               2 │
│               3 │
│               4 │
│               5 │
└─────────────────┘
```

يُحذف الجدول عند اكتمال الاستعلام.

يمكن استخدام دوال الجداول لإنشاء الجداول، وفق البنية التالية:

```sql title="Query"
CREATE TABLE [IF NOT EXISTS] [db.]table_name AS table_function()
```

مثال:

```sql title="Query"
CREATE TABLE series AS generateSeries(1, 5);
SELECT * FROM series;
```

```response title="Response"
┌─generate_series─┐
│               1 │
│               2 │
│               3 │
│               4 │
│               5 │
└─────────────────┘
```

أخيرًا، يمكن استخدام دوال الجداول لإدراج البيانات في جدول. على سبيل المثال،
يمكننا كتابة محتويات الجدول الذي أنشأناه في المثال السابق
في ملف على القرص باستخدام دالة الجدول `file` مرة أخرى:

```sql title="Query"
INSERT INTO FUNCTION file('numbers.csv', 'CSV') SELECT * FROM series;
```

```bash title="Query"
cat numbers.csv
1
2
3
4
5
```

:::note
لا يمكنك استخدام دوال الجداول إذا كان الإعداد [allow&#95;ddl](/ar/operations/settings/settings#allow_ddl) غير مفعّل.
:::
