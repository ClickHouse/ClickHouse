ينشئ جدول [Merge](../../engines/table-engines/special/merge.md) مؤقتًا.
يُشتق مخطط الجدول من الجداول الأساسية باستخدام اتحاد أعمدتها واشتقاق الأنواع المشتركة.
تتوفر الأعمدة الافتراضية نفسها كما في محرك الجدول [Merge](../../engines/table-engines/special/merge.md).

<div id="syntax">
  ## الصيغة
</div>

```sql
merge(['db_name',] 'tables_regexp')
```

<div id="arguments">
  ## المعاملات
</div>

| المعامل         | الوصف                                                                                                                                                                                                                                                                                                    |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | القيم الممكنة (اختياري، والقيمة الافتراضية هي `currentDatabase()`):<br />    - اسم قاعدة بيانات،<br />    - تعبير ثابت يُرجع سلسلة نصية تتضمن اسم قاعدة بيانات، على سبيل المثال `currentDatabase()`،<br />    - `REGEXP(expression)`، حيث يكون `expression` تعبيرًا نمطيًا لمطابقة أسماء قواعد البيانات. |
| `tables_regexp` | تعبير نمطي لمطابقة أسماء الجداول في قاعدة البيانات أو قواعد البيانات المحددة.                                                                                                                                                                                                                            |
