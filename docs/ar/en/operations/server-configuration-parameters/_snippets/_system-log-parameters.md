---
title: معلمات سجل النظام
---

يمكن تهيئة الإعدادات التالية عبر الوسوم الفرعية:

| Setting                            | Description                                                                                                                                    | Default             | Note                                                                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `database`                         | اسم قاعدة البيانات.                                                                                                                            |                     |                                                                                                                        |
| `table`                            | اسم جدول النظام.                                                                                                                               |                     |                                                                                                                        |
| `engine`                           | [تعريف محرك MergeTree](../../../engines/table-engines/mergetree-family/mergetree.md#table_engine-mergetree-creating-a-table) لجدول نظام.       |                     | لا يمكن استخدامه إذا كان `partition_by` أو `order_by` معرّفَين. وإذا لم يتم تحديده، فسيتم اختيار `MergeTree` افتراضيًا |
| `partition_by`                     | [مفتاح تقسيم مخصص](../../../engines/table-engines/mergetree-family/custom-partitioning-key.md) لجدول نظام.                                     |                     | إذا تم تحديد `engine` لجدول النظام، فيجب تحديد المعلمة `partition_by` مباشرةً داخل &#39;engine&#39;                    |
| `ttl`                              | يحدد [TTL](/ar/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-ttl) للجدول.                                               |                     | إذا تم تحديد `engine` لجدول النظام، فيجب تحديد المعلمة `ttl` مباشرةً داخل &#39;engine&#39;                             |
| `order_by`                         | [مفتاح فرز مخصص](../../../engines/table-engines/mergetree-family/mergetree.md#order_by) لجدول نظام. لا يمكن استخدامه إذا كان `engine` معرّفًا. |                     | إذا تم تحديد `engine` لجدول النظام، فيجب تحديد المعلمة `order_by` مباشرةً داخل &#39;engine&#39;                        |
| `storage_policy`                   | اسم سياسة التخزين التي ستُستخدم للجدول (اختياري).                                                                                              |                     | إذا تم تحديد `engine` لجدول النظام، فيجب تحديد المعلمة `storage_policy` مباشرةً داخل &#39;engine&#39;                  |
| `settings`                         | [معلمات إضافية](../../../engines/table-engines/mergetree-family/mergetree.md/#settings) تتحكم في سلوك MergeTree (اختياري).                     |                     | إذا تم تحديد `engine` لجدول النظام، فيجب تحديد المعلمة `settings` مباشرةً داخل &#39;engine&#39;                        |
| `flush_interval_milliseconds`      | الفاصل الزمني لتفريغ البيانات من المخزن المؤقت في الذاكرة إلى الجدول.                                                                          | `7500`              |                                                                                                                        |
| `max_size_rows`                    | الحجم الأقصى للسجلات بعدد الأسطر. وعندما يصل عدد السجلات غير المُفرَّغة إلى max&#95;size، تُفرَّغ السجلات إلى القرص.                           | `1048576`           |                                                                                                                        |
| `reserved_size_rows`               | حجم الذاكرة المحجوزة مسبقًا للسجلات بعدد الأسطر.                                                                                               | `8192`              |                                                                                                                        |
| `buffer_size_rows_flush_threshold` | قيمة الحد لعدد الأسطر. إذا تم بلوغ هذا الحد، يبدأ تفريغ السجلات إلى القرص في الخلفية.                                                          | `max_size_rows / 2` |                                                                                                                        |
| `flush_on_crash`                   | يحدد ما إذا كان ينبغي تفريغ السجلات إلى القرص عند حدوث تعطل.                                                                                   | `false`             |                                                                                                                        |

بالإضافة إلى ذلك، يتحكم الإعداد التالي على مستوى الخادم في سياسة التفريغ الافتراضية لجميع جداول سجل النظام:

```xml
<default_system_log_flush_policy>
    <skip_alias_columns>true</skip_alias_columns>
</default_system_log_flush_policy>
```

| الإعداد              | الوصف                                                                                                                  | الافتراضي |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------- | --------- |
| `skip_alias_columns` | عندما تكون القيمة `true`، تُستبعَد أعمدة ALIAS من مخططات جداول سجلات النظام. وهذا مطلوب لسجلات النظام المستندة إلى S3. | `false`   |
