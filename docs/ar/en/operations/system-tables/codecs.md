<div id="description">
  ## الوصف
</div>

يحتوي على معلومات عن برامج الترميز للضغط والتشفير.

يمكنك استخدام هذا الجدول للحصول على معلومات عن برامج الترميز للضغط والتشفير المتاحة

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم الـ codec.
* `method_byte` ([UInt8](/ar/sql-reference/data-types/int-uint)) — البايت الذي يحدد الـ codec في الملف المضغوط.
* `is_compression` ([UInt8](/ar/sql-reference/data-types/int-uint)) — تكون القيمة true إذا كان هذا الـ codec يضغط شيئًا ما. وإلا فقد يكون مجرد تحويل يساعد على الضغط.
* `is_generic_compression` ([UInt8](/ar/sql-reference/data-types/int-uint)) — الـ codec عبارة عن خوارزمية ضغط عامة مثل lz4 وzstd.
* `is_encryption` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يقوم الـ codec بالتشفير.
* `is_timeseries_codec` ([UInt8](/ar/sql-reference/data-types/int-uint)) — الـ codec مخصص لسلاسل زمنية ذات أعداد فاصلة عائمة.
* `is_experimental` ([UInt8](/ar/sql-reference/data-types/int-uint)) — هذا الـ codec تجريبي.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف عام للـ codec على مستوى عالٍ.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT * FROM system.codecs WHERE name='LZ4'
```

```text title="Response"
Row 1:
──────
name:                   LZ4
method_byte:            130
is_compression:         1
is_generic_compression: 1
is_encryption:          0
is_timeseries_codec:    0

description:            Extremely fast; good compression; balanced speed and efficiency.
```
