`INFORMATION_SCHEMA` (أو: `information_schema`) هي قاعدة بيانات نظام توفّر [عرضًا مستقلًا عن نظم إدارة قواعد البيانات](https://en.wikipedia.org/wiki/Information_schema) وموحّدًا إلى حدٍّ ما لبيانات التعريف الخاصة بكائنات قاعدة البيانات. وتُعدّ العروض في `INFORMATION_SCHEMA` عمومًا أقل كفاءة من جداول النظام العادية، لكن يمكن للأدوات استخدامها للحصول على معلومات أساسية بطريقة موحّدة عبر مختلف نظم إدارة قواعد البيانات. ومن المفترض أن يتطور هيكل العروض في `INFORMATION_SCHEMA` ومحتواها بطريقة متوافقة مع الإصدارات السابقة، أي لا تُضاف إلا وظائف جديدة، من دون تغيير الوظائف الحالية أو إزالتها. وعلى مستوى التنفيذ الداخلي، ترتبط العروض في `INFORMATION_SCHEMA` عادةً بجداول النظام العادية مثل [system.columns](../../operations/system-tables/columns.md) و[system.databases](../../operations/system-tables/databases.md) و[system.tables](../../operations/system-tables/tables.md).

```sql
SHOW TABLES FROM INFORMATION_SCHEMA;

-- or:
SHOW TABLES FROM information_schema;
```

```text
┌─name────────────────────┐
│ COLUMNS                 │
│ KEY_COLUMN_USAGE        │
│ REFERENTIAL_CONSTRAINTS │
│ SCHEMATA                │
| STATISTICS              |
│ TABLES                  │
│ VIEWS                   │
│ columns                 │
│ key_column_usage        │
│ referential_constraints │
│ schemata                │
| statistics              |
│ tables                  │
│ views                   │
└─────────────────────────┘
```

`INFORMATION_SCHEMA` يحتوي على العروض التالية:

* [COLUMNS](#columns)
* [KEY&#95;COLUMN&#95;USAGE](#key_column_usage)
* [REFERENTIAL&#95;CONSTRAINTS](#referential_constraints)
* [SCHEMATA](#schemata)
* [STATISTICS](#statistics)
* [TABLES](#tables)
* [VIEWS](#views)

تتوفر أيضًا عروض مكافئة غير حساسة لحالة الأحرف، مثل `INFORMATION_SCHEMA.columns`، لأسباب تتعلق بالتوافق مع قواعد البيانات الأخرى. وينطبق الأمر نفسه على جميع الأعمدة في هذه العروض، إذ تتوفر كل من الصيغ المكتوبة بأحرف صغيرة (على سبيل المثال `table_name`) وبأحرف كبيرة (`TABLE_NAME`).

<div id="schemata">
  ## SCHEMATA
</div>

يحتوي على أعمدة مقروءة من جدول النظام [system.databases](../../operations/system-tables/databases.md)، وأعمدة غير مدعومة في ClickHouse أو لا تنطبق هنا (وتكون دائمًا `NULL`)، لكنها مطلوبة وفقًا للمعيار.

الأعمدة:

* `catalog_name` ([String](../../sql-reference/data-types/string.md)) — اسم قاعدة البيانات.
* `schema_name` ([String](../../sql-reference/data-types/string.md)) — اسم قاعدة البيانات.
* `schema_owner` ([String](../../sql-reference/data-types/string.md)) — اسم مالك المخطط، ويكون دائمًا `'default'`.
* `default_character_set_catalog` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — `NULL`، غير مدعوم.
* `default_character_set_schema` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — `NULL`، غير مدعوم.
* `default_character_set_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — `NULL`، غير مدعوم.
* `sql_path` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — `NULL`، غير مدعوم.

**مثال**

```sql title="Query"
SELECT catalog_name,
       schema_name,
       schema_owner,
       default_character_set_catalog,
       default_character_set_schema,
       default_character_set_name,
       sql_path
FROM information_schema.schemata
WHERE schema_name ILIKE 'information_schema' 
LIMIT 1 
FORMAT Vertical;
```

<div id="tables">
  ## TABLES
</div>

يتضمن الأعمدة المقروءة من جدول النظام [system.tables](../../operations/system-tables/tables.md).

الأعمدة:

* `table_catalog` ([String](../../sql-reference/data-types/string.md)) — اسم قاعدة البيانات التي يوجد فيها الجدول.
* `table_schema` ([String](../../sql-reference/data-types/string.md)) — اسم قاعدة البيانات التي يوجد فيها الجدول.
* `table_name` ([String](../../sql-reference/data-types/string.md)) — اسم الجدول.
* `table_type` ([String](../../sql-reference/data-types/string.md)) — نوع الجدول. القيم الممكنة:
  * `BASE TABLE`
  * `VIEW`
  * `FOREIGN TABLE`
  * `LOCAL TEMPORARY`
  * `SYSTEM VIEW`
* `table_rows` ([Nullable](../../sql-reference/data-types/nullable.md)([UInt64](../../sql-reference/data-types/int-uint.md))) — العدد الإجمالي للصفوف. تكون NULL إذا تعذر تحديده.
* `data_length` ([Nullable](../../sql-reference/data-types/nullable.md)([UInt64](../../sql-reference/data-types/int-uint.md))) — حجم البيانات على القرص. تكون NULL إذا تعذر تحديده.
* `index_length` ([Nullable](../../sql-reference/data-types/nullable.md)([UInt64](../../sql-reference/data-types/int-uint.md))) — الحجم الإجمالي للمفتاح الأساسي والفهارس الثانوية وجميع العلامات.
* `table_collation` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — ترتيب الأحرف الافتراضي للجدول. يكون دائمًا `utf8mb4_0900_ai_ci`.
* `table_comment` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — التعليق المستخدَم عند إنشاء الجدول.

**مثال**

```sql title="Query"
SELECT table_catalog, 
       table_schema, 
       table_name, 
       table_type, 
       table_collation, 
       table_comment
FROM INFORMATION_SCHEMA.TABLES
WHERE (table_schema = currentDatabase() OR table_schema = '')
  AND table_name NOT LIKE '%inner%'
LIMIT 1 
FORMAT Vertical;
```

```text title="Response"
Row 1:
──────
table_catalog:   default
table_schema:    default
table_name:      describe_example
table_type:      BASE TABLE
table_collation: utf8mb4_0900_ai_ci
table_comment:   
```

<div id="views">
  ## VIEWS
</div>

يتضمن أعمدة مأخوذة من جدول النظام [system.tables](../../operations/system-tables/tables.md) عند استخدام محرك الجدول [View](../../engines/table-engines/special/view.md).

الأعمدة:

{/*AUTOGENERATED_START*/ }

* `table_catalog` ([String](../../sql-reference/data-types/string.md)) — اسم قاعدة البيانات التي يوجد فيها الجدول.
* `table_schema` ([String](../../sql-reference/data-types/string.md)) — اسم قاعدة البيانات التي يوجد فيها الجدول.
* `table_name` ([String](../../sql-reference/data-types/string.md)) — اسم الجدول.
* `view_definition` ([String](../../sql-reference/data-types/string.md)) — استعلام `SELECT` الخاص بالعرض.
* `check_option` ([String](../../sql-reference/data-types/string.md)) — `NONE`، بدون تحقّق.
* `is_updatable` ([Enum8](../../sql-reference/data-types/enum.md)) — `NO`، العرض غير قابل للتحديث.
* `is_insertable_into` ([Enum8](../../sql-reference/data-types/enum.md)) — يوضّح ما إذا كان العرض المُنشأ [مُجسَّدًا](/ar/sql-reference/statements/create/view#materialized-view). القيم الممكنة:
  * `NO` — العرض المُنشأ غير مُجسَّد.
  * `YES` — العرض المُنشأ مُجسَّد.
* `is_trigger_updatable` ([Enum8](../../sql-reference/data-types/enum.md)) — `NO`، المشغّل غير قابل للتحديث.
* `is_trigger_deletable` ([Enum8](../../sql-reference/data-types/enum.md)) — `NO`، المشغّل غير قابل للحذف.
* `is_trigger_insertable_into` ([Enum8](../../sql-reference/data-types/enum.md)) — `NO`، لا تُدرج أي بيانات في المشغّل.

{/*AUTOGENERATED_END*/ }

**مثال**

```sql title="Query"
CREATE VIEW v (n Nullable(Int32), f Float64) AS SELECT n, f FROM t;
CREATE MATERIALIZED VIEW mv ENGINE = Null AS SELECT * FROM system.one;
SELECT table_catalog,
       table_schema,
       table_name,
       view_definition,
       check_option,
       is_updatable,
       is_insertable_into,
       is_trigger_updatable,
       is_trigger_deletable,
       is_trigger_insertable_into
FROM information_schema.views
WHERE table_schema = currentDatabase() 
LIMIT 1
FORMAT Vertical;
```

```text title="Response"
Row 1:
──────
table_catalog:              default
table_schema:               default
table_name:                 mv
view_definition:            SELECT * FROM system.one
check_option:               NONE
is_updatable:               NO
is_insertable_into:         YES
is_trigger_updatable:       NO
is_trigger_deletable:       NO
is_trigger_insertable_into: NO
```

<div id="key_column_usage">
  ## KEY_COLUMN_USAGE
</div>

يحتوي على أعمدة من جدول النظام [system.tables](../../operations/system-tables/tables.md) التي تُطبَّق عليها قيود.

الأعمدة:

* `constraint_catalog` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا. دائمًا `def`.
* `constraint_schema` ([String](../../sql-reference/data-types/string.md)) — اسم المخطط (قاعدة البيانات) الذي ينتمي إليه القيد.
* `constraint_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — اسم القيد.
* `table_catalog` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا. دائمًا `def`.
* `table_schema` ([String](../../sql-reference/data-types/string.md)) — اسم المخطط (قاعدة البيانات) الذي ينتمي إليه الجدول.
* `table_name` ([String](../../sql-reference/data-types/string.md)) — اسم الجدول الذي ينطبق عليه القيد.
* `column_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — اسم العمود الذي ينطبق عليه القيد.
* `ordinal_position` ([UInt32](../../sql-reference/data-types/int-uint.md)) — غير مستخدم حاليًا. دائمًا `1`.
* `position_in_unique_constraint` ([Nullable](../../sql-reference/data-types/nullable.md)([UInt32](../../sql-reference/data-types/int-uint.md))) — غير مستخدم حاليًا. دائمًا `NULL`.
* `referenced_table_schema` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — غير مستخدم حاليًا. دائمًا NULL.
* `referenced_table_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — غير مستخدم حاليًا. دائمًا NULL.
* `referenced_column_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — غير مستخدم حاليًا. دائمًا NULL.

**مثال**

```sql title="Query"
CREATE TABLE test (i UInt32, s String) ENGINE MergeTree ORDER BY i;
SELECT constraint_catalog,
       constraint_schema,
       constraint_name,
       table_catalog,
       table_schema,
       table_name,
       column_name,
       ordinal_position,
       position_in_unique_constraint,
       referenced_table_schema,
       referenced_table_name,
       referenced_column_name
FROM information_schema.key_column_usage 
WHERE table_name = 'test' 
FORMAT Vertical;
```

<div id="referential_constraints">
  ## REFERENTIAL_CONSTRAINTS
</div>

يحتوي على معلومات حول المفاتيح الخارجية. ويُرجع حاليًا نتيجة فارغة (أي بلا صفوف)، وهو ما يكفي فقط لتوفير التوافق مع أدوات 3rd party مثل Tableau Online.

الأعمدة:

* `constraint_catalog` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `constraint_schema` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `constraint_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — غير مستخدم حاليًا.
* `unique_constraint_catalog` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `unique_constraint_schema` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `unique_constraint_name` ([Nullable](../../sql-reference/data-types/nullable.md)([String](../../sql-reference/data-types/string.md))) — غير مستخدم حاليًا.
* `match_option` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `update_rule` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `delete_rule` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `table_name` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.
* `referenced_table_name` ([String](../../sql-reference/data-types/string.md)) — غير مستخدم حاليًا.

<div id="statistics">
  ## STATISTICS
</div>

يوفّر معلومات حول فهارس الجدول. ويُرجع حاليًا نتيجة فارغة (من دون أي صفوف)، وهذا يكفي فقط لضمان التوافق مع أدوات الجهات الخارجية مثل Tableau Online.
