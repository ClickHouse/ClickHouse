<div id="description">
  ## الوصف
</div>

تحتوي على قائمة بمحركات قواعد البيانات التي يدعمها الخادم.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم محرك قاعدة البيانات.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف عام لوظيفة محرك قاعدة البيانات.
* `syntax` ([String](/ar/sql-reference/data-types/string)) — كيفية تحديد محرك قاعدة البيانات في عبارة ENGINE ضمن استعلام CREATE DATABASE.
* `examples` ([String](/ar/sql-reference/data-types/string)) — أمثلة استخدام.
* `introduced_in` ([String](/ar/sql-reference/data-types/string)) — إصدار ClickHouse الذي ظهر فيه محرك قاعدة البيانات لأول مرة، بصيغة major.minor.
* `related` ([Array](/ar/sql-reference/data-types/array)([String](/ar/sql-reference/data-types/string))) — أسماء محركات قواعد البيانات ذات الصلة.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```
