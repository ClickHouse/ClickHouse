<div id="description">
  ## الوصف
</div>

معلومات عن [العروض المادية القابلة للتحديث](../../sql-reference/statements/create/view.md#refreshable-materialized-view). تحتوي على جميع العروض المادية القابلة للتحديث، سواء كانت هناك عملية تحديث جارية أم لا.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات التي يوجد فيها الجدول.
* `view` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول.
* `uuid` ([UUID](/ar/sql-reference/data-types/uuid)) — معرّف UUID للجدول (قاعدة بيانات Atomic).
* `status` ([String](/ar/sql-reference/data-types/string)) — الحالة الحالية لعملية التحديث.
* `last_success_time` ([Nullable(DateTime)](/ar/sql-reference/data-types/nullable)) — الوقت الذي بدأ فيه آخر تحديث ناجح. تكون NULL إذا لم تحدث أي عمليات تحديث ناجحة منذ بدء تشغيل الخادم أو إنشاء الجدول.
* `last_success_duration_ms` ([Nullable(UInt64)](/ar/sql-reference/data-types/nullable)) — المدة التي استغرقها آخر تحديث.
* `last_refresh_time` ([Nullable(DateTime)](/ar/sql-reference/data-types/nullable)) — الوقت الذي انتهت فيه آخر محاولة تحديث (إن كان معروفًا) أو بدأت فيه (إن لم يكن معروفًا أو كانت لا تزال قيد التشغيل). تكون NULL إذا لم تحدث أي محاولات تحديث منذ بدء تشغيل الخادم أو إنشاء الجدول.
* `last_refresh_replica` ([String](/ar/sql-reference/data-types/string)) — إذا كان التنسيق مفعّلًا، فهذا هو اسم النسخة المتماثلة التي نفّذت محاولة التحديث الحالية (إذا كانت قيد التشغيل) أو السابقة (إذا لم تكن قيد التشغيل).
* `next_refresh_time` ([Nullable(DateTime)](/ar/sql-reference/data-types/nullable)) — الوقت المجدول لبدء التحديث التالي. تكون NULL إذا لم يكن وقت التحديث التالي معروفًا حاليًا، على سبيل المثال عند انتظار التبعيات (الحالة `WaitingForDependencies` أو `MissingDependencies`).
* `exception` ([String](/ar/sql-reference/data-types/string)) — رسالة الخطأ من المحاولة السابقة إذا فشلت.
* `retry` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد المحاولات الفاشلة حتى الآن بالنسبة إلى التحديث الحالي. لا تكون متاحة إذا كانت الحالة `RunningOnAnotherReplica`.
* `progress` ([Nullable(Float64)](/ar/sql-reference/data-types/nullable)) — تقدّم عملية التحديث الجارية حاليًا أو المكتملة مؤخرًا على النسخة المتماثلة المحددة، بين 0 و1. تكون NULL إذا كانت الحالة `RunningOnAnotherReplica` أو إذا لم تكن عملية التحديث قيد التشغيل.
* `read_rows` ([Nullable(UInt64)](/ar/sql-reference/data-types/nullable)) — عدد الصفوف التي قرأتها عملية التحديث الجارية حاليًا أو المكتملة مؤخرًا على النسخة المتماثلة المحددة. تكون NULL إذا كانت الحالة `RunningOnAnotherReplica`.
* `read_bytes` ([Nullable(UInt64)](/ar/sql-reference/data-types/nullable)) — عدد البايتات التي قرأتها عملية التحديث الجارية حاليًا أو المكتملة مؤخرًا على النسخة المتماثلة المحددة. تكون NULL إذا كانت الحالة `RunningOnAnotherReplica`
* `total_rows` ([Nullable(UInt64)](/ar/sql-reference/data-types/nullable)) — العدد الإجمالي التقديري للصفوف التي يجب أن تقرأها عملية التحديث الجارية حاليًا أو المكتملة مؤخرًا على النسخة المتماثلة المحددة. تكون NULL إذا كانت الحالة `RunningOnAnotherReplica`
* `written_rows` ([Nullable(UInt64)](/ar/sql-reference/data-types/nullable)) — عدد الصفوف التي كتبتها عملية التحديث الجارية حاليًا أو المكتملة مؤخرًا على النسخة المتماثلة المحددة. تكون NULL إذا كانت الحالة `RunningOnAnotherReplica`
* `written_bytes` ([Nullable(UInt64)](/ar/sql-reference/data-types/nullable)) — عدد البايتات التي كتبتها عملية التحديث الجارية حاليًا أو المكتملة مؤخرًا على النسخة المتماثلة المحددة. تكون NULL إذا كانت الحالة `RunningOnAnotherReplica`

{/*AUTOGENERATED_END*/ }
