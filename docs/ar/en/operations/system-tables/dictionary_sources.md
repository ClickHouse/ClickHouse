<div id="description">
  ## الوصف
</div>

يتضمن قائمة بمصادر القواميس التي يدعمها الخادم، إلى جانب التوثيق المضمّن لكل مصدر. ويحدّد مصدر القاموس الجهة التي تُحمَّل منها بيانات القاموس؛ ويُحدَّد في عبارة `SOURCE` ضمن استعلام `CREATE DICTIONARY`.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم مصدر القاموس، كما هو محدد في عبارة SOURCE.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف عام لوظيفة مصدر القاموس.
* `syntax` ([String](/ar/sql-reference/data-types/string)) — بنية عبارة SOURCE المستخدمة لتحديد المصدر. لاحظ أن بعض المصادر تخضع للتحكم في الوصول عند إنشاء قاموس من استعلام DDL (بدلاً من ملف تهيئة الخادم)؛ راجع `description` الخاص بكل مصدر للاطلاع على التفاصيل.
* `examples` ([String](/ar/sql-reference/data-types/string)) — أمثلة الاستخدام.
* `introduced_in` ([String](/ar/sql-reference/data-types/string)) — إصدار ClickHouse الذي طُرح فيه المصدر لأول مرة، بصيغة major.minor.
* `related` ([Array](/ar/sql-reference/data-types/array)([String](/ar/sql-reference/data-types/string))) — أسماء مصادر القاموس ذات الصلة.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT name, syntax
FROM system.dictionary_sources
WHERE name IN ('clickhouse', 'file')
ORDER BY name
```

```text title="Response"
┌─name───────┬─syntax─────────────────────────────────────────────────────────────────────────┐
│ clickhouse │ SOURCE(CLICKHOUSE(host 'host' port 9000 user 'default' password '' db 'db' table 'table')) │
│ file       │ SOURCE(FILE(path '/path/to/file' format 'CSV'))                                  │
└────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
