<div id="description">
  ## الوصف
</div>

يحتوي على الحالة في الذاكرة لبيانات AzureQueue الوصفية، والصفوف التي تُعالَج حاليًا لكل ملف.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/ar/sql-reference/data-types/string)) — المسار في ZooKeeper إلى البيانات الوصفية
* `file_path` ([String](/ar/sql-reference/data-types/string)) — مسار الملف الجاري معالجته
* `file_name` ([String](/ar/sql-reference/data-types/string)) — اسم الملف الجاري معالجته
* `rows_processed` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد الصفوف المُعالَجة حاليًا
* `status` ([String](/ar/sql-reference/data-types/string)) — حالة المعالجة: Processed، Processing، Failed
* `processing_start_time` ([Nullable(DateTime)](/ar/sql-reference/data-types/nullable)) — الوقت الذي بدأت فيه معالجة الملف
* `processing_end_time` ([Nullable(DateTime)](/ar/sql-reference/data-types/nullable)) — الوقت الذي انتهت فيه معالجة الملف
* `exception` ([String](/ar/sql-reference/data-types/string)) — الاستثناء الذي وقع أثناء المعالجة

{/*AUTOGENERATED_END*/ }
