<div id="description">
  ## الوصف
</div>

يتضمن معلومات حول الإعدادات العامة للخادم، والمحددة في `config.xml`.
يعرض الجدول حاليًا الإعدادات من الطبقة الأولى فقط في `config.xml`، ولا يدعم الإعدادات المتداخلة (على سبيل المثال [logger](../../operations/server-configuration-parameters/settings.md#logger)).

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم إعداد الخادم.
* `value` ([String](/ar/sql-reference/data-types/string)) — قيمة إعداد الخادم.
* `default` ([String](/ar/sql-reference/data-types/string)) — القيمة الافتراضية لإعداد الخادم.
* `changed` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان الإعداد محددًا في `config.xml`
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف موجز لإعداد الخادم.
* `type` ([String](/ar/sql-reference/data-types/string)) — نوع قيمة إعداد الخادم.
* `changeable_without_restart` ([Enum8(&#39;No&#39; = 0, &#39;IncreaseOnly&#39; = 1, &#39;DecreaseOnly&#39; = 2, &#39;Yes&#39; = 3)](/ar/sql-reference/data-types/enum)) — يوضّح ما إذا كان يمكن تغيير الإعداد أثناء التشغيل.
* `is_obsolete` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان الإعداد مهملًا.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

يوضح المثال التالي كيفية الحصول على معلومات حول إعدادات الخادم التي يتضمن اسمها `thread_pool`.

```sql
SELECT *
FROM system.server_settings
WHERE name LIKE '%thread_pool%'
```

قد يكون استخدام `WHERE changed` مفيدًا، على سبيل المثال، عندما تريد التحقق
من أن الإعدادات في ملفات الإعدادات قد حُمّلت بشكل صحيح وأنها قيد الاستخدام.

{/* */ }

```sql
SELECT * FROM system.server_settings WHERE changed AND name='max_thread_pool_size'
```
