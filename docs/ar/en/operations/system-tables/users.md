<div id="description">
  ## الوصف
</div>

يتضمن قائمة بـ[حسابات المستخدمين](../../guides/sre/user-management/index.md#user-account-management) المُهيّأة على الخادم.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم المستخدم.
* `id` ([UUID](/ar/sql-reference/data-types/uuid)) — معرّف المستخدم.
* `storage` ([String](/ar/sql-reference/data-types/string)) — المسار إلى تخزين المستخدمين. يُضبط في المعامل `access_control_path`.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/ar/sql-reference/data-types/array)) — يعرض أنواع المصادقة. توجد عدة طرق لتحديد هوية المستخدم: بدون كلمة مرور، أو بكلمة مرور بنص صريح، أو بكلمة مرور مُرمَّزة باستخدام SHA256، أو بكلمة مرور مُرمَّزة باستخدام SHA-1 المزدوج، أو بكلمة مرور مُرمَّزة باستخدام bcrypt.
* `auth_params` ([Array(String)](/ar/sql-reference/data-types/array)) — معاملات المصادقة بتنسيق JSON وفقًا لـ `auth_type`.
* `valid_until` ([Array(DateTime)](/ar/sql-reference/data-types/array)) — تاريخ ووقت انتهاء صلاحية بيانات اعتماد المستخدم.
* `host_ip` ([Array(String)](/ar/sql-reference/data-types/array)) — عناوين IP للمضيفين المسموح لهم بالاتصال بخادم ClickHouse.
* `host_names` ([Array(String)](/ar/sql-reference/data-types/array)) — أسماء المضيفين المسموح لهم بالاتصال بخادم ClickHouse.
* `host_names_regexp` ([Array(String)](/ar/sql-reference/data-types/array)) — التعبير النمطي لأسماء المضيفين المسموح لهم بالاتصال بخادم ClickHouse.
* `host_names_like` ([Array(String)](/ar/sql-reference/data-types/array)) — أسماء المضيفين المسموح لهم بالاتصال بخادم ClickHouse، والمحددة باستخدام الشرط LIKE.
* `default_roles_all` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضح أن جميع الأدوار الممنوحة مُعيَّنة لهذا المستخدم افتراضيًا.
* `default_roles_list` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة الأدوار الممنوحة افتراضيًا.
* `default_roles_except` ([Array(String)](/ar/sql-reference/data-types/array)) — جميع الأدوار الممنوحة مُعيَّنة كأدوار افتراضية، باستثناء الأدوار المدرجة.
* `grantees_any` ([UInt8](/ar/sql-reference/data-types/int-uint)) — علامة تشير إلى ما إذا كان بإمكان مستخدم لديه أي خيارات منح أن يمنحها لأي شخص.
* `grantees_list` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة المستخدمين أو الأدوار المسموح لهذا المستخدم بمنح الخيارات لهم.
* `grantees_except` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة المستخدمين أو الأدوار غير المسموح لهذا المستخدم بمنح الخيارات لهم.
* `default_database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات الافتراضية لهذا المستخدم.
