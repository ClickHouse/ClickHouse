<div id="description">
  ## الوصف
</div>

يعرض جميع المُجذِّرات المتاحة.
يمكن استخدام هذه المُجذِّرات في الدالة [stem](../../sql-reference/functions/nlp-functions.md).

:::note التوفّر
يتوفّر `system.stemmers` فقط في إصدارات ClickHouse المجمّعة مع الاعتمادية `libstemmer` (`USE_LIBSTEMMER`). أمّا في الإصدارات التي لا تتضمنها، فلن يكون الجدول موجودًا، وستفشل الاستعلامات عليه مع `UNKNOWN_TABLE`. يمكنك التحقق مما إذا كان هذا الخيار مفعّلًا في إصدارك باستخدام:

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

الأعمدة:

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — معرّف مُجذِّر Snowball (اللغة/الخوارزمية)

{/*AUTOGENERATED_END*/ }
