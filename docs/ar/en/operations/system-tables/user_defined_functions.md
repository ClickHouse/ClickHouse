<div id="description">
  ## الوصف
</div>

يحتوي على حالة التحميل، ومعلومات الخطأ، والبيانات الوصفية للتكوين الخاصة بـ [الدوال المعرّفة من قبل المستخدم (UDFs)](/ar/sql-reference/functions/udf.md).

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم UDF.
* `load_status` ([Enum8(&#39;Success&#39; = 0, &#39;Failed&#39; = 1)](/ar/sql-reference/data-types/enum)) — حالة التحميل. القيم الممكنة: Success — تم تحميل UDF وهو جاهز للاستخدام، Failed — فشل تحميل UDF (راجع الحقل &#39;loading&#95;error&#95;message&#39; للتفاصيل).
* `loading_error_message` ([String](/ar/sql-reference/data-types/string)) — رسالة الخطأ التفصيلية عند فشل التحميل. تكون فارغة إذا تم التحميل بنجاح.
* `last_successful_update_time` ([Nullable(DateTime)](/ar/sql-reference/data-types/nullable)) — الطابع الزمني لآخر تحديث ناجح. تكون NULL إذا لم ينجح مطلقًا.
* `loading_duration_ms` ([UInt64](/ar/sql-reference/data-types/int-uint)) — الوقت المستغرق في تحميل UDF، بالمللي ثانية.
* `type` ([Enum8(&#39;executable&#39; = 0, &#39;executable&#95;pool&#39; = 1)](/ar/sql-reference/data-types/enum)) — نوع UDF: &#39;executable&#39; (عملية واحدة) أو &#39;executable&#95;pool&#39; (مجموعة عمليات).
* `command` ([String](/ar/sql-reference/data-types/string)) — البرنامج النصي أو الأمر الذي يُنفَّذ لهذا UDF.
* `format` ([String](/ar/sql-reference/data-types/string)) — تنسيق البيانات للإدخال/الإخراج (مثل &#39;TabSeparated&#39; و&#39;JSONEachRow&#39;).
* `return_type` ([String](/ar/sql-reference/data-types/string)) — نوع الإرجاع للدالة (مثل &#39;String&#39; و&#39;UInt64&#39;).
* `return_name` ([String](/ar/sql-reference/data-types/string)) — معرّف قيمة الإرجاع الاختياري. يكون فارغًا إذا لم تتم تهيئته.
* `argument_types` ([Array(String)](/ar/sql-reference/data-types/array)) — مصفوفة بأنواع الوسيطات (مثل [&#39;String&#39;, &#39;UInt64&#39;]).
* `argument_names` ([Array(String)](/ar/sql-reference/data-types/array)) — مصفوفة بأسماء الوسيطات. وتكون سلاسل فارغة للوسيطات غير المسماة.
* `max_command_execution_time` ([UInt64](/ar/sql-reference/data-types/int-uint)) — الحد الأقصى بالثواني لمعالجة كتلة بيانات. فقط للنوع &#39;executable&#95;pool&#39;.
* `command_termination_timeout` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد الثواني قبل إرسال SIGTERM إلى عملية الأمر.
* `command_read_timeout` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد المللي ثانية المخصصة للقراءة من stdout الخاص بالأمر.
* `command_write_timeout` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد المللي ثانية المخصصة للكتابة إلى stdin الخاص بالأمر.
* `pool_size` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد مثيلات عملية الأمر. فقط للنوع &#39;executable&#95;pool&#39;.
* `send_chunk_header` ([UInt8](/ar/sql-reference/data-types/int-uint)) — ما إذا كان سيتم إرسال عدد الصفوف قبل كل جزء بيانات (قيمة منطقية).
* `execute_direct` ([UInt8](/ar/sql-reference/data-types/int-uint)) — ما إذا كان سيتم تنفيذ الأمر مباشرةً (1) أو عبر /bin/bash‏ (0).
* `lifetime` ([UInt64](/ar/sql-reference/data-types/int-uint)) — الفاصل الزمني لإعادة التحميل بالثواني. 0 يعني أن إعادة التحميل معطلة.
* `deterministic` ([UInt8](/ar/sql-reference/data-types/int-uint)) — ما إذا كانت الدالة تُرجع النتيجة نفسها للوسيطات نفسها (قيمة منطقية).

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

اعرض جميع UDFs وحالة تحميلها:

```sql
SELECT
    name,
    load_status,
    type,
    command,
    return_type,
    argument_types
FROM system.user_defined_functions
FORMAT Vertical;
```

```response
Row 1:
──────
name:           my_sum_udf
load_status:    Success
type:           executable
command:        /var/lib/clickhouse/user_scripts/sum.py
return_type:    UInt64
argument_types: ['UInt64','UInt64']
```

ابحث عن UDFs الفاشلة:

```sql
SELECT
    name,
    loading_error_message
FROM system.user_defined_functions
WHERE load_status = 'Failed';
```
