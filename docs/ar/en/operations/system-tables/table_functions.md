<div id="description">
  ## الوصف
</div>

يحتوي على قائمة بجميع دوال الجدول المتاحة ووصف لكل منها.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم دالة الجدول.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف موجز لدالة الجدول.
* `allow_readonly` ([UInt8](/ar/sql-reference/data-types/int-uint)) — علامة تحدد ما إذا كان يمكن لمستخدم بصلاحية القراءة فقط استخدام هذه الدالة.

{/*AUTOGENERATED_END*/ }
