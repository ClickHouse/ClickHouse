<div id="description">
  ## الوصف
</div>

يصف محتوى ملف تعريف الإعدادات:

* القيود.
* الأدوار والمستخدمين الذين ينطبق عليهم هذا الإعداد.
* ملفات تعريف الإعدادات الأصلية.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `profile_name` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — اسم ملف تعريف الإعدادات.
* `user_name` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — اسم المستخدم.
* `role_name` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — اسم الدور.
* `index` ([UInt64](/ar/sql-reference/data-types/int-uint)) — الرقم التسلسلي لعنصر ملف تعريف الإعدادات.
* `setting_name` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — اسم الإعداد.
* `value` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — قيمة الإعداد.
* `min` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — الحد الأدنى لقيمة الإعداد. تكون NULL إذا لم يتم تعيينها.
* `max` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — الحد الأقصى لقيمة الإعداد. تكون NULL إذا لم يتم تعيينها.
* `writability` ([Nullable(Enum8(&#39;WRITABLE&#39; = 0, &#39;CONST&#39; = 1, &#39;CHANGEABLE&#95;IN&#95;READONLY&#39; = 2))](/ar/sql-reference/data-types/nullable)) — الخاصية التي توضح ما إذا كان الإعداد قابلاً للتغيير أم لا.
* `inherit_profile` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — ملف التعريف الأب لملف تعريف الإعدادات هذا. تكون NULL إذا لم يتم تعيينه. سيرث ملف تعريف الإعدادات جميع قيم الإعدادات وقيودها (min, max, readonly) من ملفات التعريف الأب التابعة له.

{/*AUTOGENERATED_END*/ }
