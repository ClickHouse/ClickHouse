<div id="description">
  ## الوصف
</div>

يتضمن معلومات حول إعدادات جداول [AzureQueue](../../engines/table-engines/integrations/azure-queue.md).
متاح بدءًا من إصدار الخادم `24.10`.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ar/sql-reference/data-types/string)) — قاعدة بيانات الجدول ذي المحرك AzureQueue.
* `table` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول ذي المحرك AzureQueue.
* `name` ([String](/ar/sql-reference/data-types/string)) — اسم الإعداد.
* `value` ([String](/ar/sql-reference/data-types/string)) — قيمة الإعداد.
* `type` ([String](/ar/sql-reference/data-types/string)) — نوع الإعداد (قيمة نصية خاصة بالتنفيذ).
* `changed` ([UInt8](/ar/sql-reference/data-types/int-uint)) — 1 إذا كان الإعداد مُعرّفًا صراحةً في ملف config أو قد غُيّر صراحةً.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف الإعداد.
* `alterable` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان المستخدم الحالي يستطيع تغيير الإعداد عبر ALTER TABLE MODIFY SETTING: 0 — لا يستطيع المستخدم الحالي تغيير الإعداد، 1 — يستطيع المستخدم الحالي تغيير الإعداد.

{/*AUTOGENERATED_END*/ }
