<div id="description">
  ## الوصف
</div>

يحتوي على قائمة بجميع نقاط الإخفاق المتاحة والمسجَّلة في الخادم، إلى جانب نوع كلٍّ منها وما إذا كانت مفعَّلة حاليًا.

يمكن تفعيل نقاط الإخفاق وتعطيلها أثناء التشغيل باستخدام الأمرين `SYSTEM ENABLE FAILPOINT` و`SYSTEM DISABLE FAILPOINT`.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم نقطة الإخفاق.
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/ar/sql-reference/data-types/enum)) — نوع نقطة الإخفاق: يُفعَّل &#39;once&#39; مرة واحدة ثم يُعطَّل تلقائيًا، ويُفعَّل &#39;regular&#39; في كل مرة، ويوقف &#39;pauseable&#95;once&#39; التنفيذ مرة واحدة، ويوقف &#39;pauseable&#39; التنفيذ في كل مرة إلى أن يُستأنف.
* `enabled` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يحدّد ما إذا كانت نقطة الإخفاق مفعّلة حاليًا (1) أو معطّلة (0).

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```
