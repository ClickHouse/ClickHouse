<div id="description">
  ## الوصف
</div>

يحتوي على معلومات عن [أنواع البيانات](../../sql-reference/data-types/index.md) المدعومة.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم نوع البيانات.
* `case_insensitive` ([UInt8](/ar/sql-reference/data-types/int-uint)) — خاصية توضّح ما إذا كان يمكن استخدام اسم نوع البيانات في استعلام دون مراعاة حالة الأحرف أم لا. على سبيل المثال، كلٌّ من `Date` و`date` صحيح.
* `alias_to` ([String](/ar/sql-reference/data-types/string)) — اسم نوع البيانات الذي يُعدّ `name` اسمًا مستعارًا له.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف عام لنوع البيانات.
* `syntax` ([String](/ar/sql-reference/data-types/string)) — بنية نوع البيانات في استعلام.
* `examples` ([String](/ar/sql-reference/data-types/string)) — أمثلة على الاستخدام.
* `introduced_in` ([String](/ar/sql-reference/data-types/string)) — إصدار ClickHouse الذي طُرح فيه نوع البيانات لأول مرة، بالتنسيق major.minor.
* `related` ([Array](/ar/sql-reference/data-types/array)([String](/ar/sql-reference/data-types/string))) — أسماء أنواع البيانات ذات الصلة.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
┌─name───────┬─case_insensitive─┬─alias_to─┐
│ LONGBLOB   │                1 │ String   │
│ LONGTEXT   │                1 │ String   │
│ TINYTEXT   │                1 │ String   │
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
