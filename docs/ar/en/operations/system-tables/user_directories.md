<div id="description">
  ## الوصف
</div>

يتضمن معلومات حول أدلة المستخدم المهيأة، وهي أدلة على نظام الملفات يُسمح لـ ClickHouse server بقراءة البيانات التي يوفّرها المستخدم منها.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم المجلد.
* `type` ([String](/ar/sql-reference/data-types/string)) — نوع مخزن الوصول، مثل users.xml أو replicated أو memory وما إلى ذلك.
* `params` ([String](/ar/sql-reference/data-types/string)) — كائن JSON يتضمن معاملات مخزن الوصول.
* `precedence` ([UInt64](/ar/sql-reference/data-types/int-uint)) — الترتيب الذي يُعرَّف به هذا المجلد في ملف config. ويُستخدم الترتيب نفسه عندما يحاول ClickHouse العثور على مستخدم أو دور.

{/*AUTOGENERATED_END*/ }
