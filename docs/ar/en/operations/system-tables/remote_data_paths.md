<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن ملفات البيانات المخزّنة على الأقراص البعيدة (مثل S3 وAzure Blob Storage)، بما في ذلك الربط بين مسارات البيانات الوصفية المحلية ومسارات كائنات blob البعيدة.

يمثّل كل صف كائن blob بعيدًا واحدًا مرتبطًا بملف بيانات.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `disk_name` ([String](/ar/sql-reference/data-types/string)) — اسم القرص.
* `path` ([String](/ar/sql-reference/data-types/string)) — مسار القرص.
* `cache_base_path` ([String](/ar/sql-reference/data-types/string)) — الدليل الأساسي لملفات التخزين المؤقت.
* `local_path` ([String](/ar/sql-reference/data-types/string)) — مسار ملف ClickHouse، ويُستخدم أيضًا كمسار للبيانات الوصفية.
* `remote_path` ([String](/ar/sql-reference/data-types/string)) — مسار blob في تخزين الكائنات المرتبط بملف ClickHouse.
* `size` ([UInt64](/ar/sql-reference/data-types/int-uint)) — حجم الملف (مضغوط).
* `common_prefix_for_blobs` ([String](/ar/sql-reference/data-types/string)) — البادئة المشتركة لـ blobs في تخزين الكائنات.
* `cache_paths` ([Array(String)](/ar/sql-reference/data-types/array)) — ملفات التخزين المؤقت الخاصة بـ blob المقابل.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.remote_data_paths LIMIT 1 FORMAT Vertical;
```

```text
Row 1:
──────
disk_name:              s3
path:                   /var/lib/clickhouse/disks/s3/
cache_base_path:        /var/lib/clickhouse/disks/s3_cache/
local_path:             store/123/1234abcd-1234-1234-1234-1234abcd1234/all_0_0_0/data.bin
remote_path:            abc123/all_0_0_0/data.bin
size:                   1048576
common_prefix_for_blobs:
cache_paths:            ['/var/lib/clickhouse/disks/s3_cache/a1/b2/c3d4e5f6']
```
