<div id="description">
  ## الوصف
</div>

يعرض جميع مُقسِّمات الرموز المتاحة.
يمكن استخدام هذه في الدوال [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens)، و[hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens)، و[hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens)، وفي [الفهرس النصي](../../engines/table-engines/mergetree-family/textindexes.md).

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم مُقسِّم الرموز

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.tokenizers;
```

```text
┌─name────────────┐
│ ngrams          │
│ splitByNonAlpha │
│ sparseGrams     │
│ tokenbf_v1      │
│ ngrambf_v1      │
│ array           │
│ splitByString   │
│ sparse_grams    │
│ asciiCJK        │
└─────────────────┘
```
