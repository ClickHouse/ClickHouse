<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن إعدادات جداول `MergeTree`.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم الإعداد.
* `value` ([String](/ar/sql-reference/data-types/string)) — قيمة الإعداد.
* `default` ([String](/ar/sql-reference/data-types/string)) — قيمة default للإعداد.
* `changed` ([UInt8](/ar/sql-reference/data-types/int-uint)) — 1 إذا كان الإعداد قد تم تعريفه صراحةً في `config` أو تم تغييره صراحةً.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف الإعداد.
* `min` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — الحد الأدنى لقيمة الإعداد، إذا كانت هناك قيمة معيّنة عبر القيود. وإذا لم تكن هناك قيمة دنيا للإعداد، فستكون القيمة NULL.
* `max` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — الحد الأقصى لقيمة الإعداد، إذا كانت هناك قيمة معيّنة عبر القيود. وإذا لم تكن هناك قيمة قصوى للإعداد، فستكون القيمة NULL.
* `disallowed_values` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة القيم غير المسموح بها
* `readonly` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان المستخدم الحالي يستطيع تغيير الإعداد: 0 — يستطيع المستخدم الحالي تغيير الإعداد، 1 — لا يستطيع المستخدم الحالي تغيير الإعداد.
* `type` ([String](/ar/sql-reference/data-types/string)) — نوع الإعداد (قيمة نصية تعتمد على التنفيذ).
* `is_obsolete` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان الإعداد مهملًا.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/ar/sql-reference/data-types/enum)) — مستوى الدعم لهذه الميزة. تُنظَّم ميزات ClickHouse ضمن مستويات تختلف بحسب حالتها الحالية
  من حيث التطوير والتوقعات الممكنة عند استخدامها:
  * PRODUCTION: الميزة مستقرة وآمنة للاستخدام، ولا توجد مشكلات في تفاعلها مع ميزات PRODUCTION الأخرى.
  * BETA: الميزة مستقرة وآمنة. لكن نتيجة استخدامها مع ميزات أخرى غير معروفة، ولا يُضمن السلوك الصحيح. نرحّب بالاختبارات والتقارير.
  * EXPERIMENTAL: الميزة قيد التطوير. وهي مخصّصة فقط للمطورين ومتحمّسي ClickHouse. وقد تعمل أو لا تعمل، كما قد تُزال في أي وقت.
  * OBSOLETE: لم تعد مدعومة. إما أنها أُزيلت بالفعل أو ستُزال في الإصدارات المستقبلية.

{/*AUTOGENERATED_END*/ }
