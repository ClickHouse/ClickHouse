<div id="description">
  ## الوصف
</div>

لا يوجد هذا الجدول إذا لم تكن هذه العقدة مُهيأة لتشغيل ClickHouse Keeper داخل العملية. ويحتوي على صف واحد لكل ملف سجل تغييرات Raft (`changelog_<from>_<to>.bin[.zstd]`) يتتبعه مخزن سجلات Keeper داخل العملية، بما في ذلك الملف النشط الذي تُضاف إليه إدخالات جديدة حاليًا.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `from_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — أول فهرس لسجل Raft في الملف (شامل).
* `to_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — آخر فهرس لسجل Raft يغطيه اسم الملف (شامل). بالنسبة إلى الملف النشط، فهذا هو هدف التدوير وقد يكون متقدمًا على `last_entry_index`.
* `last_entry_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — أعلى فهرس سجل أُلحق فعليًا بهذا الملف. تكون القيمة `NULL` إذا لم يكن الملف النشط قد تلقّى أي إدخالات بعد أو إذا كان الملف تالفًا.
* `entries` ([UInt64](../../sql-reference/data-types/int-uint.md)) — عدد الإدخالات المُلحقة بهذا الملف. `ALIAS` لـ `ifNull(last_entry_index - from_log_index + 1, 0)`.
* `path` ([String](../../sql-reference/data-types/string.md)) — مسار الملف على القرص.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — اسم القرص الذي يحتوي الملف.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — حجم الملف على القرص.
* `modification_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — وقت آخر تعديل للملف.
* `is_compressed` ([Bool](../../sql-reference/data-types/boolean.md)) — حمولة الملف مضغوطة باستخدام zstd.
* `active` ([Bool](../../sql-reference/data-types/boolean.md)) — يُلحَق بهذا الملف حاليًا.
* `is_broken` ([Bool](../../sql-reference/data-types/boolean.md)) — تم العثور على السجل الأخير تالفًا عند بدء التشغيل.

{/*AUTOGENERATED_END*/ }

مثال:

```sql
SELECT from_log_index, to_log_index, entries, path, active FROM system.keeper_changelogs ORDER BY from_log_index;
```

│           1001 │         2000 │     537 │ changelog_1001_2000.bin.zstd   │ true   │
