يتضمن معلومات عن جميع المعاملات التي نُفِّذت على الخادم الحالي.

من الآمن تنفيذ TRUNCATE لهذا الجدول أو إسقاطه في أي وقت.

الأعمدة:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ar/sql-reference/data-types/lowcardinality)) — اسم المضيف الذي نُفِّذت عليه المعاملة.
* `type` ([Enum8(&#39;Begin&#39; = 1, &#39;Commit&#39; = 2, &#39;Rollback&#39; = 3, &#39;AddPart&#39; = 10, &#39;LockPart&#39; = 11, &#39;UnlockPart&#39; = 12)](/ar/sql-reference/data-types/enum)) — نوع المعاملة. القيم الممكنة: Begin, Commit, Rollback, AddPart, LockPart, UnlockPart.
* `event_date` ([Date](/ar/sql-reference/data-types/date)) — تاريخ السجل.
* `event_time` ([DateTime64(6)](/ar/sql-reference/data-types/datetime64)) — وقت السجل
* `thread_id` ([UInt64](/ar/sql-reference/data-types/int-uint)) — معرّف خيط التنفيذ.
* `query_id` ([String](/ar/sql-reference/data-types/string)) — معرّف استعلام نُفِّذ ضمن نطاق المعاملة.
* `tid` ([Tuple(UInt64, UInt64, UUID)](/ar/sql-reference/data-types/tuple)) — معرّف المعاملة.
* `tid_hash` ([UInt64](/ar/sql-reference/data-types/int-uint)) — تجزئة المعرّف.
* `csn` ([UInt64](/ar/sql-reference/data-types/int-uint)) — رقم تسلسل Commit
* `database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات التي نُفِّذت عليها المعاملة.
* `table` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول الذي نُفِّذت عليه المعاملة.
* `uuid` ([UUID](/ar/sql-reference/data-types/uuid)) — معرّف UUID للجدول الذي نُفِّذت عليه المعاملة.
* `part` ([String](/ar/sql-reference/data-types/string)) — اسم الجزء المشارك في المعاملة.

{/*AUTOGENERATED_END*/ }
