<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن [أعباء العمل](/ar/operations/workload-scheduling.md#workload_entity_storage) الموجودة على الخادم المحلي. ويحتوي الجدول على صف لكل عبء عمل.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم عبء العمل.
* `parent` ([String](/ar/sql-reference/data-types/string)) — اسم عبء العمل الأصلي.
* `create_query` ([String](/ar/sql-reference/data-types/string)) — استعلام CREATE الخاص بعبء العمل.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT *
FROM system.workloads
FORMAT Vertical
```

```text
Row 1:
──────
name:         production
parent:       all
create_query: CREATE WORKLOAD production IN `all` SETTINGS weight = 9

Row 2:
──────
name:         development
parent:       all
create_query: CREATE WORKLOAD development IN `all`

Row 3:
──────
name:         all
parent:
create_query: CREATE WORKLOAD `all`
```
