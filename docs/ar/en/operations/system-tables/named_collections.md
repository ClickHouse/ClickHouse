<div id="description">
  ## الوصف
</div>

يحتوي على قائمة بجميع المجموعات المسماة التي أُنشئت عبر استعلام SQL أو استُخرجت من ملف التهيئة بعد تحليله.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم المجموعة المُسمّاة.
* `collection` ([Map(String, String)](/ar/sql-reference/data-types/map)) — البنية الداخلية للمجموعة.
* `source` ([String](/ar/sql-reference/data-types/string)) — مصدر المجموعة المُسمّاة.
* `create_query` ([String](/ar/sql-reference/data-types/string)) — استعلام إنشاء المجموعة المُسمّاة.

{/*AUTOGENERATED_END*/ }
