<div id="description">
  ## الوصف
</div>

يحتوي على القيم التاريخية لـ `system.asynchronous_metrics`، والتي تُحفَظ مرة واحدة في كل فترة زمنية (ثانية واحدة افتراضيًا). وهو مفعّل افتراضيًا.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ar/sql-reference/data-types/lowcardinality)) — اسم مضيف الخادم الذي ينفّذ الاستعلام.
* `event_date` ([Date](/ar/sql-reference/data-types/date)) — تاريخ الحدث.
* `event_time` ([DateTime](/ar/sql-reference/data-types/datetime)) — وقت الحدث.
* `metric` ([LowCardinality(String)](/ar/sql-reference/data-types/lowcardinality)) — اسم المقياس.
* `value` ([Float64](/ar/sql-reference/data-types/float)) — قيمة المقياس.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.asynchronous_metric_log LIMIT 3 \G
```

```text
Row 1:
──────
hostname:   clickhouse.eu-central1.internal
event_date: 2023-11-14
event_time: 2023-11-14 14:39:07
metric:     AsynchronousHeavyMetricsCalculationTimeSpent
value:      0.001

Row 2:
──────
hostname:   clickhouse.eu-central1.internal
event_date: 2023-11-14
event_time: 2023-11-14 14:39:08
metric:     AsynchronousHeavyMetricsCalculationTimeSpent
value:      0

Row 3:
──────
hostname:   clickhouse.eu-central1.internal
event_date: 2023-11-14
event_time: 2023-11-14 14:39:09
metric:     AsynchronousHeavyMetricsCalculationTimeSpent
value:      0
```
