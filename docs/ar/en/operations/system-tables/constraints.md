<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن القيود الموجودة في جميع الجداول.

لا تظهر القيود المعرّفة على [الجداول المؤقتة](../../sql-reference/statements/create/table.md#temporary-tables) في `system.constraints` إلا ضمن الجلسة التي أُنشئت فيها. وتُعرض بحقل `database` فارغ.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول.
* `name` ([String](/ar/sql-reference/data-types/string)) — اسم القيد.
* `type` ([Enum8(&#39;CHECK&#39; = 0, &#39;ASSUME&#39; = 1)](/ar/sql-reference/data-types/enum)) — نوع القيد.
* `expression` ([String](/ar/sql-reference/data-types/string)) — تعبير القيد.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.constraints LIMIT 2 FORMAT Vertical;
```

```text
Row 1:
──────
database:    default
table:       hits
name:        check_hits
type:        CHECK
expression:  CounterID > 0

Row 2:
──────
database:    default
table:       hits
name:        assume_positive
type:        ASSUME
expression:  WatchID > 0
```
