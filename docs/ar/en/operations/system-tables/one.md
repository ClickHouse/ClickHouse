<div id="description">
  ## الوصف
</div>

يحتوي هذا الجدول على صف واحد فقط وعمود واحد باسم `dummy` من النوع UInt8، وتكون قيمته 0.

يُستخدم هذا الجدول إذا لم يحدّد استعلام `SELECT` عبارة `FROM`.

وهذا مشابه لجدول `DUAL` الموجود في أنظمة إدارة قواعد البيانات الأخرى.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `dummy` ([UInt8](/ar/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.one LIMIT 10;
```

```response
┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
```
