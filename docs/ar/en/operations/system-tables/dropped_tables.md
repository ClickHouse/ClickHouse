<div id="description">
  ## الوصف
</div>

يحتوي على معلومات حول الجداول التي نُفِّذ عليها الأمر drop table ولم تُنفَّذ بعدُ عملية تنظيف البيانات الخاصة بها.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt32](/ar/sql-reference/data-types/int-uint)) — المؤشر في قائمة انتظار marked&#95;dropped&#95;tables.
* `database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول.
* `uuid` ([UUID](/ar/sql-reference/data-types/uuid)) — معرّف UUID للجدول.
* `engine` ([String](/ar/sql-reference/data-types/string)) — اسم محرك الجدول.
* `metadata_dropped_path` ([String](/ar/sql-reference/data-types/string)) — مسار ملف البيانات الوصفية للجدول في الدليل metadata&#95;dropped.
* `table_dropped_time` ([DateTime](/ar/sql-reference/data-types/datetime)) — الوقت المُجدول للمحاولة التالية لإزالة بيانات الجدول. وعادةً ما يكون وقت حذف الجدول مضافًا إليه `database_atomic_delay_before_drop_table_sec`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

يوضح المثال التالي كيفية الحصول على معلومات عن `dropped_tables`.

```sql
SELECT *
FROM system.dropped_tables\G
```
