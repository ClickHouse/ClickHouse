<div id="description">
  ## الوصف
</div>

يتضمن معلومات حول معلمات [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite) المستخدمة في الجداول التي تستخدم محركات [*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md).

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/ar/sql-reference/data-types/string)) — اسم معلمة graphite&#95;rollup.
* `rule_type` ([String](/ar/sql-reference/data-types/string)) — نوع القاعدة. القيم الممكنة: RuleTypeAll = 0 - الافتراضي، مع regex، ومتوافق مع المخطط القديم؛ RuleTypePlain = 1 - مقاييس عادية، مع regex، ومتوافق مع المخطط القديم؛ RuleTypeTagged = 2 - مقاييس ذات علامات، مع regex، ومتوافق مع المخطط القديم؛ RuleTypeTagList = 3 - مقاييس ذات علامات، مع regex (تُحوَّل إلى RuleTypeTagged من سلسلة مثل &#39;retention=10min ; env=(staging|prod)&#39;)
* `regexp` ([String](/ar/sql-reference/data-types/string)) — نمط لاسم المقياس.
* `function` ([String](/ar/sql-reference/data-types/string)) — اسم دالة التجميع.
* `age` ([UInt64](/ar/sql-reference/data-types/int-uint)) — الحد الأدنى لعمر البيانات بالثواني.
* `precision` ([UInt64](/ar/sql-reference/data-types/int-uint)) — مدى دقة تحديد عمر البيانات بالثواني.
* `priority` ([UInt16](/ar/sql-reference/data-types/int-uint)) — أولوية النمط.
* `is_default` ([UInt8](/ar/sql-reference/data-types/int-uint)) — ما إذا كان النمط هو الافتراضي.
* `Tables.database` ([Array(String)](/ar/sql-reference/data-types/array)) — مصفوفة بأسماء جداول قاعدة البيانات التي تستخدم المعلمة `config_name`.
* `Tables.table` ([Array(String)](/ar/sql-reference/data-types/array)) — مصفوفة بأسماء الجداول التي تستخدم المعلمة `config_name`.

{/*AUTOGENERATED_END*/ }
