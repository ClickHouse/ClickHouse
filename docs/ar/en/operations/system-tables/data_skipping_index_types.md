<div id="description">
  ## الوصف
</div>

يحتوي على قائمة بأنواع فهارس تخطي البيانات التي يدعمها الخادم، إلى جانب الوثائق المضمنة لكل نوع. ويُحدَّد نوع فهرس تخطي البيانات في `TYPE` ضمن تعريف `INDEX` في استعلام `CREATE TABLE`، ويتيح لـ ClickHouse تخطي وحدات `granules` التي لا يمكن أن تطابق شرط الاستعلام.

لاحظ أن هذا الجدول يسرد *أنواع* الفهارس المتاحة، بينما يسرد [`system.data_skipping_indices`](/ar/operations/system-tables/data_skipping_indices) مثيلات الفهارس المعرّفة على الجداول الموجودة.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم نوع فهرس تخطي البيانات، كما هو محدد في TYPE ضمن تعريف INDEX.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف عام لما يفعله نوع فهرس تخطي البيانات.
* `syntax` ([String](/ar/sql-reference/data-types/string)) — كيفية تعريف الفهرس في عبارة INDEX ضمن استعلام CREATE TABLE.
* `examples` ([String](/ar/sql-reference/data-types/string)) — أمثلة استخدام.
* `introduced_in` ([String](/ar/sql-reference/data-types/string)) — إصدار ClickHouse الذي طُرح فيه نوع الفهرس لأول مرة، بصيغة major.minor.
* `related` ([Array](/ar/sql-reference/data-types/array)([String](/ar/sql-reference/data-types/string))) — أسماء أنواع فهارس تخطي البيانات ذات الصلة.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT name, syntax
FROM system.data_skipping_index_types
WHERE name IN ('minmax', 'set')
ORDER BY name
```

```text title="Response"
┌─name───┬─syntax───────────────────────────────────────┐
│ minmax │ INDEX name expr TYPE minmax GRANULARITY n     │
│ set    │ INDEX name expr TYPE set(max_rows) GRANULARITY n │
└────────┴──────────────────────────────────────────────┘
```
