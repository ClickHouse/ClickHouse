<div id="description">
  ## الوصف
</div>

يجمع هذا الجدول التوثيق المضمَّن للمكوّنات الموحَّدة في النظام في جدول واحد. ويمثّل كل صف كيانًا واحدًا (مثل دالة أو محرك جدول أو نوع بيانات، وما إلى ذلك)، ويحتوي على التوثيق المرجعي لذلك الكيان معروضًا بصيغة Markdown — وهو نفس المحتوى المنشور على الموقع الإلكتروني والمكشوف عبر جداول `system.*` المخصّصة لكل نوع.

يُجمَّع `description` من الأجزاء المنظَّمة للتوثيق المضمَّن (`description` و`syntax` والوسائط والأمثلة وما إلى ذلك)، لذا يحتوي عمود واحد على التوثيق الكامل للكيان. وتُعرَض الأسماء المستعارة كإحالة قصيرة إلى الكيان الأصلي، مثل: ``Alias of `trunc`.``

يجمع هذا الجدول، إلى حدٍّ ما، المعلومات المتاحة في جداول التوثيق المخصّصة لكل نوع ([`system.functions`](/ar/operations/system-tables/functions) و[`system.table_engines`](/ar/operations/system-tables/table_engines) و[`system.data_type_families`](/ar/operations/system-tables/data_type_families) وغيرها). وهو مخصّص، على وجه الخصوص، لدعم أمر `help` تفاعلي في العميل، لكنه مفيد أيضًا بحد ذاته.

تُجمَع الأنواع التالية من الكيانات (وتُعرض قيمة عمود `type` بين قوسين):

* الدوال (`Function`)
* الدوال التجميعية (`Aggregate Function`)
* دوال الجداول (`Table Function`)
* محركات الجداول (`Table Engine`)
* محركات قواعد البيانات (`Database Engine`)
* أنواع البيانات (`Data Type`)
* تخطيطات القواميس (`Dictionary Layout`)
* مصادر القواميس (`Dictionary Source`)
* مُركِّبات الدوال التجميعية (`Aggregate Function Combinator`)
* أنواع فهارس تخطي البيانات (`Data Skipping Index`)
* أنواع الأقراص (`Disk Type`)
* الإعدادات (`Setting`)
* إعدادات MergeTree (`MergeTree Setting`)
* إعدادات الخادم (`Server Setting`)
* التنسيقات (`Format`)
* ترميزات الضغط (`Compression Codec`)
* أحداث التنميط (`Profile Event`)
* المقاييس الحالية (`Current Metric`)
* المقاييس غير المتزامنة (`Asynchronous Metric`)
* جداول النظام (`System Table`)

بالنسبة إلى الإعدادات (من أي نوع)، يكون التوثيق هو وصف الإعداد إلى جانب نوعه وقيمته الافتراضية؛ ولا تُعرَض الإعدادات المهجورة. أما بالنسبة إلى جداول النظام، فيكون التوثيق هو تعليق الجدول مع قائمة أعمدته (اسم كل عمود ونوعه ووصفه).

يحتوي عمود `source` على مسار الملف المصدري الذي يُعرَّف فيه توثيق الكيان، نسبةً إلى جذر المستودع. وبالنسبة إلى معظم الكيانات، يُلتقط هذا تلقائيًا في الموضع الذي يُنشأ فيه كائن التوثيق (موضع تسجيل المكوّن)؛ أما الأنواع التي يُوثَّق كل منها في ملف مصدري واحد (مثل الإعدادات وأحداث التنميط والمقاييس الحالية)، فيكون المقصود هو ذلك الملف.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم الكيان، مثل `domainWithoutWWW` أو `MergeTree`.
* `type` ([Enum8](/ar/sql-reference/data-types/enum)) — نوع الكيان، مثل `Function` أو `Table Engine`.
* `description` ([String](/ar/sql-reference/data-types/string)) — الوثائق المرجعية للكيان، معروضة بصيغة Markdown ومجمّعة من الوثائق المضمّنة (وهي نفس المحتوى المنشور على الموقع الإلكتروني)، بما في ذلك البنية النحوية والأمثلة والأجزاء المنظَّمة الأخرى، إن وُجدت.
* `source` ([String](/ar/sql-reference/data-types/string)) — المسار إلى الملف المصدري الذي تُعرَّف فيه وثائق الكيان، نسبةً إلى جذر المستودع. يكون فارغًا إذا كان موقع المصدر غير معروف.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

اطّلِع على توثيق كيان معيّن:

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

يمكن أن يشير الاسم نفسه إلى عدة أنواع من الكيانات (على سبيل المثال، توجد كلٌّ من دالة الجدول `file` ومصدر القاموس `file`)، لذا من المفيد البحث عن الاسم عبر جميع الأنواع:

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

احسب عدد الكيانات الموثقة من كل نوع:

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
