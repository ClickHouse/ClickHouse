<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن [الموارد](/ar/operations/workload-scheduling.md#workload_entity_storage) الموجودة على الخادم المحلي. يحتوي الجدول على صف لكل مورد.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم المورد.
* `read_disks` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة بأسماء الأقراص التي تستخدم هذا المورد لعمليات القراءة.
* `write_disks` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة بأسماء الأقراص التي تستخدم هذا المورد لعمليات الكتابة.
* `unit` ([String](/ar/sql-reference/data-types/string)) — وحدة المورد المستخدمة في قياس التكلفة.
* `create_query` ([String](/ar/sql-reference/data-types/string)) — استعلام CREATE الخاص بالمورد.

{/*AUTOGENERATED_END*/ }

مثال:

```sql
SELECT *
FROM system.resources
FORMAT Vertical
```

```text
Row 1:
──────
name:         io_read
read_disks:   ['s3']
write_disks:  []
create_query: CREATE RESOURCE io_read (READ DISK s3)

Row 2:
──────
name:         io_write
read_disks:   []
write_disks:  ['s3']
create_query: CREATE RESOURCE io_write (WRITE DISK s3)
```
