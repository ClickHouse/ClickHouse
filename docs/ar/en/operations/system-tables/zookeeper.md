<div id="description">
  ## الوصف
</div>

لا يكون الجدول موجودًا إلا إذا تم تهيئة ClickHouse Keeper أو ZooKeeper. ويعرض جدول `system.zookeeper` بيانات عناقيد Keeper المعرّفة في ملف الإعدادات.
يجب أن يتضمن الاستعلام إما شرط `path =`   أو شرط `path IN`  ضمن عبارة `WHERE` كما هو موضح أدناه. ويقابل ذلك مسار العُقد الفرعية التي تريد جلب البيانات لها.

يعرض الاستعلام `SELECT * FROM system.zookeeper WHERE path = '/clickhouse'` بيانات جميع العُقد الفرعية ضمن العُقدة `/clickhouse`.
ولعرض بيانات جميع العُقد الجذرية، اكتب path = &#39;/&#39;.
إذا كان المسار المحدد في &#39;path&#39; غير موجود، فسيتم إطلاق استثناء.

يعرض الاستعلام `SELECT * FROM system.zookeeper WHERE path IN ('/', '/clickhouse')` بيانات جميع العُقد الفرعية ضمن العُقدتين `/` و`/clickhouse`.
إذا كان أي مسار ضمن مجموعة &#39;path&#39; المحددة غير موجود، فسيتم إطلاق استثناء.
ويمكن استخدامه لتنفيذ دفعة من استعلامات Keeper path.

يعرض الاستعلام `SELECT * FROM system.zookeeper WHERE path = '/clickhouse' AND zookeeperName = 'auxiliary_cluster'` البيانات في عنقود ZooKeeper ‏`auxiliary_cluster`.
إذا لم تكن `'auxiliary_cluster'` المحددة موجودة، فسيتم إطلاق استثناء.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` (String) — اسم العقدة.
* `path` (String) — مسار العقدة.
* `value` (String) — قيمة العقدة.
* `zookeeperName` (String) — اسم عنقود ZooKeeper الافتراضي أو أحد عناقيد ZooKeeper الإضافية.
* `dataLength` (Int32) — حجم القيمة.
* `numChildren` (Int32) — عدد العُقد الفرعية.
* `czxid` (Int64) — معرّف المعاملة التي أنشأت العقدة.
* `mzxid` (Int64) — معرّف المعاملة التي غيّرت العقدة لآخر مرة.
* `pzxid` (Int64) — معرّف المعاملة التي أضافت العُقد الفرعية أو حذفتها لآخر مرة.
* `ctime` (DateTime) — وقت إنشاء العقدة.
* `mtime` (DateTime) — وقت آخر تعديل على العقدة.
* `version` (Int32) — إصدار العقدة: عدد المرات التي تغيّرت فيها.
* `cversion` (Int32) — عدد العُقد الفرعية التي أُضيفت أو أُزيلت.
* `aversion` (Int32) — عدد التغييرات على ACL.
* `ephemeralOwner` (Int64) — بالنسبة إلى العُقد المؤقتة، معرّف الجلسة المالكة لهذه العقدة.

{/*AUTOGENERATED_END*/ }
