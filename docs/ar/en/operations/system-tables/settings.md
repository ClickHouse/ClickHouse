<div id="description">
  ## الوصف
</div>

يحتوي على معلومات عن إعدادات الجلسة للمستخدم الحالي.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم الإعداد.
* `value` ([String](/ar/sql-reference/data-types/string)) — قيمة الإعداد.
* `changed` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان الإعداد قد حُدِّد صراحةً في ملف config أو تم تغييره صراحةً.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف مختصر للإعداد.
* `min` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — الحد الأدنى لقيمة الإعداد، إذا كانت هناك قيمة محددة عبر القيود. وإذا لم تكن هناك قيمة دنيا للإعداد، فستكون القيمة NULL.
* `max` ([Nullable(String)](/ar/sql-reference/data-types/nullable)) — الحد الأقصى لقيمة الإعداد، إذا كانت هناك قيمة محددة عبر القيود. وإذا لم تكن هناك قيمة قصوى للإعداد، فستكون القيمة NULL.
* `disallowed_values` ([Array(String)](/ar/sql-reference/data-types/array)) — قائمة القيم غير المسموح بها
* `readonly` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان المستخدم الحالي يمكنه تغيير الإعداد: 0 — يمكن للمستخدم الحالي تغيير الإعداد، 1 — لا يمكن للمستخدم الحالي تغيير الإعداد.
* `type` ([String](/ar/sql-reference/data-types/string)) — نوع القيمة التي يمكن إسنادها إلى هذا الإعداد.
* `default` ([String](/ar/sql-reference/data-types/string)) — القيمة الافتراضية للإعداد.
* `alias_for` ([String](/ar/sql-reference/data-types/string)) — اسم الإعداد الأصلي إذا كان هذا الإعداد اسمًا مستعارًا لإعداد آخر.
* `is_obsolete` ([UInt8](/ar/sql-reference/data-types/int-uint)) — يوضّح ما إذا كان الإعداد مهملًا.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/ar/sql-reference/data-types/enum)) — مستوى الدعم لهذه الميزة. تُنظَّم ميزات ClickHouse ضمن مستويات تختلف بحسب الحالة الحالية
  لتطويرها والتوقعات الممكنة عند استخدامها:
  * PRODUCTION: الميزة مستقرة وآمنة للاستخدام، ولا توجد مشكلات في تفاعلها مع ميزات PRODUCTION الأخرى.
  * BETA: الميزة مستقرة وآمنة. لكن نتيجة استخدامها مع ميزات أخرى غير معروفة، ولا يمكن ضمان صحتها. نرحب بالاختبارات والتقارير.
  * EXPERIMENTAL: الميزة قيد التطوير. وهي مخصّصة فقط للمطورين ومتحمسي ClickHouse. قد تعمل الميزة أو لا تعمل، وقد تُزال في أي وقت.
  * OBSOLETE: لم تعد مدعومة. إما أنها أُزيلت بالفعل أو ستُزال في إصدارات مستقبلية.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

يوضح المثال التالي كيفية الحصول على معلومات حول الإعدادات التي يتضمن اسمها `min_i`.

```sql
SELECT *
FROM system.settings
WHERE name LIKE '%min_insert_block_size_%'
FORMAT Vertical
```

قد يكون استخدام `WHERE changed` مفيدًا، على سبيل المثال، عندما تريد التحقق مما يلي:

* ما إذا كانت الإعدادات في ملفات التهيئة قد حُمّلت بشكل صحيح وما إذا كانت مستخدمة.
* الإعدادات التي تغيّرت في الجلسة الحالية.

```sql
SELECT * FROM system.settings WHERE changed AND name='load_balancing'
```
