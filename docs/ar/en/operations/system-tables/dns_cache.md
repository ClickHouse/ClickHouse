<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن سجلات DNS المخزنة مؤقتًا.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([String](/ar/sql-reference/data-types/string)) — اسم المضيف.
* `ip_address` ([String](/ar/sql-reference/data-types/string)) — عنوان IP.
* `ip_family` ([Enum8(&#39;IPv4&#39; = 0, &#39;IPv6&#39; = 1, &#39;UNIX&#95;LOCAL&#39; = 2)](/ar/sql-reference/data-types/enum)) — عائلة عنوان IP.
* `cached_at` ([DateTime](/ar/sql-reference/data-types/datetime)) — الطابع الزمني الذي تم فيه تخزين السجل مؤقتًا.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT * FROM system.dns_cache;
```

| hostname  | ip&#95;address | ip&#95;family | cached&#95;at       |
| :-------- | :------------- | :------------ | :------------------ |
| localhost | ::1            | IPv6          | 2024-02-11 17:04:40 |
| localhost | 127.0.0.1      | IPv4          | 2024-02-11 17:04:40 |
