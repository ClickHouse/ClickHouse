<div id="purpose">
  ## الوصف
</div>

يسجّل جدول `system.delta_lake_metadata_log` أحداث الوصول إلى البيانات الوصفية وتحليلها لجداول Delta Lake التي يقرأها ClickHouse. ويوفّر معلومات تفصيلية عن كل ملف البيانات الوصفية، مما يفيد في استكشاف الأخطاء وإصلاحها، والتدقيق، وفهم تطوّر بنية جداول Delta.

يسجّل هذا الجدول كل ملف البيانات الوصفية يُقرأ من جداول Delta Lake. ويساعد المستخدمين على تتبّع كيفية تفسير ClickHouse للبيانات الوصفية لجداول Delta وتشخيص المشكلات المرتبطة بتطوّر المخطط، أو تحديد اللقطة، أو تخطيط الاستعلام.

:::note
هذا الجدول مخصّص أساسًا لأغراض استكشاف الأخطاء وإصلاحها.
:::

<div id="controlling-log-verbosity">
  ### التحكّم في مستوى تفصيل السجل
</div>

يمكنك التحكّم في أحداث البيانات الوصفية التي تُسجَّل باستخدام الإعداد [`delta_lake_log_metadata`](../../operations/settings/settings.md#delta_lake_log_metadata).

لتسجيل جميع البيانات الوصفية المستخدمة في الاستعلام الحالي:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```
