<div id="description">
  ## الوصف
</div>

يحتوي هذا الجدول على الأدوار النشطة للمستخدم الحالي. ويؤدي `SET ROLE` إلى تغيير محتويات هذا الجدول.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/ar/sql-reference/data-types/string)) — اسم الدور.
* `with_admin_option` ([UInt8](/ar/sql-reference/data-types/int-uint)) — 1 إذا كان الدور يمتلك امتياز ADMIN OPTION.
* `is_default` ([UInt8](/ar/sql-reference/data-types/int-uint)) — 1 إذا كان الدور مُعيَّنًا كدور افتراضي.

{/*AUTOGENERATED_END*/ }
