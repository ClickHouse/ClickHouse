<div id="description">
  ## الوصف
</div>

يحتوي جدول النظام هذا على البيانات الوصفية الخاصة بكل ملف في جداول Iceberg الموجودة في ClickHouse، بحيث يقابل كل ملف بيانات أو ملف حذف مشار إليه في اللقطة الحالية لكل جدول صفٌّ واحد. وسيكون هذا الجدول فارغًا إذا لم تكن لديك أي جداول Iceberg في ClickHouse.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول.
* `snapshot_id` ([Int64](/ar/sql-reference/data-types/int-uint)) — معرّف اللقطة التي أُضيف الملف عندها.
* `content` ([Enum8](/ar/sql-reference/data-types/enum)) — نوع محتوى الملف: `DATA` أو `POSITION_DELETE` أو `EQUALITY_DELETE`.
* `file_path` ([String](/ar/sql-reference/data-types/string)) — مسار التخزين المُحدَّد للملف.
* `file_format` ([String](/ar/sql-reference/data-types/string)) — تنسيق الملف، مثل `'PARQUET'`.
* `record_count` ([Int64](/ar/sql-reference/data-types/int-uint)) — عدد السجلات في الملف.
* `file_size_in_bytes` ([Int64](/ar/sql-reference/data-types/int-uint)) — حجم الملف بالبايت.
* `partition` ([String](/ar/sql-reference/data-types/string)) — تمثيل نصي لـ tuple الخاص بـ partition.
* `schema_id` ([Int32](/ar/sql-reference/data-types/int-uint)) — معرّف المخطط المُحدَّد لإدخال manifest هذا.
* `sequence_number` ([Int64](/ar/sql-reference/data-types/int-uint)) — رقم التسلسل المُحدَّد لإدخال manifest (ويكون دائمًا 0 في format v1).
* `sort_order_id` ([Nullable(Int32)](/ar/sql-reference/data-types/nullable)) — معرّف ترتيب الفرز للملف، إذا كان محددًا.
* `null_value_counts` ([Map(Int32, Int64)](/ar/sql-reference/data-types/map)) — عدد قيم NULL لكل عمود (معرّف العمود -&gt; العدد).
* `column_sizes` ([Map(Int32, Int64)](/ar/sql-reference/data-types/map)) — حجم كل عمود على القرص بالبايت (معرّف العمود -&gt; عدد البايتات).
* `value_counts` ([Map(Int32, Int64)](/ar/sql-reference/data-types/map)) — إجمالي عدد القيم لكل عمود (معرّف العمود -&gt; العدد).
* `equality_ids` ([Array(Int32)](/ar/sql-reference/data-types/array)) — معرّفات الحقول الخاصة بالمساواة لملفات حذف المساواة (وتكون فارغة للملفات التي لا تستخدم حذف المساواة).

{/*AUTOGENERATED_END*/ }
