<div id="description">
  ## الوصف
</div>

يضمّ الاستعلامات المستخدمة في صفحة `/dashboard` التي يمكن الوصول إليها عبر [واجهة HTTP](/ar/interfaces/http).
قد يكون هذا الجدول مفيدًا للمراقبة واستكشاف الأخطاء وإصلاحها. ويحتوي على صف لكل مخطط في لوحة معلومات.

:::note
يمكن لصفحة `/dashboard` عرض استعلامات ليس من `system.dashboards` فحسب، بل من أي جدول له البنية نفسها.
وقد يكون ذلك مفيدًا لإنشاء لوحات معلومات مخصّصة.
:::

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `dashboard` ([String](/ar/sql-reference/data-types/string)) — اسم لوحة المعلومات.
* `title` ([String](/ar/sql-reference/data-types/string)) — عنوان المخطط.
* `query` ([String](/ar/sql-reference/data-types/string)) — الاستعلام المستخدم لجلب البيانات المراد عرضها.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT *
FROM system.dashboards
WHERE title ILIKE '%CPU%'
```
