<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن عدد الأحداث التي حدثت في النظام. على سبيل المثال، يمكنك أن تجد في الجدول عدد استعلامات `SELECT` التي تمت معالجتها منذ بدء تشغيل ClickHouse server.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/ar/sql-reference/data-types/string)) — اسم الحدث.
* `value` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد مرات حدوث الحدث.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف الحدث.

**الأسماء المستعارة:**

* `name` — اسم مستعار لـ `event`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.events LIMIT 5
```
