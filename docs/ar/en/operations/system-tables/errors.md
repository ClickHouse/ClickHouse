<div id="description">
  ## الوصف
</div>

يحتوي على رموز الخطأ مع عدد مرات حدوثها.

لعرض جميع رموز الخطأ المحتملة، بما في ذلك تلك التي لم تحدث، عيّن الإعداد [system&#95;events&#95;show&#95;zero&#95;values](../settings/settings.md#system_events_show_zero_values) إلى 1.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم الخطأ (errorCodeToName).
* `code` ([Int32](/ar/sql-reference/data-types/int-uint)) — رقم الخطأ.
* `value` ([UInt64](/ar/sql-reference/data-types/int-uint)) — عدد مرات حدوث هذا الخطأ.
* `last_error_time` ([DateTime](/ar/sql-reference/data-types/datetime)) — الوقت الذي حدث فيه آخر خطأ.
* `last_error_message` ([String](/ar/sql-reference/data-types/string)) — رسالة آخر خطأ.
* `last_error_format_string` ([String](/ar/sql-reference/data-types/string)) — سلسلة التنسيق الخاصة بآخر خطأ.
* `last_error_trace` ([Array(UInt64)](/ar/sql-reference/data-types/array)) — تتبّع مكدس يمثّل قائمة بالعناوين الفعلية التي تُخزَّن عندها الدوال المستدعاة.
* `remote` ([UInt8](/ar/sql-reference/data-types/int-uint)) — استثناء عن بُعد (أي تم استلامه أثناء أحد الاستعلامات الموزعة).
* `query_id` ([String](/ar/sql-reference/data-types/string)) — معرّف الاستعلام الذي تسبّب في الخطأ (إن كان متاحًا).

{/*AUTOGENERATED_END*/ }

:::note
قد تزداد عدادات بعض الأخطاء أثناء تنفيذ الاستعلام بنجاح. لا يُنصح باستخدام هذا الجدول لأغراض مراقبة الخادم ما لم تكن متأكدًا من أن الخطأ المقابل لا يمكن أن يكون نتيجة إيجابية كاذبة.
:::

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
