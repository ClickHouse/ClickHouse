<div id="description">
  ## الوصف
</div>

يحتوي على قائمة بأنواع الأقراص التي يدعمها الخادم، إلى جانب الوثائق المضمّنة لكل نوع. يُحدَّد نوع القرص في `type` ضمن تكوين القرص، وهو ما يحدّد أين وكيف يخزّن القرص بياناته (نظام الملفات المحلي، وتخزين الكائنات، وذاكرة تخزين مؤقت فوق قرص آخر، وما إلى ذلك).

لاحظ أن هذا الجدول يسرد *أنواع* الأقراص المتاحة، في حين يسرد [`system.disks`](/ar/operations/system-tables/disks) مثيلات الأقراص المهيّأة على الخادم.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ar/sql-reference/data-types/string)) — اسم نوع القرص، كما هو محدد في `type` ضمن تهيئة القرص.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف عام لما يفعله نوع القرص.
* `syntax` ([String](/ar/sql-reference/data-types/string)) — كيفية تحديد نوع القرص في تهيئة القرص.
* `examples` ([String](/ar/sql-reference/data-types/string)) — أمثلة استخدام.
* `introduced_in` ([String](/ar/sql-reference/data-types/string)) — إصدار ClickHouse الذي طُرح فيه نوع القرص لأول مرة، بالتنسيق major.minor.
* `related` ([Array](/ar/sql-reference/data-types/array)([String](/ar/sql-reference/data-types/string))) — أسماء أنواع الأقراص ذات الصلة.

{/*AUTOGENERATED_END*/ }

<div id="configuration-examples">
  ## أمثلة على التهيئة
</div>

يمكن تهيئة القرص بطريقتين: **ثابتًا** في ملفات تهيئة الخادم (XML أو YAML)، أو **ديناميكيًا** ضمن إعدادات استعلام `CREATE`/`ATTACH` باستخدام الدالة `disk`. ويُقبل في كلتا الحالتين نوع القرص نفسه والمعلمات نفسها.

<div id="static-configuration">
  ### التهيئة الثابتة
</div>

تُعرَّف الأقراص ضمن `storage_configuration` في تهيئة الخادم. يوضّح المثال التالي قرص `s3` وسياسة تخزين تستخدمه.

```xml title="config.xml"
<clickhouse>
    <storage_configuration>
        <disks>
            <s3_disk>
                <type>s3</type>
                <endpoint>https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/</endpoint>
                <use_environment_credentials>1</use_environment_credentials>
            </s3_disk>
        </disks>
        <policies>
            <s3_policy>
                <volumes>
                    <main>
                        <disk>s3_disk</disk>
                    </main>
                </volumes>
            </s3_policy>
        </policies>
    </storage_configuration>
</clickhouse>
```

التهيئة نفسها بصيغة YAML:

```yaml title="config.yaml"
storage_configuration:
  disks:
    s3_disk:
      type: s3
      endpoint: https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/
      use_environment_credentials: 1
  policies:
    s3_policy:
      volumes:
        main:
          disk: s3_disk
```

يمكن للجدول بعد ذلك استخدام القرص من خلال سياسة التخزين الخاصة به:

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS storage_policy = 's3_policy';
```

<div id="dynamic-configuration">
  ### التهيئة الديناميكية
</div>

يمكن أيضًا تعريف قرص مباشرةً ضمن إعدادات استعلام `CREATE`/`ATTACH`، من دون الحاجة إلى قرص معرّف مسبقًا في ملف تهيئة، باستخدام الدالة `disk`:

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS disk = disk(
    type = s3,
    endpoint = 'https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/',
    use_environment_credentials = 1
);
```

راجع [تهيئة التخزين الخارجي](/ar/operations/storing-data) للاطلاع على القائمة الكاملة للمعلمات لكل نوع من أنواع الأقراص.

<div id="example">
  ## مثال
</div>

```sql title="Query"
SELECT name, description
FROM system.disk_types
WHERE name IN ('local', 'object_storage')
ORDER BY name
```
