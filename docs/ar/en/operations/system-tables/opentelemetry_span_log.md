<div id="description">
  ## الوصف
</div>

يتضمن معلومات حول [مقاطع التتبع](https://opentracing.io/docs/overview/spans/) للاستعلامات المنفَّذة.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ar/sql-reference/data-types/lowcardinality)) — اسم المضيف الذي التُقط عليه هذا الـ مقطع التتبع.
* `trace_id` ([UUID](/ar/sql-reference/data-types/uuid)) — معرّف الـ trace للاستعلام المنفَّذ.
* `span_id` ([UInt64](/ar/sql-reference/data-types/int-uint)) — معرّف الـ trace مقطع التتبع.
* `parent_span_id` ([UInt64](/ar/sql-reference/data-types/int-uint)) — معرّف الـ trace مقطع التتبع الأصل.
* `operation_name` ([LowCardinality(String)](/ar/sql-reference/data-types/lowcardinality)) — اسم العملية.
* `kind` ([Enum8(&#39;INTERNAL&#39; = 0, &#39;SERVER&#39; = 1, &#39;CLIENT&#39; = 2, &#39;PRODUCER&#39; = 3, &#39;CONSUMER&#39; = 4)](/ar/sql-reference/data-types/enum)) — قيمة SpanKind الخاصة بالـ مقطع التتبع. INTERNAL — يشير إلى أن الـ مقطع التتبع يمثّل عملية داخلية داخل التطبيق. SERVER — يشير إلى أن الـ مقطع التتبع يغطي المعالجة من جهة الخادم لطلب RPC متزامن أو أي طلب بعيد آخر. CLIENT — يشير إلى أن الـ مقطع التتبع يصف طلبًا إلى خدمة بعيدة. PRODUCER — يشير إلى أن الـ مقطع التتبع يصف الجهات البادئة لطلب غير متزامن. وغالبًا ما ينتهي هذا الـ مقطع التتبع الأصل قبل الـ مقطع التتبع الابن CONSUMER المقابل، وربما حتى قبل أن يبدأ الـ مقطع التتبع الابن. CONSUMER - يشير إلى أن الـ مقطع التتبع يصف مقطع التتبع ابنًا لطلب PRODUCER غير متزامن.
* `start_time_us` ([UInt64](/ar/sql-reference/data-types/int-uint)) — وقت بدء الـ trace مقطع التتبع (بالميكروثانية).
* `finish_time_us` ([UInt64](/ar/sql-reference/data-types/int-uint)) — وقت انتهاء الـ trace مقطع التتبع (بالميكروثانية).
* `finish_date` ([Date](/ar/sql-reference/data-types/date)) — تاريخ انتهاء الـ trace مقطع التتبع.
* `status_code` ([Enum8(&#39;UNSET&#39; = 0, &#39;OK&#39; = 1, &#39;ERROR&#39; = 2)](/ar/sql-reference/data-types/enum)) — رمز الحالة الخاص بالـ مقطع التتبع.
* `status_message` ([LowCardinality(String)](/ar/sql-reference/data-types/lowcardinality)) — رسالة الخطأ.
* `attribute` ([Map(LowCardinality(String), String)](/ar/sql-reference/data-types/map)) — السمة المرتبطة بالـ trace مقطع التتبع. تُملأ وفقًا للتوصيات الواردة في معيار OpenTelemetry.

**الأسماء البديلة:**

* `attribute.names` — اسم بديل لـ `mapKeys(attribute)`.
* `attribute.values` — اسم بديل لـ `mapValues(attribute)`.

{/*AUTOGENERATED_END*/ }
