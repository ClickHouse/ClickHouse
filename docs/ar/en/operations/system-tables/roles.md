<div id="description">
  ## الوصف
</div>

يحتوي على معلومات عن [الأدوار](../../guides/sre/user-management/index.md#role-management) المهيأة.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([سلسلة](/ar/sql-reference/data-types/string)) — اسم الدور.
* `id` ([معرّف UUID](/ar/sql-reference/data-types/uuid)) — معرّف الدور.
* `storage` ([سلسلة](/ar/sql-reference/data-types/string)) — مسار تخزين الأدوار. يُضبط في المعلَمة `access_control_path`.

{/*AUTOGENERATED_END*/ }
