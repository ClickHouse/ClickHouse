<div id="description">
  ## الوصف
</div>

يحتوي هذا الجدول على مقاييس مُدرَّج تكراري يمكن احتسابها فورًا وتصديرها بصيغة Prometheus. ويظل محدَّثًا دائمًا. ويحل محل `system.latency_log` المهمل.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/ar/sql-reference/data-types/string)) — اسم المقياس.
* `value` ([Float64](/ar/sql-reference/data-types/float)) — قيمة المقياس.
* `description` ([String](/ar/sql-reference/data-types/string)) — وصف المقياس.
* `labels` ([Map(String, String)](/ar/sql-reference/data-types/map)) — وسوم المقياس.

**الأسماء البديلة:**

* `name` — اسم بديل لـ `metric`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

يمكنك استخدام استعلام مثل هذا لتصدير جميع مقاييس المُدرَّج التكراري بصيغة Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'histogram' AS type
FROM system.histogram_metrics
FORMAT Prometheus
```

| `keeper_dispatcher_requests_queue_time_milliseconds_bucket`  | الوقت الذي يقضيه الطلب في قائمة انتظار طلبات الموزّع في Keeper، بالمللي ثانية.                                                             |
| `keeper_write_pre_commit_time_milliseconds_bucket`           | الوقت اللازم للمعالجة التمهيدية لطلب كتابة قبل Raft commit، بالمللي ثانية.                                                                 |
| `keeper_write_commit_time_milliseconds_bucket`               | الوقت اللازم لمعالجة طلب كتابة بعد Raft commit، بالمللي ثانية.                                                                             |
| `keeper_dispatcher_responses_queue_time_milliseconds_bucket` | الوقت الذي تقضيه الاستجابة في قائمة انتظار استجابات الموزّع في Keeper، بالمللي ثانية.                                                      |
| `keeper_send_response_time_milliseconds_bucket`              | الوقت اللازم لإرسال استجابة إلى العميل في معالج TCP الخاص بـ Keeper (ويشمل الانتظار في قائمة الانتظار والكتابة إلى socket)، بالمللي ثانية. |
| `keeper_read_wait_for_write_time_milliseconds_bucket`        | الوقت الذي ينتظره طلب القراءة حتى يكتمل طلب الكتابة الذي يعتمد عليه، بالمللي ثانية.                                                        |

| `filesystem_cache_evicted_segment_size_bytes_bucket`         | توزيع أحجام أجزاء الملفات المطروحة من ذاكرة التخزين المؤقت بالبايت، موسوم باسم ذاكرة التخزين المؤقت.                                       |
| `filesystem_cache_evicted_segment_hits_by_user_bucket`       | توزيع عدد مرات الإصابة في أجزاء الملفات المطروحة من ذاكرة التخزين المؤقت، موسوم باسم ذاكرة التخزين المؤقت ومعرّف المستخدم.                 |
| `filesystem_cache_evicted_segment_size_bytes_by_user_bucket` | توزيع أحجام أجزاء الملفات المطروحة من ذاكرة التخزين المؤقت بالبايت، موسوم باسم ذاكرة التخزين المؤقت ومعرّف المستخدم.                       |
