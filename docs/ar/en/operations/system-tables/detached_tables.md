<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن كل جدول منفصل.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ar/sql-reference/data-types/string)) — اسم قاعدة البيانات التي يقع فيها الجدول.
* `table` ([String](/ar/sql-reference/data-types/string)) — اسم الجدول.
* `uuid` ([UUID](/ar/sql-reference/data-types/uuid)) — معرّف UUID للجدول (قاعدة بيانات Atomic).
* `metadata_path` ([String](/ar/sql-reference/data-types/string)) — مسار البيانات الوصفية للجدول في نظام الملفات.
* `is_permanently` ([UInt8](/ar/sql-reference/data-types/int-uint)) — فُصل الجدول بشكل دائم.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## مثال
</div>

```sql
SELECT * FROM system.detached_tables FORMAT Vertical;
```

```text
Row 1:
──────
database:                   base
table:                      t1
uuid:                       81b1c20a-b7c6-4116-a2ce-7583fb6b6736
metadata_path:              /var/lib/clickhouse/store/461/461cf698-fd0b-406d-8c01-5d8fd5748a91/t1.sql
is_permanently:             1
```
