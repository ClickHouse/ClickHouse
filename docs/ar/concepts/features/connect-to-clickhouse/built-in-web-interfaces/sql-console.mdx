وحدة تحكم SQL هي واجهة مستخدم ويب مُضمَّنة لتشغيل الاستعلامات واستكشاف البيانات، ويمكن الوصول إليها من أي منفذ HTTP في ClickHouse عبر المسار `/ui`، مثل `http://localhost:8123/ui`.

<Note>
  وحدة تحكم SQL ميزة تجريبية.
</Note>

## نظرة عامة {#overview}

وحدة تحكم SQL تطبيقٌ أحادي الصفحة (SPA) يُصرَّف في حزمة ثابتة ويُضمَّن مباشرةً في الملف التنفيذي لـ ClickHouse، على غرار تضمين ClickStack عند المسار `/clickstack`. وتُقدَّم جميع الموارد الثابتة من الملف التنفيذي لـ ClickHouse نفسه، دون تحميل أي شبكات CDN تابعة لجهة خارجية.

لفتحها، انتقل إلى `/ui` على أي منفذ HTTP لـ ClickHouse (مثلًا: `http://localhost:8123/ui`).

## كيفية تقديم المحتوى {#how-it-is-served}

تُضغط الحزمة باستخدام gzip أثناء عملية الإصدار وتُضمَّن باستخدام `#embed`، لذا تتضمن كل استجابة من `/ui` ترويسة `Content-Encoding: gzip`. وبما أن وحدة تحكم SQL تطبيق أحادي الصفحة يُجري التوجيه من جهة العميل، فيُقدَّم `index.html` كبديل استجابةً للطلبات ضمن `/ui` التي لا تقابل موردًا ثابتًا مُضمَّنًا ولا تبدو كملف (أي ليس لها امتداد). أما الطلبات إلى المسارات التي تبدو كموارد ثابتة مفقودة (مثل `/ui/nonexistent.js`)، فتُرجع رمز حالة HTTP بقيمة `404 Not Found`.

تتم مطابقة المسار `/ui` مطابقة تامة أو عندما يتبعه أحد الفواصل `/` أو `?` أو `#`، حتى لا تستحوذ الآلية الاحتياطية للتطبيق أحادي الصفحة على المسارات المجاورة مثل `/uix`.

## العلاقة بواجهات مستخدم الويب الأخرى {#relationship-to-other-web-uis}

يأتي ClickHouse مزوَّدًا بعدة واجهات ويب مدمجة تُقدَّم عبر منفذ HTTP:

* [`/play`](/ar/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql) — واجهة Web SQL الخفيفة.
* `/dashboard` — لوحات المعلومات المدمجة.
* `/clickstack` — واجهة مستخدم ClickStack المُضمَّنة.
* `/ui` — وحدة تحكم SQL الموضَّحة في هذه الصفحة.

تتوفر روابط إلى جميع هذه الواجهات في الصفحة الرئيسية لخادم HTTP الخاص بـ ClickHouse.

## المصادقة {#authentication}

تخضع وحدة تحكم SQL لعمليات التحقق من الهوية نفسها التي يخضع لها بروتوكول HTTP، بما في ذلك فحص `Session` والتحكم في الوصول. ولا يتطلب تقديم الموارد الثابتة لواجهة UI على المسار `/ui` أي مصادقة، أما الاستعلامات الصادرة عن واجهة UI فتخضع للمصادقة كأي طلب HTTP آخر.
