يتيح تنسيق استعلامات الإدخال.

المفاتيح:

* `--help` or`-h` — يعرض رسالة المساعدة.
* `--query` — ينسّق الاستعلامات مهما بلغ طولها أو تعقيدها.
* `--hilite` or `--highlight` — يضيف تمييزًا لبنية الجملة باستخدام تسلسلات الهروب ANSI الخاصة بالطرفية.
* `--oneline` — ينسّق الاستعلام في سطر واحد.
* `--max_line_length` — ينسّق الاستعلامات في سطر واحد إذا كان طولها أقل من القيمة المحددة.
* `--wrap_width` — يلفّ أسطر الاستعلامات متعددة الأسطر عند عرض العرض المحدد. يكون التغليف معطّلًا افتراضيًا (`0`). ولا تُغلَّف الاستعلامات المنسّقة في سطر واحد بواسطة `--oneline` أو `--max_line_length`.
* `--comments` — يُبقي التعليقات في المخرجات.
* `--quiet` or `-q` — يتحقق فقط من صحة البنية النحوية، من دون أي مخرجات عند النجاح.
* `--multiquery` or `-n` — يسمح بوجود عدة استعلامات في الملف نفسه.
* `--obfuscate` — يجري التمويه بدلًا من التنسيق.
* `--seed <string>` — سلسلة seed عشوائية تحدد نتيجة التمويه.
* `--backslash` — يضيف محرف شرطة مائلة عكسية في نهاية كل سطر من الاستعلام المنسّق. قد يكون ذلك مفيدًا عند نسخ استعلام من الويب أو من أي مكان آخر على عدة أسطر، ثم الرغبة في تنفيذه في سطر الأوامر.
* `--semicolons_inline` — في وضع multiquery، يكتب الفواصل المنقوطة في السطر الأخير من الاستعلام بدلًا من سطر جديد.

إذا لم يتسع العرض لاستدعاء دالة، أو لمصفوفة أو Tuple، أو لسلسلة `AND`/`OR`، أو لتعريف نافذة، أو لقائمة الأعمدة في `INSERT`، فإن عناصرها تبدأ في أسطر جديدة بإزاحة أعمق. أما وسيطات الدالة وعناصر المصفوفة التي تكون قيمًا بسيطة (أسماء الأعمدة والقيم الحرفية) فتُحزَّم بحيث يضم كل سطر عدة عناصر منها. ولا تتغير الاستعلامات التي تتسع أسطرها المنسّقة للعرض أصلًا. والعرض حد مرن: إذ يمكن أن تتجاوزه السلاسل النصية والمعرّفات وغيرها من الأجزاء غير القابلة للتجزئة. ويُؤخذ عرض محارف Unicode في الحسبان. ولا تُغلَّف التعليقات التي يُبقيها `--comments` ولا البيانات التي تلي `INSERT ... VALUES`.

## أمثلة {#examples}

1. تنسيق استعلام:

```bash title="Query"
$ clickhouse-format --query "select number from numbers(10) where number%2 order by number desc;"
```

```bash title="Response"
SELECT number
FROM numbers(10)
WHERE number % 2
ORDER BY number DESC
```

2. الإبراز والإخراج في سطر واحد:

```bash title="Query"
$ clickhouse-format --oneline --hilite <<< "SELECT sum(number) FROM numbers(5);"
```

```sql title="Response"
SELECT sum(number) FROM numbers(5)
```

3. الاستعلامات المتعددة:

```bash title="Query"
$ clickhouse-format -n <<< "SELECT min(number) FROM numbers(5); SELECT max(number) FROM numbers(5);"
```

```sql title="Response"
SELECT min(number)
FROM numbers(5)
;

SELECT max(number)
FROM numbers(5)
;

```

4. التمويه:

```bash title="Query"
$ clickhouse-format --seed Hello --obfuscate <<< "SELECT cost_first_screen BETWEEN a AND b, CASE WHEN x >= 123 THEN y ELSE NULL END;"
```

```sql title="Response"
SELECT treasury_mammoth_hazelnut BETWEEN nutmeg AND span, CASE WHEN chive >= 116 THEN switching ELSE ANYTHING END;
```

الاستعلام نفسه وسلسلة seed أخرى:

```bash title="Query"
$ clickhouse-format --seed World --obfuscate <<< "SELECT cost_first_screen BETWEEN a AND b, CASE WHEN x >= 123 THEN y ELSE NULL END;"
```

```sql title="Response"
SELECT horse_tape_summer BETWEEN folklore AND moccasins, CASE WHEN intestine >= 116 THEN nonconformist ELSE FORESTRY END;
```

5. إضافة الشرطة المائلة العكسية:

```bash title="Query"
$ clickhouse-format --backslash <<< "SELECT * FROM (SELECT 1 AS x UNION ALL SELECT 1 UNION DISTINCT SELECT 3);"
```

```sql title="Response"
SELECT * \
FROM  \
( \
    SELECT 1 AS x \
    UNION ALL \
    SELECT 1 \
    UNION DISTINCT \
    SELECT 3 \
)
```

6. تغليف التعبيرات الطويلة:

```bash title="Query"
$ clickhouse-format --wrap_width 40 --query "SELECT concat(first_name, ' ', middle_name, ' ', last_name) FROM people"
```

```sql title="Response"
SELECT
    concat(
        first_name, ' ', middle_name,
        ' ', last_name
    )
FROM people
```
