تتيح لك ميزة الوكلاء الاستعلام عن بيانات ClickHouse واستكشافها عبر المحادثة، دون الحاجة إلى كتابة SQL أو منطق التنسيق بنفسك.
يفهم الوكيل ما تقصده، ويضع خطة بالخطوات اللازمة، ويستدعي الأدوات التي هيّأتها، ثم يعرض عليك النتائج.
هذه الميزة حاليًا في مرحلة تجريبية، وقد يتغير سلوكها وإمكاناتها قبل طرحها للتوافر العام.

## ما الذي يمكنك فعله به {#what-you-can-do}

باستخدام الوكلاء، يمكنك:

* إنشاء وكلاء مخصصين دون كتابة أي شيفرة، إذ يمكنك كتابة التعليمات واختيار نموذج وإرفاق الأدوات.
* إجراء محادثات على خدمة ClickHouse الخاصة بك، إذ يستدعي الوكيل الأدوات كلما احتاج إليها.
* مشاركة وكلائك مع زملائك في الفريق أو نشرها في السوق.
