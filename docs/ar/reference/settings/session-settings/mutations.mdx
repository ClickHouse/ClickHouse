هذه الإعدادات متاحة في [system.settings](/ar/reference/system-tables/settings)، وتُولَّد تلقائيًا من [الشفرة المصدرية](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/Settings.cpp).

## mutations_max_literal_size_to_replace {#mutations_max_literal_size_to_replace}

<SettingsInfoBlock type="UInt64" default_value="16384" />

الحد الأقصى لحجم القيمة الحرفية المُسلسلة، بالبايت، التي سيجري استبدالها في استعلامات `UPDATE` و`DELETE`. لا يسري هذا إلا إذا كان واحد على الأقل من الإعدادين المذكورين أعلاه مُمكّنًا. القيمة الافتراضية: 16384 ‏(16 KiB).

## mutations_sync {#mutations_sync}

<SettingsInfoBlock type="UInt64" default_value="0" />

يتحكم في كيفية انتظار العميل لعمليات التعديل التي تُنشئها عمليات [`ALTER TABLE`](/ar/reference/statements/alter/index) مثل `UPDATE` و`DELETE` و`MATERIALIZE INDEX` و`MATERIALIZE PROJECTION` و`MATERIALIZE COLUMN` و`MATERIALIZE STATISTICS`.

القيم الممكنة:

| Value | Description                                                                                                |
| ----- | ---------------------------------------------------------------------------------------------------------- |
| `0`   | تُنفَّذ عمليات `التعديل` بشكل غير متزامن.                                                                 |
| `1`   | ينتظر الاستعلام حتى تكتمل جميع عمليات `التعديل` على الخادم الحالي.                                        |
| `2`   | ينتظر الاستعلام حتى تكتمل جميع عمليات `التعديل` على جميع النسخ المتماثلة (إن وُجدت).                      |
| `3`   | ينتظر الاستعلام النسخ المتماثلة النشطة فقط. أما النسخ غير النشطة فتطبّق عمليات `التعديل` عندما تصبح نشطة. |
