## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "إعداد Cloud جديد"}]}]} />

يكون له تأثير فقط في ClickHouse Cloud. الحد الأقصى لحجم المخزن المؤقت المُستخدَم للكتابة إلى خوادم distributed cache، لكل مخزن مؤقت للكتابة. وهو مستقل عن المخزن المؤقت الذي يُكتب إلى تخزين الكائنات؛ إذ يستمر الأخير في النمو حتى يبلغ حجم جزء بيانات التحميل. إذا كانت القيمة 0، يُستخدم `DBMS_DEFAULT_BUFFER_SIZE` ‏(1 MiB). يبدأ المخزن المؤقت عند `adaptive_write_buffer_initial_size` ولا ينمو إلى هذا الحجم إلا أثناء كتابة الدفق، كي لا يخصص جزء بيانات هذا الحجم لكل دفق يكتب إليه.
