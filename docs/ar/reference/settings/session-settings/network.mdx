## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "تم تغيير طريقة الضغط الافتراضية لاتصالات client\/server وserver\/server من `LZ4` إلى `ZSTD` لتقليل حركة مرور الشبكة."}]}]} />

ترميز الضغط المستخدم لاتصالات client/server وserver/server عبر native protocol، ولاستجابة HTTP request المُنفَّذ باستخدام `compress=1`، والذي يستخدم صيغة الـ frame نفسها، وللتبادل التدفقي بين مهام distributed query plan (`make_distributed_plan`). تستخدم عمليات التبادل عبر temporary files ترميز الـ server الافتراضي.

القيم الممكنة:

* `NONE` — بدون ضغط.
* `LZ4` — استخدام ترميز `LZ4`.
* `LZ4HC` — استخدام ترميز `LZ4HC`.
* `ZSTD` — استخدام ترميز `ZSTD`.

## network_zstd_compression_level {#network_zstd_compression_level}

<SettingsInfoBlock type="Int64" default_value="3" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "3"},{"label": "تمت مواءمة مستوى ضغط `ZSTD` الافتراضي للشبكة مع الضغط الافتراضي الجديد `ZSTD(3)` على القرص."}]}]} />

يحدّد مستوى ضغط ZSTD. لا يُستخدم إلا عندما تكون قيمة [network&#95;compression&#95;method](/ar/reference/settings/session-settings/network#network_compression_method) هي `ZSTD`.

القيم الممكنة:

* عدد صحيح موجب من 1 إلى 15.
