<div id="database">
  ## قاعدة البيانات
</div>

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": ""},{"label": "إعداد جديد يحدد قاعدة البيانات الحالية للاستعلام. يحل محل المعالجة الخاصة لمعامل URL ‏`database` في واجهة HTTP وترويسة `X-ClickHouse-Database`."}]}]} />

يحدد قاعدة البيانات الحالية للاستعلام، وهي قاعدة البيانات التي تُفسَّر ضمنها أسماء الجداول غير المؤهلة، وبالأثر نفسه للأمر `USE <database>`. بخلاف عبارة `USE`، يُعد هذا إعداد جلسة عاديًا: فمثل أي إعداد آخر، يقبل قيمة دون التحقق من صحتها، ويُبلَّغ عن قاعدة بيانات غير معروفة عند تطبيق الإعداد (عند تنفيذ استعلام)، لا عند تنفيذ `SET`. ويتبع نموذج الامتيازات الخاص بقاعدة البيانات الافتراضية التي يحددها العميل (والذي يعممه)، لا نموذج `USE`: إذ لا يتطلب اختيار قاعدة البيانات الحالية امتياز `SHOW_DATABASES`، بينما يُتحقق من صلاحية الوصول إلى الجداول الموجودة فيها كالمعتاد. يُستخدم كوجهة لمعامل URL ‏`database` في واجهة HTTP وترويسة `X-ClickHouse-Database`.

<div id="database_atomic_wait_for_drop_and_detach_synchronously">
  ## database_atomic_wait_for_drop_and_detach_synchronously
</div>

<SettingsInfoBlock type="Bool" default_value="0" />

يضيف المُعدِّل `SYNC` إلى جميع استعلامات `DROP` و`DETACH`.

القيم الممكنة:

* 0 — ستُنفَّذ الاستعلامات بتأخير.
* 1 — ستُنفَّذ الاستعلامات دون تأخير.
