يحدد تنفيذ فحص مسار الكتابة لـ UNIQUE KEY. لا يتوفر حاليًا سوى تنفيذ أساسي أحادي الخيط،
لذا يشير كلٌّ من `auto` و`simple` إليه.

محجوز: لا تأثير لهذا الإعداد بعد، إذ لا تُقرأ قيمته حتى يتم ربط مسار كتابة UNIQUE KEY INSERT
الذي ينشئ الفحص. أُعلن عنه الآن لكي يتوفر الخيار مع التنفيذ.
