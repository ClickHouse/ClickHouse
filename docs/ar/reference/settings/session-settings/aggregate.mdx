## aggregate_function_input_format {#aggregate_function_input_format}

<SettingsInfoBlock type="AggregateFunctionInputFormat" default_value="state" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.12"},{"label": "state"},{"label": "إعداد جديد للتحكم في صيغة إدخال AggregateFunction أثناء عمليات INSERT. تُضبط قيمة الإعداد على state افتراضيًا"}]}]} />

كيفية قراءة صيغ الإدخال للأعمدة من النوع `AggregateFunction`.

القيم الممكنة:

* `state` — الحالة المُسلسَلة للدالة التجميعية، بالشكل الذي تكتبها به تنسيقات الإخراج (القيمة الافتراضية).
* `value` — قيمة وسيطة الدالة التجميعية، أو tuple من الوسائط إن كانت متعددة. تُجمَّع القيمة لتكوين الحالة.
* `array` — مصفوفة من القيم، كما هو موضّح في الخيار `value` أعلاه. تُجمَّع جميع عناصر المصفوفة لتكوين الحالة.

في وضعَي `value` و`array` تقرأ الصيغة العمود كما لو كان من نوع القيم نفسها: `T` في حالة `AggregateFunction(f, T)`، و`Tuple(T1, T2)` في حالة `AggregateFunction(f, T1, T2)`، أو `Array` منه في وضع `array`. وتُكتب القيم بالتمثيل الذي تستخدمه الصيغة لذلك النوع: رقم أو سلسلة نصية في الصيغ النصية، ومصفوفة JSON في صيغ JSON، والترميز الثنائي للنوع في `RowBinary` أو `Native`، وعمود من ذلك النوع في `Parquet`، وهكذا. وينطبق هذا على كل صيغة إدخال، وكذلك على `AggregateFunction` المتداخل داخل `Array` أو `Tuple` أو `Map`.

**Examples**

لجدول ببنية:

```sql
CREATE TABLE example (
    user_id UInt64,
    avg_session_length AggregateFunction(avg, UInt32)
);
```

مع `aggregate_function_input_format = 'value'`:

```sql
INSERT INTO example FORMAT CSV
123,456
```

```sql
INSERT INTO example FORMAT JSONEachRow
{"user_id": 123, "avg_session_length": 456}
```

مع `aggregate_function_input_format = 'array'`:

```sql
INSERT INTO example FORMAT CSV
123,"[456,789,101]"
```

```sql
INSERT INTO example FORMAT JSONEachRow
{"user_id": 123, "avg_session_length": [456, 789, 101]}
```

ملاحظة: صيغتا `value` و`array` أبطأ من الصيغة الافتراضية `state`، لأنهما تتطلبان إنشاء القيم وتجميعها أثناء الإدراج.

## aggregate_functions_null_for_empty {#aggregate_functions_null_for_empty}

<SettingsInfoBlock type="Bool" default_value="0" />

يُمكّن أو يعطّل إعادة كتابة جميع الدوال التجميعية في الاستعلام عبر إضافة اللاحقة [-OrNull](/ar/reference/functions/aggregate-functions/combinators#-ornull) إليها. فعِّله لتحقيق التوافق مع معيار SQL.
ويُنفَّذ ذلك من خلال إعادة كتابة الاستعلام (على غرار الإعداد [count&#95;distinct&#95;implementation](/ar/reference/settings/session-settings/count-distinct#count_distinct_implementation)) للحصول على نتائج متسقة في الاستعلامات الموزعة.

القيم الممكنة:

* 0 — معطّل.
* 1 — مفعّل.

**مثال**

انظر إلى الاستعلام التالي الذي يتضمن دوال تجميعية:

```sql
SELECT SUM(-1), MAX(0) FROM system.one WHERE 0;
```

عند ضبط `aggregate_functions_null_for_empty = 0`، سينتج:

```text
┌─SUM(-1)─┬─MAX(0)─┐
│       0 │      0 │
└─────────┴────────┘
```

مع `aggregate_functions_null_for_empty = 1` ستكون النتيجة كما يلي:

```text
┌─SUMOrNull(-1)─┬─MAXOrNull(0)─┐
│          NULL │         NULL │
└───────────────┴──────────────┘
```
