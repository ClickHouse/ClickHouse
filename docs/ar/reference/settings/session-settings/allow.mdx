  ## allow_creating_set_partitions_independently
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "إعداد جديد لتمكين إزالة التكرار المسبقة والمتوازية لكل partition من نتيجة الاستعلام الفرعي عند بناء المجموعة لـ `IN (subquery)`، عندما يكون تعبير partition دالة حتمية لأعمدة إخراج الاستعلام الفرعي."}]}]} />

يتيح إزالة التكرار المسبقة والمتوازية لكل partition من نتيجة الاستعلام الفرعي عند بناء المجموعة لـ `IN (subquery)`، عندما يكون تعبير partition في جدول `MergeTree` الخاص بالاستعلام الفرعي دالة حتمية لأعمدة إخراج الاستعلام الفرعي. يُقرأ كل partition عبر تدفق منفصل وتُزال تكراراته بشكل مستقل، لذلك لا يحسب تحويل ملء المجموعة الوحيد التجزئة إلا للصفوف الفريدة. لا يُطبَّق مع `FINAL` أو النسخ المتماثلة المتوازية أو `GLOBAL IN`. لا يطلب التحسين القراءة لكل partition إلا عندما تحتوي البيانات على أكثر من partition واحد، ولا يتجاوز عدد صفوف أكبر partition ضعف عدد صفوف partition المتوسط (راجع [force&#95;creating&#95;set&#95;partitions&#95;independently](/ar/reference/settings/session-settings/force#force_creating_set_partitions_independently) لتجاوز فحص عدم التوازن). وعندما تكون التدفقات منفصلة بحسب partition أصلًا لأن ميزة أخرى لكل partition قد فصلتها (مثل `LIMIT BY` لكل partition)، تُطبَّق إزالة التكرار المسبقة بغض النظر عن ذلك، لأن تخطيط القراءة محدد مسبقًا. أثناء بناء المجموعة، تحتفظ جداول إزالة التكرار الخاصة بكل تدفق مجتمعةً بنسخة إضافية واحدة تقريبًا من المفاتيح الفريدة.

  ## allow_distinct_partitions_independently
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "إعداد جديد يتيح تقييم `DISTINCT` بشكل مستقل لكل partition عندما يكون تعبير partition دالة حتمية لأعمدة `DISTINCT`."}]}]} />

فعّل التقييم المستقل لـ `DISTINCT` لكل partition على خيوط تنفيذ منفصلة عندما يكون تعبير partition دالة حتمية لأعمدة `DISTINCT`، مع تجاوز الدمج بين التدفقات. يفيد ذلك عندما يكون عدد partitionات قريبًا من عدد الأنوية وتكون partitionات متقاربة الحجم؛ وإلا، تتجاوزه آلية استدلالية للتكلفة. راجع [max&#95;number&#95;of&#95;partitions&#95;for&#95;independent&#95;distinct](/ar/reference/settings/session-settings/max-number#max_number_of_partitions_for_independent_distinct) و[force&#95;distinct&#95;partitions&#95;independently](/ar/reference/settings/session-settings/force#force_distinct_partitions_independently). لا يُطبَّق مع `FINAL` أو النسخ المتماثلة المتوازية.

  ## allow_key_condition_coalesce_rewrite
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.5"},{"label": "1"},{"label": "إعداد جديد لإعادة كتابة الشروط من الشكل `coalesce(a_1, ..., a_N) <op> const` (وكذلك `ifNull` بصورة مكافئة، أو عندما يكون الثابت على اليسار) إلى فصل منطقي قبل تحليل الفهارس، بحيث يمكن استخدام المفتاح الأساسي وفهارس التخطي الخاصة بكل عمود على كل `a_i`. كما تُعالَج أيضًا الأشكال ذات الثوابت الجزئية مثل `coalesce(a, 42, b)` و`coalesce(a, b, 42)`."}]}]} />

أعِد كتابة الشروط من الشكل `coalesce(a_1, ..., a_N) <op> const` (وكذلك `ifNull` بصورة مكافئة، أو عندما يكون الثابت على اليسار) إلى الفصل المنطقي `(a_1 <op> const) OR (a_1 IS NULL AND a_2 <op> const) OR ... OR (a_1 IS NULL AND ... AND a_{N-1} IS NULL AND a_N <op> const)` قبل تحليل الفهارس، بحيث يمكن استخدام المفتاح الأساسي وفهارس التخطي الخاصة بكل عمود على كل `a_i`. تُعالَج الأشكال ذات الثوابت الجزئية مثل `coalesce(a, 42, b)` و`coalesce(a, b, 42)`: إذ تُطبَّع قائمة الوسائط كما يفعل `coalesce` نفسه (تُحذف القيم الحرفية `NULL`، وتُحذف الوسائط التي تلي أول وسيطة غير `Nullable`)، ويُضاف الثابت غير `NULL` الختامي، إن وُجد، باعتباره الفرع الأخير. تُستخدم إعادة الكتابة فقط كإضافة لتحسين استبعاد البيانات عبر الفهارس؛ ويستمر الترشيح وقت التشغيل في استخدام الشرط الأصلي.
بالإضافة إلى ذلك، يُعاد كتابة شروط المساواة الدقيقة من الشكل `nullIf(key, sentinel) = const` (حيث `sentinel != const` وتتطابق الأنواع تمامًا) إلى `key = const`، بحيث يتمكن المفتاح الأساسي وpartition وفهارس التخطي على `key` من استبعاد الحبيبات مباشرةً. لا يُدعم استبعاد البيانات عبر `nullIf` للنطاقات أو الشروط الفصلية.
