## prewarm_mark_cache {#prewarm_mark_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

إذا كانت القيمة true، فستُهيَّأ
التخزين المؤقت للعلامات مسبقًا بحفظ العلامات فيها أثناء عمليات insert وmerge وfetch، وعند
بدء تشغيل server

## prewarm_primary_key_cache {#prewarm_primary_key_cache}

وعمليات الجلب، وعند بدء تشغيل الخادم

## prewarm_statistics_cache {#prewarm_statistics_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "إعداد جديد للتهيئة المسبقة لذاكرة التخزين المؤقت للإحصاءات بإحصاءات الأعمدة الخاصة بأجزاء البيانات الجديدة وعند بدء التشغيل. أصبحت ذاكرة التخزين المؤقت للإحصاءات الآن مخصصة لكل جزء بيانات وكل عمود بدلًا من لقطة للجدول بأكمله؛ وأصبح الإعدادان `refresh_statistics_interval` و`use_statistics_cache` متقادمين."}]}]} />

عند تعيين القيمة true، تكون ذاكرة التخزين المؤقت للإحصاءات
مهيأة مسبقًا عبر تحميل إحصاءات الأعمدة لأجزاء البيانات عند الإدراج
والدمج وعمليات الجلب، وعند بدء تشغيل الخادم. أما عند تعطيله، فتُحمَّل إحصاءات جزء البيانات
إلى ذاكرة التخزين المؤقت عند أول استعلام يحتاج إليها.
