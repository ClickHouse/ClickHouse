<div id="bitmapAnd">
  ## bitmapAnd
</div>

قُدِّم في: v20.1.0

يحسب الاقتران المنطقي (AND) لخريطتَي bitmap.

**الصيغة**

```sql
bitmapAnd(bitmap1, bitmap2)
```

**الوسائط**

* `bitmap1` — كائن الـ bitmap الأول. [`AggregateFunction(groupBitmap, T)`](/ar/reference/data-types/aggregatefunction). - `bitmap2` — كائن الـ bitmap الثاني. [`AggregateFunction(groupBitmap, T)`](/ar/reference/data-types/aggregatefunction).

**القيمة المُعادة**

يعيد bitmap يحتوي على البتات الموجودة في كلٍّ من وحدتَي bitmap المُدخلتَين [`AggregateFunction(groupBitmap, T)`](/ar/reference/data-types/aggregatefunction)

**أمثلة**

**مثال على الاستخدام**

```sql title=Query
SELECT bitmapToArray(bitmapAnd(bitmapBuild([1, 2, 3]), bitmapBuild([3, 4, 5]))) AS res;
```

```response title=Response
┌─res─┐
│ [3] │
└─────┘
```

<div id="bitmapBuild">
  ## bitmapBuild
</div>

أُضيفت في: v20.1.0

تُنشئ bitmap من مصفوفة من الأعداد الصحيحة. أنواع العناصر المدعومة هي الأعداد الصحيحة الموقَّعة وغير الموقَّعة ذات 8 أو 16 أو 32 أو 64 بت. وهي عكس الدالة [`bitmapToArray`](/ar/reference/functions/regular-functions/bitmap-functions#bitmapToArray).

**الصيغة**

```sql
bitmapBuild(array)
```

**الوسيطات**

* `array` — مصفوفة من الأعداد الصحيحة. [`Array((U)Int*)`](/ar/reference/data-types/array)

**القيمة المُعادة**

يعيد bitmap من المصفوفة المُدخلة [`AggregateFunction(groupBitmap, T)`](/ar/reference/data-types/aggregatefunction)

**أمثلة**

**مثال على الاستخدام**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([1, 2, 3, 4, 5])) AS res, toTypeName(bitmapBuild([1, 2, 3, 4, 5])) AS type;
```

```response title=Response
┌─res────────────┬─type──────────────────────────────────┐
│ 00050102030405 │ AggregateFunction(groupBitmap, UInt8) │
└────────────────┴───────────────────────────────────────┘
```

**bitmap موقَّعة**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([-128, -1]::Array(Int8))) AS res, toTypeName(bitmapBuild([-128, -1]::Array(Int8))) AS type;
```

```response title=Response
┌─res──────┬─type─────────────────────────────────┐
│ 000280FF │ AggregateFunction(groupBitmap, Int8) │
└──────────┴──────────────────────────────────────┘
```

<div id="bitmapContains">

```response title=Response
└─────┘
```

<div id="bitmapTransform">
  ## bitmapTransform
</div>

أُضيف في: v20.1.0

يستبدل العناصر في bitmap وفقًا لتعيين من `from_array` إلى `to_array`.
تُفسَّر القيم كأعداد صحيحة غير موقعة من نوع عنصر bitmap (ضمن نفس المجال مثل [`bitmapContains`](/ar/reference/functions/regular-functions/bitmap-functions#bitmapContains)).
بالنسبة إلى bitmaps الموقعة، يطابق العنصر السالب نظيره غير الموقّع (على سبيل المثال، تطابق قيمة `Int8`‏ `-1` القيمة `255`).
تؤدي القيمة في `to_array` التي لا تلائم نوع عنصر bitmap إلى ظهور الخطأ `BAD_ARGUMENTS`. أما القيمة في `from_array`
التي لا تلائم النوع فلا يُعثر عليها ببساطة، لذا لا يُطبَّق الاستبدال المقابل.

**الصيغة**

```sql
bitmapTransform(bitmap, from_array, to_array)
```

**الوسيطات**

* `bitmap` — كائن bitmap. [`AggregateFunction(groupBitmap, T)`](/ar/reference/data-types/aggregatefunction). - `from_array` — مصفوفة من البتات المضبوطة الأصلية المطلوب استبدالها. <div id="subBitmap">
  ## subBitmap
</div>

يعيد مجموعة فرعية من bitmap بعد تخطي `offset` عنصرًا، بترتيب تصاعدي للقيم غير الموقعة. الحد الأقصى لعدد العناصر في bitmap المُعادة هو `cardinality_limit`.

```sql
subBitmap(bitmap, offset, cardinality_limit)
```

**الوسيطات**

[`UInt32`](/ar/reference/data-types/int-uint) - `cardinality_limit` — الحد الأقصى لعدد البتات المضبوطة التي يمكن تضمينها في المجموعة الفرعية. [`UInt32`](/ar/reference/data-types/int-uint)

**القيمة المُعادة**

يعيد bitmap يحتوي على عدد لا يتجاوز `cardinality_limit` من العناصر بعد تخطي `offset` من العناصر بترتيب تصاعدي للقيم غير الموقعة [`AggregateFunction(groupBitmap, T)`](/ar/reference/data-types/aggregatefunction)

**أمثلة**

**مثال على الاستخدام**

```sql title=Query
SELECT bitmapToArray(subBitmap(bitmapBuild([1, 2, 3, 4, 5]), 2, 2)) AS res;
```

```response title=Response
┌─res───┐
│ [3,4] │
└───────┘
```
