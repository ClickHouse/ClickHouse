`timeSeriesMetricFamilies(db_name.time_series_table)` - يُعيد جدول [عائلات المقاييس](/ar/reference/engines/table-engines/integrations/time-series#metric-families-table)
الذي يستخدمه الجدول `db_name.time_series_table` الذي يكون محرك جدوله هو محرك [TimeSeries](/ar/reference/engines/table-engines/integrations/time-series):

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES metric_families_table
```

تعمل الدالة أيضًا إذا كان جدول *عائلات المقاييس* هو الجدول الداخلي (inner):

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

الاستعلامات التالية متكافئة:

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  للدالة `timeSeriesMetricFamilies` اسم بديل هو `timeSeriesMetrics`، وقد تم الإبقاء عليه للتوافق مع الإصدارات السابقة.
</Note>
