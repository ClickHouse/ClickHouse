يمثل قاموس فهرس نصي في جداول MergeTree.
يعيد الرموز مع البيانات الوصفية لقوائم الترحيل الخاصة بها.
ويمكن استخدامه للفحص الداخلي.

## الصيغة {#syntax}

```sql
mergeTreeTextIndex(database, table, index_name)
```

## الوسيطات {#arguments}

| الوسيطة      | الوصف                                             |
| ------------ | ------------------------------------------------- |
| `database`   | اسم قاعدة البيانات التي سيُقرأ منها الفهرس النصي. |
| `table`      | اسم الجدول الذي سيُقرأ منه الفهرس النصي.          |
| `index_name` | الفهرس النصي الذي ستتم القراءة منه.               |

## القيمة المعادة {#returned-value}

كائن من نوع جدول يحتوي على الرموز والبيانات الوصفية لقوائم الترحيل الخاصة بها.

إذا كان الفهرس يستخدم مُقسِّم الرموز `keyValuePairs`، فإن كل رمز يكون زوجًا `(key, value)` من عمود من نوع `Map`، ويتضمن الناتج عمودين إضافيين هما `token_key` و`token_value` يحتويان على جزأي الرمز بعد فك ترميزهما.

تُعاد قوائم الترحيلات الخاصة بالرموز في الأعمدة الافتراضية التالية. لا تُعاد هذه الأعمدة عند استخدام `SELECT *`، بل يجب تحديدها صراحةً.

| العمود      | النوع           | الوصف                                                                                            |
| ----------- | --------------- | ------------------------------------------------------------------------------------------------ |
| `row_id`    | `UInt32`        | رقم الصف في جزء البيانات (راجع `_part_offset`) ضمن قائمة الترحيلات الخاصة بالرمز.                |
| `positions` | `Array(UInt32)` | مواضع الرمز في الصف. لا يتوفر إلا إذا كان الفهرس مُعرَّفًا بالوسيطة `support_phrase_search = 1`. |

إذا جرى تحديد أيٍّ من هذه الأعمدة، فسيتضمن الناتج صفًا مقابل كل صف في قائمة الترحيلات لكل رمز، على غرار تطبيق `ARRAY JOIN` على قائمة الترحيلات، إذ تتكرر الأعمدة الأخرى للرمز في كل صف منها.

تُعاد قوائم الترحيلات كما هي مخزَّنة في فهرس جزء البيانات، ولذلك فهي تتضمن الصفوف المحذوفة بواسطة `DELETE` الخفيف (راجع `_row_exists`) إلى أن يُدمَج الجزء.

## مثال للاستخدام {#usage-example}

```sql title="Query"
CREATE TABLE tab
(
    id UInt64,
    s String,
    INDEX idx_s (s) TYPE text(tokenizer = splitByNonAlpha)
)
ENGINE = MergeTree
ORDER BY id;

INSERT INTO tab SELECT number, concatWithSeparator(' ', 'apple', 'banana') FROM numbers(500);
INSERT INTO tab SELECT 500 + number, concatWithSeparator(' ', 'cherry', 'date') FROM numbers(500);

SELECT * FROM mergeTreeTextIndex(currentDatabase(), tab, idx_s);
```

## مثال على الاستخدام: قوائم الترحيلات {#usage-example-posting-lists}

```sql title="Query"
CREATE TABLE tab
(
    id UInt64,
    s String,
    INDEX idx_s (s) TYPE text(tokenizer = splitByNonAlpha, support_phrase_search = 1)
)
ENGINE = MergeTree
ORDER BY id
SETTINGS allow_experimental_text_index_phrase_search = 1;

INSERT INTO tab VALUES (0, 'apple banana apple'), (1, 'banana cherry'), (2, 'cherry apple');

SELECT token, row_id, positions FROM mergeTreeTextIndex(currentDatabase(), tab, idx_s) ORDER BY token, row_id;
```

```text title="Response"
   ┌─token──┬─row_id─┬─positions─┐
1. │ apple  │      0 │ [0,2]     │
2. │ apple  │      2 │ [1]       │
3. │ banana │      0 │ [1]       │
4. │ banana │      1 │ [0]       │
5. │ cherry │      1 │ [1]       │
6. │ cherry │      2 │ [0]       │
   └────────┴────────┴───────────┘
```
