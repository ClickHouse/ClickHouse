`timeSeriesTimeRanges(db_name.time_series_table)` - يُعيد جدول [النطاقات الزمنية](/ar/reference/engines/table-engines/integrations/time-series#time-ranges-table)
الذي يستخدمه الجدول `db_name.time_series_table`، والذي يعتمد على محرك الجدول [TimeSeries](/ar/reference/engines/table-engines/integrations/time-series)، على سبيل المثال:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

الاستعلامات التالية متكافئة:

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  لا يوجد جدول *النطاقات الزمنية* إلا إذا كان الإعداد `store_time_ranges` مفعّلًا.
  أما الجداول ذات [الإصدار](/ar/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 أو ما قبله، فتحتفظ بالعمودين `min_time` و`max_time`
  في جدول [الوسوم](/ar/reference/engines/table-engines/integrations/time-series#tags-table).
</Note>
