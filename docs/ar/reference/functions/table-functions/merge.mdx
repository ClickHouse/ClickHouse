ينشئ [Merge](/ar/reference/engines/table-engines/special/merge) جدولًا مؤقتًا.
يُشتق مخطط الجدول من الجداول الأساسية باستخدام اتحاد أعمدتها واستنتاج الأنواع المشتركة.
تتوفّر الأعمدة الظاهرية نفسها كما في محرك الجدول [Merge](/ar/reference/engines/table-engines/special/merge).

## البنية {#syntax}

```sql
merge(['db_name',] 'tables_regexp')
```

## الوسيطات {#arguments}

| الوسيط          | الوصف                                                                                                                                                                                                                                                                                                      |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | القيم الممكنة (اختياري، والقيمة الافتراضية هي `currentDatabase()`):<br />    - اسم قاعدة البيانات،<br />    - تعبير ثابت يُرجع سلسلة نصية تتضمن اسم قاعدة بيانات، على سبيل المثال `currentDatabase()`،<br />    - `REGEXP(expression)`، حيث تكون `expression` تعبيرًا نمطيًا لمطابقة أسماء قواعد البيانات. |
| `tables_regexp` | تعبير نمطي لمطابقة أسماء الجداول في قاعدة البيانات أو قواعد البيانات المحددة.                                                                                                                                                                                                                              |

## صلاحيات الوصول {#access-rights}

تُقرأ الجداول المطابقة وفق قواعد الوصول نفسها المطبّقة على محرك الجدول [Merge](/ar/reference/engines/table-engines/special/merge#access-rights). إذ لا تُقرأ البيانات إلا من الجداول المطابقة التي يستطيع المستخدم الحالي رؤيتها، أي تلك التي يمتلك عليها امتياز [`SHOW TABLES`](/ar/reference/statements/grant#show)، ومنها وحدها يُستخلص مخطط الجدول. أما الجدول المطابق الذي لا يستطيع المستخدم رؤيته فيُتجاهَل دون إصدار error. ويتطلب استخلاص المخطط امتياز [`SHOW COLUMNS`](/ar/reference/statements/grant#show) على الجداول التي يُستخلص منها. كما تتطلب قراءة أي جدول مطابق يستطيع المستخدم رؤيته امتياز [`SELECT`](/ar/reference/statements/grant#select) على الأعمدة التي يقرؤها الاستعلام، وإلا فشل الاستعلام مع الخطأ `ACCESS_DENIED`.
