## sum {#sum}

ظهر لأول مرة في: v1.1.0

يحسب مجموع القيم العددية أو الفواصل الزمنية.

**الصيغة**

```sql
sum(num)
```

**الوسائط**

* `num` — عمود من القيم العددية أو من الفواصل الزمنية. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`Interval`](/ar/reference/data-types/special-data-types/interval)

**القيمة المُعادة**

يعيد مجموع القيم. إذا كانت الوسيطة من النوع `Interval`، فإن النتيجة تكون فاصلًا زمنيًا بالوحدة نفسها، ويُنتج الإدخال الفارغ فاصلًا زمنيًا طوله صفر. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`Interval`](/ar/reference/data-types/special-data-types/interval)

**أمثلة**

**حساب مجموع رواتب الموظفين**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**إجمالي الوقت المستغرق في معالجة الطلبات**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
