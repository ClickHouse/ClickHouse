<div id="gini">
  ## gini
</div>

أُضيف في: v26.8.0

تحسب [معامل جيني](https://en.wikipedia.org/wiki/Gini_coefficient) لعمود من القيم العددية المنتهية وغير السالبة، وهو مقياس لعدم المساواة في التوزيع.

تتراوح النتيجة من `0` (مساواة تامة: جميع القيم متساوية) إلى حد أقصى يقترب من `1` مع ازدياد `n` (عدم مساواة تامة: قيمة واحدة تستحوذ على كل شيء والبقية أصفار). بالنسبة إلى عينة منتهية تتكون من `n` قيم، يكون الحد الأقصى هو `(n - 1) / n`.

تُجمع جميع القيم المُمرَّرة بنوع الإدخال الخاص بها، ثم تُرتَّب قبل إجراء حساب نهائي مستقر عدديًا. يُحسب المعامل من الفروق المطبَّعة بين الأزواج المتجاورة ويُعاد كـ `Float64`، لذا يُقرَّب إلى دقة `Float64`. لذلك، تستهلك الدالة ذاكرة بمقدار `O(n)`، حيث إن `n` هو عدد القيم المُمرَّرة. تُتجاوز قيم `NaN`، بينما تُرفض القيم اللانهائية والسالبة.

**البنية**

```sql
gini(expr)
```

**الوسيطات**

* `expr` — تعبير يُنتج قيماً رقمية محدودة وغير سالبة. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal`](/ar/reference/data-types/decimal)

**القيمة المُعادة**

معامل جيني، أو `NaN` إذا كان عدد القيم أقل من 2 أو كان مجموعها يساوي 0. [`Float64`](/ar/reference/data-types/float)

**أمثلة**

**قيم متساوية**

```sql title=Query
SELECT gini(x) FROM (SELECT 100 AS x FROM numbers(10));
```

```response title=Response
┌─gini(x)─┐
│       0 │
└─────────┘
```

**توزيع متحيز**

```sql title=Query
SELECT gini(x) FROM (SELECT number AS x FROM numbers(10));
```

```response title=Response
┌─────────────gini(x)─┐
│ 0.36666666666666664 │
└─────────────────────┘
```
