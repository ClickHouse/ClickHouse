## regr_sxx {#regr_sxx}

أُضيف في: v26.9.0

تُعيد مجموع مربعات المتغير المستقل:

$$
\Sigma{(x - \bar{x})^2}
$$

**الصيغة**

```sql
regr_sxx(y, x)
```

**الأسماء البديلة**: `regrSXX`

**الوسيطات**

- `y` — المتغير التابع. [`(U)Int*`](/reference/data-types/int-uint) أو [`Float*`](/reference/data-types/float)
- `x` — المتغير المستقل. [`(U)Int*`](/reference/data-types/int-uint) أو [`Float*`](/reference/data-types/float)

**القيمة المعادة**

تُعيد مجموع مربعات انحرافات `x` عن متوسطه. [`Float64`](/reference/data-types/float)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT regr_sxx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_sxx(y, x)─┐
│              5 │
└────────────────┘
```
