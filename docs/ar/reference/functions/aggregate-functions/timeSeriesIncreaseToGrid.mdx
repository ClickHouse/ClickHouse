## timeSeriesIncreaseToGrid {#timeSeriesIncreaseToGrid}

أُضيف في: v26.8.0

دالة تجميعية تستقبل بيانات السلاسل الزمنية على هيئة أزواج من الطوابع الزمنية والقيم، وتحسب منها [الزيادة على غرار PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#increase) على شبكة زمنية منتظمة يحددها طابع زمني للبداية وطابع زمني للنهاية وخطوة. ولكل نقطة على الشبكة، تُؤخذ في الحسبان العينات الواقعة ضمن النافذة الزمنية المحددة لحساب `increase`.

تمثل القيمة إجمالي الزيادة المستقرأة للعدّاد خلال النافذة. ويُعامَل أي انخفاض بين عينتين متتاليتين على أنه إعادة تعيين للعدّاد ويُحتسب ضمن الزيادة، ومن ثَمّ تعكس النتيجة النمو التراكمي للعدّاد حتى عندما يبدأ من الصفر من جديد.

يمكن تمرير العينات بإحدى الصيغ الثلاث التالية:

* على هيئة وسيطتين `timestamp` و`value`، بحيث يحتوي كل صف على عينة واحدة؛
* على هيئة مصفوفتين من الطوابع الزمنية والقيم، بحيث يحتوي كل صف على سلسلة زمنية كاملة؛
* على هيئة مصفوفة واحدة من صفوف مرتبة `(timestamp, value)`، بحيث يحتوي كل صف على سلسلة زمنية كاملة.

إذا اشتركت عدة عينات في الطابع الزمني نفسه، فلا تُستخدم إلا واحدة منها، وهي العينة ذات القيمة الأكبر. وتُعدّ قيمة NaN أدنى من أي قيمة أخرى، لذا لا تُستخدم إلا إذا كانت جميع العينات عند هذا الطابع الزمني NaN.

<Warning>
  هذه الدالة في مرحلة المعاينة الخاصة، ويمكن تفعيلها بضبط `enable_time_series_aggregate_functions=true`.
</Warning>

**الصيغة**

```sql
timeSeriesIncreaseToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
timeSeriesIncreaseToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples)
```

**المعلمات**

* `start_timestamp` — تحدد بداية الشبكة الزمنية. ويمكن أن تكون أيضًا عددًا كسريًا، أو string تحتوي على عدد أو نص يمثل تاريخًا ووقتًا. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `end_timestamp` — تحدد نهاية الشبكة الزمنية. ويمكن أن تكون أيضًا عددًا كسريًا، أو string تحتوي على عدد أو نص يمثل تاريخًا ووقتًا. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `grid_step` — تحدد خطوة الشبكة الزمنية بالثواني. ويمكن أن تكون أيضًا عددًا كسريًا، أو string تحتوي على عدد أو مدة مثل &#39;15s&#39; أو &#39;1m&#39;. [`UInt32`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `staleness` — تحدد الحد الأقصى لتقادم العينات المأخوذة في الحسبان، بالثواني. ونافذة التقادم فاصل زمني مفتوح من اليسار ومغلق من اليمين. ويمكن أن تكون أيضًا عددًا كسريًا، أو string تحتوي على عدد أو مدة مثل &#39;15s&#39; أو &#39;1m&#39;. [`UInt32`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)

**الوسيطات**

* `timestamp` — الطابع الزمني للعينة. يمكن أن يكون قيمًا مفردة أو مصفوفات. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Array(UInt32)`](/ar/reference/data-types/array) أو [`Array(DateTime)`](/ar/reference/data-types/array) أو [`Array(DateTime64)`](/ar/reference/data-types/array)
* `value` — قيمة السلسلة الزمنية المقابلة للطابع الزمني. يمكن أن تكون قيمًا مفردة أو مصفوفات. [`Float*`](/ar/reference/data-types/float) أو [`Array(Float*)`](/ar/reference/data-types/array)
* `samples` — عينات السلسلة الزمنية، تُمرَّر على شكل مصفوفة من Tuple بالصيغة `(timestamp, value)`، حيث تكون عناصر Tuple من نوعي الطابع الزمني والقيمة المذكورين أعلاه. وهي بديل عن تمرير الطوابع الزمنية والقيم كوسيطتين منفصلتين. [`Array(Tuple(T1, T2))`](/ar/reference/data-types/array)

**القيمة المعادة**

تُرجع قيم الزيادة على الشبكة الزمنية المحددة. تحتوي المصفوفة المُرجَعة على قيمة واحدة لكل نقطة من نقاط الشبكة الزمنية. وتكون القيمة NULL إذا لم تتوفر عينات كافية ضمن النافذة لحساب قيمة الزيادة عند نقطة معينة من الشبكة. [`Array(Nullable(Float64))`](/ar/reference/data-types/array)

**أمثلة**

**الاستخدام الأساسي مع أزواج منفردة من الطابع الزمني والقيمة**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesIncreaseToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesIncreaseToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,0,3,4.5,2.5,NULL,NULL,3.75]                                                     │
└────────────────────────────────────────────────────────────────────────────────────────────┘
```

**استخدام وسيطات من نوع المصفوفة**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesIncreaseToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesIncreaseToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,0,3,4.5,2.5,NULL,NULL,3.75]                                                       │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```
