## regr_r2 {#regr_r2}

أُضيف في: v26.9.0

تُعيد معامل التحديد لملاءمة المربعات الصغرى، أي مربع
معامل الارتباط. وتُعيد `nan` عندما تكون قيمة `x` ثابتة، و`1` عندما تكون قيمة `y` ثابتة.

**الصيغة**

```sql
regr_r2(y, x)
```

**الأسماء البديلة**: `regrR2`

**الوسيطات**

* `y` — المتغير التابع. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float)
* `x` — المتغير المستقل. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float)

**القيمة المعادة**

تُعيد قيمة تتراوح بين 0 و1. [`Float64`](/ar/reference/data-types/float)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
