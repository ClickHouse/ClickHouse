## regr_intercept {#regr_intercept}

أُضيف في: v26.9.0

تُعيد الجزء المقطوع (نقطة التقاطع) لخط انحدار `y` على `x` المحسوب بطريقة المربعات الصغرى:

$$
\bar{y} - slope \cdot \bar{x}
$$

تُعيد `nan` عندما تكون قيمة `x` ثابتة، لأن خط الانحدار يكون عندئذٍ عموديًا.

**الصيغة**

```sql
regr_intercept(y, x)
```

**الأسماء البديلة**: `regrIntercept`

**الوسيطات**

* `y` — المتغير التابع. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float)
* `x` — المتغير المستقل. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float)

**القيمة المعادة**

تُعيد الجزء المقطوع (Intercept) لخط الانحدار. [`Float64`](/ar/reference/data-types/float)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT regr_intercept(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

