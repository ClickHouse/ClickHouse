<div id="timeSeriesResetsToGrid">
  ## timeSeriesResetsToGrid
</div>

أُضيفت في: v25.6.0

دالة تجميع تأخذ بيانات السلاسل الزمنية على شكل أزواج من الطوابع الزمنية والقيم، وتحسب [عمليات إعادة الضبط على نمط PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#resets) من هذه البيانات على شبكة زمنية منتظمة تُحدَّد بالطابع الزمني للبداية والطابع الزمني للنهاية و`step`. ولكل نقطة على هذه الشبكة، تُؤخذ العيّنات اللازمة لحساب `resets` ضمن النافذة الزمنية المحددة.

إذا كانت عدة عينات تحمل الطابع الزمني نفسه، فلا يُستخدم سوى واحد منها: العينة ذات القيمة الأكبر. تخسر قيمة NaN أمام أي قيمة أخرى، لذا لا تُستخدم قيمة NaN إلا إذا كانت جميع العينات عند هذا الطابع الزمني هي NaN.

<Note>
  هذه الدالة تجريبية، ولتفعيلها اضبط `allow_experimental_time_series_aggregate_functions=true`.
</Note>

**البنية**

```sql
timeSeriesResetsToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
```

**المعلمات**

* `start_timestamp` — يحدّد بداية الشبكة. ومع وسيطة طابع زمني من النوع `DateTime64`، يمكن أن يكون أيضًا رقمًا كسريًا أو سلسلة تحتوي على رقم أو نص للتاريخ والوقت. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `end_timestamp` — يحدّد نهاية الشبكة. ومع وسيطة طابع زمني من النوع `DateTime64`، يمكن أن يكون أيضًا رقمًا كسريًا أو سلسلة تحتوي على رقم أو نص للتاريخ والوقت. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `grid_step` — يحدّد خطوة الشبكة بالثواني. ومع وسيطة طابع زمني من النوع `DateTime64`، يمكن أن يكون أيضًا رقمًا كسريًا أو سلسلة تحتوي على رقم أو مدة مثل &#39;15s&#39; أو &#39;1m&#39;. [`UInt32`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `staleness` — يحدّد الحد الأقصى لـ&quot;التقادم&quot; بالثواني للعينات المأخوذة في الحسبان. ومع وسيطة طابع زمني من النوع `DateTime64`، يمكن أن يكون أيضًا رقمًا كسريًا أو سلسلة تحتوي على رقم أو مدة مثل &#39;15s&#39; أو &#39;1m&#39;. [`UInt32`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)

**الوسائط**

* `timestamp` — الطابع الزمني للعينة. يمكن أن يكون قيمة مفردة أو مصفوفات. - `value` — قيمة السلسلة الزمنية المقابلة للطابع الزمني. يمكن أن تكون قيمة مفردة أو مصفوفات.

**القيمة المُعادة**

قيم `resets` على الشبكة المحددة على هيئة `Array(Nullable(Float64))`. تحتوي المصفوفة المُعادة على قيمة واحدة لكل نقطة في الشبكة الزمنية. تكون القيمة NULL إذا لم توجد عينات ضمن النافذة اللازمة لحساب قيمة `resets` لنقطة شبكة معيّنة.

**أمثلة**

**احسب قيم resets على الشبكة [90, 105, 120, 135, 150, 165, 180, 195, 210, 225]**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 130 and 190 is to show how values are filled for ts = 180 according to window parameter
    [110, 120, 130, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 3, 2, 6, 6, 4, 2, 0]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 135 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesResetsToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesResetsToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,0,1,1,0,NULL,0,1,2]                                                           │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

**الاستعلام نفسه مع وسيطات من النوع Array**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 3, 2, 6, 6, 4, 2, 0]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 135 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesResetsToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesResetsToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,0,1,1,0,NULL,0,1,2]                                                             │
└────────────────────────────────────────────────────────────────────────────────────────────┘
```
