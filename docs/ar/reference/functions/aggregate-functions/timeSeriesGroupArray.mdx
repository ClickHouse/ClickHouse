## timeSeriesGroupArray {#timeSeriesGroupArray}

أُضيف في: v25.8.0

يرتّب بيانات السلاسل الزمنية حسب الطابع الزمني بترتيب تصاعدي.

يمكن تمرير العينات بأحد الأشكال الثلاثة التالية:

* كمعاملين هما `timestamp` و`value`، حيث يحتوي كل صف على عينة واحدة؛
* كمصفوفتين من الطوابع الزمنية والقيم، حيث يحتوي كل صف على سلسلة زمنية كاملة؛
* كمصفوفة واحدة من عناصر `Tuple` بالشكل `(timestamp, value)`، حيث يحتوي كل صف على سلسلة زمنية كاملة. لهذا الشكل النوع نفسه كالنتيجة، مما يسمح باستخدام الدالة في نوع البيانات `SimpleAggregateFunction`.

إذا كانت عدة عينات تحمل الطابع الزمني نفسه، فلا يُستخدم سوى واحدة منها: العينة ذات القيمة الأكبر. تخسر قيمة `NaN` أمام أي قيمة أخرى، لذا لا تُستخدم قيمة `NaN` إلا إذا كانت جميع العينات عند هذا الطابع الزمني هي `NaN`.

<Note>
  هذه الدالة تجريبية. فعِّلها بتعيين `allow_experimental_time_series_aggregate_functions=true`.
</Note>

**البنية**

```sql
timeSeriesGroupArray(timestamp, value)
timeSeriesGroupArray(samples)
```

**المعاملات**

* `timestamp` — الطابع الزمني للعينة. يمكن أن يكون قيمة فردية أو مصفوفة. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Array(UInt32)`](/ar/reference/data-types/array) أو [`Array(DateTime)`](/ar/reference/data-types/array) أو [`Array(DateTime64)`](/ar/reference/data-types/array)
* `value` — قيمة السلاسل الزمنية المقابلة للطابع الزمني. يمكن أن تكون قيمة فردية أو مصفوفة. [`Float*`](/ar/reference/data-types/float) أو [`Array(Float*)`](/ar/reference/data-types/array)
* `samples` — عينات السلاسل الزمنية المُمرَّرة في صورة مصفوفة من عناصر `Tuple` بالشكل `(timestamp, value)`، حيث تحمل عناصر الـ `Tuple` أنواع الطابع الزمني والقيمة المذكورة أعلاه. [`Array(Tuple(T1, T2))`](/ar/reference/data-types/array)

**القيمة المُعادة**

تُرجِع مصفوفة من عناصر `Tuple` بالشكل `(timestamp, value)` مرتبة حسب الطابع الزمني ترتيبًا تصاعديًا. [`Array(Tuple(T1, T2))`](/ar/reference/data-types/array)

**أمثلة**

**الاستخدام الأساسي مع القيم الفردية**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 140, 100]::Array(UInt32) AS timestamps,
    [1, 6, 8, 17, 19, 5]::Array(Float32) AS values
SELECT timeSeriesGroupArray(timestamp, value)
FROM
(
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesGroupArray(timestamp, value)─────┐
│ [(100,5),(110,1),(120,6),(130,8),(140,19)] │
└────────────────────────────────────────────┘
```

**تمرير عينات متعددة من الطوابع الزمنية والقيم في صورة مصفوفات متساوية الحجم**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 140, 100]::Array(UInt32) AS timestamps,
    [1, 6, 8, 17, 19, 5]::Array(Float32) AS values
SELECT timeSeriesGroupArray(timestamps, values);
```

```response title=Response
┌─timeSeriesGroupArray(timestamps, values)───┐
│ [(100,5),(110,1),(120,6),(130,8),(140,19)] │
└────────────────────────────────────────────┘
```
