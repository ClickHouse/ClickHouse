## avg {#avg}

أُضيف في: v1.1.0

يحسب المتوسط الحسابي.

**الصيغة**

```sql
avg(x)
```

**الوسيطات**

* `x` — قيم الإدخال. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal`](/ar/reference/data-types/decimal) أو [`Date`](/ar/reference/data-types/date) أو [`Date32`](/ar/reference/data-types/date32) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64(P)`](/ar/reference/data-types/datetime64) أو [`Time`](/ar/reference/data-types/time) أو [`Time64(P)`](/ar/reference/data-types/time64) أو [`Interval`](/ar/reference/data-types/special-data-types/interval)

**القيمة المعادة**

تُرجع الدالة المتوسط الحسابي. إذا كانت `x` عددية، تكون النتيجة من النوع `Float64`، أو `NaN` إذا كانت `x` فارغة. أما إذا كانت `x` من نوع تاريخ أو وقت أو فاصل زمني، فيبقى نوع النتيجة مطابقًا لنوع `x`: يُقرَّب المتوسط إلى أقرب قيمة قابلة للتمثيل، وتكون النتيجة عند فراغ `x` هي القيمة الصفرية لذلك النوع. [`Float64`](/ar/reference/data-types/float) أو [`Date`](/ar/reference/data-types/date) أو [`Date32`](/ar/reference/data-types/date32) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64(P)`](/ar/reference/data-types/datetime64) أو [`Time`](/ar/reference/data-types/time) أو [`Time64(P)`](/ar/reference/data-types/time64) أو [`Interval`](/ar/reference/data-types/special-data-types/interval)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**يُرجع الجدول الفارغ القيمة NaN**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**متوسط الفاصل الزمني**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
