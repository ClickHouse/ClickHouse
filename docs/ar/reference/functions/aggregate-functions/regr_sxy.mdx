## regr_sxy {#regr_sxy}

أُضيف في: v26.9.0

تُرجع مجموع حواصل ضرب المتغيرين:

$$
\Sigma{(x - \bar{x})(y - \bar{y})}
$$

**الصيغة**

```sql
regr_sxy(y, x)
```

**الأسماء البديلة**: `regrSXY`

**الوسيطات**

- `y` — المتغير التابع. [`(U)Int*`](/reference/data-types/int-uint) أو [`Float*`](/reference/data-types/float)
- `x` — المتغير المستقل. [`(U)Int*`](/reference/data-types/int-uint) أو [`Float*`](/reference/data-types/float)

**القيمة المُعادة**

تُرجع مجموع حواصل ضرب انحرافات `x` و`y` عن متوسطيهما. [`Float64`](/reference/data-types/float)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT regr_sxy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_sxy(y, x)─┐
│             10 │
└────────────────┘
```
