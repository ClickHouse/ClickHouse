## regr_count {#regr_count}

أُضيف في: v26.9.0

يحسب عدد الصفوف التي لا تكون فيها أيٌّ من القيمتين `y` و`x` مساويةً لـ `NULL`.

**الصيغة**

```sql
regr_count(y, x)
```

**الأسماء البديلة**: `regrCount`

**الوسيطات**

* `y` — المتغير التابع. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float)
* `x` — المتغير المستقل. [`(U)Int*`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float)

**القيمة المعادة**

تُعيد عدد الأزواج التي لا تحتوي على قيم NULL. [`UInt64`](/ar/reference/data-types/int-uint)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT regr_count(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_count(y, x)─┐
│                4 │
└──────────────────┘
```
