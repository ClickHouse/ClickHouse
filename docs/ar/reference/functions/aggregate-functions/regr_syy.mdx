## regr_syy {#regr_syy}

أُضيف في: v26.9.0

تُعيد مجموع مربعات المتغير التابع:

$$
\Sigma{(y - \bar{y})^2}
$$

**الصيغة**

```sql
regr_syy(y, x)
```

**الأسماء البديلة**: `regrSYY`

**الوسيطات**

- `y` — المتغير التابع. [`(U)Int*`](/reference/data-types/int-uint) أو [`Float*`](/reference/data-types/float)
- `x` — المتغير المستقل. [`(U)Int*`](/reference/data-types/int-uint) أو [`Float*`](/reference/data-types/float)

**القيمة المُعادة**

تُعيد مجموع مربعات انحرافات `y` عن متوسطها. [`Float64`](/reference/data-types/float)

**أمثلة**

**الاستخدام الأساسي**

```sql title=Query
SELECT regr_syy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_syy(y, x)─┐
│             20 │
└────────────────┘
```
