## estimateCompressionRatio {#estimateCompressionRatio}

أُضيف في: v25.4.0

تُقدِّر الضغط لعمود معيّن دون ضغطه فعليًا.

<Note>
  في الأمثلة أدناه، ستختلف النتيجة بحسب برنامج ترميز الضغط الافتراضي للخادم.
  راجع [برامج ترميز ضغط الأعمدة](/ar/reference/statements/create/table#column_compression_codec).
</Note>

**الصيغة**

```sql
estimateCompressionRatio([codec, block_size_bytes])(column)
```

**المعلمات**

* `codec` — قيمة `String` تحتوي على برنامج ترميز ضغط واحد أو عدة برامج ترميز ضغط مفصولة بفواصل ضمن سلسلة واحدة. [`String`](/ar/reference/data-types/string)
* `block_size_bytes` — حجم كتلة البيانات المضغوطة. وهذا يشبه ضبط كلٍّ من [`max_compress_block_size`](/ar/reference/settings/merge-tree-settings/max#max_compress_block_size) و[`min_compress_block_size`](/ar/reference/settings/merge-tree-settings/min#min_compress_block_size). القيمة الافتراضية هي 1 MiB ‏(1048576 بايت). والحد الأقصى المسموح به هو 256 MiB ‏(268435456 بايت). [`UInt64`](/ar/reference/data-types/int-uint)

**الوسائط**

* `column` — عمود من أي نوع. [`Any`](/ar/reference/data-types/index)

**القيمة المرجعة**

تعيد قيمة تقديرية للضغط للعمود المحدد. [`Float64`](/ar/reference/data-types/float)

**أمثلة**

**الاستخدام الأساسي مع برنامج ترميز الضغط الافتراضي**

```sql title=Query
CREATE TABLE compression_estimate_example
(
    `number` UInt64
)
ENGINE = MergeTree()
ORDER BY number
SETTINGS min_bytes_for_wide_part = 0;

INSERT INTO compression_estimate_example
SELECT number FROM system.numbers LIMIT 100_000;

SELECT estimateCompressionRatio(number) AS estimate FROM compression_estimate_example
```

```response title=Response
┌──────────estimate─┐
│ 5.758875867430677 │
└───────────────────┘
```

**استخدام برنامج ترميز ضغط معيّن**

```sql title=Query
SELECT estimateCompressionRatio('T64')(number) AS estimate FROM compression_estimate_example
```

```response title=Response
┌──────────estimate─┐
│ 3.762758101688538 │
└───────────────────┘
```

**استخدام عدة برامج ترميز ضغط**

```sql title=Query
SELECT estimateCompressionRatio('T64, ZSTD')(number) AS estimate FROM compression_estimate_example
```

```response title=Response
┌───────────estimate─┐
│ 143.60078980434392 │
└────────────────────┘
```
