## timeSeriesFirstToGrid {#timeSeriesFirstToGrid}

أُضيف في: v26.10.0

دالة تجميعية تستقبل بيانات السلاسل الزمنية على هيئة أزواج من الطوابع الزمنية والقيم، وتحسب منها [first&#95;over&#95;time على غرار PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) على شبكة زمنية منتظمة تُحدَّد بطابع زمني للبداية وطابع زمني للنهاية وخطوة. وتكون النتيجة لكل نقطة على الشبكة هي قيمة أقدم عينة ضمن النافذة الزمنية المحددة.

يمكن تمرير العينات بإحدى الصيغ الثلاث التالية:

* وسيطتان هما `timestamp` و`value`، بحيث يضم كل صف عينة واحدة؛
* مصفوفتان من الطوابع الزمنية والقيم، بحيث يضم كل صف سلسلة زمنية كاملة؛
* مصفوفة واحدة من الصفوف المرتبة `(timestamp, value)`، بحيث يضم كل صف سلسلة زمنية كاملة.

إذا اشتركت عدة عينات في الطابع الزمني نفسه، فلا تُستخدم إلا واحدة منها، وهي العينة ذات القيمة الأكبر. وتُقدَّم أي قيمة أخرى على قيمة NaN، لذا لا تُستخدم قيمة NaN إلا إذا كانت جميع العينات عند هذا الطابع الزمني NaN.

<Warning>
  هذه الدالة في مرحلة المعاينة الخاصة، ويمكنك تفعيلها بضبط الإعداد `enable_time_series_aggregate_functions=true`.
</Warning>

**الصيغة**

```sql
timeSeriesFirstToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(timestamp, value)
timeSeriesFirstToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(samples)
```

**المعلمات**

* `start_timestamp` — يحدد بداية الشبكة الزمنية. ويمكن أيضًا أن يكون عددًا كسريًا، أو سلسلة نصية تحتوي على عدد أو على نص يمثل تاريخًا ووقتًا. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `end_timestamp` — يحدد نهاية الشبكة الزمنية. ويمكن أيضًا أن يكون عددًا كسريًا، أو سلسلة نصية تحتوي على عدد أو على نص يمثل تاريخًا ووقتًا. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `grid_step` — يحدد خطوة الشبكة الزمنية بالثواني. ويمكن أيضًا أن يكون عددًا كسريًا، أو سلسلة نصية تحتوي على عدد أو على مدة مثل &#39;15s&#39; أو &#39;1m&#39;. [`UInt32`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)
* `staleness_window` — يحدد الحد الأقصى لـ&quot;تقادم&quot; العينات المعتبرة بالثواني. ونافذة التقادم فاصل زمني مفتوح من اليسار ومغلق من اليمين. ويمكن أيضًا أن يكون عددًا كسريًا، أو سلسلة نصية تحتوي على عدد أو على مدة مثل &#39;15s&#39; أو &#39;1m&#39;. [`UInt32`](/ar/reference/data-types/int-uint) أو [`Float*`](/ar/reference/data-types/float) أو [`Decimal*`](/ar/reference/data-types/decimal) أو [`String`](/ar/reference/data-types/string)

**الوسيطات**

* `timestamp` — الطابع الزمني للعينة. ويمكن أن يكون قيمًا فردية أو مصفوفات. [`UInt32`](/ar/reference/data-types/int-uint) أو [`DateTime`](/ar/reference/data-types/datetime) أو [`DateTime64`](/ar/reference/data-types/datetime64) أو [`Array(UInt32)`](/ar/reference/data-types/array) أو [`Array(DateTime)`](/ar/reference/data-types/array) أو [`Array(DateTime64)`](/ar/reference/data-types/array)
* `value` — قيمة السلسلة الزمنية المقابلة للطابع الزمني. ويمكن أن تكون قيمًا فردية أو مصفوفات. [`Float*`](/ar/reference/data-types/float) أو [`Array(Float*)`](/ar/reference/data-types/array)
* `samples` — عينات السلسلة الزمنية، وتُمرَّر في صورة مصفوفة من الصفوف المرتبة `(timestamp, value)`، حيث تكون عناصر الصف المرتب من أنواع الطابع الزمني والقيمة المذكورة أعلاه. وهي بديل عن تمرير الطوابع الزمنية والقيم في وسيطتين منفصلتين. [`Array(Tuple(T1, T2))`](/ar/reference/data-types/array)

**القيمة المعادة**

تُعيد قيم أقدم العينات على الشبكة الزمنية المحددة، وتكون من نوع `value` نفسه. تحتوي المصفوفة المعادة على قيمة واحدة لكل نقطة في الشبكة الزمنية، وتكون القيمة NULL إذا لم توجد أي عينة ضمن النافذة عند نقطة معينة من الشبكة. [`Array(Nullable(Float*))`](/ar/reference/data-types/array)

**أمثلة**

**حساب قيم first&#95;over&#95;time على الشبكة الزمنية [90, 105, 120, 135, 150, 165, 180, 195, 210]**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to staleness window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    30 AS window_seconds  -- "staleness" window
SELECT timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,1,1,3,4,NULL,5,5]                                                            │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

**الاستعلام نفسه باستخدام وسيطات من نوع مصفوفة**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    30 AS window_seconds
SELECT timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,1,1,3,4,NULL,5,5]                                                              │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```
