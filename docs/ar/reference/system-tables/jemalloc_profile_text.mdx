## الوصف {#description}

يعرض ملف تعريف كومة jemalloc بعد تحويله إلى رموز. شغّل &#39;SYSTEM JEMALLOC FLUSH PROFILE&#39; أولًا لإنشاء ملف تعريف.

## الأعمدة {#columns}

* `line` ([String](/ar/reference/data-types/string)) — سطر من ملف تعريف كومة jemalloc بعد تحويله إلى رموز.
