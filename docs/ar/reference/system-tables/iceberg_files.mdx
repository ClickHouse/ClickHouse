<div id="description">
  ## الوصف
</div>

يحتوي جدول النظام هذا على البيانات الوصفية الخاصة بكل ملف في جداول Iceberg الموجودة في ClickHouse، بحيث يقابل كل ملف بيانات أو حذف مشار إليه في اللقطة الحالية لكل جدول صفٌّ واحد. وسيكون هذا الجدول فارغًا إذا لم تكن لديك أي جداول Iceberg في ClickHouse.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/reference/data-types/string)) — اسم الجدول.
* `snapshot_id` ([Int64](/ar/reference/data-types/int-uint)) — معرّف اللقطة التي أُضيف فيها الملف.
* `content` ([Enum8(&#39;DATA&#39; = 0, &#39;POSITION&#95;DELETE&#39; = 1, &#39;EQUALITY&#95;DELETE&#39; = 2)](/ar/reference/data-types/enum)) — نوع محتوى الملف.
* `file_path` ([String](/ar/reference/data-types/string)) — مسار التخزين المحلول للملف.
* `file_format` ([String](/ar/reference/data-types/string)) — تنسيق الملف، مثل &#39;PARQUET&#39;.
* `record_count` ([Int64](/ar/reference/data-types/int-uint)) — عدد السجلات في الملف.
* `file_size_in_bytes` ([Int64](/ar/reference/data-types/int-uint)) — حجم الملف بالبايت.
* `partition` ([String](/ar/reference/data-types/string)) — تمثيل نصي لمجموعة القسم.
* `schema_id` ([Int32](/ar/reference/data-types/int-uint)) — معرّف المخطط المحلول لإدخال البيان هذا.
* `sequence_number` ([Int64](/ar/reference/data-types/int-uint)) — رقم التسلسل المحلول لإدخال البيان (يكون دائمًا 0 في التنسيق v1).
* `sort_order_id` ([Nullable(Int32)](/ar/reference/data-types/nullable)) — معرّف ترتيب فرز الملف، إن كان محددًا.
* `null_value_counts` ([Map(Int32, Int64)](/ar/reference/data-types/map)) — عدد قيم NULL لكل عمود (معرّف العمود -&gt; العدد).
* `column_sizes` ([Map(Int32, Int64)](/ar/reference/data-types/map)) — الحجم على القرص لكل عمود بالبايت (معرّف العمود -&gt; البايت).
* `value_counts` ([Map(Int32, Int64)](/ar/reference/data-types/map)) — إجمالي عدد القيم لكل عمود (معرّف العمود -&gt; العدد).
* `equality_ids` ([Array(Int32)](/ar/reference/data-types/array)) — معرّفات حقول المساواة لملفات الحذف بالمساواة (فارغة للملفات التي لا تستخدم الحذف بالمساواة).

{/*AUTOGENERATED_END*/}
