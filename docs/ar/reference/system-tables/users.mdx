<div id="description">
  ## الوصف
</div>

يتضمن قائمة بـ[حسابات المستخدمين](/ar/concepts/features/security/access-rights#user-account-management) المُعرَّفة على الخادم.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ar/reference/data-types/string)) — اسم المستخدم.
* `id` ([UUID](/ar/reference/data-types/uuid)) — معرّف المستخدم.
* `storage` ([String](/ar/reference/data-types/string)) — مسار تخزين المستخدمين. يُضبط عبر المعلَمة access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/ar/reference/data-types/array)) — يعرض أنواع المصادقة. توجد عدة طرق للتحقق من هوية المستخدم: من دون كلمة مرور، أو بكلمة مرور نصية عادية، أو بكلمة مرور مُرمّزة بـ SHA256، أو بكلمة مرور مُرمّزة بـ SHA-1 المزدوج، أو بكلمة مرور مُرمّزة بـ bcrypt.
* `auth_params` ([Array(String)](/ar/reference/data-types/array)) — معلمات المصادقة بتنسيق JSON وفقًا لـ auth&#95;type.
* `valid_until` ([Array(DateTime64(0))](/ar/reference/data-types/array)) — تاريخ ووقت انتهاء صلاحية بيانات اعتماد المستخدم، واحدة لكل طريقة مصادقة. القيمة المخزنة لحظة زمنية مطلقة تُعرض وفق المنطقة الزمنية للخادم أو الجلسة؛ وتشير القيمة المخزنة `0` (حقبة Unix، المعروضة كـ `1970-01-01 00:00:00` على خادم في `UTC`) إلى أن بيانات الاعتماد لا تنتهي صلاحيتها أبدًا.
* `auth_grants` ([Array(String)](/ar/reference/data-types/array)) — لكل طريقة مصادقة: حدّ حقوق الوصول المحدد في عبارة `GRANTS`، أو سلسلة فارغة إذا لم تكن حقوق الوصول مقيّدة.
* `host_ip` ([Array(String)](/ar/reference/data-types/array)) — عناوين IP للمضيفين المسموح لهم بالاتصال بخادم ClickHouse.
* `host_names` ([Array(String)](/ar/reference/data-types/array)) — أسماء المضيفين المسموح لهم بالاتصال بخادم ClickHouse.
* `host_names_regexp` ([Array(String)](/ar/reference/data-types/array)) — تعبير نمطي لأسماء المضيفين المسموح لهم بالاتصال بخادم ClickHouse.
* `host_names_like` ([Array(String)](/ar/reference/data-types/array)) — أسماء المضيفين المسموح لهم بالاتصال بخادم ClickHouse، المحددة باستخدام المسند LIKE.
* `default_roles_all` ([UInt8](/ar/reference/data-types/int-uint)) — يوضح أن جميع الأدوار الممنوحة تُعيَّن للمستخدم افتراضيًا.
* `default_roles_list` ([Array(String)](/ar/reference/data-types/array)) — قائمة بالأدوار الممنوحة المُعيَّنة افتراضيًا.
* `default_roles_except` ([Array(String)](/ar/reference/data-types/array)) — جميع الأدوار الممنوحة المُعيَّنة افتراضيًا، باستثناء الأدوار المدرجة.
* `grantees_any` ([UInt8](/ar/reference/data-types/int-uint)) — علامة تشير إلى ما إذا كان المستخدم الذي يملك أي خيار منح يمكنه منحه لأي شخص.
* `grantees_list` ([Array(String)](/ar/reference/data-types/array)) — قائمة المستخدمين أو الأدوار التي يُسمح لهذا المستخدم بمنح خيارات المنح لها.
* `grantees_except` ([Array(String)](/ar/reference/data-types/array)) — قائمة المستخدمين أو الأدوار التي يُحظر على هذا المستخدم منح خيارات المنح لها.
* `default_database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات الافتراضية لهذا المستخدم.
