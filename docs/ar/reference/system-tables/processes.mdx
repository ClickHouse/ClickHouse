<div id="description">
  ## الوصف
</div>

يُستخدم جدول نظامي هذا لتنفيذ الاستعلام `SHOW PROCESSLIST`.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/ar/reference/data-types/int-uint)) — يحدد ما إذا كان هذا الاستعلام صادرًا مباشرةً عن المستخدم أو أرسله ClickHouse server في سياق تنفيذ استعلام موزّع.
* `user` ([String](/ar/reference/data-types/string)) — المستخدم الذي أجرى الاستعلام. يُرجى ملاحظة أنه في المعالجة الموزعة، تُرسل الاستعلامات إلى الخوادم البعيدة باسم المستخدم default. يحتوي هذا الحقل على اسم المستخدم الخاص باستعلام معيّن، وليس باسم مستخدم الاستعلام الذي بدأه هذا الاستعلام.
* `query_id` ([String](/ar/reference/data-types/string)) — معرّف الاستعلام، إن كان محددًا.
* `address` ([IPv6](/ar/reference/data-types/ipv6)) — عنوان IP الذي أُجري الاستعلام منه. وينطبق الأمر نفسه على المعالجة الموزعة. لتتبّع المصدر الأصلي للاستعلام الموزّع، راجع system.processes على الخادم الذي طلب الاستعلام.
* `port` ([UInt16](/ar/reference/data-types/int-uint)) — منفذ العميل الذي أُجري الاستعلام منه.
* `initial_user` ([String](/ar/reference/data-types/string)) — اسم المستخدم الذي شغّل الاستعلام الأولي (لتنفيذ الاستعلام الموزّع).
* `initial_query_id` ([String](/ar/reference/data-types/string)) — معرّف الاستعلام الأولي (لتنفيذ الاستعلام الموزّع).
* `initial_address` ([IPv6](/ar/reference/data-types/ipv6)) — عنوان IP الذي أُطلق منه الاستعلام الأب.
* `initial_port` ([UInt16](/ar/reference/data-types/int-uint)) — منفذ العميل المُستخدم لإجراء الاستعلام الأب.
* `interface` ([UInt8](/ar/reference/data-types/int-uint)) — الواجهة المُستخدمة لإرسال الاستعلام. TCP = 1، HTTP = 2، GRPC = 3، MYSQL = 4، POSTGRESQL = 5، LOCAL = 6، TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/ar/reference/data-types/string)) — اسم مستخدم نظام التشغيل الذي يشغّل clickhouse-client.
* `client_hostname` ([String](/ar/reference/data-types/string)) — اسم مضيف جهاز العميل الذي يعمل عليه clickhouse-client أو عميل TCP آخر.
* `client_name` ([String](/ar/reference/data-types/string)) — اسم clickhouse-client أو عميل TCP آخر.
* `client_agent` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — وكيل الشيفرة المعتمد على الذكاء الاصطناعي الذي استدعى العميل (مثل `claude-code` و`cursor`) ويُكتشف من متغيرات البيئة. تكون القيمة فارغة إذا لم يُكتشف أي وكيل.
* `client_revision` ([UInt64](/ar/reference/data-types/int-uint)) — مراجعة clickhouse-client أو عميل TCP آخر.
* `client_version_major` ([UInt64](/ar/reference/data-types/int-uint)) — الإصدار الرئيسي لـ clickhouse-client أو عميل TCP آخر.
* `client_version_minor` ([UInt64](/ar/reference/data-types/int-uint)) — الإصدار الثانوي لـ clickhouse-client أو عميل TCP آخر.
* `client_version_patch` ([UInt64](/ar/reference/data-types/int-uint)) — مكوّن التصحيح في إصدار clickhouse-client أو عميل TCP آخر.
* `http_method` ([UInt8](/ar/reference/data-types/int-uint)) — أسلوب HTTP الذي بدأ الاستعلام. القيم الممكنة: 0 — أُطلق الاستعلام من واجهة TCP. 1 — استُخدم أسلوب GET. 2 — استُخدم أسلوب POST.
* `http_user_agent` ([String](/ar/reference/data-types/string)) — ترويسة HTTP ‏UserAgent المُمرّرة مع استعلام HTTP.
* `http_referer` ([String](/ar/reference/data-types/string)) — ترويسة HTTP ‏Referer المُمرّرة مع استعلام HTTP (تحتوي على عنوان كامل أو جزئي للصفحة التي تُجري الاستعلام).
* `forwarded_for` ([String](/ar/reference/data-types/string)) — ترويسة HTTP ‏X-Forwarded-For المُمرّرة مع استعلام HTTP.
* `quota_key` ([String](/ar/reference/data-types/string)) — مفتاح الحصة المحدد في إعداد الحصص (انظر keyed).
* `distributed_depth` ([UInt64](/ar/reference/data-types/int-uint)) — عدد المرات التي أُعيد فيها إرسال الاستعلام داخليًا بين عُقد الخوادم.
* `elapsed` ([Float64](/ar/reference/data-types/float)) — الوقت بالثواني منذ بدء تنفيذ الطلب.
* `is_cancelled` ([UInt8](/ar/reference/data-types/int-uint)) — ما إذا كان الاستعلام قد أُلغي.
* `is_all_data_sent` ([UInt8](/ar/reference/data-types/int-uint)) — ما إذا كانت جميع البيانات قد أُرسلت إلى العميل (أي إن الاستعلام كان قد اكتمل على الخادم).
* `read_rows` ([UInt64](/ar/reference/data-types/int-uint)) — عدد الصفوف المقروءة من الجدول. في المعالجة الموزعة، يمثل هذا العدد الإجمالي عبر جميع الخوادم البعيدة على الخادم الطالب.
* `read_bytes` ([UInt64](/ar/reference/data-types/int-uint)) — عدد البايتات غير المضغوطة المقروءة من الجدول. في المعالجة الموزعة، يمثل هذا العدد الإجمالي عبر جميع الخوادم البعيدة على الخادم الطالب.
* `total_rows_approx` ([UInt64](/ar/reference/data-types/int-uint)) — تقدير العدد الإجمالي للصفوف المطلوب قراءتها. في المعالجة الموزعة، يمثل هذا العدد الإجمالي عبر جميع الخوادم البعيدة على الخادم الطالب. ويمكن تحديثه أثناء معالجة الطلب عند اكتشاف مصادر جديدة لمعالجتها.
* `written_rows` ([UInt64](/ar/reference/data-types/int-uint)) — عدد الصفوف المكتوبة إلى التخزين.
* `written_bytes` ([UInt64](/ar/reference/data-types/int-uint)) — عدد البايتات المكتوبة إلى التخزين.
* `memory_usage` ([Int64](/ar/reference/data-types/int-uint)) — مقدار ذاكرة RAM التي يستخدمها الاستعلام. وقد لا يشمل بعض أنواع الذاكرة المخصصة.
* `peak_memory_usage` ([Int64](/ar/reference/data-types/int-uint)) — الذروة الحالية لاستخدام الذاكرة.
* `query` ([String](/ar/reference/data-types/string)) — نص الاستعلام. بالنسبة إلى INSERT، لا يشمل البيانات المراد إدراجها.
* `normalized_query_hash` ([UInt64](/ar/reference/data-types/int-uint)) — قيمة hash رقمية متطابقة، على سبيل المثال، للاستعلامات التي لا تختلف إلا في قيم القيم الحرفية.
* `query_kind` ([String](/ar/reference/data-types/string)) — نوع الاستعلام: SELECT أو INSERT، إلخ.
* `thread_ids` ([Array(UInt64)](/ar/reference/data-types/array)) — قائمة معرّفات جميع سلاسل التنفيذ التي شاركت في هذا الاستعلام.
* `peak_threads_usage` ([UInt64](/ar/reference/data-types/int-uint)) — الحد الأقصى لعدد سلاسل التنفيذ المتزامنة التي تنفذ الاستعلام.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ar/reference/data-types/map)) — أحداث ProfileEvents المحسوبة لهذا الاستعلام.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ar/reference/data-types/map)) — قائمة الإعدادات المعدّلة على مستوى المستخدم.
* `current_database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات الحالية.
* `is_internal` ([UInt8](/ar/reference/data-types/int-uint)) — يشير إلى ما إذا كان استعلامًا مساعدًا يُنفذ داخليًا.

**الأسماء المستعارة:**

* `ProfileEvents.Names` — اسم مستعار لـ `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — اسم مستعار لـ `mapValues(ProfileEvents)`.
* `Settings.Names` — اسم مستعار لـ `mapKeys(Settings)`.
* `Settings.Values` — اسم مستعار لـ `mapValues(Settings)`.
