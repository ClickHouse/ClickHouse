<div id="description">
  ## الوصف
</div>

يتضمن حالة التحميل، ومعلومات عن الخطأ، والبيانات الوصفية للتهيئة الخاصة بـ [الدوال المعرّفة من قبل المستخدم (UDFs)](/ar/reference/functions/regular-functions/udf).

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ar/reference/data-types/string)) — اسم UDF.
* `load_status` ([Enum8(&#39;Success&#39; = 0, &#39;Failed&#39; = 1)](/ar/reference/data-types/enum)) — حالة التحميل. القيم الممكنة: Success — تم تحميل UDF وهو جاهز للاستخدام، Failed — تعذّر تحميل UDF (راجع الحقل &#39;loading&#95;error&#95;message&#39; للتفاصيل).
* `loading_error_message` ([String](/ar/reference/data-types/string)) — رسالة الخطأ التفصيلية عند فشل التحميل. تكون فارغة عند نجاح التحميل.
* `last_successful_update_time` ([Nullable(DateTime)](/ar/reference/data-types/nullable)) — الطابع الزمني لآخر تحديث ناجح. NULL إذا لم ينجح أي تحديث من قبل.
* `loading_duration_ms` ([UInt64](/ar/reference/data-types/int-uint)) — الوقت المستغرق لتحميل UDF بالمللي ثانية.
* `type` ([Enum8(&#39;executable&#39; = 0, &#39;executable&#95;pool&#39; = 1)](/ar/reference/data-types/enum)) — نوع UDF: &#39;executable&#39; (عملية واحدة) أو &#39;executable&#95;pool&#39; (مجمع عمليات).
* `command` ([String](/ar/reference/data-types/string)) — البرنامج النصي أو الأمر الذي يُنفّذ لهذه UDF.
* `format` ([String](/ar/reference/data-types/string)) — تنسيق البيانات لعمليات الإدخال/الإخراج (مثل &#39;TabSeparated&#39; و&#39;JSONEachRow&#39;).
* `return_type` ([String](/ar/reference/data-types/string)) — نوع القيمة التي تُرجعها الدالة (مثل &#39;String&#39; و&#39;UInt64&#39;).
* `return_name` ([String](/ar/reference/data-types/string)) — معرّف اختياري لقيمة الإرجاع. يكون فارغًا إذا لم يُضبط.
* `argument_types` ([Array(String)](/ar/reference/data-types/array)) — مصفوفة بأنواع الوسيطات (مثل [&#39;String&#39; و&#39;UInt64&#39;]).
* `argument_names` ([Array(String)](/ar/reference/data-types/array)) — مصفوفة بأسماء الوسيطات. سلاسل فارغة للوسيطات غير المسمّاة.
* `max_command_execution_time` ([UInt64](/ar/reference/data-types/int-uint)) — الحد الأقصى لعدد الثواني لمعالجة كتلة بيانات. لنوع &#39;executable&#95;pool&#39; فقط.
* `command_termination_timeout` ([UInt64](/ar/reference/data-types/int-uint)) — عدد الثواني قبل إرسال SIGTERM إلى عملية الأمر.
* `command_read_timeout` ([UInt64](/ar/reference/data-types/int-uint)) — عدد المللي ثانية المخصصة للقراءة من stdout الخاص بالأمر.
* `command_write_timeout` ([UInt64](/ar/reference/data-types/int-uint)) — عدد المللي ثانية المخصصة للكتابة إلى stdin الخاص بالأمر.
* `pool_size` ([UInt64](/ar/reference/data-types/int-uint)) — عدد مثيلات عملية الأمر. لنوع &#39;executable&#95;pool&#39; فقط.
* `send_chunk_header` ([UInt8](/ar/reference/data-types/int-uint)) — ما إذا كان سيتم إرسال عدد الصفوف قبل كل جزء من البيانات (قيمة منطقية).
* `execute_direct` ([UInt8](/ar/reference/data-types/int-uint)) — ما إذا كان سيتم تنفيذ الأمر مباشرةً (1) أو عبر /bin/bash (0).
* `lifetime` ([UInt64](/ar/reference/data-types/int-uint)) — فترة إعادة التحميل بالثواني. تعني 0 تعطيل إعادة التحميل.
* `deterministic` ([UInt8](/ar/reference/data-types/int-uint)) — ما إذا كانت الدالة تُرجع النتيجة نفسها للوسيطات نفسها (قيمة منطقية).

{/*AUTOGENERATED_END*/}

<div id="example">
  ## مثال
</div>

اعرض جميع UDFs وحالة تحميلها:

```sql
SELECT
    name,
    load_status,
    type,
    command,
    return_type,
    argument_types
FROM system.user_defined_functions
FORMAT Vertical;
```

```response
Row 1:
──────
name:           my_sum_udf
load_status:    Success
type:           executable
command:        /var/lib/clickhouse/user_scripts/sum.py
return_type:    UInt64
argument_types: ['UInt64','UInt64']
```

العثور على UDFs الفاشلة:

```sql
SELECT
    name,
    loading_error_message
FROM system.user_defined_functions
WHERE load_status = 'Failed';
```
