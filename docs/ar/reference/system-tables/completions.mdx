## الوصف {#description}

يحتوي على قائمة برموز الإكمال.

## الأعمدة {#columns}

* `word` ([String](/ar/reference/data-types/string)) — رمز الإكمال.
* `context` ([String](/ar/reference/data-types/string)) — نوع الكيان المرتبط بالرمز (مثل جدول).
* `belongs` ([Nullable(String)](/ar/reference/data-types/nullable)) — الكيان الذي ينتمي إليه هذا الرمز (مثل اسم قاعدة البيانات المالكة).
