## الوصف {#description}

تتضمن قائمة بجميع دوال الجداول المتاحة وأوصافها.

## الأعمدة {#columns}

* `name` ([String](/ar/reference/data-types/string)) — اسم دالة الجدول.
* `description` ([String](/ar/reference/data-types/string)) — وصف موجز لدالة الجدول.
* `allow_readonly` ([UInt8](/ar/reference/data-types/int-uint)) — علامة تشير إلى ما إذا كان يمكن لمستخدم للقراءة فقط استخدام هذه الدالة.
