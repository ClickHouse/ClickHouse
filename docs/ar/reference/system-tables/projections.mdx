## الوصف {#description}

يحتوي على معلومات حول الإسقاطات الموجودة في جميع الجداول.

تُحسب قيم الأعمدة `total_rows` و`data_compressed_bytes` و`data_uncompressed_bytes` بجمعها عبر أجزاء البيانات النشطة في الجدول التي تحتوي على الإسقاط، ولذلك تبقى قيمها صفرًا إلى أن يُبنى الإسقاط، كأن يتم ذلك عبر عمليات الإدراج التي تُنفَّذ بعد إضافته أو عبر `ALTER TABLE ... MATERIALIZE PROJECTION`. لمعرفة حجم كل جزء إسقاط، راجع [system.projection&#95;parts](/ar/operations/system-tables/projection_parts).

## الأعمدة {#columns}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/reference/data-types/string)) — اسم الجدول.
* `name` ([String](/ar/reference/data-types/string)) — اسم الإسقاط.
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ar/reference/data-types/enum)) — نوع الإسقاط.
* `total_rows` ([UInt64](/ar/reference/data-types/int-uint)) — إجمالي عدد الصفوف.
* `data_compressed_bytes` ([UInt64](/ar/reference/data-types/int-uint)) — حجم البيانات المضغوطة بالبايتات.
* `data_uncompressed_bytes` ([UInt64](/ar/reference/data-types/int-uint)) — حجم البيانات بعد فك الضغط بالبايتات.
* `sorting_key` ([Array(String)](/ar/reference/data-types/array)) — مفتاح ترتيب الإسقاط.
* `query` ([String](/ar/reference/data-types/string)) — استعلام الإسقاط.
* `settings` ([Map(String, String)](/ar/reference/data-types/map)) — إعدادات الإسقاط.
