## الوصف

يتضمن معلومات حول [الأدوار](/ar/concepts/features/security/access-rights#role-management) التي تم تكوينها.

## الأعمدة

* `name` ([String](/ar/reference/data-types/string)) — اسم الدور.
* `id` ([UUID](/ar/reference/data-types/uuid)) — معرّف الدور.
* `storage` ([String](/ar/reference/data-types/string)) — مسار تخزين الأدوار. يُضبط في المعلَمة `access_control_path`.
