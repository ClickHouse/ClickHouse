<div id="description">
  ## الوصف
</div>

يتضمن معلومات عن [القواميس](/ar/reference/statements/create/dictionary).

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات التي تحتوي على القاموس المُنشأ بواسطة استعلام DDL. سلسلة فارغة للقواميس الأخرى.
* `name` ([String](/ar/reference/data-types/string)) — اسم القاموس.
* `uuid` ([UUID](/ar/reference/data-types/uuid)) — معرّف UUID للقاموس.
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/ar/reference/data-types/enum)) — حالة القاموس. القيم الممكنة: NOT&#95;LOADED — القاموس غير محمّل حاليًا في الذاكرة، LOADED — تم تحميل القاموس بنجاح، FAILED — تعذّر تحميل القاموس بسبب خطأ، LOADING — يجري تحميل القاموس الآن، LOADED&#95;AND&#95;RELOADING — تم تحميل القاموس بنجاح ويجري إعادة تحميله الآن (أسباب شائعة: استعلام SYSTEM RELOAD DICTIONARY، timeout، تغيّر إعدادات القاموس)، FAILED&#95;AND&#95;RELOADING — تعذّر تحميل القاموس بسبب خطأ ويجري تحميله الآن.
* `origin` ([String](/ar/reference/data-types/string)) — المسار إلى ملف الإعدادات الذي يصف القاموس.
* `type` ([String](/ar/reference/data-types/string)) — نوع تخصيص القاموس. تخزين القواميس في الذاكرة.
* `key.names` ([Array(String)](/ar/reference/data-types/array)) — مصفوفة بأسماء المفاتيح التي يوفرها القاموس.
* `key.types` ([Array(String)](/ar/reference/data-types/array)) — المصفوفة المقابلة لأنواع المفاتيح التي يوفرها القاموس.
* `attribute.names` ([Array(String)](/ar/reference/data-types/array)) — مصفوفة بأسماء السمات التي يوفرها القاموس.
* `attribute.types` ([Array(String)](/ar/reference/data-types/array)) — المصفوفة المقابلة لأنواع السمات التي يوفرها القاموس.
* `bytes_allocated` ([UInt64](/ar/reference/data-types/int-uint)) — مقدار RAM المخصص للقاموس.
* `hierarchical_index_bytes_allocated` ([UInt64](/ar/reference/data-types/int-uint)) — مقدار RAM المخصص للفهرس الهرمي.
* `query_count` ([UInt64](/ar/reference/data-types/int-uint)) — عدد الاستعلامات منذ تحميل القاموس أو منذ آخر إعادة تشغيل ناجحة.
* `hit_rate` ([Float64](/ar/reference/data-types/float)) — بالنسبة إلى قواميس cache، النسبة المئوية للاستخدامات التي كانت القيمة فيها موجودة في cache.
* `found_rate` ([Float64](/ar/reference/data-types/float)) — النسبة المئوية للاستخدامات التي عُثر فيها على القيمة.
* `element_count` ([UInt64](/ar/reference/data-types/int-uint)) — عدد العناصر المخزنة في القاموس.
* `load_factor` ([Float64](/ar/reference/data-types/float)) — نسبة الامتلاء في القاموس (وبالنسبة إلى قاموس hashed، نسبة الامتلاء في جدول hash).
* `source` ([String](/ar/reference/data-types/string)) — نص يصف مصدر بيانات القاموس.
* `lifetime_min` ([UInt64](/ar/reference/data-types/int-uint)) — الحد الأدنى لعمر القاموس في الذاكرة، وبعده يحاول ClickHouse إعادة تحميل القاموس (إذا تم تعيين invalidate&#95;query، فلا يحدث ذلك إلا إذا تغيّر). يُضبط بالثواني.
* `lifetime_max` ([UInt64](/ar/reference/data-types/int-uint)) — الحد الأقصى لعمر القاموس في الذاكرة، وبعده يحاول ClickHouse إعادة تحميل القاموس (إذا تم تعيين invalidate&#95;query، فلا يحدث ذلك إلا إذا تغيّر). يُضبط بالثواني.
* `loading_start_time` ([DateTime](/ar/reference/data-types/datetime)) — وقت بدء تحميل القاموس.
* `last_successful_update_time` ([DateTime](/ar/reference/data-types/datetime)) — وقت انتهاء تحميل القاموس أو تحديثه. يساعد في مراقبة المشكلات المتعلقة بمصادر القواميس والتحقيق في أسبابها.
* `error_count` ([UInt64](/ar/reference/data-types/int-uint)) — عدد الأخطاء منذ آخر تحميل ناجح. يساعد في مراقبة المشكلات المتعلقة بمصادر القواميس والتحقيق في أسبابها.
* `loading_duration` ([Float32](/ar/reference/data-types/float)) — مدة تحميل القاموس.
* `last_exception` ([String](/ar/reference/data-types/string)) — نص الخطأ الذي يحدث عند إنشاء القاموس أو إعادة تحميله إذا تعذّر إنشاؤه.
* `comment` ([String](/ar/reference/data-types/string)) — نص التعليق الخاص بالقاموس.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## مثال
</div>

اضبط القاموس:

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

تأكد من تحميل القاموس.

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
