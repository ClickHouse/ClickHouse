<div id="description">
  ## الوصف
</div>

معلومات حول [العروض المادية القابلة للتحديث](/ar/reference/statements/create/view#refreshable-materialized-view). تحتوي على جميع العروض المادية القابلة للتحديث، سواء أكانت هناك عملية تحديث جارية أم لا.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات التي يوجد فيها الجدول.
* `view` ([String](/ar/reference/data-types/string)) — اسم الجدول.
* `uuid` ([UUID](/ar/reference/data-types/uuid)) — معرّف UUID للجدول (قاعدة بيانات Atomic).
* `status` ([String](/ar/reference/data-types/string)) — حالة التحديث الحالية.
* `last_success_time` ([Nullable(DateTime)](/ar/reference/data-types/nullable)) — وقت بدء آخر تحديث ناجح. تكون القيمة NULL إذا لم يحدث أي تحديث ناجح منذ بدء تشغيل الخادم أو إنشاء الجدول.
* `last_success_duration_ms` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — مدة آخر تحديث.
* `last_refresh_time` ([Nullable(DateTime)](/ar/reference/data-types/nullable)) — وقت انتهاء آخر محاولة تحديث (إذا كان معلومًا)، أو وقت بدئها (إذا لم يكن معلومًا أو كانت لا تزال قيد التشغيل). تكون القيمة NULL إذا لم تحدث أي محاولات تحديث منذ بدء تشغيل الخادم أو إنشاء الجدول.
* `last_refresh_replica` ([String](/ar/reference/data-types/string)) — إذا كان التنسيق مفعّلًا، اسم النسخة المتماثلة التي أجرت محاولة التحديث الحالية (إذا كانت قيد التشغيل) أو السابقة (إذا لم تكن قيد التشغيل).
* `next_refresh_time` ([Nullable(DateTime)](/ar/reference/data-types/nullable)) — الوقت المجدول لبدء التحديث التالي. تكون القيمة NULL إذا لم يكن وقت التحديث التالي معلومًا حاليًا، مثلًا عند انتظار التبعيات (الحالة `WaitingForDependencies` أو `MissingDependencies`).
* `exception` ([String](/ar/reference/data-types/string)) — رسالة الخطأ من المحاولة السابقة إذا فشلت.
* `retry` ([UInt64](/ar/reference/data-types/int-uint)) — عدد المحاولات الفاشلة حتى الآن للتحديث الحالي. غير متاح إذا كانت الحالة `RunningOnAnotherReplica`.
* `progress` ([Nullable(Float64)](/ar/reference/data-types/nullable)) — مدى تقدّم التحديث الجاري أو آخر تحديث مكتمل على النسخة المتماثلة المحددة، بين 0 و1. تكون القيمة NULL إذا كانت الحالة `RunningOnAnotherReplica` أو لم يكن التحديث قيد التشغيل.
* `read_rows` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — عدد الصفوف التي قرأها التحديث الجاري أو آخر تحديث مكتمل على النسخة المتماثلة المحددة. تكون القيمة NULL إذا كانت الحالة `RunningOnAnotherReplica`.
* `read_bytes` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — عدد البايتات التي قرأها التحديث الجاري أو آخر تحديث مكتمل على النسخة المتماثلة المحددة. تكون القيمة NULL إذا كانت الحالة `RunningOnAnotherReplica`
* `total_rows` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — العدد الإجمالي المقدّر للصفوف التي يجب أن يقرأها التحديث الجاري أو آخر تحديث مكتمل على النسخة المتماثلة المحددة. تكون القيمة NULL إذا كانت الحالة `RunningOnAnotherReplica`
* `written_rows` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — عدد الصفوف التي كتبها التحديث الجاري أو آخر تحديث مكتمل على النسخة المتماثلة المحددة. تكون القيمة NULL إذا كانت الحالة `RunningOnAnotherReplica`
* `written_bytes` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — عدد البايتات التي كتبها التحديث الجاري أو آخر تحديث مكتمل على النسخة المتماثلة المحددة. تكون القيمة NULL إذا كانت الحالة `RunningOnAnotherReplica`

{/*AUTOGENERATED_END*/}

  ## مثال

```sql
    last_refresh_time,
    next_refresh_time

```
