## الوصف {#description}

يتضمن قائمة بمحركات قواعد البيانات التي يدعمها الخادم.

## الأعمدة {#columns}

* `name` ([String](/ar/reference/data-types/string)) — اسم محرك قاعدة البيانات.
* `description` ([String](/ar/reference/data-types/string)) — وصف عام لوظيفة محرك قاعدة البيانات.
* `syntax` ([String](/ar/reference/data-types/string)) — كيفية تحديد محرك قاعدة البيانات في العبارة ENGINE ضمن استعلام CREATE DATABASE.
* `examples` ([String](/ar/reference/data-types/string)) — أمثلة استخدام.
* `introduced_in` ([String](/ar/reference/data-types/string)) — إصدار ClickHouse الذي طُرح فيه محرك قاعدة البيانات لأول مرة، بصيغة major.minor.
* `related` ([Array(String)](/ar/reference/data-types/array)) — أسماء محركات قواعد البيانات ذات الصلة.

## مثال {#example}

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

```text title="Response"
┌─name─────┐
│ Atomic   │
│ Ordinary │
└──────────┘
```
