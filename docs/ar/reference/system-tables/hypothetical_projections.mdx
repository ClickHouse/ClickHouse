يسرد كل إسقاط افتراضي (what-if) معرَّف في الجلسة الحالية. راجع [`CREATE HYPOTHETICAL PROJECTION`](/ar/reference/statements/hypothetical-projection#create-hypothetical-projection) و[`EXPLAIN WHATIF`](/ar/reference/statements/explain#explain-whatif).

تقتصر المحتويات على نطاق الجلسة: فكل اتصال لا يرى سوى إسقاطاته الافتراضية الخاصة، ويكون الجدول فارغًا إذا لم يُنشأ أي منها في الجلسة الحالية.

يجري تحديد `(database, table)` الحاليين عبر معرّف UUID في وقت تنفيذ الاستعلام، لذا فهما يعكسان عمليات `RENAME TABLE`، كما تُخفى تلقائيًا الإدخالات الخاصة بالجداول المحذوفة.

## الأعمدة {#columns}

{/*AUTOGENERATED_START*/}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات
* `table` ([String](/ar/reference/data-types/string)) — اسم الجدول
* `name` ([String](/ar/reference/data-types/string)) — اسم الإسقاط
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ar/reference/data-types/enum)) — نوع الإسقاط
* `sorting_key` ([Array(String)](/ar/reference/data-types/array)) — مفتاح فرز الإسقاط
* `query` ([String](/ar/reference/data-types/string)) — استعلام SELECT الخاص بالإسقاط، ويكون فارغًا في حالة صيغة INDEX ... TYPE ...
* `definition` ([String](/ar/reference/data-types/string)) — التصريح الكامل للإسقاط كما هو مكتوب
* `settings` ([Map(String, String)](/ar/reference/data-types/map)) — إعدادات الإسقاط المأخوذة من WITH SETTINGS

{/*AUTOGENERATED_END*/}

**مثال**

```sql
CREATE HYPOTHETICAL PROJECTION p_by_b ON t (SELECT a, b ORDER BY b);
SELECT name, type, sorting_key FROM system.hypothetical_projections;
```

```text
┌─name───┬─type───┬─sorting_key─┐
│ p_by_b │ Normal │ ['b']       │
└────────┴────────┴─────────────┘
```
