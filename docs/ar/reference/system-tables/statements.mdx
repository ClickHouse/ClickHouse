<div id="description">
  ## الوصف
</div>

يتضمن قائمة بجميع عبارات SQL في ClickHouse.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ar/reference/data-types/string)) — اسم عبارة SQL.
* `syntax` ([String](/ar/reference/data-types/string)) — صياغة التعليمة.
* `description` ([String](/ar/reference/data-types/string)) — وصف لما تنفّذه التعليمة، مع أمثلة على الاستخدام.
* `parent_name` ([String](/ar/reference/data-types/string)) — اسم التعليمة الحاوية، مثل SELECT لعبارة WHERE. يكون فارغًا للتعليمة ذات المستوى الأعلى.
* `related` ([Array(String)](/ar/reference/data-types/array)) — أسماء التعليمات ذات الصلة.

{/*AUTOGENERATED_END*/}
