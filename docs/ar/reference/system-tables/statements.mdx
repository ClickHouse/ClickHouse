## الوصف {#description}

يتضمن قائمة بجميع عبارات SQL في ClickHouse.

## الأعمدة {#columns}

* `name` ([String](/ar/reference/data-types/string)) — اسم عبارة SQL.
* `syntax` ([String](/ar/reference/data-types/string)) — صياغة العبارة.
* `description` ([String](/ar/reference/data-types/string)) — وصف لما تنفّذه العبارة، مع أمثلة على الاستخدام.
* `parent_name` ([String](/ar/reference/data-types/string)) — اسم العبارة الحاوية، مثل SELECT لعبارة WHERE. يكون فارغًا للعبارة ذات المستوى الأعلى.
* `related` ([Array(String)](/ar/reference/data-types/array)) — أسماء العبارات ذات الصلة.
