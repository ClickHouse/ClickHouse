## الوصف {#description}

لا يكون الجدول موجودًا إلا إذا تم تكوين ClickHouse Keeper أو ZooKeeper. ويعرض جدول `system.zookeeper` البيانات من عناقيد Keeper المعرّفة في التكوين.
يجب أن يتضمن الاستعلام إما شرط `path =`   أو شرط `path IN`  ضمن عبارة `WHERE` كما هو موضح أدناه. ويتوافق ذلك مع مسار العُقد الفرعية التي تريد جلب البيانات لها.

يعرض الاستعلام `SELECT * FROM system.zookeeper WHERE path = '/clickhouse'` البيانات لجميع العُقد الفرعية ضمن العُقدة `/clickhouse`.
ولعرض البيانات لجميع العُقد الجذرية، اكتب path = &#39;/&#39;.
إذا كان المسار المحدد في &#39;path&#39; غير موجود، فسيتم طرح استثناء.

يعرض الاستعلام `SELECT * FROM system.zookeeper WHERE path IN ('/', '/clickhouse')` البيانات لجميع العُقد الفرعية ضمن العُقدتين `/` و `/clickhouse`.
إذا كانت مجموعة &#39;path&#39; المحددة تتضمن مسارًا غير موجود، فسيتم طرح استثناء.
ويمكن استخدامه لتنفيذ دفعة من استعلامات Keeper path.

يعرض الاستعلام `SELECT * FROM system.zookeeper WHERE path = '/clickhouse' AND zookeeperName = 'auxiliary_cluster'` البيانات في عنقود ZooKeeper ‏`auxiliary_cluster`.
إذا لم يكن `auxiliary_cluster` المحدد موجودًا، فسيتم طرح استثناء.

## Columns {#columns}

* `name` ([String](/ar/reference/data-types/string)) — اسم الـ عقدة.
* `value` ([String](/ar/reference/data-types/string)) — قيمة الـ عقدة.
* `zookeeperName` ([String](/ar/reference/data-types/string)) — اسم عنقود ZooKeeper الافتراضي أو أحد عناقيد ZooKeeper المساعدة.
* `czxid` ([Int64](/ar/reference/data-types/int-uint)) — معرّف الـ transaction التي أنشأت الـ عقدة.
* `mzxid` ([Int64](/ar/reference/data-types/int-uint)) — معرّف آخر transaction غيّرت الـ عقدة.
* `ctime` ([DateTime](/ar/reference/data-types/datetime)) — وقت إنشاء الـ عقدة.
* `mtime` ([DateTime](/ar/reference/data-types/datetime)) — وقت آخر تعديل على الـ عقدة.
* `version` ([Int32](/ar/reference/data-types/int-uint)) — إصدار الـ عقدة: عدد المرات التي تغيّرت فيها الـ عقدة.
* `cversion` ([Int32](/ar/reference/data-types/int-uint)) — عدد العناصر المنحدرة المضافة أو المحذوفة.
* `aversion` ([Int32](/ar/reference/data-types/int-uint)) — عدد التغييرات على الـ ACL.
* `ephemeralOwner` ([Int64](/ar/reference/data-types/int-uint)) — بالنسبة إلى الـ عقد من النوع ephemeral، معرّف الـ session التي تملك هذه الـ عقدة.
* `dataLength` ([Int32](/ar/reference/data-types/int-uint)) — حجم القيمة.
* `numChildren` ([Int32](/ar/reference/data-types/int-uint)) — عدد العناصر المنحدرة.
* `pzxid` ([Int64](/ar/reference/data-types/int-uint)) — معرّف آخر transaction حذفت أو أضافت عناصر منحدرة.
* `path` ([String](/ar/reference/data-types/string)) — مسار الـ عقدة.
