## الوصف {#description}

تحتوي على معلومات عن ملفات البيانات المخزنة على الأقراص البعيدة (مثل S3 وAzure Blob Storage)، بما في ذلك الربط بين مسارات البيانات الوصفية المحلية ومسارات كائنات blob البعيدة.

يمثل كل صف كائن blob بعيدًا واحدًا مرتبطًا بملف من ملفات البيانات.

## الأعمدة {#columns}

* `disk_name` ([String](/ar/reference/data-types/string)) — اسم القرص.
* `path` ([String](/ar/reference/data-types/string)) — مسار القرص.
* `metadata_type` ([String](/ar/reference/data-types/string)) — نوع تخزين البيانات الوصفية للقرص (مثل `Local`، `PlainRewritable`).
* `cache_base_path` ([String](/ar/reference/data-types/string)) — الدليل الأساسي لملفات ذاكرة التخزين المؤقت.
* `local_path` ([String](/ar/reference/data-types/string)) — مسار ملف ClickHouse، ويُستخدم أيضًا كمسار للبيانات الوصفية.
* `remote_path` ([String](/ar/reference/data-types/string)) — مسار blob في تخزين الكائنات المرتبط بملف ClickHouse.
* `size` ([UInt64](/ar/reference/data-types/int-uint)) — حجم الملف (بعد الضغط).
* `common_prefix_for_blobs` ([String](/ar/reference/data-types/string)) — البادئة المشتركة لـ blob في تخزين الكائنات.
* `cache_paths` ([Array(String)](/ar/reference/data-types/array)) — ملفات ذاكرة التخزين المؤقت لـ blob المقابل.
* `last_modified` ([DateTime](/ar/reference/data-types/datetime)) — وقت آخر تعديل للبيانات الوصفية للملف. تكون القيمة صفرًا إذا كان تخزين البيانات الوصفية لا يسجّل هذه المعلومة.

## مثال {#example}

```sql
SELECT * FROM system.remote_data_paths LIMIT 1 FORMAT Vertical;
```

```text
remote_path:            abc123/all_0_0_0/data.bin
size:                   1048576
common_prefix_for_blobs:
cache_paths:            ['/var/lib/clickhouse/disks/s3_cache/a1/b2/c3d4e5f6']
```
