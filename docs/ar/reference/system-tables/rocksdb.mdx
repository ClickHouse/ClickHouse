## الوصف {#description}

يحتوي على قائمة بالمقاييس التي يكشف عنها RocksDB المضمّن.

## الأعمدة {#columns}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/reference/data-types/string)) — اسم الجدول الذي يستخدم المحرك StorageEmbeddedRocksDB.
* `name` ([String](/ar/reference/data-types/string)) — اسم المقياس.
* `value` ([UInt64](/ar/reference/data-types/int-uint)) — قيمة المقياس.
