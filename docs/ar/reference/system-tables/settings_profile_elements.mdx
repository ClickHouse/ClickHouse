<div id="description">
  ## الوصف
</div>

يصف محتوى ملف تعريف الإعداد:

* القيود.
* الأدوار والمستخدمون الذين ينطبق عليهم ملف تعريف الإعداد هذا.
* ملفات تعريف الإعداد الأصلية.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `profile_name` ([Nullable(String)](/ar/reference/data-types/nullable)) — اسم ملف تعريف الإعدادات.
* `user_name` ([Nullable(String)](/ar/reference/data-types/nullable)) — اسم المستخدم.
* `role_name` ([Nullable(String)](/ar/reference/data-types/nullable)) — اسم الدور.
* `index` ([UInt64](/ar/reference/data-types/int-uint)) — الرقم التسلسلي لعنصر في ملف تعريف الإعدادات.
* `setting_name` ([Nullable(String)](/ar/reference/data-types/nullable)) — اسم الإعداد.
* `value` ([Nullable(String)](/ar/reference/data-types/nullable)) — قيمة الإعداد.
* `min` ([Nullable(String)](/ar/reference/data-types/nullable)) — الحد الأدنى لقيمة الإعداد. NULL إذا لم يُضبط.
* `max` ([Nullable(String)](/ar/reference/data-types/nullable)) — الحد الأقصى لقيمة الإعداد. NULL إذا لم يُضبط.
* `writability` ([Nullable(Enum8(&#39;WRITABLE&#39; = 0, &#39;CONST&#39; = 1, &#39;CHANGEABLE&#95;IN&#95;READONLY&#39; = 2))](/ar/reference/data-types/nullable)) — خاصية توضح ما إذا كان يمكن تغيير الإعداد أم لا.
* `inherit_profile` ([Nullable(String)](/ar/reference/data-types/nullable)) — ملف تعريف أصلي لملف تعريف الإعدادات هذا. NULL إذا لم يُضبط. سيرث ملف تعريف الإعدادات جميع قيم الإعدادات وقيودها (min، max، readonly) من ملفات التعريف الأصلية.

{/*AUTOGENERATED_END*/}
