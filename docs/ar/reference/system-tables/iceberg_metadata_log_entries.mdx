## الوصف {#description}

يحتوي جدول النظام هذا على ملفات البيانات الوصفية لجداول Iceberg الموجودة في ClickHouse، بواقع صف واحد لكل ملف بيانات وصفية. ويكون هذا الجدول فارغًا إذا لم تكن لديك أي جداول Iceberg في ClickHouse.

## الأعمدة {#columns}

* `database` ([String](/ar/reference/data-types/string)) — اسم قاعدة البيانات.
* `table` ([String](/ar/reference/data-types/string)) — اسم الجدول.
* `timestamp` ([DateTime64(3)](/ar/reference/data-types/datetime64)) — تاريخ ووقت اعتماد ملف البيانات الوصفية هذا بوصفه الملف الحالي.
* `file` ([String](/ar/reference/data-types/string)) — مسار ملف البيانات الوصفية.
* `latest_snapshot_id` ([Nullable(UInt64)](/ar/reference/data-types/nullable)) — معرّف أحدث لقطة في وقت ملف البيانات الوصفية هذا.
* `latest_schema_id` ([Nullable(Int32)](/ar/reference/data-types/nullable)) — معرّف المخطط لأحدث لقطة.
* `latest_sequence_number` ([Nullable(Int64)](/ar/reference/data-types/nullable)) — الرقم التسلسلي لأحدث لقطة.
