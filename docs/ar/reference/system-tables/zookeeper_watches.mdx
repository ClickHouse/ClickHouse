## الوصف {#description}

يعرض [مراقبات](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches) النشطة حاليًا والمسجَّلة من خادم ClickHouse هذا على عُقد ZooKeeper (بما في ذلك مثيلات ZooKeeper الإضافية). يمثّل كل صف مراقبة واحدة.

**التوافر**

لا يوجد `system.zookeeper_watches` إلا عند تهيئة ClickHouse Keeper أو ZooKeeper. أما على الخوادم التي لم تُهيَّأ فيها أي منهما، فلا يوجد الجدول، وستفشل الاستعلامات الموجَّهة إليه بالخطأ `UNKNOWN_TABLE`.

## الأعمدة {#columns}

* `zookeeper_name` ([String](/ar/reference/data-types/string)) — اسم اتصال ZooKeeper (&quot;default&quot; للاتصال الرئيسي، أو الاسم المساعد).
* `create_time` ([DateTime](/ar/reference/data-types/datetime)) — وقت إنشاء المراقبة.
* `create_time_microseconds` ([DateTime64(6)](/ar/reference/data-types/datetime64)) — وقت إنشاء المراقبة بدقة الميكروثانية.
* `path` ([String](/ar/reference/data-types/string)) — مسار ZooKeeper الخاضع للمراقبة.
* `session_id` ([Int64](/ar/reference/data-types/int-uint)) — معرّف الجلسة للاتصال الذي سجّل المراقبة.
* `request_xid` ([Int64](/ar/reference/data-types/int-uint)) — XID للطلب الذي أنشأ المراقبة.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/ar/reference/data-types/enum)) — العملية التي أنشأت المراقبة.
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/ar/reference/data-types/enum)) — نوع المراقبة: Children (قائمة)، أو Exists، أو Data (جلب).
