<div id="description">
  ## الوصف
</div>

يحتوي على محتويات ملفات البيانات الوصفية لـ Delta.

يمكن تنفيذ TRUNCATE أو drop لهذا الجدول بأمان في أي وقت.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `hostname` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — اسم مضيف الخادم الذي ينفّذ الاستعلام.
* `event_date` ([Date](/ar/reference/data-types/date)) — تاريخ الإدخال.
* `event_time` ([DateTime](/ar/reference/data-types/datetime)) — وقت الحدث.
* `query_id` ([String](/ar/reference/data-types/string)) — معرّف الاستعلام.
* `table_path` ([String](/ar/reference/data-types/string)) — مسار الجدول.
* `file_path` ([String](/ar/reference/data-types/string)) — مسار الملف.
* `content` ([String](/ar/reference/data-types/string)) — المحتوى بتنسيق JSON.
