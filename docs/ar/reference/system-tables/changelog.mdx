## الوصف {#description}

يحتوي على إدخالات سجل التغييرات المنسَّق الخاص بـ ClickHouse (ملف `CHANGELOG.md` في المستودع)، بواقع صف واحد لكل إدخال في كل إصدار ميزات، مما يتيح الاستعلام عن ملاحظات الإصدار باستخدام SQL.

## الأعمدة {#columns}

* `version` ([Tuple(major UInt16, minor UInt8, patch UInt16)](/ar/reference/data-types/tuple)) — رقم الإصدار الذي ينتمي إليه الإدخال، في صورة Tuple قابلة للمقارنة. يقتصر سجل التغييرات المُنتقى على إصدارات الميزات، لذا تكون قيمة `patch` دائمًا 0.
* `release_date` ([Date](/ar/reference/data-types/date)) — تاريخ الإصدار.
* `is_lts` ([UInt8](/ar/reference/data-types/int-uint)) — تكون القيمة 1 إذا كان الإصدار ذا دعم طويل الأمد.
* `category` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — قسم سجل التغييرات الذي ينتمي إليه الإدخال، مثل &#39;New Feature&#39; و&#39;Performance Improvement&#39; و&#39;Bug Fix&#39;.
* `description` ([String](/ar/reference/data-types/string)) — نص الإدخال في سجل التغييرات.
* `pull_requests` ([Array(UInt32)](/ar/reference/data-types/array)) — أرقام طلبات السحب التي يشير إليها الإدخال.
* `authors` ([Array(String)](/ar/reference/data-types/array)) — مؤلفو طلبات السحب المشار إليها.

## مثال {#example}

ابحث عن أحدث التغييرات المتعلقة بـ JSON، مرتبةً من الإصدار الأحدث إلى الأقدم:

```sql
SELECT version, category, description
FROM system.changelog
WHERE description ILIKE '%JSON%' AND version >= (26, 1, 0)
ORDER BY version DESC
LIMIT 3
```
