<div id="description">
  ## الوصف
</div>

يحتوي على قائمة بجميع معالجات HTTP المعرّفة بلغة SQL والتي أُنشئت باستخدام CREATE HANDLER.

<div id="columns">
  ## الأعمدة
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ar/reference/data-types/string)) — اسم المعالج.
* `protocol` ([Nullable(String)](/ar/reference/data-types/nullable)) — البروتوكول القابل للتركيب الذي يقتصر عليه المعالج، أو NULL إذا كان المعالج نشطًا على جميع نقاط نهاية HTTP (المنافذ المضمّنة `http`/`https` وكل مستمع لبروتوكول قابل للتركيب من نوع HTTP).
* `url_match_type` ([String](/ar/reference/data-types/string)) — كيفية مطابقة URL: مطابقة تامة أو بادئة أو تعبير نمطي.
* `url` ([String](/ar/reference/data-types/string)) — نمط URL الذي يطابقه المعالج.
* `methods` ([Array(String)](/ar/reference/data-types/array)) — طُرق HTTP المسموح بها.
* `type` ([String](/ar/reference/data-types/string)) — نوع المعالج (لا يُدعم سوى `query`).
* `query` ([String](/ar/reference/data-types/string)) — استعلام SQL الذي ينفذه المعالج. تُخفى الأسرار ما لم يكن المستخدم مخوّلًا برؤيتها.
* `create_query` ([String](/ar/reference/data-types/string)) — عبارة CREATE HANDLER. تُخفى الأسرار ما لم يكن المستخدم مخوّلًا برؤيتها.

{/*AUTOGENERATED_END*/}
