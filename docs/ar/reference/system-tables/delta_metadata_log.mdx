## الوصف {#purpose}

يسجّل جدول `system.delta_lake_metadata_log` أحداث الوصول إلى البيانات الوصفية وتحليلها لجداول Delta Lake التي يقرأها ClickHouse. ويوفّر معلومات مفصلة عن كل ملف بيانات وصفية، ما يجعله مفيدًا لاستكشاف الأخطاء وإصلاحها، والتدقيق، وفهم تطور بنية جداول Delta.

يسجّل هذا الجدول كل ملف بيانات وصفية يُقرأ من جداول Delta Lake. ويساعد المستخدمين على تتبّع كيفية تفسير ClickHouse للبيانات الوصفية لجداول Delta وتشخيص المشكلات المرتبطة بتطور المخطط، أو تحديد اللقطة، أو تخطيط الاستعلام.

هذا الجدول مخصّص أساسًا لأغراض استكشاف الأخطاء وإصلاحها.

### التحكم في مستوى تفصيل السجل {#controlling-log-verbosity}

يمكنك التحكم في أحداث البيانات الوصفية التي تُسجَّل باستخدام الإعداد [`delta_lake_log_metadata`](/ar/reference/settings/session-settings/delta-lake#delta_lake_log_metadata).

لتسجيل جميع البيانات الوصفية المستخدمة في الاستعلام الحالي:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

من الآمن تنفيذ TRUNCATE على هذا الجدول أو حذفه في أي وقت.

## الأعمدة {#columns}

* `hostname` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — اسم مضيف الخادم الذي ينفّذ الاستعلام.
* `clickhouse_version` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — إصدار خادم ClickHouse الذي أنتج الصف.
* `system_processor` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — معمارية المعالج لخادم ClickHouse الذي أنتج الصف.
* `event_date` ([Date](/ar/reference/data-types/date)) — تاريخ الإدخال.
* `event_time` ([DateTime](/ar/reference/data-types/datetime)) — وقت الحدث.
* `query_id` ([String](/ar/reference/data-types/string)) — معرّف الاستعلام.
* `table_path` ([String](/ar/reference/data-types/string)) — مسار الجدول.
* `file_path` ([String](/ar/reference/data-types/string)) — مسار الملف.
* `content` ([String](/ar/reference/data-types/string)) — المحتوى بتنسيق JSON.
