## الوصف {#description}

يتضمن قائمة بالمناطق الزمنية التي يدعمها خادم ClickHouse. وقد تختلف هذه القائمة من المناطق الزمنية حسب إصدار ClickHouse.

## الأعمدة {#columns}

* `time_zone` ([String](/ar/reference/data-types/string)) — قائمة بالمناطق الزمنية المدعومة.

## مثال {#example}

```sql
SELECT * FROM system.time_zones LIMIT 10
```

```text
┌─time_zone──────────┐
│ Africa/Abidjan     │
│ Africa/Accra       │
│ Africa/Addis_Ababa │
│ Africa/Algiers     │
│ Africa/Asmara      │
│ Africa/Asmera      │
│ Africa/Bamako      │
│ Africa/Bangui      │
│ Africa/Banjul      │
│ Africa/Bissau      │
└────────────────────┘
```
