## الوصف {#description}

يعرض هذا الجدول تحذيرات تتعلق بـ ClickHouse server.
وتُدمج التحذيرات من النوع نفسه في تحذير واحد.
على سبيل المثال، إذا تجاوز عدد قواعد البيانات المرفقة N عتبة قابلة للتهيئة T، فسيُعرض إدخال واحد يحتوي على القيمة الحالية N بدلاً من N إدخالاً منفصلاً.
وإذا انخفضت القيمة الحالية إلى ما دون العتبة، فيُحذف الإدخال من الجدول.

يمكن تهيئة الجدول عبر الإعدادات التالية:

* [max&#95;table&#95;num&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/ar/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/ar/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## الأعمدة {#columns}

* `message` ([String](/ar/reference/data-types/string)) — رسالة تحذير صادرة من ClickHouse server.
* `message_format_string` ([LowCardinality(String)](/ar/reference/data-types/lowcardinality)) — سلسلة تنسيق استُخدمت لتنسيق الرسالة.

## أمثلة {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
