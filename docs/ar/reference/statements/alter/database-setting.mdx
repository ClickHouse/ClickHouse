يغيّر إعدادات محرك قاعدة البيانات. وتختلف الإعدادات القابلة للتغيير باختلاف المحرك؛ إذ لا تدعم جميع المحركات أو الإعدادات التعديل بعد إنشاء قاعدة البيانات.

تغيّر هذه العبارة إعدادات محرك قاعدة البيانات، لا إعدادات الجلسة ولا القيم الافتراضية للجداول في قاعدة البيانات.

## الصيغة {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

استخدم `ON CLUSTER` لتنفيذ العبارة على جميع المضيفات في العنقود المحدد.
تتطلب هذه العبارة امتياز `ALTER DATABASE SETTINGS`.

## الإعدادات المدعومة {#supported-settings}

راجع وثائق محرك قاعدة البيانات للاطلاع على إعداداته وقيوده. على سبيل المثال:

* يدعم المحركان [`Atomic`](/ar/reference/engines/database-engines/atomic) و[`Ordinary`](/ar/reference/engines/database-engines/ordinary) تغيير `max_tables`.
* يدعم [`MaterializedPostgreSQL`](/ar/reference/engines/database-engines/materialized-postgresql) تغيير بعض إعدادات replication، مثل `materialized_postgresql_max_block_size`.
* يدعم [`DataLakeCatalog`](/ar/reference/engines/database-engines/datalake) تغيير بعض إعدادات الـ catalog، وتتوقف الإعدادات المتاحة على نوع الـ catalog.

يؤدي استخدام محرك أو إعداد غير مدعوم إلى إطلاق استثناء.

## مثال {#example}

تغيير الحد الأقصى لعدد الجداول في قاعدة بيانات من نوع `Atomic`:

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

اضبط `max_tables` على `0` لإلغاء هذا الحد المفروض على مستوى قاعدة البيانات:

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
