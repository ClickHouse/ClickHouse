تُعيد عبارة `SHUFFLE` صفوف نتيجة الاستعلام بترتيب عشوائي منتظم. وتُستخدم بدلاً من عبارة [ORDER BY](/ar/reference/statements/select/order-by)، ولا يمكن استخدامهما معاً.

تُعيد هذه العبارة النتيجة نفسها التي تُعيدها `ORDER BY rand()`، لكنها تعمل في زمن O(n) بدلاً من O(n * log(n)).

يمكن استخدام `SHUFFLE` من دون `LIMIT` لترتيب جميع الصفوف عشوائياً، أو مع `LIMIT n` لأخذ عينة عشوائية منتظمة من `n` صفاً (تُعاد هي الأخرى بترتيب عشوائي). وعند استخدام `LIMIT n`، يحتفظ كل دفق بـ`n` صفاً فقط، ولذلك يبقى استخدام الذاكرة O(n) أياً كان عدد الصفوف في نتيجة الاستعلام. ويمكن استخدام `OFFSET` و`LIMIT BY` كما مع `ORDER BY`.

<Note>
  هذه ميزة تجريبية. لتمكينها، استخدم الإعداد [`allow_experimental_shuffle_query`](/ar/reference/settings/session-settings#allow_experimental_shuffle_query).
</Note>

## تفاصيل التنفيذ {#implementation-details}

تُتخذ الاختيارات العشوائية لحظة الحاجة إليها: إذ لا تُولَّد أي قيم عشوائية للصفوف ولا تُخزَّن مسبقًا. بدون `LIMIT`، يُرسَل كل صف إلى دفق يُختار عشوائيًا من بين `max_threads` دفقًا، ثم يُخلط كل دفق بالتوازي باستخدام خوارزمية Fisher-Yates (على أجزاء تتسع لها ذاكرة التخزين المؤقت لوحدة CPU)، وبعد ذلك تُضم الدفقات بعضها إلى بعض. ومع `LIMIT n`، يحتفظ كل دفق بعينة عشوائية منتظمة مكوّنة من `n` صف باستخدام أخذ العينات بطريقة الخزان (reservoir sampling)، وهي طريقة تتخطى الصفوف التي لا يمكن أن تدخل العينة دون فحصها، ثم تُدمج العينات: إذ يُحدَّد عدد الصفوف المأخوذة من كل دفق بأخذ عينات دون إرجاع من أعداد صفوف الدفقات. وفي الاستعلام الموزّع، تخلط الخوادم البعيدة بياناتها وترفق بالصفوف مفاتيح عشوائية مرتّبة، ثم يدمج المُبادِر الدفقات المخلوطة وفقًا لهذه المفاتيح، وهو ما يستهلك ذاكرة بمقدار O(1).

بدون `LIMIT`، يحتفظ `SHUFFLE` بجميع الصفوف في الذاكرة. وخلافًا لـ `ORDER BY`، فإنه لا يرحّل البيانات إلى القرص.

يمكن تنفيذ `ORDER BY rand()` و`ORDER BY rand64()` بالطريقة نفسها التي يُنفَّذ بها `SHUFFLE` (عبر الإعداد `query_plan_use_shuffle_for_order_by_rand`) عندما لا تُستخدم القيمة العشوائية في أي موضع آخر من الاستعلام ويكون الفرز الخارجي معطّلًا. أما عند تهيئة الفرز الخارجي، فيُعطَّل هذا التحسين حتى مع `LIMIT` منتهٍ، لأن العينة قد تتجاوز سعة الذاكرة مع ذلك، في حين لا يستطيع `SHUFFLE` ترحيل البيانات إلى القرص. ويُبقي `ORDER BY rand64()` مع حدٍّ منتهٍ على الفرز للحفاظ على جميع بتات القيم العشوائية.

## أمثلة {#examples}

```sql
SET allow_experimental_shuffle_query = 1;

SELECT number FROM numbers(5) SHUFFLE;
```

```text
┌─number─┐
│      3 │
│      0 │
│      4 │
│      1 │
│      2 │
└────────┘
```

عينة عشوائية من ثلاثة صفوف:

```sql
SELECT number FROM numbers(1000000) SHUFFLE LIMIT 3;
```

```text
┌─number─┐
│ 493721 │
│  20857 │
│ 871324 │
└────────┘
```

`SHUFFLE` رمز يأتي بعد عبارة `FROM`. ولاستخدام `shuffle` اسمًا بديلًا لجدول، اكتب `AS shuffle`.
