يسمح بتنفيذ عدة عبارات بالتوازي.

## الصيغة {#syntax}

```sql
statement1 PARALLEL WITH statement2 [PARALLEL WITH statement3 ...]
```

ينفّذ العبارات `statement1` و`statement2` و`statement3` و... بالتوازي مع بعضها البعض. ولا يمكن الجمع إلا بين العبارات التي لا تُرجع مجموعة نتائج ولا تتوقع بيانات إدخال، راجع [القيود](#restrictions).

قد يكون تنفيذ العبارات بالتوازي أسرع من تنفيذ العبارات نفسها بالتتابع في كثير من الحالات. على سبيل المثال، من المرجّح أن يكون `statement1 PARALLEL WITH statement2 PARALLEL WITH statement3` أسرع من `statement1; statement2; statement3`.

## أمثلة {#examples}

ينشئ جدولين بالتوازي:

```sql
CREATE TABLE table1(x Int32) ENGINE = MergeTree ORDER BY tuple()
PARALLEL WITH
CREATE TABLE table2(y String) ENGINE = MergeTree ORDER BY tuple();
```

يحذف جدولين بالتوازي:

```sql
DROP TABLE table1
PARALLEL WITH
DROP TABLE table2;
```

## القيود {#restrictions}

تُرفَض أي عبارة تُعيد مجموعة نتائج، مثل `SELECT`، أو تتوقع بيانات إدخال، ويظهر حينها الخطأ `INCORRECT_QUERY`.

أما عبارات DDL المنفَّذة باستخدام [`ON CLUSTER`](/ar/reference/statements/distributed-ddl) أو عبر سجل DDL لقاعدة بيانات [`Replicated`](/ar/reference/engines/database-engines/replicated)، فتُعيد جدول حالة، ولذلك تُرفَض هي أيضًا، لكن لا يحدث ذلك إلا بعد إرسالها إلى المضيفين، الذين يمضون في تنفيذها رغم ذلك. ويمكن دمجها إذا كانت قيمة [`distributed_ddl_output_mode`](/ar/reference/settings/session-settings/distributed-ddl#distributed_ddl_output_mode) هي `none` أو `none_only_active`:

```sql
SET distributed_ddl_output_mode = 'none';

CREATE TABLE table1 ON CLUSTER default (x Int32) ENGINE = MergeTree ORDER BY tuple()
PARALLEL WITH
CREATE TABLE table2 ON CLUSTER default (y String) ENGINE = MergeTree ORDER BY tuple();
```

## الإعدادات {#settings}

يحدّد الإعداد [max&#95;threads](/ar/reference/settings/session-settings/max-threads#max_threads) عدد سلاسل التنفيذ التي يتم إنشاؤها.

## مقارنة مع UNION {#comparison-with-union}

تُعد العبارة `PARALLEL WITH` مشابهة إلى حدّ ما لـ [UNION](/ar/reference/statements/select/union)، إذ تنفّذ أيضًا عواملها بالتوازي. ومع ذلك، توجد بعض الاختلافات:

* لا تُرجع `PARALLEL WITH` أي نتائج من تنفيذ عواملها، ولا يمكنها إلا إعادة إطلاق استثناء منها إذا وُجد؛
* تجمع `PARALLEL WITH` بين عبارات لا تُرجع مجموعة نتائج ولا تتوقع بيانات إدخال، في حين تجمع `UNION` بين استعلامات `SELECT`.
