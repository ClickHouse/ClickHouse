```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

تُرجِع عمودًا واحدًا من النوع `UInt8` يحتوي على قيمة واحدة هي `0` إذا لم يكن الجدول أو قاعدة البيانات موجودَين، أو `1` إذا كان الجدول موجودًا في قاعدة البيانات المحددة.

## صيغة الاستعلام الفرعي {#subquery-form}

يتحقق المعامل `EXISTS` مما إذا كان الاستعلام الفرعي يُرجع أي صفوف، إذ يُرجع `0` إذا كانت نتيجة الاستعلام الفرعي فارغة، ويُرجع `1` خلاف ذلك.

يمكنك استخدام `EXISTS` في عبارة [`WHERE`](/ar/reference/statements/select/where). ولا يمكن للاستعلام الفرعي الإشارة إلى جداول أو أعمدة من الاستعلام الخارجي.

**الصيغة**

```sql
EXISTS(subquery)
```

**أمثلة**

تحقّق ممّا إذا كان الاستعلام الفرعي يُرجِع صفوفًا:

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

استخدم `EXISTS` في عبارة `WHERE` مع استعلام فرعي يُعيد عدة صفوف:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

عندما تكون نتيجة الاستعلام الفرعي فارغة، تُرجع `EXISTS` القيمة `0`:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```

**انظر أيضًا:** `SHOW`، `DESCRIBE TABLE`، `CREATE`
