<Info>
  هذه ميزة تجريبية قد تتغير في الإصدارات المستقبلية بطرق غير متوافقة مع الإصدارات السابقة.
  فعِّل استخدام مصدر القاموس YTsaurus
  باستخدام الإعداد [`allow_experimental_ytsaurus_dictionary_source`](/ar/reference/settings/session-settings/allow-experimental#allow_experimental_ytsaurus_dictionary_source).
</Info>

مثال على الإعدادات:

<Tabs>
  <Tab title="DDL">
    ```sql
    SOURCE(YTSAURUS(
        http_proxy_urls 'http://localhost:8000'
        cypress_path '//tmp/test'
        oauth_token 'password'
    ))
    ```
  </Tab>

  <Tab title="ملف التهيئة">
    ```xml
    <source>
        <ytsaurus>
            <http_proxy_urls>http://localhost:8000</http_proxy_urls>
            <cypress_path>//tmp/test</cypress_path>
            <oauth_token>password</oauth_token>
            <check_table_schema>1</check_table_schema>
        </ytsaurus>
    </source>
    ```
  </Tab>
</Tabs>

<br />

حقول الإعدادات:

| الإعداد                                    | الوصف                                                                                                                                                                                                                           |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `http_proxy_urls`                          | عنوان URL لوكيل HTTP الخاص بـ YTsaurus.                                                                                                                                                                                         |
| `cypress_path`                             | مسار Cypress إلى مصدر الجدول.                                                                                                                                                                                                   |
| `oauth_token`                              | رمز OAuth.                                                                                                                                                                                                                      |
| `lookup_throttler_max_requests_per_second` | الحد الأقصى لعدد طلبات البحث المُرسَلة إلى YTsaurus في الثانية عند جلب المفاتيح لعمليات التحميل الانتقائي للقاموس (`CACHE` و`COMPLEX_KEY_CACHE` وغيرها). تؤدي القيمة `0` إلى تعطيل تقييد المعدل. القيمة الافتراضية هي `200000`. |
| `lookup_max_rows_per_query`                | الحد الأقصى لعدد الصفوف في طلب بحث واحد إلى YTsaurus. تُقسَّم عمليات التحميل الانتقائي إلى مقاطع بهذا الحجم. القيمة `0`، وهي القيمة الافتراضية، تعني عدم وجود حد، أي يُرسَل التحميل الانتقائي في طلب واحد.                      |
