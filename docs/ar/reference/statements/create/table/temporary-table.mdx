## دعم الجداول المؤقتة {#temporary-table-support}

<Note>
  يرجى ملاحظة أن الجداول المؤقتة لا تُنسخ متماثلًا. لذلك، لا يوجد ما يضمن إتاحة البيانات المُدرجة في جدول مؤقت في النسخ المتماثلة الأخرى. وتتمثل حالة الاستخدام الرئيسية التي قد تفيد فيها الجداول المؤقتة في الاستعلام عن مجموعات بيانات خارجية صغيرة أو ربطها خلال جلسة واحدة.
</Note>

يدعم ClickHouse الجداول المؤقتة التي تتميز بالخصائص التالية:

* تختفي الجداول المؤقتة عند انتهاء الجلسة، بما في ذلك عند فقدان الاتصال.
* يستخدم الجدول المؤقت محرك الجداول Memory إذا لم يُحدَّد محرك، ويمكنه استخدام أي محرك جداول باستثناء المحركين Replicated و`KeeperMap`.
* لا يمكن تحديد DB لجدول مؤقت، إذ يُنشأ خارج قواعد البيانات.
* يتعذر إنشاء جدول مؤقت باستخدام استعلام DDL موزع على جميع خوادم cluster (باستخدام `ON CLUSTER`)، لأن هذا الجدول لا يوجد إلا في الجلسة الحالية.
* إذا كان للجدول المؤقت الاسم نفسه لجدول آخر، وكان استعلام يحدد اسم الجدول دون تحديد DB، فسيُستخدم الجدول المؤقت.
* في معالجة الاستعلامات الموزعة، تُمرَّر الجداول المؤقتة ذات محرك Memory المستخدمة في استعلام إلى الخوادم البعيدة.
* يمكن تقييد عدد الجداول المؤقتة في الجلسة وأحجامها باستخدام الإعدادات [max&#95;temporary&#95;tables](/ar/reference/settings/session-settings/max-temporary#max_temporary_tables) و[max&#95;temporary&#95;table&#95;memory&#95;usage](/ar/reference/settings/session-settings/max-temporary#max_temporary_table_memory_usage) (لمحرك `Memory`) و[max&#95;temporary&#95;table&#95;size&#95;bytes&#95;compressed](/ar/reference/settings/session-settings/max-temporary#max_temporary_table_size_bytes_compressed) و[max&#95;temporary&#95;table&#95;size&#95;bytes&#95;uncompressed](/ar/reference/settings/session-settings/max-temporary#max_temporary_table_size_bytes_uncompressed) (لعائلة `MergeTree`).

## Syntax {#syntax}

لإنشاء جدول مؤقت، استخدم الصيغة التالية:

```sql
CREATE [OR REPLACE] TEMPORARY TABLE [IF NOT EXISTS] table_name
(
    name1 [type1] [DEFAULT|MATERIALIZED|ALIAS expr1],
    name2 [type2] [DEFAULT|MATERIALIZED|ALIAS expr2],
    ...
) [ENGINE = engine]
```

في معظم الحالات، لا تُنشأ الجداول المؤقتة يدويًا، بل عند استخدام بيانات خارجية في استعلام أو عند استخدام `(GLOBAL) IN` الموزّع. لمزيد من المعلومات، راجع الأقسام ذات الصلة.

يمكن استخدام جداول ذات [ENGINE = Memory](/ar/reference/engines/table-engines/special/memory) بدلًا من الجداول المؤقتة.
