ينشئ مجموعة مُسمّاة جديدة.

<Note>
  يمكن تمكين المجموعات المُسمّاة المُنشأة باستخدام DDL في بعض خدمات ClickHouse Cloud. تواصل مع فريق الدعم لتأكيد التوافر.
</Note>

**الصيغة**

```sql
CREATE [OR REPLACE] NAMED COLLECTION [IF NOT EXISTS] name [ON CLUSTER cluster] AS
key_name1 = 'some value' [[NOT] OVERRIDABLE],
key_name2 = 'some value' [[NOT] OVERRIDABLE],
key_name3 = 'some value' [[NOT] OVERRIDABLE],
...
```

لا يمكن استخدام `OR REPLACE` و`IF NOT EXISTS` معًا. يؤدي تنفيذ `CREATE OR REPLACE` على مجموعة مُسمّاة موجودة
إلى استبدالها بالكامل، إذ تُزال المفاتيح وعلامات قابلية التجاوز التي لا يتضمنها التعريف الجديد.

يتطلب تجاوز مفتاح مُخزَّن عند استخدام المجموعة المُسمّاة امتلاك امتياز `SHOW NAMED COLLECTIONS SECRETS` على تلك المجموعة،
حتى بالنسبة إلى المفاتيح المُعلَّمة بـ `OVERRIDABLE`. أما المفاتيح المُعلَّمة بـ `NOT OVERRIDABLE` فلا يمكن تجاوزها.
وتخضع مصادر القواميس للقاعدة نفسها، إذ يُتحقَّق من الامتياز عند إنشاء القاموس أو إرفاقه أو استعادته.
أما عند تحميل القاموس، فلا يُفرض إلا قيد المفاتيح المُعلَّمة بـ `NOT OVERRIDABLE`.

**مثال**

```sql
CREATE NAMED COLLECTION foobar AS a = '1', b = '2' OVERRIDABLE;
CREATE OR REPLACE NAMED COLLECTION foobar AS a = '2', c = '3';
```
