## الوصف {#description}

مماثل لـ [`JSONCompactEachRowWithProgress`](/ar/reference/formats/JSON/JSONCompactEachRowWithProgress)، لكن جميع القيم تُحوَّل إلى سلاسل نصية. ويستخدم أنواع كائنات المستوى الأعلى نفسها (`meta` و`row` و`progress` و`totals` و`min`/`max` و`rows_before_limit_at_least` و`rows_before_aggregation`، بالإضافة إلى `exception` في المستوى الأعلى)؛ وتظل حمولات `row` / `totals` / `min` / `max` **مصفوفات** مرتبة وفق ترتيب الأعمدة، مع تسلسل كل عنصر فيها في صورة سلسلة نصية.

راجع [`JSONCompactEachRowWithProgress`](/ar/reference/formats/JSON/JSONCompactEachRowWithProgress) للاطلاع على العقد الكامل لكائنات الدفق (قد يصل `progress` قبل `meta`؛ ويمثّل `rows_before_limit_at_least` حدًّا أدنى تقديريًا عندما يحتوي الاستعلام على `LIMIT`، ولا يُعد دليلًا على حذف صفوف؛ ولا يُكتب `exception` إلا عبر مسار HTTP عند ضبط `http_write_exception_in_output_format=1`).

## مثال للاستخدام {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
