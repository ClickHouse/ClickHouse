## الوصف {#description}

تختلف هذه الصيغة عن `JSONEachRow`/`JSONStringsEachRow` في أن ClickHouse يبث كل حدث على هيئة كائن JSON مستقل، ويُخرج إلى جانب ذلك معلومات التقدم.

تُسلسَل جميع قيم الحقول على هيئة سلاسل نصية (بما في ذلك الأنواع المركبة)؛ فمثلًا يُخرَج `arr` بالشكل `"arr":"[0,1]"`، لا على هيئة مصفوفة JSON متداخلة. وكذلك تُحوَّل القيم المفردة إلى سلاسل نصية (`"num":"42"`).

تطابق أنواع كائنات المستوى الأعلى نظيراتها في [`JSONEachRowWithProgress`](/ar/reference/formats/JSON/JSONEachRowWithProgress) (`meta` و`row` و`progress` و`totals`/`min`/`max` و`rows_before_limit_at_least` و`rows_before_aggregation` و`exception` في المستوى الأعلى). راجع تلك الصفحة للاطلاع على المواصفات الكاملة للدفق: فقد يصل كائن `progress` قبل `meta`، وتمثّل `rows_before_limit_at_least` تقديرًا أدنى عندما يتضمن الاستعلام `LIMIT` (ولا تعني بالضرورة أن صفوفًا قد حُذفت)، ولا يُكتب `exception` إلا عبر مسار HTTP عند ضبط `http_write_exception_in_output_format=1`.

## مثال للاستخدام {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
