ابدأ مع ClickHouse Cloud على [AWS Marketplace](https://aws.amazon.com/marketplace) عبر عرض عام بنظام PAYG (الدفع حسب الاستخدام).

<div id="prerequisites">
  ## المتطلبات المسبقة {#prerequisites}
</div>

* حساب AWS مفعَّل مع صلاحيات الشراء من قِبل مسؤول الفوترة لديك.
* لإتمام الشراء، يجب أن تكون مسجّل الدخول إلى AWS Marketplace باستخدام هذا الحساب.
* لربط مؤسسة ClickHouse باشتراكك، يجب أن تكون مسؤولًا عن تلك المؤسسة.

## خطوات التسجيل {#steps-to-sign-up}

<Steps>
  <Step title="ابحث عن ClickHouse Cloud - Pay as you go" id="search-payg">
    انتقل إلى [AWS Marketplace](https://aws.amazon.com/marketplace) وابحث عن &quot;ClickHouse Cloud - Pay As You Go&quot;.

    <div className="ch-image-lg">
      <Frame>
        ![البحث عن ClickHouse في AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="عرض خيارات الشراء" id="purchase-options">
    انقر على [صفحة المنتج](https://aws.amazon.com/marketplace/pp/prodview-p4gwofrqpkltu) ثم على **عرض خيارات الشراء**.

    <div className="ch-image-lg">
      <Frame>
        ![عرض خيارات الشراء في AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="الاشتراك" id="subscribe">
    في الشاشة التالية، انقر على الاشتراك.

    <div className="ch-image-lg">
      <Frame>
        ![الاشتراك في AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="إعداد حسابك" id="set-up-your-account">
    في هذه المرحلة، لم يكتمل الإعداد بعد، ولم تبدأ فوترة مؤسستك في ClickHouse Cloud عبر السوق حتى الآن. عليك الآن النقر على إعداد حسابك في اشتراك السوق الخاص بك، ليُعاد توجيهك إلى ClickHouse Cloud لإكمال الإعداد.

    <div className="ch-image-lg">
      <Frame>
        ![إعداد حسابك](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-4.webp)
      </Frame>
    </div>

    بعد إعادة توجيهك إلى ClickHouse Cloud، يمكنك إما تسجيل الدخول بحساب موجود أو إنشاء حساب جديد. هذه الخطوة بالغة الأهمية، إذ تتيح لنا ربط مؤسستك في ClickHouse Cloud بالفوترة عبر AWS Marketplace.

    <Info>
      **مستخدمو ClickHouse Cloud الجدد**

      إذا كنت مستخدمًا جديدًا لـ ClickHouse Cloud، فاتبع الخطوات أدناه.
    </Info>

    <Accordion title="خطوات المستخدمين الجدد">
      إذا كنت مستخدمًا جديدًا لـ ClickHouse Cloud، فانقر على Register أسفل الصفحة. سيُطلب منك إنشاء مستخدم جديد والتحقق من بريدك الإلكتروني. بعد التحقق، يمكنك مغادرة صفحة تسجيل الدخول إلى ClickHouse Cloud وتسجيل الدخول باسم المستخدم الجديد عبر https://console.clickhouse.cloud.

      <div className="ch-image-md">
        <Frame>
          ![التسجيل في ClickHouse Cloud](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-5.webp)
        </Frame>
      </div>

      <Info>
        **المستخدمون الجدد**

        ستحتاج أيضًا إلى تقديم بعض المعلومات الأساسية عن نشاطك التجاري. راجع لقطات الشاشة أدناه.
      </Info>

      <div className="ch-image-md">
        <Frame>
          ![قبل البدء](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
        </Frame>
      </div>

      <div className="ch-image-md">
        <Frame>
          ![قبل البدء (تابع)](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
        </Frame>
      </div>
    </Accordion>

    إذا كنت مستخدمًا حاليًا لـ ClickHouse Cloud، فما عليك سوى تسجيل الدخول باستخدام بيانات اعتمادك.
  </Step>

  <Step title="إضافة اشتراك السوق إلى مؤسسة" id="add-marketplace-subscription">
    بعد تسجيل الدخول بنجاح، يمكنك إنشاء مؤسسة جديدة تُفوتر عبر اشتراك السوق هذا، أو اختيار مؤسسة موجودة لفوترتها عبره.

    <div className="ch-image-lg">
      <Frame>
        ![إضافة اشتراك السوق](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
      </Frame>
    </div>

    إذا كنت تسجّل حساب ClickHouse جديدًا، فستجد مؤسسة افتراضية أُنشئت لك، ويمكنك ربط اشتراك السوق الخاص بك بها.

    <div className="ch-image-lg">
      <Frame>
        ![ربط المؤسسة الافتراضية باشتراك AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-13.webp)
      </Frame>
    </div>

    بعد إكمال هذه الخطوة، ستُربط مؤسستك باشتراك AWS هذا، وسيُفوتر كل الاستخدام عبر حساب AWS الخاص بك.

    يمكنك التحقق من صفحة الفوترة الخاصة بالمؤسسة في واجهة ClickHouse UI من أن الفوترة أصبحت مرتبطة فعلًا بـ AWS Marketplace.

    <div className="ch-image-lg">
      <Frame>
        ![تأكيد صفحة الفوترة](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-9.webp)
      </Frame>
    </div>
  </Step>
</Steps>
