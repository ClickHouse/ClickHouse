## التوسيع الأفقي اليدوي {#manual-horizontal-scaling}

<ScalePlanFeatureBadge feature="التوسيع الأفقي اليدوي" />

يمكنك استخدام [واجهات برمجة التطبيقات العامة](/ar/products/cloud/api-reference/service/instance-scaling-update) في ClickHouse Cloud لتوسيع خدمتك من خلال تحديث إعدادات التوسيع الخاصة بالخدمة، أو تعديل عدد النسخ المتماثلة من وحدة تحكم ClickHouse Cloud.

كما تدعم الفئتَان **Scale** و**Enterprise** الخدمات ذات النسخة المتماثلة الواحدة. وبعد توسيع الخدمات أفقيًا، يمكن تقليصها مجددًا إلى حد أدنى يبلغ نسخة متماثلة واحدة. لاحظ أن الخدمات ذات النسخة المتماثلة الواحدة تكون أقل توافراً، ولا يُنصح باستخدامها في بيئات الإنتاج.

<Note>
  للاطلاع على حدود النسخ المتماثلة التي تنطبق على خدمتك، راجع [حدود الاستخدام](/ar/cloud/bestpractices/usage-limits). تواصل مع فريق الدعم لدينا إذا كنت بحاجة إلى نسخ متماثلة إضافية.
</Note>

### توسيع النطاق الأفقي عبر API {#horizontal-scaling-via-api}

لتوسيع نطاق عنقود أفقيًا، أرسل طلب `PATCH` عبر API لتعديل عدد النسخ المتماثلة. تُظهر لقطات الشاشة أدناه استدعاءً إلى API لتوسيع نطاق عنقود من `3` نسخ متماثلة إلى `6` نسخ متماثلة، بالإضافة إلى الاستجابة المقابلة.

إذا أرسلت طلب توسيع النطاق جديدًا، أو عدة طلبات متتالية، بينما يوجد طلب قيد التنفيذ بالفعل، فستتجاهل خدمة توسيع النطاق الحالات الوسيطة وتستقر على العدد النهائي للنسخ المتماثلة.

### توسيع النطاق الأفقي عبر UI {#horizontal-scaling-via-ui}

لتوسيع نطاق الخدمة أفقيًا من خلال UI، يمكنك تعديل عدد النُسخ المتماثلة للخدمة في صفحة **الإعدادات**.

<div className="ch-image-md">
  <Frame>
    ![إعدادات تهيئة توسيع النطاق](/images/cloud/manage/scaling-configure.webp)
  </Frame>
</div>

*إعدادات توسيع نطاق الخدمة من وحدة تحكم ClickHouse Cloud*

بعد اكتمال توسيع نطاق الخدمة، ينبغي أن تعرض لوحة بيانات المقاييس في وحدة تحكم ClickHouse Cloud التخصيص الصحيح للخدمة. وتُظهر لقطة الشاشة أدناه أن العنقود قد توسّع نطاقه ليصل إجمالي الذاكرة إلى `96 GiB`، أي `6` نُسخ متماثلة، مع تخصيص ذاكرة قدره `16 GiB` لكل نسخة.
