يتطلب بناء تطبيقات تفاعلية قائمة على البيانات أكثر من مجرد قاعدة بيانات سريعة، وبيانات منظَّمة جيدًا، واستعلامات محسَّنة.
فواجهتك الأمامية والخدمات المصغّرة تحتاج أيضًا إلى طريقة سهلة لاستهلاك البيانات التي تُرجعها تلك الاستعلامات، ويفضَّل أن يكون ذلك عبر واجهات برمجة تطبيقات منظَّمة جيدًا.

تتيح لك ميزة **نقاط نهاية API للاستعلامات** إنشاء نقطة نهاية واجهة برمجة تطبيقات مباشرةً من أي استعلام SQL محفوظ في ClickHouse Cloud Console.
وستتمكن من الوصول إلى نقاط نهاية واجهة برمجة تطبيقات عبر HTTP لتنفيذ استعلاماتك المحفوظة دون الحاجة إلى الاتصال بخدمة ClickHouse Cloud عبر برنامج تشغيل native.

## التحكم في الوصول عبر IP {#ip-access-control}

تلتزم نقاط نهاية API للاستعلامات بقائمة السماح لعناوين IP على مستوى مفتاح API. وعلى غرار SQL Console، تمرِّر نقاط نهاية API للاستعلامات الطلبات من داخل البنية التحتية لـ ClickHouse، لذا لا تنطبق إعدادات قائمة السماح لعناوين IP على مستوى الخدمة.

لتقييد العملاء الذين يمكنهم استدعاء نقاط نهاية API للاستعلامات الخاصة بك:

<Steps>
  <Step title="افتح إعدادات مفتاح واجهة برمجة تطبيقات" id="open-settings">
    1. انتقل إلى ClickHouse Cloud Console → **Organization** → **مفاتيح API**

    <div className="ch-image-md">
      <Frame>
        ![مفاتيح API](/images/cloud/guides/query-endpoints/console-api-keys.webp)
      </Frame>
    </div>

    2. انقر على **تعديل** بجوار مفتاح API المستخدم لـ نقاط نهاية API للاستعلامات

    <div className="ch-image-md">
      <Frame>
        ![تعديل](/images/cloud/guides/query-endpoints/api-key-edit.webp)
      </Frame>
    </div>
  </Step>

  <Step title="أضف عناوين IP المسموح بها" id="add-ips">
    1. في قسم **Allow access to this مفتاح API**، حدِّد **Specific locations**
    2. أدخل عناوين IP أو نطاقات CIDR (على سبيل المثال، `203.0.113.1` أو `203.0.113.0/24`)
    3. أضف عدة إدخالات حسب الحاجة

    <div className="ch-image-md">
      <Frame>
        ![مواقع محددة](/images/cloud/guides/query-endpoints/specific-locations.webp)
      </Frame>
    </div>

    يتطلب إنشاء نقاط نهاية API للاستعلامات دور Admin في Console ومفتاح API يملك الأذونات المناسبة.
  </Step>
</Steps>
