يوضح هذا الدليل كيفية تمكين خادم MCP البعيد في ClickHouse Cloud وإعداده للاستخدام مع أدوات التطوير الشائعة.

**المتطلبات الأساسية**

* [خدمة ClickHouse Cloud](/ar/get-started/setup/cloud) قيد التشغيل
* بيئة التطوير المتكاملة (IDE) أو أداة التطوير المعتمدة على الوكلاء التي تفضّلها
* للمصادقة غير التفاعلية (headless)، [مفتاح API لـ ClickHouse Cloud](/ar/cloud/manage/openapi) يمتلك صلاحية الوصول إلى المؤسسة والخدمات المطلوبة

## تمكين خادم MCP البعيد لـ Cloud {#enable-remote-mcp-server}

اتصل بخدمة ClickHouse Cloud التي تريد تمكين خادم MCP البعيد لها.
في القائمة الجانبية اليسرى، انقر على **Connect**. ستُفتح نافذة تتضمن تفاصيل الاتصال.

اختر **Connect with MCP**:

<Image img="/images/use-cases/AI_ML/MCP/1connectmcpmodal.webp" alt="اختر MCP في نافذة Connect" size="md" />

بدّل الزر إلى وضع التشغيل لتمكين MCP لهذه الخدمة. يتطلب تمكين MCP أو تعطيله امتلاك الصلاحية `control-plane:service:manage-mcp` (راجع [أدوار وصلاحيات Console](/ar/products/cloud/reference/security/console-roles#console-permissions)):

<Image img="/images/use-cases/AI_ML/MCP/2enable_mcp.webp" alt="تمكين خادم MCP" size="md" />

انسخ عنوان URL المعروض، وهو نفسه الظاهر أدناه:

```bash
https://mcp.clickhouse.cloud/mcp
```

<div id="setup-clickhouse-cloud-remote-mcp-server">
  ## إعداد Remote MCP للتطوير {#setup-clickhouse-cloud-remote-mcp-server}
</div>

اختر بيئة التطوير المتكاملة أو الأداة المناسبة أدناه، ثم اتبع تعليمات الإعداد المقابلة.

### المصادقة من بيئة غير تفاعلية {#headless-mcp-client-authentication}

إذا كان عميل MCP يعمل على مضيف بعيد أو غير تفاعلي، بحيث يتعذّر عمليًا استخدام تدفق OAuth عبر المتصفح، فاستخدم [مفتاح واجهة برمجة تطبيقات ClickHouse Cloud](/ar/cloud/manage/openapi) للمصادقة بدلًا من ذلك.

1. في وحدة تحكم ClickHouse Cloud، افتح مؤسستك واختر **API Keys**.
2. أنشئ مفتاحًا يتضمن الحد الأدنى من الأدوار والأذونات اللازمة للمؤسسات والخدمات التي يحتاج عميل MCP إلى الوصول إليها، ثم نزّل معرّف المفتاح والسر الخاص به.
3. على المضيف البعيد، مرّر بيانات الاعتماد عبر نظام إدارة الأسرار المعتمد لديك، ثم أنشئ قيمة تفويض HTTP Basic:

```bash
export CLICKHOUSE_CLOUD_API_KEY="<key_id>"
export CLICKHOUSE_CLOUD_API_SECRET="<key_secret>"

export CH_AUTH="Basic $(
  printf '%s:%s' \
    "$CLICKHOUSE_CLOUD_API_KEY" \
    "$CLICKHOUSE_CLOUD_API_SECRET" |
  base64 | tr -d '\n'
)"
```

4. اختر عميل MCP الذي تستخدمه وأضف خادم MCP البعيد:

<Tabs>
  <Tab title="Claude Code" id="headless-auth-claude-code">
    ```bash
    claude mcp add \
      --scope user \
      --transport http \
      clickhouse-cloud \
      https://mcp.clickhouse.cloud/mcp \
      --header 'Authorization: ${CH_AUTH}'
    ```

    يستبدل Claude Code المتغير `CH_AUTH` بقيمته من البيئة عند الاتصال. شغّل Claude Code ونفّذ `/mcp` للتأكد من أن `clickhouse-cloud` متصل.

    راجع [توثيق MCP في Claude Code](https://code.claude.com/docs/en/mcp#option-1-add-a-remote-http-server) للاطلاع على تفاصيل خوادم HTTP البعيدة وتهيئة الترويسات.
  </Tab>

  <Tab title="Codex" id="headless-auth-codex">
    أضف الإدخال التالي إلى `~/.codex/config.toml`:

    ```toml
    [mcp_servers.clickhouse-cloud]
    url = "https://mcp.clickhouse.cloud/mcp"
    env_http_headers = { Authorization = "CH_AUTH" }
    ```

    نفّذ `codex mcp list` للتأكد من تهيئة `clickhouse-cloud`.

    راجع [مرجع تهيئة Codex](https://developers.openai.com/codex/config-reference) للاطلاع على تفاصيل `mcp_servers.<id>.env_http_headers`.
  </Tab>

  <Tab title="OpenCode" id="headless-auth-opencode">
    أضف الإدخال التالي إلى ملف التهيئة `opencode.jsonc`:

    ```jsonc
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "servers": {
          "clickhouse-cloud": {
            "type": "remote",
            "url": "https://mcp.clickhouse.cloud/mcp",
            "oauth": false,
            "headers": {
              "Authorization": "{env:CH_AUTH}"
            }
          }
        }
      }
    }
    ```

    نفّذ `opencode mcp list` للتأكد من أن `clickhouse-cloud` متصل.

    راجع [توثيق MCP في OpenCode](https://opencode.ai/v2/docs/mcp-servers#remote) للاطلاع على تفاصيل الخوادم البعيدة والترويسات واستبدال متغيرات البيئة.
  </Tab>
</Tabs>

احرص على أن يكون `CH_AUTH` متاحًا في كل session للعميل، ولا تُثبّت مفتاح API أو الـ Secret أو قيمة `CH_AUTH` في نظام التحكم بالمصدر. تذكّر أن ترميز Base64 لا يُشفّر بيانات الاعتماد.

لا تتطلب طريقة المصادقة هذه بمفتاح API متصفحًا ولا تسجيل دخول منفصلًا عبر `clickhousectl`.

<div id="claude-code">
  ### Claude Code {#claude-code}
</div>

من دليل العمل الحالي، شغِّل الأمر التالي لإضافة تكوين ClickHouse Cloud MCP Server إلى Claude Code:

```bash
claude mcp add --transport http clickhouse-cloud https://mcp.clickhouse.cloud/mcp
```

ثم شغِّل Claude Code:

```bash
claude
```

شغّل الأمر التالي لعرض خوادم MCP:

```bash
/mcp
```

حدِّد `clickhouse-cloud` وسجِّل الدخول عبر OAuth باستخدام بيانات الاعتماد الخاصة بك في ClickHouse Cloud.

<div id="claude-web">
  ### واجهة الويب لـ Claude {#claude-web}
</div>

1. انتقل إلى **Customize** &gt; **Connectors**
2. انقر على أيقونة &quot;+&quot; ثم **Add custom connector**
3. سمِّ الموصل المخصص باسم مثل `clickhouse-cloud` ثم أضِفه
4. انقر على الموصل `clickhouse-cloud` الذي أُضيف حديثًا، ثم انقر على **Connect**
5. أكمِل المصادقة باستخدام بيانات اعتماد ClickHouse Cloud عبر OAuth

<div id="cursor">
  ### Cursor {#cursor}
</div>

1. تصفّح خوادم MCP وثبّتها من [متجر Cursor](https://cursor.com/marketplace).
2. ابحث عن ClickHouse وانقر على &quot;إضافة إلى Cursor&quot; على أي خادم لتثبيته.
3. أكمل المصادقة باستخدام OAuth.

<div id="visual-studio-code">
  ### Visual Studio Code {#visual-studio-code}
</div>

أضِف الإعداد التالي إلى `.vscode/mcp.json`:

```json
{
  "servers": {
    "clickhouse-cloud": {
      "type": "http",
      "url": "https://mcp.clickhouse.cloud/mcp"
    }
  }
}
```

لمزيد من التفاصيل، راجع [وثائق Visual Studio Code](https://code.visualstudio.com/docs/copilot/customization/mcp-servers).

<div id="windsurf">
  ### Windsurf {#windsurf}
</div>

حرِّر ملف `mcp_config.json` باستخدام التكوين التالي:

```json
{
  "mcpServers": {
    "clickhouse-cloud": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.clickhouse.cloud/mcp"]
    }
  }
}
```

لمزيد من التفاصيل، اطّلع على [وثائق Windsurf](https://docs.windsurf.com/windsurf/cascade/mcp#adding-a-new-mcp).

<div id="zed">
  ### Zed {#zed}
</div>

أضِف ClickHouse كخادم مخصّص.
أضِف ما يلي إلى إعدادات Zed ضمن **context&#95;servers**:

```json
{
  "context_servers": {
    "clickhouse-cloud": {
      "url": "https://mcp.clickhouse.cloud/mcp"
    }
  }
}
```

بعد ذلك، من المفترض أن يطلب منك Zed المصادقة عبر OAuth عند اتصاله بالخادم للمرة الأولى.
لمزيد من التفاصيل، راجع [وثائق Zed](https://zed.dev/docs/ai/mcp#as-custom-servers).

<div id="codex">
  ### Codex {#codex}
</div>

نفّذ الأمر التالي لإضافة خادم MCP الخاص بـ ClickHouse Cloud عبر CLI:

```bash
codex mcp add clickhouse-cloud --url https://mcp.clickhouse.cloud/mcp
```

<div id="example-usage">
  ## مثال على الاستخدام {#example-usage}
</div>

بمجرد الاتصال، يمكنك التفاعل مع ClickHouse Cloud عبر مطالبات باللغة الطبيعية.
فيما يلي بعض مسارات سير العمل الشائعة والأدوات التي سيستدعيها MCP client في الخلفية.
للاطلاع على قائمة كاملة بالأدوات المتاحة، راجع [مرجع الأدوات](/ar/products/cloud/features/ai-ml/remote-mcp#available-tools).

<div id="exploring-data">
  ### استكشاف بياناتك {#exploring-data}
</div>

ابدأ بالتعرّف على المتاح:

| الموجّه                                                      | الأداة المستخدمة                             |
| ------------------------------------------------------------ | -------------------------------------------- |
| &quot;ما المؤسسات التي يمكنني الوصول إليها؟&quot;            | `get_organizations`                          |
| &quot;ما قواعد البيانات المتاحة على خدمتي؟&quot;             | `list_databases`                             |
| &quot;اعرض لي الجداول في قاعدة البيانات `default`&quot;      | `list_tables`                                |
| &quot;اعرض جميع الجداول التي تبدأ أسماؤها بـ `events_`&quot; | `list_tables` (باستخدام عامل التصفية `like`) |

<div id="running-queries">
  ### تشغيل الاستعلامات التحليلية {#running-queries}
</div>

اطرح أسئلة بلغة طبيعية، وسيتولى الوكيل ترجمتها إلى SQL:

| الموجِّه                                                             | الأداة المستخدمة   |
| -------------------------------------------------------------------- | ------------------ |
| &quot;أرني أول 10 صفوف من جدول `hits`&quot;                          | `run_select_query` |
| &quot;ما متوسط مدة الجلسة حسب البلد خلال آخر 7 أيام؟&quot;           | `run_select_query` |
| &quot;كم عدد الصفوف في كل جدول ضمن قاعدة البيانات `analytics`؟&quot; | `run_select_query` |

لا تتيح الأداة `run_select_query` سوى عبارات `SELECT`. جميع الاستعلامات للقراءة فقط.
