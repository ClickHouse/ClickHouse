على الرغم من أن ClickHouse معروف بسرعته وموثوقيته، فإن الأداء الأمثل
يتحقق ضمن معايير تشغيلية محددة. على سبيل المثال، قد يؤثر وجود عدد كبير جدًا من الجداول
أو قواعد البيانات أو الأجزاء سلبًا في الأداء. ولتفادي ذلك، يفرض ClickHouse
Cloud حدودًا على عدة أبعاد تشغيلية.
ترد القيم الافتراضية لهذه القيود أدناه. وما لم يُذكر خلاف ذلك،
تنطبق هذه القيود على مستوى الخدمة.

<Tip>
  إذا وصلت إلى أحد هذه القيود، فمن المحتمل أنك
  تنفذ حالة استخدامك بطريقة غير مُحسّنة. تواصل مع [الدعم](https://clickhouse.com/support/program)، وسنساعدك
  بكل سرور في تحسين حالة استخدامك لتجنب تجاوز القيود،
  أو سنبحث معًا كيفية زيادتها بطريقة منضبطة.
</Tip>

| البُعد                                | الحد                                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **قواعد البيانات**                    | 1000                                                                                                         |
| **الجداول**                           | 5000                                                                                                         |
| **العروض**                            | 15000                                                                                                        |
| **القواميس**                          | 5000                                                                                                         |
| **المجموعات المُسمّاة** (معاينة خاصة) | 1000                                                                                                         |
| **الأعمدة**                           | ~1000 (يُفضّل التنسيق الواسع على المضغوط)                                                                    |
| **الأقسام**                           | 50k                                                                                                          |
| **الأجزاء**                           | 10k (راجع إعداد [`max_parts_in_total`](/ar/products/cloud/guides/cloud-compatibility#max_parts_in_total-10000)) |
| **حجم الجزء**                         | 150 GB                                                                                                       |
| **الخدمات لكل مؤسسة**                 | 20 (مرن)                                                                                                     |
| **النسخ المتماثلة لكل خدمة**          | 20 (مرن)                                                                                                     |
| **النسخ المتماثلة لكل مستودع**        | 50 (مرن)                                                                                                     |
| **انخفاض عدد القيم المميزة**          | 10k أو أقل                                                                                                   |
| **المفاتيح الأساسية في جدول**         | 4–5 تُصفّي البيانات بشكل كافٍ                                                                                |
| **تزامن الاستعلامات**                 | 1000 (لكل نسخة متماثلة)                                                                                      |
| **إدخال البيانات على دفعات**          | أي كمية &gt; 1M صف تُقسَّم إلى كتل من 1M صف                                                                  |

للاطلاع على حدود النسخ المتماثلة للمستودعات وحدود التحجيم، راجع [المستودعات](/ar/products/cloud/features/infrastructure/warehouses#scaling).

القيم أعلاه هي قيود افتراضية. قد يكون الحد المفروض على خدمة محددة أعلى من القيمة المعروضة هنا، إذ تُهيّأ الخدمات الأكبر بسعة احتياطية أكبر. يُدرج الحد الفعلي المطبق على خدمتك في التحذير الذي تتلقاه عند الاقتراب منه. بالنسبة إلى الخدمات التي تتجاوز بالفعل حدود الاستخدام المذكورة أعلاه، تُضبط حدود الجداول/قواعد البيانات عند عدد الجداول/قواعد البيانات الحالي للخدمة بالإضافة إلى 25%.

<Note>
  بالنسبة إلى خدمات النسخة المتماثلة الواحدة، يقتصر الحد الأقصى لعدد قواعد البيانات على
  100، والحد الأقصى لعدد الجداول على 500. بالإضافة إلى ذلك، يقتصر التخزين
  لخدمات المستوى الأساسي على 1 TB. أما حدود العروض والقواميس والمجموعات
  المُسمّاة المذكورة أعلاه، فهي قيمة موحّدة تنطبق على جميع الخدمات،
  بما في ذلك خدمات النسخة المتماثلة الواحدة.
</Note>

يمكن التحقق من حدود التحذير والإيقاف الخاصة بخدمتك عبر الاستعلام عن system.server&#95;settings. على سبيل المثال،

```
SELECT * 
FROM system.server_settings 
WHERE name IN ('max_table_num_to_warn', 'max_table_num_to_throw', 'max_database_num_to_warn', 'max_database_num_to_throw', 'max_view_num_to_warn', 'max_view_num_to_throw', 'max_dictionary_num_to_warn', 'max_dictionary_num_to_throw', 'max_named_collection_num_to_warn', 'max_named_collection_num_to_throw')
```
