* نُقل إلى الإصدارة الأقدم [#86386](https://github.com/ClickHouse/ClickHouse/issues/86386): معالجة تعليمات التضمين من `/etc/metrika.xml` افتراضيًا عند إنشاء disks من SQL. [#86232](https://github.com/ClickHouse/ClickHouse/pull/86232) ([alekar](https://github.com/alekar)).
* نُقل إلى الإصدارة الأقدم [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653): إصلاح الخطأ `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` عند قراءة blobs فارغة من Azure blob storage لقرص plain&#95;rewritable. * نُقل إلى الإصدارة الأقدم [#86457](https://github.com/ClickHouse/ClickHouse/issues/86457): إصلاح خلل في Materialized Views: قد لا يعمل MV إذا تم إنشاؤه ثم حذفه ثم إنشاؤه مجددًا بالاسم نفسه. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الإصدارة الأقدم [#86468](https://github.com/ClickHouse/ClickHouse/issues/86468): إصلاح تسرّب `MergesMutationsMemoryTracking` بسبب جداول `Buffer`، وإصلاح `query_views_log` عند streaming من `Kafka` (وغيره). * نُقل إلى الإصدارة الأقدم [#86549](https://github.com/ClickHouse/ClickHouse/issues/86549): إصلاح استخدام memory غير مهيّأة في getSubcolumnType. [#86498](https://github.com/ClickHouse/ClickHouse/pull/86498) ([Raúl Marín](https://github.com/Algunenano)).
