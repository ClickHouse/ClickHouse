* نُقل إلى الفرع الأقدم في [#16494](https://github.com/ClickHouse/ClickHouse/issues/16494): إصلاح خطأ متعلق بـ MySQL database. عندما يكون MySQL server المستخدم كمحرّك قاعدة بيانات متوقفًا، فإن بعض الاستعلامات تُطلق استثناءً لأنها تحاول جلب الجداول من server معطّل، رغم أن ذلك غير ضروري. على سبيل المثال، يجب أن يعمل الاستعلام `SELECT ... FROM system.parts` مع جداول MergeTree فقط من دون الوصول إلى MySQL database إطلاقًا. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).

[#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

[#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
