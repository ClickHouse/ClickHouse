  ### إصدار ClickHouse v21.2.1.5869-ما قبل الاستقرار FIXME مقارنةً بـ v21.1.1.5646-ما قبل الاستقرار
</div>

<div id="backward-incompatible-change">
  #### تغيير غير متوافق مع الإصدارات السابقة
</div>

* * إصلاح تتبّع الذاكرة في `OPTIMIZE TABLE`/عمليات الدمج - مع احتساب حدود ذاكرة الاستعلام وأخذ العينات لـ `OPTIMIZE TABLE`/عمليات الدمج. [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* حظر `lcm`/`gcd` للأعداد ذات الفاصلة العائمة. [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* تُحظر الدوال البتّية (`bitAnd`, `bitOr`، إلخ) مع الوسائط ذات الفاصلة العائمة. ويجب الآن إجراء تحويل صريح إلى عدد صحيح. [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### ميزة جديدة
</div>

* أُضيف دعم لخيار `zstd` الطويل لتحسين ضغط أعمدة String وتوفير المساحة. [#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * أُضيف دعم لتعيين أسماء مجموعات LDAP، وقيم السمات عمومًا، إلى الأدوار المحلية للمستخدمين من أدلة مستخدمي LDAP. [#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* أصبح نوع البيانات `Nested` يدعم الآن مستويات تعشيق عشوائية. وأُضيفت الأعمدة الفرعية للأنواع المعقدة، مثل `size0` في `Array`، و`null` في `Nullable`، وأسماء عناصر `Tuple`، ويمكن قراءتها دون الحاجة إلى قراءة العمود بالكامل. [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* أُضيف دعم وسيطة `Tuple` إلى الدالتين `argMin` و`argMax`. [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* أُضيف دعم `Nullable` إلى `FlatDictionary` و`HashedDictionary` و`ComplexKeyHashedDictionary` و`DirectDictionary` و`ComplexKeyDirectDictionary` و`RangeHashedDictionary`. [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* مُنع استخدام عمود ذي فاصلة عائمة كمفتاح partition، وذلك بالاستناد إلى: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* أُضيفت الدالة decodeXMLComponent لفك ترميز المحارف في XML. `SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* أُضيف PostgreSQL table engine (لكلٍّ من select/insert، مع دعم المصفوفات متعددة الأبعاد)، وكذلك كـ table function. وأُضيف PostgreSQL dictionary source. وأُضيف PostgreSQL database engine. [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* أُضيف بناء الجملة `SELECT ALL`. يُغلق [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706). [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* أُضيفت ثلاث دوال لنوع البيانات map: 1. ‏mapContains(map, key) للتحقق مما إذا كانت map.keys تتضمن المفتاح key، وهو الوسيط الثاني. 2. ‏mapKeys(map) تُرجع جميع المفاتيح بتنسيق Array 3. ‏mapValues(map) تُرجع جميع القيم بتنسيق Array. [#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* أُضيف دعم ربط مفتاح الاختصار MetaKey+Enter في واجهة play UI. [#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* تدعم الدالة formatDateTime المُعدِّل %Q لتنسيق التاريخ إلى ربع السنة. ... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* ... [#19261](https://github.com/ClickHouse/ClickHouse/pull/19261) ([RegulusZ](https://github.com/RegulusZ)).
* أُضيفت أسماء الكائنات التابعة لـ factories&#39;، التي تُنشأ أثناء تنفيذ query، إلى system.query&#95;log. يُغلق [#18495](https://github.com/ClickHouse/ClickHouse/issues/18495). [#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* أُضيفت الدالة الرياضية `sign`. [#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).
* أُضيفت الدالتان `parseDateTimeBestEffortUSOrZero` و`parseDateTimeBestEffortUSOrNull`. [#19712](https://github.com/ClickHouse/ClickHouse/pull/19712) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#19764](https://github.com/ClickHouse/ClickHouse/pull/19764) ([emhlbmc](https://github.com/emhlbmc)).

<div id="performance-improvement">
  #### تحسينات الأداء
</div>

* استخدام pool للاتصالات الخاصة بـ S3، ويتحكم فيه إعداد `s3_max_connections`. [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* إعادة كتابة الدالتين `sumIf()` و`sum(if())` إلى الدالة `countIf()` عندما تكون متكافئة منطقيًا. [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* تحديث libcxx واستخدام ABI غير مستقر لتقديم أداء أفضل. [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* تسريع إزالة الأجزاء عبر تقليل عدد استدعاءات النظام `stat`. يعيد هذا التحسين الذي كان موجودًا قبل فترة. كما يوفّر واجهة أكثر أمانًا لـ `IDisk`. وهذا يُغلق [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065). [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* تسريع الدالة التجميعية `sum`. لا يظهر هذا التحسين إلا في اختبارات الأداء الاصطناعية، وهو غير عملي كثيرًا. [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* دعم تقسيم خطوة `Filter` في plan الاستعلام إلى زوج `Expression + Filter`. وبالاقتران مع تحسين دمج `Expression + Expression` ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458))، قد يؤخر ذلك تنفيذ بعض التعبيرات إلى ما بعد خطوة `Filter`. [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* تقليل التنافس على الأقفال عبر طبقات متعددة من محرك Buffer. [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* تحسين latency الخادم قليلًا عبر إزالة الوصول إلى configuration عند كل اتصال. [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
