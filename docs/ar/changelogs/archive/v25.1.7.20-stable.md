  #### إصلاح خلل (سلوك غير صحيح ظاهر للمستخدم في إصدار مستقر رسمي)
</div>

* نُقل إلى الفرع الأقدم في [#76997](https://github.com/ClickHouse/ClickHouse/issues/76997): إصلاح فقدان البيانات عند تفعيل async insert وتنفيذ insert into ... from file ... مع أحجام block غير متساوية؛ فإذا كان حجم الـ block الأول &lt; async&#95;max&#95;size لكن الـ block الثاني &gt; async&#95;max&#95;size، فلن يتم إدراج الـ block الثاني. وتبقى هذه البيانات في `squashing`. [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* نُقل إلى الفرع الأقدم في [#76675](https://github.com/ClickHouse/ClickHouse/issues/76675): إصلاح تهيئة `used_flag` في hash المتوازي. وقد يتسبب ذلك في تعطل الخادم. [#76580](https://github.com/ClickHouse/ClickHouse/pull/76580) ([Nikita Taranov](https://github.com/nickitat)).
* نُقل إلى الفرع الأقدم في [#76833](https://github.com/ClickHouse/ClickHouse/issues/76833): تفريغ مخازن buffer الخاصة بكتابة المخرجات قبل إنهائها. يُصلح هذا `LOGICAL_ERROR` الناتج أثناء الإنهاء النهائي لبعض تنسيقات الإخراج، مثل `JSONEachRowWithProgressRowOutputFormat`. [#76726](https://github.com/ClickHouse/ClickHouse/pull/76726) ([Antonio Andelic](https://github.com/antonio2368)).
* نُقل إلى الفرع الأقدم في [#77062](https://github.com/ClickHouse/ClickHouse/issues/77062): إصلاح فرز قيم `BFloat16`. هذا يُغلق [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487). وهذا يُغلق [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669). [#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
