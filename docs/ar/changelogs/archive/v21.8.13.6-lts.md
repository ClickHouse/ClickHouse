[#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الفرع الأقدم [#32146](https://github.com/ClickHouse/ClickHouse/issues/32146): إصلاح الخطأ `Directory ... already exists and is not empty` عند فصل part. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الفرع الأقدم [#32213](https://github.com/ClickHouse/ClickHouse/issues/32213): قد يُحدَّد عدد replicas النشطة بشكل غير صحيح عند إدراج البيانات باستخدام quorum إذا كان الإعداد `replicated_can_become_leader` معطلاً على بعض replicas. تم إصلاح ذلك. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الفرع الأقدم [#32312](https://github.com/ClickHouse/ClickHouse/issues/32312): قد تصبح identifiers الخاصة بـ XML Dictionaries، المستخدمة في table create query، مؤهلة إلى `default_database` أثناء upgrade إلى version أحدث. يُغلق [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963). [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* نُقل إلى الفرع الأقدم [#32540](https://github.com/ClickHouse/ClickHouse/issues/32540): قد تعلق بعض entries في replication queue لمدة `temporary_directories_lifetime` (يوم واحد افتراضياً) مع الخطأ `Directory tmp_merge_<part_name>` أو `Part ... (state Deleting) already exists, but it will be deleted soon` أو خطأ مشابه. تم إصلاح ذلك. يُصلح [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الفرع الأقدم [#32353](https://github.com/ClickHouse/ClickHouse/issues/32353): إصلاح تعطل مع SIGFPE في aggregate function ‏`avgWeighted` مع argument من نوع `Decimal`. يُصلح [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الفرع الأقدم [#33048](https://github.com/ClickHouse/ClickHouse/issues/33048): إصلاح احتمال حدوث استثناء عند بدء تشغيل محرك تخزين RabbitMQ عبر تأخير إنشاء القناة. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* نُقل إلى الفرع الأقدم [#32795](https://github.com/ClickHouse/ClickHouse/issues/32795): إصلاح تعطل عند استخدام fuzzBits مع تكرار نفس FixedString عدة مرات، وإغلاق [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737).
