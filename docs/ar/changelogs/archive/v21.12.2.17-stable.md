<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### إصلاحات الأخطاء (سلوك غير صحيح ظاهر للمستخدم في إصدار مستقر رسمي)
</div>

* نُقل إلى الفرع الأقدم [#32681](https://github.com/ClickHouse/ClickHouse/issues/32681): إصلاح إزالة الإسقاطات بشكل غير متوقع عند فصل الأجزاء. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* نُقل إلى الفرع الأقدم [#32483](https://github.com/ClickHouse/ClickHouse/issues/32483): إصلاح تحليل `'APPLY lambda'` الذي كان قد يؤدي إلى تعطل العميل/الخادم. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* نُقل إلى الفرع الأقدم [#32542](https://github.com/ClickHouse/ClickHouse/issues/32542): قد تعلق بعض العناصر في قائمة انتظار النسخ المتماثل لمدة `temporary_directories_lifetime` (يوم واحد افتراضيًا) مع الخطأ `Directory tmp_merge_<part_name>` أو `Part ... (state Deleting) already exists, but it will be deleted soon` أو خطأ مشابه. تم إصلاح ذلك. يصلح [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* نُقل إلى الفرع الأقدم [#32710](https://github.com/ClickHouse/ClickHouse/issues/32710): إصلاح حالات الفشل في الاستعلامات التي تحاول استخدام فهارس التخطي، والتي لم تُجسَّد بعد. يصلح [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) و[#30343](https://github.com/ClickHouse/ClickHouse/issues/30343). [#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* نُقل إلى الفرع الأقدم [#32569](https://github.com/ClickHouse/ClickHouse/issues/32569): إصلاح تعطل في `JoinCommon::removeColumnNullability`، ويغلق [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458). [#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* نُقل إلى الفرع الأقدم [#32770](https://github.com/ClickHouse/ClickHouse/issues/32770): إصلاح أداء القاموس `sparse_hashed` مع المفاتيح المتسلسلة (دالة hash غير صحيحة). [#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* نُقل إلى الفرع الأقدم [#32634](https://github.com/ClickHouse/ClickHouse/issues/32634): إصلاح دورة حياة الجدول (أي احتمال use-after-free) في حالة تنفيذ DROP TABLE وINSERT بالتوازي. [#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* نُقل إلى الفرع الأقدم [#32632](https://github.com/ClickHouse/ClickHouse/issues/32632): إصلاح Exception محتمل عند بدء تشغيل تخزين RabbitMQ عبر تأخير إنشاء القناة. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* نُقل إلى الفرع الأقدم [#32733](https://github.com/ClickHouse/ClickHouse/issues/32733): إصلاح شيفرة سيئة بشكل مفاجئ في الدالة `file`. [#32640](https://github.com/ClickHouse/ClickHouse/pull/32640) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* نُقل إلى الفرع الأقدم [#32793](https://github.com/ClickHouse/ClickHouse/issues/32793): إصلاح تعطل عند استخدام fuzzBits مع نفس FixedString عدة مرات، ويغلق [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737). [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
