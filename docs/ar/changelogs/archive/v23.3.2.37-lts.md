<div id="improvement">
  #### تحسين
</div>

* نُقل إلى الفرع الأقدم [#48459](https://github.com/ClickHouse/ClickHouse/issues/48459): أصبح المُنسِّق &#39;%M&#39; في الدالة `formatDateTime()` يعرض الآن اسم الشهر بدلًا من الدقائق. وهذا يجعل السلوك متسقًا مع MySQL. ويمكن استعادة السلوك السابق باستخدام الإعداد &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot;. [#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).
* نُقل إلى الفرع الأقدم [#48842](https://github.com/ClickHouse/ClickHouse/issues/48842): إصلاح مشكلة عدم التعامل مع بعض الإعدادات المتعلقة بـ MySQL عند استخدام مصدر قاموس MySQL مع مجموعة مسماة. يُغلق [#48402](https://github.com/ClickHouse/ClickHouse/issues/48402). [#48759](https://github.com/ClickHouse/ClickHouse/pull/48759) ([Kseniia Sumarokova](https://github.com/kssenii)).
* نُقل إلى الفرع الأقدم [#49035](https://github.com/ClickHouse/ClickHouse/issues/49035): إضافة آلية احتياطية للمصادقة بكلمة مرور عند فشل المصادقة باستخدام شهادة مستخدم SSL. يُغلق [#48974](https://github.com/ClickHouse/ClickHouse/issues/48974). [#48989](https://github.com/ClickHouse/ClickHouse/pull/48989) ([Nikolay Degterinsky](https://github.com/evillique)).
