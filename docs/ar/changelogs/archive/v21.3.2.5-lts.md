<div id="backward-incompatible-change">
  #### تغيير غير متوافق مع الإصدارات السابقة
</div>

* الآن ستُكتب جميع أسماء الدوال غير الحساسة لحالة الأحرف بأحرف صغيرة أثناء تحليل الاستعلام. وهذا ضروري لتوجيه استعلامات projection. [#20174](https://github.com/ClickHouse/ClickHouse/pull/20174) ([Amos Bird](https://github.com/amosbird)).

<div id="improvement">
  #### تحسينات
</div>

* إصلاح إنشاء `TTL` في الحالات التي يكون فيها تعبيره دالة ويتطابق مع مفتاح `ORDER BY`. أصبح الآن مسموحًا بتعيين aggregation مخصص لأعمدة primary key في `TTL` باستخدام `GROUP BY`. تغيير غير متوافق مع الإصدارات السابقة: بالنسبة إلى أعمدة primary key غير الموجودة في `GROUP BY` والتي لم تعد تُضبط صراحةً، ستُطبَّق الآن الدالة `any` بدلًا من `max` عند انتهاء `TTL`. كذلك، إذا كنت تستخدم `TTL` مع `WHERE` أو `GROUP BY`، فقد تظهر استثناءات أثناء عمليات الدمج عند إجراء rolling update. [#15450](https://github.com/ClickHouse/ClickHouse/pull/15450) ([Anton Popov](https://github.com/CurtizJ)).
* طلبات Hedged للاستعلامات البعيدة. عند تمكين الإعداد `use_hedged_requests` (وهو مفعّل افتراضيًا)، يُسمح بإنشاء عدة اتصالات مع replicas مختلفة للاستعلام. يُنشأ اتصال جديد إذا لم يتم إنشاء الاتصال الحالي (أو الاتصالات الحالية) مع replica (أو replicas) خلال `hedged_connection_timeout`، أو إذا لم يتم تلقي أي بيانات خلال `receive_data_timeout`. يستخدم الاستعلام أول اتصال يرسل حزمة Progress غير فارغة (أو حزمة Data إذا كان `allow_changing_replica_until_first_data_packet` مفعّلًا)، وتُلغى الاتصالات الأخرى. الاستعلامات التي تستخدم `max_parallel_replicas > 1` مدعومة. [#19291](https://github.com/ClickHouse/ClickHouse/pull/19291) ([Kruglov Pavel](https://github.com/Avogar)).
* طباعة الإطارات المضمنة لتتبعات المكدس القاتلة. [#19317](https://github.com/ClickHouse/ClickHouse/pull/19317) ([Ivan](https://github.com/abyss7)).
* عدم تجاهل أخطاء الكتابة بصمت. [#19451](https://github.com/ClickHouse/ClickHouse/pull/19451) ([Azat Khuzhin](https://github.com/azat)).
* أُضيف دعم `PREWHERE` عندما تكون للجداول تعبيرات أمان على مستوى الصف محددة. [#19576](https://github.com/ClickHouse/ClickHouse/pull/19576) ([Denis Glazachev](https://github.com/traceon)).
* إضافة واجهة IStoragePolicy. [#19608](https://github.com/ClickHouse/ClickHouse/pull/19608) ([Ernest Zaslavsky](https://github.com/kreuzerkrieg)).
* إضافة إمكانية تنظيم INSERT إلى `Distributed` استنادًا إلى حجم البايتات المعلّقة للإرسال غير المتزامن (تمت إضافة الإعدادات `bytes_to_delay_insert`/`max_delay_to_insert` و`bytes_to_throw_insert` إلى engine `Distributed`). [#19673](https://github.com/ClickHouse/ClickHouse/pull/19673) ([Azat Khuzhin](https://github.com/azat)).
* نقل الشروط غير المرتبطة بـ JOIN إلى WHERE clause. [#18720](https://github.com/ClickHouse/ClickHouse/issues/18720). [#19685](https://github.com/ClickHouse/ClickHouse/pull/19685) ([hexiaoting](https://github.com/hexiaoting)).
