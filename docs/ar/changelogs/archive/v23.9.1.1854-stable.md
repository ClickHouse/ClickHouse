<div id="new-feature">
  #### ميزة جديدة
</div>

* تمت إضافة نوع جديد من المصادقة يعتمد على مفاتيح SSH. وهو يعمل فقط مع بروتوكول Native TCP. [#41109](https://github.com/ClickHouse/ClickHouse/pull/41109) ([George Gamezardashvili](https://github.com/InfJoker)).
* تمت إضافة دعم لجدولة IO للأقراص البعيدة. يمكن الآن أن يحتوي قسم تهيئة التخزين لأنواع الأقراص `s3` و`s3_plain` و`hdfs` و`azure_blob_storage` على العنصرين `read_resource` و`write_resource` اللذين يحملان أسماء الموارد. ويمكن تهيئة سياسات الجدولة لهذه الموارد في قسم منفصل من تهيئة الخادم باسم `resources`. كما يمكن وسم الاستعلامات باستخدام الإعداد `workload` وتصنيفها باستخدام قسم تهيئة الخادم `workload_classifiers` لتحقيق أهداف متنوعة لجدولة الموارد. مزيد من التفاصيل في docs/en/operations/workload-scheduling.md. [#47009](https://github.com/ClickHouse/ClickHouse/pull/47009) ([Sergei Trifonov](https://github.com/serxa)).
* تمت إضافة عمود جديد &#95;block&#95;number لحل [#44532](https://github.com/ClickHouse/ClickHouse/issues/44532). [#47532](https://github.com/ClickHouse/ClickHouse/pull/47532) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* أُضيف الخياران `partial_result_update_duration_ms` و`max_rows_in_partial_result` لإظهار تحديثات النتيجة الجزئية لجدول الإخراج في الوقت الفعلي أثناء تنفيذ الاستعلام. [#48607](https://github.com/ClickHouse/ClickHouse/pull/48607) ([Alexey Perevyshin](https://github.com/alexX512)).
* تمت إضافة دعم لوضعي المطابقة غير الحساسة لحالة الأحرف وdot-all في قواميس RegExpTree. [#50906](https://github.com/ClickHouse/ClickHouse/pull/50906) ([Johann Gan](https://github.com/johanngan)).
* تمت إضافة دعم `ALTER TABLE MODIFY COMMENT`. ملاحظة: أُضيف شيء مشابه منذ وقت طويل بواسطة مساهم خارجي، لكن هذه الميزة لم تكن تعمل إطلاقًا ولم تسبّب سوى إرباك المستخدمين. هذا يغلق [#36377](https://github.com/ClickHouse/ClickHouse/issues/36377). [#51304](https://github.com/ClickHouse/ClickHouse/pull/51304) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* تمت إضافة &quot;GCD&quot;، المعروف أيضًا باسم &quot;القاسم المشترك الأكبر&quot;، كـ codec جديد لضغط البيانات. يحسب هذا الـ codec القاسم المشترك الأكبر لجميع قيم العمود، ثم يقسم كل قيمة على هذا القاسم. ويُعد codec GCD codec لإعداد البيانات (مشابهًا لـ Delta وDoubleDelta) ولا يمكن استخدامه بشكل مستقل. وهو يعمل مع أنواع بيانات الأعداد الصحيحة والعشرية والتاريخ/الوقت. ومن حالات الاستخدام المناسبة لـ codec GCD قيم الأعمدة التي تتغير (زيادةً أو نقصانًا) بمضاعفات القاسم المشترك الأكبر، مثل 24 - 28 - 16 - 24 - 8 - 24 (على افتراض أن GCD = 4). [#53149](https://github.com/ClickHouse/ClickHouse/pull/53149) ([Alexander Nam](https://github.com/seshWCS)).
* تمت إضافة اسمين مستعارين جديدين للأنواع هما &quot;DECIMAL(P)&quot; (كاختصار لـ &quot;DECIMAL(P, 0&quot;) و&quot;DECIMAL&quot; (كاختصار لـ &quot;DECIMAL(10, 0)&quot;). وهذا يجعل ClickHouse أكثر توافقًا مع لهجة SQL الخاصة بـ MySQL. [#53328](https://github.com/ClickHouse/ClickHouse/pull/53328) ([Val Doroshchuk](https://github.com/valbok)).
* تمت إضافة جدول سجل نظام جديد `backup_log` لتتبّع جميع عمليات `BACKUP` و`RESTORE`. [#53638](https://github.com/ClickHouse/ClickHouse/pull/53638) ([Victor Krasnov](https://github.com/sirvickr)).
* تمت إضافة إعداد format باسم &quot;output&#95;format&#95;markdown&#95;escape&#95;special&#95;characters&quot; (القيمة الافتراضية: false). يتحكم هذا الإعداد في ما إذا كانت المحارف الخاصة مثل &quot;!&quot; و&quot;#&quot; و&quot;$&quot; وغيرها تُفلت (أي تُسبق بمحرف backslash) في output format &quot;Markdown&quot;. [#53860](https://github.com/ClickHouse/ClickHouse/pull/53860) ([irenjj](https://github.com/irenjj)).
* تمت إضافة الدالة `decodeHTMLComponent`. [#54097](https://github.com/ClickHouse/ClickHouse/pull/54097) ([Bharat Nallan](https://github.com/bharatnc)).
* تمت إضافة peak&#95;threads&#95;usage إلى جدول query&#95;log. [#54335](https://github.com/ClickHouse/ClickHouse/pull/54335) ([Alexey Gerasimchuck](https://github.com/Demilivor)).
* تمت إضافة دعم SHOW FUNCTIONS إلى clickhouse-client. [#54337](https://github.com/ClickHouse/ClickHouse/pull/54337) ([Julia Kartseva](https://github.com/wat-ze-hex)).
* يُحسّن طلب السحب هذا استدلال المخطط من تنسيقات JSON: 1) أصبح من الممكن الآن استدلال named Tuples من JSON objects من دون JSON type التجريبي باستخدام الإعداد `input_format_json_try_infer_named_tuples_from_objects` في تنسيقات JSON. سابقًا، ومن دون JSON type التجريبي، كان يمكن استدلال JSON objects فقط على أنها Strings أو Maps، أما الآن فأصبح بالإمكان استدلال named Tuple. وسيحتوي نوع Tuple الناتج على جميع مفاتيح الكائنات التي تمت قراءتها في عينة البيانات أثناء استدلال المخطط. وقد يفيد ذلك عند قراءة بيانات JSON مهيكلة من دون كائنات sparse. وهذا الإعداد مفعّل افتراضيًا. 2) إتاحة parsing لـ JSON array إلى عمود من النوع String باستخدام الإعداد `input_format_json_read_arrays_as_strings`. ويمكن أن يساعد ذلك في قراءة المصفوفات التي تحتوي على values من types مختلفة. 3) إتاحة استخدام النوع String لمفاتيح JSON ذات types غير المعروفة (`null`/`[]`/`{}`) في بيانات العينة باستخدام الإعداد `input_format_json_infer_incomplete_types_as_strings`. يمكننا الآن في تنسيقات JSON قراءة أي value إلى عمود String، كما يمكن تجنّب ظهور الخطأ `Cannot determine type for column 'column_name' by first 25000 rows of data, most likely this column contains only Nulls or empty Arrays/Maps` أثناء استدلال المخطط باستخدام النوع String للأنواع غير المعروفة، وبذلك ستُقرأ البيانات بنجاح. [#54427](https://github.com/ClickHouse/ClickHouse/pull/54427) ([Kruglov Pavel](https://github.com/Avogar)).
* تمت إضافة الدالة &quot;toDaysSinceYearZero&quot; بالاسم المستعار &quot;TO&#95;DAYS()&quot; (للتوافق مع MySQL)، وتُرجع عدد الأيام المنقضية منذ 0001-01-01. [#54479](https://github.com/ClickHouse/ClickHouse/pull/54479) ([Robert Schulze](https://github.com/rschu1ze)).
* تمت إضافة الدوال YYYYMMDDtoDate(), YYYYMMDDtoDate32(), YYYYMMDDhhmmssToDateTime() و YYYYMMDDhhmmssToDateTime64(). وهي تحوّل تاريخًا أو تاريخًا مع وقت مُرمّزًا كعدد صحيح (مثل 20230911) إلى تاريخ أصلي أو تاريخ ووقت أصليين. وبذلك، فإنها توفّر الوظيفة المعاكسة للدوال الحالية YYYYMMDDToDate(), YYYYMMDDToDateTime(), YYYYMMDDhhmmddToDateTime(), YYYYMMDDhhmmddToDateTime64(). [#54509](https://github.com/ClickHouse/ClickHouse/pull/54509) ([Robert Schulze](https://github.com/rschu1ze)).
* تمت إضافة نوع عقدة IO scheduling باسم &quot;bandwidth&#95;limit&quot;. ويتيح لك تحديد قيود `max_speed` و `max_burst` على حركة المرور المارة عبر هذه العقدة. مزيد من التفاصيل في docs/en/operations/workload-scheduling.md. [#54618](https://github.com/ClickHouse/ClickHouse/pull/54618) ([Sergei Trifonov](https://github.com/serxa)).
* أصبحت الدالة `toDaysSinceYearZero()` تدعم الآن argument من النوع `DateTime` و `DateTime64`. [#54856](https://github.com/ClickHouse/ClickHouse/pull/54856) ([Serge Klochkov](https://github.com/slvrtrn)).
* إتاحة عناوين URL بأسلوب S3 لـ table functions `s3` و `gcs` و `oss`. ويُحوَّل URL تلقائيًا إلى HTTP. مثال: `'s3://clickhouse-public-datasets/hits.csv'` يُحوَّل إلى `'https://clickhouse-public-datasets.s3.amazonaws.com/hits.csv'`. [#54931](https://github.com/ClickHouse/ClickHouse/pull/54931) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* تمت إضافة عدة دوال لمسافة السلاسل النصية، بما في ذلك `byteHammingDistance` و `byteJaccardIndex` و `byteEditDistance`. ### إدخال توثيقي للتغييرات الموجّهة للمستخدم. [#54935](https://github.com/ClickHouse/ClickHouse/pull/54935) ([flynn](https://github.com/ucasfl)).
* إضافة إعداد جديد `print_pretty_type_names` لطباعة أسماء الأنواع المتداخلة العميقة بشكل منسّق، مثل Tuple/Maps/Arrays. [#55095](https://github.com/ClickHouse/ClickHouse/pull/55095) ([Kruglov Pavel](https://github.com/Avogar)).
