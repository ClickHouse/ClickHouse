<div id="clickhouse-release-v201014881-prestable-fixme-as-compared-to-v20914585-prestable">
  ### إصدار ClickHouse ‏v20.10.1.4881-prestable FIXME مقارنةً بـ v20.9.1.4585-prestable
</div>

<div id="backward-incompatible-change">
  #### تغيير غير متوافق مع الإصدارات السابقة
</div>

* إضافة دعم للتعليقات المتداخلة متعددة الأسطر `/* comment /* comment */ */` في SQL. وهذا يتوافق مع معيار SQL. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* تغيير القيمة الافتراضية للإعداد `format_regexp_escaping_rule` (وهو مرتبط بتنسيق `Regexp`) إلى `Raw` (أي قراءة النمط الفرعي بالكامل كقيمة) لجعل السلوك أقرب إلى ما يتوقعه المستخدمون. [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* جعل `multiple_joins_rewriter_version` متقادمًا. إزالة الإصدار الأول من مُعيد كتابة عمليات JOIN. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).

* دعم أنواع MySQL: ‏`decimal` (باعتباره `Decimal` في ClickHouse) و`datetime` بدقة أجزاء من الثانية (باعتباره `DateTime64`). ... [#11512](https://github.com/ClickHouse/ClickHouse/pull/11512) ([Vasily Nemkov](https://github.com/Enmk)).

[#13573](https://github.com/ClickHouse/ClickHouse/pull/13573) ([Amos Bird](https://github.com/amosbird)).
* إضافة ميزة جديدة: format ‏LineAsString التي تقبل تسلسلاً من line تفصل بينها أسطر جديدة و/أو مسافات و/أو فواصل. [#13846](https://github.com/ClickHouse/ClickHouse/pull/13846) ([hexiaoting](https://github.com/hexiaoting)).
* إعدادات جديدة لحدود query complexity، وهي `max_rows_to_read_leaf` و`max_bytes_to_read_leaf`، للاستعلامات الموزعة بهدف تقييد الحد الأقصى من الصفوف/البايتات المقروءة على leaf nodes. يُطبَّق هذا الحد على القراءات المحلية فقط، **باستثناء** مرحلة merge النهائية على root node. [#14221](https://github.com/ClickHouse/ClickHouse/pull/14221) ([Roman Khavronenko](https://github.com/hagen1778)).
* إضافة formats ‏JSONStrings التي تُخرج البيانات في Arrays من Strings. [#14333](https://github.com/ClickHouse/ClickHouse/pull/14333) ([hcz](https://github.com/hczhcz)).
* يمكن الآن أن تحتوي insert statements على asterisk (أو متغيراته) مع محوّلات column في قائمة الأعمدة. [#14453](https://github.com/ClickHouse/ClickHouse/pull/14453) ([Amos Bird](https://github.com/amosbird)).
* تمت إضافة برنامج نصي لاستيراد repository خاصة بـ git إلى ClickHouse. [#14471](https://github.com/ClickHouse/ClickHouse/pull/14471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* إضافة إمكانية تحديد `TTL ... RECOMPRESS codec_name` لعائلة MergeTree table engines. [#14494](https://github.com/ClickHouse/ClickHouse/pull/14494) ([alesapin](https://github.com/alesapin)).
* إضافة event&#95;time&#95;microseconds إلى جدولي `system.asynchronous_metric_log` و`system.metric_log`. [#14514](https://github.com/ClickHouse/ClickHouse/pull/14514) ([Bharat Nallan](https://github.com/bharatnc)).
* إضافة ميزة جديدة: SHOW DATABASES LIKE &#39;xxx&#39;. [#14521](https://github.com/ClickHouse/ClickHouse/pull/14521) ([hexiaoting](https://github.com/hexiaoting)).
* دعم Data type ‏Decimal في MaterializedMySQL. [#14535](https://github.com/ClickHouse/ClickHouse/pull/14535) ([Winter Zhang](https://github.com/zhang2014)).
* السماح بتمثيل قابل للتهيئة لـ NULL في TSV output format. ويُتحكَّم فيه بواسطة setting ‏`output_format_tsv_null_representation` التي تكون `\N` افتراضيًا. هذا يُغلق [#9375](https://github.com/ClickHouse/ClickHouse/issues/9375). لاحظ أن هذا setting يتحكم فقط في output format، وأن `\N` هو تمثيل NULL الوحيد المدعوم لـ TSV input format. [#14586](https://github.com/ClickHouse/ClickHouse/pull/14586) ([Kruglov Pavel](https://github.com/Avogar)).
* إضافة ميزة جديدة: format ‏LineAsString التي تقبل تسلسلاً من line تفصل بينها أسطر جديدة و/أو مسافات و/أو فواصل. [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* تمت إضافة الدالة `formatReadableQuantity`. وهي مفيدة لتسهيل قراءة الأرقام الكبيرة. [#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).

[#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).

* أصبحنا ندعم الآن الصيغة `WITH <identifier> AS (subquery) ... ` لإضافة استعلامات فرعية مسماة ضمن سياق الاستعلام. ويغلق هذا [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416). ويغلق هذا [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967). [#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).

<div id="performance-improvement">
  #### تحسين الأداء
</div>

* تفعيل compact parts افتراضيًا للأجزاء الصغيرة. يتيح ذلك معالجة عمليات `insert` المتكررة بكفاءة أعلى قليلًا (4..100 مرة). [#11913](https://github.com/ClickHouse/ClickHouse/pull/11913) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* تحسين أداء القيم بعرض 256 بت باستخدام (u)int64&#95;t بوصفه base type للأعداد الصحيحة العريضة. كانت الأعداد الصحيحة العريضة الأصلية تستخدم أنواع 8 بت كأساس. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* قصر قفل مقطع شيفرة `mlock` فقط عند بدء تشغيل clickhouse-server. في الإصدارات السابقة، كانت جميع المناطق المعيّنة تُقفل في الذاكرة، بما في ذلك معلومات Debug. وعادةً ما تُفصل معلومات Debug في ملف مستقل، لكن إذا لم يحدث ذلك، كان يؤدي إلى زيادة في memory usage بمقدار +2..3 GiB. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* كان يُختار سابقًا fixed key method للتجميع حسب fixed string واحد. وهذا غير ضروري لأن لدينا StringHashTable التي تنفّذ تحسين packedFix مشابهًا لأعمدة FixedString. وينبغي استخدام low&#95;cardinality&#95;key&#95;fixed&#95;string إن أمكن. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* إصلاح اختيار `DateTime <op> DateTime` الخاطئ للتنفيذ العام البطيء. يُصلح هذا [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153). [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* استخدام طلب S3 DeleteObjects واحد بدلًا من عدة طلبات DeleteObject داخل cycle. لا توجد أي تغييرات وظيفية، لذا فهذا مغطى بالاختبارات الحالية مثل integration/test&#95;log&#95;family&#95;s3. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* تسريع الضرب بعرض 256 بت. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* تحسين أداء `quantileTDigest`. يُصلح هذا [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668). [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* استخدام قرص مؤقت بشكل صريح لتخزين البيانات المؤقتة الخاصة بالدمج العمودي. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
