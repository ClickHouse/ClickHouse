  ## server_setting_name

الوصف.

صِف ما يُضبط في هذا القسم من الإعدادات.

القيمة الممكنة: ...

**الإعدادات** (اختياري)

إذا كان هذا القسم يتضمن عدة إعدادات، فأدرجها هنا. حدِّد القيم الممكنة والقيم الافتراضية:

* setting&#95;1 — الوصف.
* setting&#95;2 — الوصف.

**مثال**

```xml
<server_setting_name>
    <setting_1> ... </setting_1>
    <setting_2> ... </setting_2>
</server_setting_name>
```

**معلومات إضافية** (اختياري)

يمكن أن يكون اسم أي قسم إضافي أي شيء، على سبيل المثال: **الاستخدام**.
