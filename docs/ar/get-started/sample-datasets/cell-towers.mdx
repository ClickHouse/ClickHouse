## التحليل الجغرافي المكاني باستخدام أبراج الاتصال {#geospatial-analysis-with-cell-towers}

يوضح هذا الدليل كيفية تحميل بيانات أبراج `OpenCelliD` إلى `ClickHouse Cloud`، وإثرائها بقاموس للبلدان، والاستعلام عن الأبراج الموجودة في ألمانيا، ثم تصويرها باستخدام `ClickHouse Agents`.

<Steps>
  <Step title="حمّل البيانات النموذجية">
    في `ClickHouse Cloud`، افتح **Load data** واختر **Cell Towers** من **Sample data** ثم حمّل مجموعة البيانات. يمثل كل صف في `cell_towers` برجاً، وتحمل `lon` و`lat` إحداثياته.

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="استعلم عن الأبراج وأثرها">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;

    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="استخدم البيانات الجغرافية">
    يوفر `ClickHouse` دوال مثل [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon). أنشئ `germany`، وأدرج حدود ألمانيا القارية من [الدليل الإنكليزي](/get-started/sample-datasets/cell-towers#germany-polygon)، ثم احسب الأبراج داخل المضلع:

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    تكون النتيجة نحو `2.62 million`.
  </Step>
  <Step title="اختياري: صوّر البيانات باستخدام ClickHouse Agents">
    هذا مثال تشغيل اختياري: `ClickHouse Agents` ميزة تجريبية تعتمد على نموذج، لذلك قد تختلف الخطة والأدوات المستخدمة والمخرجات بين عمليات التشغيل. افتح **ClickHouse agents** وأرسل: "Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables".

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="محادثة ClickHouse Agent تنشئ شبكة كثافة للأبراج في ألمانيا"/>

    في إحدى عمليات التشغيل، عثر الوكيل على MCC الألماني وحسب الأبراج وجمعها في شبكة `0.1°` ورسم الحدود على الخريطة.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="خريطة حرارية لكثافة أبراج الاتصال في ألمانيا"/>
  </Step>
</Steps>
