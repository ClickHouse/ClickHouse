<div id="introduction">
  ## المقدمة
</div>

يُعدّ تصفية جدول في ClickHouse باستخدام عمود مصفوفي مهمة شائعة، ويوفّر المنتج العديد من [الدوال](/ar/reference/functions/regular-functions/array-functions) للتعامل مع الأعمدة من نوع Array.

في هذه المقالة، سنركّز على تصفية جدول باستخدام عمود مصفوفي، لكن الفيديو أدناه يستعرض أيضًا العديد من الدوال الأخرى المرتبطة بالمصفوفات:

<div id="example">
  ## مثال
</div>

سنستخدم مثالًا لجدول يضم عمودين هما `tags_string` و`tags_int`، ويحتويان على مصفوفة من السلاسل النصية ومصفوفة من الأعداد الصحيحة، على الترتيب.

* أنشئ قاعدة بيانات وجدولًا تجريبيين.

```sql
CREATE DATABASE db1;
```

* أنشئ جدولًا تجريبيًا

```sql
CREATE TABLE db1.tags_table
(
    `id` UInt64,
    `tags_string` Array(String),
    `tags_int` Array(UInt64),
)
ENGINE = MergeTree
ORDER BY id;
```

* أدرِج بعض البيانات التجريبية في الجدول.

```sql
INSERT INTO db1.tags_table VALUES (1, ['tag1', 'tag2', 'tag3'], [1, 2, 3]), (2, ['tag2', 'tag3', 'tag4'], [2, 3, 4]), (3, ['tag1', 'tag3', 'tag5'], [1, 3, 5]);
```

صفِّ الجدول باستخدام الدالة `has(arr, elem)` لإرجاع الصفوف التي تحتوي فيها `arr` على العنصر `elem`.

صفِّ الجدول لإرجاع الصفوف التي تحتوي فيها `tags_string` على العنصر `tag1`.

```sql
SELECT * FROM db1.tags_table WHERE has(tags_string, 'tag1');
```

```text
┌─id─┬─tags_string────────────┬─tags_int─┐
│  1 │ ['tag1','tag2','tag3'] │ [1,2,3]  │
│  3 │ ['tag1','tag3','tag5'] │ [1,3,5]  │
└────┴────────────────────────┴──────────┘
```

استخدم الدالة `hasAll(arr, elems)` لإرجاع الصفوف التي تكون فيها جميع العناصر في المصفوفة `elems` موجودة ضمن المصفوفة `arr`.

قم بتصفية الجدول لإرجاع الصفوف التي تكون فيها جميع العناصر في المصفوفة `tags_string` موجودة ضمن المصفوفة `['tag1', 'tag2']`.

```sql
SELECT * FROM db1.tags_table WHERE hasAll(tags_string, ['tag1', 'tag2']);
```

```text
┌─id─┬─tags_string────────────┬─tags_int─┐
│  1 │ ['tag1','tag2','tag3'] │ [1,2,3]  │
└────┴────────────────────────┴──────────┘
```

استخدم الدالة `hasAny(arr, elems)` لإرجاع الصفوف التي تحتوي فيها المصفوفة `arr` على عنصر واحد على الأقل من المصفوفة `elems`.

صفِّ الجدول لإرجاع الصفوف التي تحتوي فيها المصفوفة `tags_string` على عنصر واحد على الأقل من المصفوفة `['tag1', 'tag2']`.

```sql
SELECT * FROM db1.tags_table WHERE hasAny(tags_string, ['tag1', 'tag2']);
```

```text
┌─id─┬─tags_string────────────┬─tags_int─┐
│  1 │ ['tag1','tag2','tag3'] │ [1,2,3]  │
│  2 │ ['tag2','tag3','tag4'] │ [2,3,4]  │
│  3 │ ['tag1','tag3','tag5'] │ [1,3,5]  │
└────┴────────────────────────┴──────────┘
```

يمكننا استخدام دالة لامبدا لتصفية الجدول باستخدام الدالة `arrayExists(lambda, arr)`.

صفِّ الجدول لإرجاع الصفوف التي تحتوي فيها المصفوفة `tags_int` على عنصر واحد على الأقل أكبر من 3.

```sql
SELECT * FROM db1.tags_table WHERE arrayExists(x -> x > 3, tags_int);
```

```text
┌─id─┬─tags_string────────────┬─tags_int─┐
│  2 │ ['tag2','tag3','tag4'] │ [2,3,4]  │
│  3 │ ['tag1','tag3','tag5'] │ [1,3,5]  │
└────┴────────────────────────┴──────────┘
```
