<div id="overview">
  ## نظرة عامة
</div>

سيرشدك هذا الدليل إلى كيفية البدء في إعداد **MSK multi-VPC** لاستخدامه مع [نقطة النهاية الخاصة العكسية لـ ClickPipes](/ar/integrations/clickpipes/aws-privatelink#msk-multi-vpc).

<div id="requirements">
  ## المتطلبات
</div>

يجب أن تكون شبكة VPC الخاصة بـ عنقود MSK لديك ضمن إحدى مناطق ClickPipes لدينا. راجع [مناطق ClickPipes](/ar/integrations/clickpipes/aws-privatelink#aws-privatelink-regions) للاطلاع على قائمة المناطق المدعومة.

<div id="enabling-multi-vpc-connectivity">
  ## تمكين اتصال multi-VPC
</div>

1. انتقل إلى عنقود MSK.
   * اختر &quot;Clusters&quot; من جزء التنقل الأيسر في وحدة تحكم Amazon MSK.
   * حدِّد عنقود MSK الذي تريد تهيئته لاتصال multi-VPC.
2. فعِّل اتصال MSK multi-VPC
   * في علامة التبويب **Connectivity**، ابحث عن قسم **Multi-VPC connectivity**.
   * انقر على **Edit**.
   * فعِّل خيار **Turn-on MSK multi-VPC connectivity**.
   * اتبع التعليمات
3. أضف المعرّف الرئيسي لحساب ClickPipes إلى سياسة العنقود
   * انتقل إلى علامة التبويب **Configuration**.
   * انقر على **Edit** في قسم **Cluster policy**.
   * أدرِج `arn:aws:iam::072088201116:root` في **سياسة IAM**. مثال:
     ```json
     {
         "Version": "2012-10-17",
         "Statement": [
             {
                 "Effect": "Allow",
                 "Principal": {
                     "AWS": [
                         "arn:aws:iam::072088201116:root"
                     ]
                 },
                 "Action": [
                     "kafka:CreateVpcConnection",
                     "kafka:GetBootstrapBrokers",
                     "kafka:DescribeCluster",
                     "kafka:DescribeClusterV2"
                 ]
             }
         ]
     }
     ```

<Tip>
  تتيح سياسة IAM الخاصة بالعنقود لـ ClickPipes بدء الاتصال من ClickPipes إلى عنقود MSK لديك.
  إذا كنت تريد تهيئة IAM authentication لعنقود MSK لديك، فيُرجى الرجوع إلى [وثائق IAM authentication](/ar/integrations/clickpipes/kafka/best-practices#iam).
</Tip>
