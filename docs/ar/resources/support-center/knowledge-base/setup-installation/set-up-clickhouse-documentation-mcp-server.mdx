<Info>
  تُهيّئ هذه الصفحة خادم MCP للبحث في وثائق ClickHouse. وللاستعلام عن بيانات ClickHouse بدلاً من ذلك، استخدم [خادم MCP مفتوح المصدر لـ ClickHouse](/ar/guides/use-cases/ai-ml/MCP) أو [خادم MCP البعيد لـ ClickHouse Cloud](/ar/products/cloud/features/ai-ml/remote-mcp).
</Info>

استعلم مباشرةً من أدوات الذكاء الاصطناعي عن وثائق ClickHouse باستخدام Model Context Protocol ‏(MCP).

<div id="connect-your-ai-tool">
  ## اربط أداة الذكاء الاصطناعي الخاصة بك
</div>

<Tabs>
  <Tab title="Claude Code" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claudecode-color.svg">
    شغّل الأمر التالي في الطرفية:

    ```bash
    claude mcp add --transport http clickhouse-docs https://clickhouse.com/docs/mcp --scope user
    ```
  </Tab>

  <Tab title="Claude Desktop" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claude.svg">
    أضف ما يلي إلى `claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex" icon="/images/logo-codex.svg">
    شغّل الأمر التالي في الطرفية:

    ```bash
    codex mcp add clickhouse-docs --url https://clickhouse.com/docs/mcp
    ```
  </Tab>

  <Tab title="Cursor" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-cursor.png">
    أضف ما يلي إلى `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Windsurf" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-windsurf.svg">
    أضف ما يلي إلى `~/.codeium/windsurf/mcp_config.json`:

    ```json
    {
      "mcpServers": {
        "clickhouse-docs": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
        }
      }
    }
    ```
  </Tab>
</Tabs>

<div id="add-clickhouse-skills">
  ## أضف مهارات ClickHouse إلى وكيل البرمجة
</div>

ثبّت مهارات ClickHouse لتزويد وكيلك بمعرفة متخصصة بـ ClickHouse وأفضل الممارسات:

```bash
npx skills add https://clickhouse.com
```
