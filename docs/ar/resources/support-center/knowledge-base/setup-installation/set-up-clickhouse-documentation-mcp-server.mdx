<Info>
توضح هذه الصفحة كيفية إعداد خادم MCP للبحث في وثائق ClickHouse. للاستعلام عن بيانات ClickHouse بدلاً من ذلك، استخدم [خادم ClickHouse MCP مفتوح المصدر](/ar/guides/use-cases/ai-ml/MCP) أو [خادم ClickHouse Cloud MCP البعيد](/ar/products/cloud/features/ai-ml/remote-mcp).
</Info>

استعلِم من وثائق ClickHouse مباشرةً عبر أدوات الذكاء الاصطناعي لديك باستخدام Model Context Protocol (MCP).

## ربط أداة الذكاء الاصطناعي {#connect-your-ai-tool}

<Tabs>
<Tab title="Claude Code" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claudecode-color.svg">

شغّل في الطرفية:

```bash
claude mcp add --transport http clickhouse-docs https://clickhouse.com/docs/mcp --scope user
```

</Tab>
<Tab title="Claude Desktop" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claude.svg">

أضف إلى `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "clickhouse-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
    }
  }
}
```

</Tab>
<Tab title="Codex" icon="/images/logo-codex.svg">

شغّل في الطرفية:

```bash
codex mcp add clickhouse-docs --url https://clickhouse.com/docs/mcp
```

</Tab>
<Tab title="Cursor" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-cursor.png">

أضف إلى `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "clickhouse-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
    }
  }
}
```

</Tab>
<Tab title="Windsurf" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-windsurf.svg">

أضف إلى `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "clickhouse-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
    }
  }
}
```

</Tab>
</Tabs>

## إضافة مهارات ClickHouse إلى وكيل البرمجة {#add-clickhouse-skills}

ثبّت مهارات ClickHouse لمنح وكيلك معرفة متخصصة بـ ClickHouse وأفضل الممارسات:

```bash
npx skills add https://clickhouse.com
```
