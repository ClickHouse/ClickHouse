## مفاهيم ClickHouse الأساسية {#core-concepts}

تتطلب معظم مهام الإدارة الإلمام بقاعدة بيانات ClickHouse التي يعتمد عليها النظام. لذا نوصي بمراجعة مفاهيم ClickHouse الأساسية الموضحة أدناه قبل تنفيذ أي عمليات إدارية أو عمليات متعلقة بالأداء.

| المفهوم                                | الوصف                                                                                                                                                                                |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **الجداول**                            | كيفية ارتباط مصادر البيانات بجداول ClickHouse التي تعتمد عليها. تستخدم جداول ClickHouse في الأساس المحرك [`MergeTree`](/ar/reference/engines/table-engines/mergetree-family/mergetree). |
| **أجزاء البيانات**                     | كيفية كتابة البيانات في صورة أجزاء بيانات غير قابلة للتغيير، ثم دمجها بمرور الوقت.                                                                                                   |
| **التقسيمات**                          | تجميعات منطقية لأجزاء الجدول تُسهّل إدارة البيانات والاستعلام عنها وتحسينها.                                                                                                         |
| **عمليات الدمج**                       | عملية تجري في الخلفية لدمج أجزاء البيانات، بهدف تقليل عدد الأجزاء التي يشملها الاستعلام والحفاظ على الأداء.                                                                          |
| **حبيبات البيانات**                    | أصغر وحدة بيانات تُقرأ أو تُستبعد أثناء تنفيذ الاستعلام.                                                                                                                             |
| **المفاتيح الرئيسية (مفاتيح الترتيب)** | كيف يحدد مفتاح `ORDER BY` تخطيط البيانات على القرص، والضغط، وآلية استبعاد البيانات عند تنفيذ الاستعلامات.                                                                            |

تُعد هذه المفاهيم أساسية لأداء ClickHouse، وستساعدك على اتخاذ قرارات إدارية مدروسة عند إدارة Self-managed ClickHouse Observability.
