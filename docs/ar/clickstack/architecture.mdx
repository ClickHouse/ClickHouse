تقوم معمارية ClickStack Open Source على ثلاثة مكوّنات أساسية: **ClickHouse**، و**واجهة مستخدم ClickStack**، و**مُجمِّع OpenTelemetry (OTel)**. ويتولّى مثيل **MongoDB** تخزين حالة التطبيق. وتشكّل هذه المكوّنات معًا حزمة أدوات إمكانية المراقبة مفتوحة المصدر وعالية الأداء، ومُحسَّنة للسجلات والمقاييس والتتبّعات.

### ClickHouse: محرك قاعدة البيانات {#clickhouse}

في صميم ClickStack يأتي ClickHouse، وهي قاعدة بيانات عمودية التوجّه صُممت للتحليلات الفورية على نطاق واسع. وهي تدعم استيعاب بيانات إمكانية المراقبة والاستعلام عنها، بما يتيح:

* بحثًا بزمن أقل من ثانية عبر تيرابايتات من الأحداث
* استيعاب مليارات السجلات عالية الكاردينالية يوميًا
* معدلات ضغط عالية لا تقل عن 10x لبيانات إمكانية المراقبة
* دعمًا أصيلًا لبيانات JSON شبه المهيكلة، بما يتيح تطوّر المخطط ديناميكيًا
* محرك SQL قويًا يضم مئات الدوال التحليلية المضمّنة

يتعامل ClickHouse مع بيانات إمكانية المراقبة على هيئة أحداث موسّعة، ما يتيح ربطًا عميقًا بين السجلات والمقاييس والتتبعات ضمن بنية موحّدة واحدة.

### مُجمِّع OpenTelemetry: استيعاب البيانات {#open-telemetry-collector}

يتضمن ClickStack مُجمِّع OpenTelemetry (OTel) مُعدًا مسبقًا لاستيعاب بيانات telemetry بطريقة مفتوحة وموحّدة. ويمكنك إرسال البيانات باستخدام بروتوكول OTLP عبر:

* gRPC (المنفذ `4317`)
* HTTP (المنفذ `4318`)

يُصدّر المُجمِّع بيانات telemetry إلى ClickHouse على دفعات فعّالة. كما يدعم مخططات جداول محسّنة لكل مصدر بيانات، بما يضمن أداءً قابلًا للتوسع عبر جميع أنواع الإشارات.

### واجهة مستخدم ClickStack: الواجهة {#hyperdx-ui}

تُعد واجهة مستخدم ClickStack واجهة المستخدم الخاصة بـ ClickStack. وهي توفّر:

* بحثًا باللغة الطبيعية وبأسلوب Lucene
* تتبّعًا مباشرًا لتصحيح الأخطاء في الوقت الفعلي
* عروضًا موحّدة للسجلات والمقاييس والتتبعات
* إعادة تشغيل الجلسات لإمكانية المراقبة للواجهة الأمامية
* إنشاء لوحات المعلومات وتهيئة التنبيهات
* واجهة استعلام SQL للتحليل المتقدم

صُممت واجهة مستخدم ClickStack خصيصًا لـ ClickHouse، وهي تجمع بين البحث القوي وسير العمل السلس، بما يتيح لك اكتشاف الحالات الشاذة والتحقيق في المشكلات واستخلاص الرؤى بسرعة.

### MongoDB: حالة التطبيق {#mongo}

يستخدم ClickStack قاعدة بيانات MongoDB لتخزين الحالة على مستوى التطبيق، بما في ذلك:

* لوحات المعلومات
* التنبيهات
* ملفات تعريف المستخدمين
* التمثيلات المرئية المحفوظة

يضمن هذا الفصل بين الحالة وبيانات الأحداث الأداء العالي وقابلية التوسع، كما يُبسّط عمليات النسخ الاحتياطي والتهيئة.

وبفضل هذه المعمارية المعيارية، يقدّم ClickStack منصة متكاملة لإمكانية المراقبة جاهزة للاستخدام فورًا، تتميز بالسرعة والمرونة، وهي مفتوحة المصدر.
