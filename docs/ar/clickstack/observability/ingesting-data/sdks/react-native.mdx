استخدم OpenTelemetry لإرسال بيانات التتبّع من طبقة JavaScript في تطبيق React Native إلى ClickHouse Observability.

<ClickStackIntegrates signals={['traces']} />

## إعداد OpenTelemetry {#set-up-opentelemetry}

اتبع [العرض التوضيحي الرسمي لـ OpenTelemetry مع React Native](https://opentelemetry.io/docs/demo/services/react-native-app/) و[الشيفرة المصدرية الخاصة بإضافة أدوات الرصد](https://github.com/open-telemetry/opentelemetry-demo/tree/main/src/react-native-app) فيه لتهيئة التتبّع وإضافة أدوات الرصد إلى طلبات الشبكة.

يعتمد العرض التوضيحي على حزم OpenTelemetry الخاصة بـ JavaScript، وهي غير مدعومة رسميًا على React Native. لذا تحقّق من توافقها مع إصدارَي React Native وOpenTelemetry المستخدمَين في تطبيقك.

## تهيئة الوجهة {#configure-destination}

استبدل تهيئة المُصدِّر المحلي في العرض التوضيحي بالوجهة الموضحة أدناه. استخدم هذا المُصدِّر في معالج span ضمن الإعداد الوارد في المصدر الأصلي. يجب أن يتضمن URL المُصدِّر المسار `/v1/traces`.

<Tabs>
  <Tab title="مُدار بالكامل">
    <BetaBadge label="خدمة في المرحلة التجريبية" />

    افتح **إعدادات الفريق → بيانات → بيانات القياس عن بُعد المُدارة** في خدمتك، وانسخ **نقطة نهاية OTLP عبر HTTP** و**مفتاح API**. احتفظ بنقطة نهاية HTTPS كاملةً بما فيها المنفذ، ثم ألحِق بها `/v1/traces`:

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_OTEL_ENDPOINT:4318/v1/traces',
      headers: {
        Authorization: 'Bearer YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>

  <Tab title="مُدار ذاتيًا">
    استخدم نقطة نهاية OTLP عبر HTTP الخاصة بجامع البيانات ومفتاح الاستيعاب. يجب أن يكون الوصول إلى جامع البيانات ممكنًا من الجهاز. لإعداد جامع البيانات، راجع [استيعاب البيانات باستخدام OpenTelemetry](/ar/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_COLLECTOR_HOST:4318/v1/traces',
      headers: {
        Authorization: 'YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>
</Tabs>

## التحقق من إدخال البيانات {#verify-ingestion}

شغّل تطبيقك على جهاز فعلي أو على محاكٍ، ثم أرسل بعض طلبات الشبكة. في ClickHouse Observability، حدّد نطاقًا زمنيًا حديثًا وابحث عن اسم الخدمة الخاص بتطبيقك ضمن التتبّعات (Traces).

للاطلاع على تفاصيل إضافة أدوات الرصد والحلول البديلة لمشكلات التوافق مع React Native، راجع [العرض التوضيحي لـ OpenTelemetry مع React Native](https://opentelemetry.io/docs/demo/services/react-native-app/). وللاطلاع على خيارات المُصدِّر، راجع [توثيق مُصدِّرات OpenTelemetry للغة JavaScript](https://opentelemetry.io/docs/languages/js/exporters/).
