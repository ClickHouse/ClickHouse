استخدم دعم OpenTelemetry المدمج في Deno لإرسال السجلات والمقاييس والتتبّعات إلى ClickHouse Observability، دون الحاجة إلى ClickStack Node.js SDK أو حزمة التسجيل القديمة الخاصة بـ Deno.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## إعداد OpenTelemetry {#set-up-opentelemetry}

اتبع [تعليمات إعداد OpenTelemetry في Deno](https://docs.deno.com/runtime/fundamentals/open_telemetry/) الرسمية لتزويد تطبيقك بأدوات جمع بيانات الرصد. هيّئ الوجهة أدناه، ثم فعّل التكامل المدمج في Deno عند تشغيل تطبيقك:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

أضف الصلاحيات التي يحتاجها تطبيقك. واستبدل أي وجهات تجريبية أو إعدادات مُصدِّر وحدة التحكم الواردة في تعليمات المصدر الأصلي، بما في ذلك تجاوزات إعدادات نقطة النهاية الخاصة بكل نوع من الإشارات.

## تهيئة الوجهة {#configure-destination}

<Tabs>
  <Tab title="مُدار بالكامل">
    <BetaBadge label="خدمة في المرحلة التجريبية" />

    افتح **إعدادات الفريق ← بيانات ← بيانات القياس عن بُعد المُدارة** في خدمتك، ثم انسخ **نقطة نهاية OTLP عبر HTTP** و**مفتاح API**. استخدم نقطة نهاية HTTPS كاملةً، بما فيها رقم المنفذ:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="مُدار ذاتيًا">
    استخدم نقطة نهاية OTLP عبر HTTP الخاصة بجامع البيانات لديك، إلى جانب مفتاح الاستيعاب. وإذا لم يكن TLS مُهيّأً على جامع البيانات، فاستخدم `http://` بدلًا من `https://`. لمعرفة كيفية إعداد جامع البيانات، راجع [استيعاب البيانات باستخدام OpenTelemetry](/ar/clickstack/observability/ingesting-data/opentelemetry#self-managed).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## التحقق من إدخال البيانات {#verify-ingestion}

شغّل تطبيقك وولّد بعض النشاط. في ClickHouse Observability، اختر نطاقًا زمنيًا حديثًا وابحث عن اسم الخدمة الخاص بتطبيقك في السجلات أو التتبّعات. وبعد مرور وقت كافٍ لإتمام عملية التصدير، تحقّق من المقاييس.
