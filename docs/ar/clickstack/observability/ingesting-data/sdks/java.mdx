استخدم وكيل OpenTelemetry لتطبيقات Java أو حزمة SDK لإرسال السجلات والمقاييس وبيانات التتبّع إلى ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## إعداد OpenTelemetry {#set-up-opentelemetry}

اتبع [تعليمات الإعداد الرسمية لوكيل OpenTelemetry لتطبيقات Java](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/) لتثبيت أدوات الرصد وتهيئة تطبيقك. ولإضافة أدوات الرصد يدويًا، راجع [وثائق Java SDK](https://opentelemetry.io/docs/languages/java/instrumentation/).

هيّئ [تصدير OTLP](https://opentelemetry.io/docs/languages/java/configuration/#properties-exporters) للإشارات التي تريد إرسالها باستخدام إعدادات الاتصال أدناه. واستبدل أي وجهات مذكورة على سبيل المثال في تعليمات المصدر الأصلي، بما في ذلك تجاوزات إعدادات نقاط النهاية الخاصة بكل إشارة.

## تهيئة الوجهة {#configure-destination}

<Tabs>
  <Tab title="مُدار بالكامل">
    <BetaBadge label="إصدار تجريبي" />

    افتح **Team Settings → Data → Managed Telemetry** في خدمتك، وانسخ **نقطة نهاية OTLP HTTP** و**مفتاح API**. استخدم نقطة نهاية HTTPS كاملةً، بما في ذلك المنفذ:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="مُدار ذاتيًا">
    استخدم نقطة نهاية OTLP HTTP الخاصة بجامع البيانات لديك ومفتاح الإدخال. وإذا لم يكن TLS مهيّأً على جامع البيانات، فاستخدم `http://` بدلًا من `https://`. لمعرفة كيفية إعداد جامع البيانات، راجع [إدخال البيانات باستخدام OpenTelemetry](/ar/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## التحقق من إدخال البيانات {#verify-ingestion}

شغّل تطبيقك المزوّد بأدوات الرصد وولّد بعض النشاط. في ClickHouse Observability، اختر نطاقًا زمنيًا حديثًا وابحث عن اسم الخدمة الخاص بتطبيقك ضمن السجلات أو التتبّعات. إذا كان تطبيقك يُصدر مقاييس، فراجع المقاييس بعد إتاحة وقت كافٍ لإتمام التصدير.

لاستكشاف أخطاء إضافة أدوات الرصد والمُصدِّر وإصلاحها، راجع [إرشادات استكشاف الأخطاء وإصلاحها الخاصة بوكيل OpenTelemetry لتطبيقات Java](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/#troubleshooting).
