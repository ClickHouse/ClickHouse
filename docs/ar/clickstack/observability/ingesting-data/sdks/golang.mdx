استخدم OpenTelemetry Go SDK لإرسال السجلات والمقاييس وبيانات التتبّع إلى ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## إعداد OpenTelemetry {#set-up-opentelemetry}

اتبع [تعليمات إعداد OpenTelemetry لـ Go](https://opentelemetry.io/docs/languages/go/getting-started/) الرسمية لتهيئة SDK وتزويد تطبيقك بأدوات جمع بيانات الرصد.

هيّئ [تصدير OTLP عبر HTTP](https://opentelemetry.io/docs/languages/go/exporters/) للإشارات التي تريد إرسالها، مستخدمًا إعدادات الاتصال أدناه. واستبدل أي وجهات واردة على سبيل المثال في تعليمات المصدر الأصلي، بما في ذلك تجاوزات إعدادات نقطة النهاية الخاصة بكل إشارة.

## تهيئة الوجهة {#configure-destination}

<Tabs>
  <Tab title="مُدار بالكامل">
    <BetaBadge label="إصدار تجريبي" />

    افتح **إعدادات الفريق ← البيانات ← القياس عن بُعد المُدار** في خدمتك، وانسخ **نقطة نهاية OTLP HTTP** و**مفتاح API**. استخدم نقطة نهاية HTTPS كاملةً بما فيها المنفذ:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="مُدار ذاتيًا">
    استخدم نقطة نهاية OTLP HTTP الخاصة بجامع البيانات ومفتاح الإدخال. واستخدم `http://` بدلًا من `https://` إذا لم يكن TLS مهيأً على جامع البيانات. لمعرفة كيفية إعداد جامع البيانات، راجع [إدخال البيانات باستخدام OpenTelemetry](/ar/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## التحقق من إدخال البيانات {#verify-ingestion}

شغّل تطبيقك المزوّد بأدوات الرصد وولّد بعض النشاط. في ClickHouse Observability، حدّد نطاقًا زمنيًا حديثًا وابحث عن اسم الخدمة الخاص بتطبيقك ضمن السجلات أو التتبّعات. وإذا كان تطبيقك يُصدر مقاييس، فراجع قسم المقاييس بعد الانتظار قليلًا حتى تكتمل عملية التصدير.

لاستكشاف أخطاء إضافة أدوات الرصد والمُصدِّر وإصلاحها، راجع [وثائق OpenTelemetry Go](https://opentelemetry.io/docs/languages/go/).
