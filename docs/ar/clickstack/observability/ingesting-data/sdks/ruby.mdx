استخدم حزمة OpenTelemetry Ruby SDK لإرسال بيانات التتبّع إلى ClickHouse Observability.

<ClickStackIntegrates signals={['traces']} />

## إعداد OpenTelemetry {#set-up-opentelemetry}

اتبع [تعليمات إعداد OpenTelemetry لـ Ruby](https://opentelemetry.io/docs/languages/ruby/getting-started/) الرسمية لتهيئة SDK وتزويد تطبيقك بأدوات جمع بيانات الرصد.

هيّئ [تصدير OTLP عبر HTTP](https://opentelemetry.io/docs/languages/ruby/exporters/) لبيانات التتبّع باستخدام إعدادات الاتصال أدناه. استبدل أي وجهات واردة كأمثلة في تعليمات المصدر الأصلي، بما في ذلك تجاوزات الإعدادات الخاصة بنقاط النهاية لكل إشارة على حدة.

## تهيئة الوجهة {#configure-destination}

<Tabs>
  <Tab title="مُدار بالكامل">
    <BetaBadge label="خدمة في المرحلة التجريبية" />

    افتح **إعدادات الفريق ← البيانات ← بيانات القياس عن بُعد المُدارة** في خدمتك، ثم انسخ **نقطة نهاية OTLP عبر HTTP** و**مفتاح API**. استخدم نقطة نهاية HTTPS كاملةً بما فيها رقم المنفذ:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="مُدار ذاتيًا">
    استخدم نقطة نهاية OTLP عبر HTTP الخاصة بجامع البيانات لديك، إلى جانب مفتاح الاستيعاب. وإذا لم يكن TLS مُهيأً على جامع البيانات، فاستخدم `http://` بدلًا من `https://`. لمعرفة كيفية إعداد جامع البيانات، راجع [استيعاب البيانات باستخدام OpenTelemetry](/ar/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## التحقق من إدخال البيانات {#verify-ingestion}

شغّل تطبيقك المزوّد بأدوات الرصد وأنشئ بعض النشاط. في ClickHouse Observability، اختر نطاقًا زمنيًا حديثًا وابحث عن اسم الخدمة الخاص بتطبيقك ضمن Traces.

لاستكشاف أخطاء إضافة أدوات الرصد والمُصدِّر وإصلاحها، راجع [وثائق OpenTelemetry الخاصة بـ Ruby](https://opentelemetry.io/docs/languages/ruby/).
