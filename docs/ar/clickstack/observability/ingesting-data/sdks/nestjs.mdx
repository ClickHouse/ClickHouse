استخدم ClickStack Node.js SDK لجمع بيانات القياس عن بُعد من تطبيق NestJS وإرسالها إلى ClickHouse Observability. تتضمن هذه الأداة إضافة أدوات الرصد لطلبات NestJS، كما تلتقط مخرجات وحدة التحكم.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## تثبيت حزمة SDK {#install-sdk}

استخدم Node.js 22.15 أو إصدارًا أحدث:

```shell
npm install @clickhouse/clickstack-node
```

## تهيئة الوجهة {#configure-destination}

<Tabs>
  <Tab title="مُدار بالكامل">
    <BetaBadge label="عرض تجريبي" />

    افتح **Team Settings → Data → Managed Telemetry** في خدمتك، ثم انسخ **نقطة نهاية OTLP HTTP** و**API key**. استخدم نقطة نهاية HTTPS كاملةً بما فيها المنفذ:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="مُدار ذاتيًا">
    استخدم نقطة نهاية OTLP HTTP الخاصة بجامع البيانات ومفتاح الإدخال. استخدم `http://` بدلًا من `https://` إذا لم يكن TLS مهيّأً في جامع البيانات لديك. لمعرفة كيفية إعداد جامع البيانات، راجع [إدخال البيانات باستخدام OpenTelemetry](/ar/clickstack/observability/ingesting-data/opentelemetry#self-managed).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## تشغيل تطبيقك {#start-application}

اضبط `OTEL_SERVICE_NAME` لتعريف تطبيقك. أنشئ إصدار تطبيق NestJS، ثم حمّل SDK مسبقًا قبل نقطة الدخول المُصرَّفة:

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

عدّل `dist/main.js` ليتوافق مع مخرجات الإصدار لديك. إذا كنت تستخدم `ts-node` أو أي مُحوِّل شيفرة آخر يعترض `require`، فاستخدم `--require @clickhouse/clickstack-node/register` بدلاً من ذلك. وإذا كنت تجمع تطبيقك في حزمة، فأبقِ الـ SDK والتبعيات المزوّدة بأدوات الرصد خارجها.

يمكنك مواصلة استخدام مسجّل السجلات الافتراضي الخاص بوحدة التحكم في NestJS. أما إذا أردت استخدام مسجّل سجلات مخصص، فاعتمد تكاملاً مدعوماً مثل Winston أو Pino. للاطلاع على تفاصيل التهيئة والتوافق، راجع [دليل Node.js](/ar/clickstack/observability/ingesting-data/sdks/nodejs).

## التحقق من إدخال البيانات {#verify-ingestion}

أرسل طلبًا إلى وحدة تحكم واجعلها تُصدر رسالة سجل. بعد ذلك، اختر في ClickHouse Observability نطاقًا زمنيًا حديثًا، وابحث عن اسم الخدمة الخاص بتطبيقك ضمن السجلات (Logs) وعمليات التتبّع (Traces). ثم تحقّق من المقاييس (Metrics) بعد منح البيانات وقتًا كافيًا للتصدير.
