يمكن فتح صفحات ClickHouse Observability عبر روابط عميقة باستخدام معلمات الاستعلام في URL، ما يتيح لك الانتقال مباشرةً إلى عملية بحث أو لوحة معلومات أو لوحة عرض بعينها من نظام خارجي (كإشعار تنبيه، أو دليل تشغيل، أو مهمة تكامل مستمر، أو رسالة دردشة، وغير ذلك).

تستخدم الأمثلة في هذه الصفحة `<YOUR_CLICKSTACK_URL>`. استبدل هذه القيمة بعنوان URL الأساسي لواجهة UI الخاصة بإمكانية المراقبة لديك.

<Note>
  تعرض الأمثلة معلمات الاستعلام دون ترميز URL لتسهيل قراءتها. عند إنشاء الروابط برمجيًا، رمِّز قيمة كل مَعلمة استعلام بترميز URL.
</Note>

<Info>
  **مَعلمة معرّف الخدمة السحابية**

  عند استخدام Cloud UI، ينبغي أن تتضمن الروابط المَعلمة `?chcServiceId=` لتحديد خدمة ClickHouse Cloud المطلوب تحميلها، إذا كان المستخدم المُصادَق عليه الذي يفتح الرابط مخوّلًا باستخدام أكثر من خدمة ClickHouse Cloud واحدة.

  مثال: فتح صفحة البحث على خدمة سحابية محددة

  ```text
  https://hyperdx.clickhouse.cloud/search?chcServiceId=abc123
  ```
</Info>

## بحث — `/search` {#search}

واجهة البحث الرئيسية في السجلات والتتبّعات. راجع [بحث](/ar/clickstack/observability/features/search) للاطلاع على تفاصيل صيغة البحث.

| معلمة           | الصيغة                                                                     | الوصف                                                                                                                  |
| --------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `source`        | string                                                                     | المصدر المراد البحث فيه، ويقبل معرّف المصدر أو **اسمه** (مثل `Logs`). لا تدعم هذه الصفحة سوى مصادر السجلات والتتبّعات. |
| `where`         | string                                                                     | نص استعلام التصفية، بصيغة Lucene أو SQL (راجع `whereLanguage`).                                                        |
| `whereLanguage` | `lucene` | `sql`                                                           | لغة الاستعلام المكتوب بها `where`.                                                                                     |
| `select`        | string                                                                     | قائمة أعمدة/تعبيرات SQL المراد عرضها في جدول النتائج.                                                                  |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | عوامل تصفية مهيكلة حسب الأوجه، تُطبَّق إضافةً إلى `where`.                                                             |
| `orderBy`       | string                                                                     | تعبير SQL للفرز في جدول النتائج.                                                                                       |
| `mode`          | `results` | `delta` | `pattern`                                            | وضع التحليل النشط. لا يتوفر `delta` إلا لمصادر التتبّع.                                                                |
| `isLive`        | `true` | `false`                                                           | ما إذا كانت المتابعة المباشرة مفعّلة (القيمة الافتراضية `true`).                                                       |
| `traceId`       | string                                                                     | ينتقل مباشرةً إلى مخطط التتبّع الشلالي لمعرّف التتبّع المحدد.                                                          |
| `from`, `to`    | مللي ثانية منذ حقبة Unix                                                   | النطاق الزمني المطلق. عند عدم تحديده، يُستخدم افتراضيًا آخر 15 دقيقة.                                                  |

يمكن أيضًا فتح بحث محفوظ مباشرةً عبر `/search/<savedSearchId>`.

### مثال: البحث في المصدر `Logs` عن الأخطاء في الخدمة `checkout` ضمن نطاق زمني محدد {#example-search-errors}

```text
<YOUR_CLICKSTACK_URL>/search?source=Logs&from=1735689600000&to=1735693200000&where=level:error&filters=[{"type":"sql","condition":"ServiceName IN ('checkout')"}]
```

### مثال: الانتقال مباشرةً إلى عرض الشلال لتتبّعٍ معيّن {#example-search-trace}

```text
<YOUR_CLICKSTACK_URL>/search?source=Traces&traceId=ba7217967eb90d040b7eb39f97ecc5c4
```

## عمليات البحث المحفوظة — `/search/list` {#saved-searches}

قائمة عمليات البحث المحفوظة.

| المعلمة | الصيغة | الوصف                                                       |
| ------- | ------ | ----------------------------------------------------------- |
| `tag`   | string | يقصر القائمة على عمليات البحث المحفوظة التي تحمل هذا الوسم. |

### مثال: استعراض عمليات البحث المحفوظة الموسومة بـ `production` {#example-saved-searches-tag}

```text
<YOUR_CLICKSTACK_URL>/search/list?tag=production
```

## لوحات المعلومات — `/dashboards/<dashboardId>` {#dashboards}

لوحة معلومات محفوظة. احذف `<dashboardId>` (`/dashboards`) لفتح لوحة معلومات مؤقتة غير محفوظة. راجع [لوحات المعلومات](/ar/clickstack/observability/features/dashboards/overview) لمزيد من التفاصيل حول إنشاء لوحات المعلومات.

| معلمة               | الصيغة                                                                                                                              | الوصف                                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `from`، `to`        | مللي ثانية منذ حقبة Unix                                                                                                            | النطاق الزمني المطبَّق على جميع المربعات. إذا لم يُحدَّد، فالقيمة الافتراضية هي آخر 15 دقيقة.                              |
| `where`             | string                                                                                                                              | نص استعلام عامل التصفية على مستوى لوحة المعلومات، ويُطبَّق على جميع المربعات.                                              |
| `whereLanguage`     | `lucene` | `sql`                                                                                                                    | لغة الاستعلام المكتوب بها `where`.                                                                                         |
| `filters`           | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]`                                                          | قيم عوامل التصفية المهيكلة للوحة المعلومات، وفي هذا المثال تُحدِّد عنصرين في القائمة المنسدلة لعامل التصفية `ServiceName`. |
| `granularity`       | `auto` | `30 second` | `1 minute` | `5 minute` | `10 minute` | `15 minute` | `30 minute` | `1 hour` | `12 hour` | `1 day` | `7 day` | حجم الفاصل الزمني في مربعات time-series. تختار القيمة `auto` حجم الفاصل تلقائيًا بناءً على النطاق الزمني المحدد.           |
| `highlightedTileId` | string                                                                                                                              | ينتقل إلى مربع معيّن ويُبرزه، وهو مفيد عند الانتقال إليه عبر رابط من تنبيه.                                            |

### مثال: فتح لوحة معلومات لنطاق زمني محدد مع إبراز مربع واحد {#example-dashboard-highlight}

يُفيد ذلك عند وضع رابط في إشعار تنبيه يؤدي مباشرةً إلى المربع الذي أطلق التنبيه.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?from=1735689600000&to=1735693200000&highlightedTileId=chart-1
```

## مستكشف المخططات — `/chart` {#chart-explorer}

أداة مخصصة لإنشاء المخططات وقابلة للمشاركة.

| معلمة        | الصيغة                   | الوصف                                                                                                                                            |
| ------------ | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `config`     | JSON                     | التهيئة الكاملة للمخطط (المصدر، وselect، وwhere، ونوع المخطط، وغير ذلك). تُنشأ عادةً عبر روابط «مشاركة» من داخل التطبيق بدلًا من كتابتها يدويًا. |
| `from`، `to` | مللي ثانية منذ حقبة Unix | النطاق الزمني. إذا لم يُحدَّد، فالقيمة الافتراضية هي آخر 15 دقيقة.                                                                               |

### مثال: فتح تهيئة مخطط زمن الانتقال p99 ضمن نطاق زمني محدد {#example-chart-config}

```text
<YOUR_CLICKSTACK_URL>/chart?granularity=auto&from=1785759381784&to=1785762981785&config={"name":"","select":[{"aggFn":"quantile","aggCondition":"","aggConditionLanguage":"lucene","valueExpression":"Duration","level":0.99,"alias":"p99"}],"where":"","whereLanguage":"lucene","displayType":"line","alignDateRangeToGranularity":true,"source":"68814eb5d40a9d0449afc1f2","connection":"68814b6fd40a9d0449afbe78","groupBy":"ServiceName"}
```

## التنبيهات — `/alerts` {#alerts}

راجع [التنبيهات](/ar/clickstack/observability/features/alerts) للاطلاع على تفاصيل إنشاء التنبيهات وإدارتها.

| المعلمة   | الصيغة | الوصف                                              |
| --------- | ------ | -------------------------------------------------- |
| `search`  | string | عامل تصفية بنص حر يُطبَّق على اسم التنبيه أو وصفه. |
| `tag`     | string | التصفية حسب الوسم.                                 |
| `creator` | string | التصفية حسب اسم منشئ التنبيه.                      |

### مثال: عرض التنبيهات الموسومة بـ `on-call` {#example-alerts-filter}

```text
<YOUR_CLICKSTACK_URL>/alerts?tag=on-call
```

## إعادة تشغيل الجلسة — `/sessions` {#session-replay}

تصفّح الجلسات وإعادة تشغيلها. راجع [إعادة تشغيل الجلسة](/ar/clickstack/observability/features/session-replay) للاطلاع على تفاصيل الميزة.

| معلمة           | صيغة                     | الوصف                                                                                 |
| --------------- | ------------------------ | ------------------------------------------------------------------------------------- |
| `sessionSource` | string                   | معرّف مصدر الجلسات أو اسمه.                                                           |
| `where`         | string                   | نص استعلام التصفية المطبَّق على قائمة الجلسات.                                        |
| `whereLanguage` | `lucene` | `sql`         | لغة الاستعلام المكتوب بها `where`.                                                    |
| `from`, `to`    | مللي ثانية منذ حقبة Unix | النطاق الزمني لقائمة الجلسات. في حال عدم تحديده، تكون القيمة الافتراضية آخر 15 دقيقة. |
| `sid`           | string                   | يفتح جلسة محددة بواسطة معرّفها.                                                       |
| `sfrom`, `sto`  | مللي ثانية منذ حقبة Unix | النافذة الزمنية للجلسة المفتوحة (تُستخدم مع `sid`).                                   |

### مثال: تصفّح إعادات تشغيل الجلسات ضمن نطاق زمني {#example-sessions-time-range}

```text
<YOUR_CLICKSTACK_URL>/sessions?from=1735689600000&to=1735693200000
```

### مثال: فتح إعادة تشغيل جلسة محددة ضمن نافذتها الزمنية المسجّلة {#example-sessions-open}

```text
<YOUR_CLICKSTACK_URL>/sessions?sid=6712abf0e4b0f2a1c3d4e5f6&sfrom=1735689600000&sto=1735690200000
```

## خريطة الخدمات — `/service-map` {#service-map}

راجع [خريطة الخدمات](/ar/clickstack/observability/service-maps) للاطلاع على تفاصيل الميزة.

| المعلمة          | الصيغة                   | الوصف                                                                                     |
| ---------------- | ------------------------ | ----------------------------------------------------------------------------------------- |
| `source`         | string                   | ID مصدر التتبّع أو اسمه.                                                                  |
| `samplingFactor` | عدد صحيح                 | المقسوم عليه في أخذ عينات التتبّع (`1` = 100% من التتبّعات، `2` = 50%، `4` = 25%، وهكذا). |
| `from`، `to`     | مللي ثانية منذ حقبة Unix | النطاق الزمني. إذا لم يُحدَّد، فالقيمة الافتراضية هي آخر 15 دقيقة.                        |

### مثال: عرض خريطة الخدمات ضمن نطاق زمني محدد {#example-service-map}

```text
<YOUR_CLICKSTACK_URL>/service-map?from=1735689600000&to=1735693200000
```

## الخدمات — `/services` {#services}

لوحات معلومات HTTP وقاعدة البيانات والأخطاء لكل خدمة.

| المعلمة         | الصيغة                                                                     | الوصف                                                                            |
| --------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `tab`           | `http` | `database` | `errors`                                             | علامة التبويب الفرعية المعروضة في لوحة معلومات الخدمة. القيمة الافتراضية: `http` |
| `source`        | string                                                                     | معرّف مصدر التتبّع.                                                              |
| `service`       | string                                                                     | اسم الخدمة المحددة.                                                              |
| `where`         | string                                                                     | نص استعلام التصفية.                                                              |
| `whereLanguage` | `lucene` | `sql`                                                           | لغة الاستعلام المكتوب بها `where` (القيمة الافتراضية في هذه الصفحة هي `sql`).    |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | قيم شريط عوامل التصفية في لوحة المعلومات.                                        |
| `from`، `to`    | مللي ثانية منذ حقبة Unix                                                   | النطاق الزمني. إذا لم يُحدَّد، فالقيمة الافتراضية هي آخر 15 دقيقة.               |

### مثال: عرض لوحة معلومات قاعدة البيانات لخدمة ضمن نطاق زمني محدد {#example-services-database}

```text
<YOUR_CLICKSTACK_URL>/services?tab=database&service=checkout&from=1735689600000&to=1735693200000
```

### مثال: عرض لوحة معلومات error الخاصة بخدمة {#example-services-errors}

```text
<YOUR_CLICKSTACK_URL>/services?tab=errors&service=payments
```

## Kubernetes — `/kubernetes` {#kubernetes}

| المعلمة                                | الصيغة                                | الوصف                                                                                               |
| -------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `logSource`, `metricSource`            | string                                | معرّفات مصدر السجلات ومصدر المقاييس. عند تحديد أحدهما فقط، يُستخدم افتراضيًا مصدر مترابط معه للآخر. |
| `tab`                                  | مثل `pods` أو `nodes` أو `namespaces` | العرض الفرعي النشط.                                                                                 |
| `q`                                    | string                                | استعلام Lucene لتصفية قائمة الموارد.                                                                |
| `podName`, `nodeName`, `namespaceName` | string                                | يفتح لوحة التفاصيل الخاصة بـ pod أو عقدة أو مساحة أسماء محددة.                                      |
| `from`, `to`                           | مللي ثانية منذ حقبة Unix              | النطاق الزمني. إذا لم يُحدَّد، فالقيمة الافتراضية هي آخر 15 دقيقة.                                  |

### مثال: فتح لوحة التفاصيل الخاصة بـ pod محدد {#example-kubernetes-pod}

```text
<YOUR_CLICKSTACK_URL>/kubernetes?tab=pods&podName=checkout-7d9f8b5c-2xk9p
```
