اربط مسارات معالجة بيانات القياس عن بُعد وتطبيقاتك بـ ClickHouse Observability عبر شركاء التكامل التالين. يشرح كل دليل كيفية تهيئة التكامل بما يناسب بيئة النشر لديك.

| القسم                                                                 | الوصف                                                                                                                                                                               |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Bindplane](/ar/clickstack/observability/integration-partners/bindplane) | ‏Bindplane مسار لمعالجة بيانات القياس عن بُعد مبني أصلاً على OpenTelemetry، ويوفّر إدارة مركزية لمُجمِّعات OpenTelemetry.                                                           |
| [bitdrift](/ar/clickstack/observability/integration-partners/bitdrift)   | ‏bitdrift منصة ديناميكية لإمكانية المراقبة مخصّصة لتطبيقات الأجهزة المحمولة، تربط بيانات القياس عن بُعد للأجهزة المحمولة بتتبعات الخدمات الخلفية عبر سياق التتبّع في OpenTelemetry. |
| [Odigos](/ar/clickstack/observability/integration-partners/odigos)       | يجمع Odigos بين eBPF وOpenTelemetry لتوفير تتبّعات موزّعة أعمق بعبء إضافي أقل بكثير مقارنةً بالوكلاء المعتمدين على bytecode.                                                        |
| [Telflo](/ar/clickstack/observability/integration-partners/telflo)       | ‏Telflo مستوى تحكم مبني أصلاً على OpenTelemetry، يوحّد إدارة جامعي البيانات وتوجيه بيانات القياس عن بُعد في مكان مركزي واحد.                                                        |
