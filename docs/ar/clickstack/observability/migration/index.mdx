انتقل من Elastic Stack أو Datadog إلى ClickHouse Observability بنسختيه المُدارة أو المُدارة ذاتيًا. تتناول هذه الأدلة تخطيط الترحيل، وصيغة البحث، وتكييف آلية جمع بيانات القياس عن بُعد الحالية لديك. وحيثما اختلفت بيانات الاتصال، اختر علامة التبويب الخاصة بنوع النشر لديك.

| التقنية                                                      | الوصف                                                                                                              |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| [Elastic Stack](/ar/clickstack/observability/migration/elastic) | خطّط لعملية الانتقال، وحوّل استعلامات البحث، ورحّل البيانات والوكلاء وأدوات الرصد المضافة إلى التطبيقات            |
| [Datadog](/ar/clickstack/observability/migration/datadog)       | هيّئ وكلاء Datadog الحاليين لإرسال بيانات القياس عن بُعد إلى نقطة نهاية مُدارة أو إلى مستقبِل Datadog مُدار ذاتيًا |
