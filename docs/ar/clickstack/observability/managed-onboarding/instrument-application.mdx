يرشدك هذا الدليل خطوة بخطوة إلى تزويد تطبيق Node.js صغير بأدوات جمع بيانات الرصد باستخدام OpenTelemetry، وإرسال سجلاته ومقاييسه وتتبّعاته وإعادات تشغيل الجلسات إلى Self-managed ClickHouse Observability. ويُزوَّد الجزء الخلفي بأدوات الرصد دون إجراء أي تغيير على الشيفرة المصدرية للتطبيق.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) هو تطبيق Node.js يستعلم عن مجموعة بيانات HackerNews المستضافة في العرض التوضيحي العام لـ ClickHouse. ويستند كل مخطط وجدول ومربع بحث فيه إلى استعلام ClickHouse حقيقي، ومن ثَمّ يُنتج كل تفاعل تتبّعًا يكون الـ span الرئيسي فيه هو استدعاء HTTPS الصادر من الجزء الخلفي إلى ClickHouse.

يفترض هذا الدليل أنك أكملت [إعداد مُجمِّع OpenTelemetry الخاص بك](/ar/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)، وأن لديك مُجمِّع ClickStack قيد التشغيل يمكن الوصول إليه من الجهاز الذي تشغّل عليه هذا التطبيق. **احرص على تدوين نقطة نهاية OTLP الخاصة به** وقيمة `OTLP_AUTH_TOKEN` التي عيّنتها عند نشره، إذ ستضيف هاتين القيمتين إلى الملف `.env` قبل تزويد التطبيق بأدوات الرصد.

## المتطلبات المسبقة {#prerequisites}

* مُجمِّع ClickStack يمكن الوصول إليه من هذا الجهاز. إذا لم تكن قد نشرته بعد، فاتبع أولًا دليل [إعداد مُجمِّع OpenTelemetry الخاص بك](/ar/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* نقطة نهاية OTLP/HTTP لهذا المُجمِّع (عادةً على المنفذ `4318`)، وقيمة `OTLP_AUTH_TOKEN` التي ضبطتها عليه. استخدمهما في المتغيرين `OTEL_EXPORTER_OTLP_ENDPOINT` و`OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+‎ وnpm.

## استنساخ المستودع {#clone-the-repository}

استنسخ [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)، وثبّت التبعيات، ثم انسخ قالب ملف env:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

ستملأ ملف `.env` في الخطوات اللاحقة، ثم تزوّد التطبيق بأدوات جمع بيانات الرصد انطلاقًا من هذا الدليل.
