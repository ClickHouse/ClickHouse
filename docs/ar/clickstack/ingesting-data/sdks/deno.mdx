استخدم دعم OpenTelemetry المدمج في Deno لإرسال السجلات والمقاييس وبيانات التتبّع إلى ClickStack. لا حاجة إلى ClickStack Node.js SDK ولا إلى حزمة التسجيل القديمة الخاصة بـ Deno.

## إعداد OpenTelemetry {#set-up-opentelemetry}

اتبع [تعليمات إعداد OpenTelemetry الرسمية الخاصة بـ Deno](https://docs.deno.com/runtime/fundamentals/open_telemetry/) لتزويد تطبيقك بأدوات جمع بيانات الرصد. هيّئ الوجهة أدناه، ثم فعّل التكامل المدمج في Deno عند تشغيل تطبيقك:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

أضف الصلاحيات التي يحتاجها تطبيقك. استبدل أي وجهات واردة على سبيل المثال أو إعدادات مُصدِّر وحدة التحكم المذكورة في تعليمات المصدر الأصلي، بما في ذلك تجاوزات إعدادات نقاط النهاية الخاصة بكل إشارة.

## تهيئة الوجهة {#configure-destination}

حدّد نقطة نهاية OTLP HTTP ومفتاح الإدخال الخاصين بمُجمِّع ClickStack. استخدم `http://` إذا لم يكن TLS مُهيَّأً على جامع البيانات لديك. لمعرفة كيفية إعداد جامع البيانات، راجع [إدخال البيانات باستخدام OpenTelemetry](/ar/clickstack/ingesting-data/opentelemetry).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## التحقق من إدخال البيانات {#verify-ingestion}

شغّل تطبيقك وولّد بعض النشاط. في ClickStack، اختر نطاقًا زمنيًا حديثًا وابحث عن اسم الخدمة الخاص بتطبيقك ضمن السجلات (Logs) أو التتبّعات (Traces). ثم تحقّق من المقاييس (Metrics) بعد مرور وقت كافٍ لتصديرها.
