على غرار [الصورة الشاملة](/ar/clickstack/deployment/all-in-one)، تتضمن صورة Docker الشاملة هذه جميع مكونات ClickStack:

* **ClickHouse**
* **واجهة مستخدم ClickStack**
* **مجمِّع OpenTelemetry ‏(OTel)** (يعرِض OTLP على المنفذين `4317` و`4318`)
* **MongoDB** (للحفاظ على حالة التطبيق بشكل دائم)

**ومع ذلك، فإن مصادقة المستخدم معطّلة في هذا الإصدار من واجهة مستخدم ClickStack**

<div id="suitable-for">
  ### مناسب لـ {#suitable-for}
</div>

* العروض التوضيحية
* تصحيح الأخطاء
* بيئات التطوير التي تُستخدم فيها واجهة مستخدم ClickStack

## خطوات النشر {#deployment-steps}

<br />

<Steps>
  <Step title="النشر باستخدام Docker" id="deploy-with-docker">
    ينشر الوضع المحلي واجهة مستخدم ClickStack على المنفذ 8080.

    ```shell
    docker run -p 8080:8080 clickhouse/clickstack-local:latest
    ```
  </Step>

  <Step title="الانتقال إلى واجهة مستخدم ClickStack" id="navigate-to-hyperdx-ui">
    انتقل إلى [http://localhost:8080](http://localhost:8080) للوصول إلى واجهة مستخدم ClickStack.

    **لن يُطلب منك إنشاء مستخدم، إذ إن المصادقة غير مفعّلة في نمط النشر هذا.**

    اتصل بعنقود ClickHouse خارجي خاص بك، مثل ClickHouse Cloud.

    <div className="ch-image-md">
      <Frame>
        ![إنشاء اسم تسجيل الدخول](/images/use-cases/observability/hyperdx-2.webp)
      </Frame>
    </div>

    أنشئ مصدرًا مع الإبقاء على جميع القيم الافتراضية، واملأ الحقل `Table` بالقيمة `otel_logs`. ستُكتشف جميع الإعدادات الأخرى تلقائيًا عادةً، وبعدها يمكنك النقر على `Save New Source`.

    <div className="ch-image-md">
      <Frame>
        ![إنشاء مصدر السجلات](/images/use-cases/observability/hyperdx-logs.webp)
      </Frame>
    </div>
  </Step>
</Steps>
