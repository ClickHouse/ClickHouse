<Note>
  **أنت على مسار الإدارة الذاتية**

  لقد اخترت إعداد ClickHouse Observability بنفسك باستخدام [التجربة المُدارة ذاتيًا](/ar/clickstack/self-configured/overview). في هذا المسار، تتولى بنفسك تشغيل جامع بيانات OpenTelemetry، وإدارة إدخال البيانات إلى خدمة ClickHouse Cloud الخاصة بك، وضبط المخطط، والفصل بين أحمال عمل الإدخال والاستعلام باستخدام المستودعات. راجع [جامع بيانات OpenTelemetry](/ar/clickstack/self-configured/ingesting-data/collector) و[ضبط الأداء](/ar/clickstack/self-configured/managing/performance-tuning) و[عزل أحمال عمل القراءة والكتابة](/ar/clickstack/self-configured/managing/isolating-read-write).

  هل تفضّل تجربة بلا خوادم يتولى فيها ClickHouse إدخال البيانات والمخططات والقدرة الحاسوبية نيابةً عنك؟ استخدم إذًا تجربة ClickHouse Observability الافتراضية واتبع دليل [تزويد تطبيقك بأدوات جمع بيانات الرصد باستخدام OpenTelemetry](/ar/clickstack/managed-onboarding/instrument-application-serverless).
</Note>

يشرح هذا الدليل خطوة بخطوة كيفية تزويد تطبيق Node.js صغير بأدوات جمع بيانات الرصد باستخدام OpenTelemetry، وإرسال سجلاته ومقاييسه وتتبّعاته وإعادات تشغيل جلساته إلى ClickHouse Observability عبر جامع البيانات الذي تشغّله. ويُزوَّد الجزء الخلفي بأدوات الرصد دون أي تعديل على الشيفرة المصدرية للتطبيق.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) هو تطبيق Node.js يستعلم عن مجموعة بيانات HackerNews المستضافة في بيئة ClickHouse التجريبية العامة. ويعتمد كل مخطط وجدول ومربع بحث فيه على استعلام ClickHouse حقيقي، لذا يُنتج كل تفاعل تتبّعًا يكون الامتداد (span) الرئيسي فيه هو استدعاء HTTPS الصادر من الجزء الخلفي إلى ClickHouse.

يفترض هذا الدليل أنك أكملت [إعداد مُجمِّع OpenTelemetry الخاص بك](/ar/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)، وأن لديك مُجمِّع ClickStack قيد التشغيل ويمكن الوصول إليه من الجهاز الذي تشغّل عليه هذا التطبيق. **تأكد من تدوين نقطة نهاية OTLP الخاصة به** وقيمة `OTLP_AUTH_TOKEN` التي عيّنتها عند نشره، إذ ستضع هاتين القيمتين في الملف `.env` قبل تزويد التطبيق بأدوات الرصد.

## المتطلبات الأساسية {#prerequisites}

* جامع بيانات ClickStack يمكن الوصول إليه من هذا الجهاز. إذا لم تكن قد نشرت واحدًا بعد، فاتبع أولًا [إعداد مُجمِّع OpenTelemetry الخاص بك](/ar/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* نقطة نهاية OTLP/HTTP لجامع البيانات ذلك (عادةً المنفذ `4318`) و`OTLP_AUTH_TOKEN` الذي ضبطته عليه. استخدمهما كـ`OTEL_EXPORTER_OTLP_ENDPOINT` و`OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ وnpm.

## استنسخ المستودع {#clone-the-repository}

استنسخ [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)، وثبّت التبعيات، وانسخ قالب ملف البيئة:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

ستملأ ملف `.env` في الخطوات التالية، ثم زوّد التطبيق بأدوات الرصد من هذا الدليل.
