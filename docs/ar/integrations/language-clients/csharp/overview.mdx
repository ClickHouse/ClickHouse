يتصل عميلَا C# الرسميان بـ ClickHouse عبر HTTP أو بروتوكول TCP الأصلي.
يتوفّر كلا العميلين ضمن حزمة NuGet ‏`ClickHouse.Driver`.

## HTTP {#http}

يوفّر عميل HTTP واجهة `ClickHouseClient` عالية المستوى والآمنة للاستخدام عبر خيوط تنفيذ متعددة، إضافةً إلى واجهة ADO.NET
التي تستخدمها أدوات ربط الكائنات بقواعد البيانات العلائقية (ORM). وهو يدعم ‎.NET 6.0 والإصدارات الأحدث، ويُنصح باستخدامه في معظم التطبيقات.

استخدم عميل HTTP إذا كنت تحتاج إلى:

* ADO.NET أو إحدى أدوات ربط الكائنات بقواعد البيانات العلائقية (ORM)؛
* إدخال البيانات وإخراجها بصيغ CSV أو JSONEachRow أو Parquet، أو عبر دفق بيانات خام؛
* المصادقة برمز حامل أو ترويسات HTTP مخصّصة؛
* آليات مخصّصة لتحديد أنواع المعلمات أو تنسيق المعلمات أو تحويل البيانات عند قراءتها؛
* تحديد قاعدة بيانات أو دور لكل استعلام؛
* أداء أفضل عند التعامل مع `JSON`. فعميل TCP لا يستطيع نقل قيم `JSON` إلا في صورة نصوص.

[اقرأ وثائق عميل HTTP](./http).

## البروتوكول الأصلي عبر TCP {#native-tcp}

لا يزال عميل البروتوكول الأصلي عبر TCP تجريبيًا، وقد تتغير واجهة برمجة التطبيقات العامة له في إصدار لاحق. ويوفّر
واجهة برمجة التطبيقات `ClickHouseTcpClient` لقراءة كتل البيانات العمودية، والضغط الأصلي، والاتصالات المعاد استخدامها من مجمّع الاتصالات،
والجلسات المثبّتة. وهو متوافق مع .NET 8.0 والإصدارات الأحدث.

استخدم عميل البروتوكول الأصلي عبر TCP إذا كنت بحاجة إلى:

* أداء أفضل، لا سيما عند معالجة البيانات على مستوى الأعمدة؛
* كتل بيانات عمودية؛
* اتصالات دائمة؛
* جلسات مثبّتة عبر `OpenSessionAsync`؛
* دوال استدعاء لمتابعة التقدم وملف التعريف والسجل والإجماليات والقيم الدنيا والعليا؛
* تمرير سياق التتبع وفق معيار W3C إلى ClickHouse.

[اقرأ توثيق عميل البروتوكول الأصلي عبر TCP](./tcp).
