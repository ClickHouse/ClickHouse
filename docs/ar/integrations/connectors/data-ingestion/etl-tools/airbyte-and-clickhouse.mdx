<Note>
  يرجى ملاحظة أن مصدر Airbyte ووجهته لـ ClickHouse هما حاليًا في مرحلة Alpha، ولا يناسبان نقل مجموعات البيانات الكبيرة (&gt; 10 ملايين صف)
</Note>

<a href="https://www.airbyte.com/" target="_blank">Airbyte</a> هي منصة مفتوحة المصدر لتكامل البيانات. تتيح إنشاء مسارات بيانات <a href="https://airbyte.com/blog/why-the-future-of-etl-is-not-elt-but-el" target="_blank">ELT</a>، وتأتي مع أكثر من 140 موصلًا جاهزًا للاستخدام. يوضّح هذا الدليل العملي خطوة بخطوة كيفية توصيل Airbyte بـ ClickHouse كوجهة وتحميل مجموعة بيانات تجريبية.

<Steps>
  <Step title="نزّل Airbyte وشغّله" id="1-download-and-run-airbyte">
    1. يعمل Airbyte على Docker ويستخدم `docker-compose`. احرص على تنزيل أحدث إصدارات Docker وتثبيتها.

    2. انشر Airbyte عبر استنساخ مستودع Github الرسمي وتشغيل `docker-compose up` في الطرفية التي تفضّلها:

       ```bash
       git clone https://github.com/airbytehq/airbyte.git --depth=1
       cd airbyte
       ./run-ab-platform.sh
       ```

    3. بمجرد ظهور شعار Airbyte في الطرفية، يمكنك الاتصال بـ <a href="http://localhost:8000" target="_blank">localhost:8000</a>

       <div className="ch-image-lg">
         <Frame>
           ![شعار Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_01.webp)
         </Frame>
       </div>

    <Note>
      كبديل، يمكنك إنشاء حساب واستخدام <a href="https://docs.airbyte.com/" target="_blank">Airbyte Cloud</a>
    </Note>
  </Step>

  <Step title="إضافة ClickHouse كوجهة" id="2-add-clickhouse-as-a-destination">
    في هذا القسم، سنوضح كيفية إضافة مثيل ClickHouse كوجهة.

    1. شغّل خادم ClickHouse (يتوافق Airbyte مع ClickHouse بدءًا من الإصدار `21.8.10.19`) أو سجّل الدخول إلى حسابك السحابي في ClickHouse:

       ```bash
       clickhouse-server start
       ```

    2. في Airbyte، انتقل إلى صفحة &quot;Destinations&quot; وأضف وجهة جديدة:

       <div className="ch-image-lg">
         <Frame>
           ![إضافة وجهة في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_02.webp)
         </Frame>
       </div>

    3. اختر ClickHouse من القائمة المنسدلة &quot;Destination type&quot;، ثم املأ نموذج &quot;Set up the destination&quot; بإدخال اسم المضيف والمنافذ الخاصة بـ ClickHouse، واسم قاعدة البيانات، واسم المستخدم وكلمة المرور، وحدّد ما إذا كان الاتصال يستخدم SSL (وهو مكافئ لخيار سطر الأوامر `--secure` في `clickhouse-client`):

       <div className="ch-image-lg">
         <Frame>
           ![إنشاء وجهة ClickHouse في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_03.webp)
         </Frame>
       </div>

    4. تهانينا! لقد أضفت ClickHouse كوجهة في Airbyte.

    <Note>
      لاستخدام ClickHouse كوجهة، يجب أن يمتلك المستخدم الذي ستعتمد عليه صلاحيات إنشاء قواعد البيانات والجداول وإدراج الصفوف. نوصي بإنشاء مستخدم مخصص لـ Airbyte (مثل `my_airbyte_user`) يتمتع بالصلاحيات التالية:

      ```sql
      CREATE USER 'my_airbyte_user'@'%' IDENTIFIED BY 'your_password_here';

      GRANT CREATE ON * TO my_airbyte_user;
      ```
    </Note>
  </Step>

  <Step title="إضافة مجموعة بيانات كمصدر" id="3-add-a-dataset-as-a-source">
    مجموعة البيانات النموذجية التي سنستخدمها هي <a href="/ar/get-started/sample-datasets/nyc-taxi" target="_blank">New York City Taxi Data</a> (المتاحة على <a href="https://github.com/toddwschneider/nyc-taxi-data" target="_blank">Github</a>). وفي هذا الدليل العملي، سنستخدم مجموعة جزئية من مجموعة البيانات هذه تخص شهر يناير 2022.

    1. في Airbyte، انتقل إلى صفحة &quot;Sources&quot; وأضف مصدرًا جديدًا من النوع File.

       <div className="ch-image-lg">
         <Frame>
           ![إضافة مصدر في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_04.webp)
         </Frame>
       </div>

    2. املأ نموذج &quot;Set up the source&quot; بتحديد اسم للمصدر وإدخال عنوان URL لملف NYC Taxi الخاص بشهر يناير 2022 (انظر أدناه). احرص على اختيار `parquet` صيغةً للملف، و`HTTPS Public Web` مزوّدًا للتخزين (Storage Provider)، و`nyc_taxi_2022` اسمًا لمجموعة البيانات (Dataset Name).

       ```text
       https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2022-01.parquet
       ```

       <div className="ch-image-lg">
         <Frame>
           ![إنشاء مصدر ClickHouse في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_05.webp)
         </Frame>
       </div>

    3. تهانينا! لقد أضفت الآن مصدرًا من نوع ملف في Airbyte.
  </Step>

  <Step title="أنشئ اتصالًا وحمّل مجموعة البيانات إلى ClickHouse" id="4-create-a-connection-and-load-the-dataset-into-clickhouse">
    1. في Airbyte، انتقل إلى صفحة &quot;Connections&quot; وأضف اتصالًا جديدًا

    <div className="ch-image-lg">
      <Frame>
        ![إضافة اتصال في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_06.webp)
      </Frame>
    </div>

    2. اختر &quot;Use existing source&quot; ثم حدّد مصدر New York City Taxi Data، وبعد ذلك اختر &quot;Use existing destination&quot; وحدّد مثيل ClickHouse الخاص بك.

    3. املأ نموذج &quot;Set up the connection&quot; باختيار قيمة لـ Replication Frequency (سنستخدم `manual` في هذا الدليل العملي)، وحدّد `nyc_taxi_2022` بوصفه الدفق الذي تريد مزامنته. تأكّد من اختيار `Normalized Tabular Data` في خيار Normalization.

    <div className="ch-image-lg">
      <Frame>
        ![إنشاء اتصال في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_07.webp)
      </Frame>
    </div>

    4. بعد إنشاء الاتصال، انقر على &quot;Sync now&quot; لبدء تحميل البيانات (لأننا اخترنا `Manual` قيمةً لـ Replication Frequency)

    <div className="ch-image-lg">
      <Frame>
        ![زر "Sync now" في Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_08.webp)
      </Frame>
    </div>

    5. سيبدأ تحميل بياناتك، ويمكنك توسيع العرض لمتابعة سجلات Airbyte ومدى التقدم. وعند انتهاء العملية، ستظهر الرسالة `Completed successfully` في السجلات:

    <div className="ch-image-lg">
      <Frame>
        ![اكتمل بنجاح](/images/integrations/data-ingestion/etl-tools/airbyte_09.webp)
      </Frame>
    </div>

       ```sql

       FROM nyc_taxi_2022
       LIMIT 10
       ```

    7. لاحظ أن Airbyte استنتج أنواع البيانات تلقائيًا وأضاف 4 أعمدة إلى جدول الوجهة. يستخدم Airbyte هذه الأعمدة لإدارة منطق النسخ المتماثل وتسجيل العمليات. لمزيد من التفاصيل، راجع  <a href="https://docs.airbyte.com/integrations/destinations/clickhouse#output-schema" target="_blank">وثائق Airbyte الرسمية</a>.

       ```sql
           `_airbyte_ab_id` String,
           `_airbyte_emitted_at` DateTime64(3, 'GMT'),

           `_airbyte_nyc_taxi_072021_hashid` String
       ```
