تُعد [Splunk](https://www.splunk.com/) منصة لتحليلات البيانات والمراقبة.

تتيح لك هذه الإضافة تخزين [سجلات تدقيق ClickHouse Cloud](/ar/products/cloud/reference/security/audit-logging) في Splunk. وتستخدم [واجهة برمجة تطبيقات ClickHouse Cloud](/ar/products/cloud/features/admin-features/api/api-overview) لتنزيل سجلات التدقيق.

لا تتضمن هذه الإضافة سوى مدخل معياري، ولا توفّر أي واجهة مستخدم إضافية.

<div id="installation">
  # التثبيت {#installation}
</div>

## في Splunk Enterprise {#for-splunk-enterprise}

نزّل الإضافة ClickHouse Cloud Audit Add-on for Splunk من [Splunkbase](https://splunkbase.splunk.com/app/7709).

<div className="ch-image-lg">
  <Frame>
    ![موقع Splunkbase يعرض صفحة تنزيل الإضافة ClickHouse Cloud Audit Add-on for Splunk](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

في Splunk Enterprise، انتقل إلى Apps -&gt; Manage، ثم انقر على Install app from file.

<div className="ch-image-lg">
  <Frame>
    ![واجهة Splunk Enterprise تعرض صفحة إدارة التطبيقات مع خيار Install app from file](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

اختر الملف المضغوط الذي نزّلته من Splunkbase، ثم انقر على Upload.

<div className="ch-image-lg">
  <Frame>
    ![مربع حوار تثبيت التطبيقات في Splunk لرفع إضافة ClickHouse](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

إذا تمّ كل شيء بنجاح، فسترى الآن تطبيق ClickHouse Audit logs مثبّتًا. وإن لم يظهر، فراجع سجلات Splunkd بحثًا عن أي أخطاء.

<div id="modular-input-configuration">
  # إعداد المُدخل المعياري {#modular-input-configuration}
</div>

لإعداد المُدخل المعياري، ستحتاج أولاً إلى معلومات من نشر ClickHouse Cloud لديك:

* معرّف المؤسسة
* [مفتاح واجهة برمجة التطبيقات للمسؤول](/ar/products/cloud/features/admin-features/api/openapi)

## الحصول على المعلومات من ClickHouse Cloud {#getting-information-from-clickhouse-cloud}

سجّل الدخول إلى [ClickHouse Cloud console](https://console.clickhouse.cloud/).

انتقل إلى Organization -&gt; Organization details في مؤسستك. ومن هناك يمكنك نسخ معرّف المؤسسة.

<div className="ch-image-lg">
  <Frame>
    ![تعرض ClickHouse Cloud console صفحة Organization details التي تتضمن معرّف المؤسسة](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

بعد ذلك، انتقل إلى API Keys من القائمة الجانبية اليسرى.

<div className="ch-image-lg">
  <Frame>
    ![تعرض ClickHouse Cloud console قسم API Keys في قائمة التنقل اليسرى](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

أنشئ مفتاح واجهة برمجة التطبيقات، وامنحه اسمًا ذا معنى، وحدد صلاحيات `Admin`. ثم انقر على Generate مفتاح واجهة برمجة التطبيقات.

<div className="ch-image-lg">
  <Frame>
    ![تعرض ClickHouse Cloud console واجهة إنشاء مفتاح واجهة برمجة التطبيقات مع تحديد صلاحيات مسؤول](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

احفظ الـ مفتاح واجهة برمجة التطبيقات والقيمة السرية في مكان آمن.

<div className="ch-image-lg">
  <Frame>
    ![تعرض ClickHouse Cloud console مفتاح واجهة برمجة التطبيقات الذي تم إنشاؤه والقيمة السرية المطلوب حفظهما](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

<div className="ch-image-lg">

اكتملت تهيئة الإدخال، ويمكنك الآن البدء في تصفح سجلات التدقيق.
