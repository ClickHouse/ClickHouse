يربط خادم ClickHouse MCP مساعدي الذكاء الاصطناعي المتوافقين بقواعد بيانات ClickHouse وأدواتها.
للاطلاع على مقدمة عن البروتوكول ومعماريته وخادم ClickHouse MCP، راجع [نظرة عامة على Model Context Protocol ‏(MCP)](/ar/concepts/features/connect-to-clickhouse/native-tools/mcp).

لتقييم ذاكرة SQL المشتركة، [أعد استخدام دروس SQL عبر Loom](https://loom.clickhouse.com/docs/use-cases/self-hosted-clickhouse#reuse-sql-lessons-across-agent-sessions) إلى جانب اتصال ClickHouse MCP الخاص بك.
يستخدم هذا التمرين أذونات منفصلة لقاعدة البيانات ومساحة الأسماء، ويتحقق من صحة مسند محفوظ مقارنةً بالمخطط القائم بعد إعادة تسمية عمود.

## إعداد خادم ClickHouse MCP {#set-up-clickhouse-mcp-server}

اختر عميل MCP، ثم اتبع [دليل إعداد خادم ClickHouse MCP](/ar/guides/use-cases/ai-ml/MCP/claude-desktop) لتوصيله بـ ClickHouse.
