  ### 生成访问密钥

  ### 创建服务账号 HMAC Key 和 Secret

  打开 **Cloud Storage &gt; Settings &gt; Interoperability**，选择现有的 **Access key**，或选择 **CREATE A KEY FOR A SERVICE ACCOUNT**。本指南将介绍为新的服务账号创建新密钥的流程。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-a-service-account-key.webp" alt="在 GCS 中生成服务账号 HMAC Key" />
  </Frame>

  ### 添加新的服务账号

  如果该项目中还没有现有的服务账号，请选择 **CREATE NEW ACCOUNT**。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-0.webp" alt="在 GCS 中添加新的服务账号" />
  </Frame>

  创建服务账号共分为三个步骤。第一步，为账号指定一个有意义的名称、ID 和描述。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-a.webp" alt="在 GCS 中定义新的服务账号名称和 ID" />
  </Frame>

  在 Interoperability 设置对话框中，推荐使用 IAM role **Storage Object Admin**；请在第二步选择该角色。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-2.webp" alt="在 GCS 中选择 IAM role Storage Object Admin" />
  </Frame>

  第三步是可选的，本指南中不会用到。可根据自身策略授予用户这些特权。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-3.webp" alt="在 GCS 中为新的服务账号配置其他设置" />
  </Frame>

  系统将显示服务账号的 HMAC Key。请保存这些信息，因为后续会在 ClickHouse 配置中用到。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-guide-key.webp" alt="获取为 GCS 生成的 HMAC Key" />
  </Frame>
