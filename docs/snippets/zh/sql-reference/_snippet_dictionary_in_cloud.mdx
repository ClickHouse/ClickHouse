---
title: Cloud 中的字典片段
---

<Note title="ClickHouse Cloud">
  使用 [`CREATE DICTIONARY`](/zh/reference/statements/create/dictionary#creating-a-dictionary-with-a-ddl-query) 创建字典。

  创建从 ClickHouse 表读取数据的字典时，请在 `SOURCE` 子句中填写专用用户的用户名和密码。该用户需要对源表具有 `SELECT` 权限。请参阅 [ClickHouse 字典源示例](/zh/reference/statements/create/dictionary/sources/clickhouse)。

  请在 [Cloud Compatibility 指南](/zh/products/cloud/guides/cloud-compatibility) 中确认受支持的字典源列表。
</Note>
