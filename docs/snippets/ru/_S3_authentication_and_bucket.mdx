<Accordion title="Создайте S3 бакеты и IAM-пользователя">
  В этой статье описываются основы настройки пользователя AWS IAM, создания S3 бакета и настройки ClickHouse для использования этого бакета в качестве S3-диска.
  Рекомендуется согласовать используемые разрешения с командой по безопасности, рассматривая приведённые настройки как отправную точку.

  ### Создание пользователя AWS IAM

  В следующих шагах вы создадите пользователя сервисного аккаунта (не пользователя для авторизации).

  1. Войдите в консоль управления AWS IAM.

  2. В меню `Users` выберите `Create user`

  <Frame>
    <img src="/images/_snippets/s3/s3-1.webp" alt="AWS IAM Management Console — добавление нового пользователя" />
  </Frame>

  3. Введите имя пользователя и установите тип учетных данных `Access key - Programmatic access`, затем выберите `Next: Permissions`

  <Frame>
    <img src="/images/_snippets/s3/s3-2.webp" alt="Настройка имени пользователя и типа доступа для пользователя IAM" />
  </Frame>

  4. Не добавляйте пользователя ни в одну группу; выберите `Next: Tags`

  <Frame>
    <img src="/images/_snippets/s3/s3-3.webp" alt="Пропуск добавления пользователя IAM в группу" />
  </Frame>

  5. Если вам не нужно добавлять теги, выберите `Next: Review`

  <Frame>
    <img src="/images/_snippets/s3/s3-4.webp" alt="Пропуск назначения тега пользователю IAM" />
  </Frame>

  6. Выберите `Create User`

  <Note>
    Предупреждение о том, что у пользователя нет разрешений, можно проигнорировать; в следующем разделе пользователю будут выданы разрешения на бакет
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-5.webp" alt="Создание IAM user с предупреждением об отсутствии разрешений" />
  </Frame>

  7. Пользователь создан; нажмите `show` и скопируйте ключ доступа и секретный ключ.

  <Note>
    Сохраните ключи в надёжном месте; секретный ключ доступа будет показан только сейчас.
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-6.webp" alt="Просмотр и копирование ключей доступа пользователя IAM" />
  </Frame>

  8. Нажмите «Закрыть», затем найдите пользователя на странице пользователей.

  <Frame>
    <img src="/images/_snippets/s3/s3-7.webp" alt="Поиск недавно созданного IAM-пользователя в списке пользователей" />
  </Frame>

  9. Скопируйте ARN (Amazon Resource Name) и сохраните его — он понадобится при настройке политики доступа к бакету.

  <Frame>
    <img src="/images/_snippets/s3/s3-8.webp" alt="Копирование ARN IAM-пользователя" />
  </Frame>

  ### Создайте S3 бакет

  1. В разделе S3 бакета выберите `Create bucket`

  <Frame>
    <img src="/images/_snippets/s3/s3-9.webp" alt="Начало создания S3 бакета" />
  </Frame>

  2. Введите название бакета, остальные параметры оставьте по умолчанию

  <Note>
    Имя бакета должно быть уникальным во всём AWS, а не только в пределах организации, иначе возникнет ошибка.
  </Note>

  3. Оставьте `Block all Public Access` включенным; публичный доступ не нужен.

  <Frame>
    <img src="/images/_snippets/s3/s3-a.webp" alt="Настройка S3 бакета с заблокированным публичным доступом" />
  </Frame>

  4. Внизу страницы выберите `Create Bucket`

  <Frame>
    <img src="/images/_snippets/s3/s3-b.webp" alt="Завершение создания S3 бакета" />
  </Frame>

  5. Перейдите по ссылке, скопируйте ARN и сохраните его — он понадобится при настройке политики доступа к бакету.

  6. После создания бакета найдите новый S3 бакет в списке S3 бакетов и перейдите по ссылке

  <Frame>
    <img src="/images/_snippets/s3/s3-c.webp" alt="Недавно созданный S3 бакет в списке бакетов" />
  </Frame>

  7. Выберите `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-d.webp" alt="Создание новой папки в бакете S3" />
  </Frame>

  8. Введите имя папки, которая будет использоваться для S3-диска ClickHouse, и выберите `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-e.webp" alt="Настройка имени папки для использования S3-диска ClickHouse" />
  </Frame>

  9. Теперь папка должна появиться в списке бакетов

  <Frame>
    <img src="/images/_snippets/s3/s3-f.webp" alt="Просмотр только что созданной папки в S3 бакете" />
  </Frame>

  10. Установите флажок рядом с новой папкой и нажмите `Copy URL`. Сохраните скопированный URL, чтобы использовать его в конфигурации хранилища ClickHouse в следующем разделе.

  <Frame>
    <img src="/images/_snippets/s3/s3-g.webp" alt="Копирование URL-адреса папки S3 для настройки ClickHouse" />
  </Frame>

  11. Выберите вкладку `Permissions` и нажмите кнопку `Edit` в разделе `Bucket Policy`

  <Frame>
    <img src="/images/_snippets/s3/s3-h.webp" alt="Доступ к настройкам политики S3 бакета" />
  </Frame>

  12. Добавьте политику для бакета, пример ниже:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    Вам следует совместно с вашей командой по безопасности определить, какие разрешения использовать; рассматривайте приведённые ниже как отправную точку.
    Дополнительные сведения о политиках и настройках см. в документации AWS:
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. Сохраните настройки политики.
</Accordion>
