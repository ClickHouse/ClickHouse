<Accordion title="Создайте S3 бакеты и пользователя IAM">
  В этой статье описаны основы настройки пользователя AWS IAM, создания S3 бакета и настройки ClickHouse для использования этого бакета в качестве S3-диска.
  Рекомендуется согласовать необходимые разрешения с командой по безопасности, рассматривая приведённые настройки как отправную точку.

  ### Создание пользователя AWS IAM

  В следующих шагах вы создадите пользователя сервисного аккаунта (не пользователя для входа).

  1. Войдите в консоль управления AWS IAM.

  2. В меню `Users` выберите `Create user`

  <Image size="md" img="/images/_snippets/s3/s3-1.webp" alt="AWS IAM Management Console — добавление нового пользователя" border force />

  3. Введите имя пользователя, выберите тип учетных данных `Access key - Programmatic access` и нажмите `Next: Permissions`

  <Image size="md" img="/images/_snippets/s3/s3-2.webp" alt="Настройка имени пользователя и типа доступа для пользователя IAM" border force />

  4. Не добавляйте пользователя ни в какую группу; выберите `Next: Tags`

  <Image size="md" img="/images/_snippets/s3/s3-3.webp" alt="Пропуск назначения группы для IAM-пользователя" border force />

  5. Если вам не нужно добавлять теги, выберите `Next: Review`

  <Image size="md" img="/images/_snippets/s3/s3-4.webp" alt="Пропуск присвоения тега пользователю IAM" border force />

  6. Выберите `Create User`

  <Note>
    Предупреждение о том, что у пользователя нет разрешений, можно игнорировать; в следующем разделе пользователю будут выданы разрешения на бакет
  </Note>

  <Image size="md" img="/images/_snippets/s3/s3-5.webp" alt="Предупреждение о создании пользователя IAM без разрешений" border force />

  7. Пользователь создан; нажмите `show` и скопируйте ключ доступа и секретный ключ.

  <Note>
    Сохраните ключи в другом месте; это единственный раз, когда секретный ключ доступа можно будет увидеть.
  </Note>

  <Image size="md" img="/images/_snippets/s3/s3-6.webp" alt="Просмотр и копирование ключей доступа IAM-пользователя" border force />

  8. Нажмите «Закрыть», затем найдите пользователя на странице пользователей.

  <Image size="md" img="/images/_snippets/s3/s3-7.webp" alt="Поиск недавно созданного пользователя IAM в списке пользователей" border force />

  9. Скопируйте ARN (Amazon Resource Name) и сохраните его для использования при настройке политики доступа к бакету.

  <Image size="md" img="/images/_snippets/s3/s3-8.webp" alt="Копирование ARN IAM-пользователя" border force />

  ### Создание S3 бакета

  1. В разделе S3 бакета выберите `Create bucket`

  <Image size="md" img="/images/_snippets/s3/s3-9.webp" alt="Начало создания S3 бакета" border force />

  2. Введите имя бакета, остальные параметры оставьте по умолчанию

  <Note>
    Имя бакета должно быть уникальным во всём AWS, а не только в рамках организации, иначе возникнет ошибка.
  </Note>

  3. Оставьте `Block all Public Access` включённым; публичный доступ не нужен.

  <Image size="md" img="/images/_snippets/s3/s3-a.webp" alt="Настройка параметров S3 бакета при заблокированном публичном доступе" border force />

  4. Внизу страницы выберите `Create Bucket`

  <Image size="md" img="/images/_snippets/s3/s3-b.webp" alt="Завершение создания S3-бакета" border force />

  5. Нажмите ссылку, скопируйте ARN и сохраните его для использования при настройке политики доступа к бакету.

  6. После создания бакета найдите новый S3 бакет в списке S3 бакетов и нажмите ссылку

  <Image size="md" img="/images/_snippets/s3/s3-c.webp" alt="Поиск только что созданного S3 бакета в списке бакетов" border force />

  7. Выберите `Create folder`

  <Image size="md" img="/images/_snippets/s3/s3-d.webp" alt="Создание новой папки в S3-бакете" border force />

  8. Введите имя папки, которая будет использоваться как целевая для S3-диска ClickHouse, и выберите `Create folder`

  <Image size="md" img="/images/_snippets/s3/s3-e.webp" alt="Настройка имени папки для использования S3-диска в ClickHouse" border force />

  9. Теперь папка должна отображаться в списке бакетов

  <Image size="md" img="/images/_snippets/s3/s3-f.webp" alt="Просмотр новой папки в S3 бакете" border force />

  10. Установите флажок рядом с новой папкой и нажмите `Copy URL`. Сохраните скопированный URL, чтобы использовать его в конфигурации хранилища ClickHouse в следующем разделе.

  <Image size="md" img="/images/_snippets/s3/s3-g.webp" alt="Копирование URL-адреса папки S3 для настройки ClickHouse" border force />

  11. Перейдите на вкладку `Permissions` и нажмите кнопку `Edit` в разделе `Bucket Policy`

  <Image size="md" img="/images/_snippets/s3/s3-h.webp" alt="Доступ к конфигурации политики S3-бакета" border force />

  12. Добавьте политику бакета, как в примере ниже:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    Вместе с вашей командой по безопасности определите, какие разрешения следует использовать; приведённые ниже сведения можно рассматривать как отправную точку.
    Дополнительные сведения о политиках и настройках см. в документации AWS:
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. Сохраните конфигурацию политики.
</Accordion>
