  ### Gere uma chave de acesso

  ### Crie uma chave HMAC e um segredo para a conta de serviço

  Abra **Cloud Storage &gt; Settings &gt; Interoperability** e escolha uma **Access key** existente ou **CREATE A KEY FOR A SERVICE ACCOUNT**. Este guia aborda o processo de criar uma nova chave para uma nova conta de serviço.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-a-service-account-key.webp" alt="Gerando uma chave HMAC de conta de serviço no GCS" />
  </Frame>

  ### Adicione uma nova conta de serviço

  Se este for um projeto sem nenhuma conta de serviço existente, clique em **CREATE NEW ACCOUNT**.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-0.webp" alt="Adicionando uma nova conta de serviço no GCS" />
  </Frame>

  Há três etapas para criar a conta de serviço. Na primeira, dê à conta um nome, um ID e uma descrição significativos.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-a.webp" alt="Definindo um novo nome e ID de conta de serviço no GCS" />
  </Frame>

  Na caixa de diálogo de configurações de Interoperability, o IAM role **Storage Object Admin** é recomendado; selecione-o na segunda etapa.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-2.webp" alt="Selecionando o IAM role Storage Object Admin no GCS" />
  </Frame>

  A terceira etapa é opcional e não é usada neste guia. Você pode permitir que usuários tenham esses privilégios com base nas suas políticas.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-3.webp" alt="Configurando ajustes adicionais para a nova conta de serviço no GCS" />
  </Frame>

  A chave HMAC da conta de serviço será exibida. Salve essas informações, pois elas serão usadas na configuração do ClickHouse.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-guide-key.webp" alt="Recuperando a chave HMAC gerada para o GCS" />
  </Frame>
