title: Autenticação e bucket do S3

<Accordion title="Criar buckets do S3 e um usuário do IAM">
  Este artigo demonstra os conceitos básicos de como configurar um usuário do IAM da AWS, criar um bucket do S3 e configurar o ClickHouse para usar o bucket como um S3 disk.
  Trabalhe com sua equipe de segurança para determinar as permissões a serem usadas e considere-as como ponto de partida.

  ### Criar um usuário do IAM da AWS

  Nas etapas a seguir, você criará um usuário de conta de serviço (não um usuário de logon).

  1. Faça login no Console de Gerenciamento do AWS IAM.

  2. No menu `Users`, selecione `Create user`

  <Frame>
    <img src="/images/_snippets/s3/s3-1.webp" alt="Console de Gerenciamento do AWS IAM - adicionando um novo usuário" />
  </Frame>

  3. Digite o nome de usuário, defina o tipo de credencial como `Access key - Programmatic access` e selecione `Next: Permissions`

  <Frame>
    <img src="/images/_snippets/s3/s3-2.webp" alt="Definindo o nome de usuário e o tipo de acesso para o usuário do IAM" />
  </Frame>

  4. Não adicione o usuário a nenhum grupo; selecione `Next: Tags`

  <Frame>
    <img src="/images/_snippets/s3/s3-3.webp" alt="Pulando a atribuição de grupo para o usuário do IAM" />
  </Frame>

  5. A menos que você precise adicionar tags, selecione `Next: Review`

  <Frame>
    <img src="/images/_snippets/s3/s3-4.webp" alt="Ignorando a atribuição de tag para o usuário do IAM" />
  </Frame>

  6. Selecione `Create User`

  <Note>
    A mensagem de aviso informando que o usuário não tem permissões pode ser ignorada; na próxima seção, serão concedidas permissões no bucket ao usuário
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-5.webp" alt="Criando o usuário do IAM sem o aviso de falta de permissões" />
  </Frame>

  7. O usuário foi criado; clique em `show` e copie a chave de acesso e a chave secreta.

  <Note>
    Guarde as chaves em outro lugar; esta é a única vez em que a chave de acesso secreta estará disponível.
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-6.webp" alt="Visualizando e copiando as chaves de acesso do usuário do IAM" />
  </Frame>

  8. Clique em Fechar e, em seguida, localize o usuário na tela de usuários.

  <Frame>
    <img src="/images/_snippets/s3/s3-7.webp" alt="Localizando o usuário do IAM recém-criado na lista de usuários" />
  </Frame>

  9. Copie o ARN (Amazon Resource Name) e salve-o para usá-lo ao configurar a política de acesso do bucket.

  <Frame>
    <img src="/images/_snippets/s3/s3-8.webp" alt="Copiando o ARN do usuário do IAM" />
  </Frame>

  ### Criar um bucket do S3

  1. Na seção do bucket do S3, selecione `Create bucket`

  <Frame>
    <img src="/images/_snippets/s3/s3-9.webp" alt="Iniciando o processo de criação do bucket do S3" />
  </Frame>

  2. Insira um nome para o bucket e deixe as demais opções como padrão

  <Note>
    O nome do bucket deve ser exclusivo em toda a AWS, não apenas na organização; caso contrário, será gerado um erro.
  </Note>

  3. Mantenha `Block all Public Access` ativado; o acesso público não é necessário.

  <Frame>
    <img src="/images/_snippets/s3/s3-a.webp" alt="Configurando as opções do bucket do S3 com o acesso público bloqueado" />
  </Frame>

  4. Selecione `Create Bucket` na parte inferior da página

  <Frame>
    <img src="/images/_snippets/s3/s3-b.webp" alt="Concluindo a criação do bucket do S3" />
  </Frame>

  5. Selecione o link, copie o ARN e salve-o para usar ao configurar a política de acesso do bucket.

  6. Depois que o bucket for criado, localize o novo bucket do S3 na lista de buckets do S3 e selecione o link

  <Frame>
    <img src="/images/_snippets/s3/s3-c.webp" alt="Localizando o bucket do S3 recém-criado na lista de buckets" />
  </Frame>

  7. Clique em `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-d.webp" alt="Criando uma nova pasta no bucket do S3" />
  </Frame>

  8. Digite um nome de pasta que será o destino do disco S3 do ClickHouse e selecione `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-e.webp" alt="Definindo o nome da pasta para uso do disco S3 do ClickHouse" />
  </Frame>

  9. A pasta agora deve aparecer na lista de buckets

  <Frame>
    <img src="/images/_snippets/s3/s3-f.webp" alt="Visualizando a pasta recém-criada no bucket do S3" />
  </Frame>

  10. Marque a caixa de seleção da nova pasta e clique em `Copy URL`. Salve a URL copiada para usá-la na configuração de armazenamento do ClickHouse na próxima seção.

  <Frame>
    <img src="/images/_snippets/s3/s3-g.webp" alt="Copiando a URL da pasta no S3 para a configuração do ClickHouse" />
  </Frame>

  11. Selecione a aba `Permissions` e clique no botão `Edit` na seção `Bucket Policy`

  <Frame>
    <img src="/images/_snippets/s3/s3-h.webp" alt="Acessando a configuração da política de bucket do S3" />
  </Frame>

  12. Adicione uma política do bucket, conforme o exemplo abaixo:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    Você deve trabalhar com sua equipe de segurança para determinar as permissões que serão usadas; considere estas como ponto de partida.
    Para mais informações sobre políticas e configurações, consulte a documentação da AWS:
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. Salve a configuração da política.
</Accordion>
