---
title: البدء السريع مع واجهة سطر أوامر Cloud
---

تغطي هذه الصفحة توفير خدمة ClickHouse Cloud والاتصال بها وتحميل البيانات، وكل ذلك من سطر الأوامر باستخدام [واجهة سطر أوامر ClickHouse](/ar/products/cloud/features/cli) (`clickhousectl`). الأوامر غير تفاعلية، ويُخرج `clickhousectl` بيانات JSON باستخدام `--json`.

<div id="prerequisites">
  ## المتطلبات الأساسية
</div>

ثبّت واجهة سطر أوامر ClickHouse:

```bash
curl https://clickhouse.com/cli | sh
```

ستحتاج أيضًا إلى `jq`.

تحتاج إلى حساب ClickHouse Cloud. إذا لم يكن لديك حساب بعد، فسيؤدي الأمر `clickhousectl cloud auth signup` إلى فتح صفحة التسجيل في متصفحك.

تتطلب عمليات الكتابة (الإنشاء والحذف) [مصادقة بمفتاح API](/ar/products/cloud/features/admin-features/api/openapi)، بينما يقتصر تسجيل الدخول عبر OAuth على القراءة فقط:

```bash
clickhousectl cloud auth login --api-key <YOUR_KEY> --api-secret <YOUR_SECRET>
```

بدلًا من ذلك، عيّن متغيرَي البيئة `CLICKHOUSE_CLOUD_API_KEY` و`CLICKHOUSE_CLOUD_API_SECRET`. تحقّق باستخدام `clickhousectl cloud auth status`؛ ويُفترض أن يظهر إدخال بنطاق `read/write`.

<div id="create-service">
  ## أنشئ خدمة ClickHouse
</div>

أنشئ الخدمة واحفظ الاستجابة؛ إذ لا تُعرض كلمة مرور المستخدم `default` إلا مرة واحدة:

```bash
clickhousectl cloud service create \
  --name quickstart-ch \
  --region us-east-1 \
  --json > ch.json
```

تتضمن الاستجابة معرّف الخدمة ونقاط النهاية وكلمة المرور المُنشأة (اقتُصرت هنا؛ إذ تتضمن الاستجابة الكاملة أيضًا إعدادات التوسعة وقائمة الوصول عبر IP والوسوم):

```json
{
  "password": "dK7mPq2x_-TzrL9vNw0s",
  "service": {
    "id": "4f7b92f3-4163-403a-b538-b9bc6e2e8f66",
    "name": "quickstart-ch",
    "provider": "aws",
    "region": "us-east-1",
    "state": "provisioning",
    "endpoints": [
      {
        "host": "quickstart-abc123.us-east-1.aws.clickhouse.cloud",
        "port": 9440,
        "protocol": "nativesecure"
      },
      {
        "host": "quickstart-abc123.us-east-1.aws.clickhouse.cloud",
        "port": 8443,
        "protocol": "https"
      }
    ],
    "numReplicas": 3,
    "minReplicaMemoryGb": 16.0,
    "maxReplicaMemoryGb": 120.0
  }
}
```

استخرج المتطلبات اللازمة لبقية هذا الدليل:

```bash
CH_ID=$(jq -r .service.id ch.json)
CH_PASSWORD=$(jq -r .password ch.json)
CH_HOST=$(jq -r '.service.endpoints[] | select(.protocol=="nativesecure") | .host' ch.json)
```

إذا فقدت كلمة المرور، أنشئ كلمة مرور جديدة باستخدام `clickhousectl cloud service reset-password "$CH_ID"`.

تُنشأ الخدمات باستخدام `clickhousectl` افتراضيًا مع قائمة وصول لعناوين IP تسمح بالوصول من جميع العناوين (`0.0.0.0/0`). لتقييد الوصول، مرّر `--ip-allow` عند إنشاء الخدمة؛ راجع [&quot;إعداد عوامل تصفية IP&quot;](/ar/products/cloud/guides/security/connectivity/setting-ip-filters).

<div id="wait-for-provisioning">
  ## انتظر حتى تكتمل تهيئة الخدمة
</div>

تستغرق التهيئة نحو دقيقة. تحقّق دوريًا حتى تصبح الحالة `running`:

```bash
while [ "$(clickhousectl cloud service get "$CH_ID" --json | jq -r .state)" != "running" ]; do
  sleep 15
done
```

<div id="run-sql">
  ## شغّل SQL باستخدام واجهة برمجة تطبيقات الاستعلام
</div>

يشغّل `clickhousectl cloud service query` استعلامات SQL عبر HTTP، دون الحاجة إلى ملف تنفيذي لـ `clickhouse` محلي أو كلمة مرور الخدمة. ينشئ الاستدعاء الأول تلقائيًا نقطة نهاية لواجهة برمجة تطبيقات الاستعلام ومفتاح API مقيّدًا بالخدمة:

```bash
clickhousectl cloud service query --id "$CH_ID" --query "SHOW databases"
```

```text
Provisioning Query API endpoint + key for service 'quickstart-ch'...
{"name":"INFORMATION_SCHEMA"}
{"name":"default"}
{"name":"information_schema"}
{"name":"system"}
```

يكون إخراج الأنبوب افتراضيًا بتنسيق `JSONEachRow`؛ مرّر `--format PrettyCompact` للحصول على إخراج على هيئة جدول بدلًا من ذلك.

<div id="create-database-and-table">
  ## إنشاء قاعدة بيانات وجدول
</div>

```bash
clickhousectl cloud service query --id "$CH_ID" \
  --query "CREATE DATABASE IF NOT EXISTS helloworld"

clickhousectl cloud service query --id "$CH_ID" \
  --query "CREATE TABLE helloworld.my_first_table (
    user_id UInt32,
    message String,
    timestamp DateTime,
    metric Float32
  ) ENGINE = MergeTree()
  PRIMARY KEY (user_id, timestamp)"
```

يطبع كلا الأمرين `OK`. أدرج بضعة صفوف:

```bash
clickhousectl cloud service query --id "$CH_ID" \
  --query "INSERT INTO helloworld.my_first_table (user_id, message, timestamp, metric) VALUES
    (101, 'Hello, ClickHouse!', now(), -1.0),
    (102, 'Insert a lot of rows per batch', yesterday(), 1.41421),
    (102, 'Sort your data based on your commonly-used queries', today(), 2.718),
    (101, 'Granules are the smallest chunks of data read', now() + 5, 3.14159)"
```

تحقّق من نجاح العملية:

```bash
clickhousectl cloud service query --id "$CH_ID" \
  --query "SELECT * FROM helloworld.my_first_table ORDER BY timestamp"
```

```text
{"user_id":102,"message":"Insert a lot of rows per batch","timestamp":"2026-08-26 00:00:00","metric":1.41421}
{"user_id":102,"message":"Sort your data based on your commonly-used queries","timestamp":"2026-08-27 00:00:00","metric":2.718}
{"user_id":101,"message":"Hello, ClickHouse!","timestamp":"2026-08-27 10:41:28","metric":-1}
{"user_id":101,"message":"Granules are the smallest chunks of data read","timestamp":"2026-08-27 10:41:33","metric":3.14159}
```

تعتمد الطوابع الزمنية على وقت تنفيذ عملية insert، لذا ستختلف القيم لديك.

<div id="load-csv-file">
  ## تحميل ملف CSV
</div>

افترض أن النص التالي موجود في ملف CSV باسم `data.csv`:

```text title="data.csv"
102,This is data in a file,2022-02-22 10:43:28,123.45
101,It is comma-separated,2022-02-23 00:00:00,456.78
103,Use FORMAT to specify the format,2022-02-21 10:43:30,678.90
```

تقرأ `INSERT ... FORMAT` البيانات من stdin، لذا مرّر الاستعلام والملف معًا عبر pipe:

```bash
printf 'INSERT INTO helloworld.my_first_table FORMAT CSV\n' | cat - data.csv \
  | clickhousectl cloud service query --id "$CH_ID"
```

تحقّق من إدراج الصفوف الجديدة:

```bash
clickhousectl cloud service query --id "$CH_ID" \
  --query "SELECT count() FROM helloworld.my_first_table"
```

```text
{"count()":7}
```

<div id="native-client">
  ## الاتصال باستخدام clickhouse client
</div>

يمكنك أيضًا الاتصال عبر البروتوكول الأصلي باستخدام [**clickhouse client**](/ar/concepts/features/interfaces/client). تتولى واجهة سطر أوامر ClickHouse إدارة الملف التنفيذي `clickhouse` نيابةً عنك، لذا لا تحتاج إلى تثبيت عميل منفصل:

```bash
clickhousectl local use latest
```

يثبّت هذا أحدث ملف تنفيذي لـ `clickhouse` وينشئ رابطًا رمزيًا له في `~/.local/bin/clickhouse`، بحيث يصبح أمر `clickhouse` متاحًا عموميًا ضمن `PATH`.

بعد ذلك، اتصل باستخدام اسم المضيف وكلمة المرور الواردين في استجابة الإنشاء. عند استخدام `--query`، تُطبع النتيجة ثم ينهي العميل عمله؛ أما بدونه، فستظهر لك موجّه الأوامر التفاعلي (`:)`) الذي يمكنك الخروج منه باستخدام `exit`:

```bash
clickhouse client --host "$CH_HOST" --secure --port 9440 \
  --user default --password "$CH_PASSWORD" \
  --query "SELECT * FROM helloworld.my_first_table ORDER BY timestamp FORMAT TabSeparated"
```

```text
102	Insert a lot of rows per batch	2026-08-26 00:00:00	1.41421
102	Sort your data based on your commonly-used queries	2026-08-27 00:00:00	2.718
101	Hello, ClickHouse!	2026-08-27 10:41:28	-1
101	Granules are the smallest chunks of data read	2026-08-27 10:41:33	3.14159
103	Use FORMAT to specify the format	2022-02-21 10:43:30	678.9
102	This is data in a file	2022-02-22 10:43:28	123.45
101	It is comma-separated	2022-02-23 00:00:00	456.78
```

يتيح نموذج الأمر نفسه تحميل الملفات:

```bash
clickhouse client --host "$CH_HOST" --secure --port 9440 \
  --user default --password "$CH_PASSWORD" \
  --query='INSERT INTO helloworld.my_first_table FORMAT CSV' < data.csv
```

<div id="cleanup">
  ## التنظيف
</div>

يؤدي حذف الخدمة إلى إزالة جميع بياناتها نهائيًا. يوقف الخيار `--force` الخدمة قيد التشغيل أولًا:

```bash
clickhousectl cloud service delete "$CH_ID" --force
```

للاحتفاظ بالبيانات مع إيقاف تكاليف الحوسبة، أوقف الخدمة باستخدام `clickhousectl cloud service stop "$CH_ID"` بدلًا من ذلك.
