title: مصادقة S3 والدلو
---

<Accordion title="أنشئ حاويات S3 ومستخدم IAM">
  يستعرض هذا المقال الأساسيات المتعلقة بكيفية تهيئة AWS IAM user، وإنشاء S3 bucket، وتهيئة ClickHouse لاستخدامه بوصفه S3 disk.
  يُنصح بالتنسيق مع فريق الأمان لديك لتحديد الـ permissions المطلوبة، واعتبار ما يرد هنا نقطةَ بداية.

  ### إنشاء مستخدم AWS IAM

  في الخطوات التالية، ستقوم بإنشاء مستخدم حساب خدمة (لا مستخدم تسجيل دخول).

  1. سجّل الدخول إلى وحدة تحكم إدارة AWS IAM.

  2. من قائمة `Users`، اختر `Create user`

  <Frame>
    <img src="/images/_snippets/s3/s3-1.webp" alt="AWS IAM Management Console - إضافة مستخدم جديد" />
  </Frame>

  3. أدخل اسم المستخدم، واضبط نوع بيانات الاعتماد على `Access key - Programmatic access`، ثم اختر `Next: Permissions`

  <Frame>
    <img src="/images/_snippets/s3/s3-2.webp" alt="إعداد اسم المستخدم ونوع الوصول لمستخدم IAM" />
  </Frame>

  4. لا تُضِف المستخدم إلى أي مجموعة؛ اختر `Next: Tags`

  <Frame>
    <img src="/images/_snippets/s3/s3-3.webp" alt="تخطي إسناد المجموعة إلى مستخدم IAM" />
  </Frame>

  5. إذا لم تكن بحاجة إلى إضافة أي وسوم، فحدِّد `Next: Review`

  <Frame>
    <img src="/images/_snippets/s3/s3-4.webp" alt="تخطي إسناد الوسم إلى مستخدم IAM" />
  </Frame>

  6. اختر `Create User`

  <Note>
    يمكن تجاهل رسالة التحذير التي تفيد بأن المستخدم لا يملك أي أذونات؛ إذ ستُمنح له الأذونات على الـ bucket في القسم التالي
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-5.webp" alt="إنشاء IAM user مع تحذير بعدم وجود أذونات" />
  </Frame>

  7. تم إنشاء المستخدم الآن؛ انقر على `show` وانسخ مفتاحَي الوصول والسر.

  <Note>
    احفظ المفاتيح في مكان آخر، فهذه هي المرة الوحيدة التي سيكون فيها مفتاح الوصول السري متاحًا.
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-6.webp" alt="عرض مفاتيح الوصول الخاصة بـ IAM user ونسخها" />
  </Frame>

  8. انقر على «إغلاق»، ثم ابحث عن المستخدم في صفحة المستخدمين.

  <Frame>
    <img src="/images/_snippets/s3/s3-7.webp" alt="العثور على IAM user المُنشأ حديثًا في قائمة المستخدمين" />
  </Frame>

  9. انسخ ARN ‏(Amazon Resource Name) واحفظه لاستخدامه عند إعداد سياسة الوصول الخاصة بالحاوية.

  <Frame>
    <img src="/images/_snippets/s3/s3-8.webp" alt="نسخ ARN لمستخدم IAM" />
  </Frame>

  ### إنشاء حزمة S3

  1. في قسم S3 bucket، اختر `Create bucket`

  <Frame>
    <img src="/images/_snippets/s3/s3-9.webp" alt="بدء إنشاء حاوية S3" />
  </Frame>

  2. أدخل اسم الـ bucket، واترك الخيارات الأخرى على الإعدادات الافتراضية

  <Note>
    يجب أن يكون اسم الحاوية فريدًا على مستوى AWS كله، وليس على مستوى المؤسسة فقط، وإلا فسيظهر خطأ.
  </Note>

  3. اترك `Block all Public Access` مفعّلًا؛ إذ لا حاجة إلى الوصول عبر الإنترنت العام.

  <Frame>
    <img src="/images/_snippets/s3/s3-a.webp" alt="تهيئة إعدادات حاوية S3 مع حظر الوصول العام" />
  </Frame>

  4. انقر على `Create Bucket` أسفل الصفحة

  <Frame>
    <img src="/images/_snippets/s3/s3-b.webp" alt="إتمام إنشاء حاوية S3" />
  </Frame>

  5. اختر الرابط، وانسخ قيمة ARN، واحفظها لاستخدامها عند تكوين سياسة الوصول إلى الحاوية.

  6. بعد إنشاء الحاوية، اعثر على حاوية S3 الجديدة في قائمة حاويات S3 واختر الرابط

  <Frame>
    <img src="/images/_snippets/s3/s3-c.webp" alt="العثور على حاوية S3 المُنشأة حديثًا في قائمة الحاويات" />
  </Frame>

  7. اختر `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-d.webp" alt="إنشاء مجلد جديد داخل حاوية S3" />
  </Frame>

  8. أدخِل اسم مجلد ليكون الوجهة لقرص S3 في ClickHouse، ثم حدِّد `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-e.webp" alt="تعيين اسم المجلد لاستخدام قرص S3 الخاص بـ ClickHouse" />
  </Frame>

  9. ينبغي أن يكون المجلد ظاهرًا الآن في قائمة الحاويات

  <Frame>
    <img src="/images/_snippets/s3/s3-f.webp" alt="عرض المجلد المُنشأ حديثًا في حاوية S3" />
  </Frame>

  10. حدِّد مربع الاختيار الخاص بالمجلد الجديد، ثم انقر على `Copy URL` واحفظ عنوان URL المنسوخ لاستخدامه في إعدادات تخزين ClickHouse في القسم التالي.

  <Frame>
    <img src="/images/_snippets/s3/s3-g.webp" alt="نسخ عنوان URL لمجلد S3 لإعداد ClickHouse" />
  </Frame>

  11. اختر علامة التبويب `Permissions` وانقر على الزر `Edit` في قسم `Bucket Policy`

  <Frame>
    <img src="/images/_snippets/s3/s3-h.webp" alt="الوصول إلى إعدادات سياسة حاوية S3" />
  </Frame>

  12. أضف سياسة للحاوية، كما في المثال أدناه:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    يجب أن تعمل مع فريق الأمن لديك لتحديد الأذونات التي ينبغي استخدامها، واعتبر هذه نقطة انطلاق.
    لمزيد من المعلومات حول السياسات والإعدادات، راجع وثائق AWS:
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. احفظ إعدادات السياسة.
</Accordion>
