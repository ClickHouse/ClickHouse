  ### Generar una clave de acceso

  ### Crear una clave HMAC y un secreto para una cuenta de servicio

  Abra **Cloud Storage &gt; Settings &gt; Interoperability** y elija una **Access key** existente, o **CREATE A KEY FOR A SERVICE ACCOUNT**. Esta guía explica el proceso para crear una clave nueva para una cuenta de servicio nueva.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-a-service-account-key.webp" alt="Generación de una clave HMAC para una cuenta de servicio en GCS" />
  </Frame>

  ### Añadir una nueva cuenta de servicio

  Si este proyecto no tiene ninguna cuenta de servicio existente, haga clic en **CREATE NEW ACCOUNT**.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-0.webp" alt="Adición de una nueva cuenta de servicio en GCS" />
  </Frame>

  La creación de la cuenta de servicio consta de tres pasos. En el primero, asigne a la cuenta un nombre, un ID y una descripción significativos.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-a.webp" alt="Definición del nombre y el ID de una nueva cuenta de servicio en GCS" />
  </Frame>

  En el cuadro de diálogo de configuración de Interoperability, se recomienda el IAM role **Storage Object Admin**; seleccione ese rol en el segundo paso.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-2.webp" alt="Selección del IAM role Storage Object Admin en GCS" />
  </Frame>

  El tercer paso es opcional y no se usa en esta guía. Puede permitir que los usuarios tengan estos privilegios según sus políticas.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-3.webp" alt="Configuración adicional de la nueva cuenta de servicio en GCS" />
  </Frame>

  Se mostrará la clave HMAC de la cuenta de servicio. Guarde esta información, ya que se utilizará en la configuración de ClickHouse.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-guide-key.webp" alt="Recuperación de la clave HMAC generada para GCS" />
  </Frame>
