---
title: Fragmento de diccionario en Cloud
---

<Note title="ClickHouse Cloud">
  Use [`CREATE DICTIONARY`](/es/reference/statements/create/dictionary#creating-a-dictionary-with-a-ddl-query) para crear diccionarios.

  Al crear un diccionario que lea datos de una tabla de ClickHouse, incluya el nombre de usuario y la contraseña de un usuario dedicado en la cláusula `SOURCE`. Ese usuario necesita el permiso `SELECT` sobre la tabla de origen. Consulte el [ejemplo de origen del diccionario de ClickHouse](/es/reference/statements/create/dictionary/sources/clickhouse).

  Consulte la lista de orígenes de diccionario compatibles en la [guía de compatibilidad de Cloud](/es/products/cloud/guides/cloud-compatibility).
</Note>
