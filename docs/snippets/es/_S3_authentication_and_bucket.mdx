title: Autenticación y bucket en S3
---

<Accordion title="Cree buckets de S3 y un usuario de IAM">
  Este artículo muestra los conceptos básicos de cómo configurar un usuario de IAM de AWS, crear un bucket de S3 y configurar ClickHouse para usar el bucket como un disco S3.
  Se recomienda trabajar con su equipo de seguridad para determinar los permisos que se utilizarán, y considerar estos como punto de partida.

  ### Crear un usuario de IAM de AWS

  En los siguientes pasos crearás un usuario de cuenta de servicio (no un usuario de inicio de sesión).

  1. Inicie sesión en la Consola de administración de AWS IAM.

  2. En el menú `Users`, seleccione `Create user`

  <Image size="md" img="/images/_snippets/s3/s3-1.webp" alt="Consola de administración de AWS IAM - Añadir un usuario nuevo" border force />

  3. Ingresa el nombre de usuario, establece el tipo de credencial como `Access key - Programmatic access` y selecciona `Next: Permissions`

  <Image size="md" img="/images/_snippets/s3/s3-2.webp" alt="Configurar el nombre de usuario y el tipo de acceso para el usuario de IAM" border force />

  4. No añadas al usuario a ningún grupo; selecciona `Next: Tags`

  <Image size="md" img="/images/_snippets/s3/s3-3.webp" alt="Omitir la asignación de grupo para el usuario de IAM" border force />

  5. A menos que necesites añadir alguna etiqueta, selecciona `Next: Review`

  <Image size="md" img="/images/_snippets/s3/s3-4.webp" alt="Omitir la asignación de etiquetas al usuario de IAM" border force />

  6. Selecciona `Create User`

  <Note>
    El mensaje de advertencia que indica que el usuario no tiene permisos puede ignorarse; en la siguiente sección se le concederán permisos sobre el bucket
  </Note>

  <Image size="md" img="/images/_snippets/s3/s3-5.webp" alt="Advertencia al crear el usuario de IAM sin permisos" border force />

  7. El usuario ya se ha creado; haz clic en `show` y copia la clave de acceso y la clave secreta.

  <Note>
    Guarda las claves en otro lugar; es la única vez que la clave de acceso secreta estará disponible.
  </Note>

  <Image size="md" img="/images/_snippets/s3/s3-6.webp" alt="Ver y copiar las claves de acceso del usuario de IAM" border force />

  8. Haz clic en Cerrar y luego busca al usuario en la pantalla de usuarios.

  <Image size="md" img="/images/_snippets/s3/s3-7.webp" alt="Encontrar al usuario de IAM recién creado en la lista de usuarios" border force />

  9. Copia el ARN (Amazon Resource Name) y guárdalo para usarlo al configurar la política de acceso del bucket.

  <Image size="md" img="/images/_snippets/s3/s3-8.webp" alt="Copiar el ARN del usuario de IAM" border force />

  ### Crear un bucket de S3

  1. En la sección del bucket de S3, selecciona `Create bucket`

  <Image size="md" img="/images/_snippets/s3/s3-9.webp" alt="Inicio del proceso de creación del bucket de S3" border force />

  2. Introduzca un nombre para el bucket y deje el resto de opciones por defecto

  <Note>
    El nombre del bucket debe ser único en todo AWS, no solo dentro de la organización; de lo contrario, se generará un error.
  </Note>

  3. Deja `Block all Public Access` activado; no se necesita acceso público.

  <Image size="md" img="/images/_snippets/s3/s3-a.webp" alt="Configurar los ajustes del bucket de S3 con el acceso público bloqueado" border force />

  4. Selecciona `Create Bucket` en la parte inferior de la página

  <Image size="md" img="/images/_snippets/s3/s3-b.webp" alt="Finalizar la creación del bucket de S3" border force />

  5. Seleccione el enlace, copie el ARN y guárdelo para utilizarlo al configurar la política de acceso del bucket.

  6. Una vez creado el bucket, busque el nuevo bucket de S3 en la lista de buckets de S3 y seleccione el enlace

  <Image size="md" img="/images/_snippets/s3/s3-c.webp" alt="Localizar el bucket de S3 recién creado en la lista de buckets" border force />

  7. Selecciona `Create folder`

  <Image size="md" img="/images/_snippets/s3/s3-d.webp" alt="Creación de una nueva carpeta en el bucket de S3" border force />

  8. Introduzca un nombre para la carpeta que será el destino del disco S3 de ClickHouse y seleccione `Create folder`

  <Image size="md" img="/images/_snippets/s3/s3-e.webp" alt="Configurar el nombre de la carpeta para usar el disco S3 de ClickHouse" border force />

  9. La carpeta ahora debería aparecer en la lista de buckets

  <Image size="md" img="/images/_snippets/s3/s3-f.webp" alt="Vista de la carpeta recién creada en el bucket de S3" border force />

  10. Seleccione la casilla de la nueva carpeta y haga clic en `Copy URL`. Guarde la URL copiada para usarla en la configuración de almacenamiento de ClickHouse en la siguiente sección.

  <Image size="md" img="/images/_snippets/s3/s3-g.webp" alt="Copiar la URL de la carpeta de S3 para configurar ClickHouse" border force />

  11. Seleccione la pestaña `Permissions` y haga clic en el botón `Edit` de la sección `Bucket Policy`

  <Image size="md" img="/images/_snippets/s3/s3-h.webp" alt="Acceso a la configuración de la política del bucket de S3" border force />

  12. Añada una política para el bucket; a continuación se muestra un ejemplo:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    Debe trabajar con su equipo de seguridad para determinar los permisos que se usarán; considérelos como punto de partida.
    Para obtener más información sobre las políticas y la configuración, consulte la documentación de AWS:
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. Guarde la configuración de la política.
</Accordion>
