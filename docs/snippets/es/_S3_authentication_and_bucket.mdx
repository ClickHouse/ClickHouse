title: Autenticación y bucket en S3
---

<Accordion title="Crear buckets de S3 y un usuario de IAM">
  Este artículo muestra los conceptos básicos de cómo configurar un usuario de IAM de AWS, crear un bucket de S3 y configurar ClickHouse para utilizar el bucket como un disco S3.
  Se recomienda trabajar con el equipo de seguridad para determinar los permisos que se utilizarán, y tomar estos como punto de partida.

  ### Crear un usuario de IAM de AWS

  En los siguientes pasos crearás un usuario de cuenta de servicio (no un usuario de inicio de sesión).

  1. Inicia sesión en la Consola de administración de AWS IAM.

  2. En el menú `Users`, selecciona `Create user`.

  <Frame>
    <img src="/images/_snippets/s3/s3-1.webp" alt="Consola de administración de AWS IAM: añadir un nuevo usuario" />
  </Frame>

  3. Introduzca el nombre de usuario, establezca el tipo de credencial en `Access key - Programmatic access` y seleccione `Next: Permissions`

  <Frame>
    <img src="/images/_snippets/s3/s3-2.webp" alt="Configuración del nombre de usuario y del tipo de acceso para el IAM user" />
  </Frame>

  4. No añadas al usuario a ningún grupo; selecciona `Next: Tags`

  <Frame>
    <img src="/images/_snippets/s3/s3-3.webp" alt="Omisión de la asignación de grupo para el usuario de IAM" />
  </Frame>

  5. Si no necesita añadir etiquetas, seleccione `Next: Review`

  <Frame>
    <img src="/images/_snippets/s3/s3-4.webp" alt="Omitiendo la asignación de etiquetas al usuario de IAM" />
  </Frame>

  6. Seleccione la opción `Create User`

  <Note>
    El mensaje de advertencia que indica que el usuario no tiene permisos puede ignorarse; en la siguiente sección se otorgarán permisos sobre el bucket al usuario
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-5.webp" alt="Creación del IAM user con advertencia de falta de permisos" />
  </Frame>

  7. El usuario ya está creado; haz clic en `show` y copia la clave de acceso y la clave secreta.

  <Note>
    Guarda las claves en otro lugar; esta es la única vez que la clave secreta de acceso estará disponible.
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-6.webp" alt="Visualización y copia de las claves de acceso del usuario IAM" />
  </Frame>

  8. Haga clic en Cerrar y, a continuación, busque al usuario en la pantalla de usuarios.

  <Frame>
    <img src="/images/_snippets/s3/s3-7.webp" alt="Encontrar el usuario de IAM recién creado en la lista de usuarios" />
  </Frame>

  9. Copie el ARN (Amazon Resource Name) y guárdelo para usarlo al configurar la política de acceso del bucket.

  <Frame>
    <img src="/images/_snippets/s3/s3-8.webp" alt="Copiando el ARN del usuario de IAM" />
  </Frame>

  ### Crear un bucket de S3

  1. En la sección del bucket de S3, selecciona `Create bucket`

  <Frame>
    <img src="/images/_snippets/s3/s3-9.webp" alt="Inicio de la creación del bucket de S3" />
  </Frame>

  2. Introduzca un nombre para el bucket y deje el resto de opciones por defecto

  <Note>
    El nombre del bucket debe ser único en todo AWS, no solo dentro de la organización, o se producirá un error.
  </Note>

  3. Deja `Block all Public Access` activada; no se necesita acceso público.

  <Frame>
    <img src="/images/_snippets/s3/s3-a.webp" alt="Configuración de los ajustes del bucket de S3 con el acceso público bloqueado" />
  </Frame>

  4. Seleccione `Create Bucket` al final de la página

  <Frame>
    <img src="/images/_snippets/s3/s3-b.webp" alt="Finalizando la creación del bucket de S3" />
  </Frame>

  5. Selecciona el enlace, copia el ARN y guárdalo para usarlo al configurar la política de acceso del bucket.

  6. Una vez creado el bucket, busca el nuevo bucket de S3 en la lista de buckets de S3 y selecciona el enlace

  <Frame>
    <img src="/images/_snippets/s3/s3-c.webp" alt="Ubicación del bucket de S3 recién creado en la lista de buckets" />
  </Frame>

  7. Selecciona `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-d.webp" alt="Creación de una carpeta nueva en el bucket de S3" />
  </Frame>

  8. Introduce un nombre para la carpeta que será el destino del disco S3 de ClickHouse y selecciona `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-e.webp" alt="Configuración del nombre de la carpeta para el uso del disco S3 en ClickHouse" />
  </Frame>

  9. La carpeta ya debería aparecer en la lista de buckets

  <Frame>
    <img src="/images/_snippets/s3/s3-f.webp" alt="Vista de la carpeta recién creada en el bucket de S3" />
  </Frame>

  10. Selecciona la casilla de la nueva carpeta y haz clic en `Copy URL`. Guarda la URL copiada para usarla en la configuración de almacenamiento de ClickHouse en la siguiente sección.

  <Frame>
    <img src="/images/_snippets/s3/s3-g.webp" alt="Copiar la URL de la carpeta de S3 para la configuración de ClickHouse" />
  </Frame>

  11. Seleccione la pestaña `Permissions` y haga clic en el botón `Edit` de la sección `Bucket Policy`

  <Frame>
    <img src="/images/_snippets/s3/s3-h.webp" alt="Acceso a la configuración de la política del bucket de S3" />
  </Frame>

  12. Añade una política al bucket, como se muestra a continuación:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    Debe trabajar con su equipo de seguridad para determinar qué permisos deben utilizarse; considérelos un punto de partida.
    Para obtener más información sobre las políticas y la configuración, consulte la documentación de AWS:
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. Guarde la configuración de la política.
</Accordion>
