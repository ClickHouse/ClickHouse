---
title: S3 の認証とバケット
---

<Accordion title="S3 バケットと IAM ユーザーを作成する">
  この記事では、AWS IAM ユーザーの設定、S3 バケットの作成、および ClickHouse がそのバケットを S3 ディスクとして使用するための設定方法の基本について説明します。
  使用する権限の決定にあたっては、セキュリティチームと連携し、ここで示す内容を出発点として検討してください。

  ### AWS IAM ユーザーの作成

  以下の手順では、サービスアカウントユーザー (ログインユーザーではなく) を作成します。

  1. AWS IAM Management Console にログインします。

  2. `Users` メニューで、`Create user` を選択します。

  <Frame>
    <img src="/images/_snippets/s3/s3-1.webp" alt="AWS IAM Management Console - 新規ユーザーの追加" />
  </Frame>

  3. ユーザー名を入力し、認証情報の種類を `Access key - Programmatic access` に設定して、`Next: Permissions` を選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-2.webp" alt="IAM ユーザーのユーザー名とアクセス種別の設定" />
  </Frame>

  4. ユーザーをどのグループにも追加せず、`Next: Tags` を選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-3.webp" alt="IAMユーザーへのグループ割り当てをスキップ" />
  </Frame>

  5. タグを追加する必要がある場合を除き、`Next: Review` を選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-4.webp" alt="IAMユーザーのタグ割り当てをスキップ" />
  </Frame>

  6. `Create User` をクリックします

  <Note>
    ユーザーに権限がないという警告メッセージは無視してかまいません。次のセクションで、そのユーザーにバケットへの権限を付与します
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-5.webp" alt="権限がないという警告が表示された IAM user の作成" />
  </Frame>

  7. これでユーザーが作成されました。`show` をクリックし、アクセスキーとシークレットキーをコピーします。

  <Note>
    キーは別の場所にも保存しておいてください。シークレットアクセスキーを確認できるのはこのときだけです。
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-6.webp" alt="IAM userのアクセスキーの表示とコピー" />
  </Frame>

  8. 「Close」をクリックし、次にUsers画面でそのユーザーを見つけます。

  <Frame>
    <img src="/images/_snippets/s3/s3-7.webp" alt="ユーザー一覧で新しく作成したIAM userを見つける" />
  </Frame>

  9. ARN (Amazon Resource Name) をコピーし、後でバケットのアクセスポリシーを設定する際に使用できるよう保存します。

  <Frame>
    <img src="/images/_snippets/s3/s3-8.webp" alt="IAM userのARNをコピーする" />
  </Frame>

  ### S3バケットの作成

  1. S3 bucket セクションで、`Create bucket` を選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-9.webp" alt="S3バケットの作成を開始する" />
  </Frame>

  2. バケット名を入力し、残りのオプションはデフォルトのままにします

  <Note>
    バケット名は、組織内だけでなくAWS全体で一意である必要があり、そうでない場合はエラーが発生します。
  </Note>

  3. `Block all Public Access` は有効のままにしてください。パブリックアクセスは不要です。

  <Frame>
    <img src="/images/_snippets/s3/s3-a.webp" alt="パブリックアクセスをブロックした状態でのS3バケット設定" />
  </Frame>

  4. ページ下部の`Create Bucket`を選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-b.webp" alt="S3バケットの作成完了" />
  </Frame>

  5. リンクを選択し、ARN をコピーして、バケットのアクセスポリシーを設定するときに使えるよう保存します。

  6. バケットが作成されたら、S3 バケット一覧で新しい S3 バケットを見つけ、リンクを選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-c.webp" alt="バケット一覧で新しく作成したS3バケットを見つける" />
  </Frame>

  7. `Create folder` をクリックします

  <Frame>
    <img src="/images/_snippets/s3/s3-d.webp" alt="S3 バケットに新しいフォルダを作成" />
  </Frame>

  8. ClickHouse S3 ディスクの保存先となるフォルダ名を入力し、`Create folder` を選択します

  <Frame>
    <img src="/images/_snippets/s3/s3-e.webp" alt="ClickHouseのS3ディスクで使用するフォルダー名の設定" />
  </Frame>

  9. フォルダがバケットの一覧に表示されるはずです

  <Frame>
    <img src="/images/_snippets/s3/s3-f.webp" alt="S3バケットで新しく作成されたフォルダを表示" />
  </Frame>

  10. 新しいフォルダのチェックボックスをオンにして、`Copy URL` をクリックします。コピーした URL は、次のセクションで ClickHouse のストレージ構成に使用するため、保存しておいてください。

  <Frame>
    <img src="/images/_snippets/s3/s3-g.webp" alt="ClickHouse の設定用に S3 フォルダの URL をコピーする" />
  </Frame>

  11. `Permissions` タブを開き、`Bucket Policy` セクションの `Edit` ボタンをクリックします

  <Frame>
    <img src="/images/_snippets/s3/s3-h.webp" alt="S3 バケットのポリシー設定にアクセスする" />
  </Frame>

  12. バケットポリシーを追加します。例を以下に示します。

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    使用する権限を決定する際は、セキュリティチームと連携してください。以下はその出発点としてご検討ください。
    ポリシーと設定の詳細については、AWS のドキュメントを参照してください。
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. ポリシーの設定を保存します。
</Accordion>
