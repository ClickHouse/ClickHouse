---
title: S3 の認証とバケット
---

<Accordion title="S3 バケットと IAM ユーザーを作成する">
  この記事では、AWS IAMユーザーの設定、S3バケットの作成、およびClickHouseがそのバケットをS3ディスクとして使用するための設定方法の基本について説明します。
  使用するpermissionsはセキュリティチームと連携して決定してください。ここで示す内容はあくまで出発点としてご参照ください。

  ### AWS IAM ユーザーの作成

  以下の手順では、サービスアカウントユーザー (ログインユーザーではなく) を作成します。

  1. AWS IAM Management Console にログインします。

  2. `Users` メニューで `Create user` を選択します。

  <Image size="md" img="/images/_snippets/s3/s3-1.webp" alt="AWS IAM Management Console - 新規ユーザーの追加" border force />

  3. ユーザー名を入力し、認証情報タイプを `Access key - Programmatic access` に設定して、`Next: Permissions` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-2.webp" alt="IAM ユーザーのユーザー名とアクセスタイプの設定" border force />

  4. ユーザーをどのグループにも追加せず; `Next: Tags` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-3.webp" alt="IAMユーザーのグループ割り当てをスキップしています" border force />

  5. タグを追加する必要がなければ、`Next: Review` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-4.webp" alt="IAM user へのタグ割り当てをスキップする" border force />

  6. `Create User` を選択します

  <Note>
    ユーザーに権限がないという警告メッセージは無視して問題ありません。次のセクションで、そのユーザーにバケットへの権限が付与されます
  </Note>

  <Image size="md" img="/images/_snippets/s3/s3-5.webp" alt="権限のないIAMユーザーを作成する際の警告" border force />

  7. これでユーザーが作成されました。`show` をクリックして、アクセスキーとシークレットキーをコピーします。

  <Note>
    キーは別の場所に保存してください。シークレットアクセスキーを確認できるのは、このときだけです。
  </Note>

  <Image size="md" img="/images/_snippets/s3/s3-6.webp" alt="IAM userのアクセスキーを表示してコピーする" border force />

  8. 「close」をクリックし、その後 Users 画面でそのユーザーを見つけます。

  <Image size="md" img="/images/_snippets/s3/s3-7.webp" alt="ユーザー一覧で新しく作成したIAM userを見つける" border force />

  9. ARN (Amazon Resource Name) をコピーし、バケットのアクセスポリシーを設定する際に使用できるよう保存します。

  <Image size="md" img="/images/_snippets/s3/s3-8.webp" alt="IAM userのARNをコピーする" border force />

  ### S3バケットの作成

  1. S3 bucket セクションで、`Create bucket` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-9.webp" alt="S3バケットの作成を開始する" border force />

  2. バケット名を入力し、他のオプションはデフォルトのままにします

  <Note>
    バケット名は、組織内だけでなくAWS全体で一意である必要があります。そうでない場合はエラーになります。
  </Note>

  3. `Block all Public Access` は有効のままにしてください。パブリックアクセスは不要です。

  <Image size="md" img="/images/_snippets/s3/s3-a.webp" alt="パブリックアクセスをブロックしたS3バケットの設定" border force />

  4. ページ下部で `Create Bucket` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-b.webp" alt="S3バケットの作成を完了する" border force />

  5. リンクを選択し、ARN をコピーして、バケットのアクセスポリシーを設定するときに使えるよう保存します。

  6. バケットが作成されたら、S3 バケット一覧で新しい S3 バケットを見つけて、そのリンクを選択します

  <Image size="md" img="/images/_snippets/s3/s3-c.webp" alt="バケット一覧で新しく作成したS3バケットを見つける" border force />

  7. `Create folder` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-d.webp" alt="S3 バケットに新しいフォルダを作成する" border force />

  8. ClickHouse S3 ディスクの保存先にするフォルダ名を入力し、`Create folder` を選択します

  <Image size="md" img="/images/_snippets/s3/s3-e.webp" alt="ClickHouse S3ディスク使用時のフォルダー名を設定する" border force />

  9. フォルダーがバケット一覧に表示されているはずです

  <Image size="md" img="/images/_snippets/s3/s3-f.webp" alt="S3 バケット内に新しく作成されたフォルダを表示する" border force />

  10. 新しいフォルダのチェックボックスをオンにし、`Copy URL` をクリックします。コピーした URL は、次のセクションで ClickHouse のストレージ構成に使用するため、保存しておいてください。

  <Image size="md" img="/images/_snippets/s3/s3-g.webp" alt="ClickHouse の設定用に S3 フォルダの URL をコピーする" border force />

  11. `Permissions` タブを選択し、`Bucket Policy` セクションで `Edit` ボタンをクリックします

  <Image size="md" img="/images/_snippets/s3/s3-h.webp" alt="S3バケットポリシー設定にアクセスする" border force />

  12. バケットポリシーを追加します。以下に例を示します:

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    使用する権限を決定する際は、セキュリティチームと連携してください。以下はその出発点としてご検討ください。
    ポリシーと設定の詳細については、AWS のドキュメントを参照してください。
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. ポリシー設定を保存します。
</Accordion>
