  ### アクセスキーを生成する

  ### サービスアカウントの HMACキーとシークレットを作成する

  **Cloud Storage &gt; Settings &gt; Interoperability** を開き、既存の **Access key** を選択するか、**CREATE A KEY FOR A SERVICE ACCOUNT** を選択します。このガイドでは、新しいサービスアカウント用に新しいキーを作成する手順を説明します。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-a-service-account-key.webp" alt="GCS でサービスアカウントの HMAC キーを生成する" />
  </Frame>

  ### 新しいサービスアカウントを追加する

  既存のサービスアカウントがないプロジェクトでは、**CREATE NEW ACCOUNT** を選択します。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-0.webp" alt="GCS で新しいサービスアカウントを追加する" />
  </Frame>

  サービスアカウントの作成は 3 つの手順で行います。最初の手順では、アカウントにわかりやすい名前、ID、説明を設定します。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-a.webp" alt="GCS で新しいサービスアカウントの名前と ID を定義する" />
  </Frame>

  Interoperability 設定ダイアログでは、IAM role として **Storage Object Admin** を推奨します。2 つ目の手順でこのロールを選択してください。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-2.webp" alt="GCS で IAM role の Storage Object Admin を選択する" />
  </Frame>

  3 つ目の手順は任意で、このガイドでは使用しません。ポリシーに応じて、ユーザーにこれらの権限を付与できます。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-3.webp" alt="GCS で新しいサービスアカウントの追加設定を構成する" />
  </Frame>

  サービスアカウントの HMAC キーが表示されます。この情報は ClickHouse の設定で使用するため、保存しておいてください。

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-guide-key.webp" alt="GCS 用に生成された HMAC キーを取得する" />
  </Frame>
