---
title: Cloud の Dictionary スニペット
---

<Note title="ClickHouse Cloud">
  Dictionary の作成には [`CREATE DICTIONARY`](/ja/reference/statements/create/dictionary#creating-a-dictionary-with-a-ddl-query) を使用してください。

  ClickHouse テーブルからデータを読み取る Dictionary を作成する場合は、`SOURCE` 句に専用ユーザーのユーザー名とパスワードを指定してください。このユーザーには、ソーステーブルに対する `SELECT` アクセス許可が必要です。詳しくは [ClickHouse Dictionary ソースの例](/ja/reference/statements/create/dictionary/sources/clickhouse)を参照してください。

  [Cloud Compatibility ガイド](/ja/products/cloud/guides/cloud-compatibility)で、サポートされている Dictionary ソースの一覧を確認してください。
</Note>
