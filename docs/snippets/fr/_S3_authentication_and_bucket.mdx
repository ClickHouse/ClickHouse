title: Authentification S3 et bucket

<Accordion title="Créer des buckets S3 et un utilisateur IAM">
  Cet article présente les bases de la configuration d&#39;un AWS IAM user, de la création d&#39;un S3 bucket et de la configuration de ClickHouse pour utiliser ce bucket comme S3 disk.
  Nous vous recommandons de travailler avec votre équipe de sécurité pour déterminer les permissions à appliquer, et de considérer ces éléments comme point de départ.

  ### Créer un utilisateur AWS IAM

  Dans les étapes suivantes, vous allez créer un utilisateur de compte de service (et non un utilisateur avec un compte de connexion).

  1. Connectez-vous à l’interface AWS IAM Management Console.

  2. Dans le menu `Users`, sélectionnez `Create user`

  <Frame>
    <img src="/images/_snippets/s3/s3-1.webp" alt="AWS IAM Management Console - Ajout d’un utilisateur" />
  </Frame>

  3. Saisissez le nom d’utilisateur et définissez le type d’informations d’identification sur `Access key - Programmatic access`, puis sélectionnez `Next: Permissions`

  <Frame>
    <img src="/images/_snippets/s3/s3-2.webp" alt="Définition du nom d’utilisateur et du type d’accès pour l’utilisateur IAM" />
  </Frame>

  4. N’ajoutez pas l’utilisateur à un groupe ; sélectionnez `Next: Tags`

  <Frame>
    <img src="/images/_snippets/s3/s3-3.webp" alt="Ignorer l’attribution à un groupe pour l’utilisateur IAM" />
  </Frame>

  5. Sauf si vous devez ajouter des tags, sélectionnez `Next: Review`

  <Frame>
    <img src="/images/_snippets/s3/s3-4.webp" alt="Omettre l’attribution de tags à l’utilisateur IAM" />
  </Frame>

  6. Sélectionnez `Create User`

  <Note>
    Le message d’avertissement indiquant que l’utilisateur ne dispose d’aucune autorisation peut être ignoré ; des autorisations lui seront accordées sur le bucket dans la section suivante
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-5.webp" alt="Création de l’IAM user avec l’avertissement indiquant l’absence d’autorisations" />
  </Frame>

  7. L’utilisateur a bien été créé ; cliquez sur `show` et copiez les clés d’accès et la clé secrète.

  <Note>
    Conservez ces clés ailleurs ; la clé d’accès secrète ne sera disponible qu’une seule fois.
  </Note>

  <Frame>
    <img src="/images/_snippets/s3/s3-6.webp" alt="Affichage et copie des clés d’accès de l’utilisateur IAM" />
  </Frame>

  8. Cliquez sur Fermer, puis recherchez l’utilisateur dans l’écran Utilisateurs.

  <Frame>
    <img src="/images/_snippets/s3/s3-7.webp" alt="Repérage du nouvel IAM user dans la liste des utilisateurs" />
  </Frame>

  9. Copiez l’ARN (Amazon Resource Name) et enregistrez-le pour l’utiliser lors de la configuration de la stratégie d’accès du bucket.

  <Frame>
    <img src="/images/_snippets/s3/s3-8.webp" alt="Copie de l’ARN de l’utilisateur IAM" />
  </Frame>

  ### Créer un bucket S3

  1. Dans la section Bucket S3, sélectionnez `Create bucket`

  <Frame>
    <img src="/images/_snippets/s3/s3-9.webp" alt="Début du processus de création du bucket S3" />
  </Frame>

  2. Saisissez un nom de bucket, puis laissez les autres options par défaut

  <Note>
    Le nom du bucket doit être unique à l’échelle d’AWS, et pas seulement au sein de l’organisation, sinon une erreur sera renvoyée.
  </Note>

  3. Laissez `Block all Public Access` activé ; l’accès public n’est pas requis.

  <Frame>
    <img src="/images/_snippets/s3/s3-a.webp" alt="Configuration des paramètres du bucket S3 avec l’accès public bloqué" />
  </Frame>

  4. Sélectionnez `Create Bucket` en bas de la page

  <Frame>
    <img src="/images/_snippets/s3/s3-b.webp" alt="Création du bucket S3 finalisée" />
  </Frame>

  5. Sélectionnez le lien, copiez l’ARN et conservez-le pour l’utiliser lors de la configuration de la politique d’accès du bucket.

  6. Une fois le bucket créé, recherchez le nouveau bucket S3 dans la liste des buckets S3 et sélectionnez le lien

  <Frame>
    <img src="/images/_snippets/s3/s3-c.webp" alt="Repérer le nouveau bucket S3 dans la liste des buckets" />
  </Frame>

  7. Sélectionnez `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-d.webp" alt="Création d’un nouveau dossier dans le bucket S3" />
  </Frame>

  8. Saisissez un nom de dossier qui servira de destination pour le disque S3 ClickHouse, puis sélectionnez `Create folder`

  <Frame>
    <img src="/images/_snippets/s3/s3-e.webp" alt="Définition du nom du dossier pour l’utilisation du disk S3 de ClickHouse" />
  </Frame>

  9. Le dossier devrait maintenant apparaître dans la liste des buckets

  <Frame>
    <img src="/images/_snippets/s3/s3-f.webp" alt="Vue du dossier nouvellement créé dans le bucket S3" />
  </Frame>

  10. Cochez la case du nouveau dossier et cliquez sur `Copy URL`. Enregistrez l’URL copiée afin de l’utiliser dans la configuration de stockage de ClickHouse à la section suivante.

  <Frame>
    <img src="/images/_snippets/s3/s3-g.webp" alt="Copie de l’URL du dossier S3 pour configurer ClickHouse" />
  </Frame>

  11. Sélectionnez l’onglet `Permissions`, puis cliquez sur le bouton `Edit` dans la section `Bucket Policy`

  <Frame>
    <img src="/images/_snippets/s3/s3-h.webp" alt="Accès à la configuration de la stratégie du bucket S3" />
  </Frame>

  12. Ajoutez une stratégie de bucket, exemple ci-dessous :

  ```json
  {
    "Version" : "2012-10-17",
    "Id" : "Policy123456",
    "Statement" : [
      {
        "Sid" : "abc123",
        "Effect" : "Allow",
        "Principal" : {
          "AWS" : "arn:aws:iam::921234567898:user/mars-s3-user"
        },
        "Action" : "s3:*",
        "Resource" : [
          "arn:aws:s3:::mars-doc-test",
          "arn:aws:s3:::mars-doc-test/*"
        ]
      }
    ]
  }
  ```

  ```response
  |Parameter | Description | Example Value |
  |----------|-------------|----------------|
  |Version | Version of the policy interpreter, leave as-is | 2012-10-17 |
  |Sid | User-defined policy id | abc123 |
  |Effect | Whether user requests will be allowed or denied | Allow |
  |Principal | The accounts or user that will be allowed | arn:aws:iam::921234567898:user/mars-s3-user |
  |Action | What operations are allowed on the bucket| s3:*|
  |Resource | Which resources in the bucket will operations be allowed in | "arn:aws:s3:::mars-doc-test", "arn:aws:s3:::mars-doc-test/*" |
  ```

  <Note>
    Vous devriez travailler avec votre équipe de sécurité afin de déterminer les autorisations à utiliser ; considérez-les comme un point de départ.
    Pour plus d’informations sur les politiques et les paramètres, consultez la documentation AWS :
    https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-policy-language-overview.html
  </Note>

  13. Enregistrez la configuration de la politique.
</Accordion>
