  ### Générer une clé d&#39;accès

  ### Créer une clé HMAC et un secret de compte de service

  Ouvrez **Cloud Storage &gt; Settings &gt; Interoperability**, puis choisissez une **Access key** existante ou **CREATE A KEY FOR A SERVICE ACCOUNT**. Ce guide décrit la procédure de création d&#39;une nouvelle clé pour un nouveau compte de service.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-a-service-account-key.webp" alt="Génération d'une clé HMAC de compte de service dans GCS" />
  </Frame>

  ### Ajouter un nouveau compte de service

  S&#39;il s&#39;agit d&#39;un projet sans compte de service existant, cliquez sur **CREATE NEW ACCOUNT**.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-0.webp" alt="Ajout d'un nouveau compte de service dans GCS" />
  </Frame>

  La création du compte de service comporte trois étapes ; lors de la première, attribuez au compte un nom, un ID et une description explicites.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-a.webp" alt="Définition d'un nom et d'un ID pour un nouveau compte de service dans GCS" />
  </Frame>

  Dans la boîte de dialogue des paramètres d&#39;interopérabilité, le rôle IAM **Storage Object Admin** est recommandé ; sélectionnez-le à la deuxième étape.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-2.webp" alt="Sélection du rôle IAM Storage Object Admin dans GCS" />
  </Frame>

  La troisième étape est facultative et n&#39;est pas utilisée dans ce guide. Vous pouvez autoriser des utilisateurs à disposer de ces privilèges selon vos politiques.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-create-service-account-3.webp" alt="Configuration de paramètres supplémentaires pour le nouveau compte de service dans GCS" />
  </Frame>

  La clé HMAC du compte de service s&#39;affichera. Enregistrez ces informations, car elles seront utilisées dans la configuration de ClickHouse.

  <Frame>
    <img src="/images/integrations/data-ingestion/s3/GCS-guide-key.webp" alt="Récupération de la clé HMAC générée pour GCS" />
  </Frame>
</Accordion>
