Most administrative tasks in ClickStack involve executing DDL statements on the underlying ClickHouse database.

## ClickStack {#clickstack-oss}

For ClickStack deployments, users perform administrative tasks using the [ClickHouse client](/concepts/features/interfaces/client). The client connects to the database over the native ClickHouse protocol and supports full DDL and administrative operations, as well as providing interactive feedback on queries.

<a id="clickstack-managed"></a>

For ClickHouse Observability, see the [Managed admin guide](/clickstack/managed/managing/admin).
