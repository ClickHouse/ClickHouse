Pages can be opened with deep links using URL query parameters, so you can jump straight into a specific search, dashboard, or panel from an external system (an alert notification, a runbook, a CI job, a chat message, and so on).

The examples on this page use `<YOUR_APP_URL>`. Replace this with your ClickStack URL — for example `http://localhost:8080` for a local deployment.
