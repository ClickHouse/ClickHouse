This section provides various sample datasets and examples to help you get started with ClickStack. These examples demonstrate different ways to work with observability data in ClickStack, from local development to production scenarios.

| Dataset | Description |
|---------|-------------|
| [Sample Data](/clickstack/self-configured/example-datasets/sample-data) | Load a sample dataset containing logs, traces and metrics from our demo environment |
| [Monitoring Kubernetes](/clickstack/self-configured/example-datasets/kubernetes) | Monitor a Kubernetes cluster with ClickStack |
| [Local Data](/clickstack/self-configured/example-datasets/local-data) | Collect local system metrics and logs sending them to ClickStack for analysis |
| [Session Replay Demo](/clickstack/self-configured/example-datasets/session-replay) | Instrument a demo web application for session replay and view your interactions in ClickStack |
| [Chrome Extension](/clickstack/self-configured/example-datasets/chrome-extension) | Inject the Browser SDK into any website using the HyperDX Chrome extension, no application code changes required |
| [Synthetic data with otelgen](/clickstack/self-configured/example-datasets/otelgen) | Use `otelgen` to send synthetic logs, traces and metrics to a running ClickStack OpenTelemetry collector |
| [HackerNews Analyzer](/clickstack/self-configured/example-datasets/instrument-application) | Instrument a Node.js app with an agent (or by hand) and send logs, traces, metrics, and session replay to ClickStack |
