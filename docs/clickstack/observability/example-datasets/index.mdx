These sample datasets and demos help you get started with fully managed ClickHouse Observability. Load sample data, collect logs and metrics from your environment, or instrument an application to explore traces and session replay.

| Dataset | Description |
|---------|-------------|
| [Sample Data](/clickstack/observability/example-datasets/sample-data) | Load a sample dataset containing logs, traces and metrics from our demo environment |
| [Monitoring Kubernetes](/clickstack/observability/example-datasets/kubernetes) | Collect logs and metrics from a Kubernetes cluster and send them to your managed service |
| [Local Data](/clickstack/observability/example-datasets/local-data) | Collect local system metrics and logs and send them to your managed service for analysis |
| [Session Replay Demo](/clickstack/observability/example-datasets/session-replay) | Instrument a demo web application for session replay and view your interactions in ClickHouse Observability |
| [Chrome Extension](/clickstack/observability/example-datasets/chrome-extension) | Inject the Browser SDK into any website using the HyperDX Chrome extension, no application code changes required |
| [Synthetic data with otelgen](/clickstack/observability/example-datasets/otelgen) | Use `otelgen` to send synthetic logs, traces and metrics to your managed telemetry endpoint |
| [Synthetic data with telemetrygen](/clickstack/observability/example-datasets/telemetrygen) | Use `telemetrygen` to send synthetic logs, traces and metrics to your managed telemetry endpoint |
| [HackerNews Analyzer](/clickstack/observability/example-datasets/instrument-application) | Instrument a Node.js app with an agent (or by hand) and send logs, traces, metrics, and session replay to ClickHouse Observability |
