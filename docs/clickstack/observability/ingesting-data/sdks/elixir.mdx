## Getting started {#getting-started-self-configured}

### Install ClickStack logger backend package {#install-hyperdx-logger-backend-package-self-configured}

The package can be installed by adding `hyperdx` to your list of dependencies in
`mix.exs`:

```elixir
def deps do
  [
    {:hyperdx, "~> 0.1.6"}
  ]
end
```

### Configure logger {#configure-logger-self-configured}

Add the following to your `config.exs` file:

```elixir
# config/releases.exs

config :logger,
  level: :info,
  backends: [:console, {Hyperdx.Backend, :hyperdx}]
```

### Configure environment variables {#configure-environment-variables-self-configured}

Afterwards you'll need to configure the following environment variables in your
shell to ship telemetry to ClickStack via the OpenTelemetry collector:

<Tabs>
<Tab title="Managed ClickStack">

```shell
OTEL_SERVICE_NAME='<YOUR_SERVICE_NAME>'
```

</Tab>

<Tab title="ClickStack Open Source">

```shell
export HYPERDX_API_KEY='<YOUR_INGESTION_API_KEY>' \
OTEL_SERVICE_NAME='<YOUR_SERVICE_NAME>'
```

</Tab>
</Tabs>

_The `OTEL_SERVICE_NAME` environment variable is used to identify your service
in the HyperDX app, it can be any name you want._
