## Connect your application {#connect-your-application}

1. Follow the guide for your language or platform to configure instrumentation.
2. Choose your destination in that guide:
   - **ClickHouse Observability:** use your service's managed OTLP endpoint and ingestion API key, available in **Team Settings → Data → Managed Telemetry**.
   - **Self configured:** use your OpenTelemetry Collector's OTLP endpoint and configured ingestion key.
3. Generate application activity, then verify the expected telemetry in the UI.

The individual guides provide the authentication format and exporter settings for each SDK. Some platforms, such as AWS Lambda, send through a local Collector before forwarding telemetry to the destination.
