Use OpenTelemetry Node.js instrumentation to send telemetry from your NestJS application to ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Set up OpenTelemetry {#set-up-opentelemetry}

Follow the official [OpenTelemetry Node.js automatic instrumentation instructions](https://opentelemetry.io/docs/zero-code/js/) to instrument your application. The instrumentation bundle includes [NestJS controller and request tracing](https://github.com/open-telemetry/opentelemetry-js-contrib/tree/main/packages/instrumentation-nestjs-core).

For logs, configure a supported logging integration, such as [Winston log sending](https://github.com/open-telemetry/opentelemetry-js-contrib/tree/main/packages/instrumentation-winston#log-sending). NestJS's default console logger is not automatically exported by the tracing instrumentation.

Configure [OTLP export over HTTP](https://opentelemetry.io/docs/languages/js/exporters/) for the signals you want to send, using the connection settings below. Replace any example destinations or console-exporter settings from the upstream instructions, including signal-specific endpoint overrides.

## Configure your destination {#configure-destination}

<Tabs>
<Tab title="ClickHouse Observability">

Open **Team Settings → Data → Managed Telemetry** in your service and copy the **OTLP HTTP endpoint** and **API key**. Use the complete HTTPS endpoint, including its port:

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
<Tab title="Self configured">

Use your collector's OTLP HTTP endpoint and ingestion key. Use `http://` instead of `https://` if your collector does not have TLS configured. For collector setup, see [Ingesting with OpenTelemetry](/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
</Tabs>

## Verify ingestion {#verify-ingestion}

Start your instrumented application and generate activity. In ClickHouse Observability, select a recent time range and find your application's service name in Logs or Traces. If your application emits metrics, check Metrics after allowing time for export.

For instrumentation and exporter troubleshooting, see the [OpenTelemetry JavaScript documentation](https://opentelemetry.io/docs/languages/js/).
