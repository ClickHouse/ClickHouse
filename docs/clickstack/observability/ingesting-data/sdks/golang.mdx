Use the OpenTelemetry Go SDK to send logs, metrics, and traces to ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Set up OpenTelemetry {#set-up-opentelemetry}

Follow the official [OpenTelemetry Go setup instructions](https://opentelemetry.io/docs/languages/go/getting-started/) to initialize the SDK and instrument your application.

Configure [OTLP export over HTTP](https://opentelemetry.io/docs/languages/go/exporters/) for the signals you want to send, using the connection settings below. Replace any example destinations from the upstream instructions, including signal-specific endpoint overrides.

## Configure your destination {#configure-destination}

<Tabs>
<Tab title="Fully managed">

<BetaBadge label="Beta offering" />

Open **Team Settings → Data → Managed Telemetry** in your service and copy the **OTLP HTTP endpoint** and **API key**. Use the complete HTTPS endpoint, including its port:

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
<Tab title="Self-managed">

Use your collector's OTLP HTTP endpoint and ingestion key. Use `http://` instead of `https://` if your collector does not have TLS configured. For collector setup, see [Ingesting with OpenTelemetry](/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
</Tabs>

## Verify ingestion {#verify-ingestion}

Start your instrumented application and generate activity. In ClickHouse Observability, select a recent time range and find your application's service name in Logs or Traces. If your application emits metrics, check Metrics after allowing time for export.

For instrumentation and exporter troubleshooting, see the [OpenTelemetry Go documentation](https://opentelemetry.io/docs/languages/go/).
