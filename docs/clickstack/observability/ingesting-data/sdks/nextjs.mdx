Use Next.js OpenTelemetry instrumentation to send server-side traces to ClickHouse Observability.

## Set up OpenTelemetry {#set-up-opentelemetry}

Follow the official [Next.js OpenTelemetry setup instructions](https://nextjs.org/docs/app/guides/open-telemetry) to configure `@vercel/otel` in your application's instrumentation file.

Configure [OTLP export](https://github.com/vercel/otel/tree/main/packages/otel#registerotelconfig-configuration) using the connection settings below. Replace any example destinations from the upstream instructions, including signal-specific endpoint overrides. For hosted deployments, set these environment variables in your deployment configuration.

If your Vercel deployment already uses a tracing integration, configure a [custom exporter](https://nextjs.org/docs/app/guides/open-telemetry#custom-exporters) for this destination; endpoint environment variables alone do not override that integration.

For browser telemetry and session replay, use the [Browser SDK guide](/clickstack/observability/ingesting-data/sdks/browser).

## Configure your destination {#configure-destination}

<Tabs>
<Tab title="ClickHouse Observability">

Open **Team Settings → Data → Managed Telemetry** in your service and copy the **OTLP HTTP endpoint** and **API key**. Use the complete HTTPS endpoint, including its port:

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
<Tab title="Self configured">

Use your collector's OTLP HTTP endpoint and ingestion key. Use `http://` instead of `https://` if your collector does not have TLS configured. For collector setup, see [Ingesting with OpenTelemetry](/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
</Tabs>

## Verify ingestion {#verify-ingestion}

Start your instrumented application and make requests to a server-rendered page or API route. In ClickHouse Observability, select a recent time range and find your application's service name in Traces.

For instrumentation and exporter troubleshooting, see the [Next.js OpenTelemetry documentation](https://nextjs.org/docs/app/guides/open-telemetry).
