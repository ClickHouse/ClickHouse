Use Deno's built-in OpenTelemetry support to send logs, metrics, and traces to ClickHouse Observability. You do not need the ClickStack Node.js SDK or the legacy Deno logging package.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Set up OpenTelemetry {#set-up-opentelemetry}

Follow the official [Deno OpenTelemetry setup instructions](https://docs.deno.com/runtime/fundamentals/open_telemetry/) to instrument your application. Configure the destination below, then enable Deno's built-in integration when starting your application:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

Add the permissions your application needs. Replace any example destinations or console-exporter settings from upstream instructions, including signal-specific endpoint overrides.

## Configure your destination {#configure-destination}

<Tabs>
<Tab title="Fully managed">

<BetaBadge label="Beta offering" />

Open **Team Settings → Data → Managed Telemetry** in your service and copy the **OTLP HTTP endpoint** and **API key**. Use the complete HTTPS endpoint, including its port:

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
<Tab title="Self-managed">

Use your collector's OTLP HTTP endpoint and ingestion key. Use `http://` instead of `https://` if your collector does not have TLS configured. For collector setup, see [Ingesting with OpenTelemetry](/clickstack/observability/ingesting-data/opentelemetry#self-managed).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

</Tab>
</Tabs>

## Verify ingestion {#verify-ingestion}

Start your application and generate activity. In ClickHouse Observability, select a recent time range and find your application's service name in Logs or Traces. Check Metrics after allowing time for export.
