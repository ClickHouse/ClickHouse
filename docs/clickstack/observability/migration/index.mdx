Migrate from Elastic Stack or Datadog to managed or self-configured ClickHouse Observability. The guides cover migration planning, search syntax, and adapting your existing telemetry collection. Where connection details differ, choose the tab for your deployment.

| Technology | Description |
|------------|-------------|
| [Elastic Stack](/clickstack/observability/migration/elastic) | Plan the transition, translate search queries, and migrate data, agents, and application instrumentation |
| [Datadog](/clickstack/observability/migration/datadog) | Configure existing Datadog agents to send telemetry to a managed endpoint or a self-configured Datadog receiver |
