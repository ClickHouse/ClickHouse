<Note>
This guide covers fully managed ClickHouse Observability. For self-managed ClickHouse Observability, see [database administration](/clickstack/self-configured/managing/overview) for sizing, retention, schema tuning, and production guidance, and [configuration options](/clickstack/self-configured/managing/config) for source settings.
</Note>

Use **Team Settings** to manage telemetry access, sources, API and agent connections, integrations, query settings, and team permissions in ClickHouse Observability.

## Administration guides {#admin-guides}

| Guide | What you can do |
| --- | --- |
| [Configuration options](/clickstack/observability/managing/config) | Manage sources and collector access, find telemetry connection details, configure API and agent access, and adjust query settings. |
| [Role-based access control](/clickstack/observability/managing/rbac) | Review built-in roles, create custom roles, and configure permissions for dashboards, saved searches, sources, and other resources. |

## Sending telemetry {#sending-telemetry}

To connect applications and collectors, start with the connection details under **Team Settings → Data → Managed Telemetry**, then follow the [ingestion guides](/clickstack/observability/ingesting-data/overview).
