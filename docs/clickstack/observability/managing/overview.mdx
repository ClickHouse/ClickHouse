Use **Team Settings** to manage sources, find telemetry connection details, adjust query settings, and configure team permissions in ClickHouse Observability.

## Administration guides {#admin-guides}

| Guide | What you can do |
| --- | --- |
| [Configuration options](/clickstack/observability/managing/config) | Enable or disable sources, find managed telemetry connection details, send a test log, and adjust query settings. |
| [Role-based access control](/clickstack/observability/managing/rbac) | Review built-in roles, create custom roles, and configure permissions for dashboards, saved searches, sources, and other resources. |

## Sending telemetry {#sending-telemetry}

To connect applications and collectors, start with the connection details under **Team Settings → Data → Managed Telemetry**, then follow the [ingestion guides](/clickstack/observability/ingesting-data/overview).

For self-configured deployments, see [database administration](/clickstack/self-configured/managing/overview) for sizing, retention, schema tuning, and production guidance.
