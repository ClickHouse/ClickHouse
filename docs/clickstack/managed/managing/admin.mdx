Most administrative tasks in ClickStack involve executing DDL statements on the underlying ClickHouse database.

## ClickHouse Observability {#clickstack-managed}

In ClickHouse Observability, users can also use both the ClickHouse client and [SQL Console](/products/cloud/features/sql-console-features/sql-console). To connect via the client, users will need to obtain the [credentials for the service](/products/cloud/guides/sql-console/connection-details).

The [SQL Console](/products/cloud/features/sql-console-features/sql-console) is a web-based interface that offers additional convenience, including SQL autocomplete, query history, and built-in charting for result visualization.
