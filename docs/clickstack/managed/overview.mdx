**ClickHouse Observability** brings the ClickStack observability experience to ClickHouse Cloud. ClickHouse Cloud operates the database and UI, while you control your ingestion pipeline.

[Get started](/clickstack/getting-started/managed). For the other deployment model, see [ClickStack](/clickstack/overview).

ClickHouse Observability provides a managed observability backend in **ClickHouse Cloud**, using the ClickStack data model and user experience.

In this model, **ClickHouse and the ClickStack UI (HyperDX)** are hosted, operated, and secured by ClickHouse Cloud. When using OpenTelemetry, users operate a collector that sends telemetry data into the managed service.

ClickHouse Observability consists of the following components:

1. **ClickStack UI (HyperDX)**
   The HyperDX UI is fully integrated into ClickHouse Cloud and managed as part of the service. It provides log search, trace exploration, dashboards, alerting, and correlation across telemetry types, with integrated authentication and access control.

2. **OpenTelemetry collector (self-managed)**
   Users run an OpenTelemetry Collector that receives telemetry data from their applications and infrastructure. This collector receives telemetry via OTLP and exports it to ClickHouse Cloud using the ClickHouse exporter. While any standards-compliant OpenTelemetry Collector can be used, we strongly recommend the **ClickStack distribution**, which is preconfigured and optimized for ClickHouse ingestion and works out of the box with ClickStack schemas.

3. **ClickHouse Cloud**
   ClickHouse is fully managed in ClickHouse Cloud, serving as the storage and query engine for all observability data. Users don't need to manage clusters, upgrades, or operational concerns.

ClickHouse Observability provides several key benefits:

- **Automatic scaling of compute independent of storage**
- **Low-cost and effectively unlimited retention** backed by object storage
- **Independent read and write isolation** using ClickHouse Cloud Warehouses
- **Integrated authentication and access control**
- **Automated backups**
- **Security and compliance features**
- **Seamless upgrades with no operational downtime**

This deployment model allows teams to focus entirely on observability workflows and instrumentation, without the overhead of operating ClickHouse or the ClickStack UI themselves.

For users deploying ClickStack in production, ClickHouse Observability is the recommended option. See the [Getting started guide](/clickstack/getting-started/managed) for instructions on deploying ClickStack with ClickHouse Cloud.
