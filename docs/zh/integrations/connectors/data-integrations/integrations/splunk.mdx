[Splunk](https://www.splunk.com/) 是一个数据分析和监控平台。

此附加组件可将 [ClickHouse Cloud 审计日志](/zh/products/cloud/reference/security/audit-logging) 存储到 Splunk 中。它使用 [ClickHouse Cloud API](/zh/products/cloud/features/admin-features/api/api-overview) 下载审计日志。

此附加组件仅包含一个 模块化输入，不提供额外的 UI。

<div id="installation">
  # 安装 {#installation}
</div>

## 适用于 Splunk Enterprise {#for-splunk-enterprise}

从 [Splunkbase](https://splunkbase.splunk.com/app/7709) 下载 ClickHouse Cloud Audit Add-on for Splunk。

<div className="ch-image-lg">
  <Frame>
    ![Splunkbase 网站上 ClickHouse Cloud Audit Add-on for Splunk 的下载页面](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

在 Splunk Enterprise 中，进入 Apps -&gt; Manage，然后点击 Install app from file。

<div className="ch-image-lg">
  <Frame>
    ![Splunk Enterprise 界面中的 Apps 管理页面，显示 Install app from file 选项](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

选择从 Splunkbase 下载的压缩包，然后点击 Upload。

<div className="ch-image-lg">
  <Frame>
    ![用于上传 ClickHouse 附加组件的 Splunk 应用安装对话框](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

如果一切顺利，您现在应该可以看到已安装的 ClickHouse Audit logs 应用程序。否则，请查看 Splunkd 日志，排查是否存在错误。

<div id="modular-input-configuration">
  # 模块化输入配置 {#modular-input-configuration}
</div>

要配置模块化输入，首先需要准备好 ClickHouse Cloud 部署中的以下信息：

* 组织 ID
* 一个 Admin [API 密钥](/zh/products/cloud/features/admin-features/api/openapi)

## 从 ClickHouse Cloud 获取信息 {#getting-information-from-clickhouse-cloud}

登录 [ClickHouse Cloud 控制台](https://console.clickhouse.cloud/)。

进入 Organization -&gt; Organization details，在此处复制组织 ID。

<div className="ch-image-lg">
  <Frame>
    ![显示包含组织 ID 的 Organization details 页面的 ClickHouse Cloud 控制台](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

然后，在左侧菜单中进入 API keys。

<div className="ch-image-lg">
  <Frame>
    ![显示左侧导航菜单中 API keys 部分的 ClickHouse Cloud 控制台](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

创建一个 API 密钥，为其指定一个有意义的名称，并选择 `Admin` 权限。点击 Generate API key。

<div className="ch-image-lg">
  <Frame>
    ![显示已选择 Admin 权限的 API 密钥创建界面的 ClickHouse Cloud 控制台](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

将 API 密钥和密钥妥善保存到安全的地方。

<div className="ch-image-lg">
  <Frame>
    ![显示已生成且需要妥善保存的 API key 和 Secret 的 ClickHouse Cloud 控制台](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

## 在 Splunk 中配置数据输入 {#configure-data-input-in-splunk}

返回 Splunk，依次进入 Settings -&gt; Data inputs。

<div className="ch-image-lg">
  <Frame>
    ![Splunk 界面中的 Settings 菜单及 Data inputs 选项](/images/integrations/tools/data-integration/splunk/splunk_008.webp)
  </Frame>
</div>

选择 ClickHouse Cloud Audit Logs 数据输入。

<div className="ch-image-lg">
  <Frame>
    ![Splunk Data inputs 页面中的 ClickHouse Cloud Audit Logs 选项](/images/integrations/tools/data-integration/splunk/splunk_009.webp)
  </Frame>
</div>

点击 “New”，为该数据输入配置一个新实例。

<div className="ch-image-lg">
  <Frame>
    ![用于配置新的 ClickHouse Cloud Audit Logs 数据输入的 Splunk 界面](/images/integrations/tools/data-integration/splunk/splunk_010.webp)
  </Frame>
</div>

填写完所有信息后，点击 Next。

<div className="ch-image-lg">
  <Frame>
    ![已填写完 ClickHouse 数据输入设置的 Splunk 配置页面](/images/integrations/tools/data-integration/splunk/splunk_011.webp)
  </Frame>
</div>

数据输入已配置完成，现在可以开始浏览审计日志了。

# 用法 {#usage}
