ClickHouse 提供官方 Tableau 连接器，并已在
[Tableau Exchange](https://exchange.tableau.com/products/1064) 上架。
该连接器基于 ClickHouse 的高级 [JDBC 驱动](/zh/integrations/language-clients/java/jdbc)。

借助此连接器，Tableau 可将 ClickHouse 数据库和表作为数据源进行集成。要启用此功能，
请按照下方的设置指南进行操作。

<div id="setup-required-prior-usage">
  ## 使用前的准备工作 {#setup-required-prior-usage}
</div>

1. 准备好连接详细信息
   <ConnectionDetails />

2. 下载并安装 <a href="https://www.tableau.com/products/desktop/download" target="_blank">Tableau
   Desktop</a>。

3. 按照 `clickhouse-tableau-connector-jdbc` 的说明，下载兼容版本的
   <a href="https://github.com/ClickHouse/clickhouse-java/releases/" target="_blank">ClickHouse JDBC 驱动</a>。

<Note>
  请确保下载 [clickhouse-jdbc-X.X.X-all-dependencies.jar](https://github.com/ClickHouse/clickhouse-java/releases) JAR 文件。该制品自版本 `0.9.2` 起提供。
</Note>

4. 将 JDBC 驱动放到以下文件夹中 (根据操作系统选择；如果文件夹不存在，可以自行创建) ：
   * macOS: `~/Library/Tableau/Drivers`
   * Windows: `C:\Program Files\Tableau\Drivers`
5. 在 Tableau 中配置 ClickHouse 数据源，然后开始构建数据可视化！

## 在 Tableau 中配置 ClickHouse 数据源 {#configure-a-clickhouse-data-source-in-tableau}

现在你已经安装并配置好了 `clickhouse-jdbc` 驱动，接下来看看如何在 Tableau 中定义一个数据源，以连接到 ClickHouse 中的 **TPCD** 数据库。

1. 启动 Tableau。 (如果它已经在运行，请先重启。)

2. 在左侧菜单中，点击 **To a Server** 部分下的 **More**。在可用连接器列表中搜索 **ClickHouse by ClickHouse**：

<div className="ch-image-md">
  <Frame>
    ![显示连接器选择菜单且高亮 ClickHouse by ClickHouse 选项的 Tableau 连接界面](/images/integrations/data-visualization/tableau_connecttoserver.webp)
  </Frame>
</div>

<br />

<Note>
  在连接器列表中看不到 **ClickHouse by ClickHouse** 连接器？这可能与 Tableau Desktop 版本过旧有关。
  要解决这个问题，可以考虑升级 Tableau Desktop，或者[手动安装该连接器](#install-the-connector-manually)。
</Note>

3. 点击 **ClickHouse by ClickHouse**，随后会弹出以下对话框：

<div className="ch-image-md">
  <Frame>
    ![显示 ClickHouse JDBC 连接器详细信息和安装按钮的 Tableau 连接器安装对话框](/images/integrations/data-visualization/tableau_connector_details.webp)
  </Frame>
</div>

<br />

4. 点击 **Install and Restart Tableau**。重启应用程序。
5. 重启后，该连接器将显示其完整名称：`ClickHouse JDBC by ClickHouse, Inc.`。点击它后，会弹出以下对话框：

<div className="ch-image-md">
  <Frame>
    ![Tableau 中的 ClickHouse 连接对话框，显示 server、port、数据库、username 和 password 字段](/images/integrations/data-visualization/tableau_connector_dialog.webp)
  </Frame>
</div>

<br />

6. 输入连接详细信息：

   | 设置       | 值                                 |
   | -------- | --------------------------------- |
   | Server   | **你的 ClickHouse 主机名 (不带任何前缀或后缀)** |
   | Port     | **8443**                          |
   | 数据库 | **default**                       |
   | Username | **default**                       |
   | Password | ******                            |

<Note>
  使用 ClickHouse Cloud 时，必须勾选 SSL 复选框以启用安全连接。
</Note>

<br />

<Note>
  我们的 ClickHouse 数据库 名为 **TPCD**，但你必须在上面的对话框中将 **数据库** 设为 **default**，然后
  在下一步中将 **Schema** 选择为 **TPCD**。 (这很可能是连接器中的一个 bug 导致的，因此这种行为
  以后可能会改变，但目前你必须使用 **default** 作为 数据库。)
</Note>

7. 点击 **Sign In** 按钮后，你应该会看到一个新的 Tableau 工作簿：

<div className="ch-image-md">
  <Frame>
    ![显示初始连接界面和数据库选择选项的新 Tableau 工作簿](/images/integrations/data-visualization/tableau_newworkbook.webp)
  </Frame>
</div>

<br />

8. 从 **Schema** 下拉菜单中选择 **TPCD**，你应该会看到 **TPCD** 中的表列表：

<div className="ch-image-md">
  <Frame>
    ![Tableau schema 选择界面，显示 TPCD 数据库中的表，包括 CUSTOMER、LINEITEM、NATION、ORDERS 等](/images/integrations/data-visualization/tableau_tpcdschema.webp)
  </Frame>
</div>

<br />

现在你已经可以在 Tableau 中构建一些可视化了！

## 在 Tableau 中构建可视化 {#building-visualizations-in-tableau}

现在我们已经在 Tableau 中配置好了 ClickHouse 数据源，接下来就对数据进行可视化……

1. 将 **CUSTOMER** 表拖到工作簿中。可以看到列已显示出来，但数据表是空的：

<div className="ch-image-md">
  <Frame>
    ![将 CUSTOMER 表拖到画布后的 Tableau 工作簿，显示列标题但没有数据](/images/integrations/data-visualization/tableau_workbook1.webp)
  </Frame>
</div>

<br />

2. 点击 **Update Now** 按钮，**CUSTOMER** 中的 100 行数据就会填充到表中。

3. 将 **ORDERS** 表拖入工作簿，然后将 **Custkey** 设置为两个表之间的关系字段：

<div className="ch-image-md">
  <Frame>
    ![Tableau 关系编辑器，显示 CUSTOMER 与 ORDERS 表之间通过 Custkey 字段建立的连接](/images/integrations/data-visualization/tableau_workbook2.webp)
  </Frame>
</div>

<br />

4. 现在，**ORDERS** 和 **LINEITEM** 表已作为数据源相互关联，您可以利用
   这一关系来解答与数据相关的问题。选择工作簿底部的 **Sheet 1** 选项卡。

<div className="ch-image-md">
  <Frame>
    ![Tableau 工作表，显示可用于分析的 ClickHouse 表中的维度和度量](/images/integrations/data-visualization/tableau_workbook3.webp)
  </Frame>
</div>

<br />

5. 假设您想了解每年各商品的订购数量。将 **ORDERS** 中的 **OrderDate** 拖入
   **Columns** 区域 (水平字段) ，然后将 **LINEITEM** 中的 **Quantity** 拖入 **Rows**。Tableau 将
   生成以下折线图：

<div className="ch-image-sm">
  <Frame>
    ![Tableau 折线图，显示基于 ClickHouse 数据的按年订购数量](/images/integrations/data-visualization/tableau_workbook4.webp)
  </Frame>
</div>

<br />

这张折线图并不算出彩，因为该数据集由脚本生成，专为测试查询性能而构建，所以
您会发现 TCPD 数据中的模拟订单变化不大。

6. 假设您想按季度和运输方式 (空运、邮寄、海运、
   卡车等) 查看平均订单金额 (以美元计) ：

   * 点击 **New Worksheet** 选项卡，创建一个新工作表
   * 将 **ORDERS** 中的 **OrderDate** 拖入 **Columns**，并将其从 **Year** 改为 **Quarter**
   * 将 **LINEITEM** 中的 **Shipmode** 拖入 **Rows**

您应该会看到如下结果：

<div className="ch-image-sm">
  <Frame>
    ![Tableau 交叉表视图，以季度为列、运输方式为行](/images/integrations/data-visualization/tableau_workbook5.webp)
  </Frame>

<br />

7. 在将指标拖到表上之前，**Abc** 值只是起占位作用。将 *
   *ORDERS** 中的 **Totalprice** 拖到表上。可以看到，默认的计算方式是对 **Totalprices** 求和 (**SUM**) ：

<div className="ch-image-md">

<div className="ch-image-md">
  <Frame>

<div id="install-the-connector-manually">
  ## 手动安装连接器 {#install-the-connector-manually}
</div>

如果您使用的 Tableau Desktop 版本较旧，默认未包含该连接器，可以按照以下步骤手动安装：

1. 从 [Tableau Exchange](https://exchange.tableau.com/products/1064) 下载最新的 taco 文件
2. 将 taco 文件放到以下位置：
   * macOS: `~/Documents/My Tableau Repository/Connectors`
   * Windows: `C:\Users\[Windows User]\Documents\My Tableau Repository\Connectors`
3. 重启 Tableau Desktop。若安装成功，您将在 `New Data Source` 部分看到该连接器。
