## 将 Looker Studio 连接到 ClickHouse {#connecting-looker-studio-to-clickhouse}

首先，使用您的 Google 账户登录 [Looker Studio](https://lookerstudio.google.com)，并创建一个新的数据源：

<div className="ch-image-md">
  <Frame>
    ![在 Looker Studio 界面中创建新的数据源](/images/integrations/data-visualization/looker_studio_01.webp)
  </Frame>
</div>

<br />

搜索 Google 提供的官方 MySQL 连接器 (名称就是 **MySQL**) ：

<div className="ch-image-md">
  <Frame>
    ![在 Looker Studio 连接器列表中搜索 MySQL 连接器](/images/integrations/data-visualization/looker_studio_02.webp)
  </Frame>
</div>

<br />

填写连接详情。请注意，MySQL 接口的默认端口为 9004，
实际端口可能因服务器配置而异。

<div className="ch-image-md">
  <Frame>
    ![在 Looker Studio 中指定 ClickHouse MySQL 连接详情](/images/integrations/data-visualization/looker_studio_03.webp)
  </Frame>
</div>

<br />

接下来，可以通过两种方式从 ClickHouse 拉取数据。第一种是使用 Table Browser 功能：

<div className="ch-image-md">
  <Frame>
    ![在 Looker Studio 中使用 Table Browser 选择 ClickHouse 表](/images/integrations/data-visualization/looker_studio_04.webp)
  </Frame>
</div>

<br />

或者，也可以指定自定义查询来拉取数据：

<div className="ch-image-md">
  <Frame>
    ![在 Looker Studio 中使用自定义 SQL 查询从 ClickHouse 拉取数据](/images/integrations/data-visualization/looker_studio_05.webp)
  </Frame>
</div>

<br />

最后，您将看到内省得到的表结构，并可按需调整数据类型。

<div className="ch-image-md">
  <Frame>
    ![在 Looker Studio 中查看内省得到的 ClickHouse 表结构](/images/integrations/data-visualization/looker_studio_06.webp)
  </Frame>
</div>

<br />

现在，您可以开始探索数据或创建新报表了！

## 在 ClickHouse Cloud 中使用 Looker Studio {#using-looker-studio-with-clickhouse-cloud}

使用 ClickHouse Cloud 时，您需要先启用 MySQL 接口。您可以在连接对话框的 “MySQL” 选项卡中启用它。

<div className="ch-image-md">
  <Frame>
    ![在 ClickHouse Cloud 设置中启用 MySQL 接口](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)
  </Frame>
</div>

<br />

在 Looker Studio UI 中，选择 “Enable SSL” 选项。ClickHouse Cloud 的 SSL 证书由 [Let&#39;s Encrypt](https://letsencrypt.org/certificates/) 签发。您可以在[这里](https://letsencrypt.org/certs/isrgrootx1.pem)下载该根证书。

<div className="ch-image-md">
  <Frame>
    ![带有 ClickHouse Cloud SSL 设置的 Looker Studio 连接配置](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)
  </Frame>
</div>

<br />

其余步骤与上一节所列步骤相同。
