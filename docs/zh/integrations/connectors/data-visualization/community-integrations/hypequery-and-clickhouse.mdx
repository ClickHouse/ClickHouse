[hypequery](https://hypequery.com) 是一个采用 Apache 2.0 许可证的开源语义层，面向在 ClickHouse 上构建嵌入式分析和 AI 智能体的团队。您可以使用 TypeScript 或 Python 定义数据集及其维度、度量、指标、关系和 tenant 规则，然后按名称进行查询。同一套定义还可以对外提供为：带有 OpenAPI 的、经过身份验证的 HTTP 端点，显式指定类型的 React 钩子，以及供 AI 智能体使用的 Model Context Protocol (MCP) 工具。TypeScript SDK 还包含一个 type-safe 的 ClickHouse 查询构建器。

hypequery 既不是托管式 BI 工具，也不是独立的语义层服务器，而是一组随后端一起安装和部署的库，因此您的 ClickHouse 凭证始终保留在您自己的服务器上。它通过 HTTP 接口连接 ClickHouse：在 TypeScript 中使用 [`@clickhouse/client`](/zh/integrations/language-clients/js/index)，在 Python 中使用 [`clickhouse-connect`](/zh/integrations/language-clients/python/index)。

## 前置条件 {#prerequisites}

* 一个 ClickHouse 服务，可以是自管理部署，也可以运行在 [ClickHouse Cloud](/zh/get-started/setup/cloud) 上。
* 使用 TypeScript SDK 需要安装 Node.js；使用 Python SDK 需要安装 Python 3.11 或更高版本。

        ```typescript
          timeKey: 'created_at',
          dimensions: {
            country: dimension.string(),
            status: dimension.string(),

            orderCount: measure.count('id'),
        ```

        ```python
        orders = dataset(
            "orders",
            source="orders",
            tenant_key="tenant_id",
            time_key="created_at",
            dimensions={
                "country": dimension.string(),
                "status": dimension.string(),
                "createdAt": dimension.timestamp(column="created_at"),

            measures={
                "revenue": measure.sum("amount"),
                "orderCount": measure.count("id"),
            },
        )
        ```

  <Step title="查询数据集" id="5-query-a-dataset">
    按名称选择维度和度量。hypequery 会验证请求、生成参数化 SQL，并在 ClickHouse 上执行。由于该数据集声明了 `tenantKey`，每个查询都必须传入调用方的 tenant，hypequery 会自动添加对应的 `WHERE tenant_id = ...` 过滤器。未指定 tenant 的查询会被拒绝：

    <Tabs>
      <Tab title="TypeScript">
        ```typescript
        import { createQueryBuilder } from '@hypequery/clickhouse';
        import { createDatasetClient, eq } from '@hypequery/datasets';
        import { Orders } from './analytics/datasets';

        const db = createQueryBuilder({
          url: process.env.CLICKHOUSE_URL!,
          username: process.env.CLICKHOUSE_USERNAME!,
          password: process.env.CLICKHOUSE_PASSWORD!,
          database: process.env.CLICKHOUSE_DATABASE!,
        });

        const analytics = createDatasetClient({ queryBuilder: db });

        const result = await analytics.execute(Orders, {
          dimensions: ['country'],
          measures: ['revenue', 'orderCount'],
          filters: [eq('status', 'completed')],
          orderBy: [{ field: 'revenue', direction: 'desc' }],
          limit: 10,
        }, {
          runtime: { tenant: 'org_123' },
        });

        console.log(result.data);
        ```
      </Tab>

      <Tab title="Python">
        ```python
        from hypequery.datasets import (
            DatasetQuery,
            ExecutionContext,
            create_dataset_client,
            filter,
            order,
            tenant,
        )
        from hypequery.execution import ClickHouseConnection, create_clickhouse_executor

        analytics = create_dataset_client(
            executor=create_clickhouse_executor(ClickHouseConnection.from_env()),
        )

        result = analytics.execute(
            orders,
            DatasetQuery(
                dimensions=("country",),
                measures=("revenue", "orderCount"),
                filters=(filter.eq("status", "completed"),),
                order_by=(order.desc("revenue"),),
                limit=10,
            ),
            context=ExecutionContext(tenant=tenant("org_123")),
        )

        print(result.data)
        ```
      </Tab>
    </Tabs>

## 为应用程序和智能体提供数据集 {#serve-datasets}

数据集在进程内运行正常后，无需再编写任何 SQL 即可将其对外提供：

* **HTTP 端点**：TypeScript 中的 `@hypequery/serve` 或 Python 中的 `hypequery.serve` 会将每个数据集转换为经过身份验证的端点，并附带输入校验和 OpenAPI 文档。Python API 可挂载到 FastAPI、Django 或 Flask 中。请参阅 [Serve](https://hypequery.com/docs/datasets/serve-integration) 和 [Python serving](https://hypequery.com/docs/python/serving)。
* **React 钩子**：`@hypequery/react` 会为这些端点生成显式指定类型的 TanStack Query 钩子，因此浏览器端代码始终无需持有 ClickHouse 凭证。请参阅 [React](https://hypequery.com/docs/react/getting-started)。
* **面向 AI 智能体的 MCP 工具**：`npx hypequery mcp` 会启动一个 MCP 服务器，让智能体能够发现您的数据集并查询命名指标，而不是直接运行原始 SQL。请参阅 [MCP](https://hypequery.com/docs/mcp/overview)。

所有接入方式都基于同一个数据集定义，因此每种方式都会应用相同的 tenant 范围限定，并返回一致的数值。

## 无需 ClickHouse 服务器即可运行 {#run-without-a-server}

在本地开发和 CI 场景中，hypequery 可以在进程内 ClickHouse 引擎 [chDB](/zh/chdb/index) 上运行相同的数据集，既不需要服务器，也不需要凭证。详见 [在 TypeScript 中使用 chDB](https://hypequery.com/docs/chdb) 和 [在 Python 中使用 chDB](https://hypequery.com/docs/python/datasets/chdb)。
