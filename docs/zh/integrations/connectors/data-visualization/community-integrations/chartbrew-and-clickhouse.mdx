[Chartbrew](https://chartbrew.com) 是一个数据可视化平台，可让您创建仪表盘并实时监控数据。它支持包括 ClickHouse 在内的多种数据源，并提供用于构建图表和报表的无代码界面。

## 目标 {#goal}

在本指南中，你将把 Chartbrew 连接到 ClickHouse，运行 SQL 查询并创建可视化。完成后，你的仪表盘大致会如下所示：

<div className="ch-image-lg">
  <Frame>
    ![Chartbrew 仪表盘](/images/integrations/data-visualization/chartbrew_01.webp)
  </Frame>
</div>

<Tip>
  **添加一些数据**

  如果你还没有可用的数据集，可以添加一个示例数据集。本指南使用 [UK Price Paid](/zh/get-started/sample-datasets/uk-price-paid) 数据集。
</Tip>

<Steps>
  <Step title="准备好连接详情" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="将 Chartbrew 连接到 ClickHouse" id="2-connect-chartbrew-to-clickhouse">
    1. 登录 [Chartbrew](https://chartbrew.com/login)，然后进入 **Connections** 选项卡。

    2. 点击 **Create connection**，然后在可用的数据库选项中选择 **ClickHouse**。

       <div className="ch-image-lg">
         <Frame>
           ![在 Chartbrew 中选择 ClickHouse 连接](/images/integrations/data-visualization/chartbrew_02.webp)
         </Frame>
       </div>

    3. 输入 ClickHouse 数据库的连接详情：

       * **Display Name**：用于在 Chartbrew 中标识该连接的名称。
       * **Host**：ClickHouse 服务器的主机名或 IP 地址。
       * **Port**：HTTPS 连接通常使用 `8443`。
       * **Database Name**：要连接的数据库。
       * **Username**：您的 ClickHouse 用户名。
       * **Password**：您的 ClickHouse 密码。

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew 中的 ClickHouse 连接设置](/images/integrations/data-visualization/chartbrew_03.webp)
         </Frame>
       </div>

    4. 点击 **Test connection**，确认 Chartbrew 能够连接到 ClickHouse。

    5. 测试成功后，点击 **Save connection**。Chartbrew 会自动从 ClickHouse 获取 schema。

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew 中的 ClickHouse JSON schema](/images/integrations/data-visualization/chartbrew_04.webp)
         </Frame>
       </div>
  </Step>

  <Step title="创建数据集并运行 SQL 查询" id="3-create-a-dataset-and-run-a-sql-query">
    1. 点击 **Create dataset** 按钮，或前往 **Datasets** 选项卡创建数据集。
    2. 选择您之前创建的 ClickHouse 连接。

    <div className="ch-image-lg">
      <Frame>
        ![为数据集选择 ClickHouse 连接](/images/integrations/data-visualization/chartbrew_05.webp)
      </Frame>
    </div>

    编写 SQL 查询，检索需要可视化的数据。例如，以下查询基于 `uk_price_paid` 数据集计算每年的平均成交价格：

    ```sql
    SELECT toYear(date) AS year, avg(price) AS avg_price
    FROM uk_price_paid
    GROUP BY year
    ORDER BY year;
    ```

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew 中的 ClickHouse SQL 查询](/images/integrations/data-visualization/chartbrew_07.webp)
      </Frame>
    </div>

    点击 **Run query** 获取数据。

    如果您不确定如何编写查询，可以使用 **Chartbrew 的 AI 助手**，根据数据库 schema 生成 SQL 查询。

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew 中的 ClickHouse AI SQL 助手](/images/integrations/data-visualization/chartbrew_06.webp)
      </Frame>
    </div>

    获取数据后，点击 **Configure dataset** 设置可视化参数。
  </Step>

  <Step title="创建可视化" id="4-create-a-visualization">
    1. 为可视化定义一个指标 (数值) 和一个维度 (分类值) 。
    2. 预览数据集，确保查询结果的结构正确。
    3. 选择图表类型 (例如折线图、条形图、饼图) ，并将其添加到仪表盘中。
    4. 点击 **Complete dataset** 完成设置。

    <div className="ch-image-lg">
      <Frame>
        ![包含 ClickHouse 数据的 Chartbrew 仪表盘](/images/integrations/data-visualization/chartbrew_08.webp)
      </Frame>
    </div>

    您可以按需创建任意数量的数据集，从不同角度对数据进行可视化。基于这些数据集，您还可以创建多个仪表盘，分别跟踪不同的指标。

    <div className="ch-image-lg">
      <Frame>
        ![包含 ClickHouse 数据的 Chartbrew 仪表盘](/images/integrations/data-visualization/chartbrew_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="自动更新数据" id="5-automate-data-updates">
    为使仪表盘始终显示最新数据，您可以为数据设置自动更新调度计划：

    1. 点击数据集刷新按钮旁的日历图标。
    2. 配置更新间隔 (例如每小时、每天) 。
    3. 保存设置，即可启用自动刷新。

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew 数据集刷新设置](/images/integrations/data-visualization/chartbrew_09.webp)
      </Frame>
    </div>
  </Step>
</Steps>
