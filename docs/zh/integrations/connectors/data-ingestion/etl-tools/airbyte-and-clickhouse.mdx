<Note>
  请注意，Airbyte 面向 ClickHouse 的 source 和目标端目前处于 Alpha 状态，不适合移动大型数据集 (&gt; 1000 万行) 。
</Note>

<a href="https://www.airbyte.com/" target="_blank">Airbyte</a> 是一个开源数据集成平台，支持创建 <a href="https://airbyte.com/blog/why-the-future-of-etl-is-not-elt-but-el" target="_blank">ELT</a> 数据管道，并开箱即用地提供 140 多个 connector。本分步教程将介绍如何将 Airbyte 连接到 ClickHouse 作为目标端，并加载一个样本数据集。

<Steps>
  <Step title="下载并运行 Airbyte" id="1-download-and-run-airbyte">
    1. Airbyte 运行在 Docker 上，并使用 `docker-compose`。请务必下载并安装最新版本的 Docker。

    2. 克隆官方 Github 代码仓库，并在您常用的终端中运行 `docker-compose up`，即可部署 Airbyte：

       ```bash
       git clone https://github.com/airbytehq/airbyte.git --depth=1
       cd airbyte
       ./run-ab-platform.sh
       ```

    3. 当终端中出现 Airbyte 横幅后，即可访问 <a href="http://localhost:8000" target="_blank">localhost:8000</a>

       <div className="ch-image-lg">
         <Frame>
           ![Airbyte 横幅](/images/integrations/data-ingestion/etl-tools/airbyte_01.webp)
         </Frame>
       </div>

    <Note>
      此外，您也可以注册并使用 <a href="https://docs.airbyte.com/" target="_blank">Airbyte Cloud</a>
    </Note>
  </Step>

  <Step title="将 ClickHouse 添加为目标端" id="2-add-clickhouse-as-a-destination">
    本节将演示如何将 ClickHouse 实例添加为目标端。

    1. 启动 ClickHouse 服务器 (Airbyte 兼容 ClickHouse `21.8.10.19` 及以上版本) ，或登录您的 ClickHouse Cloud 账户：

       ```bash
       clickhouse-server start
       ```

    2. 在 Airbyte 中，进入 &quot;Destinations&quot; 页面并添加一个新的目标端：

       <div className="ch-image-lg">
         <Frame>
           ![在 Airbyte 中添加目标端](/images/integrations/data-ingestion/etl-tools/airbyte_02.webp)
         </Frame>
       </div>

    3. 从 &quot;Destination type&quot; 下拉列表中选择 ClickHouse，然后填写 &quot;Set up the destination&quot; 表单，包括 ClickHouse 主机名和端口、数据库名称、用户名和密码，并选择是否使用 SSL 连接 (等价于 `clickhouse-client` 中的 `--secure` 命令行选项) ：

       <div className="ch-image-lg">
         <Frame>
           ![在 Airbyte 中创建 ClickHouse 目标端](/images/integrations/data-ingestion/etl-tools/airbyte_03.webp)
         </Frame>
       </div>

    4. 恭喜！您已成功在 Airbyte 中将 ClickHouse 添加为目标端。

    <Note>
      要将 ClickHouse 用作目标端，所使用的用户需要具备创建数据库和表以及插入行的权限。我们建议为 Airbyte 创建一个专用用户 (例如 `my_airbyte_user`) ，并授予以下权限：

      ```sql
      CREATE USER 'my_airbyte_user'@'%' IDENTIFIED BY 'your_password_here';

      GRANT CREATE ON * TO my_airbyte_user;
      ```
    </Note>
  </Step>

  <Step title="将数据集添加为 source" id="3-add-a-dataset-as-a-source">
    本文使用的示例数据集是 <a href="/zh/get-started/sample-datasets/nyc-taxi" target="_blank">纽约市出租车数据</a> (托管于 <a href="https://github.com/toddwschneider/nyc-taxi-data" target="_blank">Github</a>) 。在本教程中，我们将使用该数据集中 2022 年 1 月的数据子集。

    1. 在 Airbyte 中，进入 &quot;Sources&quot; 页面，新建一个类型为 file 的 source。

       <div className="ch-image-lg">
         <Frame>
           ![在 Airbyte 中添加 source](/images/integrations/data-ingestion/etl-tools/airbyte_04.webp)
         </Frame>
       </div>

    2. 填写 &quot;Set up the source&quot; 表单：为 source 命名，并填入 NYC Taxi 2022 年 1 月数据文件的 URL (见下文) 。请务必将文件格式设为 `parquet`，Storage Provider 设为 `HTTPS Public Web`，Dataset Name 设为 `nyc_taxi_2022`。

       ```text
       https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2022-01.parquet
       ```

       <div className="ch-image-lg">
         <Frame>
           ![在 Airbyte 中创建 ClickHouse source](/images/integrations/data-ingestion/etl-tools/airbyte_05.webp)
         </Frame>
       </div>

    3. 恭喜！您已成功在 Airbyte 中添加了一个文件 source。
  </Step>

  <Step title="创建连接并将数据集加载到 ClickHouse" id="4-create-a-connection-and-load-the-dataset-into-clickhouse">
    1. 在 Airbyte 中，打开 &quot;Connections&quot; 页面并添加新连接

    <div className="ch-image-lg">
      <Frame>
        ![在 Airbyte 中添加连接](/images/integrations/data-ingestion/etl-tools/airbyte_06.webp)
      </Frame>
    </div>

    2. 选择 &quot;Use existing source&quot; 并选择 New York City Taxi Data，然后选择 &quot;Use existing destination&quot; 并选择您的 ClickHouse 实例。

    3. 填写 &quot;Set up the connection&quot; 表单：选择复制频率 (本教程使用 `manual`) ，并选择 `nyc_taxi_2022` 作为要同步的 stream。请务必将 Normalization 设置为 `Normalized Tabular Data`。

    <div className="ch-image-lg">
      <Frame>
        ![在 Airbyte 中创建连接](/images/integrations/data-ingestion/etl-tools/airbyte_07.webp)
      </Frame>
    </div>

    4. 连接创建完成后，点击 &quot;Sync now&quot; 触发数据加载 (因为我们将复制频率设置为了 `Manual`)

    <div className="ch-image-lg">
      <Frame>
        ![在 Airbyte 中点击 Sync now 立即同步](/images/integrations/data-ingestion/etl-tools/airbyte_08.webp)
      </Frame>
    </div>

    5. 数据随即开始加载，您可以展开视图查看 Airbyte 日志和进度。操作完成后，日志中会显示 `Completed successfully` 消息：

    <div className="ch-image-lg">
      <Frame>
        ![已成功完成](/images/integrations/data-ingestion/etl-tools/airbyte_09.webp)
      </Frame>
    </div>

    6. 使用您常用的 SQL 客户端连接到 ClickHouse 实例，并查看生成的表：

       ```sql
       SELECT *
       FROM nyc_taxi_2022
       LIMIT 10
       ```
