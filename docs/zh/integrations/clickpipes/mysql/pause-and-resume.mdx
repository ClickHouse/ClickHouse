在某些情况下，暂停 MySQL ClickPipe 会很有用。例如，你可能希望在现有数据保持静止不变的状态下进行一些分析。或者，你可能正在升级 MySQL。下面介绍如何暂停和恢复 MySQL ClickPipe。

<div id="pause-clickpipe-steps">
  ## 暂停 MySQL ClickPipe 的步骤
</div>

1. 在“数据源”选项卡中，点击要暂停的 MySQL ClickPipe。
2. 转到 **Settings** 选项卡。
3. 点击 **暂停** 按钮。

<div className="ch-image-md">

<Frame>

![](/images/integrations/data-ingestion/clickpipes/postgres/pause_button.webp)

</Frame>

</div>

4. 此时会弹出确认对话框。再次点击 **暂停**。

<div className="ch-image-md">

<Frame>

![](/images/integrations/data-ingestion/clickpipes/postgres/pause_dialog.webp)

</Frame>

</div>

4. 转到 **Metrics** 选项卡。
5. 大约 5 秒后 (以及页面刷新后) ，该管道的状态应变为 **暂停**。

<div className="ch-image-md">

<Frame>

![](/images/integrations/data-ingestion/clickpipes/postgres/pause_status.webp)

</Frame>

</div>

<div id="resume-clickpipe-steps">
  ## 恢复 MySQL ClickPipe 的步骤
</div>

1. 在“数据源”选项卡中，点击要恢复的 MySQL ClickPipe。mirror 的状态一开始应为 **暂停**。
2. 转到 **Settings** 选项卡。
3. 点击 **恢复** 按钮。

<div className="ch-image-md">

<Frame>

![](/images/integrations/data-ingestion/clickpipes/postgres/resume_button.webp)

</Frame>

</div>

4. 此时会弹出一个确认对话框。再次点击 **恢复**。

<div className="ch-image-md">

<Frame>

![](/images/integrations/data-ingestion/clickpipes/postgres/resume_dialog.webp)

</Frame>

</div>

5. 转到 **Metrics** 选项卡。
6. 大约 5 秒后 (以及刷新页面后) ，管道的状态应变为 **Running**。
