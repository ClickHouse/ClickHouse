**前置条件**

要按照本指南进行操作，你需要准备：

* 一个 Azure Blob Storage 账户
* [Azure 连接字符串](/zh/integrations/connectors/data-ingestion/azure/azure-data-factory/using-azureblobstorage#acquiring-azure-blob-storage-access-keys)
* 容器名称
* 一个正在运行的 ClickHouse Cloud 服务

<Steps>
  <Step title="进入数据源页面" id="navigate-to-data-sources">
    在服务主页中，点击左侧菜单中的 **数据源**。
    展开 **ClickPipes** 下拉列表，然后点击 **创建 ClickPipe**

    <div className="ch-image-md">
      <Frame>
        ![进入数据源页面](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/01-navigate-to-datasources.webp)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![创建 ClickPipe](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/02-create-clickpipe.webp)
      </Frame>
    </div>
  </Step>

  <Step title="选择数据源" id="select-data-source">
    选择 **Azure Blob Storage** 作为数据类型

    <div className="ch-image-md">
      <Frame>
        ![选择 Azure Blob Storage](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/03-select-blob-storage.webp)
      </Frame>
    </div>
  </Step>

  <Step title="设置 ClickPipe 连接" id="setup-connection">
    1. 为 ClickPipe 指定一个便于识别的名称
    2. 在身份验证方法下拉列表中选择 **连接字符串**
    3. 将 Azure 连接字符串粘贴到 **连接字符串** 字段中
    4. 输入容器名称
    5. 输入 Azure Blob Storage 文件路径；如需摄取多个文件，可使用通配符

    (可选) 启用持续摄取。详情请参阅[“持续摄取”](/zh/integrations/clickpipes/object-storage/azure-blob-storage/overview#continuous-ingestion)。

    最后，点击 **Incoming data**

    <div className="ch-image-md">
      <Frame>
        ![配置详情](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/04-configuration-details.webp)
      </Frame>
    </div>
  </Step>

  <Step title="选择数据格式" id="select-data-format">
    1. 选择文件类型
    2. 选择文件压缩方式 (`detect automatically`、`none`、`gzip`、`brotli`、`xz` 或 `zstd`)
    3. 完成其他格式相关的配置，例如逗号分隔格式所用的分隔符
    4. 点击 **Parse information**

    <div className="ch-image-md">
      <Frame>
        ![选择数据格式](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/05-choose-data-format.webp)
      </Frame>
    </div>
  </Step>

  <Step title="配置表、schema 和设置" id="configure-table-schema">
    接下来，需要新建一个表或选择一个现有表来存储传入的数据。

    1. 选择将数据上传到新表还是现有表
    2. 选择要使用的数据库；如果是新表，还需指定表名
    3. 选择一个或多个排序键
    4. 定义从源文件到目标表的映射，包括列名、列类型、默认值和是否可为空
    5. 最后，指定高级设置，例如要使用的引擎类型、分区表达式和主键

    <div className="ch-image-md">
      <Frame>
        ![解析信息](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/06-parse-information.webp)
      </Frame>
    </div>

    完成表、schema 和设置的配置后，点击 **Details and settings**
  </Step>

  <Step title="配置权限" id="configure-permissions">
    ClickPipes 会创建一个专用数据库用户来写入数据。
    您可以为该用户选择一个角色。
    如果需要从目标表访问物化视图或字典，请选择“Full access”。

    <div className="ch-image-md">
      <Frame>
        ![配置权限](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/07-permissions.webp)
      </Frame>
    </div>
  </Step>

  <Step title="完成设置" id="complete-setup">
    点击 **创建 ClickPipe** 完成设置

    此时，您应能看到 ClickPipe 处于预配状态。
    片刻之后，其状态将从 **预配** 变为 **completed**。
  </Step>
</Steps>
