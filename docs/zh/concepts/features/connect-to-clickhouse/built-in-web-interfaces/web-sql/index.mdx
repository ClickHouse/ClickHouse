Web SQL 界面 (Play) 是 ClickHouse 内置的浏览器查询界面。任何 ClickHouse HTTP 端口都会在 `/play` 路径下提供该界面 (例如 `http://localhost:8123/play`) 。您可以通过它编写和运行查询，以表格或图表形式查看结果，还可以复制查询的 URL 来共享查询。

整个界面都包含在 `programs/server/play.html` 中。这是一个自包含的单页面，直接由 ClickHouse 二进制文件提供，不依赖任何框架，也无需构建步骤。唯一的例外是图表渲染：首次以图表形式显示结果时，系统会从第三方 CDN 惰性加载 `uPlot` 图表库，因此在离线或出站受限的部署环境中无法使用图表。

## 查询选项卡 {#query-tabs}

借助选项卡，您可以同时打开多个查询，而无需在单个编辑器中来回切换，也不必依赖浏览器历史记录。

每个选项卡都有各自独立的查询文本、标题、查询参数和最近一次的结果。连接设置 (URL、用户、密码) 则是全局的，由所有选项卡共享。

### 标签栏何时出现 {#when-the-tab-bar-appears}

运行过查询后，或存在多个选项卡时，标签栏才会出现。如果只有一个且尚无结果的选项卡，页面外观与引入选项卡功能之前完全一致，因此在真正需要之前，标签栏不会显示。

当前选项卡在视觉上与页面融为一体：其背景会跟随各查询对应的哈希颜色 (即页面背景已在使用的颜色) ，并带有渐变效果：在浅色主题下顶部饱和度更高，在深色主题下顶部更亮。非活动选项卡则根据各自查询文本的哈希值着色，因此不同选项卡会自动以颜色区分。

### 创建、关闭和重命名选项卡 {#creating-closing-and-renaming-tabs}

* 点击选项卡右侧的 `[+]` 按钮可新建选项卡。
* 点击选项卡上的 `x` 图标可关闭该选项卡。
* 新选项卡的默认名称依次为 `Query A`、`Query B`，以此类推。
* 点击当前选项卡的标题即可直接内联编辑；编辑框会随文本长度自动扩展。

### 切换选项卡 {#switching-tabs}

* 点击未激活的选项卡即可切换到该选项卡。
* 在选项卡面板上滚动鼠标滚轮也可切换选项卡：向上滚动切换到左侧的选项卡，向下滚动切换到右侧的选项卡 (如有) 。垂直和水平方向的滚轮滚动均支持。

标签栏在水平方向上采用粘性定位：页面水平滚动时，它会始终固定在左侧，与底部的 ClickHouse 徽标相同；而在垂直方向上，它会随页面其余内容一起滚出视野。

### 持久化与浏览器历史记录 {#persistence-and-browser-history}

工作区 (包括各选项卡及其标题、当前活跃选项卡、选项卡顺序以及小型结果快照) 会持久化到 IndexedDB 中，并在重新加载时恢复。持久化采用尽力而为的策略：如果 IndexedDB 不可用，工作区将降级为内存状态，仅在当前会话中保留。

选项卡还与浏览器的 History API 及 URL 相集成：

* 历史记录状态中保存了当前活跃的选项卡，因此可以通过浏览器的后退和前进按钮切换选项卡。
* URL 中会添加 `tab=<name>` 参数。加载页面时，URL 中的查询和 `tab` 参数会与已保存的选项卡进行 reconcile：如果存在同名选项卡，则复用该选项卡 (并替换其中的查询) ；如果未找到该名称或选项卡未命名，则新建选项卡。因此，您可以打开带有新查询的 URL，同时保留自己已保存的选项卡。

## 笔记本模式 {#notebook-mode}

点击结果下方出现的 `[+]` 按钮添加一个单元，即可将选项卡转换为笔记本，即由查询单元和文本单元组成的有序序列。笔记本模式针对每个选项卡单独生效。请参阅
[网页用户界面笔记本模式](/zh/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook)。

### 限制 {#limitations}

切换到其他选项卡后，查询仍会继续运行。其进度和资源指标会在后台持续累计；重新打开该选项卡时，会重新接管这一实时状态，
因此指标会从当前值继续累计，而不会从接近零的位置重新开始。关闭选项卡，或者通过后退/前进导航到
其他历史记录条目，则会停止该查询。

只有较小的结果才会保存快照以供恢复。较大的结果 (超过快照大小上限) 或图像结果不会被持久化：切换选项卡或重新加载后，选项卡会保留其查询，但不会保留已渲染的结果，重新运行该查询即可再次生成结果。这既适用于单个查询的结果，也适用于 “Run all” (多查询) 运行所产生的合并输出。
