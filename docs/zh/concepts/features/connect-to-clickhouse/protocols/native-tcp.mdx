原生协议用于[命令行客户端](/zh/concepts/features/connect-to-clickhouse/native-tools/clickhouse-client)、分布式查询处理过程中的服务器间通信，以及部分语言客户端 (例如 [clickhouse-go](/zh/integrations/go#connection-details)) 。

ClickHouse 为原生协议及其所承载的列式格式提供了官方规范：

* [原生协议](/zh/resources/develop-contribute/native-protocol/protocol) — 数据包帧信息、连接状态机、版本协商，以及所有非 `Block` 消息的请求正文。
* [Native 格式](/zh/resources/develop-contribute/native-protocol/format) — `Block` 与列的结构、各类型的编码，以及压缩帧。该格式也可在 TCP 协议之外使用，例如通过 HTTP 使用 `FORMAT Native`。
