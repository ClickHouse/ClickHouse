ClickHouse 支持 MySQL wire 协议。这样，某些没有原生 ClickHouse 连接器的客户端可以改用 MySQL 协议进行连接。该功能已在以下 BI 工具中通过验证：

* [Looker Studio](/zh/integrations/connectors/data-visualization/looker-studio-and-clickhouse)
* [Tableau Online](/zh/integrations/connectors/data-visualization/tableau/tableau-online-and-clickhouse)
* [QuickSight](/zh/integrations/connectors/data-visualization/quicksight-and-clickhouse)

如果您要尝试其他未经测试的客户端或集成，请注意可能存在以下限制：

* SSL 实现可能不完全兼容，可能会出现 [TLS SNI](https://www.cloudflare.com/learning/ssl/what-is-sni/) 相关问题。
* 某些工具可能需要尚未实现的方言功能 (例如 MySQL 特有的函数或设置) 。

如果有可用的原生驱动程序 (例如 [DBeaver](/zh/integrations/connectors/sql-clients/dbeaver)) ，应始终优先使用原生驱动程序，而非 MySQL 接口。此外，尽管大多数 MySQL 语言客户端都能正常工作，但对于已包含 MySQL 查询的代码库，MySQL 接口并不保证可以无缝直接替换。

如果您的用例涉及某个没有原生 ClickHouse 驱动程序的工具，您希望通过 MySQL 接口使用它，并且发现了某些不兼容问题，请在 ClickHouse 代码仓库中[创建议题](https://github.com/ClickHouse/ClickHouse/issues)。

<Note>
  为了更好地支持上述 BI 工具的 SQL 方言，ClickHouse 的 MySQL 接口在运行 SELECT 查询时会隐式启用设置 [prefer&#95;column&#95;name&#95;to&#95;alias = 1](/zh/reference/settings/session-settings/prefer#prefer_column_name_to_alias)。
  该设置无法关闭，在极少数边缘情况下，同一查询发送到 ClickHouse 普通查询接口和 MySQL 查询接口时，可能会产生不同的行为。
</Note>

## 在 ClickHouse Cloud 中创建多个 MySQL 用户 {#creating-multiple-mysql-users-in-clickhouse-cloud}

默认情况下，系统内置一个 `mysql4<subdomain>` 用户，其密码与 `default` 用户相同。`<subdomain>` 部分是 ClickHouse Cloud 主机名的第一段。之所以采用这种格式，是为了兼容那些实现了安全连接、但未在 [TLS 握手中提供 SNI 信息](https://www.cloudflare.com/learning/ssl/what-is-sni) 的工具。对于这类工具，如果用户名中不包含额外的提示，就无法完成内部路由 (MySQL 控制台客户端就是其中之一) 。

因此，在创建用于 MySQL 接口的新用户时，我们*强烈建议*遵循 `mysql4<subdomain>_<username>` 格式，其中 `<subdomain>` 是用于识别您的云服务的提示，`<username>` 是您自行选择的任意后缀。

<Tip>
  对于类似 `foobar.us-east1.aws.clickhouse.cloud` 的 ClickHouse Cloud 主机名，`<subdomain>` 部分为 `foobar`，自定义 MySQL 用户名可以是 `mysql4foobar_team1`。
</Tip>

例如，如果您需要应用额外的设置，可以另外创建用户来配合 MySQL 接口使用。

1. 可选：创建一个[设置配置文件](/zh/reference/statements/create/settings-profile)，供您的自定义用户使用。例如，创建 `my_custom_profile`，其中包含一项额外设置，当我们使用稍后创建的用户进行连接时，该设置将默认生效：

   ```sql
   CREATE SETTINGS PROFILE my_custom_profile SETTINGS prefer_column_name_to_alias=1;
   ```

   此处的 `prefer_column_name_to_alias` 仅作示例，您也可以使用其他设置。

2. 按以下格式[创建用户](/zh/reference/statements/create/user)：`mysql4<subdomain>_<username>` ([见上文](#creating-multiple-mysql-users-in-clickhouse-cloud)) 。密码必须采用双重 SHA1 格式。例如：

   ```sql
   CREATE USER mysql4foobar_team1 IDENTIFIED WITH double_sha1_password BY 'YourPassword42$';
   ```

   或者，如果您希望为该用户使用自定义 profile：

   ```sql
   CREATE USER mysql4foobar_team1 IDENTIFIED WITH double_sha1_password BY 'YourPassword42$' SETTINGS PROFILE 'my_custom_profile';
   ```

   其中 `my_custom_profile` 是您之前创建的 profile 的名称。

3. 为新用户[授予](/zh/reference/statements/grant)操作目标表或数据库所需的权限。例如，如果您只想授予对 `system.query_log` 的访问权限：

   ```sql
   GRANT SELECT ON system.query_log TO mysql4foobar_team1;
   ```

4. 使用新创建的用户，通过 MySQL 接口连接到您的 ClickHouse Cloud 服务。

### ClickHouse Cloud 中多个 MySQL 用户的故障排查 {#troubleshooting-multiple-mysql-users-in-clickhouse-cloud}

如果您创建了新的 MySQL 用户，并在通过 MySQL 命令行客户端连接时遇到以下错误：

```sql
ERROR 2013 (HY000): Lost connection to MySQL server at 'reading authorization packet', system error: 54
```

在这种情况下，请确保用户名符合 `mysql4<subdomain>_<username>` 格式，如 ([上文](#creating-multiple-mysql-users-in-clickhouse-cloud)) 所述。

## 在自管理 ClickHouse 上启用 MySQL 接口 {#enabling-the-mysql-interface-on-self-managed-clickhouse}

在服务器的配置文件中添加 [mysql&#95;port](/zh/reference/settings/server-settings/settings/mysql#mysql_port) 设置。例如，可以在 `config.d/` [文件夹](/zh/concepts/features/configuration/server-config/configuration-files)中新建一个 XML 文件来定义该端口：

```xml
<clickhouse>
    <mysql_port>9004</mysql_port>
</clickhouse>
```

启动 ClickHouse 服务器，并查找类似下面的日志消息，其中会提示正在监听 MySQL 兼容协议连接：

```bash
{} <Information> Application: Listening for MySQL compatibility protocol: 127.0.0.1:9004
```

## 将 MySQL 连接到 ClickHouse {#connect-mysql-to-clickhouse}

以下命令演示了如何使用 MySQL 客户端 `mysql` 连接到 ClickHouse：

```bash
mysql --protocol tcp -h [hostname] -u [username] -P [port_number] [database_name]
```

例如：

```bash
$ mysql --protocol tcp -h 127.0.0.1 -u default -P 9004 default
```

连接成功时的输出：

```text
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 4
Server version: 20.2.1.1-ClickHouse

Copyright (c) 2000, 2019, Oracle and/or its affiliates. All rights reserved.

Oracle is a registered trademark of Oracle Corporation and/or its
affiliates. Other names may be trademarks of their respective
owners.

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

mysql>
```

为兼容所有 MySQL 客户端，建议在配置文件中使用[双重 SHA1](/zh/concepts/features/configuration/settings/settings-users#user-namepassword) 设置用户密码。
如果使用 [SHA256](/zh/reference/functions/regular-functions/hash-functions#SHA256) 设置用户密码，某些客户端将无法通过身份验证 (包括 mysqljs 以及旧版本的 MySQL 和 MariaDB 命令行工具) 。

限制：

* 不支持预处理查询

* 某些数据类型以字符串形式发送

要取消长时间运行的查询，请使用 `KILL QUERY connection_id` 语句 (处理过程中会将其替换为 `KILL QUERY WHERE query_id = connection_id`) 。例如：

```bash
$ mysql --protocol tcp -h mysql_server -P 9004 default -u default --password=123 -e "KILL QUERY 123456;"
```
