请根据您使用 ClickHouse 的方式，选择最合适的接口。如需开发应用程序，建议首先选用官方语言客户端或驱动程序；如需交互式操作，可使用原生工具或基于 Web 的工具；如需直接集成，请使用网络协议。连接之前，请根据需要配置[网络端口](/zh/concepts/features/security/network-ports)、[访问权限](/zh/concepts/features/security/access-rights)和 [TLS](/zh/concepts/features/security/tls/configuring-tls)。
