ClickHouse ADBC 驱动程序提供符合标准的 [Arrow Database Connectivity (ADBC)](https://arrow.apache.org/adbc/)
接口，用于将兼容 ADBC 的应用程序连接到 ClickHouse。

该驱动程序通过 [HTTP 协议](/zh/concepts/features/connect-to-clickhouse/protocols/http)与 ClickHouse 服务器通信。HTTP 是所有 ClickHouse 部署均支持的主要
协议，因此该驱动程序能够在各种环境中保持一致的行为，包括本地安装、云端 managed service，以及仅支持基于 HTTP 访问的
环境。

该驱动程序的源代码托管于
[adbc&#95;clickhouse GitHub 代码仓库](https://github.com/clickhouse/adbc_clickhouse)。

<Note>
  该驱动程序仍在积极开发中，部分 ADBC 功能可能尚未完全实现。当前版本
  侧重于提供基本的连接能力和核心 ADBC 功能，更多功能将在后续
  发行版中陆续推出。

  您的反馈非常宝贵，将帮助我们确定新功能和改进的优先级。如果您遇到
  限制、功能缺失或异常行为，欢迎通过以下议题跟踪器提交您的反馈或功能请求：
  [github.com/ClickHouse/adbc&#95;clickhouse/issues](https://github.com/ClickHouse/adbc_clickhouse/issues)
</Note>

## 安装 {#installation}

您可以使用 [dbc](https://docs.columnar.tech/dbc/) 安装最新版本的驱动程序：

```bash
dbc install clickhouse
```

此外，您也可以从 [github.com/adbc-drivers/clickhouse/releases](https://github.com/adbc-drivers/clickhouse/releases) 手动下载。

## 数据库选项 {#database-options}

以下数据库选项用于通过 ClickHouse ADBC 驱动程序建立连接。

* `uri`：指定 ClickHouse 服务器的完整 HTTP(S) 端点，包括协议、主机和端口。
* `username`：用于在 ClickHouse 服务器上进行身份验证的用户名。
* `password`：与指定用户名对应的密码。
