[Model Context Protocol](https://www.anthropic.com/news/model-context-protocol) (MCP) 是一项开放标准，可让 AI 助手连接到外部系统。
它为模型访问数据源、API、数据库和工具提供了统一的接口，无需为每一种模型与服务的组合单独构建自定义集成。

AI 应用程序只需实现一次 MCP，即可连接到任何兼容的服务器。
同样，MCP 服务器也可以向任何兼容的客户端开放其功能。

## 架构 {#architecture}

MCP 采用客户端-服务器架构：

* MCP 客户端 (如 Claude Desktop、Cursor 或 VS Code) 与 MCP 服务器建立连接。
* MCP 服务器通过标准化接口对外提供工具和能力。
* AI 模型在需要时调用这些工具，以访问外部数据和功能。

## ClickHouse MCP 服务器 {#clickhouse-mcp-server}

[ClickHouse MCP 服务器](https://github.com/ClickHouse/mcp-clickhouse) 使 AI 助手能够发现 ClickHouse 集群中的数据库和表、查看 schema，并对集群运行 SQL 查询。
该服务器提供的工具可能因版本而异，请参阅相应的集成指南，了解其示例中使用的工具名称。

默认情况下，该服务器仅允许只读查询。
请为助手使用专用的 ClickHouse 用户，并仅授予其所需的权限。

如需连接本地 MCP 客户端，请参阅[设置 ClickHouse MCP 服务器](/zh/guides/use-cases/ai-ml/MCP/claude-desktop)。
如需使用托管的远程服务器，请参阅 [ClickHouse Cloud 中的远程 MCP 服务器](/zh/products/cloud/features/ai-ml/remote-mcp)。
