本页列出了会影响 JOIN 语义、执行计划、执行过程和内存使用的会话设置。每项设置都链接到[会话设置参考文档](/zh/reference/settings/session-settings)中的对应条目，可在其中查看该设置的默认值和可选值。有关 JOIN 的语法和语义，请参阅 [`JOIN` 子句参考文档](/zh/reference/statements/select/join)。

## 语义与语法 {#semantics-and-syntax}

| 设置                                                                                                                                                                                     | 描述                                                                                                          |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/zh/reference/settings/session-settings/join#join_default_strictness)                                                                                         | 设置未显式指定严格性的 JOIN 所采用的默认严格性。                                                                                 |
| [`any_join_distinct_right_table_keys`](/zh/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | 启用 `ANY INNER JOIN` 和 `ANY LEFT JOIN` 的旧版行为。在该行为下，`t1 ANY LEFT JOIN t2` 和 `t2 ANY RIGHT JOIN t1` 可能返回不同的结果。 |
| [`join_any_take_last_row`](/zh/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | 当右表中某个键存在多个匹配行时，决定 `ANY` 严格性的 JOIN 取第一个还是最后一个匹配行。                                                           |
| [`join_use_nulls`](/zh/reference/settings/session-settings/join#join_use_nulls)                                                                                                           | 控制外连接中未匹配行的列是填充默认值还是 `NULL`。                                                                                |
| [`semi_join_include_columns_from_both_sides`](/zh/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | 控制 `SEMI JOIN` 的结果是包含两个表的列，还是仅包含保留表的列。                                                                      |
| [`anti_join_include_columns_from_both_sides`](/zh/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | 控制 `ANTI JOIN` 的结果是包含两个表的列，还是仅包含保留表的列。                                                                      |
| [`cross_to_inner_join_rewrite`](/zh/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | 控制是否将逗号分隔的表列表，或在 `WHERE` 中带有等值条件的 `CROSS JOIN` 重写为 `INNER JOIN`。                                            |
| [`allow_block_nested_loop_join`](/zh/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | 允许将 `ON` 部分不含表间相等条件的 JOIN 以块嵌套循环连接方式执行。                                                                     |
| [`enable_lateral_join`](/zh/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | 启用实验性的 `LATERAL JOIN` 语法，使 JOIN 右侧的子查询能够引用左侧的列。                                                             |
| [`single_join_prefer_left_table`](/zh/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | 在单个 JOIN 中，将两个表之间存在歧义的标识符解析为左表的标识符。                                                                         |
| [`joined_subquery_requires_alias`](/zh/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | 要求 JOIN 中的子查询和表函数必须指定别名。                                                                                    |
| [`allow_dynamic_type_in_join_keys`](/zh/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | 允许使用 `Dynamic` 类型的 JOIN 键。                                                                                  |
| [`analyzer_compatibility_join_using_top_level_identifier`](/zh/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | 根据查询中的同名别名 (例如 `SELECT` 列表中的别名) 解析 `USING` 中的列名。                                                            |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/zh/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | 在包含两个及以上 JOIN 的查询中，沿用旧版 analyzer 的做法，以表名或别名限定结果列名。                                                          |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/zh/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | 与 26.6 之前的版本一样，将 JOIN 最左侧表上的 `FINAL` 修饰符应用于所有参与连接的表。                                                        |

## 算法选择与调优 {#algorithm-selection-and-tuning}

| 设置项                                                                                                                                           | 描述                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| [`join_algorithm`](/zh/reference/settings/session-settings/join#join_algorithm)                                                                  | 按优先级顺序列出 ClickHouse 可使用的 JOIN 算法。                                                                                       |
| [`parallel_hash_join_threshold`](/zh/reference/settings/session-settings/parallel#parallel_hash_join_threshold)                                  | 设置右表预估行数的阈值，达到该值时，哈希 JOIN 会将其哈希表拆分为多个部分，由多个线程并发填充。                                                                      |
| [`hash_join_layout`](/zh/reference/settings/session-settings/other#hash_join_layout)                                                             | 强制哈希 JOIN 在单个线程上构建一个哈希表，或在多个线程上构建拆分的哈希表，用于测试和调试。                                                                        |
| [`max_threads`](/zh/reference/settings/session-settings/max-threads#max_threads)                                                                 | 设置查询处理线程的最大数量，该值同时也限制填充拆分哈希表的线程数。                                                                                       |
| [`grace_hash_join_initial_buckets`](/zh/reference/settings/session-settings/grace-hash#grace_hash_join_initial_buckets)                          | 设置 `grace_hash` JOIN 的初始桶数。                                                                                             |
| [`grace_hash_join_max_buckets`](/zh/reference/settings/session-settings/grace-hash#grace_hash_join_max_buckets)                                  | 限制 `grace_hash` JOIN 的桶数。                                                                                               |
| [`partial_merge_join_rows_in_right_blocks`](/zh/reference/settings/session-settings/partial-merge#partial_merge_join_rows_in_right_blocks)       | 限制 `partial_merge` JOIN 中右表每个已排序块的行数。                                                                                   |
| [`partial_merge_join_left_table_buffer_bytes`](/zh/reference/settings/session-settings/partial-merge#partial_merge_join_left_table_buffer_bytes) | 设置 `partial_merge` JOIN 将左表的块合并为更大块时的大小上限。                                                                              |
| [`join_on_disk_max_files_to_merge`](/zh/reference/settings/session-settings/join#join_on_disk_max_files_to_merge)                                | 限制 merge JOIN 在磁盘上执行时并行排序的文件数。                                                                                          |
| [`max_rows_in_set_to_optimize_join`](/zh/reference/settings/session-settings/max-rows#max_rows_in_set_to_optimize_join)                          | 设置键集合的最大大小。在连接之前，该集合用于按一侧输入的键过滤 JOIN 的另一侧输入。                                                                            |
| [`query_plan_join_shard_by_pk_ranges`](/zh/reference/settings/session-settings/query-plan#query_plan_join_shard_by_pk_ranges)                    | 当 JOIN 键包含两个 `MergeTree` 表主键的前缀时，将这两个表的 JOIN 按主键范围拆分为多个独立的 JOIN 执行。                                                     |
| [`join_output_by_rowlist_perkey_rows_threshold`](/zh/reference/settings/session-settings/join#join_output_by_rowlist_perkey_rows_threshold)      | 设置右表中每个键平均行数的阈值，达到该值时，哈希 JOIN 按行列表输出匹配项。                                                                                |
| [`allow_join_right_table_sorting`](/zh/reference/settings/session-settings/allow#allow_join_right_table_sorting)                                 | 在满足 `join_to_sort_minimum_perkey_rows` 和 `join_to_sort_maximum_table_rows` 条件时，允许在 `LEFT` 或 `INNER` 哈希 JOIN 中按键对右表重新排序。 |
| [`join_to_sort_minimum_perkey_rows`](/zh/reference/settings/session-settings/join-to#join_to_sort_minimum_perkey_rows)                           | 设置按键对右表重新排序所需的右表每键最小平均行数。                                                                                               |
| [`join_to_sort_maximum_table_rows`](/zh/reference/settings/session-settings/join-to#join_to_sort_maximum_table_rows)                             | 设置允许按键对右表重新排序的右表最大行数。                                                                                                   |
| [`enable_hash_join_row_store`](/zh/reference/settings/session-settings/enable#enable_hash_join_row_store)                                        | 启用将哈希 JOIN 的载荷转换为行优先布局。                                                                                                 |
| [`min_rows_ratio_for_hash_join_row_store`](/zh/reference/settings/session-settings/min#min_rows_ratio_for_hash_join_row_store)                   | 设置输出行数与构建端行数之间的最小预估比率，达到该值时，哈希 JOIN 的载荷会转换为行优先布局。                                                                       |
| [`enable_join_fixed_hash_table_conversion`](/zh/reference/settings/session-settings/enable-join#enable_join_fixed_hash_table_conversion)         | 当键为取值范围较小的单个整数时，启用将 JOIN 的哈希表转换为扁平数组。                                                                                   |
| [`enable_join_key_only_hash_tables`](/zh/reference/settings/session-settings/enable-join#enable_join_key_only_hash_tables)                       | 针对 `LEFT ANTI` JOIN 以及不选择右表任何列的 `LEFT SEMI` JOIN，启用仅存储 JOIN 键的哈希表。                                                      |
| [`enable_software_prefetch_in_join`](/zh/reference/settings/session-settings/enable-software#enable_software_prefetch_in_join)                   | 在哈希 JOIN 的探测阶段启用软件预取。                                                                                                   |
| [`enable_packed_string_keys_in_hash_join`](/zh/reference/settings/session-settings/enable#enable_packed_string_keys_in_hash_join)                | 在哈希表中以 16 字节存储每个键，从而加快基于单个 `String` 键的哈希 JOIN，并降低其内存占用。                                                                 |
| [`min_rows_for_packed_string_keys_in_hash_join`](/zh/reference/settings/session-settings/min#min_rows_for_packed_string_keys_in_hash_join)       | 设置右表预估行数的阈值，低于该值时，哈希 JOIN 保留精确的 `String` 键，而不使用打包式键。                                                                    |
| [`collect_hash_table_stats_during_joins`](/zh/reference/settings/session-settings/collect-hash#collect_hash_table_stats_during_joins)            | 启用哈希表统计信息收集，同一 JOIN 后续执行时会据此确定哈希表的大小。                                                                                   |
| [`max_size_to_preallocate_for_joins`](/zh/reference/settings/session-settings/max-size#max_size_to_preallocate_for_joins)                        | 限制 JOIN 哈希表中预分配空间的元素总数。                                                                                                 |
| [`max_joined_block_size_rows`](/zh/reference/settings/session-settings/max-joined#max_joined_block_size_rows)                                    | 限制 JOIN 结果中每个块的行数。                                                                                                      |
| [`max_joined_block_size_bytes`](/zh/reference/settings/session-settings/max-joined#max_joined_block_size_bytes)                                  | 限制 JOIN 结果中每个块的字节数。                                                                                                     |
| [`min_joined_block_size_rows`](/zh/reference/settings/session-settings/min-joined#min_joined_block_size_rows)                                    | 设置行数阈值，低于该值时，JOIN 的输入块和输出块会合并为更大的块。                                                                                     |
| [`min_joined_block_size_bytes`](/zh/reference/settings/session-settings/min-joined#min_joined_block_size_bytes)                                  | 设置字节数阈值，低于该值时，JOIN 的输入块和输出块会合并为更大的块。                                                                                    |
| [`joined_block_split_single_row`](/zh/reference/settings/session-settings/joined#joined_block_split_single_row)                                  | 当左表的单行存在大量匹配项时，允许将该行的哈希 JOIN 结果拆分为多个块。                                                                                  |
| [`parallel_non_joined_rows_processing`](/zh/reference/settings/session-settings/parallel#parallel_non_joined_rows_processing)                    | 在 `RIGHT` 或 `FULL` JOIN 中，允许多个线程输出右表中未匹配的行。                                                                             |
| [`enable_lazy_columns_replication`](/zh/reference/settings/session-settings/enable#enable_lazy_columns_replication)                              | 启用对 JOIN 结果中列的惰性复制，避免在内存中多次复制相同的行。                                                                                      |

## 查询规划器 {#query-planner}

| 设置项                                                                                                                                                                             | 描述                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [`query_plan_join_swap_table`](/zh/reference/settings/session-settings/query-plan#query_plan_join_swap_table)                                                                      | 控制查询规划器将 JOIN 的哪个输入用作构建侧。                                                          |
| [`query_plan_optimize_join_order_limit`](/zh/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_limit)                                                  | 设置查询规划器优化 JOIN 顺序时，单个子查询中所允许的最大表数量。                                                |
| [`query_plan_optimize_join_order_algorithm`](/zh/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_algorithm)                                          | 列出查询规划器依次尝试的连接顺序算法。                                                                |
| [`query_plan_optimize_join_order_conflict_detector`](/zh/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_conflict_detector)                          | 选择冲突检测器，`dpsub` 连接顺序算法借助它判断哪些重排序有效。                                                |
| [`query_plan_optimize_join_order_max_searched_plans`](/zh/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_max_searched_plans)                        | 限制连接顺序优化器在回退到下一个算法之前所枚举的部分执行计划数量。                                                  |
| [`use_statistics`](/zh/reference/settings/session-settings/use-statistics#use_statistics)                                                                                          | 允许优化器使用列统计信息，包括用于 JOIN 重排序和构建侧选择的估算。                                               |
| [`allow_statistics`](/zh/reference/settings/session-settings/allow-statistics#allow_statistics)                                                                                    | 允许定义带统计信息的列以及操作统计信息。                                                               |
| [`materialize_statistics_on_insert`](/zh/reference/settings/session-settings/materialize-statistics-on-insert#materialize_statistics_on_insert)                                    | 控制是否为新插入的数据部分构建列统计信息。                                                              |
| [`use_hash_table_stats_for_join_reordering`](/zh/reference/settings/session-settings/use#use_hash_table_stats_for_join_reordering)                                                 | 启用在 JOIN 重排序期间利用已收集的哈希表统计信息进行基数估算。                                                 |
| [`use_datalake_metadata_statistics`](/zh/reference/settings/session-settings/use)                                                                                                  | 启用基于表元数据中的统计信息估算数据湖读取量 (仅限 Iceberg) ，供 JOIN 重排序使用。                                 |
| [`allow_general_join_planning`](/zh/reference/settings/session-settings/allow#allow_general_join_planning)                                                                         | 允许使用更通用的 JOIN 规划算法，该算法可处理更复杂的条件，仅适用于哈希 JOIN。                                       |
| [`query_plan_filter_push_down`](/zh/reference/settings/session-settings/query-plan#query_plan_filter_push_down)                                                                    | 启用在执行计划中下推过滤器，包括下推到 JOIN 之下。                                                       |
| [`query_plan_convert_outer_join_to_inner_join`](/zh/reference/settings/session-settings/query-plan#query_plan_convert_outer_join_to_inner_join)                                    | 当 JOIN 之后的过滤器总会移除未匹配行的默认值时，允许将 `OUTER JOIN` 转换为 `INNER JOIN`。                      |
| [`query_plan_convert_outer_join_to_inner_join_transitively`](/zh/reference/settings/session-settings/query-plan#query_plan_convert_outer_join_to_inner_join_transitively)          | 将 `query_plan_convert_outer_join_to_inner_join` 的作用范围扩展到执行计划中更上层的过滤器以及外层 JOIN 的条件。 |
| [`query_plan_convert_any_join_to_semi_or_anti_join`](/zh/reference/settings/session-settings/query-plan#query_plan_convert_any_join_to_semi_or_anti_join)                          | 当 JOIN 之后的过滤器总会拒绝未匹配的行或已匹配的行时，允许将 `ANY JOIN` 转换为 `SEMI JOIN` 或 `ANTI JOIN`。        |
| [`query_plan_convert_join_to_in`](/zh/reference/settings/session-settings/query-plan#query_plan_convert_join_to_in)                                                                | 当输出列仅来自左表时，允许将 JOIN 转换为使用 `IN` 的子查询。                                               |
| [`rewrite_in_to_join`](/zh/reference/settings/session-settings/rewrite#rewrite_in_to_join)                                                                                         | 将 `x IN subquery` 形式的表达式重写为 JOIN。                                                  |
| [`query_plan_merge_filter_into_join_condition`](/zh/reference/settings/session-settings/query-plan#query_plan_merge_filter_into_join_condition)                                    | 允许将过滤器合并到 JOIN 条件中，并将 `CROSS JOIN` 转换为 `INNER JOIN`。                               |
| [`query_plan_merge_expression_into_join`](/zh/reference/settings/session-settings/query-plan#query_plan_merge_expression_into_join)                                                | 允许在 JOIN 重排序期间将表达式合并到 JOIN 步骤中。                                                    |
| [`query_plan_short_circuit_constant_false_join`](/zh/reference/settings/session-settings/query-plan#query_plan_short_circuit_constant_false_join)                                  | 当 `ON` 条件折叠为常量 false 时，将 JOIN 中每个无法产生行的输入替换为空数据源。                                  |
| [`query_plan_read_in_order_through_join`](/zh/reference/settings/session-settings/query-plan#query_plan_read_in_order_through_join)                                                | 穿过 JOIN 时仍保持按顺序读取左表，以便后续步骤利用该顺序。                                                   |
| [`query_plan_top_k_through_join`](/zh/reference/settings/session-settings/query-plan#query_plan_top_k_through_join)                                                                | 当排序键仅引用保留侧的列时，将 `ORDER BY ... LIMIT n` 下推到 `LEFT` 或 `RIGHT` JOIN 之下。               |
| [`query_plan_propagate_predicate_across_join`](/zh/reference/settings/session-settings/query-plan#query_plan_propagate_predicate_across_join)                                      | 通过 JOIN 键将过滤条件从等值 JOIN 的一侧复制到另一侧。                                                  |
| [`enable_join_transitive_predicates`](/zh/reference/settings/session-settings/enable-join#enable_join_transitive_predicates)                                                       | 根据现有 JOIN 条件推导传递性等值条件，供连接顺序优化器使用。                                                  |
| [`use_join_disjunctions_push_down`](/zh/reference/settings/session-settings/use#use_join_disjunctions_push_down)                                                                   | 启用将 JOIN 条件中由 `OR` 连接的部分下推到相应的输入。                                                  |
| [`query_plan_lazy_materialization_for_join`](/zh/reference/settings/session-settings/query-plan#query_plan_lazy_materialization_for_join)                                          | 为包含 JOIN 的 `LIMIT n` 查询启用惰性物化，仅为 `LIMIT` 之后保留的行读取列。                                |
| [`query_plan_max_limit_for_join_lazy_indexing`](/zh/reference/settings/session-settings/query-plan#query_plan_max_limit_for_join_lazy_indexing)                                    | 设置启用 JOIN 惰性索引优化的最大 `LIMIT` 值。                                                     |
| [`query_plan_min_columns_for_join_lazy_indexing`](/zh/reference/settings/session-settings/query-plan#query_plan_min_columns_for_join_lazy_indexing)                                | 设置启用 JOIN 惰性索引优化所需的左侧负载列最小数量。                                                      |
| [`enable_join_runtime_filters`](/zh/reference/settings/session-settings/enable-join#enable_join_runtime_filters)                                                                   | 启用在运行时利用从构建侧收集的 JOIN 键集合过滤 JOIN 的探测侧。                                              |
| [`enable_join_runtime_filters_index_analysis`](/zh/reference/settings/session-settings/enable-join#enable_join_runtime_filters_index_analysis)                                     | 启用利用运行时过滤器裁剪 JOIN 探测侧的 granule。                                                    |
| [`enable_join_seal_gated_reading`](/zh/reference/settings/session-settings/enable-join#enable_join_seal_gated_reading)                                                             | 延迟读取哈希 JOIN 的探测侧，直到构建侧的运行时过滤器构建完成。                                                 |
| [`join_runtime_filter_exact_values_limit`](/zh/reference/settings/session-settings/join-runtime#join_runtime_filter_exact_values_limit)                                            | 设置 JOIN 运行时过滤器以集合形式存储值的最大数量，超过该数量后将切换为布隆过滤器。                                       |
| [`join_runtime_bloom_filter_bytes`](/zh/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_bytes)                                                          | 设置用作 JOIN 运行时过滤器的布隆过滤器大小 (以字节为单位) 。                                                |
| [`join_runtime_bloom_filter_hash_functions`](/zh/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_hash_functions)                                        | 设置用作 JOIN 运行时过滤器的布隆过滤器所使用的哈希函数数量。                                                  |
| [`join_runtime_bloom_filter_max_ratio_of_set_bits`](/zh/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_max_ratio_of_set_bits)                          | 设置置位比率的阈值，超过该阈值时将禁用运行时布隆过滤器。                                                       |
| [`join_runtime_filter_from_fixed_hash_table`](/zh/reference/settings/session-settings/join-runtime#join_runtime_filter_from_fixed_hash_table)                                      | 将已转换为扁平数组的哈希表直接用作 JOIN 运行时过滤器。                                                     |
| [`join_runtime_filter_size_from_hash_table_stats`](/zh/reference/settings/session-settings/join-runtime#join_runtime_filter_size_from_hash_table_stats)                            | 根据先前执行中收集的哈希表统计信息来确定 JOIN 运行时过滤器的大小。                                               |
| [`join_runtime_filter_min_probe_rows`](/zh/reference/settings/session-settings/join-runtime#join_runtime_filter_min_probe_rows)                                                    | 设置探测侧预估行数的阈值，预估行数小于或等于该值时不创建 JOIN 运行时过滤器。                                          |
| [`join_runtime_filter_pass_ratio_threshold_for_disabling`](/zh/reference/settings/session-settings/join-runtime#join_runtime_filter_pass_ratio_threshold_for_disabling)            | 设置通过行数与检查行数之比的阈值，超过该阈值时将暂时禁用 JOIN 运行时过滤器。                                          |
| [`join_runtime_filter_blocks_to_skip_before_reenabling`](/zh/reference/settings/session-settings/join-runtime#join_runtime_filter_blocks_to_skip_before_reenabling)                | 设置暂时禁用的 JOIN 运行时过滤器在处理多少个块之后重新尝试启用。                                                |
| [`correlated_subqueries_default_join_kind`](/zh/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_default_join_kind)                                 | 控制关联子查询的去关联计划 (包含 `LATERAL JOIN`) 使用 `LEFT` JOIN 还是 `RIGHT` JOIN。                  |
| [`correlated_subqueries_substitute_equivalent_expressions`](/zh/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_substitute_equivalent_expressions) | 对关联子查询进行去关联时，允许用从过滤器推导出的等价表达式进行替换，而不是创建 `CROSS JOIN`。                              |
| [`correlated_subqueries_use_in_memory_buffer`](/zh/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_use_in_memory_buffer)                           | 为关联子查询 (包含 `LATERAL JOIN`) 的输入使用内存中缓冲区，以避免重复计算输入。                                  |

## 内存限制与溢写 {#memory-limits-and-spilling}

| 设置项                                                                                                                               | 描述                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| [`max_rows_in_join`](/zh/reference/settings/session-settings/max-rows#max_rows_in_join)                                              | 限制 JOIN 右表数据结构中的行数。                                                          |
| [`max_bytes_in_join`](/zh/reference/settings/session-settings/max-bytes#max_bytes_in_join)                                           | 限制 JOIN 右表数据结构的大小 (以字节为单位) 。                                                 |
| [`join_overflow_mode`](/zh/reference/settings/session-settings/join#join_overflow_mode)                                              | 定义 JOIN 达到 `max_rows_in_join` 或 `max_bytes_in_join` 时所执行的操作。                 |
| [`default_max_bytes_in_join`](/zh/reference/settings/session-settings/default#default_max_bytes_in_join)                             | 在需要限制但未设置 `max_bytes_in_join` 时，设置右表的最大大小。                                   |
| [`max_bytes_before_external_join`](/zh/reference/settings/session-settings/max-bytes#max_bytes_before_external_join)                 | 设置基于哈希的 JOIN 在右表大小 (以字节为单位) 达到多少时落盘。                                         |
| [`max_bytes_ratio_before_external_join`](/zh/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_join)     | 以占可用内存的比率设置基于哈希的 JOIN 的落盘阈值。                                                 |
| [`enable_adaptive_memory_spill_scheduler`](/zh/reference/settings/session-settings/enable#enable_adaptive_memory_spill_scheduler)    | 启用后，当查询面临内存压力时，将符合条件的处理器 (包括支持溢写的 JOIN) 溢写到磁盘。                               |
| [`legacy_join_size_limits_trigger_spilling`](/zh/reference/settings/session-settings/other#legacy_join_size_limits_trigger_spilling) | 恢复旧版行为：`max_rows_in_join` 和 `max_bytes_in_join` 会使 JOIN 中磁盘上的部分继续落盘，而不是终止查询。 |
| [`max_bytes_before_external_sort`](/zh/reference/settings/session-settings/max-bytes#max_bytes_before_external_sort)                 | 设置排序 (包括 `full_sorting_merge` JOIN 中的排序) 在内存使用量达到多少时落盘。                      |
| [`max_bytes_ratio_before_external_sort`](/zh/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_sort)     | 设置排序 (包括 `full_sorting_merge` JOIN 中的排序) 在内存使用量占可用内存的比率达到多少时落盘。              |
| [`cross_join_min_rows_to_compress`](/zh/reference/settings/session-settings/cross-join#cross_join_min_rows_to_compress)              | 设置 `CROSS JOIN` 或块嵌套循环连接的块在行数达到多少时于内存中压缩。                                    |
| [`cross_join_min_bytes_to_compress`](/zh/reference/settings/session-settings/cross-join#cross_join_min_bytes_to_compress)            | 设置 `CROSS JOIN` 或块嵌套循环连接的块在大小 (以字节为单位) 达到多少时于内存中压缩。                          |
| [`temporary_files_codec`](/zh/reference/settings/session-settings/temporary-files#temporary_files_codec)                             | 设置排序和 JOIN 操作写入磁盘的临时文件所使用的压缩编解码器。                                            |

## 分布式 JOIN {#distributed-joins}

| 设置项                                                                                                                                                               | 描述                                                              |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| [`distributed_product_mode`](/zh/reference/settings/session-settings/distributed#distributed_product_mode)                                                           | 控制在针对分布式表的查询中，ClickHouse 如何执行其中涉及分布式表的 `IN` 和 JOIN 子查询。         |
| [`prefer_global_in_and_join`](/zh/reference/settings/session-settings/prefer#prefer_global_in_and_join)                                                              | 启用后，将 `IN` 和 JOIN 替换为 `GLOBAL IN` 和 `GLOBAL JOIN`。              |
| [`max_rows_to_transfer`](/zh/reference/settings/session-settings/max-rows#max_rows_to_transfer)                                                                      | 限制 `GLOBAL IN` 或 `GLOBAL JOIN` 传递给远程服务器或保存到临时表中的行数。             |
| [`max_bytes_to_transfer`](/zh/reference/settings/session-settings/max-bytes#max_bytes_to_transfer)                                                                   | 限制 `GLOBAL IN` 或 `GLOBAL JOIN` 传递给远程服务器或保存到临时表中的未压缩字节数。         |
| [`transfer_overflow_mode`](/zh/reference/settings/session-settings/other#transfer_overflow_mode)                                                                     | 定义达到 `max_rows_to_transfer` 或 `max_bytes_to_transfer` 限制时执行的操作。 |
| [`parallel_replicas_for_queries_with_multiple_tables`](/zh/reference/settings/session-settings/parallel-replicas#parallel_replicas_for_queries_with_multiple_tables) | 允许对包含 JOIN 的查询使用并行副本。                                           |
| [`parallel_replicas_prefer_local_join`](/zh/reference/settings/session-settings/parallel-replicas#parallel_replicas_prefer_local_join)                               | 使用并行副本时，如果每个副本都能自行读取 JOIN 的物化侧，则使用本地 JOIN 而非 `GLOBAL JOIN`。     |
| [`distributed_plan_default_shuffle_join_bucket_count`](/zh/reference/settings/session-settings/distributed-plan#distributed_plan_default_shuffle_join_bucket_count)  | 设置基于规则的分布式查询计划器中数据重分布哈希 JOIN 的默认桶数。                             |
| [`distributed_plan_join_runtime_filters`](/zh/reference/settings/session-settings/distributed-plan#distributed_plan_join_runtime_filters)                            | 将 JOIN 运行时过滤器发送到分布式查询计划中读取探测侧的阶段。                               |
| [`distributed_plan_max_rows_to_broadcast`](/zh/reference/settings/session-settings/distributed-plan#distributed_plan_max_rows_to_broadcast)                          | 设置最大行数阈值：行数不超过该值时，基于规则的分布式查询计划器使用广播 JOIN 而非数据重分布 JOIN。          |
