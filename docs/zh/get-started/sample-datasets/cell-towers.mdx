## 使用蜂窝基站数据集进行地理空间分析 {#geospatial-analysis-with-cell-towers}

本指南将 `OpenCelliD` 蜂窝基站数据加载到 `ClickHouse Cloud`，通过国家字典扩充数据，查询德国境内的基站，并使用 `ClickHouse Agents` 进行可视化。

<Steps>
  <Step title="加载示例数据">
    在 `ClickHouse Cloud` 中打开 **Load data**，从 **Sample data** 选择 **Cell Towers** 并加载数据集。`cell_towers` 的每一行都是一个基站，`lon` 和 `lat` 是其坐标。

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="查询并扩充基站数据">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;

    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="使用地理数据">
    `ClickHouse` 提供 [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon) 等函数。创建 `germany`，插入[英文指南](/get-started/sample-datasets/cell-towers#germany-polygon)中的德国本土边界，然后统计多边形内的基站：

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    结果约为 `2.62 million`。
  </Step>
  <Step title="可选：使用 ClickHouse Agents 可视化数据">
    这是一个可选的运行示例：`ClickHouse Agents` 是模型驱动的 Beta 功能，因此其计划、所用工具和输出可能因运行而异。打开 **ClickHouse agents**，发送："Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables"。

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="创建德国基站密度网格的 ClickHouse Agent 对话"/>

    在一次运行中，Agent 找到了德国 MCC、统计了基站、将它们归入 `0.1°` 网格，并在地图上绘制了边界。

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="德国蜂窝基站密度热力图"/>
  </Step>
</Steps>
