### 使用 SQL 控制台添加数据 {#add-data-using-the-sql-console}

        与大多数数据库管理系统一样，ClickHouse 在逻辑上将表组织到**数据库**中。可使用 [`CREATE DATABASE`](/zh/reference/statements/create/database) 命令在 ClickHouse 中创建新数据库：

        ```sql
        CREATE DATABASE IF NOT EXISTS helloworld
        ```

        运行以下命令，在 `helloworld` 数据库中创建名为 `my_first_table` 的表：

        ```sql
        CREATE TABLE helloworld.my_first_table
        (
            user_id UInt32,
            message String,
            timestamp DateTime,
            metric Float32
        )
        ENGINE = MergeTree()
        PRIMARY KEY (user_id, timestamp)
        ```

        在上述示例中，`my_first_table` 是一个包含四列的 [`MergeTree`](/zh/reference/engines/table-engines/mergetree-family/mergetree) 表：

        * `user_id`：32 位无符号整数 ([UInt32](/zh/reference/data-types/int-uint))
        * `message`：[String](/zh/reference/data-types/string) 数据类型，用于替代其他数据库系统中的 `VARCHAR`、`BLOB`、`CLOB` 等类型
        * `timestamp`：[DateTime](/zh/reference/data-types/datetime) 值，表示某一时间点
        * `metric`：32 位浮点数 ([Float32](/zh/reference/data-types/float))

        <Info>
          **表引擎**

          表引擎决定了：

          * 数据的存储方式和存储位置
          * 支持哪些查询
          * 数据是否以副本形式存储

          <br />

          可供选择的表引擎有很多，但对于单节点 ClickHouse 服务器上的简单表，[`MergeTree`](/zh/reference/engines/table-engines/mergetree-family/mergetree) 通常是您的首选。
        </Info>

#### 主键简介 {#a-brief-intro-to-primary-keys}

        在继续之前，务必先了解 ClickHouse 中主键的工作原理 (主键的实现方式
        可能会出乎您的意料！) ：

        * ClickHouse 中的主键对于表中的每一行而&#x8A00;***并不唯一***

        ClickHouse 表的主键决定了数据写入磁盘时的排序方式。每 8,192 行或 10MB
        数据 (称为**索引粒度**) 会在主键索引文件中生成一个条目。基于这种粒度机制
        形成的**稀疏索引**可以轻松放入内存，而每个粒度代表 `SELECT` 查询期间所处理的
        最小列数据条带。

        可以使用 `PRIMARY KEY` 参数定义主键。如果定义表时未指定 `PRIMARY KEY`，
        则主键默认为 `ORDER BY` 子句中指定的元组。如果同时指定了 `PRIMARY KEY` 和 `ORDER BY`，则主键必须是排序顺序的子集。

        主键同时也是 sorting key，即元组 `(user_id, timestamp)`。因此，每个
        列文件中存储的数据都会先按 `user_id` 排序，再按 `timestamp` 排序。

        如需深入了解 ClickHouse 的核心概念，请参阅[“核心概念”](/zh/concepts/core-concepts/index)。

#### 向表中插入数据 {#insert-data-into-your-table}

        在 ClickHouse 中，您可以使用熟悉的 [`INSERT INTO TABLE`](/zh/reference/statements/insert-into) 命令，但需要注意的是，每次向 [`MergeTree`](/zh/reference/engines/table-engines/mergetree-family/mergetree) 表执行插入操作时，都会在存储中创建一个 **part** (数据分片) 。

        <Tip>
          **ClickHouse 最佳实践**

          每个批次应插入大量行，一次插入数万甚至数百万
          行。不必担心，ClickHouse 能够轻松应对这种数据量，而且由于向您的服务发送的写入请求更少，还能[为您节省成本](/zh/concepts/best-practices/selecting-an-insert-strategy#batch-inserts-if-synchronous)。
        </Tip>

        <br />

        即使只是一个简单的示例，我们也一次插入多行数据：

        ```sql
        INSERT INTO helloworld.my_first_table (user_id, message, timestamp, metric) VALUES
            (101, 'Hello, ClickHouse!',                                 now(),       -1.0    ),
            (102, 'Insert a lot of rows per batch',                     yesterday(), 1.41421 ),
            (102, 'Sort your data based on your commonly-used queries', today(),     2.718   ),
            (101, 'Granules are the smallest chunks of data read',      now() + 5,   3.14159 )
        ```

        <Note>
          请注意，`timestamp` 列是使用多种 [**Date**](/zh/reference/data-types/date) 和 [**日期时间**](/zh/reference/data-types/datetime) 函数填充的。ClickHouse 提供了数百个实用函数，您可以在[**函数**部分](/zh/reference/functions/index)中查看。
        </Note>

        验证是否生效：

        ```sql
        SELECT * FROM helloworld.my_first_table
        ```

### 使用 ClickHouse 客户端添加数据 {#add-data-using-the-clickhouse-client}

        您还可以使用名为 [**clickhouse 客户端**](/zh/concepts/features/interfaces/client) 的命令行工具连接到您的 ClickHouse Cloud 服务。点击左侧菜单中的 `Connect` 即可查看连接详情。在弹出的对话框中，从下拉菜单中选择 `Native`：

        <div className="ch-image-lg">
          <Frame>
            ![clickhouse 客户端连接详情](/images/_snippets/client_details.webp)
          </Frame>
        </div>

        <br />

        1. 安装 [ClickHouse](/zh/get-started/setup/self-managed/quick-install)。

        2. 运行以下命令，并将其中的主机名、用户名和密码替换为您自己的值：

        ```bash
        ./clickhouse client --host HOSTNAME.REGION.CSP.clickhouse.cloud \
        --secure --port 9440 \
        --user default \
        --password <password>
        ```

        如果看到笑脸提示符，就可以开始运行查询了！

        ```response
        :)
        ```

        3. 运行以下查询试一试：

        <br />

        ```sql
        SELECT *
        FROM helloworld.my_first_table
        ORDER BY timestamp
        ```

        可以看到，返回的响应采用了整齐的表格格式：

        ```response
        ┌─user_id─┬─message────────────────────────────────────────────┬───────────timestamp─┬──metric─┐
        │     102 │ Insert a lot of rows per batch                     │ 2022-03-21 00:00:00 │ 1.41421 │
        │     102 │ Sort your data based on your commonly-used queries │ 2022-03-22 00:00:00 │   2.718 │
        │     101 │ Hello, ClickHouse!                                 │ 2022-03-22 14:04:09 │      -1 │
        │     101 │ Granules are the smallest chunks of data read      │ 2022-03-22 14:04:14 │ 3.14159 │
        └─────────┴────────────────────────────────────────────────────┴─────────────────────┴─────────┘

        4 rows in set. Elapsed: 0.008 sec.
        ```

        4. 添加 [`FORMAT`](/zh/reference/statements/select/format) 子句，指定 [ClickHouse 支持的众多输出格式](/zh/reference/formats/index)之一：

        <br />

        ```sql
        SELECT *
        FROM helloworld.my_first_table
        ORDER BY timestamp
        FORMAT TabSeparated
        ```

        在上述查询中，输出结果以制表符分隔的格式返回：

        ```response
        Query id: 3604df1c-acfd-4117-9c56-f86c69721121

        102 Insert a lot of rows per batch      2022-03-21 00:00:00     1.41421
        102 Sort your data based on your commonly-used queries  2022-03-22 00:00:00     2.718
        101 Hello, ClickHouse!  2022-03-22 14:04:09     -1
        101 Granules are the smallest chunks of data read       2022-03-22 14:04:14     3.14159

        4 rows in set. Elapsed: 0.005 sec.
        ```

        5. 如需退出 `clickhouse client`，请输入 **exit** 命令：

        <br />

        ```bash
        exit
        ```

### 上传文件 {#upload-a-file}

        刚开始使用数据库时，常见的一项任务是将文件中已有的数据插入数据库。我们在线提供了一些
        可供插入的点击流样本数据，其中包括用户 ID、访问的 URL 以及
        事件的时间戳。

        假设在名为 `data.csv` 的 CSV 文件中有以下文本：

        ```bash title="data.csv"
        102,This is data in a file,2022-02-22 10:43:28,123.45
        101,It is comma-separated,2022-02-23 00:00:00,456.78
        103,Use FORMAT to specify the format,2022-02-21 10:43:30,678.90
        ```

        1. 以下命令将数据插入到 `my_first_table` 中：

        <br />

        ```bash
        ./clickhouse client --host HOSTNAME.REGION.CSP.clickhouse.cloud \
        --secure --port 9440 \
        --user default \
        --password <password> \
        --query='INSERT INTO helloworld.my_first_table FORMAT CSV' < data.csv
        ```

        2. 此时在 SQL 控制台中查询该表，即可看到新插入的行：

        <br />

          <Frame>
            ![从 CSV 文件导入的新行](/images/_snippets/new_rows_from_csv.webp)
          </Frame>
        </div>
