ClickHouse Observability 支持对事件 (日志和链路追踪) 进行全文搜索。只需输入与事件匹配的关键字，即可开始搜索。例如，如果日志中包含 &quot;Error&quot;，只需在搜索栏中输入 &quot;Error&quot; 即可找到。

在仪表盘和图表中过滤事件时，同样使用这套搜索语法。

## 搜索功能 {#search-features}

### Lucene 搜索语法 {#natural-language-syntax}

* 搜索不区分大小写
* 搜索默认按完整单词匹配 (例如，`Error` 会匹配 `Error here`，但不会匹配 `Errors here`) 。可以在单词两侧加上通配符来匹配部分单词 (例如，`*Error*` 会匹配 `AnyError` 和 `AnyErrors`)
* 搜索词不分先后顺序 (例如，`Hello World` 会匹配包含 `Hello World` 和 `World Hello` 的日志)
* 可以使用 `NOT` 或 `-` 排除关键字 (例如，`Error NOT Exception` 或 `Error -Exception`)
* 可以使用 `AND` 和 `OR` 组合多个关键字 (例如，`Error OR Exception`)
* 可以使用双引号进行精确匹配 (例如，`"Error tests not found"`)

#### 列/属性搜索 {#column-search}

* 可以使用 `column:value` 搜索列以及 JSON/Map 属性 (例如 `SeverityText:error`、
  `ServiceName:app`)
* 可以使用比较运算符 (`>`、`<`、
  `>=`、`<=`) 按范围搜索值 (例如 `Duration:>1000`)
* 可以使用 `property:*` 搜索存在某个属性的记录 (例如
  `Duration:*`)

### 时间输入 {#time-input}

* 时间输入支持自然语言 (例如 `1 hour ago`、`yesterday`、
  `last week`)
* 如果只指定单个时间点，将搜索从该时间点到当前时间的
  数据。
* 执行搜索时，时间范围始终会被转换为已解析的时间范围，便于
  调试与时间相关的查询。
* 您还可以在直方图中框选条形，以放大查看特定的时间范围。

### SQL 搜索语法 {#sql-syntax}

您可以按需将搜索输入框切换为 SQL 模式。在该模式下，可使用任何有效的
`WHERE` 子句进行搜索。对于无法用 Lucene 语法表达的复杂查询，
这一功能尤为实用。

### SELECT 语句 {#select-statement}

如需指定搜索结果中显示的列，可以使用 `SELECT`
输入框。该输入框接受一个 SQL `SELECT` 表达式，用于指定搜索页面中要查询的列。
目前暂不支持别名 (例如，不能使用 `column as "alias"`) 。

## 保存的搜索 {#saved-searches}

您可以保存搜索，以便日后快速访问。保存后，搜索会显示在 `Saved Searches` 页面中，方便您随时调出常用的搜索查询，无需重新构建。

### 为保存的搜索添加告警 {#alerts-on-saved-searches}

您可以为保存的搜索设置告警进行监控，以便在满足特定条件时收到通知。告警可配置为在与保存的搜索匹配的事件数量高于或低于指定阈值时触发。

有关设置和配置告警的更多信息，请参阅[告警文档](/zh/clickstack/observability/features/alerts)。
