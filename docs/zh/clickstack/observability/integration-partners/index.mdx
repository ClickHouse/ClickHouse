借助以下集成合作伙伴，将您的遥测数据管道和应用程序接入 ClickHouse Observability。每篇指南均介绍了如何针对您的部署配置相应集成。

| 分组                                                                    | 描述                                                                  |
| --------------------------------------------------------------------- | ------------------------------------------------------------------- |
| [Bindplane](/zh/clickstack/observability/integration-partners/bindplane) | Bindplane 是一款 OpenTelemetry 原生的遥测数据管道，可集中管理 OpenTelemetry 收集器。      |
| [bitdrift](/zh/clickstack/observability/integration-partners/bitdrift)   | bitdrift 是一款面向移动应用的动态可观测性平台，可通过 OpenTelemetry 追踪上下文将移动端遥测与后端追踪关联起来。 |
| [Odigos](/zh/clickstack/observability/integration-partners/odigos)       | Odigos 结合 eBPF 与 OpenTelemetry，可提供更深入的分布式链路追踪，且开销远低于字节码 agent。      |
| [Telflo](/zh/clickstack/observability/integration-partners/telflo)       | Telflo 是一款 OpenTelemetry 原生的控制平面，可集中管理采集器并统一路由遥测数据。                 |
