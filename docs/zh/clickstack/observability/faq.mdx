本页介绍 ClickHouse Observability 的全托管模式和自管理模式，并解答有关数据采集、告警、仪表盘和指标发现的常见问题。

## 部署与数据采集 {#data-collection}

<Accordion title="全托管与自管理 ClickHouse Observability 有何区别？">
  **全托管**

  <BetaBadge label="Beta 版服务" />

  推荐从[全托管 ClickHouse Observability](/zh/clickstack/observability/overview) 入手。只需将遥测数据发送到托管的 OpenTelemetry 端点；摄取采集器、schema、基础设施和扩缩容均由 ClickHouse 负责。

  **自管理**

  [Self-managed ClickHouse Observability](/zh/clickstack/self-configured/overview) 让您可以自行控制摄取、schema、数据保留和数据库配置。ClickHouse Cloud 托管 ClickHouse 和 ClickStack 用户界面，而摄取采集器的运行以及数据库调优和容量管理则由您负责。自管理版本不属于 Beta 版服务。
</Accordion>

<Accordion title="是否需要运行 OpenTelemetry 采集器？">
  **全托管：** 无需部署摄取采集器。应用程序和遥测数据生成器可以直接将数据发送到托管的 OpenTelemetry 端点。

  如需读取日志文件或收集主机和 Kubernetes 指标，您可能仍需在自己的环境中运行采集器，再将这些数据转发到托管采集器。示例请参阅[本地日志和指标](/zh/clickstack/observability/example-datasets/local-data)和[监控 Kubernetes](/zh/clickstack/observability/example-datasets/kubernetes)。

  **自管理：** 您需要运行一个摄取采集器，并将其连接到您的 ClickHouse Cloud 服务。应用程序和代理将遥测数据发送到该采集器，再由其写入 ClickHouse。我们推荐使用 ClickStack 发行版。连接说明请参阅[使用 OpenTelemetry 摄取数据](/zh/clickstack/observability/ingesting-data/opentelemetry#installing-otel-collector-managed-self-configured)，启动采集器请参阅[部署指南](/zh/clickstack/self-configured/deployment/managed#start-a-collector-existing)。
</Accordion>

<Accordion title="在哪里可以找到遥测端点和 API key？">
  **全托管：** 在您的 ClickHouse Observability 服务中，打开 **团队设置 → 数据 → Managed Telemetry**，复制 OTLP 端点和摄取 API key。配置 SDK、转发采集器或遥测数据生成器时，请使用这些信息。

  **自管理：** 使用您所运行采集器的 OTLP 端点，以及其接收器上配置的身份验证令牌 (如有) 。对于 ClickStack 采集器，如果启用了 `OTLP_AUTH_TOKEN`，请在 `authorization` 请求头中发送该令牌。这些信息与采集器写入数据时所用的 ClickHouse Cloud 数据库端点和凭据相互独立。示例请参阅[使用 OpenTelemetry 摄取数据](/zh/clickstack/observability/ingesting-data/opentelemetry#sending-data-to-collector-managed-self-configured)。

  请按照所用工具要求的格式填写端点。[示例数据和演示](/zh/clickstack/observability/example-datasets)中提供了各工具的配置示例。
</Accordion>

## 告警 {#alerting}

<Accordion title="ClickHouse Observability 支持哪些类型的告警？">
  ClickHouse Observability 支持两种类型的告警：

  * [搜索告警](/zh/clickstack/observability/features/alerts#search-alerts)：当某个时间窗口内匹配的日志或 trace 结果数量高于或低于阈值时触发通知。
  * [仪表板图表告警](/zh/clickstack/observability/features/alerts#dashboard-alerts)：当仪表板面板中绘制的指标越过设定的阈值时触发通知。

  这两种告警都会将结果与已配置的阈值进行比对评估。完整详情请参阅[告警](/zh/clickstack/observability/features/alerts)。
</Accordion>

<Accordion title="能否针对复杂的指标条件（例如比率、p95/p99 或多指标公式）设置告警？">
  可以先将该计算构建为仪表盘图表，再为该图表附加阈值告警。[图表构建器](/zh/clickstack/observability/features/dashboards/overview#navigate-chart-explorer)支持比率、百分位数等计算。

  如果计算需要用到 SQL，请使用[基于 SQL 的图表告警](/zh/clickstack/observability/features/alerts#sql-based-alerts)。SQL 告警支持折线图、堆叠条形图和数值图。保存仪表盘后，告警即会生效。
</Accordion>

## 仪表盘与下钻 {#dashboards-and-drill-downs}

<Accordion title="是否提供预置仪表盘？">
  是的。打开 **仪表盘**，即可找到 **Services**、**Kubernetes** 和 **LLM** 预置仪表盘。只要正在摄取相关遥测数据，且所选时间范围内包含这些数据，这些仪表盘就会显示数据。

  您还可以基于已摄取的日志、链路追踪和指标创建自定义仪表盘。有关如何构建图表并将其组织到仪表盘中，请参阅[仪表盘](/zh/clickstack/observability/features/dashboards/overview)。
</Accordion>

<Accordion title="ClickHouse Observability 是否支持参数化仪表盘或仪表盘变量？">
  是的，ClickHouse Observability 支持通过自定义筛选器和变量实现参数化的仪表盘，其取值来自从 ClickHouse 查询到的数据。借助这些筛选器，您可以将仪表盘上的部分或全部卡片动态限定到某个特定值 (例如服务名称、环境或主机) 。

  有关创建仪表盘和应用筛选条件的详细信息，请参阅[仪表盘](/zh/clickstack/observability/features/dashboards/overview)。
</Accordion>

<Accordion title="支持哪些下钻能力？">
  ClickHouse Observability 支持以下下钻工作流：

  * [仪表盘级筛选](/zh/clickstack/observability/features/dashboards/overview#filter-dashboards)：仪表盘级的 Lucene 或 SQL 筛选条件会作用于已启用 **Apply filters** 的卡片。您还可以调整仪表盘的时间范围。
  * 自定义仪表盘筛选器：自定义仪表盘支持显式的筛选控件，其选项取自您的数据，用户无需手动编写查询即可限定参与筛选的卡片范围。
  * 点击查看事件：点击仪表盘面板中的数据并选择 **View Events**，即可跳转到[搜索](/zh/clickstack/observability/features/search)页面，并自动带上针对日志和链路追踪数据的相关筛选条件。
  * [表格行点击下钻](/zh/clickstack/observability/features/dashboards/row-click-drilldowns)：可以将表格卡片配置为点击某一行时打开搜索页面或另一个仪表盘，并将该行的值作为筛选条件一并传递。借此可实现多级工作流，例如从服务清单下钻到单个服务的详情仪表盘。

  <Note>
    使用[搜索](/zh/clickstack/observability/features/search)查看单条日志和链路追踪，使用 Chart Explorer 探索指标。
  </Note>
</Accordion>

## 指标发现 {#metrics-discovery}

<Accordion title="是否有用于浏览和搜索指标的 UI？">
  ![指标属性浏览器](/images/clickstack/faq/metrics-explorer-fully-managed.png)

  您可以通过[图表构建器](/zh/clickstack/observability/features/dashboards/overview#navigate-chart-explorer)中的指标名称下拉列表查找指标名称。选中某个指标后，指标属性浏览器面板会显示该指标的描述、单位、可用属性及属性值。您可以在该面板中浏览属性，并直接将其添加为筛选条件或 group-by 字段。

  目前尚未提供类似日志搜索的专用指标搜索页面。
</Accordion>
