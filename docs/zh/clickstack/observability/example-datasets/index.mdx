这些示例数据集和演示可帮助您快速上手全托管的 ClickHouse Observability。您可以加载样本数据、从自己的环境中收集日志和指标，或对应用程序进行插桩，从而探索链路追踪和会话回放。

| 数据集                                                                                      | 描述                                                                              |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [样本数据](/zh/clickstack/observability/example-datasets/sample-data)                           | 加载样本数据集，其中包含来自我们演示环境的日志、链路追踪和指标                                                 |
| [监控 Kubernetes](/zh/clickstack/observability/example-datasets/kubernetes)                   | 从 Kubernetes 集群收集日志和指标，并发送到您的 managed service                                   |
| [本地数据](/zh/clickstack/observability/example-datasets/local-data)                            | 收集本地系统指标和日志，并发送到您的 managed service 进行分析                                         |
| [会话回放演示](/zh/clickstack/observability/example-datasets/session-replay)                      | 对演示 Web 应用程序进行插桩以启用会话回放，并在 ClickHouse Observability 中查看您的交互操作                   |
| [Chrome 扩展程序](/zh/clickstack/observability/example-datasets/chrome-extension)               | 使用 HyperDX Chrome 扩展将浏览器 SDK 注入任意网站，无需修改应用程序代码                                  |
| [使用 otelgen 生成合成数据](/zh/clickstack/observability/example-datasets/otelgen)                  | 使用 `otelgen` 将合成的日志、链路追踪和指标发送到您的托管遥测端点                                          |
| [使用 telemetrygen 生成合成数据](/zh/clickstack/observability/example-datasets/telemetrygen)        | 使用 `telemetrygen` 将合成的日志、链路追踪和指标发送到您的托管遥测端点                                     |
| [HackerNews Analyzer](/zh/clickstack/observability/example-datasets/instrument-application) | 使用 agent (或手动) 对 Node.js 应用进行插桩，并将日志、链路追踪、指标和会话回放数据发送到 ClickHouse Observability |
