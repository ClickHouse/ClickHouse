从 Elastic Stack 或 Datadog 迁移到托管或自管理的 ClickHouse Observability。这些指南涵盖迁移规划、搜索语法，以及如何调整现有的遥测数据采集方式。如果连接详情因部署方式而异，请选择与您的部署方式对应的选项卡。

| 技术                                                           | 描述                                                  |
| ------------------------------------------------------------ | --------------------------------------------------- |
| [Elastic Stack](/zh/clickstack/observability/migration/elastic) | 规划迁移过程、转换搜索查询，并迁移数据、agent 和应用程序插桩                   |
| [Datadog](/zh/clickstack/observability/migration/datadog)       | 配置现有的 Datadog 代理，将遥测数据发送到托管端点或自管理的 Datadog receiver |
