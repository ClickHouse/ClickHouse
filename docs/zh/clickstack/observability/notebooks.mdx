AI 笔记本是 ClickHouse Observability 中的一款交互式调查工具，它将 AI agent 与手动分析相结合。您可以用自然语言描述问题，AI agent 会代您查询日志、链路追踪和指标，并以一系列内容块的形式呈现相关数据、图表和摘要。您还可以在 AI 生成的结果旁添加自己的内容块 (图表、表格、搜索和 Markdown 笔记) ，从而形成一份完整的调查记录。

## 设置 {#setup}

AI 笔记本目前在 ClickHouse Cloud 中处于 Beta 阶段。AI 模型及其提供商均由平台自动管理。

使用 AI 笔记本前，需满足以下条件：

1. **已启用生成式 AI** — 团队管理员须开启“生成式 AI”授权开关。请参阅[启用生成式 AI](#enabling-generative-ai)。
2. **笔记本访问权限** — 你的角色须具有笔记本的读写权限。

启用后，所有具备相应角色的用户都会在左侧边栏中看到 **AI 笔记本** 条目。

## 启用生成式 AI {#enabling-generative-ai}

团队管理员必须先开启生成式 AI 授权同意开关，才能使用笔记本 (及其他 AI 功能) 。

1. 打开 **团队设置**，找到 **Configure 生成式 AI**。
2. 开启生成式 AI 开关。
3. 阅读并接受授权同意对话框中的条款。

## 使用 AI 笔记本 {#using-notebooks}

### 创建笔记本 {#creating-a-notebook}

1. 在左侧边栏中选择 **AI 笔记本**。
2. 点击 **新建私有笔记本** (仅自己可见) 或 **新建共享笔记本** (团队成员可见) 。

笔记本列表页面会显示您有权访问的所有笔记本。您可以按名称或标签进行过滤，也可以在 **我的笔记本** 和 **所有笔记本** 之间切换。

<div className="ch-image-lg">
  <Frame>
    ![笔记本列表页面](/images/clickstack/observability-notebook-list.png)
  </Frame>
</div>

### 运行 AI 调查 {#running-investigation}

在笔记本底部输入提示词，描述您想要调查的内容，例如：*“为什么过去一小时内 checkout 服务的错误率激增？”*

点击 **Send** (或按 Enter) 。AI agent 将会：

1. 检查您可用的数据源。
2. 针对您的日志、链路追踪和指标执行搜索查询和聚合查询。
3. 生成一系列内容块，展示其思考过程、执行过的查询、中间图表，以及包含结论的最终摘要。

每个步骤都会以内容块形式显示在笔记本中。**思考过程** 内容块展示每个查询背后的推理过程，**Output** 内容块则包含 agent 得出的结论以及可选的图表。与普通的 AI 聊天不同，在笔记本中您可以清楚看到 AI 在每个步骤中所依据的数据，从而验证其推理、发现它可能遗漏的有价值线索，并通过[分支](#branching)调查来引导其转向其他方向。

调查运行期间，您可以点击 **Stop** 将其取消。

### 创建调查分支 {#branching}

在 AI 进行调查的过程中，您可能会注意到某个中间步骤揭示了值得关注的信息，但 agent 却沿着另一条路径继续推进。借助**分支创建**功能，您可以从该节点使用不同的提示词重新开始，同时保留原有的调查路径。

要创建分支：

1. 展开要从中创建分支的卡片，然后点击 **Restart from Here**。
2. 在对话框中输入修改后的提示词，引导调查转向新的方向。
3. 点击 **Create Branch**。AI 将从该节点开始一个新的调查分支。

  <Frame>
    ![Create New Branch 对话框](/images/clickstack/observability-notebook-branch-modal.png)

</div>

当某个卡片拥有多个分支时，卡片标题栏上会出现左右箭头按钮，并显示一个徽章 (例如 **1/2**) ，用于指示分支的数量。点击箭头即可在各分支之间切换。

### 手动添加内容块 {#manual-tiles}

除了 AI 生成的内容块外，您还可以使用笔记本底部的按钮添加自己的分析块：

| 按钮           | 快捷键 | 描述                                                                                 |
| ------------ | --- | ---------------------------------------------------------------------------------- |
| **搜索**       | `S` | 日志/trace 搜索视图，等同于搜索页面。                                                             |
| **图表**       | `L` | 时间序列折线图，使用与[仪表盘](/zh/clickstack/observability/features/dashboards/overview)相同的可视化构建器。 |
| **表**        | `T` | 表格形式的聚合视图。                                                                         |
| **Markdown** | `M` | 自由格式文本，用于记录笔记、假设或结论。                                                               |

添加内容块后，内容块会以内联编辑模式打开，您可以在其中配置数据源、筛选条件和聚合，所用界面与构建[仪表盘可视化](/zh/clickstack/observability/features/dashboards/overview#creating-visualizations)时相同。点击 **保存** 即可完成该内容块。

手动添加的内容块会位于当前分支中最后一个可见内容块的下方。拖动内容块底部边缘即可在垂直方向调整其大小。

  如果当前有 AI 调查正在运行，添加或编辑手动内容块会取消该调查。执行操作前会弹出确认对话框。
</Note>

### 共享与整理 {#sharing-organizing}

* **私有与共享** — 点击笔记本顶部栏中的锁形图标，即可在私有 (仅自己可见) 和共享 (团队成员可见) 之间切换。只有笔记本创建者可以更改此设置。
* **标签** — 为笔记本添加标签，便于在列表页中快速筛选。
* **命名** — 点击笔记本标题即可重命名。如果在未命名的笔记本中发起调查，AI 会自动建议一个名称。

### 自定义 agent 上下文 {#custom-agent-context}

团队管理员可以提供额外的上下文，这些内容会包含在该团队的每一次 AI 笔记本调查中。借助这一功能，您可以向 AI 提供系统架构、命名约定或已知问题等背景信息。

配置步骤如下：

1. 在左侧侧边栏中进入 **AI 笔记本**。
2. 点击右上角的设置齿轮图标，打开 **自定义 agent 上下文** (仅团队管理员可用) 。
3. 输入自定义上下文 (最多 50,000 个字符) ，然后保存。

该上下文会追加到 AI 的系统提示中，作用于团队内的所有笔记本调查。
