使用 ClickStack Node.js SDK 从您的 NestJS 应用程序收集遥测数据，并发送到 ClickHouse Observability。该 SDK 内置 NestJS 请求插桩，并可捕获控制台输出。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## 安装 SDK {#install-sdk}

请使用 Node.js 22.15 或更高版本：

```shell
npm install @clickhouse/clickstack-node
```

## 配置目标端 {#configure-destination}

<Tabs>
  <Tab title="全托管">
    <BetaBadge label="Beta 版" />

    在您的服务中打开 **团队设置 → 数据 → Managed Telemetry**，复制 **OTLP HTTP 端点** 和 **API key**。请使用包含端口的完整 HTTPS 端点：

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="自管理">
    使用您的采集器的 OTLP HTTP 端点和摄取 API key。如果采集器未配置 TLS，请将 `https://` 替换为 `http://`。有关如何设置采集器，请参阅[使用 OpenTelemetry 摄取数据](/zh/clickstack/observability/ingesting-data/opentelemetry#self-managed)。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## 启动应用程序 {#start-application}

设置 `OTEL_SERVICE_NAME` 来标识您的应用程序。先构建 NestJS 应用程序，然后在加载已编译的入口点之前预加载 SDK：

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

请根据您的构建输出调整 `dist/main.js`。如果您使用 `ts-node` 或其他会挂钩 `require` 的转译器，请改用 `--require @clickhouse/clickstack-node/register`。如果您会对应用程序进行打包，请将 SDK 及已插桩的依赖项标记为外部依赖 (external) ，不要将其打包进去。

您可以继续使用 NestJS 的默认控制台日志记录器。如需使用自定义日志记录器，请选择受支持的集成，例如 Winston 或 Pino。有关配置和兼容性的详细信息，请参阅 [Node.js 指南](/zh/clickstack/observability/ingesting-data/sdks/nodejs)。

## 验证摄取 {#verify-ingestion}

向某个控制器发送一个请求，并输出一条日志消息。在 ClickHouse Observability 中选择一个最近的时间范围，然后在 Logs (日志) 和 Traces (链路追踪) 中查找你的应用程序的服务名称。等待指标导出完成后，再查看 Metrics (指标) 。
