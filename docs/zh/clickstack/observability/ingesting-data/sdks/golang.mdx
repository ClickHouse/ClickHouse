使用 OpenTelemetry Go SDK 将日志、指标和链路追踪数据发送到 ClickHouse Observability。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## 设置 OpenTelemetry {#set-up-opentelemetry}

按照官方的 [OpenTelemetry Go 设置说明](https://opentelemetry.io/docs/languages/go/getting-started/)初始化 SDK，并对应用程序进行插桩。

使用下方的连接设置，为要发送的信号配置[基于 HTTP 的 OTLP 导出](https://opentelemetry.io/docs/languages/go/exporters/)。请替换上游说明中的所有示例目标端，包括针对特定信号的端点覆盖配置。

## 配置目标端 {#configure-destination}

<Tabs>
  <Tab title="全托管">
    <BetaBadge label="Beta 版服务" />

    在您的服务中打开 **团队设置 → 数据 → Managed Telemetry**，复制 **OTLP HTTP 端点** 和 **API key**。请使用包含端口的完整 HTTPS 端点：

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="自管理">
    使用采集器的 OTLP HTTP 端点和摄取 key。如果采集器未配置 TLS，请使用 `http://` 代替 `https://`。有关如何设置采集器，请参阅[使用 OpenTelemetry 摄取数据](/zh/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## 验证摄取 {#verify-ingestion}

启动已插桩的应用程序，并让其产生一些活动。在 ClickHouse Observability 中选择最近的时间范围，然后在 日志 或 链路追踪 中查找应用程序的服务名称。如果应用程序会发出指标，请稍等片刻以完成导出，然后查看 指标。

有关插桩和导出器的故障排查，请参阅 [OpenTelemetry Go 文档](https://opentelemetry.io/docs/languages/go/)。
