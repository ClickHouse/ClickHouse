## 连接您的应用程序 {#connect-your-application}

1. 参照适用于您所用语言或平台的指南配置插桩。
2. 在该指南中选择目标端：
   * **全托管：** 使用您服务的托管 OTLP 端点和摄取 API key，可在 **团队设置 → 数据 → Managed Telemetry** 中找到。
   * **自管理：** 使用您的 OpenTelemetry 收集器的 OTLP 端点及已配置的摄取密钥。
3. 在应用程序中产生一些活动，然后在 UI 中确认能看到预期的遥测数据。

各指南分别说明了每个 SDK 的身份验证格式和导出器设置。Lambda 指南还提供了 OpenTelemetry 层选项，可通过本地采集器转发遥测数据。
