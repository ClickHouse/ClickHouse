借助 URL 查询参数，可以通过深度链接打开 ClickHouse Observability 页面，从而从外部系统 (如告警通知、运行手册、CI 作业、聊天消息等) 直接跳转到特定的搜索、仪表盘或面板。

本页示例使用 `<YOUR_CLICKSTACK_URL>` 作为占位符，请将其替换为您的可观测性 UI 的基准 URL。

<Note>
  为便于阅读，示例中的查询参数未经 URL 编码。以编程方式构建链接时，请对每个查询参数值进行 URL 编码。
</Note>

<Info>
  **云服务 ID 参数**

  使用 Cloud UI 时，链接应包含 `?chcServiceId=` 参数。这样，当点击链接的已通过身份验证的用户有权访问多个 ClickHouse 云服务时，即可确定应加载哪个 ClickHouse 云服务。

  示例：针对特定云服务打开搜索页面

  ```text
  https://hyperdx.clickhouse.cloud/search?chcServiceId=abc123
  ```
</Info>

## 搜索 — `/search` {#search}

主要的日志/trace 搜索视图。有关搜索语法的详细信息，请参阅[搜索](/zh/clickstack/observability/features/search)。

| 参数              | 格式                                                                         | 描述                                                                                    |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `source`        | 字符串                                                                     | 要搜索的 source，可以是 source ID，也可以是 source **名称** (例如 `Logs`) 。此页面仅支持日志和 trace 类型的 source。 |
| `where`         | 字符串                                                                     | 过滤查询文本，可使用 Lucene 或 SQL 语法 (参见 `whereLanguage`) 。                                     |
| `whereLanguage` | `lucene` | `sql`                                                           | `where` 所使用的查询语言。                                                                     |
| `select`        | 字符串                                                                     | 在结果表中显示的 SQL 列/表达式列表。                                                                 |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | 结构化分面筛选条件，在 `where` 的基础上叠加应用。                                                         |
| `orderBy`       | 字符串                                                                     | 结果表的 SQL 排序表达式。                                                                       |
| `mode`          | `results` | `delta` | `pattern`                                            | 当前启用的分析模式。`delta` 仅适用于链路追踪数据源。                                                        |
| `isLive`        | `true` | `false`                                                           | 是否启用实时跟踪 (默认值为 `true`) 。                                                              |
| `traceId`       | 字符串                                                                     | 直接跳转到指定追踪 ID 的链路追踪瀑布图。                                                                |
| `from`, `to`    | 自 Unix 纪元起的毫秒数                                                             | 绝对时间范围。如果省略，则默认为最近 15 分钟。                                                             |

也可以通过 `/search/<savedSearchId>` 直接打开已保存的搜索。

### 示例：在指定时间范围内搜索 `Logs` source 中 `checkout` 服务的错误 {#example-search-errors}

```text
<YOUR_CLICKSTACK_URL>/search?source=Logs&from=1735689600000&to=1735693200000&where=level:error&filters=[{"type":"sql","condition":"ServiceName IN ('checkout')"}]
```

### 示例：直接跳转到 trace 的瀑布视图 {#example-search-trace}

```text
<YOUR_CLICKSTACK_URL>/search?source=Traces&traceId=ba7217967eb90d040b7eb39f97ecc5c4
```

## 仪表盘 — `/dashboards/<dashboardId>` {#dashboards}

已保存的仪表盘。省略 `<dashboardId>`(即 `/dashboards`)可打开一个未保存的临时仪表盘。有关构建仪表盘的详细信息，请参阅[仪表盘](/zh/clickstack/observability/features/dashboards/overview)。

| 参数                  | 格式                                                                                                                                  | 描述                                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `from`, `to`        | 自 Unix 纪元起的毫秒数                                                                                                                      | 应用于所有卡片的时间范围。省略时默认为最近 15 分钟。                                                                                                   |
| `where`             | 字符串                                                                                                                                 | 仪表盘级别的过滤查询文本，作用于所有卡片。                                                                                                          |
| `whereLanguage`     | `lucene` | `sql`                                                                                                                    | `where` 所使用的查询语言。                                                                                                              |
| `filters`           | 由筛选值条目组成的 JSON 数组                                                                                                                   | 仪表盘中[自定义筛选器和变量](/zh/clickstack/observability/features/dashboards/overview#custom-filters)的选中值。请参阅[筛选值](#dashboard-filter-values)。 |
| `granularity`       | `auto` | `30 second` | `1 minute` | `5 minute` | `10 minute` | `15 minute` | `30 minute` | `1 hour` | `12 hour` | `1 day` | `7 day` | 时间序列卡片的桶大小。`auto` 会根据所选时间范围自动确定桶大小。                                                                                            |
| `highlightedTileId` | 字符串                                                                                                                                 | 滚动至指定卡片并将其高亮显示，适用于从告警链接跳转的场景。                                                                                                  |

### 筛选值 {#dashboard-filter-values}

`filters` 参数是一个 JSON 数组。每个条目用于设置一个筛选条件的选中值，格式为以下几种之一：

| 条目                                                                                                                | 适用对象                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `{"type":"variable","name":"<variableName>","values":["<value1>","<value2>"]}`                                    | 属于变量的筛选条件：静态值、SQL 查询值、PromQL 标签值、数据源和连接变量，以及启用了 **Available as variable** 的 SQL 表达式值筛选条件。`name` 为该筛选条件的变量名。                                                                                                                        |
| `{"type":"adhoc","name":"<uniqueName>","conditions":[{"key":"<key>","operator":"<operator>","value":"<value>"}]}` | [临时过滤器](/zh/clickstack/observability/features/dashboards/overview#adhoc-filters)。`name` 为该筛选条件的唯一名称，`operator` 取值为 `=`、`!=`、`=~`、`!~`、`LIKE`、`NOT LIKE` 或 `IN` 之一。`LIKE` 和 `NOT LIKE` 仅适用于 SQL 数据源——Prometheus 临时过滤器会忽略使用这两个运算符的条件。 |
| `{"type":"sql","condition":"<expression> IN ('<value1>', '<value2>')"}`                                           | 不属于变量的 SQL 表达式值筛选条件。条件中的表达式必须与该筛选条件的 **Filter expression** 一致。                                                                                                                                                                     |

规则如下：

* 当变量条目与 `sql` 条目指向同一筛选条件时，以变量条目为准。在引入变量之前创建的链接 (所有筛选条件均使用 `sql` 条目) 仍可正常使用。
* 对于数据源和连接变量，值可以填写 source 或连接的**名称**，而不必使用其 ID。系统会先按名称精确匹配，再进行不区分大小写的匹配。这样，即使同一 source 在不同环境中的 ID 不同，链接也能保持有效。
* 单选筛选条件仅使用第一个值。
* 与仪表盘上任何筛选条件都不匹配或格式有误的条目将被忽略。

### 示例：打开指定时间范围的仪表盘并高亮某个卡片 {#example-dashboard-highlight}

适用于从告警通知直接链接到触发该告警的卡片。

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?from=1735689600000&to=1735693200000&highlightedTileId=chart-1
```

### 示例：在变量型筛选条件中选择值 {#example-dashboard-variables}

在变量名为 `service` 的筛选条件中选中 `checkout` 和 `payments`，并在变量名为 `severity` 的筛选条件中选中 `ERROR`。

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?filters=[{"type":"variable","name":"service","values":["checkout","payments"]},{"type":"variable","name":"severity","values":["ERROR"]}]
```

### 示例：按名称选择数据源和连接 {#example-dashboard-source-variable}

在名为 `logs` 的数据源变量中选择 `Production Logs` source，并在名为 `cluster` 的连接变量中选择 `Production` 连接。

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?filters=[{"type":"variable","name":"logs","values":["Production Logs"]},{"type":"variable","name":"cluster","values":["Production"]}]
```

### 示例：添加临时过滤条件 {#example-dashboard-adhoc}

向唯一名称为 `adhoc` 的临时过滤器添加两个条件：`ServiceName` 为 `checkout` 或 `payments`，且 `SeverityText` 不为 `DEBUG`。

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?filters=[{"type":"adhoc","name":"adhoc","conditions":[{"key":"ServiceName","operator":"IN","value":"checkout"},{"key":"ServiceName","operator":"IN","value":"payments"},{"key":"SeverityText","operator":"!=","value":"DEBUG"}]}]
```

## Chart Explorer — `/chart` {#chart-explorer}

一个可共享的即席图表构建器。

| 参数           | 格式             | 描述                                                             |
| ------------ | -------------- | -------------------------------------------------------------- |
| `config`     | JSON           | 完整的图表配置 (source、select、where、图表类型等) 。通常由应用内的“共享”链接自动生成，而非手动编写。 |
| `from`, `to` | 自 Unix 纪元起的毫秒数 | 时间范围。若省略，默认为最近 15 分钟。                                          |

### 示例：打开指定时间范围的 p99 延迟图表配置 {#example-chart-config}

```text
<YOUR_CLICKSTACK_URL>/chart?granularity=auto&from=1785759381784&to=1785762981785&config={"name":"","select":[{"aggFn":"quantile","aggCondition":"","aggConditionLanguage":"lucene","valueExpression":"Duration","level":0.99,"alias":"p99"}],"where":"","whereLanguage":"lucene","displayType":"line","alignDateRangeToGranularity":true,"source":"68814eb5d40a9d0449afc1f2","connection":"68814b6fd40a9d0449afbe78","groupBy":"ServiceName"}
```

## 会话回放 — `/sessions` {#session-replay}

会话回放的浏览与播放。有关功能详情，请参阅[会话回放](/zh/clickstack/observability/features/session-replay)。

| 参数              | 格式               | 描述                           |
| --------------- | ---------------- | ---------------------------- |
| `sessionSource` | 字符串           | 会话 source 的 ID 或名称。          |
| `where`         | 字符串           | 用于过滤会话列表的查询文本。               |
| `whereLanguage` | `lucene` | `sql` | `where` 所使用的查询语言。            |
| `from`、`to`     | 自 Unix 纪元起的毫秒数   | 会话列表的时间范围。如果省略，则默认为最近 15 分钟。 |
| `sid`           | 字符串           | 按 ID 打开指定会话。                 |
| `sfrom`、`sto`   | 自 Unix 纪元起的毫秒数   | 已打开会话的时间窗口 (与 `sid` 配合使用) 。  |

### 示例：浏览指定时间范围内的会话回放 {#example-sessions-time-range}

```text
<YOUR_CLICKSTACK_URL>/sessions?from=1735689600000&to=1735693200000
```

### 示例：按录制时的时间窗口打开指定会话回放 {#example-sessions-open}

```text
<YOUR_CLICKSTACK_URL>/sessions?sid=6712abf0e4b0f2a1c3d4e5f6&sfrom=1735689600000&sto=1735690200000
```

## 服务 — `/services` {#services}

按服务划分的 HTTP、数据库和错误仪表盘。

| 参数              | 格式                                                                         | 描述                                |
| --------------- | -------------------------------------------------------------------------- | --------------------------------- |
| `tab`           | `http` | `database` | `errors`                                             | 当前显示的服务仪表盘子选项卡。默认值：`http`         |
| `source`        | 字符串                                                                        | 链路追踪数据源 ID。                       |
| `service`       | 字符串                                                                        | 所选服务名称。                           |
| `where`         | 字符串                                                                        | 筛选用的查询文本。                         |
| `whereLanguage` | `lucene` | `sql`                                                           | `where` 所使用的查询语言 (此页面默认为 `sql`) 。 |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | 仪表盘筛选栏中的值。                        |
| `from`、`to`     | 自 Unix 纪元起的毫秒数                                                             | 时间范围。若省略，则默认为最近 15 分钟。            |

### 示例：查看服务在指定时间范围内的数据库仪表盘 {#example-services-database}

```text
<YOUR_CLICKSTACK_URL>/services?tab=database&service=checkout&from=1735689600000&to=1735693200000
```

### 示例：查看服务的错误仪表盘 {#example-services-errors}

```text
<YOUR_CLICKSTACK_URL>/services?tab=errors&service=payments
```
