本指南将引导您使用 OpenTelemetry 对一个小型 Node.js 应用程序进行插桩，并将其日志、指标、链路追踪和会话回放发送到 Self-managed ClickHouse Observability。后端插桩无需改动应用程序的任何源代码。

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) 是一个 Node.js 应用，用于查询托管在公共 ClickHouse 演示环境中的 HackerNews 数据集。其中每个图表、表和搜索框背后都是真实的 ClickHouse 查询，因此每次交互都会生成一条 trace，其主跨度即后端向 ClickHouse 发起的 HTTPS 调用。

本指南假定您已完成[设置 OpenTelemetry 采集器](/zh/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)，并且已有一个正在运行的 ClickStack 采集器，可从运行此应用程序的机器访问该采集器。**请务必记下其 OTLP 端点**，以及部署时设置的 `OTLP_AUTH_TOKEN`。在插桩之前，您需要将这些值填入 `.env`。

## 前置条件 {#prerequisites}

* 一个可从本机访问的 ClickStack 采集器。如果尚未部署，请先参阅[设置 OpenTelemetry 采集器](/zh/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)完成部署。
* 该采集器的 OTLP/HTTP 端点 (通常使用端口 `4318`) ，以及您为其设置的 `OTLP_AUTH_TOKEN`。请将二者分别配置为 `OTEL_EXPORTER_OTLP_ENDPOINT` 和 `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`。
* Node 18+ 和 npm。

## 克隆代码仓库 {#clone-the-repository}

克隆 [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer)，安装依赖项，然后复制 env 模板文件：

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

你将在接下来的步骤中填写 `.env` 文件，然后在此目录下进行插桩。
