使用 ClickStack Node.js SDK 从您的 NestJS 应用程序收集遥测数据，并将其发送到 ClickStack。该 SDK 内置 NestJS 请求插桩，并会捕获控制台输出。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## 安装 SDK {#install-sdk}

请使用 Node.js 22.15 或更高版本：

```shell
npm install @clickhouse/clickstack-node
```

## 配置目标端 {#configure-destination}

为 ClickStack 采集器设置 OTLP HTTP 端点和摄取密钥。如果采集器未配置 TLS，请使用 `http://`。有关采集器的设置方法，请参阅[使用 OpenTelemetry 摄取数据](/zh/clickstack/ingesting-data/opentelemetry)。

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## 启动应用程序 {#start-application}

设置 `OTEL_SERVICE_NAME` 以标识您的应用程序。先构建 NestJS 应用程序，然后在已编译的入口点之前预加载 SDK：

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

请根据您的构建产物调整 `dist/main.js`。如果您使用 `ts-node` 或其他会挂钩 `require` 的转译器，请改用 `--require @clickhouse/clickstack-node/register`。如果您对应用程序进行打包，请将 SDK 及已插桩的依赖项设为外部依赖 (external) ，不要打包进产物中。

您可以继续使用 NestJS 的默认控制台日志记录器。如需使用自定义日志记录器，请选用受支持的集成，例如 Winston 或 Pino。有关配置和兼容性的详细信息，请参阅 [Node.js 指南](/zh/clickstack/ingesting-data/sdks/nodejs)。

## 验证摄取 {#verify-ingestion}

向某个控制器发送请求，并输出一条日志消息。在 ClickStack 中选择最近的时间范围，然后在 Logs 和 Traces 中查找您应用程序的服务名称。等待数据导出完成后，再查看 Metrics。
