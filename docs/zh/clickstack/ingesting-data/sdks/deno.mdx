借助 Deno 内置的 OpenTelemetry 支持，即可将日志、指标和链路追踪发送到 ClickStack，无需使用 ClickStack Node.js SDK 或旧版 Deno 日志软件包。

## 设置 OpenTelemetry {#set-up-opentelemetry}

请按照 Deno 官方的 [Deno OpenTelemetry 设置指南](https://docs.deno.com/runtime/fundamentals/open_telemetry/)对应用程序进行插桩。先配置下方的目标端，然后在启动应用程序时启用 Deno 内置的集成：

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

添加应用程序所需的权限。替换上游说明中的所有示例目标端和控制台导出器设置，包括针对特定信号的端点覆盖配置。

## 配置目标端 {#configure-destination}

为 ClickStack 采集器设置 OTLP HTTP 端点和摄取密钥。如果采集器未配置 TLS，请使用 `http://`。有关采集器的设置方法，请参阅[使用 OpenTelemetry 摄取数据](/zh/clickstack/ingesting-data/opentelemetry)。

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## 验证摄取 {#verify-ingestion}

启动应用程序并产生一些活动。在 ClickStack 中选择最近的时间范围，然后在 日志 或 链路追踪 中查找应用程序的服务名称。稍等片刻待数据导出完成后，再查看 指标。
