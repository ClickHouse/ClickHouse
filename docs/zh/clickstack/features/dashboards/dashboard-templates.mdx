ClickStack 包含一个预置的仪表板模板库，可让您立即了解常见的基础设施和应用程序指标。

## 浏览可用模板 {#browsing-templates}

要浏览内置模板库，请进入 **仪表盘**，然后点击 **浏览仪表板模板**。

<div className="ch-image-lg">
  <Frame>
    ![浏览仪表板模板按钮](/images/use-cases/observability/browse-dashboard-template.webp)
  </Frame>
</div>

这会打开模板库，模板按类别分类显示。点击 **Import** 即可开始导入该模板。

<div className="ch-image-lg">
  <Frame>
    ![仪表板模板库](/images/use-cases/observability/dashboard-template-gallery.webp)
  </Frame>
</div>

## 导入模板 {#importing-a-template}

要导入模板，必须为仪表盘中的每个可视化项设置数据源。请在每个可视化项的下拉菜单中选择一个数据源，然后点击 `Finish Import`。

<div className="ch-image-lg">
  <Frame>
    ![仪表板模板导入](/images/use-cases/observability/import-dashboard-template.webp)
  </Frame>
</div>

### OTel 运行时指标 {#otel-runtime-metrics}

内置的 OTel 运行时指标模板专为通过 [OpenTelemetry 运行时指标](https://opentelemetry.io/docs/specs/semconv/runtime/) 插桩的应用程序而设计。

| 模板                          | 描述                                         |
| --------------------------- | ------------------------------------------ |
| **.NET Runtime Metrics**    | .NET 应用程序的 GC 回收次数、堆大小、线程池使用情况和程序集数量       |
| **Go Runtime Metrics**      | Go 应用程序的 Goroutine 数量、GC 暂停时间、堆使用情况和内存统计信息 |
| **JVM Runtime Metrics**     | 基于 JVM 的应用程序的堆内存与非堆内存、GC 耗时、线程数量和类加载情况     |
| **Node.js Runtime Metrics** | Node.js 应用程序的事件循环延迟、堆使用情况、CPU 利用率和 V8 内存   |

注意：

* 每个模板都配置了一个[自定义筛选器](/zh/clickstack/features/dashboards/overview#custom-filters)，用于筛选 [`telemetry.sdk.language`](https://opentelemetry.io/docs/specs/semconv/registry/attributes/telemetry/#telemetry-sdk-language) 资源属性与该仪表盘对应运行时相匹配的服务。
  * 如果环境使用了自定义的 ClickHouse 指标表 schema，可能需要调整此筛选器，使其查询正确的服务名称列和资源属性列。
  * 在数据量较大的环境中，可以通过[物化](/zh/clickstack/managing/performance-tuning#materialize-frequently-queried-attributes) `ResourceAttributes['telemetry.sdk.language']` 列来缩短筛选器的加载时间。
* 模板在发布时会引用最新的 OTel 语义约定，并随 OTel 规范的更新而定期更新。对于使用较旧版本 OTel SDK 插桩的服务，可能需要[编辑](/zh/clickstack/features/dashboards/overview#dashboards-editing-visualizations)可视化，改为引用旧的指标名称。
