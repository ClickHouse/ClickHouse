ClickHouse Observability — 自行管理完全运行在 **ClickHouse Cloud** 中，在提供全托管可观测性后端的同时，保留了相同的 ClickStack 数据模型和用户体验。

在此模式下，**ClickHouse 和 ClickStack 用户界面**由 ClickHouse Cloud 负责托管、运维和安全防护。用户只需运行一个 **OpenTelemetry (OTel) 收集器**，将遥测数据发送到该托管服务即可。

### ClickHouse Cloud：核心引擎 {#clickhouse-cloud}

ClickHouse Observability — 自行管理的核心是 ClickHouse Cloud，即 ClickHouse 的无服务器版本。ClickHouse 是一款专为大规模实时分析而设计的列式数据库，为可观测性数据的摄取和查询提供支撑，能够实现：

* 在 TB 级事件数据中进行 sub-second 搜索
* 每天摄取数十亿条 high-cardinality 记录
* 对可观测性数据实现至少 10 倍的压缩率
* 原生支持半结构化 JSON 数据，支持动态模式演进
* 强大的 SQL 引擎，内置数百个分析函数

ClickHouse Cloud 将可观测性数据作为宽事件处理，从而能够在统一的结构中对日志、指标和链路追踪进行深度关联。

相较于 ClickHouse 开源版，它还为可观测性带来了诸多优势：

* 计算资源独立于存储自动扩缩容
* 基于对象存储，以低成本实现几乎无限的数据保留
* 可通过仓库[独立隔离读写工作负载](/zh/clickstack/self-configured/managing/isolating-read-write)。
* 集成身份验证
* 自动备份
* 安全与合规功能
* 无缝升级

### OpenTelemetry 收集器：数据摄取 {#open-telemetry-collector-managed}

ClickHouse Observability — 自行管理包含一个预配置的 OpenTelemetry (OTel) 收集器，以开放、标准化的方式摄取遥测数据。您可以通过以下方式使用 OTLP 协议发送数据：

* gRPC (端口 `4317`)
* HTTP (端口 `4318`)

该收集器以高效的批次将遥测数据导出到 ClickHouse Cloud。它为每个数据源提供经过优化的表结构，确保所有信号类型均具备可扩展的性能。

**该架构组件由用户自行管理**

### ClickStack 用户界面：交互界面 {#hyperdx}

ClickStack 用户界面是 ClickStack 的前端界面，提供以下功能：

* 自然语言搜索和 Lucene 风格搜索
* 实时追踪 (Live tailing) ，便于实时调试
* 日志、指标和链路追踪的统一视图
* 会话回放，实现前端可观测性
* 创建仪表盘和配置告警
* SQL 查询接口，支持高级分析

ClickStack 用户界面专为 ClickHouse 打造，将强大的搜索能力与直观的工作流相结合，助您快速发现异常、排查问题并获取洞察。

在 ClickHouse Observability — 自行管理版本中，该 UI 已集成到 ClickHouse Cloud 控制台的身份验证系统中。
