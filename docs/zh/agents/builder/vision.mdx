视觉功能可让用户上传图像，交由 agent 进行分析。agent 会将图像传给支持视觉的模型，由模型描述或总结图像内容，或回答与图像内容相关的问题。

## 启用视觉能力 {#enable-it}

视觉功能仅适用于支持图像输入的模型。如果所选模型无法处理图像输入，消息编辑器中的上传控件将处于禁用状态。切换到支持视觉的模型即可重新启用该控件。

## 使用视觉能力 {#use-it}

点击消息编辑器左下角的回形针图标，选择 **Upload to Provider** 来附加图片，例如截图、照片、图表或示意图。然后就可以提出任何需要读取图片内容的问题，例如：*“这个查询计划有什么问题？”*、*“转录这张截图中的文字”* 或 *“将这个仪表盘与上周的对比一下。”*

agent 会将图片视为消息上下文的一部分，因此同一轮次中的后续问题可以直接引用其中的内容，无需重新上传。

## 将视觉与其他工具结合使用 {#combine-with-other-tools}

视觉与[代码解释器](/zh/agents/builder/code-interpreter)搭配使用，可实现基于图像的分析——例如，agent 先从截图中读取数值，再运行 Python 计算总和；当图像中涉及模型需要查询的内容时，还可以将其与[网页搜索](/zh/agents/builder/web-search)结合使用。
