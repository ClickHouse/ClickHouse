借助图像生成功能，agent 可以根据文本提示词生成新图像，也可以编辑用户上传的图像。agent 会根据用户的请求和可用的上下文，自行决定执行生成还是编辑操作。

## 启用图像生成 {#enable-it}

图像生成需通过agent构建器中的 **Add Tools** 弹窗添加 (而非 Capabilities 部分) 。点击agent构建器面板底部的 **Add Tools**，然后添加任一图像模型工具，例如 **OpenAI Image Tools**、**DALL-E-3** 或 **Stable Diffusion**。agent会根据请求选择合适的工具，你也可以在指令中加以限制。

## 生成 {#generation}

当用户请求生成图像时，agent 会携带提示词调用生成工具，并以内联方式返回生成的图像。agent 会在其上下文中保留对该图像的引用，以便在同一对话中对其进行描述或复用。

## 编辑 {#editing}

如果用户上传一张图像并要求修改 (例如更改颜色、添加对象或扩展构图) ，agent 会调用该工具的编辑变体。生成结果会按要求替换相应区域，或对源图像进行扩展。

## 说明 {#notes}

* 生成的图像不会被自动送去做单独的视觉分析。如需让agent*解读*图像，请对用户上传的图像使用[视觉](/zh/agents/builder/vision)功能。
* 提供商的内容策略同样适用。违反提供商策略的提示词会返回错误，而不会生成图像。
