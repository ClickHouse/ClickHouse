模型参数用于控制智能体使用哪个模型，以及该模型如何生成响应。
在 **智能体构建器** 选项卡中，点击 **模型** 标题下方的 **选择模型**，
即可打开 **模型参数** 窗口。

## 提供商和模型 {#provider-and-model}

* **提供商** - 选择上游 LLM 提供商。
* **模型** - 选择该提供商下的具体模型。不同模型各有所长：大型推理模型适合规划密集型任务，速度更快的小型模型则适合常规查询。

**提供商**和**模型**均为必填项。面板中的其余选项会根据所选模型支持的功能自动调整。

## 上下文与输出限制 {#context-and-output-limits}

* **Max Context 标记** - 限制智能体发送给模型的上下文总量。保留为 **System** 即使用模型的默认值。调低可降低成本；如果智能体需要基于大量输入进行推理，则可调高。
* **Max Output 标记** - 限制智能体响应的长度。**System** 表示使用模型的默认值。如果响应过长，可将其调低；如果响应被截断，则可调高。
* **File Token Limit** - 限制单个上传文件在上下文中可占用的标记数。当用户附加大文件，而您不希望这些文件挤占对话中其他内容的空间时，此设置非常有用。

## 采样 {#sampling}

* **Temperature (温度)&#x20;**&#x20;- 控制随机性。较高的值 (0.7–1.0) 使输出更随机，较低的值 (0.0–0.3) 则使输出更集中、更具确定性。建议只调整该参数或 Top P 其中之一，不要同时调整两者。
* **Top P** - 核采样 (nucleus sampling) 。改变模型选择输出 标记 的方式。
* **Top K** - 在每一步中将采样范围限制为可能性最高的前 K 个 标记。部分提供商支持该参数；它从不同于温度的维度控制输出的确定性。

如果您并非针对特定行为进行调优，请将滑块保持在默认值附近：小幅调整通常收效甚微，而大幅调整则可能降低输出质量。

## 推理控制 {#reasoning-controls}

适用于支持扩展推理的模型。具体可用的选项因提供商而异。

* **思考** - 用于开启或关闭模型的扩展推理模式。开启后，模型会在给出最终答案之前先生成内部思考标记；这通常能提高复杂任务的准确性，但会增加延迟和标记消耗。
* **思考预算** - 为思考阶段设置标记预算。模型消耗完该数量的标记后，会停止思考并给出答案。
* **推理强度** - 推理强度的总体调节项 (**自动**、低、中、高) 。适用于不直接提供思考标记预算的推理模型。
* **思考可见性** - 用于控制模型的思考内容是以内联方式向用户展示、收起在折叠视图中，还是完全不显示。

## 对话行为 {#conversation-behavior}

* **Resend Files** - 开启后，之前轮次中附加的文件会在后续每个轮次中重新发送，以免模型遗漏这些文件。如果对话较短，或模型会在对话过程中逐步总结文件内容，可关闭此选项以节省 标记。
* **Use 提示缓存** - 在提供商支持的情况下，缓存提示词中可复用的部分；当指令和工具描述在多个轮次中重复出现时，可降低对话的成本和延迟。
* **网页搜索** - 在受支持的模型上开启或关闭提供商原生的网页搜索功能。它不同于[网页搜索工具](/zh/agents/builder/web-search)：后者是作为智能体的工具之一运行的，而非提供商自身的能力。

## 重置 {#reset}

面板底部的**重置模型参数**按钮会将所有字段恢复为系统默认值。如果您已尝试过多种配置，想从头开始，可以使用此功能。
