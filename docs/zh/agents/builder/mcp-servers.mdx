Model Context Protocol (MCP) 是一种开放标准，用于向 AI 模型提供工具和数据源。为 ClickHouse 智能体附加 MCP 服务器后，该智能体即可使用该服务器提供的所有功能，例如议题跟踪系统、可观测性后端、内部 API、第三方 SaaS，以及其他任何提供 MCP 端点的服务。

## 附加 MCP 服务器 {#attach-an-mcp-server}

在智能体构建器中，打开 **MCP 服务器** 部分，然后点击 **添加服务器**。输入该服务器的 URL 和身份验证设置，再选择要让此智能体使用该服务器上的哪些工具。最后保存智能体。

一个智能体可以附加多个服务器。智能体每次调用工具都会记录到对话中，便于用户了解智能体执行了哪些操作。

## 传输方式 {#transport}

ClickHouse 智能体采用 Streamable HTTP，即 production-grade 的 MCP 传输方式。您附加的服务器必须能够从 ClickHouse Cloud 通过 HTTP(S) 访问。

## 身份验证 {#authentication}

MCP 服务器可能需要凭证。智能体 支持以下几种方式：

* **Bearer 令牌**及其他静态请求头：在配置服务器时提供的固定值。
* **OAuth 2.0**：交互式流程。您 (或任何具有访问权限的用户) 首次调用该服务器上的工具时，浏览器会打开登录窗口；令牌会自动管理和刷新。
* **Per-user 凭证**：服务器 config 中的变量会根据调用方用户的 profile 进行替换，从而让每个用户都以自己的身份进行身份验证，而不是共用一个服务账号。

用户提供的凭证会加密存储，且仅限输入该凭证的用户使用。其他用户的智能体运行过程永远无法看到某个用户的凭证。

## 限制 {#limits}

单次智能体运行在每个请求中最多可引用 50 个不同的 MCP 服务器目标，以及最多 100 个展开后的工具配置。如需超出上述限制，应使用[子智能体](/zh/agents/builder/subagents)对智能体进行拆分。
