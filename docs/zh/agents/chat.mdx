## 对话 {#conversations}

点击左侧导航中的撰写图标，即可开始新对话。
在对话窗口左上角的 Agent 选择器对话框中，选择要使用的 agent——默认选中 **ClickHouse 智能体**。
随后即可在输入框中输入消息并点击发送。每个对话都会保存在侧边栏的历史记录中，之后可以重新打开、重命名或删除。

  </Frame>

您可以直接编辑自己发送的任意一条消息，agent 会从会话历史中的该位置起重新生成响应。
您也可以只重新生成 agent 的最后一条响应，而无需重新发送消息。

## 书签 {#bookmarks}

可以为单条消息或整个对话添加书签，以便日后快速查找。书签仅对您本人可见，即使对话被重命名也会保留。

## 置顶对话 {#pinned-conversations}

置顶对话后，该对话会固定显示在侧边栏顶部，与下方按日期分组的历史记录分开。在侧边栏中打开该对话的选项菜单 (三点图标) ，然后选择 **Pin**。所有置顶对话都会集中显示在 **Pinned** 分组中，位于 **Today**、**Yesterday** 及更早的分组上方。

如需取消置顶，请打开同一菜单并选择 **Unpin**。

## 分支 {#forking}

分支功能可从某条特定消息开始创建一个新对话。您可以借此探索其他路径，而不会影响原始对话。
共有三种分支模式可供选择：

* **仅可见消息** - 复制通往分支起始消息的直接路径。
* **包含相关分支** - 复制主路径以及所有已有分支。
* **包含截至此处的全部内容** - 复制分支起始消息之前的全部内容。

分支对话相互独立，其中的更改不会同步回原始对话。

## 共享聊天 {#sharing-chats}

您可以为任意对话生成共享链接，发送给团队成员或保存下来以备参考。接收者看到的是只读视图，其中包括制品和可见的分支。您可以随时在共享仪表盘中撤销链接。

对已有消息所做的编辑会同步显示在共享视图中；生成链接后新增的消息则不会显示。

任何查看共享链接的人都可以点击 **Continue this chat**，在自己的账户中继续该对话。此操作会将该对话 (包括其正在查看的分支) 复制到其历史记录中，作为一个新的私有对话，您的原始对话不受影响。

要共享对话，请在侧边栏中打开该对话的菜单，然后选择 **共享**：

## 键盘快捷键 {#keyboard-shortcuts}

按 `Cmd+Shift+/` (Windows 和 Linux 上为 `Ctrl+Shift+/`) 即可打开键盘快捷键参考，也可以在账户菜单中依次选择 **帮助** → **键盘快捷键** 打开。所有快捷键均可自定义：在对话框中点击某一行即可录制新的组合键；如需撤销更改，请使用 **全部重置为默认值**。

默认快捷键如下：

| 操作        | macOS                 | Windows 和 Linux        |
| --------- | --------------------- | ---------------------- |
| 显示键盘快捷键   | `Cmd+Shift+/`         | `Ctrl+Shift+/`         |
| 新建聊天      | `Cmd+Shift+O`         | `Ctrl+Shift+O`         |
| 聚焦聊天输入框   | `Shift+Esc`           | `Shift+Esc`            |
| 上传文件      | `Cmd+Shift+U`         | `Ctrl+Shift+U`         |
| 复制最后一条响应  | `Cmd+Shift+;`         | `Ctrl+Shift+;`         |
| 发送消息      | `Cmd+Enter`           | `Ctrl+Enter`           |
| 显示/隐藏侧边栏  | `Cmd+Shift+S`         | `Ctrl+Shift+S`         |
| 打开模型选择器   | `Cmd+Shift+M`         | `Ctrl+Shift+M`         |
| 聚焦搜索框     | `Cmd+/`               | `Ctrl+/`               |
| 打开设置      | `Cmd+Shift+,`         | `Ctrl+Shift+,`         |
| 为对话添加书签   | `Cmd+Shift+B`         | `Ctrl+Shift+B`         |
| 停止生成      | `Cmd+Shift+X`         | `Ctrl+Shift+X`         |
| 重新生成响应    | `Cmd+Shift+E`         | `Ctrl+Shift+E`         |
| 编辑最后一条消息  | `Cmd+Shift+I`         | `Ctrl+Shift+I`         |
| 继续生成响应    | `Cmd+Shift+C`         | `Ctrl+Shift+C`         |
| 复制最后一个代码块 | `Cmd+Shift+K`         | `Ctrl+Shift+K`         |
| 滚动到顶部     | `Cmd+Shift+Up`        | `Ctrl+Shift+Up`        |
| 滚动到底部     | `Cmd+Shift+Down`      | `Ctrl+Shift+Down`      |
| 归档对话      | `Cmd+Shift+L`         | `Ctrl+Shift+L`         |
| 删除对话      | `Cmd+Shift+Backspace` | `Ctrl+Shift+Backspace` |

你还可以为agent、提示词、文件和书签等面板分配自定义快捷键，这些面板默认未设置快捷键。
