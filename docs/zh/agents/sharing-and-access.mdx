Agents 采用分层权限模型：角色决定用户可以使用哪些功能，资源级访问列表决定谁可以使用特定的 agent 或其他资源，而 Admin 权限则决定由谁来统筹管理所有内容。

## 角色 {#roles}

角色是分配给一个或多个用户的一组功能权限。默认角色如下：

* **用户** - 可以运行agent并进行聊天。能否构建agent、创建技能、共享资源等，取决于其角色中各项功能的开关设置。
* **管理员** - 拥有用户角色的全部权限，并具备组织级控制能力：管理用户、配置市场、授予权限。

管理员可以创建自定义角色，并为其单独设置开关，从而实现更细粒度的控制。

## 资源共享 {#resource-sharing}

agent、提示词和技能各自都有一个访问列表。每个主体可被授予以下三种访问级别之一：

* **查看者** - 可以使用该资源，但无法修改。
* **编辑者** - 可以更改该资源的配置 (指令、已附加的工具、模型等) 。
* **所有者** - 拥有编辑者的全部权限，还可以删除该资源或更改其共享设置。

创建资源后，您默认是该资源的所有者。未明确共享的资源仅对您本人可见。

## 主体 {#principals}

您可以向以下对象授予访问权限：

* **单个用户** - 逐个用户授予。
* **用户组** - 团队或组织单元。之后如有用户加入或离开该组，其访问权限会自动更新。
* **组织范围内** - 组织中的所有人都能看到该资源。前提是角色级别的相应开关允许此操作。

只有在组织范围内可见的资源，才能在[市场](/zh/agents/marketplace)中被发现。

## 共享agent {#share-an-agent}

点击agent构建器底部的 **共享** 图标。图标上的徽章会显示当前拥有访问权限的用户或组的数量。

随即会打开 **共享** 弹窗。按名称或电子邮件搜索用户或组，选择访问级别 (**查看者**、**编辑者** 或 **所有者**) ，然后点击 **保存更改**。如需在组织范围内共享，请打开 **Share with everyone in ClickHouse** 开关。

接收者下次刷新后，即可在其可用agent列表中看到该agent。如需撤销访问权限，请在同一弹窗中删除对应的行。接收者将立即失去访问权限；正在进行中的对话可以继续完成，但无法再打开新的对话。

## 默认 agent {#default-agent}

您可以将某个 agent 设为默认 agent。新建对话时将默认使用该 agent，除非您另行选择。管理员还可以设置组织级默认 agent，供尚未自行选择的用户使用。

## 管理员操作 {#admin-operations}

仅限管理员执行的操作包括：

* 创建和编辑角色。
* 配置市场类别并挑选推荐的agent。
* 在组织级别启用或禁用功能 (记忆、网页搜索、代码解释器、市场等) 。
* 向其他用户授予 Admin 权限。

在 ClickHouse Cloud 中，管理面板仅对组织管理员开放。如果您看不到该面板，请联系您的组织管理员或 ClickHouse Cloud 支持团队申请访问权限。

## 注意事项 {#gotchas}

* **删除agent会使其所有共享失效。** 接收者将失去访问权限；他们与该agent的已保存对话仍可查看，但无法继续。
* **编辑已共享的agent会影响所有使用者。** 如需试验而不影响他人，请使用副本。
* **撤销用户的角色不会删除其创建的资源。** 该用户的agent、提示词和技能仍保留在其访问列表中；在完全移除该用户之前，请先转移所有权。
