在 Cloud 控制台中构建自定义智能体，并对您的服务运行自然语言查询。

## 前置条件 {#prerequisites}

* 一个可执行查询的 ClickHouse Cloud 服务。
* 智能体构建器中可使用 **创建智能体** 选项。如果没有该选项，请联系组织管理员在“管理设置”中授予创建智能体的权限，详见[共享与访问](/zh/agents/sharing-and-access)。

## 构建智能体 {#build-the-agent}

<Steps>
  <Step title="启动 ClickHouse 智能体" id="launch-agents">
    在您的云服务中，点击左侧边栏中的 **ClickHouse 智能体**，打开智能体启动页。点击 **Launch ClickHouse 智能体** 打开智能体构建器。

    <div className="ch-image-lg">
      <Frame>
        ![云服务导航中已选中 ClickHouse 智能体 (Beta)，显示带有 Launch ClickHouse 智能体 按钮的启动页](/images/cloud/agent-builder/launch-ch-agents.webp)
      </Frame>
    </div>
  </Step>

  <Step title="创建智能体" id="create-the-agent">
    在智能体构建器中，点击左侧面板顶部的 **Create New Agent**，然后填写以下核心字段：

    * **Name** - 智能体的简短标识名称。
    * **Description** - 说明智能体的用途，团队成员均可查看。
    * **Category** - 智能体的类别。除非您的组织设置了自定义类别，否则保留默认值 `General` 即可。
    * **Instructions** - 即系统提示，用于描述智能体的角色、需要回答的问题以及必须遵循的业务规则。
    * **Model** - 从下拉列表中选择一个模型。

    <div className="ch-image-lg">
      <Frame>
        ![智能体构建器面板，显示 Create New Agent 下拉列表、表单字段（Name、Description、Category、Instructions、Model）以及 Capabilities 部分](/images/cloud/agent-builder/agent-builder.webp)
      </Frame>
    </div>
  </Step>

  <Step title="附加能力和工具" id="attach-tools">
    智能体的能力和工具分布在两个位置。

    **Capabilities** 位于主面板中，包含第一方功能，例如 [Run Code](/zh/agents/builder/code-interpreter)、[Web Search](/zh/agents/builder/web-search)、File Context、Artifacts、[MCP Servers](/zh/agents/builder/mcp-servers) 和 [Skills](/zh/agents/builder/skills)。按需打开相应功能的开关即可。

    <div className="ch-image-sm">
      <Frame>
        ![智能体构建器面板的 Capabilities 部分，显示 Run Code、Web Search、File Context、Artifacts、MCP Servers 和 Skills 开关](/images/cloud/agent-builder/capabilities.webp)
      </Frame>
    </div>

    **Tools** 需通过面板底部的 **Add Tools** 按钮添加，包含第三方集成，例如[图像生成](/zh/agents/builder/image-generation)、[视觉](/zh/agents/builder/vision)、搜索 API 以及外部服务。

    <div className="ch-image-sm">
      <Frame>
        ![智能体构建器面板底部，Add Tools 按钮已高亮显示](/images/cloud/agent-builder/tools-button.webp)
      </Frame>
    </div>

    点击 **Add Tools** 浏览工具目录：

    <div className="ch-image-lg">
      <Frame>
        ![Agent Tools 弹窗，以网格形式显示第三方集成，包括 Google、OpenAI Image Tools、Wolfram、DALL-E-3、Tavily Search、Calculator 和 Stable Diffusion](/images/cloud/agent-builder/tools-modal.webp)
      </Frame>
    </div>

    [子智能体](/zh/agents/builder/subagents)在 **Advanced settings** 中配置，详情请参阅子智能体页面。

    已附加的能力和工具可随时更改。
  </Step>

  <Step title="运行查询" id="run-a-query">
    保存智能体，新建一个对话，然后在智能体选择器中选择您的智能体。输入问题，例如 *“本周行数排名前 10 的表有哪些？”*，智能体会规划步骤、按需调用工具并返回答案。

    <div className="ch-image-lg">
      <Frame>
        ![聊天记录，显示问题“What are my top 10 tables by row count this week?”以及智能体的回答：一个按行数列出各服务中前 10 张表的 Markdown 表格，下方附有 Key Observations](/images/cloud/agent-builder/chat-query.webp)
      </Frame>
    </div>
  </Step>
</Steps>

## 后续步骤 {#next-steps}

* 与团队成员[共享该智能体](/zh/agents/sharing-and-access)。
* 该智能体达到稳定版本后，可将其发布到[市场](/zh/agents/marketplace)。
