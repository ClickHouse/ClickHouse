借助智能体，您可以通过对话查询和探索 ClickHouse 数据，无需自行编写 SQL 或编排逻辑。
智能体会理解您的意图、规划步骤、调用您已配置的工具，并将结果返回给您。
此功能目前处于 Beta 阶段；在正式可用之前，其行为和能力可能会有所变化。

## 功能概览 {#what-you-can-do}

借助智能体，您可以：

* 无需编写代码即可构建自定义智能体：编写指令、选择模型并附加工具。
* 基于您的 ClickHouse 服务进行对话，智能体会按需调用工具。
* 与团队成员共享您的智能体，或将其发布到市场。
