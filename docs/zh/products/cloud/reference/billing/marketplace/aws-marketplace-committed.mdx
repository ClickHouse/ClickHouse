通过 [AWS Marketplace](https://aws.amazon.com/marketplace) 的承诺合同开始使用 ClickHouse Cloud。
承诺合同 (也称为专属报价) 允许客户承诺在一段时间内为 ClickHouse Cloud 支出一定金额。

<div id="prerequisites">
  ## 前置条件 {#prerequisites}
</div>

* 一份来自 ClickHouse、基于特定合同条款的 专属报价。
* 要将 ClickHouse 组织关联到您的承诺消费优惠，您必须是该组织的管理员。

在 AWS 中查看并接受您的承诺合同所需的权限：

* 如果您使用 AWS 托管策略，则必须具备以下权限：
  * `AWSMarketplaceRead-only`、`AWSMarketplaceManageSubscriptions`
  * 或 `AWSMarketplaceFullAccess`
* 如果您未使用 AWS 托管策略，则必须具备以下权限：
  * IAM 操作 `aws-marketplace:ListPrivateListings` 和 `aws-marketplace:ViewSubscriptions`

## 注册步骤 {#steps-to-sign-up}

<Steps>
  <Step title="接受您的专属报价" id="private-offer-accept">
    您应该已收到一封电子邮件，其中包含用于查看并接受专属报价的链接。

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace 专属报价电子邮件](/images/cloud/reference/mp_committed_spend_1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="打开查看报价链接" id="review-offer-link">
    点击电子邮件中的 Review Offer 链接。
    随后将进入 AWS Marketplace 页面，其中显示专属报价的详细信息。
  </Step>

  <Step title="设置你的账户" id="setup-your-account">
    在 AWS 门户上完成订阅步骤，然后点击 **“设置你的账户”**。
    此时务必跳转到 ClickHouse Cloud，注册新账户或使用现有账户登录。
    如果未完成此步骤，我们将无法把您的 AWS Marketplace 合同关联到 ClickHouse Cloud。

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace 专属报价电子邮件](/images/cloud/reference/mp_committed_spend_2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="登录 Cloud" id="login-cloud">
    跳转到 ClickHouse Cloud 后，您可以使用现有账户登录，或注册新账户。
    必须完成此步骤，我们才能将您的 ClickHouse Cloud 组织绑定到 AWS Marketplace 计费。

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace 专属报价电子邮件](/images/cloud/reference/mp_committed_spend_3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="新用户请注册" id="register">
    如果您是 ClickHouse Cloud 新用户，请点击页面底部的 “Register”。
    系统将提示您创建新用户并验证电子邮件。
    验证电子邮件后，您可以离开 ClickHouse Cloud 登录页面，前往 [https://console.clickhouse.cloud](https://console.clickhouse.cloud) 使用新用户名登录。

    请注意，新用户还需要提供一些有关您业务的基本信息，
    如以下截图所示。

    <div className="ch-image-md">
      <Frame>
        ![提供业务信息](/images/cloud/reference/mp_committed_spend_4.png)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![提供业务信息](/images/cloud/reference/mp_committed_spend_5.png)
      </Frame>
    </div>

    如果您是 ClickHouse Cloud 现有用户，只需使用您的凭证登录即可。
  </Step>

  <Step title="创建或选择要计费的组织" id="create-select-org-to-bill">
    成功登录后，您可以新建一个组织，或选择一个现有组织，将其费用计入此云市场合同。

    <div className="ch-image-md">
      <Frame>
        ![创建或选择要通过此订阅计费的组织](/images/cloud/reference/mp_committed_spend_6.webp)
      </Frame>
    </div>

    完成此步骤后，您的组织将关联到您的 AWS 承诺消费合同，所有用量都将通过您的 AWS 账户计费。
    您可以在 ClickHouse UI 中该组织的账单页面上确认计费已成功关联到 AWS Marketplace。

    <div className="ch-image-md">
      <Frame>
        ![确认设置已完成](/images/cloud/reference/mp_committed_spend_7.webp)
      </Frame>
    </div>

    如果遇到任何问题，请随时联系我们的[支持团队](https://clickhouse.com/support/program)。
  </Step>
</Steps>
