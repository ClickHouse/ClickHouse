通过 [AWS Marketplace](https://aws.amazon.com/marketplace) 的 PAYG (按使用量付费) 公开优惠，开始使用 ClickHouse Cloud。

<div id="prerequisites">
  ## 前置条件 {#prerequisites}
</div>

* 一个已由您的计费管理员授予购买权限的 AWS 账户。
* 要完成购买，您必须使用此账户登录 AWS Marketplace。
* 要将 ClickHouse 组织连接到您的订阅，您必须是该组织的管理员。

## 注册步骤 {#steps-to-sign-up}

<Steps>
  <Step title="搜索 ClickHouse Cloud - Pay as you go" id="search-payg">
    前往 [AWS Marketplace](https://aws.amazon.com/marketplace)，搜索“ClickHouse Cloud - Pay As You Go”。

    <div className="ch-image-lg">
      <Frame>
        ![在 AWS Marketplace 中搜索 ClickHouse](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="查看购买选项" id="purchase-options">
    点击该[产品页面](https://aws.amazon.com/marketplace/pp/prodview-p4gwofrqpkltu)，然后点击 **查看购买选项**。

    <div className="ch-image-lg">
      <Frame>
        ![在 AWS Marketplace 中查看购买选项](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="订阅" id="subscribe">
    在下一个页面中，点击订阅。

    <div className="ch-image-lg">
      <Frame>
        ![在 AWS Marketplace 中订阅](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="设置你的账户" id="set-up-your-account">
    此时设置尚未完成，你的 ClickHouse Cloud 组织还未通过云市场计费。接下来，你需要在 Marketplace 订阅中点击设置你的账户，跳转到 ClickHouse Cloud 完成设置。

    <div className="ch-image-lg">
      <Frame>
        ![设置你的账户](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-4.webp)
      </Frame>
    </div>

    跳转到 ClickHouse Cloud 后，你可以使用现有账户登录，也可以注册新账户。这一步至关重要，我们需要借此将你的 ClickHouse Cloud 组织与 AWS Marketplace 计费绑定。

    <Info>
      **ClickHouse Cloud 新用户**

      如果你是 ClickHouse Cloud 新用户，请按照以下步骤操作。
    </Info>

    <Accordion title="新用户步骤">
      如果你是 ClickHouse Cloud 新用户，请点击页面底部的 Register。系统会提示你创建新用户并验证电子邮件。验证完成后，你可以离开 ClickHouse Cloud 登录页面，前往 https://console.clickhouse.cloud 使用新用户名登录。

      <div className="ch-image-md">
        <Frame>
          ![ClickHouse Cloud 注册](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-5.webp)
        </Frame>
      </div>

      <Info>
        **新用户**

        你还需要提供一些关于你公司业务的基本信息，请参见下方截图。
      </Info>

      <div className="ch-image-md">
        <Frame>
          ![开始之前](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
        </Frame>
      </div>

      <div className="ch-image-md">
        <Frame>
          ![开始之前（续）](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
        </Frame>
      </div>
    </Accordion>

    如果你是 ClickHouse Cloud 现有用户，直接使用你的凭证登录即可。
  </Step>

  <Step title="将 Marketplace 订阅添加到组织" id="add-marketplace-subscription">
    登录成功后，你可以选择新建一个组织，或选择一个现有组织，并通过此 Marketplace 订阅进行计费。

    <div className="ch-image-lg">
      <Frame>
        ![添加 Marketplace 订阅](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
      </Frame>
    </div>

    如果你正在注册新的 ClickHouse 账户，系统会自动为你创建一个默认组织，你可以将 Marketplace 订阅关联到该组织。

    <div className="ch-image-lg">
      <Frame>
        ![将默认组织关联到 AWS Marketplace 订阅](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-13.webp)
      </Frame>
    </div>

    完成此步骤后，你的组织将关联到该 AWS 订阅，所有用量都将通过你的 AWS 账户计费。

    你可以在 ClickHouse UI 中该组织的账单页面上确认计费已关联到 AWS Marketplace。

    <div className="ch-image-lg">
      <Frame>
        ![确认账单页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-9.webp)
      </Frame>
    </div>
  </Step>
</Steps>
