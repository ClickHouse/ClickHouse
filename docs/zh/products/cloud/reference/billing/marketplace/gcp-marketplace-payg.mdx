通过 [GCP Marketplace](https://console.cloud.google.com/marketplace) 上的 PAYG (按使用量付费) 公开优惠开始使用 ClickHouse Cloud。

<div id="prerequisites">
  ## 前置条件
</div>

* 由您的计费管理员授予购买权限的 GCP 项目。
* 要在 GCP Marketplace 订阅 ClickHouse Cloud，您必须使用具有购买权限的账户登录，并选择相应的项目。

<div id="steps-to-sign-up">
  ## 注册步骤
</div>

1. 前往 [GCP Marketplace](https://cloud.google.com/marketplace) 并搜索 ClickHouse Cloud。请确保已选择正确的项目。

<div className="ch-image-md">

<Frame>

![GCP Marketplace 首页](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-1.webp)

</Frame>

</div>

2. 点击该[产品页面](https://console.cloud.google.com/marketplace/product/clickhouse-public/clickhouse-cloud)，然后点击 **Subscribe**。

<div className="ch-image-md">

<Frame>

![GCP Marketplace 中的 ClickHouse Cloud](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-2.webp)

</Frame>

</div>

3. 在下一个页面中，配置订阅：

* 方案默认是“ClickHouse Cloud”
* 订阅周期为“Monthly”
* 选择合适的计费账户
* 接受条款并点击 **Subscribe**

<br />

<div className="ch-image-sm">

<Frame>

![在 GCP Marketplace 中配置订阅](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-3.webp)

</Frame>

</div>

<br />

4. 点击 **Subscribe** 后，您会看到一个 **Sign up with ClickHouse** 弹窗。

<br />

<div className="ch-image-md">

<Frame>

![GCP Marketplace 注册弹窗](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-4.webp)

</Frame>

</div>

<br />

5. 请注意，此时设置流程尚未完成。您需要点击 **Set up your account** 跳转到 ClickHouse Cloud，并在 ClickHouse Cloud 上完成注册。

6. 跳转到 ClickHouse Cloud 后，您可以使用现有账户登录，或者注册一个新账户。此步骤非常重要，因为我们需要将您的 ClickHouse Cloud 组织绑定到 GCP Marketplace 计费。

<br />

<div className="ch-image-md">

<Frame>

![ClickHouse Cloud 登录页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)

</Frame>

</div>

<br />

如果您是 ClickHouse Cloud 新用户，请点击页面底部的 **Register**。系统会提示您创建新用户并验证邮箱。完成邮箱验证后，您可以离开 ClickHouse Cloud 登录页面，然后使用新的用户名在 [https://console.clickhouse.cloud](https://console.clickhouse.cloud) 登录。

<br />

<div className="ch-image-md">

<Frame>

![ClickHouse Cloud 注册页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)

</Frame>

</div>

<br />

请注意，如果您是新用户，还需要提供一些企业基本信息。请参见下方截图。

<br />

<div className="ch-image-md">

<Frame>

![ClickHouse Cloud 注册信息表单](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)

</Frame>

</div>

<br />

如果您是现有 ClickHouse Cloud 用户，只需使用您的凭据直接登录。

7. 成功登录后，将创建一个新的 ClickHouse Cloud 组织。该组织会关联到您的 GCP 计费账户，所有使用量都将通过您的 GCP 账户计费。

8. 登录后，您可以确认您的计费确实已关联到 GCP Marketplace，并开始设置 ClickHouse Cloud 资源。

<br />

<div className="ch-image-md">

<Frame>

![ClickHouse Cloud 登录页面](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-5.webp)

</Frame>

</div>

<br />

<div className="ch-image-md">

<Frame>

![ClickHouse Cloud 新服务页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-11.webp)

</Frame>

</div>

<br />

9. 您应该会收到一封确认注册的电子邮件：

<br />

<br />

<div className="ch-image-md">

<Frame>

![GCP Marketplace 确认邮件](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-6.webp)

</Frame>

</div>
