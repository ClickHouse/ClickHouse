通过 [GCP Marketplace](https://console.cloud.google.com/marketplace) 的承诺合同开始使用 ClickHouse Cloud。承诺合同也称为专属优惠，允许客户承诺在一段时间内为 ClickHouse Cloud 消费一定金额。

<div id="prerequisites">
  ## 前置条件 {#prerequisites}
</div>

* ClickHouse 基于特定合同条款提供的专属优惠。

## 注册步骤 {#steps-to-sign-up}

1. 您应已收到一封电子邮件，其中包含用于查看并接受专属报价的链接。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 专属报价电子邮件](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-1.webp)
  </Frame>
</div>

<br />

2. 点击电子邮件中的 **Review Offer** 链接，随后将跳转到 GCP Marketplace 页面，其中显示专属报价详情。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 报价摘要](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-2.webp)
  </Frame>
</div>

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 定价摘要](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-3.webp)
  </Frame>
</div>

<br />

3. 查看专属报价详情，确认无误后点击 **Accept**。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 接受页面](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-4.webp)
  </Frame>
</div>

<br />

4. 点击 **Go to product page**。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 接受确认](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-5.webp)
  </Frame>
</div>

<br />

5. 点击 **Manage on provider**。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace ClickHouse Cloud 页面](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-6.webp)
  </Frame>
</div>

<br />

此时务必跳转到 ClickHouse Cloud 并完成注册或登录。若未完成此步骤，我们将无法把您的 GCP Marketplace 订阅关联到 ClickHouse Cloud。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 离开网站确认弹窗](/images/cloud/manage/billing/marketplace/gcp-marketplace-committed-7.webp)
  </Frame>
</div>

<br />

6. 跳转到 ClickHouse Cloud 后，您可以使用现有账户登录，也可以注册新账户。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 登录页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
  </Frame>
</div>

<br />

如果您是 ClickHouse Cloud 新用户，请点击页面底部的 **Register**。系统将提示您创建新用户并验证电子邮件。完成邮箱验证后，您可以离开 ClickHouse Cloud 登录页面，前往 [https://console.clickhouse.cloud](https://console.clickhouse.cloud) 使用新用户名登录。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 注册页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
  </Frame>
</div>

<br />

请注意，新用户还需要提供一些企业基本信息，如下方截图所示。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 注册信息表单](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
  </Frame>
</div>

<br />

如果您是 ClickHouse Cloud 现有用户，直接使用您的凭证登录即可。

7. 成功登录后，系统将创建一个新的 ClickHouse Cloud 组织。该组织将与您的 GCP 计费账户关联，所有用量都将通过您的 GCP 账户计费。

8. 登录后，您可以确认计费确实已与 GCP Marketplace 绑定，然后开始设置您的 ClickHouse Cloud 资源。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 登录页面](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-5.webp)
  </Frame>
</div>

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud 新服务页面](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-11.webp)
  </Frame>
</div>

<br />

9. 您将收到一封注册确认电子邮件：

<br />

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 确认电子邮件](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-6.webp)
  </Frame>
</div>

<br />
