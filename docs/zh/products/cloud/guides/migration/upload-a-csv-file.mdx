<Visibility for="humans">
  <View title="Cloud UI">
    ClickHouse Cloud 提供了一种便捷的文件导入方式，支持以下格式：

    | 格式                              |
    | ------------------------------- |
    | `CSV`                           |
    | `CSVWithNamesAndTypes`          |
    | `CSVWithNames`                  |
    | `JSONEachRow`                   |
    | `TabSeparated`                  |
    | `TabSeparatedWithNames`         |
    | `TabSeparatedWithNamesAndTypes` |

    <Steps>
      <Step title="上传文件" id="upload-file">
        在 Cloud 主页中，按下图所示选择您的服务：

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_02](/images/cloud/migrate/csv_01.webp)
          </Frame>
        </div>

        如果服务处于空闲状态，需要先将其唤醒。

        按下图所示，在左侧选项卡中选择 `Data sources`：

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_03](/images/cloud/migrate/csv_02.webp)
          </Frame>
        </div>

        接下来，在数据源页面右侧选择 `Upload a file`：

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_04](/images/cloud/migrate/csv_03.webp)
          </Frame>
        </div>

        随后会弹出文件对话框，您可以从中选择要插入到 Cloud 服务中某个表的数据文件。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_04.webp)
          </Frame>
        </div>
      </Step>

      <Step title="配置表" id="configure-table">
        文件上传完成后，即可配置要插入数据的目标表。页面会显示该表前三行的预览。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_08](/images/cloud/migrate/csv_08.webp)
          </Frame>
        </div>

        现在可以选择目标表，选项包括：

        * 新表
        * 现有表

        <br />

        您可以指定要将数据上传到哪个数据库；如果选择新表，还可以指定新建表的名称。此外，您还可以选择 sorting key：

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_05.webp)
          </Frame>
        </div>

        从文件中读取的列会显示为 `Source field`，对于每个字段，您可以修改：

        * 推断类型
        * 默认值
        * 是否将该列设为 [Nullable](/zh/reference/data-types/nullable)

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_06](/images/cloud/migrate/csv_06.webp)
          </Frame>
        </div>

        <Info>
          **排除字段**

          如果不希望导入某个字段，也可以将其移除。
        </Info>

        您可以指定要使用的表引擎类型：

        * `MergeTree`
        * `ReplacingMergeTree`
        * `SummingMergeTree`
        * `Null`

        <br />

        您还可以指定分区键表达式和主键表达式。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_07](/images/cloud/migrate/csv_07.webp)
          </Frame>
        </div>

        点击 `Import to ClickHouse` (如上图所示) 导入数据。导入任务随后会进入队列，此时 `Status` 列中会显示 `queued` 状态徽章，如下图所示。您也可以点击 `Open as query` (如上图所示) ，在 SQL 控制台中打开对应的插入查询。该查询会通过 `URL` 表函数插入已上传到 S3 存储桶的文件。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_09](/images/cloud/migrate/csv_09.webp)
          </Frame>
        </div>

        如果任务失败，`Data upload history` 选项卡的 `Status` 列中会显示 `failed` 状态徽章。点击 `View Details` 可查看上传失败的具体原因。您可能需要根据插入失败的错误信息修改表配置或清洗数据。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_11](/images/cloud/migrate/csv_10.webp)
          </Frame>
        </div>
      </Step>
    </Steps>
  </View>

  <View title="命令行客户端">
    您可以自行按此流程操作、将其编写为脚本，或交由 AI 智能体执行。如需使用控制台操作，请切换到 **Cloud UI** 视图。
