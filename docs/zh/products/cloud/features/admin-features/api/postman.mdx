本指南将帮助你使用 [Postman](https://www.postman.com/product/what-is-postman/) 测试 ClickHouse Cloud API。
你可以直接在 Web 浏览器中使用 Postman 应用程序，也可以将其下载到桌面端。

### 创建账户 {#create-an-account}

* 可在 [https://www.postman.com](https://www.postman.com) 注册免费账户。

<div className="ch-image-md">
  <Frame>
    ![Postman 网站](/images/cloud/manage/postman/postman1.webp)
  </Frame>
</div>

### 创建工作区 {#create-a-workspace}

* 给工作区命名并设置可见性级别。

<div className="ch-image-md">
  <Frame>
    ![创建工作区](/images/cloud/manage/postman/postman2.webp)
  </Frame>
</div>

### 创建集合 {#create-a-collection}

* 在左上角菜单中，点击 &quot;Explore&quot; 下方的 &quot;导入&quot;：

<div className="ch-image-md">
  <Frame>
    ![Explore > 导入](/images/cloud/manage/postman/postman3.webp)
  </Frame>
</div>

* 此时会弹出一个模态窗口：

<div className="ch-image-md">
  <Frame>
    ![API URL 输入项](/images/cloud/manage/postman/postman4.webp)
  </Frame>
</div>

* 输入 API 地址：&quot;https://api.clickhouse.cloud/v1&quot;，然后按下 &#39;Enter&#39;：

* 点击 &quot;导入&quot; 按钮，选择 &quot;Postman Collection&quot;：

<div className="ch-image-md">
  <Frame>
    ![集合 > 导入](/images/cloud/manage/postman/postman6.webp)
  </Frame>
</div>

### 使用 ClickHouse Cloud API 规范 {#interface-with-the-clickhouse-cloud-api-spec}

* “ClickHouse Cloud 的 API 规范”现在会显示在“集合” (左侧导航) 中。

<div className="ch-image-md">
  <Frame>
    ![导入 API](/images/cloud/manage/postman/postman7.webp)
  </Frame>
</div>

* 点击“ClickHouse Cloud 的 API 规范”。然后在中间面板中选择“Authorization”选项卡：

<div className="ch-image-md">
  <Frame>
    ![导入完成](/images/cloud/manage/postman/postman8.webp)
  </Frame>
</div>

### 设置授权 {#set-authorization}

* 在下拉菜单中选择“Basic Auth”：

<div className="ch-image-md">
  <Frame>
    ![Basic Auth](/images/cloud/manage/postman/postman9.webp)
  </Frame>
</div>

* 输入您在设置 ClickHouse Cloud API keys 时收到的用户名和密码：

<div className="ch-image-md">
  <Frame>
    ![凭证](/images/cloud/manage/postman/postman10.webp)
  </Frame>
</div>

<div id="enable-variables">
  ### 启用变量 {#enable-variables}
</div>

* [变量](https://learning.postman.com/docs/sending-requests/variables/)可用于在 Postman 中存储和重复使用值，从而简化 API 测试。

#### 设置组织 ID 和服务 ID {#set-the-organization-id-and-service-id}

* 在“集合”中，点击中间窗格里的“变量”选项卡 (Base URL 已在之前导入 API 时设置) ：
* 在 `baseURL` 下方，点击空白字段“Add new value”，然后填入你的组织 ID 和服务 ID：

<div className="ch-image-md">
  <Frame>
    ![组织 ID 和服务 ID](/images/cloud/manage/postman/postman11.webp)
  </Frame>
</div>

<div id="test-the-clickhouse-cloud-api-functionalities">
  ## 测试 ClickHouse Cloud API 的各项功能 {#test-the-clickhouse-cloud-api-functionalities}
</div>

### 测试“GET 可用组织列表” {#test-get-list-of-available-organizations}

* 在“ClickHouse Cloud 的 OpenAPI 规范”下，展开 &gt; V1 &gt; organizations 文件夹
* 点击“GET 可用组织列表”，然后点击右侧蓝色的“Send”按钮：

<div className="ch-image-md">
  <Frame>
    ![测试获取组织信息](/images/cloud/manage/postman/postman12.webp)
  </Frame>
</div>

* 返回结果应显示你的组织详细信息，且 &quot;status&quot;: 200。(如果你收到 &quot;status&quot; 400，但没有任何组织信息，则说明配置不正确。)

<div className="ch-image-md">
  <Frame>
    ![状态](/images/cloud/manage/postman/postman13.webp)
  </Frame>
</div>

### 测试“GET organizational details” {#test-get-organizational-details}

* 在 `organizationid` 文件夹下，找到“GET organizational details”：
* 在中间窗格菜单的 Params 下，需要填写 `organizationid`。

<div className="ch-image-md">
  <Frame>
    ![测试获取组织详细信息](/images/cloud/manage/postman/postman14.webp)
  </Frame>
</div>

* 将此值改为花括号中的 `orgid`：`{{orgid}}` (如果你之前已设置过该值，会出现一个包含该值的菜单) ：

<div className="ch-image-md">
  <Frame>
    ![提交测试](/images/cloud/manage/postman/postman15.webp)
  </Frame>
</div>

* 点击“Save”按钮后，再点击屏幕右上角蓝色的“Send”按钮。

<div className="ch-image-md">
  <Frame>
    ![返回值](/images/cloud/manage/postman/postman16.webp)
  </Frame>
</div>

* 返回结果应包含你的组织详细信息，且 &quot;status&quot;: 200。 (如果返回的是 &quot;status&quot; 400，且没有组织信息，则说明你的配置不正确。)

### 测试“GET service details” {#test-get-service-details}

* 点击“GET service details”
* 分别将 `organizationid` 和 `serviceid` 的值编辑为 `{{orgid}}` 和 `{{serviceid}}`。
* 点击“Save”，然后点击右侧蓝色的“Send”按钮。

<div className="ch-image-md">
  <Frame>
    ![服务列表](/images/cloud/manage/postman/postman17.webp)
  </Frame>
</div>

* 返回结果应显示你的服务列表及其详细信息，且 &quot;status&quot;: 200。(如果你收到 &quot;status&quot; 400，且没有任何服务信息，则说明你的配置不正确)。
