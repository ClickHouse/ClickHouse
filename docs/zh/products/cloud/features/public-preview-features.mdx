公开预览功能是指已基本完成、并有明确路径走向正式可用 (GA) 的 ClickHouse Cloud 功能。这些功能已开放给客户使用以收集反馈，但尚未进入 Beta 阶段。

<Warning>
  公开预览功能可能会发生变更，且不在标准 ClickHouse Cloud SLA 的保障范围内。
</Warning>

## 启用公开预览 {#enable-public-preview}

1. 登录 Cloud 控制台，并选择相应的组织。
2. 打开组织菜单，选择 **Preview features**。也可以通过组织侧边栏进入该页面。
3. 找到目标功能，选择 **Learn more** 查看其要求和限制，然后打开对应的开关。如果开关处于禁用状态，请联系组织管理员启用该功能。
4. 如果提供了 **Go to...** 或 **View in...** 服务链接，可通过该链接开始使用该功能。

<Note>
  功能是否可用取决于您所在组织的访问权限以及该功能的滚动发布进度。并非所有公开预览功能都向每个组织开放。如需确认访问权限，请联系 [Cloud 技术支持](https://clickhouse.com/support/program)。
</Note>
