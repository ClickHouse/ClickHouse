借助 Claude Platform 关联计费，同时是 ClickHouse 和 Anthropic 客户的用户可以将 ClickHouse Cloud 各产品 (例如 [ClickHouse 智能体](/zh/agents/index)) 中产生的所有 Claude 模型用量直接计入自己的 Claude 组织账单。

Claude Platform 关联计费目前处于公开预览阶段，所有 ClickHouse Cloud 组织均可使用。

您只需将 Claude 组织与 ClickHouse Cloud 组织关联一次。
此后，Anthropic 会将您的 ClickHouse Cloud 组织产生的 Claude 模型用量计入您的 Claude 组织，按该 Claude 组织的费率及其现有计费条款进行计费。
这样，您就可以充分利用与 Anthropic 之间已有的承诺支出或协商费率。

## 计费方式 {#how-billing-works}

当您的 Claude 组织处于关联状态时：

* Anthropic 会将您的 ClickHouse Cloud 组织中的 Claude 模型用量计入您的 Claude 组织，从其预付余额中扣除，或列入其发票。
* 适用您的 Claude 组织的费率，以及您与 Anthropic 约定的承诺支出 (如有) 。
* 您组织的 Claude 模型请求将发送至 Anthropic，而不再发送至托管在亚马逊 Bedrock 上的 Claude 模型。

请注意以下事项：

* 关联计费涵盖所有 ClickHouse Cloud 产品中的全部 Claude 模型用量。
* 为您的组织启用与 Claude Platform 的关联计费后，ClickHouse Cloud 中将仅提供 Claude 模型。
* 您的 Claude 组织中的促销抵用额度不可用于关联计费。
* 关联仅影响 Claude 用量的计费方式，不会改变您在 ClickHouse Cloud 中使用 Claude 时适用的条款或数据相关安排。
* 进行关联时，您可以为通过 ClickHouse Cloud 产生的 Claude 用量设置每月支出上限。当通过 ClickHouse Cloud 产生的支出达到该上限时，来自 ClickHouse Cloud 的 Claude 模型请求将暂停，直至下个月或您提高上限为止。

如果您未关联 Claude 组织，则一切照旧：ClickHouse Cloud 中的 Claude 模型将继续由亚马逊 Bedrock 提供。

## 要求 {#requirements}

* **未启用 HIPAA 或 PCI DSS 合规。** 已启用 [HIPAA](/zh/products/cloud/reference/security/compliance-overview#hipaa-since-2024) 或 [PCI DSS](/zh/products/cloud/reference/security/compliance-overview#pci-service-provider-since-2025) 合规的 ClickHouse Cloud 组织无法使用与 Claude Platform 的关联计费功能。
* **拥有关联计费权限的 ClickHouse Cloud 角色。** 您需要在 ClickHouse Cloud 组织中拥有管理员角色。
* **拥有计费审批权限的 Claude 角色。** 您需要在 Claude 组织中拥有 所有者、管理员 或 账单 角色。
* **符合条件的 Claude 组织。** 您的 Claude 组织必须直接向 Anthropic 支付 API 使用费用，可采用预付费额度或按发票结算的方式。通过云市场 (AWS、Google Cloud 或 Azure) 计费的 Claude 组织，以及仅订阅了 Claude 套餐的组织，均无法进行关联。

## 关联您的 Claude 组织 {#link-your-claude-organization}

<Steps>
  <Step title="打开组织设置">
    以组织管理员身份在 ClickHouse Cloud 控制台中打开 **组织设置**，然后滚动到 **Claude organization** 部分。
    点击 **Link your Claude organization**。

    <div className="ch-image-md">
      <Frame>
        ![ClickHouse Cloud 组织设置中的 Claude organization 部分，包含 Link your Claude organization 按钮](/images/cloud/linked-billing-claude-platform/01-link-button.webp)
      </Frame>
    </div>
  </Step>

  <Step title="登录 Claude">
    系统会将您重定向到 Claude。
    如果您尚未登录，请使用在待关联 Claude 组织中拥有 所有者、管理员 或 账单 角色的账户登录。
    如果您的账户属于多个 Claude 组织，请选择要关联的组织。
  </Step>

  <Step title="了解计费方式">
    Claude 会说明此连接的计费方式。
    查看详细信息后，点击 **Continue**。

    <div className="ch-image-sm">
      <Frame>
        ![Claude 批准页面，说明 ClickHouse 将代表您的组织使用 Claude，且 Anthropic 会将相应用量计入您组织的账单](/images/cloud/linked-billing-claude-platform/02-consent-how-billing-works.webp)
      </Frame>
    </div>
  </Step>

  <Step title="设置每月支出上限">
    您可以为通过 ClickHouse Cloud 使用的 Claude 设置每月支出上限 (可选) ，然后点击 **Continue**。
    如需不设上限直接关联，请点击 **Continue without a limit**。
    您可以随时在 Claude 控制台 中更改该上限。

    <div className="ch-image-sm">
      <Frame>
        ![Claude 批准页面，包含用于设置通过 ClickHouse Cloud 使用 Claude 的每月支出上限的字段](/images/cloud/linked-billing-claude-platform/03-consent-spend-limit.webp)
      </Frame>
    </div>
  </Step>

  <Step title="关联并授权">
    查看 ClickHouse 将获得的权限，然后点击 **Link and authorize**。

    <div className="ch-image-sm">
      <Frame>
        ![Claude 批准页面，概述 ClickHouse 可在每月支出上限内代表您的组织使用 Claude，并包含 Link and authorize 按钮](/images/cloud/linked-billing-claude-platform/04-consent-link-and-authorize.webp)
      </Frame>
    </div>
  </Step>

  <Step title="确认关联">
    系统会将您带回 ClickHouse Cloud 控制台，并提示您的 Claude 组织已关联成功。
    **Claude organization** 部分会显示 **Linked** 状态、关联日期以及关联 ID 的末尾几个字符。

    <div className="ch-image-md">
      <Frame>
        ![Claude organization 部分，显示 Linked 状态、关联日期、关联 ID 以及 Unlink 按钮](/images/cloud/linked-billing-claude-platform/05-linked.webp)
      </Frame>
    </div>

    此后，您的 ClickHouse Cloud 组织中的 Claude 用量将计入您的 Claude 组织账单。
  </Step>
</Steps>

## 在 Claude 控制台中监控用量和支出 {#monitor-usage}

如需了解通过 ClickHouse Cloud 使用 Claude 为您的 Claude 组织产生了多少费用，请在 Claude 控制台中打开 [Linked platforms](https://platform.claude.com/linked-platforms)，然后选择 **ClickHouse**。该页面显示以下信息：

* 被计费的 Claude 组织、关联时间以及批准人。
* **Spent this month**：本月通过 ClickHouse Cloud 产生的支出；如果您设置了月度支出上限，还会显示其与该上限的对比情况。该上限会在每月第一天 (UTC) 重置。
* **Link history**：该组织每次关联或取消关联的记录及相应操作人。

<div className="ch-image-sm">
  <Frame>
    ![Claude 控制台中 ClickHouse 的 Linked platforms 页面，显示连接详情以及 Spent this month 计量条与月度支出上限的对比](/images/cloud/linked-billing-claude-platform/07-claude-console-spend.webp)
  </Frame>
</div>

您还可以在此页面中设置、提高或移除通过 ClickHouse Cloud 使用 Claude 的月度支出上限，或取消与 ClickHouse 的关联。

此外，您的 Claude 组织在 Claude 控制台 [Spend limits](https://platform.claude.com/settings/billing#spend-limits) 下设置的整体 **Monthly spend limit** 同样适用于通过 ClickHouse Cloud 使用的 Claude。

## 解除 Claude 组织的关联 {#unlink}

您可以从任意一方解除关联，但从不同一方操作，结果也有所不同。

### 在 ClickHouse Cloud 中取消关联 {#unlink-in-clickhouse-cloud}

在 **组织设置** 中，点击 **Claude organization** 部分中的 **Unlink**。
ClickHouse Cloud 随即恢复默认行为：您组织中的 Claude 模型请求将发送至托管在 亚马逊 Bedrock 上的 Claude 模型，Claude 用量也不再计入您的 Claude 组织账单。
这是恢复默认行为的唯一途径。

### 在 Claude 控制台 中取消关联 {#unlink-in-the-claude-console}

在 [Linked platforms](https://platform.claude.com/linked-platforms) 页面上，选择 **ClickHouse**，然后点击 **Unlink**。
此后，ClickHouse Cloud 将无法再代表您的组织使用 Claude，Anthropic 也不再将通过 ClickHouse Cloud 新产生的 Claude 用量计入您的 Claude 组织账单。

<Warning>
  在 Claude 控制台 中取消关联后，ClickHouse Cloud 不会自动恢复为默认行为。
  在您重新关联或在 ClickHouse Cloud 的 **组织设置** 中显式取消关联之前，您的 ClickHouse Cloud 组织发出的 Claude 模型请求都会失败。
  例如，ClickHouse 智能体会返回 `The model provider could not complete this request (status 403).`
</Warning>

<div className="ch-image-md">
  <Frame>
    ![ClickHouse 智能体聊天界面显示错误 The model provider could not complete this request (status 403)](/images/cloud/linked-billing-claude-platform/08-agents-403-error.webp)
  </Frame>
</div>

随后，ClickHouse Cloud **组织设置** 中的 **Claude organization** 部分会显示以下消息：`The link was removed on the Claude side, or your Claude organization cannot be billed directly. Relink to continue.`

<div className="ch-image-md">
  <Frame>
    ![Claude organization 部分显示警告，提示关联已在 Claude 端被移除，并提供 Relink 和 Unlink 按钮](/images/cloud/linked-billing-claude-platform/06-link-removed.webp)
  </Frame>
</div>

如需继续，请执行以下任一操作：

* 点击 **Relink** 并重新完成[关联步骤](#link-your-claude-organization)，以继续将 Claude 用量计入您的 Claude 组织账单。
* 点击 **Unlink** 恢复默认行为，即 Claude 模型请求将发送至托管在亚马逊 Bedrock 上的 Claude 模型。

## 故障排查 {#troubleshooting}

| 症状                                          | 可能原因                                                                   | 处理方法                                                                                                                                                                                                           |
| ------------------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Link your Claude organization** 按钮处于禁用状态。 | 您在 ClickHouse Cloud 组织中没有管理员角色，或者您的组织已启用 HIPAA 或 PCI DSS 合规。           | 请组织管理员进行关联。已启用 HIPAA 或 PCI DSS 合规的组织无法使用与 Claude Platform 的关联计费；Claude 模型仍将通过 亚马逊 Bedrock 提供。                                                                                                               |
| Claude 的批准页面未列出您的组织，或提示无法关联 ClickHouse。     | 您的 Claude 组织不[符合条件](#requirements)，或者您的账户在该组织中不具备所有者、管理员或账单角色。         | 请查看[要求](#requirements)。                                                                                                                                                                                        |
| Claude 请求失败，且**组织设置**显示关联已在 Claude 端被移除。    | 关联已在 Claude 控制台中被移除，或者 Anthropic 无法直接向您的 Claude 组织计费。                  | 在 ClickHouse Cloud 中[重新关联或取消关联](#unlink-in-the-claude-console)。                                                                                                                                                |
| Claude 请求在月中途停止。                            | 通过 ClickHouse Cloud 产生的支出已达到您在关联时设置的每月支出上限，或者您的 Claude 组织已达到其整体每月支出上限。 | 在 Claude 控制台的 [Linked platforms](https://platform.claude.com/linked-platforms) 中提高通过 ClickHouse Cloud 使用 Claude 的支出上限，或在 [Spend limits](https://platform.claude.com/settings/billing#spend-limits) 中提高组织的支出上限。 |
| Claude 请求失败，但您的 Claude 组织已关联。               | Anthropic 当前无法向您的 Claude 组织计费，例如预付抵用额度已用尽或组织已被暂停。                      | 在 Claude 控制台中检查您的计费情况。                                                                                                                                                                                         |

如有关于 ClickHouse Cloud 的问题，请联系 [ClickHouse 支持团队](https://clickhouse.com/support/program)。
如需在 Anthropic 端管理支出上限或连接，请使用 Claude 控制台中的 [Linked platforms](https://platform.claude.com/linked-platforms) 页面。
