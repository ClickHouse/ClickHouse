ClickHouse BYOC on AWS 支持两种私有连接方式：VPC 对等连接 和 AWS PrivateLink。

<div id="common-prerequisites">
  ## 前置条件 {#common-prerequisites}
</div>

VPC 对等互连 和 PrivateLink 均需执行的通用步骤。

### 为 ClickHouse BYOC 启用私有负载均衡器 {#step-enable-private-load-balancer-for-clickhouse-byoc}

在 ClickHouse Cloud 控制台中，为您的 BYOC 基础设施启用 **私有负载均衡器**。

<div className="ch-image-md">
  <Frame>
    ![BYOC 启用私有负载均衡器](/images/cloud/reference/byoc-private-load-balancer.webp)
  </Frame>
</div>

## 设置 VPC 对等连接 {#aws-vpc-peering}

要为 ClickHouse BYOC 创建或删除 VPC 对等连接，请按以下步骤操作：

<Steps>
  <Step title="创建对等连接" id="step-1-create-a-peering-connection">
    1. 在 ClickHouse BYOC 账户中，前往 VPC 仪表板。
    2. 选择 Peering Connections。
    3. 点击 Create Peering Connection
    4. 将 VPC Requester 设置为 ClickHouse VPC ID。
    5. 将 VPC Accepter 设置为目标 VPC ID。 (如适用，选择另一个账户)
    6. 点击 Create Peering Connection。

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 创建对等连接](/images/cloud/reference/byoc-vpcpeering-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="接受对等连接请求" id="step-2-accept-the-peering-connection-request">
    前往对等账户后，客户可在 (VPC -&gt; Peering connections -&gt; Actions -&gt; Accept request) 页面批准此 VPC 对等连接请求。

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 接受对等连接](/images/cloud/reference/byoc-vpcpeering-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="将目标端添加到 ClickHouse VPC 路由表" id="step-3-add-destination-to-clickhouse-vpc-route-tables">
    在 ClickHouse BYOC 账户中，

    1. 在 VPC 仪表板中选择 Route Tables。
    2. 搜索 ClickHouse VPC ID，并编辑每个附加到私有子网的路由表。
    3. 点击 Routes 选项卡下的 Edit 按钮。
    4. 点击 Add another route。
    5. 在 Destination 中输入目标 VPC 的 CIDR 范围。
    6. 在 Target 中选择“Peering Connection”和该对等连接的 ID。

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 添加路由表](/images/cloud/reference/byoc-vpcpeering-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="将目标端添加到目标 VPC 路由表" id="step-4-add-destination-to-the-target-vpc-route-tables">
    在对等 AWS 账户中，

    1. 在 VPC 仪表板中选择 Route Tables。
    2. 搜索目标 VPC ID。
    3. 点击 Routes 选项卡下的 Edit 按钮。
    4. 点击 Add another route。
    5. 在 Destination 中输入 ClickHouse VPC 的 CIDR 范围。
    6. 在 Target 中选择“Peering Connection”和该对等连接的 ID。

    <div className="ch-image-lg">
      <Frame>
        ![BYOC 添加路由表](/images/cloud/reference/byoc-vpcpeering-4.webp)
      </Frame>
    </div>
  </Step>

  <Step title="编辑安全组以允许对等 VPC 访问" id="step-5-edit-security-group-to-allow-peered-vpc-access">
    在 ClickHouse BYOC 账户中，您需要更新安全组 (Security Group) 设置，以允许来自对等 VPC 的流量。请联系 ClickHouse 支持团队，请求添加包含对等 VPC CIDR 范围的入站规则。

    ***

    现在应已可从对等 VPC 访问 ClickHouse 服务。
  </Step>
</Steps>

要通过私网方式访问 ClickHouse，系统会预配私有负载均衡器和端点，以便用户从其对等 VPC 安全连接。专用终结点遵循公网端点的格式，并带有 `-private` 后缀。例如：

* **公网端点**: `h5ju65kv87.mhp0y4dmph.us-west-2.aws.clickhouse-byoc.com`
* **专用终结点**: `h5ju65kv87-private.mhp0y4dmph.us-west-2.aws.clickhouse-byoc.com`

可选：在确认对等连接正常工作后，您可以申请移除 ClickHouse BYOC 的公网负载均衡器。

<div id="setup-privatelink">
  ## 设置 PrivateLink {#setup-privatelink}
</div>

AWS PrivateLink 可为您的 ClickHouse BYOC 服务提供安全的私网连接，无需进行 VPC peering 或使用互联网网关。所有流量均在 AWS 网络内传输，确保不会经过公网。

<Note>
  **跨区域连接。** ClickHouse 控制台中的 **Enable private link** 开关会预配端点服务，但仅适用于**同一区域**的消费者。AWS 默认禁用端点服务的跨区域访问，ClickHouse 控制台也不会对此进行管理——如果您的客户端位于其他区域，需由您自行启用：端点服务位于您的 BYOC 账户中，因此请在您的 AWS 控制台中，将消费者所在区域添加到其 **Supported regions** 列表中 (请参阅下方第 3 步) 。ClickHouse 不会更改或重置这些配置值。AWS 跨区域数据传输费率适用。
</Note>

<Steps>
  <Step title="在 ClickHouse 控制台中启用 Private Link" id="step-1-enable-private-link">
    <Note>
      前置条件：请确保已启用**私有负载均衡器**。
    </Note>

    <div className="ch-image-md">
      <Frame>
        ![启用 BYOC PrivateLink](/images/cloud/reference/byoc-privatelink.webp)
      </Frame>
    </div>
  </Step>

  <Step title={<>获取端点的 <code>Service 名称</code></>} id="step-2-obtain-endpoint-service-name">
    1. 在 ClickHouse Cloud 控制台中，打开需要通过 PrivateLink 连接的服务的“设置”页面。
    2. 点击“设置私有端点”。
    3. 在弹出面板中，复制 `Service name` 的值，下一步会用到它。 (启用 PrivateLink 后，该值可能需要一段时间才会生成。)

       <div className="ch-image-md">
         <Frame>
           ![私有端点](/images/cloud/security/aws-privatelink-pe-create.webp)
         </Frame>
       </div>
  </Step>

  <Step title="在您的网络中创建端点" id="step-3-create-endpoint">
    1. 打开您**自己的 AWS 控制台** (即客户端应用程序所在的 AWS 账户) → VPC → Endpoints → Create endpoints。

    2. 选择 &quot;Endpoint services that use NLBs and GWLBs&quot;，并填入上一步获取的 `Service name`。

    3. 点击 &quot;Verify service&quot;。

       <div className="ch-image-md">
         <Frame>
           ![AWS PrivateLink 端点设置](/images/cloud/security/aws-privatelink-endpoint-settings.webp)
         </Frame>
       </div>

    4. (可选) 如需通过 PrivateLink 建立跨区域连接，请勾选 &quot;Cross region endpoint&quot; 复选框并指定服务区域。服务区域即您的 BYOC 基础设施所在的区域。同时还需：

    5. 打开您的 **BYOC AWS 控制台** (即创建 BYOC 基础设施的 AWS 账户) → VPC → Endpoint services → `clickhouse-cloud-infra-xxx` → Supported regions。

    6. 将客户端应用程序所在的区域添加到支持区域列表中。默认情况下，仅支持该 BYOC 基础设施所在的区域。如需从多个区域发起连接，可添加多个区域，ClickHouse 不会更改或重置这些值。

       <div className="ch-image-md">
         <Frame>
           ![AWS PrivateLink 跨区域端点设置](/images/cloud/reference/byoc-privatelink-aws-cross-region.webp)
         </Frame>
       </div>

    7. 选择您的 VPC 和子网 (建议每个可用区各选一个子网) 。

       <div className="ch-image-md">
         <Frame>
           ![选择 VPC 和子网](/images/cloud/security/aws-privatelink-select-vpc-and-subnets.webp)
         </Frame>
       </div>

    8. **重要**：为该端点启用 &quot;Private DNS names&quot;——这是私有 DNS 正常工作的前提。
       BYOC 端点的私有 DNS (采用 `*.vpce.{subdomain}` 格式) 依托 AWS PrivateLink 内置的 &quot;Private DNS names&quot; 功能实现，无需配置任何 Route53 记录。满足以下条件时，DNS 解析会自动完成：
       * 已启用 &quot;Private DNS names&quot;，并且
       * 已启用 &quot;DNS Hostnames&quot;

         可在 VPC Settings → DNS resolution and DNS hostnames 中进行设置。

         这样，使用 `vpce` 子域名的连接即可自动经由 PrivateLink 端点路由，无需额外配置 DNS。

    9. (可选) 分配安全组/标签。

    <Note>
      请确保安全组已放行端口 `443`、`8443` 和 `9440`。
    </Note>

    8. 点击 &quot;Create endpoint&quot;，稍候片刻，等待端点创建完成。

    9. 端点创建完成后，复制 `Endpoint ID` 的值，下一步中将会用到。

       <div className="ch-image-md">
         <Frame>
           ![VPC Endpoint ID](/images/cloud/security/aws-privatelink-vpc-endpoint-id.webp)
         </Frame>
       </div>
  </Step>

  <Step title="批准端点连接" id="step-4-approve-endpoint-connection">
    1. 再次打开 **BYOC VPC 控制台** → Endpoint services → `clickhouse-cloud-infra-xxx` → Endpoint connections。
    2. 找到从您自己的 VPC 发起的连接请求，点击 &quot;Accept endpoint connection request&quot; 批准该请求。

       <div className="ch-image-md">
         <Frame>
           ![BYOC PrivateLink 批准](/images/cloud/reference/byoc-privatelink-2.webp)
         </Frame>
       </div>
  </Step>

  <Step title={<>将 <code>Endpoint ID</code> 添加到 ClickHouse 服务允许列表</>} id="step-5-add-endpoint-id-to-services-allow-list">
    1. 在 ClickHouse Cloud 控制台中，进入要通过 PrivateLink 连接的服务的“设置”页面。
    2. 点击“设置私有端点”。
    3. 在弹出面板中，输入上一步获取的 `Endpoint ID`，并可选填描述。
    4. 点击“创建端点”。

    <Note>
      如果要允许来自现有 PrivateLink 连接的访问，请使用现有端点下拉列表。
      该下拉列表会显示同一基础设施内各服务已有的 PrivateLink 连接。
    </Note>

    <div className="ch-image-md">
      <Frame>
        ![私有端点筛选条件](/images/cloud/security/aws-privatelink-pe-filters.webp)
      </Frame>
    </div>
  </Step>

  <Step title="使用 PrivateLink 访问实例" id="step-6-connect-via-privatelink">
    1. 在 ClickHouse Cloud 控制台中，进入服务的“设置”页面。
    2. 点击“设置私有端点”。
    3. 在打开的弹出面板中，复制 `DNS name`。

       <div className="ch-image-md">
         <Frame>
           ![专用终结点 DNS 名称](/images/cloud/security/aws-privatelink-pe-dns-name.webp)
         </Frame>
       </div>

       通过 PrivateLink 对 ClickHouse 服务的访问受两个级别的控制：

       1. **Istio Authorization Policy**：由 ClickHouse 在您的 BYOC 基础设施中管理的服务级授权策略
       2. **VPC 端点安全组 (Security Group)&#x20;**：附加到 VPC 端点的安全组，用于控制 VPC 中哪些资源可以使用该端点

       <Note>
         私有负载均衡器的“Enforce inbound rules on PrivateLink traffic”功能处于禁用状态，因此访问仅由 Istio 授权策略和 VPC 端点的安全组控制。
       </Note>
  </Step>
</Steps>
