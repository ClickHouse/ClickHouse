本页列出 ClickHouse BYOC 在您的 AWS 账户中使用的各个 IAM 策略和角色，以及它们的权限、范围和用途。如需大致了解 BYOC 权限模型，请参阅 [BYOC 特权](/zh/products/bring-your-own-cloud/reference/privilege)。

## 引导 IAM role {#bootstrap-iam-role}

下表介绍了引导 IAM role `ClickHouseManagementRole` 的各项策略。

| 策略                                         | 权限                                                                                              | 范围                                                                                                                                                                                                                               | 用途                                                                                                                             |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `BasePolicy` (内联)                          | 获取调用方的身份。读取服务配额和 AWS 默认服务配额。                                                                    | 所有资源。只读。                                                                                                                                                                                                                         | 预配前的健康状态检查和配额检查                                                                                                                |
| `ClickHouse-IAM-Base-Policy`               | 读取 IAM 角色、策略和实例配置文件。将角色传递给 AWS 服务。创建服务关联角色。创建集群的 OpenID Connect (OIDC) 身份提供商、为其添加标签或将其删除。       | 读取：所有 IAM 角色和策略。传递角色：仅限 BYOC 角色名称 (例如 `*-k8s-worker`、`*-karpenter-node`、`*-CH-S3-Role`) ，且只能传递给 EKS、EKS Pod Identity 和 EC2。服务关联角色：仅限 EKS、EKS 节点组和 VPC Lattice。OIDC 提供商：仅限带有标签 `clickhouse-byoc=true` 的提供商，该角色可为任意 OIDC 提供商添加此标签。 | 读取 IAM 状态。将 BYOC 角色传递给 EKS 和 EC2。                                                                                              |
| `ClickHouse-IAM-Extended-Policy` (可选，默认启用) | 创建、修改和删除 IAM 角色、策略和实例配置文件                                                                       | 仅限带有标签 `clickhouse-byoc=true` 的资源，该角色可为任意角色、策略或实例配置文件添加此标签。不受此限制的操作：从实例配置文件中移除角色。                                                                                                                                                | 创建其他角色 (详见下一节) 。如果您[自带 IAM 角色](/zh/products/bring-your-own-cloud/onboarding/customization-aws#customer-managed-iam-roles)，则无需此策略。 |
| `ClickHouse-S3-Policy`                     | 创建桶。读取和设置桶配置：标签、生命周期、加密、所有权、阻止公网访问和指标。列出桶中的对象。不允许读取或写入对象，也不允许删除桶。                               | 仅限名称为 `*.*.aws.clickhouse.cloud-shared`、`*.*.aws.clickhouse.cloud-backup` 和 `*.*.aws.clickhouse.cloud-monitoring` 的桶                                                                                                             | 管理用于存储 ClickHouse 表数据、备份和监控数据的桶                                                                                                |
| `ClickHouse-EKS-Policy`                    | 创建、修改和删除 EKS cluster、附加组件、节点组及 Pod Identity 关联。读取所有 EKS 资源。                                     | 写入：仅限名称以 `clickhouse-cloud-` 开头的资源。读取：所有 EKS 资源。                                                                                                                                                                                 | 管理 EKS cluster 及其附加组件和节点组                                                                                                      |
| `ClickHouse-EC2-Policy`                    | 查看 EC2、Elastic Load Balancing 和 Auto Scaling 的信息。启动实例。管理启动模板、网络接口、安全组、弹性 IP 和标签。修改实例、网络接口和卷的属性。 | 安全组：带有标签 `clickhouse-byoc=true` 或 `aws:eks:cluster-name` = `clickhouse-cloud-*` 的资源。弹性 IP 和标签变更：带有标签 `clickhouse-byoc=true` 的资源，该角色可为任意资源添加此标签。不限作用域：实例、启动模板、网络接口和卷。                                                             | 管理节点及控制集群网络访问的安全组                                                                                                              |
| `ClickHouse-VPCWrite-Policy` (可选，默认启用)     | 创建、修改和删除 VPC、子网、NAT 网关、互联网网关、路由表和 VPC 端点                                                        | 仅限带有 `clickhouse-byoc=true` 标签的资源                                                                                                                                                                                                | 用于 BYOC VPC。如果您[自带 VPC](/zh/products/bring-your-own-cloud/onboarding/customization-aws#customer-managed-vpc-aws)，则无需此策略。          |
| `ClickHouse-VPCPrivateLink-Policy`         | 创建、修改和删除 VPC endpoint service                                                                   | 仅限带有 `clickhouse-byoc=true` 标签的资源                                                                                                                                                                                                | 供您的服务使用的 AWS PrivateLink 端点                                                                                                    |
| `ClickHouse-VPCLattice-Policy`             | 创建、修改和删除 VPC Lattice 资源网关、资源配置以及 AWS RAM 资源共享。以只读方式访问 VPC Lattice 和 AWS RAM。                    | 写入：仅限带有标签 `clickhouse-byoc=true` 的资源。读取：所有 VPC Lattice 和 AWS RAM 资源。                                                                                                                                                             | 通过私网访问 EKS API                                                                                                                 |
| `ClickHouse-CloudWatch-Policy`             | 读取 CloudWatch 日志。创建日志组。为日志组添加标签并设置其保留期限。                                                        | 创建：仅限带有标签 `clickhouse-byoc=true` 的日志组。打标签和设置保留期限：仅限 `/aws/eks/clickhouse-cloud-*` 日志组。读取：所有日志组。                                                                                                                                  | EKS 控制平面日志                                                                                                                     |
| `ClickHouse-KMS-Policy` (可选，默认关闭)          | 读取密钥详细信息。为密钥创建授权。                                                                               | 仅限 ClickHouse BYOC AWS 账户中的 KMS 密钥                                                                                                                                                                                               | EKS 机密信息加密                                                                                                                     |
| `ClickHouse-KMSTDE-Policy` (可选，默认关闭)       | 创建 KMS 密钥。查看密钥和密钥策略。启用密钥轮换。为密钥添加标签。不允许加密、解密、更改密钥策略或删除密钥。                                        | 带有标签 `clickhouse-byoc=true` 的密钥；只要密钥的密钥策略允许，该角色即可为任意密钥添加此标签                                                                                                                                                                      | 用于透明数据加密 (TDE) 的密钥                                                                                                             |

如需查看完整的策略文档，请参阅 [Terraform 模块](https://github.com/ClickHouse/terraform-byoc-onboarding/blob/main/modules/aws/main.tf) 或 [CloudFormation 模板](https://s3.us-east-2.amazonaws.com/clickhouse-public-resources.clickhouse.cloud/cf-templates/byoc_v2.yaml)。

## 控制器创建的其他 IAM 角色 {#additional-iam-roles-created-by-the-controller}

除了通过 CloudFormation 或 Terraform 创建的 `ClickHouseManagementRole` 之外，控制器还会为每个 BYOC 基础设施创建若干其他角色。
每个角色的名称都以 `<infra>-<region>-` 为前缀。其中，`<infra>` 是您的 BYOC 基础设施名称，`<region>` 是 AWS 区域。

| 角色                            | 权限                                                                                                                                        | 用途                                    |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| `data-plane-mgmt`             | 读取 EKS 信息。列出和删除 BYOC 桶中的对象，并为这些桶设置加密、版本控制和生命周期。读取负载均衡器和 Auto Scaling 组的信息。ClickHouse 管理服务使用您的外部 ID 代入此角色。                                 | ClickHouse 服务和集群的日常管理                 |
| `k8s-control-plane`           | AWS 托管策略 `AmazonEKSClusterPolicy`、`AmazonEKSServicePolicy`、`AmazonEKSVPCResourceController`。仅 EKS 可以代入此角色。                                | EKS 集群角色                              |
| `k8s-worker`                  | AWS 托管策略 `AmazonEKSWorkerNodePolicy`、`AmazonEKS_CNI_Policy`、`AmazonEC2ContainerRegistryReadOnly`。代入只读角色以拉取 ClickHouse 容器镜像。仅 EC2 可以代入此角色。 | 系统节点的节点角色                             |
| `karpenter-node` (角色和实例配置文件)  | 与 `k8s-worker` 相同，另加 `AmazonSSMManagedInstanceCore`。仅 EC2 可以代入此角色。                                                                        | ClickHouse 服务器和 Keeper 节点的节点角色        |
| `karpenter-controller`        | 启动和终止带有此集群标签的 EC2 实例。读取 BYOC 所在区域的 EC2 信息。仅允许传递 `karpenter-node` 角色。读取价格和 EKS AMI 参数。                                                     | Karpenter：为 ClickHouse 添加和移除节点        |
| `cluster-autoscaler`          | 读取 Auto Scaling 组的信息。设置 Auto Scaling 组的所需容量并终止其中的实例。                                                                                      | 对系统节点组进行扩缩容                           |
| `load-balancer-controller`    | AWS 发布的 AWS Load Balancer Controller 策略。更改负载均衡器和目标组时，相关资源必须带有任意集群的 `elbv2.k8s.aws/cluster` 标签。侦听器、规则、目标注册和标签相关操作不受范围限制。                   | 为您的服务端点创建网络负载均衡器                      |
| `ebs-csi-driver`              | AWS 发布的 EBS CSI 驱动程序策略。删除卷和快照时，相关资源必须带有驱动程序标签。                                                                                            | 为 ClickHouse 和 Keeper 提供磁盘            |
| `CH-S3-Role`                  | 允许执行所有 S3 操作，但仅限于 BYOC 共享桶和备份桶中的 ClickHouse 前缀下。代入您为 ClickHouse 访问 S3 而设置的角色。代入角色以向 ClickHouse 发送用量数据。                                    | ClickHouse 服务器 Pod 使用的身份，用于读写表数据和备份。  |
| `thanos`                      | 列出、读取、写入和删除 BYOC 监控桶中的对象                                                                                                                  | 存储监控指标                                |
| `state-exporter`              | 代入 ClickHouse 角色。无其他权限。                                                                                                                   | 向 ClickHouse 发送基础设施的健康状态              |
| `clickhouse-scraper`          | 代入 ClickHouse 角色。无其他权限。                                                                                                                   | 向 ClickHouse 发送用于计费的用量数据              |
| `kube-metric-forwarder-asc`   | 代入 ClickHouse 角色。无其他权限。                                                                                                                   | 向 ClickHouse 发送 Kubernetes 指标，用于自动扩缩容 |

有关具体的策略文档，请参阅 [Terraform 模块](https://github.com/ClickHouse/terraform-byoc-onboarding/blob/main/modules/aws-per-infra-iam/main.tf)。
