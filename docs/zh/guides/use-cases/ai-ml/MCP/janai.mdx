> 本指南介绍如何在 [Jan.ai](https://jan.ai/docs) 中使用 ClickHouse MCP 服务器。

<Steps>
  <Step title="安装 Jan.ai" id="install-janai">
    Jan.ai 是一款开源的 ChatGPT 替代工具，可完全离线运行。
    您可以下载适用于 [Mac](https://jan.ai/docs/desktop/install/mac)、[Windows](https://jan.ai/docs/desktop/windows) 或 [Linux](https://jan.ai/docs/desktop/linux) 的 Jan.ai。

    它是一款原生应用，下载完成后即可直接启动。
  </Step>

  <Step title="向 Jan.ai 添加 LLM" id="add-llm-to-janai">
    可以通过设置菜单启用模型。

    如需启用 OpenAI，需要提供 API key，如下图所示：

    <div className="ch-image-md">
      <Frame>
        ![启用 OpenAI 模型](/images/use-cases/AI_ML/MCP/0_janai_openai.webp)
      </Frame>
    </div>
  </Step>

  <Step title="启用 MCP 服务器" id="enable-mcp-servers">
    截至撰写本文时，MCP 服务器在 Jan.ai 中仍是一项实验性功能。
    可以通过打开实验性功能开关来启用：

    <div className="ch-image-md">
      <Frame>
        ![启用 MCP 服务器](/images/use-cases/AI_ML/MCP/1_janai_mcp_servers.webp)
      </Frame>
    </div>

    打开该开关后，左侧菜单中会出现 `MCP servers`。
  </Step>

  <Step title="配置 ClickHouse MCP 服务器" id="configure-clickhouse-mcp-server">
    点击 `MCP servers` 菜单，即可看到可连接的 MCP 服务器列表：

    <div className="ch-image-md">
      <Frame>
        ![MCP 服务器列表](/images/use-cases/AI_ML/MCP/2_janai_mcp_servers_list.webp)
      </Frame>
    </div>

    这些服务器默认均处于禁用状态，点击对应开关即可启用。

    要安装 ClickHouse MCP 服务器，请点击 `+` 图标，然后在表单中填写以下内容：

    <div className="ch-image-md">
      <Frame>
        ![添加 MCP 服务器](/images/use-cases/AI_ML/MCP/3_janai_add_mcp_server.webp)
      </Frame>
    </div>

    完成后，如果 ClickHouse Server 的开关尚未打开，请将其打开：

    <div className="ch-image-md">
      <Frame>
        ![启用 MCP 服务器](/images/use-cases/AI_ML/MCP/4_janai_toggle.webp)
      </Frame>
    </div>

    现在，ClickHouse MCP 服务器的工具将显示在聊天对话框中：

    <div className="ch-image-md">
      <Frame>
        ![ClickHouse MCP 服务器工具](/images/use-cases/AI_ML/MCP/5_jani_tools.webp)
      </Frame>
    </div>
  </Step>

  <Step title="通过 Jan.ai 与 ClickHouse MCP 服务器对话" id="chat-to-clickhouse-mcp-server">
    现在可以围绕 ClickHouse 中存储的数据展开对话了！
    先来提一个问题：

    <div className="ch-image-md">
      <Frame>
        ![提问](/images/use-cases/AI_ML/MCP/6_janai_question.webp)
      </Frame>
    </div>

    Jan.ai 在调用工具前会请求确认：

    <div className="ch-image-md">
      <Frame>
        ![工具确认](/images/use-cases/AI_ML/MCP/7_janai_tool_confirmation.webp)
      </Frame>
    </div>

    随后会显示已执行的工具调用列表：

    <div className="ch-image-md">
      <Frame>
        ![已调用的工具](/images/use-cases/AI_ML/MCP/8_janai_tools_called.webp)
      </Frame>
    </div>

    点击某个工具调用，即可查看该调用的详细信息：

    <div className="ch-image-md">
      <Frame>
        ![已调用工具的展开视图](/images/use-cases/AI_ML/MCP/9_janai_tools_called_expanded.webp)
      </Frame>
    </div>

    下方即为查询结果：

    <div className="ch-image-md">
      <Frame>
        ![结果](/images/use-cases/AI_ML/MCP/10_janai_result.webp)
      </Frame>
    </div>
  </Step>
</Steps>
