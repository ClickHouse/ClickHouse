ClickHouse MCP 服务器可将兼容的 AI 助手连接到 ClickHouse 数据库和工具。
有关该协议、其架构及 ClickHouse MCP 服务器的介绍，请参阅 [模型上下文协议 (MCP) 概述](/zh/concepts/features/connect-to-clickhouse/native-tools/mcp)。

如需评估共享 SQL 记忆，可在使用 ClickHouse MCP 连接的同时，[借助 Loom 复用 SQL 经验](https://loom.clickhouse.com/docs/use-cases/self-hosted-clickhouse#reuse-sql-lessons-across-agent-sessions)。
该练习分别使用数据库授权和命名空间授权，并在列重命名后，基于当前 schema 检查已保存的谓词。

## 设置 ClickHouse MCP 服务器 {#set-up-clickhouse-mcp-server}

选择您的 MCP 客户端，然后按照 [ClickHouse MCP 服务器设置指南](/zh/guides/use-cases/ai-ml/MCP/claude-desktop) 将其连接至 ClickHouse。
