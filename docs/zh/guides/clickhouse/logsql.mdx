## 概述 {#overview}

ClickHouse 提供了一种实验性的 `logsql` 方言，可使用
[VictoriaLogs LogsQL](https://docs.victoriametrics.com/victorialogs/logsql/) 语法查询日志表。
它会将 LogsQL 查询转换为 ClickHouse `SELECT` 查询。

在会话中启用该方言并配置源表：

```sql
SET enable_logsql_dialect = 1;
SET logsql_database = 'default';
SET logsql_table = 'logs';
SET logsql_time_column = '_time';
SET logsql_message_column = '_msg';
SET dialect = 'logsql';
```

所配置的表必须包含时间列和消息列。支持 LogsQL 过滤器、
stream 过滤器、文本和数值比较、时间范围，以及 `fields`、`stats`、`sort`、`limit`、`format`、`extract` 和 `unpack_json`
等管道操作。文本过滤器要求日志列为 `String` 类型；显式声明类型的字段可
用于数值比较和数值统计。

该方言目前处于实验阶段，并非对
VictoriaLogs 的逐字节实现。不支持的语法会被拒绝，并返回 `NOT_IMPLEMENTED`；此外，在 ClickHouse 类型、正则表达式、时区
或 SQL 聚合规则存在差异的情况下，查询
语义也可能有所不同。如果某个 LogsQL 语法结构不受支持，或需要与 VictoriaLogs 完全兼容，请改用常规的 ClickHouse SQL。
