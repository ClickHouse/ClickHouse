<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#97329](https://github.com/ClickHouse/ClickHouse/issues/97329) 中回移：移除了带有 SQL Security 的视图在 `ATTACH` 查询中不必要的跳过权限检查。这可防止用户在未验证所需访问权限的情况下附加带有 definer 的视图时发生潜在的权限提升。[#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)) 。
* 已在 [#95816](https://github.com/ClickHouse/ClickHouse/issues/95816) 中回移：修复了在使用多个 join 且带有 `USING` 子句时，源表中限定列的类型推断问题。此前，即使某一列未参与该次 join，后续 join 也会错误地将其底层源列的类型更新为共同超类型 (例如，在 `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` 中，`t2.a` 列仅用于第一次 join，因此其类型应为 `t1.a` 和 `t2.a` 的超类型，不应包含 `t3.a`) 。当函数预期的列类型与执行计划中实际出现的列类型不一致时，可能会导致逻辑错误或崩溃。[#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)) 。
* 已在 [#96394](https://github.com/ClickHouse/ClickHouse/issues/96394) 中回移：修复了在某些情况下，分布式查询使用负数 `LIMIT/OFFSET` 时会出现的逻辑错误。[#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)) 。
* 已在 [#96220](https://github.com/ClickHouse/ClickHouse/issues/96220) 中回移：修复了对 JSON 数组应用 `tupleElement` 时发生的崩溃。关闭 [#95581](https://github.com/ClickHouse/ClickHouse/issues/95581)。[#95647](https://github.com/ClickHouse/ClickHouse/pull/95647) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#96054](https://github.com/ClickHouse/ClickHouse/issues/96054) 中回移：修复了对已分区 Delta Lake 数据进行 squashing 时的问题。[#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#96084](https://github.com/ClickHouse/ClickHouse/issues/96084) 中回移：修复了在空 MergeTree 表上使用 `direct` join algorithm 时可能出现的 `NOT_SUPPORTED` 错误。[#95935](https://github.com/ClickHouse/ClickHouse/pull/95935) ([Vladimir Cherkasov](https://github.com/vdimir)) 。
* 已在 [#96213](https://github.com/ClickHouse/ClickHouse/issues/96213) 中回移：修复了 JSON 数据类型中的 skipping paths。此前，使用 `JSON(SKIP path)` 时，所有以 `path` 为前缀的 JSON 键都会被跳过，甚至包括 `"pathpath"` 这样的键，因此可能导致这些路径的数据在插入期间丢失。现已修复该问题，只有键 `"path"` 会被跳过。[#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#96080](https://github.com/ClickHouse/ClickHouse/issues/96080) 中回移：修复了全局分析器的周期问题 (由 `global_profiler_real_time_period_ns` 和 `global_profiler_cpu_time_period_ns` 控制) 。此前实际使用的是截断后的值，而不是设置值，导致分析器唤醒频率高于预期。[#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#96542](https://github.com/ClickHouse/ClickHouse/issues/96542) 中回移：修复了撤销默认角色的问题。[#96103](https://github.com/ClickHouse/ClickHouse/pull/96103) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#96160](https://github.com/ClickHouse/ClickHouse/issues/96160) 中回移：修复了索引分析中的释放后使用问题。在禁用 `use_primary_key` 且使用索引的条件析取数量非常多这一罕见组合下，会触发该问题。[#96112](https://github.com/ClickHouse/ClickHouse/pull/96112) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#96157](https://github.com/ClickHouse/ClickHouse/issues/96157) 中回移：修复了 `formatDateTime` 在使用非固定宽度格式说明符 (如 MySQL 和 JODA 风格) 时使用未初始化值的问题。[#96133](https://github.com/ClickHouse/ClickHouse/pull/96133) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#97153](https://github.com/ClickHouse/ClickHouse/issues/97153) 中回移：修复了 `AccessRights::contains` 在部分 `revoke` 场景下返回错误结果的问题。[#96170](https://github.com/ClickHouse/ClickHouse/pull/96170) ([pufit](https://github.com/pufit)).
* 已在 [#96280](https://github.com/ClickHouse/ClickHouse/issues/96280) 中回移：修复了 ProcessList 中可能出现的死锁问题。当我们向 cancellation checker 添加任务时，如果 overcommit 跟踪器被触发，可能会因锁顺序反转而发生此问题。[#96182](https://github.com/ClickHouse/ClickHouse/pull/96182) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#96462](https://github.com/ClickHouse/ClickHouse/issues/96462) 中回移：修复了一个 bug：涉及外连接 (LEFT、RIGHT 或 FULL) 并结合多个 INNER JOIN 的查询，可能因非法的 join 重排而返回错误结果。当外连接的 ON 条件引用多个先前已连接表中的列时，优化器未能正确考虑所有表依赖关系，可能错误地重排 join，导致行缺失。关闭 [#95972](https://github.com/ClickHouse/ClickHouse/issues/95972)。[#96193](https://github.com/ClickHouse/ClickHouse/pull/96193) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#96562](https://github.com/ClickHouse/ClickHouse/issues/96562) 中回移：当表未定义 STATISTICS 时，ClickHouse 不应尝试处理它们。这样可避免为检查统计信息文件是否存在而产生的一些额外开销 (100+ms) 。 (issue [#96068](https://github.com/ClickHouse/ClickHouse/issues/96068)) 。[#96233](https://github.com/ClickHouse/ClickHouse/pull/96233) ([Han Fei](https://github.com/hanfei1991)).
* 已在 [#96386](https://github.com/ClickHouse/ClickHouse/issues/96386) 中回移：修复了某些情况下 `not IN` 和 `not has` 函数的分区裁剪错误。[#96241](https://github.com/ClickHouse/ClickHouse/pull/96241) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* 已在 [#96327](https://github.com/ClickHouse/ClickHouse/issues/96327) 中回移：修复了向量相似度索引中的 `stack-use-after-scope` 问题。[#96259](https://github.com/ClickHouse/ClickHouse/pull/96259) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#96532](https://github.com/ClickHouse/ClickHouse/issues/96532) 中回移：修复了 cancellation checker 线程在 `max_execution_time` 值较高的查询中出现活锁的问题。[#96450](https://github.com/ClickHouse/ClickHouse/pull/96450) ([Sergei Trifonov](https://github.com/serxa)).
* 已在 [#96693](https://github.com/ClickHouse/ClickHouse/issues/96693) 中回移：在 bech32 中校验 witness version，以避免缓冲区溢出。[#96671](https://github.com/ClickHouse/ClickHouse/pull/96671) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#97206](https://github.com/ClickHouse/ClickHouse/issues/97206) 中回移：修复在生存时间 (TTL) 合并后，如果一个块中的所有行都被过滤掉，`min(timestamp)` 通过 `_minmax_count_projection` 返回纪元值 (`1970-01-01`) 的问题。[#96703](https://github.com/ClickHouse/ClickHouse/pull/96703) ([Raquel Barbadillo](https://github.com/rbarbadillo)).
* 已在 [#96919](https://github.com/ClickHouse/ClickHouse/issues/96919) 中回移：修复此前对同一列执行过轻量级更新后，`ALTER TABLE DROP COLUMN` 查询失败的问题。[#96861](https://github.com/ClickHouse/ClickHouse/pull/96861) ([Anton Popov](https://github.com/CurtizJ)).
