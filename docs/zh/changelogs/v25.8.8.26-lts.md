<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#87742](https://github.com/ClickHouse/ClickHouse/issues/87742) 中回移：修复了 GeoParquet 导致客户端协议错误的问题。[#84020](https://github.com/ClickHouse/ClickHouse/pull/84020) ([Michael Kolupaev](https://github.com/al13n321))。
* 已在 [#87387](https://github.com/ClickHouse/ClickHouse/issues/87387) 中回移：在为数据库名称生成拼写纠正提示时检查访问权限。[#85371](https://github.com/ClickHouse/ClickHouse/pull/85371) ([Dmitry Novik](https://github.com/novikd))。
* 已在 [#87668](https://github.com/ClickHouse/ClickHouse/issues/87668) 中回移：修复了对包含 numeric/decimal 列的 Postgres 数据库引擎表执行 detach/attach 时的问题。[#86480](https://github.com/ClickHouse/ClickHouse/pull/86480) ([Julian Maicher](https://github.com/jmaicher))。
* 已在 [#87639](https://github.com/ClickHouse/ClickHouse/issues/87639) 中回移：修复了查询中 CTE 内计算得到的函数结果具有非确定性的问题。[#86967](https://github.com/ClickHouse/ClickHouse/pull/86967) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* 已在 [#87808](https://github.com/ClickHouse/ClickHouse/issues/87808) 中回移：函数 checkHeaders 现在会正确校验提供的请求头，并拒绝被禁止的请求头。原作者：Michael Anastasakis (@michael-anastasakis)。[#87172](https://github.com/ClickHouse/ClickHouse/pull/87172) ([Raúl Marín](https://github.com/Algunenano))。
* 已在 [#87813](https://github.com/ClickHouse/ClickHouse/issues/87813) 中回移：修复了带有从另一个 `MergeTree` 表读取的子查询的轻量级更新问题。[#87285](https://github.com/ClickHouse/ClickHouse/pull/87285) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#87730](https://github.com/ClickHouse/ClickHouse/issues/87730) 中回移：修复了对 Buffer 表执行 select 和 insert 时的访问权限校验问题。[#87545](https://github.com/ClickHouse/ClickHouse/pull/87545) ([pufit](https://github.com/pufit))。
* 已在 [#87771](https://github.com/ClickHouse/ClickHouse/issues/87771) 中回移：修复了一个缺陷：如果某个 View 或 Materialized View 被异步删除，且服务器在后台清理完成前重启，可能会导致该视图的 SELECT settings 覆盖全局服务器设置。[#87603](https://github.com/ClickHouse/ClickHouse/pull/87603) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#87795](https://github.com/ClickHouse/ClickHouse/issues/87795) 中回移：修复了 HashJoin 算法在未使用右侧行列表时生成输出块的问题。修复了 [#87401](https://github.com/ClickHouse/ClickHouse/issues/87401)。[#87699](https://github.com/ClickHouse/ClickHouse/pull/87699) ([Dmitry Novik](https://github.com/novikd))。
