<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 已在 [#89358](https://github.com/ClickHouse/ClickHouse/issues/89358) 中回移：禁止在共享对象存储路径上创建多个 `plain-rewritable` 磁盘，因为不同元数据存储事务发生冲突时，这可能会导致未定义行为。[#89038](https://github.com/ClickHouse/ClickHouse/pull/89038) ([Mikhail Artemenko](https://github.com/Michicosun)) 。

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#89506](https://github.com/ClickHouse/ClickHouse/issues/89506) 中回移：查询现可同时利用 optimize&#95;read&#95;in&#95;order 和 query&#95;plan&#95;optimize&#95;lazy&#95;materialization。已解决 [#88767](https://github.com/ClickHouse/ClickHouse/issues/88767)。[#88866](https://github.com/ClickHouse/ClickHouse/pull/88866) ([Manuel](https://github.com/raimannma)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#89650](https://github.com/ClickHouse/ClickHouse/issues/89650) 中回移：为 bcrypt 身份验证添加缓存。[#87115](https://github.com/ClickHouse/ClickHouse/pull/87115) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#89425](https://github.com/ClickHouse/ClickHouse/issues/89425) 中回移：查询 Iceberg 表时，IN 表达式中的子查询会在分区裁剪分析前被正确地预先计算。[#89177](https://github.com/ClickHouse/ClickHouse/pull/89177) ([Daniil Ivanik](https://github.com/divanik)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#89578](https://github.com/ClickHouse/ClickHouse/issues/89578) 中回移：修复在 JSON 中读取混合 Array Floats 和 Bools 时的问题。此前插入此类数据会导致异常。[#88008](https://github.com/ClickHouse/ClickHouse/pull/88008) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#89508](https://github.com/ClickHouse/ClickHouse/issues/89508) 中回移：修复当 query&#95;plan&#95;optimize&#95;join&#95;order&#95;limit &gt; 1 时，CROSS JOIN 重排序中的 logical error，关闭 [#89409](https://github.com/ClickHouse/ClickHouse/issues/89409)。[#88286](https://github.com/ClickHouse/ClickHouse/pull/88286) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#89673](https://github.com/ClickHouse/ClickHouse/issues/89673) 中回移：修复 [#88426](https://github.com/ClickHouse/ClickHouse/issues/88426)：1. 不允许在 Alias 中显式定义列，列会自动从目标表加载，从而确保别名始终与目标表的 schema 保持一致。2. 从 IStorage 代理更多 methods。[#88552](https://github.com/ClickHouse/ClickHouse/pull/88552) ([Kai Zhu](https://github.com/nauu)).
* 已在 [#89446](https://github.com/ClickHouse/ClickHouse/issues/89446) 中回移：修复新 analyzer 在处理子查询时可能出现的 &quot;Context has expired&quot; 问题。[#88694](https://github.com/ClickHouse/ClickHouse/pull/88694) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#89466](https://github.com/ClickHouse/ClickHouse/issues/89466) 中回移：修复对内部表执行 DROP 时，settings max&#95;table&#95;size&#95;to&#95;drop 和 max&#95;partition&#95;size&#95;to&#95;drop 的大小限制传递问题。[#88812](https://github.com/ClickHouse/ClickHouse/pull/88812) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#89716](https://github.com/ClickHouse/ClickHouse/issues/89716) 中回移：修复 icebergS3Cluster protocol。开始支持 iceberg cluster function 中的 schema evolution、位置删除和相等删除。解决了 [#88287](https://github.com/ClickHouse/ClickHouse/issues/88287)。[#88919](https://github.com/ClickHouse/ClickHouse/pull/88919) ([Yang Jiang](https://github.com/Ted-Jiang)).
* 已在 [#89438](https://github.com/ClickHouse/ClickHouse/issues/89438) 中回移：修复 L2DistanceTransposed(vec1, vec2, p) 中的 LOGICAL&#95;ERROR：部分 QBit 读取优化在 p 为 LowCardinality(Nullable(T)) 时，错误地从 return type 中移除了 Nullable。解决了 [#88362](https://github.com/ClickHouse/ClickHouse/issues/88362)。[#89397](https://github.com/ClickHouse/ClickHouse/pull/89397) ([Raufs Dunamalijevs](https://github.com/rienath)).
* 已在 [#89449](https://github.com/ClickHouse/ClickHouse/issues/89449) 中回移：修复加载表时的问题：对于 Tuple 自身存在不正确的稀疏 serialization (由旧版本 ClickHouse 写入) 。[#89405](https://github.com/ClickHouse/ClickHouse/pull/89405) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#89487](https://github.com/ClickHouse/ClickHouse/issues/89487) 中回移：修复使用 `deduplicate_merge_projection_mode='ignore'` 时，对被 生存时间 (TTL) 清空且带有非空 projections 的 parts 的错误 merge 处理。解决了 [#89430](https://github.com/ClickHouse/ClickHouse/issues/89430)。[#89458](https://github.com/ClickHouse/ClickHouse/pull/89458) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#89570](https://github.com/ClickHouse/ClickHouse/issues/89570) 中回移：修复 Keeper 启动期间读取更新日志的问题，该问题会发生在更新日志在 rotation 期间未被正确重命名时。[#89496](https://github.com/ClickHouse/ClickHouse/pull/89496) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#89633](https://github.com/ClickHouse/ClickHouse/issues/89633) 中回移：修复在对右侧表的唯一键使用 OR 条件时，JOIN 结果不正确的问题。解决了 [#89391](https://github.com/ClickHouse/ClickHouse/issues/89391)。[#89512](https://github.com/ClickHouse/ClickHouse/pull/89512) ([Vladimir Cherkasov](https://github.com/vdimir)) 。
* 已在 [#89595](https://github.com/ClickHouse/ClickHouse/issues/89595) 中回移：修复 analyzer 与 PK IN (子查询) (v2) 一起使用时可能出现的 &quot;Context has expired&quot; 问题。修复了 [#89433](https://github.com/ClickHouse/ClickHouse/issues/89433)。[#89527](https://github.com/ClickHouse/ClickHouse/pull/89527) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#89688](https://github.com/ClickHouse/ClickHouse/issues/89688) 中回移：修复一处崩溃问题：当聚合函数的状态中包含 LowCardinality(String) 列的序列化值时，可能发生崩溃。[#89550](https://github.com/ClickHouse/ClickHouse/pull/89550) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#89678](https://github.com/ClickHouse/ClickHouse/issues/89678) 中回移：仅为受支持的 JOIN 算法添加运行时过滤器，即哈希 JOIN。只有当 JOIN 算法先完整读取右侧、再读取左侧时，才能构建过滤器；例如，FullSortingMergeJoin 会同时读取两侧。修复了 [#89220](https://github.com/ClickHouse/ClickHouse/issues/89220)。[#89652](https://github.com/ClickHouse/ClickHouse/pull/89652) ([Alexander Gololobov](https://github.com/davenger)) 。
* 已在 [#89699](https://github.com/ClickHouse/ClickHouse/issues/89699) 中回移：修复某些情况下 JOIN 运行时过滤器导致的逻辑错误/崩溃。修复了 [#89062](https://github.com/ClickHouse/ClickHouse/issues/89062)。[#89666](https://github.com/ClickHouse/ClickHouse/pull/89666) ([Alexander Gololobov](https://github.com/davenger)) 。
