<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#83343](https://github.com/ClickHouse/ClickHouse/issues/83343) 中回移：尝试将 QueryTreeHash 稍微提速。[#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#83207](https://github.com/ClickHouse/ClickHouse/issues/83207) 中回移：允许在 JSON 和 Dynamic 列上执行 ALTER UPDATE。[#82419](https://github.com/ClickHouse/ClickHouse/pull/82419) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#83015](https://github.com/ClickHouse/ClickHouse/issues/83015) 中回移：Keeper 改进：在后台线程中跨 disk 移动更新日志文件。此前，将更新日志移动到其他 disk 时，会导致 Keeper 整体被阻塞，直到移动完成。如果移动耗时较长 (例如移动到 S3 disk) ，会造成性能下降。[#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#83205](https://github.com/ClickHouse/ClickHouse/issues/83205) 中回移：`SYSTEM RESTART REPLICA` 可能因 ZooKeeper 连接问题而失败。为了避免遗漏这张表，我们现在会持续重试，直到该表创建完成。[#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已在 [#83270](https://github.com/ClickHouse/ClickHouse/issues/83270) 中回移：修复 `clickhouse-benchmark` 中 `--reconnect` 选项的错误默认值。该值曾在 [#79465](https://github.com/ClickHouse/ClickHouse/issues/79465) 中被误改。[#82677](https://github.com/ClickHouse/ClickHouse/pull/82677) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#82928](https://github.com/ClickHouse/ClickHouse/issues/82928) 中回移：Keeper 改进：支持为 world:anyone ACL 指定具体权限。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#83146](https://github.com/ClickHouse/ClickHouse/issues/83146) 中回移：向 `system.s3queue_log` 添加列 `commit_time` 和 `commit_id`。[#83016](https://github.com/ClickHouse/ClickHouse/pull/83016) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#83184](https://github.com/ClickHouse/ClickHouse/issues/83184) 中回移：汇总 clickhouse client 中关于未知配置项的警告，并以摘要形式记录。[#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 已在 [#83281](https://github.com/ClickHouse/ClickHouse/issues/83281) 中回移：此前，对于关联到 select 语句格式错误的 MV 的 INSERT，依赖检查存在问题，用户可能收到晦涩的 `std::exception`，而不是带有明确说明的有意义错误。现已修复。此修复对应：[#82889](https://github.com/ClickHouse/ClickHouse/issues/82889)。[#83190](https://github.com/ClickHouse/ClickHouse/pull/83190) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

* 已回移至 [#83211](https://github.com/ClickHouse/ClickHouse/issues/83211)：修复了 SummingMergeTree 的性能下降问题，该问题由 25.5 中的 [https://github.com/ClickHouse/ClickHouse/pull/79051](https://github.com/ClickHouse/ClickHouse/pull/79051) 引入。[#82130](https://github.com/ClickHouse/ClickHouse/pull/82130) ([Pavel Kruglov](https://github.com/Avogar)) 。

* 已回移至 [#82758](https://github.com/ClickHouse/ClickHouse/issues/82758)：修复了解析 Time 时可能导致 msan 问题的情况。此修复同时解决了 [#82477](https://github.com/ClickHouse/ClickHouse/issues/82477)。[#82514](https://github.com/ClickHouse/ClickHouse/pull/82514) ([Yarik Briukhovetskyi](https://github.com/yariks5s)) 。
