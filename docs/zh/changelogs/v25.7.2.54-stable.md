<div id="improvement">
  #### 改进
</div>

* 已在 [#84783](https://github.com/ClickHouse/ClickHouse/issues/84783) 中回移：此更改为 `ConcurrentBoundedQueue` 的大小新增了一个维度化指标，并以队列类型 (即队列的用途) 和队列 id (即当前队列实例的随机生成 id) 作为标签。[#84675](https://github.com/ClickHouse/ClickHouse/pull/84675) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)) 。
* 已在 [#85007](https://github.com/ClickHouse/ClickHouse/issues/85007) 中回移：在 Keeper 中新增了 4LW `lgrq`，用于切换是否对收到的请求进行日志记录。[#84719](https://github.com/ClickHouse/ClickHouse/pull/84719) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#84869](https://github.com/ClickHouse/ClickHouse/issues/84869) 中回移：降低 Keeper 中存储锁的争用。[#84732](https://github.com/ClickHouse/ClickHouse/pull/84732) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#85001](https://github.com/ClickHouse/ClickHouse/issues/85001) 中回移：使用 `keeper_server.coordination_settings.latest_logs_cache_entry_count_threshold` 和 `keeper_server.coordination_settings.commit_logs_cache_entry_count_threshold` 按条目数量限制 Keeper 日志条目缓存大小。[#84877](https://github.com/ClickHouse/ClickHouse/pull/84877) ([Antonio Andelic](https://github.com/antonio2368)) 。
