<div id="improvement">
  #### 改进

* 已在 [#86333](https://github.com/ClickHouse/ClickHouse/issues/86333) 中回移：新增 `allow_experimental_delta_lake_writes`。[#86180](https://github.com/ClickHouse/ClickHouse/pull/86180) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#86493](https://github.com/ClickHouse/ClickHouse/issues/86493) 中回移：新增仅为特定通道启用 JSON 日志的功能；为此，请将 `logger.formatting.channel` 设置为 `syslog`/`console`/`errorlog`/`log` 之一。[#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 回移至 [#86614](https://github.com/ClickHouse/ClickHouse/issues/86614)：在恢复数据库副本时正确关闭表。关闭不当会导致数据库副本恢复期间某些表引擎出现 `LOGICAL_ERROR`。[#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* 回移至 [#86386](https://github.com/ClickHouse/ClickHouse/issues/86386)：通过 SQL 创建 disk 时，默认处理 `/etc/metrika.xml` 中的 include 配置。[#86232](https://github.com/ClickHouse/ClickHouse/pull/86232) ([alekar](https://github.com/alekar)).
* 回移至 [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653)：修复 plain&#95;rewritable disk 从 Azure Blob 存储读取空 blob 时出现的 `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` 问题。[#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* 回移至 [#86457](https://github.com/ClickHouse/ClickHouse/issues/86457)：修复了 Materialized Views 中的一个问题：某个 MV 在创建、删除后，再以相同名称重新创建时，可能无法正常工作。[#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 回移至 [#86468](https://github.com/ClickHouse/ClickHouse/issues/86468)：修复 `Buffer` 表导致的 `MergesMutationsMemoryTracking` 泄漏，并修复从 `Kafka` (以及其他来源) 流式读取时的 `query_views_log` 问题。[#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
* 回移至 [#86549](https://github.com/ClickHouse/ClickHouse/issues/86549)：修复 getSubcolumnType 中使用未初始化内存的问题。[#86498](https://github.com/ClickHouse/ClickHouse/pull/86498) ([Raúl Marín](https://github.com/Algunenano)).
* 回移至 [#86582](https://github.com/ClickHouse/ClickHouse/issues/86582)：在关闭时忽略刷新日志期间发生的异常，并让关闭过程更安全 (以避免 SIGSEGV) 。[#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
