<div id="new-feature">
  #### 新特性
</div>

* 已在 [#102253](https://github.com/ClickHouse/ClickHouse/issues/102253) 中回移：为 HTTP 连接池套接字的内核 TCP 接收和发送缓冲内存 (`sk_rmem_alloc`, `sk_wmem_alloc`) 新增异步指标，按连接组上报 p50/p75/p90/p95 分位数及总量。[#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#102296](https://github.com/ClickHouse/ClickHouse/issues/102296) 中回移：修复读取 Map 子列时可能出现的逻辑错误。关闭 [#100769](https://github.com/ClickHouse/ClickHouse/issues/100769)。关闭 [#101336](https://github.com/ClickHouse/ClickHouse/issues/101336)。[#101641](https://github.com/ClickHouse/ClickHouse/pull/101641) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#102267](https://github.com/ClickHouse/ClickHouse/issues/102267) 中回移：修复 26.1+ 中文件系统缓存中的 SLRU 竞争缺陷，该问题可能导致空间预留时出现逻辑错误。在调试构建版本中，它还可能导致断言失败：`'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`。[#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#102174](https://github.com/ClickHouse/ClickHouse/issues/102174) 中回移：修复 UDF 刷新时发生的崩溃，该问题是由于 `ZooKeeperRetriesControl` 在未续订已过期的 ZooKeeper 会话时仍进行重试所致。[#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)) 。
