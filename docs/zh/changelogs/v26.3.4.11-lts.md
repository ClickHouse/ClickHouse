<div id="improvement">
  #### 改进
</div>

* 已在 [#101603](https://github.com/ClickHouse/ClickHouse/issues/101603) 中回移：Cgroupv2 内存跟踪现在不再将 `slab_reclaimable` 计入内核内存，因此对不可回收内存使用量的衡量更准确。[#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#101868](https://github.com/ClickHouse/ClickHouse/issues/101868) 中回移：文本索引现已 GA，并且无论 `compatibility` 设置如何都会保持启用，从而避免在备份恢复期间或运行于兼容模式时被意外禁用。[#101518](https://github.com/ClickHouse/ClickHouse/pull/101518) ([Nikita Fomichev](https://github.com/fm4v)) 。
* 已在 [#101862](https://github.com/ClickHouse/ClickHouse/issues/101862) 中回移：将 libarchive 从 3.8.5 升级到 3.8.6。[#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#101856](https://github.com/ClickHouse/ClickHouse/issues/101856) 中回移：将 curl 从 8.18 升级到 8.19。[#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#101461](https://github.com/ClickHouse/ClickHouse/issues/101461) 中回移：修复了 Keeper 中的一个缺陷：如果同一服务器上的另一个无关会话恰好在错误的时机被关闭，读取请求可能会卡住 (导致会话超时) 。[#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#101689](https://github.com/ClickHouse/ClickHouse/issues/101689) 中回移：修复了 usearch `sorted_buffer_gt::insert()` 中的堆缓冲区溢出问题，该问题可能在向量相似性搜索期间导致崩溃或静默地破坏内存。[#100537](https://github.com/ClickHouse/ClickHouse/pull/100537) ([Dustin Healy](https://github.com/dustinhealy)).
* 已在 [#101633](https://github.com/ClickHouse/ClickHouse/issues/101633) 中回移：修复了 parseDateTimeBestEffort 在解析小数秒位数超过 18 位的日期时间字符串时出现的未定义行为 (有符号整数溢出) 。[#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* 已在 [#101364](https://github.com/ClickHouse/ClickHouse/issues/101364) 中回移：修复了在启用 JIT 编译时 (达到编译阈值后) ，`Decimal` 列上的 `MAX`/`MIN` 聚合函数返回错误结果的问题。[#101203](https://github.com/ClickHouse/ClickHouse/pull/101203) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#101625](https://github.com/ClickHouse/ClickHouse/issues/101625) 中回移：修复了当查询同时读取包含 Dynamic Map type 的 Tuple 列及其子列时，服务器发生崩溃的问题 (逻辑错误：&quot;Variant ... is empty&quot;)  (例如，`SELECT ... WHERE NOT ignore(*, mapKeys(t.m))`) 。[#101448](https://github.com/ClickHouse/ClickHouse/pull/101448) ([Groene AI](https://github.com/groeneai)).
