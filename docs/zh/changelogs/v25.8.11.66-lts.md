<div id="improvement">
  #### 改进
</div>

* 回移至 [#88492](https://github.com/ClickHouse/ClickHouse/issues/88492)：对备份目标位置执行服务端 (native) 复制时，使用带有备份专用设置 (例如 `backup_slow_all_threads_after_retryable_s3_error`) 的 S3 存储客户端。将 `s3_slow_all_threads_after_retryable_error` 标记为已废弃。[#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva))。
* 回移至 [#88537](https://github.com/ClickHouse/ClickHouse/issues/88537)：为 Iceberg SELECT 的性能跟踪添加更多信息。[#87903](https://github.com/ClickHouse/ClickHouse/pull/87903) ([Daniil Ivanik](https://github.com/divanik))。
* 回移至 [#88300](https://github.com/ClickHouse/ClickHouse/issues/88300)：更新 Azure SDK，纳入在 copy 和 create container 功能中出现的 `Content-Length` 修复。[#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni))。
* 回移至 [#88742](https://github.com/ClickHouse/ClickHouse/issues/88742)：新增配置项 `keeper_server.coordination_settings.check_node_acl_on_remove`。如果启用，则每次删除节点前都会校验该节点自身及其父节点的 ACL；否则仅校验父节点的 ACL。[#88513](https://github.com/ClickHouse/ClickHouse/pull/88513) ([Antonio Andelic](https://github.com/antonio2368))。
* 回移至 [#88781](https://github.com/ClickHouse/ClickHouse/issues/88781)：修复由 `GLOBAL IN` 导致的内存泄漏 ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)) 。[#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94))。
* 回移至 [#88764](https://github.com/ClickHouse/ClickHouse/issues/88764)：为 `clickhouse-keeper` 的 postinstall 脚本新增一个步骤，以启用开机自启动。[#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan))。
