  ### ClickHouse 发布版本 v26.2.10.10-稳定版本 (4fc1e4f53f8) FIXME，与 v26.2.9.9-稳定版本 (94b91bf8dcf) 相比

<div id="new-feature">
  #### 新特性
</div>

* 已在 [#102251](https://github.com/ClickHouse/ClickHouse/issues/102251) 中回移：为 HTTP 连接池套接字的内核 TCP 接收和发送缓冲区内存 (`sk_rmem_alloc`、`sk_wmem_alloc`) 新增异步指标，并按连接分组以 p50/p75/p90/p95 分位数和总计形式上报。[#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#102324](https://github.com/ClickHouse/ClickHouse/issues/102324) 中回移：在嵌入式客户端 (SSH 和 WebSocket 协议) 中禁用 AI SQL 生成功能 (`??` 命令) ，以防止访问服务器的环境变量。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#102339](https://github.com/ClickHouse/ClickHouse/issues/102339) 中回移：修复将 result table 重构为 Web 组件后，play.html Web UI 中列宽调整的问题。[#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#101947](https://github.com/ClickHouse/ClickHouse/issues/101947) 中回移：优化服务器启动时的缓存加载。[#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#102138](https://github.com/ClickHouse/ClickHouse/issues/102138) 中回移：将内部 mongo-c-driver 从 2.2.2 升级到 2.2.3。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移至 [#102277](https://github.com/ClickHouse/ClickHouse/issues/102277)：修复 `addStreams` 期间 stream 构造函数抛出异常时，`MergeTreeDataPartWriterWide::cancel` 中出现的 SIGSEGV 问题；该问题会导致 `column_streams` 中留下一个空条目。[#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368))。
* 已回移至 [#102265](https://github.com/ClickHouse/ClickHouse/issues/102265)：修复 26.1+ 中文件系统缓存的 SLRU 竞争问题，它可能导致空间预留逻辑错误。在调试构建中，还可能导致断言失败：`'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`。[#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 已回移至 [#102172](https://github.com/ClickHouse/ClickHouse/issues/102172)：修复 UDF 刷新时的崩溃问题，原因是 `ZooKeeperRetriesControl` 在未续期的情况下，对已过期的 ZooKeeper 会话进行了重试。[#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v))。
* 已回移至 [#102237](https://github.com/ClickHouse/ClickHouse/issues/102237)：修复查询带有 WHERE 子句的视图时发生的崩溃 (SIGSEGV) 问题。该问题出现在内部查询生成的列类型与视图元数据不一致时 (例如启用 `join_use_nulls` 时，LEFT JOIN 生成的 Nullable) 。[#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
