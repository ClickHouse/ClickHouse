<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 已在 [#92120](https://github.com/ClickHouse/ClickHouse/issues/92120) 中回移：这是对 [https://github.com/ClickHouse/ClickHouse/pull/88380](https://github.com/ClickHouse/ClickHouse/pull/88380) 的后续跟进。此 PR 将 projections 中禁用位置参数标记为一项向后不兼容的变更。此外，它还引入了 `enable_positional_arguments_for_projections` 设置，以便在 projections 中存在位置参数时，能够安全升级 ClickHouse 集群。[#92007](https://github.com/ClickHouse/ClickHouse/pull/92007) ([Dmitry Novik](https://github.com/novikd)).

<div id="improvement">
  #### 改进
</div>

* 已在[#92571](https://github.com/ClickHouse/ClickHouse/issues/92571)中回移：使聚合/排序期间用于检测查询内存使用量并触发落盘的机制更加稳健。[#92500](https://github.com/ClickHouse/ClickHouse/pull/92500) ([Azat Khuzhin](https://github.com/azat)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#92530](https://github.com/ClickHouse/ClickHouse/issues/92530) 中回移：修复 Log 引擎在读取子列时可能出现的逻辑错误。关闭 [#91710](https://github.com/ClickHouse/ClickHouse/issues/91710)。[#91711](https://github.com/ClickHouse/ClickHouse/pull/91711) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#92256](https://github.com/ClickHouse/ClickHouse/issues/92256) 中回移：为共享数据中存在重复 path 的 JSON 以及动态 path 添加修复机制，这种情况可能由 [https://github.com/ClickHouse/ClickHouse/pull/90816](https://github.com/ClickHouse/ClickHouse/pull/90816) 中已修复的 bug 导致。[#91886](https://github.com/ClickHouse/ClickHouse/pull/91886) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#92555](https://github.com/ClickHouse/ClickHouse/issues/92555) 中回移：进行 schema 推断时，对于通配符匹配到的文件，只缓存推断出该 schema 的那个文件，而不是缓存所有文件。关闭 [#91745](https://github.com/ClickHouse/ClickHouse/issues/91745)。[#92006](https://github.com/ClickHouse/ClickHouse/pull/92006) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#92683](https://github.com/ClickHouse/ClickHouse/issues/92683) 中回移：在 insert select 中释放请求 stream，以避免关闭 HTTP connection。[#92175](https://github.com/ClickHouse/ClickHouse/pull/92175) ([Sema Checherinda](https://github.com/CheSema)) 。
* 已在 [#92707](https://github.com/ClickHouse/ClickHouse/issues/92707) 中回移：修复 `count_distinct_optimization` 在窗口函数和多参数场景下的处理问题。[#92376](https://github.com/ClickHouse/ClickHouse/pull/92376) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#92431](https://github.com/ClickHouse/ClickHouse/issues/92431) 中回移：修复聚合函数在 MEMORY&#95;LIMIT&#95;EXCEEDED 后可能发生崩溃的问题。[#92390](https://github.com/ClickHouse/ClickHouse/pull/92390) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#92674](https://github.com/ClickHouse/ClickHouse/issues/92674) 中回移：在 MergeTree 中执行变更期间继承源分片的序列化信息设置。这修复了数据 types 序列化发生变化后，查询已变更分片时可能返回错误结果的问题。[#92419](https://github.com/ClickHouse/ClickHouse/pull/92419) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#92622](https://github.com/ClickHouse/ClickHouse/issues/92622) 中回移：修复对 Backup database 执行 SHOW CREATE DATABASE 时的死锁问题。[#92541](https://github.com/ClickHouse/ClickHouse/pull/92541) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#92665](https://github.com/ClickHouse/ClickHouse/issues/92665) 中回移：防止 `tokens()` 在第二个参数为 null 时发生崩溃。[#92586](https://github.com/ClickHouse/ClickHouse/pull/92586) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#92743](https://github.com/ClickHouse/ClickHouse/issues/92743) 中回移：修复在 `WHERE` 中使用 `not match(...)` 时数据 skipping 逻辑中的 bug，该问题会导致结果错误。关闭 [#92492](https://github.com/ClickHouse/ClickHouse/issues/92492)。[#92726](https://github.com/ClickHouse/ClickHouse/pull/92726) ([Nihal Z. Miaji](https://github.com/nihalzp)) 。

* 已在 [#92803](https://github.com/ClickHouse/ClickHouse/issues/92803) 中回移：修复了 ALTER TABLE REWRITE PARTS (v2) 中的 &quot;Cannot add action to empty ExpressionActionsChain&quot; 问题。[#92754](https://github.com/ClickHouse/ClickHouse/pull/92754) ([Azat Khuzhin](https://github.com/azat)) 。
