<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#85306](https://github.com/ClickHouse/ClickHouse/issues/85306) 中回移：修复了 ALTER MODIFY ORDER BY 未校验排序键中的生存时间 (TTL) 列的问题。现在，在 ALTER 操作期间，如果在 ORDER BY 子句中使用生存时间 (TTL) 列，将被正确拒绝，从而防止潜在的表损坏。[#84536](https://github.com/ClickHouse/ClickHouse/pull/84536) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* 已在 [#85381](https://github.com/ClickHouse/ClickHouse/issues/85381) 中回移：修复了 `ReplicatedMergeTree` 中补丁分区片段的清理问题。此前，在将用于物化补丁分区片段的已合并或已变更 parts 从另一副本下载下来之前，轻量级更新的结果可能会暂时在当前副本上不可见。[#85121](https://github.com/ClickHouse/ClickHouse/pull/85121) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#85246](https://github.com/ClickHouse/ClickHouse/issues/85246) 中回移：修复了 MV 中类型不同时出现的 illegal&#95;type&#95;of&#95;argument 问题。[#85135](https://github.com/ClickHouse/ClickHouse/pull/85135) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#85236](https://github.com/ClickHouse/ClickHouse/issues/85236) 中回移：修复了 `additional_table_filters expression` 设置中 `IN (subquery)` 内的 `Not-ready Set` 问题。[#85210](https://github.com/ClickHouse/ClickHouse/pull/85210) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#85264](https://github.com/ClickHouse/ClickHouse/issues/85264) 中回移：去除了 SYSTEM DROP REPLICA 查询期间不必要的 `getStatus()` 调用。修复了表在后台删除时抛出 `Shutdown for storage is called` 异常的问题。[#85220](https://github.com/ClickHouse/ClickHouse/pull/85220) ([Nikolay Degterinsky](https://github.com/evillique)).
