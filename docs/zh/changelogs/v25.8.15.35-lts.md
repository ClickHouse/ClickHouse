  #### 改进

* 已在 [#94146](https://github.com/ClickHouse/ClickHouse/issues/94146) 中回移：在某些情况下，我们发现 ClickHouse 在从表读取数据时不会遵循内存限制。此问题现已修复。[#93715](https://github.com/ClickHouse/ClickHouse/pull/93715) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#93845](https://github.com/ClickHouse/ClickHouse/issues/93845) 中回移：修复了在某些情况下，从名称中包含点号的列读取子列时出现的问题。解决了 [#81261](https://github.com/ClickHouse/ClickHouse/issues/81261)、[#82058](https://github.com/ClickHouse/ClickHouse/issues/82058)、[#88169](https://github.com/ClickHouse/ClickHouse/issues/88169)。[#87205](https://github.com/ClickHouse/ClickHouse/pull/87205) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#92032](https://github.com/ClickHouse/ClickHouse/issues/92032) 中回移：修复了 GenerateRandom 表引擎在非字面量参数下崩溃的问题：现在会返回带有明确消息的 BAD&#95;ARGUMENTS，而不是 LOGICAL&#95;ERROR。[#88157](https://github.com/ClickHouse/ClickHouse/pull/88157) ([Shafi Ahmed](https://github.com/ita004)) 。
* 已在 [#90417](https://github.com/ClickHouse/ClickHouse/issues/90417) 中回移：修复了由于析构顺序错误导致 server 在正常关闭过程中崩溃的问题。解决了 [#82420](https://github.com/ClickHouse/ClickHouse/issues/82420)。[#90076](https://github.com/ClickHouse/ClickHouse/pull/90076) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#94010](https://github.com/ClickHouse/ClickHouse/issues/94010) 中回移：修复了 randomStringUTF8 中因整数溢出导致的崩溃。[#90326](https://github.com/ClickHouse/ClickHouse/pull/90326) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已在 [#93719](https://github.com/ClickHouse/ClickHouse/issues/93719) 中回移：修复了 analyzer 中列别名里的动态子列解析问题。此前，列别名中的动态子列会被包装为 `getSubcolumn`，并且在某些情况下可能根本无法解析。关闭了 [#91434](https://github.com/ClickHouse/ClickHouse/issues/91434)。[#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#93952](https://github.com/ClickHouse/ClickHouse/issues/93952) 中回移：修复了存储 `S3Queue` 在 `Ordered` 模式下出现的逻辑错误 ` Failed to set file processing within 100 retries`。该错误现已改为警告。在 25.10 之前的版本中，如果 Keeper 会话过期，可能会发生此错误；不过在 25.10+ 版本中，它仍只会显示为警告，因为在 `Ordered` 模式下处理并发度较高时，理论上仍有可能触发此错误。[#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#93590](https://github.com/ClickHouse/ClickHouse/issues/93590) 中回移：修复了终止后台调度池时可能发生的卡住问题 (可能导致 server 在关闭时卡住) 。[#93008](https://github.com/ClickHouse/ClickHouse/pull/93008) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#93557](https://github.com/ClickHouse/ClickHouse/issues/93557) 中回移：修复了在反序列化格式错误且 offsets 越界的 `groupConcat` 聚合状态时发生的崩溃。[#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)) 。
* 已在 [#93400](https://github.com/ClickHouse/ClickHouse/issues/93400) 中回移：修复了在存在标量关联子查询时，从子查询中移除未使用列的问题。修复前，如果某列仅在关联子查询中使用，它也可能被移除，从而导致查询因 `NOT_FOUND_COLUMN_IN_BLOCK` 错误而失败。[#93273](https://github.com/ClickHouse/ClickHouse/pull/93273) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#93470](https://github.com/ClickHouse/ClickHouse/issues/93470) 中回移：修复了 `groupConcat` 状态反序列化中的整数溢出漏洞，该漏洞可能在构造的聚合状态下引发内存安全问题。[#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath))。
* 已在 [#93685](https://github.com/ClickHouse/ClickHouse/issues/93685) 中回移：确保 ZooKeeper 在关闭时能够完成清理 (修复了极少数情况下关闭时可能挂起的问题) 。[#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#93951](https://github.com/ClickHouse/ClickHouse/issues/93951) 中回移：修复了在存在去重竞争条件时恢复 ReplicatedMergeTree 会触发 LOGICAL&#95;ERROR 的问题。[#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos))。
* 已在 [#94147](https://github.com/ClickHouse/ClickHouse/issues/94147) 中回移：修复了在某些输入格式中直接反序列化到 Sparse 列时，将 Sparse 列用于生存时间 (TTL) 更新的问题。同时修复了可能出现的逻辑错误 `Unexpected type of result TTL column`。[#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar))。
* 已在 [#93805](https://github.com/ClickHouse/ClickHouse/issues/93805) 中回移：校验解压后缓冲区的大小是否符合预期。[#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano))。
