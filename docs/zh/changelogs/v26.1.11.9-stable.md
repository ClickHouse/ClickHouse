<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移到 [#102655](https://github.com/ClickHouse/ClickHouse/issues/102655)：修复 `ASTColumnsExceptTransformer::transform` 中的 LOGICAL&#95;ERROR 异常。[#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* 已回移到 [#101418](https://github.com/ClickHouse/ClickHouse/issues/101418)：修复 StringSearcher.h 中 use-of-uninitialized-value 问题。[#100225](https://github.com/ClickHouse/ClickHouse/pull/100225) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已回移到 [#102677](https://github.com/ClickHouse/ClickHouse/issues/102677)：修复 CPU lease scheduler 中的 use-after-free 崩溃问题：当等待定时器的生命周期超过其所引用 `ProfileEvents::Counters` 的工作线程时，就会触发该问题。[#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* 已回移到 [#102709](https://github.com/ClickHouse/ClickHouse/issues/102709)：修复 26.1+ 中文件系统缓存的 SLRU 竞争问题，该问题可能导致空间预留 logical error。在 debug build 中，还可能触发以下断言失败：`'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`。[#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已回移到 [#102750](https://github.com/ClickHouse/ClickHouse/issues/102750)：修复在已有 collection 上执行 `CREATE NAMED COLLECTION IF NOT EXISTS` 时导致 `NamedCollection` CurrentMetric 被错误放大的问题，以及启动时从 config 或 SQL storage 加载的 collection 未初始化的问题。关闭 [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507)。[#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* 已回移到 [#102795](https://github.com/ClickHouse/ClickHouse/issues/102795)：修复 row policy 在某些特殊情况下会触发 “Not found column in block” 异常的问题。[#102648](https://github.com/ClickHouse/ClickHouse/pull/102648) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已回移到 [#102743](https://github.com/ClickHouse/ClickHouse/issues/102743)：修复在等待过程中删除可刷新materialized view 时，`SYSTEM WAIT VIEW` 会一直挂起的问题。[#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
