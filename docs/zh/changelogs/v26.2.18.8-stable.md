  ### ClickHouse 发布 v26.2.18.8-稳定版本 (0aad8577ed5) FIXME，较 v26.2.17.31-稳定版本 (5e87b68d622)

<div id="new-feature">
  #### 新特性
</div>

* 已在 [#104161](https://github.com/ClickHouse/ClickHouse/issues/104161) 中回移：为可刷新materialized view 新增了 `SYSTEM PAUSE VIEW [db.]name` 和 `SYSTEM PAUSE VIEWS` 查询。与 `SYSTEM STOP VIEW` 不同，`SYSTEM PAUSE VIEW` 不会中断当前正在进行的刷新——正在执行的刷新会继续完成，只会阻止后续刷新。可通过 `SYSTEM START VIEW` 或 `SYSTEM START VIEWS` 恢复，这两个命令现在都会统一清除 stopped 和 paused 两种状态。[#103252](https://github.com/ClickHouse/ClickHouse/pull/103252) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#104199](https://github.com/ClickHouse/ClickHouse/issues/104199) 中回移：修复 SummingMergeTree 和 CoalescingMergeTree merge 期间将 `MEMORY_LIMIT_EXCEEDED` 异常误报为 `CORRUPTED_DATA` 的问题。[#97537](https://github.com/ClickHouse/ClickHouse/pull/97537) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* 已在 [#104149](https://github.com/ClickHouse/ClickHouse/issues/104149) 中回移：对 row policies/additional&#95;table&#95;filters 禁用简单 LIMIT 优化 (以支持并行索引分析) 。[#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#103827](https://github.com/ClickHouse/ClickHouse/issues/103827) 中回移：修复当聚合投影匹配查询、且表中的某些 parts 没有投影数据时，`SELECT DISTINCT` 会静默返回不完整结果的问题 (例如，在一个已含数据的表上新增该投影后，未运行 `MATERIALIZE PROJECTION`) 。关闭 [#102951](https://github.com/ClickHouse/ClickHouse/issues/102951)。[#103052](https://github.com/ClickHouse/ClickHouse/pull/103052) ([Nihal Z. Miaji](https://github.com/nihalzp))。
* 已在 [#104196](https://github.com/ClickHouse/ClickHouse/issues/104196) 中回移：修复读取 `AggregateFunction(topK(N), String)` 列时出现 `SIZES_OF_ARRAYS_DONT_MATCH` 的问题；该问题发生在其持久化的 `alpha_size` 因 pre-25.12 的一次 deserialize+serialize 循环而变大之后。[#104002](https://github.com/ClickHouse/ClickHouse/pull/104002) ([Raúl Marín](https://github.com/Algunenano))。
* 已在 [#104191](https://github.com/ClickHouse/ClickHouse/issues/104191) 中回移：修复反序列化 `quantileTiming` 状态时发生越界写入的问题。[#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
