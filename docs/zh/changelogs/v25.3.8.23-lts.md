<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#88220](https://github.com/ClickHouse/ClickHouse/issues/88220) 中回移：修复了一个崩溃问题：某些用户提交到 `AggregateFunction(quantileDD)` 列的有效数据可能导致合并操作无限递归。[#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)) 。
* 已在 [#88598](https://github.com/ClickHouse/ClickHouse/issues/88598) 中回移：修复了当 `parallel_replicas_for_cluster_functions` 设置为 1 时，使用 `url()` 表函数解析表 schema 的问题。[#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已在 [#88647](https://github.com/ClickHouse/ClickHouse/issues/88647) 中回移：对于节点数 &gt; 10 的大型集群，在恢复时有很高概率因报错 `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again` 而失败。`num_hosts` 节点会被多个主机同时覆盖。此修复将控制重试次数的设置改为动态。关闭 [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721)。[#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#88712](https://github.com/ClickHouse/ClickHouse/issues/88712) 中回移：修复了底层 const PREWHERE 列发生并发变更时可能引发的潜在崩溃。[#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#88902](https://github.com/ClickHouse/ClickHouse/issues/88902) 中回移：恢复后，Replicated 数据库的副本可能会长时间卡住，并持续打印类似 `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)` 的消息；该问题现已修复。[#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#88886](https://github.com/ClickHouse/ClickHouse/issues/88886) 中回移：修复了对 `loop` 表函数执行 select 时的访问校验问题。[#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)) 。
* 已在 [#89033](https://github.com/ClickHouse/ClickHouse/issues/89033) 中回移：修复了函数 `reverseUTF8` 中的缺陷。在之前的版本中，它会错误地反转长度为 4 的 UTF-8 码点的字节顺序。此项关闭 [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913)。[#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
