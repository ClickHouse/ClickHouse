* 为 `clickhouse-server` 和 `clickhouse-keeper` 新增 distroless Docker 镜像变体，标签为 `<version>-distroless`。[#101442](https://github.com/ClickHouse/ClickHouse/pull/101442) ([Rahul Nair](https://github.com/motsc)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#100462](https://github.com/ClickHouse/ClickHouse/issues/100462) 中回移：对 poco 内部的 std 流设置 `this->exceptions(std::ios::badbit);`。[#96455](https://github.com/ClickHouse/ClickHouse/pull/96455) ([Sema Checherinda](https://github.com/CheSema)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#99090](https://github.com/ClickHouse/ClickHouse/issues/99090) 中回移：修复通过 `clickhouse-client` 的 `--external` 传入的外部表无法按名称访问 Tuple 子列的问题 (例如对 `Tuple(a UUID, b Int32)` 使用 `SELECT x.a`) 。关闭了 [#96925](https://github.com/ClickHouse/ClickHouse/issues/96925)。[#98755](https://github.com/ClickHouse/ClickHouse/pull/98755) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#100488](https://github.com/ClickHouse/ClickHouse/issues/100488) 中回移：JDBC、ODBC 和 NATS 连接字符串中的凭据现在会在查询日志和 `SHOW CREATE` 输出中进行脱敏，防止敏感信息意外泄露。对于 URI 风格的连接字符串 (例如 {scheme}://{user}:{password}@{host}) ，现在仅脱敏密码部分，其余部分保持可见，以便于调试。`nats_token` 设置现在也会被脱敏。[#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#100592](https://github.com/ClickHouse/ClickHouse/issues/100592) 中回移：修复在 `optimize_on_insert=0` 时，向包含嵌套 `Array(JSON)` 列且使用 wide parts 的表插入数据时出现的 LOGICAL&#95;ERROR 异常“Stream ... not found”问题。[#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#100722](https://github.com/ClickHouse/ClickHouse/issues/100722) 中回移：修复当 projection 的 SELECT 部分包含查询原始 SELECT 部分中不存在的列时出现的 NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK 问题。关闭了 [#100194](https://github.com/ClickHouse/ClickHouse/issues/100194)。[#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
