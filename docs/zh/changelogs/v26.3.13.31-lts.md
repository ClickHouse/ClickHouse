<div id="backward-incompatible-change">
  #### 不兼容的变更
</div>

* 已在 [#106045](https://github.com/ClickHouse/ClickHouse/issues/106045) 中回移：设置 `show_data_lake_catalogs_in_system_tables` 已重命名为 `show_remote_databases_in_system_tables`，并扩展了适用范围：当其值为 0 (默认值) 时，除了数据湖目录外，`MySQL` 和 `PostgreSQL` 数据库也会在 `system.tables`、`system.columns` 和 `system.completions` 中被隐藏。旧的设置名称仍作为别名保留。[#104416](https://github.com/ClickHouse/ClickHouse/pull/104416) ([Pablo Marcos](https://github.com/pamarcos)) 。

<div id="new-feature">
  #### 新特性
</div>

* 已在 [#104562](https://github.com/ClickHouse/ClickHouse/issues/104562) 中回移：为可刷新materialized view 新增了 `SYSTEM PAUSE VIEW [db.]name` 和 `SYSTEM PAUSE VIEWS` 查询。与 `SYSTEM STOP VIEW` 不同，`SYSTEM PAUSE VIEW` 不会中断当前正在运行的 刷新——正在进行中的 刷新 会继续完成，只会阻止后续的 刷新。可通过 `SYSTEM START VIEW` 或 `SYSTEM START VIEWS` 撤销；这两个命令现在都会统一清除 stopped 和 paused 两种状态。[#103252](https://github.com/ClickHouse/ClickHouse/pull/103252) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#105589](https://github.com/ClickHouse/ClickHouse/issues/105589) 中回移：采用 APPEND 模式的 Replicated 可刷新materialized view，如果在刷新期间与 ZooKeeper 的连接曾短暂中断，将不再刷新两次。[#104051](https://github.com/ClickHouse/ClickHouse/pull/104051) ([Michael Kolupaev](https://github.com/al13n321)) 。
