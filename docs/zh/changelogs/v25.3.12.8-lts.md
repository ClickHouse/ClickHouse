  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#92689](https://github.com/ClickHouse/ClickHouse/issues/92689) 中回移：修复读取子列时 Log 引擎中可能出现的逻辑错误。关闭 [#91710](https://github.com/ClickHouse/ClickHouse/issues/91710)。[#91711](https://github.com/ClickHouse/ClickHouse/pull/91711) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#92895](https://github.com/ClickHouse/ClickHouse/issues/92895) 中回移：修复列与同名子列之间可能发生的冲突，该问题会导致使用错误的序列化方式并使查询失败。关闭 [#90219](https://github.com/ClickHouse/ClickHouse/issues/90219)。关闭 [#85161](https://github.com/ClickHouse/ClickHouse/issues/85161)。[#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#93117](https://github.com/ClickHouse/ClickHouse/issues/93117) 中回移：重构了通配符授权检查中的错误逻辑。此前的尝试 [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) 修复了一个严重漏洞，但限制过于严格，导致某些通配符 `GRANT` 语句因无关的撤销授权而失败。[#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)) 。
* 已在 [#93219](https://github.com/ClickHouse/ClickHouse/issues/93219) 中回移：修复在 JSON 中为路径 &#39;skip&#39; 创建类型提示时的问题。关闭 [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731)。[#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#93218](https://github.com/ClickHouse/ClickHouse/issues/93218) 中回移：修复通过 alter 将设置 `ratio_of_defaults_for_sparse_serialization` 改为 `1.0` 后，稀疏列变更之后可能出现的 FILE&#95;DOESNT&#95;EXIST 错误。[#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#93040](https://github.com/ClickHouse/ClickHouse/issues/93040) 中回移：修复在 WHERE 中使用 `not materialize(...)` 或 `not CAST(...)` 时，数据 skipping 逻辑中的缺陷，该问题会导致结果错误。关闭 [#88536](https://github.com/ClickHouse/ClickHouse/issues/88536)。[#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)) 。
