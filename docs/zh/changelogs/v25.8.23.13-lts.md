<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移到 [#103184](https://github.com/ClickHouse/ClickHouse/issues/103184)：修复在 JSON 列上创建的 min-max 索引使用错误极值，导致查询结果错误的问题。关闭 [#101700](https://github.com/ClickHouse/ClickHouse/issues/101700)。[#101918](https://github.com/ClickHouse/ClickHouse/pull/101918) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移到 [#102352](https://github.com/ClickHouse/ClickHouse/issues/102352)：修复 `MergeTreeDataPartWriterWide::cancel` 中的 SIGSEGV 问题：当 `addStreams` 期间某个 stream 构造函数抛出异常时，会在 `column_streams` 中留下一个空条目。[#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已回移到 [#102968](https://github.com/ClickHouse/ClickHouse/issues/102968)：修复时区调整后发生溢出时日期数据类型推断错误的问题。关闭 [#102601](https://github.com/ClickHouse/ClickHouse/issues/102601)。[#102674](https://github.com/ClickHouse/ClickHouse/pull/102674) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移到 [#103300](https://github.com/ClickHouse/ClickHouse/issues/103300)：修复对使用二进制编码的数据类型进行扁平化的 Dynamic 类型时的序列化问题。关闭 [#101911](https://github.com/ClickHouse/ClickHouse/issues/101911)。[#102692](https://github.com/ClickHouse/ClickHouse/pull/102692) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移到 [#103018](https://github.com/ClickHouse/ClickHouse/issues/103018)：在新的 analyzer 中将行策略的 OR 链优化为 IN。[#102915](https://github.com/ClickHouse/ClickHouse/pull/102915) ([Azat Khuzhin](https://github.com/azat)) 。
* 已回移到 [#103663](https://github.com/ClickHouse/ClickHouse/issues/103663)：修复 Parquet ColumnIndex 中 String 列统计信息出现 `min_value > max_value` 的问题。[#103334](https://github.com/ClickHouse/ClickHouse/pull/103334) ([Saurabh Kumar Ojha](https://github.com/saurabhojha)) 。
* 已回移到 [#103408](https://github.com/ClickHouse/ClickHouse/issues/103408)：在 Native 格式中检查格式错误的扁平化 Dynamic 数据。[#103392](https://github.com/ClickHouse/ClickHouse/pull/103392) ([Pavel Kruglov](https://github.com/Avogar)) 。
