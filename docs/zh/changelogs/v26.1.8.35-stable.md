<div id="improvement">
  #### 改进

* 已在 [#102311](https://github.com/ClickHouse/ClickHouse/issues/102311) 中回移：在嵌入式客户端 (SSH 和 WebSocket 协议) 中禁用 AI SQL generation (`??` 命令) ，以防止访问服务器的环境变量。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

* 已在 [#102136](https://github.com/ClickHouse/ClickHouse/issues/102136) 中回移：将内部 mongo-c-driver 从 2.2.2 升级到 2.2.3。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#101925](https://github.com/ClickHouse/ClickHouse/issues/101925) 中回移：将 libarchive 从 3.8.5 升级到 3.8.6。[#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#101852](https://github.com/ClickHouse/ClickHouse/issues/101852) 中回移：将 curl 从 8.18 升级到 8.19。[#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)) 。

* 已在 [#101183](https://github.com/ClickHouse/ClickHouse/issues/101183) 中回移：修复服务器关闭期间加载字典时，因空指针解引用导致的 segfault。字典线程会并发调用 `Context::getUserDefinedSQLObjectsStorage` (会解引用 `user_defined_sql_objects_storage`) ，而主线程会调用 `Context::shutdown` (将 `user_defined_sql_objects_storage` 设为 null) 。我们需要确保在执行 `Context::shutdown` 之前，先禁用字典加载器中的后续更新，终止当前正在运行的字典查询，并等待字典加载线程结束——这与我们处理普通查询的方式类似。[#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
