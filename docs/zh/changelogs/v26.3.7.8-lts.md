<div id="improvement">
  #### 改进
</div>

* 已在 [#102314](https://github.com/ClickHouse/ClickHouse/issues/102314) 中回移：在嵌入式客户端 (SSH 和 WebSocket 协议) 中禁用 AI SQL 生成 (`??` 命令) ，以防止访问服务器环境变量。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#102340](https://github.com/ClickHouse/ClickHouse/issues/102340) 中回移：在结果表重构为 Web 组件后，修复 play.html web UI 中的列宽调整问题。[#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#102370](https://github.com/ClickHouse/ClickHouse/issues/102370) 中回移：修复了一个缺陷：如果文件的 HEAD 请求响应中缺少 `Content-Length` 请求头 (例如由于 GCS 中的解压缩转码) ，ClickHouse 可能会跳过这些文件。[#99971](https://github.com/ClickHouse/ClickHouse/pull/99971) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已在 [#101534](https://github.com/ClickHouse/ClickHouse/issues/101534) 中回移：某些目录可能会在 `select * from system.databases` 查询结果的 `SETTINGS` 部分显示敏感信息。此 PR 可防止这种情况发生。[#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 已在 [#102436](https://github.com/ClickHouse/ClickHouse/issues/102436) 中回移：修复了 S3 `Client::~Client` 析构函数中抛出的异常导致服务器终止的问题。[#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
* 已在 [#102279](https://github.com/ClickHouse/ClickHouse/issues/102279) 中回移：修复了 `MergeTreeDataPartWriterWide::cancel` 中的 SIGSEGV；当某个流构造函数在 `addStreams` 期间抛出异常时，会在 `column_streams` 中留下一个空条目。[#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#102240](https://github.com/ClickHouse/ClickHouse/issues/102240) 中回移：修复了查询带有 WHERE 子句的视图时发生的崩溃 (SIGSEGV) ；当内部查询生成的列类型与视图元数据不一致时 (例如启用 `join_use_nulls` 时，LEFT JOIN 产生的 Nullable) ，就会触发该问题。[#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
