  ### ClickHouse 发布 v24.8.6.70-lts (ddb8c219771) FIXME，相比 v24.8.5.115-lts (8c4cb00a384)
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 已在 [#71359](https://github.com/ClickHouse/ClickHouse/issues/71359) 中回移：修复了 JSON 子列文件中未转义的特殊字符可能导致的 `No such file or directory` 错误。[#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#70680](https://github.com/ClickHouse/ClickHouse/issues/70680) 中回移：从 keeper 同步 `user_directories` 时不再进行校验。[#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#71395](https://github.com/ClickHouse/ClickHouse/issues/71395) 中回移：列出目录时不再调用对象存储 API，因为这样做的成本效益较低。改为将文件名列表存储在内存中。相应的权衡是初始加载时间更长，并且需要更多内存来存储文件名。[#70823](https://github.com/ClickHouse/ClickHouse/pull/70823) ([Julia Kartseva](https://github.com/jkartseva)).
* 已在 [#71287](https://github.com/ClickHouse/ClickHouse/issues/71287) 中回移：减少 `plain_rewritable` 磁盘上的对象存储 HEAD API 请求数量。[#70915](https://github.com/ClickHouse/ClickHouse/pull/70915) ([Julia Kartseva](https://github.com/jkartseva)).

* 已在 [#70623](https://github.com/ClickHouse/ClickHouse/issues/70623) 中回移：修复在创建包含两个 SELECT 和一个 `INTERSECT` 的 materialized view 时，服务器发生段错误的问题，例如 `CREATE MATERIALIZED VIEW v0 AS (SELECT 1) INTERSECT (SELECT 1);`。[#70264](https://github.com/ClickHouse/ClickHouse/pull/70264) ([Konstantin Bogdanov](https://github.com/thevar1able)).

* 已在 [#70556](https://github.com/ClickHouse/ClickHouse/issues/70556) 中回移：修复 WHERE 中 lambda function 导致的崩溃问题。[#70464](https://github.com/ClickHouse/ClickHouse/pull/70464) ([Raúl Marín](https://github.com/Algunenano)).
