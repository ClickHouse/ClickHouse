<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#74222](https://github.com/ClickHouse/ClickHouse/issues/74222) 中回移：避免在 `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` 后出现暂停。获取用于后台任务调度的正确设置。 [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 已在 [#73889](https://github.com/ClickHouse/ClickHouse/issues/73889) 中回移：修复 Dynamic 列和 JSON 列在准备 squashin 时的问题。此前在某些情况下，即使尚未达到 types/paths 的限制，新类型也可能被插入到 shared variant/shared data 中。 [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74435](https://github.com/ClickHouse/ClickHouse/issues/74435) 中回移：修复当字典的数据源包含带有错误数据的函数时触发的 segfault。 [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已在 [#74139](https://github.com/ClickHouse/ClickHouse/issues/74139) 中回移：修复 Dynamic 列中可能出现的数据不一致问题。修复可能出现的逻辑错误 `Nested columns sizes are inconsistent with local_discriminators column size`。 [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74527](https://github.com/ClickHouse/ClickHouse/issues/74527) 中回移：修复包含 `FINAL` 和 `SAMPLE` 的查询中的 `NOT_FOUND_COLUMN_IN_BLOCK`。修复从 `CollapsingMergeTree` 执行带 `FINAL` 的 SELECT 查询时结果错误的问题，并启用 `FINAL` 的优化。 [#73682](https://github.com/ClickHouse/ClickHouse/pull/73682) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#74138](https://github.com/ClickHouse/ClickHouse/issues/74138) 中回移：修复 Dynamic/Object 结构的反序列化问题。该问题可能导致 CANNOT&#95;READ&#95;ALL&#95;DATA 异常。 [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74111](https://github.com/ClickHouse/ClickHouse/issues/74111) 中回移：修复了 [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078) (S3 Express 支持失效) 的问题。 [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* 已在 [#74104](https://github.com/ClickHouse/ClickHouse/issues/74104) 中回移：使用 plain&#95;rewritable 元数据的磁盘可由多个服务器实例共享。预期场景是，一个实例读取某个元数据对象时，另一个实例可能会修改它。使用 Azure 存储初始化 plain&#95;rewritable 期间，会忽略“对象未找到”错误，这与为 S3 实现的行为类似。 [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* 已在 [#74152](https://github.com/ClickHouse/ClickHouse/issues/74152) 中回移：修复用户在 Kafka 表引擎中指定关键字参数时的问题。 [#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已在 [#74173](https://github.com/ClickHouse/ClickHouse/issues/74173) 中回移：修复从压缩的 Memory 引擎表读取子列时发生的崩溃。修复了 [#74009](https://github.com/ClickHouse/ClickHouse/issues/74009)。 [#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat)).
