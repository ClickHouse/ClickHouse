<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移到 [#80466](https://github.com/ClickHouse/ClickHouse/issues/80466)：尝试在 SingleValueDataGeneric 中使用 IColumn 而不是 Field。这修复了某些聚合函数 (如 `argMax`) 在 `Dynamic/Variant/JSON` 类型下返回值不正确的问题。[#79166](https://github.com/ClickHouse/ClickHouse/pull/79166) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移到 [#80258](https://github.com/ClickHouse/ClickHouse/issues/80258)：修复在投影之前没有任何列参与查询执行时，延迟物化导致的 AMBIGUOUS&#95;COLUMN&#95;NAME 错误。例如，SELECT * FROM t ORDER BY rand() LIMIT 5。[#79926](https://github.com/ClickHouse/ClickHouse/pull/79926) ([Igor Nikonov](https://github.com/devcrafter)) 。
* 已回移到 [#80339](https://github.com/ClickHouse/ClickHouse/issues/80339)：修复从 Merge 引擎读取子列的问题。[#80158](https://github.com/ClickHouse/ClickHouse/pull/80158) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移到 [#80506](https://github.com/ClickHouse/ClickHouse/issues/80506)：修复 MongoDB 文档中嵌套数值字段被错误序列化为字符串的问题。移除从 MongoDB 读取文档时的最大深度限制。[#80289](https://github.com/ClickHouse/ClickHouse/pull/80289) ([Kirill Nikiforov](https://github.com/allmazz)) 。
* 已回移到 [#80402](https://github.com/ClickHouse/ClickHouse/issues/80402)：修复 PostgreSQL 存储中 DateTime 和 DateTime64 的文本表示问题。[#80301](https://github.com/ClickHouse/ClickHouse/pull/80301) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)) 。
* 已回移到 [#80395](https://github.com/ClickHouse/ClickHouse/issues/80395)：修复在 `ON` 表达式不是简单等值条件时，由逻辑 JOIN 阶段的过滤下推优化导致的 `NOT_FOUND_COLUMN_IN_BLOCK` 错误。修复了 [#79647](https://github.com/ClickHouse/ClickHouse/issues/79647)。修复了 [#77848](https://github.com/ClickHouse/ClickHouse/issues/77848)。[#80360](https://github.com/ClickHouse/ClickHouse/pull/80360) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
