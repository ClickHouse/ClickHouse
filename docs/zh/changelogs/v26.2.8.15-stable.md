<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#100217](https://github.com/ClickHouse/ClickHouse/issues/100217) 中回移：修复了一个崩溃问题：在 `IDatabaseTablesIterator::table()` 调用中对表做快照之后，到后续迭代期间其他线程修改这些表之前的这段时间里创建的系统表，可能会触发空指针解引用。[#98792](https://github.com/ClickHouse/ClickHouse/pull/98792) ([Grant Holly](https://github.com/grantholly-clickhouse)).
* 已在 [#100855](https://github.com/ClickHouse/ClickHouse/issues/100855) 中回移：修复了当表在读取查询运行期间被并发 drop 时发生的 heap-use-after-free 问题 (过去 90 天内在 CI 中出现了 19 次) 。[#99483](https://github.com/ClickHouse/ClickHouse/pull/99483) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#101472](https://github.com/ClickHouse/ClickHouse/issues/101472) 中回移：修复了 Keeper 中的一个 bug：如果同一 server 上另一个无关 session 恰好在错误的时机被关闭，某个读取请求可能会卡住 (导致 session 超时) 。[#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#101393](https://github.com/ClickHouse/ClickHouse/issues/101393) 中回移：修复了在异步插入 (TCP) 以及所有通过 HTTP 的插入中，解析 `DateTime` 值时忽略 `session_timezone` 的问题。[#100647](https://github.com/ClickHouse/ClickHouse/pull/100647) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#101960](https://github.com/ClickHouse/ClickHouse/issues/101960) 中回移：修复了在使用按主键分片优化的 JOIN 中，若启用了查询条件缓存且某些 parts 被缓存条件过滤掉，会返回错误结果的问题。[#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* 已在 [#101642](https://github.com/ClickHouse/ClickHouse/issues/101642) 中回移：修复了 parseDateTimeBestEffort 在解析小数秒位数超过 18 位的日期时间字符串时的未定义行为 (有符号整数溢出) 。[#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* 已在 [#101362](https://github.com/ClickHouse/ClickHouse/issues/101362) 中回移：修复了在启用 JIT 编译时 (达到编译阈值后) ，对 `Decimal` 列执行 `MAX`/`MIN` 聚合函数会返回错误结果的问题。[#101203](https://github.com/ClickHouse/ClickHouse/pull/101203) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#101371](https://github.com/ClickHouse/ClickHouse/issues/101371) 中回移：... [#101230](https://github.com/ClickHouse/ClickHouse/pull/101230) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#101561](https://github.com/ClickHouse/ClickHouse/issues/101561) 中回移：修复了从 delta lake cluster 向 replicated merge tree 执行 insert-select 的问题。[#101299](https://github.com/ClickHouse/ClickHouse/pull/101299) ([Konstantin Vedernikov](https://github.com/scanhex12)).
