* 已在 [#78899](https://github.com/ClickHouse/ClickHouse/issues/78899) 中回移：修复了 `BFloat16` 在 `IN` 子句中的类型强制转换问题 (即 `SELECT toBFloat16(1) IN [1, 2, 3];` 现在返回 `1`) 。关闭了 [#78754](https://github.com/ClickHouse/ClickHouse/issues/78754)。[#78839](https://github.com/ClickHouse/ClickHouse/pull/78839) ([Raufs Dunamalijevs](https://github.com/rienath)) 。
* 已在 [#79137](https://github.com/ClickHouse/ClickHouse/issues/79137) 中回移：在 `recoverLostReplica` 期间移除设置，与以下 PR 中的处理方式一致：[https://github.com/ClickHouse/ClickHouse/pull/78637](https://github.com/ClickHouse/ClickHouse/pull/78637)。[#79113](https://github.com/ClickHouse/ClickHouse/pull/79113) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* 已在 [#78790](https://github.com/ClickHouse/ClickHouse/issues/78790) 中回移：修复 analyzer 中带有字面量的表达式上的跳过索引不生效的问题，并在索引分析期间移除无意义的类型转换。 [#77229](https://github.com/ClickHouse/ClickHouse/pull/77229) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#79285](https://github.com/ClickHouse/ClickHouse/issues/79285) 中回移：修复 Replicated database 中的可刷新materialized view 在新添加的副本上无法工作的问题。 [#77774](https://github.com/ClickHouse/ClickHouse/pull/77774) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#78438](https://github.com/ClickHouse/ClickHouse/issues/78438) 中回移：修复 Database Replicated 中的元数据 override 问题，该问题可能发生在执行 ALTER 查询后紧接着执行 RENAME 查询时。 [#78107](https://github.com/ClickHouse/ClickHouse/pull/78107) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#78547](https://github.com/ClickHouse/ClickHouse/issues/78547) 中回移：对 Azure 访问签名进行掩码处理，使其对用户和在 logs 中均不可见。 [#78189](https://github.com/ClickHouse/ClickHouse/pull/78189) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#78528](https://github.com/ClickHouse/ClickHouse/issues/78528) 中回移：修复 Wide parts 中带前缀的 substream 预取问题。 [#78205](https://github.com/ClickHouse/ClickHouse/pull/78205) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#78952](https://github.com/ClickHouse/ClickHouse/issues/78952) 中回移：如果某个副本的 `disable_insertion_and_mutation` 为 true，则不调度 RefreshMV 任务。该任务本身属于插入操作，因此在 `disable_insertion_and_mutation` 为 true 时会失败。 [#78277](https://github.com/ClickHouse/ClickHouse/pull/78277) ([Xu Jia](https://github.com/XuJia0210)).
* 已在 [#78979](https://github.com/ClickHouse/ClickHouse/issues/78979) 中回移：为 Merge 引擎校验对底层表的访问权限。 [#78339](https://github.com/ClickHouse/ClickHouse/pull/78339) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* 已在 [#78649](https://github.com/ClickHouse/ClickHouse/issues/78649) 中回移：`Distributed` 引擎表可能会丢失 FINAL 修饰符。 [#78428](https://github.com/ClickHouse/ClickHouse/pull/78428) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#78534](https://github.com/ClickHouse/ClickHouse/issues/78534) 中回移：回退“在代码中的某些位置应用 preserve&#95;most attribute”，因为这可能导致崩溃。 [#78449](https://github.com/ClickHouse/ClickHouse/pull/78449) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#78760](https://github.com/ClickHouse/ClickHouse/issues/78760) 中回移：应用 `max_streams_to_max_threads_ratio` setting 后，如果计划的流数量为零，则至少设置一个读取流。 [#78505](https://github.com/ClickHouse/ClickHouse/pull/78505) ([Eduard Karacharov](https://github.com/korowa)).
