<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#96316](https://github.com/ClickHouse/ClickHouse/issues/96316) 中回移：移除了对启用 SQL Security 的视图执行 `ATTACH` 查询时不必要的“跳过权限检查”逻辑。这可防止用户在未验证所需访问权限的情况下附加带有 definer 的视图时发生潜在的权限提升。 [#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)).
* 已在 [#95806](https://github.com/ClickHouse/ClickHouse/issues/95806) 中回移：修复了在使用多个 JOIN 且带有 `USING` 子句时，源表中带限定名列的类型推断问题。此前，后续 JOIN 会错误地将底层源列的类型更新为共同超类型，即使该列并未参与该 JOIN (例如，在 `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` 中，`t2.a` 列仅用于第一个 JOIN，因此其类型应为 `t1.a` 和 `t2.a` 的共同超类型，不包括 `t3.a`) 。当函数预期的列类型与执行计划中实际出现的类型不一致时，这可能导致逻辑错误或崩溃。 [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#96396](https://github.com/ClickHouse/ClickHouse/issues/96396) 中回移：修复了在分布式查询中使用负数 `LIMIT/OFFSET` 时某些情况下出现的逻辑错误。 [#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* 已在 [#96222](https://github.com/ClickHouse/ClickHouse/issues/96222) 中回移：修复了对 JSON 数组应用 `tupleElement` 时发生的崩溃。关闭 [#95581](https://github.com/ClickHouse/ClickHouse/issues/95581)。 [#95647](https://github.com/ClickHouse/ClickHouse/pull/95647) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#95825](https://github.com/ClickHouse/ClickHouse/issues/95825) 中回移：修复了分区 Delta Lake 数据的压缩合并问题。 [#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#95852](https://github.com/ClickHouse/ClickHouse/issues/95852) 中回移：修复了运行时过滤器中 Nullable JOIN 列的竞态条件。 [#95775](https://github.com/ClickHouse/ClickHouse/pull/95775) ([Hechem Selmi](https://github.com/m-selmi)).
* 已在 [#97187](https://github.com/ClickHouse/ClickHouse/issues/97187) 中回移：修复了在带有嵌套路径的 JSON 上执行 `tupleElement` 的问题，此前这可能导致错误的查询结果。 [#95907](https://github.com/ClickHouse/ClickHouse/pull/95907) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#96086](https://github.com/ClickHouse/ClickHouse/issues/96086) 中回移：修复了在空 MergeTree 表上使用 `direct` JOIN 算法时可能出现的 `NOT_SUPPORTED` 错误。 [#95935](https://github.com/ClickHouse/ClickHouse/pull/95935) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#95993](https://github.com/ClickHouse/ClickHouse/issues/95993) 中回移：修复了 system.asynchronous&#95;metric&#95;log 中的 event&#95;date。 [#95947](https://github.com/ClickHouse/ClickHouse/pull/95947) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#96215](https://github.com/ClickHouse/ClickHouse/issues/96215) 中回移：修复了 JSON 数据类型中的跳过路径问题。此前在使用 `JSON(SKIP path)` 时，所有带有前缀 `path` 的 JSON 键都会被跳过，甚至包括 `"pathpath"` 这样的键，因此在插入期间可能导致这些路径的数据丢失。现在该问题已修复，只有键 `"path"` 会被跳过。 [#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
