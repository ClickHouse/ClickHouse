<div id="improvement">
  #### 改进
</div>

* 已在 [#82417](https://github.com/ClickHouse/ClickHouse/issues/82417) 中回移：在 best effort 的 DateTime64 解析中支持带小数部分的 Unix 时间戳。[#78908](https://github.com/ClickHouse/ClickHouse/pull/78908) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#82413](https://github.com/ClickHouse/ClickHouse/issues/82413) 中回移：哈希函数现已支持数组、Tuple 和 Map 中的 NULL。 (问题 [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) 和 [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)) 。[#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已在 [#81801](https://github.com/ClickHouse/ClickHouse/issues/81801) 中回移：新增 profile 事件 `PageCacheReadBytes`。[#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#82593](https://github.com/ClickHouse/ClickHouse/issues/82593) 中回移：Keeper 改进：新增配置项 `keeper_server.cleanup_old_and_ignore_new_acl`。启用后，所有节点上的 ACL 都会被清除，同时会忽略新请求的 ACL。如果目标是彻底移除节点上的 ACL，则务必保持该配置项处于启用状态，直到创建新的快照。[#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#82858](https://github.com/ClickHouse/ClickHouse/issues/82858) 中回移：在 [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 之后，`X-ClickHouse-Progress` 和 `X-ClickHouse-Summary` 请求头格式被修改为省略零值。此 PR 仅打算让 `X-ClickHouse-Summary` 恢复此前的行为，因为这样更合理。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#82924](https://github.com/ClickHouse/ClickHouse/issues/82924) 中回移：Keeper 改进：支持为 world:anyone ACL 指定具体权限。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#82185](https://github.com/ClickHouse/ClickHouse/issues/82185) 中回移：修复列类型改为 Nullable 后，在物化 projection 期间出现的逻辑错误。[#80741](https://github.com/ClickHouse/ClickHouse/pull/80741) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#81811](https://github.com/ClickHouse/ClickHouse/issues/81811) 中回移：修复在分布式查询中使用谓词下推 (`allow_push_predicate_ast_for_distributed_subqueries=1`) 时，如果源表在发起端不存在而报出的 `Table does not exist` 错误。修复了 [#77281](https://github.com/ClickHouse/ClickHouse/issues/77281)。[#80915](https://github.com/ClickHouse/ClickHouse/pull/80915) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#82014](https://github.com/ClickHouse/ClickHouse/issues/82014) 中回移：修复在跨副本复制场景下使用 `distributed_product_mode_local=local` 时出现的 `Unknown table expression identifier` 错误。[#81162](https://github.com/ClickHouse/ClickHouse/pull/81162) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#82330](https://github.com/ClickHouse/ClickHouse/issues/82330) 中回移：修复在左侧参数为 null 且子查询结果为非 Nullable 时，`transform_null_in=1` 下 `IN` 的执行问题。[#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#82175](https://github.com/ClickHouse/ClickHouse/issues/82175) 中回移：从现有表读取时，执行 default/materialize 表达式期间不再校验 experimental/可疑类型。[#81618](https://github.com/ClickHouse/ClickHouse/pull/81618) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#82124](https://github.com/ClickHouse/ClickHouse/issues/82124) 中回移：修复在 merges 期间，当字典用于生存时间 (TTL) 表达式时出现的 &quot;Context has expired&quot; 问题。[#81690](https://github.com/ClickHouse/ClickHouse/pull/81690) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#82323](https://github.com/ClickHouse/ClickHouse/issues/82323) 中回移：在之前的版本中，server 对 `/js` 请求返回了过多内容。此更改关闭了 [#61890](https://github.com/ClickHouse/ClickHouse/issues/61890)。[#81895](https://github.com/ClickHouse/ClickHouse/pull/81895) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#82235](https://github.com/ClickHouse/ClickHouse/issues/82235) 中回移：此前，`MongoDB` 表 engine 的定义中，`host:port` 参数可以包含路径部分，但该部分会被静默忽略。MongoDB 集成会拒绝加载这类表。通过此修复，如果 `MongoDB` engine 有五个参数，则*允许加载这类表并忽略路径部分*，同时使用参数中的数据库名称。*注意：* 此修复不适用于新创建的表、使用 `mongo` table function 的查询，也不适用于字典源和命名集合。[#81942](https://github.com/ClickHouse/ClickHouse/pull/81942) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#82777](https://github.com/ClickHouse/ClickHouse/issues/82777) 中回移：修复查询中仅使用常量别名列时的过滤器分析问题。修复了 [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448)。[#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#82550](https://github.com/ClickHouse/ClickHouse/issues/82550) 中回移：修复在 GROUP BY 和 SET 的生存时间 (TTL) 中使用同一列时出现的 LOGICAL&#95;ERROR 及后续崩溃问题。[#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* 已在 [#82153](https://github.com/ClickHouse/ClickHouse/issues/82153) 中回移：修复 `arraySimilarity` 中的复制粘贴错误，禁止使用 UInt32 和 Int32 权重。并更新测试和文档。[#82103](https://github.com/ClickHouse/ClickHouse/pull/82103) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#82316](https://github.com/ClickHouse/ClickHouse/issues/82316) 中回移：修复在带有 `WHERE` 条件和 `IndexSet` 的 `arrayJoin` 查询中出现的 `Not found column` 错误。[#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#82558](https://github.com/ClickHouse/ClickHouse/issues/82558) 中回移：修复 server 在内存压力下处理远程查询时可能发生的死锁问题。[#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)) 。
* 已在 [#82521](https://github.com/ClickHouse/ClickHouse/issues/82521) 中回移：为 AWS ECS token 添加过期时间，使其能够重新加载。[#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已在 [#82577](https://github.com/ClickHouse/ClickHouse/issues/82577) 中回移：修复在 日志/query&#95;log 中隐藏命名集合配置值的问题。关闭 [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405)。[#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#82568](https://github.com/ClickHouse/ClickHouse/issues/82568) 中回移：修复终止 session 时日志中可能发生的 crash，因为 user&#95;id 有时可能为空。[#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 已在 [#82686](https://github.com/ClickHouse/ClickHouse/issues/82686) 中回移：修复在分析关联列的行级策略 expression 时出现的 `LOGICAL_ERROR`。[#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#82733](https://github.com/ClickHouse/ClickHouse/issues/82733) 中回移：Functions `trim{Left,Right,Both}` 现已支持类型为 &quot;FixedString(N)&quot; 的输入字符串。例如，`SELECT trimBoth(toFixedString('abc', 3), 'ac')` 现可正常工作。[#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#82798](https://github.com/ClickHouse/ClickHouse/issues/82798) 中回移：修复 `groupArraySample`/`groupArrayLast` 在元素为空时的反序列化问题 (如果输入为空，反序列化可能会跳过 binary 的一部分，这可能导致读取数据时发生损坏，并在 TCP protocol 中出现 UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER) 。这不影响数值和日期时间类型。[#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)) 。
