<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#98402](https://github.com/ClickHouse/ClickHouse/issues/98402) 中回移：`loop` 表函数直接调用了 `inner_storage->read()`，绕过了解释器层；而行策略、列级授权及其他安全检查正是在这一层执行的。因此，即使直接执行 SELECT 返回零行，受行策略限制的用户仍可通过 `loop(table)` 读取所有行。[#97682](https://github.com/ClickHouse/ClickHouse/pull/97682) ([pufit](https://github.com/pufit)) 。
* 已在 [#98310](https://github.com/ClickHouse/ClickHouse/issues/98310) 中回移：修复混用主键和非主键跳过索引时 FINAL 查询结果不正确的问题。[#98097](https://github.com/ClickHouse/ClickHouse/pull/98097) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#98352](https://github.com/ClickHouse/ClickHouse/issues/98352) 中回移：为 `aggregated_zookeeper_log` 中的 watch 响应设置 `Watch` component，而不是将其留空。[#98202](https://github.com/ClickHouse/ClickHouse/pull/98202) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#98326](https://github.com/ClickHouse/ClickHouse/issues/98326) 中回移：修复 `ColumnConst::getExtremes` 中的越界访问问题，该问题在启用 `extremes = 1` 时可能导致崩溃。[#98263](https://github.com/ClickHouse/ClickHouse/pull/98263) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#98388](https://github.com/ClickHouse/ClickHouse/issues/98388) 中回移：修复由对数据跨越 65535 边界的键列执行 `toDate` 转换而触发的 LOGICAL&#95;ERROR 异常 “Invalid binary search result in `MergeTreeSetIndex`”。[#98276](https://github.com/ClickHouse/ClickHouse/pull/98276) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
