<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#85759](https://github.com/ClickHouse/ClickHouse/issues/85759) 中回移：修复了 parquet writer 为 Decimal 类型输出错误统计信息 (min/max) 的问题。[#83754](https://github.com/ClickHouse/ClickHouse/pull/83754) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#85796](https://github.com/ClickHouse/ClickHouse/issues/85796) 中回移：修复了在 RowBinary format 中写入带有 NULL value 的 JSON paths 时的问题。[#83923](https://github.com/ClickHouse/ClickHouse/pull/83923) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#85883](https://github.com/ClickHouse/ClickHouse/issues/85883) 中回移：修复了在 lazy materialization 情况下读取 Variant column 时的问题。[#84400](https://github.com/ClickHouse/ClickHouse/pull/84400) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#85778](https://github.com/ClickHouse/ClickHouse/issues/85778) 中回移：修复了 `DeltaLake` engine 的 delta-kernel 实现中的竞争条件问题。[#85221](https://github.com/ClickHouse/ClickHouse/pull/85221) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#85620](https://github.com/ClickHouse/ClickHouse/issues/85620) 中回移：使用按顺序反向读取优化的并行副本查询可能会产生错误结果。[#85406](https://github.com/ClickHouse/ClickHouse/pull/85406) ([Igor Nikonov](https://github.com/devcrafter)).
* 已在 [#85697](https://github.com/ClickHouse/ClickHouse/issues/85697) 中回移：修复了在 String 反序列化期间发生 MEMORY&#95;LIMIT&#95;EXCEEDED 时可能出现的 UB (崩溃) 问题。[#85440](https://github.com/ClickHouse/ClickHouse/pull/85440) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#85826](https://github.com/ClickHouse/ClickHouse/issues/85826) 中回移：修复了 KafkaAssignedPartitions 和 KafkaConsumersWithAssignment 指标不正确的问题。[#85494](https://github.com/ClickHouse/ClickHouse/pull/85494) ([Ilya Golshtein](https://github.com/ilejn)).
* 已在 [#85916](https://github.com/ClickHouse/ClickHouse/issues/85916) 中回移：修复了 icebergS3Cluster 和 icebergAzureCluster table functions 中 secrets 的脱敏问题。[#85658](https://github.com/ClickHouse/ClickHouse/pull/85658) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 已在 [#85871](https://github.com/ClickHouse/ClickHouse/issues/85871) 中回移：修复了 coalescing merge tree 在处理大字符串时发生 segfault 的问题。此修复关闭了 [#84582](https://github.com/ClickHouse/ClickHouse/issues/84582)。[#85709](https://github.com/ClickHouse/ClickHouse/pull/85709) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 已在 [#85854](https://github.com/ClickHouse/ClickHouse/issues/85854) 中回移：修复了字典在出现 MEMORY&#95;LIMIT&#95;EXCEEDED 错误时，使用 update&#95;field 可能导致不一致的问题。[#85807](https://github.com/ClickHouse/ClickHouse/pull/85807) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#85993](https://github.com/ClickHouse/ClickHouse/issues/85993) 中回移：支持在以 `Distributed` 目标端表执行并行分布式 `INSERT SELECT` 时使用来自 `WITH` statement 的全局常量。此前，该查询可能抛出 `Unknown expression identifier` 错误。[#85811](https://github.com/ClickHouse/ClickHouse/pull/85811) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#86041](https://github.com/ClickHouse/ClickHouse/issues/86041) 中回移：修复了 `Replicated` database recovery 中的一个缺陷：如果表名包含 `%` 符号，则在恢复过程中可能会以不同的名称重新创建该表。[#85987](https://github.com/ClickHouse/ClickHouse/pull/85987) ([Alexander Tokmakov](https://github.com/tavplubix)).
