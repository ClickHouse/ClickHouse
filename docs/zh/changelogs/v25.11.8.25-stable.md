<div id="improvement">
  #### 改进
</div>

* 已在 [#94933](https://github.com/ClickHouse/ClickHouse/issues/94933) 中回移：当脏页大小与 `max_server_memory_usage` 的比率超过 `memory_worker_purge_dirty_pages_threshold_ratio` 时，强制清理 jemalloc arenas。[#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)) 。
* 已在 [#94729](https://github.com/ClickHouse/ClickHouse/issues/94729) 中回移：在面向 S3 和 Azure Blob 存储的 BACKUP/RESTORE 中，支持使用 SQL 定义的命名集合。关闭 [#94604](https://github.com/ClickHouse/ClickHouse/issues/94604)。[#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已在 [#95166](https://github.com/ClickHouse/ClickHouse/issues/95166) 中回移：将 jemalloc 脏页清理放到独立于 MemoryWorker 主线程的另一个线程中执行。如果清理过慢，可能会延迟 RSS 使用量的更新，进而导致进程因内存不足而被终止。新增配置项 `memory_worker_purge_total_memory_threshold_ratio`，根据总内存使用量的比率启动脏页清理。[#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)) 。
