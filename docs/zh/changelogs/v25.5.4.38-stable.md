  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#82187](https://github.com/ClickHouse/ClickHouse/issues/82187) 中回移：修复将列类型更改为 Nullable 时，在物化投影期间发生的逻辑错误。[#80741](https://github.com/ClickHouse/ClickHouse/pull/80741) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#82332](https://github.com/ClickHouse/ClickHouse/issues/82332) 中回移：修复在左侧参数为 null 且子查询结果为非 Nullable 时，`transform_null_in=1` 条件下 `IN` 的执行问题。[#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#82177](https://github.com/ClickHouse/ClickHouse/issues/82177) 中回移：从现有表读取时，在执行 default/materialize 表达式期间不再校验实验性/可疑类型。[#81618](https://github.com/ClickHouse/ClickHouse/pull/81618) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#82032](https://github.com/ClickHouse/ClickHouse/issues/82032) 中回移：修复在处理标量关联子查询期间未读取所需列的问题。修复了 [#81716](https://github.com/ClickHouse/ClickHouse/issues/81716)。[#81805](https://github.com/ClickHouse/ClickHouse/pull/81805) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#82324](https://github.com/ClickHouse/ClickHouse/issues/82324) 中回移：在先前版本中，服务器对 `/js` 请求返回了过多内容。此更改关闭了 [#61890](https://github.com/ClickHouse/ClickHouse/issues/61890)。[#81895](https://github.com/ClickHouse/ClickHouse/pull/81895) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#82236](https://github.com/ClickHouse/ClickHouse/issues/82236) 中回移：此前，`MongoDB` 表引擎定义中的 `host:port` 参数可以包含 path 组件，但该组件会被静默忽略。MongoDB 集成会拒绝加载这类表。通过此修复，*如果 `MongoDB` 引擎有五个参数，我们允许加载这类表并忽略 path 组件*，同时使用参数中的数据库名称。*注意：* 此修复不适用于新创建的表、使用 `mongo` 表函数的查询，以及字典源和命名集合。[#81942](https://github.com/ClickHouse/ClickHouse/pull/81942) ([Vladimir Cherkasov](https://github.com/vdimir)) 。
* 已在 [#82098](https://github.com/ClickHouse/ClickHouse/issues/82098) 中回移：修复 `Aggregator` 在 merge 期间发生异常时可能导致的 crash。[#82022](https://github.com/ClickHouse/ClickHouse/pull/82022) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已在 [#82552](https://github.com/ClickHouse/ClickHouse/issues/82552) 中回移：修复在生存时间 (TTL) 中将同一列同时用于 GROUP BY 和 SET 时出现的 LOGICAL&#95;ERROR 及后续 crash。[#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已在 [#82154](https://github.com/ClickHouse/ClickHouse/issues/82154) 中回移：修复 arraySimilarity 中的复制粘贴错误，禁止使用 UInt32 和 Int32 权重。更新测试和文档。[#82103](https://github.com/ClickHouse/ClickHouse/pull/82103) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#82318](https://github.com/ClickHouse/ClickHouse/issues/82318) 中回移：修复在带有 `WHERE` 条件和 `IndexSet` 的 `arrayJoin` 查询中出现的 `Not found column` 错误。[#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#82262](https://github.com/ClickHouse/ClickHouse/issues/82262) 中回移：修复 Glue catalog 集成中的一个缺陷。现在 ClickHouse 可以读取带有嵌套数据类型的表，即使其中某些子列包含 Decimal 类型，例如：`map<string, decimal(9, 2)>`。修复了 [#81301](https://github.com/ClickHouse/ClickHouse/issues/81301)。[#82114](https://github.com/ClickHouse/ClickHouse/pull/82114) ([alesapin](https://github.com/alesapin)).
* 已在 [#82588](https://github.com/ClickHouse/ClickHouse/issues/82588) 中回移：修复表依赖项中的一个缺陷，该问题会导致 Materialized Views 漏掉 INSERT 查询。[#82222](https://github.com/ClickHouse/ClickHouse/pull/82222) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#82523](https://github.com/ClickHouse/ClickHouse/issues/82523) 中回移：为 AWS ECS 标记添加过期时间，以便能够重新加载。[#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#82579](https://github.com/ClickHouse/ClickHouse/issues/82579) 中回移：修复在 logs/query&#95;log 中隐藏命名集合配置值的问题。关闭了 [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405)。[#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#82570](https://github.com/ClickHouse/ClickHouse/issues/82570) 中回移：修复终止会话时日志记录中一个可能导致崩溃的问题，因为 user&#95;id 有时可能为空。[#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
