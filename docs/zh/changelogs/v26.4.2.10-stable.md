  ### ClickHouse 发布 v26.4.2.10-稳定版本 (184f682d431) FIXME，相较于 v26.4.1.1141-稳定版本 (7156188a3ba)

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#104160](https://github.com/ClickHouse/ClickHouse/issues/104160) 中回移：当缓存被禁用时 (服务器设置 `index_uncompressed_cache_size = 0`，这是默认值) ，避免索引未压缩缓存带来的额外开销。[#104063](https://github.com/ClickHouse/ClickHouse/pull/104063) ([Michael Kolupaev](https://github.com/al13n321)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#104213](https://github.com/ClickHouse/ClickHouse/issues/104213) 中回移：新增 SQL 函数 `obfuscateQuery` 和 `obfuscateQueryWithSeed`，可通过将标识符和字面量替换为随机占位符来混淆 SQL 查询字符串，同时保留查询结构。修复了查询混淆中短标识符和超大整数字面量的边界情况。[#101027](https://github.com/ClickHouse/ClickHouse/pull/101027) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#104224](https://github.com/ClickHouse/ClickHouse/issues/104224) 中回移：修复了运行带有 `MATERIALIZED` CTE 的查询时的内存泄漏问题。[#104153](https://github.com/ClickHouse/ClickHouse/pull/104153) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#104211](https://github.com/ClickHouse/ClickHouse/issues/104211) 中回移：修复 `MergeTreeDataPartWriterCompact::cancel` 在 stream 分配失败时的未定义行为。[#101292](https://github.com/ClickHouse/ClickHouse/pull/101292) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#104151](https://github.com/ClickHouse/ClickHouse/issues/104151) 中回移：在启用行策略/additional&#95;table&#95;filters 时禁用简单 LIMIT 优化 (以支持并行索引分析) 。[#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#104244](https://github.com/ClickHouse/ClickHouse/issues/104244) 中回移：修复 26.x 中的数据正确性回归问题：当经 JIT 编译的 `if` 和 `multiIf` 的结果类型为 `Decimal`，且某个分支中包含非 `Decimal` (整数或 Float) 字面量时，会静默返回一个比正确值小 `10^scale` 倍的值。慢速 (非 JIT) 路径不受影响。受影响版本的临时规避方法：`SET compile_expressions = 0`。[#103809](https://github.com/ClickHouse/ClickHouse/pull/103809) ([Groene AI](https://github.com/groeneai))。
* 已在 [#104147](https://github.com/ClickHouse/ClickHouse/issues/104147) 中回移：修复读取 `AggregateFunction(topK(N), String)` 列时出现的 `SIZES_OF_ARRAYS_DONT_MATCH` 问题；该问题会在其持久化的 `alpha_size` 因 pre-25.12 的一次反序列化+序列化循环而增大后发生。[#104002](https://github.com/ClickHouse/ClickHouse/pull/104002) ([Raúl Marín](https://github.com/Algunenano))。
* 已在 [#104195](https://github.com/ClickHouse/ClickHouse/issues/104195) 中回移：修复反序列化 `quantileTiming` 状态时的越界写入问题。[#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov))。

<div id="not-for-changelog-insignificant">
  #### 不记入更新日志 / 不重要
