<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#83339](https://github.com/ClickHouse/ClickHouse/issues/83339) 中回移：尝试将 QueryTreeHash 稍微提速。[#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#83013](https://github.com/ClickHouse/ClickHouse/issues/83013) 中回移：Keeper 改进：在后台线程中跨磁盘移动更新日志文件。此前，将更新日志移动到其他磁盘时，Keeper 会在移动完成前被全局阻塞。如果移动耗时较长 (例如移动到 S3 磁盘) ，会导致性能下降。[#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#83203](https://github.com/ClickHouse/ClickHouse/issues/83203) 中回移：`SYSTEM RESTART REPLICA` 可能因 ZooKeeper 连接问题而失败。为避免遗漏这张表，我们现在会持续重试，直到表创建成功。[#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已在 [#83180](https://github.com/ClickHouse/ClickHouse/issues/83180) 中回移：合并 clickhouse client 中关于未知设置的警告，并将其汇总记录。[#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* 已在 [#82911](https://github.com/ClickHouse/ClickHouse/issues/82911) 中回移：在 AzureBlobStorage 中，执行 native copy 时会比较身份验证方法；如果此过程中发生异常，现已改为回退到 read and copy (即非 native copy) 。[#82693](https://github.com/ClickHouse/ClickHouse/pull/82693) ([Smita Kulkarni](https://github.com/SmitaRKulkarni))。
* 已在 [#83110](https://github.com/ClickHouse/ClickHouse/issues/83110) 中回移：修复 union/intersect/except&#95;default&#95;mode Rewrite 中的 exception safety 问题。关闭 [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664)。[#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#83328](https://github.com/ClickHouse/ClickHouse/issues/83328) 中回移：修复 Iceberg 中的数据竞争问题。[#82841](https://github.com/ClickHouse/ClickHouse/pull/82841) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#83287](https://github.com/ClickHouse/ClickHouse/issues/83287) 中回移：从 AST 解析类型为 SCRAM&#95;SHA256&#95;PASSWORD 的身份验证数据时，设置 salt。[#82888](https://github.com/ClickHouse/ClickHouse/pull/82888) ([Tuan Pham Anh](https://github.com/tuanpach))。
* 已在 [#83025](https://github.com/ClickHouse/ClickHouse/issues/83025) 中回移：修复包含对存储为 `Merge` 的表进行 JOIN 表达式的查询中的过滤器修改问题。修复 [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092)。[#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd))。
* 已在 [#83309](https://github.com/ClickHouse/ClickHouse/issues/83309) 中回移：修复 QueryMetricLog 中的 LOGICAL&#95;ERROR：Mutex 不能为 NULL。[#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos))。
* 已在 [#83238](https://github.com/ClickHouse/ClickHouse/issues/83238) 中回移：修复启用 analyzer 后的性能下降问题，即次级查询总是从 VIEW 中读取所有列。修复 [#81718](https://github.com/ClickHouse/ClickHouse/issues/81718)。[#83036](https://github.com/ClickHouse/ClickHouse/pull/83036) ([Dmitry Novik](https://github.com/novikd))。

* 已在 [#83465](https://github.com/ClickHouse/ClickHouse/issues/83465) 中回移：修复当 CTE 定义引用另一个同名表表达式时触发的 `TOO_DEEP_SUBQUERIES` 异常。[#83413](https://github.com/ClickHouse/ClickHouse/pull/83413) ([Dmitry Novik](https://github.com/novikd)) 。
