<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#101736](https://github.com/ClickHouse/ClickHouse/issues/101736) 中回移：将数据哈希计算从 squashing 阶段延后到 sink，并通过 `updateHashWithValueRange` 按批次对列进行哈希计算，修复了在 `deduplicate_insert=enable` (自 26.2 起默认为启用) 时出现的显著 INSERT 性能回退，将 22 列 500 万行数据的额外开销从约 ~2.5 秒降至 ~0.5 秒。[#101494](https://github.com/ClickHouse/ClickHouse/pull/101494) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#101949](https://github.com/ClickHouse/ClickHouse/issues/101949) 中回移：优化服务启动时的缓存加载。[#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#102140](https://github.com/ClickHouse/ClickHouse/issues/102140) 中回移：将内部 mongo-c-driver 从 2.2.2 升级至 2.2.3。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#101962](https://github.com/ClickHouse/ClickHouse/issues/101962) 中回移：修复在带有 shard-by-PK 优化的 JOIN 使用查询条件缓存，且某些 parts 被缓存条件过滤掉时返回错误结果的问题。[#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* 已在 [#101987](https://github.com/ClickHouse/ClickHouse/issues/101987) 中回移：修复 materialized view 的内部表在异步启动期间因启动依赖顺序错误而出现 “Target table doesn&#39;t exist” 错误的问题。[#100946](https://github.com/ClickHouse/ClickHouse/pull/100946) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#101563](https://github.com/ClickHouse/ClickHouse/issues/101563) 中回移：修复从 delta lake cluster 向 replicated merge tree 执行 insert-select 时的问题。[#101299](https://github.com/ClickHouse/ClickHouse/pull/101299) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 已在 [#102076](https://github.com/ClickHouse/ClickHouse/issues/102076) 中回移：修复 `Object` 类型动态路径并行反序列化中的 use-after-scope 问题，该问题在读取包含大量动态路径的表时可能导致崩溃。[#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#102102](https://github.com/ClickHouse/ClickHouse/issues/102102) 中回移：修复函数 `formatDateTime` 在某些 (非默认) 格式化设置下使用格式说明符 `%W` 时输出不正确的问题。[#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* 已在 [#102030](https://github.com/ClickHouse/ClickHouse/issues/102030) 中回移：修复 ZooKeeper 会话在定期刷新期间过期时 UDF registry 丢失的问题——在一次完全刷新成功之前，所有用户自定义函数都可能不可用。[#101891](https://github.com/ClickHouse/ClickHouse/pull/101891) ([Nikita Fomichev](https://github.com/fm4v)).
* 已在 [#102094](https://github.com/ClickHouse/ClickHouse/issues/102094) 中回移：`splitByString` 分词器现在会拒绝空分隔符字符串。[#101928](https://github.com/ClickHouse/ClickHouse/pull/101928) ([Robert Schulze](https://github.com/rschu1ze)).
