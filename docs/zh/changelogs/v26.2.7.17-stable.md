<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#101233](https://github.com/ClickHouse/ClickHouse/issues/101233) 中回移：修复 async insert 查询在 `query_log` 和客户端输出中将 `written_rows`、`read_rows` 和 `result_rows` 记录为 0 的问题。[#99879](https://github.com/ClickHouse/ClickHouse/pull/99879) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#100170](https://github.com/ClickHouse/ClickHouse/issues/100170) 中回移：... [#100024](https://github.com/ClickHouse/ClickHouse/pull/100024) ([Shaohua Wang](https://github.com/tiandiwonder)).
* 已在 [#100920](https://github.com/ClickHouse/ClickHouse/issues/100920) 中回移：修复在包含 LowCardinality 元素的 Tuple 键上结合 PREWHERE/WHERE 使用 `has()` 函数时服务端崩溃的问题。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* 已在 [#101185](https://github.com/ClickHouse/ClickHouse/issues/101185) 中回移：修复服务端关闭期间加载字典时因空指针解引用导致的 segfault。字典线程会并发调用 `Context::getUserDefinedSQLObjectsStorage` (会解引用 `user_defined_sql_objects_storage`) ，同时主线程调用 `Context::shutdown` (将 `user_defined_sql_objects_storage` 设为 null) 。因此，需要在执行 `Context::shutdown` 之前，先确保禁用字典加载器的后续更新、终止当前正在运行的字典查询，并等待字典加载线程结束——这与处理普通查询的方式类似。[#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 已在 [#101089](https://github.com/ClickHouse/ClickHouse/issues/101089) 中回移：修复 `ULIDStringToDateTime` 在输入包含非 ASCII 字节时的缓冲区溢出问题。[#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#101013](https://github.com/ClickHouse/ClickHouse/issues/101013) 中回移：修复 `intDiv`/`intDivOrZero` 在可空 Tuple 数组上抛出异常的问题，例如 `SELECT intDiv([divide((1, 2), ... AND NULL)], 2)`。[#100895](https://github.com/ClickHouse/ClickHouse/pull/100895) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#101248](https://github.com/ClickHouse/ClickHouse/issues/101248) 中回移：在存储 `StorageAlias` 定义之前先对 engine Arguments 进行求值，这样 `currentDatabase()` 之类的 expressions 会在保存到数据库前先解析为 literals。[#100902](https://github.com/ClickHouse/ClickHouse/pull/100902) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#101124](https://github.com/ClickHouse/ClickHouse/issues/101124) 中回移：修复使用文本搜索索引时，如果 `IN` 子句中包含 tuple subquery (例如 `WHERE (id, str) IN (SELECT (id, str) FROM ...)`) ，或者 subquery 中的 columns 数量与 `IN` 左侧的 tuple 不匹配，会导致崩溃的问题。[#100959](https://github.com/ClickHouse/ClickHouse/pull/100959) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#101078](https://github.com/ClickHouse/ClickHouse/issues/101078) 中回移：修复 `sumCountOrDefault` aggregate function 在带有一个或多个 `Nullable` argument 时，在引入 `Nullable(Tuple)` 后无法读取旧版已序列化状态的问题。关闭 [#100882](https://github.com/ClickHouse/ClickHouse/issues/100882)。[#101021](https://github.com/ClickHouse/ClickHouse/pull/101021) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* 已在 [#101346](https://github.com/ClickHouse/ClickHouse/issues/101346) 中回移：修复了一种可能导致 cache 中出现 `Having zero bytes, ...` logical error 的情况，原因是远程对象在 `list` 与 `read` 之间被覆盖，先前这会导致对象 metadata 过期。 [#101219](https://github.com/ClickHouse/ClickHouse/pull/101219) ([Kseniia Sumarokova](https://github.com/kssenii)).
