<div id="improvement">
  #### 改进
</div>

* 已在 [#81442](https://github.com/ClickHouse/ClickHouse/issues/81442) 中回移：为 Azure Blob 存储中普通磁盘在 system.tables 中上报的数据路径添加容器前缀，使其与 S3 和 GCP 的上报方式保持一致。[#79241](https://github.com/ClickHouse/ClickHouse/pull/79241) ([Julia Kartseva](https://github.com/jkartseva)) 。
* 已在 [#81220](https://github.com/ClickHouse/ClickHouse/issues/81220) 中回移：修复一处崩溃问题：如果在析构函数中尝试删除临时文件时抛出异常 (这些文件用于将临时数据落盘到磁盘) ，程序可能会终止。[#80776](https://github.com/ClickHouse/ClickHouse/pull/80776) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#81536](https://github.com/ClickHouse/ClickHouse/issues/81536) 中回移：将 libxml2 升级到 2.14.3。[#81187](https://github.com/ClickHouse/ClickHouse/pull/81187) ([larryluogit](https://github.com/larryluogit)) 。
* 已在 [#81409](https://github.com/ClickHouse/ClickHouse/issues/81409) 中回移：在带日志的文件系统中，`mkdir` 会写入文件系统日志，而该日志会持久化到磁盘。磁盘较慢时，这可能耗时较长。因此，将其移出 reserve lock 的作用域显然更合理。[#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#81486](https://github.com/ClickHouse/ClickHouse/issues/81486) 中回移：使用 `krb5` 1.21.3-final。[#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已在 [#81478](https://github.com/ClickHouse/ClickHouse/issues/81478) 中回移：使用 `orc` 2.1.2。[#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已在 [#81666](https://github.com/ClickHouse/ClickHouse/issues/81666) 中回移：将 Iceberg manifest 文件的读取推迟到首次执行读取查询时。[#81619](https://github.com/ClickHouse/ClickHouse/pull/81619) ([Daniil Ivanik](https://github.com/divanik)) 。
* 已在 [#81930](https://github.com/ClickHouse/ClickHouse/issues/81930) 中回移：尝试修复文件系统缓存中的逻辑错误：“Having zero bytes but range is not finished”。[#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
