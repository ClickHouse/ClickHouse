* 已在 [#105377](https://github.com/ClickHouse/ClickHouse/issues/105377) 中回移：检查 Avro reader 在嵌套类型反序列化期间是否发生栈溢出。[#102417](https://github.com/ClickHouse/ClickHouse/pull/102417) ([Pavel Kruglov](https://github.com/Avogar)) 。

* 已在 [#105619](https://github.com/ClickHouse/ClickHouse/issues/105619) 中回移：修复读取 Arrow 或 ArrowStream 文件时的堆缓冲区溢出问题，该问题会在二进制或 String 列中存在损坏的中间 offsets 时触发；同时修复读取带地理标签的 Arrow 列时的空指针解引用问题。[#105449](https://github.com/ClickHouse/ClickHouse/pull/105449) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#106483](https://github.com/ClickHouse/ClickHouse/issues/106483) 中回移：修复 ALTER 后从压缩的 Memory 表中读取 Dynamic 子列时出现的 SIGSEGV。关闭 [#104901](https://github.com/ClickHouse/ClickHouse/issues/104901)。[#105464](https://github.com/ClickHouse/ClickHouse/pull/105464) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#105967](https://github.com/ClickHouse/ClickHouse/issues/105967) 中回移：修复 JSON type 中 `singleValueOrNull` 反序列化时的 SEGFAULT。关闭 [#103630](https://github.com/ClickHouse/ClickHouse/issues/103630)。[#105535](https://github.com/ClickHouse/ClickHouse/pull/105535) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#106553](https://github.com/ClickHouse/ClickHouse/issues/106553) 中回移：修复一个 server 崩溃 (SIGSEGV) 问题：任何拥有 `CREATE TABLE` 权限的用户，都可以通过 HTTP 或 native protocol 发送不带 `ENGINE` clause 的 `CREATE TABLE ... TO INNER UUID '...'` 来触发该问题。同一 bug 也会导致 client 崩溃。现在 parser 会返回正确的 `BAD_ARGUMENTS` error，而不是解引用空指针。[#105579](https://github.com/ClickHouse/ClickHouse/pull/105579) ([Groene AI](https://github.com/groeneai)) 。
* 已在 [#106762](https://github.com/ClickHouse/ClickHouse/issues/106762) 中回移：修复在同一个 VALUES 子句中向 String 列插入不同大小的元组时发生的崩溃。关闭 [#101727](https://github.com/ClickHouse/ClickHouse/issues/101727)。[#105582](https://github.com/ClickHouse/ClickHouse/pull/105582) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#106754](https://github.com/ClickHouse/ClickHouse/issues/106754) 中回移：修复展平 Dynamic 列的 Native 反序列化中的 OOB 读取问题。[#105666](https://github.com/ClickHouse/ClickHouse/pull/105666) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移到 [#105854](https://github.com/ClickHouse/ClickHouse/issues/105854)：修复了当 collection 名称为空或包含 NUL 字节时，`mongodb` 表函数、MongoDB 存储以及 MongoDB 字典源中的崩溃问题。[#105776](https://github.com/ClickHouse/ClickHouse/pull/105776) ([Raúl Marín](https://github.com/Algunenano)).
* 已回移到 [#106467](https://github.com/ClickHouse/ClickHouse/issues/106467)：修复了在部分撤销 `SHOW DICTIONARIES` 权限后，`system.dictionaries` 返回 0 行的问题。[#106105](https://github.com/ClickHouse/ClickHouse/pull/106105) ([Pavel Kruglov](https://github.com/Avogar)).
* 已回移到 [#107967](https://github.com/ClickHouse/ClickHouse/issues/107967)：修复了在将基于约束的优化 (`optimize_using_constraints`) 与关联子查询一起使用时发生的崩溃，以及可能出现的 `NOT_FOUND_COLUMN_IN_BLOCK` 错误。[#106349](https://github.com/ClickHouse/ClickHouse/pull/106349) ([Raúl Marín](https://github.com/Algunenano)).
* 已回移到 [#107348](https://github.com/ClickHouse/ClickHouse/issues/107348)：修复了 Arrow IPC 格式读取器 (`ArrowColumnToCHColumn`) 中的多个堆越界读取漏洞。格式错误的 Arrow 文件可能声明比其缓冲区实际包含更多的行，声明与父项不一致的 list/struct/map 子项长度，提供非单调的 list 偏移量，或截断子项有效性 bitmap，从而导致读取越过堆分配的末尾。任何拥有 `SELECT` 权限的用户都可通过 `file()`、`format()`、表函数或 ArrowFlight 输入触发该问题。现在，在进行任何原始指针访问之前，都会先校验所有 data、偏移量、view-struct 和有效性-bitmap 缓冲区，并检查 list/struct/map 的形状和偏移量是否一致。[#106395](https://github.com/ClickHouse/ClickHouse/pull/106395) ([Raúl Marín](https://github.com/Algunenano)).
* 已回移到 [#107839](https://github.com/ClickHouse/ClickHouse/issues/107839)：修复了格式读取器中可由不受信任输入触发的多项内存安全和资源耗尽问题：原生 Parquet reader 在处理 `DataPageV2` 的定义/重复级别长度时存在堆越界读取漏洞；对具有深度嵌套 schema 的 Parquet 文件会导致栈溢出；以及在解析 GeoParquet WKB/WKT 几何和 Avro 字符串/字节时，内存分配会忽略 `max_memory_usage`。[#106739](https://github.com/ClickHouse/ClickHouse/pull/106739) ([Raúl Marín](https://github.com/Algunenano)).
* 已回移到 [#106786](https://github.com/ClickHouse/ClickHouse/issues/106786)：修复了 `decodeHTMLComponent` 在解码包含可扩展 HTML 实体 `&nGt;` 或 `&nLt;` 的字符串时发生的堆缓冲区溢出 (服务器崩溃) 问题，任何用户只需一次 `SELECT` 即可触发。[#106741](https://github.com/ClickHouse/ClickHouse/pull/106741) ([Raúl Marín](https://github.com/Algunenano)).
* 已回移到 [#107275](https://github.com/ClickHouse/ClickHouse/issues/107275)：在刷新访问实体时，不再在 ZooKeeper 读取期间持有互斥锁。[#107097](https://github.com/ClickHouse/ClickHouse/pull/107097) ([Azat Khuzhin](https://github.com/azat)).
* 已回移到 [#108278](https://github.com/ClickHouse/ClickHouse/issues/108278)：修复了在读取 MsgPack、BSON、ORC、Parquet、JSON、DeltaLake、Iceberg 和 Paimon 格式中的深度嵌套 schema 或值时，可能发生的服务器栈溢出 (崩溃) 问题。现在，此类深度嵌套输入会被直接拒绝并抛出异常。[#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* 已回移到 [#108220](https://github.com/ClickHouse/ClickHouse/issues/108220)：修复了 `windowFunnel` 在完成一个精心构造、且事件类型超出范围的聚合函数状态时发生的堆缓冲区溢出 (服务器崩溃) 问题，任何用户只需一次 `SELECT` 即可触发。[#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* 已在 [#107712](https://github.com/ClickHouse/ClickHouse/issues/107712) 中回移：修复 PostgreSQL wire protocol 解析器中的一个整数下溢问题。此前，当消息的长度字段小于 4 时，会导致 `size - 4` 回绕，并触发过大的 `resize`/`ignore`。[#107485](https://github.com/ClickHouse/ClickHouse/pull/107485) ([uwezkhan](https://github.com/uwezkhan)).
* 已在 [#108236](https://github.com/ClickHouse/ClickHouse/issues/108236) 中回移：为 Elf 和 DWARF 解析补充缺失的边界检查。[#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).

* 已在 [#107870](https://github.com/ClickHouse/ClickHouse/issues/107870) 中回移：修复 replicated part 拉取协议中的两个路径遍历问题，这些问题可能使恶意副本将文件写入 part 目录之外。[#107606](https://github.com/ClickHouse/ClickHouse/pull/107606) ([Antonio Andelic](https://github.com/antonio2368)).
