<div id="backward-incompatible-change">
  #### 向后不兼容变更
</div>

* 如果 `allow_materialized_view_with_bad_select` 为 `false`，则检查 materialized view 中的所有列是否与目标表匹配。[#74481](https://github.com/ClickHouse/ClickHouse/pull/74481) ([Christoph Wurm](https://github.com/cwurm)).
* 修复了 `dateTrunc` 与负值日期/日期时间参数一起使用时的异常情况。[#77622](https://github.com/ClickHouse/ClickHouse/pull/77622) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已移除旧版 MongoDB 集成。服务器设置 `use_legacy_mongodb_integration` 已废弃，现已不起任何作用。[#77895](https://github.com/ClickHouse/ClickHouse/pull/77895) ([Robert Schulze](https://github.com/rschu1ze)).
* 增强了 SummingMergeTree 的验证逻辑，跳过对用于分区键或排序键的列进行聚合。[#78022](https://github.com/ClickHouse/ClickHouse/pull/78022) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).



<div id="new-feature">
  #### 新特性
</div>

* 已在 [#79232](https://github.com/ClickHouse/ClickHouse/issues/79232) 中回移：为 MergeTree SETTINGS 新增一个选项，用于在 CREATE 查询未为给定列显式定义压缩编解码器时，指定默认压缩编解码器。此更改关闭了 [#42005](https://github.com/ClickHouse/ClickHouse/issues/42005)。[#66394](https://github.com/ClickHouse/ClickHouse/pull/66394) ([gvoelfin](https://github.com/gvoelfin)).
* 为分布式查询序列化查询计划。新增设置项 `serialize_query_plan`。启用后，来自 `Distributed` 表的查询在执行远程查询时将使用序列化后的查询计划。这为 TCP 协议引入了一种新的数据包类型，需要将 `<process_query_plan_packet>true</process_query_plan_packet>` 添加到服务器配置中，以允许处理该数据包。[#69652](https://github.com/ClickHouse/ClickHouse/pull/69652) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 新增设置项，可按特定 timestamp 查询 Iceberg 表。[#71072](https://github.com/ClickHouse/ClickHouse/pull/71072) ([Brett Hoerner](https://github.com/bretthoerner)).
* 支持低基数 Decimal 数据类型，修复了 [#72256](https://github.com/ClickHouse/ClickHouse/issues/72256)。[#72833](https://github.com/ClickHouse/ClickHouse/pull/72833) ([zhanglistar](https://github.com/zhanglistar)).
* 为 AzureBlobStorage 支持 DeltaLake 表引擎。修复了 [#68043](https://github.com/ClickHouse/ClickHouse/issues/68043)。[#74541](https://github.com/ClickHouse/ClickHouse/pull/74541) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* 新增 bind&#95;host 设置项，用于为 ClickHouse 命令行客户端连接设置源 IP 地址。[#74741](https://github.com/ClickHouse/ClickHouse/pull/74741) ([Todd Yocum](https://github.com/toddyocum)).
* 在 system.tables 中引入 parametrized&#95;view&#95;parameters。关闭了 https://github.com/clickhouse/clickhouse/issues/66756。[#75112](https://github.com/ClickHouse/ClickHouse/pull/75112) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* 允许修改数据库注释。关闭了 [#73351](https://github.com/ClickHouse/ClickHouse/issues/73351) ### 面向用户变更的文档条目。[#75622](https://github.com/ClickHouse/ClickHouse/pull/75622) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* 已在 [#79361](https://github.com/ClickHouse/ClickHouse/issues/79361) 中回移：支持在 WHERE 子句中将关联子查询用作 `EXISTS` 表达式的参数。关闭了 [#72459](https://github.com/ClickHouse/ClickHouse/issues/72459)。[#76078](https://github.com/ClickHouse/ClickHouse/pull/76078) ([Dmitry Novik](https://github.com/novikd)).
* Scram SHA256 及 postgres wire auth 更新。[#76839](https://github.com/ClickHouse/ClickHouse/pull/76839) ([scanhex12](https://github.com/scanhex12)).
* 支持 `IcebergMetadataFilesCache`，可将 manifest 文件/list 和 metadata.json 存储在同一个缓存中。[#77156](https://github.com/ClickHouse/ClickHouse/pull/77156) ([Han Fei](https://github.com/hanfei1991)).
* 新增函数 `arrayLevenshteinDistance`、`arrayLevenshteinDistanceWeighted` 和 `arraySimilarity`。[#77187](https://github.com/ClickHouse/ClickHouse/pull/77187) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 允许用户查询 Iceberg 表在过去某个时间点的状态。[#77439](https://github.com/ClickHouse/ClickHouse/pull/77439) ([Daniil Ivanik](https://github.com/divanik)).
* 为工作负载新增 CPU slot 调度，详见 https://clickhouse.com/docs/operations/workload-scheduling#cpu&#95;scheduling 。[#77595](https://github.com/ClickHouse/ClickHouse/pull/77595) ([Sergei Trifonov](https://github.com/serxa)).
* hasAll() 函数现在可以利用 tokenbf&#95;v1、ngrambf&#95;v1 全文跳过索引。[#77662](https://github.com/ClickHouse/ClickHouse/pull/77662) ([UnamedRus](https://github.com/UnamedRus)) 。
* `JSON` 数据类型现已达到生产可用。参见 https://jsonbench.com/。`Dynamic` 和 `Varaint` 数据类型现已达到生产可用。[#77785](https://github.com/ClickHouse/ClickHouse/pull/77785) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 新增了用于反序列化后向量相似度索引的内存缓存。这应当会让重复执行的近似最近邻 (ANN) 搜索查询更快。新缓存的大小由服务器设置 `vector_similarity_index_cache_size` 和 `vector_similarity_index_cache_max_entries` 控制。此功能取代了早期发行版中的跳过索引缓存功能。[#77905](https://github.com/ClickHouse/ClickHouse/pull/77905) ([Shankar Iyer](https://github.com/shankar-iyer)) 。
* 已回移到 [#79343](https://github.com/ClickHouse/ClickHouse/issues/79343)：待定。[#78041](https://github.com/ClickHouse/ClickHouse/pull/78041) ([Igor Nikonov](https://github.com/devcrafter)) 。
* 新增了 sparseGrams 和 sparseGramsHashes 函数，以及它们的 UTF8 版本。作者：[scanhex12](https://github.com/scanhex12)。[#78176](https://github.com/ClickHouse/ClickHouse/pull/78176) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)) 。
* 新增 `toInterval` 函数。该函数接受 2 个参数 (value 和 unit) ，并将 value 转换为特定的 `Interval` 类型。[#78723](https://github.com/ClickHouse/ClickHouse/pull/78723) ([Andrew Davis](https://github.com/pulpdrew)) 。



<div id="performance-improvement">
  #### 性能提升
</div>

* 通过惰性投影优化性能，避免读取未使用的列。[#55518](https://github.com/ClickHouse/ClickHouse/pull/55518) ([Xiaozhe Yu](https://github.com/wudidapaopao)).
* 为 `NativeORCBlockInputFormat` 支持异步 IO 预取，通过隐藏远程 IO 延迟提升整体性能。在我的测试用例中，加速比最高可达 1.47x。[#70534](https://github.com/ClickHouse/ClickHouse/pull/70534) ([李扬](https://github.com/taiyang-li)).
* 为异步插入预分配内存，以提升性能。[#74945](https://github.com/ClickHouse/ClickHouse/pull/74945) ([Ilya Golshtein](https://github.com/ilejn)).
* 对 wrapInNullable 做了简单优化，避免不必要的 null map 分配。[#76489](https://github.com/ClickHouse/ClickHouse/pull/76489) ([李扬](https://github.com/taiyang-li)).
* 优化 arraySort。[#76850](https://github.com/ClickHouse/ClickHouse/pull/76850) ([李扬](https://github.com/taiyang-li)).
* 通过将对 `col->insertFrom()` 的调用去虚化，加速构建 JOIN 结果。[#77350](https://github.com/ClickHouse/ClickHouse/pull/77350) ([Alexander Gololobov](https://github.com/davenger)).
* 合并同一分片的标记，并一次性将其写入查询条件缓存，以减少锁开销。[#77377](https://github.com/ClickHouse/ClickHouse/pull/77377) ([zhongyuankai](https://github.com/zhongyuankai)).
* 优化带有一次括号展开的查询的 s3Cluster 性能。[#77686](https://github.com/ClickHouse/ClickHouse/pull/77686) ([Tomáš Hromada](https://github.com/gyfis)).
* 优化按单个 Nullable 或低基数列进行排序的性能。[#77789](https://github.com/ClickHouse/ClickHouse/pull/77789) ([李扬](https://github.com/taiyang-li)).
* 当缓存以被动方式使用时 (例如用于合并操作) ，禁用 `filesystem_cache_prefer_bigger_buffer_size`。[#77898](https://github.com/ClickHouse/ClickHouse/pull/77898) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 为 Iceberg 实现简单的 count 优化。现在，不带任何过滤器的 `count()` 查询应该会更快。关闭 [#77639](https://github.com/ClickHouse/ClickHouse/issues/77639)。[#78090](https://github.com/ClickHouse/ClickHouse/pull/78090) ([alesapin](https://github.com/alesapin)).
* 支持基于列的 lower&#95;bound 和 uppert&#95;bound 值进行 Iceberg 数据裁剪。修复 [#77638](https://github.com/ClickHouse/ClickHouse/issues/77638)。[#78242](https://github.com/ClickHouse/ClickHouse/pull/78242) ([alesapin](https://github.com/alesapin)).
* 优化 NativeReader 的内存使用。[#78442](https://github.com/ClickHouse/ClickHouse/pull/78442) ([Azat Khuzhin](https://github.com/azat)).
* 简单优化：如果需要 CAST，则不要将 count(if()) 重写为 countIf。关闭 [#78564](https://github.com/ClickHouse/ClickHouse/issues/78564)。[#78565](https://github.com/ClickHouse/ClickHouse/pull/78565) ([李扬](https://github.com/taiyang-li)).
* 已回移到 [#79163](https://github.com/ClickHouse/ClickHouse/issues/79163)：现在启用并行副本时，我们使用副本数来确定读取任务大小。当待读取的数据量不大时，这能在各副本之间实现更好的工作分配。[#78695](https://github.com/ClickHouse/ClickHouse/pull/78695) ([Nikita Taranov](https://github.com/nickitat)).
* 已回移到 [#79190](https://github.com/ClickHouse/ClickHouse/issues/79190)：如果可能，将过滤器查询计划步骤中的等值条件合并到 JOIN 条件中，以便将其用作哈希表键。[#78877](https://github.com/ClickHouse/ClickHouse/pull/78877) ([Dmitry Novik](https://github.com/novikd)).



<div id="improvement">
  #### 改进
</div>

* 在可用 `multiRead` 的地方，不再使用单次 `get` 请求，以减少 Keeper 请求数量；随着副本数增加，这类请求原本可能会给 Keeper 带来显著负载。[#56862](https://github.com/ClickHouse/ClickHouse/pull/56862) ([Nikolay Degterinsky](https://github.com/evillique)).
* 当 server 过载时会拒绝查询。该决策基于等待时间 (`OSCPUWaitMicroseconds`) 与忙碌时间 (`OSCPUVirtualTimeMicroseconds`) 的比值。当该比值介于 `min_os_cpu_wait_time_ratio_to_throw` 和 `max_os_cpu_wait_time_ratio_to_throw` 之间时，查询会以一定概率被丢弃 (这两个是查询级别的设置) 。[#63206](https://github.com/ClickHouse/ClickHouse/pull/63206) ([Alexey Katsman](https://github.com/alexkats)).
* 可刷新materialized view 的 refresh 现在会出现在 `system.query_log` 中。[#71333](https://github.com/ClickHouse/ClickHouse/pull/71333) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#79175](https://github.com/ClickHouse/ClickHouse/issues/79175) 中回移：如果指定 `--path` 命令行参数，`clickhouse-local` 在重启后将保留其 databases。这解决了 [#50647](https://github.com/ClickHouse/ClickHouse/issues/50647)。这也解决了 [#49947](https://github.com/ClickHouse/ClickHouse/issues/49947)。[#71722](https://github.com/ClickHouse/ClickHouse/pull/71722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为所有类型的 replicated tasks 启用了 backoff 逻辑。这将有助于降低 CPU usage、memory usage 和日志文件大小。新增设置 `max_postpone_time_for_failed_replicated_fetches_ms`、`max_postpone_time_for_failed_replicated_merges_ms` 和 `max_postpone_time_for_failed_replicated_tasks_ms`，它们与 `max_postpone_time_for_failed_mutations_ms` 类似。[#74576](https://github.com/ClickHouse/ClickHouse/pull/74576) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 如果 JOIN 的连接键对于两部分都是 PK 的前缀，则对 JOIN 使用动态分片。此优化可通过 `query_plan_join_shard_by_pk_ranges` 设置启用 (默认禁用) 。[#74733](https://github.com/ClickHouse/ClickHouse/pull/74733) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 重新启用了 SSH protocol。修复了一些严重漏洞，因此现在无法再使用自定义 pager 或指定 `server-logs-file`。默认禁用了通过环境变量传递 client 选项的能力 (仍可通过 config.xml 中的 `ssh-server.enable_client_options_passing` 启用) 。支持 progress 表、查询取消、自动补全、profile events progress、stdin 和 `send_logs_level` 选项。这解决了：[ #74340](https://github.com/ClickHouse/ClickHouse/issues/74340)。[#74989](https://github.com/ClickHouse/ClickHouse/pull/74989) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 支持在 readonly MergeTree 表中执行 refresh。[#76467](https://github.com/ClickHouse/ClickHouse/pull/76467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 向 system.errors 添加 query&#95;id。相关 ticket：[#75815](https://github.com/ClickHouse/ClickHouse/issues/75815)。[#76581](https://github.com/ClickHouse/ClickHouse/pull/76581) ([Vladimir Baikov](https://github.com/bkvvldmr)).
* 支持从 View 中读取 JSON type 和 subcolumns。[#76903](https://github.com/ClickHouse/ClickHouse/pull/76903) ([Pavel Kruglov](https://github.com/Avogar)).
* 新增对将 UInt128 转换为 IPv6 的支持。这使得可以对 IPv6 执行 `bitAnd` 操作和算术运算，并将结果转换回 IPv6。修复了 [#76752](https://github.com/ClickHouse/ClickHouse/issues/76752)。此外，`bitAnd` 对 IPv6 执行操作得到的结果现在也可以转换回 IPv6。另见：https://github.com/ClickHouse/ClickHouse/pull/57707。[#76928](https://github.com/ClickHouse/ClickHouse/pull/76928) ([Muzammil Abdul Rehman](https://github.com/muzammilar)) 。
* 默认情况下，不会在 Variant 类型内的文本格式中解析特殊的 Bool 值。可通过设置 `allow_special_bool_values_inside_variant` 启用。[#76974](https://github.com/ClickHouse/ClickHouse/pull/76974) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 支持在 session 级别和 server 级别为低优先级查询配置每个任务的等待时间。[#77013](https://github.com/ClickHouse/ClickHouse/pull/77013) ([VicoWu](https://github.com/VicoWu)) 。
* 对 PostgreSQL 的 CHARACTER、CHAR 和 BPCHAR 使用 FixedString。[#77304](https://github.com/ClickHouse/ClickHouse/pull/77304) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 支持让数据库使用远程磁盘来存储元数据文件。[#77365](https://github.com/ClickHouse/ClickHouse/pull/77365) ([Tuan Pham Anh](https://github.com/tuanpach)) 。
* 实现了对 JSON 数据类型的值进行比较。现在，JSON 对象可以像 Map 一样进行比较。[#77397](https://github.com/ClickHouse/ClickHouse/pull/77397) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 支持对 plain&#95;rewritable disk 执行 ALTER TABLE ... ATTACH|DETACH|MOVE|REPLACE PARTITION。[#77406](https://github.com/ClickHouse/ClickHouse/pull/77406) ([Julia Kartseva](https://github.com/jkartseva)) 。
* 支持在 `additional_table_filters` 设置中使用查询参数。变更后，以下查询将成功执行。[#77680](https://github.com/ClickHouse/ClickHouse/pull/77680) ([wxybear](https://github.com/wxybear)) 。
* 改进了 system.kafka&#95;consumers 的权限支持。内部 librdkafka 错误现在会以异常形式呈现。[#77700](https://github.com/ClickHouse/ClickHouse/pull/77700) ([Ilya Golshtein](https://github.com/ilejn)) 。
* 现在可以通过其 XML 定义中的新标签将用户自定义函数 (UDFs) 标记为具有确定性。此外，查询缓存现在会检查查询中调用的 UDFs 是否具有确定性。如果是，则会缓存查询结果。 (Issue [#59988](https://github.com/ClickHouse/ClickHouse/issues/59988)) 。[#77769](https://github.com/ClickHouse/ClickHouse/pull/77769) ([Jimmy Aguilar Mena](https://github.com/Ergus)) 。
* 新增了 Buffer 表引擎参数校验。[#77840](https://github.com/ClickHouse/ClickHouse/pull/77840) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)) 。
* 新增 config `enable_hdfs_pread`，用于启用或禁用 HDFS pread。[#77885](https://github.com/ClickHouse/ClickHouse/pull/77885) ([kevinyhzou](https://github.com/KevinyhZou)) 。
* 新增了用于统计 ZooKeeper `multi` 读写请求数量的 profile events。[#77888](https://github.com/ClickHouse/ClickHouse/pull/77888) ([JackyWoo](https://github.com/JackyWoo)) 。
* 当 disable&#95;insertion&#95;and&#95;mutation 开启时，允许创建临时表并向其中插入数据。[#77901](https://github.com/ClickHouse/ClickHouse/pull/77901) ([Xu Jia](https://github.com/XuJia0210)) 。
* 将 max&#95;insert&#95;delayed&#95;streams&#95;for&#95;parallel&#95;write 降低到 100。[#77919](https://github.com/ClickHouse/ClickHouse/pull/77919) ([Azat Khuzhin](https://github.com/azat)) 。
* 新增支持使用 `max_merge_delayed_streams_for_parallel_write` 配置 merges 可并行 flush 的列数 (这应可将写入 S3 的 vertical merges 的内存使用降低约 25 倍) 。[#77922](https://github.com/ClickHouse/ClickHouse/pull/77922) ([Azat Khuzhin](https://github.com/azat)).
* 修复了 Joda 语法中类似 &#39;yyy&#39; 的年份解析问题。[#77973](https://github.com/ClickHouse/ClickHouse/pull/77973) ([李扬](https://github.com/taiyang-li)).
* Attach MergeTree 表的 parts 现在会按其块顺序执行，这对 ReplacingMergeTree 等特殊的 merging 算法很重要。此更改关闭了 [#71009](https://github.com/ClickHouse/ClickHouse/issues/71009)。[#77976](https://github.com/ClickHouse/ClickHouse/pull/77976) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Query masking rules 现在可以在发生匹配时抛出 LOGICAL&#95;ERROR。这有助于检查预设密码是否在日志中的任何位置泄露。[#78094](https://github.com/ClickHouse/ClickHouse/pull/78094) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 为更好地兼容 MySQL，向 `information_schema.tables` 新增了 `index_length_column` 列。[#78119](https://github.com/ClickHouse/ClickHouse/pull/78119) ([Paweł Zakrzewski](https://github.com/KrzaQ)).
* 引入两个新指标：`TotalMergeFailures` 和 `NonAbortedMergeFailures`。这些指标用于检测短时间内 merges 失败次数过多的情况。[#78150](https://github.com/ClickHouse/ClickHouse/pull/78150) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 修复了在 path style 下未指定 key 时 S3 URI 解析错误的问题。[#78185](https://github.com/ClickHouse/ClickHouse/pull/78185) ([Arthur Passos](https://github.com/arthurpassos)).
* 修复了异步指标 `BlockActiveTime`、`BlockDiscardTime`、`BlockWriteTime`、`BlockQueueTime` 和 `BlockReadTime` 的错误数值 (在此更改前，1 秒会被错误报告为 0.001) 。[#78211](https://github.com/ClickHouse/ClickHouse/pull/78211) ([filimonov](https://github.com/filimonov)).
* 对于 StorageS3(Azure)Queue，现在在推送到 materialized view 期间发生错误时会遵循 `loading_retries` 限制。此前这类错误会被无限重试。[#78313](https://github.com/ClickHouse/ClickHouse/pull/78313) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 在使用 delta-kernel-rs 实现的 StorageDeltaLake 中，修复了性能和进度条问题。[#78368](https://github.com/ClickHouse/ClickHouse/pull/78368) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 向量相似度索引最多可能多分配 2 倍的主内存。此修复重做了内存分配策略，从而降低内存消耗，并提升向量相似度索引缓存的效果。 (issue [#78056](https://github.com/ClickHouse/ClickHouse/issues/78056)) 。[#78394](https://github.com/ClickHouse/ClickHouse/pull/78394) ([Shankar Iyer](https://github.com/shankar-iyer)).
* 为 `system.metric_log` 表引入了用于指定 schema 类型的 setting `schema_type`。允许三种 schema：`wide` -- 当前 schema，每个 metric/event 单独存放在一列中 (最适合读取单独列) ；`transposed` -- 类似于 `system.asynchronous_metric_log`，metrics/events 按行存储；以及最值得关注的 `transposed_with_wide_view` -- 使用 `transposed` schema 创建 underlying table，同时还会引入一个采用 `wide` schema 的 VIEW，将查询转换到底层表上。在 `transposed_with_wide_view` 中，view 不支持亚秒级分辨率，`event_time_microseconds` 只是出于向后兼容而保留的别名。[#78412](https://github.com/ClickHouse/ClickHouse/pull/78412) ([alesapin](https://github.com/alesapin)).
