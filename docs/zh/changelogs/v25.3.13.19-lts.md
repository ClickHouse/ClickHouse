<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#92030](https://github.com/ClickHouse/ClickHouse/issues/92030) 中回移：修复 GenerateRandom 引擎在非字面量参数下崩溃的问题：返回带有明确提示信息的 BAD&#95;ARGUMENTS，而不是 LOGICAL&#95;ERROR。[#88157](https://github.com/ClickHouse/ClickHouse/pull/88157) ([Shafi Ahmed](https://github.com/ita004)).
* 已在 [#90415](https://github.com/ClickHouse/ClickHouse/issues/90415) 中回移：修复因错误的销毁顺序导致服务器正常关闭过程中崩溃的问题。解决了 [#82420](https://github.com/ClickHouse/ClickHouse/issues/82420)。[#90076](https://github.com/ClickHouse/ClickHouse/pull/90076) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#94008](https://github.com/ClickHouse/ClickHouse/issues/94008) 中回移：修复 randomStringUTF8 中整数溢出导致的崩溃。[#90326](https://github.com/ClickHouse/ClickHouse/pull/90326) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#93555](https://github.com/ClickHouse/ClickHouse/issues/93555) 中回移：修复在反序列化格式错误的 `groupConcat` aggregate state 且 offsets 越界时发生的崩溃。[#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)).
* 已在 [#93468](https://github.com/ClickHouse/ClickHouse/issues/93468) 中回移：修复 `groupConcat` 状态反序列化中的整数溢出漏洞，该漏洞可能在特制的 aggregate states 下导致内存安全问题。[#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath)).
* 已在 [#93684](https://github.com/ClickHouse/ClickHouse/issues/93684) 中回移：确保 ZooKeeper 在关闭时完成终结 (修复极少数情况下关闭时可能卡住的问题) 。[#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#93950](https://github.com/ClickHouse/ClickHouse/issues/93950) 中回移：修复在存在去重竞争条件时恢复 ReplicatedMergeTree 出现的 LOGICAL&#95;ERROR。[#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos)).
* 已在 [#93961](https://github.com/ClickHouse/ClickHouse/issues/93961) 中回移：修复在某些 input formats 中直接反序列化到稀疏列时，使用稀疏列进行 生存时间 (TTL) 更新的问题。同时修复了可能出现的逻辑错误 `Unexpected type of result TTL column`。[#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#93804](https://github.com/ClickHouse/ClickHouse/issues/93804) 中回移：验证解压后缓冲区的大小是否符合预期。[#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#93794](https://github.com/ClickHouse/ClickHouse/issues/93794) 中回移：防止用户在使用 `merge` 表引擎时，未经 `SHOW COLUMNS` 权限检查就获取表的列列表。[#93695](https://github.com/ClickHouse/ClickHouse/pull/93695) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#94159](https://github.com/ClickHouse/ClickHouse/issues/94159) 中回移：修复了 [https://github.com/ClickHouse/clickhouse-core-incidents/issues/1217](https://github.com/ClickHouse/clickhouse-core-incidents/issues/1217)。异常由 `SCOPE_EXIT` 内部的 `socket.setBlocking(true)` 调用抛出：[日志](https://grafana.clickhouse-prd.com/a/loghouseapp/sysex?thanos_datasource=LightHouse+Thanos+%28production%29\&environment=production\&sortOrder=Asc\&namespace=ns-olive-ae-66\&region=us-central1\&limit=500\&whereExtra=and+level+%3D+%27Fatal%27\&tableName=text_log\&groupBy=level\&extraCols=level\&timeFrom=2025-12-29T01%3A13%3A46Z\&timeFromCHFormat=2025-12-29+01%3A13%3A46\&timeFromUnix=1766970826\&timeTo=2025-12-29T02%3A13%3A51Z\&timeToCHFormat=2025-12-29+02%3A13%3A51\&timeToUnix=1766974431\&dateTo=2025-12-29\&dateFrom=2025-12-29)。由于 `SCOPE_EXIT` 会创建一个作用域保护对象，并在该对象的析构函数中执行提供的代码，因此不能将 `SCOPE_EXIT` 用于会抛出异常的函数，而应改用 `SCOPE_EXIT_SAFE`。[#94100](https://github.com/ClickHouse/ClickHouse/pull/94100) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
