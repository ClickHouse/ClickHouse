<div id="improvement">
  #### 改进
</div>

* 已在 [#81179](https://github.com/ClickHouse/ClickHouse/issues/81179) 中回移：现在，`system.iceberg_history` 会显示来自 glue 或 iceberg rest 等目录数据库的历史记录。另外，为保持一致性，将 `system.iceberg_history` 中的 `table_name` 和 `database_name` 列重命名为 `table` 和 `database`。[#80975](https://github.com/ClickHouse/ClickHouse/pull/80975) ([alesapin](https://github.com/alesapin)).
* 已在 [#81230](https://github.com/ClickHouse/ClickHouse/issues/81230) 中回移：将 libarchive 升级到 3.7.9，以修复以下问题：CVE-2024-20696 CVE-2025-25724 CVE-2024-48958 CVE-2024-57970 CVE-2025-1632 CVE-2024-48957 CVE-2024-48615。[#81174](https://github.com/ClickHouse/ClickHouse/pull/81174) ([larryluogit](https://github.com/larryluogit)).
* 已在 [#81538](https://github.com/ClickHouse/ClickHouse/issues/81538) 中回移：将 libxml2 升级到 2.14.3。[#81187](https://github.com/ClickHouse/ClickHouse/pull/81187) ([larryluogit](https://github.com/larryluogit)).
* 已在 [#81317](https://github.com/ClickHouse/ClickHouse/issues/81317) 中回移：MemoryResidentWithoutPageCache 以字节为单位表示服务器进程使用的物理内存量，不包括用户态页缓存。在使用用户态页缓存时，这能更准确地反映实际内存使用量。禁用用户态页缓存时，该值等于 MemoryResident。[#81233](https://github.com/ClickHouse/ClickHouse/pull/81233) ([Jayme Bird](https://github.com/jaymebrd)).
* 已在 [#81411](https://github.com/ClickHouse/ClickHouse/issues/81411) 中回移：在带日志的文件系统中，`mkdir` 会写入文件系统日志，并持久化到磁盘。在磁盘较慢的情况下，这可能耗时较长。显然应该将其移到 reserve lock 的作用域之外。[#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#81488](https://github.com/ClickHouse/ClickHouse/issues/81488) 中回移：使用 `krb5` 1.21.3-final。[#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#81480](https://github.com/ClickHouse/ClickHouse/issues/81480) 中回移：使用 `orc` 2.1.2。[#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#81668](https://github.com/ClickHouse/ClickHouse/issues/81668) 中回移：将 Iceberg manifest 文件的读取推迟到首次读取查询时。[#81619](https://github.com/ClickHouse/ClickHouse/pull/81619) ([Daniil Ivanik](https://github.com/divanik)).
* 已在 [#81803](https://github.com/ClickHouse/ClickHouse/issues/81803) 中回移：添加 profile 事件 `PageCacheReadBytes`。[#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#81932](https://github.com/ClickHouse/ClickHouse/issues/81932) 中回移：尝试修复文件系统缓存中的逻辑错误：“Having zero bytes but range is not finished”。[#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)).
