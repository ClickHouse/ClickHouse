<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移到 [#88511](https://github.com/ClickHouse/ClickHouse/issues/88511)：修复了从不能嵌套在 Nullable 中的 Variants 读取 null map 子列的问题。[#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar))。
* 已回移到 [#88734](https://github.com/ClickHouse/ClickHouse/issues/88734)：从 `Poco::Net::HTTPChunkedStreamBuf::readFromDevice` 抛出的 `Poco::TimeoutException` 异常会导致进程因 SIGABRT 崩溃。[#88668](https://github.com/ClickHouse/ClickHouse/pull/88668) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
* 已回移到 [#88908](https://github.com/ClickHouse/ClickHouse/issues/88908)：恢复后，Replicated 数据库的副本可能会长时间卡住，并持续打印类似 `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)` 的消息；此问题已修复。[#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已回移到 [#88892](https://github.com/ClickHouse/ClickHouse/issues/88892)：修复了对 `loop` 表函数执行 select 时的访问校验问题。[#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit))。
* 已回移到 [#88942](https://github.com/ClickHouse/ClickHouse/issues/88942)：修复了函数 `reverseUTF8` 中的缺陷。在之前的版本中，它会错误地反转长度为 4 的 UTF-8 码点字节顺序。此修复关闭了 [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913)。[#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已回移到 [#88978](https://github.com/ClickHouse/ClickHouse/issues/88978)：使用 SQL SECURITY DEFINER 创建视图时，不再检查 `SET DEFINER <current_user>:definer` 的访问权限。[#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit))。
* 已回移到 [#89083](https://github.com/ClickHouse/ClickHouse/issues/89083)：此修复关闭了 [#88081](https://github.com/ClickHouse/ClickHouse/issues/88081)。[#88988](https://github.com/ClickHouse/ClickHouse/pull/88988) ([scanhex12](https://github.com/scanhex12))。
* 已回移到 [#89026](https://github.com/ClickHouse/ClickHouse/issues/89026)：修复了分析 skipping indexes 时的性能下降问题。[#89004](https://github.com/ClickHouse/ClickHouse/pull/89004) ([Anton Popov](https://github.com/CurtizJ))。
