<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#87312](https://github.com/ClickHouse/ClickHouse/issues/87312) 中回移：修复 25.1 之前创建的 KeeperMap 表在执行 DROP 查询后仍在 ZooKeeper 中保留数据的问题。[#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#87168](https://github.com/ClickHouse/ClickHouse/issues/87168) 中回移：修复惰性物化中读取带有数组大小子列的数组时的问题。[#87139](https://github.com/ClickHouse/ClickHouse/pull/87139) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#87394](https://github.com/ClickHouse/ClickHouse/issues/87394) 中回移：修复在 `max_temporary_data_on_disk_size` 限制跟踪中，对临时数据释放的统计不正确的问题，关闭了 [#87118](https://github.com/ClickHouse/ClickHouse/issues/87118)。[#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
* 已在 [#87329](https://github.com/ClickHouse/ClickHouse/issues/87329) 中回移：修复非关联 `EXISTS` 可能返回错误结果的问题。该问题由 [https://github.com/ClickHouse/ClickHouse/pull/85481](https://github.com/ClickHouse/ClickHouse/pull/85481) 中引入的 `execute_exists_as_scalar_subquery=1` 所导致，并影响 `25.8`。修复了 [#86415](https://github.com/ClickHouse/ClickHouse/issues/86415)。[#87207](https://github.com/ClickHouse/ClickHouse/pull/87207) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#87437](https://github.com/ClickHouse/ClickHouse/issues/87437) 中回移：修复由于混用了 const 和非 const 块，导致 `JOIN` 中出现“Too large size passed to allocator” `LOGICAL_ERROR` 的问题。[#87231](https://github.com/ClickHouse/ClickHouse/pull/87231) ([Azat Khuzhin](https://github.com/azat)).
