  ### ClickHouse 发布 v26.5.5.8-稳定版本 (1d04e5e9f07) FIXME，与 v26.5.4.21-稳定版本 (8c0618b0f18) 相比

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#108869](https://github.com/ClickHouse/ClickHouse/issues/108869) 中回移：修复了对包含存在循环依赖表的备份执行 `RESTORE` 时，server 中止的问题。[#103824](https://github.com/ClickHouse/ClickHouse/pull/103824) ([Konstantin Bogdanov](https://github.com/thevar1able))。
* 已在 [#108903](https://github.com/ClickHouse/ClickHouse/issues/108903) 中回移：修复了以下 logical error (`Unexpected return type from equals. Expected Nullable(UInt8). Got UInt8`) ：当析取 (部分 predicate) 下推优化将条件下推到 `USING` 键上，而该键的类型又被 JOIN 扩宽时会触发该错误。还修复了 analyzer 在解析包含可常量折叠的 `if`/`multiIf` 分支且这些分支引用未知标识符的 `JOIN ... USING` 查询中的标识符时，发生的 server 崩溃 (段错误) 问题。[#107407](https://github.com/ClickHouse/ClickHouse/pull/107407) ([Groene AI](https://github.com/groeneai))。
* 已在 [#108643](https://github.com/ClickHouse/ClickHouse/issues/108643) 中回移：修复了 `ReplicatedMergeTree` 表的 `RESTORE`，使备份中的重复内容分片会被保留，而不是被静默去重。[#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos))。
* 已在 [#108748](https://github.com/ClickHouse/ClickHouse/issues/108748) 中回移：从 `_distance` 列执行 SELECT 的 vector search 查询现在会返回正确的错误，而不再是因 `LOGICAL_ERROR` 失败。[#108423](https://github.com/ClickHouse/ClickHouse/pull/108423) ([Robert Schulze](https://github.com/rschu1ze))。
* 已在 [#108667](https://github.com/ClickHouse/ClickHouse/issues/108667) 中回移：修复了从多个部分 materialized 文本索引进行直接读取的问题。[#108607](https://github.com/ClickHouse/ClickHouse/pull/108607) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#108825](https://github.com/ClickHouse/ClickHouse/issues/108825) 中回移：修复了当 `LowCardinality(FixedString)` (或 `LowCardinality(Nullable(FixedString))`) 键列在键表达式中被函数包裹时，分区和主键 pruning 会被静默禁用的问题，例如 `PARTITION BY sipHash64(k) % N` 且 `WHERE k = 'literal'`。这类查询会扫描所有分区，而不是对其进行 pruning。[#108777](https://github.com/ClickHouse/ClickHouse/pull/108777) ([Groene AI](https://github.com/groeneai))。
* 已在 [#108907](https://github.com/ClickHouse/ClickHouse/issues/108907) 中回移：修复了 `insert_quorum = 'auto'` 在存活副本数少于多数时，不会预先拒绝插入的问题。现在这类插入会立即以 `TOO_FEW_LIVE_REPLICAS` 失败，而不是先写入本地分片，之后再因 `UNKNOWN_STATUS_OF_INSERT` 超时。[#108800](https://github.com/ClickHouse/ClickHouse/pull/108800) ([Gagan Dhakrey](https://github.com/gagandhakrey))。
