<div id="improvement">
  #### 改进
</div>

* 已在 [#83633](https://github.com/ClickHouse/ClickHouse/issues/83633) 中回移：当 `distributed_ddl_output_mode='*_only_active'` 时，无需等待复制延迟大于 `max_replication_lag_to_enqueue` 的新副本或已恢复副本。这有助于避免出现 `DDL task is not finished on some hosts`：例如某个新副本在完成初始化或恢复后变为活跃状态，但在初始化期间已积压了大量复制日志时。另外，还实现了 `SYSTEM SYNC DATABASE REPLICA STRICT` 查询，用于等待复制日志低于 `max_replication_lag_to_enqueue`。[#83302](https://github.com/ClickHouse/ClickHouse/pull/83302) ([Alexander Tokmakov](https://github.com/tavplubix)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#83570](https://github.com/ClickHouse/ClickHouse/issues/83570) 中回移：修复空 `Memory` 表的备份问题，该问题会导致从备份恢复时因 `BACKUP_ENTRY_NOT_FOUND` 错误而失败。[#82791](https://github.com/ClickHouse/ClickHouse/pull/82791) ([Julia Kartseva](https://github.com/jkartseva)) 。
* 已在 [#83670](https://github.com/ClickHouse/ClickHouse/issues/83670) 中回移：修复与 `max_untracked_memory` 相关的内存处理错误。[#83607](https://github.com/ClickHouse/ClickHouse/pull/83607) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#83661](https://github.com/ClickHouse/ClickHouse/issues/83661) 中回移：在极端情况下，带有 UNION ALL 的 INSERT SELECT 可能会导致空指针解引用。此项关闭了 [#83618](https://github.com/ClickHouse/ClickHouse/issues/83618)。[#83643](https://github.com/ClickHouse/ClickHouse/pull/83643) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#83741](https://github.com/ClickHouse/ClickHouse/issues/83741) 中回移：修复 `block_size_bytes=0` 时 `estimateCompressionRatio()` 中的无限循环问题。[#83704](https://github.com/ClickHouse/ClickHouse/pull/83704) ([Azat Khuzhin](https://github.com/azat)) 。
