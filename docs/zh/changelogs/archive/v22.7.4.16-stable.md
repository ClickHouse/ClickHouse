<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#40163](https://github.com/ClickHouse/ClickHouse/issues/40163) 中回移：修复当列为 const 时，HashMethodOneNumber 获取错误键值的问题。[#40020](https://github.com/ClickHouse/ClickHouse/pull/40020) ([Duc Canh Le](https://github.com/canhld94)) 。
* 已在 [#40125](https://github.com/ClickHouse/ClickHouse/issues/40125) 中回移：通过为需要重新计算的索引添加正确的文件扩展名 (.idx 或 idx2) ，修复 collectFilesToSkip() 中的 bug，从而避免错误的硬链接。修复了 [#39896](https://github.com/ClickHouse/ClickHouse/issues/39896)。[#40095](https://github.com/ClickHouse/ClickHouse/pull/40095) ([Jianmei Zhang](https://github.com/zhangjmruc)) 。
* 已在 [#40291](https://github.com/ClickHouse/ClickHouse/issues/40291) 中回移：已报告一个堆栈跟踪中包含 CaresPTRResolver::resolve 的段错误问题。[#40134](https://github.com/ClickHouse/ClickHouse/pull/40134) ([Arthur Passos](https://github.com/arthurpassos)) 。
* 已在 [#40210](https://github.com/ClickHouse/ClickHouse/issues/40210) 中回移：修复加密函数参数检查不足的问题 (由查询 fuzzer 发现) 。这关闭了 [#39987](https://github.com/ClickHouse/ClickHouse/issues/39987)。[#40194](https://github.com/ClickHouse/ClickHouse/pull/40194) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#40284](https://github.com/ClickHouse/ClickHouse/issues/40284) 中回移：修复 CapnProto 输入格式中可能出现的段错误。该 bug 由 *kiojj* 通过 ClickHouse 漏洞奖励 [program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现并提交。[#40241](https://github.com/ClickHouse/ClickHouse/pull/40241) ([Kruglov Pavel](https://github.com/Avogar)) 。
