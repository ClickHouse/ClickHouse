<div id="clickhouse-release-v209614-stable-fixme-as-compared-to-v20955-stable">
  ### ClickHouse 发布版本 v20.9.6.14-稳定版本 FIXME，与 v20.9.5.5-稳定版本相比
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#17030](https://github.com/ClickHouse/ClickHouse/issues/17030) 中回移：现已支持连接到需要 SNI 的 `clickhouse-server` 安全端点。这在 `clickhouse-server` 部署于 TLS 代理后方时可实现。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#15678](https://github.com/ClickHouse/ClickHouse/issues/15678) 中回移：发生异常时，查询可更快结束；如果发生异常，则会取消远程副本上的执行。[#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#17105](https://github.com/ClickHouse/ClickHouse/issues/17105) 中回移：修复 [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) 和 [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231)，解决使用 &#39;if&#39; 后缀聚合函数时远程查询失败的问题。[#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* 已在 [#16759](https://github.com/ClickHouse/ClickHouse/issues/16759) 中回移：修复在 max&#95;threads&gt;0 且 ORDER BY 中包含表达式时，optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order 的问题。[#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#16740](https://github.com/ClickHouse/ClickHouse/issues/16740) 中回移：修复启用 `transform_null_in` 设置时，多列和 Tuple 上的 `IN` 运算符问题。修复 [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310)。[#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#17023](https://github.com/ClickHouse/ClickHouse/issues/17023) 中回移：修复在不带任何参数的情况下使用 `any` 时发生崩溃的问题。此项针对 [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803)。cc @azat。[#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#16879](https://github.com/ClickHouse/ClickHouse/issues/16879) 中回移：如果没有数据写入 WriteBufferFromS3，则中止分段上传。[#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* 已在 [#16945](https://github.com/ClickHouse/ClickHouse/issues/16945) 中回移：防止使用 TimeSeriesGroupSum 时 ClickHouse server 崩溃。[#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* 已在 [#17078](https://github.com/ClickHouse/ClickHouse/issues/17078) 中回移：修复带有 `ORDER BY` 的查询中可能出现的 `Illegal type of argument` 错误。修复 [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580)。[#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#17009](https://github.com/ClickHouse/ClickHouse/issues/17009) 中回移：安装脚本应始终在 config 文件夹中创建子目录。此项仅与使用自定义 config 的 Docker build 相关。[#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* 已在 [#17013](https://github.com/ClickHouse/ClickHouse/issues/17013) 中回移：修复在 `ALTER TABLE ... MODIFY COLUMN ... NewType` 之后可能发生的 server 崩溃问题：当 `SELECT` 对正在修改的列带有 `WHERE` 表达式，且 ALTER 尚未完成时，会触发该问题。[#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#17037](https://github.com/ClickHouse/ClickHouse/issues/17037) 中回移：发生错误时，重新解析 `format_avro_schema_registry_url` 的 IP。[#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* 已在 [#17172](https://github.com/ClickHouse/ClickHouse/issues/17172) 中回移：修复了一个 bug，即在非 leader 的 ReplicatedMergeTree 表上，`ON CLUSTER` 查询可能会一直卡住。[#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
