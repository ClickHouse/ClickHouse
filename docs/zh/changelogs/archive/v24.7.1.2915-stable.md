<div id="clickhouse-release-v24712915-stable-a37d2d43da7-fixme-as-compared-to-v24711-new-aa023477a92">
  ### ClickHouse 发布 v24.7.1.2915-稳定版本 (a37d2d43da7) FIXME，相较于 v24.7.1.1-new (aa023477a92)
</div>

<div id="backward-incompatible-change">
  #### 不向后兼容的变更
</div>

* 更改 Variant 数据类型的二进制序列化：新增 `compact` 模式，避免在仅包含单一 Variant 或仅包含 NULL 值的粒度中多次写入相同的判别值。新增默认启用的 MergeTree 设置 `use_compact_variant_discriminators_serialization`。请注意，Variant 类型仍处于 Experimental 阶段，因此序列化发生不向后兼容的变更是可以接受的。 [#62774](https://github.com/ClickHouse/ClickHouse/pull/62774) ([Kruglov Pavel](https://github.com/Avogar)).
* 在 Replicated 数据库中，禁止使用 `CREATE MATERIALIZED VIEW ... ENGINE Replicated*MergeTree POPULATE AS SELECT ...`。 [#63963](https://github.com/ClickHouse/ClickHouse/pull/63963) ([vdimir](https://github.com/vdimir)).
* `clickhouse-keeper-client` 现在只接受字符串字面量中的路径，例如 `ls '/hello/world'`，不接受 `ls /hello/world` 这类裸字符串。 [#65494](https://github.com/ClickHouse/ClickHouse/pull/65494) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 指标 `KeeperOutstandingRequets` 已重命名为 `KeeperOutstandingRequests`。此更改修复了在 [#66179](https://github.com/ClickHouse/ClickHouse/issues/66179) 中报告的拼写错误。 [#66206](https://github.com/ClickHouse/ClickHouse/pull/66206) ([Robert Schulze](https://github.com/rschu1ze)).
* 从 `system.functions` 表中移除 `is_deterministic` 字段。 [#66630](https://github.com/ClickHouse/ClickHouse/pull/66630) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新特性
</div>

* 扩展函数 `tuple`，使其能够在查询中构造命名元组。引入函数 `tupleNames` 以从元组中提取名称。[#54881](https://github.com/ClickHouse/ClickHouse/pull/54881) ([Amos Bird](https://github.com/amosbird)).
* `ASOF JOIN` 现已支持 `full_sorting_join` 算法，关闭了 [#54493](https://github.com/ClickHouse/ClickHouse/issues/54493)。[#55051](https://github.com/ClickHouse/ClickHouse/pull/55051) ([vdimir](https://github.com/vdimir)).
* 新增表函数 `fuzzQuery,`。该函数允许你对给定的查询字符串进行随机变异。示例：`SELECT query FROM fuzzQuery('SELECT 1');`。[#62103](https://github.com/ClickHouse/ClickHouse/pull/62103) ([pufit](https://github.com/pufit)).
* 新增窗口函数 `percent_rank`。[#62747](https://github.com/ClickHouse/ClickHouse/pull/62747) ([lgbo](https://github.com/lgbo-ustc)).
* `clickhouse-client` 现已支持 JWT 身份验证。[#62829](https://github.com/ClickHouse/ClickHouse/pull/62829) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 新增 SQL 函数 `changeYear`、`changeMonth`、`changeDay`、`changeHour`、`changeMinute`、`changeSecond`。例如，`SELECT changeMonth(toDate('2024-06-14'), 7)` 返回日期 `2024-07-14`。[#63186](https://github.com/ClickHouse/ClickHouse/pull/63186) ([cucumber95](https://github.com/cucumber95)).
* 引入启动脚本，可在启动阶段执行预先配置的查询。[#64889](https://github.com/ClickHouse/ClickHouse/pull/64889) ([pufit](https://github.com/pufit)).
* 支持在客户端配置中使用 accept&#95;invalid&#95;certificate，允许客户端通过安全 TCP 连接到使用自签名证书运行的服务器——可作为相应 `openSSL` 客户端设置 `verificationMode=none` + `invalidCertificateHandler.name=AcceptCertificateHandler` 的简写。[#65238](https://github.com/ClickHouse/ClickHouse/pull/65238) ([peacewalker122](https://github.com/peacewalker122)).
* 新增 system.error&#95;log，其中包含来自表 system.errors 的错误值历史记录，并会定期写入磁盘。[#65381](https://github.com/ClickHouse/ClickHouse/pull/65381) ([Pablo Marcos](https://github.com/pamarcos)).
* 新增聚合函数 `groupConcat`。其作用与 `arrayStringConcat( groupArray(column), ',')` 基本相同。可接收 2 个参数：字符串分隔符和要处理的元素数量。[#65451](https://github.com/ClickHouse/ClickHouse/pull/65451) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 新增 AzureQueue 存储。[#65458](https://github.com/ClickHouse/ClickHouse/pull/65458) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 新增一个设置，用于禁用/启用将页面索引写入 Parquet 文件。[#65475](https://github.com/ClickHouse/ClickHouse/pull/65475) ([lgbo](https://github.com/lgbo-ustc)).
* 允许系统管理员配置 `logger.console_log_level`。[#65559](https://github.com/ClickHouse/ClickHouse/pull/65559) ([Azat Khuzhin](https://github.com/azat)).
* 使用表函数 `file` 时，会自动在目录路径末尾追加通配符 `*`。[#66019](https://github.com/ClickHouse/ClickHouse/pull/66019) ([Zhidong (David) Guo](https://github.com/Gun9niR)).
* 在非交互模式下为客户端新增 `--memory-usage` 选项。[#66393](https://github.com/ClickHouse/ClickHouse/pull/66393) ([vdimir](https://github.com/vdimir)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 默认启用 `optimize_functions_to_subcolumns`。[#58661](https://github.com/ClickHouse/ClickHouse/pull/58661) ([Anton Popov](https://github.com/CurtizJ)).
* 将整数转字符串的算法替换为更快的版本 (从修改版 amdn/itoa 改为修改版 jeaiii/itoa) 。[#61661](https://github.com/ClickHouse/ClickHouse/pull/61661) ([Raúl Marín](https://github.com/Algunenano)).
* 现在会收集并缓存 join (`parallel_hash` 算法) 创建的哈希表大小。这些信息将用于在后续执行查询时为哈希表预分配空间，从而节省哈希表扩容时间。[#64553](https://github.com/ClickHouse/ClickHouse/pull/64553) ([Nikita Taranov](https://github.com/nickitat)).
* 通过缓冲，优化了带有 `ORDER BY` 主键且 `WHERE` 包含高选择性条件的查询。该行为由设置 `read_in_order_use_buffering` 控制 (默认启用) ，并且可能会增加查询的内存使用量。[#64607](https://github.com/ClickHouse/ClickHouse/pull/64607) ([Anton Popov](https://github.com/CurtizJ)).
* 提升了加载 `plain_rewritable` 元数据的性能。[#65634](https://github.com/ClickHouse/ClickHouse/pull/65634) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在只读磁盘上 Attach 表时，将通过不加载过期分区片段来减少资源占用。[#65635](https://github.com/ClickHouse/ClickHouse/pull/65635) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 Set 索引支持 minmax 超矩形。[#65676](https://github.com/ClickHouse/ClickHouse/pull/65676) ([AntiTopQuark](https://github.com/AntiTopQuark)).
* 卸载过期分区片段的主索引，以降低总体内存使用量。[#65852](https://github.com/ClickHouse/ClickHouse/pull/65852) ([Anton Popov](https://github.com/CurtizJ)).
* 当 pattern 很简单时，函数 `replaceRegexpAll` 和 `replaceRegexpOne` 现在会显著加快，也就是说其中不包含元字符、字符类、标志、分组字符等。 (感谢 Taiyang Li。) [#66185](https://github.com/ClickHouse/ClickHouse/pull/66185) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="improvement">
  #### 改进
</div>

* 支持将 rocksdb 用作 Keeper 的后端存储。[#56626](https://github.com/ClickHouse/ClickHouse/pull/56626) ([Han Fei](https://github.com/hanfei1991)).
* 设置 `optimize_trivial_insert_select` 默认处于禁用状态。在大多数情况下，启用它会带来收益。尽管如此，如果你发现 INSERT SELECT 变慢或内存使用增加，可以重新启用它，或执行 `SET compatibility = '24.6'`。[#58970](https://github.com/ClickHouse/ClickHouse/pull/58970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 当 `clickhouse-client` 或 `clickhouse-local` 崩溃时，会打印 stacktrace 和诊断信息。[#61109](https://github.com/ClickHouse/ClickHouse/pull/61109) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `SHOW INDEX | INDEXES | INDICES | KEYS` 的结果此前按主键列名排序。由于这种方式不够直观，现在改为按主键列在主键中的位置排序。[#61131](https://github.com/ClickHouse/ClickHouse/pull/61131) ([Robert Schulze](https://github.com/rschu1ze)).
* 此 PR 更改了 MV 的去重方式，修复了许多场景，例如：- 在目标端表上：数据会被拆分为 2 个或更多块，而这些块在并行 inserted 时会被视为重复。- 在 MV 目标端表上：相同的块会被去重，这种情况会发生在 MV 因执行 aggregation 而经常针对不同输入数据产生相同结果时。- 在 MV 目标端表上：来自不同 MV 的相同块会被去重。[#61601](https://github.com/ClickHouse/ClickHouse/pull/61601) ([Sema Checherinda](https://github.com/CheSema)).
* 读取 JSON file 时，允许以不区分大小写的方式匹配列名 (`input_format_json_case_insensitive_column_matching`) 。[#61750](https://github.com/ClickHouse/ClickHouse/pull/61750) ([kevinyhzou](https://github.com/KevinyhZou)).
* 支持读取分区的 DeltaLake 数据。通过读取 metadata 而非数据来推断 DeltaLake schema。[#63201](https://github.com/ClickHouse/ClickHouse/pull/63201) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 在 Composable protocols 中，TLS 层仅接受 `certificateFile` 和 `privateKeyFile` 参数。[https://clickhouse.com/docs/en/operations/settings/composable-protocols](https://clickhouse.com/docs/en/operations/settings/composable-protocols). [#63985](https://github.com/ClickHouse/ClickHouse/pull/63985) ([Anton Ivashkin](https://github.com/ianton-ru)).
* 为 clickhouse-disks 提供交互式 client，并支持从本地 directory 添加本地 disk。修复了 [#56791](https://github.com/ClickHouse/ClickHouse/issues/56791)。[#64446](https://github.com/ClickHouse/ClickHouse/pull/64446) ([Daniil Ivanik](https://github.com/divanik)).
* 新增 profile 事件 `SelectQueriesWithPrimaryKeyUsage`，用于指示有多少 SELECT queries 使用主键来评估 WHERE clause。[#64492](https://github.com/ClickHouse/ClickHouse/pull/64492) ([0x01f](https://github.com/0xfei)).
* `StorageS3Queue` 相关修复与改进。根据服务器上的物理 CPU 核心数推导 `s3queue_processing_threads_num` 的默认值 (不再像之前那样默认为 1) 。将 `s3queue_loading_retries` 的默认值设为 10。修复 `system.s3queue` 的 exception 列中可能出现的含糊 &quot;Uncaught exception&quot;。出现 `MEMORY_LIMIT_EXCEEDED` exception 时不增加重试次数。将文件 commit 移到表插入完全结束之后的阶段，以避免文件在尚未 inserted 时就被 commited。新增设置 `s3queue_max_processed_files_before_commit`、`s3queue_max_processed_rows_before_commit`、`s3queue_max_processed_bytes_before_commit`、`s3queue_max_processing_time_sec_before_commit`，以更好地控制 commit 和 flush 时机。[#65046](https://github.com/ClickHouse/ClickHouse/pull/65046) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 修复了 s390x 上多列聚合损坏的问题。 [#65062](https://github.com/ClickHouse/ClickHouse/pull/65062) ([Harry Lee](https://github.com/HarryLeeIBM)).
* 参数化视图函数现已支持别名 (仅限新的 analyzer) 。 [#65190](https://github.com/ClickHouse/ClickHouse/pull/65190) ([Kseniia Sumarokova](https://github.com/kssenii)).
* S3：缩短查询的重试时长，并增加备份的重试次数。查询为 8.5 分钟和 100 次重试，备份恢复为 1.2 小时和 1000 次重试。 [#65232](https://github.com/ClickHouse/ClickHouse/pull/65232) ([Sema Checherinda](https://github.com/CheSema)).
* 更新了 azureBlobStorage，使其在日志中屏蔽 account key。 [#65273](https://github.com/ClickHouse/ClickHouse/pull/65273) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 当过滤表达式是 `PARTITION BY` 表达式的一部分时，支持对 `IN` 谓词进行分区裁剪。 [#65335](https://github.com/ClickHouse/ClickHouse/pull/65335) ([Eduard Karacharov](https://github.com/korowa)).
* 添加了包含所有 detached 表主要信息的系统表。 [#65400](https://github.com/ClickHouse/ClickHouse/pull/65400) ([Konstantin Morozov](https://github.com/k-morozov)).
* 在使用自定义键并行副本时，新增对 `cluster_for_parallel_replicas` 的支持。这使你能够在 MergeTree 表上将并行副本与自定义键结合使用。 [#65453](https://github.com/ClickHouse/ClickHouse/pull/65453) ([Antonio Andelic](https://github.com/antonio2368)).
* 支持查询计划中的 LIMIT 优化。支持 PostgreSQL 存储和表函数的 LIMIT 下推。 [#65454](https://github.com/ClickHouse/ClickHouse/pull/65454) ([Maksim Kita](https://github.com/kitaisreal)).
* Arraymin/max 现可用于所有可比较的数据类型。 [#65455](https://github.com/ClickHouse/ClickHouse/pull/65455) ([pn](https://github.com/chloro-pn)).
* 改进了 cgroups v2 的内存核算，将 page cache 占用量排除在外。 [#65470](https://github.com/ClickHouse/ClickHouse/pull/65470) ([Nikita Taranov](https://github.com/nickitat)).
* 在将 chunks 序列化后插入 EmbeddedRocksDB 表时，不再为每一行创建格式设置。 [#65474](https://github.com/ClickHouse/ClickHouse/pull/65474) ([Duc Canh Le](https://github.com/canhld94)).
* 修复了 s390x 上解析 Dwarf5 时的越界异常。 [#65501](https://github.com/ClickHouse/ClickHouse/pull/65501) ([Harry Lee](https://github.com/HarryLeeIBM)).
* 将 `clickhouse-local` 的提示符简化为 `:)`。`getFQDNOrHostName()` 在 macOS 上耗时过长，而且我们本来也不希望在 `clickhouse-local` 的提示符中显示主机名。 [#65510](https://github.com/ClickHouse/ClickHouse/pull/65510) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 避免在低配虚拟机上打印 jemalloc 关于每 CPU arena 的消息。 [#65532](https://github.com/ClickHouse/ClickHouse/pull/65532) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 默认禁用文件系统缓存后台下载。待我们修复以下问题后会重新启用：如果使用后台下载线程，内存释放发生在查询上下文之外 (而缓冲区分配发生在查询上下文之内) ，可能导致 &quot;Memory limit exceeded&quot;。此外，我们还需要添加一个单独的设置来定义后台工作线程的最大下载大小 (当前受 max&#95;file&#95;segment&#95;size 限制，这个值可能过大) 。 [#65534](https://github.com/ClickHouse/ClickHouse/pull/65534) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 为配置新增选项 `<config_reload_interval_ms>`，可用于指定 ClickHouse 重新加载配置的频率。 [#65545](https://github.com/ClickHouse/ClickHouse/pull/65545) ([alesapin](https://github.com/alesapin)).
* 为 ClickHouse 数据类型实现二进制编码，并在文档中补充其规范说明。将其用于 Dynamic 二进制序列化，并允许通过设置在 RowBinaryWithNamesAndTypes 和 Native 格式中使用。 [#65546](https://github.com/ClickHouse/ClickHouse/pull/65546) ([Kruglov Pavel](https://github.com/Avogar)).
* 改进了 ZooKeeper 负载均衡。即使设置了 `fallback_session_lifetime`，当前会话在最优节点恢复可用前也不会过期。新增了对 AZ 感知负载均衡的支持。 [#65570](https://github.com/ClickHouse/ClickHouse/pull/65570) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 服务器设置 `compiled_expression_cache_size` 和 `compiled_expression_cache_elements_size` 现在会显示在 `system.server_settings` 中。 [#65584](https://github.com/ClickHouse/ClickHouse/pull/65584) ([Robert Schulze](https://github.com/rschu1ze)).
* 当对带有 projection 的表执行轻量级删除时，用户可以选择抛出异常 (默认行为) ，或删除 projection 后再执行轻量级删除。 [#65594](https://github.com/ClickHouse/ClickHouse/pull/65594) ([jsc0218](https://github.com/jsc0218)).
* 新增了基于 x509 SubjectAltName extension 识别用户的支持。 [#65626](https://github.com/ClickHouse/ClickHouse/pull/65626) ([Anton Kozlov](https://github.com/tonickkozlov)).
* `clickhouse-local` 将遵循配置文件中的 `max_server_memory_usage` 和 `max_server_memory_usage_to_ram_ratio`。默认情况下，它还会像 `clickhouse-server` 一样，将最大内存使用量设置为系统内存的 90%。这解决了 [#65695](https://github.com/ClickHouse/ClickHouse/issues/65695)。 [#65697](https://github.com/ClickHouse/ClickHouse/pull/65697) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 添加了一个将文件备份到 ClickHouse 的脚本。虽然有点奇怪，但确实可用。 [#65699](https://github.com/ClickHouse/ClickHouse/pull/65699) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* PostgreSQL source 现已支持取消操作。 [#65722](https://github.com/ClickHouse/ClickHouse/pull/65722) ([Maksim Kita](https://github.com/kitaisreal)).
* 使 allow&#95;experimental&#95;analyzer 在 distributed queries 中由 initiator 控制。这可确保在混合版本 clusters 中执行操作时的兼容性和正确性。 [#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 让 Keeper 遵循 cgroup CPU 限制。 [#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)).
* 允许在没有参数的情况下使用 `concat` 函数 &#96;&#96;&#96; sql :) select concat();。 [#65887](https://github.com/ClickHouse/ClickHouse/pull/65887) ([李扬](https://github.com/taiyang-li)).
* 允许在 clickhouse-local 中控制命名集合。 [#65973](https://github.com/ClickHouse/ClickHouse/pull/65973) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 改进了 Azure profile events。 [#65999](https://github.com/ClickHouse/ClickHouse/pull/65999) ([alesapin](https://github.com/alesapin)).
* `Query was cancelled` 之前可能会在 ClickHouse 客户端中打印两次。此问题现已修复。 [#66005](https://github.com/ClickHouse/ClickHouse/pull/66005) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 支持按 writer time zone 读取 ORC 文件。 [#66025](https://github.com/ClickHouse/ClickHouse/pull/66025) ([kevinyhzou](https://github.com/KevinyhZou)).
* 重构了 JSONExtract 函数，支持更多 types，包括 Experimental 的 Dynamic 类型。 [#66046](https://github.com/ClickHouse/ClickHouse/pull/66046) ([Kruglov Pavel](https://github.com/Avogar)).
* DatabaseCatalog 现在可使用最多 `database_catalog_drop_table_concurrency` 个线程来更快删除表。[#66065](https://github.com/ClickHouse/ClickHouse/pull/66065) ([Sema Checherinda](https://github.com/CheSema))。
* 此 PR 更改了 MV 去重的工作方式，修复了很多场景，例如：- 在目标端表上：数据会被拆分为 2 个或更多块，而这些块在并行插入时会被视为重复块。- 在 MV 目标端表上：相同的块会被去重；当 MV 因执行 aggregation 而针对不同输入数据频繁生成相同结果数据时，就会出现这种情况。- 在 MV 目标端表上：来自不同 MV 的相同块也会被去重。[#66144](https://github.com/ClickHouse/ClickHouse/pull/66144) ([Sema Checherinda](https://github.com/CheSema))。
* 支持 Variant 和 Dynamic 子列的 null map 子列。[#66178](https://github.com/ClickHouse/ClickHouse/pull/66178) ([Kruglov Pavel](https://github.com/Avogar))。
* 添加了用于控制 PostgreSQL 连接的 settings。* Setting `postgresql_connection_attempt_timeout` 指定传递给连接 URL 中 `connect_timeout` parameter 的值。* Setting `postgresql_connection_pool_retries` 指定与 PostgreSQL 端点建立连接时的重试次数。[#66232](https://github.com/ClickHouse/ClickHouse/pull/66232) ([Dmitry Novik](https://github.com/novikd))。
* 降低了 input&#95;wait&#95;elapsed&#95;us/input&#95;wait&#95;elapsed&#95;us/elapsed&#95;us 的误差。[#66239](https://github.com/ClickHouse/ClickHouse/pull/66239) ([Azat Khuzhin](https://github.com/azat))。
* 改进了 FilesystemCache 的 ProfileEvents。[#66249](https://github.com/ClickHouse/ClickHouse/pull/66249) ([zhukai](https://github.com/nauu))。
