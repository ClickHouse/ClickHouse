  ### ClickHouse 版本 v21.1.1.5646-prestable FIXME (相较于 v20.12.1.5236-prestable)
</div>

<div id="backward-incompatible-change">
  #### 不兼容的变更
</div>

* 禁止 `toUnixTimestamp(Date())` (此前它只是返回 Date 的 UInt16 表示) 。[#17376](https://github.com/ClickHouse/ClickHouse/pull/17376) ([Azat Khuzhin](https://github.com/azat)).
* 移除了聚合函数 `timeSeriesGroupSum` 和 `timeSeriesGroupRateSum`，因为据我一位朋友说，它们从来就没正常工作过。此更改修复了 [#16869](https://github.com/ClickHouse/ClickHouse/issues/16869)。如果你曾碰巧成功用过这些函数，请发送邮件至 clickhouse-feedback@yandex-team.com。[#17423](https://github.com/ClickHouse/ClickHouse/pull/17423) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 设置 `input_format_null_as_default` 现默认启用。[#17525](https://github.com/ClickHouse/ClickHouse/pull/17525) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 默认将 `insert_quorum_parallel` 设为 1。相比“sequential” quorum 插入，这种方式使用起来方便得多。但如果你依赖 sequential consistency，则应将该设置改回 0。[#17567](https://github.com/ClickHouse/ClickHouse/pull/17567) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 限制 `ALTER MODIFY SETTING` 修改会影响数据分区片段的存储设置 (`write_final_mark` 和 `enable_mixed_granularity_parts`) 。[#18306](https://github.com/ClickHouse/ClickHouse/pull/18306) ([Amos Bird](https://github.com/amosbird)).
* 检查来自 config 的 profile 设置约束。如果 users.xml 包含不满足相应约束的设置，server 将无法启动。[#18486](https://github.com/ClickHouse/ClickHouse/pull/18486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 移除 `sumburConsistentHash` 函数。此更改关闭了 [#18120](https://github.com/ClickHouse/ClickHouse/issues/18120)。[#18656](https://github.com/ClickHouse/ClickHouse/pull/18656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新增 `DIV` 和 `MOD` 运算符。`DIV` 实现整数除法。这是为了兼容 MySQL 以及支持 `sqllogictest`。此更改关闭了 [#18707](https://github.com/ClickHouse/ClickHouse/issues/18707)。如果你将 DIV 或 MOD 用作列名或别名，可能会引入不兼容问题。遇到不兼容时，请在 AS 关键字后面写别名，或将标识符用引号括起来 (双引号或反引号均可) 。[#18760](https://github.com/ClickHouse/ClickHouse/pull/18760) ([Du Chuan](https://github.com/spongedu)).

<div id="new-feature">
  #### 新特性
</div>

* 使用 [https://github.com/lemire/fast&#95;float](https://github.com/lemire/fast_float) 解析浮点数。 [#16787](https://github.com/ClickHouse/ClickHouse/pull/16787) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#16819](https://github.com/ClickHouse/ClickHouse/pull/16819) ([pronvis](https://github.com/pronvis)).
* 提供了一个新的聚合函数组合器：`-SimpleState`，可通过查询构建 SimpleAggregateFunction 类型。它对于定义 AggregatingMergeTree 引擎的 materialized view 很有用，也会让 projections 受益。 [#16853](https://github.com/ClickHouse/ClickHouse/pull/16853) ([Amos Bird](https://github.com/amosbird)).
* 新增了 `mannWitneyUTest`、`studentTTest` 和 `welchTTest` 聚合函数，并对 RankCorr 做了一些重构。 [#16883](https://github.com/ClickHouse/ClickHouse/pull/16883) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 添加了设置 optimize&#95;on&#95;insert。启用后，会对 INSERT 写入的数据块执行与该块发生合并时相同的转换 (例如 Replacing、Collapsing、Aggregating...) 。该设置将默认启用。这可能会影响 Materialized View 和 MaterializeMySQL 的行为 (参见详细说明) 。此更改关闭了 [#10683](https://github.com/ClickHouse/ClickHouse/issues/10683)。 [#16954](https://github.com/ClickHouse/ClickHouse/pull/16954) ([Kruglov Pavel](https://github.com/Avogar)).
* 添加了 `*.zst` 压缩/解压支持。这样即可在 `file()` 函数中使用 `*.zst`，并在 HTTP 客户端中使用 `Content-encoding: zstd`。此更改关闭了 [#16791 ](https://github.com/ClickHouse/ClickHouse/issues/16791)。 [#17144](https://github.com/ClickHouse/ClickHouse/pull/17144) ([Abi Palagashvili](https://github.com/fibersel)).
* * IP 字典现已直接支持 `IPv4` / `IPv6` 类型。[#17571](https://github.com/ClickHouse/ClickHouse/pull/17571) ([Vladimir C](https://github.com/vdimir)) 。
* 相关：[#16176](https://github.com/ClickHouse/ClickHouse/issues/16176) 用法：`set limit = 10; set offset = 20;` 这两个设置会影响 SELECT 查询，效果相当于追加了 `select * from ($your_original_select_query) tmp limit xxx offset xxx;`。[#17633](https://github.com/ClickHouse/ClickHouse/pull/17633) ([hexiaoting](https://github.com/hexiaoting)) 。
* 为 MergeTree 表中的总行数、字节数和 parts 总数新增异步指标。此项修复了 [#11714](https://github.com/ClickHouse/ClickHouse/issues/11714)。[#17639](https://github.com/ClickHouse/ClickHouse/pull/17639) ([flynn](https://github.com/ucasfl)) 。
* 引入 `DETACH TABLE/VIEW ... PERMANENTLY` 语法，这样重启后表不会再自动恢复出现 (仅会在显式请求时恢复) 。该表仍可使用简写语法 ATTACH TABLE 重新附加。实现了 [#5555](https://github.com/ClickHouse/ClickHouse/issues/5555)。修复了 [#13850](https://github.com/ClickHouse/ClickHouse/issues/13850)。[#17642](https://github.com/ClickHouse/ClickHouse/pull/17642) ([filimonov](https://github.com/filimonov)) 。
* 新增名为 `system.distributed_ddl_queue` 的表，用于显示 DDL 工作线程队列中的查询。[#17656](https://github.com/ClickHouse/ClickHouse/pull/17656) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 新增函数 `encodeXMLComponent`，用于对字符进行转义，以便将字符串放入 XML 文本节点或 attribute 中。[#17659](https://github.com/ClickHouse/ClickHouse/pull/17659) ([nauta](https://github.com/nautaa)) 。
* 现在 ClickHouse 客户端支持打开 EDITOR 编辑命令。`Alt-Shift-E`。[#17665](https://github.com/ClickHouse/ClickHouse/pull/17665) ([Amos Bird](https://github.com/amosbird)) 。
* 新增对 PROXYv1 protocol 的支持，用于封装 native TCP 接口。允许 quotas 按 proxy 转发的 IP 地址进行区分 (适用于 PROXYv1 地址，以及 HTTP interface 中的 X-Forwarded-For) 。这在仅通过受信任的 proxy (例如 CloudFlare) 提供 ClickHouse 访问、但又希望按用户原始 IP 地址统计资源使用情况时非常有用。此项修复了 [#17268](https://github.com/ClickHouse/ClickHouse/issues/17268)。[#17707](https://github.com/ClickHouse/ClickHouse/pull/17707) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 新增在函数 `firstSignificantSubdomainCustom`、`cutToFirstSignificantSubdomainCustom` 中使用 custom TLD list 的能力。[#17748](https://github.com/ClickHouse/ClickHouse/pull/17748) ([Azat Khuzhin](https://github.com/azat)) 。
* Clickhouse-benchmark 新增了 query parameter。[#17832](https://github.com/ClickHouse/ClickHouse/pull/17832) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 扩展了 `OPTIMIZE ... DEDUPLICATE` 语法，允许显式指定 (或通过 asterisk/列转换器隐式指定) 用于检查重复项的列列表。... [#17846](https://github.com/ClickHouse/ClickHouse/pull/17846) ([Vasily Nemkov](https://github.com/Enmk)) 。
* 向 MergeTreeSettings 添加了设置 `min_compress_block_size` 和 `max_compress_block_size`，其优先级高于全局设置，并会在设置后生效。close [13890](https://github.com/ClickHouse/ClickHouse/issues/13890)。[#17867](https://github.com/ClickHouse/ClickHouse/pull/17867) ([flynn](https://github.com/ucasfl)) 。
* 实现了 `ATTACH TABLE name FROM 'path/to/data/' (col1 Type1, ...` 查询。该查询会使用给定结构创建新表，并从 `user_files` 中指定的目录附加表数据。[#17903](https://github.com/ClickHouse/ClickHouse/pull/17903) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 新增 `arrayMin`、`arrayMax`、`arrayAvg` aggregation 函数。[#18032](https://github.com/ClickHouse/ClickHouse/pull/18032) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 支持 `SHOW SETTINGS` statement，用于显示 system.settings 中的参数。还支持 `SHOW CHANGED SETTINGS` 以及 `LIKE/ILIKE` clause。[#18056](https://github.com/ClickHouse/ClickHouse/pull/18056) ([Jianmei Zhang](https://github.com/zhangjmruc)) 。
* 允许在 `CREATE TABLE ... AS SELECT` 中指定列。示例：`CREATE TABLE t1 (x String) ENGINE = Memory AS SELECT 1;`。[#18060](https://github.com/ClickHouse/ClickHouse/pull/18060) ([Maksim Kita](https://github.com/kitaisreal)) 。
* * IP 字典支持按键查询。解决了 [#18241](https://github.com/ClickHouse/ClickHouse/issues/18241)。[#18480](https://github.com/ClickHouse/ClickHouse/pull/18480) ([Vladimir C](https://github.com/vdimir)) 。
* 已实现 `REPLACE TABLE` 和 `CREATE OR REPLACE TABLE` 查询。[#18521](https://github.com/ClickHouse/ClickHouse/pull/18521) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 新增函数 `byteSize`，用于估算其参数在内存中未压缩时占用的字节数。例如，对 UInt32 参数会返回常量 4，对 String 参数则返回字符串长度 + 9。该函数可接受多个参数，典型用法是 `byteSize(*)`。[#18579](https://github.com/ClickHouse/ClickHouse/pull/18579) ([Ping Yu](https://github.com/pingyu))。
* 为 `system.part_log` 新增 `query_id` 列，用于记录已插入 parts 对应的查询 ID。关闭 [#10097](https://github.com/ClickHouse/ClickHouse/issues/10097)。[#18644](https://github.com/ClickHouse/ClickHouse/pull/18644) ([flynn](https://github.com/ucasfl))。
* 现为 MergeTree 家族中的表新增存储设置 `max_partitions_to_read`，用于限制单个查询中可访问的最大分区数。同时还新增了用户设置 `force_max_partition_limit`，以强制执行此限制。[#18712](https://github.com/ClickHouse/ClickHouse/pull/18712) ([Amos Bird](https://github.com/amosbird))。
* 函数 `position` 现已支持 `position(needle in haystack)` 语法，以兼容 SQL。关闭 [#18701](https://github.com/ClickHouse/ClickHouse/issues/18701)。... [#18779](https://github.com/ClickHouse/ClickHouse/pull/18779) ([Jianmei Zhang](https://github.com/zhangjmruc))。

<div id="performance-improvement">
  #### 性能提升
</div>

* 略微提升了 Float 解析性能。[#16809](https://github.com/ClickHouse/ClickHouse/pull/16809) ([Maksim Kita](https://github.com/kitaisreal)).
* 提升了函数 `repeat` 的性能。[#16937](https://github.com/ClickHouse/ClickHouse/pull/16937) ([satanson](https://github.com/satanson)).
* 修复了在大量 `MergeTree` 表上读取 `Merge` 表时的性能问题。修复 [#7748](https://github.com/ClickHouse/ClickHouse/issues/7748)。[#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).
* 现在，`-If` 组合器已完成去虚拟化，且 `count` 已正确向量化。相关内容见 [https://github.com/ClickHouse/ClickHouse/pull/17041](https://github.com/ClickHouse/ClickHouse/pull/17041)。[#17043](https://github.com/ClickHouse/ClickHouse/pull/17043) ([Amos Bird](https://github.com/amosbird)).
* 提升了主键中包含 SimpleAggregateFunction(String) 的 AggregatingMergeTree 的性能。[#17109](https://github.com/ClickHouse/ClickHouse/pull/17109) ([Azat Khuzhin](https://github.com/azat)).
* 添加了 `remerge_sort_lowered_memory_bytes_ratio` 设置 (如果 remerge 后的内存使用量没有按该比例降低，则会禁用 remerge) 。[#17539](https://github.com/ClickHouse/ClickHouse/pull/17539) ([Azat Khuzhin](https://github.com/azat)).
* 加快了 `IPv6CIDRToRange` 的实现速度。[#17569](https://github.com/ClickHouse/ClickHouse/pull/17569) ([Vladimir C](https://github.com/vdimir)).
* 使用 dragonbox 算法替代 ryu 进行 float 到字符串的转换。[#17831](https://github.com/ClickHouse/ClickHouse/pull/17831) ([Maksim Kita](https://github.com/kitaisreal)).
* 优化了 StorageMemory 的读取性能。[#18052](https://github.com/ClickHouse/ClickHouse/pull/18052) ([Maksim Kita](https://github.com/kitaisreal)).
* 在向分布式表同步 INSERT 时，不再向分片发送空块。此更改关闭了 [#14571](https://github.com/ClickHouse/ClickHouse/issues/14571)。[#18775](https://github.com/ClickHouse/ClickHouse/pull/18775) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在 `AggregateFunctionWindowFunnelData` 中将 `PODArray` 替换为 `PODArrayWithStackMemory`，以提升 `windowFunnel` 函数的性能。[#18817](https://github.com/ClickHouse/ClickHouse/pull/18817) ([flynn](https://github.com/ucasfl)).
* 为 `clickhouse-local` 添加了 `--no-system-table` 选项，可在没有系统表的情况下运行。这样可避免初始化 `DateLUT`，后者在启动时可能会耗费明显时间 (数十毫秒) 。[#18899](https://github.com/ClickHouse/ClickHouse/pull/18899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 改进
</div>

* * 全新的 IP 字典实现，内存占用更低，在某些场景下性能更佳，并修复了若干 bug。[#16804](https://github.com/ClickHouse/ClickHouse/pull/16804) ([Vladimir C](https://github.com/vdimir)).
* 为 S3 client 新增了通过环境变量、`~/.aws` 和 `AssumeRole` 进行正确身份验证的支持。[#16856](https://github.com/ClickHouse/ClickHouse/pull/16856) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 支持 HTTP 代理和 HTTPS S3 端点的配置。[#16861](https://github.com/ClickHouse/ClickHouse/pull/16861) ([Pavel Kovalenko](https://github.com/Jokser)).
* 当 `-OrNull` 组合器与 `-If`、`-Merge`、`-MergeState`、`-State` 组合器一起使用时，应将 `-OrNull` 放在前面。[#16935](https://github.com/ClickHouse/ClickHouse/pull/16935) ([flynn](https://github.com/ucasfl)).
* * 增加对多个 ZooKeeper 集群的配置支持。[#17070](https://github.com/ClickHouse/ClickHouse/pull/17070) ([fastio](https://github.com/fastio)).
* * 为发送到 S3 存储的请求添加 HTTP 重定向次数上限 (&#39;s3&#95;max&#95;redirects&#39;) 。[#17220](https://github.com/ClickHouse/ClickHouse/pull/17220) ([ianton-ru](https://github.com/ianton-ru)) 。
* 现在 set 索引已支持 `GLOBAL IN`。此修复解决了 [#17232](https://github.com/ClickHouse/ClickHouse/issues/17232) 和 [#5576](https://github.com/ClickHouse/ClickHouse/issues/5576)。[#17253](https://github.com/ClickHouse/ClickHouse/pull/17253) ([Amos Bird](https://github.com/amosbird)).
* 避免了 bigint 转换过程中可能发生的栈溢出。大整数仍处于 Experimental 阶段。[#17269](https://github.com/ClickHouse/ClickHouse/pull/17269) ([flynn](https://github.com/ucasfl)).
* 改进了精简版 Web UI：添加历史记录；支持共享；避免不同请求之间的竞态条件；添加请求进行中和就绪指示器；添加 favicon；在 textarea 未获得焦点时检测 Ctrl+Enter。[#17293](https://github.com/ClickHouse/ClickHouse/pull/17293) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 当列大小未知时，允许将 `optimize_move_to_prewhere` 优化用于 compact parts。[#17330](https://github.com/ClickHouse/ClickHouse/pull/17330) ([Anton Popov](https://github.com/CurtizJ)).
* 实现了 `countSubstrings()`/`countSubstringsCaseInsensitive()`/`countSubstringsCaseInsensitiveUTF8()` (统计子串出现次数) 。[#17347](https://github.com/ClickHouse/ClickHouse/pull/17347) ([Azat Khuzhin](https://github.com/azat)).
* 在 receiveHello 中添加 eof 检查，以防出现 `Attempt to read after eof` 异常。[#17365](https://github.com/ClickHouse/ClickHouse/pull/17365) ([Kruglov Pavel](https://github.com/Avogar)).
* 将 `malloc` 替换为 `new`，以便 `MemoryTracker` 将这部分内存纳入统计。[#17412](https://github.com/ClickHouse/ClickHouse/pull/17412) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 修复了 `INSERT ... SELECT ... SETTINGS` 查询中 SETTINGS 子句的解析问题。[#17414](https://github.com/ClickHouse/ClickHouse/pull/17414) ([Azat Khuzhin](https://github.com/azat)).
* 对 `./clickhouse install` 脚本进行了多项改进。[#17421](https://github.com/ClickHouse/ClickHouse/pull/17421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 简化了 Sys/V init 脚本。此前该脚本在 Ubuntu 12.04 上无法正常工作。[#17428](https://github.com/ClickHouse/ClickHouse/pull/17428) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 现在，通过 MySQL 和 PostgreSQL 协议到达服务器的查询具有不同的 interface 类型 (可在表 `system.query_log` 的 `interface` 列中看到) ：MySQL 为 `4`，PostgreSQL 为 `5`，不再使用此前的 `1`；`1` 现在仅用于 native protocol。[#17437](https://github.com/ClickHouse/ClickHouse/pull/17437) ([Vitaly Baranov](https://github.com/vitlibar)).
* 允许在 `config.xml` 中使用 `<ttl>` attribute 指定 [生存时间 (TTL)](https://clickhouse.tech/docs/en/engines/table-engines/mergetree-family/mergetree/#mergetree-table-ttl)，以从 [system 日志表](https://clickhouse.tech/docs/en/operations/system-tables/) 中删除旧条目。[#17438](https://github.com/ClickHouse/ClickHouse/pull/17438) ([Du Chuan](https://github.com/spongedu)).
* 添加了函数 countMatches/countMatchesCaseInsensitive。[#17459](https://github.com/ClickHouse/ClickHouse/pull/17459) ([Azat Khuzhin](https://github.com/azat)).
* 当启用 `asterisk_include_materialized_columns` 和 `asterisk_include_alias_columns` 开关时，在通配符查询中也会像 MATERIALIZED / ALIAS 一样返回动态列。[#17462](https://github.com/ClickHouse/ClickHouse/pull/17462) ([Ken Chen](https://github.com/chenziliang)).
* 导出所有服务器当前线程的异步指标。这有助于排查类似 [https://github.com/ClickHouse-Extras/poco/pull/28](https://github.com/ClickHouse-Extras/poco/pull/28) 的问题。[#17463](https://github.com/ClickHouse/ClickHouse/pull/17463) ([Amos Bird](https://github.com/amosbird)) 。
* 导出 DDLWorker 当前已执行的最大 DDL entry。这有助于检查 DDLWorker 是否卡在某个位置。[#17464](https://github.com/ClickHouse/ClickHouse/pull/17464) ([Amos Bird](https://github.com/amosbird)) 。
* 查询混淆器：避免将某些 SQL 关键字用作标识符名称。[#17526](https://github.com/ClickHouse/ClickHouse/pull/17526) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 允许在 ALTER 查询的 UPDATE 语句中使用查询参数。修复了 [#10976](https://github.com/ClickHouse/ClickHouse/issues/10976)。[#17563](https://github.com/ClickHouse/ClickHouse/pull/17563) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 不再在 INSERT 查询执行到一半时抛出“parts 过多”错误。[#17566](https://github.com/ClickHouse/ClickHouse/pull/17566) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 允许从调试文件重新加载符号。此 PR 还修复了一个 build-id 问题。[#17637](https://github.com/ClickHouse/ClickHouse/pull/17637) ([Amos Bird](https://github.com/amosbird)) 。
* 修复了 [#17457](https://github.com/ClickHouse/ClickHouse/issues/17457)。[#17641](https://github.com/ClickHouse/ClickHouse/pull/17641) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 切换到 RocksDB 的补丁版本 (来自 ClickHouse-Extras) 。[#17643](https://github.com/ClickHouse/ClickHouse/pull/17643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 在 Buffer flush 期间不再忽略服务器内存限制。[#17646](https://github.com/ClickHouse/ClickHouse/pull/17646) ([Azat Khuzhin](https://github.com/azat)) 。
* 移除了在表初始化时因无 connection 而抛出异常的行为 (它会在后台重新连接) 。[#17709](https://github.com/ClickHouse/ClickHouse/pull/17709) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* system.query&#95;log 现在包含更丰富的信息，以便进行更好的查询分析。[#17726](https://github.com/ClickHouse/ClickHouse/pull/17726) ([Amos Bird](https://github.com/amosbird)) 。
