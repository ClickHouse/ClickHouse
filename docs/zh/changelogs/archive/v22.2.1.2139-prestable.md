<div id="new-feature">
  #### 新特性
</div>

* (尚未可用于生产环境，已归入 experimental features) 为 `MemoryTracker` 添加内存 overcommit。新增内存限制 `guaranteed` 设置，表示软内存限制。当达到硬内存限制时，`MemoryTracker` 会尝试取消 overcommit 最严重的查询。新设置 `memory_usage_overcommit_max_wait_microseconds` 指定查询最多可等待另一查询停止的时长。关闭 [#28375](https://github.com/ClickHouse/ClickHouse/issues/28375)。[#31182](https://github.com/ClickHouse/ClickHouse/pull/31182) ([Dmitry Novik](https://github.com/novikd)) 。
* 该设置允许用户在 MergeTree/ReplicatedMergeTree 中自定义去重语义。如果提供了该设置，则会使用它而不是数据摘要来生成块 ID。因此，例如，在每个 INSERT 语句中为该设置提供一个唯一值，用户就可以避免对相同的已插入数据进行去重。此更改关闭：[#7461](https://github.com/ClickHouse/ClickHouse/issues/7461)。[#32304](https://github.com/ClickHouse/ClickHouse/pull/32304) ([Igor Nikonov](https://github.com/devcrafter)) 。
* 为 INSERT 语句添加对 DEFAULT 关键字的支持。关闭 [#6331](https://github.com/ClickHouse/ClickHouse/issues/6331)。[#33141](https://github.com/ClickHouse/ClickHouse/pull/33141) ([Andrii Buriachevskyi](https://github.com/0over)) 。
* 为 ttests 添加置信区间。[#33260](https://github.com/ClickHouse/ClickHouse/pull/33260) ([achimbab](https://github.com/achimbab)) 。
* 允许在 insert 时为 File/S3/HDFS 引擎创建新文件。允许覆盖 HDFS 中的文件。默认情况下，尝试覆盖 S3 中的文件时会抛出异常。对于带有后缀的 format，尝试向文件追加数据时会抛出异常。关闭 [#31640](https://github.com/ClickHouse/ClickHouse/issues/31640) 关闭 [#31622](https://github.com/ClickHouse/ClickHouse/issues/31622) 关闭 [#23862](https://github.com/ClickHouse/ClickHouse/issues/23862) 关闭 [#15022](https://github.com/ClickHouse/ClickHouse/issues/15022) 关闭 [#16674](https://github.com/ClickHouse/ClickHouse/issues/16674)。[#33302](https://github.com/ClickHouse/ClickHouse/pull/33302) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 添加 `h3ToCenterChild` 函数。[#33313](https://github.com/ClickHouse/ClickHouse/pull/33313) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 合并用于文本分类的函数。参见 [#23271](https://github.com/ClickHouse/ClickHouse/issues/23271)。[#33314](https://github.com/ClickHouse/ClickHouse/pull/33314) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 实现了 meanZTest。[#33354](https://github.com/ClickHouse/ClickHouse/pull/33354) ([achimbab](https://github.com/achimbab)) 。
* * 新增函数 bitSlice。[#33360](https://github.com/ClickHouse/ClickHouse/pull/33360) ([RogerYK](https://github.com/RogerYK)).
* 新增 h3 其他函数：`edgeLengthKm`,`exactEdgeLengthKm`,`exactEdgeLengthM`,`exactEdgeLengthRads`,`numHexagons`。[#33621](https://github.com/ClickHouse/ClickHouse/pull/33621) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 新增 `DEGREES` 和 `RADIANS` 函数。[#33769](https://github.com/ClickHouse/ClickHouse/pull/33769) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 参数 `--host` 现在可接受多个主机；如果其中一个不可用，客户端将尝试连接到下一个主机。[#33824](https://github.com/ClickHouse/ClickHouse/pull/33824) ([Filippov Denis](https://github.com/DF5HSE)) 。
* 在 clickhouse-local 中根据文件名检测格式。[#33829](https://github.com/ClickHouse/ClickHouse/pull/33829) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 在 PoolBase 中新增 `expire()` 方法，用于重新分配池中的无效对象。[#34076](https://github.com/ClickHouse/ClickHouse/pull/34076) ([lgbo](https://github.com/lgbo-ustc)) 。
* 新增表函数 `format(format_name, data)`。[#34125](https://github.com/ClickHouse/ClickHouse/pull/34125) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 允许创建默认的表引擎。[#34187](https://github.com/ClickHouse/ClickHouse/pull/34187) ([Ilya Yatsishin](https://github.com/qoega)) 。
* 在 `CREATE TABLE` 查询中新增了 `EPHEMERAL` 列修饰符。关闭了 [#9436](https://github.com/ClickHouse/ClickHouse/issues/9436)。[#34424](https://github.com/ClickHouse/ClickHouse/pull/34424) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)) 。

<div id="performance-improvement">
  #### 性能提升
</div>

* 对插入到 S3 和合并到 S3 的操作，尽可能并行写入文件。[#33291](https://github.com/ClickHouse/ClickHouse/pull/33291) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 如果某个键对应大量时间间隔，则提升 RangeHashedDictionary 的性能。修复了 [#23821](https://github.com/ClickHouse/ClickHouse/issues/23821)。[#33516](https://github.com/ClickHouse/ClickHouse/pull/33516) ([Maksim Kita](https://github.com/kitaisreal)).
* 为 memcmpSmall 函数添加 x86 avx512 支持，以加速内存比较。仅在自行编译 ClickHouse 时有效。[#33706](https://github.com/ClickHouse/ClickHouse/pull/33706) ([hanqf-git](https://github.com/hanqf-git)).
* 重构后将标量缓存重新引入 MV 执行。[#33958](https://github.com/ClickHouse/ClickHouse/pull/33958) ([Raúl Marín](https://github.com/Algunenano)).
* 使 ORDER BY tuple 的速度几乎与 ORDER BY 列一样快。我们对多列 ORDER BY 有专门的优化：[https://github.com/ClickHouse/ClickHouse/pull/10831](https://github.com/ClickHouse/ClickHouse/pull/10831)。将其也应用于 tuple 列同样有益。[#34060](https://github.com/ClickHouse/ClickHouse/pull/34060) ([Amos Bird](https://github.com/amosbird)).
* 对 `ExecuteScalarSubqueriesMatcher::visit` 中潜在的热点路径做了小幅优化，此前每次函数调用都会构造 `std::set<String>`。[#34128](https://github.com/ClickHouse/ClickHouse/pull/34128) ([Federico Rodriguez](https://github.com/fedrod)).
* 小幅提升了 `Regexp` 格式的性能。[#34202](https://github.com/ClickHouse/ClickHouse/pull/34202) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 优化 quantilesExact{Low,High}，改用 nth&#95;element 替代排序。[#34287](https://github.com/ClickHouse/ClickHouse/pull/34287) ([Daniel Kutenin](https://github.com/danlark1)) 。
* 提升 `LineAsString` 格式的性能。此更改关闭了 [#34303](https://github.com/ClickHouse/ClickHouse/issues/34303)。[#34306](https://github.com/ClickHouse/ClickHouse/pull/34306) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 加快数据分区片段的加载速度。此前未实现并行加载：设置 `part_loading_threads` 没有生效。参见 [#4699](https://github.com/ClickHouse/ClickHouse/issues/4699)。[#34310](https://github.com/ClickHouse/ClickHouse/pull/34310) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 `_file` 和 `_path` 虚拟列 (在类文件表引擎中) 设为 `LowCardinality`，从而加快针对多个文件的查询。关闭了 [#34300](https://github.com/ClickHouse/ClickHouse/issues/34300)。[#34317](https://github.com/ClickHouse/ClickHouse/pull/34317) ([flynn](https://github.com/ucasfl)).
* 提升 `mapPopulateSeries` 函数的性能。关闭了 [#33944](https://github.com/ClickHouse/ClickHouse/issues/33944)。[#34318](https://github.com/ClickHouse/ClickHouse/pull/34318) ([Maksim Kita](https://github.com/kitaisreal)).
* 在执行快照时，使用 vector 收集无用的 list 迭代器；随后在 clearOutdatedNodes 中只需遍历 vector，而不必遍历 list，因此速度更快。[#34484](https://github.com/ClickHouse/ClickHouse/pull/34484) ([zhanglistar](https://github.com/zhanglistar)).
* 提升对 URL、S3、File、HDFS 表函数执行 insert 的性能。关闭了 [#34348](https://github.com/ClickHouse/ClickHouse/issues/34348)。[#34510](https://github.com/ClickHouse/ClickHouse/pull/34510) ([Maksim Kita](https://github.com/kitaisreal)).
* 根据 [https://github.com/eBay/NuRaft/issues/209](https://github.com/eBay/NuRaft/issues/209)，没有必要对该方法加锁。[#34523](https://github.com/ClickHouse/ClickHouse/pull/34523) ([zhanglistar](https://github.com/zhanglistar)).
