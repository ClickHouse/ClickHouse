<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#32693](https://github.com/ClickHouse/ClickHouse/issues/32693) 中回移：尚未达到 Quota 限制，却仍被判定为超限。此 PR 修复了 [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174)。[#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).

#### 缺陷修复 (官方稳定版本中用户可见的异常行为) 

* 已在 [#32681](https://github.com/ClickHouse/ClickHouse/issues/32681) 中回移：修复在 detach parts 时意外删除投影的问题。[#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#32483](https://github.com/ClickHouse/ClickHouse/issues/32483) 中回移：修复 `'APPLY lambda'` 的解析问题，该问题可能导致客户端/服务端崩溃。[#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#32542](https://github.com/ClickHouse/ClickHouse/issues/32542) 中回移：某些复制队列条目可能会因 `temporary_directories_lifetime` (默认 1 天) 而卡住，并报出 `Directory tmp_merge_<part_name>`、`Part ... (state Deleting) already exists, but it will be deleted soon` 或类似错误。现已修复。修复了 [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32710](https://github.com/ClickHouse/ClickHouse/issues/32710) 中回移：修复尝试使用尚未 materialized 的 skipping indices 时查询失败的问题。修复了 [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) 和 [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343)。[#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#32569](https://github.com/ClickHouse/ClickHouse/issues/32569) 中回移：修复 `JoinCommon::removeColumnNullability` 中的崩溃问题，关闭 [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458)。[#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#32770](https://github.com/ClickHouse/ClickHouse/issues/32770) 中回移：修复 sparse&#95;hashed dict 在顺序键场景下的性能问题 (哈希函数错误) 。[#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#32634](https://github.com/ClickHouse/ClickHouse/issues/32634) 中回移：修复并行 DROP TABLE 和 INSERT 场景下的表生命周期问题 (即可能发生 use-after-free) 。[#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#32632](https://github.com/ClickHouse/ClickHouse/issues/32632) 中回移：通过延迟创建 channel，修复 RabbitMQ storage 启动时可能出现的异常。[#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#32733](https://github.com/ClickHouse/ClickHouse/issues/32733) 中回移：修复函数 `file` 中一处明显有问题的代码。[#32640](https://github.com/ClickHouse/ClickHouse/pull/32640) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#32793](https://github.com/ClickHouse/ClickHouse/issues/32793) 中回移：修复对同一个 FixedString 多次使用 fuzzBits 时发生的崩溃问题，关闭 [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
