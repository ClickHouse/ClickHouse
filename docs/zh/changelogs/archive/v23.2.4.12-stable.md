<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#47277](https://github.com/ClickHouse/ClickHouse/issues/47277) 中回移：修复了 [https://github.com/ClickHouse/ClickHouse/pull/43221](https://github.com/ClickHouse/ClickHouse/pull/43221) 中引入的二进制格式下 IPv4/IPv6 序列化/反序列化问题。关闭 [#46522](https://github.com/ClickHouse/ClickHouse/issues/46522)。[#46616](https://github.com/ClickHouse/ClickHouse/pull/46616) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#47212](https://github.com/ClickHouse/ClickHouse/issues/47212) 中回移：在某些情况下，通过 native TCP protocol 和 HTTP protocol 发送的 `INSERT` 查询无法被正确取消。如果客户端取消查询、客户端崩溃，或在极少数情况下发生网络错误，可能会导致查询只被部分执行，进而导致去重失效。修复了 [#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) 和 [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377)。[#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#47363](https://github.com/ClickHouse/ClickHouse/issues/47363) 中回移：修复了取消分布式查询时可能出现的死锁问题。[#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)) 。
