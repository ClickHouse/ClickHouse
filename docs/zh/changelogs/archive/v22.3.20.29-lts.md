<div id="improvement">
  #### 改进
</div>

* 已在 [#46979](https://github.com/ClickHouse/ClickHouse/issues/46979) 中回移：将 `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` 应用到所有副本，因为 `ALTER TABLE t MOVE` 不会复制到其他副本。[#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 修复 QueryNormalizer 中错误的别名递归 [#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* 修复聚合优化中的算术操作问题 [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* 修复 `maxIntersections` 函数中的 MSan 报告 [#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复某些 LIKE 搜索在 LIKE pattern 包含带引号的不可引用字符时返回错误结果的问题 [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
* 修复 QueryStatus 中可能发生的死锁问题 [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).
