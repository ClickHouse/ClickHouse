<div id="improvement">
  #### 改进
</div>

* 已在 [#48157](https://github.com/ClickHouse/ClickHouse/issues/48157) 中回移：修复了对一个存在不可用依赖表的 materialized view 执行 Attach 操作时出现的 `UNKNOWN_TABLE` 异常。在尝试从备份中恢复状态时，这可能会很有用。[#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#48957](https://github.com/ClickHouse/ClickHouse/issues/48957) 中回移：最近一次更新后，`dockerd` 需要显式同时指定 `--tlsverify=false` 和 HTTP 端口。[#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* 移除一项功能 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
