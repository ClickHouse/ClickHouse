<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#55291](https://github.com/ClickHouse/ClickHouse/issues/55291) 中回移：包含源代码及子模块的资源会在 Darwin 专用构建任务中构建，可用于在不检出子模块的情况下构建 ClickHouse。[#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* 已在 [#54705](https://github.com/ClickHouse/ClickHouse/issues/54705) 中回移：为拉取请求中未变更的镜像，用 master 的最新标签补充 `changed_images.json`。[#54369](https://github.com/ClickHouse/ClickHouse/pull/54369) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#54683](https://github.com/ClickHouse/ClickHouse/issues/54683) 中回移：每次 push 都构建并上传它们，其实并不划算。[#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 已在 [#55407](https://github.com/ClickHouse/ClickHouse/issues/55407) 中回移：解决从 clickhouse-server 软件包启动独立模式的 clickhouse-keeper 时出现的问题。[#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 已在 [#55723](https://github.com/ClickHouse/ClickHouse/issues/55723) 中回移：修复 integration check 的 Python 脚本，使其使用 gh API URL；并为 CI 测试添加 README。[#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
