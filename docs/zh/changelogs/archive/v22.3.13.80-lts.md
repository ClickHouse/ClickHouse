  ### ClickHouse 发布版本 v22.3.13.80-lts (e2708b01fba) FIXME 相较于 v22.3.12.19-lts (4a08f8a073b)
</div>

<div id="new-feature">
  #### 新特性
</div>

* 已在 [#41264](https://github.com/ClickHouse/ClickHouse/issues/41264) 中回移：实现了将数据库引擎从 `Ordinary` 自动转换为 `Atomic`。在 `flags` 目录中创建空的 `convert_ordinary_to_atomic` 文件后，所有 `Ordinary` 数据库都会在服务器下次启动时自动完成转换。解决了 [#39546](https://github.com/ClickHouse/ClickHouse/issues/39546)。[#39933](https://github.com/ClickHouse/ClickHouse/pull/39933) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#40886](https://github.com/ClickHouse/ClickHouse/issues/40886) 中回移：新增了一个设置，用于禁用 `kafka_num_consumers` 的数量限制。关闭了 [#40331](https://github.com/ClickHouse/ClickHouse/issues/40331)。[#40670](https://github.com/ClickHouse/ClickHouse/pull/40670) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#41273](https://github.com/ClickHouse/ClickHouse/issues/41273) 中回移：修复了在将 Array(Nullable) 用作参数时，函数 `encrypt` 和 `contingency` 存在的内存安全问题。该修复解决了 [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004)。[#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进

* 已在 [#41557](https://github.com/ClickHouse/ClickHouse/issues/41557) 中回移：向 deb 软件包添加 `source` 字段，并更新 `nfpm`。[#41531](https://github.com/ClickHouse/ClickHouse/pull/41531) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

No such file or directory.`。[#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).

* 已在 [#40663](https://github.com/ClickHouse/ClickHouse/issues/40663) 中回移: 修复 AWS SDK 中 bug 导致的潜在数据丢失问题 ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)) 。该 bug 仅会在 ClickHouse 通过 S3 使用时触发。[#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
* 已在 [#40901](https://github.com/ClickHouse/ClickHouse/issues/40901) 中回移: 修复在无查询上下文时推送到 MV 的内存泄漏问题 (来自 Kafka/...) 。[#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#41637](https://github.com/ClickHouse/ClickHouse/issues/41637) 中回移: 修复 aggregate function combinators 中可能出现的 segfault、use-heap-after-free 以及内存泄漏问题。关闭 [#40848](https://github.com/ClickHouse/ClickHouse/issues/40848)。[#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#41664](https://github.com/ClickHouse/ClickHouse/issues/41664) 中回移: 子查询中带有 `OFFSET` 子句且外层查询带有 `WHERE` 子句的查询可能返回错误结果，该问题已修复。修复了 [#40416](https://github.com/ClickHouse/ClickHouse/issues/40416)。[#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#41356](https://github.com/ClickHouse/ClickHouse/issues/41356) 中回移: 在 MsgPack format 中执行 UUID 插入前添加列类型检查。[#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#41807](https://github.com/ClickHouse/ClickHouse/issues/41807) 中回移：Native format 中的恶意数据可能会导致崩溃。[#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#41804](https://github.com/ClickHouse/ClickHouse/issues/41804) 中回移：聚合函数 `categorialInformationValue` 的属性定义有误，可能导致运行时发生空指针解引用。此项关闭了 [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443)。[#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#41503](https://github.com/ClickHouse/ClickHouse/issues/41503) 中回移：以 Apache `ORC` 格式写入数据时，可能会导致缓冲区越界。[#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#41639](https://github.com/ClickHouse/ClickHouse/issues/41639) 中回移：修复带有 `OFFSET` 的查询中可能出现的 `pipeline stuck` 异常。该错误是在 `enable_optimize_predicate_expression = 0` 且 `WHERE` 中条件恒为 `false` 时发现的。修复了 [#41383](https://github.com/ClickHouse/ClickHouse/issues/41383)。[#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#41899](https://github.com/ClickHouse/ClickHouse/issues/41899) 中回移：修复在 `Merge` 表上执行 `SELECT` 且启用 `optimize_monotonous_functions_in_order_by` 设置时可能发生的崩溃。修复了 [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269)。[#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
