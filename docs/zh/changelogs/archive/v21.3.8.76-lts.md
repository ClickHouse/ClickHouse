  ### ClickHouse 版本 v21.3.8.76-长期支持版 FIXME (与 v21.3.7.62-stable 相比)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#23396](https://github.com/ClickHouse/ClickHouse/issues/23396) 中回移：如果由 NULL 组成的 Tuple (例如 `(NULL, NULL)`) 位于 `IN` 运算符左侧，而右侧是由 non-NULL Tuple 组成的集合，例如 `SELECT (NULL, NULL) IN ((0, 0), (3, 1))`，则现在会返回 0，而不是因类型不兼容而抛出异常。该表达式也可能由于对类似 `SELECT (NULL, NULL) = (8, 0) OR (NULL, NULL) = (3, 2) OR (NULL, NULL) = (0, 0) OR (NULL, NULL) = (3, 1)` 的语句进行优化而出现。此项修复关闭了 [#22017](https://github.com/ClickHouse/ClickHouse/issues/22017)。[#22063](https://github.com/ClickHouse/ClickHouse/pull/22063) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#23272](https://github.com/ClickHouse/ClickHouse/issues/23272) 中回移：禁用设置 `use_hedged_requests` 和 `async_socket_for_remote`，因为有证据表明它们可能会导致问题。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#23232](https://github.com/ClickHouse/ClickHouse/issues/23232) 中回移：如果在 default profile 中启用 `data_type_default_nullable` 设置，服务器可能无法启动，现已修复。修复了 [#22573](https://github.com/ClickHouse/ClickHouse/issues/22573)。[#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#23406](https://github.com/ClickHouse/ClickHouse/issues/23406) 中回移：如果子查询被优化为常量，QueryAliasVisitor 会优先为 ASTWithAlias 选择 alias。修复了 [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924)。修复了 [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401)。[#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#23381](https://github.com/ClickHouse/ClickHouse/issues/23381) 中回移：修复了从 `MaterializeMySQL` 中按键列条件查询时出现 `Not found column` 错误的问题。修复了 [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432)。[#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#23284](https://github.com/ClickHouse/ClickHouse/issues/23284) 中回移：修复了当主键不是第一个 attribute 时，simple key dictionary 无法通过 DDL 创建的问题。修复了 [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236)。[#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#23450](https://github.com/ClickHouse/ClickHouse/issues/23450) 中回移：修复了在创建和删除 ReplicatedMergeTree 表之间极少发生的 (distributed) 竞态条件。这可能导致在尝试创建 replicated table 时出现 `node doesn't exist` 之类的异常。修复了 [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419)。[#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#23500](https://github.com/ClickHouse/ClickHouse/issues/23500) 中回移：修复了在收到来自 remote query 的 `unknown packet` 时可能发生的崩溃问题 (启用 `async_socket_for_remote` 时) 。可能修复了 [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167)。[#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#23468](https://github.com/ClickHouse/ClickHouse/issues/23468) 中回移：如果该列位于主键中 (或是其单调函数) ，且未关闭 `optimize_read_in_order` 设置，则带有 `COLLATE` 的 `ORDER BY` 无法正确工作。此项关闭了 [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379)。旧版本的临时解决方案：关闭 `optimize_read_in_order` 设置。[#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#23544](https://github.com/ClickHouse/ClickHouse/issues/23544) 中回移：移除了对单个 `Tuple` 参数的 `argMin` 和 `argMax` 支持。这部分代码不具备内存安全性。该功能是误加的，而且容易引起混淆。后续可以用其他名称重新引入这些函数。此项修复了 [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384)，并回退了 [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359)。[#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#23479](https://github.com/ClickHouse/ClickHouse/issues/23479) 中回移：Kafka 存储可能支持 `arrow` 和 `arrowstream` 格式的消息。[#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* 已在 [#23499](https://github.com/ClickHouse/ClickHouse/issues/23499) 中回移：- 修复 `deltaSum` 聚合函数在 Counter 重置场景下的缺陷 ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* 已在 [#23493](https://github.com/ClickHouse/ClickHouse/issues/23493) 中回移：修复了一个缺陷：无法将空数组字面量转换为维度大于 1 的数组。关闭 [#14476](https://github.com/ClickHouse/ClickHouse/issues/14476)。[#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)).
