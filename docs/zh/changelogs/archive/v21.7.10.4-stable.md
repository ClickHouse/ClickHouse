  # 2022 更新日志
</div>

<div id="clickhouse-release-v217104-stable-fixme-as-compared-to-v21797-stable">
  ### ClickHouse 版本 v21.7.10.4-稳定版本 FIXME，相比 v21.7.9.7-稳定版本
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#28898](https://github.com/ClickHouse/ClickHouse/issues/28898) 中回移：在垂直合并中使用实际的 tmp 文件，而不是预定义的 &quot;rows&#95;sources&quot;。这样可避免在 tmp 磁盘上生成无用目录。[#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#27925](https://github.com/ClickHouse/ClickHouse/issues/27925) 中回移：修复 PostgreSQL 风格的类型转换 (`::` 运算符) 在处理负数时的问题。[#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#28752](https://github.com/ClickHouse/ClickHouse/issues/28752) 中回移：修复在分布式查询中，当设置 `legacy_column_name_of_tuple_literal = 0` 时，将析取链转换为 `IN` (由设置 `optimize_min_equality_disjunction_chain_length` 控制) 的问题。[#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#28509](https://github.com/ClickHouse/ClickHouse/issues/28509) 中回移：修复了在后台处理分布式 DDL 队列时可能发生的 ZooKeeper watch 泄漏问题。关闭 [#26036](https://github.com/ClickHouse/ClickHouse/issues/26036)。[#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#28570](https://github.com/ClickHouse/ClickHouse/issues/28570) 中回移：修复了对 `ReplicatedVersionedCollapsingMergeTree` 执行 ALTER 后，可能出现错误 `Existing table metadata in ZooKeeper differs in sorting key expression.` 的缺陷。修复 [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515)。[#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* 已在 [#28598](https://github.com/ClickHouse/ClickHouse/issues/28598) 中回移：修复了查询包含 `Nested` 列，且同时包含名称中带点、并与 `Nested` 具有相同前缀的标量列的表时出现的 `There is no subcolumn` 错误 (例如 `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`) 。[#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#28742](https://github.com/ClickHouse/ClickHouse/issues/28742) 中回移：修复了创建分布式表时，如果传入参数错误会导致 core dump 的问题。[#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* 已在 [#28788](https://github.com/ClickHouse/ClickHouse/issues/28788) 中回移：修复了 ReplicatedMergeTreeQueue 中一个无害的竞态条件。用户通常不会察觉到这个问题，但它可能引发一些隐蔽的缺陷。[#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* 已在 [#28947](https://github.com/ClickHouse/ClickHouse/issues/28947) 中回移：修复了从 compact parts 读取子列的问题。[#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#28931](https://github.com/ClickHouse/ClickHouse/issues/28931) 中回移：修复了高阶数组函数在处理常量时的问题 (`arrayCompact` 会触发 `SIGSEGV`，`arrayDifference` / `arrayCumSumNonNegative` 会触发 `ILLEGAL_COLUMN`) 。[#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
