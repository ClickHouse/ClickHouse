<div id="bug-fix">
  #### 缺陷修复
</div>

* 已回移至 [#23971](https://github.com/ClickHouse/ClickHouse/issues/23971)：修复了过时 `ReplicatedMergeTree` 副本在恢复过程中的一个 bug。如果在副本停机期间执行了 `ALTER` 查询，某些元数据更新可能会被过时副本忽略。[#23742](https://github.com/ClickHouse/ClickHouse/pull/23742) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已回移至 [#23819](https://github.com/ClickHouse/ClickHouse/issues/23819)：修复了在 `PREWHERE` 和行级 policy 过滤器同时生效且结果为空时发生崩溃的问题。[#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* 已回移至 [#23816](https://github.com/ClickHouse/ClickHouse/issues/23816)：修复了 `CLEAR COLUMN` 在被 materialized view 引用时无法生效的问题。关闭 [#23764](https://github.com/ClickHouse/ClickHouse/issues/23764)。[#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
* 已回移至 [#23831](https://github.com/ClickHouse/ClickHouse/issues/23831)：修复了带有 `GLOBAL IN/JOIN` 和 `use_hedged_requests` 的查询报错 `Can't initialize pipeline with empty pipe` 的问题。修复了 [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431)。[#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已回移至 [#23930](https://github.com/ClickHouse/ClickHouse/issues/23930)：修复了 HashedDictionary 复杂 key 更新字段的 initial load 问题。关闭 [#23800](https://github.com/ClickHouse/ClickHouse/issues/23800)。[#23824](https://github.com/ClickHouse/ClickHouse/pull/23824) ([Maksim Kita](https://github.com/kitaisreal)).
* 已回移至 [#23957](https://github.com/ClickHouse/ClickHouse/issues/23957)：修复了在 source 中存在重复项时，CACHE() 字典的 keys 指标统计问题 (会导致 `DictCacheKeysRequestedMiss` 溢出) 。[#23929](https://github.com/ClickHouse/ClickHouse/pull/23929) ([Azat Khuzhin](https://github.com/azat)).
* 已回移至 [#24003](https://github.com/ClickHouse/ClickHouse/issues/24003)：修复了 external GROUP BY 和 overflow 行导致的 SIGSEGV 问题 (即类似 `SELECT FROM GROUP BY WITH TOTALS SETTINGS max_bytes_before_external_group_by>0, max_rows_to_group_by>0, group_by_overflow_mode='any', totals_mode='before_having'` 的查询) 。[#23962](https://github.com/ClickHouse/ClickHouse/pull/23962) ([Azat Khuzhin](https://github.com/azat)).
* 已回移至 [#24188](https://github.com/ClickHouse/ClickHouse/issues/24188)：某些 `ALTER PARTITION` 查询可能会在复制队列中触发 `Part A intersects previous part B` 和 `Unexpected merged part C intersecting drop range D` 错误。现已修复。修复了 [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296)。[#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已回移至 [#24031](https://github.com/ClickHouse/ClickHouse/issues/24031)：修复了 MergeJoin 中的崩溃问题，关闭 [#24010](https://github.com/ClickHouse/ClickHouse/issues/24010)。[#24013](https://github.com/ClickHouse/ClickHouse/pull/24013) ([Vladimir C](https://github.com/vdimir)).
* 已回移至 [#24141](https://github.com/ClickHouse/ClickHouse/issues/24141)：Bug：对带有 `select xxx final` 的查询执行 explain pipeline 时，会显示错误的 pipeline：&#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* 已在 [#24171](https://github.com/ClickHouse/ClickHouse/issues/24171) 中回移：修复了一个罕见 bug。该问题可能导致表仅部分完成初始化，却仍可处理写请求 (insert/alter 等) 。现在，这类表将进入只读模式。[#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#24215](https://github.com/ClickHouse/ClickHouse/issues/24215) 中回移：修复了 RBAC 在高负载下可能出现的竞态条件。此 PR 修复了 [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090) 和 [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134)。[#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#24243](https://github.com/ClickHouse/ClickHouse/issues/24243) 中回移：修复了在查询执行期间 HDFS 不可访问时，server 异常终止的问题。关闭 [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117)。[#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
