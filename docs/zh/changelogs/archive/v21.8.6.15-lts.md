<div id="clickhouse-release-v218615-lts-fixme-as-compared-to-v21857-lts">
  ### ClickHouse 版本 v21.8.6.15-lts FIXME (相比 v21.8.5.7-lts)

<div id="improvement">
  #### 改进
</div>

* 已在 [#28899](https://github.com/ClickHouse/ClickHouse/issues/28899) 中回移：在垂直合并中使用真实的临时文件，而不是预定义的 &quot;rows&#95;sources&quot;。这样可以避免在 tmp 磁盘中生成无用的目录。[#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#28642](https://github.com/ClickHouse/ClickHouse/issues/28642) 中回移：修复 Keeper 中异常的会话过期逻辑。这可能有助于解决 CI 中的问题：[https://clickhouse-test-reports.s3.yandex.net/0/6bd9b82141c98dcd7796fd9d08326831095ba519/stress&#95;test&#95;(debug).html#fail1](https://clickhouse-test-reports.s3.yandex.net/0/6bd9b82141c98dcd7796fd9d08326831095ba519/stress_test_\(debug\).html#fail1)。[#28519](https://github.com/ClickHouse/ClickHouse/pull/28519) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#28718](https://github.com/ClickHouse/ClickHouse/issues/28718) 中回移：待补充。关闭 [#28529](https://github.com/ClickHouse/ClickHouse/issues/28529)。[#28614](https://github.com/ClickHouse/ClickHouse/pull/28614) ([Kseniia Sumarokova](https://github.com/kssenii)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#27923](https://github.com/ClickHouse/ClickHouse/issues/27923) 中回移：修复 PostgreSQL 风格类型转换 (`::` 运算符) 在处理负数时的问题。[#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#28753](https://github.com/ClickHouse/ClickHouse/issues/28753) 中回移：修复在设置 `legacy_column_name_of_tuple_literal = 0` 时，分布式查询中将析取链转换为 `IN` 的问题 (由设置 `optimize_min_equality_disjunction_chain_length` 控制) 。[#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)) 。

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#28644](https://github.com/ClickHouse/ClickHouse/issues/28644) 中回移：修复在极少数情况下，修改 `clickhouse-keeper` 配置可能导致日志丢失和服务器卡死的问题。[#28360](https://github.com/ClickHouse/ClickHouse/pull/28360) ([alesapin](https://github.com/alesapin)).
* 已在 [#28508](https://github.com/ClickHouse/ClickHouse/issues/28508) 中回移：修复 MaterializedPostgreSQL engine 中表名缺少引号的问题。关闭 [#28316](https://github.com/ClickHouse/ClickHouse/issues/28316)。[#28433](https://github.com/ClickHouse/ClickHouse/pull/28433) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#28510](https://github.com/ClickHouse/ClickHouse/issues/28510) 中回移：修复在后台处理分布式 DDL queue 时可能发生的 ZooKeeper watches 泄漏问题。关闭 [#26036](https://github.com/ClickHouse/ClickHouse/issues/26036)。[#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#28573](https://github.com/ClickHouse/ClickHouse/issues/28573) 中回移：修复对 `ReplicatedVersionedCollapsingMergeTree` 执行 alter 后，可能出现错误 `Existing table metadata in ZooKeeper differs in sorting key expression.` 的问题。修复 [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515)。[#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* 已在 [#28597](https://github.com/ClickHouse/ClickHouse/issues/28597) 中回移：修复从包含 `Nested` 列，以及名称中带点、且前缀与 `Nested` 相同的标量列的表中查询时，出现 `There is no subcolumn` 错误的问题 (例如 `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`) 。[#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#28714](https://github.com/ClickHouse/ClickHouse/issues/28714) 中回移：为 system.processes 表添加 Settings.Names 和 Settings.Values 别名。[#28685](https://github.com/ClickHouse/ClickHouse/pull/28685) ([Vitaly Orlov](https://github.com/orloffv)).
* 已在 [#28741](https://github.com/ClickHouse/ClickHouse/issues/28741) 中回移：修复创建分布式表时，传入错误参数会导致 coredump 的问题。[#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* 已在 [#28791](https://github.com/ClickHouse/ClickHouse/issues/28791) 中回移：修复 ReplicatedMergeTreeQueue 中一个无害的竞态条件。用户通常感知不到，但它可能导致一些隐蔽的问题。[#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* 已在 [#28994](https://github.com/ClickHouse/ClickHouse/issues/28994) 中回移：修复 `DROP PART` 与 `REPLACE/MOVE PARTITION` 之间的竞态条件，该问题在极少数情况下可能导致副本间出现不一致。[#28864](https://github.com/ClickHouse/ClickHouse/pull/28864) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#28948](https://github.com/ClickHouse/ClickHouse/issues/28948) 中回移：修复从 compact parts 中读取子列的问题。[#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#28930](https://github.com/ClickHouse/ClickHouse/issues/28930) 中回移：修复高阶 array functions 在常量参数场景下的问题 (`arrayCompact` 会触发 `SIGSEGV`，`arrayDifference` 和 `arrayCumSumNonNegative` 会触发 `ILLEGAL_COLUMN`) 。[#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
