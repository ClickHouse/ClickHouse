<div id="improvement">
  #### 改进
</div>

* 已在 [#41507](https://github.com/ClickHouse/ClickHouse/issues/41507) 中回移：修复了将设置 `do_no_evict_index_and_mark_files` 从 1 切换为 0，或从 0 切换为 1 后导致缓存不兼容的问题。[#41330](https://github.com/ClickHouse/ClickHouse/pull/41330) ([Kseniia Sumarokova](https://github.com/kssenii)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#41229](https://github.com/ClickHouse/ClickHouse/issues/41229) 中回移：修复了当参数使用元素类型为 Nullable 的 Array 时，函数 `encrypt` 和 `contingency` 存在的内存安全问题。此修复解决了 [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004)。[#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#41560](https://github.com/ClickHouse/ClickHouse/issues/41560) 中回移：为 deb 软件包添加 `source` 字段，并更新 `nfpm`。[#41531](https://github.com/ClickHouse/ClickHouse/pull/41531) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#41284](https://github.com/ClickHouse/ClickHouse/issues/41284) 中回移：修复 `WITH` 语句引入的未使用未知列问题。此修复解决了 [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812)。[#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#41837](https://github.com/ClickHouse/ClickHouse/issues/41837) 中回移：修复包含轻量级删除行的 parts 的垂直合并问题。[#40559](https://github.com/ClickHouse/ClickHouse/pull/40559) ([Alexander Gololobov](https://github.com/davenger))。
* 已在 [#41618](https://github.com/ClickHouse/ClickHouse/issues/41618) 中回移：修复聚合函数组合器中可能出现的 segfault、释放后继续使用堆内存和内存泄漏问题。关闭 [#40848](https://github.com/ClickHouse/ClickHouse/issues/40848)。[#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar))。
* 已在 [#41667](https://github.com/ClickHouse/ClickHouse/issues/41667) 中回移：修复了这样一种问题：当子查询中带有 `OFFSET` 子句，且外层查询中带有 `WHERE` 子句时，查询可能返回错误结果。修复了 [#40416](https://github.com/ClickHouse/ClickHouse/issues/40416)。[#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#41685](https://github.com/ClickHouse/ClickHouse/issues/41685) 中回移：修复启用 `query_plan_optimize_primary_key` 时，查询结果可能错误的问题。修复了 [#40599](https://github.com/ClickHouse/ClickHouse/issues/40599)。[#41281](https://github.com/ClickHouse/ClickHouse/pull/41281) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#41362](https://github.com/ClickHouse/ClickHouse/issues/41362) 中回移：修复对象存储 disk 中误报的逻辑错误 `Expected relative path`。与 [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246) 相关。[#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 已在 [#41359](https://github.com/ClickHouse/ClickHouse/issues/41359) 中回移：在 MsgPack 格式中插入 UUID 前增加列类型检查。[#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar))。
* 已在 [#41596](https://github.com/ClickHouse/ClickHouse/issues/41596) 中回移：修复 async&#95;socket&#95;for&#95;remote/use&#95;hedged&#95;requests 与并行执行 KILL 时可能发生的死锁问题。[#41343](https://github.com/ClickHouse/ClickHouse/pull/41343) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#41521](https://github.com/ClickHouse/ClickHouse/issues/41521) 中回移：自 22.8 起，如果数据库为 `Replicated`，且集群名称与数据库名称相同，则会忽略 `ON CLUSTER` 子句。因此，`DROP PARTITION ON CLUSTER` 与 `Replicated` 配合使用时会出现异常行为。现已修复；现在仅对在数据库级别复制的查询忽略 `ON CLUSTER` 子句。修复了 [#41299](https://github.com/ClickHouse/ClickHouse/issues/41299)。[#41390](https://github.com/ClickHouse/ClickHouse/pull/41390) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#41480](https://github.com/ClickHouse/ClickHouse/issues/41480) 中回移：Native 格式中的恶意数据可能导致崩溃。[#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#41806](https://github.com/ClickHouse/ClickHouse/issues/41806) 中回移：聚合函数 `categorialInformationValue` 的属性定义不正确，可能导致运行时发生空指针解引用。此项关闭了 [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443)。[#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#41506](https://github.com/ClickHouse/ClickHouse/issues/41506) 中回移：以 Apache `ORC` 格式写入数据可能会导致缓冲区越界。[#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#41581](https://github.com/ClickHouse/ClickHouse/issues/41581) 中回移：修复查询取消 (`KILL QUERY` 或 server 关闭) 时可能发生的挂起/死锁问题。[#41467](https://github.com/ClickHouse/ClickHouse/pull/41467) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#41645](https://github.com/ClickHouse/ClickHouse/issues/41645) 中回移：带有 `ORDER BY` 且 `1500 <= LIMIT <= max_block_size` 的查询可能返回错误结果，前部会缺少部分行。修复了 [#41182](https://github.com/ClickHouse/ClickHouse/issues/41182)。[#41576](https://github.com/ClickHouse/ClickHouse/pull/41576) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#41642](https://github.com/ClickHouse/ClickHouse/issues/41642) 中回移：修复带有 `OFFSET` 的查询可能出现的 `pipeline stuck` 异常。该错误是在 `enable_optimize_predicate_expression = 0` 且 `WHERE` 中条件恒为 false 时发现的。修复了 [#41383](https://github.com/ClickHouse/ClickHouse/issues/41383)。[#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#41901](https://github.com/ClickHouse/ClickHouse/issues/41901) 中回移：修复在 `Merge` 表上执行 `SELECT` 且启用 `optimize_monotonous_functions_in_order_by` 设置时可能发生的崩溃。修复了 [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269)。[#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#41836](https://github.com/ClickHouse/ClickHouse/issues/41836) 中回移：不再允许创建或修改 merge tree 表时使用虚拟列名 &#95;row&#95;exists，因为该名称已为轻量级删除保留。修复了 [#41716](https://github.com/ClickHouse/ClickHouse/issues/41716)。[#41763](https://github.com/ClickHouse/ClickHouse/pull/41763) ([Jianmei Zhang](https://github.com/zhangjmruc)) 。
* 已在 [#41890](https://github.com/ClickHouse/ClickHouse/issues/41890) 中回移：旧版本的 Replicated database 在 [Zoo]Keeper 中没有特殊标记。我们只需要检查该节点是否包含某些不明数据，而不是检查特殊标记。[#41875](https://github.com/ClickHouse/ClickHouse/pull/41875) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
