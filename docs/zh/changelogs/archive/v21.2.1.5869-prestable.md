<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* * 修复 `OPTIMIZE TABLE`/merges 的内存跟踪问题——将查询内存限制和采样纳入 `OPTIMIZE TABLE`/merges 的处理。 [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* 禁止将 `lcm`/`gcd` 用于 Float。 [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* 禁止将按位函数 (`bitAnd`、`bitOr` 等) 用于浮点参数。现在必须先显式转换为整数。 [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 新特性
</div>

* 新增对 zstd long 选项的支持，可更有效地压缩 String 类型列以节省空间。[#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)) 。
* * 新增支持将 LDAP 组名以及各类 attribute 值映射为来自 ldap user directories 的用户的本地角色。[#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)) 。
* `Nested` Data type 现在支持任意层级的嵌套。新增了复杂类型的 subcolumns，例如 `Array` 中的 `size0`、`Nullable` 中的 `null` 以及 `Tuple` 元素名称，这些都无需读取整列即可单独读取。 [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* 为 `argMin` 和 `argMax` 函数添加了对 tuple 参数的支持。 [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 为 `FlatDictionary`、`HashedDictionary`、`ComplexKeyHashedDictionary`、`DirectDictionary`、`ComplexKeyDirectDictionary`、`RangeHashedDictionary` 增加了 `Nullable` 支持。 [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* 禁止将浮点列用作分区键，相关问题见： [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255。 [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* 添加函数 decodeXMLComponent，用于解码 XML 字符。`SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* 新增 PostgreSQL table engine (支持 select/insert，并支持多维数组) ，同时也可作为 table function 使用。新增 PostgreSQL 字典源。新增 PostgreSQL database engine。 [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 添加 `SELECT ALL` 语法。关闭 [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706)。 [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* 为 map 数据类型添加了三个函数：1. mapContains(map, key)，用于检查 map.keys 是否包含第二个参数 key。2. mapKeys(map)，以 Array 形式返回所有 key。3. mapValues(map)，以 Array 形式返回所有值。 [#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* 在 play UI 中支持 MetaKey+Enter 快捷键绑定。 [#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* 函数 formatDateTime 支持 `%Q` 修饰符，可将日期格式化为季度。 ... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* ... [#19261](https://github.com/ClickHouse/ClickHouse/pull/19261) ([RegulusZ](https://github.com/RegulusZ)).
* 将查询期间创建的 factories&#39; 对象名称添加到 system.query&#95;log 中。关闭 [#18495](https://github.com/ClickHouse/ClickHouse/issues/18495)。 [#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 添加 `sign` 数学函数。 [#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).
* 新增函数 `parseDateTimeBestEffortUSOrZero`、`parseDateTimeBestEffortUSOrNull`。 [#19712](https://github.com/ClickHouse/ClickHouse/pull/19712) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#19764](https://github.com/ClickHouse/ClickHouse/pull/19764) ([emhlbmc](https://github.com/emhlbmc)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 为 S3 连接使用连接池，由 `s3_max_connections` 设置控制。[#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 在逻辑等价时，将 `sumIf()` 和 `sum(if())` 函数重写为 `countIf()` 函数。[#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* 更新 libcxx，并使用不稳定 ABI 以提升性能。[#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* 通过减少 `stat` 系统调用的次数来加快 parts 的删除速度。这恢复了之前曾有过的优化。`IDisk` 的接口也更安全了。此更改关闭了 [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065)。[#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 提升聚合函数 `sum` 的执行速度。该改进仅在合成基准测试中可见，实际意义不大。[#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 支持将查询计划中的 `Filter` 步骤拆分为 `Expression + Filter` 对。结合 `Expression + Expression` 合并优化 ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)) ，可将某些表达式的执行推迟到 `Filter` 步骤之后。[#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 减少 Buffer 引擎多层场景下的锁竞争。[#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* 通过移除每次建立连接时对配置的访问，略微降低服务器延迟。[#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
