  # 2022 更新日志

<div id="clickhouse-release-v215225-prestable-fixme-as-compared-to-v21516601-prestable">
  ### ClickHouse 发布 v21.5.2.25-prestable FIXME，对比 v21.5.1.6601-prestable
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#23342](https://github.com/ClickHouse/ClickHouse/issues/23342) 中回移：禁用设置 `use_hedged_requests` 和 `async_socket_for_remote`，因为已有证据表明它们可能会引发问题。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#23678](https://github.com/ClickHouse/ClickHouse/issues/23678) 中回移：修复了 `quantile(s)TDigest`。按照 tdunning/t-digest 3.2+，增加了对单例质心的特殊处理。同时，还修复了该算法早期版本实现中质心过度压缩的问题。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#23343](https://github.com/ClickHouse/ClickHouse/issues/23343) 中回移：此 PR 修复了关闭期间发生的崩溃问题，原因是当某些连接仍然存活时，currentConnections() 可能返回零。[#23154](https://github.com/ClickHouse/ClickHouse/pull/23154) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#23405](https://github.com/ClickHouse/ClickHouse/issues/23405) 中回移：如果 subquery 被优化为常量，QueryAliasVisitor 会优先为 ASTWithAlias 使用 alias。修复了 [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924)。修复了 [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401)。[#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#23383](https://github.com/ClickHouse/ClickHouse/issues/23383) 中回移：修复了从 `MaterializeMySQL` 中 select 数据时，按 Key column 添加 condition 会报 `Not found column` error 的问题。修复了 [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432)。[#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23386](https://github.com/ClickHouse/ClickHouse/issues/23386) 中回移：修复了禁用 `input_format_with_names_use_header ` setting 后会丢弃 CSVWithNames format 全部输入数据的问题。此修复解决了 [#22406](https://github.com/ClickHouse/ClickHouse/issues/22406)。[#23202](https://github.com/ClickHouse/ClickHouse/pull/23202) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#23340](https://github.com/ClickHouse/ClickHouse/issues/23340) 中回移：为 optimize&#95;skip&#95;unused&#95;shards&#95;rewrite&#95;in 添加类型转换 (修复了 `optimize_skip_unused_shards_rewrite_in` 中的 `use-of-uninitialized-value`) 。[#23219](https://github.com/ClickHouse/ClickHouse/pull/23219) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#23341](https://github.com/ClickHouse/ClickHouse/issues/23341) 中回移：修复了当主键不是第一个 attribute 时，simple key 字典无法通过 DDL 创建的问题。修复了 [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236)。[#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#23449](https://github.com/ClickHouse/ClickHouse/issues/23449) 中回移：修复了在创建和删除 ReplicatedMergeTree 表时极少发生的 (分布式) 竞态条件。该问题可能会在尝试创建 replicated table 时导致出现 `node doesn't exist` 之类的异常。修复了 [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419)。[#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23578](https://github.com/ClickHouse/ClickHouse/issues/23578) 中回移：修复了在后台清理旧块时极少发生的竞态条件。如果某个块距离去重窗口末尾过近，可能会导致该块未被去重。[#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23427](https://github.com/ClickHouse/ClickHouse/issues/23427) 中回移：修复了在收到来自 remote query 的 `unknown packet` 时可能发生的崩溃 (启用 `async_socket_for_remote` 时) 。可能修复了 [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167)。[#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#23675](https://github.com/ClickHouse/ClickHouse/issues/23675) 中回移：在分区裁剪期间不要放宽 NOT 条件。此修复解决了 [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) 和 [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539)。[#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#23581](https://github.com/ClickHouse/ClickHouse/issues/23581) 中回移：* 修复了 `join_algorithm = 'auto'` 时 dict join 中的 bug。关闭 [#23002](https://github.com/ClickHouse/ClickHouse/issues/23002)。[#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#23428](https://github.com/ClickHouse/ClickHouse/issues/23428) 中回移：修复了带有 `UNION` 的查询可能出现 `Block structure mismatch` 错误的问题，这种情况可能发生在过滤下推优化之后。修复了 [#23029](https://github.com/ClickHouse/ClickHouse/issues/23029)。[#23359](https://github.com/ClickHouse/ClickHouse/pull/23359) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#23642](https://github.com/ClickHouse/ClickHouse/issues/23642) 中回移：修复了基于虚拟列进行分区裁剪时生成不兼容常量表达式的问题。此修复解决了 [https://github.com/ClickHouse/ClickHouse/pull/21401#discussion&#95;r611888913](https://github.com/ClickHouse/ClickHouse/pull/21401#discussion_r611888913)。[#23366](https://github.com/ClickHouse/ClickHouse/pull/23366) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#23453](https://github.com/ClickHouse/ClickHouse/issues/23453) 中回移：如果某列位于主键中 (或是其单调函数) ，且未关闭设置 `optimize_read_in_order`，则带有 `COLLATE` 的 `ORDER BY` 无法正常工作。此项关闭了 [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379)。旧版本的临时解决方法：关闭设置 `optimize_read_in_order`。[#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#23510](https://github.com/ClickHouse/ClickHouse/issues/23510) 中回移：移除了对单个 `Tuple` 参数的 `argMin` 和 `argMax` 的支持。相关代码不满足内存安全要求。该功能是误加的，也容易让用户困惑。后续可以用其他名称重新引入这些函数。此修复解决了 [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) 并回退了 [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359)。[#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

* 已在 [#23477](https://github.com/ClickHouse/ClickHouse/issues/23477) 中回移：Kafka 存储现在支持 `arrow` 和 `arrowstream` 格式的消息。[#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)) 。
* 已在 [#23587](https://github.com/ClickHouse/ClickHouse/issues/23587) 中回移：修复了使用多磁盘配置创建 ReplicatedMergeTree 表失败时出现的 `Cannot unlink file` 错误。此项关闭了 [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755)。[#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
