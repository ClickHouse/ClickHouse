<div id="new-feature">
  #### 新特性
</div>

* 已在 [#40868](https://github.com/ClickHouse/ClickHouse/issues/40868) 中回移：新增设置，可取消 `kafka_num_consumers` 的限制。关闭 [#40331](https://github.com/ClickHouse/ClickHouse/issues/40331)。[#40670](https://github.com/ClickHouse/ClickHouse/pull/40670) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#41274](https://github.com/ClickHouse/ClickHouse/issues/41274) 中回移：修复了在将 Array of Nullable 用作参数时，函数 `encrypt` 和 `contingency` 的内存安全问题。此修复解决了 [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004)。[#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定发行版中用户可见的异常行为)
</div>

* 已在 [#41282](https://github.com/ClickHouse/ClickHouse/issues/41282) 中回移：修复由 WITH 语句引入的未使用未知列问题。此修复解决了 [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812)。[#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#40905](https://github.com/ClickHouse/ClickHouse/issues/40905) 中回移：修复 `WriteBufferFromS3` 在任务调度失败期间可能发生的死锁问题。[#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal))。
* 已在 [#40864](https://github.com/ClickHouse/ClickHouse/issues/40864) 中回移：- 修复解析包含可变维数组的 `Object` 类型值时发生的崩溃问题。[#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94))。
* 已在 [#40803](https://github.com/ClickHouse/ClickHouse/issues/40803) 中回移：向 `ProcessList` 插入新查询时会发生内存分配。如果在这些分配过程中达到内存限制，则无法使用 `OvercommitTracker`，因为此时已经获取了 `ProcessList::mutex`。修复了 [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)。[#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd))。
* 已在 [#40891](https://github.com/ClickHouse/ClickHouse/issues/40891) 中回移：修复在没有查询上下文时向 MV 推送数据 (来自 Kafka/...) 导致的内存泄漏问题。[#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#41133](https://github.com/ClickHouse/ClickHouse/issues/41133) 中回移：修复 `DESCRIBE TABLE url()` 和其他一些 `DESCRIBE TABLE <table_function>()` 的访问权限问题。[#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar))。
* 已在 [#41360](https://github.com/ClickHouse/ClickHouse/issues/41360) 中回移：修复对象存储磁盘中不正确的逻辑错误 `Expected relative path`。与 [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246) 相关。[#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 已在 [#41357](https://github.com/ClickHouse/ClickHouse/issues/41357) 中回移：在 MsgPack format 中执行 UUID 插入前增加列类型检查。[#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar))。
