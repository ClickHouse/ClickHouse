<div id="new-feature">
  #### 新特性
</div>

* 新增将自定义 setting 重置为 default 并从表的 metadata 中移除的功能。这样无需知道 system/config 的默认值，也能回滚这项变更。关闭 [#14449](https://github.com/ClickHouse/ClickHouse/issues/14449)。[#17769](https://github.com/ClickHouse/ClickHouse/pull/17769) ([xjewer](https://github.com/xjewer)).
* 新增 MaterializedPostgreSQL 表引擎和 database engine。database engine 支持复制整个 database，或 database 中任意子集的表。[#20470](https://github.com/ClickHouse/ClickHouse/pull/20470) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 新增对部分 SQLJSON 标准的支持。[#24148](https://github.com/ClickHouse/ClickHouse/pull/24148) ([l1tsolaiki](https://github.com/l1tsolaiki)).
* 收集常见系统指标 (记录在 `system.asynchronous_metrics` 和 `system.asynchronous_metric_log` 中) ，包括 CPU usage、Disk usage、memory usage、IO、网络、文件、平均负载、CPU 频率、热传感器、EDAC 计数器、系统运行时间；同时还新增了关于 scheduling 抖动以及收集这些指标所耗时间的指标。它在 ClickHouse 中的作用类似于 `atop`，即使未安装额外工具，也能获取 Monitoring 数据。关闭 [#9430](https://github.com/ClickHouse/ClickHouse/issues/9430)。[#24416](https://github.com/ClickHouse/ClickHouse/pull/24416) ([Yegor Levankov](https://github.com/elevankoff)).
* 新增对 `DISTINCT ON (columns)` expression 的支持，关闭 [#25404](https://github.com/ClickHouse/ClickHouse/issues/25404)。[#25589](https://github.com/ClickHouse/ClickHouse/pull/25589) ([Zijie Lu](https://github.com/TszKitLo40)).
* * 在 `mapAdd` 和 `mapSubtract` functions 中支持 Map type * 在 `mapAdd` 和 `mapSubtract` functions 中支持 (U)Int128、U(Int256) types。[#25596](https://github.com/ClickHouse/ClickHouse/pull/25596) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 新增对 bin/unbin functions 的支持。[#25609](https://github.com/ClickHouse/ClickHouse/pull/25609) ([zhaoyu](https://github.com/zxc111)).
* 引入 `system.data_skipping_indices` 表，用于包含现有 data skipping indices 的信息。关闭 [#7659](https://github.com/ClickHouse/ClickHouse/issues/7659)。[#25693](https://github.com/ClickHouse/ClickHouse/pull/25693) ([Dmitry Novik](https://github.com/novikd)).
* 在 [https://github.com/ClickHouse/ClickHouse/pull/12073](https://github.com/ClickHouse/ClickHouse/pull/12073) 的基础上，为 ADD INDEX 命令新增 FIRST keyword，从而可以在 indices 列表的开头添加索引。[#25904](https://github.com/ClickHouse/ClickHouse/pull/25904) ([xjewer](https://github.com/xjewer)).
* 当给出 `EXPLAIN PIPELINE graph = 1` 查询时，在 Web UI 中将 pipelines 渲染为 graph。[#26067](https://github.com/ClickHouse/ClickHouse/pull/26067) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新增 functions `leftPad()`, `rightPad()`, `leftPadUTF8()`, `rightPadUTF8()`。[#26075](https://github.com/ClickHouse/ClickHouse/pull/26075) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 当 `compile_aggregate_expressions` 设置启用时，新增了编译聚合函数的选项。[#24789](https://github.com/ClickHouse/ClickHouse/pull/24789) ([Maksim Kita](https://github.com/kitaisreal)) 。

<div id="improvement">
  #### 改进
</div>

* `StorageMerge` 的 `Database` 参数现支持正则表达式。此更改关闭了 #776。[#25064](https://github.com/ClickHouse/ClickHouse/pull/25064) ([flynn](https://github.com/ucasfl)).
* 允许使用 JSONExtract 将非字符串元素提取为字符串。此更改用于解决 [#25414](https://github.com/ClickHouse/ClickHouse/issues/25414)。[#25452](https://github.com/ClickHouse/ClickHouse/pull/25452) ([Amos Bird](https://github.com/amosbird)).
* 支持动态重载配置，以调整后台作业执行池中的线程数 (合并、变更、拉取) 。[#25548](https://github.com/ClickHouse/ClickHouse/pull/25548) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 为 StorageS3 和 StorageHDFS 增加 `TRUNCATE TABLE` 支持。关闭了 [#25530](https://github.com/ClickHouse/ClickHouse/issues/25530)。[#25550](https://github.com/ClickHouse/ClickHouse/pull/25550) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 使 `NetworkReceiveElapsedMicroseconds` 指标能够正确计入等待客户端发送 INSERT 数据所花费的时间。此更改关闭了 [#9958](https://github.com/ClickHouse/ClickHouse/issues/9958)。[#25602](https://github.com/ClickHouse/ClickHouse/pull/25602) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了 `ALTER TABLE ... DETACH` 与后台合并之间可能出现的逻辑竞态条件。[#25605](https://github.com/ClickHouse/ClickHouse/pull/25605) ([Azat Khuzhin](https://github.com/azat)).
* 在 JOIN 中支持 materialized 列和别名列，关闭了 [#13274](https://github.com/ClickHouse/ClickHouse/issues/13274)。[#25634](https://github.com/ClickHouse/ClickHouse/pull/25634) ([Vladimir C](https://github.com/vdimir)).
* MaterializeMySQL 现已支持 `ENUM` 数据类型。[#25676](https://github.com/ClickHouse/ClickHouse/pull/25676) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* 在 `ReplicatedMergeTree` 中，对 `DROP PARTITION` 和 `TRUNCATE` 操作会取消该分区上已在运行的合并。解决了 [#17151](https://github.com/ClickHouse/ClickHouse/issues/17151)。[#25684](https://github.com/ClickHouse/ClickHouse/pull/25684) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 在系统日志表 (`system.query_log`、`system.query_thread_log`、`system.processes`、`system.opentelemetry_span_log`) 中，对键值字典使用 `Map` 数据类型。为兼容旧查询，创建了虚拟列。关闭了 [#18698](https://github.com/ClickHouse/ClickHouse/issues/18698)。作者 @hexiaoting、@sundy-li。[#25773](https://github.com/ClickHouse/ClickHouse/pull/25773) ([Maksim Kita](https://github.com/kitaisreal)).
* 修复了空集上 GROUP BY 常量行为不一致的问题。关闭了 [#6842](https://github.com/ClickHouse/ClickHouse/issues/6842)。[#25786](https://github.com/ClickHouse/ClickHouse/pull/25786) ([Kseniia Sumarokova](https://github.com/kssenii)).
* MySQL Engine 现已支持在 MySQL 和 ClickHouse 之间同步列注释。[#25795](https://github.com/ClickHouse/ClickHouse/pull/25795) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* 修复了 Merge() 存储的 &quot;No available columns&quot; 问题。[#25801](https://github.com/ClickHouse/ClickHouse/pull/25801) ([Azat Khuzhin](https://github.com/azat)).
* 允许在工作目录不可读的情况下启动 ClickHouse 客户端。[#25817](https://github.com/ClickHouse/ClickHouse/pull/25817) ([ianton-ru](https://github.com/ianton-ru)).
* 改进了 ReplicatedMergeTree 表对 lost parts 的处理，修复了 ReplicationQueue 中极少发生的不一致问题。用户对此不应有任何可见感知。修复了 [#10368](https://github.com/ClickHouse/ClickHouse/issues/10368)。[#25820](https://github.com/ClickHouse/ClickHouse/pull/25820) ([alesapin](https://github.com/alesapin)) 。
* 修复了一个极其罕见的 bug，该 bug 可能会在执行 `DROP PART` 或后台删除空 part 后导致出现 intersecting parts。[#25884](https://github.com/ClickHouse/ClickHouse/pull/25884) ([alesapin](https://github.com/alesapin)) 。
* 将 history 文件从 readline 格式转换为 replxx 格式。[#25888](https://github.com/ClickHouse/ClickHouse/pull/25888) ([Azat Khuzhin](https://github.com/azat)) 。
* 为 JSON extract 增加了对 LowCardinality、Decimal 和 UUID 的支持。关闭了 [#24606](https://github.com/ClickHouse/ClickHouse/issues/24606)。[#25900](https://github.com/ClickHouse/ClickHouse/pull/25900) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 增加了对列名为 `"null"` 的查询 (必须使用反引号或双引号指定) 的支持，以及对 ON CLUSTER 的支持。此更改关闭了 [#24035](https://github.com/ClickHouse/ClickHouse/issues/24035)。[#25907](https://github.com/ClickHouse/ClickHouse/pull/25907) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 现在在尝试 parse 无效的 Date 时会正确抛出异常。此更改关闭了 [#6481](https://github.com/ClickHouse/ClickHouse/issues/6481)。[#25909](https://github.com/ClickHouse/ClickHouse/pull/25909) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 允许参数化聚合函数的 parameters 使用任意常量 expression (例如 `1 + 2`) ，而不只是 literals。这也允许将 query parameters (在参数化查询中，如 `{param:UInt8}`) 用作参数化聚合函数的 parameters。此更改关闭了 [#11607](https://github.com/ClickHouse/ClickHouse/issues/11607)。[#25910](https://github.com/ClickHouse/ClickHouse/pull/25910) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 允许 `quantiles*` functions 与 `aggregate_functions_null_for_empty` 配合使用。此更改关闭了 [#25892](https://github.com/ClickHouse/ClickHouse/issues/25892)。[#25919](https://github.com/ClickHouse/ClickHouse/pull/25919) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 使 `sudo service clickhouse-server start` 能够在带有 `systemd` 的系统 (如 Centos 8) 上正常工作。此更改关闭了 [#14298](https://github.com/ClickHouse/ClickHouse/issues/14298)。此更改关闭了 [#17799](https://github.com/ClickHouse/ClickHouse/issues/17799)。[#25921](https://github.com/ClickHouse/ClickHouse/pull/25921) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 为 `Nested` data types 中的 Unicode (例如中文、西里尔文) components 增加了支持。此更改关闭了 [#25594](https://github.com/ClickHouse/ClickHouse/issues/25594)。[#25923](https://github.com/ClickHouse/ClickHouse/pull/25923) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 允许对 JOIN 后的表使用复杂的带引号标识符。此更改关闭了 [#17861](https://github.com/ClickHouse/ClickHouse/issues/17861)。[#25924](https://github.com/ClickHouse/ClickHouse/pull/25924) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 新增设置 `optimize_move_to_prewhere_if_final`。如果查询包含 `FINAL`，则仅当 `optimize_move_to_prewhere` 和 `optimize_move_to_prewhere_if_final` 均已启用时，才会启用 `move_to_prewhere` 优化。关闭了 [#8684](https://github.com/ClickHouse/ClickHouse/issues/8684)。[#25940](https://github.com/ClickHouse/ClickHouse/pull/25940) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 为网络交互添加更多插桩：为 recv/send 字节新增计数器；为 recvs/sends 新增 Gauge。补充了缺失的文档。这关闭了 [#5897](https://github.com/ClickHouse/ClickHouse/issues/5897)。[#25962](https://github.com/ClickHouse/ClickHouse/pull/25962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Web UI：如果值看起来像 URL，则自动生成链接。[#25965](https://github.com/ClickHouse/ClickHouse/pull/25965) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了 mysql 协议中执行查询 `SET SQL_SELECT_LIMIT` 时的错误。关闭了 [#17115](https://github.com/ClickHouse/ClickHouse/issues/17115)。[#25972](https://github.com/ClickHouse/ClickHouse/pull/25972) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 为 `empty` 和 `notEmpty` 函数添加了对 `UUID` 类型参数的支持。若 `UUID` 全为零 (nil UUID) ，则视为空。这关闭了 [#3446](https://github.com/ClickHouse/ClickHouse/issues/3446)。[#25974](https://github.com/ClickHouse/ClickHouse/pull/25974) ([zhaoyu](https://github.com/zxc111)).
* 为 bin 和 hex 函数添加了对 AggregateFunction 类型参数的支持。[#26094](https://github.com/ClickHouse/ClickHouse/pull/26094) ([zhaoyu](https://github.com/zxc111)).
* 对于具有复杂键的字典，如果复杂键仅包含一个属性，则允许在 `dictGet`、`dictHas` 函数中不将键表达式包裹在 `tuple` 中。[#26130](https://github.com/ClickHouse/ClickHouse/pull/26130) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 从 `Date` 到 `DateTime` (或 `DateTime64`) 的 `CAST` 过去不会使用 `DateTime` 类型的时区。这也会影响 `Date` 与 `DateTime` 之间的比较。推断 `Date` 和 `DateTime` 的公共类型时，同样未使用对应的时区。这会影响函数 `if` 和数组构造的结果。关闭了 [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
