* 已在 [#76214](https://github.com/ClickHouse/ClickHouse/issues/76214) 中回移：`clickhouse-library-bridge` 允许从 filesystem 打开任意库，因此只有在隔离环境中运行才安全。为防止其与 clickhouse-server 运行在同一环境中时产生漏洞，我们将把库的 path 限制为 configuration 中指定的位置。该漏洞由 **Arseniy Dugin** 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
