<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#76700](https://github.com/ClickHouse/ClickHouse/issues/76700) 中回移：修复了在优化器将 join 两侧对调时，`ConcurrentHashJoin` 中发生重复预分配的问题。[#75149](https://github.com/ClickHouse/ClickHouse/pull/75149) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已在 [#76696](https://github.com/ClickHouse/ClickHouse/issues/76696) 中回移：修复了当 `max_rows_in_join = max_bytes_in_join = 0` 时，`parallel_hash` 中不必要的竞争问题。[#75155](https://github.com/ClickHouse/ClickHouse/pull/75155) ([Nikita Taranov](https://github.com/nickitat)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#76437](https://github.com/ClickHouse/ClickHouse/issues/76437) 中回移：允许在 `postgresql` 或 `mysql` 表函数中解析 `localhost:1234/handle` 这类端点。这修复了 [https://github.com/ClickHouse/ClickHouse/pull/52503](https://github.com/ClickHouse/ClickHouse/pull/52503) 中引入的回归问题。[#75944](https://github.com/ClickHouse/ClickHouse/pull/75944) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#76609](https://github.com/ClickHouse/ClickHouse/issues/76609) 中回移：当备份期间向 S3 执行多分片复制因 Access Denied 失败时，使用正确的回退机制。在使用不同凭据的存储桶之间执行备份时，多分片复制可能会产生 Access Denied 错误。[#76515](https://github.com/ClickHouse/ClickHouse/pull/76515) ([Antonio Andelic](https://github.com/antonio2368)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#76142](https://github.com/ClickHouse/ClickHouse/issues/76142) 中回移：修复了 `forwarded_for` 字段中的某些 IPv6 地址 (如 `::ffff:1.1.1.1`) 被错误解析的问题，该问题会导致客户端因异常而断开连接。[#75133](https://github.com/ClickHouse/ClickHouse/pull/75133) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#76395](https://github.com/ClickHouse/ClickHouse/issues/76395) 中回移：确保在为 NumRowsCache 统计 total&#95;number&#95;of&#95;rows 时不会指定 key&#95;condition。[#75164](https://github.com/ClickHouse/ClickHouse/pull/75164) ([Daniil Ivanik](https://github.com/divanik)).
* 已在 [#76529](https://github.com/ClickHouse/ClickHouse/issues/76529) 中回移：当 materialized view 写入 URL engine 且出现连接问题时，遵循 `materialized_views_ignore_errors` 设置。[#75679](https://github.com/ClickHouse/ClickHouse/pull/75679) ([Christoph Wurm](https://github.com/cwurm)).
* 已在 [#76540](https://github.com/ClickHouse/ClickHouse/issues/76540) 中回移：修复了某些包含 `UNION ALL` 的查询出现 `Block structure mismatch in QueryPipeline stream` 错误的问题。[#75715](https://github.com/ClickHouse/ClickHouse/pull/75715) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#76475](https://github.com/ClickHouse/ClickHouse/issues/76475) 中回移：修复了错误的权限检查问题，此前 `ALTER RENAME` 需要 `CREATE USER` 权限。关闭 [#74372](https://github.com/ClickHouse/ClickHouse/issues/74372)。[#76241](https://github.com/ClickHouse/ClickHouse/pull/76241) ([pufit](https://github.com/pufit)).
* 已在 [#76403](https://github.com/ClickHouse/ClickHouse/issues/76403) 中回移：修复了当 `WHERE` 条件中包含 `pointInPolygon` 函数时，索引分析中出现的逻辑错误。[#76360](https://github.com/ClickHouse/ClickHouse/pull/76360) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#76484](https://github.com/ClickHouse/ClickHouse/issues/76484) 中回移：移除了信号处理程序中的内存分配。[#76446](https://github.com/ClickHouse/ClickHouse/pull/76446) ([Nikita Taranov](https://github.com/nickitat)).
