<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#32254](https://github.com/ClickHouse/ClickHouse/issues/32254) 中回移：修复写入 protobuf 时跳过列的问题。此 PR 修复了 [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)，参见评论 [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318。[#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#32345](https://github.com/ClickHouse/ClickHouse/issues/32345) 中回移：修复在子查询中删除不需要的列时出现的问题。如果查询中存在不带 GROUP BY 的聚合函数，即使它看起来不需要，也不要将其删除。[#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#32152](https://github.com/ClickHouse/ClickHouse/issues/32152) 中回移：修复当带类型的函数 `dictGet` 用于字典属性且类型为 `Nullable` 时发生崩溃的问题。修复了 [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#32298](https://github.com/ClickHouse/ClickHouse/issues/32298) 中回移：修复递归用户自定义函数导致崩溃的问题。关闭 [#30856](https://github.com/ClickHouse/ClickHouse/issues/30856)。[#31820](https://github.com/ClickHouse/ClickHouse/pull/31820) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#32148](https://github.com/ClickHouse/ClickHouse/issues/32148) 中回移：修复 detach 分片时出现 `Directory ... already exists and is not empty` 错误的问题。[#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32212](https://github.com/ClickHouse/ClickHouse/issues/32212) 中回移：修复在启用 `cast_keep_nullable` 时从 `Nullable` 执行 `CAST` 的问题 (此前例如 `toUInt32OrDefault(toNullable(toUInt32(1)))` 会报 `PARAMETER_OUT_OF_BOUND` 错误) 。[#32080](https://github.com/ClickHouse/ClickHouse/pull/32080) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#32283](https://github.com/ClickHouse/ClickHouse/issues/32283) 中回移：修复字典在自定义数据库查询中 `{condition}` 不生效的情况。[#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#32482](https://github.com/ClickHouse/ClickHouse/issues/32482) 中回移：修复 `APPLY lambda` 的解析问题，该问题可能导致客户端/服务端崩溃。[#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#32217](https://github.com/ClickHouse/ClickHouse/issues/32217) 中回移：使用 quorum 插入数据时，如果某些副本上禁用了设置 `replicated_can_become_leader`，活跃副本数量可能会被错误判断。现已修复。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32311](https://github.com/ClickHouse/ClickHouse/issues/32311) 中回移：升级到较新版本时，用于表 CREATE 查询的 XML 字典标识符可能会被限定为 `default_database`。关闭 [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)。[#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#32354](https://github.com/ClickHouse/ClickHouse/issues/32354) 中回移：修复聚合函数 `avgWeighted` 在参数为 `Decimal` 时出现 SIGFPE 崩溃的问题。修复了 [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)。[#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32392](https://github.com/ClickHouse/ClickHouse/issues/32392) 中回移：修复默认表达式的数据类型与列的数据类型不一致时的 `ALTER ... MATERIALIZE COLUMN ...` 查询问题。[#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#32418](https://github.com/ClickHouse/ClickHouse/issues/32418) 中回移：修复无事可做的变更操作卡住的问题 (在启用设置 `empty_result_for_aggregation_by_empty_set` 时) 。[#32358](https://github.com/ClickHouse/ClickHouse/pull/32358) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
