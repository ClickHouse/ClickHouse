<div id="performance-improvement">
  #### 性能提升
</div>

* 使用 JIT 编译排序列比较器，提升 ORDER BY、MergeJoin 以及向 MergeTree 插入数据时的性能。[#34469](https://github.com/ClickHouse/ClickHouse/pull/34469) ([Maksim Kita](https://github.com/kitaisreal)).
* 第一个提交是提高内联阈值。后续提交将通过内联进一步优化那些已显示出更好性能的查询。这样既不会增加编译时间和二进制文件大小，也能优化程序。[#34544](https://github.com/ClickHouse/ClickHouse/pull/34544) ([Daniel Kutenin](https://github.com/danlark1)).
* 将 OR LIKE 链改写为 multiMatchAny。待我们更有信心确认其稳定可用后再启用。[#34932](https://github.com/ClickHouse/ClickHouse/pull/34932) ([Daniel Kutenin](https://github.com/danlark1)).
* 将 &#39;select countDistinct(a) from t&#39; 改写为 &#39;select count(1) from (select a from t groupBy a)&#39;。[#35993](https://github.com/ClickHouse/ClickHouse/pull/35993) ([zhanglistar](https://github.com/zhanglistar)).
* 更改了 `system.asynchronous_metric_log` 的结构。其占用空间将减少约 10 倍。此变更关闭了 [#36357](https://github.com/ClickHouse/ClickHouse/issues/36357)。字段 `event_time_microseconds` 已被移除，因为它没有实际用途。[#36360](https://github.com/ClickHouse/ClickHouse/pull/36360) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 默认的 `HashJoin` 在插入右表的行时不是线程安全的，因此只能以单线程运行。右表较大时，由于 CPU 利用率较低，join 过程会非常缓慢。[#36415](https://github.com/ClickHouse/ClickHouse/pull/36415) ([lgbo](https://github.com/lgbo-ustc)).
* 当 path 包含通配符且匹配到的 directory 中含有大量文件时，提升从 `File` 表引擎和表函数 `file` 读取数据的性能。[#36647](https://github.com/ClickHouse/ClickHouse/pull/36647) ([Anton Popov](https://github.com/CurtizJ)).
* 为输入 format `HiveText` 应用并行解析，在读取本地文件时可将 HiveText 的解析速度提升 2 倍。[#36650](https://github.com/ClickHouse/ClickHouse/pull/36650) ([李扬](https://github.com/taiyang-li)).
* 通过缩小 mutex 的作用范围，提升文件描述符缓存的性能。[#36682](https://github.com/ClickHouse/ClickHouse/pull/36682) ([Anton Kozlov](https://github.com/tonickkozlov)).
* 此 PR 改进了 WindowView 中的 `WATCH` 查询：1. 通过调用 `fire_condition` 信号，降低返回查询结果的延迟。2. 通过更频繁地检查 `isCancelled()`，加快取消查询操作 (ctrl-c) 的响应速度。[#37226](https://github.com/ClickHouse/ClickHouse/pull/37226) ([vxider](https://github.com/Vxider)).
* 提升了在不使用 GROUP BY expression 时 `avg` 和 `sum` 聚合函数的性能。[#37257](https://github.com/ClickHouse/ClickHouse/pull/37257) ([Maksim Kita](https://github.com/kitaisreal)).
* 使用动态分发提升一元算术函数 (`bitCount`、`bitNot`、`abs`、`intExp2`、`intExp10`、`negate`、`roundAge`、`roundDuration`、`roundToExp2`、`sign`) 的性能。[#37289](https://github.com/ClickHouse/ClickHouse/pull/37289) ([Maksim Kita](https://github.com/kitaisreal)).
