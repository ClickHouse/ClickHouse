<div id="clickhouse-release-v209476-stable-fixme-as-compared-to-v209345-stable">
  ### ClickHouse 版本 v20.9.4.76-稳定版本 FIXME，与 v20.9.3.45-稳定版本 相比
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#16145](https://github.com/ClickHouse/ClickHouse/issues/16145) 中回移：现在，无论 cluster 配置中的 `<internal_replication>` 设置如何，都允许执行 `ALTER ... ON CLUSTER` 查询。[#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)).
* 已在 [#16312](https://github.com/ClickHouse/ClickHouse/issues/16312) 中回移：添加 allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards (允许在分片键中使用 rand() 或 dictGet() 之类的非确定性函数) 。[#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#15618](https://github.com/ClickHouse/ClickHouse/issues/15618) 中回移：现在，向 ReplicatedMergeTree 传入单个参数时会抛出错误，而不是将其忽略。[#15516](https://github.com/ClickHouse/ClickHouse/pull/15516) ([nvartolomei](https://github.com/nvartolomei)) 。
* 已在 [#16201](https://github.com/ClickHouse/ClickHouse/issues/16201) 中回移：在 detach 只读表时，递减 `ReadonlyReplica` 指标。此项修复解决了 [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598)。[#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)) 。
* 已在 [#16229](https://github.com/ClickHouse/ClickHouse/issues/16229) 中回移：修复了 S3 表函数中通配符相关的 bug；此前不会将从 URL 中解析出的区域应用到 S3 客户端配置中。[#15646](https://github.com/ClickHouse/ClickHouse/pull/15646) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 已在 [#15870](https://github.com/ClickHouse/ClickHouse/issues/15870) 中回移：修复了错误 `Cannot add simple transform to empty Pipe`。当从 `Buffer` 表读取数据且其结构与目标表不同时，如果目标表对查询返回空结果，就可能出现该错误。修复了 [#15529](https://github.com/ClickHouse/ClickHouse/issues/15529)。[#15662](https://github.com/ClickHouse/ClickHouse/pull/15662) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#15774](https://github.com/ClickHouse/ClickHouse/issues/15774) 中回移：修复了设置 `max_replicated_logs_to_keep` 默认值过低的问题，这可能导致副本过于频繁地丢失。通过选择最新的副本进行克隆，改进了丢失副本的恢复流程。同时，不再从丢失的副本中删除旧 parts，而是将其 detach。[#15701](https://github.com/ClickHouse/ClickHouse/pull/15701) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#15798](https://github.com/ClickHouse/ClickHouse/issues/15798) 中回移：修复了某些仅选择虚拟列的查询场景。此前可能会抛出 `Not found column _nothing in block` 异常。修复了 [#12298](https://github.com/ClickHouse/ClickHouse/issues/12298)。[#15756](https://github.com/ClickHouse/ClickHouse/pull/15756) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#15868](https://github.com/ClickHouse/ClickHouse/issues/15868) 中回移：修复了 MaterializeMySQL 中 `select count()` 结果不准确的问题。[#15767](https://github.com/ClickHouse/ClickHouse/pull/15767) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#15901](https://github.com/ClickHouse/ClickHouse/issues/15901) 中回移：修复了在执行 `ALTER MODIFY COLUMN` 查询后，再执行 `SELECT ... ORDER BY DESC` 查询时出现的 `Block structure mismatch` 异常。修复了 [#15800](https://github.com/ClickHouse/ClickHouse/issues/15800)。[#15852](https://github.com/ClickHouse/ClickHouse/pull/15852) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#15924](https://github.com/ClickHouse/ClickHouse/issues/15924) 中回移：现在，当 `ALTER MODIFY COLUMN ... DEFAULT ...` 中的默认值与列类型不兼容时，会抛出异常。修复了 [#15854](https://github.com/ClickHouse/ClickHouse/issues/15854)。[#15858](https://github.com/ClickHouse/ClickHouse/pull/15858) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#15919](https://github.com/ClickHouse/ClickHouse/issues/15919) 中回移：修复了 RBAC 中可能发生的死锁问题。[#15875](https://github.com/ClickHouse/ClickHouse/pull/15875) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#16167](https://github.com/ClickHouse/ClickHouse/issues/16167) 中回移：修复当查询包含 `WHERE`、`PREWHERE` 和 `GLOBAL IN` 时，从 `Distributed` 表查询返回错误空结果的问题。修复了 [#15792](https://github.com/ClickHouse/ClickHouse/issues/15792)。[#15933](https://github.com/ClickHouse/ClickHouse/pull/15933) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#16356](https://github.com/ClickHouse/ClickHouse/issues/16356) 中回移：修复在表被并发重命名时，`DROP TABLE IF EXISTS` 因 `Table ... doesn't exist` 错误而失败的问题 (适用于 atomic 数据库引擎) 。修复并发执行某些涉及多个表的 DDL 查询 (如 `DROP DATABASE` 和 `RENAME TABLE`) 时偶发的死锁问题。修复并发执行 `DROP/DETACH TABLE` 时，`DROP/DETACH DATABASE` 因 `Table ... doesn't exist` 而失败的问题。[#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#15971](https://github.com/ClickHouse/ClickHouse/issues/15971) 中回移：修复创建 database 失败时发生崩溃的问题。[#15954](https://github.com/ClickHouse/ClickHouse/pull/15954) ([Winter Zhang](https://github.com/zhang2014)).
* 已在 [#16022](https://github.com/ClickHouse/ClickHouse/issues/16022) 中回移：修复 profile 解析中的歧义：`CREATE USER ... SETTINGS profile readonly` 现在会被视为使用名为 `readonly` 的 profile，而不是将 `profile` 视为带有 readonly 约束的 setting。此修复解决了 [#15628](https://github.com/ClickHouse/ClickHouse/issues/15628)。[#15982](https://github.com/ClickHouse/ClickHouse/pull/15982) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#16218](https://github.com/ClickHouse/ClickHouse/issues/16218) 中回移：修复向 MaterializedView 插入数据或从中查询数据时，如果并发删除目标表会导致罕见段错误的问题 (适用于 atomic 数据库引擎) 。[#15984](https://github.com/ClickHouse/ClickHouse/pull/15984) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#16026](https://github.com/ClickHouse/ClickHouse/issues/16026) 中回移：防止在一段时间无活动后发生复制错误时，副本卡住 5–10 分钟。[#15987](https://github.com/ClickHouse/ClickHouse/pull/15987) ([filimonov](https://github.com/filimonov)).
* 已在 [#16091](https://github.com/ClickHouse/ClickHouse/issues/16091) 中回移：允许对具有复杂 key 的字典使用 direct 布局。[#16007](https://github.com/ClickHouse/ClickHouse/pull/16007) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#16361](https://github.com/ClickHouse/ClickHouse/issues/16361) 中回移：修复 collate 名称和 charset 名称解析器，并支持 `length = 0` 的 String 类型。[#16008](https://github.com/ClickHouse/ClickHouse/pull/16008) ([Winter Zhang](https://github.com/zhang2014)).
* 已在 [#16140](https://github.com/ClickHouse/ClickHouse/issues/16140) 中回移：修复 `ReplicatedVersionedCollapsingMergeTree` 的 `ALTER MODIFY ... ORDER BY` 查询卡住的问题。此修复解决了 [#15980](https://github.com/ClickHouse/ClickHouse/issues/15980)。[#16011](https://github.com/ClickHouse/ClickHouse/pull/16011) ([alesapin](https://github.com/alesapin)).
