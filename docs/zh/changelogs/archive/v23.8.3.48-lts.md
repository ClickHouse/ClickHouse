<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已回移到 [#54974](https://github.com/ClickHouse/ClickHouse/issues/54974)：修复了一个问题：在 prewhere 优化期间，复合条件动作 DAG 可能会丢失某个中间步骤的输出列，而该列又是后续某一步所需的输入列。[#53492](https://github.com/ClickHouse/ClickHouse/pull/53492) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)) 。
* 已回移到 [#54996](https://github.com/ClickHouse/ClickHouse/issues/54996)：当 `prefer_localhost_replica=1` 时，并行副本要么完全在本地副本上执行，要么会产生错误结果。修复了 [#54276](https://github.com/ClickHouse/ClickHouse/issues/54276)。[#54334](https://github.com/ClickHouse/ClickHouse/pull/54334) ([Igor Nikonov](https://github.com/devcrafter)) 。
* 已回移到 [#54516](https://github.com/ClickHouse/ClickHouse/issues/54516)：修复了 S3 表函数中可能出现的 &#39;URI contains invalid characters&#39; 错误。关闭了 [#54345](https://github.com/ClickHouse/ClickHouse/issues/54345)。[#54373](https://github.com/ClickHouse/ClickHouse/pull/54373) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已回移到 [#54418](https://github.com/ClickHouse/ClickHouse/issues/54418)：在处理 `analysisOfVariance` 的 group number 参数时检查溢出，以避免崩溃。该崩溃由 WINGFUZZ 发现。[#54385](https://github.com/ClickHouse/ClickHouse/pull/54385) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已回移到 [#54527](https://github.com/ClickHouse/ClickHouse/issues/54527)：复现了这里描述的 bug [#54135](https://github.com/ClickHouse/ClickHouse/issues/54135)。[#54430](https://github.com/ClickHouse/ClickHouse/pull/54430) ([Sema Checherinda](https://github.com/CheSema)) 。
* 已回移到 [#54854](https://github.com/ClickHouse/ClickHouse/issues/54854)：修复了使用 Variant aggregate states 时错误的 aggregation projection 优化。该优化被意外启用，但实现并不完整，因为在 [https://github.com/ClickHouse/ClickHouse/pull/39420](https://github.com/ClickHouse/ClickHouse/pull/39420) 之后，DataTypeAggregateFunction 的比较已被归一化。这修复了 [#54406](https://github.com/ClickHouse/ClickHouse/issues/54406)。[#54480](https://github.com/ClickHouse/ClickHouse/pull/54480) ([Amos Bird](https://github.com/amosbird)) 。
* 已回移到 [#54599](https://github.com/ClickHouse/ClickHouse/issues/54599)：修复了在禁用 input&#95;format&#95;with&#95;names&#95;use&#95;header 时，读取列子集过程中 WithNames 格式的解析错误。关闭了 [#52591](https://github.com/ClickHouse/ClickHouse/issues/52591)。[#54513](https://github.com/ClickHouse/ClickHouse/pull/54513) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已回移到 [#54594](https://github.com/ClickHouse/ClickHouse/issues/54594)：从 23.5 版本开始，zero-copy replication 可能会在 ZooKeeper 和 S3 上遗留一些垃圾数据。这可能发生在删除已变更的过期分区片段时。该问题的特征是出现日志消息 `Failed to get mutation parent on {} for part {}, refusing to remove blobs`。[#54550](https://github.com/ClickHouse/ClickHouse/pull/54550) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已回移到 [#54627](https://github.com/ClickHouse/ClickHouse/issues/54627)：修复了 `ColumnUnique` 中对共享变量的未同步写入问题。[#54575](https://github.com/ClickHouse/ClickHouse/pull/54575) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已回移到 [#54625](https://github.com/ClickHouse/ClickHouse/issues/54625)：修复了 `ColumnDecimal` 的序列化。[#54601](https://github.com/ClickHouse/ClickHouse/pull/54601) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已在 [#54945](https://github.com/ClickHouse/ClickHouse/issues/54945) 中回移：修复了虚拟列 (例如 &#95;file) 在使用 ORDER BY 时显示错误值的问题。[#54811](https://github.com/ClickHouse/ClickHouse/pull/54811) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已在 [#54872](https://github.com/ClickHouse/ClickHouse/issues/54872) 中回移：Keeper 修复：在回调中正确捕获变量，以避免在关闭期间发生段错误。[#54841](https://github.com/ClickHouse/ClickHouse/pull/54841) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#54950](https://github.com/ClickHouse/ClickHouse/issues/54950) 中回移：修复了在通过扩展其枚举类型来 ALTER 表分区键时，投影优化报错的问题。修复方式是在分区键被修改时重建 `minmax_count_projection`。此修复解决了 [#54941](https://github.com/ClickHouse/ClickHouse/issues/54941)。[#54943](https://github.com/ClickHouse/ClickHouse/pull/54943) ([Amos Bird](https://github.com/amosbird)) 。
