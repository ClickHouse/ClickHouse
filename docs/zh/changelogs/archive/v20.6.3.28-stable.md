<div id="bug-fix">
  #### 缺陷修复

* 已在 [#13301](https://github.com/ClickHouse/ClickHouse/issues/13301) 中回移：函数 `groupArrayMoving*` 在分布式查询中无法正常工作。其结果是在错误的数据类型下计算的 (未提升到最大的类型) 。函数 `groupArrayMovingAvg` 返回整数结果，这与 `avg` 函数不一致。此修复解决了 [#12568](https://github.com/ClickHouse/ClickHouse/issues/12568)。[#12622](https://github.com/ClickHouse/ClickHouse/pull/12622) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#13029](https://github.com/ClickHouse/ClickHouse/issues/13029) 中回移：现在，CREATE USER IF NOT EXISTS 在用户已存在时不会抛出异常。此修复解决了 [#12507](https://github.com/ClickHouse/ClickHouse/issues/12507)。[#12646](https://github.com/ClickHouse/ClickHouse/pull/12646) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#12983](https://github.com/ClickHouse/ClickHouse/issues/12983) 中回移：修复从 DDL 查询创建的 range hashed 字典中的列重复问题。此修复解决了 [#10605](https://github.com/ClickHouse/ClickHouse/issues/10605)。[#12857](https://github.com/ClickHouse/ClickHouse/pull/12857) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#13222](https://github.com/ClickHouse/ClickHouse/issues/13222) 中回移：修复带常量参数的 DateTime64 转换函数。[#13205](https://github.com/ClickHouse/ClickHouse/pull/13205) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#13245](https://github.com/ClickHouse/ClickHouse/issues/13245) 中回移：修复 `arrayElement` 函数中的断言问题：当数组元素为 Nullable，且数组下标也为 Nullable 时会触发该问题。此修复解决了 [#12172](https://github.com/ClickHouse/ClickHouse/issues/12172)。[#13224](https://github.com/ClickHouse/ClickHouse/pull/13224) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#13267](https://github.com/ClickHouse/ClickHouse/issues/13267) 中回移：修复 `if` 函数在 cond 为 nullable constexpr 且不为字面量 NULL 时的问题。修复了 [#12463](https://github.com/ClickHouse/ClickHouse/issues/12463)。[#13226](https://github.com/ClickHouse/ClickHouse/pull/13226) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#13298](https://github.com/ClickHouse/ClickHouse/issues/13298) 中回移：修复对带有 NaN 值的 Float 类型调用 `uniqExact`、`topK`、`sumDistinct` 及类似聚合函数时，可能出现的性能偏低和结果略有偏差的问题。它还会在 debug 构建中触发断言。此修复解决了 [#12491](https://github.com/ClickHouse/ClickHouse/issues/12491)。[#13254](https://github.com/ClickHouse/ClickHouse/pull/13254) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#13316](https://github.com/ClickHouse/ClickHouse/issues/13316) 中回移：如果用户向函数 `h3ToChildren` 传入特制的参数，服务器可能会崩溃。此修复解决了 [#13275](https://github.com/ClickHouse/ClickHouse/issues/13275)。[#13277](https://github.com/ClickHouse/ClickHouse/pull/13277) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#13329](https://github.com/ClickHouse/ClickHouse/issues/13329) 中回移：修复来自延迟副本的查询可能出现 `Totals having transform was already added to pipeline` 错误的问题。[#13290](https://github.com/ClickHouse/ClickHouse/pull/13290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。

* 已在 [#13375](https://github.com/ClickHouse/ClickHouse/issues/13375) 中回移：修复函数 `groupArrayMovingSum` 在反序列化空状态时发生 segfault 的问题。修复了 [#13339](https://github.com/ClickHouse/ClickHouse/issues/13339)。[#13341](https://github.com/ClickHouse/ClickHouse/pull/13341) ([alesapin](https://github.com/alesapin)).
