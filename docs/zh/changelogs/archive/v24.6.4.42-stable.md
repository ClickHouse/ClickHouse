<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 在 [#68066](https://github.com/ClickHouse/ClickHouse/issues/68066) 中回移：修复发送到外部数据库的查询中布尔字面量的问题 (适用于 `PostgreSQL` 等引擎) 。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* 在 [#68566](https://github.com/ClickHouse/ClickHouse/issues/68566) 中回移：修复由 fuzzer 发现的 indexHint 函数相关问题。[#66286](https://github.com/ClickHouse/ClickHouse/pull/66286) ([Anton Popov](https://github.com/CurtizJ)).
* 在 [#68159](https://github.com/ClickHouse/ClickHouse/issues/68159) 中回移：修复 cluster() 的 inter-server secret 问题 (像以前一样保留初始 USER) 。[#66364](https://github.com/ClickHouse/ClickHouse/pull/66364) ([Azat Khuzhin](https://github.com/azat)).
* 在 [#68116](https://github.com/ClickHouse/ClickHouse/issues/68116) 中回移：修复读取 Variant subcolumn 时可能出现的 PARAMETER&#95;OUT&#95;OF&#95;BOUND error。[#66659](https://github.com/ClickHouse/ClickHouse/pull/66659) ([Kruglov Pavel](https://github.com/Avogar)).
* 在 [#67887](https://github.com/ClickHouse/ClickHouse/issues/67887) 中回移：如果文件名/URI 中包含 `::` 且并非归档文件，则可正确解析。[#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368)).
* 在 [#68611](https://github.com/ClickHouse/ClickHouse/issues/68611) 中回移：修复 [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)。避免在 `ReplaceTableNodeToDummyVisitor` 中遍历未解析的 table function argument。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* 在 [#68275](https://github.com/ClickHouse/ClickHouse/issues/68275) 中回移：修复通过 HTTP interface 向 stream 类引擎 (Kafka、RabbitMQ、NATS) 插入数据的问题。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 在 [#67993](https://github.com/ClickHouse/ClickHouse/issues/67993) 中回移：在 ALTER ADD/MODIFY COLUMN 中校验 Experimental/可疑 data types。[#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).
* 在 [#68208](https://github.com/ClickHouse/ClickHouse/issues/68208) 中回移：修复 predicate 中存在 non-deterministic 函数时 `count()` 结果错误的问题。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 在 [#68093](https://github.com/ClickHouse/ClickHouse/issues/68093) 中回移：修复了在容器化环境中、可用 CPU 数量受限时最大线程 soft limit 的计算问题。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* 在 [#68124](https://github.com/ClickHouse/ClickHouse/issues/68124) 中回移：修复了新 analyzer 下 mutations 中对未触及 parts 的跳过逻辑。此前在启用 analyzer 时，即使根据 predicate 变更不会影响该 part，part 中的数据也可能被变更重写。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* 在 [#68221](https://github.com/ClickHouse/ClickHouse/issues/68221) 中回移：修复了一个由特制查询触发的 NULL 指针解引用问题，该问题可通过 hopEnd、hopStart、tumbleEnd 和 tumbleStart 导致 server 崩溃。[#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* 在 [#68173](https://github.com/ClickHouse/ClickHouse/issues/68173) 中回移：移除了一个错误的优化，该优化会去掉使用 `OFFSET` 的子查询中的排序。修复了 [#67906](https://github.com/ClickHouse/ClickHouse/issues/67906)。[#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)) 。
* 在 [#68339](https://github.com/ClickHouse/ClickHouse/issues/68339) 中回移：尝试修复查询被取消时 Postgres 崩溃的问题。[#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 在 [#68396](https://github.com/ClickHouse/ClickHouse/issues/68396) 中回移：修复查询 `SYSTEM SYNC REPLICA` 缺少同步副本模式的问题。[#68326](https://github.com/ClickHouse/ClickHouse/pull/68326) ([Duc Canh Le](https://github.com/canhld94)) 。
* 在 [#68668](https://github.com/ClickHouse/ClickHouse/issues/68668) 中回移：修复当函数 `sipHash64Keyed`、`sipHash128Keyed` 或 `sipHash128ReferenceKeyed` 应用于空数组或元组时出现的 `LOGICAL_ERROR`。[#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)) 。
