<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#40542](https://github.com/ClickHouse/ClickHouse/issues/40542) 中回移：修复了任务调度失败期间 WriteBufferFromS3 中可能发生的死锁问题。[#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal))。
* 已在 [#40450](https://github.com/ClickHouse/ClickHouse/issues/40450) 中回移：修复了 MergeTree 引擎家族中与列生存时间 (TTL) 相关的一个罕见缺陷：在重复执行 vertical merge 的情况下，可能出现错误 `Cannot unlink file ColumnName.bin ... No such file or directory.`。[#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin))。
* 已在 [#40532](https://github.com/ClickHouse/ClickHouse/issues/40532) 中回移：修复了代理解析器在首次成功请求端点后即停止的问题。[#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal))。
* 已在 [#40624](https://github.com/ClickHouse/ClickHouse/issues/40624) 中回移：修复了因 AWS SDK 中的缺陷导致的潜在数据丢失问题 ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)) 。该缺陷仅会在 ClickHouse 使用 S3 时触发。[#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin))。
