<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#54583](https://github.com/ClickHouse/ClickHouse/issues/54583) 中回移：修复了 replicated merge tree 中一个罕见缺陷，该缺陷可能导致日志中出现可自行恢复的 `CHECKSUM_DOESNT_MATCH` 错误。[#54549](https://github.com/ClickHouse/ClickHouse/pull/54549) ([alesapin](https://github.com/alesapin))。
* 已在 [#56253](https://github.com/ClickHouse/ClickHouse/issues/56253) 中回移：修复了 match() 函数 (正则表达式) 中的缺陷：当 pattern 包含交替分支时，会生成错误的 key condition。[#54696](https://github.com/ClickHouse/ClickHouse/pull/54696) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* 已在 [#56322](https://github.com/ClickHouse/ClickHouse/issues/56322) 中回移：修复了启动时加载表过程中发生崩溃的问题。关闭 [#55767](https://github.com/ClickHouse/ClickHouse/issues/55767)。[#56232](https://github.com/ClickHouse/ClickHouse/pull/56232) ([Nikolay Degterinsky](https://github.com/evillique))。
* 已在 [#56292](https://github.com/ClickHouse/ClickHouse/issues/56292) 中回移：修复了 Keeper 信号处理器中的段错误。[#56266](https://github.com/ClickHouse/ClickHouse/pull/56266) ([Antonio Andelic](https://github.com/antonio2368))。
* 已在 [#56443](https://github.com/ClickHouse/ClickHouse/issues/56443) 中回移：修复了使用 `T64` codec 解压格式错误的数据时，因缓冲区溢出导致崩溃的问题。该问题由 [https://twitter.com/malacupa](https://twitter.com/malacupa) 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#56434](https://github.com/ClickHouse/ClickHouse/pull/56434) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
