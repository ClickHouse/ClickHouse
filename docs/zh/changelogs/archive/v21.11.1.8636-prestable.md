<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 现在，ClickHouse Keeper 的 snapshots 默认使用 `ZSTD` codec 压缩，而不再使用自定义的 ClickHouse LZ4 块压缩。可通过协调 setting `compress_snapshots_with_zstd_format` 关闭此行为 (所有 quorum 副本上的值必须一致) 。这种向后不兼容的情况非常少见，只有在新节点向旧节点发送 snapshot 时才可能发生 (会出现在 recovery 场景下) ，因为旧节点无法读取 ZSTD 格式的 snapshots。 [#29417](https://github.com/ClickHouse/ClickHouse/pull/29417) ([alesapin](https://github.com/alesapin)).
* Function `bayesAB` 已移除。此更改关闭了 [#26233](https://github.com/ClickHouse/ClickHouse/issues/26233)。 [#29934](https://github.com/ClickHouse/ClickHouse/pull/29934) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 移除 MergeTree 表 setting `write_final_mark`。该值将始终为 `true`。 [#30455](https://github.com/ClickHouse/ClickHouse/pull/30455) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 调整 SQL JSON function 中 json&#95;path 和 json 的顺序 (以保证正确性) 。关闭 [#30449](https://github.com/ClickHouse/ClickHouse/issues/30449)。 [#30474](https://github.com/ClickHouse/ClickHouse/pull/30474) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 移除 setting `odbc_max_field_size`，因为它已不再使用。关闭 [#30413](https://github.com/ClickHouse/ClickHouse/issues/30413)。 [#30778](https://github.com/ClickHouse/ClickHouse/pull/30778) ([Kseniia Sumarokova](https://github.com/kssenii)).
