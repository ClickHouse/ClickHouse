<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#25849](https://github.com/ClickHouse/ClickHouse/issues/25849) 中回移：从 `Date` 到 `DateTime` (或 `DateTime64`) 的 `CAST` 未使用 `DateTime` 类型的时区。这也会影响 `Date` 与 `DateTime` 之间的比较。对 `Date` 和 `DateTime` 进行公共类型推断时，同样没有使用相应的时区。这会影响函数 `if` 和数组构造的结果。关闭 [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#25679](https://github.com/ClickHouse/ClickHouse/issues/25679) 中回移：修复了随机生成器状态在反序列化时的缺陷，该缺陷可能导致某些数据类型 (例如 `AggregateFunction(groupArraySample(N), T))`) 出现非确定性行为。[#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#25556](https://github.com/ClickHouse/ClickHouse/issues/25556) 中回移：修复了在对其他聚合函数的聚合函数状态进行聚合时，计算聚合函数状态可能发生崩溃的问题 (不是实际用例) 。参见 [#24523](https://github.com/ClickHouse/ClickHouse/issues/24523)。[#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#25767](https://github.com/ClickHouse/ClickHouse/issues/25767) 中回移：修复了 PREWHERE 中使用非 uint8 类型时的断言问题，关闭 [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589)。[#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#25636](https://github.com/ClickHouse/ClickHouse/issues/25636) 中回移：修复了查询 `WITH TOTALS` 和 `WITH FILL` 时 totals 结果错误的问题。修复 [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872)。[#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#25653](https://github.com/ClickHouse/ClickHouse/issues/25653) 中回移：修复了在没有查询时执行 `EXPLAIN AST` 的空指针解引用问题。[#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#25715](https://github.com/ClickHouse/ClickHouse/issues/25715) 中回移：如果源分区为空，`REPLACE PARTITION` 在极少数情况下可能会被忽略。现已修复。修复 [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869)。[#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#25695](https://github.com/ClickHouse/ClickHouse/issues/25695) 中回移：修复了在数据库之间移动 `Distributed` 表时出现的 `No such file or directory` 错误。修复 [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971)。[#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#25754](https://github.com/ClickHouse/ClickHouse/issues/25754) 中回移：修复了在重新加载集群配置的同时查询 `system.clusters` 时出现的数据竞争问题。[#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)) 。
