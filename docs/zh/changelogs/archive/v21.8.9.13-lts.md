* 已在 [#29817](https://github.com/ClickHouse/ClickHouse/issues/29817) 中回移：即使 `insert_allow_materialized_columns=0`，也允许在分布式表中将 materialized 列用作分片键。[#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#29973](https://github.com/ClickHouse/ClickHouse/issues/29973) 中回移：修复 `AccessControlManager` 的关闭问题。现在，在 `AccessControlManager` 被销毁后，将不会再次重新加载配置。此 PR 还修复了不稳定测试 [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html)。[#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)) 。

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#29676](https://github.com/ClickHouse/ClickHouse/issues/29676) 中回移：修复 projection parts 的 vertical merge。此修复解决了 [#29253](https://github.com/ClickHouse/ClickHouse/issues/29253)。此 PR 还修复了在 [https://github.com/ClickHouse/ClickHouse/pull/25165](https://github.com/ClickHouse/ClickHouse/pull/25165) 中引入的若干 projection merge/变更问题。[#29337](https://github.com/ClickHouse/ClickHouse/pull/29337) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#29538](https://github.com/ClickHouse/ClickHouse/issues/29538) 中回移：修复带有下推 `HAVING` 谓词的子查询可能出现的 `Block structure mismatch`。修复了 [#29010](https://github.com/ClickHouse/ClickHouse/issues/29010)。[#29475](https://github.com/ClickHouse/ClickHouse/pull/29475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#29589](https://github.com/ClickHouse/ClickHouse/issues/29589) 中回移：在 ODBC bridge 中为 Invalid cursor state 错误添加重试。这是一个可重试的错误。关闭了 [#29473](https://github.com/ClickHouse/ClickHouse/issues/29473)。[#29518](https://github.com/ClickHouse/ClickHouse/pull/29518) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#29593](https://github.com/ClickHouse/ClickHouse/issues/29593) 中回移：修复 check `pathStartsWith` 中的 bug，因为 `std::mismatch` 的用法存在问题：` The behavior is undefined if the second range is shorter than the first range.`。[#29531](https://github.com/ClickHouse/ClickHouse/pull/29531) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#29628](https://github.com/ClickHouse/ClickHouse/issues/29628) 中回移：修复 `ALTER MODIFY` 查询中的罕见 segfault：当在 `DEFAULT` expression 中使用错误的表标识符 (如 `x.y.z...`) 时会触发。修复了 [#29184](https://github.com/ClickHouse/ClickHouse/issues/29184)。[#29573](https://github.com/ClickHouse/ClickHouse/pull/29573) ([alesapin](https://github.com/alesapin)).
* 已在 [#29752](https://github.com/ClickHouse/ClickHouse/issues/29752) 中回移：过滤谓词中的条件在下推优化后可能会丢失。[#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#29840](https://github.com/ClickHouse/ClickHouse/issues/29840) 中回移：修复 server 重启时 setting `materialized_postgresql_tables_list` 行为不正确的问题。发现于 [#28529](https://github.com/ClickHouse/ClickHouse/issues/28529)。[#29686](https://github.com/ClickHouse/ClickHouse/pull/29686) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#29847](https://github.com/ClickHouse/ClickHouse/issues/29847) 中回移：修复 `GROUP BY` 期间对 `LowCardinality` 的并发访问问题 (会导致 SIGSEGV) 。[#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#29911](https://github.com/ClickHouse/ClickHouse/issues/29911) 中回移：修复 `ATTACH TABLE ... FROM 'path'` 查询中的错误类型转换问题，即使用非字符串 literal 代替 path 时会触发该问题。该问题可能导致读取未初始化内存。[#29790](https://github.com/ClickHouse/ClickHouse/pull/29790) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#29867](https://github.com/ClickHouse/ClickHouse/issues/29867) 中回移：避免在极少数情况下可能出现 `Timeout exceeded: elapsed 18446744073.709553 seconds` 错误，推测是由内核中的某个 bug 导致。修复了 [#29154](https://github.com/ClickHouse/ClickHouse/issues/29154)。[#29811](https://github.com/ClickHouse/ClickHouse/pull/29811) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#29877](https://github.com/ClickHouse/ClickHouse/issues/29877) 中回移：修复系统表重建检查问题 (无法检测枚举值的变化) 。[#29857](https://github.com/ClickHouse/ClickHouse/pull/29857) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#30210](https://github.com/ClickHouse/ClickHouse/issues/30210) 中回移：修复 `FileChecker` 与 `StorageLog`/`StorageStripeLog` 之间可能发生的数据竞争问题。[#29959](https://github.com/ClickHouse/ClickHouse/pull/29959) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#30069](https://github.com/ClickHouse/ClickHouse/issues/30069) 中回移：修复由 `tuple()` 引发的 sample 崩溃问题，关闭 [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004)。[#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)) 。
* 已在 [#30125](https://github.com/ClickHouse/ClickHouse/issues/30125) 中回移：已修复已删除的 `Memory` 数据库在服务器重启后可能重新出现的问题 ([#29795](https://github.com/ClickHouse/ClickHouse/issues/29795)) 。另外还添加了 `force_remove_data_recursively_on_drop` 设置，作为删除 `Ordinary` 数据库时出现 `Directory not empty` 错误的临时解决方法 (因为在 Cloud 环境中无法手动删除残留数据) 。[#30054](https://github.com/ClickHouse/ClickHouse/pull/30054) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#30263](https://github.com/ClickHouse/ClickHouse/issues/30263) 中回移：修复 FlatDictionary、HashedDictionary 对可空属性的 bytes&#95;allocated 计算问题。[#30238](https://github.com/ClickHouse/ClickHouse/pull/30238) ([Maksim Kita](https://github.com/kitaisreal)) 。
