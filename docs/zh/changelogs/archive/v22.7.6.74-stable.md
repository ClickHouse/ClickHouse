<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#41283](https://github.com/ClickHouse/ClickHouse/issues/41283) 中回移：修复由 WITH 语句引入的未使用未知列问题。此修复解决了 [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812)。[#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#40865](https://github.com/ClickHouse/ClickHouse/issues/40865) 中回移：- 修复解析包含可变维度数组的 `Object` 类型值时发生的崩溃问题。[#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* 已在 [#40804](https://github.com/ClickHouse/ClickHouse/issues/40804) 中回移：向 `ProcessList` 插入新查询时会发生内存分配。如果在这些分配过程中达到内存限制，则无法使用 `OvercommitTracker`，因为此时已持有 `ProcessList::mutex`。修复了 [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)。[#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#40810](https://github.com/ClickHouse/ClickHouse/issues/40810) 中回移：在 [#40595](https://github.com/ClickHouse/ClickHouse/issues/40595) 中有人报告，`host_regexp` 功能在 `/etc/hosts` 中进行名称到地址解析时工作不正常。现已修复。[#40769](https://github.com/ClickHouse/ClickHouse/pull/40769) ([Arthur Passos](https://github.com/arthurpassos)).
* 已在 [#41134](https://github.com/ClickHouse/ClickHouse/issues/41134) 中回移：修复 `DESCRIBE TABLE url()` 以及其他一些 `DESCRIBE TABLE <table_function>()` 的访问权限问题。[#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#41617](https://github.com/ClickHouse/ClickHouse/issues/41617) 中回移：修复聚合函数组合器中可能出现的 segfault、use-heap-after-free 和内存泄漏问题。已关闭 [#40848](https://github.com/ClickHouse/ClickHouse/issues/40848)。[#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#41666](https://github.com/ClickHouse/ClickHouse/issues/41666) 中回移：子查询中带有 `OFFSET` 子句且外层查询中带有 `WHERE` 子句的查询，可能返回错误结果，现已修复。修复了 [#40416](https://github.com/ClickHouse/ClickHouse/issues/40416)。[#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#41361](https://github.com/ClickHouse/ClickHouse/issues/41361) 中回移：修复对象存储磁盘中错误触发的逻辑错误 `Expected relative path`。与 [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246) 相关。[#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#41358](https://github.com/ClickHouse/ClickHouse/issues/41358) 中回移：在 MsgPack format 中插入 UUID 之前增加列类型检查。[#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#41808](https://github.com/ClickHouse/ClickHouse/issues/41808) 中回移：Native format 中的恶意数据可能导致崩溃。[#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#41805](https://github.com/ClickHouse/ClickHouse/issues/41805) 中回移：聚合函数 `categorialInformationValue` 的属性定义有误，可能导致运行时发生空指针解引用。此项关闭了 [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443)。[#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#41505](https://github.com/ClickHouse/ClickHouse/issues/41505) 中回移：以 Apache `ORC` 格式写入数据时，可能导致缓冲区越界。[#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#41644](https://github.com/ClickHouse/ClickHouse/issues/41644) 中回移：带有 `ORDER BY` 且 `1500 <= LIMIT <= max_block_size` 的查询可能返回错误结果，顶部的一些行会丢失。修复了 [#41182](https://github.com/ClickHouse/ClickHouse/issues/41182)。[#41576](https://github.com/ClickHouse/ClickHouse/pull/41576) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#41641](https://github.com/ClickHouse/ClickHouse/issues/41641) 中回移：修复带有 `OFFSET` 的查询可能出现的 `pipeline stuck` 异常。该问题是在 `enable_optimize_predicate_expression = 0` 且 `WHERE` 中存在恒为 false 的条件时发现的。修复了 [#41383](https://github.com/ClickHouse/ClickHouse/issues/41383)。[#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#41900](https://github.com/ClickHouse/ClickHouse/issues/41900) 中回移：修复了在启用 `optimize_monotonous_functions_in_order_by` 设置时，从 `Merge` 表执行 `SELECT` 可能发生的崩溃问题。修复了 [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269)。[#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
