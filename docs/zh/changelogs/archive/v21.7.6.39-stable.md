* 已在 [#26854](https://github.com/ClickHouse/ClickHouse/issues/26854) 中回移：ParallelFormattingOutputFormat：使用 mutex 处理与 collector&#95;thread 的 join 操作 ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)) 。[#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#26938](https://github.com/ClickHouse/ClickHouse/issues/26938) 中回移：修复 ReplicatedMergeTree 表关闭时删除数据而导致数据与元数据不一致的问题。[#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)) 。
* 已在 [#26986](https://github.com/ClickHouse/ClickHouse/issues/26986) 中回移：应用某些组合器时，聚合函数参数可能会丢失，从而导致类似 `Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported` 的异常。现已修复。修复了 [#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) 和 [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433)。[#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#26944](https://github.com/ClickHouse/ClickHouse/issues/26944) 中回移：修复当 `DEFAULT` 列引用其他没有 `DEFAULT` 表达式的非 materialized 列时出现的错误 `Missing columns: 'xxx'`。修复了 [#26591](https://github.com/ClickHouse/ClickHouse/issues/26591)。[#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#26999](https://github.com/ClickHouse/ClickHouse/issues/26999) 中回移：修复自定义 TLD 的读取问题 (在较小 buffer 或较大文件时会停止处理) 。[#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#27029](https://github.com/ClickHouse/ClickHouse/issues/27029) 中回移：现在，`ALTER TABLE ... PARTITION ID xxx` 这类查询中的 partition ID 会校验其有效性。修复了 [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718)。[#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#27050](https://github.com/ClickHouse/ClickHouse/issues/27050) 中回移：[RFC] 修复因与 DROP&#95;RANGE 发生竞态而可能导致的变更堆积问题。[#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#27105](https://github.com/ClickHouse/ClickHouse/issues/27105) 中回移：修复了 `cache`、`complex_key_cache`、`ssd_cache`、`complex_key_ssd_cache` 的配置解析问题。对于非 `cache` 类型的字典，选项 `allow_read_expired_keys`、`max_update_queue_size`、`update_queue_push_timeout_milliseconds`、`query_wait_timeout_milliseconds` 之前不会被解析。[#27032](https://github.com/ClickHouse/ClickHouse/pull/27032) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#27156](https://github.com/ClickHouse/ClickHouse/issues/27156) 中回移：修复 GRPCServer 中的同步问题。此 PR 修复了 [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024)。[#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#27261](https://github.com/ClickHouse/ClickHouse/issues/27261) 中回移：在极少数情况下，`system.detached_parts` 表中某些 parts 可能包含不正确的信息，现已修复。修复了 [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114)。[#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
