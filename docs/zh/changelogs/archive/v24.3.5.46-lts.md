<div id="improvement">
  #### 改进
</div>

* 已在 [#65463](https://github.com/ClickHouse/ClickHouse/issues/65463) 中回移：重新加载证书时会同步重新加载证书链。[#61671](https://github.com/ClickHouse/ClickHouse/pull/61671) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)) 。
* 已在 [#65882](https://github.com/ClickHouse/ClickHouse/issues/65882) 中回移：始终使用全局线程池中充足数量的线程来启动 Keeper。[#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94)) 。
* 已在 [#65302](https://github.com/ClickHouse/ClickHouse/issues/65302) 中回移：恢复了 ClickHouse 在 CSV 格式中处理和解释 Tuples 的行为。此更改实际上回退了 [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994)，并且仅在少数几个设置启用时生效：`output_format_csv_serialize_tuple_into_separate_columns`、`input_format_csv_deserialize_separate_columns_into_tuple` 和 `input_format_csv_try_infer_strings_from_quoted_tuples`。[#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#65892](https://github.com/ClickHouse/ClickHouse/issues/65892) 中回移：在 Keeper 中遵循 cgroup CPU 限制。[#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)) 。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 严重缺陷修复 (崩溃、LOGICAL_ERROR、数据丢失、RBAC)
</div>

* 已在 [#65283](https://github.com/ClickHouse/ClickHouse/issues/65283) 中回移：修复了 UniqInjectiveFunctionsEliminationPass 与 uniqCombined 相关的崩溃问题。[#65188](https://github.com/ClickHouse/ClickHouse/pull/65188) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#65370](https://github.com/ClickHouse/ClickHouse/issues/65370) 中回移：修复了 ClickHouse Keeper 中一个会在关闭会话时导致摘要不匹配的缺陷。[#65198](https://github.com/ClickHouse/ClickHouse/pull/65198) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 已在 [#65446](https://github.com/ClickHouse/ClickHouse/issues/65446) 中回移：为 Distinct 组合器使用正确的内存对齐方式。此前，使用该组合器时，可能因无效的内存分配而发生崩溃。[#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#65708](https://github.com/ClickHouse/ClickHouse/issues/65708) 中回移：修复了 maxIntersections 中的崩溃问题。[#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)).

* 已回移到 [#65352](https://github.com/ClickHouse/ClickHouse/issues/65352)：修复 StatusFile 中 ~WriteBufferFromFileDescriptor 发生未捕获异常时可能导致中止的问题。[#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已回移到 [#65327](https://github.com/ClickHouse/ClickHouse/issues/65327)：修复从 Backup 恢复时，若创建了其 definer 尚未恢复的 MV，导致恢复被阻塞并陷入崩溃循环的问题。[#64595](https://github.com/ClickHouse/ClickHouse/pull/64595) ([pufit](https://github.com/pufit)) 。
* 已回移到 [#65538](https://github.com/ClickHouse/ClickHouse/issues/65538)：修复 `ALTER TABLE ... ON CLUSTER ... MODIFY SQL SECURITY` 引发的崩溃。[#64957](https://github.com/ClickHouse/ClickHouse/pull/64957) ([pufit](https://github.com/pufit)) 。
* 已回移到 [#65576](https://github.com/ClickHouse/ClickHouse/issues/65576)：修复销毁 AccessControl 时发生的崩溃：添加显式关闭。[#64993](https://github.com/ClickHouse/ClickHouse/pull/64993) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已回移到 [#65159](https://github.com/ClickHouse/ClickHouse/issues/65159)：修复将算术操作从 aggregation 中提取出去的问题。在新的 analyzer 中，该优化仅会应用一次。[#65104](https://github.com/ClickHouse/ClickHouse/pull/65104) ([Dmitry Novik](https://github.com/novikd)) 。
* 已回移到 [#65615](https://github.com/ClickHouse/ClickHouse/issues/65615)：修复新的 analyzer 中 aggregate function 名称重写的问题。[#65110](https://github.com/ClickHouse/ClickHouse/pull/65110) ([Dmitry Novik](https://github.com/novikd)) 。
* 已回移到 [#65728](https://github.com/ClickHouse/ClickHouse/issues/65728)：递归消除函数 `uniq*` 参数中的 injective 函数。该功能原本可以正常工作，但在新的 analyzer 中失效了。[#65140](https://github.com/ClickHouse/ClickHouse/pull/65140) ([Duc Canh Le](https://github.com/canhld94)) 。
* 已回移到 [#65261](https://github.com/ClickHouse/ClickHouse/issues/65261)：修复 Hashed 和 Hashed&#95;Array 字典短路求值中的 bug，该问题可能会读取未初始化的数值，从而导致各种错误。[#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)) 。
* 已回移到 [#65667](https://github.com/ClickHouse/ClickHouse/issues/65667)：在启用 `read-in-order` 优化的情况下，针对带有 `FINAL` 的查询禁用 `non-intersecting-parts` 优化。这可能导致错误的查询结果。作为临时解决方法，在此修复合入之前，请禁用 `do_not_merge_across_partitions_select_final` 和 `split_parts_ranges_into_intersecting_and_non_intersecting_final`。[#65505](https://github.com/ClickHouse/ClickHouse/pull/65505) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已回移到 [#65784](https://github.com/ClickHouse/ClickHouse/issues/65784)：修复 MergeJoin 中的 bug。在稀疏序列化中，某列可能会在未执行所需转换的情况下，被当作其嵌套类型的列处理。[#65632](https://github.com/ClickHouse/ClickHouse/pull/65632) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已回移到 [#65929](https://github.com/ClickHouse/ClickHouse/issues/65929)：对于从 `PostgreSQL` 读取数据的查询，如果 ClickHouse 查询已结束，则取消内部的 `PostgreSQL` 查询。否则，在内部 `PostgreSQL` 查询完成之前，ClickHouse 查询将无法取消。[#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#65824](https://github.com/ClickHouse/ClickHouse/issues/65824) 中回移：修复了在使用旧版 analyzer 和 dictGetOrDefault 时短路逻辑中的一个 bug。[#65802](https://github.com/ClickHouse/ClickHouse/pull/65802) ([jsc0218](https://github.com/jsc0218)).
