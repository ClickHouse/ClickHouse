<div id="clickhouse-release-v2493128-stable-9a816c73dd4-fixme-as-compared-to-v249242-stable-de7c791a2ea">
  ### ClickHouse 发布 v24.9.3.128-稳定版本 (9a816c73dd4) FIXME 与 v24.9.2.42-稳定版本 (de7c791a2ea) 相比
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的更改
</div>

* 已在 [#71361](https://github.com/ClickHouse/ClickHouse/issues/71361) 中回移：修复了 JSON 子列相关文件中未转义的特殊符号可能导致的错误 `No such file or directory`。[#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)) 。

<div id="new-feature">
  #### 新特性
</div>

* 已在 [#71318](https://github.com/ClickHouse/ClickHouse/issues/71318) 中回移：允许每种身份验证方法拥有各自的过期日期，并将该字段从用户实体中移除。[#70090](https://github.com/ClickHouse/ClickHouse/pull/70090) ([Arthur Passos](https://github.com/arthurpassos)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#70681](https://github.com/ClickHouse/ClickHouse/issues/70681) 中回移：从 keeper 同步 user&#95;directories 时不做校验。[#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#71668](https://github.com/ClickHouse/ClickHouse/issues/71668) 中回移：当 user/group 以 ID 形式提供时，`clickhouse su` 会失败。此补丁将其修复为同时接受 `UID:GID`。 ### 面向用户变更的文档条目。[#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 已在 [#71938](https://github.com/ClickHouse/ClickHouse/issues/71938) 中回移：在一个 `history` 周期内将 `HostResolver` 更新 3 次。[#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
