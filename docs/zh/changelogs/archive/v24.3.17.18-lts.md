<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#75640](https://github.com/ClickHouse/ClickHouse/issues/75640) 中回移：修复 docker 初始化脚本失败时的日志消息，使其更清晰易懂。[#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* 已在 [#76227](https://github.com/ClickHouse/ClickHouse/issues/76227) 中回移：修复 PSQL 复制中因未捕获异常导致的崩溃。[#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#76101](https://github.com/ClickHouse/ClickHouse/issues/76101) 中回移：修复 LowCardinality Nullable 数据类型在 nullsafe JOIN 处理中的问题。此前，带有 nullsafe 比较的 JOIN ON (例如 `IS NOT DISTINCT FROM`、`<=>`、`a IS NULL AND b IS NULL OR a == b`) 无法在 LowCardinality 列上正确工作。[#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#75830](https://github.com/ClickHouse/ClickHouse/issues/75830) 中回移：修复 `DistinctSortedStreamTransform` 中的空指针解引用问题。[#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).

Shiryaev](https://github.com/Felixoid)) 。
