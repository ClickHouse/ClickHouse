<div id="improvement">
  #### 改进
</div>

* 已在 [#76864](https://github.com/ClickHouse/ClickHouse/issues/76864) 中回移：新增支持在不重启服务器的情况下动态重新加载 `max_remote_read_network_bandwidth_for_serve` 和 `max_remote_write_network_bandwidth_for_server`。[#74206](https://github.com/ClickHouse/ClickHouse/pull/74206) ([Kai Zhu](https://github.com/nauu)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#76997](https://github.com/ClickHouse/ClickHouse/issues/76997) 中回移：修复了在启用 async insert 且执行 `insert into ... from file ...` 时，如果块大小不一致，并且第一个块大小 &lt; `async_max_size`、第二个块 &gt; `async_max_size`，第二个块不会被写入，从而导致数据丢失的问题。这些数据会遗留在 `squashing` 中。[#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* 已在 [#76675](https://github.com/ClickHouse/ClickHouse/issues/76675) 中回移：修复了并行哈希中 `used_flag` 的初始化问题。该问题可能导致服务器崩溃。[#76580](https://github.com/ClickHouse/ClickHouse/pull/76580) ([Nikita Taranov](https://github.com/nickitat)).
* 已在 [#76833](https://github.com/ClickHouse/ClickHouse/issues/76833) 中回移：在最终完成输出写入缓冲区之前先将其刷新。修复了某些输出格式在最终完成过程中产生的 `LOGICAL_ERROR`，例如 `JSONEachRowWithProgressRowOutputFormat`。[#76726](https://github.com/ClickHouse/ClickHouse/pull/76726) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#77062](https://github.com/ClickHouse/ClickHouse/issues/77062) 中回移：修复了 `BFloat16` 值的排序问题。此更改关闭了 [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487)。此更改关闭了 [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669)。[#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
