<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#40451](https://github.com/ClickHouse/ClickHouse/issues/40451) 中回移：修复 MergeTree 引擎家族中与列生存时间 (TTL) 相关的罕见缺陷：在重复执行纵向合并时，可能出现错误 `Cannot unlink file ColumnName.bin ... No such file or directory.`。[#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
* 已在 [#40533](https://github.com/ClickHouse/ClickHouse/issues/40533) 中回移：代理解析器会在首次成功请求某个端点后停止。[#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#40625](https://github.com/ClickHouse/ClickHouse/issues/40625) 中回移：修复因 AWS SDK 缺陷导致的潜在数据丢失问题 ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)) 。该缺陷只有在通过 S3 使用 ClickHouse 时才会触发。[#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
