<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534) 中回移：修复了 `LowCardinality` 列的内存大小计算问题。[#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已在 [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005) 中回移：发现并发控制可能导致 INSERT 和 SELECT 之间的 CPU 分配不均。当所有 CPU 插槽在没有竞争的情况下被无条件分配给 `max_threads` = 1 的 INSERT 时，`max_threads` 值较高的 SELECT 会因只能使用单个线程而性能较差。[#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535) 中回移：更准确地统计 `parallel_hash` JOIN 算法中 `max_joined_block_size_rows` 设置，有助于避免相比 `hash` 算法出现更高的内存消耗。[#74630](https://github.com/ClickHouse/ClickHouse/pull/74630) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已在 [#75844](https://github.com/ClickHouse/ClickHouse/issues/75844) 中回移：为解密和解压添加检查与日志记录。[#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#76046](https://github.com/ClickHouse/ClickHouse/issues/76046) 中回移：Keeper 改进：提交到内存存储时禁用摘要计算以提升性能。可通过 `keeper_server.digest_enabled_on_commit` 配置启用。预处理请求时仍会计算摘要。[#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#75709](https://github.com/ClickHouse/ClickHouse/issues/75709) 中回移：为保证兼容性，禁用从 server 向 client 发送设置 (`send_settings_to_client=false`) 。 (此功能后续将重新实现为 client setting，以提升易用性。) [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已在 [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805) 中回移：新增配置 `memory_worker_correct_memory_tracker`，用于启用基于后台线程定期读取的不同来源信息对内部 memory tracker 进行修正。[#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069) 中回移：新增 `MemoryTrackingUncorrected` 指标，用于显示未经 RSS 修正的内部全局 memory tracker 的值。[#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)) 。
