<div id="bug-fix">
  #### 缺陷修复
</div>

* 回移于 [#32692](https://github.com/ClickHouse/ClickHouse/issues/32692)：尚未达到配额上限，却被判定为超出限制。此 PR 修复了 [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174)。[#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).

#### 缺陷修复 (官方稳定版本中用户可见的异常行为) 

* 回移于 [#32680](https://github.com/ClickHouse/ClickHouse/issues/32680)：修复 detach parts 时意外删除投影的问题。[#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* 回移于 [#32285](https://github.com/ClickHouse/ClickHouse/issues/32285)：修复字典在自定义数据库查询中 `{condition}` 不生效的问题。[#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* 回移于 [#32730](https://github.com/ClickHouse/ClickHouse/issues/32730)：修复 `APPLY lambda` 的 parsing 问题，该问题可能导致客户端/server 崩溃。[#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* 回移于 [#32313](https://github.com/ClickHouse/ClickHouse/issues/32313)：升级到较新版本时，用于表 create query 的 XML 字典标识符可能会被限定为 `default_database`。关闭 [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)。[#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* 回移于 [#32539](https://github.com/ClickHouse/ClickHouse/issues/32539)：某些 replication queue 条目可能会因 `Directory tmp_merge_<part_name>`、`Part ... (state Deleting) already exists, but it will be deleted soon` 或类似 error 而卡住长达 `temporary_directories_lifetime` (默认 1 天) 。现已修复。修复了 [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 回移于 [#32709](https://github.com/ClickHouse/ClickHouse/issues/32709)：修复查询尝试使用尚未 materialized 的 skipping indices 时失败的问题。修复了 [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) 和 [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343)。[#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* 回移于 [#32567](https://github.com/ClickHouse/ClickHouse/issues/32567)：修复 `JoinCommon::removeColumnNullability` 中的崩溃问题，关闭 [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458)。[#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* 回移于 [#32794](https://github.com/ClickHouse/ClickHouse/issues/32794)：修复对同一个 FixedString 多次使用 fuzzBits 时发生崩溃的问题，关闭 [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
* 回移于 [#33182](https://github.com/ClickHouse/ClickHouse/issues/33182)：如果使用 `MySQL` engine 的数据库无法连接到 MySQL 服务器，server 可能启动失败；现已修复。修复了 [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441)。[#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 回移于 [#33655](https://github.com/ClickHouse/ClickHouse/issues/33655)：修复 hdfs URL 检查不允许使用 HA namenode 地址的问题。该缺陷由 [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042) 引入。[#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
