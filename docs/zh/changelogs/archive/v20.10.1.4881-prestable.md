<div id="clickhouse-release-v201014881-prestable-fixme-as-compared-to-v20914585-prestable">
  ### ClickHouse 发布 v20.10.1.4881-prestable，相比 v20.9.1.4585-prestable 的 FIXME
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 在 SQL 中新增对嵌套多行注释 `/* comment /* comment */ */` 的支持。这符合 SQL 标准。[#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 `format_regexp_escaping_rule` 设置的默认值 (与 `Regexp` 格式相关) 更改为 `Raw` (即将整个子模式作为一个值读取) ，使其行为更符合用户预期。[#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 `multiple_joins_rewriter_version` 标记为已废弃，并移除 joins rewriter 的第一个版本。[#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### 新特性
</div>

* 支持 MySQL 类型：`decimal` (映射为 ClickHouse `Decimal`) 以及具有子秒级精度的 `datetime` (映射为 `DateTime64`) 。... [#11512](https://github.com/ClickHouse/ClickHouse/pull/11512) ([Vasily Nemkov](https://github.com/Enmk)).
* 允许在插入、合并和拉取操作时启用 fsync。[#11948](https://github.com/ClickHouse/ClickHouse/pull/11948) ([Anton Popov](https://github.com/CurtizJ)).
* 保障集群间查询执行的安全性 (将 initial&#95;user 用作当前查询用户) 。[#13156](https://github.com/ClickHouse/ClickHouse/pull/13156) ([Azat Khuzhin](https://github.com/azat)).
* * 新增 `mapPopulateSeries` 函数。[#13166](https://github.com/ClickHouse/ClickHouse/pull/13166) ([Ildus Kurbangaliev](https://github.com/ildus)) 。
* 允许用户在 config file 的 `<replicated_merge_tree>` 部分为 `ReplicatedMergeTree*` 存储指定 settings。其工作方式与 `<merge_tree>` 部分类似。对于 `ReplicatedMergeTree*` 存储，来自 `<merge_tree>` 和 `<replicated_merge_tree>` 的 settings 会同时生效，但 `<replicated_merge_tree>` 中的 settings 优先级更高。新增了 `system.replicated_merge_tree_settings` 表。[#13573](https://github.com/ClickHouse/ClickHouse/pull/13573) ([Amos Bird](https://github.com/amosbird)).
* 添加新特性：format LineAsString，可接受由换行、空格和/或逗号分隔的 line 序列。[#13846](https://github.com/ClickHouse/ClickHouse/pull/13846) ([hexiaoting](https://github.com/hexiaoting)).
* 为 distributed queries 新增查询复杂度限制 settings `max_rows_to_read_leaf`、`max_bytes_to_read_leaf`，用于限制 leaf nodes 上读取的最大行数/字节数。该限制仅适用于本地读取，**不包括** root node 上最终的 merge 阶段。[#14221](https://github.com/ClickHouse/ClickHouse/pull/14221) ([Roman Khavronenko](https://github.com/hagen1778)).
* 添加 JSONStrings formats，以字符串数组的形式输出数据。[#14333](https://github.com/ClickHouse/ClickHouse/pull/14333) ([hcz](https://github.com/hczhcz)).
* 现在，insert statements 可以在列列表中使用带列转换器的 asterisk (或 Variant) 。[#14453](https://github.com/ClickHouse/ClickHouse/pull/14453) ([Amos Bird](https://github.com/amosbird)).
* 新增了一个用于将 git repository 导入 ClickHouse 的 script。[#14471](https://github.com/ClickHouse/ClickHouse/pull/14471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 MergeTree 表引擎家族添加了指定 `TTL ... RECOMPRESS codec_name` 的能力。[#14494](https://github.com/ClickHouse/ClickHouse/pull/14494) ([alesapin](https://github.com/alesapin)).
* 向 `system.asynchronous_metric_log` 和 `system.metric_log` 表中添加了 `event_time_microseconds`。[#14514](https://github.com/ClickHouse/ClickHouse/pull/14514) ([Bharat Nallan](https://github.com/bharatnc)).
* 添加新特性：SHOW DATABASES LIKE &#39;xxx&#39;。[#14521](https://github.com/ClickHouse/ClickHouse/pull/14521) ([hexiaoting](https://github.com/hexiaoting)).
* MaterializedMySQL 现已支持 Decimal data type。[#14535](https://github.com/ClickHouse/ClickHouse/pull/14535) ([Winter Zhang](https://github.com/zhang2014)).
* 允许为 TSV output format 配置 NULL 表示形式。它由 setting `output_format_tsv_null_representation` 控制，默认值为 `\N`。这解决了 [#9375](https://github.com/ClickHouse/ClickHouse/issues/9375)。请注意，该 setting 仅控制 output format，而 `\N` 是 TSV input format 唯一支持的 NULL 表示形式。[#14586](https://github.com/ClickHouse/ClickHouse/pull/14586) ([Kruglov Pavel](https://github.com/Avogar)).
* 添加新特性：format LineAsString，可接受由换行、空格和/或逗号分隔的 line 序列。[#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 新增了 `formatReadableQuantity` function，有助于人们更直观地阅读大数值。[#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* 添加了移除列属性和表生存时间 (TTL) 的能力。引入了 queries `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` 和 `ALTER TABLE REMOVE TTL`。这两种操作都是 lightweight 的，并且在 metadata 层执行。[#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* 在 `system.text_log`、`system.trace_log`、`system.query_log` 和 `system.query_thread_log` 表中新增 `event_time_microseconds` 字段。[#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* 现在支持使用 `WITH <identifier> AS (subquery) ... ` 在查询上下文中引入命名子查询。此项关闭了 [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416)。此项关闭了 [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967)。[#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* 如果 config 中指定了默认值，则允许省略 Replicated 表引擎的参数。[#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* 新增表函数 `null('structure')`。[#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* 新增查询混淆工具。它允许共享更多查询，以便开展更充分的测试。此项关闭了 [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268)。[#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新增 `RawBLOB` format。它用于在不进行任何转义和分隔符处理的情况下输入或输出单个值。此项关闭了 [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349)。[#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了 [15350](https://github.com/ClickHouse/ClickHouse/issues/15350)。[#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* 引入 `enable_global_with_statement` 设置，可将第一个 select 的 `WITH` 语句传播到同一级别的其他 select 查询，并使 `WITH` 语句中的别名对子查询可见。[#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* 新增 `reinterpretAsUUID` 函数，可将大端序字节字符串转换为 UUID。[#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 新增并行 quorum 插入。此项关闭了 [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601)。[#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### 性能提升
</div>

* 默认对小型 parts 启用 compact parts。这将使高频插入操作的处理效率略有提升 (4..100 倍) 。[#11913](https://github.com/ClickHouse/ClickHouse/pull/11913) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 使用 `uint64_t`/`int64_t` 作为宽整数的基本类型，提升 256 位字节处理性能。原始宽整数使用 8 位类型作为基本类型。[#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)) 。
* 启动 clickhouse-server 时仅锁定 `mlock` 代码段。在之前的版本中，所有映射区域都会被锁定在内存中，包括调试信息。调试信息通常会拆分到单独的文件中，但如果没有，就会导致内存使用量额外增加 2..3 GiB。[#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 过去，我们会选择 fixed key method 来按单个固定字符串进行分组。但这其实没有必要，因为我们有 StringHashTable，它会对 FixedString 列执行类似的 packedFix 优化。而且在可能的情况下，应使用 low&#95;cardinality&#95;key&#95;fixed&#95;string。[#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)) 。
* 修复了 `DateTime <op> DateTime` 误选较慢通用实现的问题。此修复解决了 [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153)。[#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)) 。
* 使用单个 S3 DeleteObjects 请求来替代循环中的多个 DeleteObject。功能没有任何变化，因此现有测试 (如 integration/test&#95;log&#95;family&#95;s3) 已可覆盖。[#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)) 。
* 提升了 256 位乘法的速度。[#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)) 。
* 提升 `quantileTDigest` 的性能。此修复解决了 [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668)。[#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 明确使用临时磁盘来存储 vertical merge 的临时数据。[#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)) 。



<div id="improvement">
  #### 改进
</div>

* 当重复块被写入某个副本，而该副本本地尚不存在该块时 (即尚未从其他副本拉取) ，不再忽略该块，而是将其写入本地，以达到与成功复制相同的效果。[#11684](https://github.com/ClickHouse/ClickHouse/pull/11684) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在 compact parts 中支持自定义编解码器。[#12183](https://github.com/ClickHouse/ClickHouse/pull/12183) ([Anton Popov](https://github.com/CurtizJ)).
* 现在 joinGet 支持多键查找。这是 [#12418](https://github.com/ClickHouse/ClickHouse/issues/12418) 的后续工作。[#13015](https://github.com/ClickHouse/ClickHouse/pull/13015) ([Amos Bird](https://github.com/amosbird)).
* 对于采用 VALUES 格式且包含内联数据的 INSERT，除换行外，现在还支持使用分号作为数据结束符。关闭了 [#12288](https://github.com/ClickHouse/ClickHouse/issues/12288)。[#13192](https://github.com/ClickHouse/ClickHouse/pull/13192) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* SYSTEM RELOAD CONFIG 现在在重新加载失败时会抛出异常，并继续使用之前的 users.xml。后台的周期性重新加载如果失败，也会继续使用之前的 users.xml。[#14492](https://github.com/ClickHouse/ClickHouse/pull/14492) ([Vitaly Baranov](https://github.com/vitlibar)).
* 为 DiskS3 添加了一个可跳过访问检查的选项。[#14497](https://github.com/ClickHouse/ClickHouse/pull/14497) ([Pavel Kovalenko](https://github.com/Jokser)).
* ClickHouse 对 partition expr 和 key expr 的处理方式不同。partition expr 用于构建包含相关列的 minmax 索引，而主键 expr 则以 expr 的形式存储。有时，用户可能会按更粗的粒度对表进行分区，例如 `partition by i / 1000`。但 binary operators 不具备单调性，这个 PR 尝试修复该问题。它也可能对其他用例有帮助。[#14513](https://github.com/ClickHouse/ClickHouse/pull/14513) ([Amos Bird](https://github.com/amosbird)).
* 修复了查询 format 中的一些尾随空白。[#14595](https://github.com/ClickHouse/ClickHouse/pull/14595) ([Azat Khuzhin](https://github.com/azat)).
* 添加了 `QueryMemoryLimitExceeded` 事件。此更改关闭了 [#14589](https://github.com/ClickHouse/ClickHouse/issues/14589)。[#14647](https://github.com/ClickHouse/ClickHouse/pull/14647) ([fastio](https://github.com/fastio)).
* 通过提供不带函数调试信息进行构建的选项，修复了这一不向后兼容的变更。[#14657](https://github.com/ClickHouse/ClickHouse/pull/14657) ([Mike Kot](https://github.com/myrrc)).
* 支持动态重新加载 ZooKeeper 配置。[#14678](https://github.com/ClickHouse/ClickHouse/pull/14678) ([sundyli](https://github.com/sundy-li)).
* 允许并行执行 distributed DDL。[#14684](https://github.com/ClickHouse/ClickHouse/pull/14684) ([Azat Khuzhin](https://github.com/azat)).
* 修复了由 ZooKeeper exists watch 导致的潜在内存泄漏。[#14693](https://github.com/ClickHouse/ClickHouse/pull/14693) ([hustnn](https://github.com/hustnn)).
* 修复了 `MaterializeMySQL` database engine 中的“Packet payload is not fully read”错误。[#14696](https://github.com/ClickHouse/ClickHouse/pull/14696) ([BohuTANG](https://github.com/BohuTANG)).
* 修复了 `bitShiftLeft()` 在传入负的大整数时可能发生崩溃的问题。[#14697](https://github.com/ClickHouse/ClickHouse/pull/14697) ([Artem Zuikov](https://github.com/4ertus2)).
* 向 system.merges 表添加了 `merge_algorithm`，以便更好地检查合并情况。[#14705](https://github.com/ClickHouse/ClickHouse/pull/14705) ([Amos Bird](https://github.com/amosbird)).
* FunctionBinaryArithmetic 中的 DecimalBinaryOperation 模板生成的冗余代码更少了。[#14743](https://github.com/ClickHouse/ClickHouse/pull/14743) ([Artem Zuikov](https://github.com/4ertus2)).
* 现在可以使用 columns 包装一组列，并在之后应用列转换器。[#14775](https://github.com/ClickHouse/ClickHouse/pull/14775) ([Amos Bird](https://github.com/amosbird)).
* 支持为 StorageJoin 和 StorageSet 禁用持久化，该功能由设置 `disable_set_and_join_persistency` 控制。此 PR 还解决了问题 [#6318](https://github.com/ClickHouse/ClickHouse/issues/6318)。[#14776](https://github.com/ClickHouse/ClickHouse/pull/14776) ([vxider](https://github.com/Vxider)).
* `query_start_time` 和 `query_start_time_microseconds` 现基于同一个 timespec 构造。[#14831](https://github.com/ClickHouse/ClickHouse/pull/14831) ([Bharat Nallan](https://github.com/bharatnc)).
* 允许在 Distributed 存储中使用 multi-volume storage configuration。[#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
* 在 `EXPLAIN` 结果中显示 `SET` 和 `JOIN` 的子查询。[#14856](https://github.com/ClickHouse/ClickHouse/pull/14856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 新增 `load_balancing_first_offset` 查询设置，可显式指定第一个副本。它与 `FIRST_OR_RANDOM` 负载均衡策略配合使用，从而能够控制副本负载。[#14867](https://github.com/ClickHouse/ClickHouse/pull/14867) ([Amos Bird](https://github.com/amosbird)).
* 修复了从分布式表执行带 SETTINGS 的 SELECT 时，过度触发 settings 约束违规的问题。[#14876](https://github.com/ClickHouse/ClickHouse/pull/14876) ([Amos Bird](https://github.com/amosbird)).
* 如果之前的 drop 尝试因 ZooKeeper session 过期而失败，现在也允许 drop Replicated 表。此项修复了 [#11891](https://github.com/ClickHouse/ClickHouse/issues/11891)。[#14926](https://github.com/ClickHouse/ClickHouse/pull/14926) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 避免了对使用 `TinyLog` 或 `Log` 表引擎的表执行 INSERT SELECT 自写入时发生死锁。此项关闭了 [#6802](https://github.com/ClickHouse/ClickHouse/issues/6802)。[#14962](https://github.com/ClickHouse/ClickHouse/pull/14962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 执行 mutations 时会忽略 key 约束。没有这个 PR，在 `force_index_by_date = 1` 或 `force_primary_key = 1` 时将无法执行 mutations。[#14973](https://github.com/ClickHouse/ClickHouse/pull/14973) ([Amos Bird](https://github.com/amosbird)).
* 新增了在插入数据分区片段时禁用 TTL move 的选项。[#15000](https://github.com/ClickHouse/ClickHouse/pull/15000) ([Pavel Kovalenko](https://github.com/Jokser)).
* 默认启用 `Atomic` database engine。[#15003](https://github.com/ClickHouse/ClickHouse/pull/15003) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 为 CAST 的 arguments 数量错误提供了更恰当的异常消息。此项关闭了 [#13992](https://github.com/ClickHouse/ClickHouse/issues/13992)。[#15029](https://github.com/ClickHouse/ClickHouse/pull/15029) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 增加了为具有子类型的列指定专用编解码器 (如 `Delta`、`T64` 等) 的能力。实现了 [#12551](https://github.com/ClickHouse/ClickHouse/issues/12551)，修复了 [#11397](https://github.com/ClickHouse/ClickHouse/issues/11397) 和 [#4609](https://github.com/ClickHouse/ClickHouse/issues/4609)。[#15089](https://github.com/ClickHouse/ClickHouse/pull/15089) ([alesapin](https://github.com/alesapin)).
* 为 `EXPLAIN PLAN` 查询添加了 `optimize` 设置。启用后，将应用查询计划级别的优化。该设置默认启用。[#15201](https://github.com/ClickHouse/ClickHouse/pull/15201) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 在 `/docker-entrypoint-initdb.d/` 中的所有脚本执行完毕之前，不允许连接到 ClickHouse server。[#15244](https://github.com/ClickHouse/ClickHouse/pull/15244) ([Aleksei Kozharin](https://github.com/alekseik1)).
* 修复了 [15264](https://github.com/ClickHouse/ClickHouse/issues/15264)。[#15285](https://github.com/ClickHouse/ClickHouse/pull/15285) ([flynn](https://github.com/ucasfl)).
* 在创建复制表时，展开 `zookeeper_path` 中的 `{database}`、`{table}` 和 `{uuid}` 宏。如果 `RENAME TABLE` 可能在 server 重启后破坏 `zookeeper_path`，则不允许执行。修复了 [#6917](https://github.com/ClickHouse/ClickHouse/issues/6917)。[#15348](https://github.com/ClickHouse/ClickHouse/pull/15348) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 为 `Regexp` 格式添加了对 &quot;Raw&quot; 列格式的支持。它允许直接完整提取子模式，而无需任何转义规则。[#15363](https://github.com/ClickHouse/ClickHouse/pull/15363) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 现在可以通过 `ALTER` 查询更改 `VersionedCollapsingMergeTree` 的版本列类型。[#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).
* 对于 `Atomic` database，如果指定了 `NO DELAY` 或 `SYNC`，则会等待 `DROP/DETACH TABLE` 实际完成。[#15448](https://github.com/ClickHouse/ClickHouse/pull/15448) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 通过启用 cluster-secure 的 Distributed 透传 *&#95;for&#95;user 设置。[#15551](https://github.com/ClickHouse/ClickHouse/pull/15551) ([Azat Khuzhin](https://github.com/azat)).
* 默认使用 Experimental pass manager。[#15608](https://github.com/ClickHouse/ClickHouse/pull/15608) ([Daniel Kutenin](https://github.com/danlark1)).
* 实现了 `force_data_skipping_indices` 设置。[#15642](https://github.com/ClickHouse/ClickHouse/pull/15642) ([Azat Khuzhin](https://github.com/azat)).
