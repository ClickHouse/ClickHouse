<div id="clickhouse-release-v208144-lts-fixme-as-compared-to-v2081315-lts">
  ### ClickHouse 发布版本 v20.8.14.4-长期支持版 FIXME (与 v20.8.13.15-长期支持版 相比)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#21235](https://github.com/ClickHouse/ClickHouse/issues/21235) 中回移：现在可以通过 mysql 副本配置部分中的 &quot;opt&#95;reconnect&quot; 参数来控制 MYSQL&#95;OPT&#95;RECONNECT 选项的值。[#19998](https://github.com/ClickHouse/ClickHouse/pull/19998) ([Alexander Kazakov](https://github.com/Akazz)) 。
* 已在 [#21203](https://github.com/ClickHouse/ClickHouse/issues/21203) 中回移：加载 mysql 源的配置时，ClickHouse 现在会随机打乱具有相同优先级的副本列表，以确保选择 mysql 端点时的轮询逻辑正常工作。此更改关闭了 [#20629](https://github.com/ClickHouse/ClickHouse/issues/20629)。[#20632](https://github.com/ClickHouse/ClickHouse/pull/20632) ([Alexander Kazakov](https://github.com/Akazz)) 。
* 已在 [#21336](https://github.com/ClickHouse/ClickHouse/issues/21336) 中回移：MySQL 字典源现在会在出现异常连接失败 (Lost connection to MySQL server during query) 时进行重试，这种情况有时会发生在 SSL/TLS 连接上。[#21237](https://github.com/ClickHouse/ClickHouse/pull/21237) ([Alexander Kazakov](https://github.com/Akazz)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#20950](https://github.com/ClickHouse/ClickHouse/issues/20950) 中回移：修复子查询中存在 const 列时 set 索引失效的问题。此修复解决了 [#17246](https://github.com/ClickHouse/ClickHouse/issues/17246)。[#17249](https://github.com/ClickHouse/ClickHouse/pull/17249) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#20948](https://github.com/ClickHouse/ClickHouse/issues/20948) 中回移：修复从包含 `LowCardinality` 类型的 `JOIN` 表读取时发生崩溃的问题。修复了 [#17228](https://github.com/ClickHouse/ClickHouse/issues/17228)。[#17397](https://github.com/ClickHouse/ClickHouse/pull/17397) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#20903](https://github.com/ClickHouse/ClickHouse/issues/20903) 中回移：修复将 `LowCardinality` 列插入使用 `TinyLog` engine 的表时出现的问题。修复了 [#18629](https://github.com/ClickHouse/ClickHouse/issues/18629)。[#19010](https://github.com/ClickHouse/ClickHouse/pull/19010) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#20899](https://github.com/ClickHouse/ClickHouse/issues/20899) 中回移：修复并发执行 `ALTER` 和 `DROP` 查询时，处理 ReplicatedMergeTree 表可能发生挂起的问题。[#19237](https://github.com/ClickHouse/ClickHouse/pull/19237) ([alesapin](https://github.com/alesapin)).
* 已在 [#20892](https://github.com/ClickHouse/ClickHouse/issues/20892) 中回移：修复断开连接后 Connection 中 CompressedWriteBuffer 被释放后仍继续使用的问题。[#19599](https://github.com/ClickHouse/ClickHouse/pull/19599) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#20888](https://github.com/ClickHouse/ClickHouse/issues/20888) 中回移：修复一个罕见问题，即数据损坏后，某些 replicated 操作 (如变更) 无法处理某些 parts。修复了 [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593)。[#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)).
* 已在 [#21049](https://github.com/ClickHouse/ClickHouse/issues/21049) 中回移：修复在 aggregate functions 中使用 `-Distinct` 组合器和 `-State` 组合器时的问题。[#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#21130](https://github.com/ClickHouse/ClickHouse/issues/21130) 中回移：修复 `ALTER MODIFY COLUMN` 会创建一个注定失败的变更这一行为。[#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#21159](https://github.com/ClickHouse/ClickHouse/issues/21159) 中回移：修复 `input_format_null_as_default` 在类型为 Nullable 时生效的问题。此修复解决了 [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116)。[#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#21378](https://github.com/ClickHouse/ClickHouse/issues/21378) 中回移：修复从 `Values` 格式向包含 `LowCardinality` 列的表插入数据时出现错误 `Bad cast from type ... to DB::ColumnLowCardinality` 的问题。修复了 [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140)。[#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
