<div id="bug-fix">
  #### 缺陷修复
</div>

* 在 [#24567](https://github.com/ClickHouse/ClickHouse/issues/24567) 中回移：当旧版 modulo 函数用于分区键时，改为使用该函数的旧版本。关闭 [#23508](https://github.com/ClickHouse/ClickHouse/issues/23508)。[#24157](https://github.com/ClickHouse/ClickHouse/pull/24157) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 在 [#24367](https://github.com/ClickHouse/ClickHouse/issues/24367) 中回移：将 `max_threads = 1` 以修复 StorageMemory 的变更失败问题。关闭 [#24274](https://github.com/ClickHouse/ClickHouse/issues/24274)。[#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)) 。
* 在 [#24383](https://github.com/ClickHouse/ClickHouse/issues/24383) 中回移：允许空的 HTTP 请求头。修复 [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901)。[#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)) 。
* 在 [#24365](https://github.com/ClickHouse/ClickHouse/issues/24365) 中回移：修复了通过 `RENAME TABLE` 查询将 Materialized View 从 Ordinary 数据库移动到 Atomic 数据库时的一个缺陷。现在内部表会随 Materialized View 一起移动到新数据库。修复 [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926)。[#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 在 [#24510](https://github.com/ClickHouse/ClickHouse/issues/24510) 中回移：修复了带有 intersect 伪 parts 的删除分区问题。在极少数情况下，可能会出现变更版本高于当前块编号的 parts。[#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)) 。
* 在 [#24542](https://github.com/ClickHouse/ClickHouse/issues/24542) 中回移：修复了 toWeek 函数单调性不正确的问题，从而修复了 [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422)。该缺陷是在 [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212) 中引入的，后来被更智能的分区裁剪器暴露出来。[#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)) 。
* 在 [#24556](https://github.com/ClickHouse/ClickHouse/issues/24556) 中回移：修复了查询 `SYSTEM RESTART REPLICA` 或 `SYSTEM SYNC REPLICA` 无限处理的问题。该问题是在 RAM 极少的服务器上发现的。[#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 在 [#24597](https://github.com/ClickHouse/ClickHouse/issues/24597) 中回移：修复了 `CREATE .. AS SELECT` 查询中 Tuple 的使用问题。[#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)) 。
* 在 [#24600](https://github.com/ClickHouse/ClickHouse/issues/24600) 中回移：启用了对分布式表子列的读取。[#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)) 。
