<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#38241](https://github.com/ClickHouse/ClickHouse/issues/38241) 中回移：修复了从配置中移除副本时，`Distributed` async insert 可能崩溃的问题。[#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#39098](https://github.com/ClickHouse/ClickHouse/issues/39098) 中回移：OvercommitTracker 内部的任何内存分配都可能导致死锁。由于日志信息帮助不大，因此直接移除日志更简单。修复了 [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794)。[#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd))。
* 已在 [#39078](https://github.com/ClickHouse/ClickHouse/issues/39078) 中回移：修复了文件系统缓存中的一个缺陷，该问题可能在某些边缘场景下出现，并且恰好发生在缓存容量达到上限时。关闭了 [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066)。[#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 已在 [#39152](https://github.com/ClickHouse/ClickHouse/issues/39152) 中回移：修复了对附加了 MATERIALIZED VIEW 且启用了设置 `extremes = 1` 的表执行 INSERT 时，可能出现的错误 `Block structure mismatch`。关闭了 [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) 和 [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729)。[#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#39274](https://github.com/ClickHouse/ClickHouse/issues/39274) 中回移：修复了带有 `PREWHERE` 和按顺序读取优化的 SELECT 查询中出现的错误 `Not found column Type in block`。[#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* 已在 [#39369](https://github.com/ClickHouse/ClickHouse/issues/39369) 中回移：声明 RabbitMQ 队列时，不使用默认参数 `x-max-length` 和 `x-overflow`。[#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko))。
* 已在 [#39350](https://github.com/ClickHouse/ClickHouse/issues/39350) 中回移：修复了 PostgreSQL 数据库引擎拉取 PostgreSQL 表时使用错误查询的问题。关闭了 [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502)。[#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii))。
