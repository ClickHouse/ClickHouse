<div id="improvement">
  #### 改进
</div>

* 已在 [#46983](https://github.com/ClickHouse/ClickHouse/issues/46983) 中回移：- 让 `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` 在所有副本上执行，因为 `ALTER TABLE t MOVE` 不会同步到副本。[#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中的用户可见异常表现)
</div>

* 已在 [#45729](https://github.com/ClickHouse/ClickHouse/issues/45729) 中回移：修复遇到重复主键时键描述不正确的问题。这种情况可能发生在投影中。详见 [#45590](https://github.com/ClickHouse/ClickHouse/issues/45590)。[#45686](https://github.com/ClickHouse/ClickHouse/pull/45686) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#46398](https://github.com/ClickHouse/ClickHouse/issues/46398) 中回移：修复 `SYSTEM UNFREEZE` 查询因异常 `CANNOT_PARSE_INPUT_ASSERTION_FAILED` 而失败的问题。[#46325](https://github.com/ClickHouse/ClickHouse/pull/46325) ([Aleksei Filatov](https://github.com/aalexfvk)) 。
* 已在 [#46903](https://github.com/ClickHouse/ClickHouse/issues/46903) 中回移：- 修复 QueryNormalizer 中错误的别名递归问题。[#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#47210](https://github.com/ClickHouse/ClickHouse/issues/47210) 中回移：在某些情况下，通过原生 TCP 协议和 HTTP 协议执行的 `INSERT` 查询无法被正确取消。如果客户端取消了查询、客户端退出，或者在少数情况下发生网络错误，就可能导致查询只部分生效，进而导致去重失效。修复了 [#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) 和 [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377)。[#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#47157](https://github.com/ClickHouse/ClickHouse/issues/47157) 中回移：- 修复使用 `min` 和 `max` 时聚合优化中的算术运算问题。[#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)) 。
* 已在 [#46881](https://github.com/ClickHouse/ClickHouse/issues/46881) 中回移：修复 `maxIntersections` 函数中的 MSan 报告。此修复关闭了 [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126)。[#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#47359](https://github.com/ClickHouse/ClickHouse/issues/47359) 中回移：修复分布式查询取消时可能发生死锁的问题。[#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)) 。
