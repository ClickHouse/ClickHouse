<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#60413](https://github.com/ClickHouse/ClickHouse/issues/60413) 中回移：修复当输入查询超过 `max_query_size` 时 KQL parser 中发生的段错误，同时重新启用 KQL dialect。修复了 [#59036](https://github.com/ClickHouse/ClickHouse/issues/59036) 和 [#59037](https://github.com/ClickHouse/ClickHouse/issues/59037)。[#59626](https://github.com/ClickHouse/ClickHouse/pull/59626) ([Yong Wang](https://github.com/kashwy)) 。
* 已在 [#60074](https://github.com/ClickHouse/ClickHouse/issues/60074) 中回移：修复 `AsynchronousBoundedReadBuffer` 报错 `Read beyond last offset` 的问题。[#59630](https://github.com/ClickHouse/ClickHouse/pull/59630) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#60299](https://github.com/ClickHouse/ClickHouse/issues/60299) 中回移：修复消息既未 ack 也未 nack 的问题。如果在 read-write 阶段发生异常，消息将被 nack。[#59775](https://github.com/ClickHouse/ClickHouse/pull/59775) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#60066](https://github.com/ClickHouse/ClickHouse/issues/60066) 中回移：修复 optimize&#95;uniq&#95;to&#95;count 会移除列别名的问题。[#60026](https://github.com/ClickHouse/ClickHouse/pull/60026) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#60638](https://github.com/ClickHouse/ClickHouse/issues/60638) 中回移：修复带有 `FINAL` 的查询在并行优化中的一个 bug，该问题在极少数情况下可能导致结果不正确。[#60041](https://github.com/ClickHouse/ClickHouse/pull/60041) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#60177](https://github.com/ClickHouse/ClickHouse/issues/60177) 中回移：修复 cosineDistance 在 Nullable 类型上的崩溃问题。[#60150](https://github.com/ClickHouse/ClickHouse/pull/60150) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#60279](https://github.com/ClickHouse/ClickHouse/issues/60279) 中回移：隐藏 `S3Queue` 表 engine 的敏感信息。[#60233](https://github.com/ClickHouse/ClickHouse/pull/60233) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#61000](https://github.com/ClickHouse/ClickHouse/issues/61000) 中回移：减少从 `system.numbers` 读取的行数。修复了 [#59418](https://github.com/ClickHouse/ClickHouse/issues/59418)。[#60546](https://github.com/ClickHouse/ClickHouse/pull/60546) ([JackyWoo](https://github.com/JackyWoo)) 。
* 已在 [#60791](https://github.com/ClickHouse/ClickHouse/issues/60791) 中回移：修复一种可能发生的缓冲区溢出：当攻击者要求 HTTP server 解压使用 codecs 组合且大小会触发数值溢出的数据时，可能出现该问题。另修复 codec NONE 在错误输入数据下内部可能发生的缓冲区溢出。该问题由 TIANGONG 研究团队通过我们的 [Bug Bounty program](https://github.com/ClickHouse/ClickHouse/issues/38986) 提交。[#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#60783](https://github.com/ClickHouse/ClickHouse/issues/60783) 中回移：用于 SQL/JSON 的 Functions 可能会读取未初始化的内存。此项关闭了 [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017)。由 Fuzzer 发现。[#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#60803](https://github.com/ClickHouse/ClickHouse/issues/60803) 中回移：不要在 UploadPart 和 CompleteMultipartUpload 调用中设置 aws 自定义 metadata `x-amz-meta-*` 请求头。[#60748](https://github.com/ClickHouse/ClickHouse/pull/60748) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)) 。
* 已在 [#60820](https://github.com/ClickHouse/ClickHouse/issues/60820) 中回移：修复 arrayEnumerateRanked 中的崩溃问题。[#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#60841](https://github.com/ClickHouse/ClickHouse/issues/60841) 中回移：修复在 INSERT SELECT JOIN 中使用 input() 时发生的崩溃问题。关闭 [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035)。[#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#60904](https://github.com/ClickHouse/ClickHouse/issues/60904) 中回移：避免在从 S3 读取时因跳过过多键而发生段错误。[#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)).
