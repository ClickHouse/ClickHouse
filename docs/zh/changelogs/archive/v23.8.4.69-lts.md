<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 在 [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673) 中回移：如果数据库已经初始化，后续启动时无需再次初始化。这可能修复数据库在 1000 次尝试内未能加载时容器无限重启的问题 (与超大数据库和多节点部署相关) 。[#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* 在 [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293) 中回移：在 Darwin 特殊构建任务中构建了包含子模块的源代码资源。这样无需检出子模块也能构建 ClickHouse。[#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* 在 [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366) 中回移：解决了从 clickhouse-server 软件包启动独立 clickhouse-keeper 时的问题。[#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 在 [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725) 中回移：修复集成检查 Python 脚本，使其使用 gh API URL，并为 CI 测试添加 README。[#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#55304](https://github.com/ClickHouse/ClickHouse/issues/55304) 中回移：修复 MaterializedPostgreSQL 中的“Chunk 中的行数无效”问题 (可能会在 PostgreSQL 版本 &gt;= 13 时发生) 。[#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#55018](https://github.com/ClickHouse/ClickHouse/issues/55018) 中回移：将已废弃的 format settings 移至单独的章节，并与所有 format settings 一并使用，以避免在使用已废弃的 format settings 时出现 `Unknown setting` 异常。关闭 [#54792](https://github.com/ClickHouse/ClickHouse/issues/54792) ### 面向用户变更的文档条目。[#54855](https://github.com/ClickHouse/ClickHouse/pull/54855) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#55097](https://github.com/ClickHouse/ClickHouse/issues/55097) 中回移：在等待 quorum 期间，如果发生 Keeper 重试，Insert quorum 可能会被错误地标记为已满足。修复 [#54543](https://github.com/ClickHouse/ClickHouse/issues/54543)。[#55026](https://github.com/ClickHouse/ClickHouse/pull/55026) ([Igor Nikonov](https://github.com/devcrafter)).
* 已在 [#55473](https://github.com/ClickHouse/ClickHouse/issues/55473) 中回移：禁止从未定义相同 indices 或 projections 的表附加分区。[#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#55461](https://github.com/ClickHouse/ClickHouse/issues/55461) 中回移：如果在 `ShellCommandSource` 构造函数中、部分 `send_data_threads` 已启动后发生异常，则需要对它们执行 join()，否则会在 `ThreadFromGlobalPool` destructor 中触发 abort()。修复 [#55091](https://github.com/ClickHouse/ClickHouse/issues/55091)。[#55103](https://github.com/ClickHouse/ClickHouse/pull/55103) ([Alexander Gololobov](https://github.com/davenger)).
* 已在 [#55412](https://github.com/ClickHouse/ClickHouse/issues/55412) 中回移：修复为不存在的 ClickHouse roles 更新 LDAP 分配角色时发生的死锁问题。[#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* 已在 [#55323](https://github.com/ClickHouse/ClickHouse/issues/55323) 中回移：修复 fs cache 中的后台下载问题。[#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#55349](https://github.com/ClickHouse/ClickHouse/issues/55349) 中回移：修复在稀疏列上执行函数时的问题 (修复 `DB::Exception: isDefaultAt is not implemented for Function: while executing 'FUNCTION Capture` 错误) 。[#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#55475](https://github.com/ClickHouse/ClickHouse/issues/55475) 中回移：修复基于 S3 的 `ReplicatedMergeTree` 引擎家族 (未使用 zero-copy replication) 中无法删除 detached 分区的问题。修复问题 [#55225](https://github.com/ClickHouse/ClickHouse/issues/55225)。修复 S3 上 Arrays 或 Nested 列等复杂 data types 的遗留 blobs 问题。部分修复 [#52393](https://github.com/ClickHouse/ClickHouse/issues/52393)。特别感谢 @alifirat 提供示例。[#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* 已在 [#55399](https://github.com/ClickHouse/ClickHouse/issues/55399) 中回移：一年前引入的一项优化是错误的。此变更关闭了 [#55272](https://github.com/ClickHouse/ClickHouse/issues/55272)。[#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#55437](https://github.com/ClickHouse/ClickHouse/issues/55437) 中回移：修复 cast 运算符 (`::`) 中数组解析的问题。[#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#55635](https://github.com/ClickHouse/ClickHouse/issues/55635) 中回移：修复查询中使用 OR 过滤条件按虚拟列筛选时的问题 (`MergeTree` 的 `_part*` 筛选、各种 `File`/`HDFS`/... 表引擎的 `_path`/`_file`，以及 `Merge` 的 `_table`) 。[#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat))。
