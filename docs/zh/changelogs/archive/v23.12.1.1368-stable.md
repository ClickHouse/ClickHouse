<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 修复了对生存时间 (TTL) 表达式中非确定性函数的检查。此前，在某些情况下可以使用非确定性函数创建生存时间 (TTL) 表达式，这可能会在后续导致未定义行为。此更改修复了 [#37250](https://github.com/ClickHouse/ClickHouse/issues/37250)。现在默认禁止不依赖表中任何列的生存时间 (TTL) 表达式。可以通过 `SET allow_suspicious_ttl_expressions = 1` 或 `SET compatibility = '23.11'` 重新允许。关闭了 [#37286](https://github.com/ClickHouse/ClickHouse/issues/37286)。[#51858](https://github.com/ClickHouse/ClickHouse/pull/51858) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 由于函数 `arrayFold` 存在缺陷，现已将其移除。此更改关闭了 [#57816](https://github.com/ClickHouse/ClickHouse/issues/57816)。此更改关闭了 [#57458](https://github.com/ClickHouse/ClickHouse/issues/57458)。[#57836](https://github.com/ClickHouse/ClickHouse/pull/57836) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 移除了 ReplacingMergeTree 中 `is_deleted` 行功能，以及用于 OPTIMIZE 查询的 `CLEANUP` 修饰符。此更改修复了 [#57930](https://github.com/ClickHouse/ClickHouse/issues/57930)。此更改关闭了 [#54988](https://github.com/ClickHouse/ClickHouse/issues/54988)。此更改关闭了 [#54570](https://github.com/ClickHouse/ClickHouse/issues/54570)。此更改关闭了 [#50346](https://github.com/ClickHouse/ClickHouse/issues/50346)。此更改关闭了 [#47579](https://github.com/ClickHouse/ClickHouse/issues/47579)。之所以必须移除此功能，是因为它的设计存在问题，而且别无选择，只能尽快移除。[#57932](https://github.com/ClickHouse/ClickHouse/pull/57932) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree setting `clean_deleted_rows` 已废弃，且不再生效。默认不允许在 `OPTIMIZE` 中使用 `CLEANUP` 关键字 (除非启用了 `allow_experimental_replacing_merge_with_cleanup`) 。[#58267](https://github.com/ClickHouse/ClickHouse/pull/58267) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="new-feature">
  #### 新特性
</div>

* 允许禁用在 GET 请求前发送 HEAD 请求。[#54602](https://github.com/ClickHouse/ClickHouse/pull/54602) ([Fionera](https://github.com/fionera)).
* 新增一个 HTTP 端点，用于检查 Keeper 是否已准备好接收流量。[#55876](https://github.com/ClickHouse/ClickHouse/pull/55876) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 为 schema inference 新增 `union` 模式。在该模式下，生成的表 schema 是所有文件 schema 的并集 (即会从每个文件分别推断 schema) 。schema inference 的模式由设置 `schema_inference_mode` 控制，有两个可能的值：`default` 和 `union`。关闭了 [#55428](https://github.com/ClickHouse/ClickHouse/issues/55428)。[#55892](https://github.com/ClickHouse/ClickHouse/pull/55892) ([Kruglov Pavel](https://github.com/Avogar)).
* 新增设置 `input_format_csv_try_infer_numbers_from_strings`，允许在 CSV format 中从 String 推断出数值。关闭了 [#56455](https://github.com/ClickHouse/ClickHouse/issues/56455)。[#56859](https://github.com/ClickHouse/ClickHouse/pull/56859) ([Kruglov Pavel](https://github.com/Avogar)).
* 可刷新materialized view。[#56946](https://github.com/ClickHouse/ClickHouse/pull/56946) ([Michael Kolupaev](https://github.com/al13n321)).
* 增加了更多关于 database 和表数量的警告。[#57375](https://github.com/ClickHouse/ClickHouse/pull/57375) ([凌涛](https://github.com/lingtaolf)).
* 新增变更命令 `ALTER TABLE <table> APPLY DELETED MASK`，可强制应用由轻量级删除写入的 mask，并从磁盘中移除被标记为已删除的行。[#57433](https://github.com/ClickHouse/ClickHouse/pull/57433) ([Anton Popov](https://github.com/CurtizJ)).
* 新增 SQL 函数 `sqid`，用于生成 Sqids ([https://sqids.org/](https://sqids.org/)) ，示例：`SELECT sqid(125, 126)`。[#57512](https://github.com/ClickHouse/ClickHouse/pull/57512) ([Robert Schulze](https://github.com/rschu1ze)).
* 使用 `HASHED_ARRAY` (以及 `COMPLEX_KEY_HASHED_ARRAY`) layout 的字典现已像 `HASHED` 一样支持 `SHARDS`。[#57544](https://github.com/ClickHouse/ClickHouse/pull/57544) ([vdimir](https://github.com/vdimir)).
* 新增异步指标，用于表示内存中主键总字节数以及已分配的主键总字节数。[#57551](https://github.com/ClickHouse/ClickHouse/pull/57551) ([Bharat Nallan](https://github.com/bharatnc)).
* 表 system.dropped&#95;tables&#95;parts 包含 system.dropped&#95;tables 表的 parts (已删除但尚未移除的表) 。[#57555](https://github.com/ClickHouse/ClickHouse/pull/57555) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 新增 `FORMAT_BYTES`，作为 `formatReadableSize` 的别名。[#57592](https://github.com/ClickHouse/ClickHouse/pull/57592) ([Bharat Nallan](https://github.com/bharatnc)).
* 新增 SHA512&#95;256 函数。[#57645](https://github.com/ClickHouse/ClickHouse/pull/57645) ([Bharat Nallan](https://github.com/bharatnc)).
* 允许向 `s3` table function 传递可选的 SESSION&#95;TOKEN。[#57850](https://github.com/ClickHouse/ClickHouse/pull/57850) ([Shani Elharrar](https://github.com/shanielh)).
* `ORDER BY` 子句现已支持指定 `ALL`，这意味着 ClickHouse 会按 `SELECT` 子句中的所有列进行排序。示例：`SELECT col1, col2 FROM tab WHERE [...] ORDER BY ALL`。[#57875](https://github.com/ClickHouse/ClickHouse/pull/57875) ([zhongyuankai](https://github.com/zhongyuankai)).
* 新增了用于 punycode 编码/解码的函数：`punycodeEncode()` 和 `punycodeDecode()`。[#57969](https://github.com/ClickHouse/ClickHouse/pull/57969) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 此 PR 恢复了 `PASTE JOIN` 的实现，允许用户在不使用 `ON` 子句的情况下连接表。示例：&#96;&#96;&#96; SQL SELECT * FROM ( SELECT number AS a FROM numbers(2) ) AS t1 PASTE JOIN ( SELECT number AS a FROM numbers(2) ORDER BY a DESC ) AS t2. [#57995](https://github.com/ClickHouse/ClickHouse/pull/57995) ([Yarik Briukhovetskyi](https://github.com/yariks5s)) 。
* `/binary` 处理程序可打开一个可视化查看器，用于查看 ClickHouse 可执行文件中的符号。[#58211](https://github.com/ClickHouse/ClickHouse/pull/58211) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="performance-improvement">
  #### 性能提升
</div>

* 在 S3 磁盘之间复制时，改为使用 S3 服务端复制，而不是通过缓冲区中转。提升了 `BACKUP/RESTORE` 操作和 `clickhouse-disks copy` 命令的性能。[#56744](https://github.com/ClickHouse/ClickHouse/pull/56744) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* HashJoin 现已遵循 `max_joined_block_size_rows` 设置，不会为 `ALL JOIN` 生成过大的块。[#56996](https://github.com/ClickHouse/ClickHouse/pull/56996) ([vdimir](https://github.com/vdimir)).
* 更早释放聚合所用内存。这可以避免不必要的外部聚合。[#57691](https://github.com/ClickHouse/ClickHouse/pull/57691) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 提升了字符串序列化性能。[#57717](https://github.com/ClickHouse/ClickHouse/pull/57717) ([Maksim Kita](https://github.com/kitaisreal)).
* 为 `Merge` 引擎表支持 trivial count 优化。[#57867](https://github.com/ClickHouse/ClickHouse/pull/57867) ([skyoct](https://github.com/skyoct)).
* 在某些情况下优化了聚合性能。[#57872](https://github.com/ClickHouse/ClickHouse/pull/57872) ([Anton Popov](https://github.com/CurtizJ)).
* `hasAny()` 函数现在可以利用全文跳过索引。[#57878](https://github.com/ClickHouse/ClickHouse/pull/57878) ([Jpnock](https://github.com/Jpnock)).
* 函数 `if(cond, then, else)` (及其别名 `cond ? : then : else`) 已优化为使用无分支求值。[#57885](https://github.com/ClickHouse/ClickHouse/pull/57885) ([zhanglistar](https://github.com/zhanglistar)).
* 在 FINAL 处理期间，从 MergeTree 表中提取互不相交的 parts 范围。这样可以避免对这些互不相交的 parts 范围执行额外的 FINAL 逻辑。当相同主键的重复值较少时，性能几乎可与不使用 FINAL 时相当。在设置 `do_not_merge_across_partitions_select_final` 时，提升了 MergeTree FINAL 的读取性能。[#58120](https://github.com/ClickHouse/ClickHouse/pull/58120) ([Maksim Kita](https://github.com/kitaisreal)).
* 如果分区键表达式仅包含主键表达式中的列，MergeTree 会自动推断 `do_not_merge_across_partitions_select_final` 设置。[#58218](https://github.com/ClickHouse/ClickHouse/pull/58218) ([Maksim Kita](https://github.com/kitaisreal)).
* 提升了原生类型上 MIN 和 MAX 的执行速度。[#58231](https://github.com/ClickHouse/ClickHouse/pull/58231) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### 改进
</div>

* 使对分布式表的插入能够正确处理更新后的集群配置。当集群节点列表动态更新时，分布式表的 Directory Monitor 无法感知新节点，必须对 Directory Monitor 重新执行 re-node 后才能感知到它。[#42826](https://github.com/ClickHouse/ClickHouse/pull/42826) ([zhongyuankai](https://github.com/zhongyuankai)).
* 使用按需加载 system database 虚拟表的方式替代 `--no-system-tables`。[#55271](https://github.com/ClickHouse/ClickHouse/pull/55271) ([Azat Khuzhin](https://github.com/azat)).
* Clickhouse-test 现在会在单个测试用例中输出 case sn、当前时间和 case 名称。[#55710](https://github.com/ClickHouse/ClickHouse/pull/55710) ([guoxiaolong](https://github.com/guoxiaolongzte)).
* 不允许创建 merge 参数不一致的 replicated 表。[#56833](https://github.com/ClickHouse/ClickHouse/pull/56833) ([Duc Canh Le](https://github.com/canhld94)).
* 为文件系统缓存实现 SLRU cache policy。[#57076](https://github.com/ClickHouse/ClickHouse/pull/57076) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 在 `system.tables` 中显示未压缩大小，该值通过数据分区片段的 checksums 获取 [#56618](https://github.com/ClickHouse/ClickHouse/issues/56618)。[#57186](https://github.com/ClickHouse/ClickHouse/pull/57186) ([Chen Lixiang](https://github.com/chenlx0)).
* 为 `Distributed` tables 添加 `skip_unavailable_shards` 设置，其行为类似于对应的查询级设置。关闭 [#43666](https://github.com/ClickHouse/ClickHouse/issues/43666)。[#57218](https://github.com/ClickHouse/ClickHouse/pull/57218) ([Gagan Goel](https://github.com/tntnatbry)).
* 函数 `substring()` (别名：`substr`、`mid`) 现在可用于 `Enum` 类型。此前，第一个函数参数必须是 `String` 或 `FixedString` 类型的值。这提升了通过 MySQL interface 与 Tableau 等 3rd party 工具交互时的兼容性。[#57277](https://github.com/ClickHouse/ClickHouse/pull/57277) ([Serge Klochkov](https://github.com/slvrtrn)).
* 当表不存在时，提供更明确的提示信息。[#57342](https://github.com/ClickHouse/ClickHouse/pull/57342) ([Bharat Nallan](https://github.com/bharatnc)).
* 允许在查询时覆盖 `max_partition_size_to_drop` 和 `max_table_size_to_drop` 这两个 server settings。[#57452](https://github.com/ClickHouse/ClickHouse/pull/57452) ([Jordi Villar](https://github.com/jrdi)).
* 新增在连接 ZooKeeper server 时对 read-only 标志的支持 (修复 [#53749](https://github.com/ClickHouse/ClickHouse/issues/53749)) 。[#57479](https://github.com/ClickHouse/ClickHouse/pull/57479) ([Mikhail Koviazin](https://github.com/mkmkme)).
* 修复了由于 &quot;No such file or directory&quot; 导致分布式发送可能卡住的问题 (发生在从磁盘恢复批次期间) 。修复了 `system.distribution_queue` 中 `error_count` 的潜在问题 (当 `distributed_directory_monitor_max_sleep_time_ms` &gt;5min 时) 。引入了用于跟踪异步 INSERT 失败的 profile event：`DistributedAsyncInsertionFailures`。[#57480](https://github.com/ClickHouse/ClickHouse/pull/57480) ([Azat Khuzhin](https://github.com/azat)).
* background fetches 中每个端点的 connection 数量上限已从 `15` 提高到 `background_fetches_pool_size` 设置的值。- MergeTree 级设置 `replicated_max_parallel_fetches_for_host` 已废弃 - MergeTree 级设置 `replicated_fetches_http_connection_timeout`、`replicated_fetches_http_send_timeout` 和 `replicated_fetches_http_receive_timeout` 已迁移到 server 级。- 设置 `keep_alive_timeout` 已加入 server 级设置列表。[#57523](https://github.com/ClickHouse/ClickHouse/pull/57523) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 现在可以在索引 (非主键) 定义中引用 ALIAS 列 (见问题 [#55650](https://github.com/ClickHouse/ClickHouse/issues/55650)) 。示例：`CREATE TABLE tab(col UInt32, col_alias ALIAS col + 1, INDEX idx (col_alias) TYPE minmax) ENGINE = MergeTree ORDER BY col;`。[#57546](https://github.com/ClickHouse/ClickHouse/pull/57546) ([Robert Schulze](https://github.com/rschu1ze)).
* 函数 `format()` 现在支持任意类型的参数 (不再仅限于 `String` 和 `FixedString` 参数) 。这对于计算 `SELECT format('The {0} to all questions is {1}', 'answer', 42)` 很重要。[#57549](https://github.com/ClickHouse/ClickHouse/pull/57549) ([Robert Schulze](https://github.com/rschu1ze)).
* `MaterializedPostgreSQL` 现已支持 PostgreSQL generated columns 和默认列值。关闭 [#40449](https://github.com/ClickHouse/ClickHouse/issues/40449)。[#57568](https://github.com/ClickHouse/ClickHouse/pull/57568) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 现在无需重启 server，即可应用部分文件系统缓存 config 设置变更。[#57578](https://github.com/ClickHouse/ClickHouse/pull/57578) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 处理获取包含空数组的 PostgreSQL 表结构时出现 sigabrt 的情况。[#57618](https://github.com/ClickHouse/ClickHouse/pull/57618) ([Mike Kot (Михаил Кот)](https://github.com/myrrc)).
* `date_trunc()` 函数现在允许第一个参数不区分大小写。现在两种写法都受支持：`SELECT date_trunc('day', now())` 和 `SELECT date_trunc('DAY', now())`。[#57624](https://github.com/ClickHouse/ClickHouse/pull/57624) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 将自上次 server 启动以来发生的错误总数公开为 `ClickHouseErrorMetric_ALL` 指标。[#57627](https://github.com/ClickHouse/ClickHouse/pull/57627) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 允许 config 中的节点同时使用 from&#95;env/from&#95;zk、非空元素以及 replace=1。[#57628](https://github.com/ClickHouse/ClickHouse/pull/57628) ([Azat Khuzhin](https://github.com/azat)).
* 生成无法解析为 JSON 的格式错误输出。[#57646](https://github.com/ClickHouse/ClickHouse/pull/57646) ([Julia Kartseva](https://github.com/jkartseva)).
* 如果启用，在选择要 merge 的 parts 时会考虑已轻量级删除的行。[#57648](https://github.com/ClickHouse/ClickHouse/pull/57648) ([Zhuo Qiu](https://github.com/jewelzqiu)).
* 使查询 system.filesystem&#95;cache 时不再占用大量内存。[#57687](https://github.com/ClickHouse/ClickHouse/pull/57687) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 允许将 IPv6 转换为 UInt128，并支持二进制算术运算。[#57707](https://github.com/ClickHouse/ClickHouse/pull/57707) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

* `sleep()` 函数现在可以通过 `KILL QUERY` 取消。[#57746](https://github.com/ClickHouse/ClickHouse/pull/57746) ([Vitaly Baranov](https://github.com/vitlibar)).
