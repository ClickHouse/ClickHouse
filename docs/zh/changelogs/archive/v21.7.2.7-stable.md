<div id="improvement">
  #### 改进
</div>

* 已在 [#25881](https://github.com/ClickHouse/ClickHouse/issues/25881) 中回移：支持在工作目录不可读时启动 ClickHouse 客户端。[#25817](https://github.com/ClickHouse/ClickHouse/pull/25817) ([ianton-ru](https://github.com/ianton-ru)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#25833](https://github.com/ClickHouse/ClickHouse/issues/25833) 中回移：从 `Date` 到 `DateTime` (或 `DateTime64`) 的 `CAST` 未使用 `DateTime` 类型的时区。这也会影响 `Date` 与 `DateTime` 之间的比较。为 `Date` 和 `DateTime` 推断公共类型时，同样未使用相应的时区。这会影响函数 `if` 和数组构造的结果。关闭 [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#25766](https://github.com/ClickHouse/ClickHouse/issues/25766) 中回移：修复了 PREWHERE 中使用非 uint8 类型时触发的断言问题，关闭 [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589)。[#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#25954](https://github.com/ClickHouse/ClickHouse/issues/25954) 中回移：修复参与生存时间 (TTL) 表达式的列执行 `ALTER MODIFY COLUMN` 时的问题。[#25554](https://github.com/ClickHouse/ClickHouse/pull/25554) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#25871](https://github.com/ClickHouse/ClickHouse/issues/25871) 中回移：修复了 `ReplicatedMergeTree` 表中 `DROP PART` 查询的一个罕见缺陷，该问题可能导致错误信息 `Unexpected merged part intersecting drop range`。[#25783](https://github.com/ClickHouse/ClickHouse/pull/25783) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#25886](https://github.com/ClickHouse/ClickHouse/issues/25886) 中回移：修复 ARM 在非默认页面大小下的异常处理问题。修复 [#25512](https://github.com/ClickHouse/ClickHouse/issues/25512)。修复 [#25044](https://github.com/ClickHouse/ClickHouse/issues/25044)。修复 [#24901](https://github.com/ClickHouse/ClickHouse/issues/24901)。修复 [#23183](https://github.com/ClickHouse/ClickHouse/issues/23183)。修复 [#20221](https://github.com/ClickHouse/ClickHouse/issues/20221)。修复 [#19703](https://github.com/ClickHouse/ClickHouse/issues/19703)。修复 [#19028](https://github.com/ClickHouse/ClickHouse/issues/19028)。修复 [#18391](https://github.com/ClickHouse/ClickHouse/issues/18391)。修复 [#18121](https://github.com/ClickHouse/ClickHouse/issues/18121)。修复 [#17994](https://github.com/ClickHouse/ClickHouse/issues/17994)。修复 [#12483](https://github.com/ClickHouse/ClickHouse/issues/12483)。[#25854](https://github.com/ClickHouse/ClickHouse/pull/25854) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#25957](https://github.com/ClickHouse/ClickHouse/issues/25957) 中回移：修复后台任务在后台线程池已满时退避时间过长的问题。修复 [#25836](https://github.com/ClickHouse/ClickHouse/issues/25836)。[#25893](https://github.com/ClickHouse/ClickHouse/pull/25893) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#25932](https://github.com/ClickHouse/ClickHouse/issues/25932) 中回移：修复使用错误参数调用 dictGet() 时发生崩溃的问题。[#25913](https://github.com/ClickHouse/ClickHouse/pull/25913) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#25981](https://github.com/ClickHouse/ClickHouse/issues/25981) 中回移：修复查询分析器在调用栈展开期间可能发生死锁的问题。修复 [#25968](https://github.com/ClickHouse/ClickHouse/issues/25968)。[#25970](https://github.com/ClickHouse/ClickHouse/pull/25970) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#26010](https://github.com/ClickHouse/ClickHouse/issues/26010) 中回移：修复将键为整数的 `Map` 类型格式化为 `JSON` 时的错误。[#25982](https://github.com/ClickHouse/ClickHouse/pull/25982) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#26097](https://github.com/ClickHouse/ClickHouse/issues/26097) 中回移：修复在某些情况下对右侧子查询执行 JOIN 时线程估算错误的问题。关闭 [#24075](https://github.com/ClickHouse/ClickHouse/issues/24075)。[#26052](https://github.com/ClickHouse/ClickHouse/pull/26052) ([Vladimir C](https://github.com/vdimir)) 。
