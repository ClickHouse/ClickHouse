<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#26940](https://github.com/ClickHouse/ClickHouse/issues/26940) 中回移：修复了关闭 ReplicatedMergeTree 表时删除数据可能导致数据与元数据不一致的问题。[#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* 已在 [#26983](https://github.com/ClickHouse/ClickHouse/issues/26983) 中回移：应用某些组合器时，聚合函数参数可能会丢失，从而导致类似 `Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported` 的异常。现已修复。修复了 [#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) 和 [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433)。[#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#26998](https://github.com/ClickHouse/ClickHouse/issues/26998) 中回移：修复了自定义 TLD 的读取问题 (在较小的 buffer 或较大的文件情况下会停止处理) 。[#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#27088](https://github.com/ClickHouse/ClickHouse/issues/27088) 中回移：现在会校验 `ALTER TABLE ... PARTITION ID xxx` 这类查询中的分区 ID 是否合法。修复了 [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718)。[#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* 已在 [#27049](https://github.com/ClickHouse/ClickHouse/issues/27049) 中回移：[RFC] 修复了因与 DROP&#95;RANGE 竞争而可能导致的变更积压问题。[#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#27158](https://github.com/ClickHouse/ClickHouse/issues/27158) 中回移：修复了 GRPCServer 中的同步问题。该 PR 修复了 [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024)。[#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#27368](https://github.com/ClickHouse/ClickHouse/issues/27368) 中回移：- 修复了函数 `multiSearch*` 在空数组情况下的未初始化内存问题，关闭 [#27169](https://github.com/ClickHouse/ClickHouse/issues/27169)。[#27181](https://github.com/ClickHouse/ClickHouse/pull/27181) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#27264](https://github.com/ClickHouse/ClickHouse/issues/27264) 中回移：在极少数情况下，`system.detached_parts` 表中某些 parts 的信息可能不正确，现已修复。修复了 [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114)。[#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#27413](https://github.com/ClickHouse/ClickHouse/issues/27413) 中回移：修复了使用旧语法创建的 MergeTree 表的分区 ID 校验不正确的问题。[#27328](https://github.com/ClickHouse/ClickHouse/pull/27328) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#27645](https://github.com/ClickHouse/ClickHouse/issues/27645) 中回移：修复了带有行级安全、prewhere 和 LowCardinality 过滤器的查询结果不正确的问题。修复了 [#27179](https://github.com/ClickHouse/ClickHouse/issues/27179)。[#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#27473](https://github.com/ClickHouse/ClickHouse/issues/27473) 中回移：修复指标 BackgroundMessageBrokerSchedulePoolTask，可能是名称拼写有误。[#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* 已在 [#27864](https://github.com/ClickHouse/ClickHouse/issues/27864) 中回移：避免某些格式在接收到来自 Kafka 的 NULL (tombstone) 消息时发生崩溃。关闭 [#19255](https://github.com/ClickHouse/ClickHouse/issues/19255)。[#27794](https://github.com/ClickHouse/ClickHouse/pull/27794) ([filimonov](https://github.com/filimonov)).
* 已在 [#28207](https://github.com/ClickHouse/ClickHouse/issues/28207) 中回移：修复读取缓冲区因 &#39;attempt to read after end of file&#39; 而失败的情况。关闭 [#26149](https://github.com/ClickHouse/ClickHouse/issues/26149)。[#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
