<div id="improvement">
  #### 改进
</div>

* 已在 [#66768](https://github.com/ClickHouse/ClickHouse/issues/66768) 中回移：使 `allow_experimental_analyzer` 由分布式查询的发起节点控制。这可确保在混合版本集群中执行操作时的兼容性和正确性。[#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 严重缺陷修复 (崩溃、LOGICAL_ERROR、数据丢失、RBAC)
</div>

* 已在 [#66884](https://github.com/ClickHouse/ClickHouse/issues/66884) 中回移：修复函数调用中低基数列大小不符合预期的问题。[#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#66691](https://github.com/ClickHouse/ClickHouse/issues/66691) 中回移：修复用户定义中的 VALID UNTIL 子句在重启后被重置的问题。关闭 [#66405](https://github.com/ClickHouse/ClickHouse/issues/66405)。[#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已在 [#67814](https://github.com/ClickHouse/ClickHouse/issues/67814) 中回移：仅与实验性的 Variant 数据类型相关。修复 Variant + AggregateFunction 类型导致的崩溃问题。[#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#67501](https://github.com/ClickHouse/ClickHouse/issues/67501) 中回移：修复 DistributedAsyncInsert 在连接为空时发生崩溃的问题。[#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已在 [#67850](https://github.com/ClickHouse/ClickHouse/issues/67850) 中回移：修复 [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)。避免在 `ReplaceTableNodeToDummyVisitor` 中遍历未解析的表函数参数。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#65350](https://github.com/ClickHouse/ClickHouse/issues/65350) 中回移：修复 StatusFile 中的 ~WriteBufferFromFileDescriptor 在出现未捕获异常时可能异常终止的问题。[#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#65621](https://github.com/ClickHouse/ClickHouse/issues/65621) 中回移：修复分布式查询按 `Nested` 列执行 `ARRAY JOIN` 时出现的 `Cannot find column` 问题。修复 [#64755](https://github.com/ClickHouse/ClickHouse/issues/64755)。[#64801](https://github.com/ClickHouse/ClickHouse/pull/64801) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#65933](https://github.com/ClickHouse/ClickHouse/issues/65933) 中回移：对于从 `PostgreSQL` 读取数据的查询，如果 ClickHouse 查询已结束，则会取消内部的 `PostgreSQL` 查询。否则，在内部 `PostgreSQL` 查询结束之前，`ClickHouse` 查询无法取消。[#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#66301](https://github.com/ClickHouse/ClickHouse/issues/66301) 中回移：改进了对包含 `IS NULL` 检查的 join 条件的处理 (例如，`ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` 会被重写为 `ON a <=> b`) ，并修复了在存在 `IS NULL` 之外的其他条件时的错误优化。[#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* 已在 [#66328](https://github.com/ClickHouse/ClickHouse/issues/66328) 中回移：在 schema inference 缓存中补充了缺失的设置 `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples`，因为这些设置会影响最终生成的 schema。这可以防止在这些设置发生变化时得到错误的 schema inference 结果。[#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#66155](https://github.com/ClickHouse/ClickHouse/issues/66155) 中回移：修复 `unbin`/`unhex` 实现中的缓冲区溢出问题。[#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* 已在 [#66454](https://github.com/ClickHouse/ClickHouse/issues/66454) 中回移：修复 ZooKeeper client 中的一个问题：在收到 ZooKeeper 返回的硬件错误后，session 可能会卡在不可用状态。例如，这可能是由 ClickHouse Keeper 中的 &quot;软内存限制&quot; 导致的。[#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#66226](https://github.com/ClickHouse/ClickHouse/issues/66226) 中回移：修复 SumIfToCountIfVisitor 处理有符号整数时的问题。[#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#66680](https://github.com/ClickHouse/ClickHouse/issues/66680) 中回移：修复在无法使用索引时对 `system.numbers_mt` 的 limit 处理问题。[#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#66604](https://github.com/ClickHouse/ClickHouse/issues/66604) 中回移：修复了 ClickHouse server 在 Docker 等容器中运行时，未能根据 cgroups v2 的配置正确检测可用最大 CPU 核心数的问题。更具体地说，容器通常会将其进程运行在名称为空的根 cgroup 中。在这种情况下，ClickHouse 会忽略 cgroups v2 设置的 CPU 限制。[#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
* 已在 [#66360](https://github.com/ClickHouse/ClickHouse/issues/66360) 中回移：修复在约束中使用带有 `IN` 的子查询时出现的 `Not-ready set` 错误。[#66261](https://github.com/ClickHouse/ClickHouse/pull/66261) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#66972](https://github.com/ClickHouse/ClickHouse/issues/66972) 中回移：修复在 `group_by_use_nulls=true` 且使用新 analyzer 时出现的 `Column identifier is already registered` 错误。[#66400](https://github.com/ClickHouse/ClickHouse/pull/66400) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
