<div id="clickhouse-release-v20685-stable-fixme-as-compared-to-v20674-stable">
  ### ClickHouse 发布版本 v20.6.8.5-stable FIXME，相较于 v20.6.7.4-stable
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#15567](https://github.com/ClickHouse/ClickHouse/issues/15567) 中回移：现在可以使用 `ALTER` 查询更改 `VersionedCollapsingMergeTree` 的版本列类型。[#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#15018](https://github.com/ClickHouse/ClickHouse/issues/15018) 中回移：修复了 `Nullable` 列排序顺序不正确的问题。此修复解决了 [#14344](https://github.com/ClickHouse/ClickHouse/issues/14344)。[#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已在 [#14826](https://github.com/ClickHouse/ClickHouse/issues/14826) 中回移：修复了有符号类型收缩 `Int -> Int` 转换时单调性检测错误的问题，该问题可能导致查询结果不正确。此缺陷在 [#14513](https://github.com/ClickHouse/ClickHouse/issues/14513) 中被发现。[#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#15147](https://github.com/ClickHouse/ClickHouse/issues/15147) 中回移：修复了当需要从 ZooKeeper 获取配置文件（使用 `from_zk` 包含选项）时，服务器在启动过程中与 ZooKeeper 通信可能卡死的问题。此修复解决了 [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814)。[#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 已在 [#15253](https://github.com/ClickHouse/ClickHouse/issues/15253) 中回移：修复了 CacheDictionary 中的段错误 [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837)。[#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已在 [#14986](https://github.com/ClickHouse/ClickHouse/issues/14986) 中回移：在 `system.asynchronous_metrics` 中发布每个逻辑核心的 CPU 频率。此修复解决了 [#14923](https://github.com/ClickHouse/ClickHouse/issues/14923)。[#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 已在 [#14968](https://github.com/ClickHouse/ClickHouse/issues/14968) 中回移：修复了当子查询包含 finalizeAggregation 函数时谓词下推无法正常工作的问题。修复了 [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847)。[#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov))。
* 已在 [#15080](https://github.com/ClickHouse/ClickHouse/issues/15080) 中回移：修复了在 `join_algorithm='auto'` 模式下执行 RIGHT 或 FULL JOIN 时，因超出内存限制需将 HashJoin 切换为 MergeJoin 而导致崩溃的问题。[#15002](https://github.com/ClickHouse/ClickHouse/pull/15002) ([Artem Zuikov](https://github.com/4ertus2))。
* 已在 [#15057](https://github.com/ClickHouse/ClickHouse/issues/15057) 中回移：修复了使用特定构造的参数调用函数 `bar` 时可能发生缓冲区溢出的问题。此修复关闭了 [#13926](https://github.com/ClickHouse/ClickHouse/issues/13926)。[#15028](https://github.com/ClickHouse/ClickHouse/pull/15028) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#15050](https://github.com/ClickHouse/ClickHouse/issues/15050) 中回移：String 与 FixedString 之间已使用填充比较（https://github.com/ClickHouse/ClickHouse/blob/master/src/Functions/FunctionsComparison.h#L333）。此 PR 将相同逻辑应用于字段比较，从而修正了将 FixedString 用作主键时的行为。此修复解决了 [#14908](https://github.com/ClickHouse/ClickHouse/issues/14908)。[#15033](https://github.com/ClickHouse/ClickHouse/pull/15033) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#15143](https://github.com/ClickHouse/ClickHouse/issues/15143) 中回移：修复了 `join_algorithm='auto'` 模式下出现 `Data compressed with different methods` 错误的问题。在 `join_algorithm='partial_merge'` 模式下，保留左表连接键的 LowCardinality 类型。[#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2))。
* 已在 [#15223](https://github.com/ClickHouse/ClickHouse/issues/15223) 中回移：修复了表引擎 `Buffer` 在执行 `ALTER` 查询后无法向 `Buffer` 插入新结构数据的缺陷。修复了 [#15117](https://github.com/ClickHouse/ClickHouse/issues/15117)。[#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin))。
* 已在 [#15404](https://github.com/ClickHouse/ClickHouse/issues/15404) 中回移：修复了将 joinGet 与 LowCardinality 类型一起使用时实例崩溃的问题。此修复解决了 [#15214](https://github.com/ClickHouse/ClickHouse/issues/15214)。[#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#15279](https://github.com/ClickHouse/ClickHouse/issues/15279) 中回移：修复了 QueryLog 中 MSan 报告的问题，`memory_usage` 字段可能使用未初始化的内存。[#15258](https://github.com/ClickHouse/ClickHouse/pull/15258) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#15412](https://github.com/ClickHouse/ClickHouse/issues/15412) 中回移：修复了对 `MySQL` 引擎同一张表存在大量子查询时查询挂起的问题。此前，若查询中对同一 `MySQL` 表的子查询超过 16 个，查询将永久挂起。[#15299](https://github.com/ClickHouse/ClickHouse/pull/15299) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#15339](https://github.com/ClickHouse/ClickHouse/issues/15339) 中回移：修复了启用 system.logs 时服务器启动过程中偶发竞态条件的问题。[#15300](https://github.com/ClickHouse/ClickHouse/pull/15300) ([alesapin](https://github.com/alesapin))。
* 已在 [#15335](https://github.com/ClickHouse/ClickHouse/issues/15335) 中回移：修复了 MergeTree 表重命名与后台清理过程中的竞态条件问题。[#15304](https://github.com/ClickHouse/ClickHouse/pull/15304) ([alesapin](https://github.com/alesapin))。
* 已在 [#15445](https://github.com/ClickHouse/ClickHouse/issues/15445) 中回移：修复了当聚合函数 `boundingRatio` 的第二个参数类型错误时未能正确报错的问题。[#15407](https://github.com/ClickHouse/ClickHouse/pull/15407) ([detailyang](https://github.com/detailyang))。
* 已在 [#15508](https://github.com/ClickHouse/ClickHouse/issues/15508) 中回移：修复了 DDLWorker 中事件订阅的缺陷，该缺陷偶尔会导致 `ON CLUSTER` 查询挂起。该问题引入自 [#13450](https://github.com/ClickHouse/ClickHouse/issues/13450)。[#15477](https://github.com/ClickHouse/ClickHouse/pull/15477) ([alesapin](https://github.com/alesapin))。
* 已在 [#15616](https://github.com/ClickHouse/ClickHouse/issues/15616) 中回移：修复了在选取数据中不存在但依赖于同样不存在的其他列时出现 `Missing columns` 错误的问题。修复了 [#15530](https://github.com/ClickHouse/ClickHouse/issues/15530)。[#15532](https://github.com/ClickHouse/ClickHouse/pull/15532) ([alesapin](https://github.com/alesapin))。
* 已在 [#15561](https://github.com/ClickHouse/ClickHouse/issues/15561) 中回移：修复了在执行相同模式的 `LIKE` 后，`ILIKE` 运算符不再大小写不敏感的缺陷。[#15536](https://github.com/ClickHouse/ClickHouse/pull/15536) ([alesapin](https://github.com/alesapin))。
* 已在 [#15728](https://github.com/ClickHouse/ClickHouse/issues/15728) 中回移：执行 `MOVE` 或 `REPLACE PARTITION`，或在极少数情况下执行 `DETACH` 或 `DROP PARTITION` 后，Mutation 操作可能会因等待某个不存在的分片而挂起。此问题已修复。[#15537](https://github.com/ClickHouse/ClickHouse/pull/15537) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#15654](https://github.com/ClickHouse/ClickHouse/issues/15654) 中回移：修复了在使用 IN 和 Distributed 表的查询中，当发起节点上不存在对应数据库时出现 'Database <db> doesn't exist.' 错误的问题。[#15538](https://github.com/ClickHouse/ClickHouse/pull/15538) ([Artem Zuikov](https://github.com/4ertus2))。
* 已在 [#15586](https://github.com/ClickHouse/ClickHouse/issues/15586) 中回移：修复了可能出现错误信息 `Could not calculate available disk space (statvfs), errno: 4, strerror: Interrupted system call` 的问题，解决了 [#15541](https://github.com/ClickHouse/ClickHouse/issues/15541)。[#15557](https://github.com/ClickHouse/ClickHouse/pull/15557) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#15664](https://github.com/ClickHouse/ClickHouse/issues/15664) 中回移：修复了在 `VALUES`、`LIMIT` 或 `IN` 运算符右侧使用 `JSON*` 函数结果时出现 `Element ... is not a constant expression` 错误的问题。[#15589](https://github.com/ClickHouse/ClickHouse/pull/15589) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#15714](https://github.com/ClickHouse/ClickHouse/issues/15714) 中回移：修复了查询计划中 `ReadFromStorage` 步骤的资源销毁顺序问题，该问题在极少数情况下可能导致崩溃，可能与 [#15610](https://github.com/ClickHouse/ClickHouse/issues/15610) 相关。[#15645](https://github.com/ClickHouse/ClickHouse/pull/15645) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
