<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#20510](https://github.com/ClickHouse/ClickHouse/issues/20510) 中回移：修复了这样一种情况：当 JSON 损坏时，系统会尝试将整个文件读入内存，进而导致内存分配器抛出异常。修复了 [#19719](https://github.com/ClickHouse/ClickHouse/issues/19719)。[#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#20575](https://github.com/ClickHouse/ClickHouse/issues/20575) 中回移：检查表函数 `view` 是否用于表达式列表中，并抛出错误。此修复解决了 [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342)。[#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#20486](https://github.com/ClickHouse/ClickHouse/issues/20486) 中回移：修复了当 JOIN 包含来自 SELECT 的常量时，`join_use_nulls=1` 会触发 `LOGICAL_ERROR` 的问题。[#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#20535](https://github.com/ClickHouse/ClickHouse/issues/20535) 中回移：修复了将 WITH 别名传播到子查询时出现的无限循环。此修复解决了 [#20388](https://github.com/ClickHouse/ClickHouse/issues/20388)。[#20476](https://github.com/ClickHouse/ClickHouse/pull/20476) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#20615](https://github.com/ClickHouse/ClickHouse/issues/20615) 中回移：为 async INSERT 在解析目录名称时添加了适当的检查 (修复 SIGSEGV) 。[#20498](https://github.com/ClickHouse/ClickHouse/pull/20498) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#20887](https://github.com/ClickHouse/ClickHouse/issues/20887) 中回移：修复了带有 UNION DISTINCT 和 LIMIT 子句的子查询。关闭 [#20597](https://github.com/ClickHouse/ClickHouse/issues/20597)。[#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)) 。
* 已在 [#20993](https://github.com/ClickHouse/ClickHouse/issues/20993) 中回移：修复了在聚合函数中同时使用 `-Distinct` 组合器和 `-State` 组合器的问题。[#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#20987](https://github.com/ClickHouse/ClickHouse/issues/20987) 中回移：使用 MySQL 5.7 客户端连接到 ClickHouse server 时，`USE database;` 查询无法执行，现已修复。修复了 [#18926](https://github.com/ClickHouse/ClickHouse/issues/18926)。[#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
