* 回移到 [#67503](https://github.com/ClickHouse/ClickHouse/issues/67503)：修复 `DistributedAsyncInsert` 中 connection 为空时发生崩溃的问题。[#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)).
* 回移到 [#67852](https://github.com/ClickHouse/ClickHouse/issues/67852)：修复 [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)。避免在 `ReplaceTableNodeToDummyVisitor` 中遍历未解析的表函数参数。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* 回移到 [#67838](https://github.com/ClickHouse/ClickHouse/issues/67838)：修复 `JSONMergePatch` 函数中潜在的堆栈溢出问题。由于原名称有误，已将该函数从 `jsonMergePatch` 重命名为 `JSONMergePatch`。为保持兼容性，仍保留原名称。改进了该函数的错误诊断信息。此项变更关闭了 [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304)。[#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移到 [#66303](https://github.com/ClickHouse/ClickHouse/issues/66303)：改进了对包含 `IS NULL` 检查的 join 条件的处理 (例如，`ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` 会被重写为 `ON a <=> b`) ，并修复了在存在 `IS NULL` 之外的其他条件时发生的不正确优化。[#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir))。
* 已回移到 [#66330](https://github.com/ClickHouse/ClickHouse/issues/66330)：在 schema 推断缓存中补充了缺失的设置 `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples`，因为这些设置会改变最终的 schema。这样可避免在这些设置变更后出现错误的 schema 推断结果。[#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar))。
* 已回移到 [#66157](https://github.com/ClickHouse/ClickHouse/issues/66157)：修复了 `unbin`/`unhex` 实现中的缓冲区溢出问题。[#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat))。
* 已回移到 [#66210](https://github.com/ClickHouse/ClickHouse/issues/66210)：禁用了在 [#64760](https://github.com/ClickHouse/ClickHouse/issues/64760) 中引入的 `merge-filters` 优化。如果该优化合并了两个过滤器表达式且未应用短路求值，可能会导致异常。[#66126](https://github.com/ClickHouse/ClickHouse/pull/66126) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已回移到 [#66456](https://github.com/ClickHouse/ClickHouse/issues/66456)：修复了 ZooKeeper 客户端中的一个问题：会话在收到来自 ZooKeeper 的硬件错误后，可能会卡在不可用状态中。例如，这种情况可能由 ClickHouse Keeper 中的 &quot;soft memory limit&quot; 导致。[#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已回移到 [#66228](https://github.com/ClickHouse/ClickHouse/issues/66228)：修复了 SumIfToCountIfVisitor 与有符号整数相关的问题。[#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano))。
* 已回移到 [#66183](https://github.com/ClickHouse/ClickHouse/issues/66183)：修复了分布式查询结果中罕见的数据缺失问题，关闭 [#61432](https://github.com/ClickHouse/ClickHouse/issues/61432)。[#66174](https://github.com/ClickHouse/ClickHouse/pull/66174) ([vdimir](https://github.com/vdimir))。
* 已回移到 [#66271](https://github.com/ClickHouse/ClickHouse/issues/66271)：对于 `distributed_ddl_output_mode` 的 `none_only_active` 模式，不再抛出 `TIMEOUT_EXCEEDED`。[#66218](https://github.com/ClickHouse/ClickHouse/pull/66218) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已回移到 [#66682](https://github.com/ClickHouse/ClickHouse/issues/66682)：修复了在无法使用索引时 `system.numbers_mt` 的 limit 处理问题。[#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* 已回移到 [#66587](https://github.com/ClickHouse/ClickHouse/issues/66587)：修复了 ClickHouse server 在 Docker 等容器中运行时，对 cgroups v2 所指定的最大可用 CPU 核心数的检测问题。更具体地说，容器中的进程通常运行在名称为空的根 cgroup 中。在这种情况下，ClickHouse 会忽略 cgroups v2 设置的 CPU 限制。[#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov))。
