<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#43829](https://github.com/ClickHouse/ClickHouse/issues/43829) 中回移：更新了 normaliser，使其克隆别名 ast。解决了 [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452)。实现：* 更新了 QueryNormalizer，使其在替换别名 ast 时对其进行克隆。此前只是赋用同一个 ast，这会导致在 LogicalExpressinsOptimizer 中出现 Exception，因为这相当于再次插入同一个 parent。* 在新的 analyzer (allow&#95;experimental&#95;analyzer) 中不会出现这个 bug，因此未对其作任何修改。我还为此添加了相应的测试。[#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)) 。
