<div id="improvement">
  #### 改进
</div>

* 已在 [#17031](https://github.com/ClickHouse/ClickHouse/issues/17031) 中回移：现已支持连接到需要 SNI 的 `clickhouse-server` 安全端点。当 `clickhouse-server` 部署在 TLS 代理后方时，即可实现这一点。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#17107](https://github.com/ClickHouse/ClickHouse/issues/17107) 中回移：修复 [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) 和 [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) 中的问题，即使用带有 `if` 后缀的聚合函数时远程查询失败。[#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014))。
* 已在 [#17022](https://github.com/ClickHouse/ClickHouse/issues/17022) 中回移：修复在不带任何参数时使用 `any` 会导致崩溃的问题。这是针对 [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803) 的修复。cc @azat。[#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#16878](https://github.com/ClickHouse/ClickHouse/issues/16878) 中回移：如果没有数据写入 WriteBufferFromS3，则中止分段上传。[#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser))。
* 已在 [#16949](https://github.com/ClickHouse/ClickHouse/issues/16949) 中回移：防止使用 TimeSeriesGroupSum 时 ClickHouse server 崩溃。[#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov))。
* 已在 [#17075](https://github.com/ClickHouse/ClickHouse/issues/17075) 中回移：修复带有 `ORDER BY` 的查询可能出现 `Illegal type of argument` 错误的问题。修复 [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580)。[#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#17008](https://github.com/ClickHouse/ClickHouse/issues/17008) 中回移：安装 script 应始终在 config 目录中创建子目录。这仅与使用自定义 config 的 Docker build 相关。[#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov))。
* 已在 [#16967](https://github.com/ClickHouse/ClickHouse/issues/16967) 中回移：`clickhouse-git-import` 中的 blame 信息计算不正确。[#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#17012](https://github.com/ClickHouse/ClickHouse/issues/17012) 中回移：修复在执行 `ALTER TABLE ... MODIFY COLUMN ... NewType` 后可能导致 server 崩溃的问题：当 `SELECT` 对正在修改的列包含 `WHERE` expression，且 alter 尚未完成时，就可能发生该问题。[#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#17038](https://github.com/ClickHouse/ClickHouse/issues/17038) 中回移：发生错误时，重新解析 `format_avro_schema_registry_url` 的 IP。[#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov))。
* 已在 [#17092](https://github.com/ClickHouse/ClickHouse/issues/17092) 中回移：修复从 double 转换为大整数 (128、256 比特) 时结果错误的问题。[#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc))。
* 已在 [#17169](https://github.com/ClickHouse/ClickHouse/issues/17169) 中回移：修复在非 leader 的 ReplicatedMergeTreeTables 上，`ON CLUSTER` 查询可能永久挂起的问题。[#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin))。
