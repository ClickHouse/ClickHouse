<div id="clickhouse-release-v20714310-prestable-fixme-as-compared-to-v20614066-prestable">
  ### ClickHouse 发布版本 v20.7.1.4310-prestable FIXME (相比 v20.6.1.4066-prestable)
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 弃用将零 Date/日期时间 值特殊输出为 `0000-00-00` 和 `0000-00-00 00:00:00`。[#12442](https://github.com/ClickHouse/ClickHouse/pull/12442) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 当函数 `modulo` (运算符 `%`) 的参数中至少有一个是浮点数时，将直接基于浮点数计算除法余数，而不再先将两个参数都转换为整数。这样可使其行为与大多数 DBMS 保持兼容。这同样适用于 Date 和 日期时间 数据类型。新增别名 `mod`。这关闭了 [#7323](https://github.com/ClickHouse/ClickHouse/issues/7323)。[#12585](https://github.com/ClickHouse/ClickHouse/pull/12585) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="new-feature">
  #### 新特性
</div>

* * 为预配置用户新增了 LDAP 身份验证支持 (“Simple Bind”方法) 。[#11234](https://github.com/ClickHouse/ClickHouse/pull/11234) ([Denis Glazachev](https://github.com/traceon)).
* 添加 `mapAdd` 和 `mapSubtract` 函数，用于处理元组映射。[#11735](https://github.com/ClickHouse/ClickHouse/pull/11735) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 新增 `system.crash_log` 表，用于收集致命错误的堆栈跟踪。[#12316](https://github.com/ClickHouse/ClickHouse/pull/12316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 添加用于贝叶斯 A/B 测试的 `bayesAB` 函数。[#12327](https://github.com/ClickHouse/ClickHouse/pull/12327) ([achimbab](https://github.com/achimbab)).
* 集成了 [COS](https://intl.cloud.tencent.com/product/cos)。[#12386](https://github.com/ClickHouse/ClickHouse/pull/12386) ([fastio](https://github.com/fastio)).
* * 添加 FROM&#95;UNIXTIME 函数，相关内容见 [12149](https://github.com/ClickHouse/ClickHouse/issues/12149)。[#12484](https://github.com/ClickHouse/ClickHouse/pull/12484) ([flynn](https://github.com/ucasfl)).
* 新增 `formatRow` 函数，可通过指定格式将任意表达式转换为字符串。它对处理 SQL 输出非常有用，并且与 `columns` 函数组合使用时也很灵活。[#12574](https://github.com/ClickHouse/ClickHouse/pull/12574) ([Amos Bird](https://github.com/amosbird)).
* 添加设置 `allow_non_metadata_alters`，用于限制执行会修改磁盘上数据的 `ALTER` 查询。默认禁用。关闭了 [#11547](https://github.com/ClickHouse/ClickHouse/issues/11547)。[#12635](https://github.com/ClickHouse/ClickHouse/pull/12635) ([alesapin](https://github.com/alesapin)).
* 为 `SimpleAggregateFunction` 添加对 `minMap` 和 `maxMap` 函数的支持。[#12662](https://github.com/ClickHouse/ClickHouse/pull/12662) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 新增了 HTTP 请求头 `X-ClickHouse-Database` 和 `X-ClickHouse-Format`，可用于设置默认数据库和输出格式。[#12981](https://github.com/ClickHouse/ClickHouse/pull/12981) ([hcz](https://github.com/hczhcz)).
* 实现了用户自定义设置。[#13013](https://github.com/ClickHouse/ClickHouse/pull/13013) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 优化匹配精确 PK 范围的查询的 PK 查找。 [#12277](https://github.com/ClickHouse/ClickHouse/pull/12277) ([Ivan Babrou](https://github.com/bobrik)).
* 尝试在 `DiskS3` 中实现流式优化。 [#12434](https://github.com/ClickHouse/ClickHouse/pull/12434) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 如果 `set optimize_monotonous_functions_in_order_by=1`，则在 ORDER BY 中将单调函数替换为其参数。 [#12467](https://github.com/ClickHouse/ClickHouse/pull/12467) ([Artem Zuikov](https://github.com/4ertus2)).
* 如果 `set optimize_if_transform_strings_to_enum = 1`，则将函数 “if” 和 “transform” 的 String 类型参数转换为枚举。 [#12515](https://github.com/ClickHouse/ClickHouse/pull/12515) ([Artem Zuikov](https://github.com/4ertus2)).
* 在 parts 上并行执行 PK 查找和跳过索引阶段，如 [#11564](https://github.com/ClickHouse/ClickHouse/issues/11564) 所述。 [#12589](https://github.com/ClickHouse/ClickHouse/pull/12589) ([Ivan Babrou](https://github.com/bobrik)).
* 在查询计划中下推 `LIMIT` 步骤。 [#13016](https://github.com/ClickHouse/ClickHouse/pull/13016) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 略微提升按 UInt8/UInt16 键进行聚合的性能。 [#13055](https://github.com/ClickHouse/ClickHouse/pull/13055) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 略微提升按 UInt8/UInt16 键进行聚合的性能。 [#13091](https://github.com/ClickHouse/ClickHouse/pull/13091) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 改进
</div>

* 新增一种 Polygon 字典类型，使用递归构建的网格来减少每个点需要检查的多边形数量。[#9278](https://github.com/ClickHouse/ClickHouse/pull/9278) ([achulkov2](https://github.com/achulkov2)).
* 允许将 TabSeparatedRaw 作为 input format 使用。[#12009](https://github.com/ClickHouse/ClickHouse/pull/12009) ([hcz](https://github.com/hczhcz)).
* 将 `AWSAuthV4Signer` 拆分到不同的日志记录器中，并移除了 &quot;AWSClient: AWSClient&quot;。[#12320](https://github.com/ClickHouse/ClickHouse/pull/12320) ([Vladimir Chebotarev](https://github.com/excitoon)).
* * 为 `Atomic` 数据库引擎实现 `RENAME DATABASE` 和 `RENAME DICTIONARY` - 添加隐式 `{uuid}` 宏，可在 `ReplicatedMergeTree` 的 ZooKeeper 路径中使用。它适用于 `CREATE ... ON CLUSTER ...` 查询。将 `show_table_uuid_in_table_create_query_if_not_nil` 设置为 `true` 即可使用。- 使 `ReplicatedMergeTree` 引擎参数变为可选，默认使用 `/clickhouse/tables/{uuid}/{shard}/` 和 `{replica}`。关闭 [#12135](https://github.com/ClickHouse/ClickHouse/issues/12135)。- 小修复。- 这些更改破坏了 `Atomic` 数据库引擎的向后兼容性。此前创建的 `Atomic` 数据库必须手动转换为新格式。[#12343](https://github.com/ClickHouse/ClickHouse/pull/12343) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 现在 joinGet 支持多键查找。[#12418](https://github.com/ClickHouse/ClickHouse/pull/12418) ([Amos Bird](https://github.com/amosbird)).
* 回滚 `Log`、`TinyLog`、`StripeLog` 引擎中的插入错误。在之前的版本中，插入错误会导致表状态不一致 (这符合文档说明，并且对这些表引擎而言属于正常现象) 。此修复解决了 [#12402](https://github.com/ClickHouse/ClickHouse/issues/12402)。[#12426](https://github.com/ClickHouse/ClickHouse/pull/12426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 避免在解析因其时区而会产生负 Unix 时间戳的日期时间值时发生溢出 (例如，莫斯科时区中的 `1970-01-01 00:00:00`) 。现在会改为截断为零。此修复解决了 [#3470](https://github.com/ClickHouse/ClickHouse/issues/3470)。此修复解决了 [#4172](https://github.com/ClickHouse/ClickHouse/issues/4172)。[#12443](https://github.com/ClickHouse/ClickHouse/pull/12443) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为发往 S3 存储的请求添加了若干指标。[#12464](https://github.com/ClickHouse/ClickHouse/pull/12464) ([ianton-ru](https://github.com/ianton-ru)).
* 将 `multiple_joins_rewriter_version` 的默认值更改为 2。这会启用新的多 JOIN 重写器，它能够识别列名。[#12469](https://github.com/ClickHouse/ClickHouse/pull/12469) ([Artem Zuikov](https://github.com/4ertus2)).
* 允许以更标准的方式设置 JOIN 的 kind 和 type：使用 `LEFT SEMI JOIN` 而不是 `SEMI LEFT JOIN`。目前两种写法都正确。[#12520](https://github.com/ClickHouse/ClickHouse/pull/12520) ([Artem Zuikov](https://github.com/4ertus2)).
* 修复了默认情况下 explain 查询的 format 被覆盖的问题，相关 issue 见 [#12432](https://github.com/ClickHouse/ClickHouse/issues/12432)。[#12541](https://github.com/ClickHouse/ClickHouse/pull/12541) ([BohuTANG](https://github.com/BohuTANG)).
* 添加了 SelectedRows 和 SelectedBytes 事件。[#12638](https://github.com/ClickHouse/ClickHouse/pull/12638) ([ianton-ru](https://github.com/ianton-ru)).
* 向 `system.query_log` 添加了 `current_database` 信息。[#12652](https://github.com/ClickHouse/ClickHouse/pull/12652) ([Amos Bird](https://github.com/amosbird)).
* 支持在 TRUNCATE TABLE 中省略 TABLE 关键字。[#12653](https://github.com/ClickHouse/ClickHouse/pull/12653) ([Winter Zhang](https://github.com/zhang2014)).
* 现在，如果在 ALTER 或变更期间发生错误，异常会转发给客户端。关闭 [#11329](https://github.com/ClickHouse/ClickHouse/issues/11329)。[#12666](https://github.com/ClickHouse/ClickHouse/pull/12666) ([alesapin](https://github.com/alesapin)).
* 防止用户将 `background_pool_size` 设置为小于 `number_of_free_entries_in_pool_to_execute_mutation` 或 `number_of_free_entries_in_pool_to_lower_max_size_of_merge` 的值。在这些情况下，ALTER 将无法工作，或者 merge 的最大大小会被限制得过小。现在会改为将这些值截断处理。此更改关闭了 [#10897](https://github.com/ClickHouse/ClickHouse/issues/10897)。[#12728](https://github.com/ClickHouse/ClickHouse/pull/12728) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 此更改通过同时显示已跳过的粒度和已检查的总粒度数，使跳过索引的效率更加直观。[#12754](https://github.com/ClickHouse/ClickHouse/pull/12754) ([Ivan Babrou](https://github.com/bobrik)).
* 此更改通过显示跳过索引前后的标记总数，使跳过索引的效率更加直观。[#12755](https://github.com/ClickHouse/ClickHouse/pull/12755) ([Ivan Babrou](https://github.com/bobrik)).
* 引入设置 `alter_partition_verbose_result`，可为某些类型的 `ALTER TABLE ... PARTITION ...` 查询输出受影响 parts 的信息 (目前支持 `ATTACH` 和 `FREEZE`) 。关闭 [#8076](https://github.com/ClickHouse/ClickHouse/issues/8076)。[#13017](https://github.com/ClickHouse/ClickHouse/pull/13017) ([alesapin](https://github.com/alesapin)).
* 在 system.events 中新增 QueryTimeMicroseconds、SelectQueryTimeMicroseconds 和 InsertQueryTimeMicroseconds。[#13028](https://github.com/ClickHouse/ClickHouse/pull/13028) ([ianton-ru](https://github.com/ianton-ru)).
* 在循环中于适当时机执行 break。[#13058](https://github.com/ClickHouse/ClickHouse/pull/13058) ([Mark Papadakis](https://github.com/markpapadakis)).
* 减少 ZooKeeper 中保留的日志量。在存在大量 server/表/inserts 且有离线副本时，避免 ZooKeeper 节点数量增长过大。[#13100](https://github.com/ClickHouse/ClickHouse/pull/13100) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 MergeTree settings 添加合理性检查。如果设置不正确，server 将拒绝启动或创建表，并向用户输出详细说明。[#13153](https://github.com/ClickHouse/ClickHouse/pull/13153) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 允许 *Map aggregate functions 作用于包含 NULL 的 Arrays。修复 [#13157](https://github.com/ClickHouse/ClickHouse/issues/13157)。[#13225](https://github.com/ClickHouse/ClickHouse/pull/13225) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 parseDateTimeBestEffort 中的断言问题。此修复解决了 [#12649](https://github.com/ClickHouse/ClickHouse/issues/12649)。[#13227](https://github.com/ClickHouse/ClickHouse/pull/13227) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 geohashesInBox 中的断言问题。此修复解决了 [#12554](https://github.com/ClickHouse/ClickHouse/issues/12554)。[#13229](https://github.com/ClickHouse/ClickHouse/pull/13229) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 现在，在 compact part 处理过程中遇到损坏的 parts 时，也会将其报告出来。[#13282](https://github.com/ClickHouse/ClickHouse/pull/13282) ([Amos Bird](https://github.com/amosbird)).
* 修复 ATTACH/ALTER/CREATE QUOTA 语句中 `Week` 时间间隔的格式化问题。[#13417](https://github.com/ClickHouse/ClickHouse/pull/13417) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* 已更新 gitignore 文件。[#13447](https://github.com/ClickHouse/ClickHouse/pull/13447) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).

</div>

* kafka：修复了当批次中间有一条含错误的消息时触发的 SIGSEGV。[#12302](https://github.com/ClickHouse/ClickHouse/pull/12302) ([Azat Khuzhin](https://github.com/azat)).
* 如果 MergeTree 表不包含 ORDER BY 或 PARTITION BY，此前可以发起将所有列 CLEAR 的 ALTER，并且 ALTER 会卡住。已修复 [#7941](https://github.com/ClickHouse/ClickHouse/issues/7941)。[#12382](https://github.com/ClickHouse/ClickHouse/pull/12382) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
