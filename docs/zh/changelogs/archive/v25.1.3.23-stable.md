<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#75311](https://github.com/ClickHouse/ClickHouse/issues/75311) 中回移：修复了在解析 JSON 类型声明时，如果类型名称不是大写会发生崩溃的问题。[#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar))。
* 已在 [#75253](https://github.com/ClickHouse/ClickHouse/issues/75253) 中回移：当 remove 操作失败时，将分片状态从 deleting 恢复为过期。[#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema))。
* 已在 [#75409](https://github.com/ClickHouse/ClickHouse/issues/75409) 中回移：修复了在启用设置 `optimize_function_to_subcolumns` 时，`Array`、`Map` 和 `Nullable(..)` 列的索引 (主索引和次级索引) 使用问题。此前，这些列的索引可能会被忽略。[#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#75461](https://github.com/ClickHouse/ClickHouse/issues/75461) 中回移：修复了 CTE 与 Insert 组合使用时的崩溃问题。[#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218))。

<div id="buildtestingpackaging-improvement">

Shiryaev](https://github.com/Felixoid)) 。
