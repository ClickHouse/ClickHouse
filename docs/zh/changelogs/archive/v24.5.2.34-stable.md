<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#64729](https://github.com/ClickHouse/ClickHouse/issues/64729) 中回移：修复了对带默认表达式的表执行 `CREATE TABLE AS` 查询时的问题。[#64455](https://github.com/ClickHouse/ClickHouse/pull/64455) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#65061](https://github.com/ClickHouse/ClickHouse/issues/65061) 中回移：修复了查询使用指向 `GLOBAL IN.` 的别名时出现的 `Expression nodes list expected 1 projection names` 和 `Unknown expression or identifier` 错误。修复了 [#64445](https://github.com/ClickHouse/ClickHouse/issues/64445)。[#64517](https://github.com/ClickHouse/ClickHouse/pull/64517) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#65088](https://github.com/ClickHouse/ClickHouse/issues/65088) 中回移：修复了会移除恒为 true 的 `WHERE` 和 `PREWHERE` 表达式的问题 (针对新的 analyzer) 。修复了 [#64575](https://github.com/ClickHouse/ClickHouse/issues/64575)。[#64695](https://github.com/ClickHouse/ClickHouse/pull/64695) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#64944](https://github.com/ClickHouse/ClickHouse/issues/64944) 中回移：修复了 OrderByLimitByDuplicateEliminationVisitor 在跨子查询场景下的问题。[#64766](https://github.com/ClickHouse/ClickHouse/pull/64766) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#64873](https://github.com/ClickHouse/ClickHouse/issues/64873) 中回移：修复了多种查询中可能出现的内存跟踪错误：包括从 S3 读取任意数据的查询、通过 HTTP protocol 的查询以及异步插入。[#64844](https://github.com/ClickHouse/ClickHouse/pull/64844) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#64984](https://github.com/ClickHouse/ClickHouse/issues/64984) 中回移：修复了当 materialized view 的列类型与源表不一致时，从该 materialized view 使用 `PREWHERE` 读取的查询报出 `Block structure mismatch` 错误的问题。修复了 [#64611](https://github.com/ClickHouse/ClickHouse/issues/64611)。[#64855](https://github.com/ClickHouse/ClickHouse/pull/64855) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#64976](https://github.com/ClickHouse/ClickHouse/issues/64976) 中回移：修复了在表启用生存时间 (TTL)，且同时存在子查询 + replicated 数据库 + 并行副本 + analyzer 时的罕见崩溃问题。虽然这种情况极其少见，但仍建议不要将 TTL 与子查询一起使用。[#64858](https://github.com/ClickHouse/ClickHouse/pull/64858) ([alesapin](https://github.com/alesapin)).
* 已在 [#65074](https://github.com/ClickHouse/ClickHouse/issues/65074) 中回移：修复了 [https://github.com/ClickHouse/ClickHouse/pull/54211](https://github.com/ClickHouse/ClickHouse/pull/54211) 引入的、parameterized VIEWs 上 `ALTER MODIFY COMMENT` 查询失效的问题。[#65031](https://github.com/ClickHouse/ClickHouse/pull/65031) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#65179](https://github.com/ClickHouse/ClickHouse/issues/65179) 中回移：修复了远程查询使用 `INTERPOLATE (alias)` 时出现的 `Unknown expression identifier` 错误 (新的 analyzer) 。修复了 [#64636](https://github.com/ClickHouse/ClickHouse/issues/64636)。[#65090](https://github.com/ClickHouse/ClickHouse/pull/65090) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#65163](https://github.com/ClickHouse/ClickHouse/issues/65163) 中回移：修复了将算术运算移出 aggregation 的问题。在新的 analyzer 中，该优化此前只会应用一次。[#62245](https://github.com/ClickHouse/ClickHouse/issues/62245) 的一部分。[#65104](https://github.com/ClickHouse/ClickHouse/pull/65104) ([Dmitry Novik](https://github.com/novikd)).
