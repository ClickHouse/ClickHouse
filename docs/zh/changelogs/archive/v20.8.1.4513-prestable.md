<div id="clickhouse-release-v20814513-prestable-fixme-as-compared-to-v20714310-prestable">
  ### ClickHouse 发布 v20.8.1.4513-prestable FIXME，相较于 v20.7.1.4310-prestable
</div>

<div id="backward-incompatible-change">
  #### 不向后兼容的更改
</div>

* 移除对 `ODBCDriver` 输入/输出 format 的支持。这是一种已弃用的 format，曾用于与 ClickHouse ODBC driver 通信，如今早已被 `ODBCDriver2` format 取代。解决了 [#13629](https://github.com/ClickHouse/ClickHouse/issues/13629)。[#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting))。
* 扩展了 `parallel_distributed_insert_select` setting，新增了一个可将 `INSERT` 执行到本地表的选项。该 setting 的类型从 `Bool` 变为 `UInt64`，因此不再支持 `false` 和 `true` 这两个值。如果你在服务器配置中使用了这些值，server 将无法启动。请分别将它们替换为 `0` 和 `1`。[#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat))。
* 现在，`OPTIMIZE FINAL` 查询不会为在创建 TTL 之前添加的 parts 重新计算生存时间 (TTL)。请使用一次 `ALTER TABLE ... MATERIALIZE TTL` 来完成计算，之后 `OPTIMIZE FINAL` 才会正确评估 TTL。此行为对复制表一直都未生效。[#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin))。



<div id="new-feature">
  #### 新特性
</div>

* 支持 `MaterializeMySQL` 数据库引擎。实现了 [#4006](https://github.com/ClickHouse/ClickHouse/issues/4006)。[#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014))。
* 支持在 Kafka 中使用 Kerberos 身份验证，依赖 `krb5` 和 `cyrus-sasl` 库。[#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn))。
* 新增类型 `Int128`、`Int256`、`UInt256` 及其相关函数。将 Decimal 扩展至 Decimal256（精度最高支持 76 位）。新类型需通过设置项 `allow_experimental_bigint_types` 启用。[#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2))。
* 函数 `position` 现已支持可选参数 `start_pos`。[#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir))。
* 新增 `ALTER SAMPLE BY` 语句，支持修改表的采样子句。[#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird))。
* 在主配置文件中新增可选节 <user_directories>。[#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar))。
* 新增函数 `normalizeQuery`，可将字面量、字面量序列及复杂别名替换为占位符。新增函数 `normalizedQueryHash`，对相似查询返回相同的 64 位哈希值，便于分析查询日志。关闭了 [#11271](https://github.com/ClickHouse/ClickHouse/issues/11271)。[#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 新增 `quantileExactLow` 和 `quantileExactHigh` 实现，并分别为 `medianExactLow` 和 `medianExactHigh` 提供对应别名。[#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc))。
* 新增函数 `defaultValueOfTypeName`，返回指定类型的默认值。[#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz))。
* 新增 `date_trunc` 函数，可将日期/时间值截断至指定的日期/时间粒度。[#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko))。
* 支持为列指定 `Default` 压缩编解码器，该编解码器将沿用 `config.xml` 中配置的压缩设置。实现了 [#9074](https://github.com/ClickHouse/ClickHouse/issues/9074)。[#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin))。
* 新增设置项 `min_index_granularity_bytes`，防止误将 `index_granularity_bytes` 设置为过低的值而创建表。[#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc))。
* 新增 `countDigits(x)` 函数，用于统计整数列或 Decimal 列中的十进制位数。新增 `isDecimalOverflow(d, [p])` 函数，用于检查 Decimal 列中的值是否超出其自身（或指定）的精度范围。[#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2))。

<div id="performance-improvement">
  #### 性能提升
</div>

* 执行简单的 `INSERT SELECT` 查询时，自动将 `max_threads` 设置为 1 或 `max_insert_threads`，并将 `max_block_size` 设置为 `min_insert_block_size_rows`。与 [#5907](https://github.com/ClickHouse/ClickHouse/issues/5907) 相关。[#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* 针对 `Array(LowCardinality(T))` 以及常量右侧参数，优化 `has()`、`indexOf()` 和 `countEqual()` 函数。[#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* 略微提升按 UInt8/UInt16 键进行聚合的性能。[#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在扫描 parts 时，如果超出 `max_rows_to_read` 限制则快速失败。此更改的目的是：如果已经明显超出 `max_rows_to_read`，就跳过对所有已选 parts 的 ranges 扫描。对于涉及大量 parts 的查询，此更改效果相当明显。[#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* 为 `Null`、`Memory`、`Distributed` 和 `Buffer` 表引擎启用并行 INSERT。[#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 略微优化带有 LowCardinality 的超短查询。[#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).



<div id="improvement">
  #### 改进
</div>

* 为 DiskS3 添加了缓存层 (将标记和索引文件缓存到本地磁盘) 。[#13076](https://github.com/ClickHouse/ClickHouse/pull/13076) ([Pavel Kovalenko](https://github.com/Jokser)) 。
* 修复了 Decimal 的负 exponent 过大时触发 assert 的问题。修复 [#13188](https://github.com/ClickHouse/ClickHouse/issues/13188)。[#13228](https://github.com/ClickHouse/ClickHouse/pull/13228) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 在 system.events 中添加了 QueryTimeMicroseconds、SelectQueryTimeMicroseconds 和 InsertQueryTimeMicroseconds。[#13336](https://github.com/ClickHouse/ClickHouse/pull/13336) ([ianton-ru](https://github.com/ianton-ru)) 。
* 在 S3 重定向中正确检查远程 host (与安全相关) 。[#13404](https://github.com/ClickHouse/ClickHouse/pull/13404) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 默认启用混合 granularity 的 parts。[#13449](https://github.com/ClickHouse/ClickHouse/pull/13449) ([alesapin](https://github.com/alesapin)) 。
* 支持并行将 parts 从 DIskLocal 移动到 DiskS3。[#13459](https://github.com/ClickHouse/ClickHouse/pull/13459) ([Pavel Kovalenko](https://github.com/Jokser)) 。
* 支持用于 custom settings 的复合标识符。[#13496](https://github.com/ClickHouse/ClickHouse/pull/13496) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 在更多情况下为 `toDate/toDateTime` 函数提供单调性。现在，输入 argument 的饱和处理方式更加自然，并能提供更好的单调性。[#13497](https://github.com/ClickHouse/ClickHouse/pull/13497) ([Amos Bird](https://github.com/amosbird)) 。
* 在早期版本中，若使用特意构造的 argument 调用，`lcm` 函数可能会在 Debug build 中触发断言违规。此项修复了 [#13368](https://github.com/ClickHouse/ClickHouse/issues/13368)。[#13510](https://github.com/ClickHouse/ClickHouse/pull/13510) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 添加了 MergeTree 预写日志 (WAL) 转储工具。[#13640](https://github.com/ClickHouse/ClickHouse/pull/13640) ([BohuTANG](https://github.com/BohuTANG)) 。
* 避免将 Arrays 作为 field 处理时导致查询过慢，改为直接抛出异常。[#13753](https://github.com/ClickHouse/ClickHouse/pull/13753) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 1. 添加 [基于 GTID 的复制](https://dev.mysql.com/doc/refman/5.7/en/replication-gtids-concepts.html)，即使复制拓扑发生变化也能正常工作，并且在 MySQL 5.6/5.7/8.0 中受支持且更推荐使用 2. 添加对 BIT/SET 字段类型的支持 3. 修复 varchar 类型元数据长度的 bug。[#13820](https://github.com/ClickHouse/ClickHouse/pull/13820) ([BohuTANG](https://github.com/BohuTANG)) 。
* 修复 `lgamma` 函数中的数据竞争。该问题仅在 `tsan` 中被发现，实际上并未产生任何副作用。[#13842](https://github.com/ClickHouse/ClickHouse/pull/13842) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 当数组元素类型为 Float32/Float64 时，函数 `arrayCompact` 现在会按位比较 NaN。在之前的版本中，如果数组元素类型为 Float32/Float64，则 NaN 始终被视为不相等；而如果类型更复杂，例如 Nullable(Float64)，则 NaN 始终被视为相等。此更改修复了 [#13857](https://github.com/ClickHouse/ClickHouse/issues/13857)。[#13868](https://github.com/ClickHouse/ClickHouse/pull/13868) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 改进了 TabSeparatedRow 格式中 NULL 值的错误信息。[#13906](https://github.com/ClickHouse/ClickHouse/pull/13906) ([jiang tao](https://github.com/tomjiang1987)).
* 修复长查询时报错不正确的问题。对于正确的查询，此前有可能收到除 `Max query size exceeded` 之外的语法错误。[#13928](https://github.com/ClickHouse/ClickHouse/pull/13928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 修复了 AvroConfluent 格式中的一个错误：收到异常小且格式损坏的消息时，Kafka 表引擎会停止处理消息。[#13941](https://github.com/ClickHouse/ClickHouse/pull/13941) ([Gervasio Varela](https://github.com/gervarela)).
* 将 -Resample 组合器的限制提高到 1M。[#13947](https://github.com/ClickHouse/ClickHouse/pull/13947) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 条件聚合函数 (例如：`avgIf`、`sumIf`、`maxIf`) 在没有行且使用 Nullable 参数时应返回 `NULL`。[#13964](https://github.com/ClickHouse/ClickHouse/pull/13964) ([Winter Zhang](https://github.com/zhang2014)).
* 如果 Memory 表由大量非常小的块构成，其性能会略有提升 (不过这种情况不太常见) 。这个想法的提出者是：[Mark Papadakis](https://github.com/markpapadakis)。关闭了 [#14043](https://github.com/ClickHouse/ClickHouse/issues/14043)。[#14056](https://github.com/ClickHouse/ClickHouse/pull/14056) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 `toDeicmal256()`，并尝试修复 Decimal 到 Float 转换中潜在的性能回退问题。[#14110](https://github.com/ClickHouse/ClickHouse/pull/14110) ([Artem Zuikov](https://github.com/4ertus2)).
* 现在可以执行 `ALTER TABLE table_name FETCH PARTITION partition_expr FROM 'zk://<host>:<port>/path-in-zookeeper'`。这对于向新集群传输数据很有帮助。[#14155](https://github.com/ClickHouse/ClickHouse/pull/14155) ([Amos Bird](https://github.com/amosbird)).
