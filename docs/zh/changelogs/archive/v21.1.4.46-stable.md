<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#19983](https://github.com/ClickHouse/ClickHouse/issues/19983) 中回移：执行 `ON CLUSTER` 查询的后台线程，可能会在等待已删除的复制表执行某些操作时卡住。现已修复。[#19684](https://github.com/ClickHouse/ClickHouse/pull/19684) ([yiguolei](https://github.com/yiguolei)).
* 已在 [#20238](https://github.com/ClickHouse/ClickHouse/issues/20238) 中回移：修复了在启动多个 clickhouse-copier 时，将数据片段移动到目标表可能失败的问题。[#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* 已在 [#20074](https://github.com/ClickHouse/ClickHouse/issues/20074) 中回移：修复了启动服务器时，默认表达式包含 dictGet() 的表无法正常启动的问题。现在允许在不加载字典的情况下获取 dictGet() 的返回类型。[#19805](https://github.com/ClickHouse/ClickHouse/pull/19805) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#19997](https://github.com/ClickHouse/ClickHouse/issues/19997) 中回移：- 修复了函数 `fromModifiedJulianDay` 在 argument type 为 `Nullable(T)`，且 `T` 为除 Int32 之外的任意整数类型时发生的 segfault。[#19959](https://github.com/ClickHouse/ClickHouse/pull/19959) ([PHO](https://github.com/depressed-pho)).
* 已在 [#20122](https://github.com/ClickHouse/ClickHouse/issues/20122) 中回移：MaterializeMySQL：修复了对更新多个表的语句进行复制时的问题。[#20066](https://github.com/ClickHouse/ClickHouse/pull/20066) ([Håvard Kvålen](https://github.com/havardk)).
* 已在 [#20297](https://github.com/ClickHouse/ClickHouse/issues/20297) 中回移：* 修复了 StorageJoin 中的一个缺陷。[#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#20390](https://github.com/ClickHouse/ClickHouse/issues/20390) 中回移：`MongoDB` 表引擎现在仅在需要读取数据时才会建立连接。`ATTACH TABLE` 也不再尝试连接。[#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#20148](https://github.com/ClickHouse/ClickHouse/issues/20148) 中回移：修复了查询中使用 `if` 函数，且 then/else 分支结果为 `Tuple` type 时导致的服务器崩溃问题。该 `Tuple` type 必须包含 `Array` 或其他复杂类型。修复了 [#18356](https://github.com/ClickHouse/ClickHouse/issues/18356)。[#20133](https://github.com/ClickHouse/ClickHouse/pull/20133) ([alesapin](https://github.com/alesapin)).
* 已在 [#20327](https://github.com/ClickHouse/ClickHouse/issues/20327) 中回移：修复了关闭过程中重新加载 config 时极少发生的服务器崩溃问题。修复了 [#19689](https://github.com/ClickHouse/ClickHouse/issues/19689)。[#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* 已在 [#20331](https://github.com/ClickHouse/ClickHouse/issues/20331) 中回移：限制对 `*CollapsingMergeTree` 和 `ReplacingMergeTree` 表引擎的版本列执行 `DROP` 或 `RENAME`。[#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* 已在 [#20363](https://github.com/ClickHouse/ClickHouse/issues/20363) 中回移：修复了 `ReplicatedMergeTree` 表引擎家族中，失败的后台任务重试过于频繁的问题。这可能导致日志过于冗长，并增加 CPU 负载。修复了 [#20203](https://github.com/ClickHouse/ClickHouse/issues/20203)。[#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* 已在 [#20378](https://github.com/ClickHouse/ClickHouse/issues/20378) 中回移：修复两个标度不同的常量 Decimal 之间进行二元运算时结果错误的问题。修复了 [#20283](https://github.com/ClickHouse/ClickHouse/issues/20283)。[#20339](https://github.com/ClickHouse/ClickHouse/pull/20339) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#20375](https://github.com/ClickHouse/ClickHouse/issues/20375) 中回移：修复 `join_use_nulls=1` 时的空指针解引用问题。[#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#20359](https://github.com/ClickHouse/ClickHouse/issues/20359) 中回移：避免 RANGE&#95;HASHED() 字典中发生无效解引用。[#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)) 。
