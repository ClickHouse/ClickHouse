<div id="improvement">
  #### 改进
</div>

* 已在 [#46981](https://github.com/ClickHouse/ClickHouse/issues/46981) 中回移：- 在所有副本上执行 `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'`。因为 `ALTER TABLE t MOVE` 不会复制到其他副本。[#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#47336](https://github.com/ClickHouse/ClickHouse/issues/47336) 中回移：有时在更改某个角色后，使用该角色的用户的访问权限可能不会体现这一变更。此 PR 修复了该问题。[#46772](https://github.com/ClickHouse/ClickHouse/pull/46772) ([Vitaly Baranov](https://github.com/vitlibar)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">

* 已在 [#47156](https://github.com/ClickHouse/ClickHouse/issues/47156) 中回移：- 修复 `min` 和 `max` 聚合优化中的算术操作问题。 [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* 已在 [#46987](https://github.com/ClickHouse/ClickHouse/issues/46987) 中回移：修复会被转换为子串搜索、且包含带引号的非 LIKE 元字符的 LIKE 谓词结果。 [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
* 已在 [#47357](https://github.com/ClickHouse/ClickHouse/issues/47357) 中回移：修复取消分布式查询时可能发生的死锁。 [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).
