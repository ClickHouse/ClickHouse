<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#24170](https://github.com/ClickHouse/ClickHouse/issues/24170) 中回移：修复了一个罕见缺陷，该缺陷可能导致表只完成部分初始化却仍可处理写请求 (insert/alter/等) 。现在这类表将处于 readonly 模式。[#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#24332](https://github.com/ClickHouse/ClickHouse/issues/24332) 中回移：将 `max_threads = 1` 以修复 StorageMemory 的变更失败问题。关闭 [#24274](https://github.com/ClickHouse/ClickHouse/issues/24274)。[#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)) 。
* 已在 [#24382](https://github.com/ClickHouse/ClickHouse/issues/24382) 中回移：允许空 HTTP 请求头。修复 [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901)。[#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)) 。
* 已在 [#24351](https://github.com/ClickHouse/ClickHouse/issues/24351) 中回移：修复了通过 `RENAME TABLE` 查询将 materialized view 从 Ordinary 数据库移动到 Atomic 数据库时的一个缺陷。现在内部表会随 materialized view 一同移动到新数据库中。修复 [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926)。[#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#24509](https://github.com/ClickHouse/ClickHouse/issues/24509) 中回移：修复了带有 intersect fake parts 的 drop partition 问题。在极少数情况下，parts 的变更版本可能大于当前块编号。[#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#24540](https://github.com/ClickHouse/ClickHouse/issues/24540) 中回移：修复了 toWeek 函数单调性错误的问题。此修复解决了 [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422)。该缺陷是在 [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212) 中引入的，之后被更智能的分区裁剪器暴露出来。[#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#24557](https://github.com/ClickHouse/ClickHouse/issues/24557) 中回移：修复了查询 `SYSTEM RESTART REPLICA` 或 `SYSTEM SYNC REPLICA` 无限处理的问题。该问题是在 RAM 极其有限的 server 上发现的。[#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#24598](https://github.com/ClickHouse/ClickHouse/issues/24598) 中回移：修复了在 `CREATE .. AS SELECT` 查询中使用 tuples 的问题。[#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#24601](https://github.com/ClickHouse/ClickHouse/issues/24601) 中回移：为分布式表启用了子列读取。[#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)) 。
