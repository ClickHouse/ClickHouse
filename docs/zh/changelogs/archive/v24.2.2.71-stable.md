<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#60640](https://github.com/ClickHouse/ClickHouse/issues/60640) 中回移：修复了带有 `FINAL` 的查询在并行优化中的一个 bug，该 bug 在极少数情况下可能导致错误结果。[#60041](https://github.com/ClickHouse/ClickHouse/pull/60041) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#61085](https://github.com/ClickHouse/ClickHouse/issues/61085) 中回移：避免对 `CREATE TABLE` 计算标量子查询。修复了 [#59795](https://github.com/ClickHouse/ClickHouse/issues/59795) 和 [#59930](https://github.com/ClickHouse/ClickHouse/issues/59930)。尝试重新实现 [https://github.com/ClickHouse/ClickHouse/pull/57855](https://github.com/ClickHouse/ClickHouse/pull/57855)。[#60464](https://github.com/ClickHouse/ClickHouse/pull/60464) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#61332](https://github.com/ClickHouse/ClickHouse/issues/61332) 中回移：修复了并行 parsing 中的死锁问题，该问题会在因错误跳过大量行时发生。[#60516](https://github.com/ClickHouse/ClickHouse/pull/60516) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#61010](https://github.com/ClickHouse/ClickHouse/issues/61010) 中回移：修复了 KQL 复合类型运算符 (如 mv-expand) 的 `max_query_size` 问题。与 [#59626](https://github.com/ClickHouse/ClickHouse/issues/59626) 相关。[#60534](https://github.com/ClickHouse/ClickHouse/pull/60534) ([Yong Wang](https://github.com/kashwy)) 。
* 已在 [#61002](https://github.com/ClickHouse/ClickHouse/issues/61002) 中回移：减少了从 `system.numbers` 读取的行数。修复了 [#59418](https://github.com/ClickHouse/ClickHouse/issues/59418)。[#60546](https://github.com/ClickHouse/ClickHouse/pull/60546) ([JackyWoo](https://github.com/JackyWoo)) 。
* 已在 [#60629](https://github.com/ClickHouse/ClickHouse/issues/60629) 中回移：不再为 Date 类型输出数值提示。[#60577](https://github.com/ClickHouse/ClickHouse/pull/60577) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#60793](https://github.com/ClickHouse/ClickHouse/issues/60793) 中回移：修复了一类缓冲区溢出问题：如果攻击者请求 HTTP server 解压使用多种编解码器组合且大小会触发数值溢出的数据，就可能发生该问题。还修复了 codec NONE 在输入数据错误时可能发生的缓冲区溢出。该问题由 TIANGONG research team 通过我们的 [Bug Bounty program](https://github.com/ClickHouse/ClickHouse/issues/38986) 提交。[#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#60785](https://github.com/ClickHouse/ClickHouse/issues/60785) 中回移：SQL/JSON Functions 可能会读取未初始化的内存。此项关闭了 [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017)。由 fuzzer 发现。[#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#60805](https://github.com/ClickHouse/ClickHouse/issues/60805) 中回移：在 UploadPart 和 CompleteMultipartUpload 调用中，不设置 AWS 自定义 metadata `x-amz-meta-*` 请求头。[#60748](https://github.com/ClickHouse/ClickHouse/pull/60748) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)) 。
* 已在 [#60822](https://github.com/ClickHouse/ClickHouse/issues/60822) 中回移：修复了 arrayEnumerateRanked 中的崩溃问题。[#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#60843](https://github.com/ClickHouse/ClickHouse/issues/60843) 中回移：修复在 INSERT SELECT JOIN 中使用 input() 时发生崩溃的问题。关闭 [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035)。[#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#60919](https://github.com/ClickHouse/ClickHouse/issues/60919) 中回移：修复在子查询中更改 `allow_experimental_analyzer` 设置值时发生崩溃的问题。[#60770](https://github.com/ClickHouse/ClickHouse/pull/60770) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#60906](https://github.com/ClickHouse/ClickHouse/issues/60906) 中回移：避免从 S3 读取时因跳过过多对象而发生 segfault。[#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#61307](https://github.com/ClickHouse/ClickHouse/issues/61307) 中回移：修复 groupArraySorted 中的多个问题。[#61203](https://github.com/ClickHouse/ClickHouse/pull/61203) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#61295](https://github.com/ClickHouse/ClickHouse/issues/61295) 中回移：Keeper：修复独立二进制程序的运行时重配置问题。[#61233](https://github.com/ClickHouse/ClickHouse/pull/61233) ([Antonio Andelic](https://github.com/antonio2368)) 。
