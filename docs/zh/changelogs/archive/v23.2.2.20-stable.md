  # 2023 更新日志
</div>

<div id="clickhouse-release-v232220-stable-f6c269c8df2-fixme-as-compared-to-v23212537-stable-52bf836e03a">
  ### ClickHouse 发布 v23.2.2.20-stable (f6c269c8df2) FIXME，与 v23.2.1.2537-stable (52bf836e03a) 相比
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#46914](https://github.com/ClickHouse/ClickHouse/issues/46914) 中回移：允许在列 DEFAULT 表达式不同的 Merge 上使用 PREWHERE。[#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#47022](https://github.com/ClickHouse/ClickHouse/issues/47022) 中回移：允许在 range() 中使用 IPv4。[#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#46828](https://github.com/ClickHouse/ClickHouse/issues/46828) 中回移：在某些情况下，由多个 PREWHERE 累积而成的组合 PREWHERE 列不会包含前面步骤中的 0 值。修复方式是：如果能够确定该过滤器在最后超过 1 个步骤中尚未应用，则应用最终过滤器。[#46785](https://github.com/ClickHouse/ClickHouse/pull/46785) ([Alexander Gololobov](https://github.com/davenger)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#47062](https://github.com/ClickHouse/ClickHouse/issues/47062) 中回移：修复在旧发行版 (如亚马逊 Linux 2) 和 ARM 平台上启动 server 时因找不到 glibc 2.28 符号而报错的问题。[#47008](https://github.com/ClickHouse/ClickHouse/pull/47008) ([Robert Schulze](https://github.com/rschu1ze)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#46895](https://github.com/ClickHouse/ClickHouse/issues/46895) 中回移：修复了 `ReplicatedMergeTree` 表和 `Atomic` 数据库中 `DROP TABLE` 查询自动重试的一个缺陷。在极少数情况下，如果 ZooKeeper 会话在 DROP 期间过期，同时又并行创建了一个在 ZooKeeper 中使用相同路径的新复制表，可能会导致出现 `Can't get data for node /zk_path/log_pointer` 和 `The specified key does not exist` 错误。[#46384](https://github.com/ClickHouse/ClickHouse/pull/46384) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#46865](https://github.com/ClickHouse/ClickHouse/issues/46865) 中回移：修复了 `Map` 数据类型中的一个缺陷。此更改关闭了 [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855)。[#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#46958](https://github.com/ClickHouse/ClickHouse/issues/46958) 中回移：修复了会被转换为子串搜索且包含带引号的非 LIKE 元字符的 LIKE 谓词结果错误。[#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="not-for-changelog-insignificant">
  #### 不计入更新日志 / 影响较小

* 减少对 Mergeable Check 的更新 [#46781](https://github.com/ClickHouse/ClickHouse/pull/46781) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
