<div id="improvement">
  #### 改进
</div>

* 已在 [#57668](https://github.com/ClickHouse/ClickHouse/issues/57668) 中回移：在通过 HTTP 执行查询时发生异常，也会输出有效的 JSON/XML。新增设置 `http_write_exception_in_output_format`，用于启用/禁用此行为 (默认启用) 。 [#52853](https://github.com/ClickHouse/ClickHouse/pull/52853) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#58491](https://github.com/ClickHouse/ClickHouse/issues/58491) 中回移：将 transfer 查询修复为与 MySQL 兼容的查询。修复了 [#57253](https://github.com/ClickHouse/ClickHouse/issues/57253)。修复了 [#52654](https://github.com/ClickHouse/ClickHouse/issues/52654)。修复了 [#56729](https://github.com/ClickHouse/ClickHouse/issues/56729)。 [#56456](https://github.com/ClickHouse/ClickHouse/pull/56456) ([flynn](https://github.com/ucasfl)).
* 已在 [#57238](https://github.com/ClickHouse/ClickHouse/issues/57238) 中回移：拉取分片时，会等待该分片在远程副本上完全提交。最好不要发送处于 PreActive 状态的分片；在零拷贝场景下，这是强制限制。 [#56808](https://github.com/ClickHouse/ClickHouse/pull/56808) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#57655](https://github.com/ClickHouse/ClickHouse/issues/57655) 中回移：修复了获取包含空数组的 PostgreSQL 表结构时出现的 SIGABRT 问题。 [#57618](https://github.com/ClickHouse/ClickHouse/pull/57618) ([Mikhail Kot](https://github.com/myrrc)).

* 已在 [#58324](https://github.com/ClickHouse/ClickHouse/issues/58324) 中回移：当 flatten&#95;nested=1 时，仅展平真正的 Nested 类型，而不是所有 Array(Tuple)。[#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#57395](https://github.com/ClickHouse/ClickHouse/issues/57395) 中回移：修复带 ALIAS 的 ALTER COLUMN 此前会抛出 `NO_SUCH_COLUMN_IN_TABLE` 异常的问题。关闭 [#50927](https://github.com/ClickHouse/ClickHouse/issues/50927)。[#56493](https://github.com/ClickHouse/ClickHouse/pull/56493) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#57449](https://github.com/ClickHouse/ClickHouse/issues/57449) 中回移：现在将禁止对与某些投影中使用的列不兼容的列执行 ALTER。此前这可能导致数据错误。此修复解决了 [#56932](https://github.com/ClickHouse/ClickHouse/issues/56932)。此 PR 还允许对索引列执行 RENAME，并通过明确指出导致阻止操作的受影响索引或投影，改进了异常消息。[#56948](https://github.com/ClickHouse/ClickHouse/pull/56948) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#57281](https://github.com/ClickHouse/ClickHouse/issues/57281) 中回移：修复带 Nullable MATERIALIZED 列的 ALTER UPDATE 后发生的 segfault。关闭 [#42918](https://github.com/ClickHouse/ClickHouse/issues/42918)。[#57147](https://github.com/ClickHouse/ClickHouse/pull/57147) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#57247](https://github.com/ClickHouse/ClickHouse/issues/57247) 中回移：修复对部分 materialized 的常规 projection 进行错误 JOIN plan 优化的问题。此修复解决了 [#57194](https://github.com/ClickHouse/ClickHouse/issues/57194)。[#57196](https://github.com/ClickHouse/ClickHouse/pull/57196) ([Amos Bird](https://github.com/amosbird)).
