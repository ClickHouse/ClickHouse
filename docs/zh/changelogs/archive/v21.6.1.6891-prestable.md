<div id="new-feature">
  #### 新特性
</div>

* 为 MergeTree* 表添加投影支持。[#20202](https://github.com/ClickHouse/ClickHouse/pull/20202) ([Amos Bird](https://github.com/amosbird)) 。
* 恢复 `indexHint` 函数，用于解决 [#21238](https://github.com/ClickHouse/ClickHouse/issues/21238)。此更改回退了 [https://github.com/ClickHouse/ClickHouse/pull/9542](https://github.com/ClickHouse/ClickHouse/pull/9542)。此更改修复了 [#9540](https://github.com/ClickHouse/ClickHouse/issues/9540)。[#21304](https://github.com/ClickHouse/ClickHouse/pull/21304) ([Amos Bird](https://github.com/amosbird)) 。
* 1. 新增聚合函数 sumCount。该函数返回一个包含两个字段 (sum 和 count) 的元组。[#21337](https://github.com/ClickHouse/ClickHouse/pull/21337) ([hexiaoting](https://github.com/hexiaoting)).
* 新增了一个适用于 S3 的低安全性 IMDS 凭证提供程序，可在 docker 环境下正常工作。[#21852](https://github.com/ClickHouse/ClickHouse/pull/21852) ([Vladimir Chebotarev](https://github.com/excitoon)).
* * 新增聚合函数 `deltaSumTimestamp`：通过存储时间戳，在 merge 过程中保持顺序，并对相邻行之间的差值求和。[#21888](https://github.com/ClickHouse/ClickHouse/pull/21888) ([Russ Frank](https://github.com/rf)) 。
* * LDAP：新增了 user DN 检测功能，可在将 Active Directory 组映射到 ClickHouse 角色时使用。[#22228](https://github.com/ClickHouse/ClickHouse/pull/22228) ([Denis Glazachev](https://github.com/traceon)).
* 引入新函数：`arrayProduct`，接受一个数组作为参数，并返回数组中所有元素的乘积。关闭 issue：[#21613](https://github.com/ClickHouse/ClickHouse/issues/21613)。[#22242](https://github.com/ClickHouse/ClickHouse/pull/22242) ([hexiaoting](https://github.com/hexiaoting)).
* 为 `EXPLAIN PIPELINE` 查询添加设置 `indexes` (布尔值，默认禁用) 。启用后，会显示使用到的索引，以及每个已应用索引过滤掉的 `parts` 和粒度数量。支持 `MergeTree*` 表。[#22352](https://github.com/ClickHouse/ClickHouse/pull/22352) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 为 `EXPLAIN PLAN` 查询添加设置 `json` (布尔值，默认值为 0) 。启用后，查询输出将为单个 `JSON` 行。建议使用 `TSVRaw` format，以避免不必要的转义。[#23082](https://github.com/ClickHouse/ClickHouse/pull/23082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 添加了 `SYSTEM QUERY RELOAD MODEL`、`SYSTEM QUERY RELOAD MODELS`。关闭 [#18722](https://github.com/ClickHouse/ClickHouse/issues/18722)。[#23182](https://github.com/ClickHouse/ClickHouse/pull/23182) ([Maksim Kita](https://github.com/kitaisreal)).
* 为 LocalServer 添加了进度条，并将其统一用于 Client 和 Local。[#23196](https://github.com/ClickHouse/ClickHouse/pull/23196) ([Egor Savin](https://github.com/Amesaru)).
* 为 DatabaseMemory 增加对 DDL 字典的支持。关闭 [#22354](https://github.com/ClickHouse/ClickHouse/issues/22354)。增加了对 `DETACH DICTIONARY PERMANENTLY` 的支持。为 Atomic database engine 增加了对 `EXCHANGE DICTIONARIES` 的支持。增加了使用 `RENAME DICTIONARY` 在数据库之间移动字典的支持。[#23436](https://github.com/ClickHouse/ClickHouse/pull/23436) ([Maksim Kita](https://github.com/kitaisreal)).
* 为 URL table function 支持 `{...}` 通配符 (其作用类似于 shards) ，以及使用分隔符 `|` 的故障转移选项。关闭 [#17181](https://github.com/ClickHouse/ClickHouse/issues/17181)。[#23446](https://github.com/ClickHouse/ClickHouse/pull/23446) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 如果 `insert_null_as_default` = 1，则在 `INSERT ... SELECT` 和 `INSERT ... SELECT ... UNION ALL ...` 查询中插入默认值而不是 NULL。关闭 [#22832](https://github.com/ClickHouse/ClickHouse/issues/22832)。[#23524](https://github.com/ClickHouse/ClickHouse/pull/23524) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 实现了表注释。关闭 [#23225](https://github.com/ClickHouse/ClickHouse/issues/23225)。[#23548](https://github.com/ClickHouse/ClickHouse/pull/23548) ([flynn](https://github.com/ucasfl)).
* 引入新函数：`arrayProduct`，接受一个数组作为参数，并返回数组中所有元素的乘积。关闭 [#21613](https://github.com/ClickHouse/ClickHouse/issues/21613)。[#23782](https://github.com/ClickHouse/ClickHouse/pull/23782) ([Maksim Kita](https://github.com/kitaisreal)).
* 添加了类似 Postgres 的类型转换运算符 (`::`) 。例如：`[1, 2]::Array(UInt8)`、`0.1::Decimal(4, 4)`、`number::UInt16`。[#23871](https://github.com/ClickHouse/ClickHouse/pull/23871) ([Anton Popov](https://github.com/CurtizJ)).
* ... [#23910](https://github.com/ClickHouse/ClickHouse/pull/23910) ([Xiang Zhou](https://github.com/javainthinking)).
* 添加函数 `splitByRegexp`。[#24077](https://github.com/ClickHouse/ClickHouse/pull/24077) ([abel-cheng](https://github.com/abel-cheng)).
* 在 `system.stack_trace` 中添加 `thread_name` 列。此更改解决了 [#23256](https://github.com/ClickHouse/ClickHouse/issues/23256)。[#24124](https://github.com/ClickHouse/ClickHouse/pull/24124) ([abel-cheng](https://github.com/abel-cheng)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 默认启用 `compile_expressions` 设置。启用此设置后，简单函数和运算符的组合将在运行时通过 LLVM 编译为原生代码。[#8482](https://github.com/ClickHouse/ClickHouse/pull/8482) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ORC 输入格式按 stripe 读取，而不是一次性将整个表读入内存；在文件很大时，这会占用大量内存。[#23102](https://github.com/ClickHouse/ClickHouse/pull/23102) ([Chao Ma](https://github.com/godliness)).
* 更新 `re2` 库。正则表达式匹配性能得到提升。此外，此 PR 还增加了对 gcc-11 的兼容性。[#24196](https://github.com/ClickHouse/ClickHouse/pull/24196) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### 改进
</div>

* 支持在 Arrow、Parquet 和 ORC 格式中插入和选择 Array 数据类型的数据。[#21770](https://github.com/ClickHouse/ClickHouse/pull/21770) ([taylor12805](https://github.com/taylor12805)).
* 为 MySQL 表引擎、字典源和 MaterializeMySQL 的小批量数据拉取新增设置 `external_storage_max_read_rows` 和 `external_storage_max_read_rows`。[#22697](https://github.com/ClickHouse/ClickHouse/pull/22697) ([TCeason](https://github.com/TCeason)).
* 对 S3 中断开的 HTTP 连接进行重试。[#22988](https://github.com/ClickHouse/ClickHouse/pull/22988) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 修复了这样一种情况：在 `clickhouse-client` 的交互模式下，出现在数据中间的进度条可能会覆盖终端中部分可见数据。此更改关闭了 [#19283](https://github.com/ClickHouse/ClickHouse/issues/19283)。[#23050](https://github.com/ClickHouse/ClickHouse/pull/23050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新增了将 MergeTree parts 恢复到 DiskS3 的 &#39;detached&#39; 目录的能力。[#23112](https://github.com/ClickHouse/ClickHouse/pull/23112) ([Pavel Kovalenko](https://github.com/Jokser)).
* 向分布式表写入时跳过不可用的副本。[#23152](https://github.com/ClickHouse/ClickHouse/pull/23152) ([Amos Bird](https://github.com/amosbird)).
* 支持在启用 `join_use_nulls` 时 LowCardinality 的可空性，关闭了 [#15101](https://github.com/ClickHouse/ClickHouse/issues/15101)。[#23237](https://github.com/ClickHouse/ClickHouse/pull/23237) ([Vladimir C](https://github.com/vdimir)).
* 禁用设置 `use_hedged_requests` 和 `async_socket_for_remote`，因为有证据表明它们可能会导致问题。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了 `quantile(s)TDigest`。根据 tdunning/t-digest 3.2+，新增了对单质心的特殊处理。同时还修复了该算法早期版本实现中质心过度压缩的问题。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 允许用户为 `MySQL` 存储指定空字符串来代替数据库名称。查询将使用默认数据库。在此前版本中，这仅对 SELECT 查询有效，现在也增加了对 INSERT 的支持。此更改关闭了 [#19281](https://github.com/ClickHouse/ClickHouse/issues/19281)。这对于配合 `Sphinx` 或其他兼容 MySQL 的外部数据库使用会很有帮助。[#23319](https://github.com/ClickHouse/ClickHouse/pull/23319) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 默认禁用 min&#95;bytes&#95;to&#95;use&#95;mmap&#95;io。[#23322](https://github.com/ClickHouse/ClickHouse/pull/23322) ([Azat Khuzhin](https://github.com/azat)).
* 如果用户因误配置将 `max_distributed_connections` 设为零，那么对 `Distributed` 表的每个查询都会抛出一条包含 &quot;logical error&quot; 的异常消息。但这实际上是预期行为，而不是 logical error，因此该异常消息略有不准确。它还会触发我们 CI 环境中的检查，而该检查会确保绝不会发生 logical error。现在，我们会将错误配置为零的 `max_distributed_connections` 视为最小可能值 (一) 。[#23348](https://github.com/ClickHouse/ClickHouse/pull/23348) ([Azat Khuzhin](https://github.com/azat)).
* 如果在 DateTime 运算中未显式指定时区，则保留默认时区的处理方式。例如，如果你给一个不带时区的 `DateTime` 类型值加 1 秒，它仍然会是一个不带时区的 `DateTime`。在之前的版本中，默认时区的值会被显式写入返回的数据类型，因此会变成 DateTime(&#39;something&#39;)。这关闭了 [#4854](https://github.com/ClickHouse/ClickHouse/issues/4854)。[#23392](https://github.com/ClickHouse/ClickHouse/pull/23392) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 以前由于 SQL 不兼容，不支持 MySQL 5.7.9。现在将 MySQL 参数校验交由 MaterializeMySQL 处理。[#23413](https://github.com/ClickHouse/ClickHouse/pull/23413) ([TCeason](https://github.com/TCeason)).
* 可以通过新的 `SYSTEM RESTART DISK` SQL 命令在运行时更改 S3 disk 设置。[#23429](https://github.com/ClickHouse/ClickHouse/pull/23429) ([Pavel Kovalenko](https://github.com/Jokser)).
* 让 OPTIMIZE 遵循 lock&#95;acquire&#95;timeout&#95;for&#95;background&#95;operations 设置。[#23623](https://github.com/ClickHouse/ClickHouse/pull/23623) ([Azat Khuzhin](https://github.com/azat)).
* 使大整数达到生产可用级别。新增对 `UInt128` 数据类型的支持。修复 `Decimal256` 数据类型的已知问题。支持在字典中使用大整数。支持对大整数使用 `gcd`/`lcm` 函数。支持在数组搜索和条件函数中使用大整数。支持 `LowCardinality(UUID)`。支持在 `generateRandom` 表函数和 `clickhouse-obfuscator` 中使用大整数。修复从标量子查询返回 `UUID` 时的错误。这修复了 [#7834](https://github.com/ClickHouse/ClickHouse/issues/7834)。这修复了 [#23936](https://github.com/ClickHouse/ClickHouse/issues/23936)。这修复了 [#4176](https://github.com/ClickHouse/ClickHouse/issues/4176)。这修复了 [#24018](https://github.com/ClickHouse/ClickHouse/issues/24018)。这修复了 [#17828](https://github.com/ClickHouse/ClickHouse/issues/17828)。不向后兼容的变更：`UUID` 类型的值不能与整数比较。例如，不要写 `uuid != 0`，而应写成 `uuid != '00000000-0000-0000-0000-000000000000'`。[#23631](https://github.com/ClickHouse/ClickHouse/pull/23631) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 MergeTree 表家族添加 `_partition_value` 虚拟列。它可用于以确定性的方式进行分区裁剪。这是为变更实现分区匹配器所必需的。[#23673](https://github.com/ClickHouse/ClickHouse/pull/23673) ([Amos Bird](https://github.com/amosbird)).
* 默认启用 `async_socket_for_remote`。[#23683](https://github.com/ClickHouse/ClickHouse/pull/23683) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 当某些 `ReplicatedMergeTree` 表的 ZooKeeper 会话过期时，如果在启用 `select_sequential_consistency` 的情况下从 `system.tables` 查询某个表的元数据，会抛出如下错误：`Session expired (Session expired): While executing Tables`。[#23793](https://github.com/ClickHouse/ClickHouse/pull/23793) ([Fuwang Hu](https://github.com/fuwhu)).
* 为 S3 存储和 disk 添加了 `region` 参数。[#23846](https://github.com/ClickHouse/ClickHouse/pull/23846) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 允许为不同的日志通道配置不同的日志级别。关闭 [#19569](https://github.com/ClickHouse/ClickHouse/issues/19569)。[#23857](https://github.com/ClickHouse/ClickHouse/pull/23857) ([filimonov](https://github.com/filimonov)).
* 在 `system.distribution_queue` 中添加 `broken_data_files`/`broken_data_compressed_bytes`。为分布式表异步插入过程中被标记为损坏的文件数量新增指标 (`BrokenDistributedFilesToInsert`) 。[#23885](https://github.com/ClickHouse/ClickHouse/pull/23885) ([Azat Khuzhin](https://github.com/azat)).
* 允许通过表设置 `rabbitmq_queue_settings_list` 添加特定队列设置。 (关闭 [#23737](https://github.com/ClickHouse/ClickHouse/issues/23737) 和 [#23918](https://github.com/ClickHouse/ClickHouse/issues/23918)) 。允许用户控制全部 RabbitMQ 设置：如果表设置 `rabbitmq_queue_consume` 设为 `1`，RabbitMQ 表引擎将只连接到指定队列，不会执行任何 RabbitMQ 消费者端设置，例如声明 exchange、队列和 bindings。 (关闭 [#21757](https://github.com/ClickHouse/ClickHouse/issues/21757)) 。在删除 RabbitMQ 表时增加了适当的清理逻辑——删除该表声明的队列，以及所有与之绑定的 exchanges (如果它们是由该表创建的) 。[#23887](https://github.com/ClickHouse/ClickHouse/pull/23887) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 为字典增加 found rate (找到值的比例) 统计 (参见 `system.dictionaries` 中的 `found_rate`) 。[#23916](https://github.com/ClickHouse/ClickHouse/pull/23916) ([Azat Khuzhin](https://github.com/azat)).
* 为 Enum 名称添加提示。关闭 [#17112](https://github.com/ClickHouse/ClickHouse/issues/17112)。[#23919](https://github.com/ClickHouse/ClickHouse/pull/23919) ([flynn](https://github.com/ucasfl)).
* 在 `http` 字典源中增加对 HTTP 压缩 (由 `Content-Encoding` HTTP 请求头决定) 的支持。此更改修复了 [#8912](https://github.com/ClickHouse/ClickHouse/issues/8912)。[#23946](https://github.com/ClickHouse/ClickHouse/pull/23946) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* 为 hashed/sparse&#95;hashed 字典添加预分配支持。[#23979](https://github.com/ClickHouse/ClickHouse/pull/23979) ([Azat Khuzhin](https://github.com/azat)).
* 支持为 PostgreSQL 字典源指定表 schema。关闭 [#23958](https://github.com/ClickHouse/ClickHouse/issues/23958)。[#23980](https://github.com/ClickHouse/ClickHouse/pull/23980) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 在服务器启动时记录操作系统名称、内核版本和 CPU 架构信息。[#23988](https://github.com/ClickHouse/ClickHouse/pull/23988) ([Azat Khuzhin](https://github.com/azat)).
* 支持将 DateTime64 用作 ReplacingMergeTree 中的版本列。[#23992](https://github.com/ClickHouse/ClickHouse/pull/23992) ([kevin wan](https://github.com/MaxWk)).
* 添加对 `ORDER BY WITH FILL` 与 `DateTime64` 组合使用的支持。[#24016](https://github.com/ClickHouse/ClickHouse/pull/24016) ([kevin wan](https://github.com/MaxWk)).
* 现在 `prefer_column_name_to_alias = 1` 也会在 `group by`、`having` 和 `order by` 中优先使用列名。此更改修复了 [#23882](https://github.com/ClickHouse/ClickHouse/issues/23882)。[#24022](https://github.com/ClickHouse/ClickHouse/pull/24022) ([Amos Bird](https://github.com/amosbird)).
* 对于 Buffer 引擎，不再为 total&#95;bytes/total&#95;rows 获取锁。[#24066](https://github.com/ClickHouse/ClickHouse/pull/24066) ([Azat Khuzhin](https://github.com/azat)).

* 将 zstd 更新到 v1.5.0。[#24135](https://github.com/ClickHouse/ClickHouse/pull/24135) ([Raúl Marín](https://github.com/Algunenano)).
* 修复 simdjson 中内存分配失败时导致崩溃的问题。[https://github.com/simdjson/simdjson/pull/1567](https://github.com/simdjson/simdjson/pull/1567) 。由于这是一个罕见的 bug，因此将其归为改进项。[#24147](https://github.com/ClickHouse/ClickHouse/pull/24147) ([Amos Bird](https://github.com/amosbird)).

* 修复了在远程查询返回 `unknown packet` 时可能发生的崩溃 (启用 `async_socket_for_remote` 时) 。可能修复了 [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167)。[#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
