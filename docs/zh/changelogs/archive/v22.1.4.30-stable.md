* 将 CI 检查回移到 22.1 发布分支。[#34897](https://github.com/ClickHouse/ClickHouse/pull/34897) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#34119](https://github.com/ClickHouse/ClickHouse/issues/34119) 中回移：修复在分布式查询中使用带字面量参数的函数 `array` 和 `tuple` 时的问题。此前这可能导致 `Not found columns` 异常。[#33938](https://github.com/ClickHouse/ClickHouse/pull/33938) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#34124](https://github.com/ClickHouse/ClickHouse/issues/34124) 中回移：修复读取嵌套元组时发生崩溃的问题。修复了 [#33838](https://github.com/ClickHouse/ClickHouse/issues/33838)。[#33956](https://github.com/ClickHouse/ClickHouse/pull/33956) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#34098](https://github.com/ClickHouse/ClickHouse/issues/34098) 中回移：修复解析页脚损坏的 ORC 文件时发生 segfault 的问题。关闭 [#33797](https://github.com/ClickHouse/ClickHouse/issues/33797)。[#33984](https://github.com/ClickHouse/ClickHouse/pull/33984) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#34038](https://github.com/ClickHouse/ClickHouse/issues/34038) 中回移：修复一个 bug：当同时使用 replicated access storage 和 keeper 时，server 无法启动。新增了两个 keeper 套接字 timeout 设置，不再使用 default user 的设置：`keeper_server.socket_receive_timeout_sec` 和 `keeper_server.socket_send_timeout_sec`。修复了 [#33973](https://github.com/ClickHouse/ClickHouse/issues/33973)。[#33988](https://github.com/ClickHouse/ClickHouse/pull/33988) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#34184](https://github.com/ClickHouse/ClickHouse/issues/34184) 中回移：修复了一个轻微的竞态条件，该问题在 ZooKeeper 连接丢失后极少数情况下可能导致 “intersecting parts” 错误。[#34096](https://github.com/ClickHouse/ClickHouse/pull/34096) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#34467](https://github.com/ClickHouse/ClickHouse/issues/34467) 中回移：修复 native protocol 变更后向分布式表插入数据的问题。上一次变更发生在 22.1 版本，因此升级到该版本后，向分布式表插入数据可能会失败。[#34132](https://github.com/ClickHouse/ClickHouse/pull/34132) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#34209](https://github.com/ClickHouse/ClickHouse/issues/34209) 中回移：修复一个 bug：在极少数情况下，读取将数据存储在 S3 等远程文件系统上的 MergeTree 表引擎家族的 LowCardinality 列时，可能出现 “Cannot read all data” 错误。[#34139](https://github.com/ClickHouse/ClickHouse/pull/34139) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#34266](https://github.com/ClickHouse/ClickHouse/issues/34266) 中回移：修复指标 `Query`，该指标显示正在执行的查询数量。在最近几个发行版中，它始终为 0。[#34224](https://github.com/ClickHouse/ClickHouse/pull/34224) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#34298](https://github.com/ClickHouse/ClickHouse/issues/34298) 中回移：修复进度条宽度问题。此前它被错误地舍入为整数个字符。[#34275](https://github.com/ClickHouse/ClickHouse/pull/34275) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#34391](https://github.com/ClickHouse/ClickHouse/issues/34391) 中回移：尝试修复读取空数组时罕见出现的 bug，该问题可能导致 `Data compressed with different methods` 错误。[#34327](https://github.com/ClickHouse/ClickHouse/pull/34327) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#34430](https://github.com/ClickHouse/ClickHouse/issues/34430) 中回移：修复从 URL 进行 schema inference 时的 segfault。关闭 [#34147](https://github.com/ClickHouse/ClickHouse/issues/34147)。[#34405](https://github.com/ClickHouse/ClickHouse/pull/34405) ([Kruglov Pavel](https://github.com/Avogar)) 。
