<div id="bug-fix">

* 已在 [#27981](https://github.com/ClickHouse/ClickHouse/issues/27981) 中回移：修复了 windowFunnel 的“strict”模式问题。此修复解决了 [#27469](https://github.com/ClickHouse/ClickHouse/issues/27469)。[#27563](https://github.com/ClickHouse/ClickHouse/pull/27563) ([achimbab](https://github.com/achimbab)).
* 已在 [#27922](https://github.com/ClickHouse/ClickHouse/issues/27922) 中回移：在 [https://github.com/ClickHouse/ClickHouse/pull/26864](https://github.com/ClickHouse/ClickHouse/pull/26864) 之后，修复了 `NamedSessionStorage` 的关闭问题：现在，存储在 `NamedSessionStorage` 中的 session 上下文会在全局 Context 销毁前先行销毁。[#27875](https://github.com/ClickHouse/ClickHouse/pull/27875) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#27926](https://github.com/ClickHouse/ClickHouse/issues/27926) 中回移：修复了 PostgreSQL 风格的类型转换 (`::` 运算符) 在处理负数时的问题。[#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#27959](https://github.com/ClickHouse/ClickHouse/issues/27959) 中回移：修复了从 `LowCardinality(UUID)` 类型列中选择 Extremes 时的问题。[#27918](https://github.com/ClickHouse/ClickHouse/pull/27918) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#27954](https://github.com/ClickHouse/ClickHouse/issues/27954) 中回移：在创建 Distributed 表前检查 cluster 名称，不允许使用错误的 cluster 名称创建表。修复了 [#27832](https://github.com/ClickHouse/ClickHouse/issues/27832)。[#27927](https://github.com/ClickHouse/ClickHouse/pull/27927) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#28000](https://github.com/ClickHouse/ClickHouse/issues/28000) 中回移：修复了使用 ON CLUSTER 子句执行 GRANT WITH REPLACE 语句时，对访问授权的检查问题。此 PR 改进了对 [https://github.com/ClickHouse/ClickHouse/pull/27701](https://github.com/ClickHouse/ClickHouse/pull/27701) 的修复。[#27983](https://github.com/ClickHouse/ClickHouse/pull/27983) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#28210](https://github.com/ClickHouse/ClickHouse/issues/28210) 中回移：修复了读取缓冲区出现“attempt to read after end of file”报错的情况。关闭了 [#26149](https://github.com/ClickHouse/ClickHouse/issues/26149)。[#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* 已在 [#28750](https://github.com/ClickHouse/ClickHouse/issues/28750) 中回移：修复了在分布式查询中将析取链转换为 `IN` 的问题 (由设置 `optimize_min_equality_disjunction_chain_length` 控制) ，该问题出现在设置 `legacy_column_name_of_tuple_literal = 0` 时。[#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).
