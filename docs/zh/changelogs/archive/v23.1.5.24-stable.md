<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#47060](https://github.com/ClickHouse/ClickHouse/issues/47060) 中回移：修复了旧版发行版 (例如亚马逊 Linux 2) 以及 ARM 平台上 server 启动时因找不到 glibc 2.28 符号而报错的问题。[#47008](https://github.com/ClickHouse/ClickHouse/pull/47008) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#46401](https://github.com/ClickHouse/ClickHouse/issues/46401) 中回移：修复 `SYSTEM UNFREEZE` 查询因异常 `CANNOT_PARSE_INPUT_ASSERTION_FAILED` 而失败的问题。[#46325](https://github.com/ClickHouse/ClickHouse/pull/46325) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 已在 [#46905](https://github.com/ClickHouse/ClickHouse/issues/46905) 中回移：修复 QueryNormalizer 中错误的别名递归问题。[#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#47211](https://github.com/ClickHouse/ClickHouse/issues/47211) 中回移：在某些情况下，通过 native TCP protocol 和 HTTP protocol 发出的 `INSERT` 查询无法被正确取消。如果客户端取消查询、客户端崩溃，或者在少数情况下发生网络错误，可能会导致查询只被部分执行，进而导致去重无法正常工作。修复了 [#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) 和 [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377)。[#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#47118](https://github.com/ClickHouse/ClickHouse/issues/47118) 中回移：修复使用 `min` 和 `max` 进行聚合优化时的算术操作问题。[#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* 已在 [#46883](https://github.com/ClickHouse/ClickHouse/issues/46883) 中回移：修复 `maxIntersections` 函数中的 MSan 报告。此修复关闭了 [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126)。[#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#47361](https://github.com/ClickHouse/ClickHouse/issues/47361) 中回移：修复分布式查询取消时可能发生的死锁问题。[#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).
