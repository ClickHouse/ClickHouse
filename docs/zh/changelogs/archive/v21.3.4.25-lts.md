* 已在 [#21928](https://github.com/ClickHouse/ClickHouse/issues/21928) 中回移：修复 Kafka 的 Avro 格式解析问题。修复了 [#21437](https://github.com/ClickHouse/ClickHouse/issues/21437)。[#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)) 。
* 已在 [#22089](https://github.com/ClickHouse/ClickHouse/issues/22089) 中回移：如果查询包含常量 `WHERE` 条件，且启用了 `optimize_skip_unused_shards` 设置，则可能会跳过所有分片，导致查询错误地返回空结果。[#21550](https://github.com/ClickHouse/ClickHouse/pull/21550) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#21793](https://github.com/ClickHouse/ClickHouse/issues/21793) 中回移：如果向 S3 写入数据时发生错误，会调用 `std::terminate`。[#21624](https://github.com/ClickHouse/ClickHouse/pull/21624) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#21746](https://github.com/ClickHouse/ClickHouse/issues/21746) 中回移：在 DDLWorker 和字典初始化完成后才开始接受连接。[#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#21749](https://github.com/ClickHouse/ClickHouse/issues/21749) 中回移：修复 `ReplicatedMergeTree` 并发执行 `OPTIMIZE` 和 `DROP` 时的问题。[#21716](https://github.com/ClickHouse/ClickHouse/pull/21716) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#21878](https://github.com/ClickHouse/ClickHouse/issues/21878) 中回移：修复使用两级聚合时，带有 Distinct 组合器的聚合函数可能崩溃的问题。这是对 [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365) 的后续修复。该问题只能在生产环境中复现。暂时还没有测试用例。cc @CurtizJ。[#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#22051](https://github.com/ClickHouse/ClickHouse/issues/22051) 中回移：修复首次执行 catboost 模型时的死锁问题。关闭了 [#13832](https://github.com/ClickHouse/ClickHouse/issues/13832)。[#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#21993](https://github.com/ClickHouse/ClickHouse/issues/21993) 中回移：修复当查询包含窗口函数且应用了按主键顺序读取优化时，`ORDER BY` 结果错误的问题。修复了 [#21828](https://github.com/ClickHouse/ClickHouse/issues/21828)。[#21915](https://github.com/ClickHouse/ClickHouse/pull/21915) ([Alexander Kuzmenkov](https://github.com/akuzm)) 。
* 已在 [#22180](https://github.com/ClickHouse/ClickHouse/issues/22180) 中回移：修复读取内容类型为 &quot;multipart/form-data&quot; 的 HTTP POST 请求时的问题。[#21936](https://github.com/ClickHouse/ClickHouse/pull/21936) ([Ivan](https://github.com/abyss7)) 。
* 已在 [#21982](https://github.com/ClickHouse/ClickHouse/issues/21982) 中回移：防止对冲连接发生重叠 (`Unknown packet 9 from server` 错误) 。[#21941](https://github.com/ClickHouse/ClickHouse/pull/21941) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#21980](https://github.com/ClickHouse/ClickHouse/issues/21980) 中回移：回退了 [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454)，该改动在加载 hashed 类型的外部字典时可能导致内存占用显著增加。并关闭了 [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935)。[#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)) 。
