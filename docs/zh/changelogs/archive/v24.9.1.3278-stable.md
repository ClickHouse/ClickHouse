<div id="backward-incompatible-change">
  #### 不向后兼容的变更
</div>

* 当子查询位于括号内时，在带有 `UNION` 的查询链中允许将 `SETTINGS` 写在 `FORMAT` 之前。这解决了 [#39712](https://github.com/ClickHouse/ClickHouse/issues/39712)。同时，还更改了在同一个查询序列中两次指定 SETTINGS clause 时的行为：离相应子查询最近的 SETTINGS clause 将优先生效。在之前的版本中，最外层的 SETTINGS clause 可能会优先于内层生效。[#60197](https://github.com/ClickHouse/ClickHouse/pull/60197) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在 Replicated 数据库中创建表时，不再允许显式指定 UUID。此外，对于 Replicated 数据库中的 *MergeTree 表，也不再允许显式指定 ZooKeeper 路径和副本名称。[#66104](https://github.com/ClickHouse/ClickHouse/pull/66104) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 重构了 Dynamic 类型。现在，当动态 data types 的数量达到上限时，新类型不会再被转换为 String，而是会以二进制格式存储在一种特殊的数据结构中，并带有二进制编码的 data type 信息。现在，任何曾插入到 Dynamic 列中的类型，都可以作为子列从中读取。[#68132](https://github.com/ClickHouse/ClickHouse/pull/68132) ([Pavel Kruglov](https://github.com/Avogar)).
* 现已支持对命名元组使用 `a[b].c` 这类表达式，也支持对任意表达式使用命名下标，例如 `expr().name`。这对于处理 JSON 很有用。这解决了 [#54965](https://github.com/ClickHouse/ClickHouse/issues/54965)。在之前的版本中，形如 `expr().name` 的表达式会被解析为 `tupleElement(expr(), name)`，查询分析器会去查找名为 `name` 的列，而不是对应的元组元素；而在新版本中，它会被改为 `tupleElement(expr(), 'name')`。在大多数情况下，旧版本实际上并不能正常工作，但仍然可以设想一种非常罕见的场景，在这种情况下，这一变更可能会导致不兼容：如果你把元组元素名称存储在某个列或别名中，并且该列或别名的名称与元组元素名称不同：`SELECT 'b' AS a, CAST([tuple(123)] AS 'Array(Tuple(b UInt8))') AS t, t[1].a`。你使用过这类查询的可能性极低，但我们仍需将此变更标记为可能不向后兼容。[#68435](https://github.com/ClickHouse/ClickHouse/pull/68435) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 启用设置 `print_pretty_type_names` 后，会在 `SHOW CREATE TABLE` 语句、`formatQuery` 函数，以及 `clickhouse-client` 和 `clickhouse-local` 的交互模式中，以 pretty 形式输出 `Tuple` data type。在之前的版本中，这项设置仅适用于 `DESCRIBE` 查询和 `toTypeName`。这解决了 [#65753](https://github.com/ClickHouse/ClickHouse/issues/65753)。[#68492](https://github.com/ClickHouse/ClickHouse/pull/68492) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新特性
</div>

* 函数 `toStartOfInterval()` 现已新增一个重载版本，可分别模拟 TimescaleDB 的 `time_bucket()` 函数和 PostgreSQL 的 `date_bin()` 函数。([#55619](https://github.com/ClickHouse/ClickHouse/issues/55619))。它允许从*任意*原点开始，将日期或 timestamp 值对齐到给定时间间隔的整数倍 (而不是使用 0000-01-01 00:00:00.000 这一*固定*原点) 。例如，`SELECT toStartOfInterval(toDateTime('2023-01-01 14:45:00'), INTERVAL 1 MINUTE, toDateTime('2023-01-01 14:35:30'));` 返回 `2023-01-01 14:44:30`，这是从原点 `2023-01-01 14:35:30` 开始按 1 分钟时间间隔对齐后的结果。[#56738](https://github.com/ClickHouse/ClickHouse/pull/56738) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 新增对 `ATTACH PARTITION ALL FROM` 的支持。[#61987](https://github.com/ClickHouse/ClickHouse/pull/61987) ([Kirill Nikiforov](https://github.com/allmazz)).
* 新增设置 `input_format_try_infer_variants`，允许在文本格式的 schema inference 过程中，当列/数组元素存在多种可能类型时推断为 Variant 类型。[#63798](https://github.com/ClickHouse/ClickHouse/pull/63798) ([Shaun Struwig](https://github.com/Blargian)).
* 引入 JSONCompactWithProgress format，ClickHouse 会将每一行输出为一个以换行分隔的 JSON object，其中包含 metadata、data、progress、totals 和 statistics。[#66205](https://github.com/ClickHouse/ClickHouse/pull/66205) ([Alexey Korepanov](https://github.com/alexkorep)).
* 实现了新的 JSON data type。[#66444](https://github.com/ClickHouse/ClickHouse/pull/66444) ([Pavel Kruglov](https://github.com/Avogar)).
* 新增 `input_format_json_empty_as_default` 设置，启用后会将 JSON 输入中的空字段视为默认值。解决了 [#59339](https://github.com/ClickHouse/ClickHouse/issues/59339)。[#66782](https://github.com/ClickHouse/ClickHouse/pull/66782) ([Alexis Arnaud](https://github.com/a-a-f)).
* 新增函数 `overlay` 和 `overlayUTF8`，可用另一个字符串替换字符串的一部分。示例：`SELECT overlay('Hello New York', 'Jersey', 11)` 返回 `Hello New Jersey`。[#66933](https://github.com/ClickHouse/ClickHouse/pull/66933) ([李扬](https://github.com/taiyang-li)).
* 新增命令：支持按分区执行轻量级删除 `DELETE FROM [db.]table [ON CLUSTER cluster] [IN PARTITION partition_expr] WHERE expr;` &#96;&#96;&#96; VM-114-29-tos :) select * from ads&#95;app&#95;poster&#95;ip&#95;source&#95;channel&#95;di&#95;replicated&#95;local;. [#67805](https://github.com/ClickHouse/ClickHouse/pull/67805) ([sunny](https://github.com/sunny19930321)).
* 为 `Interval` Data type 值实现了比较，因此现在会将它们转换为最小 supertype。[#68057](https://github.com/ClickHouse/ClickHouse/pull/68057) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 新增 create&#95;if&#95;not&#95;exists 设置，使 CREATE 语句默认采用 IF NOT EXISTS 行为。[#68164](https://github.com/ClickHouse/ClickHouse/pull/68164) ([Peter Nguyen](https://github.com/petern48)).
* 现已支持在 Azure 和本地读取 Iceberg 表。[#68210](https://github.com/ClickHouse/ClickHouse/pull/68210) ([Daniil Ivanik](https://github.com/divanik)).
* 新增 aggregate functions distinctDynamicTypes/distinctJSONPaths/distinctJSONPathsAndTypes，以便更好地对 JSON column type 的内容进行内部信息分析。[#68463](https://github.com/ClickHouse/ClickHouse/pull/68463) ([Pavel Kruglov](https://github.com/Avogar)).
* 现在可以按标签删除查询缓存条目。例如，由 `SELECT 1 SETTINGS use_query_cache = true, query_cache_tag = 'abc'` 创建的查询缓存条目，现在可通过 `SYSTEM DROP QUERY CACHE TAG 'abc'` 删除 (当然也可以直接使用 `SYSTEM DROP QUERY CACHE`，这会清空整个查询缓存) 。[#68477](https://github.com/ClickHouse/ClickHouse/pull/68477) ([Michał Tabaszewski](https://github.com/pinsvin00)) 。
* 为命名集合添加存储加密。[#68615](https://github.com/ClickHouse/ClickHouse/pull/68615) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 新增 `ripeMD160` 函数，用于计算字符串的 RIPEMD-160 密码学哈希。示例：`SELECT hex(ripeMD160('The quick brown fox jumps over the lazy dog'))` 返回 `37F332F68DB77BD9D7EDD4969571AD671CF9DD3B`。[#68639](https://github.com/ClickHouse/ClickHouse/pull/68639) ([Dergousov Maxim](https://github.com/m7kss1)) 。
* 为 URL 表引擎添加虚拟列 &#95;headers。关闭 [#65026](https://github.com/ClickHouse/ClickHouse/issues/65026)。[#68867](https://github.com/ClickHouse/ClickHouse/pull/68867) ([flynn](https://github.com/ucasfl)) 。
* 添加 `system.projections` 表，用于跟踪可用的投影。[#68901](https://github.com/ClickHouse/ClickHouse/pull/68901) ([Jordi Villar](https://github.com/jrdi)) 。
* 新增用于 Spark 兼容性 (arrays&#95;zip) 的 `arrayZipUnaligned` 函数，它在原有 `arrayZip` 的基础上支持未对齐数组。&#96;&#96;&#96; sql SELECT arrayZipUnaligned([1], [1, 2, 3]). [#69030](https://github.com/ClickHouse/ClickHouse/pull/69030) ([李扬](https://github.com/taiyang-li)) 。
* 在 HTTP 请求头 `X-ClickHouse-Summary` 中新增 `RealTimeMicroseconds` 指标。这样一来，无需再到 `system.query_log` 中查看，就能知道一个请求的 CPU 时间。[#69032](https://github.com/ClickHouse/ClickHouse/pull/69032) ([Alejandro](https://github.com/alexon1234)) 。
* 为 Keeper client 新增 cp/mv 命令，可原子地复制/移动节点。[#69034](https://github.com/ClickHouse/ClickHouse/pull/69034) ([Mikhail Artemenko](https://github.com/Michicosun)) 。
* 为函数 `arrayAUC` 新增参数 `scale` (默认值：`true`) ，可用于跳过归一化步骤 (issue [#69609](https://github.com/ClickHouse/ClickHouse/issues/69609)) 。[#69717](https://github.com/ClickHouse/ClickHouse/pull/69717) ([gabrielmcg44](https://github.com/gabrielmcg44)) 。

<div id="performance-improvement">
  #### 性能提升
</div>

* 在 left 或 inner hash join 中，当左表的键分布较密集时，通过按键重排右表来提升 join 性能。[#60341](https://github.com/ClickHouse/ClickHouse/pull/60341) ([kevinyhzou](https://github.com/KevinyhZou)).
* 通过将 `RowRefList` 或 `RowRef` 追加到 AddedColumns 以支持惰性输出，提升了所有 join 的性能；在 buildOutput 时，使用 `RowRefList`/`RowRef` 进行输出，并从 `buildOutput` 的 for 循环中移除了 `is_join_get` 条件。[#63677](https://github.com/ClickHouse/ClickHouse/pull/63677) ([kevinyhzou](https://github.com/KevinyhZou)).
* 将文件系统缓存元数据异步加载到启动流程中，以加快重启速度。[#65736](https://github.com/ClickHouse/ClickHouse/pull/65736) ([Daniel Pozo Escalona](https://github.com/danipozo)).
* 对函数 `array` 和 `map` 进行了优化，使其在某些常见场景下的处理速度大幅提升。[#67707](https://github.com/ClickHouse/ClickHouse/pull/67707) ([李扬](https://github.com/taiyang-li)).
* 对 ORC 字符串读取做了简单优化，尤其是在列中不包含 NULL 值时。[#67794](https://github.com/ClickHouse/ClickHouse/pull/67794) ([李扬](https://github.com/taiyang-li)).
* 通过减少合并调度步骤的开销，提升了 merges 的整体性能。[#68016](https://github.com/ClickHouse/ClickHouse/pull/68016) ([Anton Popov](https://github.com/CurtizJ)).
* 当未设置 profile、未设置凭据且 IMDS 不可用时 (例如在云环境之外的机器上查询公网存储桶时) ，加快了对 S3 的请求。这关闭了 [#52771](https://github.com/ClickHouse/ClickHouse/issues/52771)。[#68082](https://github.com/ClickHouse/ClickHouse/pull/68082) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 引入了一种新算法，通过一致性哈希确定副本之间标记分布的单位。针对不同的读取模式选择不同数量的标记，以提升性能。[#68424](https://github.com/ClickHouse/ClickHouse/pull/68424) ([Nikita Taranov](https://github.com/nickitat)).
* 尝试在 RowInputFormatWithNamesAndTypes 中对 format reader 进行去虚化，看看是否能带来一些性能提升。[#68437](https://github.com/ClickHouse/ClickHouse/pull/68437) ([李扬](https://github.com/taiyang-li)).
* 添加了按 key 并行 merge 的实现，以最大化 CPU 利用率。[#68441](https://github.com/ClickHouse/ClickHouse/pull/68441) ([Jiebin Sun](https://github.com/jiebinn)).
* 添加设置 `output_format_orc_dictionary_key_size_threshold`，允许用户在 ORC output format 中为字符串列启用字典编码。这有助于减小输出 ORC 文件大小，并显著提升读取性能。[#68591](https://github.com/ClickHouse/ClickHouse/pull/68591) ([李扬](https://github.com/taiyang-li)).
* 在 Hive 分区处理中实现了仅读取所需文件。[#68963](https://github.com/ClickHouse/ClickHouse/pull/68963) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 引入新的 Keeper 请求 RemoveRecursive，可删除节点及其整个子树。[#69332](https://github.com/ClickHouse/ClickHouse/pull/69332) ([Mikhail Artemenko](https://github.com/Michicosun)).
* 通过并行向向量索引写入数据，提升了带向量相似度索引的 insert 性能。[#69493](https://github.com/ClickHouse/ClickHouse/pull/69493) ([flynn](https://github.com/ucasfl)).
* 此前，在并行副本通知处理中，数据片段去重逻辑的算法复杂度为 O(n^2)，对于拥有大量数据片段 (或分区) 的表，可能会耗费较多时间。此次变更将复杂度降为 O(n*log(n))。[#69596](https://github.com/ClickHouse/ClickHouse/pull/69596) ([Alexander Gololobov](https://github.com/davenger)).

<div id="improvement">
  #### 改进
</div>

* 加强了代码库中与小型实体解析相关的部分。发现并修复了以下一些小问题：- 如果 `DeltaLake` 表按 Bool 分区，分区值始终会被解释为 false；- `ExternalDistributed` 表在提供的地址中只使用单个分片；`max_threads` 设置等参数的值此前会打印为 `'auto(N)'`，而不是 `auto(N)`。[#52503](https://github.com/ClickHouse/ClickHouse/pull/52503) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 可刷新materialized view 改进：新增追加模式 (`... REFRESH EVERY 1 MINUTE APPEND ...`) ，可向现有表追加行而不是覆盖整张表；支持重试 (默认禁用，在查询的 SETTINGS 部分配置) ；新增 `SYSTEM WAIT VIEW <name>` 查询，用于等待当前正在运行的刷新；以及其他一些修复。[#58934](https://github.com/ClickHouse/ClickHouse/pull/58934) ([Michael Kolupaev](https://github.com/al13n321)).
* 使用 cgroup 专用指标统计 CPU 使用率，而不是使用系统级指标。[#62003](https://github.com/ClickHouse/ClickHouse/pull/62003) ([Nikita Taranov](https://github.com/nickitat)).
* 远程 S3 disk 的 IO scheduling 现在在 HTTP socket 流级别进行 (而不是整个 S3 请求级别) ，以解决 `bandwidth_limit` throttling 问题。[#65182](https://github.com/ClickHouse/ClickHouse/pull/65182) ([Sergei Trifonov](https://github.com/serxa)).
* 允许用户配置多个身份验证方法，而不再只能有一个。还允许将身份验证方法重置为最近添加的方法。如果你打算在一段时间内同时运行 24.8 和 24.9 版本的实例，建议在这段期间将 `max_authentication_methods_per_user = 1`，以避免潜在错误。[#65277](https://github.com/ClickHouse/ClickHouse/pull/65277) ([Arthur Passos](https://github.com/arthurpassos)).
* Functions `upperUTF8` 和 `lowerUTF8` 之前只能对西里尔字母进行大小写转换。现在这一限制已被移除，任意语言的字符都可以转换为大写或小写。Example：`SELECT upperUTF8('Süden')` 现在返回 `SÜDEN`。[#65761](https://github.com/ClickHouse/ClickHouse/pull/65761) ([李扬](https://github.com/taiyang-li)).
* 当在带有 projection 的表上执行轻量级删除时，此前用户只能二选一：要么抛出异常 (默认) ，要么删除 projection 后执行轻量级删除；现在新增了第三种选择，即先执行轻量级删除，再重建 projection。[#66169](https://github.com/ClickHouse/ClickHouse/pull/66169) ([Shichao](https://github.com/jsc0218)).
* 新增两个选项 (`dns_allow_resolve_names_to_ipv4` 和 `dns_allow_resolve_names_to_ipv6`) ，用于按 IP 协议族阻止连接。[#66895](https://github.com/ClickHouse/ClickHouse/pull/66895) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 新增 `min_max` 作为一种新的 (Experimental) 统计类型。它支持估算数值列上的范围谓词，例如 `x < 100`。[#67013](https://github.com/ClickHouse/ClickHouse/pull/67013) ([JackyWoo](https://github.com/JackyWoo)).
* 使 ClickHouse 客户端中对 C-z 的忽略行为可配置 (ignore&#95;shell&#95;suspend) 。[#67134](https://github.com/ClickHouse/ClickHouse/pull/67134) ([Azat Khuzhin](https://github.com/azat)).
* 改进了对 Variant/Dynamic 列执行的 castOrDefault，使其在内部类型完全不可转换时也能正常工作。[#67150](https://github.com/ClickHouse/ClickHouse/pull/67150) ([Pavel Kruglov](https://github.com/Avogar)).
* 改进了 JSON output formats 中的 Unicode 编码，确保在结果数据包含某些字节序列时仍能生成有效的 JSON。[#67938](https://github.com/ClickHouse/ClickHouse/pull/67938) ([mwoenker](https://github.com/mwoenker)).
* 新增了 merges 和 mutations 的 profile events，以便更好地进行内部信息分析。[#68015](https://github.com/ClickHouse/ClickHouse/pull/68015) ([Anton Popov](https://github.com/CurtizJ))。
* Odbc：从服务器配置中获取 http&#95;max&#95;tries。[#68128](https://github.com/ClickHouse/ClickHouse/pull/68128) ([Rodolphe Dugé de Bernonville](https://github.com/RodolpheDuge))。
* 为 x509 SubjectAltName extension 中的用户标识添加通配符支持。[#68236](https://github.com/ClickHouse/ClickHouse/pull/68236) ([Marco Vilas Boas](https://github.com/marco-vb))。
* 改进了日期时间的 schema inference。现在仅当日期时间包含小数部分时才使用 DateTime64，否则使用常规的 DateTime。现在对 Date/DateTime 的推断也更加严格，尤其是在 `date_time_input_format='best_effort'` 时，以避免在边界情况下从字符串中推断出日期时间。[#68382](https://github.com/ClickHouse/ClickHouse/pull/68382) ([Pavel Kruglov](https://github.com/Avogar))。
* 删除了字典中 named collections 的旧代码，并替换为新实现，从而允许在字典中使用通过 DDL 创建的 named collections。关闭 [#60936](https://github.com/ClickHouse/ClickHouse/issues/60936)，关闭 [#36890](https://github.com/ClickHouse/ClickHouse/issues/36890)。[#68412](https://github.com/ClickHouse/ClickHouse/pull/68412) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 外部 HTTP 身份验证改用 HTTP/1.1，而不是默认的 HTTP/1.0。[#68456](https://github.com/ClickHouse/ClickHouse/pull/68456) ([Aleksei Filatov](https://github.com/aalexfvk))。

* 新增了一组用于 Thread Pool 内部信息分析的指标，可更深入地了解 thread pool 的性能和行为。[#68674](https://github.com/ClickHouse/ClickHouse/pull/68674) ([filimonov](https://github.com/filimonov))。
