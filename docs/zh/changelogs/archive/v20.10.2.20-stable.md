<div id="clickhouse-release-v2010220-stable-fixme-as-compared-to-v20914585-prestable">
  ### ClickHouse 发布版 v20.10.2.20-stable，与 v20.9.1.4585-prestable 相比的 FIXME
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 在 SQL 中新增了对嵌套多行注释 `/* comment /* comment */ */` 的支持。这符合 SQL 标准。[#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 `format_regexp_escaping_rule` 设置项的默认值 (与 `Regexp` 格式相关) 更改为 `Raw` (即将整个子模式作为一个值读取) ，使其行为更符合用户预期。[#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 `multiple_joins_rewriter_version` 标记为已废弃。移除了 JOIN 重写器的第一个版本。[#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### 新特性
</div>

* 新增特性：`LineAsString` 格式，接受由换行、空格和/或逗号分隔的 line 序列。[#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 新增 `formatReadableQuantity` 函数，便于人类阅读大数字。[#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* 新增移除列属性和表生存时间 (TTL) 的能力。引入了查询 `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` 和 `ALTER TABLE REMOVE TTL`。这两项操作都是轻量级的，并在元数据层执行。[#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* 在 `system.text_log`、`system.trace_log`、`system.query_log` 和 `system.query_thread_log` 表中引入 `event_time_microseconds` 字段。[#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* 现在支持 `WITH <identifier> AS (subquery) ... `，用于在查询上下文中引入命名子查询。此项变更关闭了 [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416) 和 [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967)。[#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* 如果在 config 中指定了默认值，则允许省略 Replicated 表引擎的参数。[#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* 新增表函数 `null('structure')`。[#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* 新增查询混淆工具，可共享更多查询以改进测试。此项变更关闭了 [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268)。[#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新增 `RawBLOB` 格式，用于在不进行任何转义或分隔符处理的情况下输入或输出单个值。此项变更关闭了 [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349)。[#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 [15350](https://github.com/ClickHouse/ClickHouse/issues/15350)。[#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* 引入 `enable_global_with_statement` 设置，该设置会将第一个 select 的 `WITH` 语句传播到同一级别的其他 select 查询，并使 `WITH` 语句中的别名对子查询可见。[#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* 新增 `reinterpretAsUUID` 函数，可将大端字节字符串转换为 UUID。[#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 新增并行 quorum 插入。此项变更关闭了 [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601)。[#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### 性能提升
</div>

* 使用 `(u)int64_t` 作为宽整数的基本类型，提升 256 位整数的性能。原来的宽整数使用 8 位类型作为基本类型。 [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* 启动 clickhouse-server 时仅锁定 `mlock` 代码段。此前版本会将所有映射区域都锁定在内存中，包括调试信息。调试信息通常会拆分到单独的文件中，但如果没有拆分，就会导致内存占用额外增加 2..3 GiB。 [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 过去我们会选择 fixed key method 来按单个固定字符串分组。由于已经有 StringHashTable，能够对 FixedString 列进行类似的 packedFix 优化，因此没有这个必要。而且如果条件允许，应使用 low&#95;cardinality&#95;key&#95;fixed&#95;string。 [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* 修复 `DateTime <op> DateTime` 误选较慢通用实现的问题。此更改修复了 [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153)。 [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* 使用一次 S3 DeleteObjects 请求代替循环中的多次 DeleteObject。功能没有任何变化，因此现有测试 (如 integration/test&#95;log&#95;family&#95;s3) 已可覆盖。 [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* 加快 256 位乘法运算。 [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* 提升 `quantileTDigest` 的性能。此更改修复了 [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668)。 [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* 显式使用临时 disk 来存储 vertical merge 的临时数据。 [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).

* 修复了 `MaterializeMySQL` 数据库引擎中的 &quot;Packet payload is not fully read&quot; 错误。[#14696](https://github.com/ClickHouse/ClickHouse/pull/14696) ([BohuTANG](https://github.com/BohuTANG)).

* 现在可以使用 columns 包裹一组列，并在之后应用列转换器。[#14775](https://github.com/ClickHouse/ClickHouse/pull/14775) ([Amos Bird](https://github.com/amosbird)).
* 支持为 StorageJoin 和 StorageSet 禁用持久化，该功能由设置 `disable_set_and_join_persistency` 控制。此外，此 PR 还解决了 issue [#6318](https://github.com/ClickHouse/ClickHouse/issues/6318)。[#14776](https://github.com/ClickHouse/ClickHouse/pull/14776) ([vxider](https://github.com/Vxider)).
* 从同一个 timespec 构造 `query_start_time` 和 `query_start_time_microseconds`。[#14831](https://github.com/ClickHouse/ClickHouse/pull/14831) ([Bharat Nallan](https://github.com/bharatnc)).
* 允许在 Distributed 存储中使用多卷存储配置。[#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
* 在 `EXPLAIN` 结果中显示 `SET` 和 `JOIN` 的子查询。[#14856](https://github.com/ClickHouse/ClickHouse/pull/14856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 提供了 `load_balancing_first_offset` 查询设置，用于显式指定哪个是第一个副本。它与 `FIRST_OR_RANDOM` 负载均衡策略配合使用，从而可以控制副本工作负载。[#14867](https://github.com/ClickHouse/ClickHouse/pull/14867) ([Amos Bird](https://github.com/amosbird)).
* 修复了从分布式表运行带 SETTINGS 的 SELECT 时出现过多设置约束违规的问题。[#14876](https://github.com/ClickHouse/ClickHouse/pull/14876) ([Amos Bird](https://github.com/amosbird)).
* 如果之前的 drop 尝试因 ZooKeeper session 过期而失败，则允许 drop Replicated 表。此更改修复了 [#11891](https://github.com/ClickHouse/ClickHouse/issues/11891)。[#14926](https://github.com/ClickHouse/ClickHouse/pull/14926) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在使用 `TinyLog` 或 `Log` 表引擎的表上对自身执行 INSERT SELECT 时，避免发生死锁。此项关闭了 [#6802](https://github.com/ClickHouse/ClickHouse/issues/6802)。[#14962](https://github.com/ClickHouse/ClickHouse/pull/14962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 执行变更时忽略 key 约束。若无此 PR，则在 `force_index_by_date = 1` 或 `force_primary_key = 1` 时无法执行变更。[#14973](https://github.com/ClickHouse/ClickHouse/pull/14973) ([Amos Bird](https://github.com/amosbird)).
* 添加了在插入数据分区片段时禁用 TTL move 的选项。[#15000](https://github.com/ClickHouse/ClickHouse/pull/15000) ([Pavel Kovalenko](https://github.com/Jokser)).
* 默认启用 `Atomic` database engine。[#15003](https://github.com/ClickHouse/ClickHouse/pull/15003) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 为 CAST 参数数量错误提供了正确的异常消息。此项关闭了 [#13992](https://github.com/ClickHouse/ClickHouse/issues/13992)。[#15029](https://github.com/ClickHouse/ClickHouse/pull/15029) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新增了为带子类型的列指定专用编解码器 (如 `Delta`、`T64` 等) 的能力。实现了 [#12551](https://github.com/ClickHouse/ClickHouse/issues/12551)，修复了 [#11397](https://github.com/ClickHouse/ClickHouse/issues/11397) 和 [#4609](https://github.com/ClickHouse/ClickHouse/issues/4609)。[#15089](https://github.com/ClickHouse/ClickHouse/pull/15089) ([alesapin](https://github.com/alesapin)).
* 为 `EXPLAIN PLAN` 查询添加了 `optimize` 设置。启用后，将应用查询计划级别的优化。默认启用。[#15201](https://github.com/ClickHouse/ClickHouse/pull/15201) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 在 `/docker-entrypoint-initdb.d/` 中的所有脚本执行完毕之前，不允许连接到 ClickHouse server。[#15244](https://github.com/ClickHouse/ClickHouse/pull/15244) ([Aleksei Kozharin](https://github.com/alekseik1)).
* 修复了 [15264](https://github.com/ClickHouse/ClickHouse/issues/15264)。[#15285](https://github.com/ClickHouse/ClickHouse/pull/15285) ([flynn](https://github.com/ucasfl)).
* 在创建 replicated table 时，展开 `zookeeper_path` 中的 `{database}`、`{table}` 和 `{uuid}` 宏。如果在 server 重启后可能破坏 `zookeeper_path`，则不允许执行 `RENAME TABLE`。修复了 [#6917](https://github.com/ClickHouse/ClickHouse/issues/6917)。[#15348](https://github.com/ClickHouse/ClickHouse/pull/15348) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 为 `Regexp` format 添加了对 &quot;Raw&quot; 列 format 的支持。它允许直接将子模式整体提取出来，而无需任何转义规则。[#15363](https://github.com/ClickHouse/ClickHouse/pull/15363) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 现在可以通过 `ALTER` 查询修改 `VersionedCollapsingMergeTree` 的版本列类型。[#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).
* 如果为 `Atomic` database 指定了 `NO DELAY` 或 `SYNC`，则会等待 `DROP/DETACH TABLE` 实际完成。[#15448](https://github.com/ClickHouse/ClickHouse/pull/15448) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 通过启用 cluster-secure 的 Distributed 透传 *&#95;for&#95;user 设置。[#15551](https://github.com/ClickHouse/ClickHouse/pull/15551) ([Azat Khuzhin](https://github.com/azat)).
* 默认启用实验性 pass manager。[#15608](https://github.com/ClickHouse/ClickHouse/pull/15608) ([Daniel Kutenin](https://github.com/danlark1)) 。
* 实现了 force&#95;data&#95;skipping&#95;indices 设置。[#15642](https://github.com/ClickHouse/ClickHouse/pull/15642) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#16102](https://github.com/ClickHouse/ClickHouse/issues/16102) 中回移：现在无论集群配置中的 `<internal_replication>` 设置如何，都允许执行 `ALTER ... ON CLUSTER` 查询。[#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)) 。
