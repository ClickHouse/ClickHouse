<div id="clickhouse-release-v205440-stable-fixme-as-compared-to-v205327-stable">
  ### ClickHouse 发布版本 v20.5.4.40-stable FIXME (与 v20.5.3.27-stable 相比)
</div>

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#12929](https://github.com/ClickHouse/ClickHouse/issues/12929) 中回移：修复了“[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) 对字面量使用 IN 运算符时未使用索引”这一问题，该性能回退大约是在 v19.3 版本中引入的。[#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#12830](https://github.com/ClickHouse/ClickHouse/issues/12830) 中回移：修复了由于线程总数限制设置错误，导致带 `UNION` 的 SELECT 查询性能下降的问题。修复了 [#12030](https://github.com/ClickHouse/ClickHouse/issues/12030)。[#12103](https://github.com/ClickHouse/ClickHouse/pull/12103) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#12836](https://github.com/ClickHouse/ClickHouse/issues/12836) 中回移：修复了 `SummingMergeTree` 引擎对分区键中的列求和时的行为；当显式定义要汇总的列且其与分区键列相交时，新增了异常。此修复解决了 [#7867](https://github.com/ClickHouse/ClickHouse/issues/7867)。[#12173](https://github.com/ClickHouse/ClickHouse/pull/12173) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#12833](https://github.com/ClickHouse/ClickHouse/issues/12833) 中回移：修复了在 `StorageFile` 中连续多次 insert 时，某些特殊类型的头信息会被重复写入的问题。此修复解决了 [#6155](https://github.com/ClickHouse/ClickHouse/issues/6155)。[#12197](https://github.com/ClickHouse/ClickHouse/pull/12197) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#12895](https://github.com/ClickHouse/ClickHouse/issues/12895) 中回移：kafka：修复了当批次中间出现带 error 的 message 时触发 SIGSEGV 的问题。[#12302](https://github.com/ClickHouse/ClickHouse/pull/12302) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#12905](https://github.com/ClickHouse/ClickHouse/issues/12905) 中回移：修复了 TOTALS/ROLLUP/CUBE 对带有 `-State` 和 `Nullable` arguments 的聚合函数处理不正确的问题。此修复解决了 [#12163](https://github.com/ClickHouse/ClickHouse/issues/12163)。[#12376](https://github.com/ClickHouse/ClickHouse/pull/12376) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#12907](https://github.com/ClickHouse/ClickHouse/issues/12907) 中回移：即使存在依赖它的 DEFAULT expressions，也允许 CLEAR 列。此修复解决了 [#12333](https://github.com/ClickHouse/ClickHouse/issues/12333)。[#12378](https://github.com/ClickHouse/ClickHouse/pull/12378) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#12909](https://github.com/ClickHouse/ClickHouse/issues/12909) 中回移：避免了在带索引的表中，当 WHERE 条件使用负数或浮点常量时触发异常。此修复解决了 [#11905](https://github.com/ClickHouse/ClickHouse/issues/11905)。[#12384](https://github.com/ClickHouse/ClickHouse/pull/12384) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#12897](https://github.com/ClickHouse/ClickHouse/issues/12897) 中回移：修复了在与字典执行 JOIN 时发生崩溃的问题；该问题出现在按字典键表达式进行连接时：`t JOIN dict ON expr(dict.id) = t.id`。已在这种情况下禁用字典 JOIN 优化。[#12458](https://github.com/ClickHouse/ClickHouse/pull/12458) ([Artem Zuikov](https://github.com/4ertus2)).

* 已在 [#12892](https://github.com/ClickHouse/ClickHouse/issues/12892) 中回移：修复了 live view 表中的竞态条件，该问题可能导致数据重复。[#12519](https://github.com/ClickHouse/ClickHouse/pull/12519) ([vzakaznikov](https://github.com/vzakaznikov)).
