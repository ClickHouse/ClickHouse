  ### ClickHouse 发行版 v23.4.5.22-稳定版本 (0ced5d6a8da) FIXME，相较于 v23.4.4.16-稳定版本 (747ba4fc6a0)

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530) 中回移：将 Dockerfile 中超大的 `RUN` 拆分为更小的条件分支。在同一个 `RUN` 层中按需安装必要工具，并在之后将其移除。仅在开始时升级一次操作系统。使用更现代的方式检查已签名的软件源。将基础 repo 降级为 ubuntu:20.04，以解决旧版 docker 中的问题。升级 golang 版本以修复 golang 漏洞。[#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570) 中回移：这是对 [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504) 的后续修复，清理步骤在重构过程中丢失了。[#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本发行版中用户可见的异常行为)
</div>

* 修复二元运算符包含 NULL 常量参数时索引分析失效的问题 [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* 修复目标 host IP 变更后 HTTPS session 无法重连的问题 [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 修复错误的常量折叠问题 [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 cache entry 中 LDAP server params 的哈希类型问题 [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* 在 Parquet format 中，回退为从 String 解析大整数，而不是抛出异常 [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* 启用 read-in-order 时不应用 projection。 [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 修复 ActionsDAG 中 fuzzer 失败的问题 [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
