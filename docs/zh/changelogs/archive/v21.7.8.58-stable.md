<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#27506](https://github.com/ClickHouse/ClickHouse/issues/27506) 中回移：修复某些在 `PREWHERE` 中使用 `LowCardinality` 的查询出现报错的问题，例如 `Expected ColumnLowCardinality, gotUInt8` 或 `Bad cast from type DB::ColumnVector<char8_t> to DB::ColumnLowCardinality`。修复了 [#23515](https://github.com/ClickHouse/ClickHouse/issues/23515)。[#27298](https://github.com/ClickHouse/ClickHouse/pull/27298) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#27644](https://github.com/ClickHouse/ClickHouse/issues/27644) 中回移：修复同时使用行级安全、PREWHERE 和 LowCardinality 过滤器时查询结果不正确的问题。修复了 [#27179](https://github.com/ClickHouse/ClickHouse/issues/27179)。[#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#27474](https://github.com/ClickHouse/ClickHouse/issues/27474) 中回移：修复指标 BackgroundMessageBrokerSchedulePoolTask，可能是拼写有误。[#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)) 。
* 已在 [#27649](https://github.com/ClickHouse/ClickHouse/issues/27649) 中回移：修复当某些 parts 包含缺失列时，在 projection 物化期间发生崩溃的问题。此修复解决了 [#27512](https://github.com/ClickHouse/ClickHouse/issues/27512)。[#27528](https://github.com/ClickHouse/ClickHouse/pull/27528) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#27778](https://github.com/ClickHouse/ClickHouse/issues/27778) 中回移：修复 `Distributed` 表中别名列的 bug。[#27652](https://github.com/ClickHouse/ClickHouse/pull/27652) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#27674](https://github.com/ClickHouse/ClickHouse/issues/27674) 中回移：修复 PostgreSQL 表函数导致连接未关闭的问题。关闭了 [#26088](https://github.com/ClickHouse/ClickHouse/issues/26088)。[#27662](https://github.com/ClickHouse/ClickHouse/pull/27662) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#27697](https://github.com/ClickHouse/ClickHouse/issues/27697) 中回移：修复当 `arrayHas` 等函数应用于底层非数值类型不同 (如 `DateTime` 和 `DateTime64`) 的 Nullable LowCardinality 数组时发生的错误类型转换问题。在之前的版本中会发生错误转换；在新版本中则会抛出异常。此项关闭了 [#26330](https://github.com/ClickHouse/ClickHouse/issues/26330)。[#27682](https://github.com/ClickHouse/ClickHouse/pull/27682) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#27748](https://github.com/ClickHouse/ClickHouse/issues/27748) 中回移：移除 arrow-cmake 中 CMakeLists.txt 里的重复源文件。[#27736](https://github.com/ClickHouse/ClickHouse/pull/27736) ([李扬](https://github.com/taiyang-li)) 。
