<div id="clickhouse-release-v201215236-prestable-fixme-as-compared-to-v201115109-prestable">
  ### ClickHouse 发布 v20.12.1.5236-prestable FIXME，对比 v20.11.1.5109-prestable
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容变更
</div>

* 创建使用 `File` 表引擎的表时，现已接受 `SETTINGS` 子句中与文件格式相关的用户设置 (例如 `format_csv_delimiter`) ，并在所有 `INSERT` 和 `SELECT` 中使用这些设置。在当前用户会话中修改的文件格式设置，或在 DML 查询自身的 `SETTINGS` 子句中修改的文件格式设置，将不再影响该查询。[#16591](https://github.com/ClickHouse/ClickHouse/pull/16591) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 默认启用 `use_compact_format_in_distributed_parts_names` (参见参考文档) 。[#16728](https://github.com/ClickHouse/ClickHouse/pull/16728) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 新特性
</div>

* 新增 ALTER UPDATE/DELETE IN PARTITION 语法。[#13403](https://github.com/ClickHouse/ClickHouse/pull/13403) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 新增 StorageEmbeddedRocksdb 引擎。[#15073](https://github.com/ClickHouse/ClickHouse/pull/15073) ([sundyli](https://github.com/sundy-li)).
* 引入查询 `ALTER TABLE ... DROP|DETACH PART 'part_name'`。[#15511](https://github.com/ClickHouse/ClickHouse/pull/15511) ([nvartolomei](https://github.com/nvartolomei)).
* 现在可以在 `clickhouse-client` 中使用 `--history_file` 参数修改历史文件路径。[#15960](https://github.com/ClickHouse/ClickHouse/pull/15960) ([Maksim Kita](https://github.com/kitaisreal)).
* 更新了 DateTime、DateTime64 的格式化，使其支持接受字符串 Date 字面量格式。[#16040](https://github.com/ClickHouse/ClickHouse/pull/16040) ([Maksim Kita](https://github.com/kitaisreal)).
* 新增设置 `aggregate_functions_null_for_empty`，该选项会重写查询中的所有聚合函数，为它们添加 -OrNull 后缀。修复 [#10273](https://github.com/ClickHouse/ClickHouse/issues/10273)。[#16123](https://github.com/ClickHouse/ClickHouse/pull/16123) ([flynn](https://github.com/ucasfl)).
* 为 Nullable、LowCardinality、Array 和 Tuple 新增 COLLATE 支持，其中嵌套类型为 String。同时重构了 ColumnString.cpp 中与排序规则相关的代码。[#16273](https://github.com/ClickHouse/ClickHouse/pull/16273) ([Kruglov Pavel](https://github.com/Avogar)).
* 支持在不同副本之间分配 merge。引入 `execute_merges_on_single_replica_time_threshold` MergeTree 设置。[#16424](https://github.com/ClickHouse/ClickHouse/pull/16424) ([filimonov](https://github.com/filimonov)).
* 新增对 `*.xz` 压缩/解压缩的支持，这使得可以在 `file()` 函数中使用 `*.xz`。此项关闭了 [#8828](https://github.com/ClickHouse/ClickHouse/issues/8828)。[#16578](https://github.com/ClickHouse/ClickHouse/pull/16578) ([Abi Palagashvili](https://github.com/fibersel)).
* 新增 `cmath` 函数：- acosh - asinh - atan2 - atanh - cosh - hypot - log1p - sinh。[#16636](https://github.com/ClickHouse/ClickHouse/pull/16636) ([Konstantin Malanchev](https://github.com/hombit)).
* 默认支持在 TSV 和 CSV 格式中将枚举值作为其 ID 输入。[#16834](https://github.com/ClickHouse/ClickHouse/pull/16834) ([Kruglov Pavel](https://github.com/Avogar)).
* 新增 tcpPort() 函数，返回该服务器正在监听的 TCP 端口。[#17134](https://github.com/ClickHouse/ClickHouse/pull/17134) ([Ivan](https://github.com/abyss7)).



<div id="performance-improvement">
  #### 性能提升
</div>

* 现在我们可以在精确匹配的情况下安全地对分区进行剪枝。一个有用的用例如下：假设表按 intHash64(x) % 100 分区，并且查询条件中原样写的是 intHash64(x) % 100，而不是 x。[#16253](https://github.com/ClickHouse/ClickHouse/pull/16253) ([Amos Bird](https://github.com/amosbird)).
* 改用 Floyd-Rivest 算法；对于 ClickHouse 的部分排序用例，它应该是最佳选择。基准测试见 https://github.com/danlark1/miniselect 和 [这里](https://drive.google.com/drive/folders/1DHEaeXgZuX6AJ9eByeZ8iQVQv0ueP8XM)。[#16825](https://github.com/ClickHouse/ClickHouse/pull/16825) ([Daniel Kutenin](https://github.com/danlark1)).



<div id="improvement">
  #### 改进
</div>

* 在 `EXPLAIN` 中添加 `VIEW` 子查询描述。限制 `VIEW` 的下推优化。将 `Distributed` 的本地副本添加到查询计划中。[#14936](https://github.com/ClickHouse/ClickHouse/pull/14936) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 使 `indexOf()` 支持使用 BloomFilter。[#14977](https://github.com/ClickHouse/ClickHouse/pull/14977) ([achimbab](https://github.com/achimbab))。
* 当 MySQL 同步用户的特权配置有误时，抛出关于正确同步特权的异常。[#15977](https://github.com/ClickHouse/ClickHouse/pull/15977) ([TCeason](https://github.com/TCeason))。
* 修复创建 materialized view 循环依赖时可能导致的栈溢出问题。关闭 [#15732](https://github.com/ClickHouse/ClickHouse/issues/15732)。[#16048](https://github.com/ClickHouse/ClickHouse/pull/16048) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 在 HTTPS 连接远程资源时支持 SNI，从而可以连接到需要 SNI 的 Cloudflare 服务器。修复 [#10055](https://github.com/ClickHouse/ClickHouse/issues/10055)。[#16252](https://github.com/ClickHouse/ClickHouse/pull/16252) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* `ReplicatedMergeTree` 系列引擎现在为复制拉取操作使用独立的线程池，线程池大小由 `background_fetches_pool_size` 参数控制，重启服务器后生效。该参数默认值为 3，即最大并行拉取数为 3 (可充分利用 10G 网络) 。修复 #520。[#16390](https://github.com/ClickHouse/ClickHouse/pull/16390) ([alesapin](https://github.com/alesapin))。
* 现在可以在 `config.xml` 中修改 `<auxiliary_zookeepers>` 配置，并在不重启服务器的情况下热加载生效。[#16627](https://github.com/ClickHouse/ClickHouse/pull/16627) ([Amos Bird](https://github.com/amosbird))。
* 允许在相同大小的整数与浮点数之间进行重新解释。修复 [16640](https://github.com/ClickHouse/ClickHouse/issues/16640)。[#16657](https://github.com/ClickHouse/ClickHouse/pull/16657) ([flynn](https://github.com/ucasfl))。
* 针对以 nginx 作为代理使用 S3 的场景提供兼容性修复。nginx 目前不接受路径为空的 URL (如 `http://domain.com?delete`) ，而原生 aws-sdk-cpp 会生成此类 URL。本次提交使用了经过修补的 aws-sdk-cpp 版本，在此情况下会将路径设为 &quot;/&quot;，生成形如 `http://domain.com/?delete` 的 URL。[#16709](https://github.com/ClickHouse/ClickHouse/pull/16709) ([ianton-ru](https://github.com/ianton-ru))。
* 在 Distributed 引擎启动时清除 async insert 遗留的空目录。[#16729](https://github.com/ClickHouse/ClickHouse/pull/16729) ([Azat Khuzhin](https://github.com/azat))。
* 易用性改进：当 `CODEC` 表达式在 `CREATE TABLE` 查询中位置有误时，语法错误信息现在会提供更明确的修正建议。修复 [#12493](https://github.com/ClickHouse/ClickHouse/issues/12493)。[#16768](https://github.com/ClickHouse/ClickHouse/pull/16768) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 当 distributed DDL 配置缺失时，提供更清晰的异常信息。修复 [#5075](https://github.com/ClickHouse/ClickHouse/issues/5075)。[#16769](https://github.com/ClickHouse/ClickHouse/pull/16769) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 对每次 INSERT (启用 internal&#95;replication 时) 应用 `use_compact_format_in_distributed_parts_names`。[#16788](https://github.com/ClickHouse/ClickHouse/pull/16788) ([Azat Khuzhin](https://github.com/azat))。
* 当配置有误时 (如缺少 `metric_log`.`collect_interval_milliseconds`) ，服务器将拒绝启动并输出异常信息。[#16815](https://github.com/ClickHouse/ClickHouse/pull/16815) ([Ivan](https://github.com/abyss7))。
* 新增 cutToFirstSignificantSubdomainWithWWW() 函数。[#16845](https://github.com/ClickHouse/ClickHouse/pull/16845) ([Azat Khuzhin](https://github.com/azat))。
* 对字典执行 ATTACH/DETACH TABLE 操作时，抛出详细的错误信息。在此 PR 之前，`detach table <dict>` 虽然可以执行，但会导致内存中的元数据格式损坏。[#16885](https://github.com/ClickHouse/ClickHouse/pull/16885) ([Amos Bird](https://github.com/amosbird))。
* 在 TTL、mutation 或折叠合并算法裁剪后，删除产生的空 parts。[#16895](https://github.com/ClickHouse/ClickHouse/pull/16895) ([Anton Popov](https://github.com/CurtizJ))。
* 支持连接到需要 SNI 的 `clickhouse-server` 安全端点，适用于 `clickhouse-server` 部署在 TLS 代理后端的场景。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov))。
* 将 `SOURCE(CLICKHOUSE(...))` 的默认 `host` 和 `port` 参数设置为当前实例，并将默认 `user` 值设置为 `'default'`。[#16997](https://github.com/ClickHouse/ClickHouse/pull/16997) ([Vladimir C](https://github.com/vdimir))。
* 在 `JSONEachRow` 格式中新增将所有行输出为 JSON 数组的功能，由 `output_format_json_array_of_rows` 参数控制。[#17152](https://github.com/ClickHouse/ClickHouse/pull/17152) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 在使用 JSON 输入/输出格式时，允许将命名元组格式化为 JSON 对象，由 `output_format_json_named_tuples_as_objects` 参数控制，默认禁用。[#17175](https://github.com/ClickHouse/ClickHouse/pull/17175) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 修正 JSONEachRow、JSONCompactEachRow 和 RegexpRow 输入格式错误信息中的语法问题。[#17205](https://github.com/ClickHouse/ClickHouse/pull/17205) ([nico piderman](https://github.com/sneako))。
