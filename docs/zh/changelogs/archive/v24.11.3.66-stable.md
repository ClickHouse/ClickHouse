<div id="new-feature">
  #### 新特性

* 已在 [#74318](https://github.com/ClickHouse/ClickHouse/issues/74318) 中回移：当 `min_age_to_force_merge_seconds` 和 `min_age_to_force_merge_on_partition_only` 均启用时，分片合并会忽略最大字节数限制。[#73656](https://github.com/ClickHouse/ClickHouse/pull/73656) ([Kai Zhu](https://github.com/nauu)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#73907](https://github.com/ClickHouse/ClickHouse/issues/73907) 中回移：将 `latest_fail_error_code_name` 列添加到 `system.mutations`。我们需要这一列来引入一个关于停滞变更的新指标，并用它构建云环境中遇到的错误图表，以及按需新增一种噪声更低的告警。[#72398](https://github.com/ClickHouse/ClickHouse/pull/72398) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 已在 [#73071](https://github.com/ClickHouse/ClickHouse/issues/73071) 中回移：实现从备份恢复时并行创建表。在此 PR 之前，`RESTORE` 命令始终使用单线程创建表，因此在备份中包含大量表时可能会很慢。[#72427](https://github.com/ClickHouse/ClickHouse/pull/72427) ([Vitaly Baranov](https://github.com/vitlibar)).
