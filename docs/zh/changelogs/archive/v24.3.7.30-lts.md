<div id="improvement">
  #### 改进
</div>

* 已在 [#68103](https://github.com/ClickHouse/ClickHouse/issues/68103) 中回移：在解析自定义设置的值时，会区分布尔值和整数：`SET custom_a = true; SET custom_b = 1;`。[#62206](https://github.com/ClickHouse/ClickHouse/pull/62206) ([Vitaly Baranov](https://github.com/vitlibar)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#67931](https://github.com/ClickHouse/ClickHouse/issues/67931) 中回移：修复 StorageMerge 经 `PREWHERE` 优化后出现的 `Not-ready Set` 错误。[#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#68062](https://github.com/ClickHouse/ClickHouse/issues/68062) 中回移：修复发送到外部 database 的查询中布尔值字面量的问题 (适用于 `PostgreSQL` 等引擎) 。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* 已在 [#67812](https://github.com/ClickHouse/ClickHouse/issues/67812) 中回移：仅与 Experimental Variant 数据类型相关。修复 Variant + AggregateFunction 类型导致的崩溃问题。[#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#67848](https://github.com/ClickHouse/ClickHouse/issues/67848) 中回移：修复 [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)。避免在 `ReplaceTableNodeToDummyVisitor` 中遍历未解析的表函数参数。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#68271](https://github.com/ClickHouse/ClickHouse/issues/68271) 中回移：修复通过 HTTP interface 向 stream 类引擎 (Kafka、RabbitMQ、NATS) 执行插入的问题。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#67806](https://github.com/ClickHouse/ClickHouse/issues/67806) 中回移：修复重新加载包含 UNION 的 SQL UDF 时的问题。此前，重启 server 可能会导致 UDF 失效。[#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#67834](https://github.com/ClickHouse/ClickHouse/issues/67834) 中回移：修复 `JSONMergePatch` 函数中潜在的栈溢出问题。由于先前的名称不正确，该函数已从 `jsonMergePatch` 重命名为 `JSONMergePatch`。为保持兼容性，旧名称仍会保留。并改进了该函数的错误诊断信息。此项关闭了 [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304)。[#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#68206](https://github.com/ClickHouse/ClickHouse/issues/68206) 中回移：修复谓词中存在非确定性函数时 `count()` 结果错误的问题。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#68089](https://github.com/ClickHouse/ClickHouse/issues/68089) 中回移：修复在可用 CPU 数量受限的容器化环境中，最大线程软限制计算错误的问题。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* 已在 [#68120](https://github.com/ClickHouse/ClickHouse/issues/68120) 中回移：修复在使用新 analyzer 时，变更操作会跳过未受影响 parts 的问题。此前，在启用 analyzer 的情况下，即使根据谓词某项变更并不影响某个 part，该 part 中的数据仍可能被该变更重写。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
