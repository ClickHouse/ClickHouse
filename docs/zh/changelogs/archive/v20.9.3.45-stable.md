<div id="clickhouse-release-v209345-stable-fixme-as-compared-to-v209220-stable">
  ### ClickHouse 发布 v20.9.3.45-stable FIXME，相较于 v20.9.2.20-stable
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#15568](https://github.com/ClickHouse/ClickHouse/issues/15568) 中回移：现在可以通过 `ALTER` 查询修改 `VersionedCollapsingMergeTree` 的版本列类型。[#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### 缺陷修复
</div>

* 回移至 [#15150](https://github.com/ClickHouse/ClickHouse/issues/15150)：修复了服务器启动时与 ZooKeeper 通信期间可能卡死的问题——当需要从 ZK 获取配置文件时（使用 `from_zk` include 选项）会触发此问题。修复了 [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814)。[#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 回移至 [#15250](https://github.com/ClickHouse/ClickHouse/issues/15250)：修复了 CacheDictionary 中的段错误 [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837)。[#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 回移至 [#14971](https://github.com/ClickHouse/ClickHouse/issues/14971)：修复了子查询包含 finalizeAggregation 函数时谓词下推无法正常工作的问题。修复了 [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847)。[#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov))。
* 回移至 [#15104](https://github.com/ClickHouse/ClickHouse/issues/15104)：修复了在 Mac OS 上的 Docker 中运行 clickhouse-server 时，在 Atomic 数据库中执行 DDL 查询时出现的 `Cannot rename ... errno: 22, strerror: Invalid argument` 错误。[#15024](https://github.com/ClickHouse/ClickHouse/pull/15024) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 回移至 [#15141](https://github.com/ClickHouse/ClickHouse/issues/15141)：修复了 `join_algorithm='auto'` 中出现的 `Data compressed with different methods` 问题。在 `join_algorithm='partial_merge'` 中，保留左表 join 键的 LowCardinality 类型。[#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2))。
* 回移至 [#15209](https://github.com/ClickHouse/ClickHouse/issues/15209)：调整了 MySQL 列定义数据包中 decimals 字段的大小。[#15152](https://github.com/ClickHouse/ClickHouse/pull/15152) ([maqroll](https://github.com/maqroll))。
* 回移至 [#15224](https://github.com/ClickHouse/ClickHouse/issues/15224)：修复了表引擎 `Buffer` 中的缺陷——执行 `ALTER` 查询后无法向 `Buffer` 插入新结构的数据。修复了 [#15117](https://github.com/ClickHouse/ClickHouse/issues/15117)。[#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15403](https://github.com/ClickHouse/ClickHouse/issues/15403)：修复了将 joinGet 与 LowCardinality 类型配合使用时实例崩溃的问题。修复了 [#15214](https://github.com/ClickHouse/ClickHouse/issues/15214)。[#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird))。
* 回移至 [#15487](https://github.com/ClickHouse/ClickHouse/issues/15487)：修复了查询在 Merge 表上执行 JOIN 时，GROUP BY 中出现"Unknown identifier"的问题。[#15242](https://github.com/ClickHouse/ClickHouse/pull/15242) ([Artem Zuikov](https://github.com/4ertus2))。
* 回移至 [#15282](https://github.com/ClickHouse/ClickHouse/issues/15282)：修复了 QueryLog 中的 MSan 报告问题——`memory_usage` 字段可能使用未初始化的内存。[#15258](https://github.com/ClickHouse/ClickHouse/pull/15258) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 回移至 [#15401](https://github.com/ClickHouse/ClickHouse/issues/15401)：修复了对 `MySQL` 引擎同一张表存在大量子查询时查询挂起的问题。此前，若查询中对同一 `MySQL` 表的子查询超过 16 个，查询将永久挂起。[#15299](https://github.com/ClickHouse/ClickHouse/pull/15299) ([Anton Popov](https://github.com/CurtizJ))。
* 回移至 [#15340](https://github.com/ClickHouse/ClickHouse/issues/15340)：修复了启用 system.logs 时服务器启动阶段偶发的竞态条件。[#15300](https://github.com/ClickHouse/ClickHouse/pull/15300) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15336](https://github.com/ClickHouse/ClickHouse/issues/15336)：修复了 MergeTree 表重命名与后台清理过程中的竞态条件。[#15304](https://github.com/ClickHouse/ClickHouse/pull/15304) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15588](https://github.com/ClickHouse/ClickHouse/issues/15588)：修复了类似 `SELECT toStartOfDay(today())` 的查询因 time_zone 参数为空而报错失败的缺陷。[#15319](https://github.com/ClickHouse/ClickHouse/pull/15319) ([Bharat Nallan](https://github.com/bharatnc))。
* 回移至 [#15446](https://github.com/ClickHouse/ClickHouse/issues/15446)：当 `boundingRatio` 聚合函数的第二个参数类型错误时，现在能正确报告错误信息。[#15407](https://github.com/ClickHouse/ClickHouse/pull/15407) ([detailyang](https://github.com/detailyang))。
* 回移至 [#15507](https://github.com/ClickHouse/ClickHouse/issues/15507)：修复了 DDLWorker 中事件订阅的缺陷，该缺陷偶发性地导致 `ON CLUSTER` 查询挂起。该问题引入自 [#13450](https://github.com/ClickHouse/ClickHouse/issues/13450)。[#15477](https://github.com/ClickHouse/ClickHouse/pull/15477) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15549](https://github.com/ClickHouse/ClickHouse/issues/15549)：修复了查询数据中不存在、且所依赖的其他列也不存在的列时出现的 `Missing columns` 错误。修复了 [#15530](https://github.com/ClickHouse/ClickHouse/issues/15530)。[#15532](https://github.com/ClickHouse/ClickHouse/pull/15532) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15560](https://github.com/ClickHouse/ClickHouse/issues/15560)：修复了执行相同模式的 `LIKE` 后，`ILIKE` 运算符不再大小写不敏感的缺陷。[#15536](https://github.com/ClickHouse/ClickHouse/pull/15536) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15725](https://github.com/ClickHouse/ClickHouse/issues/15725)：修复了变更操作在执行 `MOVE` 或 `REPLACE PARTITION` 后（极少数情况下也发生在 `DETACH` 或 `DROP PARTITION` 后）可能因等待不存在的分片而挂起的问题。[#15537](https://github.com/ClickHouse/ClickHouse/pull/15537) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 回移至 [#15655](https://github.com/ClickHouse/ClickHouse/issues/15655)：修复了发起节点上不存在对应数据库时，使用 IN 和分布式表的查询出现"Database <db> doesn't exist."错误的问题。[#15538](https://github.com/ClickHouse/ClickHouse/pull/15538) ([Artem Zuikov](https://github.com/4ertus2))。
* 回移至 [#15631](https://github.com/ClickHouse/ClickHouse/issues/15631)：大幅降低了 AggregatingInOrderTransform/optimize_aggregation_in_order 的内存占用。[#15543](https://github.com/ClickHouse/ClickHouse/pull/15543) ([Azat Khuzhin](https://github.com/azat))。
* 回移至 [#15583](https://github.com/ClickHouse/ClickHouse/issues/15583)：防止出现错误信息 `Could not calculate available disk space (statvfs), errno: 4, strerror: Interrupted system call`。修复了 [#15541](https://github.com/ClickHouse/ClickHouse/issues/15541)。[#15557](https://github.com/ClickHouse/ClickHouse/pull/15557) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 回移至 [#15665](https://github.com/ClickHouse/ClickHouse/issues/15665)：修复了在 `VALUES`、`LIMIT` 或 `IN` 运算符右侧使用 `JSON*` 函数结果时出现的 `Element ... is not a constant expression` 错误。[#15589](https://github.com/ClickHouse/ClickHouse/pull/15589) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 回移至 [#15712](https://github.com/ClickHouse/ClickHouse/issues/15712)：修复了查询计划中 `ReadFromStorage` 步骤的资源销毁顺序问题，该问题在极少数情况下可能导致程序崩溃，可能与 [#15610](https://github.com/ClickHouse/ClickHouse/issues/15610) 相关。[#15645](https://github.com/ClickHouse/ClickHouse/pull/15645) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 回移至 [#15696](https://github.com/ClickHouse/ClickHouse/issues/15696)：修复了 AMQP-CPP 中的竞态条件。[#15667](https://github.com/ClickHouse/ClickHouse/pull/15667) ([alesapin](https://github.com/alesapin))。
* 回移至 [#15739](https://github.com/ClickHouse/ClickHouse/issues/15739)：修复了当 `MATERIALIZED VIEW` 的查询包含 `ARRAY JOIN` 时，向其插入数据可能出现的 `Cannot find column` 错误。[#15717](https://github.com/ClickHouse/ClickHouse/pull/15717) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
