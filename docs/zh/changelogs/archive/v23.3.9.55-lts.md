  ### ClickHouse 发布版本 v23.3.9.55-长期支持版 (b9c5c8622d3) FIXME，相比于 v23.3.8.21-长期支持版 (1675f2264f3)

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#52213](https://github.com/ClickHouse/ClickHouse/issues/52213) 中回移：如果没有插入任何数据，则不要在 `ANY` hash join 中存储块。[#48633](https://github.com/ClickHouse/ClickHouse/pull/48633) ([vdimir](https://github.com/vdimir)).
* 已在 [#52826](https://github.com/ClickHouse/ClickHouse/issues/52826) 中回移：修复错误的投影分析导致主键失效的问题。该问题仅在 `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1` 时存在。此修复解决了 [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823)。此修复解决了 [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173)。[#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#53019](https://github.com/ClickHouse/ClickHouse/issues/53019) 中回移：将内联 cache 打包进 Docker 镜像有时会引发一些奇怪的问题。既然我们完全不用它，去掉它就没问题了。[#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#53288](https://github.com/ClickHouse/ClickHouse/issues/53288) 中回移：编译器的 profile 数据 (`-ftime-trace`) 会上传到 ClickHouse Cloud。这是继 [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) 之后的第二次尝试。[#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#53461](https://github.com/ClickHouse/ClickHouse/issues/53461) 中回移：在 `clickhouse start` 命令中保留环境参数。修复了 [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962)。[#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
