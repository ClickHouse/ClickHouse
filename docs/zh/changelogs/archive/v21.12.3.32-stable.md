<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#32890](https://github.com/ClickHouse/ClickHouse/issues/32890) 中回移：修复当 materialized view 的目标为 JOIN 或 SET 表时出现 LOGICAL&#95;ERROR 的问题。 [#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#33183](https://github.com/ClickHouse/ClickHouse/issues/33183) 中回移：如果使用 `MySQL` engine 的 database 无法连接到 MySQL 服务器，server 可能会启动失败；该问题现已修复。修复了 [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441)。 [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32904](https://github.com/ClickHouse/ClickHouse/issues/32904) 中回移：`MergeTree` table engine 在运行中的变更过多或内存占用过高时，可能会静默跳过某些变更；该问题现已修复。修复了 [#17882](https://github.com/ClickHouse/ClickHouse/issues/17882)。 [#32814](https://github.com/ClickHouse/ClickHouse/pull/32814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#33047](https://github.com/ClickHouse/ClickHouse/issues/33047) 中回移：修复从远程文件系统异步读取时的 lazy 寻道优化问题。关闭了 [#32803](https://github.com/ClickHouse/ClickHouse/issues/32803)。 [#32835](https://github.com/ClickHouse/ClickHouse/pull/32835) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#32932](https://github.com/ClickHouse/ClickHouse/issues/32932) 中回移：关闭 [#32487](https://github.com/ClickHouse/ClickHouse/issues/32487)。 [#32914](https://github.com/ClickHouse/ClickHouse/pull/32914) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#32962](https://github.com/ClickHouse/ClickHouse/issues/32962) 中回移：修复 `replaceRegexpAll` 函数中的回归问题。匹配到的子串为空时，该函数会返回错误结果。此项关闭了 [#32777](https://github.com/ClickHouse/ClickHouse/issues/32777)。此项关闭了 [#30245](https://github.com/ClickHouse/ClickHouse/issues/30245)。 [#32945](https://github.com/ClickHouse/ClickHouse/pull/32945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#33067](https://github.com/ClickHouse/ClickHouse/issues/33067) 中回移：修复 hdfs URL 检查不允许使用 HA namenode 地址的问题。该缺陷由 [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042) 引入。 [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#33100](https://github.com/ClickHouse/ClickHouse/issues/33100) 中回移：修复 `cancel_http_readonly_queries_on_client_close` 场景下的 Context 泄漏问题 (即已上传到 server 的外部表及其他资源发生泄漏) 。 [#32982](https://github.com/ClickHouse/ClickHouse/pull/32982) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#33123](https://github.com/ClickHouse/ClickHouse/issues/33123) 中回移：修复启用 `local_filesystem_read_prefetch` 或 `remote_filesystem_read_prefetch` 时，读取 `LowCardinality` 列会报错 `Invalid version for SerializationLowCardinality key column` 的问题。 [#33046](https://github.com/ClickHouse/ClickHouse/pull/33046) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
