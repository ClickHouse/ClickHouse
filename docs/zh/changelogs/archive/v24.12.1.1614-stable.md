<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 函数 `greatest` 和 `least` 现在会忽略 NULL 输入值；而此前如果参数中有一个为 NULL，它们就会返回 NULL。例如，`SELECT greatest(1, 2, NULL)` 现在会返回 2。这使其行为与 PostgreSQL 兼容。[#65519](https://github.com/ClickHouse/ClickHouse/pull/65519) ([kevinyhzou](https://github.com/KevinyhZou)).
* 基于 Poco 驱动程序的旧版 MongoDB 集成已被移除。服务器设置 `use_legacy_mongodb_integration` 现已废弃，不再生效。[#71997](https://github.com/ClickHouse/ClickHouse/pull/71997) ([Kirill Nikiforov](https://github.com/allmazz)).



<div id="new-feature">
  #### 新特性
</div>

* 新增查询，支持将 MergeTree 表挂载为 ReplicatedMergeTree，反之亦然。[#65401](https://github.com/ClickHouse/ClickHouse/pull/65401) ([Kirill](https://github.com/kirillgarbar))。
* 实现了 SYSTEM LOAD PRIMARY KEY 命令，用于加载指定表所有 parts 的主索引；若未指定表，则加载所有表的主索引。该命令适用于基准测试场景，并可避免查询执行时产生额外延迟。[#66252](https://github.com/ClickHouse/ClickHouse/pull/66252) ([ZAWA_ll](https://github.com/Zawa-ll))。
* 新增语句 `SYSTEM LOAD PRIMARY KEY`，用于加载指定表所有 parts 的主索引；若未指定表，则加载所有表的主索引。该语句适用于基准测试场景，并可避免查询执行时产生额外延迟。[#67733](https://github.com/ClickHouse/ClickHouse/pull/67733) ([ZAWA_ll](https://github.com/Zawa-ll))。
* [Iceberg 数据存储](https://iceberg.apache.org/spec/#file-system-operations)格式为用户提供了丰富的表结构修改选项。此拉取请求实现了对 Iceberg 格式表的读取支持，涵盖列顺序、列名及简单类型扩展均已发生变更的场景。[#69445](https://github.com/ClickHouse/ClickHouse/pull/69445) ([Daniil Ivanik](https://github.com/divanik))。
* 新增函数 `toUnixTimestamp64Second`，将 `DateTime64` 转换为固定秒精度的 `Int64` 值，当日期早于 1970 年 1 月 1 日（星期四）00:00:00 UTC 时可返回负值。[#70597](https://github.com/ClickHouse/ClickHouse/pull/70597) ([zhanglistar](https://github.com/zhanglistar))。
* 新增设置 `enforce_index_structure_match_on_partition_manipulation`，当源表的 projections 和二级索引是目标表的子集时，允许执行挂载操作。关闭 [#70602](https://github.com/ClickHouse/ClickHouse/issues/70602)。[#70603](https://github.com/ClickHouse/ClickHouse/pull/70603) ([zwy991114](https://github.com/zwy991114))。
* 函数 `cast` 的输出与 Apache Spark 存在差异，导致 gluten 项目出现不一致，详见 https://github.com/apache/incubator-gluten/issues/7602。此拉取请求新增了 Spark 文本输出格式支持，默认禁用。[#70957](https://github.com/ClickHouse/ClickHouse/pull/70957) ([zhanglistar](https://github.com/zhanglistar))。
* 此拉取请求引入了新设置 `allow_experimental_reverse_key`，支持在 MergeTree 排序键中使用降序排列。该功能适用于时间序列分析，尤其是 TopN 查询。使用示例：```sql CREATE TABLE example ( time DateTime, key Int32, value String ) ENGINE = MergeTree ORDER BY (time DESC, key); -- 'time' 字段降序排列 SETTINGS allow_experimental_reverse_key = 1;。[#71095](https://github.com/ClickHouse/ClickHouse/pull/71095) ([Amos Bird](https://github.com/amosbird))。
* 集成 Iceberg REST Catalog。[#71542](https://github.com/ClickHouse/ClickHouse/pull/71542) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 新增选项，用于在查询计划中指定 join 的内表（build 表）。该选项通过 `query_plan_join_swap_table` 控制，可设置为 `auto`。在此模式下，ClickHouse 将自动选择行数最少的表作为内表。[#71577](https://github.com/ClickHouse/ClickHouse/pull/71577) ([Vladimir Cherkasov](https://github.com/vdimir))。
* 新增语法 ALTER USER {ADD|MODIFY|DROP SETTING}、ALTER USER {ADD|DROP PROFILE}，ALTER ROLE 和 ALTER PROFILE 同样支持以上语法。[#72050](https://github.com/ClickHouse/ClickHouse/pull/72050) ([pufit](https://github.com/pufit))。
* 新增 `arrayPrAUC` 函数，用于计算精确率-召回率曲线（Precision Recall curve）的 AUC（曲线下面积）。[#72073](https://github.com/ClickHouse/ClickHouse/pull/72073) ([Emmanuel](https://github.com/emmanuelsdias))。
* 为 `MergeTree` 表的主索引新增缓存功能（可通过表设置 `use_primary_key_cache` 启用）。若同时启用主索引的延迟加载与缓存，主索引将按需加载至缓存（类似于标记缓存），而非永久驻留内存。新增在数据 parts 插入、合并、拉取及表重启时对主索引进行预热的功能（可通过设置 `prewarm_primary_key_cache` 启用）。[#72102](https://github.com/ClickHouse/ClickHouse/pull/72102) ([Anton Popov](https://github.com/CurtizJ))。
* 已回移至 [#73593](https://github.com/ClickHouse/ClickHouse/issues/73593)：`SELECT` 和 `VIEW` 语句现已支持别名，例如 `SELECT b FROM (SELECT number, number*2 FROM numbers(2)) AS x (a, b);`。此改动使 TPC-H 查询 15 无需任何修改即可运行。[#72480](https://github.com/ClickHouse/ClickHouse/pull/72480) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* 为数组类型新增 `indexOfAssumeSorted` 函数，针对非递减有序数组的元素查找进行了优化。[#72517](https://github.com/ClickHouse/ClickHouse/pull/72517) ([Eric Kurbanov](https://github.com/erickurbanov))。
* 聚合函数 `groupConcat` 现支持以可选的第二个参数形式指定分隔符。[#72540](https://github.com/ClickHouse/ClickHouse/pull/72540) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* 新增设置 `http_response_headers`，支持自定义 HTTP 响应头。例如，可指示浏览器渲染存储在数据库中的图片。关闭 [#59620](https://github.com/ClickHouse/ClickHouse/issues/59620)。[#72656](https://github.com/ClickHouse/ClickHouse/pull/72656) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 新增函数 `fromUnixTimestamp64Second`，将 Int64 类型的 Unix timestamp 值转换为 DateTime64。[#73146](https://github.com/ClickHouse/ClickHouse/pull/73146) ([Robert Schulze](https://github.com/rschu1ze))。

<div id="performance-improvement">
  #### 性能提升
</div>

* 针对对象存储磁盘，`clickhouse disks remove --recursive` 的内存占用已降低。[#67323](https://github.com/ClickHouse/ClickHouse/pull/67323) ([Kirill](https://github.com/kirillgarbar))。
* 为更多表达式启用 JIT 编译：abs/bitCount/sign/modulo/pmod/isNull/isNotNull/assumeNotNull/to(U)Int*/toFloat*、比较函数（=、<、>、>=、<=）、逻辑函数（and、or）。[#70598](https://github.com/ClickHouse/ClickHouse/pull/70598) ([李扬](https://github.com/taiyang-li))。
* 当 `join_algorithm` 设置为 `default` 时，现在将优先使用 `parallel_hash` 算法（如适用）。当 `parallel_hash` 无法使用时，仍会回退到原有的两种备选方案（`direct` 和 `hash`）。[#70788](https://github.com/ClickHouse/ClickHouse/pull/70788) ([Nikita Taranov](https://github.com/nickitat))。
* 新增选项，支持从 `WHERE` 和 `ON` 表达式中提取公共表达式，以减少 join 过程中使用的哈希表数量。可通过设置 `optimize_extract_common_expressions = 1` 启用。[#71537](https://github.com/ClickHouse/ClickHouse/pull/71537) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* 支持在包含 `LowCardinality(String)` 的 `SELECT` 查询中使用索引。[#71598](https://github.com/ClickHouse/ClickHouse/pull/71598) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* 在启用并行副本与本地执行计划的查询执行过程中，跳过工作线程上的索引分析。协调器将根据自身（即查询发起方）的索引分析结果，为工作线程选择需要读取的数据范围。[#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter))。
* 恢复了 https://github.com/ClickHouse/ClickHouse/pull/57631 中的优化——在 compact parts 中读取单列的子列，该优化此前被意外删除。[#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar))。
* 通过对比较器中的调用进行去虚拟化，提升了 `LowCardinality(String)` 列的排序速度。[#72337](https://github.com/ClickHouse/ClickHouse/pull/72337) ([Alexander Gololobov](https://github.com/davenger))。
* 针对部分简单数据类型优化了 argMin/Max 函数。[#72350](https://github.com/ClickHouse/ClickHouse/pull/72350) ([alesapin](https://github.com/alesapin))。
* 优化了内存追踪器中共享锁的加锁方式，以降低锁竞争。[#72375](https://github.com/ClickHouse/ClickHouse/pull/72375) ([Jiebin Sun](https://github.com/jiebinn))。
* 新增设置 `use_async_executor_for_materialized_views`。对 materialized view 查询采用异步且可能多线程的执行方式，可加快 INSERT 期间的视图处理速度，但同时会消耗更多内存。[#72497](https://github.com/ClickHouse/ClickHouse/pull/72497) ([alesapin](https://github.com/alesapin))。
* 设置 `max_size_to_preallocate_for_aggregation` 和 `max_size_to_preallocate_for_joins` 的默认值进一步提升至 `10^12`，使该优化能在更多场景下生效。[#72555](https://github.com/ClickHouse/ClickHouse/pull/72555) ([Nikita Taranov](https://github.com/nickitat))。
* 提升了聚合函数状态的反序列化性能（适用于 `AggregateFunction` 数据类型及分布式查询），并小幅提升了 `RowBinary` 格式的解析性能。[#72818](https://github.com/ClickHouse/ClickHouse/pull/72818) ([Anton Popov](https://github.com/CurtizJ))。

<div id="improvement">
  #### 改进
</div>

* 新增取消逻辑：`CancellationChecker` 会检查每个已启动查询的超时情况，并在超时后将其停止。[#69880](https://github.com/ClickHouse/ClickHouse/pull/69880) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).

* server config (users.xml) 中的设置现在也会应用到 client。对 format 设置很有用，例如 `date_time_output_format`。[#71178](https://github.com/ClickHouse/ClickHouse/pull/71178) ([Michael Kolupaev](https://github.com/al13n321)).
* 修复了 [#71227](https://github.com/ClickHouse/ClickHouse/issues/71227)。[#71286](https://github.com/ClickHouse/ClickHouse/pull/71286) ([Arthur Passos](https://github.com/arthurpassos)).
* 根据 server/user memory usage 自动将 `GROUP BY`/`ORDER BY` 转为落盘执行。通过 `max_bytes_ratio_before_external_group_by`/`max_bytes_ratio_before_external_sort` 查询设置控制。[#71406](https://github.com/ClickHouse/ClickHouse/pull/71406) ([Azat Khuzhin](https://github.com/azat)).
* 函数 `translate` 现在支持删除字符：如果 `from` argument 包含的字符多于 `to` argument，就会删除多出的字符。示例：`SELECT translate('clickhouse', 'clickhouse', 'CLICK')` 现在返回 `CLICK`。[#71441](https://github.com/ClickHouse/ClickHouse/pull/71441) ([shuai.xu](https://github.com/shuai-xu)).
* 支持将 Object ALTER 为 JSON。[#71784](https://github.com/ClickHouse/ClickHouse/pull/71784) ([Pavel Kruglov](https://github.com/Avogar)).
* 在 `MergeTreeReadPoolParallelReplicasInOrder` 中拆分 ranges，以减少读取期间的内存消耗。[#72173](https://github.com/ClickHouse/ClickHouse/pull/72173) ([JIaQi](https://github.com/JiaQiTang98)).
* 在为分布式 `INSERT ... SELECT` 构建执行计划时遵循 `prefer_locahost_replica`。[#72190](https://github.com/ClickHouse/ClickHouse/pull/72190) ([filimonov](https://github.com/filimonov)).
* 问题在[这里](https://github.com/ClickHouse/ClickHouse/issues/72091)有描述。Azure Iceberg Writer 会创建不符合规范的 Iceberg 元数据文件 (以及 manifest 文件) 。在这个 PR 中，我增加了一种尝试：使用 v2 reader 读取 v1 iceberg format metadata (因为它们就是以这种方式写入的) ；另外，如果它们没有在 manifest 文件中创建对应字段，也会报错。[#72277](https://github.com/ClickHouse/ClickHouse/pull/72277) ([Daniil Ivanik](https://github.com/divanik)).
* 将 JSON/Dynamic/Variant types 从 experimental features 提升为 beta。[#72294](https://github.com/ClickHouse/ClickHouse/pull/72294) ([Pavel Kruglov](https://github.com/Avogar)).
* 现在允许在查询中使用 `UNION [ALL]` 来 `CREATE MATERIALIZED VIEW`。其行为与带 `JOIN` 的 matview 相同：**只有 `SELECT` expression 中的第一张表会作为 insert 的 trigger**，其余所有表都会被忽略。[#72347](https://github.com/ClickHouse/ClickHouse/pull/72347) ([alesapin](https://github.com/alesapin)).
* 如果插入批次中的分区键只有一个值，则可加速向 MergeTree 的插入。[#72348](https://github.com/ClickHouse/ClickHouse/pull/72348) ([alesapin](https://github.com/alesapin)).
* 之前存放在 `/utils` 文件夹中、需要手动从源码编译的所有小型工具，现在都已成为主 ClickHouse 支持包的一部分。此变更关闭了：[#72404](https://github.com/ClickHouse/ClickHouse/issues/72404)。[#72426](https://github.com/ClickHouse/ClickHouse/pull/72426) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 实现从备份恢复时并行创建表。在此 PR 之前，`RESTORE` 命令始终只使用单线程创建表，因此当备份中包含大量表时，速度可能会很慢。[#72427](https://github.com/ClickHouse/ClickHouse/pull/72427) ([Vitaly Baranov](https://github.com/vitlibar)).
* 在 system.metrics 中新增 MergeTreeIndexGranularityInternalArraysTotalSize 指标。该指标用于找出拥有超大数据集、容易出现高内存占用问题的实例。[#72490](https://github.com/ClickHouse/ClickHouse/pull/72490) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 当 ClickHouse 用作字典的数据源时，新增了对 source 查询的验证。[#72548](https://github.com/ClickHouse/ClickHouse/pull/72548) ([Alexey Katsman](https://github.com/alexkats)).
* 确保 ClickHouse 在重新加载配置时能够感知 ZooKeeper 中的变更。[#72593](https://github.com/ClickHouse/ClickHouse/pull/72593) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
