<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#31204](https://github.com/ClickHouse/ClickHouse/issues/31204) 中回移：通过增加对 hdfs URL 结构的额外检查，修复了因 hdfs URL 错误导致 debug server 中发生 abort，以及 release server 中出现 `DB::Exception: std::out_of_range: basic_string` 错误的问题。[#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#31253](https://github.com/ClickHouse/ClickHouse/issues/31253) 中回移：修复了 Keeper 中的一个 bug；当部分协调日志丢失，且快照比最新日志更新时，可能会导致无法启动。[#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)).
* 已在 [#31521](https://github.com/ClickHouse/ClickHouse/issues/31521) 中回移：从 RPNElement 中移除了 not like function。[#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* 已在 [#31552](https://github.com/ClickHouse/ClickHouse/issues/31552) 中回移：修复了 S3 的 STS credentials provider 中的 `nullptr` 问题。[#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 已在 [#31582](https://github.com/ClickHouse/ClickHouse/issues/31582) 中回移：* 在该优化中的 bug 修复之前，禁用 `partial_merge_join_left_table_buffer_bytes`。参见 [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009))。* 移除冗余选项 `partial_merge_join_optimizations`。[#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#31599](https://github.com/ClickHouse/ClickHouse/issues/31599) 中回移：修复了仅列名包含无效 UTF-8 序列时生成的 JSON 无效的问题。[#31534](https://github.com/ClickHouse/ClickHouse/pull/31534) ([Kevin Michel](https://github.com/kmichel-aiven)).
* 已在 [#31779](https://github.com/ClickHouse/ClickHouse/issues/31779) 中回移：修复了 `RENAME TABLE` 查询在尝试重命名 `Ordinary` database 中的 DDL 字典时行为不正确的问题。[#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#31790](https://github.com/ClickHouse/ClickHouse/issues/31790) 中回移：Settings `input_format_allow_errors_num` 和 `input_format_allow_errors_ratio` 在解析 `IPv4` 等 domain types 时不生效，现已修复。修复了 [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686)。[#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#31829](https://github.com/ClickHouse/ClickHouse/issues/31829) 中回移：修复了在执行 `ON CLUSTER` 查询时，如果指定的 cluster 名称恰好是 `Replicated` database 的名称，就会出现 `there are no such cluster here` 错误的问题。[#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#31813](https://github.com/ClickHouse/ClickHouse/issues/31813) 中回移：修复了 JSONEachRowWithProgress output format 中的竞争问题，即当输出中混合数据和进度行时会出现该问题。[#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#31761](https://github.com/ClickHouse/ClickHouse/issues/31761) 中回移：修复了 `Buffer` table engine 对 `Map` type 的支持问题。修复了 [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546)。[#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#31890](https://github.com/ClickHouse/ClickHouse/issues/31890) 中回移：修复 TSKV 格式中可能出现的断言 `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.`。[#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#31910](https://github.com/ClickHouse/ClickHouse/issues/31910) 中回移：修复函数 `empty` 和 `notEmpty` 在参数为 `UUID` 类型时的问题。修复了 [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819)。[#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
