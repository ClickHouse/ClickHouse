<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#75811](https://github.com/ClickHouse/ClickHouse/issues/75811) 中回移：正确传递用于客户端与服务端通信的 Native format 设置。[#73924](https://github.com/ClickHouse/ClickHouse/pull/73924) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74090](https://github.com/ClickHouse/ClickHouse/issues/74090) 中回移：修复隐式特权的问题 (此前其行为类似通配符) 。[#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#75556](https://github.com/ClickHouse/ClickHouse/issues/75556) 中回移：修复在 macOS 上通过 PostgreSQL 接口执行查询 `INSERT INTO SELECT` 时发生的崩溃 (问题 [#72938](https://github.com/ClickHouse/ClickHouse/issues/72938)) 。[#74231](https://github.com/ClickHouse/ClickHouse/pull/74231) ([Artem Yurov](https://github.com/ArtemYurov)).
* 已在 [#75630](https://github.com/ClickHouse/ClickHouse/issues/75630) 中回移：修复 PSQL 复制中因未捕获异常导致的崩溃。[#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#76103](https://github.com/ClickHouse/ClickHouse/issues/76103) 中回移：修复 LowCardinality Nullable 数据类型的空值安全 JOIN 处理。此前，带有空值安全比较的 JOIN ON (例如 `IS NOT DISTINCT FROM`、`<=>`、`a IS NULL AND b IS NULL OR a == b`) 在 LowCardinality 列上无法正确工作。[#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#75568](https://github.com/ClickHouse/ClickHouse/issues/75568) 中回移：Keeper 修复：回滚日志时避免向已损坏的更新日志写入。[#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#75652](https://github.com/ClickHouse/ClickHouse/issues/75652) 中回移：对 azureblobstorage 表引擎的凭据进行脱敏。[#75319](https://github.com/ClickHouse/ClickHouse/pull/75319) ([Garrett Thomas](https://github.com/garrettthomaskth)).
* 已在 [#75744](https://github.com/ClickHouse/ClickHouse/issues/75744) 中回移：修复 Protobuf schema 缓存中的崩溃问题；该问题可能在以 Protobuf format 输出并并行执行查询 `SYSTEM DROP FORMAT SCHEMA CACHE` 时发生。[#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#76096](https://github.com/ClickHouse/ClickHouse/issues/76096) 中回移：修复在分布式表上的 JOIN 中使用 Array 类型的 JSON subcolumns 时，可能出现的错误 `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes`。[#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#75854](https://github.com/ClickHouse/ClickHouse/issues/75854) 中回移：修复 allow&#95;feature&#95;tier 与 compatibility MergeTree 设置之间的交互问题。[#75635](https://github.com/ClickHouse/ClickHouse/pull/75635) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#75892](https://github.com/ClickHouse/ClickHouse/issues/75892) 中回移：修复在不同类型的列之间执行多次异步 `RENAME` 查询 (使用 `alter_sync = 0`) 后，从 `MergeTree` 表读取时偶发崩溃的问题。[#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#76157](https://github.com/ClickHouse/ClickHouse/issues/76157) 中回移：在对其 PK 列执行 alter modify 时重建 projection。此前，这可能会导致在对 projection PK 所使用的列执行 alter modify 后进行 selects 时出现 `CANNOT_READ_ALL_DATA` 错误。[#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#75823](https://github.com/ClickHouse/ClickHouse/issues/75823) 中回移：修复了 `DistinctSortedStreamTransform` 中的空指针解引用问题。[#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* 已在 [#76216](https://github.com/ClickHouse/ClickHouse/issues/76216) 中回移：`clickhouse-library-bridge` 允许从 filesystem 中打开任意库，因此只有在隔离环境中运行才是安全的。为防止其在 clickhouse-server 附近运行时产生漏洞，我们将把库的 path 限制在 configuration 中提供的位置。该漏洞由 **Arseniy Dugin** 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
