<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#75990](https://github.com/ClickHouse/ClickHouse/issues/75990) 中回移：我们发现，并发控制可能导致 INSERT 和 SELECT 之间的 CPU 分配不均。当所有 CPU 插槽在无竞争的情况下被无条件分配给 `max_threads` = 1 的 INSERT 时，`max_threads` 值较高的 SELECT 由于只能使用单个线程，性能会明显下降。[#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)) 。
