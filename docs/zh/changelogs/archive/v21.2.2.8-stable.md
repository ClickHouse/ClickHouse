  ### ClickHouse 发布版 v21.2.2.8-稳定版本 FIXME (相较于 v21.1.1.5646-prestable)
</div>

<div id="backward-incompatible-change">
  #### 不向后兼容的变更
</div>

* * 修复 `OPTIMIZE TABLE`/合并操作的内存跟踪问题——在 `OPTIMIZE TABLE`/合并操作中计入查询内存限制和采样设置。 [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* 禁止将 `lcm`/`gcd` 用于浮点数。 [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* 按位函数 (`bitAnd`、`bitOr` 等) 不得用于浮点参数。现在必须显式转换为整数。 [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 新特性
</div>

* 新增了对 zstd long 选项的支持，以更好地压缩字符串列，从而节省空间。[#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * 新增支持将 LDAP 组名以及一般的属性值映射到来自 LDAP 用户目录的用户的本地角色。[#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* 数据类型 `Nested` 现已支持任意层级的嵌套。引入了复杂类型的子列，例如 `Array` 中的 `size0`、`Nullable` 中的 `null` 以及 `Tuple` 元素名称，这些子列无需读取整列即可读取。[#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* 为 `argMin` 和 `argMax` 函数添加了对 `Tuple` 参数的支持。[#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 为 `FlatDictionary`、`HashedDictionary`、`ComplexKeyHashedDictionary`、`DirectDictionary`、`ComplexKeyDirectDictionary`、`RangeHashedDictionary` 添加了 `Nullable` 支持。[#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* 禁止将浮点列用作分区键，相关内容见：[#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255。[#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* 添加函数 decodeXMLComponent，用于解码 XML 字符。`SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* 添加了 PostgreSQL 表引擎 (同时支持 select/insert，并支持多维数组) ，也可作为表函数使用。添加了 PostgreSQL 字典源。添加了 PostgreSQL 数据库引擎。[#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 添加 `SELECT ALL` 语法。关闭 [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706)。[#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* 为 map 数据类型添加了三个函数：1. mapContains(map, key)，用于检查 map.keys 是否包含第二个参数 key。2. mapKeys(map)，以 `Array` 格式返回所有键。3. mapValues(map)，以 `Array` 格式返回所有值。[#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* 在 play UI 中支持 MetaKey+Enter 快捷键绑定。[#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* 函数 formatDateTime 支持 `%Q` 修饰符，可将日期格式化为季度。... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* ... [#19261](https://github.com/ClickHouse/ClickHouse/pull/19261) ([RegulusZ](https://github.com/RegulusZ)).
* 将查询期间创建的工厂对象名称添加到 system.query&#95;log 中。关闭 [#18495](https://github.com/ClickHouse/ClickHouse/issues/18495)。[#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 添加 `sign` 数学函数。[#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).
* 添加了函数 `parseDateTimeBestEffortUSOrZero`、`parseDateTimeBestEffortUSOrNull`。[#19712](https://github.com/ClickHouse/ClickHouse/pull/19712) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#19764](https://github.com/ClickHouse/ClickHouse/pull/19764) ([emhlbmc](https://github.com/emhlbmc)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 为 S3 连接使用连接池，由 `s3_max_connections` 设置控制。[#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 在逻辑等价时，将 `sumIf()` 和 `sum(if())` 函数重写为 `countIf()` 函数。[#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)) 。
* 更新 libcxx 并使用不稳定 ABI，以获得更好的性能。[#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)) 。
* 通过减少 `stat` 系统调用的次数，加快 parts 删除速度。这恢复了之前已有的一项优化。`IDisk` 的接口也更加安全。此更改关闭了 [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065)。[#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 加速聚合函数 `sum`。该改进仅在合成基准测试中可见，实际意义不大。[#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 支持将查询计划中的 `Filter` 步骤拆分为 `Expression + Filter` 对。结合 `Expression + Expression` 合并优化 ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)) ，这可能会将某些表达式的执行延后到 `Filter` 步骤之后。[#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 减少 Buffer engine 多个 layer 的锁竞争。[#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)) 。
* 通过移除每次连接时对配置的访问，略微改善 server 延迟。[#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="improvement">
  #### 改进
</div>

* 新增支持在创建 `LIVE VIEW` 表时使用 `WITH ... [AND] [PERIODIC] REFRESH [interval_in_sec]` 子句。[#14822](https://github.com/ClickHouse/ClickHouse/pull/14822) ([vzakaznikov](https://github.com/vzakaznikov)).
* * 添加 optimize&#95;alias&#95;column&#95;prediction (默认开启) ，其作用包括：* 在进行分区裁剪以及使用次级索引跳过数据时，在 WHERE 中正确处理别名列 * 对于 optimize&#95;trivial&#95;count，在 WHERE 中正确处理用于简单 count 查询的别名列 * 对于 optimize&#95;aggregation&#95;in&#95;order/optimize&#95;read&#95;in&#95;order，在 GROUP BY/ORDER BY 中正确处理别名列。[#16995](https://github.com/ClickHouse/ClickHouse/pull/16995) ([sundyli](https://github.com/sundy-li)) 。
* 更新了 AWS C++ SDK，以便在 S3 中使用全局区域。[#17870](https://github.com/ClickHouse/ClickHouse/pull/17870) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 支持向表函数 `cluster` insert 数据，并且表函数 `remote` 和 `cluster` 都支持通过指定分片键将数据分发到各个节点。关闭了 [#16752](https://github.com/ClickHouse/ClickHouse/issues/16752)。[#18264](https://github.com/ClickHouse/ClickHouse/pull/18264) ([flynn](https://github.com/ucasfl)) 。
* 支持 `EXISTS VIEW` 语法。[#18552](https://github.com/ClickHouse/ClickHouse/pull/18552) ([Du Chuan](https://github.com/spongedu)) 。
* 将 librdkafka 更新至 v1.6.0-RC2。修复了 [#18668](https://github.com/ClickHouse/ClickHouse/issues/18668)。[#18671](https://github.com/ClickHouse/ClickHouse/pull/18671) ([filimonov](https://github.com/filimonov)) 。
* 允许为 CTE 进一步指定别名。当 `enable_global_with_statement = 1` 时，会将 CSE 传播到同一级别的子查询中。此更改修复了 [#17378](https://github.com/ClickHouse/ClickHouse/issues/17378)。此更改还修复了 [https://github.com/ClickHouse/ClickHouse/pull/16575#issuecomment-753416235](https://github.com/ClickHouse/ClickHouse/pull/16575#issuecomment-753416235)。[#18684](https://github.com/ClickHouse/ClickHouse/pull/18684) ([Amos Bird](https://github.com/amosbird)) 。
* 为 bitmapTransform、bitmapSubsetInRange、bitmapSubsetLimit、bitmapContains 函数新增了对 [UInt8, UInt16, UInt32, UInt64] 参数类型的支持。此更改关闭了 [#18713](https://github.com/ClickHouse/ClickHouse/issues/18713)。[#18791](https://github.com/ClickHouse/ClickHouse/pull/18791) ([sundyli](https://github.com/sundy-li)) 。
* 新增了基于前缀的 S3 端点设置。[#18812](https://github.com/ClickHouse/ClickHouse/pull/18812) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 修复了包含 aggregate function states 的表在进行 RIGHT 和 FULL JOIN 时的问题。在之前的版本中，会抛出与 `cloneResized` 方法相关的异常。[#18818](https://github.com/ClickHouse/ClickHouse/pull/18818) ([templarzq](https://github.com/templarzq)) 。
* * 在发送前，先在发送端校验分布式批次中每个块的校验和 (无需将文件读取两遍，校验和会在读取时完成验证) ，这样可避免接收端的 INSERT 卡住 (例如发送端存在被截断的 .bin 文件时) ——同时避免了对批量 INSERT 的 .bin 文件进行两次读取 (此前为了计算行数/字节数并将块合并考虑在内，这是必需的；现在这些信息已包含在请求头中，同时保留了向后兼容性) 。[#18853](https://github.com/ClickHouse/ClickHouse/pull/18853) ([Azat Khuzhin](https://github.com/azat)).
* 添加 `normalizeQueryKeepNames` 和 `normalizedQueryHashKeepNames`，可在归一化查询时不再用 `?` 掩盖长名称。这有助于更好地分析复杂的查询日志。[#18910](https://github.com/ClickHouse/ClickHouse/pull/18910) ([Amos Bird](https://github.com/amosbird)).
* Docker image：对 clickhouse-server 入口点进行了多项改进。[#18954](https://github.com/ClickHouse/ClickHouse/pull/18954) ([filimonov](https://github.com/filimonov)).

* 在 clickhouse-server images 中，显式将 clickhouse 用户和用户组的 uid / gid 设置为固定值 (101)。[#19096](https://github.com/ClickHouse/ClickHouse/pull/19096) ([filimonov](https://github.com/filimonov)).

* 修复了 Pretty formats 中 `IPv4` 数据类型的值对齐错误。此前它们是右对齐，而不是左对齐。此项关闭了 [#19184](https://github.com/ClickHouse/ClickHouse/issues/19184)。[#19339](https://github.com/ClickHouse/ClickHouse/pull/19339) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* 支持使用 `.debug` 文件的新位置。此项修复了 [#19348](https://github.com/ClickHouse/ClickHouse/issues/19348)。[#19520](https://github.com/ClickHouse/ClickHouse/pull/19520) ([Amos Bird](https://github.com/amosbird)).
* 为 map 数据类型启用 length/empty/notEmpty 函数，其返回 map 中键的数量。[#19530](https://github.com/ClickHouse/ClickHouse/pull/19530) ([李扬](https://github.com/taiyang-li)).
* 支持函数 `multiIf` 返回常量结果。[#19533](https://github.com/ClickHouse/ClickHouse/pull/19533) ([Maksim Kita](https://github.com/kitaisreal)).
* 新增一个选项，可在读取时禁用校验和验证。绝不应在生产环境中使用。请不要期待禁用它能带来任何收益。它只能用于实验和基准测试。该设置仅适用于 MergeTree 家族的表。对于其他表引擎以及通过网络接收的数据，始终会验证校验和。根据我的观察，性能没有差异，或者差异小于 0.5%。 [#19588](https://github.com/ClickHouse/ClickHouse/pull/19588) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* 如果无法精确确定区域，表函数 `S3` 将使用全局区域。这关闭了 [#10998](https://github.com/ClickHouse/ClickHouse/issues/10998)。 [#19750](https://github.com/ClickHouse/ClickHouse/pull/19750) ([Vladimir Chebotarev](https://github.com/excitoon)).

* `formatReadableTimeDelta` 函数现在可以正确输出无穷大参数。在先前版本中，这里会隐式转换为实现相关的整数值。 [#19791](https://github.com/ClickHouse/ClickHouse/pull/19791) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `S3` 表函数现在支持 `auto` 压缩模式 (自动检测) 。这关闭了 [#18754](https://github.com/ClickHouse/ClickHouse/issues/18754)。 [#19793](https://github.com/ClickHouse/ClickHouse/pull/19793) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 与远程 MySQL 服务器交互时，将字符集设置为 utf8mb4。修复了 [#19795](https://github.com/ClickHouse/ClickHouse/issues/19795)。 [#19800](https://github.com/ClickHouse/ClickHouse/pull/19800) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 `clickhouse-benchmark` 添加了 `--reconnect` 选项。指定此选项后，会在每次请求前重新连接。这是测试所必需的。 [#19872](https://github.com/ClickHouse/ClickHouse/pull/19872) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
