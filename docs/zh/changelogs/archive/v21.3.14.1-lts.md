<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#25851](https://github.com/ClickHouse/ClickHouse/issues/25851) 中回移：从 `Date` 转换为 `DateTime` (或 `DateTime64`) 的 `CAST` 未使用 `DateTime` 类型的时区。这也会影响 `Date` 与 `DateTime` 之间的比较。为 `Date` 和 `DateTime` 推断公共类型时，同样未使用对应的时区。这会影响函数 `if` 和数组构造的结果。关闭了 [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128)。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#25678](https://github.com/ClickHouse/ClickHouse/issues/25678) 中回移：修复了随机生成器状态反序列化中的一个缺陷，该缺陷可能导致某些数据类型 (例如 `AggregateFunction(groupArraySample(N), T))`) 出现非确定性行为。[#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#25637](https://github.com/ClickHouse/ClickHouse/issues/25637) 中回移：修复了 `WITH TOTALS` 和 `WITH FILL` 查询返回的 totals 错误。修复了 [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872)。[#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#25651](https://github.com/ClickHouse/ClickHouse/issues/25651) 中回移：修复了未提供查询时 `EXPLAIN AST` 中的空指针解引用问题。[#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#25716](https://github.com/ClickHouse/ClickHouse/issues/25716) 中回移：在极少数情况下，如果源分区为空，`REPLACE PARTITION` 可能会被忽略；现已修复。修复了 [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869)。[#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#25712](https://github.com/ClickHouse/ClickHouse/issues/25712) 中回移：修复了在数据库之间移动 `Distributed` 表时出现的 `No such file or directory` 错误。修复了 [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971)。[#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
