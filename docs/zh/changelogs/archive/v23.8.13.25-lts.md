<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#62898](https://github.com/ClickHouse/ClickHouse/issues/62898)中回移：修复了零拷贝复制 (一项 Experimental 功能) 中的一个缺陷，该缺陷可能在 REPLACE/MOVE PARTITION 后导致 `The specified key does not exist` 错误和数据丢失。类似问题也可能发生在磁盘之间的 生存时间 (TTL) move 操作中。[#54193](https://github.com/ClickHouse/ClickHouse/pull/54193) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#61964](https://github.com/ClickHouse/ClickHouse/issues/61964)中回移：修复了当发起节点上不存在数据库时，带有 ON CLUSTER 子句的 ATTACH 查询的问题。关闭 [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009)。[#61365](https://github.com/ClickHouse/ClickHouse/pull/61365) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已在 [#62527](https://github.com/ClickHouse/ClickHouse/issues/62527)中回移：修复了 `MOVE PARTITION` 查询与 merges 之间的数据竞争问题，该问题会导致相交的 parts。[#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)) 。
* 已在 [#62238](https://github.com/ClickHouse/ClickHouse/issues/62238)中回移：修复了在使用 `input_format_allow_errors_num/ratio` settings 时，JSON 数据解析过程中会跳过转义序列解析错误的问题。[#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#62673](https://github.com/ClickHouse/ClickHouse/issues/62673)中回移：修复了使用 Hive table engine 时出现的段错误。参见 [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154)、[#62560](https://github.com/ClickHouse/ClickHouse/issues/62560)。[#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)) 。
