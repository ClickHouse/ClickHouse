<div id="clickhouse-release-v209220-stable-fixme-as-compared-to-v20814513-prestable">
  ### ClickHouse 版本 v20.9.2.20-stable FIXME，与 v20.8.1.4513-prestable 相比
</div>

<div id="new-feature">
  #### 新特性
</div>

* 添加了表函数 `view`，可将子查询转换为表对象，从而便于在不同场景中传递查询。例如，它可用于 remote/cluster 表函数中。 [#12567](https://github.com/ClickHouse/ClickHouse/pull/12567) ([Amos Bird](https://github.com/amosbird)).
* 现在可以编写 `select * apply(length) apply(max) from wide_string_table` 来找出所有字符串列的最大长度。此外，还提供了以下两种变体： [#14233](https://github.com/ClickHouse/ClickHouse/pull/14233) ([Amos Bird](https://github.com/amosbird)).
* 添加了聚合函数 RankCorrelationSpearman，用于计算秩相关系数。延续自 [#11769](https://github.com/ClickHouse/ClickHouse/issues/11769)。 [#14411](https://github.com/ClickHouse/ClickHouse/pull/14411) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 添加了通过查询工具生成数据库的功能。延续自 [#10973](https://github.com/ClickHouse/ClickHouse/issues/10973)。 [#14442](https://github.com/ClickHouse/ClickHouse/pull/14442) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 优化带有 GROUP BY sharding&#95;key 的 Distributed 查询中的 LIMIT/LIMIT BY/ORDER BY (在 optimize&#95;skip&#95;unused&#95;shards 和 optimize&#95;distributed&#95;group&#95;by&#95;sharding&#95;key 启用时) 。[#10373](https://github.com/ClickHouse/ClickHouse/pull/10373) ([Azat Khuzhin](https://github.com/azat)) 。

<div id="improvement">
  #### 改进
</div>

* 改进了 StorageRabbitMQ：新增连接和通道故障处理、正确的提交处理、insert 失败处理、改进的 exchange、队列持久化与队列恢复能力，以及新的队列设置。修复了测试。[#12761](https://github.com/ClickHouse/ClickHouse/pull/12761) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 新增 Redis `requirepass` 授权。[#13688](https://github.com/ClickHouse/ClickHouse/pull/13688) ([Ivan Torgashov](https://github.com/it1804)).
* 为 DateTime 类型添加精度参数。[#13761](https://github.com/ClickHouse/ClickHouse/pull/13761) ([Winter Zhang](https://github.com/zhang2014)).
* 通过为每个消费者提供独立线程，提升了 Kafka 引擎的性能。并为流式引擎 (如 Kafka) 提供了独立的线程池。[#13939](https://github.com/ClickHouse/ClickHouse/pull/13939) ([fastio](https://github.com/fastio)).
* 为 `system.part_log` 中的 parts 添加了默认压缩编解码器，名称为 `default_compression_codec`。[#14116](https://github.com/ClickHouse/ClickHouse/pull/14116) ([alesapin](https://github.com/alesapin)).
* 将 boost multiprecision 中的宽整数替换为 [https://github.com/cerevra/int](https://github.com/cerevra/int) 中的实现。[#14229](https://github.com/ClickHouse/ClickHouse/pull/14229) ([Artem Zuikov](https://github.com/4ertus2)).
* 在 MaterializeMySQL 中隐式将主键转换为非 NULL (与 MySQL 相同) 。修复了 [#14114](https://github.com/ClickHouse/ClickHouse/issues/14114)。[#14397](https://github.com/ClickHouse/ClickHouse/pull/14397) ([Winter Zhang](https://github.com/zhang2014)).
* 按照 [#11384](https://github.com/ClickHouse/ClickHouse/issues/11384) 中的提议，新增设置 `system_events_show_zero_values`。[#14404](https://github.com/ClickHouse/ClickHouse/pull/14404) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* 现在 obfuscator 已支持 UUID 类型，正如 [#13163](https://github.com/ClickHouse/ClickHouse/issues/13163) 中所提议的那样。[#14409](https://github.com/ClickHouse/ClickHouse/pull/14409) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* 为多个 `JOIN` 和 `IN` 并行创建 Set。这可能会略微提升包含多个不同 `IN subquery` 表达式的查询性能。[#14412](https://github.com/ClickHouse/ClickHouse/pull/14412) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 现在，如果 TTL 之前尚未 materialized，则会在 merge 期间应用。[#14438](https://github.com/ClickHouse/ClickHouse/pull/14438) ([alesapin](https://github.com/alesapin)).
* 对于 `SET @@var = value` 这类查询，MySQL handler 会返回 `OK`。此类 statement 会被忽略。之所以需要这样做，是因为某些 MySQL driver 会在握手后发送 `SET @@` 查询进行初始化 [#9336](https://github.com/ClickHouse/ClickHouse/issues/9336)#issuecomment-686222422 。[#14469](https://github.com/ClickHouse/ClickHouse/pull/14469) ([BohuTANG](https://github.com/BohuTANG)).
* 禁止在 `toStartOf*` 类函数中使用空的 time&#95;zone argument。[#14509](https://github.com/ClickHouse/ClickHouse/pull/14509) ([Bharat Nallan](https://github.com/bharatnc)).
* ... [#14523](https://github.com/ClickHouse/ClickHouse/pull/14523) ([BohuTANG](https://github.com/BohuTANG)).
* 已在 [#14873](https://github.com/ClickHouse/ClickHouse/issues/14873) 中回移：允许在 Distributed 存储中使用多卷存储配置。[#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).

* 修复了在非全局级别执行 GRANT ALL 语句时的问题。[#13987](https://github.com/ClickHouse/ClickHouse/pull/13987) ([Vitaly Baranov](https://github.com/vitlibar)).

* 改进了 SSD cache complex key external dictionaries 中对 Tuple 大小的检查。修复了 [#13981](https://github.com/ClickHouse/ClickHouse/issues/13981)。[#14313](https://github.com/ClickHouse/ClickHouse/pull/14313) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了带有嵌套解释器的查询中 QueryPlan 的 lifetime 问题 (用于 EXPLAIN PIPELINE graph=1) 。[#14315](https://github.com/ClickHouse/ClickHouse/pull/14315) ([Azat Khuzhin](https://github.com/azat)).
* 修复了执行带有 REFRESH 命令的 ALTER LIVE VIEW 查询时发生的 Exception。[#14320](https://github.com/ClickHouse/ClickHouse/pull/14320) ([Bharat Nallan](https://github.com/bharatnc)).
* 修复了对通过 `AS table_function` 创建的表执行 `ALTER` 查询时发生的 crash。修复了 [#14212](https://github.com/ClickHouse/ClickHouse/issues/14212)。[#14326](https://github.com/ClickHouse/ClickHouse/pull/14326) ([alesapin](https://github.com/alesapin)).
* 如果 `PipelineExecutor` 自身发生 Exception，则停止查询执行。这样可避免极少数情况下查询卡住。[#14334](https://github.com/ClickHouse/ClickHouse/pull/14334) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 如果 `PipelineExecutor` 自身发生 Exception，则停止查询执行。这样可避免极少数情况下查询卡住。此项是 [#14334](https://github.com/ClickHouse/ClickHouse/issues/14334) 的后续修复。[#14402](https://github.com/ClickHouse/ClickHouse/pull/14402) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 修复了在表的某些分区仅包含单个分片时，可能导致 merges assignment 错误的 bug。[#14444](https://github.com/ClickHouse/ClickHouse/pull/14444) ([alesapin](https://github.com/alesapin)).
* 将 SysVinit 的 restart/start/stop/reload 操作代理到 systemd (如果使用的是 systemd) 。[#14460](https://github.com/ClickHouse/ClickHouse/pull/14460) ([Azat Khuzhin](https://github.com/azat)).
* 为 `topK` aggregate function 增加了数组大小 overflow 检查。如果没有此检查，用户可能会发送带有精心构造参数的查询，从而导致 server crash。此项关闭了 [#14452](https://github.com/ClickHouse/ClickHouse/issues/14452)。[#14467](https://github.com/ClickHouse/ClickHouse/pull/14467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
