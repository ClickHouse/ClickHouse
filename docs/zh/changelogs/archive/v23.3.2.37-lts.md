<div id="improvement">
  #### 改进
</div>

* 已在 [#48459](https://github.com/ClickHouse/ClickHouse/issues/48459) 中回移：函数 formatDateTime() 中的格式说明符 &#39;%M&#39; 现在输出月份名称，而不是分钟。这使其行为与 MySQL 保持一致。可以通过设置 &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot; 恢复之前的行为。[#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#48842](https://github.com/ClickHouse/ClickHouse/issues/48842) 中回移：修复了在 mysql 字典源 + 命名集合场景下，某些与 mysql 相关的设置未被处理的问题。关闭 [#48402](https://github.com/ClickHouse/ClickHouse/issues/48402)。[#48759](https://github.com/ClickHouse/ClickHouse/pull/48759) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#49035](https://github.com/ClickHouse/ClickHouse/issues/49035) 中回移：增加了在使用 SSL 用户证书进行身份验证失败时回退到密码身份验证的机制。关闭 [#48974](https://github.com/ClickHouse/ClickHouse/issues/48974)。[#48989](https://github.com/ClickHouse/ClickHouse/pull/48989) ([Nikolay Degterinsky](https://github.com/evillique)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#48589](https://github.com/ClickHouse/ClickHouse/issues/48589) 中回移：更新时区信息。更新了以下时区：Africa/Cairo、Africa/Casablanca、Africa/El&#95;Aaiun、America/Bogota、America/Cambridge&#95;Bay、America/Ciudad&#95;Juarez、America/Godthab、America/Inuvik、America/Iqaluit、America/Nuuk、America/Ojinaga、America/Pangnirtung、America/Rankin&#95;Inlet、America/Resolute、America/Whitehorse、America/Yellowknife、Asia/Gaza、Asia/Hebron、Asia/Kuala&#95;Lumpur、Asia/Singapore、Canada/Yukon、Egypt、Europe/Kirov、Europe/Volgograd、Singapore。[#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#48960](https://github.com/ClickHouse/ClickHouse/issues/48960) 中回移：在最近一次更新后，`dockerd` 现在需要显式指定 http 端口，并同时设置 `--tlsverify=false`。[#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 移除一个功能 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 rabbitmq 中的 CPU 使用率问题 (在 [#44404](https://github.com/ClickHouse/ClickHouse/issues/44404) 之后于 23.2 中恶化)  [#48311](https://github.com/ClickHouse/ClickHouse/pull/48311) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 修复 DistributedSink 的 ThreadPool，并为 CurrentMetrics/ProfileEvents/StatusInfo 使用 StrongTypedef，以避免后续错误 [#48314](https://github.com/ClickHouse/ClickHouse/pull/48314) ([Azat Khuzhin](https://github.com/azat)).
* 在 TemporaryFileStream 中重置 cache File 段的下载器 [#48386](https://github.com/ClickHouse/ClickHouse/pull/48386) ([Vladimir C](https://github.com/vdimir)).
* 修复 ClickHouse 在加载依赖字典的分布式表时启动报错的问题 [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 修复 cache 中可能发生的 segfault [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 修复键为 IP 和 UUID 类型时的嵌套 map 问题 [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 修复 Keeper 中的一个 bug：有时 ACL 中的节点未以 scheme `auth` 创建。 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 修复 IPv4 与 UInt 的比较问题 [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
