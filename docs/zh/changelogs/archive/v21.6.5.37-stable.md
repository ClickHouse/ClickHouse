<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#25480](https://github.com/ClickHouse/ClickHouse/issues/25480) 中回移：修复对 Distributed materialized view 执行 join 时出现的 &quot;Missing columns&quot; 异常。[#24870](https://github.com/ClickHouse/ClickHouse/pull/24870) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#25366](https://github.com/ClickHouse/ClickHouse/issues/25366) 中回移：修复 Protobuf format 中拆分后的嵌套消息的序列化问题。此 PR 修复了 [#24647](https://github.com/ClickHouse/ClickHouse/issues/24647)。[#25000](https://github.com/ClickHouse/ClickHouse/pull/25000) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#25102](https://github.com/ClickHouse/ClickHouse/issues/25102) 中回移：区分不同表的 KILL MUTATION (修复异常的 `Cancelled mutating parts` 错误) 。[#25025](https://github.com/ClickHouse/ClickHouse/pull/25025) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#25213](https://github.com/ClickHouse/ClickHouse/issues/25213) 中回移：修复使用 CSVWithNames format 插入部分列时发生的错误。修复了 [#25129](https://github.com/ClickHouse/ClickHouse/issues/25129)。[#25169](https://github.com/ClickHouse/ClickHouse/pull/25169) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#25352](https://github.com/ClickHouse/ClickHouse/issues/25352) 中回移：修复安装脚本中的 TOCTOU 错误。[#25277](https://github.com/ClickHouse/ClickHouse/pull/25277) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#25385](https://github.com/ClickHouse/ClickHouse/issues/25385) 中回移：修复大整数中的错误行为和 UBSan 报告。在之前的版本中，`CAST(1e19 AS UInt128)` 会返回零。[#25279](https://github.com/ClickHouse/ClickHouse/pull/25279) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#25470](https://github.com/ClickHouse/ClickHouse/issues/25470) 中回移：修复 joinGetOrNull 在非 Nullable 列上的问题。此修复解决了 [#24261](https://github.com/ClickHouse/ClickHouse/issues/24261)。[#25288](https://github.com/ClickHouse/ClickHouse/pull/25288) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#25360](https://github.com/ClickHouse/ClickHouse/issues/25360) 中回移：修复在查询中将 `LowCardinality` argument 用于 IN 时出现的错误 `Bad cast from type DB::ColumnLowCardinality to DB::ColumnVector<char8_t>` (该 bug 出现在 21.6 中) 。修复了 [#25187](https://github.com/ClickHouse/ClickHouse/issues/25187)。[#25290](https://github.com/ClickHouse/ClickHouse/pull/25290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#25356](https://github.com/ClickHouse/ClickHouse/issues/25356) 中回移：修复 min/maxMap 中的逻辑错误 Cannot sum Array/Tuple。[#25298](https://github.com/ClickHouse/ClickHouse/pull/25298) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#25436](https://github.com/ClickHouse/ClickHouse/issues/25436) 中回移：为 `SummingMergeTree` 支持 `SimpleAggregateFunction(LowCardinality)`。修复了 [#25134](https://github.com/ClickHouse/ClickHouse/issues/25134)。[#25300](https://github.com/ClickHouse/ClickHouse/pull/25300) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#25363](https://github.com/ClickHouse/ClickHouse/issues/25363) 中回移：在 ZooKeeper 连接丢失时，`ReplicatedMergeTree` 表可能会在尝试重新连接前等待后台操作完成。现已修复，现在后台操作会被强制停止。[#25306](https://github.com/ClickHouse/ClickHouse/pull/25306) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#25388](https://github.com/ClickHouse/ClickHouse/issues/25388) 中回移：修复了 `quantileDeterministic` 函数及类似函数可能出现非确定性行为的问题。该修复关闭了 [#20480](https://github.com/ClickHouse/ClickHouse/issues/20480)。[#25313](https://github.com/ClickHouse/ClickHouse/pull/25313) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#25448](https://github.com/ClickHouse/ClickHouse/issues/25448) 中回移：修复了查询计划的表达式下推优化中 `WHERE` 条件丢失的问题 (默认将 `query_plan_filter_push_down = 1`) 。修复了 [#25368](https://github.com/ClickHouse/ClickHouse/issues/25368)。[#25370](https://github.com/ClickHouse/ClickHouse/pull/25370) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#25407](https://github.com/ClickHouse/ClickHouse/issues/25407) 中回移：修复了在 DDL 中使用 `REPLACE` 列转换器时的问题，方法是为格式化后的查询正确添加引号。该修复解决了 [#23925](https://github.com/ClickHouse/ClickHouse/issues/23925)。[#25391](https://github.com/ClickHouse/ClickHouse/pull/25391) ([Amos Bird](https://github.com/amosbird)).
