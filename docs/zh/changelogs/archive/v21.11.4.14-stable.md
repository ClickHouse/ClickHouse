<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#31282](https://github.com/ClickHouse/ClickHouse/issues/31282) 中回移：修复了 intersect/except 的一些边界情况问题。关闭 [#30803](https://github.com/ClickHouse/ClickHouse/issues/30803)。[#30965](https://github.com/ClickHouse/ClickHouse/pull/30965) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#31237](https://github.com/ClickHouse/ClickHouse/issues/31237) 中回移：修复了一个 bug，即在删除 materialized view 后执行 select 查询时会出错。发现于 [#30691](https://github.com/ClickHouse/ClickHouse/issues/30691)。[#30997](https://github.com/ClickHouse/ClickHouse/pull/30997) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#31374](https://github.com/ClickHouse/ClickHouse/issues/31374) 中回移：修复了 StorageMerge 在使用别名和 where 时的问题 (此前完全无法使用) 。关闭 [#28802](https://github.com/ClickHouse/ClickHouse/issues/28802)。[#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#31236](https://github.com/ClickHouse/ClickHouse/issues/31236) 中回移：修复了 Keeper 中的一个 bug：当部分协调日志丢失，且现有 snapshot 比最新日志更新时，可能会导致无法启动。[#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#31435](https://github.com/ClickHouse/ClickHouse/issues/31435) 中回移：修复了 group by 和位置参数相关的 bug。关闭 [#31280](https://github.com/ClickHouse/ClickHouse/issues/31280)#issuecomment-968696186。[#31420](https://github.com/ClickHouse/ClickHouse/pull/31420) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
