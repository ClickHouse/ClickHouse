  ### ClickHouse 版本发布 v20.8.6.6-长期支持版 FIXME (相比 v20.8.5.45-长期支持版)
</div>

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#16494](https://github.com/ClickHouse/ClickHouse/issues/16494) 中回移：修复了 MySQL database 的一个缺陷。当用作 database engine 的 MySQL 服务器不可用时，某些查询会抛出 Exception，因为它们会尝试从已禁用的 server 获取表，但这其实并不必要。例如，查询 `SELECT ... FROM system.parts` 应当只对 MergeTree tables 生效，完全不应访问 MySQL database。[#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#16816](https://github.com/ClickHouse/ClickHouse/issues/16816) 中回移：修复了行为不一致的问题，即当用于过滤的数据集未创建时，返回的数据可能有一部分会被丢弃。[#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#16506](https://github.com/ClickHouse/ClickHouse/issues/16506) 中回移：修复了 replication queue 中超大 entries 的处理问题。如果表结构非常大 (接近 1 MB) ，这些超大 entries 可能会出现在 ALTER 查询中。此修复解决了 [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307)。[#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#16472](https://github.com/ClickHouse/ClickHouse/issues/16472) 中回移：修复了 Distributed 的 DROP TABLE 问题 (与 INSERT 存在竞争条件) 。[#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#16573](https://github.com/ClickHouse/ClickHouse/issues/16573) 中回移：通过正确收缩 GTID sets，修复了在使用 MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine，且 MySQL Slave 启用了 `slave_parallel_worker` 时 metadata 快速增长的问题。此修复解决了 [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951)。[#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* 已在 [#16552](https://github.com/ClickHouse/ClickHouse/issues/16552) 中回移：现在从输入中解析 AVRO 时，会从类型中移除 LowCardinality。修复了 [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188)。[#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* 已在 [#16823](https://github.com/ClickHouse/ClickHouse/issues/16823) 中回移：修复了 [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081)。[#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#16892](https://github.com/ClickHouse/ClickHouse/issues/16892) 中回移：修复了一种罕见的静默崩溃问题：当 query profiler 开启，且 ClickHouse 安装在使用某个 glibc 版本的操作系统上时，由于该版本 (推测) 对某些函数的 asynchronous unwind tables 存在缺陷，可能会触发此问题。此修复解决了 [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301)。此修复也解决了 [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098)。[#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
