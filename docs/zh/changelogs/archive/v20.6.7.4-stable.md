  ### ClickHouse 版本 v20.6.7.4-稳定版本 FIXME，相较于 v20.6.6.7-稳定版本

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#14726](https://github.com/ClickHouse/ClickHouse/issues/14726) 中回移：修复了在 StorageReplicatedMergeTree 引擎执行 CreateQuery 期间发生 ZooKeeper 异常后，数据目录未被清理的问题。[#14563](https://github.com/ClickHouse/ClickHouse/pull/14563) ([Bharat Nallan](https://github.com/bharatnc)).
* 已在 [#14805](https://github.com/ClickHouse/ClickHouse/issues/14805) 中回移：修复了 `ALTER UPDATE` 变更在赋值表达式中使用 Nullable 列和常量值 (如 `UPDATE x = 42`) 时，可能导致列值错误或触发 segfault 的缺陷。修复了 [#13634](https://github.com/ClickHouse/ClickHouse/issues/13634)、[#14045](https://github.com/ClickHouse/ClickHouse/issues/14045)。[#14646](https://github.com/ClickHouse/ClickHouse/pull/14646) ([alesapin](https://github.com/alesapin)).
* 已在 [#14723](https://github.com/ClickHouse/ClickHouse/issues/14723) 中回移：修复了执行 `ALTER ... MODIFY QUERY` 时，materialized view 的元数据中缺失 default database 名称的问题。[#14664](https://github.com/ClickHouse/ClickHouse/pull/14664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#14913](https://github.com/ClickHouse/ClickHouse/issues/14913) 中回移：修复了尝试向 StorageFile(fd) 执行 INSERT 时出现的 SIGSEGV。[#14887](https://github.com/ClickHouse/ClickHouse/pull/14887) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#14945](https://github.com/ClickHouse/ClickHouse/issues/14945) 中回移：修复了某些对 `extractAllGroups` 函数的调用可能触发 “Memory limit exceeded” 错误的问题。此修复解决了 [#13383](https://github.com/ClickHouse/ClickHouse/issues/13383)。[#14889](https://github.com/ClickHouse/ClickHouse/pull/14889) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
