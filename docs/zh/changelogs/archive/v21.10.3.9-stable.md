<div id="improvement">
  #### 改进
</div>

* 已回移至 [#30453](https://github.com/ClickHouse/ClickHouse/issues/30453)：允许 file 表函数使用指向 user&#95;files 目录中文件的符号链接。[#30309](https://github.com/ClickHouse/ClickHouse/pull/30309) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已回移至 [#30635](https://github.com/ClickHouse/ClickHouse/issues/30635)：更完整地支持位置参数。[#30433](https://github.com/ClickHouse/ClickHouse/pull/30433) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix">
  #### 缺陷修复

* 已在 [#31369](https://github.com/ClickHouse/ClickHouse/issues/31369) 中回移：修复了使用部分撤销授权时 SHOW GRANTS 的问题。此 PR 修复了 [#31138](https://github.com/ClickHouse/ClickHouse/issues/31138)。[#31249](https://github.com/ClickHouse/ClickHouse/pull/31249) ([Vitaly Baranov](https://github.com/vitlibar)).

* 在 [#30766](https://github.com/ClickHouse/ClickHouse/issues/30766) 中回移：修复在添加新副本时，Replicated database 上的 DDL 查询发生挂起的问题。[#29328](https://github.com/ClickHouse/ClickHouse/pull/29328) ([Kevin Michel](https://github.com/kmichel-aiven)) 。
* 在 [#30504](https://github.com/ClickHouse/ClickHouse/issues/30504) 中回移：修复 server 重启时设置 `materialized_postgresql_tables_list` 的错误行为。问题发现于 [#28529](https://github.com/ClickHouse/ClickHouse/issues/28529)。[#29686](https://github.com/ClickHouse/ClickHouse/pull/29686) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 在 [#30137](https://github.com/ClickHouse/ClickHouse/issues/30137) 中回移：修复包含 `GLOBAL IN` 和 `WITH TOTALS` 的查询出现 `Port is already connected` 错误的问题。仅适用于 21.9 和 21.10。[#30086](https://github.com/ClickHouse/ClickHouse/pull/30086) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 在 [#30465](https://github.com/ClickHouse/ClickHouse/issues/30465) 中回移：支持函数 `initializeAggregation` 的 Nullable arguments。[#30177](https://github.com/ClickHouse/ClickHouse/pull/30177) ([Anton Popov](https://github.com/CurtizJ)) 。
* 在 [#30353](https://github.com/ClickHouse/ClickHouse/issues/30353) 中回移：修复 `pread_fake_async`/`pread_threadpool` 与 `min_bytes_to_use_direct_io` 配合使用时的问题。[#30191](https://github.com/ClickHouse/ClickHouse/pull/30191) ([Azat Khuzhin](https://github.com/azat)) 。
* 在 [#30334](https://github.com/ClickHouse/ClickHouse/issues/30334) 中回移：* 允许在多个 joins 中使用以数字开头的标识符。[#30230](https://github.com/ClickHouse/ClickHouse/pull/30230) ([Vladimir C](https://github.com/vdimir)) 。
* 在 [#30654](https://github.com/ClickHouse/ClickHouse/issues/30654) 中回移：修复 `[I]LIKE` 函数。关闭 [#28661](https://github.com/ClickHouse/ClickHouse/issues/28661)。[#30244](https://github.com/ClickHouse/ClickHouse/pull/30244) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 在 [#30378](https://github.com/ClickHouse/ClickHouse/issues/30378) 中回移：修复 replaceRegexpAll 的 bug。[#30292](https://github.com/ClickHouse/ClickHouse/pull/30292) ([Memo](https://github.com/Joeywzr)) 。
* 在 [#30526](https://github.com/ClickHouse/ClickHouse/issues/30526) 中回移：修复执行 REPLACE PARTITION 期间 session 过期时可能发生的 segfault。[#30432](https://github.com/ClickHouse/ClickHouse/pull/30432) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 在 [#30587](https://github.com/ClickHouse/ClickHouse/issues/30587) 中回移：* 修复对同一张表执行带有 scalar subquery 的 ALTER 时发生的死锁问题，关闭 [#30461](https://github.com/ClickHouse/ClickHouse/issues/30461)。[#30492](https://github.com/ClickHouse/ClickHouse/pull/30492) ([Vladimir C](https://github.com/vdimir)) 。
* 在 [#30608](https://github.com/ClickHouse/ClickHouse/issues/30608) 中回移：Limit push down 优化可能导致 `Cannot find column` 错误。修复了 [#30438](https://github.com/ClickHouse/ClickHouse/issues/30438)。[#30562](https://github.com/ClickHouse/ClickHouse/pull/30562) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#30747](https://github.com/ClickHouse/ClickHouse/issues/30747) 中回移：更新 aws-sdk 子模块，以修复 Yandex.S3 中的限流问题。 [#30646](https://github.com/ClickHouse/ClickHouse/pull/30646) ([ianton-ru](https://github.com/ianton-ru)).
* 已在 [#30751](https://github.com/ClickHouse/ClickHouse/issues/30751) 中回移：在 UTF8 字符串中执行不区分大小写搜索的函数 (如 `positionCaseInsensitiveUTF8` 和 `countSubstringsCaseInsensitiveUTF8`) 可能会找到实际上并不匹配的子字符串；该问题已修复。 [#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#30709](https://github.com/ClickHouse/ClickHouse/issues/30709) 中回移：修复 PREWHERE 始终为 true 时 PREWHERE 与 WHERE 一起使用的问题。 [#30668](https://github.com/ClickHouse/ClickHouse/pull/30668) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#30771](https://github.com/ClickHouse/ClickHouse/issues/30771) 中回移：修复了非复制表 `MergeTree` 中 `REPLACE/MOVE PARTITION` 与后台合并之间的一个竞态条件，该问题可能导致被移动或替换的数据仍有一部分留在分区中。修复了 [#29327](https://github.com/ClickHouse/ClickHouse/issues/29327)。 [#30717](https://github.com/ClickHouse/ClickHouse/pull/30717) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#30859](https://github.com/ClickHouse/ClickHouse/issues/30859) 中回移：修复了在 `ReplicatedMergeTree` 中从 ZooKeeper 路径提取辅助 ZooKeeper 名称时的歧义问题。此前，如果 ZooKeeper 路径中包含冒号，服务器可能会因 `Unknown auxiliary ZooKeeper name` 而启动失败。修复了 [#29052](https://github.com/ClickHouse/ClickHouse/issues/29052)。另外，之前允许指定不以斜杠开头的 ZooKeeper 路径，但现在这已弃用，并且不再允许使用此类路径创建新表。辅助 ZooKeeper 名称中同样不允许包含斜杠和冒号。 [#30822](https://github.com/ClickHouse/ClickHouse/pull/30822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#30926](https://github.com/ClickHouse/ClickHouse/issues/30926) 中回移：修复了当操作数超过两个时，Set 索引在 AND/OR 表达式中未被使用的问题。这修复了 [#30416](https://github.com/ClickHouse/ClickHouse/issues/30416)。 [#30887](https://github.com/ClickHouse/ClickHouse/pull/30887) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#31289](https://github.com/ClickHouse/ClickHouse/issues/31289) 中回移：修复了 intersect/except 的一些边界情况。关闭了 [#30803](https://github.com/ClickHouse/ClickHouse/issues/30803)。 [#30965](https://github.com/ClickHouse/ClickHouse/pull/30965) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#31152](https://github.com/ClickHouse/ClickHouse/issues/31152) 中回移：在 ATTACH PARTITION ... FROM 和 MOVE PARTITION ... 场景下，跳过 max&#95;partition&#95;size&#95;to&#95;drop 检查。 [#30995](https://github.com/ClickHouse/ClickHouse/pull/30995) ([Amr Alaa](https://github.com/amralaa-MSFT)).
* 已在 [#31041](https://github.com/ClickHouse/ClickHouse/issues/31041) 中回移：将 `formatRow` 函数用于非行 format 会导致 segfault。现在已禁止将此函数用于这类 format (因为这没有意义) 。 [#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#31203](https://github.com/ClickHouse/ClickHouse/issues/31203) 中回移：通过额外检查 hdfs URL 结构，修复了在 hdfs URL 错误时，调试版服务器中的 abort，以及发布版服务器中的 `DB::Exception: std::out_of_range: basic_string` 错误。[#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#31373](https://github.com/ClickHouse/ClickHouse/issues/31373) 中回移：修复了 StorageMerge 在使用别名和 where 时的问题 (此前完全无法工作) 。关闭 [#28802](https://github.com/ClickHouse/ClickHouse/issues/28802)。[#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#31255](https://github.com/ClickHouse/ClickHouse/issues/31255) 中回移：修复了 Keeper 中的一个 bug；当部分协调日志丢失，且最新快照比最新日志更新时，可能会导致无法启动。[#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#31436](https://github.com/ClickHouse/ClickHouse/issues/31436) 中回移：修复了 group by 和位置参数相关的问题。关闭 [#31280](https://github.com/ClickHouse/ClickHouse/issues/31280)#issuecomment-968696186。[#31420](https://github.com/ClickHouse/ClickHouse/pull/31420) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
