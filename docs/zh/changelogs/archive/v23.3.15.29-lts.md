<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#55671](https://github.com/ClickHouse/ClickHouse/issues/55671) 中回移：如果数据库已经初始化，后续启动时就无需再次初始化。这可能会修复数据库在 1000 次尝试内未能加载时导致容器无限重启的问题 (与超大数据库和多节点部署相关) 。[#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)) 。
* 已在 [#55734](https://github.com/ClickHouse/ClickHouse/issues/55734) 中回移：修复集成检查 Python 脚本，使其使用 gh API URL；为 CI 测试添加 README。[#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)) 。
* 已在 [#55829](https://github.com/ClickHouse/ClickHouse/issues/55829) 中回移：检查 tgz 的 sha512；为 Keeper 使用合适的仓库；对于 tarball 包，仅将文件名写入 TGZ.sha512 文件。[#31473](https://github.com/ClickHouse/ClickHouse/issues/31473) 的前置条件。[#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

* 修复了在基于 S3 且未启用零拷贝的 replicated merge tree 中，无法删除 detached 分区的问题 [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* 修复了 QueryNormalizer 在存在循环别名时崩溃的问题 [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* 修复了稀疏列场景下窗口函数的问题。 [#55895](https://github.com/ClickHouse/ClickHouse/pull/55895) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
