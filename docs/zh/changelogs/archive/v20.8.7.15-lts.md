  ### ClickHouse 发布版本 v20.8.7.15-长期支持版 FIXME，对比 v20.8.6.6-长期支持版
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#17029](https://github.com/ClickHouse/ClickHouse/issues/17029) 中回移：支持连接到需要 SNI 的 `clickhouse-server` 安全端点。当 `clickhouse-server` 位于 TLS 代理后方时，可使用此功能。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#15676](https://github.com/ClickHouse/ClickHouse/issues/15676) 中回移：发生异常时，查询会更快结束；如果出现异常，会取消远程副本上的执行。[#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#17106](https://github.com/ClickHouse/ClickHouse/issues/17106) 中回移：修复 [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) 和 [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231)，解决使用带有 &#39;if&#39; 后缀的聚合函数时远程查询失败的问题。[#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* 已在 [#16761](https://github.com/ClickHouse/ClickHouse/issues/16761) 中回移：修复在 max&#95;threads&gt;0 且 ORDER BY 中包含表达式时，optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order 的问题。[#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#16738](https://github.com/ClickHouse/ClickHouse/issues/16738) 中回移：修复启用 `transform_null_in` 设置时，多列和 Tuple 上的 `IN` operator 问题。修复了 [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310)。[#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#17021](https://github.com/ClickHouse/ClickHouse/issues/17021) 中回移：修复不带任何参数使用 `any` 时发生崩溃的问题。此项对应 [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803)。cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#16880](https://github.com/ClickHouse/ClickHouse/issues/16880) 中回移：如果没有数据写入 WriteBufferFromS3，则中止分段上传。[#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* 已在 [#16950](https://github.com/ClickHouse/ClickHouse/issues/16950) 中回移：防止使用 TimeSeriesGroupSum 时 ClickHouse server 崩溃。[#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* 已在 [#17077](https://github.com/ClickHouse/ClickHouse/issues/17077) 中回移：修复带有 `ORDER BY` 的查询可能出现 `Illegal type of argument` 错误的问题。修复了 [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580)。[#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#17007](https://github.com/ClickHouse/ClickHouse/issues/17007) 中回移：安装脚本应始终在 config 文件夹中创建子目录。这仅与使用自定义配置的 Docker build 相关。[#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* 已在 [#17011](https://github.com/ClickHouse/ClickHouse/issues/17011) 中回移：修复执行 `ALTER TABLE ... MODIFY COLUMN ... NewType` 后可能发生的 server 崩溃问题：当 `SELECT` 对正在修改的列包含 `WHERE` 表达式，且 alter 尚未完成时，就可能触发该问题。[#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#17040](https://github.com/ClickHouse/ClickHouse/issues/17040) 中回移：出错时重新解析 `format_avro_schema_registry_url` 的 IP。[#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* 已在 [#17171](https://github.com/ClickHouse/ClickHouse/issues/17171) 中回移：修复了一个 bug：对于非 leader 的 ReplicatedMergeTreeTables，`ON CLUSTER` 查询可能会一直挂起。[#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
