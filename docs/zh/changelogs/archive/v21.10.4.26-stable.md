* 已在 [#31745](https://github.com/ClickHouse/ClickHouse/issues/31745) 中回移：修复了 `RENAME TABLE` 查询在尝试重命名 `Ordinary` database 中的 DDL 字典时行为不正确的问题。[#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).

* 已在 [#31830](https://github.com/ClickHouse/ClickHouse/issues/31830) 中回移：修复了执行 `ON CLUSTER` 查询时，如果指定的 cluster 名称正好是 `Replicated` database 的名称，就会报出 `there are no such cluster here` 错误的问题。[#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#31815](https://github.com/ClickHouse/ClickHouse/issues/31815) 中回移：修复了 JSONEachRowWithProgress output format 中的竞争问题，该问题会在输出里混合数据和进度行时出现。[#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#32016](https://github.com/ClickHouse/ClickHouse/issues/32016) 中回移：修复了启用 positional arguments 时 group by / order by / limit by 的别名问题。关闭了 [#31173](https://github.com/ClickHouse/ClickHouse/issues/31173)。[#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#31762](https://github.com/ClickHouse/ClickHouse/issues/31762) 中回移：修复了 `Buffer` 表引擎与 `Map` 类型配合使用时的问题。修复了 [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546)。[#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#31892](https://github.com/ClickHouse/ClickHouse/issues/31892) 中回移：修复了 TSKV format 中可能出现的断言 `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.`。[#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#32031](https://github.com/ClickHouse/ClickHouse/issues/32031) 中回移：修复了使用 Nullable 主键时对 Nullable 类型进行无效 CAST 的问题。这修复了 [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075)。[#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird)).

* 已在 [#31909](https://github.com/ClickHouse/ClickHouse/issues/31909) 中回移：修复了函数 `empty` 和 `notEmpty` 在参数为 `UUID` 类型时的问题。修复 [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819)。[#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)) 。
