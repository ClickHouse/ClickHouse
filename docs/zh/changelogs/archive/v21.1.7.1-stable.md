<div id="bug-fix">
  #### 缺陷修复
</div>

* 回移至 [#21261](https://github.com/ClickHouse/ClickHouse/issues/21261)：修复在 Replicated(*)MergeTree 引擎需要指定其他参数时，default&#95;replica&#95;path 和 default&#95;replica&#95;name 配置值不起作用的问题。[#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy))。
* 回移至 [#21155](https://github.com/ClickHouse/ClickHouse/issues/21155)：修复与将 Tuple 转换为 Map 相关的缺陷。关闭 [#21029](https://github.com/ClickHouse/ClickHouse/issues/21029)。[#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting))。
* 回移至 [#21233](https://github.com/ClickHouse/ClickHouse/issues/21233)：现在只有支持变更操作的表引擎才允许执行变更操作 (MergeTree 家族、Memory、MaterializedView) 。其他引擎将报出更清晰的错误。修复 [#21168](https://github.com/ClickHouse/ClickHouse/issues/21168)。[#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin))。
* 回移至 [#21428](https://github.com/ClickHouse/ClickHouse/issues/21428)：修复包含 `UNION` 的查询在 `EXPLAIN` 中崩溃的问题。修复 [#20876](https://github.com/ClickHouse/ClickHouse/issues/20876)、[#21170](https://github.com/ClickHouse/ClickHouse/issues/21170)。[#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl))。
* 回移至 [#21408](https://github.com/ClickHouse/ClickHouse/issues/21408)：修复对 ZooKeeper 的冗余重连，以及单个 ClickHouse server 出现两个活动会话的可能性。这两个问题均在 [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678) 中引入。[#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin))。
* 回移至 [#21549](https://github.com/ClickHouse/ClickHouse/issues/21549)：现在 `ALTER MODIFY COLUMN` 查询将正确作用于分区键、数据跳过索引、生存时间 (TTL) 等的变更。修复 [#13675](https://github.com/ClickHouse/ClickHouse/issues/13675)。[#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin))。
* 回移至 [#21377](https://github.com/ClickHouse/ClickHouse/issues/21377)：修复从 `Values` 格式向包含 `LowCardinality` 列的表插入数据时出现的错误 `Bad cast from type ... to DB::ColumnLowCardinality`。修复 [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140)。[#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
