  #### 缺陷修复 (正式稳定版本中用户可见的异常表现)

* 已在 [#45904](https://github.com/ClickHouse/ClickHouse/issues/45904) 中回移：修复了表元数据中 `EPHEMERAL` 列默认值无法解析的问题。[#44026](https://github.com/ClickHouse/ClickHouse/pull/44026) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#45321](https://github.com/ClickHouse/ClickHouse/issues/45321) 中回移：修复了 `CREATE TABLE` 语句中 `DEFAULT` 表达式归一化的一个 bug。在执行 CREATE 查询期间，函数 `in` 的第二个参数 (或运算符 `IN` 的右参数) 可能会被替换为其求值结果。修复了 [#44496](https://github.com/ClickHouse/ClickHouse/issues/44496)。[#44547](https://github.com/ClickHouse/ClickHouse/pull/44547) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#45000](https://github.com/ClickHouse/ClickHouse/issues/45000) 中回移：进一步修复了从远程文件系统读取 `LowCardinality` 字典时可能出现的 `Cannot read all data` 错误。修复了 [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709)。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#45553](https://github.com/ClickHouse/ClickHouse/issues/45553) 中回移：修复了当存在结构有误的字典时 (例如 xml config 中类型不正确) ，执行 `SELECT ... FROM system.dictionaries` 会抛出异常的问题。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 已在 [#46226](https://github.com/ClickHouse/ClickHouse/issues/46226) 中回移：`c-ares` 相关场景中已报告了几起段错误。最近观察到的所有堆栈跟踪都显示在向 `std::unodered_set<>` 插入时失败。我认为已经找到了根本原因，看起来与未处理完的查询有关。在此 PR 之前，CH 会调用 `poll` 来等待 `c-ares` 通道中的文件描述符。根据 [poll 文档](https://man7.org/linux/man-pages/man2/poll.2.html)，返回负值表示发生了错误。因此，我们会中止执行并返回失败。问题在于，发生系统中断时 `poll` 也会返回负值。系统中断并不意味着处理失败或结束，但由于只检查返回值是否为负，我们仍会中止执行。一旦执行被中止，整个调用栈都会被销毁，其中包括传递给 c-ares 回调 `void *` 参数的 `std::unordered_set<std::string>`。当 c-ares 完成请求后，会调用该回调，而它会访问无效的内存地址，从而导致段错误。[#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos)).
* 已在 [#46218](https://github.com/ClickHouse/ClickHouse/issues/46218) 中回移：修复了在 compact parts 中读取多级不存在的嵌套列的问题。[#46045](https://github.com/ClickHouse/ClickHouse/pull/46045) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#46446](https://github.com/ClickHouse/ClickHouse/issues/46446) 中回移：修复了在异步插入中发送 `VALUES` 格式的无效数据时可能出现的 `LOGICAL_ERROR`。[#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#46678](https://github.com/ClickHouse/ClickHouse/issues/46678) 中回移：修复了函数 `arrayMap` 中常量 `LowCardinality` 参数处理不正确的问题。此 bug 在 release 版本中可能导致段错误，在 debug build 中可能导致 `Bad cast` 逻辑错误。[#46569](https://github.com/ClickHouse/ClickHouse/pull/46569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#46872](https://github.com/ClickHouse/ClickHouse/issues/46872) 中回移：修复 `Map` 数据类型中的一个 bug。此更改关闭了 [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855)。[#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#46954](https://github.com/ClickHouse/ClickHouse/issues/46954) 中回移：修复 LIKE 谓词在被转换为子串搜索且包含带引号的非 LIKE 元字符时的结果错误。[#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)) 。
