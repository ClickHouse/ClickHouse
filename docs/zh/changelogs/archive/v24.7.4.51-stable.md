<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#68232](https://github.com/ClickHouse/ClickHouse/issues/68232) 中回移：修复了在某些系统表中使用子查询进行过滤时出现的 `Not-ready Set` 问题。[#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#68068](https://github.com/ClickHouse/ClickHouse/issues/68068) 中回移：修复了发送到外部数据库的查询中布尔字面量的问题 (适用于 `PostgreSQL` 等引擎) 。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* 已在 [#68613](https://github.com/ClickHouse/ClickHouse/issues/68613) 中回移：修复了 [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)。避免在 `ReplaceTableNodeToDummyVisitor` 中遍历未解析的表函数参数。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#68278](https://github.com/ClickHouse/ClickHouse/issues/68278) 中回移：修复了通过 HTTP 接口向 stream 类引擎 (Kafka、RabbitMQ、NATS) 插入数据时的问题。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#68040](https://github.com/ClickHouse/ClickHouse/issues/68040) 中回移：修复了使用递归 CTE 创建视图时的问题。[#67587](https://github.com/ClickHouse/ClickHouse/pull/67587) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#68038](https://github.com/ClickHouse/ClickHouse/issues/68038) 中回移：修复了 `percent_rank` 导致的崩溃问题。`percent_rank` 的默认窗口帧类型已改为 `range unbounded preceding and unbounded following`。现在会考虑 `IWindowFunction` 的默认窗口帧，因此 SQL 中未定义窗口帧的 window functions 也能被正确放入不同的 `WindowTransfomer` 中。[#67661](https://github.com/ClickHouse/ClickHouse/pull/67661) ([lgbo](https://github.com/lgbo-ustc)).
* 已在 [#68224](https://github.com/ClickHouse/ClickHouse/issues/68224) 中回移：修复了当 predicate 中存在 non-deterministic function 时 `count()` 结果错误的问题。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#68095](https://github.com/ClickHouse/ClickHouse/issues/68095) 中回移：修复了在可用 CPU 数量受限的容器化环境中，最大线程 soft limit 的计算错误。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* 已在 [#68126](https://github.com/ClickHouse/ClickHouse/issues/68126) 中回移：修复了在新 analyzer 下，变更操作会跳过未受影响 parts 的问题。此前在启用 analyzer 时，即使根据 predicate 该变更并不影响此 part，part 中的数据也可能被变更重写。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#68223](https://github.com/ClickHouse/ClickHouse/issues/68223) 中回移：修复了一个由精心构造的查询触发的 NULL 指针解引用问题，该问题可通过 hopEnd、hopStart、tumbleEnd 和 tumbleStart 导致服务器崩溃。[#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* 已在 [#68175](https://github.com/ClickHouse/ClickHouse/issues/68175) 中回移：移除了一个错误的优化，该优化会去掉使用 `OFFSET` 的子查询中的排序。修复了 [#67906](https://github.com/ClickHouse/ClickHouse/issues/67906)。[#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)).
* 在 [#68341](https://github.com/ClickHouse/ClickHouse/issues/68341) 中回移：尝试修复取消查询时 Postgres 崩溃的问题。[#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 在 [#68398](https://github.com/ClickHouse/ClickHouse/issues/68398) 中回移：修复查询 `SYSTEM SYNC REPLICA` 缺少同步副本模式的问题。[#68326](https://github.com/ClickHouse/ClickHouse/pull/68326) ([Duc Canh Le](https://github.com/canhld94)) 。
* 在 [#68669](https://github.com/ClickHouse/ClickHouse/issues/68669) 中回移：修复对空数组或元组应用函数 `sipHash64Keyed`、`sipHash128Keyed` 或 `sipHash128ReferenceKeyed` 时出现的 `LOGICAL_ERROR`。[#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)) 。
