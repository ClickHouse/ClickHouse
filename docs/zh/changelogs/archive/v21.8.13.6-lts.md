<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#32688](https://github.com/ClickHouse/ClickHouse/issues/32688) 中回移：尚未达到配额限制，却被判定为超限。此 PR 修复了 [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174)。[#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).
* 已在 [#32343](https://github.com/ClickHouse/ClickHouse/issues/32343) 中回移：修复移除子查询中不需要的列时出现的缺陷。如果查询中存在不带 Group By 的聚合函数，即使它看起来不需要，也不要将其移除。[#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

#### 缺陷修复 (官方稳定版本中用户可见的异常行为)

* 已在 [#32108](https://github.com/ClickHouse/ClickHouse/issues/32108) 中回移：修复 odbc 查询返回空结果时崩溃的问题。关闭 [#31465](https://github.com/ClickHouse/ClickHouse/issues/31465)。[#31766](https://github.com/ClickHouse/ClickHouse/pull/31766) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#32150](https://github.com/ClickHouse/ClickHouse/issues/32150) 中回移：修复将类型参数用于字典 attribute 且该类型为 `Nullable` 时，函数 `dictGet` 发生崩溃的问题。修复 [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#32075](https://github.com/ClickHouse/ClickHouse/issues/32075) 中回移：修复函数 transform 使用 decimal 参数时的一个 bug。[#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* 已在 [#31955](https://github.com/ClickHouse/ClickHouse/issues/31955) 中回移：- 构造 `KeeperTCPHandler` 时，将 config 路径从 `keeper_server.session_timeout_ms` 更改为 `keeper_server.coordination_settings.session_timeout_ms` - `operation_timeout` 同样如此。[#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* 已在 [#32161](https://github.com/ClickHouse/ClickHouse/issues/32161) 中回移：如果某个 parts 在所有副本上都已丢失，且同一分区中没有其他 parts，则某些 `GET_PART` entry 可能会卡在 replication queue 中。现已修复此问题，但仅限于 partition key 只包含整数 types 或 `Date[Time]` 列的情况。修复 [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485)。[#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32146](https://github.com/ClickHouse/ClickHouse/issues/32146) 中回移：修复 detach 分片时出现 `Directory ... already exists and is not empty` error 的问题。[#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32213](https://github.com/ClickHouse/ClickHouse/issues/32213) 中回移：如果使用 quorum 插入时，某些副本上禁用了 setting `replicated_can_become_leader`，则活跃副本数可能判断错误。现已修复。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32312](https://github.com/ClickHouse/ClickHouse/issues/32312) 中回移：升级到较新版本时，用于表 create query 的 XML 字典标识符可能会被限定到 `default_database`。关闭 [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)。[#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#32540](https://github.com/ClickHouse/ClickHouse/issues/32540) 中回移：某些 replication queue entries 可能会因 `Directory tmp_merge_<part_name>`、`Part ... (state Deleting) already exists, but it will be deleted soon` 或类似 error 而卡住长达 `temporary_directories_lifetime` (默认为 1 天) 的时间。现已修复。修复 [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32353](https://github.com/ClickHouse/ClickHouse/issues/32353) 中回移：修复 aggregate function `avgWeighted` 在参数为 `Decimal` 时因 SIGFPE 崩溃的问题。修复 [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)。[#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#33048](https://github.com/ClickHouse/ClickHouse/issues/33048) 中回移：通过延迟创建通道，修复 RabbitMQ 存储启动时可能出现的异常。[#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#32795](https://github.com/ClickHouse/ClickHouse/issues/32795) 中回移：修复对多个相同的 FixedString 使用 fuzzBits 时发生的崩溃，关闭了 [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)) 。
