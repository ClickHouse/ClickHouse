<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#56581](https://github.com/ClickHouse/ClickHouse/issues/56581) 中回移：如果表是通过带显式列描述的表函数创建的，则禁止 `system.tables` 中的 `data_paths` 列引用远程数据源。[#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)) 。
* 已在 [#56877](https://github.com/ClickHouse/ClickHouse/issues/56877) 中回移：修复 `view()` 表函数中 `UNION` 的查询结果不完整问题。[#56274](https://github.com/ClickHouse/ClickHouse/pull/56274) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#56409](https://github.com/ClickHouse/ClickHouse/issues/56409) 中回移：禁止向现有表添加类型为 `Object(JSON)` 的列。关闭：[#56095](https://github.com/ClickHouse/ClickHouse/issues/56095) 关闭：[#49944](https://github.com/ClickHouse/ClickHouse/issues/49944)。[#56307](https://github.com/ClickHouse/ClickHouse/pull/56307) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#56756](https://github.com/ClickHouse/ClickHouse/issues/56756) 中回移：修复了在创建 Kafka 表时，由 Kerberos 初始化过程中抛出的异常引发的段错误。关闭 [#56073](https://github.com/ClickHouse/ClickHouse/issues/56073)。[#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已在 [#56748](https://github.com/ClickHouse/ClickHouse/issues/56748) 中回移：修复了 RabbitMQ 表引擎无法通过安全连接接入 RabbitMQ 的问题。[#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)) 。
* 已在 [#56839](https://github.com/ClickHouse/ClickHouse/issues/56839) 中回移：服务器在使用 `FPC` codec 解压格式错误的数据时发生崩溃。该问题由 [https://twitter.com/malacupa](https://twitter.com/malacupa) 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
