<div id="bug-fix">
  #### 缺陷修复
</div>

* 回移至 [#24969](https://github.com/ClickHouse/ClickHouse/issues/24969)：允许在 postgresql 协议中使用 NULL 值。关闭 [#22622](https://github.com/ClickHouse/ClickHouse/issues/22622)。[#24857](https://github.com/ClickHouse/ClickHouse/pull/24857) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 回移至 [#25186](https://github.com/ClickHouse/ClickHouse/issues/25186)：修复在 bucket 根目录声明 S3 disk 时的缺陷。此前会报告如下错误：``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):。[#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon))。
* 回移至 [#25023](https://github.com/ClickHouse/ClickHouse/issues/25023)：修复分布式查询的 limit/offset 配置项（在远程节点上忽略该设置）。[#24940](https://github.com/ClickHouse/ClickHouse/pull/24940) ([Azat Khuzhin](https://github.com/azat))。
* 回移至 [#25049](https://github.com/ClickHouse/ClickHouse/issues/25049)：修复并发执行 `alter move/replace partition` 时，复制队列中极偶发的 `Tagging already tagged part` 错误。可能修复了 [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142)。[#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin))。
* 回移至 [#25081](https://github.com/ClickHouse/ClickHouse/issues/25081)：修复使用含**非空** `GROUP BY` 键的聚合 PROJECTION 来执行带**空**键 `GROUP BY` 查询时结果错误的问题。[#25055](https://github.com/ClickHouse/ClickHouse/pull/25055) ([Amos Bird](https://github.com/amosbird))。
* 回移至 [#25107](https://github.com/ClickHouse/ClickHouse/issues/25107)：修复允许创建含自引用列的表（如 `a UInt32 ALIAS a + 1` 或 `b UInt32 MATERIALIZED b`）的缺陷。修复了 [#24910](https://github.com/ClickHouse/ClickHouse/issues/24910)、[#24292](https://github.com/ClickHouse/ClickHouse/issues/24292)。[#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin))。
* 回移至 [#25106](https://github.com/ClickHouse/ClickHouse/issues/25106)：修复 mapContains 中常量 Map 导致报错 `empty column was returned by function mapContains` 的缺陷。关闭 [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077)。[#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar))。
* 回移至 [#25143](https://github.com/ClickHouse/ClickHouse/issues/25143)：修复使用 CROSS JOIN 且 `joined_subquery_requires_alias = 0` 时查询崩溃的问题。修复了 [#24011](https://github.com/ClickHouse/ClickHouse/issues/24011)。[#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 回移至 [#25157](https://github.com/ClickHouse/ClickHouse/issues/25157)：修复升级至 21.5 后，当表在分区键中使用 `UUID` 时可能导致 parts 丢失的问题（不建议在分区键中使用 `UUID`）。修复了 [#25070](https://github.com/ClickHouse/ClickHouse/issues/25070)。[#25127](https://github.com/ClickHouse/ClickHouse/pull/25127) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 回移至 [#25182](https://github.com/ClickHouse/ClickHouse/issues/25182)：对带 `FINAL` 的 `SELECT` 查询不使用表的 PROJECTION，该功能暂不支持。[#25163](https://github.com/ClickHouse/ClickHouse/pull/25163) ([Amos Bird](https://github.com/amosbird))。
