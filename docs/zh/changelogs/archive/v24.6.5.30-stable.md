<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定发行版中用户可见的异常行为)
</div>

* 已在 [#68969](https://github.com/ClickHouse/ClickHouse/issues/68969) 中回移：修复函数 `fromModifiedJulianDay` 的上限。它本应为 `9999-12-31`，却被错误地设成了 `9999-01-01`。[#67583](https://github.com/ClickHouse/ClickHouse/pull/67583) ([PHO](https://github.com/depressed-pho)).
* 已在 [#68814](https://github.com/ClickHouse/ClickHouse/issues/68814) 中回移：修复了 Parquet 筛选中在文件内 data types 与请求 types 差异较大时发生的 crash (例如 `... FROM file('a.parquet', Parquet, 'x String')`，但文件中的 `x` 实际为 `Int64`) 。若未应用此修复，可使用 `input_format_parquet_filter_push_down = 0` 作为临时解决方法。[#68131](https://github.com/ClickHouse/ClickHouse/pull/68131) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#69005](https://github.com/ClickHouse/ClickHouse/issues/69005) 中回移：在 [https://github.com/ClickHouse/ClickHouse/pull/61984](https://github.com/ClickHouse/ClickHouse/pull/61984) 之后，`schema_inference_make_columns_nullable=0` 在 Parquet/Arrow formats 中仍可能将 columns 推断为 `Nullable`。这一变更不向后兼容，用户也注意到了这一行为变化。此 PR 使 `schema_inference_make_columns_nullable=0` 恢复到此前的行为 (不会推断出 Nullable columns) ，并为该 setting 新增了 `auto` 值：仅当数据包含可空性信息时，才会将 columns 推断为 `Nullable`。[#68298](https://github.com/ClickHouse/ClickHouse/pull/68298) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#68883](https://github.com/ClickHouse/ClickHouse/issues/68883) 中回移：修复了 [#50868](https://github.com/ClickHouse/ClickHouse/issues/50868)。在 distributed query 中，嵌套 subquery 返回的较小 DateTime64 常量值会被错误地转换为 Nulls，从而导致报错，并可能产生不正确的 query results。[#68323](https://github.com/ClickHouse/ClickHouse/pull/68323) ([Shankar](https://github.com/shiyer7474)).
* 已在 [#69025](https://github.com/ClickHouse/ClickHouse/issues/69025) 中回移：将虚拟列 ` _table` 和 `_database` 重新加入分布式表中。它们在 24.3 版本之前一直可用。[#68672](https://github.com/ClickHouse/ClickHouse/pull/68672) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#68860](https://github.com/ClickHouse/ClickHouse/issues/68860) 中回移：修复了 Variant column 排列期间可能出现的错误 `Size of permutation (0) is less than required (...)`。[#68681](https://github.com/ClickHouse/ClickHouse/pull/68681) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#68786](https://github.com/ClickHouse/ClickHouse/issues/68786) 中回移：修复了在函数 `sipHash(64/128)Keyed` 中，对以 arrays 作为 keys 的 maps 进行哈希时，materialized 常量 keys 的问题。[#68731](https://github.com/ClickHouse/ClickHouse/pull/68731) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* 已在 [#69156](https://github.com/ClickHouse/ClickHouse/issues/69156) 中回移：修复 anyHeavy 状态 merge 期间可能出现结果错误的问题。[#68950](https://github.com/ClickHouse/ClickHouse/pull/68950) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#69116](https://github.com/ClickHouse/ClickHouse/issues/69116) 中回移：修复出现空 async insert 时可能发生的 logical error。[#69080](https://github.com/ClickHouse/ClickHouse/pull/69080) ([Han Fei](https://github.com/hanfei1991)).
