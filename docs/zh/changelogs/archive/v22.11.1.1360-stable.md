  # 2022 更新日志

<div id="clickhouse-release-v221111360-stable-0d211ed1984-fixme-as-compared-to-v221011877-stable-98ab5a3c189">
  ### ClickHouse 发布 v22.11.1.1360-稳定版本 (0d211ed1984) FIXME，与 v22.10.1.1877-稳定版本 (98ab5a3c189) 相比
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* JSONExtract 家族中的函数现在会尝试将值强制转换为所要求的类型。[#41502](https://github.com/ClickHouse/ClickHouse/pull/41502) ([Márcio Martins](https://github.com/marcioapm)).

<div id="new-feature">
  #### 新特性
</div>

* * 新增函数 `displayName`，关闭了 [#36770](https://github.com/ClickHouse/ClickHouse/issues/36770)。[#37681](https://github.com/ClickHouse/ClickHouse/pull/37681) ([hongbin](https://github.com/xlwh))。
* 在 `system.query_log` 中新增了已应用的行级策略。[#39819](https://github.com/ClickHouse/ClickHouse/pull/39819) ([Vladimir Chebotaryov](https://github.com/quickhouse))。
* 新增 Hudi 和 DeltaLake 表引擎，为只读模式，且仅适用于 S3 上的表。[#41054](https://github.com/ClickHouse/ClickHouse/pull/41054) ([Daniil Rubin](https://github.com/rubin-do))。
* 新增 4LW 命令 `csnp`，用于手动创建快照。此外，还新增了 `lgif`，用于获取特定节点的 Raft 信息 (例如最近创建的快照索引、最近提交的日志索引) 。[#41766](https://github.com/ClickHouse/ClickHouse/pull/41766) ([JackyWoo](https://github.com/JackyWoo))。
* 支持在向 replicated merge trees 插入时对 Keeper 请求进行重试。除了提升容错能力外，这也旨在带来更好的用户体验——如果 Keeper 重启 (例如因升级) ，可避免在插入期间向用户返回错误。[#42607](https://github.com/ClickHouse/ClickHouse/pull/42607) ([Igor Nikonov](https://github.com/devcrafter))。
* 新增与 Spark 类似的函数 ascii：[https://spark.apache.org/docs/latest/api/sql/#ascii](https://spark.apache.org/docs/latest/api/sql/#ascii)。[#42670](https://github.com/ClickHouse/ClickHouse/pull/42670) ([李扬](https://github.com/taiyang-li))。
* 新增函数 pmod，基于 modulo 返回非负结果。[#42755](https://github.com/ClickHouse/ClickHouse/pull/42755) ([李扬](https://github.com/taiyang-li))。
* 发布了函数 `formatReadableDecimalSize`。[#42774](https://github.com/ClickHouse/ClickHouse/pull/42774) ([Alejandro](https://github.com/alexon1234))。
* 新增了对 S3 PUT 和 GET 每秒请求数的限流。可使用设置 `s3_max_get_rps`、`s3_max_get_burst`、`s3_max_put_rps`、`s3_max_put_burst` 来配置标记桶限流器。该功能既可用于 S3 ObjectStorage，也可用于 S3 表函数。还可为不同的 S3 disk 或端点配置不同的限制。[#43014](https://github.com/ClickHouse/ClickHouse/pull/43014) ([Sergei Trifonov](https://github.com/serxa))。
* 新增表函数 hudi 和 deltaLake。[#43080](https://github.com/ClickHouse/ClickHouse/pull/43080) ([flynn](https://github.com/ucasfl))。
* 新增函数 factorial，与 Impala 或 Spark 中的同类函数类似。[#43110](https://github.com/ClickHouse/ClickHouse/pull/43110) ([李扬](https://github.com/taiyang-li))。
* 新增函数 randCanonical，类似于 Spark 或 Impala 中的 rand 函数。该函数生成伪随机结果，其值相互独立且同分布，并在 [0, 1) 区间上服从均匀分布。[#43124](https://github.com/ClickHouse/ClickHouse/pull/43124) ([李扬](https://github.com/taiyang-li))。

<div id="performance-improvement">
  #### 性能提升
</div>

* 目前，唯一会达到饱和的运算符是 And 和 Or，本次更改会影响它们的代码路径。[#42214](https://github.com/ClickHouse/ClickHouse/pull/42214) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* 当 `match` 函数的条件是字符串前缀时，可以使用索引。此项关闭了 [#37333](https://github.com/ClickHouse/ClickHouse/issues/37333)。[#42458](https://github.com/ClickHouse/ClickHouse/pull/42458) ([clarkcaoliu](https://github.com/Clark0)).
* 修复了 JSONExtract 在 LowCardinality(String) 元组上的性能问题。[#42761](https://github.com/ClickHouse/ClickHouse/pull/42761) ([AlfVII](https://github.com/AlfVII)).
* 为 LineAsString 输入格式增加了并行解析支持。性能仅有小幅提升。此项关闭了 [#42502](https://github.com/ClickHouse/ClickHouse/issues/42502)。[#42780](https://github.com/ClickHouse/ClickHouse/pull/42780) ([Kruglov Pavel](https://github.com/Avogar)).
* Keeper 性能提升：改进了在许多不同节点存在未提交状态时的 commit 性能。这有助于缓解 follower 节点同步速度不够快的情况。[#42926](https://github.com/ClickHouse/ClickHouse/pull/42926) ([Antonio Andelic](https://github.com/antonio2368)).
* 将无键 aggregation 的 `uniqExact` 状态合并并行化，即类似 `SELECT uniqExact(number) FROM table` 的查询。当唯一键数量接近 10^6 时，提升会比较明显。另外，`uniq` 的性能也略有优化。此项关闭了 [#4510](https://github.com/ClickHouse/ClickHouse/issues/4510)。[#43072](https://github.com/ClickHouse/ClickHouse/pull/43072) ([Nikita Taranov](https://github.com/nickitat)).

<div id="improvement">
  #### 改进
</div>

* 支持在其他类型中使用 `Object` 类型，例如 `Array(JSON)`。[#36969](https://github.com/ClickHouse/ClickHouse/pull/36969) ([Anton Popov](https://github.com/CurtizJ)).
* 对于拉取的 part，移除其覆盖的 parts (以避免复制延迟可能增大) 。[#39737](https://github.com/ClickHouse/ClickHouse/pull/39737) ([Azat Khuzhin](https://github.com/azat)).
* ClickHouse Client 和 ClickHouse Local 现在即使在非交互模式下也会默认显示进度。如果 `/dev/tty` 可用，进度将直接输出到终端，而不会写入 stderr。这样即使 stderr 被重定向到文件，也能看到进度，并且文件不会被终端转义序列污染。可以通过 `--progress false` 关闭进度。这关闭了 [#32238](https://github.com/ClickHouse/ClickHouse/issues/32238)。[#42003](https://github.com/ClickHouse/ClickHouse/pull/42003) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 1. 现在已支持对 Interval 执行加法、减法和取负操作。如果 Interval 的类型不同，它们会被转换为由这些类型组成的 Tuple。2. 由多个 Interval 组成的 Tuple 可以加到 Date/日期时间 字段上，或从中减去。3. 新增了对不同类型 Interval 的解析支持，例如：`INTERVAL '1 HOUR 1 MINUTE 1 SECOND'`。[#42195](https://github.com/ClickHouse/ClickHouse/pull/42195) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* * 将 `notLike` 添加到键条件原子映射中，使 `NOT LIKE 'prefix%'` 这样的条件也能使用主索引。[#42209](https://github.com/ClickHouse/ClickHouse/pull/42209) ([Duc Canh Le](https://github.com/canhld94)) 。
* 为 base64 编码函数添加对 `FixedString` 输入的支持。[#42285](https://github.com/ClickHouse/ClickHouse/pull/42285) ([ltrk2](https://github.com/ltrk2)) 。
* 在 `system.detached_parts` 中新增列 `bytes_on_disk` 和 `path`。解决 [#42264](https://github.com/ClickHouse/ClickHouse/issues/42264)。[#42303](https://github.com/ClickHouse/ClickHouse/pull/42303) ([chen](https://github.com/xiedeyantu)) 。
* 改进了表函数中对插入表结构的使用方式；现在，设置 `use_structure_from_insertion_table_in_table_functions` 新增了一个可选值 `2`，表示 ClickHouse 将尝试自动判断是否可以使用插入表的结构。解决 [#40028](https://github.com/ClickHouse/ClickHouse/issues/40028)。[#42320](https://github.com/ClickHouse/ClickHouse/pull/42320) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 为 filesystem 和 S3 添加了用于递归遍历目录的 `**` glob 支持。解决 [#36316](https://github.com/ClickHouse/ClickHouse/issues/36316)。[#42376](https://github.com/ClickHouse/ClickHouse/pull/42376) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)) 。
* 在 `system.query_log`、`/var/log/clickhouse-server/*.log` 以及错误消息中屏蔽密码和密钥。[#42484](https://github.com/ClickHouse/ClickHouse/pull/42484) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 在 query&#95;info 中新增一个名为 `limit` 的变量，用于指示该查询是否为 limit-trivial 查询。如果是，我们会调整近似总行数以供后续估算。解决 [#7071](https://github.com/ClickHouse/ClickHouse/issues/7071)。[#42580](https://github.com/ClickHouse/ClickHouse/pull/42580) ([Han Fei](https://github.com/hanfei1991)) 。
* 为 `s3_plain` 磁盘实现了 `MergeTree` 表的 `ATTACH` (并修复了 `s3_plain` 的一些问题) 。[#42628](https://github.com/ClickHouse/ClickHouse/pull/42628) ([Azat Khuzhin](https://github.com/azat)) 。
* 修复了 INSERT FROM INFILE 没有进度提示的问题。解决 [#42548](https://github.com/ClickHouse/ClickHouse/issues/42548)。[#42634](https://github.com/ClickHouse/ClickHouse/pull/42634) ([chen](https://github.com/xiedeyantu)) 。
* 添加 `min_age_to_force_merge_on_partition_only` 设置，以便仅对整个分区中的旧 parts 执行优化。[#42659](https://github.com/ClickHouse/ClickHouse/pull/42659) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 限流算法已改为令牌桶。[#42665](https://github.com/ClickHouse/ClickHouse/pull/42665) ([Sergei Trifonov](https://github.com/serxa)) 。
* 重构了 FunctionTokens，使相关函数支持返回最大标记数 (默认禁用) 。[#42673](https://github.com/ClickHouse/ClickHouse/pull/42673) ([李扬](https://github.com/taiyang-li)) 。
* 在 system.table&#95;functions 中新增字段 allow&#95;readonly，以允许在只读模式下使用表函数，解决 [#42414](https://github.com/ClickHouse/ClickHouse/issues/42414) 实现：* 向表 system.table&#95;functions 新增字段 allow&#95;readonly。* 更新为使用新字段 allow&#95;readonly，以允许在只读模式下使用表函数。测试：* 为 filesystem 添加了一个测试 tests/queries/0&#95;stateless/02473&#95;functions&#95;in&#95;readonly&#95;mode.sh 文档：* 更新了 Table Functions 的英文文档。[#42708](https://github.com/ClickHouse/ClickHouse/pull/42708) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)) 。
* 允许 `formatDateTime` 和 `FROM&#95;UNIXTIME` 函数使用 `Date32` 参数。[#42737](https://github.com/ClickHouse/ClickHouse/pull/42737) ([Roman Vasin](https://github.com/rvasin)) 。
* 将 tzdata 更新至 2022f。除美国边境附近地区外，墨西哥将不再实行夏令时：[https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html)。Chihuahua 将于 2022-10-30 调整为全年采用 UTC-6。Fiji 也不再实行夏令时。参见 [https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) 和 [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209)。[#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为异步插入添加 `FailedAsyncInsertQuery` 事件指标。[#42814](https://github.com/ClickHouse/ClickHouse/pull/42814) ([Krzysztof Góralski](https://github.com/kgoralski)).
* 在查询计划之上实现了 `read-in-order` 优化。该优化默认启用。将 `query_plan_read_in_order = 0` 可切换回之前基于 AST 的版本。[#42829](https://github.com/ClickHouse/ClickHouse/pull/42829) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 对 Backup 到 S3 的上传分片大小采用指数级增长策略。[#42833](https://github.com/ClickHouse/ClickHouse/pull/42833) ([Vitaly Baranov](https://github.com/vitlibar)).
* 当 merge 任务持续繁忙且磁盘空间不足时，完全过期的 parts 无法被选中并删除，从而进一步加剧磁盘空间不足。现在，当整个 Part 过期时，无需额外磁盘空间作为保障，以确保生存时间 (TTL) 能正常执行。[#42869](https://github.com/ClickHouse/ClickHouse/pull/42869) ([zhongyuankai](https://github.com/zhongyuankai)).
* bug 修复：[#42856](https://github.com/ClickHouse/ClickHouse/issues/42856) 忽略 MySQL binlog SAVEPOINT 事件。[#42931](https://github.com/ClickHouse/ClickHouse/pull/42931) ([zzsmdfj](https://github.com/zzsmdfj)).
* 为 INSERT VALUES 查询添加交互式 parameter 支持。[#43077](https://github.com/ClickHouse/ClickHouse/pull/43077) ([Nikolay Degterinsky](https://github.com/evillique)).
* 为任意结构化的 named collections、access type 和 system.named&#95;collections 添加通用实现。[#43147](https://github.com/ClickHouse/ClickHouse/pull/43147) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 添加 oss function 和 StorageOSS (这对用户来说更方便) 。oss 与 S3 完全兼容。[#43155](https://github.com/ClickHouse/ClickHouse/pull/43155) ([zzsmdfj](https://github.com/zzsmdfj)).
* 改进 `system.asynchronous_metrics` 表中 OS 相关信息收集过程的错误报告。[#43192](https://github.com/ClickHouse/ClickHouse/pull/43192) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `system.asynchronous_metrics` 现在包含 embedded documentation。该文档也会导出到 Prometheus。修复了 `cache` disks 指标中的一个错误：此前只会对某一个任意 cache disk 进行计算，而不是对全部进行计算。此项关闭了 [#7644](https://github.com/ClickHouse/ClickHouse/issues/7644)。[#43194](https://github.com/ClickHouse/ClickHouse/pull/43194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 调整了 `INFORMATION_SCHEMA` 表，使 ClickHouse 现在可以通过 MySQL compatibility protocol 连接到自身。添加 columns 而非 aliases (与 [#9769](https://github.com/ClickHouse/ClickHouse/issues/9769) 相关) 。这将提升与各类 MySQL clients 的兼容性。[#43198](https://github.com/ClickHouse/ClickHouse/pull/43198) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* 在 readonly 模式下禁用 `deltaLake` 和 `hudi` 表函数。 [#43316](https://github.com/ClickHouse/ClickHouse/pull/43316) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 更新了 normaliser，使其克隆 alias AST。解决了 [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452)。实现：* 更新了 QueryNormalizer，在 alias AST 被替换时会先克隆它。此前只是赋值为同一个 AST，这会导致 LogicalExpressinsOptimizer 中出现异常，因为会再次插入同一个父节点。* 使用新的 analyzer (allow&#95;experimental&#95;analyzer) 时不会出现这个 bug，因此未对其做任何修改。我也为此添加了测试。[#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 修复了 Lazy 数据库中表备份的竞态问题。[#43104](https://github.com/ClickHouse/ClickHouse/pull/43104) ([Vitaly Baranov](https://github.com/vitlibar)).
* 修复了使用 s3Cluster 表函数时 skip&#95;unavailable&#95;shards 不生效的问题。[#43131](https://github.com/ClickHouse/ClickHouse/pull/43131) ([chen](https://github.com/xiedeyantu)).

* 新增了使用 Jepsen 测试 ClickHouse server 的支持。顺便一提，我们已经支持使用 Jepsen 测试 ClickHouse Keeper。此拉取请求将该能力扩展到了复制表。[#42619](https://github.com/ClickHouse/ClickHouse/pull/42619) ([Antonio Andelic](https://github.com/antonio2368))。
* * 改进错误修复验证检查：修复了会跳过该检查的问题，将独立状态迁移到 CI 中，并在检查标签和风格检查之后运行。关闭 [#40349](https://github.com/ClickHouse/ClickHouse/issues/40349)。[#42702](https://github.com/ClickHouse/ClickHouse/pull/42702) ([Vladimir C](https://github.com/vdimir))。
* 在集成测试中，在归档文件之前等待所有文件完成同步。[#42891](https://github.com/ClickHouse/ClickHouse/pull/42891) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* 使用 [https://github.com/matus-chochlik/ctcache](https://github.com/matus-chochlik/ctcache) 缓存 clang-tidy 的结果。[#42913](https://github.com/ClickHouse/ClickHouse/pull/42913) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* 在此修复之前，RPM 会将用户自定义配置保存在 `$file.rpmsave` 中。该 PR 修复了这个问题，不会再用软件包中的文件替换用户文件。[#42936](https://github.com/ClickHouse/ClickHouse/pull/42936) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* 新增一个 CI 步骤，将提交标记为可发布；同时软性禁止从 master 以外的分支启动发布脚本。[#43017](https://github.com/ClickHouse/ClickHouse/pull/43017) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
