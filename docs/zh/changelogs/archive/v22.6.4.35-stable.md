<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#38242](https://github.com/ClickHouse/ClickHouse/issues/38242) 中回移：修复了从配置中移除副本时，`Distributed` async insert 可能发生崩溃的问题。[#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#38865](https://github.com/ClickHouse/ClickHouse/issues/38865) 中回移：修复了 s3 在配合并行读取缓冲区时的可寻道读取问题。 (会影响查询期间的内存使用。) 关闭了 [#38258](https://github.com/ClickHouse/ClickHouse/issues/38258)。[#38802](https://github.com/ClickHouse/ClickHouse/pull/38802) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#38853](https://github.com/ClickHouse/ClickHouse/issues/38853) 中回移：更新了 `simdjson`。这修复了 [#38621](https://github.com/ClickHouse/ClickHouse/issues/38621)。[#38838](https://github.com/ClickHouse/ClickHouse/pull/38838) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#38942](https://github.com/ClickHouse/ClickHouse/issues/38942) 中回移：修复带秒单位的 settings profile。[#38896](https://github.com/ClickHouse/ClickHouse/pull/38896) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#39063](https://github.com/ClickHouse/ClickHouse/issues/39063) 中回移：OvercommitTracker 内部的任何内存分配都可能导致死锁。由于日志信息帮助不大，直接移除日志更简单。修复了 [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794)。[#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#39077](https://github.com/ClickHouse/ClickHouse/issues/39077) 中回移：修复了文件系统缓存中的一个缺陷，该问题可能在某些边缘情况下出现，并恰好与缓存容量达到上限同时发生。关闭了 [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066)。[#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#39151](https://github.com/ClickHouse/ClickHouse/issues/39151) 中回移：修复了向附加了 MATERIALIZED VIEW 且启用了设置 `extremes = 1` 的表执行 INSERT 时，可能出现的错误 `Block structure mismatch`。关闭了 [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) 和 [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729)。[#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#39275](https://github.com/ClickHouse/ClickHouse/issues/39275) 中回移：修复了带有 `PREWHERE` 和按顺序读取优化的 SELECT 查询中出现的错误 `Not found column Type in block`。[#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#39371](https://github.com/ClickHouse/ClickHouse/issues/39371) 中回移：声明 RabbitMQ 队列时不再带默认参数 `x-max-length` 和 `x-overflow`。[#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* 已在 [#39352](https://github.com/ClickHouse/ClickHouse/issues/39352) 中回移：修复了 PostgreSQL database engine 拉取 PostgreSQL 表时所用查询不正确的问题。关闭了 [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502)。[#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
