<div id="improvement">

* 已在 [#24794](https://github.com/ClickHouse/ClickHouse/issues/24794) 中回移：避免隐藏标量子查询中的 `Limit for rows or bytes to read exceeded` 等错误。[#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).



<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#25567](https://github.com/ClickHouse/ClickHouse/issues/25567) 中回移：Kafka 存储现可支持 parquet 格式的消息。[#23412](https://github.com/ClickHouse/ClickHouse/pull/23412) ([Chao Ma](https://github.com/godliness))。
* 已在 [#24554](https://github.com/ClickHouse/ClickHouse/issues/24554) 中回移：修复了通过 HTTP 插入数据时因异常导致服务器故障的问题。此修复解决了 [#23512](https://github.com/ClickHouse/ClickHouse/issues/23512)。[#23643](https://github.com/ClickHouse/ClickHouse/pull/23643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已在 [#23833](https://github.com/ClickHouse/ClickHouse/issues/23833) 中回移：修复了使用 `GLOBAL IN/JOIN` 和 `use_hedged_requests` 的查询出现 `Can't initialize pipeline with empty pipe` 错误的问题。修复了 [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431)。[#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#24703](https://github.com/ClickHouse/ClickHouse/issues/24703) 中回移：允许空 HTTP 头。修复了 [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901)。[#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7))。
* 已在 [#24702](https://github.com/ClickHouse/ClickHouse/issues/24702) 中回移：修复了删除分区时与伪造 parts 相交的问题。在极少数情况下，可能存在变更版本号大于当前块编号的 parts。[#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#24725](https://github.com/ClickHouse/ClickHouse/issues/24725) 中回移：在 "multipart/form-data" 消息中，将边界前的 CRLF 视为边界的一部分。修复了 [#23905](https://github.com/ClickHouse/ClickHouse/issues/23905)。[#24399](https://github.com/ClickHouse/ClickHouse/pull/24399) ([Ivan](https://github.com/abyss7))。
* 已在 [#24826](https://github.com/ClickHouse/ClickHouse/issues/24826) 中回移：- 修复了在 LDAP 角色（重新）映射期间，当 LDAP 组被映射到不存在的本地角色时可能发生死锁的问题。[#24431](https://github.com/ClickHouse/ClickHouse/pull/24431) ([Denis Glazachev](https://github.com/traceon))。
* 已在 [#25566](https://github.com/ClickHouse/ClickHouse/issues/25566) 中回移：修复了 toWeek 函数单调性不正确的问题。此修复解决了 [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422)。该缺陷引入自 https://github.com/ClickHouse/ClickHouse/pull/5212，后被更智能的分区裁剪器暴露。[#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#24700](https://github.com/ClickHouse/ClickHouse/issues/24700) 中回移：修复了 `SYSTEM RESTART REPLICA` 或 `SYSTEM SYNC REPLICA` 查询无限执行的问题。该问题在内存极少的服务器上被发现。[#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已在 [#24698](https://github.com/ClickHouse/ClickHouse/issues/24698) 中回移：为分布式表启用子列读取功能。[#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ))。
* 修复了远程 JDBC bridge 连接超时问题。关闭了 [#9609](https://github.com/ClickHouse/ClickHouse/issues/9609)。[#24588](https://github.com/ClickHouse/ClickHouse/pull/24588) ([Maksim Kita](https://github.com/kitaisreal))。
* 已在 [#24771](https://github.com/ClickHouse/ClickHouse/issues/24771) 中回移：修复了可能导致 ZooKeeper 客户端在 clickhouse-server 内部挂起的缺陷。[#24721](https://github.com/ClickHouse/ClickHouse/pull/24721) ([alesapin](https://github.com/alesapin))。
* 已在 [#24934](https://github.com/ClickHouse/ClickHouse/issues/24934) 中回移：- 修复了 ZooKeeper 连接断开后，若副本在恢复连接后被克隆，其复制队列可能包含过期条目的问题。- 修复了复制队列包含相交虚拟 parts 时发生崩溃的问题。该情况在某些数据 part 丢失时偶有发生，现改为在日志中打印错误而非终止进程。[#24777](https://github.com/ClickHouse/ClickHouse/pull/24777) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#24850](https://github.com/ClickHouse/ClickHouse/issues/24850) 中回移：修复了在等待变更时，若变更尚未加载到内存中，可能向客户端抛出 `Mutation was killed` 异常的缺陷。[#24809](https://github.com/ClickHouse/ClickHouse/pull/24809) ([alesapin](https://github.com/alesapin))。
* 已在 [#24917](https://github.com/ClickHouse/ClickHouse/issues/24917) 中回移：修复了低内存服务器上极罕见的缺陷，该缺陷可能导致不重启便无法执行合并操作。可能修复了 [#24603](https://github.com/ClickHouse/ClickHouse/issues/24603)。[#24872](https://github.com/ClickHouse/ClickHouse/pull/24872) ([alesapin](https://github.com/alesapin))。
* 已在 [#25185](https://github.com/ClickHouse/ClickHouse/issues/25185) 中回移：修复了在 bucket 根目录声明 S3 磁盘时的缺陷。此前会报告如下错误：``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):。[#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon))。

* 已在 [#25562](https://github.com/ClickHouse/ClickHouse/issues/25562) 中回移：修复了并发执行 `alter move/replace partition` 时，复制队列中极罕见的 `Tagging already tagged part` 错误。可能修复了 [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142)。[#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin))。
