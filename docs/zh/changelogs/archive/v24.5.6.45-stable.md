<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#67902](https://github.com/ClickHouse/ClickHouse/issues/67902) 中回移：修复 StorageMerge 在 `PREWHERE` 优化后出现的 `Not-ready Set` 错误。[#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#68252](https://github.com/ClickHouse/ClickHouse/issues/68252) 中回移：修复某些系统表在使用子查询进行筛选时出现的 `Not-ready Set` 问题。[#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#68064](https://github.com/ClickHouse/ClickHouse/issues/68064) 中回移：修复发送到外部数据库的查询中的布尔值字面量问题 (适用于 `PostgreSQL` 等引擎) 。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* 已在 [#68158](https://github.com/ClickHouse/ClickHouse/issues/68158) 中回移：修复 `cluster()` 对 `inter-server secret` 的处理问题 (和之前一样保留初始用户) 。[#66364](https://github.com/ClickHouse/ClickHouse/pull/66364) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#68115](https://github.com/ClickHouse/ClickHouse/issues/68115) 中回移：修复读取 Variant 子列时可能出现的 PARAMETER&#95;OUT&#95;OF&#95;BOUND 错误。[#66659](https://github.com/ClickHouse/ClickHouse/pull/66659) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#67886](https://github.com/ClickHouse/ClickHouse/issues/67886) 中回移：如果文件名/URI 包含 `::` 且其不是归档文件，则可正确解析。[#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#68272](https://github.com/ClickHouse/ClickHouse/issues/68272) 中回移：修复通过 HTTP 接口向 stream 类引擎 (Kafka、RabbitMQ、NATS) 插入数据的问题。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#67807](https://github.com/ClickHouse/ClickHouse/issues/67807) 中回移：修复重新加载带有 UNION 的 SQL UDFs 时的问题。此前，重启服务器可能会导致 UDF 失效。[#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#67836](https://github.com/ClickHouse/ClickHouse/issues/67836) 中回移：修复 `JSONMergePatch` 函数中潜在的栈溢出问题。由于之前的名称不正确，已将该函数从 `jsonMergePatch` 重命名为 `JSONMergePatch`。为保持兼容性，之前的名称仍然保留。还改进了该函数的错误诊断信息。此项修复关闭了 [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304)。[#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#67991](https://github.com/ClickHouse/ClickHouse/issues/67991) 中回移：在 ALTER ADD/MODIFY COLUMN 中校验 Experimental/可疑数据类型。[#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#68207](https://github.com/ClickHouse/ClickHouse/issues/68207) 中回移：修复谓词中存在非确定性函数时 `count()` 结果错误的问题。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#68091](https://github.com/ClickHouse/ClickHouse/issues/68091) 中回移：修复在可用 CPU 数量受限的容器化环境中最大线程软限制的计算问题。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* 已在 [#68122](https://github.com/ClickHouse/ClickHouse/issues/68122) 中回移：修复了在使用新 analyzer 的变更中错误跳过未受影响 parts 的问题。此前，在启用 analyzer 时，即使根据谓词该变更不会影响某个 part，其中的数据也可能被变更重写。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#68171](https://github.com/ClickHouse/ClickHouse/issues/68171) 中回移：移除了一个错误的优化，该优化会移除使用 `OFFSET` 的子查询中的排序。修复了 [#67906](https://github.com/ClickHouse/ClickHouse/issues/67906)。[#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)).
* 已在 [#68337](https://github.com/ClickHouse/ClickHouse/issues/68337) 中回移：尝试修复查询被取消时 Postgres 崩溃的问题。[#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#68667](https://github.com/ClickHouse/ClickHouse/issues/68667) 中回移：修复了将函数 `sipHash64Keyed`、`sipHash128Keyed` 或 `sipHash128ReferenceKeyed` 应用于空数组或元组时出现的 `LOGICAL_ERROR`。[#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)).
