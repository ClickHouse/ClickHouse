* 已在 [#66687](https://github.com/ClickHouse/ClickHouse/issues/66687) 中回移：修复用户定义中的 VALID UNTIL 子句在重启后被重置的问题。关闭 [#66405](https://github.com/ClickHouse/ClickHouse/issues/66405)。[#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#66324](https://github.com/ClickHouse/ClickHouse/issues/66324) 中回移：在 schema inference cache 中补充了缺失的设置 `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples`，因为这些设置会改变最终的 schema。这样可防止在这些设置变更后得到错误的 schema inference 结果。[#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#66151](https://github.com/ClickHouse/ClickHouse/issues/66151) 中回移：修复了 `unbin`/`unhex` 实现中的缓冲区溢出问题。[#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* 已在 [#66451](https://github.com/ClickHouse/ClickHouse/issues/66451) 中回移：修复了 ZooKeeper 客户端中的一个问题：收到来自 ZooKeeper 的硬件错误后，session 可能卡在不可用状态。例如，这种情况可能由 ClickHouse Keeper 中的 &quot;soft memory limit&quot; 触发。[#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#66222](https://github.com/ClickHouse/ClickHouse/issues/66222) 中回移：修复了 SumIfToCountIfVisitor 在处理有符号整数时的问题。[#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#66676](https://github.com/ClickHouse/ClickHouse/issues/66676) 中回移：修复了在无法使用任何索引时 `system.numbers_mt` 的 limit 处理问题。[#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#66602](https://github.com/ClickHouse/ClickHouse/issues/66602) 中回移：修复了 ClickHouse server 在 Docker 等容器中运行时，根据 cgroups v2 检测可用 CPU 核心最大数量的方式。更具体地说，容器通常会让其进程运行在名称为空的根 cgroup 中；在这种情况下，ClickHouse 会忽略 cgroups v2 设置的 CPU 限制。[#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
* 已在 [#66356](https://github.com/ClickHouse/ClickHouse/issues/66356) 中回移：修复了在约束中使用带 `IN` 的子查询时出现的 `Not-ready set` 错误。[#66261](https://github.com/ClickHouse/ClickHouse/pull/66261) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#66970](https://github.com/ClickHouse/ClickHouse/issues/66970) 中回移：修复了在 `group_by_use_nulls=true` 且启用新 analyzer 时出现的 `Column identifier is already registered` 错误。[#66400](https://github.com/ClickHouse/ClickHouse/pull/66400) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#66967](https://github.com/ClickHouse/ClickHouse/issues/66967) 中回移：修复了查询在 `GROUP BY` 键中包含常量 expression 且启用新 analyzer 时出现的 `Cannot find column` 错误。[#66433](https://github.com/ClickHouse/ClickHouse/pull/66433) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#66718](https://github.com/ClickHouse/ClickHouse/issues/66718) 中回移：正确跟踪了 `Allocator::realloc` 的内存使用。[#66548](https://github.com/ClickHouse/ClickHouse/pull/66548) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#66949](https://github.com/ClickHouse/ClickHouse/issues/66949) 中回移：修复了带 `WINDOW` 的查询返回无效结果的问题。当 `PARTITION` 列采用稀疏 serialization，且 window functions 并行执行时，可能会出现这种情况。[#66579](https://github.com/ClickHouse/ClickHouse/pull/66579) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#66946](https://github.com/ClickHouse/ClickHouse/issues/66946) 中回移：修复在将标量子查询用作 IN 的第一个参数时出现的 `Method getResultType is not supported for QUERY query node` 错误 (使用新 analyzer 时) 。[#66655](https://github.com/ClickHouse/ClickHouse/pull/66655) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#67629](https://github.com/ClickHouse/ClickHouse/issues/67629) 中回移：修复 Context::getDDLWorker 中偶发的死锁。[#66843](https://github.com/ClickHouse/ClickHouse/pull/66843) ([Alexander Gololobov](https://github.com/davenger)).
* 已在 [#67193](https://github.com/ClickHouse/ClickHouse/issues/67193) 中回移：修复了 TRUNCATE DATABASE 会像 DROP DATABASE 查询一样停止复制的问题。[#67129](https://github.com/ClickHouse/ClickHouse/pull/67129) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#67375](https://github.com/ClickHouse/ClickHouse/issues/67375) 中回移：修复对通过单个分片上的 `Distriburted` 表读取的 `Merge` 表执行查询时出现的错误 `Cannot convert column because it is non constant in source stream but must be constant in result.`。[#67146](https://github.com/ClickHouse/ClickHouse/pull/67146) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#67572](https://github.com/ClickHouse/ClickHouse/issues/67572) 中回移：修复嵌套短路函数的执行问题。[#67520](https://github.com/ClickHouse/ClickHouse/pull/67520) ([Kruglov Pavel](https://github.com/Avogar)).
