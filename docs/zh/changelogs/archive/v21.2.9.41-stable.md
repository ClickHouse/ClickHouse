  # 2022 更新日志
</div>

<div id="clickhouse-release-v212941-stable-fixme-as-compared-to-v212831-stable">
  ### ClickHouse 版本 v21.2.9.41-stable FIXME (相较于 v21.2.8.31-stable)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#22818](https://github.com/ClickHouse/ClickHouse/issues/22818) 中回移：使 FQDN 及其他与 DNS 相关的函数在 Alpine 镜像中能够正常工作。[#20336](https://github.com/ClickHouse/ClickHouse/pull/20336) ([filimonov](https://github.com/filimonov)).
* 已在 [#22812](https://github.com/ClickHouse/ClickHouse/issues/22812) 中回移：如果 PODArray 实例化时使用的元素大小既不是 16 的约数，也不是 16 的倍数，则可能发生缓冲区溢出。当前发行版中不存在此类缺陷。[#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#22965](https://github.com/ClickHouse/ClickHouse/issues/22965) 中回移：修复一个极少见的缺陷：使用 `quorum_parallel=1` 执行 quorum insert 时，由于去重机制，实际上并不是真正的“quorum”。[#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* 已在 [#22719](https://github.com/ClickHouse/ClickHouse/issues/22719) 中回移：检查表函数 view 是否被当作列使用。这是对 [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350) 的补充。[#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#22756](https://github.com/ClickHouse/ClickHouse/issues/22756) 中回移：修复函数 `map` 在分布式查询中的使用问题。[#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* 已在 [#22889](https://github.com/ClickHouse/ClickHouse/issues/22889) 中回移：修复从 MergeTree 反向读取时近似总行数统计不准确的问题。[#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22915](https://github.com/ClickHouse/ClickHouse/issues/22915) 中回移：LIVE VIEW (实验性功能) 。修复 `TemporaryLiveViewCleaner` 中并发执行 TEMPORARY LIVE VIEW 的 DROP/CREATE 时可能出现的挂起问题，参见 [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e)。[#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#22918](https://github.com/ClickHouse/ClickHouse/issues/22918) 中回移：修复将 `mannWhitneyUTest` 和 `rankCorr` 与窗口函数一起使用时发生的崩溃问题。此修复解决了 [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728)。[#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#22814](https://github.com/ClickHouse/ClickHouse/issues/22814) 中回移：允许在 gdb 下使用已修改的二进制文件启动。此前版本中，如果在启动前先在 gdb 中设置断点，服务端会因完整性检查失败而拒绝启动。[#21258](https://github.com/ClickHouse/ClickHouse/pull/21258) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

* FileDictionarySource 修复绝对文件路径问题 [#22822](https://github.com/ClickHouse/ClickHouse/pull/22822) ([Maksim Kita](https://github.com/kitaisreal)).
