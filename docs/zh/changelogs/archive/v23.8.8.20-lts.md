<div id="improvement">
  #### 改进
</div>

* 已回移至 [#56509](https://github.com/ClickHouse/ClickHouse/issues/56509)：允许备份内部表已删除的 materialized view，而不再导致备份失败。[#56387](https://github.com/ClickHouse/ClickHouse/pull/56387) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已回移至 [#56929](https://github.com/ClickHouse/ClickHouse/issues/56929)：早期 ClickHouse 版本中存在一个潜在漏洞：如果用户已建立连接，并使用 “interserver secret” 方法尝试身份验证但失败，服务器不会立即终止连接，而是继续接收并忽略客户端发来的剩余数据包。虽然这些数据包会被忽略，但仍然会被解析；如果它们使用了另一种已知存在漏洞的压缩方法，就可能导致该漏洞在无需身份验证的情况下被利用。该问题由 [https://twitter.com/malacupa](https://twitter.com/malacupa) 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#56794](https://github.com/ClickHouse/ClickHouse/pull/56794) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

  #### 构建/测试/打包改进

Shiryaev](https://github.com/Felixoid)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移至 [#57111](https://github.com/ClickHouse/ClickHouse/issues/57111)：修复在初始节点上不存在该数据库时执行 ON CLUSTER 查询的问题。关闭 [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009)。[#56484](https://github.com/ClickHouse/ClickHouse/pull/56484) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已回移至 [#57169](https://github.com/ClickHouse/ClickHouse/issues/57169)：修复使用 `Gorilla` codec 解压格式错误的数据时因缓冲区溢出导致崩溃的问题。该问题由 [https://twitter.com/malacupa](https://twitter.com/malacupa) 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#57107](https://github.com/ClickHouse/ClickHouse/pull/57107) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 已回移至 [#57175](https://github.com/ClickHouse/ClickHouse/issues/57175)：对于在身份验证之前发生的任何异常，关闭服务器间连接。该问题由 [https://twitter.com/malacupa](https://twitter.com/malacupa) 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#57142](https://github.com/ClickHouse/ClickHouse/pull/57142) ([Antonio Andelic](https://github.com/antonio2368)) 。
