<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#22335](https://github.com/ClickHouse/ClickHouse/issues/22335) 中回移：修复表函数 `clusterAllReplicas` 返回错误 `_shard_num` 的问题。关闭 [#21481](https://github.com/ClickHouse/ClickHouse/issues/21481)。[#21498](https://github.com/ClickHouse/ClickHouse/pull/21498) ([flynn](https://github.com/ucasfl)).
* 已在 [#22319](https://github.com/ClickHouse/ClickHouse/issues/22319) 中回移：针对外部数据库引擎 (MySQL、PostgreSQL) 的查询，在 where 中移除 joined 表里的未知列。关闭 [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614)，关闭 [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (重复) ，关闭 [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (重复) 。[#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#22241](https://github.com/ClickHouse/ClickHouse/issues/22241) 中回移：修复标量子查询的索引分析问题。这修复了 [#21717](https://github.com/ClickHouse/ClickHouse/issues/21717)，该问题是在 [https://github.com/ClickHouse/ClickHouse/pull/18896](https://github.com/ClickHouse/ClickHouse/pull/18896) 中引入的。[#21766](https://github.com/ClickHouse/ClickHouse/pull/21766) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#22150](https://github.com/ClickHouse/ClickHouse/issues/22150) 中回移：改进 WriteBufferFromS3 中的错误处理和日志记录。[#21836](https://github.com/ClickHouse/ClickHouse/pull/21836) ([Pavel Kovalenko](https://github.com/Jokser)).
* 已在 [#22468](https://github.com/ClickHouse/ClickHouse/issues/22468) 中回移：在极少数情况下，`CollapsingMergeTree` 的合并可能会产生包含 `index_granularity + 1` 行的粒度。为此，在 [#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) 中添加的内部检查 (影响 21.2 和 21.3) 可能会报错 `Incomplete granules are not allowed while blocks are granules size`。该错误会导致 parts 无法合并。[#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#22203](https://github.com/ClickHouse/ClickHouse/issues/22203) 中回移：Docker entrypoint：避免在 `LOG_PATH` 为空时对 `.` 执行 chown。关闭 [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100)。[#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* 已在 [#22261](https://github.com/ClickHouse/ClickHouse/issues/22261) 中回移：为存在缺陷的 Linux 内核禁用 `async_socket_for_remote`/`use_hedged_requests`。[#22109](https://github.com/ClickHouse/ClickHouse/pull/22109) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22281](https://github.com/ClickHouse/ClickHouse/issues/22281) 中回移：修复 `ReplicatedMergeTree` 表引擎中等待 `OPTIMIZE` 和 `ALTER` 查询的问题。现在即使表已被 detach 或重启，查询也不会挂起。[#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* 已在 [#22265](https://github.com/ClickHouse/ClickHouse/issues/22265) 中回移：修复后台线程池名称。[#22122](https://github.com/ClickHouse/ClickHouse/pull/22122) ([fastio](https://github.com/fastio)).
* 已在 [#22262](https://github.com/ClickHouse/ClickHouse/issues/22262) 中回移：修复 `JOIN` 与 `TOTALS` 和 `arrayJoin` 一起使用时出现的 `Invalid number of rows in Chunk` 错误。关闭 [#19303](https://github.com/ClickHouse/ClickHouse/issues/19303)。[#22129](https://github.com/ClickHouse/ClickHouse/pull/22129) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#22316](https://github.com/ClickHouse/ClickHouse/issues/22316) 中回移：修复配置中不存在 `http_port` 时的 Docker 入口脚本问题。[#22132](https://github.com/ClickHouse/ClickHouse/pull/22132) ([Ewout](https://github.com/devwout)).
* 已在 [#22313](https://github.com/ClickHouse/ClickHouse/issues/22313) 中回移：修复 `use_hedged_requests=0` 且 `async_socket_for_remote=1` 时的查询取消问题。[#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22366](https://github.com/ClickHouse/ClickHouse/issues/22366) 中回移：现在，尝试对已覆盖的分片执行变更时，ClickHouse 不会再抛出 `LOGICAL_ERROR` 异常。修复 [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013)。[#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* 已在 [#22562](https://github.com/ClickHouse/ClickHouse/issues/22562) 中回移：不再限制 HTTP chunk 大小。修复 [#21907](https://github.com/ClickHouse/ClickHouse/issues/21907)。[#22322](https://github.com/ClickHouse/ClickHouse/pull/22322) ([Ivan](https://github.com/abyss7)).
* 已在 [#22531](https://github.com/ClickHouse/ClickHouse/issues/22531) 中回移：`tokenbf_v1` 全文索引中读取时可能发生缓冲区溢出。多读出的字节不会被使用，但在极少数情况下，读取操作可能导致崩溃。关闭 [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233)。[#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#22463](https://github.com/ClickHouse/ClickHouse/issues/22463) 中回移：为并行解析过程补充了缺失的内存统计。在之前的版本中，当结果集包含非常大的数据块时，可能发生 OOM。关闭 [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008)。[#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#22507](https://github.com/ClickHouse/ClickHouse/issues/22507) 中回移：在 HedgedConnections 中取消 packet receiver 之前，先将套接字从 epoll 中移除，以防止可能的竞态条件。希望这能修复 [#22161](https://github.com/ClickHouse/ClickHouse/issues/22161)。[#22443](https://github.com/ClickHouse/ClickHouse/pull/22443) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#22554](https://github.com/ClickHouse/ClickHouse/issues/22554) 中回移：修复 partial merge join 与 `LowCardinality` 相关的 bug。关闭 [#22386](https://github.com/ClickHouse/ClickHouse/issues/22386)，关闭 [#22388](https://github.com/ClickHouse/ClickHouse/issues/22388)。[#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#22607](https://github.com/ClickHouse/ClickHouse/issues/22607) 中回移：修复 TSV format 中末尾没有换行符的空字符串反序列化问题。关闭 [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244)。无需升级版本的一种可能变通方法：将 `input_format_null_as_default` 设为零。旧版本中该值就是零。[#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#22576](https://github.com/ClickHouse/ClickHouse/issues/22576) 中回移：通过从同一线程解锁 TinyLog 的 rwlock 来修复 UB。[#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22651](https://github.com/ClickHouse/ClickHouse/issues/22651) 中回移：避免 *Log engines 中因由其他线程解锁 rwlock 而导致的 UB。[#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22653](https://github.com/ClickHouse/ClickHouse/issues/22653) 中回移：仅在写入缓冲区已初始化时才尝试执行 flush。修复客户端过早关闭连接时出现的 segfault [#22579](https://github.com/ClickHouse/ClickHouse/issues/22579)。[#22591](https://github.com/ClickHouse/ClickHouse/pull/22591) ([nvartolomei](https://github.com/nvartolomei)).
* 已在 [#22681](https://github.com/ClickHouse/ClickHouse/issues/22681) 中回移：修复在 SELECT 子句中不包含列时，Log 处理嵌套类型会出现 LOGICAL&#95;ERROR 的问题。[#22654](https://github.com/ClickHouse/ClickHouse/pull/22654) ([Azat Khuzhin](https://github.com/azat)).
