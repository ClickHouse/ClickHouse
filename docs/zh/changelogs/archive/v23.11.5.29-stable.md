<div id="improvement">
  #### 改进
</div>

* 已在 [#58815](https://github.com/ClickHouse/ClickHouse/issues/58815) 中回移：新增 `SYSTEM JEMALLOC PURGE`，用于清除未使用的 jemalloc 页；新增 `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE`，用于在启用 Profiler 时控制 jemalloc profile。还在 Keeper 中新增了与 jemalloc 相关的 4LW 命令：`jmst` 用于转储 jemalloc 统计信息，`jmfp`、`jmep`、`jmdp` 用于在启用 Profiler 时控制 jemalloc profile。[#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#59234](https://github.com/ClickHouse/ClickHouse/issues/59234) 中回移：允许在 Iceberg 表引擎中忽略 schema evolution，并在读取所有数据时使用用户建表时指定的 schema，或建表时从元数据中解析出的最新 schema。该功能通过设置 `iceberg_engine_ignore_schema_evolution` 实现，默认禁用。请注意，启用此设置可能导致结果不正确，因为在 schema 已演化的情况下，所有数据文件都会使用同一个 schema 读取。[#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)) 。
