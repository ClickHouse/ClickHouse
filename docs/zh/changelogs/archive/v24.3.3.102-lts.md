<div id="improvement">
  #### 改进
</div>

* 已在 [#62188](https://github.com/ClickHouse/ClickHouse/issues/62188) 中回移：strictness 为 `ANY` 的 StorageJoin 在重新加载后仍能保持一致性。当插入多行具有相同键的行时，第一行的优先级最高 (此前会在表加载时随机选取) 。已关闭 [#51027](https://github.com/ClickHouse/ClickHouse/issues/51027)。[#61972](https://github.com/ClickHouse/ClickHouse/pull/61972) ([vdimir](https://github.com/vdimir)) 。
* 已在 [#62443](https://github.com/ClickHouse/ClickHouse/issues/62443) 中回移：客户端必须向服务器发送请求头 &#39;Keep-Alive: timeout=X&#39;。如果客户端收到服务器返回的、带有该请求头的响应，则必须使用服务器提供的值。此外，客户端最好不要使用即将过期的连接，以避免发生连接关闭竞态。[#62249](https://github.com/ClickHouse/ClickHouse/pull/62249) ([Sema Checherinda](https://github.com/CheSema)) 。
* 已在 [#62666](https://github.com/ClickHouse/ClickHouse/issues/62666) 中回移：S3 存储和备份同样需要采用与 S3 disk 相同的默认 Keep-Alive 设置。[#62648](https://github.com/ClickHouse/ClickHouse/pull/62648) ([Sema Checherinda](https://github.com/CheSema)) 。
