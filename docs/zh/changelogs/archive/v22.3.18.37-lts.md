<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#46372](https://github.com/ClickHouse/ClickHouse/issues/46372) 中回移：修复非远程磁盘上垂直合并时内存占用过高的问题。对远程磁盘遵循 `max_insert_delayed_streams_for_parallel_write`。[#46275](https://github.com/ClickHouse/ClickHouse/pull/46275) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#46357](https://github.com/ClickHouse/ClickHouse/issues/46357) 中回移：允许对 Compact 格式的 parts 使用 Vertical merge algorithm。这将使 ClickHouse server 在后台操作中占用更少内存。此变更关闭了 [#46084](https://github.com/ClickHouse/ClickHouse/issues/46084)。[#46282](https://github.com/ClickHouse/ClickHouse/pull/46282) ([Anton Popov](https://github.com/CurtizJ)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#45856](https://github.com/ClickHouse/ClickHouse/issues/45856) 中回移：修复 ZooKeeper 下载问题，更新版本，并优化镜像体积。[#44853](https://github.com/ClickHouse/ClickHouse/pull/44853) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#45620](https://github.com/ClickHouse/ClickHouse/issues/45620) 中回移：修复了读取远程文件系统中的 `LowCardinality` 字典时可能出现的 `Cannot read all data` 错误。修复了 [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709)。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#45549](https://github.com/ClickHouse/ClickHouse/issues/45549) 中回移：修复了当存在结构有误的字典 (例如 xml 配置中的类型不正确) 时，执行 `SELECT ... FROM system.dictionaries` 会抛出异常的问题。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
