* 已在 [#26297](https://github.com/ClickHouse/ClickHouse/issues/26297) 中回移：修复了 ClickHouse 在查询执行期间发生异常时，通过 MySQL 协议数据包发送错误 `sequence_id` 的问题。该问题可能导致 MySQL 客户端重置与 ClickHouse server 的连接。修复了 [#21184](https://github.com/ClickHouse/ClickHouse/issues/21184)。[#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#26356](https://github.com/ClickHouse/ClickHouse/issues/26356) 中回移：修复了带 totals 的 join 中出现的 logical error，关闭 [#26017](https://github.com/ClickHouse/ClickHouse/issues/26017)。[#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#26359](https://github.com/ClickHouse/ClickHouse/issues/26359) 中回移：修复了丢失副本恢复过程中一个罕见的 bug，该问题可能导致副本出现分歧。[#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#26419](https://github.com/ClickHouse/ClickHouse/issues/26419) 中回移：修复了以已删除用户身份登录时可能发生的 crash。此 PR 修复了 [#26073](https://github.com/ClickHouse/ClickHouse/issues/26073)。[#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#26413](https://github.com/ClickHouse/ClickHouse/issues/26413) 中回移：修复了 `partial_merge_join` 中未 join 的块 stream 无限持续的问题，关闭 [#26325](https://github.com/ClickHouse/ClickHouse/issues/26325)。[#26374](https://github.com/ClickHouse/ClickHouse/pull/26374) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#26447](https://github.com/ClickHouse/ClickHouse/issues/26447) 中回移：修复了某些模糊测试触发的 msan crash。修复了 [#22517](https://github.com/ClickHouse/ClickHouse/issues/22517)。[#26428](https://github.com/ClickHouse/ClickHouse/pull/26428) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
