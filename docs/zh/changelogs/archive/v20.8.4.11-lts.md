<div id="clickhouse-release-v208411-lts-fixme-as-compared-to-v208318-stable">
  ### ClickHouse 发布 v20.8.4.11-lts FIXME，相较于 v20.8.3.18-stable
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#15569](https://github.com/ClickHouse/ClickHouse/issues/15569) 中回移：现在可以通过 `ALTER` 查询更改 `VersionedCollapsingMergeTree` 的版本列类型。[#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)) 。



<div id="bug-fix">
  #### 问题修复
</div>

* 已在 [#15017](https://github.com/ClickHouse/ClickHouse/issues/15017) 中回移：修复了 `Nullable` 列排序顺序不正确的问题。此修复解决了 [#14344](https://github.com/ClickHouse/ClickHouse/issues/14344)。[#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已在 [#14823](https://github.com/ClickHouse/ClickHouse/issues/14823) 中回移：修复了有符号类型收缩 `Int -> Int` 转换时单调性检测错误的问题，该问题可能导致查询结果不正确。此 bug 在 [#14513](https://github.com/ClickHouse/ClickHouse/issues/14513) 中被发现。[#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#15148](https://github.com/ClickHouse/ClickHouse/issues/15148) 中回移：修复了使用 `from_zk` 包含选项从 ZooKeeper 获取配置文件时，服务器启动过程中可能卡死的问题。此修复解决了 [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814)。[#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 已在 [#15251](https://github.com/ClickHouse/ClickHouse/issues/15251) 中回移：修复了 CacheDictionary 中的段错误 [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837)。[#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已在 [#14955](https://github.com/ClickHouse/ClickHouse/issues/14955) 中回移：修复了使用 `MaterializeMySQL` 数据库引擎时出现的 `.metadata.tmp File exists` 错误。[#14898](https://github.com/ClickHouse/ClickHouse/pull/14898) ([Winter Zhang](https://github.com/zhang2014))。
* 已在 [#14987](https://github.com/ClickHouse/ClickHouse/issues/14987) 中回移：在 `system.asynchronous_metrics` 中发布每个逻辑核心的 CPU 频率。此修复解决了 [#14923](https://github.com/ClickHouse/ClickHouse/issues/14923)。[#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 已在 [#14969](https://github.com/ClickHouse/ClickHouse/issues/14969) 中回移：修复了子查询包含 finalizeAggregation 函数时谓词下推无法正常工作的问题。修复了 [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847)。[#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov))。
* 已在 [#15053](https://github.com/ClickHouse/ClickHouse/issues/15053) 中回移：现在设置项 `number_of_free_entries_in_pool_to_execute_mutation` 和 `number_of_free_entries_in_pool_to_lower_max_size_of_merge` 可以等于 `background_pool_size`。[#14975](https://github.com/ClickHouse/ClickHouse/pull/14975) ([alesapin](https://github.com/alesapin))。
* 已在 [#15077](https://github.com/ClickHouse/ClickHouse/issues/15077) 中回移：修复了在 `join_algorithm='auto'` 模式下执行 RIGHT 或 FULL JOIN 时，因超出内存限制需将 HashJoin 切换为 MergeJoin 而导致崩溃的问题。[#15002](https://github.com/ClickHouse/ClickHouse/pull/15002) ([Artem Zuikov](https://github.com/4ertus2))。
* 已在 [#15102](https://github.com/ClickHouse/ClickHouse/issues/15102) 中回移：修复了在 Mac OS 上的 Docker 中运行 clickhouse-server 时，在 Atomic 数据库中执行 DDL 查询时出现的 `Cannot rename ... errno: 22, strerror: Invalid argument` 错误。[#15024](https://github.com/ClickHouse/ClickHouse/pull/15024) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#15056](https://github.com/ClickHouse/ClickHouse/issues/15056) 中回移：修复了使用特定构造的参数调用函数 `bar` 时可能发生缓冲区溢出的问题。此修复关闭了 [#13926](https://github.com/ClickHouse/ClickHouse/issues/13926)。[#15028](https://github.com/ClickHouse/ClickHouse/pull/15028) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#15049](https://github.com/ClickHouse/ClickHouse/issues/15049) 中回移：String 与 FixedString 之间已使用填充比较（https://github.com/ClickHouse/ClickHouse/blob/master/src/Functions/FunctionsComparison.h#L333）。此 PR 将相同逻辑应用于字段比较，从而修正了将 FixedString 用作主键时的行为。此修复解决了 [#14908](https://github.com/ClickHouse/ClickHouse/issues/14908)。[#15033](https://github.com/ClickHouse/ClickHouse/pull/15033) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#15142](https://github.com/ClickHouse/ClickHouse/issues/15142) 中回移：修复了 `join_algorithm='auto'` 模式下出现的 `Data compressed with different methods` 错误。在 `join_algorithm='partial_merge'` 模式下，保留左表 join 键的 LowCardinality 类型。[#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2))。
* 已在 [#15208](https://github.com/ClickHouse/ClickHouse/issues/15208) 中回移：调整了 MySQL 列定义数据包中 decimals 字段的大小。[#15152](https://github.com/ClickHouse/ClickHouse/pull/15152) ([maqroll](https://github.com/maqroll))。
* 已在 [#15222](https://github.com/ClickHouse/ClickHouse/issues/15222) 中回移：修复了表引擎 `Buffer` 中的 bug，该 bug 导致执行 `ALTER` 查询后无法向 `Buffer` 插入新结构的数据。修复了 [#15117](https://github.com/ClickHouse/ClickHouse/issues/15117)。[#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin))。
* 已在 [#15405](https://github.com/ClickHouse/ClickHouse/issues/15405) 中回移：修复了将 joinGet 与 LowCardinality 类型一起使用时实例崩溃的问题。此修复解决了 [#15214](https://github.com/ClickHouse/ClickHouse/issues/15214)。[#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#15489](https://github.com/ClickHouse/ClickHouse/issues/15489) 中回移：修复了查询在 Merge 表上执行 JOIN 时 GROUP BY 中出现"Unknown identifier"的问题。[#15242](https://github.com/ClickHouse/ClickHouse/pull/15242) ([Artem Zuikov](https://github.com/4ertus2))。
* 已在 [#15281](https://github.com/ClickHouse/ClickHouse/issues/15281) 中回移：修复了 QueryLog 中的 MSan 报告问题，`memory_usage` 字段可能使用未初始化的内存。[#15258](https://github.com/ClickHouse/ClickHouse/pull/15258) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#15402](https://github.com/ClickHouse/ClickHouse/issues/15402) 中回移：修复了对 `MySQL` 引擎同一张表包含大量子查询时查询挂起的问题。此前，若查询中对同一 `MySQL` 表的子查询超过 16 个，查询将永久挂起。[#15299](https://github.com/ClickHouse/ClickHouse/pull/15299) ([Anton Popov](https://github.com/CurtizJ))。

* 已在 [#15334](https://github.com/ClickHouse/ClickHouse/issues/15334) 中回移：修复了 MergeTree 表重命名与后台清理过程中的竞态条件。[#15304](https://github.com/ClickHouse/ClickHouse/pull/15304) ([alesapin](https://github.com/alesapin))。
