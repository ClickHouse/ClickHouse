* 已在 [#74955](https://github.com/ClickHouse/ClickHouse/issues/74955) 中回移：修复在 Azure Blob 存储中，对带有空列的表执行数据分区片段合并时出现 FILE&#95;DOESNT&#95;EXIST 错误的问题。[#74892](https://github.com/ClickHouse/ClickHouse/pull/74892) ([Julia Kartseva](https://github.com/jkartseva)).
* 已在 [#75052](https://github.com/ClickHouse/ClickHouse/issues/75052) 中回移：在 HDFS select 请求期间发生 SASL 错误时刷新 HDFS krb ticket。[#74930](https://github.com/ClickHouse/ClickHouse/pull/74930) ([inv2004](https://github.com/inv2004)).
* 已在 [#75412](https://github.com/ClickHouse/ClickHouse/issues/75412) 中回移：当 remove 操作失败时，将 part 的状态从 deleting 恢复为过期。[#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#75405](https://github.com/ClickHouse/ClickHouse/issues/75405) 中回移：修复在启用设置 `optimize_function_to_subcolumns` 时，`Array`、`Map` 和 `Nullable(..)` 列对索引 (主索引和次级索引) 的使用问题。此前，这些列的索引可能会被忽略。[#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#75458](https://github.com/ClickHouse/ClickHouse/issues/75458) 中回移：修复包含 Insert 的 CTE 崩溃问题。[#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).
* 已在 [#75481](https://github.com/ClickHouse/ClickHouse/issues/75481) 中回移：隐藏 `icebergS3`、`icebergAzure` 表函数和表引擎中的敏感信息。[#75378](https://github.com/ClickHouse/ClickHouse/pull/75378) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
