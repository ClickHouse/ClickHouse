<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#26787](https://github.com/ClickHouse/ClickHouse/issues/26787) 中回移：修复内部 buffer 末尾存在转义序列时 zstd 解压缩失败的问题。关闭 [#26013](https://github.com/ClickHouse/ClickHouse/issues/26013)。[#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#26487](https://github.com/ClickHouse/ClickHouse/issues/26487) 中回移：修复重写列别名后名称解析错误的问题。此修复解决了 [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432)。[#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#26615](https://github.com/ClickHouse/ClickHouse/issues/26615) 中回移：修复当字典名或数据库名带引号时，`CREATE DICTIONARY` 查询出现问题的情况。关闭 [#26491](https://github.com/ClickHouse/ClickHouse/issues/26491)。[#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#26606](https://github.com/ClickHouse/ClickHouse/issues/26606) 中回移：修复在 rabbitmq setup 未启动时关闭 rabbitmq 发生崩溃的问题。关闭 [#26504](https://github.com/ClickHouse/ClickHouse/issues/26504)。[#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#26612](https://github.com/ClickHouse/ClickHouse/issues/26612) 中回移：更新 clickhouse-server docker 入口点中的 `chown` cmd check。修复了 Kubernetes 上集群 pod (容器组) 重启失败 (或超时) 的问题。[#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix)) 。
* 已在 [#26647](https://github.com/ClickHouse/ClickHouse/issues/26647) 中回移：修复 groupBitmapAnd/Or/Xor 的函数名错误。[#26557](https://github.com/ClickHouse/ClickHouse/pull/26557) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#26704](https://github.com/ClickHouse/ClickHouse/issues/26704) 中回移：修复窗口函数中潜在的空指针解引用问题。此修复解决了 [#25276](https://github.com/ClickHouse/ClickHouse/issues/25276)。[#26668](https://github.com/ClickHouse/ClickHouse/pull/26668) ([Alexander Kuzmenkov](https://github.com/akuzm)) 。
* 已在 [#26772](https://github.com/ClickHouse/ClickHouse/issues/26772) 中回移：修复了 SET ROLE 偶尔工作不正确的问题。[#26707](https://github.com/ClickHouse/ClickHouse/pull/26707) ([Vitaly Baranov](https://github.com/vitlibar)) 。
