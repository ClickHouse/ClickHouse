  ### ClickHouse 发布稳定版本 v20.12.7.3-stable FIXME，与 v20.12.6.29-stable 相比
</div>

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#20683](https://github.com/ClickHouse/ClickHouse/issues/20683) 中回移：如果将空字符串作为 IV 传入，encrypt/decrypt 函数中可能会读取未初始化的内存。此项关闭了 [#19391](https://github.com/ClickHouse/ClickHouse/issues/19391)。[#19397](https://github.com/ClickHouse/ClickHouse/pull/19397) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#20635](https://github.com/ClickHouse/ClickHouse/issues/20635) 中回移：修复了一个罕见缺陷，即数据损坏后，某些复制相关操作 (如变更) 将无法处理某些 parts。修复了 [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593)。[#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#20617](https://github.com/ClickHouse/ClickHouse/issues/20617) 中回移：检查表函数 `view` 是否在表达式列表中使用，并抛出错误。此项修复了 [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342)。[#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#20487](https://github.com/ClickHouse/ClickHouse/issues/20487) 中回移：修复了当 JOIN 包含来自 SELECT 的 const 时，`join_use_nulls=1` 会触发 `LOGICAL_ERROR` 的问题。[#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#20614](https://github.com/ClickHouse/ClickHouse/issues/20614) 中回移：为 async INSERT 解析目录名称时添加了适当的检查 (修复 SIGSEGV) 。[#20498](https://github.com/ClickHouse/ClickHouse/pull/20498) ([Azat Khuzhin](https://github.com/azat)) 。
