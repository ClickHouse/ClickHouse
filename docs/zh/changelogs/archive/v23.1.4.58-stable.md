<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (正式稳定版本中的异常表现)
</div>

* 已在 [#46228](https://github.com/ClickHouse/ClickHouse/issues/46228) 中回移：`c-ares` 相关场景中已报告了几个段错误。最近观察到的所有堆栈跟踪都失败在向 `std::unodered_set<>` 插入时。我认为已经找到了根本原因，似乎是查询未被处理。在此 PR 之前，CH 会调用 `poll` 来等待 `c-ares` 通道中的文件描述符。根据 [poll 文档](https://man7.org/linux/man-pages/man2/poll.2.html)，返回负值表示发生了错误。因此，我们会中止执行并返回失败。问题在于，发生系统中断时，`poll` 也会返回负值。系统中断并不意味着处理失败或结束，但由于我们只检查返回值是否为负，仍然会中止执行。执行一旦中止，整个调用栈都会被销毁，其中包括作为 `void *` 参数传给 c-ares 回调的 `std::unordered_set<std::string>`。等到 c-ares 完成该请求后，回调就会被触发，并访问无效内存地址，从而导致段错误。[#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos)) 。
* 已在 [#46967](https://github.com/ClickHouse/ClickHouse/issues/46967) 中回移：向后兼容——允许从 UInt64 到 IPv4 的隐式窄化转换，这是 `"INSERT ... VALUES ..."` 表达式所必需的。[#45865](https://github.com/ClickHouse/ClickHouse/pull/45865) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)) 。
* 已在 [#46220](https://github.com/ClickHouse/ClickHouse/issues/46220) 中回移：修复在 compact parts 中读取不存在的多层 Nested 列时的问题。[#46045](https://github.com/ClickHouse/ClickHouse/pull/46045) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#46751](https://github.com/ClickHouse/ClickHouse/issues/46751) 中回移：对将 Replace domain IP 类型 (IPv4、IPv6) 替换为原生类型的后续修复：[https://github.com/ClickHouse/ClickHouse/pull/43221](https://github.com/ClickHouse/ClickHouse/pull/43221)。[#46087](https://github.com/ClickHouse/ClickHouse/pull/46087) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)) 。
* 已在 [#46448](https://github.com/ClickHouse/ClickHouse/issues/46448) 中回移：修复异步插入中发送 `VALUES` 格式的无效数据时可能出现的 `LOGICAL_ERROR`。[#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ)) 。
