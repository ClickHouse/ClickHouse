* 已在 [#74077](https://github.com/ClickHouse/ClickHouse/issues/74077) 中回移：允许修改 S3(Azure)Queue 存储中的 commit 设置。 (commit 设置包括：max&#95;processed&#95;files&#95;before&#95;commit、max&#95;processed&#95;rows&#95;before&#95;commit、max&#95;processed&#95;bytes&#95;before&#95;commit、max&#95;processing&#95;time&#95;sec&#95;before&#95;commit) 。[#73635](https://github.com/ClickHouse/ClickHouse/pull/73635) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#74160](https://github.com/ClickHouse/ClickHouse/issues/74160) 中回移：避免在 `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` 后出现停顿；并为后台任务调度获取正确的设置。 [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 已在 [#74143](https://github.com/ClickHouse/ClickHouse/issues/74143) 中回移：将格式设置传递给 TCPHandler 中的 NativeWriter，使 `output_format_native_write_json_as_string` 之类的设置能够被正确应用。 [#73179](https://github.com/ClickHouse/ClickHouse/pull/73179) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#73895](https://github.com/ClickHouse/ClickHouse/issues/73895) 中回移：修复 Dynamic 列和 JSON 列在 squashin 准备阶段的问题。此前在某些情况下，即使尚未达到 types/paths 的限制，新类型也可能被插入到 shared variant/shared data 中。 [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74441](https://github.com/ClickHouse/ClickHouse/issues/74441) 中回移：修复当字典的数据源包含带有错误数据的函数时发生的 segfault。 [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已在 [#73799](https://github.com/ClickHouse/ClickHouse/issues/73799) 中回移：修复 Dynamic 列中可能出现的数据不一致问题。修复了可能出现的逻辑错误 `Nested columns sizes are inconsistent with local_discriminators column size`。 [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74029](https://github.com/ClickHouse/ClickHouse/issues/74029) 中回移：修复 Dynamic/Object 结构的反序列化问题。该问题可能导致 CANNOT&#95;READ&#95;ALL&#95;DATA 异常。 [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74100](https://github.com/ClickHouse/ClickHouse/issues/74100) 中回移：修复了 [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078) (S3 Express Support 已失效) 的问题。 [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* 已在 [#74092](https://github.com/ClickHouse/ClickHouse/issues/74092) 中回移：修复隐式特权的问题 (此前其行为类似通配符) 。 [#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#74044](https://github.com/ClickHouse/ClickHouse/issues/74044) 中回移：修复创建嵌套 Map 时内存占用过高的问题。 [#73982](https://github.com/ClickHouse/ClickHouse/pull/73982) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#74057](https://github.com/ClickHouse/ClickHouse/issues/74057) 中回移：修复以下问题：如果某个别名被另一个别名引用，且其选择顺序相反，则该别名可能不会被添加到 projection 中。 [#74033](https://github.com/ClickHouse/ClickHouse/pull/74033) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#74110](https://github.com/ClickHouse/ClickHouse/issues/74110) 中回移：使用 plain&#95;rewritable metadata 的 disk 可以在多个 server instance 之间共享。一个实例读取元数据对象、另一个实例对其进行修改，属于预期行为。在使用 Azure storage 初始化 plain&#95;rewritable 时，会忽略 object not found 错误，这与 S3 的实现行为类似。 [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* 已在 [#74136](https://github.com/ClickHouse/ClickHouse/issues/74136) 中回移：修复了用户在 Kafka 表引擎中指定关键字参数时出现的问题。[#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* 已在 [#74179](https://github.com/ClickHouse/ClickHouse/issues/74179) 中回移：修复了从压缩后的 Memory 引擎表中读取子列时发生崩溃的问题。修复了 [#74009](https://github.com/ClickHouse/ClickHouse/issues/74009)。[#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat))。
