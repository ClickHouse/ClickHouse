<div id="improvement">
  #### 改进
</div>

* 已在 [#40817](https://github.com/ClickHouse/ClickHouse/issues/40817) 中回移：设置 `show_addresses_in_stack_traces` 曾在默认 `config.xml` 中被意外禁用。现已将其从配置中移除，因此该设置现默认启用。[#40749](https://github.com/ClickHouse/ClickHouse/pull/40749) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#40944](https://github.com/ClickHouse/ClickHouse/issues/40944) 中回移：修复了 MySQL 数据库引擎 和 MySQL 表函数传递 MySQL 超时参数时的问题。关闭了 [#34168](https://github.com/ClickHouse/ClickHouse/issues/34168)?notification&#95;referrer&#95;id=NT&#95;kwDOAzsV57MzMDMxNjAzNTY5OjU0MjAzODc5。[#40751](https://github.com/ClickHouse/ClickHouse/pull/40751) ([Kseniia Sumarokova](https://github.com/kssenii)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进

* 已在 [#41157](https://github.com/ClickHouse/ClickHouse/issues/41157) 中回移：将 macOS 二进制文件添加到 GH 发布资源中，修复了 [#37718](https://github.com/ClickHouse/ClickHouse/issues/37718)。[#41088](https://github.com/ClickHouse/ClickHouse/pull/41088) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (正式稳定版本中用户可见的异常表现)
</div>

* 已在 [#40866](https://github.com/ClickHouse/ClickHouse/issues/40866) 中回移：修复了解析包含可变维度数组的 `Object` 类型值时发生的崩溃。 [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* 已在 [#40805](https://github.com/ClickHouse/ClickHouse/issues/40805) 中回移：向 `ProcessList` 插入新查询时会发生内存分配。如果在这些分配过程中达到内存限制，则无法使用 `OvercommitTracker`，因为 `ProcessList::mutex` 已经被持有。修复了 [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)。 [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#40777](https://github.com/ClickHouse/ClickHouse/issues/40777) 中回移：修复了在没有查询上下文时向 MV 推送 (来自 Kafka/...) 导致的内存泄漏。 [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#41135](https://github.com/ClickHouse/ClickHouse/issues/41135) 中回移：修复了 `DESCRIBE TABLE url()` 以及其他一些 `DESCRIBE TABLE <table_function>()` 的访问权限问题。 [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#41242](https://github.com/ClickHouse/ClickHouse/issues/41242) 中回移：修复了将数据库引擎从 Ordinary 自动转换为 Atomic 时出现的 “possible deadlock avoided” 错误。 [#41146](https://github.com/ClickHouse/ClickHouse/pull/41146) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#41234](https://github.com/ClickHouse/ClickHouse/issues/41234) 中回移：修复了对损坏 detached parts 的后台清理问题。 [#41190](https://github.com/ClickHouse/ClickHouse/pull/41190) ([Kseniia Sumarokova](https://github.com/kssenii)).
