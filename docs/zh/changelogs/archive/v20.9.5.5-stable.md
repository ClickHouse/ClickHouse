  ### ClickHouse 版本 v20.9.5.5-稳定版本 FIXME (相较于 v20.9.4.76-稳定版本)
</div>

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493) 中回移：修复 MySQL 数据库相关问题。当作为数据库引擎使用的 MySQL 服务器不可用时，某些查询会抛出 Exception，因为它们会尝试从已禁用的服务器获取表，而实际上这并不必要。例如，查询 `SELECT ... FROM system.parts` 应当只处理 MergeTree 表，完全不应访问 MySQL 数据库。[#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817) 中回移：修复了一种行为不一致的问题：由于用于过滤的集合未创建，返回数据的一部分可能会被丢弃。[#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508) 中回移：修复复制队列中特大条目的处理问题。如果表结构特别大 (接近 1 MB) ，ALTER 查询中可能会出现非常大的条目。此修复解决了 [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307)。[#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474) 中回移：修复 Distributed 的 DROP TABLE 问题 (与 INSERT 存在竞争条件) 。[#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571) 中回移：修复在使用 MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine，且 MySQL Slave 启用了 `slave_parallel_worker` 时，元数据快速增长的问题，方法是正确缩减 GTID sets。此修复解决了 [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951)。[#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)) 。
* 已在 [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554) 中回移：现在从输入中解析 AVRO 时，会从类型中移除 LowCardinality。修复了 [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188)。[#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)) 。
* 已在 [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748) 中回移：修复了 [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081)。[#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894) 中回移：修复了这样一种少见的静默 crash：当启用查询分析器，且 ClickHouse 安装在某个 glibc 版本 (推测) 对部分函数的异步栈展开表存在缺陷的操作系统上时，可能发生该问题。此修复解决了 [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301)。此修复解决了 [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098)。[#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
