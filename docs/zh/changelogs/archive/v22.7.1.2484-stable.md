<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 默认启用 `enable_positional_arguments` 设置。它允许使用 `SELECT ... ORDER BY 1, 2` 这类查询，其中 1、2 表示对 SELECT clause 的引用。如果需要恢复旧行为，请禁用此设置。[#38204](https://github.com/ClickHouse/ClickHouse/pull/38204) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Ordinary` 数据库引擎以及 `*MergeTree` 表的旧存储定义语法已弃用。默认情况下，无法再创建新的此类对象。如果 `system` database 使用 `Ordinary` engine，则会在 server 启动时自动转换为 `Atomic`。可以通过设置 (`allow_deprecated_database_ordinary` 和 `allow_deprecated_syntax_for_merge_tree`) 保留旧行为，但这些设置可能会在未来的发行版中被移除。[#38335](https://github.com/ClickHouse/ClickHouse/pull/38335) ([Alexander Tokmakov](https://github.com/tavplubix)).
* * 默认会强制将逗号 join 改写为 inner (即默认值设为 `cross_to_inner_join_rewrite = 2`) 。如需保留旧行为，请将 `cross_to_inner_join_rewrite` 设为 `1`。[#39326](https://github.com/ClickHouse/ClickHouse/pull/39326) ([Vladimir C](https://github.com/vdimir)).
* 默认禁用 `format_csv_allow_single_quotes`。[#37096](https://github.com/ClickHouse/ClickHouse/issues/37096). [#39423](https://github.com/ClickHouse/ClickHouse/pull/39423) ([Kruglov Pavel](https://github.com/Avogar)).

* 允许在列列表中使用尾随逗号。关闭 [#38425](https://github.com/ClickHouse/ClickHouse/issues/38425)。[#38440](https://github.com/ClickHouse/ClickHouse/pull/38440) ([chen](https://github.com/xiedeyantu)) 。
* 将 clickhouse 压缩为自解压可执行文件 (路径为 programs/self-extracting) 。新增构建目标 &#39;self-extracting&#39;。[#38447](https://github.com/ClickHouse/ClickHouse/pull/38447) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)) 。
* 新增设置 `additional_table_filters`。使用此设置，您可以为表指定额外的过滤条件，并在读取后立即应用。示例：`select number, x, y from (select number from system.numbers limit 5) f any left join (select x, y from table_1) s on f.number = s.x settings additional_table_filters={'system.numbers : 'number != 3', 'table_1' : 'x != 2'}`。同时新增设置 `additional_result_filter`，用于为查询结果指定额外的过滤条件。关闭 [#37918](https://github.com/ClickHouse/ClickHouse/issues/37918)。[#38475](https://github.com/ClickHouse/ClickHouse/pull/38475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 新增 SQLInsert 输出格式。关闭 [#38441](https://github.com/ClickHouse/ClickHouse/issues/38441)。[#38477](https://github.com/ClickHouse/ClickHouse/pull/38477) ([Kruglov Pavel](https://github.com/Avogar)).
* 可下载的 ClickHouse Executable 现为压缩的自解压文件。[#38653](https://github.com/ClickHouse/ClickHouse/pull/38653) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

* 新增函数 `translate(string, from_string, to_string)` 和 `translateUTF8(string, from_string, to_string)`。[#38935](https://github.com/ClickHouse/ClickHouse/pull/38935) ([Nikolay Degterinsky](https://github.com/evillique)).
* 新增 `compatibility` 设置和 `system.settings_changes` 系统表，其中包含各个 ClickHouse 版本中的设置变更信息。关闭 [#35972](https://github.com/ClickHouse/ClickHouse/issues/35972)。[#38957](https://github.com/ClickHouse/ClickHouse/pull/38957) ([Kruglov Pavel](https://github.com/Avogar)).
* 为 tupleElement 函数新增第 3 个参数；如果 tuple 不包含该成员，则返回此参数。仅当第 2 个参数的类型为 String 时生效。关闭 [#38872](https://github.com/ClickHouse/ClickHouse/issues/38872)。[#38989](https://github.com/ClickHouse/ClickHouse/pull/38989) ([lokax](https://github.com/lokax)).
* 支持 parseTimedelta 函数。其用法如下：&#96;&#96;&#96;sql # &#39; &#39;, &#39;;&#39;, &#39;-&#39;, &#39;+&#39;, &#39;,&#39;, &#39;:&#39; 可用作分隔符，例如 &quot;1yr-2mo&quot;、&quot;2m:6s&quot; SELECT parseTimeDelta(&#39;1yr-2mo-4w + 12 days, 3 hours : 1 minute ; 33 seconds&#39;);。[#39071](https://github.com/ClickHouse/ClickHouse/pull/39071) ([jiahui-97](https://github.com/jiahui-97)).
* 新增用于限制远程存储 IO 操作的选项：`max_remote_read_network_bandwidth_for_server` 和 `max_remote_write_network_bandwidth_for_server`。[#39095](https://github.com/ClickHouse/ClickHouse/pull/39095) ([Sergei Trifonov](https://github.com/serxa)).
* 新增 `send_logs_source_regexp` 设置。将 server 文本日志中源名称与指定 regexp 匹配的日志发送出去。为空表示匹配所有源。[#39161](https://github.com/ClickHouse/ClickHouse/pull/39161) ([Amos Bird](https://github.com/amosbird)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 新增 `local_filesystem_read_method` 方法 `io_uring`，基于异步 Linux [io&#95;uring](https://kernel.dk/io_uring.pdf) 子系统；与默认的 `pread` 方法相比，几乎在所有场景下都能提升读取性能。[#36103](https://github.com/ClickHouse/ClickHouse/pull/36103) ([Saulius Valatka](https://github.com/sauliusvl)).
* 针对已排序列的 distinct 优化：当输入流按 distinct 中的列排序时，使用专用的 distinct 转换。该优化可应用于 pre-distinct、final distinct，或同时应用于两者。初始实现由 @dimarub2000 完成。[#37803](https://github.com/ClickHouse/ClickHouse/pull/37803) ([Igor Nikonov](https://github.com/devcrafter)).
* 为 LZ4 解压新增经过 VBMI 优化的 copyOverlap32Shuffle。[#37891](https://github.com/ClickHouse/ClickHouse/pull/37891) ([Guo Wangyang](https://github.com/guowangy)).
* 使用 `BinaryHeap` 的批次版本，提升了 `ORDER BY`、`MergeTree` 合并以及窗口函数的性能。[#38022](https://github.com/ClickHouse/ClickHouse/pull/38022) ([Maksim Kita](https://github.com/kitaisreal)).
* 修复了由 [https://github.com/ClickHouse/ClickHouse/pull/35616](https://github.com/ClickHouse/ClickHouse/pull/35616) 引入的严重 join 性能回退。值得一提的是，像 ssb queries 这样常见的 join 查询在将近 3 个月里慢了 10 倍，居然一直没人反馈。[#38052](https://github.com/ClickHouse/ClickHouse/pull/38052) ([Amos Bird](https://github.com/amosbird)).
* 从 Intel hyperscan 库迁移到 vectorscan，提升了许多非 x86 平台上的字符串匹配速度。[#38171](https://github.com/ClickHouse/ClickHouse/pull/38171) ([Robert Schulze](https://github.com/rschu1ze)).
* 提高了聚合后执行的查询计划步骤的并行度。[#38295](https://github.com/ClickHouse/ClickHouse/pull/38295) ([Nikita Taranov](https://github.com/nickitat)).
* 提升了向 `JSON` 类型列插入数据的性能。[#38320](https://github.com/ClickHouse/ClickHouse/pull/38320) ([Anton Popov](https://github.com/CurtizJ)).
* 优化了 HashTable 中的插入和查找操作。[#38413](https://github.com/ClickHouse/ClickHouse/pull/38413) ([Nikita Taranov](https://github.com/nickitat)).
* 修复了 [#32493](https://github.com/ClickHouse/ClickHouse/issues/32493) 导致的性能下降问题。[#38417](https://github.com/ClickHouse/ClickHouse/pull/38417) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 使用 SIMD 指令提升了列向量 replicate 的性能。作者 @zzachimed。[#38565](https://github.com/ClickHouse/ClickHouse/pull/38565) ([Maksim Kita](https://github.com/kitaisreal)).
* 数组上的 Norm 和 Distance functions 提速 1.2 到 2 倍。[#38740](https://github.com/ClickHouse/ClickHouse/pull/38740) ([Alexander Gololobov](https://github.com/davenger)).
* 对于带有 ORDER BY (a, b) 的查询，生成的执行计划可能比 ORDER BY a, b 的效率更低。[#38873](https://github.com/ClickHouse/ClickHouse/pull/38873) ([Igor Nikonov](https://github.com/devcrafter)).
* Executable UDF、Executable Dictionary、Executable Storage poll 子进程修复了在子进程终止期间 1 秒的等待问题。[#38929](https://github.com/ClickHouse/ClickHouse/pull/38929) ([Constantine Peresypkin](https://github.com/pkit)).
* * 将过滤器下推到 sorting join 的右侧。[#39123](https://github.com/ClickHouse/ClickHouse/pull/39123) ([Vladimir C](https://github.com/vdimir)).
* 优化了对 system.stack&#95;trace 的访问。[#39177](https://github.com/ClickHouse/ClickHouse/pull/39177) ([Azat Khuzhin](https://github.com/azat)).
