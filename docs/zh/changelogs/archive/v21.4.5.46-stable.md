  # 2022 更新日志

<div id="clickhouse-release-v214546-stable-fixme-as-compared-to-v214430-stable">
  ### ClickHouse 版本 v21.4.5.46-stable FIXME，相比 v21.4.4.30-stable
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#23273](https://github.com/ClickHouse/ClickHouse/issues/23273) 中回移：禁用设置 `use_hedged_requests` 和 `async_socket_for_remote`，因为已有证据表明这两项设置可能会引发问题。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#23234](https://github.com/ClickHouse/ClickHouse/issues/23234) 中回移：如果在 default profile 中启用了 `data_type_default_nullable` setting，server 可能无法启动；该问题现已修复。修复了 [#22573](https://github.com/ClickHouse/ClickHouse/issues/22573)。[#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23407](https://github.com/ClickHouse/ClickHouse/issues/23407) 中回移：如果 subquery 被优化为常量，QueryAliasVisitor 会优先为 ASTWithAlias 使用 alias。修复了 [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924)。修复了 [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401)。[#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#23382](https://github.com/ClickHouse/ClickHouse/issues/23382) 中回移：修复了从 `MaterializeMySQL` 中按 key column 条件查询时出现的 `Not found column` error。修复了 [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432)。[#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23385](https://github.com/ClickHouse/ClickHouse/issues/23385) 中回移：修复了禁用 `input_format_with_names_use_header ` setting 后会丢弃所有 CSVWithNames 格式输入的问题。此修复解决了 [#22406](https://github.com/ClickHouse/ClickHouse/issues/22406)。[#23202](https://github.com/ClickHouse/ClickHouse/pull/23202) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#23287](https://github.com/ClickHouse/ClickHouse/issues/23287) 中回移：修复了当 primary key 不是第一个 attribute 时，无法通过 DDL 创建简单 key 字典的问题。修复了 [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236)。[#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#23451](https://github.com/ClickHouse/ClickHouse/issues/23451) 中回移：修复了在创建和删除 ReplicatedMergeTree 表时一种极少见的 (distributed) 竞态条件。该问题可能会在尝试创建 replicated table 时导致出现 `node doesn't exist` 之类的异常。修复了 [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419)。[#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23426](https://github.com/ClickHouse/ClickHouse/issues/23426) 中回移：修复了收到来自 remote query 的 `unknown packet` 时可能发生的 crash (启用 `async_socket_for_remote` 时) 。可能修复了 [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167)。[#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#23467](https://github.com/ClickHouse/ClickHouse/issues/23467) 中回移：如果列位于 primary key 中 (或是其单调函数) ，且未关闭 `optimize_read_in_order` setting，则带有 `COLLATE` 的 `ORDER BY` 无法正常工作。此修复关闭了 [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379)。旧版本的变通方法：关闭 `optimize_read_in_order` setting。[#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#23509](https://github.com/ClickHouse/ClickHouse/issues/23509) 中回移：移除对单个 `Tuple` 参数的 `argMin` 和 `argMax` 的支持。该代码不具备内存安全性。这个功能是误加入的，而且容易让人困惑。后续可以再以不同名称重新引入这些函数。此修复解决了 [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384)，并回退了 [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359)。[#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#23478](https://github.com/ClickHouse/ClickHouse/issues/23478) 中回移：Kafka 存储现已支持 `arrow` 和 `arrowstream` 格式的消息。[#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)) 。
* 已在 [#23498](https://github.com/ClickHouse/ClickHouse/issues/23498) 中回移：- 修复 `deltaSum` 聚合函数在计数器重置场景下的问题 ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)) 。
* 已在 [#23492](https://github.com/ClickHouse/ClickHouse/issues/23492) 中回移：修复了一个问题：此前不允许从空数组字面量转换为维度大于 1 的数组。关闭 [#14476](https://github.com/ClickHouse/ClickHouse/issues/14476)。[#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)) 。
