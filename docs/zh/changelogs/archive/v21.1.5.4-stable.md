<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#20678](https://github.com/ClickHouse/ClickHouse/issues/20678) 中回移：如果某个文件中存在空数据块，则将分布式批次标记为损坏。[#19449](https://github.com/ClickHouse/ClickHouse/pull/19449) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#20646](https://github.com/ClickHouse/ClickHouse/issues/20646) 中回移：函数 `greatCircleAngle` 在早期版本中会返回不准确的结果。此项修复关闭了 [#19769](https://github.com/ClickHouse/ClickHouse/issues/19769)。[#19789](https://github.com/ClickHouse/ClickHouse/pull/19789) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#20507](https://github.com/ClickHouse/ClickHouse/issues/20507) 中回移：修复了在 JSON 损坏时尝试将整个文件读入内存，从而导致内存分配器抛出异常的问题。修复了 [#19719](https://github.com/ClickHouse/ClickHouse/issues/19719)。[#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#20618](https://github.com/ClickHouse/ClickHouse/issues/20618) 中回移：检查表达式列表中是否使用了表函数 `view`，如果使用则报错。此项修复解决了 [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342)。[#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#20488](https://github.com/ClickHouse/ClickHouse/issues/20488) 中回移：修复了当 JOIN 包含来自 SELECT 的常量时，`join_use_nulls=1` 会触发 `LOGICAL_ERROR` 的问题。[#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#20886](https://github.com/ClickHouse/ClickHouse/issues/20886) 中回移：修复带有 `union distinct` 和 `limit` 子句的子查询。关闭 [#20597](https://github.com/ClickHouse/ClickHouse/issues/20597)。[#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)) 。
* 已在 [#20992](https://github.com/ClickHouse/ClickHouse/issues/20992) 中回移：修复聚合函数中 `-Distinct` 组合器与 `-State` 组合器搭配使用的问题。[#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#20988](https://github.com/ClickHouse/ClickHouse/issues/20988) 中回移：使用 MySQL 5.7 客户端连接到 ClickHouse server 时，`USE database;` 查询无法正常工作，现已修复。修复了 [#18926](https://github.com/ClickHouse/ClickHouse/issues/18926)。[#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
