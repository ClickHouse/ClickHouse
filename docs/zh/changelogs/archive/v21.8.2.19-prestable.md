  ### ClickHouse 版本 v21.8.2.19-prestable FIXME，较 v21.8.1.7409-prestable
</div>

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#26524](https://github.com/ClickHouse/ClickHouse/issues/26524) 中回移：降低了短查询的延迟，这类查询需要从具有大量列的表中读取数据。[#26371](https://github.com/ClickHouse/ClickHouse/pull/26371) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#26283](https://github.com/ClickHouse/ClickHouse/issues/26283) 中回移：修复了 `optimize_skip_unused_shards_rewrite_in` 在非 UInt64 类型上的问题 (否则最终可能会选择错误的分片，或抛出 `Cannot infer type of an empty tuple` 或 `Function tuple requires at least one argument`) 。[#25798](https://github.com/ClickHouse/ClickHouse/pull/25798) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#26587](https://github.com/ClickHouse/ClickHouse/issues/26587) 中回移：修复了从 `MaterializeMySQL` 查询数据时出现的 `Not found column ...` 和 `Missing column ...` 错误。修复了 [#23708](https://github.com/ClickHouse/ClickHouse/issues/23708)、[#24830](https://github.com/ClickHouse/ClickHouse/issues/24830)、[#25794](https://github.com/ClickHouse/ClickHouse/issues/25794)。[#25822](https://github.com/ClickHouse/ClickHouse/pull/25822) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#26190](https://github.com/ClickHouse/ClickHouse/issues/26190) 中回移：修复了 remote() 中从不带函数的列获取分片键时的问题 (此前 `select * from remote('127.1', system.one, dummy)` 会导致 `Unknown column: dummy, there are only columns .` 错误) 。[#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#26284](https://github.com/ClickHouse/ClickHouse/issues/26284) 中回移：修复了在配合 prewhere 使用普通 projection 时可能出现的数据头不匹配问题。此修复解决了 [#26020](https://github.com/ClickHouse/ClickHouse/issues/26020)。[#26038](https://github.com/ClickHouse/ClickHouse/pull/26038) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#26298](https://github.com/ClickHouse/ClickHouse/issues/26298) 中回移：修复了 ClickHouse 在查询执行期间发生异常时发送的 MySQL 协议 packet 中 `sequence_id` 不正确的问题。这可能导致 MySQL client 重置与 ClickHouse server 的连接。修复了 [#21184](https://github.com/ClickHouse/ClickHouse/issues/21184)。[#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#26204](https://github.com/ClickHouse/ClickHouse/issues/26204) 中回移：修复了使用多个 `untuple` 表达式时可能发生的崩溃问题。[#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#26228](https://github.com/ClickHouse/ClickHouse/issues/26228) 中回移：移除了 `system.stack_trace` 表中 `thread_name` 列里的多余换行符。此修复解决了 [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124)。[#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#26358](https://github.com/ClickHouse/ClickHouse/issues/26358) 中回移：修复了带 totals 的 join 中的逻辑错误，关闭 [#26017](https://github.com/ClickHouse/ClickHouse/issues/26017)。[#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#26788](https://github.com/ClickHouse/ClickHouse/issues/26788) 中回移：修复了内部缓冲区末尾存在 escape sequences 时的 zstd 解压问题。关闭 [#26013](https://github.com/ClickHouse/ClickHouse/issues/26013)。[#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#26360](https://github.com/ClickHouse/ClickHouse/issues/26360) 中回移：修复了丢失副本恢复过程中的一个罕见 bug，该 bug 可能导致副本间出现不一致。[#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#26452](https://github.com/ClickHouse/ClickHouse/issues/26452) 中回移：修复 `optimize_distributed_group_by_sharding_key` 在处理多列时的问题 (在 `optimize_skip_unused_shards=1`/`allow_nondeterministic_optimize_skip_unused_shards=1`，且分片键表达式中包含多列时，会导致结果错误) 。[#26353](https://github.com/ClickHouse/ClickHouse/pull/26353) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#26422](https://github.com/ClickHouse/ClickHouse/issues/26422) 中回移：修复使用已删除用户登录时可能发生的崩溃。此 PR 修复了 [#26073](https://github.com/ClickHouse/ClickHouse/issues/26073)。[#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#26417](https://github.com/ClickHouse/ClickHouse/issues/26417) 中回移：修复 `partial_merge_join` 中无限未 JOIN 的块流问题，并关闭 [#26325](https://github.com/ClickHouse/ClickHouse/issues/26325)。[#26374](https://github.com/ClickHouse/ClickHouse/pull/26374) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#26448](https://github.com/ClickHouse/ClickHouse/issues/26448) 中回移：修复某些模糊测试触发的 msan 崩溃。修复了 [#22517](https://github.com/ClickHouse/ClickHouse/issues/22517)。[#26428](https://github.com/ClickHouse/ClickHouse/pull/26428) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#26488](https://github.com/ClickHouse/ClickHouse/issues/26488) 中回移：修复重写列别名后名称解析异常的问题。此修复解决了 [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432)。[#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#26613](https://github.com/ClickHouse/ClickHouse/issues/26613) 中回移：修复在字典名称或数据库名称带引号时，`CREATE DICTIONARY` 查询出现的问题。关闭 [#26491](https://github.com/ClickHouse/ClickHouse/issues/26491)。[#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#26605](https://github.com/ClickHouse/ClickHouse/issues/26605) 中回移：修复在 RabbitMQ 初始化未启动的情况下关闭 RabbitMQ 时发生的崩溃。关闭 [#26504](https://github.com/ClickHouse/ClickHouse/issues/26504)。[#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#26608](https://github.com/ClickHouse/ClickHouse/issues/26608) 中回移：更新 clickhouse-server Docker 入口点中的 `chown` 命令检查。它修复了 Kubernetes 上 cluster pod (容器组) 重启失败 (或超时) 的问题。[#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix)) 。

* 已在 [#26644](https://github.com/ClickHouse/ClickHouse/issues/26644) 中回移：修复文件为空时的 history 文件转换问题。[#26589](https://github.com/ClickHouse/ClickHouse/pull/26589) ([Azat Khuzhin](https://github.com/azat)) 。
