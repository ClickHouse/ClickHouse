<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#18392](https://github.com/ClickHouse/ClickHouse/issues/18392) 中回移：修复服务器以守护进程模式运行时 `system.stack_trace` 表为空的问题。[#17630](https://github.com/ClickHouse/ClickHouse/pull/17630) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#18043](https://github.com/ClickHouse/ClickHouse/issues/18043) 中回移：修复 `topK` aggregate function 中可能出现的 segfault 问题。此变更关闭了 [#17404](https://github.com/ClickHouse/ClickHouse/issues/17404)。[#17845](https://github.com/ClickHouse/ClickHouse/pull/17845) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#18111](https://github.com/ClickHouse/ClickHouse/issues/18111) 中回移：修复 max&#95;distributed&#95;connections 的问题 (影响 `prefer_localhost_replica=1` 和 `max_threads!=max_distributed_connections`) 。[#17848](https://github.com/ClickHouse/ClickHouse/pull/17848) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#18021](https://github.com/ClickHouse/ClickHouse/issues/18021) 中回移：如果查询包含 ARRAY JOIN (因此该查询实际上并不简单) ，简单查询优化会产生错误结果。[#17887](https://github.com/ClickHouse/ClickHouse/pull/17887) ([sundyli](https://github.com/sundy-li)).
* 已在 [#17981](https://github.com/ClickHouse/ClickHouse/issues/17981) 中回移：修复 [#15187](https://github.com/ClickHouse/ClickHouse/issues/15187)，修复 [#17912](https://github.com/ClickHouse/ClickHouse/issues/17912)，为 MaterializeMySQL 支持转换 MySQL 前缀索引。抄送：@tavplubix。[#17944](https://github.com/ClickHouse/ClickHouse/pull/17944) ([Winter Zhang](https://github.com/zhang2014)).
* 已在 [#18078](https://github.com/ClickHouse/ClickHouse/issues/18078) 中回移：修复 S3 URL 解析中的 `std::out_of_range: basic_string` 问题。[#18059](https://github.com/ClickHouse/ClickHouse/pull/18059) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 已在 [#18179](https://github.com/ClickHouse/ClickHouse/issues/18179) 中回移：修复尝试设置 profile 时出现的 `Unknown setting profile` 错误。[#18167](https://github.com/ClickHouse/ClickHouse/pull/18167) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#18359](https://github.com/ClickHouse/ClickHouse/issues/18359) 中回移：修复 [#18186](https://github.com/ClickHouse/ClickHouse/issues/18186)，修复 [#16372](https://github.com/ClickHouse/ClickHouse/issues/16372)，修复 MaterializeMySQL 数据库引擎中唯一键转换导致的 crash。[#18211](https://github.com/ClickHouse/ClickHouse/pull/18211) ([Winter Zhang](https://github.com/zhang2014)).
* 已在 [#18258](https://github.com/ClickHouse/ClickHouse/issues/18258) 中回移：修复 枚举 与 Int 类型之间的键比较问题。此变更修复了 [#17989](https://github.com/ClickHouse/ClickHouse/issues/17989)。[#18214](https://github.com/ClickHouse/ClickHouse/pull/18214) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#18296](https://github.com/ClickHouse/ClickHouse/issues/18296) 中回移：- 修复在双 IPv4/IPv6 协议栈机器上，server 无法访问 `clickhouse-odbc-bridge` 进程的问题；- 修复 ODBC 字典更新使用格式错误的查询执行和/或导致 crash 的问题；可能关闭了 [#14489](https://github.com/ClickHouse/ClickHouse/issues/14489)。[#18278](https://github.com/ClickHouse/ClickHouse/pull/18278) ([Denis Glazachev](https://github.com/traceon)).
