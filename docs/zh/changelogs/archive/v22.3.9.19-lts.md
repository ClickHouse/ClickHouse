<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#39097](https://github.com/ClickHouse/ClickHouse/issues/39097) 中回移：OvercommitTracker 中的任何内存分配都可能导致死锁。由于日志提供的信息帮助不大，因此直接移除了日志。修复了 [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794)。[#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd))。
* 已在 [#39080](https://github.com/ClickHouse/ClickHouse/issues/39080) 中回移：修复了文件系统缓存中的一个缺陷，该问题可能会在某些边界情况下、且缓存容量刚好达到上限时发生。关闭了 [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066)。[#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 已在 [#39149](https://github.com/ClickHouse/ClickHouse/issues/39149) 中回移：修复了向带有已附加 MATERIALIZED VIEW 且启用了设置 `extremes = 1` 的表执行 INSERT 时，可能出现的错误 `Block structure mismatch`。关闭了 [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) 和 [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729)。[#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#39372](https://github.com/ClickHouse/ClickHouse/issues/39372) 中回移：声明 RabbitMQ 队列时不再使用默认参数 `x-max-length` 和 `x-overflow`。[#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko))。
* 已在 [#39379](https://github.com/ClickHouse/ClickHouse/issues/39379) 中回移：修复了 MaterializedPostgreSQL database engine 中的段错误；如果在复制初始化期间发生异常，可能会触发该问题。关闭了 [#36939](https://github.com/ClickHouse/ClickHouse/issues/36939)。[#39272](https://github.com/ClickHouse/ClickHouse/pull/39272) ([Kseniia Sumarokova](https://github.com/kssenii))。
* 已在 [#39351](https://github.com/ClickHouse/ClickHouse/issues/39351) 中回移：修复了 PostgreSQL database engine 中用于拉取 PostgreSQL 表的查询不正确的问题。关闭了 [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502)。[#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii))。
