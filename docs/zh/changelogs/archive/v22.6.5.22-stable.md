* 已在 [#39749](https://github.com/ClickHouse/ClickHouse/issues/39749) 中回移：修复从加密磁盘读取时的寻道问题。此 PR 修复了 [#38381](https://github.com/ClickHouse/ClickHouse/issues/38381)。[#39687](https://github.com/ClickHouse/ClickHouse/pull/39687) ([Vitaly Baranov](https://github.com/vitlibar)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#39883](https://github.com/ClickHouse/ClickHouse/issues/39883) 中回移：此前的软件包会将 systemd.service 文件安装到 `/etc`。该目录中的文件会被标记为 `conf`，因此既不会被清理，也不会自动更新。此 PR 会将这些文件清理掉。[#39323](https://github.com/ClickHouse/ClickHouse/pull/39323) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#39207](https://github.com/ClickHouse/ClickHouse/issues/39207) 中回移：修复从将数据存储在 S3 中的 `MergeTree` 表读取稀疏列时的问题。[#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#38932](https://github.com/ClickHouse/ClickHouse/issues/38932) 中回移：修复 `parallel_view_processing=1` 与 `optimize_trivial_insert_select=1` 同时启用时的问题。修复向视图推送数据时 `max_insert_threads` 的问题。[#38731](https://github.com/ClickHouse/ClickHouse/pull/38731) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#39590](https://github.com/ClickHouse/ClickHouse/issues/39590) 中回移：修复 Avro 格式中的数据竞争以及可能发生的堆缓冲区溢出问题。关闭 [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094)。关闭 [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652)。[#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar))。
* 已在 [#39612](https://github.com/ClickHouse/ClickHouse/issues/39612) 中回移：修复 splitByChar 的 maxsplit 参数此前无法正确工作的问题。[#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov))。
* 已在 [#39791](https://github.com/ClickHouse/ClickHouse/issues/39791) 中回移：修复 tuples 和运算符 `IN` 的错误索引分析问题，该问题可能导致错误的查询结果。[#39752](https://github.com/ClickHouse/ClickHouse/pull/39752) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#39836](https://github.com/ClickHouse/ClickHouse/issues/39836) 中回移：修复 `local_filesystem_read_method=pread_threadpool` 时出现 `CANNOT_READ_ALL_DATA` 异常的问题。根据 [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS)，此缺陷仅影响 Linux 内核 5.9 和 5.10 版本。[#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ))。
