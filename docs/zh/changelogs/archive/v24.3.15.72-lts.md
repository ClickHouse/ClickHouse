<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#72150](https://github.com/ClickHouse/ClickHouse/issues/72150) 中回移：此 PR 使 `RESTORE ON CLUSTER` 在向每个 `ReplicatedMergeTree` 表附加任何已恢复的 parts 之前，都会先等待该表退出 readonly 状态。此前它不会等待，因此在表启动期间，可能会几乎在检查其他副本的同时尝试附加某些 parts。受此问题影响，在极少数情况下，某些 parts 可能在 `RESTORE ON CLUSTER` 期间完全未被附加。[#62207](https://github.com/ClickHouse/ClickHouse/pull/62207) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#72408](https://github.com/ClickHouse/ClickHouse/issues/72408) 中回移：在执行 `ATTACH PART` 查询期间被去重的 parts 不会再卡在 `attaching_` 前缀状态。[#65636](https://github.com/ClickHouse/ClickHouse/pull/65636) ([Kirill](https://github.com/kirillgarbar)) 。
* 已在 [#71979](https://github.com/ClickHouse/ClickHouse/issues/71979) 中回移：在[这个问题](https://github.com/ClickHouse/ClickHouse/pull/59946#issuecomment-1943653197)之后，生产环境中已有相当多的表副本出现如下情况：其 `metadata_version` 节点值既等于 `0`，又与对应表的 `metadata` 节点版本不一致。这会导致这些副本上的 `alter` 查询失败。[#69274](https://github.com/ClickHouse/ClickHouse/pull/69274) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)) 。
* 已在 [#72396](https://github.com/ClickHouse/ClickHouse/issues/72396) 中回移：为 named collections 补上了缺失的反转义处理。没有此修复时，clickhouse-server 将无法启动。[#71308](https://github.com/ClickHouse/ClickHouse/pull/71308) ([MikhailBurdukov](https://github.com/MikhailBurdukov)) 。
* 已在 [#73354](https://github.com/ClickHouse/ClickHouse/issues/73354) 中回移：修复旧版 PostgreSQL 中报错 `column "attgenerated" does not exist` 的问题，修复 [#60651](https://github.com/ClickHouse/ClickHouse/issues/60651)。[#71396](https://github.com/ClickHouse/ClickHouse/pull/71396) ([0xMihalich](https://github.com/0xMihalich)) 。
* 已在 [#72141](https://github.com/ClickHouse/ClickHouse/issues/72141) 中回移：在将分片移动到 zero-copy disk 之前先获取 zero-copy 共享锁，以防在 Keeper 不可用时发生潜在的数据丢失。[#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)) 。
* 已在 [#72153](https://github.com/ClickHouse/ClickHouse/issues/72153) 中回移：仅允许在 subquery 中使用的 EXPLAIN AST 里包含 SELECT 查询。其他类型的查询会导致 logical error：&#39;Bad cast from type DB::ASTCreateQuery to DB::ASTSelectWithUnionQuery&#39; 或 `Inconsistent AST formatting`。[#71982](https://github.com/ClickHouse/ClickHouse/pull/71982) ([Pavel Kruglov](https://github.com/Avogar)) 。
