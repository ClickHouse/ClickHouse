  # 2022 更新日志

<div id="clickhouse-release-v214655-stable-fixme-as-compared-to-v214546-stable">
  ### ClickHouse 版本 v21.4.6.55-稳定版本 FIXME (相较于 v21.4.5.46-稳定版本)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#23679](https://github.com/ClickHouse/ClickHouse/issues/23679) 中回移：修复了 `quantile(s)TDigest`。根据 tdunning/t-digest 3.2+，新增了对单点质心的特殊处理。同时还修复了早期版本算法实现中质心过度压缩的问题。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#23580](https://github.com/ClickHouse/ClickHouse/issues/23580) 中回移：修复了后台清理旧块时一个极少见的竞态条件。如果块距离去重窗口结束过近，可能会导致该块未被去重。[#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23676](https://github.com/ClickHouse/ClickHouse/issues/23676) 中回移：分区裁剪期间不再放宽 NOT 条件。此修复解决了 [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) 和 [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539)。[#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#23583](https://github.com/ClickHouse/ClickHouse/issues/23583) 中回移：* 修复了 dict join 在 join&#95;algorithm = &#39;auto&#39; 时的 bug。关闭 [#23002](https://github.com/ClickHouse/ClickHouse/issues/23002)。[#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#23641](https://github.com/ClickHouse/ClickHouse/issues/23641) 中回移：修复了基于虚拟列进行分区裁剪时生成不兼容常量表达式的问题。此修复解决了 [https://github.com/ClickHouse/ClickHouse/pull/21401#discussion&#95;r611888913](https://github.com/ClickHouse/ClickHouse/pull/21401#discussion_r611888913)。[#23366](https://github.com/ClickHouse/ClickHouse/pull/23366) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#23586](https://github.com/ClickHouse/ClickHouse/issues/23586) 中回移：允许像 21.1 版本之前一样将更多条件移到 `PREWHERE`。移过去的条件数量不足可能会导致性能下降。[#23397](https://github.com/ClickHouse/ClickHouse/pull/23397) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#23588](https://github.com/ClickHouse/ClickHouse/issues/23588) 中回移：修复了在多磁盘配置下创建 ReplicatedMergeTree 表失败时出现的 `Cannot unlink file` 错误。此修复关闭了 [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755)。[#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#23591](https://github.com/ClickHouse/ClickHouse/issues/23591) 中回移：修复了 `ReplacingMergeTree` 垂直合并中的边界情况问题。在极少数情况下，这可能导致合并失败，并出现类似 `Incomplete granules are not allowed while blocks are granules size` 的异常。[#23459](https://github.com/ClickHouse/ClickHouse/pull/23459) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#23611](https://github.com/ClickHouse/ClickHouse/issues/23611) 中回移：修复了 restart / stop 命令卡住的问题。关闭 [#20214](https://github.com/ClickHouse/ClickHouse/issues/20214)。[#23552](https://github.com/ClickHouse/ClickHouse/pull/23552) ([filimonov](https://github.com/filimonov)) 。
* 已在 [#23693](https://github.com/ClickHouse/ClickHouse/issues/23693) 中回移：修复了通过 HTTP 插入数据时，异常导致服务器故障的问题。此修复解决了 [#23512](https://github.com/ClickHouse/ClickHouse/issues/23512)。[#23643](https://github.com/ClickHouse/ClickHouse/pull/23643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#23695](https://github.com/ClickHouse/ClickHouse/issues/23695) 中回移：在聚合函数 `mannWhitneyUTest` 的两个样本中，若值完全相同，则新增抛出异常。此修复解决了 [#23646](https://github.com/ClickHouse/ClickHouse/issues/23646)。[#23654](https://github.com/ClickHouse/ClickHouse/pull/23654) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#23774](https://github.com/ClickHouse/ClickHouse/issues/23774) 中回移：避免在向 Distributed 执行 INSERT 时，在发生某些异常后可能出现 &quot;Cannot schedule a task&quot; 错误。[#23744](https://github.com/ClickHouse/ClickHouse/pull/23744) ([Azat Khuzhin](https://github.com/azat)) 。
