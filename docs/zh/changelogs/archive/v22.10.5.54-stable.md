<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#43100](https://github.com/ClickHouse/ClickHouse/issues/43100) 中回移：更新了 normaliser，使其克隆别名 AST。解决了 [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452)。实现：* 更新了 QueryNormalizer，在替换别名 AST 时会对其进行克隆。此前只是赋值为同一个 AST，这会导致 LogicalExpressinsOptimizer 中出现异常，因为相同的父节点会被再次插入。* 该 bug 在新的 analyzer (allow&#95;experimental&#95;analyzer) 中不会出现，因此无需对其进行修改。我还为此添加了一个测试。[#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)) 。
* 已在 [#44659](https://github.com/ClickHouse/ClickHouse/issues/44659) 中回移：修复了 Lazy database 中表执行 Backup 时的竞争问题。[#43104](https://github.com/ClickHouse/ClickHouse/pull/43104) ([Vitaly Baranov](https://github.com/vitlibar)) 。
