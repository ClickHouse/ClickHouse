  ### ClickHouse 发布版本 v25.1.5.31-稳定版本 (48f17e8a805) FIXME，与 v25.1.4.53-稳定版本 (c3f28b8bf5d) 相比

<div id="improvement">
  #### 改进
</div>

* 已在 [#76048](https://github.com/ClickHouse/ClickHouse/issues/76048) 中回移：Keeper 改进：为提升性能，在提交到内存中存储时禁用摘要计算。可通过配置项 `keeper_server.digest_enabled_on_commit` 启用。预处理请求时仍会计算摘要。[#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#76315](https://github.com/ClickHouse/ClickHouse/issues/76315) 中回移：新增服务器设置 `throw_on_unknown_workload`，用于指定当查询中的 `workload` 设置为未知值时的行为：要么允许无限制访问 (默认) ，要么抛出 `RESOURCE_ACCESS_DENIED` 错误。该设置可用于强制所有查询都使用工作负载调度。[#75999](https://github.com/ClickHouse/ClickHouse/pull/75999) ([Sergei Trifonov](https://github.com/serxa)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#76341](https://github.com/ClickHouse/ClickHouse/issues/76341) 中回移：检查某些存储中不支持的类型。 [#74218](https://github.com/ClickHouse/ClickHouse/pull/74218) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#76362](https://github.com/ClickHouse/ClickHouse/issues/76362) 中回移：修复使用 NULL 安全比较时，`JOIN ON` 子句中表达式类型别名相关的问题。 [#74970](https://github.com/ClickHouse/ClickHouse/pull/74970) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#75634](https://github.com/ClickHouse/ClickHouse/issues/75634) 中回移：修复 PSQL 复制中由于未捕获异常导致的崩溃。 [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#76246](https://github.com/ClickHouse/ClickHouse/issues/76246) 中回移：SASL 可能导致任意 RPC 调用失败，此修复可在 krb5 票据过期时重试调用。 [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* 已在 [#76161](https://github.com/ClickHouse/ClickHouse/issues/76161) 中回移：在对其 PK 列执行 ALTER MODIFY 时重建投影。此前，这可能导致在对投影 PK 中使用的列执行 ALTER MODIFY 后，查询期间出现 `CANNOT_READ_ALL_DATA` 错误。 [#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#76261](https://github.com/ClickHouse/ClickHouse/issues/76261) 中回移：在设置变更历史中记录了 v24.12 默认启用 parallel hash 作为 JOIN 算法。这意味着，如果配置的兼容级别早于 v24.12，ClickHouse 将继续使用非并行 hash 执行 join。 [#75870](https://github.com/ClickHouse/ClickHouse/pull/75870) ([Robert Schulze](https://github.com/rschu1ze)).
* 已在 [#76201](https://github.com/ClickHouse/ClickHouse/issues/76201) 中回移：`clickhouse-library-bridge` 允许从文件系统中打开任意库，因此只有在隔离环境中运行才是安全的。为防止其与 clickhouse-server 部署在一起时产生漏洞，我们将把库文件路径限制在配置中指定的位置。该漏洞由 **Arseniy Dugin** 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。 [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
