<div id="improvement">
  #### 改进
</div>

* 已在 [#30355](https://github.com/ClickHouse/ClickHouse/issues/30355) 中回移：为 bridge 进程使用独立的 `clickhouse-bridge` 组和用户。设置 oom&#95;score&#95;adj，使这些 bridge 进程在发生 OOM 时优先被 OOM Killer 终止。将最大 RSS 设为 1 GiB。关闭了 [#23861](https://github.com/ClickHouse/ClickHouse/issues/23861)。[#25280](https://github.com/ClickHouse/ClickHouse/pull/25280) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#29945](https://github.com/ClickHouse/ClickHouse/issues/29945) 中回移：将 zoneinfo 文件更新到 2021c。[#29925](https://github.com/ClickHouse/ClickHouse/pull/29925) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#30041](https://github.com/ClickHouse/ClickHouse/issues/30041) 中回移：修复 `AccessControlManager` 的关闭过程。现在，`AccessControlManager` 销毁后将不再重新加载配置。此 PR 修复了不稳定的测试 [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html)。[#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#29260](https://github.com/ClickHouse/ClickHouse/issues/29260) 中回移：修复使用 nullable 或 lowcardinality 主键时无效的常量类型转换问题。[#28636](https://github.com/ClickHouse/ClickHouse/pull/28636) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#29026](https://github.com/ClickHouse/ClickHouse/issues/29026) 中回移：修复 `GLOBAL IN` 子查询使用线程数的问题 (自 [#19414](https://github.com/ClickHouse/ClickHouse/issues/19414) 的缺陷修复后，它一直以单线程执行) 。[#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#29194](https://github.com/ClickHouse/ClickHouse/issues/29194) 中回移：修复在 Avro 输入格式中向类型为 LowCardinality(Nullable) 的列插入数据时发生的 segfault。[#29132](https://github.com/ClickHouse/ClickHouse/pull/29132) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#29360](https://github.com/ClickHouse/ClickHouse/issues/29360) 中回移：修复在重新创建或创建 `ReplicatedMergeTree` 的新副本时，可能出现 `Table columns structure in ZooKeeper is different from local table structure` 异常的问题，该问题会在某个表列包含带不区分大小写函数的默认表达式时发生。[#29266](https://github.com/ClickHouse/ClickHouse/pull/29266) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#29300](https://github.com/ClickHouse/ClickHouse/issues/29300) 中回移：修复连接超时问题 (`send_timeout`/`receive_timeout`) 。[#29282](https://github.com/ClickHouse/ClickHouse/pull/29282) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#30042](https://github.com/ClickHouse/ClickHouse/issues/30042) 中回移：修复在下推优化后过滤器谓词中的条件可能丢失的问题。[#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#29848](https://github.com/ClickHouse/ClickHouse/issues/29848) 中回移：修复 `GROUP BY` 期间并发访问 `LowCardinality` 时的问题 (会导致 SIGSEGV) 。[#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#30066](https://github.com/ClickHouse/ClickHouse/issues/30066) 中回移：修复 `sample by tuple()` 导致的崩溃，关闭 [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004)。[#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
* 已在 [#30332](https://github.com/ClickHouse/ClickHouse/issues/30332) 中回移：* 允许在多个 join 中使用以数字开头的标识符。[#30230](https://github.com/ClickHouse/ClickHouse/pull/30230) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#30379](https://github.com/ClickHouse/ClickHouse/issues/30379) 中回移：修复 replaceRegexpAll 的缺陷。[#30292](https://github.com/ClickHouse/ClickHouse/pull/30292) ([Memo](https://github.com/Joeywzr)).
