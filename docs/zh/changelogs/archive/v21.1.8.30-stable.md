  ### ClickHouse 发布版本 v21.1.8.30-稳定版本 FIXME，相较于 v21.1.7.1-稳定版本

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#21205](https://github.com/ClickHouse/ClickHouse/issues/21205) 中回移：修复使用自定义 (非 default) ZooKeeper 集群的 Replicated*MergeTree 被删除时出现的元数据泄漏问题。[#21119](https://github.com/ClickHouse/ClickHouse/pull/21119) ([fastio](https://github.com/fastio)).
* 已在 [#21161](https://github.com/ClickHouse/ClickHouse/issues/21161) 中回移：修复在类型为 Nullable 时，`input_format_null_as_default` 不生效的问题。此修复解决了 [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116)。[#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#21926](https://github.com/ClickHouse/ClickHouse/issues/21926) 中回移：修复 Kafka 的 Avro 格式解析问题。修复了 [#21437](https://github.com/ClickHouse/ClickHouse/issues/21437)。[#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)).
* 已在 [#22189](https://github.com/ClickHouse/ClickHouse/issues/22189) 中回移：修复 Poco 中 SecureSocket 内部 SSL 对象上的竞态问题。[#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#22317](https://github.com/ClickHouse/ClickHouse/issues/22317) 中回移：修复针对外部数据库引擎 (MySQL、PostgreSQL) 的查询中，WHERE 子句里的 JOIN 表包含未知列时的问题。关闭 [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614)、[#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (重复) 、[#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (重复) 。[#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#21797](https://github.com/ClickHouse/ClickHouse/issues/21797) 中回移：修复 `async_socket_for_remote=1` 时分布式请求取消的问题 (例如从多个分片执行带 LIMIT 的简单 SELECT，即 `select * from remote('127.{2,3}', system.numbers) limit 100`) 。[#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22287](https://github.com/ClickHouse/ClickHouse/issues/22287) 中回移：在 DDLWorker 和字典初始化完成后才开始接受连接。[#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#21810](https://github.com/ClickHouse/ClickHouse/issues/21810) 中回移：修复 ReplicatedMerge 表引擎中的一个问题：当 `ALTER MODIFY COLUMN` 查询未改变 Decimal 列的大小 (32 bit 或 64 bit) 时，其类型不会被修改。[#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* 已在 [#21880](https://github.com/ClickHouse/ClickHouse/issues/21880) 中回移：修复在使用 two-level aggregation 时，带有 Distinct 组合器的聚合函数可能崩溃的问题。这是对 [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365) 的后续修复。该问题只能在 production 环境中复现，暂时还没有测试用例。cc @CurtizJ. [#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#22052](https://github.com/ClickHouse/ClickHouse/issues/22052) 中回移：修复首次执行 catboost 模型时的死锁问题。关闭 [#13832](https://github.com/ClickHouse/ClickHouse/issues/13832)。[#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#21981](https://github.com/ClickHouse/ClickHouse/issues/21981) 中回移：回退了 [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454) 的变更，该变更在加载哈希类型的外部字典时可能导致内存使用量显著增加。此项修复关闭了 [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935)。[#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#22465](https://github.com/ClickHouse/ClickHouse/issues/22465) 中回移：在极少数情况下，`CollapsingMergeTree` 的合并可能会创建包含 `index_granularity + 1` 行的粒度块。因此，[#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) 中新增的内部检查 (影响 21.2 和 21.3) 可能会因错误 `Incomplete granules are not allowed while blocks are granules size` 而失败。该错误会导致 parts 无法合并。[#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#22149](https://github.com/ClickHouse/ClickHouse/issues/22149) 中回移：函数 `decrypt` 缺少对 AEAD 模式加密数据最小长度的检查。此项修复关闭了 [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897)。[#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#22283](https://github.com/ClickHouse/ClickHouse/issues/22283) 中回移：Docker 入口点：当 `LOG_PATH` 为空时，避免对 `.` 执行 chown。关闭了 [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100)。[#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)) 。
* 已在 [#22280](https://github.com/ClickHouse/ClickHouse/issues/22280) 中回移：修复 `ReplicatedMergeTree` 表引擎中等待 `OPTIMIZE` 和 `ALTER` 查询的问题。现在，即使表已分离或已重启，查询也不会再挂起。[#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#22501](https://github.com/ClickHouse/ClickHouse/issues/22501) 中回移：修复在 `use_hedged_requests=0` 和 `async_socket_for_remote=1` 条件下的查询取消问题。[#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#22368](https://github.com/ClickHouse/ClickHouse/issues/22368) 中回移：现在，尝试对已被覆盖的 part 执行 mutation 时，ClickHouse 不会再抛出 `LOGICAL_ERROR` 异常。修复了 [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013)。[#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#22533](https://github.com/ClickHouse/ClickHouse/issues/22533) 中回移：`tokenbf_v1` 全文索引在读取时可能发生缓冲区溢出。虽然多读取的字节不会被使用，但在极少数情况下，读取操作仍可能导致崩溃。此项修复关闭了 [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233)。[#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#22462](https://github.com/ClickHouse/ClickHouse/issues/22462) 中回移：为并行 parsing 例程补充了缺失的内存统计。在早期版本中，当结果集包含非常大的数据块时，可能会发生 OOM。此项修复关闭了 [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008)。[#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 在 [#22555](https://github.com/ClickHouse/ClickHouse/issues/22555) 中回移：修复 `LowCardinality` 与 partial merge join 配合使用时的错误。关闭 [#22386](https://github.com/ClickHouse/ClickHouse/issues/22386) 和 [#22388](https://github.com/ClickHouse/ClickHouse/issues/22388)。[#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)) 。
* 在 [#22608](https://github.com/ClickHouse/ClickHouse/issues/22608) 中回移：修复 TSV 格式在末尾没有换行符时，空字符串的反序列化问题。此修复关闭了 [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244)。如果不升级版本，一种可行的临时处理方法是将 `input_format_null_as_default` 设置为零。旧版本中该值默认为零。[#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 在 [#22578](https://github.com/ClickHouse/ClickHouse/issues/22578) 中回移：通过从同一线程对 TinyLog 的 rwlock 执行解锁，修复 UB。[#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)) 。
* 在 [#22650](https://github.com/ClickHouse/ClickHouse/issues/22650) 中回移：避免 *Log engines 中因从另一线程解锁 rwlock 而导致的 UB。[#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)) 。
* 在 [#22700](https://github.com/ClickHouse/ClickHouse/issues/22700) 中回移：修复 ReplicatedMergeTree 表引擎在多个副本上等待变更完成时的问题。此前，变更/ALTER 查询可能会在其他副本上的变更实际执行之前就已结束。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)) 。
* 在 [#22739](https://github.com/ClickHouse/ClickHouse/issues/22739) 中回移：修复发生 OOM 异常时 zk 请求可能卡住的问题。修复 [#22438](https://github.com/ClickHouse/ClickHouse/issues/22438)。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
