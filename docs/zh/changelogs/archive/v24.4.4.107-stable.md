<div id="improvement">
  #### 改进
</div>

* 已在 [#65884](https://github.com/ClickHouse/ClickHouse/issues/65884) 中回移：始终以足够数量的全局线程池线程启动 Keeper。[#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94)) 。
* 已在 [#65303](https://github.com/ClickHouse/ClickHouse/issues/65303) 中回移：恢复了 ClickHouse 在 CSV format 中处理和解释 Tuple 的原有行为。此更改实际上回退了 [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994)，并仅在少数几个设置下生效：`output_format_csv_serialize_tuple_into_separate_columns`、`input_format_csv_deserialize_separate_columns_into_tuple` 和 `input_format_csv_try_infer_strings_from_quoted_tuples`。[#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#65894](https://github.com/ClickHouse/ClickHouse/issues/65894) 中回移：让 Keeper 遵循 cgroup CPU 限制。[#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)) 。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 严重缺陷修复 (崩溃、LOGICAL_ERROR、数据丢失、RBAC)
</div>

* 已在 [#65372](https://github.com/ClickHouse/ClickHouse/issues/65372) 中回移：修复了 ClickHouse Keeper 中的一个缺陷，该缺陷会在关闭会话时导致摘要不匹配。[#65198](https://github.com/ClickHouse/ClickHouse/pull/65198) ([Aleksei Filatov](https://github.com/aalexfvk)) 。
* 已在 [#66883](https://github.com/ClickHouse/ClickHouse/issues/66883) 中回移：修复了函数调用中低基数列大小异常的问题。[#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#65435](https://github.com/ClickHouse/ClickHouse/issues/65435) 中回移：禁止在旧 analyzer 中使用 `QUALIFY` 子句。旧 analyzer 会忽略 `QUALIFY`，因此可能导致变更中出现意外的数据删除。[#65356](https://github.com/ClickHouse/ClickHouse/pull/65356) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#65448](https://github.com/ClickHouse/ClickHouse/issues/65448) 中回移：为 Distinct 组合器使用正确的内存对齐方式。此前，使用该组合器时，可能因无效的内存分配而发生崩溃。[#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#65710](https://github.com/ClickHouse/ClickHouse/issues/65710) 中回移：修复了 maxIntersections 中的崩溃问题。[#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#66689](https://github.com/ClickHouse/ClickHouse/issues/66689) 中回移：修复了重启后用户定义中的 VALID UNTIL 子句被重置的问题。关闭 [#66405](https://github.com/ClickHouse/ClickHouse/issues/66405)。[#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)) 。
