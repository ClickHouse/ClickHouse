<div id="clickhouse-release-v20527-stable-fixme-as-compared-to-v20513833-prestable">
  ### ClickHouse 版本发布 v20.5.2.7-稳定版本 FIXME，相较于 v20.5.1.3833-prestable
</div>

<div id="new-feature">
  #### 新特性
</div>

* 新增了对 `Alter table drop replica replica_name` 的支持，修复了 [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080)。[#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)) 。

<div id="improvement">
  #### 改进
</div>

* 添加在选择副本时可忽略的错误数量 (`distributed_replica_error_ignore`) 。[#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* 为没有结构锁的存储提供多版本元数据支持。[#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* 略微放宽对 ODBC 连接字符串的校验。如果主机名或用户名仅包含单词字符以及 `.` 和 `-`，则不要将其放在花括号中。之所以需要这样做，是因为某些 ODBC Driver (例如 PostgreSQL) 无法识别用花括号括起来的主机名。[#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为兼容 MySQL，支持标准整数类型 (`BIGINT`、`INT`、...) 的 `SIGNED` 和 `UNSIGNED` 修饰符。[#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 允许将 `sumWithOverflow` 用作 `SimpleAggregateFunction`。关闭了 [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053)。[#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 为哈希函数添加对 FixedString 的支持。[#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 修复了 `SELECT *, xyz.*` 这类查询的异常行为：原本应报错，却成功执行。[#11753](https://github.com/ClickHouse/ClickHouse/pull/11753) ([hexiaoting](https://github.com/hexiaoting)).
* 修复了条件中包含 NULL 时 `if()` 返回错误结果的问题。[#11807](https://github.com/ClickHouse/ClickHouse/pull/11807) ([Artem Zuikov](https://github.com/4ertus2)).
* 修复了通过 HTTP interface 进行内存统计的问题 (在 `wait_end_of_query=1` 时影响可能较为明显) 。[#11840](https://github.com/ClickHouse/ClickHouse/pull/11840) ([Azat Khuzhin](https://github.com/azat)).
* 修复了在 prewhere 条件中使用 `Nullable` 列导致的罕见崩溃问题。这是对 [#11608](https://github.com/ClickHouse/ClickHouse/issues/11608) 的后续修复。[#11869](https://github.com/ClickHouse/ClickHouse/pull/11869) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#11965](https://github.com/ClickHouse/ClickHouse/issues/11965) 中回移：修复了解析 DateTime64 时可能出现的浮点异常。该修复解决了 [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374)。[#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了解析 DateTime64 时可能出现的浮点异常。该修复解决了 [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374)。[#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#11963](https://github.com/ClickHouse/ClickHouse/issues/11963) 中回移：在执行 `USE database` 语句后，检查 access rights 时使用正确的当前数据库。[#11920](https://github.com/ClickHouse/ClickHouse/pull/11920) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#12059](https://github.com/ClickHouse/ClickHouse/issues/12059) 中回移：修复了包含 `Nullable` 列的元组比较结果不正确的问题。修复了 [#11985](https://github.com/ClickHouse/ClickHouse/issues/11985)。[#12039](https://github.com/ClickHouse/ClickHouse/pull/12039) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 为无服务器环境添加了一个简单的 GitHub hook 脚本。[#11605](https://github.com/ClickHouse/ClickHouse/pull/11605) ([alesapin](https://github.com/alesapin)).
* 在发生致命错误时，如有可能将日志发送给客户端。这将使测试结果更易读。[#11826](https://github.com/ClickHouse/ClickHouse/pull/11826) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 支持 ClickHouse 在 Android 上运行。[#11894](https://github.com/ClickHouse/ClickHouse/pull/11894) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
