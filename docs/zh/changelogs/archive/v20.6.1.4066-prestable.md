<div id="clickhouse-release-v20614066-prestable-fixme-as-compared-to-v20513833-prestable">
  ### ClickHouse 版本 v20.6.1.4066-预稳定版本 FIXME (相较于 v20.5.1.3833-预稳定版本)
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* `clickhouse-local` 现在默认使用唯一的临时数据目录，不再像以前那样使用当前目录。如有需要，可通过 `-- --path` 选项显式指定数据目录。[#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### 新特性
</div>

* 添加对 `Alter table drop replica replica_name` 的支持。此更改修复了 [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080)。[#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* 为 `MergeTree` 家族表新增了 in-memory 格式的 parts，用于将数据存储在内存中。parts 会在首次 merge 时写入磁盘。如果某个分片的行数或字节数低于阈值 `min_rows_for_compact_part` 和 `min_bytes_for_compact_part`，则会以 in-memory 格式创建。此外，还提供了可选的预写日志支持，默认启用，并由设置 `in_memory_parts_enable_wal` 控制。[#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* 为 aggregate functions 添加 `-Distinct` 组合器。[#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* 支持表引擎 mongo(host:port, database, collection, user, password)。[#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* 添加 RabbitMQ 存储引擎。[#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 新增可选启用的设置，可通过 [Sentry](https://sentry.io) 向 ClickHouse 核心团队发送崩溃报告。[#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* 添加 ORCBlockOutputFormat。[#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* 新增 `max_thread_pool_size` config，用于修改全局线程池中的最大线程数。[#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* `EXPLAIN` 查询的初始实现。语法：`EXPLAIN SELECT ...`。此更改修复了 [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118)。[#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 将 S3 metadata 中的 paths 改为相对路径，从而可以更轻松地处理 S3 blobs。[#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 支持 Avro UUID 输入/输出。[#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* 新增只读 MongoDB 表引擎。支持读取扁平字段 (基本类型，不支持嵌套字段) 。[#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* 添加设置，用于处理 Avro schema 中未找到的字段。[#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* 添加函数 `parseDateTimeBestEffortUS`。[#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 支持 ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST。[#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* 添加函数 initializedAggregation，用于基于单个值初始化 aggregation。[#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* 支持在 `set join_algorithm=partial_merge` 下使用 RIGHT 和 FULL JOIN。仅支持 ALL strictness (不支持 ANY、SEMI、ANTI、ASOF) 。[#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* 实现了 PostgreSQL 风格的 ILIKE 运算符，见 [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710)。[#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc))。
* 允许 Nullable 类型作为 MergeTree 表的键。[#5319](https://github.com/ClickHouse/ClickHouse/issues/5319)。[#12433](https://github.com/ClickHouse/ClickHouse/pull/12433) ([Amos Bird](https://github.com/amosbird))。

<div id="performance-improvement">
  #### 性能提升
</div>

* 如果配置了 `min_bytes_to_use_direct_io` 或 `min_bytes_to_use_mmap_io` 设置，则允许对二级索引使用 direct&#95;io 和 mmap&#95;io。[#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 修复了从 MergeTree 读取时对标记数量的估算。这对于正确处理 `merge_tree_max_rows_to_use_cache`、`merge_tree_max_bytes_to_use_cache`、`merge_tree_min_rows_for_concurrent_read`、`merge_tree_min_bytes_for_concurrent_read`、`merge_tree_min_rows_for_seek`、`merge_tree_min_bytes_for_seek` 这些设置是必需的。现在，`min_bytes_to_use_mmap_io` 设置也会应用于 MergeTree 表引擎家族中的读取索引和紧凑 parts。[#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 修复了“[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) IN 运算符在使用字面量时未使用索引”这一在 v19.3 前后引入的性能回退问题。[#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)) 。
* 当 `set optimize_injective_functions_inside_uniq=1` 时，会移除 `uniq*()` 内部的单射函数。[#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)) 。
* 添加了 ORDER BY 优化：如果 `set optimize_redundant_functions_in_order_by = 1`，则将 `ORDER BY x, f(x)` 重写为 `ORDER by x`。[#12404](https://github.com/ClickHouse/ClickHouse/pull/12404) ([Artem Zuikov](https://github.com/4ertus2)) 。
* 将某些操作的内存使用量最多降低了一半。[#12424](https://github.com/ClickHouse/ClickHouse/pull/12424) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="improvement">
  #### 改进
</div>

* 新增了在选择副本时可忽略错误数量的参数 (`distributed_replica_error_ignore`) 。[#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* 基于排序键前缀优化了 `ORDER BY` 和 `GROUP BY` 的性能。[#11696](https://github.com/ClickHouse/ClickHouse/pull/11696) ([Anton Popov](https://github.com/CurtizJ)).
* * 添加 `optimize_skip_unused_shards_nesting` (用于控制分片跳过优化的嵌套层级) - 添加 `force_skip_optimize_shards_nesting` (用于控制检查分片是否被跳过时的嵌套层级) - 弃用 `force_optimize_skip_unused_shards_no_nested` (应改用 `force_skip_optimize_shards_nesting`) - 如果 sharding&#95;key 包含非确定性函数，则禁用 `optimize_skip_unused_shards` (即 `rand()`；注意这不会对 `INSERT` 端产生任何影响) 。[#11715](https://github.com/ClickHouse/ClickHouse/pull/11715) ([Azat Khuzhin](https://github.com/azat)) 。
* 为没有结构锁的存储后端提供多版本元数据。[#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* 略微放宽了对 ODBC connection string 的校验。如果 hostname 或 用户名 仅包含单词字符以及 `.` 和 `-`，则不要将其放在花括号中。这样做是必要的，因为某些 ODBC driver (例如 PostgreSQL) 无法识别用花括号括起来的 hostname。[#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 支持解析不带分隔符的 UUID (大多数实现通常都会去掉分隔符，这有助于用户写入数据) 。[#11856](https://github.com/ClickHouse/ClickHouse/pull/11856) ([Winter Zhang](https://github.com/zhang2014)).
* 为兼容 MySQL，支持标准整数类型 (`BIGINT`、`INT` 等) 的 `SIGNED` 和 `UNSIGNED` 修饰符。[#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 允许将 `sumWithOverflow` 用作 `SimpleAggregateFunction`。关闭 [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053)。[#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 在哈希函数中添加了对 FixedString 的支持。[#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).
* 重写了 `optimize_arithmetic_operations_in_aggregate_functions` 优化相关代码。[#11899](https://github.com/ClickHouse/ClickHouse/pull/11899) ([Artem Zuikov](https://github.com/4ertus2)).
* 在 `DatabaseOrdinary.cpp` 中使用 std::filesystem::path 替代 std::string，以改进路径拼接并修复双斜杠路径问题。[#11900](https://github.com/ClickHouse/ClickHouse/pull/11900) ([Bharat Nallan](https://github.com/bharatnc)).
* 弃用旧的 regular 风格，改用新的 globalVariable 方法 [#11832](https://github.com/ClickHouse/ClickHouse/issues/11832)。[#11901](https://github.com/ClickHouse/ClickHouse/pull/11901) ([BohuTANG](https://github.com/BohuTANG)).
* 与 [issue 9797](https://github.com/ClickHouse/ClickHouse/issues/9797) 相关。[#11923](https://github.com/ClickHouse/ClickHouse/pull/11923) ([flynn](https://github.com/ucasfl)).
* `system.tables` 现在会将 Memory 和 Buffer 表引擎的列容量考虑在内，从而能更准确地估算常驻内存大小。[#11935](https://github.com/ClickHouse/ClickHouse/pull/11935) ([Max Akhmedov](https://github.com/zlobober)).
* 向 system.asynchronous&#95;metrics 添加 CPU 频率，并使指标收集周期可配置。[#11972](https://github.com/ClickHouse/ClickHouse/pull/11972) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 允许执行仅修改元数据的分区键 ALTER，例如向 Enum 数据类型中添加更多元素。此修复解决了 [#7513](https://github.com/ClickHouse/ClickHouse/issues/7513)。[#11973](https://github.com/ClickHouse/ClickHouse/pull/11973) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 load&#95;balancing 添加副本优先级 (用于手动设置负载均衡优先级) 。[#11995](https://github.com/ClickHouse/ClickHouse/pull/11995) ([Azat Khuzhin](https://github.com/azat)).
* 支持 MySQL engine 读取枚举类型 [#3985](https://github.com/ClickHouse/ClickHouse/issues/3985)。[#11996](https://github.com/ClickHouse/ClickHouse/pull/11996) ([BohuTANG](https://github.com/BohuTANG)).
* 为 DiskS3 实现了单分片上传。[#12026](https://github.com/ClickHouse/ClickHouse/pull/12026) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 将无用的 S3 日志下调到 TRACE 级别。[#12067](https://github.com/ClickHouse/ClickHouse/pull/12067) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 改进了 `REVOKE` 命令：现在仅要求对将被撤销的权限具备 grant/admin option。例如，执行 `REVOKE ALL ON *.* FROM user1` 现在不再要求必须拥有通过 grant option 授予的全部 access rights。新增命令 `REVOKE ALL FROM user1` —— 该命令会撤销授予给 `user1` 的所有 roles。[#12083](https://github.com/ClickHouse/ClickHouse/pull/12083) ([Vitaly Baranov](https://github.com/vitlibar)).
* 在 system.disks 中添加了 `type` 列。[#12115](https://github.com/ClickHouse/ClickHouse/pull/12115) ([ianton-ru](https://github.com/ianton-ru)).
* 在 `formatDateTime` 函数中新增了对 `%g` (两位 ISO 年份) 和 `%G` (四位 ISO 年份) 替换的支持。[#12136](https://github.com/ClickHouse/ClickHouse/pull/12136) ([vivarum](https://github.com/vivarum)).
* 为 MySQL client/driver 添加了 `KILL QUERY [connection_id]`，用于取消长时间运行的查询，参见 issue [#12038](https://github.com/ClickHouse/ClickHouse/issues/12038)。[#12152](https://github.com/ClickHouse/ClickHouse/pull/12152) ([BohuTANG](https://github.com/BohuTANG)).
* 1. 支持 MySQL &#39;SELECT DATABASE()&#39; [#9336](https://github.com/ClickHouse/ClickHouse/issues/9336) 2. 添加 MySQL 查询替换的集成测试。[#12314](https://github.com/ClickHouse/ClickHouse/pull/12314) ([BohuTANG](https://github.com/BohuTANG)).
* 此设置允许选择用于打印表格的字符集 (`utf8` 或 `ascii`) 。[#12372](https://github.com/ClickHouse/ClickHouse/pull/12372) ([Sabyanin Maxim](https://github.com/s-mx)).
* 向客户端返回详细的异常消息，而不是 &#39;MySQL server has gone away&#39;。[#12383](https://github.com/ClickHouse/ClickHouse/pull/12383) ([BohuTANG](https://github.com/BohuTANG)).
* 为 Buffer 引擎添加 lifetime&#95;rows/lifetime&#95;bytes。[#12421](https://github.com/ClickHouse/ClickHouse/pull/12421) ([Azat Khuzhin](https://github.com/azat)).
