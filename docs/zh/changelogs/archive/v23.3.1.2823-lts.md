  ### ClickHouse 发布 v23.3.1.2823-lts (46e85357ce2) FIXME (与 v23.2.1.2537-stable (52bf836e03a) 相比)
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 放宽了 *domain*RFC()/netloc() 中 URL authority 部分允许使用的符号限制。 [#46841](https://github.com/ClickHouse/ClickHouse/pull/46841) ([Azat Khuzhin](https://github.com/azat)).
* 禁止基于 KafkaEngine 创建列带有 DEFAULT/EPHEMERAL/ALIAS/MATERIALIZED 语句的表。 [#47138](https://github.com/ClickHouse/ClickHouse/pull/47138) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* 已移除 “asynchronous connection drain” 功能，相关设置和指标也一并移除。该功能属于内部功能，因此此次移除不应影响此前从未听说过该功能的用户。 [#47486](https://github.com/ClickHouse/ClickHouse/pull/47486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `arraySum`/`Min`/`Max`/`Avg`/`Product`、`arrayCumSum`/`CumSumNonNegative`、`arrayDifference`、数组构造、IN 运算符、查询参数、`groupArrayMovingSum`、统计函数、`min`/`max`/`any`/`argMin`/`argMax`、PostgreSQL wire protocol、MySQL 表引擎和函数、`sumMap`、`mapAdd`、`mapSubtract`、`arrayIntersect` 现已支持 256 位 Decimal 数据类型 (超过 38 位数字) 。`arrayIntersect` 还新增了对大整数的支持。涉及矩的统计聚合函数 (例如 `corr` 或各种 `TTest`) 将使用 `Float64` 作为内部表示 (在此更改之前使用的是 `Decimal128`，但并无实际意义) ，并且这些函数在方差为无穷大时可能返回 `nan` 而不是 `inf`。某些函数此前已允许用于 `Decimal256` 数据类型，但在之前的版本中返回的是 `Decimal128`，现已修复。此项修复关闭了 [#47569](https://github.com/ClickHouse/ClickHouse/issues/47569)。此项修复关闭了 [#44864](https://github.com/ClickHouse/ClickHouse/issues/44864)。此项修复关闭了 [#28335](https://github.com/ClickHouse/ClickHouse/issues/28335)。 [#47594](https://github.com/ClickHouse/ClickHouse/pull/47594) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 backup&#95;threads/restore&#95;threads 改为服务器级设置。 [#47881](https://github.com/ClickHouse/ClickHouse/pull/47881) ([Azat Khuzhin](https://github.com/azat)).
* 修复了 isIPv6String 函数在 IPv6 地址不正确时可能产生误报的问题。例如，`1234::1234:` 之前会被视为有效的 IPv6 地址。 [#47895](https://github.com/ClickHouse/ClickHouse/pull/47895) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="new-feature">
  #### 新特性
</div>

* 新增一种使用设置 `parallel_replicas_custom_key` 和 `parallel_replicas_custom_key_filter_type` 在副本间拆分工作的模式。如果 cluster 由单个 shard 和多个 replicas 组成，则会随机选择最多 `max_parallel_replicas` 个 replicas，并将其视为 shards。对于每个 shard，在发送到 shard 之前，都会由 initiator 为查询添加相应的过滤器。如果 cluster 由多个 shards 组成，则其行为与 `sample_key` 相同，但可以定义任意 key。[#45108](https://github.com/ClickHouse/ClickHouse/pull/45108) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 新增查询设置 `partial_result_on_first_cancel`，允许被取消的查询 (例如由于 Ctrl-C) 返回部分结果。[#45689](https://github.com/ClickHouse/ClickHouse/pull/45689) ([Alexey Perevyshin](https://github.com/alexX512)) 。
* 为临时表新增对任意表引擎的支持，但 Replicated 和 KeeperMap 引擎除外。部分关闭 [#31497](https://github.com/ClickHouse/ClickHouse/issues/31497)。[#46071](https://github.com/ClickHouse/ClickHouse/pull/46071) ([Roman Vasin](https://github.com/rvasin)) 。
* 新增使用 ZooKeeper 复制用户定义 SQL 函数的功能。[#46085](https://github.com/ClickHouse/ClickHouse/pull/46085) ([Aleksei Filatov](https://github.com/aalexfvk)) 。
* 实现了 `system.server_settings` (类似于 `system.settings`) ，其中将包含 server 配置。[#46550](https://github.com/ClickHouse/ClickHouse/pull/46550) ([pufit](https://github.com/pufit)) 。
* 引入函数 `WIDTH_BUCKET`。[#42974](https://github.com/ClickHouse/ClickHouse/issues/42974)。[#46790](https://github.com/ClickHouse/ClickHouse/pull/46790) ([avoiderboi](https://github.com/avoiderboi)) 。
* 新增函数 parseDateTime/parseDateTimeInJodaSyntax，可按指定的 format string 进行解析。parseDateTime 按 MySQL 语法将字符串解析为日期时间，parseDateTimeInJodaSyntax 按 Joda 语法解析。[#46815](https://github.com/ClickHouse/ClickHouse/pull/46815) ([李扬](https://github.com/taiyang-li)) 。
* 对表函数 `null` 的默认结构使用 `dummy UInt8`。关闭 [#46930](https://github.com/ClickHouse/ClickHouse/issues/46930)。[#47006](https://github.com/ClickHouse/ClickHouse/pull/47006) ([flynn](https://github.com/ucasfl)) 。
* parseDateTimeBestEffort 函数新增对 `Dec 15, 2021` 的支持。关闭 [#46816](https://github.com/ClickHouse/ClickHouse/issues/46816)。[#47071](https://github.com/ClickHouse/ClickHouse/pull/47071) ([chen](https://github.com/xiedeyantu)) 。
* 新增函数 ULIDStringToDateTime()。关闭 [#46945](https://github.com/ClickHouse/ClickHouse/issues/46945)。[#47087](https://github.com/ClickHouse/ClickHouse/pull/47087) ([Nikolay Degterinsky](https://github.com/evillique)) 。
* 新增设置 `http_wait_end_of_query` 和 `http_response_buffer_size`，分别对应 HTTP interface 的 URL params `wait_end_of_query` 和 `buffer_size`。[#47108](https://github.com/ClickHouse/ClickHouse/pull/47108) ([Vladimir C](https://github.com/vdimir)) 。
* 支持 `UNDROP TABLE` 查询。关闭 [#46811](https://github.com/ClickHouse/ClickHouse/issues/46811)。[#47241](https://github.com/ClickHouse/ClickHouse/pull/47241) ([chen](https://github.com/xiedeyantu)) 。
* 新增 `system.marked_dropped_tables` 表，用于显示已从 `Atomic` database 中删除但尚未完全移除的表。[#47364](https://github.com/ClickHouse/ClickHouse/pull/47364) ([chen](https://github.com/xiedeyantu)) 。
* 新增 `INSTR` 作为 `positionCaseInsensitive` 的别名，以兼容 MySQL。关闭 [#47529](https://github.com/ClickHouse/ClickHouse/issues/47529)。[#47535](https://github.com/ClickHouse/ClickHouse/pull/47535) ([flynn](https://github.com/ucasfl)).
* 新增 `toDecimalString` 函数，可将数字转换为具有固定精度的字符串。[#47838](https://github.com/ClickHouse/ClickHouse/pull/47838) ([Andrey Zvonov](https://github.com/zvonand)).
* 新增 `REGEXP` 操作符 (类似 `LIKE`、`IN`、`MOD` 等操作符) ，以更好地兼容 MySQL。[#47869](https://github.com/ClickHouse/ClickHouse/pull/47869) ([Robert Schulze](https://github.com/rschu1ze)).
* 允许对使用 CLICKHOUSE source 的 DIRECT 字典通过多线程执行读取管道。要启用此功能，请在 `CREATE DICTIONARY` 语句中 source 的 `SETTINGS` 部分设置 `dictionary_use_async_executor=1`。[#47986](https://github.com/ClickHouse/ClickHouse/pull/47986) ([Vladimir C](https://github.com/vdimir)).
* 新增 merge tree 设置 `max_number_of_mutatuins_for_replica`。该设置会将每个副本的 part mutations 数量限制为指定值。值为 0 表示每个副本的 mutations 数量不受限制 (但执行仍可能受其他设置约束) 。[#48047](https://github.com/ClickHouse/ClickHouse/pull/48047) ([Vladimir C](https://github.com/vdimir)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 优化了单个 Nullable 键的聚合性能。[#45772](https://github.com/ClickHouse/ClickHouse/pull/45772) ([LiuNeng](https://github.com/liuneng1994)).
* 使 hasTokenOrNull、hasTokenCaseInsensitive 和 hasTokenCaseInsensitiveOrNull 能够利用小写 tokenbf&#95;v1 索引。[#46252](https://github.com/ClickHouse/ClickHouse/pull/46252) ([ltrk2](https://github.com/ltrk2)).
* 通过先搜索前两个字符，优化了通用 SIMD StringSearcher。[#46289](https://github.com/ClickHouse/ClickHouse/pull/46289) ([Jiebin Sun](https://github.com/jiebinn)).
* System.detached&#95;parts 可能会非常大。- 新增了多个来源以适应块大小限制 - 在每个块中使用 iothread pool 计算 part 大小，即并行执行系统调用。[#46624](https://github.com/ClickHouse/ClickHouse/pull/46624) ([Sema Checherinda](https://github.com/CheSema)).
* 将 ReplicatedMergeTree 表的 `max_replicated_merges_in_queue` 默认值从 16 提高到 1000。这样可加快拥有大量副本的集群上的后台 merge 操作，例如 ClickHouse Cloud 中使用共享存储的集群。[#47050](https://github.com/ClickHouse/ClickHouse/pull/47050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 在之前的版本中，大量文件的备份速度极其缓慢。[#47251](https://github.com/ClickHouse/ClickHouse/pull/47251) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 支持在使用 StorageJoin、StorageDictionary、StorageEmbeddedRocksDB 的 JOIN 中，将过滤器下推到 left table。[#47280](https://github.com/ClickHouse/ClickHouse/pull/47280) ([Maksim Kita](https://github.com/kitaisreal)).
* 内存中的标记现已压缩，内存占用减少了 3 到 6 倍。[#47290](https://github.com/ClickHouse/ClickHouse/pull/47290) ([Michael Kolupaev](https://github.com/al13n321)).
* 更新了 copier，使用 group by 而不是 distinct 来获取分区列表。对于大表，这将 select 时间从超过 500 秒缩短到不到 1 秒。[#47386](https://github.com/ClickHouse/ClickHouse/pull/47386) ([Clayton McClure](https://github.com/cmcclure-twilio)).
* 处理了 [https://github.com/clickhouse/clickhouse/issues/46453](https://github.com/clickhouse/clickhouse/issues/46453)。bisect 将 [https://github.com/clickhouse/clickhouse/pull/35525](https://github.com/clickhouse/clickhouse/pull/35525) 标记为引入问题的变更。这个 pr 看起来是在回退该 pr 中的改动。[#47544](https://github.com/ClickHouse/ClickHouse/pull/47544) ([Ongkong](https://github.com/ongkong)).
* 修复了带有 `FINAL` 的查询中的过度读取问题。[#47801](https://github.com/ClickHouse/ClickHouse/pull/47801) ([Nikita Taranov](https://github.com/nickitat)).
* 在 server 启动时，`max_final_threads` 会被设置为核心数 (使用与 `max_threads` 相同的算法) 。这提升了高 CPU 数量 server 上 `final` 执行的并发性。[#47915](https://github.com/ClickHouse/ClickHouse/pull/47915) ([Nikita Taranov](https://github.com/nickitat)).
* 避免在读取请求中拆分批次，以提升性能。[#47978](https://github.com/ClickHouse/ClickHouse/pull/47978) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="improvement">
  #### 改进
</div>

* 添加与 map 相关的函数：`mapFromArrays`，可根据一对数组创建 map。[#31125](https://github.com/ClickHouse/ClickHouse/pull/31125) ([李扬](https://github.com/taiyang-li)).
* 重写 Distributed 的发送逻辑，避免将文件系统用作队列，改为使用内存队列。[#45491](https://github.com/ClickHouse/ClickHouse/pull/45491) ([Azat Khuzhin](https://github.com/azat)).
* 允许对 named collections 进行单独授权 (例如，可仅向特定 collection 授予 `SHOW/CREATE/ALTER/DROP named collection` 访问权限，而不必一次性授予全部) 。关闭了 [#40894](https://github.com/ClickHouse/ClickHouse/issues/40894)。新增访问类型 `NAMED_COLLECTION_CONTROL`，默认不会授予 `default` 用户，除非在用户配置中显式添加 (执行 `GRANT ALL` 需要此权限) ；此外，与 23.2 不同，`show_named_collections` 不再需要为 `default` 用户手动指定，才能使其拥有完整访问权限。[#46241](https://github.com/ClickHouse/ClickHouse/pull/46241) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 现在，所有通过 HTTP 协议发起的查询，其响应中都会添加 `X-ClickHouse-Query-Id` 和 `X-ClickHouse-Timezone` 响应头。此前仅对 `SELECT` 查询如此。[#46364](https://github.com/ClickHouse/ClickHouse/pull/46364) ([Anton Popov](https://github.com/CurtizJ)).
* 支持通过在 URI 中列举多个 host:port 连接到 MongoDB Replica Set，并支持在 MongoDB 字典中使用 readPreference 选项。示例 URI：mongodb://db0.example.com:27017,db1.example.com:27017,db2.example.com:27017/?replicaSet=myRepl&amp;readPreference=primary。[#46524](https://github.com/ClickHouse/ClickHouse/pull/46524) ([artem-yadr](https://github.com/artem-yadr)).
* 基于查询计划重新实现投影分析。新增设置 `query_plan_optimize_projection=1`，用于在旧版本和新版本之间切换。修复了 [#44963](https://github.com/ClickHouse/ClickHouse/issues/44963)。[#46537](https://github.com/ClickHouse/ClickHouse/pull/46537) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 默认在输出格式中使用 Parquet v2 格式而不是 v1。新增设置 `output_format_parquet_version` 来控制 Parquet 版本，可选值为 `v1_0`、`v2_4`、`v2_6`、`v2_latest` (默认值) 。[#46617](https://github.com/ClickHouse/ClickHouse/pull/46617) ([Kruglov Pavel](https://github.com/Avogar)).
* 不记入更新日志 - [#42648](https://github.com/ClickHouse/ClickHouse/issues/42648) 的一部分。[#46632](https://github.com/ClickHouse/ClickHouse/pull/46632) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 允许在推送到 MATERILIZED VIEW 时忽略错误 (新增设置 `materialized_views_ignore_errors`，默认值为 `false`，但在将日志刷新到 `system.*_log` 表时会无条件设为 `true`) 。[#46658](https://github.com/ClickHouse/ClickHouse/pull/46658) ([Azat Khuzhin](https://github.com/azat)).
* 默认启用 `input&#95;format&#95;json&#95;ignore&#95;unknown&#95;keys&#95;in&#95;named&#95;tuple`。[#46742](https://github.com/ClickHouse/ClickHouse/pull/46742) ([Kruglov Pavel](https://github.com/Avogar)).
* 现在可以使用新的配置语法来配置名称中带点号的 Kafka topic。[#46752](https://github.com/ClickHouse/ClickHouse/pull/46752) ([Robert Schulze](https://github.com/rschu1ze)).
* 修复了用于检查 hyperscan pattern 中有问题重复项的启发式逻辑。[#46819](https://github.com/ClickHouse/ClickHouse/pull/46819) ([Robert Schulze](https://github.com/rschu1ze)).
* 当某个块已由另一个副本并发创建时，不要将 ZK 节点已存在上报到 system.errors。[#46820](https://github.com/ClickHouse/ClickHouse/pull/46820) ([Raúl Marín](https://github.com/Algunenano)).
* 允许在 Merge 中对列使用不同的 DEFAULT expression 时使用 PREWHERE。[#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* 提高 `clickhouse-local` 的打开文件数限制。这样它就能在拥有大量 CPU 核心的服务器上从 `web` 表读取数据。遇到打开文件过多时，不再回退为停止从 URL table engine 读取。这解决了 [#46852](https://github.com/ClickHouse/ClickHouse/issues/46852)。[#46853](https://github.com/ClickHouse/ClickHouse/pull/46853) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 现在，当数字无法解析时抛出的 Exception 将具有更易读的异常消息。[#46917](https://github.com/ClickHouse/ClickHouse/pull/46917) ([Robert Schulze](https://github.com/rschu1ze)).
* 新增在每个已处理 task 后更新 `system.backups`。[#46989](https://github.com/ClickHouse/ClickHouse/pull/46989) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* 允许在 Native input format 中进行类型转换。新增设置 `input_format_native_allow_types_conversion` 用于控制此行为 (默认启用) 。[#46990](https://github.com/ClickHouse/ClickHouse/pull/46990) ([Kruglov Pavel](https://github.com/Avogar)).
* 允许 `range` 函数使用 IPv4 生成 IP 范围。[#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 在 [https://github.com/ClickHouse/ClickHouse/pull/46772](https://github.com/ClickHouse/ClickHouse/pull/46772) 之前，Role 变更有时不会被 promoted。这个 PR 只是新增了测试。[#47002](https://github.com/ClickHouse/ClickHouse/pull/47002) ([Ilya Golshtein](https://github.com/ilejn)).
* 改进了在无法将分片从一个 volume/disk 移动到另一个时的异常消息。[#47032](https://github.com/ClickHouse/ClickHouse/pull/47032) ([alesapin](https://github.com/alesapin)).
* 在 `JSONType` 函数中支持 `Bool` 类型。此前对于 Bool 值会误返回 `Null` 类型。[#47046](https://github.com/ClickHouse/ClickHouse/pull/47046) ([Anton Popov](https://github.com/CurtizJ)).
* 使用 &#95;request&#95;body parameter 配置预定义的 http queries。[#47086](https://github.com/ClickHouse/ClickHouse/pull/47086) ([Constantine Peresypkin](https://github.com/pkit)).
* 移除了自定义 disk 结构的日志记录。[#47103](https://github.com/ClickHouse/ClickHouse/pull/47103) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 允许嵌套的自定义 disks。此前自定义 disks 仅支持扁平的 disk 结构。[#47106](https://github.com/ClickHouse/ClickHouse/pull/47106) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 在内置 UI 的 SQL editor 中，按下 Enter 时会自动缩进。[#47113](https://github.com/ClickHouse/ClickHouse/pull/47113) ([Alexey Korepanov](https://github.com/alexkorep)).
* 允许控制 Parquet/ORC/Arrow output formats 中的压缩，并为 input formats 支持更多压缩方式。这解决了 [#13541](https://github.com/ClickHouse/ClickHouse/issues/13541)。[#47114](https://github.com/ClickHouse/ClickHouse/pull/47114) ([Kruglov Pavel](https://github.com/Avogar)).
* 使用 &#39;sudo&#39; 进行自解压时，将尝试把解压出的文件的 uid 和 gid 设置为当前运行用户。[#47116](https://github.com/ClickHouse/ClickHouse/pull/47116) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 目前，函数 repeat 的第二个参数必须是无符号整数类型，因此不能接受 -1 这样的整数值。这与 Spark 函数的行为不同，因此这里已修复为与 Spark 保持一致。测试如下。[#47134](https://github.com/ClickHouse/ClickHouse/pull/47134) ([KevinyhZou](https://github.com/KevinyhZou)).
* 从 stacktrace 中移除 `::__1` 部分。将 stacktrace 中的 `std::basic_string<char, ...` 显示为 `String`。[#47171](https://github.com/ClickHouse/ClickHouse/pull/47171) ([Mike Kot](https://github.com/myrrc)).
* 为 Backup IO 操作引入独立的线程池。这样可以与其他池独立扩展，并提升性能。[#47174](https://github.com/ClickHouse/ClickHouse/pull/47174) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 重新实现 interserver 模式以避免重放攻击 (注意，此更改与旧版 server 向后兼容) 。[#47213](https://github.com/ClickHouse/ClickHouse/pull/47213) ([Azat Khuzhin](https://github.com/azat)).
* 使函数 `optimizeregularexpression` 能识别 re 分组，并改进 regexp tree dictionary。[#47218](https://github.com/ClickHouse/ClickHouse/pull/47218) ([Han Fei](https://github.com/hanfei1991)).
* 在 Backup 处理的最后阶段收集 metadata 时，使用 MultiRead 读取请求和 retries。[#47243](https://github.com/ClickHouse/ClickHouse/pull/47243) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Keeper 改进：新增 4LW `clrs`，用于清理 Keeper 使用的资源 (例如释放未使用的内存) 。[#47256](https://github.com/ClickHouse/ClickHouse/pull/47256) ([Antonio Andelic](https://github.com/antonio2368)).
* 为编解码器 `DoubleDelta(bytes_size)`、`Gorilla(bytes_size)`、`FPC(level, float_size)` 添加可选参数，从而允许在 `clickhouse-compressor` 中无需指定 column type 即可使用这些编解码器。修复了 `clickhouse-compressor` 在使用这些编解码器时可能出现的崩溃和算术错误。修复内容见：[https://github.com/ClickHouse/ClickHouse/discussions/47262](https://github.com/ClickHouse/ClickHouse/discussions/47262)。[#47271](https://github.com/ClickHouse/ClickHouse/pull/47271) ([Kruglov Pavel](https://github.com/Avogar)).
