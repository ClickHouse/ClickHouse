<div id="clickhouse-release-v213655-lts-fixme-as-compared-to-v213542-lts">
  ### ClickHouse 版本 v21.3.6.55-lts FIXME (相较于 v21.3.5.42-lts)
</div>

<div id="improvement">
  #### 改进
</div>

* 已回移到 [#22811](https://github.com/ClickHouse/ClickHouse/issues/22811)：如果 PODArray 在实例化时的元素大小既不是 16 的因数，也不是 16 的倍数，则可能发生缓冲区溢出。当前发行版中不存在此类问题。[#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已回移到 [#22823](https://github.com/ClickHouse/ClickHouse/issues/22823)：新增 profile 事件 HedgedRequestsChangeReplica，并将读取数据超时从秒改为毫秒。[#21886](https://github.com/ClickHouse/ClickHouse/pull/21886) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已回移到 [#22936](https://github.com/ClickHouse/ClickHouse/issues/22936)：正确检查异步分布式块的结构。[#22325](https://github.com/ClickHouse/ClickHouse/pull/22325) ([Azat Khuzhin](https://github.com/azat)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已回移到 [#22968](https://github.com/ClickHouse/ClickHouse/issues/22968) 中：修复一个极少出现的缺陷：启用 `quorum_parallel=1` 时，quorum insert 会因去重而实际上不满足“quorum”要求。[#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* 已回移到 [#22723](https://github.com/ClickHouse/ClickHouse/issues/22723) 中：检查 table function view 是否被当作列使用。这是对 [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350) 的补充。[#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* 已回移到 [#22807](https://github.com/ClickHouse/ClickHouse/issues/22807) 中：对 [#21936](https://github.com/ClickHouse/ClickHouse/issues/21936) 的后续修复。同时也修复了 [#22433](https://github.com/ClickHouse/ClickHouse/issues/22433)。[#22518](https://github.com/ClickHouse/ClickHouse/pull/22518) ([Ivan](https://github.com/abyss7)).
* 已回移到 [#22759](https://github.com/ClickHouse/ClickHouse/issues/22759) 中：修复函数 `map` 在分布式查询中的使用问题。[#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* 已回移到 [#22701](https://github.com/ClickHouse/ClickHouse/issues/22701) 中：修复 ReplicatedMergeTree 表引擎在多个副本上等待 mutations 时的问题。此前，mutation/alter 查询可能会在其他副本上的 mutation 实际执行前就已结束。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* 已回移到 [#22738](https://github.com/ClickHouse/ClickHouse/issues/22738) 中：修复发生 OOM exception 时 zk requests 可能卡住的问题。修复了 [#22438](https://github.com/ClickHouse/ClickHouse/issues/22438)。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已回移到 [#22892](https://github.com/ClickHouse/ClickHouse/issues/22892) 中：修复从 MergeTree 反向读取时总行数近似统计不准确的问题。[#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* 已回移到 [#22922](https://github.com/ClickHouse/ClickHouse/issues/22922) 中：修复过滤器列用于 aggregation 时 `HAVING` 下推的问题。[#22763](https://github.com/ClickHouse/ClickHouse/pull/22763) ([Anton Popov](https://github.com/CurtizJ)).
* 已回移到 [#22916](https://github.com/ClickHouse/ClickHouse/issues/22916) 中：LIVE VIEW (Experimental 功能) 。修复 `TemporaryLiveViewCleaner` 中并发执行 TEMPORARY LIVE VIEW 的 DROP/CREATE 时可能发生卡住的问题，参见 [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e)。[#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已回移到 [#22920](https://github.com/ClickHouse/ClickHouse/issues/22920) 中：修复使用 `mannWhitneyUTest` 和 `rankCorr` 配合窗口函数时发生崩溃的问题。此修复解决了 [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728)。[#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
