<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#42329](https://github.com/ClickHouse/ClickHouse/issues/42329) 中回移：将 cctz 更新到最新的 master，并将 tzdb 更新到 2020e。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano)).
* 已在 [#42359](https://github.com/ClickHouse/ClickHouse/issues/42359) 中回移：将 tzdata 更新到 2022e，以支持新的 timezone 变更。巴勒斯坦的切换时间现改为周六 02:00。将乌克兰的三个时区合并为一个。约旦和叙利亚从采用夏令时的 +02/+03 切换为全年 +03。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS))。这关闭了 [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252)。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#42268](https://github.com/ClickHouse/ClickHouse/issues/42268) 中回移：修复了复用 base backup 中大于 4GB 的文件时的问题。[#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#42299](https://github.com/ClickHouse/ClickHouse/issues/42299) 中回移：修复了 projections 与 `aggregate_functions_null_for_empty` 设置相关的一个 bug。这个 bug 非常罕见，只有在 server 的 config 中启用 `aggregate_functions_null_for_empty` 设置时才会出现。此项关闭了 [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647)。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#42386](https://github.com/ClickHouse/ClickHouse/issues/42386) 中回移：对已附加的分片 (其列与表 schema 不同) 执行 `ALTER UPDATE` 时，可能会在磁盘上创建无效的 `columns.txt` 元数据。读取此类分片时，可能会报错失败或返回无效数据。修复了 [#42161](https://github.com/ClickHouse/ClickHouse/issues/42161)。[#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#42498](https://github.com/ClickHouse/ClickHouse/issues/42498) 中回移：`additional_table_filters` 设置未应用于 `Distributed` 存储。修复了 [#41692](https://github.com/ClickHouse/ClickHouse/issues/41692)。[#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#42593](https://github.com/ClickHouse/ClickHouse/issues/42593) 中回移：此项关闭了 [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453)。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
