<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#64982](https://github.com/ClickHouse/ClickHouse/issues/64982) 中回移：修复当 materialized view 的列类型与源表不同时，查询从 materialized view 使用 `PREWHERE` 读取时出现 `Block structure mismatch` 错误的问题。修复了 [#64611](https://github.com/ClickHouse/ClickHouse/issues/64611)。[#64855](https://github.com/ClickHouse/ClickHouse/pull/64855) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#64974](https://github.com/ClickHouse/ClickHouse/issues/64974) 中回移：修复表在使用带有子查询 + replicated 数据库 + 并行副本 + analyzer 的 TTL 时极少发生的崩溃问题。这种情况确实非常罕见，但仍请不要将 TTL 与子查询一起使用。[#64858](https://github.com/ClickHouse/ClickHouse/pull/64858) ([alesapin](https://github.com/alesapin)).
* 已在 [#65072](https://github.com/ClickHouse/ClickHouse/issues/65072) 中回移：修复 [https://github.com/ClickHouse/ClickHouse/pull/54211](https://github.com/ClickHouse/ClickHouse/pull/54211) 中导致参数化 VIEW 的 `ALTER MODIFY COMMENT` 查询失效的问题。[#65031](https://github.com/ClickHouse/ClickHouse/pull/65031) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#65177](https://github.com/ClickHouse/ClickHouse/issues/65177) 中回移：修复远程查询在使用 `INTERPOLATE (alias)` (新 analyzer) 时出现 `Unknown expression identifier` 错误的问题。修复了 [#64636](https://github.com/ClickHouse/ClickHouse/issues/64636)。[#65090](https://github.com/ClickHouse/ClickHouse/pull/65090) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#65263](https://github.com/ClickHouse/ClickHouse/issues/65263) 中回移：修复 Hashed 和 Hashed&#95;Array 字典短路求值中的缺陷，该问题可能会读取未初始化的数值，从而导致各种错误。[#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)).
