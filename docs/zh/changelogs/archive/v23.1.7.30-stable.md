  ### ClickHouse 发布版本 v23.1.7.30-stable (c94dba6e023) FIXME，与 v23.1.6.42-stable (783ddf67991) 相比
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#48161](https://github.com/ClickHouse/ClickHouse/issues/48161) 中回移：修复了附加某个 materialized view 时，若其依赖的表不可用会报 `UNKNOWN_TABLE` 异常的问题。这在尝试从备份中恢复状态时可能会很有帮助。[#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#48585](https://github.com/ClickHouse/ClickHouse/issues/48585) 中回移：更新时区信息。以下时区已更新：Africa/Cairo、Africa/Casablanca、Africa/El&#95;Aaiun、America/Bogota、America/Cambridge&#95;Bay、America/Ciudad&#95;Juarez、America/Godthab、America/Inuvik、America/Iqaluit、America/Nuuk、America/Ojinaga、America/Pangnirtung、America/Rankin&#95;Inlet、America/Resolute、America/Whitehorse、America/Yellowknife、Asia/Gaza、Asia/Hebron、Asia/Kuala&#95;Lumpur、Asia/Singapore、Canada/Yukon、Egypt、Europe/Kirov、Europe/Volgograd、Singapore。[#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#48958](https://github.com/ClickHouse/ClickHouse/issues/48958) 中回移：在最近一次更新后，`dockerd` 需要显式指定 HTTP 端口，并同时使用 `--tlsverify=false`。[#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 修复带有 limit 的 grace hash join 中的竞态问题 [#47153](https://github.com/ClickHouse/ClickHouse/pull/47153) ([Vladimir C](https://github.com/vdimir)).
* 修复带有 projection 的 explain graph [#47473](https://github.com/ClickHouse/ClickHouse/pull/47473) ([flynn](https://github.com/ucasfl)).
* 修复 polygonsSymDifferenceCartesian 中的崩溃问题 [#47702](https://github.com/ClickHouse/ClickHouse/pull/47702) ([pufit](https://github.com/pufit)).
* 移除一项功能 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复 ClickHouse 在加载依赖字典的分布式表时启动报错的问题 [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 修复 cache 中可能出现的 segfault 问题 [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 修复键为 IP 和 UUID 类型的嵌套 map 问题 [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 修复 Keeper 中的一个缺陷：在 ACL 中，有时节点不会以 scheme `auth` 创建。 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 修复 IPv4 与 UInt 的比较问题 [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
