<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#21352](https://github.com/ClickHouse/ClickHouse/issues/21352) 中回移：修复了标量子查询和用于索引的子查询的线程数问题 (在 [#19007](https://github.com/ClickHouse/ClickHouse/issues/19007) 之后一直都会使用单线程) 。修复了 [#20457](https://github.com/ClickHouse/ClickHouse/issues/20457)、[#20512](https://github.com/ClickHouse/ClickHouse/issues/20512)。[#20550](https://github.com/ClickHouse/ClickHouse/pull/20550) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#21262](https://github.com/ClickHouse/ClickHouse/issues/21262) 中回移：修复了在 Replicated(*)MergeTree 引擎需要指定其他参数时，default&#95;replica&#95;path 和 default&#95;replica&#95;name 配置值无效的问题。[#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy))。
* 已在 [#21156](https://github.com/ClickHouse/ClickHouse/issues/21156) 中回移：修复了将 tuple 转换为 map 时的相关缺陷。关闭了 [#21029](https://github.com/ClickHouse/ClickHouse/issues/21029)。[#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting))。
* 已在 [#21234](https://github.com/ClickHouse/ClickHouse/issues/21234) 中回移：现在，只有支持变更的表引擎才允许执行变更 (MergeTree 家族、Memory、MaterializedView) 。其他引擎会返回更清晰的错误信息。修复了 [#21168](https://github.com/ClickHouse/ClickHouse/issues/21168)。[#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin))。
* 已在 [#21427](https://github.com/ClickHouse/ClickHouse/issues/21427) 中回移：修复了带有 `UNION` 的查询在执行 `EXPLAIN` 时发生崩溃的问题。修复了 [#20876](https://github.com/ClickHouse/ClickHouse/issues/20876)、[#21170](https://github.com/ClickHouse/ClickHouse/issues/21170)。[#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl))。
* 已在 [#21301](https://github.com/ClickHouse/ClickHouse/issues/21301) 中回移：修复了到 ZooKeeper 的冗余重连问题，以及单个 ClickHouse server 出现两个活动会话的可能性。这两个问题均是在 [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678) 中引入的。[#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin))。
* 已在 [#21553](https://github.com/ClickHouse/ClickHouse/issues/21553) 中回移：现在 `ALTER MODIFY COLUMN` 查询会正确应用到分区键、跳过索引、生存时间 (TTL) 等的变更。修复了 [#13675](https://github.com/ClickHouse/ClickHouse/issues/13675)。[#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin))。
* 已在 [#21380](https://github.com/ClickHouse/ClickHouse/issues/21380) 中回移：修复了从 `Values` format 向包含 `LowCardinality` 列的表插入数据时出现的错误 `Bad cast from type ... to DB::ColumnLowCardinality`。修复了 [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140)。[#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
