<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (正式稳定版本中的用户可见异常表现)
</div>

* 已在 [#40162](https://github.com/ClickHouse/ClickHouse/issues/40162) 中回移：修复了当列为 const 时，HashMethodOneNumber 获取错误键值的问题。[#40020](https://github.com/ClickHouse/ClickHouse/pull/40020) ([Duc Canh Le](https://github.com/canhld94)).
* 已在 [#40124](https://github.com/ClickHouse/ClickHouse/issues/40124) 中回移：通过为需要重新计算的索引添加正确的文件扩展名 (.idx 或 idx2) ，修复了 collectFilesToSkip() 中的缺陷，从而避免错误创建硬链接。修复了 [#39896](https://github.com/ClickHouse/ClickHouse/issues/39896)。[#40095](https://github.com/ClickHouse/ClickHouse/pull/40095) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* 已在 [#40209](https://github.com/ClickHouse/ClickHouse/issues/40209) 中回移：修复了加密函数参数检查不足的问题 (由查询 fuzzer 发现) 。此更改关闭了 [#39987](https://github.com/ClickHouse/ClickHouse/issues/39987)。[#40194](https://github.com/ClickHouse/ClickHouse/pull/40194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#40281](https://github.com/ClickHouse/ClickHouse/issues/40281) 中回移：修复了 CapnProto input format 中可能发生的 segfault。该缺陷由 *kiojj* 通过 ClickHouse 缺陷赏金[计划](https://github.com/ClickHouse/ClickHouse/issues/38986)发现并提交。[#40241](https://github.com/ClickHouse/ClickHouse/pull/40241) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#40489](https://github.com/ClickHouse/ClickHouse/issues/40489) 中回移：修复了 MergeTree 引擎家族中与列生存时间 (TTL) 相关的一个罕见缺陷：在重复进行 vertical merge 时，可能会出现错误 `Cannot unlink file ColumnName.bin ... No such file or directory.`。[#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
