* 已在 [#42297](https://github.com/ClickHouse/ClickHouse/issues/42297) 中回移：将 cctz 更新到最新的 master，并将 tzdb 更新到 2020e。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano)).
* 已在 [#42361](https://github.com/ClickHouse/ClickHouse/issues/42361) 中回移：将 tzdata 更新到 2022e，以支持新的时区变更。巴勒斯坦的切换时间现改为周六 02:00。将乌克兰的三个时区合并为一个。约旦和叙利亚从带夏令时的 +02/+03 切换为全年 +03。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS))。此变更修复了 [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252)。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#42122](https://github.com/ClickHouse/ClickHouse/issues/42122) 中回移：修复了 `"Part ... intersects part ..."` 错误。在极少数情况下，如果副本在将某个分片标记为损坏并分离后立即重启，可能会触发该错误。[#41741](https://github.com/ClickHouse/ClickHouse/pull/41741) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#41938](https://github.com/ClickHouse/ClickHouse/issues/41938) 中回移：不再允许创建或修改带有虚拟列名 `_row_exists` 的 MergeTree 表，因为该名称保留给轻量级删除使用。修复了 [#41716](https://github.com/ClickHouse/ClickHouse/issues/41716)。[#41763](https://github.com/ClickHouse/ClickHouse/pull/41763) ([Jianmei Zhang](https://github.com/zhangjmruc))。
* 已在 [#42179](https://github.com/ClickHouse/ClickHouse/issues/42179) 中回移：修复了复用基础备份中大于 4GB 文件的问题。[#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#42301](https://github.com/ClickHouse/ClickHouse/issues/42301) 中回移：修复了 projections 与 `aggregate_functions_null_for_empty` 设置相关的一个缺陷。该缺陷非常罕见，仅会在你于 server 的 config 中启用 `aggregate_functions_null_for_empty` 设置时出现。此更改关闭了 [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647)。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#42388](https://github.com/ClickHouse/ClickHouse/issues/42388) 中回移：对已附加的分片执行 `ALTER UPDATE` (其列与表 schema 不同) 时，可能会在磁盘上生成无效的 `columns.txt` 元数据。读取此类分片时可能报错失败，或返回无效数据。修复了 [#42161](https://github.com/ClickHouse/ClickHouse/issues/42161)。[#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#42500](https://github.com/ClickHouse/ClickHouse/issues/42500) 中回移：设置 `additional_table_filters` 未应用于 `Distributed` 存储。修复了 [#41692](https://github.com/ClickHouse/ClickHouse/issues/41692)。[#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* 已在 [#42581](https://github.com/ClickHouse/ClickHouse/issues/42581) 中回移：此更改回退了 [#40217](https://github.com/ClickHouse/ClickHouse/issues/40217)，该变更曾在日期/时间函数中引入回归问题。[#42367](https://github.com/ClickHouse/ClickHouse/pull/42367) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#42572](https://github.com/ClickHouse/ClickHouse/issues/42572) 中回移：修复了处理 Decimal 数据类型时的缓冲区溢出问题。此更改关闭了 [#42451](https://github.com/ClickHouse/ClickHouse/issues/42451)。[#42465](https://github.com/ClickHouse/ClickHouse/pull/42465) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#42595](https://github.com/ClickHouse/ClickHouse/issues/42595) 中回移：此更改关闭了 [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453)。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
