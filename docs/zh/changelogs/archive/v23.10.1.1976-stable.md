  ### ClickHouse 发布 v23.10.1.1976-稳定版本 (13adae0e42f) FIXME，相较于 v23.9.1.1854-稳定版本 (8f9a227de1f)
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容变更
</div>

* 完全重写了 S3Queue 存储：更改了在 ZooKeeper 中保存信息的方式，以减少 ZooKeeper 请求；在可以确定状态不会变化的情况下，增加了对 ZooKeeper 状态的缓存；改进了从 S3 轮询的流程，降低了其激进程度；还更改了对已跟踪文件的 ttl 和 max set 的维护方式，现改为后台进程。新增了 `system.s3queue` 和 `system.s3queue_log` 表。关闭了 [#54998](https://github.com/ClickHouse/ClickHouse/issues/54998)。[#54422](https://github.com/ClickHouse/ClickHouse/pull/54422) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 不再提供自动移除损坏数据分区片段的选项。此更改关闭了 [#55174](https://github.com/ClickHouse/ClickHouse/issues/55174)。[#55184](https://github.com/ClickHouse/ClickHouse/pull/55184) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已废弃的内存中数据分区片段将无法再从预写日志中读取。如果你之前配置过内存中的 parts，则必须在升级前将其移除。[#55186](https://github.com/ClickHouse/ClickHouse/pull/55186) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 移除了与 Meilisearch 的集成。原因：它仅兼容旧版 0.18。Meilisearch 的新版本更改了协议，因此现已无法使用。注意：如果你愿意帮助恢复该集成，我们将不胜感激。[#55189](https://github.com/ClickHouse/ClickHouse/pull/55189) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 将 directory monitor 概念重命名为后台 INSERT。所有 `*directory_monitor*` 设置均已重命名为 `distributed_background_insert*`。**应保留向后兼容性** (因为旧设置已作为别名添加) 。[#55978](https://github.com/ClickHouse/ClickHouse/pull/55978) ([Azat Khuzhin](https://github.com/azat)).
* 不再混淆 send&#95;timeout 和 receive&#95;timeout。[#56035](https://github.com/ClickHouse/ClickHouse/pull/56035) ([Azat Khuzhin](https://github.com/azat)).
* 比较不同单位的时间间隔时将抛出异常。此更改关闭了 [#55942](https://github.com/ClickHouse/ClickHouse/issues/55942)。你可能偶尔依赖过此前的行为，即无论单位为何，都会直接比较底层数值。[#56090](https://github.com/ClickHouse/ClickHouse/pull/56090) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新特性
</div>

* 添加函数 &quot;arrayFold(x1, ..., xn, accum -&gt; expression, array1, ..., arrayn, init&#95;accum)&quot;，该函数可将 lambda function 应用于多个基数相同的数组，并将结果累积到累加器中。[#49794](https://github.com/ClickHouse/ClickHouse/pull/49794) ([Lirikl](https://github.com/Lirikl)).
* 添加聚合函数 lttb，它使用 [Largest-Triangle-Three-Buckets](https://skemman.is/bitstream/1946/15343/3/SS_MSthesis.pdf) 算法对数据进行降采样，以便用于可视化。[#53145](https://github.com/ClickHouse/ClickHouse/pull/53145) ([Sinan](https://github.com/sinsinan)).
* 查询 `CHECK TABLE` 具有更好的性能和可用性 (会发送 Progress 更新，并且可取消) 。支持使用 `CHECK TABLE ... PART 'part_name'` 检查特定分片。[#53404](https://github.com/ClickHouse/ClickHouse/pull/53404) ([vdimir](https://github.com/vdimir)).
* 添加函数 `jsonMergePatch`。在将 JSON 数据作为字符串处理时，它提供了一种将这些字符串 (即 JSON object 的字符串表示) 合并为单个字符串的方法，结果中仅包含一个 JSON object。[#54364](https://github.com/ClickHouse/ClickHouse/pull/54364) ([Memo](https://github.com/Joeywzr)).
* 添加新的 SQL function：&quot;arrayRandomSample(arr, k)&quot;，它从输入数组中返回一个包含 k 个元素的样本。此前，类似功能只能通过不太方便的语法实现，例如 &quot;SELECT arrayReduce(&#39;groupArraySample(3)&#39;, range(10))&quot;。[#54391](https://github.com/ClickHouse/ClickHouse/pull/54391) ([itayisraelov](https://github.com/itayisraelov)).
* 添加新函数 `getHttpHeader`，用于获取发送到 ClickHouse server 的请求所使用的 HTTP 请求头值。如果请求不是通过 HTTP protocol 发出的，或不存在该请求头，则返回空字符串。[#54813](https://github.com/ClickHouse/ClickHouse/pull/54813) ([凌涛](https://github.com/lingtaolf)).
* 引入 -ArgMin/-ArgMax aggregate combinators，它们允许仅按最小值/最大值进行聚合。可在 [#54818](https://github.com/ClickHouse/ClickHouse/issues/54818) 中查看一个用例。此 PR 还将 combinators 重新整理到了专用文件夹中。[#54947](https://github.com/ClickHouse/ClickHouse/pull/54947) ([Amos Bird](https://github.com/amosbird)).
* 允许使用 `SYSTEM DROP SCHEMA FORMAT CACHE [FOR Protobuf]` 删除 Protobuf format 的缓存。[#55064](https://github.com/ClickHouse/ClickHouse/pull/55064) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* 添加外部 HTTP Basic authenticator。[#55199](https://github.com/ClickHouse/ClickHouse/pull/55199) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 添加函数 `byteSwap`，用于反转无符号整数的字节序。这对于反转那些在内部表示为无符号整数的类型值特别有用，例如 IPv4。[#55211](https://github.com/ClickHouse/ClickHouse/pull/55211) ([Priyansh Agrawal](https://github.com/Priyansh121096)).
* 添加函数 `formatQuery()`，它返回 SQL 查询字符串的格式化版本 (可能跨多行) 。同时还添加了函数 `formatQuerySingleLine()`，功能相同，但返回的字符串不包含换行符。[#55239](https://github.com/ClickHouse/ClickHouse/pull/55239) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* 添加 DWARF input format，用于从 ELF 可执行文件、库或 object file 中读取调试符号。[#55450](https://github.com/ClickHouse/ClickHouse/pull/55450) ([Michael Kolupaev](https://github.com/al13n321)).
* 允许在 RabbitMQ、NATS 和 FileLog 引擎中保存未解析的记录和错误。新增虚拟列 `_error`，以及 `_raw_message` (用于 NATS 和 RabbitMQ) 和 `_raw_record` (用于 FileLog) ；当 ClickHouse 无法解析新记录时，这些列会被填充。该行为通过存储设置控制：NATS 使用 `nats_handle_error_mode`，RabbitMQ 使用 `rabbitmq_handle_error_mode`，FileLog 使用 `handle_error_mode`，类似于 `kafka_handle_error_mode`。如果将其设置为 `default`，则在 ClickHouse 无法解析记录时会抛出异常；如果设置为 `stream`，则会将错误和原始记录保存到虚拟列中。关闭 [#36035](https://github.com/ClickHouse/ClickHouse/issues/36035)。[#55477](https://github.com/ClickHouse/ClickHouse/pull/55477) ([Kruglov Pavel](https://github.com/Avogar)) 。
* Keeper 客户端改进：新增 get&#95;all&#95;children&#95;number 命令，返回指定路径下所有子节点的数量。[#55485](https://github.com/ClickHouse/ClickHouse/pull/55485) ([guoxiaolong](https://github.com/guoxiaolongzte)) 。
* 如果某个表的键中包含空间填充曲线，例如 `ORDER BY mortonEncode(x, y)`，则其参数上的条件 (例如 `x >= 10 AND x <= 20 AND y >= 20 AND y <= 30`) 可用于索引。新增设置 `analyze_index_with_space_filling_curves`，用于启用或禁用此分析。此项关闭 [#41195](https://github.com/ClickHouse/ClickHouse/issues/41195)。延续 [#4538](https://github.com/ClickHouse/ClickHouse/issues/4538)。延续 [#6286](https://github.com/ClickHouse/ClickHouse/issues/6286)。延续 [#28130](https://github.com/ClickHouse/ClickHouse/issues/28130)。延续 [#41753](https://github.com/ClickHouse/ClickHouse/issues/41753)。[#55642](https://github.com/ClickHouse/ClickHouse/pull/55642) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 新增设置 `optimize_trivial_approximate_count_query`，用于让存储 EmbeddedRocksDB 使用 `count()` 近似值。为 StorageJoin 启用 trivial count。[#55806](https://github.com/ClickHouse/ClickHouse/pull/55806) ([Duc Canh Le](https://github.com/canhld94)) 。
* Keeper 客户端改进：新增 get&#95;direct&#95;children&#95;number 命令，返回指定路径下直接子节点的数量。[#55898](https://github.com/ClickHouse/ClickHouse/pull/55898) ([xuzifu666](https://github.com/xuzifu666)) 。
* 新增语句 `SHOW SETTING setting_name`，它是现有语句 `SHOW SETTINGS` 的简化版本。[#55979](https://github.com/ClickHouse/ClickHouse/pull/55979) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 此 PR 支持将 Npy format 的数据传递给 ClickHouse。&#96;&#96;&#96; SELECT * FROM file(&#39;example&#95;array.npy&#39;, Npy). [#55982](https://github.com/ClickHouse/ClickHouse/pull/55982) ([Yarik Briukhovetskyi](https://github.com/yariks5s)) 。
* 此 PR 实现了一个名为 `force_optimize_projection_name` 的新设置，它接受一个 projection 名称作为参数。如果其值设置为非空字符串，ClickHouse 会检查该 projection 是否在查询中至少使用过一次。关闭 [#55331](https://github.com/ClickHouse/ClickHouse/issues/55331)。[#56134](https://github.com/ClickHouse/ClickHouse/pull/56134) ([Yarik Briukhovetskyi](https://github.com/yariks5s)) 。

<div id="performance-improvement">
  #### 性能提升
</div>

* 添加选项 `query_plan_preserve_num_streams_after_window_functions`，在计算窗口函数后保留流的数量，以支持并行流处理。[#50771](https://github.com/ClickHouse/ClickHouse/pull/50771) ([frinkr](https://github.com/frinkr)).
* 数据量较小时，释放更多 num&#95;streams。[#53867](https://github.com/ClickHouse/ClickHouse/pull/53867) ([Jiebin Sun](https://github.com/jiebinn)).
* 在序列化前优化 RoaringBitmaps。[#55044](https://github.com/ClickHouse/ClickHouse/pull/55044) ([UnamedRus](https://github.com/UnamedRus)).
* 倒排索引中的倒排列表现已优化为对内部 bitmap 使用尽可能小的表示形式。根据数据的重复程度，这可能会显著减少倒排索引的空间占用。[#55069](https://github.com/ClickHouse/ClickHouse/pull/55069) ([Harry Lee](https://github.com/HarryLeeIBM)).
* 修复了 Context 锁竞争问题，这显著提升了大量短时运行的并发查询的性能。[#55121](https://github.com/ClickHouse/ClickHouse/pull/55121) ([Maksim Kita](https://github.com/kitaisreal)).
* 倒排索引的创建性能提升了 30%。这是通过将 `std::unordered_map` 替换为 `absl::flat_hash_map` 实现的。[#55210](https://github.com/ClickHouse/ClickHouse/pull/55210) ([Harry Lee](https://github.com/HarryLeeIBM)).
* 支持 ORC 过滤器下推 (row group 级别) 。[#55330](https://github.com/ClickHouse/ClickHouse/pull/55330) ([李扬](https://github.com/taiyang-li)).
* 提升存在大量临时 File 时的外部聚合性能。[#55489](https://github.com/ClickHouse/ClickHouse/pull/55489) ([Maksim Kita](https://github.com/kitaisreal)).
* 默认情况下为次级索引的标记缓存设置合理大小，以避免反复加载标记。[#55654](https://github.com/ClickHouse/ClickHouse/pull/55654) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 读取跳过索引时，避免不必要地重建索引粒度。这解决了 [#55653](https://github.com/ClickHouse/ClickHouse/issues/55653)#issuecomment-1763766009 中的问题。[#55683](https://github.com/ClickHouse/ClickHouse/pull/55683) ([Amos Bird](https://github.com/amosbird)).
* 在执行期间缓存 set 中的 CAST 函数，以提升当 set 元素类型与列类型不完全匹配时 `IN` 函数的性能。[#55712](https://github.com/ClickHouse/ClickHouse/pull/55712) ([Duc Canh Le](https://github.com/canhld94)).
* 提升 `ColumnVector::insertMany` 和 `ColumnVector::insertManyFrom` 的性能。[#55714](https://github.com/ClickHouse/ClickHouse/pull/55714) ([frinkr](https://github.com/frinkr)).
* ... 从 map 中取值非常常见。实践中，同一个 Map 列中的 key 结构通常相同，因此可以尝试预测下一行 key 的位置并减少比较次数。[#55929](https://github.com/ClickHouse/ClickHouse/pull/55929) ([lgbo](https://github.com/lgbo-ustc)).
* ... 修复了一个问题：struct 字段裁剪在某些情况下不生效。例如 &#96;&#96;&#96;sql INSERT INTO FUNCTION file(&#39;test&#95;parquet&#95;struct&#39;, Parquet, &#39;x Tuple(a UInt32, b UInt32, c String)&#39;) SELECT tuple(number, rand(), concat(&#39;testxxxxxxx&#39; toString(number))) FROM numbers(10);. [#56117](https://github.com/ClickHouse/ClickHouse/pull/56117) ([lgbo](https://github.com/lgbo-ustc)).

  #### 改进

* 这是 Kusto 查询语言方言支持的第二部分。[Phase 1 implementation ](https://github.com/ClickHouse/ClickHouse/pull/37961) 已合并。[#42510](https://github.com/ClickHouse/ClickHouse/pull/42510) ([larryluogit](https://github.com/larryluogit)).
* Op 处理器 ID 是转换为 UInt64 的原始 ptr。现以更美观的方式打印。[#48852](https://github.com/ClickHouse/ClickHouse/pull/48852) ([Vlad Seliverstov](https://github.com/behebot)).
* 创建设置了 lifetime 字段的 direct 字典时，会在创建阶段被拒绝。修复：[#27861](https://github.com/ClickHouse/ClickHouse/issues/27861)。[#49043](https://github.com/ClickHouse/ClickHouse/pull/49043) ([Rory Crispin](https://github.com/RoryCrispin)).
* 允许在带有分区的查询中使用参数，例如 `ALTER TABLE t DROP PARTITION`。关闭 [#49449](https://github.com/ClickHouse/ClickHouse/issues/49449)。[#49516](https://github.com/ClickHouse/ClickHouse/pull/49516) ([Nikolay Degterinsky](https://github.com/evillique)).
* 1.重构 zookeeper&#95;connection 相关代码 2.为 zookeeper&#95;connection 新增一列 xid。[#50702](https://github.com/ClickHouse/ClickHouse/pull/50702) ([helifu](https://github.com/helifu)).
* 新增能力：可根据待读取行数的估算值，调整查询执行中使用的并行副本数量。[#51692](https://github.com/ClickHouse/ClickHouse/pull/51692) ([Raúl Marín](https://github.com/Algunenano)).
* 在 `async_socket_for_remote` 模式 (默认) 下执行的分布式查询现在会遵守 `max_threads` 限制。此前，某些查询可能会创建过多线程 (最多可达 `max_distributed_connections`) ，从而导致服务器性能问题。[#53504](https://github.com/ClickHouse/ClickHouse/pull/53504) ([filimonov](https://github.com/filimonov)).
* 重新加载后显示正确的服务器设置。[#53774](https://github.com/ClickHouse/ClickHouse/pull/53774) ([helifu](https://github.com/helifu)).
* 在查询中新增对数学减号字符 `−` 的支持，效果类似于 `-`。[#54100](https://github.com/ClickHouse/ClickHouse/pull/54100) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 Replicated 数据库引擎添加副本组。关闭 [#53620](https://github.com/ClickHouse/ClickHouse/issues/53620)。[#54421](https://github.com/ClickHouse/ClickHouse/pull/54421) ([Nikolay Degterinsky](https://github.com/evillique)).
* 此 PR 将修复 [这里](https://github.com/ClickHouse/ClickHouse/pull/54566) 的 UBsan 测试错误。[#54568](https://github.com/ClickHouse/ClickHouse/pull/54568) ([JackyWoo](https://github.com/JackyWoo)).
* 支持通过原生协议处理带外部数据的异步插入。此前仅在数据内联到查询中时才支持。[#54730](https://github.com/ClickHouse/ClickHouse/pull/54730) ([Anton Popov](https://github.com/CurtizJ)).
* 与其让查询完全失败，不如对可重试的 S3 错误进行重试。默认将 s3&#95;retry&#95;attempts 设为更大的值。[#54770](https://github.com/ClickHouse/ClickHouse/pull/54770) ([Sema Checherinda](https://github.com/CheSema)).
* 在生成大量临时 File 的情况下，优化了外部聚合的内存消耗。[#54798](https://github.com/ClickHouse/ClickHouse/pull/54798) ([Nikita Taranov](https://github.com/nickitat)).
* 新增负载均衡 test&#95;hostname&#95;levenshtein&#95;distance。[#54826](https://github.com/ClickHouse/ClickHouse/pull/54826) ([JackyWoo](https://github.com/JackyWoo)).
* 在从 Zookeeper 分布式 DDL 队列执行 DDL 时，缓存可跳过的条目。[#54828](https://github.com/ClickHouse/ClickHouse/pull/54828) ([Duc Canh Le](https://github.com/canhld94)).
* 改进了在日志中隐藏 secrets 的机制。[#55089](https://github.com/ClickHouse/ClickHouse/pull/55089) ([Vitaly Baranov](https://github.com/vitlibar)).
* 向 `system.parts_columns` 表添加了 `substreams` 和 `filenames` 字段。[#55108](https://github.com/ClickHouse/ClickHouse/pull/55108) ([Anton Popov](https://github.com/CurtizJ)).
* 目前 projection 分析将仅基于查询计划执行。设置 `query_plan_optimize_projection` 已废弃 (很久以前它就已默认启用) 。[#55112](https://github.com/ClickHouse/ClickHouse/pull/55112) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 现在，当函数 &quot;untuple()&quot; 作用于包含命名元素的 tuple，且函数本身也带有 alias (例如 &quot;select untuple(tuple(1)::Tuple(element&#95;alias Int)) AS untuple&#95;alias&quot;) 时，结果列名会根据 untuple 的 alias 和 tuple 元素的 alias 生成 (在该示例中为：&quot;untuple&#95;alias.element&#95;alias&quot;) 。[#55123](https://github.com/ClickHouse/ClickHouse/pull/55123) ([garcher22](https://github.com/garcher22)).
* 添加了设置 `describe_include_virtual_columns`，允许将表的 virtual columns 包含在 `DESCRIBE` 查询结果中。还新增了设置 `describe_compact_output`。如果将其设为 `true`，`DESCRIBE` 查询将仅返回列名和类型，不包含额外信息。[#55129](https://github.com/ClickHouse/ClickHouse/pull/55129) ([Anton Popov](https://github.com/CurtizJ)).
* 有时，带有 `optimize_throw_if_noop=1` 的 `OPTIMIZE` 可能会因 `unknown reason` 错误而失败，而真正原因是不同 parts 中存在不同的 projections。此问题已修复。[#55130](https://github.com/ClickHouse/ClickHouse/pull/55130) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 允许多个 MaterializedPostgreSQL 表跟踪同一个 Postgres 表。默认情况下此行为未启用 (出于兼容性考虑，因为这是一个不向后兼容的变更) ，但可以通过设置 `materialized_postgresql_use_unique_replication_consumer_identifier` 启用。关闭 [#54918](https://github.com/ClickHouse/ClickHouse/issues/54918)。[#55145](https://github.com/ClickHouse/ClickHouse/pull/55145) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 允许从短字符串中解析带小数部分的负数 DateTime64 和 日期时间。[#55146](https://github.com/ClickHouse/ClickHouse/pull/55146) ([Andrey Zvonov](https://github.com/zvonand)).
* 为提高与 MySQL 的兼容性，1. &quot;information&#95;schema.tables&quot; 现在包含新字段 &quot;table&#95;rows&quot;；2. &quot;information&#95;schema.columns&quot; 现在包含新字段 &quot;extra&quot;。[#55215](https://github.com/ClickHouse/ClickHouse/pull/55215) ([Robert Schulze](https://github.com/rschu1ze)).
* 如果结果为零且抛出了异常，ClickHouse 客户端 将不会显示 &quot;0 rows in set&quot;。[#55240](https://github.com/ClickHouse/ClickHouse/pull/55240) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* 支持省略关键字 `TABLE` 的 RENAME TABLE 语法，例如 `RENAME db.t1 to db.t2`。[#55373](https://github.com/ClickHouse/ClickHouse/pull/55373) ([凌涛](https://github.com/lingtaolf)).
* 向 `system.clusters` 添加了 `internal_replication`。[#55377](https://github.com/ClickHouse/ClickHouse/pull/55377) ([Konstantin Morozov](https://github.com/k-morozov)).
* 根据 request protocol 选择远程 proxy 解析器，添加 proxy 功能文档，并移除 `DB::ProxyConfiguration::Protocol::ANY`。[#55430](https://github.com/ClickHouse/ClickHouse/pull/55430) ([Arthur Passos](https://github.com/arthurpassos)).
