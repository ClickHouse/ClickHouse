<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (稳定版本中用户可见的问题)
</div>

* 已在 [#32679](https://github.com/ClickHouse/ClickHouse/issues/32679) 中回移：修复在 detach parts 时意外移除 projection 的问题。[#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#32543](https://github.com/ClickHouse/ClickHouse/issues/32543) 中回移：某些复制队列条目可能会因 `temporary_directories_lifetime` (默认 1 天) 而卡住，并报出 `Directory tmp_merge_<part_name>`、`Part ... (state Deleting) already exists, but it will be deleted soon` 或类似错误。现已修复。修复了 [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#32769](https://github.com/ClickHouse/ClickHouse/issues/32769) 中回移：修复 sequential keys 场景下 sparse&#95;hashed dict 的性能问题 (哈希函数错误) 。[#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#32635](https://github.com/ClickHouse/ClickHouse/issues/32635) 中回移：修复并行执行 DROP TABLE 和 INSERT 时的表 lifetime 问题 (即可能发生 use-after-free) 。[#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#32633](https://github.com/ClickHouse/ClickHouse/issues/32633) 中回移：通过延迟创建 channel，修复 RabbitMQ storage 启动时可能出现 exception 的问题。[#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#32891](https://github.com/ClickHouse/ClickHouse/issues/32891) 中回移：修复当 materialized view 的目标是 JOIN 或 SET 表时出现的 LOGICAL&#95;ERROR。[#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#32792](https://github.com/ClickHouse/ClickHouse/issues/32792) 中回移：修复对同一个 FixedString 多次使用 fuzzBits 时发生崩溃的问题，关闭 [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737)。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
