<div id="improvement">
  #### 改进
</div>

* 已在 [#49954](https://github.com/ClickHouse/ClickHouse/issues/49954) 中回移：新增对一种 (较少见) 情况的支持，即 `IN` 运算符中的参数为单元素元组。[#49844](https://github.com/ClickHouse/ClickHouse/pull/49844) ([MikhailBurdukov](https://github.com/MikhailBurdukov))。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#49210](https://github.com/ClickHouse/ClickHouse/issues/49210) 中回移：修复 glibc 兼容性检查：替换 musl 中的 `preadv`。[#49144](https://github.com/ClickHouse/ClickHouse/pull/49144) ([alesapin](https://github.com/alesapin))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 修复聚合空字符串错误 [#48999](https://github.com/ClickHouse/ClickHouse/pull/48999) ([LiuNeng](https://github.com/liuneng1994))。
* 修复包含多个 StorageJoin 的查询中出现键未找到错误的问题 [#49137](https://github.com/ClickHouse/ClickHouse/pull/49137) ([vdimir](https://github.com/vdimir))。
* 修复过期分区片段加载时的竞争条件 [#49223](https://github.com/ClickHouse/ClickHouse/pull/49223) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 修复 DISTINCT 中的错误 [#49628](https://github.com/ClickHouse/ClickHouse/pull/49628) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 修复 randomStringUTF8(<奇数>) 中的 msan 问题 [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze))。
* 修复 OptimizeRegularExpression 中的 `is_prefix` 问题 [#49919](https://github.com/ClickHouse/ClickHouse/pull/49919) ([Han Fei](https://github.com/hanfei1991))。
* 修复 Protobuf 中 IPv6 的编码问题 [#49933](https://github.com/ClickHouse/ClickHouse/pull/49933) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* 修复在 `ReplicatedMergeTree` 的 attach 线程中启动表时发生死锁的问题 [#50026](https://github.com/ClickHouse/ClickHouse/pull/50026) ([Antonio Andelic](https://github.com/antonio2368))。
* 修复 JIT 编译中不等于 NaN 的问题 [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal))。
* 修复 `multiIf` 在常量条件与 Nullable 参数下导致崩溃的问题 [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ))。
* 修复目标主机 IP 变更时 HTTPS 会话重连的问题 [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk))。
* 修复使用 DateTime64 索引查询时 Date/Date32 到 DateTime64 的类型转换问题 [#50280](https://github.com/ClickHouse/ClickHouse/pull/50280) ([Lucas Chang](https://github.com/lucas-tubi))。
* 修复 Keeper 在预处理请求时发生异常导致死锁的问题 [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr))。
* 修复不正确的常量折叠问题 [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 修复 Log 家族表在 TRUNCATE 后返回错误行数的问题 [#50585](https://github.com/ClickHouse/ClickHouse/pull/50585) ([flynn](https://github.com/ucasfl))。
* 修复 `uniqExact` 并行合并中的错误 [#50590](https://github.com/ClickHouse/ClickHouse/pull/50590) ([Nikita Taranov](https://github.com/nickitat))。
* 避免从右侧 GLOBAL JOIN 表中读取所有列 [#50721](https://github.com/ClickHouse/ClickHouse/pull/50721) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
