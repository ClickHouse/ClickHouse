<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#42296](https://github.com/ClickHouse/ClickHouse/issues/42296) 中回移：将 cctz 更新到最新的 master，并将 tzdb 更新到 2020e。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano)) 。
* 已在 [#42360](https://github.com/ClickHouse/ClickHouse/issues/42360) 中回移：将 tzdata 更新到 2022e，以支持新的时区变更。巴勒斯坦的切换时间现改为周六 02:00。将乌克兰的三个时区简化为一个。约旦和叙利亚从带夏令时的 +02/+03 切换为全年采用 +03。 ([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS)) 。此项修复关闭了 [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252)。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#42489](https://github.com/ClickHouse/ClickHouse/issues/42489) 中回移：移除了在 `MergeTree` 表的未受影响分区中跳过变更的逻辑，因为该功能实际上从未正确工作过，并且可能导致已完成的变更再次出现。[#40589](https://github.com/ClickHouse/ClickHouse/pull/40589) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#42121](https://github.com/ClickHouse/ClickHouse/issues/42121) 中回移：修复了一个极少见情况下可能出现的 &quot;Part ... intersects part ...&quot; 错误：如果在将某个分片作为损坏分片分离后立即重启副本，就可能触发该问题。[#41741](https://github.com/ClickHouse/ClickHouse/pull/41741) ([Alexander Tokmakov](https://github.com/tavplubix)).
* * 防止向 groupBitmap* 传入错误的聚合状态时发生崩溃。[#41972](https://github.com/ClickHouse/ClickHouse/pull/41972) ([Raúl Marín](https://github.com/Algunenano)).
* * 修复了在使用 materialized view 时，X-ClickHouse-Summary 中读取字节数/行数统计不正确的问题。[#41973](https://github.com/ClickHouse/ClickHouse/pull/41973) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#42269](https://github.com/ClickHouse/ClickHouse/issues/42269) 中回移：修复了复用 base backup 中大于 4GB 的文件时的问题。[#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#42300](https://github.com/ClickHouse/ClickHouse/issues/42300) 中回移：修复了 projections 与 `aggregate_functions_null_for_empty` 设置相关的一个缺陷。该缺陷极为罕见，且仅会在你在 server 的 config 中启用 `aggregate_functions_null_for_empty` 设置时出现。此更改关闭了 [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647)。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#42387](https://github.com/ClickHouse/ClickHouse/issues/42387) 中回移：对已附加的分片 (其列与表 schema 不同) 执行 `ALTER UPDATE` 时，可能会在磁盘上生成无效的 `columns.txt` metadata。读取此类分片时可能报错，或返回无效数据。修复了 [#42161](https://github.com/ClickHouse/ClickHouse/issues/42161)。[#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#42499](https://github.com/ClickHouse/ClickHouse/issues/42499) 中回移：设置 `additional_table_filters` 未应用于 `Distributed` 存储。修复了 [#41692](https://github.com/ClickHouse/ClickHouse/issues/41692)。[#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#42571](https://github.com/ClickHouse/ClickHouse/issues/42571) 中回移：修复了处理 Decimal data types 时的缓冲区溢出问题。此更改关闭了 [#42451](https://github.com/ClickHouse/ClickHouse/issues/42451)。[#42465](https://github.com/ClickHouse/ClickHouse/pull/42465) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#42594](https://github.com/ClickHouse/ClickHouse/issues/42594) 中回移：此更改关闭了 [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453)。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
