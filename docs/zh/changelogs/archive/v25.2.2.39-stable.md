  ### ClickHouse 发行版 v25.2.2.39-稳定版本 (a1200cff50a) FIXME，与 v25.2.1.3085-稳定版本 (09989205d6f) 相比

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 已在 [#77183](https://github.com/ClickHouse/ClickHouse/issues/77183) 中回移：当 analyzer 被禁用时，无论 `compatibility` 设置如何，都会默认禁用并行副本。仍可通过将 `parallel_replicas_only_with_analyzer` 显式设置为 `false` 来更改此行为。[#77115](https://github.com/ClickHouse/ClickHouse/pull/77115) ([Igor Nikonov](https://github.com/devcrafter)) 。

<div id="new-feature">
  #### 新特性
</div>

* 已在 [#77358](https://github.com/ClickHouse/ClickHouse/issues/77358) 中回移：新增 `concurrent_threads_scheduler` 服务器级设置，用于控制 CPU 插槽在并发查询之间的分配方式。可将其设置为 `round_robin` (此前的行为) 或 `fair_round_robin`，以解决 INSERT 与 SELECT 查询之间 CPU 分配不公平的问题。[#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定发行版中用户可见的异常行为)
</div>

* 已在 [#76999](https://github.com/ClickHouse/ClickHouse/issues/76999) 中回移：修复启用异步插入并执行 `insert into ... from file ...` 时，在块大小不一致的情况下可能发生的数据丢失问题：如果第一个块大小 &lt; `async_max_size`，但第二个块 &gt; `async_max_size`，则第二个块不会被插入，这些数据会残留在 `squashing` 中。[#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* 已在 [#76970](https://github.com/ClickHouse/ClickHouse/issues/76970) 中回移：修复从分布式表中选择布尔字面量时出现的 `THERE_IS_NO_COLUMN` 异常。[#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#77049](https://github.com/ClickHouse/ClickHouse/issues/77049) 中回移：修复 JSON 子列并行前缀反序列化时的异常处理问题。[#76809](https://github.com/ClickHouse/ClickHouse/pull/76809) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#77260](https://github.com/ClickHouse/ClickHouse/issues/77260) 中回移：修复异步插入期间发生错误时，因 JSON 列回滚异常而可能导致崩溃的问题。[#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#77064](https://github.com/ClickHouse/ClickHouse/issues/77064) 中回移：修复 `BFloat16` 值的排序问题。这关闭了 [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487)。这关闭了 [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669)。[#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#77222](https://github.com/ClickHouse/ClickHouse/issues/77222) 中回移：通过添加检查，在数据分片一致性检查中跳过临时子列，修复带有 Variant 子列的 JSON 的问题。[#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).

* 已在 [#77240](https://github.com/ClickHouse/ClickHouse/issues/77240) 中回移：在 Kafka 和 RabbitMQ 引擎中支持新的 JSON 和子列。[#77122](https://github.com/ClickHouse/ClickHouse/pull/77122) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#77386](https://github.com/ClickHouse/ClickHouse/issues/77386) 中回移：`SELECT toBFloat16(-0.0) == toBFloat16(0.0)` 现在会正确返回 `true` (此前为 `false`) 。这使其行为与 `Float32` 和 `Float64` 保持一致。[#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* 已在 [#77379](https://github.com/ClickHouse/ClickHouse/issues/77379) 中回移：修复 Bool 值对应的分区名称问题。此问题由 [https://github.com/ClickHouse/ClickHouse/pull/74533](https://github.com/ClickHouse/ClickHouse/pull/74533) 引入。[#77319](https://github.com/ClickHouse/ClickHouse/pull/77319) ([Pavel Kruglov](https://github.com/Avogar)).
