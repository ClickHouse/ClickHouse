<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#72704](https://github.com/ClickHouse/ClickHouse/issues/72704) 中回移：在使用并行副本且启用本地执行计划的查询执行过程中，跳过工作线程上的跳过索引分析。协调器会根据自身 (即查询发起节点) 执行的索引分析，为工作线程选择要读取的 ranges。[#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter)) 。
* 已在 [#73035](https://github.com/ClickHouse/ClickHouse/issues/73035) 中回移：恢复从 [https://github.com/ClickHouse/ClickHouse/pull/57631](https://github.com/ClickHouse/ClickHouse/pull/57631) 引入的在 Compact parts 中读取单列 subcolumns 的优化。该优化曾被意外删除。[#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#72677](https://github.com/ClickHouse/ClickHouse/issues/72677) 中回移：改进对缓存标记内存占用的估算，从而降低缓存的总体内存占用。[#72630](https://github.com/ClickHouse/ClickHouse/pull/72630) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#73065](https://github.com/ClickHouse/ClickHouse/issues/73065) 中回移：支持解析 GCS S3 错误 `AuthenticationRequired`。[#72753](https://github.com/ClickHouse/ClickHouse/pull/72753) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#73057](https://github.com/ClickHouse/ClickHouse/issues/73057) 中回移：新增 S3 请求设置 `http_max_fields`、`http_max_field_name_size`、`http_max_field_value_size`，并在执行备份或恢复时解析 S3 API 响应时使用这些设置。[#72778](https://github.com/ClickHouse/ClickHouse/pull/72778) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#73454](https://github.com/ClickHouse/ClickHouse/issues/73454) 中回移：在 ObjectStorageQueueMetadata 清理线程中使用 Keeper multi requests。[#73357](https://github.com/ClickHouse/ClickHouse/pull/73357) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#73435](https://github.com/ClickHouse/ClickHouse/issues/73435) 中回移：当 ClickHouse 在 cgroup 下运行时，仍会收集与系统负载、进程调度、内存等相关的全系统异步指标。当 ClickHouse 是主机上唯一资源消耗较高的进程时，这些指标可能会提供有用的信号。[#73369](https://github.com/ClickHouse/ClickHouse/pull/73369) ([Nikita Taranov](https://github.com/nickitat)) 。
