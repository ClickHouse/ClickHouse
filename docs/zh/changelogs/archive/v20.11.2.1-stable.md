<div id="clickhouse-release-v201121-stable-fixme-as-compared-to-v201014881-prestable">
  ### ClickHouse 发布版本 v20.11.2.1-稳定版本 FIXME，相较于 v20.10.1.4881-prestable
</div>

<div id="backward-incompatible-change">
  #### 向后不兼容的更改
</div>

* 使 `rankCorr` 函数在数据不足时返回 `nan` [#16124](https://github.com/ClickHouse/ClickHouse/issues/16124)。[#16135](https://github.com/ClickHouse/ClickHouse/pull/16135) ([hexiaoting](https://github.com/hexiaoting))。
* 聚合函数 `boundingRatio`、`rankCorr`、`retention`、`timeSeriesGroupSum`、`timeSeriesGroupRateSum`、`windowFunnel` 之前被错误地设为不区分大小写。现在其名称已按设计改回区分大小写。只有 SQL 标准中规定的函数、为兼容其他 DBMS 而提供的函数，或与这类函数类似的函数，才应不区分大小写。[#16407](https://github.com/ClickHouse/ClickHouse/pull/16407) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 移除 `ANALYZE` 和 `AST` 查询，并将设置 `enable_debug_queries` 标记为已废弃，因为它现在已并入功能完整的 `EXPLAIN` 查询。[#16536](https://github.com/ClickHouse/ClickHouse/pull/16536) ([Ivan](https://github.com/abyss7))。
* 限制在各类键 (排序键、主键、分区键等) 中使用不可比较的 data types (如 `AggregateFunction`) 。[#16601](https://github.com/ClickHouse/ClickHouse/pull/16601) ([alesapin](https://github.com/alesapin))。
* 如果在 `distributed_ddl` config 部分中指定了某个 `profile`，则该 `profile` 可能会在 server 启动时覆盖 `default` `profile` 的设置。此问题已修复，现在分布式 DDL queries 的设置不应影响全局 server settings。[#16635](https://github.com/ClickHouse/ClickHouse/pull/16635) ([Alexander Tokmakov](https://github.com/tavplubix))。

<div id="new-feature">
  #### 新特性
</div>

* #WelchTTest 聚合函数的实现。[#10351](https://github.com/ClickHouse/ClickHouse/pull/10351) ([antikvist](https://github.com/antikvist)).
* 新增函数 `encrypt`、`aes_encrypt_mysql`、`decrypt`、`aes_decrypt_mysql`。这些函数运行速度较慢 (低于 ClickHouse 的标准) ，因此我们将其视为 Experimental 功能。[#11844](https://github.com/ClickHouse/ClickHouse/pull/11844) ([Vasily Nemkov](https://github.com/Enmk)).
* * 新增支持将 LDAP 作为本地不存在用户的用户目录。[#12736](https://github.com/ClickHouse/ClickHouse/pull/12736) ([Denis Glazachev](https://github.com/traceon)).
* 为多磁盘配置中的 volume 添加了 `disable_merges` 选项。[#13956](https://github.com/ClickHouse/ClickHouse/pull/13956) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 添加了初步的 OpenTelemetry 支持。ClickHouse 现在可以通过 Native 和 HTTP 协议接收 OpenTelemetry 的 traceparent 请求头，并在某些情况下将其向下游传递。已执行查询的 trace spans 会保存到 `system.opentelemetry_span_log` 表中。[#14195](https://github.com/ClickHouse/ClickHouse/pull/14195) ([Alexander Kuzmenkov](https://github.com/akuzm)) 。
* 支持一次性读取/写入单个 Protobuf Message (不带长度分隔符) 。[#15199](https://github.com/ClickHouse/ClickHouse/pull/15199) ([filimonov](https://github.com/filimonov)) 。
* 添加了函数 `formatReadableTimeDelta`，可将时间差格式化为人类可读的字符串……[#15497](https://github.com/ClickHouse/ClickHouse/pull/15497) ([Filipe Caixeta](https://github.com/filipecaixeta)) 。
* 添加了 `tid` 和 `logTrace` 函数。此更改关闭了 [#9434](https://github.com/ClickHouse/ClickHouse/issues/9434)。[#15803](https://github.com/ClickHouse/ClickHouse/pull/15803) ([flynn](https://github.com/ucasfl)) 。
* 为 ClickHouse 客户端添加了新选项 `print_query_id`。它有助于生成包含由客户端生成的当前查询 ID 的任意字符串。[#15809](https://github.com/ClickHouse/ClickHouse/pull/15809) ([Amos Bird](https://github.com/amosbird)) 。
* 允许在 CREATE TABLE 查询的列列表中指定主键。[#15823](https://github.com/ClickHouse/ClickHouse/pull/15823) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 添加了设置 date&#95;time&#95;output&#95;format。[#15845](https://github.com/ClickHouse/ClickHouse/pull/15845) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 在带有 ORDER BY 的 SELECT 查询中实现了 `OFFSET offset_row_count {ROW | ROWS} FETCH {FIRST | NEXT} fetch_row_count {ROW | ROWS} {ONLY | WITH TIES}`。相关 issue：[#15367](https://github.com/ClickHouse/ClickHouse/issues/15367)。[#15855](https://github.com/ClickHouse/ClickHouse/pull/15855) ([hexiaoting](https://github.com/hexiaoting)) 。
* 添加了一个聚合函数，用于计算 Welch&#39;s t-test 使用的 p-value。[#15874](https://github.com/ClickHouse/ClickHouse/pull/15874) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 添加了 max&#95;concurrent&#95;queries&#95;for&#95;all&#95;users 设置，具体用例见 [#6636](https://github.com/ClickHouse/ClickHouse/issues/6636)。[#16154](https://github.com/ClickHouse/ClickHouse/pull/16154) ([nvartolomei](https://github.com/nvartolomei)) 。
* 为 ClickHouse 添加了最简 web UI。[#16158](https://github.com/ClickHouse/ClickHouse/pull/16158) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 添加了函数 `untuple`，这是一个特殊函数，可通过展平命名元组向 SELECT 列表中引入新列。[#16242](https://github.com/ClickHouse/ClickHouse/pull/16242) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 添加了 toUUIDOrNull、toUUIDOrZero 转换函数。[#16337](https://github.com/ClickHouse/ClickHouse/pull/16337) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 添加了 `system.replicated_fetches` 表，用于显示当前正在运行的后台拉取任务。[#16428](https://github.com/ClickHouse/ClickHouse/pull/16428) ([alesapin](https://github.com/alesapin)) 。
* * `errorCodeToName()` 函数 - 返回错误的变量名 (对分析 `query&#95;log` 及类似内容很有用)  - `system.errors` 表 - 显示错误发生的次数 (遵循 `system_events_show_zero_values`) 。[#16438](https://github.com/ClickHouse/ClickHouse/pull/16438) ([Azat Khuzhin](https://github.com/azat)).
* 支持基于 Alpine 创建 Docker 镜像。使用来自 Ubuntu 20.04 的预编译二进制文件和 glibc 组件。[#16479](https://github.com/ClickHouse/ClickHouse/pull/16479) ([filimonov](https://github.com/filimonov)).
* 新增 `log_queries_min_query_duration_ms`，只有耗时超过该设置值的查询才会写入 `query_log`/`query_thread_log` (即类似于 MySQL 中的 `slow_query_log`) 。[#16529](https://github.com/ClickHouse/ClickHouse/pull/16529) ([Azat Khuzhin](https://github.com/azat)).
* > 新增 farmFingerprint64 函数。[#16570](https://github.com/ClickHouse/ClickHouse/pull/16570) ([Jacob Hayes](https://github.com/JacobHayes)) 。
* 现在我们可以通过查询参数传递标识符，并且这些参数可用作表对象或列。[#3815](https://github.com/ClickHouse/ClickHouse/issues/3815)。[#16594](https://github.com/ClickHouse/ClickHouse/pull/16594) ([Amos Bird](https://github.com/amosbird)) 。
* 为 MergeTree BloomFilter 索引新增了对大整数 (UInt256、Int128、Int256) 和 UUID 数据类型的支持。[#16642](https://github.com/ClickHouse/ClickHouse/pull/16642) ([Maksim Kita](https://github.com/kitaisreal)) 。

* 小幅提升逻辑函数的性能。[#16347](https://github.com/ClickHouse/ClickHouse/pull/16347) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 提升 `quantileMerge` 的性能。在此前版本中，它的速度慢得离谱。此项修复关闭了 [#1463](https://github.com/ClickHouse/ClickHouse/issues/1463)。[#16643](https://github.com/ClickHouse/ClickHouse/pull/16643) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 提升 `-OrNull` 和 `-OrDefault` 聚合函数的性能。[#16661](https://github.com/ClickHouse/ClickHouse/pull/16661) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="improvement">
  #### 改进
</div>

* 允许在 `CREATE TABLE table AS table_function(...)` 查询中显式指定列列表。修复了 [#9249](https://github.com/ClickHouse/ClickHouse/issues/9249) 和 [#14214](https://github.com/ClickHouse/ClickHouse/issues/14214)。[#14295](https://github.com/ClickHouse/ClickHouse/pull/14295) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 现在简单的 count 优化变得稍微复杂了一些。包含精确分区表达式的谓词也可以优化。这也修复了 [#11092](https://github.com/ClickHouse/ClickHouse/issues/11092) 中在 `max_parallel_replicas > 1` 时返回错误计数的问题。[#15074](https://github.com/ClickHouse/ClickHouse/pull/15074) ([Amos Bird](https://github.com/amosbird)) 。
* 为 CSV、TSV 和 JSON 输入格式启用按 ID 解析枚举值。[#15685](https://github.com/ClickHouse/ClickHouse/pull/15685) ([vivarum](https://github.com/vivarum)) 。
* 为 `zookeeper-dump-tree` 工具添加重连功能。[#15711](https://github.com/ClickHouse/ClickHouse/pull/15711) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 移除 `MemoryTrackingInBackground*` 指标，以避免可能产生误导的结果。这修复了 [#15684](https://github.com/ClickHouse/ClickHouse/issues/15684)。[#15813](https://github.com/ClickHouse/ClickHouse/pull/15813) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 将某些日志消息的级别从 information 改为 debug，这样 information 消息就不会在每次查询时都出现。此更改关闭了 [#5293](https://github.com/ClickHouse/ClickHouse/issues/5293)。[#15816](https://github.com/ClickHouse/ClickHouse/pull/15816) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 修复了在配置错误 (`connections_with_failover_max_tries` 设为 0) 时查询挂起 (无限循环) 的问题。[#15876](https://github.com/ClickHouse/ClickHouse/pull/15876) ([Azat Khuzhin](https://github.com/azat)) 。
* 向 `db_generator` 添加了 boost::program&#95;options，以提高其实用性。此更改关闭了 [#15940](https://github.com/ClickHouse/ClickHouse/issues/15940)。[#15973](https://github.com/ClickHouse/ClickHouse/pull/15973) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 将 `INTERVAL '1 hour'` 视为与 `INTERVAL 1 HOUR` 等价，以兼容 Postgres。这修复了 [#15637](https://github.com/ClickHouse/ClickHouse/issues/15637)。[#15978](https://github.com/ClickHouse/ClickHouse/pull/15978) ([flynn](https://github.com/ucasfl)) 。
* 为带有复合键的 Redis 字典添加 cache 布局支持。[#15985](https://github.com/ClickHouse/ClickHouse/pull/15985) ([Anton Popov](https://github.com/CurtizJ)) 。
* 修复了一个罕见问题：ClickHouse 客户端 可能会因加载自动补全建议而在退出时异常终止。这修复了 [#16035](https://github.com/ClickHouse/ClickHouse/issues/16035)。[#16047](https://github.com/ClickHouse/ClickHouse/pull/16047) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 现在无论集群配置中的 `<internal_replication>` 设置如何，都允许执行 `ALTER ... ON CLUSTER` 查询。[#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)) 。
* * 修复了通过 HTTP 发起的查询中 `memory&#95;profiler&#95;step`/`max&#95;untracked&#95;memory` 的问题 (包含测试) ；此外，即使在 XML 配置中全局调整该值也无济于事，因为这些设置实际上根本不会生效，只有默认值 (4MB) 会被[使用](https://github.com/ClickHouse/ClickHouse/blob/17731245336d8c84f75e4c0894c5797ed7732190/src/Common/ThreadStatus.h#L104)。- 修复了 HTTP 查询最顶层 ThreadStatus 的 `query&#95;id` 问题 (通过在读取 `query&#95;id` 后初始化 QueryScope) 。[#16101](https://github.com/ClickHouse/ClickHouse/pull/16101) ([Azat Khuzhin](https://github.com/azat)).
* 添加 allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards (允许在分片键中使用非确定性内容，如 rand() 或 dictGet()) 。[#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).
* 为 DROP DATABASE 添加 database&#95;atomic&#95;wait&#95;for&#95;drop&#95;and&#95;detach&#95;synchronously/NO DELAY/SYNC。[#16127](https://github.com/ClickHouse/ClickHouse/pull/16127) ([Azat Khuzhin](https://github.com/azat)).
* 添加对嵌套数据类型 (如命名元组) 作为子类型的支持。修复了 [#15587](https://github.com/ClickHouse/ClickHouse/issues/15587)。[#16262](https://github.com/ClickHouse/ClickHouse/pull/16262) ([Ivan](https://github.com/abyss7)).
* 如果系统中没有 tmp 文件夹 (如 chroot、配置错误等情况) ，clickhouse-local 将在当前目录中创建临时子文件夹。[#16280](https://github.com/ClickHouse/ClickHouse/pull/16280) ([filimonov](https://github.com/filimonov)).
* 现在可以在 MergeTree 表引擎家族中指定 `PRIMARY KEY` 而不指定 `ORDER BY`。关闭了 [#15591](https://github.com/ClickHouse/ClickHouse/issues/15591)。[#16284](https://github.com/ClickHouse/ClickHouse/pull/16284) ([alesapin](https://github.com/alesapin)).
* 尝试对 croaring 使用 cmake 版本而不是 amalgamation.sh。[#16285](https://github.com/ClickHouse/ClickHouse/pull/16285) ([sundyli](https://github.com/sundy-li)).
* 为 Set/Join 表引擎添加 total&#95;rows/total&#95;bytes (来自 system.tables) 支持。[#16306](https://github.com/ClickHouse/ClickHouse/pull/16306) ([Azat Khuzhin](https://github.com/azat)).
* 当客户端连接已断开时，提供更好的诊断信息。在之前的版本中，服务器中会记录 `Attempt to read after EOF` 和 `Broken pipe` 异常。在新版本中，则会记录信息消息 `Client has dropped the connection, cancel the query.`。[#16329](https://github.com/ClickHouse/ClickHouse/pull/16329) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 添加 `TablesToDropQueueSize` 指标。它等于已删除、且正在等待后台数据清理的表数量。[#16364](https://github.com/ClickHouse/ClickHouse/pull/16364) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 修复 quantileDeterministic 函数中的调试断言。在之前的版本中，它还可能通过网络传输最多两倍的数据，不过并不存在功能性 bug。此更改修复了 [#15683](https://github.com/ClickHouse/ClickHouse/issues/15683)。[#16410](https://github.com/ClickHouse/ClickHouse/pull/16410) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 为 JBOD 架构和 `MergeTree` 存储提供更好的读取任务调度。新增设置 `read_backoff_min_concurrency`，作为读取线程数的下限。[#16423](https://github.com/ClickHouse/ClickHouse/pull/16423) ([Amos Bird](https://github.com/amosbird)).
* 修复了 [#16263](https://github.com/ClickHouse/ClickHouse/issues/16263) 中的 bug。同时还尽可能缩短了事件循环的生命周期，并新增了更高效的队列设置。[#16426](https://github.com/ClickHouse/ClickHouse/pull/16426) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 允许将当前实例中已提交或已过期的分片拉取到 detached 目录中。这在从另一个集群迁移表并采用 N 对 1 的分片映射时很有用。这也与当前的 fetchPartition 实现保持一致。[#16538](https://github.com/ClickHouse/ClickHouse/pull/16538) ([Amos Bird](https://github.com/amosbird)).
* 在 query&#95;thread&#95;log 中添加 current&#95;database 字段。[#16558](https://github.com/ClickHouse/ClickHouse/pull/16558) ([Azat Khuzhin](https://github.com/azat)) 。
* WITH 子句中的子查询 (CTE) 现在可以按名称引用 WITH 子句中前面定义的子查询。[#16575](https://github.com/ClickHouse/ClickHouse/pull/16575) ([Amos Bird](https://github.com/amosbird)) 。
* * 改进了 `Atomic` 数据库中清理已删除表数据的后台任务调度。- 如果表实际上没有数据目录，`Atomic` 数据库将不会创建指向表数据目录的损坏符号链接。[#16584](https://github.com/ClickHouse/ClickHouse/pull/16584) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 现在，参数化函数可用于 APPLY 列转换器。[#16589](https://github.com/ClickHouse/ClickHouse/pull/16589) ([Amos Bird](https://github.com/amosbird)).
* 现在，`event_time_microseconds` 字段存储为 Decimal64，而不是 UInt64。移除了 Field::get() 中一处不正确的检查。[#16617](https://github.com/ClickHouse/ClickHouse/pull/16617) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 尽早应用 SETTINGS clause。这样可以在查询中修改更多设置。此更改关闭了 [#3178](https://github.com/ClickHouse/ClickHouse/issues/3178)。[#16619](https://github.com/ClickHouse/ClickHouse/pull/16619) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 改进了运行时 ZooKeeper 配置的更新机制。[#16630](https://github.com/ClickHouse/ClickHouse/pull/16630) ([sundyli](https://github.com/sundy-li)).
* 使 `minMap` 和 `maxMap` 的行为更加合理。结果中将不再跳过零值。修复了 [#16087](https://github.com/ClickHouse/ClickHouse/issues/16087)。[#16631](https://github.com/ClickHouse/ClickHouse/pull/16631) ([Ildus Kurbangaliev](https://github.com/ildus)).
* 改进了输入数据中解析错误的诊断信息。在出现 `Cannot read all data` 错误时，会提供行号。[#16644](https://github.com/ClickHouse/ClickHouse/pull/16644) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 提供了通过 nginx 服务器作为代理使用 S3 的变通方案。当前 Nginx 不接受像 [http://domain.com?delete](http://domain.com?delete) 这样 path 为空的 URL，但原生 aws-sdk-cpp 会生成这类 URL。此次提交使用了打过补丁的 aws-sdk-cpp 版本，在这种情况下会生成以 &quot;/&quot; 作为 path 的 URL，例如 [http://domain.com/?delete](http://domain.com/?delete)。[#16814](https://github.com/ClickHouse/ClickHouse/pull/16814) ([ianton-ru](https://github.com/ianton-ru)).

<div id="bug-fix">
  #### 缺陷修复
</div>

* 更新 jemalloc，修复带有亲和性掩码的 percpu&#95;arena 问题。 [#15035](https://github.com/ClickHouse/ClickHouse/pull/15035) ([Azat Khuzhin](https://github.com/azat)).
* 在分离只读表时，递减 `ReadonlyReplica` 指标。此修复解决了 [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598)。 [#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)).
* 修复了 S3 表函数中通配符的 bug：未将 URL 中的区域应用到 S3 client 配置中。 [#15646](https://github.com/ClickHouse/ClickHouse/pull/15646) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 修复错误 `Cannot add simple transform to empty Pipe`。该错误会在从 `Buffer` 表读取、且其结构与目标表不一致时发生。如果目标表的查询返回空结果，就可能出现该问题。修复了 [#15529](https://github.com/ClickHouse/ClickHouse/issues/15529)。 [#15662](https://github.com/ClickHouse/ClickHouse/pull/15662) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 如果第一次尝试失败，现在可以将分片移动到另一块 disk/volume。 [#15723](https://github.com/ClickHouse/ClickHouse/pull/15723) ([Pavel Kovalenko](https://github.com/Jokser)).
* 修复了在 Atomic database 中删除带有内部表的 materialized view 时的问题 (由于递归对 MV 的内部表执行 DROP TABLE，导致工作线程挂起，进而使后续所有 DROP TABLE 都被阻塞) 。 [#15743](https://github.com/ClickHouse/ClickHouse/pull/15743) ([Azat Khuzhin](https://github.com/azat)).
