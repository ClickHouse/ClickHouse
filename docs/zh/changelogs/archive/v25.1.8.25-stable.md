<div id="new-feature">
  #### 新特性
</div>

* 已在 [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357) 中回移：新增 `concurrent_threads_scheduler` 服务端设置，用于控制 CPU 插槽在并发查询之间的分配方式。可将其设置为 `round_robin` (此前的行为) 或 `fair_round_robin`，以解决 INSERT 和 SELECT 之间 CPU 分配不公平的问题。[#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)) 。

<div id="improvement">
  #### 改进
</div>

* 已在 [#77202](https://github.com/ClickHouse/ClickHouse/issues/77202) 中回移：此前，Replicated 数据库可能会将查询中指定的凭据打印到日志中。该问题现已修复。关闭 [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123)。[#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* 已在 [#76151](https://github.com/ClickHouse/ClickHouse/issues/76151) 中回移：将格式设置传递给 Native format 中 JSON 的字符串格式化。 [#75832](https://github.com/ClickHouse/ClickHouse/pull/75832) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#76968](https://github.com/ClickHouse/ClickHouse/issues/76968) 中回移：修复从分布式表中选择布尔字面量时出现 THERE&#95;IS&#95;NO&#95;COLUMN 异常的问题。 [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#77256](https://github.com/ClickHouse/ClickHouse/issues/77256) 中回移：修复异步插入期间发生错误时，因 JSON 列错误回滚而可能导致崩溃的问题。 [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#77220](https://github.com/ClickHouse/ClickHouse/issues/77220) 中回移：通过添加检查，在分片一致性检查中跳过临时子列，修复带有 Variant 子列的 JSON 相关缺陷。 [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* 已在 [#77248](https://github.com/ClickHouse/ClickHouse/issues/77248) 中回移：修复创建 Kafka 表时因异常导致崩溃的问题。 [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#77384](https://github.com/ClickHouse/ClickHouse/issues/77384) 中回移：`SELECT toBFloat16(-0.0) == toBFloat16(0.0)` 现在会正确返回 `true` (此前为 `false`) 。这使其行为与 `Float32` 和 `Float64` 保持一致。 [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* 已在 [#77333](https://github.com/ClickHouse/ClickHouse/issues/77333) 中回移：修复包含 Nullable 元素的 Tuple 与 String 之间的比较问题。 [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
