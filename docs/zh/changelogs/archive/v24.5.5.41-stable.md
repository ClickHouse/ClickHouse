<div id="improvement">
  #### 改进
</div>

* 已在 [#66768](https://github.com/ClickHouse/ClickHouse/issues/66768) 中回移：允许由分布式查询的发起节点控制 `allow_experimental_analyzer`。这可确保在混合版本集群中执行操作时的兼容性和正确性。[#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移至 [#65350](https://github.com/ClickHouse/ClickHouse/issues/65350)：修复了 StatusFile 中 ~WriteBufferFromFileDescriptor 出现未捕获异常时可能导致进程中止的问题。[#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已回移至 [#65621](https://github.com/ClickHouse/ClickHouse/issues/65621)：修复了在分布式查询中对 `Nested` 列执行 `ARRAY JOIN` 时出现的 `Cannot find column` 问题。修复了 [#64755](https://github.com/ClickHouse/ClickHouse/issues/64755)。[#64801](https://github.com/ClickHouse/ClickHouse/pull/64801) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已回移至 [#67902](https://github.com/ClickHouse/ClickHouse/issues/67902)：修复了 StorageMerge 在 `PREWHERE` 优化后出现的 `Not-ready Set` 错误。[#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已回移至 [#66884](https://github.com/ClickHouse/ClickHouse/issues/66884)：修复了函数调用中低基数列大小不符合预期的问题。[#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已回移至 [#65933](https://github.com/ClickHouse/ClickHouse/issues/65933)：对于从 `PostgreSQL` 读取数据的查询，如果 ClickHouse 查询已结束，则会取消内部的 `PostgreSQL` 查询。否则，在内部 `PostgreSQL` 查询完成之前，`ClickHouse` 查询无法取消。[#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已回移至 [#66301](https://github.com/ClickHouse/ClickHouse/issues/66301)：改进了对包含 `IS NULL` 检查的 join 条件的处理 (例如，将 `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` 重写为 `ON a <=> b`) ，并修复了存在 `IS NULL` 之外其他条件时的错误优化问题。[#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)) 。
* 已回移至 [#66328](https://github.com/ClickHouse/ClickHouse/issues/66328)：将缺失的设置 `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` 加入 schema 推断缓存，因为这些设置会改变最终生成的 schema。这可防止在这些设置发生变化时得到错误的 schema 推断结果。[#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已回移至 [#68252](https://github.com/ClickHouse/ClickHouse/issues/68252)：修复了在某些系统表中使用子查询进行筛选时出现的 `Not-ready Set` 问题。[#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已回移至 [#66155](https://github.com/ClickHouse/ClickHouse/issues/66155)：修复了 `unbin`/`unhex` 实现中的缓冲区溢出漏洞。[#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已回移至 [#66454](https://github.com/ClickHouse/ClickHouse/issues/66454)：修复了 ZooKeeper client 中的一个问题：在收到来自 ZooKeeper 的硬件错误后，会话可能卡在不可用状态。例如，这可能是由 ClickHouse Keeper 中的 &quot;soft memory limit&quot; 引起的。[#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
