  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#44998](https://github.com/ClickHouse/ClickHouse/issues/44998) 中回移：修复了另一种 `Cannot read all data` 错误，该错误可能在从远程文件系统读取 `LowCardinality` 字典时发生。修复了 [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709)。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#45551](https://github.com/ClickHouse/ClickHouse/issues/45551) 中回移：修复了在存在结构有误的字典 (例如 xml config 中类型不正确) 时，执行 `SELECT ... FROM system.dictionaries` 会抛出异常的问题。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)) 。
