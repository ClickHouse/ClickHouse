  ### ClickHouse 版本 v22.10.1.1877-稳定版本 (98ab5a3c189) FIXME，较 v22.9.1.2603-稳定版本 (3030d4c7ff0)

<div id="backward-incompatible-change">
  #### 向后不兼容的变更
</div>

* 重命名缓存命令：`show caches` -&gt; `show filesystem caches`，`describe cache` -&gt; `describe filesystem cache`。[#41508](https://github.com/ClickHouse/ClickHouse/pull/41508) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 移除对 `LIVE VIEW` 中 `WITH TIMEOUT` 部分的支持。该变更关闭了 [#40557](https://github.com/ClickHouse/ClickHouse/issues/40557)。[#42173](https://github.com/ClickHouse/ClickHouse/pull/42173) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="new-feature">
  #### 新特性
</div>

* 为 ClickHouse 增加了 Rust 代码支持，并以 BLAKE3 哈希函数库为示例。 [#33435](https://github.com/ClickHouse/ClickHouse/pull/33435) ([BoloniniD](https://github.com/BoloniniD)).
* 这是 Kusto 查询语言的初始实现 (MVP) 。 [#37961](https://github.com/ClickHouse/ClickHouse/pull/37961) ([Yong Wang](https://github.com/kashwy)).
* * 支持通过设置 `max_temporary_data_on_disk_size_for_user`/`max_temporary_data_on_disk_size_for_query` 来限制存储在磁盘上的临时数据量。[#40893](https://github.com/ClickHouse/ClickHouse/pull/40893) ([Vladimir C](https://github.com/vdimir)).
* 在 `javaHash` 中支持 Java 整数的哈希计算。 [#41131](https://github.com/ClickHouse/ClickHouse/pull/41131) ([JackyWoo](https://github.com/JackyWoo)).
* 此 PR 支持像 BoringSSL submodule 一样对 OpenSSL 进行内置构建。构建 flag，即 ENABLE&#95;CH&#95;BUNDLE&#95;BORINGSSL，用于在 BoringSSL 和 OpenSSL 之间进行选择。默认使用 BoringSSL 的内置构建。 [#41142](https://github.com/ClickHouse/ClickHouse/pull/41142) ([MeenaRenganathan22](https://github.com/MeenaRenganathan22)).
* 新增了可组合的 protocol configuration。 [#41198](https://github.com/ClickHouse/ClickHouse/pull/41198) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 为 ON CLUSTER DDL 添加 OpenTelemetry 支持 (要求将 `distributed_ddl_entry_format_version` 设置为 4) 。 [#41484](https://github.com/ClickHouse/ClickHouse/pull/41484) ([Frank Chen](https://github.com/FrankChen021)).
* 新增设置 `format_json_object_each_row_column_for_object_name`，用于在 JSONObjectEachRow format 中将 object name 写入为列值或将其解析为列值。 [#41703](https://github.com/ClickHouse/ClickHouse/pull/41703) ([Kruglov Pavel](https://github.com/Avogar)).
* 新增 Morton Coding (ZCurve) 编码/解码函数。 [#41753](https://github.com/ClickHouse/ClickHouse/pull/41753) ([Constantine Peresypkin](https://github.com/pkit)).
* 实现了对不同 UUID binary formats 的支持，包括最常见的两种：默认的 big-endian，以及 [RFC 4122](https://datatracker.ietf.org/doc/html/rfc4122#section-4.1.1) 中规定的 Microsoft 混合 endian。 [#42108](https://github.com/ClickHouse/ClickHouse/pull/42108) ([ltrk2](https://github.com/ltrk2)).
* 新增 aggregate function `analysisOfVariance` (`anova`)，用于对多个呈正态分布的观测组执行统计检验，以判断各组的 mean 是否相同。原始 PR [#37872](https://github.com/ClickHouse/ClickHouse/issues/37872)。 [#42131](https://github.com/ClickHouse/ClickHouse/pull/42131) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 添加对 `SET setting_name = DEFAULT` 的支持。 [#42187](https://github.com/ClickHouse/ClickHouse/pull/42187) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* * 添加了符合 RFC 规范的 `URL` 函数，包括：`cutToFirstSignificantSubdomainCustomRFC`、`cutToFirstSignificantSubdomainCustomWithWWWRFC`、`cutToFirstSignificantSubdomainRFC`、`cutToFirstSignificantSubdomainWithWWWRFC`、`domainRFC`、`domainWithoutWWWRFC`、`firstSignificantSubdomainCustomRFC`、`firstSignificantSubdomainRFC`、`portRFC`、`topLevelDomainRFC`。[#42274](https://github.com/ClickHouse/ClickHouse/pull/42274) ([Quanfa Fu](https://github.com/dentiscalprum)) 。
* 新增了一组可按指定分布生成随机值的函数 (`randUniform`, `randNormal`, `randLogNormal`, `randExponential`, `randChiSquared`, `randStudentT`, `randFisherF`, `randBernoulli`, `randBinomial`, `randNegativeBinomial`, `randPoisson`) 。此更改关闭了 [#21834](https://github.com/ClickHouse/ClickHouse/issues/21834)。[#42411](https://github.com/ClickHouse/ClickHouse/pull/42411) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="performance-improvement">
  #### 性能提升
</div>

* 实现了 operator precedence element parser，以解决栈溢出问题并减小所需栈空间。[#34892](https://github.com/ClickHouse/ClickHouse/pull/34892) ([Nikolay Degterinsky](https://github.com/evillique)).
* DISTINCT 按顺序优化利用了数据流的排序特性。此改进将在适用时为 DISTINCT 启用按顺序读取 (此前必须为 DISTINCT 中的列提供 ORDER BY) 。[#41014](https://github.com/ClickHouse/ClickHouse/pull/41014) ([Igor Nikonov](https://github.com/devcrafter)).
* ColumnVector：使用 AVX512VBMI 优化 UInt8 索引。[#41247](https://github.com/ClickHouse/ClickHouse/pull/41247) ([Guo Wangyang](https://github.com/guowangy)).
* 在 ICX 设备 (Intel Xeon Platinum 8380 CPU，80 核，160 线程) 上进行的 **SSB** (Star Schema Benchmark) 性能实验表明，此变更可使所有子场景的 QPS 几何平均值提升 **2.95 倍**。[#41675](https://github.com/ClickHouse/ClickHouse/pull/41675) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* 修复了 JSONExtract 在 LowCardinality(String) Tuple 上的性能问题。[#41726](https://github.com/ClickHouse/ClickHouse/pull/41726) ([AlfVII](https://github.com/AlfVII)).
* 为 AArch64 构建添加 ldapr 能力。Graviton 2+、Azure 和 GCP 实例支持该功能。该功能直到不久前才出现在 clang-15 中：[not so long ago](https://github.com/llvm/llvm-project/commit/9609b5daffe9fd28d83d83da895abc5113f76c24)。[#41778](https://github.com/ClickHouse/ClickHouse/pull/41778) ([Daniel Kutenin](https://github.com/danlark1)).
* 提升了比较字符串且其中一个 argument 为空常量字符串时的性能。[#41870](https://github.com/ClickHouse/ClickHouse/pull/41870) ([Jiebin Sun](https://github.com/jiebinn)).
* 优化 ColumnAggregateFunction 的 insertFrom，在某些情况下共享 aggregate state。[#41960](https://github.com/ClickHouse/ClickHouse/pull/41960) ([flynn](https://github.com/ucasfl)).
* 放宽了“parts 过多”阈值。这关闭了 [#6551](https://github.com/ClickHouse/ClickHouse/issues/6551)。现在，如果平均 part 大小足够大 (至少 10 GiB) ，ClickHouse 将允许一个分区中存在更多 parts。这使得在单台服务器上的单个表的单个分区中容纳最多 PB 级数据成为可能，这可以通过磁盘柜或对象存储实现。[#42002](https://github.com/ClickHouse/ClickHouse/pull/42002) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 提高了写入 AzureBlobStorage 的效率 (遵循 `max_single_part_upload_size`，而不是按每个缓冲区大小写入一个块) 。相关低效问题见 [#41754](https://github.com/ClickHouse/ClickHouse/issues/41754)。[#42041](https://github.com/ClickHouse/ClickHouse/pull/42041) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 使 process list 和 query&#95;log 中的线程 ID 保持唯一，以避免浪费。[#42180](https://github.com/ClickHouse/ClickHouse/pull/42180) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 改进
</div>

* 新增了 `allow_experimental_analyzer` 设置下用于查询分析和规划的底层基础设施。[#31796](https://github.com/ClickHouse/ClickHouse/pull/31796) ([Maksim Kita](https://github.com/kitaisreal)).
* * 支持在子查询中使用 `(EXPLAIN SELECT ...)` 表达式。像 `SELECT * FROM (EXPLAIN PIPELINE SELECT col FROM TABLE ORDER BY col)` 这样的查询现已合法。[#40630](https://github.com/ClickHouse/ClickHouse/pull/40630) ([Vladimir C](https://github.com/vdimir)).
* 当前在查询作用域内更改 `async_insert_max_data_size` 或 `async_insert_busy_timeout_ms` 没有意义，而且会带来较差的用户体验。例如，用户希望低频插入数据，但又无法访问服务器配置来调整默认设置。[#40668](https://github.com/ClickHouse/ClickHouse/pull/40668) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 内嵌 Keeper 现在始终会在后台启动，从而允许 ClickHouse 在未达到 quorum 的情况下启动。[#40991](https://github.com/ClickHouse/ClickHouse/pull/40991) ([Antonio Andelic](https://github.com/antonio2368)).
* 改进了从远程文件系统读取的能力，并使读写线程池大小可配置。关闭 [#41070](https://github.com/ClickHouse/ClickHouse/issues/41070)。[#41011](https://github.com/ClickHouse/ClickHouse/pull/41011) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 当前一个连接过期时，重新建立新连接的响应速度更快了。此前默认有一个每分钟运行一次的任务，因此表可能会在这段时间内处于只读状态。[#41092](https://github.com/ClickHouse/ClickHouse/pull/41092) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 现在在 WindowTransform/arratReduce*/initializeAggregation/aggregate functions versioning 中支持所有组合器的组合。此前，`ForEach/Resample/Map` 这类组合器在这些位置无法使用，使用它们会导致类似 `State function ... inserts results into non-state column` 的异常。[#41107](https://github.com/ClickHouse/ClickHouse/pull/41107) ([Kruglov Pavel](https://github.com/Avogar)).
* 现在，投影可与零拷贝复制一起使用。[#41147](https://github.com/ClickHouse/ClickHouse/pull/41147) ([alesapin](https://github.com/alesapin)).
* * 新增函数 tryDecrypt：解密失败时 (例如使用错误的密钥解密) 返回 NULL，而不是抛出异常。[#41206](https://github.com/ClickHouse/ClickHouse/pull/41206) ([Duc Canh Le](https://github.com/canhld94)).
* 向 `system.disks` 表添加 `unreserved_space` 列，用于检查每个 disk 上未被预留占用的空间大小。[#41254](https://github.com/ClickHouse/ClickHouse/pull/41254) ([filimonov](https://github.com/filimonov)).
* 支持从 ast arguments 获取 S3 认证请求头。[#41261](https://github.com/ClickHouse/ClickHouse/pull/41261) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 添加设置 &#39;allow&#95;implicit&#95;no&#95;password&#39;，禁止创建无密码用户，除非显式指定 &#39;IDENTIFIED WITH no&#95;password&#39;。[#41341](https://github.com/ClickHouse/ClickHouse/pull/41341) ([Nikolay Degterinsky](https://github.com/evillique)).
* keeper-improvement：新增将 snapshots 上传到 S3 的支持。S3 信息可在 `keeper_server.s3_snapshot` 中定义。[#41342](https://github.com/ClickHouse/ClickHouse/pull/41342) ([Antonio Andelic](https://github.com/antonio2368)).
* 为 Keeper 和内部 ZooKeeper client 添加对 MultiRead 的支持。[#41410](https://github.com/ClickHouse/ClickHouse/pull/41410) ([Antonio Andelic](https://github.com/antonio2368)).
* 新增在 IN Operator 中将 Decimal 类型与浮点 literal 进行比较的支持。[#41544](https://github.com/ClickHouse/ClickHouse/pull/41544) ([liang.huang](https://github.com/lhuang09287750)).
* 在 cache config 中允许使用可读大小配置值。[#41688](https://github.com/ClickHouse/ClickHouse/pull/41688) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 在 input formats 的 errors logger 中检查文件路径，以防止路径遍历攻击。[#41694](https://github.com/ClickHouse/ClickHouse/pull/41694) ([Kruglov Pavel](https://github.com/Avogar)).
* ClickHouse 可能会在一段时间内缓存过期的 DNS entries (默认 15 秒) ，直到缓存异步更新完成。在此期间，ClickHouse 仍可能尝试建立 connection 并报错。此问题已修复。[#41707](https://github.com/ClickHouse/ClickHouse/pull/41707) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 为 `clickhouse-client`/`clickhouse-local` 添加了使用类 fzf 工具 (fzf/sk) 的交互式 history 搜索 (注意：你还可以使用 `FZF_DEFAULT_OPTS`/`SKIM_DEFAULT_OPTIONS` 进一步配置其行为) 。[#41730](https://github.com/ClickHouse/ClickHouse/pull/41730) ([Azat Khuzhin](https://github.com/azat)).
* 对于 client，在连接带有无效 certificate 的安全 server 时，仅允许通过 &#39;--accept-certificate&#39; 标志继续。[#41743](https://github.com/ClickHouse/ClickHouse/pull/41743) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 添加函数 &quot;tryBase58Decode()&quot;，类似于现有的 &quot;tryBase64Decode()&quot; 函数。[#41824](https://github.com/ClickHouse/ClickHouse/pull/41824) ([Robert Schulze](https://github.com/rschu1ze)).
* 改进了使用不同主键替换分区时的反馈信息。修复了 [#34798](https://github.com/ClickHouse/ClickHouse/issues/34798)。[#41838](https://github.com/ClickHouse/ClickHouse/pull/41838) ([Salvatore](https://github.com/tbsal)).
* 在启动时将 `clickhouse su` 命令改回 `sudo -u`，以遵循 `/etc/security/limits.conf` 中的限制。[#41847](https://github.com/ClickHouse/ClickHouse/pull/41847) ([Eugene Konkov](https://github.com/ekonkov)).
* 修复并行 parsing：segmentator 现在会检查 max&#95;block&#95;size。[#41852](https://github.com/ClickHouse/ClickHouse/pull/41852) ([Vitaly Baranov](https://github.com/vitlibar)).
* 不再报告 TABLE&#95;IS&#95;DROPPED 异常，以便在表刚被删除时跳过该表。 [#41908](https://github.com/ClickHouse/ClickHouse/pull/41908) ([AlfVII](https://github.com/AlfVII)).
* 改进选项 enable&#95;extended&#95;results&#95;for&#95;datetime&#95;functions，使 toStartOfDay、toStartOfHour、toStartOfFifteenMinutes、toStartOfTenMinutes、toStartOfFiveMinutes、toStartOfMinute 和 timeSlot 等函数返回 DateTime64 类型的结果。 [#41910](https://github.com/ClickHouse/ClickHouse/pull/41910) ([Roman Vasin](https://github.com/rvasin)).
* 改进文本格式中的 日期时间 类型推断。现在会遵循设置 `date_time_input_format`，且不再尝试将数字时间戳推断为日期时间。关闭了 [#41389](https://github.com/ClickHouse/ClickHouse/issues/41389) 和 [#42206](https://github.com/ClickHouse/ClickHouse/issues/42206)。 [#41912](https://github.com/ClickHouse/ClickHouse/pull/41912) ([Kruglov Pavel](https://github.com/Avogar)).
* 移除在使用 `perform_ttl_move_on_insert`=false 插入时令人困惑的警告。 [#41980](https://github.com/ClickHouse/ClickHouse/pull/41980) ([Vitaly Baranov](https://github.com/vitlibar)).
* 允许用户像编写 `count(*)` 一样编写 `countState(*)`。这关闭了 [#9338](https://github.com/ClickHouse/ClickHouse/issues/9338)。 [#41983](https://github.com/ClickHouse/ClickHouse/pull/41983) ([Amos Bird](https://github.com/amosbird)).
* * 修复 rankCorr 的大小溢出问题。[#42020](https://github.com/ClickHouse/ClickHouse/pull/42020) ([Duc Canh Le](https://github.com/canhld94)) 。
* 新增了一个选项，可在 Sentry 配置中将任意字符串指定为环境名称，以便生成更便于使用的报告。[#42037](https://github.com/ClickHouse/ClickHouse/pull/42037) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 新增了系统表 `asynchronous_insert_log `。它包含有关异步插入的信息 (包括发出即忘模式下查询的结果 (使用 `wait_for_async_insert=0`) ) ，以便更好地查看内部信息。[#42040](https://github.com/ClickHouse/ClickHouse/pull/42040) ([Anton Popov](https://github.com/CurtizJ)).
* 修复了从 CSV 解析超出范围的 Date 时的问题。[#42044](https://github.com/ClickHouse/ClickHouse/pull/42044) ([Andrey Zvonov](https://github.com/zvonand)).
* parseDataTimeBestEffort 现已支持在日期和时间之间使用逗号。关闭 [#42038](https://github.com/ClickHouse/ClickHouse/issues/42038)。[#42049](https://github.com/ClickHouse/ClickHouse/pull/42049) ([flynn](https://github.com/ucasfl)).
* 在 &#39;Accept-Encoding&#39; 中新增对 lz4、bz2、snappy 方法的支持。[#42071](https://github.com/ClickHouse/ClickHouse/pull/42071) ([Nikolay Degterinsky](https://github.com/evillique)).
* 对 BLAKE3 函数进行了多项小修复。[#42073](https://github.com/ClickHouse/ClickHouse/pull/42073) ([BoloniniD](https://github.com/BoloniniD)).
* 改进了 `ReplicatedMergeTree` 的过期副本恢复流程。如果丢失的副本中包含某些健康副本上不存在的 parts，但根据健康副本的复制队列，这些 parts 未来应当会出现，那么丢失的副本将保留这些 parts，而不是将其 detach。[#42134](https://github.com/ClickHouse/ClickHouse/pull/42134) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 支持按原有路径/数据结构执行 BACKUP 到 S3。[#42232](https://github.com/ClickHouse/ClickHouse/pull/42232) ([Azat Khuzhin](https://github.com/azat)).
* 新增了在 date&#95;diff 函数中使用 Date32 argument 的支持。修复了在 date&#95;diff 函数中使用 DateTime64 argument，且开始日期早于 Unix epoch、结束日期晚于 Unix epoch 时出现的问题。[#42308](https://github.com/ClickHouse/ClickHouse/pull/42308) ([Roman Vasin](https://github.com/rvasin)).
* 将较大的 parts 上传到 minio 时，&#39;Complete Multipart Upload&#39; 可能耗时较长。Minio 每 10 秒发送一次心跳 (见 [https://github.com/minio/minio/pull/7198](https://github.com/minio/minio/pull/7198)) 。但 ClickHouse 会更早超时，因为默认发送/接收 timeout 被[设置](https://github.com/ClickHouse/ClickHouse/blob/cc24fcd6d5dfb67f5f66f5483e986bd1010ad9cf/src/IO/S3/PocoHTTPClient.cpp#L123)为 5 秒。[#42321](https://github.com/ClickHouse/ClickHouse/pull/42321) ([filimonov](https://github.com/filimonov)).
* 新增支持将 `S3` 用作 backups 的目标端类型。[#42333](https://github.com/ClickHouse/ClickHouse/pull/42333) ([Vitaly Baranov](https://github.com/vitlibar)).
* 修复了对 Decimal 等复杂类型的 aggregate state types 进行极少发生的无效 cast 问题。此修复解决了 [#42408](https://github.com/ClickHouse/ClickHouse/issues/42408)。[#42417](https://github.com/ClickHouse/ClickHouse/pull/42417) ([Amos Bird](https://github.com/amosbird)).
* 支持在请求的读取范围超过 cache 设置 `bypass_cache_threashold` 所定义的 threshold 时完全跳过 cache (包括不下载到 cache，也不读取已缓存数据) ，需要通过 `enable_bypass_cache_with_threshold` 启用。[#42418](https://github.com/ClickHouse/ClickHouse/pull/42418) ([Han Shukai](https://github.com/KinderRiven)).
* 如果范围内的每个 part 都早于某个阈值，则合并 parts。该阈值可通过 `min_age_to_force_merge_seconds` 设置。此项更改关闭了 [#35836](https://github.com/ClickHouse/ClickHouse/issues/35836)。[#42423](https://github.com/ClickHouse/ClickHouse/pull/42423) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 在 clickhouse-local 中启用了 CompiledExpressionCache。[#42477](https://github.com/ClickHouse/ClickHouse/pull/42477) ([AlfVII](https://github.com/AlfVII)) 。
* 移除了客户端提示符中对 `{database}` macro 的支持。如果未指定 database，则会显示错误，而且在执行 `USE` 语句后也不会更新。此项更改关闭了 [#25891](https://github.com/ClickHouse/ClickHouse/issues/25891)。[#42508](https://github.com/ClickHouse/ClickHouse/pull/42508) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* * 改进丢失的 Keeper 连接的恢复时间。[#42541](https://github.com/ClickHouse/ClickHouse/pull/42541) ([Raúl Marín](https://github.com/Algunenano)) 。
* 允许 `dateName` 函数使用 Date32 类型的参数。[#42554](https://github.com/ClickHouse/ClickHouse/pull/42554) ([Roman Vasin](https://github.com/rvasin)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 为 AST Fuzzer 新增了 WHERE 子句生成功能，并支持添加或移除 ORDER BY 和 WHERE 子句。[#38519](https://github.com/ClickHouse/ClickHouse/pull/38519) ([Ilya Yatsishin](https://github.com/qoega)).
* Aarch64 二进制文件现在至少需要 ARMv8.2 (于 2016 年发布) 。最值得注意的是，这使其能够使用 ARM LSE，即原生原子操作。此外，还新增了 CMake 构建选项 &quot;NO&#95;ARMV81&#95;OR&#95;HIGHER&quot;，以支持为较旧的 ARMv8.0 硬件 (例如 Raspberry Pi 4) 编译二进制文件。[#41610](https://github.com/ClickHouse/ClickHouse/pull/41610) ([Robert Schulze](https://github.com/rschu1ze)).
* 将 runners 更新到 22.04 后，cgroups 在特权模式下无法正常工作，相关 issue 见：[https://github.com/moby/moby/issues/42275#issuecomment-1115055846](https://github.com/moby/moby/issues/42275#issuecomment-1115055846)。[#41857](https://github.com/ClickHouse/ClickHouse/pull/41857) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 允许使用 Musl 构建 ClickHouse (在此前虽已支持但实际不可用的基础上做了一些小改动) 。[#41987](https://github.com/ClickHouse/ClickHouse/pull/41987) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* * 增加对 `$CLICKHOUSE_CRONFILE` 文件的检查，以避免运行 `sed` 命令时因文件不存在而报错。[#42081](https://github.com/ClickHouse/ClickHouse/pull/42081) ([Chun-Sheng, Li](https://github.com/peter279k)).
* 将 cctz 更新到最新的 master，并将 tzdb 更新到 2020e。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano)).
* 将 tzdata 更新到 2022e，以支持新的时区变更。巴勒斯坦的切换时间现为周六 02:00。将乌克兰的三个时区合并为一个。约旦和叙利亚从带夏令时的 +02/+03 切换为全年 +03。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS))。此更改关闭了 [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252)。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 修复了对 power8 的支持。[#42462](https://github.com/ClickHouse/ClickHouse/pull/42462) ([Boris Kuschel](https://github.com/bkuschel)).

* 修复了这样一个问题：如果 `ReplicatedMergeTree` 表由 20.3 或更早版本创建，且之后从未被修改，22.9 在启动时可能无法加载该表。修复了 [#41742](https://github.com/ClickHouse/ClickHouse/issues/41742)。[#41796](https://github.com/ClickHouse/ClickHouse/pull/41796) ([Alexander Tokmakov](https://github.com/tavplubix)).

* 修复了启用 compressed marks 设置时 compact parts 的问题。修复了 [#41783](https://github.com/ClickHouse/ClickHouse/issues/41783) 和 [#41746](https://github.com/ClickHouse/ClickHouse/issues/41746)。[#41823](https://github.com/ClickHouse/ClickHouse/pull/41823) ([alesapin](https://github.com/alesapin)).
* 旧版本的 Replicated database 在 [Zoo]Keeper 中没有特殊标记。现在只需检查该节点是否包含某些不明数据，而不必检查特殊标记。[#41875](https://github.com/ClickHouse/ClickHouse/pull/41875) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

* 修复了分离损坏分片时出现的 &quot;Directory already exists and is not empty&quot; 错误，该错误可能导致 `ReplicatedMergeTree` 表无法启动复制。修复 [#40957](https://github.com/ClickHouse/ClickHouse/issues/40957)。[#41981](https://github.com/ClickHouse/ClickHouse/pull/41981) ([Alexander Tokmakov](https://github.com/tavplubix)).
