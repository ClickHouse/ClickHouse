<div id="clickhouse-release-v2010330-stable-fixme-as-compared-to-v2010220-stable">
  ### ClickHouse 发布版 v20.10.3.30-稳定版本 FIXME (相较于 v20.10.2.20-稳定版本)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#16313](https://github.com/ClickHouse/ClickHouse/issues/16313) 中回移：添加 allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards (允许在分片键中使用 rand() 或 dictGet() 等非确定性函数) 。[#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#16202](https://github.com/ClickHouse/ClickHouse/issues/16202) 中回移：在分离只读表时递减 `ReadonlyReplica` 指标。此修复解决了 [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598)。[#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li))。
* 已在 [#16177](https://github.com/ClickHouse/ClickHouse/issues/16177) 中回移：如果首次尝试失败，可以将分片移动到另一块磁盘/卷上。[#15723](https://github.com/ClickHouse/ClickHouse/pull/15723) ([Pavel Kovalenko](https://github.com/Jokser))。
* 已在 [#16323](https://github.com/ClickHouse/ClickHouse/issues/16323) 中回移：修复了在表被并发重命名时，`DROP TABLE IF EXISTS` 因 `Table ... doesn't exist` 错误而失败的问题 (适用于 `Atomic` 数据库引擎) 。修复了并发执行某些涉及多个表的 DDL 查询 (如 `DROP DATABASE` 和 `RENAME TABLE`) 时偶发的死锁问题。修复了在并发执行 `DROP/DETACH TABLE` 时，`DROP/DETACH DATABASE` 因 `Table ... doesn't exist` 而失败的问题。[#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix))。
* 已在 [#16359](https://github.com/ClickHouse/ClickHouse/issues/16359) 中回移：修复 collate name 和 charset name 解析器，并支持 String 类型的 `length = 0`。[#16008](https://github.com/ClickHouse/ClickHouse/pull/16008) ([Winter Zhang](https://github.com/zhang2014))。
* 已在 [#16299](https://github.com/ClickHouse/ClickHouse/issues/16299) 中回移：修复 sharding&#95;key 中的 dictGet (以及类似场景，即函数上下文被永久存储时) 。[#16205](https://github.com/ClickHouse/ClickHouse/pull/16205) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#16234](https://github.com/ClickHouse/ClickHouse/issues/16234) 中回移：修复了无视限制仍可能发生内存过量分配的问题。此修复关闭了 [#14560](https://github.com/ClickHouse/ClickHouse/issues/14560)。[#16206](https://github.com/ClickHouse/ClickHouse/pull/16206) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#16327](https://github.com/ClickHouse/ClickHouse/issues/16327) 中回移：修复了使用字符串键执行 `GROUP BY` 时可能出现的内存泄漏，该问题由 `TwoLevelStringHashTable` 实现中的错误导致。[#16264](https://github.com/ClickHouse/ClickHouse/pull/16264) ([Amos Bird](https://github.com/amosbird))。
* 已在 [#16374](https://github.com/ClickHouse/ClickHouse/issues/16374) 中回移：修复了在 `prefer_localhost_replica=0` 和 `internal_replication` 条件下异步 Distributed INSERT 的问题。[#16358](https://github.com/ClickHouse/ClickHouse/pull/16358) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#16419](https://github.com/ClickHouse/ClickHouse/issues/16419) 中回移：修复了带有 totals/rollup/cube 修饰符的 `GROUP BY`，以及对 `GROUP BY` 键使用 min/max 函数时的问题。修复了 [#16393](https://github.com/ClickHouse/ClickHouse/issues/16393)。[#16397](https://github.com/ClickHouse/ClickHouse/pull/16397) ([Anton Popov](https://github.com/CurtizJ))。
* 已在 [#16448](https://github.com/ClickHouse/ClickHouse/issues/16448) 中回移：修复了函数 `dictGet` 在发生异常时的 double free 问题。如果字典加载时报错，就可能触发该问题。[#16429](https://github.com/ClickHouse/ClickHouse/pull/16429) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
