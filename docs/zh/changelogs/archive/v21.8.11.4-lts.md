<div id="bug-fix">
  #### 缺陷修复

* 已在 [#31368](https://github.com/ClickHouse/ClickHouse/issues/31368) 中回移：修复了使用部分撤销权限时 SHOW GRANTS 的问题。此 PR 修复了 [#31138](https://github.com/ClickHouse/ClickHouse/issues/31138)。[#31249](https://github.com/ClickHouse/ClickHouse/pull/31249) ([Vitaly Baranov](https://github.com/vitlibar)) 。

#### 缺陷修复 (官方稳定版本中用户可见的异常行为

* 已在 [#30914](https://github.com/ClickHouse/ClickHouse/issues/30914) 中回移：修复了在指定 `TO` 和 `FROM` 且结果集为空时，`ORDER BY ... WITH FILL` 的问题。[#30888](https://github.com/ClickHouse/ClickHouse/pull/30888) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#28756](https://github.com/ClickHouse/ClickHouse/issues/28756) 中回移：修复了未使用全部键列时 NOT-IN 索引优化失效的问题。此修复解决了 [#28120](https://github.com/ClickHouse/ClickHouse/issues/28120)。[#28315](https://github.com/ClickHouse/ClickHouse/pull/28315) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#30825](https://github.com/ClickHouse/ClickHouse/issues/30825) 中回移：修复了使用 PREWHERE 时出现的 &quot;Column is not under aggregate function and not in GROUP BY&quot; 问题 (修复了 [#28461](https://github.com/ClickHouse/ClickHouse/issues/28461)) 。[#28502](https://github.com/ClickHouse/ClickHouse/pull/28502) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#29175](https://github.com/ClickHouse/ClickHouse/issues/29175) 中回移：修复了查询外部数据库 (如 MySQL) 时，在 IN 中使用多列 (例如 `(k,v) IN ((1, 2))`) 的问题 (但请注意，这会对 `clickhouse-copier` 造成一定的向后不兼容，因为它对 tuple 元素使用了别名) 。[#28888](https://github.com/ClickHouse/ClickHouse/pull/28888) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#30610](https://github.com/ClickHouse/ClickHouse/issues/30610) 中回移：修复了 ORDER BY 包含 WITH FILL 时的错误优化问题。此修复关闭了 [#28908](https://github.com/ClickHouse/ClickHouse/issues/28908)。此修复关闭了 [#26049](https://github.com/ClickHouse/ClickHouse/issues/26049)。[#28910](https://github.com/ClickHouse/ClickHouse/pull/28910) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#30767](https://github.com/ClickHouse/ClickHouse/issues/30767) 中回移：修复了在添加新副本时 Replicated database 上 DDL queries 卡住的问题。[#29328](https://github.com/ClickHouse/ClickHouse/pull/29328) ([Kevin Michel](https://github.com/kmichel-aiven)).
* 已在 [#30205](https://github.com/ClickHouse/ClickHouse/issues/30205) 中回移：修复了 `StorageLog` 中 `LogSink::writeMarks()` 与 `LogSource` 之间的数据竞争问题。[#29946](https://github.com/ClickHouse/ClickHouse/pull/29946) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#30463](https://github.com/ClickHouse/ClickHouse/issues/30463) 中回移：函数 `initializeAggregation` 现已支持 Nullable arguments。[#30177](https://github.com/ClickHouse/ClickHouse/pull/30177) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#30655](https://github.com/ClickHouse/ClickHouse/issues/30655) 中回移：修复了 `[I]LIKE` 函数。关闭了 [#28661](https://github.com/ClickHouse/ClickHouse/issues/28661)。[#30244](https://github.com/ClickHouse/ClickHouse/pull/30244) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#30289](https://github.com/ClickHouse/ClickHouse/issues/30289) 中回移：修复了 ComplexKeyHashedDictionary 和 ComplexKeySparseHashedDictionary 从 layout config 解析 `preallocate` 选项的问题。[#30246](https://github.com/ClickHouse/ClickHouse/pull/30246) ([Maksim Kita](https://github.com/kitaisreal)).
* 已在 [#30525](https://github.com/ClickHouse/ClickHouse/issues/30525) 中回移：修复了执行 REPLACE PARTITION 期间会话过期时可能发生的 segfault。[#30432](https://github.com/ClickHouse/ClickHouse/pull/30432) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 修复了 `parallel_view_processing` 中的异常处理。这解决了相关问题，并避免了在启用该功能且在 materialized view 处理过程中发生异常 (例如 &quot;Memory limit exceeded ...&quot;) 时，在某些罕见边缘情况下出现崩溃。[#30472](https://github.com/ClickHouse/ClickHouse/pull/30472) ([filimonov](https://github.com/filimonov)).
* 已在 [#30585](https://github.com/ClickHouse/ClickHouse/issues/30585) 中回移：* 修复了对同一张表执行带有标量子查询的 ALTER 时发生死锁的问题，关闭 [#30461](https://github.com/ClickHouse/ClickHouse/issues/30461)。[#30492](https://github.com/ClickHouse/ClickHouse/pull/30492) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#30607](https://github.com/ClickHouse/ClickHouse/issues/30607) 中回移：Limit 下推优化可能导致报错 `Cannot find column`。修复 [#30438](https://github.com/ClickHouse/ClickHouse/issues/30438)。[#30562](https://github.com/ClickHouse/ClickHouse/pull/30562) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#30753](https://github.com/ClickHouse/ClickHouse/issues/30753) 中回移：`positionCaseInsensitiveUTF8` 和 `countSubstringsCaseInsensitiveUTF8` 等用于在 UTF8 String 中进行不区分大小写搜索的函数，可能会找到实际上并不匹配的子字符串，此问题已修复。[#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#30710](https://github.com/ClickHouse/ClickHouse/issues/30710) 中回移：修复了在 PREWHERE 始终为 true 时使用 PREWHERE 与 WHERE 的问题。[#30668](https://github.com/ClickHouse/ClickHouse/pull/30668) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#30770](https://github.com/ClickHouse/ClickHouse/issues/30770) 中回移：修复了非复制表 `MergeTree` 中 `REPLACE/MOVE PARTITION` 与后台 merge 之间的竞态条件，该问题可能导致已移动/替换数据的一部分仍留在分区中。修复 [#29327](https://github.com/ClickHouse/ClickHouse/issues/29327)。[#30717](https://github.com/ClickHouse/ClickHouse/pull/30717) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#30857](https://github.com/ClickHouse/ClickHouse/issues/30857) 中回移：修复了在 `ReplicatedMergeTree` 中从 ZooKeeper path 提取辅助 ZooKeeper 名称时的歧义问题。此前，如果 ZooKeeper path 中包含冒号，server 可能因 `Unknown auxiliary ZooKeeper name` 而启动失败。修复 [#29052](https://github.com/ClickHouse/ClickHouse/issues/29052)。此外，之前允许指定不以斜杠开头的 ZooKeeper path，但现在该用法已弃用，并且不允许再用此类 path 创建新表。辅助 ZooKeeper 名称中同样不允许出现斜杠和冒号。[#30822](https://github.com/ClickHouse/ClickHouse/pull/30822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#30925](https://github.com/ClickHouse/ClickHouse/issues/30925) 中回移：修复了在操作数超过两个时，AND/OR 表达式中 set 索引未生效的问题。修复了 [#30416](https://github.com/ClickHouse/ClickHouse/issues/30416)。[#30887](https://github.com/ClickHouse/ClickHouse/pull/30887) ([Amos Bird](https://github.com/amosbird)).
* 已在 [#31151](https://github.com/ClickHouse/ClickHouse/issues/31151) 中回移：在 ATTACH PARTITION ... FROM 和 MOVE PARTITION ... 的情况下跳过 max&#95;partition&#95;size&#95;to&#95;drop 检查。[#30995](https://github.com/ClickHouse/ClickHouse/pull/30995) ([Amr Alaa](https://github.com/amralaa-MSFT)).
* 已在 [#31040](https://github.com/ClickHouse/ClickHouse/issues/31040) 中回移：将 `formatRow` 函数用于非行格式会导致 segfault。现已禁止在这类格式中使用该函数 (因为这本身就没有意义) 。[#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#31132](https://github.com/ClickHouse/ClickHouse/issues/31132) 中回移：修复 JSONValue/Query 对带引号标识符的处理。这样一来，JSON path 中即可包含空格。关闭 [#30971](https://github.com/ClickHouse/ClickHouse/issues/30971)。[#31003](https://github.com/ClickHouse/ClickHouse/pull/31003) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#31372](https://github.com/ClickHouse/ClickHouse/issues/31372) 中回移：修复 StorageMerge 在使用别名和 WHERE 子句时的问题 (此前完全无法工作) 。关闭 [#28802](https://github.com/ClickHouse/ClickHouse/issues/28802)。[#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii)).
