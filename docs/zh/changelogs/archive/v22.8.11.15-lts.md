<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#43098](https://github.com/ClickHouse/ClickHouse/issues/43098) 中回移：更新了 normaliser，使其克隆 alias AST。解决了 [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452)。实现：* 更新了 QueryNormalizer，在 alias AST 被替换时对其进行克隆。此前如果只是赋用同一个对象，会导致 LogicalExpressinsOptimizer 中抛出异常，因为这会再次插入同一个 parent。* 该缺陷在新的 analyzer (allow&#95;experimental&#95;analyzer) 中不会出现，因此未对其做任何改动。我还为此添加了相应测试。[#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)) 。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#43751](https://github.com/ClickHouse/ClickHouse/issues/43751) 中回移：有人报告，在尝试将 S3 中的 Parquet 文件读入 ClickHouse 时会出现以下异常。[#43297](https://github.com/ClickHouse/ClickHouse/pull/43297) ([Arthur Passos](https://github.com/arthurpassos)) 。
* 已在 [#43617](https://github.com/ClickHouse/ClickHouse/issues/43617) 中回移：修复 `sumMap()` 对 `Nullable(Decimal())` 的处理问题。[#43414](https://github.com/ClickHouse/ClickHouse/pull/43414) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#43886](https://github.com/ClickHouse/ClickHouse/issues/43886) 中回移：修复带有 `ON CLUSTER` 的 `ALTER ... RESET SETTING` 语句。此前它可能只会应用到一个副本。修复了 [#43843](https://github.com/ClickHouse/ClickHouse/issues/43843)。[#43848](https://github.com/ClickHouse/ClickHouse/pull/43848) ([Elena Torró](https://github.com/elenatorro)) 。
