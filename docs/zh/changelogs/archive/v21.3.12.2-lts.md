<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#24189](https://github.com/ClickHouse/ClickHouse/issues/24189) 中回移：某些 `ALTER PARTITION` 查询可能会在复制队列中触发 `Part A intersects previous part B` 和 `Unexpected merged part C intersecting drop range D` 错误。现已修复。修复了 [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296)。[#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#24306](https://github.com/ClickHouse/ClickHouse/issues/24306) 中回移：修复了在 WHERE 中使用 const `DateTime` 值与 `DateTime64` 列进行比较时的问题。... [#24100](https://github.com/ClickHouse/ClickHouse/pull/24100) ([Vasily Nemkov](https://github.com/Enmk)).
* 已在 [#24140](https://github.com/ClickHouse/ClickHouse/issues/24140) 中回移：缺陷：使用 `select xxx final` 执行 explain pipeline 时会显示错误的管道：&#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* 已在 [#24190](https://github.com/ClickHouse/ClickHouse/issues/24190) 中回移：修复了一个罕见缺陷，该缺陷可能导致表仅被部分初始化却仍可处理写请求 (insert/alter 等) 。现在这类表将处于只读模式。[#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* 已在 [#24235](https://github.com/ClickHouse/ClickHouse/issues/24235) 中回移：修复了 RBAC 在高负载下可能出现的竞态条件。此 PR 修复了 [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090) 和 [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134)。[#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* 已在 [#24244](https://github.com/ClickHouse/ClickHouse/issues/24244) 中回移：修复了因 hdfs 在查询执行期间变得不可访问而导致服务器异常终止的问题。关闭 [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117)。[#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#24241](https://github.com/ClickHouse/ClickHouse/issues/24241) 中回移：修复了 StorageMemory 中的拼写错误。该缺陷是在 [#15127](https://github.com/ClickHouse/ClickHouse/issues/15127) 中引入的，现已修复。关闭 [#24192](https://github.com/ClickHouse/ClickHouse/issues/24192)。[#24193](https://github.com/ClickHouse/ClickHouse/pull/24193) ([张中南](https://github.com/plugine)).
* 已在 [#24353](https://github.com/ClickHouse/ClickHouse/issues/24353) 中回移：修复了将 Materialized View 从 Ordinary 移动到 Atomic 数据库时的一个缺陷 (`RENAME TABLE` 查询) 。现在内部表会随 Materialized View 一起移动到新数据库。修复了 [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926)。[#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
