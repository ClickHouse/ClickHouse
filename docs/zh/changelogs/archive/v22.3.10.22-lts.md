<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#39206](https://github.com/ClickHouse/ClickHouse/issues/39206) 中回移：修复了从将数据存储在 S3 中的 `MergeTree` 表读取稀疏列时的问题。[#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#39381](https://github.com/ClickHouse/ClickHouse/issues/39381) 中回移：修复了在带有 `PREWHERE` 和按顺序读取优化的 selects 中出现的错误 `Not found column Type in block`。[#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 已在 [#39588](https://github.com/ClickHouse/ClickHouse/issues/39588) 中回移：修复了 Avro 格式中的数据竞争以及可能发生的堆缓冲区溢出。关闭 [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094) 关闭 [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652)。[#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* 已在 [#39610](https://github.com/ClickHouse/ClickHouse/issues/39610) 中回移：修复了 splitByChar 的 maxsplit argument，此前该参数未能正常工作。[#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* 已在 [#39834](https://github.com/ClickHouse/ClickHouse/issues/39834) 中回移：修复了 `local_filesystem_read_method=pread_threadpool` 下的 `CANNOT_READ_ALL_DATA` Exception。根据 [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS)，此缺陷仅影响 Linux 内核 5.9 和 5.10 版本。[#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
