  ### ClickHouse 发布版本 v23.5.5.92-稳定版本 (557edaddace) FIXME，相较于 v23.5.4.25-稳定版本 (190f962abcf)

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#52749](https://github.com/ClickHouse/ClickHouse/issues/52749) 中回移：修复了错误的投影分析问题，该问题会导致主键失效。此问题仅在 `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1` 时存在。此修复还解决了 [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823) 和 [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173)。[#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)) 。

<div id="buildtestingpackaging-improvement">
  #### 构建/测试/打包改进
</div>

* 已在 [#51886](https://github.com/ClickHouse/ClickHouse/issues/51886) 中回移：更新 cargo 依赖项。[#51721](https://github.com/ClickHouse/ClickHouse/pull/51721) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#52909](https://github.com/ClickHouse/ClickHouse/issues/52909) 中回移：为 clickhouse-server 软件包添加 `clickhouse-keeper-client` 符号链接。[#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#53021](https://github.com/ClickHouse/ClickHouse/issues/53021) 中回移：将 inline cache 打包进 Docker 镜像有时会引发一些奇怪的问题。反正我们完全不用它，所以去掉即可。[#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* 已在 [#53289](https://github.com/ClickHouse/ClickHouse/issues/53289) 中回移：将编译器的性能分析数据 (`-ftime-trace`) 上传到 ClickHouse Cloud。这是继 [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) 之后的第二次尝试。[#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#53463](https://github.com/ClickHouse/ClickHouse/issues/53463) 中回移：在 `clickhouse start` 命令中保留环境参数。修复了 [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962)。[#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
