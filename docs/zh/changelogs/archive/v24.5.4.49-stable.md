<div id="improvement">
  #### 改进
</div>

* 已在[#65886](https://github.com/ClickHouse/ClickHouse/issues/65886)中回移：始终确保 Keeper 启动时全局线程池中有足够数量的线程。[#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94)) 。
* 已在[#65304](https://github.com/ClickHouse/ClickHouse/issues/65304)中回移：恢复了 ClickHouse 在 CSV 格式中处理和解释 Tuple 的方式。此更改实际上回退了 [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994)，并使其仅在少数几个设置下可用：`output_format_csv_serialize_tuple_into_separate_columns`、`input_format_csv_deserialize_separate_columns_into_tuple` 和 `input_format_csv_try_infer_strings_from_quoted_tuples`。[#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在[#65896](https://github.com/ClickHouse/ClickHouse/issues/65896)中回移：让 Keeper 遵守 cgroup CPU 限制。[#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)) 。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 严重缺陷修复 (崩溃、LOGICAL_ERROR、数据丢失、RBAC)
</div>

* 已在 [#65287](https://github.com/ClickHouse/ClickHouse/issues/65287) 中回移：修复 UniqInjectiveFunctionsEliminationPass 和 uniqCombined 导致崩溃的问题。[#65188](https://github.com/ClickHouse/ClickHouse/pull/65188) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#65374](https://github.com/ClickHouse/ClickHouse/issues/65374) 中回移：修复 ClickHouse Keeper 在关闭会话期间导致 digest 不匹配的问题。[#65198](https://github.com/ClickHouse/ClickHouse/pull/65198) ([Aleksei Filatov](https://github.com/aalexfvk)) 。
* 已在 [#65437](https://github.com/ClickHouse/ClickHouse/issues/65437) 中回移：在旧版 analyzer 中禁止使用 `QUALIFY` 子句。旧版 analyzer 会忽略 `QUALIFY`，因此可能导致在变更操作中意外删除数据。[#65356](https://github.com/ClickHouse/ClickHouse/pull/65356) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#65450](https://github.com/ClickHouse/ClickHouse/issues/65450) 中回移：为 Distinct 组合器使用正确的内存对齐方式。此前，使用该组合器时，可能因无效的内存分配而发生崩溃。[#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#65712](https://github.com/ClickHouse/ClickHouse/issues/65712) 中回移：修复 maxIntersections 中的崩溃问题。[#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)) 。

* 已在 [#65732](https://github.com/ClickHouse/ClickHouse/issues/65732) 中回移：递归消除 `uniq*` 函数参数中的 injective 函数。该功能此前可正常工作，但在新的 analyzer 中失效了。[#65140](https://github.com/ClickHouse/ClickHouse/pull/65140) ([Duc Canh Le](https://github.com/canhld94)).

* 已在 [#65812](https://github.com/ClickHouse/ClickHouse/issues/65812) 中回移：修复函数 `parseDateTime` 使用 `%F` 和 `%D` 占位符时抛出无效异常的问题。[#65768](https://github.com/ClickHouse/ClickHouse/pull/65768) ([Antonio Andelic](https://github.com/antonio2368))。
