<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#32252](https://github.com/ClickHouse/ClickHouse/issues/32252) 中回移：修复写入 Protobuf 时跳过列的问题。此 PR 修复了 [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)，请参见评论 [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318。[#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)) 。
* 已在 [#32346](https://github.com/ClickHouse/ClickHouse/issues/32346) 中回移：修复在子查询中删除不必要的列时出现的缺陷。如果查询中存在不带 group by 的聚合函数，即使该列看似不需要，也不要删除。[#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)) 。

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#32151](https://github.com/ClickHouse/ClickHouse/issues/32151) 中回移：修复了当字典属性类型为 `Nullable` 时，对其使用带类型的函数 `dictGet` 会导致崩溃的问题。修复了 [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)) 。
* 已在 [#32093](https://github.com/ClickHouse/ClickHouse/issues/32093) 中回移：如果某个分片在所有副本上都已丢失，且同一分区中没有其他分片，则某些 `GET_PART` 条目可能会卡在复制队列中。该问题已在分区键仅包含整数类型列或 `Date[Time]` 时修复。修复了 [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485)。[#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#32147](https://github.com/ClickHouse/ClickHouse/issues/32147) 中回移：修复了在 detach 分片时出现 `Directory ... already exists and is not empty` 错误的问题。[#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#32216](https://github.com/ClickHouse/ClickHouse/issues/32216) 中回移：修复了在使用 quorum 执行插入时，如果某些副本禁用了设置 `replicated_can_become_leader`，活跃副本数量可能被错误判定的问题。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#32352](https://github.com/ClickHouse/ClickHouse/issues/32352) 中回移：修复了聚合函数 `avgWeighted` 在使用 `Decimal` 参数时发生 SIGFPE 崩溃的问题。修复了 [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)。[#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#32393](https://github.com/ClickHouse/ClickHouse/issues/32393) 中回移：修复了当默认表达式的数据类型与列的数据类型不一致时，`ALTER ... MATERIALIZE COLUMN ...` 查询的问题。[#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)) 。
