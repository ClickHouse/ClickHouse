  ### ClickHouse 版本 v20.8.3.18-稳定版本 FIXME (相较于 v20.8.2.3-稳定版本)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#14874](https://github.com/ClickHouse/ClickHouse/issues/14874) 中回移：允许在 Distributed 存储中使用多卷存储配置。[#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)) 。
* 如果存在正在进行的 S3 请求，可加快 server 关闭过程。[#14858](https://github.com/ClickHouse/ClickHouse/pull/14858) ([Pavel Kovalenko](https://github.com/Jokser)) 。

<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#14600](https://github.com/ClickHouse/ClickHouse/issues/14600) 中回移：修复了带有组合器 -Resample 的函数中罕见的 segfault 问题，该问题可能在参数极大导致 overflow 时出现。[#14562](https://github.com/ClickHouse/ClickHouse/pull/14562) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#14727](https://github.com/ClickHouse/ClickHouse/issues/14727) 中回移：在 StorageReplicatedMergeTree Engine 的 CreateQuery 期间发生 ZooKeeper 异常后，清理数据目录。[#14563](https://github.com/ClickHouse/ClickHouse/pull/14563) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 已在 [#14653](https://github.com/ClickHouse/ClickHouse/issues/14653) 中回移：添加了检查器，因为无论调用 `lc->isNullable()` 还是 `ls->getDictionaryPtr()->isNullable()`，都无法返回正确结果。[#14591](https://github.com/ClickHouse/ClickHouse/pull/14591) ([Mike Kot](https://github.com/myrrc)) 。
* 已在 [#14666](https://github.com/ClickHouse/ClickHouse/issues/14666) 中回移：修复了因结果列 Decimal 标度错误导致的 Decimal 乘法结果错误问题。[#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)) 。
* 已在 [#14793](https://github.com/ClickHouse/ClickHouse/issues/14793) 中回移：修复了 `ALTER UPDATE` 变更中，如果赋值表达式使用 Nullable 列和常量值 (如 `UPDATE x = 42`) ，会导致列值错误或出现 segfault 的 bug。修复了 [#13634](https://github.com/ClickHouse/ClickHouse/issues/13634)、[#14045](https://github.com/ClickHouse/ClickHouse/issues/14045)。[#14646](https://github.com/ClickHouse/ClickHouse/pull/14646) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#14722](https://github.com/ClickHouse/ClickHouse/issues/14722) 中回移：修复了执行 `ALTER ... MODIFY QUERY` 时，materialized view 的 metadata 中缺失默认数据库名称的问题。[#14664](https://github.com/ClickHouse/ClickHouse/pull/14664) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#14910](https://github.com/ClickHouse/ClickHouse/issues/14910) 中回移：修复了尝试向 StorageFile(fd) 执行 INSERT 时出现的 SIGSEGV 问题。[#14887](https://github.com/ClickHouse/ClickHouse/pull/14887) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#14943](https://github.com/ClickHouse/ClickHouse/issues/14943) 中回移：修复了某些对 `extractAllGroups` 函数的调用可能触发 “Memory limit exceeded” 错误的问题。此修复同时解决了 [#13383](https://github.com/ClickHouse/ClickHouse/issues/13383)。[#14889](https://github.com/ClickHouse/ClickHouse/pull/14889) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
