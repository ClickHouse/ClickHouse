<div id="bug-fix">
  #### 缺陷修复
</div>

* 已在 [#22191](https://github.com/ClickHouse/ClickHouse/issues/22191) 中回移：修复了 Poco 中 `SecureSocket` 内部 SSL 对象上的竞争问题。[#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#22336](https://github.com/ClickHouse/ClickHouse/issues/22336) 中回移：修复表函数 `clusterAllReplicas` 返回错误 `_shard_num` 的问题。关闭 [#21481](https://github.com/ClickHouse/ClickHouse/issues/21481)。[#21498](https://github.com/ClickHouse/ClickHouse/pull/21498) ([flynn](https://github.com/ucasfl)) 。
* 已在 [#22092](https://github.com/ClickHouse/ClickHouse/issues/22092) 中回移：如果查询带有常量 `WHERE` 条件，且已启用 setting `optimize_skip_unused_shards`，则可能会跳过所有分片，导致查询返回错误的空结果。[#21550](https://github.com/ClickHouse/ClickHouse/pull/21550) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#22318](https://github.com/ClickHouse/ClickHouse/issues/22318) 中回移：对于外部数据库引擎 (MySQL、PostgreSQL) 的查询，从 WHERE 子句中的 JOIN 表移除未知列。关闭 [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614)、关闭 [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (重复) 、关闭 [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (重复) 。[#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)) 。
* 已在 [#22285](https://github.com/ClickHouse/ClickHouse/issues/22285) 中回移：在 DDLWorker 和字典初始化完成后才开始接受连接。[#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#21753](https://github.com/ClickHouse/ClickHouse/issues/21753) 中回移：修复 `ReplicatedMergeTree` 的并发 `OPTIMIZE` 和 `DROP` 问题。[#21716](https://github.com/ClickHouse/ClickHouse/pull/21716) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#21809](https://github.com/ClickHouse/ClickHouse/issues/21809) 中回移：修复 ReplicatedMerge 表引擎中的一个问题：当 `ALTER MODIFY COLUMN` 查询未改变 Decimal 列的大小 (32 比特或 64 比特) 时，其类型不会被修改。[#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#22188](https://github.com/ClickHouse/ClickHouse/issues/22188) 中回移：回退了 S3 连接池。[#21737](https://github.com/ClickHouse/ClickHouse/pull/21737) ([Vladimir Chebotarev](https://github.com/excitoon)) 。
* 已在 [#22240](https://github.com/ClickHouse/ClickHouse/issues/22240) 中回移：修复标量子查询的索引分析问题。此修复解决了 [#21717](https://github.com/ClickHouse/ClickHouse/issues/21717)，该问题是在 [https://github.com/ClickHouse/ClickHouse/pull/18896](https://github.com/ClickHouse/ClickHouse/pull/18896) 中引入的。[#21766](https://github.com/ClickHouse/ClickHouse/pull/21766) ([Amos Bird](https://github.com/amosbird)) 。
* 已在 [#22050](https://github.com/ClickHouse/ClickHouse/issues/22050) 中回移：修复首次执行 catboost 模型时的死锁问题。关闭 [#13832](https://github.com/ClickHouse/ClickHouse/issues/13832)。[#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#22464](https://github.com/ClickHouse/ClickHouse/issues/22464) 中回移：在极少数情况下，`CollapsingMergeTree` 的合并可能会创建包含 `index_granularity + 1` 行的粒度。因此，[#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) 中新增的内部检查 (影响 21.2 和 21.3) 可能会因错误 `Incomplete granules are not allowed while blocks are granules size` 而失败，导致 parts 无法合并。[#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#22204](https://github.com/ClickHouse/ClickHouse/issues/22204) 中回移：Docker entrypoint：当 `LOG_PATH` 为空时，避免对 `.` 执行 chown。关闭 [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100)。[#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)) 。
* 已在 [#22278](https://github.com/ClickHouse/ClickHouse/issues/22278) 中回移：修复 `ReplicatedMergeTree` 表引擎中 `OPTIMIZE` 和 `ALTER` 查询的等待问题。现在，即使表已被 detached 或重启，查询也不会挂起。[#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#22266](https://github.com/ClickHouse/ClickHouse/issues/22266) 中回移：修复后台线程池名称。[#22122](https://github.com/ClickHouse/ClickHouse/pull/22122) ([fastio](https://github.com/fastio)) 。
* 已在 [#22315](https://github.com/ClickHouse/ClickHouse/issues/22315) 中回移：修复配置中不存在 `http_port` 时的 Docker entrypoint 问题。[#22132](https://github.com/ClickHouse/ClickHouse/pull/22132) ([Ewout](https://github.com/devwout)) 。
* 已在 [#22502](https://github.com/ClickHouse/ClickHouse/issues/22502) 中回移：修复在 `use_hedged_requests=0` 和 `async_socket_for_remote=1` 时的查询取消问题。[#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#22369](https://github.com/ClickHouse/ClickHouse/issues/22369) 中回移：现在，对已被覆盖的 part 执行 mutation 时，ClickHouse 不会再抛出 `LOGICAL_ERROR` 异常。修复 [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013)。[#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)) 。
* 已在 [#22530](https://github.com/ClickHouse/ClickHouse/issues/22530) 中回移：`tokenbf_v1` 全文索引中可能出现缓冲区溢出 (读取时) 。多读出的字节不会被使用，但在极少数情况下，读取操作可能导致崩溃。此项关闭 [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233)。[#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#22461](https://github.com/ClickHouse/ClickHouse/issues/22461) 中回移：为并行解析例程补充了缺失的内存统计。在之前的版本中，当结果集包含非常大的数据块时，可能会发生 OOM。此项关闭 [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008)。[#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#22557](https://github.com/ClickHouse/ClickHouse/issues/22557) 中回移：修复 `LowCardinality` 在 partial merge join 中的 bug。关闭 [#22386](https://github.com/ClickHouse/ClickHouse/issues/22386) 和 [#22388](https://github.com/ClickHouse/ClickHouse/issues/22388)。[#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* 已在 [#22606](https://github.com/ClickHouse/ClickHouse/issues/22606) 中回移：修复 TSV format 末尾没有换行符时空字符串的反序列化问题。此修复关闭了 [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244)。无需升级版本的一种临时规避方法：将 `input_format_null_as_default` 设为零。旧版本中的值即为零。[#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#22575](https://github.com/ClickHouse/ClickHouse/issues/22575) 中回移：通过在同一线程中解锁 TinyLog 的 rwlock 来修复 UB。[#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22648](https://github.com/ClickHouse/ClickHouse/issues/22648) 中回移：避免 *Log engines 因从另一个线程解锁 rwlock 而导致的 UB。[#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22682](https://github.com/ClickHouse/ClickHouse/issues/22682) 中回移：修复 Log 在 SELECT clause 中未包含列时，嵌套类型导致的 LOGICAL&#95;ERROR。[#22654](https://github.com/ClickHouse/ClickHouse/pull/22654) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#22699](https://github.com/ClickHouse/ClickHouse/issues/22699) 中回移：修复 ReplicatedMergeTree 表引擎在多个副本上等待 mutations 的问题。此前，mutation/alter 查询可能会在其他副本上的 mutation 实际执行之前就结束。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* 已在 [#22740](https://github.com/ClickHouse/ClickHouse/issues/22740) 中回移：修复发生 OOM exception 时 zk requests 可能卡住的问题。修复了 [#22438](https://github.com/ClickHouse/ClickHouse/issues/22438)。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
