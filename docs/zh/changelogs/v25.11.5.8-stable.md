  ### ClickHouse 发布 v25.11.5.8-稳定版本 (06e6dea3bb5) FIXME，相较于 v25.11.4.19-稳定版本 (2c64eff7334)

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#92901](https://github.com/ClickHouse/ClickHouse/issues/92901) 中回移：修复列与同名子列之间可能发生的冲突，该问题会导致使用错误的序列化方式并引发查询失败。关闭 [#90219](https://github.com/ClickHouse/ClickHouse/issues/90219)。关闭 [#85161](https://github.com/ClickHouse/ClickHouse/issues/85161)。 [#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#92988](https://github.com/ClickHouse/ClickHouse/issues/92988) 中回移：避免因从已断开的 `Connection` 读取数据而导致崩溃。 [#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* 已在 [#92879](https://github.com/ClickHouse/ClickHouse/issues/92879) 中回移：修复存储 `S3Queue` 在 `Ordered` 模式下的逻辑错误 ` Failed to set file processing within 100 retries`。该错误现已改为警告。在 25.10 之前的版本中，如果 Keeper session 过期，就可能出现此错误；不过在 25.10+ 版本中，它仍会以警告形式出现，因为在 `Ordered` 模式下处理并发较高时，理论上仍有可能触发该错误。 [#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#92943](https://github.com/ClickHouse/ClickHouse/issues/92943) 中回移：修复轻量级更新中主索引的使用问题：当 `WHERE` 子句的谓词中包含带子查询的 `IN` 子句时，会出现该问题。 [#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#92962](https://github.com/ClickHouse/ClickHouse/issues/92962) 中回移：修复对设置了 `ratio_of_defaults_for_sparse_serialization=0.0` 的稀疏列执行变更后可能出现的 `FILE_DOESNT_EXIST` 错误。关闭 [#92633](https://github.com/ClickHouse/ClickHouse/issues/92633)。 [#92860](https://github.com/ClickHouse/ClickHouse/pull/92860) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#92934](https://github.com/ClickHouse/ClickHouse/issues/92934) 中回移：修复旧版 Parquet reader (默认未使用) 中的 Parquet schema inference 问题：当 JSON 列位于 Tuple 列之后时会出错。还修复了旧版 Parquet reader (默认未使用) 在处理空 Tuple 时失败的问题。 [#92867](https://github.com/ClickHouse/ClickHouse/pull/92867) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#93032](https://github.com/ClickHouse/ClickHouse/issues/93032) 中回移：修复由于共享 parts 的 TOCTOU 竞争而可能使用过期分区片段的问题。 [#93022](https://github.com/ClickHouse/ClickHouse/pull/93022) ([Azat Khuzhin](https://github.com/azat)).
