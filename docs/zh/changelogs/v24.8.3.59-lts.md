<div id="new-feature">
  #### 新特性
</div>

* 已在 [#68710](https://github.com/ClickHouse/ClickHouse/issues/68710) 中回移：现在支持按标签删除查询缓存项。例如，由 `SELECT 1 SETTINGS use_query_cache = true, query_cache_tag = 'abc'` 创建的查询缓存项，现在可以通过 `SYSTEM DROP QUERY CACHE TAG 'abc'` 删除 (当然，也可以直接使用：`SYSTEM DROP QUERY CACHE`，这会清空整个查询缓存) 。[#68477](https://github.com/ClickHouse/ClickHouse/pull/68477) ([Michał Tabaszewski](https://github.com/pinsvin00)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#68973](https://github.com/ClickHouse/ClickHouse/issues/68973) 中回移：修复函数 `fromModifiedJulianDay` 的上界。其正确值应为 `9999-12-31`，但之前被错误设置为 `9999-01-01`。[#67583](https://github.com/ClickHouse/ClickHouse/pull/67583) ([PHO](https://github.com/depressed-pho)) 。
* 已在 [#68818](https://github.com/ClickHouse/ClickHouse/issues/68818) 中回移：修复了 Parquet 筛选中一个会导致 crash 的问题：当文件中的 data types 与请求的 types 差异较大时会触发该问题 (例如 `... FROM file('a.parquet', Parquet, 'x String')`，但文件中的 `x` 实际为 `Int64`) 。如果无法应用此修复，可使用 `input_format_parquet_filter_push_down = 0` 作为临时变通方法。[#68131](https://github.com/ClickHouse/ClickHouse/pull/68131) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已在 [#68893](https://github.com/ClickHouse/ClickHouse/issues/68893) 中回移：在 [https://github.com/ClickHouse/ClickHouse/pull/61984](https://github.com/ClickHouse/ClickHouse/pull/61984) 之后，`schema_inference_make_columns_nullable=0` 在 Parquet/Arrow formats 中仍可能将列推断为 `Nullable`。该变更与旧行为不兼容，用户也注意到了这一行为变化。此 PR 使 `schema_inference_make_columns_nullable=0` 恢复为先前的行为 (不会推断出 Nullable 列) ，并为该设置新增了 `auto` 值：只有当数据本身包含可空性信息时，才会将列设为 `Nullable`。[#68298](https://github.com/ClickHouse/ClickHouse/pull/68298) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#68721](https://github.com/ClickHouse/ClickHouse/issues/68721) 中回移：修复了 [#50868](https://github.com/ClickHouse/ClickHouse/issues/50868)。在 distributed query 中，嵌套 subquery 返回的较小 DateTime64 常量值会被错误地转换为 NULL，从而导致报错，并可能产生不正确的 query results。[#68323](https://github.com/ClickHouse/ClickHouse/pull/68323) ([Shankar](https://github.com/shiyer7474)) 。
* 已在 [#69029](https://github.com/ClickHouse/ClickHouse/issues/69029) 中回移：将虚拟列 ` _table` 和 `_database` 重新加入分布式表。它们在 24.3 版本之前一直可用。[#68672](https://github.com/ClickHouse/ClickHouse/pull/68672) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#68864](https://github.com/ClickHouse/ClickHouse/issues/68864) 中回移：修复了 Variant 列在置换过程中可能出现的错误 `Size of permutation (0) is less than required (...)`。[#68681](https://github.com/ClickHouse/ClickHouse/pull/68681) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#68854](https://github.com/ClickHouse/ClickHouse/issues/68854) 中回移：修复了新 JSON column 可能触发的错误 `DB::Exception: Block structure mismatch in joined block stream: different columns:`。[#68686](https://github.com/ClickHouse/ClickHouse/pull/68686) ([Kruglov Pavel](https://github.com/Avogar)) 。
* 已在 [#68790](https://github.com/ClickHouse/ClickHouse/issues/68790) 中回移：修复了函数 `sipHash(64/128)Keyed` 在对以数组为键的 Map 进行哈希时，materialized 常量键处理不正确的问题。[#68731](https://github.com/ClickHouse/ClickHouse/pull/68731) ([Salvatore Mesoraca](https://github.com/aiven-sal)) 。
