<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#104164](https://github.com/ClickHouse/ClickHouse/issues/104164) 中回移：当缓存被禁用时，避免索引未压缩缓存带来的额外开销 (服务器设置 `index_uncompressed_cache_size = 0`，这也是默认值) 。[#104063](https://github.com/ClickHouse/ClickHouse/pull/104063) ([Michael Kolupaev](https://github.com/al13n321)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#104797](https://github.com/ClickHouse/ClickHouse/issues/104797) 中回移：修复 `dictGetOrDefault` 在键参数为 `Nullable` 时发生空指针解引用的问题。[#98460](https://github.com/ClickHouse/ClickHouse/pull/98460) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* 已在 [#104022](https://github.com/ClickHouse/ClickHouse/issues/104022) 中回移：修复向 JSON 列插入行时可能出现的异常：当该行引入了新的动态字段，同时还存在一个值不兼容的类型化字段，且该列随后被用作 GROUP BY 键时，就会触发该问题。[#100758](https://github.com/ClickHouse/ClickHouse/pull/100758) ([Jimmy Aguilar Mena](https://github.com/Ergus))。
* 已在 [#102430](https://github.com/ClickHouse/ClickHouse/issues/102430) 中回移：修复 S3 `Client::~Client` 析构函数中的异常逃逸导致 server 终止的问题。[#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey))。
* 已在 [#102447](https://github.com/ClickHouse/ClickHouse/issues/102447) 中回移：修复 coalescing merge tree 对数组类型的处理问题。此修复关闭了 [#89509](https://github.com/ClickHouse/ClickHouse/issues/89509)。[#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12))。
* 已在 [#104148](https://github.com/ClickHouse/ClickHouse/issues/104148) 中回移：在存在行策略/additional&#95;table&#95;filters 时禁用简单 LIMIT 优化 (以支持并行索引分析) 。[#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat))。
* 已在 [#104210](https://github.com/ClickHouse/ClickHouse/issues/104210) 中回移：不带 materialized views 的普通 INSERT 不再请求过多的 ConcurrencyControl slots 和线程 (使用 `max_threads` 而不是 `max_insert_threads`) ，从而避免在高 INSERT 吞吐量的 clusters 上出现 CC slot 饥饿和线程数暴涨的问题。[#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema))。
* 已在 [#104613](https://github.com/ClickHouse/ClickHouse/issues/104613) 中回移：修复 ClickHouse、MySQL、PostgreSQL 和 XDBC 字典源中的数据竞争问题，其中 `clone() const` 会读取，而 `isModified() const` 会写入同一个 `invalidate_query_response` 字符串。[#103277](https://github.com/ClickHouse/ClickHouse/pull/103277) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
* 已在 [#105212](https://github.com/ClickHouse/ClickHouse/issues/105212) 中回移：修复将 `AggregateFunction` 状态与整数相乘时出现的堆内存释放后使用问题 (例如 `quantilesExactState(...) * N`) 。平方求幂循环会将该状态与自身合并，而当聚合函数的 `merge` 会重新分配其内部存储时，这种行为是未定义的。关闭 STID 0988-40af。[#103536](https://github.com/ClickHouse/ClickHouse/pull/103536) ([Groene AI](https://github.com/groeneai))。
* 修复升级到 25.8.22 后，在 S3 disks 上通过 GCS 使用时出现的 `S3_ERROR: Response checksums mismatch` 问题 (原因是 `aws-sdk-cpp` 1.11.771 默认启用了 CRC32 灵活校验和，而 GCS 不支持该特性) 。[#103542](https://github.com/ClickHouse/ClickHouse/pull/103542) ([Eugene Klimov](https://github.com/Slach))。
* 已在 [#103752](https://github.com/ClickHouse/ClickHouse/issues/103752) 中回移：修复日志中嵌套 credentials 的脱敏问题。[#103552](https://github.com/ClickHouse/ClickHouse/pull/103552) ([Vitaly Baranov](https://github.com/vitlibar))。
* 已在 [#103793](https://github.com/ClickHouse/ClickHouse/issues/103793) 中回移：修复了解析带有双精度小数部分的 dateTime 时的未定义行为。[#103773](https://github.com/ClickHouse/ClickHouse/pull/103773) ([Yarik Briukhovetskyi](https://github.com/yariks5s)) 。
* 已在 [#105077](https://github.com/ClickHouse/ClickHouse/issues/105077) 中回移：修复了 `StorageKafka2` 中的释放后使用问题；当 Keeper 会话被替换、且消费者仍持有临时 topic 分区锁时，该问题可能导致服务器崩溃。[#103890](https://github.com/ClickHouse/ClickHouse/pull/103890) ([Groene AI](https://github.com/groeneai)) 。
* 已在 [#104189](https://github.com/ClickHouse/ClickHouse/issues/104189) 中回移：修复了反序列化 `quantileTiming` 状态时的越界写入问题。[#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#104775](https://github.com/ClickHouse/ClickHouse/issues/104775) 中回移：修复了解析 Postgres 数组时可能发生的下溢问题。[#104322](https://github.com/ClickHouse/ClickHouse/pull/104322) ([Grant Holly](https://github.com/grantholly-clickhouse)) 。
* 已在 [#105234](https://github.com/ClickHouse/ClickHouse/issues/105234) 中回移：修复了当向未配置 `<placement>` 的 Keeper 发送带有 `quorum_reads=true` 的 `get /keeper/availability_zone` 时，Keeper 会陷入终止与重启循环的问题。[#104663](https://github.com/ClickHouse/ClickHouse/pull/104663) ([myeongjun](https://github.com/myeongjjun)) 。
* 已在 [#104953](https://github.com/ClickHouse/ClickHouse/issues/104953) 中回移：修复了 `FutureSetFromTuple::buildOrderedSetInplace` 中会导致逻辑错误的 TOCTOU 数据竞争问题。[#104673](https://github.com/ClickHouse/ClickHouse/pull/104673) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)) 。
* 已在 [#104842](https://github.com/ClickHouse/ClickHouse/issues/104842) 中回移：修复了 `AvroConfluentRowInputFormat` 中因释放后使用缺陷导致的段错误。[#104751](https://github.com/ClickHouse/ClickHouse/pull/104751) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)) 。
