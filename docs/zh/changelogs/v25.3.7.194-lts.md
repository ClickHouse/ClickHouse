* 已在 [#84500](https://github.com/ClickHouse/ClickHouse/issues/84500) 中回移：Web UI 的两项小改进：- 正确处理无输出的查询，例如 `CREATE`、`INSERT` (直到最近，这类查询还会导致加载动画一直转圈) ；- 双击表时，滚动回顶部。[#81131](https://github.com/ClickHouse/ClickHouse/pull/81131) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#84031](https://github.com/ClickHouse/ClickHouse/issues/84031) 中回移：使用 cgroup 信息 (如果适用，即启用了 `memory_worker_use_cgroup` 且 cgroups 可用) 来修正内存跟踪器 (`memory_worker_correct_memory_tracker`) 。[#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)) 。

* 已在 [#85017](https://github.com/ClickHouse/ClickHouse/issues/85017) 中回移：在 Keeper 中添加 4LW `lgrq`，用于切换对已接收请求的日志记录。[#84719](https://github.com/ClickHouse/ClickHouse/pull/84719) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#84866](https://github.com/ClickHouse/ClickHouse/issues/84866) 中回移：减少 Keeper 中存储锁的争用。[#84732](https://github.com/ClickHouse/ClickHouse/pull/84732) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#85014](https://github.com/ClickHouse/ClickHouse/issues/85014) 中回移：使用 `keeper_server.coordination_settings.latest_logs_cache_entry_count_threshold` 和 `keeper_server.coordination_settings.commit_logs_cache_entry_count_threshold`，按条目数限制 Keeper 日志条目缓存的大小。[#84877](https://github.com/ClickHouse/ClickHouse/pull/84877) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#85731](https://github.com/ClickHouse/ClickHouse/issues/85731) 中回移：新增 `show_data_lake_catalogs_in_system_tables` 标志，用于控制是否在 `system.tables` 中添加数据湖表，解决了 [#85384](https://github.com/ClickHouse/ClickHouse/issues/85384)。[#85411](https://github.com/ClickHouse/ClickHouse/pull/85411) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)) 。
