  ### ClickHouse 发布 v25.8.16.34-lts (7938087aa80) FIXME，对比 v25.8.15.35-lts (7a0b36cf893)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#95144](https://github.com/ClickHouse/ClickHouse/issues/95144) 中回移：当脏页大小与 `max_server_memory_usage` 的比率超过 `memory_worker_purge_dirty_pages_threshold_ratio` 时，强制清理 jemalloc arenas。[#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)) 。
* 已在 [#94727](https://github.com/ClickHouse/ClickHouse/issues/94727) 中回移：为 S3 和 Azure Blob 存储的 BACKUP/RESTORE 添加对 SQL 定义的命名集合的支持。关闭 [#94604](https://github.com/ClickHouse/ClickHouse/issues/94604)。[#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已在 [#95165](https://github.com/ClickHouse/ClickHouse/issues/95165) 中回移：在独立于 MemoryWorker 主线程的其他线程中执行 jemalloc 脏页清理。如果清理速度过慢，可能会延迟 RSS 使用量更新，进而导致进程因内存不足而被杀死。引入新 config `memory_worker_purge_total_memory_threshold_ratio`，根据总内存使用量的比率启动脏页清理。[#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#95432](https://github.com/ClickHouse/ClickHouse/issues/95432) 中回移：现在 `view_duration_ms` 显示的是组处于活跃状态的时间，而不是其中各线程耗时的总和。[#94966](https://github.com/ClickHouse/ClickHouse/pull/94966) ([Sema Checherinda](https://github.com/CheSema)) 。
