  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已回移至 [#99158](https://github.com/ClickHouse/ClickHouse/issues/99158)：当某列的子列被其他列的 default/alias 表达式使用时，禁止删除该列，并在 `ALTER DROP COLUMN` 时对 default 表达式使用 analyzer。[#98569](https://github.com/ClickHouse/ClickHouse/pull/98569) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* 已回移至 [#100080](https://github.com/ClickHouse/ClickHouse/issues/100080)：修复在非 analyzer 情况下错误忽略 TABLE&#95;UUID&#95;MISMATCH 的问题。[#99380](https://github.com/ClickHouse/ClickHouse/pull/99380) ([Azat Khuzhin](https://github.com/azat))。
* 已回移至 [#100356](https://github.com/ClickHouse/ClickHouse/issues/100356)：修复 `toWeek()` 的错误分区裁剪问题；该问题会导致在按 `toYYYYMM(date)` 分区的表上，带有 `WHERE toWeek(date, mode) = N` 的查询在第 49-52 周返回空结果。[#99542](https://github.com/ClickHouse/ClickHouse/pull/99542) ([Takumi Hara](https://github.com/takumihara))。
* 已回移至 [#100168](https://github.com/ClickHouse/ClickHouse/issues/100168)：... [#100024](https://github.com/ClickHouse/ClickHouse/pull/100024) ([Shaohua Wang](https://github.com/tiandiwonder))。
* 已回移至 [#100265](https://github.com/ClickHouse/ClickHouse/issues/100265)：修复了在构建文本索引期间抛出 &quot;Memory Limit&quot; 异常时发生的罕见崩溃问题。[#100213](https://github.com/ClickHouse/ClickHouse/pull/100213) ([Anton Popov](https://github.com/CurtizJ))。
* 已回移至 [#100342](https://github.com/ClickHouse/ClickHouse/issues/100342)：修复了涉及 `Dynamic` 列、交叉连接和运行时过滤器的查询中的 `LOGICAL_ERROR` 异常。该问题是由于 `ColumnVariant::filter` 在 `hasOnlyNulls` 优化路径中共享 Variant 列指针而不是克隆它们所致。关闭 [https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147)。[#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar))。
* 已回移至 [#100594](https://github.com/ClickHouse/ClickHouse/issues/100594)：修复在 `optimize_on_insert=0` 时，向具有嵌套 `Array(JSON)` 列且使用 wide parts 的表中插入数据时出现的 LOGICAL&#95;ERROR 异常 &quot;Stream ... not found&quot;。[#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar))。
* 已回移至 [#100887](https://github.com/ClickHouse/ClickHouse/issues/100887)：验证 backup 元数据中的文件条目路径，以在 `RESTORE` 期间拒绝路径遍历、绝对路径和空名称。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos))。
* 已回移至 [#100725](https://github.com/ClickHouse/ClickHouse/issues/100725)：修复投影 SELECT 部分包含查询原始 SELECT 部分中不存在的列时出现的 NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK 问题。关闭 [#100194](https://github.com/ClickHouse/ClickHouse/issues/100194)。[#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* 已回移至 [#100918](https://github.com/ClickHouse/ClickHouse/issues/100918)：修复在包含 LowCardinality 元素的 Tuple 键上结合 PREWHERE/WHERE 使用 `has()` 函数时的服务器崩溃问题。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai))。
* 在 [#100868](https://github.com/ClickHouse/ClickHouse/issues/100868) 中回移：修复了 `If`、`Distinct`、`DistinctIf`、`IfState ` 这些聚合函数组合器在返回类型为 `Tuple` 且包含一个或多个 `Nullable` 参数时，在引入 `Nullable(Tuple)` 后无法读取旧序列化状态的问题。关闭 [#98917](https://github.com/ClickHouse/ClickHouse/issues/98917)。[#100826](https://github.com/ClickHouse/ClickHouse/pull/100826) ([Nihal Z. Miaji](https://github.com/nihalzp)).
