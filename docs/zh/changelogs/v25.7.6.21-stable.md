<div id="improvement">
  #### 改进
</div>

* 已在 [#86504](https://github.com/ClickHouse/ClickHouse/issues/86504) 中回移：新增了仅针对特定通道启用 JSON 日志的功能；为此，请将 `logger.formatting.channel` 设置为 `syslog`/`console`/`errorlog`/`log` 之一。[#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#86112](https://github.com/ClickHouse/ClickHouse/issues/86112) 中回移：将 `distributed_depth` 作为 *Cluster function 的判断依据是不正确的，并且可能导致数据重复；请改用 `client_info.collaborate_with_initiator`。 [#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#86266](https://github.com/ClickHouse/ClickHouse/issues/86266) 中回移：修复了在 `DatabaseReplicated` 中尝试执行 `CREATE ... AS (SELECT * FROM s3Cluster(...))` 时出现的逻辑错误。 [#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#86163](https://github.com/ClickHouse/ClickHouse/issues/86163) 中回移：现在，对于非 delta 表，unity catalog 会忽略包含异常 data types 的 schema。修复了 [#85699](https://github.com/ClickHouse/ClickHouse/issues/85699)。 [#85950](https://github.com/ClickHouse/ClickHouse/pull/85950) ([alesapin](https://github.com/alesapin)).
* 已在 [#86291](https://github.com/ClickHouse/ClickHouse/issues/86291) 中回移：如果表 (例如 `ReplacingMergeTree`) 是在设置 `index_granularity_bytes = 0` 的情况下创建的，则带有跳过索引的 `FINAL` 查询会抛出异常。该问题现已修复。 [#86147](https://github.com/ClickHouse/ClickHouse/pull/86147) ([Shankar Iyer](https://github.com/shankar-iyer)).
* 已在 [#86308](https://github.com/ClickHouse/ClickHouse/issues/86308) 中回移：修复了在一次 INSERT 中同时存在 const 和非常量块时发生的崩溃问题。 [#86230](https://github.com/ClickHouse/ClickHouse/pull/86230) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#86348](https://github.com/ClickHouse/ClickHouse/issues/86348) 中回移：修复了 ALTER UPDATE Nullable(JSON) 期间发生的崩溃问题。 [#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#86454](https://github.com/ClickHouse/ClickHouse/issues/86454) 中回移：修复了 materialized view 中的一个缺陷：如果某个 MV 被创建、删除后，又以相同名称重新创建，它可能无法正常工作。 [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 已在 [#86466](https://github.com/ClickHouse/ClickHouse/issues/86466) 中回移：修复了由 `Buffer` 表导致的 `MergesMutationsMemoryTracking` 泄漏问题，并修复了从 `Kafka` (及其他来源) 进行流式处理时的 `query_views_log` 问题。 [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
