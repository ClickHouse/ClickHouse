  ### ClickHouse 版本 v25.11.6.11-稳定版本 (90415175004) FIXME，与 v25.11.5.8-稳定版本 (06e6dea3bb5) 相比

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#92312](https://github.com/ClickHouse/ClickHouse/issues/92312) 中回移：Https://github.com/clickhouse/clickhouse/pull/84477 新增了对 `select` 查询的约束，这些查询可在 `insert select from s3cluster()` 查询中用于并行分布式执行。此更改允许使用 `where`，而此前也可以这样做。[#84611](https://github.com/ClickHouse/ClickHouse/pull/84611) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#93375](https://github.com/ClickHouse/ClickHouse/issues/93375) 中回移：当 Azure Blob 存储的原生复制因 BadRequest 失败时 (例如块列表无效) ，会回退到读写复制。此前仅在将 blob 复制到不同存储账户时遇到 Unauthorized 错误的情况下才会这样处理。但我们有时也会看到“The specified block list is invalid”错误。因此现在已更新条件：只要原生复制失败，都会回退到读写方式。[#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)) 。
* 已在 [#93336](https://github.com/ClickHouse/ClickHouse/issues/93336) 中回移：`flipCoordinates` 现已支持几何类型。[#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#93123](https://github.com/ClickHouse/ClickHouse/issues/93123) 中回移：重写了通配符授权检查中的错误逻辑。此前的尝试 [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) 修复了一个严重漏洞，但限制过于严格，导致某些通配符 `GRANT` 语句因无关的 REVOKE 操作而失败。[#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)) 。
* 已在 [#93222](https://github.com/ClickHouse/ClickHouse/issues/93222) 中回移：修复了在 JSON 中为路径 &#39;skip&#39; 创建类型提示时的问题。关闭 [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731)。[#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#93182](https://github.com/ClickHouse/ClickHouse/issues/93182) 中回移：修复了在通过 ALTER 将设置 `ratio_of_defaults_for_sparse_serialization` 改为 `1.0` 后，稀疏列变更之后可能出现的 FILE&#95;DOESNT&#95;EXIST 错误。[#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#93046](https://github.com/ClickHouse/ClickHouse/issues/93046) 中回移：修复了在 WHERE 中使用 `not materialize(...)` 或 `not CAST(...)` 时，数据跳过逻辑中的缺陷，该问题会导致结果错误。关闭 [#88536](https://github.com/ClickHouse/ClickHouse/issues/88536)。[#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)) 。
* 已在 [#93057](https://github.com/ClickHouse/ClickHouse/issues/93057) 中回移：修复了在预先取消分布式查询后，连接仍处于损坏状态的问题。[#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#93311](https://github.com/ClickHouse/ClickHouse/issues/93311) 中回移：在合并期间重建投影时移除未使用的列。这可降低内存使用，并减少临时 parts 的创建。[#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
