<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常表现)
</div>

* 已在 [#75642](https://github.com/ClickHouse/ClickHouse/issues/75642) 中回移：修复 docker 初始化脚本失败时的日志消息，使其更易理解。[#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* 已在 [#75118](https://github.com/ClickHouse/ClickHouse/issues/75118) 中回移：修复插入时间间隔时发生的崩溃 (问题 [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)) 。[#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* 已在 [#75305](https://github.com/ClickHouse/ClickHouse/issues/75305) 中回移：修复在 JSON 类型声明解析过程中，当类型名称不是大写时发生的崩溃。[#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#76228](https://github.com/ClickHouse/ClickHouse/issues/76228) 中回移：修复因 PSQL 复制中的未捕获异常导致的崩溃。[#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* 已在 [#76245](https://github.com/ClickHouse/ClickHouse/issues/76245) 中回移：Sasl 可能导致任意 rpc 调用失败；此修复可在 krb5 ticker 过期时重试调用。[#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* 已在 [#75403](https://github.com/ClickHouse/ClickHouse/issues/75403) 中回移：修复在启用设置 `optimize_function_to_subcolumns` 时，`Array`、`Map` 和 `Nullable(..)` 列对索引 (主索引和次级索引) 的使用问题。此前，这些列的索引可能会被忽略。[#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#76102](https://github.com/ClickHouse/ClickHouse/issues/76102) 中回移：修复 LowCardinality Nullable 数据类型的空值安全 JOIN 处理。此前，带空值安全比较的 JOIN ON (例如 `IS NOT DISTINCT FROM`、`<=>`、`a IS NULL AND b IS NULL OR a == b`) 在 LowCardinality 列上无法正确工作。[#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#75566](https://github.com/ClickHouse/ClickHouse/issues/75566) 中回移：Keeper 修复：回滚日志时避免写入损坏的更新日志。[#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#75742](https://github.com/ClickHouse/ClickHouse/issues/75742) 中回移：修复 protobuf schema cache 中可能发生的崩溃；该问题可能出现在以 Protobuf format 输出时，以及并行执行查询 `SYSTEM DROP FORMAT SCHEMA CACHE` 时。[#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#76094](https://github.com/ClickHouse/ClickHouse/issues/76094) 中回移：修复在分布式表上的 JOIN 中使用 Array 类型的 JSON 子列时，可能出现的错误 `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes`。[#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#75890](https://github.com/ClickHouse/ClickHouse/issues/75890) 中回移：修复在不同类型的列之间多次执行异步 `RENAME` 查询 (使用 `alter_sync = 0`) 后，从 `MergeTree` 表读取时偶发的崩溃。[#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#75831](https://github.com/ClickHouse/ClickHouse/issues/75831) 中回移：修复了 `DistinctSortedStreamTransform` 中的空指针解引用问题。[#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)) 。
* 已在 [#76215](https://github.com/ClickHouse/ClickHouse/issues/76215) 中回移：`clickhouse-library-bridge` 允许从 filesystem 打开任意库，因此只有在隔离环境中运行才是安全的。为防止其与 `clickhouse-server` 在相近环境中运行时产生漏洞，我们将把库的 path 限制在 configuration 中指定的位置。此漏洞由 **Arseniy Dugin** 通过 [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) 发现。[#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
