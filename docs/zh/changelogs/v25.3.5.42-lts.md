  ### ClickHouse 发行版 v25.3.5.42-lts (14e08ead34a) FIXME，相较于 v25.3.4.190-lts (93636ae3130)

<div id="improvement">
  #### 改进
</div>

* 已在 [#78853](https://github.com/ClickHouse/ClickHouse/issues/78853) 中回移：对于 StorageS3(Azure)Queue 推送到 materialized view 期间发生的错误，现在会遵循 `loading_retries` 的限制。此前，此类错误会无限重试。[#78313](https://github.com/ClickHouse/ClickHouse/pull/78313) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#82411](https://github.com/ClickHouse/ClickHouse/issues/82411) 中回移：哈希函数现已支持处理数组、Tuple 和 Map 中的 NULL 值。 (问题 [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) 和 [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)) 。[#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* 已在 [#81612](https://github.com/ClickHouse/ClickHouse/issues/81612) 中回移：使用 `orc` 2.1.2。[#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#81697](https://github.com/ClickHouse/ClickHouse/issues/81697) 中回移：使用 `grpc` 1.73.0。[#81629](https://github.com/ClickHouse/ClickHouse/pull/81629) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#82592](https://github.com/ClickHouse/ClickHouse/issues/82592) 中回移：Keeper 改进：新增配置 `keeper_server.cleanup_old_and_ignore_new_acl`。启用后，所有节点上的 ACL 都会被清除，同时新请求的 ACL 会被忽略。如果目标是彻底移除节点上的 ACL，务必保持该配置处于启用状态，直到创建新的 snapshot。[#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#82922](https://github.com/ClickHouse/ClickHouse/issues/82922) 中回移：Keeper 改进：支持为 world:anyone ACL 指定具体 permissions。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定发行版中用户可见的异常行为)
</div>

* 已在 [#82328](https://github.com/ClickHouse/ClickHouse/issues/82328) 中回移：修复左侧参数为 null 且子查询结果为非 Nullable 时，`transform_null_in=1` 的 `IN` 执行问题。[#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#82775](https://github.com/ClickHouse/ClickHouse/issues/82775) 中回移：修复当查询中仅使用常量别名列时的过滤器分析问题。修复了 [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448)。[#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#82548](https://github.com/ClickHouse/ClickHouse/issues/82548) 中回移：修复在 TTL 的 GROUP BY 和 SET 中使用同一列时出现的 LOGICAL&#95;ERROR 以及后续崩溃问题。[#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已在 [#82314](https://github.com/ClickHouse/ClickHouse/issues/82314) 中回移：修复在 `WHERE` 条件下配合 `IndexSet` 使用 `arrayJoin` 的查询中出现 `Not found column` 错误的问题。[#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#82557](https://github.com/ClickHouse/ClickHouse/issues/82557) 中回移：修复 server 在内存压力下执行远程查询时可能发生死锁的问题。[#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)) 。
* 已在 [#82519](https://github.com/ClickHouse/ClickHouse/issues/82519) 中回移：为 AWS ECS 标记添加过期时间，以便重新加载。[#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已在 [#82575](https://github.com/ClickHouse/ClickHouse/issues/82575) 中回移：修复在 logs/query&#95;log 中隐藏命名集合配置值的问题。关闭了 [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405)。[#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#82566](https://github.com/ClickHouse/ClickHouse/issues/82566) 中回移：修复终止会话时日志记录过程中可能发生崩溃的问题，因为 user&#95;id 有时可能为空。[#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)) 。
* 已在 [#82731](https://github.com/ClickHouse/ClickHouse/issues/82731) 中回移：Functions `trim{Left,Right,Both}` 现已支持类型为 &quot;FixedString(N)&quot; 的输入字符串。例如，`SELECT trimBoth(toFixedString('abc', 3), 'ac')` 现在可以正常工作。[#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)) 。
