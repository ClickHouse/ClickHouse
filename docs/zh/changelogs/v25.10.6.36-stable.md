  ### ClickHouse 发布版本 v25.10.6.36-稳定版本 (853dbd2ee0c) FIXME 与 v25.10.5.40-稳定版本 (93e6f3ffcbd) 相比

<div id="improvement">
  #### 改进
</div>

* 已在 [#94931](https://github.com/ClickHouse/ClickHouse/issues/94931) 中回移：当脏页大小与 `max_server_memory_usage` 的比率超过 `memory_worker_purge_dirty_pages_threshold_ratio` 时，强制执行 jemalloc arenas 清理。[#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)) 。
* 已在 [#94728](https://github.com/ClickHouse/ClickHouse/issues/94728) 中回移：为 S3 和 Azure Blob 存储中的 BACKUP/RESTORE 添加对通过 SQL 定义的命名集合的支持。关闭 [#94604](https://github.com/ClickHouse/ClickHouse/issues/94604)。[#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已在 [#94984](https://github.com/ClickHouse/ClickHouse/issues/94984) 中回移：确保调度器在 CPU 资源紧张时优先调度 MemoryWorker 线程，因为它能保护 ClickHouse 进程免受致命风险。[#94864](https://github.com/ClickHouse/ClickHouse/pull/94864) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。
* 已在 [#95141](https://github.com/ClickHouse/ClickHouse/issues/95141) 中回移：在不同于 MemoryWorker 主线程的另一个线程中执行 jemalloc 脏页清理。如果清理速度较慢，可能会延迟 RSS 使用量的更新，从而导致进程因内存不足而被杀死。新增配置项 `memory_worker_purge_total_memory_threshold_ratio`，根据总内存使用量的比率启动脏页清理。[#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#95434](https://github.com/ClickHouse/ClickHouse/issues/95434) 中回移：现在 `view_duration_ms` 显示的是组处于活动状态的时间，而不是其中各线程耗时的总和。[#94966](https://github.com/ClickHouse/ClickHouse/pull/94966) ([Sema Checherinda](https://github.com/CheSema)) 。

* 已在 [#95284](https://github.com/ClickHouse/ClickHouse/issues/95284) 中回移：修复了在使用 ON CLUSTER 时，CREATE USER 身份验证方法中的查询参数替换问题。身份验证方法中的查询参数 (例如密码) 没有被替换，导致远程节点上出现 UNKNOWN&#95;QUERY&#95;PARAMETER 错误。[#92777](https://github.com/ClickHouse/ClickHouse/pull/92777) ([xiaohuanlin](https://github.com/xiaohuanlin)) 。

* 已在 [#95528](https://github.com/ClickHouse/ClickHouse/issues/95528) 中回移：如果对同一批文件执行大量相互冲突的并发备份，可能会导致服务器崩溃。[#93659](https://github.com/ClickHouse/ClickHouse/pull/93659) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
