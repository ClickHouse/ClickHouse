<div id="improvement">
  #### 改进
</div>

* 已在 [#82503](https://github.com/ClickHouse/ClickHouse/issues/82503) 中回移：新增支持无需重启服务器即可动态重新加载 `max_local_read_bandwidth_for_server` 和 `max_local_write_bandwidth_for_server`。[#82083](https://github.com/ClickHouse/ClickHouse/pull/82083) ([Kai Zhu](https://github.com/nauu)) 。
* 已在 [#83012](https://github.com/ClickHouse/ClickHouse/issues/83012) 中回移：Keeper 改进：在后台线程中跨磁盘移动更新日志文件。此前，将更新日志移动到其他磁盘时，会一直全局阻塞 Keeper，直到移动完成。如果移动操作耗时较长 (例如移动到 S3 磁盘) ，会导致性能下降。[#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#82856](https://github.com/ClickHouse/ClickHouse/issues/82856) 中回移：在 [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 之后，`X-ClickHouse-Progress` 和 `X-ClickHouse-Summary` 请求头的格式被修改为省略零值。此 PR 旨在仅为 `X-ClickHouse-Summary` 恢复此前的行为，因为这样更合理。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#79891](https://github.com/ClickHouse/ClickHouse/issues/79891) 中回移：修复了某些情况下使用 analyzer 时未应用次级索引的问题。修复 [#65607](https://github.com/ClickHouse/ClickHouse/issues/65607)，修复 [#69373](https://github.com/ClickHouse/ClickHouse/issues/69373)。[#78485](https://github.com/ClickHouse/ClickHouse/pull/78485) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 已在 [#83254](https://github.com/ClickHouse/ClickHouse/issues/83254) 中回移：修复了外部表引擎中 cached buffer 禁用边界对齐失效的问题。该问题由 [https://github.com/ClickHouse/ClickHouse/pull/81868](https://github.com/ClickHouse/ClickHouse/pull/81868) 引入。[#82493](https://github.com/ClickHouse/ClickHouse/pull/82493) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 已在 [#82796](https://github.com/ClickHouse/ClickHouse/issues/82796) 中回移：修复了 `groupArraySample`/`groupArrayLast` 在元素为空时的反序列化问题 (如果输入为空，反序列化可能会跳过 binary 的一部分，从而导致读取数据时发生损坏，并在 TCP protocol 中出现 UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER) 。这不会影响数值和日期时间类型。[#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
* 已在 [#83108](https://github.com/ClickHouse/ClickHouse/issues/83108) 中回移：修复了 union/intersect/except&#95;default&#95;mode rewrite 中的异常安全问题。关闭 [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664)。[#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#82991](https://github.com/ClickHouse/ClickHouse/issues/82991) 中回移：使用非缓存型 Database 实现时，返回列后，对应表的 metadata 会被删除，引用也会失效。[#82939](https://github.com/ClickHouse/ClickHouse/pull/82939) ([buyval01](https://github.com/buyval01)).
* 已在 [#83023](https://github.com/ClickHouse/ClickHouse/issues/83023) 中回移：修复了对包含 JOIN expression 且其中一张表使用 `Merge` storage 的查询进行过滤器修改时的问题。修复 [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092)。[#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd)).
* 已在 [#83307](https://github.com/ClickHouse/ClickHouse/issues/83307) 中回移：修复了 QueryMetricLog 中的 LOGICAL&#95;ERROR：Mutex 不能为 NULL。[#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos)).
* 已在 [#83080](https://github.com/ClickHouse/ClickHouse/issues/83080) 中回移：修复了函数 `formatDateTime` 在将格式说明符 `%f` 与可变长度格式说明符 (如 `%M`) 一起使用时输出错误的问题。[#83020](https://github.com/ClickHouse/ClickHouse/pull/83020) ([Robert Schulze](https://github.com/rschu1ze)).
* 修复了 25.3 中的此问题 (对于 25.4+，该问题不再相关) [#82601](https://github.com/ClickHouse/ClickHouse/issues/82601)。[#83226](https://github.com/ClickHouse/ClickHouse/pull/83226) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* 已在 [#83402](https://github.com/ClickHouse/ClickHouse/issues/83402) 中回移：修复了 S3 client 的 `no_sign_request`。可用它来显式避免对 S3 requests 进行签名，也可以通过基于 endpoint 的 settings 为特定 endpoints 定义该项。[#83379](https://github.com/ClickHouse/ClickHouse/pull/83379) ([Antonio Andelic](https://github.com/antonio2368)).
* 已在 [#83464](https://github.com/ClickHouse/ClickHouse/issues/83464) 中回移：修复当 CTE 定义引用另一个同名表表达式时触发的 `TOO_DEEP_SUBQUERIES` 异常。[#83413](https://github.com/ClickHouse/ClickHouse/pull/83413) ([Dmitry Novik](https://github.com/novikd)) 。
* 已在 [#83668](https://github.com/ClickHouse/ClickHouse/issues/83668) 中回移：修复 max&#95;untracked&#95;memory 相关的内存处理错误。[#83607](https://github.com/ClickHouse/ClickHouse/pull/83607) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#83660](https://github.com/ClickHouse/ClickHouse/issues/83660) 中回移：在某些边缘情况下，带有 UNION ALL 的 INSERT SELECT 可能导致空指针解引用。此项关闭了 [#83618](https://github.com/ClickHouse/ClickHouse/issues/83618)。[#83643](https://github.com/ClickHouse/ClickHouse/pull/83643) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
