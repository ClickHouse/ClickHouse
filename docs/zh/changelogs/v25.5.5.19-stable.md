<div id="improvement">
  #### 改进
</div>

* 回移至 [#82594](https://github.com/ClickHouse/ClickHouse/issues/82594)：Keeper 改进：新增配置项 `keeper_server.cleanup_old_and_ignore_new_acl`。启用后，所有节点上的 ACL 都会被清除，同时会忽略新请求的 ACL。如果目标是彻底移除节点上的 ACL，则务必保持该配置项处于启用状态，直到创建新的快照。[#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* 回移至 [#82860](https://github.com/ClickHouse/ClickHouse/issues/82860)：在 [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 之后，`X-ClickHouse-Progress` 和 `X-ClickHouse-Summary` 请求头格式被修改为省略零值。此 PR 旨在仅将 `X-ClickHouse-Summary` 恢复为之前的行为，因为这样更合理。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 回移至 [#82926](https://github.com/ClickHouse/ClickHouse/issues/82926)：Keeper 改进：支持为 world:anyone ACL 设置特定权限。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 回移至 [#82779](https://github.com/ClickHouse/ClickHouse/issues/82779)：修复查询中仅使用常量别名列时的过滤器分析问题。修复了 [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448)。[#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd))。
* 回移至 [#82559](https://github.com/ClickHouse/ClickHouse/issues/82559)：修复 server 在内存压力下执行远程查询时可能发生的死锁问题。[#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar))。
* 回移至 [#82688](https://github.com/ClickHouse/ClickHouse/issues/82688)：修复对关联列进行 ROW POLICY 表达式分析期间出现的 `LOGICAL_ERROR`。[#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd))。
* 回移至 [#82735](https://github.com/ClickHouse/ClickHouse/issues/82735)：函数 `trim{Left,Right,Both}` 现已支持 &quot;FixedString(N)&quot; 类型的输入字符串。例如，`SELECT trimBoth(toFixedString('abc', 3), 'ac')` 现在已可正常运行。[#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze))。
* 回移至 [#82800](https://github.com/ClickHouse/ClickHouse/issues/82800)：修复 `groupArraySample`/`groupArrayLast` 在元素为空时的反序列化问题 (如果输入为空，反序列化可能会跳过部分二进制内容，从而导致读取数据时发生损坏，并在 TCP protocol 中出现 UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER) 。这不影响数值和日期时间类型。[#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim))。
