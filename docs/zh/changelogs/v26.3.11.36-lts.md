  ### ClickHouse 发布版本 v26.3.11.36-lts (fa3aa24e791) FIXME，相比 v26.3.10.62-lts (e1c11930c28)
</div>

<div id="improvement">
  #### 改进
</div>

* 已在 [#104034](https://github.com/ClickHouse/ClickHouse/issues/104034) 中回移：当行策略仅依赖排序键列且具有确定性时，跳过将该行策略延后到 `FINAL` 之后执行，并跳过在这种情况下由该行策略强制触发的相应 `PREWHERE` 延后。 [#102884](https://github.com/ClickHouse/ClickHouse/pull/102884) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 已在 [#104384](https://github.com/ClickHouse/ClickHouse/issues/104384) 中回移：在可刷新 materialized view 持续刷新的情况下，基于快照表的状态而非全局状态进行决策，从而提升 backups 的稳健性。 [#103384](https://github.com/ClickHouse/ClickHouse/pull/103384) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* 已在 [#104702](https://github.com/ClickHouse/ClickHouse/issues/104702) 中回移：修复 &#96;lowerUTF8&#96; / &#96;upperUTF8&#96; 在处理大型非 ASCII 数据集 (例如构建文本索引期间) 时，由于累计输出缓冲区超过 2 GiB 而抛出异常的问题；对于过长的单行数据，会返回明确的错误。 [#104229](https://github.com/ClickHouse/ClickHouse/pull/104229) ([Shaohua Wang](https://github.com/tiandiwonder)).
* 已在 [#105063](https://github.com/ClickHouse/ClickHouse/issues/105063) 中回移：新增设置 `defer_partition_pruning_after_final` (默认值为 `1`) ，使 26.3 引入的在 `FINAL` 下跳过分区裁剪的行为可选择关闭。将其设为 `0` 可恢复 26.3 之前的分区裁剪行为——对于相同 PK 的行不会跨分区的事件日志工作负载，速度会显著更快。`compatibility = '26.2'` 会自动将其切换为 `0`。 [#104705](https://github.com/ClickHouse/ClickHouse/pull/104705) ([Nikita Fomichev](https://github.com/fm4v)).

* 已在 [#104471](https://github.com/ClickHouse/ClickHouse/issues/104471) 中回移：修复当带有 `IN (subquery)` 的过滤器被 query optimizer 移至 PREWHERE 时出现的 “Not-ready Set” 异常。 [#100375](https://github.com/ClickHouse/ClickHouse/pull/100375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#104026](https://github.com/ClickHouse/ClickHouse/issues/104026) 中回移：修复向 JSON column 插入行时可能发生的异常：该行在带有不兼容值的类型化字段旁引入了一个新的动态字段，且随后该列被用作 GROUP BY 键。 [#100758](https://github.com/ClickHouse/ClickHouse/pull/100758) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* 已在 [#104406](https://github.com/ClickHouse/ClickHouse/issues/104406) 中回移：修复由于 join 重排序将 INNER JOIN 过滤器 (仅引用外连接中保留的一侧) 推入外连接的 ON 子句而导致的错误查询结果。 [#101504](https://github.com/ClickHouse/ClickHouse/pull/101504) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#105364](https://github.com/ClickHouse/ClickHouse/issues/105364) 中回移：修复 RIGHT ANY JOIN 在 right table 的每个键对应多行且输出块因大小限制被拆分时产生的错误结果。关闭 [#99431](https://github.com/ClickHouse/ClickHouse/issues/99431)。 [#102064](https://github.com/ClickHouse/ClickHouse/pull/102064) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#103343](https://github.com/ClickHouse/ClickHouse/issues/103343) 中回移：修复在 in-memory database (例如 temporary tables) 中的表上执行 ALTER 查询时可能发生的崩溃。 [#102360](https://github.com/ClickHouse/ClickHouse/pull/102360) ([Den Kalantaevskii](https://github.com/Diskein)).
* 已在 [#105379](https://github.com/ClickHouse/ClickHouse/issues/105379) 中回移：在 Avro 读取器进行 nested types deserialization 期间检查 stack overflow。 [#102417](https://github.com/ClickHouse/ClickHouse/pull/102417) ([Pavel Kruglov](https://github.com/Avogar)).
* 已在 [#105611](https://github.com/ClickHouse/ClickHouse/issues/105611) 中回移：修复向后兼容性被破坏的问题：旧 clients 通过 `remote()` 或分布式表向较新的 server 插入数据时，会因 `processInsertQuery` 末尾无条件执行 `sendProgress` 而报错 `UNEXPECTED_PACKET_FROM_SERVER`。 [#103148](https://github.com/ClickHouse/ClickHouse/pull/103148) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#104618](https://github.com/ClickHouse/ClickHouse/issues/104618) 中回移：修复 ClickHouse、MySQL、PostgreSQL 和 XDBC 字典源中的 data race，其中 `clone() const` 会读取、而 `isModified() const` 会写入同一个 `invalidate_query_response` 字符串。 [#103277](https://github.com/ClickHouse/ClickHouse/pull/103277) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 已在 [#105216](https://github.com/ClickHouse/ClickHouse/issues/105216) 中回移：修复将 `AggregateFunction` 状态与整数相乘时的 heap-use-after-free 问题 (例如 `quantilesExactState(...) * N`) 。平方求幂循环会将该状态与其自身 merge，而当 aggregate function 的 `merge` 会重新分配其内部存储时，这属于未定义行为。关闭 STID 0988-40af。 [#103536](https://github.com/ClickHouse/ClickHouse/pull/103536) ([Groene AI](https://github.com/groeneai)).
* 已在 [#104365](https://github.com/ClickHouse/ClickHouse/issues/104365) 中回移：修复了一个问题：对于表达式中包含捕获常量的 lambda 的 `ALIAS` 列 (例如 `arrayMap((k, v) -> concat(k, '=', v), mapKeys(m), mapValues(m)))`) ，其文本和 bloom filter 跳过索引此前会被静默忽略。[#103708](https://github.com/ClickHouse/ClickHouse/pull/103708) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#103902](https://github.com/ClickHouse/ClickHouse/issues/103902) 中回移：修复了包含 JSON column 的表在数据分区片段检查和一致性检查中的问题。此前这可能导致文件缺失的误报。[#103858](https://github.com/ClickHouse/ClickHouse/pull/103858) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#105081](https://github.com/ClickHouse/ClickHouse/issues/105081) 中回移：修复了 `StorageKafka2` 中的 use-after-free 问题：当消费者持有临时 topic-partition 锁时，如果 Keeper session 被替换，可能导致 server 崩溃。[#103890](https://github.com/ClickHouse/ClickHouse/pull/103890) ([Groene AI](https://github.com/groeneai)) 。
* 已在 [#105185](https://github.com/ClickHouse/ClickHouse/issues/105185) 中回移：修复了 PostgreSQL、Cassandra 和 XDBC 字典源中的 SQL injection 漏洞：此前，包含 single quotes 的字符串键会使用 `\'` (backslash) 进行转义，但这些后端会将其视为字面反斜杠，而不是转义序列，从而允许将任意 SQL 注入字典 lookup 查询。`ExternalQueryBuilder` 现在会针对这些后端生成符合 SQL 标准的 `''` escaping；ClickHouse 和 MySQL 字典源则继续使用 backslash escaping。[#104009](https://github.com/ClickHouse/ClickHouse/pull/104009) ([Shaohua Wang](https://github.com/tiandiwonder)) 。
* 已在 [#104340](https://github.com/ClickHouse/ClickHouse/issues/104340) 中回移：修复了设置 `optimize_inverse_dictionary_lookup` 时若干边界场景下的正确性问题；在这些情况下，该优化可能会静默丢弃行或抑制异常。关闭 [#103270](https://github.com/ClickHouse/ClickHouse/issues/103270)。关闭 [#103085](https://github.com/ClickHouse/ClickHouse/issues/103085)。[#104133](https://github.com/ClickHouse/ClickHouse/pull/104133) ([Nihal Z.
