<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#102453](https://github.com/ClickHouse/ClickHouse/issues/102453) 中回移：修复了 Coalescing merge tree 对 Array 类型的处理问题。此更改关闭了 [#89509](https://github.com/ClickHouse/ClickHouse/issues/89509)。[#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12)) 。
* 已在 [#102479](https://github.com/ClickHouse/ClickHouse/issues/102479) 中回移：修复了字符串搜索函数 (`countSubstrings`、`position` 等) 在搜索完全由 null 字节组成的 needle 时发生的越界读取问题。[#102401](https://github.com/ClickHouse/ClickHouse/pull/102401) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#102456](https://github.com/ClickHouse/ClickHouse/issues/102456) 中回移：当 `compatibility` 设置为低于 26.1 的版本时，全文索引设置 (`enable_full_text_index`、`allow_experimental_full_text_index`、`use_skip_indexes_on_data_read`) 将不再被禁用。此前，这可能导致 `SharedDatabaseCatalog` 无法创建带有全文索引的表。[#102422](https://github.com/ClickHouse/ClickHouse/pull/102422) ([Nikita Fomichev](https://github.com/fm4v)) 。
