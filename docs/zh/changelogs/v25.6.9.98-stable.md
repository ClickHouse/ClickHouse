<div id="improvement">
  #### 改进
</div>

* 已在 [#86063](https://github.com/ClickHouse/ClickHouse/issues/86063) 中回移：由临时用户创建的视图现在会保存一份真实用户副本，因此在临时用户被删除后不再失效。[#84763](https://github.com/ClickHouse/ClickHouse/pull/84763) ([pufit](https://github.com/pufit)) 。
* 已在 [#85728](https://github.com/ClickHouse/ClickHouse/issues/85728) 中回移：新增 `show_data_lake_catalogs_in_system_tables` 标志，用于控制是否将数据湖表加入 `system.tables`，解决了 [#85384](https://github.com/ClickHouse/ClickHouse/issues/85384)。[#85411](https://github.com/ClickHouse/ClickHouse/pull/85411) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)) 。
* 已在 [#86251](https://github.com/ClickHouse/ClickHouse/issues/86251) 中回移：在 S3 对象存储中遇到可重试错误时，对 S3 客户端线程进行降速。此更改将之前的设置 `backup_slow_all_threads_after_retryable_s3_error` 扩展到 S3 磁盘，并将其重命名为更通用的 `s3_slow_all_threads_after_retryable_error`。[#85918](https://github.com/ClickHouse/ClickHouse/pull/85918) ([Julia Kartseva](https://github.com/jkartseva)) 。
* 已在 [#86503](https://github.com/ClickHouse/ClickHouse/issues/86503) 中回移：新增仅对特定通道启用 JSON 日志的能力；为此，请将 `logger.formatting.channel` 设置为 `syslog`/`console`/`errorlog`/`log` 之一。[#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)) 。
