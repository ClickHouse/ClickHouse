<div id="new-feature">

* 为 `clickhouse-server` 和 `clickhouse-keeper` 新增 distroless Docker 镜像变体，标签为 `<version>-distroless`。[#101426](https://github.com/ClickHouse/ClickHouse/pull/101426) ([Rahul Nair](https://github.com/motsc)).

<div id="improvement">
  #### 改进
</div>

* 已在 [#102323](https://github.com/ClickHouse/ClickHouse/issues/102323) 中回移：在嵌入式客户端 (SSH 和 WebSocket 协议) 中禁用 AI SQL generation (`??` 命令) ，以防止访问服务器环境变量。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#101597](https://github.com/ClickHouse/ClickHouse/issues/101597) 中回移：Cgroupv2 内存跟踪现在会将 `slab_reclaimable` 排除在内核内存统计之外，从而能更准确地衡量不可回收的内存使用量。[#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#102134](https://github.com/ClickHouse/ClickHouse/issues/102134) 中回移：将内部 mongo-c-driver 从 2.2.2 升级到 2.2.3。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#101929](https://github.com/ClickHouse/ClickHouse/issues/101929) 中回移：将 libarchive 从 3.8.5 升级到 3.8.6。[#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)) 。
* 已在 [#101864](https://github.com/ClickHouse/ClickHouse/issues/101864) 中回移：将 curl 从 8.18 升级到 8.19。[#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#92409](https://github.com/ClickHouse/ClickHouse/issues/92409) 中回移：修复了谓词包含 `NULL` 常量时，`Set` 索引分析过程中发生的 `Bad get` 错误。修复 [#84856](https://github.com/ClickHouse/ClickHouse/issues/84856) 和 [#82974](https://github.com/ClickHouse/ClickHouse/issues/82974)。[#89429](https://github.com/ClickHouse/ClickHouse/pull/89429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* 已在 [#94969](https://github.com/ClickHouse/ClickHouse/issues/94969) 中回移：在另一个当前正在使用的 workload 中创建 workload 不再导致崩溃。[#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)) 。
* 已在 [#96287](https://github.com/ClickHouse/ClickHouse/issues/96287) 中回移：修复了 CTE 折叠常量的查询条件缓存哈希冲突问题，该问题可能导致错误的查询结果。关闭 [#96060](https://github.com/ClickHouse/ClickHouse/issues/96060)。[#96172](https://github.com/ClickHouse/ClickHouse/pull/96172) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#102653](https://github.com/ClickHouse/ClickHouse/issues/102653) 中回移：修复了 `ASTColumnsExceptTransformer::transform` 中的 LOGICAL&#95;ERROR 异常。[#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已回移到 [#100487](https://github.com/ClickHouse/ClickHouse/issues/100487)：JDBC、ODBC 和 NATS 连接字符串中的凭据现在会在查询日志和 `SHOW CREATE` 输出中进行掩码处理，从而防止敏感信息意外泄露。对于 URI 风格的连接字符串 (例如 {scheme}://{user}:{password}@{host}) ，仅对密码部分进行掩码处理，其余部分保持可见，以便更方便地进行调试。`nats_token` 设置现在也会进行掩码处理。[#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)) 。
* 已回移至 [#101470](https://github.com/ClickHouse/ClickHouse/issues/101470)：修复了 Keeper 中的一个 bug：如果同一服务器上的另一个无关会话恰好在错误的时机被关闭，某个读取请求可能会卡住 (导致会话超时) 。[#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)) 。
* 已回移至 [#99963](https://github.com/ClickHouse/ClickHouse/issues/99963)：修复 analyzer 的性能下降问题，并从 ARRAY JOIN 中裁剪未使用的列。[#99587](https://github.com/ClickHouse/ClickHouse/pull/99587) ([Dmitry Novik](https://github.com/novikd)) 。
* 已回移至 [#100338](https://github.com/ClickHouse/ClickHouse/issues/100338)：修复了涉及 `Dynamic` 列、CROSS JOIN 和运行时过滤器的查询中出现的 `LOGICAL_ERROR` 异常；该问题是由于 `ColumnVariant::filter` 在 `hasOnlyNulls` 优化路径中共享 Variant 列指针，而不是克隆它们所致。关闭 [https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147)。[#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已回移至 [#100885](https://github.com/ClickHouse/ClickHouse/issues/100885)：校验备份元数据中的文件条目 path，在 `RESTORE` 期间拒绝路径遍历、绝对路径和空名称。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)) 。
* 已回移至 [#100916](https://github.com/ClickHouse/ClickHouse/issues/100916)：修复在包含 LowCardinality 元素的 Tuple 键上结合 PREWHERE/WHERE 使用 `has()` 函数时导致的 server 崩溃。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)) 。
* 已回移至 [#101528](https://github.com/ClickHouse/ClickHouse/issues/101528)：某些目录可能会在 `select * from system.databases` 查询结果的 `SETTINGS` 部分暴露部分敏感信息。此 PR 可防止此类行为。[#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)) 。
* 已回移至 [#102619](https://github.com/ClickHouse/ClickHouse/issues/102619)：修复了 s3Cluster 和分布式查询中的段错误，该问题由连接池释放后继续使用引起。[#100837](https://github.com/ClickHouse/ClickHouse/pull/100837) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已回移至 [#101085](https://github.com/ClickHouse/ClickHouse/issues/101085)：修复 `ULIDStringToDateTime` 在输入包含非 ASCII 字节时的缓冲区溢出问题。[#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* 已回移至 [#101926](https://github.com/ClickHouse/ClickHouse/issues/101926)：修复 parseDateTimeBestEffort 在解析小数秒位数超过 18 位的日期时间字符串时出现的未定义行为 (有符号整数溢出) 。[#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)) 。
* 已回移至 [#102675](https://github.com/ClickHouse/ClickHouse/issues/102675)：修复 CPU lease scheduler 中因释放后继续使用而导致的崩溃；当等待计时器的生命周期长于其所引用 `ProfileEvents::Counters` 的工作线程时，就会触发该问题。[#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已回移至 [#102069](https://github.com/ClickHouse/ClickHouse/issues/102069)：修复 `Object` 类型动态 path 并行反序列化中的 use-after-scope 问题；读取包含大量动态 path 的表时，此问题可能导致崩溃。[#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)) 。
