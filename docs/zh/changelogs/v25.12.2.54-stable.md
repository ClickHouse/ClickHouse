<div id="backward-incompatible-change">
  #### 不兼容变更
</div>

* 已在 [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224) 中回移：默认为 JSON 启用高级 shared data。此变更后，将无法降级至 25.8 以下版本，因为这些版本无法读取含有 JSON 列的新数据分区片段。为确保安全升级，建议将 `compatibility` 设置为先前版本，或将 MergeTree settings 设置为 `dynamic_serialization_version='v2', object_serialization_version='v2'`。[#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar))。
* 已在 [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061) 中回移：回退"允许 INSERT 到简单 ALIAS 列"（回退 ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154)）。该功能与自定义 formats 不兼容，且未通过 setting 加以保护。[#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat))。

<div id="performance-improvement">
  #### 性能提升
</div>

* 已在 [#92711](https://github.com/ClickHouse/ClickHouse/issues/92711) 中回移：优化 distinctJSONPaths 聚合函数，使其仅从数据分区片段中读取 JSON paths，而非读取整个 JSON 列。[#92196](https://github.com/ClickHouse/ClickHouse/pull/92196) ([Pavel Kruglov](https://github.com/Avogar))。

* 已在 [#92604](https://github.com/ClickHouse/ClickHouse/issues/92604) 中回移：在 system.data_skipping_indices 中新增创建方式（隐式/显式）列。[#92378](https://github.com/ClickHouse/ClickHouse/pull/92378) ([Raúl Marín](https://github.com/Algunenano))。
* 已在 [#93377](https://github.com/ClickHouse/ClickHouse/issues/93377) 中回移：当 Azure Blob 存储的原生复制因 BadRequest 失败时（例如无效的块列表），回退至读写复制模式。此前仅在将 blob 复制到不同 storage account 时遇到 Unauthorized 错误才会触发此回退。由于有时也会出现"指定的块列表无效"错误，现已将触发条件更新为所有原生复制失败时均回退至读写模式。[#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni))。

* 已在 [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338) 中回移：为 `flipCoordinates` 添加 geometry type 支持。[#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc))。
