  ### ClickHouse 版本 v25.6.4.12-稳定版本 (c3c91c0239e) FIXME，较 v25.6.3.116-稳定版本 (3c68d19c3b3)

<div id="improvement">
  #### 改进
</div>

* 已在 [#83635](https://github.com/ClickHouse/ClickHouse/issues/83635) 中回移：当 `distributed_ddl_output_mode='*_only_active'` 时，不再等待复制延迟大于 `max_replication_lag_to_enqueue` 的新副本或已恢复的副本。这有助于避免出现 `DDL task is not finished on some hosts`：例如某个新副本在完成初始化或恢复后变为活跃状态，但它在初始化期间已经积累了大量复制日志。此外，还实现了 `SYSTEM SYNC DATABASE REPLICA STRICT` 查询，用于等待复制日志降到 `max_replication_lag_to_enqueue` 以下。[#83302](https://github.com/ClickHouse/ClickHouse/pull/83302) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#83556](https://github.com/ClickHouse/ClickHouse/issues/83556) 回移：对 Iceberg array 元素和 Iceberg map 值 (包括其所有嵌套子字段) 禁用基于边界的文件裁剪。[#83520](https://github.com/ClickHouse/ClickHouse/pull/83520) ([Daniil Ivanik](https://github.com/divanik)) 。
* 已在 [#83674](https://github.com/ClickHouse/ClickHouse/issues/83674) 回移：修复 `max_untracked_memory` 相关的内存处理错误。[#83607](https://github.com/ClickHouse/ClickHouse/pull/83607) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#83663](https://github.com/ClickHouse/ClickHouse/issues/83663) 回移：在某些边缘情况下，`INSERT SELECT` 配合 `UNION ALL` 可能导致空指针解引用。此项修复关闭了 [#83618](https://github.com/ClickHouse/ClickHouse/issues/83618)。[#83643](https://github.com/ClickHouse/ClickHouse/pull/83643) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#83745](https://github.com/ClickHouse/ClickHouse/issues/83745) 回移：修复 `estimateCompressionRatio()` 在 `block_size_bytes=0` 时会陷入死循环的问题。[#83704](https://github.com/ClickHouse/ClickHouse/pull/83704) ([Azat Khuzhin](https://github.com/azat)) 。
