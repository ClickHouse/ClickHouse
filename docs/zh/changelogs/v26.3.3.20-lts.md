<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#101224](https://github.com/ClickHouse/ClickHouse/issues/101224) 中回移：修复异步插入查询在 `query_log` 和客户端输出中将 `written_rows`、`read_rows` 和 `result_rows` 显示为 0 的问题。[#99879](https://github.com/ClickHouse/ClickHouse/pull/99879) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#100891](https://github.com/ClickHouse/ClickHouse/issues/100891) 中回移：校验备份元数据中的文件条目路径，在 `RESTORE` 过程中拒绝路径遍历、绝对路径和空名称。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* 已在 [#101394](https://github.com/ClickHouse/ClickHouse/issues/101394) 中回移：修复在异步插入 (TCP) 以及通过 HTTP 执行的所有插入中解析 `DateTime` 值时忽略 `session_timezone` 的问题。[#100647](https://github.com/ClickHouse/ClickHouse/pull/100647) ([Sema Checherinda](https://github.com/CheSema)).
* 已在 [#100922](https://github.com/ClickHouse/ClickHouse/issues/100922) 中回移：修复在包含 LowCardinality 元素的 Tuple 键上结合 PREWHERE/WHERE 使用 `has()` 函数时导致服务器崩溃的问题。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* 已在 [#101187](https://github.com/ClickHouse/ClickHouse/issues/101187) 中回移：修复服务器关闭期间加载字典时因空指针解引用导致的 segfault。字典线程会并发调用 `Context::getUserDefinedSQLObjectsStorage` (会解引用 `user_defined_sql_objects_storage`) ，而主线程会调用 `Context::shutdown` (将 `user_defined_sql_objects_storage` 设为 null) 。我们需要确保在执行 `Context::shutdown` 之前，先在字典加载器中禁用后续更新，终止当前正在运行的字典查询，并等待字典加载线程结束。这与普通查询的处理方式类似。[#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* 已在 [#101091](https://github.com/ClickHouse/ClickHouse/issues/101091) 中回移：修复当输入包含非 ASCII 字节时，`ULIDStringToDateTime` 中的缓冲区溢出问题。[#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 已在 [#101015](https://github.com/ClickHouse/ClickHouse/issues/101015) 中回移：修复 `intDiv`/`intDivOrZero` 在 Nullable Tuple 数组上抛出异常的问题，例如 `SELECT intDiv([divide((1, 2), ... AND NULL)], 2)`。[#100895](https://github.com/ClickHouse/ClickHouse/pull/100895) ([Raúl Marín](https://github.com/Algunenano)).
* 已在 [#101250](https://github.com/ClickHouse/ClickHouse/issues/101250) 中回移：在存储定义之前先对 `StorageAlias` 的引擎参数求值，以便将 `currentDatabase()` 这类表达式在保存到数据库前解析为字面量。[#100902](https://github.com/ClickHouse/ClickHouse/pull/100902) ([Nikolay Degterinsky](https://github.com/evillique)).
* 已在 [#101140](https://github.com/ClickHouse/ClickHouse/issues/101140) 中回移：修复使用包含 Tuple 子查询的 `IN` 子句时文本搜索索引发生崩溃的问题，例如 `WHERE (id, str) IN (SELECT (id, str) FROM ...)`；当子查询中的列数与 `IN` 左侧的 Tuple 不匹配时，也会发生该问题。[#100959](https://github.com/ClickHouse/ClickHouse/pull/100959) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#101080](https://github.com/ClickHouse/ClickHouse/issues/101080) 中回移：修复 `sumCountOrDefault` 聚合函数在带有一个或多个 `Nullable` 参数时，在引入 `Nullable(Tuple)` 后无法读取旧版已序列化状态的问题。关闭 [#100882](https://github.com/ClickHouse/ClickHouse/issues/100882)。[#101021](https://github.com/ClickHouse/ClickHouse/pull/101021) ([Nihal Z. Miaji](https://github.com/nihalzp)) 。
* 已在 [#101169](https://github.com/ClickHouse/ClickHouse/issues/101169) 中回移：修复使用带 PREWHERE 的投影并结合 `ORDER BY ... LIMIT` 时，`optimizeLazyMaterialization` 中出现异常的问题。[#101115](https://github.com/ClickHouse/ClickHouse/pull/101115) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#101349](https://github.com/ClickHouse/ClickHouse/issues/101349) 中回移：修复一种情况：远程对象在 `list` 和 `read` 之间被覆盖，之前会导致对象 metadata 过期，进而在 cache 中触发 `Having zero bytes, ...` 逻辑错误。[#101219](https://github.com/ClickHouse/ClickHouse/pull/101219) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
