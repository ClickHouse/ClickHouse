<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### 缺陷修复 (官方稳定版本中用户可见的异常行为)
</div>

* 已在 [#95286](https://github.com/ClickHouse/ClickHouse/issues/95286) 中回移：修复在使用 ON CLUSTER 时，CREATE USER 的身份验证方法中查询参数替换失效的问题。身份验证方法中的查询参数 (例如密码) 此前不会被替换，导致远程节点上出现 UNKNOWN&#95;QUERY&#95;PARAMETER 错误。[#92777](https://github.com/ClickHouse/ClickHouse/pull/92777) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* 已在 [#95529](https://github.com/ClickHouse/ClickHouse/issues/95529) 中回移：当大量并发备份同时争用相同文件时，备份可能导致服务器崩溃。[#93659](https://github.com/ClickHouse/ClickHouse/pull/93659) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 已在 [#94973](https://github.com/ClickHouse/ClickHouse/issues/94973) 中回移：在当前正在使用的另一个工作负载中创建工作负载，不再会导致崩溃。[#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)).
* 已在 [#95642](https://github.com/ClickHouse/ClickHouse/issues/95642) 中回移：修复涉及 `toWeek`、`toYearWeek`、`toStartOfWeek`、`toLastDayOfWeek` 和 `toDayOfWeek` 的谓词在主键和跳过索引裁剪中的错误，并修复其中部分函数在针对 `LowCardinality(String)` 的有效查询上抛出异常的问题。[#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* 已在 [#95629](https://github.com/ClickHouse/ClickHouse/issues/95629) 中回移：修复 `ReplicatedMergeTree` 启动期间因并发删除 `delete_tmp_*` 目录而引发的崩溃问题。[#94892](https://github.com/ClickHouse/ClickHouse/pull/94892) ([myeongjun](https://github.com/myeongjjun)).
* 已在 [#95815](https://github.com/ClickHouse/ClickHouse/issues/95815) 中回移：修复在使用多个 JOIN 且配合 `USING` 子句时，对源表限定列的类型推断问题。此前，后续 JOIN 会错误地将底层源列的类型更新为共同超类型，即使该列并未参与该次 JOIN (例如，在 `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` 中，`t2.a` 列只用于第一个 JOIN，因此其类型应为 `t1.a` 和 `t2.a` 的共同超类型，而不应包含 `t3.a`) 。当函数期望的列类型与执行计划中实际出现的类型不一致时，这可能会导致逻辑错误或崩溃。[#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* 已在 [#95425](https://github.com/ClickHouse/ClickHouse/issues/95425) 中回移：在获取 manifest .avro 列表和文件内容时，只进行一次列转换。[#95164](https://github.com/ClickHouse/ClickHouse/pull/95164) ([Daniil Ivanik](https://github.com/divanik)).
* 已在 [#95382](https://github.com/ClickHouse/ClickHouse/issues/95382) 中回移：修复轻量级更新后应用大型补丁分区片段时内存统计不准确的问题。此前，应用大型补丁可能导致内存占用过高，并最终使服务器进程被 OOM Killer 杀死。[#95231](https://github.com/ClickHouse/ClickHouse/pull/95231) ([Anton Popov](https://github.com/CurtizJ)).
* 已在 [#95572](https://github.com/ClickHouse/ClickHouse/issues/95572) 中回移：`redis` 表函数的 password 参数现在会在日志和系统表中 (例如 `query_log`) 被脱敏。[#95325](https://github.com/ClickHouse/ClickHouse/pull/95325) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 已在 [#96392](https://github.com/ClickHouse/ClickHouse/issues/96392) 中回移：修复了在分布式查询中使用负数 `LIMIT/OFFSET` 时，某些情况下会出现的逻辑错误。[#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)) 。
* 已在 [#95606](https://github.com/ClickHouse/ClickHouse/issues/95606) 中回移：避免了分布式查询在取消时可能发生的崩溃。[#95466](https://github.com/ClickHouse/ClickHouse/pull/95466) ([Aleksandr Musorin](https://github.com/AVMusorin)) 。
* 已在 [#95546](https://github.com/ClickHouse/ClickHouse/issues/95546) 中回移：修复了 plain&#95;rewritable 上加密磁盘的检查问题 (修复了可能出现的 `It is not possible to register multiple plain-rewritable disks with the same object storage prefix`) 。[#95470](https://github.com/ClickHouse/ClickHouse/pull/95470) ([Azat Khuzhin](https://github.com/azat)) 。
* 已在 [#95695](https://github.com/ClickHouse/ClickHouse/issues/95695) 中回移：修复了在等待分布式 DDL 且同时删除 Replicated 数据库时出现的 `There was an error: Cannot obtain error message` 逻辑错误。修复 [#95539](https://github.com/ClickHouse/ClickHouse/issues/95539)。[#95664](https://github.com/ClickHouse/ClickHouse/pull/95664) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* 已在 [#96053](https://github.com/ClickHouse/ClickHouse/issues/96053) 中回移：修复了对分区 Delta Lake 数据进行 squashing 时的问题。[#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* 已在 [#96211](https://github.com/ClickHouse/ClickHouse/issues/96211) 中回移：修复了 JSON 数据类型中的 skipping paths。此前使用 `JSON(SKIP path)` 时，所有前缀为 `path` 的 JSON 键都会被跳过，甚至包括 `"pathpath"` 这样的键，因此可能在插入期间导致这些路径的数据丢失。现在该问题已修复，只有键 `"path"` 会被跳过。[#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)) 。
* 已在 [#96078](https://github.com/ClickHouse/ClickHouse/issues/96078) 中回移：修复了全局 profiler 的周期 (由 `global_profiler_real_time_period_ns` 和 `global_profiler_cpu_time_period_ns` 控制) 。此前实际使用的是截断后的值，而不是设置值，导致 profiler 的唤醒频率高于预期。[#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#96155](https://github.com/ClickHouse/ClickHouse/issues/96155) 中回移：修复了 `formatDateTime` 在使用非定宽格式说明符 (例如 MySQL 和 JODA 风格) 时的 use-of-uninitialized-value 问题。[#96133](https://github.com/ClickHouse/ClickHouse/pull/96133) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#96278](https://github.com/ClickHouse/ClickHouse/issues/96278) 中回移：修复了 ProcessList 中可能发生的死锁。这可能是因为在向 cancellation checker 添加任务时，如果内存 overcommit 跟踪器被触发，就可能发生锁顺序反转。[#96182](https://github.com/ClickHouse/ClickHouse/pull/96182) ([Antonio Andelic](https://github.com/antonio2368)) 。
* 已在 [#96325](https://github.com/ClickHouse/ClickHouse/issues/96325) 中回移：修复了向量相似度索引中的 `stack-use-after-scope` 问题。[#96259](https://github.com/ClickHouse/ClickHouse/pull/96259) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#96530](https://github.com/ClickHouse/ClickHouse/issues/96530) 中回移：修复了 `max_execution_time` 值较高的查询在 cancellation checker 线程中出现的活锁问题。[#96450](https://github.com/ClickHouse/ClickHouse/pull/96450) ([Sergei Trifonov](https://github.com/serxa)) 。
* 已在 [#96625](https://github.com/ClickHouse/ClickHouse/issues/96625) 中回移：修复了 Parquet V3 读取器中，当 `PREWHERE` 过滤器列包含非布尔值的 UInt8 值时触发的 `LOGICAL_ERROR` 异常。[#96594](https://github.com/ClickHouse/ClickHouse/pull/96594) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* 已在 [#96691](https://github.com/ClickHouse/ClickHouse/issues/96691) 中回移：校验 bech32 中的 witness version，以避免缓冲区溢出。[#96671](https://github.com/ClickHouse/ClickHouse/pull/96671) ([Raúl Marín](https://github.com/Algunenano)) 。
* 已在 [#96917](https://github.com/ClickHouse/ClickHouse/issues/96917) 中回移：修复了在同一列上此前执行过轻量级更新后，`ALTER TABLE DROP COLUMN` 查询失败的问题。[#96861](https://github.com/ClickHouse/ClickHouse/pull/96861) ([Anton Popov](https://github.com/CurtizJ)) 。
* 已在 [#96936](https://github.com/ClickHouse/ClickHouse/issues/96936) 中回移：修复了 `indexOfAssumeSorted` 在使用不兼容类型调用时出现的 `std::terminate` 异常 (例如，在 `IPv4` 数组中使用整数作为搜索值) 。[#96877](https://github.com/ClickHouse/ClickHouse/pull/96877) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
