表引擎主要分为三大类：

* [MergeTree 引擎家族](../../../engines/table-engines/mergetree-family/index.md) 用于主要的生产场景。
* [Log 引擎家族](../../../engines/table-engines/log-family/index.md) 用于少量临时数据。
* [用于集成的表引擎](../../../engines/table-engines/integrations/index.md)。

其余引擎的用途较为独特，尚未归入任何家族，因此被归入“特殊”这一类别。
