ClickHouse 提供了多种与外部系统集成的方式，其中包括表引擎。与其他所有表引擎一样，其配置通过 `CREATE TABLE` 或 `ALTER TABLE` 查询完成。从用户的角度看，配置好的集成与普通表无异，但对其发出的查询实际上会被转发到外部系统。这种透明的查询方式是该方案相比其他集成方式 (如字典或表函数) 的一大优势，因为后者每次使用时都需要采用专门的查询方法。
