<div id="uuidv7-generation">
  ## UUIDv7 生成
</div>

生成的 UUID 包含一个 48 比特的 Unix 毫秒时间戳，后面依次是版本 &quot;7&quot; (4 比特) 、用于区分同一毫秒内 UUID 的计数器 (42 比特，包含变体字段 &quot;2&quot;，2 比特) ，以及随机字段 (32 比特) 。
对于任意给定的时间戳 (`unix_ts_ms`) ，计数器都会从一个随机值开始，并在每生成一个新的 UUID 时递增 1，直到时间戳发生变化。如果计数器溢出，则时间戳字段会加 1，同时将计数器重置为一个新的随机起始值。
UUID 生成函数可保证：对于同一时间戳，在并发运行的所有线程和查询中的全部函数调用之间，计数器字段都会保持单调递增。

<div id="snowflake-id-generation">
  ## Snowflake ID 生成
</div>

生成的 Snowflake ID 包含当前的毫秒级 Unix 时间戳 (41 + 1 个最高位为 0 的比特) ，后面依次是机器 ID (10 比特) 和计数器 (12 比特) ，用于区分同一毫秒内生成的 ID。对于任意给定的时间戳 (`unix_ts_ms`) ，计数器从 0 开始，每生成一个新的 Snowflake ID 就加 1，直到时间戳发生变化。如果计数器溢出，则时间戳字段加 1，并将计数器重置为 0。

:::note
生成的 Snowflake IDs 基于 UNIX 纪元 1970-01-01。虽然 Snowflake IDs 的纪元没有统一的标准或建议，但其他系统中的实现可能会使用不同的纪元，例如 Twitter/X (2010-11-04) 或 Mastodon (2015-01-01) 。
:::
