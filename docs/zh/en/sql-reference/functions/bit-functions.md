位函数适用于 `UInt8`、`UInt16`、`UInt32`、`UInt64`、`Int8`、`Int16`、`Int32`、`Int64`、`Float32` 或 `Float64` 中任意一对类型。某些函数还支持 `String` 和 `FixedString` 类型。

结果类型为整数，其位数等于各参数中的最大位数。如果参数中至少有一个是有符号类型，则结果为有符号数。如果某个参数是浮点数，则会将其转换为 Int64。
