这些函数使用 AES (高级加密标准) 算法对数据进行加密和解密。

密钥长度取决于加密模式：`-128-`、`-196-` 和 `-256-` 模式的密钥长度分别为 `16`、`24` 和 `32` 字节。

初始化向量的长度始终为 16 字节 (超过 16 字节的部分将被忽略) 。
