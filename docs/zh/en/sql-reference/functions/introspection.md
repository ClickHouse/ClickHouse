你可以使用本章介绍的函数检查 [ELF](https://en.wikipedia.org/wiki/Executable_and_Linkable_Format) 和 [DWARF](https://en.wikipedia.org/wiki/DWARF) 的内部信息，用于查询性能分析。

:::note
这些函数速度较慢，并且可能带来安全风险。
:::

要使内部信息函数正常工作：

* 安装 `clickhouse-common-static-dbg` 软件包。

* 将 [allow&#95;introspection&#95;functions](../../operations/settings/settings.md#allow_introspection_functions) 设置为 1。

  出于安全原因，内部信息函数默认处于禁用状态。

ClickHouse 会将 Profiler 报告保存到 [trace&#95;log](/zh/operations/system-tables/trace_log) 系统表。请确保该表和 Profiler 已正确配置。
