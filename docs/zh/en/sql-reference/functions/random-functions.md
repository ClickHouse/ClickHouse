本节中的所有函数都接受零个或一个参数。该参数 (如果提供) 的唯一用途是防止发生[公共子表达式消除](/zh/sql-reference/functions/overview#common-subexpression-elimination)，从而确保同一随机函数在同一行内的两次不同调用返回不同的随机值。

相关内容

* 指南：[在 ClickHouse 中生成随机数据](/zh/guides/generating-test-data)
* 博客：[在 ClickHouse 中生成随机数据](https://clickhouse.com/blog/generating-random-test-distribution-data-for-clickhouse)

:::note
随机数由非加密算法生成。
:::
