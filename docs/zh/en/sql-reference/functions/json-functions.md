<div id="types-of-functions">
  ## JSON 函数的类型
</div>

用于解析 JSON 的函数分为两类：

* [`simpleJSON*` (`visitParam*`)](#simplejson-visitparam-functions)，用于以极高速度解析 JSON 的有限子集。
* [`JSONExtract*`](#jsonextract-functions)，用于解析常规 JSON。

<div id="simplejson-visitparam-functions">
  ### simpleJSON (visitParam) functions
</div>

ClickHouse 提供了用于处理简化 JSON 的特殊函数。所有这些 JSON 函数都基于对 JSON 形式的一些严格假设。它们会尽量少做处理，以便尽可能快地完成任务。

具体假设如下：

1. 字段名 (函数参数) 必须是常量。
2. 字段名在 JSON 中必须以某种规范形式编码。例如：`simpleJSONHas('{"abc":"def"}', 'abc') = 1`，但 `simpleJSONHas('{"\\u0061\\u0062\\u0063":"def"}', 'abc') = 0`
3. 会在任意嵌套层级中搜索字段，不作区分。如果存在多个匹配字段，则使用第一次出现的字段。
4. JSON 在字符串字面量之外不能有空格字符。

<div id="jsonextract-functions">
  ### JSONExtract 函数
</div>

这些函数基于 [simdjson](https://github.com/lemire/simdjson)，适用于更复杂的 JSON 解析场景。

<div id="case-insensitive-jsonextract-functions">
  ### 不区分大小写的 JSONExtract 函数
</div>

这些函数在从 JSON 对象中提取值时，会执行基于 ASCII 的不区分大小写键名匹配。
除对象键匹配时不区分大小写外，它们的行为与区分大小写的对应函数完全一致。
如果有多个仅大小写不同的键都匹配，则返回第一个匹配项。

:::note
这些函数的性能可能不如区分大小写的对应函数，因此如非必要，请使用常规的 JSONExtract 函数。
:::
