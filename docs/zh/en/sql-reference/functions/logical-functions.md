以下函数对任意数值类型的参数执行逻辑运算。
它们返回 `0` 或 `1`，类型为 [`UInt8`](../data-types/int-uint.md)；在某些情况下，也会返回 `NULL`。

参数值为零时视为 `false`，非零值视为 `true`。
