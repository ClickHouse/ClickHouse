用户通过 SQL 语句与 ClickHouse 交互。ClickHouse 支持常见的 SQL 语句，例如 [SELECT](select/index.md) 和 [CREATE](create/index.md)，也提供 [KILL](kill.md) 和 [OPTIMIZE](optimize.md) 等专用语句。
