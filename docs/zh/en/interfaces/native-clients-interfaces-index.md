ClickHouse 提供了多种原生客户端和接口，方便您连接到 ClickHouse。

更多信息请参阅以下页面：

| Section                                          | Summary                               |
| ------------------------------------------------ | ------------------------------------- |
| [clickhousectl](/zh/interfaces/cli)                 | 适用于本地和云端的 ClickHouse 命令行客户端。          |
| [ClickHouse 客户端](/zh/interfaces/client)             | 原生命令行客户端，支持命令行选项和配置文件。                |
| [驱动和接口](/zh/interfaces/overview)                    | 提供多种网络接口、库和可视化界面。                     |
| [SQL 控制台](/zh/integrations/sql-clients/sql-console) | 在 ClickHouse Cloud 中与数据交互的快速简便方式。     |
| [Web SQL UI (Play)](/zh/interfaces/web-sql)         | ClickHouse 在 `/play` 提供的内置浏览器 SQL 界面。 |
