<div id="description">
  ## 描述
</div>

此表只有一行，且仅包含一个值为 0 的 `dummy` UInt8 列。

如果 `SELECT` 查询未指定 `FROM` 子句，则会使用此表。

它类似于其他 DBMSs 中的 `DUAL` 表。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `dummy` ([UInt8](/zh/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT * FROM system.one LIMIT 10;
```

```response
┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
```
