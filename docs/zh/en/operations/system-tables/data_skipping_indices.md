<div id="description">
  ## 描述
</div>

包含所有表中现有数据跳过索引的相关信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名。
* `name` ([String](/zh/sql-reference/data-types/string)) — 索引名称。
* `type` ([String](/zh/sql-reference/data-types/string)) — 索引类型。
* `type_full` ([String](/zh/sql-reference/data-types/string)) — 来自 CREATE 语句的索引类型表达式。
* `expr` ([String](/zh/sql-reference/data-types/string)) — 用于计算索引的表达式。
* `creation` ([Enum8(&#39;Explicit&#39; = 0, &#39;Implicit&#39; = 1)](/zh/sql-reference/data-types/enum)) — 索引是否为隐式创建的 (通过 add&#95;minmax&#95;index&#95;for&#95;numeric&#95;columns 或类似方式)
* `granularity` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 块中包含的粒度数。
* `data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 压缩数据的大小，以字节为单位。
* `data_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 解压后数据的大小，以字节为单位。
* `marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 标记的大小，以字节为单位。

{/*AUTOGENERATED_END*/ }
