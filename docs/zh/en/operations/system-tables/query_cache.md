<div id="description">
  ## 说明
</div>

显示[查询缓存](../query-cache.md)中的内容。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/zh/sql-reference/data-types/string)) — 查询语句。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 查询的 ID。
* `result_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 查询缓存项的大小。
* `tag` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 查询缓存项的标签。
* `stale` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 查询缓存项是否已失效。
* `shared` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 查询缓存项是否由多个用户共享。
* `compressed` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 查询缓存项是否已压缩。
* `expires_at` ([DateTime](/zh/sql-reference/data-types/datetime)) — 查询缓存项何时失效。
* `key_hash` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 查询语句的哈希值，用作查找查询缓存项的键。

{/*AUTOGENERATED_END*/ }
