<div id="description">
  ## 描述
</div>

包含 AzureQueue 元数据的内存状态，以及每个文件当前正在处理的行数。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/zh/sql-reference/data-types/string)) — ZooKeeper 中元数据的路径
* `file_path` ([String](/zh/sql-reference/data-types/string)) — 正在处理的文件的文件路径
* `file_name` ([String](/zh/sql-reference/data-types/string)) — 正在处理的文件的文件名
* `rows_processed` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 当前已处理的行数
* `status` ([String](/zh/sql-reference/data-types/string)) — 处理状态：Processed、Processing、Failed
* `processing_start_time` ([Nullable(DateTime)](/zh/sql-reference/data-types/nullable)) — 文件开始处理的时间
* `processing_end_time` ([Nullable(DateTime)](/zh/sql-reference/data-types/nullable)) — 文件处理结束的时间
* `exception` ([String](/zh/sql-reference/data-types/string)) — 处理过程中发生的异常

{/*AUTOGENERATED_END*/ }
