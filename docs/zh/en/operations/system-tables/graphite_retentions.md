<div id="description">
  ## 说明
</div>

包含有关参数 [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite) 的信息，这些参数用于使用 [*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md) 引擎的表。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/zh/sql-reference/data-types/string)) — graphite&#95;rollup 参数名称。
* `rule_type` ([String](/zh/sql-reference/data-types/string)) — 规则类型。可能的值：RuleTypeAll = 0 - 默认，带有 regex，与旧方案兼容；RuleTypePlain = 1 - 普通指标，带有 regex，与旧方案兼容；RuleTypeTagged = 2 - 带标签的指标，带有 regex，与旧方案兼容；RuleTypeTagList = 3 - 带标签的指标，带有 regex (由类似 &#39;retention=10min ; env=(staging|prod)&#39; 的字符串转换为 RuleTypeTagged)
* `regexp` ([String](/zh/sql-reference/data-types/string)) — 指标名称的模式。
* `function` ([String](/zh/sql-reference/data-types/string)) — 聚合函数名称。
* `age` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据的最小保留时长 (以秒为单位) 。
* `precision` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 以秒为单位定义数据时长的精度。
* `priority` ([UInt16](/zh/sql-reference/data-types/int-uint)) — 模式优先级。
* `is_default` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该模式是否为默认模式。
* `Tables.database` ([Array(String)](/zh/sql-reference/data-types/array)) — 使用 `config_name` 参数的数据库名称数组。
* `Tables.table` ([Array(String)](/zh/sql-reference/data-types/array)) — 使用 `config_name` 参数的表名数组。

{/*AUTOGENERATED_END*/ }
