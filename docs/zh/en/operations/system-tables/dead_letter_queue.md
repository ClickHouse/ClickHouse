<div id="description">
  ## 描述
</div>

包含通过流式引擎接收且在解析时出错的消息相关信息。目前已为 Kafka 和 RabbitMQ 实现。

可通过将引擎特定的 `handle_error_mode` 设置为 `dead_letter_queue` 来启用日志。

数据的刷新周期可在服务器设置部分 [dead&#95;letter&#95;queue](../../operations/server-configuration-parameters/settings.md#dead_letter_queue) 的 `flush_interval_milliseconds` 参数中设置。要强制刷新，请使用 [SYSTEM FLUSH LOGS](/zh/sql-reference/statements/system#flush-logs) 查询。

ClickHouse 不会自动从该表中删除数据。更多信息，请参见 [Introduction](../../operations/system-tables/overview.md#system-tables-introduction)。
