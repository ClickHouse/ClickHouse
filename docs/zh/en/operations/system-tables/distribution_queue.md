<div id="description">
  ## 描述
</div>

包含有关队列中等待发送到各分片的本地文件的信息。这些本地文件包含新的 parts，这些 parts 是以异步模式向 Distributed 表插入新数据时创建的。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `data_path` ([String](/zh/sql-reference/data-types/string)) — 本地文件所在文件夹的路径。
* `is_blocked` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 标志，指示是否已阻止将本地文件发送到服务器。
* `error_count` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 错误数。
* `data_files` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 文件夹中的本地文件数。
* `data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 本地文件中压缩数据的大小，单位为字节。
* `broken_data_files` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 被标记为损坏的文件数 (由错误导致) 。
* `broken_data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 损坏文件中压缩数据的大小，单位为字节。
* `last_exception` ([String](/zh/sql-reference/data-types/string)) — 最近一次发生的错误的文本消息 (如有) 。
* `last_exception_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 最近一次异常发生的时间。

{/*AUTOGENERATED_END*/ }
