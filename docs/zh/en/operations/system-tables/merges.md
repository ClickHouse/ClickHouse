<div id="description">
  ## 说明
</div>

包含有关 MergeTree 家族中的表当前正在进行的合并和 part mutation 的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 该表所在的数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名。
* `elapsed` ([Float64](/zh/sql-reference/data-types/float)) — 自合并开始以来经过的时间 (以秒为单位) 。
* `progress` ([Float64](/zh/sql-reference/data-types/float)) — 已完成工作的百分比，范围为 0 到 1。
* `num_parts` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 要合并的 parts 数量。
* `source_part_names` ([Array(String)](/zh/sql-reference/data-types/array)) — 源 parts 名称列表。
* `result_part_name` ([String](/zh/sql-reference/data-types/string)) — 合并结果生成的 part 名称。
* `source_part_paths` ([Array(String)](/zh/sql-reference/data-types/array)) — 每个源 part 的路径列表。
* `result_part_path` ([String](/zh/sql-reference/data-types/string)) — 合并结果生成的 part 的路径。
* `partition_id` ([String](/zh/sql-reference/data-types/string)) — 发生合并的分区标识符。
* `partition` ([String](/zh/sql-reference/data-types/string)) — 分区名称
* `is_mutation` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果该过程是 part mutation，则为 1。
* `total_size_bytes_compressed` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 已合并数据块中压缩数据的总大小。
* `total_size_bytes_uncompressed` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 已合并数据块中未压缩数据的总大小。
* `total_size_marks` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 已合并 parts 中标记的总数。
* `bytes_read_uncompressed` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 读取的未压缩字节数。
* `rows_read` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 读取的行数。
* `bytes_written_uncompressed` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 写入的未压缩字节数。
* `rows_written` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 写入的行数。
* `columns_written` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 写入的列数 (用于垂直合并算法) 。
* `memory_usage` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 合并过程的内存消耗。
* `thread_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 合并过程的线程 ID。
* `merge_type` ([String](/zh/sql-reference/data-types/string)) — 当前合并的类型。如果这是变更，则为空。
* `merge_algorithm` ([String](/zh/sql-reference/data-types/string)) — 当前合并使用的算法。如果这是变更，则为空。

{/*AUTOGENERATED_END*/ }
