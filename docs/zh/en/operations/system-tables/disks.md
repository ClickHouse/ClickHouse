<div id="description">
  ## 描述
</div>

包含有关在[服务器配置](../../engines/table-engines/mergetree-family/mergetree.md#table_engine-mergetree-multiple-volumes_configure)中定义的磁盘的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 服务器配置中磁盘的名称。
* `path` ([String](/zh/sql-reference/data-types/string)) — 文件系统中挂载点的路径。
* `free_space` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 磁盘上的可用空间，单位为字节。
* `total_space` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 磁盘容量，单位为字节。
* `unreserved_space` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 未被预留占用的可用空间 (`free_space` 减去当前正在运行的 merge、insert 及其他磁盘写入操作所占用的预留空间大小) 。
* `keep_free_space` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 磁盘上应保留的可用空间，单位为字节。定义在磁盘配置的 `keep_free_space_bytes` 参数中。
* `type` ([String](/zh/sql-reference/data-types/string)) — 磁盘类型，用于指示该磁盘将数据存储在何处——RAM、本地磁盘或远程存储。
* `object_storage_type` ([String](/zh/sql-reference/data-types/string)) — 如果磁盘类型为 `object_storage`，则表示对象存储的类型。
* `metadata_type` ([String](/zh/sql-reference/data-types/string)) — 如果磁盘类型为 `object_storage`，则表示元数据存储的类型。
* `is_encrypted` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该磁盘是否会对底层数据加密的标志。
* `is_read_only` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该磁盘是否只能执行只读操作的标志。
* `is_write_once` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示磁盘是否为一次写入型的标志。这意味着它支持将 BACKUP 写入该磁盘，但不支持对该磁盘上的 MergeTree 表执行 INSERT。
* `is_remote` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示对该磁盘执行操作时是否会涉及网络交互的标志。
* `is_broken` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示磁盘是否已损坏的标志。损坏的磁盘空间将为 0，且无法使用。
* `cache_path` ([String](/zh/sql-reference/data-types/string)) — 如果磁盘支持缓存，则表示本地磁盘上缓存目录的路径。

{/*AUTOGENERATED_END*/ }
