<div id="description">
  ## 说明
</div>

包含有关支持的数据类型的信息，详见[数据类型](../../sql-reference/data-types/index.md)。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 数据类型名称。
* `case_insensitive` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 用于指示是否可在查询中以不区分大小写的方式使用数据类型名称的属性。例如，`Date` 和 `date` 都是有效的。
* `alias_to` ([String](/zh/sql-reference/data-types/string)) — `name` 作为其别名所对应的数据类型名称。
* `description` ([String](/zh/sql-reference/data-types/string)) — 对该数据类型的概括性说明。
* `syntax` ([String](/zh/sql-reference/data-types/string)) — 该数据类型在查询中的写法。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 用法示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 该数据类型首次引入时对应的 ClickHouse 版本，格式为 major.minor。
* `related` ([Array](/zh/sql-reference/data-types/array)([String](/zh/sql-reference/data-types/string))) — 相关数据类型的名称。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
┌─name───────┬─case_insensitive─┬─alias_to─┐
│ LONGBLOB   │                1 │ String   │
│ LONGTEXT   │                1 │ String   │
│ TINYTEXT   │                1 │ String   │
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
