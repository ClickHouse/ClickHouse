<div id="description">
  ## 描述
</div>

包含当前正在分片之间移动的 parts 及其移动进度信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 执行移动操作所在数据库的名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 执行移动操作所在表的名称。
* `task_name` ([String](/zh/sql-reference/data-types/string)) — 移动任务的名称。
* `task_uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — 移动任务的标识符。
* `create_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 任务创建时间。
* `part_name` ([String](/zh/sql-reference/data-types/string)) — 正在移动中的 parts 名称。
* `part_uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — 正在移动中的 parts UUID。
* `to_shard` ([String](/zh/sql-reference/data-types/string)) — 目标分片的名称。
* `dst_part_name` ([String](/zh/sql-reference/data-types/string)) — 结果 parts 名称。
* `update_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 最后一次更新的时间。
* `state` ([String](/zh/sql-reference/data-types/string)) — 移动的当前状态。
* `rollback` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该操作是否已回滚的标志。
* `num_tries` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 完成该操作的尝试次数。
* `last_exception` ([String](/zh/sql-reference/data-types/string)) — 最后一个异常名称 (如有) 。

{/*AUTOGENERATED_END*/ }
