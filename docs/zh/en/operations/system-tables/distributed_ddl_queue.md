<div id="description">
  ## 描述
</div>

包含有关在集群上执行的[分布式 DDL 查询 (ON CLUSTER 子句) ](../../sql-reference/distributed-ddl.md)的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `entry` ([String](/zh/sql-reference/data-types/string)) — 查询 ID。
* `entry_version` ([Nullable(UInt8)](/zh/sql-reference/data-types/nullable)) — 条目的版本。
* `initiator_host` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 发起 DDL 操作的主机。
* `initiator_port` ([Nullable(UInt16)](/zh/sql-reference/data-types/nullable)) — 发起方使用的端口。
* `cluster` ([String](/zh/sql-reference/data-types/string)) — 集群名称，若无法确定则为空。
* `query` ([String](/zh/sql-reference/data-types/string)) — 执行的查询。
* `settings` ([Map(String, String)](/zh/sql-reference/data-types/map)) — DDL 操作中使用的设置。
* `query_create_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 查询创建时间。
* `host` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 主机名。
* `port` ([Nullable(UInt16)](/zh/sql-reference/data-types/nullable)) — 主机端口。
* `status` ([Nullable(Enum8(&#39;Inactive&#39; = 0, &#39;Active&#39; = 1, &#39;Finished&#39; = 2, &#39;Removing&#39; = 3, &#39;Unknown&#39; = 4))](/zh/sql-reference/data-types/nullable)) — 查询状态。
* `exception_code` ([Nullable(UInt16)](/zh/sql-reference/data-types/nullable)) — 异常代码。
* `exception_text` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 异常消息。
* `query_finish_time` ([Nullable(DateTime)](/zh/sql-reference/data-types/nullable)) — 查询完成时间。
* `query_duration_ms` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 查询执行耗时 (以毫秒为单位) 。

{/*AUTOGENERATED_END*/ }
