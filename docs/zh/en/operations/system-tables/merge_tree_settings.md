<div id="description">
  ## 说明
</div>

包含 `MergeTree` 表相关设置信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 设置名称。
* `value` ([String](/zh/sql-reference/data-types/string)) — 设置值。
* `default` ([String](/zh/sql-reference/data-types/string)) — 设置默认值。
* `changed` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果该设置已在 config 中显式定义或被显式修改，则为 1。
* `description` ([String](/zh/sql-reference/data-types/string)) — 设置说明。
* `min` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 该设置的最小值 (如果通过约束设置了最小值) 。如果该设置没有最小值，则包含 NULL。
* `max` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 该设置的最大值 (如果通过约束设置了最大值) 。如果该设置没有最大值，则包含 NULL。
* `disallowed_values` ([Array(String)](/zh/sql-reference/data-types/array)) — 不允许的值列表
* `readonly` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 显示当前用户是否可以更改该设置：0 — 当前用户可以更改该设置，1 — 当前用户无法更改该设置。
* `type` ([String](/zh/sql-reference/data-types/string)) — 设置类型 (实现相关的字符串值) 。
* `is_obsolete` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 显示该设置是否已废弃。
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/zh/sql-reference/data-types/enum)) — 此功能的支持层级。ClickHouse 功能按层级划分，具体取决于其当前的
  开发状态，以及使用它们时可预期的表现：
  * PRODUCTION: 该功能处于稳定版本状态，可安全使用，并且与其他 PRODUCTION 功能交互时不会出现问题。
  * BETA: 该功能稳定且安全。与其他功能一同使用时的结果尚不明确，且不保证正确性。欢迎进行测试并提交反馈。
  * EXPERIMENTAL: 该功能仍在开发中。仅适用于开发者和 ClickHouse 爱好者。该功能可能可用，也可能不可用，并且可能随时被移除。
  * OBSOLETE: 不再受支持。它要么已被移除，要么将在未来的发行版中被移除。

{/*AUTOGENERATED_END*/ }
