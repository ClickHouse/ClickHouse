<div id="description">
  ## 描述
</div>

包含存储在远程磁盘 (如 S3、Azure Blob 存储) 中的数据文件信息，包括本地元数据路径与远程 blob 路径之间的映射关系。

每一行对应一个与数据文件关联的远程 blob 对象。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `disk_name` ([String](/zh/sql-reference/data-types/string)) — 磁盘名称。
* `path` ([String](/zh/sql-reference/data-types/string)) — 磁盘路径。
* `cache_base_path` ([String](/zh/sql-reference/data-types/string)) — 缓存文件的根目录。
* `local_path` ([String](/zh/sql-reference/data-types/string)) — ClickHouse 文件的路径，也可用作元数据路径。
* `remote_path` ([String](/zh/sql-reference/data-types/string)) — 对象存储中的 blob 路径，与该 ClickHouse 文件关联。
* `size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 文件大小 (压缩后) 。
* `common_prefix_for_blobs` ([String](/zh/sql-reference/data-types/string)) — 对象存储中 blobs 的公共前缀。
* `cache_paths` ([Array(String)](/zh/sql-reference/data-types/array)) — 对应 blob 的缓存文件路径。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT * FROM system.remote_data_paths LIMIT 1 FORMAT Vertical;
```

```text
Row 1:
──────
disk_name:              s3
path:                   /var/lib/clickhouse/disks/s3/
cache_base_path:        /var/lib/clickhouse/disks/s3_cache/
local_path:             store/123/1234abcd-1234-1234-1234-1234abcd1234/all_0_0_0/data.bin
remote_path:            abc123/all_0_0_0/data.bin
size:                   1048576
common_prefix_for_blobs:
cache_paths:            ['/var/lib/clickhouse/disks/s3_cache/a1/b2/c3d4e5f6']
```
