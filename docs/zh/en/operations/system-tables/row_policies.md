<div id="description">
  ## 描述
</div>

包含某个特定表的过滤器，以及应应用此 ROW POLICY 的角色和/或用户列表。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — ROW POLICY的名称。
* `short_name` ([String](/zh/sql-reference/data-types/string)) — ROW POLICY的简称。ROW POLICY名称是复合形式，例如：myfilter ON mydb.mytable。这里，&#39;myfilter ON mydb.mytable&#39; 是ROW POLICY的名称，&#39;myfilter&#39; 是其简称。
* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。如果策略针对的是数据库，则为空。
* `id` ([UUID](/zh/sql-reference/data-types/uuid)) — ROW POLICY ID。
* `storage` ([String](/zh/sql-reference/data-types/string)) — 存储ROW POLICY的目录名称。
* `select_filter` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 用于在 SELECT 查询中过滤的 expression。
* `is_restrictive` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示ROW POLICY是否限制对行的访问。值：• 0 — ROW POLICY使用 `AS PERMISSIVE` clause 定义，• 1 — ROW POLICY使用 `AS RESTRICTIVE` clause 定义。
* `apply_to_all` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示这些ROW POLICY适用于所有 roles 和/或 users。
* `apply_to_list` ([Array(String)](/zh/sql-reference/data-types/array)) — 应用这些ROW POLICY的 roles 和/或 users 列表。
* `apply_to_except` ([Array(String)](/zh/sql-reference/data-types/array)) — 这些ROW POLICY适用于除所列 roles 和/或 users 之外的所有 roles 和/或 users。

{/*AUTOGENERATED_END*/ }
