<div id="description">
  ## 描述
</div>

该表包含有关 [MergeTree](/zh/engines/table-engines/mergetree-family/mergetree.md) 表进行中的[数据分片移动](/zh/sql-reference/statements/alter/partition#move-partitionpart)的信息。每个数据分片移动对应一行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 包含正在移动的数据分片的表名称。
* `elapsed` ([Float64](/zh/sql-reference/data-types/float)) — 自数据分片开始移动以来经过的时间 (秒) 。
* `target_disk_name` ([String](/zh/sql-reference/data-types/string)) — 数据分片将要移入的目标磁盘名称。
* `target_disk_path` ([String](/zh/sql-reference/data-types/string)) — 文件系统中该磁盘挂载点的路径。
* `part_name` ([String](/zh/sql-reference/data-types/string)) — 正在移动的数据分片名称。
* `part_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分片大小。
* `thread_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 执行移动操作的线程标识符。

{/*AUTOGENERATED_END*/ }
