<div id="description">
  ## 说明
</div>

如果此节点未配置为运行进程内 ClickHouse Keeper，则此表不存在。该表对每个 Raft 集群成员各有一行，将静态集群拓扑 (来自 Raft 配置) 与本地节点自身的日志位置结合在一起。

每个节点都只会填充一个 `last_log_index` 值——也就是与其自身 `server_id` 对应的那一行。peer 的日志位置不会在此处显示，因为这些位置只在 leader 上跟踪，而这个视图在整个集群中并不是对称的。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — 此集群成员的 Raft server id。
* `host` ([String](../../sql-reference/data-types/string.md)) — 从端点解析出的 host (最后一个冒号之前的部分) 。
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — 配置中的原始 Raft 端点 (`host:port`) 。
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — 如果此成员是无投票权的 observer，则为 `true`，通过 `<can_become_leader>false</can_become_leader>` 配置。
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — 此成员的 Raft 优先级；在 leader election 期间，值越高越优先。
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — 如果此成员是当前的 Raft leader，则为 `true`。
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — 如果此行描述的是本地 Keeper 节点，则为 `true`。
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — 此节点上本地 Raft 日志存储中的最高日志索引。仅在与当前节点对应的行 (`is_self = true`) 中填充；其他行则为 `NULL`。

{/*AUTOGENERATED_END*/ }

示例：

```sql
SELECT * FROM system.keeper_cluster ORDER BY server_id;
```
