<div id="description">
  ## 描述
</div>

包含有关队列中待处理的异步插入的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/zh/sql-reference/data-types/string)) — 查询文本。
* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `format` ([String](/zh/sql-reference/data-types/string)) — 格式名称。
* `first_update` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 首次写入时间，精度为微秒。
* `total_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 队列中等待处理的总字节数。
* `entries.query_id` ([Array(String)](/zh/sql-reference/data-types/array)) — 队列中等待处理的各写入操作的查询 id 数组。
* `entries.bytes` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 队列中等待处理的每个插入查询的字节数数组。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT * FROM system.asynchronous_inserts LIMIT 1 \G;
```

```text title="Response"
──────

total_bytes:      133223

entries.bytes:    [133223]
```
