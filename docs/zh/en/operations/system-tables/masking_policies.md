<div id="description">
  ## 说明
</div>

包含系统中定义的所有脱敏策略信息。

脱敏策略只能在 ClickHouse Cloud 中创建和应用。在 open-source 构建中，`system.masking_policies` 表始终为空，但该表仍然存在，因此 `SHOW MASKING POLICIES` 这类内部信息查询仍可正常执行，并返回空结果而不是抛出异常。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string.md)) — 数据脱敏策略的名称。完整名称格式为 `short_name ON database.table`。
* `short_name` ([String](/zh/sql-reference/data-types/string.md)) — 数据脱敏策略的短名称。例如，如果完整名称为 `mask_email ON mydb.mytable`，则短名称为 `mask_email`。
* `database` ([String](/zh/sql-reference/data-types/string.md)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string.md)) — 表名称。
* `id` ([UUID](/zh/sql-reference/data-types/uuid.md)) — 数据脱敏策略 ID。
* `storage` ([String](/zh/sql-reference/data-types/string.md)) — 存储数据脱敏策略的目录名称。
* `update_assignments` ([Nullable(String)](/zh/sql-reference/data-types/nullable.md)) — 定义如何对数据进行脱敏的 UPDATE 赋值。例如：`email = '***masked***', phone = '***-***-****'`。
* `where_condition` ([Nullable(String)](/zh/sql-reference/data-types/nullable.md)) — 可选的 WHERE 条件，用于指定何时应用脱敏。
* `priority` ([Int64](/zh/sql-reference/data-types/int-uint.md)) — 应用多个数据脱敏策略时的优先级。优先级较高的策略会先应用。默认值为 0。
* `apply_to_all` ([UInt8](/zh/sql-reference/data-types/int-uint.md)) — 表示该数据脱敏策略是否适用于所有角色和/或用户。为 true 时值为 1，否则为 0。
* `apply_to_list` ([Array(String)](/zh/sql-reference/data-types/array.md)) — 应用该数据脱敏策略的角色和/或用户列表。
* `apply_to_except` ([Array(String)](/zh/sql-reference/data-types/array.md)) — 该数据脱敏策略适用于除所列角色和/或用户之外的所有角色和/或用户。仅在 `apply_to_all` 为 1 时填充。
