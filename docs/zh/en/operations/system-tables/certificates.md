<div id="description">
  ## 描述
</div>

包含可用证书及其来源的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `version` ([Int32](/zh/sql-reference/data-types/int-uint)) — 证书版本。值为 0 表示 v1，1 表示 v2，2 表示 v3。
* `serial_number` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 由签发方分配的证书序列号。
* `signature_algo` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 签名算法——签发方用于签署此证书的算法。
* `issuer` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 签发方——签发此证书的证书颁发机构的唯一标识符。
* `not_before` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 此证书开始生效的时间。
* `not_after` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 此证书失效的时间。
* `subject` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 主体——标识公钥所有者。
* `pkey_algo` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 公钥算法，定义该公钥可配合使用的算法。
* `path` ([String](/zh/sql-reference/data-types/string)) — 包含此证书的文件或目录路径。
* `default` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 证书位于默认证书位置。
* `protocol` ([String](/zh/sql-reference/data-types/string)) — 如果证书来自按协议区分的 TLS 配置，则为协议名称；否则为空。

{/*AUTOGENERATED_END*/ }
