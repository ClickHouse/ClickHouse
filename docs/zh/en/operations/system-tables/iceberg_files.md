<div id="description">
  ## 说明
</div>

此系统表包含 ClickHouse 中现有 Iceberg 表的逐文件元数据，其中每一行对应各表当前快照引用的一个数据文件或删除文件。如果 ClickHouse 中没有任何 Iceberg 表，则该表为空。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `snapshot_id` ([Int64](/zh/sql-reference/data-types/int-uint)) — 添加该文件时对应的快照 ID。
* `content` ([Enum8](/zh/sql-reference/data-types/enum)) — 文件内容类型：`DATA`、`POSITION_DELETE` 或 `EQUALITY_DELETE`。
* `file_path` ([String](/zh/sql-reference/data-types/string)) — 文件解析后的存储路径。
* `file_format` ([String](/zh/sql-reference/data-types/string)) — 文件格式，例如 `'PARQUET'`。
* `record_count` ([Int64](/zh/sql-reference/data-types/int-uint)) — 文件中的记录数。
* `file_size_in_bytes` ([Int64](/zh/sql-reference/data-types/int-uint)) — 文件大小 (字节) 。
* `partition` ([String](/zh/sql-reference/data-types/string)) — 分区元组的文本表示。
* `schema_id` ([Int32](/zh/sql-reference/data-types/int-uint)) — 为此清单条目解析得到的 schema ID。
* `sequence_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 清单条目解析得到的序列号 (格式 v1 始终为 0) 。
* `sort_order_id` ([Nullable(Int32)](/zh/sql-reference/data-types/nullable)) — 文件的排序顺序 ID (如果已指定) 。
* `null_value_counts` ([Map(Int32, Int64)](/zh/sql-reference/data-types/map)) — 每列的 NULL 值计数 (列 id -&gt; 计数) 。
* `column_sizes` ([Map(Int32, Int64)](/zh/sql-reference/data-types/map)) — 每列在磁盘上的大小 (字节)  (列 id -&gt; 字节数) 。
* `value_counts` ([Map(Int32, Int64)](/zh/sql-reference/data-types/map)) — 每列的总值计数 (列 id -&gt; 计数) 。
* `equality_ids` ([Array(Int32)](/zh/sql-reference/data-types/array)) — equality delete 文件的等值字段 ID (对于非 equality delete 文件为空) 。

{/*AUTOGENERATED_END*/ }
