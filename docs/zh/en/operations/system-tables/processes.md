<div id="description">
  ## 描述
</div>

该系统表用于实现 `SHOW PROCESSLIST` 查询。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `is_initial_query` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 此查询是直接来自用户，还是由 ClickHouse server 在分布式查询执行过程中发起的。
* `user` ([String](/zh/sql-reference/data-types/string)) — 发起该查询的用户。请注意，在分布式处理中，查询会以 `default` 用户身份发送到远程服务器。该字段包含的是当前这个特定查询的用户名，而不是由该查询触发的其他查询的用户名。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 查询 ID (如果已定义) 。
* `address` ([IPv6](/zh/sql-reference/data-types/ipv6)) — 发起该查询的 IP 地址。在分布式处理中也是如此。若要跟踪分布式查询最初是从哪里发起的，请查看查询请求发起方服务器上的 system.processes。
* `port` ([UInt16](/zh/sql-reference/data-types/int-uint)) — 发起该查询的客户端端口。
* `initial_user` ([String](/zh/sql-reference/data-types/string)) — 执行初始查询的用户名 (用于分布式查询执行) 。
* `initial_query_id` ([String](/zh/sql-reference/data-types/string)) — 初始查询的 ID (用于分布式查询执行) 。
* `initial_address` ([IPv6](/zh/sql-reference/data-types/ipv6)) — 发起父查询的 IP 地址。
* `initial_port` ([UInt16](/zh/sql-reference/data-types/int-uint)) — 发起父查询时使用的客户端端口。
* `interface` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 发送查询时使用的接口。TCP = 1，HTTP = 2，GRPC = 3，MYSQL = 4，POSTGRESQL = 5，LOCAL = 6，TCP&#95;INTERSERVER = 7。
* `os_user` ([String](/zh/sql-reference/data-types/string)) — 运行 ClickHouse 客户端的操作系统用户名。
* `client_hostname` ([String](/zh/sql-reference/data-types/string)) — 运行 ClickHouse 客户端或其他 TCP 客户端的客户端机器主机名。
* `client_name` ([String](/zh/sql-reference/data-types/string)) — ClickHouse 客户端或其他 TCP 客户端的名称。
* `client_agent` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 调用该客户端的 AI 编码 agent (例如 `claude-code` 或 `cursor`) ，通过环境变量检测得出。如果未检测到 agent，则为空。
* `client_revision` ([UInt64](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端的修订版本。
* `client_version_major` ([UInt64](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端的主版本号。
* `client_version_minor` ([UInt64](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端的次版本号。
* `client_version_patch` ([UInt64](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端版本的补丁号部分。
* `http_method` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 发起该查询的 HTTP 方法。可能的值：0 — 查询是通过 TCP 接口发起的。1 — 使用了 GET 方法。2 — 使用了 POST 方法。
* `http_user_agent` ([String](/zh/sql-reference/data-types/string)) — HTTP 查询中传递的 UserAgent HTTP 请求头。
* `http_referer` ([String](/zh/sql-reference/data-types/string)) — HTTP 查询中传递的 Referer HTTP 请求头 (包含发起查询页面的完整或部分地址) 。
* `forwarded_for` ([String](/zh/sql-reference/data-types/string)) — HTTP 查询中传递的 X-Forwarded-For HTTP 请求头。
* `quota_key` ([String](/zh/sql-reference/data-types/string)) — quotas 设置中指定的配额键 (参见 keyed) 。
* `distributed_depth` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 查询在服务器节点之间内部转发的次数。
* `elapsed` ([Float64](/zh/sql-reference/data-types/float)) — 从请求开始执行到现在所经过的时间 (以秒为单位) 。
* `is_cancelled` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 查询是否已取消。
* `is_all_data_sent` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 是否已将所有数据发送给客户端 (换句话说，查询已在服务器上完成) 。
* `read_rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 从表中读取的行数。对于分布式处理，在请求发起服务器上，这是所有远程服务器的总和。
* `read_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 从表中读取的未压缩字节数。对于分布式处理，在请求发起服务器上，这是所有远程服务器的总和。
* `total_rows_approx` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 预计需要读取的总行数的近似值。对于分布式处理，在请求发起服务器上，这是所有远程服务器的总和。当发现新的待处理数据源时，它可能会在请求处理期间更新。
* `written_rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 写入存储的行数。
* `written_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 写入存储的字节数。
* `memory_usage` ([Int64](/zh/sql-reference/data-types/int-uint)) — 查询使用的 RAM 量。它可能不包括某些类型的专用内存。
* `peak_memory_usage` ([Int64](/zh/sql-reference/data-types/int-uint)) — 当前的内存使用峰值。
* `query` ([String](/zh/sql-reference/data-types/string)) — 查询文本。对于 INSERT，它不包括要插入的数据。
* `normalized_query_hash` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数值哈希值；对于仅字面量值不同的查询，该值相同。
* `query_kind` ([String](/zh/sql-reference/data-types/string)) — 查询类型，例如 SELECT、INSERT 等。
* `thread_ids` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 参与此查询的所有线程的标识符列表。
* `peak_threads_usage` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 执行该查询时的最大并发线程数。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/zh/sql-reference/data-types/map)) — 为此查询计算的 ProfileEvents。
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/zh/sql-reference/data-types/map)) — 已修改的用户级设置列表。
* `current_database` ([String](/zh/sql-reference/data-types/string)) — 当前数据库的名称。
* `is_internal` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示这是否为内部执行的辅助查询。

**别名：**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)` 的别名。
* `ProfileEvents.Values` — `mapValues(ProfileEvents)` 的别名。
* `Settings.Names` — `mapKeys(Settings)` 的别名。
* `Settings.Values` — `mapValues(Settings)` 的别名。

{/*AUTOGENERATED_END*/ }
