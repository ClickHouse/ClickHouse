<div id="description">
  ## 描述
</div>

列出了所有可用的聚合函数组合器，它们可应用于聚合函数，并改变其工作方式。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 组合器名称。
* `is_internal` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 此组合器是否仅用于内部使用。

{/*AUTOGENERATED_END*/ }
