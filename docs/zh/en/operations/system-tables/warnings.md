<div id="description">
  ## 描述
</div>

包含在 ClickHouse 客户端连接到服务器后立即显示的服务器配置警告。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `message` ([String](/zh/sql-reference/data-types/string)) — ClickHouse 服务器 发出的警告信息。
* `message_format_string` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 用于格式化该信息的格式字符串。

{/*AUTOGENERATED_END*/ }
