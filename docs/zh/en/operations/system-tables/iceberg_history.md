<div id="description">
  ## 描述
</div>

此系统表包含 ClickHouse 中现有 Iceberg 表的快照历史。如果 ClickHouse 中没有任何 Iceberg 表，该表将为空。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `made_current_at` ([Nullable(DateTime64(3))](/zh/sql-reference/data-types/nullable)) — 此快照成为当前快照的日期和时间。
* `snapshot_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 用于标识快照的快照 ID。
* `parent_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 此快照的父快照 ID。
* `is_current_ancestor` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示此快照是否为当前快照祖先的标志。

{/*AUTOGENERATED_END*/ }
