<div id="description">
  ## 说明
</div>

包含有关驻留在本地服务器上的[资源](/zh/operations/workload-scheduling.md#workload_entity_storage)的信息。表中每个资源对应一行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 资源名称。
* `read_disks` ([Array(String)](/zh/sql-reference/data-types/array)) — 使用此资源进行读取操作的磁盘名称列表。
* `write_disks` ([Array(String)](/zh/sql-reference/data-types/array)) — 使用此资源进行写入操作的磁盘名称列表。
* `unit` ([String](/zh/sql-reference/data-types/string)) — 用于成本度量的资源单位。
* `create_query` ([String](/zh/sql-reference/data-types/string)) — 该资源的 CREATE 查询。

{/*AUTOGENERATED_END*/ }

示例：

```sql
SELECT *
FROM system.resources
FORMAT Vertical
```

```text
Row 1:
──────
name:         io_read
read_disks:   ['s3']
write_disks:  []
create_query: CREATE RESOURCE io_read (READ DISK s3)

Row 2:
──────
name:         io_write
read_disks:   []
write_disks:  ['s3']
create_query: CREATE RESOURCE io_write (WRITE DISK s3)
```
