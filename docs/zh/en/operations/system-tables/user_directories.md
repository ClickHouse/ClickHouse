<div id="description">
  ## 说明
</div>

包含有关已配置用户目录的信息——这些目录位于文件系统中，ClickHouse server 可从中读取用户提供的数据。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 目录的名称。
* `type` ([String](/zh/sql-reference/data-types/string)) — 访问存储的类型，例如 users.xml、replicated、memory 等。
* `params` ([String](/zh/sql-reference/data-types/string)) — 包含访问存储参数的 JSON。
* `precedence` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 该目录在 config 中的声明顺序。ClickHouse 在尝试查找用户或角色时也会使用相同的顺序。

{/*AUTOGENERATED_END*/ }
