<div id="description">
  ## 描述
</div>

列出服务器支持的数据库引擎。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 数据库引擎名称。
* `description` ([String](/zh/sql-reference/data-types/string)) — 对数据库引擎作用的高级概述。
* `syntax` ([String](/zh/sql-reference/data-types/string)) — 在 CREATE DATABASE 查询的 ENGINE 子句中指定数据库引擎的方式。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 使用示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 首次引入该数据库引擎的 ClickHouse 版本，格式为 major.minor。
* `related` ([Array](/zh/sql-reference/data-types/array)([String](/zh/sql-reference/data-types/string))) — 相关数据库引擎的名称。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

```text title="Response"
┌─name─────┐
│ Atomic   │
│ Ordinary │
```
