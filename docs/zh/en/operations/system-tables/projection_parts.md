<div id="description">
  ## 描述
</div>

此表包含 MergeTree 家族中各表的 projection parts 信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/zh/sql-reference/data-types/string)) — 分区名称。
* `name` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段名称。
* `part_type` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段的存储格式。可能的值：Wide (每列一个文件) 和 Compact (所有列共用一个文件) 。
* `parent_name` ([String](/zh/sql-reference/data-types/string)) — 源 (父) 数据分区片段的名称。
* `parent_uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — 源 (父) 数据分区片段的 UUID。
* `parent_part_type` ([String](/zh/sql-reference/data-types/string)) — 源 (父) 数据分区片段的存储格式。
* `active` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 用于指示数据分区片段是否处于活动状态的标志。如果数据分区片段处于活动状态，则会在表中使用；否则即将被删除。非活动数据分区片段会在合并和变更操作后出现。
* `marks` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 标记数量。若要获取数据分区片段中行数的近似值，可将 marks 乘以索引粒度 (通常为 8192)  (此提示不适用于自适应粒度) 。
* `rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 行数。
* `bytes_on_disk` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 所有数据分区片段文件的总大小 (以字节为单位) 。
* `data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中压缩数据的总大小。不包括所有辅助文件 (例如带有标记的文件) 。
* `data_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中未压缩数据的总大小。不包括所有辅助文件 (例如带有标记的文件) 。
* `marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 带有标记的文件的大小。
* `parent_marks` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 源 (父) 数据分区片段中的标记数量。
* `parent_rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 源 (父) 数据分区片段中的行数。
* `parent_bytes_on_disk` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 所有源 (父) 数据分区片段文件的总大小 (以字节为单位) 。
* `parent_data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 源 (父) 数据分区片段中压缩数据的总大小。
* `parent_data_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 源 (父) 数据分区片段中未压缩数据的总大小。
* `parent_marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 源 (父) 数据分区片段中带有标记的文件的大小。
* `modification_time` ([日期时间](/zh/sql-reference/data-types/datetime)) — 包含该数据分区片段的目录被修改的时间。这通常对应于数据分区片段的创建时间。
* `remove_time` ([日期时间](/zh/sql-reference/data-types/datetime)) — 数据分区片段变为非活动状态的时间。
* `refcount` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 该数据分区片段被使用的位置数量。大于 2 的值表示该数据分区片段被用于查询或合并。
* `min_date` ([Date](/zh/sql-reference/data-types/date)) — 数据分区片段中日期键的最小值。
* `max_date` ([Date](/zh/sql-reference/data-types/date)) — 数据分区片段中日期键的最大值。
* `min_time` ([日期时间](/zh/sql-reference/data-types/datetime)) — 数据分区片段中日期时间键的最小值。
* `max_time` ([日期时间](/zh/sql-reference/data-types/datetime)) — 数据分区片段中日期时间键的最大值。
* `partition_id` ([String](/zh/sql-reference/data-types/string)) — 分区 ID。
* `min_block_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 合并后构成当前数据分区片段的各数据分区片段中的最小编号。
* `max_block_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 合并后构成当前数据分区片段的各数据分区片段中的最大编号。
* `level` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 合并树的层级。0 表示当前数据分区片段是通过插入创建的，而不是由其他数据分区片段合并而成。
* `data_version` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 用于确定应对该数据分区片段应用哪些变更的版本号 (即版本高于 data&#95;version 的变更) 。
* `primary_key_bytes_in_memory` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 主键值占用的内存量 (以字节为单位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 为主键值预留的内存量 (以字节为单位) 。
* `is_frozen` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示是否存在分区数据备份的标志。1 表示备份存在，0 表示备份不存在。
* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `engine` ([String](/zh/sql-reference/data-types/string)) — 不带参数的表引擎名称。
* `disk_name` ([String](/zh/sql-reference/data-types/string)) — 存储该数据分区片段的磁盘名称。
* `path` ([String](/zh/sql-reference/data-types/string)) — 包含数据分区片段文件的目录绝对路径。
* `hash_of_all_files` ([String](/zh/sql-reference/data-types/string)) — 压缩文件的 sipHash128。
* `hash_of_uncompressed_files` ([String](/zh/sql-reference/data-types/string)) — 未压缩文件的 sipHash128 (例如带有标记、索引文件等的文件) 。
* `uncompressed_hash_of_compressed_files` ([String](/zh/sql-reference/data-types/string)) — 将压缩文件按未压缩状态计算时，其中数据的 sipHash128。
* `delete_ttl_info_min` ([日期时间](/zh/sql-reference/data-types/datetime)) — TTL DELETE 规则对应的日期时间键最小值。
* `delete_ttl_info_max` ([日期时间](/zh/sql-reference/data-types/datetime)) — TTL DELETE 规则对应的日期时间键最大值。
* `move_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — 表达式数组。每个表达式定义一条 TTL MOVE 规则。
* `move_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 日期时间值数组。每个元素表示一条 TTL MOVE 规则的最小键值。
* `move_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 日期时间值数组。每个元素表示一条 TTL MOVE 规则的最大键值。
* `default_compression_codec` ([String](/zh/sql-reference/data-types/string)) — 用于压缩此数据分区片段的 codec 名称 (当列未显式指定 codec 时) 。
* `recompression_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — TTL 表达式。
* `recompression_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此数据分区片段内计算得到的 TTL 表达式最小值。用于判断是否至少存在一行的 TTL 已过期。
* `recompression_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算出的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `group_by_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — 生存时间 (TTL) 表达式。
* `group_by_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算出的生存时间 (TTL) 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已过期。
* `group_by_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算出的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `rows_where_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — 生存时间 (TTL) 表达式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算出的生存时间 (TTL) 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已过期。
* `rows_where_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算出的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `is_broken` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 投影分片是否损坏
* `exception_code` ([Int32](/zh/sql-reference/data-types/int-uint)) — 用于说明投影分片损坏状态的异常消息
* `exception` ([String](/zh/sql-reference/data-types/string)) — 用于说明投影分片损坏状态的异常代码

**别名：**

* `bytes` — `bytes_on_disk` 的别名。
* `marks_size` — `marks_bytes` 的别名。
* `part_name` — `name` 的别名。
