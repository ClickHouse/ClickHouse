<div id="description">
  ## 描述
</div>

包含各个 Replicated 数据库副本的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 所属 Replicated 数据库的名称。
* `is_readonly` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 数据库副本是否处于只读模式。
* `max_log_ptr` ([Int32](/zh/sql-reference/data-types/int-uint)) — 常规活动日志中的最大条目编号。
* `replica_name` ([String](/zh/sql-reference/data-types/string)) — ClickHouse Keeper 中的副本名称。
* `replica_path` ([String](/zh/sql-reference/data-types/string)) — ClickHouse Keeper 中副本数据的路径。
* `zookeeper_path` ([String](/zh/sql-reference/data-types/string)) — ClickHouse Keeper 中数据库数据的路径。
* `shard_name` ([String](/zh/sql-reference/data-types/string)) — 集群中分片的名称。
* `log_ptr` ([Int32](/zh/sql-reference/data-types/int-uint)) — 副本复制到其执行队列中的常规活动日志最大条目编号加一。
* `total_replicas` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 此数据库已知的副本总数。
* `zookeeper_exception` ([String](/zh/sql-reference/data-types/string)) — 上一次异常信息；如果在从 ClickHouse Keeper 拉取信息时发生错误，则会显示该消息。
* `is_session_expired` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 与 ClickHouse Keeper 的会话已过期。基本上与 `is_readonly` 相同。

{/*AUTOGENERATED_END*/ }
