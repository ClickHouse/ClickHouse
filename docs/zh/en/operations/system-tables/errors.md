<div id="description">
  ## 描述
</div>

包含错误代码及其触发次数。

要显示所有可能的错误代码 (包括未触发的错误代码) ，请将设置 [system&#95;events&#95;show&#95;zero&#95;values](../settings/settings.md#system_events_show_zero_values) 设为 1。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 错误名称 (errorCodeToName) 。
* `code` ([Int32](/zh/sql-reference/data-types/int-uint)) — 错误代码编号。
* `value` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 此错误发生的次数。
* `last_error_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 最近一次发生错误的时间。
* `last_error_message` ([String](/zh/sql-reference/data-types/string)) — 最近一次错误的消息。
* `last_error_format_string` ([String](/zh/sql-reference/data-types/string)) — 最近一次错误的格式字符串。
* `last_error_trace` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 栈追踪，表示存储被调用方法的物理地址列表。
* `remote` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 远程异常 (即在某次分布式查询期间接收到的异常) 。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 导致错误的查询 ID (如果可用) 。

{/*AUTOGENERATED_END*/ }

:::note
即使查询已成功执行，某些错误的计数器也可能会增加。除非您确定相应错误不可能是误报，否则不建议将此表用于服务器监控。
:::

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
