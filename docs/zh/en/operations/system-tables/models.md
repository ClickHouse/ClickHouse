<div id="description">
  ## 描述
</div>

包含已加载到 LibraryBridge 内存中的 CatBoost 模型列表，以及各模型的加载时间。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `model_path` ([String](/zh/sql-reference/data-types/string)) — 训练好的模型路径。
* `type` ([String](/zh/sql-reference/data-types/string)) — 模型类型。目前仅支持 catboost。
* `loading_start_time` ([日期时间](/zh/sql-reference/data-types/datetime)) — 模型开始加载的时间。
* `loading_duration` ([Float32](/zh/sql-reference/data-types/float)) — 加载模型所耗费的时间。

{/*AUTOGENERATED_END*/ }
