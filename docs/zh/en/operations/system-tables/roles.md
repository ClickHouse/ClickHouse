<div id="description">
  ## 描述
</div>

包含已配置[角色](../../guides/sre/user-management/index.md#role-management)的相关信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 角色名称。
* `id` ([UUID](/zh/sql-reference/data-types/uuid)) — 角色 ID。
* `storage` ([String](/zh/sql-reference/data-types/string)) — 角色存储路径。在 `access_control_path` 参数中配置。

{/*AUTOGENERATED_END*/ }
