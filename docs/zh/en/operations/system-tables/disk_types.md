<div id="description">
  ## 描述
</div>

包含服务器支持的磁盘类型列表，以及每种类型的内嵌文档。磁盘类型在磁盘配置的 `type` 中指定，用于确定磁盘在何处以及如何存储其数据 (本地文件系统、对象存储、另一块磁盘上的缓存等) 。

请注意，此表列出的是可用的磁盘*类型*，而 [`system.disks`](/zh/operations/system-tables/disks) 列出的是服务器上配置的磁盘实例。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 磁盘类型的名称，即磁盘配置中 `type` 指定的值。
* `description` ([String](/zh/sql-reference/data-types/string)) — 对该磁盘类型用途的概括性描述。
* `syntax` ([String](/zh/sql-reference/data-types/string)) — 该磁盘类型在磁盘配置中的指定方式。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 使用示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 该磁盘类型首次引入的 ClickHouse 版本，格式为 major.minor。
* `related` ([Array](/zh/sql-reference/data-types/array)([String](/zh/sql-reference/data-types/string))) — 相关磁盘类型的名称。

{/*AUTOGENERATED_END*/ }

<div id="configuration-examples">
  ## 配置示例
</div>

磁盘可以通过两种方式配置：**静态**方式是在服务器配置文件 (XML 或 YAML) 中配置；**动态**方式是在 `CREATE`/`ATTACH` 查询的设置中使用 `disk` 函数进行配置。这两种方式都支持相同的磁盘类型和参数。

<div id="static-configuration">
  ### 静态配置
</div>

磁盘在服务器配置的 `storage_configuration` 下定义。以下示例定义了一个 `s3` 磁盘，以及一个使用该磁盘的存储策略。

```xml title="config.xml"
<clickhouse>
    <storage_configuration>
        <disks>
            <s3_disk>
                <type>s3</type>
                <endpoint>https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/</endpoint>
                <use_environment_credentials>1</use_environment_credentials>
            </s3_disk>
        </disks>
        <policies>
            <s3_policy>
                <volumes>
                    <main>
                        <disk>s3_disk</disk>
                    </main>
                </volumes>
            </s3_policy>
        </policies>
    </storage_configuration>
</clickhouse>
```

相同配置的 YAML 形式：

```yaml title="config.yaml"
storage_configuration:
  disks:
    s3_disk:
      type: s3
      endpoint: https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/
      use_environment_credentials: 1
  policies:
    s3_policy:
      volumes:
        main:
          disk: s3_disk
```

随后，该表即可通过其存储策略使用该磁盘：

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS storage_policy = 's3_policy';
```

<div id="dynamic-configuration">
  ### 动态配置
</div>

也可以直接在 `CREATE`/`ATTACH` 查询的设置中定义磁盘，无需在配置文件中预先定义磁盘，方法是使用 `disk` 函数：

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS disk = disk(
    type = s3,
    endpoint = 'https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/',
    use_environment_credentials = 1
);
```

请参阅[配置外部存储](/zh/operations/storing-data)，了解每种磁盘类型的完整参数列表。

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT name, description
FROM system.disk_types
WHERE name IN ('local', 'object_storage')
ORDER BY name
```
