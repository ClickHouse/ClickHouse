<div id="description">
  ## 说明
</div>

列出所有可用的分词器。
它们可用于函数 [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens)、[hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens)、[hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens) 以及 [文本索引](../../engines/table-engines/mergetree-family/textindexes.md) 中。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 分词器名称

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT * FROM system.tokenizers;
```

```text
┌─name────────────┐
│ ngrams          │
│ splitByNonAlpha │
│ sparseGrams     │
│ tokenbf_v1      │
│ ngrambf_v1      │
│ array           │
│ splitByString   │
│ sparse_grams    │
│ asciiCJK        │
└─────────────────┘
```
