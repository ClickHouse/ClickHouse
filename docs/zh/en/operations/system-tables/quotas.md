<div id="description">
  ## 描述
</div>

包含[QUOTA](../../operations/system-tables/quotas.md)的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — QUOTA名称。
* `id` ([UUID](/zh/sql-reference/data-types/uuid)) — QUOTA ID。
* `storage` ([String](/zh/sql-reference/data-types/string)) — QUOTA的 Storage。可能的值：如果QUOTA在 users.xml 文件中配置，则为 &#39;users.xml&#39;；如果QUOTA通过 SQL 查询配置，则为 &#39;disk&#39;。
* `keys` ([Array(Enum8(&#39;user&#95;name&#39; = 1, &#39;ip&#95;address&#39; = 2, &#39;forwarded&#95;ip&#95;address&#39; = 3, &#39;client&#95;key&#39; = 4, &#39;normalized&#95;query&#95;hash&#39; = 7))](/zh/sql-reference/data-types/array)) — 键值指定QUOTA的共享方式。如果两个连接使用相同的QUOTA和键值，它们将共享相同额度的资源。取值：[] — 所有用户共享同一个QUOTA，[&#39;user&#95;name&#39;] — 用户名相同的连接共享同一个QUOTA，[&#39;ip&#95;address&#39;] — 来自同一 IP 的连接共享同一个QUOTA。[&#39;client&#95;key&#39;] — 具有相同键值的连接共享同一个QUOTA。键值必须由客户端显式提供。使用 clickhouse-client 时，可通过 --quota&#95;key 参数传递键值，或者在客户端配置文件中使用 quota&#95;key 参数。使用 HTTP interface 时，请使用 X-ClickHouse-Quota 请求头，[&#39;user&#95;name&#39;, &#39;client&#95;key&#39;] — 具有相同 client&#95;key 的连接共享同一个QUOTA。如果客户端未提供键值，则按 `user_name` 跟踪QUOTA，[&#39;client&#95;key&#39;, &#39;ip&#95;address&#39;] — 具有相同 client&#95;key 的连接共享同一个QUOTA。如果客户端未提供键值，则按 ip&#95;address 跟踪QUOTA。
* `durations` ([Array(UInt32)](/zh/sql-reference/data-types/array)) — 以秒为单位的时间间隔长度。
* `apply_to_all` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 逻辑值，表示QUOTA应用于哪些用户。取值：0 — QUOTA应用于 apply&#95;to&#95;list 中指定的用户。1 — QUOTA应用于除 apply&#95;to&#95;except 中列出的用户之外的所有用户。
* `apply_to_list` ([Array(String)](/zh/sql-reference/data-types/array)) — 应用此QUOTA的用户名/角色列表。
* `apply_to_except` ([Array(String)](/zh/sql-reference/data-types/array)) — 不应用此QUOTA的用户名/角色列表。
* `ipv4_prefix_bits` ([Nullable(UInt8)](/zh/sql-reference/data-types/nullable)) — IPv4 地址掩码的前缀位数。来自同一子网的连接共享同一个QUOTA。仅在 key 为 `ip_address` 或 `forwarded_ip_address` 时使用。
* `ipv6_prefix_bits` ([Nullable(UInt8)](/zh/sql-reference/data-types/nullable)) — IPv6 地址掩码的前缀位数。来自同一子网的连接共享同一个QUOTA。仅在 key 为 `ip_address` 或 `forwarded_ip_address` 时使用。

{/*AUTOGENERATED_END*/ }
