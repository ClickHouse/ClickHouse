<div id="description">
  ## 描述
</div>

该表包含当前用户的已启用角色。`SET ROLE` 会更改此表中的内容。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/zh/sql-reference/data-types/string)) — 角色名称。
* `with_admin_option` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果角色具有 ADMIN OPTION 权限，则值为 1。
* `is_default` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果该角色被设为默认角色，则值为 1。

{/*AUTOGENERATED_END*/ }
