<div id="description">
  ## 说明
</div>

包含有关已缓存 DNS 记录的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([String](/zh/sql-reference/data-types/string)) — 主机名。
* `ip_address` ([String](/zh/sql-reference/data-types/string)) — IP 地址。
* `ip_family` ([Enum8(&#39;IPv4&#39; = 0, &#39;IPv6&#39; = 1, &#39;UNIX&#95;LOCAL&#39; = 2)](/zh/sql-reference/data-types/enum)) — IP 地址族。
* `cached_at` ([日期时间](/zh/sql-reference/data-types/datetime)) — 记录被缓存的时间戳。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT * FROM system.dns_cache;
```

| hostname  | ip&#95;address | ip&#95;family | cached&#95;at       |
| :-------- | :------------- | :------------ | :------------------ |
| localhost | ::1            | IPv6          | 2024-02-11 17:04:40 |
| localhost | 127.0.0.1      | IPv4          | 2024-02-11 17:04:40 |
