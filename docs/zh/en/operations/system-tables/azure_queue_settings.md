<div id="description">
  ## 描述
</div>

包含有关 [AzureQueue](../../engines/table-engines/integrations/azure-queue.md) 表设置的信息。
自 `24.10` 版本的服务器起可用。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 使用 AzureQueue engine 的表所在的数据库。
* `table` ([String](/zh/sql-reference/data-types/string)) — 使用 AzureQueue engine 的表的名称。
* `name` ([String](/zh/sql-reference/data-types/string)) — 设置名称。
* `value` ([String](/zh/sql-reference/data-types/string)) — 设置值。
* `type` ([String](/zh/sql-reference/data-types/string)) — 设置类型 (实现相关的字符串值) 。
* `changed` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果该设置是在 config 中显式定义或被显式更改的，则值为 1。
* `description` ([String](/zh/sql-reference/data-types/string)) — 设置说明。
* `alterable` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示当前用户是否可以通过 ALTER TABLE MODIFY SETTING 更改该设置：0 — 当前用户不能更改该设置，1 — 当前用户可以更改该设置。

{/*AUTOGENERATED_END*/ }
