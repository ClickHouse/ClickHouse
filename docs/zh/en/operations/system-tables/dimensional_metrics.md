<div id="description">
  ## 说明
</div>

此表包含可即时计算并以 Prometheus 格式导出的维度指标，并且始终为最新状态。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/zh/sql-reference/data-types/string)) — 指标名称。
* `value` ([Float64](/zh/sql-reference/data-types/float)) — 指标值。
* `description` ([String](/zh/sql-reference/data-types/string)) — 指标描述。
* `labels` ([Map(String, String)](/zh/sql-reference/data-types/map)) — 指标标签。

**别名：**

* `name` — `metric` 的别名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

你可以使用如下查询，以 Prometheus 格式导出所有维度指标。

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## 指标说明
</div>

<div id="merge_failures">
  ### merge_failures
</div>

自启动以来所有合并失败的次数。

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

按错误类型标示启动脚本失败；当启动脚本失败时，该值设为 1，并带有错误名称标签。

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

MergeTree 数据分区片段的数量，标签包括分区片段状态、分区片段类型，以及是否为投影分区片段。

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

从文件系统缓存中逐出的 File 段数量，按缓存名称标记。默认禁用；可通过 `expose_prometheus_eviction_metrics` 启用。

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

从文件系统缓存中淘汰的 File 段总字节数，按缓存名称区分。默认禁用；可通过 `expose_prometheus_eviction_metrics` 启用。

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

从文件系统缓存中被驱逐的 File 段数量，按缓存名称和用户 ID 标记。默认禁用；可通过 `expose_prometheus_eviction_metrics` 和 `expose_prometheus_eviction_metrics_per_user` 启用。

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

从文件系统缓存中逐出的 File 段总字节数，按缓存名称和用户 ID 区分。默认禁用；可通过 `expose_prometheus_eviction_metrics` 和 `expose_prometheus_eviction_metrics_per_user` 启用。
