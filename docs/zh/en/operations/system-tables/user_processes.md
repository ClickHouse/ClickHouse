<div id="description">
  ## 描述
</div>

此系统表可用于概览用户的内存使用情况和 ProfileEvents。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `user` ([String](/zh/sql-reference/data-types/string)) — 用户名。
* `memory_usage` ([Int64](/zh/sql-reference/data-types/int-uint)) — 该用户所有进程使用的 RAM 总量。它可能不包括某些类型的专用内存。请参见 max&#95;memory&#95;usage 设置。
* `peak_memory_usage` ([Int64](/zh/sql-reference/data-types/int-uint)) — 该用户的内存使用峰值。当该用户没有运行任何查询时，此值可能会被重置。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/zh/sql-reference/data-types/map)) — ProfileEvents 的汇总，用于衡量该用户的不同指标。相关说明可在 system.events 表中找到。

**别名：**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)` 的别名。
* `ProfileEvents.Values` — `mapValues(ProfileEvents)` 的别名。

{/*AUTOGENERATED_END*/ }
