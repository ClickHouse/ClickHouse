<div id="description">
  ## 描述
</div>

包含驻留在本地服务器上的 [workloads](/zh/operations/workload-scheduling.md#workload_entity_storage) 信息。表中每个 工作负载 对应一行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 工作负载的名称。
* `parent` ([String](/zh/sql-reference/data-types/string)) — 父级工作负载的名称。
* `create_query` ([String](/zh/sql-reference/data-types/string)) — 该工作负载的 CREATE 查询。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT *
FROM system.workloads
FORMAT Vertical
```

```text
Row 1:
──────
name:         production
parent:       all
create_query: CREATE WORKLOAD production IN `all` SETTINGS weight = 9

Row 2:
──────
name:         development
parent:       all
create_query: CREATE WORKLOAD development IN `all`

Row 3:
──────
name:         all
parent:
create_query: CREATE WORKLOAD `all`
```
