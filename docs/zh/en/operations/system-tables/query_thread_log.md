<div id="description">
  ## 描述
</div>

包含执行查询的线程信息，例如线程名称、线程开始时间、查询处理耗时。

要启用日志记录：

1. 在 [query&#95;thread&#95;log](/zh/operations/server-configuration-parameters/settings#query_thread_log) 部分配置参数。
2. 将 [log&#95;query&#95;threads](/zh/operations/settings/settings#log_query_threads) 设置为 1。

数据刷写周期在 [query&#95;thread&#95;log](/zh/operations/server-configuration-parameters/settings#query_thread_log) 服务器设置部分的 `flush_interval_milliseconds` 参数中设置。若要强制刷写，请使用 [SYSTEM FLUSH LOGS](/zh/sql-reference/statements/system#flush-logs) 查询。

ClickHouse 不会自动从表中删除数据。更多信息，请参见 [Introduction](/zh/operations/system-tables/overview#system-tables-introduction)。

你可以使用 [log&#95;queries&#95;probability](/zh/operations/settings/settings#log_queries_probability)) 设置来减少记录到 `query_thread_log` 表中的查询数量。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 执行该查询的服务器主机名。
* `event_date` ([Date](/zh/sql-reference/data-types/date)) — 线程完成该查询执行时的日期。
* `event_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 线程完成该查询执行时的日期和时间。
* `event_time_microseconds` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 线程完成该查询执行时的日期和时间，精确到微秒。
* `query_start_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 查询开始执行的时间。
* `query_start_time_microseconds` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 查询开始执行的时间，精确到微秒。
* `query_duration_ms` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 查询执行耗时。
* `read_rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 读取的行数。
* `read_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 读取的字节数。
* `written_rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 对于 INSERT 查询，表示写入的行数。对于其他查询，该列的值为 0。
* `written_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 对于 INSERT 查询，表示写入的字节数。对于其他查询，该列的值为 0。
* `memory_usage` ([Int64](/zh/sql-reference/data-types/int-uint)) — 该线程上下文中已分配内存与已释放内存之差。
* `peak_memory_usage` ([Int64](/zh/sql-reference/data-types/int-uint)) — 该线程上下文中已分配内存与已释放内存之间的最大差值。
* `thread_name` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 线程名称。
* `thread_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 内部线程 ID。
* `master_thread_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 初始线程的操作系统 ID。
* `current_database` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 当前数据库的名称。
* `query` ([String](/zh/sql-reference/data-types/string)) — 查询字符串。
* `normalized_query_hash` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 归一化查询的哈希值，即去除了常量等内容后的查询哈希值。
* `is_initial_query` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 查询类型。可能的值：1 — 查询由客户端发起，0 — 查询由另一个查询发起，用于分布式查询执行。
* `connection_address` ([IPv6](/zh/sql-reference/data-types/ipv6)) — 建立连接的客户端 IP 地址。通过代理连接时，这里将是代理的地址。
* `connection_port` ([UInt16](/zh/sql-reference/data-types/int-uint)) — 建立连接的客户端端口。通过代理连接时，这里将是代理的端口。
* `user` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 发起当前查询的用户名。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 查询 ID。
* `address` ([IPv6](/zh/sql-reference/data-types/ipv6)) — 用于发起查询的 IP 地址。通过代理连接且设置了 `auth_use_forwarded_address` 时，这里将是客户端的地址而不是代理的地址。
* `port` ([UInt16](/zh/sql-reference/data-types/int-uint)) — 用于发起查询的客户端端口。通过代理连接且设置了 `auth_use_forwarded_address` 时，这里显示的是客户端端口，而不是代理端口。
* `initial_user` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 运行初始查询的用户名 (用于分布式查询执行) 。
* `initial_query_id` ([String](/zh/sql-reference/data-types/string)) — 初始查询的 ID (用于分布式查询执行) 。
* `initial_address` ([IPv6](/zh/sql-reference/data-types/ipv6)) — 发起父查询的源 IP 地址。
* `initial_port` ([UInt16](/zh/sql-reference/data-types/int-uint)) — 用于发起父查询的客户端端口。
* `initial_query_start_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 初始查询开始执行的时间。
* `initial_query_start_time_microseconds` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 初始查询开始执行的时间
* `authenticated_user` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 会话中完成身份验证的用户名。
* `interface` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 发起查询所使用的接口。可能的值：1 — TCP，2 — HTTP。
* `is_secure` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示连接是否安全的标志。
* `os_user` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 运行 ClickHouse 客户端的操作系统用户名。
* `client_hostname` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 运行 ClickHouse 客户端或其他 TCP 客户端的客户端机器的主机名。
* `client_name` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — ClickHouse 客户端或其他 TCP 客户端的名称。
* `client_agent` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 调用该客户端的 AI 编码代理 (例如 `claude-code` 或 `cursor`) ，根据环境变量检测得出。若未检测到代理，则为空。
* `client_revision` ([UInt32](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端的修订版本。
* `client_version_major` ([UInt32](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端的主版本号。
* `client_version_minor` ([UInt32](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端的次版本号。
* `client_version_patch` ([UInt32](/zh/sql-reference/data-types/int-uint)) — ClickHouse 客户端或其他 TCP 客户端版本的补丁版本号。
* `script_query_number` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 多查询脚本中的顺序查询编号。
* `script_line_number` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 多查询脚本中当前查询起始所在的行号。
* `http_method` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 发起查询的 HTTP 方法。可能的值：0 — 查询从 TCP 接口发起，1 — 使用 GET 方法，2 — 使用 POST 方法。
* `http_user_agent` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — HTTP 请求中传递的 UserAgent 请求头。
* `http_referer` ([String](/zh/sql-reference/data-types/string)) — HTTP 查询中传递的 `Referer` HTTP 请求头 (包含发起查询的页面的完整或部分地址) 。
* `forwarded_for` ([String](/zh/sql-reference/data-types/string)) — HTTP 查询中传递的 `X-Forwarded-For` HTTP 请求头。
* `quota_key` ([String](/zh/sql-reference/data-types/string)) — quotas 设置中指定的“配额键”。
* `distributed_depth` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 查询在服务器之间被转发的次数。
* `revision` ([UInt32](/zh/sql-reference/data-types/int-uint)) — ClickHouse 修订版本。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/zh/sql-reference/data-types/map)) — 用于衡量该线程不同指标的 ProfileEvents。其说明可在 `system.events` 表中找到。

**别名：**

* `ProfileEvents.Names` — 是 `mapKeys(ProfileEvents)` 的别名。
* `ProfileEvents.Values` — 是 `mapValues(ProfileEvents)` 的别名。
