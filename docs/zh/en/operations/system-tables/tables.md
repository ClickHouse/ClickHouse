<div id="description">
  ## 描述
</div>

包含服务器所知的每个表的元数据。

[Detached](../../sql-reference/statements/detach.md) 表不会显示在 `system.tables` 中。

[临时表](../../sql-reference/statements/create/table.md#temporary-tables) 仅会在创建它们的会话中的 `system.tables` 里可见。它们的 `database` 字段为空，且 `is_temporary` 标志已启用。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 该表所在数据库的名称。
* `name` ([String](/zh/sql-reference/data-types/string)) — 表名。
* `uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — 表的 uuid (Atomic 数据库) 。
* `engine` ([String](/zh/sql-reference/data-types/string)) — 表引擎名称 (不含参数) 。
* `is_temporary` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该表是否为临时表的标志。
* `data_paths` ([Array(String)](/zh/sql-reference/data-types/array)) — 文件系统中该表数据的路径。
* `metadata_path` ([String](/zh/sql-reference/data-types/string)) — 文件系统中该表元数据的路径。
* `metadata_modification_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 表元数据的最后修改时间。
* `metadata_version` ([Int32](/zh/sql-reference/data-types/int-uint)) — ReplicatedMergeTree 表的元数据版本；非 ReplicatedMergeTree 表为 0。
* `dependencies_database` ([Array(String)](/zh/sql-reference/data-types/array)) — 数据库依赖项。
* `dependencies_table` ([Array(String)](/zh/sql-reference/data-types/array)) — 表依赖项 (即当前表的 materialized views) 。
* `create_table_query` ([String](/zh/sql-reference/data-types/string)) — 用于创建该表的查询。
* `engine_full` ([String](/zh/sql-reference/data-types/string)) — 表引擎参数。
* `as_select` ([String](/zh/sql-reference/data-types/string)) — 视图对应的 SELECT 查询。
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/zh/sql-reference/data-types/array)) — parameterized view 的参数。
* `partition_key` ([String](/zh/sql-reference/data-types/string)) — 表中指定的分区键表达式。
* `sorting_key` ([String](/zh/sql-reference/data-types/string)) — 表中指定的排序键表达式。
* `primary_key` ([String](/zh/sql-reference/data-types/string)) — 表中指定的主键表达式。
* `sampling_key` ([String](/zh/sql-reference/data-types/string)) — 表中指定的采样键表达式。
* `storage_policy` ([String](/zh/sql-reference/data-types/string)) — 存储策略。适用于使用 MergeTree 和 Distributed 引擎的表。
* `total_rows` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 总行数；如果能快速确定表中的精确行数，则返回该值，否则返回 NULL (包括底层 Buffer 表) 。
* `total_bytes` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 总字节数；如果能快速确定该表在存储上的精确字节数，则返回该值，否则返回 NULL (不包括任何底层存储) 。如果表将数据存储在磁盘上，则返回磁盘已用空间 (即压缩后的大小) 。如果表将数据存储在内存中，则返回内存中已用字节数的近似值。
* `total_bytes_uncompressed` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 未压缩总字节数；如果能根据该表在存储上的 parts 校验和快速确定精确字节数，则返回该值，否则返回 NULL (不考虑底层存储 (如果有) ) 。
* `parts` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 该表中的 parts 总数。
* `active_parts` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 该表中的活跃 parts 数量。
* `total_marks` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 此表中所有 parts 的标记总数。
* `active_on_fly_data_mutations` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 适合即时应用的活动数据变更总数 (UPDATE 和 DELETE) 。
* `active_on_fly_alter_mutations` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 适合即时应用的活动 ALTER 变更总数 (MODIFY COLUMN) 。
* `active_on_fly_metadata_mutations` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 适合即时应用的活动元数据变更总数 (RENAME) 。
* `columns_descriptions_cache_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — *MergeTree 表的列描述缓存大小
* `lifetime_rows` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 自服务器启动以来 INSERT 的总行数 (仅适用于 Buffer 表) 。
* `lifetime_bytes` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 自服务器启动以来 INSERT 的总字节数 (仅适用于 Buffer 表) 。
* `comment` ([String](/zh/sql-reference/data-types/string)) — 表的注释。
* `has_own_data` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该表自身是否在磁盘上存储数据，还是仅访问其他来源的标志。
* `loading_dependencies_database` ([Array(String)](/zh/sql-reference/data-types/array)) — 数据库加载依赖项 (应在当前对象之前加载的对象列表) 。
* `loading_dependencies_table` ([Array(String)](/zh/sql-reference/data-types/array)) — 表加载依赖项 (应在当前对象之前加载的对象列表) 。
* `loading_dependent_database` ([Array(String)](/zh/sql-reference/data-types/array)) — 依赖于当前对象加载的数据库。
* `loading_dependent_table` ([Array(String)](/zh/sql-reference/data-types/array)) — 依赖于当前对象加载的表。
* `target_database` ([String](/zh/sql-reference/data-types/string)) — 对于 materialized view，这是该视图写入的目标端表所在的数据库 (`TO` 目标，或隐式的 `.inner.*` 表) 。对于其他引擎，此值为空。
* `target_table` ([String](/zh/sql-reference/data-types/string)) — 对于 materialized view，这是该视图写入的目标端表名称 (`TO` 目标，或隐式的 `.inner.*` 表) 。对于其他引擎，此值为空。
* `definer` ([String](/zh/sql-reference/data-types/string)) — 该表使用的 SQL SECURITY DEFINER 名称。

**别名：**

* `table` — `name` 的别名。

{/*AUTOGENERATED_END*/ }
