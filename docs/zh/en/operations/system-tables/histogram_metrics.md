<div id="description">
  ## 描述
</div>

此表包含可即时计算并以 Prometheus 格式导出的直方图指标。它始终保持最新状态，可替代已弃用的 `system.latency_log`。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/zh/sql-reference/data-types/string)) — 指标名称。
* `value` ([Float64](/zh/sql-reference/data-types/float)) — 指标值。
* `description` ([String](/zh/sql-reference/data-types/string)) — 指标说明。
* `labels` ([Map(String, String)](/zh/sql-reference/data-types/map)) — 指标标记。

**别名：**

* `name` — `metric` 的别名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

你可以使用如下查询，以 Prometheus 格式导出所有直方图指标。

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'histogram' AS type
FROM system.histogram_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## 指标说明
</div>

| 指标                                                           | 描述                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------ |
| `keeper_response_time_ms_bucket`                             | Keeper 的响应时间，以毫秒为单位。                                   |
| `keeper_client_queue_duration_milliseconds_bucket`           | 请求在由 Keeper 客户端处理前，等待入队以及在队列中等待的时间，以毫秒为单位。             |
| `keeper_receive_request_time_milliseconds_bucket`            | 在 Keeper TCP 处理器中，从客户端接收并解析请求所需的时间，以毫秒为单位。             |
| `keeper_dispatcher_requests_queue_time_milliseconds_bucket`  | 请求在 Keeper dispatcher requests queue 中等待的时间，以毫秒为单位。    |
| `keeper_write_pre_commit_time_milliseconds_bucket`           | 写入请求在 Raft commit 前进行预处理所需的时间，以毫秒为单位。                  |
| `keeper_write_commit_time_milliseconds_bucket`               | 写入请求在 Raft commit 后处理所需的时间，以毫秒为单位。                     |
| `keeper_dispatcher_responses_queue_time_milliseconds_bucket` | 响应在 Keeper dispatcher 响应队列中等待的时间，以毫秒为单位。               |
| `keeper_send_response_time_milliseconds_bucket`              | 在 Keeper TCP 处理器中向客户端发送响应所需的时间 (包括排队等待和写入套接字) ，以毫秒为单位。 |
| `keeper_read_wait_for_write_time_milliseconds_bucket`        | 读取请求等待其依赖的写入请求完成所需的时间，以毫秒为单位。                          |
| `keeper_read_process_time_milliseconds_bucket`               | 在 Keeper 中处理读取请求所需的时间，以毫秒为单位。                          |
| `keeper_batch_size_elements_bucket`                          | 发送到 Raft 的批次大小，以元素数计。                                  |
| `keeper_batch_size_bytes_bucket`                             | 发送到 Raft 的批次大小，以字节计。                                   |
| `filesystem_cache_evicted_segment_hits_bucket`               | File 段在被驱逐时的缓存命中次数分布，按缓存名称标记。                          |
| `filesystem_cache_evicted_segment_size_bytes_bucket`         | 被驱逐的 File 段的字节大小分布，按缓存名称标记。                            |
| `filesystem_cache_evicted_segment_hits_by_user_bucket`       | 被驱逐的 File 段的缓存命中次数分布，按缓存名称和用户 ID 标记。                   |
| `filesystem_cache_evicted_segment_size_bytes_by_user_bucket` | 被驱逐的 File 段的字节大小分布，按缓存名称和用户 ID 标记。                     |
