<div id="purpose">
  ## 描述
</div>

包含 [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) 表的 detached parts 相关信息。`reason` 列用于说明该 part 被 detached 的原因。

对于由用户 detached 的 parts，reason 为空。这类 parts 可以使用 [ALTER TABLE ATTACH PARTITION|PART](/zh/sql-reference/statements/alter/partition#attach-partitionpart) 命令重新附加。

有关其他列的说明，请参见 [system.parts](../../operations/system-tables/parts.md)。

如果 part 名称无效，某些列的值可能为 `NULL`。这类 parts 可以使用 [ALTER TABLE DROP DETACHED PART](/zh/sql-reference/statements/alter/partition#drop-detached-partitionpart) 删除。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 该数据分区片段所属数据库的名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 该数据分区片段所属表的名称。
* `partition_id` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 该数据分区片段所属分区的标识符。
* `name` ([String](/zh/sql-reference/data-types/string)) — 该数据分区片段的名称。
* `bytes_on_disk` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 该数据分区片段所有文件的总大小，以字节为单位。
* `modification_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 包含该数据分区片段的目录的修改时间。通常对应于执行 detach 的时间。
* `disk` ([String](/zh/sql-reference/data-types/string)) — 存储该数据分区片段的磁盘名称。
* `path` ([String](/zh/sql-reference/data-types/string)) — 磁盘上该数据分区片段文件的路径。
* `reason` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 该数据分区片段被 detached 的原因说明。
* `min_block_number` ([Nullable(Int64)](/zh/sql-reference/data-types/nullable)) — 合并后构成当前数据分区片段的最小数据分区片段编号。
* `max_block_number` ([Nullable(Int64)](/zh/sql-reference/data-types/nullable)) — 合并后构成当前数据分区片段的最大数据分区片段编号。
* `level` ([Nullable(UInt32)](/zh/sql-reference/data-types/nullable)) — 合并树的深度。0 表示当前数据分区片段是通过 insert 创建的，而不是通过合并其他 parts 创建的。

{/*AUTOGENERATED_END*/ }
