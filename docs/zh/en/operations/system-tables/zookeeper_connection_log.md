<div id="description">
  ## 描述
</div>

`system.zookeeper_connection_log` 表显示 ZooKeeper 连接 (包括辅助 ZooKeepers) 的历史记录。每一行都展示一条与连接相关事件的信息。

:::note
该表不包含因服务器关闭而导致的连接断开事件。
:::

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 已连接到 ZooKeeper 或已从 ZooKeeper 断开连接的 server 的主机名。
* `type` ([Enum8(&#39;Connected&#39; = 0, &#39;Disconnected&#39; = 1)](/zh/sql-reference/data-types/enum)) — 事件类型。Possible values：Connected、Disconnected。
* `event_date` ([Date](/zh/sql-reference/data-types/date)) — 条目的日期。
* `event_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 条目的时间
* `event_time_microseconds` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 精确到微秒的条目时间。
* `name` ([String](/zh/sql-reference/data-types/string)) — ZooKeeper cluster 的名称。
* `host` ([String](/zh/sql-reference/data-types/string)) — ClickHouse 连接到或断开连接的 ZooKeeper 节点的主机名/IP。
* `port` ([UInt16](/zh/sql-reference/data-types/int-uint)) — ClickHouse 连接到或断开连接的 ZooKeeper 节点的端口。
* `index` ([UInt8](/zh/sql-reference/data-types/int-uint)) — ClickHouse 连接到或断开连接的 ZooKeeper 节点的索引。该索引来自 ZooKeeper config。
* `client_id` ([Int64](/zh/sql-reference/data-types/int-uint)) — connection 的 session ID。
* `keeper_api_version` ([UInt8](/zh/sql-reference/data-types/int-uint)) — Keeper API 版本。
* `enabled_feature_flags` ([Array(Enum16(&#39;FILTERED&#95;LIST&#39; = 0, &#39;MULTI&#95;READ&#39; = 1, &#39;CHECK&#95;NOT&#95;EXISTS&#39; = 2, &#39;CREATE&#95;IF&#95;NOT&#95;EXISTS&#39; = 3, &#39;REMOVE&#95;RECURSIVE&#39; = 4, &#39;MULTI&#95;WATCHES&#39; = 5, &#39;CHECK&#95;STAT&#39; = 6, &#39;PERSISTENT&#95;WATCHES&#39; = 7, &#39;CREATE&#95;WITH&#95;STATS&#39; = 8, &#39;TRY&#95;REMOVE&#95;RECURSIVE&#39; = 9, &#39;LIST&#95;WITH&#95;STAT&#95;AND&#95;DATA&#39; = 10, &#39;GET&#95;CHILDREN&#95;RECURSIVE&#39; = 11))](/zh/sql-reference/data-types/array)) — 已启用的功能开关。仅适用于 ClickHouse Keeper。
* `availability_zone` ([String](/zh/sql-reference/data-types/string)) — 可用区
* `reason` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 连接或断开连接的原因。

{/*AUTOGENERATED_END*/ }

```sql
SELECT * FROM system.zookeeper_connection_log;
```
