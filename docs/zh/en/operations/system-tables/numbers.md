<div id="description">
  ## 描述
</div>

此表包含一个名为 `number` 的 UInt64 列，其中包含几乎所有从零开始的自然数。

你可以将此表用于测试，或在需要进行暴力搜索时使用。

对此表的读取不会并行执行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `number` ([UInt64](/zh/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }
