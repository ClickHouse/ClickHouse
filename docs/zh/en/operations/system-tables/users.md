<div id="description">
  ## 说明
</div>

包含服务器上已配置的[用户账户](../../guides/sre/user-management/index.md#user-account-management)列表。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 用户名。
* `id` ([UUID](/zh/sql-reference/data-types/uuid)) — 用户 ID。
* `storage` ([String](/zh/sql-reference/data-types/string)) — 用户存储路径。在 access&#95;control&#95;path 参数中配置。
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/zh/sql-reference/data-types/array)) — 显示身份验证类型。用户身份验证有多种方式：无密码、明文密码、SHA256 编码密码、双重 SHA-1 编码密码或 bcrypt 编码密码。
* `auth_params` ([Array(String)](/zh/sql-reference/data-types/array)) — JSON 格式的身份验证参数，具体内容取决于 auth&#95;type。
* `valid_until` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 用户凭据的过期日期和时间。
* `host_ip` ([Array(String)](/zh/sql-reference/data-types/array)) — 允许连接到 ClickHouse 服务器的主机 IP 地址。
* `host_names` ([Array(String)](/zh/sql-reference/data-types/array)) — 允许连接到 ClickHouse 服务器的主机名。
* `host_names_regexp` ([Array(String)](/zh/sql-reference/data-types/array)) — 允许连接到 ClickHouse 服务器的主机名正则表达式。
* `host_names_like` ([Array(String)](/zh/sql-reference/data-types/array)) — 使用 LIKE 谓词设置的允许连接到 ClickHouse 服务器的主机名。
* `default_roles_all` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 显示是否默认已为该用户设置所有已授予的角色。
* `default_roles_list` ([Array(String)](/zh/sql-reference/data-types/array)) — 默认授予的角色列表。
* `default_roles_except` ([Array(String)](/zh/sql-reference/data-types/array)) — 除列出的角色外，所有已授予的角色都设为默认。
* `grantees_any` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该标志指示具有任意授权选项的用户是否可以将其授予任何人。
* `grantees_list` ([Array(String)](/zh/sql-reference/data-types/array)) — 允许该用户向其授予授权选项的用户或角色列表。
* `grantees_except` ([Array(String)](/zh/sql-reference/data-types/array)) — 禁止该用户向其授予授权选项的用户或角色列表。
* `default_database` ([String](/zh/sql-reference/data-types/string)) — 该用户的默认数据库名称。

{/*AUTOGENERATED_END*/ }
