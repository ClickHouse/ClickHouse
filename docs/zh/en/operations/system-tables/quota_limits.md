<div id="description">
  ## 描述
</div>

包含所有配额在各个时间间隔上的最大值信息。一个配额可以对应任意多行，也可以不对应任何行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/zh/sql-reference/data-types/string)) — 配额名称。
* `duration` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 用于计算资源消耗的时间间隔长度，以秒为单位。
* `is_randomized_interval` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 布尔值。表示该时间间隔是否经过随机化。如果未随机化，时间间隔始终在固定时间开始。例如，1 分钟的时间间隔总是在整分钟开始 (即可以在 11:20:00 开始，但绝不会在 11:20:01 开始) ，1 天的时间间隔总是在 UTC 午夜开始。如果时间间隔经过随机化，则第一个时间间隔会在随机时间开始，后续时间间隔依次开始。取值：0 — 时间间隔未随机化，1 — 时间间隔已随机化。
* `max_queries` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许执行的各类查询的最大数量。
* `max_query_selects` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许执行的 SELECT 查询的最大数量。
* `max_query_inserts` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许执行的 INSERT 查询的最大数量。
* `max_errors` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许报错的查询最大数量。
* `max_result_rows` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许的所有查询结果集的总行数上限。
* `max_result_bytes` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许的所有查询结果集的总字节数上限。
* `max_read_rows` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许所有查询在执行期间读取的最大行数。
* `max_read_bytes` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许所有查询在执行期间读取的最大字节数。
* `max_execution_time` ([Nullable(Float64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许所有查询执行的最长时间 (以纳秒为单位)
* `max_written_bytes` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许所有查询在执行期间写入的最大字节数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许连续身份验证失败的最大次数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 在指定时间段内允许任意单个归一化查询执行的最大次数。
