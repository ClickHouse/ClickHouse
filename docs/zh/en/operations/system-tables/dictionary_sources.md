<div id="description">
  ## 描述
</div>

包含服务器支持的字典源列表，以及各个源的内嵌文档。字典源决定字典数据从何处加载；它在 `CREATE DICTIONARY` 查询的 `SOURCE` 子句中指定。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 字典源的名称，如 SOURCE 子句中所指定。
* `description` ([String](/zh/sql-reference/data-types/string)) — 对字典源作用的概述。
* `syntax` ([String](/zh/sql-reference/data-types/string)) — 用于指定源的 SOURCE 子句结构。请注意，当通过 DDL 查询创建字典时 (而不是通过服务器配置文件) ，某些源会受到访问控制限制；详情请参见各个源的 `description`。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 用法示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 首次引入该源的 ClickHouse 版本，格式为 major.minor。
* `related` ([Array](/zh/sql-reference/data-types/array)([String](/zh/sql-reference/data-types/string))) — 相关字典源的名称。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT name, syntax
FROM system.dictionary_sources
WHERE name IN ('clickhouse', 'file')
ORDER BY name
```

```text title="Response"
┌─name───────┬─syntax─────────────────────────────────────────────────────────────────────────┐
│ clickhouse │ SOURCE(CLICKHOUSE(host 'host' port 9000 user 'default' password '' db 'db' table 'table')) │
│ file       │ SOURCE(FILE(path '/path/to/file' format 'CSV'))                                  │
└────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
