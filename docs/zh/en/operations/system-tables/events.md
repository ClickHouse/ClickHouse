<div id="description">
  ## 描述
</div>

包含有关系统中事件发生次数的信息。例如，在该表中，你可以查看自 ClickHouse server 启动以来已处理了多少个 `SELECT` 查询。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/zh/sql-reference/data-types/string)) — 事件名称。
* `value` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 发生的事件数量。
* `description` ([String](/zh/sql-reference/data-types/string)) — 事件描述。

**别名：**

* `name` — `event` 的别名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT * FROM system.events LIMIT 5
```
