<div id="description">
  ## 说明
</div>

包含使用 LLVM 的 XRay 功能生成的插桩点。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `id` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 插桩点的 ID
* `function_id` ([Int32](/zh/sql-reference/data-types/int-uint)) — 在 ELF 二进制文件的 xray&#95;instr&#95;map 部分中分配给该函数的 ID。
* `function_name` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 用于为该函数插桩的名称。
* `handler` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 被打入该函数插桩点中的处理程序。
* `entry_type` ([Enum8(&#39;Entry&#39; = 0, &#39;Exit&#39; = 1, &#39;EntryAndExit&#39; = 2)](/zh/sql-reference/data-types/enum)) — 补丁的入口类型。
* `symbol` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 完整且去修饰后的符号名称。
* `arguments` ([Array(Dynamic)](/zh/sql-reference/data-types/array)) — 调用 `handler` 时使用的参数。

{/*AUTOGENERATED_END*/ }
