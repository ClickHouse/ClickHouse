<div id="description">
  ## 描述
</div>

包含已配置 profile 的各项属性。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — profile 的名称。
* `id` ([UUID](/zh/sql-reference/data-types/uuid)) — profile 的 ID。
* `storage` ([String](/zh/sql-reference/data-types/string)) — profile 的存储路径。在 `access_control_path` 参数中配置。
* `num_elements` ([UInt64](/zh/sql-reference/data-types/int-uint)) — `system.settings_profile_elements` 表中此 profile 的元素数量。
* `apply_to_all` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示该 profile 应用于所有角色和/或用户。
* `apply_to_list` ([Array(String)](/zh/sql-reference/data-types/array)) — 应用该 profile 的角色和/或用户列表。
* `apply_to_except` ([Array(String)](/zh/sql-reference/data-types/array)) — 该 profile 应用于除所列角色和/或用户之外的所有角色和/或用户。

{/*AUTOGENERATED_END*/ }
