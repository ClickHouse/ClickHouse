<div id="description">
  ## 描述
</div>

包含所有格式的列表，以及用于标明各格式是否适用于输入/输出、是否支持并行化的标志。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 格式名称。
* `is_input` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该格式是否适用于数据输入的标志。
* `is_output` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该格式是否适用于数据输出的标志。
* `supports_parallel_parsing` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该格式是否支持并行解析的标志。
* `supports_parallel_formatting` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该格式是否支持并行格式化的标志。
* `is_tty_friendly` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该格式通常是否能在终端中良好显示的标志。对于其他格式，命令行客户端会在输出前进行询问。
* `content_type` ([String](/zh/sql-reference/data-types/string)) — 与输出格式对应的 HTTP Content-Type。可能取决于当前的格式设置。
* `supports_random_access` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该格式是否支持在输入中随机访问的标志。
* `has_schema_inference` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该格式可以根据数据动态推断 schema (无论是从嵌入的请求头/元数据中，还是从数据片段本身中) 。
* `has_external_schema` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该格式要么具有固定 schema，要么接受以其自身格式提供的预定义 schema。
* `prefers_large_blocks` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该格式会在输出时写入更大的块，并在输入时生成更大的块。
* `supports_append` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 可以使用该格式向单个文件追加内容。
* `supports_subsets_of_columns` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该输入格式能够识别某些列是否被省略。
* `description` ([String](/zh/sql-reference/data-types/string)) — 该格式的概述性说明。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 用法示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 该格式首次引入时的 ClickHouse 版本，格式为 major.minor。
* `related` ([Array](/zh/sql-reference/data-types/array)([String](/zh/sql-reference/data-types/string))) — 相关格式的名称。

{/*AUTOGENERATED_END*/ }
