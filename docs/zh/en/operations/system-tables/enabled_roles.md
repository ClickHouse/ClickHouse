<div id="description">
  ## 说明
</div>

包含当前所有已启用角色，包括当前用户的当前角色，以及授予当前角色的已授予角色。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/zh/sql-reference/data-types/string)) — 角色名称。
* `with_admin_option` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果该角色具有 ADMIN OPTION privilege，则为 1。
* `is_current` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 标志，表示 `enabled_role` 是否为 current user 的 当前角色。
* `is_default` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 标志，表示 `enabled_role` 是否为默认角色。

{/*AUTOGENERATED_END*/ }
