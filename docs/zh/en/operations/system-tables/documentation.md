<div id="description">
  ## 描述
</div>

将系统中各类统一组件的嵌入式文档汇总到一张表中。每一行对应一个实体 (如函数、表引擎、数据类型等) ，并包含该实体渲染为 Markdown 的参考文档——也就是发布在网站上、并通过按类型划分的 `system.*` 系统表提供的相同内容。

`description` 由嵌入式文档中的结构化部分 (`description`、`syntax`、参数、示例等) 组装而成，因此单列即可容纳某个实体的完整文档。别名会渲染为指向规范实体的简短引用，例如 &#96;&#96;&#96;trunc&#96; 的别名。&#96;&#96;

从某种意义上说，这张表汇集了按类型划分的文档表中提供的信息 ([`system.functions`](/zh/operations/system-tables/functions)、[`system.table_engines`](/zh/operations/system-tables/table_engines)、[`system.data_type_families`](/zh/operations/system-tables/data_type_families) 等) 。它尤其用于为客户端中的交互式 `help` 命令提供支持，但其本身也很有用。

会收集以下类型的实体 (括号中显示的是 `type` 列的值) ：

* 函数 (`Function`)
* 聚合函数 (`Aggregate Function`)
* 表函数 (`Table Function`)
* 表引擎 (`Table Engine`)
* 数据库引擎 (`Database Engine`)
* 数据类型 (`Data Type`)
* 字典布局 (`Dictionary Layout`)
* 字典源 (`Dictionary Source`)
* 聚合函数组合器 (`Aggregate Function Combinator`)
* 数据跳过索引类型 (`Data Skipping Index`)
* 磁盘类型 (`Disk Type`)
* 设置 (`Setting`)
* MergeTree 设置 (`MergeTree Setting`)
* 服务器设置 (`Server Setting`)
* 格式 (`Format`)
* 压缩编解码器 (`Compression Codec`)
* profile events (`Profile Event`)
* 当前指标 (`Current Metric`)
* 异步指标 (`Asynchronous Metric`)
* 系统表 (`System Table`)

对于各类设置项，文档包含该设置的说明，以及其类型和默认值；已废弃设置不会对外提供。对于系统表，文档则由表注释及其列清单 (每列的名称、类型和说明) 组成。

`source` 列保存定义该实体文档的源文件路径，相对于仓库根目录。对于大多数实体，该路径会在构造文档对象的位置 (即组件的注册位置) 自动记录；对于那些各自在单个源文件中编写文档的类型 (例如设置项、profile events 和当前指标) ，则就是该文件。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 实体的名称，例如 `domainWithoutWWW` 或 `MergeTree`。
* `type` ([Enum8](/zh/sql-reference/data-types/enum)) — 实体的类型，例如 `Function` 或 `Table Engine`。
* `description` ([String](/zh/sql-reference/data-types/string)) — 以 Markdown 呈现的实体参考文档，由内嵌文档整理生成 (与网站上发布的内容相同) ，包括语法、示例及其他结构化部分 (如果有) 。
* `source` ([String](/zh/sql-reference/data-types/string)) — 定义该实体文档的源文件路径，相对于仓库根目录。如果源位置未知，则为空。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

查看特定实体的文档：

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

同一个名称可能对应多种实体 (例如，既有 `file` 表函数，也有 `file` 字典源) ，因此在所有类型中查找某个名称会更方便：

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

统计文档中每种类型的实体数量：

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
