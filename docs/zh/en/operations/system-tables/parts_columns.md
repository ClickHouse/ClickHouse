<div id="description">
  ## 描述
</div>

包含有关 [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) 表的 parts 和列的信息。
每一行描述一个 parts。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/zh/sql-reference/data-types/string)) — 分区名称。
* `name` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段名称。
* `uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — parts 的 UUID。
* `part_type` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段的存储格式。可能的值：Wide — 每一列都存储在文件系统中的单独文件中，Compact — 所有列都存储在文件系统中的同一个文件中。
* `active` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示数据分区片段是否处于活动状态的标志。如果数据分区片段处于活动状态，则会在表中使用；否则会被删除。非活动的数据分区片段会在合并后保留。
* `marks` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 标记数量。要获取数据分区片段中行数的近似值，可将 marks 乘以索引粒度 (通常为 8192)  (此提示不适用于自适应粒度) 。
* `rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 行数。
* `bytes_on_disk` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段所有文件的总大小 (以字节为单位) 。
* `data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中压缩数据的总大小。不包括所有辅助文件 (例如标记文件) 。
* `data_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中未压缩数据的总大小。不包括所有辅助文件 (例如标记文件) 。
* `marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 标记文件的大小。
* `modification_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 包含该数据分区片段的目录被修改的时间。通常对应于数据分区片段的创建时间。
* `remove_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 数据分区片段变为非活动状态的时间。
* `refcount` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 使用该数据分区片段的位置数量。值大于 2 表示该数据分区片段正用于查询或合并。
* `min_date` ([Date](/zh/sql-reference/data-types/date)) — 如果 Date 列包含在分区键中，则为该列的最小值。
* `max_date` ([Date](/zh/sql-reference/data-types/date)) — 如果 Date 列包含在分区键中，则为该列的最大值。
* `min_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 如果 DateTime 列包含在分区键中，则为该列的最小值。
* `max_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 如果 DateTime 列包含在分区键中，则为该列的最大值。
* `partition_id` ([String](/zh/sql-reference/data-types/string)) — 分区 ID。
* `min_block_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 合并后构成当前分片的最小数据分区片段编号。
* `max_block_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 合并后构成当前分片的最大数据分区片段编号。
* `level` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 合并树的深度。零表示当前分片是通过 insert 创建的，而不是通过合并其他分片创建的。
* `data_version` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 用于确定哪些 mutations 应应用于该数据分区片段的编号 (版本高于 data&#95;version 的 mutations) 。
* `primary_key_bytes_in_memory` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 主键值占用的内存量 (以字节为单位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 为主键值预留的内存量 (以字节为单位) 。
* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `engine` ([String](/zh/sql-reference/data-types/string)) — 不带参数的表引擎名称。
* `disk_name` ([String](/zh/sql-reference/data-types/string)) — 存储数据分区片段的磁盘名称。
* `path` ([String](/zh/sql-reference/data-types/string)) — 包含数据分区片段文件的文件夹绝对路径。
* `column` ([String](/zh/sql-reference/data-types/string)) — 列名称。
* `type` ([String](/zh/sql-reference/data-types/string)) — 列类型。
* `column_position` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 列在表中的序号位置，从 1 开始。
* `default_kind` ([String](/zh/sql-reference/data-types/string)) — 默认值的表达式类型 (DEFAULT、MATERIALIZED、ALIAS) ；如果未定义，则为空字符串。
* `default_expression` ([String](/zh/sql-reference/data-types/string)) — 默认值表达式；如果未定义，则为空字符串。
* `column_bytes_on_disk` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 列在磁盘上的总大小 (以字节为单位) 。
* `column_data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 列中压缩数据的总大小 (以字节为单位) 。
* `column_data_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 列中解压后数据的总大小 (以字节为单位) 。
* `column_marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 列的标记总大小 (以字节为单位) 。
* `column_modification_time` ([Nullable(DateTime)](/zh/sql-reference/data-types/nullable)) — 列最后的修改时间。
* `column_ttl_min` ([Nullable(DateTime)](/zh/sql-reference/data-types/nullable)) — 该列计算所得生存时间 (TTL) 表达式的最小值。
* `column_ttl_max` ([Nullable(DateTime)](/zh/sql-reference/data-types/nullable)) — 该列计算所得生存时间 (TTL) 表达式的最大值。
* `statistics` ([Array(String)](/zh/sql-reference/data-types/array)) — 该列的统计信息。
* `estimates.min` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 该列的估算最小值。
* `estimates.max` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 该列的估算最大值。
* `estimates.cardinality` ([Nullable(UInt64)](/zh/sql-reference/data-types/nullable)) — 该列的估算基数。
* `serialization_kind` ([String](/zh/sql-reference/data-types/string)) — 列的序列化方式
* `substreams` ([Array(String)](/zh/sql-reference/data-types/array)) — 列被序列化到的子流名称
* `filenames` ([Array(String)](/zh/sql-reference/data-types/array)) — 列的各个子流对应的文件名
* `subcolumns.names` ([Array(String)](/zh/sql-reference/data-types/array)) — 列的子列名称
* `subcolumns.types` ([Array(String)](/zh/sql-reference/data-types/array)) — 列的各子列的类型
* `subcolumns.serializations` ([Array(String)](/zh/sql-reference/data-types/array)) — 列的各子列的序列化类型
* `subcolumns.bytes_on_disk` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 每个子列在磁盘上的大小 (以字节为单位)
* `subcolumns.data_compressed_bytes` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 每个子列的压缩数据大小 (以字节为单位)
* `subcolumns.data_uncompressed_bytes` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 每个子列的未压缩数据大小 (以字节为单位)
* `subcolumns.marks_bytes` ([Array(UInt64)](/zh/sql-reference/data-types/array)) — 列的每个子列的标记大小 (以字节为单位)

**别名：**

* `bytes` — `bytes_on_disk` 的别名。
* `marks_size` — `marks_bytes` 的别名。
* `part_name` — `name` 的别名。

{/*AUTOGENERATED_END*/ }
