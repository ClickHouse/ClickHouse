<div id="description">
  ## 描述
</div>

包含 ClickHouse server 的构建选项信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 构建选项名称。
* `value` ([String](/zh/sql-reference/data-types/string)) — 构建选项的值。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
