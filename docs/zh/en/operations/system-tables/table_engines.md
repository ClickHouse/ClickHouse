<div id="description">
  ## 描述
</div>

包含服务器支持的表引擎及其功能支持信息的说明。

此表包含以下列 (括号中显示列类型) ：

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 表引擎的名称。
* `supports_settings` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持 SETTINGS 子句的标志。
* `supports_skipping_indices` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持数据跳过索引的标志。
* `supports_projections` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持投影的标志。
* `supports_sort_order` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持 PARTITION&#95;BY、PRIMARY&#95;KEY、ORDER&#95;BY 和 SAMPLE&#95;BY 子句的标志。
* `supports_ttl` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持生存时间 (TTL) 的标志。
* `supports_replication` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持数据复制的标志。
* `supports_deduplication` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持数据去重的标志。
* `supports_parallel_insert` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示表引擎是否支持并行插入的标志 (请参见 max&#95;insert&#95;threads 设置) 。
* `description` ([String](/zh/sql-reference/data-types/string)) — 对表引擎功能的描述。对于有专门文档页面的引擎，这里包含该页面完整的 Markdown 正文；对于其余引擎，这里则是简要摘要。
* `syntax` ([String](/zh/sql-reference/data-types/string)) — 创建表时表引擎的使用方式。对于大多数引擎，这是 CREATE TABLE 查询中的 ENGINE 子句；但有些引擎 (例如各种视图或 Loop 引擎) 会通过其他形式使用，例如 CREATE VIEW 或对表函数执行 SELECT。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 用法示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 该表引擎首次引入的 ClickHouse 版本，格式为 major.minor。
* `related` ([Array](/zh/sql-reference/data-types/array)([String](/zh/sql-reference/data-types/string))) — 相关表引擎的名称。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql title="Query"
SELECT
    name,
    supports_settings,
    supports_skipping_indices,
    supports_sort_order,
    supports_ttl,
    supports_replication,
    supports_deduplication,
    supports_parallel_insert
FROM system.table_engines
WHERE name IN ('Kafka', 'MergeTree', 'ReplicatedCollapsingMergeTree')
```
