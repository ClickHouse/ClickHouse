<div id="description">
  ## 描述
</div>

包含 [system.dropped&#95;tables](./dropped_tables.md) 中已删除的 [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) 表的 parts 信息

该表的 schema 与 [system.parts](./parts.md) 相同

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/zh/sql-reference/data-types/string)) — 分区标识符 (由表的分区键表达式派生而来的字符串表示形式) 。
* `name` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段的名称。数据分区片段的命名结构可用于判断数据、摄取和合并模式的诸多特征。数据分区片段的命名格式如下：

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * 定义：
    * `partition_id` - 标识分区键
    * `minimum_block_number` - 标识该 part 中的最小块编号。ClickHouse 始终会合并连续的块
    * `maximum_block_number` - 标识该 part 中的最大块编号
    * `level` - 该 part 每发生一次额外的合并就加 1。`level` 为 0 表示这是一个尚未合并的新 part。需要注意的是，ClickHouse 中的所有 parts 始终都是不可变的
    * `data_version` - 可选值，在 part 发生 mutation 时递增 (再次强调，由于 parts 是不可变的，发生 mutation 的数据始终只会写入新的 part)
* `uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — 数据分区片段的 UUID。
* `part_type` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段的存储格式。可能的值：`Wide` — 每列存储在单独的文件中，`Compact` — 所有列存储在一个文件中。数据存储格式由 MergeTree 表的 `min_bytes_for_wide_part` 和 `min_rows_for_wide_part` 设置控制。
* `active` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示数据分区片段是否处于活动状态的标志。如果数据分区片段处于活动状态，则会在表中使用。否则，它将被删除。非活动数据分区片段会在合并和变更操作后出现。
* `marks` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 标记数量。要获取数据分区片段中行数的近似值，可将 marks 乘以索引粒度 (通常为 8192)  (此提示对自适应粒度不适用) 。
* `rows` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 行数。
* `files` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中的文件数。
* `bytes_on_disk` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中所有文件的总大小 (以字节为单位) 。
* `data_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中压缩数据的总大小。所有辅助文件 (例如带有 marks 的文件) 均不包括在内。
* `data_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中未压缩数据的总大小。所有辅助文件 (例如带有 marks 的文件) 均不包括在内。
* `primary_key_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 磁盘上 primary.idx/cidx 文件中主键值占用的内存量 (以字节为单位) 。
* `marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 带有 marks 的文件大小。
* `secondary_indices_compressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中次级索引压缩数据的总大小。所有辅助文件 (例如带有 marks 的文件) 均不包括在内。
* `secondary_indices_uncompressed_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 数据分区片段中次级索引未压缩数据的总大小。所有辅助文件 (例如带有 marks 的文件) 均不包括在内。
* `secondary_indices_marks_bytes` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 次级索引带有 marks 的文件大小。
* `modification_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 存放该数据分区片段的目录被修改的时间。这通常对应于数据分区片段的创建时间。
* `remove_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 数据分区片段变为非活动状态的时间。
* `refcount` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 使用该数据分区片段的位置数量。值大于 2 表示该数据分区片段已用于查询或合并。
* `min_date` ([Date](/zh/sql-reference/data-types/date)) — 数据分区片段中日期键的最小值。
* `max_date` ([Date](/zh/sql-reference/data-types/date)) — 数据分区片段中日期键的最大值。
* `min_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 数据分区片段中日期时间键的最小值。
* `max_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 数据分区片段中日期时间键的最大值。
* `partition_id` ([String](/zh/sql-reference/data-types/string)) — 分区 ID。
* `min_block_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 合并后构成当前数据分区片段的最小数据分区片段编号。
* `max_block_number` ([Int64](/zh/sql-reference/data-types/int-uint)) — 合并后构成当前数据分区片段的最大数据分区片段编号。
* `level` ([UInt32](/zh/sql-reference/data-types/int-uint)) — 合并树的深度。零表示当前数据分区片段是通过插入创建的，而不是通过合并其他数据分区片段创建的。
* `data_version` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 用于确定哪些变更应应用到数据分区片段的版本号 (版本高于 data&#95;version 的变更) 。
* `primary_key_bytes_in_memory` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 主键值占用的内存量 (以字节为单位) 。当启用 `primary_key_lazy_load` 且主键未加载时，该值为 0。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 为主键值预留的内存量 (以字节为单位) 。当启用 `primary_key_lazy_load` 且主键未加载时，该值为 0。
* `index_granularity_bytes_in_memory` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 索引粒度值占用的内存量 (以字节为单位)  (在 primary&#95;key&#95;lazy&#95;load=1 且 use&#95;primary&#95;key&#95;cache=1 的情况下为 0) 。
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 为索引粒度值预留的内存量 (以字节为单位)  (在 primary&#95;key&#95;lazy&#95;load=1 且 use&#95;primary&#95;key&#95;cache=1 的情况下为 0) 。
* `is_frozen` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示是否存在分区数据备份的标志位。1 表示备份存在。0 表示备份不存在。更多详情，请参见 FREEZE PARTITION。
* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `engine` ([String](/zh/sql-reference/data-types/string)) — 不带参数的表引擎名称。
* `disk_name` ([String](/zh/sql-reference/data-types/string)) — 存储该数据分区片段的磁盘名称。
* `path` ([String](/zh/sql-reference/data-types/string)) — 数据分区片段文件所在文件夹的绝对路径。
* `hash_of_all_files` ([String](/zh/sql-reference/data-types/string)) — 压缩文件的 sipHash128。
* `hash_of_uncompressed_files` ([String](/zh/sql-reference/data-types/string)) — 未压缩文件的 sipHash128 (例如带有标记、索引文件等的文件) 。
* `uncompressed_hash_of_compressed_files` ([String](/zh/sql-reference/data-types/string)) — 将压缩文件中的数据按未压缩状态计算得到的 sipHash128。
* `delete_ttl_info_min` ([DateTime](/zh/sql-reference/data-types/datetime)) — TTL DELETE 规则的日期时间键最小值。
* `delete_ttl_info_max` ([DateTime](/zh/sql-reference/data-types/datetime)) — TTL DELETE 规则的日期时间键最大值。
* `move_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — 表达式数组。每个表达式定义一条 TTL MOVE 规则。
* `move_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 日期时间值数组。每个元素描述一条 TTL MOVE 规则的最小键值。
* `move_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 日期时间值数组。每个元素描述一条 TTL MOVE 规则的最大键值。
* `default_compression_codec` ([String](/zh/sql-reference/data-types/string)) — 用于压缩此数据分区片段的 codec 名称 (当列没有显式指定 codec 时) 。
* `recompression_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — TTL 表达式。
* `recompression_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此数据分区片段内计算出的 TTL 表达式最小值。用于判断是否至少有一行的 TTL 已过期。
* `recompression_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此数据分区片段内计算出的 TTL 表达式最大值。用于判断是否所有行的 TTL 均已过期。
* `group_by_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — TTL 表达式。
* `group_by_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此数据分区片段内计算出的 TTL 表达式最小值。用于判断是否至少有一行的 TTL 已过期。
* `group_by_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算得到的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `rows_where_ttl_info.expression` ([Array(String)](/zh/sql-reference/data-types/array)) — 生存时间 (TTL) 表达式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算得到的生存时间 (TTL) 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已过期。
* `rows_where_ttl_info.max` ([Array(DateTime)](/zh/sql-reference/data-types/array)) — 此分片内计算得到的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `projections` ([Array(String)](/zh/sql-reference/data-types/array)) — 为此分片计算得到的投影名称列表。
* `visible` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示此分片是否对 SELECT 查询可见的标志。
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/zh/sql-reference/data-types/tuple)) — 已创建或正尝试创建此对象的事务 ID。
* `removal_tid_lock` ([UInt64](/zh/sql-reference/data-types/int-uint)) — `removal_tid` 的哈希值，用于锁定待移除的对象。
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/zh/sql-reference/data-types/tuple)) — 已移除或正尝试移除此对象的事务 ID
* `creation_csn` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 创建此对象的事务的 CSN
* `removal_csn` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 移除此对象的事务的 CSN
* `has_lightweight_delete` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 指示该分片是否具有轻量级删除掩码的标志。
* `last_removal_attempt_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 服务器上次尝试删除此分片的时间。
* `removal_state` ([String](/zh/sql-reference/data-types/string)) — 分片移除过程的当前状态。

**别名：**

* `bytes` — `bytes_on_disk` 的别名。
* `marks_size` — `marks_bytes` 的别名。
* `part_name` — `name` 的别名。
