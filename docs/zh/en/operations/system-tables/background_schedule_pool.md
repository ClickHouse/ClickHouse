<div id="systembackground_schedule_pool">
  # system.background_schedule_pool
</div>

<SystemTableCloud />

<div id="description">
  ## 描述
</div>

包含有关后台调度池中任务的信息。后台调度池用于执行周期性任务，例如 Distributed 发送、缓冲区刷写以及消息 broker 相关操作。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `pool` ([String](/zh/sql-reference/data-types/string)) — 池名称。可能的值：`schedule` — 通用调度池，`buffer_flush` — 用于刷新 Buffer 表数据的池，`distributed` — 用于 Distributed 表操作的池，`message_broker` — 用于消息 broker 操作的池。
* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名。
* `table_uuid` ([UUID](/zh/sql-reference/data-types/uuid)) — 表 UUID。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 查询 ID (如果当前正在执行) 。注意：这不是真实的查询 ID，而是一个随机生成的 ID，用于匹配 `system.text_log` 中的日志。
* `elapsed_ms` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 任务执行时间 (如果当前正在执行) 。
* `log_name` ([String](/zh/sql-reference/data-types/string)) — 任务的日志名称。
* `deactivated` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 任务是否已停用 (始终为 false，因为已停用的任务会从池中移除) 。
* `scheduled` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 任务是否已安排执行。
* `delayed` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 任务是否延迟安排执行。
* `executing` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 任务当前是否正在执行。

{/*AUTOGENERATED_END*/ }
