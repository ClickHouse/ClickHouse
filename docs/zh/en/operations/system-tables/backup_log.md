<div id="description">
  ## 描述
</div>

包含有关 `BACKUP` 和 `RESTORE` 操作的日志记录条目。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 执行查询的服务器主机名。
* `event_date` ([Date](/zh/sql-reference/data-types/date)) — 记录的日期。
* `event_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 记录的时间。
* `event_time_microseconds` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 记录的时间，精确到微秒。
* `id` ([String](/zh/sql-reference/data-types/string)) — 备份或恢复操作的标识符。
* `name` ([String](/zh/sql-reference/data-types/string)) — 备份存储的名称 (即 `FROM` 或 `TO` 子句的内容) 。
* `base_backup_name` ([String](/zh/sql-reference/data-types/string)) — 增量备份场景下的基础备份名称。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 与备份操作关联的查询 ID。
* `status` ([Enum8(&#39;CREATING&#95;BACKUP&#39; = 0, &#39;BACKUP&#95;CREATED&#39; = 1, &#39;BACKUP&#95;FAILED&#39; = 2, &#39;RESTORING&#39; = 3, &#39;RESTORED&#39; = 4, &#39;RESTORE&#95;FAILED&#39; = 5, &#39;BACKUP&#95;CANCELLED&#39; = 6, &#39;RESTORE&#95;CANCELLED&#39; = 7)](/zh/sql-reference/data-types/enum)) — 操作状态。
* `error` ([String](/zh/sql-reference/data-types/string)) — 失败操作的错误信息 (成功操作时为空字符串) 。
* `start_time` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 操作开始时间。
* `end_time` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 操作结束时间。
* `num_files` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 备份中存储的文件数。
* `total_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 备份中存储文件的总大小。
* `num_entries` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 备份中的条目数，即：如果备份以文件夹形式存储，则为该文件夹中的文件数；如果备份以归档形式存储，则为该归档中的文件数。如果是增量备份，或者其中包含空文件或重复文件，则它与 `num_files` 不同。以下关系始终成立：`num_entries ≤ num_files`。
* `uncompressed_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 备份的未压缩大小。
* `compressed_size` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 备份的压缩后大小。如果备份不是以归档形式存储，则它等于 uncompressed&#95;size。
* `files_read` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 恢复操作期间读取的文件数。
* `bytes_read` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 恢复操作期间读取文件的总大小。
* `settings` ([Map(LowCardinality(String), String)](/zh/sql-reference/data-types/map)) — 此操作实际使用的备份/恢复专用设置 (来自 `SETTINGS` 子句，包括默认值) 。敏感设置不会显示。
* `engine_settings` ([Map(LowCardinality(String), String)](/zh/sql-reference/data-types/map)) — 备份引擎的 reader/writer 实际使用的设置 (例如 S3 `allow_native_copy`) 。当操作涉及多个无法用扁平映射表示的引擎时，该字段为空：增量备份和恢复、轻量级快照恢复，以及非内部 `ON CLUSTER` 操作。

{/*AUTOGENERATED_END*/ }
