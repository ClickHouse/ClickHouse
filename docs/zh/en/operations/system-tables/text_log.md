<div id="description">
  ## 描述
</div>

包含日志记录条目。可通过 `text_log.level` 服务器设置限制写入此表的日志级别。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 执行查询的服务器主机名。
* `event_date` ([Date](/zh/sql-reference/data-types/date)) — 条目的日期。
* `event_time` ([DateTime](/zh/sql-reference/data-types/datetime)) — 条目的时间。
* `event_time_microseconds` ([DateTime64(6)](/zh/sql-reference/data-types/datetime64)) — 条目的时间，精确到微秒。
* `thread_name` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 执行日志记录的线程名称。
* `thread_id` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 操作系统线程 ID。
* `level` ([Enum8(&#39;Fatal&#39; = 1, &#39;Critical&#39; = 2, &#39;Error&#39; = 3, &#39;Warning&#39; = 4, &#39;Notice&#39; = 5, &#39;Information&#39; = 6, &#39;Debug&#39; = 7, &#39;Trace&#39; = 8, &#39;Test&#39; = 9)](/zh/sql-reference/data-types/enum)) — 条目级别。可能的值：1 或 &#39;Fatal&#39;、2 或 &#39;Critical&#39;、3 或 &#39;Error&#39;、4 或 &#39;Warning&#39;、5 或 &#39;Notice&#39;、6 或 &#39;Information&#39;、7 或 &#39;Debug&#39;、8 或 &#39;Trace&#39;。
* `query_id` ([String](/zh/sql-reference/data-types/string)) — 查询 ID。
* `logger_name` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 日志记录器名称 (例如 DDLWorker) 。
* `message` ([String](/zh/sql-reference/data-types/string)) — 消息本身。
* `revision` ([UInt32](/zh/sql-reference/data-types/int-uint)) — ClickHouse 修订版本。
* `source_file` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 执行日志记录的源文件。
* `source_line` ([UInt64](/zh/sql-reference/data-types/int-uint)) — 执行日志记录的源代码行号。
* `message_format_string` ([LowCardinality(String)](/zh/sql-reference/data-types/lowcardinality)) — 用于格式化消息的格式字符串。
* `value1` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 1。
* `value2` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 2。
* `value3` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 3。
* `value4` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 4。
* `value5` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 5。
* `value6` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 6。
* `value7` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 7。
* `value8` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 8。
* `value9` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 9。
* `value10` ([String](/zh/sql-reference/data-types/string)) — 用于格式化消息的参数 10。

{/*AUTOGENERATED_END*/ }
