<div id="description">
  ## 描述
</div>

与 [`system.numbers`](../../operations/system-tables/numbers.md) 相同，但读取是并行化的。返回的数字顺序可以是任意的。

用于测试。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `number` ([UInt64](/zh/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }
