<div id="description">
  ## 描述
</div>

描述 SETTINGS PROFILE 包含的内容：

* 约束。
* 适用该设置的角色和用户。
* 父 profile。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `profile_name` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — profile 名称。
* `user_name` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 用户名。
* `role_name` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 角色名称。
* `index` ([UInt64](/zh/sql-reference/data-types/int-uint)) — profile 元素的顺序编号。
* `setting_name` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 设置名称。
* `value` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 设置值。
* `min` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 设置的最小值。若未设置，则为 NULL。
* `max` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 设置的最大值。若未设置，则为 NULL。
* `writability` ([Nullable(Enum8(&#39;WRITABLE&#39; = 0, &#39;CONST&#39; = 1, &#39;CHANGEABLE&#95;IN&#95;READONLY&#39; = 2))](/zh/sql-reference/data-types/nullable)) — 显示某项设置是否可更改的属性。
* `inherit_profile` ([Nullable(String)](/zh/sql-reference/data-types/nullable)) — 此 profile 的父 profile。若未设置，则为 NULL。该 profile 将从其父 profile 继承所有设置的值和约束 (min、max、readonly) 。

{/*AUTOGENERATED_END*/ }
