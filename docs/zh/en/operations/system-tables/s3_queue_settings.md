<div id="description">
  ## 说明
</div>

包含有关 [S3Queue](../../engines/table-engines/integrations/s3queue.md) 表设置的信息。从 server 版本 `24.10` 开始可用。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 使用 S3Queue 引擎的表所在的数据库。
* `table` ([String](/zh/sql-reference/data-types/string)) — 使用 S3Queue 引擎的表名。
* `name` ([String](/zh/sql-reference/data-types/string)) — 设置名称。
* `value` ([String](/zh/sql-reference/data-types/string)) — 设置值。
* `type` ([String](/zh/sql-reference/data-types/string)) — 设置类型 (实现特定的字符串值) 。
* `changed` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 如果该设置是在配置中显式定义的，或被显式修改过，则为 1。
* `description` ([String](/zh/sql-reference/data-types/string)) — 设置说明。
* `alterable` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 表示当前用户是否可通过 ALTER TABLE MODIFY SETTING 更改该设置：0 — 当前用户不能更改该设置，1 — 当前用户可以更改该设置。

{/*AUTOGENERATED_END*/ }
