<div id="description">
  ## 描述
</div>

包含有关常规函数和聚合函数的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 函数名称。
* `is_aggregate` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 该函数是否为聚合函数。
* `case_insensitive` ([UInt8](/zh/sql-reference/data-types/int-uint)) — 函数名是否可不区分大小写使用。
* `alias_to` ([String](/zh/sql-reference/data-types/string)) — 原始函数名 (如果该函数名是别名) 。
* `create_query` ([String](/zh/sql-reference/data-types/string)) — 已废弃。
* `origin` ([Enum8(&#39;System&#39; = 0, &#39;SQLUserDefined&#39; = 1, &#39;ExecutableUserDefined&#39; = 2)](/zh/sql-reference/data-types/enum)) — 已废弃。
* `description` ([String](/zh/sql-reference/data-types/string)) — 对函数作用的简要说明。
* `syntax` ([String](/zh/sql-reference/data-types/string)) — 函数签名。
* `arguments` ([String](/zh/sql-reference/data-types/string)) — 函数参数。
* `parameters` ([String](/zh/sql-reference/data-types/string)) — 函数参数 (仅适用于聚合函数) 。
* `returned_value` ([String](/zh/sql-reference/data-types/string)) — 函数的返回值。
* `examples` ([String](/zh/sql-reference/data-types/string)) — 使用示例。
* `introduced_in` ([String](/zh/sql-reference/data-types/string)) — 该函数首次引入的 ClickHouse 版本。
* `categories` ([String](/zh/sql-reference/data-types/string)) — 函数类别。
* `deterministic` ([Nullable(UInt8)](/zh/sql-reference/data-types/int-uint)) — 对于相同参数，函数是否返回相同结果。未知时为 `NULL` (例如聚合函数或用户自定义函数) 。
* `higher_order` ([Nullable(UInt8)](/zh/sql-reference/data-types/int-uint)) — 该函数是否为高阶函数——即至少接受一个 lambda 表达式作为参数 (例如 `arrayMap`、`arrayFilter`、`mapApply`) 。未知时为 `NULL`。

{/*AUTOGENERATED_END*/ }
