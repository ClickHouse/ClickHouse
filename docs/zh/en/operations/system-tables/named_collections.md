<div id="description">
  ## 描述
</div>

包含所有通过 SQL 查询创建或从配置文件中解析出的命名集合。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — 集合名称。
* `collection` ([Map(String, String)](/zh/sql-reference/data-types/map)) — 集合的内部结构。
* `source` ([String](/zh/sql-reference/data-types/string)) — 命名集合的来源。
* `create_query` ([String](/zh/sql-reference/data-types/string)) — 创建命名集合的查询语句。

{/*AUTOGENERATED_END*/ }
