<div id="description">
  ## 描述
</div>

包含所有表中现有约束的信息。

在[临时表](../../sql-reference/statements/create/table.md#temporary-tables)上定义的约束，仅在创建它们的会话中才会显示在 `system.constraints` 中。它们显示时的 `database` 字段为空。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/zh/sql-reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/sql-reference/data-types/string)) — 表名称。
* `name` ([String](/zh/sql-reference/data-types/string)) — 约束名称。
* `type` ([Enum8(&#39;CHECK&#39; = 0, &#39;ASSUME&#39; = 1)](/zh/sql-reference/data-types/enum)) — 约束类型。
* `expression` ([String](/zh/sql-reference/data-types/string)) — 约束表达式。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 示例
</div>

```sql
SELECT * FROM system.constraints LIMIT 2 FORMAT Vertical;
```

```text
Row 1:
──────
database:    default
table:       hits
name:        check_hits
type:        CHECK
expression:  CounterID > 0

Row 2:
──────
database:    default
table:       hits
name:        assume_positive
type:        ASSUME
expression:  WatchID > 0
```
