<div id="description">
  ## 描述
</div>

显示所有可用的词干提取器。
这些词干提取器可用于函数 [stem](../../sql-reference/functions/nlp-functions.md)。

:::note 可用性
`system.stemmers` 仅在使用 `libstemmer` 依赖项 (`USE_LIBSTEMMER`) 编译的 ClickHouse 构建中存在。在未包含该依赖项的构建中，此表不存在，对其执行查询会因 `UNKNOWN_TABLE` 而失败。你可以通过以下方式检查当前构建是否已启用它：

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

列：

{/*AUTOGENERATED_START*/ }

* `name` ([String](/zh/sql-reference/data-types/string)) — Snowball 词干提取器的标识符 (语言/算法)

{/*AUTOGENERATED_END*/ }
