| 工具/实用程序                                                                            | 说明                                               |
| ---------------------------------------------------------------------------------- | ------------------------------------------------ |
| [clickhouse-local](../../operations/utilities/clickhouse-local.md)                 | 无需启动 ClickHouse server 即可对数据运行 SQL 查询，类似于 `awk`。 |
| [clickhouse-benchmark](../../operations/utilities/clickhouse-benchmark.md)         | 使用自定义查询和 settings 对 server 施加负载。                 |
| [clickhouse-format](../../operations/utilities/clickhouse-format.md)               | 支持对输入查询进行格式化。                                    |
| [ClickHouse obfuscator](../../operations/utilities/clickhouse-obfuscator.md)       | 对数据进行混淆。                                         |
| [ClickHouse compressor](../../operations/utilities/clickhouse-compressor.md)       | 压缩和解压数据。                                         |
| [clickhouse-disks](../../operations/utilities/clickhouse-disks.md)                 | 在不同 ClickHouse disks 上的文件之间提供类似 filesystem 的操作。  |
| [clickhouse-odbc-bridge](../../operations/utilities/odbc-bridge.md)                | 用于 ODBC Driver 的代理服务器。                           |
| [clickhouse&#95;backupview](../../operations/utilities/backupview.md)              | 用于分析 ClickHouse backups 的 Python 模块。             |
| [clickhouse-keeper-client](../../operations/utilities/clickhouse-keeper-client.md) | 用于与 ClickHouse Keeper 交互的客户端应用程序。                |
| [Keeper HTTP API](../../operations/utilities/clickhouse-keeper-http-api.md)        | ClickHouse Keeper 的 HTTP API 和嵌入式仪表板。            |
