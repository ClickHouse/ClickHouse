更改数据库引擎的设置。可更改的设置取决于具体引擎；并非所有引擎或设置都支持在创建数据库后修改。

此语句更改的是数据库引擎设置，而非会话设置或数据库中表的默认值。

## 语法 {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

使用 `ON CLUSTER` 可在指定集群的所有主机上执行该语句。
执行该语句需要 `ALTER DATABASE SETTINGS` 特权。

## 支持的设置 {#supported-settings}

各数据库引擎支持的设置及其限制，请参阅相应数据库引擎的文档。例如：

* [`Atomic`](/zh/reference/engines/database-engines/atomic) 和 [`Ordinary`](/zh/reference/engines/database-engines/ordinary) 支持修改 `max_tables`。
* [`MaterializedPostgreSQL`](/zh/reference/engines/database-engines/materialized-postgresql) 支持修改部分复制设置，例如 `materialized_postgresql_max_block_size`。
* [`DataLakeCatalog`](/zh/reference/engines/database-engines/datalake) 支持修改部分目录设置，具体可用的设置取决于目录类型。

使用不支持的引擎或设置会引发异常。

## 示例 {#example}

修改 `Atomic` 数据库中表的最大数量：

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

将 `max_tables` 设置为 `0`，即可取消此数据库级别的限制：

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
