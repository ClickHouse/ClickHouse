可并行执行多条语句。

## 语法 {#syntax}

```sql
statement1 PARALLEL WITH statement2 [PARALLEL WITH statement3 ...]
```

并行执行语句 `statement1`、`statement2`、`statement3` 等。只有既不返回结果集、也不需要输入数据的语句才能组合使用，参见[限制](#restrictions)。

在很多情况下，并行执行这些语句可能比按顺序依次执行相同的语句更快。例如，`statement1 PARALLEL WITH statement2 PARALLEL WITH statement3` 很可能比 `statement1; statement2; statement3` 更快。

## 示例 {#examples}

并行创建两个表：

```sql
CREATE TABLE table1(x Int32) ENGINE = MergeTree ORDER BY tuple()
PARALLEL WITH
CREATE TABLE table2(y String) ENGINE = MergeTree ORDER BY tuple();
```

并行删除两个表：

```sql
DROP TABLE table1
PARALLEL WITH
DROP TABLE table2;
```

## 限制 {#restrictions}

返回结果集的语句 (例如 `SELECT`) 或需要输入数据的语句会被拒绝，并报 `INCORRECT_QUERY` 错误。

通过 [`ON CLUSTER`](/zh/reference/statements/distributed-ddl) 执行的 DDL，或通过 [`Replicated`](/zh/reference/engines/database-engines/replicated) 数据库的 DDL 日志执行的 DDL，会返回一个状态表，因此同样会被拒绝。但拒绝发生在语句已发送到各主机之后，这些主机仍会执行该语句。如果 [`distributed_ddl_output_mode`](/zh/reference/settings/session-settings/distributed-ddl#distributed_ddl_output_mode) 设置为 `none` 或 `none_only_active`，则可以合并此类语句：

```sql
SET distributed_ddl_output_mode = 'none';

CREATE TABLE table1 ON CLUSTER default (x Int32) ENGINE = MergeTree ORDER BY tuple()
PARALLEL WITH
CREATE TABLE table2 ON CLUSTER default (y String) ENGINE = MergeTree ORDER BY tuple();
```

## 设置 {#settings}

设置 [max&#95;threads](/zh/reference/settings/session-settings/max-threads#max_threads) 用于控制生成的线程数。

## 与 UNION 的比较 {#comparison-with-union}

`PARALLEL WITH` 子句与 [UNION](/zh/reference/statements/select/union) 有些类似，后者同样会并行执行其操作数。不过，两者之间也有一些区别：

* `PARALLEL WITH` 不会返回其操作数执行产生的任何结果；如果其中某个操作数抛出异常，它只能将该异常重新抛出；
* `PARALLEL WITH` 组合的是既不返回结果集、也不需要输入数据的语句，而 `UNION` 组合的是 `SELECT` 查询。
