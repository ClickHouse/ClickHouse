```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

返回一个 `UInt8` 类型的单列：如果表或数据库不存在，该列包含单个值 `0`；如果表存在于指定的数据库中，则包含 `1`。

## 子查询形式 {#subquery-form}

`EXISTS` 运算符用于检查子查询是否返回了行。如果子查询结果为空，则返回 `0`；否则返回 `1`。

`EXISTS` 可用于 [`WHERE`](/zh/reference/statements/select/where) 子句中。子查询不能引用外层查询中的表或列。

**语法**

```sql
EXISTS(subquery)
```

**示例**

检查子查询是否返回任何行：

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

在 `WHERE` 子句中将 `EXISTS` 与返回多行的子查询配合使用：

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

当子查询结果为空时，`EXISTS` 返回 `0`：

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```
