CREATE 查询可用于创建新的[数据库](/zh/reference/statements/create/database)、[表](/zh/reference/statements/create/table)和[视图](/zh/reference/statements/create/view)等。

**语法**

```sql
CREATE DATABASE ...
CREATE TABLE ...
CREATE VIEW ...
CREATE DICTIONARY ...
CREATE FUNCTION ...
CREATE NAMED COLLECTION ...
CREATE USER | ROLE | ROW POLICY | MASKING POLICY | QUOTA | SETTINGS PROFILE ...
```

**相关：** `ATTACH`、`DROP`、`CREATE TABLE`、`CREATE DATABASE`、`CREATE VIEW`、`CREATE DICTIONARY`
