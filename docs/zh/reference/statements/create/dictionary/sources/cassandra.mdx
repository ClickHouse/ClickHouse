设置示例：

<Tabs>
  <Tab title="DDL">
    ```sql
    SOURCE(CASSANDRA(
        host 'localhost'
        port 9042
        user 'username'
        password 'qwerty123'
        secure 1
        compression 'lz4'
        keyspace 'database_name'
        column_family 'table_name'
        allow_filtering 1
        partition_key_prefix 1
        consistency 'One'
        where '"SomeColumn" = 42'
        max_threads 8
        query 'SELECT id, value_1, value_2 FROM database_name.table_name'
    ))
    ```
  </Tab>

  <Tab title="配置文件">
    ```xml
    <source>
        <cassandra>

            <where>"SomeColumn" = 42</where>

        </cassandra>
    </source>
    ```
  </Tab>

设置项：

| 设置                     | 说明                                                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `host`                 | Cassandra 主机，或以逗号分隔的主机列表。                                                                                                                                    |
| `port`                 | Cassandra 服务器的端口。若未指定，则使用默认端口 `9042`。                                                                                                                        |
| `user`                 | Cassandra 用户名。                                                                                                                                               |
| `password`             | Cassandra 用户的密码。                                                                                                                                             |
| `secure`               | 使用 TLS 进行连接。TLS 客户端设置 (例如证书验证模式) 取自服务器配置中的 `openSSL.client` 部分。默认值为 `0`。                                                                                     |
| `compression`          | 传输数据的压缩方式：`none`、`lz4` 或 `snappy`。默认值为 `none`。                                                                                                               |
| `keyspace`             | keyspace (数据库) 名称。                                                                                                                                           |
| `column_family`        | column family (表) 名称。                                                                                                                                        |
| `allow_filtering`      | 是否允许在聚簇键列上使用可能开销较高的条件。默认值为 `1`。                                                                                                                              |
| `partition_key_prefix` | Cassandra 表主键中分区键列的数量。复合键字典需要此项。字典定义中的键列顺序必须与 Cassandra 中保持一致。默认值为 `1` (第一个键列是分区键，其余键列为聚簇键) 。                                                                |
| `consistency`          | 一致性级别。可选值：`One`、`Two`、`Three`、`All`、`EachQuorum`、`Quorum`、`LocalQuorum`、`LocalOne`、`Serial`、`LocalSerial`。默认值为 `One`。                                        |
| `where`                | 可选的筛选条件。                                                                                                                                                     |
| `max_threads`          | 加载数据时保持打开的最大空闲连接数，例如在复合键字典中从多个分区加载数据时。默认值为 `8`。                                                                                                              |
| `query`                | 自定义查询。可选。由于 CQL 不支持子查询，对于使用复杂键且布局为 `cache` 或 `direct` 的字典，查询中必须包含 `{condition}` 占位符，该占位符会被替换为针对所请求键的条件。占位符必须紧跟在 `WHERE` 或 `AND` 之后，因为加载整个字典时，它会连同这些关键字一起被移除。 |

<Note>
  `column_family` 或 `where` 字段不能与 `query` 字段同时使用。此外，必须声明 `column_family` 和 `query` 两者中的一个。
</Note>
