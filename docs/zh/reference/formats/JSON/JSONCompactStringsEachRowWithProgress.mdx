## 描述 {#description}

与 [`JSONCompactEachRowWithProgress`](/zh/reference/formats/JSON/JSONCompactEachRowWithProgress) 类似，但所有值都会转换为字符串。其使用的顶层对象类型与前者相同 (`meta`、`row`、`progress`、`totals`、`min`/`max`、`rows_before_limit_at_least`、`rows_before_aggregation`，以及顶层的 `exception`)；`row` / `totals` / `min` / `max` 的载荷仍为按列顺序排列的 **数组**，其中每个元素都序列化为字符串。

有关完整的流对象契约，请参阅 [`JSONCompactEachRowWithProgress`](/zh/reference/formats/JSON/JSONCompactEachRowWithProgress) (`progress` 可能先于 `meta` 到达；当查询包含 `LIMIT` 时，`rows_before_limit_at_least` 只是一个下限估计值，并不能说明有行被丢弃；`exception` 仅在通过 HTTP 且设置了 `http_write_exception_in_output_format=1` 时才会写入)。

## 使用示例 {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
