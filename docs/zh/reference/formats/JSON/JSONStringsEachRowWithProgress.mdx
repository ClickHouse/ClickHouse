## 描述 {#description}

与 `JSONEachRow`/`JSONStringsEachRow` 的不同之处在于，ClickHouse 会将每个事件作为独立的 JSON 对象以流式方式输出，同时还会返回进度信息。

所有字段值 (包括复杂类型) 都会序列化为字符串：例如，`arr` 会输出为 `"arr":"[0,1]"`，而不是嵌套的 JSON 数组。标量值同样会转换为字符串 (`"num":"42"`) 。

顶层对象的类型与 [`JSONEachRowWithProgress`](/zh/reference/formats/JSON/JSONEachRowWithProgress) 相同 (`meta`、`row`、`progress`、`totals`/`min`/`max`、`rows_before_limit_at_least`、`rows_before_aggregation`，以及顶层的 `exception`) 。完整的流契约请参阅该页面：`progress` 对象可能先于 `meta` 到达；当查询包含 `LIMIT` 时，`rows_before_limit_at_least` 是一个下限估计值 (并不意味着确实有行被丢弃) ；`exception` 仅在通过 HTTP 访问且设置了 `http_write_exception_in_output_format=1` 时才会写入。

## 使用示例 {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
