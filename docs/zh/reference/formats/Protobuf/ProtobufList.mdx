## 描述 {#description}

`ProtobufList` 格式会将多行数据组合到一个名为 `Envelope` 的带长度分隔的 [Protocol Buffers](/zh/reference/formats/Protobuf/Protobuf) 消息中。每一行都会编码为一个字段编号为 1 的子消息。

## 示例用法 {#example-usage}

将以下 schema 保存为 `schemafile.proto`。将 `row` 字段声明为 `repeated`，这样使用该 schema 的 Protobuf 解码器就能读取封装中的所有行。

```capnp title="schemafile.proto"
syntax = "proto3";
message Envelope {
  message MessageType {
    string name = 1;
  }
  repeated MessageType row = 1;
}
```

在同一目录下运行以下命令，将两行数据写入文件，然后再读取出来。

```bash
clickhouse local --query "SELECT name FROM values('name String', 'Ada', 'Grace') ORDER BY name
    SETTINGS format_schema = 'schemafile:MessageType' FORMAT ProtobufList" > people.bin

clickhouse local --structure 'name String' --input-format ProtobufList \
    --format_schema 'schemafile:MessageType' --query 'SELECT name FROM table' < people.bin
```

```text
Ada
Grace
```

`format_schema` 中指定的消息类型会先解析为顶层 `Envelope` 消息内部的嵌套类型。如果未在其中找到匹配项——无论是因为 schema 中没有 `Envelope` 消息，还是因为 `Envelope` 中不包含所请求名称的消息——则直接使用该名称对应的顶层消息。
