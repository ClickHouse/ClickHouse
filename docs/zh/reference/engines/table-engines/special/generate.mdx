GenerateRandom 表引擎可根据给定的表 schema 生成随机数据。

用法示例：

* 用于测试中填充可复现的大型表。
* 为模糊测试生成随机输入。

## 在 ClickHouse 服务器中使用 {#usage-in-clickhouse-server}

```sql
ENGINE = GenerateRandom([random_seed [,max_string_length [,max_array_length]]])
[SETTINGS null_ratio = ..., max_json_depth = ..., max_json_keys_per_object = ...]
```

`max_array_length` 和 `max_string_length` 参数分别指定生成数据中所有
array 或 map 列以及字符串的最大长度。

`SETTINGS` 子句用于控制 `Nullable`、`Variant`、`Dynamic` 和 `JSON` 值的生成方式：
`null_ratio` (默认值为 `0.0625`) 表示值为 `NULL` 的概率，同时也是某个 `JSON` 键在一行中缺失的基础概率——少数稀疏键的缺失频率会高出数倍；`max_json_depth` (默认值为 `3`) 限制生成的 `JSON` 对象的最大嵌套深度；
`max_json_keys_per_object` (默认值为 `8`) 限制对象每一层中生成的键数量上限。[`generateRandom`](/zh/reference/functions/table-functions/generate) 表函数同样支持
这些设置。

Generate 表引擎仅支持 `SELECT` 查询。

它支持所有可存储在表中的 [DataTypes](/zh/reference/data-types/index)，
但 `AggregateFunction`、`Interval`、`Nothing` 和 `QBit` 除外。

## 示例 {#example}

**1.** 创建 `generate_engine_table` 表：

```sql
CREATE TABLE generate_engine_table (name String, value UInt32) ENGINE = GenerateRandom(1, 5, 3)
```

**2.** 查询数据：

```sql
SELECT * FROM generate_engine_table LIMIT 3
```

```text
┌─name─┬──────value─┐
│ c4xJ │ 1412771199 │
│ r    │ 1791099446 │
│ 7#$  │  124312908 │
└──────┴────────────┘
```

## 实现细节 {#details-of-implementation}

* 不支持：
  * `ALTER`
  * `SELECT ... SAMPLE`
  * `INSERT`
  * 索引
  * 复制
