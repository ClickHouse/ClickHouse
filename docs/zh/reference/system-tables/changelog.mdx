## 描述 {#description}

包含经过整理的 ClickHouse 更新日志 (即代码仓库中的 `CHANGELOG.md`) 中的条目，每个功能发行版中的每个条目各占一行，便于使用 SQL 查询发行说明。

## 列 {#columns}

* `version` ([Tuple(major UInt16, minor UInt8, patch UInt16)](/zh/reference/data-types/tuple)) — 该条目所属发行版的版本号，以可比较的元组形式表示。精选更新日志只收录功能发行版，因此 `patch` 为 0。
* `release_date` ([Date](/zh/reference/data-types/date)) — 发行版的发布日期。
* `is_lts` ([UInt8](/zh/reference/data-types/int-uint)) — 若该发行版为长期支持版，则为 1。
* `category` ([LowCardinality(String)](/zh/reference/data-types/lowcardinality)) — 该条目所属的更新日志章节，例如 &#39;New Feature&#39;、&#39;Performance Improvement&#39;、&#39;Bug Fix&#39;。
* `description` ([String](/zh/reference/data-types/string)) — 更新日志条目的文本内容。
* `pull_requests` ([Array(UInt32)](/zh/reference/data-types/array)) — 该条目引用的拉取请求编号。
* `authors` ([Array(String)](/zh/reference/data-types/array)) — 所引用拉取请求的作者。

## 示例 {#example}

查找近期与 JSON 相关的变更，按发行版从新到旧排序：

```sql
SELECT version, category, description
FROM system.changelog
WHERE description ILIKE '%JSON%' AND version >= (26, 1, 0)
ORDER BY version DESC
LIMIT 3
```
