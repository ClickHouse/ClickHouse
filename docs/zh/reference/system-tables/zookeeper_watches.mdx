## 描述 {#description}

显示此 ClickHouse server 当前在 ZooKeeper 节点 (包括辅助 ZooKeeper) 上注册的活动 [watch](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches)。每一行表示一个 watch。

**可用性**

`system.zookeeper_watches` 仅在配置了 ClickHouse Keeper 或 ZooKeeper 时存在。在两者均未配置的服务器上，该表不存在，对其执行的查询会以 `UNKNOWN_TABLE` 错误失败。

## 列 {#columns}

* `zookeeper_name` ([String](/zh/reference/data-types/string)) — ZooKeeper 连接的名称 (主连接为 &quot;default&quot;，或辅助连接名称) 。
* `create_time` ([DateTime](/zh/reference/data-types/datetime)) — watch 创建的时间。
* `create_time_microseconds` ([DateTime64(6)](/zh/reference/data-types/datetime64)) — 以微秒精度记录的 watch 创建时间。
* `path` ([String](/zh/reference/data-types/string)) — 被 watch 监听的 ZooKeeper 路径。
* `session_id` ([Int64](/zh/reference/data-types/int-uint)) — 注册该 watch 的连接的会话 ID。
* `request_xid` ([Int64](/zh/reference/data-types/int-uint)) — 创建该 watch 的请求的 XID。
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/zh/reference/data-types/enum)) — 创建该 watch 的操作。
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/zh/reference/data-types/enum)) — watch 类型：Children (list) 、Exists 或 Data (get) 。

