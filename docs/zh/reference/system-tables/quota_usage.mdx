<div id="description">
  ## 描述
</div>

当前用户的配额使用情况：已使用量和剩余量。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/zh/reference/data-types/string)) — 配额名称。
* `quota_key` ([String](/zh/reference/data-types/string)) — 键值。
* `start_time` ([Nullable(DateTime)](/zh/reference/data-types/nullable)) — 开始计算资源消耗的时间。
* `end_time` ([Nullable(DateTime)](/zh/reference/data-types/nullable)) — 结束计算资源消耗的时间。
* `duration` ([Nullable(UInt32)](/zh/reference/data-types/nullable)) — 用于计算资源消耗的时间间隔长度，单位为秒。
* `queries` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前已执行的查询数。
* `max_queries` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 允许执行的各类查询总数上限。
* `query_selects` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前已执行的 SELECT 查询数。
* `max_query_selects` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 允许执行的 SELECT 查询数上限。
* `query_inserts` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前已执行的 INSERT 查询数。
* `max_query_inserts` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 允许执行的 INSERT 查询数上限。
* `errors` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前发生错误的查询数。
* `max_errors` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内允许发生错误的查询数上限。
* `result_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内所有查询结果集的总行数。
* `max_result_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内所有查询结果集的总行数上限。
* `result_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内所有查询结果集的总字节数。
* `max_result_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内所有查询结果集的总字节数上限。
* `read_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内执行所有查询时读取的总行数。
* `max_read_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内执行所有查询时允许读取的最大行数。
* `read_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内执行所有查询时读取的总字节数。
* `max_read_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内执行所有查询时允许读取的最大字节数。
* `execution_time` ([Nullable(Float64)](/zh/reference/data-types/nullable)) — 当前时间段内执行查询所花费的总时间 (单位为纳秒)
* `max_execution_time` ([Nullable(Float64)](/zh/reference/data-types/nullable)) — 在指定时间段内所有查询允许使用的最大执行时间 (单位为纳秒)
* `written_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内执行所有查询时写入的总字节数。
* `max_written_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内执行所有查询时允许写入的最大字节数。
* `failed_sequential_authentications` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内连续身份验证失败的次数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内允许的连续身份验证失败次数上限。
* `queries_per_normalized_hash` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 当前时间段内任一归一化查询的最大执行次数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 在指定时间段内任一归一化查询允许的最大执行次数。
