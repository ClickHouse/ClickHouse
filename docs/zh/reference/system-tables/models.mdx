## 描述 {#description}

<Warning>
  CatBoost 集成已从 ClickHouse 中移除，`system.models` 不再存在：查询该表会失败并返回 `UNKNOWN_TABLE`。保留本页仅为留存其曾发布的文档内容；如需了解当前存在的表，请参见[系统表概览](/zh/reference/system-tables/overview)。
</Warning>

曾包含加载到 `LibraryBridge` 内存中的 CatBoost 模型列表，以及各模型的加载时间。

## 列 {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/zh/reference/data-types/string)) — 已训练模型的路径。
* `type` ([String](/zh/reference/data-types/string)) — 模型类型。目前仅支持 catboost。
* `loading_start_time` ([DateTime](/zh/reference/data-types/datetime)) — 模型开始加载的时间。
* `loading_duration` ([Float32](/zh/reference/data-types/float)) — 加载模型所用的时间。

{/*AUTOGENERATED_END*/}
