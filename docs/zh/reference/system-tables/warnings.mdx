## 说明 {#description}

此表显示有关 ClickHouse 服务器的警告。
相同类型的警告会合并为一条警告。
例如，如果已挂载 (attached) 的数据库数量 N 超过可配置的阈值 T，则只显示一条包含当前值 N 的记录，而不是 N 条独立记录。
如果当前值降至阈值以下，该记录会从表中移除。

可通过以下设置配置此表：

* [max&#95;table&#95;num&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/zh/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/zh/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## 列 {#columns}

* `message` ([String](/zh/reference/data-types/string)) — 由 ClickHouse 服务器 发出的警告消息。
* `message_format_string` ([LowCardinality(String)](/zh/reference/data-types/lowcardinality)) — 用于格式化该消息的格式字符串。

## 示例 {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
