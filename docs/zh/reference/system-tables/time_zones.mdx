## 描述 {#description}

列出了 ClickHouse 服务器 支持的时区。该列表可能会因 ClickHouse 版本而异。

## 列 {#columns}

* `time_zone` ([String](/zh/reference/data-types/string)) — 支持的时区列表。

## 示例 {#example}

```sql
SELECT * FROM system.time_zones LIMIT 10
```

```text
┌─time_zone──────────┐
│ Africa/Abidjan     │
│ Africa/Accra       │
│ Africa/Addis_Ababa │
│ Africa/Algiers     │
│ Africa/Asmara      │
│ Africa/Asmera      │
│ Africa/Bamako      │
│ Africa/Bangui      │
│ Africa/Banjul      │
│ Africa/Bissau      │
└────────────────────┘
```
