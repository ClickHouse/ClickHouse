<div id="description">
  ## 描述
</div>

包含有关[服务器配置](/zh/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-multiple-volumes_configure)中定义的磁盘的信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types/string)) — 服务器配置中磁盘的名称。
* `path` ([String](/zh/reference/data-types/string)) — 文件系统中挂载点的路径。
* `free_space` ([UInt64](/zh/reference/data-types/int-uint)) — 磁盘上的可用空间，单位为字节。
* `total_space` ([UInt64](/zh/reference/data-types/int-uint)) — 磁盘卷容量，单位为字节。
* `unreserved_space` ([UInt64](/zh/reference/data-types/int-uint)) — 未被预留占用的可用空间 (free&#95;space 减去当前正在运行的合并、插入及其他磁盘写入操作所占用的预留空间) 。
* `keep_free_space` ([UInt64](/zh/reference/data-types/int-uint)) — 磁盘上应保留的可用空间，单位为字节。在磁盘配置的 keep&#95;free&#95;space&#95;bytes 参数中定义。
* `type` ([String](/zh/reference/data-types/string)) — 指示此磁盘存储数据位置的磁盘类型：RAM、本地驱动器或远程存储。
* `object_storage_type` ([String](/zh/reference/data-types/string)) — 如果磁盘类型为 object&#95;storage，则表示对象存储类型。
* `metadata_type` ([String](/zh/reference/data-types/string)) — 如果磁盘类型为 object&#95;storage，则表示元数据存储类型。
* `is_encrypted` ([UInt8](/zh/reference/data-types/int-uint)) — 指示此磁盘是否对底层数据进行加密的标志。
* `is_read_only` ([UInt8](/zh/reference/data-types/int-uint)) — 指示此磁盘只能执行读取操作的标志。
* `is_write_once` ([UInt8](/zh/reference/data-types/int-uint)) — 指示磁盘是否为一次写入磁盘的标志。这意味着支持向此磁盘执行 BACKUP，但不支持向此磁盘上的 MergeTree 表执行 INSERT。
* `is_remote` ([UInt8](/zh/reference/data-types/int-uint)) — 指示对此磁盘执行哪些操作会涉及网络交互的标志。
* `is_broken` ([UInt8](/zh/reference/data-types/int-uint)) — 指示磁盘是否损坏的标志。损坏的磁盘空间为 0，且无法使用。
* `cache_path` ([String](/zh/reference/data-types/string)) — 如果磁盘支持缓存，则表示本地驱动器上缓存目录的路径。

{/*AUTOGENERATED_END*/}
