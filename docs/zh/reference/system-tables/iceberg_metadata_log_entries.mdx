## 描述 {#description}

该系统表包含 ClickHouse 中现有 Iceberg 表的元数据文件，每个元数据文件对应一行。如果 ClickHouse 中不存在任何 Iceberg 表，则该系统表为空。

## 列 {#columns}

* `database` ([String](/zh/reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/reference/data-types/string)) — 表名。
* `timestamp` ([DateTime64(3)](/zh/reference/data-types/datetime64)) — 该元数据文件成为当前版本的日期和时间。
* `file` ([String](/zh/reference/data-types/string)) — 元数据文件的路径。
* `latest_snapshot_id` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 生成该元数据文件时最新快照的 ID。
* `latest_schema_id` ([Nullable(Int32)](/zh/reference/data-types/nullable)) — 最新快照的模式 ID。
* `latest_sequence_number` ([Nullable(Int64)](/zh/reference/data-types/nullable)) — 最新快照的序列号。
