<div id="description">
  ## 说明
</div>

包含系统中定义的所有脱敏策略相关信息。

脱敏策略只能在 ClickHouse Cloud 中创建和应用。在开源构建中，`system.masking_policies` 表始终为空，但该表仍然存在，以便 `SHOW MASKING POLICIES` 这类内部信息查询能够正常工作，并返回空结果而不是抛出异常。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types/string)) — 脱敏策略的名称。
* `short_name` ([String](/zh/reference/data-types/string)) — 脱敏策略的短名称。脱敏策略名称由多个部分组成，例如：mask&#95;email ON mydb.mytable。其中，&#39;mask&#95;email ON mydb.mytable&#39; 是脱敏策略的名称，&#39;mask&#95;email&#39; 是其短名称。
* `database` ([String](/zh/reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/reference/data-types/string)) — 表名称。
* `id` ([UUID](/zh/reference/data-types/uuid)) — 脱敏策略 ID。
* `storage` ([String](/zh/reference/data-types/string)) — 存储该脱敏策略的目录名称。
* `update_assignments` ([Nullable(String)](/zh/reference/data-types/nullable)) — 定义数据应如何脱敏的 UPDATE 赋值，例如：email = &#39;***masked***&#39;, phone = &#39;***-***-****&#39;。未设置时为 NULL。
* `where_condition` ([Nullable(String)](/zh/reference/data-types/nullable)) — 用于选择应用脱敏的行的可选条件。未设置时为 NULL。
* `priority` ([Int64](/zh/reference/data-types/int-uint)) — 脱敏策略的优先级。优先级更高的策略会先应用。
* `apply_to_all` ([UInt8](/zh/reference/data-types/int-uint)) — 表示该脱敏策略已为所有角色和/或用户设置。
* `apply_to_list` ([Array(String)](/zh/reference/data-types/array)) — 应用该脱敏策略的角色和/或用户列表。
* `apply_to_except` ([Array(String)](/zh/reference/data-types/array)) — 该脱敏策略适用于除所列角色和/或用户外的所有角色和/或用户。

{/*AUTOGENERATED_END*/}
