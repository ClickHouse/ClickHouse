<div id="description">
  ## 说明
</div>

包含通过 [`CREATE HANDLER`](/zh/reference/statements/create/handler) 创建的所有由 SQL 定义的 HTTP 处理程序 列表。

读取此表需要 `SHOW HANDLERS` 权限；否则该表显示为空。处理程序 查询中可能嵌入的 secret (例如传递给表函数的凭据) 仅当用户有权查看 secret 时，才会显示在
`query` 和 `create_query` 列中 (即已启用 `display_secrets_in_show_and_select` 服务器设置和 `format_display_secrets_in_show_and_select` 格式
设置，且用户拥有 `displaySecretsInShowAndSelect` 权限) ；否则会被掩码处理，与 `SHOW CREATE TABLE` 中的行为完全一致。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types/string)) — 处理程序 的名称。
* `protocol` ([Nullable(String)](/zh/reference/data-types/nullable)) — 处理程序 限定使用的可组合协议；如果 处理程序 在所有 HTTP 端点 (内置 `http`/`https` 端口以及所有 HTTP 类型的可组合协议 listener) 上均处于活动状态，则为 NULL。
* `url_match_type` ([String](/zh/reference/data-types/string)) — URL 匹配方式：精确匹配、前缀匹配或正则表达式匹配。
* `url` ([String](/zh/reference/data-types/string)) — 处理程序 要匹配的 URL 模式。
* `methods` ([Array(String)](/zh/reference/data-types/array)) — 允许的 HTTP 方法。
* `type` ([String](/zh/reference/data-types/string)) — 处理程序 类型 (仅支持 `query`) 。
* `query` ([String](/zh/reference/data-types/string)) — 处理程序 执行的 SQL 查询。除非用户有权查看，否则会隐藏 secrets。
* `create_query` ([String](/zh/reference/data-types/string)) — CREATE HANDLER 语句。除非用户有权查看，否则会隐藏 secrets。

{/*AUTOGENERATED_END*/}
