## 说明 {#description}

以单行单列的形式返回 jemalloc 统计信息。等同于 SYSTEM JEMALLOC STATS 命令。

## 列 {#columns}

* `stats` ([String](/zh/reference/data-types/string)) — 由 malloc&#95;stats&#95;print 输出的 JEMalloc 统计信息。
