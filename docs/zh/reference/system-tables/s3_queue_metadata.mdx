<div id="description">
  ## 说明
</div>

包含 Keeper 中每个 S3Queue 元数据对象当前已处理、处理中和失败节点的数量，并可按需显示其内容。与显示内存缓存的 system.s3queue&#95;metadata&#95;cache 不同，此表直接从 Keeper 读取状态。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/zh/reference/data-types/string)) — zookeeper 中元数据的路径。对于辅助 zookeeper 上的队列，此项为工厂键 `<zookeeper_name>:<path>`，而不是原始 Keeper 路径。
* `processed_nodes_count` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — keeper 中 `processed` 目录内的节点数。仅在 `unordered` 模式下设置：`ordered` 模式下不存在按文件记录的已处理节点 (请参阅 `processed_path`) ，因此该值为 NULL。
* `processing_nodes_count` ([UInt64](/zh/reference/data-types/int-uint)) — keeper 中 `processing` 目录内的节点数
* `failed_nodes_count` ([UInt64](/zh/reference/data-types/int-uint)) — keeper 中 `failed` 目录内的节点数
* `processed_nodes` ([Map(String, String)](/zh/reference/data-types/map)) — keeper 中 `processed` 目录的内容 (节点名称 -&gt; 节点数据) 。仅在 `unordered` 模式下填充。仅在选中此列时拉取。
* `processing_nodes` ([Map(String, String)](/zh/reference/data-types/map)) — keeper 中 `processing` 目录的内容 (节点名称 -&gt; 节点数据) 。仅在选中此列时拉取。
* `failed_nodes` ([Map(String, String)](/zh/reference/data-types/map)) — keeper 中 `failed` 目录的内容 (节点名称 -&gt; 节点数据) 。仅在选中此列时拉取。
* `processed_path` ([Map(String, String)](/zh/reference/data-types/map)) — keeper 中每个已处理指针对应的最后处理路径 (相对指针路径 -&gt; 最后处理的文件路径) 。仅在 `ordered` 模式下填充，涵盖单个指针、按 bucket 划分的指针和按分区划分的指针。仅在选中此列时拉取。

{/*AUTOGENERATED_END*/}
