<div id="description">
  ## 描述
</div>

包含某个特定表的过滤器，以及应使用该行策略的角色和/或用户列表。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types/string)) — 行策略名称。
* `short_name` ([String](/zh/reference/data-types/string)) — 行策略的简称。行策略名称由多个部分组成，例如：myfilter ON mydb.mytable。此处 &#39;myfilter ON mydb.mytable&#39; 为行策略名称，&#39;myfilter&#39; 为其简称。
* `database` ([String](/zh/reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/reference/data-types/string)) — 表名称。若为数据库策略，则为空。
* `id` ([UUID](/zh/reference/data-types/uuid)) — 行策略 ID。
* `storage` ([String](/zh/reference/data-types/string)) — 存储行策略的目录名称。
* `select_filter` ([Nullable(String)](/zh/reference/data-types/nullable)) — 用于在 SELECT 查询中筛选的表达式。
* `is_restrictive` ([UInt8](/zh/reference/data-types/int-uint)) — 表示行策略是否限制对行的访问。值：• 0 — 行策略通过 `AS PERMISSIVE` 子句定义，• 1 — 行策略通过 `AS RESTRICTIVE` 子句定义。
* `apply_to_all` ([UInt8](/zh/reference/data-types/int-uint)) — 表示行策略是否应用于所有角色和/或用户。
* `apply_to_list` ([Array(String)](/zh/reference/data-types/array)) — 应用行策略的角色和/或用户列表。
* `apply_to_except` ([Array(String)](/zh/reference/data-types/array)) — 行策略应用于除所列角色和/或用户外的所有角色和/或用户。

{/*AUTOGENERATED_END*/}
