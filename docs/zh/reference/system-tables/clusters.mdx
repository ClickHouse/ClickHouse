<div id="description">
  ## 描述
</div>

包含配置文件中可用集群及其服务器的信息。

<div id="Columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `cluster` ([String](/zh/reference/data-types/string)) — 集群名称。
* `shard_num` ([UInt32](/zh/reference/data-types/int-uint)) — 集群中 сегмент 的编号，从 1 开始。
* `shard_name` ([String](/zh/reference/data-types/string)) — 集群中 сегмент 的名称。
* `shard_weight` ([UInt32](/zh/reference/data-types/int-uint)) — 写入数据时 сегмент 的相对权重。
* `internal_replication` ([UInt8](/zh/reference/data-types/int-uint)) — 指示此主机是否属于可自行复制数据的协调组的标志。
* `replica_num` ([UInt32](/zh/reference/data-types/int-uint)) — сегмент 中副本的编号，从 1 开始。
* `host_name` ([String](/zh/reference/data-types/string)) — 配置中指定的主机名。
* `host_address` ([String](/zh/reference/data-types/string)) — 通过 DNS 获取的主机 IP 地址。
* `port` ([UInt16](/zh/reference/data-types/int-uint)) — 用于连接服务器的端口。
* `is_local` ([UInt8](/zh/reference/data-types/int-uint)) — 指示该主机是否为本地主机的标志。
* `user` ([String](/zh/reference/data-types/string)) — 用于连接服务器的用户名。
* `default_database` ([String](/zh/reference/data-types/string)) — 默认数据库名称。
* `errors_count` ([UInt32](/zh/reference/data-types/int-uint)) — 此主机无法连接到副本的次数。
* `slowdowns_count` ([UInt32](/zh/reference/data-types/int-uint)) — 使用对冲请求建立连接时，导致切换副本的慢速响应次数。
* `estimated_recovery_time` ([UInt32](/zh/reference/data-types/int-uint)) — 副本错误计数归零并被视为恢复正常前的剩余秒数。
* `database_shard_name` ([String](/zh/reference/data-types/string)) — `Replicated` 数据库 сегмент 的名称 (适用于属于 `Replicated` 数据库的集群) 。
* `database_replica_name` ([String](/zh/reference/data-types/string)) — `Replicated` 数据库副本的名称 (适用于属于 `Replicated` 数据库的集群) 。
* `is_shared_catalog_cluster` ([UInt8](/zh/reference/data-types/int-uint)) — Bool，指示集群是否属于 Shared Catalog。
* `is_active` ([Nullable(UInt8)](/zh/reference/data-types/nullable)) — Replicated 数据库副本的状态 (适用于属于 Replicated 数据库的集群) ：1 表示 &#39;副本在线&#39;，0 表示 &#39;副本离线&#39;，NULL 表示 &#39;未知&#39;。
* `unsynced_after_recovery` ([Nullable(UInt8)](/zh/reference/data-types/nullable)) — 指示 Replicated 数据库副本在创建或恢复后，其复制延迟是否超过 max&#95;replication&#95;lag&#95;to&#95;enqueue。
* `replication_lag` ([Nullable(UInt32)](/zh/reference/data-types/nullable)) — `Replicated` 数据库副本的复制延迟 (适用于属于 Replicated 数据库的集群) 。
* `recovery_time` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — `Replicated` 数据库副本的恢复时间 (适用于属于 Replicated 数据库的集群) ，单位为毫秒。

**别名：**

* `name` — `cluster` 的别名。

{/*AUTOGENERATED_END*/}
