## 描述 {#description}

与 [`system.numbers`](/zh/reference/system-tables/numbers) 相同，但读取被并行化。返回的数字顺序可能是任意的。

用于测试。

## 列 {#columns}

* `number` ([UInt64](/zh/reference/data-types/int-uint))

SELECT * FROM system.numbers_mt LIMIT 10;
