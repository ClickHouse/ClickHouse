## 描述 {#description}

包含所有表中现有投影的信息。

`total_rows`、`data_compressed_bytes` 和 `data_uncompressed_bytes` 列是基于表中包含该投影的活跃 parts 求和得出的，因此在投影构建完成之前，这些值均为零。投影可通过添加投影之后执行的插入操作或 `ALTER TABLE ... MATERIALIZE PROJECTION` 来构建。如需了解每个投影数据分片的大小，请参阅 [system.projection&#95;parts](/zh/operations/system-tables/projection_parts)。

## 列 {#columns}

* `database` ([String](/zh/reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/reference/data-types/string)) — 表名称。
* `name` ([String](/zh/reference/data-types/string)) — 投影名称。
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/zh/reference/data-types/enum)) — 投影类型。
* `total_rows` ([UInt64](/zh/reference/data-types/int-uint)) — 总行数。
* `data_compressed_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 已压缩数据的大小，以字节为单位。
* `data_uncompressed_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 已解压数据的大小，以字节为单位。
* `sorting_key` ([Array(String)](/zh/reference/data-types/array)) — 投影排序键。
* `query` ([String](/zh/reference/data-types/string)) — 投影查询。
* `settings` ([Map(String, String)](/zh/reference/data-types/map)) — 投影设置。
