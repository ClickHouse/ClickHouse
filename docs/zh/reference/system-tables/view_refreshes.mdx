<div id="description">
  ## 描述
</div>

有关[可刷新materialized view](/zh/reference/statements/create/view#refreshable-materialized-view)的信息。包含所有可刷新materialized view，无论当前是否有刷新正在进行。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/zh/reference/data-types/string)) — 表所在的数据库名称。
* `view` ([String](/zh/reference/data-types/string)) — 表名称。
* `uuid` ([UUID](/zh/reference/data-types/uuid)) — 表的 UUID (Atomic 数据库) 。
* `status` ([String](/zh/reference/data-types/string)) — 当前刷新状态。
* `last_success_time` ([Nullable(DateTime)](/zh/reference/data-types/nullable)) — 最近一次成功刷新开始的时间。自 server 启动或表创建以来如果未成功刷新过，则为 NULL。
* `last_success_duration_ms` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 最近一次刷新所耗时间。
* `last_refresh_time` ([Nullable(DateTime)](/zh/reference/data-types/nullable)) — 最近一次刷新尝试的完成时间 (如果已知) ，或开始时间 (如果未知或仍在运行) 。自 server 启动或表创建以来如果未进行过刷新尝试，则为 NULL。
* `last_refresh_replica` ([String](/zh/reference/data-types/string)) — 如果已启用协调，执行当前刷新尝试 (如果正在运行) 或上一次刷新尝试 (如果未运行) 的副本名称。
* `next_refresh_time` ([Nullable(DateTime)](/zh/reference/data-types/nullable)) — 计划开始下一次刷新的时间。如果当前无法确定下一次刷新时间，则为 NULL，例如等待依赖项时 (状态为 `WaitingForDependencies` 或 `MissingDependencies`) 。
* `exception` ([String](/zh/reference/data-types/string)) — 上一次尝试失败时的错误消息。
* `retry` ([UInt64](/zh/reference/data-types/int-uint)) — 当前刷新截至目前的失败尝试次数。如果状态为 `RunningOnAnotherReplica`，则不可用。
* `progress` ([Nullable(Float64)](/zh/reference/data-types/nullable)) — 指定副本上当前正在运行或最近完成的刷新进度，取值范围为 0 到 1。如果状态为 `RunningOnAnotherReplica` 或刷新未运行，则为 NULL。
* `read_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 指定副本上当前正在运行或最近完成的刷新已读取的行数。如果状态为 `RunningOnAnotherReplica`，则为 NULL。
* `read_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 指定副本上当前正在运行或最近完成的刷新已读取的字节数。如果状态为 `RunningOnAnotherReplica`，则为 NULL
* `total_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 指定副本上当前正在运行或最近完成的刷新预计需要读取的总行数。如果状态为 `RunningOnAnotherReplica`，则为 NULL
* `written_rows` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 指定副本上当前正在运行或最近完成的刷新已写入的行数。如果状态为 `RunningOnAnotherReplica`，则为 NULL
* `written_bytes` ([Nullable(UInt64)](/zh/reference/data-types/nullable)) — 指定副本上当前正在运行或最近完成的刷新已写入的字节数。如果状态为 `RunningOnAnotherReplica`，则为 NULL

{/*AUTOGENERATED_END*/}
