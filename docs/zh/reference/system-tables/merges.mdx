<div id="description">
  ## 描述
</div>

包含 MergeTree 家族中的表当前正在进行的合并和 part mutation 的相关信息。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/zh/reference/data-types/string)) — 表所在数据库的名称。
* `table` ([String](/zh/reference/data-types/string)) — 表名。
* `elapsed` ([Float64](/zh/reference/data-types/float)) — 自合并开始以来经过的时间 (单位：秒) 。
* `progress` ([Float64](/zh/reference/data-types/float)) — 已完成工作的比例，范围为 0 到 1。
* `num_parts` ([UInt64](/zh/reference/data-types/int-uint)) — 要合并的 parts 数量。
* `source_part_names` ([Array(String)](/zh/reference/data-types/array)) — 源 parts 的名称列表。
* `result_part_name` ([String](/zh/reference/data-types/string)) — 合并后生成的 part 名称。
* `source_part_paths` ([Array(String)](/zh/reference/data-types/array)) — 各源 part 的路径列表。
* `result_part_path` ([String](/zh/reference/data-types/string)) — 合并后生成的 part 的路径。
* `partition_id` ([String](/zh/reference/data-types/string)) — 正在进行合并的分区标识符。
* `partition` ([String](/zh/reference/data-types/string)) — 分区名称
* `is_mutation` ([UInt8](/zh/reference/data-types/int-uint)) — 如果此过程为 part mutation，则为 1。
* `total_size_bytes_compressed` ([UInt64](/zh/reference/data-types/int-uint)) — 已合并 chunks 中压缩数据的总大小。
* `total_size_bytes_uncompressed` ([UInt64](/zh/reference/data-types/int-uint)) — 已合并 chunks 中压缩数据的总大小。
* `total_size_marks` ([UInt64](/zh/reference/data-types/int-uint)) — 已合并 parts 中标记的总数。
* `bytes_read_uncompressed` ([UInt64](/zh/reference/data-types/int-uint)) — 读取的未压缩字节数。
* `rows_read` ([UInt64](/zh/reference/data-types/int-uint)) — 读取的行数。
* `bytes_written_uncompressed` ([UInt64](/zh/reference/data-types/int-uint)) — 写入的未压缩字节数。
* `rows_written` ([UInt64](/zh/reference/data-types/int-uint)) — 写入的行数。
* `columns_written` ([UInt64](/zh/reference/data-types/int-uint)) — 写入的列数 (适用于 Vertical 合并 algorithm) 。
* `memory_usage` ([UInt64](/zh/reference/data-types/int-uint)) — 合并过程的内存消耗。
* `thread_id` ([UInt64](/zh/reference/data-types/int-uint)) — 合并过程的线程 ID。
* `merge_type` ([String](/zh/reference/data-types/string)) — 当前合并的类型。如果是 mutation，则为空。
* `merge_algorithm` ([String](/zh/reference/data-types/string)) — 当前合并使用的算法。如果是 mutation，则为空。
* `current_projection` ([String](/zh/reference/data-types/string)) — 当前正在合并或重建的 projection 名称。如果不处于 projection 合并阶段，则为空。
* `current_projection_progress` ([Float64](/zh/reference/data-types/float)) — 当前 projection 合并的进度，范围为 0 到 1。
* `current_projection_parts_merging` ([UInt64](/zh/reference/data-types/int-uint)) — 当前正在合并的 projection parts 数量。
* `current_projection_parts_remaining` ([UInt64](/zh/reference/data-types/int-uint)) — 当前 projection 尚待合并的 projection parts 数量。
* `projections_completed` ([Array(String)](/zh/reference/data-types/array)) — 截至目前已合并或重建的 projections 列表。
* `projections_remaining` ([Array(String)](/zh/reference/data-types/array)) — 仍需合并或重建的 projections 列表。

{/*AUTOGENERATED_END*/}
