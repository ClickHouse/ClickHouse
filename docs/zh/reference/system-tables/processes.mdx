<div id="description">
  ## 描述
</div>

该系统表用于实现 `SHOW PROCESSLIST` 查询。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/zh/reference/data-types/int-uint)) — 此查询是直接由用户发起，还是由 ClickHouse server 在分布式查询执行过程中发起。
* `user` ([String](/zh/reference/data-types/string)) — 发起该查询的用户。请注意，在分布式处理过程中，查询会以 default 用户身份发送到远程服务器。该字段包含当前查询的用户名，而非由该查询发起的查询的用户名。
* `query_id` ([String](/zh/reference/data-types/string)) — 查询 ID (如已定义) 。
* `address` ([IPv6](/zh/reference/data-types/ipv6)) — 发起查询的 IP 地址。分布式处理时也是如此。要追踪分布式查询最初从何处发起，请查看查询发起方服务器上的 system.processes。
* `port` ([UInt16](/zh/reference/data-types/int-uint)) — 发起查询所用的客户端端口。
* `initial_user` ([String](/zh/reference/data-types/string)) — 执行初始查询的用户名 (用于分布式查询执行) 。
* `initial_query_id` ([String](/zh/reference/data-types/string)) — 初始查询的 ID (用于分布式查询执行) 。
* `initial_address` ([IPv6](/zh/reference/data-types/ipv6)) — 发起父查询的 IP 地址。
* `initial_port` ([UInt16](/zh/reference/data-types/int-uint)) — 发起父查询所用的客户端端口。
* `interface` ([UInt8](/zh/reference/data-types/int-uint)) — 发送查询所使用的接口。TCP = 1，HTTP = 2，GRPC = 3，MYSQL = 4，POSTGRESQL = 5，LOCAL = 6，TCP&#95;INTERSERVER = 7。
* `os_user` ([String](/zh/reference/data-types/string)) — 运行 clickhouse-client 的操作系统用户名。
* `client_hostname` ([String](/zh/reference/data-types/string)) — 运行 clickhouse-client 或其他 TCP 客户端的客户端主机名。
* `client_name` ([String](/zh/reference/data-types/string)) — clickhouse-client 或其他 TCP 客户端的名称。
* `client_agent` ([LowCardinality(String)](/zh/reference/data-types/lowcardinality)) — 调用客户端的 AI 编程 agent (例如 `claude-code`、`cursor`) ，通过环境变量检测。未检测到 agent 时为空。
* `client_revision` ([UInt64](/zh/reference/data-types/int-uint)) — clickhouse-client 或其他 TCP 客户端的修订版本。
* `client_version_major` ([UInt64](/zh/reference/data-types/int-uint)) — clickhouse-client 或其他 TCP 客户端的主版本。
* `client_version_minor` ([UInt64](/zh/reference/data-types/int-uint)) — clickhouse-client 或其他 TCP 客户端的次版本。
* `client_version_patch` ([UInt64](/zh/reference/data-types/int-uint)) — clickhouse-client 或其他 TCP 客户端版本的补丁版本号。
* `http_method` ([UInt8](/zh/reference/data-types/int-uint)) — 发起查询所使用的 HTTP 方法。可能的值：0 — 查询通过 TCP 接口发起。1 — 使用 GET 方法。2 — 使用 POST 方法。
* `http_user_agent` ([String](/zh/reference/data-types/string)) — HTTP 查询中传递的 UserAgent HTTP 请求头。
* `http_referer` ([String](/zh/reference/data-types/string)) — HTTP 查询中传递的 Referer HTTP 请求头 (包含发起查询页面的完整或部分地址) 。
* `forwarded_for` ([String](/zh/reference/data-types/string)) — HTTP 查询中传递的 X-Forwarded-For HTTP 请求头。
* `quota_key` ([String](/zh/reference/data-types/string)) — quotas 设置中指定的配额键 (请参阅 keyed) 。
* `distributed_depth` ([UInt64](/zh/reference/data-types/int-uint)) — 查询在服务器节点之间内部转发的次数。
* `elapsed` ([Float64](/zh/reference/data-types/float)) — 自请求开始执行以来经过的时间 (秒) 。
* `is_cancelled` ([UInt8](/zh/reference/data-types/int-uint)) — 查询是否已取消。
* `is_all_data_sent` ([UInt8](/zh/reference/data-types/int-uint)) — 是否已将所有数据发送给客户端 (即查询已在服务器端完成) 。
* `read_rows` ([UInt64](/zh/reference/data-types/int-uint)) — 从表中读取的行数。对于分布式处理，在请求方服务器上，该值为所有远程服务器的总和。
* `read_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 从表中读取的未压缩字节数。对于分布式处理，在请求方服务器上，该值为所有远程服务器的总和。
* `total_rows_approx` ([UInt64](/zh/reference/data-types/int-uint)) — 预计需要读取的总行数。对于分布式处理，在请求方服务器上，该值为所有远程服务器的总和。请求处理过程中发现新的数据源时，该值可能会更新。
* `written_rows` ([UInt64](/zh/reference/data-types/int-uint)) — 写入存储的行数。
* `written_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 写入存储的字节数。
* `memory_usage` ([Int64](/zh/reference/data-types/int-uint)) — 查询使用的 RAM 量，可能不包括某些类型的专用内存。
* `peak_memory_usage` ([Int64](/zh/reference/data-types/int-uint)) — 当前内存使用量的峰值。
* `query` ([String](/zh/reference/data-types/string)) — 查询文本。对于 INSERT，不包含待插入的数据。
* `normalized_query_hash` ([UInt64](/zh/reference/data-types/int-uint)) — 数值哈希值；例如，仅字面量值不同的查询具有相同的哈希值。
* `query_kind` ([String](/zh/reference/data-types/string)) — 查询类型，例如 SELECT、INSERT 等。
* `thread_ids` ([Array(UInt64)](/zh/reference/data-types/array)) — 参与此查询的所有线程的标识符列表。
* `peak_threads_usage` ([UInt64](/zh/reference/data-types/int-uint)) — 同时执行该查询的线程数峰值。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/zh/reference/data-types/map)) — 此查询的 ProfileEvents。
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/zh/reference/data-types/map)) — 已修改的用户级设置列表。
* `current_database` ([String](/zh/reference/data-types/string)) — 当前数据库的名称。
* `is_internal` ([UInt8](/zh/reference/data-types/int-uint)) — 指示该查询是否为内部执行的辅助查询。

**别名：**

* `ProfileEvents.Names` 是 `mapKeys(ProfileEvents)` 的别名。
* `ProfileEvents.Values` 是 `mapValues(ProfileEvents)` 的别名。
* `Settings.Names` 是 `mapKeys(Settings)` 的别名。
* `Settings.Values` 是 `mapValues(Settings)` 的别名。

{/*AUTOGENERATED_END*/}

SELECT * FROM system.processes LIMIT 10 FORMAT Vertical;
