<div id="description">
  ## 说明
</div>

包含 ClickHouse 的所有 SQL 语句。

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/zh/reference/data-types/string)) — SQL 语句的名称。
* `syntax` ([String](/zh/reference/data-types/string)) — 语句的语法。
* `description` ([String](/zh/reference/data-types/string)) — 语句功能说明，包括用法示例。
* `parent_name` ([String](/zh/reference/data-types/string)) — 包含该语句的父语句名称，例如 WHERE 子句的父语句为 SELECT。顶层语句为空。
* `related` ([Array(String)](/zh/reference/data-types/array)) — 相关语句的名称。

{/*AUTOGENERATED_END*/}
