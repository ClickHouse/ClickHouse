## 描述 {#description}

列出通过 SQL 查询创建或从配置文件解析得到的所有命名集合。

## 列 {#columns}

* `name` ([String](/zh/reference/data-types/string)) — 集合名称。
* `collection` ([Map(String, String)](/zh/reference/data-types/map)) — 集合内部信息。
* `source` ([String](/zh/reference/data-types/string)) — 命名集合源。
* `create_query` ([String](/zh/reference/data-types/string)) — 命名集合的创建查询。
