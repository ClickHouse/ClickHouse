<div id="description">
  ## 描述
</div>

包含来自 [system.dropped&#95;tables](/zh/reference/system-tables/dropped_tables) 的已删除 [MergeTree](/zh/reference/engines/table-engines/mergetree-family/mergetree) 表的 parts 信息

此表的 schema 与 [system.parts](/zh/reference/system-tables/parts) 相同

<div id="columns">
  ## 列
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/zh/reference/data-types/string)) — 分区标识符 (由表分区键表达式生成的字符串表示形式) 。
* `name` ([String](/zh/reference/data-types/string)) — 数据分区片段的名称。可通过分片命名结构确定数据、摄取和合并模式的许多特征。分片命名格式如下：

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * 定义：
    * `partition_id` - 标识分区键
    * `minimum_block_number` - 标识 part 中的最小块编号。ClickHouse 始终合并连续的块
    * `maximum_block_number` - 标识 part 中的最大块编号
    * `level` - 每对 part 进行一次额外合并，该值就递增 1。级别为 0 表示这是一个尚未合并的新 part。请注意，ClickHouse 中的所有 part 始终不可变
    * `data_version` - 可选值，part 发生变更时递增 (同样，由于 part 不可变，更改后的数据始终只会写入新的 part)
* `uuid` ([UUID](/zh/reference/data-types/uuid)) — 数据分区片段的 UUID。
* `part_type` ([String](/zh/reference/data-types/string)) — 数据分区片段的存储格式。可能的值：`Wide` — 每列存储在单独的文件中；`Compact` — 所有列存储在同一个文件中。数据存储格式由 MergeTree 表的 `min_bytes_for_wide_part` 和 `min_rows_for_wide_part` 设置控制。
* `part_storage_type` ([String](/zh/reference/data-types/string)) — `DataPartStorage` 的类型。可能的值：`Packed` — 大多数数据分区片段文件存储在单个归档文件中 (投影和少量服务文件 (如 `txn_version.txt`) 会单独写入) ；`Full` — 每个文件单独存储。
* `active` ([UInt8](/zh/reference/data-types/int-uint)) — 指示数据分区片段是否处于活动状态的标志。活动的数据分区片段会用于表中；否则即将被删除。非活动的数据分区片段会在合并和变更操作后出现。
* `marks` ([UInt64](/zh/reference/data-types/int-uint)) — 标记数。要估算数据分区片段中的行数，请将标记数乘以索引粒度 (通常为 8192)  (此方法不适用于自适应粒度) 。
* `rows` ([UInt64](/zh/reference/data-types/int-uint)) — 行数。
* `files` ([UInt64](/zh/reference/data-types/int-uint)) — 数据分区片段中的文件数。
* `bytes_on_disk` ([UInt64](/zh/reference/data-types/int-uint)) — 所有数据分区片段文件的总大小 (以字节为单位) 。
* `data_compressed_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 数据分区片段中压缩数据的总大小，不包括所有辅助文件 (例如，带标记的文件) 。
* `data_uncompressed_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 数据分区片段中未压缩数据的总大小，不包括所有辅助文件 (例如，带标记的文件) 。
* `primary_key_size` ([UInt64](/zh/reference/data-types/int-uint)) — 磁盘上 primary.idx/cidx 文件中主键值占用的内存量 (以字节为单位) 。
* `marks_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 带标记的文件大小。
* `secondary_indices_compressed_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 数据分区片段中次级索引压缩数据的总大小，不包括所有辅助文件 (例如，带标记的文件) 。
* `secondary_indices_uncompressed_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 数据分区片段中次级索引未压缩数据的总大小，不包括所有辅助文件 (例如，带标记的文件) 。
* `secondary_indices_marks_bytes` ([UInt64](/zh/reference/data-types/int-uint)) — 次级索引带标记的文件大小。
* `modification_time` ([DateTime](/zh/reference/data-types/datetime)) — 包含数据分区片段的目录的修改时间，通常对应于数据分区片段的创建时间。
* `remove_time` ([DateTime](/zh/reference/data-types/datetime)) — 数据分区片段变为非活动状态的时间。
* `refcount` ([UInt32](/zh/reference/data-types/int-uint)) — 数据分区片段被使用的位置数。值大于 2 表示该数据分区片段正被查询或合并操作使用。
* `min_date` ([Date](/zh/reference/data-types/date)) — 数据分区片段中日期键的最小值。
* `max_date` ([Date](/zh/reference/data-types/date)) — 数据分区片段中日期键的最大值。
* `min_time` ([DateTime](/zh/reference/data-types/datetime)) — 数据分区片段中日期时间键的最小值。
* `max_time` ([DateTime](/zh/reference/data-types/datetime)) — 数据分区片段中日期时间键的最大值。
* `partition_id` ([String](/zh/reference/data-types/string)) — 分区 ID。
* `min_block_number` ([Int64](/zh/reference/data-types/int-uint)) — 合并后构成当前数据分区片段的数据分区片段的最小编号。
* `max_block_number` ([Int64](/zh/reference/data-types/int-uint)) — 合并后构成当前数据分区片段的数据分区片段的最大编号。
* `level` ([UInt32](/zh/reference/data-types/int-uint)) — 合并树的层级深度。0 表示当前分片由插入操作创建，而非通过合并其他分片创建。
* `data_version` ([UInt64](/zh/reference/data-types/int-uint)) — 用于确定应对数据分区片段应用哪些变更的版本号 (版本高于 data&#95;version 的变更) 。
* `primary_key_bytes_in_memory` ([UInt64](/zh/reference/data-types/int-uint)) — 主键值占用的内存量 (以字节为单位) 。启用 `primary_key_lazy_load` 且未加载主键时，此值为 0。非零时，这些字节由分片本身持有，并计入 `jemalloc.mergetree_arena.active_bytes`。它们绝不会计入 `PrimaryIndexCacheBytes`：对于每个分片，两者互斥。索引要么位于分片中 (此指标) ，要么位于共享的 `PrimaryIndexCache` 中 (另一指标) ，具体取决于 `primary_key_lazy_load` 和 `use_primary_key_cache`。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/zh/reference/data-types/int-uint)) — 为主键值预留的内存量 (以字节为单位) 。启用 `primary_key_lazy_load` 且未加载主键时，此值为 0。非零时，计入 `jemalloc.mergetree_arena.active_bytes`。有关其与 `PrimaryIndexCacheBytes` 的关系，请参阅 `primary_key_bytes_in_memory` 的说明。
* `index_granularity_bytes_in_memory` ([UInt64](/zh/reference/data-types/int-uint)) — 索引粒度值占用的内存量 (以字节为单位) 。当 primary&#95;key&#95;lazy&#95;load=1 且 use&#95;primary&#95;key&#95;cache=1 时，此值为 0。非零时，这些字节由分片本身持有，并计入 `jemalloc.mergetree_arena.active_bytes`。
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/zh/reference/data-types/int-uint)) — 为索引粒度值预留的内存量 (以字节为单位) 。当 primary&#95;key&#95;lazy&#95;load=1 且 use&#95;primary&#95;key&#95;cache=1 时，此值为 0。非零时，计入 `jemalloc.mergetree_arena.active_bytes`。
* `is_frozen` ([UInt8](/zh/reference/data-types/int-uint)) — 表示分区数据备份是否存在的标志。1 表示备份存在；0 表示备份不存在。有关详细信息，请参阅 FREEZE PARTITION。
* `database` ([String](/zh/reference/data-types/string)) — 数据库名称。
* `table` ([String](/zh/reference/data-types/string)) — 表名称。
* `engine` ([String](/zh/reference/data-types/string)) — 不含参数的表引擎名称。
* `disk_name` ([String](/zh/reference/data-types/string)) — 存储数据分区片段的磁盘名称。
* `path` ([String](/zh/reference/data-types/string)) — 数据分区片段文件所在目录的绝对路径。
* `hash_of_all_files` ([String](/zh/reference/data-types/string)) — 压缩文件的 sipHash128。
* `hash_of_uncompressed_files` ([String](/zh/reference/data-types/string)) — 未压缩文件 (标记文件、索引文件等) 的 sipHash128。
* `uncompressed_hash_of_compressed_files` ([String](/zh/reference/data-types/string)) — 将压缩文件中的数据视为未压缩数据时计算的 sipHash128。
* `delete_ttl_info_min` ([DateTime](/zh/reference/data-types/datetime)) — 生存时间 (TTL) DELETE 规则的日期时间键最小值。
* `delete_ttl_info_max` ([DateTime](/zh/reference/data-types/datetime)) — 生存时间 (TTL) DELETE 规则的日期时间键最大值。
* `move_ttl_info.expression` ([Array(String)](/zh/reference/data-types/array)) — 表达式数组。每个表达式定义一条 TTL MOVE 规则。
* `move_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types/array)) — 日期时间值数组。每个元素表示一条 TTL MOVE 规则的最小键值。
* `move_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types/array)) — 日期时间值数组。每个元素表示一条 TTL MOVE 规则的最大键值。
* `default_compression_codec` ([String](/zh/reference/data-types/string)) — 当列未显式指定编解码器或使用 `CODEC(Default)` 时，用于压缩此数据分区片段的编解码器名称。启用 `allow_experimental_adaptive_codec_selection` 后，此类列的各个块可能使用其他编解码器；请参阅 [`mergeTreeCodecBlockCounts`](/zh/reference/functions/table-functions/mergeTreeCodecBlockCounts)。
* `recompression_ttl_info.expression` ([Array(String)](/zh/reference/data-types/array)) — 生存时间 (TTL) 表达式。
* `recompression_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types/array)) — 此数据分区片段中计算得到的生存时间 (TTL) 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已过期。
* `recompression_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types/array)) — 此数据分区片段中计算得到的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `group_by_ttl_info.expression` ([Array(String)](/zh/reference/data-types/array)) — 生存时间 (TTL) 表达式。
* `group_by_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types/array)) — 此数据分区片段中计算得到的生存时间 (TTL) 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已过期。
* `group_by_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types/array)) — 此数据分区片段中计算得到的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `rows_where_ttl_info.expression` ([Array(String)](/zh/reference/data-types/array)) — 生存时间 (TTL) 表达式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/zh/reference/data-types/array)) — 此数据分区片段中计算得到的生存时间 (TTL) 表达式的最小值。用于判断是否至少有一行的生存时间 (TTL) 已过期。
* `rows_where_ttl_info.max` ([Array(DateTime)](/zh/reference/data-types/array)) — 此数据分区片段中计算得到的生存时间 (TTL) 表达式的最大值。用于判断是否所有行的生存时间 (TTL) 都已过期。
* `projections` ([Array(String)](/zh/reference/data-types/array)) — 为此数据分区片段计算的投影名称列表。
* `visible` ([UInt8](/zh/reference/data-types/int-uint)) — 指示此数据分区片段是否对 SELECT 查询可见的标志。
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/zh/reference/data-types/tuple)) — 已创建或正尝试创建此对象的事务 ID。
* `removal_tid_lock` ([UInt64](/zh/reference/data-types/int-uint)) — removal&#95;tid 的哈希值，用于锁定待移除的对象。
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/zh/reference/data-types/tuple)) — 已移除或正尝试移除此对象的事务 ID
* `creation_csn` ([UInt64](/zh/reference/data-types/int-uint)) — 创建此对象的事务的 CSN
* `removal_csn` ([UInt64](/zh/reference/data-types/int-uint)) — 移除此对象的事务的 CSN
* `has_lightweight_delete` ([UInt8](/zh/reference/data-types/int-uint)) — 指示该数据分区片段是否具有轻量级删除掩码的标志。
* `last_removal_attempt_time` ([DateTime](/zh/reference/data-types/datetime)) — server 上次尝试删除此数据分区片段的时间。
* `removal_state` ([String](/zh/reference/data-types/string)) — 数据分区片段移除过程的当前状态。

**别名：**

* `bytes` — `bytes_on_disk` 的别名。
* `marks_size` — `marks_bytes` 的别名。
* `part_name` — `name` 的别名。
