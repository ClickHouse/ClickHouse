创建一个临时 [Merge](/zh/reference/engines/table-engines/special/merge) 表。
该表的 schema 通过对底层表的列取并集并推导公共类型得出。
也可使用与 [Merge](/zh/reference/engines/table-engines/special/merge) 表引擎相同的虚拟列。

## 语法 {#syntax}

```sql
merge(['db_name',] 'tables_regexp')
```

## 参数 {#arguments}

| 参数              | 描述                                                                                                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | 可能的取值 (可选，默认为 `currentDatabase()`) ：<br />    - 数据库名称，<br />    - 返回数据库名称字符串的常量表达式，例如 `currentDatabase()`，<br />    - `REGEXP(expression)`，其中 `expression` 是用于匹配 DB 名称的正则表达式。 |
| `tables_regexp` | 用于匹配指定 DB 或多个 DB 中表名的正则表达式。                                                                                                                                                   |

## 访问权限 {#access-rights}

读取匹配到的表时，遵循与 [Merge](/zh/reference/engines/table-engines/special/merge#access-rights) 表引擎相同的访问规则。数据仅从当前用户可见的匹配表中读取，即当前用户拥有 [`SHOW TABLES`](/zh/reference/statements/grant#show) 特权的表，表结构也仅根据这些表推导得出。对于用户不可见的匹配表，系统会直接跳过，不会报错。推导表结构需要对作为推导来源的表拥有 [`SHOW COLUMNS`](/zh/reference/statements/grant#show) 特权。读取用户可见的匹配表时，需要对查询所读取的列拥有 [`SELECT`](/zh/reference/statements/grant#select) 特权，否则查询将失败并返回 `ACCESS_DENIED`。
