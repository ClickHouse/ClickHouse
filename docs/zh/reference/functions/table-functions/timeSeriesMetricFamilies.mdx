`timeSeriesMetricFamilies(db_name.time_series_table)` - 返回表引擎为 [TimeSeries](/zh/reference/engines/table-engines/integrations/time-series) 引擎的表 `db_name.time_series_table` 所使用的 [metric families](/zh/reference/engines/table-engines/integrations/time-series#metric-families-table) 表：

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES metric_families_table
```

当 *metric families* 表作为内表时，该函数同样有效：

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

以下查询是等价的：

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  函数 `timeSeriesMetricFamilies` 有一个别名 `timeSeriesMetrics`，保留该别名是为了向后兼容。
</Note>
