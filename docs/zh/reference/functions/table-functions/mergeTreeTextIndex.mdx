表示 MergeTree 表中文本索引的字典。
返回标记及其倒排列表元数据。
可用于查看内部信息。

## 语法 {#syntax}

```sql
mergeTreeTextIndex(database, table, index_name)
```

## 参数 {#arguments}

| 参数           | 描述               |
| ------------ | ---------------- |
| `database`   | 要读取其中文本索引的数据库名称。 |
| `table`      | 要读取其中文本索引的表名称。   |
| `index_name` | 要读取的文本索引名称。      |

## 返回值 {#returned-value}

一个包含标记及其倒排列表元数据的表。

如果索引使用 `keyValuePairs` 分词器，则每个标记都是 `Map` 列中的一个 `(key, value)` 键值对，结果还会包含 `token_key` 和 `token_value` 两列，分别存储该标记解码后的两个组成部分。

标记的倒排列表通过以下虚拟列返回。`SELECT *` 不会返回这些列，必须显式指定。

| 列           | 类型              | 描述                                                     |
| ----------- | --------------- | ------------------------------------------------------ |
| `row_id`    | `UInt32`        | 该标记倒排列表中的某一行在数据分区片段中的行号 (参见 `_part_offset`) 。          |
| `positions` | `Array(UInt32)` | 该标记在该行中的位置。仅当索引设置了参数 `support_phrase_search = 1` 时才存在。 |

如果查询了其中任一列，则每个标记的倒排列表中的每一行都会在结果中对应一行，效果类似于对倒排列表执行 `ARRAY JOIN`：该标记的其他列会在每一行中重复出现。

倒排列表按其在数据分区片段索引中的存储形式原样返回，因此在该数据分区片段被合并之前，其中仍会包含已被轻量级删除 (参见 `_row_exists`) 的行。

## 使用示例 {#usage-example}

```sql title="Query"
CREATE TABLE tab
(
    id UInt64,
    s String,
    INDEX idx_s (s) TYPE text(tokenizer = splitByNonAlpha)
)
ENGINE = MergeTree
ORDER BY id;

INSERT INTO tab SELECT number, concatWithSeparator(' ', 'apple', 'banana') FROM numbers(500);
INSERT INTO tab SELECT 500 + number, concatWithSeparator(' ', 'cherry', 'date') FROM numbers(500);

SELECT * FROM mergeTreeTextIndex(currentDatabase(), tab, idx_s);
```

## 使用示例：倒排列表 {#usage-example-posting-lists}

```sql title="Query"
CREATE TABLE tab
(
    id UInt64,
    s String,
    INDEX idx_s (s) TYPE text(tokenizer = splitByNonAlpha, support_phrase_search = 1)
)
ENGINE = MergeTree
ORDER BY id
SETTINGS allow_experimental_text_index_phrase_search = 1;

INSERT INTO tab VALUES (0, 'apple banana apple'), (1, 'banana cherry'), (2, 'cherry apple');

SELECT token, row_id, positions FROM mergeTreeTextIndex(currentDatabase(), tab, idx_s) ORDER BY token, row_id;
```

```text title="Response"
   ┌─token──┬─row_id─┬─positions─┐
1. │ apple  │      0 │ [0,2]     │
2. │ apple  │      2 │ [1]       │
3. │ banana │      0 │ [1]       │
4. │ banana │      1 │ [0]       │
5. │ cherry │      1 │ [1]       │
6. │ cherry │      2 │ [0]       │
   └────────┴────────┴───────────┘
```
