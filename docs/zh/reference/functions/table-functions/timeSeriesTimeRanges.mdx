`timeSeriesTimeRanges(db_name.time_series_table)` - 返回表 `db_name.time_series_table` 所使用的 [time ranges](/zh/reference/engines/table-engines/integrations/time-series#time-ranges-table) 表，
其中表 `db_name.time_series_table` 的表引擎为 [TimeSeries](/zh/reference/engines/table-engines/integrations/time-series) 引擎，例如：

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

以下查询是等价的：

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  仅当启用了 `store_time_ranges` 设置时，才会存在 *time ranges* 表。
  [版本](/zh/reference/engines/table-engines/integrations/time-series#schema-versioning) 为 7 及更早的表会将 `min_time` 和 `max_time` 列保留在
  [tags](/zh/reference/engines/table-engines/integrations/time-series#tags-table) 表中。
</Note>
