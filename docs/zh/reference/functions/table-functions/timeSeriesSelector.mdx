从 TimeSeries 表中读取经选择器过滤且时间戳位于指定时间间隔内的时间序列。
此函数类似于 [范围选择器](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors)，但也可用于实现 [即时选择器](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors)。

## 语法 {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## 参数 {#arguments}

* `db_name` - TimeSeries 表所在数据库的名称。
* `time_series_table` - TimeSeries 表的名称。
* `instant_query` - 采用 [PromQL 语法](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors) 编写的即时选择器，不包含 `@` 或 `offset` 修饰符。
* `min_time` - 起始时间戳，含边界值。
* `max_time` - 结束时间戳，含边界值。
* `return_columns` - 用于返回样本的列：`'samples'` 或 `'timestamp_and_value'`，详见下文。

即使表中的时间戳精确到整秒，`min_time` 和 `max_time` 也可以包含秒的小数部分：
函数会严格按照 `min_time <= timestamp <= max_time` 选择样本，不会根据表中时间戳的数据类型对边界值进行舍入。

## 返回值 {#returned-value}

该函数返回 `id` 列 (包含与指定选择器匹配的时间序列的标识符) ，以及由参数 `return_columns` 指定的列中的样本：

* `'samples'` - `samples` 列，以 `(timestamp, value)` 元组数组的形式包含时间序列的样本，并按时间戳排序。
  同一时间序列的样本可能分多行返回，例如样本表中的每个时间桶对应一行。
  可使用聚合函数 `timeSeriesGroupArray` 合并同一时间序列的各行。
* `'timestamp_and_value'` - `timestamp` 和 `value` 列，每行一个样本。

版本 11 及更高版本的 `TimeSeries` 表以数组形式存储样本桶，更早版本的表则每行存储一个样本。
当请求的列与表的布局不一致时，会对样本进行转换，这会耗费一定时间；PromQL 函数请求的列与表的布局一致。

返回数据不保证特定顺序。

## 示例 {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
