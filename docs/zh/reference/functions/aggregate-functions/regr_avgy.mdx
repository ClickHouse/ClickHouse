## regr_avgy {#regr_avgy}

引入版本：v26.9.0

返回因变量的平均值。

该平均值以数据中的某个值为基准计算，而非以零为基准，因此对于超过
2^53 的整数列，其结果可能比 [`avg`](/zh/reference/functions/aggregate-functions/avg) 更接近精确平均值，
因为后者是用 `Float64` 类型的总和做除法。

**语法**

```sql
regr_avgy(y, x)
```

**别名**：`regrAvgY`

**参数**

* `y` — 因变量。[`(U)Int*`](/zh/reference/data-types/int-uint) 或 [`Float*`](/zh/reference/data-types/float)
* `x` — 自变量。[`(U)Int*`](/zh/reference/data-types/int-uint) 或 [`Float*`](/zh/reference/data-types/float)

**返回值**

返回 `y` 的平均值。[`Float64`](/zh/reference/data-types/float)

**示例**

**基本用法**

```sql title=Query
SELECT regr_avgy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```
