## regr_sxy {#regr_sxy}

引入版本：v26.9.0

返回两个变量的离差乘积之和：

$$
\Sigma{(x - \bar{x})(y - \bar{y})}
$$

**语法**

```sql
regr_sxy(y, x)
```

**别名**：`regrSXY`

**参数**

- `y` — 因变量。 [`(U)Int*`](/reference/data-types/int-uint) 或 [`Float*`](/reference/data-types/float)
- `x` — 自变量。 [`(U)Int*`](/reference/data-types/int-uint) 或 [`Float*`](/reference/data-types/float)

**返回值**

返回 `x` 和 `y` 相对于各自平均值的离差乘积之和。 [`Float64`](/reference/data-types/float)

**示例**

**基本用法**

```sql title=查询
SELECT regr_sxy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=响应
┌─regr_sxy(y, x)─┐
│             10 │
└────────────────┘
```
