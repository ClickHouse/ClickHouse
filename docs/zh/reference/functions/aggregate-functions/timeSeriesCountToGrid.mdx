## timeSeriesCountToGrid {#timeSeriesCountToGrid}

引入版本：v26.9.0

聚合函数，接收由时间戳和值对组成的时间序列数据，并在由起始时间戳、结束时间戳和步长定义的等间隔时间网格上，基于这些数据计算[类似 PromQL 的 count&#95;over&#95;time](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time)。对于网格上的每个点，统计指定时间窗口内的样本数量。

样本可以通过以下三种形式之一传入：

* 以 `timestamp` 和 `value` 两个参数传入，每行包含一个样本；
* 以时间戳和值两个 array 传入，每行包含一条完整的时间序列；
* 以由 `(timestamp, value)` Tuple 组成的单个 array 传入，每行包含一条完整的时间序列。

如果多个样本的时间戳相同，则只使用其中值最大的那个样本。非数字 (NaN) 值小于任何其他值，因此只有当该时间戳上的所有样本均为 NaN 时，才会使用 NaN 值。

<Warning>
  此函数处于私有预览阶段，可通过设置 `enable_time_series_aggregate_functions=true` 启用。
</Warning>

**语法**

```sql
timeSeriesCountToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
timeSeriesCountToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples)
```

**参数**

* `start_timestamp` — 指定网格的起点。也可以是小数，或包含数字或日期时间文本的字符串。[`UInt32`](/zh/reference/data-types/int-uint) 或 [`DateTime`](/zh/reference/data-types/datetime) 或 [`DateTime64`](/zh/reference/data-types/datetime64) 或 [`Float*`](/zh/reference/data-types/float) 或 [`Decimal*`](/zh/reference/data-types/decimal) 或 [`String`](/zh/reference/data-types/string)
* `end_timestamp` — 指定网格的终点。也可以是小数，或包含数字或日期时间文本的字符串。[`UInt32`](/zh/reference/data-types/int-uint) 或 [`DateTime`](/zh/reference/data-types/datetime) 或 [`DateTime64`](/zh/reference/data-types/datetime64) 或 [`Float*`](/zh/reference/data-types/float) 或 [`Decimal*`](/zh/reference/data-types/decimal) 或 [`String`](/zh/reference/data-types/string)
* `grid_step` — 指定网格的步长 (单位为秒) 。也可以是小数，或包含数字或时长 (如 &#39;15s&#39; 或 &#39;1m&#39;) 的字符串。[`UInt32`](/zh/reference/data-types/int-uint) 或 [`Float*`](/zh/reference/data-types/float) 或 [`Decimal*`](/zh/reference/data-types/decimal) 或 [`String`](/zh/reference/data-types/string)
* `staleness` — 指定参与计算的样本的最大过期时长 (单位为秒) 。过期时间窗口为左开右闭区间。也可以是小数，或包含数字或时长 (如 &#39;15s&#39; 或 &#39;1m&#39;) 的字符串。[`UInt32`](/zh/reference/data-types/int-uint) 或 [`Float*`](/zh/reference/data-types/float) 或 [`Decimal*`](/zh/reference/data-types/decimal) 或 [`String`](/zh/reference/data-types/string)

**参数**

* `timestamp` — 样本的时间戳。可以是单个值或数组。[`UInt32`](/zh/reference/data-types/int-uint) 或 [`DateTime`](/zh/reference/data-types/datetime) 或 [`DateTime64`](/zh/reference/data-types/datetime64) 或 [`Array(UInt32)`](/zh/reference/data-types/array) 或 [`Array(DateTime)`](/zh/reference/data-types/array) 或 [`Array(DateTime64)`](/zh/reference/data-types/array)
* `value` — 与时间戳对应的时间序列值。可以是单个值或数组。[`Float*`](/zh/reference/data-types/float) 或 [`Array(Float*)`](/zh/reference/data-types/array)
* `samples` — 以 `(timestamp, value)` Tuple 数组形式传入的时间序列样本，其中 Tuple 元素的类型分别与上文所列的时间戳和值的类型一致。可用于替代将时间戳和值作为两个独立参数分别传入的方式。[`Array(Tuple(T1, T2))`](/zh/reference/data-types/array)

**返回值**

返回指定网格上的样本数量。返回的数组中，每个时间网格点对应一个值。如果某个网格点的窗口内没有样本，则该值为 NULL。[`Array(Nullable(UInt64))`](/zh/reference/data-types/array)

**示例**

**基本用法：使用单个时间戳-值对**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesCountToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesCountToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,2,3,4,2,1,1,3]                                                               │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

**使用 array 参数**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesCountToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesCountToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,2,3,4,2,1,1,3]                                                                 │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```
