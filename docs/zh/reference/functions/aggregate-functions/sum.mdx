## sum {#sum}

引入版本：v1.1.0

计算数值或时间间隔之和。

**语法**

```sql
sum(num)
```

**参数**

* `num` — 数值类型或时间间隔类型的列。[`(U)Int*`](/zh/reference/data-types/int-uint) 或 [`Float*`](/zh/reference/data-types/float) 或 [`Decimal*`](/zh/reference/data-types/decimal) 或 [`Interval`](/zh/reference/data-types/special-data-types/interval)

**返回值**

返回这些值的总和。若参数为 `Interval` 类型，则结果为相同单位的时间间隔；若输入为空，则返回长度为零的时间间隔。[`(U)Int*`](/zh/reference/data-types/int-uint) 或 [`Float*`](/zh/reference/data-types/float) 或 [`Decimal*`](/zh/reference/data-types/decimal) 或 [`Interval`](/zh/reference/data-types/special-data-types/interval)

**示例**

**计算员工工资总和**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**请求总耗时**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
