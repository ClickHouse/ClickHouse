## avg {#avg}

引入版本：v1.1.0

计算算术平均值。

**语法**

```sql
avg(x)
```

**参数**

* `x` — 输入值。类型可以是 [`(U)Int*`](/zh/reference/data-types/int-uint)、[`Float*`](/zh/reference/data-types/float)、[`Decimal`](/zh/reference/data-types/decimal)、[`Date`](/zh/reference/data-types/date)、[`Date32`](/zh/reference/data-types/date32)、[`DateTime`](/zh/reference/data-types/datetime)、[`DateTime64(P)`](/zh/reference/data-types/datetime64)、[`Time`](/zh/reference/data-types/time)、[`Time64(P)`](/zh/reference/data-types/time64) 或 [`Interval`](/zh/reference/data-types/special-data-types/interval)

**返回值**

返回算术平均值。如果 `x` 是数值，结果为 `Float64`；如果 `x` 为空，则返回 `NaN`。如果 `x` 是日期、时间或时间间隔，结果与 `x` 的类型相同：平均值会四舍五入到最接近的可表示值；如果 `x` 为空，则返回该类型的零值。返回类型可以是 [`Float64`](/zh/reference/data-types/float)、[`Date`](/zh/reference/data-types/date)、[`Date32`](/zh/reference/data-types/date32)、[`DateTime`](/zh/reference/data-types/datetime)、[`DateTime64(P)`](/zh/reference/data-types/datetime64)、[`Time`](/zh/reference/data-types/time)、[`Time64(P)`](/zh/reference/data-types/time64) 或 [`Interval`](/zh/reference/data-types/special-data-types/interval)

**示例**

**基本用法**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**空表返回非数字**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**时间间隔的平均值**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
