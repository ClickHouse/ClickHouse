## fsync_after_insert {#fsync_after_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

对每个新插入的 分片 执行 fsync，确保在 `INSERT` 查询
被确认时数据已持久化。会降低插入性能，在使用 wide 分片 时尤为明显。
另请参见 `group_fsync_before_insert_finish`。

## fsync_part_directory {#fsync_part_directory}

<SettingsInfoBlock type="Bool" default_value="0" />

在所有分片相关操作 (写入、重命名等) 完成后，对分片目录执行 fsync。
