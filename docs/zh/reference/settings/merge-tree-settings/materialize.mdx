## materialize_skip_indexes_on_merge {#materialize_skip_indexes_on_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.1"},{"label": "1"},{"label": "新设置"}]}]} />

启用后，合并操作会为新的 parts 构建并存储跳过索引。
否则，这些索引只能通过显式执行 [MATERIALIZE INDEX](/zh/reference/statements/alter/skipping-index#materialize-index)
或 [在 INSERT 时](/zh/reference/settings/session-settings/materialize#materialize_skip_indexes_on_insert) 创建/存储。

另请参见 [exclude&#95;materialize&#95;skip&#95;indexes&#95;on&#95;merge](/zh/reference/settings/merge-tree-settings/exclude#exclude_materialize_skip_indexes_on_merge)，以进行更细粒度的控制。

## materialize_statistics_on_merge {#materialize_statistics_on_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.1"},{"label": "1"},{"label": "新设置"}]}]} />

启用后，合并操作会为新的 parts 构建并存储统计信息。
否则，这些统计信息可通过显式执行 [MATERIALIZE STATISTICS](/zh/reference/statements/alter/statistics)
或[在 INSERT 时](/zh/reference/settings/session-settings/materialize-statistics-on-insert#materialize_statistics_on_insert)创建/存储

## materialize_ttl_recalculate_only {#materialize_ttl_recalculate_only}

<SettingsInfoBlock type="Bool" default_value="0" />

启用后，`MATERIALIZE TTL` 会为每个数据分区片段重新计算已存储的 `TTL` 元数据，且在此操作期间不会删除已过期的数据。禁用时，常规的生存时间 (TTL) 物化通常会执行已配置的行级、列级或 `GROUP BY` TTL 操作。对于仅设置了行级 TTL 且启用了 `ttl_only_drop_parts` 的表，则改为重新计算 `TTL` 元数据，并仅删除已完全过期的 parts。
