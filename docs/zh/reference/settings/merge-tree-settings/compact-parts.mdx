## compact_parts_merge_max_bytes_to_prefetch_part {#compact_parts_merge_max_bytes_to_prefetch_part}

<SettingsInfoBlock type="UInt64" default_value="16777216" />

仅在 ClickHouse Cloud 中可用。在合并或变更期间将 compact part 整体读入内存时的最大大小。
如果某个分片的大小不超过每列读取缓冲区在最坏情况下的内存占用 (即已配置的缓冲区大小，启用预取时为其两倍) ，
也会将这个较大的分片整体读入。对于条带较小的分片，这可能比逐列读取占用更多内存，
但只需发送一个请求，而无需针对每列的每个条带分别发送请求。设置为 0 表示禁用此功能。
