## enable_adaptive_codec_selection {#enable_adaptive_codec_selection}

<ExperimentalBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "New setting."}]}]} />

启用后，对于使用默认编解码器的列 (即未指定 `CODEC` 子句或指定 `CODEC(Default)`) ，合并和变更会为每个块选择编解码器。
候选编解码器包括表的默认编解码器 (请参阅 `default_compression_codec` 设置) 、`NONE` 以及适合该列类型的专用编解码器。
输出最小的候选项将被选中。因此，压缩效果不会比默认编解码器更差，无法压缩的块会以原始形式存储。
如果某列的默认编解码器包含加密 (例如 `AES_128_GCM_SIV`) ，则不会对其进行自适应选择，因此始终会应用加密。
每个块所使用的编解码器可通过 [`mergeTreeCodecBlockCounts`](/zh/reference/functions/table-functions/index) 表函数查看。

## enable_mixed_granularity_parts {#enable_mixed_granularity_parts}

<SettingsInfoBlock type="Bool" default_value="1" />

启用或禁用切换为使用 `index_granularity_bytes` 设置来控制粒度大小。在 19.11 版本之前，只有
`index_granularity` 设置可用于限制粒度大小。`index_granularity_bytes`
设置可在从包含大行 (数十到数百 MB) 的表中读取数据时提升 ClickHouse 的性能。
如果你的表中存在大行，可以为这些表启用此设置，
以提高 `SELECT` 查询的效率。
