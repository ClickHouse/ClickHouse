合并已排序的流时，使用批次排序队列可减少每行的队列开销。

仅适用于不会改变行的合并，即普通 `MergeTree`
(`Ordinary` 合并模式) 。对于具有合并时语义的引擎，例如 `ReplacingMergeTree`、`CollapsingMergeTree`、
`SummingMergeTree`、`AggregatingMergeTree`、`CoalescingMergeTree`、
`GraphiteMergeTree` 和 `VersionedCollapsingMergeTree`，此设置无效；无论此设置如何，这些引擎都会继续使用
默认队列。
