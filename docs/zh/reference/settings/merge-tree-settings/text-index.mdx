<div id="text_index_serialization_version">
  ## text_index_serialization_version
</div>

<SettingsInfoBlock type="MergeTreeTextIndexSerializationVersion" default_value="v2_with_positions" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "v2_with_positions"},{"label": "允许使用持久化标记位置以支持短语搜索的 'v2_with_positions' 文本索引格式。在较低兼容性版本下会回退到 'v1_with_codec'，从而确保滚动升级期间较新服务器仍写入较旧服务器可读取的格式。"}]}, {"id": "row-2","items": [{"label": "26.6"},{"label": "v1_with_codec"},{"label": "新增设置。用于控制文本索引的磁盘格式版本。在较低兼容性版本下会回退到 'v0_initial'，从而确保滚动升级期间较新服务器仍写入较旧服务器可读取的先前格式。"}]}]} />

写入文本索引时首选的磁盘序列化格式版本。

此设置仅表示偏好，而非硬性约束：如果配置的版本无法
表示某个索引，系统会自动选择能够表示该索引的较新版本，因此
写入文本索引绝不会因该设置而失败。

在滚动升级期间，请在已升级的服务器上通过 profile 级别的 `compatibility` 设置固定格式，
以确保它们继续写入较旧服务器仍可读取的格式。

可能的值：

* `v0_initial` — 原始格式。不持久化倒排列表编解码器类型。
* `v1_with_codec` — 在文本索引头部持久化倒排列表编解码器类型。
* `v2_with_positions` — 为启用了 `support_phrase_search` 的索引持久化标记位置。
