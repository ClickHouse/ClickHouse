这些设置用于配置 ClickHouse 服务器，由 ClickHouse 源代码自动生成。

## database_catalog_drop_error_cooldown_sec {#database_catalog_drop_error_cooldown_sec}

<SettingsInfoBlock type="UInt64" default_value="5" changeable_without_restart="No" />如果删除表失败，ClickHouse 会在重试该操作前等待这么长时间。

## database_catalog_drop_table_concurrency {#database_catalog_drop_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="16" changeable_without_restart="No" />用于删除表操作的线程池大小。

## database_catalog_shutdown_table_concurrency {#database_catalog_shutdown_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="No" />服务器停止时用于关闭表的线程池大小。零表示线程数等于 CPU 核心数。

## database_catalog_unused_dir_cleanup_period_sec {#database_catalog_unused_dir_cleanup_period_sec}

<SettingsInfoBlock type="UInt64" default_value="86400" changeable_without_restart="No" />原用于清理 `store/` 目录中垃圾文件的后台任务的参数，表示该任务的调度周期。该设置已弃用且不再生效：该任务已被移除，ClickHouse 不会自动隐藏或删除 `store/` 中未使用的目录。

## database_catalog_unused_dir_hide_timeout_sec {#database_catalog_unused_dir_hide_timeout_sec}

<SettingsInfoBlock type="UInt64" default_value="3600" changeable_without_restart="No" />此前用于清理 `store/` 目录中垃圾文件的后台任务的参数：该任务在经过此时间后，会撤销未使用目录的所有访问权限。该设置已弃用且不再生效：该任务已被移除，ClickHouse 不会自动隐藏或删除 `store/` 中未使用的目录。

## database_catalog_unused_dir_rm_timeout_sec {#database_catalog_unused_dir_rm_timeout_sec}

<SettingsInfoBlock type="UInt64" default_value="2592000" changeable_without_restart="No" />此前用于清理 `store/` 目录中垃圾文件的后台任务的参数：表示该任务删除未使用目录前的等待时间。该设置已弃用且不再生效：该任务已被移除，ClickHouse 不会自动隐藏或删除 `store/` 中未使用的目录。
