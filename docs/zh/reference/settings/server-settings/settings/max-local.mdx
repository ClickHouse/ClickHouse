这些设置用于配置 ClickHouse 服务器，由 ClickHouse 源代码自动生成。

## max_local_read_bandwidth_for_server {#max_local_read_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

本地读取的最大速度，单位为字节/秒。

该限制仅作用于从块设备读取的数据：只要读取方法能够识别出由 OS 页面缓存提供的读取，这部分读取就不会计入限制 (默认的 `local_filesystem_read_method = 'pread_threadpool'`、`pread` 以及对文件系统缓存文件的读取均可识别) 。

<Note>
  值为 `0` 表示无限制。
</Note>

## max_local_write_bandwidth_for_server {#max_local_write_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="是" />

本地写入的最大带宽，以每秒字节数为单位。

<Note>
  值为 `0` 表示无限制。
</Note>
