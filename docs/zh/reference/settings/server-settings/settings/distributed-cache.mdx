这些设置用于配置 ClickHouse 服务器，并由 ClickHouse 源代码自动生成。

## distributed_cache_apply_throttling_settings_from_client {#distributed_cache_apply_throttling_settings_from_client}

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />缓存服务器是否应使用从客户端接收的限流设置。

## distributed_cache_keep_up_free_connections_ratio {#distributed_cache_keep_up_free_connections_ratio}

<SettingsInfoBlock type="Float" default_value="0.1" changeable_without_restart="否" />分布式缓存会尽量保持的空闲活动连接数量的软限制。当空闲连接数低于 distributed&#95;cache&#95;keep&#95;up&#95;free&#95;connections&#95;ratio * max&#95;connections 时，将关闭活动时间最早的连接，直到该数量重新高于此限制。

## distributed_cache_warmer_max_bytes_in_queue {#distributed_cache_warmer_max_bytes_in_queue}

<SettingsInfoBlock type="UInt64" default_value="107374182400" changeable_without_restart="No" />仅在 ClickHouse Cloud 中生效。对于未配置本地文件系统缓存的磁盘，缓存预热器在队列中保留的范围的最大总大小；超出该上限时，将丢弃最旧的范围 (若配置了本地缓存，预热器则使用其 `max_size`) 。值为 0 表示不限制。

## distributed_cache_warmer_max_file_segment_size {#distributed_cache_warmer_max_file_segment_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="33554432" changeable_without_restart="No" />仅在 ClickHouse Cloud 中生效。当数据分片所在的磁盘没有本地文件系统缓存时，缓存预热器会按此大小的范围，将拉取到的数据分片读取到分布式缓存中 (若存在本地缓存，预热器则使用该缓存的 `max_file_segment_size`) 。

## distributed_cache_warmer_max_segments_in_queue {#distributed_cache_warmer_max_segments_in_queue}

<SettingsInfoBlock type="UInt64" default_value="100000" changeable_without_restart="No" />仅在 ClickHouse Cloud 中生效。对于未配置本地文件系统缓存的磁盘，缓存预热器在队列中最多保留的范围数量；超出此上限时，最旧的范围会被丢弃 (若配置了本地缓存，预热器则改用该缓存的 `max_elements`) 。设为 0 表示不限制。

## distributed_cache_write_pool_size {#distributed_cache_write_pool_size}

<SettingsInfoBlock type="UInt64" default_value="100" changeable_without_restart="No" />可在后台线程中同时运行的分布式缓存写请求的最大数量 (跨所有查询) 。达到该限制后，将跳过 write-through cache 的写入 (数据仍会写入 object storage) ，因此既不会因等待 slot 而阻塞，也不会创建数量无限增长的线程。临时数据的写入不使用后台线程，因此不受该限制影响。
