这些设置用于配置 ClickHouse 服务器，由 ClickHouse 源代码自动生成。

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />多阶段分布式查询中流式数据交换套接字的 SO&#95;RCVBUF 选项大小。0 表示使用内核默认值 (TCP 自动调优) 。大于 0 的值用于限制每个套接字接收缓冲区的上限 (同时受 net.core.rmem&#95;max 限制) 。该值在建立每个连接时读取，因此重新加载 config 后仅对新连接生效。

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />多阶段分布式查询中流式数据交换套接字的 SO&#95;SNDBUF 选项大小。0 = 内核默认值 (TCP 自动调优) 。大于 0 的值会为每个套接字的发送缓冲区设定上限 (该值受 net.core.wmem&#95;max 限制) ，代价是在高 RTT 链路上，数据流吞吐量会被限制在 sndbuf/RTT 以内。该设置在建立每个连接时读取，因此重新加载 config 仅对新连接生效。
