这些设置用于配置 ClickHouse 服务器，由 ClickHouse 源代码自动生成。

## reader_executor_memory_pressure_critical_level_pct {#reader_executor_memory_pressure_critical_level_pct}

<SettingsInfoBlock type="UInt64" default_value="95" changeable_without_restart="Yes" />内存压力阈值，达到该阈值时 Experimental `ReaderExecutor` 会进入 `Critical` 内存压力级别，即其最激进的读取窗口缩减模式。有关作用域、取值范围及顺序规则，请参见 `reader_executor_memory_pressure_elevated_level_pct`。

## reader_executor_memory_pressure_elevated_level_pct {#reader_executor_memory_pressure_elevated_level_pct}

<SettingsInfoBlock type="UInt64" default_value="75" changeable_without_restart="Yes" />内存压力阈值，以 memory tracker 的 hard limit 的百分比表示；达到该阈值时，Experimental `ReaderExecutor` 会进入 `Elevated` 内存压力级别，并开始收缩其读取 window。这些 threshold 会独立应用于三个 作用域 —— 服务器总量 (`max_server_memory_usage`) 、用户 (`max_memory_usage_for_user`) 和查询 (`max_memory_usage`) —— reader 取三者中的最高值，因此即使服务器处于 idle 状态，某个已接近自身限制的查询同样会收缩其 window。未设置 hard limit 的 作用域 不参与计算。取值必须在 `[1, 100]` 范围内，且满足 `elevated <= high <= critical`；超出范围或顺序错误的三元组会在启动时以及执行 `SYSTEM RELOAD CONFIG` 时被拒绝。0 也会被拒绝，因为 `elevated` 为 0 会使所有 作用域 都处于 `Elevated`，包括未设置 hard limit 的 作用域。

## reader_executor_memory_pressure_high_level_pct {#reader_executor_memory_pressure_high_level_pct}

<SettingsInfoBlock type="UInt64" default_value="90" changeable_without_restart="Yes" />Experimental `ReaderExecutor` 进入 `High` 内存压力级别的内存压力阈值。有关作用域、取值范围和顺序规则，请参阅 `reader_executor_memory_pressure_elevated_level_pct`。
