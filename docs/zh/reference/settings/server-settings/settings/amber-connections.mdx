这些设置用于配置 ClickHouse 服务器，由 ClickHouse 源代码自动生成。

## amber_connections_hard_limit {#amber_connections_hard_limit}

<SettingsInfoBlock type="UInt64" default_value="200000" changeable_without_restart="No" />达到此限制后，再尝试创建连接时将抛出异常。设置为 0 可关闭硬限制。该限制适用于 Amber 连接。

## amber_connections_rcvbuf {#amber_connections_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="204800" changeable_without_restart="Yes" />Amber 连接的 SO&#95;RCVBUF 选项大小。默认值为 204800 (200 KB) ：对象存储通过同一区域内访问，带宽时延积远低于 100 KB，因此设置较小的上限即可达到满吞吐量，同时避免内核自动调优为每个套接字分配数 MiB 的缓冲区。设置为 0 则改用内核 TCP 自动调优来管理接收缓冲区。说明：将此设置改回 0 后，仅新建的连接会恢复自动调优；现有的池化连接在重新创建之前仍会保持固定的缓冲区大小。

## amber_connections_sndbuf {#amber_connections_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Amber 连接的 SO&#95;SNDBUF 选项大小。若设置为大于 0 的值，则会覆盖内核 TCP 对发送缓冲区的自动调优。0 表示使用内核默认值 (自动调优) 。注意：将此设置改回 0 后，仅新建的连接会恢复自动调优；现有的池化连接在重新创建之前仍会保留固定的缓冲区大小。

## amber_connections_soft_limit {#amber_connections_soft_limit}

<SettingsInfoBlock type="UInt64" default_value="5000" changeable_without_restart="No" />超出此限制的连接，其存活时间会显著缩短。此限制适用于 Amber 连接。

## amber_connections_store_limit {#amber_connections_store_limit}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="No" />对象池中为复用而保留的空闲连接的最大数量。已存储的连接数达到该值后，后续连接在使用完毕后将被重置，不再保留。该限制不约束正在使用的连接。设置为 0 可禁用连接缓存。该限制适用于 Amber 连接。

## amber_connections_warn_limit {#amber_connections_warn_limit}

<SettingsInfoBlock type="UInt64" default_value="8000" changeable_without_restart="No" />当正在使用的连接数超过此上限时，会在日志中写入警告消息。此上限适用于 Amber 连接。
