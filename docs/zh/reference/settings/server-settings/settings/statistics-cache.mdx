## statistics_cache_policy {#statistics_cache_policy}

<SettingsInfoBlock type="String" default_value="SLRU" changeable_without_restart="No" />统计信息缓存的淘汰策略名称。可选值：`LRU`、`SLRU`、`SIEVE`。

## statistics_cache_prewarm_ratio {#statistics_cache_prewarm_ratio}

<SettingsInfoBlock type="Double" default_value="0.95" changeable_without_restart="No" />预热时统计信息缓存的填充量占缓存总大小的比率。

## statistics_cache_size {#statistics_cache_size}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="Yes" />MergeTree 家族表中数据分区片段的列统计信息缓存的最大大小。统计信息按数据分区片段和列分别缓存，按需加载，并在每次查询时运行时动态合并。

## statistics_cache_size_ratio {#statistics_cache_size_ratio}

<SettingsInfoBlock type="Double" default_value="0.5" changeable_without_restart="No" />统计信息缓存中受保护队列 (使用 SLRU 策略时) 的大小占该缓存总大小的比率。
