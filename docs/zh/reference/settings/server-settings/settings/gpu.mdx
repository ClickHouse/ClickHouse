这些设置用于配置 ClickHouse 服务器，由 ClickHouse 源代码自动生成。

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />GPU 默认内存对象池中保留 (而不归还给驱动程序) 的已释放设备内存量。使用默认值时，对象池会增长到查询的峰值占用，并保持该大小直至服务器关闭。

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />GPU 锁页主机内存对象池中可保留以供复用、而不归还给系统的已释放锁页主机内存的最大大小。
