这些设置用于配置 ClickHouse server，由 ClickHouse 源代码自动生成。

<div id="enable_azure_sdk_logging">
  ## enable_azure_sdk_logging
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />启用 Azure SDK 的日志

<div id="enable_read_through_distributed_cache">
  ## enable_read_through_distributed_cache
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />仅在 ClickHouse Cloud 中有效。允许从分布式缓存读取。这是一个无需重启即可生效的服务器级开关，因此没有自身查询 profile 的后台操作 (合并、变更、`Buffer` 表刷写) 也会遵循此设置。各个查询可通过 `force_read_through_distributed_cache` 设置覆盖此设置。

<div id="enable_silk_runtime">
  ## enable_silk_runtime
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />启用对 silk fiber 运行时的实验性支持：在服务器启动时初始化 silk fiber 调度器，使支持该运行时的子系统能够在 fiber 上运行其作业

<div id="enable_webterminal">
  ## enable_webterminal
</div>

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />启用 `/webterminal` HTTP 端点上的 Web 终端界面。它通过 WebSocket 在浏览器中提供交互式的 `clickhouse-client` 会话。当设置为 `false` 时，对 `/webterminal` 的请求会返回 HTTP 状态 `403 Forbidden`。

<div id="enable_write_through_distributed_cache">
  ## enable_write_through_distributed_cache
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />仅在 ClickHouse Cloud 中有效。允许写入分布式缓存 (写入 S3 也将通过分布式缓存完成) 。这是一个无需重启即可生效的服务器级开关，因此不具备自身查询 profile 的后台操作 (合并、变更、`Buffer` 表刷写) 也会遵循此设置。单个查询可以通过 `force_write_through_distributed_cache` 设置覆盖此设置。
