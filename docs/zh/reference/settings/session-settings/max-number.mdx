<div id="max_number_of_partitions_for_independent_aggregation">
  ## max_number_of_partitions_for_independent_aggregation
</div>

<SettingsInfoBlock type="UInt64" default_value="128" />

对表中每个分区进行独立聚合时的最大分区数。这是 [allow&#95;aggregate&#95;partitions&#95;independently](/zh/reference/settings/session-settings/allow#allow_aggregate_partitions_independently) 成本启发式的一部分。
