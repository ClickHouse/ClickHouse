## iceberg_insert_max_bytes_in_data_file {#iceberg_insert_max_bytes_in_data_file}

插入操作时 Iceberg Parquet 数据文件的最大字节数。

该默认值与 Iceberg 表属性 `write.target-file-size-bytes` 的文档默认值 (512 MiB) 一致，
参见 https://iceberg.apache.org/docs/1.5.2/configuration/。请注意，ClickHouse 比较该限制时使用的是目前已写入文件的数据的
未压缩大小，而 Iceberg 该属性针对的是最终生成文件的大小；此外，`iceberg_insert_max_rows_in_data_file`
会独立于文件大小对文件加以限制。
