## hdfs_create_new_file_on_insert {#hdfs_create_new_file_on_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

启用或禁用在 HDFS 引擎表 中每次 insert 时创建新文件的功能。如果启用，每次 insert 时都会创建一个新的 HDFS 文件，文件名类似以下 pattern：

初始：`data.Parquet.gz` -&gt; `data.1.Parquet.gz` -&gt; `data.2.Parquet.gz`，以此类推。

Possible values：

* 0 — `INSERT` 查询会将新数据追加到文件末尾。
* 1 — `INSERT` 查询会创建一个新文件。

## hdfs_skip_empty_files {#hdfs_skip_empty_files}

<SettingsInfoBlock type="Bool" default_value="0" />

启用或禁用在 [HDFS](/zh/reference/engines/table-engines/integrations/hdfs) 引擎表中跳过空文件。

可能的值：

* 0 — 如果空文件与所请求的格式不兼容，`SELECT` 会抛出异常。
* 1 — 对于空文件，`SELECT` 返回空结果。

## hdfs_skip_hidden_files {#hdfs_skip_hidden_files}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "新增设置：按通配符列出文件时，跳过非通配符前缀之下含有以 `_` 或 `.` 开头的路径分段的文件，与其他 Hive 生态读取器的行为保持一致。设置了 `partition_strategy = 'hive'` 的表始终会跳过此类路径。"}]}]} />

启用或禁用在 [HDFS](/zh/reference/engines/table-engines/integrations/hdfs) 引擎表中按通配符列出文件时跳过隐藏路径。隐藏路径指在路径的非通配符前缀之下，含有以 `_` 或 `.` 开头的路径分段的文件。包含 `=` 的分段属于分区目录 (例如分区列 `_p` 对应的 `_p=1`) ，不视为隐藏。Hive 生态的写入器 (Hive、Spark、Trino) 会在此类路径下暂存尚未完成的输出并写入标记文件 (`_temporary/`、`.spark-staging-<id>/`、`_SUCCESS`) ，读取这些文件会与写入器的提交形成竞态条件。非通配符前缀内的分段不做检查。设置了 `partition_strategy = 'hive'` 的表无论此设置取何值，始终会跳过隐藏路径。

可选值：

* 0 — 读取通配符匹配到的所有文件。
* 1 — 跳过在非通配符前缀之下含有隐藏路径分段的文件。

## hdfs_truncate_on_insert {#hdfs_truncate_on_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

启用或禁用在 HDFS 引擎表中执行插入前的截断操作。如果禁用，当 HDFS 中的文件已存在时，尝试插入会抛出异常。

可能的值：

* 0 — `INSERT` 查询会将新数据追加到文件末尾。
* 1 — `INSERT` 查询会用新数据替换文件的现有内容。
