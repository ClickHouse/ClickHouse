## promql_push_down_label_matchers {#promql_push_down_label_matchers}

<PrivatePreviewBadge />

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "新增设置，用于将 PromQL 标签匹配器跨二元运算符复制。"}]}]} />

对于 PromQL 二元运算符用来匹配数据系列的标签，将运算符一侧的标签匹配器复制到另一侧的选择器中。例如，`b / on(job) a{job="x"}` 只会读取 `b` 中 `job="x"` 的数据系列。
如果匹配器过滤掉的数据系列可能导致 Prometheus 报告重复的数据系列，则不会复制该匹配器。具体而言：不会复制到运算符的 &quot;one&quot; 一侧 (除非该侧是按匹配标签进行的聚合) ；不会复制到 `and` 和 `unless` 以外的向量间运算符中；也不会穿过基于范围的函数或与标量运算的运算符 (除非其输入是按名称选择的单个指标) 。
不带 `bool` 的比较会保留指标名称，因此匹配器总能穿过此类比较。其他函数以及一元负号则会阻断匹配器的传递。
复制的匹配器会把选择整个指标的选择器变为带过滤条件的选择器。如果该匹配器保留了指标的大部分数据系列，那么在 `id` 按指标聚簇 (默认情况) 的 [TimeSeries](/zh/reference/engines/table-engines/integrations/time-series) 表上，查询可能反而变慢。对于此类查询，请禁用此设置。
