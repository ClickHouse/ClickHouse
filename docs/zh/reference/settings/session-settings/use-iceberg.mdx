## use_iceberg_manifest_list_partition_pruning {#use_iceberg_manifest_list_partition_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "新增设置：无需读取 Iceberg manifest 文件，即可跳过 manifest 列表中分区摘要无法匹配查询过滤器的文件。"}]}]} />

无需读取 Iceberg manifest 文件，即可跳过 manifest 列表中分区摘要无法匹配查询过滤器的整个文件。需要启用 [use&#95;iceberg&#95;partition&#95;pruning](/zh/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning)，且仅当 manifest 文件包含较少的不同分区值时才有帮助；按分区列聚簇的 `rewriteManifests` 会产生这种结果。

## use_iceberg_metadata_files_cache {#use_iceberg_metadata_files_cache}

<SettingsInfoBlock type="Bool" default_value="1" />
