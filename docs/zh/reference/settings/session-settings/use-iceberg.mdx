## use_iceberg_manifest_list_partition_pruning {#use_iceberg_manifest_list_partition_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "新增设置：无需读取 Iceberg manifest 文件，即可跳过 manifest 列表中分区摘要无法匹配查询过滤器的文件。"}]}]} />

无需读取 Iceberg manifest 文件，即可跳过 manifest 列表中分区摘要无法匹配查询过滤器的整个文件。需要启用 [use&#95;iceberg&#95;partition&#95;pruning](/zh/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning)，且仅当 manifest 文件包含较少的不同分区值时才有帮助；按分区列聚簇的 `rewriteManifests` 会产生这种结果。

## use_iceberg_table_statistics_ndv {#use_iceberg_table_statistics_ndv}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "新增设置：用于 JOIN 重排序时，从 `metadata.json` 的表统计信息中获取 Iceberg 列的不同值数量。"}]}]} />

启用 [`use_datalake_metadata_statistics`](/zh/reference/settings/session-settings/use#use_datalake_metadata_statistics) 后，如果清单文件未提供某个 Iceberg 列的不同值数量，则从 `metadata.json` 的表统计信息中获取该值，即仅针对该列的 `apache-datasketches-theta-v1` 二进制大对象中的 `ndv` 属性。此类统计信息由 Spark `compute_table_stats` 或 Trino `ANALYZE` 写入。仅使用基于当前所读取快照计算得到的二进制大对象。这些数值仅用于 JOIN 重排序和条件估算，不会影响查询结果。
