## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "将客户端\/服务器以及服务器\/服务器通信的默认压缩方法从 `LZ4` 改为 `ZSTD`，以减少网络流量。"}]}]} />

用于压缩通过 native protocol 进行的客户端/服务器端以及服务器/服务器之间通信的编解码器。

该设置不适用于 distributed queries 的流式 exchange 通道，该通道始终使用服务器的默认编解码器：每个压缩帧都是 self-describing 的，因此 receiver 会自动检测所用的编解码器。

可能的值：

* `NONE` — 不压缩。
* `LZ4` — 使用 LZ4 编解码器。
* `LZ4HC` — 使用 LZ4HC 编解码器。
* `ZSTD` — 使用 ZSTD 编解码器。

**另请参见**

* [network&#95;zstd&#95;compression&#95;level](/zh/reference/settings/session-settings/network#network_zstd_compression_level)

## network_zstd_compression_level {#network_zstd_compression_level}

<SettingsInfoBlock type="Int64" default_value="3" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "3"},{"label": "将网络 `ZSTD` 压缩的默认级别与新的磁盘上 `ZSTD(3)` 压缩默认值保持一致。"}]}]} />

调整 ZSTD 的压缩级别。仅在 [network&#95;compression&#95;method](/zh/reference/settings/session-settings/network#network_compression_method) 设置为 `ZSTD` 时使用。

可能的值：

* 1 到 15 的正整数。
