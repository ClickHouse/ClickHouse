## opentelemetry_trace_stateless_worker_discovery {#opentelemetry_trace_stateless_worker_discovery}

<CloudOnlyBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "新增设置，用于在查询为预配工作线程而向 stateless-worker 自动发现服务发出请求时，收集相应的 OpenTelemetry 跨度。"}]}]} />

仅在 ClickHouse Cloud 中生效。对于本身已启用 trace 的查询，在其为预配 (租用) 工作线程而向 stateless-worker 自动发现服务发出请求时，收集相应的 OpenTelemetry 跨度。
这些跨度的名称为 `StatelessWorkerDiscovery.<action>`，并带有 `clickhouse.discovery.action` 和 `clickhouse.discovery.status` 属性。
