  ## max_rand_distribution_parameter
</div>

<SettingsInfoBlock type="Float" default_value="1000000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1000000"},{"label": "用于限制随机分布函数中形状参数的新设置，可防止在极端输入下卡住。"}]}]} />

`randChiSquared`、`randStudentT` 和 `randFisherF` 等随机分布函数中分布形状参数的最大值。这样可避免参数值过于极端时计算耗时过长。`0` 可禁用该限制；对于使采样器完全无法终止的值，仍会予以拒绝。

<div id="max_rand_distribution_trials">
  ## max_rand_distribution_trials
</div>

<SettingsInfoBlock type="UInt64" default_value="1000000000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1000000000"},{"label": "用于限制随机分布函数试验次数的新设置，可防止在极端输入下卡住。"}]}]} />

`randBinomial` 和 `randNegativeBinomial` 等随机分布函数允许的最大试验次数。这样可防止在试验次数很大时计算时间过长。`0` 会禁用该限制，并且该设置可以提高到高于其默认值，但概率严格介于 0 和 1 之间的 `randBinomial` 始终会拒绝超过 10^9 次试验。这是因为在最坏情况下，生成单个样本的开销与试验次数成正比，且出现这种情况的概率会随试验次数增加而增大。概率为 0 和 1 时不受此硬性上限限制，因为生成样本的开销为常数时间。
