## cluster_for_parallel_replicas {#cluster_for_parallel_replicas}

当前服务器所在分片对应的集群

Cloud 默认值：`default`。

## cluster_function_process_archive_on_multiple_nodes {#cluster_function_process_archive_on_multiple_nodes}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "1"},{"label": "新增设置"}]}]} />

如果设置为 `true`，可提升 cluster function 中归档文件处理的性能。若要保持兼容性，并避免在早期版本中使用带归档文件的 cluster function 时升级到 25.7+ 过程中出现错误，则应将其设置为 `false`。

## cluster_function_wait_for_replica_ms {#cluster_function_wait_for_replica_ms}

<SettingsInfoBlock type="Milliseconds" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "新增设置"}]}]} />

对于 `*Cluster` 表函数或基于对象存储的并行副本，发起服务器会等待副本请求任务，超过该时长后，便将分配给该副本的文件转交给其他副本。`0` 表示禁用等待。
