## enable_lightweight_update {#enable_lightweight_update}

**别名**: `allow_experimental_lightweight_update`

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.8"},{"label": "1"},{"label": "轻量级更新已进入 Beta。新增了设置 'allow_experimental_lightweight_update' 的别名。"}]}, {"id": "row-2","items": [{"label": "25.5"},{"label": "0"},{"label": "新增设置。该设置最初名为 `allow_experimental_lightweight_update`，该名称现已成为其别名。"}]}]} />

允许使用轻量级更新。轻量级更新仅将更新后的值写入补丁分区片段，而不会像变更那样重写整个数据分区片段。

如果禁用此设置，`UPDATE` 语句会抛出异常；此时即使 `alter_update_mode` 或 `lightweight_delete_mode` 要求使用轻量级更新，`ALTER TABLE ... UPDATE` 和轻量级删除也不会使用轻量级更新 (若设置为 `lightweight_force` 或 `lightweight_update_force`，则会抛出异常) 。
