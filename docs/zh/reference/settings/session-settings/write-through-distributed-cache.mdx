## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "新增云设置"}]}]} />

仅在 ClickHouse Cloud 中生效。每个 write buffer 写入分布式缓存服务器时所用缓冲区的最大大小。它与写入 object storage 的缓冲区相互独立：后者会持续增长，直至达到 upload part 大小。如果为 0，则使用 `DBMS_DEFAULT_BUFFER_SIZE` (1 MiB) 。该缓冲区从 `adaptive_write_buffer_initial_size` 开始，只在 stream 写入过程中逐步增长到此大小，从而避免一个 part 为其写入的每个 stream 都按该大小分配缓冲区。
