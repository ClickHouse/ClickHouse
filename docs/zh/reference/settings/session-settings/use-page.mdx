## use_page_cache_for_disks_without_file_cache {#use_page_cache_for_disks_without_file_cache}

## use_page_cache_for_local_disks {#use_page_cache_for_local_disks}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "新增设置：对本地磁盘使用用户态页缓存"}]}]} />

从本地磁盘读取时使用用户态页缓存。该设置仅用于测试，实际中通常不太可能带来性能提升。要求 `local_filesystem_read_method = 'pread'` 或 `'read'`。此设置不会禁用 OS page cache；如需禁用，可使用 `min_bytes_to_use_direct_io`。仅影响常规表，不影响 `file()` 表函数或 `File()` 表引擎。

## use_page_cache_for_object_storage {#use_page_cache_for_object_storage}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "新增设置：为对象存储表函数使用用户态页缓存"}]}, {"id": "row-2","items": [{"label": "26.12"},{"label": "1"},{"label": "如果服务器上已配置页缓存，则默认对对象存储表引擎和表函数使用用户态页缓存。"}]}]} />

从对象存储表函数 (s3、azure、hdfs、Iceberg、Delta Lake 等) 和表引擎 (S3、Azure、HDFS、Iceberg、Delta Lake 等) 读取数据时，使用用户态页缓存。仅当服务器上已配置用户态页缓存 (`page_cache_max_size`) 时，此设置才会生效；并且仅适用于具有强 ETag 的对象，或具有取自表记录的不可变身份的对象 (Iceberg 和 Delta Lake 的数据文件) 。用户态页缓存不会与文件系统缓存同时使用。若与分布式缓存配合使用，则还需启用 `use_page_cache_with_distributed_cache`。

## use_page_cache_lookahead_for_text_index {#use_page_cache_lookahead_for_text_index}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "新增设置"}]}]} />

对于不按文件顺序读取的文本索引文件 (字典、倒排列表、位置) ，默认情况下会经由用户态页缓存读取，预读量为一个块，以便每次读取后都能复用远程连接。启用此设置后，这些文件将改为像其他文件一样使用 `page_cache_lookahead_blocks`。

## use_page_cache_with_distributed_cache {#use_page_cache_with_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.3"},{"label": "0"},{"label": "新增设置"}]}]} />

使用分布式缓存时，启用用户态页缓存。
