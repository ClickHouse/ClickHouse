<div id="enable_parallel_single_level_merge">
  ## enable_parallel_single_level_merge
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "新增设置：将键空间拆分为互不重叠的哈希分区，由各线程独立合并，从而并行执行单层聚合哈希表的最终合并。"}]}]} />

并行执行各线程单层聚合哈希表的最终合并。键空间会根据键的哈希值拆分为互不重叠的分区，每个分区独立合并：合并线程遍历所有线程本地表，并合并属于其分区的键，因此不会有两个线程同时处理同一个键。如果关闭此设置，单层表将在单个线程上串行合并。无论此设置是否启用，按 8 位和 16 位键进行的聚合均会保留其自身基于范围分区的并行合并。
