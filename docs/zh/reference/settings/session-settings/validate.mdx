## validate_group_by_all_key_types {#validate_group_by_all_key_types}

控制是否依据 [allow&#95;suspicious&#95;types&#95;in&#95;group&#95;by](/zh/reference/settings/session-settings/allow-suspicious#allow_suspicious_types_in_group_by) 检查 `GROUP BY ALL` 展开 `SELECT` expressions 后所得的 grouping keys。禁用此设置可恢复 26.7 之前版本的行为：这些版本会接受写为 `GROUP BY ALL` 的 [Variant](/zh/reference/data-types/variant) 或 [Dynamic](/zh/reference/data-types/dynamic) key，例如未指定类型的 JSON subpath 作为 grouping key。仅在启用 analyzer 时生效 (`enable_analyzer = 1`，即默认值) ；旧 analyzer 在 26.7 之前同样会拒绝此类 key，因此无需恢复任何行为。显式 `GROUP BY` 不受影响，无论如何仍会拒绝此类 key，因此该设置的范围比 `allow_suspicious_types_in_group_by` 更窄，后者也允许在显式 `GROUP BY` 中使用它们。

可能的值：

* 0 - 不验证 `GROUP BY ALL` 展开后所得的 key types。
* 1 - 验证这些类型，与显式 `GROUP BY` 验证其自身 keys 的方式相同。
