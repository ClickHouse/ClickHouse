## create_token_default_ttl_seconds {#create_token_default_ttl_seconds}

<SettingsInfoBlock type="UInt64" default_value="1800" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1800"},{"label": "新增设置，用于为通过 `CREATE TOKEN` 创建且未显式指定 `VALID UNTIL` 或 `VALID FOR` 子句的标记设置有效期。该语句为新增功能，因此没有可恢复的早期行为；先前值即默认值本身：与较早版本的 `兼容性` 不得导致标记变为永不过期。"}]}]} />

通过 [`CREATE TOKEN`](/zh/reference/statements/create/token) 创建且未指定自身 `VALID UNTIL` 或 `VALID FOR` 子句的标记的有效期，单位为秒。默认值为 30 分钟，因此未要求延长有效期的标记有效期较短。

可能的值：

* 正整数 — 标记将在创建后经过相应秒数后过期。
* 0 — 未指定显式子句的标记永不过期。

这仅是默认值。查询中显式指定的 `VALID UNTIL` 或 `VALID FOR` 子句始终优先，包括 `VALID UNTIL 'infinity'`；它会创建一个无论此设置为何都永不过期的标记。
