## optimize_min_max_from_files {#optimize_min_max_from_files}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "新增设置：基于 Parquet 列块统计信息计算 `min` \/ `max`。"}]}]} />

启用或禁用直接利用数据文件中已存储的统计信息计算列的 `min` 和 `max`，而无需读取数据。该优化仅适用于满足以下条件的查询：聚合函数只有针对表列的 `min` 和 `max`，且不含 `GROUP BY` 和筛选条件。该设置适用于使用 `Parquet` 格式的表函数/引擎 `file` (不适用于归档内的文件) ，且仅支持整数 (最多 64 位) 、日期、日期时间和 decimal 类型的列，同时要求每个行组中都包含这些列的列块统计信息。

可选值：

* 0 - 优化已禁用。
* 1 - 优化已启用。
