## show_create_query_identifier_quoting_rule {#show_create_query_identifier_quoting_rule}

<SettingsInfoBlock type="IdentifierQuotingRule" default_value="when_necessary" />

控制在 `SHOW CREATE` 输出中何时为标识符加引号。`when_necessary` (默认值) 仅在必要时为标识符加引号，以生成有效且无歧义的 SQL；`user_display` 为属于 SQL 关键字的标识符加引号；`always` 为所有标识符加引号。此设置控制是否添加引号；引号字符及转义方式则由 `show_create_query_identifier_quoting_style` 控制。

## show_create_query_identifier_quoting_style {#show_create_query_identifier_quoting_style}

<SettingsInfoBlock type="IdentifierQuotingStyle" default_value="Backticks" />

控制 `SHOW CREATE` 输出中带引号标识符的书写方式。`Backticks` (默认) 使用 ClickHouse 风格的反引号；`DoubleQuotes` 使用双引号，并采用 ClickHouse 的转义规则；`BackticksMySQL` 使用与 MySQL 兼容的反引号，标识符内嵌的反引号会被双写。此设置不决定哪些标识符需要加引号；如需控制这一点，请使用 `show_create_query_identifier_quoting_rule`。
