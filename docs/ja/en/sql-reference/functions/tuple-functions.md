<div id="untuple">
  ## untuple
</div>

呼び出し位置で、[tuple](/ja/sql-reference/data-types/tuple) の要素を構文的に置換します。

結果カラムの名前は実装依存であり、変更される可能性があります。`untuple` の後で特定のカラム名を前提にしないでください。

**構文**

```sql
untuple(x)
```

クエリ結果からカラムを除外するには、`EXCEPT` 式を使用できます。

**引数**

* `x` — `tuple` 関数、カラム、または要素のタプル。[Tuple](../data-types/tuple.md)。

**戻り値**

* なし。

**例**

入力テーブル:

```text
┌─key─┬─v1─┬─v2─┬─v3─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 20 │ 40 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 65 │ 70 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 30 │ 20 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 12 │  7 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 50 │ 70 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴────┴────┴───────────┘
```

`Tuple` 型のカラムを `untuple` 関数の引数として使用する例:

```sql title="Query"
SELECT untuple(v6) FROM kv;
```

```text title="Response"
┌─_ut_1─┬─_ut_2─┐
│    33 │ ab    │
│    44 │ cd    │
│    55 │ ef    │
│    66 │ gh    │
│    77 │ kl    │
└───────┴───────┘
```

`EXCEPT` 式の使用例:

```sql title="Query"
SELECT untuple((* EXCEPT (v2, v3),)) FROM kv;
```

```text title="Response"
┌─key─┬─v1─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴───────────┘
```
