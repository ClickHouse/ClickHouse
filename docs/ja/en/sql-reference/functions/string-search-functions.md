このセクションのすべての関数は、デフォルトで大文字と小文字を区別して検索を行います。大文字と小文字を区別しない検索は、通常、別の関数バリアントとして提供されます。

:::note
大文字と小文字を区別しない検索は、英語の大文字・小文字の規則に従います。たとえば、英語では `i` の大文字は
`I` ですが、トルコ語では `İ` です。そのため、英語以外の言語では想定外の結果になる場合があります。
:::

このセクションの関数は、検索対象の文字列 (このセクションでは `haystack` と呼びます) と検索文字列 (このセクションでは `needle` と呼びます) がシングルバイトでエンコードされたテキストであることも前提としています。この前提が
満たされていなくても、例外はスローされず、結果は未定義です。UTF-8 でエンコードされた文字列での検索は、通常、別の関数
バリアントとして提供されます。同様に、UTF-8 関数バリアントを使用していて、入力文字列が UTF-8 でエンコードされたテキストでない場合でも、例外はスローされず、
結果は未定義です。なお、自動的な Unicode 正規化は行われませんが、そのために
[normalizeUTF8*()](/ja/sql-reference/functions/string-functions#normalizeUTF8NFC) 関数を使用できます。

[一般的な文字列関数](string-functions.md) と [文字列置換関数](string-replace-functions.md) については、別途説明しています。
