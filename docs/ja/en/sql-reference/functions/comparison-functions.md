<div id="comparison-rules">
  ## 比較ルール
</div>

以下の比較関数は、型 [UInt8](/ja/sql-reference/data-types/int-uint) の `0` または `1` を返します。比較できるのは同じグループ内の値同士のみです
(例: `UInt16` と `UInt64`) 。異なるグループ間では比較できません (例: `UInt16` と `DateTime`) 。
数値と文字列の比較が可能で、文字列と日付、日付と時刻の比較も可能です。
Tuple と Array の比較は辞書順で行われます。つまり、左側と右側の Tuple/Array の対応する各要素ごとに
比較されます。

比較可能な型は次のとおりです。

* 数値と Decimal
* 文字列と Fixed String
* Date
* 日付と時刻
* Tuple (辞書順比較)
* Array (辞書順比較)

:::note
String はバイト単位で比較されます。文字列のいずれかに UTF-8 でエンコードされたマルチバイト文字が含まれている場合、予期しない結果になることがあります。
ある文字列 S1 が別の文字列 S2 をプレフィックスとして持つ場合、S1 は S2 より長いものと見なされます。
:::
