<div id="h3-index">
  ## H3 Index
</div>

[H3](https://h3geo.org/) は地理空間インデックスシステムで、地球の表面を均一な六角形セルからなるグリッドに分割します。このシステムは階層構造になっており、最上位レベルの各六角形 (「親」) は、同じ形のより小さな 7 つの六角形 (「子」) に分割でき、この分割がさらに繰り返されます。

この階層のレベルは `resolution` と呼ばれ、`0` から `15` までの値を取ります。このうち `0` は、セルが最も大きく最も粗い `base` レベルです。

緯度と経度の組は、グリッドセルを識別する 64 ビットの H3 index に変換できます。

H3 index は主に位置情報のバケット化や、そのほかの地理空間操作に使用されます。

H3 システムの完全な説明は、[Uber Engineering のサイト](https://www.uber.com/blog/h3/)で確認できます。

<div id="h3isvalid">
  ## h3IsValid
</div>

その数値が有効な [H3](#h3-index) インデックスかどうかを確認します。

**構文**

```sql
h3IsValid(h3index)
```

**パラメータ**

* `h3index` — 六角形インデックス番号。[UInt64](../../data-types/int-uint.md)。

**戻り値**

* 1 — この数値は有効な H3 インデックスです。[UInt8](../../data-types/int-uint.md)。
* 0 — この数値は有効な H3 インデックスではありません。[UInt8](../../data-types/int-uint.md)。

**例**

```sql title="Query"
SELECT h3IsValid(630814730351855103) AS h3IsValid;
```

```text title="Response"
┌─h3IsValid─┐
│         1 │
└───────────┘
```

<div id="h3getresolution">
  ## h3GetResolution
</div>

指定された[H3](#h3-index)索引の解像度を取得します。

**構文**

```sql
h3GetResolution(h3index)
```

**パラメータ**

* `h3index` — 六角形インデックス番号。[UInt64](../../data-types/int-uint.md)。

**戻り値**

* インデックスの解像度。範囲: `[0, 15]`。[UInt8](../../data-types/int-uint.md)。
* インデックスが無効な場合、この関数はランダムな値を返します。インデックスを確認するには [h3IsValid](#h3isvalid) を使用してください。[UInt8](../../data-types/int-uint.md)。

**例**

```sql title="Query"
SELECT h3GetResolution(639821929606596015) AS resolution;
```

```text title="Response"
┌─resolution─┐
│         14 │
└────────────┘
```

<div id="geotoh3">
  ## geoToH3
</div>

指定した解像度で `(lat, lon)` の [H3](#h3-index) 索引を返します。

**構文**

```sql
geoToH3(lat, lon, resolution)
```

**引数**

* `lat` — 緯度。[Float64](../../data-types/float.md)。
* `lon` — 経度。[Float64](../../data-types/float.md)。
* `resolution` — インデックスの解像度。範囲: `[0, 15]`。[UInt8](../../data-types/int-uint.md)。

**戻り値**

* 六角形インデックス番号。[UInt64](../../data-types/int-uint.md)。
* エラー時は 0。[UInt64](../../data-types/int-uint.md)。

注記: ClickHouse v25.4 以前では、`geoToH3()` は `(lon, lat)` の順序で値を受け取ります。ClickHouse v25.5 以降では、入力値の順序は `(lat, lon)` です。以前の動作は、設定 `geotoh3_argument_order = 'lon_lat'` を使用して復元できます。

**例**

```sql title="Query"
SELECT geoToH3(55.71290588, 37.79506683, 15) AS h3Index;
```

```text title="Response"
┌────────────h3Index─┐
│ 644325524701193974 │
└────────────────────┘
```


<div id="h3polygontocellswithcontainment">
  ## h3PolygonToCellsWithContainment
</div>

指定したジオメトリ (Ring または (Multi-) Polygon) を、H3 の実験的な包含モードを使用して、指定した解像度でカバーする hexagon を返します。

この関数では、`flags` を H3 の包含モードに次のように対応付けます。

* `0` — `CONTAINMENT_CENTER`
* `1` — `CONTAINMENT_FULL`
* `2` — `CONTAINMENT_OVERLAPPING`
* `3` — `CONTAINMENT_OVERLAPPING_BBOX`

**構文**

```sql
h3PolygonToCellsWithContainment(geometry, resolution, flags)
```

**引数**

* `geometry` には、次のいずれかの [Geoデータ型](../../data-types/geo.md) またはその基になるプリミティブ型を指定できます。
  * [Ring](../../data-types/geo.md#ring)
  * [Polygon](../../data-types/geo.md#polygon)
  * [MultiPolygon](../../data-types/geo.md#multipolygon)
* `resolution` — インデックスの解像度。範囲: `[0, 15]`。[UInt8](../../data-types/int-uint.md)。
* `flags` — 包含モード。範囲: `[0, 3]`。`0`、`1`、`2`、`3` などの整数リテラル、または [UInt32](../../data-types/int-uint.md) の値 (例: `toUInt32(2)`) を使用します。値は `UInt32` として H3 API に渡されます。その他のネイティブ整数型は、正確なキャストで変換されます。

**戻り値**

* 選択した包含モードに応じた H3 インデックス の Array。[Array](../../data-types/array.md)([UInt64](../../data-types/int-uint.md))。

**例**

```sql title="Query"
SELECT
    h3PolygonToCellsWithContainment([(-122.4089866999972145, 37.813318999983238), (-122.3544736999993603, 37.7198061999978478), (-122.4798767000009008, 37.8151571999998453)], 7, 0) AS center_cells,
    h3PolygonToCellsWithContainment([(-122.4089866999972145, 37.813318999983238), (-122.3544736999993603, 37.7198061999978478), (-122.4798767000009008, 37.8151571999998453)], 7, 2) AS overlap_cells;
```

```text title="Response"

1. │ [608692970585063423,608692970719281151,608692970752835583,608692970769612799,608692970819944447,608692971927240703,608692972027903999] │ [608692970249519103,608692970266296319,608692970585063423,608692970601840639,608692970635395071,608692970685726719,608692970719281151,608692970736058367,608692970752835583,608692970769612799,608692970786390015,608692970819944447,608692971927240703,608692971994349567,608692972027903999] │
   └────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┴────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
