幾何オブジェクトを扱うための関数です。たとえば、[球面上の点同士の距離を計算する](./coordinates.md)、[geohash を計算する](./geohash.md)、[H3 インデックス](./h3.md)を扱う、[Mapbox Vector Tiles をエンコードする](./mvt.md)といった処理に使用できます。
