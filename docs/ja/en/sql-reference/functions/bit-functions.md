ビット関数は、`UInt8`、`UInt16`、`UInt32`、`UInt64`、`Int8`、`Int16`、`Int32`、`Int64`、`Float32`、`Float64` の任意の 2 つの型の組み合わせに対して動作します。`String` 型および `FixedString` 型をサポートする関数もあります。

結果の型は、引数のうち最大のビット数と同じビット数を持つ整数になります。少なくとも 1 つの引数が符号付きの場合、結果は符号付き整数になります。引数が浮動小数点数の場合は、Int64 にキャストされます。
