ハッシュ関数は、要素を決定論的な擬似ランダム順に並べ替えるために使用できます。

Simhash は、近い (類似した) 引数に対して近いハッシュ値を返すハッシュ関数です。

ほとんどのハッシュ関数は、任意の型の引数を任意の数だけ受け取ります。

:::note
NULL のハッシュは NULL です。Nullable カラムの非 NULL ハッシュを取得するには、tuple でラップします。

```sql
SELECT cityHash64(tuple(NULL))
```

:::

:::note
テーブル全体の内容の hash を計算するには、`sum(cityHash64(tuple(*)))` (または他の hash function) を使用します。`tuple` を使うことで、NULL 値を含む行もスキップされません。`sum` によって、行の順序は結果に影響しなくなります。
:::
