これらの関数は、AES (Advanced Encryption Standard) アルゴリズムを使用したデータの暗号化と復号を行います。

鍵長は暗号化モードによって異なり、`-128-`、`-196-`、`-256-` モードではそれぞれ `16`、`24`、`32` バイトです。

初期化ベクトルの長さは常に 16 バイトです (16 バイトを超える部分は無視されます) 。
