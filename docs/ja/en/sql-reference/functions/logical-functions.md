以下の関数は、任意の数値型の引数に対して論理演算を行います。
これらの関数は、[`UInt8`](../data-types/int-uint.md) 型の `0` または `1` を返し、場合によっては `NULL` を返します。

引数の `0` は `false`、`0` 以外の値は `true` と見なされます。
