ユーザーは SQL文を使って ClickHouse を操作します。ClickHouse は [SELECT](select/index.md) や [CREATE](create/index.md) などの一般的な SQL文に加え、[KILL](kill.md) や [OPTIMIZE](optimize.md) などの専用の文もサポートしています。
