ClickHouse には、ClickHouse に接続するためのさまざまなネイティブクライアントとインターフェイスが用意されています。

詳しくは、以下のページを参照してください。

| セクション                                                | 概要                                                      |
| ---------------------------------------------------- | ------------------------------------------------------- |
| [clickhousectl](/ja/interfaces/cli)                     | ClickHouse 用の CLI。ローカル環境と Cloud に対応しています。               |
| [ClickHouse Client](/ja/interfaces/client)              | コマンドラインオプションと設定ファイルをサポートするネイティブコマンドラインクライアント。           |
| [ドライバーとインターフェイス](/ja/interfaces/overview)               | 各種ネットワークインターフェイス、ライブラリ、ビジュアルインターフェイス。                   |
| [SQL Console](/ja/integrations/sql-clients/sql-console) | ClickHouse Cloud のデータをすばやく簡単に操作する方法。                    |
| [Web SQL UI (Play)](/ja/interfaces/web-sql)             | ClickHouse が `/play` で提供する、ブラウザー内で使える組み込み SQL インターフェイス。 |
