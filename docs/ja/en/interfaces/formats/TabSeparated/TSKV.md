<div id="description">
  ## 説明
</div>

[`TabSeparated`](./TabSeparated.md)フォーマットと同様ですが、値を `name=value` 形式で出力します。
名前は [`TabSeparated`](./TabSeparated.md) フォーマットと同じ方法でエスケープされ、`=` 記号もエスケープされます。

```text
SearchPhrase=   count()=8267016
SearchPhrase=bathroom interior design    count()=2166
SearchPhrase=clickhouse     count()=1655
SearchPhrase=2014 spring fashion    count()=1549
SearchPhrase=freeform photos       count()=1480
SearchPhrase=angelina jolie    count()=1245
SearchPhrase=omsk       count()=1112
SearchPhrase=photos of dog breeds    count()=1091
SearchPhrase=curtain designs        count()=1064
SearchPhrase=baku       count()=1000
```

```sql title="Query"
SELECT * FROM t_null FORMAT TSKV
```

```text title="Response"
x=1    y=\N
```

:::note
小さいカラムが大量にある場合、このフォーマットは非効率であり、通常はこれを使う理由はありません。
それでも、効率の面では [`JSONEachRow`](../JSON/JSONEachRow.md) フォーマットに劣りません。
:::

パース時には、異なるカラムの値は任意の順序で指定できます。
一部の値は省略しても構いません。省略された値は対応するデフォルト値と同じものとして扱われます。
この場合、ゼロと空の行がデフォルト値として使用されます。
テーブルで指定できる複雑な値は、デフォルト値としてはサポートされていません。

パースでは、等号や値を伴わない追加のフィールド `tskv` を加えることもできます。このフィールドは無視されます。

インポート時には、不明な名前のカラムはスキップされます。
これは、設定 [`input_format_skip_unknown_fields`](/ja/operations/settings/settings-formats.md/#input_format_skip_unknown_fields) が `1` に設定されている場合です。

[NULL](/ja/sql-reference/syntax.md) は `\N` としてフォーマットされます。

  ### データの読み込み
</div>

```sql
SELECT *
FROM football
FORMAT TSKV
```
