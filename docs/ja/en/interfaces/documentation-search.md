ドキュメント検索ページは、埋め込みのリファレンスドキュメントを即座に検索できる、小規模で自己完結型の Web UI です。任意の ClickHouse HTTP ポートの `/docs` パスで提供されます。

任意の ClickHouse HTTP ポートで `/docs` にアクセスすると (たとえば `http://localhost:8123/docs`) 、開くことができます。

<div id="what-it-does">
  ## できること
</div>

このページは、入力に合わせて HTTP 経由で [`system.documentation`](/ja/operations/system-tables/documentation) テーブルにクエリを実行し、選択したエンティティの Markdown を表示します。`system.documentation` を読み取るため、このテーブルが公開しているすべてのエンティティ、つまり関数、集約関数、テーブル関数、テーブルエンジン、データベースエンジン、データ型、設定、フォーマット、圧縮コーデック、プロファイルイベント、メトリクス、システムテーブルそのものなどを対象としており、常に実行中のサーバーに埋め込まれているドキュメントと一致します。

検索ボックスに入力すると、一致候補が種類ごとに色分けされた一覧で表示され、候補を選択するとそのドキュメントが表示されます。表示には次のものが含まれます。

* エンティティのタイトルの横にある鉛筆アイコンのリンク。`system.documentation` の `source` カラムから取得した GitHub 上のソースファイルを開きます。
* コードブロックの ClickHouse SQL シンタックスハイライト。[`/play`](/ja/interfaces/http) UI と同じ埋め込みレキサー (`Lexer.wasm`) を使用します。
* [KaTeX](https://katex.org/) による TeX 数式 (たとえば `corr` ページの数式) 。
* `:::note`/`:::tip`/… の補足ブロック、共有可能なリンク付き見出しアンカー、コードブロックにホバーしたときの「Copy」ボタン。
* 相対リンクは、該当するものがあればアプリ内の別のドキュメント化されたエンティティに解決され、なければ `https://clickhouse.com/docs` に解決されます。また、「Related」と「Alias of」の参照はアプリ内リンクになります。

現在の検索語、開いているエンティティ、セクションは URL フラグメントにも反映されるため、特定のページやセクションへ直接リンクでき、ブラウザーの戻る/進む操作でも復元されます。自動検出付きのライト/ダークテーマ切り替えは `/play` と統一されています。

<div id="connecting">
  ## 接続
</div>

ヘッダーには `/play` とまったく同じく、`URL`、`user`、`password` の入力欄があります。ページが ClickHouse から配信される場合、`URL` の既定値は現在のオリジンになります。ページをローカルファイルとして開く場合は、既定で `http://localhost:8123/` になるため、リモートサーバーに対してページをローカルで開くこともできます。クロスリンク名のcache は、接続が変更されると自動的に再構築されます。

<div id="assets">
  ## アセット
</div>

Markdown レンダラー ([Marked](https://marked.js.org/)) 、数式レンダラー (KaTeX とそのフォント) 、SQL レキサーを含むすべてのアセットは、ページが HTTP 経由で配信される場合、ClickHouse バイナリ自体から提供されます。ClickHouse の HTTP オリジンではサードパーティの CDN は読み込まれないため、このページは自己完結しており、オフラインでも動作し、扱う認証情報と同時にサードパーティのネットワークコードが実行されることもありません。

<div id="security">
  ## セキュリティに関する考慮事項
</div>

このページは、ヘッダーに入力した認証情報を使って ClickHouse の HTTP エンドポイントにクエリを送信するため、HTTP プロトコルと同じ注意事項が当てはまります。

* 信頼できない環境では、認証情報を保護するため、`/docs` は必ず HTTPS 経由で提供してください。
* HTTP プロトコルへのアクセスを制限するのと同様に、ネットワーク レベル (ファイアウォール、リバースプロキシ、または `listen_host` 設定) でもアクセスを制限してください。

`system.documentation` にはサーバーに埋め込まれた静的なリファレンスドキュメントしか含まれていないため、このページからテーブル内のデータが公開されることはありません。
