Web SQL UI (Play) は、ClickHouse に組み込まれたブラウザ内のクエリインターフェイスです。ClickHouse の任意の HTTP ポートの `/play` パスで提供されます (例: `http://localhost:8123/play`) 。クエリを作成して実行し、結果をテーブルまたはチャートとして表示したり、URL をコピーしてクエリを共有したりできます。

インターフェイス全体は `programs/server/play.html` に含まれており、フレームワークやビルドステップを使わず、ClickHouse バイナリから直接提供される単一の自己完結型ページです。唯一の例外はチャートのレンダリングです。`uPlot` チャートライブラリは、結果を初めてチャートとして表示する際にサードパーティの CDN から遅延読み込みされるため、オフライン環境やエグレスが制限されたデプロイメントではチャートを利用できません。

<div id="query-tabs">
  ## クエリタブ
</div>

タブを使うと、1つのエディタで複数のクエリを切り替えたりブラウザの履歴に頼ったりすることなく、複数のクエリを並べて管理できます。

各タブには、それぞれ独自のクエリテキスト、タイトル、クエリパラメータ、最後の実行結果があります。接続設定 (URL、ユーザー、パスワード) はグローバルで、すべてのタブに共通です。

<div id="when-the-tab-bar-appears">
  ### タブバーが表示されるタイミング
</div>

タブバーは、クエリを実行したとき、またはタブが複数あるときに表示されます。結果のないタブが1つだけある場合は、タブ機能が導入される前のページと見た目がまったく同じなので、必要になるまではタブバーは表示されません。

アクティブなタブは、見た目としてページに自然になじみます。背景にはクエリごとのハッシュカラー (ページ背景ですでに使われているものと同じ色) が反映され、ライトテーマでは上部ほど彩度が高く、ダークテーマでは上部ほど明るいグラデーションになります。非アクティブなタブには、それぞれのクエリテキストのハッシュに応じた色味が付き、異なるタブが自動的に色で見分けられるようになっています。

<div id="creating-closing-and-renaming-tabs">
  ### タブの作成、タブを閉じる、名前の変更
</div>

* タブの右側にある `[+]` ボタンをクリックして、新しいタブを作成します。
* タブ上の `x` アイコンをクリックして、タブを閉じます。
* 新しいタブには `Query A`、`Query B` などのデフォルト名が付きます。
* アクティブなタブのタイトルをクリックすると、その場で編集できます。編集フィールドはテキストに合わせて広がります。

<div id="switching-tabs">
  ### タブの切り替え
</div>

* 非アクティブなタブをクリックすると、そのタブに切り替わります。
* タブパネル上でマウスホイールをスクロールすると、タブを切り替えられます。上にスクロールすると左のタブに、下にスクロールすると右のタブに切り替わります (存在する場合) 。縦方向・横方向どちらのホイールスクロールにも対応しています。

タブバーは水平方向には固定されており、ページを横スクロールしても下部の ClickHouse ロゴと同様に左側にとどまります。一方、縦方向にはページの他の部分と一緒にスクロールしていきます。

<div id="persistence-and-browser-history">
  ### 永続化とブラウザー履歴
</div>

ワークスペース (タブ、タブのタイトル、アクティブなタブ、タブの順序、小さな結果スナップショット) は IndexedDB に永続化され、再読み込み時に復元されます。永続化はベストエフォートで行われます。IndexedDB を利用できない場合、ワークスペースは現在のセッション中は in-memory state にフォールバックします。

タブはブラウザーの History API および URL とも連携します。

* 履歴 state にはアクティブなタブが保持されるため、ブラウザーの戻るボタンと進むボタンでタブを切り替えられます。
* URL には `tab=<name>` パラメーターが追加されます。読み込み時には、URL のクエリと `tab` パラメーターが保存済みのタブとリコンサイルされます。その名前の既存タブがあれば再利用され (そのクエリで置き換えられます) 、名前が見つからない場合、または名前未設定の場合は新しいタブが作成されます。これにより、自分で保存したタブを保持したまま、新しいクエリを含む URL を開けるようになります。

<div id="limitations">
  ### 制限事項
</div>

クエリの実行中にタブを切り替えると、そのクエリの実行中状態は失われます。

復元のためにスナップショット保存されるのは、小さな結果だけです。大きな結果 (スナップショットのサイズ上限を超えるもの) や画像結果は保存されません。つまり、タブを切り替えたり再読み込みしたりしても、タブにはクエリは残りますが、表示されていた結果は保持されず、クエリを再実行すると再度生成されます。これは、単一クエリの結果にも、&quot;Run all&quot; (複数クエリ) の実行による結合出力にも当てはまります。
