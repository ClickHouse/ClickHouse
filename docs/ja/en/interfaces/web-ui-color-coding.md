組み込みの Web SQL UI (`play.html`。任意の ClickHouse HTTP ポートの [`/play`](/ja/interfaces/http) パスで提供) では、結果セルを色分けして、カラム内のパターンを一目で把握しやすくできます。各カラムには、個別に切り替えられる色分けモードがあります。

<div id="switching-the-mode">
  ## モードの切り替え
</div>

各カラム見出しの右側には 🌈 アイコンが表示されます。これをクリックすると、そのカラムで使用できるモードが順に切り替わります。ホバーポインター (マウス) を備えたデバイスでは、見出しにホバーしている間だけアイコンが表示されるため、通常は邪魔になりません。一方、ホバーできないタッチデバイスやその他の粗いポインターデバイスでは、直接タップできるよう、アイコンは常に表示されます。

カラムで使用できるモードは、その型によって異なります。

* 数値カラムと `Date`/`DateTime`/`Date32`/`DateTime64` カラムでは、`bar` → `heatmap` → `categorical` → `none` の順に切り替わります。
* それ以外のすべてのカラムでは、`none` と `categorical` が切り替わります。

デフォルトのモードは、数値カラムでは `bar`、日付・時刻カラムを含むその他すべてのカラムでは `none` です。

<div id="modes">
  ## モード
</div>

* **`bar`** — 値に比例した横棒をセル内に描画します。数値カラムでは棒は 0 を基準に伸びます。`Date`/`DateTime` カラムでは、タイムスタンプに 0 基準は意味を持たないため、代わりにカラムの `min`..`max` の範囲に広がります。
* **`heatmap`** — カラムの最小値から最大値の範囲でスケーリングした値を表す色で、セルの背景全体を塗りつぶします。
* **`categorical`** — セルの値をハッシュ化して得た色でセルの背景を塗りつぶします。そのため、同じ値には同じ色、異なる値には異なる色が割り当てられます。これはどのカラム型でも機能します。
* **`none`** — 色分けは行いません。

`Date`、`DateTime`、`Date32`、`DateTime64` の各カラムは時刻の値に基づいて色付けされ、スケールが閲覧者のブラウザのタイムゾーンに依存しないよう、UTC として解釈されます。

`heatmap` と `categorical` の背景色には `oklch` カラースペースを使用し、テーマごとに lightness と chroma を固定したまま hue のみを変化させることで、ライトテーマとダークテーマの両方でセル内テキストの可読性を保ちます。背景は、1 つの行が複数行にわたる場合でもセル全体を塗りつぶします。

<div id="categorical-emphasis">
  ## 選択時のカテゴリ別強調
</div>

`categorical` モードでは、セルを選択すると、同じ値を持つほかのセルが強調され、太字かつ最大コントラストの文字色 (ダークテーマでは純白、ライトテーマでは純黒) で表示されます。一方、選択したセル自体は強調されません。これにより、特定の値がそのカラム内のほかのどこに現れているかを簡単に確認できます。

<div id="persistence">
  ## 永続化
</div>

選択したモードは、ページのURLとブラウザの履歴にカラムごとに記録されるため、ページを再読み込みしたり、リンクを共有したり、戻る／進むで移動したりしても保持されます。URLと履歴の状態をコンパクトに保つため、保存されるのはデフォルト以外の選択だけです。

<div id="limitations">
  ## 制限事項
</div>

* 縦方向 (転置) の単一行レイアウトでは、色分けは表示されません。
* `DateTime64(9)` の差が 1 マイクロ秒未満の場合、グラデーションでは視覚的な違いに意味がないため、色のスケール上では区別されません。
