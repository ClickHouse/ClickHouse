ClickHouse は、テーブルエンジンをはじめ、外部システムと連携するためのさまざまな手段を提供しています。他のすべてのテーブルエンジンと同様に、設定は `CREATE TABLE` または `ALTER TABLE` クエリを使用して行います。設定後、ユーザーから見ると、そのインテグレーションは通常のテーブルのように見えますが、それに対するクエリは外部システムにプロキシされて実行されます。このように透過的にクエリできることは、使用のたびに独自のクエリ方法が必要な Dictionaries や Table functions などの代替手法と比べた場合の、このアプローチの主な利点の 1 つです。
