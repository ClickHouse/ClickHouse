テーブルエンジンは、大きく3つのカテゴリに分けられます。

* 主な本番利用向けの [MergeTree エンジンファミリー](../../../engines/table-engines/mergetree-family/index.md)
* 小規模な一時データ向けの [Log エンジンファミリー](../../../engines/table-engines/log-family/index.md)
* [インテグレーション向けテーブルエンジン](../../../engines/table-engines/integrations/index.md)

残りのエンジンはそれぞれ用途が独特で、まだファミリーには分類されていないため、この &quot;special&quot; カテゴリに配置されています。
