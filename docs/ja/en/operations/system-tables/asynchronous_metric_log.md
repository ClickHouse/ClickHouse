<div id="description">
  ## 説明
</div>

`system.asynchronous_metrics` の履歴値を格納します。一定の時間間隔 (既定では1秒) ごとに1回保存されます。既定で有効です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行するサーバーのホスト名。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — イベント日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — イベント時刻。
* `metric` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — メトリクス名。
* `value` ([Float64](/ja/sql-reference/data-types/float)) — メトリクス値。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.asynchronous_metric_log LIMIT 3 \G
```
