<div id="description">
  ## 説明
</div>

`system.part_log` テーブルは、[part&#95;log](/ja/operations/server-configuration-parameters/settings#part_log) サーバー設定が指定されている場合にのみ作成されます。

このテーブルには、データの追加やマージなど、[MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) ファミリーのテーブルの [データパーツ](../../engines/table-engines/mergetree-family/custom-partitioning-key.md) で発生したイベントに関する情報が含まれています。

`system.part_log` テーブルには、次のカラムがあります。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行しているサーバーのホスト名。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — このデータパーツを作成した INSERT クエリの識別子。
* `event_type` ([Enum8(&#39;NewPart&#39; = 1, &#39;MergeParts&#39; = 2, &#39;DownloadPart&#39; = 3, &#39;RemovePart&#39; = 4, &#39;MutatePart&#39; = 5, &#39;MovePart&#39; = 6, &#39;MergePartsStart&#39; = 7, &#39;MutatePartStart&#39; = 8)](/ja/sql-reference/data-types/enum)) — データパーツで発生したイベントの種類。次のいずれかの値を取ります: NewPart — 新しいデータパーツの挿入、MergePartsStart — データパーツのマージ開始、MergeParts — データパーツのマージ完了、DownloadPart — データパーツのダウンロード、RemovePart — [DETACH PARTITION](/ja/sql-reference/statements/alter/partition#detach-partitionpart) を使用したデータパーツの削除または detach。MutatePartStart — データパーツの mutation 開始、MutatePart — データパーツの mutation 完了、MovePart — データパーツをあるディスクから別のディスクへ移動。
* `merge_reason` ([Enum8(&#39;NotAMerge&#39; = 1, &#39;RegularMerge&#39; = 2, &#39;TTLDeleteMerge&#39; = 3, &#39;TTLRecompressMerge&#39; = 4, &#39;TTLDropMerge&#39; = 5)](/ja/sql-reference/data-types/enum)) — 型が MERGE&#95;PARTS のイベントの理由。次のいずれかの値を取ります: NotAMerge — 現在のイベントは MERGE&#95;PARTS 型ではありません、RegularMerge — 通常のマージ、TTLDeleteMerge、TTLDropMerge — 期限切れデータのクリーンアップ。TTLRecompressMerge — データパーツの再圧縮。
* `merge_algorithm` ([Enum8(&#39;Undecided&#39; = 0, &#39;Vertical&#39; = 1, &#39;Horizontal&#39; = 2)](/ja/sql-reference/data-types/enum)) — 型が MERGE&#95;PARTS のイベントに対するマージアルゴリズム。次のいずれかの値を取ります: Undecided、Horizontal、Vertical
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — イベントの日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — イベント時刻。
* `event_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — マイクロ秒精度のイベント時刻。
* `duration_ms` ([UInt64](/ja/sql-reference/data-types/int-uint)) — この操作の所要時間。
* `database` ([String](/ja/sql-reference/data-types/string)) — データパーツが属するデータベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — データパーツが属するテーブルの名前。
* `table_uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — データパーツが属するテーブルの UUID。
* `part_name` ([String](/ja/sql-reference/data-types/string)) — データパーツの名前。
* `partition_id` ([String](/ja/sql-reference/data-types/string)) — データパーツが挿入されたパーティションの ID。`tuple()` でパーティション化している場合、このカラムの値は `all` になります。
* `partition` ([String](/ja/sql-reference/data-types/string)) — パーティション名。
* `part_type` ([String](/ja/sql-reference/data-types/string)) — パーツの種類。設定可能な値: Wide および Compact。
* `part_storage_type` ([String](/ja/sql-reference/data-types/string)) — DataPartStorage の種類。設定可能な値: Packed - すべてのファイルが 1 つのブロブに保存されます、Full - ファイルごとに 1 つのブロブ。
* `disk_name` ([String](/ja/sql-reference/data-types/string)) — データパーツが存在するディスク名。
* `path_on_disk` ([String](/ja/sql-reference/data-types/string)) — データパーツのファイルが格納されているフォルダーへの絶対パス。
* `rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内の行数。
* `size_in_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ディスク上のデータパーツのサイズ (バイト単位) 。
* `merged_from` ([Array(String)](/ja/sql-reference/data-types/array)) — 現在のパーツの構成元となったソースパーツ名の配列。
* `bytes_uncompressed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 結果のパーツのバイト単位の非圧縮サイズ。
* `read_rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージ中に読み取られた行数。
* `read_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージ中に読み取られたバイト数。
* `peak_memory_usage` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージ中に使用された RAM の最大量。
* `deduplication_block_ids` ([Array(String)](/ja/sql-reference/data-types/array)) — このパーツの挿入時に、重複排除のために使用されたブロック ID の配列。
* `error` ([UInt16](/ja/sql-reference/data-types/int-uint)) — 発生した例外のエラーコード。
* `exception` ([String](/ja/sql-reference/data-types/string)) — 発生したエラーのテキストメッセージ。
* `mutation_ids` ([Array(String)](/ja/sql-reference/data-types/array)) — type が MUTATE&#95;PART&#95;START および MUTATE&#95;PART のイベントにおいて、ソースパーツ (merged&#95;from) に適用された mutation ID の配列。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ja/sql-reference/data-types/map)) — この操作中に収集されたすべてのプロファイルイベント。
* `projections_duration_ms` ([Map(LowCardinality(String), UInt64)](/ja/sql-reference/data-types/map)) — 各 projection のマージまたは再構築にかかった時間 (ミリ秒) 。

**別名:**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)` の別名です。
* `ProfileEvents.Values` — `mapValues(ProfileEvents)` の別名です。
* `name` — `part_name` の別名です。

{/*AUTOGENERATED_END*/ }

`system.part_log` テーブルは、`MergeTree` テーブルに初めてデータを挿入した後に作成されます。
