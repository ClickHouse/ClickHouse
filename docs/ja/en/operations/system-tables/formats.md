<div id="description">
  ## 説明
</div>

入力/出力に適しているかどうか、および並列化をサポートしているかどうかを示すフラグとともに、すべてのフォーマットの一覧を含みます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — フォーマット名。
* `is_input` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットがデータ入力に適しているかどうかを示すフラグ。
* `is_output` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットがデータ出力に適しているかどうかを示すフラグ。
* `supports_parallel_parsing` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットが並列パースをサポートするかどうかを示すフラグ。
* `supports_parallel_formatting` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットが並列フォーマットをサポートするかどうかを示すフラグ。
* `is_tty_friendly` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットが通常ターミナル上で問題なく表示されるかどうかを示すフラグ。その他のフォーマットでは、CLI は出力前に確認を求めます。
* `content_type` ([String](/ja/sql-reference/data-types/string)) — 出力フォーマットに対応する HTTP Content-Type。現在のフォーマット設定によって変わる場合があります。
* `supports_random_access` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットが入力でランダムアクセスをサポートするかどうかを示すフラグ。
* `has_schema_inference` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットは、データから動的にスキーマを推論できます (埋め込みヘッダー/メタデータ、またはデータ自体から) 。
* `has_external_schema` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットは、固定スキーマを持つか、独自のフォーマットで事前定義されたスキーマを受け入れます。
* `prefers_large_blocks` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットは、出力時により大きな blocks を書き込み、入力時にもより大きな blocks を生成します。
* `supports_append` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このフォーマットでは、単一のファイルに追記できます。
* `supports_subsets_of_columns` ([UInt8](/ja/sql-reference/data-types/int-uint)) — この入力フォーマットは、一部のカラムが省略されていることを認識できます。
* `description` ([String](/ja/sql-reference/data-types/string)) — そのフォーマットの概要説明。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — このフォーマットが最初に導入された ClickHouse のバージョン。形式は major.minor です。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連するフォーマットの名前。
