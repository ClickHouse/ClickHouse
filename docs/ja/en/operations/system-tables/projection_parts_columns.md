<div id="description">
  ## 説明
</div>

このテーブルには、MergeTree family のテーブルにあるプロジェクションパーツ内のカラムに関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/ja/sql-reference/data-types/string)) — パーティション名。
* `name` ([String](/ja/sql-reference/data-types/string)) — データパートの名前。
* `part_type` ([String](/ja/sql-reference/data-types/string)) — データパートの格納フォーマット。
* `parent_name` ([String](/ja/sql-reference/data-types/string)) — ソース (親) データパートの名前。
* `parent_uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — ソース (親) データパートの UUID。
* `parent_part_type` ([String](/ja/sql-reference/data-types/string)) — ソース (親) データパートの格納フォーマット。
* `active` ([UInt8](/ja/sql-reference/data-types/int-uint)) — データパートがアクティブかどうかを示すフラグ
* `marks` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マーク数。
* `rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 行数。
* `bytes_on_disk` ([UInt64](/ja/sql-reference/data-types/int-uint)) — すべてのデータパートファイルの合計サイズ (バイト単位) 。
* `data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパート内の圧縮データの合計サイズ。補助ファイル (たとえばマークファイル) は含まれません。
* `data_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパート内の非圧縮データの合計サイズ。補助ファイル (たとえばマークファイル) は含まれません。
* `marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マークファイルのサイズ。
* `parent_marks` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ソース (親) パート内のマーク数。
* `parent_rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ソース (親) パート内の行数。
* `parent_bytes_on_disk` ([UInt64](/ja/sql-reference/data-types/int-uint)) — すべてのソース (親) データパートファイルの合計サイズ (バイト単位) 。
* `parent_data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ソース (親) データパート内の圧縮データの合計サイズ。
* `parent_data_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ソース (親) データパート内の非圧縮データの合計サイズ。
* `parent_marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ソース (親) データパート内のマークファイルのサイズ。
* `modification_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパートがあるディレクトリの更新時刻。通常、これはデータパートの作成時刻に対応します。
* `remove_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパートが非アクティブになった時刻。
* `refcount` ([UInt32](/ja/sql-reference/data-types/int-uint)) — データパートが使用されている箇所の数。値が 2 より大きい場合、そのデータパートはクエリまたはマージで使用されています。
* `min_date` ([Date](/ja/sql-reference/data-types/date)) — パーティションキーに Date カラムが含まれている場合の最小値。
* `max_date` ([Date](/ja/sql-reference/data-types/date)) — パーティションキーに Date カラムが含まれている場合の最大値。
* `min_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — パーティションキーに DateTime カラムが含まれている場合の最小値。
* `max_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — パーティションキーに DateTime カラムが含まれている場合の、そのカラムの最大値。
* `partition_id` ([String](/ja/sql-reference/data-types/string)) — パーティションの ID。
* `min_block_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マージ後の現在のパーツを構成するデータパートの最小番号。
* `max_block_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マージ後の現在のパーツを構成するデータパートの最大番号。
* `level` ([UInt32](/ja/sql-reference/data-types/int-uint)) — マージツリーの深さ。0 は、現在のパーツが他のパーツのマージではなく INSERT によって作成されたことを意味します。
* `data_version` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパートに適用すべきミューテーションを判定するための番号です (data&#95;version より大きいバージョンのミューテーション) 。
* `primary_key_bytes_in_memory` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 主キーの値に使用されるメモリ量 (バイト単位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 主キーの値のために確保されているメモリ量 (バイト単位) 。
* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `engine` ([String](/ja/sql-reference/data-types/string)) — パラメータを含まないテーブルエンジン名。
* `disk_name` ([String](/ja/sql-reference/data-types/string)) — データパートを格納するディスクの名前。
* `path` ([String](/ja/sql-reference/data-types/string)) — データパートのファイルがあるフォルダへの絶対パス。
* `column` ([String](/ja/sql-reference/data-types/string)) — カラム名。
* `type` ([String](/ja/sql-reference/data-types/string)) — カラム型。
* `column_position` ([UInt64](/ja/sql-reference/data-types/int-uint)) — テーブル内のカラムの序数位置。1 から始まります。
* `default_kind` ([String](/ja/sql-reference/data-types/string)) — デフォルト値の式の種類 (DEFAULT、MATERIALIZED、ALIAS) 。定義されていない場合は空文字列です。
* `default_expression` ([String](/ja/sql-reference/data-types/string)) — デフォルト値の式。定義されていない場合は空文字列です。
* `column_bytes_on_disk` ([UInt64](/ja/sql-reference/data-types/int-uint)) — カラムの合計サイズ (バイト単位) 。
* `column_data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — カラム内の圧縮データの合計サイズ (バイト単位) 。
* `column_data_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — カラム内の展開後データの合計サイズ (バイト単位) 。
* `column_marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マークを含むカラムのサイズ (バイト単位) 。
* `column_modification_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — カラムが最後に変更された時刻。

**別名:**

* `bytes` — `bytes_on_disk` の別名です。
* `marks_size` — `marks_bytes` の別名です。
* `part_name` — `name` の別名です。
