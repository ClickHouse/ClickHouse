<div id="description">
  ## 説明
</div>

このテーブルには、ZooKeeper サーバーへのリクエストのパラメータと、それに対するレスポンスに関する情報が含まれています。

リクエストについては、リクエストパラメータに対応するカラムのみが設定され、残りのカラムにはデフォルト値 (`0` または `NULL`) が入ります。レスポンスが到着すると、そのデータがほかのカラムに追加されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行しているサーバーのホスト名。
* `type` ([Enum8(&#39;Request&#39; = 1, &#39;Response&#39; = 2, &#39;Finalize&#39; = 3)](/ja/sql-reference/data-types/enum)) — ZooKeeperクライアントにおけるイベントタイプ。次のいずれかの値を取ります: Request — リクエストが送信された、Response — レスポンスを受信した、Finalize — 接続が失われ、レスポンスは受信されなかった。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — イベントが発生した日付。
* `event_time` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — イベントが発生した日付と時刻。
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このリクエストを実行したスレッドの ID。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — このリクエストが実行されたクエリの ID。
* `address` ([IPv6](/ja/sql-reference/data-types/ipv6)) — リクエストの実行に使用された ZooKeeper サーバーの IP アドレス。
* `port` ([UInt16](/ja/sql-reference/data-types/int-uint)) — リクエストの実行に使用された ZooKeeper サーバーのポート。
* `session_id` ([Int64](/ja/sql-reference/data-types/int-uint)) — 各接続に対して ZooKeeper サーバーが設定する session ID。
* `duration_microseconds` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ZooKeeper がリクエストを実行するのに要した時間。
* `xid` ([Int64](/ja/sql-reference/data-types/int-uint)) — セッション内でのリクエストの ID。通常は連番のリクエスト番号です。リクエスト行と、それに対応する Response/Finalize 行で同一です。
* `has_watch` ([UInt8](/ja/sql-reference/data-types/int-uint)) — watch が設定されているかどうか。
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/ja/sql-reference/data-types/enum)) — リクエストまたはレスポンスのタイプ。
* `path` ([String](/ja/sql-reference/data-types/string)) — リクエストで指定された ZooKeeper node へのパス。リクエストでパスの指定が不要な場合は空文字列です。
* `data` ([String](/ja/sql-reference/data-types/string)) — ZooKeeper node に書き込まれたデータ (SET および CREATE リクエストではリクエストが書き込もうとした内容、GET リクエストへのレスポンスでは読み取られた内容) 、または空文字列。
* `is_ephemeral` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 作成される ZooKeeper node がエフェメラルかどうか。
* `is_sequential` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 作成される ZooKeeper node が sequential として作成されるかどうか。
* `version` ([Nullable(Int32)](/ja/sql-reference/data-types/nullable)) — 実行時にリクエストが想定する ZooKeeper node のバージョン。これは CHECK、SET、REMOVE リクエストでサポートされます (リクエストがバージョンをチェックしない場合は -1、バージョンチェックをサポートしないその他のリクエストでは NULL です) 。
* `requests_size` ([UInt32](/ja/sql-reference/data-types/int-uint)) — multi request に含まれるリクエスト数 (これは、複数の連続する通常のリクエストで構成され、それらをアトミックに実行する特別なリクエストです) 。multi request に含まれるすべてのリクエストは同じ xid を持ちます。
* `request_idx` ([UInt32](/ja/sql-reference/data-types/int-uint)) — multi request に含まれるリクエストの番号 (multi request 自体は 0、その後は 1 から順です) 。
* `zxid` ([Int64](/ja/sql-reference/data-types/int-uint)) — ZooKeeper transaction ID。正常に実行されたリクエストへの応答として ZooKeeper サーバーが発行するシリアル番号です (リクエストが実行されなかった場合、エラーが返された場合、またはクライアントがリクエストが実行されたかどうかを把握していない場合は 0) 。
* `error` ([Nullable(Enum8(&#39;ZNOWATCHER&#39; = -121, &#39;ZNOTREADONLY&#39; = -119, &#39;ZSESSIONMOVED&#39; = -118, &#39;ZNOTHING&#39; = -117, &#39;ZCLOSING&#39; = -116, &#39;ZAUTHFAILED&#39; = -115, &#39;ZINVALIDACL&#39; = -114, &#39;ZINVALIDCALLBACK&#39; = -113, &#39;ZSESSIONEXPIRED&#39; = -112, &#39;ZNOTEMPTY&#39; = -111, &#39;ZNODEEXISTS&#39; = -110, &#39;ZNOCHILDRENFOREPHEMERALS&#39; = -108, &#39;ZBADVERSION&#39; = -103, &#39;ZNOAUTH&#39; = -102, &#39;ZNONODE&#39; = -101, &#39;ZAPIERROR&#39; = -100, &#39;ZOUTOFMEMORY&#39; = -10, &#39;ZINVALIDSTATE&#39; = -9, &#39;ZBADARGUMENTS&#39; = -8, &#39;ZOPERATIONTIMEOUT&#39; = -7, &#39;ZUNIMPLEMENTED&#39; = -6, &#39;ZMARSHALLINGERROR&#39; = -5, &#39;ZCONNECTIONLOSS&#39; = -4, &#39;ZDATAINCONSISTENCY&#39; = -3, &#39;ZRUNTIMEINCONSISTENCY&#39; = -2, &#39;ZSYSTEMERROR&#39; = -1, &#39;ZOK&#39; = 0))](/ja/sql-reference/data-types/nullable)) — エラーコード。多くの値を取り得ますが、ここではその一部のみを示します: ZOK — リクエストは正常に実行された、ZCONNECTIONLOSS — 接続が失われた、ZOPERATIONTIMEOUT — リクエスト実行のタイムアウトが発生した、ZSESSIONEXPIRED — セッションの有効期限が切れた、NULL — リクエストは完了しています。
* `watch_type` ([Nullable(Enum8(&#39;NOTWATCHING&#39; = -2, &#39;SESSION&#39; = -1, &#39;CREATED&#39; = 1, &#39;DELETED&#39; = 2, &#39;CHANGED&#39; = 3, &#39;CHILD&#39; = 4))](/ja/sql-reference/data-types/nullable)) — watch イベントの種類 (op&#95;num = Watch の応答の場合) 。それ以外の応答では NULL です。
* `watch_state` ([Nullable(Enum16(&#39;AUTH&#95;FAILED&#39; = -113, &#39;EXPIRED&#95;SESSION&#39; = -112, &#39;CONNECTING&#39; = 1, &#39;ASSOCIATING&#39; = 2, &#39;CONNECTED&#39; = 3, &#39;READONLY&#39; = 5, &#39;NOTCONNECTED&#39; = 999))](/ja/sql-reference/data-types/nullable)) — watch イベントの状態 (op&#95;num = Watch の応答の場合) 。それ以外の応答では NULL です。
* `path_created` ([String](/ja/sql-reference/data-types/string)) — 作成された ZooKeeper ノードのパス (CREATE リクエストへのレスポンスの場合) 。ノードが sequential として作成された場合は、このパスと異なることがあります。
* `stat_czxid` ([Int64](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードの作成を引き起こした変更の zxid。
* `stat_mzxid` ([Int64](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードを最後に変更した変更の zxid。
* `stat_pzxid` ([Int64](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードの子ノードを最後に変更した変更のトランザクション ID。
* `stat_version` ([Int32](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードのデータの変更回数。
* `stat_cversion` ([Int32](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードの子ノードの変更回数。
* `stat_dataLength` ([Int32](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードのデータ フィールドの長さ。
* `stat_numChildren` ([Int32](/ja/sql-reference/data-types/int-uint)) — この ZooKeeper ノードの子ノード数。
* `children` ([Array(String)](/ja/sql-reference/data-types/array)) — 子 ZooKeeper ノードの一覧 (LIST リクエストへのレスポンスの場合) 。

{/*AUTOGENERATED_END*/ }
