<div id="description">
  ## 説明
</div>

テーブル `system.errors` のエラー値の履歴が格納されており、定期的にディスクにフラッシュされます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行しているサーバーのホスト名。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — イベント日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — イベント時刻。
* `code` ([Int32](/ja/sql-reference/data-types/int-uint)) — エラーコード。
* `error` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — エラー名。
* `value` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 時間間隔内に発生したエラーの数。
* `remote` ([UInt8](/ja/sql-reference/data-types/int-uint)) — リモート例外 (つまり、分散クエリのいずれかで受信したもの) 。
* `last_error_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 最後にエラーが発生した時刻。
* `last_error_message` ([String](/ja/sql-reference/data-types/string)) — 最後のエラーのメッセージ。
* `last_error_query_id` ([String](/ja/sql-reference/data-types/string)) — 最後のエラーの原因となったクエリの ID (利用可能な場合) 。
* `last_error_trace` ([Array(UInt64)](/ja/sql-reference/data-types/array)) — 呼び出されたメソッドが格納されている物理アドレスの一覧を表すスタックトレース。

{/*AUTOGENERATED_END*/ }
