<div id="description">
  ## 説明
</div>

設定されたユーザーディレクトリ (ClickHouse server がユーザー指定のデータの読み取りを許可されている、ファイルシステム上のディレクトリ) に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — ディレクトリ名。
* `type` ([String](/ja/sql-reference/data-types/string)) — アクセスストレージの種類 (例: users.xml、replicated、memory など) 。
* `params` ([String](/ja/sql-reference/data-types/string)) — アクセスストレージのパラメーターを含む JSON。
* `precedence` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このディレクトリが config 内で宣言される順序です。ClickHouse がユーザーまたはロールを見つけようとする際にも、同じ順序が使用されます。

{/*AUTOGENERATED_END*/ }
