<div id="description">
  ## 説明
</div>

LibraryBridge のメモリに読み込まれている CatBoost モデルの一覧と、その読み込み時刻が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `model_path` ([String](/ja/sql-reference/data-types/string)) — 学習済みモデルへのパス。
* `type` ([String](/ja/sql-reference/data-types/string)) — モデルの種類。現在は catboost のみ。
* `loading_start_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — モデルの読み込みが開始された時刻。
* `loading_duration` ([Float32](/ja/sql-reference/data-types/float)) — モデルの読み込みにかかった時間。

{/*AUTOGENERATED_END*/ }
