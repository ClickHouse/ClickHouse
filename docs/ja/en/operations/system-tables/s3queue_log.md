S3Queueエンジンで処理されたファイルに関する情報を含むログエントリが格納されています。

このテーブルは、いつでも truncate や drop を行っても安全です。

カラム:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — ホスト名
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — このログ行が書き込まれたイベントの日付
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — このログ行が書き込まれたイベント時刻
* `database` ([String](/ja/sql-reference/data-types/string)) — キューテーブル (`S3Queue` または `AzureQueue`) が存在するデータベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — キューテーブル (`S3Queue` または `AzureQueue`) の名前。
* `uuid` ([String](/ja/sql-reference/data-types/string)) — キューテーブル (`S3Queue` または `AzureQueue`) の UUID。
* `file_name` ([String](/ja/sql-reference/data-types/string)) — 処理対象ファイルの名前。
* `rows_processed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 処理された行数。
* `status` ([Enum8(&#39;Processed&#39; = 0, &#39;Failed&#39; = 1)](/ja/sql-reference/data-types/enum)) — 処理対象ファイルのステータス。
* `processing_start_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — ファイルの処理開始時刻。
* `processing_end_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — ファイルの処理終了時刻。
* `exception` ([String](/ja/sql-reference/data-types/string)) — 発生した場合の例外メッセージ。
* `commit_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このファイルがコミットされたトランザクションの ID。
* `commit_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — Keeper でファイルがコミットされた時刻 (Failed または Processed のいずれかとして) 。
* `transaction_start_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 処理トランザクション全体が開始された時刻。
* `get_object_time_ms` ([UInt64](/ja/sql-reference/data-types/int-uint)) — オブジェクトストレージ内でオブジェクトを見つけるのにかかった時間。

{/*AUTOGENERATED_END*/ }
