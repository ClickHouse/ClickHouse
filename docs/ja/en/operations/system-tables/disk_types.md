<div id="description">
  ## 説明
</div>

サーバーでサポートされているディスクタイプの一覧と、各タイプの組み込みドキュメントが含まれています。ディスクタイプはディスク設定の `type` で指定され、ディスクがデータをどこにどのように保存するか (ローカルファイルシステム、オブジェクトストレージ、別のディスク上の cache など) を決定します。

このテーブルには利用可能なディスク*タイプ*が一覧表示されます。一方、[`system.disks`](/ja/operations/system-tables/disks) にはサーバーに設定されているディスクインスタンスが一覧表示されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — `ディスク設定` の `type` で指定される `ディスクタイプ` の名前。
* `description` ([String](/ja/sql-reference/data-types/string)) — その `ディスクタイプ` の概要説明。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — `ディスク設定` で `ディスクタイプ` をどのように指定するか。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — その `ディスクタイプ` が最初に導入された ClickHouse のバージョン。形式は major.minor です。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連する `ディスクタイプ` の名前。

{/*AUTOGENERATED_END*/ }

<div id="configuration-examples">
  ## 設定例
</div>

ディスクは 2 つの方法で設定できます。**静的**にはサーバー設定ファイル (XML または YAML) で、**動的**には `disk` 関数を使用する `CREATE`/`ATTACH` クエリの設定で行います。どちらの場合も、同じディスクタイプとパラメーターを使用できます。

<div id="static-configuration">
  ### 静的設定
</div>

ディスクは、サーバー設定内の `storage_configuration` で定義します。次の例では、`s3` ディスクと、それを使用するストレージポリシーを定義しています。

```xml title="config.xml"
<clickhouse>
    <storage_configuration>
        <disks>
            <s3_disk>
                <type>s3</type>
                <endpoint>https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/</endpoint>
                <use_environment_credentials>1</use_environment_credentials>
            </s3_disk>
        </disks>
        <policies>
            <s3_policy>
                <volumes>
                    <main>
                        <disk>s3_disk</disk>
                    </main>
                </volumes>
            </s3_policy>
        </policies>
    </storage_configuration>
</clickhouse>
```

同じ設定をYAMLで記述すると、次のとおりです:

```yaml title="config.yaml"
storage_configuration:
  disks:
    s3_disk:
      type: s3
      endpoint: https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/
      use_environment_credentials: 1
  policies:
    s3_policy:
      volumes:
        main:
          disk: s3_disk
```

テーブルは次に、ストレージポリシーを通じてこのディスクを使用できます：

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS storage_policy = 's3_policy';
```

<div id="dynamic-configuration">
  ### 動的設定
</div>

事前に設定ファイルでディスクを定義していなくても、`disk` 関数を使って、`CREATE`/`ATTACH` クエリの設定内でディスクを直接定義できます。

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS disk = disk(
    type = s3,
    endpoint = 'https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/',
    use_environment_credentials = 1
);
```

各ディスクタイプのパラメータ一覧については、[外部ストレージの設定](/ja/operations/storing-data)を参照してください。

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT name, description
FROM system.disk_types
WHERE name IN ('local', 'object_storage')
ORDER BY name
```
