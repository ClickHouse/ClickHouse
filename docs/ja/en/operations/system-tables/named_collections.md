<div id="description">
  ## 説明
</div>

SQLクエリで作成された、または設定ファイルから読み込まれた、すべての 名前付きコレクション の一覧が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — コレクション名。
* `collection` ([Map(String, String)](/ja/sql-reference/data-types/map)) — コレクションの内部情報。
* `source` ([String](/ja/sql-reference/data-types/string)) — 名前付きコレクションのソース。
* `create_query` ([String](/ja/sql-reference/data-types/string)) — 名前付きコレクションを作成するクエリ。

{/*AUTOGENERATED_END*/ }
