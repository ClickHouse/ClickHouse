<div id="description">
  ## 説明
</div>

[*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md) エンジンを使用するテーブルで用いられる [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite) パラメーターに関する情報です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/ja/sql-reference/data-types/string)) — graphite&#95;rollup の parameter 名。
* `rule_type` ([String](/ja/sql-reference/data-types/string)) — ルールの種類。設定可能な値: RuleTypeAll = 0 - デフォルト値。正規表現あり、旧認証スキームとの互換性あり; RuleTypePlain = 1 - プレーンなメトリクス。正規表現あり、旧認証スキームとの互換性あり; RuleTypeTagged = 2 - タグ付きメトリクス。正規表現あり、旧認証スキームとの互換性あり; RuleTypeTagList = 3 - タグ付きメトリクス。正規表現あり (&#39;retention=10min ; env=(staging|prod)&#39; のような文字列から RuleTypeTagged に変換)
* `regexp` ([String](/ja/sql-reference/data-types/string)) — メトリクス名のパターン。
* `function` ([String](/ja/sql-reference/data-types/string)) — 集約関数の名前。
* `age` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データの最小経過時間 (秒) 。
* `precision` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データの経過時間を秒単位でどの程度の精度で定義するか。
* `priority` ([UInt16](/ja/sql-reference/data-types/int-uint)) — パターンの優先度。
* `is_default` ([UInt8](/ja/sql-reference/data-types/int-uint)) — そのパターンがデフォルトかどうか。
* `Tables.database` ([Array(String)](/ja/sql-reference/data-types/array)) — `config_name` parameter を使用するデータベーステーブル名の Array。
* `Tables.table` ([Array(String)](/ja/sql-reference/data-types/array)) — `config_name` parameter を使用するテーブル名の Array。

{/*AUTOGENERATED_END*/ }
