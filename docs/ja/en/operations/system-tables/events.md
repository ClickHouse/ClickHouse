<div id="description">
  ## 説明
</div>

システム内で発生したイベント数に関する情報が含まれます。たとえば、このテーブルでは、ClickHouse server の起動後に処理された `SELECT` クエリの数を確認できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/ja/sql-reference/data-types/string)) — イベント名。
* `value` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 発生したイベントの数。
* `description` ([String](/ja/sql-reference/data-types/string)) — イベントの説明。

**別名:**

* `name` — `event` の別名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.events LIMIT 5
```
