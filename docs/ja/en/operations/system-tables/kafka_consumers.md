<div id="description">
  ## 説明
</div>

Kafkaコンシューマーに関する情報を含みます。
[Kafka テーブルエンジン](../../engines/table-engines/integrations/kafka) (ClickHouseネイティブインテグレーション) に適用されます

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — Kafka エンジンを持つテーブルのデータベース。
* `table` ([String](/ja/sql-reference/data-types/string)) — Kafka エンジンを持つテーブルの名前。
* `consumer_id` ([String](/ja/sql-reference/data-types/string)) — Kafka コンシューマーの識別子。1 つのテーブルに複数のコンシューマーを持つことができます。`kafka_num_consumers` パラメーターで指定します。
* `assignments.topic` ([Array(String)](/ja/sql-reference/data-types/array)) — Kafka トピック。
* `assignments.partition_id` ([Array(Int32)](/ja/sql-reference/data-types/array)) — Kafka パーティション ID。1 つのパーティションに割り当てられるコンシューマーは 1 つだけです。
* `assignments.current_offset` ([Array(Int64)](/ja/sql-reference/data-types/array)) — 現在のオフセット。
* `assignments.intent_size` ([Array(Nullable(Int64))](/ja/sql-reference/data-types/array)) — 新しい StorageKafka でプッシュ済みだが、まだコミットされていないメッセージ数。
* `exceptions.time` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — 直近 10 件の例外が生成された時刻のタイムスタンプ。
* `exceptions.text` ([Array(String)](/ja/sql-reference/data-types/array)) — 直近 10 件の例外のテキスト。
* `last_poll_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 直近のポーリングのタイムスタンプ。
* `num_messages_read` ([UInt64](/ja/sql-reference/data-types/int-uint)) — コンシューマーが読み取ったメッセージ数。
* `last_commit_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 直近のポーリングのタイムスタンプ。
* `num_commits` ([UInt64](/ja/sql-reference/data-types/int-uint)) — コンシューマーのコミット総数。
* `last_rebalance_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 直近の Kafka リバランスのタイムスタンプ。
* `num_rebalance_revocations` ([UInt64](/ja/sql-reference/data-types/int-uint)) — コンシューマーのパーティション割り当てが取り消された回数。
* `num_rebalance_assignments` ([UInt64](/ja/sql-reference/data-types/int-uint)) — コンシューマーが Kafka クラスターに割り当てられた回数。
* `is_currently_used` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコンシューマーが現在使用中かどうかを示すフラグ。
* `last_used` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — このコンシューマーが最後に使用された時刻。
* `rdkafka_stat` ([String](/ja/sql-reference/data-types/string)) — ライブラリ内部の統計情報。無効にするには statistics&#95;interval&#95;ms を 0 に設定します。デフォルトは 3000 (3 秒ごとに 1 回) です。
* `dependencies` ([Array(Array(String))](/ja/sql-reference/data-types/array)) — 推移的なデータベース依存関係。
* `missing_dependencies` ([Array(Array(String))](/ja/sql-reference/data-types/array)) — 欠落している推移的なデータベース依存関係。

{/*AUTOGENERATED_END*/ }
