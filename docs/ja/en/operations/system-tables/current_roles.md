<div id="description">
  ## 説明
</div>

現在のユーザーで有効になっているロールが含まれます。`SET ROLE` はこのテーブルの内容を変更します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/ja/sql-reference/data-types/string)) — ロール名。
* `with_admin_option` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ロールに ADMIN OPTION 権限がある場合は 1。
* `is_default` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ロールがデフォルトとして設定されている場合は 1。

{/*AUTOGENERATED_END*/ }
