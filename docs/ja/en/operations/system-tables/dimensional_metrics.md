<div id="description">
  ## 説明
</div>

このテーブルには、その場で計算でき、Prometheus フォーマットでエクスポート可能な次元メトリクスが含まれています。常に最新の状態です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/ja/sql-reference/data-types/string)) — メトリクス名。
* `value` ([Float64](/ja/sql-reference/data-types/float)) — メトリクスの値。
* `description` ([String](/ja/sql-reference/data-types/string)) — メトリクスの説明。
* `labels` ([Map(String, String)](/ja/sql-reference/data-types/map)) — メトリクスラベル。

**別名:**

* `name` — `metric` の別名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

このようなクエリを使用すると、すべての次元メトリクスをPrometheusフォーマットでエクスポートできます。

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## メトリクスの説明
</div>

<div id="merge_failures">
  ### merge_failures
</div>

起動以降の失敗したマージの総数。

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

エラーの種類ごとに起動スクリプトの失敗を示します。起動スクリプトが失敗すると 1 に設定され、エラー名のラベルが付与されます。

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

MergeTree データパートの数。パートの状態、パートの種類、およびプロジェクションパートかどうかを示すラベルごとに集計されます。

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの数。キャッシュ名ごとにラベル付けされます。デフォルトでは無効になっており、`expose_prometheus_eviction_metrics` で有効化できます。

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの総バイト数です。キャッシュ名ごとにラベル付けされます。デフォルトでは無効で、`expose_prometheus_eviction_metrics` で有効にできます。

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの数。cache 名とユーザー ID でラベル付けされます。デフォルトでは無効です。`expose_prometheus_eviction_metrics` と `expose_prometheus_eviction_metrics_per_user` で有効にします。

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの合計バイト数。cache 名とユーザー ID でラベル付けされます。デフォルトでは無効です。`expose_prometheus_eviction_metrics` と `expose_prometheus_eviction_metrics_per_user` で有効にできます。
