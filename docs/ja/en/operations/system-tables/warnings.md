<div id="description">
  ## 説明
</div>

clickhouse-client がサーバーに接続した直後に表示される、サーバー設定に関する警告が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `message` ([String](/ja/sql-reference/data-types/string)) — ClickHouse server によって出力される警告メッセージ。
* `message_format_string` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — メッセージの整形に使用されたフォーマット文字列。

{/*AUTOGENERATED_END*/ }
