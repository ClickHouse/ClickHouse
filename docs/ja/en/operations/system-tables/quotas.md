<div id="description">
  ## 説明
</div>

[クォータ](../../operations/system-tables/quotas.md) に関する情報が記載されています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — クォータ名。
* `id` ([UUID](/ja/sql-reference/data-types/uuid)) — クォータ ID。
* `storage` ([String](/ja/sql-reference/data-types/string)) — クォータの保存場所。取り得る値: users.xml ファイルでクォータが設定されている場合は &#39;users.xml&#39;、SQL クエリでクォータが設定されている場合は &#39;disk&#39;。
* `keys` ([Array(Enum8(&#39;user&#95;name&#39; = 1, &#39;ip&#95;address&#39; = 2, &#39;forwarded&#95;ip&#95;address&#39; = 3, &#39;client&#95;key&#39; = 4, &#39;normalized&#95;query&#95;hash&#39; = 7))](/ja/sql-reference/data-types/array)) — キーは、クォータをどのように共有するかを指定します。2 つの接続が同じクォータとキーを使用する場合、それらは同じ量のリソースを共有します。値: [] — すべてのユーザーが同じクォータを共有します、[&#39;user&#95;name&#39;] — 同じユーザー名の接続は同じクォータを共有します、[&#39;ip&#95;address&#39;] — 同じ IP からの接続は同じクォータを共有します、[&#39;client&#95;key&#39;] — 同じキーを持つ接続は同じクォータを共有します。キーはクライアントが明示的に指定する必要があります。clickhouse-client を使用する場合は、`--quota_key` パラメータにキーの値を渡すか、クライアントの設定ファイルで `quota_key` パラメータを使用します。HTTP インターフェイスを使用する場合は、`X-ClickHouse-Quota` ヘッダーを使用します、[&#39;user&#95;name&#39;, &#39;client&#95;key&#39;] — 同じ client&#95;key を持つ接続は同じクォータを共有します。クライアントがキーを指定しない場合、クォータは `user_name` ごとに追跡されます、[&#39;client&#95;key&#39;, &#39;ip&#95;address&#39;] — 同じ client&#95;key を持つ接続は同じクォータを共有します。クライアントがキーを指定しない場合、クォータは ip&#95;address ごとに追跡されます。
* `durations` ([Array(UInt32)](/ja/sql-reference/data-types/array)) — 秒単位の時間間隔の長さ。
* `apply_to_all` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 論理値。クォータがどのユーザーに適用されるかを示します。値: 0 — クォータは apply&#95;to&#95;list で指定されたユーザーに適用されます。1 — クォータは apply&#95;to&#95;except に列挙されたユーザーを除くすべてのユーザーに適用されます。
* `apply_to_list` ([Array(String)](/ja/sql-reference/data-types/array)) — クォータを適用するユーザー名/ロールの一覧。
* `apply_to_except` ([Array(String)](/ja/sql-reference/data-types/array)) — クォータを適用しないユーザー名/ロールの一覧。
* `ipv4_prefix_bits` ([Nullable(UInt8)](/ja/sql-reference/data-types/nullable)) — IPv4 address のマスキングに使用するプレフィックス bit 数。同じサブネットからの接続は同じクォータを共有します。key が `ip_address` または `forwarded_ip_address` の場合にのみ使用されます。
* `ipv6_prefix_bits` ([Nullable(UInt8)](/ja/sql-reference/data-types/nullable)) — IPv6 address のマスキングに使用するプレフィックス bit 数。同じサブネットからの接続は同じクォータを共有します。key が `ip_address` または `forwarded_ip_address` の場合にのみ使用されます。

{/*AUTOGENERATED_END*/ }
