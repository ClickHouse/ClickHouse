<div id="description">
  ## 説明
</div>

現在分片間を移動中のパーツと、その進捗に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — 移動が実行されるデータベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — 移動が実行されるテーブルの名前。
* `task_name` ([String](/ja/sql-reference/data-types/string)) — 移動タスクの名前。
* `task_uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — 移動タスクの識別子。
* `create_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — タスクが作成された時刻。
* `part_name` ([String](/ja/sql-reference/data-types/string)) — 移動処理中のパート名。
* `part_uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — 移動処理中のパートの UUID。
* `to_shard` ([String](/ja/sql-reference/data-types/string)) — 宛先分片の名前。
* `dst_part_name` ([String](/ja/sql-reference/data-types/string)) — 結果のパート名。
* `update_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 最後に更新が行われた時刻。
* `state` ([String](/ja/sql-reference/data-types/string)) — 移動の現在の状態。
* `rollback` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 操作がロールバックされたかどうかを示すフラグ。
* `num_tries` ([UInt32](/ja/sql-reference/data-types/int-uint)) — 操作を完了するまでの試行回数。
* `last_exception` ([String](/ja/sql-reference/data-types/string)) — 直近の例外名 (存在する場合) 。

{/*AUTOGENERATED_END*/ }
