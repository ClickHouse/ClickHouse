<div id="description">
  ## 説明
</div>

ローカルサーバー上に存在する[リソース](/ja/operations/workload-scheduling.md#workload_entity_storage)に関する情報を含みます。このテーブルには、各リソースに対して1行ずつ含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — リソースの名前。
* `read_disks` ([Array(String)](/ja/sql-reference/data-types/array)) — 読み取り操作でこのリソースを使用するディスク名の一覧。
* `write_disks` ([Array(String)](/ja/sql-reference/data-types/array)) — 書き込み操作でこのリソースを使用するディスク名の一覧。
* `unit` ([String](/ja/sql-reference/data-types/string)) — コスト測定に使用されるリソースの単位。
* `create_query` ([String](/ja/sql-reference/data-types/string)) — リソースの CREATE クエリ。

{/*AUTOGENERATED_END*/ }

例:

```sql
SELECT *
FROM system.resources
FORMAT Vertical
```

```text
Row 1:
──────
name:         io_read
read_disks:   ['s3']
write_disks:  []
create_query: CREATE RESOURCE io_read (READ DISK s3)

Row 2:
──────
name:         io_write
read_disks:   []
write_disks:  ['s3']
create_query: CREATE RESOURCE io_write (WRITE DISK s3)
```
