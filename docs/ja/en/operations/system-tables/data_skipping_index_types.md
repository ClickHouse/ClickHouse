<div id="description">
  ## 説明
</div>

サーバーでサポートされているデータスキッピングインデックスの索引タイプの一覧と、各索引タイプに埋め込まれたドキュメントが含まれます。データスキッピングインデックスの索引タイプは、`CREATE TABLE` クエリ内の `INDEX` 宣言の `TYPE` で指定します。これにより、ClickHouse はクエリの条件に一致しないグラニュールをスキップできます。

このテーブルには利用可能な*索引タイプ*が一覧表示されます。一方、[`system.data_skipping_indices`](/ja/operations/system-tables/data_skipping_indices) には、既存のテーブルに定義されている索引インスタンスが一覧表示されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — `INDEX` 宣言の `TYPE` で指定する、データスキッピングインデックスの型の名前。
* `description` ([String](/ja/sql-reference/data-types/string)) — このデータスキッピングインデックスの型の概要。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — `CREATE TABLE` クエリの `INDEX` 句で索引を宣言する方法。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — この索引タイプが最初に導入された ClickHouse のバージョン。形式は major.minor。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連するデータスキッピングインデックスの型の名前。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT name, syntax
FROM system.data_skipping_index_types
WHERE name IN ('minmax', 'set')
ORDER BY name
```

```text title="Response"
┌─name───┬─syntax───────────────────────────────────────┐
│ minmax │ INDEX name expr TYPE minmax GRANULARITY n     │
│ set    │ INDEX name expr TYPE set(max_rows) GRANULARITY n │
└────────┴──────────────────────────────────────────────┘
```
