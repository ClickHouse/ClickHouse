<div id="description">
  ## 説明
</div>

キュー内の保留中の非同期挿入に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/ja/sql-reference/data-types/string)) — クエリテキスト。
* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `format` ([String](/ja/sql-reference/data-types/string)) — フォーマット名。
* `first_update` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — 最初に insert された時刻 (マイクロ秒精度) 。
* `total_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — キューで待機中の合計バイト数。
* `entries.query_id` ([Array(String)](/ja/sql-reference/data-types/array)) — キューで待機中の inserts のクエリ ID を格納した Array。
* `entries.bytes` ([Array(UInt64)](/ja/sql-reference/data-types/array)) — キューで待機中の各 INSERT クエリのバイト数を格納した Array。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT * FROM system.asynchronous_inserts LIMIT 1 \G;
```

```text title="Response"
Row 1:
──────
query:            INSERT INTO public.data_guess (user_id, datasource_id, timestamp, path, type, num, str) FORMAT CSV
database:         public
table:            data_guess
format:           CSV
first_update:     2023-06-08 10:08:54.199606
total_bytes:      133223
entries.query_id: ['b46cd4c4-0269-4d0b-99f5-d27668c6102e']
entries.bytes:    [133223]
```
