<div id="description">
  ## 説明
</div>

ReplicatedMergeTree エンジン固有のすべての設定について、現在値、デフォルト値、および説明の一覧を示します。これらの設定は、CREATE クエリの SETTINGS セクションでいずれも変更できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — 設定名。
* `value` ([String](/ja/sql-reference/data-types/string)) — 設定の値。
* `default` ([String](/ja/sql-reference/data-types/string)) — 設定のデフォルト値。
* `changed` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 設定が config で明示的に定義されているか、明示的に変更されている場合は 1。
* `description` ([String](/ja/sql-reference/data-types/string)) — 設定の説明。
* `min` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 制約によって最小値が設定されている場合の、その値。設定に最小値がない場合は NULL が格納されます。
* `max` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 制約によって最大値が設定されている場合の、その値。設定に最大値がない場合は NULL が格納されます。
* `disallowed_values` ([Array(String)](/ja/sql-reference/data-types/array)) — 許可されない値の一覧
* `readonly` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 現在のユーザーがこの設定を変更できるかどうかを示します: 0 — 現在のユーザーはこの設定を変更できます。1 — 現在のユーザーはこの設定を変更できません。
* `type` ([String](/ja/sql-reference/data-types/string)) — 設定の型 (実装固有の文字列値) 。
* `is_obsolete` ([UInt8](/ja/sql-reference/data-types/int-uint)) — この設定が廃止されたものかどうかを示します。
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/ja/sql-reference/data-types/enum)) — この feature のサポートレベルです。ClickHouse の feature は tier ごとに分類されており、その
  開発状況や、利用時に期待できる内容に応じて異なります:
  * PRODUCTION: この feature は stable で、安全に使用でき、他の PRODUCTION feature と組み合わせても問題はありません。
  * BETA: この feature は stable で安全です。他の feature と組み合わせた場合の結果は不明であり、正しさは保証されません。テストと報告を歓迎します。
  * EXPERIMENTAL: この feature は開発中です。開発者と ClickHouse 愛好家のみを対象としています。この feature は動作する場合もあればしない場合もあり、いつでも削除される可能性があります。
  * OBSOLETE: すでにサポートされていません。すでに削除されているか、今後の releases で削除される予定です。

{/*AUTOGENERATED_END*/ }
