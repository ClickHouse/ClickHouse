<div id="description">
  ## 説明
</div>

サーバーでサポートされているテーブルエンジンの説明と、各機能のサポート状況に関する情報を含みます。

この表には、次のカラムが含まれます (カラム型は括弧内に示されています) :

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — テーブルエンジンの名前。
* `supports_settings` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンが SETTINGS 句をサポートしているかどうかを示すフラグ。
* `supports_skipping_indices` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンがスキッピングインデックスをサポートしているかどうかを示すフラグ。
* `supports_projections` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンがプロジェクションをサポートしているかどうかを示すフラグ。
* `supports_sort_order` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンが PARTITION&#95;BY、PRIMARY&#95;KEY、ORDER&#95;BY、SAMPLE&#95;BY の各句をサポートしているかどうかを示すフラグ。
* `supports_ttl` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンが有効期限 (TTL) をサポートしているかどうかを示すフラグ。
* `supports_replication` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンがデータのレプリケーションをサポートしているかどうかを示すフラグ。
* `supports_deduplication` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンがデータの重複排除をサポートしているかどうかを示すフラグ。
* `supports_parallel_insert` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルエンジンが並列 insert をサポートしているかどうかを示すフラグ (`max&#95;insert&#95;threads` setting を参照) 。
* `description` ([String](/ja/sql-reference/data-types/string)) — テーブルエンジンの動作内容の説明です。専用のドキュメントページがあるエンジンでは、そのページの Markdown 本文全体がここに含まれます。それ以外のエンジンでは、簡潔な要約が含まれます。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — テーブル作成時にそのテーブルエンジンをどのように使用するかを示します。ほとんどのエンジンでは、これは CREATE TABLE クエリの ENGINE 句ですが、一部のエンジン (各種 VIEW や Loop エンジンなど) は、CREATE VIEW や table function からの SELECT など、別の形式で使用されます。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — そのテーブルエンジンが最初に導入された ClickHouse のバージョンです。形式は major.minor です。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連するテーブルエンジンの名前。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT
    name,
    supports_settings,
    supports_skipping_indices,
    supports_sort_order,
    supports_ttl,
    supports_replication,
    supports_deduplication,
    supports_parallel_insert
FROM system.table_engines
WHERE name IN ('Kafka', 'MergeTree', 'ReplicatedCollapsingMergeTree')
```
