<div id="description">
  ## 説明
</div>

利用可能なすべてのトークナイザーを一覧表示します。
これらは、関数 [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens)、[hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens)、[hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens)、および [テキスト索引](../../engines/table-engines/mergetree-family/textindexes.md) で使用できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — トークナイザー名

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.tokenizers;
```

```text
┌─name────────────┐
│ ngrams          │
│ splitByNonAlpha │
│ sparseGrams     │
│ tokenbf_v1      │
│ ngrambf_v1      │
│ array           │
│ splitByString   │
│ sparse_grams    │
│ asciiCJK        │
└─────────────────┘
```
