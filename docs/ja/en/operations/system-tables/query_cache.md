<div id="description">
  ## 説明
</div>

[クエリキャッシュ](../query-cache.md) の内容を表示します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/ja/sql-reference/data-types/string)) — クエリ文字列。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — クエリの ID。
* `result_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — クエリキャッシュエントリのサイズ。
* `tag` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリキャッシュエントリのタグ。
* `stale` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリキャッシュエントリが古い状態かどうか。
* `shared` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリキャッシュエントリが複数のユーザー間で共有されているかどうか。
* `compressed` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリキャッシュエントリが圧縮されているかどうか。
* `expires_at` ([DateTime](/ja/sql-reference/data-types/datetime)) — クエリキャッシュエントリが古い状態になる時刻。
* `key_hash` ([UInt64](/ja/sql-reference/data-types/int-uint)) — クエリ文字列のハッシュ値で、クエリキャッシュエントリを見つけるためのキーとして使用されます。

{/*AUTOGENERATED_END*/ }
