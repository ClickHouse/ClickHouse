<div id="description">
  ## 説明
</div>

システム内の各種コンポーネントに関する埋め込みドキュメントを、1 つのテーブルに集約します。各行は 1 つのエンティティ (関数、テーブルエンジン、データ型など) に対応し、そのエンティティのリファレンスドキュメントを Markdown としてレンダリングした内容を含みます。これは、ウェブサイトで公開され、種類ごとの `system.*` システムテーブルで参照できるものと同じ内容です。

`description` は、埋め込みドキュメントの構造化された各部分 (`description`、`syntax`、引数、例など) から組み立てられるため、1 つのカラムにそのエンティティの完全なドキュメントが格納されます。エイリアスは、正規エンティティへの短い参照としてレンダリングされます。たとえば、``Alias of `trunc`.`` のようになります。

このテーブルは、ある意味では、種類ごとのドキュメントテーブル ([`system.functions`](/ja/operations/system-tables/functions)、[`system.table_engines`](/ja/operations/system-tables/table_engines)、[`system.data_type_families`](/ja/operations/system-tables/data_type_families) など) で利用できる情報を集約したものです。特に、クライアントの対話的な `help` コマンドを支えることを目的としていますが、それ単体でも有用です。

次の種類のエンティティが収集されます (括弧内は `type` カラムの値です) :

* 関数 (`Function`)
* 集約関数 (`Aggregate Function`)
* テーブル関数 (`Table Function`)
* テーブルエンジン (`Table Engine`)
* データベース エンジン (`Database Engine`)
* データ型 (`Data Type`)
* Dictionary layouts (`Dictionary Layout`)
* Dictionary sources (`Dictionary Source`)
* 集約関数コンビネータ (`Aggregate Function Combinator`)
* データスキッピングインデックスの型 (`Data Skipping Index`)
* ディスクタイプ (`Disk Type`)
* 設定 (`Setting`)
* MergeTree 設定 (`MergeTree Setting`)
* サーバー設定 (`Server Setting`)
* フォーマット (`Format`)
* 圧縮コーデック (`Compression Codec`)
* プロファイルイベント (`Profile Event`)
* 現在のメトリクス (`Current Metric`)
* 非同期メトリクス (`Asynchronous Metric`)
* システムテーブル (`System Table`)

設定 (種類を問わず) については、ドキュメントには設定の説明に加えて、その型とデフォルト値が含まれます。廃止された設定は公開されません。システムテーブルについては、ドキュメントにはテーブルコメントに加えて、そのカラム一覧 (各カラムの名前、型、説明) が含まれます。

`source` カラムには、そのエンティティのドキュメントが定義されているソースファイルのパスが、リポジトリルートからの相対パスで格納されます。大半のエンティティでは、ドキュメントオブジェクトが構築される場所 (コンポーネントの登録箇所) で自動的に取得されます。一方、種類ごとに 1 つのソースファイルで記述されているもの (設定、プロファイルイベント、現在のメトリクスなど) については、そのファイルが入ります。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — エンティティの名前です。たとえば `domainWithoutWWW` や `MergeTree` などがあります。
* `type` ([Enum8](/ja/sql-reference/data-types/enum)) — エンティティの種類です。たとえば `Function` や `Table Engine` などがあります。
* `description` ([String](/ja/sql-reference/data-types/string)) — Markdown としてレンダリングされる、エンティティのリファレンスドキュメントです。埋め込みドキュメント (Web サイトで公開されているものと同じ内容) をもとに構成されており、該当する場合は構文、例、そのほかの構造化された要素が含まれます。
* `source` ([String](/ja/sql-reference/data-types/string)) — エンティティのドキュメントが定義されているソースファイルへのパスです。リポジトリルートからの相対パスで、ソースの場所が不明な場合は空になります。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

特定のエンティティのドキュメントを参照する場合:

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

同じ名前が複数種類のエンティティを指すことがあります (たとえば、`file` table function と `file` Dictionary ソースの両方があります) 。そのため、すべての種類をまたいで名前を調べられると便利です。

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

種類ごとに、記載されているエンティティの数を数えます：

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
