<div id="description">
  ## 説明
</div>

このシステムテーブルには、ClickHouse に存在する Iceberg テーブルのファイルごとのメタデータが格納されます。各テーブルの現在のスナップショットによって参照されるデータファイルまたは削除ファイルごとに 1 行が対応します。ClickHouse に Iceberg テーブルが 1 つも存在しない場合、このテーブルは空になります。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `snapshot_id` ([Int64](/ja/sql-reference/data-types/int-uint)) — ファイルが追加された時点のスナップショット ID。
* `content` ([Enum8](/ja/sql-reference/data-types/enum)) — ファイルコンテンツの種類: `DATA`、`POSITION_DELETE`、または `EQUALITY_DELETE`。
* `file_path` ([String](/ja/sql-reference/data-types/string)) — ファイルの解決済みストレージパス。
* `file_format` ([String](/ja/sql-reference/data-types/string)) — ファイルフォーマット。例: `'PARQUET'`。
* `record_count` ([Int64](/ja/sql-reference/data-types/int-uint)) — ファイル内のレコード数。
* `file_size_in_bytes` ([Int64](/ja/sql-reference/data-types/int-uint)) — ファイルサイズ (バイト単位) 。
* `partition` ([String](/ja/sql-reference/data-types/string)) — パーティションタプルのテキスト表現。
* `schema_id` ([Int32](/ja/sql-reference/data-types/int-uint)) — このマニフェストエントリに対して解決されたスキーマ ID。
* `sequence_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マニフェストエントリの解決済みシーケンス番号 (フォーマット v1 では常に 0) 。
* `sort_order_id` ([Nullable(Int32)](/ja/sql-reference/data-types/nullable)) — 指定されている場合のファイルのソート順 ID。
* `null_value_counts` ([Map(Int32, Int64)](/ja/sql-reference/data-types/map)) — カラムごとの NULL 値の数 (column id -&gt; count) 。
* `column_sizes` ([Map(Int32, Int64)](/ja/sql-reference/data-types/map)) — カラムごとのディスク上のサイズ (バイト単位)  (column id -&gt; bytes) 。
* `value_counts` ([Map(Int32, Int64)](/ja/sql-reference/data-types/map)) — カラムごとの値の総数 (column id -&gt; count) 。
* `equality_ids` ([Array(Int32)](/ja/sql-reference/data-types/array)) — equality delete ファイルの等価性フィールド ID (equality delete 以外のファイルでは空) 。
