<div id="description">
  ## 説明
</div>

サーバーに設定されている[ユーザーアカウント](../../guides/sre/user-management/index.md#user-account-management)の一覧です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — ユーザー名。
* `id` ([UUID](/ja/sql-reference/data-types/uuid)) — ユーザー ID。
* `storage` ([String](/ja/sql-reference/data-types/string)) — ユーザーのストレージへのパス。`access_control_path` パラメータで設定されます。
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/ja/sql-reference/data-types/array)) — authentication の種類を表示します。ユーザーを識別する方法には、パスワードなし、平文パスワード、SHA256 でエンコードされたパスワード、二重 SHA-1 でエンコードされたパスワード、bcrypt でエンコードされたパスワードなど、複数あります。
* `auth_params` ([Array(String)](/ja/sql-reference/data-types/array)) — `auth_type` に応じた JSON フォーマットの authentication parameter。
* `valid_until` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — ユーザー credentials の有効期限となる日付と時刻。
* `host_ip` ([Array(String)](/ja/sql-reference/data-types/array)) — ClickHouse server への接続が許可されているホストの IP アドレス。
* `host_names` ([Array(String)](/ja/sql-reference/data-types/array)) — ClickHouse server への接続が許可されているホスト名。
* `host_names_regexp` ([Array(String)](/ja/sql-reference/data-types/array)) — ClickHouse server への接続が許可されているホスト名の regular expression。
* `host_names_like` ([Array(String)](/ja/sql-reference/data-types/array)) — LIKE predicate を使用して設定された、ClickHouse server への接続が許可されているホスト名。
* `default_roles_all` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ユーザーに付与されたすべての granted ロール がデフォルトで設定されていることを示します。
* `default_roles_list` ([Array(String)](/ja/sql-reference/data-types/array)) — デフォルトで提供される granted ロール の一覧。
* `default_roles_except` ([Array(String)](/ja/sql-reference/data-types/array)) — 一覧に含まれるものを除き、付与されたすべてのロールがデフォルトとして設定されます。
* `grantees_any` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 何らかの grant options を持つユーザーが、それを誰にでも付与できるかどうかを示すフラグ。
* `grantees_list` ([Array(String)](/ja/sql-reference/data-types/array)) — このユーザーが options を付与できるユーザーまたはロールの一覧。
* `grantees_except` ([Array(String)](/ja/sql-reference/data-types/array)) — このユーザーが options を付与することを禁止されているユーザーまたはロールの一覧。
* `default_database` ([String](/ja/sql-reference/data-types/string)) — このユーザーの default database の名前。

{/*AUTOGENERATED_END*/ }
