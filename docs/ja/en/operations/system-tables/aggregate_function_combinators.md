<div id="description">
  ## 説明
</div>

使用可能なすべての集約関数コンビネータの一覧です。これらは集約関数に適用でき、動作を変更します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — コンビネータの名前。
* `is_internal` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコンビネータが内部用途専用かどうか。

{/*AUTOGENERATED_END*/ }
