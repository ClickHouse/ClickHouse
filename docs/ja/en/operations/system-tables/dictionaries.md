  ## 説明

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — DDL query によって作成された Dictionary を含むデータベース名。その他の Dictionary では空文字列です。
* `name` ([String](/ja/sql-reference/data-types/string)) — Dictionary 名。
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — Dictionary の UUID。
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/ja/sql-reference/data-types/enum)) — Dictionary のステータス。設定可能な値: NOT&#95;LOADED — 使用されていないため Dictionary はロードされていません、LOADED — Dictionary は正常にロードされました、FAILED — エラーにより Dictionary をロードできませんでした、LOADING — Dictionary は現在ロード中です、LOADED&#95;AND&#95;RELOADING — Dictionary は正常にロードされており、現在再ロード中です (よくある理由: SYSTEM RELOAD DICTIONARY クエリ、timeout、dictionary config の変更) 、FAILED&#95;AND&#95;RELOADING — エラーにより Dictionary をロードできず、現在再ロード中です。
* `origin` ([String](/ja/sql-reference/data-types/string)) — Dictionary を記述した configuration file へのパス。
* `type` ([String](/ja/sql-reference/data-types/string)) — Dictionary の割り当てタイプ。Dictionary のメモリ内での格納方法を示します。
* `key.names` ([Array(String)](/ja/sql-reference/data-types/array)) — Dictionary が提供するキー名の Array。
* `key.types` ([Array(String)](/ja/sql-reference/data-types/array)) — Dictionary が提供するキー type の対応する Array。
* `attribute.names` ([Array(String)](/ja/sql-reference/data-types/array)) — Dictionary が提供する attribute 名の Array。
* `attribute.types` ([Array(String)](/ja/sql-reference/data-types/array)) — Dictionary が提供する attribute type の対応する Array。
* `bytes_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — Dictionary に割り当てられている RAM 量。
* `hierarchical_index_bytes_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 階層索引に割り当てられている RAM 量。
* `query_count` ([UInt64](/ja/sql-reference/data-types/int-uint)) — Dictionary のロード後、または最後の正常な再起動以降のクエリ数。
* `hit_rate` ([Float64](/ja/sql-reference/data-types/float)) — cache Dictionary において、値が cache に存在していたアクセスの割合。
* `found_rate` ([Float64](/ja/sql-reference/data-types/float)) — 値が見つかったアクセスの割合。
* `element_count` ([UInt64](/ja/sql-reference/data-types/int-uint)) — Dictionary に格納されている項目数。
* `load_factor` ([Float64](/ja/sql-reference/data-types/float)) — Dictionary の充填率 (ハッシュ化された Dictionary の場合は、hash table の充填率) 。
* `source` ([String](/ja/sql-reference/data-types/string)) — Dictionary のデータソースを説明するテキスト。
* `lifetime_min` ([UInt64](/ja/sql-reference/data-types/int-uint)) — メモリ内の Dictionary の最小 lifetime。この時間を過ぎると、ClickHouse は Dictionary の再ロードを試みます (`invalidate_query` が設定されている場合は、変更があったときのみ) 。単位は seconds です。
* `lifetime_max` ([UInt64](/ja/sql-reference/data-types/int-uint)) — メモリ内の Dictionary の最大 lifetime。この時間を過ぎると、ClickHouse は Dictionary の再ロードを試みます (`invalidate_query` が設定されている場合は、変更があったときのみ) 。単位は seconds です。
* `loading_start_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — Dictionary のロード開始時刻。
* `last_successful_update_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — Dictionary のロードまたは更新の完了時刻。Dictionary ソースに関する問題の監視や、原因の調査に役立ちます。
* `error_count` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 最後に正常にロードされて以降の error 数。Dictionary ソースに関する問題の監視や、原因の調査に役立ちます。
* `loading_duration` ([Float32](/ja/sql-reference/data-types/float)) — Dictionary のロード時間。
* `last_exception` ([String](/ja/sql-reference/data-types/string)) — Dictionary を作成できなかった場合に、作成時または再ロード時に発生した error の内容。
* `comment` ([String](/ja/sql-reference/data-types/string)) — Dictionary に対する comment の内容。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

Dictionaryを設定します:

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

Dictionaryが読み込まれていることを確認してください。

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
