<div id="description">
  ## 説明
</div>

利用可能な証明書と、その入手元に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `version` ([Int32](/ja/sql-reference/data-types/int-uint)) — 証明書のバージョン。値は、v1 が 0、v2 が 1、v3 が 2 です。
* `serial_number` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 発行者によって割り当てられた証明書のシリアル番号。
* `signature_algo` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 署名アルゴリズム。この証明書への署名に発行者が使用するアルゴリズムです。
* `issuer` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 発行者。この証明書を発行する認証局を一意に識別する識別子です。
* `not_before` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — この証明書が有効となる期間の開始時刻。
* `not_after` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — この証明書が有効となる期間の終了時刻。
* `subject` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — サブジェクト。公開鍵の所有者を識別します。
* `pkey_algo` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 公開鍵アルゴリズム。公開鍵に使用できるアルゴリズムを定義します。
* `path` ([String](/ja/sql-reference/data-types/string)) — この証明書を含むファイルまたはディレクトリへのパス。
* `default` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 証明書がデフォルトの証明書格納場所にあります。
* `protocol` ([String](/ja/sql-reference/data-types/string)) — 証明書がプロトコルごとの TLS 設定に由来する場合はプロトコル名、それ以外の場合は空です。

{/*AUTOGENERATED_END*/ }
