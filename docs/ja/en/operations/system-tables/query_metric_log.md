<div id="description">
  ## 説明
</div>

個々のクエリについて、`system.events` テーブルのメモリ使用量とメトリクス値の履歴が記録され、定期的にディスクにフラッシュされます。

クエリが開始されると、`query_metric_log_interval` ミリ秒ごと (既定では 1000
に設定) にデータが収集されます。クエリの実行時間が `query_metric_log_interval` を超える場合は、クエリの終了時にもデータが収集されます。
