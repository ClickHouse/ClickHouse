<div id="description">
  ## 説明
</div>

設定済みの設定プロファイルのプロパティが含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — 設定プロファイル名。
* `id` ([UUID](/ja/sql-reference/data-types/uuid)) — 設定プロファイルの ID。
* `storage` ([String](/ja/sql-reference/data-types/string)) — 設定プロファイルの保存先へのパス。`access_control_path` パラメータで設定します。
* `num_elements` ([UInt64](/ja/sql-reference/data-types/int-uint)) — `system.settings_profile_elements` テーブル内にある、このプロファイルの要素数。
* `apply_to_all` ([UInt8](/ja/sql-reference/data-types/int-uint)) — この設定プロファイルがすべてのロールおよび/またはユーザーに設定されていることを示します。
* `apply_to_list` ([Array(String)](/ja/sql-reference/data-types/array)) — この設定プロファイルが適用されるロールおよび/またはユーザーの一覧。
* `apply_to_except` ([Array(String)](/ja/sql-reference/data-types/array)) — 一覧に含まれるものを除く、すべてのロールおよび/またはユーザーにこの設定プロファイルが適用されます。

{/*AUTOGENERATED_END*/ }
