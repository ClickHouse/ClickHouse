<div id="description">
  ## 説明
</div>

すべてのテーブルに存在するデータスキッピングインデックスに関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `name` ([String](/ja/sql-reference/data-types/string)) — 索引名。
* `type` ([String](/ja/sql-reference/data-types/string)) — 索引タイプ。
* `type_full` ([String](/ja/sql-reference/data-types/string)) — CREATEステートメント内の索引タイプ式。
* `expr` ([String](/ja/sql-reference/data-types/string)) — 索引の計算に使用される式。
* `creation` ([Enum8(&#39;Explicit&#39; = 0, &#39;Implicit&#39; = 1)](/ja/sql-reference/data-types/enum)) — 索引が暗黙的に作成されたかどうか (`add_minmax_index_for_numeric_columns` などによる)
* `granularity` ([UInt64](/ja/sql-reference/data-types/int-uint)) — block 内のグラニュール数。
* `data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 圧縮データのサイズ (バイト単位) 。
* `data_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 非圧縮データのサイズ (バイト単位) 。
* `marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マークのサイズ (バイト単位) 。

{/*AUTOGENERATED_END*/ }
