<div id="description">
  ## 説明
</div>

リモートオブジェクト向けのファイルシステムキャッシュ内にあるすべてのエントリの情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `cache_name` ([String](/ja/sql-reference/data-types/string)) — キャッシュオブジェクトの名前。`SYSTEM DESCRIBE FILESYSTEM CACHE <name>`、`SYSTEM DROP FILESYSTEM CACHE <name>` コマンドで使用できます
* `cache_base_path` ([String](/ja/sql-reference/data-types/string)) — すべてのキャッシュファイル (`cache_name` で識別されるキャッシュ) が保存されるベースディレクトリのパス。
* `cache_path` ([String](/ja/sql-reference/data-types/string)) — ソースファイル内のファイルセグメントに対応する、特定のキャッシュファイルのパス
* `key` ([String](/ja/sql-reference/data-types/string)) — ファイルセグメントのキャッシュキー
* `file_segment_range_begin` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ファイルセグメント範囲の開始位置に対応するオフセット
* `file_segment_range_end` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ファイルセグメント範囲の終了位置 (終端を含む) に対応するオフセット
* `size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ファイルセグメントのサイズ
* `state` ([String](/ja/sql-reference/data-types/string)) — ファイルセグメントの状態 (DOWNLOADED、DOWNLOADING、PARTIALLY&#95;DOWNLOADED、...)
* `finished_download_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — ファイルセグメントのダウンロードが完了した時刻。
* `cache_hits` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 対応するファイルセグメントのキャッシュヒット数
* `references` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 対応するファイルセグメントへの参照数。値が 1 の場合、現時点ではどこからも使用されていません (存在する唯一の参照はキャッシュストレージ自体のものです)
* `downloaded_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ファイルセグメントのダウンロード済みサイズ
* `kind` ([String](/ja/sql-reference/data-types/string)) — ファイルセグメントの種類 (&#39;Temporary data in cache&#39; の一部として追加されたファイルセグメントを区別するために使用されます)
* `unbound` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 内部実装用のフラグ
* `user_id` ([String](/ja/sql-reference/data-types/string)) — ファイルセグメントを作成したユーザーの ID
* `segment_type` ([String](/ja/sql-reference/data-types/string)) — セグメントの種類。データファイル (`.json`、`.txt` など) とデータファイル (`.bin`、mark file) を区別するために使用されます。
* `file_size` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在のファイルセグメントが属するファイルのサイズ

{/*AUTOGENERATED_END*/ }
