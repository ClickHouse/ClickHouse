<div id="description">
  ## 説明
</div>

ローカルサーバー上に存在する[スケジューリングノード](/ja/operations/workload-scheduling.md/#hierarchy)の情報と状態が含まれます。
このテーブルは監視に使用できます。このテーブルには、各スケジューリングノードに対して 1 行が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `resource` ([String](/ja/sql-reference/data-types/string)) — リソース名
* `path` ([String](/ja/sql-reference/data-types/string)) — このリソーススケジューリング階層内にあるスケジューリングノードのパス
* `type` ([String](/ja/sql-reference/data-types/string)) — スケジューリングノードの種類。
* `weight` ([Float64](/ja/sql-reference/data-types/float)) — ノードの重み。`fair` 型の親ノードで使用されます。
* `priority` ([Int64](/ja/sql-reference/data-types/int-uint)) — ノードの優先度。&#39;priority&#39; 型の親ノードで使用されます (値が小さいほど優先度が高くなります) 。
* `is_active` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このノードが現在アクティブかどうか。つまり、デキュー対象のリソースリクエストがあり、制約が満たされている状態かどうかを示します。
* `active_children` ([UInt64](/ja/sql-reference/data-types/int-uint)) — アクティブな状態にある子の数。
* `dequeued_requests` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このノードからデキューされたリソースリクエストの総数。
* `canceled_requests` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このノードからキャンセルされたリソースリクエストの総数。
* `dequeued_cost` ([Int64](/ja/sql-reference/data-types/int-uint)) — このノードからデキューされたすべてのリクエストのコスト (例: バイト単位のサイズ) の合計。
* `throughput` ([Float64](/ja/sql-reference/data-types/float)) — 現在の平均スループット (1 秒あたりのデキュー済みコスト) 。
* `canceled_cost` ([Int64](/ja/sql-reference/data-types/int-uint)) — このノードからキャンセルされたすべてのリクエストのコスト (例: バイト単位のサイズ) の合計。
* `busy_periods` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このノードが非アクティブ化された総回数。
* `vruntime` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — `fair` ノードの子にのみ適用されます。SFQ アルゴリズムが max-min 公平方式で次に処理する子を選択するために使用するノードの仮想ランタイムです。
* `system_vruntime` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — `fair` ノードにのみ適用されます。最後に処理されたリソースリクエストの `vruntime` を示す仮想ランタイムです。子のアクティブ化時に、新しい `vruntime` の値として使用されます。
* `queue_length` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — `fifo` ノードにのみ適用されます。現在キュー内にあるリソースリクエストの数。
* `queue_cost` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — fifo ノードにのみ適用されます。キュー内にあるすべてのリクエストのコスト (例: バイト単位のサイズ) の合計。
* `budget` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — fifo ノードにのみ適用されます。新しいリソースリクエストに使用できる &#39;コスト単位&#39; の数です。リソースリクエストの見積もりコストと実コストに差異がある場合 (例: 読み取り/書き込みの失敗後) に現れることがあります。
* `is_satisfied` ([Nullable(UInt8)](/ja/sql-reference/data-types/nullable)) — 制約ノードにのみ適用されます (例: `inflight_limit`) 。このノードのすべての制約が満たされている場合は `1` になります。
* `inflight_requests` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — `inflight_limit` ノードにのみ適用されます。このノードからデキューされ、現在処理中のリソースリクエストの数。
* `inflight_cost` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — `inflight_limit` ノードにのみ適用されます。このノードからデキューされ、現在処理中のすべてのリソースリクエストのコスト (例: バイト数) の合計。
* `max_requests` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — `inflight_limit` ノードにのみ適用されます。制約違反の原因となる inflight&#95;requests の上限。
* `max_cost` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — `inflight_limit` ノードにのみ適用されます。制約違反の原因となる inflight&#95;cost の上限。
* `max_speed` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — `bandwidth_limit` ノードにのみ適用されます。1 秒あたりのトークン数で表した帯域幅の上限。
* `max_burst` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — `bandwidth_limit` ノードにのみ適用されます。トークンバケットスロットラーで使用可能なトークン数の上限。
* `throttling_us` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — `bandwidth_limit` ノードのみ。 このノードがスロットリング状態にあった合計時間 (マイクロ秒) 。
* `tokens` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — `bandwidth_limit` ノードのみ。トークンバケット スロットラーで現在使用可能なトークン数。

{/*AUTOGENERATED_END*/ }

```sql
SELECT *
FROM system.scheduler
WHERE resource = 'network_read' AND path = '/prio/fair/prod'
FORMAT Vertical
```
