<div id="description">
  ## 説明
</div>

サーバーがサポートするデータベースエンジンの一覧です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — データベースエンジンの名前。
* `description` ([String](/ja/sql-reference/data-types/string)) — そのデータベースエンジンの役割の概要。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — CREATE DATABASEクエリのENGINE句でデータベースエンジンをどのように指定するか。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — そのデータベースエンジンが最初に導入されたClickHouseのバージョン (major.minor形式) 。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連するデータベースエンジンの名前。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

│ Atomic   │
