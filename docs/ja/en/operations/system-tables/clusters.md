<div id="description">
  ## 説明
</div>

設定ファイルで利用可能なクラスターと、それらに含まれるサーバーに関する情報です。

<div id="Columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `cluster` ([String](/ja/sql-reference/data-types/string)) — クラスター名。
* `shard_num` ([UInt32](/ja/sql-reference/data-types/int-uint)) — クラスター内の分片番号。1 から始まります。
* `shard_name` ([String](/ja/sql-reference/data-types/string)) — クラスター内の分片名。
* `shard_weight` ([UInt32](/ja/sql-reference/data-types/int-uint)) — データ書き込み時の分片の相対的な重み。
* `internal_replication` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このホストが、データを自力でレプリケートできる構成の一部であるかどうかを示すフラグ。
* `replica_num` ([UInt32](/ja/sql-reference/data-types/int-uint)) — 分片内のレプリカ番号。1 から始まります。
* `host_name` ([String](/ja/sql-reference/data-types/string)) — config で指定された host name。
* `host_address` ([String](/ja/sql-reference/data-types/string)) — DNS から取得されたホストの IP アドレス。
* `port` ([UInt16](/ja/sql-reference/data-types/int-uint)) — サーバーへの接続に使用するポート。
* `is_local` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ホストがローカルであるかどうかを示すフラグ。
* `user` ([String](/ja/sql-reference/data-types/string)) — サーバーへの接続に使用するユーザー名。
* `default_database` ([String](/ja/sql-reference/data-types/string)) — default database 名。
* `errors_count` ([UInt32](/ja/sql-reference/data-types/int-uint)) — このホストからレプリカへの到達に失敗した回数。
* `slowdowns_count` ([UInt32](/ja/sql-reference/data-types/int-uint)) — hedged requests で connection を確立する際に、レプリカの切り替えにつながった遅延の回数。
* `estimated_recovery_time` ([UInt32](/ja/sql-reference/data-types/int-uint)) — レプリカの error 回数が 0 にリセットされ、正常な状態に戻ったとみなされるまでの残り Seconds。
* `database_shard_name` ([String](/ja/sql-reference/data-types/string)) — `Replicated` database の分片名 (`Replicated` database に属するクラスターの場合) 。
* `database_replica_name` ([String](/ja/sql-reference/data-types/string)) — `Replicated` database のレプリカ名 (`Replicated` database に属するクラスターの場合) 。
* `is_shared_catalog_cluster` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クラスターが Shared Catalog に属しているかどうかを示す Bool。
* `is_active` ([Nullable(UInt8)](/ja/sql-reference/data-types/nullable)) — Replicated database レプリカの status (Replicated database に属するクラスターの場合) 。1 は &#39;レプリカはオンライン&#39;、0 は &#39;レプリカはオフライン&#39;、NULL は &#39;不明&#39; を意味します。
* `unsynced_after_recovery` ([Nullable(UInt8)](/ja/sql-reference/data-types/nullable)) — Replicated database レプリカの作成後または復旧後に、そのレプリカのレプリケーションラグが max&#95;replication&#95;lag&#95;to&#95;enqueue を超えているかどうかを示します。
* `replication_lag` ([Nullable(UInt32)](/ja/sql-reference/data-types/nullable)) — `Replicated` database レプリカのレプリケーションラグ (Replicated database に属するクラスターの場合) 。
* `recovery_time` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — `Replicated` database レプリカの復旧時間 (Replicated database に属するクラスターの場合) 。単位は Milliseconds です。

**別名:**

* `name` — `cluster` の別名。

{/*AUTOGENERATED_END*/ }
