現在のサーバーで実行されたすべてのトランザクションに関する情報が格納されています。

このテーブルは、いつでも truncate または drop しても安全です。

カラム:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — トランザクションが実行されたホストのホスト名。
* `type` ([Enum8(&#39;Begin&#39; = 1, &#39;Commit&#39; = 2, &#39;Rollback&#39; = 3, &#39;AddPart&#39; = 10, &#39;LockPart&#39; = 11, &#39;UnlockPart&#39; = 12)](/ja/sql-reference/data-types/enum)) — トランザクションの種類。設定可能な値: Begin, Commit, Rollback, AddPart, LockPart, UnlockPart。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — エントリの日付。
* `event_time` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — エントリの時刻
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — スレッドの識別子。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — トランザクションのスコープ内で実行されたクエリの ID。
* `tid` ([Tuple(UInt64, UInt64, UUID)](/ja/sql-reference/data-types/tuple)) — トランザクションの識別子。
* `tid_hash` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 識別子のハッシュ。
* `csn` ([UInt64](/ja/sql-reference/data-types/int-uint)) — Commit Sequence Number
* `database` ([String](/ja/sql-reference/data-types/string)) — トランザクションが実行されたデータベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — トランザクションが実行されたテーブルの名前。
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — トランザクションが実行されたテーブルの UUID。
* `part` ([String](/ja/sql-reference/data-types/string)) — トランザクションに含まれる part の名前。

{/*AUTOGENERATED_END*/ }
