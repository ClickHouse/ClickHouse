<div id="description">
  ## 説明
</div>

クエリを実行するスレッドに関する情報が含まれます。たとえば、スレッド名、スレッド開始時刻、クエリ処理時間などです。

ロギングを開始するには:

1. [query&#95;thread&#95;log](/ja/operations/server-configuration-parameters/settings#query_thread_log) セクションでパラメーターを設定します。
2. [log&#95;query&#95;threads](/ja/operations/settings/settings#log_query_threads) を 1 に設定します。

データのフラッシュ間隔は、[query&#95;thread&#95;log](/ja/operations/server-configuration-parameters/settings#query_thread_log) サーバー設定セクションの `flush_interval_milliseconds` パラメーターで設定します。フラッシュを強制実行するには、[SYSTEM FLUSH LOGS](/ja/sql-reference/statements/system#flush-logs) クエリを使用します。

ClickHouse はテーブルからデータを自動的に削除しません。詳細については、[Introduction](/ja/operations/system-tables/overview#system-tables-introduction) を参照してください。

`query_thread_log` テーブルに記録されるクエリの数を減らすには、[log&#95;queries&#95;probability](/ja/operations/settings/settings#log_queries_probability)) 設定を使用できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行しているサーバーのホスト名。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — スレッドがクエリの実行を完了した日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — スレッドがクエリの実行を完了した日時。
* `event_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — スレッドがクエリの実行を完了した日時 (マイクロ秒精度) 。
* `query_start_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — クエリ実行の開始時刻。
* `query_start_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — クエリ実行の開始時刻 (マイクロ秒精度) 。
* `query_duration_ms` ([UInt64](/ja/sql-reference/data-types/int-uint)) — クエリ実行時間。
* `read_rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 読み取られた行数。
* `read_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 読み取られたバイト数。
* `written_rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — INSERT クエリでは書き込まれた行数。それ以外のクエリでは、このカラムの値は 0 です。
* `written_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — INSERT クエリでは書き込まれたバイト数。それ以外のクエリでは、このカラムの値は 0 です。
* `memory_usage` ([Int64](/ja/sql-reference/data-types/int-uint)) — このスレッドのコンテキストにおける、割り当てられたメモリ量と解放されたメモリ量の差。
* `peak_memory_usage` ([Int64](/ja/sql-reference/data-types/int-uint)) — このスレッドのコンテキストにおける、割り当てられたメモリ量と解放されたメモリ量の最大差。
* `thread_name` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — スレッド名。
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 内部スレッド ID。
* `master_thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 初期スレッドの OS 上の ID。
* `current_database` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 現在のデータベース名。
* `query` ([String](/ja/sql-reference/data-types/string)) — クエリ文字列。
* `normalized_query_hash` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 正規化クエリのハッシュ。定数などを除去したものです。
* `is_initial_query` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリタイプ。設定可能な値: 1 — クライアントによって開始されたクエリ、0 — 分散クエリ実行のために別のクエリによって開始されたクエリ。
* `connection_address` ([IPv6](/ja/sql-reference/data-types/ipv6)) — 接続元クライアントの IP アドレス。プロキシ経由で接続した場合、これはプロキシのアドレスになります。
* `connection_port` ([UInt16](/ja/sql-reference/data-types/int-uint)) — 接続元クライアントのポート。プロキシ経由で接続した場合、これはプロキシのポートになります。
* `user` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 現在のクエリを開始したユーザー名。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — クエリの ID。
* `address` ([IPv6](/ja/sql-reference/data-types/ipv6)) — クエリの実行に使用された IP アドレス。プロキシ経由で接続し、`auth_use_forwarded_address` が設定されている場合、これはプロキシではなくクライアントのアドレスになります。
* `port` ([UInt16](/ja/sql-reference/data-types/int-uint)) — クエリの実行に使用されたクライアントのポート。プロキシ経由で接続され、`auth_use_forwarded_address` が設定されている場合、これはプロキシではなくクライアントのポートになります。
* `initial_user` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 初期クエリを実行したユーザー名 (distributed query execution 用) 。
* `initial_query_id` ([String](/ja/sql-reference/data-types/string)) — 初期クエリの ID (distributed query execution 用) 。
* `initial_address` ([IPv6](/ja/sql-reference/data-types/ipv6)) — 親クエリの起点となった IP アドレス。
* `initial_port` ([UInt16](/ja/sql-reference/data-types/int-uint)) — 親クエリの実行に使用されたクライアントのポート。
* `initial_query_start_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 初期クエリ実行の開始時刻。
* `initial_query_start_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — 初期クエリ実行の開始時刻
* `authenticated_user` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — セッションで認証されたユーザー名。
* `interface` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリの開始元となったインターフェイス。設定可能な値: 1 — TCP、2 — HTTP。
* `is_secure` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 接続がセキュアかどうかを示すフラグ。
* `os_user` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — `clickhouse-client` を実行している OS ユーザー名。
* `client_hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — `clickhouse-client` または別の TCP クライアントを実行しているクライアントマシンのホスト名。
* `client_name` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — `clickhouse-client` または別の TCP クライアントの名前。
* `client_agent` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 環境変数から検出された、クライアントを呼び出した AI コーディング agent (たとえば `claude-code` や `cursor`) 。agent が検出されなかった場合は空です。
* `client_revision` ([UInt32](/ja/sql-reference/data-types/int-uint)) — `clickhouse-client` または別の TCP クライアントのリビジョン。
* `client_version_major` ([UInt32](/ja/sql-reference/data-types/int-uint)) — `clickhouse-client` または別の TCP クライアントのメジャーバージョン。
* `client_version_minor` ([UInt32](/ja/sql-reference/data-types/int-uint)) — `clickhouse-client` または別の TCP クライアントのマイナーバージョン。
* `client_version_patch` ([UInt32](/ja/sql-reference/data-types/int-uint)) — `clickhouse-client` または別の TCP クライアントのバージョンのパッチ番号。
* `script_query_number` ([UInt32](/ja/sql-reference/data-types/int-uint)) — 複数クエリを含むスクリプト内での連番のクエリ番号。
* `script_line_number` ([UInt32](/ja/sql-reference/data-types/int-uint)) — 現在のクエリが開始される、複数クエリを含むスクリプト内の行番号。
* `http_method` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリを開始した HTTP メソッド。設定可能な値: 0 — クエリは TCP インターフェイスから開始された、1 — GET メソッドが使用された、2 — POST メソッドが使用された。
* `http_user_agent` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — HTTP リクエストで渡された User-Agent ヘッダー。
* `http_referer` ([String](/ja/sql-reference/data-types/string)) — HTTP クエリで渡された `Referer` HTTP ヘッダー (クエリを実行したページの絶対アドレスまたは部分アドレスを含みます) 。
* `forwarded_for` ([String](/ja/sql-reference/data-types/string)) — HTTP クエリで渡された `X-Forwarded-For` HTTP ヘッダー。
* `quota_key` ([String](/ja/sql-reference/data-types/string)) — quotas 設定で指定された &#39;quota key&#39;。
* `distributed_depth` ([UInt64](/ja/sql-reference/data-types/int-uint)) — クエリがサーバー間で何回転送されたか。
* `revision` ([UInt32](/ja/sql-reference/data-types/int-uint)) — ClickHouseのリビジョン。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ja/sql-reference/data-types/map)) — このスレッドのさまざまなメトリクスを測定するProfileEvents。各項目の説明は、`system.events` テーブルに記載されています。

**別名:**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)` の別名です。
* `ProfileEvents.Values` — `mapValues(ProfileEvents)` の別名です。
