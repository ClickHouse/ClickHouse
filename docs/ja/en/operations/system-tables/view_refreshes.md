<div id="description">
  ## 説明
</div>

[リフレッシュ可能なマテリアライズドビュー](../../sql-reference/statements/create/view.md#refreshable-materialized-view)に関する情報です。現在リフレッシュ中かどうかにかかわらず、すべてのリフレッシュ可能なマテリアライズドビューが含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — テーブルが存在するデータベースの名前。
* `view` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — テーブルの UUID (Atomic データベース) 。
* `status` ([String](/ja/sql-reference/data-types/string)) — リフレッシュの現在の状態。
* `last_success_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — 直近で成功したリフレッシュが開始された時刻。サーバーの起動以降またはテーブルの作成以降に成功したリフレッシュが一度もない場合は NULL。
* `last_success_duration_ms` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 直近のリフレッシュにかかった時間。
* `last_refresh_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — 直近のリフレッシュ試行が終了した時刻 (判明している場合) または開始した時刻 (不明な場合や現在も実行中の場合) 。サーバーの起動以降またはテーブルの作成以降にリフレッシュ試行が一度もない場合は NULL。
* `last_refresh_replica` ([String](/ja/sql-reference/data-types/string)) — 協調が有効な場合、現在の (実行中であれば) または前回の (実行中でなければ) リフレッシュ試行を行ったレプリカの名前。
* `next_refresh_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — 次回のリフレッシュ開始が予定されている時刻。次回のリフレッシュ時刻が現在不明な場合は NULL。たとえば、依存関係を待機している場合 (status が `WaitingForDependencies` または `MissingDependencies`) 。
* `exception` ([String](/ja/sql-reference/data-types/string)) — 前回の試行が失敗した場合のエラーメッセージ。
* `retry` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 現在のリフレッシュについて、これまでに失敗した試行回数。status が `RunningOnAnotherReplica` の場合は利用できません。
* `progress` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了したリフレッシュの進捗。値は 0 から 1 の範囲。status が `RunningOnAnotherReplica` の場合、またはリフレッシュが実行中でない場合は NULL。
* `read_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定されたレプリカにおいて、現在実行中または直近で完了したリフレッシュが読み取った行数。status が `RunningOnAnotherReplica` の場合は NULL。
* `read_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定されたレプリカにおいて、現在実行中または直近で完了したリフレッシュが読み取ったバイト数。status が `RunningOnAnotherReplica` の場合は NULL
* `total_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定されたレプリカにおいて、現在実行中または直近で完了したリフレッシュが読み取る必要があると見積もられる総行数。status が `RunningOnAnotherReplica` の場合は NULL
* `written_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定されたレプリカにおいて、現在実行中または直近で完了したリフレッシュが書き込んだ行数。status が `RunningOnAnotherReplica` の場合は NULL
* `written_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定されたレプリカにおいて、現在実行中または直近で完了したリフレッシュが書き込んだバイト数。status が `RunningOnAnotherReplica` の場合は NULL

{/*AUTOGENERATED_END*/ }

  ## 例
</div>

```sql
SELECT
    database,
    view,
    status,
    last_refresh_time,
    next_refresh_time
FROM system.view_refreshes

┌─database─┬─view───────────────────────┬─status────┬───last_refresh_time─┬───next_refresh_time─┐

└──────────┴────────────────────────────┴───────────┴─────────────────────┴─────────────────────┘
```
