<div id="description">
  ## 説明
</div>

ログエントリが格納されます。このテーブルに記録されるログレベルは、サーバー設定 `text_log.level` で制限できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行するサーバーのホスト名。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — エントリの日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — エントリの時刻。
* `event_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — マイクロ秒精度のエントリ時刻。
* `thread_name` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — ログを記録したスレッドの名前。
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — OS のスレッド ID。
* `level` ([Enum8(&#39;Fatal&#39; = 1, &#39;Critical&#39; = 2, &#39;Error&#39; = 3, &#39;Warning&#39; = 4, &#39;Notice&#39; = 5, &#39;Information&#39; = 6, &#39;Debug&#39; = 7, &#39;Trace&#39; = 8, &#39;Test&#39; = 9)](/ja/sql-reference/data-types/enum)) — エントリのレベル。設定可能な値: 1 または &#39;Fatal&#39;、2 または &#39;Critical&#39;、3 または &#39;Error&#39;、4 または &#39;Warning&#39;、5 または &#39;Notice&#39;、6 または &#39;Information&#39;、7 または &#39;Debug&#39;、8 または &#39;Trace&#39;。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — クエリ ID。
* `logger_name` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — ロガーの名前 (例: DDLWorker) 。
* `message` ([String](/ja/sql-reference/data-types/string)) — メッセージ本体。
* `revision` ([UInt32](/ja/sql-reference/data-types/int-uint)) — ClickHouse のリビジョン。
* `source_file` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — ログを記録したソースファイル。
* `source_line` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ログを記録したソースコードの行番号。
* `message_format_string` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — メッセージの整形に使用されたフォーマット文字列。
* `value1` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 1。
* `value2` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 2。
* `value3` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 3。
* `value4` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 4。
* `value5` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 5。
* `value6` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 6。
* `value7` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 7。
* `value8` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 8。
* `value9` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 9。
* `value10` ([String](/ja/sql-reference/data-types/string)) — メッセージの整形に使用された引数 10。

{/*AUTOGENERATED_END*/ }
