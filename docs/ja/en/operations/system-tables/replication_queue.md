<div id="description">
  ## 説明
</div>

`ReplicatedMergeTree` ファミリーのテーブルについて、ClickHouse Keeper または ZooKeeper に保存されているレプリケーションキュー内のタスクに関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `replica_name` ([String](/ja/sql-reference/data-types/string)) — ClickHouse Keeper 内のレプリカ名。同じテーブルの各レプリカには異なる名前が付けられます。
* `position` ([UInt32](/ja/sql-reference/data-types/int-uint)) — キュー内でのタスクの位置。
* `node_name` ([String](/ja/sql-reference/data-types/string)) — ClickHouse Keeper 内のノード名。
* `type` ([String](/ja/sql-reference/data-types/string)) — キュー内のタスクの種類。次のいずれかです: • GET&#95;PART — 別のレプリカからパーツを取得します。• ATTACH&#95;PART — パーツをアタッチします。detached フォルダ内で見つかった場合は、自身のレプリカからアタッチすることもあります。両者はほぼ同じなので、いくつか最適化が入った GET&#95;PART と考えることもできます。• MERGE&#95;PARTS — パーツをマージします。• DROP&#95;RANGE — 指定した番号範囲内の、指定したパーティションのパーツを削除します。• CLEAR&#95;COLUMN — 注: 非推奨。指定したパーティションから特定のカラムを削除します。• CLEAR&#95;INDEX — 注: 非推奨。指定したパーティションから特定の索引を削除します。• REPLACE&#95;RANGE — 特定範囲のパーツを削除し、新しいパーツで置き換えます。• MUTATE&#95;PART — 1 つ以上の mutation をパーツに適用します。• ALTER&#95;METADATA — グローバルな /metadata および /columns パスに従って alter の変更を適用します。
* `create_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — タスクが実行のために登録された日時。
* `required_quorum` ([UInt32](/ja/sql-reference/data-types/int-uint)) — タスクの完了確認を待っているレプリカ数。このカラムは GET&#95;PARTS タスクにのみ関係します。
* `source_replica` ([String](/ja/sql-reference/data-types/string)) — ソースレプリカ名。
* `new_part_name` ([String](/ja/sql-reference/data-types/string)) — 新しいパーツの名前。
* `parts_to_merge` ([Array(String)](/ja/sql-reference/data-types/array)) — マージまたは更新するパーツ名。
* `is_detach` ([UInt8](/ja/sql-reference/data-types/int-uint)) — DETACH&#95;PARTS タスクがキュー内にあるかどうかを示すフラグです。
* `is_currently_executing` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 特定のタスクが現在実行中かどうかを示すフラグです。
* `num_tries` ([UInt32](/ja/sql-reference/data-types/int-uint)) — タスクの完了に失敗した試行回数。
* `last_exception` ([String](/ja/sql-reference/data-types/string)) — 最後に発生したエラーのテキストメッセージ (存在する場合) 。
* `last_exception_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 最後にエラーが発生した日時。
* `last_attempt_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — タスクが最後に試行された日時。
* `num_postponed` ([UInt32](/ja/sql-reference/data-types/int-uint)) — アクションが延期された回数。
* `postpone_reason` ([String](/ja/sql-reference/data-types/string)) — タスクが延期された理由。
* `last_postpone_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — タスクが最後に延期された日時。
* `merge_type` ([String](/ja/sql-reference/data-types/string)) — 現在のマージの種類。mutation の場合は空です。

{/*AUTOGENERATED_END*/ }
