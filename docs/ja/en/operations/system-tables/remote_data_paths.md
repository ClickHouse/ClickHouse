<div id="description">
  ## 説明
</div>

リモートディスク (S3 や Azure Blob Storage など) に保存されているデータファイルに関する情報が含まれます。これには、ローカルのメタデータパスとリモートのブロブパスの対応関係も含まれます。

各行は、データファイルに関連付けられた 1 つのリモートブロブオブジェクトを表します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `disk_name` ([String](/ja/sql-reference/data-types/string)) — ディスク名。
* `path` ([String](/ja/sql-reference/data-types/string)) — ディスクのパス。
* `cache_base_path` ([String](/ja/sql-reference/data-types/string)) — cache ファイルのベースディレクトリ。
* `local_path` ([String](/ja/sql-reference/data-types/string)) — ClickHouse ファイルのパス。メタデータパスとしても使用されます。
* `remote_path` ([String](/ja/sql-reference/data-types/string)) — object storage 内の、ClickHouse ファイルに関連付けられたブロブのパス。
* `size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ファイルのサイズ (圧縮済み) 。
* `common_prefix_for_blobs` ([String](/ja/sql-reference/data-types/string)) — object storage 内のブロブに共通するプレフィックス。
* `cache_paths` ([Array(String)](/ja/sql-reference/data-types/array)) — 対応するブロブの cache ファイル。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.remote_data_paths LIMIT 1 FORMAT Vertical;
```

```text
Row 1:
──────
disk_name:              s3
path:                   /var/lib/clickhouse/disks/s3/
cache_base_path:        /var/lib/clickhouse/disks/s3_cache/
local_path:             store/123/1234abcd-1234-1234-1234-1234abcd1234/all_0_0_0/data.bin
remote_path:            abc123/all_0_0_0/data.bin
size:                   1048576
common_prefix_for_blobs:
cache_paths:            ['/var/lib/clickhouse/disks/s3_cache/a1/b2/c3d4e5f6']
```
