<div id="description">
  ## 説明
</div>

このシステムテーブルには、ClickHouse に存在する Iceberg テーブルのスナップショット履歴が格納されています。ClickHouse に Iceberg テーブルが存在しない場合、このテーブルは空です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `made_current_at` ([Nullable(DateTime64(3))](/ja/sql-reference/data-types/nullable)) — このスナップショットが現在のスナップショットになった日時。
* `snapshot_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — スナップショットを識別するためのスナップショット ID。
* `parent_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このスナップショットの親 ID。
* `is_current_ancestor` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このスナップショットが現在のスナップショットの祖先かどうかを示すフラグ。

{/*AUTOGENERATED_END*/ }
