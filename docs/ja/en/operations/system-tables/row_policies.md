<div id="description">
  ## 説明
</div>

特定のテーブルに対するフィルターと、このROW POLICYを適用するロールやユーザーの一覧が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — ROW POLICYの名前。
* `short_name` ([String](/ja/sql-reference/data-types/string)) — ROW POLICYの短縮名。ROW POLICY名は複合的で、たとえば myfilter ON mydb.mytable のようになります。ここで &#39;myfilter ON mydb.mytable&#39; はROW POLICYの名前、&#39;myfilter&#39; はその短縮名です。
* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。データベースに対するポリシーの場合は空です。
* `id` ([UUID](/ja/sql-reference/data-types/uuid)) — ROW POLICY ID。
* `storage` ([String](/ja/sql-reference/data-types/string)) — ROW POLICYが保存されているディレクトリ名。
* `select_filter` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — SELECT クエリでのフィルタリングに使用される式。
* `is_restrictive` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ROW POLICYが行へのアクセスを制限するかどうかを示します。値: • 0 — ROW POLICYは `AS PERMISSIVE` 句で定義されています、• 1 — ROW POLICYは `AS RESTRICTIVE` 句で定義されています。
* `apply_to_all` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ROW POLICYがすべてのロールおよび/またはユーザーに設定されていることを示します。
* `apply_to_list` ([Array(String)](/ja/sql-reference/data-types/array)) — ROW POLICYが適用されるロールおよび/またはユーザーの一覧。
* `apply_to_except` ([Array(String)](/ja/sql-reference/data-types/array)) — 一覧に含まれるものを除く、すべてのロールおよび/またはユーザーにROW POLICYが適用されます。

{/*AUTOGENERATED_END*/ }
