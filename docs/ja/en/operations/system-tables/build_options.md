<div id="description">
  ## 説明
</div>

ClickHouse serverのビルドオプションに関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — ビルドオプションの名前。
* `value` ([String](/ja/sql-reference/data-types/string)) — ビルドオプションの値。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
