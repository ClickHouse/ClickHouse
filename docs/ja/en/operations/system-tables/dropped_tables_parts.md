<div id="description">
  ## 説明
</div>

[system.dropped&#95;tables](./dropped_tables.md) に記録されている、削除された [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) テーブルのパーツに関する情報が含まれます

このテーブルのスキーマは [system.parts](./parts.md) と同じです

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/ja/sql-reference/data-types/string)) — パーティション識別子 (テーブルのパーティションキー式から導出される文字列表現) 。
* `name` ([String](/ja/sql-reference/data-types/string)) — データパートの名前。パートの命名構造を使用すると、データや、取り込み・マージのパターンに関するさまざまな情報を判断できます。パートの命名形式は次のとおりです。

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * 定義:
    * `partition_id` - パーティションキーを識別します
    * `minimum_block_number` - パーツ内の最小ブロック番号を識別します。ClickHouse は常に連続するブロックをマージします
    * `maximum_block_number` - パーツ内の最大ブロック番号を識別します
    * `level` - パーツに対してマージが 1 回行われるごとに 1 ずつ増加します。レベル 0 は、これがまだマージされていない新しいパーツであることを示します。ClickHouse のすべてのパーツは常に不変であることを覚えておくことが重要です
    * `data_version` - 任意の値で、パーツがミューテーションされると増加します (繰り返しになりますが、パーツは不変であるため、ミューテーションされたデータは常に新しいパーツにのみ書き込まれます)
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — データパーツの UUID。
* `part_type` ([String](/ja/sql-reference/data-types/string)) — データパーツの保存フォーマット。設定可能な値: `Wide` — 各カラムが別々のファイルに保存されます。`Compact` — すべてのカラムが 1 つのファイルに保存されます。データの保存フォーマットは、MergeTree テーブルの `min_bytes_for_wide_part` および `min_rows_for_wide_part` 設定によって制御されます。
* `active` ([UInt8](/ja/sql-reference/data-types/int-uint)) — データパーツがアクティブかどうかを示すフラグ。データパーツがアクティブな場合はテーブルで使用され、そうでない場合は削除予定です。非アクティブなデータパーツは、マージ操作や mutation 操作の後に現れます。
* `marks` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マーク数。データパーツ内のおおよその行数を取得するには、marks に index granularity (通常は 8192) を掛けます (この方法は adaptive granularity では機能しません) 。
* `rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 行数。
* `files` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のファイル数。
* `bytes_on_disk` ([UInt64](/ja/sql-reference/data-types/int-uint)) — すべてのデータパーツファイルの合計サイズ (バイト) 。
* `data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内の圧縮データの合計サイズ。補助ファイル (たとえばマークを含むファイル) は含まれません。
* `data_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内の非圧縮データの合計サイズ。補助ファイル (たとえばマークを含むファイル) は含まれません。
* `primary_key_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ディスク上の primary.idx/cidx ファイル内の主キー値が使用するメモリ量 (バイト) 。
* `marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マークを含むファイルのサイズ。
* `secondary_indices_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のセカンダリ索引の圧縮データの合計サイズ。補助ファイル (たとえばマークを含むファイル) は含まれません。
* `secondary_indices_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のセカンダリ索引の非圧縮データの合計サイズ。補助ファイル (たとえばマークを含むファイル) は含まれません。
* `secondary_indices_marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — セカンダリ索引のマークを含むファイルのサイズ。
* `modification_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツを含むディレクトリが変更された時刻。通常、これはデータパーツの作成時刻に対応します。
* `remove_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツが非アクティブになった時刻。
* `refcount` ([UInt32](/ja/sql-reference/data-types/int-uint)) — データパーツが使用されている箇所の数。値が 2 より大きい場合、そのデータパーツはクエリまたはマージで使用されています。
* `min_date` ([Date](/ja/sql-reference/data-types/date)) — データパーツ内の日付キーの最小値。
* `max_date` ([Date](/ja/sql-reference/data-types/date)) — データパーツ内の日付キーの最大値。
* `min_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最小値。
* `max_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最大値。
* `partition_id` ([String](/ja/sql-reference/data-types/string)) — パーティションの ID。
* `min_block_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最小番号。
* `max_block_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最大番号。
* `level` ([UInt32](/ja/sql-reference/data-types/int-uint)) — マージツリーの深さ。0 は、現在のパーツが他のパーツのマージではなく insert によって作成されたことを意味します。
* `data_version` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このデータパートに適用する mutation を判定するために使用される数値 (`data_version` より大きいバージョンの mutation) 。
* `primary_key_bytes_in_memory` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 主キーの値が使用するメモリ量 (バイト単位) 。`primary_key_lazy_load` が有効で、キーが読み込まれていない場合は 0 になります。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 主キーの値のために確保されているメモリ量 (バイト単位) 。`primary_key_lazy_load` が有効で、キーが読み込まれていない場合は 0 になります。
* `index_granularity_bytes_in_memory` ([UInt64](/ja/sql-reference/data-types/int-uint)) — index granularity の値が使用するメモリ量 (バイト単位)  (primary&#95;key&#95;lazy&#95;load=1 かつ use&#95;primary&#95;key&#95;cache=1 の場合は 0 になります) 。
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — index granularity の値のために確保されているメモリ量 (バイト単位)  (primary&#95;key&#95;lazy&#95;load=1 かつ use&#95;primary&#95;key&#95;cache=1 の場合は 0 になります) 。
* `is_frozen` ([UInt8](/ja/sql-reference/data-types/int-uint)) — パーティションデータのバックアップが存在することを示すフラグです。1 はバックアップが存在すること、0 はバックアップが存在しないことを示します。詳細は FREEZE PARTITION を参照してください。
* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `engine` ([String](/ja/sql-reference/data-types/string)) — パラメータを含まないテーブルエンジン名。
* `disk_name` ([String](/ja/sql-reference/data-types/string)) — データパートを格納するディスクの名前。
* `path` ([String](/ja/sql-reference/data-types/string)) — データパートのファイルが含まれるフォルダへの絶対パス。
* `hash_of_all_files` ([String](/ja/sql-reference/data-types/string)) — 圧縮ファイルの sipHash128。
* `hash_of_uncompressed_files` ([String](/ja/sql-reference/data-types/string)) — 非圧縮ファイル (marks、index file など) の sipHash128。
* `uncompressed_hash_of_compressed_files` ([String](/ja/sql-reference/data-types/string)) — 圧縮ファイル内のデータを、非圧縮であるかのように扱った場合の sipHash128。
* `delete_ttl_info_min` ([DateTime](/ja/sql-reference/data-types/datetime)) — TTL DELETE ルールに対する日付と時刻キーの最小値。
* `delete_ttl_info_max` ([DateTime](/ja/sql-reference/data-types/datetime)) — TTL DELETE ルールに対する日付と時刻キーの最大値。
* `move_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — 式の Array。各式は TTL MOVE ルールを定義します。
* `move_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — 日付と時刻の値の Array。各要素は TTL MOVE ルールの最小キー値を表します。
* `move_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — 日付と時刻の値の Array。各要素は TTL MOVE ルールの最大キー値を表します。
* `default_compression_codec` ([String](/ja/sql-reference/data-types/string)) — このデータパートの圧縮に使用される codec の名前 (カラムに明示的な codec がない場合) 。
* `recompression_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — TTL 式。
* `recompression_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — この part 内で計算された TTL 式の最小値。少なくとも 1 行で TTL が期限切れになっているかどうかを把握するために使用されます。
* `recompression_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — この part 内で計算された TTL 式の最大値。すべての行で TTL が期限切れになっているかどうかを把握するために使用されます。
* `group_by_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — TTL 式。
* `group_by_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — この part 内で計算された TTL 式の最小値。少なくとも 1 行で TTL が期限切れになっているかどうかを把握するために使用されます。
* `group_by_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された有効期限 (TTL) 式の最大値。すべての行で有効期限 (TTL) が切れているかどうかを判断するために使用されます。
* `rows_where_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — 有効期限 (TTL) 式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された有効期限 (TTL) 式の最小値。少なくとも1つの行で有効期限 (TTL) が切れているかどうかを判断するために使用されます。
* `rows_where_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された有効期限 (TTL) 式の最大値。すべての行で有効期限 (TTL) が切れているかどうかを判断するために使用されます。
* `projections` ([Array(String)](/ja/sql-reference/data-types/array)) — このパートに対して計算されたプロジェクション名の一覧。
* `visible` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このパートが SELECT クエリから参照可能かどうかを示すフラグ。
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ja/sql-reference/data-types/tuple)) — このオブジェクトを作成した、または作成しようとしているトランザクションの ID。
* `removal_tid_lock` ([UInt64](/ja/sql-reference/data-types/int-uint)) — `removal_tid` のハッシュ値で、オブジェクトの削除をロックするために使用されます。
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ja/sql-reference/data-types/tuple)) — このオブジェクトを削除した、または削除しようとしているトランザクションの ID。
* `creation_csn` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このオブジェクトを作成したトランザクションの CSN。
* `removal_csn` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このオブジェクトを削除したトランザクションの CSN。
* `has_lightweight_delete` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このパートに論理削除マスクがあるかどうかを示すフラグ。
* `last_removal_attempt_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — サーバーがこのパートの削除を最後に試行した時刻。
* `removal_state` ([String](/ja/sql-reference/data-types/string)) — パート削除プロセスの現在の状態。

**別名:**

* `bytes` — `bytes_on_disk` の別名です。
* `marks_size` — `marks_bytes` の別名です。
* `part_name` — `name` の別名です。
