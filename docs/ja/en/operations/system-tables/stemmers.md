<div id="description">
  ## 説明
</div>

利用可能なすべてのステマーを表示します。
これらは関数 [stem](../../sql-reference/functions/nlp-functions.md) で使用できます。

:::note 利用可否
`system.stemmers` は、`libstemmer` 依存関係 (`USE_LIBSTEMMER`) を含めてコンパイルされた ClickHouse ビルドでのみ使用できます。これを含まないビルドでは、このテーブルは存在せず、これに対するクエリは `UNKNOWN_TABLE` で失敗します。ご利用のビルドでこれが有効になっているかどうかは、次の方法で確認できます。

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

カラム:

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — Snowball stemmer の識別子 (言語/アルゴリズム)

{/*AUTOGENERATED_END*/ }
