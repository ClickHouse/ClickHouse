<div id="description">
  ## 説明
</div>

すべてのアリーナから集計した、jemalloc アロケータ経由で異なるサイズクラス (ビン) に割り当てられたメモリに関する情報が含まれます。
これらの統計は、jemalloc のスレッドローカルキャッシュの影響により、必ずしも完全に正確とは限りません。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt16](/ja/sql-reference/data-types/int-uint)) — サイズ順に並べた ビン の索引。
* `large` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 大きな割り当ての場合は True、小さな割り当ての場合は False。
* `size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — この ビン の割り当てサイズ。
* `allocations` ([Int64](/ja/sql-reference/data-types/int-uint)) — 割り当て回数。
* `deallocations` ([Int64](/ja/sql-reference/data-types/int-uint)) — 解放回数。
* `nregs` ([Int64](/ja/sql-reference/data-types/int-uint)) — 1 つのスラブあたりのリージョン数。
* `curslabs` ([Int64](/ja/sql-reference/data-types/int-uint)) — 現在のスラブ数。
* `curregs` ([Int64](/ja/sql-reference/data-types/int-uint)) — このサイズクラスの現在のリージョン数。

**別名:**

* `availregs` — `nregs * curslabs` の別名。
* `util` — `curregs / availregs` の別名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

現在のメモリ使用量全体に最も大きく寄与している割り当てのサイズを確認します。

```sql
SELECT
    *,
    allocations - deallocations AS active_allocations,
    size * active_allocations AS allocated_bytes
FROM system.jemalloc_bins
WHERE allocated_bytes > 0
ORDER BY allocated_bytes DESC
LIMIT 10
```
