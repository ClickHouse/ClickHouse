<div id="description">
  ## 説明
</div>

LLVM の XRay 機能で使用されるインストルメンテーションポイントが含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `id` ([UInt32](/ja/sql-reference/data-types/int-uint)) — インストルメンテーションポイントの ID
* `function_id` ([Int32](/ja/sql-reference/data-types/int-uint)) — ELF バイナリの xray&#95;instr&#95;map セクションで関数に割り当てられた ID。
* `function_name` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 関数のインストルメントに使用される名前。
* `handler` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 関数のインストルメンテーションポイントにパッチ適用されたハンドラー。
* `entry_type` ([Enum8(&#39;Entry&#39; = 0, &#39;Exit&#39; = 1, &#39;EntryAndExit&#39; = 2)](/ja/sql-reference/data-types/enum)) — パッチのエントリタイプ。
* `symbol` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 完全なデマングル済みのシンボル名。
* `arguments` ([Array(Dynamic)](/ja/sql-reference/data-types/array)) — ハンドラー呼び出しの引数。

{/*AUTOGENERATED_END*/ }
