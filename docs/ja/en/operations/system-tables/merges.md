<div id="description">
  ## 説明
</div>

MergeTree familyのテーブルで現在処理中のマージおよびパーツミューテーションに関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — テーブルが存在するデータベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `elapsed` ([Float64](/ja/sql-reference/data-types/float)) — マージ開始からの経過時間 (秒) 。
* `progress` ([Float64](/ja/sql-reference/data-types/float)) — 完了した作業の割合 (0 から 1) 。
* `num_parts` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージ対象のパーツ数。
* `source_part_names` ([Array(String)](/ja/sql-reference/data-types/array)) — ソースパーツ名の一覧。
* `result_part_name` ([String](/ja/sql-reference/data-types/string)) — マージの結果として生成されるパーツの名前。
* `source_part_paths` ([Array(String)](/ja/sql-reference/data-types/array)) — 各ソースパーツのパスの一覧。
* `result_part_path` ([String](/ja/sql-reference/data-types/string)) — マージの結果として生成されるパーツのパス。
* `partition_id` ([String](/ja/sql-reference/data-types/string)) — マージが行われているパーティションの識別子。
* `partition` ([String](/ja/sql-reference/data-types/string)) — パーティション名
* `is_mutation` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このプロセスがパーツ ミューテーション の場合は 1。
* `total_size_bytes_compressed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージされた chunk 内の圧縮データの合計サイズ。
* `total_size_bytes_uncompressed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージされた chunk 内の非圧縮データの合計サイズ。
* `total_size_marks` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージされたパーツ内の marks の総数。
* `bytes_read_uncompressed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 読み込まれた非圧縮バイト数。
* `rows_read` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 読み込まれた行数。
* `bytes_written_uncompressed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 書き込まれた非圧縮バイト数。
* `rows_written` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 書き込まれた行数。
* `columns_written` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 書き込まれたカラム数 (Vertical merge アルゴリズムの場合) 。
* `memory_usage` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージ処理のメモリ使用量。
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マージ処理のスレッド ID。
* `merge_type` ([String](/ja/sql-reference/data-types/string)) — 現在のマージの種類。ミューテーション の場合は空です。
* `merge_algorithm` ([String](/ja/sql-reference/data-types/string)) — 現在のマージで使用されるアルゴリズム。ミューテーション の場合は空です。

{/*AUTOGENERATED_END*/ }
