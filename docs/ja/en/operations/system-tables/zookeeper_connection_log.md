<div id="description">
  ## 説明
</div>

`system.zookeeper_connection_log` テーブルには、ZooKeeper 接続 (補助的な ZooKeeper を含む) の履歴が記録されます。各行には、接続に関する 1 件のイベント情報が表示されます。

:::note
このテーブルには、サーバーのシャットダウンによって発生した切断イベントは含まれません。
:::

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — ZooKeeper への接続または切断が行われたサーバーのホスト名。
* `type` ([Enum8(&#39;Connected&#39; = 0, &#39;Disconnected&#39; = 1)](/ja/sql-reference/data-types/enum)) — イベントの種類。設定可能な値: Connected、Disconnected。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — エントリの日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — エントリの時刻
* `event_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — マイクロ秒精度のエントリ時刻。
* `name` ([String](/ja/sql-reference/data-types/string)) — ZooKeeper クラスターの名前。
* `host` ([String](/ja/sql-reference/data-types/string)) — ClickHouse が接続または切断した ZooKeeper ノードのホスト名/IP。
* `port` ([UInt16](/ja/sql-reference/data-types/int-uint)) — ClickHouse が接続または切断した ZooKeeper ノードのポート。
* `index` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ClickHouse が接続または切断した ZooKeeper ノードの索引。この索引は ZooKeeper の設定に基づきます。
* `client_id` ([Int64](/ja/sql-reference/data-types/int-uint)) — 接続の session ID。
* `keeper_api_version` ([UInt8](/ja/sql-reference/data-types/int-uint)) — Keeper API のバージョン。
* `enabled_feature_flags` ([Array(Enum16(&#39;FILTERED&#95;LIST&#39; = 0, &#39;MULTI&#95;READ&#39; = 1, &#39;CHECK&#95;NOT&#95;EXISTS&#39; = 2, &#39;CREATE&#95;IF&#95;NOT&#95;EXISTS&#39; = 3, &#39;REMOVE&#95;RECURSIVE&#39; = 4, &#39;MULTI&#95;WATCHES&#39; = 5, &#39;CHECK&#95;STAT&#39; = 6, &#39;PERSISTENT&#95;WATCHES&#39; = 7, &#39;CREATE&#95;WITH&#95;STATS&#39; = 8, &#39;TRY&#95;REMOVE&#39; = 9, &#39;LIST&#95;WITH&#95;STAT&#95;AND&#95;DATA&#39; = 10, &#39;GET&#95;CHILDREN&#95;RECURSIVE&#39; = 11))](/ja/sql-reference/data-types/array)) — 有効な機能フラグ。ClickHouse Keeper にのみ適用されます。
* `availability_zone` ([String](/ja/sql-reference/data-types/string)) — アベイラビリティーゾーン
* `reason` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 接続または切断の理由。

{/*AUTOGENERATED_END*/ }
