<div id="description">
  ## 説明
</div>

このテーブルには、即時に算出でき、Prometheus形式でエクスポート可能なヒストグラムメトリクスが含まれています。常に最新の状態です。非推奨の `system.latency_log` を置き換えるものです。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/ja/sql-reference/data-types/string)) — メトリクス名。
* `value` ([Float64](/ja/sql-reference/data-types/float)) — メトリクスの値。
* `description` ([String](/ja/sql-reference/data-types/string)) — メトリクスの説明。
* `labels` ([Map(String, String)](/ja/sql-reference/data-types/map)) — メトリクスのラベル。

**別名:**

* `name` — `metric` の別名。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

このようなクエリを使うと、すべてのヒストグラムメトリクスをPrometheus形式でエクスポートできます。

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'histogram' AS type
FROM system.histogram_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## メトリクスの説明
</div>

| Metric                                                       | Description                                                          |
| ------------------------------------------------------------ | -------------------------------------------------------------------- |
| `keeper_response_time_ms_bucket`                             | Keeper の応答時間 (ミリ秒) 。                                                 |
| `keeper_client_queue_duration_milliseconds_bucket`           | リクエストがエンキューされるまでの待機時間と、Keeper クライアントで処理される前にキュー内で待機する時間 (ミリ秒) 。      |
| `keeper_receive_request_time_milliseconds_bucket`            | Keeper TCP ハンドラーでクライアントからのリクエストを受信して解析するまでの時間 (ミリ秒) 。                |
| `keeper_dispatcher_requests_queue_time_milliseconds_bucket`  | リクエストが Keeper のディスパッチャーのリクエストキュー内で費やす時間 (ミリ秒) 。                      |
| `keeper_write_pre_commit_time_milliseconds_bucket`           | Raft のコミット前に書き込みリクエストを前処理する時間 (ミリ秒) 。                                |
| `keeper_write_commit_time_milliseconds_bucket`               | Raft のコミット後に書き込みリクエストを処理する時間 (ミリ秒) 。                                 |
| `keeper_dispatcher_responses_queue_time_milliseconds_bucket` | レスポンスが Keeper のディスパッチャーのレスポンスキュー内で費やす時間 (ミリ秒) 。                      |
| `keeper_send_response_time_milliseconds_bucket`              | Keeper TCP ハンドラーでクライアントにレスポンスを送信する時間 (キュー待機と socket への書き込みを含む、ミリ秒) 。 |
| `keeper_read_wait_for_write_time_milliseconds_bucket`        | 読み取りリクエストが、依存する書き込みリクエストの完了を待機する時間 (ミリ秒) 。                           |
| `keeper_read_process_time_milliseconds_bucket`               | Keeper で読み取りリクエストを処理する時間 (ミリ秒) 。                                     |
| `keeper_batch_size_elements_bucket`                          | Raft に送信される Batch のサイズ (要素数) 。                                       |
| `keeper_batch_size_bytes_bucket`                             | Raft に送信される Batch のサイズ (バイト数) 。                                      |
| `filesystem_cache_evicted_segment_hits_bucket`               | ファイルセグメントのエビクション時点における cache ヒット回数の分布。cache 名でラベル付けされます。             |
| `filesystem_cache_evicted_segment_size_bytes_bucket`         | エビクションされたファイルセグメントのバイトサイズの分布。cache 名でラベル付けされます。                      |
| `filesystem_cache_evicted_segment_hits_by_user_bucket`       | エビクションされたファイルセグメントの cache ヒット回数の分布。cache 名と user id でラベル付けされます。      |
| `filesystem_cache_evicted_segment_size_bytes_by_user_bucket` | エビクションされたファイルセグメントのバイトサイズの分布。cache 名と user id でラベル付けされます。            |
