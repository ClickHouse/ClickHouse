<div id="description">
  ## 説明
</div>

サポートされている[データ型](../../sql-reference/data-types/index.md)に関する情報です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — データ型の名前。
* `case_insensitive` ([UInt8](/ja/sql-reference/data-types/int-uint)) — データ型名をクエリ内で大文字と小文字を区別せずに使用できるかどうかを示すプロパティ。たとえば、`Date` と `date` はどちらも有効です。
* `alias_to` ([String](/ja/sql-reference/data-types/string)) — `name` がエイリアスである対象のデータ型名。
* `description` ([String](/ja/sql-reference/data-types/string)) — そのデータ型の概要説明。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — クエリ内でのデータ型の表記。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — そのデータ型が最初に導入された ClickHouse のバージョン (major.minor 形式) 。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連するデータ型の名前。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
┌─name───────┬─case_insensitive─┬─alias_to─┐
│ LONGBLOB   │                1 │ String   │
│ LONGTEXT   │                1 │ String   │
│ TINYTEXT   │                1 │ String   │
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
