<div id="description">
  ## 説明
</div>

すべての QUOTA の全インターバルにおける上限に関する情報が含まれます。1 つの QUOTA に対応する行数は、0 行以上で任意です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/ja/sql-reference/data-types/string)) — QUOTA 名。
* `duration` ([UInt32](/ja/sql-reference/data-types/int-uint)) — リソース消費量を計算する時間インターバルの長さ (秒) 。
* `is_randomized_interval` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ブール値。インターバルがランダム化されているかどうかを示します。ランダム化されていない場合、インターバルは常に同じ時刻に始まります。たとえば、1 分のインターバルは常に分単位のちょうどの時刻から始まります (つまり、11:20:00 に開始することはありますが、11:20:01 に開始することはありません) 。また、1 日のインターバルは常に UTC の午前 0 時に始まります。インターバルがランダム化されている場合、最初のインターバルはランダムな時刻に始まり、その後のインターバルは順次開始します。値: 0 — インターバルはランダム化されていません、1 — インターバルはランダム化されています。
* `max_queries` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行できるすべての種類のクエリの最大数。
* `max_query_selects` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行できる SELECT クエリの最大数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行できる INSERT クエリの最大数。
* `max_errors` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、エラーになったクエリの最大数。
* `max_result_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、すべてのクエリの結果セットに含まれる行の合計最大数。
* `max_result_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、すべてのクエリの結果セットに含まれるバイトの合計最大数。
* `max_read_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、すべてのクエリの実行中に読み取る行の最大数。
* `max_read_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、すべてのクエリの実行中に読み取るバイトの最大数。
* `max_execution_time` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内において、すべてのクエリの実行に許可される最大時間 (ナノ秒) 。
* `max_written_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、すべてのクエリの実行中に書き込むバイトの最大数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、連続する認証失敗の最大回数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、単一の正規化クエリの最大実行回数。
