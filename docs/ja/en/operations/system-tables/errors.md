<div id="description">
  ## 説明
</div>

エラーコードと、そのエラーが発生した回数が含まれます。

発生していないものも含め、考えられるすべてのエラーコードを表示するには、設定 [system&#95;events&#95;show&#95;zero&#95;values](../settings/settings.md#system_events_show_zero_values) を 1 に設定します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — エラーの名前 (errorCodeToName) 。
* `code` ([Int32](/ja/sql-reference/data-types/int-uint)) — エラーのコード番号。
* `value` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このエラーが発生した回数。
* `last_error_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 最後にエラーが発生した時刻。
* `last_error_message` ([String](/ja/sql-reference/data-types/string)) — 最後のエラーのメッセージ。
* `last_error_format_string` ([String](/ja/sql-reference/data-types/string)) — 最後のエラーのフォーマット文字列。
* `last_error_trace` ([Array(UInt64)](/ja/sql-reference/data-types/array)) — 呼び出されたメソッドが格納されている物理アドレスの一覧を示すスタックトレース。
* `remote` ([UInt8](/ja/sql-reference/data-types/int-uint)) — リモート例外 (つまり、分散クエリのいずれかで受信したもの) 。
* `query_id` ([String](/ja/sql-reference/data-types/string)) — エラーの原因となったクエリの ID (利用可能な場合) 。

{/*AUTOGENERATED_END*/ }

:::note
一部のエラーのカウンターは、クエリが正常に実行された場合でも増加することがあります。該当するエラーが誤検知である可能性がないと確信できる場合を除き、サーバー監視の目的でこのテーブルを使用することは推奨されません。
:::

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
