<div id="description">
  ## 説明
</div>

システムで定義されているすべてのマスキングポリシーに関する情報を含みます。

マスキングポリシーは ClickHouse Cloud でのみ作成および適用できます。オープンソースのビルドでは `system.masking_policies` テーブルは常に空ですが、`SHOW MASKING POLICIES` のようなイントロスペクション用クエリが機能し、例外をスローするのではなく空の結果を返せるよう、このテーブル自体は引き続き存在します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string.md)) — マスキングポリシーの名前。完全名の形式は `short_name ON database.table` です。
* `short_name` ([String](/ja/sql-reference/data-types/string.md)) — マスキングポリシーの短縮名。たとえば、完全名が `mask_email ON mydb.mytable` の場合、短縮名は `mask_email` です。
* `database` ([String](/ja/sql-reference/data-types/string.md)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string.md)) — テーブル名。
* `id` ([UUID](/ja/sql-reference/data-types/uuid.md)) — マスキングポリシーの ID。
* `storage` ([String](/ja/sql-reference/data-types/string.md)) — マスキングポリシーが保存されているディレクトリ名。
* `update_assignments` ([Nullable(String)](/ja/sql-reference/data-types/nullable.md)) — データをどのようにマスクするかを定義する UPDATE の代入式。例: `email = '***masked***', phone = '***-***-****'`。
* `where_condition` ([Nullable(String)](/ja/sql-reference/data-types/nullable.md)) — マスキングを適用する条件を指定する、省略可能な WHERE 条件。
* `priority` ([Int64](/ja/sql-reference/data-types/int-uint.md)) — 複数のマスキングポリシーを適用する際の優先度。優先度の高いポリシーから先に適用されます。デフォルトは 0 です。
* `apply_to_all` ([UInt8](/ja/sql-reference/data-types/int-uint.md)) — マスキングポリシーがすべてのロールおよび/またはユーザーに適用されるかどうかを示します。true の場合は 1、それ以外は 0 です。
* `apply_to_list` ([Array(String)](/ja/sql-reference/data-types/array.md)) — マスキングポリシーが適用されるロールおよび/またはユーザーの一覧。
* `apply_to_except` ([Array(String)](/ja/sql-reference/data-types/array.md)) — 一覧に含まれるものを除くすべてのロールおよび/またはユーザーにマスキングポリシーが適用されます。`apply_to_all` が 1 の場合にのみ設定されます。

{/*AUTOGENERATED_END*/ }
