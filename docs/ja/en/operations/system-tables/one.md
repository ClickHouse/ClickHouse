<div id="description">
  ## 説明
</div>

このテーブルには、値 0 を含む `dummy` UInt8 カラムが 1 つだけあり、行も 1 行だけ含まれています。

このテーブルは、`SELECT` クエリで `FROM` 句が指定されていない場合に使用されます。

これは、他の DBMS にある `DUAL` テーブルに似ています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `dummy` ([UInt8](/ja/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.one LIMIT 10;
```

```response
┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
```
