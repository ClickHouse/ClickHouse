<div id="description">
  ## 説明
</div>

アップロードや削除など、さまざまなブロブストレージ操作に関する情報を含むログエントリが格納されています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — クエリを実行しているサーバーのホスト名。
* `event_date` ([Date](/ja/sql-reference/data-types/date)) — イベントの日付。
* `event_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — イベントの時刻。
* `event_time_microseconds` ([DateTime64(6)](/ja/sql-reference/data-types/datetime64)) — マイクロ秒精度のイベント時刻。
* `event_type` ([Enum8(&#39;Upload&#39; = 1, &#39;Delete&#39; = 2, &#39;MultiPartUploadCreate&#39; = 3, &#39;MultiPartUploadWrite&#39; = 4, &#39;MultiPartUploadComplete&#39; = 5, &#39;MultiPartUploadAbort&#39; = 6, &#39;Read&#39; = 7)](/ja/sql-reference/data-types/enum)) — イベントの種類。設定可能な値: &#39;Upload&#39;, &#39;Delete&#39;, &#39;MultiPartUploadCreate&#39;, &#39;MultiPartUploadWrite&#39;, &#39;MultiPartUploadComplete&#39;, &#39;MultiPartUploadAbort&#39;, &#39;Read&#39;
* `query_id` ([String](/ja/sql-reference/data-types/string)) — イベントに関連付けられたクエリの識別子 (存在する場合) 。
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 操作を実行しているスレッドの識別子。
* `thread_name` ([String](/ja/sql-reference/data-types/string)) — 操作を実行しているスレッドの名前。
* `disk_name` ([LowCardinality(String)](/ja/sql-reference/data-types/lowcardinality)) — 関連するディスクの名前。
* `bucket` ([String](/ja/sql-reference/data-types/string)) — バケットの名前。
* `remote_path` ([String](/ja/sql-reference/data-types/string)) — リモートリソースへのパス。
* `local_path` ([String](/ja/sql-reference/data-types/string)) — リモートリソースを参照する、ローカルシステム上のメタデータファイルへのパス。
* `data_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — アップロードイベントに含まれるデータのサイズ。
* `elapsed_microseconds` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 操作の経過時間 (マイクロ秒) 。
* `error_code` ([Int32](/ja/sql-reference/data-types/int-uint)) — 操作のエラーコード。エラーがない場合は 0。
* `error` ([String](/ja/sql-reference/data-types/string)) — イベントに関連付けられたエラーメッセージ (存在する場合) 。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

ブロブストレージの操作でファイルがアップロードされ、そのイベントが記録されるとします。

```sql
SELECT * FROM system.blob_storage_log WHERE query_id = '7afe0450-504d-4e4b-9a80-cd9826047972' ORDER BY event_date, event_time_microseconds \G
```

```text
Row 1:
──────
hostname:                clickhouse.eu-central1.internal
event_date:              2023-10-31
event_time:              2023-10-31 16:03:40
event_time_microseconds: 2023-10-31 16:03:40.481437
event_type:              Upload
query_id:                7afe0450-504d-4e4b-9a80-cd9826047972
thread_id:               2381740
disk_name:               disk_s3
bucket:                  bucket1
remote_path:             rrr/kxo/tbnqtrghgtnxkzgtcrlutwuslgawe
local_path:              store/654/6549e8b3-d753-4447-8047-d462df6e6dbe/tmp_insert_all_1_1_0/checksums.txt
data_size:               259
error:
```

この例では、アップロード操作は ID `7afe0450-504d-4e4b-9a80-cd9826047972` の `INSERT` クエリに関連付けられています。ローカルのメタデータファイル `store/654/6549e8b3-d753-4447-8047-d462df6e6dbe/tmp_insert_all_1_1_0/checksums.txt` は、ディスク `disk_s3` 上のバケット `bucket1` にあるリモートパス `rrr/kxo/tbnqtrghgtnxkzgtcrlutwuslgawe` を参照しており、そのサイズは 259 バイトです。
