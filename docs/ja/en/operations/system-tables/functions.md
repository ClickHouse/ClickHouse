<div id="description">
  ## 説明
</div>

通常の関数および集約関数に関する情報です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — 関数名。
* `is_aggregate` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 集約関数かどうか。
* `case_insensitive` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 関数名を大文字・小文字を区別せずに使用できるかどうか。
* `alias_to` ([String](/ja/sql-reference/data-types/string)) — 関数名がエイリアスである場合の元の関数名。
* `create_query` ([String](/ja/sql-reference/data-types/string)) — 廃止された。
* `origin` ([Enum8(&#39;System&#39; = 0, &#39;SQLUserDefined&#39; = 1, &#39;ExecutableUserDefined&#39; = 2)](/ja/sql-reference/data-types/enum)) — 廃止された。
* `description` ([String](/ja/sql-reference/data-types/string)) — 関数の動作の概要説明。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — 関数のシグネチャ。
* `arguments` ([String](/ja/sql-reference/data-types/string)) — 関数の引数。
* `parameters` ([String](/ja/sql-reference/data-types/string)) — 関数のパラメータ (集約関数のみ) 。
* `returned_value` ([String](/ja/sql-reference/data-types/string)) — 関数が返す値。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — 関数が最初に導入された ClickHouse のバージョン。
* `categories` ([String](/ja/sql-reference/data-types/string)) — 関数のカテゴリ。
* `deterministic` ([Nullable(UInt8)](/ja/sql-reference/data-types/int-uint)) — 同じ引数に対して常に同じ結果を返すかどうか。不明な場合 (例: 集約関数やユーザー定義関数) は `NULL`。
* `higher_order` ([Nullable(UInt8)](/ja/sql-reference/data-types/int-uint)) — 高階関数かどうか。つまり、少なくとも 1 つの lambda 式を引数として受け取るかどうか (例: `arrayMap`, `arrayFilter`, `mapApply`) 。不明な場合は `NULL`。

{/*AUTOGENERATED_END*/ }
