<div id="description">
  ## 説明
</div>

このノードがプロセス内 ClickHouse Keeper を実行するように設定されていない場合、このテーブルは存在しません。このテーブルには Raft クラスター メンバーごとに 1 行が含まれ、静的なクラスター トポロジー (Raft 設定に基づく) とローカルノード自身のログ位置が組み合わされています。

各ノードが設定する `last_log_index` の値は、正確に 1 つだけです。該当するのは、自身の `server_id` に対応する行です。ピアのログ位置はここには表示されません。これらはリーダーでのみ追跡され、このビューはクラスター全体で対称ではないためです。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — このクラスター メンバーの Raft サーバーID。
* `host` ([String](../../sql-reference/data-types/string.md)) — endpoint から解析されたホスト (最後のコロンより前のプレフィックス) 。
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — 設定どおりの生の Raft endpoint (`host:port`) 。
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — このメンバーが `<can_become_leader>false</can_become_leader>` によって設定された非投票オブザーバーである場合は `true`。
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — このメンバーの Raft 優先度。値が高いほど、リーダー選出時に優先されます。
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — このメンバーが現在の Raft リーダーである場合は `true`。
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — この行がローカルの Keeper ノードを表す場合は `true`。
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — このノード上のローカル Raft ログストア内にある最大のログ索引。現在のノードに対応する行 (`is_self = true`) でのみ設定され、他の行では `NULL` になります。

{/*AUTOGENERATED_END*/ }

```sql
SELECT * FROM system.keeper_cluster ORDER BY server_id;
```
