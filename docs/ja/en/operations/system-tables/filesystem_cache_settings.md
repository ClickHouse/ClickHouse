<div id="description">
  ## 説明
</div>

すべてのファイルシステムキャッシュの設定に関する情報が含まれます

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `cache_name` ([String](/ja/sql-reference/data-types/string)) — キャッシュ名
* `path` ([String](/ja/sql-reference/data-types/string)) — キャッシュディレクトリのパス
* `max_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — キャッシュの最大サイズ
* `max_elements` ([UInt64](/ja/sql-reference/data-types/int-uint)) — キャッシュ要素の最大数。例: ファイルセグメント (ファイルシステム上のファイル数を制限)
* `max_file_segment_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 1 つのファイルセグメントの最大サイズ
* `boundary_alignment` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ファイルセグメントのアラインメント
* `cache_on_write_operations` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ライトスルーキャッシュを有効にします (INSERT および MERGE 時にキャッシュ)
* `cache_policy` ([String](/ja/sql-reference/data-types/string)) — キャッシュのエビクションポリシー
* `slru_size_ratio` ([Float64](/ja/sql-reference/data-types/float)) — 保護対象要素と probationary 要素のサイズ比を表す SLRU キャッシュポリシーの比率
* `background_download_threads` ([UInt64](/ja/sql-reference/data-types/int-uint)) — バックグラウンドダウンロードスレッド数。値 `0` でバックグラウンドダウンロードを無効化
* `background_download_queue_size_limit` ([UInt64](/ja/sql-reference/data-types/int-uint)) — バックグラウンドダウンロードキューのサイズ。値 `0` でバックグラウンドダウンロードを無効化
* `background_download_max_file_segment_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — バックグラウンドダウンロードでダウンロードできる最大サイズ
* `load_metadata_threads` ([UInt64](/ja/sql-reference/data-types/int-uint)) — server 起動時にキャッシュのメタデータ読み込みに使用するスレッドの最大数
* `load_metadata_asynchronously` ([UInt8](/ja/sql-reference/data-types/int-uint)) — server 起動時のメタデータの非同期読み込みを有効にします
* `keep_free_space_size_ratio` ([Float64](/ja/sql-reference/data-types/float)) — キャッシュがバックグラウンドで維持しようとする空き領域の比率
* `keep_free_space_elements_ratio` ([Float64](/ja/sql-reference/data-types/float)) — キャッシュがバックグラウンドで維持しようとする空き要素数の比率
* `keep_free_space_remove_batch` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 空き領域/空き要素の比率を維持するバックグラウンドスレッドが 1 回で削除するキャッシュ要素数
* `invalidated_entries_cleanup_interval_ms` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 無効化された (遅延削除された) 優先度キューエントリを削除するバックグラウンドタスクの待機間隔 (ミリ秒)
* `invalidated_entries_cleanup_threshold` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 累積した無効な優先度キューエントリ数。この値に達するとバックグラウンドでの削除がトリガーされます
* `invalidated_entries_cleanup_remove_batch` ([UInt64](/ja/sql-reference/data-types/int-uint)) — バックグラウンドの各反復で、単一の書き込みロック下で削除される無効な優先度キューエントリの最大数
* `enable_filesystem_query_cache_limit` ([UInt8](/ja/sql-reference/data-types/int-uint)) — クエリ内で書き込めるキャッシュの最大サイズ制限を有効にします
* `cache_hits_threshold` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 非推奨の設定
* `enable_bypass_cache_with_threshold` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 文書化されていません。使用は推奨されません
* `bypass_cache_threshold` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 文書化されていません。使用は推奨されません
* `write_cache_per_user_id_directory` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ClickHouse Cloud の内部設定
* `allow_dynamic_cache_resize` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ファイルシステムキャッシュの動的なサイズ変更を許可します
* `max_size_ratio_to_total_space` ([Float64](/ja/sql-reference/data-types/float)) — 総ディスク容量に対する `max_size` の比率
* `skip_cache_on_disk_failure` ([UInt8](/ja/sql-reference/data-types/int-uint)) — true の場合、ディスク I/O エラー時にファイルシステムキャッシュの操作を黙ってスキップします。false (デフォルト) の場合、ディスク I/O エラーは起動失敗として伝播されます。
* `use_split_cache` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ファイルを system/data 用に分離して使用します。
* `split_cache_ratio` ([Float64](/ja/sql-reference/data-types/float)) — split&#95;cache における cache の総サイズに対する system セグメントの比率
* `overcommit_eviction_evict_step` ([UInt64](/ja/sql-reference/data-types/int-uint)) — overcommit エビクションポリシーにおけるバイト単位のエビクションステップです。keep&#95;free&#95;space&#95;*&#95;ratio 設定で使用されます
* `check_cache_probability` ([Float64](/ja/sql-reference/data-types/float)) — デバッグまたは sanitizer ビルドでのみ機能します。cache 全体を走査し、各 cache 要素の state を確認することで、cache の正しさを検証します
* `expose_prometheus_eviction_metrics` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ファイルシステムキャッシュのエビクション活動に関する Prometheus メトリクス (`filesystem_cache_evictions_total` など) を公開します。デフォルトではオフです。`SYSTEM RELOAD CONFIG` によりランタイムで切り替えできます。
* `expose_prometheus_eviction_metrics_per_user` ([UInt8](/ja/sql-reference/data-types/int-uint)) — さらに、ユーザー ID ごとのエビクションメトリクスを公開します。`expose_prometheus_eviction_metrics` が必要です。カーディナリティは、エビクションを実行するユーザー数が増えるほど高くなります。
* `is_initialized` ([UInt8](/ja/sql-reference/data-types/int-uint)) — cache が正常に初期化されたかどうかを示します
* `current_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 現在の cache サイズ
* `current_elements_num` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 現在の cache 要素 (ファイルセグメント) 数
