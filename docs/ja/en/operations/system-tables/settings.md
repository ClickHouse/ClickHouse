<div id="description">
  ## 説明
</div>

現在のユーザーのセッション設定に関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — 設定名。
* `value` ([String](/ja/sql-reference/data-types/string)) — 設定値。
* `changed` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 設定が config で明示的に定義されているか、明示的に変更されたかを示します。
* `description` ([String](/ja/sql-reference/data-types/string)) — 設定の簡単な説明。
* `min` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 制約によって最小値が設定されている場合、その値を示します。設定に最小値がない場合は、NULL が入ります。
* `max` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — 制約によって最大値が設定されている場合、その値を示します。設定に最大値がない場合は、NULL が入ります。
* `disallowed_values` ([Array(String)](/ja/sql-reference/data-types/array)) — 使用できない値の一覧
* `readonly` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 現在のユーザーがこの設定を変更できるかどうかを示します: 0 — 現在のユーザーは設定を変更できます、1 — 現在のユーザーは設定を変更できません。
* `type` ([String](/ja/sql-reference/data-types/string)) — この設定に割り当てられる値の型。
* `default` ([String](/ja/sql-reference/data-types/string)) — 設定のデフォルト値。
* `alias_for` ([String](/ja/sql-reference/data-types/string)) — この設定が別の設定の alias である場合の、元の設定名。
* `is_obsolete` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 設定が廃止されたものかどうかを示します。
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/ja/sql-reference/data-types/enum)) — この feature のサポートレベル。ClickHouse の features は tier ごとに分類されており、その
  開発状況と、使用時にどの程度の期待を持てるかによって異なります:
  * PRODUCTION: この feature は stable で、安全に使用でき、他の PRODUCTION feature と組み合わせても問題はありません。
  * BETA: この feature は stable で安全です。他の feature と組み合わせて使用した場合の結果は不明であり、正しさは保証されません。テストや報告を歓迎します。
  * EXPERIMENTAL: この feature は開発中です。開発者と ClickHouse 愛好家のみを対象としています。この feature は動作する場合もしない場合もあり、いつでも削除される可能性があります。
  * OBSOLETE: すでにサポートされていません。すでに削除されているか、今後の releases で削除される予定です。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

次の例は、名前に `min_i` を含む設定の情報を取得する方法を示しています。

```sql
SELECT *
FROM system.settings
WHERE name LIKE '%min_insert_block_size_%'
FORMAT Vertical
```

`WHERE changed` は、たとえば次のような確認をしたい場合に役立ちます。

* 設定ファイル内の設定が正しく読み込まれ、実際に使用されているかどうか。
* 現在のセッションで変更された設定。

```sql
SELECT * FROM system.settings WHERE changed AND name='load_balancing'
```
