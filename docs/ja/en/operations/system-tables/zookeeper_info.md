<div id="description">
  ## 説明
</div>

このテーブルには、ZooKeeper に関する統合的な内部診断情報が出力されます。ノードは設定から取得されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_cluster_name` ([String](../../sql-reference/data-types/string.md)) — ZooKeeper クラスターの名前。
* `host` ([String](../../sql-reference/data-types/string.md)) — ClickHouse が接続した ZooKeeper ノードのホスト名/IP。
* `port` ([UInt16](../../sql-reference/data-types/int-uint.md)) — ClickHouse が接続した ZooKeeper ノードのポート。
* `index` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — ClickHouse が接続した ZooKeeper ノードのインデックス。インデックスは ZooKeeper の設定に基づきます。接続されていない場合、このカラムは NULL です。
* `is_connected` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — ZooKeeper に接続されているかどうか。
* `is_readonly` ([UInt8](../../sql-reference/data-types/int-uint.md)) — 読み取り専用かどうか。
* `version` ([String](../../sql-reference/data-types/string.md)) — ZooKeeper のバージョン。
* `avg_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 平均レイテンシ。
* `max_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 最大レイテンシ。
* `min_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 最小レイテンシ。
* `packets_received` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 受信したパケット数。
* `packets_sent` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 送信したパケット数。
* `outstanding_requests` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 未処理のリクエスト数。
* `server_state` ([String](../../sql-reference/data-types/string.md)) — サーバーの状態。
* `is_leader` ([UInt8](../../sql-reference/data-types/int-uint.md)) — この ZooKeeper がリーダーかどうか。
* `znode_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — znode 数。
* `watch_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — watch 数。
* `ephemerals_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ephemeral ノード数。
* `approximate_data_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — おおよそのデータサイズ。
* `followers` ([UInt64](../../sql-reference/data-types/int-uint.md)) — リーダーのフォロワー数。このフィールドはリーダーでのみ公開されます。
* `synced_followers` ([UInt64](../../sql-reference/data-types/int-uint.md)) — リーダーの同期済みフォロワー数。このフィールドはリーダーでのみ公開されます。
* `pending_syncs` ([UInt64](../../sql-reference/data-types/int-uint.md)) — リーダーで保留中の同期数。このフィールドはリーダーでのみ公開されます。
* `open_file_descriptor_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — オープンしているファイルディスクリプタ数。Unix プラットフォームでのみ使用できます。
* `max_file_descriptor_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — 最大ファイルディスクリプタ数。Unix プラットフォームでのみ使用できます。
* `connections` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper 接続数。
* `outstanding` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の outstanding 値。
* `zxid` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の zxid 値。
* `node_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper のノード数。
* `snapshot_dir_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper のスナップショットディレクトリのサイズ。
* `log_dir_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper のログディレクトリのサイズ。
* `first_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の先頭ログの索引。
* `first_log_term` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の先頭ログの term。
* `last_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の末尾ログの索引。
* `last_log_term` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の末尾ログの term。
* `last_committed_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の直近のコミット済み索引。
* `leader_committed_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の leader のコミット済みログ索引。
* `target_committed_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の対象のコミット済みログ索引。
* `last_snapshot_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ZooKeeper の直近のスナップショット索引。
