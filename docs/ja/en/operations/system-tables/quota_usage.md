<div id="description">
  ## 説明
</div>

現在のユーザーのクォータ使用状況: 使用量と残量。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/ja/sql-reference/data-types/string)) — クォータ名。
* `quota_key` ([String](/ja/sql-reference/data-types/string)) — キー値。
* `start_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — リソース消費量の計算開始時刻。
* `end_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — リソース消費量の計算終了時刻。
* `duration` ([Nullable(UInt32)](/ja/sql-reference/data-types/nullable)) — リソース消費量の計算対象となる時間間隔の長さ (秒単位) 。
* `queries` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在実行されたクエリ数。
* `max_queries` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行可能な全種類のクエリの最大数。
* `query_selects` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在実行された SELECT クエリ数。
* `max_query_selects` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行可能な SELECT クエリの最大数。
* `query_inserts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在実行された INSERT クエリ数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行可能な INSERT クエリの最大数。
* `errors` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在エラーとなったクエリ数。
* `max_errors` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、エラーとなったクエリ数の最大値。
* `result_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの結果セットの総行数。
* `max_result_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セットの総行数の最大値。
* `result_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの結果セットの総バイト数。
* `max_result_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セットの総バイト数の最大値。
* `read_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの実行中に読み取られた総行数。
* `max_read_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取る行数の最大値。
* `read_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの実行中に読み取られた総バイト数。
* `max_read_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取るバイト数の最大値。
* `execution_time` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内にクエリの実行に費やされた合計時間 (ナノ秒単位)
* `max_execution_time` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — 指定期間内にすべてのクエリの実行に許可される合計時間の最大値 (ナノ秒単位)
* `written_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの実行中に書き込まれた総バイト数。
* `max_written_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に書き込むバイト数の最大値。
* `failed_sequential_authentications` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、連続した認証失敗回数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、連続した認証失敗回数の最大値。
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、単一の正規化クエリの最大実行回数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、単一の正規化クエリの最大実行回数。
