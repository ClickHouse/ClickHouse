<div id="description">
  ## 説明
</div>

サーバーが認識している各テーブルのメタデータが含まれます。

[デタッチされた](../../sql-reference/statements/detach.md)テーブルは、`system.tables` には表示されません。

[一時テーブル](../../sql-reference/statements/create/table.md#temporary-tables)は、作成された session でのみ `system.tables` に表示されます。これらは、`database` フィールドが空で、`is_temporary` flag が有効になった状態で表示されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — テーブルが属するデータベースの名前。
* `name` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — テーブルの uuid (Atomic データベース) 。
* `engine` ([String](/ja/sql-reference/data-types/string)) — テーブルエンジン名 (パラメーターを除く) 。
* `is_temporary` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブルが一時テーブルかどうかを示すフラグ。
* `data_paths` ([Array(String)](/ja/sql-reference/data-types/array)) — ファイルシステム内のテーブルデータへのパス。
* `metadata_path` ([String](/ja/sql-reference/data-types/string)) — ファイルシステム内のテーブルメタデータへのパス。
* `metadata_modification_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — テーブルメタデータの最終変更時刻。
* `metadata_version` ([Int32](/ja/sql-reference/data-types/int-uint)) — ReplicatedMergeTree テーブルのメタデータバージョン。ReplicatedMergeTree でないテーブルでは 0。
* `dependencies_database` ([Array(String)](/ja/sql-reference/data-types/array)) — データベースの依存関係。
* `dependencies_table` ([Array(String)](/ja/sql-reference/data-types/array)) — テーブルの依存関係 (現在のテーブルに依存する materialized view) 。
* `create_table_query` ([String](/ja/sql-reference/data-types/string)) — テーブルの作成に使用されたクエリ。
* `engine_full` ([String](/ja/sql-reference/data-types/string)) — テーブルエンジンのパラメーター。
* `as_select` ([String](/ja/sql-reference/data-types/string)) — ビューの SELECT クエリ。
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/ja/sql-reference/data-types/array)) — パラメーター化ビューのパラメーター。
* `partition_key` ([String](/ja/sql-reference/data-types/string)) — テーブルで指定されたパーティションキー式。
* `sorting_key` ([String](/ja/sql-reference/data-types/string)) — テーブルで指定されたソートキー式。
* `primary_key` ([String](/ja/sql-reference/data-types/string)) — テーブルで指定された主キー式。
* `sampling_key` ([String](/ja/sql-reference/data-types/string)) — テーブルで指定されたサンプリングキー式。
* `storage_policy` ([String](/ja/sql-reference/data-types/string)) — ストレージポリシー。MergeTree および Distributed エンジンを使用するテーブルに関係します。
* `total_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 総行数。テーブルの正確な行数をすばやく取得できる場合はその値を返し、そうでない場合は NULL を返します (基盤となる Buffer table を含む) 。
* `total_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 総バイト数。ストレージ上のテーブルの正確なバイト数をすばやく取得できる場合はその値を返し、そうでない場合は NULL を返します (基盤となるストレージは含みません) 。テーブルがデータをディスクに保存している場合は、ディスク上の使用容量 (つまり compressed) を返します。テーブルがデータをメモリに保存している場合は、メモリ内で使用されているおおよそのバイト数を返します。
* `total_bytes_uncompressed` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 非圧縮の総バイト数。ストレージ上のテーブルについて、パーツのチェックサムから正確なバイト数をすばやく取得できる場合はその値を返し、そうでない場合は NULL を返します (基盤となるストレージがある場合でも考慮しません) 。
* `parts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — このテーブル内のパーツの総数。
* `active_parts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — このテーブル内のアクティブなパーツ数。
* `total_marks` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — このテーブルのすべてのパーツに含まれるマークの総数。
* `active_on_fly_data_mutations` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 即時適用可能な、アクティブなデータ mutation (UPDATE および DELETE) の総数。
* `active_on_fly_alter_mutations` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 即時適用可能な、アクティブな alter mutation (MODIFY COLUMN) の総数。
* `active_on_fly_metadata_mutations` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 即時適用可能な、アクティブなメタデータ mutation (RENAME) の総数。
* `columns_descriptions_cache_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — *MergeTree テーブルのカラム説明 cache のサイズ
* `lifetime_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — サーバー起動後に INSERT された行の累計数 (Buffer table のみ) 。
* `lifetime_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — サーバー起動後に INSERT されたバイト数の累計 (Buffer table のみ) 。
* `comment` ([String](/ja/sql-reference/data-types/string)) — テーブルのコメント。
* `has_own_data` ([UInt8](/ja/sql-reference/data-types/int-uint)) — テーブル自体がディスク上にデータを保存しているか、または別のソースにアクセスするだけかを示すフラグ。
* `loading_dependencies_database` ([Array(String)](/ja/sql-reference/data-types/array)) — データベースの loading dependencies (現在の object より先にロードされるべき object の一覧) 。
* `loading_dependencies_table` ([Array(String)](/ja/sql-reference/data-types/array)) — テーブルの loading dependencies (現在の object より先にロードされるべき object の一覧) 。
* `loading_dependent_database` ([Array(String)](/ja/sql-reference/data-types/array)) — ロード時にこのデータベースに依存するデータベース。
* `loading_dependent_table` ([Array(String)](/ja/sql-reference/data-types/array)) — ロード時にこのテーブルに依存するテーブル。
* `target_database` ([String](/ja/sql-reference/data-types/string)) — materialized view の場合、ビューの書き込み先である宛先テーブルのデータベース (`TO` の対象、または暗黙的な `.inner.*` テーブル) 。他のエンジンでは空です。
* `target_table` ([String](/ja/sql-reference/data-types/string)) — materialized view の場合、ビューの書き込み先である宛先テーブルの名前 (`TO` の対象、または暗黙的な `.inner.*` テーブル) 。他のエンジンでは空です。
* `definer` ([String](/ja/sql-reference/data-types/string)) — このテーブルで使用される SQL security definer の名前。

**別名:**

* `table` — `name` の別名。

{/*AUTOGENERATED_END*/ }
