<div id="description">
  ## 説明
</div>

[S3Queue](../../engines/table-engines/integrations/s3queue.md) テーブルの設定に関する情報が含まれています。サーバーのバージョン `24.10` 以降で利用できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — S3Queue engine を持つテーブルのデータベース。
* `table` ([String](/ja/sql-reference/data-types/string)) — S3Queue engine を持つテーブルの名前。
* `name` ([String](/ja/sql-reference/data-types/string)) — 設定名。
* `value` ([String](/ja/sql-reference/data-types/string)) — 設定値。
* `type` ([String](/ja/sql-reference/data-types/string)) — 設定の種類 (実装固有の文字列値) 。
* `changed` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 設定が config で明示的に定義されている、または明示的に変更されている場合は 1。
* `description` ([String](/ja/sql-reference/data-types/string)) — 設定の説明。
* `alterable` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 現在のユーザーが ALTER TABLE MODIFY SETTING を通じて設定を変更できるかどうかを示します: 0 — 現在のユーザーは設定を変更できません。1 — 現在のユーザーは設定を変更できます。

{/*AUTOGENERATED_END*/ }
