<div id="purpose">
  ## 説明
</div>

[MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) テーブルのデタッチされたパーツに関する情報が含まれています。`reason` カラムには、そのパーツがデタッチされた理由が示されます。

ユーザーによってデタッチされたパーツでは、理由は空欄です。これらのパーツは、[ALTER TABLE ATTACH PARTITION|PART](/ja/sql-reference/statements/alter/partition#attach-partitionpart) コマンドでアタッチできます。

その他のカラムの説明については、[system.parts](../../operations/system-tables/parts.md) を参照してください。

パーツ名が無効な場合、一部のカラムの値が `NULL` になることがあります。これらのパーツは、[ALTER TABLE DROP DETACHED PART](/ja/sql-reference/statements/alter/partition#drop-detached-partitionpart) で削除できます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — このパーツが属するデータベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — このパーツが属するテーブルの名前。
* `partition_id` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — このパーツが属するパーティションの識別子。
* `name` ([String](/ja/sql-reference/data-types/string)) — このパーツの名前。
* `bytes_on_disk` ([UInt64](/ja/sql-reference/data-types/int-uint)) — すべてのデータパーツファイルの合計サイズ (バイト単位) 。
* `modification_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツを含むディレクトリが変更された時刻。通常、これはデタッチが発生した時刻に対応します。
* `disk` ([String](/ja/sql-reference/data-types/string)) — このデータパーツを保存しているディスクの名前。
* `path` ([String](/ja/sql-reference/data-types/string)) — このデータパーツのファイルがあるディスク上のパス。
* `reason` ([Nullable(String)](/ja/sql-reference/data-types/nullable)) — このパーツがデタッチされた理由の説明。
* `min_block_number` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — マージ後の現在のパーツを構成するデータパーツの最小番号。
* `max_block_number` ([Nullable(Int64)](/ja/sql-reference/data-types/nullable)) — マージ後の現在のパーツを構成するデータパーツの最大番号。
* `level` ([Nullable(UInt32)](/ja/sql-reference/data-types/nullable)) — マージツリーの深さ。0 は、現在のパーツが他のパーツのマージではなく、insert によって作成されたことを意味します。

{/*AUTOGENERATED_END*/ }
