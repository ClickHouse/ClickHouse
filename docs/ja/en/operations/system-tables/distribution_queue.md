<div id="description">
  ## 説明
</div>

分片に送信されるのを待っているキュー内のローカルファイルに関する情報が含まれます。これらのローカルファイルには、非同期モードで Distributed テーブルに新しいデータを挿入した際に作成される新しいパーツが含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `data_path` ([String](/ja/sql-reference/data-types/string)) — ローカルファイルが格納されているフォルダーへのパス。
* `is_blocked` ([UInt8](/ja/sql-reference/data-types/int-uint)) — ローカルファイルのサーバーへの送信がブロックされているかどうかを示すフラグ。
* `error_count` ([UInt64](/ja/sql-reference/data-types/int-uint)) — エラーの数。
* `data_files` ([UInt64](/ja/sql-reference/data-types/int-uint)) — フォルダー内のローカルファイルの数。
* `data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ローカルファイル内の圧縮データのサイズ (バイト単位) 。
* `broken_data_files` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 破損としてマークされたファイルの数 (エラーが原因) 。
* `broken_data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 破損ファイル内の圧縮データのサイズ (バイト単位) 。
* `last_exception` ([String](/ja/sql-reference/data-types/string)) — 最後に発生したエラーに関するテキストメッセージ (存在する場合) 。
* `last_exception_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — 最後に例外が発生した時刻。

{/*AUTOGENERATED_END*/ }
