<div id="description">
  ## 説明
</div>

S3Queue のメタデータのインメモリ状態と、ファイルごとに現在処理中の行が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/ja/sql-reference/data-types/string)) — ZooKeeper 内でメタデータを指すパス
* `file_path` ([String](/ja/sql-reference/data-types/string)) — 処理中のファイルのファイルパス
* `file_name` ([String](/ja/sql-reference/data-types/string)) — 処理中のファイルのファイル名
* `rows_processed` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 現在処理中の行数
* `status` ([String](/ja/sql-reference/data-types/string)) — 処理のステータス: Processed、Processing、Failed
* `processing_start_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — ファイルの処理が開始された時刻
* `processing_end_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — ファイルの処理が終了した時刻
* `exception` ([String](/ja/sql-reference/data-types/string)) — 処理中に発生した例外

{/*AUTOGENERATED_END*/ }
