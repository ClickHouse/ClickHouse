<div id="description">
  ## 説明
</div>

設定されている[ロール](../../guides/sre/user-management/index.md#role-management)に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — ロール名。
* `id` ([UUID](/ja/sql-reference/data-types/uuid)) — ロール ID。
* `storage` ([String](/ja/sql-reference/data-types/string)) — ロールの保存先へのパス。`access_control_path` パラメーターで設定されます。

{/*AUTOGENERATED_END*/ }
