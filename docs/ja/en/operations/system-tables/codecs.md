<div id="description">
  ## 説明
</div>

圧縮および暗号化コーデックに関する情報が含まれています。

このテーブルを使用すると、利用可能な圧縮および暗号化コーデックの情報を確認できます

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — コーデック名。
* `method_byte` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 圧縮ファイル内でコーデックを示すバイト。
* `is_compression` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコーデックが何らかの圧縮を行う場合は true。それ以外の場合は、圧縮を補助する単なる変換であることがあります。
* `is_generic_compression` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコーデックが、lz4 や zstd のような汎用圧縮アルゴリズムであることを示します。
* `is_encryption` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコーデックが暗号化を行うことを示します。
* `is_timeseries_codec` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコーデックが、浮動小数点の時系列データ向けのコーデックであることを示します。
* `is_experimental` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このコーデックが実験的機能であることを示します。
* `description` ([String](/ja/sql-reference/data-types/string)) — コーデックの概要説明。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT * FROM system.codecs WHERE name='LZ4'
```

```text title="Response"

```
