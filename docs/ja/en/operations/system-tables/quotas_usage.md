<div id="description">
  ## 説明
</div>

全ユーザーのクォータ使用状況。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/ja/sql-reference/data-types/string)) — クォータ名。
* `quota_key` ([String](/ja/sql-reference/data-types/string)) — キー値。
* `is_current` ([UInt8](/ja/sql-reference/data-types/int-uint)) — 現在のユーザーのクォータ使用状況。
* `start_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — リソース消費量の計算開始時刻。
* `end_time` ([Nullable(DateTime)](/ja/sql-reference/data-types/nullable)) — リソース消費量の計算終了時刻。
* `duration` ([Nullable(UInt32)](/ja/sql-reference/data-types/nullable)) — リソース消費量の計算対象となる時間間隔の長さ (秒単位) 。
* `queries` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在実行されたクエリの数。
* `max_queries` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行が許可される全種類のクエリの最大数。
* `query_selects` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在実行された SELECT クエリの数。
* `max_query_selects` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行が許可される SELECT クエリの最大数。
* `query_inserts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在実行された INSERT クエリの数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 実行が許可される INSERT クエリの最大数。
* `errors` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在エラーとなっているクエリの数。
* `max_errors` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、エラーとなったクエリの最大数。
* `result_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの結果セット内の行の現在の合計数。
* `max_result_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セット内の行の合計最大数。
* `result_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの結果セット内の現在の合計バイト数。
* `max_result_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セット内の合計最大バイト数。
* `read_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの実行中に読み取られた行の現在の合計数。
* `max_read_rows` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取れる行の最大数。
* `read_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの実行中に読み取られた現在の合計バイト数。
* `max_read_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取れるバイト数の最大値。
* `execution_time` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内にクエリの実行に費やされた時間の現在の合計 (ナノ秒単位)
* `max_execution_time` ([Nullable(Float64)](/ja/sql-reference/data-types/nullable)) — 指定期間内にすべてのクエリの実行に許可される時間の最大値 (ナノ秒単位)
* `written_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、すべてのクエリの実行中に書き込まれた現在の合計バイト数。
* `max_written_bytes` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、すべてのクエリの実行中に書き込まれる最大バイト数。
* `failed_sequential_authentications` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、連続した認証失敗の現在の回数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、連続した認証失敗の最大回数。
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 現在の期間内における、任意の単一の正規化クエリの現在の最大実行回数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/sql-reference/data-types/nullable)) — 指定された期間内に許可される、任意の単一の正規化クエリの最大実行回数。
