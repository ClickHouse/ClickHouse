<div id="description">
  ## 説明
</div>

サーバーでサポートされている Dictionary ソースの一覧と、各ソースに対応する組み込みドキュメントが含まれています。Dictionary ソースは、Dictionary データの読み込み元を決定するもので、`CREATE DICTIONARY` クエリの `SOURCE` 句で指定します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/ja/sql-reference/data-types/string)) — `SOURCE` 句で指定する Dictionary ソースの名前。
* `description` ([String](/ja/sql-reference/data-types/string)) — その Dictionary ソースの役割の概要。
* `syntax` ([String](/ja/sql-reference/data-types/string)) — ソースを指定するための `SOURCE` 句の構文。Dictionary を DDL クエリから作成する場合 (サーバー設定ファイルから作成する場合とは異なり) 、一部のソースはアクセス制御の対象となる点に注意してください。詳細については、各ソースの `description` を参照してください。
* `examples` ([String](/ja/sql-reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/sql-reference/data-types/string)) — そのソースが最初に導入された ClickHouse のバージョン。形式は major.minor です。
* `related` ([Array](/ja/sql-reference/data-types/array)([String](/ja/sql-reference/data-types/string))) — 関連する Dictionary ソースの名前。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT name, syntax
FROM system.dictionary_sources
WHERE name IN ('clickhouse', 'file')
ORDER BY name
```

```text title="Response"
┌─name───────┬─syntax─────────────────────────────────────────────────────────────────────────┐
│ clickhouse │ SOURCE(CLICKHOUSE(host 'host' port 9000 user 'default' password '' db 'db' table 'table')) │
│ file       │ SOURCE(FILE(path '/path/to/file' format 'CSV'))                                  │
└────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
