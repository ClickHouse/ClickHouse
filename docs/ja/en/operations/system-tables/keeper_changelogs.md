<div id="description">
  ## 説明
</div>

このテーブルは、このノードがプロセス内 ClickHouse Keeper を実行するように設定されていない場合は存在しません。プロセス内 Keeper log store によって追跡される各 Raft changelog ファイル (`changelog_<from>_<to>.bin[.zstd]`) ごとに 1 行が含まれ、現在追記中の アクティブファイル も含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `from_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ファイル内の最初の Raft ログ索引 (含む) 。
* `to_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ファイル名が表す最後の Raft ログ索引 (含む) 。アクティブファイルでは、これはローテーション先の値であり、`last_entry_index` より先になる場合があります。
* `last_entry_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — 実際にこのファイルに追記されたログ索引の最大値。アクティブファイルがまだエントリを受信していない場合、またはファイルが破損している場合は `NULL` です。
* `entries` ([UInt64](../../sql-reference/data-types/int-uint.md)) — このファイルに追記されたエントリ数。`ifNull(last_entry_index - from_log_index + 1, 0)` の `ALIAS`。
* `path` ([String](../../sql-reference/data-types/string.md)) — ディスク上のファイルパス。
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — ファイルを保持しているディスクの名前。
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — ディスク上のファイルサイズ。
* `modification_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — ファイルの最終更新時刻。
* `is_compressed` ([Bool](../../sql-reference/data-types/boolean.md)) — ファイルの payload が zstd で圧縮されているかどうか。
* `active` ([Bool](../../sql-reference/data-types/boolean.md)) — このファイルに現在追記中かどうか。
* `is_broken` ([Bool](../../sql-reference/data-types/boolean.md)) — 起動時に末尾レコードの破損が検出されたかどうか。

{/*AUTOGENERATED_END*/ }

例:

```sql
SELECT from_log_index, to_log_index, entries, path, active FROM system.keeper_changelogs ORDER BY from_log_index;
```

```text
┌─from_log_index─┬─to_log_index─┬─entries─┬─path───────────────────────────┬─active─┐
│              1 │         1000 │    1000 │ changelog_1_1000.bin.zstd      │ false  │
│           1001 │         2000 │     537 │ changelog_1001_2000.bin.zstd   │ true   │
└────────────────┴──────────────┴─────────┴────────────────────────────────┴────────┘
```
