<div id="description">
  ## 説明
</div>

このテーブルには、[MergeTree](/ja/engines/table-engines/mergetree-family/mergetree.md) テーブルで進行中の [データパート の移動](/ja/sql-reference/statements/alter/partition#move-partitionpart) に関する情報が含まれています。各 データパート の移動は 1 行で表されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/ja/sql-reference/data-types/string)) — データベースの名前。
* `table` ([String](/ja/sql-reference/data-types/string)) — 移動中の データパート を含むテーブルの名前。
* `elapsed` ([Float64](/ja/sql-reference/data-types/float)) — データパート の移動開始からの経過時間 (秒) 。
* `target_disk_name` ([String](/ja/sql-reference/data-types/string)) — データパート の移動先のディスク名。
* `target_disk_path` ([String](/ja/sql-reference/data-types/string)) — ファイルシステム内のディスクのマウントポイントへのパス。
* `part_name` ([String](/ja/sql-reference/data-types/string)) — 移動中の データパート の名前。
* `part_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパート のサイズ。
* `thread_id` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 移動を実行するスレッドの識別子。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT * FROM system.moves
```

```response
└──────────┴───────┴─────────────┴──────────────────┴──────────────────┴───────────┴───────────┴───────────┘
```
