<div id="description">
  ## 説明
</div>

DROP TABLE が実行されたものの、まだデータのクリーンアップが行われていないテーブルに関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt32](/ja/sql-reference/data-types/int-uint)) — marked&#95;dropped&#95;tables キュー内の索引。
* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — テーブルの UUID。
* `engine` ([String](/ja/sql-reference/data-types/string)) — テーブルエンジン名。
* `metadata_dropped_path` ([String](/ja/sql-reference/data-types/string)) — metadata&#95;dropped ディレクトリ内にあるテーブルのメタデータファイルのパス。
* `table_dropped_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — テーブルデータの削除を次に試行する予定時刻。通常は、テーブルが削除された時刻に `database_atomic_delay_before_drop_table_sec` を加えた時刻です。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

次の例では、`dropped_tables` の情報を取得する方法を示します。

```sql
SELECT *
FROM system.dropped_tables\G
```

