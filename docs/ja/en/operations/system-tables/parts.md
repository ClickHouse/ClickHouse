<div id="description">
  ## 説明
</div>

[MergeTree](../../engines/table-engines/mergetree-family/mergetree.md) テーブルのパーツに関する情報が含まれています。

各行は 1 つのデータパーツを表します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/ja/sql-reference/data-types/string)) — パーティション識別子 (テーブルのパーティションキー式から導かれる文字列表現) 。
* `name` ([String](/ja/sql-reference/data-types/string)) — データパートの名前。パートの命名構造から、データの内容や、取り込み・マージのパターンに関するさまざまな情報を判断できます。パートの命名フォーマットは次のとおりです。

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * 定義:
    * `partition_id` - パーティションキーを識別します
    * `minimum_block_number` - パーツ内の最小ブロック番号を識別します。ClickHouse は常に連続したブロックをマージします
    * `maximum_block_number` - パーツ内の最大ブロック番号を識別します
    * `level` - パーツに対して追加のマージが行われるたびに 1 ずつ増加します。`level` が 0 の場合、これはまだマージされていない新しいパーツであることを示します。ClickHouse のすべてのパーツは常に不変であることを覚えておくことが重要です
    * `data_version` - 任意の値で、パーツにミューテーションが適用されると増加します (繰り返しになりますが、パーツは不変であるため、ミューテーションされたデータも常に新しいパーツにのみ書き込まれます)
* `uuid` ([UUID](/ja/sql-reference/data-types/uuid)) — データパーツの UUID。
* `part_type` ([String](/ja/sql-reference/data-types/string)) — データパーツの保存フォーマット。設定可能な値: `Wide` — 各カラムが個別のファイルに保存されます。`Compact` — すべてのカラムが 1 つのファイルに保存されます。データの保存フォーマットは、MergeTree テーブルの `min_bytes_for_wide_part` および `min_rows_for_wide_part` 設定で制御されます。
* `active` ([UInt8](/ja/sql-reference/data-types/int-uint)) — データパーツがアクティブかどうかを示すフラグ。データパーツがアクティブな場合はテーブルで使用されます。そうでない場合は、削除対象です。非アクティブなデータパーツは、マージ操作および変更操作の後に現れます。
* `marks` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マーク数。データパーツ内のおおよその行数を求めるには、marks に index granularity (通常は 8192) を掛けます (この方法は adaptive granularity では機能しません) 。
* `rows` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 行数。
* `files` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のファイル数。
* `bytes_on_disk` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のすべてのファイルの合計サイズ (バイト単位) 。
* `data_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内の圧縮データの合計サイズ。補助ファイル (たとえば、マークファイル) は含まれません。
* `data_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内の非圧縮データの合計サイズ。補助ファイル (たとえば、マークファイル) は含まれません。
* `primary_key_size` ([UInt64](/ja/sql-reference/data-types/int-uint)) — ディスク上の primary.idx/cidx ファイル内で主キーの値が使用するメモリ量 (バイト単位) 。
* `marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — マークファイルのサイズ。
* `secondary_indices_compressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のセカンダリ索引の圧縮データの合計サイズ。補助ファイル (たとえば、マークファイル) は含まれません。
* `secondary_indices_uncompressed_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパーツ内のセカンダリ索引の非圧縮データの合計サイズ。補助ファイル (たとえば、マークファイル) は含まれません。
* `secondary_indices_marks_bytes` ([UInt64](/ja/sql-reference/data-types/int-uint)) — セカンダリ索引のマークファイルのサイズ。
* `modification_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツを含むディレクトリが変更された時刻。通常、これはデータパーツの作成時刻に対応します。
* `remove_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツが非アクティブになった時刻。
* `refcount` ([UInt32](/ja/sql-reference/data-types/int-uint)) — データパーツが使用されている箇所の数。値が 2 より大きい場合、そのデータパーツはクエリまたはマージで使用されています。
* `min_date` ([Date](/ja/sql-reference/data-types/date)) — データパーツ内の日付キーの最小値。
* `max_date` ([Date](/ja/sql-reference/data-types/date)) — データパーツ内の日付キーの最大値。
* `min_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最小値。
* `max_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最大値。
* `partition_id` ([String](/ja/sql-reference/data-types/string)) — パーティションの ID。
* `min_block_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最小番号。
* `max_block_number` ([Int64](/ja/sql-reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最大番号。
* `level` ([UInt32](/ja/sql-reference/data-types/int-uint)) — マージツリーの深さ。0 は、現在のパーツが他のパーツのマージではなく insert によって作成されたことを意味します。
* `data_version` ([UInt64](/ja/sql-reference/data-types/int-uint)) — データパートにどのミューテーションを適用するかを判定するための番号です (`data_version` より大きいバージョンのミューテーション) 。
* `primary_key_bytes_in_memory` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 主キー値が使用するメモリ量 (バイト単位) 。`primary_key_lazy_load` が有効で、かつキーが読み込まれていない場合は 0 になります。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — 主キー値のために確保されているメモリ量 (バイト単位) 。`primary_key_lazy_load` が有効で、かつキーが読み込まれていない場合は 0 になります。
* `index_granularity_bytes_in_memory` ([UInt64](/ja/sql-reference/data-types/int-uint)) — インデックス粒度の値が使用するメモリ量 (バイト単位) です (`primary_key_lazy_load=1` かつ `use_primary_key_cache=1` の場合は 0 になります) 。
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ja/sql-reference/data-types/int-uint)) — インデックス粒度の値のために確保されているメモリ量 (バイト単位) です (`primary_key_lazy_load=1` かつ `use_primary_key_cache=1` の場合は 0 になります) 。
* `is_frozen` ([UInt8](/ja/sql-reference/data-types/int-uint)) — パーティションのデータバックアップが存在することを示すフラグです。1 はバックアップが存在することを、0 はバックアップが存在しないことを示します。詳細は FREEZE PARTITION を参照してください。
* `database` ([String](/ja/sql-reference/data-types/string)) — データベース名。
* `table` ([String](/ja/sql-reference/data-types/string)) — テーブル名。
* `engine` ([String](/ja/sql-reference/data-types/string)) — パラメーターを含まないテーブルエンジン名。
* `disk_name` ([String](/ja/sql-reference/data-types/string)) — データパートを格納しているディスク名。
* `path` ([String](/ja/sql-reference/data-types/string)) — データパートのファイルがあるフォルダーへの絶対パス。
* `hash_of_all_files` ([String](/ja/sql-reference/data-types/string)) — 圧縮ファイルの sipHash128。
* `hash_of_uncompressed_files` ([String](/ja/sql-reference/data-types/string)) — 非圧縮ファイル (mark ファイル、インデックスファイルなど) の sipHash128。
* `uncompressed_hash_of_compressed_files` ([String](/ja/sql-reference/data-types/string)) — 圧縮ファイル内のデータを、非圧縮であるかのように扱った場合の sipHash128。
* `delete_ttl_info_min` ([DateTime](/ja/sql-reference/data-types/datetime)) — TTL DELETE ルールの日付と時刻キーの最小値。
* `delete_ttl_info_max` ([DateTime](/ja/sql-reference/data-types/datetime)) — TTL DELETE ルールの日付と時刻キーの最大値。
* `move_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — 式の Array。各式は TTL MOVE ルールを定義します。
* `move_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — 日付と時刻の値の Array。各要素は TTL MOVE ルールのキー値の最小値を表します。
* `move_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — 日付と時刻の値の Array。各要素は TTL MOVE ルールのキー値の最大値を表します。
* `default_compression_codec` ([String](/ja/sql-reference/data-types/string)) — このデータパートの圧縮に使用される codec の名前です (カラムに明示的な codec が指定されていない場合) 。
* `recompression_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — TTL 式。
* `recompression_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された TTL 式の最小値です。少なくとも 1 行で TTL の有効期限が切れているかどうかを把握するために使用されます。
* `recompression_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された TTL 式の最大値です。すべての行で TTL の有効期限が切れているかどうかを把握するために使用されます。
* `group_by_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — TTL 式。
* `group_by_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された TTL 式の最小値です。少なくとも 1 行で TTL の有効期限が切れているかどうかを把握するために使用されます。
* `group_by_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された有効期限 (TTL) 式の最大値。TTL が期限切れのすべての行が含まれているかどうかを判断するために使用されます。
* `rows_where_ttl_info.expression` ([Array(String)](/ja/sql-reference/data-types/array)) — 有効期限 (TTL) 式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された有効期限 (TTL) 式の最小値。TTL が期限切れの行が少なくとも 1 つ含まれているかどうかを判断するために使用されます。
* `rows_where_ttl_info.max` ([Array(DateTime)](/ja/sql-reference/data-types/array)) — このパート内で計算された有効期限 (TTL) 式の最大値。TTL が期限切れのすべての行が含まれているかどうかを判断するために使用されます。
* `projections` ([Array(String)](/ja/sql-reference/data-types/array)) — このパートに対して計算されたプロジェクション名の一覧。
* `visible` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このパートが SELECT クエリに対して可視かどうかを示すフラグ。
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ja/sql-reference/data-types/tuple)) — このオブジェクトを作成した、または作成しようとしているトランザクションの ID。
* `removal_tid_lock` ([UInt64](/ja/sql-reference/data-types/int-uint)) — `removal_tid` のハッシュ。削除のためにオブジェクトをロックする際に使用されます。
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ja/sql-reference/data-types/tuple)) — このオブジェクトを削除した、または削除しようとしているトランザクションの ID
* `creation_csn` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このオブジェクトを作成したトランザクションの CSN
* `removal_csn` ([UInt64](/ja/sql-reference/data-types/int-uint)) — このオブジェクトを削除したトランザクションの CSN
* `has_lightweight_delete` ([UInt8](/ja/sql-reference/data-types/int-uint)) — このパートが論理削除マスクを持つかどうかを示すフラグ。
* `last_removal_attempt_time` ([DateTime](/ja/sql-reference/data-types/datetime)) — サーバーがこのパートの削除を最後に試みた時刻。
* `removal_state` ([String](/ja/sql-reference/data-types/string)) — パートの削除プロセスの現在の状態。

**別名:**

* `bytes` — `bytes_on_disk` の別名です。
* `marks_size` — `marks_bytes` の別名です。
* `part_name` — `name` の別名です。
