<div id="description">
  ## 説明
</div>

[HTTPインターフェイス](/ja/interfaces/http) からアクセスできる `/dashboard` ページで使用されるクエリが格納されています。
このテーブルは、監視やトラブルシューティングに役立ちます。ダッシュボード内の各チャートごとに1行が含まれています。

:::note
`/dashboard` ページでは、`system.dashboards` のクエリだけでなく、同じスキーマを持つ任意のテーブルのクエリも表示できます。
これは、カスタムダッシュボードの作成に便利です。
:::

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/ }

* `dashboard` ([String](/ja/sql-reference/data-types/string)) — ダッシュボードの名前。
* `title` ([String](/ja/sql-reference/data-types/string)) — チャートのタイトル。
* `query` ([String](/ja/sql-reference/data-types/string)) — 表示するデータを取得するためのクエリ。

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## 例
</div>

```sql
SELECT *
FROM system.dashboards
WHERE title ILIKE '%CPU%'
```
