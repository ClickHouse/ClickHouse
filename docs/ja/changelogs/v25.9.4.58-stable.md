<div id="improvement">
  #### 改善

* [#88480](https://github.com/ClickHouse/ClickHouse/issues/88480) でバックポート: バックアップ宛先へのサーバー側 (native) コピーで、バックアップ固有の設定 (たとえば `backup_slow_all_threads_after_retryable_s3_error`) を使用する S3 ストレージクライアントを使うようにしました。`s3_slow_all_threads_after_retryable_error` は廃止されました。[#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva))。
* [#88302](https://github.com/ClickHouse/ClickHouse/issues/88302) でバックポート: コピー機能およびコンテナー作成機能で発生していた &#39;Content-Length&#39; の問題の修正を含むよう、azure sdk を更新しました。[#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni))。
* [#88783](https://github.com/ClickHouse/ClickHouse/issues/88783) でバックポート: `GLOBAL IN` によるメモリリークを修正しました ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)) 。[#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94))。
* [#88766](https://github.com/ClickHouse/ClickHouse/issues/88766) でバックポート: `clickhouse-keeper` の postinstall スクリプトに、起動時に自動開始できるようにするステップを追加しました。[#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#88226](https://github.com/ClickHouse/ClickHouse/issues/88226) でバックポート: `AggregateFunction(quantileDD)` カラムに対してユーザーが送信した一部の有効なデータにより、マージが無限再帰してクラッシュする不具合を修正しました。[#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* [#88229](https://github.com/ClickHouse/ClickHouse/issues/88229) でバックポート: row policy がある場合に動作しなかった move-to-prewhere optimization を修正しました。[#85118](https://github.com/ClickHouse/ClickHouse/issues/85118) の続きです。[#69777](https://github.com/ClickHouse/ClickHouse/issues/69777) をクローズ。[#83748](https://github.com/ClickHouse/ClickHouse/issues/83748) をクローズ。[#87303](https://github.com/ClickHouse/ClickHouse/pull/87303) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#88391](https://github.com/ClickHouse/ClickHouse/issues/88391) でバックポート: AzureBlobStorage で、まずネイティブコピーを試し、&#39;Unauthroized&#39; エラー時には read &amp; write にフォールバックするよう更新しました (AzureBlobStorage では、ソースと宛先で storage account が異なると &#39;Unauthorized&#39; エラーが発生します) 。また、構成で endpoint が定義されている場合に &quot;use&#95;native&#95;copy&quot; が適用されるよう修正しました。[#87826](https://github.com/ClickHouse/ClickHouse/pull/87826) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#88692](https://github.com/ClickHouse/ClickHouse/issues/88692) でバックポート: 引数の型が GROUP BY で許可されていない場合は、GROUP BY から単射関数を削除しないよう修正しました。[#87958](https://github.com/ClickHouse/ClickHouse/pull/87958) ([Pavel Kruglov](https://github.com/Avogar)).
* [#88438](https://github.com/ClickHouse/ClickHouse/issues/88438) でバックポート: クエリで `session_timezone` 設定を使用した際に、日時ベースのキーに対する granules/パーティション の除外が誤っていた不具合を修正しました。[#87987](https://github.com/ClickHouse/ClickHouse/pull/87987) ([Eduard Karacharov](https://github.com/korowa)).
* [#88422](https://github.com/ClickHouse/ClickHouse/issues/88422) でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/84503](https://github.com/ClickHouse/ClickHouse/pull/84503) で導入された grants チェックについて、評価前に URI の正規化を適用するようにしました。[#88089](https://github.com/ClickHouse/ClickHouse/pull/88089) ([pufit](https://github.com/pufit)).
* [#88176](https://github.com/ClickHouse/ClickHouse/issues/88176) でバックポート: 無効なテーブルがアタッチされた外部 database (`PostgreSQL`/`SQLite`/...) がある状態で `system.tables` を読み取る際に、uncaught exception が発生する可能性がある不具合を修正しました。[#88105](https://github.com/ClickHouse/ClickHouse/pull/88105) ([Azat Khuzhin](https://github.com/azat)).
* [#88258](https://github.com/ClickHouse/ClickHouse/issues/88258) でバックポート: クラスター内に非アクティブなレプリカがある場合、`ON CLUSTER` クエリにかかる時間が短くなりました。[#88153](https://github.com/ClickHouse/ClickHouse/pull/88153) ([alesapin](https://github.com/alesapin)).
* [#88208](https://github.com/ClickHouse/ClickHouse/issues/88208) でバックポート: cgroups なしで ClickHouse を実行できるよう修正しました (意図せず、cgroups が非同期メトリクスの要件になっていました) 。[#88164](https://github.com/ClickHouse/ClickHouse/pull/88164) ([Azat Khuzhin](https://github.com/azat)).
* [#88285](https://github.com/ClickHouse/ClickHouse/issues/88285) でバックポート: `ColumnLowCardinality` における `is_shared` フラグの伝播を修正しました。`ReverseIndex` 内でハッシュ値がすでに事前計算されてキャッシュされた後にカラムへ新しい値が挿入されると、誤った GROUP BY 結果につながる可能性がありました。[#88213](https://github.com/ClickHouse/ClickHouse/pull/88213) ([Nikita Taranov](https://github.com/nickitat)).
* [#88461](https://github.com/ClickHouse/ClickHouse/issues/88461) でバックポート: ワークロード設定 `max_cpu_share` を修正しました。これにより、ワークロード設定 `max_cpus` が設定されていなくても使用できるようになりました。[#88217](https://github.com/ClickHouse/ClickHouse/pull/88217) ([Neerav](https://github.com/neeravsalaria))。
* [#88338](https://github.com/ClickHouse/ClickHouse/issues/88338) でバックポート: 相関サブクエリがオブジェクトストレージでも動作するようになりました。[#88290](https://github.com/ClickHouse/ClickHouse/pull/88290) ([alesapin](https://github.com/alesapin))。
* [#88358](https://github.com/ClickHouse/ClickHouse/issues/88358) でバックポート: `system.projections` および `system.data_skipping_indices` へのアクセス時に DataLake データベースの初期化を試みないようにしました。[#88330](https://github.com/ClickHouse/ClickHouse/pull/88330) ([Azat Khuzhin](https://github.com/azat))。
* [#88432](https://github.com/ClickHouse/ClickHouse/issues/88432) でバックポート: `countMatches` 関数の二次計算量の問題を修正しました。[#88400](https://github.com/ClickHouse/ClickHouse/issues/88400) をクローズしました。[#88401](https://github.com/ClickHouse/ClickHouse/pull/88401) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#88650](https://github.com/ClickHouse/ClickHouse/issues/88650) でバックポート: ノード数が 10 を超える大規模なクラスターでは、`[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again` というエラーにより restore が失敗する可能性が高くなっていました。`num_hosts` ノードが多数のホストによって同時に上書きされていたためです。この修正により、試行回数を制御する設定が動的になりました。[#87721](https://github.com/ClickHouse/ClickHouse/issues/87721) をクローズしました。[#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* [#88629](https://github.com/ClickHouse/ClickHouse/issues/88629) でバックポート: タプル型に対する coalescing merge tree を修正しました。これにより [#88469](https://github.com/ClickHouse/ClickHouse/issues/88469) をクローズしました。[#88526](https://github.com/ClickHouse/ClickHouse/pull/88526) ([scanhex12](https://github.com/scanhex12))。
* [#88718](https://github.com/ClickHouse/ClickHouse/issues/88718) でバックポート: 基盤となる const PREWHERE カラムの同時 mutation によって発生しうるクラッシュを修正しました。[#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat))。
* [#88837](https://github.com/ClickHouse/ClickHouse/issues/88837) でバックポート: 非同期ロギングが失敗した場合に例外を捕捉し、プログラムの異常終了を防ぐようにしました。[#88814](https://github.com/ClickHouse/ClickHouse/pull/88814) ([Raúl Marín](https://github.com/Algunenano))。
