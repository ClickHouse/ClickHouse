<div id="improvement">
  #### 改善
</div>

* [#86880](https://github.com/ClickHouse/ClickHouse/issues/86880) にバックポート: Delta Lake で挿入される data files に対する行数/バイト数の上限を追加しました。`delta_lake_insert_max_rows_in_data_file` および `delta_lake_insert_max_bytes_in_data_file` の Settings で制御されます。[#86357](https://github.com/ClickHouse/ClickHouse/pull/86357) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#86734](https://github.com/ClickHouse/ClickHouse/issues/86734) にバックポート: メタデータが破損したカタログに対して `SYSTEM DROP REPLICA` を実行した場合に発生するエラーを修正しました。[#86391](https://github.com/ClickHouse/ClickHouse/pull/86391) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#87026](https://github.com/ClickHouse/ClickHouse/issues/87026) にバックポート: race condition により multipart upload 中に元の Exception が失われた際に発生する、誤解を招く「specified upload does not exist」エラーを修正しました。[#86725](https://github.com/ClickHouse/ClickHouse/pull/86725) ([Julia Kartseva](https://github.com/jkartseva)).
* [#86817](https://github.com/ClickHouse/ClickHouse/issues/86817) にバックポート: Keeper における RemoveRecursive リクエストのパフォーマンスを改善しました。[#86789](https://github.com/ClickHouse/ClickHouse/pull/86789) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#86702](https://github.com/ClickHouse/ClickHouse/issues/86702) にバックポート: Parquet file の書き込み時に、Iceberg の source id と Parquet 名の対応関係がスキーマに合わせて調整されていませんでした。この PR では、現在のスキーマではなく、各 Iceberg data file に対応するスキーマを処理します。[#85829](https://github.com/ClickHouse/ClickHouse/pull/85829) ([Daniil Ivanik](https://github.com/divanik))。
* [#86959](https://github.com/ClickHouse/ClickHouse/issues/86959) にバックポート: 他のカラムの materialized expression で使用されているサブカラムを持つカラムに対する alter update を修正しました。従来は、式にサブカラムを含む materialized column が正しく更新されていませんでした。[#85985](https://github.com/ClickHouse/ClickHouse/pull/85985) ([Pavel Kruglov](https://github.com/Avogar))。
* [#86695](https://github.com/ClickHouse/ClickHouse/issues/86695) にバックポート: サブカラムが PK またはパーティション式で使用されているカラムの alter を禁止しました。[#86005](https://github.com/ClickHouse/ClickHouse/pull/86005) ([Pavel Kruglov](https://github.com/Avogar))。
* [#86519](https://github.com/ClickHouse/ClickHouse/issues/86519) にバックポート: Delta Lake ストレージで、default 以外の column mapping mode を使用した場合のサブカラム読み取りの不具合を修正しました。[#86064](https://github.com/ClickHouse/ClickHouse/pull/86064) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#87012](https://github.com/ClickHouse/ClickHouse/issues/87012) にバックポート: UB を除去し、Iceberg のパーティション式のパースに関する問題を修正しました。[#86166](https://github.com/ClickHouse/ClickHouse/pull/86166) ([Daniil Ivanik](https://github.com/divanik))。
* [#86949](https://github.com/ClickHouse/ClickHouse/issues/86949) にバックポート: LowCardinality(Nullable(T)) から Dynamic への cast を修正しました。[#86365](https://github.com/ClickHouse/ClickHouse/pull/86365) ([Pavel Kruglov](https://github.com/Avogar))。
* [#86879](https://github.com/ClickHouse/ClickHouse/issues/86879) にバックポート: Delta Lake への書き込み中に発生する論理エラーを修正しました。[#86175](https://github.com/ClickHouse/ClickHouse/issues/86175) をクローズしました。[#86367](https://github.com/ClickHouse/ClickHouse/pull/86367) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#86719](https://github.com/ClickHouse/ClickHouse/issues/86719) にバックポート: GROUP BY Nullable(JSON) を修正しました。[#86410](https://github.com/ClickHouse/ClickHouse/pull/86410) ([Pavel Kruglov](https://github.com/Avogar))。
* [#87088](https://github.com/ClickHouse/ClickHouse/issues/87088) にバックポート: サイズ 0 の part file を含むクエリで Backup DB エンジンが例外を発生させる問題を修正しました。[#86563](https://github.com/ClickHouse/ClickHouse/pull/86563) ([Max Justus Spransy](https://github.com/maxjustus))。
* [#86875](https://github.com/ClickHouse/ClickHouse/issues/86875) にバックポート: send&#95;chunk&#95;header が有効で、UDF が HTTP プロトコル経由で呼び出される場合に、chunk header が欠落する問題を修正しました。[#86606](https://github.com/ClickHouse/ClickHouse/pull/86606) ([Vladimir Cherkasov](https://github.com/vdimir))。
* [#86874](https://github.com/ClickHouse/ClickHouse/issues/86874) でバックポート: Keeper セッションの有効期限切れが原因で発生していた、S3Queue の論理エラー &quot;Expected current processor {} to be equal to {}&quot; を修正しました。 [#86615](https://github.com/ClickHouse/ClickHouse/pull/86615) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#86709](https://github.com/ClickHouse/ClickHouse/issues/86709) にバックポート: Iceberg メタデータキャッシュが無効になっていても、ファイルシステム cache は無効化しないようにしました。[#86635](https://github.com/ClickHouse/ClickHouse/pull/86635) ([Daniil Ivanik](https://github.com/divanik)).
* [#86793](https://github.com/ClickHouse/ClickHouse/issues/86793) にバックポート: `ArrowFlight` ハンドラーでのシャットダウン処理を修正しました。この PR で [#86596](https://github.com/ClickHouse/ClickHouse/issues/86596) を修正しています。[#86665](https://github.com/ClickHouse/ClickHouse/pull/86665) ([Vitaly Baranov](https://github.com/vitlibar)).
