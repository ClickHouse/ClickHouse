* [#93725](https://github.com/ClickHouse/ClickHouse/issues/93725)でバックポート: アナライザにおけるカラム別名内の Dynamic サブカラムの解決を修正しました。従来は、カラム別名内の Dynamic サブカラムが `getSubcolumn` でラップされており、場合によってはまったく解決されないことがありました。[#91434](https://github.com/ClickHouse/ClickHouse/issues/91434) をクローズしました。[#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93596](https://github.com/ClickHouse/ClickHouse/issues/93596)でバックポート: 終了中の background schedule pool で発生しうるハングを修正しました (シャットダウン時にサーバーがハングする原因になる可能性があります) 。[#93008](https://github.com/ClickHouse/ClickHouse/pull/93008) ([Azat Khuzhin](https://github.com/azat)).
* [#93563](https://github.com/ClickHouse/ClickHouse/issues/93563)でバックポート: 範囲外の offsets を持つ不正な `groupConcat` aggregate state のデシリアライズ時に発生するクラッシュを修正しました。[#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#93522](https://github.com/ClickHouse/ClickHouse/issues/93522)でバックポート: `hasAllTokens` および `hasAnyTokens` 関数において、第2引数が空の Array の場合の処理を修正しました。[#93328](https://github.com/ClickHouse/ClickHouse/pull/93328) ([Anton Popov](https://github.com/CurtizJ)).
* [#93476](https://github.com/ClickHouse/ClickHouse/issues/93476)でバックポート: 細工された aggregate states によってメモリ安全性の問題を引き起こす可能性がある、`groupConcat` state のデシリアライゼーションにおける整数オーバーフローの脆弱性を修正しました。[#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#93520](https://github.com/ClickHouse/ClickHouse/issues/93520)でバックポート: 索引にトークンが含まれない場合 (すべての配列が空、またはすべてのトークンがトークナイザーによってスキップされる場合) の Array カラムに対するテキスト索引解析を修正しました。[#93457](https://github.com/ClickHouse/ClickHouse/pull/93457) ([Anton Popov](https://github.com/CurtizJ)).
* [#93587](https://github.com/ClickHouse/ClickHouse/issues/93587)でバックポート: Sparse カラムへ直接デシリアライズする際の、デシリアライゼーション中のサブカラム抽出を修正しました。[#93512](https://github.com/ClickHouse/ClickHouse/pull/93512) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93672](https://github.com/ClickHouse/ClickHouse/issues/93672)でバックポート: シャットダウン時に ZooKeeper が確実に終了処理されるようにしました (ごくまれなケースで発生しうるシャットダウン時のハングを修正) 。[#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat)).
* [#93934](https://github.com/ClickHouse/ClickHouse/issues/93934)でバックポート: deduplication の競合がある状態で ReplicatedMergeTree を復元する際の LOGICAL&#95;ERROR を修正しました。[#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos)).
* [#93927](https://github.com/ClickHouse/ClickHouse/issues/93927)でバックポート: 一部の入力フォーマットで Sparse カラムへ直接デシリアライズする際、TTL 更新に Sparse カラムを使用する処理を修正しました。これにより、発生しうる論理エラー `Unexpected type of result TTL column` も修正されます。[#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93734](https://github.com/ClickHouse/ClickHouse/issues/93734)でバックポート: 展開後のバッファサイズが想定どおりであることを検証するようにしました。[#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano)).
* [#93802](https://github.com/ClickHouse/ClickHouse/issues/93802)でバックポート: `merge` テーブルエンジンを使用して、`SHOW COLUMNS` 権限を確認せずにユーザーがテーブルからカラム一覧を取得できないようにしました。[#93695](https://github.com/ClickHouse/ClickHouse/pull/93695) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#93764](https://github.com/ClickHouse/ClickHouse/issues/93764) でバックポート: サブカラム上に作成されたスキップ索引のマテリアライズを修正しました。[#93708](https://github.com/ClickHouse/ClickHouse/pull/93708) ([Anton Popov](https://github.com/CurtizJ)).
* [#93825](https://github.com/ClickHouse/ClickHouse/issues/93825) でバックポート: `PipelineExecutor` の存続中に `IStorage` オブジェクトが破棄されないよう、ストレージの共有ポインタを `QueryPipeline::resources::storage_holders` に保持するようにしました。[#93746](https://github.com/ClickHouse/ClickHouse/pull/93746) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).

Miaji](https://github.com/nihalzp)).
