<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#102522](https://github.com/ClickHouse/ClickHouse/issues/102522)でバックポート: エンジン自体も設定をサポートしている場合に、CREATE クエリ内の設定変更を検証するよう修正しました。[#99279](https://github.com/ClickHouse/ClickHouse/pull/99279) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#102622](https://github.com/ClickHouse/ClickHouse/issues/102622)でバックポート: 接続プールの use-after-free により発生する、s3Cluster および分散クエリでの segfault を修正しました。[#100837](https://github.com/ClickHouse/ClickHouse/pull/100837) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#102539](https://github.com/ClickHouse/ClickHouse/issues/102539)でバックポート: `IStorage::getDependentViewsByColumn` における `storage_id` のデータ競合を修正しました。[#101385](https://github.com/ClickHouse/ClickHouse/pull/101385) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#102518](https://github.com/ClickHouse/ClickHouse/issues/102518)でバックポート: クラッシュの可能性を回避するため、`getSubcolumnData` でサブカラムの完全一致がプレフィックス一致より優先されるよう修正しました。[#101271](https://github.com/ClickHouse/ClickHouse/issues/101271) をクローズします。[#101645](https://github.com/ClickHouse/ClickHouse/pull/101645) ([Pavel Kruglov](https://github.com/Avogar)).
* [#102565](https://github.com/ClickHouse/ClickHouse/issues/102565)でバックポート: Database Replicated で、ターゲットテーブルを持たない alias table が新規レプリカ上で初期化に失敗する問題を修正しました。[#101320](https://github.com/ClickHouse/ClickHouse/issues/101320) をクローズします。[#102397](https://github.com/ClickHouse/ClickHouse/pull/102397) ([Nikolay Degterinsky](https://github.com/evillique)).
