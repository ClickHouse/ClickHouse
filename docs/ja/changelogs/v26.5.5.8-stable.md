<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#108869](https://github.com/ClickHouse/ClickHouse/issues/108869) でバックポート: 循環依存のあるテーブルを含むバックアップの `RESTORE` 中にサーバーが異常終了する不具合を修正しました。 [#103824](https://github.com/ClickHouse/ClickHouse/pull/103824) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108903](https://github.com/ClickHouse/ClickHouse/issues/108903) でバックポート: 選言 (部分的な predicate) のプッシュダウン最適化により、JOIN によって型が拡張された `USING` key に condition がプッシュダウンされた際に発生する論理エラー (`Unexpected return type from equals. Expected Nullable(UInt8). Got UInt8`) を修正しました。あわせて、未知の identifiers を参照する定数畳み込み可能な `if`/`multiIf` の branches を含む `JOIN ... USING` クエリで identifiers を解決する際に、アナライザでサーバーがクラッシュ (segmentation fault) する問題も修正しました。 [#107407](https://github.com/ClickHouse/ClickHouse/pull/107407) ([Groene AI](https://github.com/groeneai)).
* [#108643](https://github.com/ClickHouse/ClickHouse/issues/108643) でバックポート: `ReplicatedMergeTree` table に対する `RESTORE` を修正し、バックアップ内の内容が重複する part が黙って重複排除されるのではなく、保持されるようにしました。 [#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* [#108748](https://github.com/ClickHouse/ClickHouse/issues/108748) でバックポート: `_distance` カラムを SELECT する vector search queries が、`LOGICAL_ERROR` で失敗するのではなく、適切な error を返すようになりました。 [#108423](https://github.com/ClickHouse/ClickHouse/pull/108423) ([Robert Schulze](https://github.com/rschu1ze)).
* [#108667](https://github.com/ClickHouse/ClickHouse/issues/108667) でバックポート: 部分的に materialized された複数のテキスト索引からの direct read を修正しました。 [#108607](https://github.com/ClickHouse/ClickHouse/pull/108607) ([Anton Popov](https://github.com/CurtizJ)).
* [#108825](https://github.com/ClickHouse/ClickHouse/issues/108825) でバックポート: key 内で `LowCardinality(FixedString)` (または `LowCardinality(Nullable(FixedString))`) の Key column が関数でラップされている場合、たとえば `WHERE k = 'literal'` を伴う `PARTITION BY sipHash64(k) % N` のようなケースで、パーティションおよび主キー pruning が黙って無効化される問題を修正しました。このような queries では pruning が行われず、すべての partitions が走査されていました。 [#108777](https://github.com/ClickHouse/ClickHouse/pull/108777) ([Groene AI](https://github.com/groeneai)).
* [#108907](https://github.com/ClickHouse/ClickHouse/issues/108907) でバックポート: `insert_quorum = 'auto'` で、生存しているレプリカが過半数未満の場合に inserts が事前に拒否されない問題を修正しました。このような inserts は、ローカル part を書き込んだあと `UNKNOWN_STATUS_OF_INSERT` でタイムアウトするのではなく、`TOO_FEW_LIVE_REPLICAS` で即座に失敗するようになりました。 [#108800](https://github.com/ClickHouse/ClickHouse/pull/108800) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
