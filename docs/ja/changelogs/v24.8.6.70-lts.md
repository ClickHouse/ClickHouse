<div id="clickhouse-release-v248670-lts-ddb8c219771-fixme-as-compared-to-v2485115-lts-8c4cb00a384">
  ### ClickHouse リリース v24.8.6.70-lts (ddb8c219771) FIXME (v24.8.5.115-lts (8c4cb00a384) との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#71359](https://github.com/ClickHouse/ClickHouse/issues/71359) でバックポート: JSON subcolumn 用のファイルで特殊記号がエスケープされていないために発生する可能性がある `No such file or directory` エラーを修正しました。[#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### 改善
</div>

* [#70680](https://github.com/ClickHouse/ClickHouse/issues/70680)でバックポート: Keeper から `user_directories` を同期する際、バリデーションを行わないようにしました。 [#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* [#71395](https://github.com/ClickHouse/ClickHouse/issues/71395)でバックポート: ディレクトリ一覧の取得時に object storage API を呼び出さないようにしました。コスト効率が悪くなる可能性があるためです。代わりに、ファイル名の一覧をメモリに保持します。トレードオフとして、初期ロード時間が長くなり、ファイル名の保存に必要なメモリ量も増加します。 [#70823](https://github.com/ClickHouse/ClickHouse/pull/70823) ([Julia Kartseva](https://github.com/jkartseva)).
* [#71287](https://github.com/ClickHouse/ClickHouse/issues/71287)でバックポート: plain&#95;rewritable ディスクにおける object storage HEAD API リクエスト数を削減しました。 [#70915](https://github.com/ClickHouse/ClickHouse/pull/70915) ([Julia Kartseva](https://github.com/jkartseva)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#70934](https://github.com/ClickHouse/ClickHouse/issues/70934)でバックポート: `IS NULL` チェックが他の関数 (`NOT` など) の内部にある場合に、誤った結果を招く可能性があった JOIN ON セクションの不適切な最適化を修正しました。[#67915](https://github.com/ClickHouse/ClickHouse/issues/67915) をクローズします。[#68049](https://github.com/ClickHouse/ClickHouse/pull/68049) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#70735](https://github.com/ClickHouse/ClickHouse/issues/70735)でバックポート: Array に空の Tuple を渡したときに発生する予期しない例外を修正しました。これにより [#68618](https://github.com/ClickHouse/ClickHouse/issues/68618) を修正します。[#68848](https://github.com/ClickHouse/ClickHouse/pull/68848) ([Amos Bird](https://github.com/amosbird)).
* [#71138](https://github.com/ClickHouse/ClickHouse/issues/71138)でバックポート: s3Cluster で structure argument が正しく伝播されるよう修正しました。従来は、s3Cluster 内のレプリカにクエリを送信する際に、カラムの `DEFAULT` 式が失われることがありました。[#69147](https://github.com/ClickHouse/ClickHouse/pull/69147) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70561](https://github.com/ClickHouse/ClickHouse/issues/70561)でバックポート: `useDefaultImplementationForLowCardinalityColumns` が `true` を返すようオーバーライドし、`LowCardinality` カラムでの `getSubcolumn` を修正しました。[#69831](https://github.com/ClickHouse/ClickHouse/pull/69831) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#70903](https://github.com/ClickHouse/ClickHouse/issues/70903)でバックポート: `tuple` 関数の評価時に、異なる named tuple 間でカラムが再利用されるのを防ぐようにしました。これにより [#70022](https://github.com/ClickHouse/ClickHouse/issues/70022) を修正します。[#70103](https://github.com/ClickHouse/ClickHouse/pull/70103) ([Amos Bird](https://github.com/amosbird)).
* [#70623](https://github.com/ClickHouse/ClickHouse/issues/70623)でバックポート: 2 つの SELECT と `INTERSECT` を含む materialized view の作成時に、server が segfault する問題を修正しました。例: `CREATE MATERIALIZED VIEW v0 AS (SELECT 1) INTERSECT (SELECT 1);`。[#70264](https://github.com/ClickHouse/ClickHouse/pull/70264) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#70688](https://github.com/ClickHouse/ClickHouse/issues/70688)でバックポート: `SYSTEM DROP FORMAT SCHEMA CACHE FOR Protobuf` における use-after-free の可能性を修正しました。[#70358](https://github.com/ClickHouse/ClickHouse/pull/70358) ([Azat Khuzhin](https://github.com/azat)).
* [#70494](https://github.com/ClickHouse/ClickHouse/issues/70494)でバックポート: GROUP BY で JSON sub-object subcolumn を処理中に発生する crash を修正しました。[#70374](https://github.com/ClickHouse/ClickHouse/pull/70374) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70482](https://github.com/ClickHouse/ClickHouse/issues/70482)でバックポート: パーツに行がない場合は、vertical merge のためにパーツを prefetch しないようにしました。[#70452](https://github.com/ClickHouse/ClickHouse/pull/70452) ([Antonio Andelic](https://github.com/antonio2368)).
* [#70556](https://github.com/ClickHouse/ClickHouse/issues/70556)でバックポート: ラムダ関数を含む WHERE で発生する crash を修正しました。[#70464](https://github.com/ClickHouse/ClickHouse/pull/70464) ([Raúl Marín](https://github.com/Algunenano)).
* [#70878](https://github.com/ClickHouse/ClickHouse/issues/70878)でバックポート: `Replicated` データベースで、secondary レプリカ上の利用不能な table function source を使った `CREATE ... AS table_function()` によるテーブル作成を修正しました。[#70511](https://github.com/ClickHouse/ClickHouse/pull/70511) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#70575](https://github.com/ClickHouse/ClickHouse/issues/70575) でバックポート: `wait_for_async_insert=1` での非同期 INSERT 時に、すべての出力を無視するようにしました。[#62644](https://github.com/ClickHouse/ClickHouse/issues/62644) をクローズ。[#70530](https://github.com/ClickHouse/ClickHouse/pull/70530) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#71052](https://github.com/ClickHouse/ClickHouse/issues/71052) でバックポート: system.remote&#95;data&#95;paths から shadow ディレクトリを走査する際に、frozen&#95;metadata.txt を無視するようにしました。[#70590](https://github.com/ClickHouse/ClickHouse/pull/70590) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#70651](https://github.com/ClickHouse/ClickHouse/issues/70651) でバックポート: 不整列なメモリ上で stateful window function を作成する際の問題を修正しました。[#70631](https://github.com/ClickHouse/ClickHouse/pull/70631) ([Raúl Marín](https://github.com/Algunenano)).
* [#70757](https://github.com/ClickHouse/ClickHouse/issues/70757) でバックポート: 空でないデフォルト式を持つ `Array` 型のカラムを追加した後、`SELECT` やマージでまれにクラッシュする問題を修正しました。[#70695](https://github.com/ClickHouse/ClickHouse/pull/70695) ([Anton Popov](https://github.com/CurtizJ)).
* [#70763](https://github.com/ClickHouse/ClickHouse/issues/70763) でバックポート: 未対応のフィールドをスキップする設定が有効な状態で proto スキーマを推論する際に、無限再帰が発生する問題を修正しました。[#70697](https://github.com/ClickHouse/ClickHouse/pull/70697) ([Raúl Marín](https://github.com/Algunenano)).
