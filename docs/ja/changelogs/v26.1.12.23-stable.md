  ### ClickHouse リリース v26.1.12.23-stable (e5aa07a1b9a) FIXME (v26.1.11.9-stable (1784404a5ac) と比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#103351](https://github.com/ClickHouse/ClickHouse/issues/103351) でバックポート: HTTP 接続における認証前のメモリ使用量を制限するため、既定の `http_max_fields` を 1,000,000 から 1,000 に、`http_max_field_name_size` を 128 KB から 4 KB に引き下げました。`http_max_request_header_size` および `http_headers_read_timeout` 設定を追加しました。以前のより高い制限値を必要とするユーザーは、設定で元に戻せます。[#103285](https://github.com/ClickHouse/ClickHouse/pull/103285) ([Sema Checherinda](https://github.com/CheSema)).

<div id="new-feature">
  #### 新機能
</div>

* [#103501](https://github.com/ClickHouse/ClickHouse/issues/103501) でバックポート: S3 GET リクエストの接続期間と消費バイト数を観測するため、`s3_read_request_duration_microseconds` と `s3_read_request_bytes` のヒストグラムメトリクスを追加しました。これらは `system.histogram_metrics` および Prometheus エンドポイントで参照できます。[#102058](https://github.com/ClickHouse/ClickHouse/pull/102058) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 改善
</div>

* [#103196](https://github.com/ClickHouse/ClickHouse/issues/103196) でバックポート: `system.stack_trace` にスレッドごとの `untracked_memory` を表示。 [#103065](https://github.com/ClickHouse/ClickHouse/pull/103065) ([Azat Khuzhin](https://github.com/azat)).
* [#103378](https://github.com/ClickHouse/ClickHouse/issues/103378) でバックポート: `max_network_bandwidth_for_user`/`max_network_bandwidth_for_all_users` をリモートファイルシステムの読み取り/書き込みにも適用。 [#103080](https://github.com/ClickHouse/ClickHouse/pull/103080) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#103374](https://github.com/ClickHouse/ClickHouse/issues/103374) でバックポート: 遅延カラムレプリケーション (`enable_lazy_columns_replication`) によって生成された `ColumnReplicated` カラムが、到着の遅い入力を含むマージソートパイプラインに流れ込んだ際に、マージアルゴリズムでクラッシュする問題 (`Logical error: isConst/isSparse/isReplicated assertTypeEquality`) を修正しました。[#101036](https://github.com/ClickHouse/ClickHouse/pull/101036) ([Groene AI](https://github.com/groeneai)).
* [#103185](https://github.com/ClickHouse/ClickHouse/issues/103185) でバックポート: `JSON` カラム上に作成された min-max 索引 で誤った極値が使われ、誤ったクエリ結果につながる問題を修正しました。[#101700](https://github.com/ClickHouse/ClickHouse/issues/101700) をクローズしました。[#101918](https://github.com/ClickHouse/ClickHouse/pull/101918) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103146](https://github.com/ClickHouse/ClickHouse/issues/103146) でバックポート: 複数の同時実行 `CREATE TABLE IF NOT EXISTS` クエリが Shared データベース 上の同じ `S3Queue` テーブルを対象とした場合に発生する `LOGICAL_ERROR` 例外を修正しました。[#102610](https://github.com/ClickHouse/ClickHouse/pull/102610) ([Nikita Taranov](https://github.com/nickitat)).
* [#103003](https://github.com/ClickHouse/ClickHouse/issues/103003) でバックポート: 静的クラスター (config で定義) に一時的に稼働中のノードが存在しなくなった場合に、ClusterDiscovery でサーバー例外が発生する問題を修正しました。[#102661](https://github.com/ClickHouse/ClickHouse/pull/102661) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102970](https://github.com/ClickHouse/ClickHouse/issues/102970) でバックポート: timezone 調整後に overflow が発生した場合、日付の型推論が誤る問題を修正しました。[#102601](https://github.com/ClickHouse/ClickHouse/issues/102601) をクローズしました。[#102674](https://github.com/ClickHouse/ClickHouse/pull/102674) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103302](https://github.com/ClickHouse/ClickHouse/issues/103302) でバックポート: バイナリエンコードされたデータ型における、フラット化された Dynamic 型のシリアライゼーションを修正しました。[#101911](https://github.com/ClickHouse/ClickHouse/issues/101911) をクローズしました。[#102692](https://github.com/ClickHouse/ClickHouse/pull/102692) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103493](https://github.com/ClickHouse/ClickHouse/issues/103493) でバックポート: socket レイヤーからの短い書き込みを Poco `BufferedStreamBuf::flushBuffer` が処理できないことが原因で、S3 リクエストが再試行されず、代わりに `ios_base::clear: unspecified iostream_category error` で失敗する問題を修正しました。[#102894](https://github.com/ClickHouse/ClickHouse/pull/102894) ([Sema Checherinda](https://github.com/CheSema)).
* [#103224](https://github.com/ClickHouse/ClickHouse/issues/103224) でバックポート: `minmax_count_projection` と単純な `COUNT(*)` 最適化が、論理削除 マスクを持つすべてのパートがマージで消えた後でも、論理削除 の後に恒久的に無効化されたままになる問題を修正しました。[#102900](https://github.com/ClickHouse/ClickHouse/pull/102900) ([Anton Popov](https://github.com/CurtizJ)).
* [#103020](https://github.com/ClickHouse/ClickHouse/issues/103020) でバックポート: 新しいアナライザで、row policy の OR-chain を IN に最適化しました。[#102915](https://github.com/ClickHouse/ClickHouse/pull/102915) ([Azat Khuzhin](https://github.com/azat)).
* [#103237](https://github.com/ClickHouse/ClickHouse/issues/103237) でバックポート: materialized view を伴わない通常の INSERT で、過剰な ConcurrencyControl スロットやスレッド (`max_insert_threads` ではなく `max_threads`) を要求しないようにし、INSERT スループットの高いクラスターでの CC スロット枯渇とスレッド数の肥大化を防ぐようにしました。[#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).
* [#103326](https://github.com/ClickHouse/ClickHouse/issues/103326) でバックポート: `HMAC` SQL 関数で秘密鍵を非表示にするようにしました。[#102927](https://github.com/ClickHouse/ClickHouse/issues/102927) を修正しました。[#102997](https://github.com/ClickHouse/ClickHouse/pull/102997) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#103201](https://github.com/ClickHouse/ClickHouse/issues/103201) でバックポート: カーネル OOM を回避するため、MEMORY&#95;LIMIT&#95;EXCEEDED を送出できるように ArrowMemoryPool を再導入しました。[#102999](https://github.com/ClickHouse/ClickHouse/pull/102999) ([Azat Khuzhin](https://github.com/azat)).
* [#103359](https://github.com/ClickHouse/ClickHouse/issues/103359) でバックポート: 認証前の TCP Hello パケット内の文字列を 64 KB に制限し、ハンドシェイク全体の時間を制限する `handshake_timeout_milliseconds` サーバー設定を追加しました。これにより、未認証のクライアントが過剰なメモリを消費したり、スレッドを無期限に占有したりするのを防ぎます。[#103284](https://github.com/ClickHouse/ClickHouse/pull/103284) ([Sema Checherinda](https://github.com/CheSema)).
* [#103650](https://github.com/ClickHouse/ClickHouse/issues/103650) でバックポート: String 型のカラムに対する Parquet ColumnIndex 統計の min&#95;value &gt; max&#95;value の問題を修正しました。[#103334](https://github.com/ClickHouse/ClickHouse/pull/103334) ([Saurabh Kumar Ojha](https://github.com/saurabhojha)).
* [#103410](https://github.com/ClickHouse/ClickHouse/issues/103410) でバックポート: Native format のフラット化された Dynamic データについて、不正な形式をチェックするようにしました。[#103392](https://github.com/ClickHouse/ClickHouse/pull/103392) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103635](https://github.com/ClickHouse/ClickHouse/issues/103635) でバックポート: `url` テーブル関数から `_time` カラムに値を設定するようにしました。[#103437](https://github.com/ClickHouse/ClickHouse/pull/103437) ([Nikita Taranov](https://github.com/nickitat)).
