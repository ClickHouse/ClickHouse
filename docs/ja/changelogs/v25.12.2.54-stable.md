<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224) でバックポート: デフォルトで JSON の高度な shared data を有効にしました。この変更以降、25.8 未満のバージョンへの downgrade はできなくなります。これらのバージョンでは、JSON column を持つ新しい data parts を読み取れないためです。安全にアップグレードするには、`compatibility` setting を以前のバージョンに設定するか、MergeTree settings `dynamic_serialization_version='v2', object_serialization_version='v2'` を設定することを推奨します。[#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061) でバックポート: 「Allow INSERT into simple ALIAS columns」を Revert しました（ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154) を Revert）。これは custom formats では動作せず、setting による保護もありません。[#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#92711](https://github.com/ClickHouse/ClickHouse/issues/92711) でバックポート: distinctJSONPaths aggregate function を最適化し、data parts から JSON paths のみを読み取り、JSON column 全体は読み取らないようにしました。[#92196](https://github.com/ClickHouse/ClickHouse/pull/92196) ([Pavel Kruglov](https://github.com/Avogar)).

* [#92604](https://github.com/ClickHouse/ClickHouse/issues/92604) でバックポート: system.data_skipping_indices に creation（implicit/explicit）カラムを追加しました。[#92378](https://github.com/ClickHouse/ClickHouse/pull/92378) ([Raúl Marín](https://github.com/Algunenano)).
* [#93377](https://github.com/ClickHouse/ClickHouse/issues/93377) でバックポート: native copy が BadRequest（例: 無効な block list）で失敗した場合、Azure Blob Storage で read-write copy に fallback するようにしました。従来は、異なる storage account へのブロブのコピー時に発生していた Unauthorized error の場合にのみ行っていました。しかし、「The specified block list is invalid」という error が発生することもあります。そのため、現在は native copy が失敗した場合はすべて read & write に fallback するよう条件を更新しました。[#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#93015](https://github.com/ClickHouse/ClickHouse/issues/93015) でバックポート: tasks の過剰なログ出力を避けるため、平均より遅い background tasks（`background_schedule_pool_log.duration_threshold_milliseconds=30`）をログに記録するようにしました。[#92965](https://github.com/ClickHouse/ClickHouse/pull/92965) ([Azat Khuzhin](https://github.com/azat)).
* [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338) でバックポート: `flipCoordinates` でジオメトリ型をサポートしました。[#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).
* [#93395](https://github.com/ClickHouse/ClickHouse/issues/93395) でバックポート: SYSTEM INSTRUMENT ADD/REMOVE の UX を改善しました。関数名に String literals を使用し、一致するすべての関数にパッチを適用できるようにし、`REMOVE` で function_name を使えるようにしました。[#93345](https://github.com/ClickHouse/ClickHouse/pull/93345) ([Pablo Marcos](https://github.com/pamarcos)).
