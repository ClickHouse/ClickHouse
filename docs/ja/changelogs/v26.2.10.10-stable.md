<div id="clickhouse-release-v2621010-stable-4fc1e4f53f8-fixme-as-compared-to-v26299-stable-94b91bf8dcf">
  ### ClickHouse リリース v26.2.10.10-stable (4fc1e4f53f8) FIXME (v26.2.9.9-stable (94b91bf8dcf) との比較)
</div>

<div id="new-feature">
  #### 新機能
</div>

* [#102251](https://github.com/ClickHouse/ClickHouse/issues/102251) でバックポート: HTTP 接続プールソケットのカーネル TCP 受信・送信バッファメモリ (`sk_rmem_alloc`, `sk_wmem_alloc`) に関する非同期メトリクスを追加し、接続グループごとに p50/p75/p90/p95 パーセンタイルおよび totals として報告されるようにしました。[#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 改善
</div>

* [#102324](https://github.com/ClickHouse/ClickHouse/issues/102324) でバックポート: サーバーの環境変数へのアクセスを防ぐため、埋め込みクライアント (SSH および WebSocket プロトコル) で AI SQL generation (`??` コマンド) を無効化しました。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#102339](https://github.com/ClickHouse/ClickHouse/issues/102339) でバックポート: 結果テーブルの Web Component 化に伴い、play.html の web UI でカラムのサイズ変更が正しく行えない問題を修正しました。[#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#101947](https://github.com/ClickHouse/ClickHouse/issues/101947) でバックポート: サーバー起動時の cache の読み込みを最適化しました。[#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102138](https://github.com/ClickHouse/ClickHouse/issues/102138) でバックポート: 内部の mongo-c-driver を 2.2.2 から 2.2.3 に更新しました。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#102277](https://github.com/ClickHouse/ClickHouse/issues/102277) にバックポート: `addStreams` 中にストリームコンストラクターが例外をスローした結果、`column_streams` に null エントリが残り、`MergeTreeDataPartWriterWide::cancel` で SIGSEGV が発生する不具合を修正しました。[#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102265](https://github.com/ClickHouse/ClickHouse/issues/102265) にバックポート: ファイルシステムキャッシュ 26.1+ における SLRU の競合バグを修正しました。これにより、領域予約時に論理エラーが発生する可能性がありました。Debug build では、failed assert `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.` が発生することもあります。[#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102172](https://github.com/ClickHouse/ClickHouse/issues/102172) にバックポート: `ZooKeeperRetriesControl` が、更新されていない古い (期限切れの) ZooKeeper session に対して再試行を行うことで発生する UDF refresh のクラッシュを修正しました。[#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)).
* [#102237](https://github.com/ClickHouse/ClickHouse/issues/102237) にバックポート: WHERE句を含む view をクエリした際に、内部クエリが view のメタデータと異なる types のカラム (例: `join_use_nulls` を指定した LEFT JOIN による Nullable) を生成すると発生するクラッシュ (SIGSEGV) を修正しました。[#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
