<div id="clickhouse-release-v257621-stable-a81134c5c92-fixme-as-compared-to-v257534-stable-a031c88152d">
  ### ClickHouse リリース v25.7.6.21-stable (a81134c5c92) FIXME v25.7.5.34-stable (a031c88152d) と比較して
</div>

<div id="improvement">
  #### 改善
</div>

* [#86504](https://github.com/ClickHouse/ClickHouse/issues/86504) でバックポート: 特定のチャネルに対してのみ JSON ログを有効にできるようにしました。設定するには、`logger.formatting.channel` を `syslog`/`console`/`errorlog`/`log` のいずれかに設定します。[#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#86112](https://github.com/ClickHouse/ClickHouse/issues/86112) にバックポート: *Cluster function の判定指標として `distributed_depth` を使用するのは不正確で、データ重複を引き起こす可能性がありました。代わりに `client_info.collaborate_with_initiator` を使用してください。[#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#86266](https://github.com/ClickHouse/ClickHouse/issues/86266) にバックポート: `DatabaseReplicated` で `CREATE ... AS (SELECT * FROM s3Cluster(...))` を試みた際に発生する論理エラーを修正しました。[#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#86163](https://github.com/ClickHouse/ClickHouse/issues/86163) にバックポート: delta table ではない場合、Unity Catalog は異常な data types を持つスキーマを無視するようになりました。[#85699](https://github.com/ClickHouse/ClickHouse/issues/85699) を修正しました。[#85950](https://github.com/ClickHouse/ClickHouse/pull/85950) ([alesapin](https://github.com/alesapin)).
* [#86291](https://github.com/ClickHouse/ClickHouse/issues/86291) にバックポート: setting `index_granularity_bytes = 0` を指定して table (例: `ReplacingMergeTree`) を作成した場合、スキップ索引付きの `FINAL` クエリで Exception がスローされていました。この例外は修正されました。[#86147](https://github.com/ClickHouse/ClickHouse/pull/86147) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#86308](https://github.com/ClickHouse/ClickHouse/issues/86308) にバックポート: 1 つの INSERT に const block と非 const block が混在する場合のクラッシュを修正しました。[#86230](https://github.com/ClickHouse/ClickHouse/pull/86230) ([Azat Khuzhin](https://github.com/azat)).
* [#86348](https://github.com/ClickHouse/ClickHouse/issues/86348) にバックポート: ALTER UPDATE Nullable(JSON) 実行中のクラッシュを修正しました。[#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86454](https://github.com/ClickHouse/ClickHouse/issues/86454) にバックポート: materialized view の不具合を修正しました。同じ名前で作成・削除した後に再作成すると、MV が動作しない場合がありました。[#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#86466](https://github.com/ClickHouse/ClickHouse/issues/86466) にバックポート: `Buffer` table に起因する `MergesMutationsMemoryTracking` のリークを修正し、`Kafka` (など) からの streaming に対する `query_views_log` も修正しました。[#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
