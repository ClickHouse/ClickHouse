<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#89578](https://github.com/ClickHouse/ClickHouse/issues/89578)でバックポート: JSON 内で Floats と Bools が混在する Array の読み取りを修正しました。従来は、このようなデータを insert すると例外が発生していました。[#88008](https://github.com/ClickHouse/ClickHouse/pull/88008) ([Pavel Kruglov](https://github.com/Avogar)).
* [#89508](https://github.com/ClickHouse/ClickHouse/issues/89508)でバックポート: query&#95;plan&#95;optimize&#95;join&#95;order&#95;limit &gt; 1 の場合に cross join の並べ替えで発生する論理エラーを修正し、[#89409](https://github.com/ClickHouse/ClickHouse/issues/89409) をクローズしました。[#88286](https://github.com/ClickHouse/ClickHouse/pull/88286) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#89673](https://github.com/ClickHouse/ClickHouse/issues/89673)でバックポート: [#88426](https://github.com/ClickHouse/ClickHouse/issues/88426) を修正しました。1. Alias で明示的なカラム定義を禁止し、カラムはターゲットテーブルから自動的に loading されるようにしました。これにより、alias が常にターゲットテーブルのスキーマと一致するようになります。2. IStorage からさらに多くの methods を proxy するようにしました。[#88552](https://github.com/ClickHouse/ClickHouse/pull/88552) ([Kai Zhu](https://github.com/nauu)).
* [#89446](https://github.com/ClickHouse/ClickHouse/issues/89446)でバックポート: subqueries を含む新しいアナライザで発生する可能性がある &quot;Context has expired&quot; を修正しました。[#88694](https://github.com/ClickHouse/ClickHouse/pull/88694) ([Azat Khuzhin](https://github.com/azat)).
* [#89466](https://github.com/ClickHouse/ClickHouse/issues/89466)でバックポート: 内部 table の DROP 時に、settings max&#95;table&#95;size&#95;to&#95;drop および max&#95;partition&#95;size&#95;to&#95;drop によるサイズ制限が正しく伝播されない問題を修正しました。[#88812](https://github.com/ClickHouse/ClickHouse/pull/88812) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#89716](https://github.com/ClickHouse/ClickHouse/issues/89716)でバックポート: icebergS3Cluster プロトコルを修正しました。iceberg cluster function で schema evolution、positional deletes、および equality deletes をサポートするようになりました。[#88287](https://github.com/ClickHouse/ClickHouse/issues/88287) を解決します。[#88919](https://github.com/ClickHouse/ClickHouse/pull/88919) ([Yang Jiang](https://github.com/Ted-Jiang)).
* [#89438](https://github.com/ClickHouse/ClickHouse/issues/89438)でバックポート: L2DistanceTransposed(vec1, vec2, p) における LOGICAL&#95;ERROR を修正しました。これは、partial QBit reading の最適化により、p が LowCardinality(Nullable(T)) の場合に return type から Nullable が誤って削除されていたためです。[#88362](https://github.com/ClickHouse/ClickHouse/issues/88362) を解決します。[#89397](https://github.com/ClickHouse/ClickHouse/pull/89397) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#89449](https://github.com/ClickHouse/ClickHouse/issues/89449)でバックポート: tuple 自体に対する不正なスパース シリアライゼーションで table を loading する際の問題を修正しました (これは古い ClickHouse バージョンで書き込まれたものです) 。[#89405](https://github.com/ClickHouse/ClickHouse/pull/89405) ([Azat Khuzhin](https://github.com/azat)).
* [#89487](https://github.com/ClickHouse/ClickHouse/issues/89487)でバックポート: `deduplicate_merge_projection_mode='ignore'` 使用時に、有効期限 (TTL) によって空になったパーツと空でない projections がある場合の、誤った merge 処理を修正しました。[#89430](https://github.com/ClickHouse/ClickHouse/issues/89430) を解決します。[#89458](https://github.com/ClickHouse/ClickHouse/pull/89458) ([Amos Bird](https://github.com/amosbird)).
* [#89570](https://github.com/ClickHouse/ClickHouse/issues/89570)でバックポート: rotation 中に changelog が正しくリネームされなかった場合に、Keeper 起動時の changelogs の読み取りで発生する問題を修正しました。[#89496](https://github.com/ClickHouse/ClickHouse/pull/89496) ([Antonio Andelic](https://github.com/antonio2368)).
* [#89633](https://github.com/ClickHouse/ClickHouse/issues/89633) でバックポート: 一意な右テーブルのキーに対して OR 条件を使用した際に、誤った JOIN 結果が返される問題を修正しました。[#89391](https://github.com/ClickHouse/ClickHouse/issues/89391) を解決します。[#89512](https://github.com/ClickHouse/ClickHouse/pull/89512) ([Vladimir Cherkasov](https://github.com/vdimir))。
* [#89595](https://github.com/ClickHouse/ClickHouse/issues/89595) でバックポート: アナライザおよび PK IN (サブクエリ) (v2) で、&quot;Context has expired&quot; が発生する可能性がある問題を修正しました。[#89433](https://github.com/ClickHouse/ClickHouse/issues/89433) を修正します。[#89527](https://github.com/ClickHouse/ClickHouse/pull/89527) ([Azat Khuzhin](https://github.com/azat))。
* [#89688](https://github.com/ClickHouse/ClickHouse/issues/89688) でバックポート: aggregate function の state に LowCardinality(String) 型カラムのシリアライズされた値が含まれる場合に発生するクラッシュを修正しました。[#89550](https://github.com/ClickHouse/ClickHouse/pull/89550) ([Pavel Kruglov](https://github.com/Avogar))。
* [#89678](https://github.com/ClickHouse/ClickHouse/issues/89678) でバックポート: ランタイムフィルタを、サポート対象の JOIN アルゴリズム、すなわちハッシュ結合に対してのみ追加するようにしました。フィルタを構築できるのは、JOIN アルゴリズムが最初に右側を完全に読み込み、その後に左側を読み込む場合に限られます。たとえば FullSortingMergeJoin は両側を同時に読み込みます。[#89220](https://github.com/ClickHouse/ClickHouse/issues/89220) を修正します。[#89652](https://github.com/ClickHouse/ClickHouse/pull/89652) ([Alexander Gololobov](https://github.com/davenger))。
* [#89699](https://github.com/ClickHouse/ClickHouse/issues/89699) でバックポート: 一部のケースで、JOIN ランタイムフィルタにより論理エラーやクラッシュが発生する問題を修正しました。[#89062](https://github.com/ClickHouse/ClickHouse/issues/89062) を修正します。[#89666](https://github.com/ClickHouse/ClickHouse/pull/89666) ([Alexander Gololobov](https://github.com/davenger))。
