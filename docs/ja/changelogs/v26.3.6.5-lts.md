<div id="new-feature">
  #### 新機能
</div>

* [#102253](https://github.com/ClickHouse/ClickHouse/issues/102253) でバックポート: HTTP 接続プールソケットのカーネル TCP の受信および送信バッファメモリ (`sk_rmem_alloc`, `sk_wmem_alloc`) に関する非同期メトリクスを追加しました。これらは、接続グループごとに p50/p75/p90/p95 パーセンタイルおよび totals として報告されます。[#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#102296](https://github.com/ClickHouse/ClickHouse/issues/102296) でバックポート: Map サブカラムの読み取り中に発生する可能性がある論理エラーを修正しました。[#100769](https://github.com/ClickHouse/ClickHouse/issues/100769) をクローズ。[#101336](https://github.com/ClickHouse/ClickHouse/issues/101336) をクローズ。[#101641](https://github.com/ClickHouse/ClickHouse/pull/101641) ([Pavel Kruglov](https://github.com/Avogar))。
* [#102267](https://github.com/ClickHouse/ClickHouse/issues/102267) でバックポート: 26.1+ のファイルシステムキャッシュにおける SLRU の競合バグを修正しました。これは領域予約の論理エラーにつながる可能性があります。debug build では、次の assert failure を引き起こす可能性もあります: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`。[#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#102174](https://github.com/ClickHouse/ClickHouse/issues/102174) でバックポート: `ZooKeeperRetriesControl` が、古い (期限切れの) ZooKeeper session を更新せずに再試行することで発生する、UDF refresh 時の crash を修正しました。[#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v))。
