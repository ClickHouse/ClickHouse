* [#85683](https://github.com/ClickHouse/ClickHouse/issues/85683) にバックポート: delta-kernel-rs バックエンドでのファイル並列処理を改善しました。[#85642](https://github.com/ClickHouse/ClickHouse/pull/85642) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">
  #### 改善
</div>

* [#86063](https://github.com/ClickHouse/ClickHouse/issues/86063) にバックポート: 一時ユーザーが作成したビューは、実ユーザーのコピーを保持するようになり、一時ユーザー削除後も無効にならなくなりました。[#84763](https://github.com/ClickHouse/ClickHouse/pull/84763) ([pufit](https://github.com/pufit))。
* [#85728](https://github.com/ClickHouse/ClickHouse/issues/85728) にバックポート: system.tables へのデータレイクのテーブル追加を制御する `show_data_lake_catalogs_in_system_tables` フラグを追加し、[#85384](https://github.com/ClickHouse/ClickHouse/issues/85384) を解決しました。[#85411](https://github.com/ClickHouse/ClickHouse/pull/85411) ([Smita Kulkarni](https://github.com/SmitaRKulkarni))。
* [#86251](https://github.com/ClickHouse/ClickHouse/issues/86251) にバックポート: S3 object storage で再試行可能なエラーが発生した際に、S3 client の threads を抑制するようにしました。これにより、従来の設定 `backup_slow_all_threads_after_retryable_s3_error` を S3 disk にも拡張し、より汎用的な `s3_slow_all_threads_after_retryable_error` にリネームしました。[#85918](https://github.com/ClickHouse/ClickHouse/pull/85918) ([Julia Kartseva](https://github.com/jkartseva))。
* [#86503](https://github.com/ClickHouse/ClickHouse/issues/86503) にバックポート: 特定の channel のみで JSON ログを有効化できるようにしました。これを行うには、`logger.formatting.channel` を `syslog`/`console`/`errorlog`/`log` のいずれかに設定します。[#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat))。
