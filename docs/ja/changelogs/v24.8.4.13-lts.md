<div id="clickhouse-release-v248413-lts-53195bc189b-fixme-as-compared-to-v248359-lts-e729b9fa40e">
  ### ClickHouse リリース v24.8.4.13-lts (53195bc189b) FIXME v24.8.3.59-lts (e729b9fa40e) との比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#68699](https://github.com/ClickHouse/ClickHouse/issues/68699)でバックポート: 辞書内の named collections に関する古いコードを削除して新しいコードに置き換え、DDL で作成した named collections を辞書で使用できるようにしました。[#60936](https://github.com/ClickHouse/ClickHouse/issues/60936) をクローズし、[#36890](https://github.com/ClickHouse/ClickHouse/issues/36890) もクローズしました。[#68412](https://github.com/ClickHouse/ClickHouse/pull/68412) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#69231](https://github.com/ClickHouse/ClickHouse/issues/69231)でバックポート: JSON type のパース時に、一部のケースで null をデフォルトとして挿入すべき場合に発生していたパースエラーを修正しました。 [#68955](https://github.com/ClickHouse/ClickHouse/pull/68955) ([Kruglov Pavel](https://github.com/Avogar)).
* [#69251](https://github.com/ClickHouse/ClickHouse/issues/69251)でバックポート: 並列レプリカを使用するクエリで、サブクエリ内の `UNION` 句が正しく処理されず、LOGICAL&#95;ERROR `Duplicate announcement received for replica` を引き起こしていた問題を修正しました。 [#69146](https://github.com/ClickHouse/ClickHouse/pull/69146) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微
</div>

* [#69189](https://github.com/ClickHouse/ClickHouse/issues/69189)でバックポート: `use_json_alias_for_old_object_type=1` かつ `allow_experimental_object_type=0` の場合、Object 型を作成しないようにしました。 [#69150](https://github.com/ClickHouse/ClickHouse/pull/69150) ([Kruglov Pavel](https://github.com/Avogar)).
* [#69229](https://github.com/ClickHouse/ClickHouse/issues/69229)でバックポート: サニタイザ使用時の memory test を無効化しました。 [#69193](https://github.com/ClickHouse/ClickHouse/pull/69193) ([alesapin](https://github.com/alesapin)).
* [#69219](https://github.com/ClickHouse/ClickHouse/issues/69219)でバックポート: サニタイザ使用時の perf風テストを無効化しました。 [#69194](https://github.com/ClickHouse/ClickHouse/pull/69194) ([alesapin](https://github.com/alesapin)).
