<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#84395](https://github.com/ClickHouse/ClickHouse/issues/84395)でバックポート: パース失敗時に Dynamic カラムのロールバックが正しく行われない問題を修正しました。[#82169](https://github.com/ClickHouse/ClickHouse/pull/82169) ([Pavel Kruglov](https://github.com/Avogar)).
* [#84671](https://github.com/ClickHouse/ClickHouse/issues/84671)でバックポート: 等価比較のオペランドの型が異なる場合や定数を参照している場合に、filter が JOIN 条件に merging される問題を修正しました。[#83432](https://github.com/ClickHouse/ClickHouse/issues/83432) を修正します。[#84145](https://github.com/ClickHouse/ClickHouse/pull/84145) ([Dmitry Novik](https://github.com/novikd)).
* [#84558](https://github.com/ClickHouse/ClickHouse/issues/84558)でバックポート: バックグラウンドのキャンセルチェッカー thread が原因で発生するデッドロックを修正しました。[#84203](https://github.com/ClickHouse/ClickHouse/pull/84203) ([Antonio Andelic](https://github.com/antonio2368)).
* [#84493](https://github.com/ClickHouse/ClickHouse/issues/84493)でバックポート: `array()` 関数で空のタプルが誤って構築される問題を修正しました。これにより [#84202](https://github.com/ClickHouse/ClickHouse/issues/84202) を修正します。[#84297](https://github.com/ClickHouse/ClickHouse/pull/84297) ([Amos Bird](https://github.com/amosbird)).
* [#84453](https://github.com/ClickHouse/ClickHouse/issues/84453)でバックポート: `zoutofmemory` をハードウェア error として扱うようにし、そうでない場合に論理エラーが throw される問題を修正しました。 [https://github.com/clickhouse/clickhouse-core-incidents/issues/877](https://github.com/clickhouse/clickhouse-core-incidents/issues/877) を参照してください。[#84420](https://github.com/ClickHouse/ClickHouse/pull/84420) ([Han Fei](https://github.com/hanfei1991)).
* [#84652](https://github.com/ClickHouse/ClickHouse/issues/84652)でバックポート: Keeper changelog への順不同の書き込みを修正しました。以前は changelog への書き込みが進行中の状態で、rollback によって宛先ファイルが同時実行で変更される可能性がありました。その結果、logs の不整合やデータ損失が発生するおそれがありました。[#84434](https://github.com/ClickHouse/ClickHouse/pull/84434) ([Antonio Andelic](https://github.com/antonio2368)).
* [#84627](https://github.com/ClickHouse/ClickHouse/issues/84627)でバックポート: データレイクで virtual column によるファイルの pruning を修正しました。[#84520](https://github.com/ClickHouse/ClickHouse/pull/84520) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#84632](https://github.com/ClickHouse/ClickHouse/issues/84632)でバックポート: 互換性のため、`allow_experimental_delta_kernel_rs` の 25.5 より前の値を `false` に変更しました。[#84587](https://github.com/ClickHouse/ClickHouse/pull/84587) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#84727](https://github.com/ClickHouse/ClickHouse/issues/84727)でバックポート: RefreshTask で &#39;view&#39; から zookeeper を取得する際に &#39;mutex&#39; を lock するようにしました。[#84699](https://github.com/ClickHouse/ClickHouse/pull/84699) ([Tuan Pham Anh](https://github.com/tuanpach)).
