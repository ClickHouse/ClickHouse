<div id="improvement">
  #### 改善
</div>

* [#81179](https://github.com/ClickHouse/ClickHouse/issues/81179) にバックポート: `system.iceberg_history` が、glue や iceberg rest などのカタログ database の history を表示するようになりました。また、一貫性向上のため、`system.iceberg_history` の `table_name` および `database_name` カラムを、それぞれ `table` と `database` にリネームしました。[#80975](https://github.com/ClickHouse/ClickHouse/pull/80975) ([alesapin](https://github.com/alesapin)).
* [#81230](https://github.com/ClickHouse/ClickHouse/issues/81230) にバックポート: libarchive を 3.7.9 に更新し、CVE-2024-20696、CVE-2025-25724、CVE-2024-48958、CVE-2024-57970、CVE-2025-1632、CVE-2024-48957、CVE-2024-48615 に対処しました。[#81174](https://github.com/ClickHouse/ClickHouse/pull/81174) ([larryluogit](https://github.com/larryluogit)).
* [#81538](https://github.com/ClickHouse/ClickHouse/issues/81538) にバックポート: libxml2 を 2.14.3 に更新しました。[#81187](https://github.com/ClickHouse/ClickHouse/pull/81187) ([larryluogit](https://github.com/larryluogit)).
* [#81317](https://github.com/ClickHouse/ClickHouse/issues/81317) にバックポート: MemoryResidentWithoutPageCache は、ユーザー空間 page cache を除いた server process の物理メモリ使用量をバイト単位で示します。これにより、ユーザー空間 page cache を使用している場合でも、実際の memory usage をより正確に把握できます。ユーザー空間 page cache が無効な場合、この値は MemoryResident と同じになります。[#81233](https://github.com/ClickHouse/ClickHouse/pull/81233) ([Jayme Bird](https://github.com/jaymebrd)).
* [#81411](https://github.com/ClickHouse/ClickHouse/issues/81411) にバックポート: journal 付き filesystem では、`mkdir` がディスクに永続化される filesystem の journal に書き込まれます。ディスクが低速な場合、これに時間がかかることがあります。そのため、これを reserve lock のスコープ外に移すのは妥当です。[#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#81488](https://github.com/ClickHouse/ClickHouse/issues/81488) にバックポート: `krb5` 1.21.3-final を使用します。[#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81480](https://github.com/ClickHouse/ClickHouse/issues/81480) にバックポート: `orc` 2.1.2 を使用します。[#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81668](https://github.com/ClickHouse/ClickHouse/issues/81668) にバックポート: 最初の読み取りクエリが実行されるまで、Iceberg のマニフェストファイルの読み取りを延期します。[#81619](https://github.com/ClickHouse/ClickHouse/pull/81619) ([Daniil Ivanik](https://github.com/divanik)).
* [#81803](https://github.com/ClickHouse/ClickHouse/issues/81803) にバックポート: profile event `PageCacheReadBytes` を追加しました。[#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#81932](https://github.com/ClickHouse/ClickHouse/issues/81932) にバックポート: ファイルシステムキャッシュにおける論理エラー &quot;Having zero bytes but range is not finished&quot; の修正を試みました。[#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)).
