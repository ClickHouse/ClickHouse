<div id="new-feature">
  #### 新機能
</div>

* `clickhouse-server` と `clickhouse-keeper` 向けに、`<version>-distroless` タグ付きの distroless Docker イメージバリアントを追加しました。 [#101442](https://github.com/ClickHouse/ClickHouse/pull/101442) ([Rahul Nair](https://github.com/motsc)).

<div id="improvement">
  #### 改善
</div>

* [#100462](https://github.com/ClickHouse/ClickHouse/issues/100462) でバックポート: poco 内部の std ストリームに対して `this->exceptions(std::ios::badbit);` を設定しました。 [#96455](https://github.com/ClickHouse/ClickHouse/pull/96455) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#99090](https://github.com/ClickHouse/ClickHouse/issues/99090)でバックポート: `clickhouse-client` の `--external` で渡された外部テーブルにおいて、名前による Tuple サブカラムへのアクセス (例: `Tuple(a UUID, b Int32)` に対する `SELECT x.a`) を修正しました。[#96925](https://github.com/ClickHouse/ClickHouse/issues/96925) をクローズします。[#98755](https://github.com/ClickHouse/ClickHouse/pull/98755) ([Pavel Kruglov](https://github.com/Avogar))。
* [#100488](https://github.com/ClickHouse/ClickHouse/issues/100488)でバックポート: JDBC、ODBC、NATS の接続文字列に含まれる認証情報が、クエリログおよび `SHOW CREATE` の出力でマスクされるようになり、機密情報が意図せず露出するのを防げるようになりました。URI 形式の接続文字列 (例: {scheme}://{user}:{password}@{host}) では、password の部分のみがマスクされ、デバッグしやすいようそれ以外の部分は表示されたままになります。`nats_token` 設定もマスクされるようになりました。[#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* [#100592](https://github.com/ClickHouse/ClickHouse/issues/100592)でバックポート: `optimize_on_insert=0` の wide パーツで、ネストした `Array(JSON)` カラムを持つテーブルへの挿入時に発生する LOGICAL&#95;ERROR 例外 `"Stream ... not found"` を修正しました。[#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar))。
* [#100722](https://github.com/ClickHouse/ClickHouse/issues/100722)でバックポート: projection の SELECT 句に、クエリの元の SELECT 句には存在しないカラムが含まれる場合に発生する NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK を修正しました。[#100194](https://github.com/ClickHouse/ClickHouse/issues/100194) をクローズします。[#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
