<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#92967](https://github.com/ClickHouse/ClickHouse/issues/92967) にバックポート: 名前にパーセントエンコードされたシーケンスを含むデータレイクテーブルの問題を修正しました。[#86626](https://github.com/ClickHouse/ClickHouse/issues/86626) をクローズします。 [#87020](https://github.com/ClickHouse/ClickHouse/pull/87020) ([Anton Ivashkin](https://github.com/ianton-ru)).
* [#92690](https://github.com/ClickHouse/ClickHouse/issues/92690) にバックポート: サブカラムの読み取り中に Log エンジンで発生する可能性がある論理エラーを修正しました。[#91710](https://github.com/ClickHouse/ClickHouse/issues/91710) をクローズします。 [#91711](https://github.com/ClickHouse/ClickHouse/pull/91711) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92897](https://github.com/ClickHouse/ClickHouse/issues/92897) にバックポート: 同名のカラムとサブカラムが競合し、誤ったシリアライゼーションが使われてクエリが失敗する可能性がある問題を修正しました。[#90219](https://github.com/ClickHouse/ClickHouse/issues/90219) をクローズします。 [#85161](https://github.com/ClickHouse/ClickHouse/issues/85161) をクローズします。 [#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93119](https://github.com/ClickHouse/ClickHouse/issues/93119) にバックポート: ワイルドカード grant に対するアクセス grant チェックの誤ったロジックを見直しました。以前の試み [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) では重大な脆弱性に対処したものの、制限が厳しすぎたため、無関係な revoke によって一部のワイルドカード `GRANT` ステートメントが失敗していました。 [#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* [#92984](https://github.com/ClickHouse/ClickHouse/issues/92984) にバックポート: 切断された `Connection` からの読み取りによって crash が発生するのを回避します。 [#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#92939](https://github.com/ClickHouse/ClickHouse/issues/92939) にバックポート: `WHERE` clause の predicate にサブクエリを含む `IN` clause がある論理更新で、プライマリインデックスの使用を修正しました。 [#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* [#93220](https://github.com/ClickHouse/ClickHouse/issues/93220) にバックポート: JSON 内のパス &#39;skip&#39; に対する型ヒントの作成を修正しました。[#92731](https://github.com/ClickHouse/ClickHouse/issues/92731) をクローズします。 [#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92930](https://github.com/ClickHouse/ClickHouse/issues/92930) にバックポート: JSON カラムが Tuple カラムの後に来る場合の、古い Parquet リーダー (デフォルトでは使用されません) における Parquet スキーマ推論を修正しました。あわせて、空の Tuple で古い Parquet リーダー (デフォルトでは使用されません) が失敗する問題も修正しました。 [#92867](https://github.com/ClickHouse/ClickHouse/pull/92867) ([Michael Kolupaev](https://github.com/al13n321)).
* [#93178](https://github.com/ClickHouse/ClickHouse/issues/93178) にバックポート: `ratio_of_defaults_for_sparse_serialization` の設定を alter で `1.0` に変更した場合に、スパースカラムの mutation 後に FILE&#95;DOESNT&#95;EXIST エラーが発生する可能性がある問題を修正しました。 [#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93042](https://github.com/ClickHouse/ClickHouse/issues/93042) にバックポート: WHERE で `not materialize(...)` または `not CAST(...)` を使用したときに不正な結果を招く、データスキップロジックのバグを修正しました。[#88536](https://github.com/ClickHouse/ClickHouse/issues/88536) をクローズします。 [#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#93053](https://github.com/ClickHouse/ClickHouse/issues/93053) にバックポート: 分散クエリの事前キャンセル後に、接続が壊れた状態のまま残ってしまう問題を修正しました。[#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)).
* [#93307](https://github.com/ClickHouse/ClickHouse/issues/93307) にバックポート: マージ中にプロジェクションが再構築される際、未使用のカラムを削除するようにしました。これによりメモリ使用量が減り、一時的なパーツの作成数も少なくなります。[#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
