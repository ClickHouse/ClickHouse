<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#108450](https://github.com/ClickHouse/ClickHouse/issues/108450)でバックポート: `JOIN ON` 内で使用された `arrayJoin()` により行数が誤って計算される問題を修正しました。結果が配列長の分だけ余計にもう一度乗算されていました。[#104785](https://github.com/ClickHouse/ClickHouse/pull/104785) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#108263](https://github.com/ClickHouse/ClickHouse/issues/108263)でバックポート: 空のマージ済みパート上のテキスト索引で発生する &quot;Too many marks&quot; を修正しました。[#106867](https://github.com/ClickHouse/ClickHouse/pull/106867) ([Azat Khuzhin](https://github.com/azat)).
* [#107911](https://github.com/ClickHouse/ClickHouse/issues/107911)でバックポート: ローカルの格納順序がグローバル順序と異なる `Map` variant を持つ `Variant` カラムを含む、ソート済みブロックのマージ時に発生するクラッシュ (`Source column is not Map` / `SIGSEGV`) を修正しました。[#107011](https://github.com/ClickHouse/ClickHouse/pull/107011) ([Groene AI](https://github.com/groeneai)).
* [#108168](https://github.com/ClickHouse/ClickHouse/issues/108168)でバックポート: MsgPack、BSON、ORC、Parquet、JSON、Delta Lake、Iceberg、Paimon フォーマットで、深くネストされたスキーマまたは値を読み取る際に発生しうるサーバーのスタックオーバーフロー (クラッシュ) を修正しました。このような深くネストされた入力は、現在では例外を返して拒否されます。[#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* [#108226](https://github.com/ClickHouse/ClickHouse/issues/108226)でバックポート: 範囲外のイベント型を持つ細工された集約関数の state を finalize した際に `windowFunnel` で発生する heap buffer overflow (サーバークラッシュ) を修正しました。この問題は、単一の `SELECT` を実行できる任意のユーザーが到達可能でした。[#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* [#108503](https://github.com/ClickHouse/ClickHouse/issues/108503)でバックポート: `update()` 内で再構築される新しい snapshot は、`createBuilder` を介して C++ S3 client の現在の認証情報をすでに取り込んでいるため、バージョンが一致する場合でも破棄せずに保持するようにしました。これにより、次のカーネル操作は新しい認証情報を持つ engine 上で実行され、STS TTL を超えて存続しなくなります。[#107480](https://github.com/ClickHouse/ClickHouse/pull/107480) ([Elmi Ahmadov](https://github.com/ahmadov)).
* [#108239](https://github.com/ClickHouse/ClickHouse/issues/108239)でバックポート: ELF および DWARF のパースに、不足していた境界チェックを追加しました。[#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108162](https://github.com/ClickHouse/ClickHouse/issues/108162)でバックポート: Apache Arrow Java &lt; 19.0.0 (Apache Spark を含む) が生成した空の `String`/`Binary` カラムを持つ Arrow/ArrowStream data の読み取りで、`INCORRECT_DATA` を返さなくなりました。[#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
* [#108208](https://github.com/ClickHouse/ClickHouse/issues/108208)でバックポート: LowCardinality カラムに対して set スキップ索引 で granule の pruning が行われない問題を修正しました。[#107868](https://github.com/ClickHouse/ClickHouse/pull/107868) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108308](https://github.com/ClickHouse/ClickHouse/issues/108308)でバックポート: `LowCardinality` のルックアップ argument を指定した場合に、`Dynamic` key を持つ `Map` に対する `has` で発生するクラッシュ (release builds では SIGSEGV、debug builds では型不一致 assertion) を修正しました。例: `has(map('a'::Dynamic, ...), toLowCardinality('b'))`。[#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* [#108398](https://github.com/ClickHouse/ClickHouse/issues/108398)でバックポート: PREWHERE 使用時の Map サブカラムのパフォーマンス低下を修正しました。[#107912](https://github.com/ClickHouse/ClickHouse/issues/107912) をクローズします。原因: [https://github.com/ClickHouse/ClickHouse/pull/99200](https://github.com/ClickHouse/ClickHouse/pull/99200)。[#107988](https://github.com/ClickHouse/ClickHouse/pull/107988) ([Pavel Kruglov](https://github.com/Avogar)).
* [#108136](https://github.com/ClickHouse/ClickHouse/issues/108136)でバックポート: 複数スレッドで `Dynamic` カラムを読み取る際のパフォーマンス低下を修正しました。原因: [https://github.com/ClickHouse/ClickHouse/pull/100730](https://github.com/ClickHouse/ClickHouse/pull/100730)。[#107942](https://github.com/ClickHouse/ClickHouse/issues/107942) をクローズします。[#107997](https://github.com/ClickHouse/ClickHouse/pull/107997) ([Pavel Kruglov](https://github.com/Avogar)).
* [#108200](https://github.com/ClickHouse/ClickHouse/issues/108200)でバックポート: 空のバッチであっても、アクセス cache のバッチ完了ハンドラーを常に実行するようにしました。[#108124](https://github.com/ClickHouse/ClickHouse/pull/108124) ([Azat Khuzhin](https://github.com/azat)).
* [#108322](https://github.com/ClickHouse/ClickHouse/issues/108322)でバックポート: ZooKeeper 接続が悪いタイミングで失われた場合に、リフレッシャブルmaterialized view が停止したままになる問題を修正しました。[#108234](https://github.com/ClickHouse/ClickHouse/pull/108234) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108485](https://github.com/ClickHouse/ClickHouse/issues/108485)でバックポート: `format_display_secrets_in_show_and_select` が無効 (デフォルト) の場合、`EXPLAIN actions`、`EXPLAIN header`、`EXPLAIN PIPELINE` の出力で、`encrypt`、`decrypt`、`HMAC` などの関数の secret 引数を非表示にするようにしました。[#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
* [#108780](https://github.com/ClickHouse/ClickHouse/issues/108780)でバックポート: `ssl_certificate` のユーザー識別を修正し、単一の `*` ワイルドカードが名前の構成要素 1 つにのみ一致するようにしました (RFC 6125 6.4.3) 。従来は、`CN` または `DNS:` SAN subject のワイルドカード (例: `*.corp.example.com`) が `evil.deep.corp.example.com` のような複数ラベルの名前にも一致していたため、より深いサブドメイン向けの certificate を持つユーザーがワイルドカードユーザーとして認証できていました。`URI:` SAN の照合は変更されていません。[#108472](https://github.com/ClickHouse/ClickHouse/pull/108472) ([Groene AI](https://github.com/groeneai)).
* [#108697](https://github.com/ClickHouse/ClickHouse/issues/108697)でバックポート: `DESCRIBE loop('db', 'table')` および `DESCRIBE loop(<inner table function>)` が `SHOW COLUMNS` / source アクセスチェックを回避し、権限のないユーザーでもテーブルのカラムスキーマを読み取れてしまうメタデータ漏えいを修正しました。[#108624](https://github.com/ClickHouse/ClickHouse/pull/108624) ([Groene AI](https://github.com/groeneai)).
