<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#80466](https://github.com/ClickHouse/ClickHouse/issues/80466) にバックポート: SingleValueDataGeneric で `Field` の代わりに IColumn を使用するようにしました。これにより、`Dynamic/Variant/JSON` 型に対する `argMax` など、一部の集約関数で戻り値が不正になる問題を修正します。[#79166](https://github.com/ClickHouse/ClickHouse/pull/79166) ([Pavel Kruglov](https://github.com/Avogar)).
* [#80258](https://github.com/ClickHouse/ClickHouse/issues/80258) にバックポート: projection までクエリ実行にカラムがまったく使用されない場合に、遅延マテリアライゼーションで `AMBIGUOUS_COLUMN_NAME` エラーが発生する問題を修正します。例: SELECT * FROM t ORDER BY rand() LIMIT 5. [#79926](https://github.com/ClickHouse/ClickHouse/pull/79926) ([Igor Nikonov](https://github.com/devcrafter)).
* [#80339](https://github.com/ClickHouse/ClickHouse/issues/80339) にバックポート: Merge engine からサブカラムを読み取る際の問題を修正します。[#80158](https://github.com/ClickHouse/ClickHouse/pull/80158) ([Pavel Kruglov](https://github.com/Avogar)).
* [#80506](https://github.com/ClickHouse/ClickHouse/issues/80506) にバックポート: MongoDB ドキュメント内のネストされた数値フィールドが文字列として不適切にシリアライゼーションされる問題を修正します。また、MongoDB のドキュメントに対する最大深度の制限を削除します。[#80289](https://github.com/ClickHouse/ClickHouse/pull/80289) ([Kirill Nikiforov](https://github.com/allmazz)).
* [#80402](https://github.com/ClickHouse/ClickHouse/issues/80402) にバックポート: PostgreSQL ストレージにおける DateTime および DateTime64 のテキスト表現を修正します。[#80301](https://github.com/ClickHouse/ClickHouse/pull/80301) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#80395](https://github.com/ClickHouse/ClickHouse/issues/80395) にバックポート: `ON` 式が単純な等価条件でない場合に、logical JOIN sep の filter-push-down optimization によって `NOT_FOUND_COLUMN_IN_BLOCK` エラーが発生する問題を修正します。[#79647](https://github.com/ClickHouse/ClickHouse/issues/79647) を修正。[#77848](https://github.com/ClickHouse/ClickHouse/issues/77848) を修正。[#80360](https://github.com/ClickHouse/ClickHouse/pull/80360) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
