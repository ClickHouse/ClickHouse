* [#80755](https://github.com/ClickHouse/ClickHouse/issues/80755) にバックポート: Dictionary の登録失敗時に起こりうる crash を修正しました (`CREATE DICTIONARY` が `CANNOT_SCHEDULE_TASK` で失敗すると、dictionary registry にダングリングポインタが残り、後で crash につながる可能性がありました) 。[#80714](https://github.com/ClickHouse/ClickHouse/pull/80714) ([Azat Khuzhin](https://github.com/azat)).

* [#80901](https://github.com/ClickHouse/ClickHouse/issues/80901) にバックポート: `IN cte` を含む分散クエリで発生する `THERE_IS_NO_COLUMN` エラーを修正しました。[#75032](https://github.com/ClickHouse/ClickHouse/issues/75032) を修正。[#80757](https://github.com/ClickHouse/ClickHouse/pull/80757) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

* [#80872](https://github.com/ClickHouse/ClickHouse/issues/80872) にバックポート: get&#95;member&#95;id() が NULL から std::string を生成していたことによる Kafka の crash を修正しました (おそらく broker への接続に失敗した場合にのみ発生していた問題です) 。[#80793](https://github.com/ClickHouse/ClickHouse/pull/80793) ([Azat Khuzhin](https://github.com/azat)).
* [#80912](https://github.com/ClickHouse/ClickHouse/issues/80912) にバックポート: Kafka エンジンのシャットダウン前にコンシューマーの終了を適切に待機するようにしました (シャットダウン後もコンシューマーがアクティブなままだと、各種 debug assertion をトリガーする可能性があり、さらにテーブルが drop/detach された後もバックグラウンドで brokers からデータを読み取ることがあります) 。[#80795](https://github.com/ClickHouse/ClickHouse/pull/80795) ([Azat Khuzhin](https://github.com/azat)).
* [#80936](https://github.com/ClickHouse/ClickHouse/issues/80936) にバックポート: Iceberg メタデータファイル cache のメモリ計上を修正しました。[#80904](https://github.com/ClickHouse/ClickHouse/pull/80904) ([Azat Khuzhin](https://github.com/azat)).
* [#81061](https://github.com/ClickHouse/ClickHouse/issues/81061) にバックポート: Nullable なパーティションキーでパーティション化が誤っていた問題を修正しました。[#80913](https://github.com/ClickHouse/ClickHouse/pull/80913) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* [#81099](https://github.com/ClickHouse/ClickHouse/issues/81099) にバックポート: 名前付きウィンドウを使用する入れ子の関数における論理エラーを修正しました。[#80926](https://github.com/ClickHouse/ClickHouse/pull/80926) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
