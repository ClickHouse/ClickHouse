<div id="improvement">
  #### 改善
</div>

* [#84783](https://github.com/ClickHouse/ClickHouse/issues/84783) でバックポート: この変更により、`ConcurrentBoundedQueue` のサイズに関するディメンション付きメトリクスが追加され、queue type (つまり、そのキューの用途) および queue id (つまり、そのキューの現在のインスタンスに対してランダムに生成される ID) でラベル付けされます。 [#84675](https://github.com/ClickHouse/ClickHouse/pull/84675) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#85007](https://github.com/ClickHouse/ClickHouse/issues/85007) でバックポート: Keeper に 4LW `lgrq` を追加し、受信したリクエストのログ記録を切り替えられるようにしました。 [#84719](https://github.com/ClickHouse/ClickHouse/pull/84719) ([Antonio Andelic](https://github.com/antonio2368)).
* [#84869](https://github.com/ClickHouse/ClickHouse/issues/84869) でバックポート: Keeper のストレージロックにおける競合を軽減しました。 [#84732](https://github.com/ClickHouse/ClickHouse/pull/84732) ([Antonio Andelic](https://github.com/antonio2368)).
* [#85001](https://github.com/ClickHouse/ClickHouse/issues/85001) でバックポート: `keeper_server.coordination_settings.latest_logs_cache_entry_count_threshold` と `keeper_server.coordination_settings.commit_logs_cache_entry_count_threshold` を使用して、Keeper のログエントリ cache のサイズをエントリ数で制限しました。 [#84877](https://github.com/ClickHouse/ClickHouse/pull/84877) ([Antonio Andelic](https://github.com/antonio2368)).
