* [#87237](https://github.com/ClickHouse/ClickHouse/issues/87237) にバックポート: `ON CLUSTER` 句を伴う論理更新を修正しました。[#87043](https://github.com/ClickHouse/ClickHouse/pull/87043) ([Anton Popov](https://github.com/CurtizJ)).
* [#87166](https://github.com/ClickHouse/ClickHouse/issues/87166) にバックポート: 遅延マテリアライゼーションにおいて、array sizes サブカラムを持つ配列の読み取りを修正しました。[#87139](https://github.com/ClickHouse/ClickHouse/pull/87139) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87820](https://github.com/ClickHouse/ClickHouse/issues/87820) にバックポート: 関数 checkHeaders が、指定されたヘッダーを正しく検証し、禁止されたヘッダーを拒否するようになりました。元の著者: Michael Anastasakis (@michael-anastasakis)。[#87172](https://github.com/ClickHouse/ClickHouse/pull/87172) ([Raúl Marín](https://github.com/Algunenano)).
* [#87477](https://github.com/ClickHouse/ClickHouse/issues/87477) にバックポート: pathStartsWith がプレフィックス配下のパスにのみ一致するようにしました。[#87181](https://github.com/ClickHouse/ClickHouse/pull/87181) ([Raúl Marín](https://github.com/Algunenano)).
* [#87812](https://github.com/ClickHouse/ClickHouse/issues/87812) にバックポート: 別の `MergeTree` テーブルを読み取るサブクエリを含む論理更新を修正しました。[#87285](https://github.com/ClickHouse/ClickHouse/pull/87285) ([Anton Popov](https://github.com/CurtizJ)).
* [#87454](https://github.com/ClickHouse/ClickHouse/issues/87454) にバックポート: `s3_plain_rewritable` では not found エラーのみを無視するようにしました (そうしないと、さまざまな問題につながる可能性があります) 。[#87426](https://github.com/ClickHouse/ClickHouse/pull/87426) ([Azat Khuzhin](https://github.com/azat)).
* [#87728](https://github.com/ClickHouse/ClickHouse/issues/87728) にバックポート: Buffer テーブルに対する select および insert のアクセス検証を修正しました。[#87545](https://github.com/ClickHouse/ClickHouse/pull/87545) ([pufit](https://github.com/pufit)).
* [#87832](https://github.com/ClickHouse/ClickHouse/issues/87832) にバックポート: async logging (10時間で約100GiBもの大きな乖離が生じる可能性があります) および text&#95;log (ほぼ同程度の乖離が生じる可能性があります) で、追跡対象メモリがリークしないようにしました。[#87584](https://github.com/ClickHouse/ClickHouse/pull/87584) ([Azat Khuzhin](https://github.com/azat))。

* [#88507](https://github.com/ClickHouse/ClickHouse/issues/88507) にバックポート: Nullable の内側には置けない Variant から null の map サブカラムを読み取る際の不具合を修正しました。[#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar))。
* [#87907](https://github.com/ClickHouse/ClickHouse/issues/87907) にバックポート: スキップ索引に関する複数のバグを修正しました。[#87817](https://github.com/ClickHouse/ClickHouse/pull/87817) ([Raúl Marín](https://github.com/Algunenano))。
* [#88071](https://github.com/ClickHouse/ClickHouse/issues/88071) にバックポート: 最後の block が空の場合に、projections を伴う merge で発生する問題を修正しました。[#87928](https://github.com/ClickHouse/ClickHouse/pull/87928) ([Raúl Marín](https://github.com/Algunenano))。
* [#88488](https://github.com/ClickHouse/ClickHouse/issues/88488) にバックポート: クエリで `session_timezone` 設定を使用した際に、日時ベースのキーに対する granule/パーティション の除外が誤って行われる問題を修正しました。[#87987](https://github.com/ClickHouse/ClickHouse/pull/87987) ([Eduard Karacharov](https://github.com/korowa))。
* [#88145](https://github.com/ClickHouse/ClickHouse/issues/88145) にバックポート: カラム `TTL` が設定された `MergeTree` テーブルで発生しうるデータ破損の可能性を修正しました。[#88095](https://github.com/ClickHouse/ClickHouse/pull/88095) ([Anton Popov](https://github.com/CurtizJ))。

* [#88354](https://github.com/ClickHouse/ClickHouse/issues/88354) にバックポート: `system.projections` および `system.data_skipping_indices` へのアクセス時に DataLake データベースを初期化しようとしないようにしました。[#88330](https://github.com/ClickHouse/ClickHouse/pull/88330) ([Azat Khuzhin](https://github.com/azat))。
