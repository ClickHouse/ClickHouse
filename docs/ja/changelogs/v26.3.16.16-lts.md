  ### ClickHouse リリース v26.3.16.16-lts (f3c09372ed9) FIXME v26.3.15.4-lts (3c767441a1e) との比較

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#108281](https://github.com/ClickHouse/ClickHouse/issues/108281) でバックポート: JDBC、ODBC、NATS の接続文字列内の認証情報が、クエリログおよび `SHOW CREATE` の出力でマスクされるようになり、機密情報の意図しない露出を防止します。URI 形式の接続文字列 (例: {scheme}://{user}:{password}@{host}) では、パスワード部分のみがマスクされ、それ以外の部分はデバッグしやすいように表示されたままになります。`nats_token` 設定もマスクされるようになりました。 [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#108446](https://github.com/ClickHouse/ClickHouse/issues/108446) でバックポート: `JOIN ON` 内で `arrayJoin()` を使用した際に行数が誤ってカウントされる不具合を修正しました。結果が配列長の分だけ余計に乗算されていました。[#104785](https://github.com/ClickHouse/ClickHouse/pull/104785) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#107482](https://github.com/ClickHouse/ClickHouse/issues/107482) でバックポート: ベクトル検索クエリでベクトル索引を使用し、さらに `minmax` のような別のスキップ索引と `use_skip_indexes_on_data_read = 1` を併用した場合に発生していた例外を修正しました。[#106473](https://github.com/ClickHouse/ClickHouse/pull/106473) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#108259](https://github.com/ClickHouse/ClickHouse/issues/108259) でバックポート: 空の merged part に対するテキスト索引で発生する &quot;Too many marks&quot; を修正しました。[#106867](https://github.com/ClickHouse/ClickHouse/pull/106867) ([Azat Khuzhin](https://github.com/azat)).
* [#108170](https://github.com/ClickHouse/ClickHouse/issues/108170) でバックポート: `UNION`/`INTERSECT`/`EXCEPT` の一方のブランチが `Sparse` シリアライズされたカラムを読み、もう一方のブランチが同じカラムを通常の完全なカラムとして読んだ場合 (たとえば materialized view への push 時) に発生していた `Block structure mismatch in UnionStep stream` 論理エラー (debug/sanitizer build では server abort、release build では `Code: 49`) を修正しました。[#107041](https://github.com/ClickHouse/ClickHouse/pull/107041) ([Groene AI](https://github.com/groeneai)).
* [#108222](https://github.com/ClickHouse/ClickHouse/issues/108222) でバックポート: `windowFunnel` で、範囲外のイベント型を含む細工された集約関数 state を finalize した際に発生する heap buffer overflow (server crash) を修正しました。この問題は、単一の `SELECT` を実行できる任意のユーザーが到達可能でした。[#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* [#108501](https://github.com/ClickHouse/ClickHouse/issues/108501) でバックポート: `update()` 内で再構築される新しいスナップショットは、`createBuilder` を通じて C++ S3 client の現在の認証情報をすでに取り込んでいるため、バージョンが一致する場合でも破棄せず保持するようにしました。これにより、次の kernel op は最新の認証情報を持つ engine 上で実行され、STS TTL を超えて存続しなくなります。[#107480](https://github.com/ClickHouse/ClickHouse/pull/107480) ([Elmi Ahmadov](https://github.com/ahmadov)).
* [#108638](https://github.com/ClickHouse/ClickHouse/issues/108638) でバックポート: `ReplicatedMergeTree` テーブルの `RESTORE` を修正し、バックアップ内の内容が重複する part が暗黙に deduplicate されず、そのまま保持されるようにしました。[#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* [#108203](https://github.com/ClickHouse/ClickHouse/issues/108203) でバックポート: LowCardinality カラムで set スキップ索引が granule を pruning しない問題を修正しました。[#107868](https://github.com/ClickHouse/ClickHouse/pull/107868) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108304](https://github.com/ClickHouse/ClickHouse/issues/108304) でバックポート: `Map` の key が `Dynamic` で、ルックアップ argument が `LowCardinality` の場合に、`has` で発生する crash (release build では SIGSEGV、debug build では type-mismatch assertion) を修正しました。例: `has(map('a'::Dynamic, ...), toLowCardinality('b'))`。[#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* [#108196](https://github.com/ClickHouse/ClickHouse/issues/108196) でバックポート: 空のバッチであっても、アクセスキャッシュの batch-finished ハンドラーを常に実行するようにしました。[#108124](https://github.com/ClickHouse/ClickHouse/pull/108124) ([Azat Khuzhin](https://github.com/azat)).
* [#108320](https://github.com/ClickHouse/ClickHouse/issues/108320)でバックポート: ZooKeeper 接続が悪いタイミングで失われた場合に、リフレッシャブルmaterialized view が停止したままになる不具合を修正しました。 [#108234](https://github.com/ClickHouse/ClickHouse/pull/108234) ([Michael Kolupaev](https://github.com/al13n321)).
* [#108481](https://github.com/ClickHouse/ClickHouse/issues/108481)でバックポート: `format_display_secrets_in_show_and_select` が無効 (デフォルト) の場合、`EXPLAIN actions`、`EXPLAIN header`、および `EXPLAIN PIPELINE` の出力で、`encrypt`、`decrypt`、`HMAC` などの関数の機密引数を非表示にするようにしました。 [#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
* [#108693](https://github.com/ClickHouse/ClickHouse/issues/108693)でバックポート: `DESCRIBE loop('db', 'table')` および `DESCRIBE loop(<inner table function>)` が `SHOW COLUMNS` / ソースへのアクセスチェックを回避し、権限のないユーザーがテーブルのカラムスキーマを読み取れてしまうメタデータ漏えい問題を修正しました。 [#108624](https://github.com/ClickHouse/ClickHouse/pull/108624) ([Groene AI](https://github.com/groeneai)).
