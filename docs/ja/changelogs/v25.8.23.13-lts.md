<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#103184](https://github.com/ClickHouse/ClickHouse/issues/103184) でバックポート: JSONカラム上に作成された min-max 索引で誤った extreams が使用され、誤ったクエリ結果につながる問題を修正しました。[#101700](https://github.com/ClickHouse/ClickHouse/issues/101700) をクローズ。[#101918](https://github.com/ClickHouse/ClickHouse/pull/101918) ([Pavel Kruglov](https://github.com/Avogar)).
* [#102352](https://github.com/ClickHouse/ClickHouse/issues/102352) でバックポート: `addStreams` 中にストリームコンストラクタが例外をスローし、`column_streams` に null エントリが残った場合に `MergeTreeDataPartWriterWide::cancel` で発生する SIGSEGV を修正しました。[#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102968](https://github.com/ClickHouse/ClickHouse/issues/102968) でバックポート: timezone 調整後に overflow が発生した場合の日付データ型の誤った推論を修正しました。[#102601](https://github.com/ClickHouse/ClickHouse/issues/102601) をクローズ。[#102674](https://github.com/ClickHouse/ClickHouse/pull/102674) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103300](https://github.com/ClickHouse/ClickHouse/issues/103300) でバックポート: バイナリエンコードされたデータ型を含む flattened Dynamic 型のシリアライゼーションを修正しました。[#101911](https://github.com/ClickHouse/ClickHouse/issues/101911) をクローズ。[#102692](https://github.com/ClickHouse/ClickHouse/pull/102692) ([Pavel Kruglov](https://github.com/Avogar)).
* [#103018](https://github.com/ClickHouse/ClickHouse/issues/103018) でバックポート: 新しいアナライザで、行ポリシーの OR-chain を IN に最適化しました。[#102915](https://github.com/ClickHouse/ClickHouse/pull/102915) ([Azat Khuzhin](https://github.com/azat)).
* [#103663](https://github.com/ClickHouse/ClickHouse/issues/103663) でバックポート: String 型のカラムに対する Parquet ColumnIndex の統計で `min_value > max_value` となる問題を修正しました。[#103334](https://github.com/ClickHouse/ClickHouse/pull/103334) ([Saurabh Kumar Ojha](https://github.com/saurabhojha)).
* [#103408](https://github.com/ClickHouse/ClickHouse/issues/103408) でバックポート: Native フォーマットで不正な flattened Dynamic データをチェックするようにしました。[#103392](https://github.com/ClickHouse/ClickHouse/pull/103392) ([Pavel Kruglov](https://github.com/Avogar)).
