<div id="clickhouse-release-v26384-lts-f3c6e5a4d27-fixme-as-compared-to-v26378-lts-177c6aa7da1">
  ### ClickHouse リリース v26.3.8.4-lts (f3c6e5a4d27) FIXME v26.3.7.8-lts (177c6aa7da1) と比較した場合
</div>

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#102453](https://github.com/ClickHouse/ClickHouse/issues/102453)でバックポート: Array 型に対する Coalescing merge tree の修正。これにより [#89509](https://github.com/ClickHouse/ClickHouse/issues/89509) はクローズされます。[#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102479](https://github.com/ClickHouse/ClickHouse/issues/102479)でバックポート: 文字列検索関数 (`countSubstrings`、`position` など) で、null byte のみで構成された needle を検索した際に発生する範囲外読み取りを修正。[#102401](https://github.com/ClickHouse/ClickHouse/pull/102401) ([Raúl Marín](https://github.com/Algunenano)).
* [#102456](https://github.com/ClickHouse/ClickHouse/issues/102456)でバックポート: `compatibility` 設定が 26.1 より古いバージョンを指している場合でも、フルテキスト索引の設定 (`enable_full_text_index`、`allow_experimental_full_text_index`、`use_skip_indexes_on_data_read`) が無効化されなくなりました。従来は、このために `SharedDatabaseCatalog` がテキスト索引付きのテーブルを作成できなくなる可能性がありました。[#102422](https://github.com/ClickHouse/ClickHouse/pull/102422) ([Nikita Fomichev](https://github.com/fm4v)).
