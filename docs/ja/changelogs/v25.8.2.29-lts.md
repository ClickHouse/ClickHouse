<div id="new-feature">

* [#86620](https://github.com/ClickHouse/ClickHouse/issues/86620) にバックポート: SELECTステートメント中にIcebergメタデータファイルを取得するためのシステムテーブル `iceberg_metadata_log` を追加しました。 [#86152](https://github.com/ClickHouse/ClickHouse/pull/86152) ([Konstantin Vedernikov](https://github.com/scanhex12)).

<div id="improvement">
  #### 改善
</div>

* [#86333](https://github.com/ClickHouse/ClickHouse/issues/86333) にバックポート: `allow_experimental_delta_lake_writes` を追加しました。 [#86180](https://github.com/ClickHouse/ClickHouse/pull/86180) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#86493](https://github.com/ClickHouse/ClickHouse/issues/86493) にバックポート: 特定のチャネルでのみ JSON ログを有効にできるようにしました。これには、`logger.formatting.channel` を `syslog`/`console`/`errorlog`/`log` のいずれかに設定します。 [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#86614](https://github.com/ClickHouse/ClickHouse/issues/86614) にバックポート: データベースレプリカの復旧時にテーブルを適切にシャットダウンするよう修正しました。不適切なシャットダウンにより、データベースレプリカの復旧中に一部のテーブルエンジンで LOGICAL&#95;ERROR が発生していました。 [#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* [#86386](https://github.com/ClickHouse/ClickHouse/issues/86386) にバックポート: SQL からディスクを作成する際、デフォルトで `/etc/metrika.xml` の include を処理するよう修正しました。 [#86232](https://github.com/ClickHouse/ClickHouse/pull/86232) ([alekar](https://github.com/alekar)).
* [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653) にバックポート: plain&#95;rewritable ディスクで Azure blob storage から空のブロブを読み込む際に発生する `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` を修正しました。 [#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* [#86457](https://github.com/ClickHouse/ClickHouse/issues/86457) にバックポート: Materialized Views の不具合を修正しました。MV は、作成後に削除され、その後同じ名前で再作成された場合に動作しないことがありました。 [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#86468](https://github.com/ClickHouse/ClickHouse/issues/86468) にバックポート: `Buffer` テーブルによる `MergesMutationsMemoryTracking` のリークを修正し、`Kafka` (およびその他) からのストリーミングにおける `query_views_log` を修正しました。 [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
* [#86549](https://github.com/ClickHouse/ClickHouse/issues/86549) にバックポート: getSubcolumnType における未初期化メモリの使用を修正しました。 [#86498](https://github.com/ClickHouse/ClickHouse/pull/86498) ([Raúl Marín](https://github.com/Algunenano)).
* [#86582](https://github.com/ClickHouse/ClickHouse/issues/86582) にバックポート: シャットダウン時のログの flush 中に発生する例外を無視するようにし、シャットダウンの安全性を向上させました (SIGSEGV の回避) 。 [#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
