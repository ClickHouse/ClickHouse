<div id="improvement">
  #### 改善
</div>

* [#72060](https://github.com/ClickHouse/ClickHouse/issues/72060) でバックポート: Dictionary ストレージ、dictionary table function、または Dictionary 自体に対する直接の `SELECT` を使用して Dictionary からデータを直接取得する場合、その Dictionary に対する `SELECT` 権限または `dictGet` 権限があれば十分になりました。これは、ACL バイパスを防ぐためのこれまでの取り組みと整合しています: [https://github.com/ClickHouse/ClickHouse/pull/57362](https://github.com/ClickHouse/ClickHouse/pull/57362) および [https://github.com/ClickHouse/ClickHouse/pull/65359](https://github.com/ClickHouse/ClickHouse/pull/65359)。また、後者との後方互換性も確保されます。 [#72051](https://github.com/ClickHouse/ClickHouse/pull/72051) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#71981](https://github.com/ClickHouse/ClickHouse/issues/71981) でバックポート: [この issue](https://github.com/ClickHouse/ClickHouse/pull/59946#issuecomment-1943653197) 以降、本番環境では `metadata_version` node の値が `0` である一方、対応する table の `metadata` node のバージョンとは異なっている table レプリカがかなり存在します。これにより、そのようなレプリカでは `alter` クエリが失敗します。[#69274](https://github.com/ClickHouse/ClickHouse/pull/69274) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#72142](https://github.com/ClickHouse/ClickHouse/issues/72142) でバックポート: Keeper が利用できない場合に発生しうるデータ損失を防ぐため、part を zero-copy ディスクへ移動する前に zero-copy shared lock を取得するようにしました。[#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72038](https://github.com/ClickHouse/ClickHouse/issues/72038) でバックポート: 主キーが DateTime64 型の場合の WHERE 条件における toDayOfWeek の例外を修正しました。[#71849](https://github.com/ClickHouse/ClickHouse/pull/71849) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#72032](https://github.com/ClickHouse/ClickHouse/issues/72032) でバックポート: 最初の argument が定数である場合に、`ORDER BY` で binary monotonic function を使用した `MergeTree` table で発生する `Illegal type` error を修正しました。[#71941](https://github.com/ClickHouse/ClickHouse/issues/71941) を修正。[#71966](https://github.com/ClickHouse/ClickHouse/pull/71966) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#72155](https://github.com/ClickHouse/ClickHouse/issues/72155) でバックポート: サブクエリ内で使用される EXPLAIN AST では SELECT クエリのみを許可するようにしました。それ以外の種類のクエリでは、論理エラー: &#39;Bad cast from type DB::ASTCreateQuery to DB::ASTSelectWithUnionQuery&#39; または `Inconsistent AST formatting` が発生します。[#71982](https://github.com/ClickHouse/ClickHouse/pull/71982) ([Pavel Kruglov](https://github.com/Avogar)).
* [#72114](https://github.com/ClickHouse/ClickHouse/issues/72114) でバックポート: `format_alter_commands_with_parentheses` が有効なときの `MOVE PARTITION ... TO TABLE ...` alter command のフォーマットを修正しました。[#72080](https://github.com/ClickHouse/ClickHouse/pull/72080) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
