* [#92030](https://github.com/ClickHouse/ClickHouse/issues/92030) でバックポート: 非リテラルなパラメータに対する GenerateRandom エンジンのクラッシュを修正し、LOGICAL&#95;ERROR ではなく、明確なメッセージ付きの BAD&#95;ARGUMENTS を返すようにしました。[#88157](https://github.com/ClickHouse/ClickHouse/pull/88157) ([Shafi Ahmed](https://github.com/ita004))。
* [#90415](https://github.com/ClickHouse/ClickHouse/issues/90415) でバックポート: 破棄順序の誤りにより、server の正常なシャットダウン中に発生していたクラッシュを修正しました。[#82420](https://github.com/ClickHouse/ClickHouse/issues/82420) を解決します。[#90076](https://github.com/ClickHouse/ClickHouse/pull/90076) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#94008](https://github.com/ClickHouse/ClickHouse/issues/94008) でバックポート: randomStringUTF8 で発生する整数 overflow によるクラッシュを修正しました。[#90326](https://github.com/ClickHouse/ClickHouse/pull/90326) ([Michael Kolupaev](https://github.com/al13n321))。
* [#93555](https://github.com/ClickHouse/ClickHouse/issues/93555) でバックポート: 不正な形式の `groupConcat` aggregate state を範囲外の offsets でデシリアライズした際に発生するクラッシュを修正しました。[#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath))。
* [#93468](https://github.com/ClickHouse/ClickHouse/issues/93468) でバックポート: 細工された aggregate states によってメモリ安全性の問題を引き起こす可能性があった、`groupConcat` state のデシリアライゼーションにおける整数 overflow の脆弱性を修正しました。[#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath))。
* [#93684](https://github.com/ClickHouse/ClickHouse/issues/93684) でバックポート: シャットダウン時に ZooKeeper が確実に終了処理されるようにしました (ごくまれなケースで発生しうるシャットダウン時のハングを修正) 。[#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat))。
* [#93950](https://github.com/ClickHouse/ClickHouse/issues/93950) でバックポート: deduplication race がある状態で ReplicatedMergeTree を復元する際に発生する LOGICAL&#95;ERROR を修正しました。[#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos))。
* [#93961](https://github.com/ClickHouse/ClickHouse/issues/93961) でバックポート: 一部の input formats において、スパースカラムへの直接デシリアライゼーション時に TTL 更新用の Sparse column を使用する処理を修正しました。これにより、論理エラー `Unexpected type of result TTL column` が発生する可能性を解消しました。[#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar))。
* [#93804](https://github.com/ClickHouse/ClickHouse/issues/93804) でバックポート: 展開後の buffer サイズが想定どおりであることを検証するようにしました。[#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano))。
* [#93794](https://github.com/ClickHouse/ClickHouse/issues/93794) でバックポート: `merge` table engine を使用して `SHOW COLUMNS` permission を確認せずに users が table からカラム一覧を取得できないようにしました。[#93695](https://github.com/ClickHouse/ClickHouse/pull/93695) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
