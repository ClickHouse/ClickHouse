<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#79662](https://github.com/ClickHouse/ClickHouse/issues/79662) でバックポート: 右テーブルのサイズが閾値未満の場合に `hash` アルゴリズムにフォールバックするための閾値 (設定 `parallel_hash_join_threshold` で制御) を導入しました。[#76185](https://github.com/ClickHouse/ClickHouse/pull/76185) ([Nikita Taranov](https://github.com/nickitat)).
* [#79728](https://github.com/ClickHouse/ClickHouse/issues/79728) でバックポート: 並列レプリカを使用した分散 `INSERT SELECT` のパフォーマンスを改善しました。[#79441](https://github.com/ClickHouse/ClickHouse/pull/79441) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#79502](https://github.com/ClickHouse/ClickHouse/issues/79502) でバックポート: &#96;&#96;&#96;sql CREATE TABLE t0 ( key Int32, value Int32 ) ENGINE=MergeTree() PRIMARY KEY key PARTITION BY key % 2;. [#78593](https://github.com/ClickHouse/ClickHouse/pull/78593) ([Vlad](https://github.com/codeworse)).
* [#79435](https://github.com/ClickHouse/ClickHouse/issues/79435) でバックポート: バッチ挿入があるテーブルで arrayUnion() が余分な (誤った) 値を返す不具合を修正しました。[#79157](https://github.com/ClickHouse/ClickHouse/issues/79157) を修正しました。[#79158](https://github.com/ClickHouse/ClickHouse/pull/79158) ([Peter Nguyen](https://github.com/petern48)).
* [#79607](https://github.com/ClickHouse/ClickHouse/issues/79607) でバックポート: データを含む plain&#95;rewritable ディスクの読み込みを修正しました。[#79439](https://github.com/ClickHouse/ClickHouse/pull/79439) ([Julia Kartseva](https://github.com/jkartseva)).
* [#79525](https://github.com/ClickHouse/ClickHouse/issues/79525) でバックポート: スパースカラムを持つテーブルにおいて、いくつかのケースで発生していた `Block structure mismatch` エラーを修正しました。[#79491](https://github.com/ClickHouse/ClickHouse/pull/79491) ([Anton Popov](https://github.com/CurtizJ)).
* [#79616](https://github.com/ClickHouse/ClickHouse/issues/79616) でバックポート: `use_hedged_requests` と `allow_experimental_parallel_reading_from_replicas` の両方が無効な場合に、リモートからの読み取りで結果が重複する問題を修正しました。[#79599](https://github.com/ClickHouse/ClickHouse/pull/79599) ([Eduard Karacharov](https://github.com/korowa)).
