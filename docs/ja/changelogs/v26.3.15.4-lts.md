<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#108279](https://github.com/ClickHouse/ClickHouse/issues/108279)でバックポート: MsgPack、BSON、ORC、Parquet、JSON、Delta Lake、Iceberg、Paimon フォーマットで、深くネストしたスキーマまたは値を読み込む際に発生しうるサーバーのスタックオーバーフロー (クラッシュ) を修正しました。このような深くネストした入力は、現在では例外を発生させて拒否されます。[#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano))。
* [#108237](https://github.com/ClickHouse/ClickHouse/issues/108237)でバックポート: Elf および DWARF のパースで不足していた境界チェックを追加しました。[#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321))。
* [#108157](https://github.com/ClickHouse/ClickHouse/issues/108157)でバックポート: Apache Arrow Java &lt; 19.0.0 (Apache Spark を含む) で生成された空の `String`/`Binary` カラムを持つ Arrow/ArrowStream データの読み取りで、`INCORRECT_DATA` がスローされなくなりました。[#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano))。
