<div id="improvement">
  #### 改善
</div>

* [#82862](https://github.com/ClickHouse/ClickHouse/issues/82862) にバックポート: [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 以降、`X-ClickHouse-Progress` と `X-ClickHouse-Summary` のヘッダーフォーマットはゼロ値を省略するよう変更されました。この PR では、`X-ClickHouse-Summary` についてのみ、妥当であるため従来の動作に戻します。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#84037](https://github.com/ClickHouse/ClickHouse/issues/84037) にバックポート: cgroup の情報 (該当する場合、つまり `memory_worker_use_cgroup` が有効で cgroup が利用可能な場合) を使用して、memory tracker (`memory_worker_correct_memory_tracker`) を調整します。[#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#83144](https://github.com/ClickHouse/ClickHouse/issues/83144) にバックポート: `lowCardinalityKeys` 関数で、共有 Dictionary の無関係なパーツを使用しないようにしました。[#83118](https://github.com/ClickHouse/ClickHouse/pull/83118) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#83766](https://github.com/ClickHouse/ClickHouse/issues/83766) にバックポート: Keeper の修正: session の close 時に ephemeral ノードが削除された場合、watch の総数が正しく更新されるようにしました。[#83583](https://github.com/ClickHouse/ClickHouse/pull/83583) ([Antonio Andelic](https://github.com/antonio2368)).
* [#84109](https://github.com/ClickHouse/ClickHouse/issues/84109) にバックポート: Avro スキーマレジストリの authentication 情報が、ユーザーやログから見えないようにマスクしました。[#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#83917](https://github.com/ClickHouse/ClickHouse/issues/83917) にバックポート: MergeTree table を `add_minmax_index_for_numeric_columns=1` または `add_minmax_index_for_string_columns=1` を指定して作成し、その後 ALTER 操作中にその索引が materialized されると、新しいレプリカ上で Replicated database が正しく初期化されなくなる問題を修正しました。[#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#83874](https://github.com/ClickHouse/ClickHouse/issues/83874) にバックポート: 名前衝突がある場合に、新しいアナライザで WITH Clause 内から外側の alias を参照できるようにする backward compatibility setting を導入しました。[#82700](https://github.com/ClickHouse/ClickHouse/issues/82700) を修正。[#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* [#84092](https://github.com/ClickHouse/ClickHouse/issues/84092) にバックポート: バックアップ から復元する際、definer USER がバックアップされていないことがあり、その結果 バックアップ 全体が壊れてしまう可能性があります。これを修正するため、復元時のターゲットテーブル作成に対する permission のチェックを延期し、runtime 中にのみ確認するようにしました。[#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* [#84224](https://github.com/ClickHouse/ClickHouse/issues/84224) にバックポート: アナライザが enabled の場合、`remote` table function の `view(...)` argument で任意の table を参照できるようにしました。[#78717](https://github.com/ClickHouse/ClickHouse/issues/78717) を修正。[#79377](https://github.com/ClickHouse/ClickHouse/issues/79377) を修正。[#83844](https://github.com/ClickHouse/ClickHouse/pull/83844) ([Dmitry Novik](https://github.com/novikd)).
* [#84129](https://github.com/ClickHouse/ClickHouse/issues/84129) にバックポート: `MATERIALIZE COLUMN` クエリによって `checksums.txt` に予期しないファイルが生成され、最終的にデタッチされた data parts につながるまれな不具合を修正しました。[#84007](https://github.com/ClickHouse/ClickHouse/pull/84007) ([alesapin](https://github.com/alesapin)).
* [#84272](https://github.com/ClickHouse/ClickHouse/issues/84272) にバックポート: クエリ condition cache を再帰 CTE と組み合わせて使用した場合に、誤った結果になる問題を修正しました (issue [#81506](https://github.com/ClickHouse/ClickHouse/issues/81506))。[#84026](https://github.com/ClickHouse/ClickHouse/pull/84026) ([zhongyuankai](https://github.com/zhongyuankai)).
* [#84288](https://github.com/ClickHouse/ClickHouse/issues/84288) にバックポート: table に projection があり、`lightweight_mutation_projection_mode = 'rebuild'` が設定されていて、ユーザーが table 内のいずれかの block から全行を削除する lighweight delete を実行した場合に、まれに ClickHouse が crash する問題を修正しました。[#84158](https://github.com/ClickHouse/ClickHouse/pull/84158) ([alesapin](https://github.com/alesapin)).
