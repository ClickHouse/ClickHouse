<div id="performance-improvement">
  #### パフォーマンス改善

* [#83337](https://github.com/ClickHouse/ClickHouse/issues/83337) にバックポート: QueryTreeHash を少し高速化。[#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="improvement">
  #### 改善
</div>

* [#82503](https://github.com/ClickHouse/ClickHouse/issues/82503) にバックポート: サーバーを再起動せずに、`max_local_read_bandwidth_for_server` と `max_local_write_bandwidth_for_server` を動的に再読み込みできるようにしました。[#82083](https://github.com/ClickHouse/ClickHouse/pull/82083) ([Kai Zhu](https://github.com/nauu))。
* [#83012](https://github.com/ClickHouse/ClickHouse/issues/83012) にバックポート: Keeper の改善: changelogファイルをバックグラウンドスレッドでディスク間移動するようにしました。以前は、changelog を別のディスクに移動すると、移動が完了するまで Keeper 全体がブロックされていました。移動に長時間かかる場合 (たとえば S3ディスクへの移動) は、これによりパフォーマンスが低下していました。[#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368))。
* [#82856](https://github.com/ClickHouse/ClickHouse/issues/82856) にバックポート: [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 以降、`X-ClickHouse-Progress` および `X-ClickHouse-Summary` のヘッダーフォーマットは、ゼロ値を省略するよう変更されていました。この PR では、`X-ClickHouse-Summary` についてのみ、従来の動作に戻しています。こちらのほうが妥当なためです。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#79891](https://github.com/ClickHouse/ClickHouse/issues/79891) でバックポート: アナライザ使用時にセカンダリ索引が適用されないことがある問題を修正しました。[#65607](https://github.com/ClickHouse/ClickHouse/issues/65607) を修正、[#69373](https://github.com/ClickHouse/ClickHouse/issues/69373) を修正。 [#78485](https://github.com/ClickHouse/ClickHouse/pull/78485) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#83254](https://github.com/ClickHouse/ClickHouse/issues/83254) でバックポート: external table engines における cache 済み buffer の境界アラインメント無効化の不具合を修正しました。この不具合は [https://github.com/ClickHouse/ClickHouse/pull/81868](https://github.com/ClickHouse/ClickHouse/pull/81868) で混入していました。 [#82493](https://github.com/ClickHouse/ClickHouse/pull/82493) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#82796](https://github.com/ClickHouse/ClickHouse/issues/82796) でバックポート: 要素が空の場合の `groupArraySample`/`groupArrayLast` のデシリアライゼーションを修正しました (入力が空の場合、デシリアライゼーションが binary の一部をスキップしてしまうことがあり、これによりデータ読み取り時の破損や TCP protocol での UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER につながる可能性がありました) 。これは numbers と date time types には影響しません。 [#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
* [#83108](https://github.com/ClickHouse/ClickHouse/issues/83108) でバックポート: union/intersect/except&#95;default&#95;mode rewrite における例外安全性の問題を修正しました。 [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664) をクローズ。 [#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#82991](https://github.com/ClickHouse/ClickHouse/issues/82991) でバックポート: Caching を行わない Database 実装を使用した場合、対応する table のメタデータがカラム返却後に削除され、参照が無効化される問題を修正しました。 [#82939](https://github.com/ClickHouse/ClickHouse/pull/82939) ([buyval01](https://github.com/buyval01)).
* [#83023](https://github.com/ClickHouse/ClickHouse/issues/83023) でバックポート: storage `Merge` を持つ table との JOIN expression を含むクエリに対する filter の変更処理を修正しました。 [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092) を修正。 [#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd)).
* [#83307](https://github.com/ClickHouse/ClickHouse/issues/83307) でバックポート: QueryMetricLog における LOGICAL&#95;ERROR: Mutex cannot be NULL を修正しました。 [#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos)).
* [#83080](https://github.com/ClickHouse/ClickHouse/issues/83080) でバックポート: function `formatDateTime` でフォーマッタ `%f` を可変長フォーマッタ (例: `%M`) と併用した際に出力が誤る問題を修正しました。 [#83020](https://github.com/ClickHouse/ClickHouse/pull/83020) ([Robert Schulze](https://github.com/rschu1ze)).
* 25.3 におけるこのバグを修正しました (25.4+ ではこの問題は該当しません)  [#82601](https://github.com/ClickHouse/ClickHouse/issues/82601)。 [#83226](https://github.com/ClickHouse/ClickHouse/pull/83226) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#83402](https://github.com/ClickHouse/ClickHouse/issues/83402) でバックポート: S3 client の `no_sign_request` を修正しました。これは S3 requests への署名を明示的に回避するために使用できます。また、endpoint ベースの settings を使って特定の endpoints に対して定義することもできます。 [#83379](https://github.com/ClickHouse/ClickHouse/pull/83379) ([Antonio Andelic](https://github.com/antonio2368)).
* [#83464](https://github.com/ClickHouse/ClickHouse/issues/83464) でバックポート: CTE 定義が同名の別のテーブル式を参照している場合に `TOO_DEEP_SUBQUERIES` 例外が発生する問題を修正しました。[#83413](https://github.com/ClickHouse/ClickHouse/pull/83413) ([Dmitry Novik](https://github.com/novikd))。
* [#83668](https://github.com/ClickHouse/ClickHouse/issues/83668) でバックポート: max&#95;untracked&#95;memory 周辺のメモリ処理の誤りを修正しました。[#83607](https://github.com/ClickHouse/ClickHouse/pull/83607) ([Azat Khuzhin](https://github.com/azat))。
* [#83660](https://github.com/ClickHouse/ClickHouse/issues/83660) でバックポート: INSERT SELECT で UNION ALL を使用した場合、まれなケースで null ポインタの逆参照が発生する可能性がある問題を修正しました。これにより [#83618](https://github.com/ClickHouse/ClickHouse/issues/83618) をクローズしました。[#83643](https://github.com/ClickHouse/ClickHouse/pull/83643) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
