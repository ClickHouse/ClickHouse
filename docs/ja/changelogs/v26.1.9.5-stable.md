* [#102620](https://github.com/ClickHouse/ClickHouse/issues/102620) でバックポート: 接続プールの use-after-free により、s3Cluster と分散クエリで発生するセグメンテーション違反を修正しました。[#100837](https://github.com/ClickHouse/ClickHouse/pull/100837) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#102535](https://github.com/ClickHouse/ClickHouse/issues/102535) でバックポート: `IStorage::getDependentViewsByColumn` の `storage_id` におけるデータ競合を修正しました。[#101385](https://github.com/ClickHouse/ClickHouse/pull/101385) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#102449](https://github.com/ClickHouse/ClickHouse/issues/102449) でバックポート: Array 型に対する coalescing merge tree の不具合を修正しました。これで [#89509](https://github.com/ClickHouse/ClickHouse/issues/89509) をクローズします。[#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102583](https://github.com/ClickHouse/ClickHouse/issues/102583) でバックポート: Database Replicated で、ターゲットテーブルのないエイリアステーブルが新規レプリカ上で初期化に失敗する問題を修正しました。[#101320](https://github.com/ClickHouse/ClickHouse/issues/101320) をクローズします。[#102397](https://github.com/ClickHouse/ClickHouse/pull/102397) ([Nikolay Degterinsky](https://github.com/evillique)).
