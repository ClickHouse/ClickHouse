<div id="improvement">
  #### 改善
</div>

* [#101603](https://github.com/ClickHouse/ClickHouse/issues/101603)でバックポート: Cgroupv2 のメモリ追跡で、カーネルメモリから `slab_reclaimable` を除外するようになり、回収不能なメモリ使用量をより正確に把握できるようになりました。[#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)).
* [#101868](https://github.com/ClickHouse/ClickHouse/issues/101868)でバックポート: テキスト索引は GA となり、`compatibility` 設定に関係なく常に有効のままになりました。これにより、バックアップの復元時や互換性モードでの実行時に予期せず無効化されるのを防ぎます。[#101518](https://github.com/ClickHouse/ClickHouse/pull/101518) ([Nikita Fomichev](https://github.com/fm4v)).
* [#101862](https://github.com/ClickHouse/ClickHouse/issues/101862)でバックポート: libarchive を 3.8.5 から 3.8.6 に更新。[#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)).
* [#101856](https://github.com/ClickHouse/ClickHouse/issues/101856)でバックポート: curl を 8.18 から 8.19 に更新。[#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#101461](https://github.com/ClickHouse/ClickHouse/issues/101461) でバックポート: Keeper で、同じサーバー上の別の無関係なセッションがちょうど不運なタイミングで閉じられると、読み取りリクエストがハングして (その結果セッションがタイムアウトし) 、処理が進まなくなる不具合を修正しました。 [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* [#101689](https://github.com/ClickHouse/ClickHouse/issues/101689) でバックポート: ベクトル類似度検索中にクラッシュや、気付きにくいメモリ破損を引き起こす可能性があった usearch `sorted_buffer_gt::insert()` の heap-buffer-overflow を修正しました。 [#100537](https://github.com/ClickHouse/ClickHouse/pull/100537) ([Dustin Healy](https://github.com/dustinhealy)).
* [#101633](https://github.com/ClickHouse/ClickHouse/issues/101633) でバックポート: 小数秒が 18 桁を超える datetime 文字列のパース時に `parseDateTimeBestEffort` で発生していた未定義動作 (符号付き整数オーバーフロー) を修正しました。 [#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* [#101364](https://github.com/ClickHouse/ClickHouse/issues/101364) でバックポート: JIT コンパイルが有効な場合 (コンパイル閾値到達後) に、`Decimal` カラムに対する `MAX`/`MIN` 集約関数が誤った結果を返す不具合を修正しました。 [#101203](https://github.com/ClickHouse/ClickHouse/pull/101203) ([Raúl Marín](https://github.com/Algunenano)).
* [#101625](https://github.com/ClickHouse/ClickHouse/issues/101625) でバックポート: クエリが Dynamic Map type を含む Tuple カラムとそのサブカラムを同時に読み取ると発生するサーバークラッシュ (論理エラー: &quot;Variant ... is empty&quot;) を修正しました (例: `SELECT ... WHERE NOT ignore(*, mapKeys(t.m))`) 。 [#101448](https://github.com/ClickHouse/ClickHouse/pull/101448) ([Groene AI](https://github.com/groeneai)).
