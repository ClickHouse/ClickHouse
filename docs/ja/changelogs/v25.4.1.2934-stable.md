<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* `allow_materialized_view_with_bad_select` が `false` の場合、materialized view 内のすべてのカラムがターゲットテーブルと一致していることを確認するようにしました。 [#74481](https://github.com/ClickHouse/ClickHouse/pull/74481) ([Christoph Wurm](https://github.com/cwurm)).
* `dateTrunc` を負の date/datetime 引数とともに使用した場合の不具合を修正しました。 [#77622](https://github.com/ClickHouse/ClickHouse/pull/77622) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 従来の MongoDB インテグレーションを削除しました。サーバー設定 `use_legacy_mongodb_integration` は廃止され、現在は何も行いません。 [#77895](https://github.com/ClickHouse/ClickHouse/pull/77895) ([Robert Schulze](https://github.com/rschu1ze)).
* SummingMergeTree の検証を強化し、パーティションキーまたはソートキーで使用されるカラムについては aggregation をスキップするようにしました。 [#78022](https://github.com/ClickHouse/ClickHouse/pull/78022) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).



<div id="new-feature">
  #### 新機能
</div>

* [#79232](https://github.com/ClickHouse/ClickHouse/issues/79232) でバックポート: 指定したカラムに対して CREATE クエリで明示的に定義されていない場合に、デフォルトの圧縮コーデックを指定できる MergeTree SETTINGS の新しいオプションを追加しました。これにより [#42005](https://github.com/ClickHouse/ClickHouse/issues/42005) をクローズします。 [#66394](https://github.com/ClickHouse/ClickHouse/pull/66394) ([gvoelfin](https://github.com/gvoelfin)).
* Distributed queries 向けにクエリプランをシリアライズします。新しい設定 `serialize_query_plan` が追加されました。有効にすると、`Distributed` table からのクエリは、remote query の実行にシリアライズされたクエリプランを使用します。これにより TCP プロトコルに新しいパケットタイプが導入され、このパケットの処理を許可するにはサーバー設定に `<process_query_plan_packet>true</process_query_plan_packet>` を追加する必要があります。 [#69652](https://github.com/ClickHouse/ClickHouse/pull/69652) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 特定の timestamp 時点の Iceberg table をクエリするための設定を追加しました。 [#71072](https://github.com/ClickHouse/ClickHouse/pull/71072) ([Brett Hoerner](https://github.com/bretthoerner)).
* low cardinality Decimal data types をサポートし、[#72256](https://github.com/ClickHouse/ClickHouse/issues/72256) を修正しました。 [#72833](https://github.com/ClickHouse/ClickHouse/pull/72833) ([zhanglistar](https://github.com/zhanglistar)).
* AzureBlobStorage 向けの DeltaLake table engine をサポートしました。[#68043](https://github.com/ClickHouse/ClickHouse/issues/68043) を修正します。 [#74541](https://github.com/ClickHouse/ClickHouse/pull/74541) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* clickhouse client connections の送信元 IP アドレスを設定するための bind&#95;host 設定を追加しました。 [#74741](https://github.com/ClickHouse/ClickHouse/pull/74741) ([Todd Yocum](https://github.com/toddyocum)).
* system.tables に parametrized&#95;view&#95;parameters を導入しました。https://github.com/clickhouse/clickhouse/issues/66756 をクローズします。 [#75112](https://github.com/ClickHouse/ClickHouse/pull/75112) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* データベースコメントの変更を許可しました。[#73351](https://github.com/ClickHouse/ClickHouse/issues/73351) をクローズします。 ### ユーザー向け変更のドキュメント項目。 [#75622](https://github.com/ClickHouse/ClickHouse/pull/75622) ([NamNguyenHoai](https://github.com/NamHoaiNguyen)).
* [#79361](https://github.com/ClickHouse/ClickHouse/issues/79361) でバックポート: WHERE clause の `EXISTS` expression の argument として相関 subqueries をサポートしました。[#72459](https://github.com/ClickHouse/ClickHouse/issues/72459) をクローズします。 [#76078](https://github.com/ClickHouse/ClickHouse/pull/76078) ([Dmitry Novik](https://github.com/novikd)).
* Scram SHA256 および postgres wire auth を更新しました。 [#76839](https://github.com/ClickHouse/ClickHouse/pull/76839) ([scanhex12](https://github.com/scanhex12)).
* `IcebergMetadataFilesCache` をサポートし、マニフェストファイルのリストと metadata.json を 1 つの cache に保存します。 [#77156](https://github.com/ClickHouse/ClickHouse/pull/77156) ([Han Fei](https://github.com/hanfei1991)).
* 関数 `arrayLevenshteinDistance`、`arrayLevenshteinDistanceWeighted`、および `arraySimilarity` を追加しました。 [#77187](https://github.com/ClickHouse/ClickHouse/pull/77187) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 過去のある時点に存在していた Iceberg table の状態をユーザーがクエリできるようにしました。 [#77439](https://github.com/ClickHouse/ClickHouse/pull/77439) ([Daniil Ivanik](https://github.com/divanik)).
* workloads 向けに CPU slot scheduling を追加しました。詳細は https://clickhouse.com/docs/operations/workload-scheduling#cpu&#95;scheduling を参照してください。 [#77595](https://github.com/ClickHouse/ClickHouse/pull/77595) ([Sergei Trifonov](https://github.com/serxa)).
* hasAll() 関数で、tokenbf&#95;v1、ngrambf&#95;v1 の全文検索用スキッピング索引を活用できるようになりました。[#77662](https://github.com/ClickHouse/ClickHouse/pull/77662) ([UnamedRus](https://github.com/UnamedRus))。
* `JSON` データ型は本番環境で利用可能になりました。https://jsonbench.com/ を参照してください。`Dynamic` および `Varaint` データ型も本番環境で利用可能です。[#77785](https://github.com/ClickHouse/ClickHouse/pull/77785) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* デシリアライズ済みのベクトル類似度索引向けにインメモリ cache を追加しました。これにより、近似最近傍 (ANN) 検索クエリを繰り返し実行する際の速度向上が見込まれます。新しい cache のサイズは、server settings `vector_similarity_index_cache_size` および `vector_similarity_index_cache_max_entries` で制御されます。この機能は、以前の release にあったスキッピング索引 cache 機能に代わるものです。[#77905](https://github.com/ClickHouse/ClickHouse/pull/77905) ([Shankar Iyer](https://github.com/shankar-iyer))。
* [#79343](https://github.com/ClickHouse/ClickHouse/issues/79343) でバックポート: TBD。[#78041](https://github.com/ClickHouse/ClickHouse/pull/78041) ([Igor Nikonov](https://github.com/devcrafter))。
* UTF-8 版の sparseGrams および sparseGramsHashes 関数を追加しました。著者: [scanhex12](https://github.com/scanhex12)。[#78176](https://github.com/ClickHouse/ClickHouse/pull/78176) ([Pervakov Grigorii](https://github.com/GrigoryPervakov))。
* `toInterval` 関数を導入しました。この関数は 2 つの引数 (value と unit) を受け取り、その値を特定の `Interval` 型に変換します。[#78723](https://github.com/ClickHouse/ClickHouse/pull/78723) ([Andrew Davis](https://github.com/pulpdrew))。



<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 未使用のカラムを読み込まないようにする lazy projection により、パフォーマンスを最適化しました。[#55518](https://github.com/ClickHouse/ClickHouse/pull/55518) ([Xiaozhe Yu](https://github.com/wudidapaopao)).
* `NativeORCBlockInputFormat` で非同期 I/O prefetch をサポートし、リモート I/O のレイテンシを隠蔽することで全体的なパフォーマンスを向上させました。私のテストケースでは、最大 1.47 倍の高速化を確認しました。[#70534](https://github.com/ClickHouse/ClickHouse/pull/70534) ([李扬](https://github.com/taiyang-li)).
* パフォーマンス向上のため、非同期 INSERT で使用するメモリを事前割り当てするようにしました。[#74945](https://github.com/ClickHouse/ClickHouse/pull/74945) ([Ilya Golshtein](https://github.com/ilejn)).
* 不要な null map の割り当てを避けるため、wrapInNullable に軽微な最適化を加えました。[#76489](https://github.com/ClickHouse/ClickHouse/pull/76489) ([李扬](https://github.com/taiyang-li)).
* arraySort を最適化しました。[#76850](https://github.com/ClickHouse/ClickHouse/pull/76850) ([李扬](https://github.com/taiyang-li)).
* `col->insertFrom()` の呼び出しの仮想化を排除することで、JOIN result の構築を高速化しました。[#77350](https://github.com/ClickHouse/ClickHouse/pull/77350) ([Alexander Gololobov](https://github.com/davenger)).
* 同じ part の marks をマージし、まとめて query condition cache に書き込むことで、lock の使用量を削減しました。[#77377](https://github.com/ClickHouse/ClickHouse/pull/77377) ([zhongyuankai](https://github.com/zhongyuankai)).
* 1 つのブラケット展開を含むクエリに対する s3Cluster のパフォーマンスを最適化しました。[#77686](https://github.com/ClickHouse/ClickHouse/pull/77686) ([Tomáš Hromada](https://github.com/gyfis)).
* 単一の Nullable または低カーディナリティのカラムに対する order by を最適化しました。[#77789](https://github.com/ClickHouse/ClickHouse/pull/77789) ([李扬](https://github.com/taiyang-li)).
* merge など、cache が受動的に使われる場合は `filesystem_cache_prefer_bigger_buffer_size` を無効にしました。[#77898](https://github.com/ClickHouse/ClickHouse/pull/77898) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Iceberg 向けに単純な count 最適化を実装しました。これにより、`count()` を使い、filters を指定しないクエリはより高速になります。[#77639](https://github.com/ClickHouse/ClickHouse/issues/77639) をクローズしました。[#78090](https://github.com/ClickHouse/ClickHouse/pull/78090) ([alesapin](https://github.com/alesapin)).
* カラムの lower&#95;bound および upper&#95;bound の値に基づく Iceberg のデータプルーニングをサポートしました。[#77638](https://github.com/ClickHouse/ClickHouse/issues/77638) を修正しました。[#78242](https://github.com/ClickHouse/ClickHouse/pull/78242) ([alesapin](https://github.com/alesapin)).
* NativeReader のメモリ使用量を最適化しました。[#78442](https://github.com/ClickHouse/ClickHouse/pull/78442) ([Azat Khuzhin](https://github.com/azat)).
* 軽微な最適化: CAST が必要な場合、count(if()) を countIf に書き換えないようにしました。[#78564](https://github.com/ClickHouse/ClickHouse/issues/78564) をクローズしました。[#78565](https://github.com/ClickHouse/ClickHouse/pull/78565) ([李扬](https://github.com/taiyang-li)).
* [#79163](https://github.com/ClickHouse/ClickHouse/issues/79163) でバックポート: 並列レプリカを有効にした読み取りでは、task size の決定に replicas 数を使用するようになりました。これにより、読み取るデータ量がそれほど多くない場合でも、replicas 間でより適切に作業を分散できます。[#78695](https://github.com/ClickHouse/ClickHouse/pull/78695) ([Nikita Taranov](https://github.com/nickitat)).
* [#79190](https://github.com/ClickHouse/ClickHouse/issues/79190) でバックポート: 可能な場合は、filter クエリプラン step の equality conditions を JOIN condition にマージし、hash table のキーとして使えるようにしました。[#78877](https://github.com/ClickHouse/ClickHouse/pull/78877) ([Dmitry Novik](https://github.com/novikd)).



<div id="improvement">
  #### 改善
</div>

* `multiRead` が利用可能な箇所では単一の `get` リクエストの使用を廃止し、Keeper へのリクエスト数を削減しました。これにより、レプリカ数の増加に伴って Keeper に大きな負荷がかかる可能性があった問題を解消しています。 [#56862](https://github.com/ClickHouse/ClickHouse/pull/56862) ([Nikolay Degterinsky](https://github.com/evillique)).
* server が overloaded な場合にクエリを拒否するようにしました。判定は、待機時間 (`OSCPUWaitMicroseconds`) と busy time (`OSCPUVirtualTimeMicroseconds`) の ratio に基づいて行われます。この ratio が `min_os_cpu_wait_time_ratio_to_throw` と `max_os_cpu_wait_time_ratio_to_throw` の間にある場合、一定の確率でクエリは破棄されます (これらはクエリレベルの設定です) 。 [#63206](https://github.com/ClickHouse/ClickHouse/pull/63206) ([Alexey Katsman](https://github.com/alexkats)).
* リフレッシャブルmaterialized view の refresh が `system.query_log` に記録されるようになりました。 [#71333](https://github.com/ClickHouse/ClickHouse/pull/71333) ([Michael Kolupaev](https://github.com/al13n321)).
* [#79175](https://github.com/ClickHouse/ClickHouse/issues/79175) でバックポート: `--path` コマンドライン引数を指定すると、`clickhouse-local` は再起動後も database を保持するようになりました。これにより [#50647](https://github.com/ClickHouse/ClickHouse/issues/50647) をクローズします。これにより [#49947](https://github.com/ClickHouse/ClickHouse/issues/49947) をクローズします。 [#71722](https://github.com/ClickHouse/ClickHouse/pull/71722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* すべての種類の replicated tasks に対して backoff ロジックを有効化しました。これにより、CPU usage、memory usage、log file サイズの削減が可能になります。`max_postpone_time_for_failed_replicated_fetches_ms`、`max_postpone_time_for_failed_replicated_merges_ms`、`max_postpone_time_for_failed_replicated_tasks_ms` という新しい設定を追加しました。これらは `max_postpone_time_for_failed_mutations_ms` と同様の設定です。 [#74576](https://github.com/ClickHouse/ClickHouse/pull/74576) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 両方の part で JOIN key が PK のプレフィックスである場合、JOIN に動的 sharding を使用するようにしました。この最適化は `query_plan_join_shard_by_pk_ranges` 設定で有効化されます (デフォルトでは無効) 。 [#74733](https://github.com/ClickHouse/ClickHouse/pull/74733) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* SSH プロトコルを再び有効化しました。いくつかの重大な脆弱性を修正し、カスタム pager の使用や `server-logs-file` の指定ができないようにしました。また、client オプションを環境変数経由で渡す機能はデフォルトで無効化しました (`config.xml` 内の `ssh-server.enable_client_options_passing` により引き続き利用可能です) 。progress table、クエリのキャンセル、completion、profile events progress、stdin、および `send_logs_level` オプションをサポートしました。これにより [#74340](https://github.com/ClickHouse/ClickHouse/issues/74340) をクローズします。 [#74989](https://github.com/ClickHouse/ClickHouse/pull/74989) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* readonly MergeTree テーブルで refresh をサポートしました。 [#76467](https://github.com/ClickHouse/ClickHouse/pull/76467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `system.errors` に `query&#95;id` を追加しました。関連チケット: [#75815](https://github.com/ClickHouse/ClickHouse/issues/75815)。 [#76581](https://github.com/ClickHouse/ClickHouse/pull/76581) ([Vladimir Baikov](https://github.com/bkvvldmr)).
* View からの JSON type および subcolumns の読み取りをサポートしました。 [#76903](https://github.com/ClickHouse/ClickHouse/pull/76903) ([Pavel Kruglov](https://github.com/Avogar)).
* UInt128 から IPv6 への変換サポートを追加しました。これにより、IPv6 に対する `bitAnd` 演算や算術演算、および IPv6 への再変換が可能になります。[#76752](https://github.com/ClickHouse/ClickHouse/issues/76752) をクローズします。これにより、IPv6 に対する `bitAnd` 演算の結果も IPv6 に再変換できるようになります。参照: https://github.com/ClickHouse/ClickHouse/pull/57707。 [#76928](https://github.com/ClickHouse/ClickHouse/pull/76928) ([Muzammil Abdul Rehman](https://github.com/muzammilar)).
* デフォルトでは、Variant 型内のテキストフォーマットで特殊な Bool 値をパースしないようにしました。これは設定 `allow_special_bool_values_inside_variant` で有効にできます。 [#76974](https://github.com/ClickHouse/ClickHouse/pull/76974) ([Pavel Kruglov](https://github.com/Avogar)).
* セッションレベルおよびサーバーレベルで、低優先度クエリのタスクごとの待機時間を設定できるようにしました。 [#77013](https://github.com/ClickHouse/ClickHouse/pull/77013) ([VicoWu](https://github.com/VicoWu)).
* PostgreSQL の CHARACTER、CHAR、BPCHAR に FixedString を使用するようにしました。 [#77304](https://github.com/ClickHouse/ClickHouse/pull/77304) ([Pablo Marcos](https://github.com/pamarcos)).
* データベースがメタデータファイルの保存にリモートディスクを使用できるようにしました。 [#77365](https://github.com/ClickHouse/ClickHouse/pull/77365) ([Tuan Pham Anh](https://github.com/tuanpach)).
* JSON data type の値の比較を実装しました。これにより、JSON オブジェクトを Map と同様に比較できるようになりました。 [#77397](https://github.com/ClickHouse/ClickHouse/pull/77397) ([Pavel Kruglov](https://github.com/Avogar)).
* plain&#95;rewritable ディスクで ALTER TABLE ... ATTACH|DETACH|MOVE|REPLACE PARTITION をサポートしました。 [#77406](https://github.com/ClickHouse/ClickHouse/pull/77406) ([Julia Kartseva](https://github.com/jkartseva)).
* `additional_table_filters` 設定内でクエリパラメータをサポートしました。この変更により、次のクエリが成功するようになります。 [#77680](https://github.com/ClickHouse/ClickHouse/pull/77680) ([wxybear](https://github.com/wxybear)).
* system.kafka&#95;consumers における権限サポートを改善しました。内部的な librdkafka エラーは例外として表示されます。 [#77700](https://github.com/ClickHouse/ClickHouse/pull/77700) ([Ilya Golshtein](https://github.com/ilejn)).
* ユーザー定義関数 (UDFs) は、XML 定義内の新しいタグで決定論的としてマークできるようになりました。また、クエリキャッシュは、クエリ内で呼び出された UDFs が決定論的かどうかを確認するようになりました。該当する場合、クエリ結果を cache します。(Issue [#59988](https://github.com/ClickHouse/ClickHouse/issues/59988))。 [#77769](https://github.com/ClickHouse/ClickHouse/pull/77769) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* Buffer テーブルエンジンのパラメータ検証を追加しました。 [#77840](https://github.com/ClickHouse/ClickHouse/pull/77840) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* hdfs pread を有効または無効にする config `enable_hdfs_pread` を追加しました。 [#77885](https://github.com/ClickHouse/ClickHouse/pull/77885) ([kevinyhzou](https://github.com/KevinyhZou)).
* ZooKeeper の &#39;multi&#39; 読み取りおよび書き込みリクエスト数に関するプロファイルイベントを追加しました。 [#77888](https://github.com/ClickHouse/ClickHouse/pull/77888) ([JackyWoo](https://github.com/JackyWoo)).
* disable&#95;insertion&#95;and&#95;mutation がオンのときでも、一時テーブルの作成と insert を許可しました。 [#77901](https://github.com/ClickHouse/ClickHouse/pull/77901) ([Xu Jia](https://github.com/XuJia0210)).
* max&#95;insert&#95;delayed&#95;streams&#95;for&#95;parallel&#95;write を 100 に引き下げました。 [#77919](https://github.com/ClickHouse/ClickHouse/pull/77919) ([Azat Khuzhin](https://github.com/azat)).
* `max_merge_delayed_streams_for_parallel_write` を使用して、マージが並列に flush できるカラム数を設定できるようにしました (これにより、S3 への vertical merge におけるメモリ使用量を約 25 分の 1 に削減できるはずです) 。 [#77922](https://github.com/ClickHouse/ClickHouse/pull/77922) ([Azat Khuzhin](https://github.com/azat)).
* `&#39;yyy&#39;` のような Joda syntax での年のパースを修正しました。 [#77973](https://github.com/ClickHouse/ClickHouse/pull/77973) ([李扬](https://github.com/taiyang-li)).
* MergeTree テーブルのパーツの Attach は、block 順で実行されるようになりました。これは ReplacingMergeTree などの特殊な merging アルゴリズムにとって重要です。これにより [#71009](https://github.com/ClickHouse/ClickHouse/issues/71009) をクローズします。 [#77976](https://github.com/ClickHouse/ClickHouse/pull/77976) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* クエリマスキングルールで、一致が発生した場合に LOGICAL&#95;ERROR をスローできるようになりました。これにより、あらかじめ定義された password がログ内のどこかに漏れていないか確認しやすくなります。 [#78094](https://github.com/ClickHouse/ClickHouse/pull/78094) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* MySQL との互換性向上のため、`information_schema.tables` に `index_length_column` カラムを追加しました。 [#78119](https://github.com/ClickHouse/ClickHouse/pull/78119) ([Paweł Zakrzewski](https://github.com/KrzaQ)).
