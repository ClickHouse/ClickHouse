* [#86691](https://github.com/ClickHouse/ClickHouse/issues/86691) にバックポート: サブカラムが PK またはパーティション式で使用されているカラムの ALTER を禁止しました。[#86005](https://github.com/ClickHouse/ClickHouse/pull/86005) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86517](https://github.com/ClickHouse/ClickHouse/issues/86517) にバックポート: ファイルシステムキャッシュの動的リサイズ中に発生する論理エラーを修正しました。[#86122](https://github.com/ClickHouse/ClickHouse/issues/86122) をクローズ。[https://github.com/ClickHouse/clickhouse-core-incidents/issues/473](https://github.com/ClickHouse/clickhouse-core-incidents/issues/473) をクローズ。[#86130](https://github.com/ClickHouse/ClickHouse/pull/86130) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#86945](https://github.com/ClickHouse/ClickHouse/issues/86945) にバックポート: LowCardinality(Nullable(T)) から Dynamic へのキャストの問題を修正しました。[#86365](https://github.com/ClickHouse/ClickHouse/pull/86365) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86851](https://github.com/ClickHouse/ClickHouse/issues/86851) にバックポート: plain&#95;rewritable ディスクで Azure blob storage から空のブロブを読み取る際に発生する `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` エラーを修正しました。[#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* [#86890](https://github.com/ClickHouse/ClickHouse/issues/86890) にバックポート: send&#95;chunk&#95;header が有効で、UDF が HTTPプロトコル経由で呼び出される場合に、chunk header が欠落する問題を修正しました。[#86606](https://github.com/ClickHouse/ClickHouse/pull/86606) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#86870](https://github.com/ClickHouse/ClickHouse/issues/86870) にバックポート: Keeper セッションの期限切れが原因で発生していた、S3Queue の論理エラー &quot;Expected current processor {} to be equal to {}&quot; を修正しました。[#86615](https://github.com/ClickHouse/ClickHouse/pull/86615) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#86975](https://github.com/ClickHouse/ClickHouse/issues/86975) にバックポート: TimeSeries エンジンのテーブルが Replicated Database で新しいレプリカの作成を妨げる問題を修正しました。[#86845](https://github.com/ClickHouse/ClickHouse/pull/86845) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#86859](https://github.com/ClickHouse/ClickHouse/issues/86859) にバックポート: tasks に一部の Keeper ノードが存在しない場合に `system.distributed_ddl_queue` をクエリできない問題を修正しました。[#86848](https://github.com/ClickHouse/ClickHouse/pull/86848) ([Antonio Andelic](https://github.com/antonio2368)).
