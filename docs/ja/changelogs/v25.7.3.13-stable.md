<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#85306](https://github.com/ClickHouse/ClickHouse/issues/85306)でバックポート: ALTER MODIFY ORDER BY で、ソートキー内の有効期限 (TTL) カラムが検証されない問題を修正しました。ALTER 操作中に ORDER BY 句で有効期限 (TTL) カラムを使用した場合、それらが正しく拒否されるようになり、テーブル破損の可能性を防ぎます。[#84536](https://github.com/ClickHouse/ClickHouse/pull/84536) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* [#85381](https://github.com/ClickHouse/ClickHouse/issues/85381)でバックポート: `ReplicatedMergeTree` におけるパッチパートのクリーンアップを修正しました。以前は、論理更新の結果が、パッチパートを実体化するマージ済みまたは mutation 済みのパーツが別のレプリカからダウンロードされるまで、そのレプリカ上で一時的に見えないことがありました。[#85121](https://github.com/ClickHouse/ClickHouse/pull/85121) ([Anton Popov](https://github.com/CurtizJ)).
* [#85246](https://github.com/ClickHouse/ClickHouse/issues/85246)でバックポート: 型が異なる場合に mv で発生する illegal&#95;type&#95;of&#95;argument を修正しました。[#85135](https://github.com/ClickHouse/ClickHouse/pull/85135) ([Sema Checherinda](https://github.com/CheSema)).
* [#85236](https://github.com/ClickHouse/ClickHouse/issues/85236)でバックポート: `additional_table_filters expression` setting 内の `IN (subquery)` における `Not-ready Set` を修正しました。[#85210](https://github.com/ClickHouse/ClickHouse/pull/85210) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#85264](https://github.com/ClickHouse/ClickHouse/issues/85264)でバックポート: SYSTEM DROP REPLICA クエリ中の不要な `getStatus()` 呼び出しを削除しました。これにより、テーブルがバックグラウンドで削除された際に `Shutdown for storage is called` 例外が発生するケースを修正しました。[#85220](https://github.com/ClickHouse/ClickHouse/pull/85220) ([Nikolay Degterinsky](https://github.com/evillique)).
