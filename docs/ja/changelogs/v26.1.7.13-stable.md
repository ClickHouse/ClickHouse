<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#99158](https://github.com/ClickHouse/ClickHouse/issues/99158)でバックポート: サブカラムが他のカラムのデフォルト/alias 式で使われている場合はそのカラムを削除できないようにし、alter drop column でのデフォルト式にアナライザを使用するようにしました。[#98569](https://github.com/ClickHouse/ClickHouse/pull/98569) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#100080](https://github.com/ClickHouse/ClickHouse/issues/100080)でバックポート: 非アナライザで TABLE&#95;UUID&#95;MISMATCH が無視されてしまう問題を修正しました。[#99380](https://github.com/ClickHouse/ClickHouse/pull/99380) ([Azat Khuzhin](https://github.com/azat)).
* [#100356](https://github.com/ClickHouse/ClickHouse/issues/100356)でバックポート: `toWeek()` に対する誤ったパーティションプルーニングを修正しました。この問題により、`toYYYYMM(date)` でパーティション分割されたテーブルで `WHERE toWeek(date, mode) = N` を含むクエリが、49～52 週で空の結果を返していました。[#99542](https://github.com/ClickHouse/ClickHouse/pull/99542) ([Takumi Hara](https://github.com/takumihara)).
* [#100168](https://github.com/ClickHouse/ClickHouse/issues/100168)でバックポート: ... [#100024](https://github.com/ClickHouse/ClickHouse/pull/100024) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#100265](https://github.com/ClickHouse/ClickHouse/issues/100265)でバックポート: テキスト索引の構築中に &quot;Memory Limit&quot; 例外が送出された場合に発生する、まれなクラッシュを修正しました。[#100213](https://github.com/ClickHouse/ClickHouse/pull/100213) ([Anton Popov](https://github.com/CurtizJ)).
* [#100342](https://github.com/ClickHouse/ClickHouse/issues/100342)でバックポート: クロス結合とランタイムフィルタを含む `Dynamic` カラムのクエリで発生していた `LOGICAL_ERROR` 例外を修正しました。原因は、`ColumnVariant::filter` が `hasOnlyNulls` 最適化パスで Variant カラムのポインタをクローンせずに共有していたことです。[https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147) をクローズします。[#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100594](https://github.com/ClickHouse/ClickHouse/issues/100594)でバックポート: `optimize_on_insert=0` の wide parts で、ネストした `Array(JSON)` カラムを持つテーブルへの挿入時に発生する LOGICAL&#95;ERROR 例外 &quot;Stream ... not found&quot; を修正しました。[#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100887](https://github.com/ClickHouse/ClickHouse/issues/100887)でバックポート: `RESTORE` 中にパストラバーサル、絶対パス、空の名前を拒否できるよう、バックアップのメタデータ内のファイルエントリパスを検証するようにしました。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* [#100725](https://github.com/ClickHouse/ClickHouse/issues/100725)でバックポート: projection の SELECT 部分に、クエリ本体の元の SELECT 部分には存在しないカラムが含まれている場合に発生する NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK を修正しました。[#100194](https://github.com/ClickHouse/ClickHouse/issues/100194) をクローズします。[#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#100918](https://github.com/ClickHouse/ClickHouse/issues/100918)でバックポート: LowCardinality 要素を含む Tuple キーに対して PREWHERE/WHERE 付きで `has()` 関数を使用したときに発生するサーバークラッシュを修正しました。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* [#100868](https://github.com/ClickHouse/ClickHouse/issues/100868)でバックポート: `Nullable(Tuple)` の導入後、戻り値の型が `Tuple` で、1 つ以上の `Nullable` 引数を持つ `If`、`Distinct`、`DistinctIf`、`IfState ` 集約関数コンビネータが、古いシリアライズ済み状態を読み取れなくなる問題を修正しました。[#98917](https://github.com/ClickHouse/ClickHouse/issues/98917) をクローズしました。[#100826](https://github.com/ClickHouse/ClickHouse/pull/100826) ([Nihal Z. Miaji](https://github.com/nihalzp)).
