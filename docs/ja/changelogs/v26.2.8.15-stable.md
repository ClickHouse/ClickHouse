<div id="improvement">
  #### 改善
</div>

* [#101866](https://github.com/ClickHouse/ClickHouse/issues/101866)でバックポート: テキスト索引が GA となり、`compatibility` 設定にかかわらず常に有効のままとなりました。これにより、バックアップからの復元時や互換性モードでの実行時に予期せず無効化されることがなくなりました。 [#101518](https://github.com/ClickHouse/ClickHouse/pull/101518) ([Nikita Fomichev](https://github.com/fm4v)).
* [#101860](https://github.com/ClickHouse/ClickHouse/issues/101860)でバックポート: libarchive を 3.8.5 から 3.8.6 に更新。 [#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)).
* [#101854](https://github.com/ClickHouse/ClickHouse/issues/101854)でバックポート: curl を 8.18 から 8.19 に更新。 [#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#100217](https://github.com/ClickHouse/ClickHouse/issues/100217) でバックポート: `IDatabaseTablesIterator::table()` 呼び出しでテーブルのスナップショットを取得した後、後続のイテレーション中に別スレッドでテーブルが変更されるまでの間に作成されたシステムテーブルにおいて、null ポインタをデリファレンスしてクラッシュする可能性がある問題を修正しました。 [#98792](https://github.com/ClickHouse/ClickHouse/pull/98792) ([Grant Holly](https://github.com/grantholly-clickhouse)).
* [#100855](https://github.com/ClickHouse/ClickHouse/issues/100855) でバックポート: 実行中の読み取りクエリと同時にテーブルが削除された場合に発生する heap-use-after-free を修正しました (過去 90 日間で CI に 19 件発生) 。 [#99483](https://github.com/ClickHouse/ClickHouse/pull/99483) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#101472](https://github.com/ClickHouse/ClickHouse/issues/101472) でバックポート: Keeper で、同じサーバー上の別の無関係なセッションがちょうど悪いタイミングで終了すると、読み取りリクエストが停止したままになり (その結果セッションがタイムアウトする) 、問題を修正しました。 [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* [#101393](https://github.com/ClickHouse/ClickHouse/issues/101393) でバックポート: 非同期 INSERT (TCP) および HTTP 経由のすべての insert で `DateTime` 値をパースする際に、`session_timezone` が無視される問題を修正しました。 [#100647](https://github.com/ClickHouse/ClickHouse/pull/100647) ([Sema Checherinda](https://github.com/CheSema)).
* [#101960](https://github.com/ClickHouse/ClickHouse/issues/101960) でバックポート: shard-by-PK 最適化を使用する JOIN で query condition cache が使われ、かつ一部のパーツがキャッシュされた条件によって除外される場合に、誤った結果になる問題を修正しました。 [#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* [#101642](https://github.com/ClickHouse/ClickHouse/issues/101642) でバックポート: 小数秒が 18 桁を超える datetime 文字列をパースする際に、parseDateTimeBestEffort で未定義動作 (符号付き整数オーバーフロー) が発生する問題を修正しました。 [#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* [#101362](https://github.com/ClickHouse/ClickHouse/issues/101362) でバックポート: JIT コンパイルが有効な場合 (コンパイルしきい値到達後) に、`Decimal` カラムに対する `MAX`/`MIN` aggregate functions が誤った結果を返す問題を修正しました。 [#101203](https://github.com/ClickHouse/ClickHouse/pull/101203) ([Raúl Marín](https://github.com/Algunenano)).
* [#101371](https://github.com/ClickHouse/ClickHouse/issues/101371) でバックポート: ... [#101230](https://github.com/ClickHouse/ClickHouse/pull/101230) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#101561](https://github.com/ClickHouse/ClickHouse/issues/101561) でバックポート: replicated merge tree を使用する Delta Lake クラスターからの insert-select に関する問題を修正しました。 [#101299](https://github.com/ClickHouse/ClickHouse/pull/101299) ([Konstantin Vedernikov](https://github.com/scanhex12)).
