<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#97329](https://github.com/ClickHouse/ClickHouse/issues/97329) でバックポート: SQL Security を持つ VIEW に対する `ATTACH` クエリで不要な skip permissions チェックを削除しました。これにより、ユーザーが必要なアクセス権を検証せずに definer 付き VIEW を ATTACH した際に起こりうる権限昇格を防止します。[#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)).
* [#95816](https://github.com/ClickHouse/ClickHouse/issues/95816) でバックポート: 複数の join を `USING` clause とともに使用した場合の、source table 由来の修飾付きカラムに対する type inference を修正しました。従来は、そのカラムが後続の join に含まれていない場合でも、後続の join によって基になる source column の型が common supertype に誤って更新されていました (たとえば `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` では、`t2.a` カラムは最初の join でしか使われないため、その型は `t1.a` と `t2.a` の supertype であるべきで、`t3.a` は含まれません) 。この問題により、Functions が実際の実行計画に現れるものとは異なるカラム型を想定した場合、論理エラーや crash につながる可能性がありました。[#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#96394](https://github.com/ClickHouse/ClickHouse/issues/96394) でバックポート: distributed queries で負の `LIMIT/OFFSET` を使用した際に、一部のケースで発生する論理エラーを修正しました。[#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#96220](https://github.com/ClickHouse/ClickHouse/issues/96220) でバックポート: JSON の配列に `tupleElement` を適用した際に発生する crash を修正しました。[#95581](https://github.com/ClickHouse/ClickHouse/issues/95581) をクローズしました。[#95647](https://github.com/ClickHouse/ClickHouse/pull/95647) ([Pavel Kruglov](https://github.com/Avogar)).
* [#96054](https://github.com/ClickHouse/ClickHouse/issues/96054) でバックポート: パーティション化された Delta Lake データをまとめる処理を修正しました。[#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#96084](https://github.com/ClickHouse/ClickHouse/issues/96084) でバックポート: 空の MergeTree table で `direct` join algorithm を使用した際に発生する可能性がある `NOT_SUPPORTED` error を修正しました。[#95935](https://github.com/ClickHouse/ClickHouse/pull/95935) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#96213](https://github.com/ClickHouse/ClickHouse/issues/96213) でバックポート: JSON data type のパスのスキップを修正しました。従来は `JSON(SKIP path)` を使用すると、プレフィックス `path` を持つすべての JSON key がスキップされ、`"pathpath"` のような key まで対象になっていたため、insert 時にそれらのパスのデータ損失につながる可能性がありました。現在は修正され、`"path"` という key のみがスキップされます。[#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* [#96080](https://github.com/ClickHouse/ClickHouse/issues/96080) でバックポート: global profiler の period (`global_profiler_real_time_period_ns` および `global_profiler_cpu_time_period_ns` で制御) を修正しました。設定値そのものではなく切り捨てられた値が使用されていたため、profiler が意図したよりも頻繁に wakeup していました。[#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)).
* [#96542](https://github.com/ClickHouse/ClickHouse/issues/96542) でバックポート: default roles の revoke を修正しました。[#96103](https://github.com/ClickHouse/ClickHouse/pull/96103) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#96160](https://github.com/ClickHouse/ClickHouse/issues/96160)でバックポート: `use_primary_key` が無効で、かつ索引を使用する条件の論理和が非常に多いというまれな組み合わせで発生する、索引解析の use-after-free を修正しました。[#96112](https://github.com/ClickHouse/ClickHouse/pull/96112) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#96157](https://github.com/ClickHouse/ClickHouse/issues/96157)でバックポート: MySQL 形式や JODA 形式などの固定幅ではないフォーマッタを使用した `formatDateTime` における use-of-uninitialized-value を修正しました。[#96133](https://github.com/ClickHouse/ClickHouse/pull/96133) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#97153](https://github.com/ClickHouse/ClickHouse/issues/97153)でバックポート: 部分的な revoke がある場合に `AccessRights::contains` が誤った結果を返す問題を修正しました。[#96170](https://github.com/ClickHouse/ClickHouse/pull/96170) ([pufit](https://github.com/pufit)).
* [#96280](https://github.com/ClickHouse/ClickHouse/issues/96280)でバックポート: ProcessList で発生しうるデッドロックを修正しました。これは、キャンセルチェッカーに task を追加している際にメモリオーバーコミットトラッカーがトリガーされると、lock inversion が発生する可能性があるためです。[#96182](https://github.com/ClickHouse/ClickHouse/pull/96182) ([Antonio Andelic](https://github.com/antonio2368)).
* [#96462](https://github.com/ClickHouse/ClickHouse/issues/96462)でバックポート: 外部結合 (LEFT、RIGHT、または FULL) と複数の INNER JOIN を組み合わせたクエリで、不正な join の並べ替えにより誤った結果が返される不具合を修正しました。外部結合の ON 条件が、それ以前に join された複数のテーブルのカラムを参照している場合、オプティマイザがすべてのテーブル依存関係を考慮できず、join を誤って並べ替えた結果、行が欠落することがありました。[#95972](https://github.com/ClickHouse/ClickHouse/issues/95972) を close。[#96193](https://github.com/ClickHouse/ClickHouse/pull/96193) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#96562](https://github.com/ClickHouse/ClickHouse/issues/96562)でバックポート: テーブルに統計情報が定義されていない場合、ClickHouse は統計情報を読み込もうとすべきではありません。これにより、統計情報ファイルが存在するかどうかを確認するためのオーバーヘッド (100ms 以上) を回避できます。 (issue [#96068](https://github.com/ClickHouse/ClickHouse/issues/96068)) 。[#96233](https://github.com/ClickHouse/ClickHouse/pull/96233) ([Han Fei](https://github.com/hanfei1991)).
* [#96386](https://github.com/ClickHouse/ClickHouse/issues/96386)でバックポート: 一部のケースで `not IN` および `not has` 関数に対するパーティションプルーニングが誤っていた問題を修正しました。[#96241](https://github.com/ClickHouse/ClickHouse/pull/96241) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#96327](https://github.com/ClickHouse/ClickHouse/issues/96327)でバックポート: ベクトル類似度索引における `stack-use-after-scope` を修正しました。[#96259](https://github.com/ClickHouse/ClickHouse/pull/96259) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#96532](https://github.com/ClickHouse/ClickHouse/issues/96532)でバックポート: `max_execution_time` の値が大きいクエリで、キャンセルチェッカー thread に発生する livelock を修正しました。[#96450](https://github.com/ClickHouse/ClickHouse/pull/96450) ([Sergei Trifonov](https://github.com/serxa)).
* [#96693](https://github.com/ClickHouse/ClickHouse/issues/96693)でバックポート: バッファオーバーフローを回避するため、bech32 の witness version を検証するようにしました。[#96671](https://github.com/ClickHouse/ClickHouse/pull/96671) ([Raúl Marín](https://github.com/Algunenano)).
* [#97206](https://github.com/ClickHouse/ClickHouse/issues/97206)でバックポート: ブロック内のすべての行がフィルタで除外された場合に、有効期限 (TTL) マージ後の `_minmax_count_projection` 経由で `min(timestamp)` が epoch (`1970-01-01`) を返してしまう問題を修正しました。 [#96703](https://github.com/ClickHouse/ClickHouse/pull/96703) ([Raquel Barbadillo](https://github.com/rbarbadillo)).
* [#96919](https://github.com/ClickHouse/ClickHouse/issues/96919)でバックポート: 同じカラムに対して以前に論理更新が実行されていた場合に、`ALTER TABLE DROP COLUMN` クエリが失敗する問題を修正しました。 [#96861](https://github.com/ClickHouse/ClickHouse/pull/96861) ([Anton Popov](https://github.com/CurtizJ)).
* [#96938](https://github.com/ClickHouse/ClickHouse/issues/96938)でバックポート: 互換性のない型で `indexOfAssumeSorted` を呼び出したとき (例: 整数の検索値に対する `IPv4` Array) に発生する `std::terminate` 例外を修正しました。 [#96877](https://github.com/ClickHouse/ClickHouse/pull/96877) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#97049](https://github.com/ClickHouse/ClickHouse/issues/97049)でバックポート: `group_by_use_nulls = 1` と CUBE/ROLLUP/GROUPING SETS を使用してウィンドウ関数を実行した際に発生する例外 `Bad cast from type DB::ColumnNullable to DB::ColumnString` を修正しました。 [#96878](https://github.com/ClickHouse/ClickHouse/pull/96878) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#97125](https://github.com/ClickHouse/ClickHouse/issues/97125)でバックポート: `BlockIO::operator=` が `query_metadata_cache` をムーブしないため、キャッシュされたストレージスナップショットが早期に破棄され、`MergeTreeData` ストレージで use-after-free が発生していたことに起因する `clearCaches` のクラッシュ (SEGFAULT) を修正しました。 [#96995](https://github.com/ClickHouse/ClickHouse/pull/96995) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
