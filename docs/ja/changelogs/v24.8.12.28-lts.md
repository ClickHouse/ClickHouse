<div id="new-feature">
  #### 新機能
</div>

* [#74316](https://github.com/ClickHouse/ClickHouse/issues/74316) でバックポート: `min_age_to_force_merge_seconds` と `min_age_to_force_merge_on_partition_only` の両方が有効になっている場合、パーツマージでは最大バイト数の制限が無視されます。 [#73656](https://github.com/ClickHouse/ClickHouse/pull/73656) ([Kai Zhu](https://github.com/nauu)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#74222](https://github.com/ClickHouse/ClickHouse/issues/74222) でバックポート: `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` の後に一時停止しないよう修正しました。バックグラウンドタスクのスケジューリングに対して正しい設定を取得するようにしました。 [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#73889](https://github.com/ClickHouse/ClickHouse/issues/73889) でバックポート: Dynamic および JSON カラム の squashin の準備処理を修正しました。従来は一部のケースで、types/paths の制限に達していなくても、新しい型が shared variant/shared data に挿入されることがありました。 [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74435](https://github.com/ClickHouse/ClickHouse/issues/74435) でバックポート: Dictionary のログソースに不正な data を持つ関数が含まれている場合に発生する segfault を修正しました。 [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#74139](https://github.com/ClickHouse/ClickHouse/issues/74139) でバックポート: Dynamic カラム で発生しうる data の不整合を修正しました。論理エラー `Nested columns sizes are inconsistent with local_discriminators column size` が発生する可能性も修正しました。 [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74527](https://github.com/ClickHouse/ClickHouse/issues/74527) でバックポート: `FINAL` および `SAMPLE` を含む queries で発生する `NOT_FOUND_COLUMN_IN_BLOCK` を修正しました。`CollapsingMergeTree` に対する `FINAL` 付きの selects で誤った結果が返る問題を修正し、`FINAL` の最適化を有効化しました。 [#73682](https://github.com/ClickHouse/ClickHouse/pull/73682) ([Anton Popov](https://github.com/CurtizJ)).
* [#74138](https://github.com/ClickHouse/ClickHouse/issues/74138) でバックポート: Dynamic/Object structure の deserialization を修正しました。これにより CANNOT&#95;READ&#95;ALL&#95;DATA 例外が発生する可能性がありました。 [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74111](https://github.com/ClickHouse/ClickHouse/issues/74111) でバックポート: [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078) を修正しました ( S3 Express Support が壊れていました )。 [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* [#74104](https://github.com/ClickHouse/ClickHouse/issues/74104) でバックポート: plain&#95;rewritable メタデータを使用する disk は、複数の server instance 間で共有できます。あるインスタンスがメタデータ object を読み取っている間に、別のインスタンスがそれを変更することが想定されています。Azure storage での plain&#95;rewritable の初期化中に発生する object not found error は、S3 向けに実装されている動作と同様に無視されます。 [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* [#74152](https://github.com/ClickHouse/ClickHouse/issues/74152) でバックポート: ユーザーが Kafka table engine で keyword arguments を指定した場合の問題を修正しました。 [#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#74173](https://github.com/ClickHouse/ClickHouse/issues/74173) でバックポート: compressed Memory engine table から subcolumn を読み取る際に発生する crash を修正しました。[#74009](https://github.com/ClickHouse/ClickHouse/issues/74009) も修正しました。 [#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat)).
