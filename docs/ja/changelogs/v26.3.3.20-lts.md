<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#101224](https://github.com/ClickHouse/ClickHouse/issues/101224) でバックポート: 非同期 INSERT のクエリで、`query_log` とクライアント出力において `written_rows`、`read_rows`、`result_rows` が 0 と報告される問題を修正しました。[#99879](https://github.com/ClickHouse/ClickHouse/pull/99879) ([Sema Checherinda](https://github.com/CheSema)).
* [#100891](https://github.com/ClickHouse/ClickHouse/issues/100891) でバックポート: `RESTORE` 中にパストラバーサル、絶対パス、空の名前を拒否するため、バックアップのメタデータ内のファイルエントリのパスを検証するようにしました。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* [#101394](https://github.com/ClickHouse/ClickHouse/issues/101394) でバックポート: 非同期 INSERT (TCP) および HTTP 経由のすべての INSERT で `DateTime` の値をパースする際に、`session_timezone` が無視される問題を修正しました。[#100647](https://github.com/ClickHouse/ClickHouse/pull/100647) ([Sema Checherinda](https://github.com/CheSema)).
* [#100922](https://github.com/ClickHouse/ClickHouse/issues/100922) でバックポート: LowCardinality 要素を含む Tuple キーに対して PREWHERE/WHERE と `has()` 関数を使用した際に、サーバーがクラッシュする問題を修正しました。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* [#101187](https://github.com/ClickHouse/ClickHouse/issues/101187) でバックポート: サーバーのシャットダウン中に Dictionary をロードしている際、null ポインタ参照による segfault が発生する問題を修正しました。`Context::getUserDefinedSQLObjectsStorage` (`user_defined_sql_objects_storage` を参照解除する) は、メインスレッドが `Context::shutdown` (`user_defined_sql_objects_storage` を null に設定する) を呼び出しているのと同時に、Dictionary のスレッドから呼び出されます。`Context::shutdown` を実行する前に、Dictionary ローダーで今後の更新を無効化し、現在実行中の Dictionary クエリを停止し、Dictionary のロードスレッドを join しておく必要があります。これは通常のクエリで行っているのと同様です。[#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#101091](https://github.com/ClickHouse/ClickHouse/issues/101091) でバックポート: 入力に非 ASCII バイトが含まれる場合に、`ULIDStringToDateTime` でバッファオーバーフローが発生する問題を修正しました。[#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101015](https://github.com/ClickHouse/ClickHouse/issues/101015) でバックポート: nullable な Tuple の配列に対して `intDiv`/`intDivOrZero` で例外が発生する問題を修正しました。例: `SELECT intDiv([divide((1, 2), ... AND NULL)], 2)`。[#100895](https://github.com/ClickHouse/ClickHouse/pull/100895) ([Raúl Marín](https://github.com/Algunenano)).
* [#101250](https://github.com/ClickHouse/ClickHouse/issues/101250) でバックポート: `StorageAlias` の定義を保存する前に engine 引数を評価するようにし、`currentDatabase()` のような式が database に保存される前にリテラルへ解決されるようにしました。[#100902](https://github.com/ClickHouse/ClickHouse/pull/100902) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#101140](https://github.com/ClickHouse/ClickHouse/issues/101140) でバックポート: tuple subquery を含む `IN` clause を text search index とともに使用した際、たとえば `WHERE (id, str) IN (SELECT (id, str) FROM ...)` のような場合や、サブクエリ内のカラム数が `IN` の左辺の tuple と一致しない場合に発生するクラッシュを修正しました。[#100959](https://github.com/ClickHouse/ClickHouse/pull/100959) ([Anton Popov](https://github.com/CurtizJ)).
* [#101080](https://github.com/ClickHouse/ClickHouse/issues/101080)でバックポート: `Nullable(Tuple)` の導入後、1 つ以上の `Nullable` 引数を持つ `sumCountOrDefault` 集約関数が、古いシリアライズ済みの状態を読み込めなくなる問題を修正しました。[#100882](https://github.com/ClickHouse/ClickHouse/issues/100882) をクローズします。[#101021](https://github.com/ClickHouse/ClickHouse/pull/101021) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#101169](https://github.com/ClickHouse/ClickHouse/issues/101169)でバックポート: PREWHERE を含む projection を `ORDER BY ... LIMIT` と併用した場合に `optimizeLazyMaterialization` で発生する例外を修正しました。[#101115](https://github.com/ClickHouse/ClickHouse/pull/101115) ([Anton Popov](https://github.com/CurtizJ)).
* [#101349](https://github.com/ClickHouse/ClickHouse/issues/101349)でバックポート: `list` と `read` の間にリモート object が上書きされ、以前は古い object メタデータが生成されていたことで、cache から `Having zero bytes, ...` 論理エラーが発生し得るケースを修正しました。[#101219](https://github.com/ClickHouse/ClickHouse/pull/101219) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#101373](https://github.com/ClickHouse/ClickHouse/issues/101373)でバックポート: ... [#101230](https://github.com/ClickHouse/ClickHouse/pull/101230) ([Kseniia Sumarokova](https://github.com/kssenii)).
