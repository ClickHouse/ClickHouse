<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#90145](https://github.com/ClickHouse/ClickHouse/issues/90145) でバックポート: クエリマスキングルールが DDL ステートメントに誤って適用されないようにしました。[#89272](https://github.com/ClickHouse/ClickHouse/pull/89272) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#90440](https://github.com/ClickHouse/ClickHouse/issues/90440) でバックポート: 一部のケースで、テキストフォーマット内の String から不正な DateTime64 値が推論される問題を修正しました。[#89368](https://github.com/ClickHouse/ClickHouse/issues/89368) を解決します。[#90013](https://github.com/ClickHouse/ClickHouse/pull/90013) ([Pavel Kruglov](https://github.com/Avogar)).
* [#90969](https://github.com/ClickHouse/ClickHouse/issues/90969) でバックポート: 1 つの ALTER で同じ Nested カラムの名前変更と変更を行う際に発生する可能性がある論理エラーを修正しました。[#90406](https://github.com/ClickHouse/ClickHouse/issues/90406) を解決します。[#90412](https://github.com/ClickHouse/ClickHouse/pull/90412) ([Pavel Kruglov](https://github.com/Avogar)).
* [#91031](https://github.com/ClickHouse/ClickHouse/issues/91031) でバックポート: `Arrow` フォーマットで `LowCardinality(Bool/Date32)` を出力する際に発生する可能性がある論理エラーを修正しました。[#83883](https://github.com/ClickHouse/ClickHouse/issues/83883) を解決します。[#90505](https://github.com/ClickHouse/ClickHouse/pull/90505) ([Pavel Kruglov](https://github.com/Avogar)).
* [#90910](https://github.com/ClickHouse/ClickHouse/issues/90910) でバックポート: named collections の非表示の secrets が `display_secrets_in_show_and_select` および `format_display_secrets_in_show_and_select` に依存するよう修正しました。[#90765](https://github.com/ClickHouse/ClickHouse/pull/90765) ([Pablo Marcos](https://github.com/pamarcos)).
* [#90848](https://github.com/ClickHouse/ClickHouse/issues/90848) でバックポート: JSON 内の shared data と dynamic パスの状態に不整合が生じ、論理エラーや予期しない結果につながる可能性がある問題を修正しました。[#90816](https://github.com/ClickHouse/ClickHouse/pull/90816) ([Pavel Kruglov](https://github.com/Avogar)).
* [#91201](https://github.com/ClickHouse/ClickHouse/issues/91201) でバックポート: JSON/Dynamic/Variant カラムの読み取り時の高いメモリ使用量を修正しました。[#90907](https://github.com/ClickHouse/ClickHouse/pull/90907) ([Pavel Kruglov](https://github.com/Avogar)).
* [#91496](https://github.com/ClickHouse/ClickHouse/issues/91496) でバックポート: `Nested` `LowCardinality` カラムに対する `SummingMergeTree` の aggregation を修正しました。[#90927](https://github.com/ClickHouse/ClickHouse/pull/90927) ([Ivan Babrou](https://github.com/bobrik)).
* [#91408](https://github.com/ClickHouse/ClickHouse/issues/91408) でバックポート: ... adaptive&#95;write&#95;buffer&#95;initial&#95;size を 0 に設定できないようにしました。[#91001](https://github.com/ClickHouse/ClickHouse/pull/91001) ([Pedro Ferreira](https://github.com/PedroTadim)).
* [#91069](https://github.com/ClickHouse/ClickHouse/issues/91069) でバックポート: `write_marks_for_substreams_in_compact_parts` を無効にした compact パーツでサブオブジェクトを読み取る際、パスが shared data と dynamic パスの両方に存在し得る場合の JSON の bug を修正しました。[#91014](https://github.com/ClickHouse/ClickHouse/pull/91014) ([Pavel Kruglov](https://github.com/Avogar)).
* [#91316](https://github.com/ClickHouse/ClickHouse/issues/91316) でバックポート: compact パーツへの書き込み中に dynamic structure の不整合が発生し、segfault につながる可能性がある問題を修正しました。[#91152](https://github.com/ClickHouse/ClickHouse/pull/91152) ([Pavel Kruglov](https://github.com/Avogar)).
* [#91334](https://github.com/ClickHouse/ClickHouse/issues/91334) でバックポート: SYSTEM DROP FILESYSTEM CACHE ON CLUSTER を修正。 [#91304](https://github.com/ClickHouse/ClickHouse/pull/91304) ([Anton Ivashkin](https://github.com/ianton-ru)).
* [#91456](https://github.com/ClickHouse/ClickHouse/issues/91456) でバックポート: マージアルゴリズムのヘッダーからスパースカラムを削除。 [#91377](https://github.com/ClickHouse/ClickHouse/issues/91377) を解決。 [#91396](https://github.com/ClickHouse/ClickHouse/pull/91396) ([Pavel Kruglov](https://github.com/Avogar)).
