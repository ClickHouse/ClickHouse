<div id="improvement">
  #### 改善
</div>

* [#88492](https://github.com/ClickHouse/ClickHouse/issues/88492) にバックポート: バックアップ保存先へのサーバー側の (ネイティブ) コピーで、バックアップ固有の設定 (たとえば `backup_slow_all_threads_after_retryable_s3_error`) を使用する S3 ストレージクライアントを使うようにしました。`s3_slow_all_threads_after_retryable_error` は廃止されました。[#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva)).
* [#88537](https://github.com/ClickHouse/ClickHouse/issues/88537) にバックポート: Iceberg の SELECT におけるパフォーマンス追跡用の情報を追加しました。[#87903](https://github.com/ClickHouse/ClickHouse/pull/87903) ([Daniil Ivanik](https://github.com/divanik)).
* [#88300](https://github.com/ClickHouse/ClickHouse/issues/88300) にバックポート: copy およびコンテナー作成機能で見られた &#39;Content-Length&#39; の不具合修正を含むように azure sdk を更新しました。[#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#88742](https://github.com/ClickHouse/ClickHouse/issues/88742) にバックポート: 設定 `keeper_server.coordination_settings.check_node_acl_on_remove` を追加しました。有効にすると、各ノードを削除する前に、そのノード自体と親ノードの両方の ACL を検証します。無効な場合は、親ノードの ACL のみを検証します。[#88513](https://github.com/ClickHouse/ClickHouse/pull/88513) ([Antonio Andelic](https://github.com/antonio2368)).
* [#88781](https://github.com/ClickHouse/ClickHouse/issues/88781) にバックポート: `GLOBAL IN` に起因するメモリリークを修正しました ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)) 。[#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94)).
* [#88764](https://github.com/ClickHouse/ClickHouse/issues/88764) にバックポート: `clickhouse-keeper` の postinstall スクリプトに、起動時の自動開始を有効にする手順を追加しました。[#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#88848](https://github.com/ClickHouse/ClickHouse/issues/88848) にバックポート済み: サポート対象範囲外の日付に対して Date/DateTime/DateTime64 を推論する際の不具合を修正しました。[#86184](https://github.com/ClickHouse/ClickHouse/pull/86184) ([Pavel Kruglov](https://github.com/Avogar)).
* [#88594](https://github.com/ClickHouse/ClickHouse/issues/88594) にバックポート済み: `parallel_replicas_for_cluster_functions` setting が 1 に設定されている場合に、`url()` table function で table schema を解決する際の不具合を修正しました。[#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#88843](https://github.com/ClickHouse/ClickHouse/issues/88843) にバックポート済み: CTE を含む insert select クエリで unknown table error が発生する不具合を修正しました。[#85368](https://github.com/ClickHouse/ClickHouse/issues/85368). [#87789](https://github.com/ClickHouse/ClickHouse/pull/87789) ([Guang Zhao](https://github.com/zheguang)).
* [#88509](https://github.com/ClickHouse/ClickHouse/issues/88509) にバックポート済み: Nullable の内側に配置できない Variant から null map subcolumn を読み取る際の不具合を修正しました。[#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar)).
* [#88390](https://github.com/ClickHouse/ClickHouse/issues/88390) にバックポート済み: AzureBlobStorage で、まず native copy を試行し、&#39;Unauthroized&#39; error 時には read &amp; write にフォールバックするようにしました (AzureBlobStorage では、source と destination の storage account が異なる場合、&#39;Unauthorized&#39; error が発生します) 。また、configuration で endpoint が定義されている場合に &quot;use&#95;native&#95;copy&quot; が適用されない不具合も修正しました。[#87826](https://github.com/ClickHouse/ClickHouse/pull/87826) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#88436](https://github.com/ClickHouse/ClickHouse/issues/88436) にバックポート済み: クエリで `session_timezone` setting を使用した際に、datetime ベースのキーに対する granules/partitions の除外が誤って行われる不具合を修正しました。[#87987](https://github.com/ClickHouse/ClickHouse/pull/87987) ([Eduard Karacharov](https://github.com/korowa)).
* [#88420](https://github.com/ClickHouse/ClickHouse/issues/88420) にバックポート済み: [https://github.com/ClickHouse/ClickHouse/pull/84503](https://github.com/ClickHouse/ClickHouse/pull/84503) で導入された grants check に対し、評価前に URI の正規化を適用するようにしました。[#88089](https://github.com/ClickHouse/ClickHouse/pull/88089) ([pufit](https://github.com/pufit)).
* [#88656](https://github.com/ClickHouse/ClickHouse/issues/88656) にバックポート済み: DDL worker が replicas set から outdated な host をクリーンアップするようになりました。これにより、ZooKeeper に保存されるメタデータ量が削減されます。[#88154](https://github.com/ClickHouse/ClickHouse/pull/88154) ([alesapin](https://github.com/alesapin)).
* [#88284](https://github.com/ClickHouse/ClickHouse/issues/88284) にバックポート済み: `ColumnLowCardinality` における `is_shared` フラグの伝播を修正しました。hash value がすでに事前計算されて `ReverseIndex` に cache されている状態で、その後カラムに新しい値が挿入されると、誤った group-by 結果につながる可能性がありました。[#88213](https://github.com/ClickHouse/ClickHouse/pull/88213) ([Nikita Taranov](https://github.com/nickitat)).
* [#88459](https://github.com/ClickHouse/ClickHouse/issues/88459) にバックポート済み: workload setting `max_cpu_share` を修正しました。これにより、`max_cpus` workload setting が設定されていなくても使用できるようになりました。[#88217](https://github.com/ClickHouse/ClickHouse/pull/88217) ([Neerav](https://github.com/neeravsalaria)).
* [#88336](https://github.com/ClickHouse/ClickHouse/issues/88336) にバックポート済み: 相関サブクエリが object storage で動作するようになりました。[#88290](https://github.com/ClickHouse/ClickHouse/pull/88290) ([alesapin](https://github.com/alesapin)).
* [#88356](https://github.com/ClickHouse/ClickHouse/issues/88356) にバックポート: `system.projections` および `system.data_skipping_indices` へのアクセス時に、DataLake データベースを初期化しようとしないようにしました。[#88330](https://github.com/ClickHouse/ClickHouse/pull/88330) ([Azat Khuzhin](https://github.com/azat)).
* [#88430](https://github.com/ClickHouse/ClickHouse/issues/88430) にバックポート: `countMatches` 関数の二次時間計算量の問題を修正しました。[#88400](https://github.com/ClickHouse/ClickHouse/issues/88400) をクローズします。[#88401](https://github.com/ClickHouse/ClickHouse/pull/88401) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#88649](https://github.com/ClickHouse/ClickHouse/issues/88649) にバックポート: node 番号が 10 を超える大規模なクラスターでは、リストアが `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again` という error で失敗する可能性が高くなっていました。`num_hosts` node が多数の host によって同時に上書きされていたためです。この修正により、試行回数を制御する setting が動的になりました。[#87721](https://github.com/ClickHouse/ClickHouse/issues/87721) をクローズします。[#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#88716](https://github.com/ClickHouse/ClickHouse/issues/88716) にバックポート: 基底の const PREWHERE カラムに対する同時実行 mutation によって発生しうるクラッシュを修正しました。[#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).

* [#88835](https://github.com/ClickHouse/ClickHouse/issues/88835) にバックポート: async ログの失敗時に例外を捕捉し、プログラムの異常終了を防ぐようにしました。[#88814](https://github.com/ClickHouse/ClickHouse/pull/88814) ([Raúl Marín](https://github.com/Algunenano)).
