<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#83339](https://github.com/ClickHouse/ClickHouse/issues/83339) でバックポート: QueryTreeHash を少し高速化しました。 [#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="improvement">
  #### 改善
</div>

* [#83013](https://github.com/ClickHouse/ClickHouse/issues/83013) でバックポート: Keeper の改善: changelogファイルをバックグラウンドスレッドでディスク間移動するようにしました。以前は、changelog を別のディスクに移動すると、移動が完了するまで Keeper 全体がブロックされていました。移動に長時間かかる場合 (たとえば S3 ディスク への移動) 、これによりパフォーマンスが低下していました。[#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)).
* [#83203](https://github.com/ClickHouse/ClickHouse/issues/83203) でバックポート: ZooKeeper の接続問題により `SYSTEM RESTART REPLICA` が失敗することがあります。このテーブルを見失わないよう、テーブルが作成されるまで再試行するようにしました。[#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#83180](https://github.com/ClickHouse/ClickHouse/issues/83180) でバックポート: clickhouse client で不明な設定に関する警告を集約し、要約として記録するようにしました。[#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#83315](https://github.com/ClickHouse/ClickHouse/issues/83315)でバックポート: Iceberg で &quot;Context has expired&quot; が発生する問題を修正。 [#82146](https://github.com/ClickHouse/ClickHouse/pull/82146) ([Azat Khuzhin](https://github.com/azat)).
* [#83255](https://github.com/ClickHouse/ClickHouse/issues/83255)でバックポート: external table エンジンにおける cached buffer の境界アラインメント無効化の不具合を修正。この問題は [https://github.com/ClickHouse/ClickHouse/pull/81868](https://github.com/ClickHouse/ClickHouse/pull/81868) で発生していました。 [#82493](https://github.com/ClickHouse/ClickHouse/pull/82493) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#82911](https://github.com/ClickHouse/ClickHouse/issues/82911)でバックポート: AzureBlobStorage で native copy のために authentication methods を比較する際、例外が発生した場合は読み取りとコピー (つまり native ではない copy) に fallback するようコードを更新。 [#82693](https://github.com/ClickHouse/ClickHouse/pull/82693) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#83110](https://github.com/ClickHouse/ClickHouse/issues/83110)でバックポート: union/intersect/except&#95;default&#95;mode の rewrite における exception safety を修正。 [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664) をクローズ。 [#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#83328](https://github.com/ClickHouse/ClickHouse/issues/83328)でバックポート: Iceberg の data race を修正。 [#82841](https://github.com/ClickHouse/ClickHouse/pull/82841) ([Azat Khuzhin](https://github.com/azat)).
* [#83287](https://github.com/ClickHouse/ClickHouse/issues/83287)でバックポート: 型 SCRAM&#95;SHA256&#95;PASSWORD で AST からパースする際に、auth data に salt を設定するよう修正。 [#82888](https://github.com/ClickHouse/ClickHouse/pull/82888) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#83025](https://github.com/ClickHouse/ClickHouse/issues/83025)でバックポート: storage `Merge` を持つテーブルとの JOIN expression を含むクエリに対する filter の変更処理を修正。 [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092) を修正。 [#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd)).
* [#83309](https://github.com/ClickHouse/ClickHouse/issues/83309)でバックポート: QueryMetricLog で発生する LOGICAL&#95;ERROR: Mutex cannot be NULL を修正。 [#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos)).
* [#83238](https://github.com/ClickHouse/ClickHouse/issues/83238)でバックポート: アナライザ が enabled な場合に、secondary queries が常に VIEWs からすべてのカラムを読み取ってしまうことによる性能低下を修正。 [#81718](https://github.com/ClickHouse/ClickHouse/issues/81718) を修正。 [#83036](https://github.com/ClickHouse/ClickHouse/pull/83036) ([Dmitry Novik](https://github.com/novikd)).
* [#83428](https://github.com/ClickHouse/ClickHouse/issues/83428)でバックポート: read-only ディスク上でバックアップを復元する際の、誤解を招く error message を修正。 [#83051](https://github.com/ClickHouse/ClickHouse/pull/83051) ([Julia Kartseva](https://github.com/jkartseva)).
* [#83197](https://github.com/ClickHouse/ClickHouse/issues/83197)でバックポート: dependencies のない create table では循環 dependencies をチェックしないように修正。これにより、[https://github.com/ClickHouse/ClickHouse/pull/65405](https://github.com/ClickHouse/ClickHouse/pull/65405) で導入された、数千のテーブルを作成する use case での性能低下を修正。 [#83077](https://github.com/ClickHouse/ClickHouse/pull/83077) ([Pavel Kruglov](https://github.com/Avogar)).
* [#83403](https://github.com/ClickHouse/ClickHouse/issues/83403) でバックポート: S3 クライアントの `no_sign_request` を修正。これにより、S3 リクエストへの署名を明示的に回避できます。また、エンドポイントベースの設定を使って、特定のエンドポイントに対して定義することもできます。[#83379](https://github.com/ClickHouse/ClickHouse/pull/83379) ([Antonio Andelic](https://github.com/antonio2368)).
* [#83465](https://github.com/ClickHouse/ClickHouse/issues/83465) でバックポート: CTE の定義が同じ名前の別のテーブル式を参照したときに発生する `TOO_DEEP_SUBQUERIES` 例外を修正。[#83413](https://github.com/ClickHouse/ClickHouse/pull/83413) ([Dmitry Novik](https://github.com/novikd)).
