<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#92689](https://github.com/ClickHouse/ClickHouse/issues/92689)でバックポート: サブカラムの読み取り時に Log engine で発生する可能性がある論理エラーを修正しました。[#91710](https://github.com/ClickHouse/ClickHouse/issues/91710) をクローズします。[#91711](https://github.com/ClickHouse/ClickHouse/pull/91711) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92895](https://github.com/ClickHouse/ClickHouse/issues/92895)でバックポート: 同じ名前のカラムとサブカラムが競合し、誤ったシリアライゼーションが使用されたり、クエリが失敗したりする可能性がある問題を修正しました。[#90219](https://github.com/ClickHouse/ClickHouse/issues/90219) をクローズします。[#85161](https://github.com/ClickHouse/ClickHouse/issues/85161) をクローズします。[#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93117](https://github.com/ClickHouse/ClickHouse/issues/93117)でバックポート: ワイルドカード権限に対するアクセス権限チェックの不適切なロジックを見直しました。以前の対応 [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) では重大な脆弱性に対処していましたが、結果として制限が厳しすぎ、一部のワイルドカード `GRANT` ステートメントが無関係な権限取り消しのために失敗していました。[#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* [#93219](https://github.com/ClickHouse/ClickHouse/issues/93219)でバックポート: JSON 内のパス &#39;skip&#39; に対する型ヒントの作成を修正しました。[#92731](https://github.com/ClickHouse/ClickHouse/issues/92731) をクローズします。[#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93218](https://github.com/ClickHouse/ClickHouse/issues/93218)でバックポート: `ratio_of_defaults_for_sparse_serialization` 設定を alter で `1.0` に変更した場合に、スパースなカラムの mutation 後に `FILE_DOESNT_EXIST` エラーが発生する可能性がある問題を修正しました。[#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93040](https://github.com/ClickHouse/ClickHouse/issues/93040)でバックポート: WHERE で `not materialize(...)` または `not CAST(...)` を使用した場合に誤った結果を引き起こしていた、データスキップのロジックの不具合を修正しました。[#88536](https://github.com/ClickHouse/ClickHouse/issues/88536) をクローズします。[#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)).
