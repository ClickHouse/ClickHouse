<div id="improvement">
  #### 改善
</div>

* [#81442](https://github.com/ClickHouse/ClickHouse/issues/81442) にバックポート: Azure blob storage のプレーンディスクについて、system.tables で報告される data path にコンテナーのプレフィックスを追加し、S3 および GCP と一貫した報告内容にしました。[#79241](https://github.com/ClickHouse/ClickHouse/pull/79241) ([Julia Kartseva](https://github.com/jkartseva)).
* [#81220](https://github.com/ClickHouse/ClickHouse/issues/81220) にバックポート: クラッシュを修正しました。デストラクタ内で一時ファイルの削除を試みた際に例外がスローされると (一時ファイルは一時データをディスクに spill するために使用されます) 、プログラムが終了する可能性がありました。[#80776](https://github.com/ClickHouse/ClickHouse/pull/80776) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#81536](https://github.com/ClickHouse/ClickHouse/issues/81536) にバックポート: libxml2 を 2.14.3 にアップグレードしました。[#81187](https://github.com/ClickHouse/ClickHouse/pull/81187) ([larryluogit](https://github.com/larryluogit)).
* [#81409](https://github.com/ClickHouse/ClickHouse/issues/81409) にバックポート: ジャーナル付きファイルシステムでは、`mkdir` はディスクに永続化されるファイルシステムのジャーナルに書き込まれます。ディスクが低速な場合、これに時間がかかることがあります。これを reserve lock のスコープ外に移すのが妥当です。[#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#81486](https://github.com/ClickHouse/ClickHouse/issues/81486) にバックポート: `krb5` 1.21.3-final を使用するようにしました。[#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81478](https://github.com/ClickHouse/ClickHouse/issues/81478) にバックポート: `orc` 2.1.2 を使用するようにしました。[#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81666](https://github.com/ClickHouse/ClickHouse/issues/81666) にバックポート: Iceberg のマニフェストファイルの読み取りを、最初の読み取りクエリまで遅らせるようにしました。[#81619](https://github.com/ClickHouse/ClickHouse/pull/81619) ([Daniil Ivanik](https://github.com/divanik)).
* [#81930](https://github.com/ClickHouse/ClickHouse/issues/81930) にバックポート: ファイルシステムキャッシュにおける論理エラー &quot;Having zero bytes but range is not finished&quot; の修正を試みました。[#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#81446](https://github.com/ClickHouse/ClickHouse/issues/81446) にバックポート: `allow_push_predicate_ast_for_distributed_subqueries` が有効な場合に、プッシュダウンされた predicate での CTE の使用を修正しました。[#75647](https://github.com/ClickHouse/ClickHouse/issues/75647) を修正。[#79672](https://github.com/ClickHouse/ClickHouse/issues/79672) を修正。[#77316](https://github.com/ClickHouse/ClickHouse/pull/77316) ([Dmitry Novik](https://github.com/novikd))。
* [#79487](https://github.com/ClickHouse/ClickHouse/issues/79487) にバックポート: `transform` で長らく発生していた論理エラーを修正しました。[#78247](https://github.com/ClickHouse/ClickHouse/pull/78247) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* [#81243](https://github.com/ClickHouse/ClickHouse/issues/81243) にバックポート: IN で Dynamic 型と JSON 型を禁止しました。現在の `IN` の実装では、誤った結果を招く可能性があります。これらの型を `IN` で適切にサポートするのは複雑なため、対応は今後行われる可能性があります。[#79282](https://github.com/ClickHouse/ClickHouse/pull/79282) ([Pavel Kruglov](https://github.com/Avogar))。
* [#81426](https://github.com/ClickHouse/ClickHouse/issues/81426) にバックポート: このカラムが相関しているかどうかの確認時に発生する、カラムの origin scope が不明であることに関する論理エラーを修正しました。[#78183](https://github.com/ClickHouse/ClickHouse/issues/78183) を修正。[#79451](https://github.com/ClickHouse/ClickHouse/issues/79451) を修正。[#79727](https://github.com/ClickHouse/ClickHouse/pull/79727) ([Dmitry Novik](https://github.com/novikd))。
* [#81622](https://github.com/ClickHouse/ClickHouse/issues/81622) にバックポート: データレイクに対する hive パーティション化を無効化しました。[https://github.com/issues/assigned?issue=ClickHouse%7CClickHouse%7C79937](https://github.com/issues/assigned?issue=ClickHouse%7CClickHouse%7C79937) に部分的に対応します。[#80005](https://github.com/ClickHouse/ClickHouse/pull/80005) ([Daniil Ivanik](https://github.com/divanik))。
* [#80838](https://github.com/ClickHouse/ClickHouse/issues/80838) にバックポート: subcolumns を含む projections で発生しうる論理エラーやクラッシュを修正しました。[#80333](https://github.com/ClickHouse/ClickHouse/pull/80333) ([Pavel Kruglov](https://github.com/Avogar))。
* [#81289](https://github.com/ClickHouse/ClickHouse/issues/81289) にバックポート: Merge engine で、一部の table にのみ存在するカラムの読み取り時に誤った結果になる問題を修正しました。[#80643](https://github.com/ClickHouse/ClickHouse/pull/80643) ([Pavel Kruglov](https://github.com/Avogar))。
* [#81341](https://github.com/ClickHouse/ClickHouse/issues/81341) にバックポート: Parquet フォーマットで const tuples または maps を出力する際に clickhouse-local がクラッシュする問題を修正しました。[#81249](https://github.com/ClickHouse/ClickHouse/pull/81249) ([Michael Kolupaev](https://github.com/al13n321))。
* [#81366](https://github.com/ClickHouse/ClickHouse/issues/81366) にバックポート: 空の table を join し、window functions を使用するクエリにおけるコーナーケースを修正しました。このバグにより並列 streams 数が爆発的に増加し、OOM につながります。[#81299](https://github.com/ClickHouse/ClickHouse/pull/81299) ([Alexander Gololobov](https://github.com/davenger))。
* [#81543](https://github.com/ClickHouse/ClickHouse/issues/81543) にバックポート: delta-kernel の Region エラーを修正しました。[#79914](https://github.com/ClickHouse/ClickHouse/issues/79914) を修正。[#81353](https://github.com/ClickHouse/ClickHouse/pull/81353) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#81503](https://github.com/ClickHouse/ClickHouse/issues/81503) にバックポート: 複数のマニフェストファイルの内容をメモリに保持しないようにしました。[#81470](https://github.com/ClickHouse/ClickHouse/pull/81470) ([Daniil Ivanik](https://github.com/divanik))。
* [#81726](https://github.com/ClickHouse/ClickHouse/issues/81726) にバックポート: クエリ設定 `use_iceberg_partition_pruning` は、Iceberg ストレージでは有効になりません。これはクエリコンテキストではなくグローバルコンテキストを使用しているためです。デフォルト値は true のため重大な問題ではありませんが、この PR で修正できます。[#81673](https://github.com/ClickHouse/ClickHouse/pull/81673) ([Han Fei](https://github.com/hanfei1991))。
* [#81846](https://github.com/ClickHouse/ClickHouse/issues/81846) にバックポート: 空の `USING ()` を指定し、旧アナライザが有効な場合に発生する `ConcurrentHashJoin` のクラッシュを修正しました。[#81754](https://github.com/ClickHouse/ClickHouse/pull/81754) ([Nikita Taranov](https://github.com/nickitat))。
* [#81906](https://github.com/ClickHouse/ClickHouse/issues/81906) にバックポート: Keeper の修正: ログ内に無効なエントリがある場合、新しいログのコミットをブロックします。以前は、リーダーが一部のログを誤って適用しても新しいログのコミットを続け、その一方でフォロワーはダイジェストの不一致を検出して中断していました。[#81780](https://github.com/ClickHouse/ClickHouse/pull/81780) ([Antonio Andelic](https://github.com/antonio2368))。
