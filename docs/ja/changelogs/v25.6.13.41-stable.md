<div id="improvement">

* [#87427](https://github.com/ClickHouse/ClickHouse/issues/87427) にバックポート: `s3_slow_all_threads_after_retryable_error` をデフォルトで無効にしました。[#87198](https://github.com/ClickHouse/ClickHouse/pull/87198) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#87155](https://github.com/ClickHouse/ClickHouse/issues/87155) にバックポート: FROM 句内の相関サブクエリについて、外側のクエリのカラムを使用している場合にのみ許可するチェックを追加しました。[#85469](https://github.com/ClickHouse/ClickHouse/issues/85469) を修正。[#85402](https://github.com/ClickHouse/ClickHouse/issues/85402) を修正。[#85966](https://github.com/ClickHouse/ClickHouse/pull/85966) ([Dmitry Novik](https://github.com/novikd)).
* [#86953](https://github.com/ClickHouse/ClickHouse/issues/86953) にバックポート: 他のカラムのマテリアライズド式で使用されているサブカラムを持つカラムに対する ALTER UPDATE を修正しました。従来は、式内にサブカラムを含む materialized column が正しく更新されていませんでした。[#85985](https://github.com/ClickHouse/ClickHouse/pull/85985) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87664](https://github.com/ClickHouse/ClickHouse/issues/87664) にバックポート: numeric/decimal カラムを持つ Postgres データベースエンジン table の detach/attach を修正しました。[#86480](https://github.com/ClickHouse/ClickHouse/pull/86480) ([Julian Maicher](https://github.com/jmaicher)).
* [#87056](https://github.com/ClickHouse/ClickHouse/issues/87056) にバックポート: RowBinary input format で JSON shared data に NULL を書き込む処理を修正し、ColumnObject に追加の検証をいくつか加えました。[#86812](https://github.com/ClickHouse/ClickHouse/pull/86812) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87053](https://github.com/ClickHouse/ClickHouse/issues/87053) にバックポート: 展開後の block の末尾での seek を修正しました。[#86906](https://github.com/ClickHouse/ClickHouse/pull/86906) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87637](https://github.com/ClickHouse/ClickHouse/issues/87637) にバックポート: CTE で計算された関数の結果がクエリ内で非決定的になる問題を修正しました。[#86967](https://github.com/ClickHouse/ClickHouse/pull/86967) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#87189](https://github.com/ClickHouse/ClickHouse/issues/87189) にバックポート: `uniqExact` 関数で `ROLLUP` および `CUBE` modifier を使用した際に、誤った結果になる可能性がある問題を修正しました。[#87014](https://github.com/ClickHouse/ClickHouse/pull/87014) ([Nikita Taranov](https://github.com/nickitat)).
* [#87415](https://github.com/ClickHouse/ClickHouse/issues/87415) にバックポート: EmbeddedRocksDB: Path は user&#95;files 内にある必要があります。[#87109](https://github.com/ClickHouse/ClickHouse/pull/87109) ([Raúl Marín](https://github.com/Algunenano)).
* [#87310](https://github.com/ClickHouse/ClickHouse/issues/87310) にバックポート: 25.1 より前に作成された KeeperMap table で、DROP クエリ実行後もデータが ZooKeeper に残る問題を修正しました。[#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#87164](https://github.com/ClickHouse/ClickHouse/issues/87164) にバックポート: 遅延マテリアライゼーションにおいて、array sizes subcolumn を持つ array の読み取りを修正しました。[#87139](https://github.com/ClickHouse/ClickHouse/pull/87139) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87636](https://github.com/ClickHouse/ClickHouse/issues/87636) にバックポート: `max_temporary_data_on_disk_size` の上限追跡で、一時データの deallocations の計上が不正確になる問題を修正しました。[#87118](https://github.com/ClickHouse/ClickHouse/issues/87118) をクローズ。[#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
* [#87475](https://github.com/ClickHouse/ClickHouse/issues/87475) にバックポート: pathStartsWith がプレフィックス配下のパスにのみ一致するようにしました。[#87181](https://github.com/ClickHouse/ClickHouse/pull/87181) ([Raúl Marín](https://github.com/Algunenano)).
* [#87459](https://github.com/ClickHouse/ClickHouse/issues/87459) でバックポート: const ブロックと非 const ブロックの混在により `JOIN` で発生する &quot;Too large size passed to allocator&quot; `LOGICAL_ERROR` を修正しました。[#87231](https://github.com/ClickHouse/ClickHouse/pull/87231) ([Azat Khuzhin](https://github.com/azat)).
* [#87452](https://github.com/ClickHouse/ClickHouse/issues/87452) でバックポート: `s3_plain_rewritable` では、not found エラーのみを無視するようにしました (そうしないと、さまざまな問題を引き起こす可能性があります) 。[#87426](https://github.com/ClickHouse/ClickHouse/pull/87426) ([Azat Khuzhin](https://github.com/azat)).
