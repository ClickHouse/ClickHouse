<div id="improvement">
  #### 改善
</div>

* [#82594](https://github.com/ClickHouse/ClickHouse/issues/82594) にバックポート: Keeper の改善: 新しい設定 `keeper_server.cleanup_old_and_ignore_new_acl` を追加しました。有効にすると、すべてのノードの ACL がクリアされ、新しいリクエストの ACL は無視されます。ノードから ACL を完全に削除することが目的であれば、新しい snapshot が作成されるまで、この設定は有効のままにしておくことが重要です。[#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* [#82860](https://github.com/ClickHouse/ClickHouse/issues/82860) にバックポート: [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 以降、`X-ClickHouse-Progress` と `X-ClickHouse-Summary` のヘッダーフォーマットは 0 の値を省略するよう変更されていました。この PR では、`X-ClickHouse-Summary` についてのみ、以前の動作に戻します。そのほうが理にかなっているためです。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#82926](https://github.com/ClickHouse/ClickHouse/issues/82926) にバックポート: Keeper の改善: world:anyone ACL に対する個別の権限をサポートしました。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#82779](https://github.com/ClickHouse/ClickHouse/issues/82779) にバックポート: クエリで定数のエイリアスカラムのみが使用されている場合のフィルター解析を修正しました。[#79448](https://github.com/ClickHouse/ClickHouse/issues/79448) を修正します。[#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* [#82559](https://github.com/ClickHouse/ClickHouse/issues/82559) にバックポート: サーバーがメモリ逼迫状態にある場合に、リモートクエリで発生しうるデッドロックを修正しました。[#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* [#82688](https://github.com/ClickHouse/ClickHouse/issues/82688) にバックポート: 相関カラムに対する ROW POLICY 式の解析中に発生する `LOGICAL_ERROR` を修正しました。[#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd)).
* [#82735](https://github.com/ClickHouse/ClickHouse/issues/82735) にバックポート: Functions `trim{Left,Right,Both}` が &quot;FixedString(N)&quot; 型の入力文字列をサポートするようになりました。たとえば、`SELECT trimBoth(toFixedString('abc', 3), 'ac')` が動作するようになりました。[#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
* [#82800](https://github.com/ClickHouse/ClickHouse/issues/82800) にバックポート: 要素が空の場合の `groupArraySample`/`groupArrayLast` のデシリアライゼーションを修正しました (入力が空の場合、デシリアライゼーション時にバイナリデータの一部をスキップしてしまうことがあり、その結果、データ読み取り時の破損や TCPプロトコル での UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER につながる可能性がありました) 。これは数値型および日時型には影響しません。[#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
