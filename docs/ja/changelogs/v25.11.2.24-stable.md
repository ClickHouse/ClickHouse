<div id="improvement">
  #### 改善
</div>

* [#90983](https://github.com/ClickHouse/ClickHouse/issues/90983) でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/90311](https://github.com/ClickHouse/ClickHouse/pull/90311) により統計のフォーマットが変更されたため、古いフォーマットの統計が存在するとサーバーがクラッシュすることがありました。この PR ではこのクラッシュを修正し、既存の統計がレガシーフォーマットを使用している場合は例外をスローするようにします。例外を回避するには、統計を再生成するために `ALTER TABLE [db.]table MATERIALIZE STATISTICS ALL` を実行する必要があります。 [#90904](https://github.com/ClickHouse/ClickHouse/pull/90904) ([Han Fei](https://github.com/hanfei1991)).
* [#91193](https://github.com/ClickHouse/ClickHouse/issues/91193) でバックポート: http clients connection の `hard_limit` に達したときに、`HTTP_CONNECTION_LIMIT_REACHED` 例外がスローされるようになりました。ディスクへの接続では `20000` に設定されています。 [#91016](https://github.com/ClickHouse/ClickHouse/pull/91016) ([Sema Checherinda](https://github.com/CheSema)).
* [#91254](https://github.com/ClickHouse/ClickHouse/issues/91254) でバックポート: 多数のサブカラムを持つ JSON カラムのカラムのサンプルを読み取る際に、無条件でスレッドプールを使用するのではなく、`merge_tree_use_prefixes_deserialization_thread_pool` 設定に従うようにすることで、潜在的なスレッドプール枯渇を修正しました。 [#91208](https://github.com/ClickHouse/ClickHouse/pull/91208) ([Raufs Dunamalijevs](https://github.com/rienath)).
