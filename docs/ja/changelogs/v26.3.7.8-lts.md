<div id="improvement">
  #### 改善
</div>

* [#102314](https://github.com/ClickHouse/ClickHouse/issues/102314) でバックポート: サーバーの環境変数にアクセスできないよう、埋め込みクライアント (SSH および WebSocket プロトコル) で AI SQL生成 (`??` コマンド) を無効化しました。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#102340](https://github.com/ClickHouse/ClickHouse/issues/102340) でバックポート: 結果テーブルの web component へのリファクタリング後に発生していた、play.html web UI でのカラムのリサイズ不具合を修正しました。[#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#102370](https://github.com/ClickHouse/ClickHouse/issues/102370)でバックポート: HEAD リクエストのレスポンスに `Content-Length` ヘッダーがない場合 (たとえば GCS での伸張トランスコーディングが原因) 、ClickHouse がファイルをスキップしてしまう不具合を修正しました。 [#99971](https://github.com/ClickHouse/ClickHouse/pull/99971) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#101534](https://github.com/ClickHouse/ClickHouse/issues/101534)でバックポート: 一部のカタログで、`select * from system.databases` のクエリ結果の `SETTINGS` セクションに一部の secret が表示されることがありました。この PR ではこの問題を防止します。 [#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102436](https://github.com/ClickHouse/ClickHouse/issues/102436)でバックポート: S3 `Client::~Client` デストラクタから例外が漏れ、server が終了してしまう問題を修正しました。 [#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
* [#102279](https://github.com/ClickHouse/ClickHouse/issues/102279)でバックポート: `addStreams` 中に stream コンストラクタが例外を送出し、`column_streams` に null エントリが残ることで発生する `MergeTreeDataPartWriterWide::cancel` の SIGSEGV を修正しました。 [#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102240](https://github.com/ClickHouse/ClickHouse/issues/102240)でバックポート: WHERE 句を含むビューをクエリした際、内部クエリがビューのメタデータとは異なる型のカラム (たとえば `join_use_nulls` を使用した LEFT JOIN による Nullable) を生成するとクラッシュ (SIGSEGV) する問題を修正しました。 [#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
