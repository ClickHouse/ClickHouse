<div id="improvement">
  #### 改善
</div>

* [#104034](https://github.com/ClickHouse/ClickHouse/issues/104034) でバックポート: 行ポリシーがソートキーのカラムのみに依存し、かつ決定論的な場合、`FINAL` の後にその行ポリシーを遅延させる処理をスキップし、そのケースで行ポリシーによって強制されていた対応する `PREWHERE` の遅延もスキップするようにしました。[#102884](https://github.com/ClickHouse/ClickHouse/pull/102884) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#104384](https://github.com/ClickHouse/ClickHouse/issues/104384) でバックポート: リフレッシュ可能なマテリアライズドビューが継続的にリフレッシュされる場合でも、グローバルな状態ではなくスナップショット時点のテーブルの状態に基づいて判定することで、バックアップの耐障害性を向上させました。[#103384](https://github.com/ClickHouse/ClickHouse/pull/103384) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#104702](https://github.com/ClickHouse/ClickHouse/issues/104702) でバックポート: 大規模な非ASCIIデータセット (たとえばテキスト索引のビルド時) の処理中に、蓄積された出力バッファが 2 GiB を超えると発生していた &#96;lowerUTF8&#96; / &#96;upperUTF8&#96; の例外を修正しました。あわせて、過度に長い単一行は明確なエラーを返して拒否するようにしました。[#104229](https://github.com/ClickHouse/ClickHouse/pull/104229) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#105063](https://github.com/ClickHouse/ClickHouse/issues/105063) でバックポート: 新しい設定 `defer_partition_pruning_after_final` (デフォルト `1`) を追加し、26.3 で導入された `FINAL` 配下でパーティションプルーニングをスキップする動作をオプトアウト可能にしました。これを `0` に設定すると、26.3 より前のパーティションプルーニングに戻ります。これは、同じ PK の行がパーティションをまたがらないイベントログのワークロードで大幅な高速化につながります。`compatibility = '26.2'` を設定すると、自動的に `0` に切り替わります。[#104705](https://github.com/ClickHouse/ClickHouse/pull/104705) ([Nikita Fomichev](https://github.com/fm4v)).

* [#105017](https://github.com/ClickHouse/ClickHouse/issues/105017)でバックポート: `DataLakeCatalog` が `auth_header` 設定を検証する際に、server の `http_forbid_headers` 設定を尊重するよう修正しました。[#98827](https://github.com/ClickHouse/ClickHouse/pull/98827) ([Michael Anastasakis](https://github.com/michael-anastasakis)).
* [#104471](https://github.com/ClickHouse/ClickHouse/issues/104471)でバックポート: `IN (subquery)` を含む filter が query optimizer によって PREWHERE に移動された際に発生する &quot;Not-ready Set&quot; 例外を修正しました。[#100375](https://github.com/ClickHouse/ClickHouse/pull/100375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#104026](https://github.com/ClickHouse/ClickHouse/issues/104026)でバックポート: 行を insert する際、その行で新しい dynamic field が追加され、同時に互換性のない値を持つ型付きフィールドが存在し、その後そのカラムが GROUP BY キーとして使われた場合に JSON column で発生しうる例外を修正しました。[#100758](https://github.com/ClickHouse/ClickHouse/pull/100758) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* [#104406](https://github.com/ClickHouse/ClickHouse/issues/104406)でバックポート: join の並べ替えによって、INNER JOIN の filter (outer join の保持側のみを参照するもの) が outer join の ON clause に押し込まれることで発生する、誤った query results を修正しました。[#101504](https://github.com/ClickHouse/ClickHouse/pull/101504) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#105364](https://github.com/ClickHouse/ClickHouse/issues/105364)でバックポート: 右テーブルが key ごとに複数の行を持ち、サイズ制限のため出力ブロックが分割される場合に、RIGHT ANY JOIN で誤った結果が返る不具合を修正しました。[#99431](https://github.com/ClickHouse/ClickHouse/issues/99431) をクローズしました。[#102064](https://github.com/ClickHouse/ClickHouse/pull/102064) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#103343](https://github.com/ClickHouse/ClickHouse/issues/103343)でバックポート: インメモリデータベース上のテーブル (例: 一時テーブル) に対して ALTER クエリを実行した際に発生しうるクラッシュを修正しました。[#102360](https://github.com/ClickHouse/ClickHouse/pull/102360) ([Den Kalantaevskii](https://github.com/Diskein)).
* [#105379](https://github.com/ClickHouse/ClickHouse/issues/105379)でバックポート: nested types のデシリアライゼーション中に、Avro reader でスタックオーバーフローを検出するようにしました。[#102417](https://github.com/ClickHouse/ClickHouse/pull/102417) ([Pavel Kruglov](https://github.com/Avogar)).
* [#105611](https://github.com/ClickHouse/ClickHouse/issues/105611)でバックポート: `processInsertQuery` の最後で無条件に `sendProgress` していたことが原因で、古い client が `remote()` または 分散テーブル 経由で新しい server に insert する際に `UNEXPECTED_PACKET_FROM_SERVER` で失敗する後方互換性の問題を修正しました。[#103148](https://github.com/ClickHouse/ClickHouse/pull/103148) ([Sema Checherinda](https://github.com/CheSema)).
* [#104618](https://github.com/ClickHouse/ClickHouse/issues/104618)でバックポート: `clone() const` が同じ `invalidate_query_response` 文字列を読み取り、`isModified() const` がそこへ書き込むことで発生する、ClickHouse、MySQL、PostgreSQL、XDBC の dictionary sources における data race を修正しました。[#103277](https://github.com/ClickHouse/ClickHouse/pull/103277) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#105216](https://github.com/ClickHouse/ClickHouse/issues/105216)でバックポート: `AggregateFunction` state に整数を掛ける際 (例: `quantilesExactState(...) * N`) に発生する heap-use-after-free を修正しました。二乗法によるべき乗ループで state をそれ自身と merge していましたが、aggregate function の `merge` が内部ストレージを再割り当てする場合、これは未定義動作になります。STID 0988-40af をクローズします。[#103536](https://github.com/ClickHouse/ClickHouse/pull/103536) ([Groene AI](https://github.com/groeneai)).
* [#104365](https://github.com/ClickHouse/ClickHouse/issues/104365)でバックポート: キャプチャされた定数を含む lambda 式 (例: `arrayMap((k, v) -> concat(k, '=', v), mapKeys(m), mapValues(m)))`) を持つ `ALIAS` カラムに対するテキストおよび bloom filter のスキップインデックスが、暗黙的に無視されていた問題を修正しました。[#103708](https://github.com/ClickHouse/ClickHouse/pull/103708) ([Anton Popov](https://github.com/CurtizJ))。
* [#103902](https://github.com/ClickHouse/ClickHouse/issues/103902)でバックポート: JSON column を持つテーブルの data part チェックおよび整合性チェックを修正しました。従来は、存在しないファイルに関する誤検知の error が発生する可能性がありました。[#103858](https://github.com/ClickHouse/ClickHouse/pull/103858) ([Pavel Kruglov](https://github.com/Avogar))。
* [#105081](https://github.com/ClickHouse/ClickHouse/issues/105081)でバックポート: consumer が一時的なトピック・パーティションロックを保持している間に Keeper session が置き換えられると server がクラッシュする可能性がある、`StorageKafka2` の use-after-free を修正しました。[#103890](https://github.com/ClickHouse/ClickHouse/pull/103890) ([Groene AI](https://github.com/groeneai))。
* [#105185](https://github.com/ClickHouse/ClickHouse/issues/105185)でバックポート: PostgreSQL、Cassandra、および XDBC dictionary sources における SQL injection 脆弱性を修正しました。シングルクォートを含む文字列 key は `\'` (backslash) でエスケープされていましたが、これらの backend ではこれがエスケープシーケンスではなくリテラルの backslash として扱われるため、dictionary のルックアップクエリに任意の SQL を injection できていました。`ExternalQueryBuilder` は、これらの backend に対して SQL 標準の `''` escaping を出力するようになりました。ClickHouse および MySQL の dictionary sources では、引き続き backslash escaping を使用します。[#104009](https://github.com/ClickHouse/ClickHouse/pull/104009) ([Shaohua Wang](https://github.com/tiandiwonder))。
* [#104340](https://github.com/ClickHouse/ClickHouse/issues/104340)でバックポート: `optimize_inverse_dictionary_lookup` 設定における複数のエッジケースでの正確性の問題を修正しました。これにより、最適化によって行が暗黙的に欠落したり、例外が抑制されたりする可能性がありました。[#103270](https://github.com/ClickHouse/ClickHouse/issues/103270) をクローズしました。[#103085](https://github.com/ClickHouse/ClickHouse/issues/103085) をクローズしました。[#104133](https://github.com/ClickHouse/ClickHouse/pull/104133) ([Nihal Z. Miaji](https://github.com/nihalzp))。

* [#104760](https://github.com/ClickHouse/ClickHouse/issues/104760)でバックポート: postgres arrays のパースで発生する可能性がある underflow を修正しました。[#104322](https://github.com/ClickHouse/ClickHouse/pull/104322) ([Grant Holly](https://github.com/grantholly-clickhouse))。
* [#105343](https://github.com/ClickHouse/ClickHouse/issues/105343)でバックポート: replicated `MergeTree` テーブルの `RESTORE` を修正し、復元された part の attach で通常の insert 用 Keeper 再試行予算ではなく `backup_restore_keeper_max_retries` を使用するようにしました。[#104610](https://github.com/ClickHouse/ClickHouse/pull/104610) ([Pablo Marcos](https://github.com/pamarcos))。
* [#105236](https://github.com/ClickHouse/ClickHouse/issues/105236)でバックポート: `<placement>` が設定されていない Keeper に対して `quorum_reads=true` を付けて `get /keeper/availability_zone` を送信した際に発生する、Keeper の終了および再起動ループを修正しました。[#104663](https://github.com/ClickHouse/ClickHouse/pull/104663) ([myeongjun](https://github.com/myeongjjun))。
* [#104958](https://github.com/ClickHouse/ClickHouse/issues/104958) でバックポート: `FutureSetFromTuple::buildOrderedSetInplace` で発生し、論理エラーを引き起こす TOCTOU のデータ競合を修正しました。[#104673](https://github.com/ClickHouse/ClickHouse/pull/104673) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#104846](https://github.com/ClickHouse/ClickHouse/issues/104846) でバックポート: `AvroConfluentRowInputFormat` における use-after-free バグによる segfault を修正しました。[#104751](https://github.com/ClickHouse/ClickHouse/pull/104751) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#105271](https://github.com/ClickHouse/ClickHouse/issues/105271) でバックポート: 動的な構造を持つ型に対する data part の整合性チェックを修正し、破損した columns&#95;substreams.txt を検出できるようにしました。追加の変更を加えた [https://github.com/ClickHouse/ClickHouse/pull/103858](https://github.com/ClickHouse/ClickHouse/pull/103858) の再提出です。[#104888](https://github.com/ClickHouse/ClickHouse/pull/104888) ([Pavel Kruglov](https://github.com/Avogar)).
* [#105096](https://github.com/ClickHouse/ClickHouse/issues/105096) でバックポート: `toUInt128(<Float64 expression>)` のように `Float` を `UInt128` に変換する式を JIT コンパイルする際に発生する `CANNOT_COMPILE_CODE Could not find symbol __fixunsdfti` を修正しました。符号なし 128 ビットの float-to-int compiler-rt 組み込み関数が、JIT シンボルリゾルバに不足していました。[#105031](https://github.com/ClickHouse/ClickHouse/issues/105031) をクローズします。[#105048](https://github.com/ClickHouse/ClickHouse/pull/105048) ([Raúl Marín](https://github.com/Algunenano)).
