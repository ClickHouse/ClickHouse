* [#95286](https://github.com/ClickHouse/ClickHouse/issues/95286) でバックポート: ON CLUSTER 使用時の CREATE USER の認証方式におけるクエリパラメータの置換を修正しました。認証方式内のクエリパラメータ (例: password) が置換されず、リモートノードで UNKNOWN&#95;QUERY&#95;PARAMETER エラーが発生していました。[#92777](https://github.com/ClickHouse/ClickHouse/pull/92777) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* [#95529](https://github.com/ClickHouse/ClickHouse/issues/95529) でバックポート: 同じファイルをめぐって競合するバックアップを多数同時実行すると、サーバーがクラッシュする可能性がありました。[#93659](https://github.com/ClickHouse/ClickHouse/pull/93659) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#94973](https://github.com/ClickHouse/ClickHouse/issues/94973) でバックポート: 現在使用中の別のワークロード内でワークロードを作成しても、クラッシュしなくなりました。[#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)).
* [#95642](https://github.com/ClickHouse/ClickHouse/issues/95642) でバックポート: `toWeek`、`toYearWeek`、`toStartOfWeek`、`toLastDayOfWeek`、`toDayOfWeek` を含む述語に対する主キーおよびスキップ索引の pruning の誤りを修正し、`LowCardinality(String)` を使用する有効なクエリでこれらの関数の一部に発生していた例外も修正しました。[#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#95629](https://github.com/ClickHouse/ClickHouse/issues/95629) でバックポート: `delete_tmp_*` directories の同時削除によって発生していた `ReplicatedMergeTree` 起動時のクラッシュを修正しました。[#94892](https://github.com/ClickHouse/ClickHouse/pull/94892) ([myeongjun](https://github.com/myeongjjun)).
* [#95815](https://github.com/ClickHouse/ClickHouse/issues/95815) でバックポート: `USING` clause とともに複数の joins を使用した際の、ソーステーブル由来の修飾付きカラムに対する型推論を修正しました。以前は、後続の joins によって、その join にそのカラムが関与していない場合でも、元のソースカラムの型が共通スーパータイプに誤って更新されていました (例: `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` では、`t2.a` カラムは最初の join でのみ使用されるため、その型は `t3.a` を除いた `t1.a` と `t2.a` の supertype であるべきです) 。この問題により、実際の実行計画に現れるものとは異なるカラム型を関数が想定した場合、論理エラーやクラッシュにつながることがありました。[#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#95425](https://github.com/ClickHouse/ClickHouse/issues/95425) でバックポート: manifest .avro の list および files の内容取得時に、カラム変換が一度だけ行われるようにしました。[#95164](https://github.com/ClickHouse/ClickHouse/pull/95164) ([Daniil Ivanik](https://github.com/divanik)).
* [#95382](https://github.com/ClickHouse/ClickHouse/issues/95382) でバックポート: 論理更新後に大きなパッチパートを適用する際の不正確なメモリ使用量の計上を修正しました。以前は、大きなパッチの適用によって過剰なメモリ使用量が発生し、server process が OOM killer によって kill されることがありました。[#95231](https://github.com/ClickHouse/ClickHouse/pull/95231) ([Anton Popov](https://github.com/CurtizJ)).
* [#95572](https://github.com/ClickHouse/ClickHouse/issues/95572) でバックポート: `redis` テーブル関数の password argument が、今後はログおよびシステムテーブル (例: `query_log`) でマスクされるようになりました。[#95325](https://github.com/ClickHouse/ClickHouse/pull/95325) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#96392](https://github.com/ClickHouse/ClickHouse/issues/96392) にバックポート: 分散クエリで負の `LIMIT/OFFSET` を使用した際に、一部のケースで発生していた論理エラーを修正しました。 [#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#95606](https://github.com/ClickHouse/ClickHouse/issues/95606) にバックポート: キャンセル時に分散クエリで発生する可能性があるクラッシュを回避しました。 [#95466](https://github.com/ClickHouse/ClickHouse/pull/95466) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* [#95546](https://github.com/ClickHouse/ClickHouse/issues/95546) にバックポート: plain&#95;rewritable 上の暗号化ディスクに対するチェックを修正しました (`It is not possible to register multiple plain-rewritable disks with the same object storage prefix` が発生する可能性を修正) 。 [#95470](https://github.com/ClickHouse/ClickHouse/pull/95470) ([Azat Khuzhin](https://github.com/azat)).
* [#95695](https://github.com/ClickHouse/ClickHouse/issues/95695) にバックポート: 分散 DDL の待機中に Replicated database を同時に削除した場合に発生していた `There was an error: Cannot obtain error message` 論理エラーを修正しました。 [#95539](https://github.com/ClickHouse/ClickHouse/issues/95539) を修正。 [#95664](https://github.com/ClickHouse/ClickHouse/pull/95664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#96053](https://github.com/ClickHouse/ClickHouse/issues/96053) にバックポート: パーティション化された Delta Lake データをまとめる処理を修正しました。 [#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#96211](https://github.com/ClickHouse/ClickHouse/issues/96211) にバックポート: JSON data type のパスのスキップを修正しました。これまでは `JSON(SKIP path)` を使用すると、`path` というプレフィックスを持つすべての JSON キーがスキップされ、`"pathpath"` のようなキーまで対象になっていたため、insert 時にこれらのパスでデータ損失が発生する可能性がありました。現在は修正され、`"path"` というキーのみがスキップされます。 [#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* [#96078](https://github.com/ClickHouse/ClickHouse/issues/96078) にバックポート: グローバルプロファイラの周期を修正しました (`global_profiler_real_time_period_ns` と `global_profiler_cpu_time_period_ns` で制御) 。設定値ではなく切り詰められた値が使われていたため、Profiler が意図した以上に頻繁に起動していました。 [#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)).
* [#96155](https://github.com/ClickHouse/ClickHouse/issues/96155) にバックポート: MySQL 形式や JODA スタイルなどの非固定幅フォーマッタで、`formatDateTime` の use-of-uninitialized-value を修正しました。 [#96133](https://github.com/ClickHouse/ClickHouse/pull/96133) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#96278](https://github.com/ClickHouse/ClickHouse/issues/96278) にバックポート: ProcessList で発生する可能性があるデッドロックを修正しました。これは、キャンセルチェッカーにタスクを追加している際にメモリオーバーコミット tracker がトリガーされると、ロック順序の逆転が起こる可能性があるためです。 [#96182](https://github.com/ClickHouse/ClickHouse/pull/96182) ([Antonio Andelic](https://github.com/antonio2368)).
* [#96325](https://github.com/ClickHouse/ClickHouse/issues/96325) にバックポート: ベクトル類似度索引における `stack-use-after-scope` を修正しました。 [#96259](https://github.com/ClickHouse/ClickHouse/pull/96259) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#96530](https://github.com/ClickHouse/ClickHouse/issues/96530) にバックポート: `max_execution_time` の値が大きいクエリで、cancellation checker thread に発生していたライブロックを修正しました。 [#96450](https://github.com/ClickHouse/ClickHouse/pull/96450) ([Sergei Trifonov](https://github.com/serxa)).
* [#96625](https://github.com/ClickHouse/ClickHouse/issues/96625) にバックポート: `PREWHERE` フィルターカラムにブール値ではない UInt8 値が含まれている場合に、Parquet V3 Native reader で `LOGICAL_ERROR` 例外が発生する問題を修正しました。[#96594](https://github.com/ClickHouse/ClickHouse/pull/96594) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#96691](https://github.com/ClickHouse/ClickHouse/issues/96691) にバックポート: バッファオーバーフローを防ぐため、bech32 の witness version を検証するようにしました。[#96671](https://github.com/ClickHouse/ClickHouse/pull/96671) ([Raúl Marín](https://github.com/Algunenano)).
* [#96917](https://github.com/ClickHouse/ClickHouse/issues/96917) にバックポート: 同じカラムに対して以前に論理更新が実行されていた場合に、`ALTER TABLE DROP COLUMN` クエリが失敗する問題を修正しました。[#96861](https://github.com/ClickHouse/ClickHouse/pull/96861) ([Anton Popov](https://github.com/CurtizJ)).
* [#96936](https://github.com/ClickHouse/ClickHouse/issues/96936) にバックポート: 互換性のない型で `indexOfAssumeSorted` を呼び出した際 (例: 整数の検索値に対する `IPv4` 配列) に `std::terminate` 例外が発生する問題を修正しました。[#96877](https://github.com/ClickHouse/ClickHouse/pull/96877) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
