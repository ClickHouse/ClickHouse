<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#102368](https://github.com/ClickHouse/ClickHouse/issues/102368) でバックポート: HEAD リクエストのレスポンスで `Content-Length` ヘッダーが欠落している場合 (たとえば、GCS で伸長トランスコーディングが行われる場合) に、ClickHouse がファイルをスキップしてしまう不具合を修正しました。[#99971](https://github.com/ClickHouse/ClickHouse/pull/99971) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#101532](https://github.com/ClickHouse/ClickHouse/issues/101532) でバックポート: 一部のカタログで、`select * from system.databases` クエリ結果の `SETTINGS` セクションに一部のシークレットが表示されることがありました。この PR でこの問題を修正しました。[#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102434](https://github.com/ClickHouse/ClickHouse/issues/102434) でバックポート: S3 の `Client::~Client` デストラクタから例外が伝播し、サーバーが終了してしまう不具合を修正しました。[#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG掲載対象外 / 軽微
</div>

* [#102416](https://github.com/ClickHouse/ClickHouse/issues/102416) にバックポート: refreshable MV で `UNKNOWN_TABLE` を引き起こしていた、クエリの storage cache 内の古い UUID を修正しました。[#98678](https://github.com/ClickHouse/ClickHouse/pull/98678) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
