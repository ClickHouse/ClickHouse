<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#98402](https://github.com/ClickHouse/ClickHouse/issues/98402)でバックポート: `loop` テーブル関数が `inner_storage->read()` を直接呼び出しており、行ポリシー、カラムレベルの権限、その他のセキュリティチェックが適用されるインタープリタ層を迂回していました。その結果、行ポリシーで制限されたユーザーでも、直接の SELECT では 0 行しか返らない場合に `loop(table)` を介してすべての行を読み取ることができていました。[#97682](https://github.com/ClickHouse/ClickHouse/pull/97682) ([pufit](https://github.com/pufit)).
* [#98310](https://github.com/ClickHouse/ClickHouse/issues/98310)でバックポート: 主キーと非主キーのスキップ索引が混在する場合に FINAL クエリの結果が誤る問題を修正しました。[#98097](https://github.com/ClickHouse/ClickHouse/pull/98097) ([Raúl Marín](https://github.com/Algunenano)).
* [#98352](https://github.com/ClickHouse/ClickHouse/issues/98352)でバックポート: `aggregated_zookeeper_log` で watch レスポンスに対し、空のままにせず `Watch` コンポーネントを設定するようにしました。[#98202](https://github.com/ClickHouse/ClickHouse/pull/98202) ([Antonio Andelic](https://github.com/antonio2368)).
* [#98326](https://github.com/ClickHouse/ClickHouse/issues/98326)でバックポート: `extremes = 1` が有効な場合にクラッシュを引き起こす可能性があった `ColumnConst::getExtremes` の範囲外アクセスを修正しました。[#98263](https://github.com/ClickHouse/ClickHouse/pull/98263) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#98388](https://github.com/ClickHouse/ClickHouse/issues/98388)でバックポート: データが 65535 の境界をまたぐキーカラムに対する `toDate` 変換でトリガーされる LOGICAL&#95;ERROR 例外 &quot;Invalid binary search result in `MergeTreeSetIndex`&quot; を修正しました。[#98276](https://github.com/ClickHouse/ClickHouse/pull/98276) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴対象外 / 軽微

* [#98301](https://github.com/ClickHouse/ClickHouse/issues/98301)でバックポート: すべてのテストが成功しているにもかかわらず、Finish Workflow が ERROR を報告する問題を修正しました。[#98158](https://github.com/ClickHouse/ClickHouse/pull/98158) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#98262](https://github.com/ClickHouse/ClickHouse/issues/98262)でバックポート: CI で、リリースPRに対する changelog と PR ボディのチェックをスキップするようにしました。[#98246](https://github.com/ClickHouse/ClickHouse/pull/98246) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#98394](https://github.com/ClickHouse/ClickHouse/issues/98394)でバックポート: 折りたたまれた jemalloc プロファイル出力に対して `max_block_size` を 500 に設定しました。[#98349](https://github.com/ClickHouse/ClickHouse/pull/98349) ([Antonio Andelic](https://github.com/antonio2368)).
