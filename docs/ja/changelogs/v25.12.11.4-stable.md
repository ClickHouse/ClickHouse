<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#103749](https://github.com/ClickHouse/ClickHouse/issues/103749)でバックポート: materialized viewを伴わない通常のINSERTで、過剰なConcurrencyControlスロットやスレッド (`max_insert_threads`ではなく`max_threads`) を要求しないようになり、INSERTスループットが高いクラスターでのCCスロット枯渇やスレッド数の急増を防ぎます。[#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* システムライブラリの CVE を解消するため、distroless Docker ベースイメージを Debian 12 から Debian 13 にアップグレードしました。[#103564](https://github.com/ClickHouse/ClickHouse/pull/103564) ([Rahul Nair](https://github.com/motsc)).
* `libssl3t64` の OpenSSL の CVE を修正するため、distroless Docker ベースイメージを更新しました。[#103597](https://github.com/ClickHouse/ClickHouse/pull/103597) ([Rahul Nair](https://github.com/motsc)).
