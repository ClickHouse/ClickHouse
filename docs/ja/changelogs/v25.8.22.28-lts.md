  ### ClickHouse リリース v25.8.22.28-lts (6d294975256) FIXME (v25.8.21.7-lts (099badce0f7) との比較)

<div id="new-feature">
  #### 新機能
</div>

* `clickhouse-server` と `clickhouse-keeper` 向けに、`<version>-distroless` タグ付きの distroless Docker イメージのバリアントを追加しました。[#101426](https://github.com/ClickHouse/ClickHouse/pull/101426) ([Rahul Nair](https://github.com/motsc)).

<div id="improvement">
  #### 改善
</div>

* [#102323](https://github.com/ClickHouse/ClickHouse/issues/102323) でバックポート: サーバーの環境変数へのアクセスを防ぐため、埋め込みクライアント (SSH および WebSocket プロトコル) で AI SQL 生成 (`??` コマンド) を無効にしました。[#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#101597](https://github.com/ClickHouse/ClickHouse/issues/101597) でバックポート: Cgroupv2 のメモリ追跡で `slab_reclaimable` がカーネルメモリから除外されるようになり、回収不能なメモリ使用量をより正確に測定できるようになりました。[#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102134](https://github.com/ClickHouse/ClickHouse/issues/102134) でバックポート: 内部の mongo-c-driver を 2.2.2 から 2.2.3 に更新しました。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).
* [#101929](https://github.com/ClickHouse/ClickHouse/issues/101929) でバックポート: libarchive を 3.8.5 から 3.8.6 に更新しました。[#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)).
* [#101864](https://github.com/ClickHouse/ClickHouse/issues/101864) でバックポート: curl を 8.18 から 8.19 に更新しました。[#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#92409](https://github.com/ClickHouse/ClickHouse/issues/92409) にバックポート: 述語に `NULL` 定数が含まれている場合に、`Set` の索引解析中に発生していた `Bad get` エラーを修正しました。[#84856](https://github.com/ClickHouse/ClickHouse/issues/84856) および [#82974](https://github.com/ClickHouse/ClickHouse/issues/82974) を修正します。[#89429](https://github.com/ClickHouse/ClickHouse/pull/89429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#94969](https://github.com/ClickHouse/ClickHouse/issues/94969) にバックポート: 現在使用中の別の workload 内で workload を作成しても、クラッシュが発生しなくなりました。[#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)).
* [#96287](https://github.com/ClickHouse/ClickHouse/issues/96287) にバックポート: CTE の畳み込み済み定数に対する query condition cache のハッシュ衝突を修正しました。これにより、誤ったクエリ結果が生じる可能性がありました。[#96060](https://github.com/ClickHouse/ClickHouse/issues/96060) をクローズしました。[#96172](https://github.com/ClickHouse/ClickHouse/pull/96172) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#102653](https://github.com/ClickHouse/ClickHouse/issues/102653) にバックポート: `ASTColumnsExceptTransformer::transform` における LOGICAL&#95;ERROR 例外を修正しました。[#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* [#100487](https://github.com/ClickHouse/ClickHouse/issues/100487) でバックポート: JDBC、ODBC、NATS の接続文字列に含まれる認証情報が、クエリログおよび `SHOW CREATE` の出力でマスクされるようになり、機密情報の意図しない漏洩を防止します。URI 形式の接続文字列 (例: {scheme}://{user}:{password}@{host}) では、パスワード部分のみがマスクされ、それ以外はデバッグしやすいよう表示されたままになります。`nats_token` 設定もマスクされるようになりました。 [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#101470](https://github.com/ClickHouse/ClickHouse/issues/101470) でバックポート: Keeper で、同じサーバー上の別の無関係なセッションが不運なタイミングでクローズされると、read request がハングしてセッションがタイムアウトすることがある不具合を修正しました。[#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* [#99963](https://github.com/ClickHouse/ClickHouse/issues/99963) でバックポート: アナライザの性能低下を修正しました。ARRAY JOIN から未使用のカラムを削除します。[#99587](https://github.com/ClickHouse/ClickHouse/pull/99587) ([Dmitry Novik](https://github.com/novikd)).
* [#100338](https://github.com/ClickHouse/ClickHouse/issues/100338) でバックポート: cross join とランタイムフィルタを含む `Dynamic` カラムのクエリで発生していた `LOGICAL_ERROR` exception を修正しました。原因は、`ColumnVariant::filter` が `hasOnlyNulls` 最適化パスで Variant カラムのポインタをクローンせずに共有していたことです。[https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147) をクローズします。[#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)).
* [#100885](https://github.com/ClickHouse/ClickHouse/issues/100885) でバックポート: `RESTORE` 中にパストラバーサル、絶対パス、空の名前を拒否するため、backup メタデータ内の file エントリの path を検証するようにしました。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* [#100916](https://github.com/ClickHouse/ClickHouse/issues/100916) でバックポート: LowCardinality 要素を含む Tuple キーに対して PREWHERE/WHERE で `has()` function を使用した際に発生する server crash を修正しました。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* [#101528](https://github.com/ClickHouse/ClickHouse/issues/101528) でバックポート: 一部の catalog では、`select * from system.databases` のクエリ結果の `SETTINGS` セクションに secret が表示されることがあります。この PR では、そのような挙動を防止します。[#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102619](https://github.com/ClickHouse/ClickHouse/issues/102619) でバックポート: 接続プールの use-after-free により発生する、s3Cluster および distributed queries での segfault を修正しました。[#100837](https://github.com/ClickHouse/ClickHouse/pull/100837) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101085](https://github.com/ClickHouse/ClickHouse/issues/101085) でバックポート: 入力に非 ASCII バイトが含まれる場合に `ULIDStringToDateTime` で発生する buffer overflow を修正しました。[#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101926](https://github.com/ClickHouse/ClickHouse/issues/101926) でバックポート: 小数秒が 18 桁を超える datetime 文字列をパースする際に parseDateTimeBestEffort で発生する未定義動作 (符号付き整数の overflow) を修正しました。[#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* [#102675](https://github.com/ClickHouse/ClickHouse/issues/102675) でバックポート: 待機タイマーが、参照先の `ProfileEvents::Counters` を持つワーカースレッドより長く生存した場合に、CPU lease scheduler で発生する use-after-free crash を修正しました。[#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102069](https://github.com/ClickHouse/ClickHouse/issues/102069) でバックポート: `Object` 型の動的パスの並列な deserialization における use-after-scope を修正しました。これにより、多数の動的パスを持つテーブルの読み取り時に crash が発生する可能性がありました。[#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102096](https://github.com/ClickHouse/ClickHouse/issues/102096) にバックポート: 特定の (`default` 以外の) フォーマット設定で、フォーマッタ `%W` を使用した関数 `formatDateTime` の出力が誤っていた問題を修正しました。[#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* [#102741](https://github.com/ClickHouse/ClickHouse/issues/102741) にバックポート: 待機中にリフレッシャブルmaterialized view がドロップされた場合に、`SYSTEM WAIT VIEW` がハングしたままになる不具合を修正しました。[#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
