<div id="clickhouse-release-v253542-lts-14e08ead34a-fixme-as-compared-to-v2534190-lts-93636ae3130">
  ### ClickHouse リリース v25.3.5.42-lts (14e08ead34a) FIXME (v25.3.4.190-lts (93636ae3130) と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#78853](https://github.com/ClickHouse/ClickHouse/issues/78853) にバックポート: StorageS3(Azure)Queue の materialized view への push 中に発生したエラーで、`loading_retries` の上限を適用するようにしました。これ以前は、この種のエラーは無制限に再試行されていました。[#78313](https://github.com/ClickHouse/ClickHouse/pull/78313) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#82411](https://github.com/ClickHouse/ClickHouse/issues/82411) にバックポート: ハッシュ関数が、配列、タプル、マップ内の NULL をサポートするようになりました。 (issues [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) および [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)) 。[#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* [#81612](https://github.com/ClickHouse/ClickHouse/issues/81612) にバックポート: `orc` 2.1.2 を使用。[#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#81697](https://github.com/ClickHouse/ClickHouse/issues/81697) にバックポート: `grpc` 1.73.0 を使用。[#81629](https://github.com/ClickHouse/ClickHouse/pull/81629) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#82592](https://github.com/ClickHouse/ClickHouse/issues/82592) にバックポート: Keeper の改善: 新しい config `keeper_server.cleanup_old_and_ignore_new_acl` を追加しました。有効にすると、すべての node の ACL がクリアされ、新しい requests に対する ACL は無視されます。node から ACL を完全に削除することが目的であれば、新しい snapshot が作成されるまで、この config を有効のままにしておくことが重要です。[#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* [#82922](https://github.com/ClickHouse/ClickHouse/issues/82922) にバックポート: Keeper の改善: world:anyone ACL に対する個別の permissions をサポートしました。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#82328](https://github.com/ClickHouse/ClickHouse/issues/82328) にバックポート: 左側の引数が null で、サブクエリの結果が非 Nullable の場合に、`transform_null_in=1` を指定した `IN` の実行を修正しました。[#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar))。
* [#82775](https://github.com/ClickHouse/ClickHouse/issues/82775) にバックポート: クエリ内で定数の alias カラムのみが使われている場合の filter 解析を修正しました。[#79448](https://github.com/ClickHouse/ClickHouse/issues/79448) を修正。[#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd))。
* [#82548](https://github.com/ClickHouse/ClickHouse/issues/82548) にバックポート: GROUP BY と SET の 有効期限 (TTL) で同じカラムを使用した際に発生する LOGICAL&#95;ERROR と、それに続く crash を修正しました。[#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos))。
* [#82314](https://github.com/ClickHouse/ClickHouse/issues/82314) にバックポート: `WHERE` 条件および `IndexSet` 配下で `arrayJoin` を含むクエリにおける `Not found column` error を修正しました。[#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#82557](https://github.com/ClickHouse/ClickHouse/issues/82557) にバックポート: server がメモリ逼迫状態にある場合に、リモートクエリで発生する可能性のあるデッドロックを修正しました。[#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar))。
* [#82519](https://github.com/ClickHouse/ClickHouse/issues/82519) にバックポート: AWS ECS token に有効期限 (TTL) を追加し、再読み込みできるようにしました。[#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able))。
* [#82575](https://github.com/ClickHouse/ClickHouse/issues/82575) にバックポート: logs/query&#95;log で named collection の values を隠す処理を修正しました。[#82405](https://github.com/ClickHouse/ClickHouse/issues/82405) をクローズ。[#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#82566](https://github.com/ClickHouse/ClickHouse/issues/82566) にバックポート: `user_id` が空になることがあるため、session 終了時のログで発生する可能性のある crash を修正しました。[#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc))。
* [#82731](https://github.com/ClickHouse/ClickHouse/issues/82731) にバックポート: Functions `trim{Left,Right,Both}` が &quot;FixedString(N)&quot; 型の入力文字列をサポートするようになりました。たとえば、`SELECT trimBoth(toFixedString('abc', 3), 'ac')` が動作するようになりました。[#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze))。
