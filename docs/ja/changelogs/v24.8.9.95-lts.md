</div>

* [#73029](https://github.com/ClickHouse/ClickHouse/issues/73029) でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/57631](https://github.com/ClickHouse/ClickHouse/pull/57631) の、compact パーツ内で単一カラムのサブカラムを読み取る際の最適化を復活させました。これは誤って削除されていました。[#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### 改善
</div>

* [#72568](https://github.com/ClickHouse/ClickHouse/issues/72568) でバックポート: `metadata_version` レコードを ZooKeeper で `attach` スレッドではなく再起動スレッド内で修正するようにしました。 [#70297](https://github.com/ClickHouse/ClickHouse/pull/70297) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).

* [#72671](https://github.com/ClickHouse/ClickHouse/issues/72671) でバックポート: cache 全体の memory usage を削減するため、cached marks の memory usage の概算精度を向上させました。 [#72630](https://github.com/ClickHouse/ClickHouse/pull/72630) ([Antonio Andelic](https://github.com/antonio2368)).
