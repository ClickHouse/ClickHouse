  ### ClickHouse リリース v26.2.4.23-stable (94012846cb5) FIXME (v26.2.3.2-stable (ba231782911) との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#98752](https://github.com/ClickHouse/ClickHouse/issues/98752) でバックポート: デフォルトで非同期 INSERT を有効化しました。ClickHouse は今後、すべての小さな INSERT をデフォルトでまとめて処理します。この設定は compatibility で制御されます。`compatibility=<version less than 26.2>` を設定した場合、デフォルト値は従来どおり `false` になります。非同期 INSERT は複数のレベルでオフ/オンを切り替えられます。users profiles の config、セッション、クエリ、または MergeTree table です。 [#97590](https://github.com/ClickHouse/ClickHouse/pull/97590) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 改善
</div>

* [#98785](https://github.com/ClickHouse/ClickHouse/issues/98785) でバックポート: 新しい設定 `allow_nullable_tuple_in_extracted_subcolumns` により、`Tuple`、`Variant`、`Dynamic`、`JSON` から抽出された `Tuple(...)` サブカラムを `Nullable(Tuple(...))` (欠損行では `NULL`) として返すか、`Tuple(...)` (欠損行ではデフォルトのタプル値) として返すかを制御できるようになりました。デフォルトでは無効で、この設定を変更するにはサーバーの再起動が必要です。[#97299](https://github.com/ClickHouse/ClickHouse/pull/97299) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#98481](https://github.com/ClickHouse/ClickHouse/issues/98481) でバックポート: jemalloc の `lg_prof_sample` を制御し、これを `jemalloc.prof.lg_sample` 非同期メトリクスとして公開するサーバー設定 `jemalloc_profiler_sampling_rate` を追加しました。[#97945](https://github.com/ClickHouse/ClickHouse/pull/97945) ([Antonio Andelic](https://github.com/antonio2368)).
* [#98488](https://github.com/ClickHouse/ClickHouse/issues/98488) でバックポート: 複数リクエスト内の各サブリクエストを個別にカウントし、実際の Keeper workload をより正確に可視化する新しい profile event `KeeperRequestTotalWithSubrequests` を追加しました。既存の `KeeperRequestTotal` event は、引き続き各複数リクエストを 1 つのリクエストとしてカウントします。[#98348](https://github.com/ClickHouse/ClickHouse/pull/98348) ([Antonio Andelic](https://github.com/antonio2368)).
* [#98749](https://github.com/ClickHouse/ClickHouse/issues/98749) でバックポート: 分散索引解析に参加するのは、「生存中」 (つまり接続可能) なレプリカのみになりました。[#98521](https://github.com/ClickHouse/ClickHouse/pull/98521) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#98439](https://github.com/ClickHouse/ClickHouse/issues/98439) でバックポート: ALIAS カラムのサブカラム読み取り時に、誤った結果が返されたり例外が発生したりする問題を修正しました。[#95408](https://github.com/ClickHouse/ClickHouse/pull/95408) ([Pavel Kruglov](https://github.com/Avogar))。
* [#98820](https://github.com/ClickHouse/ClickHouse/issues/98820) でバックポート: `Nullable(Tuple)` の導入後、`sumCount` 集約関数が以前にシリアライズされた状態を読み取れなくなっていた問題を修正しました。[#97370](https://github.com/ClickHouse/ClickHouse/issues/97370) をクローズします。[#97502](https://github.com/ClickHouse/ClickHouse/pull/97502) ([Nihal Z. Miaji](https://github.com/nihalzp))。
* [#98659](https://github.com/ClickHouse/ClickHouse/issues/98659) でバックポート: scalar file() および DESCRIBE TABLE file() に対して READ ON FILE チェックを適用するようにしました。[#98115](https://github.com/ClickHouse/ClickHouse/pull/98115) ([Nikolay Degterinsky](https://github.com/evillique))。
* [#98563](https://github.com/ClickHouse/ClickHouse/issues/98563) でバックポート: 分散索引解析 (実験的機能) および query condition cache で誤った結果が返る問題を修正しました。[#98269](https://github.com/ClickHouse/ClickHouse/pull/98269) ([Azat Khuzhin](https://github.com/azat))。
* [#98774](https://github.com/ClickHouse/ClickHouse/issues/98774) でバックポート: MergeTree テーブルで `IN` サブクエリを含む `PREWHERE` を使用した際に、`LOGICAL_ERROR: Not-ready Set is passed as the second argument for function 'in'` が発生する問題を修正しました。[#98522](https://github.com/ClickHouse/ClickHouse/pull/98522) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#98651](https://github.com/ClickHouse/ClickHouse/issues/98651) でバックポート: 新しい block の append 中に例外が発生した場合の処理で、Buffer engine におけるカラムの rollback を修正しました。従来のロジックでは、カラムの in-memory state が破損する可能性がありました。[#98551](https://github.com/ClickHouse/ClickHouse/pull/98551) ([Pavel Kruglov](https://github.com/Avogar))。
* [#98623](https://github.com/ClickHouse/ClickHouse/issues/98623) でバックポート: テキスト索引と他のスキップ索引を併用する際の動作を修正しました。以前は、クエリの filter でテキスト索引と通常のスキップ索引を同時に利用すると、&quot;Trying to get non-existing mark&quot; のような論理エラーが発生することがありました。[#98555](https://github.com/ClickHouse/ClickHouse/pull/98555) ([Anton Popov](https://github.com/CurtizJ))。
* [#98673](https://github.com/ClickHouse/ClickHouse/issues/98673) でバックポート: PK 内の expressions (カラムだけでなく式も含む) に対する分散索引解析を修正しました (これにより、リモートレプリカ上の不要な granules がまったく filter されない問題が発生していました) 。[#98561](https://github.com/ClickHouse/ClickHouse/pull/98561) ([Azat Khuzhin](https://github.com/azat))。
