* [#83343](https://github.com/ClickHouse/ClickHouse/issues/83343)でバックポート: QueryTreeHash を少し高速化するようにしました。 [#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="improvement">
  #### 改善
</div>

* [#83207](https://github.com/ClickHouse/ClickHouse/issues/83207)でバックポート: JSON および Dynamic カラムで ALTER UPDATE を許可しました。[#82419](https://github.com/ClickHouse/ClickHouse/pull/82419) ([Pavel Kruglov](https://github.com/Avogar))。
* [#83015](https://github.com/ClickHouse/ClickHouse/issues/83015)でバックポート: Keeper の改善: changelog file をバックグラウンドスレッドでディスク間移動できるようにしました。これまでは、changelog を別のディスクに移動すると、移動が完了するまで Keeper 全体がブロックされていました。移動に時間がかかる場合 (たとえば S3 disk への移動) 、性能低下の原因になっていました。[#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368))。
* [#83205](https://github.com/ClickHouse/ClickHouse/issues/83205)でバックポート: `SYSTEM RESTART REPLICA` が ZooKeeper との connection の問題により失敗することがあります。この table が見落とされるのを防ぐため、table が作成されるまで再試行するようにしました。[#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique))。
* [#83270](https://github.com/ClickHouse/ClickHouse/issues/83270)でバックポート: `clickhouse-benchmark` の `--reconnect` オプションの誤ったデフォルト値を修正しました。この値は [#79465](https://github.com/ClickHouse/ClickHouse/issues/79465) で誤って変更されていました。[#82677](https://github.com/ClickHouse/ClickHouse/pull/82677) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#82928](https://github.com/ClickHouse/ClickHouse/issues/82928)でバックポート: Keeper の改善: world:anyone ACL に対する個別 permission をサポートしました。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368))。
* [#83146](https://github.com/ClickHouse/ClickHouse/issues/83146)でバックポート: `system.s3queue_log` に `commit_time`、`commit_id` カラムを追加しました。[#83016](https://github.com/ClickHouse/ClickHouse/pull/83016) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#83184](https://github.com/ClickHouse/ClickHouse/issues/83184)でバックポート: clickhouse client での不明な Settings 警告を集約し、要約としてログに記録するようにしました。[#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc))。
* [#83281](https://github.com/ClickHouse/ClickHouse/issues/83281)でバックポート: 不正な SELECT を持つ MV に対する INSERT で依存関係チェックに誤りがあり、明確な説明を伴う意味のある error ではなく、分かりにくい `std::exception` が返される可能性がありました。現在は修正されています。修正対象: [#82889](https://github.com/ClickHouse/ClickHouse/issues/82889)。[#83190](https://github.com/ClickHouse/ClickHouse/pull/83190) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
