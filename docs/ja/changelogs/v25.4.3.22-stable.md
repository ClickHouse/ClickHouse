  # 2025 年の変更履歴
</div>

<div id="clickhouse-release-v254322-stable-f23535c7722-fixme-as-compared-to-v254231-stable-e2ce00b6885">
  ### ClickHouse リリース v25.4.3.22-stable (f23535c7722) FIXME、v25.4.2.31-stable (e2ce00b6885) との比較
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#79924](https://github.com/ClickHouse/ClickHouse/issues/79924) にバックポート: `LogSeriesLimiter` がインスタンス化のたびにクリーンアップを実行しないようにし、高並行環境でのロック競合とパフォーマンス低下を防止しました。[#79864](https://github.com/ClickHouse/ClickHouse/pull/79864) ([filimonov](https://github.com/filimonov)).

<div id="improvement">
  #### 改善
</div>

* [#79904](https://github.com/ClickHouse/ClickHouse/issues/79904) にバックポート: `access_control_improvements.enable_user_name_access_type` 設定を追加しました。この設定により、[https://github.com/ClickHouse/ClickHouse/pull/72246](https://github.com/ClickHouse/ClickHouse/pull/72246) で導入された、ユーザー/ロールに対するきめ細かな権限付与を有効または無効にできます。25.1 より前のレプリカを含むクラスターがある場合は、この設定をオフにすることを検討してください。[#79842](https://github.com/ClickHouse/ClickHouse/pull/79842) ([pufit](https://github.com/pufit)).
* [#79934](https://github.com/ClickHouse/ClickHouse/issues/79934) にバックポート: `ASTSelectWithUnionQuery::clone()` メソッドの実装が適切に行われ、`is_normalized` フィールドも考慮されるようになりました。これは [#77569](https://github.com/ClickHouse/ClickHouse/issues/77569) の解決に役立つ可能性があります。[#79909](https://github.com/ClickHouse/ClickHouse/pull/79909) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#79820](https://github.com/ClickHouse/ClickHouse/issues/79820) にバックポート: サーバーから `async_insert` を適用する処理 (`apply_settings_from_server` 経由) を修正しました (従来はクライアント側で `Unknown packet 11 from server` エラーが発生していました) 。 [#77578](https://github.com/ClickHouse/ClickHouse/pull/77578) ([Azat Khuzhin](https://github.com/azat)).
* [#79785](https://github.com/ClickHouse/ClickHouse/issues/79785) にバックポート: リフレッシャブルmaterialized view によってバックアップが破損する問題を修正しました。 [#77893](https://github.com/ClickHouse/ClickHouse/pull/77893) ([Michael Kolupaev](https://github.com/al13n321)).
* [#79741](https://github.com/ClickHouse/ClickHouse/issues/79741) にバックポート: MergeTree の Wide part における動的 subcolumn の検出で発生するクラッシュを修正しました。 [#79466](https://github.com/ClickHouse/ClickHouse/pull/79466) ([Pavel Kruglov](https://github.com/Avogar)).
* [#79585](https://github.com/ClickHouse/ClickHouse/issues/79585) にバックポート: テーブル名の長さの検証は、初回の作成クエリに対してのみ行うようにしました。後方互換性の問題を避けるため、副次的な作成では検証しません。 [#79488](https://github.com/ClickHouse/ClickHouse/pull/79488) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#79973](https://github.com/ClickHouse/ClickHouse/issues/79973) にバックポート: クエリ `CREATE DATABASE datalake ENGINE = DataLakeCatalog(\'http://catalog:8181\', \'admin\', \'password\')` で password を非表示にしました。 [#79941](https://github.com/ClickHouse/ClickHouse/pull/79941) ([Han Fei](https://github.com/hanfei1991)).
