  ### ClickHouse リリース v25.11.4.19-stable (2c64eff7334) FIXME、v25.11.3.54-stable (2199c84bef3) との比較
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#92120](https://github.com/ClickHouse/ClickHouse/issues/92120)でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/88380](https://github.com/ClickHouse/ClickHouse/pull/88380) のフォローアップ。このPRでは、プロジェクション内で位置引数を無効化する変更を、後方互換性を持たない変更として扱います。さらに、プロジェクションに位置引数が含まれている場合でも ClickHouseクラスターを安全にアップグレードできるよう、`enable_positional_arguments_for_projections` 設定が導入されています。 [#92007](https://github.com/ClickHouse/ClickHouse/pull/92007) ([Dmitry Novik](https://github.com/novikd)).

<div id="improvement">
  #### 改善
</div>

* [#92571](https://github.com/ClickHouse/ClickHouse/issues/92571) でバックポート: 集約/ソート中のディスクへのスピル時におけるクエリのメモリ使用量検出を、より堅牢にしました。[#92500](https://github.com/ClickHouse/ClickHouse/pull/92500) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#92530](https://github.com/ClickHouse/ClickHouse/issues/92530)でバックポート: サブカラムの読み取り中に Log engine で発生する可能性がある論理エラーを修正しました。[#91710](https://github.com/ClickHouse/ClickHouse/issues/91710) をクローズします。[#91711](https://github.com/ClickHouse/ClickHouse/pull/91711) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92256](https://github.com/ClickHouse/ClickHouse/issues/92256)でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/90816](https://github.com/ClickHouse/ClickHouse/pull/90816) で修正された不具合によって発生しうる、shared data 内でパスが重複した JSON と動的パスを修復する仕組みを追加しました。[#91886](https://github.com/ClickHouse/ClickHouse/pull/91886) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92555](https://github.com/ClickHouse/ClickHouse/issues/92555)でバックポート: スキーマ推論時に、glob 内のすべてのファイルではなく、スキーマを推論した元のファイルに対してのみスキーマを cache するようにしました。[#91745](https://github.com/ClickHouse/ClickHouse/issues/91745) をクローズします。[#92006](https://github.com/ClickHouse/ClickHouse/pull/92006) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92683](https://github.com/ClickHouse/ClickHouse/issues/92683)でバックポート: HTTP 接続が閉じられるのを防ぐため、insert select でリクエストストリームを解放するようにしました。[#92175](https://github.com/ClickHouse/ClickHouse/pull/92175) ([Sema Checherinda](https://github.com/CheSema)).
* [#92707](https://github.com/ClickHouse/ClickHouse/issues/92707)でバックポート: ウィンドウ関数および複数引数に対する `count_distinct_optimization` の処理を修正しました。[#92376](https://github.com/ClickHouse/ClickHouse/pull/92376) ([Raúl Marín](https://github.com/Algunenano)).
* [#92431](https://github.com/ClickHouse/ClickHouse/issues/92431)でバックポート: MEMORY&#95;LIMIT&#95;EXCEEDED 後に aggregate functions で発生する可能性があるクラッシュを修正しました。[#92390](https://github.com/ClickHouse/ClickHouse/pull/92390) ([Azat Khuzhin](https://github.com/azat)).
* [#92674](https://github.com/ClickHouse/ClickHouse/issues/92674)でバックポート: MergeTree での mutation 中に、元の part のシリアライゼーション情報設定を引き継ぐようにしました。これにより、データ型のシリアライゼーション変更後に mutation 済み part に対するクエリで誤った結果が返る可能性を修正しました。[#92419](https://github.com/ClickHouse/ClickHouse/pull/92419) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92622](https://github.com/ClickHouse/ClickHouse/issues/92622)でバックポート: Backup database に対する SHOW CREATE DATABASE で発生するデッドロックを修正しました。[#92541](https://github.com/ClickHouse/ClickHouse/pull/92541) ([Azat Khuzhin](https://github.com/azat)).
* [#92665](https://github.com/ClickHouse/ClickHouse/issues/92665)でバックポート: 第 2 引数が NULL の `tokens()` で発生するクラッシュを防止しました。[#92586](https://github.com/ClickHouse/ClickHouse/pull/92586) ([Raúl Marín](https://github.com/Algunenano)).
* [#92743](https://github.com/ClickHouse/ClickHouse/issues/92743)でバックポート: `WHERE` で `not match(...)` を使用した際に誤った結果を引き起こす、データ skipping ロジックの不具合を修正しました。[#92492](https://github.com/ClickHouse/ClickHouse/issues/92492) をクローズします。[#92726](https://github.com/ClickHouse/ClickHouse/pull/92726) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#92771](https://github.com/ClickHouse/ClickHouse/issues/92771)でバックポート: 読み取り専用ディスク上に MergeTree テーブルが作成されている場合、起動時に一時ディレクトリの削除を試みないようにしました。[#92748](https://github.com/ClickHouse/ClickHouse/pull/92748) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#92803](https://github.com/ClickHouse/ClickHouse/issues/92803)でバックポート: ALTER TABLE REWRITE PARTS (v2) における &quot;Cannot add action to empty ExpressionActionsChain&quot; の問題を修正。 [#92754](https://github.com/ClickHouse/ClickHouse/pull/92754) ([Azat Khuzhin](https://github.com/azat)).
