<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#93844](https://github.com/ClickHouse/ClickHouse/issues/93844)でバックポート: 一部のケースで、名前にドットを含むカラムからサブカラムを読み取れない不具合を修正しました。[#81261](https://github.com/ClickHouse/ClickHouse/issues/81261)、[#82058](https://github.com/ClickHouse/ClickHouse/issues/82058)、[#88169](https://github.com/ClickHouse/ClickHouse/issues/88169) を解決します。[#87205](https://github.com/ClickHouse/ClickHouse/pull/87205) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94156](https://github.com/ClickHouse/ClickHouse/issues/94156)でバックポート: アナライザにおけるカラム別名内の dynamic サブカラム の解決を修正しました。従来は、カラム別名内の dynamic サブカラム が `getSubcolumn` でラップされており、場合によってはまったく解決できないことがありました。[#91434](https://github.com/ClickHouse/ClickHouse/issues/91434) をクローズします。[#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)).
* [#95348](https://github.com/ClickHouse/ClickHouse/issues/95348)でバックポート: 再起動後に interserver host が変更された場合に、Replicated DB を attach できない不具合を修正しました。[#93779](https://github.com/ClickHouse/ClickHouse/pull/93779) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#94354](https://github.com/ClickHouse/ClickHouse/issues/94354)でバックポート: JSON の型付きパスに対する不適切な check を修正しました。この check は [https://github.com/ClickHouse/ClickHouse/pull/92842](https://github.com/ClickHouse/ClickHouse/pull/92842) で導入されており、既存テーブルの起動時にエラーを引き起こす可能性がありました。[#94070](https://github.com/ClickHouse/ClickHouse/pull/94070) ([Pavel Kruglov](https://github.com/Avogar)).
* [#95199](https://github.com/ClickHouse/ClickHouse/issues/95199)でバックポート: 関数からサブカラムへの最適化がサブカラムに適用されない不具合を修正しました。[#94323](https://github.com/ClickHouse/ClickHouse/pull/94323) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94925](https://github.com/ClickHouse/ClickHouse/issues/94925)でバックポート: 欠損カラムに対して `isNotNull` が評価された際に、ANY LEFT JOIN の最適化中に発生するクラッシュを修正しました。[#94600](https://github.com/ClickHouse/ClickHouse/pull/94600) ([Molly](https://github.com/ggmolly)).
* [#94829](https://github.com/ClickHouse/ClickHouse/issues/94829)でバックポート: BACKUP/RESTORE のリストア操作における権限の問題を修正しました。[#94617](https://github.com/ClickHouse/ClickHouse/pull/94617) ([Pablo Marcos](https://github.com/pamarcos)).
* [#95636](https://github.com/ClickHouse/ClickHouse/issues/95636)でバックポート: `toWeek`、`toYearWeek`、`toStartOfWeek`、`toLastDayOfWeek`、`toDayOfWeek` を含む predicates における主キーおよびスキップ索引の不正な pruning を修正し、`LowCardinality(String)` を使用する有効なクエリで、これらの関数の一部が例外を起こす問題も修正しました。[#94816](https://github.com/ClickHouse/ClickHouse/pull/94816) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#95147](https://github.com/ClickHouse/ClickHouse/issues/95147)でバックポート: `getURLHostRFC` 関数では、ポインタを参照外しする前の境界チェックが不足していました。空文字列が `domainRFC` に渡されると、未初期化メモリを読み取り、MSan エラーを引き起こしていました。[#94851](https://github.com/ClickHouse/ClickHouse/pull/94851) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#95569](https://github.com/ClickHouse/ClickHouse/issues/95569)でバックポート: `redis` table function の password 引数が、今後はログおよびシステムテーブル (例: `query_log`) でマスクされるようになりました。[#95325](https://github.com/ClickHouse/ClickHouse/pull/95325) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
