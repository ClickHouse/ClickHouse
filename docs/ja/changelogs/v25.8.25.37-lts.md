* [#105448](https://github.com/ClickHouse/ClickHouse/issues/105448) にバックポート: zookeeper ストレージの使用時に、バックグラウンドで named collections を再読み込み中に発生する uncaught exception を修正しました。[https://github.com/ClickHouse/clickhouse-private/issues/44180](https://github.com/ClickHouse/clickhouse-private/issues/44180) をクローズします。[#92717](https://github.com/ClickHouse/ClickHouse/pull/92717) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#107770](https://github.com/ClickHouse/ClickHouse/issues/107770) にバックポート: HTTP ハンドラーで `query_id` をサニタイズし、`X-ClickHouse-Query-Id` header を介した response headers への CRLF 挿入を防止しました。[#100500](https://github.com/ClickHouse/ClickHouse/pull/100500) ([Pablo Marcos](https://github.com/pamarcos)).
* [#105377](https://github.com/ClickHouse/ClickHouse/issues/105377) にバックポート: nested types の deserialization 中に、Avro reader で stack overflow を検出するようにしました。[#102417](https://github.com/ClickHouse/ClickHouse/pull/102417) ([Pavel Kruglov](https://github.com/Avogar)).
* [#105400](https://github.com/ClickHouse/ClickHouse/issues/105400) にバックポート: replicated `MergeTree` table の `RESTORE` を修正し、復元されたパートの Attach に通常の insert 用 Keeper 再試行枠ではなく `backup_restore_keeper_max_retries` を使用するようにしました。[#104610](https://github.com/ClickHouse/ClickHouse/pull/104610) ([Pablo Marcos](https://github.com/pamarcos)).
* [#105619](https://github.com/ClickHouse/ClickHouse/issues/105619) にバックポート: binary または string カラム内の破損した中間 offsets を含む Arrow または ArrowStream ファイルの読み取り時に発生する heap-buffer-overflow と、geo タグ付き Arrow カラムの読み取り時に発生する null ポインタ逆参照を修正しました。[#105449](https://github.com/ClickHouse/ClickHouse/pull/105449) ([Raúl Marín](https://github.com/Algunenano)).
* [#106483](https://github.com/ClickHouse/ClickHouse/issues/106483) にバックポート: ALTER 後に compressed Memory table から Dynamic subcolumns を読み取る際に発生する SIGSEGV を修正しました。[#104901](https://github.com/ClickHouse/ClickHouse/issues/104901) をクローズします。[#105464](https://github.com/ClickHouse/ClickHouse/pull/105464) ([Pavel Kruglov](https://github.com/Avogar)).
* [#105967](https://github.com/ClickHouse/ClickHouse/issues/105967) にバックポート: JSON type に対する `singleValueOrNull` の deserialization で発生する SEGFAULT を修正しました。[#103630](https://github.com/ClickHouse/ClickHouse/issues/103630) をクローズします。[#105535](https://github.com/ClickHouse/ClickHouse/pull/105535) ([Pavel Kruglov](https://github.com/Avogar)).
* [#106553](https://github.com/ClickHouse/ClickHouse/issues/106553) にバックポート: HTTP またはネイティブプロトコル経由で `ENGINE` clause なしに `CREATE TABLE ... TO INNER UUID '...'` を送信した場合、`CREATE TABLE` 権限を持つ任意のユーザーが引き起こせる server crash (SIGSEGV) を修正しました。同じバグは client もクラッシュさせていました。現在は null ポインタを逆参照する代わりに、パーサーが適切な `BAD_ARGUMENTS` error を返します。[#105579](https://github.com/ClickHouse/ClickHouse/pull/105579) ([Groene AI](https://github.com/groeneai)).
* [#106762](https://github.com/ClickHouse/ClickHouse/issues/106762) にバックポート: 同じ VALUES clause 内でサイズの異なる tuples を String カラムに挿入した際に発生する crash を修正しました。[#101727](https://github.com/ClickHouse/ClickHouse/issues/101727) をクローズします。[#105582](https://github.com/ClickHouse/ClickHouse/pull/105582) ([Pavel Kruglov](https://github.com/Avogar)).
* [#106754](https://github.com/ClickHouse/ClickHouse/issues/106754) にバックポート: flattened Dynamic カラムの Native deserialization における OOB read を修正しました。[#105666](https://github.com/ClickHouse/ClickHouse/pull/105666) ([Pavel Kruglov](https://github.com/Avogar)).
* [#105854](https://github.com/ClickHouse/ClickHouse/issues/105854) でバックポート: コレクション名が空、または NUL バイトを含む場合に、`mongodb` table function、MongoDB storage、および MongoDB Dictionary ソースでクラッシュが発生する問題を修正しました。[#105776](https://github.com/ClickHouse/ClickHouse/pull/105776) ([Raúl Marín](https://github.com/Algunenano))。
* [#106467](https://github.com/ClickHouse/ClickHouse/issues/106467) でバックポート: `SHOW DICTIONARIES` の権限が部分的に取り消された場合に、`system.dictionaries` が 0 行を返す問題を修正しました。[#106105](https://github.com/ClickHouse/ClickHouse/pull/106105) ([Pavel Kruglov](https://github.com/Avogar))。
* [#107967](https://github.com/ClickHouse/ClickHouse/issues/107967) でバックポート: 制約ベースの最適化 (`optimize_using_constraints`) を相関サブクエリと併用した際に発生するクラッシュと、発生する可能性のある `NOT_FOUND_COLUMN_IN_BLOCK` エラーを修正しました。[#106349](https://github.com/ClickHouse/ClickHouse/pull/106349) ([Raúl Marín](https://github.com/Algunenano))。
* [#107348](https://github.com/ClickHouse/ClickHouse/issues/107348) でバックポート: Arrow IPC フォーマットの reader (`ArrowColumnToCHColumn`) における複数の Heap out-of-bounds read を修正しました。不正な Arrow file によって、buffer に含まれる数を超える行数が宣言されたり、list/struct/map の child の長さが親と矛盾する形で宣言されたり、単調でない list offsets が与えられたり、child validity bitmap が切り詰められたりすると、ヒープ割り当て領域の終端を超える読み取りが発生する可能性がありました。これは、`file()`、`format()`、table functions、または ArrowFlight 入力を通じて、`SELECT` privilege を持つ任意のユーザーが到達可能です。現在は、生ポインタにアクセスする前に、すべての data、offsets、view-struct、validity-bitmap buffer を検証し、list/struct/map の形状と offsets の整合性も確認するようになりました。[#106395](https://github.com/ClickHouse/ClickHouse/pull/106395) ([Raúl Marín](https://github.com/Algunenano))。
* [#107839](https://github.com/ClickHouse/ClickHouse/issues/107839) でバックポート: 信頼できない入力から到達可能なフォーマット reader における、複数のメモリ安全性およびリソース枯渇の問題を修正しました。内容は、native Parquet リーダーの `DataPageV2` における definition/repetition level-length 処理での Heap out-of-bounds read、深くネストしたスキーマを持つ Parquet files でのスタックオーバーフロー、さらに GeoParquet の WKB/WKT Geometry および Avro string/bytes のパース時に `max_memory_usage` を無視していた割り当てです。[#106739](https://github.com/ClickHouse/ClickHouse/pull/106739) ([Raúl Marín](https://github.com/Algunenano))。
* [#106786](https://github.com/ClickHouse/ClickHouse/issues/106786) でバックポート: 展開される HTML エンティティ `&nGt;` または `&nLt;` を含む文字列のデコード時に `decodeHTMLComponent` で発生する heap buffer overflow (server crash) を修正しました。この問題は、単一の `SELECT` を実行できる任意のユーザーが到達可能でした。[#106741](https://github.com/ClickHouse/ClickHouse/pull/106741) ([Raúl Marín](https://github.com/Algunenano))。
* [#107275](https://github.com/ClickHouse/ClickHouse/issues/107275) でバックポート: access エンティティ refresh において、ZooKeeper の読み取り中に mutex を保持しないようにしました。[#107097](https://github.com/ClickHouse/ClickHouse/pull/107097) ([Azat Khuzhin](https://github.com/azat))。
* [#108278](https://github.com/ClickHouse/ClickHouse/issues/108278) でバックポート: MsgPack、BSON、ORC、Parquet、JSON、Delta Lake、Iceberg、および Paimon フォーマットで、深くネストしたスキーマまたは値の読み取り時に発生する可能性がある server stack overflow (crash) を修正しました。このような深くネストした入力は、現在では例外として拒否されます。[#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano))。
* [#108220](https://github.com/ClickHouse/ClickHouse/issues/108220) でバックポート: 範囲外のイベント型を持つ細工された aggregate-function state を finalize した際に `windowFunnel` で発生する heap buffer overflow (server crash) を修正しました。この問題は、単一の `SELECT` を実行できる任意のユーザーが到達可能でした。[#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan))。
* [#107712](https://github.com/ClickHouse/ClickHouse/issues/107712) にバックポート: 長さフィールドが 4 未満のメッセージにより `size - 4` のラップアラウンドと過大な `resize`/`ignore` が発生していた、PostgreSQL ワイヤプロトコル パーサーの整数アンダーフローを修正しました。[#107485](https://github.com/ClickHouse/ClickHouse/pull/107485) ([uwezkhan](https://github.com/uwezkhan)).
* [#108236](https://github.com/ClickHouse/ClickHouse/issues/108236) にバックポート: ELF および DWARF のパースに、不足していた境界チェックを追加しました。[#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* [#107874](https://github.com/ClickHouse/ClickHouse/issues/107874) にバックポート: ORC reader に、不足していた境界チェックを追加しました。[#107580](https://github.com/ClickHouse/ClickHouse/pull/107580) ([Michael Kolupaev](https://github.com/al13n321)).
* [#107870](https://github.com/ClickHouse/ClickHouse/issues/107870) にバックポート: 悪意のあるレプリカがパーツディレクトリ外にファイルを書き込める可能性があった、replicated part fetch プロトコルの 2 件のパストラバーサル問題を修正しました。[#107606](https://github.com/ClickHouse/ClickHouse/pull/107606) ([Antonio Andelic](https://github.com/antonio2368)).
* [#108649](https://github.com/ClickHouse/ClickHouse/issues/108649) にバックポート: バックアップ内の内容が重複するパーツが暗黙に重複排除されず保持されるよう、`ReplicatedMergeTree` テーブルの `RESTORE` を修正しました。[#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* [#108155](https://github.com/ClickHouse/ClickHouse/issues/108155) にバックポート: Apache Arrow Java &lt; 19.0.0 (Apache Spark を含む) が生成した、空の `String`/`Binary` カラムを含む Arrow/ArrowStream データの読み取りで、`INCORRECT_DATA` が発生しなくなりました。[#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
* [#108302](https://github.com/ClickHouse/ClickHouse/issues/108302) にバックポート: ルックアップ引数が `LowCardinality` の場合に、`Dynamic` キーを持つ `Map` に対する `has` で発生していたクラッシュ (リリースビルドでは SIGSEGV、デバッグビルドでは型不一致アサーション) を修正しました。例: `has(map('a'::Dynamic, ...), toLowCardinality('b'))`。[#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* [#108531](https://github.com/ClickHouse/ClickHouse/issues/108531) にバックポート: `format_display_secrets_in_show_and_select` が無効 (デフォルト) の場合、`EXPLAIN actions`、`EXPLAIN header`、`EXPLAIN PIPELINE` の出力で、`encrypt`、`decrypt`、`HMAC` などの関数のシークレット引数を非表示にするようにしました。[#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
