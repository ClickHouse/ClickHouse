<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#87742](https://github.com/ClickHouse/ClickHouse/issues/87742) にバックポート: GeoParquet がクライアントのプロトコルエラーを引き起こす不具合を修正しました。[#84020](https://github.com/ClickHouse/ClickHouse/pull/84020) ([Michael Kolupaev](https://github.com/al13n321)).
* [#87387](https://github.com/ClickHouse/ClickHouse/issues/87387) にバックポート: データベース名の誤記修正ヒントを生成する際にアクセス権を確認するようにしました。[#85371](https://github.com/ClickHouse/ClickHouse/pull/85371) ([Dmitry Novik](https://github.com/novikd)).
* [#87668](https://github.com/ClickHouse/ClickHouse/issues/87668) にバックポート: 数値/Decimalカラムを持つ Postgres データベースエンジンのテーブルに対する detach/attach を修正しました。[#86480](https://github.com/ClickHouse/ClickHouse/pull/86480) ([Julian Maicher](https://github.com/jmaicher)).
* [#87639](https://github.com/ClickHouse/ClickHouse/issues/87639) にバックポート: CTE で計算された関数の結果がクエリ内で非決定論的になる問題を修正しました。[#86967](https://github.com/ClickHouse/ClickHouse/pull/86967) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#87808](https://github.com/ClickHouse/ClickHouse/issues/87808) にバックポート: 関数 checkHeaders が指定された headers を正しく検証し、禁止された headers を拒否するようになりました。元の著者: Michael Anastasakis (@michael-anastasakis)。[#87172](https://github.com/ClickHouse/ClickHouse/pull/87172) ([Raúl Marín](https://github.com/Algunenano)).
* [#87813](https://github.com/ClickHouse/ClickHouse/issues/87813) にバックポート: 別の `MergeTree` テーブルを読み取るサブクエリを含む論理更新の不具合を修正しました。[#87285](https://github.com/ClickHouse/ClickHouse/pull/87285) ([Anton Popov](https://github.com/CurtizJ)).
* [#87730](https://github.com/ClickHouse/ClickHouse/issues/87730) にバックポート: Buffer table に対する select および insert のアクセス検証を修正しました。[#87545](https://github.com/ClickHouse/ClickHouse/pull/87545) ([pufit](https://github.com/pufit)).
* [#87771](https://github.com/ClickHouse/ClickHouse/issues/87771) にバックポート: 非同期に削除された View または Materialized View のバックグラウンドクリーンアップが完了する前にサーバーが再起動された場合、その View の SELECT settings によって global server settings が上書きされる可能性がある不具合を修正しました。[#87603](https://github.com/ClickHouse/ClickHouse/pull/87603) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#87795](https://github.com/ClickHouse/ClickHouse/issues/87795) にバックポート: 右側の行リストが使用されない場合の HashJoin algorithm における出力 block の生成を修正しました。[#87401](https://github.com/ClickHouse/ClickHouse/issues/87401) を修正します。[#87699](https://github.com/ClickHouse/ClickHouse/pull/87699) ([Dmitry Novik](https://github.com/novikd)).
