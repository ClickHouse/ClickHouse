  #### 新機能

* [#68710](https://github.com/ClickHouse/ClickHouse/issues/68710) でバックポート: クエリキャッシュのエントリをタグで削除できるようになりました。たとえば、`SELECT 1 SETTINGS use_query_cache = true, query_cache_tag = 'abc'` によって作成されたクエリキャッシュのエントリは、`SYSTEM DROP QUERY CACHE TAG 'abc'` で削除できます (もちろん、`SYSTEM DROP QUERY CACHE` とするだけでクエリキャッシュ全体をクリアすることもできます) 。 [#68477](https://github.com/ClickHouse/ClickHouse/pull/68477) ([Michał Tabaszewski](https://github.com/pinsvin00)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#68973](https://github.com/ClickHouse/ClickHouse/issues/68973)でバックポート: 関数 `fromModifiedJulianDay` の上限値を修正しました。本来は `9999-12-31` であるべきところ、誤って `9999-01-01` に設定されていました。[#67583](https://github.com/ClickHouse/ClickHouse/pull/67583) ([PHO](https://github.com/depressed-pho)).
* [#68818](https://github.com/ClickHouse/ClickHouse/issues/68818)でバックポート: ファイル内のデータ型が要求された型と大きく異なる場合の Parquet フィルタリングで発生するクラッシュを修正しました (例: `... FROM file('a.parquet', Parquet, 'x String')` と指定していても、ファイル内では `x Int64`) 。この修正がない場合は、回避策として `input_format_parquet_filter_push_down = 0` を使用してください。[#68131](https://github.com/ClickHouse/ClickHouse/pull/68131) ([Michael Kolupaev](https://github.com/al13n321)).
* [#68893](https://github.com/ClickHouse/ClickHouse/issues/68893)でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/61984](https://github.com/ClickHouse/ClickHouse/pull/61984) 以降、`schema_inference_make_columns_nullable=0` を設定していても、Parquet/Arrow フォーマットでカラムが `Nullable` になる場合がありました。この変更は後方互換性がなく、ユーザーにも動作の変化として認識されていました。この PR により、`schema_inference_make_columns_nullable=0` は従来どおり動作するようになり (`Nullable` カラムは推論されません) 、さらにこの設定には新しい値 `auto` が追加され、データに nullability の情報がある場合にのみカラムが `Nullable` になります。[#68298](https://github.com/ClickHouse/ClickHouse/pull/68298) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68721](https://github.com/ClickHouse/ClickHouse/issues/68721)でバックポート: [#50868](https://github.com/ClickHouse/ClickHouse/issues/50868) を修正しました。分散クエリ内のネストされたサブクエリが返す小さな DateTime64 の定数値が誤って NULL に変換され、その結果、エラーや誤ったクエリ結果を引き起こす可能性がありました。[#68323](https://github.com/ClickHouse/ClickHouse/pull/68323) ([Shankar](https://github.com/shiyer7474)).
* [#69029](https://github.com/ClickHouse/ClickHouse/issues/69029)でバックポート: 仮想カラム ` _table` と `_database` を分散テーブルに再追加しました。これらはバージョン 24.3 までは利用可能でした。[#68672](https://github.com/ClickHouse/ClickHouse/pull/68672) ([Anton Popov](https://github.com/CurtizJ)).
* [#68864](https://github.com/ClickHouse/ClickHouse/issues/68864)でバックポート: Variant カラムの permutation 中に発生する可能性があるエラー `Size of permutation (0) is less than required (...)` を修正しました。[#68681](https://github.com/ClickHouse/ClickHouse/pull/68681) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68854](https://github.com/ClickHouse/ClickHouse/issues/68854)でバックポート: 新しい JSON カラムで発生する可能性があるエラー `DB::Exception: Block structure mismatch in joined block stream: different columns:` を修正しました。[#68686](https://github.com/ClickHouse/ClickHouse/pull/68686) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68790](https://github.com/ClickHouse/ClickHouse/issues/68790)でバックポート: 関数 `sipHash(64/128)Keyed` で、Array をキーとする Map をハッシュ化する際に materialized された定数キーに関する問題を修正しました。[#68731](https://github.com/ClickHouse/ClickHouse/pull/68731) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* [#69108](https://github.com/ClickHouse/ClickHouse/issues/69108)でバックポート: TODO. [#68744](https://github.com/ClickHouse/ClickHouse/pull/68744) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#68850](https://github.com/ClickHouse/ClickHouse/issues/68850)でバックポート: アナライザでサブクエリから動的サブカラムを解決する際の問題を修正しました。[#68824](https://github.com/ClickHouse/ClickHouse/pull/68824) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68911](https://github.com/ClickHouse/ClickHouse/issues/68911)でバックポート: Delta Lake における複雑な型のメタデータのパースを修正しました。[#68739](https://github.com/ClickHouse/ClickHouse/issues/68739) をクローズしました。[#68836](https://github.com/ClickHouse/ClickHouse/pull/68836) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#69160](https://github.com/ClickHouse/ClickHouse/issues/69160)でバックポート: anyHeavy state のマージ中に誤った結果が生じる可能性がある問題を修正しました。[#68950](https://github.com/ClickHouse/ClickHouse/pull/68950) ([Raúl Marín](https://github.com/Algunenano)).
* [#69072](https://github.com/ClickHouse/ClickHouse/issues/69072)でバックポート: 設定 `optimize_functions_to_subcolumns` が有効な場合の materialized view への書き込みを修正しました。[#68951](https://github.com/ClickHouse/ClickHouse/pull/68951) ([Anton Popov](https://github.com/CurtizJ)).
* [#69016](https://github.com/ClickHouse/ClickHouse/issues/69016)でバックポート: const Dynamic カラムのメソッドでシリアライゼーション cache を使用しないようにしました。これにより、未初期化の値が使用されたり、集計中に race condition が発生したりする可能性がありました。[#68953](https://github.com/ClickHouse/ClickHouse/pull/68953) ([Kruglov Pavel](https://github.com/Avogar)).
* [#69120](https://github.com/ClickHouse/ClickHouse/issues/69120)でバックポート: 空の非同期 INSERT がある場合に発生する論理エラーを修正しました。[#69080](https://github.com/ClickHouse/ClickHouse/pull/69080) ([Han Fei](https://github.com/hanfei1991)).
