* [#93845](https://github.com/ClickHouse/ClickHouse/issues/93845)でバックポート: 一部のケースで、名前にドットを含むカラムからサブカラムを読み取る際の問題を修正しました。[#81261](https://github.com/ClickHouse/ClickHouse/issues/81261)、[#82058](https://github.com/ClickHouse/ClickHouse/issues/82058)、[#88169](https://github.com/ClickHouse/ClickHouse/issues/88169) を解決します。[#87205](https://github.com/ClickHouse/ClickHouse/pull/87205) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92032](https://github.com/ClickHouse/ClickHouse/issues/92032)でバックポート: 非リテラルなパラメータに対する GenerateRandom エンジンのクラッシュを修正しました。`LOGICAL_ERROR` ではなく、明確なメッセージ付きで BAD&#95;ARGUMENTS を返すようになりました。[#88157](https://github.com/ClickHouse/ClickHouse/pull/88157) ([Shafi Ahmed](https://github.com/ita004)).
* [#90417](https://github.com/ClickHouse/ClickHouse/issues/90417)でバックポート: 破棄順序の誤りにより、サーバーの正常なシャットダウン中に発生していたクラッシュを修正しました。[#82420](https://github.com/ClickHouse/ClickHouse/issues/82420) を解決します。[#90076](https://github.com/ClickHouse/ClickHouse/pull/90076) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#94010](https://github.com/ClickHouse/ClickHouse/issues/94010)でバックポート: randomStringUTF8 で整数オーバーフローによって発生するクラッシュを修正しました。[#90326](https://github.com/ClickHouse/ClickHouse/pull/90326) ([Michael Kolupaev](https://github.com/al13n321)).
* [#93719](https://github.com/ClickHouse/ClickHouse/issues/93719)でバックポート: アナライザにおけるカラム別名内の動的サブカラムの解決を修正しました。これまでは、カラム別名内の動的サブカラムが `getSubcolumn` でラップされ、一部のケースではまったく解決されないことがありました。[#91434](https://github.com/ClickHouse/ClickHouse/issues/91434) をクローズします。[#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93952](https://github.com/ClickHouse/ClickHouse/issues/93952)でバックポート: `Ordered` モードの `S3Queue` ストレージで発生する論理エラー ` Failed to set file processing within 100 retries` を修正しました。これは警告に置き換えられました。このエラーは、Keeper セッションの有効期限が切れた場合に 25.10 より前のバージョンで発生することがありましたが、`Ordered` モードで処理の並行度が高い場合には理論上このエラーが引き続き発生しうるため、25.10 以降でも警告のままです。[#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#93590](https://github.com/ClickHouse/ClickHouse/issues/93590)でバックポート: background schedule pool の終了時にハングする可能性がある問題を修正しました (シャットダウン時にサーバーがハングする原因になる可能性があります) 。[#93008](https://github.com/ClickHouse/ClickHouse/pull/93008) ([Azat Khuzhin](https://github.com/azat)).
* [#93557](https://github.com/ClickHouse/ClickHouse/issues/93557)でバックポート: 範囲外の offsets を含む不正な `groupConcat` aggregate state をデシリアライズした際に発生するクラッシュを修正しました。[#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#93400](https://github.com/ClickHouse/ClickHouse/issues/93400)でバックポート: スカラー相関サブクエリが存在する場合の、サブクエリからの未使用カラム削除を修正しました。修正前は、カラムが相関サブクエリでのみ使用されている場合に削除されることがあり、その結果クエリは `NOT_FOUND_COLUMN_IN_BLOCK` エラーで失敗していました。[#93273](https://github.com/ClickHouse/ClickHouse/pull/93273) ([Dmitry Novik](https://github.com/novikd)).
* [#93470](https://github.com/ClickHouse/ClickHouse/issues/93470)でバックポート: 細工された aggregate state によりメモリ安全性の問題を引き起こす可能性があった、`groupConcat` state のデシリアライゼーションにおける整数オーバーフローの脆弱性を修正しました。[#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#93685](https://github.com/ClickHouse/ClickHouse/issues/93685)でバックポート: シャットダウン時に ZooKeeper が確実に終了処理されるようにしました (ごくまれにシャットダウン時にハングする可能性があった問題を修正) 。[#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat)).
