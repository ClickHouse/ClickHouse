  ### ClickHouse リリース v25.6.4.12-stable (c3c91c0239e) FIXME (v25.6.3.116-stable (3c68d19c3b3) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#83635](https://github.com/ClickHouse/ClickHouse/issues/83635) にバックポート: `distributed_ddl_output_mode='*_only_active'` の場合、`max_replication_lag_to_enqueue` を超えるレプリケーションラグがある新規または復旧したレプリカを待機しないようにしました。これにより、初期化または復旧の完了後に新しいレプリカがアクティブ化されたものの、初期化中に大量のレプリケーションログが蓄積していた場合に、`DDL task is not finished on some hosts` を回避しやすくなります。あわせて、レプリケーションログが `max_replication_lag_to_enqueue` 未満になるまで待機する `SYSTEM SYNC DATABASE REPLICA STRICT` クエリも実装しました。[#83302](https://github.com/ClickHouse/ClickHouse/pull/83302) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#83556](https://github.com/ClickHouse/ClickHouse/issues/83556) にバックポート: Iceberg の array 要素および Iceberg の map の値 (それらにネストされたすべてのサブフィールドを含む) に対する、境界値ベースのファイルプルーニングを無効化しました。[#83520](https://github.com/ClickHouse/ClickHouse/pull/83520) ([Daniil Ivanik](https://github.com/divanik))。
* [#83674](https://github.com/ClickHouse/ClickHouse/issues/83674) にバックポート: max&#95;untracked&#95;memory 周りのメモリ処理の不具合を修正しました。[#83607](https://github.com/ClickHouse/ClickHouse/pull/83607) ([Azat Khuzhin](https://github.com/azat))。
* [#83663](https://github.com/ClickHouse/ClickHouse/issues/83663) にバックポート: まれなケースで、UNION ALL を伴う INSERT SELECT により null ポインタの逆参照が発生する可能性がありました。これで [#83618](https://github.com/ClickHouse/ClickHouse/issues/83618) をクローズしました。[#83643](https://github.com/ClickHouse/ClickHouse/pull/83643) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#83745](https://github.com/ClickHouse/ClickHouse/issues/83745) にバックポート: block&#95;size&#95;bytes=0 の場合に estimateCompressionRatio() で無限ループが発生する不具合を修正しました。[#83704](https://github.com/ClickHouse/ClickHouse/pull/83704) ([Azat Khuzhin](https://github.com/azat))。
