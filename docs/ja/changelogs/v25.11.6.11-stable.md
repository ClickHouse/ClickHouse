  ### ClickHouse リリース v25.11.6.11-stable (90415175004) FIXME (v25.11.5.8-stable (06e6dea3bb5) との比較)
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#92312](https://github.com/ClickHouse/ClickHouse/issues/92312) でバックポート: Https://github.com/clickhouse/clickhouse/pull/84477 で、並列分散実行のために `insert select from s3cluster()` クエリで使用できる select クエリに関する制約が追加されました。この変更により、以前から可能だった where も使用できるようになりました。 [#84611](https://github.com/ClickHouse/ClickHouse/pull/84611) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="improvement">
  #### 改善
</div>

* [#93375](https://github.com/ClickHouse/ClickHouse/issues/93375) でバックポート: Azure Blob Storage でネイティブコピーが BadRequest で失敗した場合 (例: 無効なブロックリスト) 、read-write コピーにフォールバックするようにしました。従来は、異なるストレージアカウント間でブロブをコピーする際に発生していた `Unauthorized` エラーに対してのみこの処理を行っていました。しかし、&quot;The specified block list is invalid&quot; エラーが発生することもあります。そのため、現在はネイティブコピーが失敗した場合はすべて read &amp; write にフォールバックするよう条件を更新しました。[#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#93336](https://github.com/ClickHouse/ClickHouse/issues/93336) でバックポート: `flipCoordinates` でジオメトリ型をサポートしました。[#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#93123](https://github.com/ClickHouse/ClickHouse/issues/93123)でバックポート: ワイルドカード grant に対するアクセス権チェックの誤ったロジックを見直しました。以前の試みである [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) では重大な脆弱性に対処していましたが、制限が厳しすぎたため、無関係な権限取り消しによって一部のワイルドカード `GRANT` ステートメントが失敗するようになっていました。 [#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* [#93222](https://github.com/ClickHouse/ClickHouse/issues/93222)でバックポート: JSON のパス &#39;skip&#39; に対する type hint の作成を修正しました。 [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731) をクローズしました。 [#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93182](https://github.com/ClickHouse/ClickHouse/issues/93182)でバックポート: `ratio_of_defaults_for_sparse_serialization` の設定を ALTER で `1.0` に変更した場合に、スパースなカラムのミューテーション後に `FILE_DOESNT_EXIST` エラーが発生する可能性がある問題を修正しました。 [#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).
* [#93046](https://github.com/ClickHouse/ClickHouse/issues/93046)でバックポート: WHERE で `not materialize(...)` または `not CAST(...)` を使用した際に誤った結果を引き起こす、データスキッピングロジックのバグを修正しました。 [#88536](https://github.com/ClickHouse/ClickHouse/issues/88536) をクローズしました。 [#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#93057](https://github.com/ClickHouse/ClickHouse/issues/93057)でバックポート: 分散クエリの事前キャンセル後に接続が壊れた状態のままになる問題を修正しました。 [#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)).
* [#93311](https://github.com/ClickHouse/ClickHouse/issues/93311)でバックポート: マージ中にプロジェクションが再構築される際、未使用のカラムを削除するようにしました。これによりメモリ使用量が減少し、一時的なパーツの作成数も少なくなります。 [#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
