<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#108866](https://github.com/ClickHouse/ClickHouse/issues/108866) でバックポート: 循環依存を持つテーブルを含むバックアップの `RESTORE` 中にサーバーが異常終了する不具合を修正しました。[#103824](https://github.com/ClickHouse/ClickHouse/pull/103824) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#108847](https://github.com/ClickHouse/ClickHouse/issues/108847) でバックポート: インクリメンタルバックアップが、`.backup` メタデータファイルの `<base_backup>` ロケーターに `S3` の認証情報を保存しないようになりました。`use_same_s3_credentials_for_base_backup = 1` を指定して作成されたバックアップ、またはこのバックアップロケーターと一致する明示的な base backup の認証情報を使って作成されたバックアップでは、secret ではない marker が保存され、復元時に追加の設定なしで復元できます。異なる明示的な base backup の認証情報、または追加の base authentication 引数を使って作成されたバックアップについては、それらを `base_backup` setting とともに `RESTORE` に渡してください。古いバージョンで認証情報を埋め込んで作成されたバックアップも引き続き復元可能です。[#107357](https://github.com/ClickHouse/ClickHouse/pull/107357) ([Pablo Marcos](https://github.com/pamarcos)).
* [#107889](https://github.com/ClickHouse/ClickHouse/issues/107889) でバックポート: `MySQL Connector/J` 8.2.0 以降 (9.x を含む) で MySQL インターフェイスを使用できない不具合を修正しました。`OK` パケットの `info` フィールドは MySQL server と同様に length-encoded されるようになり、JDBC driver が接続できるようになりました。[#107693](https://github.com/ClickHouse/ClickHouse/pull/107693) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#108763](https://github.com/ClickHouse/ClickHouse/issues/108763) でバックポート: `ssl_certificate` による user 識別を修正し、単一の `*` ワイルドカードが名前の 1 つの部分にのみ一致するようにしました (RFC 6125 6.4.3) 。従来は、`CN` または `DNS:` SAN subject 内のワイルドカード (たとえば `*.corp.example.com`) が `evil.deep.corp.example.com` のような複数ラベルの名前にも一致していたため、より深い subdomain 用の certificate を持つユーザーが wildcard user として authentication できていました。`URI:` SAN の一致動作は変わりません。[#108472](https://github.com/ClickHouse/ClickHouse/pull/108472) ([Groene AI](https://github.com/groeneai)).
* [#108896](https://github.com/ClickHouse/ClickHouse/issues/108896) でバックポート: `max_parser_depth` が大きな値に設定されている場合に、`[[[ ... ]]]` や &#96;array(array( ... ))&#96;&#96; のような深くネストした expression によって発生するサーバークラッシュ (stack overflow) を修正しました。[#108493](https://github.com/ClickHouse/ClickHouse/pull/108493) ([Raúl Marín](https://github.com/Algunenano)).
* [#109141](https://github.com/ClickHouse/ClickHouse/issues/109141) でバックポート: `GROUPING SETS`、`ROLLUP`、`CUBE` と `max_threads > 1` を使用して `uniqExact` aggregate states を merge する際に発生する segmentation fault を修正しました。[#108928](https://github.com/ClickHouse/ClickHouse/pull/108928) ([Raúl Marín](https://github.com/Algunenano)).
