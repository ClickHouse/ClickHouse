<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#88511](https://github.com/ClickHouse/ClickHouse/issues/88511) でバックポート: Nullable の内部に配置できない Variant から、null の map subcolumn を読み取る際の不具合を修正しました。 [#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar)).
* [#88734](https://github.com/ClickHouse/ClickHouse/issues/88734) でバックポート: `Poco::Net::HTTPChunkedStreamBuf::readFromDevice` からスローされる `Poco::TimeoutException` 例外によって SIGABRT でクラッシュする問題を修正しました。 [#88668](https://github.com/ClickHouse/ClickHouse/pull/88668) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#88908](https://github.com/ClickHouse/ClickHouse/issues/88908) でバックポート: 復旧後、Replicated database のレプリカが `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)` のようなメッセージを出力し続け、長時間スタックすることがある問題を修正しました。 [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#88892](https://github.com/ClickHouse/ClickHouse/issues/88892) でバックポート: `loop` table function に対する SELECT 時のアクセス検証を修正しました。 [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* [#88942](https://github.com/ClickHouse/ClickHouse/issues/88942) でバックポート: 関数 `reverseUTF8` の不具合を修正しました。以前のバージョンでは、長さ 4 の UTF-8 code point のバイト列を誤って逆順にしていました。これにより [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913) をクローズします。 [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#88978](https://github.com/ClickHouse/ClickHouse/issues/88978) でバックポート: SQL SECURITY DEFINER を指定してビューを作成する際に、アクセス権 `SET DEFINER <current_user>:definer` を確認しないようにしました。 [#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit)).
* [#89083](https://github.com/ClickHouse/ClickHouse/issues/89083) でバックポート: これにより [#88081](https://github.com/ClickHouse/ClickHouse/issues/88081) をクローズします。 [#88988](https://github.com/ClickHouse/ClickHouse/pull/88988) ([scanhex12](https://github.com/scanhex12)).
* [#89026](https://github.com/ClickHouse/ClickHouse/issues/89026) でバックポート: skipping indexes の解析におけるパフォーマンス低下を修正しました。 [#89004](https://github.com/ClickHouse/ClickHouse/pull/89004) ([Anton Popov](https://github.com/CurtizJ)).
