<div id="new-feature">
  #### 新機能
</div>

* [#104161](https://github.com/ClickHouse/ClickHouse/issues/104161) でバックポート: リフレッシャブルmaterialized view向けに、`SYSTEM PAUSE VIEW [db.]name` および `SYSTEM PAUSE VIEWS` クエリが追加されました。`SYSTEM STOP VIEW` とは異なり、`SYSTEM PAUSE VIEW` は現在実行中のリフレッシュを中断しません。進行中のリフレッシュは完了まで続行され、その後のリフレッシュのみが抑止されます。これは `SYSTEM START VIEW` または `SYSTEM START VIEWS` で解除され、これらは停止状態と一時停止状態の両方を一律にクリアするようになりました。[#103252](https://github.com/ClickHouse/ClickHouse/pull/103252) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#104199](https://github.com/ClickHouse/ClickHouse/issues/104199) でバックポート: SummingMergeTree および CoalescingMergeTree のマージ中に、`MEMORY_LIMIT_EXCEEDED` 例外が誤って `CORRUPTED_DATA` として報告される不具合を修正しました。[#97537](https://github.com/ClickHouse/ClickHouse/pull/97537) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#104149](https://github.com/ClickHouse/ClickHouse/issues/104149) でバックポート: row policies/additional&#95;table&#95;filters 使用時の trivial LIMIT 最適化を無効化しました (並列索引解析を可能にするため) 。[#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* [#103827](https://github.com/ClickHouse/ClickHouse/issues/103827) でバックポート: 集約プロジェクションがクエリに一致し、かつテーブルの一部のパーツにプロジェクションデータがない場合 (たとえば、すでにデータがあるテーブルにプロジェクションを追加したものの、`MATERIALIZE PROJECTION` を実行していない場合) に、`SELECT DISTINCT` が不完全な結果を返してもエラーにならない不具合を修正しました。[#102951](https://github.com/ClickHouse/ClickHouse/issues/102951) をクローズしました。[#103052](https://github.com/ClickHouse/ClickHouse/pull/103052) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#104196](https://github.com/ClickHouse/ClickHouse/issues/104196) でバックポート: pre-25.12 の deserialize+serialize サイクルによって永続化された `alpha_size` が増大していた `AggregateFunction(topK(N), String)` カラムの読み取り時に、`SIZES_OF_ARRAYS_DONT_MATCH` が発生する不具合を修正しました。[#104002](https://github.com/ClickHouse/ClickHouse/pull/104002) ([Raúl Marín](https://github.com/Algunenano)).
* [#104191](https://github.com/ClickHouse/ClickHouse/issues/104191) でバックポート: `quantileTiming` state のデシリアライズ中に境界外書き込みが発生する不具合を修正しました。[#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
