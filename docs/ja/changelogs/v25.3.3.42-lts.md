  ### ClickHouse リリース v25.3.3.42-lts (c4bfe68b052) FIXME (v25.3.2.39-lts (3ec1fd3f690) との比較)

<div id="improvement">
  #### 改善
</div>

* [#78899](https://github.com/ClickHouse/ClickHouse/issues/78899) でバックポート: `BFloat16` に対する `IN` 句の型変換を修正 (つまり、`SELECT toBFloat16(1) IN [1, 2, 3];` は `1` を返すようになりました) 。[#78754](https://github.com/ClickHouse/ClickHouse/issues/78754) をクローズ。[#78839](https://github.com/ClickHouse/ClickHouse/pull/78839) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#79137](https://github.com/ClickHouse/ClickHouse/issues/79137) でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/78637](https://github.com/ClickHouse/ClickHouse/pull/78637) と同様に、`recoverLostReplica` 実行時に設定を削除するよう修正。[#79113](https://github.com/ClickHouse/ClickHouse/pull/79113) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#78790](https://github.com/ClickHouse/ClickHouse/issues/78790) にバックポート: アナライザで、リテラルを含む式に対するスキップ索引が機能しない問題を修正し、索引の解析中に不要な CAST を削除しました。 [#77229](https://github.com/ClickHouse/ClickHouse/pull/77229) ([Pavel Kruglov](https://github.com/Avogar)).
* [#79285](https://github.com/ClickHouse/ClickHouse/issues/79285) にバックポート: 新しく追加されたレプリカで Replicated database のリフレッシャブルmaterialized view が動作しない問題を修正しました。 [#77774](https://github.com/ClickHouse/ClickHouse/pull/77774) ([Michael Kolupaev](https://github.com/al13n321)).
* [#78438](https://github.com/ClickHouse/ClickHouse/issues/78438) にバックポート: ALTER クエリの直後に RENAME クエリが実行された場合に発生する可能性があった、Database Replicated でのメタデータ override を修正しました。 [#78107](https://github.com/ClickHouse/ClickHouse/pull/78107) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#78547](https://github.com/ClickHouse/ClickHouse/issues/78547) にバックポート: azure access signature がユーザーや logs から見えないようにマスクしました。 [#78189](https://github.com/ClickHouse/ClickHouse/pull/78189) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#78528](https://github.com/ClickHouse/ClickHouse/issues/78528) にバックポート: wide パーツ内で、プレフィックス付き substream の prefetch を修正しました。 [#78205](https://github.com/ClickHouse/ClickHouse/pull/78205) ([Pavel Kruglov](https://github.com/Avogar)).
* [#78952](https://github.com/ClickHouse/ClickHouse/issues/78952) にバックポート: レプリカの `disable_insertion_and_mutation` が true の場合、RefreshMV task を schedule しないようにしました。task は insertion を伴うため、`disable_insertion_and_mutation` が true の場合は Failed します。 [#78277](https://github.com/ClickHouse/ClickHouse/pull/78277) ([Xu Jia](https://github.com/XuJia0210)).
* [#78979](https://github.com/ClickHouse/ClickHouse/issues/78979) にバックポート: Merge engine で基になるテーブルへのアクセスを検証するようにしました。 [#78339](https://github.com/ClickHouse/ClickHouse/pull/78339) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* [#78649](https://github.com/ClickHouse/ClickHouse/issues/78649) にバックポート: `Distributed` engine table で FINAL modifier が失われることがある問題を修正しました。 [#78428](https://github.com/ClickHouse/ClickHouse/pull/78428) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#78534](https://github.com/ClickHouse/ClickHouse/issues/78534) にバックポート: クラッシュを引き起こす可能性があるため、&quot;Apply preserve&#95;most attribute at some places in code&quot; を元に戻しました。 [#78449](https://github.com/ClickHouse/ClickHouse/pull/78449) ([Azat Khuzhin](https://github.com/azat)).
* [#78760](https://github.com/ClickHouse/ClickHouse/issues/78760) にバックポート: `max_streams_to_max_threads_ratio` setting の適用後に planned stream が 0 になる場合でも、読み取り用に少なくとも 1 つの stream を確保するようにしました。 [#78505](https://github.com/ClickHouse/ClickHouse/pull/78505) ([Eduard Karacharov](https://github.com/korowa)).
* [#78614](https://github.com/ClickHouse/ClickHouse/issues/78614) にバックポート: cgroups v1 と v2 の両方が有効なシステムで、ClickHouse が自身の cgroup v2 を判別できるようになりました。 [#78566](https://github.com/ClickHouse/ClickHouse/pull/78566) ([Grigory Korolev](https://github.com/gkorolev)).
* [#78772](https://github.com/ClickHouse/ClickHouse/issues/78772) にバックポート: ObjectStorage cluster table functions は、table level-settings と組み合わせて使用すると Failed していました。 [#78587](https://github.com/ClickHouse/ClickHouse/pull/78587) ([Daniil Ivanik](https://github.com/divanik)).
* [#78685](https://github.com/ClickHouse/ClickHouse/issues/78685) にバックポート: attach 時にクエリ設定を削除。 [#78637](https://github.com/ClickHouse/ClickHouse/pull/78637) ([Raúl Marín](https://github.com/Algunenano)).
* [#78945](https://github.com/ClickHouse/ClickHouse/issues/78945) にバックポート: 不正なシャットダウン後に ALTER を行った場合に REFRESHABLE MV がクラッシュする問題を修正。 [#78858](https://github.com/ClickHouse/ClickHouse/pull/78858) ([Azat Khuzhin](https://github.com/azat)).
* [#79272](https://github.com/ClickHouse/ClickHouse/issues/79272) にバックポート: Keeper の修正: 失敗したマルチリクエストでウォッチがトリガーされるのを防止。 [#79247](https://github.com/ClickHouse/ClickHouse/pull/79247) ([Antonio Andelic](https://github.com/antonio2368)).
