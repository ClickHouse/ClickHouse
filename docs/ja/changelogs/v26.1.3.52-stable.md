<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#96316](https://github.com/ClickHouse/ClickHouse/issues/96316) にバックポート: SQL Security を持つ VIEW に対する `ATTACH` クエリで、不要な権限チェックのスキップを削除しました。これにより、ユーザーが必要なアクセス権を検証しないまま definer 付きの VIEW を attach した場合に起こり得る権限昇格を防止します。[#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit))。
* [#95806](https://github.com/ClickHouse/ClickHouse/issues/95806) にバックポート: 複数の join を `USING` clause とともに使用した場合の、source table の修飾付きカラムに対する type inference を修正しました。以前は、そのカラムがその join に関与していない場合でも、後続の join によって元の source column の型が誤って common supertype に更新されていました (たとえば `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` では、`t2.a` カラムが使われるのは最初の join だけなので、その型は `t1.a` と `t2.a` の supertype であるべきで、`t3.a` は含まれません) 。この問題により、関数が実際の実行計画に現れるものとは異なるカラム型を想定してしまい、論理エラーやクラッシュにつながる可能性がありました。[#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir))。
* [#96396](https://github.com/ClickHouse/ClickHouse/issues/96396) にバックポート: distributed queries で負の `LIMIT/OFFSET` を使用した場合に、一部のケースで発生する論理エラーを修正しました。[#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp))。
* [#96222](https://github.com/ClickHouse/ClickHouse/issues/96222) にバックポート: JSON の配列に `tupleElement` を適用した際のクラッシュを修正しました。[#95581](https://github.com/ClickHouse/ClickHouse/issues/95581) をクローズしました。[#95647](https://github.com/ClickHouse/ClickHouse/pull/95647) ([Pavel Kruglov](https://github.com/Avogar))。
* [#95825](https://github.com/ClickHouse/ClickHouse/issues/95825) にバックポート: パーティション化された Delta Lake データをまとめる処理を修正しました。[#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#95852](https://github.com/ClickHouse/ClickHouse/issues/95852) にバックポート: runtime filters における Nullable join カラムの race condition を修正しました。[#95775](https://github.com/ClickHouse/ClickHouse/pull/95775) ([Hechem Selmi](https://github.com/m-selmi))。
* [#97187](https://github.com/ClickHouse/ClickHouse/issues/97187) にバックポート: ネストされたパスを持つ JSON に対して `tupleElement` を実行した際の問題を修正しました。以前は、誤った query result につながる可能性がありました。[#95907](https://github.com/ClickHouse/ClickHouse/pull/95907) ([Pavel Kruglov](https://github.com/Avogar))。

* [#95993](https://github.com/ClickHouse/ClickHouse/issues/95993) にバックポート: system.asynchronous&#95;metric&#95;log の event&#95;date を修正しました。[#95947](https://github.com/ClickHouse/ClickHouse/pull/95947) ([Raúl Marín](https://github.com/Algunenano))。
* [#96215](https://github.com/ClickHouse/ClickHouse/issues/96215) にバックポート: JSON data type におけるパスのスキップを修正しました。以前は `JSON(SKIP path)` を使用すると、プレフィックス `path` を持つすべての JSON キーがスキップされ、`"pathpath"` のようなキーまで対象になっていたため、insert 時にこれらのパスのデータが失われる可能性がありました。現在は修正され、キー `"path"` のみがスキップされます。[#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar))。
