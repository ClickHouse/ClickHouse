<div id="clickhouse-release-v248741-lts-e28553d4f2b-fixme-as-compared-to-v248670-lts-ddb8c219771">
  ### ClickHouse リリース v24.8.7.41-lts (e28553d4f2b) FIXME (v24.8.6.70-lts (ddb8c219771) と比較して)
</div>

<div id="improvement">
  #### 改善
</div>

* [#71713](https://github.com/ClickHouse/ClickHouse/issues/71713)でバックポート: clickhouse イメージのエントリポイントで、CLICKHOUSE&#95;PASSWORD が XML 用にエスケープされるようになりました。[#69301](https://github.com/ClickHouse/ClickHouse/pull/69301) ([aohoyd](https://github.com/aohoyd)).
* [#71666](https://github.com/ClickHouse/ClickHouse/issues/71666)でバックポート: user/group が ID として指定されている場合、`clickhouse su` が失敗します。この修正により、`UID:GID` も受け付けるようになりました。 ### ユーザー向け変更のドキュメント項目。 [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#71936](https://github.com/ClickHouse/ClickHouse/issues/71936)でバックポート: `history` 期間内に `HostResolver` を 3 回更新します。[#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#71486](https://github.com/ClickHouse/ClickHouse/issues/71486) でバックポート: 一部の圧縮レスポンスで `Content-Encoding` が送信されない問題を修正しました。[#64802](https://github.com/ClickHouse/ClickHouse/issues/64802)。 [#68975](https://github.com/ClickHouse/ClickHouse/pull/68975) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#71462](https://github.com/ClickHouse/ClickHouse/issues/71462) でバックポート: named collections で不足していたアンエスケープ処理を追加しました。この修正がないと clickhouse-server は起動できません。[#71308](https://github.com/ClickHouse/ClickHouse/pull/71308) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#71747](https://github.com/ClickHouse/ClickHouse/issues/71747) でバックポート: JSON 型ヒント内の疑わしい型および Experimental な型をチェックするようにしました。[#71369](https://github.com/ClickHouse/ClickHouse/pull/71369) ([Pavel Kruglov](https://github.com/Avogar)).
* [#71604](https://github.com/ClickHouse/ClickHouse/issues/71604) でバックポート: Variant カラムを含む Chunk で `Invalid number of rows` エラーが発生する問題を修正しました。[#71388](https://github.com/ClickHouse/ClickHouse/pull/71388) ([Pavel Kruglov](https://github.com/Avogar)).
* [#71826](https://github.com/ClickHouse/ClickHouse/issues/71826) でバックポート: optimize&#95;rewrite&#95;array&#95;exists&#95;to&#95;has によるクラッシュを修正しました。[#71432](https://github.com/ClickHouse/ClickHouse/pull/71432) ([Raúl Marín](https://github.com/Algunenano)).
* [#71517](https://github.com/ClickHouse/ClickHouse/issues/71517) でバックポート: arrayJoin が見かけ上 `WHERE` 条件に現れる場合に、`Argument for function must be constant` エラー (旧アナライザ) が発生する可能性がある問題を修正しました。 [https://github.com/ClickHouse/ClickHouse/pull/65414](https://github.com/ClickHouse/ClickHouse/pull/65414) 後のリグレッションです。 [#71476](https://github.com/ClickHouse/ClickHouse/pull/71476) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#71551](https://github.com/ClickHouse/ClickHouse/issues/71551) でバックポート: カラムが 0 個の SortCursor でクラッシュしないようにしました (旧アナライザ) 。 [#71494](https://github.com/ClickHouse/ClickHouse/pull/71494) ([Raúl Marín](https://github.com/Algunenano)).
* [#71614](https://github.com/ClickHouse/ClickHouse/issues/71614) でバックポート: materialized view 内のクエリで CTE を使った IN を使用する場合のアナライザの問題を修正しました。 [#65598](https://github.com/ClickHouse/ClickHouse/issues/65598) をクローズします。 [#71538](https://github.com/ClickHouse/ClickHouse/pull/71538) ([Maksim Kita](https://github.com/kitaisreal)).
* [#71566](https://github.com/ClickHouse/ClickHouse/issues/71566) でバックポート: 制約で UDF を使用した場合のクラッシュを回避しました。 [#71541](https://github.com/ClickHouse/ClickHouse/pull/71541) ([Raúl Marín](https://github.com/Algunenano)).
* [#71727](https://github.com/ClickHouse/ClickHouse/issues/71727) でバックポート: bitShift 関数で範囲外の場合、エラーをスローする代わりに 0 またはデフォルト文字を返すようにしました。 [#71580](https://github.com/ClickHouse/ClickHouse/pull/71580) ([Pablo Marcos](https://github.com/pamarcos)).
* [#71876](https://github.com/ClickHouse/ClickHouse/issues/71876) でバックポート: 空の Tuple で ALTER を実行した際の LOGICAL&#95;ERROR を修正しました。これにより [#71647](https://github.com/ClickHouse/ClickHouse/issues/71647) も修正されます。 [#71679](https://github.com/ClickHouse/ClickHouse/pull/71679) ([Amos Bird](https://github.com/amosbird)).
* [#71737](https://github.com/ClickHouse/ClickHouse/issues/71737) でバックポート: パーティションカラムに対する述語で NOT IN 演算子を使用する場合、定数集合を変換しないようにしました。[#71695](https://github.com/ClickHouse/ClickHouse/pull/71695) ([Eduard Karacharov](https://github.com/korowa)).
* [#72002](https://github.com/ClickHouse/ClickHouse/issues/72002) でバックポート: clickhouse-client の構文ハイライトで発生するクラッシュを修正しました。[#71864](https://github.com/ClickHouse/ClickHouse/issues/71864) をクローズしました。[#71949](https://github.com/ClickHouse/ClickHouse/pull/71949) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#71690](https://github.com/ClickHouse/ClickHouse/issues/71690)でバックポート: clickhouse-server の Dockerfile.ubuntu を改善。`CLICKHOUSE_UID/CLICKHOUSE_GID` 環境変数を非推奨化。要件に準拠するため、`CLICKHOUSE_DOCKER_RESTART_ON_EXIT` の処理を削除。ある箇所ではそのまま、別の箇所では `/usr/bin/clickhouse*` となっていた不整合をなくすため、`clickhouse/clickhouse-server/clickhouse-keeper` の実行形式を統一。[#71573](https://github.com/ClickHouse/ClickHouse/pull/71573) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
