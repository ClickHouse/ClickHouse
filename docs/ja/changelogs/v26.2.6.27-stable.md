* [#100070](https://github.com/ClickHouse/ClickHouse/issues/100070) でバックポート: オブジェクトストレージ (S3、Azure など) のファイル一覧取得および読み取りパイプラインを内部診断できるように、`ObjectStorageListedObjects`、`ObjectStorageGlobFilteredObjects`、`ObjectStoragePredicateFilteredObjects`、`ObjectStorageReadObjects` の ProfileEvents を追加しました。[#99778](https://github.com/ClickHouse/ClickHouse/pull/99778) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#100460](https://github.com/ClickHouse/ClickHouse/issues/100460) でバックポート: JDBC、ODBC、NATS の接続文字列に含まれる認証情報は、クエリログと `SHOW CREATE` の出力でマスクされるようになり、機密情報が意図せず漏洩するのを防ぎます。URI 形式の接続文字列 (例: {scheme}://{user}:{password}@{host}) では、パスワード部分のみがマスクされ、それ以外の部分はデバッグしやすいように表示されたままになります。`nats_token` 設定もマスクされるようになりました。 [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#100082](https://github.com/ClickHouse/ClickHouse/issues/100082) でバックポート: アナライザ以外で `TABLE&#95;UUID&#95;MISMATCH` が無視される問題を修正。 [#99380](https://github.com/ClickHouse/ClickHouse/pull/99380) ([Azat Khuzhin](https://github.com/azat)).
* [#100060](https://github.com/ClickHouse/ClickHouse/issues/100060) でバックポート: 25.10 からそれ以降のバージョンへ、暗黙的な minmax 索引を持つレプリケートテーブルをアップグレードする際の互換性の問題を修正。 [#99392](https://github.com/ClickHouse/ClickHouse/pull/99392) ([Raúl Marín](https://github.com/Algunenano)).
* [#100317](https://github.com/ClickHouse/ClickHouse/issues/100317) でバックポート: テキスト索引解析における否定関数 (`notEquals`、`notLike`、`notIn`) のサポートを削除。これらの関数ではグラニュールを一切スキップできなかったため、それらに対する索引解析は利点がなく、オーバーヘッドを増やすだけでした。 [#99393](https://github.com/ClickHouse/ClickHouse/pull/99393) ([Anton Popov](https://github.com/CurtizJ)).
* [#100106](https://github.com/ClickHouse/ClickHouse/issues/100106) でバックポート: `DETACH/ATTACH TABLE` クエリの後、まれにデータパートが破損として誤ってマークされ、デタッチされる問題を修正。 [#99529](https://github.com/ClickHouse/ClickHouse/pull/99529) ([Anton Popov](https://github.com/CurtizJ)).
* [#100358](https://github.com/ClickHouse/ClickHouse/issues/100358) でバックポート: `toYYYYMM(date)` でパーティション化されたテーブルで、`WHERE toWeek(date, mode) = N` を含むクエリが第 49〜52 週で空の結果を返していた、`toWeek()` の誤ったパーティションプルーニングを修正。 [#99542](https://github.com/ClickHouse/ClickHouse/pull/99542) ([Takumi Hara](https://github.com/takumihara)).
* [#99750](https://github.com/ClickHouse/ClickHouse/issues/99750) でバックポート: ローカルファイルから Google の認証情報を読み取ることを禁止。この設定は、ファイルパスが分かっている場合に他の認証情報まで読み取れてしまうため、安全ではありません。 [#99584](https://github.com/ClickHouse/ClickHouse/pull/99584) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#100316](https://github.com/ClickHouse/ClickHouse/issues/100316) でバックポート: プリプロセッサを使用するテキスト索引による、`IN` 関数を含む述語の解析を修正。あわせて、テキスト索引内で検索対象トークンが衝突し、不正確な結果につながる可能性がある問題も修正しました。 [#99755](https://github.com/ClickHouse/ClickHouse/pull/99755) ([Anton Popov](https://github.com/CurtizJ)).
* [#100099](https://github.com/ClickHouse/ClickHouse/issues/100099) でバックポート: `NumericIndexedVector` の集約状態に偶数の整数定数を乗算した際に発生するアサーション失敗 (debug builds では例外、release builds では不正確な結果) を修正。この問題は、`pointwiseAddInplace` におけるエイリアスされた Roaring bitmap への自己 XOR が原因でした。 [#99976](https://github.com/ClickHouse/ClickHouse/pull/99976) ([Desel72](https://github.com/Desel72)).
* [#100285](https://github.com/ClickHouse/ClickHouse/issues/100285) でバックポート: 部分文字列マッチングをサポートしないトークナイザー (`array`、`splitByString`) で、`startsWith` および `endsWith` 関数に対してテキスト索引が誤って使われる問題を修正。以前は、これらのトークナイザーで誤った結果が黙って生成され、一致する行を含むグラニュールを索引がスキップしてしまう可能性がありました。 [#100151](https://github.com/ClickHouse/ClickHouse/pull/100151) ([Anton Popov](https://github.com/CurtizJ)).
* [#100267](https://github.com/ClickHouse/ClickHouse/issues/100267) でバックポート: テキスト索引の構築中に &quot;Memory Limit&quot; 例外がスローされた場合に発生する、まれなクラッシュを修正。 [#100213](https://github.com/ClickHouse/ClickHouse/pull/100213) ([Anton Popov](https://github.com/CurtizJ)).
* [#100258](https://github.com/ClickHouse/ClickHouse/issues/100258) でバックポート: `IN` 句を含む述語に対し、`mapValues` 上に構築されたテキスト索引の解析中に発生していた &quot;Not-ready Set is passed as the second argument&quot; エラーを修正しました。[#100224](https://github.com/ClickHouse/ClickHouse/pull/100224) ([Anton Popov](https://github.com/CurtizJ))。
* [#100344](https://github.com/ClickHouse/ClickHouse/issues/100344) でバックポート: `Dynamic` カラムを含み、cross joins とランタイムフィルタを伴うクエリで発生していた `LOGICAL_ERROR` 例外を修正しました。原因は、`hasOnlyNulls` 最適化パスで `ColumnVariant::filter` が variant column のポインタを複製せず共有していたことです。[https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147) をクローズします。[#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar))。
* [#100553](https://github.com/ClickHouse/ClickHouse/issues/100553) でバックポート: `delta_lake_snapshot_start_version` を設定せずに `delta_lake_snapshot_end_version` を設定した場合、本来は `BAD_ARGUMENTS` エラーを返すべきところ、何も通知せず無視していたコピー＆ペースト由来のバグを修正しました。[#100454](https://github.com/ClickHouse/ClickHouse/pull/100454) ([Mohammad Lareb Zafar](https://github.com/zlareb1))。
* [#100596](https://github.com/ClickHouse/ClickHouse/issues/100596) でバックポート: `optimize_on_insert=0` の wide parts で、ネストした `Array(JSON)` カラムを持つテーブルへの挿入時に発生する LOGICAL&#95;ERROR 例外 &quot;Stream ... not found&quot; を修正しました。[#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar))。
* [#100889](https://github.com/ClickHouse/ClickHouse/issues/100889) でバックポート: バックアップ メタデータ内のファイルエントリのパスを検証し、`RESTORE` 中に path traversal、絶対パス、および空の名前を拒否するようにしました。[#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos))。
* [#100638](https://github.com/ClickHouse/ClickHouse/issues/100638) でバックポート: `ALTER MODIFY COLUMN` によってカラムが非-Tuple 型から Tuple に変更された後のパーツのマージ中に、`SerializationInfoTuple::add` が通常の `SerializationInfo` 参照に対して `assert_cast` を実行してしまうことで発生していた segfault を修正しました。[#100509](https://github.com/ClickHouse/ClickHouse/pull/100509) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
* [#100727](https://github.com/ClickHouse/ClickHouse/issues/100727) でバックポート: projection の SELECT 部分に、クエリの元の SELECT 部分には存在しないカラムが含まれている場合に発生する NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK を修正しました。[#100194](https://github.com/ClickHouse/ClickHouse/issues/100194) をクローズします。[#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* [#100865](https://github.com/ClickHouse/ClickHouse/issues/100865) でバックポート: `Nullable(Tuple)` の導入後、戻り値の型が `Tuple` で、1 つ以上の `Nullable` 引数を持つ `If`、`Distinct`、`DistinctIf`、`IfState ` 集約関数コンビネータが、古いシリアライズ済み状態を読み取れなくなっていた問題を修正しました。[#98917](https://github.com/ClickHouse/ClickHouse/issues/98917) をクローズします。[#100826](https://github.com/ClickHouse/ClickHouse/pull/100826) ([Nihal Z. Miaji](https://github.com/nihalzp))。
