<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#104160](https://github.com/ClickHouse/ClickHouse/issues/104160)でバックポート: キャッシュが無効な場合 (サーバー設定 `index_uncompressed_cache_size = 0`、これがデフォルト値) に、インデックス非圧縮キャッシュのオーバーヘッドを回避しました。[#104063](https://github.com/ClickHouse/ClickHouse/pull/104063) ([Michael Kolupaev](https://github.com/al13n321)) 。

<div id="improvement">
  #### 改善
</div>

* [#104213](https://github.com/ClickHouse/ClickHouse/issues/104213)でバックポート: 識別子とリテラルをランダム化されたプレースホルダーに置き換えつつ、クエリの構造を保ったままSQLクエリ文字列を難読化するSQL関数 `obfuscateQuery` および `obfuscateQueryWithSeed` を追加しました。短い識別子や大きすぎる整数リテラルに対するクエリ難読化の境界ケースも修正しました。[#101027](https://github.com/ClickHouse/ClickHouse/pull/101027) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#104224](https://github.com/ClickHouse/ClickHouse/issues/104224)でバックポート: `MATERIALIZED` CTEを含むクエリの実行時に発生するメモリリークを修正しました。[#104153](https://github.com/ClickHouse/ClickHouse/pull/104153) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#104211](https://github.com/ClickHouse/ClickHouse/issues/104211)でバックポート: ストリームの割り当てに失敗した際に `MergeTreeDataPartWriterCompact::cancel` で発生する未定義の動作を修正しました。[#101292](https://github.com/ClickHouse/ClickHouse/pull/101292) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#104151](https://github.com/ClickHouse/ClickHouse/issues/104151)でバックポート: row policies/additional&#95;table&#95;filters 使用時の自明な LIMIT 最適化を無効化しました (並列の索引解析を可能にするため) 。[#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* [#104244](https://github.com/ClickHouse/ClickHouse/issues/104244)でバックポート: 26.x で発生していたデータ整合性のリグレッションを修正しました。この問題では、JIT コンパイルされた `if` および `multiIf` で、結果型が `Decimal` であり、かつ一方の分岐に非 `Decimal` (整数または浮動小数点) の literal がある場合、`10^scale` 倍小さい値を黙って返していました。低速な (非 JIT) 経路には影響ありませんでした。影響を受けるバージョンでの回避策: `SET compile_expressions = 0`。[#103809](https://github.com/ClickHouse/ClickHouse/pull/103809) ([Groene AI](https://github.com/groeneai)).
* [#104147](https://github.com/ClickHouse/ClickHouse/issues/104147)でバックポート: 25.12 より前の deserialize+serialize cycle によって永続化された `alpha_size` が増加していた `AggregateFunction(topK(N), String)` カラムの読み取り時に発生する `SIZES_OF_ARRAYS_DONT_MATCH` を修正しました。[#104002](https://github.com/ClickHouse/ClickHouse/pull/104002) ([Raúl Marín](https://github.com/Algunenano)).
* [#104195](https://github.com/ClickHouse/ClickHouse/issues/104195)でバックポート: `quantileTiming` state の deserialize 中に発生する境界外書き込みを修正しました。[#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微

* [#104208](https://github.com/ClickHouse/ClickHouse/issues/104208) でバックポート: `obfuscateQuery` と `obfuscateQueryWithSeed` は、`clickhouse-format --obfuscate` の挙動に合わせて、組み込み関数、集約関数、テーブル関数、フォーマット、データ型、ストレージ、コーデック、および設定の名前を保持するようになりました。[#103843](https://github.com/ClickHouse/ClickHouse/pull/103843) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
