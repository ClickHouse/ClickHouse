<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#75642](https://github.com/ClickHouse/ClickHouse/issues/75642) でバックポート: わかりやすくするために、Docker init script の失敗ログメッセージを修正しました。 [#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* [#75118](https://github.com/ClickHouse/ClickHouse/issues/75118) でバックポート: interval の挿入時に発生するクラッシュを修正しました (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)) 。 [#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* [#75305](https://github.com/ClickHouse/ClickHouse/issues/75305) でバックポート: 型名が大文字でない場合に、JSON type 宣言のパース中に発生するクラッシュを修正しました。 [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* [#76228](https://github.com/ClickHouse/ClickHouse/issues/76228) でバックポート: PSQL レプリケーションで、キャッチされない例外により発生するクラッシュを修正しました。 [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* [#76245](https://github.com/ClickHouse/ClickHouse/issues/76245) でバックポート: Sasl はどの RPC 呼び出しでも失敗する可能性がありますが、この修正により、krb5 ticker の有効期限が切れている場合に呼び出しを再試行できるようになります。 [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* [#75403](https://github.com/ClickHouse/ClickHouse/issues/75403) でバックポート: 設定 `optimize_function_to_subcolumns` が有効な場合の、`Array`、`Map`、`Nullable(..)` カラムに対する索引 (プライマリおよびセカンダリ) の使用を修正しました。以前は、これらのカラムの索引が無視されることがありました。 [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* [#76102](https://github.com/ClickHouse/ClickHouse/issues/76102) でバックポート: LowCardinality の Nullable データ型に対する NULL 安全な JOIN 処理を修正しました。以前は、`IS NOT DISTINCT FROM`、`<=>`、`a IS NULL AND b IS NULL OR a == b` のような NULL 安全比較を含む `JOIN ON` が、LowCardinality カラムで正しく動作していませんでした。 [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#75566](https://github.com/ClickHouse/ClickHouse/issues/75566) でバックポート: Keeper 修正: ログのロールバック時に、破損した changelog へ書き込まないようにしました。 [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75742](https://github.com/ClickHouse/ClickHouse/issues/75742) でバックポート: Protobuf フォーマットでの出力と、並行して実行されるクエリ `SYSTEM DROP FORMAT SCHEMA CACHE` によって発生しうる protobuf schema cache のクラッシュを修正しました。 [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* [#76094](https://github.com/ClickHouse/ClickHouse/issues/76094) でバックポート: Array 型の JSON subcolumn を分散テーブル上の JOIN で使用した際に発生しうる `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes` エラーを修正しました。 [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75890](https://github.com/ClickHouse/ClickHouse/issues/75890) でバックポート: 異なる型のカラム間で複数の非同期 `RENAME` クエリ (`alter_sync = 0`) を実行した後、`MergeTree` テーブルの読み取り時にまれに発生していたクラッシュを修正しました。 [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* [#75831](https://github.com/ClickHouse/ClickHouse/issues/75831) でバックポート: `DistinctSortedStreamTransform` におけるヌルポインタの逆参照を修正しました。[#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* [#76215](https://github.com/ClickHouse/ClickHouse/issues/76215) でバックポート: `clickhouse-library-bridge` はファイルシステム上の任意のライブラリを開くことができるため、安全に実行できるのは隔離された環境内に限られます。`clickhouse-server` と同じ環境で実行された場合の脆弱性を防ぐため、ライブラリのパスを設定で指定された場所に制限します。この脆弱性は、**Arseniy Dugin** により [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて発見されました。[#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
