<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#101233](https://github.com/ClickHouse/ClickHouse/issues/101233) でバックポート: `query_log` とクライアント出力で `written_rows`、`read_rows`、`result_rows` が 0 と報告される非同期 INSERT クエリの問題を修正しました。[#99879](https://github.com/ClickHouse/ClickHouse/pull/99879) ([Sema Checherinda](https://github.com/CheSema)).
* [#100170](https://github.com/ClickHouse/ClickHouse/issues/100170) でバックポート: ... [#100024](https://github.com/ClickHouse/ClickHouse/pull/100024) ([Shaohua Wang](https://github.com/tiandiwonder)).
* [#100920](https://github.com/ClickHouse/ClickHouse/issues/100920) でバックポート: LowCardinality 要素を含む Tuple キーに対して、PREWHERE/WHERE で `has()` 関数を使用した際にサーバーがクラッシュする問題を修正しました。[#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* [#101185](https://github.com/ClickHouse/ClickHouse/issues/101185) でバックポート: サーバーのシャットダウン中に Dictionary を読み込む際、null ポインタの逆参照によって segfault が発生する問題を修正しました。`Context::getUserDefinedSQLObjectsStorage` (`user_defined_sql_objects_storage` を逆参照) が Dictionary のスレッドから呼び出される一方で、メインスレッドは `Context::shutdown` を呼び出して `user_defined_sql_objects_storage` を null に設定します。`Context::shutdown` を実行する前に、Dictionary ローダーで今後の更新を無効にし、現在実行中の Dictionary クエリを kill し、Dictionary 読み込みスレッドを join する必要があります。これは通常のクエリに対して行っている処理と同様です。[#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#101089](https://github.com/ClickHouse/ClickHouse/issues/101089) でバックポート: 入力に非 ASCII バイトが含まれる場合に発生する `ULIDStringToDateTime` の buffer overflow を修正しました。[#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101013](https://github.com/ClickHouse/ClickHouse/issues/101013) でバックポート: nullable な tuple の配列に対する `intDiv`/`intDivOrZero` で発生する例外を修正しました。例: `SELECT intDiv([divide((1, 2), ... AND NULL)], 2)`。[#100895](https://github.com/ClickHouse/ClickHouse/pull/100895) ([Raúl Marín](https://github.com/Algunenano)).
* [#101248](https://github.com/ClickHouse/ClickHouse/issues/101248) でバックポート: 定義を保存する前に `StorageAlias` の engine 引数を評価するようにし、`currentDatabase()` のような式がデータベースに保存される前にリテラルへ解決されるようにしました。[#100902](https://github.com/ClickHouse/ClickHouse/pull/100902) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#101124](https://github.com/ClickHouse/ClickHouse/issues/101124) でバックポート: tuple サブクエリを含む `IN` 句でテキスト検索索引を使用した際のクラッシュ、たとえば `WHERE (id, str) IN (SELECT (id, str) FROM ...)` のようなケースや、サブクエリ内のカラム数が `IN` の左辺の tuple と一致しない場合のクラッシュを修正しました。[#100959](https://github.com/ClickHouse/ClickHouse/pull/100959) ([Anton Popov](https://github.com/CurtizJ)).
* [#101078](https://github.com/ClickHouse/ClickHouse/issues/101078) でバックポート: `Nullable(Tuple)` の導入後、1 つ以上の `Nullable` 引数を持つ `sumCountOrDefault` aggregate function が古いシリアライズ済み state を読み取れなくなる問題を修正しました。[#100882](https://github.com/ClickHouse/ClickHouse/issues/100882) をクローズします。[#101021](https://github.com/ClickHouse/ClickHouse/pull/101021) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* [#101346](https://github.com/ClickHouse/ClickHouse/issues/101346) でバックポート: `list` と `read` の間にリモート object が上書きされることで object のメタデータが stale になり、その結果 cache から `Having zero bytes, ...` 論理エラーが発生しうる問題を修正しました。 [#101219](https://github.com/ClickHouse/ClickHouse/pull/101219) ([Kseniia Sumarokova](https://github.com/kssenii)).
