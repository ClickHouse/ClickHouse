<div id="improvement">
  #### 改善
</div>

* [#58815](https://github.com/ClickHouse/ClickHouse/issues/58815) でバックポート: 未使用の jemalloc ページをパージする `SYSTEM JEMALLOC PURGE` と、プロファイラが有効な場合に jemalloc の profile を制御する `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` を追加しました。さらに、Keeper に jemalloc 関連の 4LW コマンドも追加しました。`jmst` は jemalloc の統計情報をダンプし、`jmfp`、`jmep`、`jmdp` は、プロファイラが有効な場合に jemalloc の profile を制御します。[#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* [#59234](https://github.com/ClickHouse/ClickHouse/issues/59234) でバックポート: Iceberg テーブルエンジンでスキーマ進化を無視し、テーブル作成時にユーザーが指定したスキーマ、またはテーブル作成時にメタデータから解析された最新のスキーマを使用して、すべてのデータを読み取れるようにしました。これは、デフォルトで無効になっている設定 `iceberg_engine_ignore_schema_evolution` で有効化できます。この設定を有効にすると、スキーマが進化している場合でも、すべての data files が同じスキーマを使って読み取られるため、結果が不正確になる可能性がある点に注意してください。[#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
