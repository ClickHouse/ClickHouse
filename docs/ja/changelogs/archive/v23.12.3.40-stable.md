  ### ClickHouse リリース v23.12.3.40-stable (a594704ae75) FIXME (v23.12.2.59-stable (17ab210e761) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#58660](https://github.com/ClickHouse/ClickHouse/issues/58660) でバックポート: 以前は、データの読み取りに多数のストリームを必要とする一部のクエリを実行すると、エラー `"Paste JOIN requires sorted tables only"` が発生していました。現在は、そのような場合、ストリーム数が 1 に調整されます。[#58608](https://github.com/ClickHouse/ClickHouse/pull/58608) ([Yarik Briukhovetskyi](https://github.com/yariks5s)) 。
* [#58817](https://github.com/ClickHouse/ClickHouse/issues/58817) でバックポート: 未使用の jemalloc ページを解放するための `SYSTEM JEMALLOC PURGE`、および Profiler が有効な場合に jemalloc profile を制御するための `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` を追加しました。さらに、Keeper に jemalloc 関連の 4LW コマンドも追加しました。jemalloc stats をダンプする `jmst` と、Profiler が有効な場合に jemalloc profile を制御する `jmfp`、`jmep`、`jmdp` です。[#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)) 。
* [#59235](https://github.com/ClickHouse/ClickHouse/issues/59235) でバックポート: Iceberg テーブルエンジンで schema evolution を無視し、テーブル作成時にユーザーが指定したスキーマ、またはテーブル作成時にメタデータから解析された最新のスキーマを使って、すべてのデータを読み取れるようにしました。これは、デフォルトで無効になっている setting `iceberg_engine_ignore_schema_evolution` によって実現されます。この setting を有効にすると、schema evolution が発生した場合でもすべての data files が同じスキーマで読み取られるため、結果が不正確になる可能性がある点に注意してください。[#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* materialized view で複数回の読み取りを可能にするため、StorageKafka からの読み取りを遅延 [#58477](https://github.com/ClickHouse/ClickHouse/pull/58477) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 交差するパーツに関する単純な不具合を修正 [#58482](https://github.com/ClickHouse/ClickHouse/pull/58482) ([Alexander Tokmakov](https://github.com/tavplubix)).
* ConcurrentHashJoin で `max_joined_block_rows` を無効化 [#58595](https://github.com/ClickHouse/ClickHouse/pull/58595) ([vdimir](https://github.com/vdimir)).
* 並列 window functions における stream のパーティション化を修正 [#58739](https://github.com/ClickHouse/ClickHouse/pull/58739) ([Dmitry Novik](https://github.com/novikd)).
* addBatchLookupTable8 で例外送出時に destroy が二重に呼び出される問題を修正 [#58745](https://github.com/ClickHouse/ClickHouse/pull/58745) ([Raúl Marín](https://github.com/Algunenano)).
* LowCardinality(Nullable) カラムに対する JSONExtract 関数を修正 [#58808](https://github.com/ClickHouse/ClickHouse/pull/58808) ([vdimir](https://github.com/vdimir)).
* mv での file log storage の複数回読み取りを修正 [#58877](https://github.com/ClickHouse/ClickHouse/pull/58877) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* 修正: 分散クエリにおける LIMIT BY と LIMIT [#59153](https://github.com/ClickHouse/ClickHouse/pull/59153) ([Igor Nikonov](https://github.com/devcrafter)).
* system.tables の not-ready set を修正 [#59351](https://github.com/ClickHouse/ClickHouse/pull/59351) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* FixedString 入力に対する translate() を修正 [#59356](https://github.com/ClickHouse/ClickHouse/pull/59356) ([Raúl Marín](https://github.com/Algunenano)).
