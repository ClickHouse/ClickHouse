<div id="clickhouse-release-v209220-stable-fixme-as-compared-to-v20814513-prestable">
  ### ClickHouse リリース v20.9.2.20-stable FIXME (v20.8.1.4513-prestable との比較)
</div>

<div id="new-feature">
  #### 新機能
</div>

* サブクエリをテーブルオブジェクトに変換するテーブル関数 `view` を追加しました。これにより、クエリを受け渡ししやすくなります。たとえば、remote/cluster テーブル関数で使用できます。[#12567](https://github.com/ClickHouse/ClickHouse/pull/12567) ([Amos Bird](https://github.com/amosbird)).
* `select * apply(length) apply(max) from wide_string_table` と記述して、すべての String 型のカラムの最大長を調べられるようになりました。さらに、次の 2 つの書き方も利用できます。 [#14233](https://github.com/ClickHouse/ClickHouse/pull/14233) ([Amos Bird](https://github.com/amosbird)).
* 順位相関係数をシンプルに計算する集約関数 RankCorrelationSpearman を追加しました。[#11769](https://github.com/ClickHouse/ClickHouse/issues/11769) の続きです。 [#14411](https://github.com/ClickHouse/ClickHouse/pull/14411) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* クエリユーティリティによるデータベース生成機能を追加しました。[#10973](https://github.com/ClickHouse/ClickHouse/issues/10973) の続きです。 [#14442](https://github.com/ClickHouse/ClickHouse/pull/14442) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* GROUP BY sharding&#95;key を使用する Distributed に対する、LIMIT/LIMIT BY/ORDER BY 付きクエリを最適化しました (optimize&#95;skip&#95;unused&#95;shards および optimize&#95;distributed&#95;group&#95;by&#95;sharding&#95;key 有効時) 。[#10373](https://github.com/ClickHouse/ClickHouse/pull/10373) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">
  #### 改善
</div>

* StorageRabbitMQ を改善しました。connection と channels の障害処理、適切なコミット、insert 失敗時の処理、exchange の改善、queue の永続性、queue の再開機能、新しい queue 設定を追加しました。テストも修正しました。[#12761](https://github.com/ClickHouse/ClickHouse/pull/12761) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Redis の requirepass 認証を追加しました。[#13688](https://github.com/ClickHouse/ClickHouse/pull/13688) ([Ivan Torgashov](https://github.com/it1804)).
* DateTime 型に精度 argument を追加しました。[#13761](https://github.com/ClickHouse/ClickHouse/pull/13761) ([Winter Zhang](https://github.com/zhang2014)).
* 各 consumer に独立した thread を割り当てることで、Kafka エンジンの性能を改善しました。ストリーミングエンジン (Kafka など) 向けに専用の thread pool を分離しました。[#13939](https://github.com/ClickHouse/ClickHouse/pull/13939) ([fastio](https://github.com/fastio)).
* `system.part_log` のパーツに対するデフォルトの圧縮 codec を、`default_compression_codec` という名前で追加しました。[#14116](https://github.com/ClickHouse/ClickHouse/pull/14116) ([alesapin](https://github.com/alesapin)).
* boost multiprecision の wide integer を [https://github.com/cerevra/int](https://github.com/cerevra/int) の実装に置き換えました。[#14229](https://github.com/ClickHouse/ClickHouse/pull/14229) ([Artem Zuikov](https://github.com/4ertus2)).
* MaterializeMySQL で主キーを暗黙的に not null に変換するようにしました (MySQL と同様) 。[#14114](https://github.com/ClickHouse/ClickHouse/issues/14114) を修正します。[#14397](https://github.com/ClickHouse/ClickHouse/pull/14397) ([Winter Zhang](https://github.com/zhang2014)).
* [#11384](https://github.com/ClickHouse/ClickHouse/issues/11384) で提案された新しい設定 system&#95;events&#95;show&#95;zero&#95;values を追加しました。[#14404](https://github.com/ClickHouse/ClickHouse/pull/14404) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* [#13163](https://github.com/ClickHouse/ClickHouse/issues/13163) で提案されたとおり、obfuscator が UUID 型をサポートするようになりました。[#14409](https://github.com/ClickHouse/ClickHouse/pull/14409) ([Dmitry Rubashkin](https://github.com/dimarub2000)).
* 複数の `JOIN` と `IN` に対する Set の作成を並列に実行するようにしました。複数の異なる `IN subquery` expression を含むクエリの性能がわずかに向上する可能性があります。[#14412](https://github.com/ClickHouse/ClickHouse/pull/14412) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* これまで materialize されていなかった TTL は、merge 中に適用されるようになりました。[#14438](https://github.com/ClickHouse/ClickHouse/pull/14438) ([alesapin](https://github.com/alesapin)).
* MySQL ハンドラーは、`SET @@var = value` のようなクエリに対して `OK` を返すようになりました。このようなステートメントは無視されます。これは、一部の MySQL ドライバーが handshake 後のセットアップのために `SET @@` クエリを送信するためです [#9336](https://github.com/ClickHouse/ClickHouse/issues/9336)#issuecomment-686222422 。[#14469](https://github.com/ClickHouse/ClickHouse/pull/14469) ([BohuTANG](https://github.com/BohuTANG)).
* `toStartOf*` 系の function では、空の time&#95;zone argument を禁止しました。[#14509](https://github.com/ClickHouse/ClickHouse/pull/14509) ([Bharat Nallan](https://github.com/bharatnc)).
* ... [#14523](https://github.com/ClickHouse/ClickHouse/pull/14523) ([BohuTANG](https://github.com/BohuTANG)).
* [#14873](https://github.com/ClickHouse/ClickHouse/issues/14873) でバックポート: storage Distributed で multi-volume storage configuration を使用できるようにしました。[#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
