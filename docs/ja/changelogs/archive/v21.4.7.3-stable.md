  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v21473-stable-fixme-as-compared-to-v214655-stable">
  ### ClickHouse リリース v21.4.7.3-stable FIXME (v21.4.6.55-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#23971](https://github.com/ClickHouse/ClickHouse/issues/23971)でバックポート: 古くなった `ReplicatedMergeTree` レプリカの復旧におけるバグを修正しました。レプリカのダウンタイム中に `ALTER` クエリが実行されると、一部のメタデータ更新が古くなったレプリカで無視されることがありました。 [#23742](https://github.com/ClickHouse/ClickHouse/pull/23742) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23819](https://github.com/ClickHouse/ClickHouse/issues/23819)でバックポート: `PREWHERE` と ROW POLICY フィルターが同時に有効で、結果が空の場合にクラッシュする問題を修正しました。 [#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* [#23816](https://github.com/ClickHouse/ClickHouse/issues/23816)でバックポート: materialized view から参照されている場合に `CLEAR COLUMN` が機能しない問題を修正しました。[#23764](https://github.com/ClickHouse/ClickHouse/issues/23764) をクローズしました。 [#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
* [#23831](https://github.com/ClickHouse/ClickHouse/issues/23831)でバックポート: `GLOBAL IN/JOIN` および `use_hedged_requests` を使用するクエリで発生する `Can't initialize pipeline with empty pipe` エラーを修正しました。 [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431) を修正しました。 [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23930](https://github.com/ClickHouse/ClickHouse/issues/23930)でバックポート: HashedDictionary の複合キー更新フィールドの初期ロードに関する不具合を修正しました。 [#23800](https://github.com/ClickHouse/ClickHouse/issues/23800) をクローズしました。 [#23824](https://github.com/ClickHouse/ClickHouse/pull/23824) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23957](https://github.com/ClickHouse/ClickHouse/issues/23957)でバックポート: ソースに重複がある CACHE() Dictionary で、keys メトリクスの集計を修正しました (`DictCacheKeysRequestedMiss` のオーバーフローの原因になります) 。 [#23929](https://github.com/ClickHouse/ClickHouse/pull/23929) ([Azat Khuzhin](https://github.com/azat)).
* [#24003](https://github.com/ClickHouse/ClickHouse/issues/24003)でバックポート: 外部 GROUP BY および overflow 行で発生する SIGSEGV を修正しました (たとえば `SELECT FROM GROUP BY WITH TOTALS SETTINGS max_bytes_before_external_group_by>0, max_rows_to_group_by>0, group_by_overflow_mode='any', totals_mode='before_having'` のようなクエリ) 。 [#23962](https://github.com/ClickHouse/ClickHouse/pull/23962) ([Azat Khuzhin](https://github.com/azat)).
* [#24188](https://github.com/ClickHouse/ClickHouse/issues/24188)でバックポート: 一部の `ALTER PARTITION` クエリにより、レプリケーションキューで `Part A intersects previous part B` および `Unexpected merged part C intersecting drop range D` エラーが発生する可能性がありました。修正済みです。 [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296) を修正しました。 [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24031](https://github.com/ClickHouse/ClickHouse/issues/24031)でバックポート: MergeJoin で発生するクラッシュを修正し、[#24010](https://github.com/ClickHouse/ClickHouse/issues/24010) をクローズしました。 [#24013](https://github.com/ClickHouse/ClickHouse/pull/24013) ([Vladimir C](https://github.com/vdimir)).
* [#24141](https://github.com/ClickHouse/ClickHouse/issues/24141)でバックポート: バグ: `select xxx final` に対する explain pipeline で誤った pipeline が表示される: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* [#24171](https://github.com/ClickHouse/ClickHouse/issues/24171) でバックポート: 部分的にしか初期化されていないにもかかわらず、書き込みリクエスト (insert/alter/など) を処理できてしまうテーブルが生じる可能性のある、まれなバグを修正しました。今後、そのようなテーブルは readonly モードになります。[#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* [#24215](https://github.com/ClickHouse/ClickHouse/issues/24215) でバックポート: 高負荷時に RBAC で発生する可能性があったレースコンディションを修正しました。この PR で [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090)、[#24134](https://github.com/ClickHouse/ClickHouse/issues/24134) を修正しました。[#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#24243](https://github.com/ClickHouse/ClickHouse/issues/24243) でバックポート: クエリ実行中に HDFS にアクセスできなくなったことによる server の異常終了を修正しました。[#24117](https://github.com/ClickHouse/ClickHouse/issues/24117) をクローズしました。[#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
