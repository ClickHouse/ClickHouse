<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#45904](https://github.com/ClickHouse/ClickHouse/issues/45904) にバックポート: テーブルのメタデータ内の EPHEMERAL カラムで、解析できないデフォルト値に関する bug を修正しました。[#44026](https://github.com/ClickHouse/ClickHouse/pull/44026) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#45321](https://github.com/ClickHouse/ClickHouse/issues/45321) にバックポート: `CREATE TABLE` ステートメントにおける `DEFAULT` 式の正規化の bug を修正しました。関数 `in` の第 2 引数 (または演算子 `IN` の右辺) が、CREATE クエリの実行中にその評価結果で置き換えられることがありました。[#44496](https://github.com/ClickHouse/ClickHouse/issues/44496) を修正します。[#44547](https://github.com/ClickHouse/ClickHouse/pull/44547) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#45000](https://github.com/ClickHouse/ClickHouse/issues/45000) にバックポート: remote fs から `LowCardinality` Dictionary を読み取る際に発生する可能性がある `Cannot read all data` error について、別の修正を行いました。[#44709](https://github.com/ClickHouse/ClickHouse/issues/44709) を修正します。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#45553](https://github.com/ClickHouse/ClickHouse/issues/45553) にバックポート: 不正な structure (たとえば xml config 内の型の誤り) を持つ Dictionary が存在する場合に発生する `SELECT ... FROM system.dictionaries` Exception を修正しました。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#46226](https://github.com/ClickHouse/ClickHouse/issues/46226) にバックポート: `c-ares` 周辺で複数の segfault が報告されていました。最近観測された stack trace はいずれも `std::unodered_set<>` への inserting 中に失敗していました。この根本原因を特定できたと考えており、未処理の queries が原因のようです。この PR 以前は、CH は `c-ares` channel 内のファイルディスクリプタを待機するために `poll` を呼び出していました。[poll docs](https://man7.org/linux/man-pages/man2/poll.2.html) によると、戻り値が負の場合は error の発生を意味します。そのため、実行を中断して failure を返していました。問題は、システム割り込みが発生した場合にも `poll` が負の値を返すことです。システム割り込みは processing の失敗や終了を意味しませんが、負の値をチェックしていたため、それでも中断していました。実行が中断されるとスタック全体が破棄され、その中には c-ares callback の `void *` parameter に渡されていた `std::unordered_set<std::string>` も含まれます。c-ares がリクエストを完了すると callback が呼び出され、無効な memory address にアクセスして segfault を引き起こしていました。[#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos)).
* [#46218](https://github.com/ClickHouse/ClickHouse/issues/46218) にバックポート: compact パーツで、複数レベルの存在しない nested カラムの読み取りを修正しました。[#46045](https://github.com/ClickHouse/ClickHouse/pull/46045) ([Azat Khuzhin](https://github.com/azat)).
* [#46446](https://github.com/ClickHouse/ClickHouse/issues/46446) にバックポート: フォーマット `VALUES` で送信された無効な data による非同期挿入で発生する可能性がある `LOGICAL_ERROR` を修正しました。[#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ)).
* [#46678](https://github.com/ClickHouse/ClickHouse/issues/46678) にバックポート: 関数 `arrayMap` における定数 `LowCardinality` argument の不正な processing を修正しました。この bug は、release では segfault、debug build では論理エラー `Bad cast` を引き起こす可能性がありました。[#46569](https://github.com/ClickHouse/ClickHouse/pull/46569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46872](https://github.com/ClickHouse/ClickHouse/issues/46872)でバックポート: `Map` データ型のバグを修正しました。これにより [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855) はクローズされます。[#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46954](https://github.com/ClickHouse/ClickHouse/issues/46954)でバックポート: 部分文字列検索に変換され、引用符付きの非 LIKE メタ文字を含む LIKE 述語の結果を修正しました。[#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
