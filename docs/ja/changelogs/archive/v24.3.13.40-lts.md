<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#63976](https://github.com/ClickHouse/ClickHouse/issues/63976) にバックポート: drop range 後の再起動時にパーツの積集合判定を修正。 [#63202](https://github.com/ClickHouse/ClickHouse/pull/63202) ([Han Fei](https://github.com/hanfei1991)).
* [#71482](https://github.com/ClickHouse/ClickHouse/issues/71482) にバックポート: 一部の圧縮レスポンスで `Content-Encoding` が送信されない問題を修正。 [#64802](https://github.com/ClickHouse/ClickHouse/issues/64802)。 [#68975](https://github.com/ClickHouse/ClickHouse/pull/68975) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#70451](https://github.com/ClickHouse/ClickHouse/issues/70451) にバックポート: PostgreSQL エンジンの FixedString カラムへの insert 時に発生するクラッシュを修正。 [#69584](https://github.com/ClickHouse/ClickHouse/pull/69584) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70619](https://github.com/ClickHouse/ClickHouse/issues/70619) にバックポート: 2 つの SELECT と `INTERSECT` を含む materialized view の作成時にサーバーで segfault が発生する問題を修正。例: `CREATE MATERIALIZED VIEW v0 AS (SELECT 1) INTERSECT (SELECT 1);`。 [#70264](https://github.com/ClickHouse/ClickHouse/pull/70264) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#70877](https://github.com/ClickHouse/ClickHouse/issues/70877) にバックポート: `Replicated` データベースで、secondary レプリカ上で table function の参照先が利用できない場合に `CREATE ... AS table_function()` を使った table 作成が失敗する問題を修正。 [#70511](https://github.com/ClickHouse/ClickHouse/pull/70511) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#70571](https://github.com/ClickHouse/ClickHouse/issues/70571) にバックポート: `wait_for_async_insert=1` を指定した非同期 INSERT で、すべての出力を無視するよう修正。 [#62644](https://github.com/ClickHouse/ClickHouse/issues/62644) をクローズ。 [#70530](https://github.com/ClickHouse/ClickHouse/pull/70530) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#71146](https://github.com/ClickHouse/ClickHouse/issues/71146) にバックポート: system.remote&#95;data&#95;paths から shadow ディレクトリを走査する際に frozen&#95;metadata.txt を無視するよう修正。 [#70590](https://github.com/ClickHouse/ClickHouse/pull/70590) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#70682](https://github.com/ClickHouse/ClickHouse/issues/70682) にバックポート: メモリアラインメント不整合時の stateful な window function の作成を修正。 [#70631](https://github.com/ClickHouse/ClickHouse/pull/70631) ([Raúl Marín](https://github.com/Algunenano)).
* [#71113](https://github.com/ClickHouse/ClickHouse/issues/71113) にバックポート: AggregateFunctionGroupArraySorted におけるクラッシュとリークを修正。 [#70820](https://github.com/ClickHouse/ClickHouse/pull/70820) ([Michael Kolupaev](https://github.com/al13n321)).
* [#70990](https://github.com/ClickHouse/ClickHouse/issues/70990) にバックポート: 二段階ハッシュテーブルで負のゼロが原因となる論理エラーを修正。これにより [#70973](https://github.com/ClickHouse/ClickHouse/issues/70973) をクローズ。 [#70979](https://github.com/ClickHouse/ClickHouse/pull/70979) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#71246](https://github.com/ClickHouse/ClickHouse/issues/71246) にバックポート: 特定の状況で名前付きセッションが閉じられず、無期限にハングし続ける問題を修正。 [#70998](https://github.com/ClickHouse/ClickHouse/pull/70998) ([Márcio Martins](https://github.com/marcio-absmartly)).
* [#71371](https://github.com/ClickHouse/ClickHouse/issues/71371) にバックポート: terminate を回避するため、data part のデストラクタに try/catch を追加。 [#71364](https://github.com/ClickHouse/ClickHouse/pull/71364) ([alesapin](https://github.com/alesapin)).
* [#71594](https://github.com/ClickHouse/ClickHouse/issues/71594) にバックポート: SortCursor でカラム数が 0 の場合にクラッシュしないよう修正 (旧アナライザ) 。[#71494](https://github.com/ClickHouse/ClickHouse/pull/71494) ([Raúl Marín](https://github.com/Algunenano)).
