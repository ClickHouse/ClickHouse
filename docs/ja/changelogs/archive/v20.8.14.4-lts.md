<div id="clickhouse-release-v208144-lts-fixme-as-compared-to-v2081315-lts">
  ### ClickHouse リリース v20.8.14.4-lts FIXME (v20.8.13.15-lts との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#21235](https://github.com/ClickHouse/ClickHouse/issues/21235) でバックポート: MYSQL&#95;OPT&#95;RECONNECT オプションの値を、mysql レプリカの config セクションの &quot;opt&#95;reconnect&quot; パラメータで制御できるようになりました。[#19998](https://github.com/ClickHouse/ClickHouse/pull/19998) ([Alexander Kazakov](https://github.com/Akazz)).
* [#21203](https://github.com/ClickHouse/ClickHouse/issues/21203) でバックポート: mysql ソースの config の読み込み時に、mysql エンドポイントの選択でラウンドロビンが正しく機能するよう、ClickHouse は同じ優先度を持つレプリカのリストをランダム化するようになりました。これにより [#20629](https://github.com/ClickHouse/ClickHouse/issues/20629) はクローズされます。[#20632](https://github.com/ClickHouse/ClickHouse/pull/20632) ([Alexander Kazakov](https://github.com/Akazz)).
* [#21336](https://github.com/ClickHouse/ClickHouse/issues/21336) でバックポート: MySQL Dictionary ソースで、SSL/TLS 接続でときどき発生する予期しない接続障害 (クエリ実行中に MySQL server との接続が失われる) に対して再試行を行うようになりました。[#21237](https://github.com/ClickHouse/ClickHouse/pull/21237) ([Alexander Kazakov](https://github.com/Akazz)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#20950](https://github.com/ClickHouse/ClickHouse/issues/20950) でバックポート: サブクエリに const カラムがある場合に、set 索引の無効化が正しく行われない問題を修正しました。これにより [#17246](https://github.com/ClickHouse/ClickHouse/issues/17246) も修正されます。 [#17249](https://github.com/ClickHouse/ClickHouse/pull/17249) ([Amos Bird](https://github.com/amosbird)).
* [#20948](https://github.com/ClickHouse/ClickHouse/issues/20948) でバックポート: `LowCardinality` 型を持つ `JOIN` テーブルの読み取り中にクラッシュする問題を修正しました。これにより [#17228](https://github.com/ClickHouse/ClickHouse/issues/17228) も修正されます。 [#17397](https://github.com/ClickHouse/ClickHouse/pull/17397) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#20903](https://github.com/ClickHouse/ClickHouse/issues/20903) でバックポート: `TinyLog` engine のテーブルに `LowCardinality` カラムを挿入する際の問題を修正しました。これにより [#18629](https://github.com/ClickHouse/ClickHouse/issues/18629) も修正されます。 [#19010](https://github.com/ClickHouse/ClickHouse/pull/19010) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#20899](https://github.com/ClickHouse/ClickHouse/issues/20899) でバックポート: 同時実行された `ALTER` クエリと `DROP` クエリが、ReplicatedMergeTree テーブルの処理中にハングすることがある不具合を修正しました。 [#19237](https://github.com/ClickHouse/ClickHouse/pull/19237) ([alesapin](https://github.com/alesapin)).
* [#20892](https://github.com/ClickHouse/ClickHouse/issues/20892) でバックポート: 切断後に Connection 内の CompressedWriteBuffer で use-after-free が発生する問題を修正しました。 [#19599](https://github.com/ClickHouse/ClickHouse/pull/19599) ([Azat Khuzhin](https://github.com/azat)).
* [#20888](https://github.com/ClickHouse/ClickHouse/issues/20888) でバックポート: データ破損後に、一部のレプリケーション操作 (mutation など) が一部のパーツを処理できなくなるまれな不具合を修正しました。これにより [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593) も修正されます。 [#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)).
* [#21049](https://github.com/ClickHouse/ClickHouse/issues/21049) でバックポート: 集約関数で `-State` combinator と `-Distinct` combinator を併用した場合の問題を修正しました。 [#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* [#21130](https://github.com/ClickHouse/ClickHouse/issues/21130) でバックポート: `ALTER MODIFY COLUMN` によって、失敗が確実な mutation が作成されてしまう動作を修正しました。 [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* [#21159](https://github.com/ClickHouse/ClickHouse/issues/21159) でバックポート: 型が Nullable の場合に `input_format_null_as_default` が有効に機能するよう修正しました。これにより [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116) も修正されます。 [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* [#21378](https://github.com/ClickHouse/ClickHouse/issues/21378) でバックポート: `Values` フォーマットから `LowCardinality` カラムを持つテーブルへ挿入する際に発生するエラー `Bad cast from type ... to DB::ColumnLowCardinality` を修正しました。これにより [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140) も修正されます。 [#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
