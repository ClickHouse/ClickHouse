<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#55291](https://github.com/ClickHouse/ClickHouse/issues/55291)でバックポート: サブモジュールを含むソースコード一式のリソースが、Darwin 向けの特別なビルドタスクでビルドされるようになりました。これにより、サブモジュールを checkout せずに ClickHouse をビルドできます。[#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* [#54705](https://github.com/ClickHouse/ClickHouse/issues/54705)でバックポート: プルリクエストで変更されていないイメージについて、master の最新タグで `changed_images.json` を拡充しました。[#54369](https://github.com/ClickHouse/ClickHouse/pull/54369) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#54683](https://github.com/ClickHouse/ClickHouse/issues/54683)でバックポート: push のたびにそれらをビルドしてアップロードしていますが、そこまでする価値はありません。[#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55407](https://github.com/ClickHouse/ClickHouse/issues/55407)でバックポート: clickhouse-server パッケージから standalone の clickhouse-keeper を起動する際の問題を解決しました。[#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55723](https://github.com/ClickHouse/ClickHouse/issues/55723)でバックポート: gh API URL を使うように integration check の Python スクリプトを修正し、CI テスト用の README を追加しました。[#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
