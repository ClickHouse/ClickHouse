  # 2025年の変更履歴
</div>

<div id="clickhouse-release-v252239-stable-a1200cff50a-fixme-as-compared-to-v25213085-stable-09989205d6f">
  ### ClickHouse リリース v25.2.2.39-stable (a1200cff50a) FIXME (v25.2.1.3085-stable (09989205d6f) との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#77183](https://github.com/ClickHouse/ClickHouse/issues/77183) でバックポート: `compatibility` 設定に関係なく、アナライザが無効な場合、並列レプリカはデフォルトで無効になります。`parallel_replicas_only_with_analyzer` を明示的に `false` に設定すれば、この動作は引き続き変更可能です。 [#77115](https://github.com/ClickHouse/ClickHouse/pull/77115) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="new-feature">
  #### 新機能
</div>

* [#77358](https://github.com/ClickHouse/ClickHouse/issues/77358) でバックポート: 同時実行クエリ間でのCPUスロットの配分を制御する `concurrent_threads_scheduler` サーバー設定を追加しました。`round_robin` (従来の動作) または `fair_round_robin` に設定でき、INSERT と SELECT の間でCPUが不公平に配分される問題に対処します。[#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#76999](https://github.com/ClickHouse/ClickHouse/issues/76999)でバックポート: async insert を有効にして、ブロックサイズが不均一な `insert into ... from file ...` を実行した際に発生するデータ損失を修正しました。最初のブロックサイズが &lt; async&#95;max&#95;size で、2 番目のブロックサイズが &gt; async&#95;max&#95;size の場合、2 番目のブロックが挿入されず、データが `squashing` に残ったままになっていました。 [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* [#76970](https://github.com/ClickHouse/ClickHouse/issues/76970)でバックポート: 分散テーブルから boolean リテラルを選択した際に発生する THERE&#95;IS&#95;NO&#95;COLUMN 例外を修正しました。 [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#77049](https://github.com/ClickHouse/ClickHouse/issues/77049)でバックポート: JSON サブカラムのプレフィックスを並列にデシリアライゼーションする際の例外処理を修正しました。 [#76809](https://github.com/ClickHouse/ClickHouse/pull/76809) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77260](https://github.com/ClickHouse/ClickHouse/issues/77260)でバックポート: 非同期 INSERT 中にエラーが発生した際、不正な JSON column のロールバックによってクラッシュする可能性がある問題を修正しました。 [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77064](https://github.com/ClickHouse/ClickHouse/issues/77064)でバックポート: `BFloat16` 値のソートを修正しました。これにより [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487) と [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669) をクローズします。 [#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#77222](https://github.com/ClickHouse/ClickHouse/issues/77222)でバックポート: part の整合性チェックで一時的なサブカラムをスキップするチェックを追加し、variant サブカラムを含む json に関する不具合を修正しました。 [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#77250](https://github.com/ClickHouse/ClickHouse/issues/77250)でバックポート: Kafka table の作成中に例外が発生した場合のクラッシュを修正しました。 [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77240](https://github.com/ClickHouse/ClickHouse/issues/77240)でバックポート: Kafka および RabbitMQ エンジンで、新しい JSON とサブカラムをサポートしました。 [#77122](https://github.com/ClickHouse/ClickHouse/pull/77122) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77386](https://github.com/ClickHouse/ClickHouse/issues/77386)でバックポート: `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` が、これまでの `false` ではなく、正しく `true` を返すようになりました。これにより、この挙動は `Float32` および `Float64` と一貫するようになります。 [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#77379](https://github.com/ClickHouse/ClickHouse/issues/77379)でバックポート: Bool 値を持つパーティション名を修正しました。この問題は [https://github.com/ClickHouse/ClickHouse/pull/74533](https://github.com/ClickHouse/ClickHouse/pull/74533) で発生していました。 [#77319](https://github.com/ClickHouse/ClickHouse/pull/77319) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77335](https://github.com/ClickHouse/ClickHouse/issues/77335)でバックポート: Nullable 要素を含むタプルと文字列との比較を修正しました。 [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
