<div id="clickhouse-release-v213184-lts-fixme-as-compared-to-v213172-lts">
  ### ClickHouse リリース v21.3.18.4-lts FIXME (v21.3.17.2-lts との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#30355](https://github.com/ClickHouse/ClickHouse/issues/30355) にバックポート: ブリッジプロセス用に、専用の `clickhouse-bridge` グループとユーザーを使用するようにしました。ブリッジが OOM キラーの最初の対象となるよう、oom&#95;score&#95;adj を設定しました。最大 RSS は 1 GiB に設定しました。[#23861](https://github.com/ClickHouse/ClickHouse/issues/23861) をクローズしました。[#25280](https://github.com/ClickHouse/ClickHouse/pull/25280) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29945](https://github.com/ClickHouse/ClickHouse/issues/29945) にバックポート: zoneinfo ファイルを 2021c に更新しました。[#29925](https://github.com/ClickHouse/ClickHouse/pull/29925) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#30041](https://github.com/ClickHouse/ClickHouse/issues/30041) にバックポート: `AccessControlManager` のシャットダウン処理を修正しました。これにより、AccessControlManager の破棄後に設定が再読み込みされることはなくなりました。この PR では、不安定だったテスト [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html) も修正しました。[#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#29260](https://github.com/ClickHouse/ClickHouse/issues/29260) にバックポート: Nullable または lowcardinality の主キーを使用した場合に発生する、無効な定数型変換を修正しました。[#28636](https://github.com/ClickHouse/ClickHouse/pull/28636) ([Amos Bird](https://github.com/amosbird))。
* [#29026](https://github.com/ClickHouse/ClickHouse/issues/29026) にバックポート: `GLOBAL IN` サブクエリで使用される threads 数を修正しました ([#19414](https://github.com/ClickHouse/ClickHouse/issues/19414) のバグ修正以降、単一 thread で実行されていました) 。[#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#29194](https://github.com/ClickHouse/ClickHouse/issues/29194) にバックポート: Avro input format で LowCardinality(Nullable) 型のカラムにデータを挿入する際に発生する segfault を修正しました。[#29132](https://github.com/ClickHouse/ClickHouse/pull/29132) ([Kruglov Pavel](https://github.com/Avogar))。
* [#29360](https://github.com/ClickHouse/ClickHouse/issues/29360) にバックポート: `ReplicatedMergeTree` のレプリカを再作成または新規作成する際、カラムのいずれかが case-insensitive な関数を含むデフォルト expression を持っていると、`Table columns structure in ZooKeeper is different from local table structure` Exception が発生する可能性がある問題を修正しました。[#29266](https://github.com/ClickHouse/ClickHouse/pull/29266) ([Anton Popov](https://github.com/CurtizJ))。
* [#29300](https://github.com/ClickHouse/ClickHouse/issues/29300) にバックポート: connection timeout (`send_timeout`/`receive_timeout`) を修正しました。[#29282](https://github.com/ClickHouse/ClickHouse/pull/29282) ([Azat Khuzhin](https://github.com/azat))。
* [#30042](https://github.com/ClickHouse/ClickHouse/issues/30042) にバックポート: プッシュダウン最適化後に filter predicate の condition が失われる可能性がある問題を修正しました。[#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#29848](https://github.com/ClickHouse/ClickHouse/issues/29848) にバックポート: `GROUP BY` 中に `LowCardinality` へ同時アクセスした際の問題を修正しました (SIGSEGV の原因になります) 。[#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat))。
* [#30066](https://github.com/ClickHouse/ClickHouse/issues/30066) にバックポート: `tuple()` によって sample が crash する問題を修正し、[#30004](https://github.com/ClickHouse/ClickHouse/issues/30004) をクローズしました。[#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl))。
* [#30332](https://github.com/ClickHouse/ClickHouse/issues/30332) にバックポート: * 複数の joins で、数字で始まる識別子を許可しました。[#30230](https://github.com/ClickHouse/ClickHouse/pull/30230) ([Vladimir C](https://github.com/vdimir))。
* [#30379](https://github.com/ClickHouse/ClickHouse/issues/30379) にバックポート: replaceRegexpAll の bug を修正しました。[#30292](https://github.com/ClickHouse/ClickHouse/pull/30292) ([Memo](https://github.com/Joeywzr))。
