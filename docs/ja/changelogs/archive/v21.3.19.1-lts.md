  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v213191-lts-fixme-as-compared-to-v213184-lts">
  ### ClickHouse リリース v21.3.19.1-lts FIXME (v21.3.18.4-lts との比較)
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#31733](https://github.com/ClickHouse/ClickHouse/issues/31733)でバックポート: JSON および XML の出力フォーマットのパフォーマンスを改善。 [#31673](https://github.com/ClickHouse/ClickHouse/pull/31673) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#31577](https://github.com/ClickHouse/ClickHouse/issues/31577)でバックポート: Quota の上限に達していないにもかかわらず、上限超過となっていた問題を修正しました。この PR は [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正します。 [#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).
* [#32347](https://github.com/ClickHouse/ClickHouse/issues/32347)でバックポート: サブクエリで不要なカラムを削除する際の bug を修正しました。GROUP BY のないクエリに集約関数が含まれる場合は、不要であっても削除しません。 [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

#### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合

* [#30913](https://github.com/ClickHouse/ClickHouse/issues/30913) でバックポート: `TO` と `FROM` が指定されていて、結果セットに行がない場合の `ORDER BY ... WITH FILL` を修正。 [#30888](https://github.com/ClickHouse/ClickHouse/pull/30888) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#30750](https://github.com/ClickHouse/ClickHouse/issues/30750)でバックポート: `positionCaseInsensitiveUTF8` や `countSubstringsCaseInsensitiveUTF8` など、UTF-8 文字列に対して大文字小文字を区別しない検索を行う関数で、実際には一致しない部分文字列を見つけてしまうことがありましたが、修正しました。[#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31038](https://github.com/ClickHouse/ClickHouse/issues/31038)でバックポート: 行フォーマット以外のフォーマットで `formatRow` 関数を使用すると segfault が発生していました。このようなフォーマットではこの関数を使用できないようにしました (意味がないため) 。[#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31519](https://github.com/ClickHouse/ClickHouse/issues/31519)でバックポート: RPNElement への not like 関数の追加を削除しました。[#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* [#31581](https://github.com/ClickHouse/ClickHouse/issues/31581)でバックポート: * この最適化のバグが修正されるまで `partial_merge_join_left_table_buffer_bytes` を無効化しました。[#31009](https://github.com/ClickHouse/ClickHouse/issues/31009) を参照してください。) * 冗長なオプション `partial_merge_join_optimizations` を削除しました。[#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* [#31792](https://github.com/ClickHouse/ClickHouse/issues/31792)でバックポート: `IPv4` などの domain 型のパースで、設定 `input_format_allow_errors_num` と `input_format_allow_errors_ratio` が機能していませんでしたが、修正しました。[#31686](https://github.com/ClickHouse/ClickHouse/issues/31686) を修正。[#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31816](https://github.com/ClickHouse/ClickHouse/issues/31816)でバックポート: データと Progress の行が出力内で混在した場合に発生する、JSONEachRowWithProgress 出力フォーマットでの競合状態を修正しました。[#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31758](https://github.com/ClickHouse/ClickHouse/issues/31758)でバックポート: `Map` 型での `Buffer` table engine の使用に関する問題を修正しました。[#30546](https://github.com/ClickHouse/ClickHouse/issues/30546) を修正。[#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* [#32153](https://github.com/ClickHouse/ClickHouse/issues/32153)でバックポート: 型が `Nullable` の Dictionary 属性に対して型付きの関数 `dictGet` を使用すると crash する問題を修正しました。[#30980](https://github.com/ClickHouse/ClickHouse/issues/30980) を修正。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#31894](https://github.com/ClickHouse/ClickHouse/issues/31894)でバックポート: TSKV フォーマットで発生する可能性がある assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` を修正しました。[#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32214](https://github.com/ClickHouse/ClickHouse/issues/32214)でバックポート: 一部のレプリカで設定 `replicated_can_become_leader` が無効になっている場合、クォーラム付きで挿入する際のアクティブなレプリカ数が誤って判定されることがありましたが、修正しました。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
