<div id="improvement">
  #### 改善
</div>

* [#76864](https://github.com/ClickHouse/ClickHouse/issues/76864)でバックポート: サーバーを再起動せずに、`max_remote_read_network_bandwidth_for_serve` と `max_remote_write_network_bandwidth_for_server` を動的に再読み込みできるようにしました。[#74206](https://github.com/ClickHouse/ClickHouse/pull/74206) ([Kai Zhu](https://github.com/nauu)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#76997](https://github.com/ClickHouse/ClickHouse/issues/76997) でバックポート: 非同期 INSERT を有効にして、ブロックサイズが不均一な状態で `insert into ... from file ...` を実行した際に発生するデータ損失を修正しました。最初のブロックサイズが `async_max_size` 未満で、2 つ目のブロックサイズが `async_max_size` を超える場合、2 つ目のブロックが挿入されず、そのデータが `squashing` に残っていました。[#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* [#76675](https://github.com/ClickHouse/ClickHouse/issues/76675) でバックポート: 並列 hash における `used_flag` の初期化を修正しました。これにより server が crash する可能性がありました。[#76580](https://github.com/ClickHouse/ClickHouse/pull/76580) ([Nikita Taranov](https://github.com/nickitat)).
* [#76833](https://github.com/ClickHouse/ClickHouse/issues/76833) でバックポート: 出力書き込み buffer を finalize する前に flush するようにしました。これにより、`JSONEachRowWithProgressRowOutputFormat` など一部の出力フォーマットの finalize 時に発生する `LOGICAL_ERROR` を修正しました。[#76726](https://github.com/ClickHouse/ClickHouse/pull/76726) ([Antonio Andelic](https://github.com/antonio2368)).
* [#77062](https://github.com/ClickHouse/ClickHouse/issues/77062) でバックポート: `BFloat16` の値のソートを修正しました。これにより [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487) と [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669) がクローズされます。[#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
