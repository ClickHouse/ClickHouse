* [#74808](https://github.com/ClickHouse/ClickHouse/issues/74808)でバックポート: `postgresql` および `sqlite` の table function における SQL インジェクションを防ぐため、セキュリティ上の問題を修正しました。[#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* [#75122](https://github.com/ClickHouse/ClickHouse/issues/75122)でバックポート: interval の insert 時に発生するクラッシュを修正しました (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)) 。[#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* [#75095](https://github.com/ClickHouse/ClickHouse/issues/75095)でバックポート: スパースシリアライゼーションが有効で、`Tuple` カラムを持つテーブル間の `INSERT SELECT` クエリを修正しました。[#74698](https://github.com/ClickHouse/ClickHouse/pull/74698) ([Anton Popov](https://github.com/CurtizJ)).
* [#75307](https://github.com/ClickHouse/ClickHouse/issues/75307)でバックポート: 型名が大文字でない場合に、JSON type 宣言のパース中に発生するクラッシュを修正しました。[#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74906](https://github.com/ClickHouse/ClickHouse/issues/74906)でバックポート: Keeper の修正: ディスクからログエントリを読み込む際の問題を修正しました。[#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75170](https://github.com/ClickHouse/ClickHouse/issues/75170)でバックポート: BACKUP および RESTORE 操作において、`query_log` の `used_privileges` フィールドと `missing_privileges` フィールドが欠落する問題を修正しました。[#74887](https://github.com/ClickHouse/ClickHouse/pull/74887) ([Alexey Katsman](https://github.com/alexkats)).
* [#74955](https://github.com/ClickHouse/ClickHouse/issues/74955)でバックポート: Azure Blob Storage 上で空のカラムを持つテーブルの data parts の merge 中に発生する FILE&#95;DOESNT&#95;EXIST エラーを修正しました。[#74892](https://github.com/ClickHouse/ClickHouse/pull/74892) ([Julia Kartseva](https://github.com/jkartseva)).
* [#75052](https://github.com/ClickHouse/ClickHouse/issues/75052)でバックポート: HDFS の select リクエスト中に sasl エラーが発生した場合、krb ticket を更新するようにしました。[#74930](https://github.com/ClickHouse/ClickHouse/pull/74930) ([inv2004](https://github.com/inv2004)).
* [#75412](https://github.com/ClickHouse/ClickHouse/issues/75412)でバックポート: remove 操作が失敗した場合に、part&#39;s state を deleting から outdated に戻すようにしました。[#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* [#75405](https://github.com/ClickHouse/ClickHouse/issues/75405)でバックポート: `optimize_function_to_subcolumns` 設定が有効な `Array`、`Map`、`Nullable(..)` カラムに対する索引 (プライマリおよびセカンダリ) の使用を修正しました。従来は、これらのカラムの索引が無視されることがありました。[#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* [#75458](https://github.com/ClickHouse/ClickHouse/issues/75458)でバックポート: Insert を含む CTE で発生するクラッシュを修正しました。[#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).
* [#75481](https://github.com/ClickHouse/ClickHouse/issues/75481)でバックポート: `icebergS3`、`icebergAzure` のテーブル関数およびテーブルエンジンで機密情報を非表示にするようにしました。[#75378](https://github.com/ClickHouse/ClickHouse/pull/75378) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#75287](https://github.com/ClickHouse/ClickHouse/issues/75287)でバックポート: さらに厳格なデフォルト設定にするための改善。現在のデフォルト設定はすでに安全で、ポートを明示的に公開するにはユーザーがオプションを指定する必要があります。ただし、`default` ユーザーに `CLICKHOUSE_PASSWORD` でパスワードが設定されておらず、かつ/または `CLICKHOUSE_USER` 環境変数でユーザー名が変更されていない場合は、追加の保護策としてローカルシステムからのみアクセスできるようにするべきです。 [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
