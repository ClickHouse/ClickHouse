<div id="clickhouse-release-v2111414-stable-fixme-as-compared-to-v211136-stable">
  ### ClickHouse リリース v21.11.4.14-stable FIXME (v21.11.3.6-stable と比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#31370](https://github.com/ClickHouse/ClickHouse/issues/31370) でバックポート: 部分的な REVOKE を使用している場合の SHOW GRANTS の不具合を修正しました。この PR で [#31138](https://github.com/ClickHouse/ClickHouse/issues/31138) を修正しました。[#31249](https://github.com/ClickHouse/ClickHouse/pull/31249) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#31282](https://github.com/ClickHouse/ClickHouse/issues/31282)でバックポート: intersect/except に関するいくつかのコーナーケースを修正しました。[#30803](https://github.com/ClickHouse/ClickHouse/issues/30803) をクローズ。[#30965](https://github.com/ClickHouse/ClickHouse/pull/30965) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#31237](https://github.com/ClickHouse/ClickHouse/issues/31237)でバックポート: materialized view を削除した後の SELECT クエリが壊れる不具合を修正しました。[#30691](https://github.com/ClickHouse/ClickHouse/issues/30691) で報告。[#30997](https://github.com/ClickHouse/ClickHouse/pull/30997) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#31374](https://github.com/ClickHouse/ClickHouse/issues/31374)でバックポート: 別名および WHERE を使用した StorageMerge の不具合を修正しました (それまではまったく動作していませんでした) 。[#28802](https://github.com/ClickHouse/ClickHouse/issues/28802) をクローズ。[#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#31236](https://github.com/ClickHouse/ClickHouse/issues/31236)でバックポート: 一部の協調ログが失われ、最新のログより新しい snapshot が存在する場合に起動できなくなる可能性がある Keeper の不具合を修正しました。[#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin))。
* [#31435](https://github.com/ClickHouse/ClickHouse/issues/31435)でバックポート: group by と positional arguments に関する不具合を修正しました。[#31280](https://github.com/ClickHouse/ClickHouse/issues/31280)#issuecomment-968696186 をクローズ。[#31420](https://github.com/ClickHouse/ClickHouse/pull/31420) ([Kseniia Sumarokova](https://github.com/kssenii))。
