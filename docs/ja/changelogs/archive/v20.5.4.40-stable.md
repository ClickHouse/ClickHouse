  ### ClickHouse リリース v20.5.4.40-stable FIXME (v20.5.3.27-stable と比較)
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#12929](https://github.com/ClickHouse/ClickHouse/issues/12929)でバックポート: 「[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) リテラルを含む IN 演算子で索引が使用されない」を修正。v19.3頃に導入されたパフォーマンス低下を修正しました。 [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#12830](https://github.com/ClickHouse/ClickHouse/issues/12830) でバックポート: スレッド総数の上限設定が誤っていたことにより発生していた、`UNION` を含む SELECT クエリのパフォーマンス問題を修正しました。これにより [#12030](https://github.com/ClickHouse/ClickHouse/issues/12030) を修正しました。[#12103](https://github.com/ClickHouse/ClickHouse/pull/12103) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#12836](https://github.com/ClickHouse/ClickHouse/issues/12836) でバックポート: `SummingMergeTree` engine がパーティションキーのカラムを合計する際の動作を修正しました。合計対象カラムを明示的に定義した場合に、それがパーティションキー カラムと重複するケースでは例外を追加しました。これにより [#7867](https://github.com/ClickHouse/ClickHouse/issues/7867) を修正しました。[#12173](https://github.com/ClickHouse/ClickHouse/pull/12173) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#12833](https://github.com/ClickHouse/ClickHouse/issues/12833) でバックポート: `StorageFile` に対して複数回連続で insert を実行した際に、一部の特殊な型の header が複数回書き込まれていた問題を修正しました。これにより [#6155](https://github.com/ClickHouse/ClickHouse/issues/6155) を修正しました。[#12197](https://github.com/ClickHouse/ClickHouse/pull/12197) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#12895](https://github.com/ClickHouse/ClickHouse/issues/12895) でバックポート: kafka: batch の途中に error を含むメッセージがある場合に発生する SIGSEGV を修正しました。[#12302](https://github.com/ClickHouse/ClickHouse/pull/12302) ([Azat Khuzhin](https://github.com/azat)).
* [#12905](https://github.com/ClickHouse/ClickHouse/issues/12905) でバックポート: `-State` と `Nullable` の argument を持つ aggregate functions に対する TOTALS/ROLLUP/CUBE を修正しました。これにより [#12163](https://github.com/ClickHouse/ClickHouse/issues/12163) を修正しました。[#12376](https://github.com/ClickHouse/ClickHouse/pull/12376) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#12907](https://github.com/ClickHouse/ClickHouse/issues/12907) でバックポート: 依存する DEFAULT expression が存在する場合でも CLEAR column を許可するようにしました。これにより [#12333](https://github.com/ClickHouse/ClickHouse/issues/12333) を修正しました。[#12378](https://github.com/ClickHouse/ClickHouse/pull/12378) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#12909](https://github.com/ClickHouse/ClickHouse/issues/12909) でバックポート: 索引付き table において、負数または浮動小数点の定数が WHERE 条件で使われた際に Exception が発生するのを回避しました。これにより [#11905](https://github.com/ClickHouse/ClickHouse/issues/11905) を修正しました。[#12384](https://github.com/ClickHouse/ClickHouse/pull/12384) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#12897](https://github.com/ClickHouse/ClickHouse/issues/12897) でバックポート: 辞書キーの expression に対して join する場合に、Dictionary を使った JOIN で crash が発生する問題を修正しました: `t JOIN dict ON expr(dict.id) = t.id`。このケースでは Dictionary join の最適化を無効化しました。[#12458](https://github.com/ClickHouse/ClickHouse/pull/12458) ([Artem Zuikov](https://github.com/4ertus2)).
* [#13004](https://github.com/ClickHouse/ClickHouse/issues/13004) でバックポート: compact パーツ の読み取り時に発生していたパフォーマンス問題を修正しました。[#12492](https://github.com/ClickHouse/ClickHouse/pull/12492) ([Anton Popov](https://github.com/CurtizJ)).
* [#12892](https://github.com/ClickHouse/ClickHouse/issues/12892) でバックポート: データ重複を引き起こす可能性があった live view table における race condition を修正しました。[#12519](https://github.com/ClickHouse/ClickHouse/pull/12519) ([vzakaznikov](https://github.com/vzakaznikov)).
* [#12888](https://github.com/ClickHouse/ClickHouse/issues/12888) でバックポート: ファイル `checksums.txt` が存在しない場合に、ClickHouse がパーツのチェックサムを再計算するようにしました。[#9827](https://github.com/ClickHouse/ClickHouse/issues/9827) 以降壊れていました。[#12545](https://github.com/ClickHouse/ClickHouse/pull/12545) ([alesapin](https://github.com/alesapin)).
* [#12873](https://github.com/ClickHouse/ClickHouse/issues/12873) でバックポート: `OPTIMIZE DEDUPLICATE` で発生する `Output of TreeExecutor is not sorted` エラーを修正しました。[#11572](https://github.com/ClickHouse/ClickHouse/issues/11572) を修正します。[#12613](https://github.com/ClickHouse/ClickHouse/pull/12613) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#12885](https://github.com/ClickHouse/ClickHouse/issues/12885) でバックポート: 外部ソートを伴うクエリで発生する可能性がある `Pipeline stuck` エラーを修正しました。[#12617](https://github.com/ClickHouse/ClickHouse/issues/12617) を修正します。[#12618](https://github.com/ClickHouse/ClickHouse/pull/12618) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
