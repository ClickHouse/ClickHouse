<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#40693](https://github.com/ClickHouse/ClickHouse/issues/40693)でバックポート: TGZ パッケージを修正。 [#40681](https://github.com/ClickHouse/ClickHouse/pull/40681) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#40542](https://github.com/ClickHouse/ClickHouse/issues/40542)でバックポート: タスクのスケジューリング失敗時に、WriteBufferFromS3 で発生する可能性のあるデッドロックを修正しました。[#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)) 。
* [#40450](https://github.com/ClickHouse/ClickHouse/issues/40450)でバックポート: MergeTree エンジンファミリーのカラム有効期限 (TTL) に関するまれなバグを修正しました。vertical merge が繰り返されると、`Cannot unlink file ColumnName.bin ... No such file or directory.` というエラーが発生することがありました。[#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)) 。
* [#40532](https://github.com/ClickHouse/ClickHouse/issues/40532)でバックポート: endpoint への最初のリクエストが成功した時点で proxy リゾルバが停止してしまう問題を修正しました。[#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)) 。
* [#40624](https://github.com/ClickHouse/ClickHouse/issues/40624)でバックポート: AWS SDK のバグによる潜在的なデータ損失を修正しました ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)) 。このバグは、ClickHouse を S3 上で使用している場合にのみ発生します。[#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)) 。
