<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#54702](https://github.com/ClickHouse/ClickHouse/issues/54702) でバックポート済み: プルリクエストで変更されていないイメージについて、`changed_images.json` に master の最新タグを追加。 [#54369](https://github.com/ClickHouse/ClickHouse/pull/54369) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#54743](https://github.com/ClickHouse/ClickHouse/issues/54743) でバックポート済み: 冗長な `clickhouse-keeper-client` のシンボリックリンクを削除。 [#54587](https://github.com/ClickHouse/ClickHouse/pull/54587) ([Tomas Barton](https://github.com/deric)).
* [#54685](https://github.com/ClickHouse/ClickHouse/issues/54685) でバックポート済み: push のたびにこれらをビルドしてアップロードしていましたが、見合うだけの価値がありません。 [#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#54974](https://github.com/ClickHouse/ClickHouse/issues/54974) にバックポート: prewhere optimization 中に、複合条件 actions DAG が中間ステップの出力カラムを失い、そのカラムが後続ステップの入力カラムとして必要な場合に問題が発生する不具合を修正しました。[#53492](https://github.com/ClickHouse/ClickHouse/pull/53492) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#54996](https://github.com/ClickHouse/ClickHouse/issues/54996) にバックポート: `prefer_localhost_replica=1` の場合、並列レプリカがローカル レプリカ上でのみ完全に実行されるか、誤った結果を返す問題を修正しました。[#54276](https://github.com/ClickHouse/ClickHouse/issues/54276) を修正。[#54334](https://github.com/ClickHouse/ClickHouse/pull/54334) ([Igor Nikonov](https://github.com/devcrafter)).
* [#54516](https://github.com/ClickHouse/ClickHouse/issues/54516) にバックポート: s3 table function で発生する可能性があるエラー &#39;URI contains invalid characters&#39; を修正しました。[#54345](https://github.com/ClickHouse/ClickHouse/issues/54345) をクローズ。[#54373](https://github.com/ClickHouse/ClickHouse/pull/54373) ([Kruglov Pavel](https://github.com/Avogar)).
* [#54418](https://github.com/ClickHouse/ClickHouse/issues/54418) にバックポート: `analysisOfVariance` の group number 引数の処理時に overflow をチェックするようにし、crash を回避します。この crash は WINGFUZZ によって発見されました。[#54385](https://github.com/ClickHouse/ClickHouse/pull/54385) ([Antonio Andelic](https://github.com/antonio2368)).
* [#54527](https://github.com/ClickHouse/ClickHouse/issues/54527) にバックポート: ここで説明されているバグ [#54135](https://github.com/ClickHouse/ClickHouse/issues/54135) を再現します。[#54430](https://github.com/ClickHouse/ClickHouse/pull/54430) ([Sema Checherinda](https://github.com/CheSema)).
* [#54854](https://github.com/ClickHouse/ClickHouse/issues/54854) にバックポート: variant aggregate states 使用時の誤った aggregation projection optimization を修正しました。この optimization は意図せず有効になっていましたが、[https://github.com/ClickHouse/ClickHouse/pull/39420](https://github.com/ClickHouse/ClickHouse/pull/39420) 以降、DataTypeAggregateFunction の比較が normalized されるようになったため、正しく実装されていませんでした。これにより [#54406](https://github.com/ClickHouse/ClickHouse/issues/54406) を修正。[#54480](https://github.com/ClickHouse/ClickHouse/pull/54480) ([Amos Bird](https://github.com/amosbird)).
* [#54599](https://github.com/ClickHouse/ClickHouse/issues/54599) にバックポート: input&#95;format&#95;with&#95;names&#95;use&#95;header が無効な状態でカラムの subset を読み込む際、WithNames フォーマットで発生する parsing error を修正しました。[#52591](https://github.com/ClickHouse/ClickHouse/issues/52591) をクローズ。[#54513](https://github.com/ClickHouse/ClickHouse/pull/54513) ([Kruglov Pavel](https://github.com/Avogar)).
* [#54594](https://github.com/ClickHouse/ClickHouse/issues/54594) にバックポート: バージョン 23.5 以降、ゼロコピー レプリケーション によって ZooKeeper と S3 に不要なデータが残る可能性がありました。これは mutated された outdated parts の削除時に発生することがあります。この問題は `Failed to get mutation parent on {} for part {}, refusing to remove blobs` という log messages によって確認できます。[#54550](https://github.com/ClickHouse/ClickHouse/pull/54550) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#54627](https://github.com/ClickHouse/ClickHouse/issues/54627) にバックポート: `ColumnUnique` 内の共有変数に対する非同期化書き込みを修正しました。[#54575](https://github.com/ClickHouse/ClickHouse/pull/54575) ([Nikita Taranov](https://github.com/nickitat)).
* [#54625](https://github.com/ClickHouse/ClickHouse/issues/54625) にバックポート: `ColumnDecimal` のシリアライゼーションを修正しました。[#54601](https://github.com/ClickHouse/ClickHouse/pull/54601) ([Nikita Taranov](https://github.com/nickitat)).
* [#54945](https://github.com/ClickHouse/ClickHouse/issues/54945) にバックポート: ORDER BY 使用時に仮想カラム (例: &#95;file) に誤った値が表示される問題を修正しました。[#54811](https://github.com/ClickHouse/ClickHouse/pull/54811) ([Michael Kolupaev](https://github.com/al13n321)).
* [#54872](https://github.com/ClickHouse/ClickHouse/issues/54872) にバックポート: Keeper の修正: シャットダウン中の segfault を回避するため、コールバック内で変数を正しくキャプチャするよう修正しました。[#54841](https://github.com/ClickHouse/ClickHouse/pull/54841) ([Antonio Andelic](https://github.com/antonio2368)).
* [#54950](https://github.com/ClickHouse/ClickHouse/issues/54950) にバックポート: テーブルのパーティションキーが Enum 型の拡張によって ALTER された場合に発生する projection 最適化エラーを修正しました。修正内容は、パーティションキーが変更された際に `minmax_count_projection` を再構築することです。これにより [#54941](https://github.com/ClickHouse/ClickHouse/issues/54941) も修正されます。[#54943](https://github.com/ClickHouse/ClickHouse/pull/54943) ([Amos Bird](https://github.com/amosbird)).
