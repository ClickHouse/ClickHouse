<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#68564](https://github.com/ClickHouse/ClickHouse/issues/68564)でバックポート: fuzzer によって見つかった `indexHint` 関数の不具合を修正しました。[#66286](https://github.com/ClickHouse/ClickHouse/pull/66286) ([Anton Popov](https://github.com/CurtizJ)).
* [#68996](https://github.com/ClickHouse/ClickHouse/issues/68996)でバックポート: 関数 `fromModifiedJulianDay` の上限を修正しました。本来は `9999-12-31` であるべきところ、誤って `9999-01-01` に設定されていました。[#67583](https://github.com/ClickHouse/ClickHouse/pull/67583) ([PHO](https://github.com/depressed-pho)).
* [#68865](https://github.com/ClickHouse/ClickHouse/issues/68865)でバックポート: ファイル内のデータ型が要求された型と大きく異なる場合に、Parquet の Filtering で発生するクラッシュを修正しました (例: `... FROM file('a.parquet', Parquet, 'x String')` だが、ファイル内では `x Int64`) 。この修正がない場合は、回避策として `input_format_parquet_filter_push_down = 0` を使用してください。[#68131](https://github.com/ClickHouse/ClickHouse/pull/68131) ([Michael Kolupaev](https://github.com/al13n321)).
* [#69004](https://github.com/ClickHouse/ClickHouse/issues/69004)でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/61984](https://github.com/ClickHouse/ClickHouse/pull/61984) の後も、`schema_inference_make_columns_nullable=0` によって Parquet/Arrow フォーマットでカラムが `Nullable` になることがありました。この変更は後方互換性がなく、ユーザーは動作の変化に気づいていました。この PR では、`schema_inference_make_columns_nullable=0` が以前どおり動作するようにし (Nullable カラムは推論されません) 、この設定に新しい値 `auto` を導入しています。これにより、データに null 許容性の情報がある場合にのみカラムが `Nullable` になります。[#68298](https://github.com/ClickHouse/ClickHouse/pull/68298) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68882](https://github.com/ClickHouse/ClickHouse/issues/68882)でバックポート: [#50868](https://github.com/ClickHouse/ClickHouse/issues/50868) を修正しました。分散クエリ内のネストされたサブクエリから返される小さな DateTime64 定数値が誤って NULL に変換され、その結果、エラーや誤ったクエリ結果を引き起こす可能性がありました。[#68323](https://github.com/ClickHouse/ClickHouse/pull/68323) ([Shankar](https://github.com/shiyer7474)).
* [#69023](https://github.com/ClickHouse/ClickHouse/issues/69023)でバックポート: 仮想カラム ` _table` と `_database` を分散テーブルに再び追加しました。これらはバージョン 24.3 までは利用可能でした。[#68672](https://github.com/ClickHouse/ClickHouse/pull/68672) ([Anton Popov](https://github.com/CurtizJ)).
* [#68858](https://github.com/ClickHouse/ClickHouse/issues/68858)でバックポート: Variant カラムの並べ替え処理中に発生する可能性があるエラー `Size of permutation (0) is less than required (...)` を修正しました。[#68681](https://github.com/ClickHouse/ClickHouse/pull/68681) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68784](https://github.com/ClickHouse/ClickHouse/issues/68784)でバックポート: 関数 `sipHash(64/128)Keyed` で、キーとして Array を持つ map の hash を計算する際の materialized 定数キーに関する不具合を修正しました。[#68731](https://github.com/ClickHouse/ClickHouse/pull/68731) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* [#69154](https://github.com/ClickHouse/ClickHouse/issues/69154)でバックポート: anyHeavy state のマージ中に誤った結果が返る可能性がある不具合を修正しました。[#68950](https://github.com/ClickHouse/ClickHouse/pull/68950) ([Raúl Marín](https://github.com/Algunenano)).
