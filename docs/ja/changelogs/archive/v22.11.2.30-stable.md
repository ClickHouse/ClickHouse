  #### 後方互換性を持たない変更

* [#43488](https://github.com/ClickHouse/ClickHouse/issues/43488) でバックポート: `String` 引数を持つ `min`、`max`、`any*`、`argMin`、`argMax` aggregate functions の state の (de)serialization における後方互換性の問題を修正しました。この非互換性は [https://github.com/ClickHouse/ClickHouse/pull/41431](https://github.com/ClickHouse/ClickHouse/pull/41431) で導入され、22.9、22.10、22.11 の分岐に影響します (それぞれ 22.9.6、22.10.4、22.11.2 以降で修正済み) 。22.3、22.7、22.8 の分岐における一部のマイナー release も影響を受けます: 22.3.13...22.3.14 (22.3.15 以降で修正済み) 、22.8.6...22.8.9 (22.8.10 以降で修正済み) 、22.7.6 以降 (22.7 では修正されないため、22.7.* から 22.8.10 以降への upgrade を推奨します) 。このリリースノートは、影響を受けるバージョンを一度も使用したことがないユーザーには関係ありません。非互換バージョンでは、上記 aggregate functions の state を読み取る際に、文字列の末尾に余分な `'\0'` が追加されます。たとえば、古いバージョンが `anyState('foobar')` の state を `state_column` に保存した場合、非互換バージョンでは `anyMerge(state_column)` の結果が `'foobar\0'` と表示されます。また、非互換バージョンは aggregate functions の state を末尾の `'\0'` なしで書き込みます。新しいバージョン (この修正を含むもの) は、1 つの特殊なケースを除き、非互換バージョンを含むすべてのバージョンによって書き込まれた data を正しく読み取れます。非互換バージョンが、実際に null 文字で終わる文字列を含む state を保存した場合、新しいバージョンは、影響を受ける aggregate function の state を読み取る際に末尾の `'\0'` を削除します。たとえば、非互換バージョンが `anyState('abrac\0dabra\0')` の state を `state_column` に保存した場合、非互換バージョンでは `anyMerge(state_column)` の結果が `'abrac\0dabra'` と表示されます。この issue は、非互換バージョンが古いバージョンまたは新しいバージョンと同じクラスター内で動作している場合の distributed queries にも影響します。[#43038](https://github.com/ClickHouse/ClickHouse/pull/43038) ([Raúl Marín](https://github.com/Algunenano)).

* [#43511](https://github.com/ClickHouse/ClickHouse/issues/43511)でバックポート: config で定義されたユーザーによる named collections へのデフォルトアクセスを制限しました。これらを参照するには、明示的に `show_named_collections=1` を指定する必要があります。 [#43325](https://github.com/ClickHouse/ClickHouse/pull/43325) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#43716](https://github.com/ClickHouse/ClickHouse/issues/43716) でバックポート: S3 から ClickHouse に Parquetファイルを読み込もうとした際に、以下の例外が発生する問題が報告されていました。 [#43297](https://github.com/ClickHouse/ClickHouse/pull/43297) ([Arthur Passos](https://github.com/arthurpassos)).
* [#43431](https://github.com/ClickHouse/ClickHouse/issues/43431) でバックポート: `Merge` エンジンを使用するテーブルで、PREWHERE 最適化が有効な `SAMPLE BY` を含むクエリを修正しました。 [#43315](https://github.com/ClickHouse/ClickHouse/pull/43315) ([Antonio Andelic](https://github.com/antonio2368)).
* [#43577](https://github.com/ClickHouse/ClickHouse/issues/43577) でバックポート: 関数 if/multiIf で `Cannot create non-empty column with type Nothing` が発生する可能性がある問題を修正しました。 [#43356](https://github.com/ClickHouse/ClickHouse/issues/43356) をクローズ。 [#43368](https://github.com/ClickHouse/ClickHouse/pull/43368) ([Kruglov Pavel](https://github.com/Avogar)).
* [#43507](https://github.com/ClickHouse/ClickHouse/issues/43507) でバックポート: 行レベルのフィルタがカラムのデフォルト値を使用する場合の不具合を修正しました。 [#43387](https://github.com/ClickHouse/ClickHouse/pull/43387) ([Alexander Gololobov](https://github.com/davenger)).
* [#43724](https://github.com/ClickHouse/ClickHouse/issues/43724) でバックポート: `toString(enum)` を含む条件における主キー解析を修正しました。 [#43596](https://github.com/ClickHouse/ClickHouse/pull/43596) ([Nikita Taranov](https://github.com/nickitat)).
* [#43807](https://github.com/ClickHouse/ClickHouse/issues/43807) でバックポート: マージ対象の part を選択する際の ZooKeeper への List リクエスト数を最適化しました。以前は、場合によっては数千件のリクエストが発生することがありました。 [#43647](https://github.com/ClickHouse/ClickHouse/issues/43647) を修正。 [#43675](https://github.com/ClickHouse/ClickHouse/pull/43675) ([Alexander Tokmakov](https://github.com/tavplubix)).
