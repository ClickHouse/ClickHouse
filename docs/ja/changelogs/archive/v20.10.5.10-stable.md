<div id="clickhouse-release-v2010510-stable-fixme-as-compared-to-v201041-stable">
  ### ClickHouse リリース v20.10.5.10-stable FIXME (v20.10.4.1-stableとの比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#17031](https://github.com/ClickHouse/ClickHouse/issues/17031) でバックポート: SNI を必要とする `clickhouse-server` のセキュアエンドポイントに接続できるようになりました。これは、`clickhouse-server` が TLS プロキシの背後でホストされている場合に可能です。 [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#17107](https://github.com/ClickHouse/ClickHouse/issues/17107) でバックポート: [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) および [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) を修正。`if` 接尾辞付きの集約関数を使用した際にリモートクエリが失敗する問題を修正しました。[#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* [#17022](https://github.com/ClickHouse/ClickHouse/issues/17022) でバックポート: 引数なしで `any` を使用した際に発生するクラッシュを修正しました。これは [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803) 向けです。cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* [#16878](https://github.com/ClickHouse/ClickHouse/issues/16878) でバックポート: WriteBufferFromS3 にデータがまったく書き込まれなかった場合、multipart upload を中止するようにしました。[#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#16949](https://github.com/ClickHouse/ClickHouse/issues/16949) でバックポート: TimeSeriesGroupSum 使用時に ClickHouse server がクラッシュしないようにしました。[#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* [#17075](https://github.com/ClickHouse/ClickHouse/issues/17075) でバックポート: `ORDER BY` を含むクエリで発生する可能性がある `Illegal type of argument` エラーを修正しました。[#16580](https://github.com/ClickHouse/ClickHouse/issues/16580) を修正。[#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17008](https://github.com/ClickHouse/ClickHouse/issues/17008) でバックポート: インストールスクリプトが config フォルダー内に常にサブディレクトリーを作成するようにしました。これはカスタム config を使用する Docker ビルドでのみ関係します。[#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* [#16967](https://github.com/ClickHouse/ClickHouse/issues/16967) でバックポート: `clickhouse-git-import` で blame 情報が正しく計算されていませんでした。[#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#17012](https://github.com/ClickHouse/ClickHouse/issues/17012) でバックポート: `ALTER TABLE ... MODIFY COLUMN ... NewType` の後、変更中のカラムに対する `WHERE` 式を含む `SELECT` を実行し、alter がまだ完了していない場合に発生する可能性がある server クラッシュを修正しました。[#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* [#17038](https://github.com/ClickHouse/ClickHouse/issues/17038) でバックポート: エラー発生時に `format_avro_schema_registry_url` の IP を再解決するようにしました。[#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* [#17092](https://github.com/ClickHouse/ClickHouse/issues/17092) でバックポート: double からのキャスト時に big integer (128、256 bit) で誤った結果になる問題を修正しました。[#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc)).
* [#17169](https://github.com/ClickHouse/ClickHouse/issues/17169) でバックポート: リーダーでない ReplicatedMergeTreeTables に対して `ON CLUSTER` クエリが無期限にハングする可能性がある bug を修正しました。[#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
