Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#38453](https://github.com/ClickHouse/ClickHouse/issues/38453) でバックポート: 条件が false の場合でも引数が評価されてしまう、ネストされた短絡評価関数の bug を修正しました。[#38040](https://github.com/ClickHouse/ClickHouse/issues/38040) をクローズしました。[#38173](https://github.com/ClickHouse/ClickHouse/pull/38173) ([Kruglov Pavel](https://github.com/Avogar)).
* [#38710](https://github.com/ClickHouse/ClickHouse/issues/38710) でバックポート: `DISTINCT` と `LIMIT` を含む分散クエリで誤った結果が返る問題を修正しました。[#38282](https://github.com/ClickHouse/ClickHouse/issues/38282) を修正しました。[#38371](https://github.com/ClickHouse/ClickHouse/pull/38371) ([Anton Popov](https://github.com/CurtizJ)).
* [#38689](https://github.com/ClickHouse/ClickHouse/issues/38689) でバックポート: IPv4/IPv6 表現の値が不正なテーブルでも、clickhouse-server を起動し、テーブルを attach/detach できるようになりました。issue [#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) に対する適切な修正です。[#38590](https://github.com/ClickHouse/ClickHouse/pull/38590) ([alesapin](https://github.com/alesapin)).
* [#38776](https://github.com/ClickHouse/ClickHouse/issues/38776) でバックポート: 一部の引数が NaN の場合でも、`rankCorr` function が正しく動作するようになりました。これにより [#38396](https://github.com/ClickHouse/ClickHouse/issues/38396) をクローズしました。[#38722](https://github.com/ClickHouse/ClickHouse/pull/38722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#38780](https://github.com/ClickHouse/ClickHouse/issues/38780) でバックポート: 誤った結果を招く Map combinator の use-after-free を修正しました。[#38748](https://github.com/ClickHouse/ClickHouse/pull/38748) ([Azat Khuzhin](https://github.com/azat)).

#### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)

* [#36818](https://github.com/ClickHouse/ClickHouse/issues/36818)でバックポート: IN サブクエリの使用時に誤ったクエリ結果を招く可能性があるプロジェクション解析を修正しました。これにより [#35336](https://github.com/ClickHouse/ClickHouse/issues/35336) を修正しました。 [#35631](https://github.com/ClickHouse/ClickHouse/pull/35631) ([Amos Bird](https://github.com/amosbird))。
* [#38467](https://github.com/ClickHouse/ClickHouse/issues/38467)でバックポート: - JOINクエリの `WHERE` 句内のリテラルで発生する可能性があるエラーを修正しました。 [#36279](https://github.com/ClickHouse/ClickHouse/issues/36279) をクローズしました。 [#36542](https://github.com/ClickHouse/ClickHouse/pull/36542) ([Vladimir C](https://github.com/vdimir))。
