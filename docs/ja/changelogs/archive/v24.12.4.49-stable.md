* [#74823](https://github.com/ClickHouse/ClickHouse/issues/74823) でバックポート: サーバーのシャットダウン中にリフレッシャブルmaterialized viewでまれに発生するクラッシュを修正しました。[#73323](https://github.com/ClickHouse/ClickHouse/pull/73323) ([Michael Kolupaev](https://github.com/al13n321)).
* [#74381](https://github.com/ClickHouse/ClickHouse/issues/74381) でバックポート: `FINAL` および `SAMPLE` を含むクエリで発生する `NOT_FOUND_COLUMN_IN_BLOCK` を修正しました。`CollapsingMergeTree` に対する `FINAL` 付きの selects で誤った結果になる問題を修正し、`FINAL` の最適化を有効化しました。[#73682](https://github.com/ClickHouse/ClickHouse/pull/73682) ([Anton Popov](https://github.com/CurtizJ)).
* [#74810](https://github.com/ClickHouse/ClickHouse/issues/74810) でバックポート: postgresql および sqlite の table function における SQL 挿入を防ぐためのセキュリティ問題を修正しました。[#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* [#74392](https://github.com/ClickHouse/ClickHouse/issues/74392) でバックポート: ファイルを Failed として設定する際に s3queue で発生する論理エラーを修正しました。[#74216](https://github.com/ClickHouse/ClickHouse/pull/74216) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#75124](https://github.com/ClickHouse/ClickHouse/issues/75124) でバックポート: interval の挿入時に発生するクラッシュを修正しました (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)) 。[#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* [#75097](https://github.com/ClickHouse/ClickHouse/issues/75097) でバックポート: `Tuple` カラムを持つテーブル間の `INSERT SELECT` クエリを修正し、スパースシリアライゼーションを有効化しました。[#74698](https://github.com/ClickHouse/ClickHouse/pull/74698) ([Anton Popov](https://github.com/CurtizJ)).
* [#75309](https://github.com/ClickHouse/ClickHouse/issues/75309) でバックポート: 型名が大文字でない場合に、JSON type 宣言のパース中に発生するクラッシュを修正しました。[#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74869](https://github.com/ClickHouse/ClickHouse/issues/74869) でバックポート: Keeper の修正: ディスクからログエントリを読み込む処理を修正しました。[#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75076](https://github.com/ClickHouse/ClickHouse/issues/75076) でバックポート: BACKUP および RESTORE 操作について、`query_log` 内の `used_privileges` フィールドと `missing_privileges` フィールドが欠落する問題を修正しました。[#74887](https://github.com/ClickHouse/ClickHouse/pull/74887) ([Alexey Katsman](https://github.com/alexkats)).
* [#74957](https://github.com/ClickHouse/ClickHouse/issues/74957) でバックポート: Azure Blob Storage 上の空のカラムを持つテーブルで、データパーツのマージ中に発生する FILE&#95;DOESNT&#95;EXIST error を修正しました。[#74892](https://github.com/ClickHouse/ClickHouse/pull/74892) ([Julia Kartseva](https://github.com/jkartseva)).
* [#75054](https://github.com/ClickHouse/ClickHouse/issues/75054) でバックポート: hdfs の select リクエスト中に sasl error が発生した場合に、HDFS の krb ticket を更新するよう修正しました。[#74930](https://github.com/ClickHouse/ClickHouse/pull/74930) ([inv2004](https://github.com/inv2004)).
* [#75413](https://github.com/ClickHouse/ClickHouse/issues/75413) でバックポート: remove 操作が失敗した場合に、part&#39;s state を deleting から outdated に戻すようにしました。[#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* [#75463](https://github.com/ClickHouse/ClickHouse/issues/75463) にバックポート: Insert を伴う CTE でクラッシュする不具合を修正しました。 [#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).

<div id="buildtestingpackaging-improvement">

* [#75289](https://github.com/ClickHouse/ClickHouse/issues/75289) にバックポート: さらに厳格なデフォルト設定にするための改善。現在のデフォルト設定はすでに安全であり、ポートを公開するにはユーザーが明示的にオプションを指定する必要があります。しかし、`default` ユーザーに `CLICKHOUSE_PASSWORD` でパスワードが設定されておらず、かつ/または `CLICKHOUSE_USER` 環境変数でユーザー名が変更されていない場合は、追加の保護策としてローカルシステムからのみ利用できるようにすべきです。[#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
