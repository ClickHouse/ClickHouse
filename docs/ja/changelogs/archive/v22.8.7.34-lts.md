  ### ClickHouse リリース v22.8.7.34-lts (3c38e5e8ab9) FIXME v22.8.6.71-lts (7bf38a43e30) との比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#42096](https://github.com/ClickHouse/ClickHouse/issues/42096) でバックポート: 起動時に `clickhouse su` コマンドを再び `sudo -u` に置き換え、`/etc/security/limits.conf` の制限が適用されるようにした。[#41847](https://github.com/ClickHouse/ClickHouse/pull/41847) ([Eugene Konkov](https://github.com/ekonkov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#42434](https://github.com/ClickHouse/ClickHouse/issues/42434)でバックポート: - BigInt を含む LowCardinality に対して、正しい集約方法を選択。 [#42342](https://github.com/ClickHouse/ClickHouse/pull/42342) ([Duc Canh Le](https://github.com/canhld94)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#42296](https://github.com/ClickHouse/ClickHouse/issues/42296)でバックポート: cctz を最新の master に更新し、tzdb を 2020e に更新しました。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano))。
* [#42360](https://github.com/ClickHouse/ClickHouse/issues/42360)でバックポート: 新しいtimezoneの変更に対応するため、tzdata を 2022e に更新しました。パレスチナの切り替えは土曜日の 02:00 になりました。ウクライナの 3 つの zones は 1 つに統合されました。ヨルダンとシリアは、DST を伴う +02/+03 から通年 +03 に切り替わります。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS))。これにより [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252) はクローズされます。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov))。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#42489](https://github.com/ClickHouse/ClickHouse/issues/42489) でバックポート: 影響のないパーティションに対する `MergeTree` table の mutations の skipping を削除しました。この機能は一度も正しく動作したことがなく、完了済みの mutations が復活するおそれがあったためです。[#40589](https://github.com/ClickHouse/ClickHouse/pull/40589) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#42121](https://github.com/ClickHouse/ClickHouse/issues/42121) でバックポート: 壊れているものとしてある part を detach した直後にレプリカが再起動すると、ごくまれに発生することがあった &quot;Part ... intersects part ...&quot; エラーを修正しました。[#41741](https://github.com/ClickHouse/ClickHouse/pull/41741) ([Alexander Tokmakov](https://github.com/tavplubix)).
* * groupBitmap* に誤った aggregation states を渡したときにクラッシュしないようにしました。[#41972](https://github.com/ClickHouse/ClickHouse/pull/41972) ([Raúl Marín](https://github.com/Algunenano)).
* * materialized view 使用時の X-ClickHouse-Summary における read bytes/rows を修正しました。[#41973](https://github.com/ClickHouse/ClickHouse/pull/41973) ([Raúl Marín](https://github.com/Algunenano)).
* [#42269](https://github.com/ClickHouse/ClickHouse/issues/42269) でバックポート: base backup から 4GB を超えるファイルを再利用する際の不具合を修正しました。[#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat)).
* [#42300](https://github.com/ClickHouse/ClickHouse/issues/42300) でバックポート: projections と `aggregate_functions_null_for_empty` setting に関する bug を修正しました。この bug は非常にまれで、server の config で `aggregate_functions_null_for_empty` setting を有効にした場合にのみ発生します。これにより [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647) をクローズします。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#42387](https://github.com/ClickHouse/ClickHouse/issues/42387) でバックポート: attached な part (table schema と異なる columns を持つもの) に対する `ALTER UPDATE` により、ディスク上に無効な `columns.txt` メタデータが作成されることがありました。そのような part の読み取りは error で失敗したり、不正な data を返したりする可能性がありました。[#42161](https://github.com/ClickHouse/ClickHouse/issues/42161) を修正します。[#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#42499](https://github.com/ClickHouse/ClickHouse/issues/42499) でバックポート: `additional_table_filters` setting が `Distributed` storage に適用されていませんでした。[#41692](https://github.com/ClickHouse/ClickHouse/issues/41692) を修正します。[#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#42571](https://github.com/ClickHouse/ClickHouse/issues/42571) でバックポート: Decimal data types の処理における buffer overflow を修正しました。これにより [#42451](https://github.com/ClickHouse/ClickHouse/issues/42451) をクローズします。[#42465](https://github.com/ClickHouse/ClickHouse/pull/42465) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#42594](https://github.com/ClickHouse/ClickHouse/issues/42594) でバックポート: これにより [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453) をクローズします。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
