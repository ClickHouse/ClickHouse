  ### ClickHouse リリース v20.10.4.1-stable FIXME (v20.10.3.30-stable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* nginx サーバーをプロキシとして使用して S3 を利用する際の回避策。現在の Nginx は、[http://domain.com?delete](http://domain.com?delete) のような空のパスを持つ URL を受け付けませんが、素の aws-sdk-cpp はこの種の URL を生成します。このコミットでは、こうした場合に [http://domain.com/?delete](http://domain.com/?delete) のようにパスとして &quot;/&quot; を含む URL を生成する、パッチ適用済みの aws-sdk-cpp バージョンを使用します。[#16813](https://github.com/ClickHouse/ClickHouse/pull/16813) ([ianton-ru](https://github.com/ianton-ru)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#16492](https://github.com/ClickHouse/ClickHouse/issues/16492)でバックポート: MySQL データベースに関する不具合を修正しました。データベースエンジンとして使用されている MySQL サーバーが停止すると、無効化されたサーバーからテーブルを取得しようとしてしまうため、一部のクエリで Exception が発生していました。これは不要な動作です。たとえば、クエリ `SELECT ... FROM system.parts` は MergeTree テーブルに対してのみ動作し、MySQL データベースにはまったくアクセスしないはずです。 [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* [#16710](https://github.com/ClickHouse/ClickHouse/issues/16710)でバックポート: フィルタリング用のセットが作成されなかったため、返却データの一部が欠落することがあった一貫性のない動作を修正しました。 [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16505](https://github.com/ClickHouse/ClickHouse/issues/16505)でバックポート: レプリケーションキュー内の非常に大きなエントリの処理を修正しました。テーブル構造が極端に大きい場合 (1 MB 近く) 、ALTER クエリで非常に大きなエントリが発生することがあります。これにより [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307) を修正します。 [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#16471](https://github.com/ClickHouse/ClickHouse/issues/16471)でバックポート: Distributed に対する DROP TABLE を修正しました (INSERT との競合状態) 。 [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* [#16572](https://github.com/ClickHouse/ClickHouse/issues/16572)でバックポート: MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine を使用し、かつ MySQL Slave で `slave_parallel_worker` が有効な場合に、GTID セットを適切に縮小することでメタデータが急増する問題を修正しました。これにより [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951) を修正します。 [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* [#16551](https://github.com/ClickHouse/ClickHouse/issues/16551)でバックポート: 入力から AVRO をパースする際、型から LowCardinality が削除されるようになりました。 [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188) を修正します。 [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* [#16749](https://github.com/ClickHouse/ClickHouse/issues/16749)でバックポート: [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081) を修正しました。 [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16760](https://github.com/ClickHouse/ClickHouse/issues/16760)でバックポート: max&#95;threads&gt;0 かつ ORDER BY に式がある場合の optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order を修正します。 [#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* [#16741](https://github.com/ClickHouse/ClickHouse/issues/16741)でバックポート: `transform_null_in` 設定が有効な場合の、複数カラムおよびタプルに対する `IN` 演算子を修正しました。 [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310) を修正します。 [#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* [#16893](https://github.com/ClickHouse/ClickHouse/issues/16893) でバックポート: クエリプロファイラが有効な状態で、ClickHouse を、一部の関数で (おそらく) 壊れた非同期アンワインドテーブルを持つ glibc バージョンの OS にインストールしている場合、まれにサイレントクラッシュが発生する問題を修正しました。これにより [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301) も修正されます。これにより [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098) も修正されます。[#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
