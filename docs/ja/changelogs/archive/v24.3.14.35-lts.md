<div id="improvement">
  #### 改善
</div>

* [#71711](https://github.com/ClickHouse/ClickHouse/issues/71711) でバックポート: clickhouse イメージの entrypoint で、`CLICKHOUSE_PASSWORD` が XML 向けにエスケープされるようになりました。[#69301](https://github.com/ClickHouse/ClickHouse/pull/69301) ([aohoyd](https://github.com/aohoyd)).
* [#71662](https://github.com/ClickHouse/ClickHouse/issues/71662) でバックポート: ユーザー/グループを ID で指定すると、`clickhouse su` が失敗していました。このパッチにより、`UID:GID` 形式も受け付けるよう修正されました。 ### ユーザー向け変更のドキュメント用エントリ。[#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#65755](https://github.com/ClickHouse/ClickHouse/issues/65755)でバックポート: `GLOBAL IN.` への別名を持つクエリで発生する `Expression nodes list expected 1 projection names` および `Unknown expression or identifier` エラーを修正。 [#64517](https://github.com/ClickHouse/ClickHouse/pull/64517) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#71600](https://github.com/ClickHouse/ClickHouse/issues/71600)でバックポート: Variant カラムで発生する `Invalid number of rows in Chunk` エラーを修正。 [#71388](https://github.com/ClickHouse/ClickHouse/pull/71388) ([Pavel Kruglov](https://github.com/Avogar)).
* [#71842](https://github.com/ClickHouse/ClickHouse/issues/71842)でバックポート: optimize&#95;rewrite&#95;array&#95;exists&#95;to&#95;has 使用時のクラッシュを修正。 [#71432](https://github.com/ClickHouse/ClickHouse/pull/71432) ([Raúl Marín](https://github.com/Algunenano)).
* [#71562](https://github.com/ClickHouse/ClickHouse/issues/71562)でバックポート: 制約で UDF を使用した際に発生するクラッシュを回避。 [#71541](https://github.com/ClickHouse/ClickHouse/pull/71541) ([Raúl Marín](https://github.com/Algunenano)).
* [#71731](https://github.com/ClickHouse/ClickHouse/issues/71731)でバックポート: bitShift 関数で範囲外となった場合、エラーをスローする代わりに 0 またはデフォルト文字を返すよう修正。 [#71580](https://github.com/ClickHouse/ClickHouse/pull/71580) ([Pablo Marcos](https://github.com/pamarcos)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#71697](https://github.com/ClickHouse/ClickHouse/issues/71697)でバックポート: Rust の依存関係をベンダリング。 [#62297](https://github.com/ClickHouse/ClickHouse/pull/62297) ([Raúl Marín](https://github.com/Algunenano)).
* [#71688](https://github.com/ClickHouse/ClickHouse/issues/71688)でバックポート: clickhouse-server の Dockerfile.ubuntu を改善。`CLICKHOUSE_UID/CLICKHOUSE_GID` 環境変数を非推奨化。要件に準拠するため、`CLICKHOUSE_DOCKER_RESTART_ON_EXIT` の処理を削除。ある箇所ではそのままの名前、別の箇所では `/usr/bin/clickhouse*` という形にならないよう、`clickhouse/clickhouse-server/clickhouse-keeper` の実行方法を統一。 [#71573](https://github.com/ClickHouse/ClickHouse/pull/71573) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
