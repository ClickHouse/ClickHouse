  ### ClickHouse リリース v21.6.1.6891-prestable FIXME (v21.5.1.6601-prestable との比較)

<div id="new-feature">
  #### 新機能
</div>

* MergeTree* テーブルでプロジェクションをサポートしました。[#20202](https://github.com/ClickHouse/ClickHouse/pull/20202) ([Amos Bird](https://github.com/amosbird)).
* `indexHint` 関数を復活させました。これは [#21238](https://github.com/ClickHouse/ClickHouse/issues/21238) に対応するものです。これにより [https://github.com/ClickHouse/ClickHouse/pull/9542](https://github.com/ClickHouse/ClickHouse/pull/9542) を元に戻します。これで [#9540](https://github.com/ClickHouse/ClickHouse/issues/9540) を修正します。[#21304](https://github.com/ClickHouse/ClickHouse/pull/21304) ([Amos Bird](https://github.com/amosbird)).
* 1. 集約関数 sumCount を追加しました。この関数は、sum と count の 2 つのフィールドからなるタプルを返します。[#21337](https://github.com/ClickHouse/ClickHouse/pull/21337) ([hexiaoting](https://github.com/hexiaoting)).
* Docker 上で正しく動作する、S3 向けの安全性が低い IMDS 認証情報プロバイダーを追加しました。 [#21852](https://github.com/ClickHouse/ClickHouse/pull/21852) ([Vladimir Chebotarev](https://github.com/excitoon)).
* * タイムスタンプを保持することで、マージ時の順序を維持しつつ連続する行の差分を合計できる新しい集約関数 `deltaSumTimestamp`。 [#21888](https://github.com/ClickHouse/ClickHouse/pull/21888) ([Russ Frank](https://github.com/rf)).
* * LDAP: Active Directory グループを ClickHouse ロールにマッピングする際に使用するユーザー DN 検出機能を実装しました。 [#22228](https://github.com/ClickHouse/ClickHouse/pull/22228) ([Denis Glazachev](https://github.com/traceon)).
* 新しい関数 `arrayProduct` を導入しました。これは配列をパラメータとして受け取り、配列内のすべての要素の積を返します。[#21613](https://github.com/ClickHouse/ClickHouse/issues/21613) をクローズしました。 [#22242](https://github.com/ClickHouse/ClickHouse/pull/22242) ([hexiaoting](https://github.com/hexiaoting)).
* `EXPLAIN PIPELINE` クエリに設定 `indexes` (ブール値、デフォルトでは無効) を追加しました。有効にすると、適用された各索引について、使用された索引、フィルタされたパーツ数、およびグラニュール数を表示します。`MergeTree*` テーブルでサポートされます。 [#22352](https://github.com/ClickHouse/ClickHouse/pull/22352) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `EXPLAIN PLAN` クエリに設定 `json` (ブール値、デフォルトは 0) を追加しました。有効にすると、クエリ出力は `JSON` の単一行になります。不要なエスケープを避けるため、`TSVRaw` フォーマットの使用を推奨します。 [#23082](https://github.com/ClickHouse/ClickHouse/pull/23082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `SYSTEM QUERY RELOAD MODEL`、`SYSTEM QUERY RELOAD MODELS` を追加しました。[#18722](https://github.com/ClickHouse/ClickHouse/issues/18722) をクローズしました。 [#23182](https://github.com/ClickHouse/ClickHouse/pull/23182) ([Maksim Kita](https://github.com/kitaisreal)).
* LocalServer 用のプログレスバーを作成し、Client と Local で共通化しました。 [#23196](https://github.com/ClickHouse/ClickHouse/pull/23196) ([Egor Savin](https://github.com/Amesaru)).
* DatabaseMemory で DDL Dictionary をサポートしました。[#22354](https://github.com/ClickHouse/ClickHouse/issues/22354) をクローズしました。`DETACH DICTIONARY PERMANENTLY` をサポートしました。atomic データベースエンジンで `EXCHANGE DICTIONARIES` をサポートしました。`RENAME DICTIONARY` を使用してデータベース間で Dictionary を移動できるようにしました。 [#23436](https://github.com/ClickHouse/ClickHouse/pull/23436) ([Maksim Kita](https://github.com/kitaisreal)).
* URL テーブル関数で、分片のように機能する glob `{...}` と、区切り文字 `|` を使った failover オプションを許可しました。[#17181](https://github.com/ClickHouse/ClickHouse/issues/17181) をクローズしました。 [#23446](https://github.com/ClickHouse/ClickHouse/pull/23446) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `insert_null_as_default` = 1 の場合、`INSERT ... SELECT` および `INSERT ... SELECT ... UNION ALL ...` クエリで、NULL の代わりにデフォルト値を挿入します。[#22832](https://github.com/ClickHouse/ClickHouse/issues/22832) をクローズしました。 [#23524](https://github.com/ClickHouse/ClickHouse/pull/23524) ([Kseniia Sumarokova](https://github.com/kssenii)).
* テーブルコメントを実装しました。[#23225](https://github.com/ClickHouse/ClickHouse/issues/23225) をクローズしました。 [#23548](https://github.com/ClickHouse/ClickHouse/pull/23548) ([flynn](https://github.com/ucasfl)).
* 新しい関数 `arrayProduct` を導入しました。これは配列をパラメータとして受け取り、配列内のすべての要素の積を返します。[#21613](https://github.com/ClickHouse/ClickHouse/issues/21613) をクローズしました。 [#23782](https://github.com/ClickHouse/ClickHouse/pull/23782) ([Maksim Kita](https://github.com/kitaisreal)).
* Postgres 風の CAST 演算子 (`::`) を追加しました。例: `[1, 2]::Array(UInt8)`、`0.1::Decimal(4, 4)`、`number::UInt16`。 [#23871](https://github.com/ClickHouse/ClickHouse/pull/23871) ([Anton Popov](https://github.com/CurtizJ)).
* ... [#23910](https://github.com/ClickHouse/ClickHouse/pull/23910) ([Xiang Zhou](https://github.com/javainthinking)).
* 関数 `splitByRegexp` を追加しました。 [#24077](https://github.com/ClickHouse/ClickHouse/pull/24077) ([abel-cheng](https://github.com/abel-cheng)).
* `system.stack_trace` に `thread_name` カラムを追加しました。これにより [#23256](https://github.com/ClickHouse/ClickHouse/issues/23256) が解決されます。[#24124](https://github.com/ClickHouse/ClickHouse/pull/24124) ([abel-cheng](https://github.com/abel-cheng)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* `compile_expressions` 設定をデフォルトで有効にしました。この設定が有効な場合、単純な関数と演算子の組み合わせは、実行時に LLVM によってネイティブコードにコンパイルされます。[#8482](https://github.com/ClickHouse/ClickHouse/pull/8482) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ORC 入力フォーマットの読み取りで、テーブル全体を一度にメモリに読み込むのではなく、ストライプ単位で読み込むようにしました。これにより、ファイルサイズが大きい場合のメモリ消費を抑えられます。[#23102](https://github.com/ClickHouse/ClickHouse/pull/23102) ([Chao Ma](https://github.com/godliness)).
* `re2` ライブラリを更新しました。正規表現マッチングのパフォーマンスが向上しています。また、この PR では gcc-11 との互換性も追加されています。[#24196](https://github.com/ClickHouse/ClickHouse/pull/24196) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### 改善
</div>

* Arrow、Parquet、ORC フォーマットでのデータの挿入と選択について、Array データ型をサポートしました。[#21770](https://github.com/ClickHouse/ClickHouse/pull/21770) ([taylor12805](https://github.com/taylor12805)).
* MySQL table engine、Dictionary ソース、および MaterializeMySQL の軽微なデータフェッチ向けに、設定 `external_storage_max_read_rows` と `external_storage_max_read_rows` を追加しました。[#22697](https://github.com/ClickHouse/ClickHouse/pull/22697) ([TCeason](https://github.com/TCeason)).
* S3 で HTTP 接続が切断された場合の再試行。[#22988](https://github.com/ClickHouse/ClickHouse/pull/22988) ([Vladimir Chebotarev](https://github.com/excitoon)).
* clickhouse-client の対話型モードで、データの途中に表示されるプログレスバーによって、ターミナル上の表示データの一部が上書きされることがある問題を修正しました。これにより [#19283](https://github.com/ClickHouse/ClickHouse/issues/19283) をクローズします。[#23050](https://github.com/ClickHouse/ClickHouse/pull/23050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* DiskS3 で、MergeTree パーツを &#39;detached&#39; directory に restore できるようになりました。[#23112](https://github.com/ClickHouse/ClickHouse/pull/23112) ([Pavel Kovalenko](https://github.com/Jokser)).
* 分散テーブルへの書き込み時に、利用できないレプリカをスキップします。[#23152](https://github.com/ClickHouse/ClickHouse/pull/23152) ([Amos Bird](https://github.com/amosbird)).
* `join_use_nulls` で LowCardinality の NULL 許容をサポートし、[#15101](https://github.com/ClickHouse/ClickHouse/issues/15101) をクローズしました。[#23237](https://github.com/ClickHouse/ClickHouse/pull/23237) ([Vladimir C](https://github.com/vdimir)).
* 問題を引き起こす可能性があることが確認されたため、設定 `use_hedged_requests` と `async_socket_for_remote` を無効化しました。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantile(s)TDigest` を修正しました。tdunning/t-digest 3.2+ に従って singleton centroid の特別処理を追加しました。あわせて、以前のバージョンのアルゴリズム実装における centroid の過剰圧縮のバグも修正しました。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).
* `MySQL` storage で、データベース名の代わりに空文字列を指定できるようになりました。クエリにはデフォルトデータベースが使用されます。以前のバージョンではこれは SELECT クエリでのみ動作していましたが、INSERT のサポートも追加されました。これにより [#19281](https://github.com/ClickHouse/ClickHouse/issues/19281) をクローズします。これは `Sphinx` やその他の MySQL 互換外部データベースを扱う際に便利です。[#23319](https://github.com/ClickHouse/ClickHouse/pull/23319) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* デフォルトで min&#95;bytes&#95;to&#95;use&#95;mmap&#95;io を無効にしました。[#23322](https://github.com/ClickHouse/ClickHouse/pull/23322) ([Azat Khuzhin](https://github.com/azat)).
* ユーザーが誤って `max_distributed_connections` を 0 に設定した場合、`Distributed` table へのすべてのクエリで &quot;logical error&quot; を含むメッセージの例外が発生していました。しかし、これは実際には想定された動作であり、論理エラーではないため、例外メッセージはやや不正確でした。また、論理エラーが決して発生しないことを保証する CI 環境のチェックもトリガーしていました。今後は、`max_distributed_connections` が 0 に誤設定されている場合、取り得る最小値である 1 として扱います。[#23348](https://github.com/ClickHouse/ClickHouse/pull/23348) ([Azat Khuzhin](https://github.com/azat)).
* 明示的に指定されていない場合、`DateTime` の操作ではデフォルトのタイムゾーンを維持するようにしました。たとえば、タイムゾーンなしの `DateTime` 型の値に 1 秒加えても、引き続きタイムゾーンなしの `DateTime` のままです。以前のバージョンでは、返されるデータ型にデフォルトのタイムゾーン値が明示的に設定されるため、DateTime(&#39;something&#39;) になっていました。これにより [#4854](https://github.com/ClickHouse/ClickHouse/issues/4854) をクローズします。[#23392](https://github.com/ClickHouse/ClickHouse/pull/23392) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 以前は SQL の非互換性により MySQL 5.7.9 をサポートしていませんでした。現在は、MySQL パラメータの検証を MaterializeMySQL に任せるようにしました。[#23413](https://github.com/ClickHouse/ClickHouse/pull/23413) ([TCeason](https://github.com/TCeason)).
* 新しい `SYSTEM RESTART DISK` SQL コマンドにより、runtime に S3 ディスク設定を変更できるようになりました。[#23429](https://github.com/ClickHouse/ClickHouse/pull/23429) ([Pavel Kovalenko](https://github.com/Jokser)).
* OPTIMIZE で lock&#95;acquire&#95;timeout&#95;for&#95;background&#95;operations を尊重するようにしました。[#23623](https://github.com/ClickHouse/ClickHouse/pull/23623) ([Azat Khuzhin](https://github.com/azat)).
* 大きな整数を production で利用可能にしました。`UInt128` data type のサポートを追加しました。`Decimal256` data type に関する既知の問題を修正しました。Dictionaries で大きな整数をサポートしました。大きな整数に対する `gcd`/`lcm` Functions をサポートしました。Array の検索および条件関数で大きな整数をサポートしました。`LowCardinality(UUID)` をサポートしました。`generateRandom` table function と `clickhouse-obfuscator` で大きな整数をサポートしました。scalar subqueries から `UUID` を返す際のエラーを修正しました。これにより [#7834](https://github.com/ClickHouse/ClickHouse/issues/7834) を修正します。これにより [#23936](https://github.com/ClickHouse/ClickHouse/issues/23936) を修正します。これにより [#4176](https://github.com/ClickHouse/ClickHouse/issues/4176) を修正します。これにより [#24018](https://github.com/ClickHouse/ClickHouse/issues/24018) を修正します。これにより [#17828](https://github.com/ClickHouse/ClickHouse/issues/17828) を修正します。後方互換性を持たない変更: `UUID` 型の値は整数と比較できなくなりました。たとえば、`uuid != 0` と書く代わりに `uuid != '00000000-0000-0000-0000-000000000000'` としてください。[#23631](https://github.com/ClickHouse/ClickHouse/pull/23631) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `_partition_value` 仮想カラムを MergeTree table family に追加しました。これにより、決定論的な方法でパーティションをプルーニングできます。これは mutations 向けの partition matcher を実装するために必要です。[#23673](https://github.com/ClickHouse/ClickHouse/pull/23673) ([Amos Bird](https://github.com/amosbird)).
* `async_socket_for_remote` をデフォルトで有効にしました。[#23683](https://github.com/ClickHouse/ClickHouse/pull/23683) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* ZooKeeper のセッションが期限切れになった `ReplicatedMergeTree` テーブルが存在する場合、`select_sequential_consistency` が有効な状態で `system.tables` から一部のテーブルのメタデータを取得すると、以下のエラーがスローされます: `Session expired (Session expired): While executing Tables`。[#23793](https://github.com/ClickHouse/ClickHouse/pull/23793) ([Fuwang Hu](https://github.com/fuwhu)).
* S3 storage とディスクに `region` parameter を追加しました。[#23846](https://github.com/ClickHouse/ClickHouse/pull/23846) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 異なるログチャネルごとに異なるログレベルを設定できるようにしました。[#19569](https://github.com/ClickHouse/ClickHouse/issues/19569) をクローズします。[#23857](https://github.com/ClickHouse/ClickHouse/pull/23857) ([filimonov](https://github.com/filimonov)).
* `system.distribution_queue` に `broken_data_files`/`broken_data_compressed_bytes` を追加しました。破損としてマークされた分散テーブルへの非同期挿入ファイル数を表すメトリクス (`BrokenDistributedFilesToInsert`) も追加しました。[#23885](https://github.com/ClickHouse/ClickHouse/pull/23885) ([Azat Khuzhin](https://github.com/azat)).
* テーブル設定 `rabbitmq_queue_settings_list` を使って、個別の queue 設定を追加できるようにしました。 ([#23737](https://github.com/ClickHouse/ClickHouse/issues/23737) および [#23918](https://github.com/ClickHouse/ClickHouse/issues/23918) をクローズ) 。また、RabbitMQ のセットアップ全体をユーザーが制御できるようにしました。テーブル設定 `rabbitmq_queue_consume` を `1` に設定すると、RabbitMQ table engine は指定された queue にのみ接続し、exchange、queues、bindings の宣言など、RabbitMQ コンシューマー側のセットアップは行いません。 ([#21757](https://github.com/ClickHouse/ClickHouse/issues/21757) をクローズ) 。さらに、RabbitMQ テーブルの削除時に適切にクリーンアップするようにしました。テーブルによって作成されたものである場合、そのテーブルが宣言した queues と、それらにバインドされたすべての exchanges を削除します。[#23887](https://github.com/ClickHouse/ClickHouse/pull/23887) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Dictionaries について、found rate (値が見つかった割合) を計測するようにしました (`system.dictionaries` の `found_rate` を参照) 。[#23916](https://github.com/ClickHouse/ClickHouse/pull/23916) ([Azat Khuzhin](https://github.com/azat)).
* Enum 名に対する hints を追加しました。[#17112](https://github.com/ClickHouse/ClickHouse/issues/17112) をクローズ。[#23919](https://github.com/ClickHouse/ClickHouse/pull/23919) ([flynn](https://github.com/ucasfl)).
* `http` Dictionary ソースで HTTP 圧縮 (`Content-Encoding` HTTP header により判定) をサポートしました。これにより [#8912](https://github.com/ClickHouse/ClickHouse/issues/8912) を修正します。[#23946](https://github.com/ClickHouse/ClickHouse/pull/23946) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* hashed/sparse&#95;hashed dictionaries の事前割り当てをサポートしました。[#23979](https://github.com/ClickHouse/ClickHouse/pull/23979) ([Azat Khuzhin](https://github.com/azat)).
* postgresql Dictionary ソースで table schema を指定できるようにしました。[#23958](https://github.com/ClickHouse/ClickHouse/issues/23958) をクローズ。[#23980](https://github.com/ClickHouse/ClickHouse/pull/23980) ([Kseniia Sumarokova](https://github.com/kssenii)).
* server 起動時に、OS 名、カーネルバージョン、CPU アーキテクチャの情報をログに記録するようにしました。[#23988](https://github.com/ClickHouse/ClickHouse/pull/23988) ([Azat Khuzhin](https://github.com/azat)).
* DateTime64 を ReplacingMergeTree のバージョンカラムとして使えるようにしました。[#23992](https://github.com/ClickHouse/ClickHouse/pull/23992) ([kevin wan](https://github.com/MaxWk)).
* `DateTime64` で `ORDER BY WITH FILL` をサポートしました。[#24016](https://github.com/ClickHouse/ClickHouse/pull/24016) ([kevin wan](https://github.com/MaxWk)).
* `prefer_column_name_to_alias = 1` で、`group by`、`having`、`order by` でもカラム名が優先されるようになりました。これにより [#23882](https://github.com/ClickHouse/ClickHouse/issues/23882) を修正します。[#24022](https://github.com/ClickHouse/ClickHouse/pull/24022) ([Amos Bird](https://github.com/amosbird)).
* Buffer engine で total&#95;bytes/total&#95;rows に対するロックを取得しないようにしました。[#24066](https://github.com/ClickHouse/ClickHouse/pull/24066) ([Azat Khuzhin](https://github.com/azat)).
* tables をシャットダウンする前に (同一 database 内で) Buffer table を flush するようにしました。これにより、基になるテーブルがすでにデタッチされているために blocks が破棄されること (およびログに `Destination table default.a_data_01870 doesn't exist. Block of data is discarded` エラーが出ること) を防ぎます。[#24067](https://github.com/ClickHouse/ClickHouse/pull/24067) ([Azat Khuzhin](https://github.com/azat)).
* ストレージのシャットダウンまで dictionaries を保持するようにしました (これにより、最後の Buffer flush 中にサーバーをシャットダウンした際に発生する可能性のある `external dictionary 'DICT' not found` エラーを回避できます) 。 [#24068](https://github.com/ClickHouse/ClickHouse/pull/24068) ([Azat Khuzhin](https://github.com/azat)).
* zstd を v1.5.0 に更新しました。 [#24135](https://github.com/ClickHouse/ClickHouse/pull/24135) ([Raúl Marín](https://github.com/Algunenano)).
* simdjson でメモリ割り当てに失敗したときに発生する crash を修正しました。 [https://github.com/simdjson/simdjson/pull/1567](https://github.com/simdjson/simdjson/pull/1567) 。まれなバグであるため、改善として分類しました。 [#24147](https://github.com/ClickHouse/ClickHouse/pull/24147) ([Amos Bird](https://github.com/amosbird)).
