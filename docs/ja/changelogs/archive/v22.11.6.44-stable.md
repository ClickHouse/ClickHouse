<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#45903](https://github.com/ClickHouse/ClickHouse/issues/45903)でバックポート: table メタデータ内の EPHEMERAL カラムで、デフォルト値をパースできない不具合を修正しました。 [#44026](https://github.com/ClickHouse/ClickHouse/pull/44026) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#46239](https://github.com/ClickHouse/ClickHouse/issues/46239)でバックポート: `c-ares` 周辺でいくつかの segfault が報告されていました。最近観測された stack trace は、いずれも `std::unodered_set<>` への挿入時に失敗しています。この根本原因は、未処理の queries にあると考えられます。この PR 以前は、CH は `c-ares` channel 内の file descriptor を待機するために `poll` を呼び出していました。[poll docs](https://man7.org/linux/man-pages/man2/poll.2.html) によると、戻り値が負の場合は error の発生を意味します。そのため、実行を中断して失敗を返していました。問題は、システム割り込みが発生した場合にも `poll` が負の値を返すことです。システム割り込みは processing の失敗や終了を意味しませんが、負の値をチェックしていたため、それでも中断していました。実行が中断されるとスタック全体が破棄され、その中には c-ares callback の `void *` parameter に渡された `std::unordered_set<std::string>` も含まれます。c-ares がリクエストを完了すると callback が呼び出され、無効なメモリアドレスにアクセスして segfault を引き起こしていました。 [#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos)).
* [#46216](https://github.com/ClickHouse/ClickHouse/issues/46216)でバックポート: compact パーツで、複数レベルの存在しないネストされたカラムの読み取りを修正しました。 [#46045](https://github.com/ClickHouse/ClickHouse/pull/46045) ([Azat Khuzhin](https://github.com/azat)).
* [#46444](https://github.com/ClickHouse/ClickHouse/issues/46444)でバックポート: フォーマット `VALUES` で送信された無効なデータによって非同期挿入で発生しうる `LOGICAL_ERROR` を修正しました。 [#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ)).
* [#46676](https://github.com/ClickHouse/ClickHouse/issues/46676)でバックポート: 関数 `arrayMap` における定数 `LowCardinality` argument の不正な processing を修正しました。この bug は、release では segfault を、debug build では論理エラー `Bad cast` を引き起こす可能性がありました。 [#46569](https://github.com/ClickHouse/ClickHouse/pull/46569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
