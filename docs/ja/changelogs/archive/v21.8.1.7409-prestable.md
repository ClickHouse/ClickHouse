<div id="backward-incompatible-change">

<div id="new-feature">
  #### 新機能
</div>

* カスタム設定をデフォルト値にリセットし、テーブルのメタデータから削除できるようにしました。これにより、システムや設定のデフォルト値を知らなくても変更をロールバックできます。[#14449](https://github.com/ClickHouse/ClickHouse/issues/14449) を修正しました。[#17769](https://github.com/ClickHouse/ClickHouse/pull/17769) ([xjewer](https://github.com/xjewer)).
* MaterializedPostgreSQL テーブルエンジンおよびデータベースエンジンを追加しました。データベースエンジンにより、データベース全体またはデータベース内のテーブルの一部をレプリケートできます。[#20470](https://github.com/ClickHouse/ClickHouse/pull/20470) ([Kseniia Sumarokova](https://github.com/kssenii)).
* SQLJSON 標準の一部をサポートしました。[#24148](https://github.com/ClickHouse/ClickHouse/pull/24148) ([l1tsolaiki](https://github.com/l1tsolaiki)).
* CPU usage、Disk usage、memory usage、I/O、ネットワーク、ファイル、load average、CPU frequencies、thermal sensors、EDAC counters、system uptime に関する一般的なシステムメトリクスを `system.asynchronous_metrics` および `system.asynchronous_metric_log` で収集するようにしました。あわせて、scheduling jitter やメトリクス収集に要した時間に関するメトリクスも追加しました。これは ClickHouse における `atop` のように機能し、追加ツールをインストールしていなくても監視データを取得できます。[#9430](https://github.com/ClickHouse/ClickHouse/issues/9430) を修正しました。[#24416](https://github.com/ClickHouse/ClickHouse/pull/24416) ([Yegor Levankov](https://github.com/elevankoff)).
* `DISTINCT ON (columns)` 式をサポートしました。[#25404](https://github.com/ClickHouse/ClickHouse/issues/25404) を修正しました。[#25589](https://github.com/ClickHouse/ClickHouse/pull/25589) ([Zijie Lu](https://github.com/TszKitLo40)).
* * `mapAdd` および `mapSubtract` 関数で Map type をサポート * `mapAdd` および `mapSubtract` 関数で (U)Int128、U(Int256) 型をサポート。[#25596](https://github.com/ClickHouse/ClickHouse/pull/25596) ([Ildus Kurbangaliev](https://github.com/ildus)).
* bin/unbin 関数をサポートしました。[#25609](https://github.com/ClickHouse/ClickHouse/pull/25609) ([zhaoyu](https://github.com/zxc111)).
* 既存のデータスキッピングインデックスに関する情報を含む `system.data_skipping_indices` テーブルを導入しました。[#7659](https://github.com/ClickHouse/ClickHouse/issues/7659) を修正しました。[#25693](https://github.com/ClickHouse/ClickHouse/pull/25693) ([Dmitry Novik](https://github.com/novikd)).
* [https://github.com/ClickHouse/ClickHouse/pull/12073](https://github.com/ClickHouse/ClickHouse/pull/12073) に加えて、ADD INDEX コマンドに FIRST キーワードを追加し、インデックス リストの先頭に index を追加できるようにしました。[#25904](https://github.com/ClickHouse/ClickHouse/pull/25904) ([xjewer](https://github.com/xjewer)).
* `EXPLAIN PIPELINE graph = 1` クエリが指定された場合、web UI で pipelines を graph として表示するようにしました。[#26067](https://github.com/ClickHouse/ClickHouse/pull/26067) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新しい関数 `leftPad()`, `rightPad()`, `leftPadUTF8()`, `rightPadUTF8()` を追加しました。[#26075](https://github.com/ClickHouse/ClickHouse/pull/26075) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* `compile_aggregate_expressions` 設定が有効な場合に、集約関数をコンパイルするオプションを追加しました。[#24789](https://github.com/ClickHouse/ClickHouse/pull/24789) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="improvement">
  #### 改善
</div>

* `StorageMerge` の `Database` 引数で正規表現をサポートしました。これにより #776 をクローズします。[#25064](https://github.com/ClickHouse/ClickHouse/pull/25064) ([flynn](https://github.com/ucasfl)).
* JSONExtract を使用して、文字列以外の要素も文字列として抽出できるようにしました。これは [#25414](https://github.com/ClickHouse/ClickHouse/issues/25414) に対応するものです。[#25452](https://github.com/ClickHouse/ClickHouse/pull/25452) ([Amos Bird](https://github.com/amosbird)).
* バックグラウンドジョブ実行用プールのスレッド数 (merges、mutations、fetches) を変更するための、config の動的リロードをサポートしました。[#25548](https://github.com/ClickHouse/ClickHouse/pull/25548) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* StorageS3 および StorageHDFS で TRUNCATE TABLE をサポートしました。[#25530](https://github.com/ClickHouse/ClickHouse/issues/25530) をクローズします。[#25550](https://github.com/ClickHouse/ClickHouse/pull/25550) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `NetworkReceiveElapsedMicroseconds` メトリックに、クライアントから INSERT 用データが届くのを待機していた時間が正しく含まれるようにしました。これにより [#9958](https://github.com/ClickHouse/ClickHouse/issues/9958) をクローズします。[#25602](https://github.com/ClickHouse/ClickHouse/pull/25602) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ALTER TABLE ... DETACH` とバックグラウンド merges の間で発生しうる論理的な race condition を修正しました。[#25605](https://github.com/ClickHouse/ClickHouse/pull/25605) ([Azat Khuzhin](https://github.com/azat)).
* joins で materialized カラムと alias カラムをサポートしました。[#13274](https://github.com/ClickHouse/ClickHouse/issues/13274) をクローズします。[#25634](https://github.com/ClickHouse/ClickHouse/pull/25634) ([Vladimir C](https://github.com/vdimir)).
* MaterializeMySQL が `ENUM` データ型をサポートするようになりました。[#25676](https://github.com/ClickHouse/ClickHouse/pull/25676) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* `ReplicatedMergeTree` において、`DROP PARTITION` および `TRUNCATE` 時に、そのパーティション内ですでに実行中の merges をキャンセルするようにしました。[#17151](https://github.com/ClickHouse/ClickHouse/issues/17151) を解決します。[#25684](https://github.com/ClickHouse/ClickHouse/pull/25684) ([Alexander Tokmakov](https://github.com/tavplubix)).
* system logs テーブル (`system.query_log`、`system.query_thread_log`、`system.processes`、`system.opentelemetry_span_log`) のキー・バリュー dictionaries に `Map` データ型を使用するようにしました。古いクエリとの互換性のため、仮想カラムも作成されます。[#18698](https://github.com/ClickHouse/ClickHouse/issues/18698) をクローズします。Authors @hexiaoting, @sundy-li. [#25773](https://github.com/ClickHouse/ClickHouse/pull/25773) ([Maksim Kita](https://github.com/kitaisreal)).
* empty set に対する GROUP BY 定数の動作の不整合を修正しました。[#6842](https://github.com/ClickHouse/ClickHouse/issues/6842) をクローズします。[#25786](https://github.com/ClickHouse/ClickHouse/pull/25786) ([Kseniia Sumarokova](https://github.com/kssenii)).
* MySQL Engine が、MySQL と ClickHouse 間でのカラム comment のやり取りをサポートするようになりました。[#25795](https://github.com/ClickHouse/ClickHouse/pull/25795) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* Merge() storage で &quot;No available columns&quot; が表示される問題を修正しました。[#25801](https://github.com/ClickHouse/ClickHouse/pull/25801) ([Azat Khuzhin](https://github.com/azat)).
* 作業 directory を読み取れない場合でも clickhouse-client を起動できるようにしました。[#25817](https://github.com/ClickHouse/ClickHouse/pull/25817) ([ianton-ru](https://github.com/ianton-ru)).
* ReplicatedMergeTree テーブルにおける lost parts の処理を改善しました。ReplicationQueue でまれに発生する不整合を修正しています。ユーザーから見える変更はありません。[#10368](https://github.com/ClickHouse/ClickHouse/issues/10368) を修正しました。[#25820](https://github.com/ClickHouse/ClickHouse/pull/25820) ([alesapin](https://github.com/alesapin)).
* `DROP PART` または空の part のバックグラウンド削除後に、ごくまれに 交差するパーツ が発生する不具合を修正しました。[#25884](https://github.com/ClickHouse/ClickHouse/pull/25884) ([alesapin](https://github.com/alesapin)).
* history file を readline フォーマットから replxx フォーマットに変換しました。[#25888](https://github.com/ClickHouse/ClickHouse/pull/25888) ([Azat Khuzhin](https://github.com/azat)).
* JSON extract で LowCardinality、Decimal、UUID をサポートしました。[#24606](https://github.com/ClickHouse/ClickHouse/issues/24606) をクローズしました。[#25900](https://github.com/ClickHouse/ClickHouse/pull/25900) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `"null"` という名前のカラムを持つクエリ (backticks または二重引用符で指定する必要があります) と ON CLUSTER をサポートしました。これにより [#24035](https://github.com/ClickHouse/ClickHouse/issues/24035) をクローズしました。[#25907](https://github.com/ClickHouse/ClickHouse/pull/25907) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 無効な Date を parse しようとした場合に、正しく exception を throw するようにしました。これにより [#6481](https://github.com/ClickHouse/ClickHouse/issues/6481) をクローズしました。[#25909](https://github.com/ClickHouse/ClickHouse/pull/25909) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Parametric aggregate functions の parameter として、literals だけでなく任意の定数 expressions (例: `1 + 2`) も指定できるようにしました。これにより、parametric aggregate functions の parameter に query parameters (`{param:UInt8}` のような parameterized queries 内) も使用できるようになります。これにより [#11607](https://github.com/ClickHouse/ClickHouse/issues/11607) をクローズしました。[#25910](https://github.com/ClickHouse/ClickHouse/pull/25910) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `quantiles*` 関数が `aggregate_functions_null_for_empty` でも動作するようにしました。これにより [#25892](https://github.com/ClickHouse/ClickHouse/issues/25892) をクローズしました。[#25919](https://github.com/ClickHouse/ClickHouse/pull/25919) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `systemd` を使用する Centos 8 のようなシステムで `sudo service clickhouse-server start` が動作するようにしました。これにより [#14298](https://github.com/ClickHouse/ClickHouse/issues/14298) をクローズしました。これにより [#17799](https://github.com/ClickHouse/ClickHouse/issues/17799) をクローズしました。[#25921](https://github.com/ClickHouse/ClickHouse/pull/25921) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Nested` data types で unicode (例: 中国語、キリル文字) の 部分 をサポートしました。これにより [#25594](https://github.com/ClickHouse/ClickHouse/issues/25594) をクローズしました。[#25923](https://github.com/ClickHouse/ClickHouse/pull/25923) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* JOIN したテーブルで複雑な quoted identifiers を使用できるようにしました。これにより [#17861](https://github.com/ClickHouse/ClickHouse/issues/17861) をクローズしました。[#25924](https://github.com/ClickHouse/ClickHouse/pull/25924) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* setting `optimize_move_to_prewhere_if_final` を追加しました。クエリに `FINAL` が含まれる場合、最適化 `move_to_prewhere` は `optimize_move_to_prewhere` と `optimize_move_to_prewhere_if_final` の両方が有効なときにのみ有効になります。[#8684](https://github.com/ClickHouse/ClickHouse/issues/8684) をクローズしました。[#25940](https://github.com/ClickHouse/ClickHouse/pull/25940) ([Kseniia Sumarokova](https://github.com/kssenii)).
* ネットワーク関連のインストルメンテーションを強化: recv/send バイト数のカウンターを追加し、recv/send 回数の Gauge を追加しました。不足していたドキュメントも追加しました。これにより [#5897](https://github.com/ClickHouse/ClickHouse/issues/5897) をクローズします。 [#25962](https://github.com/ClickHouse/ClickHouse/pull/25962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Web UI: 値が URL のように見える場合、自動的にリンクを生成するようにしました。 [#25965](https://github.com/ClickHouse/ClickHouse/pull/25965) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* mysql プロトコルでクエリ `SET SQL_SELECT_LIMIT` を使用した際に発生するエラーを修正しました。 [#17115](https://github.com/ClickHouse/ClickHouse/issues/17115) をクローズします。 [#25972](https://github.com/ClickHouse/ClickHouse/pull/25972) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `empty` および `notEmpty` 関数で `UUID` 型の argument をサポートしました。`UUID` は全体がゼロ (nil UUID) の場合、empty と見なされます。これにより [#3446](https://github.com/ClickHouse/ClickHouse/issues/3446) をクローズします。 [#25974](https://github.com/ClickHouse/ClickHouse/pull/25974) ([zhaoyu](https://github.com/zxc111)).
* bin 関数および hex 関数で AggregateFunction 型の argument をサポートしました。 [#26094](https://github.com/ClickHouse/ClickHouse/pull/26094) ([zhaoyu](https://github.com/zxc111)).
* 複合キーを持つ Dictionary で、複合キーに attribute が 1 つしか含まれない場合は、`dictGet` および `dictHas` 関数で key expression を tuple でラップしなくてもよいようにしました。 [#26130](https://github.com/ClickHouse/ClickHouse/pull/26130) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix">
  #### バグ修正
</div>

* `Date` から `DateTime` (または `DateTime64`) への `CAST` で、`DateTime` 型の timezone が使われていませんでした。これは `Date` と `DateTime` の比較にも影響する可能性があります。また、`Date` と `DateTime` の共通型の推論でも、対応する timezone が使われていませんでした。そのため、関数 `if` と配列構築の結果に影響していました。[#24128](https://github.com/ClickHouse/ClickHouse/issues/24128) をクローズします。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* 非 `uint8` 型を使った PREWHERE で発生するアサーションを修正しました。[#19589](https://github.com/ClickHouse/ClickHouse/issues/19589) をクローズします。[#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* 有効期限 (TTL) の式で使われているカラムに対する `ALTER MODIFY COLUMN` を修正しました。[#25554](https://github.com/ClickHouse/ClickHouse/pull/25554) ([Anton Popov](https://github.com/CurtizJ)).
