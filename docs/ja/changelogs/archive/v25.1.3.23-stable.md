<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#75311](https://github.com/ClickHouse/ClickHouse/issues/75311)でバックポート: 型名が大文字でない場合に、JSON type 宣言のパース中に発生するクラッシュを修正しました。[#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75253](https://github.com/ClickHouse/ClickHouse/issues/75253)でバックポート: remove 操作が失敗した場合に、part の state を deleting から outdated に戻すよう修正しました。[#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* [#75409](https://github.com/ClickHouse/ClickHouse/issues/75409)でバックポート: `optimize_function_to_subcolumns` 設定が有効な場合の、`Array`、`Map`、`Nullable(..)` カラムに対する索引 (プライマリおよびセカンダリ) の使用を修正しました。従来は、これらのカラムの索引が無視される可能性がありました。[#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* [#75461](https://github.com/ClickHouse/ClickHouse/issues/75461)でバックポート: Insert を含む CTE で発生するクラッシュ不具合を修正しました。[#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#75291](https://github.com/ClickHouse/ClickHouse/issues/75291)でバックポート: デフォルト設定をさらに厳しくするための改善。現在のデフォルト設定はすでに安全で、ポートを明示的に公開するにはユーザーがオプションを指定する必要があります。ただし、`default` ユーザーに `CLICKHOUSE_PASSWORD` でパスワードが設定されておらず、かつ/または `CLICKHOUSE_USER` 環境変数でユーザー名が変更されていない場合は、追加の保護策としてローカルシステムからのみアクセスできるようにすべきです。[#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
