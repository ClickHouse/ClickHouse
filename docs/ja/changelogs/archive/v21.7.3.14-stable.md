<div id="bug-fix">
  #### バグ修正
</div>

* [#26191](https://github.com/ClickHouse/ClickHouse/issues/26191)でバックポート: remote() で、関数を含まないカラムからの `sharding_key` を修正しました (従来は `select * from remote('127.1', system.one, dummy)` を実行すると `Unknown column: dummy, there are only columns .` エラーが発生していました) 。 [#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* [#26109](https://github.com/ClickHouse/ClickHouse/issues/26109)でバックポート: ZooKeeper クライアント内の `abort` により、まれにサーバーがクラッシュする問題を修正しました。 [#25813](https://github.com/ClickHouse/ClickHouse/issues/25813) を修正します。 [#26079](https://github.com/ClickHouse/ClickHouse/pull/26079) ([alesapin](https://github.com/alesapin)).
* [#26142](https://github.com/ClickHouse/ClickHouse/issues/26142)でバックポート: `validate_polygons` 設定がオフの場合に `pointInPolygon` で発生しうるクラッシュを修正しました。 [#26113](https://github.com/ClickHouse/ClickHouse/pull/26113) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26170](https://github.com/ClickHouse/ClickHouse/issues/26170)でバックポート: LowCarinality カラムでの `joinGet` を修正し、[#25993](https://github.com/ClickHouse/ClickHouse/issues/25993) をクローズしました。 [#26118](https://github.com/ClickHouse/ClickHouse/pull/26118) ([Vladimir C](https://github.com/vdimir)).
* [#26206](https://github.com/ClickHouse/ClickHouse/issues/26206)でバックポート: 複数の `untuple` 式を使用した場合に発生する可能性のあるクラッシュを修正しました。 [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26229](https://github.com/ClickHouse/ClickHouse/issues/26229)でバックポート: `system.stack_trace` テーブルの `thread_name` カラムに含まれる余分な改行を削除しました。これにより [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124) を修正します。 [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 存在しないリモートディレクトリを走査した際に例外を投げる問題を修正しました。 [#26296](https://github.com/ClickHouse/ClickHouse/pull/26296) ([ianton-ru](https://github.com/ianton-ru)).
