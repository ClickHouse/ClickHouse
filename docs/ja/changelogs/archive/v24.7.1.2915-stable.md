  ### ClickHouse リリース v24.7.1.2915-stable (a37d2d43da7) FIXME v24.7.1.1-new (aa023477a92) と比較して

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* Variant データ型のバイナリシリアライゼーションを変更しました。単一の variant しか含まれない、または NULL 値しか含まれないグラニュールで同じ判別子を複数回書き込まないようにするため、`compact` モードを追加しました。あわせて、デフォルトで有効な MergeTree 設定 `use_compact_variant_discriminators_serialization` を追加しました。なお、Variant 型は依然として実験的であるため、シリアライゼーションに後方互換性のない変更があっても問題ありません。[#62774](https://github.com/ClickHouse/ClickHouse/pull/62774) ([Kruglov Pavel](https://github.com/Avogar)).
* Replicated データベースでは、`CREATE MATERIALIZED VIEW ... ENGINE Replicated*MergeTree POPULATE AS SELECT ...` を禁止しました。[#63963](https://github.com/ClickHouse/ClickHouse/pull/63963) ([vdimir](https://github.com/vdimir)).
* `clickhouse-keeper-client` は、`ls '/hello/world'` のように文字列リテラルで指定されたパスのみを受け付けるようになり、`ls /hello/world` のようなクォートなしの文字列は受け付けなくなります。[#65494](https://github.com/ClickHouse/ClickHouse/pull/65494) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* メトリック `KeeperOutstandingRequets` は `KeeperOutstandingRequests` にリネームされました。これは [#66179](https://github.com/ClickHouse/ClickHouse/issues/66179) で報告されたタイプミスを修正するものです。[#66206](https://github.com/ClickHouse/ClickHouse/pull/66206) ([Robert Schulze](https://github.com/rschu1ze)).
* `system.functions` テーブルから `is_deterministic` フィールドを削除しました。[#66630](https://github.com/ClickHouse/ClickHouse/pull/66630) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新機能
</div>

* クエリ内で名前付きタプルを構築できるように、関数 `tuple` を拡張しました。タプルから名前を抽出する関数 `tupleNames` も導入しました。[#54881](https://github.com/ClickHouse/ClickHouse/pull/54881) ([Amos Bird](https://github.com/amosbird)).
* `full_sorting_join` アルゴリズムで `ASOF JOIN` をサポートしました。[#54493](https://github.com/ClickHouse/ClickHouse/issues/54493) を解決します。[#55051](https://github.com/ClickHouse/ClickHouse/pull/55051) ([vdimir](https://github.com/vdimir)).
* 新しいテーブル関数 `fuzzQuery,` を追加しました。この関数を使うと、指定したクエリ文字列にランダムな変化を加えられます。例: `SELECT query FROM fuzzQuery('SELECT 1');`。[#62103](https://github.com/ClickHouse/ClickHouse/pull/62103) ([pufit](https://github.com/pufit)).
* 新しいウィンドウ関数 `percent_rank` を追加しました。[#62747](https://github.com/ClickHouse/ClickHouse/pull/62747) ([lgbo](https://github.com/lgbo-ustc)).
* `clickhouse-client` で JWT 認証をサポートしました。[#62829](https://github.com/ClickHouse/ClickHouse/pull/62829) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* SQL 関数 `changeYear`、`changeMonth`、`changeDay`、`changeHour`、`changeMinute`、`changeSecond` を追加しました。たとえば、`SELECT changeMonth(toDate('2024-06-14'), 7)` は日付 `2024-07-14` を返します。[#63186](https://github.com/ClickHouse/ClickHouse/pull/63186) ([cucumber95](https://github.com/cucumber95)).
* 起動時に事前設定されたクエリを実行できる startup scripts を導入しました。[#64889](https://github.com/ClickHouse/ClickHouse/pull/64889) ([pufit](https://github.com/pufit)).
* 自己署名証明書で動作する server に client が secure TCP 経由で接続できるよう、client の config で accept&#95;invalid&#95;certificate をサポートしました。これは、対応する `openSSL` client setting である `verificationMode=none` と `invalidCertificateHandler.name=AcceptCertificateHandler` の簡略指定として利用できます。[#65238](https://github.com/ClickHouse/ClickHouse/pull/65238) ([peacewalker122](https://github.com/peacewalker122)).
* `system.errors` テーブルの error values の history を含み、定期的にディスクへフラッシュされる `system.error_log` を追加しました。[#65381](https://github.com/ClickHouse/ClickHouse/pull/65381) ([Pablo Marcos](https://github.com/pamarcos)).
* aggregate function `groupConcat` を追加しました。これは `arrayStringConcat( groupArray(column), ',')` とほぼ同じです。受け取れる parameter は 2 つで、文字列の区切り文字と処理する要素数です。[#65451](https://github.com/ClickHouse/ClickHouse/pull/65451) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* AzureQueue storage を追加しました。[#65458](https://github.com/ClickHouse/ClickHouse/pull/65458) ([Kseniia Sumarokova](https://github.com/kssenii)).
* parquet files へのページ索引の書き込みを無効化/有効化する新しい設定を追加しました。[#65475](https://github.com/ClickHouse/ClickHouse/pull/65475) ([lgbo](https://github.com/lgbo-ustc)).
* system administrator が `logger.console_log_level` を設定できるようにしました。[#65559](https://github.com/ClickHouse/ClickHouse/pull/65559) ([Azat Khuzhin](https://github.com/azat)).
* テーブル関数 `file` で、directory パスの末尾にワイルドカード `*` を自動的に追加するようにしました。[#66019](https://github.com/ClickHouse/ClickHouse/pull/66019) ([Zhidong (David) Guo](https://github.com/Gun9niR)).
* 対話型モードではない client に `--memory-usage` オプションを追加しました。[#66393](https://github.com/ClickHouse/ClickHouse/pull/66393) ([vdimir](https://github.com/vdimir)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* `optimize_functions_to_subcolumns` がデフォルトで有効になりました。[#58661](https://github.com/ClickHouse/ClickHouse/pull/58661) ([Anton Popov](https://github.com/CurtizJ)).
* int から string への変換アルゴリズムを、より高速なものに置き換えました (修正版 amdn/itoa から修正版 jeaiii/itoa へ) 。[#61661](https://github.com/ClickHouse/ClickHouse/pull/61661) ([Raúl Marín](https://github.com/Algunenano)).
* join (`parallel_hash` アルゴリズム) で作成される hash tables のサイズを収集して cache するようになりました。この情報は後続のクエリ実行時に hash tables の領域を事前確保するために使用され、hash table のリサイズにかかる時間を削減します。[#64553](https://github.com/ClickHouse/ClickHouse/pull/64553) ([Nikita Taranov](https://github.com/nickitat)).
* `ORDER BY` 主キーと、高い selectivity の condition を含む `WHERE` を持つクエリを、buffering を利用して最適化しました。これは設定 `read_in_order_use_buffering` (デフォルトで有効) で制御され、クエリのメモリ使用量が増加する場合があります。[#64607](https://github.com/ClickHouse/ClickHouse/pull/64607) ([Anton Popov](https://github.com/CurtizJ)).
* `plain_rewritable` メタデータの読み込み性能を改善しました。[#65634](https://github.com/ClickHouse/ClickHouse/pull/65634) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 読み取り専用ディスク上でテーブルをアタッチする際、outdated parts を読み込まないことで使用リソースを削減します。[#65635](https://github.com/ClickHouse/ClickHouse/pull/65635) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Set 索引で minmax hyperrectangle をサポートしました。[#65676](https://github.com/ClickHouse/ClickHouse/pull/65676) ([AntiTopQuark](https://github.com/AntiTopQuark)).
* 合計メモリ使用量を削減するため、outdated parts のプライマリインデックスをアンロードします。[#65852](https://github.com/ClickHouse/ClickHouse/pull/65852) ([Anton Popov](https://github.com/CurtizJ)).
* `replaceRegexpAll` 関数および `replaceRegexpOne` 関数は、pattern が単純、つまりメタ文字、pattern class、フラグ、グループ化文字などを含まない場合に、大幅に高速化されました。 (Taiyang Li に感謝します。) [#66185](https://github.com/ClickHouse/ClickHouse/pull/66185) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="improvement">
  #### 改善
</div>

* Keeper のバックエンドストレージとして RocksDB をサポートしました。[#56626](https://github.com/ClickHouse/ClickHouse/pull/56626) ([Han Fei](https://github.com/hanfei1991)).
* 設定 `optimize_trivial_insert_select` はデフォルトで無効になりました。ほとんどの場合、この変更は有益なはずです。ただし、INSERT SELECT が遅くなったりメモリ使用量が増えたりする場合は、再度有効にするか、`SET compatibility = '24.6'` を設定してください。[#58970](https://github.com/ClickHouse/ClickHouse/pull/58970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `clickhouse-client` または `clickhouse-local` がクラッシュした場合に、スタックトレースと診断情報を出力するようにしました。[#61109](https://github.com/ClickHouse/ClickHouse/pull/61109) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `SHOW INDEX | INDEXES | INDICES | KEYS` の結果は、以前は主キーカラム名でソートされていました。これは直感的ではなかったため、現在は主キー内での主キーカラムの位置順でソートされるようになりました。[#61131](https://github.com/ClickHouse/ClickHouse/pull/61131) ([Robert Schulze](https://github.com/rschu1ze)).
* この PR では、MV の重複排除の仕組みを変更しています。たとえば次のような多くのケースを修正しました: - 宛先テーブルで、データが 2 個以上のブロックに分割され、それらのブロックが並列に挿入された際に重複と見なされる。 - MV の宛先テーブルで、同一のブロックが重複排除される。これは、集約の実行により、異なる入力データに対して MV が結果として同じデータを頻繁に生成する場合に発生する。 - MV の宛先テーブルで、異なる MV から来た同一のブロックが重複排除される。[#61601](https://github.com/ClickHouse/ClickHouse/pull/61601) ([Sema Checherinda](https://github.com/CheSema)).
* JSON ファイルの読み取り時に、カラム名を大文字小文字を区別せずに照合できるようにしました (`input_format_json_case_insensitive_column_matching`) 。[#61750](https://github.com/ClickHouse/ClickHouse/pull/61750) ([kevinyhzou](https://github.com/KevinyhZou)).
* パーティション化された Delta Lake データの読み取りをサポートしました。また、データではなくメタデータを読み取って Delta Lake のスキーマを推定するようにしました。[#63201](https://github.com/ClickHouse/ClickHouse/pull/63201) ([Kseniia Sumarokova](https://github.com/kssenii)).
* コンポーザブルプロトコルの TLS レイヤーでは、`certificateFile` と `privateKeyFile` パラメータのみを受け付けるようになりました。[https://clickhouse.com/docs/en/operations/settings/composable-protocols](https://clickhouse.com/docs/en/operations/settings/composable-protocols). [#63985](https://github.com/ClickHouse/ClickHouse/pull/63985) ([Anton Ivashkin](https://github.com/ianton-ru)).
* clickhouse-disks 用の対話型クライアントを作成し、ローカルディレクトリからローカルディスクを追加できるようにしました。[#56791](https://github.com/ClickHouse/ClickHouse/issues/56791) を修正しました。[#64446](https://github.com/ClickHouse/ClickHouse/pull/64446) ([Daniil Ivanik](https://github.com/divanik)).
* `WHERE` 句の評価に主キーを使用する SELECT クエリの数を示すプロファイルイベント `SelectQueriesWithPrimaryKeyUsage` を追加しました。[#64492](https://github.com/ClickHouse/ClickHouse/pull/64492) ([0x01f](https://github.com/0xfei)).
* `StorageS3Queue` 関連の修正と改善。`s3queue_processing_threads_num` のデフォルト値を、従来の 1 ではなく、サーバー上の物理 CPU コア数に応じて決定するようにしました。`s3queue_loading_retries` のデフォルト値を 10 に設定しました。`system.s3queue` の exception カラムに曖昧な &quot;Uncaught exception&quot; が表示される可能性がある問題を修正しました。`MEMORY_LIMIT_EXCEEDED` exception では再試行回数を増やさないようにしました。挿入されていないのにファイルがコミットされるのを防ぐため、ファイルの commit を、テーブルへの挿入が完全に完了した後の段階に移動しました。commit と flush のタイミングをより適切に制御するため、設定 `s3queue_max_processed_files_before_commit`, `s3queue_max_processed_rows_before_commit`, `s3queue_max_processed_bytes_before_commit`, `s3queue_max_processing_time_sec_before_commit` を追加しました。[#65046](https://github.com/ClickHouse/ClickHouse/pull/65046) ([Kseniia Sumarokova](https://github.com/kssenii)).
* s390x で壊れていた複数カラムの aggregation を修正しました。 [#65062](https://github.com/ClickHouse/ClickHouse/pull/65062) ([Harry Lee](https://github.com/HarryLeeIBM)).
* パラメーター化ビュー関数で別名をサポートしました (新しいアナライザのみ) 。 [#65190](https://github.com/ClickHouse/ClickHouse/pull/65190) ([Kseniia Sumarokova](https://github.com/kssenii)).
* S3。クエリの再試行時間を短縮し、backups の再試行回数を増やしました。クエリでは 8.5 分・再試行 100 回、バックアップの復元では 1.2 時間・再試行 1000 回です。 [#65232](https://github.com/ClickHouse/ClickHouse/pull/65232) ([Sema Checherinda](https://github.com/CheSema)).
* azureBlobStorage のログで account key をマスクするように更新しました。 [#65273](https://github.com/ClickHouse/ClickHouse/pull/65273) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* フィルタ式が `PARTITION BY` 式の一部である場合の `IN` predicates に対するパーティション pruning。 [#65335](https://github.com/ClickHouse/ClickHouse/pull/65335) ([Eduard Karacharov](https://github.com/korowa)).
* すべての detached table に関する主要な情報を持つシステムテーブルを追加しました。 [#65400](https://github.com/ClickHouse/ClickHouse/pull/65400) ([Konstantin Morozov](https://github.com/k-morozov)).
* custom key 並列レプリカの使用時に `cluster_for_parallel_replicas` をサポートしました。これにより、MergeTree テーブルで custom key を使った並列レプリカを利用できます。 [#65453](https://github.com/ClickHouse/ClickHouse/pull/65453) ([Antonio Andelic](https://github.com/antonio2368)).
* クエリプランの LIMIT 最適化をサポートしました。PostgreSQL ストレージおよびテーブル関数で LIMIT pushdown をサポートしました。 [#65454](https://github.com/ClickHouse/ClickHouse/pull/65454) ([Maksim Kita](https://github.com/kitaisreal)).
* Arraymin/max を、比較可能なすべての data types に適用できるようにしました。 [#65455](https://github.com/ClickHouse/ClickHouse/pull/65455) ([pn](https://github.com/chloro-pn)).
* cgroups v2 のメモリ使用量の計測を改善し、page cache が占める量を除外するようにしました。 [#65470](https://github.com/ClickHouse/ClickHouse/pull/65470) ([Nikita Taranov](https://github.com/nickitat)).
* EmbeddedRocksDB テーブルへの挿入用にチャンクをシリアライズする際、各行ごとに format settings を作成しないようにしました。 [#65474](https://github.com/ClickHouse/ClickHouse/pull/65474) ([Duc Canh Le](https://github.com/canhld94)).
* s390x での Dwarf5 のパース時に発生する範囲外 exception を修正しました。 [#65501](https://github.com/ClickHouse/ClickHouse/pull/65501) ([Harry Lee](https://github.com/HarryLeeIBM)).
* `clickhouse-local` のプロンプトを `:)` のみに簡略化しました。macOS では `getFQDNOrHostName()` に時間がかかりすぎるうえ、そもそも `clickhouse-local` のプロンプトに hostname は不要です。 [#65510](https://github.com/ClickHouse/ClickHouse/pull/65510) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* 低スペックの virtual machine で、per-CPU arenas に関する jemalloc のメッセージが出力されないようにしました。 [#65532](https://github.com/ClickHouse/ClickHouse/pull/65532) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* config に新しいオプション `<config_reload_interval_ms>` を追加し、clickhouse が config を再読み込みする頻度を指定できるようにしました。 [#65545](https://github.com/ClickHouse/ClickHouse/pull/65545) ([alesapin](https://github.com/alesapin)).
* ClickHouse のデータ型向けのバイナリ encoding を実装し、その仕様をドキュメントに追加しました。これを Dynamic のバイナリシリアライゼーションで使用し、設定により `RowBinaryWithNamesAndTypes` および `Native` フォーマットでも使用できるようにしました。[#65546](https://github.com/ClickHouse/ClickHouse/pull/65546) ([Kruglov Pavel](https://github.com/Avogar)).
* ZooKeeper の負荷分散を改善しました。現在のセッションは、`fallback_session_lifetime` に関係なく、最適なノードが利用可能になるまで期限切れになりません。さらに、AZ を考慮した負荷分散もサポートしました。[#65570](https://github.com/ClickHouse/ClickHouse/pull/65570) ([Alexander Tokmakov](https://github.com/tavplubix)).
* サーバー設定 `compiled_expression_cache_size` と `compiled_expression_cache_elements_size` が `system.server_settings` に表示されるようになりました。[#65584](https://github.com/ClickHouse/ClickHouse/pull/65584) ([Robert Schulze](https://github.com/rschu1ze)).
* プロジェクションを持つテーブルで論理削除が発生した場合、ユーザーは、例外を発生させる (デフォルト) か、論理削除の対象となるプロジェクションを削除するかを選択できます。[#65594](https://github.com/ClickHouse/ClickHouse/pull/65594) ([jsc0218](https://github.com/jsc0218)).
* X.509 の SubjectAltName 拡張に基づくユーザー識別をサポートしました。[#65626](https://github.com/ClickHouse/ClickHouse/pull/65626) ([Anton Kozlov](https://github.com/tonickkozlov)).

* ファイルを ClickHouse にバックアップするためのスクリプトを追加しました。奇妙ですが、ちゃんと動作します。[#65699](https://github.com/ClickHouse/ClickHouse/pull/65699) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* Keeper で cgroup の CPU 制限を反映するようにしました。[#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)).
