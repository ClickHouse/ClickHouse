<div id="bug-fix">
  #### バグ修正

* [#41228](https://github.com/ClickHouse/ClickHouse/issues/41228)でバックポート: 引数として Array of Nullable を使用した場合の、`encrypt` 関数および `contingency` 関数におけるメモリ安全性の問題を修正しました。この修正により [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004) も解決されます。[#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#41283](https://github.com/ClickHouse/ClickHouse/issues/41283)でバックポート: WITHステートメントで導入された未使用の不明なカラムに関する問題を修正しました。これにより [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812) も修正されます。 [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* [#40865](https://github.com/ClickHouse/ClickHouse/issues/40865)でバックポート: 可変次元の配列を含む `Object` 型の値のパース中に発生するクラッシュを修正しました。 [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* [#40804](https://github.com/ClickHouse/ClickHouse/issues/40804)でバックポート: `ProcessList` への新しいクエリの挿入時に割り当てが発生します。これらの割り当て中にメモリ制限に達すると、`ProcessList::mutex` がすでに取得されているため、`OvercommitTracker` を使用できません。 [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611) を修正します。 [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* [#40810](https://github.com/ClickHouse/ClickHouse/issues/40810)でバックポート: [#40595](https://github.com/ClickHouse/ClickHouse/issues/40595) では、`/etc/hosts` での名前解決において `host_regexp` 機能が正しく動作していないことが報告されていました。これを修正しました。 [#40769](https://github.com/ClickHouse/ClickHouse/pull/40769) ([Arthur Passos](https://github.com/arthurpassos)).
* [#41134](https://github.com/ClickHouse/ClickHouse/issues/41134)でバックポート: `DESCRIBE TABLE url()` および一部の `DESCRIBE TABLE <table_function>()` に対するアクセス権を修正しました。 [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#41617](https://github.com/ClickHouse/ClickHouse/issues/41617)でバックポート: 集約関数コンビネータにおける、segfault、use-heap-after-free、メモリリークの可能性がある問題を修正しました。 [#40848](https://github.com/ClickHouse/ClickHouse/issues/40848) をクローズします。 [#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41666](https://github.com/ClickHouse/ClickHouse/issues/41666)でバックポート: サブクエリ内に `OFFSET` 句、外側のクエリに `WHERE` 句を含むクエリで誤った結果が返る可能性がある問題を修正しました。 [#40416](https://github.com/ClickHouse/ClickHouse/issues/40416) を修正します。 [#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#41361](https://github.com/ClickHouse/ClickHouse/issues/41361)でバックポート: ディスクの object storage で発生する誤った論理エラー `Expected relative path` を修正しました。 [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246) に関連します。 [#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#41358](https://github.com/ClickHouse/ClickHouse/issues/41358)でバックポート: MsgPack フォーマットで UUID を挿入する前にカラム型チェックを追加しました。 [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41808](https://github.com/ClickHouse/ClickHouse/issues/41808)でバックポート: Native format 内の悪意あるデータがクラッシュを引き起こす可能性がある問題を修正しました。 [#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41805](https://github.com/ClickHouse/ClickHouse/issues/41805)でバックポート: 集約関数 `categorialInformationValue` のプロパティ定義が誤っており、実行時に null ポインタの逆参照が発生する可能性がありました。これにより [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443) をクローズします。[#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41505](https://github.com/ClickHouse/ClickHouse/issues/41505)でバックポート: Apache `ORC` フォーマットでデータを書き込む際に、バッファオーバーランが発生する可能性がありました。[#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41644](https://github.com/ClickHouse/ClickHouse/issues/41644)でバックポート: `ORDER BY` と `1500 <= LIMIT <= max_block_size` を含むクエリで、先頭の行の一部が欠落した誤った結果が返される可能性がありました。[#41182](https://github.com/ClickHouse/ClickHouse/issues/41182) を修正しました。[#41576](https://github.com/ClickHouse/ClickHouse/pull/41576) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41641](https://github.com/ClickHouse/ClickHouse/issues/41641)でバックポート: `OFFSET` を含むクエリで発生する可能性がある `pipeline stuck` 例外を修正しました。このエラーは、`enable_optimize_predicate_expression = 0` かつ `WHERE` に常に false となる条件がある場合に確認されました。[#41383](https://github.com/ClickHouse/ClickHouse/issues/41383) を修正しました。[#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41900](https://github.com/ClickHouse/ClickHouse/issues/41900)でバックポート: `optimize_monotonous_functions_in_order_by` 設定が有効な `Merge` テーブルに対する `SELECT` で発生する可能性があるクラッシュを修正しました。[#41269](https://github.com/ClickHouse/ClickHouse/issues/41269) を修正しました。[#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
