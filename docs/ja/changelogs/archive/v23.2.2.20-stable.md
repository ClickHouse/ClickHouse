  # 2023年 変更履歴
</div>

<div id="clickhouse-release-v232220-stable-f6c269c8df2-fixme-as-compared-to-v23212537-stable-52bf836e03a">
  ### ClickHouse リリース v23.2.2.20-stable (f6c269c8df2) FIXME (v23.2.1.2537-stable (52bf836e03a) と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#46914](https://github.com/ClickHouse/ClickHouse/issues/46914)でバックポート: カラムごとに異なるDEFAULT式があるMergeで、PREWHEREを使用可能にしました。[#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* [#47022](https://github.com/ClickHouse/ClickHouse/issues/47022)でバックポート: range()でIPv4を使用可能にしました。[#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#46828](https://github.com/ClickHouse/ClickHouse/issues/46828) でバックポート: 複数の PREWHERE から蓄積された結合 PREWHERE カラムで、場合によっては前段のステップの 0 が含まれないことがありました。この修正では、最後のステップのうち複数のステップから適用されたものではないことが分かっている場合に、最終フィルタを適用します。 [#46785](https://github.com/ClickHouse/ClickHouse/pull/46785) ([Alexander Gololobov](https://github.com/davenger)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#47062](https://github.com/ClickHouse/ClickHouse/issues/47062) でバックポート: 古いディストリビューション (例: Amazon Linux 2) や ARM 環境で、glibc 2.28 のシンボルが見つからずサーバー起動時にエラーになる問題を修正しました。 [#47008](https://github.com/ClickHouse/ClickHouse/pull/47008) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#46895](https://github.com/ClickHouse/ClickHouse/issues/46895) でバックポート: `ReplicatedMergeTree` テーブルおよび `Atomic` データベースにおける `DROP TABLE` クエリの自動再試行のバグを修正しました。まれに、DROP 中に ZooKeeper セッションの有効期限が切れ、同じ ZooKeeper パスを持つ新しいレプリケートテーブルが並列に作成されると、`Can't get data for node /zk_path/log_pointer` および `The specified key does not exist` エラーが発生することがありました。[#46384](https://github.com/ClickHouse/ClickHouse/pull/46384) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#46865](https://github.com/ClickHouse/ClickHouse/issues/46865) でバックポート: `Map` データ型のバグを修正しました。これで [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855) をクローズします。[#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46958](https://github.com/ClickHouse/ClickHouse/issues/46958) でバックポート: 部分文字列検索に変換され、引用符で囲まれた LIKE 以外のメタ文字を含む LIKE 述語の結果を修正しました。[#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴 には記載しない / 軽微
</div>

* Mergeable Check の更新頻度を減らしました [#46781](https://github.com/ClickHouse/ClickHouse/pull/46781) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
