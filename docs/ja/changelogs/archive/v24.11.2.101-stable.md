<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#72704](https://github.com/ClickHouse/ClickHouse/issues/72704) にバックポート: 並列レプリカでローカルプランが有効な場合のクエリ実行時に、ワーカー側での索引解析をスキップするようにしました。マージコーディネーターは、自身の側 (クエリのイニシエーター上) で行った索引解析に基づいて、ワーカーが読み取る範囲を選択します。[#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter))。
* [#73035](https://github.com/ClickHouse/ClickHouse/issues/73035) にバックポート: [https://github.com/ClickHouse/ClickHouse/pull/57631](https://github.com/ClickHouse/ClickHouse/pull/57631) にあった、compact パーツ内の単一カラムのサブカラム読み取りに関する最適化を復活させました。これは誤って削除されていました。[#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar))。

<div id="improvement">
  #### 改善
</div>

* [#72677](https://github.com/ClickHouse/ClickHouse/issues/72677) にバックポート: キャッシュされた mark のメモリ使用量の推定精度を改善し、cache の総メモリ使用量を削減しました。[#72630](https://github.com/ClickHouse/ClickHouse/pull/72630) ([Antonio Andelic](https://github.com/antonio2368))。
* [#73065](https://github.com/ClickHouse/ClickHouse/issues/73065) にバックポート: GCS S3 エラー `AuthenticationRequired` のパースをサポートしました。[#72753](https://github.com/ClickHouse/ClickHouse/pull/72753) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#73057](https://github.com/ClickHouse/ClickHouse/issues/73057) にバックポート: S3 リクエスト設定 `http_max_fields`、`http_max_field_name_size`、`http_max_field_value_size` を追加し、バックアップ作成時または復元時に S3 API レスポンスをパースする際に使用するようにしました。[#72778](https://github.com/ClickHouse/ClickHouse/pull/72778) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#73454](https://github.com/ClickHouse/ClickHouse/issues/73454) にバックポート: `ObjectStorageQueueMetadata` のクリーンアップスレッドで Keeper のマルチリクエストを使用するようにしました。[#73357](https://github.com/ClickHouse/ClickHouse/pull/73357) ([Antonio Andelic](https://github.com/antonio2368))。
* [#73435](https://github.com/ClickHouse/ClickHouse/issues/73435) にバックポート: ClickHouse が cgroup 配下で動作している場合でも、システム負荷、プロセススケジューリング、メモリなどに関連するシステム全体の非同期メトリクスを引き続き収集するようにしました。ClickHouse がホスト上で高いリソース消費を伴う唯一のプロセスである場合、これらは有用なシグナルになる可能性があります。[#73369](https://github.com/ClickHouse/ClickHouse/pull/73369) ([Nikita Taranov](https://github.com/nickitat))。
