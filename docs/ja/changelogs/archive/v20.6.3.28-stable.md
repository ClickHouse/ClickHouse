<div id="clickhouse-release-v206328-stable-fixme-as-compared-to-v206215-prestable">
  ### ClickHouse リリース v20.6.3.28-stable FIXME (v20.6.2.15-prestableとの比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#13301](https://github.com/ClickHouse/ClickHouse/issues/13301)でバックポート: 関数 `groupArrayMoving*` が分散クエリで正しく動作していませんでした。結果が不適切なデータ型 (最大の型への昇格なし) で計算されていました。また、関数 `groupArrayMovingAvg` は `avg` 関数と整合しない整数値を返していました。これにより [#12568](https://github.com/ClickHouse/ClickHouse/issues/12568) を修正しました。[#12622](https://github.com/ClickHouse/ClickHouse/pull/12622) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#13029](https://github.com/ClickHouse/ClickHouse/issues/13029)でバックポート: CREATE USER IF NOT EXISTS は、ユーザーが存在する場合に例外をスローしなくなりました。これにより [#12507](https://github.com/ClickHouse/ClickHouse/issues/12507) を修正しました。[#12646](https://github.com/ClickHouse/ClickHouse/pull/12646) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#12983](https://github.com/ClickHouse/ClickHouse/issues/12983)でバックポート: DDLクエリから作成された range hashed dictionary で発生するカラム重複を修正しました。これにより [#10605](https://github.com/ClickHouse/ClickHouse/issues/10605) を修正しました。[#12857](https://github.com/ClickHouse/ClickHouse/pull/12857) ([alesapin](https://github.com/alesapin)).
* [#13222](https://github.com/ClickHouse/ClickHouse/issues/13222)でバックポート: 定数 argument を持つ DateTime64 の変換関数を修正しました。[#13205](https://github.com/ClickHouse/ClickHouse/pull/13205) ([Azat Khuzhin](https://github.com/azat)).
* [#13245](https://github.com/ClickHouse/ClickHouse/issues/13245)でバックポート: 配列要素が Nullable で、かつ配列の添字も Nullable である場合の `arrayElement` 関数の assert を修正しました。これにより [#12172](https://github.com/ClickHouse/ClickHouse/issues/12172) を修正しました。[#13224](https://github.com/ClickHouse/ClickHouse/pull/13224) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#13267](https://github.com/ClickHouse/ClickHouse/issues/13267)でバックポート: literal NULL ではない nullable constexpr を cond に指定した場合の関数 if の不具合を修正しました。これにより [#12463](https://github.com/ClickHouse/ClickHouse/issues/12463) を修正しました。[#13226](https://github.com/ClickHouse/ClickHouse/pull/13226) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#13298](https://github.com/ClickHouse/ClickHouse/issues/13298)でバックポート: NaN 値を含む Float 型に対して呼び出された `uniqExact`、`topK`、`sumDistinct` などの集約関数で、発生する可能性のある低パフォーマンスとわずかに不正確な結果を修正しました。また、デバッグビルドで assert がトリガーされることもありました。これにより [#12491](https://github.com/ClickHouse/ClickHouse/issues/12491) を修正しました。[#13254](https://github.com/ClickHouse/ClickHouse/pull/13254) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#13316](https://github.com/ClickHouse/ClickHouse/issues/13316)でバックポート: 特別に細工された引数を関数 `h3ToChildren` に渡した場合、サーバーがクラッシュする可能性がありました。これにより [#13275](https://github.com/ClickHouse/ClickHouse/issues/13275) を修正しました。[#13277](https://github.com/ClickHouse/ClickHouse/pull/13277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#13329](https://github.com/ClickHouse/ClickHouse/issues/13329)でバックポート: 遅延レプリカからのクエリで発生する可能性がある error `Totals having transform was already added to pipeline` を修正しました。[#13290](https://github.com/ClickHouse/ClickHouse/pull/13290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#13317](https://github.com/ClickHouse/ClickHouse/issues/13317)でバックポート: `join_use_nulls=1` の場合に発生する `LEFT ASOF JOIN` のクラッシュを修正しました。[#13291](https://github.com/ClickHouse/ClickHouse/pull/13291) ([Artem Zuikov](https://github.com/4ertus2)).
* [#13375](https://github.com/ClickHouse/ClickHouse/issues/13375)でバックポート: 関数 `groupArrayMovingSum` が空の state をデシリアライズする際に発生する segfault を修正しました。[#13339](https://github.com/ClickHouse/ClickHouse/issues/13339) を修正。[#13341](https://github.com/ClickHouse/ClickHouse/pull/13341) ([alesapin](https://github.com/alesapin)).
* [#13432](https://github.com/ClickHouse/ClickHouse/issues/13432)でバックポート: clickhouse-local での PrettyCompactMonoBlock を修正しました。PrettyCompactMonoBlock での extremes/totals を修正しました。[#7746](https://github.com/ClickHouse/ClickHouse/issues/7746) を修正。[#13394](https://github.com/ClickHouse/ClickHouse/pull/13394) ([Azat Khuzhin](https://github.com/azat)).
* [#13443](https://github.com/ClickHouse/ClickHouse/issues/13443)でバックポート: `SET optimize_move_functions_out_of_any = 1` と `any()` 内の別名を使用した場合に発生する `aggregate function any(x) is found inside another aggregate function in query` エラーを修正しました。[#13419](https://github.com/ClickHouse/ClickHouse/pull/13419) ([Artem Zuikov](https://github.com/4ertus2)).
