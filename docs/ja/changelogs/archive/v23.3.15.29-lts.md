<div id="clickhouse-release-v2331529-lts-218336662e4-fixme-as-compared-to-v2331478-lts-c8f4ba52c65">
  ### ClickHouse リリース v23.3.15.29-lts (218336662e4) FIXME (v23.3.14.78-lts (c8f4ba52c65) との比較)
</div>

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#55671](https://github.com/ClickHouse/ClickHouse/issues/55671)でバックポート: データベースがすでに初期化されている場合、以降の起動時に再度初期化する必要がなくなりました。これにより、データベースを 1000 回試行しても読み込めない場合にコンテナーが無限に再起動する問題が解消される可能性があります (非常に大規模なデータベースやマルチノード構成で該当) 。 [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* [#55734](https://github.com/ClickHouse/ClickHouse/issues/55734)でバックポート: gh api url を使用するよう、インテグレーションチェック用の Python スクリプトを修正し、CI テスト用の README を追加。 [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
* [#55829](https://github.com/ClickHouse/ClickHouse/issues/55829)でバックポート: tgz の sha512 を確認し、Keeper 用に適切なリポジトリを使用するよう修正。また、tarball パッケージの TGZ.sha512 ファイルにはファイル名のみを書き込むよう変更。 [#31473](https://github.com/ClickHouse/ClickHouse/issues/31473) の前提条件。 [#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* zero copy を使用しない S3 上の replicated merge tree で、デタッチされたパーティションを削除できない不具合を修正 [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* 循環参照する別名がある場合に QueryNormalizer がクラッシュする不具合を修正 [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* スパースなカラムでウィンドウ関数が正しく動作しない不具合を修正 [#55895](https://github.com/ClickHouse/ClickHouse/pull/55895) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).

<div id="no-cl-entry">
