<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#37715](https://github.com/ClickHouse/ClickHouse/issues/37715) でバックポート: aggregate function、prewhere、join において、定数文字列の衝突によって発生する予期しないエラーを修正しました。[#36891](https://github.com/ClickHouse/ClickHouse/issues/36891) をクローズします。[#37336](https://github.com/ClickHouse/ClickHouse/pull/37336) ([Vladimir C](https://github.com/vdimir)).
* [#37511](https://github.com/ClickHouse/ClickHouse/issues/37511) でバックポート: normalizeUTF8 関数の論理エラーを修正しました。[#37298](https://github.com/ClickHouse/ClickHouse/issues/37298) をクローズします。[#37443](https://github.com/ClickHouse/ClickHouse/pull/37443) ([Maksim Kita](https://github.com/kitaisreal)).
* [#37843](https://github.com/ClickHouse/ClickHouse/issues/37843) でバックポート: named collections で設定された MySQL データベースに対して `show create table` を実行した際に発生するセグメンテーションフォールトを修正しました。[#37683](https://github.com/ClickHouse/ClickHouse/issues/37683) をクローズします。[#37690](https://github.com/ClickHouse/ClickHouse/pull/37690) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#37940](https://github.com/ClickHouse/ClickHouse/issues/37940) でバックポート: 内部 cast 関数の設定 `cast_ipv4_ipv6_default_on_conversion_error` を修正しました。[#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) をクローズします。[#37761](https://github.com/ClickHouse/ClickHouse/pull/37761) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#37926](https://github.com/ClickHouse/ClickHouse/issues/37926)でバックポート: asof join key の NULL 許容性をチェックする処理を修正し、[#35565](https://github.com/ClickHouse/ClickHouse/issues/35565) をクローズしました。[#35674](https://github.com/ClickHouse/ClickHouse/pull/35674) ([Vladimir C](https://github.com/vdimir)).
* [#37172](https://github.com/ClickHouse/ClickHouse/issues/37172)でバックポート: `-WithNames` フォーマットで存在しないカラムの索引に関する bug を修正しました。この問題により、カラム数が 256 を超える場合に `INCORRECT_NUMBER_OF_COLUMNS ` error が発生していました。[#35793](https://github.com/ClickHouse/ClickHouse/issues/35793) をクローズしました。[#35803](https://github.com/ClickHouse/ClickHouse/pull/35803) ([Kruglov Pavel](https://github.com/Avogar)).
* [#37457](https://github.com/ClickHouse/ClickHouse/issues/37457)でバックポート: 外部 ClickHouse Dictionary の hostname を解決できない場合、server の起動に失敗することがありました。この問題を修正しました。[#36451](https://github.com/ClickHouse/ClickHouse/issues/36451) を修正しました。[#36463](https://github.com/ClickHouse/ClickHouse/pull/36463) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#36925](https://github.com/ClickHouse/ClickHouse/issues/36925)でバックポート: 負荷が低く再起動が発生した場合に、破損した compressed log files につながる可能性がある clickhouse-keeper の bug を修正しました。[#36910](https://github.com/ClickHouse/ClickHouse/pull/36910) ([alesapin](https://github.com/alesapin)).
* [#37364](https://github.com/ClickHouse/ClickHouse/issues/37364)でバックポート: `quantileTDigest` における infs の問題を修正しました。[#32107](https://github.com/ClickHouse/ClickHouse/issues/32107) を修正しました。[#37021](https://github.com/ClickHouse/ClickHouse/pull/37021) ([Vladimir Chebotarev](https://github.com/excitoon)).
