<div id="improvement">

</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#15018](https://github.com/ClickHouse/ClickHouse/issues/15018) にバックポート: `Nullable` カラムのソート順が誤っていた問題を修正しました。[#14344](https://github.com/ClickHouse/ClickHouse/issues/14344) を修正します。[#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#14826](https://github.com/ClickHouse/ClickHouse/issues/14826) にバックポート: 符号付き型の縮小 `Int -> Int` キャストにおける単調性の誤検出を修正しました。この問題により、クエリ結果が不正になる可能性がありました。このバグは [#14513](https://github.com/ClickHouse/ClickHouse/issues/14513) で発覚しました。[#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird))。
* [#15147](https://github.com/ClickHouse/ClickHouse/issues/15147) にバックポート: 設定ファイルを ZooKeeper から取得する必要がある場合 (`from_zk` インクルードオプション使用時) に、起動時に ZooKeeper との通信でサーバーがハングする問題を修正しました。[#14814](https://github.com/ClickHouse/ClickHouse/issues/14814) を修正します。[#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* [#15253](https://github.com/ClickHouse/ClickHouse/issues/15253) にバックポート: CacheDictionary のセグメンテーションフォルトを修正しました [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837)。[#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#14986](https://github.com/ClickHouse/ClickHouse/issues/14986) にバックポート: `system.asynchronous_metrics` に論理コアごとの CPU 周波数を公開するようにしました。[#14923](https://github.com/ClickHouse/ClickHouse/issues/14923) を修正します。[#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* [#14968](https://github.com/ClickHouse/ClickHouse/issues/14968) にバックポート: サブクエリに finalizeAggregation 関数が含まれる場合に述語プッシュダウンが正しく機能しない問題を修正しました。[#14847](https://github.com/ClickHouse/ClickHouse/issues/14847) を修正します。[#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov))。
* [#15080](https://github.com/ClickHouse/ClickHouse/issues/15080) にバックポート: `join_algorithm='auto'` での RIGHT または FULL JOIN において、メモリ制限超過時に HashJoin から MergeJoin へ切り替える際に発生するクラッシュを修正しました。[#15002](https://github.com/ClickHouse/ClickHouse/pull/15002) ([Artem Zuikov](https://github.com/4ertus2))。
* [#15057](https://github.com/ClickHouse/ClickHouse/issues/15057) にバックポート: 関数 `bar` に細工された引数を渡した場合にバッファオーバーフローが発生する可能性がありました。[#13926](https://github.com/ClickHouse/ClickHouse/issues/13926) をクローズします。[#15028](https://github.com/ClickHouse/ClickHouse/pull/15028) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#15050](https://github.com/ClickHouse/ClickHouse/issues/15050) にバックポート: String と FixedString の比較にはすでにパディング比較を使用しています (https://github.com/ClickHouse/ClickHouse/blob/master/src/Functions/FunctionsComparison.h#L333) 。この PR では同じロジックをフィールド比較にも適用し、FixedString を主キーとして使用する際の動作を修正しました。[#14908](https://github.com/ClickHouse/ClickHouse/issues/14908) を修正します。[#15033](https://github.com/ClickHouse/ClickHouse/pull/15033) ([Amos Bird](https://github.com/amosbird))。
* [#15143](https://github.com/ClickHouse/ClickHouse/issues/15143) にバックポート: `join_algorithm='auto'` における `Data compressed with different methods` エラーを修正しました。`join_algorithm='partial_merge'` において左テーブルの結合キーの型として LowCardinality を維持するようにしました。[#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2))。
* [#15223](https://github.com/ClickHouse/ClickHouse/issues/15223) にバックポート: `ALTER` クエリ後に新しい構造のデータを `Buffer` テーブルエンジンに挿入できないバグを修正しました。[#15117](https://github.com/ClickHouse/ClickHouse/issues/15117) を修正します。[#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin))。
* [#15404](https://github.com/ClickHouse/ClickHouse/issues/15404) にバックポート: LowCardinality 型で joinGet を使用した際にインスタンスがクラッシュする問題を修正しました。[#15214](https://github.com/ClickHouse/ClickHouse/issues/15214) を修正します。[#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird))。
* [#15279](https://github.com/ClickHouse/ClickHouse/issues/15279) にバックポート: QueryLog における MSan レポートを修正しました。フィールド `memory_usage` に未初期化メモリが使用される可能性がありました。[#15258](https://github.com/ClickHouse/ClickHouse/pull/15258) ([Alexey Milovidov](https://github.com/alexey-milovidov))。

* [#15335](https://github.com/ClickHouse/ClickHouse/issues/15335) にバックポート: MergeTree テーブルのリネームとバックグラウンドクリーンアップ中に発生する競合状態を修正しました。[#15304](https://github.com/ClickHouse/ClickHouse/pull/15304) ([alesapin](https://github.com/alesapin))。
