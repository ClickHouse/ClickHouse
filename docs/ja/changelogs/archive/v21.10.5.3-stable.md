  # 2022年の変更履歴

<div id="clickhouse-release-v211053-stable-fixme-as-compared-to-v2110426-stable">
  ### ClickHouse リリース v21.10.5.3-stable FIXME (v21.10.4.26-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#32252](https://github.com/ClickHouse/ClickHouse/issues/32252)でバックポート: Protobuf の書き込み時にカラムがスキップされる問題を修正しました。この PR では [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160) を修正しています。詳しくはコメント [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318 を参照してください。[#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#32346](https://github.com/ClickHouse/ClickHouse/issues/32346)でバックポート: サブクエリ内で不要なカラムを削除する際のバグを修正しました。GROUP BY のないクエリに集約関数が含まれている場合は、不要に見えても削除しないようにしました。[#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#32151](https://github.com/ClickHouse/ClickHouse/issues/32151) でバックポート: 型付きの関数 `dictGet` を、型が `Nullable` の Dictionary 属性に対して使用した際にクラッシュする不具合を修正しました。[#30980](https://github.com/ClickHouse/ClickHouse/issues/30980) を修正。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32093](https://github.com/ClickHouse/ClickHouse/issues/32093) でバックポート: すべてのレプリカでパーツが失われ、同じパーティション内に他のパーツが存在しない場合、一部の `GET_PART` エントリがレプリケーションキュー内で停止したままになることがありました。これは、パーティションキーに整数型のカラムまたは `Date[Time]` のカラムのみが含まれる場合に修正されています。[#31485](https://github.com/ClickHouse/ClickHouse/issues/31485) を修正。[#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32147](https://github.com/ClickHouse/ClickHouse/issues/32147) でバックポート: パーツの detach 時に発生する `Directory ... already exists and is not empty` エラーを修正しました。[#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32216](https://github.com/ClickHouse/ClickHouse/issues/32216) でバックポート: 一部のレプリカで設定 `replicated_can_become_leader` が無効になっている場合、クォーラム付きで挿入するとアクティブなレプリカ数が誤って判定されることがありました。この不具合を修正しました。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32352](https://github.com/ClickHouse/ClickHouse/issues/32352) でバックポート: `Decimal` 引数を持つ aggregate function `avgWeighted` で発生する SIGFPE によるクラッシュを修正しました。[#32053](https://github.com/ClickHouse/ClickHouse/issues/32053) を修正。[#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32393](https://github.com/ClickHouse/ClickHouse/issues/32393) でバックポート: デフォルト式のデータ型がカラムのデータ型と一致しない場合の `ALTER ... MATERIALIZE COLUMN ...` クエリを修正しました。[#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
