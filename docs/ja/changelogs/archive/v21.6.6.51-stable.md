<div id="clickhouse-release-v216651-stable-fixme-as-compared-to-v216537-stable">

<div id="bug-fix">
  #### バグ修正
</div>

* [#25850](https://github.com/ClickHouse/ClickHouse/issues/25850)でバックポート: `Date` から `DateTime` (または `DateTime64`) への `CAST` で、`DateTime` 型の timezone が使われていませんでした。これは `Date` と `DateTime` の比較にも影響する可能性があります。また、`Date` と `DateTime` の共通型の推論でも、対応する timezone が使われていませんでした。その結果、関数 `if` や配列構築の結果に影響していました。[#24128](https://github.com/ClickHouse/ClickHouse/issues/24128) をクローズします。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25677](https://github.com/ClickHouse/ClickHouse/issues/25677)でバックポート: 乱数生成器の state のデシリアライゼーションに関する bug を修正しました。この問題により、`AggregateFunction(groupArraySample(N), T))` などの一部の data types が非決定論的に動作する可能性がありました。[#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25535](https://github.com/ClickHouse/ClickHouse/issues/25535)でバックポート: DiskS3 から file を読み取る際に発生する可能性のあるエラー &#39;Cannot read from istream at offset 0&#39; を修正しました。[#24885](https://github.com/ClickHouse/ClickHouse/pull/24885) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#25557](https://github.com/ClickHouse/ClickHouse/issues/25557)でバックポート: 他の aggregate functions の aggregate function states を aggregation して aggregate function states を計算する際に発生しうるクラッシュを修正しました (実用的な use case ではありません) 。[#24523](https://github.com/ClickHouse/ClickHouse/issues/24523) を参照してください。[#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25506](https://github.com/ClickHouse/ClickHouse/issues/25506)でバックポート: copier の task config に sharding&#95;key がない場合に発生する segfault を修正しました。[#25419](https://github.com/ClickHouse/ClickHouse/pull/25419) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#25765](https://github.com/ClickHouse/ClickHouse/issues/25765)でバックポート: 非 uint8 型の PREWHERE で発生する assertion を修正し、[#19589](https://github.com/ClickHouse/ClickHouse/issues/19589) をクローズしました。[#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* [#25635](https://github.com/ClickHouse/ClickHouse/issues/25635)でバックポート: `WITH TOTALS` および `WITH FILL` を使ったクエリで誤った totals が返される問題を修正しました。[#20872](https://github.com/ClickHouse/ClickHouse/issues/20872) を修正します。[#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* [#25652](https://github.com/ClickHouse/ClickHouse/issues/25652)でバックポート: クエリなしの `EXPLAIN AST` で発生する null pointer dereference を修正しました。[#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25717](https://github.com/ClickHouse/ClickHouse/issues/25717)でバックポート: ソースのパーティションが空の場合、まれに `REPLACE PARTITION` が無視されることがありましたが、修正しました。[#24869](https://github.com/ClickHouse/ClickHouse/issues/24869) を修正します。[#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25696](https://github.com/ClickHouse/ClickHouse/issues/25696)でバックポート: `Distributed` テーブルをデータベース間で移動する際に発生する `No such file or directory` error を修正しました。[#24971](https://github.com/ClickHouse/ClickHouse/issues/24971) を修正します。[#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25755](https://github.com/ClickHouse/ClickHouse/issues/25755) でバックポート: `system.clusters` へのクエリ実行と同時にクラスター設定を再読み込みした際に発生するデータレースを修正しました。[#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)).
