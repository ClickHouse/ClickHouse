<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530) でバックポート: Dockerfile 内の巨大な `RUN` を、より小さな条件分岐に分割しました。同じ `RUN` レイヤー内で必要なツールを必要なときだけインストールし、その後削除します。OS のアップグレードは冒頭で一度だけ実行します。署名付きリポジトリを検証するための現代的な方法を使用します。古い docker バージョンでの問題に対処するため、ベースリポジトリを ubuntu:20.04 にダウングレードします。golang の脆弱性に対処するため、golang のバージョンをアップグレードします。[#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570) でバックポート: これは [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504) のフォローアップで、リファクタリングの過程でクリーンアップ処理が失われていました。[#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* 二項演算子に NULL 定数の引数が含まれる場合に索引解析が壊れる不具合を修正しました [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* 対象ホストの IP が変更された際に HTTPS セッションを再接続できない問題を修正しました [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* 誤った定数畳み込みを修正しました [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* cache エントリ内の LDAP server params hash の型を修正しました [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* Parquet フォーマットで、例外を発生させる代わりに String から大きな整数をパースするようフォールバックします [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* read-in-order が有効な場合は projection を適用しないようにしました。 [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* ActionsDAG での fuzzer の失敗を修正しました [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
