  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v213201-lts-fixme-as-compared-to-v213191-lts">
  ### ClickHouse リリース v21.3.20.1-lts FIXME (v21.3.19.1-ltsとの比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#32690](https://github.com/ClickHouse/ClickHouse/issues/32690) にバックポート: クォータ制限には達していないにもかかわらず、制限超過として扱われていました。この PR で [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正しました。[#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321))。
* [#33727](https://github.com/ClickHouse/ClickHouse/issues/33727) にバックポート: Nativeフォーマットで LowCardinality データをデシリアライズする際に発生する、low cardinality data の nullポインタ逆参照を修正しました。[#33021](https://github.com/ClickHouse/ClickHouse/pull/33021) ([Harry Lee](https://github.com/HarryLeeIBM))。

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#32791](https://github.com/ClickHouse/ClickHouse/issues/32791) にバックポート: 同じ FixedString を複数指定して fuzzBits を使用した際に発生するクラッシュを修正し、[#32737](https://github.com/ClickHouse/ClickHouse/issues/32737) をクローズしました。 [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴 には含めない / 軽微
</div>

* ProtobufSchemas の data race を修正。 [#27822](https://github.com/ClickHouse/ClickHouse/pull/27822) ([filimonov](https://github.com/filimonov)).
* StrictResize processor の場合に Pipeline が停止する可能性がある問題を修正。 [#32270](https://github.com/ClickHouse/ClickHouse/pull/32270) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* null 引数を指定した `arraySlice` を修正。 [#32456](https://github.com/ClickHouse/ClickHouse/pull/32456) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `hasColumnInTable` の condition が定数で、存在しないカラムを含むクエリを修正。 [#32506](https://github.com/ClickHouse/ClickHouse/pull/32506) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#33024](https://github.com/ClickHouse/ClickHouse/issues/33024) [#33061](https://github.com/ClickHouse/ClickHouse/pull/33061) をマージ。 ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#33022](https://github.com/ClickHouse/ClickHouse/issues/33022) [#33062](https://github.com/ClickHouse/ClickHouse/pull/33062) をマージ。 ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#33065](https://github.com/ClickHouse/ClickHouse/issues/33065) を 21.3 にチェリーピック: [#33050](https://github.com/ClickHouse/ClickHouse/issues/33050) [#33079](https://github.com/ClickHouse/ClickHouse/issues/33079) [#33578](https://github.com/ClickHouse/ClickHouse/pull/33578) をマージ。 ([Heena Bansal](https://github.com/HeenaBansal2009)).
