<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* flatten&#95;nested=1 の場合、すべての Array(Tuple) ではなく、真の Nested 型だけをフラット化する [#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* ALIAS を使用した ALTER COLUMN の問題を修正 [#56493](https://github.com/ClickHouse/ClickHouse/pull/56493) ([Nikolay Degterinsky](https://github.com/evillique)).
* projection カラムに対する互換性のない ALTER を防止 [#56948](https://github.com/ClickHouse/ClickHouse/pull/56948) ([Amos Bird](https://github.com/amosbird)).
* Nullable な MATERIALIZED カラムを使った ALTER UPDATE の後に発生する segfault を修正 [#57147](https://github.com/ClickHouse/ClickHouse/pull/57147) ([Nikolay Degterinsky](https://github.com/evillique)).
* 部分的に materialized された通常の projection での誤った JOIN プラン最適化を修正 [#57196](https://github.com/ClickHouse/ClickHouse/pull/57196) ([Amos Bird](https://github.com/amosbird)).
* すべてのケースで `ReadonlyReplica` Metric を正しく扱うよう修正 [#57267](https://github.com/ClickHouse/ClickHouse/pull/57267) ([Antonio Andelic](https://github.com/antonio2368)).
* background merges が cache 内の一時データストレージを正しく使用するよう修正 [#57275](https://github.com/ClickHouse/ClickHouse/pull/57275) ([vdimir](https://github.com/vdimir)).
* MergeTree mutations がソースパーツの index granularity を再利用するよう修正 [#57352](https://github.com/ClickHouse/ClickHouse/pull/57352) ([Maksim Kita](https://github.com/kitaisreal)).
* 部分的に const なカラムに対する jsonMergePatch 関数の問題を修正 [#57379](https://github.com/ClickHouse/ClickHouse/pull/57379) ([Nikolay Degterinsky](https://github.com/evillique)).
* StreamingFormatExecutor での読み取りバッファの処理を修正 [#57438](https://github.com/ClickHouse/ClickHouse/pull/57438) ([Kruglov Pavel](https://github.com/Avogar)).
* bugfix: SYSTEM STOP LISTEN TCP SECURE を正しくパースするよう修正 [#57483](https://github.com/ClickHouse/ClickHouse/pull/57483) ([joelynch](https://github.com/joelynch)).
* replicated アクセスエンティティの管理では、grant/revoke クエリ内の ON CLUSTER clause を無視するようにした。  [#57538](https://github.com/ClickHouse/ClickHouse/pull/57538) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* system.kafka&#95;consumers をデフォルトで無効化 (メモリリークが継続的に発生する可能性があるため)  [#57822](https://github.com/ClickHouse/ClickHouse/pull/57822) ([Azat Khuzhin](https://github.com/azat)).
* BLAKE3 (Rust) における不正なメモリアクセスを修正 [#57876](https://github.com/ClickHouse/ClickHouse/pull/57876) ([Raúl Marín](https://github.com/Algunenano)).
* CREATE INDEX における関数名を正規化 [#57906](https://github.com/ClickHouse/ClickHouse/pull/57906) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Keeper における不正な preprocessing を修正 [#58069](https://github.com/ClickHouse/ClickHouse/pull/58069) ([Antonio Andelic](https://github.com/antonio2368)).
* Poco::UTF32Encoding における整数 overflow を修正 [#58073](https://github.com/ClickHouse/ClickHouse/pull/58073) ([Andrey Fedotov](https://github.com/anfedotoff)).
* JSONCompactEachRow の並列パースを削除 [#58181](https://github.com/ClickHouse/ClickHouse/pull/58181) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* JSONCompactEachRow の並列パースを修正 [#58250](https://github.com/ClickHouse/ClickHouse/pull/58250) ([Kruglov Pavel](https://github.com/Avogar)).
* 壊れた detached parts を持つレプリカを削除した後に blobs が失われる問題を修正 [#58333](https://github.com/ClickHouse/ClickHouse/pull/58333) ([Alexander Tokmakov](https://github.com/tavplubix)).
* LIMIT のみのクエリでは MergeTreePrefetchedReadPool を無効化 [#58505](https://github.com/ClickHouse/ClickHouse/pull/58505) ([Maksim Kita](https://github.com/kitaisreal)).
