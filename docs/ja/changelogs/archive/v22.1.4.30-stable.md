  # 2022年の変更履歴

<div id="clickhouse-release-v221430-stable-fixme-as-compared-to-v22137-stable">
  ### ClickHouse リリース v22.1.4.30-stable FIXME (v22.1.3.7-stableとの比較)
</div>

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* 22.1リリースブランチにCIチェックをバックポートしました。 [#34897](https://github.com/ClickHouse/ClickHouse/pull/34897) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#34119](https://github.com/ClickHouse/ClickHouse/issues/34119)でバックポート: 分散クエリにおける、リテラル引数を持つ関数 `array` と `tuple` の使用を修正しました。従来は `Not found columns` 例外が発生する可能性がありました。[#33938](https://github.com/ClickHouse/ClickHouse/pull/33938) ([Anton Popov](https://github.com/CurtizJ)).
* [#34124](https://github.com/ClickHouse/ClickHouse/issues/34124)でバックポート: ネストされたタプルの読み取り中に発生するクラッシュを修正しました。[#33838](https://github.com/ClickHouse/ClickHouse/issues/33838) を修正します。[#33956](https://github.com/ClickHouse/ClickHouse/pull/33956) ([Anton Popov](https://github.com/CurtizJ)).
* [#34098](https://github.com/ClickHouse/ClickHouse/issues/34098)でバックポート: 破損したフッターを持つ ORC ファイルのパース中に発生する segfault を修正しました。[#33797](https://github.com/ClickHouse/ClickHouse/issues/33797) をクローズします。[#33984](https://github.com/ClickHouse/ClickHouse/pull/33984) ([Kruglov Pavel](https://github.com/Avogar)).
* [#34038](https://github.com/ClickHouse/ClickHouse/issues/34038)でバックポート: replicated access storage と Keeper を併用した場合に、サーバーが起動できなくなる不具合を修正しました。`default` ユーザーの設定を使う代わりに、Keeper サーバーのソケットのタイムアウト用として `keeper_server.socket_receive_timeout_sec` と `keeper_server.socket_send_timeout_sec` の 2 つの設定を導入しました。[#33973](https://github.com/ClickHouse/ClickHouse/issues/33973) を修正します。[#33988](https://github.com/ClickHouse/ClickHouse/pull/33988) ([alesapin](https://github.com/alesapin)).
* [#34184](https://github.com/ClickHouse/ClickHouse/issues/34184)でバックポート: ZooKeeper 接続断の後、ごくまれに &quot;交差するパーツ&quot; エラーを引き起こす軽微な race condition を修正しました。[#34096](https://github.com/ClickHouse/ClickHouse/pull/34096) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#34467](https://github.com/ClickHouse/ClickHouse/issues/34467)でバックポート: ネイティブプロトコルの変更時に分散テーブルへの inserts を修正しました。最後の変更はバージョン 22.1 で行われたため、そのバージョンへの upgrade 後に分散テーブルへの inserts が失敗する可能性があります。[#34132](https://github.com/ClickHouse/ClickHouse/pull/34132) ([Anton Popov](https://github.com/CurtizJ)).
* [#34209](https://github.com/ClickHouse/ClickHouse/issues/34209)でバックポート: S3 のようなリモートファイルシステムにデータを格納する MergeTree テーブルエンジンファミリーで、LowCardinality カラムの読み取り中に、まれに &quot;Cannot read all data&quot; エラーが発生する不具合を修正しました。[#34139](https://github.com/ClickHouse/ClickHouse/pull/34139) ([alesapin](https://github.com/alesapin)).
* [#34266](https://github.com/ClickHouse/ClickHouse/issues/34266)でバックポート: 実行中のクエリ数を示すメトリック `Query` を修正しました。直近のいくつかの releases では常に 0 になっていました。[#34224](https://github.com/ClickHouse/ClickHouse/pull/34224) ([Anton Popov](https://github.com/CurtizJ)).
* [#34298](https://github.com/ClickHouse/ClickHouse/issues/34298)でバックポート: progress bar の幅を修正しました。誤って文字数を整数に丸めていました。[#34275](https://github.com/ClickHouse/ClickHouse/pull/34275) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#34391](https://github.com/ClickHouse/ClickHouse/issues/34391)でバックポート: 空の配列の読み取り中に、`Data compressed with different methods` エラーにつながる可能性があるまれな不具合の修正を試みました。[#34327](https://github.com/ClickHouse/ClickHouse/pull/34327) ([Anton Popov](https://github.com/CurtizJ)).
* [#34430](https://github.com/ClickHouse/ClickHouse/issues/34430)でバックポート: URL からの schema inference における segfault を修正しました。[#34147](https://github.com/ClickHouse/ClickHouse/issues/34147) をクローズします。[#34405](https://github.com/ClickHouse/ClickHouse/pull/34405) ([Kruglov Pavel](https://github.com/Avogar)).
