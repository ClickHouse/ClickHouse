  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v21171-stable-fixme-as-compared-to-v211613-stable">
  ### ClickHouse リリース v21.1.7.1-stable FIXME (v21.1.6.13-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#21261](https://github.com/ClickHouse/ClickHouse/issues/21261) にバックポート: Replicated(*)MergeTree エンジンで別のパラメータを指定する必要がある場合に、default&#95;replica&#95;path と default&#95;replica&#95;name の values が機能しない問題を修正しました。[#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy)).
* [#21155](https://github.com/ClickHouse/ClickHouse/issues/21155) にバックポート: tuple を map に CAST する際のバグを修正しました。[#21029](https://github.com/ClickHouse/ClickHouse/issues/21029) をクローズしました。[#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting)).
* [#21233](https://github.com/ClickHouse/ClickHouse/issues/21233) にバックポート: mutations は、それをサポートする table engine (MergeTree family、Memory、MaterializedView) でのみ許可されるようになりました。その他のエンジンでは、より明確な error が報告されます。[#21168](https://github.com/ClickHouse/ClickHouse/issues/21168) を修正しました。[#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin)).
* [#21428](https://github.com/ClickHouse/ClickHouse/issues/21428) にバックポート: `UNION` を含むクエリに対する `EXPLAIN` で発生する crash を修正しました。[#20876](https://github.com/ClickHouse/ClickHouse/issues/20876)、[#21170](https://github.com/ClickHouse/ClickHouse/issues/21170) を修正しました。[#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl)).
* [#21408](https://github.com/ClickHouse/ClickHouse/issues/21408) にバックポート: ZooKeeper への不要な reconnects と、単一の ClickHouse server に対して 2 つのアクティブな sessions が存在する可能性を修正しました。どちらの問題も [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678) で導入されたものです。[#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin)).
* [#21549](https://github.com/ClickHouse/ClickHouse/issues/21549) にバックポート: `ALTER MODIFY COLUMN` クエリが、パーティションキー、skip indices、有効期限 (TTL) などの変更にも正しく反映されるようになりました。[#13675](https://github.com/ClickHouse/ClickHouse/issues/13675) を修正しました。[#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin)).
* [#21377](https://github.com/ClickHouse/ClickHouse/issues/21377) にバックポート: `Values` フォーマットから `LowCardinality` カラムを持つテーブルに insert する際に発生する error `Bad cast from type ... to DB::ColumnLowCardinality` を修正しました。[#21140](https://github.com/ClickHouse/ClickHouse/issues/21140) を修正しました。[#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
