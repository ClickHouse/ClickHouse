<div id="bug-fix">
  #### バグ修正
</div>

* [#25480](https://github.com/ClickHouse/ClickHouse/issues/25480) にバックポート: Distributed materialized view の join 時に発生する &quot;Missing columns&quot; 例外を修正しました。[#24870](https://github.com/ClickHouse/ClickHouse/pull/24870) ([Azat Khuzhin](https://github.com/azat)).
* [#25366](https://github.com/ClickHouse/ClickHouse/issues/25366) にバックポート: Protobuf format における、分割されたネストメッセージのシリアライゼーションを修正しました。この PR で [#24647](https://github.com/ClickHouse/ClickHouse/issues/24647) も修正されています。[#25000](https://github.com/ClickHouse/ClickHouse/pull/25000) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#25102](https://github.com/ClickHouse/ClickHouse/issues/25102) にバックポート: 異なる table に対する KILL MUTATION を区別できるようにしました (予期しない `Cancelled mutating parts` error を修正) 。[#25025](https://github.com/ClickHouse/ClickHouse/pull/25025) ([Azat Khuzhin](https://github.com/azat)).
* [#25213](https://github.com/ClickHouse/ClickHouse/issues/25213) にバックポート: CSVWithNames format を使用してカラムの subset を insert する際に発生していた error を修正しました。[#25129](https://github.com/ClickHouse/ClickHouse/issues/25129) を修正します。[#25169](https://github.com/ClickHouse/ClickHouse/pull/25169) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#25352](https://github.com/ClickHouse/ClickHouse/issues/25352) にバックポート: インストール script の TOCTOU error を修正しました。[#25277](https://github.com/ClickHouse/ClickHouse/pull/25277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25385](https://github.com/ClickHouse/ClickHouse/issues/25385) にバックポート: 大きな整数における不正な動作と UBSan レポートを修正しました。以前のバージョンでは `CAST(1e19 AS UInt128)` がゼロを返していました。[#25279](https://github.com/ClickHouse/ClickHouse/pull/25279) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25470](https://github.com/ClickHouse/ClickHouse/issues/25470) にバックポート: Nullable ではないカラムに対する joinGetOrNull を修正しました。これにより [#24261](https://github.com/ClickHouse/ClickHouse/issues/24261) も修正されます。[#25288](https://github.com/ClickHouse/ClickHouse/pull/25288) ([Amos Bird](https://github.com/amosbird)).
* [#25360](https://github.com/ClickHouse/ClickHouse/issues/25360) にバックポート: `LowCardinality` argument を IN で使用したクエリで発生する error `Bad cast from type DB::ColumnLowCardinality to DB::ColumnVector<char8_t>` を修正しました (このバグは 21.6 で発生しました) 。[#25187](https://github.com/ClickHouse/ClickHouse/issues/25187) を修正します。[#25290](https://github.com/ClickHouse/ClickHouse/pull/25290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25356](https://github.com/ClickHouse/ClickHouse/issues/25356) にバックポート: min/maxMap における 論理エラー Cannot sum Array/Tuple を修正しました。[#25298](https://github.com/ClickHouse/ClickHouse/pull/25298) ([Kruglov Pavel](https://github.com/Avogar)).
* [#25436](https://github.com/ClickHouse/ClickHouse/issues/25436) にバックポート: `SummingMergeTree` で `SimpleAggregateFunction(LowCardinality)` をサポートしました。[#25134](https://github.com/ClickHouse/ClickHouse/issues/25134) を修正します。[#25300](https://github.com/ClickHouse/ClickHouse/pull/25300) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25363](https://github.com/ClickHouse/ClickHouse/issues/25363) にバックポート: ZooKeeper 接続が失われると、`ReplicatedMergeTree` table は再接続を試みる前にバックグラウンド操作の完了を待つことがありました。この問題を修正し、現在はバックグラウンド操作を強制的に停止するようになりました。[#25306](https://github.com/ClickHouse/ClickHouse/pull/25306) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25388](https://github.com/ClickHouse/ClickHouse/issues/25388) にバックポート: `quantileDeterministic` 関数および類似の関数で、非決定論的な動作が生じる可能性がある問題を修正しました。これにより [#20480](https://github.com/ClickHouse/ClickHouse/issues/20480) をクローズします。[#25313](https://github.com/ClickHouse/ClickHouse/pull/25313) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25448](https://github.com/ClickHouse/ClickHouse/issues/25448) にバックポート: クエリプランの式プッシュダウン最適化で `WHERE` 条件が失われる問題を修正しました (デフォルトで `query_plan_filter_push_down = 1` を設定) 。[#25368](https://github.com/ClickHouse/ClickHouse/issues/25368) を修正します。[#25370](https://github.com/ClickHouse/ClickHouse/pull/25370) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25407](https://github.com/ClickHouse/ClickHouse/issues/25407) にバックポート: DDL で使用した際の `REPLACE` カラム変換子について、フォーマット済みクエリを正しくクォートするよう修正しました。これにより [#23925](https://github.com/ClickHouse/ClickHouse/issues/23925) を修正します。[#25391](https://github.com/ClickHouse/ClickHouse/pull/25391) ([Amos Bird](https://github.com/amosbird)).
