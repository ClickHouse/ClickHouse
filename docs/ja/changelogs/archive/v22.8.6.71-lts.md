<div id="improvement">

* [#41507](https://github.com/ClickHouse/ClickHouse/issues/41507)でバックポート: 設定 `do_no_evict_index_and_mark_files` を 1 から 0、または 0 から 1 に切り替えた際に発生する cache の非互換性を修正しました。[#41330](https://github.com/ClickHouse/ClickHouse/pull/41330) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix">
  #### バグ修正

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#41284](https://github.com/ClickHouse/ClickHouse/issues/41284)でバックポート: WITHステートメントによって導入された、未使用の不明なカラムに関する問題を修正しました。これにより [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812) が修正されます。 [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* [#41837](https://github.com/ClickHouse/ClickHouse/issues/41837)でバックポート: 論理削除された行を含むパーツのvertical mergeを修正しました。 [#40559](https://github.com/ClickHouse/ClickHouse/pull/40559) ([Alexander Gololobov](https://github.com/davenger)).
* [#41618](https://github.com/ClickHouse/ClickHouse/issues/41618)でバックポート: 集約関数コンビネータにおける、segfault、use-heap-after-free、メモリリークが発生する可能性がある問題を修正しました。 [#40848](https://github.com/ClickHouse/ClickHouse/issues/40848) をクローズします。 [#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41667](https://github.com/ClickHouse/ClickHouse/issues/41667)でバックポート: サブクエリに `OFFSET` 句があり、外側のクエリに `WHERE` 句がある場合に、誤った結果が返る可能性がある問題を修正しました。 [#40416](https://github.com/ClickHouse/ClickHouse/issues/40416) を修正します。 [#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#41685](https://github.com/ClickHouse/ClickHouse/issues/41685)でバックポート: `query_plan_optimize_primary_key` が有効な場合に、誤ったクエリ結果が返る可能性がある問題を修正しました。 [#40599](https://github.com/ClickHouse/ClickHouse/issues/40599) を修正します。 [#41281](https://github.com/ClickHouse/ClickHouse/pull/41281) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41362](https://github.com/ClickHouse/ClickHouse/issues/41362)でバックポート: ディスクのobject storageで発生する、誤った論理エラー `Expected relative path` を修正しました。 [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246) に関連します。 [#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#41359](https://github.com/ClickHouse/ClickHouse/issues/41359)でバックポート: MsgPackフォーマットでUUIDを挿入する前に、カラム型のチェックを追加しました。 [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41596](https://github.com/ClickHouse/ClickHouse/issues/41596)でバックポート: async&#95;socket&#95;for&#95;remote/use&#95;hedged&#95;requests と並列 KILL によって発生する可能性があるデッドロックを修正しました。 [#41343](https://github.com/ClickHouse/ClickHouse/pull/41343) ([Azat Khuzhin](https://github.com/azat)).
* [#41521](https://github.com/ClickHouse/ClickHouse/issues/41521)でバックポート: 22.8 以降、database が `Replicated` で、クラスター名とdatabase名が同じ場合、`ON CLUSTER` 句は無視されていました。その結果、`DROP PARTITION ON CLUSTER` が `Replicated` で想定外の動作をしていました。これを修正し、現在はdatabaseレベルで複製されるクエリに対してのみ `ON CLUSTER` 句が無視されます。 [#41299](https://github.com/ClickHouse/ClickHouse/issues/41299) を修正します。 [#41390](https://github.com/ClickHouse/ClickHouse/pull/41390) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#41480](https://github.com/ClickHouse/ClickHouse/issues/41480)でバックポート: Native format の不正なデータによってクラッシュが発生する可能性がある問題を修正しました。 [#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41806](https://github.com/ClickHouse/ClickHouse/issues/41806)でバックポート: 集約関数 `categorialInformationValue` のプロパティ定義が誤っており、実行時に null ポインタの逆参照が発生する可能性がありました。これにより [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443) をクローズします。 [#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41506](https://github.com/ClickHouse/ClickHouse/issues/41506)でバックポート: Apache `ORC` フォーマットでのデータ書き込み時に、バッファオーバーランが発生する可能性がありました。 [#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41581](https://github.com/ClickHouse/ClickHouse/issues/41581)でバックポート: クエリのキャンセル時 (`KILL QUERY` または server のシャットダウン時) に、ハングまたはデッドロックが発生する可能性がある問題を修正しました。 [#41467](https://github.com/ClickHouse/ClickHouse/pull/41467) ([Azat Khuzhin](https://github.com/azat)).
* [#41645](https://github.com/ClickHouse/ClickHouse/issues/41645)でバックポート: `ORDER BY` と `1500 <= LIMIT <= max_block_size` を含むクエリで、先頭の行が欠落した誤った結果が返される可能性がありました。 [#41182](https://github.com/ClickHouse/ClickHouse/issues/41182) を修正します。 [#41576](https://github.com/ClickHouse/ClickHouse/pull/41576) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41642](https://github.com/ClickHouse/ClickHouse/issues/41642)でバックポート: `OFFSET` を含むクエリで `pipeline stuck` 例外が発生する可能性がある問題を修正しました。このエラーは、`enable_optimize_predicate_expression = 0` かつ `WHERE` に常に false となる条件がある場合に見つかりました。 [#41383](https://github.com/ClickHouse/ClickHouse/issues/41383) を修正します。 [#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41901](https://github.com/ClickHouse/ClickHouse/issues/41901)でバックポート: `optimize_monotonous_functions_in_order_by` 設定が有効な `Merge` テーブルに対する `SELECT` で発生する可能性があるクラッシュを修正しました。 [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269) を修正します。 [#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41836](https://github.com/ClickHouse/ClickHouse/issues/41836)でバックポート: 論理削除用に予約されている仮想カラム名 &#95;row&#95;exists を持つ merge tree テーブルの作成または変更を許可しないようにしました。 [#41716](https://github.com/ClickHouse/ClickHouse/issues/41716) を修正しました。 [#41763](https://github.com/ClickHouse/ClickHouse/pull/41763) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* [#41890](https://github.com/ClickHouse/ClickHouse/issues/41890)でバックポート: `Replicated` database の古いバージョンには、[Zoo]Keeper 内に特別なマーカーがありません。そのため、特別なマークではなく、node に何らかの不明なデータが含まれているかどうかだけを確認する必要があります。 [#41875](https://github.com/ClickHouse/ClickHouse/pull/41875) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
