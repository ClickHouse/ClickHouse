<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#64422](https://github.com/ClickHouse/ClickHouse/issues/64422)でバックポート: [#59989](https://github.com/ClickHouse/ClickHouse/issues/59989) を修正。従来とは逆に、強制的に有効化されている場合、またはデータベースが存在しない場合に init script を実行するようにしました。 [#59991](https://github.com/ClickHouse/ClickHouse/pull/59991) ([jktng](https://github.com/jktng)).
* [#64016](https://github.com/ClickHouse/ClickHouse/issues/64016)でバックポート: パラメーター化ビューで &quot;Invalid storage definition in metadata file&quot; が発生する問題を修正。 [#60708](https://github.com/ClickHouse/ClickHouse/pull/60708) ([Azat Khuzhin](https://github.com/azat)).
* [#63456](https://github.com/ClickHouse/ClickHouse/issues/63456)でバックポート: 関数 `addDays` (および類似の関数) で、最初のパラメーターが `DateTime64` の場合にエラーが報告される問題を修正。 [#61561](https://github.com/ClickHouse/ClickHouse/pull/61561) ([Shuai li](https://github.com/loneylee)).
* [#63289](https://github.com/ClickHouse/ClickHouse/issues/63289)でバックポート: untuple と未解決の lambda によるクラッシュを修正。 [#63131](https://github.com/ClickHouse/ClickHouse/pull/63131) ([Raúl Marín](https://github.com/Algunenano)).
* [#63512](https://github.com/ClickHouse/ClickHouse/issues/63512)でバックポート: `session_timezone` をクエリレベルの設定として使用した際に、`X-ClickHouse-Timezone` ヘッダーが誤った timezone を返す問題を修正。 [#63377](https://github.com/ClickHouse/ClickHouse/pull/63377) ([Andrey Zvonov](https://github.com/zvonand)).
* [#63902](https://github.com/ClickHouse/ClickHouse/issues/63902)でバックポート: `query_plan_remove_redundant_distinct` により、WINDOW FUNCTIONS を含むクエリが壊れる可能性がある問題を修正 (`allow_experimental_analyzer` が on の場合) 。 [#62820](https://github.com/ClickHouse/ClickHouse/issues/62820) も修正。 [#63776](https://github.com/ClickHouse/ClickHouse/pull/63776) ([Igor Nikonov](https://github.com/devcrafter)).
* [#64104](https://github.com/ClickHouse/ClickHouse/issues/64104)でバックポート: 信頼できないバイナリ入力を、より安全な方法でデシリアライズするようにしました。 [#64024](https://github.com/ClickHouse/ClickHouse/pull/64024) ([Robert Schulze](https://github.com/rschu1ze)).
* [#64265](https://github.com/ClickHouse/ClickHouse/issues/64265)でバックポート: CREATE TABLE as MaterializedView で LOGICAL&#95;ERROR が発生する問題を修正。 [#64174](https://github.com/ClickHouse/ClickHouse/pull/64174) ([Raúl Marín](https://github.com/Algunenano)).
* [#64867](https://github.com/ClickHouse/ClickHouse/issues/64867)でバックポート: 複数種類のクエリにおいて、メモリ使用量の追跡が誤る可能性がある問題を修正。対象は、S3 から任意のデータを読み取るクエリ、HTTP プロトコル経由のクエリ、非同期挿入です。 [#64844](https://github.com/ClickHouse/ClickHouse/pull/64844) ([Anton Popov](https://github.com/CurtizJ)).
