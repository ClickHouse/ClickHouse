  ### ClickHouse リリース v20.8.7.15-lts FIXME (v20.8.6.6-lts と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#17029](https://github.com/ClickHouse/ClickHouse/issues/17029) にバックポート: SNI が必要な `clickhouse-server` のセキュアな endpoint に接続できるようにしました。これは、`clickhouse-server` が TLS proxy の背後でホストされている場合に可能です。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#15676](https://github.com/ClickHouse/ClickHouse/issues/15676) にバックポート: 例外発生時にクエリがより速く終了するようにしました。例外が発生した場合、リモートレプリカでの実行をキャンセルします。[#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* [#17106](https://github.com/ClickHouse/ClickHouse/issues/17106) にバックポート: [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) および [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) を修正。&#39;if&#39; 接尾辞付き集約関数の使用時に発生するリモートクエリの失敗を修正。[#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* [#16761](https://github.com/ClickHouse/ClickHouse/issues/16761) にバックポート: max&#95;threads&gt;0 かつ ORDER BY に式がある場合の optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order を修正します。[#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* [#16738](https://github.com/ClickHouse/ClickHouse/issues/16738) にバックポート: `transform_null_in` 設定が有効な場合の、複数カラムおよびタプルに対する `IN` operator を修正。[#15310](https://github.com/ClickHouse/ClickHouse/issues/15310) を修正。[#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* [#17021](https://github.com/ClickHouse/ClickHouse/issues/17021) にバックポート: 引数なしで `any` を使用した場合のクラッシュを修正。これは [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803) 向けです。cc @azat。[#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* [#16880](https://github.com/ClickHouse/ClickHouse/issues/16880) にバックポート: WriteBufferFromS3 にデータが書き込まれなかった場合、multipart upload を中止します。[#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#16950](https://github.com/ClickHouse/ClickHouse/issues/16950) にバックポート: TimeSeriesGroupSum の使用時に ClickHouse server がクラッシュするのを防止します。[#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* [#17077](https://github.com/ClickHouse/ClickHouse/issues/17077) にバックポート: `ORDER BY` を含むクエリで発生する可能性がある `Illegal type of argument` エラーを修正。[#16580](https://github.com/ClickHouse/ClickHouse/issues/16580) を修正。[#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17007](https://github.com/ClickHouse/ClickHouse/issues/17007) にバックポート: インストールスクリプトが config フォルダー内に常にサブディレクトリを作成するよう修正。これは custom config を使用する Docker ビルドにのみ関係します。[#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* [#17011](https://github.com/ClickHouse/ClickHouse/issues/17011) にバックポート: `ALTER TABLE ... MODIFY COLUMN ... NewType` の後、`SELECT` に変更対象カラムに対する `WHERE` 式があり、ALTER がまだ完了していない場合に発生する可能性がある server crash を修正。[#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* [#17040](https://github.com/ClickHouse/ClickHouse/issues/17040) にバックポート: エラー時に `format_avro_schema_registry_url` の IP を再解決します。[#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* [#17171](https://github.com/ClickHouse/ClickHouse/issues/17171) にバックポート: リーダーではない ReplicatedMergeTreeTables で、`ON CLUSTER` クエリが永続的にハングすることがある不具合を修正しました。[#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
