  ### ClickHouse リリース v20.7.1.4310-prestable FIXME (v20.6.1.4066-prestable との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* Date/DateTime のゼロ値を `0000-00-00` および `0000-00-00 00:00:00` として特別に表示する機能は非推奨になりました。[#12442](https://github.com/ClickHouse/ClickHouse/pull/12442) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 引数に少なくとも 1 つの浮動小数点数を含む関数 `modulo` (演算子 `%`) は、両方の引数を整数に変換せず、浮動小数点数に対して直接除算の剰余を計算するようになります。これにより、動作は大半の DBMS と互換性のあるものになります。これは Date および DateTime のデータ型にも適用されます。別名 `mod` を追加しました。これにより [#7323](https://github.com/ClickHouse/ClickHouse/issues/7323) は解決されます。[#12585](https://github.com/ClickHouse/ClickHouse/pull/12585) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* * `Atomic` データベースエンジンで `RENAME DATABASE` と `RENAME DICTIONARY` を実装しました - `ReplicatedMergeTree` の ZooKeeper パスで使用できる暗黙の `{uuid}` マクロを追加しました。これは `CREATE ... ON CLUSTER ...` クエリで動作します。使用するには、`show_table_uuid_in_table_create_query_if_not_nil` を `true` に設定してください。 - `ReplicatedMergeTree` エンジンの引数を省略可能にし、デフォルトで `/clickhouse/tables/{uuid}/{shard}/` と `{replica}` を使用するようにしました。[#12135](https://github.com/ClickHouse/ClickHouse/issues/12135) をクローズします。 - 軽微な修正。 - これらの変更により、`Atomic` データベースエンジンの後方互換性は失われます。既存の `Atomic` データベースは、新しい形式に手動で変換する必要があります。[#12343](https://github.com/ClickHouse/ClickHouse/pull/12343) ([Alexander Tokmakov](https://github.com/tavplubix)).
* joinGet が複数キーのルックアップをサポートするようになりました。[#12418](https://github.com/ClickHouse/ClickHouse/pull/12418) ([Amos Bird](https://github.com/amosbird)).
* `Log`、`TinyLog`、`StripeLog` エンジンで、挿入エラー時にロールバックするようにしました。以前のバージョンでは、挿入エラーによってテーブルの状態に不整合が生じていました (これはドキュメントどおりの動作であり、これらのテーブルエンジンでは正常です) 。これにより [#12402](https://github.com/ClickHouse/ClickHouse/issues/12402) を修正します。[#12426](https://github.com/ClickHouse/ClickHouse/pull/12426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* タイムゾーンの影響で負の Unix timestamp となる `DateTime` 値 (たとえばモスクワの `1970-01-01 00:00:00`) のパース時に overflow が発生するのを回避します。代わりに 0 に丸めます。これにより [#3470](https://github.com/ClickHouse/ClickHouse/issues/3470) を修正します。これにより [#4172](https://github.com/ClickHouse/ClickHouse/issues/4172) を修正します。[#12443](https://github.com/ClickHouse/ClickHouse/pull/12443) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* S3 storages へのリクエストに関する複数のメトリクスを追加しました。[#12464](https://github.com/ClickHouse/ClickHouse/pull/12464) ([ianton-ru](https://github.com/ianton-ru)).
* `multiple_joins_rewriter_version` のデフォルト値を 2 に変更しました。これにより、カラム名を認識する新しい複数 JOIN リライターが有効になります。[#12469](https://github.com/ClickHouse/ClickHouse/pull/12469) ([Artem Zuikov](https://github.com/4ertus2)).
* より標準的な書き方で JOIN の kind と type を指定できるようにしました。`SEMI LEFT JOIN` ではなく `LEFT SEMI JOIN` と書けます。現時点ではどちらも正しいです。[#12520](https://github.com/ClickHouse/ClickHouse/pull/12520) ([Artem Zuikov](https://github.com/4ertus2)).
* explain クエリのフォーマットがデフォルトで上書きされる問題を修正しました。issue [#12432](https://github.com/ClickHouse/ClickHouse/issues/12432)。[#12541](https://github.com/ClickHouse/ClickHouse/pull/12541) ([BohuTANG](https://github.com/BohuTANG)).
