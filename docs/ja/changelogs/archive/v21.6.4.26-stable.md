  ### ClickHouse リリース v21.6.4.26-stable FIXME (v21.6.3.14-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#24969](https://github.com/ClickHouse/ClickHouse/issues/24969) にバックポート: postgresql プロトコルで NULL 値を許可するよう修正。[#22622](https://github.com/ClickHouse/ClickHouse/issues/22622) をクローズ。[#24857](https://github.com/ClickHouse/ClickHouse/pull/24857) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#25186](https://github.com/ClickHouse/ClickHouse/issues/25186) にバックポート: バケットのルートに S3 ディスクを宣言する際のバグを修正。以前は次のエラーが発生していた: ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):。[#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon))。
* [#25023](https://github.com/ClickHouse/ClickHouse/issues/25023) にバックポート: 分散クエリにおける limit/offset の設定を修正（リモートノードでは無視するよう対応）。[#24940](https://github.com/ClickHouse/ClickHouse/pull/24940) ([Azat Khuzhin](https://github.com/azat))。
* [#25049](https://github.com/ClickHouse/ClickHouse/issues/25049) にバックポート: `alter move/replace partition` の同時実行中にレプリケーションキューで発生する極めてまれなエラー `Tagging already tagged part` を修正。[#22142](https://github.com/ClickHouse/ClickHouse/issues/22142) の修正も含む可能性あり。[#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin))。
* [#25081](https://github.com/ClickHouse/ClickHouse/issues/25081) にバックポート: **空でない** `GROUP BY` キーを持つ集計プロジェクションを使用して、**空の**キーによる `GROUP BY` クエリを実行した際に誤った結果が返される問題を修正。[#25055](https://github.com/ClickHouse/ClickHouse/pull/25055) ([Amos Bird](https://github.com/amosbird))。
* [#25107](https://github.com/ClickHouse/ClickHouse/issues/25107) にバックポート: `a UInt32 ALIAS a + 1` や `b UInt32 MATERIALIZED b` のように、カラムが自身を参照するテーブルを作成できてしまうバグを修正。[#24910](https://github.com/ClickHouse/ClickHouse/issues/24910)、[#24292](https://github.com/ClickHouse/ClickHouse/issues/24292) を修正。[#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin))。
* [#25106](https://github.com/ClickHouse/ClickHouse/issues/25106) にバックポート: mapContains における定数マップのバグを修正。このバグにより `empty column was returned by function mapContains` というエラーが発生していた。[#25077](https://github.com/ClickHouse/ClickHouse/issues/25077) をクローズ。[#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar))。
* [#25143](https://github.com/ClickHouse/ClickHouse/issues/25143) にバックポート: CROSS JOIN と `joined_subquery_requires_alias = 0` を使用したクエリでのクラッシュを修正。[#24011](https://github.com/ClickHouse/ClickHouse/issues/24011) を修正。[#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#25157](https://github.com/ClickHouse/ClickHouse/issues/25157) にバックポート: パーティションキーに `UUID` を使用しているテーブルで 21.5 へのアップデート後にパーツが失われる可能性がある問題を修正（パーティションキーへの `UUID` の使用は推奨されない）。[#25070](https://github.com/ClickHouse/ClickHouse/issues/25070) を修正。[#25127](https://github.com/ClickHouse/ClickHouse/pull/25127) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#25182](https://github.com/ClickHouse/ClickHouse/issues/25182) にバックポート: FINAL を伴う `SELECT` ではテーブルのプロジェクションを使用しないよう修正。この組み合わせはまだサポートされていない。[#25163](https://github.com/ClickHouse/ClickHouse/pull/25163) ([Amos Bird](https://github.com/amosbird))。
