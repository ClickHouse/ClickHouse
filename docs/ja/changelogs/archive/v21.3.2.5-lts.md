  # 2022年 変更履歴

<div id="clickhouse-release-v21325-lts-fixme-as-compared-to-v21215869-prestable">
  ### ClickHouse リリース v21.3.2.5-lts FIXME (v21.2.1.5869-prestable と比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 大文字と小文字を区別しないすべての関数名は、クエリ解析時に小文字へ正規化されるようになりました。これは、プロジェクションクエリのルーティングに必要です。 [#20174](https://github.com/ClickHouse/ClickHouse/pull/20174) ([Amos Bird](https://github.com/amosbird)).
* 古い構文で table TTL を指定した MergeTree テーブルの作成は、それが単に無視されてしまうため、現在は許可されていません。古いテーブルの Attach は引き続き可能です。 [#20282](https://github.com/ClickHouse/ClickHouse/pull/20282) ([alesapin](https://github.com/alesapin)).

<div id="new-feature">
  #### 新機能
</div>

* 実験的な `Replicated` データベースエンジンを追加しました。複数のホスト間で DDLクエリをレプリケートします。[#16193](https://github.com/ClickHouse/ClickHouse/pull/16193) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 分散クエリの重複排除は [#16033](https://github.com/ClickHouse/ClickHouse/issues/16033) のフォローアップであり、提案 [#13574](https://github.com/ClickHouse/ClickHouse/issues/13574) を部分的に解決します。[#17348](https://github.com/ClickHouse/ClickHouse/pull/17348) ([xjewer](https://github.com/xjewer)).
* DiskS3 のメタデータファイルをバックアップ/リストアできるようになりました。[#18377](https://github.com/ClickHouse/ClickHouse/pull/18377) ([Pavel Kovalenko](https://github.com/Jokser)).
* * プルリクエストに含まれる変更です。[#18508](https://github.com/ClickHouse/ClickHouse/pull/18508) ([PHO](https://github.com/depressed-pho)).
* file() 関数が追加され、ファイルを String として読み込めるようになりました。これにより [#issue:18851](https://github.com/ClickHouse/ClickHouse/issues/18851) がクローズされます。 [#19204](https://github.com/ClickHouse/ClickHouse/pull/19204) ([keenwolf](https://github.com/keen-wolf))。
* `MergeTree*` エンジンを使用するテーブルに、クエリの同時実行制御のための新しいテーブルレベル設定が 2 つ追加されました。設定 `max_concurrent_queries` は、このテーブルに関連する同時実行クエリ数を制限します。設定 `min_marks_to_honor_max_concurrent_queries` は、クエリが少なくともこの数のマークを読み取る場合にのみ、前述の設定を適用することを指定します。 [#19544](https://github.com/ClickHouse/ClickHouse/pull/19544) ([Amos Bird](https://github.com/amosbird))。
* * [#18454](https://github.com/ClickHouse/ClickHouse/issues/18454)で言及。関数 `htmlOrxmlCoarseParse` を追加。`<script></script>` の解析をサポート。`<style></style>` の解析をサポート。`<![CDATA[]]>` の解析をサポート。空白の折りたたみをサポート。任意の `<content>` フォーマットの解析をサポート。HyperScan が SIMD をサポート。すべて単一パスで実行されます。[#19600](https://github.com/ClickHouse/ClickHouse/pull/19600) ([zlx19950903](https://github.com/zlx19950903)).
* QUOTA タイプ QUERY&#95;SELECTS および QUERY&#95;INSERTS を追加しました。[#19603](https://github.com/ClickHouse/ClickHouse/pull/19603) ([JackyWoo](https://github.com/JackyWoo)).
* ExecutableDictionarySource に implicit&#95;key オプションを追加しました。[#14527](https://github.com/ClickHouse/ClickHouse/issues/14527) を修正しています。[#19677](https://github.com/ClickHouse/ClickHouse/pull/19677) ([Maksim Kita](https://github.com/kitaisreal)).
* S3 client で Server Side Encryption Customer Keys (`x-amz-server-side-encryption-customer-(key/md5)` header) のサポートを追加しました。[the link](https://docs.aws.amazon.com/AmazonS3/latest/dev/ServerSideEncryptionCustomerKeys.html) を参照してください。[#19428](https://github.com/ClickHouse/ClickHouse/issues/19428) をクローズしました。[#19748](https://github.com/ClickHouse/ClickHouse/pull/19748) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Function `reinterpretAs` を更新し、big integer をサポートするようにしました。[#19691](https://github.com/ClickHouse/ClickHouse/issues/19691) を修正しています。[#19858](https://github.com/ClickHouse/ClickHouse/pull/19858) ([Maksim Kita](https://github.com/kitaisreal)).
* 分散テーブルから特定の分片にデータを insert できるようにする setting `insert_shard_id` を追加しました。[#19961](https://github.com/ClickHouse/ClickHouse/pull/19961) ([flynn](https://github.com/ucasfl)).
* UTC からのオフセットを秒単位で返す timezoneOffset(datetime) function を追加しました。これにより [#issue:19850](https://github.com/ClickHouse/ClickHouse/issues/19850) をクローズします。[#19962](https://github.com/ClickHouse/ClickHouse/pull/19962) ([keenwolf](https://github.com/keen-wolf)).
* `system.part_log` table に、新しい `event_time_microseconds` column を追加しました。[#20027](https://github.com/ClickHouse/ClickHouse/pull/20027) ([Bharat Nallan](https://github.com/bharatnc)).
* ... 連続する行の差分を合計する aggregate function `deltaSum` を追加しました。[#20057](https://github.com/ClickHouse/ClickHouse/pull/20057) ([Russ Frank](https://github.com/rf)).
* 非アクティブなパーツが多すぎる場合に insertion を遅延させる、または error を throw するための 2 つの settings を追加しました。これは、server がパーツを十分な速さでクリーンアップできない場合に有用です。[#20178](https://github.com/ClickHouse/ClickHouse/pull/20178) ([Amos Bird](https://github.com/amosbird)).
* file engine settings `engine_file_empty_if_not_exists` および `engine_file_truncate_on_insert` を追加しました。[#20620](https://github.com/ClickHouse/ClickHouse/pull/20620) ([M0r64n](https://github.com/M0r64n)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* `do_not_merge_across_partitions_select_final` 設定が 1 の場合、`level>0` の単一 part に対する parallel select final を追加しました。[#19375](https://github.com/ClickHouse/ClickHouse/pull/19375) ([Kruglov Pavel](https://github.com/Avogar)).
* joins 時のビットマップカラムのパフォーマンスを改善しました。[#19407](https://github.com/ClickHouse/ClickHouse/pull/19407) ([templarzq](https://github.com/templarzq)).
* 受信および送信データのコピー回数を減らすため、HTTP server を部分的に再実装しました。これにより、HTTP 経由で長いレコードを insert する際のパフォーマンスが最大 1.5 倍向上します。[#19516](https://github.com/ClickHouse/ClickHouse/pull/19516) ([Ivan](https://github.com/abyss7)).
* より厳密な aliasing により、aggregate functions のパフォーマンスを改善しました。[#19946](https://github.com/ClickHouse/ClickHouse/pull/19946) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* DataType パーサーが指数的な計算量になる可能性があるケースを修正しました (fuzzer により発見) 。これにより [#20096](https://github.com/ClickHouse/ClickHouse/issues/20096) をクローズします。[#20132](https://github.com/ClickHouse/ClickHouse/pull/20132) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Memory` table 向けに `compress` 設定を追加しました。これを有効にすると、その table の RAM 使用量が減少します。一部のマシンや datasets では SELECT も高速になる場合がありますが、常にそうとは限りません。これにより [#20093](https://github.com/ClickHouse/ClickHouse/issues/20093) をクローズします。注: Memory table が MergeTree より遅くなる理由としては、(1) 圧縮がない (2) blocks のサイズが固定 (3) indices と prewhere がない、などがあります... [#20168](https://github.com/ClickHouse/ClickHouse/pull/20168) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Memory table への INSERT SELECT では、blocks を過度にまとめないようにしました。以前のバージョンでは、INSERT SELECT 後に Memory table 内で非効率なデータ表現が作成されていました。これにより [#13052](https://github.com/ClickHouse/ClickHouse/issues/13052) をクローズします。[#20169](https://github.com/ClickHouse/ClickHouse/pull/20169) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 複数の固定サイズフィールドによる aggregation のパフォーマンスを改善しました (未確認) 。[#20454](https://github.com/ClickHouse/ClickHouse/pull/20454) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 極端なケース (読み取り速度が 50 GB/sec 程度の場合) における `Memory` table からの読み取りを高速化しました。pipeline の簡素化と、それに伴う pipeline scheduling での lock 競合の減少によるものです。[#20468](https://github.com/ClickHouse/ClickHouse/pull/20468) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 複数の固定サイズ key による GROUP BY のパフォーマンスを改善しました。[#20472](https://github.com/ClickHouse/ClickHouse/pull/20472) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 設定 `distributed_aggregation_memory_efficient` がデフォルトで有効になりました。これによりメモリ使用量が減少し、distributed queries のパフォーマンスが向上します。[#20599](https://github.com/ClickHouse/ClickHouse/pull/20599) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* aggregation における code をわずかに改善しました。[#20978](https://github.com/ClickHouse/ClickHouse/pull/20978) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* パフォーマンス向上のため、intDiv/module vectorConstant specializations を再度追加しました。これにより [#21293](https://github.com/ClickHouse/ClickHouse/issues/21293) を修正します。回帰は [https://github.com/ClickHouse/ClickHouse/pull/18145](https://github.com/ClickHouse/ClickHouse/pull/18145) で導入されました。[#21307](https://github.com/ClickHouse/ClickHouse/pull/21307) ([Amos Bird](https://github.com/amosbird)).

<div id="improvement">
  #### 改善
</div>

* 式が関数で、かつ `ORDER BY` キーと同じである場合の `TTL` の作成を修正しました。これにより、`GROUP BY` を使った `TTL` で主キーカラムに対するカスタム集約を設定できるようになりました。後方互換性のない変更: `GROUP BY` に含まれず、明示的にも設定されていない主キーカラムには、TTL の有効期限切れ時に `max` ではなく `any` 関数が適用されるようになりました。また、`WHERE` または `GROUP BY` を伴う TTL を使用している場合、ローリングアップデート中のマージで例外が発生することがあります。 [#15450](https://github.com/ClickHouse/ClickHouse/pull/15450) ([Anton Popov](https://github.com/CurtizJ)).
* リモートクエリ向けの Hedged Requests。`use_hedged_requests` が有効 (デフォルト) な場合、1 つのクエリに対して異なるレプリカへの複数の connection を確立できるようにしました。既存のレプリカへの connection が `hedged_connection_timeout` 以内に確立されない場合、または `receive_data_timeout` 以内にデータを受信しなかった場合、新しい connection が有効になります。クエリは、最初に空でない Progress パケット (または `allow_changing_replica_until_first_data_packet` が有効な場合は Data パケット) を送信した connection を使用し、その他の connections はキャンセルされます。`max_parallel_replicas > 1` のクエリにも対応しています。 [#19291](https://github.com/ClickHouse/ClickHouse/pull/19291) ([Kruglov Pavel](https://github.com/Avogar)).
* 致命的な stacktraces に対して inline frames を出力するようにしました。 [#19317](https://github.com/ClickHouse/ClickHouse/pull/19317) ([Ivan](https://github.com/abyss7)).
* 書き込みエラーを黙って無視しないようにしました。 [#19451](https://github.com/ClickHouse/ClickHouse/pull/19451) ([Azat Khuzhin](https://github.com/azat)).
* テーブルに row-level security expressions が指定されている場合の `PREWHERE` サポートを追加しました。 [#19576](https://github.com/ClickHouse/ClickHouse/pull/19576) ([Denis Glazachev](https://github.com/traceon)).
* IStoragePolicy インターフェイスを追加しました。 [#19608](https://github.com/ClickHouse/ClickHouse/pull/19608) ([Ernest Zaslavsky](https://github.com/kreuzerkrieg)).
* 非同期送信の保留バイト数に基づいて Distributed への INSERT をスロットリングする機能を追加しました (`Distributed` engine に `bytes_to_delay_insert`/`max_delay_to_insert` および `bytes_to_throw_insert` 設定を追加) 。 [#19673](https://github.com/ClickHouse/ClickHouse/pull/19673) ([Azat Khuzhin](https://github.com/azat)).
* JOIN に関係しない conditions を WHERE clause に移動します。 [#18720](https://github.com/ClickHouse/ClickHouse/issues/18720). [#19685](https://github.com/ClickHouse/ClickHouse/pull/19685) ([hexiaoting](https://github.com/hexiaoting)).
* Buffer profile 用の個別の config ディレクティブを追加しました。 [#19721](https://github.com/ClickHouse/ClickHouse/pull/19721) ([Azat Khuzhin](https://github.com/azat)).
* `system.parts` に MaterializeMySQL テーブルを表示するようにしました。 [#19770](https://github.com/ClickHouse/ClickHouse/pull/19770) ([Stig Bakken](https://github.com/stigsb)).
* 再起動後、MaxDDLEntryID を最後の値で初期化するようにしました。この PR 以前は、新しい DDLTask が処理されるまで MaxDDLEntryID は 0 のままでした。 [#19924](https://github.com/ClickHouse/ClickHouse/pull/19924) ([Amos Bird](https://github.com/amosbird)).
* 一致しない場合に、分散テーブルへの INSERT 用のブロック構造変換を追加しました。 [#19947](https://github.com/ClickHouse/ClickHouse/pull/19947) ([Azat Khuzhin](https://github.com/azat)).
* ユーザーが `JSONExtract` 関数を `Float32` 型を要求して呼び出した場合、結果型への不正確な変換を許可するようにしました。たとえば、JSON 内の数値 `0.1` は倍精度であり Float32 では表現できませんが、それでもユーザーはその値を取得したい場合があります。以前のバージョンでは、変換が不正確であることを示すため、非 Nullable 型には 0 を、Nullable 型には NULL を返していました。このロジックは 100% 正しかったものの、ユーザーには意外で、疑問の原因になっていました。これにより [#13962](https://github.com/ClickHouse/ClickHouse/issues/13962) をクローズします。 [#19960](https://github.com/ClickHouse/ClickHouse/pull/19960) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MYSQL&#95;OPT&#95;RECONNECT オプションの値を、mysql レプリカの config セクションにある &quot;opt&#95;reconnect&quot; パラメータで制御できるようになりました。 [#19998](https://github.com/ClickHouse/ClickHouse/pull/19998) ([Alexander Kazakov](https://github.com/Akazz)).
* 他のストレージ インターフェイスと同様に、IDisk::getType() が `String` ではなく `DiskType` を返すようにしました。 [#19999](https://github.com/ClickHouse/ClickHouse/pull/19999) ([Ernest Zaslavsky](https://github.com/kreuzerkrieg)).
* 実行可能 Dictionary で、誤った使い方をした場合にのみ発生し得たデータ競合を修正しました (スクリプトが入力を無視してデータを返す場合) 。 [#20045](https://github.com/ClickHouse/ClickHouse/pull/20045) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `system.tables` で MaterializeMySQL テーブルの詳細をすべて表示するようにしました。 [#20051](https://github.com/ClickHouse/ClickHouse/pull/20051) ([Stig Bakken](https://github.com/stigsb)).
* `system.zookeeper` の path に対する IN クエリをサポートしました。 [#20105](https://github.com/ClickHouse/ClickHouse/pull/20105) ([小路](https://github.com/nicelulu)).

* `avg` aggregate function 内の算術式に対して代数的最適化を行います。[#20092](https://github.com/ClickHouse/ClickHouse/issues/20092) をクローズしました。[#20183](https://github.com/ClickHouse/ClickHouse/pull/20183) ([flynn](https://github.com/ucasfl)).
