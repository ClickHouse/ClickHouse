  ### ClickHouse リリース v20.12.5.14-stable FIXME (v20.12.4.5-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#18166](https://github.com/ClickHouse/ClickHouse/issues/18166) でバックポート: クエリ `MODIFY COLUMN ... REMOVE TTL` で、実際にはカラムの有効期限 (TTL) が削除されない問題を修正しました。[#18130](https://github.com/ClickHouse/ClickHouse/pull/18130) ([alesapin](https://github.com/alesapin)).
* [#18424](https://github.com/ClickHouse/ClickHouse/issues/18424) でバックポート: 二段階集約の使用時に、combinator `Distinct` を持つ aggregate functions で発生する可能性のある crash を修正しました。[#17682](https://github.com/ClickHouse/ClickHouse/issues/17682) を修正しています。[#18365](https://github.com/ClickHouse/ClickHouse/pull/18365) ([Anton Popov](https://github.com/CurtizJ)).
* [#18428](https://github.com/ClickHouse/ClickHouse/issues/18428) でバックポート: table `system.settings_profile_elements` の filling を修正しました。この PR で [#18231](https://github.com/ClickHouse/ClickHouse/issues/18231) を修正しています。[#18379](https://github.com/ClickHouse/ClickHouse/pull/18379) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#18482](https://github.com/ClickHouse/ClickHouse/issues/18482) でバックポート: wide パーツから compact パーツへの merges を制限しました。vertical merge の場合、結果のパーツが壊れる原因となっていました。[#18381](https://github.com/ClickHouse/ClickHouse/pull/18381) ([Anton Popov](https://github.com/CurtizJ)).
* [#18471](https://github.com/ClickHouse/ClickHouse/issues/18471) でバックポート: `Nullable(String)` 型の argument で `toType(...)` functions (`toDate`, `toUInt32` など) を実行した際に発生する `value is too short` error を修正しました。現在は、このような functions は parsing error 時に throwing exception する代わりに `NULL` を返します。[#7673](https://github.com/ClickHouse/ClickHouse/issues/7673) を修正しています。[#18445](https://github.com/ClickHouse/ClickHouse/pull/18445) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#18533](https://github.com/ClickHouse/ClickHouse/issues/18533) でバックポート: `parseDateTimeBestEffort` function で 12AM を正しくサポートするようにしました。これにより [#18402](https://github.com/ClickHouse/ClickHouse/issues/18402) を修正しています。[#18449](https://github.com/ClickHouse/ClickHouse/pull/18449) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* [#18502](https://github.com/ClickHouse/ClickHouse/issues/18502) でバックポート: merges 中の AIO を使った書き込みを無効化しました。これは、merge 中に主キーカラムでごくまれにデータ破損が発生する可能性があるためです。[#18481](https://github.com/ClickHouse/ClickHouse/pull/18481) ([alesapin](https://github.com/alesapin)).
