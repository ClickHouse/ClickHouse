  ### ClickHouse リリース v24.12.1.1614-stable (a6d2b2e35b2) FIXME、v24.12.1.1-new (e4c9b022237) と比較

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 関数 `greatest` と `least` は、NULL の入力値を無視するようになりました。以前は、引数のいずれかが NULL の場合は NULL を返していました。たとえば、`SELECT greatest(1, 2, NULL)` は現在 2 を返します。これにより、挙動が PostgreSQL と互換になります。 [#65519](https://github.com/ClickHouse/ClickHouse/pull/65519) ([kevinyhzou](https://github.com/KevinyhZou)).
* Poco ドライバーをベースにしたレガシーな MongoDB インテグレーションは削除されました。サーバー設定 `use_legacy_mongodb_integration` は廃止されており、現在は効果がありません。 [#71997](https://github.com/ClickHouse/ClickHouse/pull/71997) ([Kirill Nikiforov](https://github.com/allmazz)).



<div id="new-feature">
  #### 新機能
</div>

* MergeTree テーブルを ReplicatedMergeTree としてアタッチする、またはその逆を行うクエリを追加しました。[#65401](https://github.com/ClickHouse/ClickHouse/pull/65401) ([Kirill](https://github.com/kirillgarbar)).
* 指定したテーブルのすべてのパーツ、またはテーブルが指定されていない場合はすべてのテーブルのプライマリインデックスを読み込む SYSTEM LOAD PRIMARY KEY コマンドを実装しました。ベンチマークやクエリ実行時の余分なレイテンシの防止に役立ちます。[#66252](https://github.com/ClickHouse/ClickHouse/pull/66252) ([ZAWA_ll](https://github.com/Zawa-ll)).
* 指定したテーブルのすべてのパーツ、またはテーブルが指定されていない場合はすべてのテーブルのプライマリインデックスを読み込む `SYSTEM LOAD PRIMARY KEY` ステートメントを追加しました。ベンチマークやクエリ実行時の余分なレイテンシの防止に役立ちます。[#67733](https://github.com/ClickHouse/ClickHouse/pull/67733) ([ZAWA_ll](https://github.com/Zawa-ll)).
* [Iceberg データストレージ](https://iceberg.apache.org/spec/#file-system-operations)フォーマットは、テーブルのスキーマを変更するための豊富なオプションをユーザーに提供します。このプルリクエストでは、カラムの順序、カラム名、および単純な型の拡張が変更された Iceberg フォーマットのテーブルの読み取りを実装しました。[#69445](https://github.com/ClickHouse/ClickHouse/pull/69445) ([Daniil Ivanik](https://github.com/divanik)).
* `DateTime64` を固定秒精度の `Int64` 値に変換する関数 `toUnixTimestamp64Second` を追加しました。これにより、1970年1月1日木曜日 00:00:00 UTC より前の日付に対して負の値を返すことができます。[#70597](https://github.com/ClickHouse/ClickHouse/pull/70597) ([zhanglistar](https://github.com/zhanglistar)).
* ソーステーブルのプロジェクションおよびセカンダリ索引がターゲットテーブルのサブセットである場合にアタッチを許可する新しい設定 `enforce_index_structure_match_on_partition_manipulation` を追加しました。[#70602](https://github.com/ClickHouse/ClickHouse/issues/70602) をクローズ。[#70603](https://github.com/ClickHouse/ClickHouse/pull/70603) ([zwy991114](https://github.com/zwy991114)).
* 関数 `cast` の出力が Apache Spark と異なるため、gluten プロジェクトで差異が生じていました（https://github.com/apache/incubator-gluten/issues/7602 参照）。このプルリクエストでは Spark テキスト出力フォーマットのサポート機能を追加しました（デフォルトは無効）。[#70957](https://github.com/ClickHouse/ClickHouse/pull/70957) ([zhanglistar](https://github.com/zhanglistar)).
* MergeTree のソートキーにおける降順ソートのサポートを有効にする新しい設定 `allow_experimental_reverse_key` を導入しました。時系列分析、特に TopN クエリに有用です。使用例: ```sql CREATE TABLE example ( time DateTime, key Int32, value String ) ENGINE = MergeTree ORDER BY (time DESC, key); -- 'time' フィールドの降順 SETTINGS allow_experimental_reverse_key = 1;. [#71095](https://github.com/ClickHouse/ClickHouse/pull/71095) ([Amos Bird](https://github.com/amosbird)).
* Iceberg REST カタログとの統合を追加しました。[#71542](https://github.com/ClickHouse/ClickHouse/pull/71542) ([Kseniia Sumarokova](https://github.com/kssenii)).
* クエリプランにおいて join の内側（ビルド）テーブルとして機能するサイドを選択するオプションを追加しました。これは `query_plan_join_swap_table` で制御され、`auto` に設定できます。このモードでは、ClickHouse は行数が最も少ないテーブルを選択しようとします。[#71577](https://github.com/ClickHouse/ClickHouse/pull/71577) ([Vladimir Cherkasov](https://github.com/vdimir)).
* ALTER USER {ADD|MODIFY|DROP SETTING}、ALTER USER {ADD|DROP PROFILE} の構文を追加しました。ALTER ROLE および ALTER PROFILE についても同様です。[#72050](https://github.com/ClickHouse/ClickHouse/pull/72050) ([pufit](https://github.com/pufit)).
* Precision Recall 曲線の AUC（曲線下面積）を計算する `arrayPrAUC` 関数を追加しました。[#72073](https://github.com/ClickHouse/ClickHouse/pull/72073) ([Emmanuel](https://github.com/emmanuelsdias)).
* `MergeTree` テーブルのプライマリインデックス用 cache を追加しました（テーブル設定 `use_primary_key_cache` で有効化可能）。プライマリインデックスに対してレイジーロードと cache が有効な場合、メモリに永続保持する代わりにオンデマンドで cache に読み込まれます（マーク cache と同様）。データパーツの挿入・マージ・フェッチ時およびテーブル再起動時のプライマリインデックスのプリウォームを追加しました（設定 `prewarm_primary_key_cache` で有効化可能）。[#72102](https://github.com/ClickHouse/ClickHouse/pull/72102) ([Anton Popov](https://github.com/CurtizJ)).
* [#73593](https://github.com/ClickHouse/ClickHouse/issues/73593) でバックポート: `SELECT` および `VIEW` ステートメントでエイリアスがサポートされるようになりました（例: `SELECT b FROM (SELECT number, number*2 FROM numbers(2)) AS x (a, b);`）。これにより TPC-H クエリ 15 を変更なしで実行できます。[#72480](https://github.com/ClickHouse/ClickHouse/pull/72480) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Array 型向けに `indexOfAssumeSorted` 関数を追加しました。非降順にソートされた Array での検索を最適化します。[#72517](https://github.com/ClickHouse/ClickHouse/pull/72517) ([Eric Kurbanov](https://github.com/erickurbanov)).
* 集計関数 `groupConcat` の省略可能な第2引数として区切り文字を使用できるようにしました。[#72540](https://github.com/ClickHouse/ClickHouse/pull/72540) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* HTTP レスポンスヘッダーをカスタマイズできる新しい設定 `http_response_headers` を追加しました。たとえば、データベースに保存された画像をブラウザにレンダリングさせることができます。[#59620](https://github.com/ClickHouse/ClickHouse/issues/59620) をクローズ。[#72656](https://github.com/ClickHouse/ClickHouse/pull/72656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Int64 の Unix timestamp 値を DateTime64 に変換する関数 `fromUnixTimestamp64Second` を追加しました。[#73146](https://github.com/ClickHouse/ClickHouse/pull/73146) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* オブジェクトストレージディスクにおける `clickhouse disks remove --recursive` のメモリ使用量を削減しました。[#67323](https://github.com/ClickHouse/ClickHouse/pull/67323) ([Kirill](https://github.com/kirillgarbar)).
* より多くの式に対して JIT コンパイルを有効化しました: abs/bitCount/sign/modulo/pmod/isNull/isNotNull/assumeNotNull/to(U)Int*/toFloat*、比較関数(=, <, >, >=, <=)、論理関数(and, or)。[#70598](https://github.com/ClickHouse/ClickHouse/pull/70598) ([李扬](https://github.com/taiyang-li)).
* `join_algorithm` 設定が `default` に設定されている場合、適用可能であれば `parallel_hash` アルゴリズムが使用されるようになりました。`parallel_hash` が使用できない場合は、従来の 2 つの代替手段（`direct` および `hash`）が引き続き考慮されます。[#70788](https://github.com/ClickHouse/ClickHouse/pull/70788) ([Nikita Taranov](https://github.com/nickitat)).
* join 時に使用されるハッシュテーブルの数を削減するため、`WHERE` および `ON` 式から共通の式を抽出するオプションを追加しました。`optimize_extract_common_expressions = 1` で有効化できます。[#71537](https://github.com/ClickHouse/ClickHouse/pull/71537) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* `LowCardinality(String)` を使用した `SELECT` で索引を利用できるようになりました。[#71598](https://github.com/ClickHouse/ClickHouse/pull/71598) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 並列レプリカとローカルプランが有効な状態でのクエリ実行時、ワーカー側での索引解析をスキップするようにしました。コーディネーターがイニシエーター側での索引解析に基づいてワーカーの読み取り範囲を決定します。[#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter)).
* https://github.com/ClickHouse/ClickHouse/pull/57631 で実装された、compact パーツ内の単一カラムのサブカラム読み取りに関する最適化を復元しました。誤って削除されていたものです。[#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)).
* コンパレーター内の呼び出しを非仮想化することで、`LowCardinality(String)` カラムのソートを高速化しました。[#72337](https://github.com/ClickHouse/ClickHouse/pull/72337) ([Alexander Gololobov](https://github.com/davenger)).
* 一部の単純なデータ型に対して argMin/Max 関数を最適化しました。[#72350](https://github.com/ClickHouse/ClickHouse/pull/72350) ([alesapin](https://github.com/alesapin)).
* メモリトラッカーにおける共有ロックのロック競合を削減するため、ロック処理を最適化しました。[#72375](https://github.com/ClickHouse/ClickHouse/pull/72375) ([Jiebin Sun](https://github.com/jiebinn)).
* 新しい設定 `use_async_executor_for_materialized_views` を追加しました。materialized view のクエリを非同期かつマルチスレッドで実行することで、INSERT 時のビュー処理を高速化できますが、メモリ消費量が増加する場合があります。[#72497](https://github.com/ClickHouse/ClickHouse/pull/72497) ([alesapin](https://github.com/alesapin)).
* 設定 `max_size_to_preallocate_for_aggregation` および `max_size_to_preallocate_for_joins` のデフォルト値をさらに `10^12` まで引き上げ、より多くのケースで最適化が適用されるようにしました。[#72555](https://github.com/ClickHouse/ClickHouse/pull/72555) ([Nikita Taranov](https://github.com/nickitat)).
* aggregate 関数の状態のデシリアライズ（データ型 `AggregateFunction` および分散クエリにおける）のパフォーマンスを改善しました。また、フォーマット `RowBinary` のパースのパフォーマンスもわずかに改善しました。[#72818](https://github.com/ClickHouse/ClickHouse/pull/72818) ([Anton Popov](https://github.com/CurtizJ)).

<div id="improvement">
  #### 改善
</div>

* 新しいキャンセルロジックを追加しました。`CancellationChecker` は開始された各クエリの timeout をチェックし、timeout に達すると停止します。 [#69880](https://github.com/ClickHouse/ClickHouse/pull/69880) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* `allow_experimental_join_condition` 設定を削除し、非等値条件をデフォルトで許可するようにしました。 [#69910](https://github.com/ClickHouse/ClickHouse/pull/69910) ([Vladimir Cherkasov](https://github.com/vdimir)).
* サーバー設定 (`users.xml`) の設定がクライアントにも適用されるようになりました。`date_time_output_format` などのフォーマット設定に便利です。 [#71178](https://github.com/ClickHouse/ClickHouse/pull/71178) ([Michael Kolupaev](https://github.com/al13n321)).
* [#71227](https://github.com/ClickHouse/ClickHouse/issues/71227) を修正しました。 [#71286](https://github.com/ClickHouse/ClickHouse/pull/71286) ([Arthur Passos](https://github.com/arthurpassos)).
* サーバー/ユーザーの memory usage に基づいて、`GROUP BY`/`ORDER BY` を自動的にディスクへ退避するようにしました。`max_bytes_ratio_before_external_group_by`/`max_bytes_ratio_before_external_sort` クエリ設定で制御します。 [#71406](https://github.com/ClickHouse/ClickHouse/pull/71406) ([Azat Khuzhin](https://github.com/azat)).
* 関数 `translate` で、`from` argument に `to` argument より多くの文字が含まれている場合に、文字の削除をサポートするようになりました。例: `SELECT translate('clickhouse', 'clickhouse', 'CLICK')` は `CLICK` を返すようになりました。 [#71441](https://github.com/ClickHouse/ClickHouse/pull/71441) ([shuai.xu](https://github.com/shuai-xu)).
* Object から JSON への ALTER をサポートしました。 [#71784](https://github.com/ClickHouse/ClickHouse/pull/71784) ([Pavel Kruglov](https://github.com/Avogar)).
* 読み取り時のメモリ消費を減らすため、`MergeTreeReadPoolParallelReplicasInOrder` の範囲を分割しました。 [#72173](https://github.com/ClickHouse/ClickHouse/pull/72173) ([JIaQi](https://github.com/JiaQiTang98)).
* distributed `INSERT ... SELECT` のプラン構築時に `prefer_locahost_replica` を考慮するようにしました。 [#72190](https://github.com/ClickHouse/ClickHouse/pull/72190) ([filimonov](https://github.com/filimonov)).
* 問題は [こちらで説明されています](https://github.com/ClickHouse/ClickHouse/issues/72091)。Azure Iceberg Writer は、仕様に準拠しない Iceberg metadata files (および manifest files) を作成します。この PR では、v1 iceberg format の metadata を v2 reader で読み取る試みを追加し (そのような形式で書き出されるため) 、さらに、マニフェストファイルに対応するフィールドが作成されていない場合はエラーを返すようにしました。 [#72277](https://github.com/ClickHouse/ClickHouse/pull/72277) ([Daniil Ivanik](https://github.com/divanik)).
* JSON/Dynamic/Variant 型を experimental features から beta に移しました。 [#72294](https://github.com/ClickHouse/ClickHouse/pull/72294) ([Pavel Kruglov](https://github.com/Avogar)).
* クエリ内で `UNION [ALL]` を使った `CREATE MATERIALIZED VIEW` が許可されるようになりました。動作は `JOIN` を伴う materialized view と同じで、**insert のトリガーとして機能するのは `SELECT` 式内の最初の table のみ** で、それ以外の table は無視されます。 [#72347](https://github.com/ClickHouse/ClickHouse/pull/72347) ([alesapin](https://github.com/alesapin)).
* 挿入された Batch 内で partition key の値が 1 つ בלבדの場合、MergeTree への insertions を高速化しました。 [#72348](https://github.com/ClickHouse/ClickHouse/pull/72348) ([alesapin](https://github.com/alesapin)).
* これまで `/utils` フォルダに格納され、ソースから手動でコンパイルする必要があった小さなユーティリティが、すべて ClickHouse のメイン bundle に含まれるようになりました。これにより [#72404](https://github.com/ClickHouse/ClickHouse/issues/72404) をクローズします。 [#72426](https://github.com/ClickHouse/ClickHouse/pull/72426) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* バックアップから復元する際に、テーブルを並列に作成できるようにしました。このPR以前は、`RESTORE` コマンドは常に1スレッドでテーブルを作成していたため、多数のテーブルを含むバックアップでは低速になる可能性がありました。[#72427](https://github.com/ClickHouse/ClickHouse/pull/72427) ([Vitaly Baranov](https://github.com/vitlibar)).
* system.metrics に新しい MergeTreeIndexGranularityInternalArraysTotalSize メトリクスを追加しました。このメトリクスは、メモリ使用量が大きくなる問題の影響を受けやすい巨大なデータセットを持つインスタンスを特定するために必要です。[#72490](https://github.com/ClickHouse/ClickHouse/pull/72490) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Dictionary のソースとして ClickHouse を使用する場合のソースクエリ検証を追加しました。[#72548](https://github.com/ClickHouse/ClickHouse/pull/72548) ([Alexey Katsman](https://github.com/alexkats)).
* config の再読み込み時に、ClickHouse が ZooKeeper の変更を認識できるようにしました。[#72593](https://github.com/ClickHouse/ClickHouse/pull/72593) ([Azat Khuzhin](https://github.com/azat)).
* キャッシュ全体のメモリ使用量を削減するため、キャッシュされたマークのメモリ使用量の見積もり精度を改善しました。[#72630](https://github.com/ClickHouse/ClickHouse/pull/72630) ([Antonio Andelic](https://github.com/antonio2368)).
* 新しい `StartupScriptsExecutionState` メトリクスを追加しました。このメトリクスは3つの値を取ります: 0 = 起動スクリプトがまだ完了していない、1 = 起動スクリプトが正常に実行された、2 = 起動スクリプトが失敗した。このメトリクスが必要なのは、特にベース構成のリリース後に、クラウドで起動スクリプトが正常に実行されているかを把握する必要があるためです。[#72637](https://github.com/ClickHouse/ClickHouse/pull/72637) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#73472](https://github.com/ClickHouse/ClickHouse/issues/73472) でバックポート: MergeTree のソートキーおよびスキップ索引でサブカラムをサポートしました。[#72644](https://github.com/ClickHouse/ClickHouse/pull/72644) ([Pavel Kruglov](https://github.com/Avogar)).

* レプリケートテーブルの作成に再試行を追加しました。[#72682](https://github.com/ClickHouse/ClickHouse/pull/72682) ([Vitaly Baranov](https://github.com/vitlibar)).
* Enum に存在しない未知の値を set で許可するようにしました。[#72662](https://github.com/ClickHouse/ClickHouse/issues/72662) を修正しました。[#72686](https://github.com/ClickHouse/ClickHouse/pull/72686) ([zhanglistar](https://github.com/zhanglistar)).
