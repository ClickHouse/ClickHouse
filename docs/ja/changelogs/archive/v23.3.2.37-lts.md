<div id="clickhouse-release-v233237-lts-1b144bcd101-fixme-as-compared-to-v23312823-lts-46e85357ce2">
  ### ClickHouse リリース v23.3.2.37-lts (1b144bcd101) FIXME v23.3.1.2823-lts (46e85357ce2) と比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#48459](https://github.com/ClickHouse/ClickHouse/issues/48459) でバックポート: 関数 formatDateTime() のフォーマッタ &#39;%M&#39; が、分ではなく月名を出力するようになりました。これにより、MySQL と整合した動作になります。以前の動作は、設定 &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot; を使用することで復元できます。[#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).
* [#48842](https://github.com/ClickHouse/ClickHouse/issues/48842) でバックポート: mysql の Dictionary ソース + named collection で、一部の MySQL 関連設定が正しく処理されない問題を修正しました。[#48402](https://github.com/ClickHouse/ClickHouse/issues/48402) をクローズしました。[#48759](https://github.com/ClickHouse/ClickHouse/pull/48759) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#49035](https://github.com/ClickHouse/ClickHouse/issues/49035) でバックポート: SSL ユーザー証明書による認証に失敗した場合、パスワード認証にフォールバックするようにしました。[#48974](https://github.com/ClickHouse/ClickHouse/issues/48974) をクローズしました。[#48989](https://github.com/ClickHouse/ClickHouse/pull/48989) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#48589](https://github.com/ClickHouse/ClickHouse/issues/48589) でバックポート: タイムゾーンを更新。更新対象は次のとおりです: Africa/Cairo, Africa/Casablanca, Africa/El&#95;Aaiun, America/Bogota, America/Cambridge&#95;Bay, America/Ciudad&#95;Juarez, America/Godthab, America/Inuvik, America/Iqaluit, America/Nuuk, America/Ojinaga, America/Pangnirtung, America/Rankin&#95;Inlet, America/Resolute, America/Whitehorse, America/Yellowknife, Asia/Gaza, Asia/Hebron, Asia/Kuala&#95;Lumpur, Asia/Singapore, Canada/Yukon, Egypt, Europe/Kirov, Europe/Volgograd, Singapore. [#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#48960](https://github.com/ClickHouse/ClickHouse/issues/48960) でバックポート: 最近の更新以降、`dockerd` では HTTP ポートを明示的に指定し、あわせて `--tlsverify=false` も必要になりました。 [#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* ある機能を削除しました [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* rabbitmq の CPU 使用率の問題を修正しました ([#44404](https://github.com/ClickHouse/ClickHouse/issues/44404) の後、23.2 で悪化していました)  [#48311](https://github.com/ClickHouse/ClickHouse/pull/48311) ([Kseniia Sumarokova](https://github.com/kssenii)).
* DistributedSink の ThreadPool を修正し、今後のエラーを防ぐために CurrentMetrics/ProfileEvents/StatusInfo で StrongTypedef を使用するようにしました [#48314](https://github.com/ClickHouse/ClickHouse/pull/48314) ([Azat Khuzhin](https://github.com/azat)).
* TemporaryFileStream 内の cache の file segment 用 downloader をリセットするようにしました [#48386](https://github.com/ClickHouse/ClickHouse/pull/48386) ([Vladimir C](https://github.com/vdimir)).
* Dictionary に依存する分散テーブルの loading 時に発生する ClickHouse の起動エラーを修正しました [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* cache で発生する可能性がある segfault を修正しました [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* IP 型および UUID 型のキーを持つ nested map を修正しました [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* ACL で `auth` 認証スキームを指定して node が作成されないことがある Keeper の bug を修正しました。 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* IPv4 を UInt と比較できるように修正しました [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
