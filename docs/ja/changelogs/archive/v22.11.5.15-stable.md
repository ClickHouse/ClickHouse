<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーから見て分かる不具合)
</div>

* [#44999](https://github.com/ClickHouse/ClickHouse/issues/44999) でバックポート: `LowCardinality` Dictionary を remote fs から読み込む際に発生することがあった `Cannot read all data` エラーの追加修正です。[#44709](https://github.com/ClickHouse/ClickHouse/issues/44709) を修正します。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#45552](https://github.com/ClickHouse/ClickHouse/issues/45552) でバックポート: 構造が不正な Dictionary (例: xml config 内の型が不正) がある場合に発生する `SELECT ... FROM system.dictionaries` の例外を修正しました。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk))。
