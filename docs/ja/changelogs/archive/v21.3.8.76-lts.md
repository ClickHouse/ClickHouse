  # 2022年の変更履歴

<div id="clickhouse-release-v213876-lts-fixme-as-compared-to-v213762-stable">
  ### ClickHouse リリース v21.3.8.76-lts FIXME (v21.3.7.62-stable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#23396](https://github.com/ClickHouse/ClickHouse/issues/23396) にバックポート: NULL の Tuple (例: `(NULL, NULL)`) が `IN` operator の左辺にあり、右辺が非 NULL の Tuple (例: `SELECT (NULL, NULL) IN ((0, 0), (3, 1))`) である場合、型の非互換に関する例外を投げるのではなく 0 を返すようにしました。この expression は、`SELECT (NULL, NULL) = (8, 0) OR (NULL, NULL) = (3, 2) OR (NULL, NULL) = (0, 0) OR (NULL, NULL) = (3, 1)` のような式の最適化によって現れることもあります。これにより [#22017](https://github.com/ClickHouse/ClickHouse/issues/22017) をクローズしました。[#22063](https://github.com/ClickHouse/ClickHouse/pull/22063) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#23272](https://github.com/ClickHouse/ClickHouse/issues/23272) にバックポート: 問題を引き起こす可能性があることを示す根拠があるため、設定 `use_hedged_requests` および `async_socket_for_remote` を無効化しました。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov))。

<div id="bug-fix">
  #### バグ修正
</div>

* [#23232](https://github.com/ClickHouse/ClickHouse/issues/23232) にバックポート: default profile で `data_type_default_nullable` setting が有効になっていると Server の起動に失敗する可能性がある問題を修正しました。[#22573](https://github.com/ClickHouse/ClickHouse/issues/22573) を修正。[#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23406](https://github.com/ClickHouse/ClickHouse/issues/23406) にバックポート: サブクエリが定数に最適化された場合に、QueryAliasVisitor が ASTWithAlias で alias を優先するようにしました。[#22924](https://github.com/ClickHouse/ClickHouse/issues/22924) を修正。[#10401](https://github.com/ClickHouse/ClickHouse/issues/10401) を修正。[#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23381](https://github.com/ClickHouse/ClickHouse/issues/23381) にバックポート: キーカラムに条件を指定して `MaterializeMySQL` から SELECT した際に発生する `Not found column` error を修正しました。[#22432](https://github.com/ClickHouse/ClickHouse/issues/22432) を修正。[#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23284](https://github.com/ClickHouse/ClickHouse/issues/23284) にバックポート: 主キーが最初の attribute でない場合に、simple key Dictionary を DDL から作成できない問題を修正しました。[#23236](https://github.com/ClickHouse/ClickHouse/issues/23236) を修正。[#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23450](https://github.com/ClickHouse/ClickHouse/issues/23450) にバックポート: ReplicatedMergeTree テーブルの作成と削除の間で発生する、非常にまれな (distributed) race condition を修正しました。これにより、レプリケートテーブルの作成時に `node doesn't exist` のような例外が発生する可能性がありました。[#21419](https://github.com/ClickHouse/ClickHouse/issues/21419) を修正。[#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23500](https://github.com/ClickHouse/ClickHouse/issues/23500) にバックポート: remote query から `unknown packet` を受信した場合 (`async_socket_for_remote` が有効なとき) に発生する可能性のある crash を修正しました。おそらく [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167) も修正。[#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23468](https://github.com/ClickHouse/ClickHouse/issues/23468) にバックポート: カラムが主キーに含まれている場合 (またはその単調関数である場合) に、setting `optimize_read_in_order` が無効になっていないと、`COLLATE` を伴う `ORDER BY` が正しく動作しない問題を修正しました。これにより [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379) をクローズします。古いバージョンでの回避策: setting `optimize_read_in_order` を無効にしてください。[#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23544](https://github.com/ClickHouse/ClickHouse/issues/23544) にバックポート: 単一の `Tuple` 引数に対する `argMin` と `argMax` のサポートを削除しました。この code はメモリ安全ではありませんでした。この feature は誤って追加されたもので、利用者の混乱を招いていました。これらの関数は、今後別名で再導入される可能性があります。これにより [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) を修正し、[#17359](https://github.com/ClickHouse/ClickHouse/issues/17359) をリバートします。[#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23479](https://github.com/ClickHouse/ClickHouse/issues/23479) にバックポート: Kafka storage で `arrow` および `arrowstream` フォーマットのメッセージをサポートできるようになりました。[#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* [#23499](https://github.com/ClickHouse/ClickHouse/issues/23499) にバックポート: カウンターのリセット時における `deltaSum` 集約関数のバグ修正 ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* [#23493](https://github.com/ClickHouse/ClickHouse/issues/23493) にバックポート: 空の配列リテラルから 1 より大きい次元を持つ配列への型変換を許可しないバグを修正しました。[#14476](https://github.com/ClickHouse/ClickHouse/issues/14476) をクローズしました。[#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)).
