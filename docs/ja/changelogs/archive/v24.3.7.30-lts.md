<div id="clickhouse-release-v243730-lts-c8a28cf4331-fixme-as-compared-to-v243648-lts-b2d33c3c45d">
  ### ClickHouse リリース v24.3.7.30-lts (c8a28cf4331) FIXME (v24.3.6.48-lts (b2d33c3c45d) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#68103](https://github.com/ClickHouse/ClickHouse/issues/68103)でバックポート: カスタム設定の値をパースする際、ブール値と整数を区別するようにしました: `SET custom_a = true; SET custom_b = 1;`. [#62206](https://github.com/ClickHouse/ClickHouse/pull/62206) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#67931](https://github.com/ClickHouse/ClickHouse/issues/67931)でバックポート: StorageMerge の `PREWHERE` 最適化後に発生する `Not-ready Set` エラーを修正しました。[#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#68062](https://github.com/ClickHouse/ClickHouse/issues/68062)でバックポート: 外部データベースに送信されるクエリ内のブール値リテラルを修正しました (`PostgreSQL` などのエンジン向け) 。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir))。
* [#67812](https://github.com/ClickHouse/ClickHouse/issues/67812)でバックポート: 実験的な Variant データ型にのみ関連する修正です。Variant + AggregateFunction 型で発生するクラッシュを修正しました。[#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar))。
* [#67848](https://github.com/ClickHouse/ClickHouse/issues/67848)でバックポート: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026) を修正しました。`ReplaceTableNodeToDummyVisitor` で、未解決のテーブル関数引数を走査しないようにしました。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd))。
* [#68271](https://github.com/ClickHouse/ClickHouse/issues/68271)でバックポート: HTTP インターフェイス経由でストリーム系エンジン (Kafka、RabbitMQ、NATS) に挿入する際の不具合を修正しました。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* [#67806](https://github.com/ClickHouse/ClickHouse/issues/67806)でバックポート: UNION を使用する SQL UDFs の再読み込みを修正しました。以前は、サーバーの再起動によって UDF が無効になることがありました。[#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368))。
* [#67834](https://github.com/ClickHouse/ClickHouse/issues/67834)でバックポート: `JSONMergePatch` 関数における潜在的なスタックオーバーフローを修正しました。以前の名前が誤っていたため、この関数名を `jsonMergePatch` から `JSONMergePatch` に変更しました。以前の名前も互換性のため引き続き保持されています。関数内のエラー診断も改善しました。これにより [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304) をクローズします。[#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#68206](https://github.com/ClickHouse/ClickHouse/issues/68206)でバックポート: predicate に非決定論的関数が含まれる場合に `count()` の結果が誤る不具合を修正しました。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* [#68089](https://github.com/ClickHouse/ClickHouse/issues/68089)でバックポート: 使用可能な CPU 数が制限されているコンテナー環境において、スレッドの最大ソフトリミットの計算を修正しました。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze))。
* [#68120](https://github.com/ClickHouse/ClickHouse/issues/68120)でバックポート: 新しいアナライザで、mutations における未変更パーツのスキップ処理を修正しました。以前は、アナライザが有効な場合、predicate 上そのパーツに mutation が影響しないにもかかわらず、パーツ内のデータが mutation によって書き換えられることがありました。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ))。
