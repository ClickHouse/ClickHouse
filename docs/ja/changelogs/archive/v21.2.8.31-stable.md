<div id="clickhouse-release-v212831-stable-fixme-as-compared-to-v212711-stable">
  ### ClickHouse リリース v21.2.8.31-stable FIXME (v21.2.7.11-stable との比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#22191](https://github.com/ClickHouse/ClickHouse/issues/22191) にバックポート: Poco の SecureSocket 内の SSL オブジェクトで発生する競合を修正しました。[#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#22336](https://github.com/ClickHouse/ClickHouse/issues/22336) にバックポート: table function `clusterAllReplicas` が誤った `_shard_num` を返す問題を修正しました。close [#21481](https://github.com/ClickHouse/ClickHouse/issues/21481)。[#21498](https://github.com/ClickHouse/ClickHouse/pull/21498) ([flynn](https://github.com/ucasfl))。
* [#22092](https://github.com/ClickHouse/ClickHouse/issues/22092) にバックポート: クエリに定数の `WHERE` 条件があり、setting `optimize_skip_unused_shards` が enabled の場合、すべての 分片 がスキップされ、クエリが誤って空の結果を返す可能性がある問題を修正しました。[#21550](https://github.com/ClickHouse/ClickHouse/pull/21550) ([Amos Bird](https://github.com/amosbird))。
* [#22318](https://github.com/ClickHouse/ClickHouse/issues/22318) にバックポート: 外部データベースエンジン (MySQL、PostgreSQL) へのクエリについて、WHERE 内の JOIN されたテーブルから不明なカラムを削除するようにしました。close [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614)、close [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (dup)、close [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (dup)。[#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir))。
* [#22285](https://github.com/ClickHouse/ClickHouse/issues/22285) にバックポート: DDLWorker と Dictionaries の初期化後に接続の受け入れを開始するようにしました。[#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat))。
* [#21753](https://github.com/ClickHouse/ClickHouse/issues/21753) にバックポート: `ReplicatedMergeTree` に対する同時実行の `OPTIMIZE` と `DROP` の問題を修正しました。[#21716](https://github.com/ClickHouse/ClickHouse/pull/21716) ([Azat Khuzhin](https://github.com/azat))。
* [#21809](https://github.com/ClickHouse/ClickHouse/issues/21809) にバックポート: ReplicatedMerge table engines で、`ALTER MODIFY COLUMN` クエリが decimal column のサイズ (32 bit または 64 bit) を変更しない場合に、その型も変更されない不具合を修正しました。[#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin))。
* [#22188](https://github.com/ClickHouse/ClickHouse/issues/22188) にバックポート: S3 接続プールの変更を元に戻しました。[#21737](https://github.com/ClickHouse/ClickHouse/pull/21737) ([Vladimir Chebotarev](https://github.com/excitoon))。
* [#22240](https://github.com/ClickHouse/ClickHouse/issues/22240) にバックポート: scalar subquery の索引解析を修正しました。これにより [#21717](https://github.com/ClickHouse/ClickHouse/issues/21717) を修正します。これは [https://github.com/ClickHouse/ClickHouse/pull/18896](https://github.com/ClickHouse/ClickHouse/pull/18896) で導入されたものです。[#21766](https://github.com/ClickHouse/ClickHouse/pull/21766) ([Amos Bird](https://github.com/amosbird))。
* [#22050](https://github.com/ClickHouse/ClickHouse/issues/22050) にバックポート: catboost model の初回実行時に発生するデッドロックを修正しました。Closes [#13832](https://github.com/ClickHouse/ClickHouse/issues/13832)。[#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar))。
* [#22464](https://github.com/ClickHouse/ClickHouse/issues/22464) にバックポート: まれに、`CollapsingMergeTree` の merge によって `index_granularity + 1` 行を持つ granule が作成されることがありました。そのため、[#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) で追加された内部 check (21.2 および 21.3 に影響) が、`Incomplete granules are not allowed while blocks are granules size` というエラーで失敗する場合がありました。このエラーにより、パーツを merge できませんでした。[#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#22204](https://github.com/ClickHouse/ClickHouse/issues/22204) にバックポート: Docker entrypoint で、`LOG_PATH` が空の場合に `.` への chown を行わないようにしました。[#22100](https://github.com/ClickHouse/ClickHouse/issues/22100) をクローズします。[#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* [#22278](https://github.com/ClickHouse/ClickHouse/issues/22278) にバックポート: `ReplicatedMergeTree` table engine における `OPTIMIZE` および `ALTER` クエリの待機処理を修正しました。これにより、table がデタッチされた場合や再起動された場合でも、クエリがハングしなくなりました。[#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* [#22266](https://github.com/ClickHouse/ClickHouse/issues/22266) にバックポート: background thread pool の名前を修正しました。[#22122](https://github.com/ClickHouse/ClickHouse/pull/22122) ([fastio](https://github.com/fastio)).
* [#22315](https://github.com/ClickHouse/ClickHouse/issues/22315) にバックポート: config に `http_port` がない場合の docker entrypoint を修正しました。[#22132](https://github.com/ClickHouse/ClickHouse/pull/22132) ([Ewout](https://github.com/devwout)).
* [#22502](https://github.com/ClickHouse/ClickHouse/issues/22502) にバックポート: `use_hedged_requests=0` および `async_socket_for_remote=1` の場合のクエリのキャンセルを修正しました。[#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* [#22369](https://github.com/ClickHouse/ClickHouse/issues/22369) にバックポート: すでにカバーされている part を mutate しようとした際に、clickhouse が `LOGICAL_ERROR` Exception を throw しないようにしました。[#22013](https://github.com/ClickHouse/ClickHouse/issues/22013) を修正します。[#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* [#22530](https://github.com/ClickHouse/ClickHouse/issues/22530) にバックポート: `tokenbf_v1` の full text index で、読み取り時に buffer overflow が発生する可能性がありました。余分なバイトは使用されませんが、まれに読み取り処理が crash につながる場合がありました。これにより [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233) をクローズします。[#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22461](https://github.com/ClickHouse/ClickHouse/issues/22461) にバックポート: 並列なパース routine に (不足していた) memory accounting を追加しました。以前のバージョンでは、resultset に非常に大きな data block が含まれている場合、OOM が発生する可能性がありました。これにより [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008) をクローズします。[#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22557](https://github.com/ClickHouse/ClickHouse/issues/22557) にバックポート: `LowCardinality` を使用する partial merge join のバグを修正しました。[#22386](https://github.com/ClickHouse/ClickHouse/issues/22386) と [#22388](https://github.com/ClickHouse/ClickHouse/issues/22388) をクローズします。[#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* [#22606](https://github.com/ClickHouse/ClickHouse/issues/22606) にバックポート: TSV フォーマットで、末尾に改行のない空文字列のデシリアライゼーションを修正しました。これにより [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244) はクローズされます。バージョンを更新しない場合の回避策: `input_format_null_as_default` をゼロに設定してください。以前のバージョンではゼロでした。[#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22575](https://github.com/ClickHouse/ClickHouse/issues/22575) にバックポート: 同じスレッドから TinyLog の rwlock をロック解除するようにして、UB を修正しました。[#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* [#22648](https://github.com/ClickHouse/ClickHouse/issues/22648) にバックポート: *Log engines において、別スレッドからのロック解除による rwlock のアンロックで発生する UB を回避しました。[#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* [#22682](https://github.com/ClickHouse/ClickHouse/issues/22682) にバックポート: `SELECT` 句にカラムを含まないネストされた型を持つ Log で発生する LOGICAL&#95;ERROR を修正しました。[#22654](https://github.com/ClickHouse/ClickHouse/pull/22654) ([Azat Khuzhin](https://github.com/azat)).
* [#22699](https://github.com/ClickHouse/ClickHouse/issues/22699) にバックポート: ReplicatedMergeTree テーブルエンジンで、複数のレプリカに対する mutation の待機処理を修正しました。以前は、他のレプリカで mutation が実際に実行される前に、mutation/alter クエリが完了してしまうことがありました。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* [#22740](https://github.com/ClickHouse/ClickHouse/issues/22740) にバックポート: OOM exception 発生時に zk requests がハングする可能性がある問題を修正しました。[#22438](https://github.com/ClickHouse/ClickHouse/issues/22438) を修正します。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
