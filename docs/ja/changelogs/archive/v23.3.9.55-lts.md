<div id="clickhouse-release-v233955-lts-b9c5c8622d3-fixme-as-compared-to-v233821-lts-1675f2264f3">
  ### ClickHouse リリース v23.3.9.55-lts (b9c5c8622d3) FIXME v23.3.8.21-lts (1675f2264f3) との比較
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#52213](https://github.com/ClickHouse/ClickHouse/issues/52213) にバックポート: 何も挿入されない場合、`ANY` ハッシュ結合でブロックを格納しないようにしました。[#48633](https://github.com/ClickHouse/ClickHouse/pull/48633) ([vdimir](https://github.com/vdimir))。
* [#52826](https://github.com/ClickHouse/ClickHouse/issues/52826) にバックポート: 主キーを無効化してしまう、誤ったPROJECTION解析を修正しました。この問題は `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1` の場合にのみ発生します。これにより [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823) と [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173) を修正します。[#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird))。

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#53019](https://github.com/ClickHouse/ClickHouse/issues/53019) にバックポート: inline cache を Dockerイメージに含めると、まれに奇妙な副作用が発生することがあります。これはまったく使用していないため、なくしても問題ありません。 [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53288](https://github.com/ClickHouse/ClickHouse/issues/53288) にバックポート: compiler の profile データ (`-ftime-trace`) を ClickHouse Cloud にアップロードするようにしました。[#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) に続く 2 回目の試みです。 [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#53461](https://github.com/ClickHouse/ClickHouse/issues/53461) にバックポート: `clickhouse start` コマンドで環境パラメータを保持するようにしました。 [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962) を修正しました。 [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* ソート前に関数を移動する最適化の問題を修正しました。 [#51481](https://github.com/ClickHouse/ClickHouse/pull/51481) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* FINAL における Pipe::unitePipes の Block 構造の不一致を修正しました。 [#51492](https://github.com/ClickHouse/ClickHouse/pull/51492) ([Nikita Taranov](https://github.com/nickitat)).
* Nullable(IPv4) の二項演算を修正しました。 [#51642](https://github.com/ClickHouse/ClickHouse/pull/51642) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* IPv4 と IPv6 を Dictionary 属性としてサポートしました。 [#51756](https://github.com/ClickHouse/ClickHouse/pull/51756) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* WINDOW 関数の ORDER BY タプルを修正しました。 [#52145](https://github.com/ClickHouse/ClickHouse/pull/52145) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* time intervals に対する expression templates を無効化しました。 [#52335](https://github.com/ClickHouse/ClickHouse/pull/52335) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 空の needle とカラム haystack を指定した場合に `countSubstrings()` がハングする問題を修正しました。 [#52409](https://github.com/ClickHouse/ClickHouse/pull/52409) ([Sergei Trifonov](https://github.com/serxa)).
* Buffer engine への挿入の問題を修正しました。 [#52440](https://github.com/ClickHouse/ClickHouse/pull/52440) ([Vasily Nemkov](https://github.com/Enmk)).
* AnyHash の実装が仕様に準拠していない問題を修正しました。 [#52448](https://github.com/ClickHouse/ClickHouse/pull/52448) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 必要に応じて ares channel を初期化および破棄するようにしました。 [#52634](https://github.com/ClickHouse/ClickHouse/pull/52634) ([Arthur Passos](https://github.com/arthurpassos)).
* 1 つのスパース カラム引数を持つ関数 `tuple` で発生するクラッシュを修正しました。 [#52659](https://github.com/ClickHouse/ClickHouse/pull/52659) ([Anton Popov](https://github.com/CurtizJ)).
* clickhouse-keeper: poll() を使用するサーバーの実装を修正しました。 [#52833](https://github.com/ClickHouse/ClickHouse/pull/52833) ([Andy Fiddaman](https://github.com/citrus-it)).
* show create mysql table におけるパスワード漏えいを修正しました。 [#52962](https://github.com/ClickHouse/ClickHouse/pull/52962) ([Duc Canh Le](https://github.com/canhld94)).
* 通常の PROJECTION AST フォーマットの誤りを修正しました。 [#53347](https://github.com/ClickHouse/ClickHouse/pull/53347) ([Amos Bird](https://github.com/amosbird)).
* system.table の select クエリ実行中に遅延実行 database が loading される問題を修正しました。 [#53372](https://github.com/ClickHouse/ClickHouse/pull/53372) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* 並列 FINAL を使用するクエリでカラムの順序が誤る問題を修正しました。 [#53489](https://github.com/ClickHouse/ClickHouse/pull/53489) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 修正: interpolate expression が、select expression でエイリアスされた同名のものではなく、元のカラムを使用してしまう問題を修正しました。 [#53572](https://github.com/ClickHouse/ClickHouse/pull/53572) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
