  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v213655-lts-fixme-as-compared-to-v213542-lts">
  ### ClickHouse リリース v21.3.6.55-lts FIXME (v21.3.5.42-lts との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#22811](https://github.com/ClickHouse/ClickHouse/issues/22811) でバックポート: PODArray が、要素サイズが 16 の約数でも倍数でもない状態でインスタンス化された場合、バッファオーバーフローが発生する可能性がありました。現在のリリースにはこのバグは存在しません。[#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22823](https://github.com/ClickHouse/ClickHouse/issues/22823) でバックポート: profile event HedgedRequestsChangeReplica を追加し、read data timeout を秒からミリ秒に変更しました。[#21886](https://github.com/ClickHouse/ClickHouse/pull/21886) ([Kruglov Pavel](https://github.com/Avogar)).
* [#22936](https://github.com/ClickHouse/ClickHouse/issues/22936) でバックポート: 非同期 分散 blocks の構造を正しくチェックするようにしました。[#22325](https://github.com/ClickHouse/ClickHouse/pull/22325) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#22968](https://github.com/ClickHouse/ClickHouse/issues/22968) にバックポート: 重複排除により、`quorum_parallel=1` を指定したクォーラム insert が実際には「クォーラム」にならないごくまれな不具合を修正しました。[#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* [#22723](https://github.com/ClickHouse/ClickHouse/issues/22723) にバックポート: table function view がカラムとして使用されているかどうかを確認するようにしました。これは [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350) を補完するものです。[#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* [#22807](https://github.com/ClickHouse/ClickHouse/issues/22807) にバックポート: [#21936](https://github.com/ClickHouse/ClickHouse/issues/21936) に対する追加修正です。[#22433](https://github.com/ClickHouse/ClickHouse/issues/22433) も修正します。[#22518](https://github.com/ClickHouse/ClickHouse/pull/22518) ([Ivan](https://github.com/abyss7)).
* [#22759](https://github.com/ClickHouse/ClickHouse/issues/22759) にバックポート: 分散クエリにおける関数 `map` の使用に関する不具合を修正しました。[#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* [#22701](https://github.com/ClickHouse/ClickHouse/issues/22701) にバックポート: ReplicatedMergeTree テーブルエンジンで、複数のレプリカに対する mutations の待機処理を修正しました。従来は、他のレプリカで mutation が実際に実行される前に mutation/alter クエリが完了してしまうことがありました。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* [#22738](https://github.com/ClickHouse/ClickHouse/issues/22738) にバックポート: OOM exception 発生時に zk requests がハングする可能性がある問題を修正しました。[#22438](https://github.com/ClickHouse/ClickHouse/issues/22438) も修正します。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#22892](https://github.com/ClickHouse/ClickHouse/issues/22892) にバックポート: MergeTree の逆方向読み取りにおける概算総行数の計算を修正しました。[#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* [#22922](https://github.com/ClickHouse/ClickHouse/issues/22922) にバックポート: filter カラムが aggregation で使われる場合の `HAVING` の pushdown を修正しました。[#22763](https://github.com/ClickHouse/ClickHouse/pull/22763) ([Anton Popov](https://github.com/CurtizJ)).
* [#22916](https://github.com/ClickHouse/ClickHouse/issues/22916) にバックポート: LIVE VIEW (実験的機能) 。`TemporaryLiveViewCleaner` における TEMPORARY LIVE VIEW の同時 DROP/CREATE でハングする可能性がある問題を修正しました。詳細は [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e) を参照してください。[#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#22920](https://github.com/ClickHouse/ClickHouse/issues/22920) にバックポート: ウィンドウ関数で `mannWhitneyUTest` と `rankCorr` を使用した際にクラッシュする問題を修正しました。これにより [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728) も修正されます。[#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
