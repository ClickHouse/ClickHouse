  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v21255-stable-fixme-as-compared-to-v21246-stable">
  ### ClickHouse リリース v21.2.5.5-stable FIXME (v21.2.4.6-stableと比較して)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#20574](https://github.com/ClickHouse/ClickHouse/issues/20574)でバックポート: remove クエリから不明なパケットを受信した際に発生する可能性があったクラッシュを修正しました (この問題は [#17868](https://github.com/ClickHouse/ClickHouse/issues/17868) で導入されました) 。 [#20547](https://github.com/ClickHouse/ClickHouse/pull/20547) ([Azat Khuzhin](https://github.com/azat)).
* [#21006](https://github.com/ClickHouse/ClickHouse/issues/21006)でバックポート: クエリのキャンセル時に発生する &#39;Empty task was returned from async task queue&#39; を修正しました。 [#20881](https://github.com/ClickHouse/ClickHouse/pull/20881) ([Azat Khuzhin](https://github.com/azat)).
* [#21132](https://github.com/ClickHouse/ClickHouse/issues/21132)でバックポート: `ALTER MODIFY COLUMN` によって、失敗すると分かっている mutation が作成されてしまう挙動を修正しました。 [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* [#21251](https://github.com/ClickHouse/ClickHouse/issues/21251)でバックポート: - storage join への並列 insert をブロックしました。 [#21009](https://github.com/ClickHouse/ClickHouse/pull/21009) ([Vladimir C](https://github.com/vdimir)).
* [#21069](https://github.com/ClickHouse/ClickHouse/issues/21069)でバックポート: 細工された範囲外の `DateTime64` 型の値をフォーマットする際に、範囲外メモリアクセスが発生する可能性がありました。これにより [#20494](https://github.com/ClickHouse/ClickHouse/issues/20494) をクローズします。これにより [#20543](https://github.com/ClickHouse/ClickHouse/issues/20543) をクローズします。 [#21023](https://github.com/ClickHouse/ClickHouse/pull/21023) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#21160](https://github.com/ClickHouse/ClickHouse/issues/21160)でバックポート: 型が Nullable の場合に `input_format_null_as_default` が有効にならない問題を修正しました。これにより [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116) を修正します。 [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* [#21228](https://github.com/ClickHouse/ClickHouse/issues/21228)でバックポート: [#21112](https://github.com/ClickHouse/ClickHouse/issues/21112) を修正しました。INSERT クエリで重複が発生する可能性がある bug を修正しました (callbacks の 1 つが少し遅れて到着した場合) 。 [#21138](https://github.com/ClickHouse/ClickHouse/pull/21138) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#21276](https://github.com/ClickHouse/ClickHouse/issues/21276)でバックポート: `join_use_nulls` と、サブクエリの `TOTALS` を JOIN する際の bug を修正しました。これにより [#19362](https://github.com/ClickHouse/ClickHouse/issues/19362) と [#21137](https://github.com/ClickHouse/ClickHouse/issues/21137) をクローズします。 [#21248](https://github.com/ClickHouse/ClickHouse/pull/21248) ([Vladimir C](https://github.com/vdimir)).
