* [#60832](https://github.com/ClickHouse/ClickHouse/issues/60832) にバックポート: tzdata を 2024a に更新しました。[#60768](https://github.com/ClickHouse/ClickHouse/pull/60768) ([Raúl Marín](https://github.com/Algunenano)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#60413](https://github.com/ClickHouse/ClickHouse/issues/60413) にバックポート: 入力クエリが `max_query_size` を超えた場合に KQL パーサーで発生するセグメンテーション違反を修正しました。また、KQL ダイアレクトを再度有効にしました。[#59036](https://github.com/ClickHouse/ClickHouse/issues/59036) および [#59037](https://github.com/ClickHouse/ClickHouse/issues/59037) を修正します。[#59626](https://github.com/ClickHouse/ClickHouse/pull/59626) ([Yong Wang](https://github.com/kashwy)).
* [#60074](https://github.com/ClickHouse/ClickHouse/issues/60074) にバックポート: `AsynchronousBoundedReadBuffer` で発生する `Read beyond last offset` エラーを修正しました。[#59630](https://github.com/ClickHouse/ClickHouse/pull/59630) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#60299](https://github.com/ClickHouse/ClickHouse/issues/60299) にバックポート: ack も nack もされないメッセージが発生する問題を修正しました。read-write フェーズ中に例外が発生した場合、メッセージは nack されます。[#59775](https://github.com/ClickHouse/ClickHouse/pull/59775) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#60066](https://github.com/ClickHouse/ClickHouse/issues/60066) にバックポート: optimize&#95;uniq&#95;to&#95;count によってカラム alias が削除される問題を修正しました。[#60026](https://github.com/ClickHouse/ClickHouse/pull/60026) ([Raúl Marín](https://github.com/Algunenano)).
* [#60638](https://github.com/ClickHouse/ClickHouse/issues/60638) にバックポート: `FINAL` を含むクエリの並列最適化における不具合を修正しました。まれに誤った結果を返すことがありました。[#60041](https://github.com/ClickHouse/ClickHouse/pull/60041) ([Maksim Kita](https://github.com/kitaisreal)).
* [#60177](https://github.com/ClickHouse/ClickHouse/issues/60177) にバックポート: Nullable で cosineDistance がクラッシュする問題を修正しました。[#60150](https://github.com/ClickHouse/ClickHouse/pull/60150) ([Raúl Marín](https://github.com/Algunenano)).
* [#60279](https://github.com/ClickHouse/ClickHouse/issues/60279) にバックポート: `S3Queue` table engine の機密情報を非表示にするようにしました。[#60233](https://github.com/ClickHouse/ClickHouse/pull/60233) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#61000](https://github.com/ClickHouse/ClickHouse/issues/61000) にバックポート: `system.numbers` から読み取る行数を削減しました。[#59418](https://github.com/ClickHouse/ClickHouse/issues/59418) を修正します。[#60546](https://github.com/ClickHouse/ClickHouse/pull/60546) ([JackyWoo](https://github.com/JackyWoo)).
* [#60791](https://github.com/ClickHouse/ClickHouse/issues/60791) にバックポート: 攻撃者が codecs の組み合わせと数値オーバーフローを引き起こすサイズを使って HTTP server にデータの展開を要求した場合に発生しうる buffer overflow を修正しました。誤った入力データに対して codec NONE 内部で発生しうる buffer overflow も修正しました。これは [Bug Bounty program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて TIANGONG research team から報告されました。[#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#60783](https://github.com/ClickHouse/ClickHouse/issues/60783) にバックポート: SQL/JSON 用の Functions が未初期化メモリを読み取る可能性がありました。これにより [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017) はクローズされます。Fuzzer により発見されました。[#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#60803](https://github.com/ClickHouse/ClickHouse/issues/60803) にバックポート: UploadPart および CompleteMultipartUpload 呼び出しで、aws custom metadata の `x-amz-meta-*` headers を設定しないようにしました。[#60748](https://github.com/ClickHouse/ClickHouse/pull/60748) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)).
* [#60820](https://github.com/ClickHouse/ClickHouse/issues/60820) にバックポート: arrayEnumerateRanked で発生するクラッシュを修正。 [#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)).
* [#60841](https://github.com/ClickHouse/ClickHouse/issues/60841) にバックポート: INSERT SELECT JOIN で input() を使用した際に発生するクラッシュを修正。 [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035) をクローズ。 [#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)).
* [#60904](https://github.com/ClickHouse/ClickHouse/issues/60904) にバックポート: S3 からの読み取り時にスキップされるオブジェクトキーが多すぎる場合の segfault を回避。 [#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)).
