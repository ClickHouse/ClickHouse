<div id="clickhouse-release-v245449-stable-63b760955a0-fixme-as-compared-to-v24535-stable-e0eb66f8e17">
  ### ClickHouse リリース v24.5.4.49-stable (63b760955a0) FIXME v24.5.3.5-stable (e0eb66f8e17) との比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#65886](https://github.com/ClickHouse/ClickHouse/issues/65886)でバックポート: Keeper が常にグローバルスレッドプールに十分な数のスレッドを確保した状態で起動するようにしました。[#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94)).
* [#65304](https://github.com/ClickHouse/ClickHouse/issues/65304)でバックポート: ClickHouse の動作と、CSVフォーマットにおける Tuples の解釈を以前の挙動に戻しました。この変更により、実質的に [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994) を差し戻し、この動作は `output_format_csv_serialize_tuple_into_separate_columns`、`input_format_csv_deserialize_separate_columns_into_tuple`、`input_format_csv_try_infer_strings_from_quoted_tuples` の一部の設定でのみ有効になります。[#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#65896](https://github.com/ClickHouse/ClickHouse/issues/65896)でバックポート: Keeper で cgroup の CPU 制限を考慮するようにしました。[#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 重大なバグ修正 (クラッシュ、LOGICAL_ERROR、データ損失、RBAC)
</div>

* [#65287](https://github.com/ClickHouse/ClickHouse/issues/65287)でバックポート: UniqInjectiveFunctionsEliminationPass と uniqCombined で発生するクラッシュを修正しました。[#65188](https://github.com/ClickHouse/ClickHouse/pull/65188) ([Raúl Marín](https://github.com/Algunenano)).
* [#65374](https://github.com/ClickHouse/ClickHouse/issues/65374)でバックポート: session の終了時に digest の不一致が発生する ClickHouse Keeper のバグを修正しました。[#65198](https://github.com/ClickHouse/ClickHouse/pull/65198) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#65437](https://github.com/ClickHouse/ClickHouse/issues/65437)でバックポート: 古いアナライザで `QUALIFY` clause を禁止しました。古いアナライザは `QUALIFY` を無視していたため、mutations で予期しないデータ削除につながる可能性がありました。[#65356](https://github.com/ClickHouse/ClickHouse/pull/65356) ([Dmitry Novik](https://github.com/novikd)).
* [#65450](https://github.com/ClickHouse/ClickHouse/issues/65450)でバックポート: Distinct combinator で正しいメモリアラインメントを使用するようにしました。以前は、この combinator の使用時に無効なメモリ割り当てが原因でクラッシュが発生する可能性がありました。[#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)).
* [#65712](https://github.com/ClickHouse/ClickHouse/issues/65712)でバックポート: maxIntersections で発生するクラッシュを修正しました。[#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#65681](https://github.com/ClickHouse/ClickHouse/issues/65681) でバックポート: `ARRAY JOIN` を含む分散クエリで発生する `duplicate alias` エラーを修正しました。[#64226](https://github.com/ClickHouse/ClickHouse/pull/64226) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65331](https://github.com/ClickHouse/ClickHouse/issues/65331) でバックポート: まだ復元されていない definer を持つ MV の作成によって、バックアップからの復元がブロックされた際に発生するクラッシュループを修正しました。[#64595](https://github.com/ClickHouse/ClickHouse/pull/64595) ([pufit](https://github.com/pufit)).
* [#64835](https://github.com/ClickHouse/ClickHouse/issues/64835) でバックポート: 式を含む有効期限 (TTL) が機能しなくなる可能性がある不具合を修正しました。[#64694](https://github.com/ClickHouse/ClickHouse/pull/64694) ([alesapin](https://github.com/alesapin)).
* [#65542](https://github.com/ClickHouse/ClickHouse/issues/65542) でバックポート: `ALTER TABLE ... ON CLUSTER ... MODIFY SQL SECURITY` で発生するクラッシュを修正しました。[#64957](https://github.com/ClickHouse/ClickHouse/pull/64957) ([pufit](https://github.com/pufit)).
* [#65580](https://github.com/ClickHouse/ClickHouse/issues/65580) でバックポート: AccessControl の破棄時に発生するクラッシュを修正し、明示的なシャットダウンを追加しました。[#64993](https://github.com/ClickHouse/ClickHouse/pull/64993) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#65618](https://github.com/ClickHouse/ClickHouse/issues/65618) でバックポート: 循環する別名がある場合に、クエリの実行時間が無限になる可能性がある問題を修正しました。[#64849](https://github.com/ClickHouse/ClickHouse/issues/64849) を修正。[#65081](https://github.com/ClickHouse/ClickHouse/pull/65081) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65617](https://github.com/ClickHouse/ClickHouse/issues/65617) でバックポート: 新しいアナライザにおける aggregate function 名の書き換えを修正しました。[#65110](https://github.com/ClickHouse/ClickHouse/pull/65110) ([Dmitry Novik](https://github.com/novikd)).
* [#65732](https://github.com/ClickHouse/ClickHouse/issues/65732) でバックポート: 関数 `uniq*` の argument 内にある単射関数を再帰的に除去するよう修正しました。これは以前は正しく動作していましたが、新しいアナライザで壊れていました。[#65140](https://github.com/ClickHouse/ClickHouse/pull/65140) ([Duc Canh Le](https://github.com/canhld94)).
* [#65265](https://github.com/ClickHouse/ClickHouse/issues/65265) でバックポート: Hashed および Hashed&#95;Array Dictionary の short circuit evaluation における不具合を修正しました。この不具合により未初期化の number を読み取り、さまざまな error につながる可能性がありました。[#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)).
* [#65663](https://github.com/ClickHouse/ClickHouse/issues/65663) でバックポート: `read-in-order` 最適化が有効な場合、`FINAL` を含むクエリで `non-intersecting-parts` 最適化を無効にしました。これにより不正なクエリ結果が返される可能性がありました。回避策として、この修正がマージされるまでは `do_not_merge_across_partitions_select_final` と `split_parts_ranges_into_intersecting_and_non_intersecting_final` を無効にしてください。[#65505](https://github.com/ClickHouse/ClickHouse/pull/65505) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65788](https://github.com/ClickHouse/ClickHouse/issues/65788) でバックポート: MergeJoin の不具合を修正しました。スパースシリアライズされたカラムが、必要な変換が行われていないにもかかわらず、その Nested 型のカラムとして扱われる可能性がありました。[#65632](https://github.com/ClickHouse/ClickHouse/pull/65632) ([Nikita Taranov](https://github.com/nickitat)).
* [#65812](https://github.com/ClickHouse/ClickHouse/issues/65812) でバックポート: `%F` および `%D` プレースホルダーを含む関数 `parseDateTime` で、不正な例外が発生する問題を修正しました。[#65768](https://github.com/ClickHouse/ClickHouse/pull/65768) ([Antonio Andelic](https://github.com/antonio2368))。
* [#65828](https://github.com/ClickHouse/ClickHouse/issues/65828) でバックポート: 古いアナライザと `dictGetOrDefault` を使用した場合の短絡評価ロジックのバグを修正しました。[#65802](https://github.com/ClickHouse/ClickHouse/pull/65802) ([jsc0218](https://github.com/jsc0218))。
