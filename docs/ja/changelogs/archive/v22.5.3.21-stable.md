<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#38241](https://github.com/ClickHouse/ClickHouse/issues/38241)でバックポート: config からレプリカを削除した際に `Distributed` の非同期 INSERT で発生する可能性があるクラッシュを修正しました。[#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#39098](https://github.com/ClickHouse/ClickHouse/issues/39098)でバックポート: OvercommitTracker 内で割り当てが発生するとデッドロックにつながる可能性がありました。ログもあまり有用ではなかったため、ログを削除しました。[#37794](https://github.com/ClickHouse/ClickHouse/issues/37794) を修正しました。[#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* [#39078](https://github.com/ClickHouse/ClickHouse/issues/39078)でバックポート: まれに、cache 容量が上限に達するタイミングと重なった場合に発生しうるファイルシステムキャッシュの bug を修正しました。[#39066](https://github.com/ClickHouse/ClickHouse/issues/39066) をクローズしました。[#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#39152](https://github.com/ClickHouse/ClickHouse/issues/39152)でバックポート: アタッチされた MATERIALIZED VIEW があり、設定 `extremes = 1` が有効な table への INSERT で発生する可能性がある error `Block structure mismatch` を修正しました。[#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) と [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729) をクローズしました。[#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#39274](https://github.com/ClickHouse/ClickHouse/issues/39274)でバックポート: `PREWHERE` と read-in-order 最適化を使用した select で発生していた error `Not found column Type in block` を修正しました。[#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#39369](https://github.com/ClickHouse/ClickHouse/issues/39369)でバックポート: デフォルト引数 `x-max-length` および `x-overflow` なしで RabbitMQ キューを宣言するようにしました。[#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* [#39350](https://github.com/ClickHouse/ClickHouse/issues/39350)でバックポート: PostgreSQL データベースエンジンで PostgreSQL の table を取得するクエリの誤りを修正しました。[#33502](https://github.com/ClickHouse/ClickHouse/issues/33502) をクローズしました。[#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
