<div id="bug-fix">
  #### バグ修正
</div>

* [#26854](https://github.com/ClickHouse/ClickHouse/issues/26854) でバックポート: ParallelFormattingOutputFormat: collector&#95;thread への join の処理に mutex を使用するようにしました ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)). [#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)).
* [#26938](https://github.com/ClickHouse/ClickHouse/issues/26938) でバックポート: データとメタデータの不整合を防ぐため、ReplicatedMergeTree テーブルのシャットダウン時にデータを削除しないよう修正しました。 [#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* [#26986](https://github.com/ClickHouse/ClickHouse/issues/26986) でバックポート: 一部の集約関数コンビネータを適用した際に aggregate function の parameter が失われ、`Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported` のような Exception が発生する可能性がありました。修正済みです。[#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) と [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433) を修正しました。 [#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26944](https://github.com/ClickHouse/ClickHouse/issues/26944) でバックポート: `DEFAULT` expression を持たない、materialized でない別の column を `DEFAULT` column が参照している場合に発生する error `Missing columns: 'xxx'` を修正しました。[#26591](https://github.com/ClickHouse/ClickHouse/issues/26591) を修正しました。 [#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)).
* [#26999](https://github.com/ClickHouse/ClickHouse/issues/26999) でバックポート: カスタム TLD の読み取りを修正しました (buffer が小さい場合や file が大きい場合に processing が停止していました) 。 [#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* [#27029](https://github.com/ClickHouse/ClickHouse/issues/27029) でバックポート: `ALTER TABLE ... PARTITION ID xxx` のようなクエリで、partition ID の正当性が検証されるようになりました。[#25718](https://github.com/ClickHouse/ClickHouse/issues/25718) を修正しました。 [#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* [#27050](https://github.com/ClickHouse/ClickHouse/issues/27050) でバックポート: [RFC] DROP&#95;RANGE との競合によって mutation stack が発生する可能性がある問題を修正しました。 [#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* [#27105](https://github.com/ClickHouse/ClickHouse/issues/27105) でバックポート: `cache`、`complex_key_cache`、`ssd_cache`、`complex_key_ssd_cache` configuration のパースを修正しました。`allow_read_expired_keys`、`max_update_queue_size`、`update_queue_push_timeout_milliseconds`、`query_wait_timeout_milliseconds` は、`cache` type 以外の Dictionaries ではパースされていませんでした。 [#27032](https://github.com/ClickHouse/ClickHouse/pull/27032) ([Maksim Kita](https://github.com/kitaisreal)).
* [#27156](https://github.com/ClickHouse/ClickHouse/issues/27156) でバックポート: GRPCServer の同期処理を修正しました。この PR で [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024) を修正しています。 [#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#27261](https://github.com/ClickHouse/ClickHouse/issues/27261) でバックポート: まれに `system.detached_parts` テーブルに一部の parts について誤った情報が含まれることがありましたが、修正しました。[#27114](https://github.com/ClickHouse/ClickHouse/issues/27114) を修正しました。 [#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
