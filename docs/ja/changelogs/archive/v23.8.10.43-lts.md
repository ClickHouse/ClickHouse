<div id="clickhouse-release-v2381043-lts-a278225bba9-fixme-as-compared-to-v238954-lts-192a1d231fa">
  ### ClickHouse リリース v23.8.10.43-lts (a278225bba9) FIXME (v23.8.9.54-lts (192a1d231fa) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#58819](https://github.com/ClickHouse/ClickHouse/issues/58819)でバックポート: 未使用の jemalloc ページをパージする `SYSTEM JEMALLOC PURGE` と、プロファイラが有効な場合に jemalloc プロファイルを制御する `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` を追加しました。さらに、Keeper に jemalloc 関連の 4LW コマンドも追加しました。jemalloc の統計をダンプする `jmst` と、プロファイラが有効な場合に jemalloc プロファイルを制御する `jmfp`、`jmep`、`jmdp` です。 [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* [#60286](https://github.com/ClickHouse/ClickHouse/issues/60286)でバックポート: GCP が `GATEWAY_TIMEOUT` HTTP エラーコードで `Internal Error` を返した場合に備えて、S3 ファイルの GCP フォールバックをバッファコピーにも適用しました。 [#60164](https://github.com/ClickHouse/ClickHouse/pull/60164) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#59879](https://github.com/ClickHouse/ClickHouse/issues/59879) でバックポート: ClickHouse コンテナーの起動時に毎回 initdb スクリプトを実行したい場合は、環境変数 `CLICKHOUSE_ALWAYS_RUN_INITDB_SCRIPTS` を設定する必要があります。 [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#57565](https://github.com/ClickHouse/ClickHouse/issues/57565) でバックポート: バックグラウンドマージが、cache 内の一時データ保存領域を正しく使用するよう修正しました。[#57275](https://github.com/ClickHouse/ClickHouse/pull/57275) ([vdimir](https://github.com/vdimir)).
* [#57476](https://github.com/ClickHouse/ClickHouse/issues/57476) でバックポート: MergeTree の compact パーツで、マテリアライズ後にスキッピング索引が壊れる可能性がある問題を修正しました。[#57352](https://github.com/ClickHouse/ClickHouse/pull/57352) ([Maksim Kita](https://github.com/kitaisreal)).
* [#58777](https://github.com/ClickHouse/ClickHouse/issues/58777) でバックポート: addBatchLookupTable8 で、例外 throw 時に destroy が二重に呼び出される問題を修正しました。[#58745](https://github.com/ClickHouse/ClickHouse/pull/58745) ([Raúl Marín](https://github.com/Algunenano)).
* [#58856](https://github.com/ClickHouse/ClickHouse/issues/58856) でバックポート: `LowCardinality(Nullable(T))` 型を抽出する JSONExtract 関数で、クラッシュする可能性がある問題を修正しました。[#58808](https://github.com/ClickHouse/ClickHouse/pull/58808) ([vdimir](https://github.com/vdimir)).
* [#59194](https://github.com/ClickHouse/ClickHouse/issues/59194) でバックポート: LIMIT BY と LIMIT の組み合わせにより、distributed queries (並列レプリカを含む) で誤った結果が返される可能性がある問題を修正しました。[#59153](https://github.com/ClickHouse/ClickHouse/pull/59153) ([Igor Nikonov](https://github.com/devcrafter)).
* [#59429](https://github.com/ClickHouse/ClickHouse/issues/59429) でバックポート: FixedString 入力に対する translate() を修正しました。想定される FixedString ではなく String カラムを返してしまい、クラッシュにつながる可能性がありました。この問題は ClickHouse Bug Bounty Program の YohannJardin によって発見されました。[#59356](https://github.com/ClickHouse/ClickHouse/pull/59356) ([Raúl Marín](https://github.com/Algunenano)).
* [#60128](https://github.com/ClickHouse/ClickHouse/issues/60128) でバックポート: `AsynchronousBoundedReadBuffer` で発生する error `Read beyond last offset` を修正しました。[#59630](https://github.com/ClickHouse/ClickHouse/pull/59630) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#59836](https://github.com/ClickHouse/ClickHouse/issues/59836) でバックポート: 初回以外のクエリにおけるクエリ開始時刻を修正しました。[#59662](https://github.com/ClickHouse/ClickHouse/pull/59662) ([Raúl Marín](https://github.com/Algunenano)).
* [#59758](https://github.com/ClickHouse/ClickHouse/issues/59758) でバックポート: FixedString 入力に対する leftPad / rightPad 関数を修正しました。[#59739](https://github.com/ClickHouse/ClickHouse/pull/59739) ([Raúl Marín](https://github.com/Algunenano)).
* [#60304](https://github.com/ClickHouse/ClickHouse/issues/60304) でバックポート: ack も nack もされないメッセージが発生する問題を修正しました。read-write フェーズ中に例外が発生した場合は、メッセージは nack されます。[#59775](https://github.com/ClickHouse/ClickHouse/pull/59775) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#60171](https://github.com/ClickHouse/ClickHouse/issues/60171) でバックポート: Nullable で cosineDistance がクラッシュする問題を修正しました。[#60150](https://github.com/ClickHouse/ClickHouse/pull/60150) ([Raúl Marín](https://github.com/Algunenano)).
