<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#44998](https://github.com/ClickHouse/ClickHouse/issues/44998) でバックポート: remote fs から `LowCardinality` Dictionary を読み取る際に発生することがあった `Cannot read all data` エラーに対する追加の修正です。[#44709](https://github.com/ClickHouse/ClickHouse/issues/44709) を修正しました。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#45551](https://github.com/ClickHouse/ClickHouse/issues/45551) でバックポート: 構造が不正な Dictionary (たとえば XML config 内の型が正しくないもの) がある場合に発生する `SELECT ... FROM system.dictionaries` の例外を修正しました。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
