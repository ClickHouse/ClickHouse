<div id="improvement">
  #### 改善
</div>

* [#57668](https://github.com/ClickHouse/ClickHouse/issues/57668)でバックポート: HTTPクエリの実行中に例外が発生した場合でも、有効な JSON/XML を出力するようにしました。この動作を有効/無効にする設定 `http_write_exception_in_output_format` を追加しました (デフォルトで有効) 。 [#52853](https://github.com/ClickHouse/ClickHouse/pull/52853) ([Kruglov Pavel](https://github.com/Avogar)).
* [#58491](https://github.com/ClickHouse/ClickHouse/issues/58491)でバックポート: 転送クエリを MySQL 互換のクエリに修正しました。 [#57253](https://github.com/ClickHouse/ClickHouse/issues/57253) を修正。 [#52654](https://github.com/ClickHouse/ClickHouse/issues/52654) を修正。 [#56729](https://github.com/ClickHouse/ClickHouse/issues/56729) を修正。 [#56456](https://github.com/ClickHouse/ClickHouse/pull/56456) ([flynn](https://github.com/ucasfl)).
* [#57238](https://github.com/ClickHouse/ClickHouse/issues/57238)でバックポート: パートのフェッチでは、そのパートがリモートレプリカ上で完全にコミットされるまで待機します。PreActive 状態のパートは送信しないほうが適切です。zero copy の場合、これは必須の制約です。 [#56808](https://github.com/ClickHouse/ClickHouse/pull/56808) ([Sema Checherinda](https://github.com/CheSema)).
* [#57655](https://github.com/ClickHouse/ClickHouse/issues/57655)でバックポート: 空の配列を含む PostgreSQL テーブル構造を取得する際の SIGABRT に対処しました。 [#57618](https://github.com/ClickHouse/ClickHouse/pull/57618) ([Mikhail Kot](https://github.com/myrrc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#58324](https://github.com/ClickHouse/ClickHouse/issues/58324) でバックポート: flatten&#95;nested=1 の場合、すべての Array(Tuple) ではなく、実際の Nested 型のみをフラット化するよう修正しました。 [#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* [#57395](https://github.com/ClickHouse/ClickHouse/issues/57395) でバックポート: これまで `NO_SUCH_COLUMN_IN_TABLE` 例外を返していた、ALIAS 付きの ALTER COLUMN を修正しました。 [#50927](https://github.com/ClickHouse/ClickHouse/issues/50927) をクローズします。 [#56493](https://github.com/ClickHouse/ClickHouse/pull/56493) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#57449](https://github.com/ClickHouse/ClickHouse/issues/57449) でバックポート: 一部のプロジェクションで使用されているカラムと互換性のない ALTER columns は、今後禁止されます。以前はこれにより不正なデータが生じる可能性がありました。これにより [#56932](https://github.com/ClickHouse/ClickHouse/issues/56932) を修正します。この PR では、索引カラムの RENAME も可能にし、さらに禁止の原因となった影響対象の索引やプロジェクションが分かるよう、例外メッセージも改善しています。 [#56948](https://github.com/ClickHouse/ClickHouse/pull/56948) ([Amos Bird](https://github.com/amosbird)).
* [#57281](https://github.com/ClickHouse/ClickHouse/issues/57281) でバックポート: Nullable MATERIALIZED カラムに対する ALTER UPDATE 後に発生する segfault を修正しました。 [#42918](https://github.com/ClickHouse/ClickHouse/issues/42918) をクローズします。 [#57147](https://github.com/ClickHouse/ClickHouse/pull/57147) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#57247](https://github.com/ClickHouse/ClickHouse/issues/57247) でバックポート: 部分的に materialized された通常の projection に対する、誤った JOIN plan 最適化を修正しました。これにより [#57194](https://github.com/ClickHouse/ClickHouse/issues/57194) を修正します。 [#57196](https://github.com/ClickHouse/ClickHouse/pull/57196) ([Amos Bird](https://github.com/amosbird)).
* [#57346](https://github.com/ClickHouse/ClickHouse/issues/57346) でバックポート: 一部のケースにおける `ReadonlyReplica` metric を修正しました (たとえば、ローカルデータと Keeper データの差異によりテーブルを初期化できない場合) 。 [#57267](https://github.com/ClickHouse/ClickHouse/pull/57267) ([Antonio Andelic](https://github.com/antonio2368)).
* [#58434](https://github.com/ClickHouse/ClickHouse/issues/58434) でバックポート: StreamingFormatExecutor での読み取りバッファの処理を修正しました。以前は Kafka やその他のストリーミングエンジンで segfault につながる可能性がありました。 [#57438](https://github.com/ClickHouse/ClickHouse/pull/57438) ([Kruglov Pavel](https://github.com/Avogar)).
* [#57539](https://github.com/ClickHouse/ClickHouse/issues/57539) でバックポート: `SYSTEM STOP LISTEN TCP SECURE` のパースを修正しました。 [#57483](https://github.com/ClickHouse/ClickHouse/pull/57483) ([joelynch](https://github.com/joelynch)).
* [#57779](https://github.com/ClickHouse/ClickHouse/issues/57779) でバックポート: Conf `<user_directories> <replicated> <zookeeper_path>/clickhouse/access/</zookeeper_path> </replicated> </user_directories>` sql &#96;&#96;&#96; show settings like &#39;ignore&#95;on&#95;cluster&#95;for&#95;replicated&#95;access&#95;entities&#95;queries&#39; ┌─name─────────────────────────────────────────────────────┬─type─┬─value─┐ │ ignore&#95;on&#95;cluster&#95;for&#95;replicated&#95;access&#95;entities&#95;queries │ bool │ 1 │ └──────────────────────────────────────────────────────────┴──────┴───────┘ のような settings を表示します。 [#57538](https://github.com/ClickHouse/ClickHouse/pull/57538) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#58256](https://github.com/ClickHouse/ClickHouse/issues/58256)でバックポート: `system.kafka&#95;consumers` をデフォルトで無効化しました (メモリリークが発生する可能性があるため) 。 [#57822](https://github.com/ClickHouse/ClickHouse/pull/57822) ([Azat Khuzhin](https://github.com/azat)).
* [#57923](https://github.com/ClickHouse/ClickHouse/issues/57923)でバックポート: BLAKE3 における無効なメモリアクセスを修正しました。 [#57876](https://github.com/ClickHouse/ClickHouse/pull/57876) ([Raúl Marín](https://github.com/Algunenano)).
* [#58084](https://github.com/ClickHouse/ClickHouse/issues/58084)でバックポート: `CREATE INDEX` クエリ内の関数名を正規化しました。索引の作成時に正規の関数名ではなくエイリアスが使われていた場合でも、`Existing table metadata in ZooKeeper differs in skip indexes` エラーが発生しないようにしました。 [#57906](https://github.com/ClickHouse/ClickHouse/pull/57906) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#58110](https://github.com/ClickHouse/ClickHouse/issues/58110)でバックポート: Keeper の修正: Leader が初期化されていない場合、リクエストの前処理時に適切に失敗するようにしました。 [#58069](https://github.com/ClickHouse/ClickHouse/pull/58069) ([Antonio Andelic](https://github.com/antonio2368)).
* [#58155](https://github.com/ClickHouse/ClickHouse/issues/58155)でバックポート: Poco::UTF32Encoding における整数オーバーフローを修正しました。 [#58073](https://github.com/ClickHouse/ClickHouse/pull/58073) ([Andrey Fedotov](https://github.com/anfedotoff)).
* [#58188](https://github.com/ClickHouse/ClickHouse/issues/58188)でバックポート: `JSONCompactEachRow` の並列パースは、以前のバージョンでは正しく動作しない可能性がありました。これで [#58180](https://github.com/ClickHouse/ClickHouse/issues/58180) をクローズします。 [#58181](https://github.com/ClickHouse/ClickHouse/pull/58181) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#58301](https://github.com/ClickHouse/ClickHouse/issues/58301)でバックポート: `JSONCompactEachRow` の並列パースを修正しました。 [#58250](https://github.com/ClickHouse/ClickHouse/pull/58250) ([Kruglov Pavel](https://github.com/Avogar)).
