<div id="2022-changelog">
  # 2022 年の変更履歴
</div>

<div id="clickhouse-release-v21228-stable-fixme-as-compared-to-v21115646-prestable">
  ### ClickHouse リリース v21.2.2.8-stable FIXME と v21.1.1.5646-prestable の比較
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* * `OPTIMIZE TABLE`/マージのメモリ追跡を修正しました - `OPTIMIZE TABLE`/マージで、クエリのメモリ制限とサンプリングが考慮されるようになりました。[#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* `lcm`/`gcd` は浮動小数点数に対して使用できなくなりました。[#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* ビット演算関数 (`bitAnd`、`bitOr` など) は、浮動小数点型の引数では使用できなくなりました。今後は整数への明示的な CAST が必要になります。[#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 新機能
</div>

* 容量節約のため、String 型のカラムをより高圧縮にできる `zstd long` オプションのサポートを追加しました。[#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * LDAP user directories のユーザーについて、LDAP グループ名や一般的な属性値をローカルロールにマッピングする機能を追加しました。[#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* データ型 `Nested` が任意の深さのネストをサポートするようになりました。`Array` の `size0`、`Nullable` の `null`、`Tuple` 要素名などの複雑な型のサブカラムが導入され、カラム全体を読み込まずにこれらを読み取れるようになりました。[#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* `argMin` および `argMax` 関数で Tuple 引数をサポートしました。[#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* `FlatDictionary`、`HashedDictionary`、`ComplexKeyHashedDictionary`、`DirectDictionary`、`ComplexKeyDirectDictionary`、`RangeHashedDictionary` で `Nullable` をサポートしました。[#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* 浮動小数点カラムをパーティションキーとして使用することを禁止しました。関連: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* XML 文字をデコードする関数 `decodeXMLComponent` を追加しました。`SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* PostgreSQL table engine (select/insert の両方に対応し、多次元配列もサポート) を追加し、さらに table function としても追加しました。PostgreSQL Dictionary ソースも追加しました。PostgreSQL database engine も追加しました。[#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `SELECT ALL` 構文を追加しました。[#18706](https://github.com/ClickHouse/ClickHouse/issues/18706) をクローズしました。[#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* map データ型向けに 3 つの関数を追加しました: 1. `map.keys` に 2 番目のパラメータ `key` が含まれているかを確認する `mapContains(map, key)`。2. すべてのキーを Array フォーマットで返す `mapKeys(map)`。3. すべての値を Array フォーマットで返す `mapValues(map)`。[#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* play UI で MetaKey+Enter のホットキーバインドをサポートしました。[#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* 関数 `formatDateTime` が、日付を四半期形式でフォーマットする `%Q` 修飾子をサポートしました。... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* ... [#19261](https://github.com/ClickHouse/ClickHouse/pull/19261) ([RegulusZ](https://github.com/RegulusZ)).
* クエリ実行中に作成されたファクトリオブジェクト名を `system.query&#95;log` に追加しました。[#18495](https://github.com/ClickHouse/ClickHouse/issues/18495) をクローズしました。[#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 数学関数 `sign` を追加しました。[#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).
* 関数 `parseDateTimeBestEffortUSOrZero`、`parseDateTimeBestEffortUSOrNull` を追加しました。[#19712](https://github.com/ClickHouse/ClickHouse/pull/19712) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#19764](https://github.com/ClickHouse/ClickHouse/pull/19764) ([emhlbmc](https://github.com/emhlbmc)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* S3 接続で接続プールを使用するようにし、`s3_max_connections` 設定で制御できるようにしました。 [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* 論理的に等価な場合、`sumIf()` および `sum(if())` 関数を `countIf()` 関数に Rewrite するようにしました。 [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* パフォーマンス向上のため、libcxx を更新し、不安定な ABI を使用するようにしました。 [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* `stat` syscall の回数を減らすことで、パーツの削除を高速化しました。これはしばらく前に存在していた最適化を復活させるものです。`IDisk` のインターフェイスもより安全になりました。これにより [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065) を close します。 [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* aggregate function `sum` を高速化しました。改善が確認できるのは合成 Benchmarks のみで、実用上の効果はあまりありません。 [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* クエリプランの `Filter` step を `Expression + Filter` の組に分割できるようにしました。`Expression + Expression` のマージ最適化 ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)) と組み合わせることで、`Filter` step 後の一部の expression の実行を遅らせられる場合があります。 [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Buffer engine の複数の layers におけるロック競合を軽減しました。 [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* 接続のたびに configuration へアクセスしないようにすることで、server の latency をわずかに改善しました。 [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 改善
</div>

* `LIVE VIEW` テーブルの作成時に、`WITH ... [AND] [PERIODIC] REFRESH [interval_in_sec]` 句をサポートするようになりました。[#14822](https://github.com/ClickHouse/ClickHouse/pull/14822) ([vzakaznikov](https://github.com/vzakaznikov)).
* * optimize&#95;alias&#95;column&#95;prediction (デフォルトで有効) を追加。これにより次のことが可能になります: * パーティションプルーニングおよびセカンダリ索引を使用したデータスキップにおいて、WHERE 内のエイリアス付きカラムを正しく扱う * optimize&#95;trivial&#95;count における単純な count クエリで、WHERE 内のエイリアス付きカラムを正しく扱う * optimize&#95;aggregation&#95;in&#95;order/optimize&#95;read&#95;in&#95;order において、GROUP BY/ORDER BY 内のエイリアス付きカラムを正しく扱う。[#16995](https://github.com/ClickHouse/ClickHouse/pull/16995) ([sundyli](https://github.com/sundy-li)).
* S3 でグローバルリージョンを利用できるよう、AWS C++ SDK を更新しました。[#17870](https://github.com/ClickHouse/ClickHouse/pull/17870) ([Vladimir Chebotarev](https://github.com/excitoon)).
* table function `cluster` への insert をサポートし、table function `remote` と `cluster` の両方で、sharding key を指定してノード間にデータを分散できるようにしました。[#16752](https://github.com/ClickHouse/ClickHouse/issues/16752) をクローズしました。[#18264](https://github.com/ClickHouse/ClickHouse/pull/18264) ([flynn](https://github.com/ucasfl)).
* `EXISTS VIEW` 構文をサポートしました。[#18552](https://github.com/ClickHouse/ClickHouse/pull/18552) ([Du Chuan](https://github.com/spongedu)).
* librdkafka を v1.6.0-RC2 に更新しました。[#18668](https://github.com/ClickHouse/ClickHouse/issues/18668) を修正しました。[#18671](https://github.com/ClickHouse/ClickHouse/pull/18671) ([filimonov](https://github.com/filimonov)).
* CTE にさらに alias を付けられるようにしました。`enable_global_with_statement = 1` の場合、同じレベルの subqueries に CSE を伝播します。これにより [#17378](https://github.com/ClickHouse/ClickHouse/issues/17378) を修正しました。また、[https://github.com/ClickHouse/ClickHouse/pull/16575#issuecomment-753416235](https://github.com/ClickHouse/ClickHouse/pull/16575#issuecomment-753416235) も修正しました。[#18684](https://github.com/ClickHouse/ClickHouse/pull/18684) ([Amos Bird](https://github.com/amosbird)).
* bitmapTransform、bitmapSubsetInRange、bitmapSubsetLimit、bitmapContains 関数で、[UInt8, UInt16, UInt32, UInt64] の argument type をサポートしました。これにより [#18713](https://github.com/ClickHouse/ClickHouse/issues/18713) をクローズしました。[#18791](https://github.com/ClickHouse/ClickHouse/pull/18791) ([sundyli](https://github.com/sundy-li)).
* プレフィックスベースの S3 endpoint 設定を追加しました。[#18812](https://github.com/ClickHouse/ClickHouse/pull/18812) ([Vladimir Chebotarev](https://github.com/excitoon)).
* aggregate function states を持つテーブルの RIGHT JOIN および FULL JOIN に関する問題を修正しました。以前のバージョンでは、`cloneResized` method に関する Exception がスローされていました。[#18818](https://github.com/ClickHouse/ClickHouse/pull/18818) ([templarzq](https://github.com/templarzq)).
* * 送信前に送信側で分散バッチのブロックごとのチェックサムを検証するようにしました (ファイルを2回読み込まなくても、読み込み中にチェックサムが検証されます) 。これにより、receiver 側で INSERT が停止するのを防げます (送信側で .bin ファイルが切り詰められていた場合)  - バッチ INSERT で .bin ファイルを2回読み込まないようにしました (以前は、ブロックをまとめる処理を考慮して行数/バイト数を計算するために必要でしたが、現在はこの情報がヘッダーに含まれており、後方互換性も維持されています) 。 [#18853](https://github.com/ClickHouse/ClickHouse/pull/18853) ([Azat Khuzhin](https://github.com/azat)).
* 長い名前を `?` でマスクせずにクエリを正規化できるよう、`normalizeQueryKeepNames` と `normalizedQueryHashKeepNames` を追加しました。これにより、複雑なクエリログをより適切に分析できます。[#18910](https://github.com/ClickHouse/ClickHouse/pull/18910) ([Amos Bird](https://github.com/amosbird)).
* Docker イメージ: clickhouse-server のエントリポイントに複数の改善を加えました。[#18954](https://github.com/ClickHouse/ClickHouse/pull/18954) ([filimonov](https://github.com/filimonov)).
* 巨大な文字列の挿入時に発生する `PeekableReadBuffer: Memory limit exceed` エラーを修正しました。[#18690](https://github.com/ClickHouse/ClickHouse/issues/18690) を修正します。[#18979](https://github.com/ClickHouse/ClickHouse/pull/18979) ([Alexander Tokmakov](https://github.com/tavplubix)).
* clickhouse-server イメージで、clickhouse ユーザーおよびグループの uid / gid を固定値 (101) に明示的に設定しました。[#19096](https://github.com/ClickHouse/ClickHouse/pull/19096) ([filimonov](https://github.com/filimonov)).
* 関数 `bar` を特定の NaN 引数で呼び出した際に発生する例外メッセージが、以前のバージョンではやや誤解を招く可能性がありました。これにより [#19088](https://github.com/ClickHouse/ClickHouse/issues/19088) を修正します。[#19107](https://github.com/ClickHouse/ClickHouse/pull/19107) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 再起動せずに `max_server_memory_usage` を変更できるようにしました。これにより [#18154](https://github.com/ClickHouse/ClickHouse/issues/18154) をクローズします。[#19186](https://github.com/ClickHouse/ClickHouse/pull/19186) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Pretty フォーマットでの `IPv4` データ型の値の誤った配置を修正しました。これまでは左寄せではなく右寄せになっていました。これにより [#19184](https://github.com/ClickHouse/ClickHouse/issues/19184) をクローズします。[#19339](https://github.com/ClickHouse/ClickHouse/pull/19339) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 任意の uid で docker を実行できるようにしました。[#19374](https://github.com/ClickHouse/ClickHouse/pull/19374) ([filimonov](https://github.com/filimonov)).
* MergeTree パーツのタイプ (Wide/Compact/InMemory) 向けのメトリクスを追加しました。[#19381](https://github.com/ClickHouse/ClickHouse/pull/19381) ([Azat Khuzhin](https://github.com/azat)).
* MySQL 互換性を改善しました。[#19387](https://github.com/ClickHouse/ClickHouse/pull/19387) ([Daniil Kondratyev](https://github.com/dankondr)).
* `system.query_log`、`system.processes` などに `http_referer` フィールドを追加しました。これにより [#19389](https://github.com/ClickHouse/ClickHouse/issues/19389) をクローズします。[#19390](https://github.com/ClickHouse/ClickHouse/pull/19390) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `toIPv6` 関数で `IPv4` アドレスを解析できるようにしました。[#19518](https://github.com/ClickHouse/ClickHouse/pull/19518) ([Bharat Nallan](https://github.com/bharatnc)).
* `.debug` ファイルの新しい配置場所をサポートしました。これにより [#19348](https://github.com/ClickHouse/ClickHouse/issues/19348) を修正します。[#19520](https://github.com/ClickHouse/ClickHouse/pull/19520) ([Amos Bird](https://github.com/amosbird)).
* map データ型で関数 length/empty/notEmpty を使えるようにし、map 内の key 数を返すようにしました。[#19530](https://github.com/ClickHouse/ClickHouse/pull/19530) ([李扬](https://github.com/taiyang-li)).
* 関数 `multiIf` で定数の結果をサポートしました。[#19533](https://github.com/ClickHouse/ClickHouse/pull/19533) ([Maksim Kita](https://github.com/kitaisreal)).
* 読み込み時のチェックサム検証を無効にするオプションを追加しました。本番環境では決して使用しないでください。無効化しても効果は期待できません。実験およびベンチマークでのみ使用できます。この設定は MergeTree family のテーブルにのみ適用されます。他のテーブルエンジンや、ネットワーク経由でデータを受信する場合は、チェックサムは常に検証されます。私の観測では、性能差はないか、あっても 0.5% 未満です。[#19588](https://github.com/ClickHouse/ClickHouse/pull/19588) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* attribute のパース時に、Dictionary のエラーメッセージを改善しました。[#19678](https://github.com/ClickHouse/ClickHouse/pull/19678) ([Maksim Kita](https://github.com/kitaisreal)).
* non-replicated MergeTree における、まれに発生する `max_number_of_merges_with_ttl_in_pool` の上限超過 (有効期限 (TTL) 付き merge がより多く割り当てられる可能性がある問題) を修正しました。[#19708](https://github.com/ClickHouse/ClickHouse/pull/19708) ([alesapin](https://github.com/alesapin)).
* `positionCaseInsensitiveUTF8` 関数で、arguments 不足のチェックにより address sanitizer がトリガーされていた問題を修正しました。[#19720](https://github.com/ClickHouse/ClickHouse/pull/19720) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* message brokers (RabbitMQ および Kafka) 用に専用の pool を追加しました。[#19722](https://github.com/ClickHouse/ClickHouse/pull/19722) ([Azat Khuzhin](https://github.com/azat)).
* distributed queries で、設定 `async_socket_for_remote` が enabled の場合、テーブルで非常に深くネストされた Data type (例: `Array(Array(Array(...more...)))`) が使用されていると、少なくとも debug build configuration では stack overflow が発生する可能性がありました。これは [#19108](https://github.com/ClickHouse/ClickHouse/issues/19108) を修正します。この変更により軽微な後方非互換性が導入されます。型定義内の過剰な括弧は今後サポートされません。例: `Array((UInt8))`。[#19736](https://github.com/ClickHouse/ClickHouse/pull/19736) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* table function `S3` は、Region を正確に判定できない場合にグローバル Region を使用するようになります。これにより [#10998](https://github.com/ClickHouse/ClickHouse/issues/10998) はクローズされます。[#19750](https://github.com/ClickHouse/ClickHouse/pull/19750) ([Vladimir Chebotarev](https://github.com/excitoon)).
* ClickHouse client の query param CTE のテストを追加しました。[#19762](https://github.com/ClickHouse/ClickHouse/pull/19762) ([Maksim Kita](https://github.com/kitaisreal)).
* `formatReadableTimeDelta` 関数で無限大の arguments を正しく出力するようにしました。以前のバージョンでは、実装依存の整数値への暗黙的変換が行われていました。[#19791](https://github.com/ClickHouse/ClickHouse/pull/19791) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `S3` table function が `auto` 圧縮モード (自動検出) をサポートするようになりました。これにより [#18754](https://github.com/ClickHouse/ClickHouse/issues/18754) はクローズされます。[#19793](https://github.com/ClickHouse/ClickHouse/pull/19793) ([Vladimir Chebotarev](https://github.com/excitoon)).
* リモート MySQL server とやり取りする際の charset を utf8mb4 に設定するようにしました。[#19795](https://github.com/ClickHouse/ClickHouse/issues/19795) を修正します。[#19800](https://github.com/ClickHouse/ClickHouse/pull/19800) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `clickhouse-benchmark` に `--reconnect` オプションを追加しました。このオプションを指定すると、各 request の前に再接続します。これはテストに必要です。[#19872](https://github.com/ClickHouse/ClickHouse/pull/19872) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
