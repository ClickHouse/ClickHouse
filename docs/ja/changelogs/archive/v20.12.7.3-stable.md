  ### ClickHouse リリース v20.12.7.3-stable FIXME (v20.12.6.29-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#20683](https://github.com/ClickHouse/ClickHouse/issues/20683) でバックポート: IV として空文字列が渡された場合に、encrypt/decrypt 関数で未初期化メモリが読み取られる可能性があった問題を修正しました。これにより [#19391](https://github.com/ClickHouse/ClickHouse/issues/19391) をクローズします。[#19397](https://github.com/ClickHouse/ClickHouse/pull/19397) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#20635](https://github.com/ClickHouse/ClickHouse/issues/20635) でバックポート: データ破損後に、一部のレプリケートされた操作 (mutation など) が一部のパーツを処理できなくなるまれなバグを修正しました。これにより [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593) を修正します。[#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin))。
* [#20617](https://github.com/ClickHouse/ClickHouse/issues/20617) でバックポート: テーブル関数 `view` が式リスト内で使用されているかどうかをチェックし、その場合は error を返すようにしました。これにより [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342) を修正します。[#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird))。
* [#20487](https://github.com/ClickHouse/ClickHouse/issues/20487) でバックポート: JOIN に SELECT の定数が含まれる場合に発生する `join_use_nulls=1` での `LOGICAL_ERROR` を修正しました。[#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat))。
* [#20614](https://github.com/ClickHouse/ClickHouse/issues/20614) でバックポート: 非同期 INSERT の directory 名をパースする際のチェックを適切に追加しました (SIGSEGV を修正) 。[#20498](https://github.com/ClickHouse/ClickHouse/pull/20498) ([Azat Khuzhin](https://github.com/azat))。
