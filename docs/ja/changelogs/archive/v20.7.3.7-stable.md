<div id="bug-fix">
  #### バグ修正
</div>

* [#14080](https://github.com/ClickHouse/ClickHouse/issues/14080)でバックポート: verbose=1 のときの `/replicas&#95;status` endpoint レスポンスの status code を修正しました。 [#13722](https://github.com/ClickHouse/ClickHouse/pull/13722) ([javi santana](https://github.com/javisantana)).
* [#14388](https://github.com/ClickHouse/ClickHouse/issues/14388)でバックポート: グローバル以外の Level で実行した場合の GRANT ALL ステートメントを修正しました。 [#13987](https://github.com/ClickHouse/ClickHouse/pull/13987) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#14137](https://github.com/ClickHouse/ClickHouse/issues/14137)でバックポート: const 2d array を polygon として使った `pointInPolygon` を修正しました。 [#14079](https://github.com/ClickHouse/ClickHouse/pull/14079) ([Alexey Ilyukhov](https://github.com/livace)).
* [#14292](https://github.com/ClickHouse/ClickHouse/issues/14292)でバックポート: サブクエリを使って空の result set から Kafka エンジンの table に INERT INTO した際に発生する crash を修正しました。 ... [#14203](https://github.com/ClickHouse/ClickHouse/pull/14203) ([Dongdong Yang](https://github.com/donge)).
* [#14307](https://github.com/ClickHouse/ClickHouse/issues/14307)でバックポート: 一部の外部 SOURCES から schema fetch を行う際に `clickhouse-odbc-bridge` で発生する segfault を修正しました。この PR は [#13861](https://github.com/ClickHouse/ClickHouse/issues/13861) を修正します。 [#14267](https://github.com/ClickHouse/ClickHouse/pull/14267) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#14342](https://github.com/ClickHouse/ClickHouse/issues/14342)でバックポート: `AS table_function` で作成された table に対する `ALTER` クエリの実行中に発生する crash を修正しました。[#14212](https://github.com/ClickHouse/ClickHouse/issues/14212) を修正します。 [#14326](https://github.com/ClickHouse/ClickHouse/pull/14326) ([alesapin](https://github.com/alesapin)).
* [#14364](https://github.com/ClickHouse/ClickHouse/issues/14364)でバックポート: `PipelineExecutor` 自体で例外が発生した場合にクエリの実行を停止するようにしました。これにより、まれに発生しうるクエリのハングを防止できます。 [#14334](https://github.com/ClickHouse/ClickHouse/pull/14334) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#14507](https://github.com/ClickHouse/ClickHouse/issues/14507)でバックポート: `PipelineExecutor` 自体で例外が発生した場合にクエリの実行を停止するようにしました。これにより、まれに発生しうるクエリのハングを防止できます。[#14334](https://github.com/ClickHouse/ClickHouse/issues/14334) の続きです。 [#14402](https://github.com/ClickHouse/ClickHouse/pull/14402) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#14486](https://github.com/ClickHouse/ClickHouse/issues/14486)でバックポート: table に単一の part しか含まれないパーティションがある場合に、merges assignment が誤る bug を修正しました。 [#14444](https://github.com/ClickHouse/ClickHouse/pull/14444) ([alesapin](https://github.com/alesapin)).
* [#14482](https://github.com/ClickHouse/ClickHouse/issues/14482)でバックポート: `topK` aggregate function において Array サイズの overflow をチェックするようにしました。このチェックがないと、ユーザーが巧妙に細工した Parameters を持つクエリを送信し、server crash を引き起こす可能性があります。これにより [#14452](https://github.com/ClickHouse/ClickHouse/issues/14452) をクローズします。 [#14467](https://github.com/ClickHouse/ClickHouse/pull/14467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#14601](https://github.com/ClickHouse/ClickHouse/issues/14601)でバックポート: combinator `-Resample` を持つ関数でまれに発生する segfault を修正しました。これは、非常に大きな Parameters による overflow の結果として発生することがありました。 [#14562](https://github.com/ClickHouse/ClickHouse/pull/14562) ([Anton Popov](https://github.com/CurtizJ)).
* [#14728](https://github.com/ClickHouse/ClickHouse/issues/14728)でバックポート: StorageReplicatedMergeTree Engine の CreateQuery 中に ZooKeeper 例外が発生した場合、data directory をクリーンアップするよう修正しました。[#14563](https://github.com/ClickHouse/ClickHouse/pull/14563) ([Bharat Nallan](https://github.com/bharatnc)).
* [#14665](https://github.com/ClickHouse/ClickHouse/issues/14665)でバックポート: Decimal の乗算結果が誤っていた問題を修正しました。原因は、結果カラムの decimal scale が誤っていたことです。[#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)).
* [#14806](https://github.com/ClickHouse/ClickHouse/issues/14806)でバックポート: 代入式に Nullable カラムと定数値 (`UPDATE x = 42` など) を含む `ALTER UPDATE` mutation で、カラムの値が不正になる、または segfault が発生するバグを修正しました。[#13634](https://github.com/ClickHouse/ClickHouse/issues/13634)、[#14045](https://github.com/ClickHouse/ClickHouse/issues/14045) を修正します。[#14646](https://github.com/ClickHouse/ClickHouse/pull/14646) ([alesapin](https://github.com/alesapin)).
* [#14720](https://github.com/ClickHouse/ClickHouse/issues/14720)でバックポート: `ALTER ... MODIFY QUERY` の実行時に、materialized view のメタデータで default database name が欠落していた問題を修正しました。[#14664](https://github.com/ClickHouse/ClickHouse/pull/14664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#14911](https://github.com/ClickHouse/ClickHouse/issues/14911)でバックポート: StorageFile(fd) への INSERT を試みた際に発生する SIGSEGV を修正しました。[#14887](https://github.com/ClickHouse/ClickHouse/pull/14887) ([Azat Khuzhin](https://github.com/azat)).
* [#14942](https://github.com/ClickHouse/ClickHouse/issues/14942)でバックポート: `extractAllGroups` 関数の一部の呼び出しで &quot;Memory limit exceeded&quot; エラーが発生することがある問題を修正しました。これにより [#13383](https://github.com/ClickHouse/ClickHouse/issues/13383) も修正されます。[#14889](https://github.com/ClickHouse/ClickHouse/pull/14889) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
