  ### ClickHouse リリース v20.5.5.74-stable FIXME (v20.5.4.40-stable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#13920](https://github.com/ClickHouse/ClickHouse/issues/13920) でバックポート: `lgamma` 関数のデータレースを修正しました。この競合は `tsan` でのみ検出され、実際の副作用は発生していませんでした。 [#13842](https://github.com/ClickHouse/ClickHouse/pull/13842) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#13300](https://github.com/ClickHouse/ClickHouse/issues/13300)でバックポート: 関数 `groupArrayMoving*` が distributed queries で動作していませんでした。結果が誤った Data type (largest type への昇格なし) で計算されていました。関数 `groupArrayMovingAvg` は、`avg` 関数と一致しない整数値を返していました。これにより [#12568](https://github.com/ClickHouse/ClickHouse/issues/12568) を修正します。[#12622](https://github.com/ClickHouse/ClickHouse/pull/12622) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#13030](https://github.com/ClickHouse/ClickHouse/issues/13030)でバックポート: CREATE USER IF NOT EXISTS は、ユーザーが存在する場合でも exception を throw しなくなりました。これにより [#12507](https://github.com/ClickHouse/ClickHouse/issues/12507) を修正します。[#12646](https://github.com/ClickHouse/ClickHouse/pull/12646) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#12996](https://github.com/ClickHouse/ClickHouse/issues/12996)でバックポート: `any(func(<lambda>))` の場合の最適化 `optimize_move_functions_out_of_any=1` を修正。[#12664](https://github.com/ClickHouse/ClickHouse/pull/12664) ([Artem Zuikov](https://github.com/4ertus2))。
* [#13092](https://github.com/ClickHouse/ClickHouse/issues/13092)でバックポート: CAST(Nullable(String), Enum()) を修正。[#12745](https://github.com/ClickHouse/ClickHouse/pull/12745) ([Azat Khuzhin](https://github.com/azat))。
* [#12984](https://github.com/ClickHouse/ClickHouse/issues/12984)でバックポート: DDL query から作成された range hashed dictionary でのカラム重複を修正。これにより [#10605](https://github.com/ClickHouse/ClickHouse/issues/10605) を修正します。[#12857](https://github.com/ClickHouse/ClickHouse/pull/12857) ([alesapin](https://github.com/alesapin))。
* [#13561](https://github.com/ClickHouse/ClickHouse/issues/13561)でバックポート: 一度 connection が切断されたあとの Redis dictionary へのアクセスを修正。これは `cache` および `direct` dictionary layouts で発生する可能性がありました。[#13082](https://github.com/ClickHouse/ClickHouse/pull/13082) ([Anton Popov](https://github.com/CurtizJ))。
* [#13508](https://github.com/ClickHouse/ClickHouse/issues/13508)でバックポート: database または table の名前にドットが含まれる場合に、users.xml から row policies をパースできない問題を修正。これにより [#5779](https://github.com/ClickHouse/ClickHouse/issues/5779)、[#12527](https://github.com/ClickHouse/ClickHouse/issues/12527) を修正します。[#13199](https://github.com/ClickHouse/ClickHouse/pull/13199) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#13358](https://github.com/ClickHouse/ClickHouse/issues/13358)でバックポート: AvroConfluent: Kafka tombstone レコードをスキップ。AvroConfluent: 壊れたレコードのスキップをサポート。... [#13203](https://github.com/ClickHouse/ClickHouse/pull/13203) ([Andrew Onyshchuk](https://github.com/oandrew))。
