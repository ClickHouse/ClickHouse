<div id="improvement">
  #### 改善
</div>

* [#23342](https://github.com/ClickHouse/ClickHouse/issues/23342) にバックポート: 問題を引き起こす可能性があることが確認されたため、設定 `use_hedged_requests` と `async_socket_for_remote` を無効化しました。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23678](https://github.com/ClickHouse/ClickHouse/issues/23678) にバックポート: `quantile(s)TDigest` を修正しました。tdunning/t-digest 3.2+ に従い、シングルトンなセントロイドに対する特別な処理を追加しました。また、以前のバージョンのアルゴリズム実装におけるセントロイドの過剰圧縮に関するバグも修正しました。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#23343](https://github.com/ClickHouse/ClickHouse/issues/23343) でバックポート: 一部の接続がまだ生きているにもかかわらず currentConnections() が 0 を返すことがあり、その結果シャットダウン時に発生していたクラッシュを修正しました。 [#23154](https://github.com/ClickHouse/ClickHouse/pull/23154) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#23405](https://github.com/ClickHouse/ClickHouse/issues/23405) でバックポート: サブクエリが定数に最適化された場合に、QueryAliasVisitor が ASTWithAlias の alias を優先するようにしました。[#22924](https://github.com/ClickHouse/ClickHouse/issues/22924) を修正。[#10401](https://github.com/ClickHouse/ClickHouse/issues/10401) を修正。 [#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23383](https://github.com/ClickHouse/ClickHouse/issues/23383) でバックポート: キーカラムに条件を指定して `MaterializeMySQL` から選択する際に発生する `Not found column` エラーを修正しました。[#22432](https://github.com/ClickHouse/ClickHouse/issues/22432) を修正。 [#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23386](https://github.com/ClickHouse/ClickHouse/issues/23386) でバックポート: `input_format_with_names_use_header ` 設定を無効にした際、CSVWithNames フォーマットの入力がすべて破棄されてしまう挙動を修正しました。これにより [#22406](https://github.com/ClickHouse/ClickHouse/issues/22406) を修正します。 [#23202](https://github.com/ClickHouse/ClickHouse/pull/23202) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#23340](https://github.com/ClickHouse/ClickHouse/issues/23340) でバックポート: optimize&#95;skip&#95;unused&#95;shards&#95;rewrite&#95;in に対する型変換を追加しました (`optimize_skip_unused_shards_rewrite_in` での `use-of-uninitialized-value` を修正) 。 [#23219](https://github.com/ClickHouse/ClickHouse/pull/23219) ([Azat Khuzhin](https://github.com/azat)).
* [#23341](https://github.com/ClickHouse/ClickHouse/issues/23341) でバックポート: 主キーが最初の attribute でない場合に、シンプルキー Dictionary を DDL から作成できない問題を修正しました。[#23236](https://github.com/ClickHouse/ClickHouse/issues/23236) を修正。 [#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23449](https://github.com/ClickHouse/ClickHouse/issues/23449) でバックポート: ReplicatedMergeTree テーブルの作成と削除の間で発生する、ごくまれな (分散環境での) 競合状態を修正しました。これにより、レプリケートテーブルの作成時に `node doesn't exist` のような例外が発生する可能性がありました。[#21419](https://github.com/ClickHouse/ClickHouse/issues/21419) を修正。 [#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23578](https://github.com/ClickHouse/ClickHouse/issues/23578) でバックポート: 古い blocks のバックグラウンドクリーンアップで発生する、ごくまれな競合状態を修正しました。deduplication window の末尾に近すぎる場合、block が deduplicated されない可能性がありました。 [#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23427](https://github.com/ClickHouse/ClickHouse/issues/23427) でバックポート: remote query から `unknown packet` を受信した場合 (`async_socket_for_remote` が有効なとき) に発生する可能性のあるクラッシュを修正しました。おそらく [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167) も修正します。 [#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23675](https://github.com/ClickHouse/ClickHouse/issues/23675) にバックポート: パーティションプルーニング中に `NOT` 条件を緩和しないようにしました。これにより [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) と [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539) を修正しました。[#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird)).
* [#23581](https://github.com/ClickHouse/ClickHouse/issues/23581) にバックポート: * `join&#95;algorithm = &#39;auto&#39;` における dict join の不具合を修正しました。[#23002](https://github.com/ClickHouse/ClickHouse/issues/23002) をクローズしました。[#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir)).
* [#23428](https://github.com/ClickHouse/ClickHouse/issues/23428) にバックポート: filter-push-down 最適化の後に発生する可能性があった、`UNION` を含むクエリでの `Block structure mismatch` エラーを修正しました。[#23029](https://github.com/ClickHouse/ClickHouse/issues/23029) を修正しました。[#23359](https://github.com/ClickHouse/ClickHouse/pull/23359) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23642](https://github.com/ClickHouse/ClickHouse/issues/23642) にバックポート: 仮想カラムに基づくパーティションプルーニングで、互換性のない定数式が生成される問題を修正しました。これにより [https://github.com/ClickHouse/ClickHouse/pull/21401#discussion&#95;r611888913](https://github.com/ClickHouse/ClickHouse/pull/21401#discussion_r611888913) の問題を修正しました。[#23366](https://github.com/ClickHouse/ClickHouse/pull/23366) ([Amos Bird](https://github.com/amosbird)).
* [#23453](https://github.com/ClickHouse/ClickHouse/issues/23453) にバックポート: カラムが主キーに含まれている場合 (またはその単調関数である場合) 、設定 `optimize_read_in_order` がオフでないと `COLLATE` を使用した `ORDER BY` が正しく動作しない問題を修正しました。これにより [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379) をクローズしました。古いバージョンでの回避策: 設定 `optimize_read_in_order` をオフにしてください。[#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23510](https://github.com/ClickHouse/ClickHouse/issues/23510) にバックポート: 単一の `Tuple` 引数に対する `argMin` と `argMax` のサポートを削除しました。このコードはメモリ安全ではありませんでした。この機能は誤って追加されたもので、ユーザーに混乱を招いていました。これらの関数は今後、別名で再導入される可能性があります。これにより [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) を修正し、[#17359](https://github.com/ClickHouse/ClickHouse/issues/17359) を差し戻しました。[#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23584](https://github.com/ClickHouse/ClickHouse/issues/23584) にバックポート: バージョン 21.1 より前と同様に、より多くの条件を `PREWHERE` に移動できるようにしました。移動される条件の数が不十分だと、パフォーマンスが低下する可能性がありました。[#23397](https://github.com/ClickHouse/ClickHouse/pull/23397) ([Anton Popov](https://github.com/CurtizJ)).
* [#23477](https://github.com/ClickHouse/ClickHouse/issues/23477) にバックポート: Kafka storage で `arrow` および `arrowstream` フォーマットのメッセージをサポートするようになりました。[#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* [#23587](https://github.com/ClickHouse/ClickHouse/issues/23587) にバックポート: マルチディスク構成で ReplicatedMergeTree テーブルの作成に失敗した際に発生する `Cannot unlink file` エラーを修正しました。これにより [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755) をクローズしました。[#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23497](https://github.com/ClickHouse/ClickHouse/issues/23497) にバックポート: カウンターのリセット時における `deltaSum` 集約関数のバグを修正。 ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* [#23491](https://github.com/ClickHouse/ClickHouse/issues/23491) にバックポート: 空の配列リテラルから、1 より大きい次元を持つ配列への CAST を行えないバグを修正。 [#14476](https://github.com/ClickHouse/ClickHouse/issues/14476) をクローズ。 [#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23589](https://github.com/ClickHouse/ClickHouse/issues/23589) にバックポート: `ReplacingMergeTree` での垂直マージにおけるコーナーケースを修正。まれに、`Incomplete granules are not allowed while blocks are granules size` のような例外により、マージが失敗することがありました。 [#23459](https://github.com/ClickHouse/ClickHouse/pull/23459) ([Anton Popov](https://github.com/CurtizJ)).
