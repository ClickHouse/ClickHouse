  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#33184](https://github.com/ClickHouse/ClickHouse/issues/33184) でバックポート: `MySQL` エンジンのデータベースが MySQL サーバーに接続できない場合、サーバーの起動に失敗することがある問題を修正しました。[#14441](https://github.com/ClickHouse/ClickHouse/issues/14441) を修正。[#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#33659](https://github.com/ClickHouse/ClickHouse/issues/33659) でバックポート: HA namenode アドレスを使用できなかった HDFS URL のチェックを修正しました。この不具合は [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042) で導入されました。[#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
* [#33206](https://github.com/ClickHouse/ClickHouse/issues/33206) でバックポート: 空のファイルを読み取る際の S3 table function の不具合を修正しました。[#33008](https://github.com/ClickHouse/ClickHouse/issues/33008) をクローズ。[#33037](https://github.com/ClickHouse/ClickHouse/pull/33037) ([Kseniia Sumarokova](https://github.com/kssenii)).
