  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v217747-stable-fixme-as-compared-to-v217639-stable">
  ### ClickHouse リリース v21.7.7.47-stable FIXME (v21.7.6.39-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#27364](https://github.com/ClickHouse/ClickHouse/issues/27364) でバックポート: 空の配列に対する関数 `multiSearch*` で未初期化メモリが使用される問題を修正し、[#27169](https://github.com/ClickHouse/ClickHouse/issues/27169) をクローズしました。[#27181](https://github.com/ClickHouse/ClickHouse/pull/27181) ([Vladimir C](https://github.com/vdimir)).
* [#27412](https://github.com/ClickHouse/ClickHouse/issues/27412) でバックポート: `LIMIT BY` および `LIMIT OFFSET` を使用した場合の `distributed_group_by_no_merge=2`+`distributed_push_down_limit=1` または `optimize_distributed_group_by_sharding_key=1` の問題を修正しました。[#27249](https://github.com/ClickHouse/ClickHouse/pull/27249) ([Azat Khuzhin](https://github.com/azat)).
* [#27418](https://github.com/ClickHouse/ClickHouse/issues/27418) でバックポート: サンプリングを含むクエリで `Cannot find column` エラーが発生する問題を修正しました。この問題は [#24574](https://github.com/ClickHouse/ClickHouse/issues/24574) で導入されました。[#26522](https://github.com/ClickHouse/ClickHouse/issues/26522) を修正。[#27301](https://github.com/ClickHouse/ClickHouse/pull/27301) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#27416](https://github.com/ClickHouse/ClickHouse/issues/27416) でバックポート: 古い構文で作成された MergeTree テーブルに対する partition ID の誤った検証を修正しました。[#27328](https://github.com/ClickHouse/ClickHouse/pull/27328) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴対象外 / 軽微

* mysql&#95;kill&#95;sync&#95;thread&#95;restore&#95;test を修正 [#26673](https://github.com/ClickHouse/ClickHouse/pull/26673) ([Vladimir C](https://github.com/vdimir)).
* test&#95;jdbc&#95;bridge で self データソースが初期化されるまで待機するよう修正 [#26827](https://github.com/ClickHouse/ClickHouse/pull/26827) ([Ilya Yatsishin](https://github.com/qoega)).
* 結合テストを改善 [#26894](https://github.com/ClickHouse/ClickHouse/pull/26894) ([Ilya Yatsishin](https://github.com/qoega)).
* `legacy_column_name_of_tuple_literal` をより影響の少ない方法で実装 [#27153](https://github.com/ClickHouse/ClickHouse/pull/27153) ([Anton Popov](https://github.com/CurtizJ)).
* PVS のチェックサムを更新 [#27317](https://github.com/ClickHouse/ClickHouse/pull/27317) ([Alexander Tokmakov](https://github.com/tavplubix)).
