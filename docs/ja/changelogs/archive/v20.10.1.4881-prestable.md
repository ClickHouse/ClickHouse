<div id="clickhouse-release-v201014881-prestable-fixme-as-compared-to-v20914585-prestable">
  ### ClickHouse リリース v20.10.1.4881-prestable FIXME (v20.9.1.4585-prestable と比較して)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* SQL でネストされた複数行コメント `/* comment /* comment */ */` をサポートしました。これは SQL 標準に準拠しています。[#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `format_regexp_escaping_rule` 設定 (`Regexp` フォーマットに関連) のデフォルト値を `Raw` に変更しました (これはサブパターン全体を値として読み取ることを意味します) 。これにより、動作がユーザーの期待により近くなります。[#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version` は廃止されました。JOIN リライターの最初のバージョンを削除しました。[#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### 新機能
</div>

* MySQL 型をサポート: `decimal` (ClickHouse では `Decimal`) および秒未満の精度を持つ `datetime` (`DateTime64`) 。 ... [#11512](https://github.com/ClickHouse/ClickHouse/pull/11512) ([Vasily Nemkov](https://github.com/Enmk)).
* insert、merge、fetch 時に fsync を有効にできるようにしました。 [#11948](https://github.com/ClickHouse/ClickHouse/pull/11948) ([Anton Popov](https://github.com/CurtizJ)).
* クラスター間クエリ実行を安全化 (initial&#95;user を現在のクエリユーザーとして使用) 。 [#13156](https://github.com/ClickHouse/ClickHouse/pull/13156) ([Azat Khuzhin](https://github.com/azat)).
* * `mapPopulateSeries` 関数を追加。[#13166](https://github.com/ClickHouse/ClickHouse/pull/13166) ([Ildus Kurbangaliev](https://github.com/ildus)) 。
* 設定ファイルの `<replicated_merge_tree>` セクションで、`ReplicatedMergeTree*` ストレージの設定を指定できるようにしました。これは `<merge_tree>` セクションと同様に機能します。`ReplicatedMergeTree*` ストレージでは、`<merge_tree>` と `<replicated_merge_tree>` の設定があわせて適用されますが、`<replicated_merge_tree>` の設定のほうが優先されます。`system.replicated_merge_tree_settings` テーブルを追加しました。[#13573](https://github.com/ClickHouse/ClickHouse/pull/13573) ([Amos Bird](https://github.com/amosbird)).
* 新機能: 改行、スペース、カンマのいずれか、またはそれらの組み合わせで区切られた line の数列を受け付けるフォーマット LineAsString を追加しました。[#13846](https://github.com/ClickHouse/ClickHouse/pull/13846) ([hexiaoting](https://github.com/hexiaoting)).
* distributed queries 向けに、leaf nodes で読み取る最大行数／最大バイト数を制限する新しい query complexity 制限設定 `max_rows_to_read_leaf`、`max_bytes_to_read_leaf` を追加しました。この制限はローカル読み取りにのみ適用され、root node での最終 merge 段階は**除外**されます。[#14221](https://github.com/ClickHouse/ClickHouse/pull/14221) ([Roman Khavronenko](https://github.com/hagen1778)).
* データを文字列の配列として出力する JSONStrings フォーマットを追加しました。[#14333](https://github.com/ClickHouse/ClickHouse/pull/14333) ([hcz](https://github.com/hczhcz)).
* これで、insert statements のカラムリストで、column transformer とともに asterisk (またはその派生形) を使用できるようになりました。[#14453](https://github.com/ClickHouse/ClickHouse/pull/14453) ([Amos Bird](https://github.com/amosbird)).
* git repository を ClickHouse にインポートする script を追加しました。[#14471](https://github.com/ClickHouse/ClickHouse/pull/14471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree table engines family に対して `TTL ... RECOMPRESS codec_name` を指定できるようにしました。[#14494](https://github.com/ClickHouse/ClickHouse/pull/14494) ([alesapin](https://github.com/alesapin)).
* `system.asynchronous_metric_log` および `system.metric_log` テーブルに event&#95;time&#95;microseconds を追加しました。[#14514](https://github.com/ClickHouse/ClickHouse/pull/14514) ([Bharat Nallan](https://github.com/bharatnc)).
* 新機能: SHOW DATABASES LIKE &#39;xxx&#39;。[#14521](https://github.com/ClickHouse/ClickHouse/pull/14521) ([hexiaoting](https://github.com/hexiaoting)).
* MaterializedMySQL で Decimal data type をサポートしました。[#14535](https://github.com/ClickHouse/ClickHouse/pull/14535) ([Winter Zhang](https://github.com/zhang2014)).
* TSV 出力フォーマットで NULL 表現を設定できるようにしました。これは、デフォルトで `\N` に設定されている `output_format_tsv_null_representation` で制御されます。これにより [#9375](https://github.com/ClickHouse/ClickHouse/issues/9375) をクローズします。なお、この設定が制御するのは出力フォーマットのみであり、TSV input format でサポートされる NULL 表現は `\N` のみです。[#14586](https://github.com/ClickHouse/ClickHouse/pull/14586) ([Kruglov Pavel](https://github.com/Avogar)).
* 新機能: 改行、スペース、カンマのいずれか、またはそれらの組み合わせで区切られた line の数列を受け付けるフォーマット LineAsString を追加しました。[#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `formatReadableQuantity` function を追加しました。大きな数値を人が読みやすくするのに便利です。[#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* カラムのプロパティと table TTL を削除する機能を追加しました。`ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` および `ALTER TABLE REMOVE TTL` クエリを導入しました。どちらの操作も lightweight で、メタデータレベルで実行されます。[#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* `system.text_log`、`system.trace_log`、`system.query_log`、`system.query_thread_log` テーブルに `event_time_microseconds` フィールドを追加しました。[#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc))。
* クエリコンテキストで名前付きサブクエリを導入するための `WITH <identifier> AS (subquery) ... ` をサポートしました。これにより [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416) をクローズします。これにより [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967) をクローズします。[#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird))。
* 設定でデフォルト値が指定されている場合、Replicated テーブルエンジンの引数を省略できるようにしました。[#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider))。
* テーブル関数 `null('structure')` を追加しました。[#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider))。
* クエリ難読化ツールを追加しました。これにより、テストを改善するためにより多くのクエリを共有できるようになります。これにより [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268) をクローズします。[#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* フォーマット `RawBLOB` を追加しました。これは、エスケープや区切り文字を一切使わずに単一の値を入力または出力するためのものです。これにより [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349) をクローズします。[#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [15350](https://github.com/ClickHouse/ClickHouse/issues/15350) を修正しました。[#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl))。
* 最初の select の `WITH` ステートメントを同じレベルの他の select クエリに伝播し、`WITH` ステートメント内の別名をサブクエリから参照できるようにする `enable_global_with_statement` 設定を導入しました。[#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird))。
* ビッグエンディアンのバイト文字列を UUID に変換できる `reinterpretAsUUID` 関数を追加しました。[#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* 並列クォーラム insert を追加しました。これにより [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601) をクローズします。[#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex))。



<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 小さなパーツに対して compact パーツをデフォルトで有効にしました。これにより、高頻度の insert をやや効率的に処理できるようになります (4..100 倍) 。 [#11913](https://github.com/ClickHouse/ClickHouse/pull/11913) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ワイド整数の基本型として `(u)int64_t` を使用することで、256 ビット演算の性能を改善しました。従来のワイド整数では、基本型として 8 ビット型を使用していました。 [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* clickhouse-server の起動時に、`mlock` でコードセグメントのみをロックするようにしました。以前のバージョンでは、デバッグ情報を含むすべてのマップ済み領域がメモリ上にロックされていました。デバッグ情報は通常は別ファイルに分割されていますが、そうでない場合はメモリ使用量が 2..3 GiB 増加していました。 [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* これまでは、1 つの FixedString で group by する際に fixed key method を選択していました。しかし、FixedString カラムに対して同様の packedFix 最適化を行う StringHashTable があるため、これは不要です。可能であれば low&#95;cardinality&#95;key&#95;fixed&#95;string を使用すべきです。 [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* `DateTime <op> DateTime` で、誤って低速な汎用実装が選択されていた問題を修正しました。これにより [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153) が修正されます。 [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* ループ内で複数の DeleteObject を使用する代わりに、1 つの S3 DeleteObjects リクエストを使用するようにしました。機能上の変更はないため、integration/test&#95;log&#95;family&#95;s3 などの既存テストでカバーされています。 [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* 256 ビット乗算を高速化しました。 [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* `quantileTDigest` の性能を改善しました。これにより [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668) が修正されます。 [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* Vertical マージの一時データの保存に、一時ディスクを明示的に使用するようにしました。 [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).



<div id="improvement">
  #### 改善
</div>

* 重複したブロックが、そのレプリカ上にローカルでは存在しない状態 (ほかのレプリカからまだ fetch されていない状態) で書き込まれた場合でも、それを無視せず、正常に replicate された場合と同じ効果になるようローカルにも書き込むようにしました。 [#11684](https://github.com/ClickHouse/ClickHouse/pull/11684) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* compact パーツでカスタムコーデックをサポートしました。 [#12183](https://github.com/ClickHouse/ClickHouse/pull/12183) ([Anton Popov](https://github.com/CurtizJ)).
* joinGet が複数キーのルックアップをサポートするようになりました。[#12418](https://github.com/ClickHouse/ClickHouse/issues/12418) の続きです。 [#13015](https://github.com/ClickHouse/ClickHouse/pull/13015) ([Amos Bird](https://github.com/amosbird)).
* VALUES format のインラインデータを伴う INSERT で、改行に加えてセミコロンもデータ終端としてサポートしました。[#12288](https://github.com/ClickHouse/ClickHouse/issues/12288) をクローズします。 [#13192](https://github.com/ClickHouse/ClickHouse/pull/13192) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* SYSTEM RELOAD CONFIG は、reload に失敗した場合に例外をスローし、以前の users.xml を引き続き使用するようになりました。バックグラウンドでの定期的な reload でも、失敗した場合は以前の users.xml を引き続き使用します。 [#14492](https://github.com/ClickHouse/ClickHouse/pull/14492) ([Vitaly Baranov](https://github.com/vitlibar)).
* DiskS3 のアクセスチェックをスキップするオプションを追加しました。 [#14497](https://github.com/ClickHouse/ClickHouse/pull/14497) ([Pavel Kovalenko](https://github.com/Jokser)).
* ClickHouse では partition expr と key expr は異なる形で扱われます。partition expr は関連するカラムを含む minmax 索引の構築に使われる一方、主キー expr は expr として保存されます。たとえば、ユーザーが `partition by i / 1000` のように、より粗い粒度でテーブルを partition することがあります。しかし、二項演算子は単調ではないため、この PR ではその問題の修正を試みています。ほかのユースケースにも有益である可能性があります。 [#14513](https://github.com/ClickHouse/ClickHouse/pull/14513) ([Amos Bird](https://github.com/amosbird)).
* クエリフォーマット内の末尾の空白をいくつか修正しました。 [#14595](https://github.com/ClickHouse/ClickHouse/pull/14595) ([Azat Khuzhin](https://github.com/azat)).
* `QueryMemoryLimitExceeded` イベントを追加しました。これにより [#14589](https://github.com/ClickHouse/ClickHouse/issues/14589) をクローズします。 [#14647](https://github.com/ClickHouse/ClickHouse/pull/14647) ([fastio](https://github.com/fastio)).
* 関数について、デバッグ情報なしでビルドするオプションを提供することで、後方互換性のない変更を修正しました。 [#14657](https://github.com/ClickHouse/ClickHouse/pull/14657) ([Mike Kot](https://github.com/myrrc)).
* ZooKeeper config の動的 reload。 [#14678](https://github.com/ClickHouse/ClickHouse/pull/14678) ([sundyli](https://github.com/sundy-li)).
* distributed DDL の並列実行を可能にしました。 [#14684](https://github.com/ClickHouse/ClickHouse/pull/14684) ([Azat Khuzhin](https://github.com/azat)).
* ZooKeeper の exists watch によって発生する可能性のあるメモリリークを修正しました。 [#14693](https://github.com/ClickHouse/ClickHouse/pull/14693) ([hustnn](https://github.com/hustnn)).
* `MaterializeMySQL` データベースエンジンでの &quot;Packet payload is not fully read&quot; エラーを修正しました。 [#14696](https://github.com/ClickHouse/ClickHouse/pull/14696) ([BohuTANG](https://github.com/BohuTANG)).
* 負の大きな整数を指定して呼び出した際の `bitShiftLeft()` のクラッシュを修正しました。 [#14697](https://github.com/ClickHouse/ClickHouse/pull/14697) ([Artem Zuikov](https://github.com/4ertus2)).
* マージの調査を改善するため、system.merges テーブルに `merge_algorithm` を追加しました。 [#14705](https://github.com/ClickHouse/ClickHouse/pull/14705) ([Amos Bird](https://github.com/amosbird)).
* FunctionBinaryArithmetic の DecimalBinaryOperation テンプレートで生成される不要なコードを削減しました。 [#14743](https://github.com/ClickHouse/ClickHouse/pull/14743) ([Artem Zuikov](https://github.com/4ertus2)).
* これで columns を使って複数のカラムをまとめ、その後にカラム変換を適用できるようになりました。 [#14775](https://github.com/ClickHouse/ClickHouse/pull/14775) ([Amos Bird](https://github.com/amosbird)).
* StorageJoin と StorageSet で永続化を無効にできるようにしました。この機能は設定 `disable_set_and_join_persistency` で制御されます。また、この PR で issue [#6318](https://github.com/ClickHouse/ClickHouse/issues/6318) を解決しました。 [#14776](https://github.com/ClickHouse/ClickHouse/pull/14776) ([vxider](https://github.com/Vxider)).
* `query_start_time` と `query_start_time_microseconds` を同じ timespec から構築するようにしました。 [#14831](https://github.com/ClickHouse/ClickHouse/pull/14831) ([Bharat Nallan](https://github.com/bharatnc)).
* Distributed ストレージで multi-volume storage configuration を使用できるようにしました。 [#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
* `EXPLAIN` の結果に `SET` および `JOIN` の subqueries を表示するようにしました。 [#14856](https://github.com/ClickHouse/ClickHouse/pull/14856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 最初のレプリカを明示的に指定するための `load_balancing_first_offset` クエリ設定を追加しました。これは `FIRST_OR_RANDOM` load balancing 戦略とあわせて使用し、レプリカの workload を制御できます。 [#14867](https://github.com/ClickHouse/ClickHouse/pull/14867) ([Amos Bird](https://github.com/amosbird)).
* 分散テーブルに対して SETTINGS 付きの SELECT を実行した際に、過剰な settings 制約違反が発生する問題を修正しました。 [#14876](https://github.com/ClickHouse/ClickHouse/pull/14876) ([Amos Bird](https://github.com/amosbird)).
* 以前の drop の試行が ZooKeeper session の期限切れで失敗していた場合でも、Replicated table を drop できるようにしました。これにより [#11891](https://github.com/ClickHouse/ClickHouse/issues/11891) を修正します。 [#14926](https://github.com/ClickHouse/ClickHouse/pull/14926) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `TinyLog` または `Log` table engines を使用するテーブルから自分自身に対して INSERT SELECT を実行する際のデッドロックを回避します。これにより [#6802](https://github.com/ClickHouse/ClickHouse/issues/6802) をクローズします。 [#14962](https://github.com/ClickHouse/ClickHouse/pull/14962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* mutations の実行時に key 制約を無視するようにしました。この PR がないと、`force_index_by_date = 1` または `force_primary_key = 1` の場合に mutations を実行できません。 [#14973](https://github.com/ClickHouse/ClickHouse/pull/14973) ([Amos Bird](https://github.com/amosbird)).
* data part の insert 時に TTL move を無効にするオプションを追加しました。 [#15000](https://github.com/ClickHouse/ClickHouse/pull/15000) ([Pavel Kovalenko](https://github.com/Jokser)).
* `Atomic` データベースエンジンをデフォルトで有効にしました。 [#15003](https://github.com/ClickHouse/ClickHouse/pull/15003) ([Alexander Tokmakov](https://github.com/tavplubix)).
* CAST の argument 数が不正な場合に、適切な exception message を表示するようにしました。これにより [#13992](https://github.com/ClickHouse/ClickHouse/issues/13992) をクローズします。 [#15029](https://github.com/ClickHouse/ClickHouse/pull/15029) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* サブタイプを持つカラムに対して、`Delta`、`T64` などの特殊な codecs を指定できるようにしました。[#12551](https://github.com/ClickHouse/ClickHouse/issues/12551) を実装し、[#11397](https://github.com/ClickHouse/ClickHouse/issues/11397) と [#4609](https://github.com/ClickHouse/ClickHouse/issues/4609) を修正します。 [#15089](https://github.com/ClickHouse/ClickHouse/pull/15089) ([alesapin](https://github.com/alesapin)).
* `EXPLAIN PLAN` クエリに `optimize` 設定を追加しました。有効にすると、クエリプランレベルの最適化が適用されます。デフォルトで有効です。[#15201](https://github.com/ClickHouse/ClickHouse/pull/15201) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `/docker-entrypoint-initdb.d/` 内のすべてのスクリプトの実行が完了するまで、ClickHouse server への接続を許可しないようにしました。[#15244](https://github.com/ClickHouse/ClickHouse/pull/15244) ([Aleksei Kozharin](https://github.com/alekseik1)).
* [15264](https://github.com/ClickHouse/ClickHouse/issues/15264) を修正しました。[#15285](https://github.com/ClickHouse/ClickHouse/pull/15285) ([flynn](https://github.com/ucasfl)).
* レプリケートテーブルの作成時に、`zookeeper_path` 内の `{database}`、`{table}`、`{uuid}` マクロを展開するようにしました。server の再起動後に `zookeeper_path` が壊れる可能性がある場合は、`RENAME TABLE` を許可しないようにしました。[#6917](https://github.com/ClickHouse/ClickHouse/issues/6917) を修正しました。[#15348](https://github.com/ClickHouse/ClickHouse/pull/15348) ([Alexander Tokmakov](https://github.com/tavplubix)).
