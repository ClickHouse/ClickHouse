<div id="clickhouse-release-v213165-lts-fixme-as-compared-to-v213154-stable">
  ### ClickHouse リリース v21.3.16.5-lts FIXME (v21.3.15.4-stable と比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#26940](https://github.com/ClickHouse/ClickHouse/issues/26940) でバックポート: データとメタデータの不整合を防ぐため、ReplicatedMergeTree テーブルのシャットダウン時にデータを削除しないようにしました。 [#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* [#26983](https://github.com/ClickHouse/ClickHouse/issues/26983) でバックポート: 一部の集約関数コンビネータの適用時に集約関数のパラメータが失われ、`Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported` のような例外が発生することがありました。修正済みです。[#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) および [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433) を修正します。 [#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26998](https://github.com/ClickHouse/ClickHouse/issues/26998) でバックポート: カスタム TLD の読み取りを修正しました (buffer が小さい場合や file が大きい場合に処理が停止していました) 。 [#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* [#27088](https://github.com/ClickHouse/ClickHouse/issues/27088) でバックポート: `ALTER TABLE ... PARTITION ID xxx` のようなクエリで、partition ID の正当性が検証されるようになりました。 [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718) を修正します。 [#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* [#27049](https://github.com/ClickHouse/ClickHouse/issues/27049) でバックポート: [RFC] DROP&#95;RANGE との競合によって発生する可能性のある mutation stack を修正しました。 [#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* [#27158](https://github.com/ClickHouse/ClickHouse/issues/27158) でバックポート: GRPCServer の同期を修正しました。この PR は [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024) を修正します。 [#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#27368](https://github.com/ClickHouse/ClickHouse/issues/27368) でバックポート: - 空の配列に対する関数 `multiSearch*` での未初期化メモリの問題を修正し、[#27169](https://github.com/ClickHouse/ClickHouse/issues/27169) をクローズします。 [#27181](https://github.com/ClickHouse/ClickHouse/pull/27181) ([Vladimir C](https://github.com/vdimir)).
* [#27264](https://github.com/ClickHouse/ClickHouse/issues/27264) でバックポート: まれに `system.detached_parts` テーブルに一部のパーツに関する誤った情報が含まれることがありましたが、修正しました。 [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114) を修正します。 [#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#27413](https://github.com/ClickHouse/ClickHouse/issues/27413) でバックポート: 古い構文で作成された MergeTree テーブルに対する partition id の不正な検証を修正しました。 [#27328](https://github.com/ClickHouse/ClickHouse/pull/27328) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#27645](https://github.com/ClickHouse/ClickHouse/issues/27645) でバックポート: row-level security、prewhere、および LowCardinality filter を含むクエリで誤った結果が返る問題を修正しました。 [#27179](https://github.com/ClickHouse/ClickHouse/issues/27179) を修正します。 [#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#27473](https://github.com/ClickHouse/ClickHouse/issues/27473)でバックポート: メトリック BackgroundMessageBrokerSchedulePoolTask を修正。タイプミスの可能性があります。 [#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* [#27864](https://github.com/ClickHouse/ClickHouse/issues/27864)でバックポート: Kafka から NULL (tombstone) メッセージを受信した際に、一部のフォーマットでクラッシュする問題を防止。 [#19255](https://github.com/ClickHouse/ClickHouse/issues/19255) をクローズ。 [#27794](https://github.com/ClickHouse/ClickHouse/pull/27794) ([filimonov](https://github.com/filimonov)).
* [#28207](https://github.com/ClickHouse/ClickHouse/issues/28207)でバックポート: 読み取りバッファが &#39;attempt to read after end of file&#39; で失敗することがある問題を修正。 [#26149](https://github.com/ClickHouse/ClickHouse/issues/26149) をクローズ。 [#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd)).

<div id="buildtestingpackaging-improvement">

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)

* [#28181](https://github.com/ClickHouse/ClickHouse/issues/28181)でバックポート: `WHERE` から `PREWHERE` に移動される条件数が過剰になる可能性がある問題を修正しました (この最適化は設定 `optimize_move_to_prewhere` で制御されます) 。[#28139](https://github.com/ClickHouse/ClickHouse/pull/28139) ([lthaooo](https://github.com/lthaooo)).
* [#28293](https://github.com/ClickHouse/ClickHouse/issues/28293)でバックポート: `ORDER BY` を含むクエリで、設定 `optimize_read_in_order` が有効な `Merge` テーブルにおいて結果が不整合になる問題を修正しました。[#28266](https://github.com/ClickHouse/ClickHouse/pull/28266) ([Anton Popov](https://github.com/CurtizJ)).
