<div id="clickhouse-release-v20614066-prestable-fixme-as-compared-to-v20513833-prestable">
  ### ClickHouse リリース v20.6.1.4066-プレ安定版 FIXME (v20.5.1.3833-プレ安定版 との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* `clickhouse-local` は、従来のように現在のディレクトリを使うのではなく、デフォルトで一意の一時データディレクトリを使用するようになりました。必要に応じて、`-- --path` オプションでデータディレクトリを明示的に指定できます。[#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### 新機能
</div>

* `Alter table drop replica replica_name` のサポートを追加しました。これにより [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080) が修正されます。[#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* `MergeTree` ファミリーのテーブルに、データをメモリ内に保持する新しい in-memory フォーマットのパーツを追加しました。パーツは最初の merge 時にディスクに書き込まれます。行数またはバイト数がしきい値 `min_rows_for_compact_part` および `min_bytes_for_compact_part` を下回る場合、パーツは in-memory フォーマットで作成されます。また、Write-Ahead-Log のオプションサポートも利用可能で、デフォルトで有効になっており、設定 `in_memory_parts_enable_wal` で制御されます。[#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* aggregate functions 向けに -Distinct combinator を追加しました。[#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* table engine mongo(host:port, database, collection, user, password) をサポートしました。[#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* RabbitMQ ストレージを追加しました。[#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [Sentry](https://sentry.io) 経由で ClickHouse コアチームにクラッシュレポートを送信するためのオプトイン設定を追加しました。[#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* ORCBlockOutputFormat を追加しました。[#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* グローバルスレッドプールの最大スレッド数を変更するための `max_thread_pool_size` config。[#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* `EXPLAIN` クエリの初期実装。構文: `EXPLAIN SELECT ...`。これにより [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118) が修正されます。[#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* S3 メタデータ内のパスを相対パスに変更し、S3 ブロブをより簡単に扱えるようにしました。[#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Avro UUID の入力/出力をサポートしました。[#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* 読み取り専用の MongoDB table engine を追加しました。フラットなフィールド (primitive types で、ネストされていないもの) を読み取れます。[#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* Avro スキーマ内で見つからないフィールドに対する設定を追加しました。[#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* 関数 `parseDateTimeBestEffortUS` を追加しました。[#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST をサポートしました。[#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* 単一の値に基づいて aggregation を初期化する関数 initializedAggregation を追加しました。[#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* `set join_algorithm=partial_merge` で RIGHT および FULL JOIN をサポートしました。サポートされる strictness は ALL のみです (ANY、SEMI、ANTI、ASOF はサポートされません) 。[#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* PostgreSQL ライクな ILIKE 演算子を実装しました。 [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710). [#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc)).
* MergeTree テーブルで Nullable 型をキーとして使用できるようになりました。 [#5319](https://github.com/ClickHouse/ClickHouse/issues/5319). [#12433](https://github.com/ClickHouse/ClickHouse/pull/12433) ([Amos Bird](https://github.com/amosbird)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 設定 `min_bytes_to_use_direct_io` または `min_bytes_to_use_mmap_io` が設定されている場合、セカンダリ索引で `direct_io` と `mmap_io` を使用できるようにしました。[#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree の読み取り時におけるマーク数の見積もりを修正しました。これは、設定 `merge_tree_max_rows_to_use_cache`、`merge_tree_max_bytes_to_use_cache`、`merge_tree_min_rows_for_concurrent_read`、`merge_tree_min_bytes_for_concurrent_read`、`merge_tree_min_rows_for_seek`、`merge_tree_min_bytes_for_seek` を正しく処理するために必要です。これにより、設定 `min_bytes_to_use_mmap_io` は MergeTree テーブルエンジンファミリーにおける索引の読み取りと compact パーツの読み取りにも適用されるようになりました。[#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 「[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) リテラルを含む IN 演算子で索引が使用されない」を修正しました。これは v19.3 頃に発生したパフォーマンス低下です。[#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).
* `set optimize_injective_functions_inside_uniq=1` の場合、`uniq*()` 内の単射関数を除去するようにしました。[#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)).
* `set optimize_redundant_functions_in_order_by = 1` の場合に、`ORDER BY x, f(x)` を `ORDER by x` に書き換える ORDER BY 最適化を追加しました。[#12404](https://github.com/ClickHouse/ClickHouse/pull/12404) ([Artem Zuikov](https://github.com/4ertus2)).
* 一部の操作でメモリ使用量を最大で 1/2 まで削減しました。[#12424](https://github.com/ClickHouse/ClickHouse/pull/12424) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="improvement">
  #### 改善
</div>

* レプリカ選択時に無視するエラー数を指定する `distributed_replica_error_ignore` を追加。[#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* ソートキーのプレフィックスによって &#39;ORDER BY&#39; および &#39;GROUP BY&#39; のパフォーマンスを改善。[#11696](https://github.com/ClickHouse/ClickHouse/pull/11696) ([Anton Popov](https://github.com/CurtizJ)).
* * `optimize_skip_unused_shards_nesting` を追加 (分片スキップ最適化のネストレベルを制御可能)  - `force_skip_optimize_shards_nesting` を追加 (分片がスキップされたかどうかを確認する際のネストレベルを制御可能)  - `force_optimize_skip_unused_shards_no_nested` を非推奨に変更 (代わりに `force_skip_optimize_shards_nesting` を使用してください)  - sharding&#95;key に非決定論的関数 (たとえば `rand()`) がある場合は `optimize_skip_unused_shards` を無効化 (なお、これは INSERT 側の動作には影響しません) 。 [#11715](https://github.com/ClickHouse/ClickHouse/pull/11715) ([Azat Khuzhin](https://github.com/azat)).
* structure ロックを伴わないストレージ向けに、マルチバージョンのメタデータを追加しました。 [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* ODBC 接続文字列の検証を少し緩和しました。hostname または username が、`.` と `-` を含む単語文字のみで構成されている場合は、中かっこで囲みません。一部の ODBC ドライバ (例: PostgreSQL) は、hostname が中かっこで囲まれていると解釈できないためです。 [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 区切り文字なしの UUID を parse できるようにしました (ほとんどの実装では区切り文字は常に削除されるため、これはユーザーが data を書き込む際に役立ちます) 。 [#11856](https://github.com/ClickHouse/ClickHouse/pull/11856) ([Winter Zhang](https://github.com/zhang2014)).
* MySQL との互換性のため、標準整数型 (`BIGINT`, `INT`, ...) の `SIGNED` および `UNSIGNED` modifier をサポートしました。 [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `sumWithOverflow` を `SimpleAggregateFunction` として使えるようにしました。[#8053](https://github.com/ClickHouse/ClickHouse/issues/8053) をクローズします。 [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Hashing functions に FixedString のサポートを追加しました。 [#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).
* `optimize_arithmetic_operations_in_aggregate_functions` 最適化のコードを書き直しました。 [#11899](https://github.com/ClickHouse/ClickHouse/pull/11899) ([Artem Zuikov](https://github.com/4ertus2)).
* `DatabaseOrdinary.cpp` で `std::string` の代わりに `std::filesystem::path` を使用し、パスの連結を改善するとともに、スラッシュが二重になったパスを修正しました。 [#11900](https://github.com/ClickHouse/ClickHouse/pull/11900) ([Bharat Nallan](https://github.com/bharatnc)).
* 古い regular スタイルを非推奨とし、新しい globalVariable メソッドを使用するようにしました [#11832](https://github.com/ClickHouse/ClickHouse/issues/11832)。 [#11901](https://github.com/ClickHouse/ClickHouse/pull/11901) ([BohuTANG](https://github.com/BohuTANG)).
* [issue 9797](https://github.com/ClickHouse/ClickHouse/issues/9797) に関連しています。 [#11923](https://github.com/ClickHouse/ClickHouse/pull/11923) ([flynn](https://github.com/ucasfl)).
* `system.tables` が Memory および Buffer table engines のカラム容量を考慮するようになり、常駐メモリサイズをより適切に近似できるようになりました。 [#11935](https://github.com/ClickHouse/ClickHouse/pull/11935) ([Max Akhmedov](https://github.com/zlobober)).
* CPU 周波数を system.asynchronous&#95;metrics に追加しました。メトリクス収集の周期を設定可能にしました。 [#11972](https://github.com/ClickHouse/ClickHouse/pull/11972) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Enum data type への要素追加のような、パーティションキーに対する「メタデータのみ」の ALTER を実行できるようにしました。これにより [#7513](https://github.com/ClickHouse/ClickHouse/issues/7513) を修正します。 [#11973](https://github.com/ClickHouse/ClickHouse/pull/11973) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* load&#95;balancing にレプリカ優先度を追加しました (ロードバランシングを手動で優先付けするため) 。 [#11995](https://github.com/ClickHouse/ClickHouse/pull/11995) ([Azat Khuzhin](https://github.com/azat)).
* MySQL engine で Enums type の読み取りをサポートしました [#3985](https://github.com/ClickHouse/ClickHouse/issues/3985)。 [#11996](https://github.com/ClickHouse/ClickHouse/pull/11996) ([BohuTANG](https://github.com/BohuTANG)).
* DiskS3 向けに単一 part の upload を実装しました。 [#12026](https://github.com/ClickHouse/ClickHouse/pull/12026) ([Vladimir Chebotarev](https://github.com/excitoon)).

* system.disks に &#39;type&#39; カラムを追加しました。[#12115](https://github.com/ClickHouse/ClickHouse/pull/12115) ([ianton-ru](https://github.com/ianton-ru)).
* `formatDateTime` 関数で、`%g` (2 桁の ISO 年) および `%G` (4 桁の ISO 年) の置換をサポートしました。[#12136](https://github.com/ClickHouse/ClickHouse/pull/12136) ([vivarum](https://github.com/vivarum)).
