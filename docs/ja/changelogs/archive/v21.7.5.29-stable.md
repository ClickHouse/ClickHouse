  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v217529-stable-fixme-as-compared-to-v217418-stable">
  ### ClickHouse リリース v21.7.5.29-stable FIXME (v21.7.4.18-stableとの比較)
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#26526](https://github.com/ClickHouse/ClickHouse/issues/26526)でバックポート: カラム数の多いテーブルの読み取りが必要な短いクエリのレイテンシを改善しました。[#26371](https://github.com/ClickHouse/ClickHouse/pull/26371) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#26787](https://github.com/ClickHouse/ClickHouse/issues/26787)でバックポート: 内部 buffer の末尾にエスケープシーケンスがある場合に zstd の伸張処理が正しく行われない問題を修正しました。[#26013](https://github.com/ClickHouse/ClickHouse/issues/26013) をクローズします。[#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#26487](https://github.com/ClickHouse/ClickHouse/issues/26487)でバックポート: カラムの別名を書き換えた後に名前解決が壊れる問題を修正しました。これにより [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432) を修正します。[#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird))。
* [#26615](https://github.com/ClickHouse/ClickHouse/issues/26615)でバックポート: Dictionary 名またはデータベース名が引用符で囲まれている場合に `CREATE DICTIONARY` クエリで発生する問題を修正しました。[#26491](https://github.com/ClickHouse/ClickHouse/issues/26491) をクローズします。[#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal))。
* [#26606](https://github.com/ClickHouse/ClickHouse/issues/26606)でバックポート: rabbitmq の Setup が開始されていない場合に、rabbitmq のシャットダウン時にクラッシュする問題を修正しました。[#26504](https://github.com/ClickHouse/ClickHouse/issues/26504) をクローズします。[#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#26612](https://github.com/ClickHouse/ClickHouse/issues/26612)でバックポート: clickhouse-server の docker entrypoint における `chown` cmd の check を更新しました。これにより、Kubernetes 上でクラスターのポッド再起動が Failed する、または timeout になる bug を修正します。[#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix))。
* [#26647](https://github.com/ClickHouse/ClickHouse/issues/26647)でバックポート: groupBitmapAnd/Or/Xor の関数名が正しくない問題を修正しました。[#26557](https://github.com/ClickHouse/ClickHouse/pull/26557) ([Amos Bird](https://github.com/amosbird))。
* [#26704](https://github.com/ClickHouse/ClickHouse/issues/26704)でバックポート: window functions における nullptr のデリファレンスが発生する可能性がある問題を修正しました。これにより [#25276](https://github.com/ClickHouse/ClickHouse/issues/25276) を修正します。[#26668](https://github.com/ClickHouse/ClickHouse/pull/26668) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* [#26772](https://github.com/ClickHouse/ClickHouse/issues/26772)でバックポート: SET ROLE が誤って動作することがある問題を、この PR で修正しました。[#26707](https://github.com/ClickHouse/ClickHouse/pull/26707) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#26907](https://github.com/ClickHouse/ClickHouse/issues/26907)でバックポート: library-bridge の ids の読み込みを修正しました。[#26834](https://github.com/ClickHouse/ClickHouse/pull/26834) ([Kseniia Sumarokova](https://github.com/kssenii))。

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微

* library bridge の追加修正 [#26873](https://github.com/ClickHouse/ClickHouse/pull/26873) ([Kseniia Sumarokova](https://github.com/kssenii)).
