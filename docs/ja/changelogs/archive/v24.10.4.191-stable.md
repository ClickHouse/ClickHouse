<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#72865](https://github.com/ClickHouse/ClickHouse/issues/72865) でバックポート: テーブルエンジン Kafka、NATS、RabbitMQ は、`SOURCES` 階層でそれぞれ個別の権限の対象となりました。これらのエンジンタイプでテーブルを作成する default 以外のデータベースユーザーには、権限を追加してください。[#71250](https://github.com/ClickHouse/ClickHouse/pull/71250) ([Christoph Wurm](https://github.com/cwurm)).

<div id="new-feature">
  #### 新機能
</div>

* [#74317](https://github.com/ClickHouse/ClickHouse/issues/74317) でバックポート: `min_age_to_force_merge_seconds` と `min_age_to_force_merge_on_partition_only` の両方が有効な場合、パーツマージは最大バイト数の制限を無視するようになりました。[#73656](https://github.com/ClickHouse/ClickHouse/pull/73656) ([Kai Zhu](https://github.com/nauu)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#72595](https://github.com/ClickHouse/ClickHouse/issues/72595) にバックポート: 並列レプリカ使用時にローカルプランが有効な場合、クエリ実行中のワーカー側でのスキップ索引解析を省略するようにしました。マージコーディネーターは、自身の側 (クエリのイニシエーター上) で行った索引解析に基づいて、ワーカーが読み取る範囲を選択します。 [#72109](https://github.com/ClickHouse/ClickHouse/pull/72109) ([Igor Nikonov](https://github.com/devcrafter)).
* [#73033](https://github.com/ClickHouse/ClickHouse/issues/73033) にバックポート: [https://github.com/ClickHouse/ClickHouse/pull/57631](https://github.com/ClickHouse/ClickHouse/pull/57631) の、compact パーツ内の単一カラムのサブカラム読み取り最適化を復活させました。これは誤って削除されていました。 [#72285](https://github.com/ClickHouse/ClickHouse/pull/72285) ([Pavel Kruglov](https://github.com/Avogar)).

* [#73565](https://github.com/ClickHouse/ClickHouse/issues/73565) でバックポート: 制限された `syscall` が原因で、Docker コンテナー内の ClickHouse が stderr に &quot;get&#95;mempolicy: Operation not permitted&quot; を出力していた issue を修正しました。 [#70900](https://github.com/ClickHouse/ClickHouse/pull/70900) ([filimonov](https://github.com/filimonov)).

* [#72675](https://github.com/ClickHouse/ClickHouse/issues/72675) でバックポート: cache の総メモリ使用量を削減するため、cached marks の memory usage の近似精度を改善しました。 [#72630](https://github.com/ClickHouse/ClickHouse/pull/72630) ([Antonio Andelic](https://github.com/antonio2368)).
* [#73063](https://github.com/ClickHouse/ClickHouse/issues/73063) でバックポート: GCS S3 error `AuthenticationRequired` のパースをサポートしました。 [#72753](https://github.com/ClickHouse/ClickHouse/pull/72753) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#73055](https://github.com/ClickHouse/ClickHouse/issues/73055) でバックポート: S3 リクエスト設定 `http_max_fields`、`http_max_field_name_size`、`http_max_field_value_size` を追加し、backup の作成時または復元時に S3 API レスポンスをパースする際に使用するようにしました。 [#72778](https://github.com/ClickHouse/ClickHouse/pull/72778) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#73453](https://github.com/ClickHouse/ClickHouse/issues/73453) でバックポート: ObjectStorageQueueMetadata のクリーンアップ thread で Keeper のマルチリクエストを使用するようにしました。 [#73357](https://github.com/ClickHouse/ClickHouse/pull/73357) ([Antonio Andelic](https://github.com/antonio2368)).
