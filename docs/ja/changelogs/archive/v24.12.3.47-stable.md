<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#74160](https://github.com/ClickHouse/ClickHouse/issues/74160) にバックポート: `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` の後に一時停止が発生する問題を回避しました。バックグラウンドタスクのスケジューリングに必要な正しい設定を取得するようにしました。 [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#74143](https://github.com/ClickHouse/ClickHouse/issues/74143) にバックポート: フォーマット設定が TCPHandler の NativeWriter に伝播されるようにし、`output_format_native_write_json_as_string` などの設定が正しく適用されるようにしました。 [#73179](https://github.com/ClickHouse/ClickHouse/pull/73179) ([Pavel Kruglov](https://github.com/Avogar)).
* [#73895](https://github.com/ClickHouse/ClickHouse/issues/73895) にバックポート: Dynamic および JSON カラム で、まとめる処理の準備に関する不具合を修正しました。以前は、types/paths の上限に達していない場合でも、新しい型が shared variant/shared data に挿入されることがありました。 [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74441](https://github.com/ClickHouse/ClickHouse/issues/74441) にバックポート: Dictionary のソースに不正なデータを含む関数がある場合に segfault が発生する問題を修正しました。 [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#73799](https://github.com/ClickHouse/ClickHouse/issues/73799) にバックポート: Dynamic カラム で発生しうるデータ不整合を修正しました。あわせて、論理エラー `Nested columns sizes are inconsistent with local_discriminators column size` が発生する可能性がある問題も修正しました。 [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74029](https://github.com/ClickHouse/ClickHouse/issues/74029) にバックポート: Dynamic/Object structure のデシリアライゼーションを修正しました。これにより CANNOT&#95;READ&#95;ALL&#95;DATA 例外が発生する可能性がありました。 [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74100](https://github.com/ClickHouse/ClickHouse/issues/74100) にバックポート: [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078) を修正しました (S3 Express Support が機能していませんでした) 。 [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* [#74092](https://github.com/ClickHouse/ClickHouse/issues/74092) にバックポート: 暗黙的な privileges を修正しました (以前はワイルドカードとして動作していました) 。 [#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* [#74044](https://github.com/ClickHouse/ClickHouse/issues/74044) にバックポート: ネストした Maps の作成時にメモリ使用量が増大する問題を修正しました。 [#73982](https://github.com/ClickHouse/ClickHouse/pull/73982) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74057](https://github.com/ClickHouse/ClickHouse/issues/74057) にバックポート: 修正: 別の alias から参照され、逆順で選択されている場合、alias が projection に追加されないことがありました。 [#74033](https://github.com/ClickHouse/ClickHouse/pull/74033) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#74110](https://github.com/ClickHouse/ClickHouse/issues/74110) にバックポート: plain&#95;rewritable メタデータ を使用するディスクは、複数の server instance 間で共有できます。あるインスタンスがメタデータオブジェクトを読み取っている間に、別のインスタンスがそれを変更することは想定内です。Azure storage での plain&#95;rewritable 初期化時には、S3 で実装されている動作と同様に、Object not found エラーは無視されます。 [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* [#74136](https://github.com/ClickHouse/ClickHouse/issues/74136) にバックポート済み: ユーザーが Kafkaテーブルエンジンでキーワード引数を指定した場合の不具合を修正しました。[#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#74179](https://github.com/ClickHouse/ClickHouse/issues/74179) にバックポート済み: 圧縮された Memory engine テーブルのサブカラムを読み取る際に発生するクラッシュを修正しました。[#74009](https://github.com/ClickHouse/ClickHouse/issues/74009) を修正。[#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat)).
