<div id="performance-improvement">
  #### パフォーマンス改善

* [#31732](https://github.com/ClickHouse/ClickHouse/issues/31732)でバックポート: JSON および XML の出力フォーマットのパフォーマンスを向上しました。 [#31673](https://github.com/ClickHouse/ClickHouse/pull/31673) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#31575](https://github.com/ClickHouse/ClickHouse/issues/31575)でバックポート: Quota の上限には達していないにもかかわらず、上限を超過したと判定されていました。この PR は [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正します。[#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#31204](https://github.com/ClickHouse/ClickHouse/issues/31204)でバックポート: hdfs url の構造に対する追加チェックを入れることで、不正な hdfs url により debug server で abort が発生し、release server で `DB::Exception: std::out_of_range: basic_string` error が発生する問題を修正しました。[#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31253](https://github.com/ClickHouse/ClickHouse/issues/31253)でバックポート: 一部の協調 logs が失われ、手元の最新 log より新しい snapshot が存在する場合に、Keeper が起動できなくなることがある bug を修正しました。[#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)).
* [#31521](https://github.com/ClickHouse/ClickHouse/issues/31521)でバックポート: not like function の RPNElement への組み込みを削除しました。[#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* [#31552](https://github.com/ClickHouse/ClickHouse/issues/31552)でバックポート: S3 用の STS credentials provider における `nullptr` の問題を解消しました。[#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#31582](https://github.com/ClickHouse/ClickHouse/issues/31582)でバックポート: * この最適化の bug が修正されるまで、`partial_merge_join_left_table_buffer_bytes` を無効化しました。[#31009](https://github.com/ClickHouse/ClickHouse/issues/31009) を参照してください。) * 冗長な option `partial_merge_join_optimizations` を削除しました。[#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* [#31599](https://github.com/ClickHouse/ClickHouse/issues/31599)でバックポート: 無効な UTF-8 シーケンスを含んでいるのがカラム名だけの場合に、生成される JSON が不正になる問題を修正しました。[#31534](https://github.com/ClickHouse/ClickHouse/pull/31534) ([Kevin Michel](https://github.com/kmichel-aiven)).
* [#31779](https://github.com/ClickHouse/ClickHouse/issues/31779)でバックポート: `Ordinary` database 内の DDL Dictionary をリネームしようとした際に、`RENAME TABLE` クエリが正しく動作しなかった問題を修正しました。[#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31790](https://github.com/ClickHouse/ClickHouse/issues/31790)でバックポート: `IPv4` などの domain types のパースで、Settings `input_format_allow_errors_num` および `input_format_allow_errors_ratio` が機能していなかった問題を修正しました。[#31686](https://github.com/ClickHouse/ClickHouse/issues/31686) を修正しています。[#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31829](https://github.com/ClickHouse/ClickHouse/issues/31829)でバックポート: 指定したクラスター名が `Replicated` database の名前である場合に、`ON CLUSTER` クエリの実行時に `there are no such cluster here` error が発生する問題を修正しました。[#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31813](https://github.com/ClickHouse/ClickHouse/issues/31813)でバックポート: data と Progress の行が出力内で混在する場合に発生する、JSONEachRowWithProgress 出力フォーマットでの race を修正しました。[#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31761](https://github.com/ClickHouse/ClickHouse/issues/31761)でバックポート: `Map` type での `Buffer` table engine の使用に関する問題を修正しました。[#30546](https://github.com/ClickHouse/ClickHouse/issues/30546) を修正しています。[#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* [#31890](https://github.com/ClickHouse/ClickHouse/issues/31890)でバックポート: TSKVフォーマットで発生する可能性のあるアサーション `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` を修正しました。 [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31910](https://github.com/ClickHouse/ClickHouse/issues/31910)でバックポート: `UUID` 型の引数に対する関数 `empty` および `notEmpty` を修正しました。 [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819) を修正しました。 [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
