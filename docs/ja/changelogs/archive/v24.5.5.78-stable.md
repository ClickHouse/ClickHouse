  ### ClickHouse リリース v24.5.5.78-stable (0138248cb62) FIXME、v24.5.4.49-stable (63b760955a0) と比較して

<div id="improvement">
  #### 改善
</div>

* [#66768](https://github.com/ClickHouse/ClickHouse/issues/66768)でバックポート: 分散クエリでは、allow&#95;experimental&#95;analyzer をイニシエーターが制御するようにしました。これにより、バージョンが混在するクラスターでの動作時に、互換性と正しさが確保されます。[#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)) 。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 重大なバグ修正 (crash, LOGICAL_ERROR, データ損失, RBAC)
</div>

* [#66884](https://github.com/ClickHouse/ClickHouse/issues/66884)でバックポート: 関数呼び出しにおける低カーディナリティのカラムのサイズが不正になる問題を修正しました。[#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* [#66691](https://github.com/ClickHouse/ClickHouse/issues/66691)でバックポート: 再起動後に USER 定義内の VALID UNTIL 句がリセットされる問題を修正しました。[#66405](https://github.com/ClickHouse/ClickHouse/issues/66405) をクローズします。[#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#67814](https://github.com/ClickHouse/ClickHouse/issues/67814)でバックポート: 実験的な Variant データ型にのみ関連します。Variant + AggregateFunction 型で発生するクラッシュを修正しました。[#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* [#67501](https://github.com/ClickHouse/ClickHouse/issues/67501)でバックポート: connection が空の場合に DistributedAsyncInsert で発生するクラッシュを修正しました。[#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)).
* [#67850](https://github.com/ClickHouse/ClickHouse/issues/67850)でバックポート: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026) を修正しました。`ReplaceTableNodeToDummyVisitor` で、未解決の table function の引数を走査しないようにしました。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#65350](https://github.com/ClickHouse/ClickHouse/issues/65350) でバックポート: StatusFile の ~WriteBufferFromFileDescriptor で、捕捉されない例外によって abort する可能性がある問題を修正しました。 [#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)).
* [#65621](https://github.com/ClickHouse/ClickHouse/issues/65621) でバックポート: `Nested` カラムによる `ARRAY JOIN` を含む distributed query で発生する `Cannot find column` を修正しました。 [#64755](https://github.com/ClickHouse/ClickHouse/issues/64755) を修正。 [#64801](https://github.com/ClickHouse/ClickHouse/pull/64801) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65933](https://github.com/ClickHouse/ClickHouse/issues/65933) でバックポート: `PostgreSQL` から読み取るクエリで、ClickHouse クエリが完了した場合は内部の `PostgreSQL` クエリもキャンセルするようにしました。これにより、内部の `PostgreSQL` クエリが完了するまで `ClickHouse` クエリをキャンセルできない問題を防ぎます。 [#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)).
* [#66301](https://github.com/ClickHouse/ClickHouse/issues/66301) でバックポート: `IS NULL` チェックを含む join 条件の処理を改善しました (たとえば `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` は `ON a <=> b` に書き換えられます) 。また、`IS NULL` 以外の condition がある場合に誤った最適化が行われる問題も修正しました。 [#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* [#66328](https://github.com/ClickHouse/ClickHouse/issues/66328) でバックポート: `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` は結果のスキーマを変えうるため、スキーマ推論 cache に不足していたこれらの settings を追加しました。これにより、これらの settings を変更した際にスキーマ推論結果が不正になるのを防ぎます。 [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* [#66155](https://github.com/ClickHouse/ClickHouse/issues/66155) でバックポート: `unbin`/`unhex` の実装における buffer overflow bug を修正しました。 [#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* [#66454](https://github.com/ClickHouse/ClickHouse/issues/66454) でバックポート: ZooKeeper client の bug を修正しました。ZooKeeper からハードウェア error を受信すると、session が使用不能な state のまま停止することがありました。たとえば、ClickHouse Keeper の &quot;soft memory limit&quot; によって発生する可能性があります。 [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#66226](https://github.com/ClickHouse/ClickHouse/issues/66226) でバックポート: SumIfToCountIfVisitor と signed integers に関する issue を修正しました。 [#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* [#66680](https://github.com/ClickHouse/ClickHouse/issues/66680) でバックポート: 索引 を使用できない場合の `system.numbers_mt` における limit の処理を修正しました。 [#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#66604](https://github.com/ClickHouse/ClickHouse/issues/66604) でバックポート: Docker などのコンテナー内で server が動作している場合に、cgroups v2 で指定された使用可能な最大 CPU コア数を ClickHouse server が正しく検出できるよう修正しました。詳しく言うと、コンテナーでは空の名前を持つ root cgroup でプロセスが実行されることがよくありますが、その場合 ClickHouse は cgroups v2 で設定された CPU 制限を無視していました。 [#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
* [#66360](https://github.com/ClickHouse/ClickHouse/issues/66360) でバックポート: 制約内で `IN` を含むサブクエリを使用した際に発生する `Not-ready set` エラーを修正しました。[#66261](https://github.com/ClickHouse/ClickHouse/pull/66261) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66972](https://github.com/ClickHouse/ClickHouse/issues/66972) でバックポート: `group_by_use_nulls=true` かつ新しいアナライザ使用時に発生する `Column identifier is already registered` エラーを修正しました。[#66400](https://github.com/ClickHouse/ClickHouse/pull/66400) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66969](https://github.com/ClickHouse/ClickHouse/issues/66969) でバックポート: `GROUP BY` キーに定数式を含み、新しいアナライザが有効なクエリで発生する `Cannot find column` エラーを修正しました。[#66433](https://github.com/ClickHouse/ClickHouse/pull/66433) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66720](https://github.com/ClickHouse/ClickHouse/issues/66720) でバックポート: `Allocator::realloc` のメモリ使用量を正しく追跡するよう修正しました。[#66548](https://github.com/ClickHouse/ClickHouse/pull/66548) ([Antonio Andelic](https://github.com/antonio2368)).
* [#66951](https://github.com/ClickHouse/ClickHouse/issues/66951) でバックポート: `WINDOW` を含むクエリで不正な結果が返る問題を修正しました。これは、`PARTITION` カラムがスパースなシリアライゼーションを持ち、ウィンドウ関数が並列に実行された場合に発生することがありました。[#66579](https://github.com/ClickHouse/ClickHouse/pull/66579) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66757](https://github.com/ClickHouse/ClickHouse/issues/66757) でバックポート: `(column IS NULL).` という式を含むクエリで発生する `Unknown identifier` および `Column is not under aggregate function` エラーを修正しました。このバグは [#65088](https://github.com/ClickHouse/ClickHouse/issues/65088) が原因で、アナライザ無効時にのみ発生していました。[#66654](https://github.com/ClickHouse/ClickHouse/pull/66654) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66948](https://github.com/ClickHouse/ClickHouse/issues/66948) でバックポート: スカラーサブクエリを IN の第 1 引数として使用した際に発生する `Method getResultType is not supported for QUERY query node` エラーを修正しました (新しいアナライザ使用時) 。[#66655](https://github.com/ClickHouse/ClickHouse/pull/66655) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#67633](https://github.com/ClickHouse/ClickHouse/issues/67633) でバックポート: Context::getDDLWorker でまれに発生するデッドロックを修正しました。[#66843](https://github.com/ClickHouse/ClickHouse/pull/66843) ([Alexander Gololobov](https://github.com/davenger)).
* [#67481](https://github.com/ClickHouse/ClickHouse/issues/67481) でバックポート: まれに、ディスク上の予期しないプロジェクションが原因で ClickHouse がパーツを破損していると誤認することがありました。この問題を修正しました。[#66898](https://github.com/ClickHouse/ClickHouse/pull/66898) ([alesapin](https://github.com/alesapin)).
* [#67197](https://github.com/ClickHouse/ClickHouse/issues/67197) でバックポート: TRUNCATE DATABASE が DROP DATABASE クエリであるかのようにレプリケーションを停止してしまう問題を修正しました。[#67129](https://github.com/ClickHouse/ClickHouse/pull/67129) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#67379](https://github.com/ClickHouse/ClickHouse/issues/67379) でバックポート: 1 つの分片を持つ `Distriburted` テーブル上の `Merge` テーブルを読み取るクエリで発生する `Cannot convert column because it is non constant in source stream but must be constant in result.` エラーを修正しました。[#67146](https://github.com/ClickHouse/ClickHouse/pull/67146) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#67576](https://github.com/ClickHouse/ClickHouse/issues/67576)でバックポート: 入れ子になった短絡評価関数の実行を修正しました。 [#67520](https://github.com/ClickHouse/ClickHouse/pull/67520) ([Kruglov Pavel](https://github.com/Avogar)).
