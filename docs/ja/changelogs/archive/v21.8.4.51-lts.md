  # 2022年の変更履歴

<div id="clickhouse-release-v218451-lts-fixme-as-compared-to-v218344-lts">
  ### ClickHouse リリース v21.8.4.51-lts FIXME (v21.8.3.44-lts と比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#27650](https://github.com/ClickHouse/ClickHouse/issues/27650) でバックポート: 一部のパーツに欠落したカラムが含まれている場合に、projection の materialization 中にクラッシュする問題を修正しました。これにより [#27512](https://github.com/ClickHouse/ClickHouse/issues/27512) も修正されます。[#27528](https://github.com/ClickHouse/ClickHouse/pull/27528) ([Amos Bird](https://github.com/amosbird))。
* [#27625](https://github.com/ClickHouse/ClickHouse/issues/27625) でバックポート: 部分から time 値を構築する際に発生するアンダーフローを修正しました。[#27193](https://github.com/ClickHouse/ClickHouse/issues/27193) をクローズします。[#27605](https://github.com/ClickHouse/ClickHouse/pull/27605) ([Vasily Nemkov](https://github.com/Enmk))。
* [#27779](https://github.com/ClickHouse/ClickHouse/issues/27779) でバックポート: `Distributed` table のエイリアス付きカラムに関する bug を修正しました。[#27652](https://github.com/ClickHouse/ClickHouse/pull/27652) ([Vladimir C](https://github.com/vdimir))。
* [#27713](https://github.com/ClickHouse/ClickHouse/issues/27713) でバックポート: `Unexpected merged part ... intersecting drop range ...` error の別の発生ケースを修正しました。[#27656](https://github.com/ClickHouse/ClickHouse/pull/27656) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#27673](https://github.com/ClickHouse/ClickHouse/issues/27673) でバックポート: PostgreSQL table function で接続が閉じられなくなる問題を修正しました。[#26088](https://github.com/ClickHouse/ClickHouse/issues/26088) をクローズします。[#27662](https://github.com/ClickHouse/ClickHouse/pull/27662) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#27700](https://github.com/ClickHouse/ClickHouse/issues/27700) でバックポート: `arrayHas` のような関数を、`DateTime` や `DateTime64` などの異なる非数値型の Nullable な LowCardinality の配列に適用した際に発生する不正な型 CAST を修正しました。以前のバージョンでは不正な CAST が発生していましたが、新しいバージョンでは exception が発生するようになります。これにより [#26330](https://github.com/ClickHouse/ClickHouse/issues/26330) をクローズします。[#27682](https://github.com/ClickHouse/ClickHouse/pull/27682) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#27747](https://github.com/ClickHouse/ClickHouse/issues/27747) でバックポート: arrow-cmake の CMakeLists.txt から重複したソースファイルを削除しました。[#27736](https://github.com/ClickHouse/ClickHouse/pull/27736) ([李扬](https://github.com/taiyang-li))。
