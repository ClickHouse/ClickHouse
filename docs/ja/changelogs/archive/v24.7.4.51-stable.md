<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#68232](https://github.com/ClickHouse/ClickHouse/issues/68232)でバックポート: サブクエリを使ったフィルタリング時に、一部のシステムテーブルで `Not-ready Set` となる問題を修正しました。[#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* [#68068](https://github.com/ClickHouse/ClickHouse/issues/68068)でバックポート: 外部データベース (`PostgreSQL` などのエンジン) に送信されるクエリ内のブール値リテラルを修正しました。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* [#68613](https://github.com/ClickHouse/ClickHouse/issues/68613)でバックポート: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026) を修正しました。`ReplaceTableNodeToDummyVisitor` で、未解決の table function の引数を走査しないようにしました。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* [#68278](https://github.com/ClickHouse/ClickHouse/issues/68278)でバックポート: HTTPインターフェイス経由でストリーム系エンジン (Kafka、RabbitMQ、NATS) に insert する際の問題を修正しました。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#68040](https://github.com/ClickHouse/ClickHouse/issues/68040)でバックポート: 再帰 CTE を含む VIEW の作成に関する問題を修正しました。[#67587](https://github.com/ClickHouse/ClickHouse/pull/67587) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#68038](https://github.com/ClickHouse/ClickHouse/issues/68038)でバックポート: `percent_rank` で発生するクラッシュを修正しました。`percent_rank` のデフォルトのフレーム型を `range unbounded preceding and unbounded following` に変更しました。`IWindowFunction` のデフォルトのウィンドウフレームが考慮されるようになり、SQL 内でウィンドウフレーム定義のない window function も異なる `WindowTransfomer` に適切に配置できるようになりました。[#67661](https://github.com/ClickHouse/ClickHouse/pull/67661) ([lgbo](https://github.com/lgbo-ustc)).
* [#68224](https://github.com/ClickHouse/ClickHouse/issues/68224)でバックポート: predicate に非決定論的関数が含まれる場合に `count()` の結果が誤る問題を修正しました。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#68095](https://github.com/ClickHouse/ClickHouse/issues/68095)でバックポート: 使用可能な CPU 数が制限されているコンテナ化環境で、最大 thread ソフト制限の計算を修正しました。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* [#68126](https://github.com/ClickHouse/ClickHouse/issues/68126)でバックポート: 新しいアナライザにおける mutations で、未変更のパーツをスキップする処理を修正しました。従来は、アナライザが enabled の場合、predicate 上は mutation がその part に影響しない場合でも、その part のデータが mutation によって rewritten されることがありました。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* [#68223](https://github.com/ClickHouse/ClickHouse/issues/68223)でバックポート: 特別に細工されたクエリによってトリガーされ、hopEnd、hopStart、tumbleEnd、tumbleStart を介して server をクラッシュさせる NULL ポインタ逆参照を修正しました。[#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* [#68175](https://github.com/ClickHouse/ClickHouse/issues/68175)でバックポート: `OFFSET` を使用するサブクエリでソートを削除する誤った最適化を削除しました。[#67906](https://github.com/ClickHouse/ClickHouse/issues/67906) を修正しました。[#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)).
* [#68341](https://github.com/ClickHouse/ClickHouse/issues/68341)でバックポート: クエリがキャンセルされた際にPostgresがクラッシュする問題の修正を試みる。 [#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#68398](https://github.com/ClickHouse/ClickHouse/issues/68398)でバックポート: クエリ `SYSTEM SYNC REPLICA` に sync replica モードが欠けていた問題を修正。 [#68326](https://github.com/ClickHouse/ClickHouse/pull/68326) ([Duc Canh Le](https://github.com/canhld94)).
* [#68669](https://github.com/ClickHouse/ClickHouse/issues/68669)でバックポート: 関数 `sipHash64Keyed`、`sipHash128Keyed`、または `sipHash128ReferenceKeyed` を空の配列またはタプルに適用した際に `LOGICAL_ERROR` が発生する問題を修正。 [#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)).
