<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#74802](https://github.com/ClickHouse/ClickHouse/issues/74802) でバックポート: SQLインジェクションを防ぐため、PostgreSQL および SQLite の table function に関するセキュリティ上の問題を修正しました。 [#74144](https://github.com/ClickHouse/ClickHouse/pull/74144) ([Pablo Marcos](https://github.com/pamarcos)).
* [#74866](https://github.com/ClickHouse/ClickHouse/issues/74866) でバックポート: Keeper の修正: ディスクからのログエントリの読み取りに関する不具合を修正しました。 [#74785](https://github.com/ClickHouse/ClickHouse/pull/74785) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#75283](https://github.com/ClickHouse/ClickHouse/issues/75283) でバックポート: デフォルト設定をさらに厳しくする改善。現在のデフォルト設定はすでに安全で、ポートを明示的に公開するにはユーザーがオプションを指定する必要があります。ただし、`default` ユーザーに `CLICKHOUSE_PASSWORD` で設定されたパスワードがなく、かつ/または `CLICKHOUSE_USER` 環境変数でユーザー名が変更されていない場合は、追加の保護策としてローカルシステムからのみ利用可能にすべきです。[#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

* [#75326](https://github.com/ClickHouse/ClickHouse/issues/75326) にバックポート: entrypoint.sh でユーザーのセットアップをスキップするオプションを追加しました。[#75316](https://github.com/ClickHouse/ClickHouse/pull/75316) ([Nikita Fomichev](https://github.com/fm4v))。
