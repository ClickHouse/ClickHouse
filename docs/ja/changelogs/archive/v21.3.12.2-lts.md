  # 2022年の変更履歴

<div id="clickhouse-release-v213122-lts-fixme-as-compared-to-v213115-lts">
  ### ClickHouse リリース v21.3.12.2-lts FIXME (v21.3.11.5-ltsとの比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#24189](https://github.com/ClickHouse/ClickHouse/issues/24189) にバックポート: 一部の `ALTER PARTITION` クエリによって、レプリケーションキューで `Part A intersects previous part B` および `Unexpected merged part C intersecting drop range D` エラーが発生する可能性がありました。修正済みです。[#23296](https://github.com/ClickHouse/ClickHouse/issues/23296) を修正。[#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24306](https://github.com/ClickHouse/ClickHouse/issues/24306) にバックポート: WHERE 句で const の `DateTime` 値と `DateTime64` カラムを使用した際の不具合を修正しました。 ... [#24100](https://github.com/ClickHouse/ClickHouse/pull/24100) ([Vasily Nemkov](https://github.com/Enmk)).
* [#24140](https://github.com/ClickHouse/ClickHouse/issues/24140) にバックポート: バグ: `select xxx final`を指定した explain pipeline が誤ったパイプラインを表示していました: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* [#24190](https://github.com/ClickHouse/ClickHouse/issues/24190) にバックポート: まれに、部分的にしか初期化されていない table が書き込みリクエスト (insert/alter など) を処理できてしまう不具合を修正しました。現在、そのような table は readonly mode になります。[#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* [#24235](https://github.com/ClickHouse/ClickHouse/issues/24235) にバックポート: 高負荷時に RBAC で発生しうる race condition を修正しました。この PR は [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090)、[#24134](https://github.com/ClickHouse/ClickHouse/issues/24134) を修正します。[#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#24244](https://github.com/ClickHouse/ClickHouse/issues/24244) にバックポート: クエリ実行中に hdfs へアクセスできなくなった場合に server が異常終了する問題を修正しました。[#24117](https://github.com/ClickHouse/ClickHouse/issues/24117) をクローズ。[#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#24241](https://github.com/ClickHouse/ClickHouse/issues/24241) にバックポート: StorageMemory の単純なタイプミスを修正しました。このバグは [#15127](https://github.com/ClickHouse/ClickHouse/issues/15127) で導入されたもので、今回修正されました。[#24192](https://github.com/ClickHouse/ClickHouse/issues/24192) をクローズ。[#24193](https://github.com/ClickHouse/ClickHouse/pull/24193) ([张中南](https://github.com/plugine)).
* [#24353](https://github.com/ClickHouse/ClickHouse/issues/24353) にバックポート: materialized view を Ordinary database から atomic database へ移動する際のバグ (`RENAME TABLE` クエリ) を修正しました。これにより、内部 table も materialized view とともに新しい database へ移動されます。[#23926](https://github.com/ClickHouse/ClickHouse/issues/23926) を修正。[#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).

  #### CHANGELOG非掲載 / 軽微

* メモリの重複に対処するため、PODArray::insert で `memmove` を使用するように変更 [#24271](https://github.com/ClickHouse/ClickHouse/pull/24271) ([Fu Zhe](https://github.com/fuzhe1989)).
