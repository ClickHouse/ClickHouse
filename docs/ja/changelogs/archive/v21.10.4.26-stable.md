<div id="clickhouse-release-v2110426-stable-fixme-as-compared-to-v211039-stable">
  ### ClickHouse リリース v21.10.4.26-stable FIXME (v21.10.3.9-stable との比較)
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#31731](https://github.com/ClickHouse/ClickHouse/issues/31731)でバックポート: JSON および XML 出力フォーマットのパフォーマンスを改善しました。[#31673](https://github.com/ClickHouse/ClickHouse/pull/31673) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。

<div id="bug-fix">
  #### バグ修正
</div>

* [#31573](https://github.com/ClickHouse/ClickHouse/issues/31573)でバックポート: Quota の上限には達していないにもかかわらず、上限超過として扱われていました。このPRで [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正します。 [#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#31518](https://github.com/ClickHouse/ClickHouse/issues/31518) でバックポート: `not like` 関数を RPNElement に移動。 [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* [#31554](https://github.com/ClickHouse/ClickHouse/issues/31554) でバックポート: S3 の STS 認証情報プロバイダーにおける `nullptr` の問題を修正。 [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#31579](https://github.com/ClickHouse/ClickHouse/issues/31579) でバックポート: * この最適化の不具合が修正されるまで、`partial_merge_join_left_table_buffer_bytes` を無効化。 [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009) を参照。) * 冗長なオプション `partial_merge_join_optimizations` を削除。 [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* [#31745](https://github.com/ClickHouse/ClickHouse/issues/31745) でバックポート: `Ordinary` データベースで DDL Dictionary のリネームを試みた際に、`RENAME TABLE` クエリが正しく動作しなかった問題を修正。 [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31794](https://github.com/ClickHouse/ClickHouse/issues/31794) でバックポート: `IPv4` などの domain 型のパースで、Settings `input_format_allow_errors_num` と `input_format_allow_errors_ratio` が機能しなかった問題を修正。 [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686) を修正。 [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31830](https://github.com/ClickHouse/ClickHouse/issues/31830) でバックポート: 指定したクラスター名が `Replicated` データベース名である場合に、`ON CLUSTER` クエリの実行時に `there are no such cluster here` エラーが発生する問題を修正。 [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31815](https://github.com/ClickHouse/ClickHouse/issues/31815) でバックポート: データと Progress の行が出力に混在する場合に、JSONEachRowWithProgress 出力フォーマットで発生する競合状態を修正。 [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32016](https://github.com/ClickHouse/ClickHouse/issues/32016) でバックポート: 位置引数が有効な場合の GROUP BY / ORDER BY / LIMIT BY の別名に関する問題を修正。 [#31173](https://github.com/ClickHouse/ClickHouse/issues/31173) をクローズ。 [#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#31762](https://github.com/ClickHouse/ClickHouse/issues/31762) でバックポート: `Map` 型での `Buffer` テーブルエンジンの使用に関する問題を修正。 [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546) を修正。 [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* [#31892](https://github.com/ClickHouse/ClickHouse/issues/31892) でバックポート: TSKV フォーマットで発生する可能性があるアサーション `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` を修正。 [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32031](https://github.com/ClickHouse/ClickHouse/issues/32031) でバックポート: Nullable 主キー使用時に Nullable 型で発生する不正なキャストを修正。これにより [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075) を修正。 [#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird)).
* [#32074](https://github.com/ClickHouse/ClickHouse/issues/32074)でバックポート: Decimal 型の引数を持つ関数 `transform` の不具合を修正しました。[#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* [#31939](https://github.com/ClickHouse/ClickHouse/issues/31939)でバックポート: - `KeeperTCPHandler` の構築時に、設定パスを `keeper_server.session_timeout_ms` から `keeper_server.coordination_settings.session_timeout_ms` に変更 - `operation_timeout` についても同様に変更。[#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* [#31909](https://github.com/ClickHouse/ClickHouse/issues/31909)でバックポート: `UUID` 型の引数に対する関数 `empty` および `notEmpty` の不具合を修正しました。[#31819](https://github.com/ClickHouse/ClickHouse/issues/31819) を修正。[#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).

<div id="not-for-changelog-insignificant">
