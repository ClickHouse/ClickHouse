<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#40162](https://github.com/ClickHouse/ClickHouse/issues/40162)でバックポート: カラムが const の場合に HashMethodOneNumber が誤ったキー値を取得する不具合を修正しました。 [#40020](https://github.com/ClickHouse/ClickHouse/pull/40020) ([Duc Canh Le](https://github.com/canhld94)).
* [#40124](https://github.com/ClickHouse/ClickHouse/issues/40124)でバックポート: 再計算対象の索引に正しいファイル拡張子 (.idx または idx2) を追加することで collectFilesToSkip() の不具合を修正し、誤ったハードリンクを回避しました。[#39896](https://github.com/ClickHouse/ClickHouse/issues/39896) を修正しました。 [#40095](https://github.com/ClickHouse/ClickHouse/pull/40095) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* [#40209](https://github.com/ClickHouse/ClickHouse/issues/40209)でバックポート: 暗号化関数の引数チェック不足を修正しました (クエリ fuzzer により発見) 。これにより [#39987](https://github.com/ClickHouse/ClickHouse/issues/39987) をクローズしました。 [#40194](https://github.com/ClickHouse/ClickHouse/pull/40194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#40281](https://github.com/ClickHouse/ClickHouse/issues/40281)でバックポート: CapnProto 入力フォーマットで発生しうる segfault を修正しました。この不具合は *kiojj* により ClickHouse bug-bounty [program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて発見され、報告されました。 [#40241](https://github.com/ClickHouse/ClickHouse/pull/40241) ([Kruglov Pavel](https://github.com/Avogar)).
* [#40489](https://github.com/ClickHouse/ClickHouse/issues/40489)でバックポート: MergeTree エンジンファミリーのカラムTTLに関するまれな不具合を修正しました。垂直マージが繰り返される場合、`Cannot unlink file ColumnName.bin ... No such file or directory.` という error が発生する可能性がありました。 [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).

* CI での変更履歴の冗長さを削減 [#40360](https://github.com/ClickHouse/ClickHouse/pull/40360) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* DNSResolver から AI&#95;V4MAPPED、AI&#95;ALL のヒントを削除 [#40502](https://github.com/ClickHouse/ClickHouse/pull/40502) ([Maksim Kita](https://github.com/kitaisreal)).
