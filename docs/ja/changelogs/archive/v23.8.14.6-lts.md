<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#63172](https://github.com/ClickHouse/ClickHouse/issues/63172) にバックポート: `server_name` を設定することで、MongoDB Atlas への接続時に最近報告された SSL ハンドシェイクエラーの解消に役立つ可能性があります: `Poco::Exception. Code: 1000, e.code() = 0, SSL Exception: error:10000438:SSL routines:OPENSSL_internal:TLSV1_ALERT_INTERNAL_ERROR`。[#63122](https://github.com/ClickHouse/ClickHouse/pull/63122) ([Alexander Gololobov](https://github.com/davenger)).
* [#63164](https://github.com/ClickHouse/ClickHouse/issues/63164) にバックポート: MongoDB の wire protocol version の確認では、これまで `config` database へのアクセスを試みていましたが、ユーザーにその database への permission がない場合は失敗することがあります。この修正では、ユーザーが指定した database 名を使用します。[#63126](https://github.com/ClickHouse/ClickHouse/pull/63126) ([Alexander Gololobov](https://github.com/davenger)).
