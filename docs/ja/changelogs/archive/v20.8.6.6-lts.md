  ### ClickHouse リリース v20.8.6.6-lts FIXME、v20.8.5.45-ltsとの比較
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#16494](https://github.com/ClickHouse/ClickHouse/issues/16494)でバックポート: MySQL データベースに関するバグを修正しました。データベースエンジンとして使用している MySQL サーバーが停止すると、本来不要であるにもかかわらず無効なサーバーからテーブルを取得しようとして、一部のクエリで Exception が発生していました。たとえば、クエリ `SELECT ... FROM system.parts` は MergeTree テーブルに対してのみ動作し、MySQL データベースにはまったくアクセスしないはずです。[#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* [#16816](https://github.com/ClickHouse/ClickHouse/issues/16816)でバックポート: フィルタリング用の set が作成されていなかったため、返却データの一部が欠落することがある不整合な動作を修正しました。[#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16506](https://github.com/ClickHouse/ClickHouse/issues/16506)でバックポート: レプリケーションキュー内の非常に大きなエントリの処理を修正しました。テーブル構造が極端に大きい (1 MB 近い) 場合、ALTER クエリで非常に大きなエントリが生成されることがあります。これにより [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307) を修正します。[#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#16472](https://github.com/ClickHouse/ClickHouse/issues/16472)でバックポート: Distributed に対する DROP TABLE を修正しました (INSERT と競合する可能性がありました) 。[#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* [#16573](https://github.com/ClickHouse/ClickHouse/issues/16573)でバックポート: GTID set を適切に縮小することで、MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine を使用し、かつ MySQL Slave で `slave_parallel_worker` が有効な場合にメタデータが急増する問題を修正しました。これにより [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951) を修正します。[#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* [#16552](https://github.com/ClickHouse/ClickHouse/issues/16552)でバックポート: 入力された AVRO をパースする際に、型から LowCardinality が削除されるようになりました。[#16188](https://github.com/ClickHouse/ClickHouse/issues/16188) を修正します。[#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* [#16823](https://github.com/ClickHouse/ClickHouse/issues/16823)でバックポート: [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081) を修正しました。[#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16892](https://github.com/ClickHouse/ClickHouse/issues/16892)でバックポート: クエリプロファイラが有効で、かつ ClickHouse が、一部の関数に対して (おそらく) 壊れた非同期アンワインドテーブルを含む glibc バージョンの OS にインストールされている場合に発生する、まれなサイレントクラッシュを修正しました。これにより [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301) を修正します。これにより [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098) も修正します。[#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
