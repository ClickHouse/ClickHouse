<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#56633](https://github.com/ClickHouse/ClickHouse/issues/56633)でバックポート: [#54043](https://github.com/ClickHouse/ClickHouse/issues/54043) で、セットアッププランがログに出力されるようになりました。これは `runner_get_all_tests.log` にのみ出力されるべきです。あわせて、失敗したインフラストラクチャイベントを CI DB に送信するようにしました。[#56214](https://github.com/ClickHouse/ClickHouse/pull/56214) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#56737](https://github.com/ClickHouse/ClickHouse/issues/56737)でバックポート: builder コンテナーで変更されたサブモジュールをフェッチしないようにしました。[#56689](https://github.com/ClickHouse/ClickHouse/pull/56689) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* table function をベースにした table の場合のシステムテーブルからの SELECT を修正。 [#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* `flatten_nested` と `data_type_default_nullable` を使用した backup からの restore を修正。 [#56306](https://github.com/ClickHouse/ClickHouse/pull/56306) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Kerberos 初期化中に発生する segfault を修正。 [#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* 修正: RabbitMQ における OpenSSL の動的 loading の問題。 [#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* data にゼロが含まれている場合に発生する GCD codec の crash を修正。 [#56704](https://github.com/ClickHouse/ClickHouse/pull/56704) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* FPC codec の crash を修正。 [#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴対象外 / 軽微

* ワークフローを再利用可能なテストに書き換える作業を継続 [#56501](https://github.com/ClickHouse/ClickHouse/pull/56501) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 例外メッセージを改善 [#56854](https://github.com/ClickHouse/ClickHouse/pull/56854) ([Antonio Andelic](https://github.com/antonio2368)).
