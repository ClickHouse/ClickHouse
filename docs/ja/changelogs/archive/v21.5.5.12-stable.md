<div id="bug-fix">
  #### バグ修正
</div>

* [#24156](https://github.com/ClickHouse/ClickHouse/issues/24156)でバックポート: Kafka storage が Parquet フォーマットのメッセージをサポートできるようになりました。[#23412](https://github.com/ClickHouse/ClickHouse/pull/23412) ([Chao Ma](https://github.com/godliness)).
* [#24187](https://github.com/ClickHouse/ClickHouse/issues/24187)でバックポート: 一部の `ALTER PARTITION` クエリにより、レプリケーションキューで `Part A intersects previous part B` および `Unexpected merged part C intersecting drop range D` エラーが発生することがありました。修正済みです。[#23296](https://github.com/ClickHouse/ClickHouse/issues/23296) を修正。[#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24304](https://github.com/ClickHouse/ClickHouse/issues/24304)でバックポート: WHERE で const の `DateTime` 値と `DateTime64` カラムを使用した場合の問題を修正しました。 ... [#24100](https://github.com/ClickHouse/ClickHouse/pull/24100) ([Vasily Nemkov](https://github.com/Enmk)).
* [#24142](https://github.com/ClickHouse/ClickHouse/issues/24142)でバックポート: バグ: `select xxx final` を使った explain pipeline で、誤ったパイプラインが表示される問題を修正しました: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* [#24214](https://github.com/ClickHouse/ClickHouse/issues/24214)でバックポート: 高負荷時に RBAC で発生する可能性があった race condition を修正しました。この PR は [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090), [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134), を修正します。[#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#24242](https://github.com/ClickHouse/ClickHouse/issues/24242)でバックポート: クエリ実行中に hdfs にアクセスできなくなったことで発生する server の異常終了を修正しました。[#24117](https://github.com/ClickHouse/ClickHouse/issues/24117) をクローズ。[#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#24239](https://github.com/ClickHouse/ClickHouse/issues/24239)でバックポート: StorageMemory の誤字を修正しました。この bug は [#15127](https://github.com/ClickHouse/ClickHouse/issues/15127) で混入したもので、現在は修正済みです。[#24192](https://github.com/ClickHouse/ClickHouse/issues/24192) をクローズ。[#24193](https://github.com/ClickHouse/ClickHouse/pull/24193) ([张中南](https://github.com/plugine)).
