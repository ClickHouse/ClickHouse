<div id="clickhouse-release-v2410321-stable-e668b927efb-fixme-as-compared-to-v2410280-stable-96b80057159">
  ### ClickHouse リリース v24.10.3.21-stable (e668b927efb) FIXME (v24.10.2.80-stable (96b80057159) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#72100](https://github.com/ClickHouse/ClickHouse/issues/72100) にバックポート: ZooKeeper 内の `metadata_version` レコードは、attach thread ではなく restarting thread で修正するようにしました。[#70297](https://github.com/ClickHouse/ClickHouse/pull/70297) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
* [#72169](https://github.com/ClickHouse/ClickHouse/issues/72169) にバックポート: 混乱を避けるため、min/max 関数で Dynamic/Variant 型を禁止しました。[#71761](https://github.com/ClickHouse/ClickHouse/pull/71761) ([Pavel Kruglov](https://github.com/Avogar))。
* [#72064](https://github.com/ClickHouse/ClickHouse/issues/72064) にバックポート: Dictionary storage、dictionary table function、または辞書自体に対する直接の SELECT を使って辞書から直接データを取得する場合、辞書に対して `SELECT` 権限または `dictGet` 権限があれば十分になりました。これは、ACL バイパスを防ぐためのこれまでの取り組み([https://github.com/ClickHouse/ClickHouse/pull/57362](https://github.com/ClickHouse/ClickHouse/pull/57362) および [https://github.com/ClickHouse/ClickHouse/pull/65359](https://github.com/ClickHouse/ClickHouse/pull/65359)) と整合しています。また、後者との後方互換性も確保されます。[#72051](https://github.com/ClickHouse/ClickHouse/pull/72051) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#72144](https://github.com/ClickHouse/ClickHouse/issues/72144) にバックポート: Keeper が利用できない場合に起こり得るデータ損失を防ぐため、part を zero-copy ディスクへ移動する前に zero-copy shared lock を取得するようにしました。[#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72088](https://github.com/ClickHouse/ClickHouse/issues/72088) にバックポート: 24.6 で壊れていた system.s3/azure&#95;queue&#95;log の `rows_processed` カラムを修正しました。[#69975](https://github.com/ClickHouse/ClickHouse/issues/69975) をクローズします。[#71946](https://github.com/ClickHouse/ClickHouse/pull/71946) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#72036](https://github.com/ClickHouse/ClickHouse/issues/72036) にバックポート: 最初の argument が定数の場合に、`ORDER BY` に binary monotonic function を含む `MergeTree` table で発生していた `Illegal type` error を修正しました。[#71941](https://github.com/ClickHouse/ClickHouse/issues/71941) を修正します。[#71966](https://github.com/ClickHouse/ClickHouse/pull/71966) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
