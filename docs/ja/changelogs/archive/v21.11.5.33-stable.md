<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#31517](https://github.com/ClickHouse/ClickHouse/issues/31517) でバックポート: `not like` 関数を RPNElement に移動。 [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* [#31551](https://github.com/ClickHouse/ClickHouse/issues/31551) でバックポート: S3 用の STS 認証情報プロバイダーにおける `nullptr` を修正。 [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#31580](https://github.com/ClickHouse/ClickHouse/issues/31580) でバックポート: * この最適化の不具合が修正されるまで `partial_merge_join_left_table_buffer_bytes` を無効化。 [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009) を参照。) * 冗長なオプション `partial_merge_join_optimizations` を削除。 [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* [#31600](https://github.com/ClickHouse/ClickHouse/issues/31600) でバックポート: 無効な UTF-8 シーケンスを含むのがカラム名だけである場合に生成される不正な JSON を修正。 [#31534](https://github.com/ClickHouse/ClickHouse/pull/31534) ([Kevin Michel](https://github.com/kmichel-aiven)).
* [#31593](https://github.com/ClickHouse/ClickHouse/issues/31593) でバックポート: non-x86 のすべてのビルドが壊れていました。これらに対するテストがないためです。これにより [#31417](https://github.com/ClickHouse/ClickHouse/issues/31417) をクローズします。これにより [#31524](https://github.com/ClickHouse/ClickHouse/issues/31524) をクローズします。 [#31574](https://github.com/ClickHouse/ClickHouse/pull/31574) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#31795](https://github.com/ClickHouse/ClickHouse/issues/31795) でバックポート: sparkbars の位置が揃わない問題を修正。参照: [#26175](https://github.com/ClickHouse/ClickHouse/issues/26175)#issuecomment-960353867, [comment](https://github.com/ClickHouse/ClickHouse/issues/26175#issuecomment-961155065)。 [#31624](https://github.com/ClickHouse/ClickHouse/pull/31624) ([小路](https://github.com/nicelulu)).
* [#31747](https://github.com/ClickHouse/ClickHouse/issues/31747) でバックポート: `Ordinary` データベース内の DDL Dictionary をリネームしようとした際に、`RENAME TABLE` クエリが正しく動作していなかった問題を修正。 [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31791](https://github.com/ClickHouse/ClickHouse/issues/31791) でバックポート: `input_format_allow_errors_num` および `input_format_allow_errors_ratio` の設定が、`IPv4` などの domain 型のパースで機能していなかった問題を修正。 [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686) を修正。 [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31895](https://github.com/ClickHouse/ClickHouse/issues/31895) でバックポート: * 文字列に UTF-8 文字が含まれる場合の関数 N-gram を修正。 [#31706](https://github.com/ClickHouse/ClickHouse/pull/31706) ([yandd](https://github.com/yandd)).
* [#31831](https://github.com/ClickHouse/ClickHouse/issues/31831) でバックポート: 指定したクラスター名が `Replicated` データベースの名前である場合に、`ON CLUSTER` クエリの実行時に `there are no such cluster here` エラーが発生する問題を修正。 [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#31814](https://github.com/ClickHouse/ClickHouse/issues/31814) でバックポート: data と Progress 行が出力内で混在した場合の JSONEachRowWithProgress 出力フォーマットにおける競合状態を修正。 [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32015](https://github.com/ClickHouse/ClickHouse/issues/32015) にバックポート: 同時実行される `ATTACH PARTITION` クエリでまれに発生する segfault を修正しました。[#31738](https://github.com/ClickHouse/ClickHouse/pull/31738) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#32017](https://github.com/ClickHouse/ClickHouse/issues/32017) にバックポート: 位置引数が有効な場合の group by / order by / limit by の別名処理を修正しました。[#31173](https://github.com/ClickHouse/ClickHouse/issues/31173) をクローズしました。[#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#31760](https://github.com/ClickHouse/ClickHouse/issues/31760) にバックポート: `Map` 型での `Buffer` table engine の使用に関する不具合を修正しました。[#30546](https://github.com/ClickHouse/ClickHouse/issues/30546) を修正しました。[#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ))。
* [#31891](https://github.com/ClickHouse/ClickHouse/issues/31891) にバックポート: TSKV フォーマットで発生する可能性がある assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` を修正しました。[#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar))。
* [#32029](https://github.com/ClickHouse/ClickHouse/issues/32029) にバックポート: Nullable な主キーを使用している場合に、Nullable 型で無効な cast が行われる問題を修正しました。これにより [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075) を修正しました。[#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird))。
* [#31920](https://github.com/ClickHouse/ClickHouse/issues/31920) にバックポート: `use_uncompressed_cache` が有効な `MergeTree` テーブルの読み取りに関する不具合を修正しました。[#31826](https://github.com/ClickHouse/ClickHouse/pull/31826) ([Anton Popov](https://github.com/CurtizJ))。
* [#32076](https://github.com/ClickHouse/ClickHouse/issues/32076) にバックポート: Decimal 引数を持つ関数 transform に関する不具合を修正しました。[#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee))。
* [#31938](https://github.com/ClickHouse/ClickHouse/issues/31938) にバックポート: `KeeperTCPHandler` の構築時に、設定パスを `keeper_server.session_timeout_ms` から `keeper_server.coordination_settings.session_timeout_ms` に変更しました。`operation_timeout` も同様です。[#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo))。
* [#31908](https://github.com/ClickHouse/ClickHouse/issues/31908) にバックポート: `UUID` 型の引数に対する関数 `empty` と `notEmpty` の不具合を修正しました。[#31819](https://github.com/ClickHouse/ClickHouse/issues/31819) を修正しました。[#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ))。
* [#32091](https://github.com/ClickHouse/ClickHouse/issues/32091) にバックポート: すべてのレプリカでパーツが失われ、同じパーティション内にほかのパーツがない場合、一部の `GET_PART` エントリが replication queue でハングすることがありました。この問題は、パーティションキーに整数型のカラムまたは `Date[Time]` だけが含まれるケースで修正されています。[#31485](https://github.com/ClickHouse/ClickHouse/issues/31485) を修正しました。[#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#32020](https://github.com/ClickHouse/ClickHouse/issues/32020) にバックポート: テーブル作成に失敗した際に、FileLog engine が不要なメタデータディレクトリを作成してしまう問題を修正しました。[#31962](https://github.com/ClickHouse/ClickHouse/issues/31962) を修正しました。[#31967](https://github.com/ClickHouse/ClickHouse/pull/31967) ([flynn](https://github.com/ucasfl)).
