<div id="clickhouse-release-v2231380-lts-e2708b01fba-fixme-as-compared-to-v2231219-lts-4a08f8a073b">
  ### ClickHouse リリース v22.3.13.80-lts (e2708b01fba) FIXME、v22.3.12.19-lts (4a08f8a073b) との比較
</div>

<div id="new-feature">
  #### 新機能
</div>

* [#41264](https://github.com/ClickHouse/ClickHouse/issues/41264) でバックポート: データベースエンジンを `Ordinary` から `Atomic` に自動変換する機能を実装しました。`flags` ディレクトリに空の `convert_ordinary_to_atomic` ファイルを作成すると、次回サーバー起動時にすべての `Ordinary` データベースが自動的に変換されます。[#39546](https://github.com/ClickHouse/ClickHouse/issues/39546) を解決します。[#39933](https://github.com/ClickHouse/ClickHouse/pull/39933) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#40886](https://github.com/ClickHouse/ClickHouse/issues/40886) でバックポート: `kafka_num_consumers` の上限を無効化する設定を追加しました。[#40331](https://github.com/ClickHouse/ClickHouse/issues/40331) をクローズします。[#40670](https://github.com/ClickHouse/ClickHouse/pull/40670) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#41273](https://github.com/ClickHouse/ClickHouse/issues/41273)でバックポート: 引数として Nullable の Array を使用した場合に発生する、関数 `encrypt` および `contingency` のメモリ安全性の問題を修正しました。これにより [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004) も修正されます。[#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#41557](https://github.com/ClickHouse/ClickHouse/issues/41557) でバックポート: debパッケージに`source`フィールドを追加し、`nfpm`を更新。[#41531](https://github.com/ClickHouse/ClickHouse/pull/41531) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#40745](https://github.com/ClickHouse/ClickHouse/issues/40745) でバックポート: * JoinSwitcher における Nullable の lowcard の CAST を修正し、[#37385](https://github.com/ClickHouse/ClickHouse/issues/37385) をクローズしました。 [#37453](https://github.com/ClickHouse/ClickHouse/pull/37453) ([Vladimir C](https://github.com/vdimir)).
* [#41812](https://github.com/ClickHouse/ClickHouse/issues/41812) でバックポート: `simdjson` を更新しました。これにより [#38621](https://github.com/ClickHouse/ClickHouse/issues/38621) が修正されます。 [#38838](https://github.com/ClickHouse/ClickHouse/pull/38838) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41320](https://github.com/ClickHouse/ClickHouse/issues/41320) でバックポート: WITH ステートメントによって導入された、未使用の不明なカラムに関する問題を修正しました。これにより [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812) が修正されます。 [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* [#40904](https://github.com/ClickHouse/ClickHouse/issues/40904) でバックポート: タスク scheduling の失敗時に WriteBufferFromS3 で発生する可能性のあるデッドロックを修正しました。 [#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)).
* [#41916](https://github.com/ClickHouse/ClickHouse/issues/41916) でバックポート: MergeTree エンジン family のカラム有効期限 (TTL) に関するまれな bug を修正しました。vertical merge が繰り返される場合、`Cannot unlink file ColumnName.bin ... No such file or directory.` という error が発生することがありました。 [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
* [#40903](https://github.com/ClickHouse/ClickHouse/issues/40903) でバックポート: proxy リゾルバが endpoint への最初の成功したリクエストで停止するよう修正しました。 [#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)).
* [#40663](https://github.com/ClickHouse/ClickHouse/issues/40663) でバックポート: AWS SDK の bug により発生する可能性のあるデータ損失を修正しました ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658))。この bug は ClickHouse を S3 上で使用している場合にのみトリガーされます。 [#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
* [#40901](https://github.com/ClickHouse/ClickHouse/issues/40901) でバックポート: クエリ Context なしで MV に Push する際のメモリリークを修正しました (Kafka/... から)。 [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* [#41637](https://github.com/ClickHouse/ClickHouse/issues/41637) でバックポート: 集約関数コンビネータにおける segfault、use-heap-after-free、およびメモリリークの可能性を修正しました。[#40848](https://github.com/ClickHouse/ClickHouse/issues/40848) をクローズしました。 [#41083](https://github.com/ClickHouse/ClickHouse/pull/41083) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41664](https://github.com/ClickHouse/ClickHouse/issues/41664) でバックポート: サブクエリ内の `OFFSET` clause と外側のクエリの `WHERE` clause を含むクエリで、誤った結果が返される可能性がある問題を修正しました。[#40416](https://github.com/ClickHouse/ClickHouse/issues/40416) を修正します。 [#41280](https://github.com/ClickHouse/ClickHouse/pull/41280) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#41356](https://github.com/ClickHouse/ClickHouse/issues/41356) でバックポート: MsgPack フォーマットで UUID を挿入する前に、column type のチェックを追加しました。 [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
* [#41807](https://github.com/ClickHouse/ClickHouse/issues/41807)でバックポート: Native format 内の悪意あるデータにより、クラッシュが発生する可能性がありました。[#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41804](https://github.com/ClickHouse/ClickHouse/issues/41804)でバックポート: aggregate function `categorialInformationValue` のプロパティ定義が誤っており、実行時に null ポインタのデリファレンスが発生する可能性がありました。これにより [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443) はクローズされます。[#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41503](https://github.com/ClickHouse/ClickHouse/issues/41503)でバックポート: Apache `ORC` フォーマットでデータを書き込むと、バッファオーバーランが発生する可能性がありました。[#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#41639](https://github.com/ClickHouse/ClickHouse/issues/41639)でバックポート: `OFFSET` を含むクエリで発生しうる `pipeline stuck` 例外を修正しました。このエラーは、`enable_optimize_predicate_expression = 0` で、かつ `WHERE` に常に false となる条件がある場合に見つかりました。[#41383](https://github.com/ClickHouse/ClickHouse/issues/41383) を修正しました。[#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#41899](https://github.com/ClickHouse/ClickHouse/issues/41899)でバックポート: `optimize_monotonous_functions_in_order_by` 設定が有効な `Merge` table からの `SELECT` で発生しうるクラッシュを修正しました。[#41269](https://github.com/ClickHouse/ClickHouse/issues/41269) を修正しました。[#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
