Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザー影響のある不具合)
</div>

* [#38242](https://github.com/ClickHouse/ClickHouse/issues/38242)でバックポート: config からレプリカを削除した際に `Distributed` の非同期 INSERT で発生する可能性があったクラッシュを修正しました。[#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#38865](https://github.com/ClickHouse/ClickHouse/issues/38865)でバックポート: 並列読み取りバッファ使用時の S3 のシーク可能な読み取りを修正しました。 (クエリ実行時のメモリ使用量に影響していました。) [#38258](https://github.com/ClickHouse/ClickHouse/issues/38258) をクローズしました。[#38802](https://github.com/ClickHouse/ClickHouse/pull/38802) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#38853](https://github.com/ClickHouse/ClickHouse/issues/38853)でバックポート: `simdjson` を更新しました。これにより [#38621](https://github.com/ClickHouse/ClickHouse/issues/38621) が修正されます。[#38838](https://github.com/ClickHouse/ClickHouse/pull/38838) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#38942](https://github.com/ClickHouse/ClickHouse/issues/38942)でバックポート: Seconds 単位の settings profile を修正しました。[#38896](https://github.com/ClickHouse/ClickHouse/pull/38896) ([Raúl Marín](https://github.com/Algunenano)).
* [#39063](https://github.com/ClickHouse/ClickHouse/issues/39063)でバックポート: OvercommitTracker 内での割り当てがデッドロックを引き起こす可能性がありました。ログには有用な情報があまり含まれていなかったため、ログを削除しました。[#37794](https://github.com/ClickHouse/ClickHouse/issues/37794) を修正しました。[#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* [#39077](https://github.com/ClickHouse/ClickHouse/issues/39077)でバックポート: cache 容量が上限に達したタイミングと重なる一部のコーナーケースで発生し得る、ファイルシステムキャッシュの不具合を修正しました。[#39066](https://github.com/ClickHouse/ClickHouse/issues/39066) をクローズしました。[#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#39151](https://github.com/ClickHouse/ClickHouse/issues/39151)でバックポート: アタッチされた MATERIALIZED VIEW を持つ table への INSERT で、setting `extremes = 1` が有効な場合に発生する可能性があったエラー `Block structure mismatch` を修正しました。[#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) と [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729) をクローズしました。[#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#39275](https://github.com/ClickHouse/ClickHouse/issues/39275)でバックポート: `PREWHERE` と read-in-order 最適化を使用する SELECT で発生していたエラー `Not found column Type in block` を修正しました。[#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#39371](https://github.com/ClickHouse/ClickHouse/issues/39371)でバックポート: デフォルト引数 `x-max-length` および `x-overflow` なしで RabbitMQ キューを宣言するようにしました。[#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* [#39352](https://github.com/ClickHouse/ClickHouse/issues/39352)でバックポート: PostgreSQL データベースエンジンで PostgreSQL table を取得するクエリの誤りを修正しました。[#33502](https://github.com/ClickHouse/ClickHouse/issues/33502) をクローズしました。[#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
