<div id="clickhouse-release-v221111360-stable-0d211ed1984-fixme-as-compared-to-v221011877-stable-98ab5a3c189">
  ### ClickHouse リリース v22.11.1.1360-stable (0d211ed1984) FIXME v22.10.1.1877-stable (98ab5a3c189) と比較して
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* JSONExtract 関数ファミリーは、今後、要求された型への変換を試みるようになります。 [#41502](https://github.com/ClickHouse/ClickHouse/pull/41502) ([Márcio Martins](https://github.com/marcioapm)).

<div id="new-feature">
  #### 新機能
</div>

* * 関数 `displayName` を追加しました。[#36770](https://github.com/ClickHouse/ClickHouse/issues/36770) をクローズします。[#37681](https://github.com/ClickHouse/ClickHouse/pull/37681) ([hongbin](https://github.com/xlwh))。
* `system.query_log` に適用された行レベルポリシーを追加しました。[#39819](https://github.com/ClickHouse/ClickHouse/pull/39819) ([Vladimir Chebotaryov](https://github.com/quickhouse))。
* Hudi および DeltaLake テーブルエンジンを追加しました。読み取り専用で、S3 上のテーブルのみを対象とします。[#41054](https://github.com/ClickHouse/ClickHouse/pull/41054) ([Daniil Rubin](https://github.com/rubin-do))。
* スナップショットを手動で作成するための 4LW コマンド `csnp` を追加しました。さらに、特定のノードの Raft 情報 (例: 最後に作成されたスナップショットのインデックス、最後にコミットされたログインデックス) を取得するための `lgif` も追加しました。[#41766](https://github.com/ClickHouse/ClickHouse/pull/41766) ([JackyWoo](https://github.com/JackyWoo))。
* Replicated MergeTree への insert 中の Keeper リクエストの再試行をサポートしました。耐障害性の向上に加え、Keeper が再起動した場合 (たとえば upgrade 時) でも insert 中にユーザーへエラーを返さないようにし、より良いユーザー体験を提供することを目的としています。[#42607](https://github.com/ClickHouse/ClickHouse/pull/42607) ([Igor Nikonov](https://github.com/devcrafter))。
* Spark と同様の関数 ascii を追加しました: [https://spark.apache.org/docs/latest/api/sql/#ascii](https://spark.apache.org/docs/latest/api/sql/#ascii)。[#42670](https://github.com/ClickHouse/ClickHouse/pull/42670) ([李扬](https://github.com/taiyang-li))。
* 剰余に基づいて非負の結果を返す関数 pmod を追加しました。[#42755](https://github.com/ClickHouse/ClickHouse/pull/42755) ([李扬](https://github.com/taiyang-li))。
* 関数 `formatReadableDecimalSize` を公開しました。[#42774](https://github.com/ClickHouse/ClickHouse/pull/42774) ([Alejandro](https://github.com/alexon1234))。
* S3 PUT および GET の 1 秒あたりのリクエスト数に対するレートスロットリングを追加しました。設定 `s3_max_get_rps`、`s3_max_get_burst`、`s3_max_put_rps`、`s3_max_put_burst` を使用してトークンバケットスロットラーを設定します。S3 ObjectStorage と S3 table function の両方で使用できます。異なる制限を、異なる S3 disk や endpoint ごとに設定できます。[#43014](https://github.com/ClickHouse/ClickHouse/pull/43014) ([Sergei Trifonov](https://github.com/serxa))。
* テーブル関数 hudi および deltaLake を追加しました。[#43080](https://github.com/ClickHouse/ClickHouse/pull/43080) ([flynn](https://github.com/ucasfl))。
* Impala や Spark と同様の関数 factorial を追加しました。[#43110](https://github.com/ClickHouse/ClickHouse/pull/43110) ([李扬](https://github.com/taiyang-li))。
* Spark や Impala の rand 関数に似た関数 randCanonical を追加しました。この関数は、[0, 1) の範囲で独立同分布の一様乱数を生成します。[#43124](https://github.com/ClickHouse/ClickHouse/pull/43124) ([李扬](https://github.com/taiyang-li))。

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 現在、飽和可能な演算子は And と Or のみで、この変更の影響を受けるのはそれらのコードパスです。 [#42214](https://github.com/ClickHouse/ClickHouse/pull/42214) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* `match` 関数は、文字列のプレフィックスに対する条件であれば索引を利用できます。これにより [#37333](https://github.com/ClickHouse/ClickHouse/issues/37333) がクローズされます。 [#42458](https://github.com/ClickHouse/ClickHouse/pull/42458) ([clarkcaoliu](https://github.com/Clark0)).
* LowCardinality(String) のタプルにおける JSONExtract の遅さを修正しました。 [#42761](https://github.com/ClickHouse/ClickHouse/pull/42761) ([AlfVII](https://github.com/AlfVII)).
* LineAsString input format の並列パースをサポートしました。パフォーマンスはわずかに改善されます。これにより [#42502](https://github.com/ClickHouse/ClickHouse/issues/42502) がクローズされます。 [#42780](https://github.com/ClickHouse/ClickHouse/pull/42780) ([Kruglov Pavel](https://github.com/Avogar)).
* Keeper のパフォーマンス改善: 多数の異なるノードが未コミット状態を持つ場合の commit 性能を改善しました。これにより、follower ノードが十分な速度で同期できないケースの改善が期待されます。 [#42926](https://github.com/ClickHouse/ClickHouse/pull/42926) ([Antonio Andelic](https://github.com/antonio2368)).
* キーなしの aggregation、つまり `SELECT uniqExact(number) FROM table` のような queries に対して、`uniqExact` state のマージを並列化しました。一意キー数が 10^6 に近づくと、この改善は顕著になります。また、`uniq` のパフォーマンスもわずかに最適化されました。これにより [#4510](https://github.com/ClickHouse/ClickHouse/issues/4510) がクローズされます。 [#43072](https://github.com/ClickHouse/ClickHouse/pull/43072) ([Nikita Taranov](https://github.com/nickitat)).

<div id="improvement">
  #### 改善
</div>

* `Object` 型を他の型の中でサポート。例: `Array(JSON)`。 [#36969](https://github.com/ClickHouse/ClickHouse/pull/36969) ([Anton Popov](https://github.com/CurtizJ)).
* fetch したパーツについて、内包されるパーツを削除 (レプリケーション遅延が増大する可能性を避けるため) 。 [#39737](https://github.com/ClickHouse/ClickHouse/pull/39737) ([Azat Khuzhin](https://github.com/azat)).
* ClickHouse Client と ClickHouse Local は、非対話型モードでもデフォルトで進行状況を表示するようになりました。 `/dev/tty` が利用可能な場合、進行状況は stderr に書き込まれず、端末に直接描画されます。これにより、stderr がファイルにリダイレクトされていても進行状況を確認でき、ファイルが端末のエスケープシーケンスで汚染されることもありません。進行状況は `--progress false` で無効にできます。これにより [#32238](https://github.com/ClickHouse/ClickHouse/issues/32238) をクローズします。 [#42003](https://github.com/ClickHouse/ClickHouse/pull/42003) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 1. インターバルに対する加算、減算、符号反転の操作が利用可能になりました。インターバルの型が異なる場合は、それらの型の Tuple に変換されます。 2. インターバルのタプルは、Date/DateTime フィールドに加算したり、そこから減算したりできます。 3. 異なる型のインターバルのパースに対応しました。たとえば、`INTERVAL '1 HOUR 1 MINUTE 1 SECOND'` です。 [#42195](https://github.com/ClickHouse/ClickHouse/pull/42195) ([Nikolay Degterinsky](https://github.com/evillique)).
* * key condition atom map に `notLike` を追加し、`NOT LIKE 'prefix%'` のような条件でもプライマリインデックスを利用できるようにしました。[#42209](https://github.com/ClickHouse/ClickHouse/pull/42209) ([Duc Canh Le](https://github.com/canhld94)).
* base64 エンコード関数で `FixedString` 入力をサポートしました。[#42285](https://github.com/ClickHouse/ClickHouse/pull/42285) ([ltrk2](https://github.com/ltrk2)).
* `system.detached_parts` に `bytes_on_disk` と `path` カラムを追加しました。[#42264](https://github.com/ClickHouse/ClickHouse/issues/42264) をクローズしました。[#42303](https://github.com/ClickHouse/ClickHouse/pull/42303) ([chen](https://github.com/xiedeyantu)).
* テーブル関数で挿入先テーブルの構造を使用する仕組みを改善しました。設定 `use_structure_from_insertion_table_in_table_functions` で新たに値 `2` を指定できるようになり、挿入先テーブルの構造を使用できるかどうかを ClickHouse が自動的に判定しようとします。[#40028](https://github.com/ClickHouse/ClickHouse/issues/40028) をクローズしました。[#42320](https://github.com/ClickHouse/ClickHouse/pull/42320) ([Kruglov Pavel](https://github.com/Avogar)).
* filesystem および S3 で、再帰的な directory 走査向けに ** glob をサポートしました。[#36316](https://github.com/ClickHouse/ClickHouse/issues/36316) を解決しました。[#42376](https://github.com/ClickHouse/ClickHouse/pull/42376) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* `system.query_log` と `/var/log/clickhouse-server/*.log` の両方、および error メッセージ内で、password と secret keys をマスクするようにしました。[#42484](https://github.com/ClickHouse/ClickHouse/pull/42484) ([Vitaly Baranov](https://github.com/vitlibar)).
* query&#95;info に `limit` という新しい変数を追加し、このクエリが limit-trivial クエリかどうかを示すようにしました。該当する場合は、後続の推定のために概算の総行数を調整します。[#7071](https://github.com/ClickHouse/ClickHouse/issues/7071) をクローズしました。[#42580](https://github.com/ClickHouse/ClickHouse/pull/42580) ([Han Fei](https://github.com/hanfei1991)).
* `s3_plain` ディスク向けに `MergeTree` table の `ATTACH` を実装しました (`s3_plain` に関するいくつかの修正も含みます) 。[#42628](https://github.com/ClickHouse/ClickHouse/pull/42628) ([Azat Khuzhin](https://github.com/azat)).
* INSERT FROM INFILE で進捗が表示されない問題を修正しました。[#42548](https://github.com/ClickHouse/ClickHouse/issues/42548) をクローズしました。[#42634](https://github.com/ClickHouse/ClickHouse/pull/42634) ([chen](https://github.com/xiedeyantu)).
* パーティション全体に対してのみ古いパーツの merge を最適化するための設定 `min_age_to_force_merge_on_partition_only` を追加しました。[#42659](https://github.com/ClickHouse/ClickHouse/pull/42659) ([Antonio Andelic](https://github.com/antonio2368)).
* throttling アルゴリズムを token bucket 方式に変更しました。[#42665](https://github.com/ClickHouse/ClickHouse/pull/42665) ([Sergei Trifonov](https://github.com/serxa)).
* 関連関数で返される最大 tokens 数を有効にするため、FunctionTokens をリファクタリングしました (デフォルトでは無効) 。[#42673](https://github.com/ClickHouse/ClickHouse/pull/42673) ([李扬](https://github.com/taiyang-li)).
* readonly モードで table functions を使用できるようにするため、system.table&#95;functions に新しいフィールド allow&#95;readonly を追加しました。[#42414](https://github.com/ClickHouse/ClickHouse/issues/42414) を解決しました。実装: * テーブル system.table&#95;functions に新しいフィールド allow&#95;readonly を追加しました。 * readonly モードで table functions を使用できるよう、新しいフィールド allow&#95;readonly を使うよう更新しました。テスト: * filesystem 向けに tests/queries/0&#95;stateless/02473&#95;functions&#95;in&#95;readonly&#95;mode.sh のテストを追加しました。ドキュメント: * Table Functions の英語ドキュメントを更新しました。[#42708](https://github.com/ClickHouse/ClickHouse/pull/42708) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* formatDateTime および FROM&#95;UNIXTIME 関数で Date32 の argument を使用できるようにしました。[#42737](https://github.com/ClickHouse/ClickHouse/pull/42737) ([Roman Vasin](https://github.com/rvasin)).
* tzdata を 2022f に更新。メキシコでは、米国国境付近を除き、今後 DST は実施されなくなります: [https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html)。チワワ州は 2022-10-30 に通年 UTC-6 へ移行します。フィジーでも今後 DST は実施されません。詳細は [https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) および [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209) を参照してください。[#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 非同期 INSERT 向けに `FailedAsyncInsertQuery` イベントメトリクスを追加。[#42814](https://github.com/ClickHouse/ClickHouse/pull/42814) ([Krzysztof Góralski](https://github.com/kgoralski)).
* クエリプラン上で `read-in-order` 最適化を実装。これはデフォルトで有効です。従来の AST ベースのバージョンを使用するには、`query_plan_read_in_order = 0` を設定してください。[#42829](https://github.com/ClickHouse/ClickHouse/pull/42829) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* S3 へのバックアップで、アップロードする part のサイズを指数関数的に増加させるようにしました。[#42833](https://github.com/ClickHouse/ClickHouse/pull/42833) ([Vitaly Baranov](https://github.com/vitlibar)).
* merge task が継続的にビジーで、かつディスク容量が不足している場合、完全に期限切れになったパーツを選択して削除できず、結果としてディスク容量不足が解消されない問題を修正しました。Part 全体の有効期限 (TTL) が切れている場合は、TTL を正常に実行するために追加のディスク容量は不要です。[#42869](https://github.com/ClickHouse/ClickHouse/pull/42869) ([zhongyuankai](https://github.com/zhongyuankai)).
* bugfix: [#42856](https://github.com/ClickHouse/ClickHouse/issues/42856) Mysql binlog の SAVEPOINT イベントを無視するようにしました。[#42931](https://github.com/ClickHouse/ClickHouse/pull/42931) ([zzsmdfj](https://github.com/zzsmdfj)).
* INSERT VALUES クエリで対話型パラメータをサポート追加。[#43077](https://github.com/ClickHouse/ClickHouse/pull/43077) ([Nikolay Degterinsky](https://github.com/evillique)).
* 任意の構造を持つ named collections、access type、および system.named&#95;collections の汎用実装を追加。[#43147](https://github.com/ClickHouse/ClickHouse/pull/43147) ([Kseniia Sumarokova](https://github.com/kssenii)).
* oss function と StorageOSS を追加 (ユーザーにとって便利です) 。oss は S3 と完全互換です。[#43155](https://github.com/ClickHouse/ClickHouse/pull/43155) ([zzsmdfj](https://github.com/zzsmdfj)).
* `system.asynchronous_metrics` テーブル向けの OS 関連情報収集におけるエラーレポートを改善。[#43192](https://github.com/ClickHouse/ClickHouse/pull/43192) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `system.asynchronous_metrics` に埋め込みドキュメントを追加。このドキュメントは Prometheus にもエクスポートされます。`cache` ディスクに関するメトリクスの不具合も修正しました。これまでは、すべてのキャッシュディスクではなく、任意の 1 つのキャッシュディスクについてのみ計算されていました。これにより [#7644](https://github.com/ClickHouse/ClickHouse/issues/7644) を解決します。[#43194](https://github.com/ClickHouse/ClickHouse/pull/43194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `INFORMATION_SCHEMA` のテーブルを修正し、ClickHouse が MySQL compatibility protocol を使って自身に接続できるようにしました。別名の代わりにカラムを追加しました ([#9769](https://github.com/ClickHouse/ClickHouse/issues/9769) 関連) 。これにより、各種 MySQL clients との互換性が向上します。[#43198](https://github.com/ClickHouse/ClickHouse/pull/43198) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* `deltaLake` および `hudi` のテーブル関数をreadonlyモードで無効化しました。[#43316](https://github.com/ClickHouse/ClickHouse/pull/43316) ([Antonio Andelic](https://github.com/antonio2368)) 。

* `s3Cluster テーブル関数` の使用時に `skip_unavailable_shards` が機能しない問題を修正しました。[#43131](https://github.com/ClickHouse/ClickHouse/pull/43131) ([chen](https://github.com/xiedeyantu)).

* Jepsen を使った ClickHouse server のテスト対応を追加しました。なお、Jepsen を使った ClickHouse Keeper のテストにはすでに対応しています。このプルリクエストでは、その対応をレプリケートテーブルまで拡張しています。[#42619](https://github.com/ClickHouse/ClickHouse/pull/42619) ([Antonio Andelic](https://github.com/antonio2368)).
* * bugfix 検証 check を改善しました。check がスキップされる bug を修正し、CI に個別の status を追加し、check labels と スタイルチェックの後に実行されるようにしました。[#40349](https://github.com/ClickHouse/ClickHouse/issues/40349) をクローズしました。[#42702](https://github.com/ClickHouse/ClickHouse/pull/42702) ([Vladimir C](https://github.com/vdimir)).
* 結合テストでファイルをアーカイブする前に、すべてのファイルの同期が完了するまで待機するようにしました。[#42891](https://github.com/ClickHouse/ClickHouse/pull/42891) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* clang-tidy の結果のキャッシュに [https://github.com/matus-chochlik/ctcache](https://github.com/matus-chochlik/ctcache) を使用するようにしました。[#42913](https://github.com/ClickHouse/ClickHouse/pull/42913) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 修正前は、ユーザー定義の config は RPM により `$file.rpmsave` に保存されていました。この PR でこれを修正し、パッケージ内のファイルでユーザーのファイルを置き換えないようにしました。[#42936](https://github.com/ClickHouse/ClickHouse/pull/42936) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* コミットを release ready としてマークする CI step を追加しました。また、master 以外のブランチから release script を起動することを緩やかに禁止しました。[#43017](https://github.com/ClickHouse/ClickHouse/pull/43017) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
