<div id="clickhouse-release-v213542-lts-fixme-as-compared-to-v213425-lts">
  ### ClickHouse リリース v21.3.5.42-lts FIXME (v21.3.4.25-ltsとの比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#22335](https://github.com/ClickHouse/ClickHouse/issues/22335) にバックポート: table function `clusterAllReplicas` が誤った `_shard_num` を返す問題を修正。close [#21481](https://github.com/ClickHouse/ClickHouse/issues/21481)。[#21498](https://github.com/ClickHouse/ClickHouse/pull/21498) ([flynn](https://github.com/ucasfl))。
* [#22319](https://github.com/ClickHouse/ClickHouse/issues/22319) にバックポート: 外部データベースエンジン (MySQL、PostgreSQL) へのクエリで、WHERE 句内の joined table から不明なカラムを削除。close [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614)、close [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (dup)、close [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (dup)。[#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir))。
* [#22241](https://github.com/ClickHouse/ClickHouse/issues/22241) にバックポート: scalar subquery の索引解析を修正。これにより [#21717](https://github.com/ClickHouse/ClickHouse/issues/21717) を修正しました。この問題は [https://github.com/ClickHouse/ClickHouse/pull/18896](https://github.com/ClickHouse/ClickHouse/pull/18896) で導入されたものです。[#21766](https://github.com/ClickHouse/ClickHouse/pull/21766) ([Amos Bird](https://github.com/amosbird))。
* [#22150](https://github.com/ClickHouse/ClickHouse/issues/22150) にバックポート: WriteBufferFromS3 のエラー処理とログを改善。[#21836](https://github.com/ClickHouse/ClickHouse/pull/21836) ([Pavel Kovalenko](https://github.com/Jokser))。
* [#22468](https://github.com/ClickHouse/ClickHouse/issues/22468) にバックポート: まれに、`CollapsingMergeTree` の merge によって `index_granularity + 1` 行を含む granule が作成されることがあります。そのため、[#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) で追加された内部チェック (21.2 および 21.3 に影響) が、`Incomplete granules are not allowed while blocks are granules size` というエラーで失敗する場合がありました。このエラーにより、パーツを merge できませんでした。[#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#22203](https://github.com/ClickHouse/ClickHouse/issues/22203) にバックポート: Docker entrypoint: `LOG_PATH` が空の場合に `.` の `chown` を行わないように変更。Closes [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100)。[#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov))。
* [#22261](https://github.com/ClickHouse/ClickHouse/issues/22261) にバックポート: 不具合のある Linux カーネルでは `async_socket_for_remote`/`use_hedged_requests` を無効化。[#22109](https://github.com/ClickHouse/ClickHouse/pull/22109) ([Azat Khuzhin](https://github.com/azat))。
* [#22281](https://github.com/ClickHouse/ClickHouse/issues/22281) にバックポート: `ReplicatedMergeTree` table engines に対する `OPTIMIZE` および `ALTER` クエリの待機処理を修正。これにより、table がデタッチされた場合や再起動後でもクエリがハングしなくなりました。[#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin))。
* [#22265](https://github.com/ClickHouse/ClickHouse/issues/22265) にバックポート: background thread pool の名前を修正。[#22122](https://github.com/ClickHouse/ClickHouse/pull/22122) ([fastio](https://github.com/fastio))。
* [#22262](https://github.com/ClickHouse/ClickHouse/issues/22262) にバックポート: `JOIN` で `TOTALS` と `arrayJoin` を使用した際に発生するエラー `Invalid number of rows in Chunk` を修正しました。[#19303](https://github.com/ClickHouse/ClickHouse/issues/19303) をクローズします。[#22129](https://github.com/ClickHouse/ClickHouse/pull/22129) ([Vladimir C](https://github.com/vdimir)).
* [#22316](https://github.com/ClickHouse/ClickHouse/issues/22316) にバックポート: 設定に `http_port` がない場合の docker エントリポイントを修正しました。[#22132](https://github.com/ClickHouse/ClickHouse/pull/22132) ([Ewout](https://github.com/devwout)).
* [#22313](https://github.com/ClickHouse/ClickHouse/issues/22313) にバックポート: `use_hedged_requests=0` および `async_socket_for_remote=1` の場合のクエリキャンセルを修正しました。[#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* [#22366](https://github.com/ClickHouse/ClickHouse/issues/22366) にバックポート: これにより、すでに対象範囲に含まれている part を mutate しようとした際に、ClickHouse が `LOGICAL_ERROR` 例外を送出しなくなりました。[#22013](https://github.com/ClickHouse/ClickHouse/issues/22013) を修正します。[#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* [#22562](https://github.com/ClickHouse/ClickHouse/issues/22562) にバックポート: HTTP chunk サイズを制限しないようにしました。[#21907](https://github.com/ClickHouse/ClickHouse/issues/21907) を修正します。[#22322](https://github.com/ClickHouse/ClickHouse/pull/22322) ([Ivan](https://github.com/abyss7)).
* [#22531](https://github.com/ClickHouse/ClickHouse/issues/22531) にバックポート: `tokenbf_v1` の全文テキスト索引で、読み取り時に buffer overflow が発生する可能性がありました。余分なバイトは使用されませんが、まれに読み取り処理によって crash する可能性があります。これにより [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233) はクローズされます。[#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22463](https://github.com/ClickHouse/ClickHouse/issues/22463) にバックポート: 並列に実行されるパース routine に、不足していたメモリ使用量の計上を追加しました。以前のバージョンでは、resultset に非常に大きな data block が含まれる場合、OOM が発生する可能性がありました。これにより [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008) はクローズされます。[#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22507](https://github.com/ClickHouse/ClickHouse/issues/22507) にバックポート: 起こりうる race を防ぐため、HedgedConnections でパケット receiver のキャンセル前に epoll から socket を削除します。これで [#22161](https://github.com/ClickHouse/ClickHouse/issues/22161) が修正されることを期待しています。[#22443](https://github.com/ClickHouse/ClickHouse/pull/22443) ([Kruglov Pavel](https://github.com/Avogar)).
* [#22554](https://github.com/ClickHouse/ClickHouse/issues/22554) にバックポート: `LowCardinality` を使用した partial merge join のバグを修正しました。[#22386](https://github.com/ClickHouse/ClickHouse/issues/22386) をクローズし、[#22388](https://github.com/ClickHouse/ClickHouse/issues/22388) をクローズします。[#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* [#22607](https://github.com/ClickHouse/ClickHouse/issues/22607) にバックポート: TSV フォーマットの末尾に改行がない空文字列のデシリアライゼーションを修正しました。これにより [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244) はクローズされます。バージョンを更新しない場合の回避策として、`input_format_null_as_default` をゼロに設定できます。古いバージョンではゼロでした。[#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22576](https://github.com/ClickHouse/ClickHouse/issues/22576) にバックポート: TinyLog の rwlock を同一スレッドからロック解除するようにして、UB を修正しました。[#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* [#22651](https://github.com/ClickHouse/ClickHouse/issues/22651) にバックポート: 別スレッドからロック解除したことによって発生する rwlock の unlock に起因する、*Log エンジンでの UB を回避しました。[#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* [#22653](https://github.com/ClickHouse/ClickHouse/issues/22653) にバックポート: write buffer の flush は、初期化されている場合にのみ試行するようにしました。クライアントがごく早い段階で接続を閉じた場合に発生する segfault を修正しました [#22579](https://github.com/ClickHouse/ClickHouse/issues/22579)。[#22591](https://github.com/ClickHouse/ClickHouse/pull/22591) ([nvartolomei](https://github.com/nvartolomei)).
* [#22681](https://github.com/ClickHouse/ClickHouse/issues/22681) にバックポート: `SELECT` 句にカラムがない nested types を含む Log で発生する LOGICAL&#95;ERROR を修正しました。[#22654](https://github.com/ClickHouse/ClickHouse/pull/22654) ([Azat Khuzhin](https://github.com/azat)).
