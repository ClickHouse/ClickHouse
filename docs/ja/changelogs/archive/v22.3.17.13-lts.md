* [#45138](https://github.com/ClickHouse/ClickHouse/issues/45138) でバックポート: Arrow/Parquet/ORC フォーマットで、Binary の代わりに String type を使用できるようにしました。この PR では、これに対応するための新しい設定が 3 つ導入されています: `output_format_arrow_string_as_string`、`output_format_parquet_string_as_string`、`output_format_orc_string_as_string`。すべての設定のデフォルト値は `false` です。[#37327](https://github.com/ClickHouse/ClickHouse/pull/37327) ([Kruglov Pavel](https://github.com/Avogar)).
