<div id="clickhouse-release-v213425-lts-fixme-as-compared-to-v213314-lts">
  ### ClickHouseリリース v21.3.4.25-lts FIXME (v21.3.3.14-ltsとの比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#21928](https://github.com/ClickHouse/ClickHouse/issues/21928) にバックポート: Kafka 向けの Avro フォーマットのパースを修正。[#21437](https://github.com/ClickHouse/ClickHouse/issues/21437) を修正。[#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn))。
* [#22089](https://github.com/ClickHouse/ClickHouse/issues/22089) にバックポート: クエリに定数の `WHERE` 条件があり、設定 `optimize_skip_unused_shards` が有効になっている場合、すべての分片がスキップされ、クエリが誤って空の結果を返す可能性がありました。[#21550](https://github.com/ClickHouse/ClickHouse/pull/21550) ([Amos Bird](https://github.com/amosbird))。
* [#21793](https://github.com/ClickHouse/ClickHouse/issues/21793) にバックポート: S3 へのデータ書き込み時にエラーが発生すると `std::terminate` が呼び出されていました。[#21624](https://github.com/ClickHouse/ClickHouse/pull/21624) ([Vladimir C](https://github.com/vdimir))。
* [#21746](https://github.com/ClickHouse/ClickHouse/issues/21746) にバックポート: DDLWorker と Dictionaries の初期化が完了してから接続を受け付けるようにしました。[#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat))。
* [#21749](https://github.com/ClickHouse/ClickHouse/issues/21749) にバックポート: `ReplicatedMergeTree` で `OPTIMIZE` と `DROP` を同時実行した場合の問題を修正。[#21716](https://github.com/ClickHouse/ClickHouse/pull/21716) ([Azat Khuzhin](https://github.com/azat))。
* [#21878](https://github.com/ClickHouse/ClickHouse/issues/21878) にバックポート: 二段階集約の使用時に、Distinct コンビネータ付き集約関数で発生しうるクラッシュを修正。これは [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365) の追加修正です。本番環境でのみ再現します。現時点ではテストケースはありません。cc @CurtizJ。[#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird))。
* [#22051](https://github.com/ClickHouse/ClickHouse/issues/22051) にバックポート: catboost モデルの初回実行時に発生するデッドロックを修正。[#13832](https://github.com/ClickHouse/ClickHouse/issues/13832) をクローズ。[#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar))。
* [#21993](https://github.com/ClickHouse/ClickHouse/issues/21993) にバックポート: クエリにウィンドウ関数が含まれ、主キー順での読み取り最適化が適用された場合に `ORDER BY` の結果が誤る問題を修正。[#21828](https://github.com/ClickHouse/ClickHouse/issues/21828) を修正。[#21915](https://github.com/ClickHouse/ClickHouse/pull/21915) ([Alexander Kuzmenkov](https://github.com/akuzm))。
* [#22180](https://github.com/ClickHouse/ClickHouse/issues/22180) にバックポート: &quot;multipart/form-data&quot; コンテンツタイプの HTTP POST リクエストの読み取りを修正。[#21936](https://github.com/ClickHouse/ClickHouse/pull/21936) ([Ivan](https://github.com/abyss7))。
* [#21982](https://github.com/ClickHouse/ClickHouse/issues/21982) にバックポート: ヘッジド接続の重複を防止 (`Unknown packet 9 from server` エラー) 。[#21941](https://github.com/ClickHouse/ClickHouse/pull/21941) ([Azat Khuzhin](https://github.com/azat))。
* [#21980](https://github.com/ClickHouse/ClickHouse/issues/21980) にバックポート: ハッシュ型の external dictionaries の読み込み時にメモリ使用量が大幅に増加する可能性があった [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454) を差し戻しました。これにより [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935) をクローズします。[#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal))。
* [#22139](https://github.com/ClickHouse/ClickHouse/issues/22139) でバックポート: 関数 `decrypt` に、AEAD モードで暗号化されたデータの最小サイズを確認するチェックがありませんでした。この修正により [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897) をクローズしました。[#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22185](https://github.com/ClickHouse/ClickHouse/issues/22185) でバックポート: InterserverIOHTTPHandler の未捕捉例外を修正しました。[#22146](https://github.com/ClickHouse/ClickHouse/pull/22146) ([Azat Khuzhin](https://github.com/azat)).
* [#22205](https://github.com/ClickHouse/ClickHouse/issues/22205) でバックポート: ネストされた writer では next() ではなく finalize() を使用するようにしました。[#22147](https://github.com/ClickHouse/ClickHouse/pull/22147) ([Azat Khuzhin](https://github.com/azat)).
