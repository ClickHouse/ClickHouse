  # 2022年の変更履歴

<div id="clickhouse-release-v217858-stable-fixme-as-compared-to-v217747-stable">
  ### ClickHouse リリース v21.7.8.58-stable FIXME (v21.7.7.47-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#27506](https://github.com/ClickHouse/ClickHouse/issues/27506)でバックポート: `PREWHERE` で `LowCardinality` を使用する一部のクエリで、`Expected ColumnLowCardinality, gotUInt8` や `Bad cast from type DB::ColumnVector<char8_t> to DB::ColumnLowCardinality` のようなエラーが発生する問題を修正しました。[#23515](https://github.com/ClickHouse/ClickHouse/issues/23515) を修正。[#27298](https://github.com/ClickHouse/ClickHouse/pull/27298) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#27644](https://github.com/ClickHouse/ClickHouse/issues/27644)でバックポート: 行レベルセキュリティ、`PREWHERE`、および LowCardinality フィルターを含むクエリで誤った結果が返る問題を修正しました。[#27179](https://github.com/ClickHouse/ClickHouse/issues/27179) を修正。[#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#27474](https://github.com/ClickHouse/ClickHouse/issues/27474)でバックポート: Metric `BackgroundMessageBrokerSchedulePoolTask` を修正しました。おそらくタイプミスです。[#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* [#27649](https://github.com/ClickHouse/ClickHouse/issues/27649)でバックポート: 一部のパーツに欠落したカラムが含まれている場合に、projection materialization 中にクラッシュする問題を修正しました。これにより [#27512](https://github.com/ClickHouse/ClickHouse/issues/27512) を修正。[#27528](https://github.com/ClickHouse/ClickHouse/pull/27528) ([Amos Bird](https://github.com/amosbird)).
* [#27778](https://github.com/ClickHouse/ClickHouse/issues/27778)でバックポート: `Distributed` table のエイリアス付きカラムに関する不具合を修正しました。[#27652](https://github.com/ClickHouse/ClickHouse/pull/27652) ([Vladimir C](https://github.com/vdimir)).
* [#27674](https://github.com/ClickHouse/ClickHouse/issues/27674)でバックポート: PostgreSQL table function で接続が閉じられなくなる問題を修正しました。[#26088](https://github.com/ClickHouse/ClickHouse/issues/26088) をクローズ。[#27662](https://github.com/ClickHouse/ClickHouse/pull/27662) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#27697](https://github.com/ClickHouse/ClickHouse/issues/27697)でバックポート: `arrayHas` のような関数を、`DateTime` や `DateTime64` などの異なる非数値型の Nullable な LowCardinality の配列に適用した際に、不正な型変換が発生する問題を修正しました。以前のバージョンでは不正な cast が発生していましたが、新しいバージョンでは例外が発生します。これにより [#26330](https://github.com/ClickHouse/ClickHouse/issues/26330) をクローズ。[#27682](https://github.com/ClickHouse/ClickHouse/pull/27682) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#27748](https://github.com/ClickHouse/ClickHouse/issues/27748)でバックポート: arrow-cmake の CMakeLists.txt から重複したソースファイルを削除しました。[#27736](https://github.com/ClickHouse/ClickHouse/pull/27736) ([李扬](https://github.com/taiyang-li)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴対象外 / 軽微
</div>

* 結合テストで、停止していないコンテナーを強制終了する際の不具合を修正しました。 [#26818](https://github.com/ClickHouse/ClickHouse/pull/26818) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#24095](https://github.com/ClickHouse/ClickHouse/issues/24095) をリバートしました。ユーザーレベル設定がビューからのクエリにも影響するようになります。 [#27227](https://github.com/ClickHouse/ClickHouse/pull/27227) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
