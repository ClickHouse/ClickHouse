<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 重大なバグ修正 (crash, LOGICAL_ERROR, data loss, RBAC)
</div>

* [#66889](https://github.com/ClickHouse/ClickHouse/issues/66889)でバックポート: 関数呼び出し時に低カーディナリティのカラムのサイズが想定外になる問題を修正しました。[#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* [#66687](https://github.com/ClickHouse/ClickHouse/issues/66687)でバックポート: 再起動後にユーザー定義の VALID UNTIL 句がリセットされる問題を修正しました。[#66405](https://github.com/ClickHouse/ClickHouse/issues/66405) をクローズ。[#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#67497](https://github.com/ClickHouse/ClickHouse/issues/67497)でバックポート: connection が空の場合に DistributedAsyncInsert でクラッシュする問題を修正しました。[#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#66324](https://github.com/ClickHouse/ClickHouse/issues/66324)でバックポート: `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` は結果のスキーマに影響する可能性があるため、スキーマ推論 cache にこれらの不足していた設定を追加しました。これにより、これらの設定が変更された場合にスキーマ推論結果が不正になることを防ぎます。[#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* [#66151](https://github.com/ClickHouse/ClickHouse/issues/66151)でバックポート: `unbin`/`unhex` の実装におけるバッファオーバーフローのバグを修正しました。[#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* [#66451](https://github.com/ClickHouse/ClickHouse/issues/66451)でバックポート: ZooKeeper client のバグを修正しました。ZooKeeper からハードウェアエラーを受信したあと、session が使用不能な状態のままになることがありました。たとえば、ClickHouse Keeper の &quot;ソフトメモリ制限&quot; が原因で発生する可能性があります。[#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#66222](https://github.com/ClickHouse/ClickHouse/issues/66222)でバックポート: SumIfToCountIfVisitor と符号付き整数に関する問題を修正しました。[#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* [#66676](https://github.com/ClickHouse/ClickHouse/issues/66676)でバックポート: 利用可能な索引がない場合の `system.numbers_mt` における limit の処理を修正しました。[#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#66602](https://github.com/ClickHouse/ClickHouse/issues/66602)でバックポート: ClickHouse server が Docker などのコンテナー内で実行されている場合に、cgroups v2 で指定された使用可能な CPU コアの最大数を正しく検出できるよう修正しました。詳しく言うと、コンテナーではプロセスが名前のないルート cgroup で実行されることがよくあります。その場合、ClickHouse は cgroups v2 で設定された CPU 制限を無視していました。[#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
* [#66356](https://github.com/ClickHouse/ClickHouse/issues/66356)でバックポート: 制約内で `IN` を含むサブクエリを使用した場合の `Not-ready set` error を修正しました。[#66261](https://github.com/ClickHouse/ClickHouse/pull/66261) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66970](https://github.com/ClickHouse/ClickHouse/issues/66970)でバックポート: `group_by_use_nulls=true` と新しいアナライザの組み合わせで発生する `Column identifier is already registered` error を修正しました。[#66400](https://github.com/ClickHouse/ClickHouse/pull/66400) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66967](https://github.com/ClickHouse/ClickHouse/issues/66967)でバックポート: `GROUP BY` キーに定数式を含むクエリで、新しいアナライザが有効な場合に発生する `Cannot find column` error を修正しました。[#66433](https://github.com/ClickHouse/ClickHouse/pull/66433) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66718](https://github.com/ClickHouse/ClickHouse/issues/66718)でバックポート: `Allocator::realloc` のメモリ使用量が正しく追跡されるよう修正しました。[#66548](https://github.com/ClickHouse/ClickHouse/pull/66548) ([Antonio Andelic](https://github.com/antonio2368)).
* [#66949](https://github.com/ClickHouse/ClickHouse/issues/66949)でバックポート: `WINDOW` を含むクエリで不正な結果になる問題を修正しました。これは、`PARTITION` カラムがスパースなシリアライゼーションを持ち、window functions が並列に実行される場合に発生する可能性がありました。[#66579](https://github.com/ClickHouse/ClickHouse/pull/66579) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66946](https://github.com/ClickHouse/ClickHouse/issues/66946)でバックポート: スカラーサブクエリを IN の最初の引数として使用した際に発生する `Method getResultType is not supported for QUERY query node` エラーを修正しました (新しいアナライザ使用時) 。 [#66655](https://github.com/ClickHouse/ClickHouse/pull/66655) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#67629](https://github.com/ClickHouse/ClickHouse/issues/67629)でバックポート: Context::getDDLWorker で断続的に発生するデッドロックを修正しました。 [#66843](https://github.com/ClickHouse/ClickHouse/pull/66843) ([Alexander Gololobov](https://github.com/davenger)).
* [#67193](https://github.com/ClickHouse/ClickHouse/issues/67193)でバックポート: TRUNCATE DATABASE で、以前は DROP DATABASE クエリであるかのようにレプリケーションが停止していた問題を修正しました。 [#67129](https://github.com/ClickHouse/ClickHouse/pull/67129) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#67375](https://github.com/ClickHouse/ClickHouse/issues/67375)でバックポート: 1 つの分片を持つ `Distriburted` テーブル上の `Merge` テーブルを読み取るクエリで発生する `Cannot convert column because it is non constant in source stream but must be constant in result.` エラーを修正しました。 [#67146](https://github.com/ClickHouse/ClickHouse/pull/67146) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#67572](https://github.com/ClickHouse/ClickHouse/issues/67572)でバックポート: ネストした短絡評価関数の実行を修正しました。 [#67520](https://github.com/ClickHouse/ClickHouse/pull/67520) ([Kruglov Pavel](https://github.com/Avogar)).
