<div id="improvement">
  #### 改善
</div>

* [#62188](https://github.com/ClickHouse/ClickHouse/issues/62188) でバックポート: strictness `ANY` の StorageJoin は、再読み込み後も挙動が一貫するようになりました。同じキーを持つ複数の行が挿入された場合、最初の行が優先されます (以前は、テーブルの読み込み時にランダムに選択されていました) 。[#51027](https://github.com/ClickHouse/ClickHouse/issues/51027) をクローズ。 [#61972](https://github.com/ClickHouse/ClickHouse/pull/61972) ([vdimir](https://github.com/vdimir)).
* [#62443](https://github.com/ClickHouse/ClickHouse/issues/62443) でバックポート: Client はヘッダー &#39;Keep-Alive: timeout=X&#39; を server に送信する必要があります。Client がそのヘッダーを含むレスポンスを server から受信した場合は、server 側の値を使用する必要があります。また、接続クローズの競合を避けるため、Client では期限切れ間近の connection を使用しないほうが適切です。 [#62249](https://github.com/ClickHouse/ClickHouse/pull/62249) ([Sema Checherinda](https://github.com/CheSema)).
* [#62666](https://github.com/ClickHouse/ClickHouse/issues/62666) でバックポート: S3 storage とバックアップにも、S3 disk と同じデフォルトの Keep-Alive 設定が必要です。 [#62648](https://github.com/ClickHouse/ClickHouse/pull/62648) ([Sema Checherinda](https://github.com/CheSema)).
