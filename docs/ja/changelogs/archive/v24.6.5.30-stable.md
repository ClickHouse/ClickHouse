<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#68969](https://github.com/ClickHouse/ClickHouse/issues/68969) でバックポート: 関数 `fromModifiedJulianDay` の上限値を修正しました。本来は `9999-12-31` であるべきところ、誤って `9999-01-01` に設定されていました。[#67583](https://github.com/ClickHouse/ClickHouse/pull/67583) ([PHO](https://github.com/depressed-pho)).
* [#68814](https://github.com/ClickHouse/ClickHouse/issues/68814) でバックポート: ファイル内のデータ型が要求された型と大きく異なる場合に、Parquet の Filtering で発生する crash を修正しました (例: `... FROM file('a.parquet', Parquet, 'x String')` だが、ファイル内では `x Int64`) 。この修正がない場合の回避策として、`input_format_parquet_filter_push_down = 0` を使用してください。[#68131](https://github.com/ClickHouse/ClickHouse/pull/68131) ([Michael Kolupaev](https://github.com/al13n321)).
* [#69005](https://github.com/ClickHouse/ClickHouse/issues/69005) でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/61984](https://github.com/ClickHouse/ClickHouse/pull/61984) 以降も、`schema_inference_make_columns_nullable=0` によって Parquet/Arrow フォーマットでカラムが `Nullable` になることがありました。この変更は後方互換性がなく、ユーザーは動作の変化に気づいていました。この PR では、`schema_inference_make_columns_nullable=0` が以前どおり動作するようにし (Nullable カラムは推論されません) 、さらにこの設定に新しい値 `auto` を導入しました。これにより、データに nullability の情報がある場合にのみカラムが `Nullable` になります。[#68298](https://github.com/ClickHouse/ClickHouse/pull/68298) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68883](https://github.com/ClickHouse/ClickHouse/issues/68883) でバックポート: [#50868](https://github.com/ClickHouse/ClickHouse/issues/50868) を修正しました。distributed query 内のネストされたサブクエリが返す小さな DateTime64 の定数値が誤って NULL に変換され、その結果、エラーや誤ったクエリ結果を引き起こす可能性がありました。[#68323](https://github.com/ClickHouse/ClickHouse/pull/68323) ([Shankar](https://github.com/shiyer7474)).
* [#69025](https://github.com/ClickHouse/ClickHouse/issues/69025) でバックポート: 仮想カラム ` _table` および `_database` を分散テーブルに再度追加しました。これらはバージョン 24.3 までは利用可能でした。[#68672](https://github.com/ClickHouse/ClickHouse/pull/68672) ([Anton Popov](https://github.com/CurtizJ)).
* [#68860](https://github.com/ClickHouse/ClickHouse/issues/68860) でバックポート: Variant カラムの permutation 中に発生する可能性があるエラー `Size of permutation (0) is less than required (...)` を修正しました。[#68681](https://github.com/ClickHouse/ClickHouse/pull/68681) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68786](https://github.com/ClickHouse/ClickHouse/issues/68786) でバックポート: 関数 `sipHash(64/128)Keyed` で、Array を key とする maps を hash 化する際に、materialized 定数 key に関する issue を修正しました。[#68731](https://github.com/ClickHouse/ClickHouse/pull/68731) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* [#69156](https://github.com/ClickHouse/ClickHouse/issues/69156) でバックポート: anyHeavy state の merge 中に誤った result となる可能性がある問題を修正しました。[#68950](https://github.com/ClickHouse/ClickHouse/pull/68950) ([Raúl Marín](https://github.com/Algunenano)).
* [#69116](https://github.com/ClickHouse/ClickHouse/issues/69116) でバックポート: 空の非同期 INSERT がある場合に発生する論理エラーを修正しました。[#69080](https://github.com/ClickHouse/ClickHouse/pull/69080) ([Han Fei](https://github.com/hanfei1991)).
