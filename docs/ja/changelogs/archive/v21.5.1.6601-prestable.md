<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 整数が浮動小数点データ型で正確に表現できない場合の、整数と浮動小数点数の比較方法を変更しました。新しいバージョンでは、丸め誤差が発生するため、比較結果は false になります。例: `9223372036854775808.0 != 9223372036854775808`。これは、`9223372036854775808` という数値が浮動小数点数として正確に表現できないためです (また、`9223372036854775808.0` は `9223372036854776000.0` に丸められます) 。しかし以前のバージョンでは、これらの数値は等しいものとして比較されていました。これは、浮動小数点数 `9223372036854776000.0` を UInt64 に変換し直すと `9223372036854775808` になるためです。参考までに、Python でもこれらの数値は等しいものとして扱われます。ただし、この挙動は CPU モデルに依存していました (一部の範囲外の数値では AMD64 と AArch64 で結果が異なっていました) 。そのため、比較をより正確にしました。今後は、整数が浮動小数点型で正確に表現される場合にのみ、整数と浮動小数点数を等しいものとして扱います。 [#22595](https://github.com/ClickHouse/ClickHouse/pull/22595) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新機能
</div>

* 配列 (または並列な複数配列の組) の各要素に式を適用し、その結果をアキュムレーターに集約する関数 `arrayFold(x1,...,xn,accum -> expression, array1,...,arrayn, init_accum)` を実装しました。 [#21589](https://github.com/ClickHouse/ClickHouse/pull/21589) ([Dmitry Krylov](https://github.com/dmalkr)).
* * Apple m1 をサポートしました。 [#21639](https://github.com/ClickHouse/ClickHouse/pull/21639) ([changvvb](https://github.com/changvvb)).
* `Distributed` テーブルに対する再帰的なクエリの深さを制限する設定 `max_distributed_depth` を追加しました。 [#20229](https://github.com/ClickHouse/ClickHouse/issues/20229) をクローズしました。 [#21942](https://github.com/ClickHouse/ClickHouse/pull/21942) ([flynn](https://github.com/ucasfl)).
* 指定したクラスター内の多数のノードから `s3` 上のファイルを並列に処理できるテーブル関数。 [#22012](https://github.com/ClickHouse/ClickHouse/pull/22012) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* MySQL/PostgreSQL table engine / テーブル関数 でレプリカをサポートしました。分片を可能にするため、MySQL / PostgreSQL storage の上に wrapper storage を追加しました。 [#20969](https://github.com/ClickHouse/ClickHouse/issues/20969) をクローズしました。 [#22217](https://github.com/ClickHouse/ClickHouse/pull/22217) ([Kseniia Sumarokova](https://github.com/kssenii)).
* config のリロード時に、catboost model configs へのパスを更新しました。 [#22434](https://github.com/ClickHouse/ClickHouse/pull/22434) ([Kruglov Pavel](https://github.com/Avogar)).
* 非レプリケート MergeTree の insert の重複排除向けに、新しい設定 `non_replicated_deduplication_window` を追加しました。 [#22514](https://github.com/ClickHouse/ClickHouse/pull/22514) ([alesapin](https://github.com/alesapin)).
* FlatDictionary に `initial_array_size`、`max_array_size` オプションを追加しました。 [#22521](https://github.com/ClickHouse/ClickHouse/pull/22521) ([Maksim Kita](https://github.com/kitaisreal)).
* `ALTER TABLE ... FETCH PART ...` クエリを追加しました。これは `FETCH PARTITION` に似ていますが、1 つのパートだけを fetch します。 [#22706](https://github.com/ClickHouse/ClickHouse/pull/22706) ([jasong](https://github.com/songenjie)).
* Dictionary に `Decimal256` 型のサポートを追加しました。 [#20979](https://github.com/ClickHouse/ClickHouse/issues/20979) をクローズしました。 [#22960](https://github.com/ClickHouse/ClickHouse/pull/22960) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* パフォーマンス向上が見込めるよう、関数アラインメントを追加しました。 [#21431](https://github.com/ClickHouse/ClickHouse/pull/21431) ([Daniel Kutenin](https://github.com/danlark1)).

* ローカルファイル以外のソース (例: URL) から `ArrowStream` 入力フォーマットを読み込む際のパフォーマンスを改善しました。 [#22673](https://github.com/ClickHouse/ClickHouse/pull/22673) ([nvartolomei](https://github.com/nvartolomei)).
* AVX2 向けに、dynamic dispatch による `intDiv` のパフォーマンスを改善しました。これにより [#22314](https://github.com/ClickHouse/ClickHouse/issues/22314) をクローズします。 [#23000](https://github.com/ClickHouse/ClickHouse/pull/23000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
