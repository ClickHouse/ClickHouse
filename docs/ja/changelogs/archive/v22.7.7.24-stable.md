<div id="clickhouse-release-v227724-stable-02ad1f979a8-fixme-as-compared-to-v227674-stable-c00ffb3c11a">
  ### ClickHouse リリース v22.7.7.24-stable (02ad1f979a8) FIXME (v22.7.6.74-stable (c00ffb3c11a) との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#42433](https://github.com/ClickHouse/ClickHouse/issues/42433)でバックポート: - BigInt を使用する LowCardinality に対して、正しい集約方式を選択。 [#42342](https://github.com/ClickHouse/ClickHouse/pull/42342) ([Duc Canh Le](https://github.com/canhld94)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#42329](https://github.com/ClickHouse/ClickHouse/issues/42329)でバックポート: cctz を最新の master に更新し、tzdb を 2020e に更新。 [#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano)).
* [#42359](https://github.com/ClickHouse/ClickHouse/issues/42359)でバックポート: 新しい timezone の変更に対応するため、tzdata を 2022e に更新。パレスチナの切り替えは土曜日 02:00 になりました。ウクライナの 3 つの zones は 1 つに統合されました。ヨルダンとシリアは、DST を伴う +02/+03 から通年 +03 に切り替わりました。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS)). これにより [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252) はクローズされます。 [#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#42268](https://github.com/ClickHouse/ClickHouse/issues/42268) でバックポート: base backup から 4GB を超えるファイルを再利用する際の不具合を修正しました。[#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat)).
* [#42299](https://github.com/ClickHouse/ClickHouse/issues/42299) でバックポート: projections と `aggregate_functions_null_for_empty` 設定に関するバグを修正しました。このバグは非常にまれで、server の config で `aggregate_functions_null_for_empty` 設定を有効にした場合にのみ発生します。これにより [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647) をクローズします。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#42386](https://github.com/ClickHouse/ClickHouse/issues/42386) でバックポート: attached part (table schema と異なるカラムを持つもの) に対する `ALTER UPDATE` により、ディスク上に無効な `columns.txt` メタデータが作成される可能性がありました。このような part からの読み取りは、エラーで失敗したり無効なデータを返したりする可能性がありました。[#42161](https://github.com/ClickHouse/ClickHouse/issues/42161) を修正しました。[#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#42498](https://github.com/ClickHouse/ClickHouse/issues/42498) でバックポート: `additional_table_filters` 設定が `Distributed` storage に適用されていませんでした。[#41692](https://github.com/ClickHouse/ClickHouse/issues/41692) を修正しました。[#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#42593](https://github.com/ClickHouse/ClickHouse/issues/42593) でバックポート: これにより [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453) をクローズします。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
