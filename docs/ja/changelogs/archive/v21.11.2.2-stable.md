<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#31154](https://github.com/ClickHouse/ClickHouse/issues/31154) でバックポート: ATTACH PARTITION ... FROM および MOVE PARTITION ... の場合は、max&#95;partition&#95;size&#95;to&#95;drop のチェックをスキップします。 [#30995](https://github.com/ClickHouse/ClickHouse/pull/30995) ([Amr Alaa](https://github.com/amralaa-MSFT)).
* [#31027](https://github.com/ClickHouse/ClickHouse/issues/31027) でバックポート: `formatRow` 関数を行フォーマット以外で使用すると segfault が発生していました。そのため、このようなフォーマットではこの関数を使用できないようにしました (意味がないためです) 。 [#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31026](https://github.com/ClickHouse/ClickHouse/issues/31026) でバックポート: 引用符付き Identifier を使用する JSONValue/Query を修正しました。これにより、JSON path にスペースを含められるようになります。 [#30971](https://github.com/ClickHouse/ClickHouse/issues/30971) をクローズしました。 [#31003](https://github.com/ClickHouse/ClickHouse/pull/31003) ([Kseniia Sumarokova](https://github.com/kssenii)).
