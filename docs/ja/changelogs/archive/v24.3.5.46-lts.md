  ### ClickHouse リリース v24.3.5.46-lts (fe54cead6b6) FIXME v24.3.4.147-lts (31a7bdc346d) との比較

<div id="improvement">
  #### 改善
</div>

* [#65463](https://github.com/ClickHouse/ClickHouse/issues/65463) にバックポート: 証明書のリロード時に証明書チェーンも再読み込みするようにしました。[#61671](https://github.com/ClickHouse/ClickHouse/pull/61671) ([Pervakov Grigorii](https://github.com/GrigoryPervakov))。
* [#65882](https://github.com/ClickHouse/ClickHouse/issues/65882) にバックポート: グローバルスレッドプール内のスレッド数を十分に確保した状態で、常に Keeper を起動するようにしました。[#64444](https://github.com/ClickHouse/ClickHouse/pull/64444) ([Duc Canh Le](https://github.com/canhld94))。
* [#65302](https://github.com/ClickHouse/ClickHouse/issues/65302) にバックポート: ClickHouse における CSV format での Tuple の扱いと解釈の挙動を元に戻しました。この変更は実質的に [https://github.com/ClickHouse/ClickHouse/pull/60994](https://github.com/ClickHouse/ClickHouse/pull/60994) を差し戻すもので、`output_format_csv_serialize_tuple_into_separate_columns`、`input_format_csv_deserialize_separate_columns_into_tuple`、`input_format_csv_try_infer_strings_from_quoted_tuples` のいくつかの設定でのみ有効になります。[#65170](https://github.com/ClickHouse/ClickHouse/pull/65170) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#65892](https://github.com/ClickHouse/ClickHouse/issues/65892) にバックポート: Keeper で cgroup の CPU 制限を考慮するようにしました。[#65819](https://github.com/ClickHouse/ClickHouse/pull/65819) ([Antonio Andelic](https://github.com/antonio2368))。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 重大なバグ修正 (クラッシュ、LOGICAL_ERROR、データ損失、RBAC)
</div>

* [#65283](https://github.com/ClickHouse/ClickHouse/issues/65283) にバックポート: UniqInjectiveFunctionsEliminationPass と uniqCombined で発生するクラッシュを修正しました。[#65188](https://github.com/ClickHouse/ClickHouse/pull/65188) ([Raúl Marín](https://github.com/Algunenano)).
* [#65370](https://github.com/ClickHouse/ClickHouse/issues/65370) にバックポート: セッションのクローズ時にダイジェスト不一致を引き起こす ClickHouse Keeper のバグを修正しました。[#65198](https://github.com/ClickHouse/ClickHouse/pull/65198) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#65446](https://github.com/ClickHouse/ClickHouse/issues/65446) にバックポート: Distinct combinator で正しいメモリアラインメントを使用するようにしました。これまでは、この combinator を使用すると不正なメモリ割り当てによりクラッシュが発生する可能性がありました。[#65379](https://github.com/ClickHouse/ClickHouse/pull/65379) ([Antonio Andelic](https://github.com/antonio2368)).
* [#65708](https://github.com/ClickHouse/ClickHouse/issues/65708) にバックポート: maxIntersections で発生するクラッシュを修正しました。[#65689](https://github.com/ClickHouse/ClickHouse/pull/65689) ([Raúl Marín](https://github.com/Algunenano)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#65352](https://github.com/ClickHouse/ClickHouse/issues/65352) でバックポート: StatusFile 内の ~WriteBufferFromFileDescriptor における uncaught exception により abort が発生する可能性がある問題を修正しました。 [#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)).
* [#65327](https://github.com/ClickHouse/ClickHouse/issues/65327) でバックポート: まだ復元されていない definer を持つ MV の作成によってバックアップからの復元がブロックされた際に、クラッシュループが発生する問題を修正しました。 [#64595](https://github.com/ClickHouse/ClickHouse/pull/64595) ([pufit](https://github.com/pufit)).
* [#65538](https://github.com/ClickHouse/ClickHouse/issues/65538) でバックポート: `ALTER TABLE ... ON CLUSTER ... MODIFY SQL SECURITY` 実行時にクラッシュする問題を修正しました。 [#64957](https://github.com/ClickHouse/ClickHouse/pull/64957) ([pufit](https://github.com/pufit)).
* [#65576](https://github.com/ClickHouse/ClickHouse/issues/65576) でバックポート: AccessControl の破棄時にクラッシュする問題を修正し、明示的なシャットダウンを追加しました。 [#64993](https://github.com/ClickHouse/ClickHouse/pull/64993) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#65159](https://github.com/ClickHouse/ClickHouse/issues/65159) でバックポート: aggregation の外側へ算術演算を押し出す処理を修正しました。新しいアナライザでは、この最適化は一度しか適用されていませんでした。 [#65104](https://github.com/ClickHouse/ClickHouse/pull/65104) ([Dmitry Novik](https://github.com/novikd)).
* [#65615](https://github.com/ClickHouse/ClickHouse/issues/65615) でバックポート: 新しいアナライザで aggregate function 名を書き換える処理を修正しました。 [#65110](https://github.com/ClickHouse/ClickHouse/pull/65110) ([Dmitry Novik](https://github.com/novikd)).
* [#65728](https://github.com/ClickHouse/ClickHouse/issues/65728) でバックポート: 関数 `uniq*` の argument 内の injective function を再帰的に除去する処理を修正しました。これは以前は正しく動作していましたが、新しいアナライザで壊れていました。 [#65140](https://github.com/ClickHouse/ClickHouse/pull/65140) ([Duc Canh Le](https://github.com/canhld94)).
* [#65261](https://github.com/ClickHouse/ClickHouse/issues/65261) でバックポート: Hashed および Hashed&#95;Array Dictionary のショートサーキット評価におけるバグを修正しました。この問題により未初期化の数値を読み取り、さまざまな error につながる可能性がありました。 [#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)).
* [#65667](https://github.com/ClickHouse/ClickHouse/issues/65667) でバックポート: `read-in-order` 最適化が有効な場合、`FINAL` を含むクエリでは `non-intersecting-parts` 最適化を無効化しました。これにより誤った query result につながる可能性がありました。回避策として、この修正がマージされるまでは `do_not_merge_across_partitions_select_final` と `split_parts_ranges_into_intersecting_and_non_intersecting_final` を無効にしてください。 [#65505](https://github.com/ClickHouse/ClickHouse/pull/65505) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#65784](https://github.com/ClickHouse/ClickHouse/issues/65784) でバックポート: MergeJoin のバグを修正しました。スパース serialisation のカラムが、必要な変換が行われていないにもかかわらず、その Nested 型のカラムとして扱われる可能性がありました。 [#65632](https://github.com/ClickHouse/ClickHouse/pull/65632) ([Nikita Taranov](https://github.com/nickitat)).
* [#65929](https://github.com/ClickHouse/ClickHouse/issues/65929) でバックポート: `PostgreSQL` から読み取るクエリでは、ClickHouse query が終了した場合に内部の `PostgreSQL` クエリをキャンセルするようにしました。そうしないと、内部の `PostgreSQL` クエリが終了するまで `ClickHouse` クエリをキャンセルできません。 [#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)).
* [#65824](https://github.com/ClickHouse/ClickHouse/issues/65824) にバックポート: 旧アナライザ使用時に `dictGetOrDefault` で短絡評価のロジックに不具合があった問題を修正しました。[#65802](https://github.com/ClickHouse/ClickHouse/pull/65802) ([jsc0218](https://github.com/jsc0218)).
