<div id="bug-fix">
  #### バグ修正
</div>

* [#20678](https://github.com/ClickHouse/ClickHouse/issues/20678) にバックポート: いずれかのファイルに空のデータブロックがある場合、distributed バッチを破損としてマークするように修正しました。[#19449](https://github.com/ClickHouse/ClickHouse/pull/19449) ([Azat Khuzhin](https://github.com/azat)).
* [#20646](https://github.com/ClickHouse/ClickHouse/issues/20646) にバックポート: 関数 `greatCircleAngle` が以前のバージョンで不正確な結果を返していた問題を修正しました。これにより [#19769](https://github.com/ClickHouse/ClickHouse/issues/19769) を解決します。[#19789](https://github.com/ClickHouse/ClickHouse/pull/19789) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#20507](https://github.com/ClickHouse/ClickHouse/issues/20507) にバックポート: 壊れた JSON の場合にファイル全体をメモリへ読み込もうとして、アロケータから例外が発生していた問題を修正しました。[#19719](https://github.com/ClickHouse/ClickHouse/issues/19719) を修正します。[#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#20618](https://github.com/ClickHouse/ClickHouse/issues/20618) にバックポート: テーブル関数 `view` が式リストで使用されているかをチェックし、エラーをスローするようにしました。これにより [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342) を修正します。[#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)).
* [#20488](https://github.com/ClickHouse/ClickHouse/issues/20488) にバックポート: JOIN に SELECT の const が含まれる場合の `join_use_nulls=1` における `LOGICAL_ERROR` を修正しました。[#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)).
* [#20886](https://github.com/ClickHouse/ClickHouse/issues/20886) にバックポート: `union distinct` と `limit` 句を含むサブクエリの問題を修正しました。[#20597](https://github.com/ClickHouse/ClickHouse/issues/20597) をクローズします。[#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)).
* [#20992](https://github.com/ClickHouse/ClickHouse/issues/20992) にバックポート: 集約関数で `-State` コンビネータと `-Distinct` コンビネータを組み合わせて使用した場合の問題を修正しました。[#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* [#20988](https://github.com/ClickHouse/ClickHouse/issues/20988) にバックポート: MySQL 5.7 クライアントを使用して ClickHouse server に接続した際、`USE database;` クエリが動作しなかった問題を修正しました。[#18926](https://github.com/ClickHouse/ClickHouse/issues/18926) を修正します。[#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)).
