<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正（正式な安定版リリースにおけるユーザーが確認できる不具合）
</div>

* [#37716](https://github.com/ClickHouse/ClickHouse/issues/37716)でバックポート: aggregate function、prewhere、join で定数文字列が衝突した際に発生する予期しないエラーを修正しました。[#36891](https://github.com/ClickHouse/ClickHouse/issues/36891) をクローズします。[#37336](https://github.com/ClickHouse/ClickHouse/pull/37336) ([Vladimir C](https://github.com/vdimir)).
* [#37408](https://github.com/ClickHouse/ClickHouse/issues/37408)でバックポート: GROUPING SETS を ROLLUP または CUBE と併用した場合に例外をスローするようにしました。[#37367](https://github.com/ClickHouse/ClickHouse/pull/37367) ([Dmitry Novik](https://github.com/novikd)).
* [#37513](https://github.com/ClickHouse/ClickHouse/issues/37513)でバックポート: normalizeUTF8 関数の論理エラーを修正しました。[#37298](https://github.com/ClickHouse/ClickHouse/issues/37298) をクローズします。[#37443](https://github.com/ClickHouse/ClickHouse/pull/37443) ([Maksim Kita](https://github.com/kitaisreal)).
* [#37942](https://github.com/ClickHouse/ClickHouse/issues/37942)でバックポート: 内部 cast 関数における setting cast&#95;ipv4&#95;ipv6&#95;default&#95;on&#95;conversion&#95;error を修正しました。[#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) をクローズします。[#37761](https://github.com/ClickHouse/ClickHouse/pull/37761) ([Maksim Kita](https://github.com/kitaisreal)).
* [#38451](https://github.com/ClickHouse/ClickHouse/issues/38451)でバックポート: 条件が false の場合でも引数が実行されてしまう、ネストした short-circuit 関数のバグを修正しました。[#38040](https://github.com/ClickHouse/ClickHouse/issues/38040) をクローズします。[#38173](https://github.com/ClickHouse/ClickHouse/pull/38173) ([Kruglov Pavel](https://github.com/Avogar)).
* [#38544](https://github.com/ClickHouse/ClickHouse/issues/38544)でバックポート: ログ出力中に OvercommitTracker を再帰的に使用できないようにしました。[#37794](https://github.com/ClickHouse/ClickHouse/issues/37794) を修正します cc @tavplubix @davenger. [#38246](https://github.com/ClickHouse/ClickHouse/pull/38246) ([Dmitry Novik](https://github.com/novikd)).
* [#38708](https://github.com/ClickHouse/ClickHouse/issues/38708)でバックポート: `DISTINCT` と `LIMIT` を含む distributed queries で誤った結果が返る問題を修正しました。[#38282](https://github.com/ClickHouse/ClickHouse/issues/38282) を修正します。[#38371](https://github.com/ClickHouse/ClickHouse/pull/38371) ([Anton Popov](https://github.com/CurtizJ)).
* [#38595](https://github.com/ClickHouse/ClickHouse/issues/38595)でバックポート: サーバーの異常終了後にパーツが削除されない問題を修正しました (サーバー終了時に削除されていないと、そのまま永続的に残っていました) 。[#38486](https://github.com/ClickHouse/ClickHouse/pull/38486) ([Azat Khuzhin](https://github.com/azat)).
* [#38598](https://github.com/ClickHouse/ClickHouse/issues/38598)でバックポート: pre-22.4 レプリカとのレプリケーション問題を回避するため、テーブル作成処理を修正しました。[#38541](https://github.com/ClickHouse/ClickHouse/pull/38541) ([Raúl Marín](https://github.com/Algunenano)).
* [#38688](https://github.com/ClickHouse/ClickHouse/issues/38688)でバックポート: IPv4/IPv6 表現の値が不正なテーブルであっても、clickhouse-server を起動し、テーブルを attach/detach できるようになりました。issue [#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) に対する適切な修正です。[#38590](https://github.com/ClickHouse/ClickHouse/pull/38590) ([alesapin](https://github.com/alesapin)).
* [#38664](https://github.com/ClickHouse/ClickHouse/issues/38664)でバックポート: pre-22.4 レプリカでの問題を回避できるよう、さらにいくつかのノードを調整しました。 [#38627](https://github.com/ClickHouse/ClickHouse/pull/38627) ([Raúl Marín](https://github.com/Algunenano)).
* [#38779](https://github.com/ClickHouse/ClickHouse/issues/38779)でバックポート: 一部の引数が NaN でも、`rankCorr` 関数が正しく動作するよう修正しました。これにより [#38396](https://github.com/ClickHouse/ClickHouse/issues/38396) をクローズします。 [#38722](https://github.com/ClickHouse/ClickHouse/pull/38722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#38783](https://github.com/ClickHouse/ClickHouse/issues/38783)でバックポート: 誤った結果を引き起こしていた Map combinator の use-after-free を修正しました。 [#38748](https://github.com/ClickHouse/ClickHouse/pull/38748) ([Azat Khuzhin](https://github.com/azat)).
