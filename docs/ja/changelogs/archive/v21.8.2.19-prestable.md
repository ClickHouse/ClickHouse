<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#26524](https://github.com/ClickHouse/ClickHouse/issues/26524)でバックポート: 多数のカラムを持つテーブルの読み取りが必要な短いクエリのレイテンシを改善。 [#26371](https://github.com/ClickHouse/ClickHouse/pull/26371) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#26283](https://github.com/ClickHouse/ClickHouse/issues/26283)でバックポート: 非 `UInt64` 型に対する `optimize_skip_unused_shards_rewrite_in` を修正しました (最終的に誤った分片を選択したり、`Cannot infer type of an empty tuple` または `Function tuple requires at least one argument` をスローしたりする可能性がありました) 。[#25798](https://github.com/ClickHouse/ClickHouse/pull/25798) ([Azat Khuzhin](https://github.com/azat)).
* [#26587](https://github.com/ClickHouse/ClickHouse/issues/26587)でバックポート: `MaterializeMySQL` から選択する際に発生する `Not found column ...` および `Missing column ...` エラーを修正しました。[#23708](https://github.com/ClickHouse/ClickHouse/issues/23708)、[#24830](https://github.com/ClickHouse/ClickHouse/issues/24830)、[#25794](https://github.com/ClickHouse/ClickHouse/issues/25794) を修正します。[#25822](https://github.com/ClickHouse/ClickHouse/pull/25822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26190](https://github.com/ClickHouse/ClickHouse/issues/26190)でバックポート: remote() で、関数を使わないカラムから sharding&#95;key を取得する場合の不具合を修正しました (以前は `select * from remote('127.1', system.one, dummy)` により `Unknown column: dummy, there are only columns .` エラーが発生していました) 。[#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* [#26284](https://github.com/ClickHouse/ClickHouse/issues/26284)でバックポート: prewhere とともに通常の projection を使用した際に、header が不整合になる可能性がある問題を修正しました。これにより [#26020](https://github.com/ClickHouse/ClickHouse/issues/26020) を修正します。[#26038](https://github.com/ClickHouse/ClickHouse/pull/26038) ([Amos Bird](https://github.com/amosbird)).
* [#26298](https://github.com/ClickHouse/ClickHouse/issues/26298)でバックポート: クエリ実行中に例外が発生した際、ClickHouse が送信する MySQL プロトコルのパケット内の `sequence_id` が不正になる問題を修正しました。これにより MySQL client が ClickHouse server への接続をリセットする可能性がありました。[#21184](https://github.com/ClickHouse/ClickHouse/issues/21184) を修正します。[#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26204](https://github.com/ClickHouse/ClickHouse/issues/26204)でバックポート: 複数の `untuple` expression を使用した場合に発生する可能性があるクラッシュを修正しました。[#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26228](https://github.com/ClickHouse/ClickHouse/issues/26228)でバックポート: `system.stack_trace` table の `thread_name` カラムに含まれる余分な改行を削除しました。これにより [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124) を修正します。[#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26358](https://github.com/ClickHouse/ClickHouse/issues/26358)でバックポート: totals を伴う join で発生する論理エラーを修正し、[#26017](https://github.com/ClickHouse/ClickHouse/issues/26017) をクローズします。[#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir)).
* [#26788](https://github.com/ClickHouse/ClickHouse/issues/26788)でバックポート: 内部 buffer の末尾に escape sequences がある場合の zstd の展開処理を修正しました。[#26013](https://github.com/ClickHouse/ClickHouse/issues/26013) をクローズします。[#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26360](https://github.com/ClickHouse/ClickHouse/issues/26360)でバックポート: 失われたレプリカの復旧時に、まれにレプリカ間で不整合が生じる可能性があるバグを修正しました。[#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26452](https://github.com/ClickHouse/ClickHouse/issues/26452)でバックポート: 複数カラムに対する `optimize_distributed_group_by_sharding_key` を修正しました (`optimize_skip_unused_shards=1`/`allow_nondeterministic_optimize_skip_unused_shards=1` を有効にし、分片キー式で複数カラムを使用した場合に誤った結果になる問題) 。 [#26353](https://github.com/ClickHouse/ClickHouse/pull/26353) ([Azat Khuzhin](https://github.com/azat)).
* [#26422](https://github.com/ClickHouse/ClickHouse/issues/26422)でバックポート: 削除済みユーザーでログインした際に発生する可能性のあるクラッシュを修正しました。この PR は [#26073](https://github.com/ClickHouse/ClickHouse/issues/26073) を修正します。 [#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#26417](https://github.com/ClickHouse/ClickHouse/issues/26417)でバックポート: `partial_merge_join` で、join されていない block stream が無限に続く問題を修正し、[#26325](https://github.com/ClickHouse/ClickHouse/issues/26325) をクローズします。 [#26374](https://github.com/ClickHouse/ClickHouse/pull/26374) ([Vladimir C](https://github.com/vdimir)).
* [#26448](https://github.com/ClickHouse/ClickHouse/issues/26448)でバックポート: fuzzing により検出された msan クラッシュの一部を修正しました。 [#22517](https://github.com/ClickHouse/ClickHouse/issues/22517) を修正します。 [#26428](https://github.com/ClickHouse/ClickHouse/pull/26428) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#26488](https://github.com/ClickHouse/ClickHouse/issues/26488)でバックポート: カラム別名の書き換え後に名前解決が壊れる問題を修正しました。これにより [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432) を修正します。 [#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird)).
* [#26613](https://github.com/ClickHouse/ClickHouse/issues/26613)でバックポート: Dictionary 名またはデータベース名が引用符で囲まれている場合の `CREATE DICTIONARY` クエリの問題を修正しました。 [#26491](https://github.com/ClickHouse/ClickHouse/issues/26491) をクローズします。 [#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal)).
* [#26605](https://github.com/ClickHouse/ClickHouse/issues/26605)でバックポート: rabbitmq の Setup が開始されていない場合に、rabbitmq のシャットダウン時にクラッシュする問題を修正しました。 [#26504](https://github.com/ClickHouse/ClickHouse/issues/26504) をクローズします。 [#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26608](https://github.com/ClickHouse/ClickHouse/issues/26608)でバックポート: clickhouse-server の docker entrypoint における `chown` cmd の check を更新しました。これにより、Kubernetes 上でクラスターのポッド再起動が失敗する、またはタイムアウトするバグを修正します。 [#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix)).
* [#26648](https://github.com/ClickHouse/ClickHouse/issues/26648)でバックポート: groupBitmapAnd/Or/Xor の誤った関数名を修正しました。 [#26557](https://github.com/ClickHouse/ClickHouse/pull/26557) ([Amos Bird](https://github.com/amosbird)).
* [#26644](https://github.com/ClickHouse/ClickHouse/issues/26644)でバックポート: ファイルが空の場合の history file の変換を修正しました。 [#26589](https://github.com/ClickHouse/ClickHouse/pull/26589) ([Azat Khuzhin](https://github.com/azat)).
* [#26705](https://github.com/ClickHouse/ClickHouse/issues/26705)でバックポート: window functions における潜在的な nullptr 逆参照を修正しました。これにより [#25276](https://github.com/ClickHouse/ClickHouse/issues/25276) を修正します。 [#26668](https://github.com/ClickHouse/ClickHouse/pull/26668) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* [#26771](https://github.com/ClickHouse/ClickHouse/issues/26771)でバックポート: SET ROLE が正しく動作しないことがある問題を、このPRで修正しました。[#26707](https://github.com/ClickHouse/ClickHouse/pull/26707) ([Vitaly Baranov](https://github.com/vitlibar)) 。
