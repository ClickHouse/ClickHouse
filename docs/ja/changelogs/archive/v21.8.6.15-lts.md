  # 2022年 変更履歴
</div>

<div id="clickhouse-release-v218615-lts-fixme-as-compared-to-v21857-lts">
  ### ClickHouse リリース v21.8.6.15-lts FIXME (v21.8.5.7-lts との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#28899](https://github.com/ClickHouse/ClickHouse/issues/28899) でバックポート: vertical merge で、あらかじめ定義された &quot;rows&#95;sources&quot; ではなく実際の tmp ファイルを使用するようにしました。これにより、tmp ディスク内に不要なディレクトリが生成されるのを防ぎます。[#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).
* [#28642](https://github.com/ClickHouse/ClickHouse/issues/28642) でバックポート: Keeper の不自然なセッション有効期限ロジックを修正しました。おそらく CI の改善に役立ちます: [https://clickhouse-test-reports.s3.yandex.net/0/6bd9b82141c98dcd7796fd9d08326831095ba519/stress&#95;test&#95;(debug).html#fail1](https://clickhouse-test-reports.s3.yandex.net/0/6bd9b82141c98dcd7796fd9d08326831095ba519/stress_test_\(debug\).html#fail1)。[#28519](https://github.com/ClickHouse/ClickHouse/pull/28519) ([alesapin](https://github.com/alesapin)).
* [#28718](https://github.com/ClickHouse/ClickHouse/issues/28718) でバックポート: 追記予定。[#28529](https://github.com/ClickHouse/ClickHouse/issues/28529) をクローズします。[#28614](https://github.com/ClickHouse/ClickHouse/pull/28614) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#27923](https://github.com/ClickHouse/ClickHouse/issues/27923) でバックポート: 負の数に対する PostgreSQL スタイルのキャスト (`::` 演算子) の不具合を修正しました。[#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)) 。
* [#28753](https://github.com/ClickHouse/ClickHouse/issues/28753) でバックポート: 設定 `legacy_column_name_of_tuple_literal = 0` の分散クエリにおいて、論理和の連鎖を `IN` に変換する処理 (設定 `optimize_min_equality_disjunction_chain_length` で制御) の不具合を修正しました。[#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)) 。

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#28644](https://github.com/ClickHouse/ClickHouse/issues/28644) でバックポート: `clickhouse-keeper` の設定変更により、まれにログが失われ、server がハングする可能性がある問題を修正しました。[#28360](https://github.com/ClickHouse/ClickHouse/pull/28360) ([alesapin](https://github.com/alesapin)).
* [#28508](https://github.com/ClickHouse/ClickHouse/issues/28508) でバックポート: MaterializedPostgreSQL engine で table 名の引用符が欠けている問題を修正しました。[#28316](https://github.com/ClickHouse/ClickHouse/issues/28316) をクローズします。[#28433](https://github.com/ClickHouse/ClickHouse/pull/28433) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#28510](https://github.com/ClickHouse/ClickHouse/issues/28510) でバックポート: distributed DDL queue のバックグラウンド処理中に、ZooKeeper のウォッチがリークする可能性がある問題を修正しました。[#26036](https://github.com/ClickHouse/ClickHouse/issues/26036) をクローズします。[#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#28573](https://github.com/ClickHouse/ClickHouse/issues/28573) でバックポート: `ReplicatedVersionedCollapsingMergeTree` の alter 後に、`Existing table metadata in ZooKeeper differs in sorting key expression.` という error が発生する可能性がある bug を修正しました。[#28515](https://github.com/ClickHouse/ClickHouse/issues/28515) を修正します。[#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* [#28597](https://github.com/ClickHouse/ClickHouse/issues/28597) でバックポート: `Nested` カラムと、名前にドットを含み `Nested` と同じプレフィックスを持つ scalar カラム (例: `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`) を含む table から select する際に、`There is no subcolumn` error が発生する問題を修正しました。[#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* [#28714](https://github.com/ClickHouse/ClickHouse/issues/28714) でバックポート: system.processes table に Settings.Names および Settings.Values の別名を追加しました。[#28685](https://github.com/ClickHouse/ClickHouse/pull/28685) ([Vitaly Orlov](https://github.com/orloffv)).
* [#28741](https://github.com/ClickHouse/ClickHouse/issues/28741) でバックポート: 渡された parameter が誤っている場合に、分散テーブルの作成時に coredump が発生する問題を修正しました。[#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* [#28791](https://github.com/ClickHouse/ClickHouse/issues/28791) でバックポート: ReplicatedMergeTreeQueue における無害な race condition を修正しました。ユーザーに見えるものではありませんが、微妙な bug につながる可能性があります。[#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* [#28994](https://github.com/ClickHouse/ClickHouse/issues/28994) でバックポート: `DROP PART` と `REPLACE/MOVE PARTITION` の間で発生する race condition を修正しました。これにより、まれにレプリカ間で内容の不整合が生じる可能性がありました。[#28864](https://github.com/ClickHouse/ClickHouse/pull/28864) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#28948](https://github.com/ClickHouse/ClickHouse/issues/28948) でバックポート: compact パーツから subcolumns を読み取る際の問題を修正しました。[#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* [#28930](https://github.com/ClickHouse/ClickHouse/issues/28930) でバックポート: const を使用した高階の array functions に関する問題 (`arrayCompact` での `SIGSEGV`、`arrayDifference` / `arrayCumSumNonNegative` での `ILLEGAL_COLUMN`) を修正しました。[#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
