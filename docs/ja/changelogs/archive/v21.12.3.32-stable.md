  ### ClickHouse リリース v21.12.3.32-stable FIXME (v21.12.2.17-stable との比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#33018](https://github.com/ClickHouse/ClickHouse/issues/33018) でバックポート: - ClickHouse Keeper ハンドラーは、応答送信時に操作を削除するよう修正。 [#32988](https://github.com/ClickHouse/ClickHouse/pull/32988) ([JackyWoo](https://github.com/JackyWoo)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#32890](https://github.com/ClickHouse/ClickHouse/issues/32890) にバックポート: materialized view のターゲットが JOIN または SET テーブルである場合に発生する LOGICAL&#95;ERROR を修正しました。[#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano))。
* [#33183](https://github.com/ClickHouse/ClickHouse/issues/33183) にバックポート: `MySQL` engine の database が MySQL server に接続できない場合に Server が起動に失敗することがある問題を修正しました。[#14441](https://github.com/ClickHouse/ClickHouse/issues/14441) を修正。[#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#32904](https://github.com/ClickHouse/ClickHouse/issues/32904) にバックポート: 実行中の mutations が多すぎる場合やメモリ使用量が高い場合に、`MergeTree` table engine が一部の mutations を黙ってスキップしてしまうことがある問題を修正しました。[#17882](https://github.com/ClickHouse/ClickHouse/issues/17882) を修正。[#32814](https://github.com/ClickHouse/ClickHouse/pull/32814) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#33047](https://github.com/ClickHouse/ClickHouse/issues/33047) にバックポート: remote fs からの非同期 reads における lazy seek の最適化を修正しました。[#32803](https://github.com/ClickHouse/ClickHouse/issues/32803) をクローズ。[#32835](https://github.com/ClickHouse/ClickHouse/pull/32835) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#32932](https://github.com/ClickHouse/ClickHouse/issues/32932) にバックポート: [#32487](https://github.com/ClickHouse/ClickHouse/issues/32487) をクローズ。[#32914](https://github.com/ClickHouse/ClickHouse/pull/32914) ([Vladimir C](https://github.com/vdimir))。
* [#32962](https://github.com/ClickHouse/ClickHouse/issues/32962) にバックポート: `replaceRegexpAll` function のリグレッションを修正しました。一致した substring が空の場合に、この function が正しく動作しない問題を修正しました。これにより [#32777](https://github.com/ClickHouse/ClickHouse/issues/32777) をクローズします。これにより [#30245](https://github.com/ClickHouse/ClickHouse/issues/30245) をクローズします。[#32945](https://github.com/ClickHouse/ClickHouse/pull/32945) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#33067](https://github.com/ClickHouse/ClickHouse/issues/33067) にバックポート: HA namenode address を使用できなかった hdfs url チェックを修正しました。このバグは [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042) で導入されました。[#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar))。
* [#33100](https://github.com/ClickHouse/ClickHouse/issues/33100) にバックポート: cancel&#95;http&#95;readonly&#95;queries&#95;on&#95;client&#95;close の場合に発生する Context リークを修正しました (つまり、server にアップロードされた外部テーブルやその他の resource がリークしていました) 。[#32982](https://github.com/ClickHouse/ClickHouse/pull/32982) ([Azat Khuzhin](https://github.com/azat))。
* [#33123](https://github.com/ClickHouse/ClickHouse/issues/33123) にバックポート: `local_filesystem_read_prefetch` または `remote_filesystem_read_prefetch` が有効な場合に `LowCardinality` カラムを read すると発生するエラー `Invalid version for SerializationLowCardinality key column` を修正しました。[#33046](https://github.com/ClickHouse/ClickHouse/pull/33046) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
