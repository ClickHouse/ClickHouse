<div id="bug-fix">
  #### バグ修正
</div>

* [#21205](https://github.com/ClickHouse/ClickHouse/issues/21205) でバックポート: カスタムの (default ではない) ZooKeeper クラスターを使用する Replicated*MergeTree を drop した際のメタデータリークを修正しました。[#21119](https://github.com/ClickHouse/ClickHouse/pull/21119) ([fastio](https://github.com/fastio)).
* [#21161](https://github.com/ClickHouse/ClickHouse/issues/21161) でバックポート: 型が Nullable の場合に `input_format_null_as_default` が有効にならない不具合を修正しました。これにより [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116) も修正されます。 [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* [#21926](https://github.com/ClickHouse/ClickHouse/issues/21926) でバックポート: Kafka 向けの Avro フォーマットのパースを修正しました。[#21437](https://github.com/ClickHouse/ClickHouse/issues/21437) を修正します。 [#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)).
* [#22189](https://github.com/ClickHouse/ClickHouse/issues/22189) でバックポート: Poco の SecureSocket 内の SSL オブジェクトにおける競合状態を修正しました。 [#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#22317](https://github.com/ClickHouse/ClickHouse/issues/22317) でバックポート: 外部データベースエンジン (MySQL、PostgreSQL) へのクエリで、WHERE 内の結合先テーブルから不明なカラムを削除するようにしました。[#14614](https://github.com/ClickHouse/ClickHouse/issues/14614) をクローズ、[#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) をクローズ (重複) 、[#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) をクローズ (重複) 。 [#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)).
* [#21797](https://github.com/ClickHouse/ClickHouse/issues/21797) でバックポート: `async_socket_for_remote=1` での分散リクエストのキャンセル (たとえば、`select * from remote('127.{2,3}', system.numbers) limit 100` のように、複数の分片から LIMIT 付きで単純に SELECT する場合) を修正しました。 [#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* [#22287](https://github.com/ClickHouse/ClickHouse/issues/22287) でバックポート: DDLWorker と辞書の初期化が完了してから接続を受け付けるようにしました。 [#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat)).
* [#21810](https://github.com/ClickHouse/ClickHouse/issues/21810) でバックポート: ReplicatedMerge テーブルエンジンで、decimal カラムのサイズ (32 bit または 64 bit) が変わらない場合、`ALTER MODIFY COLUMN` クエリでその型が変更されない不具合を修正しました。 [#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* [#21880](https://github.com/ClickHouse/ClickHouse/issues/21880) でバックポート: 二段階集約の使用時に、Distinct コンビネータ付きの集約関数で発生しうるクラッシュを修正しました。これは [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365) の追加修正です。本番環境でのみ再現します。現時点ではテストケースはありません。cc @CurtizJ。 [#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)).
* [#22052](https://github.com/ClickHouse/ClickHouse/issues/22052) でバックポート: catboost model の初回実行時に発生するデッドロックを修正しました。[#13832](https://github.com/ClickHouse/ClickHouse/issues/13832) をクローズします。 [#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar)).
* [#21981](https://github.com/ClickHouse/ClickHouse/issues/21981) にバックポート: ハッシュ型の外部辞書の読み込み中にメモリ使用量が大幅に増加する可能性があった [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454) を元に戻しました。これにより [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935) をクローズします。[#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)).
* [#22465](https://github.com/ClickHouse/ClickHouse/issues/22465) にバックポート: まれに、`CollapsingMergeTree` のマージで `index_granularity + 1` 行を持つ granule が作成されることがありました。そのため、[#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) で追加された内部チェック (21.2 および 21.3 に影響) が、`Incomplete granules are not allowed while blocks are granules size` というエラーで失敗する場合がありました。このエラーにより、パーツをマージできませんでした。[#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#22149](https://github.com/ClickHouse/ClickHouse/issues/22149) にバックポート: 関数 `decrypt` には、AEAD モードで暗号化されたデータの最小サイズを確認するチェックが不足していました。これにより [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897) をクローズします。[#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22283](https://github.com/ClickHouse/ClickHouse/issues/22283) にバックポート: Docker entrypoint: `LOG_PATH` が空の場合に `.` への chown を回避します。[#22100](https://github.com/ClickHouse/ClickHouse/issues/22100) をクローズします。[#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* [#22280](https://github.com/ClickHouse/ClickHouse/issues/22280) にバックポート: `ReplicatedMergeTree` テーブルエンジンに対する `OPTIMIZE` および `ALTER` クエリの待機処理を修正しました。これにより、テーブルがデタッチされた場合や再起動された場合でも、クエリがハングしなくなります。[#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* [#22501](https://github.com/ClickHouse/ClickHouse/issues/22501) にバックポート: `use_hedged_requests=0` および `async_socket_for_remote=1` でのクエリキャンセルを修正しました。[#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* [#22368](https://github.com/ClickHouse/ClickHouse/issues/22368) にバックポート: これで、すでにカバーされているパーツを mutate しようとしても、ClickHouse が `LOGICAL_ERROR` 例外をスローしなくなります。[#22013](https://github.com/ClickHouse/ClickHouse/issues/22013) を修正しました。[#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* [#22533](https://github.com/ClickHouse/ClickHouse/issues/22533) にバックポート: `tokenbf_v1` テキスト索引で、読み取り時にバッファオーバーフローが発生する可能性がありました。余分なバイトは使用されませんが、まれに読み取り操作によってクラッシュが発生する可能性がありました。これにより [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233) をクローズします。[#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22462](https://github.com/ClickHouse/ClickHouse/issues/22462) にバックポート: 並列なパースルーチンに、不足していたメモリ使用量の計上を追加しました。以前のバージョンでは、結果セットに非常に大きなデータブロックが含まれていると OOM が発生する可能性がありました。これにより [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008) をクローズします。[#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22555](https://github.com/ClickHouse/ClickHouse/issues/22555) でバックポート: `LowCardinality` を使用する partial merge join の不具合を修正。[#22386](https://github.com/ClickHouse/ClickHouse/issues/22386) をクローズし、[#22388](https://github.com/ClickHouse/ClickHouse/issues/22388) をクローズ。[#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* [#22608](https://github.com/ClickHouse/ClickHouse/issues/22608) でバックポート: 末尾に改行のない空文字列の TSV フォーマットにおけるデシリアライゼーションを修正。これにより [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244) をクローズ。バージョンを更新しない場合の回避策: `input_format_null_as_default` を 0 に設定してください。旧バージョンでは 0 でした。[#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#22578](https://github.com/ClickHouse/ClickHouse/issues/22578) でバックポート: TinyLog の rwlock を同じスレッドからロック解除するようにして、UB を修正。[#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* [#22650](https://github.com/ClickHouse/ClickHouse/issues/22650) でバックポート: *Log engines で、別スレッドからのロック解除に起因する rwlock のロック解除時の UB を回避。[#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* [#22700](https://github.com/ClickHouse/ClickHouse/issues/22700) でバックポート: ReplicatedMergeTree テーブルエンジンで、複数のレプリカに対する mutations の待機処理を修正。これまでは、mutation/alter クエリが他のレプリカで mutation が実際に実行される前に完了してしまうことがありました。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* [#22739](https://github.com/ClickHouse/ClickHouse/issues/22739) でバックポート: OOM 例外発生時に zk リクエストがハングする可能性がある問題を修正。[#22438](https://github.com/ClickHouse/ClickHouse/issues/22438) を修正。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
