<div id="bug-fix">
  #### バグ修正
</div>

* [#21206](https://github.com/ClickHouse/ClickHouse/issues/21206) でバックポート: カスタムの (デフォルト以外の) ZooKeeper クラスターを使用する Replicated*MergeTree が削除された際に、メタデータリークが発生する問題を修正しました。[#21119](https://github.com/ClickHouse/ClickHouse/pull/21119) ([fastio](https://github.com/fastio)).
* [#21927](https://github.com/ClickHouse/ClickHouse/issues/21927) でバックポート: Kafka 向けの Avro format のパースを修正しました。[#21437](https://github.com/ClickHouse/ClickHouse/issues/21437) を修正します。[#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)).
* [#21855](https://github.com/ClickHouse/ClickHouse/issues/21855) でバックポート: `optimize_skip_unused_shards` が有効で、使用される分片が 0 の場合に、` Cannot find column` エラーが発生する可能性がある問題を修正しました。[#21579](https://github.com/ClickHouse/ClickHouse/pull/21579) ([Azat Khuzhin](https://github.com/azat)).
* [#21688](https://github.com/ClickHouse/ClickHouse/issues/21688) でバックポート: horizontal merge における `fsync_part_directory` を修正しました。[#21642](https://github.com/ClickHouse/ClickHouse/pull/21642) ([Azat Khuzhin](https://github.com/azat)).
* [#21795](https://github.com/ClickHouse/ClickHouse/issues/21795) でバックポート: `async_socket_for_remote=1` 使用時の分散リクエストのキャンセル処理 (たとえば、複数の分片に対する limit 付きの単純な select である `select * from remote('127.{2,3}', system.numbers) limit 100`) を修正しました。[#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* [#21879](https://github.com/ClickHouse/ClickHouse/issues/21879) でバックポート: 二段階集約の使用時に、Distinct コンビネータ付きの集約関数でクラッシュが発生する可能性がある問題を修正しました。これは [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365) に対する追加修正です。本番環境でのみ再現します。現時点ではテストケースはありません。cc @CurtizJ. [#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)).
* [#21979](https://github.com/ClickHouse/ClickHouse/issues/21979) でバックポート: ハッシュ型の外部辞書の読み込み中にメモリ使用量が大幅に増加する可能性があるため、[#15454](https://github.com/ClickHouse/ClickHouse/issues/15454) を差し戻しました。これにより [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935) をクローズします。[#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)).
* [#22140](https://github.com/ClickHouse/ClickHouse/issues/22140) でバックポート: 関数 `decrypt` で、AEAD mode で暗号化されたデータの最小サイズを確認するチェックが不足していました。これにより [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897) をクローズします。[#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
