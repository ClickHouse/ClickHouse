<div id="2023-changelog">
  # 2023年の変更履歴
</div>

<div id="clickhouse-release-v237225-stable-8dd1107b032-fixme-as-compared-to-v23712470-stable-a70127baecc">
  ### ClickHouse リリース v23.7.2.25-stable (8dd1107b032) FIXME v23.7.1.2470-stable (a70127baecc) と比較して
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#52850](https://github.com/ClickHouse/ClickHouse/issues/52850) でバックポート: 動的ディスクに名前がある場合、ディスク関数の引数では `disk = disk(name = 'disk_name'`, ...) のように指定する必要があります。以前のバージョンでは `disk = disk_<disk_name>(...)` のように指定できましたが、この形式は現在サポートされていません。[#52820](https://github.com/ClickHouse/ClickHouse/pull/52820) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#52913](https://github.com/ClickHouse/ClickHouse/issues/52913)でバックポート: clickhouse-server パッケージに `clickhouse-keeper-client` へのシンボリックリンクを追加。 [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* Nullable(IPv4) の二項演算を修正 [#51642](https://github.com/ClickHouse/ClickHouse/pull/51642) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Dictionary 属性として IPv4 および IPv6 をサポート [#51756](https://github.com/ClickHouse/ClickHouse/pull/51756) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 必要に応じて ares チャネルを初期化・破棄するように修正.. [#52634](https://github.com/ClickHouse/ClickHouse/pull/52634) ([Arthur Passos](https://github.com/arthurpassos)).
* スパースなカラムを 1 つ引数に取る関数 `tuple` のクラッシュを修正 [#52659](https://github.com/ClickHouse/ClickHouse/pull/52659) ([Anton Popov](https://github.com/CurtizJ)).
* Keeper の再構成におけるデータ競合を修正 [#52804](https://github.com/ClickHouse/ClickHouse/pull/52804) ([Antonio Andelic](https://github.com/antonio2368)).
* clickhouse-keeper: poll() を使用するサーバー実装を修正 [#52833](https://github.com/ClickHouse/ClickHouse/pull/52833) ([Andy Fiddaman](https://github.com/citrus-it)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微
</div>

* setting `disable_url_encoding` を `enable_url_encoding` にリネームし、テストを追加 [#52656](https://github.com/ClickHouse/ClickHouse/pull/52656) ([Kruglov Pavel](https://github.com/Avogar)).
* SYSTEM STOP LISTEN の不具合を修正し、テストを強化 [#52680](https://github.com/ClickHouse/ClickHouse/pull/52680) ([Nikolay Degterinsky](https://github.com/evillique)).
* スパース シリアライゼーション向けの最小プロトコル バージョンを引き上げ [#52835](https://github.com/ClickHouse/ClickHouse/pull/52835) ([Anton Popov](https://github.com/CurtizJ)).
* Docker の改善 [#52869](https://github.com/ClickHouse/ClickHouse/pull/52869) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
