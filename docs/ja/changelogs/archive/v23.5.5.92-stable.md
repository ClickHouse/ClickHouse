<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#52749](https://github.com/ClickHouse/ClickHouse/issues/52749) でバックポート: 主キーを無効化してしまう、誤ったプロジェクション解析を修正しました。この問題は、`query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1` の場合にのみ発生します。これにより [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823) を修正します。これにより [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173) を修正します。[#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#51886](https://github.com/ClickHouse/ClickHouse/issues/51886)でバックポート: Cargo の依存関係を更新。 [#51721](https://github.com/ClickHouse/ClickHouse/pull/51721) ([Raúl Marín](https://github.com/Algunenano)).
* [#52909](https://github.com/ClickHouse/ClickHouse/issues/52909)でバックポート: `clickhouse-keeper-client` のシンボリックリンクを clickhouse-server パッケージに追加。 [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53021](https://github.com/ClickHouse/ClickHouse/issues/53021)でバックポート: inline cache を Docker イメージに埋め込むと、ときどき不可解な副作用が発生します。そもそもまったく使用していないため、削除しても問題ありません。 [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53289](https://github.com/ClickHouse/ClickHouse/issues/53289)でバックポート: コンパイラのプロファイルデータ (`-ftime-trace`) を ClickHouse Cloud にアップロード。[#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) に続く2回目の試みです。 [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#53463](https://github.com/ClickHouse/ClickHouse/issues/53463)でバックポート: `clickhouse start` コマンドで環境パラメータを保持。 [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962) を修正。 [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
