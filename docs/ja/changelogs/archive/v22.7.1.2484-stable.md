  ### ClickHouse リリース v22.7.1.2484-stable (f4f05ec786a) FIXME (v22.6.1.1985-stable (7000c4e0033) と比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 設定 `enable_positional_arguments` がデフォルトで有効になりました。これにより、1、2 が SELECT 句への参照である `SELECT ... ORDER BY 1, 2` のようなクエリを実行できます。以前の動作に戻す必要がある場合は、この設定を無効にしてください。[#38204](https://github.com/ClickHouse/ClickHouse/pull/38204) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Ordinary` データベースエンジンおよび `*MergeTree` テーブル向けの古いストレージ定義構文は非推奨になりました。デフォルトでは、新規に作成することはできません。`system` データベースが `Ordinary` エンジンを使用している場合、server の起動時に自動的に `Atomic` に変換されます。以前の動作を維持するための設定 (`allow_deprecated_database_ordinary` および `allow_deprecated_syntax_for_merge_tree`) はありますが、これらの設定は将来のリリースで削除される可能性があります。[#38335](https://github.com/ClickHouse/ClickHouse/pull/38335) ([Alexander Tokmakov](https://github.com/tavplubix)).
* * デフォルトで comma join を inner join に書き換えるよう強制します (デフォルト値 `cross_to_inner_join_rewrite = 2` を設定) 。以前の動作にするには、`cross_to_inner_join_rewrite = 1` を設定してください。[#39326](https://github.com/ClickHouse/ClickHouse/pull/39326) ([Vladimir C](https://github.com/vdimir)).
* `format_csv_allow_single_quotes` はデフォルトで無効になりました。[#37096](https://github.com/ClickHouse/ClickHouse/issues/37096). [#39423](https://github.com/ClickHouse/ClickHouse/pull/39423) ([Kruglov Pavel](https://github.com/Avogar)).

  #### 新機能
</div>

* RocksDB向けの新しい`direct` JOINアルゴリズムを追加。関連 issue: [#33582](https://github.com/ClickHouse/ClickHouse/issues/33582)。 [#35363](https://github.com/ClickHouse/ClickHouse/pull/35363) ([Vladimir C](https://github.com/vdimir)).

* 外部ファイルのインポート時に、zstd のデコードにおける最大メモリ使用量を設定するための `zstd_window_log_max` を追加しました。[#35693](https://github.com/ClickHouse/ClickHouse/issues/35693) をクローズしました。[#37015](https://github.com/ClickHouse/ClickHouse/pull/37015) ([wuxiaobai24](https://github.com/wuxiaobai24)).
* NATS への pub/sub を可能にするテーブルエンジン NatsStorage を実装しました。[#32388](https://github.com/ClickHouse/ClickHouse/issues/32388) をクローズしました。[#37171](https://github.com/ClickHouse/ClickHouse/pull/37171) ([tchepavel](https://github.com/tchepavel)).

* [#17202](https://github.com/ClickHouse/ClickHouse/issues/17202) では、host&#95;regexp が複数ありうる PTR 応答のうち 1 つに対してしかテストされていないことが報告されていました。この PR では必要な変更を加え、host&#95;regexp を考えられるすべての PTR 応答に適用し、いずれかに一致するかどうかを検証するようにしました。[#37827](https://github.com/ClickHouse/ClickHouse/pull/37827) ([Arthur Passos](https://github.com/arthurpassos)).
* Hadoop のセキュア RPC 転送 (hadoop.rpc.protection=privacy および hadoop.rpc.protection=integrity) をサポートしました。[#37852](https://github.com/ClickHouse/ClickHouse/pull/37852) ([Peng Liu](https://github.com/michael1589)).
* `StorageHive` で struct 型をサポートしました。[#38118](https://github.com/ClickHouse/ClickHouse/pull/38118) ([lgbo](https://github.com/lgbo-ustc)).
* Base58 のエンコード/デコードを追加しました。[#38159](https://github.com/ClickHouse/ClickHouse/pull/38159) ([Andrey Zvonov](https://github.com/zvonand)).
* Play UI にチャートの可視化機能を追加しました。[#38197](https://github.com/ClickHouse/ClickHouse/pull/38197) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `StorageHive` テーブルで `alter` コマンドをサポートしました。[#38214](https://github.com/ClickHouse/ClickHouse/pull/38214) ([lgbo](https://github.com/lgbo-ustc)).
* `CREATE TABLE ... EMPTY AS SELECT` クエリを追加しました。SELECT クエリからテーブル構造を自動的に推定しますが、作成後にテーブルへデータは投入しません。[#38049](https://github.com/ClickHouse/ClickHouse/issues/38049) を解決しました。[#38272](https://github.com/ClickHouse/ClickHouse/pull/38272) ([Alexander Tokmakov](https://github.com/tavplubix)).
* スタンドアロン クエリをトランザクション内で実行するための新しい設定 `implicit_transaction` を追加しました。トランザクションの開始と終了 (クエリが成功した場合は COMMIT、失敗した場合は ROLLBACK) を自動的に処理します。[#38344](https://github.com/ClickHouse/ClickHouse/pull/38344) ([Raúl Marín](https://github.com/Algunenano)).
* カラム一覧で末尾のカンマを許可しました。[#38425](https://github.com/ClickHouse/ClickHouse/issues/38425) をクローズしました。[#38440](https://github.com/ClickHouse/ClickHouse/pull/38440) ([chen](https://github.com/xiedeyantu)).
* clickhouse を自己展開型の実行可能ファイルに圧縮しました (パス: programs/self-extracting) 。新しい build ターゲット &#39;self-extracting&#39; を追加しました。[#38447](https://github.com/ClickHouse/ClickHouse/pull/38447) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 設定 `additional_table_filters` を導入しました。この設定を使用すると、読み取り直後に適用される、テーブルに対する追加のフィルタ条件を指定できます。例: `select number, x, y from (select number from system.numbers limit 5) f any left join (select x, y from table_1) s on f.number = s.x settings additional_table_filters={'system.numbers : 'number != 3', 'table_1' : 'x != 2'}`。また、クエリ結果に対する追加のフィルタ条件を指定する設定 `additional_result_filter` も導入しました。[#37918](https://github.com/ClickHouse/ClickHouse/issues/37918) をクローズします。[#38475](https://github.com/ClickHouse/ClickHouse/pull/38475) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* SQLInsert 出力フォーマットを追加しました。[#38441](https://github.com/ClickHouse/ClickHouse/issues/38441) をクローズします。[#38477](https://github.com/ClickHouse/ClickHouse/pull/38477) ([Kruglov Pavel](https://github.com/Avogar))。
* ダウンロード可能な ClickHouse 実行可能ファイルは、圧縮された自己展開形式になりました。[#38653](https://github.com/ClickHouse/ClickHouse/pull/38653) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* `isNullable` 関数をサポートしました。この関数は、引数が Nullable かどうかを確認し、true(1) または false(0) を返します。[#38611](https://github.com/ClickHouse/ClickHouse/issues/38611) をクローズします。[#38841](https://github.com/ClickHouse/ClickHouse/pull/38841) ([lokax](https://github.com/lokax))。
* 関数 `translate(string, from_string, to_string)` および `translateUTF8(string, from_string, to_string)` を追加しました。[#38935](https://github.com/ClickHouse/ClickHouse/pull/38935) ([Nikolay Degterinsky](https://github.com/evillique))。
* `compatibility` 設定と、ClickHouse のバージョン間での設定変更に関する情報を含む `system.settings_changes` システムテーブルを追加しました。[#35972](https://github.com/ClickHouse/ClickHouse/issues/35972) をクローズします。[#38957](https://github.com/ClickHouse/ClickHouse/pull/38957) ([Kruglov Pavel](https://github.com/Avogar))。
* tupleElement 関数に 3 番目の引数を追加し、tuple にメンバーがない場合はその値を返すようにしました。2 番目の引数が String 型の場合にのみ機能します。[#38872](https://github.com/ClickHouse/ClickHouse/issues/38872) をクローズします。[#38989](https://github.com/ClickHouse/ClickHouse/pull/38989) ([lokax](https://github.com/lokax))。
* parseTimedelta 関数をサポートしました。これは次のように使用できます: &#96;&#96;&#96;sql # 区切り文字として &#39; &#39;、&#39;;&#39;、&#39;-&#39;、&#39;+&#39;、&#39;,&#39;、&#39;:&#39; を使用できます。例: &quot;1yr-2mo&quot;、&quot;2m:6s&quot; SELECT parseTimeDelta(&#39;1yr-2mo-4w + 12 days, 3 hours : 1 minute ; 33 seconds&#39;);。[#39071](https://github.com/ClickHouse/ClickHouse/pull/39071) ([jiahui-97](https://github.com/jiahui-97))。
* リモートストレージでの I/O 操作を制限するオプション `max_remote_read_network_bandwidth_for_server` と `max_remote_write_network_bandwidth_for_server` を追加しました。[#39095](https://github.com/ClickHouse/ClickHouse/pull/39095) ([Sergei Trifonov](https://github.com/serxa))。
* `send_logs_source_regexp` 設定を追加しました。指定した regexp に一致するログソース名を持つサーバーのテキストログを送信します。空の場合はすべてのログソースを意味します。[#39161](https://github.com/ClickHouse/ClickHouse/pull/39161) ([Amos Bird](https://github.com/amosbird))。
* OpenTelemetry は、デフォルトで Processors spans を含まない traces を収集するようになりました。Processors spans の収集を有効にするには、`opentelemetry_trace_processors` 設定を使用します。[#39170](https://github.com/ClickHouse/ClickHouse/pull/39170) ([Ilya Yatsishin](https://github.com/qoega))。

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 非同期 Linux [io&#95;uring](https://kernel.dk/io_uring.pdf) サブシステムに基づく、新しい `local_filesystem_read_method` の `io_uring` メソッドを追加しました。デフォルトの `pread` メソッドと比べ、ほぼあらゆるケースで読み取り性能が向上します。 [#36103](https://github.com/ClickHouse/ClickHouse/pull/36103) ([Saulius Valatka](https://github.com/sauliusvl)).
* sorted columns に対する distinct の最適化。入力ストリームが distinct 対象のカラムで sorted されている場合に、専用の distinct 変換を使用します。この最適化は pre-distinct、final distinct、またはその両方に適用できます。初期実装は @dimarub2000 によるものです。 [#37803](https://github.com/ClickHouse/ClickHouse/pull/37803) ([Igor Nikonov](https://github.com/devcrafter)).
* LZ4 の展開向けに、VBMI 最適化版の copyOverlap32Shuffle を追加しました。 [#37891](https://github.com/ClickHouse/ClickHouse/pull/37891) ([Guo Wangyang](https://github.com/guowangy)).
* `BinaryHeap` の batch 版を使用して、`ORDER BY`、`MergeTree` の merges、window functions の性能を改善しました。 [#38022](https://github.com/ClickHouse/ClickHouse/pull/38022) ([Maksim Kita](https://github.com/kitaisreal)).
* [https://github.com/ClickHouse/ClickHouse/pull/35616](https://github.com/ClickHouse/ClickHouse/pull/35616) で導入された join 性能の大幅な回帰を修正しました。ssb クエリのような一般的な join クエリが、ほぼ 3 か月もの間 10 倍遅くなっていたにもかかわらず、誰からも報告がなかったのは興味深い点です。 [#38052](https://github.com/ClickHouse/ClickHouse/pull/38052) ([Amos Bird](https://github.com/amosbird)).
* Intel hyperscan ライブラリから vectorscan に移行しました。これにより、非 x86 プラットフォームで多くの文字列マッチングが高速化されます。 [#38171](https://github.com/ClickHouse/ClickHouse/pull/38171) ([Robert Schulze](https://github.com/rschu1ze)).
* aggregation の後に実行されるクエリプランステップの並列度を向上させました。 [#38295](https://github.com/ClickHouse/ClickHouse/pull/38295) ([Nikita Taranov](https://github.com/nickitat)).
* `JSON` 型のカラムへの insertion の性能を改善しました。 [#38320](https://github.com/ClickHouse/ClickHouse/pull/38320) ([Anton Popov](https://github.com/CurtizJ)).
* HashTable における insertion とルックアップを最適化しました。 [#38413](https://github.com/ClickHouse/ClickHouse/pull/38413) ([Nikita Taranov](https://github.com/nickitat)).
* [#32493](https://github.com/ClickHouse/ClickHouse/issues/32493) に起因する性能低下を修正しました。 [#38417](https://github.com/ClickHouse/ClickHouse/pull/38417) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* SIMD 命令を使用して、カラムベクターの replicate の性能を改善しました。著者は @zzachimed です。 [#38565](https://github.com/ClickHouse/ClickHouse/pull/38565) ([Maksim Kita](https://github.com/kitaisreal)).
* arrays 向けの Norm and Distance functions が 1.2～2 倍高速化されました。 [#38740](https://github.com/ClickHouse/ClickHouse/pull/38740) ([Alexander Gololobov](https://github.com/davenger)).
* ORDER BY (a, b) を含むクエリでは、ORDER BY a, b の場合よりも効率の低い実行計画が生成されることがあります。 [#38873](https://github.com/ClickHouse/ClickHouse/pull/38873) ([Igor Nikonov](https://github.com/devcrafter)).
* 実行可能 UDF、Executable Dictionary、Executable Storage の poll サブプロセスで、終了時に 1 秒間サブプロセスを待機してしまう問題を修正しました。 [#38929](https://github.com/ClickHouse/ClickHouse/pull/38929) ([Constantine Peresypkin](https://github.com/pkit)).
* * sorting join の右側に filter pushdown を適用します。 [#39123](https://github.com/ClickHouse/ClickHouse/pull/39123) ([Vladimir C](https://github.com/vdimir)).
* system.stack&#95;trace へのアクセスを最適化しました。 [#39177](https://github.com/ClickHouse/ClickHouse/pull/39177) ([Azat Khuzhin](https://github.com/azat)).
