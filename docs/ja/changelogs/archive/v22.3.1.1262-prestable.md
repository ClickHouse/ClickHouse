* `toDatetime` 関数のオーバーフロー時の挙動を改善しました。日付文字列が非常に大きい場合は、1970 に変換されます。 [#32898](https://github.com/ClickHouse/ClickHouse/pull/32898) ([HaiBo Li](https://github.com/marising)).
* `arrayCompact` が他の高階関数と同様に動作するようにしました。つまり、ラムダ関数の結果ではなく、元の配列に対して compaction を実行します。`arrayCompact` で複雑なラムダ関数を使用している場合は、`arrayCompact` の引数を `arrayMap` でラップすることで以前の動作を復元できます。以下をクローズします: [#34010](https://github.com/ClickHouse/ClickHouse/issues/34010) [#18535](https://github.com/ClickHouse/ClickHouse/issues/18535) [#14778](https://github.com/ClickHouse/ClickHouse/issues/14778).   #### 新機能

* セミ構造化データ (現時点ではJSONのみ) の格納をサポートする新しいデータ型 `Object(<schema_format>)` を追加しました。データはこの型に文字列として書き込まれます。その後、セミ構造化データのフォーマットに従ってすべてのパスが抽出され、各値を格納できる最適な型の個別カラムとして書き込まれます。これらのカラムは、ソースデータのパスに一致する名前 (例：`data.key1.key2`) またはキャスト演算子 (`data.key1.key2::Int64`) でクエリできます。[#23932](https://github.com/ClickHouse/ClickHouse/pull/23932) ([Anton Popov](https://github.com/CurtizJ)).
* SSL経由で接続するユーザーのX.509証明書による認証をサポートしました。[#31484](https://github.com/ClickHouse/ClickHouse/pull/31484) ([eungenue](https://github.com/eungenue)).

#### パフォーマンス改善

* 大きな list に対して `std::distance` を呼び出すと性能が低下するため、Node 内のバージョンを使う実装に置き換え、メモリ使用量は 1000 万 Nodes あたり 80MB です。ロジックは次のとおりです。list 内の各 node は `size_t` 型の version を持ち、`insert` または `insertOrReplace` method で class のメンバー変数 `current_version` を使って設定されます。version が増加するのは `enableSnapshot` method のときだけです。snapshot 実行時には `snapshotSizeWithVersion` を呼び出して、snapshot サイズと version (`snapshot_up_to_version`) を取得します。list を走査する際、node version が `snapshot_up_to_version` 以下であれば削除から保護され、node version が `snapshot_up_to_version` より大きければ、その node には任意の操作を行えます。[#34486](https://github.com/ClickHouse/ClickHouse/pull/34486) ([zhanglistar](https://github.com/zhanglistar)).
* Nuraft の log store の compaction では、通常の commit 処理でも使われる内部 lock を取得する必要があるため、Changelog class の `compact` method で不要な logs を background thread で削除するようにしました。詳細は https://github.com/ClickHouse-Extras/NuRaft/blob/1707a7572aa66ec5d0a2dbe2bf5effa3352e6b2d/src/handle&#95;commit.cxx#L560 を参照してください。[#34534](https://github.com/ClickHouse/ClickHouse/pull/34534) ([zhanglistar](https://github.com/zhanglistar)).
* 最新の snapshot は memory に保持せず、必要になったときに読み込むようにしました。連続読み取りは `mmap` system call を使うことで、HDD 上でも 200MBps 超の速度が出ます。snapshot データは、元データと圧縮済みデータを memory に保持せず、圧縮 method を使って直接ディスクに書き込みます。[#34584](https://github.com/ClickHouse/ClickHouse/pull/34584) ([zhanglistar](https://github.com/zhanglistar)).
* `std::stable_sort` を `pdqsort` に置き換えることで、MergeTree の insert 性能を改善しました。[#34750](https://github.com/ClickHouse/ClickHouse/pull/34750) ([Maksim Kita](https://github.com/kitaisreal)).
* batches 単位で処理することで、`ANY` aggregation function の性能を改善しました。[#34760](https://github.com/ClickHouse/ClickHouse/pull/34760) ([Raúl Marín](https://github.com/Algunenano)).
* `detectCharset `、`detectLanguageUnknown ` functions の性能を改善しました。Dictionary ソース が `ClickHouse` の場合の `DirectDictionary` の性能を改善しました。大きな `IN` section を含む queries の処理性能を改善しました。[#34888](https://github.com/ClickHouse/ClickHouse/pull/34888) ([Maksim Kita](https://github.com/kitaisreal)).
* atomic stat を使うことで connection での lock を削減しました。なお、これは概算の stat です。[#35010](https://github.com/ClickHouse/ClickHouse/pull/35010) ([zhanglistar](https://github.com/zhanglistar)).
