<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#32679](https://github.com/ClickHouse/ClickHouse/issues/32679) にバックポート: パーツを detach した際に予期せずプロジェクションが削除される問題を修正しました。[#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* [#32543](https://github.com/ClickHouse/ClickHouse/issues/32543) にバックポート: 一部のレプリケーションキューのエントリが、`Directory tmp_merge_<part_name>` や `Part ... (state Deleting) already exists, but it will be deleted soon` などのエラーにより、`temporary_directories_lifetime` (デフォルトでは 1 日) の間ハングする可能性がありました。この問題を修正しました。[#29616](https://github.com/ClickHouse/ClickHouse/issues/29616) を修正。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32769](https://github.com/ClickHouse/ClickHouse/issues/32769) にバックポート: 連番キー使用時の `sparse_hashed` dict の性能問題を修正しました (誤った hash function が使われていました) 。[#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* [#32635](https://github.com/ClickHouse/ClickHouse/issues/32635) にバックポート: DROP TABLE と INSERT が並行して実行された場合のテーブルのライフタイムの問題 (use-after-free の可能性) を修正しました。[#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* [#32633](https://github.com/ClickHouse/ClickHouse/issues/32633) にバックポート: チャネルの作成を遅らせることで、RabbitMQ ストレージの起動時に発生しうる例外を修正しました。[#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32891](https://github.com/ClickHouse/ClickHouse/issues/32891) にバックポート: materialized view のターゲットが JOIN または SET テーブルである場合に発生する LOGICAL&#95;ERROR を修正しました。[#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* [#32792](https://github.com/ClickHouse/ClickHouse/issues/32792) にバックポート: 同じ FixedString を複数回指定して fuzzBits を使用した際にクラッシュする問題を修正し、[#32737](https://github.com/ClickHouse/ClickHouse/issues/32737) をクローズしました。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
