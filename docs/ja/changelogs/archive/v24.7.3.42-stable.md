* [#67969](https://github.com/ClickHouse/ClickHouse/issues/67969)でバックポート: `ALTER ADD COLUMN` クエリ後にサブカラムを読み取れない問題を修正しました。[#66243](https://github.com/ClickHouse/ClickHouse/pull/66243) ([Anton Popov](https://github.com/CurtizJ))。
* [#67637](https://github.com/ClickHouse/ClickHouse/issues/67637)でバックポート: Context::getDDLWorker でまれに発生するデッドロックを修正しました。[#66843](https://github.com/ClickHouse/ClickHouse/pull/66843) ([Alexander Gololobov](https://github.com/davenger))。
* [#67820](https://github.com/ClickHouse/ClickHouse/issues/67820)でバックポート: 並列レプリカ使用時にクエリをキャンセルすると発生しうるデッドロックを修正しました。[#66905](https://github.com/ClickHouse/ClickHouse/pull/66905) ([Nikita Taranov](https://github.com/nickitat))。
* [#67881](https://github.com/ClickHouse/ClickHouse/issues/67881)でバックポート: ファイル名/URI に `::` が含まれていても、アーカイブでない場合は正しく解析されるよう修正しました。[#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368))。
* [#67713](https://github.com/ClickHouse/ClickHouse/issues/67713)でバックポート: UNION を含む SQL UDFs の再読み込みを修正しました。従来は、サーバーを再起動すると UDF が無効になることがありました。[#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368))。
* [#67995](https://github.com/ClickHouse/ClickHouse/issues/67995)でバックポート: ALTER ADD/MODIFY COLUMN で、実験的または疑わしいデータ型を検証するようにしました。[#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar))。

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 重大なバグ修正 (クラッシュ、LOGICAL_ERROR、データ損失、RBAC)
</div>

* [#67818](https://github.com/ClickHouse/ClickHouse/issues/67818)でバックポート: 実験的なVariantデータ型にのみ関連します。Variant + AggregateFunction型でクラッシュする問題を修正しました。[#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar))。
* [#67766](https://github.com/ClickHouse/ClickHouse/issues/67766)でバックポート: `tuple()`引数を使用した`uniq`および`uniqTheta `で発生するクラッシュを修正しました。[#67303](https://github.com/ClickHouse/ClickHouse/issues/67303)をクローズします。[#67306](https://github.com/ClickHouse/ClickHouse/pull/67306) ([flynn](https://github.com/ucasfl))。
* [#67854](https://github.com/ClickHouse/ClickHouse/issues/67854)でバックポート: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026)を修正しました。`ReplaceTableNodeToDummyVisitor`で未解決のテーブル関数引数を走査しないようにしました。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd))。
* [#67840](https://github.com/ClickHouse/ClickHouse/issues/67840)でバックポート: `JSONMergePatch`関数で発生する可能性があるスタックオーバーフローを修正しました。以前の名前が誤っていたため、この関数名を`jsonMergePatch`から`JSONMergePatch`に変更しました。以前の名前も互換性のため引き続き使用できます。関数内のエラー診断も改善しました。これにより[#67304](https://github.com/ClickHouse/ClickHouse/issues/67304)をクローズします。[#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
