  # 2023年の変更履歴
</div>

<div id="clickhouse-release-v232634-stable-570190045b0-fixme-as-compared-to-v232546-stable-b50faecbb12">
  ### ClickHouse リリース v23.2.6.34-stable (570190045b0) FIXME (v23.2.5.46-stable (b50faecbb12) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#48709](https://github.com/ClickHouse/ClickHouse/issues/48709)でバックポート: function formatDateTime() のフォーマッタ &#39;%M&#39; は、分ではなく月名を出力するようになりました。これにより、MySQL と一貫した動作になります。以前の動作は、設定 &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot; を使用すると復元できます。 [#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#48587](https://github.com/ClickHouse/ClickHouse/issues/48587)でバックポート: タイムゾーンを更新。更新対象は次のとおりです: Africa/Cairo, Africa/Casablanca, Africa/El&#95;Aaiun, America/Bogota, America/Cambridge&#95;Bay, America/Ciudad&#95;Juarez, America/Godthab, America/Inuvik, America/Iqaluit, America/Nuuk, America/Ojinaga, America/Pangnirtung, America/Rankin&#95;Inlet, America/Resolute, America/Whitehorse, America/Yellowknife, Asia/Gaza, Asia/Hebron, Asia/Kuala&#95;Lumpur, Asia/Singapore, Canada/Yukon, Egypt, Europe/Kirov, Europe/Volgograd, Singapore. [#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#48959](https://github.com/ClickHouse/ClickHouse/issues/48959)でバックポート: 最近の更新後、`dockerd` では http ポートを明示的に指定し、あわせて `--tlsverify=false` を指定する必要があります。 [#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* limit 指定時の Grace Hash Join における競合状態を修正 [#47153](https://github.com/ClickHouse/ClickHouse/pull/47153) ([Vladimir C](https://github.com/vdimir)).
* projection を含む explain graph を修正 [#47473](https://github.com/ClickHouse/ClickHouse/pull/47473) ([flynn](https://github.com/ucasfl)).
* polygonsSymDifferenceCartesian で発生するクラッシュを修正 [#47702](https://github.com/ClickHouse/ClickHouse/pull/47702) ([pufit](https://github.com/pufit)).
* ある機能を削除 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* rabbitmq での CPU usage を修正 ([#44404](https://github.com/ClickHouse/ClickHouse/issues/44404) 以降、23.2 で悪化していたもの)  [#48311](https://github.com/ClickHouse/ClickHouse/pull/48311) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Dictionary に依存する分散テーブルのロード時に発生する ClickHouse 起動エラー [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* cache で発生しうる segfault を修正 [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* IP 型および UUID 型のキーを持つネストした Map を修正 [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* ACL で認証スキーム `auth` を指定していても、ノードが作成されないことがある Keeper の bug を修正 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* IPv4 を UInt と比較可能にする修正 [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
