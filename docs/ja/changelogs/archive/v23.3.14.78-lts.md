<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#54312](https://github.com/ClickHouse/ClickHouse/issues/54312)でバックポート: [#47151](https://github.com/ClickHouse/ClickHouse/issues/47151) の後に発生していた QEMU の奇妙な追加ログ出力を修正しました。詳しくは [https://s3.amazonaws.com/clickhouse-test-reports/50078/a4743996ee4f3583884d07bcd6501df0cfdaa346/stateless&#95;tests&#95;&#95;release&#95;&#95;databasereplicated&#95;&#95;](https://s3.amazonaws.com/clickhouse-test-reports/50078/a4743996ee4f3583884d07bcd6501df0cfdaa346/stateless_tests__release__databasereplicated__)[3&#95;4].html を参照してください。[#50442](https://github.com/ClickHouse/ClickHouse/pull/50442) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55391](https://github.com/ClickHouse/ClickHouse/issues/55391)でバックポート: サブモジュールを含むソースコード一式を含むリソースを、Darwin 向けの特別なビルドタスクでビルドするようにしました。これにより、サブモジュールをチェックアウトしなくても ClickHouse をビルドできます。[#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* [#54703](https://github.com/ClickHouse/ClickHouse/issues/54703)でバックポート: プルリクエストで変更されていないイメージについて、master の最新タグで `changed_images.json` を補完します。[#54369](https://github.com/ClickHouse/ClickHouse/pull/54369) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#54679](https://github.com/ClickHouse/ClickHouse/issues/54679)でバックポート: これらはプッシュのたびにビルドしてアップロードしていますが、その価値はありません。[#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* CTE を含み、複数回使用されるパラメーター化ビューの不具合を修正 [#52328](https://github.com/ClickHouse/ClickHouse/pull/52328) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* OptimizedRegularExpression の再帰深度をチェックするように修正 [#52451](https://github.com/ClickHouse/ClickHouse/pull/52451) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* PROJECTION の drop 後に発生する論理削除の不具合を修正 [#52517](https://github.com/ClickHouse/ClickHouse/pull/52517) ([Anton Popov](https://github.com/CurtizJ)).
* 大きな LIMIT でのスパースなカラムのソートを修正 [#52827](https://github.com/ClickHouse/ClickHouse/pull/52827) ([Anton Popov](https://github.com/CurtizJ)).
* DateTime へのサブ秒インターバルの加算を修正 [#53309](https://github.com/ClickHouse/ClickHouse/pull/53309) ([Michael Kolupaev](https://github.com/al13n321)).
* bloom filter で IPv6 を許可するよう修正 [#54200](https://github.com/ClickHouse/ClickHouse/pull/54200) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `analysisOfVariance` 関数で、加算前にオーバーフローをチェックするよう修正 [#54385](https://github.com/ClickHouse/ClickHouse/pull/54385) ([Antonio Andelic](https://github.com/antonio2368)).
* removeSharedRecursive のバグを再現し、修正 [#54430](https://github.com/ClickHouse/ClickHouse/pull/54430) ([Sema Checherinda](https://github.com/CheSema)).
* 正規化された state を持つ集約PROJECTIONを修正 [#54480](https://github.com/ClickHouse/ClickHouse/pull/54480) ([Amos Bird](https://github.com/amosbird)).
* input&#95;format&#95;with&#95;names&#95;use&#95;header が無効な場合に、WithNames フォーマットで発生しうるパースエラーを修正 [#54513](https://github.com/ClickHouse/ClickHouse/pull/54513) ([Kruglov Pavel](https://github.com/Avogar)).
* MaterializedPostgreSQL で発生する &quot;Invalid number of rows in Chunk&quot; を修正 [#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 異なるPROJECTIONまたはインデックスを持つテーブルからのパーツの Attach を防止 [#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* ゴミ箱最適化を修正 (一定範囲まで)  [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* CAST 演算子における Array のパースを修正 [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
