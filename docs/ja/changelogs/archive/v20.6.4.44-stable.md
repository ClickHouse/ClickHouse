  ### ClickHouse リリース v20.6.4.44-stable FIXME (v20.6.3.28-stable との比較)

<div id="improvement">
  #### 改善
</div>

* [#13919](https://github.com/ClickHouse/ClickHouse/issues/13919) でバックポート: `lgamma` 関数のデータレースを修正しました。このデータレースは `tsan` でのみ検出され、実際には副作用はまったく発生していませんでした。[#13842](https://github.com/ClickHouse/ClickHouse/pull/13842) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#13560](https://github.com/ClickHouse/ClickHouse/issues/13560)でバックポート: 一度接続が切断されると、その後 Redis dictionary にアクセスできなくなる問題を修正しました。この問題は `cache` および `direct` の辞書レイアウトで発生する可能性があります。[#13082](https://github.com/ClickHouse/ClickHouse/pull/13082) ([Anton Popov](https://github.com/CurtizJ))。
* [#13507](https://github.com/ClickHouse/ClickHouse/issues/13507)でバックポート: データベース名またはテーブル名にドットが含まれている場合に、users.xml から行ポリシーをパースできない問題を修正しました。これにより [#5779](https://github.com/ClickHouse/ClickHouse/issues/5779)、[#12527](https://github.com/ClickHouse/ClickHouse/issues/12527) を修正します。[#13199](https://github.com/ClickHouse/ClickHouse/pull/13199) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#13357](https://github.com/ClickHouse/ClickHouse/issues/13357)でバックポート: AvroConfluent: Kafka の tombstone レコードをスキップ。AvroConfluent: 壊れたレコードのスキップをサポート。... [#13203](https://github.com/ClickHouse/ClickHouse/pull/13203) ([Andrew Onyshchuk](https://github.com/oandrew))。
* [#13350](https://github.com/ClickHouse/ClickHouse/issues/13350)でバックポート: roundUpToPowerOfTwoOrZero() で、MSB がセットされた数値に対して入力値をそのまま返すよう修正しました。[#13234](https://github.com/ClickHouse/ClickHouse/pull/13234) ([Azat Khuzhin](https://github.com/azat))。
* [#13479](https://github.com/ClickHouse/ClickHouse/issues/13479)でバックポート: 定数カラムを含み、主キーの `ORDER BY` プレフィックスを使用するクエリの問題を修正しました。[#13396](https://github.com/ClickHouse/ClickHouse/pull/13396) ([Anton Popov](https://github.com/CurtizJ))。
* [#13487](https://github.com/ClickHouse/ClickHouse/issues/13487)でバックポート: クエリが 0 行を返す場合に `Arrow` および `Parquet` フォーマットで出力が空になる問題を修正しました。空の出力はこれらのフォーマットでは有効でないためです。[#13399](https://github.com/ClickHouse/ClickHouse/pull/13399) ([hcz](https://github.com/hczhcz))。
* [#13524](https://github.com/ClickHouse/ClickHouse/issues/13524)でバックポート: `StorageMemory` で発生しうる競合状態を修正しました。[https://clickhouse-test-reports.s3.yandex.net/0/9cac8a7244063d2092ad25d45502611e18d3749c/stress&#95;test&#95;(thread)/stderr.log](https://clickhouse-test-reports.s3.yandex.net/0/9cac8a7244063d2092ad25d45502611e18d3749c/stress_test_\(thread\)/stderr.log) テストの書き方がまったく分かりません。[#13416](https://github.com/ClickHouse/ClickHouse/pull/13416) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#13483](https://github.com/ClickHouse/ClickHouse/issues/13483)でバックポート: `NULL` 要素を含むタプルの比較で、無効な戻り値の型になる問題を修正しました。[#12461](https://github.com/ClickHouse/ClickHouse/issues/12461) を修正します。[#13420](https://github.com/ClickHouse/ClickHouse/pull/13420) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#13462](https://github.com/ClickHouse/ClickHouse/issues/13462)でバックポート: Unix timestamp が引数として渡された場合に `parseDateTimeBestEffort` 関数で発生するエラーを修正しました。これにより [#13362](https://github.com/ClickHouse/ClickHouse/issues/13362) を修正します。[#13441](https://github.com/ClickHouse/ClickHouse/pull/13441) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#13552](https://github.com/ClickHouse/ClickHouse/issues/13552)でバックポート: compact パーツにおけるセカンダリ索引の破損を修正しました。[#13538](https://github.com/ClickHouse/ClickHouse/pull/13538) ([Anton Popov](https://github.com/CurtizJ))。
* [#13662](https://github.com/ClickHouse/ClickHouse/issues/13662) でバックポート: 同時実行の `ALTER ... REPLACE/MOVE PARTITION ...` クエリがデッドロックを引き起こす可能性がありました。修正済みです。[#13626](https://github.com/ClickHouse/ClickHouse/pull/13626) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#13720](https://github.com/ClickHouse/ClickHouse/issues/13720) でバックポート: StorageMerge と `set enable_optimize_predicate_expression=1` を使用した JOIN で発生するクラッシュを修正しました。[#13679](https://github.com/ClickHouse/ClickHouse/pull/13679) ([Artem Zuikov](https://github.com/4ertus2)).
* [#13703](https://github.com/ClickHouse/ClickHouse/issues/13703) でバックポート: optimize&#95;move&#95;functions&#95;out&#95;of&#95;any 有効時に any(arrayJoin()) -&gt; arrayJoin() の最適化を行わないようにしました。[#13681](https://github.com/ClickHouse/ClickHouse/pull/13681) ([Azat Khuzhin](https://github.com/azat)).
* [#13733](https://github.com/ClickHouse/ClickHouse/issues/13733) でバックポート: ユーザーとグループの確認時に `clickhouse-server.init` で表示される不正確なメッセージを修正しました。[#13711](https://github.com/ClickHouse/ClickHouse/pull/13711) ([ylchou](https://github.com/ylchou)).
* [#13902](https://github.com/ClickHouse/ClickHouse/issues/13902) でバックポート: `FixedString` カラムの誤ったソートを修正しました。[#13182](https://github.com/ClickHouse/ClickHouse/issues/13182) を修正。[#13887](https://github.com/ClickHouse/ClickHouse/pull/13887) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
