  ### ClickHouse リリース v20.11.1.5109-prestable FIXME (v20.10.1.4881-prestable と比較して)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* データが不十分な場合、`rankCorr` 関数が nan を返すようにしました。 [#16124](https://github.com/ClickHouse/ClickHouse/issues/16124)。 [#16135](https://github.com/ClickHouse/ClickHouse/pull/16135) ([hexiaoting](https://github.com/hexiaoting))。
* 集約関数 `boundingRatio`、`rankCorr`、`retention`、`timeSeriesGroupSum`、`timeSeriesGroupRateSum`、`windowFunnel` は、誤って大文字と小文字を区別しないようになっていました。現在は、設計どおりこれらの名前で大文字と小文字を区別するようにしています。大文字と小文字を区別しないべきなのは、SQL 標準で定義されている関数、他の DBMS との互換性のために作られた関数、またはそれらに類似する関数だけです。 [#16407](https://github.com/ClickHouse/ClickHouse/pull/16407) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* `ANALYZE` および `AST` クエリを削除し、設定 `enable_debug_queries` を廃止しました。これは、現在ではフル機能を備えた `EXPLAIN` クエリの一部になったためです。 [#16536](https://github.com/ClickHouse/ClickHouse/pull/16536) ([Ivan](https://github.com/abyss7))。
* 比較できないデータ型 (`AggregateFunction` など) をキー (ソートキー、主キー、パーティションキーなど) で使用することを制限しました。 [#16601](https://github.com/ClickHouse/ClickHouse/pull/16601) ([alesapin](https://github.com/alesapin))。
* `distributed_ddl` 設定セクションで `profile` を指定すると、その `profile` がサーバー起動時に `default` profile の設定を上書きできていました。この問題を修正し、分散 DDL クエリの設定がサーバー全体の設定に影響しないようになりました。 [#16635](https://github.com/ClickHouse/ClickHouse/pull/16635) ([Alexander Tokmakov](https://github.com/tavplubix))。

* CREATE TABLE クエリのカラム一覧で主キーを指定できるようにしました。[#15823](https://github.com/ClickHouse/ClickHouse/pull/15823) ([Maksim Kita](https://github.com/kitaisreal)).
* 設定 `date&#95;time&#95;output&#95;format` を追加しました。[#15845](https://github.com/ClickHouse/ClickHouse/pull/15845) ([Maksim Kita](https://github.com/kitaisreal)).
* ORDER BY を伴う SELECT クエリで `OFFSET offset_row_count {ROW | ROWS} FETCH {FIRST | NEXT} fetch_row_count {ROW | ROWS} {ONLY | WITH TIES}` を実装しました。関連 issue: [#15367](https://github.com/ClickHouse/ClickHouse/issues/15367)。[#15855](https://github.com/ClickHouse/ClickHouse/pull/15855) ([hexiaoting](https://github.com/hexiaoting)).

* named tuple をフラット化して SELECT リストに新しいカラムを追加できる特別な関数 `untuple` を追加しました。[#16242](https://github.com/ClickHouse/ClickHouse/pull/16242) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `toUUIDOrNull`、`toUUIDOrZero` の CAST 関数を追加しました。[#16337](https://github.com/ClickHouse/ClickHouse/pull/16337) ([Maksim Kita](https://github.com/kitaisreal)).
* 現在実行中のバックグラウンドフェッチを表示する `system.replicated_fetches` テーブルを追加しました。[#16428](https://github.com/ClickHouse/ClickHouse/pull/16428) ([alesapin](https://github.com/alesapin)).
* * `errorCodeToName()` function - error の変数名を返します (`query_log` などの分析に役立ちます)  - `system.errors` table - error の発生回数を表示します (`system_events_show_zero_values` に従います) 。 [#16438](https://github.com/ClickHouse/ClickHouse/pull/16438) ([Azat Khuzhin](https://github.com/azat)).

* > farmFingerprint64関数を追加しました。 [#16570](https://github.com/ClickHouse/ClickHouse/pull/16570) ([Jacob Hayes](https://github.com/JacobHayes)).
* Identifier をクエリパラメータで指定できるようになりました。これらのパラメータは、テーブルオブジェクトやカラムとして使用できます。 [#3815](https://github.com/ClickHouse/ClickHouse/issues/3815). [#16594](https://github.com/ClickHouse/ClickHouse/pull/16594) ([Amos Bird](https://github.com/amosbird)).
* MergeTree BloomFilter 索引で、大きな整数型 (UInt256、Int128、Int256) および UUID データ型がサポートされるようになりました。 [#16642](https://github.com/ClickHouse/ClickHouse/pull/16642) ([Maksim Kita](https://github.com/kitaisreal)).
