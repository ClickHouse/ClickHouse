  ### ClickHouse リリース v23.3.3.52-lts (cb963c474db) FIXME、v23.3.2.37-lts (1b144bcd101) との比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#49954](https://github.com/ClickHouse/ClickHouse/issues/49954) でバックポート: `IN` 演算子の引数が単一要素のタプルである (まれな) ケースのサポートを追加しました。[#49844](https://github.com/ClickHouse/ClickHouse/pull/49844) ([MikhailBurdukov](https://github.com/MikhailBurdukov))。

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#49210](https://github.com/ClickHouse/ClickHouse/issues/49210) でバックポート: glibc の互換性チェックを修正し、musl の `preadv` を置き換えました。[#49144](https://github.com/ClickHouse/ClickHouse/pull/49144) ([alesapin](https://github.com/alesapin))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* 集計の空文字列エラーを修正 [#48999](https://github.com/ClickHouse/ClickHouse/pull/48999) ([LiuNeng](https://github.com/liuneng1994)).
* 複数の StorageJoin を使用するクエリでキーが見つからないエラーを修正 [#49137](https://github.com/ClickHouse/ClickHouse/pull/49137) ([vdimir](https://github.com/vdimir)).
* 古いパーツの読み込み時の競合状態を修正 [#49223](https://github.com/ClickHouse/ClickHouse/pull/49223) ([Alexander Tokmakov](https://github.com/tavplubix)).
* DISTINCT のバグを修正 [#49628](https://github.com/ClickHouse/ClickHouse/pull/49628) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* randomStringUTF8(<奇数>) における msan の問題を修正 [#49750](https://github.com/ClickHouse/ClickHouse/pull/49750) ([Robert Schulze](https://github.com/rschu1ze)).
* OptimizeRegularExpression における `is_prefix` を修正 [#49919](https://github.com/ClickHouse/ClickHouse/pull/49919) ([Han Fei](https://github.com/hanfei1991)).
* Protobuf における IPv6 エンコーディングを修正 [#49933](https://github.com/ClickHouse/ClickHouse/pull/49933) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* `ReplicatedMergeTree` のアタッチスレッドでテーブルを起動する際のデッドロックを回避 [#50026](https://github.com/ClickHouse/ClickHouse/pull/50026) ([Antonio Andelic](https://github.com/antonio2368)).
* JIT コンパイルにおける NaN の不等値比較を修正 [#50056](https://github.com/ClickHouse/ClickHouse/pull/50056) ([Maksim Kita](https://github.com/kitaisreal)).
* `multiIf` で定数条件および Nullable な引数を使用した際のクラッシュを修正 [#50123](https://github.com/ClickHouse/ClickHouse/pull/50123) ([Anton Popov](https://github.com/CurtizJ)).
* 接続先ホストの IP が変更された際の HTTPS セッションの再接続を修正 [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* DateTime64 索引を使用したクエリ実行時における Date/Date32 から DateTime64 への型変換を修正 [#50280](https://github.com/ClickHouse/ClickHouse/pull/50280) ([Lucas Chang](https://github.com/lucas-tubi)).
* リクエストの前処理中に例外が発生した際の Keeper のデッドロックを修正 [#50387](https://github.com/ClickHouse/ClickHouse/pull/50387) ([frinkr](https://github.com/frinkr)).
* 不正な定数畳み込みを修正 [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Log ファミリーテーブルがトランケート後に誤った行数を返す問題を修正 [#50585](https://github.com/ClickHouse/ClickHouse/pull/50585) ([flynn](https://github.com/ucasfl)).
* `uniqExact` の並列マージにおけるバグを修正 [#50590](https://github.com/ClickHouse/ClickHouse/pull/50590) ([Nikita Taranov](https://github.com/nickitat)).
* GLOBAL JOIN の右テーブルからすべてのカラムを読み込まないように修正 [#50721](https://github.com/ClickHouse/ClickHouse/pull/50721) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
