<div id="clickhouse-release-v215821-stable-fixme-as-compared-to-v21579-stable">
  ### ClickHouse リリース v21.5.8.21-stable FIXME (v21.5.7.9-stable との比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#25849](https://github.com/ClickHouse/ClickHouse/issues/25849) でバックポート: `Date` から `DateTime` (または `DateTime64`) への `CAST` で、`DateTime` 型のタイムゾーンが使用されていませんでした。これは `Date` と `DateTime` の比較にも影響する可能性があります。また、`Date` と `DateTime` の共通型の推論でも、対応するタイムゾーンが使用されていませんでした。その結果、関数 `if` および配列構築の結果に影響が出ていました。[#24128](https://github.com/ClickHouse/ClickHouse/issues/24128) をクローズしました。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25679](https://github.com/ClickHouse/ClickHouse/issues/25679) でバックポート: 乱数生成器の state のデシリアライゼーションにおけるバグを修正しました。このバグにより、`AggregateFunction(groupArraySample(N), T))` などの一部のデータ型が非決定論的に振る舞う可能性がありました。[#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25556](https://github.com/ClickHouse/ClickHouse/issues/25556) でバックポート: 他の集約関数の集約関数状態をさらに集約して集約関数状態を計算する際に発生しうるクラッシュを修正しました (実用的なユースケースではありません) 。[#24523](https://github.com/ClickHouse/ClickHouse/issues/24523) を参照してください。[#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#25767](https://github.com/ClickHouse/ClickHouse/issues/25767) でバックポート: 非 uint8 型の PREWHERE で発生するアサーションを修正し、[#19589](https://github.com/ClickHouse/ClickHouse/issues/19589) をクローズしました。[#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* [#25636](https://github.com/ClickHouse/ClickHouse/issues/25636) でバックポート: クエリ `WITH TOTALS` および `WITH FILL` における誤った totals を修正しました。[#20872](https://github.com/ClickHouse/ClickHouse/issues/20872) を修正しました。[#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* [#25653](https://github.com/ClickHouse/ClickHouse/issues/25653) でバックポート: クエリなしの `EXPLAIN AST` で発生する null pointer dereference を修正しました。[#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25715](https://github.com/ClickHouse/ClickHouse/issues/25715) でバックポート: まれに、ソースパーティションが空の場合に `REPLACE PARTITION` が無視されることがありましたが、これを修正しました。[#24869](https://github.com/ClickHouse/ClickHouse/issues/24869) を修正しました。[#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25695](https://github.com/ClickHouse/ClickHouse/issues/25695) でバックポート: `Distributed` table を database 間で移動する際に発生する `No such file or directory` error を修正しました。[#24971](https://github.com/ClickHouse/ClickHouse/issues/24971) を修正しました。[#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25754](https://github.com/ClickHouse/ClickHouse/issues/25754) でバックポート: `system.clusters` をクエリしている最中に同時にクラスター configuration を再読み込みすると発生する data race を修正しました。[#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)).
