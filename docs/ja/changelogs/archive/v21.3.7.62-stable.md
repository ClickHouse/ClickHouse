  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v213762-stable-fixme-as-compared-to-v213655-lts">
  ### ClickHouse リリース v21.3.7.62-stable FIXME (v21.3.6.55-ltsとの比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#23014](https://github.com/ClickHouse/ClickHouse/issues/23014) でバックポート: 頻繁に小規模な挿入が行われる場合や ZooKeeper クラスターが低速な本番環境での利用により適するよう、`background_fetches_pool_size` を 8 に設定しました。[#22945](https://github.com/ClickHouse/ClickHouse/pull/22945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23081](https://github.com/ClickHouse/ClickHouse/issues/23081) でバックポート: 関数 `extractAllGroupsHorizontal` の結果における最大一致数のしきい値を引き上げました。[#23036](https://github.com/ClickHouse/ClickHouse/pull/23036) ([Vasily Nemkov](https://github.com/Enmk)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#23156](https://github.com/ClickHouse/ClickHouse/issues/23156)でバックポート: 補助的な AWS リクエストで待機時間が無制限になるバグを修正しました。[#22594](https://github.com/ClickHouse/ClickHouse/pull/22594) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#23033](https://github.com/ClickHouse/ClickHouse/issues/23033)でバックポート: サブクエリで `untuple` を使用した場合に発生することがある `Cannot find column in ActionsDAG result` エラーを修正しました。[#22290](https://github.com/ClickHouse/ClickHouse/issues/22290) を修正。[#22991](https://github.com/ClickHouse/ClickHouse/pull/22991) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23075](https://github.com/ClickHouse/ClickHouse/issues/23075)でバックポート: clickhouse-client の候補表示から重要でない詳細情報を削除しました。これにより [#22158](https://github.com/ClickHouse/ClickHouse/issues/22158) をクローズしました。[#23040](https://github.com/ClickHouse/ClickHouse/pull/23040) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23170](https://github.com/ClickHouse/ClickHouse/issues/23170)でバックポート: `Markdown` フォーマットで、一部の値がテーブルセル内で中央揃えで整形されていましたが、そうならないようにしました。[#23096](https://github.com/ClickHouse/ClickHouse/pull/23096) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
