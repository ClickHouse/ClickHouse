<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#39097](https://github.com/ClickHouse/ClickHouse/issues/39097) でバックポート: OvercommitTracker 内でメモリ割り当てが発生すると、デッドロックにつながる可能性があります。ログはあまり有益ではなかったため、ログ出力を削除しました。[#37794](https://github.com/ClickHouse/ClickHouse/issues/37794) を修正しました。[#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd))。
* [#39080](https://github.com/ClickHouse/ClickHouse/issues/39080) でバックポート: キャッシュ容量が上限に達するタイミングと重なった一部のコーナーケースで発生し得る、ファイルシステムキャッシュのバグを修正しました。[#39066](https://github.com/ClickHouse/ClickHouse/issues/39066) をクローズしました。[#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#39149](https://github.com/ClickHouse/ClickHouse/issues/39149) でバックポート: アタッチされた MATERIALIZED VIEW があり、設定 `extremes = 1` が有効な table への INSERT で発生し得るエラー `Block structure mismatch` を修正しました。[#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) と [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729) をクローズしました。[#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#39372](https://github.com/ClickHouse/ClickHouse/issues/39372) でバックポート: デフォルト引数 `x-max-length` および `x-overflow` なしで RabbitMQ キューを宣言するようにしました。[#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko))。
* [#39379](https://github.com/ClickHouse/ClickHouse/issues/39379) でバックポート: レプリケーションの初期化時に何らかの例外が発生した場合に起こり得る、MaterializedPostgreSQL データベースエンジンのセグメンテーション違反を修正しました。[#36939](https://github.com/ClickHouse/ClickHouse/issues/36939) をクローズしました。[#39272](https://github.com/ClickHouse/ClickHouse/pull/39272) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#39351](https://github.com/ClickHouse/ClickHouse/issues/39351) でバックポート: PostgreSQL データベースエンジンで PostgreSQL の table を取得するクエリの誤りを修正しました。[#33502](https://github.com/ClickHouse/ClickHouse/issues/33502) をクローズしました。[#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii))。

<div id="not-for-changelog-insignificant">
  #### 変更履歴対象外 / 軽微

* 待機時間を段階的に延ばしながら、docker buildx コマンドを再試行するようにした。 [#38898](https://github.com/ClickHouse/ClickHouse/pull/38898) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
