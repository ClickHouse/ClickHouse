* [#61591](https://github.com/ClickHouse/ClickHouse/issues/61591) にバックポート: ActionsDAG::split で、「block に対して最初のパーツ、次に 2 番目のパーツを実行した結果が、元の DAG の実行結果と等価である」ことを保証できない問題を修正しました。[#61458](https://github.com/ClickHouse/ClickHouse/pull/61458) ([Raúl Marín](https://github.com/Algunenano))。
* [#61648](https://github.com/ClickHouse/ClickHouse/issues/61648) にバックポート: 互換性設定で async&#95;insert&#95;use&#95;adaptive&#95;busy&#95;timeout を正しく無効化できるよう修正しました。[#61468](https://github.com/ClickHouse/ClickHouse/pull/61468) ([Raúl Marín](https://github.com/Algunenano))。
* [#61748](https://github.com/ClickHouse/ClickHouse/issues/61748) にバックポート: UUID を使用して `system.parts` または `system.parts_columns` をフィルタリングしたときに、誤った結果になる問題を修正しました。[#61479](https://github.com/ClickHouse/ClickHouse/pull/61479) ([Dan Wu](https://github.com/wudanzy))。
* [#61963](https://github.com/ClickHouse/ClickHouse/issues/61963) にバックポート: `ALTER QUERY MODIFY SQL SECURITY` クエリがテーブルの DDL を正しく上書きするよう修正しました。[#61480](https://github.com/ClickHouse/ClickHouse/pull/61480) ([pufit](https://github.com/pufit))。
* [#61699](https://github.com/ClickHouse/ClickHouse/issues/61699) にバックポート: `clickhouse-client -s` 引数を修正しました。二重に定義されていたため壊れていました。[#61530](https://github.com/ClickHouse/ClickHouse/pull/61530) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* [#61578](https://github.com/ClickHouse/ClickHouse/issues/61578) にバックポート: 開始位置が定数の文字列検索で、以前はメモリ破損につながる可能性があった問題を修正しました。[#61547](https://github.com/ClickHouse/ClickHouse/pull/61547) ([Antonio Andelic](https://github.com/antonio2368))。
* [#62531](https://github.com/ClickHouse/ClickHouse/issues/62531) にバックポート: `MOVE PARTITION` クエリとマージ処理の間のデータ競合により、交差するパーツが生じる問題を修正しました。[#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin))。
* [#61860](https://github.com/ClickHouse/ClickHouse/issues/61860) にバックポート: 不正な UTF-8 シーケンスを指定した場合に `multiSearchAllPositionsCaseInsensitiveUTF8` でクラッシュが発生する問題を修正しました。例: [#61714](https://github.com/ClickHouse/ClickHouse/issues/61714#issuecomment-2012768202)。[#61749](https://github.com/ClickHouse/ClickHouse/pull/61749) ([pufit](https://github.com/pufit))。
* [#62242](https://github.com/ClickHouse/ClickHouse/issues/62242) にバックポート: `input_format_allow_errors_num/ratio` 設定の使用時に、JSON データのパース中にエスケープシーケンスのパースエラーがスキップされてしまう問題を修正しました。[#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar))。
* [#62218](https://github.com/ClickHouse/ClickHouse/issues/62218) にバックポート: Row Policy に式がない場合に Engine Merge がクラッシュする問題を修正しました。[#61971](https://github.com/ClickHouse/ClickHouse/pull/61971) ([Ilya Golshtein](https://github.com/ilejn)).
* [#62342](https://github.com/ClickHouse/ClickHouse/issues/62342) にバックポート: Context 内のスカラーにおけるデータ競合を修正しました。[#62305](https://github.com/ClickHouse/ClickHouse/pull/62305) ([Kruglov Pavel](https://github.com/Avogar)).
* [#62677](https://github.com/ClickHouse/ClickHouse/issues/62677) にバックポート: Hive table engine 使用時に発生するセグメンテーションフォールトを修正しました。参考: [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154), [#62560](https://github.com/ClickHouse/ClickHouse/issues/62560)。[#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#62639](https://github.com/ClickHouse/ClickHouse/issues/62639) にバックポート: groupArraySorted のメモリリークを修正しました。[#62536](https://github.com/ClickHouse/ClickHouse/issues/62536) を修正。[#62597](https://github.com/ClickHouse/ClickHouse/pull/62597) ([Antonio Andelic](https://github.com/antonio2368)).
* [#63054](https://github.com/ClickHouse/ClickHouse/issues/63054) にバックポート: サーバークラッシュにつながる可能性がある GCD codec 実装のバグを修正しました。[#62853](https://github.com/ClickHouse/ClickHouse/pull/62853) ([Nikita Taranov](https://github.com/nickitat)).

* [#63142](https://github.com/ClickHouse/ClickHouse/issues/63142) にバックポート: 関数 `abs` の単調性判定が誤っている問題を修正しました。[#63097](https://github.com/ClickHouse/ClickHouse/pull/63097) ([Duc Canh Le](https://github.com/canhld94)).
