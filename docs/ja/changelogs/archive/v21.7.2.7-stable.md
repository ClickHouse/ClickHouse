<div id="improvement">

* [#25881](https://github.com/ClickHouse/ClickHouse/issues/25881) にバックポート: 読み取り不可の作業ディレクトリでも clickhouse-client を起動できるようにしました。 [#25817](https://github.com/ClickHouse/ClickHouse/pull/25817) ([ianton-ru](https://github.com/ianton-ru)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#25833](https://github.com/ClickHouse/ClickHouse/issues/25833) にバックポート: `Date` から `DateTime` (または `DateTime64`) への `CAST` で、`DateTime` 型の timezone が使われていませんでした。これは `Date` と `DateTime` の比較にも影響する可能性があります。また、`Date` と `DateTime` の共通型の推論でも、対応する timezone が使われていませんでした。そのため、関数 `if` と配列構築の結果に影響していました。[#24128](https://github.com/ClickHouse/ClickHouse/issues/24128) をクローズ。 [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25766](https://github.com/ClickHouse/ClickHouse/issues/25766) にバックポート: PREWHERE で非 uint8 型を使用した場合のアサーションを修正。[#19589](https://github.com/ClickHouse/ClickHouse/issues/19589) をクローズ。 [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* [#25954](https://github.com/ClickHouse/ClickHouse/issues/25954) にバックポート: 有効期限 (TTL) 式に含まれるカラムに対する `ALTER MODIFY COLUMN` を修正。 [#25554](https://github.com/ClickHouse/ClickHouse/pull/25554) ([Anton Popov](https://github.com/CurtizJ)).
* [#25871](https://github.com/ClickHouse/ClickHouse/issues/25871) にバックポート: `ReplicatedMergeTree` テーブルに対する `DROP PART` クエリで、まれに `Unexpected merged part intersecting drop range` というエラーメッセージが発生する不具合を修正。 [#25783](https://github.com/ClickHouse/ClickHouse/pull/25783) ([alesapin](https://github.com/alesapin)).
* [#25886](https://github.com/ClickHouse/ClickHouse/issues/25886) にバックポート: デフォルト以外のページサイズでの ARM の Exception 処理を修正。[#25512](https://github.com/ClickHouse/ClickHouse/issues/25512) を修正。[#25044](https://github.com/ClickHouse/ClickHouse/issues/25044) を修正。[#24901](https://github.com/ClickHouse/ClickHouse/issues/24901) を修正。[#23183](https://github.com/ClickHouse/ClickHouse/issues/23183) を修正。[#20221](https://github.com/ClickHouse/ClickHouse/issues/20221) を修正。[#19703](https://github.com/ClickHouse/ClickHouse/issues/19703) を修正。[#19028](https://github.com/ClickHouse/ClickHouse/issues/19028) を修正。[#18391](https://github.com/ClickHouse/ClickHouse/issues/18391) を修正。[#18121](https://github.com/ClickHouse/ClickHouse/issues/18121) を修正。[#17994](https://github.com/ClickHouse/ClickHouse/issues/17994) を修正。[#12483](https://github.com/ClickHouse/ClickHouse/issues/12483) を修正。 [#25854](https://github.com/ClickHouse/ClickHouse/pull/25854) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25957](https://github.com/ClickHouse/ClickHouse/issues/25957) にバックポート: background pool がいっぱいのときに、バックグラウンドタスクの backoff が極端に長くなる問題を修正。[#25836](https://github.com/ClickHouse/ClickHouse/issues/25836) を修正。 [#25893](https://github.com/ClickHouse/ClickHouse/pull/25893) ([alesapin](https://github.com/alesapin)).
* [#25932](https://github.com/ClickHouse/ClickHouse/issues/25932) にバックポート: 不正な argument で dictGet() を呼び出した際の crash を修正。 [#25913](https://github.com/ClickHouse/ClickHouse/pull/25913) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#25981](https://github.com/ClickHouse/ClickHouse/issues/25981) にバックポート: クエリプロファイラのスタック巻き戻し中に発生する可能性があるデッドロックを修正。[#25968](https://github.com/ClickHouse/ClickHouse/issues/25968) を修正。 [#25970](https://github.com/ClickHouse/ClickHouse/pull/25970) ([Maksim Kita](https://github.com/kitaisreal)).
* [#26010](https://github.com/ClickHouse/ClickHouse/issues/26010) にバックポート: 整数キーを持つ型 `Map` の `JSON` へのフォーマットの不具合を修正しました。[#25982](https://github.com/ClickHouse/ClickHouse/pull/25982) ([Anton Popov](https://github.com/CurtizJ)).
* [#26097](https://github.com/ClickHouse/ClickHouse/issues/26097) にバックポート: 一部のケースで、右側サブクエリとの join におけるスレッド数の見積もりが誤っていた問題を修正しました。[#24075](https://github.com/ClickHouse/ClickHouse/issues/24075) をクローズしました。[#26052](https://github.com/ClickHouse/ClickHouse/pull/26052) ([Vladimir C](https://github.com/vdimir)).
