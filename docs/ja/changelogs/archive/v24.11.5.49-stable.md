<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#75811](https://github.com/ClickHouse/ClickHouse/issues/75811)でバックポート: クライアントとサーバー間の通信で Native フォーマットの設定が正しく伝播されるよう修正しました。 [#73924](https://github.com/ClickHouse/ClickHouse/pull/73924) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74090](https://github.com/ClickHouse/ClickHouse/issues/74090)でバックポート: 暗黙的な権限を修正しました (以前はワイルドカードとして機能していました) 。 [#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* [#75556](https://github.com/ClickHouse/ClickHouse/issues/75556)でバックポート: macOS 上の PostgreSQL interface で `INSERT INTO SELECT` クエリを実行した際に発生するクラッシュを修正しました (issue [#72938](https://github.com/ClickHouse/ClickHouse/issues/72938)) 。 [#74231](https://github.com/ClickHouse/ClickHouse/pull/74231) ([Artem Yurov](https://github.com/ArtemYurov)).
* [#75630](https://github.com/ClickHouse/ClickHouse/issues/75630)でバックポート: PSQL レプリケーションで、未捕捉の例外によって発生するクラッシュを修正しました。 [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* [#76103](https://github.com/ClickHouse/ClickHouse/issues/76103)でバックポート: LowCardinality Nullable データ型に対する NULL セーフな JOIN 処理を修正しました。以前は、`IS NOT DISTINCT FROM`、`<=>`、`a IS NULL AND b IS NULL OR a == b` のような NULL セーフ比較を使う JOIN ON が、LowCardinality カラムで正しく動作していませんでした。 [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#75568](https://github.com/ClickHouse/ClickHouse/issues/75568)でバックポート: Keeper の修正: ログをロールバックする際に、壊れた changelog に書き込まないようにしました。 [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75652](https://github.com/ClickHouse/ClickHouse/issues/75652)でバックポート: azureblobstorage table engine の認証情報をマスクしました。 [#75319](https://github.com/ClickHouse/ClickHouse/pull/75319) ([Garrett Thomas](https://github.com/garrettthomaskth)).
* [#75744](https://github.com/ClickHouse/ClickHouse/issues/75744)でバックポート: Protobuf フォーマットでの出力中、および並列クエリ `SYSTEM DROP FORMAT SCHEMA CACHE` の実行中に発生しうる Protobuf スキーマ cache のクラッシュを修正しました。 [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* [#76096](https://github.com/ClickHouse/ClickHouse/issues/76096)でバックポート: Array 型の JSON subcolumn を分散テーブルに対する JOIN で使用した際に発生しうるエラー `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes` を修正しました。 [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75854](https://github.com/ClickHouse/ClickHouse/issues/75854)でバックポート: allow&#95;feature&#95;tier と compatibility MergeTree setting の相互作用を修正しました。 [#75635](https://github.com/ClickHouse/ClickHouse/pull/75635) ([Raúl Marín](https://github.com/Algunenano)).
* [#75892](https://github.com/ClickHouse/ClickHouse/issues/75892)でバックポート: 異なる型のカラム間で複数の非同期 `RENAME` クエリ (`alter_sync = 0`) を実行した後、`MergeTree` テーブルの読み取り中にまれに発生していたクラッシュを修正しました。 [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* [#76157](https://github.com/ClickHouse/ClickHouse/issues/76157) でバックポート: projection の PK カラムに対して alter modify を行う際に、projection を再構築するよう修正しました。従来は、projection の PK で使用されているカラムに alter modify を行うと、その後の selects で `CANNOT_READ_ALL_DATA` エラーが発生することがありました。[#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75823](https://github.com/ClickHouse/ClickHouse/issues/75823) でバックポート: `DistinctSortedStreamTransform` における null ポインタの逆参照を修正しました。[#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* [#76216](https://github.com/ClickHouse/ClickHouse/issues/76216) でバックポート: `clickhouse-library-bridge` はファイルシステム上の任意のライブラリを開けるため、安全に実行できるのは分離された環境内に限られます。clickhouse-server と近接した環境で実行した場合の脆弱性を防ぐため、ライブラリのパスを configuration で指定された場所に制限します。この脆弱性は、**Arseniy Dugin** により [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて発見されました。[#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
