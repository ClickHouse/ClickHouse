<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#67902](https://github.com/ClickHouse/ClickHouse/issues/67902) でバックポート: StorageMerge の `PREWHERE` 最適化後に発生する `Not-ready Set` エラーを修正しました。[#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#68252](https://github.com/ClickHouse/ClickHouse/issues/68252) でバックポート: subqueries を使った filter 時に、一部のシステムテーブルで発生する `Not-ready Set` を修正しました。[#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* [#68064](https://github.com/ClickHouse/ClickHouse/issues/68064) でバックポート: 外部 database (`PostgreSQL` などのエンジン) に送信されるクエリ内のブール値リテラルを修正しました。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* [#68158](https://github.com/ClickHouse/ClickHouse/issues/68158) でバックポート: inter-server secret に対する cluster() を修正しました (従来どおり元の user を維持します) 。[#66364](https://github.com/ClickHouse/ClickHouse/pull/66364) ([Azat Khuzhin](https://github.com/azat)).
* [#68115](https://github.com/ClickHouse/ClickHouse/issues/68115) でバックポート: variant subcolumn の読み取り中に発生する可能性がある PARAMETER&#95;OUT&#95;OF&#95;BOUND エラーを修正しました。[#66659](https://github.com/ClickHouse/ClickHouse/pull/66659) ([Kruglov Pavel](https://github.com/Avogar)).
* [#67886](https://github.com/ClickHouse/ClickHouse/issues/67886) でバックポート: アーカイブでない場合、`::` を含むファイル名/URI を正しく parse できるよう修正しました。[#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368)).
* [#68272](https://github.com/ClickHouse/ClickHouse/issues/68272) でバックポート: HTTP interface 経由で stream 系エンジン (Kafka、RabbitMQ、NATS) へ inserting する処理を修正しました。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#67807](https://github.com/ClickHouse/ClickHouse/issues/67807) でバックポート: UNION を含む SQL UDFs の再読み込みを修正しました。以前は、server を再起動すると UDF が無効になることがありました。[#67665](https://github.com/ClickHouse/ClickHouse/pull/67665) ([Antonio Andelic](https://github.com/antonio2368)).
* [#67836](https://github.com/ClickHouse/ClickHouse/issues/67836) でバックポート: `JSONMergePatch` 関数における潜在的な stack overflow を修正しました。以前の名前が誤っていたため、この関数名を `jsonMergePatch` から `JSONMergePatch` に変更しました。互換性のため、以前の名前も引き続き利用できます。関数内の error 診断も改善しました。これにより [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304) をクローズします。[#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#67991](https://github.com/ClickHouse/ClickHouse/issues/67991) でバックポート: ALTER ADD/MODIFY COLUMN で experimental/suspicious data types を検証するようにしました。[#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68207](https://github.com/ClickHouse/ClickHouse/issues/68207) でバックポート: predicate に non-deterministic function が含まれる場合の `count()` の誤った結果を修正しました。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#68091](https://github.com/ClickHouse/ClickHouse/issues/68091) でバックポート: 使用可能な CPU 数が制限されているコンテナー化環境で、最大 thread soft limit の計算を修正しました。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* [#68122](https://github.com/ClickHouse/ClickHouse/issues/68122) にバックポート: 新しいアナライザにおいて、ミューテーションで未変更のパーツをスキップできない問題を修正しました。以前は、アナライザが有効な場合、条件上このパーツがミューテーションの影響を受けないにもかかわらず、パーツ内のデータがミューテーションによって書き換えられることがありました。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* [#68171](https://github.com/ClickHouse/ClickHouse/issues/68171) にバックポート: `OFFSET` を使用するサブクエリでソートを削除する誤った最適化を削除しました。[#67906](https://github.com/ClickHouse/ClickHouse/issues/67906) を修正します。[#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)).
* [#68337](https://github.com/ClickHouse/ClickHouse/issues/68337) にバックポート: クエリがキャンセルされた際に Postgres がクラッシュする問題の修正を試みました。[#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#68667](https://github.com/ClickHouse/ClickHouse/issues/68667) にバックポート: 関数 `sipHash64Keyed`、`sipHash128Keyed`、`sipHash128ReferenceKeyed` を空の配列またはタプルに適用した際に発生する `LOGICAL_ERROR` を修正しました。[#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)).
