<div id="2022-changelog">
  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v219330-stable-fixme-as-compared-to-v219217-stable">
  ### ClickHouse リリース v21.9.3.30-stable FIXME (v21.9.2.17-stableとの比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#28897](https://github.com/ClickHouse/ClickHouse/issues/28897)でバックポート: vertical mergeで、事前定義された &quot;rows&#95;sources&quot; ではなく実際のtmpファイルを使用するようにしました。これにより、tmpディスク内に不要なディレクトリが生成されるのを防ぎます。[#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#28815](https://github.com/ClickHouse/ClickHouse/issues/28815) でバックポート: 部分的に作成された aggregate projection を含む `SELECT` で、例外発生時にクラッシュする可能性がある問題を修正しました。[#28700](https://github.com/ClickHouse/ClickHouse/pull/28700) ([Amos Bird](https://github.com/amosbird))。
* [#28789](https://github.com/ClickHouse/ClickHouse/issues/28789) でバックポート: ReplicatedMergeTreeQueue における軽微な race condition を修正しました。通常はユーザーに見える問題ではありませんが、微妙な不具合につながる可能性があります。[#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin))。
* [#28842](https://github.com/ClickHouse/ClickHouse/issues/28842) でバックポート: short circuit evaluation における式のコンパイルを修正しました。[#28821](https://github.com/ClickHouse/ClickHouse/pull/28821) ([Azat Khuzhin](https://github.com/azat))。
* [#28993](https://github.com/ClickHouse/ClickHouse/issues/28993) でバックポート: まれにレプリカ間で不整合が生じる可能性があった、`DROP PART` と `REPLACE/MOVE PARTITION` の間の race condition を修正しました。[#28864](https://github.com/ClickHouse/ClickHouse/pull/28864) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#28949](https://github.com/ClickHouse/ClickHouse/issues/28949) でバックポート: compact パーツからの subcolumns の読み取りを修正しました。[#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ))。
* [#28925](https://github.com/ClickHouse/ClickHouse/issues/28925) でバックポート: short-curcuit 関数評価における LowCardinality の不具合を修正しました。[#28884](https://github.com/ClickHouse/ClickHouse/issues/28884) をクローズしました。[#28887](https://github.com/ClickHouse/ClickHouse/pull/28887) ([Kruglov Pavel](https://github.com/Avogar))。
* [#28927](https://github.com/ClickHouse/ClickHouse/issues/28927) でバックポート: consts を使った高階 array functions の問題 (`arrayCompact` での `SIGSEGV`、`arrayDifference` / `arrayCumSumNonNegative` での `ILLEGAL_COLUMN`) を修正しました。[#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat))。
* [#29025](https://github.com/ClickHouse/ClickHouse/issues/29025) でバックポート: `GLOBAL IN` サブクエリで使用される threads 数を修正しました ([#19414](https://github.com/ClickHouse/ClickHouse/issues/19414) のバグ修正以降、単一 thread で実行されていました) 。[#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。

<div id="not-for-changelog-insignificant">
  #### CHANGELOG には含めない / 軽微
</div>

* ネイティブプロトコルでの LC 向けチェックを追加。 [#27827](https://github.com/ClickHouse/ClickHouse/pull/27827) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 同じプレフィックスを持つ非配列カラムと併用した場合の Nested カラムの扱いを修正 [2] [#28762](https://github.com/ClickHouse/ClickHouse/pull/28762) ([Anton Popov](https://github.com/CurtizJ)).
* `compiled_expression_cache_size` を 128MB に引き下げ。 [#28816](https://github.com/ClickHouse/ClickHouse/pull/28816) ([Maksim Kita](https://github.com/kitaisreal)).
* カラムのデフォルト値における `dictGet` の Identifier を修正。 [#28863](https://github.com/ClickHouse/ClickHouse/pull/28863) ([Maksim Kita](https://github.com/kitaisreal)).
