<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに認識可能な不具合)
</div>

* [#46907](https://github.com/ClickHouse/ClickHouse/issues/46907)でバックポート: - QueryNormalizer における誤ったエイリアス再帰を修正しました。 [#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* [#47091](https://github.com/ClickHouse/ClickHouse/issues/47091)でバックポート: - `min` と `max` を使用する集約最適化における算術演算を修正しました。 [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* [#46885](https://github.com/ClickHouse/ClickHouse/issues/46885)でバックポート: `maxIntersections` 関数で報告される MSan の問題を修正しました。これにより [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126) を解決しました。 [#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#47067](https://github.com/ClickHouse/ClickHouse/issues/47067)でバックポート: systemd サービスのタイプミスを修正しました。これにより systemd サービスの起動に失敗する問題が発生していました。 [#47051](https://github.com/ClickHouse/ClickHouse/pull/47051) ([Palash Goel](https://github.com/palash-goel)).
* [#47259](https://github.com/ClickHouse/ClickHouse/issues/47259)でバックポート: 実カラムに対する PREWHERE サポートを修正しました。 [#47154](https://github.com/ClickHouse/ClickHouse/pull/47154) ([Azat Khuzhin](https://github.com/azat)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微

* コンテキスト切り替え時に flushUntrackedMemory を実行するようにした [#47102](https://github.com/ClickHouse/ClickHouse/pull/47102) ([Sema Checherinda](https://github.com/CheSema)).
