  ### ClickHouse リリース v23.8.1.2992-lts (ebc7d9a9f3b) FIXME、v23.7.1.2470-stable (a70127baecc) との比較
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* メタデータキャッシュ機能を非推奨にしました。これは Experimental な機能で、これまで一度も使われていませんでした。この機能は危険です: [#51182](https://github.com/ClickHouse/ClickHouse/issues/51182)。`system.merge_tree_metadata_cache` system table を削除しました。メタデータキャッシュはこのバージョンでも引き続き利用できますが、まもなく削除される予定です。これにより [#39197](https://github.com/ClickHouse/ClickHouse/issues/39197) をクローズします。 [#51303](https://github.com/ClickHouse/ClickHouse/pull/51303) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 動的ディスクに名前がある場合、ディスク関数の引数では `disk = disk(name = 'disk_name'`, ...) のように指定する必要があります。以前のバージョンでは `disk = disk_<disk_name>(...)` と指定できましたが、今後はサポートされません。 [#52820](https://github.com/ClickHouse/ClickHouse/pull/52820) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `clickhouse-benchmark` は、`--concurrency` を 1 より大きくして実行した場合、接続を並列に確立するようになります。以前は、欧州から米国に向けて 1000 同時接続で実行すると実用的ではありませんでした。高レイテンシ接続での QPS の計算も修正しました。後方互換性を持たない変更: `clickhouse-benchmark` の JSON 出力オプションは削除されました。このオプションを使用していた場合は、回避策として `system.query_log` から JSON フォーマットでデータを抽出することもできます。 [#53293](https://github.com/ClickHouse/ClickHouse/pull/53293) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `event_time_microseconds` カラムがあるため冗長になったことから、`system.text_log` から `microseconds` カラムを削除し、`system.metric_log` から `milliseconds` カラムを削除しました。 [#53601](https://github.com/ClickHouse/ClickHouse/pull/53601) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ストレージ `S3Queue` のメタデータ用 ZooKeeper パスを変更しました。 [#54137](https://github.com/ClickHouse/ClickHouse/pull/54137) ([Kseniia Sumarokova](https://github.com/kssenii)).



<div id="new-feature">
  #### 新機能
</div>

* `trace_type = 'MemorySample'` 向けに、`system.trace_log` にカラム `ptr` を追加しました。このカラムには割り当てアドレスが格納されます。割り当て済みで未解放のメモリを含むフレームグラフを構築できる関数 `flameGraph` も追加しました。[#38391](https://github.com/ClickHouse/ClickHouse/issues/38391) の改訂版です。[#45322](https://github.com/ClickHouse/ClickHouse/pull/45322) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `count_distinct_implementation` を使って `countDistinctIf` を書き換えるための設定 `rewrite_count_distinct_if_with_count_distinct_implementation` を追加しました。[#30642](https://github.com/ClickHouse/ClickHouse/issues/30642) をクローズします。[#46051](https://github.com/ClickHouse/ClickHouse/pull/46051) ([flynn](https://github.com/ucasfl)).
* S3 からのストリーミングデータ取り込み用の新しい table engine `S3Queue` を追加しました。[#37012](https://github.com/ClickHouse/ClickHouse/issues/37012) をクローズします。[#49086](https://github.com/ClickHouse/ClickHouse/pull/49086) ([s-kat](https://github.com/s-kat)).
* SevenZipArchiveReader - TarArchiveReader - Table Function file(&#39;path&#95;to&#95;archive :: filename&#39;) - &quot;Table Function file(&#39;path&#95;to&#95;archive :: filename&#39;)&quot; の機能テスト - TarArchiveReader/SevenZipArchiveReader の単体テスト。[#50321](https://github.com/ClickHouse/ClickHouse/pull/50321) ([nikitakeba](https://github.com/nikitakeba)).
* table function `azureBlobStorageCluster` を追加しました。サポートされる機能セットは table function `S3Cluster` と非常によく似ています。[#50795](https://github.com/ClickHouse/ClickHouse/pull/50795) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* [#50808](https://github.com/ClickHouse/ClickHouse/issues/50808) の issue で、table 名なしで cluster、clusterAllReplicas、remote、remoteRaw、remoteSecure を使用できるようにしました。[#50848](https://github.com/ClickHouse/ClickHouse/pull/50848) ([Yangkuan Liu](https://github.com/LiuYangkuan)).
* Kafka コンシューマーを監視するためのシステムテーブルを追加しました。[#50999](https://github.com/ClickHouse/ClickHouse/pull/50999) ([Ilya Golshtein](https://github.com/ilejn)).
* max&#95;sessions&#95;for&#95;user 設定を追加しました。[#51724](https://github.com/ClickHouse/ClickHouse/pull/51724) ([Alexey Gerasimchuck](https://github.com/Demilivor)).
* ClickHouse には UTC timezone の timestamp を別の timezone の timestamp に変換する関数がなく、これは Spark と異なるため、Spark の `to_utc_timestamp/from_utc_timestamp` と同じように動作する関数 `toUTCTimestamp/fromUTCTimestamp` を追加しました。[#52117](https://github.com/ClickHouse/ClickHouse/pull/52117) ([KevinyhZou](https://github.com/KevinyhZou)).
* ClickHouse table の structure を CapnProto/Protobuf フォーマットのスキーマに変換する新しい関数 `structureToCapnProtoSchema`/`structureToProtobufSchema` を追加しました。table structure から生成される autogenerated schema を使用することで、外部 format schema なしで CapnProto/Protobuf フォーマットのデータを入力/出力できるようにしました (設定 `format_capn_proto_use_autogenerated_schema`/`format_protobuf_use_autogenerated_schema` で制御) 。さらに、設定 `output_format_schema` により、入力/出力時に autogenerated schema をエクスポートできるようにしました。[#52278](https://github.com/ClickHouse/ClickHouse/pull/52278) ([Kruglov Pavel](https://github.com/Avogar)).
* SYSTEM.QUERY&#95;LOG の新しいフィールド &quot;query&#95;cache&#95;usage&quot; により、query cache が使用されたかどうか、またどのように使用されたかを確認できるようになりました。[#52384](https://github.com/ClickHouse/ClickHouse/pull/52384) ([Robert Schulze](https://github.com/rschu1ze)).
* 新しい関数 startsWithUTF8 と endsWithUTF8 を追加しました。[#52555](https://github.com/ClickHouse/ClickHouse/pull/52555) ([李扬](https://github.com/taiyang-li)).
* TSV/CuatomSeprarated/JSONCompactEachRow で可変数のカラムを許可し、可変数のカラムに対するスキーマ推論が機能するようにしました。設定 `input_format_tsv_allow_variable_number_of_columns`、`input_format_custom_allow_variable_number_of_columns`、`input_format_json_compact_allow_variable_number_of_columns` を追加しました。[#52692](https://github.com/ClickHouse/ClickHouse/pull/52692) ([Kruglov Pavel](https://github.com/Avogar)).
* `SYSTEM STOP/START PULLING REPLICATION LOG` クエリを追加しました (`ReplicatedMergeTree` のテスト用) 。[#52881](https://github.com/ClickHouse/ClickHouse/pull/52881) ([Alexander Tokmakov](https://github.com/tavplubix)).
* イニシエーター上で、mutation において定数の非決定論的関数を実行できるようにしました。[#53129](https://github.com/ClickHouse/ClickHouse/pull/53129) ([Anton Popov](https://github.com/CurtizJ)).
* データをまったく読み込まず、`system.one` と同様に、型 `UInt8` で値 `0` の `dummy` カラムを持つ単一の行を常に返す入力フォーマット One を追加しました。これは `_file/_path` 仮想カラムと組み合わせて使用でき、データを読み込まずに file/s3/url/hdfs/etc table functions 内のファイルを一覧表示できます。[#53209](https://github.com/ClickHouse/ClickHouse/pull/53209) ([Kruglov Pavel](https://github.com/Avogar)).
* tupleConcat 関数を追加しました。[#52759](https://github.com/ClickHouse/ClickHouse/issues/52759) をクローズします。[#53239](https://github.com/ClickHouse/ClickHouse/pull/53239) ([Nikolay Degterinsky](https://github.com/evillique)).
* `TRUNCATE DATABASE` 操作をサポートしました。[#53261](https://github.com/ClickHouse/ClickHouse/pull/53261) ([Bharat Nallan](https://github.com/bharatnc)).
* 主キー処理で使用するスレッド数を制限するための設定 max&#95;threads&#95;for&#95;indexes を追加しました。[#53313](https://github.com/ClickHouse/ClickHouse/pull/53313) ([Joris Giovannangeli](https://github.com/jorisgio)).
* 近似近傍探索手法として HNSW の Experimental サポートを追加しました。[#53447](https://github.com/ClickHouse/ClickHouse/pull/53447) ([Davit Vardanyan](https://github.com/davvard)).

* ([#52755](https://github.com/ClickHouse/ClickHouse/issues/52755) , [#52895](https://github.com/ClickHouse/ClickHouse/issues/52895)) 関数 `arrayRotateLeft`、`arrayRotateRight`、`arrayShiftLeft`、`arrayShiftRight` を追加しました。[#53557](https://github.com/ClickHouse/ClickHouse/pull/53557) ([Mikhail Koviazin](https://github.com/mkmkme)).
* `system.clusters` に、クラスターの alias としてカラム `name` を追加しました。[#53605](https://github.com/ClickHouse/ClickHouse/pull/53605) ([irenjj](https://github.com/irenjj)).
* 高度なダッシュボードで一括編集 (保存/読み込み) が可能になりました。[#53608](https://github.com/ClickHouse/ClickHouse/pull/53608) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* AArch64、PowerPC、SystemZ、RISCV で JIT コンパイルを有効化しました。[#38217](https://github.com/ClickHouse/ClickHouse/pull/38217) ([Maksim Kita](https://github.com/kitaisreal)).
* このパッチにより、マージ前にすべての hashsets を並列に処理する方法が追加されました。[#50748](https://github.com/ClickHouse/ClickHouse/pull/50748) ([Jiebin Sun](https://github.com/jiebinn)).
* aggregationmethodserialized 使用時の Nullable string key の aggregation パフォーマンスを最適化しました。[#51399](https://github.com/ClickHouse/ClickHouse/pull/51399) ([LiuNeng](https://github.com/liuneng1994)).
* ICX デバイス (Intel Xeon Platinum 8380 CPU、80 コア、160 スレッド) 上での **SSB** の性能評価では、experimental なアナライザを有効にした場合、この変更により **geomean QPS** が **8.5%** 改善される可能性が示されています。詳細は以下のとおりです: ![image](https://github.com/ClickHouse/ClickHouse/assets/26588299/4e58bf8b-d276-408d-ad45-38c82d3cb918)。[#52091](https://github.com/ClickHouse/ClickHouse/pull/52091) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* Parquet の filter pushdown。つまり、Parquet files の読み取り時に、WHERE 条件と各カラムの最小値/最大値に基づいて行グループ (ファイル内の chunk) をスキップします。特に、ファイルがあるカラムでおおむねソートされている場合、そのカラムの狭い範囲で filter する queries は大幅に高速化されます。[#52951](https://github.com/ClickHouse/ClickHouse/pull/52951) ([Michael Kolupaev](https://github.com/al13n321)).
* UniqExactSet で、すべての hashSets が singleLevel の場合のマージを最適化しました。[#52973](https://github.com/ClickHouse/ClickHouse/pull/52973) ([Jiebin Sun](https://github.com/jiebinn)).
* StorageJoin: すべてのカラムを含む clone ハッシュ結合を作成しないようにしました。[#53046](https://github.com/ClickHouse/ClickHouse/pull/53046) ([Duc Canh Le](https://github.com/canhld94)).
* Parquet で小さな行グループをまとめてバッチ処理することで、読み取りを最適化しました。[#53069](https://github.com/ClickHouse/ClickHouse/issues/53069) をクローズ。[#53281](https://github.com/ClickHouse/ClickHouse/pull/53281) ([Kruglov Pavel](https://github.com/Avogar)).
* パフォーマンス向上のため、arrow を使わない native な orc input format を実装しました。[#53324](https://github.com/ClickHouse/ClickHouse/pull/53324) ([李扬](https://github.com/taiyang-li)).
* ダッシュボードから server にデータ圧縮を指示するようになり、低速なインターネット接続で長い time frame を扱う場合に有用です。たとえば、86400 points を持つ 1 つの chart は、非圧縮では 1.5 MB ですが、`br` で圧縮すると 60 KB になります。[#53569](https://github.com/ClickHouse/ClickHouse/pull/53569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ほとんどの input format で、files からの count を最適化しました。[#44334](https://github.com/ClickHouse/ClickHouse/issues/44334) をクローズ。[#53637](https://github.com/ClickHouse/ClickHouse/pull/53637) ([Kruglov Pavel](https://github.com/Avogar)).
* BACKUP と RESTORE におけるスレッドプールの活用を改善しました。[#53649](https://github.com/ClickHouse/ClickHouse/pull/53649) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* client の performance check における不要な低速化要因を削除しました。[#53695](https://github.com/ClickHouse/ClickHouse/pull/53695) ([Raúl Marín](https://github.com/Algunenano)).
