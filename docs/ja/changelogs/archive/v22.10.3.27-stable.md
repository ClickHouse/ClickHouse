  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v2210327-stable-6d3b2985724-fixme-as-compared-to-v2210211-stable-d2bfcaba002">
  ### ClickHouse リリース v22.10.3.27-stable (6d3b2985724) FIXME、v22.10.2.11-stable (d2bfcaba002) との比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#42842](https://github.com/ClickHouse/ClickHouse/issues/42842)でバックポート: tzdata を 2022f に更新。メキシコでは、米国との国境付近を除き、夏時間は実施されなくなります: [https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html)。チワワ州は 2022-10-30 に通年 UTC-6 に移行します。フィジーでも夏時間は実施されなくなります。[https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) および [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209) を参照してください。 [#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#42959](https://github.com/ClickHouse/ClickHouse/issues/42959) でバックポート: この修正前は、ユーザー定義の設定が RPM によって `$file.rpmsave` に保存されていました。この PR で修正され、パッケージ内のファイルによってユーザーのファイルが置き換えられないようになりました。[#42936](https://github.com/ClickHouse/ClickHouse/pull/42936) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* [#43042](https://github.com/ClickHouse/ClickHouse/issues/43042) でバックポート: コミットをリリース準備完了としてマークするための CI ステップを追加しました。また、master 以外のブランチからリリーススクリプトを起動することを緩やかに禁止しました。[#43017](https://github.com/ClickHouse/ClickHouse/pull/43017) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#42864](https://github.com/ClickHouse/ClickHouse/issues/42864)でバックポート: lowerUTF8()/upperUTF8() で、シンボルが 16 バイト境界をまたぐ場合の問題を修正 (文字列が 16 バイトを超える場合によく発生) 。 [#42812](https://github.com/ClickHouse/ClickHouse/pull/42812) ([Azat Khuzhin](https://github.com/azat)).
* [#43173](https://github.com/ClickHouse/ClickHouse/issues/43173)でバックポート: まれにクエリのキャンセル時にハングする可能性がある問題を修正。 [#42874](https://github.com/ClickHouse/ClickHouse/pull/42874) ([Azat Khuzhin](https://github.com/azat)).
* [#43064](https://github.com/ClickHouse/ClickHouse/issues/43064)でバックポート: projection は使用可能でも利用できる projection がない場合に、まれに NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK エラーが発生する問題を修正。これにより [#42771](https://github.com/ClickHouse/ClickHouse/issues/42771) を修正します。このバグは [https://github.com/ClickHouse/ClickHouse/pull/25563](https://github.com/ClickHouse/ClickHouse/pull/25563) で導入されました。 [#42938](https://github.com/ClickHouse/ClickHouse/pull/42938) ([Amos Bird](https://github.com/amosbird)).
* [#43075](https://github.com/ClickHouse/ClickHouse/issues/43075)でバックポート: lambda のパースを修正。 [#41848](https://github.com/ClickHouse/ClickHouse/issues/41848) をクローズ。 [#42979](https://github.com/ClickHouse/ClickHouse/pull/42979) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#43444](https://github.com/ClickHouse/ClickHouse/issues/43444)でバックポート: 複数の buffer の過剰読み取りを修正。 [#43159](https://github.com/ClickHouse/ClickHouse/pull/43159) ([Raúl Marín](https://github.com/Algunenano)).
* [#43430](https://github.com/ClickHouse/ClickHouse/issues/43430)でバックポート: `Merge` engine を使用する table で、PREWHERE optimization 有効時の `SAMPLE BY` を含むクエリを修正。 [#43315](https://github.com/ClickHouse/ClickHouse/pull/43315) ([Antonio Andelic](https://github.com/antonio2368)).
