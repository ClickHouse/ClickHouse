<div id="clickhouse-release-v211167-stable-fixme-as-compared-to-v2111533-stable">
  ### ClickHouse リリース v21.11.6.7-stable FIXME (v21.11.5.33-stable と比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#32254](https://github.com/ClickHouse/ClickHouse/issues/32254)でバックポート: protobuf の書き込み時にカラムがスキップされる問題を修正しました。この PR で [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160) を修正しています。詳しくはコメント [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318 を参照してください。[#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#32345](https://github.com/ClickHouse/ClickHouse/issues/32345)でバックポート: サブクエリ内で不要なカラムを削除する際のバグを修正しました。group by のないクエリに集約関数が含まれている場合は、不要に見えても削除しません。[#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372))。

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#32152](https://github.com/ClickHouse/ClickHouse/issues/32152)でバックポート: type が `Nullable` の場合に、Dictionary 属性に対して型指定付きの関数 `dictGet` を使用するとクラッシュする問題を修正しました。[#30980](https://github.com/ClickHouse/ClickHouse/issues/30980) を修正。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32298](https://github.com/ClickHouse/ClickHouse/issues/32298)でバックポート: 再帰的な user defined function によるクラッシュを修正しました。[#30856](https://github.com/ClickHouse/ClickHouse/issues/30856) をクローズ。[#31820](https://github.com/ClickHouse/ClickHouse/pull/31820) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32148](https://github.com/ClickHouse/ClickHouse/issues/32148)でバックポート: part の detach 時に `Directory ... already exists and is not empty` error が発生する問題を修正しました。[#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32212](https://github.com/ClickHouse/ClickHouse/issues/32212)でバックポート: `cast_keep_nullable` を指定した `Nullable` からの `CAST` を修正しました (以前は、たとえば `toUInt32OrDefault(toNullable(toUInt32(1)))` で `PARAMETER_OUT_OF_BOUND` error が発生していました) 。[#32080](https://github.com/ClickHouse/ClickHouse/pull/32080) ([Azat Khuzhin](https://github.com/azat)).
* [#32283](https://github.com/ClickHouse/ClickHouse/issues/32283)でバックポート: カスタム database クエリで `{condition}` が機能しないケースを Dictionaries で修正しました。[#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32482](https://github.com/ClickHouse/ClickHouse/issues/32482)でバックポート: client/server の crash につながる可能性があった `'APPLY lambda'` のパースを修正しました。[#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32217](https://github.com/ClickHouse/ClickHouse/issues/32217)でバックポート: 一部のレプリカで setting `replicated_can_become_leader` が無効になっている場合、クォーラム付きで insert する際のアクティブな replicas 数が誤って判定される可能性がありました。これを修正しました。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32311](https://github.com/ClickHouse/ClickHouse/issues/32311)でバックポート: table create query で使用される XML dictionaries identifiers が、新しいバージョンへの upgrade 中に `default_database` で修飾されることがある問題を修正しました。[#31963](https://github.com/ClickHouse/ClickHouse/issues/31963) をクローズ。[#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32354](https://github.com/ClickHouse/ClickHouse/issues/32354)でバックポート: `Decimal` argument を持つ aggregate function `avgWeighted` で、SIGFPE による crash を修正しました。[#32053](https://github.com/ClickHouse/ClickHouse/issues/32053) を修正。[#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32392](https://github.com/ClickHouse/ClickHouse/issues/32392)でバックポート: default expression の data type が column の data type と一致しない場合の `ALTER ... MATERIALIZE COLUMN ...` クエリを修正しました。[#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
* [#32418](https://github.com/ClickHouse/ClickHouse/issues/32418)でバックポート: 実行対象のない mutations が停止したままになる問題を修正しました (setting `empty_result_for_aggregation_by_empty_set` が enabled の場合) 。[#32358](https://github.com/ClickHouse/ClickHouse/pull/32358) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
