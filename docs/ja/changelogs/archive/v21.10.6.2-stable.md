<div id="bug-fix">
  #### バグ修正
</div>

* [#32692](https://github.com/ClickHouse/ClickHouse/issues/32692) でバックポート: クォータの上限には達していないにもかかわらず、上限超過として扱われていました。このPRで [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正しました。[#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).

#### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)

* [#32680](https://github.com/ClickHouse/ClickHouse/issues/32680) でバックポート: パーツを detach する際に projection が予期せず削除される問題を修正しました。[#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird))。
* [#32285](https://github.com/ClickHouse/ClickHouse/issues/32285) でバックポート: カスタム database クエリで `{condition}` が機能しない場合がある Dictionaries の問題を修正しました。[#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal))。
* [#32730](https://github.com/ClickHouse/ClickHouse/issues/32730) でバックポート: client/server の crash につながる可能性があった `APPLY lambda` のパースの問題を修正しました。[#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar))。
* [#32313](https://github.com/ClickHouse/ClickHouse/issues/32313) でバックポート: XML dictionaries の Identifier は、table create query で使用されている場合、新しいバージョンへのアップグレード時に `default_database` で修飾されることがあります。[#31963](https://github.com/ClickHouse/ClickHouse/issues/31963) をクローズしました。[#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal))。
* [#32539](https://github.com/ClickHouse/ClickHouse/issues/32539) でバックポート: 一部の replication queue のエントリが、`Directory tmp_merge_<part_name>` や `Part ... (state Deleting) already exists, but it will be deleted soon` などの error により、`temporary_directories_lifetime` (デフォルトでは 1 日) の間ハングする可能性がありました。この問題を修正しました。[#29616](https://github.com/ClickHouse/ClickHouse/issues/29616) を修正しました。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#32709](https://github.com/ClickHouse/ClickHouse/issues/32709) でバックポート: まだ materialized されていない skipping indices を使用しようとする queries で発生する失敗を修正しました。[#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) および [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343) を修正しました。[#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ))。
* [#32567](https://github.com/ClickHouse/ClickHouse/issues/32567) でバックポート: `JoinCommon::removeColumnNullability` で発生する crash を修正し、[#32458](https://github.com/ClickHouse/ClickHouse/issues/32458) をクローズしました。[#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir))。
* [#32794](https://github.com/ClickHouse/ClickHouse/issues/32794) でバックポート: 同じ FixedString を複数回使って fuzzBits を使用した際に発生する crash を修正し、[#32737](https://github.com/ClickHouse/ClickHouse/issues/32737) をクローズしました。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc))。
* [#33182](https://github.com/ClickHouse/ClickHouse/issues/33182) でバックポート: `MySQL` engine の database が MySQL server に接続できない場合に Server の起動に失敗することがありましたが、この問題を修正しました。[#14441](https://github.com/ClickHouse/ClickHouse/issues/14441) を修正しました。[#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#33655](https://github.com/ClickHouse/ClickHouse/issues/33655) でバックポート: HA namenode address を使用できなかった hdfs url check を修正しました。この bug は [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042) で導入されました。[#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar))。
