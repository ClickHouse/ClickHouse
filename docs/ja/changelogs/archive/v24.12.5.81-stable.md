<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534) にバックポート: `LowCardinality` カラムのメモリ上のサイズ計算を修正しました。[#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)) 。
* [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005) にバックポート: Concurrency 制御により、INSERT と SELECT の間で CPU 配分が不公平になる可能性があることが判明しました。すべての CPU slots が無条件に (競合なしで) `max_threads` = 1 の INSERT に割り当てられると、`max_threads` の値が大きい SELECT は実質的に単一スレッドしか使えず、パフォーマンスが低下します。[#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)) 。

<div id="improvement">
  #### 改善
</div>

* [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535) にバックポート: `parallel_hash` JOINアルゴリズムにおける `max_joined_block_size_rows` 設定の計上をより正確にしました。これにより、`hash` アルゴリズムと比べてメモリ消費量が増加するのを防ぎやすくなります。[#74630](https://github.com/ClickHouse/ClickHouse/pull/74630) ([Nikita Taranov](https://github.com/nickitat)).
* [#75844](https://github.com/ClickHouse/ClickHouse/issues/75844) にバックポート: 復号および解凍に対するチェックとログを追加しました。[#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#76046](https://github.com/ClickHouse/ClickHouse/issues/76046) にバックポート: Keeper の改善: パフォーマンス向上のため、インメモリストレージへの commit 時の digest 計算を無効化しました。これは `keeper_server.digest_enabled_on_commit` config で有効にできます。リクエストの preprocess 時には引き続き digest が計算されます。[#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75709](https://github.com/ClickHouse/ClickHouse/issues/75709) にバックポート: 互換性のため、server から client への settings の送信 (`send_settings_to_client=false`) を無効化しました (この feature は、今後使いやすさ向上のため client setting として再実装される予定です) 。[#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805) にバックポート: `memory_worker_correct_memory_tracker` という config を追加し、background thread で定期的に読み取られる別の情報源の情報を使って、内部 memory tracker を補正できるようにしました。[#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069) にバックポート: RSS で補正されていない内部グローバル memory tracker の値を示す `MemoryTrackingUncorrected` metric を追加しました。[#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).
