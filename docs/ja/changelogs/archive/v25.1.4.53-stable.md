<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#75990](https://github.com/ClickHouse/ClickHouse/issues/75990) にバックポート: 並行制御によって、INSERT と SELECT の間で CPU の配分が不公平になる可能性があることが判明しました。`max_threads` = 1 の INSERT に、すべての CPU スロットが無条件に (競合なしで) 割り当てられると、`max_threads` の値が大きい SELECT でも単一のスレッドしか使用できず、パフォーマンスが大きく低下する場合があります。[#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### 改善
</div>

* [#75918](https://github.com/ClickHouse/ClickHouse/issues/75918) にバックポート: `DatabaseIceberg` で、カタログ設定からの `s3.endpoint` をネイティブにサポート。 [#74558](https://github.com/ClickHouse/ClickHouse/issues/74558) をクローズ。 [#75375](https://github.com/ClickHouse/ClickHouse/pull/75375) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#75846](https://github.com/ClickHouse/ClickHouse/issues/75846) にバックポート: 復号および展開のためのチェックとログを追加。 [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#75705](https://github.com/ClickHouse/ClickHouse/issues/75705) にバックポート: 互換性のため、サーバーからクライアントへの設定の送信 (`send_settings_to_client=false`) を無効化 (この機能は、使い勝手向上のため、後に client setting として再実装される予定です) 。 [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321))。
* [#75801](https://github.com/ClickHouse/ClickHouse/issues/75801) にバックポート: バックグラウンドスレッドでさまざまなソースから定期的に読み取られる情報を使って、内部 memory tracker を補正できる設定 `memory_worker_correct_memory_tracker` を追加。 [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368))。
* [#76070](https://github.com/ClickHouse/ClickHouse/issues/76070) にバックポート: RSS による補正前の内部グローバル memory tracker の値を示す `MemoryTrackingUncorrected` メトリクスを追加。 [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368))。

* [#75612](https://github.com/ClickHouse/ClickHouse/issues/75612) でバックポート: クライアント/サーバー間通信で Native format の設定が正しく伝播されるよう修正。 [#73924](https://github.com/ClickHouse/ClickHouse/pull/73924) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75560](https://github.com/ClickHouse/ClickHouse/issues/75560) でバックポート: macOS 上の PostgreSQL interface で、`INSERT INTO SELECT` クエリにより発生する crash を修正 (issue [#72938](https://github.com/ClickHouse/ClickHouse/issues/72938))。 [#74231](https://github.com/ClickHouse/ClickHouse/pull/74231) ([Artem Yurov](https://github.com/ArtemYurov)).

* [#76085](https://github.com/ClickHouse/ClickHouse/issues/76085) でバックポート: LowCardinality Nullable data type に対する nullsafe JOIN の処理を修正。これまでは、`IS NOT DISTINCT FROM`、`<=>`、`a IS NULL AND b IS NULL OR a == b` のような nullsafe 比較を使う JOIN ON が、LowCardinality カラムで正しく動作していませんでした。 [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#75572](https://github.com/ClickHouse/ClickHouse/issues/75572) でバックポート: Keeper の修正: ログをロールバックする際に、壊れた changelog へ書き込まないようにした。 [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* [#75587](https://github.com/ClickHouse/ClickHouse/issues/75587) でバックポート: azureblobstorage table engine の credentials をマスク。 [#75319](https://github.com/ClickHouse/ClickHouse/pull/75319) ([Garrett Thomas](https://github.com/garrettthomaskth)).
* [#75748](https://github.com/ClickHouse/ClickHouse/issues/75748) でバックポート: Protobuf format での出力中、および並列クエリ `SYSTEM DROP FORMAT SCHEMA CACHE` の実行中に発生しうる Protobuf schema cache の crash を修正。 [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75425](https://github.com/ClickHouse/ClickHouse/issues/75425) でバックポート: `icebergS3`、`icebergAzure` table function および table engine の機密情報を非表示にするようにした。 [#75378](https://github.com/ClickHouse/ClickHouse/pull/75378) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#76100](https://github.com/ClickHouse/ClickHouse/issues/76100) でバックポート: Array 型の JSON subcolumn を分散テーブル上の JOIN で使用した際に発生しうる `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes` エラーを修正。 [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* [#75858](https://github.com/ClickHouse/ClickHouse/issues/75858) でバックポート: allow&#95;feature&#95;tier と compatibility MergeTree setting の相互作用を修正。 [#75635](https://github.com/ClickHouse/ClickHouse/pull/75635) ([Raúl Marín](https://github.com/Algunenano)).
* [#75896](https://github.com/ClickHouse/ClickHouse/issues/75896) でバックポート: 異なる型のカラム間で複数の非同期 `RENAME` クエリ (`alter_sync = 0`) を実行した後、`MergeTree` table の読み取り時にまれに発生していた crash を修正。 [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* [#75827](https://github.com/ClickHouse/ClickHouse/issues/75827) でバックポート: `DistinctSortedStreamTransform` における null pointer dereference を修正。 [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* [#75838](https://github.com/ClickHouse/ClickHouse/issues/75838) にバックポート: 関数 `translate` における未初期化メモリの読み取りを修正しました。これにより [#75592](https://github.com/ClickHouse/ClickHouse/issues/75592) はクローズされます。[#75794](https://github.com/ClickHouse/ClickHouse/pull/75794) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#75998](https://github.com/ClickHouse/ClickHouse/issues/75998) にバックポート: 暗黙的に追加された min-max インデックスを持つテーブルを新しいテーブルにコピーできない不具合を修正しました (issue [#75677](https://github.com/ClickHouse/ClickHouse/issues/75677)) 。[#75877](https://github.com/ClickHouse/ClickHouse/pull/75877) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
