<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正（正式な安定版リリースにおけるユーザーが確認できる不具合）
</div>

* [#37717](https://github.com/ClickHouse/ClickHouse/issues/37717) でバックポート: aggregate function、prewhere、join において定数文字列が衝突した際に発生する予期しないエラーを修正しました。[#36891](https://github.com/ClickHouse/ClickHouse/issues/36891) をクローズします。[#37336](https://github.com/ClickHouse/ClickHouse/pull/37336) ([Vladimir C](https://github.com/vdimir)).
* [#37512](https://github.com/ClickHouse/ClickHouse/issues/37512) でバックポート: normalizeUTF8 関数の論理エラーを修正しました。[#37298](https://github.com/ClickHouse/ClickHouse/issues/37298) をクローズします。[#37443](https://github.com/ClickHouse/ClickHouse/pull/37443) ([Maksim Kita](https://github.com/kitaisreal)).
* [#37941](https://github.com/ClickHouse/ClickHouse/issues/37941) でバックポート: 内部 cast 関数向けの setting `cast_ipv4_ipv6_default_on_conversion_error` を修正しました。[#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) をクローズします。[#37761](https://github.com/ClickHouse/ClickHouse/pull/37761) ([Maksim Kita](https://github.com/kitaisreal)).
* [#38452](https://github.com/ClickHouse/ClickHouse/issues/38452) でバックポート: ネストした短絡関数で、condition が false の場合でも argument が実行されてしまう不具合を修正しました。[#38040](https://github.com/ClickHouse/ClickHouse/issues/38040) をクローズします。[#38173](https://github.com/ClickHouse/ClickHouse/pull/38173) ([Kruglov Pavel](https://github.com/Avogar)).
* [#38711](https://github.com/ClickHouse/ClickHouse/issues/38711) でバックポート: `DISTINCT` と `LIMIT` を含む distributed queries で誤った結果が返る不具合を修正しました。[#38282](https://github.com/ClickHouse/ClickHouse/issues/38282) を修正します。[#38371](https://github.com/ClickHouse/ClickHouse/pull/38371) ([Anton Popov](https://github.com/CurtizJ)).
* [#38593](https://github.com/ClickHouse/ClickHouse/issues/38593) でバックポート: server の異常終了後にパーツが削除されない不具合を修正しました (server シャットダウン時に削除されなかった場合、以後ずっと残ってしまいます) 。[#38486](https://github.com/ClickHouse/ClickHouse/pull/38486) ([Azat Khuzhin](https://github.com/azat)).
* [#38596](https://github.com/ClickHouse/ClickHouse/issues/38596) でバックポート: 22.4 より前のレプリカでレプリケーションの問題が起きないよう、table の作成処理を修正しました。[#38541](https://github.com/ClickHouse/ClickHouse/pull/38541) ([Raúl Marín](https://github.com/Algunenano)).
* [#38686](https://github.com/ClickHouse/ClickHouse/issues/38686) でバックポート: IPv4/IPv6 表現の値が不正な table であっても、clickhouse-server を起動し、table の attach/detach を行えるようになりました。issue [#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) への適切な修正です。[#38590](https://github.com/ClickHouse/ClickHouse/pull/38590) ([alesapin](https://github.com/alesapin)).
* [#38663](https://github.com/ClickHouse/ClickHouse/issues/38663) でバックポート: 22.4 より前のレプリカとの問題を回避するため、さらにいくつかの node を対応させました。[#38627](https://github.com/ClickHouse/ClickHouse/pull/38627) ([Raúl Marín](https://github.com/Algunenano)).
* [#38777](https://github.com/ClickHouse/ClickHouse/issues/38777) でバックポート: 一部の arguments が NaN の場合でも、`rankCorr` 関数が正しく動作するようになりました。これにより [#38396](https://github.com/ClickHouse/ClickHouse/issues/38396) はクローズされます。[#38722](https://github.com/ClickHouse/ClickHouse/pull/38722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#38781](https://github.com/ClickHouse/ClickHouse/issues/38781) でバックポート: 誤った結果につながる Map combinator の use-after-free を修正しました。[#38748](https://github.com/ClickHouse/ClickHouse/pull/38748) ([Azat Khuzhin](https://github.com/azat)).
