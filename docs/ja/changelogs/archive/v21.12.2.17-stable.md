  ### ClickHouse リリース v21.12.2.17-stable FIXME (v21.12.1.9017-prestable との比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#32693](https://github.com/ClickHouse/ClickHouse/issues/32693) にバックポート: クォータ制限には達していないのに、制限超過として扱われていました。このPRは [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正します。 [#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).

#### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合) 

* [#32681](https://github.com/ClickHouse/ClickHouse/issues/32681) にバックポート: パーツを detach した際に projection が予期せず削除される問題を修正しました。[#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* [#32483](https://github.com/ClickHouse/ClickHouse/issues/32483) にバックポート: client/server の crash につながる可能性があった `'APPLY lambda'` のパース処理を修正しました。[#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* [#32542](https://github.com/ClickHouse/ClickHouse/issues/32542) にバックポート: `Directory tmp_merge_<part_name>` や `Part ... (state Deleting) already exists, but it will be deleted soon` などの error により、一部の replication queue のエントリが `temporary_directories_lifetime` (既定では 1 日) の間ハングする可能性がありました。これを修正しました。[#29616](https://github.com/ClickHouse/ClickHouse/issues/29616) を修正。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32710](https://github.com/ClickHouse/ClickHouse/issues/32710) にバックポート: まだ materialized されていない skipping indices を使おうとした queries が失敗する問題を修正しました。[#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) および [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343) を修正。[#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* [#32569](https://github.com/ClickHouse/ClickHouse/issues/32569) にバックポート: `JoinCommon::removeColumnNullability` で発生する crash を修正し、[#32458](https://github.com/ClickHouse/ClickHouse/issues/32458) をクローズしました。[#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* [#32770](https://github.com/ClickHouse/ClickHouse/issues/32770) にバックポート: sequential な key における sparse&#95;hashed dict の性能問題 (誤った hash function) を修正しました。[#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* [#32634](https://github.com/ClickHouse/ClickHouse/issues/32634) にバックポート: DROP TABLE と INSERT が並行して実行された場合の table の lifetime (つまり use-after-free が発生しうる問題) を修正しました。[#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* [#32632](https://github.com/ClickHouse/ClickHouse/issues/32632) にバックポート: channel の作成を遅らせることで、RabbitMQ storage の起動時に発生しうる exception を修正しました。[#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32733](https://github.com/ClickHouse/ClickHouse/issues/32733) にバックポート: 関数 `file` 内の著しく不適切な code を修正しました。[#32640](https://github.com/ClickHouse/ClickHouse/pull/32640) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#32793](https://github.com/ClickHouse/ClickHouse/issues/32793) にバックポート: 同じ FixedString を複数回使って fuzzBits を使用した際に発生する crash を修正し、[#32737](https://github.com/ClickHouse/ClickHouse/issues/32737) をクローズしました。[#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
