<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#53025](https://github.com/ClickHouse/ClickHouse/issues/53025)でバックポート: inline cache を Docker イメージに含めると、まれに奇妙な副作用が発生します。いずれにせよ、これはまったく使っていないため問題ありません。[#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* 23.7 でクラスター上の named collections の問題を修正しました [#52687](https://github.com/ClickHouse/ClickHouse/pull/52687) ([Al Korgun](https://github.com/alkorgun)).
* show create mysql table におけるパスワード漏えいの問題を修正しました [#52962](https://github.com/ClickHouse/ClickHouse/pull/52962) ([Duc Canh Le](https://github.com/canhld94)).
* ZstdDeflatingWriteBuffer が出力を切り詰めてしまうことがある問題を修正しました [#53064](https://github.com/ClickHouse/ClickHouse/pull/53064) ([Michael Kolupaev](https://github.com/al13n321)).
