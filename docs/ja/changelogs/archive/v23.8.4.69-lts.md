  ### ClickHouse リリース v23.8.4.69-lts (d4d1e7b9ded) FIXME (v23.8.3.48-lts (ebe4eb3d23e) との比較)

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673) でバックポート: データベースがすでに初期化されている場合、以後の起動時に再度初期化する必要がなくなりました。これにより、データベースが 1000 回の試行以内に読み込めなかった場合にコンテナが無限に再起動する問題を解消できる可能性があります (非常に大規模なデータベースやマルチノード構成で該当) 。 [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293) でバックポート: サブモジュールを含むソースコード付きのリソースを、Darwin 向けの特別なビルドタスクでビルドするようにしました。これにより、サブモジュールをチェックアウトせずに ClickHouse をビルドできます。 [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366) でバックポート: clickhouse-server パッケージからスタンドアロンの clickhouse-keeper を起動する際の問題を解決しました。 [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725) でバックポート: gh api url を使用するようにインテグレーションチェック用の Python スクリプトを修正し、CI テスト用の Readme を追加しました。 [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#55304](https://github.com/ClickHouse/ClickHouse/issues/55304)でバックポート: MaterializedPostgreSQL における &quot;Invalid number of rows in Chunk&quot; を修正しました (これは PostgreSQL バージョン &gt;= 13 で発生する可能性がありました) 。[#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#55018](https://github.com/ClickHouse/ClickHouse/issues/55018)でバックポート: 廃止されたフォーマット設定を別セクションに移動し、廃止されたフォーマット設定の使用時に `Unknown setting` 例外が発生しないよう、すべてのフォーマット設定とあわせて使うようにしました。[#54792](https://github.com/ClickHouse/ClickHouse/issues/54792) をクローズします。### ユーザー向け変更のドキュメント エントリ。[#54855](https://github.com/ClickHouse/ClickHouse/pull/54855) ([Kruglov Pavel](https://github.com/Avogar)).
* [#55097](https://github.com/ClickHouse/ClickHouse/issues/55097)でバックポート: クォーラムの待機中に Keeper の再試行が発生した場合、insert quorum が誤って満たされたと判定されることがありました。[#54543](https://github.com/ClickHouse/ClickHouse/issues/54543) を修正します。[#55026](https://github.com/ClickHouse/ClickHouse/pull/55026) ([Igor Nikonov](https://github.com/devcrafter)).
* [#55473](https://github.com/ClickHouse/ClickHouse/issues/55473)でバックポート: 同じ indices または projections が定義されていないテーブルからパーティションを attach できないようにしました。[#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#55461](https://github.com/ClickHouse/ClickHouse/issues/55461)でバックポート: 一部の `send_data_threads` が開始された後に `ShellCommandSource` コンストラクタ内で例外が発生した場合は、それらを join() する必要があります。そうしないと、`ThreadFromGlobalPool` のデストラクタで abort() がトリガーされます。[#55091](https://github.com/ClickHouse/ClickHouse/issues/55091) を修正します。[#55103](https://github.com/ClickHouse/ClickHouse/pull/55103) ([Alexander Gololobov](https://github.com/davenger)).
* [#55412](https://github.com/ClickHouse/ClickHouse/issues/55412)でバックポート: 存在しない ClickHouse ロールに対する LDAP の割り当てロール更新で発生するデッドロックを修正しました。[#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* [#55323](https://github.com/ClickHouse/ClickHouse/issues/55323)でバックポート: fs cache のバックグラウンド ダウンロードを修正しました。[#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#55349](https://github.com/ClickHouse/ClickHouse/issues/55349)でバックポート: スパース カラムに対する関数実行を修正しました (`DB::Exception: isDefaultAt is not implemented for Function: while executing 'FUNCTION Capture` エラーを修正) 。[#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* [#55475](https://github.com/ClickHouse/ClickHouse/issues/55475)でバックポート: S3 上の `ReplicatedMergeTree` エンジン ファミリー (ゼロコピー レプリケーションなし) で、デタッチされたパーティションを drop できない問題を修正しました。issue [#55225](https://github.com/ClickHouse/ClickHouse/issues/55225) を修正します。Arrays や Nested カラムのような複雑な data types で、S3 に不要な blobs が残るバグを修正しました。[#52393](https://github.com/ClickHouse/ClickHouse/issues/52393) を部分的に修正します。examples を提供してくれた @alifirat に深く感謝します。[#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* [#55399](https://github.com/ClickHouse/ClickHouse/issues/55399)でバックポート: 1 年前に導入された最適化に誤りがありました。これにより [#55272](https://github.com/ClickHouse/ClickHouse/issues/55272) をクローズします。[#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#55437](https://github.com/ClickHouse/ClickHouse/issues/55437) でバックポート: cast 演算子 (`::`) における Array のパースを修正。 [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* [#55635](https://github.com/ClickHouse/ClickHouse/issues/55635) でバックポート: クエリ内の OR フィルターでの仮想カラムによるフィルタリングを修正 (`MergeTree` の `_part*` フィルタリング、各種 `File`/`HDFS`/... エンジンの `_path`/`_file`、`Merge` の `_table`) 。 [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* [#55445](https://github.com/ClickHouse/ClickHouse/issues/55445) でバックポート: 一部のバージョンの MongoDB で発生していた接続の問題を修正。 [#55376](https://github.com/ClickHouse/ClickHouse/issues/55376)、[#55232](https://github.com/ClickHouse/ClickHouse/issues/55232) をクローズ。 [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#55534](https://github.com/ClickHouse/ClickHouse/issues/55534) でバックポート: 非同期 task のキャンセル時に例外が発生した場合、fiber が破棄されないことで起こり得るデッドロックを修正。 [#55185](https://github.com/ClickHouse/ClickHouse/issues/55185) をクローズ。 [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* [#55747](https://github.com/ClickHouse/ClickHouse/issues/55747) でバックポート: 循環する別名がある場合に QueryNormalizer がクラッシュする問題を修正。 [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* [#55760](https://github.com/ClickHouse/ClickHouse/issues/55760) でバックポート: クエリ内の OR フィルターでの仮想カラムによるフィルタリングを修正 (MergeTree の &#95;part* フィルタリング、各種 File/HDFS/... エンジンの &#95;path/&#95;file、Merge の &#95;table) 。 [#55678](https://github.com/ClickHouse/ClickHouse/pull/55678) ([Azat Khuzhin](https://github.com/azat)).
