<div id="2022-changelog">
  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v217104-stable-fixme-as-compared-to-v21797-stable">
  ### ClickHouse リリース v21.7.10.4-stable FIXME (v21.7.9.7-stable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#28898](https://github.com/ClickHouse/ClickHouse/issues/28898) にバックポート: 垂直マージで、事前定義された &quot;rows&#95;sources&quot; ではなく実際の tmp ファイルを使用するようにしました。これにより、tmp ディスク上に不要なディレクトリが生成されるのを防ぎます。 [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#27925](https://github.com/ClickHouse/ClickHouse/issues/27925) にバックポート: 負の数に対する PostgreSQL スタイルのキャスト (`::` 演算子) の不具合を修正しました。[#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* [#28752](https://github.com/ClickHouse/ClickHouse/issues/28752) にバックポート: 設定 `legacy_column_name_of_tuple_literal = 0` の分散クエリで、論理和の連鎖を `IN` に変換する処理 (設定 `optimize_min_equality_disjunction_chain_length` で制御) の不具合を修正しました。[#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#28509](https://github.com/ClickHouse/ClickHouse/issues/28509) にバックポート: distributed DDL queue のバックグラウンド処理中に、ZooKeeper のウォッチがリークする可能性がある問題を修正しました。[#26036](https://github.com/ClickHouse/ClickHouse/issues/26036) をクローズします。[#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#28570](https://github.com/ClickHouse/ClickHouse/issues/28570) にバックポート: `ReplicatedVersionedCollapsingMergeTree` の ALTER 後に `Existing table metadata in ZooKeeper differs in sorting key expression.` というエラーが発生する可能性があるバグを修正しました。[#28515](https://github.com/ClickHouse/ClickHouse/issues/28515) を修正しました。[#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* [#28598](https://github.com/ClickHouse/ClickHouse/issues/28598) にバックポート: `Nested` カラムと、名前にドットを含み `Nested` と同じプレフィックスを持つスカラーカラムがあるテーブルに対して SELECT した際、`There is no subcolumn` エラーが発生する問題を修正しました (例: `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`) 。[#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* [#28742](https://github.com/ClickHouse/ClickHouse/issues/28742) にバックポート: 渡されたパラメータが誤っている場合に、分散テーブルの作成時にコアダンプが発生する問題を修正しました。[#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* [#28788](https://github.com/ClickHouse/ClickHouse/issues/28788) にバックポート: ReplicatedMergeTreeQueue における無害な race condition を修正しました。ユーザーから見える問題ではないはずですが、微妙なバグにつながる可能性があります。[#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* [#28947](https://github.com/ClickHouse/ClickHouse/issues/28947) にバックポート: compact パーツからの subcolumns の読み取りを修正しました。[#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* [#28931](https://github.com/ClickHouse/ClickHouse/issues/28931) にバックポート: 定数使用時の高階 array functions の不具合 (`arrayCompact` での `SIGSEGV`、`arrayDifference` / `arrayCumSumNonNegative` での `ILLEGAL_COLUMN`) を修正しました。[#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴には含めない / 軽微
</div>

* ネイティブプロトコルの LC に対するチェックを追加。 [#27827](https://github.com/ClickHouse/ClickHouse/pull/27827) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* CHJIT のカスタムメモリマネージャー。 [#28236](https://github.com/ClickHouse/ClickHouse/pull/28236) ([Maksim Kita](https://github.com/kitaisreal)).
* nulls に対する dictGet のデフォルト実装。 [#28530](https://github.com/ClickHouse/ClickHouse/pull/28530) ([Maksim Kita](https://github.com/kitaisreal)).
* 同じプレフィックスを持つ配列でないカラムとネストされたカラムの使用を修正。 [2] [#28762](https://github.com/ClickHouse/ClickHouse/pull/28762) ([Anton Popov](https://github.com/CurtizJ)).
* compiled&#95;expression&#95;cache&#95;size を 128MB に引き下げ。 [#28816](https://github.com/ClickHouse/ClickHouse/pull/28816) ([Maksim Kita](https://github.com/kitaisreal)).
