<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 一部の複雑なクエリで、カラムの別名が式名と同一の場合に、不正な CAST が発生することがある問題を修正しました。これにより [#25447](https://github.com/ClickHouse/ClickHouse/issues/25447) と [#26914](https://github.com/ClickHouse/ClickHouse/issues/26914) が修正されます。この修正により後方互換性に影響が生じる可能性があります。異なる式に同じ名前が付いている場合は、例外がスローされます。`enable_optimize_predicate_expression` が設定されている一部のまれなケースでは、既存の動作に影響する可能性があります。[#26639](https://github.com/ClickHouse/ClickHouse/pull/26639) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* clickhouse-local では、ポート付きのローカルアドレスを常にリモートとして扱うようにしました。[#26736](https://github.com/ClickHouse/ClickHouse/pull/26736) ([Raúl Marín](https://github.com/Algunenano)).
* 異なるパラメータを持つ集約関数によって生成された集約関数の state に対して、`-Merge` combinator を持つパラメトリック 集約関数 を適用できないようにしました。たとえば、`fooState(42)(x)` の state は `fooMerge(s)` や `fooMerge(123)(s)` では確定できず、`fooMerge(42)(s)` のようにパラメータを明示的に指定し、かつ一致している必要があります。これは、最終化のためにのみパラメータを使用する `quantile` や `sequence*` などの一部の特殊な 集約関数 には影響しません。[#26847](https://github.com/ClickHouse/ClickHouse/pull/26847) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `Decimal` types のテキスト表現では、末尾のゼロを出力しないようにしました。例: scale 6 の decimal では、`1.230000` ではなく `1.23` が出力されます。これにより [#15794](https://github.com/ClickHouse/ClickHouse/issues/15794) はクローズされます。アプリケーションが何らかの形で末尾のゼロに依存していた場合、わずかな非互換が生じる可能性があります。出力フォーマットでのシリアライゼーションは、設定 `output_format_decimal_trailing_zeros` で制御できます。`toString` の実装および String へのキャストは無条件に変更されます。[#27680](https://github.com/ClickHouse/ClickHouse/pull/27680) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* インポート/エクスポート向けに `bzip2` 圧縮方式のサポートを追加しました。これにより [#22428](https://github.com/ClickHouse/ClickHouse/issues/22428) をクローズしました。 [#27377](https://github.com/ClickHouse/ClickHouse/pull/27377) ([Nikolay Degterinsky](https://github.com/evillique)).
* * ZooKeeper を介して user、ロール、行ポリシー、quotas、および settings profiles をレプリケート保存できるようにしました (実験的) 。 [#27426](https://github.com/ClickHouse/ClickHouse/pull/27426) ([Kevin Michel](https://github.com/kmichel-aiven)).
* 名前付きタプルを値のペアの配列に変換する関数 `tupleToNameValuePairs` を追加しました。 [#27505](https://github.com/ClickHouse/ClickHouse/pull/27505) ([Braulio Valdivielso Martínez](https://github.com/BraulioVM)).
* 集約関数 のパラメーターで with および select の定数を使用できるようにしました。 [#10945](https://github.com/ClickHouse/ClickHouse/issues/10945) をクローズしました。 [#27531](https://github.com/ClickHouse/ClickHouse/pull/27531) ([abel-cheng](https://github.com/abel-cheng)).
* ComplexKeyRangeHashed Dictionary を追加しました。これにより [#22029](https://github.com/ClickHouse/ClickHouse/issues/22029) をクローズしました。 [#27629](https://github.com/ClickHouse/ClickHouse/pull/27629) ([Maksim Kita](https://github.com/kitaisreal)).

* 日時関連の比較処理を特化し、パフォーマンスを向上。これにより [#27083](https://github.com/ClickHouse/ClickHouse/issues/27083) を修正。[#27122](https://github.com/ClickHouse/ClickHouse/pull/27122) ([Amos Bird](https://github.com/amosbird)).
* `clock_gettime` syscall の回数を減らすことで、`max_execution_time=0` の場合の高速なクエリのパフォーマンスを改善。[#27325](https://github.com/ClickHouse/ClickHouse/pull/27325) ([filimonov](https://github.com/filimonov)).
* `clock_gettime` syscall の回数を減らし、一部の高速なクエリでのパフォーマンス向上が見込まれます。[#27492](https://github.com/ClickHouse/ClickHouse/pull/27492) ([filimonov](https://github.com/filimonov)).

  #### 改善
