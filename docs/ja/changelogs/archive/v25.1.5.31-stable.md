  ### ClickHouse リリース v25.1.5.31-stable (48f17e8a805) FIXME v25.1.4.53-stable (c3f28b8bf5d) との比較

<div id="improvement">
  #### 改善
</div>

* [#76048](https://github.com/ClickHouse/ClickHouse/issues/76048)でバックポート: パフォーマンス向上のため、インメモリストレージへのコミット時には digest の計算を無効にする Keeper の改善を行いました。これは `keeper_server.digest_enabled_on_commit` 設定で有効化できます。なお、リクエストの前処理時には引き続き digest が計算されます。 [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* [#76315](https://github.com/ClickHouse/ClickHouse/issues/76315)でバックポート: `workload` 設定に未知の値が指定されたクエリに対する動作を選べるサーバー設定 `throw_on_unknown_workload` を追加しました。無制限のアクセスを許可する (デフォルト) か、`RESOURCE_ACCESS_DENIED` エラーを返すかを選択できます。これは、すべてのクエリでワークロードスケジューリングを使用するよう強制するのに役立ちます。 [#75999](https://github.com/ClickHouse/ClickHouse/pull/75999) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#76341](https://github.com/ClickHouse/ClickHouse/issues/76341) でバックポート: 一部の storages で未サポートの型をチェックするようにしました。[#74218](https://github.com/ClickHouse/ClickHouse/pull/74218) ([Pavel Kruglov](https://github.com/Avogar))。
* [#76362](https://github.com/ClickHouse/ClickHouse/issues/76362) でバックポート: null-safe 比較を使用した場合に、JOIN ON 句内で型エイリアスされた式に関する問題を修正しました。[#74970](https://github.com/ClickHouse/ClickHouse/pull/74970) ([Vladimir Cherkasov](https://github.com/vdimir))。
* [#75634](https://github.com/ClickHouse/ClickHouse/issues/75634) でバックポート: PSQL レプリケーションにおいて、捕捉されない例外によって発生するクラッシュを修正しました。[#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat))。
* [#76246](https://github.com/ClickHouse/ClickHouse/issues/76246) でバックポート: Sasl はあらゆる rpc 呼び出しで失敗する可能性がありますが、この修正により krb5 ticker の有効期限が切れた場合に呼び出しを再試行できるようになります。[#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004))。
* [#76161](https://github.com/ClickHouse/ClickHouse/issues/76161) でバックポート: projection の PK カラムに対する alter modify 時に、projection を再構築するようにしました。以前は、projection の PK に使われているカラムに alter modify を行うと、その後の selects 中に `CANNOT_READ_ALL_DATA` エラーが発生することがありました。[#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar))。
* [#76261](https://github.com/ClickHouse/ClickHouse/issues/76261) でバックポート: v24.12 で parallel hash が join algorithm としてデフォルトで有効化されたことを、Settings の変更履歴に記録しました。つまり、v24.12 より古い互換性レベルが設定されている場合、ClickHouse は引き続き非並列 hash を使って join を実行します。[#75870](https://github.com/ClickHouse/ClickHouse/pull/75870) ([Robert Schulze](https://github.com/rschu1ze))。
* [#76201](https://github.com/ClickHouse/ClickHouse/issues/76201) でバックポート: `clickhouse-library-bridge` は filesystem 上の任意のライブラリを開くことができるため、隔離された環境内でのみ安全に実行できます。clickhouse-server の近くで実行された場合の脆弱性を防ぐため、ライブラリのパスを configuration で指定された場所に制限します。この脆弱性は、**Arseniy Dugin** により [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて発見されました。[#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
