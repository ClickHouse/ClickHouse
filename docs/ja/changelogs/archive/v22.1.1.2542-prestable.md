  ### ClickHouse リリース v22.1.1.2542-prestable FIXME (v21.12.1.9017-prestableとの比較)

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 共有データ用の zero-copy マークの ZooKeeper パスを変更しました。リネームされたパーツについて、ZooKeeper 内のマークが削除されるよう修正しました。[#32061](https://github.com/ClickHouse/ClickHouse/pull/32061) ([ianton-ru](https://github.com/ianton-ru)).
* * スカラーサブクエリを考慮するようにしました。この変更により、スカラーサブクエリで読み取られた行が `query_log` に記録されるようになりました。スカラーサブクエリがキャッシュされている場合 (繰り返し実行される場合、または複数の行に対して呼び出される場合) 、読み取られた行は 1 回だけカウントされます。この変更により、スカラーサブクエリの実行中でもクエリを KILL したり、進捗を報告したりできるようになります。[#32271](https://github.com/ClickHouse/ClickHouse/pull/32271) ([Raúl Marín](https://github.com/Algunenano)).
* `left`、`right`、`leftUTF8`、`rightUTF8` 関数を追加しました。負の OFFSET (文字列末尾からのオフセット) を指定した `substringUTF8` 関数の実装上のエラーを修正しました。`left` および `right` 関数は、以前はパーサー内で実装されていました。アップグレードに関する注意: 別名のない `left` または `right` 関数を含む分散クエリは、クラスターに異なるバージョンの clickhouse-server が含まれている場合、例外をスローする可能性があります。クラスターのアップグレード中にこのエラーが発生した場合は、すべてのノードが同じバージョンになるよう、クラスターのアップグレードを完了してください。また、この問題を回避するために、クエリ内のカラムに別名 (`AS something`) を追加することもできます。[#33407](https://github.com/ClickHouse/ClickHouse/pull/33407) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新機能
</div>

* スパース シリアライゼーションを実装しました。これにより、多数のデフォルト値 (ゼロ) を含むカラムで、ディスク使用量を削減し、一部のクエリのパフォーマンスを向上できます。これは `ratio_of_defaults_for_sparse_serialization` を設定することで有効にできます。デフォルト値数の全値数に対する比率がこのしきい値を上回る場合、そのカラムにはスパース シリアライゼーションが動的に選択されます。シリアライゼーション (デフォルトまたはスパース) は各パーツ内のカラムごとに固定されますが、パーツごとに異なる場合があります。 [#22535](https://github.com/ClickHouse/ClickHouse/pull/22535) ([Anton Popov](https://github.com/CurtizJ)).
* GROUP BY grouping sets (a, b, (a, b)) のような grouping sets 関数を追加しました。 [#26869](https://github.com/ClickHouse/ClickHouse/pull/26869) ([taylor12805](https://github.com/taylor12805)).
* distributed query の実行中に、分片内のすべてのレプリカから読み取れるようにしました。これを有効にするには、`allow_experimental_parallel_reading_from_replicas=true` を設定し、`max_parallel_replicas` に任意の数値を指定してください。これにより [#26748](https://github.com/ClickHouse/ClickHouse/issues/26748) がクローズされます。 [#29279](https://github.com/ClickHouse/ClickHouse/pull/29279) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* ホストおよびポートの設定が変更されたときに、サーバーを起動・停止するようにしました。 [#30549](https://github.com/ClickHouse/ClickHouse/pull/30549) ([Kevin Michel](https://github.com/kmichel-aiven)).
* コメント付きで任意の種類のビューを作成できるようにしました。... [#31062](https://github.com/ClickHouse/ClickHouse/pull/31062) ([Vasily Nemkov](https://github.com/Enmk)).
* ClickHouse から Apache Hive にアクセスするための Hive table engine を実装しました。関連 RFC: [#29245](https://github.com/ClickHouse/ClickHouse/issues/29245)。 [#31104](https://github.com/ClickHouse/ClickHouse/pull/31104) ([李扬](https://github.com/taiyang-li)).
* * Zoo/Keeper によるクラスターの自動検出機能。 [#31442](https://github.com/ClickHouse/ClickHouse/pull/31442) ([Vladimir C](https://github.com/vdimir)).
* AWS S3 をバックエンドとするディスクと同様に、Azure Blob Storage をバックエンドとするディスクのサポートを追加しました。現在の実装では、基本的なディスク操作をすべて実行できます。 [#31505](https://github.com/ClickHouse/ClickHouse/pull/31505) ([Jakub Kuklis](https://github.com/jkuklis)).
* * MaterializedMySQL のテーブルスキーマをカスタマイズするための &quot;TABLE OVERRIDE&quot; 機能を追加しました。 [#32325](https://github.com/ClickHouse/ClickHouse/pull/32325) ([Stig Bakken](https://github.com/stigsb)).
* 入力フォーマット向けのデータスキーマ推論を実装しました。table function `file`、`url`、`s3`、`hdfs` と `clickhouse-local` のパラメータで、structure を省略するか、`auto` のみを指定できるようになりました。さらに、table engine `File`、`HDFS`、`S3`、`URL`、`Merge`、`Buffer`、`Distributed`、`ReplicatedMergeTree` の Create Query でも、structure を省略できるようになりました (新しいレプリカを追加する場合) 。[#32455](https://github.com/ClickHouse/ClickHouse/pull/32455) ([Kruglov Pavel](https://github.com/Avogar)).
* MaterializedPostgreSQL で TABLE OVERRIDE clause をサポートしました。RFC: [#31480](https://github.com/ClickHouse/ClickHouse/issues/31480)。[#32749](https://github.com/ClickHouse/ClickHouse/pull/32749) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `EXPLAIN TABLE OVERRIDE` クエリを追加しました。[#32836](https://github.com/ClickHouse/ClickHouse/pull/32836) ([Stig Bakken](https://github.com/stigsb)).
* `SET` クエリ、または HTTP request のクエリパラメータで無効な setting を定義した場合、エラーメッセージにその setting 名に似た候補が含まれるようになりました (候補が存在する場合) 。[#32946](https://github.com/ClickHouse/ClickHouse/pull/32946) ([Antonio Andelic](https://github.com/antonio2368)).
* aggregate functions `cramersV`、`cramersVBiasCorrected`、`theilsU`、`contingency` を追加しました。これらの関数は、カテゴリ値間の依存関係 (関連性の尺度) を計算します。いずれの関数も、実装にはクロス集計 (値の組み合わせごとの histogram) を使用しています。相関係数に似ていますが、数値に限らず任意の離散値に対して使えるものと考えることができます。[#33366](https://github.com/ClickHouse/ClickHouse/pull/33366) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 関数 `arrayLast` を追加しました。[#33390](https://github.com/ClickHouse/ClickHouse/issues/33390) をクローズしました。[#33415](https://github.com/ClickHouse/ClickHouse/pull/33415) ([Maksim Kita](https://github.com/kitaisreal)).
* MONTHNAME 関数を追加しました。[#33436](https://github.com/ClickHouse/ClickHouse/pull/33436) ([usurai](https://github.com/usurai)).
* ファイル拡張子の自動検出を追加しました。[#30918](https://github.com/ClickHouse/ClickHouse/issues/30918) をクローズしました。[#33443](https://github.com/ClickHouse/ClickHouse/pull/33443) ([zhongyuankai](https://github.com/zhongyuankai)).
* 関数 `arrayLastIndex` を追加しました。[#33465](https://github.com/ClickHouse/ClickHouse/pull/33465) ([Maksim Kita](https://github.com/kitaisreal)).
* 新しい h3 の補助関数 `h3DegsToRads`、`h3RadsToDegs`、`h3HexAreaKm2`、`h3CellAreaM2`、`h3CellAreaRads2` を追加しました。[#33479](https://github.com/ClickHouse/ClickHouse/pull/33479) ([Bharat Nallan](https://github.com/bharatnc)).
* file/hdfs/s3/url table function と HDFS/S3/URL table engine で、ファイル拡張子からフォーマットを検出できるようになりました。[#33565](https://github.com/ClickHouse/ClickHouse/pull/33565) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 重大ではない変更です。ごくまれに、すべてのレプリカで data part が失われた場合、いくつかの data part のマージ後に、後続のクエリでパーティションプルーニング時にスキップされるパーティション数が少なくなることがあります。影響はほとんどありません。 [#32220](https://github.com/ClickHouse/ClickHouse/pull/32220) ([Azat Khuzhin](https://github.com/azat)).
* `reinterpret` 関数のパフォーマンスをわずかに改善しました。 [#32587](https://github.com/ClickHouse/ClickHouse/pull/32587) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 文字列属性を持つディクショナリのメモリ割り当てを削減しました。 [#33466](https://github.com/ClickHouse/ClickHouse/pull/33466) ([Maksim Kita](https://github.com/kitaisreal)).
* パーサーで指数関数的なバックトラッキングが発生しないようにしました。これにより [#20158](https://github.com/ClickHouse/ClickHouse/issues/20158) をクローズします。 [#33481](https://github.com/ClickHouse/ClickHouse/pull/33481) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
