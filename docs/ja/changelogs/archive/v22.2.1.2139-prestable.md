<div id="new-feature">
  #### 新機能
</div>

* (本番環境には未対応のため、実験的機能に追加) `MemoryTracker` にメモリオーバーコミットを追加しました。ソフトメモリ制限を表すメモリ制限用の `guaranteed` 設定を追加しました。ハードメモリ制限に達した場合、`MemoryTracker` は最もオーバーコミットしているクエリのキャンセルを試みます。新しい設定 `memory_usage_overcommit_max_wait_microseconds` は、あるクエリが別のクエリの停止をどれだけ待機できるかを指定します。[#28375](https://github.com/ClickHouse/ClickHouse/issues/28375) をクローズしました。[#31182](https://github.com/ClickHouse/ClickHouse/pull/31182) ([Dmitry Novik](https://github.com/novikd)).
* この設定により、ユーザーは MergeTree/ReplicatedMergeTree で独自の重複排除ルールを指定できます。指定した場合、block ID の生成にはデータダイジェストの代わりにその値が使用されます。たとえば、各 INSERT ステートメントでこの設定に一意の値を指定することで、同じ挿入データが重複排除されるのを回避できます。これにより [#7461](https://github.com/ClickHouse/ClickHouse/issues/7461) をクローズします。[#32304](https://github.com/ClickHouse/ClickHouse/pull/32304) ([Igor Nikonov](https://github.com/devcrafter)).
* INSERT ステートメントで `DEFAULT` キーワードをサポートしました。[#6331](https://github.com/ClickHouse/ClickHouse/issues/6331) をクローズしました。[#33141](https://github.com/ClickHouse/ClickHouse/pull/33141) ([Andrii Buriachevskyi](https://github.com/0over)).
* ttests に信頼区間を追加しました。[#33260](https://github.com/ClickHouse/ClickHouse/pull/33260) ([achimbab](https://github.com/achimbab)).
* File/S3/HDFS エンジンで INSERT 時に新しいファイルを作成できるようにしました。HDFS ではファイルの上書きを可能にしました。デフォルトでは、S3 のファイルを上書きしようとすると例外をスローします。接尾辞を持つフォーマットでは、ファイルへのデータ追記を試みると例外をスローします。[#31640](https://github.com/ClickHouse/ClickHouse/issues/31640) をクローズしました。[#31622](https://github.com/ClickHouse/ClickHouse/issues/31622) をクローズしました。[#23862](https://github.com/ClickHouse/ClickHouse/issues/23862) をクローズしました。[#15022](https://github.com/ClickHouse/ClickHouse/issues/15022) をクローズしました。[#16674](https://github.com/ClickHouse/ClickHouse/issues/16674) をクローズしました。[#33302](https://github.com/ClickHouse/ClickHouse/pull/33302) ([Kruglov Pavel](https://github.com/Avogar)).
* `h3ToCenterChild` 関数を追加しました。[#33313](https://github.com/ClickHouse/ClickHouse/pull/33313) ([Bharat Nallan](https://github.com/bharatnc)).
* テキスト分類用のマージ関数を追加しました。[#23271](https://github.com/ClickHouse/ClickHouse/issues/23271) を参照してください。[#33314](https://github.com/ClickHouse/ClickHouse/pull/33314) ([Nikolay Degterinsky](https://github.com/evillique)).
* meanZTest を実装しました。[#33354](https://github.com/ClickHouse/ClickHouse/pull/33354) ([achimbab](https://github.com/achimbab)).
* * 関数 bitSlice を追加。 [#33360](https://github.com/ClickHouse/ClickHouse/pull/33360) ([RogerYK](https://github.com/RogerYK)).
* 新しい h3 のその他の関数 `edgeLengthKm`,`exactEdgeLengthKm`,`exactEdgeLengthM`,`exactEdgeLengthRads`,`numHexagons` を追加しました。[#33621](https://github.com/ClickHouse/ClickHouse/pull/33621) ([Bharat Nallan](https://github.com/bharatnc)).
* `DEGREES` および `RADIANS` 関数を追加しました。[#33769](https://github.com/ClickHouse/ClickHouse/pull/33769) ([Bharat Nallan](https://github.com/bharatnc)).
* パラメータ `--host` で複数のホストを指定できるようになりました。そのうちの 1 つが利用できない場合、クライアントは次のホストへの接続を試みます。[#33824](https://github.com/ClickHouse/ClickHouse/pull/33824) ([Filippov Denis](https://github.com/DF5HSE)).
* clickhouse-local でファイル名からフォーマットを検出できるようになりました。[#33829](https://github.com/ClickHouse/ClickHouse/pull/33829) ([Kruglov Pavel](https://github.com/Avogar)).
* PoolBase に新しいメソッド `expire()` を追加しました。これは、プール内の無効なオブジェクトを再割り当てするために使用されます。[#34076](https://github.com/ClickHouse/ClickHouse/pull/34076) ([lgbo](https://github.com/lgbo-ustc)).
* テーブル関数 `format(format_name, data)` を追加しました。[#34125](https://github.com/ClickHouse/ClickHouse/pull/34125) ([Kruglov Pavel](https://github.com/Avogar)).
* デフォルトのテーブルエンジンを作成できるようにしました。[#34187](https://github.com/ClickHouse/ClickHouse/pull/34187) ([Ilya Yatsishin](https://github.com/qoega)).
* `EPHEMERAL` カラム指定子が `CREATE TABLE` クエリに追加されました。[#9436](https://github.com/ClickHouse/ClickHouse/issues/9436) をクローズしました。[#34424](https://github.com/ClickHouse/ClickHouse/pull/34424) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* S3 への insert と merge で、可能な限りファイルを並列に書き込むようにしました。 [#33291](https://github.com/ClickHouse/ClickHouse/pull/33291) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* キーに多数のインターバルがある場合の RangeHashedDictionary のパフォーマンスを改善しました。 [#23821](https://github.com/ClickHouse/ClickHouse/issues/23821) を修正しました。 [#33516](https://github.com/ClickHouse/ClickHouse/pull/33516) ([Maksim Kita](https://github.com/kitaisreal)).
* メモリ比較を高速化するため、memcmpSmall 関数に x86 avx512 サポートを追加しました。これは ClickHouse を自分でコンパイルした場合にのみ動作します。 [#33706](https://github.com/ClickHouse/ClickHouse/pull/33706) ([hanqf-git](https://github.com/hanqf-git)).
* MV 実行向けに scalar cache を改良し、再導入しました。 [#33958](https://github.com/ClickHouse/ClickHouse/pull/33958) ([Raúl Marín](https://github.com/Algunenano)).
* ORDER BY tuple を ORDER BY カラムとほぼ同等の速度にしました。複数カラムの ORDER BY には特別な最適化があります: [https://github.com/ClickHouse/ClickHouse/pull/10831](https://github.com/ClickHouse/ClickHouse/pull/10831) 。これを tuple カラムにも適用することで効果が得られます。 [#34060](https://github.com/ClickHouse/ClickHouse/pull/34060) ([Amos Bird](https://github.com/amosbird)).
* `ExecuteScalarSubqueriesMatcher::visit` の潜在的なホットパスを小幅に改善しました。ここでは関数呼び出しのたびに `std::set<String>` が構築されていました。 [#34128](https://github.com/ClickHouse/ClickHouse/pull/34128) ([Federico Rodriguez](https://github.com/fedrod)).
* `Regexp` フォーマットのパフォーマンスをわずかに改善しました。 [#34202](https://github.com/ClickHouse/ClickHouse/pull/34202) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* ソートの代わりに nth&#95;element を使用するよう、quantilesExact{Low,High} を最適化しました。 [#34287](https://github.com/ClickHouse/ClickHouse/pull/34287) ([Daniel Kutenin](https://github.com/danlark1)).
* `LineAsString` フォーマットのパフォーマンスを改善しました。これにより [#34303](https://github.com/ClickHouse/ClickHouse/issues/34303) はクローズされます。[#34306](https://github.com/ClickHouse/ClickHouse/pull/34306) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* データパーツの読み込みを高速化しました。従来は並列化されておらず、設定 `part_loading_threads` は効果を持っていませんでした。[#4699](https://github.com/ClickHouse/ClickHouse/issues/4699) を参照してください。[#34310](https://github.com/ClickHouse/ClickHouse/pull/34310) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `_file` および `_path` 仮想カラム (ファイル系テーブルエンジン内) が `LowCardinality` になり、複数ファイルに対するクエリが高速化されます。これにより [#34300](https://github.com/ClickHouse/ClickHouse/issues/34300) はクローズされます。[#34317](https://github.com/ClickHouse/ClickHouse/pull/34317) ([flynn](https://github.com/ucasfl)).
* `mapPopulateSeries` 関数のパフォーマンスを改善しました。これにより [#33944](https://github.com/ClickHouse/ClickHouse/issues/33944) はクローズされます。[#34318](https://github.com/ClickHouse/ClickHouse/pull/34318) ([Maksim Kita](https://github.com/kitaisreal)).
* snapshot 実行時に不要なリストイテレーターを集めるためにベクターを使うようにし、その後の clearOutdatedNodes ではリストではなくベクターをたどるだけで済むため、高速化されます。[#34484](https://github.com/ClickHouse/ClickHouse/pull/34484) ([zhanglistar](https://github.com/zhanglistar)).
* URL、S3、File、HDFS の table function への insert のパフォーマンスを改善しました。これにより [#34348](https://github.com/ClickHouse/ClickHouse/issues/34348) はクローズされます。[#34510](https://github.com/ClickHouse/ClickHouse/pull/34510) ([Maksim Kita](https://github.com/kitaisreal)).
* [https://github.com/eBay/NuRaft/issues/209](https://github.com/eBay/NuRaft/issues/209) によると、このメソッドをロックする必要はありません。[#34523](https://github.com/ClickHouse/ClickHouse/pull/34523) ([zhanglistar](https://github.com/zhanglistar)).
