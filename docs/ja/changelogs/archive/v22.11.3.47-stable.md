<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#44113](https://github.com/ClickHouse/ClickHouse/issues/44113) でバックポート: SHA-512 サムをビルド工程に戻しました。 [#44017](https://github.com/ClickHouse/ClickHouse/pull/44017) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#44434](https://github.com/ClickHouse/ClickHouse/issues/44434) でバックポート: プロセスがハングした場合、2.5 時間後にストレステストを終了するようにしました。 [#44214](https://github.com/ClickHouse/ClickHouse/pull/44214) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#44380](https://github.com/ClickHouse/ClickHouse/issues/44380) でバックポート: まれに、類似したプレフィックスを持つ別のタスクが成功したため、バイナリが再ビルドされないことがありました。たとえば、`binary_darwin_aarch64` が成功したため、`binary_darwin` は再実行されませんでした。 [#44311](https://github.com/ClickHouse/ClickHouse/pull/44311) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#44560](https://github.com/ClickHouse/ClickHouse/issues/44560) でバックポート: 圧縮時のエラーが発生した場合に結合テストを再試行するようにしました。 [#44529](https://github.com/ClickHouse/ClickHouse/pull/44529) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">

* [#44756](https://github.com/ClickHouse/ClickHouse/issues/44756) でバックポート: [#40651](https://github.com/ClickHouse/ClickHouse/issues/40651) [#41404](https://github.com/ClickHouse/ClickHouse/issues/41404)。[#42126](https://github.com/ClickHouse/ClickHouse/pull/42126) ([Alexander Gololobov](https://github.com/davenger))。

* [#43620](https://github.com/ClickHouse/ClickHouse/issues/43620) でバックポート: Nullable(Decimal()) に対する sumMap() を修正。[#43414](https://github.com/ClickHouse/ClickHouse/pull/43414) ([Azat Khuzhin](https://github.com/azat))。
* [#43981](https://github.com/ClickHouse/ClickHouse/issues/43981) でバックポート: s3Cluster 関数が NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK エラーを返す問題を修正。[#43534](https://github.com/ClickHouse/ClickHouse/issues/43534) をクローズ。[#43629](https://github.com/ClickHouse/ClickHouse/pull/43629) ([chen](https://github.com/xiedeyantu))。
* [#44009](https://github.com/ClickHouse/ClickHouse/issues/44009) でバックポート: - AWS S3 上の大きな S3 オブジェクトでマルチパートアップロードを使用する処理を修正。[#43824](https://github.com/ClickHouse/ClickHouse/pull/43824) ([ianton-ru](https://github.com/ianton-ru))。
* [#43889](https://github.com/ClickHouse/ClickHouse/issues/43889) でバックポート: `ON CLUSTER` を伴う `ALTER ... RESET SETTING` を修正。これまでは 1 つのレプリカにしか適用されない可能性がありました。[#43843](https://github.com/ClickHouse/ClickHouse/issues/43843) を修正。[#43848](https://github.com/ClickHouse/ClickHouse/pull/43848) ([Elena Torró](https://github.com/elenatorro))。
* [#44147](https://github.com/ClickHouse/ClickHouse/issues/44147) でバックポート: `quantiles` 関数の未定義動作を修正。未初期化メモリにつながる可能性がありました。fuzzer により発見。この変更で [#44066](https://github.com/ClickHouse/ClickHouse/issues/44066) をクローズ。[#44067](https://github.com/ClickHouse/ClickHouse/pull/44067) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#44287](https://github.com/ClickHouse/ClickHouse/issues/44287) でバックポート: `ReadonlyReplica` Metric が負の値を取らないように修正。[#44220](https://github.com/ClickHouse/ClickHouse/pull/44220) ([Antonio Andelic](https://github.com/antonio2368))。
* [#44677](https://github.com/ClickHouse/ClickHouse/issues/44677) でバックポート: 定数引数を持つ関数 `IN` が `LowCardinality` と組み合わせて定数引数として使用された場合に発生しうる crash を修正。[#44221](https://github.com/ClickHouse/ClickHouse/issues/44221) を修正。[#44346](https://github.com/ClickHouse/ClickHouse/pull/44346) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
