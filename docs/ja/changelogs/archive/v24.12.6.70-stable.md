<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#76694](https://github.com/ClickHouse/ClickHouse/issues/76694) でバックポート: `max_rows_in_join = max_bytes_in_join = 0` の場合に `parallel_hash` で発生する不要な競合を修正しました。 [#75155](https://github.com/ClickHouse/ClickHouse/pull/75155) ([Nikita Taranov](https://github.com/nickitat)).

<div id="improvement">
  #### 改善
</div>

* [#76428](https://github.com/ClickHouse/ClickHouse/issues/76428)でバックポート: ユーザーから指摘されていた `clickhouse-disks` の使い勝手に関するいくつかの問題に対処しました。[#67136](https://github.com/ClickHouse/ClickHouse/issues/67136) をクローズします。[#73616](https://github.com/ClickHouse/ClickHouse/pull/73616) ([Daniil Ivanik](https://github.com/divanik)).
* [#76862](https://github.com/ClickHouse/ClickHouse/issues/76862)でバックポート: サーバーを再起動せずに、`max_remote_read_network_bandwidth_for_serve` と `max_remote_write_network_bandwidth_for_server` を実行中に再読み込みできるようにしました。[#74206](https://github.com/ClickHouse/ClickHouse/pull/74206) ([Kai Zhu](https://github.com/nauu)).
* [#76451](https://github.com/ClickHouse/ClickHouse/issues/76451)でバックポート: `postgresql` または `mysql` の table function で、`localhost:1234/handle` のようなエンドポイントを解析できるようにしました。これにより、[https://github.com/ClickHouse/ClickHouse/pull/52503](https://github.com/ClickHouse/ClickHouse/pull/52503) で導入されたリグレッションが修正されます。[#75944](https://github.com/ClickHouse/ClickHouse/pull/75944) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#76652](https://github.com/ClickHouse/ClickHouse/issues/76652)でバックポート: サーバー設定 `throw_on_unknown_workload` を追加しました。これにより、`workload` 設定に不明な値が指定されたクエリに対して、無制限のアクセスを許可する (デフォルト) か、`RESOURCE_ACCESS_DENIED` エラーを返すかを選択できます。これは、すべてのクエリで Workload scheduling を使用するよう強制するのに役立ちます。[#75999](https://github.com/ClickHouse/ClickHouse/pull/75999) ([Sergei Trifonov](https://github.com/serxa)).
* [#76671](https://github.com/ClickHouse/ClickHouse/issues/76671)でバックポート: Access Denied によりバックアップ中の S3 への multipart copy が失敗した場合に、適切な fallback を使用するようにしました。異なる認証情報を持つ bucket 間でバックアップを行うと、multipart copy によって Access Denied エラーが発生することがあります。[#76515](https://github.com/ClickHouse/ClickHouse/pull/76515) ([Antonio Andelic](https://github.com/antonio2368)).
* [#77200](https://github.com/ClickHouse/ClickHouse/issues/77200)でバックポート: 以前は `Replicated` データベースが、クエリで指定された認証情報をログに出力してしまうことがありました。この動作は修正されました。これにより [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123) をクローズします。[#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

* [#77254](https://github.com/ClickHouse/ClickHouse/issues/77254)でバックポート: 非同期 INSERT 中にエラーが発生した際、JSON column の不適切な rollback によりクラッシュする可能性がある問題を修正しました。[#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
