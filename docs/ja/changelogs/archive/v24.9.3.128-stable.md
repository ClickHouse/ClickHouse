<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#71361](https://github.com/ClickHouse/ClickHouse/issues/71361) でバックポート: JSONサブカラムのファイルで特殊記号がエスケープされていないことにより発生する可能性があるエラー `No such file or directory` を修正しました。[#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="new-feature">
  #### 新機能
</div>

* [#71318](https://github.com/ClickHouse/ClickHouse/issues/71318) でバックポート: 各認証方式が個別の有効期限を持てるようにし、その設定をユーザーエンティティから削除しました。 [#70090](https://github.com/ClickHouse/ClickHouse/pull/70090) ([Arthur Passos](https://github.com/arthurpassos)).

<div id="improvement">
  #### 改善
</div>

* [#70681](https://github.com/ClickHouse/ClickHouse/issues/70681)でバックポート: keeper から `user_directories` を同期する際の検証を行わないようにしました。[#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* [#71668](https://github.com/ClickHouse/ClickHouse/issues/71668)でバックポート: user/group が ID で指定されている場合、`clickhouse su` が失敗していました。この patch により、`UID:GID` 形式も受け付けるよう修正されました。### ユーザー向け変更のドキュメントエントリ。 [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#71938](https://github.com/ClickHouse/ClickHouse/issues/71938)でバックポート: `history` period の間に `HostResolver` を 3 回更新するようにしました。[#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#70936](https://github.com/ClickHouse/ClickHouse/issues/70936) でバックポート: `IS NULL` チェックが `NOT` などの別の関数の内側にある場合に、誤った結果を招く可能性がある JOIN ON 句の最適化の不具合を修正しました。[#67915](https://github.com/ClickHouse/ClickHouse/issues/67915) をクローズします。[#68049](https://github.com/ClickHouse/ClickHouse/pull/68049) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#70441](https://github.com/ClickHouse/ClickHouse/issues/70441) でバックポート: PostgreSQL エンジンの FixedString カラムへの挿入時に発生するクラッシュを修正しました。[#69584](https://github.com/ClickHouse/ClickHouse/pull/69584) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70563](https://github.com/ClickHouse/ClickHouse/issues/70563) でバックポート: `useDefaultImplementationForLowCardinalityColumns` が `true` を返すようオーバーライドすることで、`LowCardinality` カラムでの `getSubcolumn` の問題を修正しました。[#69831](https://github.com/ClickHouse/ClickHouse/pull/69831) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#70871](https://github.com/ClickHouse/ClickHouse/issues/70871) でバックポート: `tuple` 関数の評価時に、異なる named tuple 間でカラムが再利用されないようにしました。これにより [#70022](https://github.com/ClickHouse/ClickHouse/issues/70022) が修正されます。[#70103](https://github.com/ClickHouse/ClickHouse/pull/70103) ([Amos Bird](https://github.com/amosbird)).
* [#70434](https://github.com/ClickHouse/ClickHouse/issues/70434) でバックポート: JSONカラムで発生する可能性のあるクラッシュを修正しました。[#70172](https://github.com/ClickHouse/ClickHouse/pull/70172) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70309](https://github.com/ClickHouse/ClickHouse/issues/70309) でバックポート: arrayMin と arrayMax に関する複数の問題を修正しました。[#70207](https://github.com/ClickHouse/ClickHouse/pull/70207) ([Raúl Marín](https://github.com/Algunenano)).

* [#70428](https://github.com/ClickHouse/ClickHouse/issues/70428) でバックポート: max&#95;types パラメーターを減らす Dynamic type の ALTER によって、サーバークラッシュが発生する可能性がある問題を修正しました。[#70328](https://github.com/ClickHouse/ClickHouse/pull/70328) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70373](https://github.com/ClickHouse/ClickHouse/issues/70373) でバックポート: WITH FILL を誤って使用した際に発生するクラッシュを修正しました。[#70338](https://github.com/ClickHouse/ClickHouse/pull/70338) ([Raúl Marín](https://github.com/Algunenano)).
* [#70690](https://github.com/ClickHouse/ClickHouse/issues/70690) でバックポート: `SYSTEM DROP FORMAT SCHEMA CACHE FOR Protobuf` における use-after-free の可能性を修正しました。[#70358](https://github.com/ClickHouse/ClickHouse/pull/70358) ([Azat Khuzhin](https://github.com/azat)).
* [#70496](https://github.com/ClickHouse/ClickHouse/issues/70496) でバックポート: JSON サブオブジェクトのサブカラムに対する GROUP BY の実行中に発生するクラッシュを修正しました。[#70374](https://github.com/ClickHouse/ClickHouse/pull/70374) ([Pavel Kruglov](https://github.com/Avogar)).
* [#70484](https://github.com/ClickHouse/ClickHouse/issues/70484)でバックポート: パーツに行が含まれていない場合、Vertical Merge のためのパーツのプリフェッチを行わないようにしました。[#70452](https://github.com/ClickHouse/ClickHouse/pull/70452) ([Antonio Andelic](https://github.com/antonio2368)).
* [#70558](https://github.com/ClickHouse/ClickHouse/issues/70558)でバックポート: ラムダ関数を含む WHERE 句で発生するクラッシュを修正しました。[#70464](https://github.com/ClickHouse/ClickHouse/pull/70464) ([Raúl Marín](https://github.com/Algunenano)).

* [#70653](https://github.com/ClickHouse/ClickHouse/issues/70653)でバックポート: アラインメントがずれたメモリ上でのステートフルなウィンドウ関数の作成を修正しました。[#70631](https://github.com/ClickHouse/ClickHouse/pull/70631) ([Raúl Marín](https://github.com/Algunenano)).
* [#70759](https://github.com/ClickHouse/ClickHouse/issues/70759)でバックポート: 空でないデフォルト式を持つ `Array` 型のカラムを追加した後、`SELECT` やマージ処理でまれに発生していたクラッシュを修正しました。[#70695](https://github.com/ClickHouse/ClickHouse/pull/70695) ([Anton Popov](https://github.com/CurtizJ)).
