  ### ClickHouse リリース v22.12.5.34-stable (b82d6401ca1) FIXME v22.12.4.76-stable (cb5772db805) との比較

<div id="improvement">
  #### 改善
</div>

* [#46983](https://github.com/ClickHouse/ClickHouse/issues/46983) でバックポート: `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` がすべてのレプリカに適用されるようにしました。これは、`ALTER TABLE t MOVE` がレプリケートされないためです。[#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#45729](https://github.com/ClickHouse/ClickHouse/issues/45729) でバックポート: 重複する主キーに遭遇した際のキーの説明を修正しました。これは projections で発生する可能性があります。詳細は [#45590](https://github.com/ClickHouse/ClickHouse/issues/45590) を参照してください。[#45686](https://github.com/ClickHouse/ClickHouse/pull/45686) ([Amos Bird](https://github.com/amosbird))。
* [#46398](https://github.com/ClickHouse/ClickHouse/issues/46398) でバックポート: `SYSTEM UNFREEZE` クエリが例外 `CANNOT_PARSE_INPUT_ASSERTION_FAILED` により失敗する問題を修正しました。[#46325](https://github.com/ClickHouse/ClickHouse/pull/46325) ([Aleksei Filatov](https://github.com/aalexfvk))。
* [#46903](https://github.com/ClickHouse/ClickHouse/issues/46903) でバックポート: - QueryNormalizer における alias の誤った再帰を修正しました。[#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano))。
* [#47210](https://github.com/ClickHouse/ClickHouse/issues/47210) でバックポート: native TCP プロトコルおよび HTTP プロトコル経由の `INSERT` クエリが、場合によっては正しくキャンセルされない問題がありました。これにより、クライアントがクエリをキャンセルした場合やクライアントが停止した場合、またはまれにネットワークエラーが発生した場合に、クエリが部分的に適用される可能性がありました。その結果、deduplication が正しく機能しない可能性がありました。[#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) と [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377) を修正します。[#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#47157](https://github.com/ClickHouse/ClickHouse/issues/47157) でバックポート: - `min` と `max` を使用した aggregate 最適化における算術演算を修正しました。[#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94))。
* [#46881](https://github.com/ClickHouse/ClickHouse/issues/46881) でバックポート: `maxIntersections` 関数に関する MSan レポートを修正しました。これにより [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126) をクローズします。[#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#47359](https://github.com/ClickHouse/ClickHouse/issues/47359) でバックポート: 分散クエリのキャンセル時に発生する可能性のあるデッドロックを修正しました。[#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar))。
