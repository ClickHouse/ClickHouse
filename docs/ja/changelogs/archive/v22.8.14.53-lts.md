<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#45845](https://github.com/ClickHouse/ClickHouse/issues/45845)でバックポート: 多数の`Array`/`Map`/`Nested`カラムを持つテーブルから読み取る短時間の`SELECT`クエリのパフォーマンスを改善しました。[#45630](https://github.com/ClickHouse/ClickHouse/pull/45630) ([Anton Popov](https://github.com/CurtizJ)).
* [#46374](https://github.com/ClickHouse/ClickHouse/issues/46374)でバックポート: リモートでないディスクでの vertical merge におけるメモリ使用量が大きすぎる問題を修正しました。リモートディスクに対して `max_insert_delayed_streams_for_parallel_write` を適用するようにしました。[#46275](https://github.com/ClickHouse/ClickHouse/pull/46275) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#46358](https://github.com/ClickHouse/ClickHouse/issues/46358)でバックポート: Compact フォーマットのパーツで Vertical merge アルゴリズムを使用できるようにしました。これにより、ClickHouse server はバックグラウンド処理で使用するメモリを大幅に削減できます。これにより [#46084](https://github.com/ClickHouse/ClickHouse/issues/46084) はクローズされます。[#46282](https://github.com/ClickHouse/ClickHouse/pull/46282) ([Anton Popov](https://github.com/CurtizJ)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#46112](https://github.com/ClickHouse/ClickHouse/issues/46112)でバックポート: パッケージでは `adduser` ツールを使用していないため、その依存関係を削除しました。これにより [#44934](https://github.com/ClickHouse/ClickHouse/issues/44934) が修正されます。[#45011](https://github.com/ClickHouse/ClickHouse/pull/45011) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46482](https://github.com/ClickHouse/ClickHouse/issues/46482)でバックポート: standalone clickhouse-keeper 向けの不要なビルドを削除しました。[#46367](https://github.com/ClickHouse/ClickHouse/pull/46367) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#46505](https://github.com/ClickHouse/ClickHouse/issues/46505)でバックポート: 少し前に ccache の圧縮は `zst` に変更されましたが、デフォルトでは `gz` アーカイブがダウンロードされていました。`zst` アーカイブを優先するようにして、これを修正しました。[#46490](https://github.com/ClickHouse/ClickHouse/pull/46490) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#45908](https://github.com/ClickHouse/ClickHouse/issues/45908) でバックポート: テーブルのメタデータ内の EPHEMERAL カラムで、パースできないデフォルト値に関するバグを修正しました。[#44026](https://github.com/ClickHouse/ClickHouse/pull/44026) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* [#46238](https://github.com/ClickHouse/ClickHouse/issues/46238) でバックポート: `c-ares` 周辺でいくつかの seg fault が報告されていました。最近確認された stack traces は、いずれも `std::unodered_set<>` への inserting 中に失敗しています。根本原因を特定できたと考えており、未処理の queries が原因のようです。この PR 以前は、CH は `c-ares` チャネル内のファイルディスクリプタを待機するために `poll` を呼び出していました。[poll docs](https://man7.org/linux/man-pages/man2/poll.2.html) によると、戻り値が負の場合は error の発生を意味します。そのため、実行を中断して失敗を返していました。問題は、システム割り込みが発生した場合にも `poll` が負の値を返すことです。システム割り込みは processing の失敗や終了を意味しないにもかかわらず、負の値をチェックしていたため中断してしまっていました。実行が中断されるとスタック全体が破棄され、その中には c-ares のコールバックの `void *` パラメータとして渡される `std::unordered_set<std::string>` も含まれます。その後 c-ares がリクエストを完了するとコールバックが呼び出され、無効なメモリアドレスにアクセスして segfault を引き起こしていました。[#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos))。
* [#45727](https://github.com/ClickHouse/ClickHouse/issues/45727) でバックポート: 重複する主キーに遭遇した際のキーの説明を修正しました。これは projections で発生することがあります。詳細は [#45590](https://github.com/ClickHouse/ClickHouse/issues/45590) を参照してください。[#45686](https://github.com/ClickHouse/ClickHouse/pull/45686) ([Amos Bird](https://github.com/amosbird))。
* [#46394](https://github.com/ClickHouse/ClickHouse/issues/46394) でバックポート: `SYSTEM UNFREEZE` queries が例外 `CANNOT_PARSE_INPUT_ASSERTION_FAILED` により失敗する問題を修正しました。[#46325](https://github.com/ClickHouse/ClickHouse/pull/46325) ([Aleksei Filatov](https://github.com/aalexfvk))。
* [#46442](https://github.com/ClickHouse/ClickHouse/issues/46442) でバックポート: フォーマット `VALUES` で送信された無効なデータにより、非同期挿入で `LOGICAL_ERROR` が発生する可能性がある問題を修正しました。[#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ))。
* [#46674](https://github.com/ClickHouse/ClickHouse/issues/46674) でバックポート: 関数 `arrayMap` における定数 `LowCardinality` argument の不正な processing を修正しました。このバグは、リリースビルドでは segfault を、デバッグビルドでは論理エラー `Bad cast` を引き起こす可能性がありました。[#46569](https://github.com/ClickHouse/ClickHouse/pull/46569) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#46879](https://github.com/ClickHouse/ClickHouse/issues/46879) でバックポート: `maxIntersections` 関数における MSan レポートを修正しました。これにより [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126) をクローズします。[#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#46871](https://github.com/ClickHouse/ClickHouse/issues/46871) でバックポート: `Map` データ型のバグを修正しました。これにより [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855) をクローズします。[#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
