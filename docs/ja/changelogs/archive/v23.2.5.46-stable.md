  # 2023年の変更履歴
</div>

<div id="clickhouse-release-v232546-stable-b50faecbb12-fixme-as-compared-to-v232412-stable-8fe866cb035">
  ### ClickHouse リリース v23.2.5.46-stable (b50faecbb12) FIXME (v23.2.4.12-stable (8fe866cb035) との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#48164](https://github.com/ClickHouse/ClickHouse/issues/48164) でバックポート: 利用できない依存テーブルを持つ materialized view にアタッチした際に `UNKNOWN_TABLE` 例外が発生する問題を修正しました。これは、バックアップから状態を復元しようとする際に役立つ可能性があります。[#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#48216](https://github.com/ClickHouse/ClickHouse/issues/48216)でバックポート: `ccache` の代わりに `sccache` を使用し、キャッシュのバックエンドに S3 を使うようにしました。[#46240](https://github.com/ClickHouse/ClickHouse/pull/46240) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#48256](https://github.com/ClickHouse/ClickHouse/issues/48256)でバックポート: `clickhouse/clickhouse-keeper` イメージは、これまで `-alpine` タグ (たとえば `latest-alpine`) 付きでしかプッシュされていませんでした。[https://github.com/ClickHouse/examples/pull/2](https://github.com/ClickHouse/examples/pull/2) での提案を受け、現在は接尾辞なしでもプッシュされるようになりました。[#48236](https://github.com/ClickHouse/ClickHouse/pull/48236) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
