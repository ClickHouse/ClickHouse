<div id="clickhouse-release-v24913278-stable-6d058d82a8e-fixme-as-compared-to-v24911-new-e02b434d2fc">
  ### ClickHouse リリース v24.9.1.3278-stable (6d058d82a8e) FIXME v24.9.1.1-new (e02b434d2fc) との比較
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* サブクエリが括弧内にある場合、`UNION` を含む一連のクエリで `FORMAT` の前に `SETTINGS` を記述できるようにしました。これにより [#39712](https://github.com/ClickHouse/ClickHouse/issues/39712) が解決されます。あわせて、クエリ内で SETTINGS 句が連続して 2 回指定された場合の動作も変更しました。対応するサブクエリでは、最も近い SETTINGS 句が優先されます。以前のバージョンでは、最も外側の SETTINGS 句が内側のものより優先されることがありました。[#60197](https://github.com/ClickHouse/ClickHouse/pull/60197) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Replicated データベースでテーブルを作成する際に UUID を明示的に指定することを許可しないようにしました。また、Replicated データベース内の *MergeTree テーブルに対して ZooKeeper パスとレプリカ名を明示的に指定することも許可しないようにしました。[#66104](https://github.com/ClickHouse/ClickHouse/pull/66104) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Dynamic 型を再実装しました。これにより、動的データ型数の上限に達した場合、新しい型は String に CAST されず、データ型をバイナリエンコードした特別なデータ構造にバイナリ形式で格納されます。さらに、これまでに Dynamic カラムへ挿入されたあらゆる型を、サブカラムとして読み取れるようになりました。[#68132](https://github.com/ClickHouse/ClickHouse/pull/68132) ([Pavel Kruglov](https://github.com/Avogar)).
* `a[b].c` のような式が名前付きタプルでサポートされるようになり、さらに `expr().name` のように任意の式に対する名前付き添字もサポートされるようになりました。これは JSON の処理に役立ちます。これにより [#54965](https://github.com/ClickHouse/ClickHouse/issues/54965) が解決されます。以前のバージョンでは、`expr().name` 形式の式は `tupleElement(expr(), name)` として解析され、クエリ アナライザは対応するタプル要素ではなく `name` というカラムを探していましたが、新しいバージョンでは `tupleElement(expr(), 'name')` に変更されました。ほとんどの場合、以前のバージョンは動作していませんでしたが、この変更によって非互換が生じる非常に特殊なケースは考えられます。たとえば、タプル要素名を、そのタプル要素名とは異なる名前のカラムまたはエイリアスに格納していた場合です: `SELECT 'b' AS a, CAST([tuple(123)] AS 'Array(Tuple(b UInt8))') AS t, t[1].a`。このようなクエリを使っていた可能性はきわめて低いものの、この変更は後方互換性に影響する可能性があるものとして扱う必要があります。[#68435](https://github.com/ClickHouse/ClickHouse/pull/68435) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 設定 `print_pretty_type_names` が有効な場合、`SHOW CREATE TABLE` ステートメント、`formatQuery` 関数、および `clickhouse-client` と `clickhouse-local` の対話型モードで、`Tuple` データ型が Pretty 形式で表示されるようになりました。以前のバージョンでは、この設定は `DESCRIBE` クエリと `toTypeName` にのみ適用されていました。これにより [#65753](https://github.com/ClickHouse/ClickHouse/issues/65753) が解決されます。[#68492](https://github.com/ClickHouse/ClickHouse/pull/68492) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### 新機能
</div>

* 関数 `toStartOfInterval()` に、TimescaleDB の `time_bucket()` 関数および PostgreSQL の `date_bin()` 関数を再現する新しいオーバーロードが追加されました。([#55619](https://github.com/ClickHouse/ClickHouse/issues/55619))。これにより、日付またはタイムスタンプの値を、指定したインターバルの倍数に *任意* の origin から揃えられるようになります (*固定* の origin である 0000-01-01 00:00:00.000 ではなく) 。たとえば、`SELECT toStartOfInterval(toDateTime('2023-01-01 14:45:00'), INTERVAL 1 MINUTE, toDateTime('2023-01-01 14:35:30'));` は `2023-01-01 14:44:30` を返します。これは、origin `2023-01-01 14:35:30` を起点とする 1 分インターバルの倍数です。[#56738](https://github.com/ClickHouse/ClickHouse/pull/56738) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* `ATTACH PARTITION ALL FROM` のサポートを追加しました。[#61987](https://github.com/ClickHouse/ClickHouse/pull/61987) ([Kirill Nikiforov](https://github.com/allmazz)).
* 設定 `input_format_try_infer_variants` を追加しました。これにより、テキストフォーマットにおいてカラム/Array 要素に複数の候補型がある場合、スキーマ推論時に Variant 型を推論できるようになります。[#63798](https://github.com/ClickHouse/ClickHouse/pull/63798) ([Shaun Struwig](https://github.com/Blargian)).
* JSONCompactWithProgress フォーマットを導入しました。これにより、ClickHouse は各行を newline-delimited JSON object として出力し、メタデータ、data、progress、totals、statistics を含めます。[#66205](https://github.com/ClickHouse/ClickHouse/pull/66205) ([Alexey Korepanov](https://github.com/alexkorep)).
* 新しい JSON データ型を実装しました。[#66444](https://github.com/ClickHouse/ClickHouse/pull/66444) ([Pavel Kruglov](https://github.com/Avogar)).
* 設定 `input_format_json_empty_as_default` を追加しました。有効にすると、JSON 入力内の空フィールドをデフォルト値として扱います。[#59339](https://github.com/ClickHouse/ClickHouse/issues/59339) をクローズしました。[#66782](https://github.com/ClickHouse/ClickHouse/pull/66782) ([Alexis Arnaud](https://github.com/a-a-f)).
* 文字列の一部を別の文字列で置き換える関数 `overlay` と `overlayUTF8` を追加しました。例: `SELECT overlay('Hello New York', 'Jersey', 11)` は `Hello New Jersey` を返します。[#66933](https://github.com/ClickHouse/ClickHouse/pull/66933) ([李扬](https://github.com/taiyang-li)).
* 新しいコマンドである、パーティション内での論理削除 `DELETE FROM [db.]table [ON CLUSTER cluster] [IN PARTITION partition_expr] WHERE expr;` を追加しました。&#96;&#96;&#96; VM-114-29-tos :) select * from ads&#95;app&#95;poster&#95;ip&#95;source&#95;channel&#95;di&#95;replicated&#95;local;. [#67805](https://github.com/ClickHouse/ClickHouse/pull/67805) ([sunny](https://github.com/sunny19930321)).
* `Interval` データ型の値の比較を実装し、最小の supertype に変換して比較できるようになりました。[#68057](https://github.com/ClickHouse/ClickHouse/pull/68057) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* CREATE ステートメントでデフォルトで IF NOT EXISTS の動作になるよう、create&#95;if&#95;not&#95;exists 設定を追加しました。[#68164](https://github.com/ClickHouse/ClickHouse/pull/68164) ([Peter Nguyen](https://github.com/petern48)).
* Azure およびローカルで Iceberg テーブルを読み取れるようになりました。[#68210](https://github.com/ClickHouse/ClickHouse/pull/68210) ([Daniil Ivanik](https://github.com/divanik)).
* JSON column type の内容をより適切に introspection するための aggregate functions distinctDynamicTypes/distinctJSONPaths/distinctJSONPathsAndTypes を追加しました。[#68463](https://github.com/ClickHouse/ClickHouse/pull/68463) ([Pavel Kruglov](https://github.com/Avogar)).
* タグを指定してクエリ cache エントリを削除できるようになりました。たとえば、`SELECT 1 SETTINGS use_query_cache = true, query_cache_tag = 'abc'` で作成されたクエリ cache エントリは、`SYSTEM DROP QUERY CACHE TAG 'abc'` で削除できます (もちろん、`SYSTEM DROP QUERY CACHE` とするだけで query cache 全体をクリアすることもできます) 。[#68477](https://github.com/ClickHouse/ClickHouse/pull/68477) ([Michał Tabaszewski](https://github.com/pinsvin00)).
* named collections の storage encryption を追加しました。[#68615](https://github.com/ClickHouse/ClickHouse/pull/68615) ([Pablo Marcos](https://github.com/pamarcos)).
* 文字列の RIPEMD-160 暗号学的 hash を計算する `ripeMD160` 関数を追加しました。例: `SELECT hex(ripeMD160('The quick brown fox jumps over the lazy dog'))` は `37F332F68DB77BD9D7EDD4969571AD671CF9DD3B` を返します。[#68639](https://github.com/ClickHouse/ClickHouse/pull/68639) ([Dergousov Maxim](https://github.com/m7kss1)).
* URL table engine に仮想カラム &#95;headers を追加しました。[#65026](https://github.com/ClickHouse/ClickHouse/issues/65026) をクローズしました。[#68867](https://github.com/ClickHouse/ClickHouse/pull/68867) ([flynn](https://github.com/ucasfl)).
* 利用可能な projections を追跡するための `system.projections` table を追加しました。[#68901](https://github.com/ClickHouse/ClickHouse/pull/68901) ([Jordi Villar](https://github.com/jrdi)).
* Spark 互換性 (arrays&#95;zip) のための新しい関数 `arrayZipUnaligned` を追加しました。これは元の `arrayZip` をベースに、長さの揃っていない Arrays を扱えるようにするものです。&#96;&#96;&#96; sql SELECT arrayZipUnaligned([1], [1, 2, 3]). [#69030](https://github.com/ClickHouse/ClickHouse/pull/69030) ([李扬](https://github.com/taiyang-li)).
* HTTP header `X-ClickHouse-Summary` に `RealTimeMicroseconds` Metric を追加しました。これにより、`system.query_log` を確認しなくても、リクエストの CPU time を把握できます。[#69032](https://github.com/ClickHouse/ClickHouse/pull/69032) ([Alejandro](https://github.com/alexon1234)).
* ノードをアトミックにコピー/移動する Keeper client 向けの cp/mv コマンドを追加しました。[#69034](https://github.com/ClickHouse/ClickHouse/pull/69034) ([Mikhail Artemenko](https://github.com/Michicosun)).
* 関数 `arrayAUC` に argument `scale` (デフォルト: `true`) を追加しました。これにより、正規化 step をスキップできます (issue [#69609](https://github.com/ClickHouse/ClickHouse/issues/69609)) 。[#69717](https://github.com/ClickHouse/ClickHouse/pull/69717) ([gabrielmcg44](https://github.com/gabrielmcg44)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 左ハッシュ結合または inner ハッシュ結合で、左テーブル側のキーが密な場合に、右テーブルをキーごとに並べ替えることで、join の性能を改善しました。 [#60341](https://github.com/ClickHouse/ClickHouse/pull/60341) ([kevinyhzou](https://github.com/KevinyhZou)).
* 遅延出力のために `AddedColumns` に `RowRefList` または `RowRef` を追加し、`buildOutput` では `RowRefList`/`RowRef` を出力に使用するようにするとともに、`buildOutput` の for ループから `is_join_get` 条件を削除することで、すべての join の性能を改善しました。 [#63677](https://github.com/ClickHouse/ClickHouse/pull/63677) ([kevinyhzou](https://github.com/KevinyhZou)).
* 再起動を高速化するため、ファイルシステムキャッシュのメタデータを起動プロセスとは非同期に読み込むようにしました。 [#65736](https://github.com/ClickHouse/ClickHouse/pull/65736) ([Daniel Pozo Escalona](https://github.com/danipozo)).
* 関数 `array` と `map` を最適化し、一般的ないくつかのケースで大幅に高速に処理できるようにしました。 [#67707](https://github.com/ClickHouse/ClickHouse/pull/67707) ([李扬](https://github.com/taiyang-li)).
* 特にカラムに NULL が含まれない場合の ORC 文字列読み取りを中心に、軽微な最適化を行いました。 [#67794](https://github.com/ClickHouse/ClickHouse/pull/67794) ([李扬](https://github.com/taiyang-li)).
* merges のスケジューリング処理のオーバーヘッドを削減することで、merges 全体の性能を改善しました。 [#68016](https://github.com/ClickHouse/ClickHouse/pull/68016) ([Anton Popov](https://github.com/CurtizJ)).
* profile が設定されておらず、credentials も設定されておらず、さらに IMDS も利用できない場合 (たとえば、Cloud 外のマシンから Public bucket をクエリしている場合) の S3 へのリクエストを高速化しました。これにより [#52771](https://github.com/ClickHouse/ClickHouse/issues/52771) をクローズします。 [#68082](https://github.com/ClickHouse/ClickHouse/pull/68082) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* consistent hash によってレプリカ間で marks の分配単位を決定する新しいアルゴリズムを追加しました。異なる読み取り pattern に応じて異なる数の marks を選択し、性能を改善します。 [#68424](https://github.com/ClickHouse/ClickHouse/pull/68424) ([Nikita Taranov](https://github.com/nickitat)).
* RowInputFormatWithNamesAndTypes でフォーマット reader の devirtualize を試み、性能改善につながるかを検証しました。 [#68437](https://github.com/ClickHouse/ClickHouse/pull/68437) ([李扬](https://github.com/taiyang-li)).
* CPU 使用率を最大化するため、キー付き parallel merge の実装を追加しました。 [#68441](https://github.com/ClickHouse/ClickHouse/pull/68441) ([Jiebin Sun](https://github.com/jiebinn)).
* ORC output format で文字列カラムに対する辞書エンコーディングを有効化できるよう、設定 `output_format_orc_dictionary_key_size_threshold` を追加しました。これにより、出力される ORC ファイルのサイズを削減し、読み取り性能を大幅に向上できます。 [#68591](https://github.com/ClickHouse/ClickHouse/pull/68591) ([李扬](https://github.com/taiyang-li)).
* hive パーティション化では、必要なファイルのみを読み取るようにしました。 [#68963](https://github.com/ClickHouse/ClickHouse/pull/68963) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* ノードとその配下のサブツリー全体を削除する新しい Keeper リクエスト RemoveRecursive を導入しました。 [#69332](https://github.com/ClickHouse/ClickHouse/pull/69332) ([Mikhail Artemenko](https://github.com/Michicosun)).
* ベクトル類似度索引へのデータ追加を並列に行うことで、insert 性能を向上させました。 [#69493](https://github.com/ClickHouse/ClickHouse/pull/69493) ([flynn](https://github.com/ucasfl)).
* これまで、parallel replica の announcement 処理における part deduplication ロジックのアルゴリズム計算量は O(n^2) であり、多数の part (またはパーティション) を持つテーブルでは無視できない時間がかかることがありました。この変更により、計算量は O(n*log(n)) になります。 [#69596](https://github.com/ClickHouse/ClickHouse/pull/69596) ([Alexander Gololobov](https://github.com/davenger)).

<div id="improvement">
  #### 改善
</div>

* 小さなエンティティのパースに関連するコードベースの一部を堅牢化しました。次の (軽微な) バグが見つかり、修正されました: - `DeltaLake` テーブルが Bool でパーティション分割されている場合、パーティション値が常に false として解釈される。- `ExternalDistributed` テーブルが、指定されたアドレス内の単一のシャードしか使用していなかった。`max_threads` 設定などの値が、`auto(N)` ではなく `'auto(N)'` として表示されていた。[#52503](https://github.com/ClickHouse/ClickHouse/pull/52503) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* リフレッシャブルmaterialized view の改善: append モード (`... REFRESH EVERY 1 MINUTE APPEND ...`) により、テーブル全体を上書きする代わりに既存のテーブルへ行を追加できるようになりました。再試行 (デフォルトでは無効で、クエリの SETTINGS セクションで設定) 、現在実行中の refresh を待機する `SYSTEM WAIT VIEW <name>` クエリ、そのほかいくつかの修正が含まれます。[#58934](https://github.com/ClickHouse/ClickHouse/pull/58934) ([Michael Kolupaev](https://github.com/al13n321)).
* CPU 使用率の計上に、システム全体のメトリクスではなく cgroup 固有のメトリクスを使用するようになりました。[#62003](https://github.com/ClickHouse/ClickHouse/pull/62003) ([Nikita Taranov](https://github.com/nickitat)).
* リモート S3 ディスクの I/O スケジューリングが、`bandwidth_limit` のスロットリング問題を解消するため、S3 リクエスト全体ではなく HTTP ソケットストリーム単位で行われるようになりました。[#65182](https://github.com/ClickHouse/ClickHouse/pull/65182) ([Sergei Trifonov](https://github.com/serxa)).
* ユーザーが 1 つだけでなく複数の認証方式を持てるようにしました。また、認証方式を直近で追加した方式にリセットできるようにしました。24.8 のインスタンス群と 24.9 のインスタンス 1 つをしばらく併用する場合は、潜在的なエラーを避けるため、その期間は `max_authentication_methods_per_user = 1` を設定することをお勧めします。[#65277](https://github.com/ClickHouse/ClickHouse/pull/65277) ([Arthur Passos](https://github.com/arthurpassos)).
* Functions `upperUTF8` と `lowerUTF8` は、以前はキリル文字しか大文字化 / 小文字化できませんでした。この制限は解消され、任意の言語の文字を大文字化/小文字化できるようになりました。Example: `SELECT upperUTF8('Süden')` は `SÜDEN` を返すようになりました。[#65761](https://github.com/ClickHouse/ClickHouse/pull/65761) ([李扬](https://github.com/taiyang-li)).
* projection を持つテーブルで論理削除が行われる場合、これまでは例外をスローする (デフォルト) か、projection を削除して論理削除を実行するかのどちらかでしたが、新たに 3 つ目の選択肢として、論理削除を実行した後に projection を再構築できるようになりました。[#66169](https://github.com/ClickHouse/ClickHouse/pull/66169) ([Shichao](https://github.com/jsc0218)).
* IP ファミリーごとに接続をブロックできるようにする 2 つのオプション (`dns_allow_resolve_names_to_ipv4` と `dns_allow_resolve_names_to_ipv6`) が追加されました。[#66895](https://github.com/ClickHouse/ClickHouse/pull/66895) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* 新しい種類の (実験的な) 統計情報として `min_max` が追加されました。これは、数値カラムに対する範囲 predicate (例: `x < 100`) の推定をサポートします。[#67013](https://github.com/ClickHouse/ClickHouse/pull/67013) ([JackyWoo](https://github.com/JackyWoo)).
* clickhouse-client で C-z の無視を設定可能にしました (ignore&#95;shell&#95;suspend) 。[#67134](https://github.com/ClickHouse/ClickHouse/pull/67134) ([Azat Khuzhin](https://github.com/azat)).
* Variant/Dynamic カラムに対する castOrDefault を改善し、内部の型がまったく変換できない場合でも動作するようにしました。[#67150](https://github.com/ClickHouse/ClickHouse/pull/67150) ([Pavel Kruglov](https://github.com/Avogar)).
* JSON 出力フォーマットにおける Unicode エンコーディングを改善しました。これにより、結果データ内の特定のバイト列でも有効な JSON が生成されることが保証されます。[#67938](https://github.com/ClickHouse/ClickHouse/pull/67938) ([mwoenker](https://github.com/mwoenker)).
* マージとミューテーションの内部診断を強化するため、対応するプロファイルイベントを追加しました。[#68015](https://github.com/ClickHouse/ClickHouse/pull/68015) ([Anton Popov](https://github.com/CurtizJ)).
* Odbc: サーバー設定から http&#95;max&#95;tries を取得するようにしました。[#68128](https://github.com/ClickHouse/ClickHouse/pull/68128) ([Rodolphe Dugé de Bernonville](https://github.com/RodolpheDuge)).
* x509 SubjectAltName 拡張機能で、ユーザー識別にワイルドカードを指定できるようにしました。[#68236](https://github.com/ClickHouse/ClickHouse/pull/68236) ([Marco Vilas Boas](https://github.com/marco-vb)).
* date time のスキーマ推論を改善しました。これにより、DateTime64 は date time に小数部がある場合にのみ使用され、それ以外では通常の DateTime が使用されます。さらに、Date/DateTime の推論もより厳密になり、特に `date_time_input_format='best_effort'` の場合に、コーナーケースで文字列から date time を推論してしまうことを避けられるようになりました。[#68382](https://github.com/ClickHouse/ClickHouse/pull/68382) ([Pavel Kruglov](https://github.com/Avogar)).
* Dictionaries 内の named collections の古いコードを削除して新しい実装に置き換え、DDL で作成した named collections を Dictionaries で使用できるようにしました。[#60936](https://github.com/ClickHouse/ClickHouse/issues/60936) と [#36890](https://github.com/ClickHouse/ClickHouse/issues/36890) をクローズしました。[#68412](https://github.com/ClickHouse/ClickHouse/pull/68412) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 外部 HTTP authentication で、HTTP/1.0 (デフォルト設定) ではなく HTTP/1.1 を使用するようにしました。[#68456](https://github.com/ClickHouse/ClickHouse/pull/68456) ([Aleksei Filatov](https://github.com/aalexfvk)).
