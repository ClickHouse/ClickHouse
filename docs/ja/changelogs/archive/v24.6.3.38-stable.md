<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#66885](https://github.com/ClickHouse/ClickHouse/issues/66885) でバックポート: 関数呼び出しにおける低カーディナリティのカラムのサイズが想定外になる問題を修正しました。 [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* [#66303](https://github.com/ClickHouse/ClickHouse/issues/66303) でバックポート: `IS NULL` チェックを含む join 条件の処理を改善しました (たとえば `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` は `ON a <=> b` に書き換えられます) 。また、`IS NULL` 以外の condition がある場合に発生する不正な最適化を修正しました。 [#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* [#66330](https://github.com/ClickHouse/ClickHouse/issues/66330) でバックポート: `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` は結果のスキーマを変更しうるため、スキーマ推論 cache に不足していたこれらの settings を追加しました。これにより、これらの settings の変更時にスキーマ推論で不正な結果が生じるのを防ぎます。 [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).

* [#66210](https://github.com/ClickHouse/ClickHouse/issues/66210) でバックポート: [#64760](https://github.com/ClickHouse/ClickHouse/issues/64760) で導入された `merge-filters` 最適化を無効化しました。この最適化が 2 つのフィルタ式を merge し、short-circuit evaluation を適用しない場合、Exception が発生する可能性があります。 [#66126](https://github.com/ClickHouse/ClickHouse/pull/66126) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66456](https://github.com/ClickHouse/ClickHouse/issues/66456) でバックポート: ZooKeeper client の bug を修正しました。ZooKeeper からハードウェア error を受信したあと、session が使用不能な state のまま停止することがありました。たとえば、これは ClickHouse Keeper の &quot;ソフトメモリ制限&quot; が原因で発生する可能性があります。 [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
