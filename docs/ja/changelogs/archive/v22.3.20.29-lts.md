  # 2023 変更履歴
</div>

<div id="clickhouse-release-v2232029-lts-297b4dd5e55-fixme-as-compared-to-v223196-lts-467e0a7bd77">
  ### ClickHouse リリース v22.3.20.29-lts (297b4dd5e55) FIXME v22.3.19.6-lts (467e0a7bd77) と比較して
</div>

<div id="improvement">
  #### 改善
</div>

* [#46979](https://github.com/ClickHouse/ClickHouse/issues/46979)でバックポート: `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` をすべてのレプリカに対して適用するようにしました。これは、`ALTER TABLE t MOVE` がレプリケートされないためです。[#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* QueryNormalizer におけるエイリアス再帰の不正な処理を修正 [#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* 集約最適化における算術演算の問題を修正 [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* `maxIntersections` 関数における MSan レポートを修正 [#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* LIKE パターンに引用符で囲まれた引用不可文字が含まれる場合に、一部の LIKE 検索で誤った結果が返る問題を修正 [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
* QueryStatus で発生する可能性があるデッドロックを修正 [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微
</div>

* 新しい PyGithub バージョン向けに型定義を更新 [#47123](https://github.com/ClickHouse/ClickHouse/pull/47123) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* リリース workflow 用の手動トリガーを追加 [#47302](https://github.com/ClickHouse/ClickHouse/pull/47302) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* PR が作成されていない backport branch 向けの保護策を追加 [#47760](https://github.com/ClickHouse/ClickHouse/pull/47760) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 有効な Reviews.STATES のみ既存のレビューを上書きするようにした [#47789](https://github.com/ClickHouse/ClickHouse/pull/47789) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 大きなブロックの前に早期 return を配置し、ログを改善 [#47822](https://github.com/ClickHouse/ClickHouse/pull/47822) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* tsan の lock-order-inversion エラーを修正 [#47953](https://github.com/ClickHouse/ClickHouse/pull/47953) ([Kruglov Pavel](https://github.com/Avogar)).
