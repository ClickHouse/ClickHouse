<div id="improvement">
  #### 改善
</div>

* [#66770](https://github.com/ClickHouse/ClickHouse/issues/66770)でバックポート: 分散クエリでは `allow_experimental_analyzer` をイニシエーターが制御するようにしました。これにより、バージョンが混在するクラスターでの操作時の互換性と正確性が確保されます。[#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### 重大なバグ修正 (crash, LOGICAL_ERROR, データ損失, RBAC)
</div>

* [#66885](https://github.com/ClickHouse/ClickHouse/issues/66885) でバックポート: 関数呼び出し時に低カーディナリティのカラムのサイズが想定外になる問題を修正しました。 [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* [#66693](https://github.com/ClickHouse/ClickHouse/issues/66693) でバックポート: ユーザー定義の `VALID UNTIL` 句が再起動後にリセットされる問題を修正しました。[#66405](https://github.com/ClickHouse/ClickHouse/issues/66405) をクローズします。 [#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#67816](https://github.com/ClickHouse/ClickHouse/issues/67816) でバックポート: 実験的な Variant データ型にのみ該当します。Variant + AggregateFunction 型で発生する crash を修正しました。 [#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* [#67503](https://github.com/ClickHouse/ClickHouse/issues/67503) でバックポート: connection が空の場合に DistributedAsyncInsert で発生する crash を修正しました。 [#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)).
* [#67852](https://github.com/ClickHouse/ClickHouse/issues/67852) でバックポート: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026) を修正しました。`ReplaceTableNodeToDummyVisitor` で未解決の table function の引数を走査しないようにしました。 [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* [#67838](https://github.com/ClickHouse/ClickHouse/issues/67838) でバックポート: `JSONMergePatch` 関数で発生しうるスタックオーバーフローを修正しました。以前の名前が誤っていたため、この関数名を `jsonMergePatch` から `JSONMergePatch` に変更しました。互換性のため、以前の名前も引き続き利用できます。この関数のエラー診断も改善しました。これにより [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304) をクローズします。 [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#66303](https://github.com/ClickHouse/ClickHouse/issues/66303) でバックポート: `IS NULL` チェックを含む join 条件の処理を改善しました (たとえば `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` は `ON a <=> b` に書き換えられます) 。また、`IS NULL` 以外の条件が含まれる場合に誤った最適化が行われる問題を修正しました。[#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* [#66330](https://github.com/ClickHouse/ClickHouse/issues/66330) でバックポート: `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` は結果のスキーマを変えうるため、スキーマ推論 cache に不足していたこれらの設定を追加しました。これにより、これらの設定が変更された際にスキーマ推論で誤った結果になることを防ぎます。[#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* [#66157](https://github.com/ClickHouse/ClickHouse/issues/66157) でバックポート: `unbin`/`unhex` の実装における buffer overflow bug を修正しました。[#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* [#66210](https://github.com/ClickHouse/ClickHouse/issues/66210) でバックポート: [#64760](https://github.com/ClickHouse/ClickHouse/issues/64760) で導入された `merge-filters` 最適化を無効化しました。この最適化で 2 つのフィルタ式がマージされ、short-circuit evaluation が適用されないと、Exception が発生する可能性があります。[#66126](https://github.com/ClickHouse/ClickHouse/pull/66126) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66456](https://github.com/ClickHouse/ClickHouse/issues/66456) でバックポート: ZooKeeper クライアントの bug を修正しました。ZooKeeper からハードウェアエラーを受信した後、session が使用不能な state のままになることがありました。たとえば、これは ClickHouse Keeper の &quot;ソフトメモリ制限&quot; によって発生する可能性があります。[#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#66228](https://github.com/ClickHouse/ClickHouse/issues/66228) でバックポート: SumIfToCountIfVisitor と符号付き整数に関する issue を修正しました。[#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* [#66183](https://github.com/ClickHouse/ClickHouse/issues/66183) でバックポート: distributed query の結果でデータが欠落するまれな case を修正し、[#61432](https://github.com/ClickHouse/ClickHouse/issues/61432) を close しました。[#66174](https://github.com/ClickHouse/ClickHouse/pull/66174) ([vdimir](https://github.com/vdimir)).
* [#66271](https://github.com/ClickHouse/ClickHouse/issues/66271) でバックポート: `distributed_ddl_output_mode` の `none_only_active` mode で `TIMEOUT_EXCEEDED` を throw しないようにしました。[#66218](https://github.com/ClickHouse/ClickHouse/pull/66218) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#66682](https://github.com/ClickHouse/ClickHouse/issues/66682) でバックポート: 索引を使用できない場合の `system.numbers_mt` の limit 処理を修正しました。[#66231](https://github.com/ClickHouse/ClickHouse/pull/66231) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#66587](https://github.com/ClickHouse/ClickHouse/issues/66587) でバックポート: server が Docker などのコンテナー内で動作している場合に、cgroups v2 で指定された使用可能な最大 CPU コア数を ClickHouse server が検出する方法を修正しました。より詳しく言うと、コンテナーでは名前が空の root cgroup で process が実行されることがよくあります。その場合、ClickHouse は cgroups v2 で設定された CPU 制限を無視していました。[#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
* [#66362](https://github.com/ClickHouse/ClickHouse/issues/66362) でバックポート: 制約内で `IN` を含むサブクエリを使用した場合に発生する `Not-ready set` エラーを修正しました。[#66261](https://github.com/ClickHouse/ClickHouse/pull/66261) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66613](https://github.com/ClickHouse/ClickHouse/issues/66613) でバックポート: `group_by_use_nulls=true` かつ新しいアナライザ使用時に発生する `Column identifier is already registered` エラーを修正しました。[#66400](https://github.com/ClickHouse/ClickHouse/pull/66400) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
