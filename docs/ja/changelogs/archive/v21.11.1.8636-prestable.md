<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* ClickHouse Keeper の snapshots は、独自の ClickHouse LZ4 block 圧縮ではなく、デフォルトで `ZSTD` codec で圧縮されるようになりました。この動作は、`compress_snapshots_with_zstd_format` 協調 setting で無効にできます (すべてのクォーラム レプリカで同じ値である必要があります) 。後方互換性が失われるケースは非常にまれで、発生するのは新しい node が古い node に snapshot を送信する場合のみです (復旧時に発生します) 。この場合、古い node は ZSTD フォーマットの snapshots を読み取れません。 [#29417](https://github.com/ClickHouse/ClickHouse/pull/29417) ([alesapin](https://github.com/alesapin)).
* Function `bayesAB` を削除しました。これにより [#26233](https://github.com/ClickHouse/ClickHouse/issues/26233) はクローズされます。 [#29934](https://github.com/ClickHouse/ClickHouse/pull/29934) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree table setting `write_final_mark` を削除しました。今後は常に `true` になります。 [#30455](https://github.com/ClickHouse/ClickHouse/pull/30455) ([Kseniia Sumarokova](https://github.com/kssenii)).
* sql json function における json&#95;path と json の順序を変更しました (正しい順序にするため) 。これにより [#30449](https://github.com/ClickHouse/ClickHouse/issues/30449) をクローズします。 [#30474](https://github.com/ClickHouse/ClickHouse/pull/30474) ([Kseniia Sumarokova](https://github.com/kssenii)).
* setting `odbc_max_field_size` は、すでに使用されていないため削除しました。これにより [#30413](https://github.com/ClickHouse/ClickHouse/issues/30413) をクローズします。 [#30778](https://github.com/ClickHouse/ClickHouse/pull/30778) ([Kseniia Sumarokova](https://github.com/kssenii)).
