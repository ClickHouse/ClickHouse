<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに見える不具合)
</div>

* [#46228](https://github.com/ClickHouse/ClickHouse/issues/46228)でバックポート: `c-ares` 周辺でいくつかのセグメンテーション違反が報告されていました。最近観測された stack trace は、いずれも `std::unodered_set<>` への挿入時に失敗しています。この問題の根本原因を特定できたと考えており、未処理のクエリが原因のようです。この PR より前は、CH は `c-ares` チャネル内のファイルディスクリプタを待機するために `poll` を呼び出していました。[poll docs](https://man7.org/linux/man-pages/man2/poll.2.html) によると、戻り値が負の場合はエラーが発生したことを意味します。そのため、実行を中断して失敗を返していました。問題は、システム割り込みが発生した場合にも `poll` が負の値を返すことです。システム割り込みは処理の失敗や終了を意味するわけではありませんが、負の値をチェックしていたため、それでも中断していました。実行が中断されるとスタック全体が破棄され、その中には c-ares のコールバックの `void *` parameter に渡された `std::unordered_set<std::string>` も含まれます。c-ares がリクエストを完了するとコールバックが呼び出され、無効なメモリアドレスにアクセスして segfault が発生していました。[#45629](https://github.com/ClickHouse/ClickHouse/pull/45629) ([Arthur Passos](https://github.com/arthurpassos)).
* [#46967](https://github.com/ClickHouse/ClickHouse/issues/46967)でバックポート: 後方互換性のため、UInt64 から IPv4 への暗黙的な縮小変換を許可しました。これは `"INSERT ... VALUES ..."` expression に必要です。[#45865](https://github.com/ClickHouse/ClickHouse/pull/45865) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#46220](https://github.com/ClickHouse/ClickHouse/issues/46220)でバックポート: compact パーツで、複数レベルの存在しない Nested カラムの読み取りを修正しました。[#46045](https://github.com/ClickHouse/ClickHouse/pull/46045) ([Azat Khuzhin](https://github.com/azat)).
* [#46751](https://github.com/ClickHouse/ClickHouse/issues/46751)でバックポート: ドメイン IP 型 (IPv4、IPv6) を native に置き換える変更 [https://github.com/ClickHouse/ClickHouse/pull/43221](https://github.com/ClickHouse/ClickHouse/pull/43221) に対する追加修正。[#46087](https://github.com/ClickHouse/ClickHouse/pull/46087) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#46448](https://github.com/ClickHouse/ClickHouse/issues/46448)でバックポート: フォーマット `VALUES` で送信された無効なデータにより、非同期挿入で発生しうる `LOGICAL_ERROR` を修正しました。[#46350](https://github.com/ClickHouse/ClickHouse/pull/46350) ([Anton Popov](https://github.com/CurtizJ)).
* [#46680](https://github.com/ClickHouse/ClickHouse/issues/46680)でバックポート: function `arrayMap` における定数 `LowCardinality` argument の不正な処理を修正しました。この bug は、release では segfault、debug build では 論理エラー `Bad cast` を引き起こす可能性がありました。[#46569](https://github.com/ClickHouse/ClickHouse/pull/46569) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46873](https://github.com/ClickHouse/ClickHouse/issues/46873)でバックポート: `Map` データ型の bug を修正しました。これにより [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855) をクローズします。[#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#46956](https://github.com/ClickHouse/ClickHouse/issues/46956)でバックポート: 部分文字列検索に変換され、引用された非 LIKE メタ文字を含む LIKE predicates の結果を修正しました。[#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
