  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v214655-stable-fixme-as-compared-to-v214546-stable">
  ### ClickHouse リリース v21.4.6.55-stable FIXME (v21.4.5.46-stable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#23679](https://github.com/ClickHouse/ClickHouse/issues/23679) でバックポート: `quantile(s)TDigest` を修正しました。tdunning/t-digest 3.2+ に従い、シングルトンのセントロイドに対する特別な処理を追加しました。また、旧バージョンのアルゴリズム実装において、セントロイドが過度に圧縮される不具合も修正しました。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#23580](https://github.com/ClickHouse/ClickHouse/issues/23580)でバックポート: 古いブロックのバックグラウンドクリーンアップにおける、ごくまれな race condition を修正しました。deduplication window の終端に近すぎる場合、ブロックが deduplicated されない可能性がありました。 [#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23676](https://github.com/ClickHouse/ClickHouse/issues/23676)でバックポート: パーティション pruning 中に NOT 条件を緩和しないようにしました。これにより [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) と [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539) を修正します。 [#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird)).
* [#23583](https://github.com/ClickHouse/ClickHouse/issues/23583)でバックポート: * join&#95;algorithm = &#39;auto&#39; の dict join における bug を修正しました。 [#23002](https://github.com/ClickHouse/ClickHouse/issues/23002) を close します。 [#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir)).
* [#23641](https://github.com/ClickHouse/ClickHouse/issues/23641)でバックポート: 仮想カラムに基づく partition pruning 中の、互換性のない定数 expression の生成を修正しました。これにより [https://github.com/ClickHouse/ClickHouse/pull/21401#discussion&#95;r611888913](https://github.com/ClickHouse/ClickHouse/pull/21401#discussion_r611888913) を修正します。 [#23366](https://github.com/ClickHouse/ClickHouse/pull/23366) ([Amos Bird](https://github.com/amosbird)).
* [#23586](https://github.com/ClickHouse/ClickHouse/issues/23586)でバックポート: バージョン 21.1 より前と同様に、より多くの条件を `PREWHERE` に移動できるようにしました。移動される条件の数が不十分だと、パフォーマンス低下につながる可能性がありました。 [#23397](https://github.com/ClickHouse/ClickHouse/pull/23397) ([Anton Popov](https://github.com/CurtizJ)).
* [#23588](https://github.com/ClickHouse/ClickHouse/issues/23588)でバックポート: マルチディスクのディスク設定で ReplicatedMergeTree table の作成に失敗した際に発生する `Cannot unlink file` error を修正しました。これにより [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755) を close します。 [#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23591](https://github.com/ClickHouse/ClickHouse/issues/23591)でバックポート: `ReplacingMergeTree` における vertical merges のコーナーケースを修正しました。まれに、`Incomplete granules are not allowed while blocks are granules size` のような exception により merges が失敗することがありました。 [#23459](https://github.com/ClickHouse/ClickHouse/pull/23459) ([Anton Popov](https://github.com/CurtizJ)).
* [#23611](https://github.com/ClickHouse/ClickHouse/issues/23611)でバックポート: restart / stop コマンドがハングする問題を修正しました。 [#20214](https://github.com/ClickHouse/ClickHouse/issues/20214) を close します。 [#23552](https://github.com/ClickHouse/ClickHouse/pull/23552) ([filimonov](https://github.com/filimonov)).
* [#23693](https://github.com/ClickHouse/ClickHouse/issues/23693)でバックポート: HTTP 経由でデータを挿入した際、exception が原因で発生する server fault を修正しました。これにより [#23512](https://github.com/ClickHouse/ClickHouse/issues/23512) を修正します。 [#23643](https://github.com/ClickHouse/ClickHouse/pull/23643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#23695](https://github.com/ClickHouse/ClickHouse/issues/23695)でバックポート: aggregate function `mannWhitneyUTest` で、両方の samples の値が完全に同一である場合に exception を追加しました。これにより [#23646](https://github.com/ClickHouse/ClickHouse/issues/23646) を修正します。 [#23654](https://github.com/ClickHouse/ClickHouse/pull/23654) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#23774](https://github.com/ClickHouse/ClickHouse/issues/23774)でバックポート: Distributed への INSERT 時に、 (何らかの例外が発生していた場合に) &quot;Cannot schedule a task&quot; エラーが発生し得る問題を回避しました。[#23744](https://github.com/ClickHouse/ClickHouse/pull/23744) ([Azat Khuzhin](https://github.com/azat)).
