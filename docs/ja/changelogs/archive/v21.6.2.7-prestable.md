  # 2022年の変更履歴

<div id="clickhouse-release-v21627-prestable-fixme-as-compared-to-v21616891-prestable">
  ### ClickHouse リリース v21.6.2.7-prestable FIXME (v21.6.1.6891-prestable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#24567](https://github.com/ClickHouse/ClickHouse/issues/24567) にバックポート: パーティションキーで使用される場合は、古い modulo 関数のバージョンを使うようにしました。[#23508](https://github.com/ClickHouse/ClickHouse/issues/23508) をクローズしました。[#24157](https://github.com/ClickHouse/ClickHouse/pull/24157) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#24367](https://github.com/ClickHouse/ClickHouse/issues/24367) にバックポート: StorageMemory の mutation 失敗を修正するため、`max_threads = 1` を設定しました。[#24274](https://github.com/ClickHouse/ClickHouse/issues/24274) をクローズしました。[#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl))。
* [#24383](https://github.com/ClickHouse/ClickHouse/issues/24383) にバックポート: 空の HTTPヘッダーを許可しました。[#23901](https://github.com/ClickHouse/ClickHouse/issues/23901) を修正しました。[#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7))。
* [#24365](https://github.com/ClickHouse/ClickHouse/issues/24365) にバックポート: Materialized View を Ordinary から Atomic データベースへ移動する際のバグを修正しました (`RENAME TABLE` クエリ) 。これにより、内部テーブルも Materialized View とともに新しいデータベースへ移動されるようになりました。[#23926](https://github.com/ClickHouse/ClickHouse/issues/23926) を修正しました。[#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#24510](https://github.com/ClickHouse/ClickHouse/issues/24510) にバックポート: intersect の偽パーツがある場合のパーティション削除を修正しました。まれに、現在のブロック番号より大きい mutation version を持つパーツが存在することがあります。[#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird))。
* [#24542](https://github.com/ClickHouse/ClickHouse/issues/24542) にバックポート: toWeek 関数の単調性が正しくない問題を修正しました。これにより [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422) も修正されます。このバグは [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212) で導入され、その後、より高度なパーティションプルーナーによって顕在化しました。[#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird))。
* [#24556](https://github.com/ClickHouse/ClickHouse/issues/24556) にバックポート: クエリ `SYSTEM RESTART REPLICA` または `SYSTEM SYNC REPLICA` の処理が終わらなくなる問題を修正しました。これは RAM が極端に少ないサーバーで検出されました。[#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
* [#24597](https://github.com/ClickHouse/ClickHouse/issues/24597) にバックポート: `CREATE .. AS SELECT` クエリでのタプルの使用を修正しました。[#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ))。
* [#24600](https://github.com/ClickHouse/ClickHouse/issues/24600) にバックポート: 分散テーブルでサブカラムを読み取れるようにしました。[#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ))。

<div id="not-for-changelog-insignificant">
  #### CHANGELOGには記載しない / 軽微

* メモリの重複がある場合に対応するため、PODArray::insert で memmove を使うようにしました。 [#24271](https://github.com/ClickHouse/ClickHouse/pull/24271) ([Fu Zhe](https://github.com/fuzhe1989)).
* clickhouse-server.init の CLI 引数を修正しました。 [#24449](https://github.com/ClickHouse/ClickHouse/pull/24449) ([Vladimir C](https://github.com/vdimir)).
* CAST 演算子に関するいくつかのケースを修正しました。 [#24471](https://github.com/ClickHouse/ClickHouse/pull/24471) ([Anton Popov](https://github.com/CurtizJ)).
