<div id="clickhouse-release-v20814513-prestable-fixme-as-compared-to-v20714310-prestable">
  ### ClickHouse リリース v20.8.1.4513-prestable FIXME (v20.7.1.4310-prestable との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* `ODBCDriver` 入出力フォーマットのサポートを削除しました。これは以前 ClickHouse ODBC driver との通信用に使われていた非推奨のフォーマットですが、現在は давно `ODBCDriver2` フォーマットに置き換えられています。[#13629](https://github.com/ClickHouse/ClickHouse/issues/13629) を修正しました。[#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting))。
* `parallel_distributed_insert_select` setting を拡張し、ローカル table への `INSERT` を実行するオプションを追加しました。setting の型は `Bool` から `UInt64` に変更されたため、`false` と `true` はサポートされなくなりました。server configuration にこれらの値が含まれている場合、server は起動しません。代わりに、それぞれ `0` と `1` に置き換えてください。[#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat))。
* `OPTIMIZE FINAL` クエリでは、現在、TTL が作成される前に追加されたパーツの有効期限 (TTL) は再計算されません。これらを計算するには、一度 `ALTER TABLE ... MATERIALIZE TTL` を使用してください。その後は `OPTIMIZE FINAL` で有効期限 (TTL) が正しく評価されます。この動作は、レプリケートテーブルではこれまで一度も機能していませんでした。[#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin))。



<div id="new-feature">
  #### 新機能
</div>

* `MaterializeMySQL` データベースエンジンをサポート。[#4006](https://github.com/ClickHouse/ClickHouse/issues/4006) を実装。[#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014))。
* `krb5` および `cyrus-sasl` ライブラリを使用した Kafka での Kerberos 認証をサポート。[#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn))。
* 型 `Int128`、`Int256`、`UInt256` およびそれらに関連する関数を追加。Decimal256（精度最大76桁）で Decimals を拡張。新しい型は設定 `allow_experimental_bigint_types` で利用可能。[#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2))。
* 関数 `position` がオプションの `start_pos` 引数をサポートするようになった。[#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir))。
* テーブルのサンプル句を変更できる `ALTER SAMPLE BY` ステートメントを追加。[#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird))。
* メイン設定ファイルに新しいオプションセクション <user_directories> を追加。[#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar))。
* リテラル、リテラルの列、および複雑な別名をプレースホルダーに置換する関数 `normalizeQuery` を追加。類似クエリに対して同一の64ビットハッシュ値を返す関数 `normalizedQueryHash` を追加。クエリログの分析に役立つ。[#11271](https://github.com/ClickHouse/ClickHouse/issues/11271) をクローズ。[#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* `medianExactLow` および `medianExactHigh` の別名をそれぞれ持つ `quantileExactLow` と `quantileExactHigh` の実装を追加。[#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc))。
* 指定した型のデフォルト値を返す関数 `defaultValueOfTypeName` を追加。[#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz))。
* 日付/時刻の値を指定した日付/時刻の単位に切り捨てる関数 `date_trunc` を追加。[#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko))。
* `config.xml` で指定された設定に対応するカラムに `Default` 圧縮コーデックを指定できる機能を追加。[#9074](https://github.com/ClickHouse/ClickHouse/issues/9074) を実装。[#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin))。
* 非常に低い `index_granularity_bytes` 設定でテーブルを誤って作成することを防ぐ設定 `min_index_granularity_bytes` を追加。[#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc))。
* 整数または Decimal カラムの10進数桁数を数える関数 `countDigits(x)` を追加。Decimal カラムの値がその（または指定した）精度を超えているかどうかを確認する関数 `isDecimalOverflow(d, [p])` を追加。[#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2))。

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 軽量な `INSERT SELECT` クエリの実行時に、`max_threads` を 1 または `max_insert_threads` に自動設定し、`max_block_size` を `min_insert_block_size_rows` に設定するようにしました。[#5907](https://github.com/ClickHouse/ClickHouse/issues/5907) に関連します。[#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* `Array(LowCardinality(T))` および右辺が定数の引数に対して、`has()`、`indexOf()`、`countEqual()` 関数を最適化しました。[#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* UInt8/UInt16 キーによる aggregation のパフォーマンスをわずかに改善しました。[#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* パーツのスキャン中に `max_rows_to_read` の制限を超えた場合、即座に失敗するようにしました。この変更の目的は、`max_rows_to_read` がすでに超過していることが明らかな場合に、選択されたすべてのパーツに対する範囲スキャンを省略することです。この変更は、多数のパーツに対するクエリで特に効果が目立ちます。[#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* テーブルエンジン `Null`、`Memory`、`Distributed`、`Buffer` で並列 INSERT を有効化しました。[#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* LowCardinality を使用する非常に短いクエリをわずかに最適化しました。[#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).

* 以前のバージョンでは、`lcm` 関数を細工された引数で呼び出すと、debug ビルドで assertion violation が発生することがありました。これにより [#13368](https://github.com/ClickHouse/ClickHouse/issues/13368) を修正します。 [#13510](https://github.com/ClickHouse/ClickHouse/pull/13510) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree Write-Ahead-Log (WAL) ダンプツールを追加。 [#13640](https://github.com/ClickHouse/ClickHouse/pull/13640) ([BohuTANG](https://github.com/BohuTANG)).
* Array がフィールドとして操作される場合に、クエリが極端に遅くなるのを回避。代わりに例外を throw します。 [#13753](https://github.com/ClickHouse/ClickHouse/pull/13753) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 1. [GTID ベースのレプリケーション](https://dev.mysql.com/doc/refman/5.7/en/replication-gtids-concepts.html)を追加。レプリケーションのトポロジーが変更されても動作し、MySQL 5.6/5.7/8.0 でサポートされており、推奨されています 2. BIT/SET フィールド型のサポートを追加 3. varchar 型のメタ長に関するバグを修正。[#13820](https://github.com/ClickHouse/ClickHouse/pull/13820) ([BohuTANG](https://github.com/BohuTANG)).
* `lgamma` 関数のデータ競合を修正しました。この競合は `tsan` でのみ検出され、実際の副作用は発生していません。 [#13842](https://github.com/ClickHouse/ClickHouse/pull/13842) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

* TabSeparatedRow フォーマットにおける NULL 値のエラーメッセージを改善しました。 [#13906](https://github.com/ClickHouse/ClickHouse/pull/13906) ([jiang tao](https://github.com/tomjiang1987)).
* 長いクエリに対して誤ったエラーが返される問題を修正しました。正しいクエリであっても、`Max query size exceeded` ではなく構文エラーになることがありました。 [#13928](https://github.com/ClickHouse/ClickHouse/pull/13928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

* -Resample コンビネータの上限を 1M に引き上げました。 [#13947](https://github.com/ClickHouse/ClickHouse/pull/13947) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 条件付き集約関数 (たとえば `avgIf`、`sumIf`、`maxIf`) は、行が存在せず、Nullable 型の引数を使用する場合に `NULL` を返すようになりました。 [#13964](https://github.com/ClickHouse/ClickHouse/pull/13964) ([Winter Zhang](https://github.com/zhang2014)).
* 非常に小さなブロックが大量にある状態で構築された場合の Memory テーブルの性能をわずかに改善しました (そのようなケースはまれです) 。このアイデアの著者: [Mark Papadakis](https://github.com/markpapadakis)。 [#14043](https://github.com/ClickHouse/ClickHouse/issues/14043) をクローズしました。 [#14056](https://github.com/ClickHouse/ClickHouse/pull/14056) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* `ALTER TABLE table_name FETCH PARTITION partition_expr FROM 'zk://<host>:<port>/path-in-zookeeper'` が使用できるようになりました。新しいクラスターへデータを移送する際に便利です。 [#14155](https://github.com/ClickHouse/ClickHouse/pull/14155) ([Amos Bird](https://github.com/amosbird)).
