  ### ClickHouse リリース v21.12.1.9017-prestable FIXME (v21.11.1.8636-prestable と比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* TSV/CSV の input format で、カスタム NULL 表現をサポートしました。TSV/CSV/JSONCompactStringsEachRow/JSONStringsEachRow の input format における Nullable(String) のデシリアライズも修正しました。これに伴い、`output_format_csv_null_representation` と `output_format_tsv_null_representation` を、それぞれ `format_csv_null_representation` と `format_tsv_null_representation` にリネームしました。[#30497](https://github.com/ClickHouse/ClickHouse/pull/30497) ([Kruglov Pavel](https://github.com/Avogar)).
* JSON&#95;VALUE が引用符なしの文字列を返すようにしました。[#27965](https://github.com/ClickHouse/ClickHouse/issues/27965) をクローズします。[#31008](https://github.com/ClickHouse/ClickHouse/pull/31008) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Kafka/RabbitMQ/FileLog に対する direct select を許可しないようにしました。これは設定 `stream_like_engine_allow_direct_select` で有効にできます。attached materialized view がある場合は、この設定を有効にしていても direct select は許可されません。Kafka および RabbitMQ では、direct select を許可していても、デフォルトではメッセージは commit されません。direct select で commit を有効にするには、ストレージレベル設定 `kafka{rabbitmq}_commit_on_select=1` (デフォルトは `0`) を使用する必要があります。cc @filimonov。[#31053](https://github.com/ClickHouse/ClickHouse/pull/31053) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `ReplicatedMergeTree` から「リーダー選出」の仕組みを削除しました。20.6 以降では複数のリーダーがサポートされているためです。古いバージョンからアップグレードする場合、古いバージョンのレプリカがリーダーになっていると、アップグレード後に server は起動に失敗します。新しいバージョンを起動するには、古いバージョンのレプリカを停止してください。その後は、20.6 より古いバージョンに downgrade できなくなります。[#32140](https://github.com/ClickHouse/ClickHouse/pull/32140) ([Alexander Tokmakov](https://github.com/tavplubix)).

* Bool データ型のサポート。[#31072](https://github.com/ClickHouse/ClickHouse/pull/31072) ([kevin wan](https://github.com/MaxWk)).
* GlobalThreadPool のすべての設定を設定ファイルから参照可能に。[#31285](https://github.com/ClickHouse/ClickHouse/pull/31285) ([Tomáš Hromada](https://github.com/gyfis)).

* - http/url 関数の Basic 認証サポート。[#31648](https://github.com/ClickHouse/ClickHouse/pull/31648) ([Peng Liu](https://github.com/michael1589)).
