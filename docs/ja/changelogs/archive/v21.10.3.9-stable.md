* [#30751](https://github.com/ClickHouse/ClickHouse/issues/30751) でバックポート: `positionCaseInsensitiveUTF8` や `countSubstringsCaseInsensitiveUTF8` など、UTF-8 文字列に対する大文字・小文字を区別しない検索用関数が、実際には一致しない部分文字列を見つけてしまうことがある問題を修正しました。[#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).

* [#30859](https://github.com/ClickHouse/ClickHouse/issues/30859) でバックポート: `ReplicatedMergeTree` で ZooKeeper パスから補助的な ZooKeeper 名を抽出する際の曖昧さを修正しました。従来は、ZooKeeper パスにコロンが含まれていると、server が `Unknown auxiliary ZooKeeper name` により起動に失敗することがありました。[#29052](https://github.com/ClickHouse/ClickHouse/issues/29052) を修正しました。また、先頭がスラッシュでない ZooKeeper パスもこれまでは指定できましたが、現在では非推奨となっており、そのようなパスを持つ新しい table は作成できません。補助的な ZooKeeper 名にスラッシュやコロンを含めることもできません。[#30822](https://github.com/ClickHouse/ClickHouse/pull/30822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30926](https://github.com/ClickHouse/ClickHouse/issues/30926) でバックポート: オペランドが 3 つ以上ある場合に、AND/OR 式で Set 索引が使われない問題を修正しました。これにより [#30416](https://github.com/ClickHouse/ClickHouse/issues/30416) も修正されます。[#30887](https://github.com/ClickHouse/ClickHouse/pull/30887) ([Amos Bird](https://github.com/amosbird)).
* [#31289](https://github.com/ClickHouse/ClickHouse/issues/31289) でバックポート: intersect/except に関するいくつかのコーナーケースを修正しました。[#30803](https://github.com/ClickHouse/ClickHouse/issues/30803) をクローズしました。[#30965](https://github.com/ClickHouse/ClickHouse/pull/30965) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#31152](https://github.com/ClickHouse/ClickHouse/issues/31152) でバックポート: ATTACH PARTITION ... FROM および MOVE PARTITION ... の場合は、max&#95;partition&#95;size&#95;to&#95;drop チェックをスキップします。[#30995](https://github.com/ClickHouse/ClickHouse/pull/30995) ([Amr Alaa](https://github.com/amralaa-MSFT)).
* [#31041](https://github.com/ClickHouse/ClickHouse/issues/31041) でバックポート: `formatRow` 関数を行フォーマット以外のフォーマットで使用すると segfault が発生していました。そのため、このようなフォーマットではこの関数を使用できないようにしました (意味がないためです) 。[#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31203](https://github.com/ClickHouse/ClickHouse/issues/31203) にバックポート: hdfs URL の構造に対する追加チェックを加えることで、不正な hdfs URL の場合に `debug server` で abort が発生し、`release server` で `DB::Exception: std::out_of_range: basic_string` エラーが発生する問題を修正しました。[#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31373](https://github.com/ClickHouse/ClickHouse/issues/31373) にバックポート: alias および where を使用する StorageMerge の不具合を修正しました (これまではまったく動作していませんでした) 。[#28802](https://github.com/ClickHouse/ClickHouse/issues/28802) をクローズしました。[#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#31255](https://github.com/ClickHouse/ClickHouse/issues/31255) にバックポート: 一部の協調ログが失われ、最新のログより新しいスナップショットが存在する場合に起動できなくなる可能性がある Keeper の不具合を修正しました。[#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)).
