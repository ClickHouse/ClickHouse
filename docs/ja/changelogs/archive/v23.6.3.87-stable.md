  ### ClickHouse リリース v23.6.3.87-stable (36911c17d0f) FIXME、v23.6.2.18-stable (89f39a7ccfe) との比較

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#52751](https://github.com/ClickHouse/ClickHouse/issues/52751) でバックポート: 主キーを無効にしてしまう誤ったプロジェクション解析を修正しました。この問題は、`query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1` の場合にのみ発生します。これにより [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823) を修正しました。これにより [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173) を修正しました。 [#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#52911](https://github.com/ClickHouse/ClickHouse/issues/52911)でバックポート: `clickhouse-server` パッケージに `clickhouse-keeper-client` の symlink を追加しました。 [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53023](https://github.com/ClickHouse/ClickHouse/issues/53023)でバックポート: inline cache を Dockerイメージに組み込むと、ときどき奇妙な不具合が発生します。まったく使っていないため、削除しても問題ありません。 [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#53290](https://github.com/ClickHouse/ClickHouse/issues/53290)でバックポート: コンパイラのプロファイルデータ (`-ftime-trace`) を ClickHouse Cloud にアップロードします。[#53100](https://github.com/ClickHouse/ClickHouse/issues/53100) に続く 2 回目の試みです。 [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#53465](https://github.com/ClickHouse/ClickHouse/issues/53465)でバックポート: `clickhouse start` コマンドで環境パラメータを保持します。 [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962) を修正します。 [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
