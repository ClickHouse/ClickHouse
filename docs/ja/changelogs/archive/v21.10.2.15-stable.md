* [#29776](https://github.com/ClickHouse/ClickHouse/issues/29776) でバックポート: `insert_allow_materialized_columns=0` であっても、materialized カラム を分散テーブルのシャーディングキーとして使用できるようにしました。 [#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#28792](https://github.com/ClickHouse/ClickHouse/issues/28792) でバックポート: settings `legacy_column_name_of_tuple_literal = 0` を指定した分散クエリにおいて、論理和のチェーンを `IN` に変換する処理 (settings `optimize_min_equality_disjunction_chain_length` で制御) の不具合を修正しました。 [#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).
* [#29127](https://github.com/ClickHouse/ClickHouse/issues/29127) でバックポート: `clickhouse-keeper-converter` の不具合を修正しました。この不具合により、ZooKeeper のログのデシリアライゼーションが不正になる可能性がありました。 [#29071](https://github.com/ClickHouse/ClickHouse/pull/29071) ([小路](https://github.com/nicelulu)).
* [#29970](https://github.com/ClickHouse/ClickHouse/issues/29970) でバックポート: `AccessControlManager` のシャットダウン処理を修正しました。これにより、AccessControlManager の破棄後に設定が再読み込みされることはなくなります。この PR により、不安定だったテスト [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html) が修正されます。 [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#30051](https://github.com/ClickHouse/ClickHouse/issues/30051) でバックポート: gRPC 呼び出しの処理中に、クエリ処理の終了時点で query ID と session ID が解放される不具合を修正しました。この PR により、不安定だったテスト [test&#95;grpc&#95;protocol/test.py::test&#95;session](https://clickhouse-test-reports.s3.yandex.net/0/1ac03811a2df9717fa7c633d1af03def821d24b6/integration_tests_\(memory\).html) が修正されます。 [#29954](https://github.com/ClickHouse/ClickHouse/pull/29954) ([Vitaly Baranov](https://github.com/vitlibar)).
