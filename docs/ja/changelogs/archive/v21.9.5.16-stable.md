<div id="bug-fix">
  #### バグ修正
</div>

* [#29775](https://github.com/ClickHouse/ClickHouse/issues/29775) でバックポート: `insert_allow_materialized_columns=0` の場合でも、マテリアライズドカラムを分散テーブルの分片キーとして使用できるようにしました。 [#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#29126](https://github.com/ClickHouse/ClickHouse/issues/29126) でバックポート: `clickhouse-keeper-converter` のバグを修正しました。このバグにより、ZooKeeper のログのデシリアライゼーションが誤って行われる可能性がありました。 [#29071](https://github.com/ClickHouse/ClickHouse/pull/29071) ([小路](https://github.com/nicelulu)).
* [#29972](https://github.com/ClickHouse/ClickHouse/issues/29972) でバックポート: `AccessControlManager` のシャットダウン処理を修正しました。これにより、AccessControlManager の破棄後に設定が再読み込みされることはなくなりました。この PR では、フレーキーテスト [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html) も修正されています。 [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#30052](https://github.com/ClickHouse/ClickHouse/issues/30052) でバックポート: gRPC 呼び出しの処理中に、クエリ処理の終了時点でクエリ ID とセッション ID が解放される不具合を修正しました。この PR では、フレーキーテスト [test&#95;grpc&#95;protocol/test.py::test&#95;session](https://clickhouse-test-reports.s3.yandex.net/0/1ac03811a2df9717fa7c633d1af03def821d24b6/integration_tests_\(memory\).html) も修正されています。 [#29954](https://github.com/ClickHouse/ClickHouse/pull/29954) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#29055](https://github.com/ClickHouse/ClickHouse/issues/29055)でバックポート: Nullable または LowCardinality の主キーが使用されている場合に、無効な定数型変換が発生する問題を修正しました。[#28636](https://github.com/ClickHouse/ClickHouse/pull/28636) ([Amos Bird](https://github.com/amosbird))。
* [#29107](https://github.com/ClickHouse/ClickHouse/issues/29107)でバックポート: `mutations_sync=2` で mutation の完了待機に関する問題を修正しました。[#28889](https://github.com/ClickHouse/ClickHouse/pull/28889) ([Azat Khuzhin](https://github.com/azat))。
* [#29815](https://github.com/ClickHouse/ClickHouse/issues/29815)でバックポート: inter-server secret の使用時に、以前の認証情報を再利用できないようにしました (そのクラスターで interserver secret が設定されている場合、Buffer/Kafka 経由で分散テーブルに INSERT する前に、その connection で以前に設定された user が再利用される可能性がありました) 。[#29060](https://github.com/ClickHouse/ClickHouse/pull/29060) ([Azat Khuzhin](https://github.com/azat))。
* [#29399](https://github.com/ClickHouse/ClickHouse/issues/29399)でバックポート: `Attempt to read after eof` (`ATTEMPT_TO_READ_AFTER_EOF`) ではなく、通常の `Database doesn't exist error` (`UNKNOWN_DATABASE`) を client に (TCP 経由で) 送信するよう修正しました。[#29229](https://github.com/ClickHouse/ClickHouse/pull/29229) ([Azat Khuzhin](https://github.com/azat))。
* [#29356](https://github.com/ClickHouse/ClickHouse/issues/29356)でバックポート: テーブルのカラムの 1 つに case-insensitive な Functions を含むデフォルト expressions がある場合に、`ReplicatedMergeTree` のレプリカを再作成または新規作成すると `Table columns structure in ZooKeeper is different from local table structure` 例外が発生する可能性がある問題を修正しました。[#29266](https://github.com/ClickHouse/ClickHouse/pull/29266) ([Anton Popov](https://github.com/CurtizJ))。
* [#29451](https://github.com/ClickHouse/ClickHouse/issues/29451)でバックポート: ReadBufferFromHDFS での assertion failure を修正しました。debug でテストを実行できるように libhdfs3 ライブラリを更新しました。[#29251](https://github.com/ClickHouse/ClickHouse/issues/29251) をクローズ。[#27814](https://github.com/ClickHouse/ClickHouse/issues/27814) をクローズ。[#29276](https://github.com/ClickHouse/ClickHouse/pull/29276) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#29301](https://github.com/ClickHouse/ClickHouse/issues/29301)でバックポート: 接続タイムアウト (`send_timeout`/`receive_timeout`) を修正しました。[#29282](https://github.com/ClickHouse/ClickHouse/pull/29282) ([Azat Khuzhin](https://github.com/azat))。
* [#29383](https://github.com/ClickHouse/ClickHouse/issues/29383)でバックポート: メモリ安全ではないため、window function `nth_value` を削除しました。これにより [#29347](https://github.com/ClickHouse/ClickHouse/issues/29347) をクローズします。[#29348](https://github.com/ClickHouse/ClickHouse/pull/29348) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#29438](https://github.com/ClickHouse/ClickHouse/issues/29438)でバックポート: misconfigured の場合に replicated access storage が正常にシャットダウンしない問題を修正しました。[#29388](https://github.com/ClickHouse/ClickHouse/pull/29388) ([Kevin Michel](https://github.com/kmichel-aiven))。
* [#29489](https://github.com/ClickHouse/ClickHouse/issues/29489)でバックポート: functions greatest/least における論理エラー `Cannot capture columns` を修正しました。[#29334](https://github.com/ClickHouse/ClickHouse/issues/29334) をクローズ。[#29454](https://github.com/ClickHouse/ClickHouse/pull/29454) ([Kruglov Pavel](https://github.com/Avogar))。
* [#29536](https://github.com/ClickHouse/ClickHouse/issues/29536)でバックポート: push-down された `HAVING` predicate を持つ subqueries で発生する可能性がある `Block structure mismatch` を修正しました。[#29010](https://github.com/ClickHouse/ClickHouse/issues/29010) を修正します。[#29475](https://github.com/ClickHouse/ClickHouse/pull/29475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29592](https://github.com/ClickHouse/ClickHouse/issues/29592)でバックポート: ODBC bridge で Invalid cursor state エラーに対する再試行を追加しました。これは再試行可能なエラーです。[#29473](https://github.com/ClickHouse/ClickHouse/issues/29473) をクローズします。[#29518](https://github.com/ClickHouse/ClickHouse/pull/29518) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29572](https://github.com/ClickHouse/ClickHouse/issues/29572)でバックポート: `std::mismatch` の使用に不具合があったため、check `pathStartsWith` の bug を修正しました: ` The behavior is undefined if the second range is shorter than the first range.`. [#29531](https://github.com/ClickHouse/ClickHouse/pull/29531) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29630](https://github.com/ClickHouse/ClickHouse/issues/29630)でバックポート: `x.y.z...` のような `DEFAULT` expression で誤った table Identifier を使用した場合に、`ALTER MODIFY` クエリでまれに発生する segfault を修正しました。[#29184](https://github.com/ClickHouse/ClickHouse/issues/29184) を修正します。[#29573](https://github.com/ClickHouse/ClickHouse/pull/29573) ([alesapin](https://github.com/alesapin)).
* [#29658](https://github.com/ClickHouse/ClickHouse/issues/29658)でバックポート: 別名を含む JIT expression compilation と short-circuit expression evaluation の不具合を修正しました。[#29403](https://github.com/ClickHouse/ClickHouse/issues/29403) をクローズします。[#29574](https://github.com/ClickHouse/ClickHouse/pull/29574) ([Maksim Kita](https://github.com/kitaisreal)).
* [#29751](https://github.com/ClickHouse/ClickHouse/issues/29751)でバックポート: push-down 最適化の後に filter predicate 内の condition が失われることがある問題を修正しました。[#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29849](https://github.com/ClickHouse/ClickHouse/issues/29849)でバックポート: `GROUP BY` 中の `LowCardinality` への同時アクセスの不具合を修正しました (SIGSEGV につながる可能性があります) 。[#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* [#29909](https://github.com/ClickHouse/ClickHouse/issues/29909)でバックポート: `ATTACH TABLE ... FROM 'path'` クエリで、path の代わりに文字列以外の literal を使用した場合の不正な cast を修正しました。これにより未初期化メモリの読み取りにつながる可能性がありました。[#29790](https://github.com/ClickHouse/ClickHouse/pull/29790) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#29865](https://github.com/ClickHouse/ClickHouse/issues/29865)でバックポート: ごくまれに発生する可能性があった `Timeout exceeded: elapsed 18446744073.709553 seconds` エラーを回避しました。原因は kernel の何らかの bug であると見られます。[#29154](https://github.com/ClickHouse/ClickHouse/issues/29154) を修正します。[#29811](https://github.com/ClickHouse/ClickHouse/pull/29811) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30024](https://github.com/ClickHouse/ClickHouse/issues/30024)でバックポート: MaterializedMySQL: MySQL との connection が失われた場合に、transaction の一部しか処理されないことがある issue を修正しました。[#29837](https://github.com/ClickHouse/ClickHouse/pull/29837) ([Håvard Kvålen](https://github.com/havardk)).
* [#29878](https://github.com/ClickHouse/ClickHouse/issues/29878) でバックポート: システムテーブルの再作成チェックを修正しました (`enum` 値の変更を検出できない問題) 。 [#29857](https://github.com/ClickHouse/ClickHouse/pull/29857) ([Azat Khuzhin](https://github.com/azat)).

* [#30070](https://github.com/ClickHouse/ClickHouse/issues/30070) でバックポート: `tuple()` によるサンプルで発生するクラッシュを修正し、[#30004](https://github.com/ClickHouse/ClickHouse/issues/30004) をクローズしました。 [#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
