  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v213983-lts-fixme-as-compared-to-v213876-lts">
  ### ClickHouse リリース v21.3.9.83-lts FIXME (v21.3.8.76-lts との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#23680](https://github.com/ClickHouse/ClickHouse/issues/23680) にバックポートされました: `quantile(s)TDigest` を修正しました。tdunning/t-digest 3.2+ に従い、singleton セントロイドに対する特別な処理を追加しました。また、旧バージョンのアルゴリズム実装におけるセントロイドの過剰圧縮に関する不具合も修正しました。[#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#23579](https://github.com/ClickHouse/ClickHouse/issues/23579) にバックポートされました: 古いブロックのバックグラウンドクリーンアップで発生する、ごくまれなレースコンディションを修正しました。重複排除ウィンドウの終端に近すぎる場合、ブロックが重複排除されない可能性がありました。[#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#23677](https://github.com/ClickHouse/ClickHouse/issues/23677) にバックポートされました: パーティションプルーニング時に NOT 条件を緩和しないようにしました。これにより [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) と [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539) を修正します。[#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird))。
* [#23582](https://github.com/ClickHouse/ClickHouse/issues/23582) にバックポートされました: * `join_algorithm = 'auto'` の dict join におけるバグを修正しました。[#23002](https://github.com/ClickHouse/ClickHouse/issues/23002) をクローズします。[#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir))。
* [#23585](https://github.com/ClickHouse/ClickHouse/issues/23585) にバックポートされました: バージョン 21.1 より前と同様に、より多くの条件を `PREWHERE` に移動できるようにしました。移動される条件の数が不十分だと、パフォーマンスの低下につながる可能性がありました。[#23397](https://github.com/ClickHouse/ClickHouse/pull/23397) ([Anton Popov](https://github.com/CurtizJ))。
* [#23592](https://github.com/ClickHouse/ClickHouse/issues/23592) にバックポートされました: マルチディスク構成の ReplicatedMergeTree テーブル作成に失敗した際に発生する `Cannot unlink file` エラーを修正しました。これにより [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755) をクローズします。[#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#23590](https://github.com/ClickHouse/ClickHouse/issues/23590) にバックポートされました: `ReplacingMergeTree` における垂直マージのコーナーケースを修正しました。まれに、`Incomplete granules are not allowed while blocks are granules size` のような例外により、マージが失敗することがありました。[#23459](https://github.com/ClickHouse/ClickHouse/pull/23459) ([Anton Popov](https://github.com/CurtizJ))。
* [#23612](https://github.com/ClickHouse/ClickHouse/issues/23612) にバックポートされました: restart / stop コマンドがハングする問題を修正しました。[#20214](https://github.com/ClickHouse/ClickHouse/issues/20214) をクローズします。[#23552](https://github.com/ClickHouse/ClickHouse/pull/23552) ([filimonov](https://github.com/filimonov))。
* [#23696](https://github.com/ClickHouse/ClickHouse/issues/23696) にバックポートされました: 集約関数 `mannWhitneyUTest` において、両方のサンプルの値が完全に同一である場合に例外を追加しました。これにより [#23646](https://github.com/ClickHouse/ClickHouse/issues/23646) を修正します。[#23654](https://github.com/ClickHouse/ClickHouse/pull/23654) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov))。
