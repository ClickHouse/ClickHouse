<div id="buildtestingpackaging-improvement">

* [#56733](https://github.com/ClickHouse/ClickHouse/issues/56733)でバックポート: builderコンテナー内で、変更されたサブモジュールを取得しないようにしました。 [#56689](https://github.com/ClickHouse/ClickHouse/pull/56689) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#56581](https://github.com/ClickHouse/ClickHouse/issues/56581)でバックポート: 明示的なカラム定義を使用する table function でテーブルを作成した場合に、`system.tables` の `data_paths` カラムがリモート data source を参照しないようにしました。[#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#56877](https://github.com/ClickHouse/ClickHouse/issues/56877)でバックポート: `view()` table function で `UNION` のクエリ結果が不完全になる問題を修正しました。[#56274](https://github.com/ClickHouse/ClickHouse/pull/56274) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#56409](https://github.com/ClickHouse/ClickHouse/issues/56409)でバックポート: 既存のテーブルに型 `Object(JSON)` のカラムを追加することを禁止しました。これにより [#56095](https://github.com/ClickHouse/ClickHouse/issues/56095) をクローズします。これにより [#49944](https://github.com/ClickHouse/ClickHouse/issues/49944) をクローズします。[#56307](https://github.com/ClickHouse/ClickHouse/pull/56307) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#56756](https://github.com/ClickHouse/ClickHouse/issues/56756)でバックポート: Kafka table の作成中に Kerberos の初期化で発生した例外が原因で起きる segfault を修正しました。[#56073](https://github.com/ClickHouse/ClickHouse/issues/56073) をクローズします。[#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#56748](https://github.com/ClickHouse/ClickHouse/issues/56748)でバックポート: RabbitMQ table engine がセキュアな connection 経由で RabbitMQ に接続できなかった問題を修正しました。[#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* [#56839](https://github.com/ClickHouse/ClickHouse/issues/56839)でバックポート: `FPC` codec を使用して不正なデータを展開した際に server が crash する問題を修正しました。この問題は [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて [https://twitter.com/malacupa](https://twitter.com/malacupa) により報告されました。[#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
