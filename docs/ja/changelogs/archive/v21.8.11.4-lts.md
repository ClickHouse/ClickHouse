<div id="bug-fix">
  #### バグ修正
</div>

* [#31368](https://github.com/ClickHouse/ClickHouse/issues/31368) でバックポート: 部分的な権限の取り消しを使用した場合の SHOW GRANTS を修正しました。この PR は [#31138](https://github.com/ClickHouse/ClickHouse/issues/31138) を修正します。[#31249](https://github.com/ClickHouse/ClickHouse/pull/31249) ([Vitaly Baranov](https://github.com/vitlibar)).

#### バグ修正 (正式な安定版リリースでユーザーに影響する不具合

* [#30914](https://github.com/ClickHouse/ClickHouse/issues/30914)でバックポート: `TO` と `FROM` が指定されており、結果セットに行がない場合の `ORDER BY ... WITH FILL` を修正しました。[#30888](https://github.com/ClickHouse/ClickHouse/pull/30888) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#28756](https://github.com/ClickHouse/ClickHouse/issues/28756) でバックポート: すべてのキーカラムが使われていない場合の NOT-IN 索引最適化を修正しました。これにより [#28120](https://github.com/ClickHouse/ClickHouse/issues/28120) も修正されます。 [#28315](https://github.com/ClickHouse/ClickHouse/pull/28315) ([Amos Bird](https://github.com/amosbird)).
* [#30825](https://github.com/ClickHouse/ClickHouse/issues/30825) でバックポート: PREWHERE 使用時に発生する &quot;Column is not under aggregate function and not in GROUP BY&quot; を修正しました ([#28461](https://github.com/ClickHouse/ClickHouse/issues/28461) の修正) 。 [#28502](https://github.com/ClickHouse/ClickHouse/pull/28502) ([Azat Khuzhin](https://github.com/azat)).
* [#29175](https://github.com/ClickHouse/ClickHouse/issues/29175) でバックポート: IN 句で複数カラムを使用する外部データベース (例: MySQL) へのクエリ (例: `(k,v) IN ((1, 2))`) を修正しました (ただし、`clickhouse-copier` は tuple 要素の alias を使用しているため、一部に後方互換性のない変更があります) 。 [#28888](https://github.com/ClickHouse/ClickHouse/pull/28888) ([Azat Khuzhin](https://github.com/azat)).
* [#30610](https://github.com/ClickHouse/ClickHouse/issues/30610) でバックポート: ORDER BY に WITH FILL が含まれる場合の不適切な最適化を修正しました。これにより [#28908](https://github.com/ClickHouse/ClickHouse/issues/28908) はクローズされます。これにより [#26049](https://github.com/ClickHouse/ClickHouse/issues/26049) はクローズされます。 [#28910](https://github.com/ClickHouse/ClickHouse/pull/28910) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#30767](https://github.com/ClickHouse/ClickHouse/issues/30767) でバックポート: 新しいレプリカの追加中に Replicated database で DDLクエリがハングする問題を修正しました。 [#29328](https://github.com/ClickHouse/ClickHouse/pull/29328) ([Kevin Michel](https://github.com/kmichel-aiven)).
* [#30205](https://github.com/ClickHouse/ClickHouse/issues/30205) でバックポート: `StorageLog` における `LogSink::writeMarks()` と `LogSource` 間の data race を修正しました。 [#29946](https://github.com/ClickHouse/ClickHouse/pull/29946) ([Azat Khuzhin](https://github.com/azat)).
* [#30463](https://github.com/ClickHouse/ClickHouse/issues/30463) でバックポート: 関数 `initializeAggregation` で Nullableな引数をサポートしました。 [#30177](https://github.com/ClickHouse/ClickHouse/pull/30177) ([Anton Popov](https://github.com/CurtizJ)).
* [#30655](https://github.com/ClickHouse/ClickHouse/issues/30655) でバックポート: `[I]LIKE` 関数を修正しました。 [#28661](https://github.com/ClickHouse/ClickHouse/issues/28661) をクローズします。 [#30244](https://github.com/ClickHouse/ClickHouse/pull/30244) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#30289](https://github.com/ClickHouse/ClickHouse/issues/30289) でバックポート: ComplexKeyHashedDictionary および ComplexKeySparseHashedDictionary で、layout config から `preallocate` オプションをパースする処理を修正しました。 [#30246](https://github.com/ClickHouse/ClickHouse/pull/30246) ([Maksim Kita](https://github.com/kitaisreal)).
* [#30525](https://github.com/ClickHouse/ClickHouse/issues/30525) でバックポート: REPLACE PARTITION の実行中に session の有効期限が切れた場合に発生しうる segfault を修正しました。 [#30432](https://github.com/ClickHouse/ClickHouse/pull/30432) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `parallel_view_processing` の例外処理を修正しました。これにより、この feature が有効で、materialized view の処理中に例外 (例: &quot;Memory limit exceeded ...&quot;) が発生した場合の、まれなコーナーケースでの問題を解消し、crash を防止します。 [#30472](https://github.com/ClickHouse/ClickHouse/pull/30472) ([filimonov](https://github.com/filimonov)).
* [#30585](https://github.com/ClickHouse/ClickHouse/issues/30585) でバックポート: * 同じテーブルに対する scalar subquery を含む ALTER で発生するデッドロックを修正し、[#30461](https://github.com/ClickHouse/ClickHouse/issues/30461) をクローズしました。[#30492](https://github.com/ClickHouse/ClickHouse/pull/30492) ([Vladimir C](https://github.com/vdimir)).
* [#30607](https://github.com/ClickHouse/ClickHouse/issues/30607) でバックポート: Limit push down 最適化によって `Cannot find column` エラーが発生することがありました。[#30438](https://github.com/ClickHouse/ClickHouse/issues/30438) を修正しました。[#30562](https://github.com/ClickHouse/ClickHouse/pull/30562) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#30753](https://github.com/ClickHouse/ClickHouse/issues/30753) でバックポート: `positionCaseInsensitiveUTF8` や `countSubstringsCaseInsensitiveUTF8` など、UTF-8 文字列に対する大文字小文字を区別しない検索 Functions で、実際には一致しない substrings が見つかってしまうことがありましたが、これを修正しました。[#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30710](https://github.com/ClickHouse/ClickHouse/issues/30710) でバックポート: PREWHERE が常に true の場合における、WHERE 付き PREWHERE の問題を修正しました。[#30668](https://github.com/ClickHouse/ClickHouse/pull/30668) ([Azat Khuzhin](https://github.com/azat)).
* [#30770](https://github.com/ClickHouse/ClickHouse/issues/30770) でバックポート: non-replicated `MergeTree` で、`REPLACE/MOVE PARTITION` とバックグラウンド merge の間に発生する race condition を修正しました。この問題により、移動または置換された data の一部がパーティション内に残ることがありました。[#29327](https://github.com/ClickHouse/ClickHouse/issues/29327) を修正しました。[#30717](https://github.com/ClickHouse/ClickHouse/pull/30717) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30857](https://github.com/ClickHouse/ClickHouse/issues/30857) でバックポート: `ReplicatedMergeTree` で ZooKeeper パス から補助的な ZooKeeper 名を抽出する際の曖昧さを修正しました。以前は、ZooKeeper パス にコロンが含まれていると、server が `Unknown auxiliary ZooKeeper name` を出して起動に失敗することがありました。[#29052](https://github.com/ClickHouse/ClickHouse/issues/29052) を修正しました。また、先頭がスラッシュで始まらない ZooKeeper パス もこれまでは指定できていましたが、現在は非推奨となっており、そのようなパスを持つ新しい table は作成できません。補助的な ZooKeeper 名にスラッシュやコロンを含めることもできません。[#30822](https://github.com/ClickHouse/ClickHouse/pull/30822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30925](https://github.com/ClickHouse/ClickHouse/issues/30925) でバックポート: オペランドが 3 つ以上ある場合に、AND/OR 式で set 索引 が使用されない問題を修正しました。これにより [#30416](https://github.com/ClickHouse/ClickHouse/issues/30416) も修正されます。 [#30887](https://github.com/ClickHouse/ClickHouse/pull/30887) ([Amos Bird](https://github.com/amosbird)).
* [#31151](https://github.com/ClickHouse/ClickHouse/issues/31151) でバックポート: ATTACH PARTITION ... FROM および MOVE PARTITION ... の場合、max&#95;partition&#95;size&#95;to&#95;drop チェックをスキップするようにしました。[#30995](https://github.com/ClickHouse/ClickHouse/pull/30995) ([Amr Alaa](https://github.com/amralaa-MSFT)).
* [#31040](https://github.com/ClickHouse/ClickHouse/issues/31040) でバックポート: `formatRow` 関数を row フォーマット 以外で使用すると segfault が発生していました。そのため、そのような フォーマット ではこの関数を使用できないようにしました (意味がないためです) 。[#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar)).
* [#31132](https://github.com/ClickHouse/ClickHouse/issues/31132)でバックポート: 引用符付き識別子を含む JSONValue/Query を修正しました。これにより、JSON path に空白を含められるようになりました。[#30971](https://github.com/ClickHouse/ClickHouse/issues/30971) をクローズ。[#31003](https://github.com/ClickHouse/ClickHouse/pull/31003) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#31372](https://github.com/ClickHouse/ClickHouse/issues/31372)でバックポート: 別名および WHERE 句を使用した StorageMerge を修正しました (これまではまったく動作していませんでした) 。[#28802](https://github.com/ClickHouse/ClickHouse/issues/28802) をクローズ。[#31044](https://github.com/ClickHouse/ClickHouse/pull/31044) ([Kseniia Sumarokova](https://github.com/kssenii)).
