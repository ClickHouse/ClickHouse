  ### ClickHouse リリース v20.11.6.6-stable FIXME (v20.11.5.18-stable と比較して)

<div id="bug-fix">
  #### バグ修正
</div>

* [#17797](https://github.com/ClickHouse/ClickHouse/issues/17797)でバックポート: - OFFSET のみを含むクエリに対する optimize&#95;distributed&#95;group&#95;by&#95;sharding&#95;key の不具合を修正しました。 [#16996](https://github.com/ClickHouse/ClickHouse/pull/16996) ([Azat Khuzhin](https://github.com/azat)).
* [#18394](https://github.com/ClickHouse/ClickHouse/issues/18394)でバックポート: サーバーがデーモンモードで実行されているときに `system.stack_trace` テーブルが空になる問題を修正しました。 [#17630](https://github.com/ClickHouse/ClickHouse/pull/17630) ([Amos Bird](https://github.com/amosbird)).
* [#18044](https://github.com/ClickHouse/ClickHouse/issues/18044)でバックポート: `topK` 集約関数で発生する可能性のある segfault を修正しました。これにより [#17404](https://github.com/ClickHouse/ClickHouse/issues/17404) はクローズされます。 [#17845](https://github.com/ClickHouse/ClickHouse/pull/17845) ([Maksim Kita](https://github.com/kitaisreal)).
* [#18022](https://github.com/ClickHouse/ClickHouse/issues/18022)でバックポート: クエリに ARRAY JOIN が含まれている場合 (つまり実際には自明でないクエリ) 、自明なクエリ最適化によって誤った結果が生成される問題を修正しました。 [#17887](https://github.com/ClickHouse/ClickHouse/pull/17887) ([sundyli](https://github.com/sundy-li)).
* [#17979](https://github.com/ClickHouse/ClickHouse/issues/17979)でバックポート: [#15187](https://github.com/ClickHouse/ClickHouse/issues/15187) と [#17912](https://github.com/ClickHouse/ClickHouse/issues/17912) を修正し、MaterializeMySQL で MySQL のプレフィックス索引の変換をサポートしました。CC: @tavplubix. [#17944](https://github.com/ClickHouse/ClickHouse/pull/17944) ([Winter Zhang](https://github.com/zhang2014)).
* [#18080](https://github.com/ClickHouse/ClickHouse/issues/18080)でバックポート: S3 URL のパース時に発生する `std::out_of_range: basic_string` を修正しました。 [#18059](https://github.com/ClickHouse/ClickHouse/pull/18059) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#18180](https://github.com/ClickHouse/ClickHouse/issues/18180)でバックポート: setting profile を設定しようとした際に発生する `Unknown setting profile` エラーを修正しました。 [#18167](https://github.com/ClickHouse/ClickHouse/pull/18167) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#18358](https://github.com/ClickHouse/ClickHouse/issues/18358)でバックポート: [#18186](https://github.com/ClickHouse/ClickHouse/issues/18186) と [#16372](https://github.com/ClickHouse/ClickHouse/issues/16372) を修正し、MaterializeMySQL データベースエンジンで一意キー変換時にクラッシュする問題を修正しました。 [#18211](https://github.com/ClickHouse/ClickHouse/pull/18211) ([Winter Zhang](https://github.com/zhang2014)).
* [#18259](https://github.com/ClickHouse/ClickHouse/issues/18259)でバックポート: Enum 型と Int 型の間のキー比較を修正しました。これにより [#17989](https://github.com/ClickHouse/ClickHouse/issues/17989) を修正します。 [#18214](https://github.com/ClickHouse/ClickHouse/pull/18214) ([Amos Bird](https://github.com/amosbird)).
* [#18297](https://github.com/ClickHouse/ClickHouse/issues/18297)でバックポート: - IPv4/IPv6 デュアルスタック環境のマシンで、サーバーから `clickhouse-odbc-bridge` プロセスに到達できない問題を修正しました; - ODBC Dictionary の更新時に不正なクエリが使用されたり、クラッシュが発生したりする問題を修正しました; おそらく [#14489](https://github.com/ClickHouse/ClickHouse/issues/14489) をクローズします。 [#18278](https://github.com/ClickHouse/ClickHouse/pull/18278) ([Denis Glazachev](https://github.com/traceon)).
