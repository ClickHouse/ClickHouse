* [#26857](https://github.com/ClickHouse/ClickHouse/issues/26857) でバックポート: ParallelFormattingOutputFormat: collector&#95;thread への join の処理に mutex を使用するよう修正 ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)). [#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)).
* [#26939](https://github.com/ClickHouse/ClickHouse/issues/26939) でバックポート: データとメタデータの不整合を防ぐため、ReplicatedMergeTree テーブルのシャットダウン時にデータを削除しないよう修正。[#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* [#26985](https://github.com/ClickHouse/ClickHouse/issues/26985) でバックポート: 一部の集約関数コンビネータの適用時に aggregate function の parameter が失われ、`Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported` のような Exception が発生する可能性がありました。修正済みです。[#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) と [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433) を修正。[#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26910](https://github.com/ClickHouse/ClickHouse/issues/26910) でバックポート: library-bridge ids の読み込みを修正。[#26834](https://github.com/ClickHouse/ClickHouse/pull/26834) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26946](https://github.com/ClickHouse/ClickHouse/issues/26946) でバックポート: `DEFAULT` カラムが `DEFAULT` 式を持たない他の非 materialized カラムを参照している場合に発生する error `Missing columns: 'xxx'` を修正。[#26591](https://github.com/ClickHouse/ClickHouse/issues/26591) を修正。[#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)).
* [#27000](https://github.com/ClickHouse/ClickHouse/issues/27000) でバックポート: カスタム TLD の読み取りを修正 (buffer が小さい場合や file が大きい場合に processing が停止する問題) 。[#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* [#27085](https://github.com/ClickHouse/ClickHouse/issues/27085) でバックポート: `ALTER TABLE ... PARTITION ID xxx` のような queries で、partition ID の妥当性が検証されるようになりました。[#25718](https://github.com/ClickHouse/ClickHouse/issues/25718) を修正。[#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* [#27052](https://github.com/ClickHouse/ClickHouse/issues/27052) でバックポート: [RFC] DROP&#95;RANGE との競合によって発生しうる mutation stack を修正。[#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* [#27159](https://github.com/ClickHouse/ClickHouse/issues/27159) でバックポート: GRPCServer の同期処理を修正。この PR は [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024) を修正します。[#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#27367](https://github.com/ClickHouse/ClickHouse/issues/27367) でバックポート: - 空の array に対する関数 `multiSearch*` の未初期化 memory を修正し、[#27169](https://github.com/ClickHouse/ClickHouse/issues/27169) をクローズ。[#27181](https://github.com/ClickHouse/ClickHouse/pull/27181) ([Vladimir C](https://github.com/vdimir)).
* [#27260](https://github.com/ClickHouse/ClickHouse/issues/27260) にバックポート: まれに `system.detached_parts` テーブルに一部のパーツの誤った情報が含まれることがありましたが、修正されました。[#27114](https://github.com/ClickHouse/ClickHouse/issues/27114) を修正。[#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#27466](https://github.com/ClickHouse/ClickHouse/issues/27466) にバックポート: 古い構文で作成された MergeTree テーブルのパーティション ID の不正な検証を修正。[#27328](https://github.com/ClickHouse/ClickHouse/pull/27328) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#27646](https://github.com/ClickHouse/ClickHouse/issues/27646) にバックポート: 行レベルセキュリティ、PREWHERE、LowCardinality フィルターを含むクエリで不正な結果になる問題を修正。[#27179](https://github.com/ClickHouse/ClickHouse/issues/27179) を修正。[#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#27471](https://github.com/ClickHouse/ClickHouse/issues/27471) にバックポート: メトリクス BackgroundMessageBrokerSchedulePoolTask を修正。おそらく名前のタイプミスです。[#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* `cache`, `complex_key_cache`, `ssd_cache`, `complex_key_ssd_cache` の設定のパースを修正。`allow_read_expired_keys`、`max_update_queue_size`、`update_queue_push_timeout_milliseconds`、`query_wait_timeout_milliseconds` の各オプションが、`cache` 型以外の Dictionaries ではパースされていませんでした。[#27523](https://github.com/ClickHouse/ClickHouse/pull/27523) ([Maksim Kita](https://github.com/kitaisreal)).
* [#27731](https://github.com/ClickHouse/ClickHouse/issues/27731) にバックポート: 一部のパーツに欠落したカラムが含まれている場合に、プロジェクションのマテリアライズ中にクラッシュする問題を修正。これにより [#27512](https://github.com/ClickHouse/ClickHouse/issues/27512) を修正。[#27528](https://github.com/ClickHouse/ClickHouse/pull/27528) ([Amos Bird](https://github.com/amosbird)).
* [#27978](https://github.com/ClickHouse/ClickHouse/issues/27978) にバックポート: windowFunnel の `"strict"` モードに関するバグを修正。これにより [#27469](https://github.com/ClickHouse/ClickHouse/issues/27469) を修正。[#27563](https://github.com/ClickHouse/ClickHouse/pull/27563) ([achimbab](https://github.com/achimbab)).
* [#27675](https://github.com/ClickHouse/ClickHouse/issues/27675) にバックポート: 接続が閉じられなくなる PostgreSQL テーブル関数の問題を修正。[#26088](https://github.com/ClickHouse/ClickHouse/issues/26088) をクローズ。[#27662](https://github.com/ClickHouse/ClickHouse/pull/27662) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#27699](https://github.com/ClickHouse/ClickHouse/issues/27699) にバックポート: `arrayHas` のような関数を、`DateTime` や `DateTime64` などの異なる非数値型の Nullable な LowCardinality の配列に適用した際の不正な型キャストを修正。以前のバージョンでは不正なキャストが発生していましたが、新しいバージョンでは例外が発生するようになります。これにより [#26330](https://github.com/ClickHouse/ClickHouse/issues/26330) をクローズ。[#27682](https://github.com/ClickHouse/ClickHouse/pull/27682) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#27746](https://github.com/ClickHouse/ClickHouse/issues/27746) にバックポート: arrow-cmake の CMakeLists.txt から重複したソースファイルを削除。[#27736](https://github.com/ClickHouse/ClickHouse/pull/27736) ([李扬](https://github.com/taiyang-li)).
* [#27865](https://github.com/ClickHouse/ClickHouse/issues/27865) にバックポート: Kafka から NULL (tombstone) メッセージを受信した際に、一部のフォーマットでクラッシュが発生する問題を修正しました。[#19255](https://github.com/ClickHouse/ClickHouse/issues/19255) をクローズ。[#27794](https://github.com/ClickHouse/ClickHouse/pull/27794) ([filimonov](https://github.com/filimonov))。
* [#28348](https://github.com/ClickHouse/ClickHouse/issues/28348) にバックポート: `DROP PART` のまれに発生するバグを修正しました。このバグにより、`Unexpected merged part intersects drop range` エラーが発生することがあります。[#27807](https://github.com/ClickHouse/ClickHouse/pull/27807) ([alesapin](https://github.com/alesapin))。
* [#27957](https://github.com/ClickHouse/ClickHouse/issues/27957) にバックポート: `LowCardinality(UUID)` 型のカラムに対して extremes を指定して選択する際の不具合を修正しました。[#27918](https://github.com/ClickHouse/ClickHouse/pull/27918) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#27952](https://github.com/ClickHouse/ClickHouse/issues/27952) にバックポート: Distributed テーブルの作成前にクラスター名を確認し、誤ったクラスター名でテーブルを作成できないようにしました。[#27832](https://github.com/ClickHouse/ClickHouse/issues/27832) を修正。[#27927](https://github.com/ClickHouse/ClickHouse/pull/27927) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#28206](https://github.com/ClickHouse/ClickHouse/issues/28206) にバックポート: 読み取りバッファで &#39;attempt to read after end of file&#39; が発生するケースを修正しました。[#26149](https://github.com/ClickHouse/ClickHouse/issues/26149) をクローズ。[#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd))。

* [#28256](https://github.com/ClickHouse/ClickHouse/issues/28256) にバックポート: children に対する `set` リクエストで list ウォッチ (`getChildren`) がトリガーされた際の `clickhouse-keeper` の不正な動作を修正しました。[#28190](https://github.com/ClickHouse/ClickHouse/pull/28190) ([alesapin](https://github.com/alesapin)) 。
* [#28264](https://github.com/ClickHouse/ClickHouse/issues/28264) にバックポート: `Nullable(LowCardinality)` 型および Extremes を含む queries で、未初期化メモリを読み取る可能性がある問題を修正しました。[#28165](https://github.com/ClickHouse/ClickHouse/issues/28165) を修正。[#28205](https://github.com/ClickHouse/ClickHouse/pull/28205) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* [#28291](https://github.com/ClickHouse/ClickHouse/issues/28291) にバックポート: `ORDER BY` と `Merge` table を含む queries で、設定 `optimize_read_in_order` が enabled の場合に結果が不整合になる問題を修正しました。[#28266](https://github.com/ClickHouse/ClickHouse/pull/28266) ([Anton Popov](https://github.com/CurtizJ)) 。
