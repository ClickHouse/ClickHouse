<div id="clickhouse-release-v201221-stable-fixme-as-compared-to-v201115109-prestable">
  ### v20.11.1.5109-prestable と比較した ClickHouse release v20.12.2.1-stable FIXME
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* `File` engine を使用するテーブルの作成時に、`SETTINGS` clause でファイルフォーマットに関連する user settings (例: `format_csv_delimiter`) を受け付け、これらの設定をすべての `INSERT` と `SELECT` で使用するようにしました。current user session で変更したファイルフォーマット設定、または DML クエリ自体の `SETTINGS` clause で指定した設定は、そのクエリには影響しなくなります。[#16591](https://github.com/ClickHouse/ClickHouse/pull/16591) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* デフォルトで `use_compact_format_in_distributed_parts_names` を有効にしました (詳細は reference のドキュメントを参照してください) 。[#16728](https://github.com/ClickHouse/ClickHouse/pull/16728) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### 新機能
</div>

* 新しい ALTER UPDATE/DELETE IN PARTITION 構文を追加しました。[#13403](https://github.com/ClickHouse/ClickHouse/pull/13403) ([Vladimir Chebotarev](https://github.com/excitoon)).
* StorageEmbeddedRocksdb Engine を追加しました。[#15073](https://github.com/ClickHouse/ClickHouse/pull/15073) ([sundyli](https://github.com/sundy-li)).
* `ALTER TABLE ... DROP|DETACH PART 'part_name'` クエリを導入しました。[#15511](https://github.com/ClickHouse/ClickHouse/pull/15511) ([nvartolomei](https://github.com/nvartolomei)).
* `clickhouse-client` で `--history_file` parameter を使用して履歴ファイルのパスを変更できるようにしました。[#15960](https://github.com/ClickHouse/ClickHouse/pull/15960) ([Maksim Kita](https://github.com/kitaisreal)).
* DateTime、DateTime64 のフォーマットを更新し、文字列の Date リテラルフォーマットを受け付けられるようにしました。[#16040](https://github.com/ClickHouse/ClickHouse/pull/16040) ([Maksim Kita](https://github.com/kitaisreal)).
* setting `aggregate_functions_null_for_empty` を追加しました。このオプションは、クエリ内のすべての aggregate functions を rewrite して、それらに `-OrNull` 接尾辞を追加します。[10273](https://github.com/ClickHouse/ClickHouse/issues/10273) を修正しました。[#16123](https://github.com/ClickHouse/ClickHouse/pull/16123) ([flynn](https://github.com/ucasfl)).
* ネストされた型が String の場合に、Nullable、LowCardinality、Array、Tuple での COLLATE をサポートしました。また、ColumnString.cpp の collations 関連コードもリファクタリングしました。[#16273](https://github.com/ClickHouse/ClickHouse/pull/16273) ([Kruglov Pavel](https://github.com/Avogar)).
* 異なるレプリカ間で merges を分散できるようになりました。`execute_merges_on_single_replica_time_threshold` mergetree setting を導入しました。[#16424](https://github.com/ClickHouse/ClickHouse/pull/16424) ([filimonov](https://github.com/filimonov)).
* `*.xz` の圧縮/展開サポートを追加しました。これにより `file()` function で `*.xz` を使用できるようになります。これにより [#8828](https://github.com/ClickHouse/ClickHouse/issues/8828) をクローズします。[#16578](https://github.com/ClickHouse/ClickHouse/pull/16578) ([Abi Palagashvili](https://github.com/fibersel)).
* 新しい `cmath` 関数を追加しました: - acosh - asinh - atan2 - atanh - cosh - hypot - log1p - sinh。[#16636](https://github.com/ClickHouse/ClickHouse/pull/16636) ([Konstantin Malanchev](https://github.com/hombit)).
* TSV および CSV フォーマットで、デフォルトで enum 値をその id として入力できるようにしました。[#16834](https://github.com/ClickHouse/ClickHouse/pull/16834) ([Kruglov Pavel](https://github.com/Avogar)).
* 新しい tcpPort() function は、この server が待ち受けている TCP ポートを返します。[#17134](https://github.com/ClickHouse/ClickHouse/pull/17134) ([Ivan](https://github.com/abyss7)).



<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 完全一致によるパーティションの安全なプルーニングが可能になりました。便利なケース: たとえば、テーブルが intHash64(x) % 100 でパーティション分割されており、クエリ条件が x ではなく intHash64(x) % 100 そのものに対して指定されている場合です。[#16253](https://github.com/ClickHouse/ClickHouse/pull/16253) ([Amos Bird](https://github.com/amosbird)).
* Floyd-Rivest アルゴリズムを使用します。部分ソートにおける ClickHouse のユースケースでは、これが最適なはずです。ベンチマークは https://github.com/danlark1/miniselect および [こちら](https://drive.google.com/drive/folders/1DHEaeXgZuX6AJ9eByeZ8iQVQv0ueP8XM) にあります。[#16825](https://github.com/ClickHouse/ClickHouse/pull/16825) ([Daniel Kutenin](https://github.com/danlark1)).
* [#17589](https://github.com/ClickHouse/ClickHouse/issues/17589) でバックポート: 非常に多数の `MergeTree` テーブルにまたがる `Merge` テーブルからの読み取り性能を改善。[#7748](https://github.com/ClickHouse/ClickHouse/issues/7748) を修正。[#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).



<div id="improvement">
  #### 改善
</div>

* `EXPLAIN` に `VIEW` サブクエリの説明を追加。`VIEW` に対するプッシュダウン最適化を制限。クエリプランに `Distributed` のローカルレプリカを追加。[#14936](https://github.com/ClickHouse/ClickHouse/pull/14936) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `indexOf()` が BloomFilter を使用するように変更。[#14977](https://github.com/ClickHouse/ClickHouse/pull/14977) ([achimbab](https://github.com/achimbab)).
* MySQL 同期ユーザーに誤った権限が設定されている場合、適切な同期権限に関する例外をスローするように変更。[#15977](https://github.com/ClickHouse/ClickHouse/pull/15977) ([TCeason](https://github.com/TCeason)).
* materialized view のループが作成された場合に発生する可能性のあるスタックオーバーフローを修正。[#15732](https://github.com/ClickHouse/ClickHouse/issues/15732) をクローズ。[#16048](https://github.com/ClickHouse/ClickHouse/pull/16048) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* リモートリソースへの HTTPS 接続で SNI をサポート。これにより SNI を必要とする Cloudflare サーバーへの接続が可能になる。[#10055](https://github.com/ClickHouse/ClickHouse/issues/10055) を修正。[#16252](https://github.com/ClickHouse/ClickHouse/pull/16252) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ReplicatedMergeTree` エンジンファミリーがレプリケーションフェッチ専用のスレッドプールを使用するように変更。プールのサイズは `background_fetches_pool_size` 設定で制限され、サーバー再起動により調整可能。デフォルト値は 3 で、並列フェッチの最大数が 3 となる（10G ネットワークの活用が可能）。#520 を修正。[#16390](https://github.com/ClickHouse/ClickHouse/pull/16390) ([alesapin](https://github.com/alesapin)).
* `<auxiliary_zookeepers>` の設定を `config.xml` で変更し、サーバーを再起動せずにリロードできるように変更。[#16627](https://github.com/ClickHouse/ClickHouse/pull/16627) ([Amos Bird](https://github.com/amosbird)).
* 同じサイズの整数と浮動小数点数の間での reinterpret を許可。[16640](https://github.com/ClickHouse/ClickHouse/issues/16640) を修正。[#16657](https://github.com/ClickHouse/ClickHouse/pull/16657) ([flynn](https://github.com/ucasfl)).
* nginx サーバーをプロキシとして S3 を使用する際の回避策を追加。nginx は現在 `http://domain.com?delete` のような空パスの URL を受け付けないが、標準の aws-sdk-cpp はこのような URL を生成する。本コミットではパッチ済みの aws-sdk-cpp を使用し、該当ケースで `http://domain.com/?delete` のように "/" をパスとして含む URL を生成するように変更。[#16709](https://github.com/ClickHouse/ClickHouse/pull/16709) ([ianton-ru](https://github.com/ianton-ru)).
* Distributed エンジン起動時に、非同期 INSERT の空ディレクトリを削除するように変更。[#16729](https://github.com/ClickHouse/ClickHouse/pull/16729) ([Azat Khuzhin](https://github.com/azat)).
* ユーザビリティの改善: `CREATE TABLE` クエリで `CODEC` 式の位置が誤っている場合の構文エラーメッセージに、より適切な提案を表示するように変更。[#12493](https://github.com/ClickHouse/ClickHouse/issues/12493) を修正。[#16768](https://github.com/ClickHouse/ClickHouse/pull/16768) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* distributed DDL の設定が存在しない場合の例外メッセージを改善。[#5075](https://github.com/ClickHouse/ClickHouse/issues/5075) を修正。[#16769](https://github.com/ClickHouse/ClickHouse/pull/16769) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `internal_replication` を使用した各 INSERT に `use_compact_format_in_distributed_parts_names` を適用するように変更。[#16788](https://github.com/ClickHouse/ClickHouse/pull/16788) ([Azat Khuzhin](https://github.com/azat)).
* 誤った設定が指定された場合（`metric_log`.`collect_interval_milliseconds` が欠落している場合）、サーバーが例外メッセージを出力して起動を拒否するように変更。[#16815](https://github.com/ClickHouse/ClickHouse/pull/16815) ([Ivan](https://github.com/abyss7)).
* `cutToFirstSignificantSubdomainWithWWW()` を追加。[#16845](https://github.com/ClickHouse/ClickHouse/pull/16845) ([Azat Khuzhin](https://github.com/azat)).
* ATTACH/DETACH TABLE <DICTIONARY> を実行した際に、わかりやすいエラーメッセージをスローするように変更。本 PR 以前は `detach table <dict>` が動作するものの、メモリ上のメタデータが不正な状態になっていた。[#16885](https://github.com/ClickHouse/ClickHouse/pull/16885) ([Amos Bird](https://github.com/amosbird)).
* TTL、ミューテーション、またはコラプシングマージアルゴリズムによって刈り込まれた後の空パーツを削除するように変更。[#16895](https://github.com/ClickHouse/ClickHouse/pull/16895) ([Anton Popov](https://github.com/CurtizJ)).
* SNI を必要とする `clickhouse-server` のセキュアエンドポイントへの接続を可能に。`clickhouse-server` が TLS プロキシの背後にホストされている場合に利用できる。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).
* `SOURCE(CLICKHOUSE(...))` の `host` および `port` パラメーターのデフォルト値を現在のインスタンスに設定し、`user` のデフォルト値を `'default'` に設定するように変更。[#16997](https://github.com/ClickHouse/ClickHouse/pull/16997) ([Vladimir C](https://github.com/vdimir)).
* `JSONEachRow` フォーマットで、`output_format_json_array_of_rows` 設定により全行を JSON 配列として出力する機能を追加。[#17152](https://github.com/ClickHouse/ClickHouse/pull/17152) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* JSON 入出力フォーマット使用時に、`output_format_json_named_tuples_as_objects` 設定（デフォルト無効）により named tuple を JSON オブジェクトとしてフォーマットできるように変更。[#17175](https://github.com/ClickHouse/ClickHouse/pull/17175) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* JSONEachRow、JSONCompactEachRow、および RegexpRow 入力フォーマットのエラーメッセージの文法を修正。[#17205](https://github.com/ClickHouse/ClickHouse/pull/17205) ([nico piderman](https://github.com/sneako)).
