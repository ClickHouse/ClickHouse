<div id="bug-fix">
  #### バグ修正
</div>

* [#42432](https://github.com/ClickHouse/ClickHouse/issues/42432) でバックポート: - BigInt を使用する LowCardinality に対して、正しい集約方法を選択。 [#42342](https://github.com/ClickHouse/ClickHouse/pull/42342) ([Duc Canh Le](https://github.com/canhld94)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#42328](https://github.com/ClickHouse/ClickHouse/issues/42328)でバックポート: cctz を最新の master に更新し、tzdb を 2020e に更新しました。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano)).
* [#42358](https://github.com/ClickHouse/ClickHouse/issues/42358)でバックポート: 新しい timezone の変更に対応するため、tzdata を 2022e に更新しました。パレスチナの切り替え時刻は土曜日の 02:00 になりました。ウクライナの 3 つのゾーンを 1 つに統合しました。ヨルダンとシリアは、DST ありの +02/+03 から通年 +03 に切り替わりました。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS))。これにより [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252) をクローズしました。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#42298](https://github.com/ClickHouse/ClickHouse/issues/42298)でバックポート: projections と `aggregate_functions_null_for_empty` 設定に関する不具合を修正しました。この不具合は非常にまれで、server の config で `aggregate_functions_null_for_empty` 設定を有効にした場合にのみ発生します。これにより [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647) はクローズされます。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#42592](https://github.com/ClickHouse/ClickHouse/issues/42592)でバックポート: これにより [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453) はクローズされます。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
