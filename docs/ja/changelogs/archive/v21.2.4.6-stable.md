  # 2022年の変更履歴

<div id="clickhouse-release-v21246-stable-fixme-as-compared-to-v212315-stable">
  ### ClickHouse リリース v21.2.4.6-stable FIXME (v21.2.3.15-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#20510](https://github.com/ClickHouse/ClickHouse/issues/20510)でバックポート: 壊れた JSON を処理する際にファイル全体をメモリへ読み込もうとして、アロケータから例外が発生していた問題を修正しました。[#19719](https://github.com/ClickHouse/ClickHouse/issues/19719) を修正。[#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#20575](https://github.com/ClickHouse/ClickHouse/issues/20575)でバックポート: テーブル関数 `view` が式リストで使用されている場合にエラーを投げるようチェックを追加しました。これにより [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342) を修正。[#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)).
* [#20486](https://github.com/ClickHouse/ClickHouse/issues/20486)でバックポート: JOIN に SELECT の定数が含まれる場合に `join_use_nulls=1` で発生する `LOGICAL_ERROR` を修正しました。[#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)).
* [#20535](https://github.com/ClickHouse/ClickHouse/issues/20535)でバックポート: WITH の別名をサブクエリに伝播する際の無限ループを修正しました。これにより [#20388](https://github.com/ClickHouse/ClickHouse/issues/20388) を修正。[#20476](https://github.com/ClickHouse/ClickHouse/pull/20476) ([Amos Bird](https://github.com/amosbird)).
* [#20615](https://github.com/ClickHouse/ClickHouse/issues/20615)でバックポート: 非同期 INSERT のディレクトリ名をパースする際に適切なチェックを追加しました (SIGSEGV を修正) 。[#20498](https://github.com/ClickHouse/ClickHouse/pull/20498) ([Azat Khuzhin](https://github.com/azat)).
* [#20887](https://github.com/ClickHouse/ClickHouse/issues/20887)でバックポート: UNION DISTINCT と LIMIT 句を含むサブクエリの問題を修正しました。[#20597](https://github.com/ClickHouse/ClickHouse/issues/20597) をクローズ。[#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)).
* [#20993](https://github.com/ClickHouse/ClickHouse/issues/20993)でバックポート: 集約関数で `-State` combinator と `-Distinct` combinator を組み合わせて使用する際の問題を修正しました。[#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* [#20987](https://github.com/ClickHouse/ClickHouse/issues/20987)でバックポート: MySQL 5.7クライアントで ClickHouse server に接続した際、`USE database;` クエリが動作しなかった問題を修正しました。[#18926](https://github.com/ClickHouse/ClickHouse/issues/18926) を修正。[#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)).
