<div id="clickhouse-release-v2281523-lts-d36fa168bbf-fixme-as-compared-to-v2281453-lts-4ea67c40077">
  ### ClickHouse リリース v22.8.15.23-lts (d36fa168bbf) FIXME (v22.8.14.53-lts (4ea67c40077) と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#46981](https://github.com/ClickHouse/ClickHouse/issues/46981) でバックポート: `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` がすべてのレプリカに適用されるようにしました。これは、`ALTER TABLE t MOVE` がレプリケーションされないためです。[#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#47336](https://github.com/ClickHouse/ClickHouse/issues/47336)でバックポート: ロールを変更した後、そのロールを使用しているユーザーのアクセス権に変更が反映されないことがありました。このPRでこの問題を修正しました。 [#46772](https://github.com/ClickHouse/ClickHouse/pull/46772) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#46901](https://github.com/ClickHouse/ClickHouse/issues/46901)でバックポート: - QueryNormalizer における alias の誤った再帰処理を修正しました。[#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano))。
* [#47156](https://github.com/ClickHouse/ClickHouse/issues/47156)でバックポート: - `min` および `max` を使った集約最適化における算術操作を修正しました。[#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94))。
* [#46987](https://github.com/ClickHouse/ClickHouse/issues/46987)でバックポート: 部分文字列検索に変換され、引用符で囲まれた非 LIKE メタ文字を含む LIKE 条件の結果を修正しました。[#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze))。
* [#47357](https://github.com/ClickHouse/ClickHouse/issues/47357)でバックポート: 分散クエリのキャンセル時に発生する可能性があるデッドロックを修正しました。[#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar))。
