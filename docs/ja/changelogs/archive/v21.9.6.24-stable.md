<div id="improvement">

* [#31371](https://github.com/ClickHouse/ClickHouse/issues/31371)でバックポート: 部分的な REVOKE が使用されている場合に SHOW GRANTS が正しく動作しない問題を修正しました。このPRで [#31138](https://github.com/ClickHouse/ClickHouse/issues/31138) を修正しています。[#31249](https://github.com/ClickHouse/ClickHouse/pull/31249) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#31576](https://github.com/ClickHouse/ClickHouse/issues/31576)でバックポート: QUOTA の上限に達していないにもかかわらず、上限超過と判定される問題を修正しました。このPRで [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正しています。[#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

#### バグ修正 (ユーザーに影響する不具合

* [#30765](https://github.com/ClickHouse/ClickHouse/issues/30765)でバックポート: 新しいレプリカの追加中に Replicated database で DDLクエリがハングする問題を修正。 [#29328](https://github.com/ClickHouse/ClickHouse/pull/29328) ([Kevin Michel](https://github.com/kmichel-aiven)).
* [#30505](https://github.com/ClickHouse/ClickHouse/issues/30505)でバックポート: server の再起動時に `materialized_postgresql_tables_list` の設定が正しく動作しない問題を修正。[#28529](https://github.com/ClickHouse/ClickHouse/issues/28529) で発見。 [#29686](https://github.com/ClickHouse/ClickHouse/pull/29686) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#30464](https://github.com/ClickHouse/ClickHouse/issues/30464)でバックポート: 関数 `initializeAggregation` で Nullable 引数をサポート。 [#30177](https://github.com/ClickHouse/ClickHouse/pull/30177) ([Anton Popov](https://github.com/CurtizJ)).
* [#30657](https://github.com/ClickHouse/ClickHouse/issues/30657)でバックポート: `[I]LIKE` 関数を修正。 [#28661](https://github.com/ClickHouse/ClickHouse/issues/28661) をクローズ。 [#30244](https://github.com/ClickHouse/ClickHouse/pull/30244) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#30524](https://github.com/ClickHouse/ClickHouse/issues/30524)でバックポート: REPLACE PARTITION の実行中にセッションの有効期限が切れた場合に発生する可能性がある segfault を修正。 [#30432](https://github.com/ClickHouse/ClickHouse/pull/30432) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30586](https://github.com/ClickHouse/ClickHouse/issues/30586)でバックポート: * 同じテーブルに対するスカラーサブクエリを含む ALTER でのデッドロックを修正し、[#30461](https://github.com/ClickHouse/ClickHouse/issues/30461) をクローズ。 [#30492](https://github.com/ClickHouse/ClickHouse/pull/30492) ([Vladimir C](https://github.com/vdimir)).
* [#30606](https://github.com/ClickHouse/ClickHouse/issues/30606)でバックポート: Limit push down 最適化により `Cannot find column` エラーが発生する可能性がある問題を修正。 [#30438](https://github.com/ClickHouse/ClickHouse/issues/30438) を修正。 [#30562](https://github.com/ClickHouse/ClickHouse/pull/30562) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#30752](https://github.com/ClickHouse/ClickHouse/issues/30752)でバックポート: `positionCaseInsensitiveUTF8` や `countSubstringsCaseInsensitiveUTF8` などの UTF-8 文字列に対する大文字・小文字を区別しない検索関数で、実際には一致しない部分文字列を見つけてしまうことがある問題を修正。 [#30663](https://github.com/ClickHouse/ClickHouse/pull/30663) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30711](https://github.com/ClickHouse/ClickHouse/issues/30711)でバックポート: PREWHERE が常に true の場合に、WHERE と併用した PREWHERE の問題を修正。 [#30668](https://github.com/ClickHouse/ClickHouse/pull/30668) ([Azat Khuzhin](https://github.com/azat)).
* [#30769](https://github.com/ClickHouse/ClickHouse/issues/30769)でバックポート: 非レプリケートの `MergeTree` で、`REPLACE/MOVE PARTITION` とバックグラウンドマージの間に race condition があり、移動または置換したデータの一部がパーティション内に残ることがある問題を修正しました。[#29327](https://github.com/ClickHouse/ClickHouse/issues/29327) を修正します。[#30717](https://github.com/ClickHouse/ClickHouse/pull/30717) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#30858](https://github.com/ClickHouse/ClickHouse/issues/30858)でバックポート: `ReplicatedMergeTree` で ZooKeeper パス から補助的な ZooKeeper 名を抽出する際の曖昧さを修正しました。従来は、ZooKeeper パス にコロンが含まれていると、サーバーが `Unknown auxiliary ZooKeeper name` により起動に失敗することがありました。[#29052](https://github.com/ClickHouse/ClickHouse/issues/29052) を修正します。また、先頭がスラッシュでない ZooKeeper パス も指定できていましたが、現在ではこれは非推奨であり、そのようなパスを持つ新しい table は作成できません。補助的な ZooKeeper 名にスラッシュやコロンを含めることもできなくなりました。[#30822](https://github.com/ClickHouse/ClickHouse/pull/30822) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#30924](https://github.com/ClickHouse/ClickHouse/issues/30924)でバックポート: オペランドが 3 つ以上ある場合に、AND/OR 式で set 索引 が使用されない問題を修正しました。これにより [#30416](https://github.com/ClickHouse/ClickHouse/issues/30416) を修正します。[#30887](https://github.com/ClickHouse/ClickHouse/pull/30887) ([Amos Bird](https://github.com/amosbird))。
* [#31290](https://github.com/ClickHouse/ClickHouse/issues/31290)でバックポート: intersect/except に関するいくつかのコーナーケースを修正しました。[#30803](https://github.com/ClickHouse/ClickHouse/issues/30803) をクローズします。[#30965](https://github.com/ClickHouse/ClickHouse/pull/30965) ([Kseniia Sumarokova](https://github.com/kssenii))。

* [#31039](https://github.com/ClickHouse/ClickHouse/issues/31039)でバックポート: `formatRow` 関数を行フォーマット以外で使用すると segfault が発生していました。そのため、そのようなフォーマットではこの関数を使用できないようにしました (意味がないためです) 。[#31001](https://github.com/ClickHouse/ClickHouse/pull/31001) ([Kruglov Pavel](https://github.com/Avogar))。
