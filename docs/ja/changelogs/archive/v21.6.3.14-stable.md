  ### ClickHouse リリース v21.6.3.14-stable FIXME (v21.6.2.7-prestable との比較)

<div id="improvement">
  #### 改善
</div>

* [#24531](https://github.com/ClickHouse/ClickHouse/issues/24531) にバックポート: 複数の S3 ボリュームを使用するゼロコピー レプリケーションを修正 ([#22679](https://github.com/ClickHouse/ClickHouse/issues/22679) を修正) 。[#22864](https://github.com/ClickHouse/ClickHouse/pull/22864) ([ianton-ru](https://github.com/ianton-ru)).
* [#24776](https://github.com/ClickHouse/ClickHouse/issues/24776) にバックポート: スカラー サブクエリで `Limit for rows or bytes to read exceeded` のようなエラーが隠れてしまう問題を修正。[#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#24727](https://github.com/ClickHouse/ClickHouse/issues/24727) にバックポート: &quot;multipart/form-data&quot; メッセージで、boundary の直前にある CRLF をその一部として扱うように修正しました。[#23905](https://github.com/ClickHouse/ClickHouse/issues/23905) を修正します。[#24399](https://github.com/ClickHouse/ClickHouse/pull/24399) ([Ivan](https://github.com/abyss7)).
* [#24827](https://github.com/ClickHouse/ClickHouse/issues/24827) にバックポート: - LDAP グループが存在しないローカルロールにマッピングされている場合に、LDAP ロールの (再) マッピング中に発生する可能性があるデッドロックを修正しました。[#24431](https://github.com/ClickHouse/ClickHouse/pull/24431) ([Denis Glazachev](https://github.com/traceon)).
* [#24936](https://github.com/ClickHouse/ClickHouse/issues/24936) にバックポート: - ZooKeeper との接続が失われ、接続復旧後にレプリカがクローンされた場合、その replication queue に古いエントリが含まれることがありました。これを修正しました。- replication queue に交差する仮想パーツが含まれている場合に発生するクラッシュを修正しました。これは、一部のデータパーツが失われた場合にまれに発生する可能性があります。プロセスを終了する代わりに、log に error を出力するようにしました。[#24777](https://github.com/ClickHouse/ClickHouse/pull/24777) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24851](https://github.com/ClickHouse/ClickHouse/issues/24851) にバックポート: mutation がまだメモリに読み込まれていない場合に、mutation の待機中に例外 `Mutation was killed` が client に送出されることがあるバグを修正しました。[#24809](https://github.com/ClickHouse/ClickHouse/pull/24809) ([alesapin](https://github.com/alesapin)).
* [#24916](https://github.com/ClickHouse/ClickHouse/issues/24916) にバックポート: メモリ容量の少ない server で、ごくまれに再起動しないと merges を実行できなくなる不具合を修正しました。おそらく [#24603](https://github.com/ClickHouse/ClickHouse/issues/24603) も修正されます。[#24872](https://github.com/ClickHouse/ClickHouse/pull/24872) ([alesapin](https://github.com/alesapin)).
* [#24952](https://github.com/ClickHouse/ClickHouse/issues/24952) にバックポート: Arrow における heap-buffer-overflow の可能性を修正しました。[#24922](https://github.com/ClickHouse/ClickHouse/pull/24922) ([Kruglov Pavel](https://github.com/Avogar)).
