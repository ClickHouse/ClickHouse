  ### ClickHouse リリース v22.6.8.35-stable (b91dc59a565) FIXME v22.6.7.7-stable (8eae2af3b9a) との比較

<div id="new-feature">
  #### 新機能
</div>

* [#40868](https://github.com/ClickHouse/ClickHouse/issues/40868) でバックポート: kafka&#95;num&#95;consumers の上限を無効化する設定を追加しました。[#40331](https://github.com/ClickHouse/ClickHouse/issues/40331) をクローズしました。[#40670](https://github.com/ClickHouse/ClickHouse/pull/40670) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#41274](https://github.com/ClickHouse/ClickHouse/issues/41274)でバックポート: 引数として Nullable の Array を使用した場合に `encrypt` 関数および `contingency` 関数で発生するメモリ安全性の問題を修正しました。これにより [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004) が修正されます。[#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#41282](https://github.com/ClickHouse/ClickHouse/issues/41282)でバックポート: WITHステートメントで導入された、未使用の不明なカラムに関する不具合を修正しました。これにより [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812) を修正します。 [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* [#40905](https://github.com/ClickHouse/ClickHouse/issues/40905)でバックポート: タスクスケジューリングの失敗時に `WriteBufferFromS3` で発生する可能性があるデッドロックを修正しました。 [#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)).
* [#40864](https://github.com/ClickHouse/ClickHouse/issues/40864)でバックポート: - 可変次元の配列を含む `Object` 型の値のパース中に発生するクラッシュを修正しました。 [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* [#40803](https://github.com/ClickHouse/ClickHouse/issues/40803)でバックポート: `ProcessList` に新しいクエリを追加する際に、割り当てが発生します。これらの割り当て中にメモリ制限に達すると、`ProcessList::mutex` がすでに取得されているため、`OvercommitTracker` を使用できません。[#40611](https://github.com/ClickHouse/ClickHouse/issues/40611) を修正します。 [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* [#40891](https://github.com/ClickHouse/ClickHouse/issues/40891)でバックポート: クエリコンテキストなしで MV に push する際 (Kafka/... から発生) のメモリリークを修正しました。 [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* [#41133](https://github.com/ClickHouse/ClickHouse/issues/41133)でバックポート: `DESCRIBE TABLE url()` およびその他いくつかの `DESCRIBE TABLE <table_function>()` のアクセス権を修正しました。 [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#41360](https://github.com/ClickHouse/ClickHouse/issues/41360)でバックポート: ディスクのオブジェクトストレージで発生する、誤った論理エラー `Expected relative path` を修正しました。 [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246) に関連します。 [#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#41357](https://github.com/ClickHouse/ClickHouse/issues/41357)でバックポート: MsgPack フォーマットで UUID を挿入する前に、カラム型チェックを追加しました。 [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
