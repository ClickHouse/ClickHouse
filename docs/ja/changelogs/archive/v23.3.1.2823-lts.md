  # 2023年の変更履歴
</div>

<div id="clickhouse-release-v23312823-lts-46e85357ce2-fixme-as-compared-to-v23212537-stable-52bf836e03a">
  ### ClickHouse リリース v23.3.1.2823-lts (46e85357ce2) FIXME (v23.2.1.2537-stable (52bf836e03a) と比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* *domain*RFC()/netloc() において、URL authority で使用できる記号を緩和しました。[#46841](https://github.com/ClickHouse/ClickHouse/pull/46841) ([Azat Khuzhin](https://github.com/azat)).
* カラムに対して DEFAULT/EPHEMERAL/ALIAS/MATERIALIZED を指定した KafkaEngine ベースのテーブルの作成を禁止しました。[#47138](https://github.com/ClickHouse/ClickHouse/pull/47138) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* 「非同期接続ドレイン」機能を削除しました。関連する設定とメトリクスも削除されています。これは内部機能だったため、この機能を知らなかったユーザーには影響しないはずです。[#47486](https://github.com/ClickHouse/ClickHouse/pull/47486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `arraySum`/`Min`/`Max`/`Avg`/`Product`、`arrayCumSum`/`CumSumNonNegative`、`arrayDifference`、配列の構築、IN Operator、クエリパラメータ、`groupArrayMovingSum`、統計関数、`min`/`max`/`any`/`argMin`/`argMax`、PostgreSQL ワイヤプロトコル、MySQL table engine と function、`sumMap`、`mapAdd`、`mapSubtract`、`arrayIntersect` で 256-bit Decimal データ型 (38 桁超) をサポートしました。`arrayIntersect` では bigint のサポートも追加しました。モーメントを含む統計 aggregate functions (`corr` や各種 `TTest` など) は、内部表現として `Float64` を使用するようになります (この変更前は `Decimal128` を使用していましたが、意味がありませんでした) 。また、分散が無限大の場合、これらの関数は `inf` ではなく `nan` を返すことがあります。以前のバージョンでは、一部の関数が `Decimal256` データ型で使用できても `Decimal128` を返していましたが、これを修正しました。これにより [#47569](https://github.com/ClickHouse/ClickHouse/issues/47569) をクローズします。これにより [#44864](https://github.com/ClickHouse/ClickHouse/issues/44864) をクローズします。これにより [#28335](https://github.com/ClickHouse/ClickHouse/issues/28335) をクローズします。[#47594](https://github.com/ClickHouse/ClickHouse/pull/47594) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* backup&#95;threads/restore&#95;threads を server settings にしました。[#47881](https://github.com/ClickHouse/ClickHouse/pull/47881) ([Azat Khuzhin](https://github.com/azat)).
* 不正な IPv6 address に対して false positive を返すことがあった isIPv6String 関数を修正しました。たとえば `1234::1234:` は有効な IPv6 address と見なされていました。[#47895](https://github.com/ClickHouse/ClickHouse/pull/47895) ([Nikolay Degterinsky](https://github.com/evillique)).

<div id="new-feature">
  #### 新機能
</div>

* 設定 `parallel_replicas_custom_key` および `parallel_replicas_custom_key_filter_type` を使用して、レプリカ間で処理を分割する新しいモードを追加しました。クラスターが複数のレプリカを持つ単一の分片で構成されている場合、最大 `max_parallel_replicas` 個までがランダムに選択され、分片として扱われます。各分片について、対応するフィルターがイニシエーター上でクエリに追加されてから、その分片に送信されます。クラスターが複数の分片で構成されている場合は、`sample_key` と同様に動作しますが、任意のキーを定義できます。[#45108](https://github.com/ClickHouse/ClickHouse/pull/45108) ([Antonio Andelic](https://github.com/antonio2368)).
* クエリ設定 `partial_result_on_first_cancel` を追加しました。これにより、キャンセルされたクエリ (たとえば Ctrl-C によるもの) で部分的な結果を返せるようになります。[#45689](https://github.com/ClickHouse/ClickHouse/pull/45689) ([Alexey Perevyshin](https://github.com/alexX512)).
* Replicated および KeeperMap エンジンを除き、一時テーブルで任意のテーブルエンジンをサポートするようにしました。[#31497](https://github.com/ClickHouse/ClickHouse/issues/31497) を部分的にクローズします。[#46071](https://github.com/ClickHouse/ClickHouse/pull/46071) ([Roman Vasin](https://github.com/rvasin)).
* ZooKeeper を使用したユーザー定義 SQL 関数のレプリケーションを追加しました。[#46085](https://github.com/ClickHouse/ClickHouse/pull/46085) ([Aleksei Filatov](https://github.com/aalexfvk)).
* サーバー設定を含む `system.server_settings` (`system.settings` と同様) を実装しました。[#46550](https://github.com/ClickHouse/ClickHouse/pull/46550) ([pufit](https://github.com/pufit)).
* 関数 `WIDTH_BUCKET` を導入しました。[#42974](https://github.com/ClickHouse/ClickHouse/issues/42974). [#46790](https://github.com/ClickHouse/ClickHouse/pull/46790) ([avoiderboi](https://github.com/avoiderboi)).
* 指定した format string に従って parseDateTime/parseDateTimeInJodaSyntax 関数を追加しました。parseDateTime は文字列を MySQL syntax の DateTime にパースし、parseDateTimeInJodaSyntax は Joda syntax でパースします。[#46815](https://github.com/ClickHouse/ClickHouse/pull/46815) ([李扬](https://github.com/taiyang-li)).
* テーブル関数 `null` のデフォルト structure として `dummy UInt8` を使用します。[#46930](https://github.com/ClickHouse/ClickHouse/issues/46930) をクローズします。[#47006](https://github.com/ClickHouse/ClickHouse/pull/47006) ([flynn](https://github.com/ucasfl)).
* parseDateTimeBestEffort 関数で `Dec 15, 2021` のサポートを追加しました。[#46816](https://github.com/ClickHouse/ClickHouse/issues/46816) をクローズします。[#47071](https://github.com/ClickHouse/ClickHouse/pull/47071) ([chen](https://github.com/xiedeyantu)).
* 関数 ULIDStringToDateTime() を追加しました。[#46945](https://github.com/ClickHouse/ClickHouse/issues/46945) をクローズします。[#47087](https://github.com/ClickHouse/ClickHouse/pull/47087) ([Nikolay Degterinsky](https://github.com/evillique)).
* HTTPインターフェイスの URL params `wait_end_of_query` および `buffer_size` に対応する設定 `http_wait_end_of_query` と `http_response_buffer_size` を追加しました。[#47108](https://github.com/ClickHouse/ClickHouse/pull/47108) ([Vladimir C](https://github.com/vdimir)).
* `UNDROP TABLE` クエリをサポートしました。[#46811](https://github.com/ClickHouse/ClickHouse/issues/46811) をクローズします。[#47241](https://github.com/ClickHouse/ClickHouse/pull/47241) ([chen](https://github.com/xiedeyantu)).
* `Atomic` database から drop されたものの、まだ完全には削除されていないテーブルを表示する `system.marked_dropped_tables` table を追加しました。[#47364](https://github.com/ClickHouse/ClickHouse/pull/47364) ([chen](https://github.com/xiedeyantu)).
* MySQL との互換性のため、`positionCaseInsensitive` の alias として `INSTR` を追加しました。[#47529](https://github.com/ClickHouse/ClickHouse/issues/47529) を解決します。[#47535](https://github.com/ClickHouse/ClickHouse/pull/47535) ([flynn](https://github.com/ucasfl))。
* 固定精度で数値を文字列に変換できる `toDecimalString` 関数を追加しました。[#47838](https://github.com/ClickHouse/ClickHouse/pull/47838) ([Andrey Zvonov](https://github.com/zvonand))。
* MySQL との互換性向上のため、演算子 &quot;LIKE&quot;、&quot;IN&quot;、&quot;MOD&quot; などと同様の演算子 &quot;REGEXP&quot; を追加しました。[#47869](https://github.com/ClickHouse/ClickHouse/pull/47869) ([Robert Schulze](https://github.com/rschu1ze))。
* CLICKHOUSE ソースを持つ DIRECT dictionary の読み取り pipeline を複数スレッドで実行できるようにしました。有効にするには、`CREATE DICTIONARY` ステートメントのソースの `SETTINGS` セクションで `dictionary_use_async_executor=1` を設定してください。[#47986](https://github.com/ClickHouse/ClickHouse/pull/47986) ([Vladimir C](https://github.com/vdimir))。
* MergeTree 設定 `max_number_of_mutatuins_for_replica` を追加しました。これにより、レプリカごとの part mutation の数を指定した値に制限できます。ゼロは、レプリカごとの mutation 数に制限がないことを意味します (実行は引き続き他の設定によって制約される場合があります) 。[#48047](https://github.com/ClickHouse/ClickHouse/pull/48047) ([Vladimir C](https://github.com/vdimir))。

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 1 つの Nullable キーによる集計のパフォーマンスを最適化しました。[#45772](https://github.com/ClickHouse/ClickHouse/pull/45772) ([LiuNeng](https://github.com/liuneng1994)).
* hasTokenOrNull、hasTokenCaseInsensitive、hasTokenCaseInsensitiveOrNull で、小文字の tokenbf&#95;v1 索引を利用できるようにしました。[#46252](https://github.com/ClickHouse/ClickHouse/pull/46252) ([ltrk2](https://github.com/ltrk2)).
* 汎用 SIMD StringSearcher を、先頭 2 文字を先に検索することで最適化しました。[#46289](https://github.com/ClickHouse/ClickHouse/pull/46289) ([Jiebin Sun](https://github.com/jiebinn)).
* System.detached&#95;parts が非常に大きくなる可能性がありました。- ブロックサイズの制限を考慮して複数のソースを追加しました - 各ブロックでは I/O スレッドプールを使ってパートサイズを計算します。つまり、syscall を並列に実行します。[#46624](https://github.com/ClickHouse/ClickHouse/pull/46624) ([Sema Checherinda](https://github.com/CheSema)).
* ReplicatedMergeTree テーブルの `max_replicated_merges_in_queue` のデフォルト値を 16 から 1000 に引き上げました。これにより、ClickHouse Cloud で共有ストレージを使用するクラスターのように、非常に多くのレプリカを持つクラスターでバックグラウンドのマージ処理をより高速に実行できます。[#47050](https://github.com/ClickHouse/ClickHouse/pull/47050) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 以前のバージョンでは、大量のファイルに対するバックアップが極端に遅いものでした。[#47251](https://github.com/ClickHouse/ClickHouse/pull/47251) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* StorageJoin、StorageDictionary、StorageEmbeddedRocksDB を使った JOIN で、左テーブルへの filter push down をサポートしました。[#47280](https://github.com/ClickHouse/ClickHouse/pull/47280) ([Maksim Kita](https://github.com/kitaisreal)).
* メモリ上のマークは圧縮されるようになり、メモリ使用量が 3～6 分の 1 になりました。[#47290](https://github.com/ClickHouse/ClickHouse/pull/47290) ([Michael Kolupaev](https://github.com/al13n321)).
* パーティションの一覧を取得するために、copier が distinct の代わりに group by を使うよう更新しました。大規模なテーブルでは、これにより select 時間が 500 秒超から 1 秒未満に短縮されました。[#47386](https://github.com/ClickHouse/ClickHouse/pull/47386) ([Clayton McClure](https://github.com/cmcclure-twilio)).
* [https://github.com/clickhouse/clickhouse/issues/46453](https://github.com/clickhouse/clickhouse/issues/46453) に対応しました。bisect により [https://github.com/clickhouse/clickhouse/pull/35525](https://github.com/clickhouse/clickhouse/pull/35525) が問題のある変更として特定されました。この PR は、その PR での変更を差し戻すものです。[#47544](https://github.com/ClickHouse/ClickHouse/pull/47544) ([Ongkong](https://github.com/ongkong)).
* `FINAL` を含むクエリで過剰な読み取りが発生する問題を修正しました。[#47801](https://github.com/ClickHouse/ClickHouse/pull/47801) ([Nikita Taranov](https://github.com/nickitat)).
* `max_final_threads` は、サーバー起動時に (`max_threads` と同じアルゴリズムで) コア数に設定されるようになりました。これにより、CPU 数の多いサーバーでの `final` 実行の同時実行性が向上します。[#47915](https://github.com/ClickHouse/ClickHouse/pull/47915) ([Nikita Taranov](https://github.com/nickitat)).
* パフォーマンス向上のため、読み取りリクエストでバッチを分割しないようにしました。[#47978](https://github.com/ClickHouse/ClickHouse/pull/47978) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="improvement">
  #### 改善
</div>

* map 関連関数 `mapFromArrays` を追加しました。これにより、一対の配列から map を作成できます。[#31125](https://github.com/ClickHouse/ClickHouse/pull/31125) ([李扬](https://github.com/taiyang-li)).
* Distributed の送信処理を見直し、queue としてファイルシステムを使わず、代わりにインメモリ queue を使用するようにしました。[#45491](https://github.com/ClickHouse/ClickHouse/pull/45491) ([Azat Khuzhin](https://github.com/azat)).
* named collections に対して個別の grant を許可しました (たとえば、`SHOW/CREATE/ALTER/DROP named collection` のアクセス権を一括ではなく、特定のコレクションにのみ付与できるようになります) 。[#40894](https://github.com/ClickHouse/ClickHouse/issues/40894) をクローズします。新しいアクセス種別 `NAMED_COLLECTION_CONTROL` を追加しました。これはユーザー config に明示的に追加しない限り default user には付与されません (`GRANT ALL` の実行に必要です) 。また、23.2 では full access rights を持つために default user に対して手動で指定する必要があった `show_named_collections` も、不要になりました。[#46241](https://github.com/ClickHouse/ClickHouse/pull/46241) ([Kseniia Sumarokova](https://github.com/kssenii)).
* これで、HTTPプロトコル経由のすべてのクエリのレスポンスに `X-ClickHouse-Query-Id` と `X-ClickHouse-Timezone` headers が追加されるようになりました。以前は `SELECT` クエリに対してのみ追加されていました。[#46364](https://github.com/ClickHouse/ClickHouse/pull/46364) ([Anton Popov](https://github.com/CurtizJ)).
* host:port の列挙を含む URI 経由で Replica Set に接続する機能と、MongoDB Dictionaries における readPreference オプションのサポートを追加しました。URI の例: mongodb://db0.example.com:27017,db1.example.com:27017,db2.example.com:27017/?replicaSet=myRepl&amp;readPreference=primary. [#46524](https://github.com/ClickHouse/ClickHouse/pull/46524) ([artem-yadr](https://github.com/artem-yadr)).
* PROJECTION 分析をクエリプラン上に再実装しました。旧バージョンと新バージョンを切り替えるための設定 `query_plan_optimize_projection=1` を追加しました。[#44963](https://github.com/ClickHouse/ClickHouse/issues/44963) を修正しました。[#46537](https://github.com/ClickHouse/ClickHouse/pull/46537) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* デフォルトで出力フォーマットに parquet format v1 ではなく v2 を使用するようにしました。parquet のバージョンを制御する設定 `output_format_parquet_version` を追加しました。設定可能な値は `v1_0`, `v2_4`, `v2_6`, `v2_latest` (デフォルト) です。[#46617](https://github.com/ClickHouse/ClickHouse/pull/46617) ([Kruglov Pavel](https://github.com/Avogar)).
* changelog には含めません。[#42648](https://github.com/ClickHouse/ClickHouse/issues/42648) の一部です。[#46632](https://github.com/ClickHouse/ClickHouse/pull/46632) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* MATERILIZED VIEW への push 時の error を無視できるようにしました (新しい設定 `materialized_views_ignore_errors` を追加。デフォルトは `false` ですが、`system.*_log` tables への logs のフラッシュでは無条件に `true` に設定されます) 。[#46658](https://github.com/ClickHouse/ClickHouse/pull/46658) ([Azat Khuzhin](https://github.com/azat)).
* input&#95;format&#95;json&#95;ignore&#95;unknown&#95;keys&#95;in&#95;named&#95;tuple をデフォルトで有効にしました。[#46742](https://github.com/ClickHouse/ClickHouse/pull/46742) ([Kruglov Pavel](https://github.com/Avogar)).
* 新しい configuration 構文により、名前にピリオドを含む Kafka topics を設定できるようになりました。[#46752](https://github.com/ClickHouse/ClickHouse/pull/46752) ([Robert Schulze](https://github.com/rschu1ze)).
* 問題のある繰り返しについて hyperscan patterns をチェックするヒューリスティクスを修正しました。[#46819](https://github.com/ClickHouse/ClickHouse/pull/46819) ([Robert Schulze](https://github.com/rschu1ze)).
* 別のレプリカが block を同時に作成した場合、`system.errors` に ZK node exists を報告しないようにしました。 [#46820](https://github.com/ClickHouse/ClickHouse/pull/46820) ([Raúl Marín](https://github.com/Algunenano)).
* カラムごとに異なる DEFAULT expression を持つ Merge で、PREWHERE を使用できるようにしました。 [#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* `clickhouse-local` で開けるファイル数の上限を引き上げました。これにより、非常に多くの CPU コアを持つ server 上で `web` table から読み取れるようになります。開いているファイル数が多すぎる場合でも、URL table engine からの読み取りを中断しないようにしました。これにより [#46852](https://github.com/ClickHouse/ClickHouse/issues/46852) を解決します。 [#46853](https://github.com/ClickHouse/ClickHouse/pull/46853) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 数値を parse できない場合に throw される Exception メッセージを、より読みやすくしました。 [#46917](https://github.com/ClickHouse/ClickHouse/pull/46917) ([Robert Schulze](https://github.com/rschu1ze)).
* task が処理されるたびに `system.backups` を更新するようにしました。 [#46989](https://github.com/ClickHouse/ClickHouse/pull/46989) ([Aleksandr Musorin](https://github.com/AVMusorin)).
* Native input format で types 変換を許可しました。これを制御する設定 `input_format_native_allow_types_conversion` を追加しました (デフォルトで enabled) 。 [#46990](https://github.com/ClickHouse/ClickHouse/pull/46990) ([Kruglov Pavel](https://github.com/Avogar)).
* `range` 関数で IPv4 を使って IP 範囲を生成できるようにしました。 [#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [https://github.com/ClickHouse/ClickHouse/pull/46772](https://github.com/ClickHouse/ClickHouse/pull/46772) より前は、ロールの変更が反映されないことがありました。この PR ではテストのみを追加しています。 [#47002](https://github.com/ClickHouse/ClickHouse/pull/47002) ([Ilya Golshtein](https://github.com/ilejn)).
* ある volume/ディスク から別の volume/ディスク へ part を移動できない場合の Exception メッセージを改善しました。 [#47032](https://github.com/ClickHouse/ClickHouse/pull/47032) ([alesapin](https://github.com/alesapin)).
* `JSONType` 関数で `Bool` type をサポートしました。以前は bool value に対して誤って `Null` type が返されていました。 [#47046](https://github.com/ClickHouse/ClickHouse/pull/47046) ([Anton Popov](https://github.com/CurtizJ)).
* 事前定義された http queries を設定するために、&#95;request&#95;body parameter を使用できるようにしました。 [#47086](https://github.com/ClickHouse/ClickHouse/pull/47086) ([Constantine Peresypkin](https://github.com/pkit)).
* カスタム disk structure のログ出力を削除しました。 [#47103](https://github.com/ClickHouse/ClickHouse/pull/47103) ([Kseniia Sumarokova](https://github.com/kssenii)).
* ネストされたカスタム disks を許可しました。以前は、カスタム disks ではフラットな disk structure のみサポートしていました。 [#47106](https://github.com/ClickHouse/ClickHouse/pull/47106) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 組み込み UI の SQL エディタで、Enter キー押下時の自動インデントに対応しました。 [#47113](https://github.com/ClickHouse/ClickHouse/pull/47113) ([Alexey Korepanov](https://github.com/alexkorep)).
* Parquet/ORC/Arrow の output formats で圧縮を制御できるようにし、input formats でより多くの圧縮方式をサポートしました。これにより [#13541](https://github.com/ClickHouse/ClickHouse/issues/13541) を解決します。 [#47114](https://github.com/ClickHouse/ClickHouse/pull/47114) ([Kruglov Pavel](https://github.com/Avogar)).
* &#39;sudo&#39; を使った自己展開では、展開されたファイルの uid と gid を実行中のユーザーに設定しようとします。 [#47116](https://github.com/ClickHouse/ClickHouse/pull/47116) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* 現在、関数 `repeat` の2番目の引数は符号なし整数型である必要があり、`-1` のような整数値は受け付けられません。また、これは Spark の関数の挙動と異なるため、Spark と同じになるよう修正しました。テスト結果は以下のとおりです。 [#47134](https://github.com/ClickHouse/ClickHouse/pull/47134) ([KevinyhZou](https://github.com/KevinyhZou)).
* stacktraces から `::__1` の部分を削除しました。stacktraces では `std::basic_string<char, ...` を `String` と表示します。 [#47171](https://github.com/ClickHouse/ClickHouse/pull/47171) ([Mike Kot](https://github.com/myrrc)).
* バックアップの I/O 操作用に専用のスレッドプールを導入しました。これにより、ほかのプールとは独立してスケールでき、パフォーマンスを向上できます。 [#47174](https://github.com/ClickHouse/ClickHouse/pull/47174) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
