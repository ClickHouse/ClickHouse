  ### ClickHouse リリース v20.12.6.29-stable FIXME (v20.12.5.18-stableとの比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#19984](https://github.com/ClickHouse/ClickHouse/issues/19984) でバックポート: `ON CLUSTER` クエリを実行するバックグラウンドスレッドが、削除されたレプリケートテーブルの処理待ちでハングすることがありました。この問題を修正しました。[#19684](https://github.com/ClickHouse/ClickHouse/pull/19684) ([yiguolei](https://github.com/yiguolei)).
* [#20240](https://github.com/ClickHouse/ClickHouse/issues/20240) でバックポート: 複数の clickhouse-copier を起動した場合に、パーツの宛先テーブルへの移動が失敗することがあるバグを修正しました。[#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* [#20080](https://github.com/ClickHouse/ClickHouse/issues/20080) でバックポート: dictGet() を含むデフォルト式を持つテーブルがある場合に、サーバーの起動に失敗する問題を修正しました。Dictionary を loading しなくても dictGet() の return type を取得できるようにしました。[#19805](https://github.com/ClickHouse/ClickHouse/pull/19805) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#20298](https://github.com/ClickHouse/ClickHouse/issues/20298) でバックポート: * StorageJoin のバグ修正。[#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* [#20391](https://github.com/ClickHouse/ClickHouse/issues/20391) でバックポート: `MongoDB` table engine は、データを読み取る場合にのみ接続を確立するようになりました。`ATTACH TABLE` では接続を試行しなくなりました。[#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#20328](https://github.com/ClickHouse/ClickHouse/issues/20328) でバックポート: シャットダウン中に config を再読み込みすると、まれにサーバーがクラッシュする問題を修正しました。[#19689](https://github.com/ClickHouse/ClickHouse/issues/19689) を修正。[#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* [#20332](https://github.com/ClickHouse/ClickHouse/issues/20332) でバックポート: `*CollapsingMergeTree` および `ReplacingMergeTree` table engines で、バージョンカラムに対する `DROP` または `RENAME` を制限しました。[#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* [#20364](https://github.com/ClickHouse/ClickHouse/issues/20364) でバックポート: `ReplicatedMergeTree` table engines ファミリーで、失敗したバックグラウンドタスクへの再試行が過度に頻繁に行われる問題を修正しました。これにより、ログが冗長になりすぎたり、CPU 負荷が増加したりする可能性がありました。[#20203](https://github.com/ClickHouse/ClickHouse/issues/20203) を修正。[#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* [#20377](https://github.com/ClickHouse/ClickHouse/issues/20377) でバックポート: `join_use_nulls=1` で発生する null 参照外しを修正しました。[#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)).
* [#20360](https://github.com/ClickHouse/ClickHouse/issues/20360) でバックポート: RANGE&#95;HASHED() Dictionary での無効な参照外しを回避しました。[#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)).
