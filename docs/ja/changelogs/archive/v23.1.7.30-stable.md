  # 2023年の変更履歴
</div>

<div id="clickhouse-release-v231730-stable-c94dba6e023-fixme-as-compared-to-v231642-stable-783ddf67991">
  ### ClickHouse リリース v23.1.7.30-stable (c94dba6e023) v23.1.6.42-stable (783ddf67991) と比較した FIXME
</div>

<div id="improvement">
  #### 改善
</div>

* [#48161](https://github.com/ClickHouse/ClickHouse/issues/48161) にバックポート: 利用できない依存テーブルを持つ materialized view にアタッチする際、`UNKNOWN_TABLE` Exception が発生する問題を修正しました。これは、バックアップから状態を復元しようとする場合に役立つ可能性があります。[#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#48585](https://github.com/ClickHouse/ClickHouse/issues/48585) にバックポート: time zones を更新しました。更新対象は次のとおりです: Africa/Cairo, Africa/Casablanca, Africa/El&#95;Aaiun, America/Bogota, America/Cambridge&#95;Bay, America/Ciudad&#95;Juarez, America/Godthab, America/Inuvik, America/Iqaluit, America/Nuuk, America/Ojinaga, America/Pangnirtung, America/Rankin&#95;Inlet, America/Resolute, America/Whitehorse, America/Yellowknife, Asia/Gaza, Asia/Hebron, Asia/Kuala&#95;Lumpur, Asia/Singapore, Canada/Yukon, Egypt, Europe/Kirov, Europe/Volgograd, Singapore。 [#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#48958](https://github.com/ClickHouse/ClickHouse/issues/48958) にバックポート: 最近の更新後、`dockerd` では http ポートを明示的に指定するとともに、`--tlsverify=false` の指定も必要になりました。 [#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* limit 付きの Grace Hash Join での競合状態を修正 [#47153](https://github.com/ClickHouse/ClickHouse/pull/47153) ([Vladimir C](https://github.com/vdimir)).
* projection を含む explain graph を修正 [#47473](https://github.com/ClickHouse/ClickHouse/pull/47473) ([flynn](https://github.com/ucasfl)).
* polygonsSymDifferenceCartesian でのクラッシュを修正 [#47702](https://github.com/ClickHouse/ClickHouse/pull/47702) ([pufit](https://github.com/pufit)).
* ある機能を削除 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Dictionary に依存する分散テーブルの読み込み時に発生する ClickHouse の起動エラーを修正 [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* cache で発生する可能性のある segfault を修正 [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* IP 型および UUID 型のキーを持つ nested map を修正 [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* ACL で認証スキーム `auth` を使ってノードが作成されないことがある Keeper の不具合を修正 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* IPv4 を UInt と比較できるように修正 [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
