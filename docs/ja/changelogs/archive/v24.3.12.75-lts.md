<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#69785](https://github.com/ClickHouse/ClickHouse/issues/69785) でバックポート: MaterializedPostgreSQL で、pg dbname に &quot;-&quot; が含まれる場合に table の Attach が失敗する問題を修正しました。 [#62730](https://github.com/ClickHouse/ClickHouse/pull/62730) ([takakawa](https://github.com/takakawa)).
* [#69461](https://github.com/ClickHouse/ClickHouse/issues/69461) でバックポート: `RoleCache` の有効期限処理を修正しました。 [#67748](https://github.com/ClickHouse/ClickHouse/pull/67748) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#68217](https://github.com/ClickHouse/ClickHouse/issues/68217) でバックポート: 特別に細工されたクエリによってトリガーされ、hopEnd、hopStart、tumbleEnd、tumbleStart 経由で server がクラッシュする NULL ポインタ逆参照を修正しました。 [#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* [#69437](https://github.com/ClickHouse/ClickHouse/issues/69437) でバックポート: 予期しない再起動後、covered-by-broken part の異常な処理により ReplicatedMergeTree のレプリケーションを開始できない問題を修正しました。 [#68584](https://github.com/ClickHouse/ClickHouse/pull/68584) ([baolin](https://github.com/baolinhuang)).
* [#69827](https://github.com/ClickHouse/ClickHouse/issues/69827) でバックポート: `ColumnsDescription::toString` が各カラムのフォーマットに同じ `IAST::FormatState object` を使用するようにしました。これにより、均一なカラムメタデータがディスクと ZooKeeper に書き込まれるようになります。 [#68733](https://github.com/ClickHouse/ClickHouse/pull/68733) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#69294](https://github.com/ClickHouse/ClickHouse/issues/69294) でバックポート: grouping sets における集計データのマージを修正しました。 [#68744](https://github.com/ClickHouse/ClickHouse/pull/68744) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#70470](https://github.com/ClickHouse/ClickHouse/issues/70470) でバックポート: zero copy を使用する replicated merge tree で、`restore replica` 後に無限ループが発生する問題を修正しました。 [#69293](https://github.com/ClickHouse/ClickHouse/pull/69293) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#69456](https://github.com/ClickHouse/ClickHouse/issues/69456) でバックポート: insertion 用の connection 取得時に、すべての接続試行が失敗した場合の未定義動作を修正しました。 [#69390](https://github.com/ClickHouse/ClickHouse/pull/69390) ([Pablo Marcos](https://github.com/pamarcos)).
* [#69497](https://github.com/ClickHouse/ClickHouse/issues/69497) でバックポート: 関数 `sqidDecode` で発生する `LOGICAL_ERROR` を修正しました ([#69450](https://github.com/ClickHouse/ClickHouse/issues/69450))。 [#69451](https://github.com/ClickHouse/ClickHouse/pull/69451) ([Robert Schulze](https://github.com/rschu1ze)).
* [#69724](https://github.com/ClickHouse/ClickHouse/issues/69724) でバックポート: prewhere への移動時に condition の元の順序を維持するようにしました。以前は順序が変わることがあり、順序が重要な場合にクエリが失敗する原因となっていました。 [#69560](https://github.com/ClickHouse/ClickHouse/pull/69560) ([Pavel Kruglov](https://github.com/Avogar)).
* [#69668](https://github.com/ClickHouse/ClickHouse/issues/69668) でバックポート: ZNOAUTH error 後の Keeper マルチリクエストの前処理を修正しました。 [#69627](https://github.com/ClickHouse/ClickHouse/pull/69627) ([Antonio Andelic](https://github.com/antonio2368)).
* [#69792](https://github.com/ClickHouse/ClickHouse/issues/69792) でバックポート: Parquet file 内の Data type を要求された Data type に変換できない場合でも、getHyperrectangleForRowGroup が例外をスローしないようにしました。これにより、Parquet file の Data type が Decimal64 で、カラムの Data type が DateTime だった場合のユーザーの問題が解消されました。 [#69745](https://github.com/ClickHouse/ClickHouse/pull/69745) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#70089](https://github.com/ClickHouse/ClickHouse/issues/70089) でバックポート: SQL security がパラメーター化ビューで正しく機能するようにしました。[#69984](https://github.com/ClickHouse/ClickHouse/pull/69984) ([pufit](https://github.com/pufit))。
* [#70077](https://github.com/ClickHouse/ClickHouse/issues/70077) でバックポート: [#69752](https://github.com/ClickHouse/ClickHouse/issues/69752) をクローズしました。[#69985](https://github.com/ClickHouse/ClickHouse/pull/69985) ([pufit](https://github.com/pufit))。
* [#70162](https://github.com/ClickHouse/ClickHouse/issues/70162) でバックポート: 範囲内のリテラルを置換する際に誤って発生する LOGICAL&#95;ERROR を修正しました。[#70122](https://github.com/ClickHouse/ClickHouse/pull/70122) ([Pablo Marcos](https://github.com/pamarcos))。
* [#70232](https://github.com/ClickHouse/ClickHouse/issues/70232) でバックポート: ALTER TABLE MODIFY COLUMN/QUERY の実行時に Nullable(Nothing) 型をチェックし、このようなデータ型を持つテーブルが作成されないようにしました。[#70123](https://github.com/ClickHouse/ClickHouse/pull/70123) ([Pavel Kruglov](https://github.com/Avogar))。
* [#70179](https://github.com/ClickHouse/ClickHouse/issues/70179) でバックポート: 解放済みヒープ領域の使用につながる可能性がある、ColumnObject/ColumnTuple の decompress メソッドにおけるデータ競合を修正しました。[#70137](https://github.com/ClickHouse/ClickHouse/pull/70137) ([Pavel Kruglov](https://github.com/Avogar))。
* [#70241](https://github.com/ClickHouse/ClickHouse/issues/70241) でバックポート: bcrypt パスワード認証方式を使用するユーザーについて、`system.query_log` にパスワードが表示される問題を修正しました。[#70148](https://github.com/ClickHouse/ClickHouse/pull/70148) ([Nikolay Degterinsky](https://github.com/evillique))。
