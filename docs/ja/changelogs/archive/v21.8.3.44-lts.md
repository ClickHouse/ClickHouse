<div id="bug-fix">
  #### バグ修正

* [#27545](https://github.com/ClickHouse/ClickHouse/issues/27545) でバックポート: 現在、スカラーサブクエリは、その型が `Nullable` になり得る場合、常に `Nullable` な結果を返します。これは、空のサブクエリでは結果が `Null` になるべきだからです。以前は、互換性のない型に関するエラーが発生する可能性がありました (型推論ではスカラーサブクエリは実行されないため、nullable でない型が使われることがありました) 。空の結果を返し、`Nullable` に変換できないスカラーサブクエリ (`Array` や `Tuple` など) は、エラーを返すようになりました。[#25411](https://github.com/ClickHouse/ClickHouse/issues/25411) を修正しました。[#26423](https://github.com/ClickHouse/ClickHouse/pull/26423) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#26856](https://github.com/ClickHouse/ClickHouse/issues/26856) でバックポート: ParallelFormattingOutputFormat: collector&#95;thread への join を処理するために mutex を使用するようにしました ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)). [#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)).
* [#26941](https://github.com/ClickHouse/ClickHouse/issues/26941) でバックポート: データとメタデータの不整合を防ぐため、ReplicatedMergeTree table のシャットダウン時にデータを削除しないようにしました。[#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* [#26981](https://github.com/ClickHouse/ClickHouse/issues/26981) でバックポート: 一部の集約関数コンビネータを適用した際に aggregate function parameters が失われ、`Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported` のような例外が発生することがありました。この問題を修正しました。[#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) と [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433) を修正しました。[#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#26909](https://github.com/ClickHouse/ClickHouse/issues/26909) でバックポート: library-bridge ids の読み込みを修正しました。[#26834](https://github.com/ClickHouse/ClickHouse/pull/26834) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#26945](https://github.com/ClickHouse/ClickHouse/issues/26945) でバックポート: `DEFAULT` カラムが、`DEFAULT` 式を持たない他の非 materialized カラムを参照している場合に発生する `Missing columns: 'xxx'` エラーを修正しました。[#26591](https://github.com/ClickHouse/ClickHouse/issues/26591) を修正しました。[#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)).
* [#26997](https://github.com/ClickHouse/ClickHouse/issues/26997) でバックポート: カスタム TLD の読み取りを修正しました (buffer が小さい場合や file が大きい場合に processing が停止する問題) 。[#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* [#27030](https://github.com/ClickHouse/ClickHouse/issues/27030) でバックポート: `ALTER TABLE ... PARTITION ID xxx` のようなクエリ内の partition ID について、正当性を検証するようになりました。[#25718](https://github.com/ClickHouse/ClickHouse/issues/25718) を修正しました。[#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
