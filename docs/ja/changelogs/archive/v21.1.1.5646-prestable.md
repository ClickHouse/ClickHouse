  # 2022年の変更履歴

<div id="clickhouse-release-v21115646-prestable-fixme-as-compared-to-v201215236-prestable">
  ### ClickHouse リリース v21.1.1.5646-prestable FIXME (v20.12.1.5236-prestable との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* `toUnixTimestamp(Date())` を禁止しました (以前は単に Date の UInt16 表現を返していました) 。 [#17376](https://github.com/ClickHouse/ClickHouse/pull/17376) ([Azat Khuzhin](https://github.com/azat)).
* 集約関数 `timeSeriesGroupSum`、`timeSeriesGroupRateSum` を削除しました。知人いわく、これらは一度も動作したことがなかったためです。これにより [#16869](https://github.com/ClickHouse/ClickHouse/issues/16869) を修正します。もし幸運にもこれらの関数を使えていた場合は、clickhouse-feedback@yandex-team.com までメールしてください。 [#17423](https://github.com/ClickHouse/ClickHouse/pull/17423) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 設定 `input_format_null_as_default` はデフォルトで有効になりました。 [#17525](https://github.com/ClickHouse/ClickHouse/pull/17525) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `insert_quorum_parallel` のデフォルト値を 1 にしました。これは &quot;sequential&quot; quorum inserts よりも大幅に使いやすいためです。ただし、逐次整合性に依存している場合は、この設定を 0 に戻してください。 [#17567](https://github.com/ClickHouse/ClickHouse/pull/17567) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* データパーツに影響するストレージ設定 (`write_final_mark` および `enable_mixed_granularity_parts`) を変更できないよう、`ALTER MODIFY SETTING` を制限しました。 [#18306](https://github.com/ClickHouse/ClickHouse/pull/18306) ([Amos Bird](https://github.com/amosbird)).
* config 内のプロファイル設定について、設定制約をチェックするようにしました。users.xml に対応する制約を満たさない設定が含まれている場合、サーバーは起動に失敗します。 [#18486](https://github.com/ClickHouse/ClickHouse/pull/18486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `sumburConsistentHash` 関数を削除しました。これにより [#18120](https://github.com/ClickHouse/ClickHouse/issues/18120) をクローズします。 [#18656](https://github.com/ClickHouse/ClickHouse/pull/18656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `DIV` および `MOD` 演算子を追加しました。`DIV` は整数除算を実装します。これは MySQL 互換性および `sqllogictest` のために必要です。これにより [#18707](https://github.com/ClickHouse/ClickHouse/issues/18707) をクローズします。`DIV` または `MOD` をカラム名や別名として使用している場合、非互換が生じる可能性があります。非互換がある場合は、AS キーワードの後に別名を記述するか、識別子を引用符 (二重引用符またはバッククォート) で囲んでください。 [#18760](https://github.com/ClickHouse/ClickHouse/pull/18760) ([Du Chuan](https://github.com/spongedu)).

<div id="new-feature">
  #### 新機能
</div>

* 浮動小数点数の解析に [https://github.com/lemire/fast&#95;float](https://github.com/lemire/fast_float) を使用するようにしました。[#16787](https://github.com/ClickHouse/ClickHouse/pull/16787) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#16819](https://github.com/ClickHouse/ClickHouse/pull/16819) ([pronvis](https://github.com/pronvis)).
* クエリ経由で SimpleAggregateFunction 型を構築するための新しい aggregate combinator `-SimpleState` を追加しました。これは AggregatingMergeTree engine の MaterializedView を定義する際に便利で、projections にも役立ちます。[#16853](https://github.com/ClickHouse/ClickHouse/pull/16853) ([Amos Bird](https://github.com/amosbird)).
* `mannWitneyUTest`、`studentTTest`、`welchTTest` aggregate functions を追加しました。また、RankCorr を少しリファクタリングしました。[#16883](https://github.com/ClickHouse/ClickHouse/pull/16883) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* setting optimize&#95;on&#95;insert を追加しました。有効にすると、INSERT されたデータ block に対して、その block 上で merge が実行された場合と同じ変換を行います (例: Replacing、Collapsing、Aggregating...) 。この setting はデフォルトで有効になります。これは Materialized View と MaterializeMySQL の動作に影響する可能性があります (詳細な説明を参照してください) 。これにより [#10683](https://github.com/ClickHouse/ClickHouse/issues/10683) をクローズします。[#16954](https://github.com/ClickHouse/ClickHouse/pull/16954) ([Kruglov Pavel](https://github.com/Avogar)).
* `*.zst` の圧縮/展開のサポートを追加しました。これにより、`file()` function で `*.zst` を使用でき、http client で `Content-encoding: zstd` を利用できるようになります。これにより [#16791 ](https://github.com/ClickHouse/ClickHouse/issues/16791) をクローズします。[#17144](https://github.com/ClickHouse/ClickHouse/pull/17144) ([Abi Palagashvili](https://github.com/fibersel)).
* * IP Dictionary は `IPv4` / `IPv6` 型をネイティブにサポートします。[#17571](https://github.com/ClickHouse/ClickHouse/pull/17571) ([Vladimir C](https://github.com/vdimir)) 。
* related: [#16176](https://github.com/ClickHouse/ClickHouse/issues/16176) 使用例: `set limit = 10; set offset = 20;` これら 2 つの設定は、`select * from ($your_original_select_query) tmp limit xxx offset xxx;` が追加された場合と同様に SELECT クエリに影響します。 [#17633](https://github.com/ClickHouse/ClickHouse/pull/17633) ([hexiaoting](https://github.com/hexiaoting)).
* MergeTree テーブル内の行数、バイト数、パーツ総数に関する非同期メトリクスを追加しました。これにより [#11714](https://github.com/ClickHouse/ClickHouse/issues/11714) を修正します。 [#17639](https://github.com/ClickHouse/ClickHouse/pull/17639) ([flynn](https://github.com/ucasfl)).
* `DETACH TABLE/VIEW ... PERMANENTLY` 構文を導入し、再起動後にテーブルが自動的に再表示されないようにしました (明示的に要求した場合のみ再表示されます) 。テーブルは引き続き短い構文 ATTACH TABLE で再度アタッチできます。 [#5555](https://github.com/ClickHouse/ClickHouse/issues/5555) を実装しました。 [#13850](https://github.com/ClickHouse/ClickHouse/issues/13850) を修正します。 [#17642](https://github.com/ClickHouse/ClickHouse/pull/17642) ([filimonov](https://github.com/filimonov)).
* DDL worker キュー内のクエリを表示する新しいテーブル `system.distributed_ddl_queue` を追加しました。 [#17656](https://github.com/ClickHouse/ClickHouse/pull/17656) ([Bharat Nallan](https://github.com/bharatnc)).
* 文字列を XML のテキストノードまたは属性に埋め込めるよう、文字をエスケープする関数 `encodeXMLComponent` を追加しました。 [#17659](https://github.com/ClickHouse/ClickHouse/pull/17659) ([nauta](https://github.com/nautaa)).
* clickhouse-client で EDITOR を開いてコマンドを編集できるようになりました。 `Alt-Shift-E`。 [#17665](https://github.com/ClickHouse/ClickHouse/pull/17665) ([Amos Bird](https://github.com/amosbird)).
* native TCP インターフェイスをラップする PROXYv1 プロトコルのサポートを追加しました。quotas で、プロキシ経由で転送された IP アドレスをキーとして使用できるようになりました (PROXYv1 のアドレスと HTTP interface の X-Forwarded-For に適用されます) 。これは、信頼できる proxy (例: CloudFlare) 経由でのみ ClickHouse へのアクセスを提供しつつ、ユーザーリソースを元の IP アドレスごとに集計したい場合に便利です。これにより [#17268](https://github.com/ClickHouse/ClickHouse/issues/17268) を修正します。 [#17707](https://github.com/ClickHouse/ClickHouse/pull/17707) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 関数 `firstSignificantSubdomainCustom`、`cutToFirstSignificantSubdomainCustom` で custom TLD list を使えるようにしました。 [#17748](https://github.com/ClickHouse/ClickHouse/pull/17748) ([Azat Khuzhin](https://github.com/azat)).
* Clickhouse-benchmark にクエリパラメータを追加しました。 [#17832](https://github.com/ClickHouse/ClickHouse/pull/17832) ([Maksim Kita](https://github.com/kitaisreal)).
* `OPTIMIZE ... DEDUPLICATE` 構文を拡張し、重複チェック対象のカラム一覧を明示的に、または asterisk/column transformers によって暗黙的に指定できるようにしました。 ... [#17846](https://github.com/ClickHouse/ClickHouse/pull/17846) ([Vasily Nemkov](https://github.com/Enmk)).
* `min_compress_block_size` と `max_compress_block_size` の設定を MergeTreeSettings に追加しました。これらはグローバル設定よりも優先度が高く、設定されている場合に有効になります。 close [13890](https://github.com/ClickHouse/ClickHouse/issues/13890)。 [#17867](https://github.com/ClickHouse/ClickHouse/pull/17867) ([flynn](https://github.com/ucasfl)).
* `ATTACH TABLE name FROM 'path/to/data/' (col1 Type1, ...` クエリを実装しました。指定した structure で新しいテーブルを作成し、`user_files` 内の指定ディレクトリからテーブルデータをアタッチします。 [#17903](https://github.com/ClickHouse/ClickHouse/pull/17903) ([Alexander Tokmakov](https://github.com/tavplubix)).
* `arrayMin`、`arrayMax`、`arrayAvg` 集約関数を追加しました。 [#18032](https://github.com/ClickHouse/ClickHouse/pull/18032) ([Maksim Kita](https://github.com/kitaisreal)).
* system.settings のパラメータを表示する `SHOW SETTINGS` ステートメントをサポートしました。`SHOW CHANGED SETTINGS` および `LIKE/ILIKE` 句もサポートしています。 [#18056](https://github.com/ClickHouse/ClickHouse/pull/18056) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* カラムを指定した CREATE TABLE AS SELECT を使用できるようにしました。例: `CREATE TABLE t1 (x String) ENGINE = Memory AS SELECT 1;`。 [#18060](https://github.com/ClickHouse/ClickHouse/pull/18060) ([Maksim Kita](https://github.com/kitaisreal)).
* * IP Dictionary がキー取得に対応しました。[#18241](https://github.com/ClickHouse/ClickHouse/issues/18241) を解決しました。[#18480](https://github.com/ClickHouse/ClickHouse/pull/18480) ([Vladimir C](https://github.com/vdimir)).
* `REPLACE TABLE` および `CREATE OR REPLACE TABLE` クエリを実装しました。[#18521](https://github.com/ClickHouse/ClickHouse/pull/18521) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 引数のメモリ上での非圧縮バイトサイズを見積もる関数 `byteSize` を追加しました。たとえば、UInt32 の argument に対しては定数 4 を返し、String argument に対しては文字列長 + 9 を返します。この関数は複数の引数を受け取れます。典型的な用途は `byteSize(*)` です。[#18579](https://github.com/ClickHouse/ClickHouse/pull/18579) ([Ping Yu](https://github.com/pingyu)).
* 挿入されたパーツについて、`system.part_log` に `query_id` カラムを追加しました。[#10097](https://github.com/ClickHouse/ClickHouse/issues/10097) をクローズします。[#18644](https://github.com/ClickHouse/ClickHouse/pull/18644) ([flynn](https://github.com/ucasfl)).
* MergeTree family のテーブル向けに、新しいストレージ設定 `max_partitions_to_read` を追加しました。これにより、1 つのクエリでアクセスできるパーティションの最大数が制限されます。この制約を適用するためのユーザー設定 `force_max_partition_limit` も追加されました。[#18712](https://github.com/ClickHouse/ClickHouse/pull/18712) ([Amos Bird](https://github.com/amosbird)).
* 関数 `position` は、SQL 互換性のため `position(needle in haystack)` 構文をサポートするようになりました。これにより [#18701](https://github.com/ClickHouse/ClickHouse/issues/18701) をクローズします。... [#18779](https://github.com/ClickHouse/ClickHouse/pull/18779) ([Jianmei Zhang](https://github.com/zhangjmruc)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* float のパース性能をわずかに改善しました。[#16809](https://github.com/ClickHouse/ClickHouse/pull/16809) ([Maksim Kita](https://github.com/kitaisreal)).
* 関数 `repeat` の性能を改善しました。[#16937](https://github.com/ClickHouse/ClickHouse/pull/16937) ([satanson](https://github.com/satanson)).
* 非常に多数の `MergeTree` テーブルにまたがる `Merge` テーブルからの読み取り性能を改善しました。[#7748](https://github.com/ClickHouse/ClickHouse/issues/7748) を修正しました。[#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).
* `-If` combinator の devirtualize を行い、`count` を適切にベクトル化しました。これは [https://github.com/ClickHouse/ClickHouse/pull/17041](https://github.com/ClickHouse/ClickHouse/pull/17041) に対応するものです。[#17043](https://github.com/ClickHouse/ClickHouse/pull/17043) ([Amos Bird](https://github.com/amosbird)).
* PK に `SimpleAggregateFunction(String)` を含む AggregatingMergeTree の性能を改善しました。[#17109](https://github.com/ClickHouse/ClickHouse/pull/17109) ([Azat Khuzhin](https://github.com/azat)).
* `remerge_sort_lowered_memory_bytes_ratio` 設定を追加しました (remerge 後の memory usage の減少率がこの比率に達しない場合、remerge は無効化されます) 。[#17539](https://github.com/ClickHouse/ClickHouse/pull/17539) ([Azat Khuzhin](https://github.com/azat)).
* `IPv6CIDRToRange` の実装を高速化しました。[#17569](https://github.com/ClickHouse/ClickHouse/pull/17569) ([Vladimir C](https://github.com/vdimir)).
* float から string への変換に、ryu の代わりに dragonbox algorithm を使用するようにしました。[#17831](https://github.com/ClickHouse/ClickHouse/pull/17831) ([Maksim Kita](https://github.com/kitaisreal)).
* StorageMemory の読み取りを最適化しました。[#18052](https://github.com/ClickHouse/ClickHouse/pull/18052) ([Maksim Kita](https://github.com/kitaisreal)).
* 分散テーブルへの同期 INSERT 時に、空の blocks を分片に送信しないようにしました。これにより [#14571](https://github.com/ClickHouse/ClickHouse/issues/14571) をクローズしました。[#18775](https://github.com/ClickHouse/ClickHouse/pull/18775) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `windowFunnel` 関数の性能改善のため、`AggregateFunctionWindowFunnelData` 内の `PODArray` を `PODArrayWithStackMemory` に置き換えました。[#18817](https://github.com/ClickHouse/ClickHouse/pull/18817) ([flynn](https://github.com/ucasfl)).
* `clickhouse-local` がシステムテーブルなしで実行できるよう、`--no-system-table` オプションを追加しました。これにより、起動時に無視できない時間 (数十 Milliseconds) かかることがある `DateLUT` の初期化を回避できます。[#18899](https://github.com/ClickHouse/ClickHouse/pull/18899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
