  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v21261-stable-fixme-as-compared-to-v21255-stable">
  ### ClickHouse リリース v21.2.6.1-stable FIXME (v21.2.5.5-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#21352](https://github.com/ClickHouse/ClickHouse/issues/21352) でバックポート: scalar subqueries および索引用サブクエリのスレッド数を修正しました ([#19007](https://github.com/ClickHouse/ClickHouse/issues/19007) 以降は常に単一スレッドが使用されていました) 。[#20457](https://github.com/ClickHouse/ClickHouse/issues/20457)、[#20512](https://github.com/ClickHouse/ClickHouse/issues/20512) を修正しました。[#20550](https://github.com/ClickHouse/ClickHouse/pull/20550) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#21262](https://github.com/ClickHouse/ClickHouse/issues/21262) でバックポート: エンジンで別のパラメーター指定が必要な場合、default&#95;replica&#95;path および default&#95;replica&#95;name の値が Replicated(*)MergeTree エンジンでは無意味になっていた問題を修正しました。[#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy)).
* [#21156](https://github.com/ClickHouse/ClickHouse/issues/21156) でバックポート: tuple から map への cast に関する bug を修正しました。[#21029](https://github.com/ClickHouse/ClickHouse/issues/21029) をクローズしました。[#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting)).
* [#21234](https://github.com/ClickHouse/ClickHouse/issues/21234) でバックポート: mutations は、それをサポートする table engines (MergeTree family、Memory、MaterializedView) でのみ許可されるようになりました。その他のエンジンでは、より明確な error が返されます。[#21168](https://github.com/ClickHouse/ClickHouse/issues/21168) を修正しました。[#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin)).
* [#21427](https://github.com/ClickHouse/ClickHouse/issues/21427) でバックポート: `UNION` を含むクエリに対する `EXPLAIN` の crash を修正しました。[#20876](https://github.com/ClickHouse/ClickHouse/issues/20876)、[#21170](https://github.com/ClickHouse/ClickHouse/issues/21170) を修正しました。[#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl)).
* [#21301](https://github.com/ClickHouse/ClickHouse/issues/21301) でバックポート: ZooKeeper への不要な reconnects と、単一の ClickHouse server に対して 2 つの active sessions が発生する可能性を修正しました。どちらの問題も [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678) で導入されました。[#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin)).
* [#21553](https://github.com/ClickHouse/ClickHouse/issues/21553) でバックポート: `ALTER MODIFY COLUMN` クエリが、partition key、skip indices、TTLs などの変更にも正しく反映されるようになりました。[#13675](https://github.com/ClickHouse/ClickHouse/issues/13675) を修正しました。[#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin)).
* [#21380](https://github.com/ClickHouse/ClickHouse/issues/21380) でバックポート: `Values` format から `LowCardinality` カラムを持つ table に inserting する際に発生する error `Bad cast from type ... to DB::ColumnLowCardinality` を修正しました。[#21140](https://github.com/ClickHouse/ClickHouse/issues/21140) を修正しました。[#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
