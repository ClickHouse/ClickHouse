  ### ClickHouse リリース v20.8.5.45-lts FIXME (v20.8.4.11-lts と比較して)
</div>

<div id="improvement">
  #### 改善
</div>

* [#16146](https://github.com/ClickHouse/ClickHouse/issues/16146)でバックポート: クラスター設定の `<internal_replication>` にかかわらず、`ALTER ... ON CLUSTER` クエリを実行できるようになりました。 [#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)).
* [#16310](https://github.com/ClickHouse/ClickHouse/issues/16310)でバックポート: allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards を追加しました (分片キーで rand() や dictGet() などの非決定論的な関数を許可するため) 。 [#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#15620](https://github.com/ClickHouse/ClickHouse/issues/15620)でバックポート: ReplicatedMergeTree に単一のパラメータが渡された場合、それを無視するのではなくエラーを返すようにしました。[#15516](https://github.com/ClickHouse/ClickHouse/pull/15516) ([nvartolomei](https://github.com/nvartolomei)).
* [#16203](https://github.com/ClickHouse/ClickHouse/issues/16203)でバックポート: read-only テーブルを detach する際に `ReadonlyReplica` メトリックをデクリメントするようにしました。これにより [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598) を修正しました。[#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)).
* [#16230](https://github.com/ClickHouse/ClickHouse/issues/16230)でバックポート: S3 table function のグロブに関するバグを修正しました。URL から取得したリージョンが S3 クライアントの設定に適用されていませんでした。[#15646](https://github.com/ClickHouse/ClickHouse/pull/15646) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#15871](https://github.com/ClickHouse/ClickHouse/issues/15871)でバックポート: 宛先テーブルと異なる構造を持つ `Buffer` テーブルの読み取り時に発生していた `Cannot add simple transform to empty Pipe` エラーを修正しました。この問題は、宛先テーブルへのクエリ結果が空だった場合に発生することがありました。[#15529](https://github.com/ClickHouse/ClickHouse/issues/15529) を修正しました。[#15662](https://github.com/ClickHouse/ClickHouse/pull/15662) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#15772](https://github.com/ClickHouse/ClickHouse/issues/15772)でバックポート: `max_replicated_logs_to_keep` setting のデフォルト値が低すぎる問題を修正しました。これにより、レプリカが頻繁に失われる可能性がありました。あわせて、最も新しいレプリカを選んでクローンするようにし、失われたレプリカの復旧プロセスを改善しました。また、失われたレプリカから古いパーツを削除せず、detach するようにしました。[#15701](https://github.com/ClickHouse/ClickHouse/pull/15701) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#15738](https://github.com/ClickHouse/ClickHouse/issues/15738)でバックポート: `MV` のクエリに `ARRAY JOIN` が含まれている場合に、`MATERIALIZED VIEW` への insert 時に発生することがあった `Cannot find column` エラーを修正しました。[#15717](https://github.com/ClickHouse/ClickHouse/pull/15717) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#15795](https://github.com/ClickHouse/ClickHouse/issues/15795)でバックポート: 仮想カラムのみを選択する一部のクエリを修正しました。以前は `Not found column _nothing in block` 例外が発生することがありました。[#12298](https://github.com/ClickHouse/ClickHouse/issues/12298) を修正しました。[#15756](https://github.com/ClickHouse/ClickHouse/pull/15756) ([Anton Popov](https://github.com/CurtizJ)).
* [#15900](https://github.com/ClickHouse/ClickHouse/issues/15900)でバックポート: `ALTER MODIFY COLUMN` クエリの後に実行された `SELECT ... ORDER BY DESC` クエリで発生していた `Block structure mismatch` 例外を修正しました。[#15800](https://github.com/ClickHouse/ClickHouse/issues/15800) を修正しました。[#15852](https://github.com/ClickHouse/ClickHouse/pull/15852) ([alesapin](https://github.com/alesapin)).
* [#15925](https://github.com/ClickHouse/ClickHouse/issues/15925)でバックポート: `ALTER MODIFY COLUMN ... DEFAULT ...` のデフォルト値がカラム型と互換性がない場合に、例外をスローするようになりました。[#15854](https://github.com/ClickHouse/ClickHouse/issues/15854) を修正しました。[#15858](https://github.com/ClickHouse/ClickHouse/pull/15858) ([alesapin](https://github.com/alesapin)).
* [#15920](https://github.com/ClickHouse/ClickHouse/issues/15920)でバックポート: RBAC で発生する可能性のあるデッドロックを修正しました。[#15875](https://github.com/ClickHouse/ClickHouse/pull/15875) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#16168](https://github.com/ClickHouse/ClickHouse/issues/16168) でバックポート: クエリに `WHERE`、`PREWHERE`、`GLOBAL IN` が含まれる場合に、`Distributed` table に対するクエリで誤って空の結果が返される問題を修正しました。[#15792](https://github.com/ClickHouse/ClickHouse/issues/15792) を修正します。[#15933](https://github.com/ClickHouse/ClickHouse/pull/15933) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#16355](https://github.com/ClickHouse/ClickHouse/issues/16355) でバックポート: table が同時にリネームされた場合に `Table ... doesn't exist` エラーで `DROP TABLE IF EXISTS` が失敗する問題を修正しました (atomic データベースエンジン向け) 。複数の table を対象とする一部の DDL queries (`DROP DATABASE` や `RENAME TABLE` など) を同時実行した際に発生する、まれなデッドロックを修正しました。`DROP/DETACH TABLE` を同時実行した場合に `Table ... doesn't exist` により `DROP/DETACH DATABASE` が失敗する問題を修正しました。[#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#15968](https://github.com/ClickHouse/ClickHouse/issues/15968) でバックポート: database の作成失敗時に発生する crash を修正しました。[#15954](https://github.com/ClickHouse/ClickHouse/pull/15954) ([Winter Zhang](https://github.com/zhang2014)).
* [#16025](https://github.com/ClickHouse/ClickHouse/issues/16025) でバックポート: settings profiles のパースにおける曖昧さを修正しました。`CREATE USER ... SETTINGS profile readonly` は、readonly 制約付きの `profile` という setting 名ではなく、`readonly` という名前の profile を使用するものとして扱われるようになりました。これにより [#15628](https://github.com/ClickHouse/ClickHouse/issues/15628) を修正します。[#15982](https://github.com/ClickHouse/ClickHouse/pull/15982) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#16219](https://github.com/ClickHouse/ClickHouse/issues/16219) でバックポート: MaterializedView への insert または MaterializedView からの select と、ターゲットテーブルの dropping を同時に行った際に発生する、まれな segfault を修正しました (atomic データベースエンジン向け) 。[#15984](https://github.com/ClickHouse/ClickHouse/pull/15984) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#16029](https://github.com/ClickHouse/ClickHouse/issues/16029) でバックポート: 一定期間非アクティブな状態が続いた後にレプリケーション error が発生した際、レプリカが 5〜10 分間ハングするのを防止します。[#15987](https://github.com/ClickHouse/ClickHouse/pull/15987) ([filimonov](https://github.com/filimonov)).
* [#16088](https://github.com/ClickHouse/ClickHouse/issues/16088) でバックポート: complex key を持つ Dictionaries で direct layout を使用できるようにしました。[#16007](https://github.com/ClickHouse/ClickHouse/pull/16007) ([Anton Popov](https://github.com/CurtizJ)).
* [#16360](https://github.com/ClickHouse/ClickHouse/issues/16360) でバックポート: collate 名と charset 名のパーサーを修正し、string type で `length = 0` をサポートしました。[#16008](https://github.com/ClickHouse/ClickHouse/pull/16008) ([Winter Zhang](https://github.com/zhang2014)).
* [#16141](https://github.com/ClickHouse/ClickHouse/issues/16141) でバックポート: `ReplicatedVersionedCollapsingMergeTree` における `ALTER MODIFY ... ORDER BY` クエリのハングを修正しました。これにより [#15980](https://github.com/ClickHouse/ClickHouse/issues/15980) を修正します。[#16011](https://github.com/ClickHouse/ClickHouse/pull/16011) ([alesapin](https://github.com/alesapin)).
* [#16078](https://github.com/ClickHouse/ClickHouse/issues/16078) でバックポート: [#15780](https://github.com/ClickHouse/ClickHouse/issues/15780) のリグレッションを修正しました。たとえば、indexOf([1, 2, 3], toLowCardinality(1)) は現在禁止されていますが、本来は禁止されるべきではありません。[#16038](https://github.com/ClickHouse/ClickHouse/pull/16038) ([Mike Kot](https://github.com/myrrc)).
* [#16294](https://github.com/ClickHouse/ClickHouse/issues/16294)でバックポート: sharding&#95;key 内の dictGet (および同様の箇所、つまり関数の Context が永続的に保持される場合) を修正しました。[#16205](https://github.com/ClickHouse/ClickHouse/pull/16205) ([Azat Khuzhin](https://github.com/azat)).
* [#16233](https://github.com/ClickHouse/ClickHouse/issues/16233)でバックポート: 制限に関係なくメモリが過剰に割り当てられる場合がある問題を修正しました。これにより [#14560](https://github.com/ClickHouse/ClickHouse/issues/14560) をクローズします。[#16206](https://github.com/ClickHouse/ClickHouse/pull/16206) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#16325](https://github.com/ClickHouse/ClickHouse/issues/16325)でバックポート: 文字列キーを使った `GROUP BY` で、`TwoLevelStringHashTable` 実装の不具合により発生する可能性があったメモリリークを修正しました。[#16264](https://github.com/ClickHouse/ClickHouse/pull/16264) ([Amos Bird](https://github.com/amosbird)).
* [#16375](https://github.com/ClickHouse/ClickHouse/issues/16375)でバックポート: prefer&#95;localhost&#95;replica=0 および internal&#95;replication 使用時の非同期 Distributed INSERT を修正しました。[#16358](https://github.com/ClickHouse/ClickHouse/pull/16358) ([Azat Khuzhin](https://github.com/azat)).
* [#16431](https://github.com/ClickHouse/ClickHouse/issues/16431)でバックポート: totals/ロールアップ/cube 修飾子を使った GROUP BY と、GROUP BY キーに対する min/max 関数の問題を修正しました。[#16393](https://github.com/ClickHouse/ClickHouse/issues/16393) を修正します。[#16397](https://github.com/ClickHouse/ClickHouse/pull/16397) ([Anton Popov](https://github.com/CurtizJ)).
* [#16450](https://github.com/ClickHouse/ClickHouse/issues/16450)でバックポート: 関数 `dictGet` で例外が発生した場合の二重解放を修正しました。これは Dictionary の読み込み時にエラーが発生した場合に起こる可能性がありました。[#16429](https://github.com/ClickHouse/ClickHouse/pull/16429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
