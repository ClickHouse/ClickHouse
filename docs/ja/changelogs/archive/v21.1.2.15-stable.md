  # 2022年の変更履歴

<div id="clickhouse-release-v211215-stable-fixme-as-compared-to-v21115646-prestable">
  ### ClickHouse リリース v21.1.2.15-安定版 FIXME (v21.1.1.5646-prestable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#19148](https://github.com/ClickHouse/ClickHouse/issues/19148) でバックポート: clickhouse-server イメージで、clickhouse ユーザーおよびグループの uid / gid を固定値 (101) に明示的に設定しました。 [#19096](https://github.com/ClickHouse/ClickHouse/pull/19096) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#19203](https://github.com/ClickHouse/ClickHouse/issues/19203) でバックポート: `table` から any カラムを 1 つだけ選択できる場合に、`SELECT count() FROM table` を実行できるようになりました。この PR は [#10639](https://github.com/ClickHouse/ClickHouse/issues/10639) を修正します。[#18233](https://github.com/ClickHouse/ClickHouse/pull/18233) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#19161](https://github.com/ClickHouse/ClickHouse/issues/19161) でバックポート: 定数引数を持つ二項関数の索引解析により、誤ったクエリ結果につながる問題を修正しました。これにより [#18364](https://github.com/ClickHouse/ClickHouse/issues/18364) を修正します。[#18373](https://github.com/ClickHouse/ClickHouse/pull/18373) ([Amos Bird](https://github.com/amosbird))。
* [#18948](https://github.com/ClickHouse/ClickHouse/issues/18948) でバックポート: `Nullable(String)` から `Nullable(Decimal(P, S))` へ `NULL` を `CAST` しようとした際に発生する `Attempt to read after eof` エラーを修正しました。これにより、nullable string から decimal をパースできない場合、関数 `CAST` は `NULL` を返すようになりました。[#7690](https://github.com/ClickHouse/ClickHouse/issues/7690) を修正します。[#18718](https://github.com/ClickHouse/ClickHouse/pull/18718) ([Winter Zhang](https://github.com/zhang2014))。
* [#18934](https://github.com/ClickHouse/ClickHouse/issues/18934) でバックポート: nullptr の逆参照を引き起こす可能性がある `bitmapOrCardinality` の問題を修正しました。これにより [#18911](https://github.com/ClickHouse/ClickHouse/issues/18911) をクローズします。[#18912](https://github.com/ClickHouse/ClickHouse/pull/18912) ([sundyli](https://github.com/sundy-li))。
* [#19115](https://github.com/ClickHouse/ClickHouse/issues/19115) でバックポート: パーティションの Attach 時には mutation をリセットするようにしました。[#18804](https://github.com/ClickHouse/ClickHouse/issues/18804)。[#18935](https://github.com/ClickHouse/ClickHouse/pull/18935) ([fastio](https://github.com/fastio))。
* [#18966](https://github.com/ClickHouse/ClickHouse/issues/18966) でバックポート: エスケープされたテキスト (例: `ALTER ... UPDATE e = CAST('foo', 'Enum8(\'foo\' = 1')`) を含む mutation が誤って serialize される bug を修正しました。[#18878](https://github.com/ClickHouse/ClickHouse/issues/18878) を修正します。[#18944](https://github.com/ClickHouse/ClickHouse/pull/18944) ([alesapin](https://github.com/alesapin))。
* [#19005](https://github.com/ClickHouse/ClickHouse/issues/19005) でバックポート: エラー `Task was not found in task queue` を修正しました (`async_socket_for_remote = 1` の場合のリモートクエリでのみ発生する可能性があります) 。[#18964](https://github.com/ClickHouse/ClickHouse/pull/18964) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#19009](https://github.com/ClickHouse/ClickHouse/issues/19009) でバックポート: `ALTER TABLE ... DROP PART 'part_name'` クエリによって、パーティション全体のすべての重複排除ブロックが削除されてしまう不正な動作を修正しました。[#18874](https://github.com/ClickHouse/ClickHouse/issues/18874) を修正します。[#18969](https://github.com/ClickHouse/ClickHouse/pull/18969) ([alesapin](https://github.com/alesapin))。
* [#19193](https://github.com/ClickHouse/ClickHouse/issues/19193) でバックポート: シャットダウン時にごくまれに発生するデッドロックを修正しました。[#18977](https://github.com/ClickHouse/ClickHouse/pull/18977) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#19004](https://github.com/ClickHouse/ClickHouse/issues/19004) でバックポート: クエリプランの `Expression` ステップのマージによって発生する可能性がある例外 `QueryPipeline stream: different number of columns` を修正しました。[#18190](https://github.com/ClickHouse/ClickHouse/issues/18190) を修正します。[#18980](https://github.com/ClickHouse/ClickHouse/pull/18980) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#19045](https://github.com/ClickHouse/ClickHouse/issues/19045)でバックポート: 最適化が常に正しいとは限らないため、`optimize_move_functions_out_of_any` を無効化しました。これにより [#18051](https://github.com/ClickHouse/ClickHouse/issues/18051) をクローズします。これにより [#18973](https://github.com/ClickHouse/ClickHouse/issues/18973) をクローズします。[#18981](https://github.com/ClickHouse/ClickHouse/pull/18981) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#19070](https://github.com/ClickHouse/ClickHouse/issues/19070)でバックポート: Join は const カラムを materialize しようとしますが、コードの他の箇所ではそれらが materialize されていることを前提にしています。[#18982](https://github.com/ClickHouse/ClickHouse/pull/18982) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#19053](https://github.com/ClickHouse/ClickHouse/issues/19053)でバックポート: `TinyLog` engine を使用する table への `LowCardinality` カラムの挿入に関する問題を修正しました。[#18629](https://github.com/ClickHouse/ClickHouse/issues/18629) を修正します。[#19010](https://github.com/ClickHouse/ClickHouse/pull/19010) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#19081](https://github.com/ClickHouse/ClickHouse/issues/19081)でバックポート: `LowCardinality` 引数で関数 `ignore` を使用した場合に、`Expected single dictionary argument for function` エラーが発生する可能性がある問題を修正しました。[#14275](https://github.com/ClickHouse/ClickHouse/issues/14275) を修正します。[#19016](https://github.com/ClickHouse/ClickHouse/pull/19016) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#19046](https://github.com/ClickHouse/ClickHouse/issues/19046)でバックポート: `groupUniqArray` が Enum 型の引数に対して正しい型を返すようにしました。これにより [#17875](https://github.com/ClickHouse/ClickHouse/issues/17875) をクローズします。[#19019](https://github.com/ClickHouse/ClickHouse/pull/19019) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#19126](https://github.com/ClickHouse/ClickHouse/issues/19126)でバックポート: 古い構文で作成された `MergeTree` table に対する `MODIFY TTL` クエリを制限しました。以前はこのクエリは成功していましたが、実際には効果がありませんでした。[#19064](https://github.com/ClickHouse/ClickHouse/pull/19064) ([Anton Popov](https://github.com/CurtizJ)).
* [#19121](https://github.com/ClickHouse/ClickHouse/issues/19121)でバックポート: `tupleHammingDistance` の実装を簡略化しました。同じ長さの tuples であれば任意のものをサポートします。[#19029](https://github.com/ClickHouse/ClickHouse/issues/19029) を修正します。[#19084](https://github.com/ClickHouse/ClickHouse/pull/19084) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#19150](https://github.com/ClickHouse/ClickHouse/issues/19150)でバックポート: 起動時のバグを修正しました。このバグにより、ClickHouse が `LowCardinality(Nullable(...))` から compression codec を読み取れず、`Attempt to read after EOF` 例外をスローしていました。[#18340](https://github.com/ClickHouse/ClickHouse/issues/18340) を修正します。[#19101](https://github.com/ClickHouse/ClickHouse/pull/19101) ([alesapin](https://github.com/alesapin)).
* [#19177](https://github.com/ClickHouse/ClickHouse/issues/19177)でバックポート: MergeTree data writer のバグを修正しました。このバグにより、fixed granularity size より大きいサイズの marks が生成される可能性がありました。[#18913](https://github.com/ClickHouse/ClickHouse/issues/18913) を修正します。[#19123](https://github.com/ClickHouse/ClickHouse/pull/19123) ([alesapin](https://github.com/alesapin)).
* [#19179](https://github.com/ClickHouse/ClickHouse/issues/19179)でバックポート: `ORC` フォーマットのファイルを無限に読み続けてしまう問題を修正 (これは [#10580](https://github.com/ClickHouse/ClickHouse/issues/10580) で導入されたものです) 。[#19095](https://github.com/ClickHouse/ClickHouse/issues/19095) を修正。[#19134](https://github.com/ClickHouse/ClickHouse/pull/19134) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#19178](https://github.com/ClickHouse/ClickHouse/issues/19178)でバックポート: - RemoteQueryExecutorReadContext をモジュール部分に分割 - `async_socket_for_remote` のパイプ fd のリークを修正。[#19153](https://github.com/ClickHouse/ClickHouse/pull/19153) ([Azat Khuzhin](https://github.com/azat)).
