<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* [#43484](https://github.com/ClickHouse/ClickHouse/issues/43484)でバックポート: `String` 引数を持つ `min`、`max`、`any*`、`argMin`、`argMax` 集約関数の state のシリアライゼーション／デシリアライゼーションにおける後方互換性の問題を修正しました。この非互換性は [https://github.com/ClickHouse/ClickHouse/pull/41431](https://github.com/ClickHouse/ClickHouse/pull/41431) で導入され、22.9、22.10、22.11 の分岐に影響します (それぞれ 22.9.6、22.10.4、22.11.2 以降で修正済み) 。22.3、22.7、22.8 の分岐の一部のマイナーリリースにも影響があります: 22.3.13...22.3.14 (22.3.15 以降で修正済み) 、22.8.6...22.8.9 (22.8.10 以降で修正済み) 、22.7.6 以降 (22.7 では修正されないため、22.7.* から 22.8.10 以降へのアップグレードを推奨します) 。このリリースノートは、影響を受けるバージョンを一度も使用したことがないユーザーには関係ありません。非互換バージョンでは、上記の集約関数の state を読み取る際に、文字列の末尾へ余分な `'\0'` が追加されます。たとえば、古いバージョンが `anyState('foobar')` の state を `state_column` に保存していた場合、非互換バージョンでは `anyMerge(state_column)` の結果として `'foobar\0'` が出力されます。また、非互換バージョンは、これらの集約関数の state を末尾の `'\0'` なしで書き込みます。新しいバージョン (この修正を含むもの) は、1 つの特殊なケースを除き、非互換バージョンを含むすべてのバージョンによって書き込まれた data を正しく読み取れます。非互換バージョンが、実際に null 文字で終わる文字列を含む state を保存した場合、新しいバージョンは影響を受ける集約関数の state を読み取る際に、末尾の `'\0'` を取り除いてしまいます。たとえば、非互換バージョンが `anyState('abrac\0dabra\0')` の state を `state_column` に保存していた場合、非互換バージョンでは `anyMerge(state_column)` の結果として `'abrac\0dabra'` が出力されます。この issue は、非互換バージョンが古いバージョンまたは新しいバージョンと同じクラスター内で動作している場合の distributed queries にも影響します。[#43038](https://github.com/ClickHouse/ClickHouse/pull/43038) ([Raúl Marín](https://github.com/Algunenano)).

<div id="improvement">
  #### 改善
</div>

* [#42839](https://github.com/ClickHouse/ClickHouse/issues/42839) でバックポート: tzdata を 2022f に更新しました。メキシコでは、米国との国境付近を除き、今後は夏時間を実施しなくなります: [https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html)。チワワ州は 2022-10-30 に通年 UTC-6 に移行します。フィジーでも今後は夏時間を実施しなくなります。[https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) および [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209) を参照してください。[#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#43050](https://github.com/ClickHouse/ClickHouse/issues/43050) でバックポート: 結合テストでファイルをアーカイブする前に、すべてのファイルの同期が完了するまで待機するようにしました。[#42891](https://github.com/ClickHouse/ClickHouse/pull/42891) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#42963](https://github.com/ClickHouse/ClickHouse/issues/42963) でバックポート: 修正前は、ユーザー定義の config は RPM によって `$file.rpmsave` に保存されていました。この PR でそれを修正し、パッケージ内のファイルでユーザーのファイルを置き換えないようにしました。[#42936](https://github.com/ClickHouse/ClickHouse/pull/42936) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#43039](https://github.com/ClickHouse/ClickHouse/issues/43039) でバックポート: コミットをリリース準備完了としてマークするための CI ステップを追加しました。また、master 以外の分岐からリリーススクリプトを起動することを緩やかに禁止しました。[#43017](https://github.com/ClickHouse/ClickHouse/pull/43017) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

* [#43427](https://github.com/ClickHouse/ClickHouse/issues/43427) でバックポート: `Merge` engine を使用するテーブルに対する、PREWHERE最適化が有効な `SAMPLE BY` クエリの不具合を修正しました。 [#43315](https://github.com/ClickHouse/ClickHouse/pull/43315) ([Antonio Andelic](https://github.com/antonio2368)).
* [#43720](https://github.com/ClickHouse/ClickHouse/issues/43720) でバックポート: `toString(enum)` を含む条件での主キーの解析に関する不具合を修正しました。 [#43596](https://github.com/ClickHouse/ClickHouse/pull/43596) ([Nikita Taranov](https://github.com/nickitat)).
