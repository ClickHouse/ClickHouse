<div id="clickhouse-release-v213314-lts-fixme-as-compared-to-v21325-lts">
  ### ClickHouse リリース v21.3.3.14-lts FIXME (v21.3.2.5-lts との比較)

<div id="bug-fix">
  #### バグ修正
</div>

* [#21644](https://github.com/ClickHouse/ClickHouse/issues/21644)でバックポート: config 更新後も S3 テーブルが古い認証情報を保持したままになる問題を修正しました。[#21457](https://github.com/ClickHouse/ClickHouse/pull/21457) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* [#21854](https://github.com/ClickHouse/ClickHouse/issues/21854)でバックポート: `optimize_skip_unused_shards` が有効で、使用される分片が 0 の場合に発生しうる ` Cannot find column` エラーを修正しました。[#21579](https://github.com/ClickHouse/ClickHouse/pull/21579) ([Azat Khuzhin](https://github.com/azat)).
* [#21687](https://github.com/ClickHouse/ClickHouse/issues/21687)でバックポート: 水平マージ時の fsync&#95;part&#95;directory を修正しました。[#21642](https://github.com/ClickHouse/ClickHouse/pull/21642) ([Azat Khuzhin](https://github.com/azat)).
* [#21796](https://github.com/ClickHouse/ClickHouse/issues/21796)でバックポート: `async_socket_for_remote=1` での分散リクエストのキャンセル処理 (たとえば、limit 付きで複数の分片に対して単純な select を行う場合、つまり `select * from remote('127.{2,3}', system.numbers) limit 100`) を修正しました。[#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* [#21811](https://github.com/ClickHouse/ClickHouse/issues/21811)でバックポート: `ALTER MODIFY COLUMN` クエリで Decimal カラムのサイズ (32 ビットまたは 64 ビット) が変わらない場合に型が変更されない ReplicatedMerge テーブルエンジンのバグを修正しました。[#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* [#21883](https://github.com/ClickHouse/ClickHouse/issues/21883)でバックポート: S3 接続プールを元に戻しました。[#21737](https://github.com/ClickHouse/ClickHouse/pull/21737) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#21874](https://github.com/ClickHouse/ClickHouse/issues/21874)でバックポート: `WHERE` または `HAVING` 条件が `GROUP BY` より前にプッシュされた場合に発生しうる、誤ったクエリ結果 (およびクラッシュの可能性) を修正しました。[#21773](https://github.com/ClickHouse/ClickHouse/issues/21773) を修正。[#21841](https://github.com/ClickHouse/ClickHouse/pull/21841) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
