  ### ClickHouse リリース v20.8.15.11-lts FIXME (v20.8.14.4-lts との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#21627](https://github.com/ClickHouse/ClickHouse/issues/21627)でバックポート: max&#95;distributed&#95;connections を修正 (`prefer_localhost_replica=1` および `max_threads!=max_distributed_connections` に影響)。 [#17848](https://github.com/ClickHouse/ClickHouse/pull/17848) ([Azat Khuzhin](https://github.com/azat)).
* [#21626](https://github.com/ClickHouse/ClickHouse/issues/21626)でバックポート: Join が const カラムを materialize しようとする一方で、コードの別の箇所ではそれらを待機してしまう問題を修正。 [#18982](https://github.com/ClickHouse/ClickHouse/pull/18982) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#21409](https://github.com/ClickHouse/ClickHouse/issues/21409)でバックポート: mutations は、それをサポートするテーブルエンジン (MergeTree family、Memory、MaterializedView) でのみ許可されるようになりました。その他のエンジンでは、より明確なエラーが返されます。[#21168](https://github.com/ClickHouse/ClickHouse/issues/21168) を修正。 [#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin)).
* [#22190](https://github.com/ClickHouse/ClickHouse/issues/22190)でバックポート: Poco の SecureSocket 内の SSL object における race condition を修正。 [#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#21547](https://github.com/ClickHouse/ClickHouse/issues/21547)でバックポート: predicate にテーブル自身が含まれる場合、レプリケートされていない MergeTree テーブルエンジンの `ALTER DELETE` mutations で発生するデッドロックを修正。[#20558](https://github.com/ClickHouse/ClickHouse/issues/20558) を修正。 [#21477](https://github.com/ClickHouse/ClickHouse/pull/21477) ([alesapin](https://github.com/alesapin)).
* [#22284](https://github.com/ClickHouse/ClickHouse/issues/22284)でバックポート: `ALTER MODIFY COLUMN` クエリで Decimal カラムのサイズ (32 bit または 64 bit) が変わらない場合に型が変更されない、ReplicatedMerge テーブルエンジンのバグを修正。 [#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* [#22282](https://github.com/ClickHouse/ClickHouse/issues/22282)でバックポート: Docker entrypoint: `LOG_PATH` が空の場合に `.` への chown を回避。[#22100](https://github.com/ClickHouse/ClickHouse/issues/22100) をクローズ。 [#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* [#22279](https://github.com/ClickHouse/ClickHouse/issues/22279)でバックポート: `ReplicatedMergeTree` テーブルエンジンに対する `OPTIMIZE` および `ALTER` クエリの待機処理を修正。これにより、テーブルがデタッチされた場合や再起動された場合でもクエリがハングしなくなります。 [#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* [#22370](https://github.com/ClickHouse/ClickHouse/issues/22370)でバックポート: すでに対象範囲に含まれている part を mutate しようとした際に、ClickHouse が `LOGICAL_ERROR` exception を throw しないようになりました。[#22013](https://github.com/ClickHouse/ClickHouse/issues/22013) を修正。 [#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
