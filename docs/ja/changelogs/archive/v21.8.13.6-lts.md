<div id="bug-fix">
  #### バグ修正
</div>

* [#32688](https://github.com/ClickHouse/ClickHouse/issues/32688)でバックポート: クォータの上限には達していないのに、上限を超過したと判定される問題を修正しました。このPRで [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174) を修正しています。[#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).
* [#32343](https://github.com/ClickHouse/ClickHouse/issues/32343)でバックポート: サブクエリ内で不要なカラムを削除する際のバグを修正しました。GROUP BY のないクエリに集約関数がある場合、不要に見えても削除しません。[#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

#### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)

* [#32108](https://github.com/ClickHouse/ClickHouse/issues/32108)でバックポート: odbc クエリで結果が空の場合にクラッシュする問題を修正しました。[#31465](https://github.com/ClickHouse/ClickHouse/issues/31465)をクローズします。[#31766](https://github.com/ClickHouse/ClickHouse/pull/31766) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32150](https://github.com/ClickHouse/ClickHouse/issues/32150)でバックポート: 型を指定した関数 `dictGet` を Dictionary 属性に対して使用し、その型が `Nullable` の場合にクラッシュする問題を修正しました。[#30980](https://github.com/ClickHouse/ClickHouse/issues/30980)を修正します。[#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32075](https://github.com/ClickHouse/ClickHouse/issues/32075)でバックポート: Decimal 引数を持つ関数 transform に関する不具合を修正しました。[#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* [#31955](https://github.com/ClickHouse/ClickHouse/issues/31955)でバックポート: - `KeeperTCPHandler` の構築時に、設定パスを `keeper_server.session_timeout_ms` から `keeper_server.coordination_settings.session_timeout_ms` に変更 - `operation_timeout` についても同様に変更。[#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* [#32161](https://github.com/ClickHouse/ClickHouse/issues/32161)でバックポート: すべてのレプリカでパーツが失われ、同じパーティション内にほかのパーツがない場合、一部の `GET_PART` エントリがレプリケーションキュー内で停止することがありました。パーティションキーが整数型のカラムのみ、または `Date[Time]` のみを含むケースで修正しました。[#31485](https://github.com/ClickHouse/ClickHouse/issues/31485)を修正します。[#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32146](https://github.com/ClickHouse/ClickHouse/issues/32146)でバックポート: パーツの detach 時に `Directory ... already exists and is not empty` エラーが発生する問題を修正しました。[#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32213](https://github.com/ClickHouse/ClickHouse/issues/32213)でバックポート: 一部のレプリカで設定 `replicated_can_become_leader` が無効になっている場合、クォーラム付きで insert するとアクティブなレプリカ数が誤って判定されることがありました。この問題を修正しました。[#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32312](https://github.com/ClickHouse/ClickHouse/issues/32312)でバックポート: table create クエリで使用される XML dictionaries identifiers が、新しいバージョンへのアップグレード時に `default_database` で修飾されることがあります。[#31963](https://github.com/ClickHouse/ClickHouse/issues/31963)をクローズします。[#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* [#32540](https://github.com/ClickHouse/ClickHouse/issues/32540)でバックポート: 一部のレプリケーションキューのエントリが、`Directory tmp_merge_<part_name>` や `Part ... (state Deleting) already exists, but it will be deleted soon` などのエラー、または類似のエラーにより、`temporary_directories_lifetime` (デフォルトでは 1 日) の間停止することがありました。この問題を修正しました。[#29616](https://github.com/ClickHouse/ClickHouse/issues/29616)を修正します。[#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#32353](https://github.com/ClickHouse/ClickHouse/issues/32353)でバックポート: `Decimal` 引数を持つ aggregate function `avgWeighted` で、SIGFPE によりクラッシュする問題を修正しました。[#32053](https://github.com/ClickHouse/ClickHouse/issues/32053)を修正します。[#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#33048](https://github.com/ClickHouse/ClickHouse/issues/33048)でバックポート: チャネルの作成を遅らせることで、RabbitMQ Storage の起動時に発生する可能性がある例外を修正。 [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#32795](https://github.com/ClickHouse/ClickHouse/issues/32795)でバックポート: 同じ FixedString を複数回使って fuzzBits を使用した際に発生するクラッシュを修正し、[#32737](https://github.com/ClickHouse/ClickHouse/issues/32737) をクローズ。 [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
