<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#54583](https://github.com/ClickHouse/ClickHouse/issues/54583)でバックポート: Replicated MergeTree でまれに発生し、ログに自己回復する `CHECKSUM_DOESNT_MATCH` エラーを引き起こす可能性がある不具合を修正しました。[#54549](https://github.com/ClickHouse/ClickHouse/pull/54549) ([alesapin](https://github.com/alesapin)).
* [#56253](https://github.com/ClickHouse/ClickHouse/issues/56253)でバックポート: alternation を含む pattern で match() 関数 (regex) を使用した場合に、誤った key condition が生成される不具合を修正しました。[#54696](https://github.com/ClickHouse/ClickHouse/pull/54696) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#56322](https://github.com/ClickHouse/ClickHouse/issues/56322)でバックポート: 起動時のテーブル読み込み中に発生するクラッシュを修正しました。[#55767](https://github.com/ClickHouse/ClickHouse/issues/55767) をクローズします。[#56232](https://github.com/ClickHouse/ClickHouse/pull/56232) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#56292](https://github.com/ClickHouse/ClickHouse/issues/56292)でバックポート: Keeper のシグナルハンドラーにおける segfault を修正しました。[#56266](https://github.com/ClickHouse/ClickHouse/pull/56266) ([Antonio Andelic](https://github.com/antonio2368)).
* [#56443](https://github.com/ClickHouse/ClickHouse/issues/56443)でバックポート: `T64` codec を使用して不正なデータを伸張する際に発生するバッファオーバーフローによるクラッシュを修正しました。この issue は [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) を通じて [https://twitter.com/malacupa](https://twitter.com/malacupa) により発見されました。[#56434](https://github.com/ClickHouse/ClickHouse/pull/56434) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
