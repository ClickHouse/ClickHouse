<div id="clickhouse-release-v216862-stable-fixme-as-compared-to-v216757-stable">

<div id="bug-fix">
  #### バグ修正
</div>

* [#26194](https://github.com/ClickHouse/ClickHouse/issues/26194) でバックポート: remote() で、関数なしのカラムから `sharding_key` を設定した場合の不具合を修正しました (以前は `select * from remote('127.1', system.one, dummy)` で `Unknown column: dummy, there are only columns .` error が発生していました) 。 [#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* [#26108](https://github.com/ClickHouse/ClickHouse/issues/26108) でバックポート: ZooKeeper client 内の `abort` が原因でまれに発生していた server crash を修正しました。これにより [#25813](https://github.com/ClickHouse/ClickHouse/issues/25813) も修正されます。 [#26079](https://github.com/ClickHouse/ClickHouse/pull/26079) ([alesapin](https://github.com/alesapin)).
* [#26167](https://github.com/ClickHouse/ClickHouse/issues/26167) でバックポート: LowCarinality カラムでの `joinGet` の不具合を修正し、[#25993](https://github.com/ClickHouse/ClickHouse/issues/25993) をクローズします。 [#26118](https://github.com/ClickHouse/ClickHouse/pull/26118) ([Vladimir C](https://github.com/vdimir)).
* [#26205](https://github.com/ClickHouse/ClickHouse/issues/26205) でバックポート: `untuple` expression を複数使用した場合に発生しうる crash を修正しました。 [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#26227](https://github.com/ClickHouse/ClickHouse/issues/26227) でバックポート: `system.stack_trace` table の `thread_name` カラムに含まれる余分な改行を削除しました。これにより [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124) も修正されます。 [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
