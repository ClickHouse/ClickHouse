  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v213172-lts-fixme-as-compared-to-v213165-lts">
  ### ClickHouse リリース v21.3.17.2-lts FIXME (v21.3.16.5-lts との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#28647](https://github.com/ClickHouse/ClickHouse/issues/28647) でバックポート: エラー `Unexpected merged part intersects drop range` を引き起こすことがある、`DROP PART` のまれなバグを修正しました。[#27807](https://github.com/ClickHouse/ClickHouse/pull/27807) ([alesapin](https://github.com/alesapin)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#28569](https://github.com/ClickHouse/ClickHouse/issues/28569) でバックポート: `ReplicatedVersionedCollapsingMergeTree` の ALTER 後に、エラー `Existing table metadata in ZooKeeper differs in sorting key expression.` が発生する可能性のあるバグを修正しました。[#28515](https://github.com/ClickHouse/ClickHouse/issues/28515) を修正します。[#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin))。
* [#28857](https://github.com/ClickHouse/ClickHouse/issues/28857) でバックポート: ReplicatedMergeTreeQueue の軽微なレースコンディションを修正しました。通常はユーザーに見えるものではありませんが、気付きにくいバグにつながる可能性があります。[#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin))。
* [#28995](https://github.com/ClickHouse/ClickHouse/issues/28995) でバックポート: compact パーツからのサブカラムの読み取りを修正しました。[#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ))。
* [#28929](https://github.com/ClickHouse/ClickHouse/issues/28929) でバックポート: 定数を伴う高階配列関数の不具合 (`arrayCompact` での `SIGSEGV`、`arrayDifference` / `arrayCumSumNonNegative` での `ILLEGAL_COLUMN`) を修正しました。[#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat))。
