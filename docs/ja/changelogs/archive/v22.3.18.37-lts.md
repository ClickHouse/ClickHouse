<div id="clickhouse-release-v2231837-lts-fe512717551-fixme-as-compared-to-v2231713-lts-fcc4de7e805">
  ### ClickHouse リリース v22.3.18.37-lts (fe512717551) FIXME v22.3.17.13-lts (fcc4de7e805) と比較して
</div>

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#46372](https://github.com/ClickHouse/ClickHouse/issues/46372)でバックポート: リモートではないディスク上の Vertical merge におけるメモリ使用量が過大になる問題を修正しました。リモート ディスクでは `max_insert_delayed_streams_for_parallel_write` を適用するようにしました。[#46275](https://github.com/ClickHouse/ClickHouse/pull/46275) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#46357](https://github.com/ClickHouse/ClickHouse/issues/46357)でバックポート: Compact フォーマットのパーツで Vertical merge アルゴリズムを使用できるようにしました。これにより、ClickHouse server はバックグラウンド処理で使用するメモリを大幅に削減できます。これで [#46084](https://github.com/ClickHouse/ClickHouse/issues/46084) をクローズします。[#46282](https://github.com/ClickHouse/ClickHouse/pull/46282) ([Anton Popov](https://github.com/CurtizJ)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#45856](https://github.com/ClickHouse/ClickHouse/issues/45856)でバックポート: ZooKeeper のダウンロードを修正し、バージョンを更新して、イメージサイズを最適化しました。[#44853](https://github.com/ClickHouse/ClickHouse/pull/44853) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#45620](https://github.com/ClickHouse/ClickHouse/issues/45620) でバックポート: `remote fs` から `LowCardinality` Dictionary を読み取る際に発生する可能性があった `Cannot read all data` エラーに対する追加の修正です。[#44709](https://github.com/ClickHouse/ClickHouse/issues/44709) を修正します。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#45549](https://github.com/ClickHouse/ClickHouse/issues/45549) でバックポート: 不正な構造 (例: xml config 内の型の誤り) を持つ Dictionary がある場合に発生する `SELECT ... FROM system.dictionaries` の例外を修正しました。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk))。

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微

* 誤った approved&#95;at を修正し、conditions を簡素化 [#45302](https://github.com/ClickHouse/ClickHouse/pull/45302) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

* automerge 修正の再挑戦。少なくともデバッグ用の痕跡は残す [#45476](https://github.com/ClickHouse/ClickHouse/pull/45476) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* release workflow の GITHUB&#95;TAG から refs/tags/ を削除 [#45636](https://github.com/ClickHouse/ClickHouse/pull/45636) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

* release 公開時の progress のタイムスタンプを廃止 [#45818](https://github.com/ClickHouse/ClickHouse/pull/45818) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* auto-merge script に補助的なログを追加 [#46080](https://github.com/ClickHouse/ClickHouse/pull/46080) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Vertical Merge の write buffer の破棄順序を修正 [#46205](https://github.com/ClickHouse/ClickHouse/pull/46205) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
