  # 2022年 変更履歴

<div id="clickhouse-release-v211613-stable-fixme-as-compared-to-v21154-stable">
  ### ClickHouse リリース v21.1.6.13-stable FIXME v21.1.5.4-stableとの比較

<div id="bug-fix">
  #### バグ修正
</div>

* [#20637](https://github.com/ClickHouse/ClickHouse/issues/20637) でバックポート: データ破損後、一部のレプリケーション対象の操作 (mutation など) が一部のパーツを処理できなくなることがあるまれな不具合を修正しました。[#19593](https://github.com/ClickHouse/ClickHouse/issues/19593) を修正します。[#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)).
* [#20573](https://github.com/ClickHouse/ClickHouse/issues/20573) でバックポート: remove クエリから未知のパケットを受信した場合に発生する可能性があったクラッシュを修正しました (この問題は [#17868](https://github.com/ClickHouse/ClickHouse/issues/17868) で導入されました) 。[#20547](https://github.com/ClickHouse/ClickHouse/pull/20547) ([Azat Khuzhin](https://github.com/azat)).
* [#21005](https://github.com/ClickHouse/ClickHouse/issues/21005) でバックポート: クエリのキャンセル時に発生する `Empty task was returned from async task queue` を修正しました。[#20881](https://github.com/ClickHouse/ClickHouse/pull/20881) ([Azat Khuzhin](https://github.com/azat)).
* [#21131](https://github.com/ClickHouse/ClickHouse/issues/21131) でバックポート: `ALTER MODIFY COLUMN` によって、確実に失敗する mutation が作成されてしまう場合の動作を修正しました。[#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* [#21250](https://github.com/ClickHouse/ClickHouse/issues/21250) でバックポート: storage join への並列 insert を禁止しました。[#21009](https://github.com/ClickHouse/ClickHouse/pull/21009) ([Vladimir C](https://github.com/vdimir)).
* [#21068](https://github.com/ClickHouse/ClickHouse/issues/21068) でバックポート: 細工された範囲外の `DateTime64` 型の値をフォーマットする際に、境界外メモリアクセスが発生する可能性がありました。これにより [#20494](https://github.com/ClickHouse/ClickHouse/issues/20494) をクローズします。これにより [#20543](https://github.com/ClickHouse/ClickHouse/issues/20543) をクローズします。[#21023](https://github.com/ClickHouse/ClickHouse/pull/21023) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#21229](https://github.com/ClickHouse/ClickHouse/issues/21229) でバックポート: [#21112](https://github.com/ClickHouse/ClickHouse/issues/21112) を修正します。INSERT クエリで重複が発生する可能性があった不具合を修正しました (callbacks の 1 つが少し遅れて到着した場合) 。[#21138](https://github.com/ClickHouse/ClickHouse/pull/21138) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#21277](https://github.com/ClickHouse/ClickHouse/issues/21277) でバックポート: `join_use_nulls` と、サブクエリの `TOTALS` を join する際の不具合を修正しました。これにより [#19362](https://github.com/ClickHouse/ClickHouse/issues/19362) と [#21137](https://github.com/ClickHouse/ClickHouse/issues/21137) をクローズします。[#21248](https://github.com/ClickHouse/ClickHouse/pull/21248) ([Vladimir C](https://github.com/vdimir)).
