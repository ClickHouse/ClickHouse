<div id="2022-changelog">
  # 2022 変更履歴
</div>

<div id="clickhouse-release-v21717283-prestable-fixme-as-compared-to-v21616891-prestable">
  ### ClickHouse リリース v21.7.1.7283-prestable FIXME (v21.6.1.6891-prestable との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 明示的に定義された大規模なセットを含むクエリのパフォーマンスを改善しました。互換性設定 `legacy_column_name_of_tuple_literal` を追加しました。21.7 未満のバージョンからそれ以降のバージョンへクラスターをローリングアップデートする際は、これを `true` に設定することを推奨します。そうしないと、更新中に `IN` 句で明示的に定義されたセットを含む分散クエリが失敗する可能性があります。[#25371](https://github.com/ClickHouse/ClickHouse/pull/25371) ([Anton Popov](https://github.com/CurtizJ)).
* clickhouse-keeper の最大バッファサイズに、前方互換性および後方互換性のない変更が加わりました。後で対応するより、今のうちに (本番環境に入る前に) 対応しておく方が望ましいです。[#25421](https://github.com/ClickHouse/ClickHouse/pull/25421) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### 新機能
</div>

* HDFS 上の VFS のサポートを追加しました。[#11058](https://github.com/ClickHouse/ClickHouse/pull/11058) ([overshov](https://github.com/overshov)).
* データは存在している可能性があるものの、ZooKeeper のメタデータが失われた場合に、レプリケートテーブルを復元する手段を提供します。[#13458](https://github.com/ClickHouse/ClickHouse/issues/13458) を解決します。[#13652](https://github.com/ClickHouse/ClickHouse/pull/13652) ([Mike Kot](https://github.com/myrrc)).
* `flow analysis` に有用な `sequenceNextNode()` 関数を実装しました。[#19766](https://github.com/ClickHouse/ClickHouse/pull/19766) ([achimbab](https://github.com/achimbab)).
* 設定ローダーに YAML 設定のサポートを追加しました。これにより [#3607](https://github.com/ClickHouse/ClickHouse/issues/3607) をクローズします。[#21858](https://github.com/ClickHouse/ClickHouse/pull/21858) ([BoloniniD](https://github.com/BoloniniD)).
* dateName 関数を追加しました。[#23085](https://github.com/ClickHouse/ClickHouse/pull/23085) ([Daniil Kondratyev](https://github.com/dankondr)).
* `quantileBFloat16` 集約関数と、それに対応する `quantilesBFloat16` および `medianBFloat16` を追加しました。これは非常にシンプルで高速な quantile 推定器で、相対誤差は 0.390625% 以下です。これにより [#16641](https://github.com/ClickHouse/ClickHouse/issues/16641) をクローズします。[#23204](https://github.com/ClickHouse/ClickHouse/pull/23204) ([Ivan Novitskiy](https://github.com/RedClusive)).
* `Join` テーブルエンジンで `ALTER DELETE` クエリをサポートしました。[#23260](https://github.com/ClickHouse/ClickHouse/pull/23260) ([foolchi](https://github.com/foolchi)).
* すべての IN/JOIN をデフォルトで GLOBAL IN/JOIN とする新しいブール設定 `prefer_global_in_and_join` を追加しました。[#23434](https://github.com/ClickHouse/ClickHouse/pull/23434) ([Amos Bird](https://github.com/amosbird)).
* bitpositionToArray 関数を追加しました。[#23843](https://github.com/ClickHouse/ClickHouse/pull/23843) ([kevin wan](https://github.com/MaxWk)).
* 集約関数 `segmentLengthSum` を追加しました。[#24250](https://github.com/ClickHouse/ClickHouse/pull/24250) ([flynn](https://github.com/ucasfl)).
* Arrow/Parquet/ORC で struct と Map を、Arrow の入出力フォーマットで Dictionary をサポートしました。新しい設定 `output_format_arrow_low_cardinality_as_dictionary` も導入しました。[#24341](https://github.com/ClickHouse/ClickHouse/pull/24341) ([Kruglov Pavel](https://github.com/Avogar)).
* AARCH64 向けに `compile_expression` 設定をサポートしました。[#24342](https://github.com/ClickHouse/ClickHouse/pull/24342) ([Maksim Kita](https://github.com/kitaisreal)).
* clickhouse-keeper が ZooKeeper 互換の `digest` ACL をサポートするようになりました。[#24448](https://github.com/ClickHouse/ClickHouse/pull/24448) ([alesapin](https://github.com/alesapin)).
* `h3ToGeo` 関数を実装しました。[#24867](https://github.com/ClickHouse/ClickHouse/pull/24867) ([Bharat Nallan](https://github.com/bharatnc)).
* query&#95;log に 2 つの新しいカラム initial&#95;query&#95;start&#95;time / initial&#95;query&#95;start&#95;time&#95;microsecond が追加され、分散クエリであればその開始時刻を記録するようになりました。[#25022](https://github.com/ClickHouse/ClickHouse/pull/25022) ([Amos Bird](https://github.com/amosbird)).
* Dictionaries で Array 型をサポートしました。[#25119](https://github.com/ClickHouse/ClickHouse/pull/25119) ([Maksim Kita](https://github.com/kitaisreal)).
* カラムを JSON 表現にシリアライズするための `toJSONString` 関数を追加しました。[#25164](https://github.com/ClickHouse/ClickHouse/pull/25164) ([Amos Bird](https://github.com/amosbird)).
* MaterializeMySQL で作成された ClickHouse データベースに、マテリアライズ元の MySQL データベースにあるすべてのカラムコメントが含まれるようになりました。[#25199](https://github.com/ClickHouse/ClickHouse/pull/25199) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* 関数 `dateName` を追加しました。著者 [Daniil Kondratyev] (@dankondr)。[#25372](https://github.com/ClickHouse/ClickHouse/pull/25372) ([Maksim Kita](https://github.com/kitaisreal)).
* 関数 `bitPositionsToArray` を追加しました。[#23792](https://github.com/ClickHouse/ClickHouse/issues/23792) をクローズしました。著者 [Kevin Wan] (@MaxWk)。[#25394](https://github.com/ClickHouse/ClickHouse/pull/25394) ([Maksim Kita](https://github.com/kitaisreal)).



<div id="performance-improvement">
  #### パフォーマンス改善
</div>

*  (変更履歴 から削除) 実験的な圧縮ライブラリを統合し、テストしました。フラグ `allow_experimental_codecs` を有効にすると利用できます。これにより [#16775](https://github.com/ClickHouse/ClickHouse/issues/16775) をクローズします。[#17847](https://github.com/ClickHouse/ClickHouse/pull/17847) ([Abi Palagashvili](https://github.com/fibersel))。
* RabbitMQ キューが空の場合に読み取り試行を再スケジュールするため、指数バックオフを追加しました。[#24340](https://github.com/ClickHouse/ClickHouse/issues/24340) をクローズします。[#24415](https://github.com/ClickHouse/ClickHouse/pull/24415) ([Kseniia Sumarokova](https://github.com/kssenii))。
* `bloom_filter` 型の索引は、定数配列を使用する `hasAny` 関数の式でも使用できます。これにより [#24291](https://github.com/ClickHouse/ClickHouse/issues/24291) をクローズします。[#24900](https://github.com/ClickHouse/ClickHouse/pull/24900) ([Vasily Nemkov](https://github.com/Enmk))。



<div id="improvement">
  #### 改善
</div>

* 複数の S3 volume におけるゼロコピー レプリケーションを修正しました ([#22679](https://github.com/ClickHouse/ClickHouse/issues/22679) を修正) 。[#22864](https://github.com/ClickHouse/ClickHouse/pull/22864) ([ianton-ru](https://github.com/ianton-ru)).
* 分散クエリに対する LIMIT の push down を可能にしました。[#23027](https://github.com/ClickHouse/ClickHouse/pull/23027) ([Azat Khuzhin](https://github.com/azat)).
* `Distributed` テーブルへの INSERT で `insert_allow_materialized_columns` (materialized columns を許可) を尊重するようにしました。[#23349](https://github.com/ClickHouse/ClickHouse/pull/23349) ([Azat Khuzhin](https://github.com/azat)).
* この PR で修正予定の bug をここに一覧します。[#23518](https://github.com/ClickHouse/ClickHouse/pull/23518) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* clickhouse-local の File テーブルエンジン、および data が stdin に渡された場合の clickhouse-client の INSERT クエリで Progress を表示するようにしました。[#18209](https://github.com/ClickHouse/ClickHouse/issues/18209) をクローズします。[#23656](https://github.com/ClickHouse/ClickHouse/pull/23656) ([Kseniia Sumarokova](https://github.com/kssenii)).
* storage join でのカラム名の衝突に対応しました。[#20309](https://github.com/ClickHouse/ClickHouse/issues/20309) をクローズします。[#23769](https://github.com/ClickHouse/ClickHouse/pull/23769) ([Vladimir C](https://github.com/vdimir)).
* 障害発生時 (たとえばメモリ制限や破損が原因の場合) に distributed batch を分割する機能を `distributed_directory_monitor_split_batch_on_failure` で追加しました (デフォルトは OFF) 。[#23864](https://github.com/ClickHouse/ClickHouse/pull/23864) ([Azat Khuzhin](https://github.com/azat)).
* メインの `clickhouse` binary への standalone `clickhouse-keeper` シンボリックリンクを追加しました。これにより、メインの clickhouse server なしで協調を実行できるようになりました。[#24059](https://github.com/ClickHouse/ClickHouse/pull/24059) ([alesapin](https://github.com/alesapin)).
* ロガー code からの例外を抑制しました。[#24069](https://github.com/ClickHouse/ClickHouse/pull/24069) ([Azat Khuzhin](https://github.com/azat)).
* `VIEW` に対するクエリでグローバル settings を使用するようにしました。`VIEW` への queries がローカル settings を使用していた挙動を修正しました。これは、`CREATE VIEW` と `SELECT` で setting が異なる場合に error につながっていました。現時点では `VIEW` はこれらの変更済み settings を使用しませんが、`CREATE VIEW` クエリの `SETTINGS` セクションで追加の settings を渡すことは引き続き可能です。[#20551](https://github.com/ClickHouse/ClickHouse/issues/20551) をクローズします。[#24095](https://github.com/ClickHouse/ClickHouse/pull/24095) ([Vladimir C](https://github.com/vdimir)).
* MySQL storage engine 用の settings (`connection_auto_close`/`connection_max_tries`/`connection_pool_size`) を追加しました。[#24146](https://github.com/ClickHouse/ClickHouse/pull/24146) ([Azat Khuzhin](https://github.com/azat)).
* multiline mode における subqueries を含む FROM clause の末尾の空白を修正し、さらに queries の output もわずかに、より分かりやすい形に変更しました。[#24151](https://github.com/ClickHouse/ClickHouse/pull/24151) ([Azat Khuzhin](https://github.com/azat)).
* `127.0.1.1` のような IPv4 address をローカルとして認識するようにしました。これは議論の余地がある変更で、[#23504](https://github.com/ClickHouse/ClickHouse/issues/23504) をクローズします。Michael Filimonov がこの feature をテストします。[#24316](https://github.com/ClickHouse/ClickHouse/pull/24316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* IPv6 address の名前解決を修正しました (たとえば `select * from remote('[::1]', system.one)` の問題を修正) 。[#24319](https://github.com/ClickHouse/ClickHouse/pull/24319) ([Azat Khuzhin](https://github.com/azat)).
* query&#95;log に 2 つの新しいカラム `initial_query_start_time / initial_query_start_time_microsecond` を追加しました。これらは、分散クエリがある場合にその開始時刻を記録します。 [#24388](https://github.com/ClickHouse/ClickHouse/pull/24388) ([Amos Bird](https://github.com/amosbird)).
* より多くのカラムを、可能な場合はエイリアス式に Rewrite するようにしました。これにより、projections などでより良い最適化が有効になる場合があります。 [#24405](https://github.com/ClickHouse/ClickHouse/pull/24405) ([Amos Bird](https://github.com/amosbird)).
* 一部の関数を subcolumns の読み取りに変換し、read data の量を削減する最適化を追加しました。たとえば、ステートメント `col IS NULL` は subcolumn `col.null` の読み取りに変換されます。この最適化は `optimize_functions_to_subcolumns` を設定することで有効にできます。 [#24406](https://github.com/ClickHouse/ClickHouse/pull/24406) ([Anton Popov](https://github.com/CurtizJ)).
* Keeper のシャットダウン時に発生する data race を修正しました。 [#24412](https://github.com/ClickHouse/ClickHouse/pull/24412) ([alesapin](https://github.com/alesapin)).
* insert クエリで Postgres のスキーマをサポートしました。 [#24149](https://github.com/ClickHouse/ClickHouse/issues/24149) をクローズしました。 [#24413](https://github.com/ClickHouse/ClickHouse/pull/24413) ([Kseniia Sumarokova](https://github.com/kssenii)).
* SSDDictionary を DDLクエリで作成する場合、user&#95;files ディレクトリ内でのみ作成できるようにしました。 [#24466](https://github.com/ClickHouse/ClickHouse/pull/24466) ([Maksim Kita](https://github.com/kitaisreal)).
* String-to-Int パーサーをより厳密にし、`toInt64('+')` が例外をスローするようにしました。 [#24475](https://github.com/ClickHouse/ClickHouse/pull/24475) ([Amos Bird](https://github.com/amosbird)).
* バックグラウンドで一度に merge できるパーツ数を制限する MergeTree setting `max_parts_to_merge_at_once` を追加しました。`OPTIMIZE FINAL` クエリには影響しません。 [#1820](https://github.com/ClickHouse/ClickHouse/issues/1820) を修正しました。 [#24496](https://github.com/ClickHouse/ClickHouse/pull/24496) ([alesapin](https://github.com/alesapin)).
* scalar subqueries で、`Limit for rows or bytes to read exceeded` のようなエラーが隠されないようにしました。 [#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).
* 2 つの Replicated*MergeTree settings、`max_replicated_fetches_network_bandwidth` と `max_replicated_sends_network_bandwidth` を追加しました。これにより、テーブルごとのレプリケーションフェッチ/送信の最大速度を制限できます。さらに、2 つのサーバー全体の設定 (`default` user profile 内) 、`max_replicated_fetches_network_bandwidth_for_server` と `max_replicated_sends_network_bandwidth_for_server` を追加しました。これらは、すべてのテーブルに対するレプリケーションの最大速度を制限します。これらの設定は厳密には適用されません。デフォルトでは無効です。 [#1821](https://github.com/ClickHouse/ClickHouse/issues/1821) を修正しました。 [#24573](https://github.com/ClickHouse/ClickHouse/pull/24573) ([alesapin](https://github.com/alesapin)).
* `insert_distributed_sync` で `max_distributed_connections` が適用されるようにしました (そうしないと、大規模なクラスターで同期 insert を行う際に `max_thread_pool_size` を使い切る可能性があります) 。 [#24754](https://github.com/ClickHouse/ClickHouse/pull/24754) ([Azat Khuzhin](https://github.com/azat)).
* `Replicated` データベースエンジンのバグを修正しました。このバグにより、まれに一部のレプリカがエンキューされた DDLクエリをスキップすることがありました。 [#24805](https://github.com/ClickHouse/ClickHouse/pull/24805) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 一部のクエリでは複数パスのセマンティック解析が必要です。その場合、`IN` 用に構築済みの Set を再利用するようにしました。 [#24874](https://github.com/ClickHouse/ClickHouse/pull/24874) ([Amos Bird](https://github.com/amosbird)).
* パーティションプルーニングで `not in` 演算子を使用できるようにしました。 [#24894](https://github.com/ClickHouse/ClickHouse/pull/24894) ([Amos Bird](https://github.com/amosbird)).
* S3 エラーのログ出力を改善し、キーやバケットが空の場合でも二重スペースが入らないようにしました。[#24897](https://github.com/ClickHouse/ClickHouse/pull/24897) ([Vladimir Chebotarev](https://github.com/excitoon)).
* distributed query で、`optimize_skip_unused_shards=1` のときに、`(sharding key) IN (one-element-tuple)` のような条件でも 分片 をスキップできるようにしました。 (複数要素の Tuple はサポートされていましたが、単一要素の Tuple は literal として parse されるため動作していませんでした) 。[#24930](https://github.com/ClickHouse/ClickHouse/pull/24930) ([Amos Bird](https://github.com/amosbird)).
* 実行時に Linux のバージョンを検出するようにしました (ネストされた epoll を正しく動作させるために必要です。これは `async_socket_for_remote`/`use_hedged_requests` に必要で、そうでない場合はリモートクエリが停止する可能性があります) 。[#25067](https://github.com/ClickHouse/ClickHouse/pull/25067) ([Azat Khuzhin](https://github.com/azat)).
* background schedule pool のサイズを 128 に増やしました (`background_schedule_pool_size` 設定) 。これにより、ZooKeeper への connection が遅い場合に replication queue がハングするのを回避できます。[#25072](https://github.com/ClickHouse/ClickHouse/pull/25072) ([alesapin](https://github.com/alesapin)).
* IDN host (例: `example.рф`) に対する topLevelDomain() を修正しました。従来はこのような host に対して空文字列を返していました。[#25103](https://github.com/ClickHouse/ClickHouse/pull/25103) ([Azat Khuzhin](https://github.com/azat)).
* server の起動時に、不正な partition ID を持つ パーツ は削除されず、常にデタッチされた 状態になっていました。[#25070](https://github.com/ClickHouse/ClickHouse/issues/25070). [#25166](https://github.com/ClickHouse/ClickHouse/pull/25166) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* aggregate function `topK` のメモリ追跡を修正しました。これにより [#25259](https://github.com/ClickHouse/ClickHouse/issues/25259) を解決します。[#25260](https://github.com/ClickHouse/ClickHouse/pull/25260) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* bridge プロセス用に、専用の `clickhouse-bridge` group と user を使うようにしました。bridge が OOM キラー の最初の対象になるように oom&#95;score&#95;adj を設定しました。最大 RSS も 1 GiB に設定しました。[#23861](https://github.com/ClickHouse/ClickHouse/issues/23861) を解決します。[#25280](https://github.com/ClickHouse/ClickHouse/pull/25280) ([Kseniia Sumarokova](https://github.com/kssenii)).
* `clickhouse-client` のプロンプトを更新し、再接続時にメッセージを表示するようにしました。これにより [#10577](https://github.com/ClickHouse/ClickHouse/issues/10577) を解決します。[#25281](https://github.com/ClickHouse/ClickHouse/pull/25281) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* function `if` の各分岐で Decimal 型と Int 型をサポートしました。これにより [#20549](https://github.com/ClickHouse/ClickHouse/issues/20549) を解決します。また、[#10142](https://github.com/ClickHouse/ClickHouse/issues/10142) も解決します。[#25283](https://github.com/ClickHouse/ClickHouse/pull/25283) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `http_max_fields`、`http_max_field_name_size`、`http_max_field_value_size` の settings を追加しました。[#25296](https://github.com/ClickHouse/ClickHouse/pull/25296) ([Ivan](https://github.com/abyss7)).
* sequenceMatch および sequenceCount 関数で、time conditions に == 演算子を追加しました。例: sequenceMatch(&#39;(?1)(?t==1)(?2)&#39;)(time, data = 1, data = 2)。[#25299](https://github.com/ClickHouse/ClickHouse/pull/25299) ([Christophe Kalenzaga](https://github.com/mga-chka)).
* LowCardinality で Interval をサポートしました。[#21730](https://github.com/ClickHouse/ClickHouse/issues/21730) を解決します。[#25410](https://github.com/ClickHouse/ClickHouse/pull/25410) ([Vladimir C](https://github.com/vdimir)).
* Flatbuffers ライブラリを v.2.0.0 に更新しました。変更点の一覧は https://github.com/google/flatbuffers/releases/tag/v2.0.0 を参照してください。 [#25474](https://github.com/ClickHouse/ClickHouse/pull/25474) ([Ilya Yatsishin](https://github.com/qoega)).
* internal&#95;replication=true の場合に dirname からレプリカを除外しました (これにより、任意の数のレプリカを持つクラスターから Distributed への INSERT が可能になります。従来は 15 レプリカまでしかサポートされておらず、それを超えると async blocks 用ディレクトリの作成時に ENAMETOOLONG で失敗していました) 。 [#25513](https://github.com/ClickHouse/ClickHouse/pull/25513) ([Azat Khuzhin](https://github.com/azat)).
* ユーザーがオペレーティングシステムに利用可能な任意のポートを要求した際、実際にバインドされたポート番号を取得するようにしました。 [#25569](https://github.com/ClickHouse/ClickHouse/pull/25569) ([bnaecker](https://github.com/bnaecker)).
* Distributed engine の起動時間を短縮しました。 [#25663](https://github.com/ClickHouse/ClickHouse/pull/25663) ([Azat Khuzhin](https://github.com/azat)).
