  # 2022年の変更履歴

<div id="clickhouse-release-v217418-stable-fixme-as-compared-to-v217314-stable">
  ### ClickHouse リリース v21.7.4.18-stable FIXME (v21.7.3.14-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#26297](https://github.com/ClickHouse/ClickHouse/issues/26297)でバックポート: クエリ実行中に例外が発生した際、ClickHouse が送信する MySQL プロトコルのパケット内の誤った `sequence_id` を修正しました。これにより、MySQL client が ClickHouse server への connection をリセットする可能性がありました。[#21184](https://github.com/ClickHouse/ClickHouse/issues/21184) を修正しました。[#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#26356](https://github.com/ClickHouse/ClickHouse/issues/26356)でバックポート: totals を伴う join で発生する論理エラーを修正し、[#26017](https://github.com/ClickHouse/ClickHouse/issues/26017) をクローズしました。[#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir))。
* [#26359](https://github.com/ClickHouse/ClickHouse/issues/26359)でバックポート: 失われたレプリカの復旧時に発生するまれな bug を修正しました。これにより、replicas 間で不整合が生じる可能性がありました。[#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#26419](https://github.com/ClickHouse/ClickHouse/issues/26419)でバックポート: 削除済みユーザーとしてログインした際に発生する可能性のある crash を修正しました。この PR で [#26073](https://github.com/ClickHouse/ClickHouse/issues/26073) を修正します。[#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#26413](https://github.com/ClickHouse/ClickHouse/issues/26413)でバックポート: `partial_merge_join` で、join されない block が無限に stream される問題を修正し、[#26325](https://github.com/ClickHouse/ClickHouse/issues/26325) をクローズしました。[#26374](https://github.com/ClickHouse/ClickHouse/pull/26374) ([Vladimir C](https://github.com/vdimir))。
* [#26447](https://github.com/ClickHouse/ClickHouse/issues/26447)でバックポート: fuzz によって検出された msan の crash をいくつか修正しました。[#22517](https://github.com/ClickHouse/ClickHouse/issues/22517) を修正しました。[#26428](https://github.com/ClickHouse/ClickHouse/pull/26428) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
