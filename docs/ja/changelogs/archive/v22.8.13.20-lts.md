<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーから見て不具合となる動作)
</div>

* [#45565](https://github.com/ClickHouse/ClickHouse/issues/45565)でバックポート: 位置引数で `Positional argument out of bounds` 例外が発生する問題を修正。[#40634](https://github.com/ClickHouse/ClickHouse/issues/40634) をクローズ。[#41189](https://github.com/ClickHouse/ClickHouse/pull/41189) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#44997](https://github.com/ClickHouse/ClickHouse/issues/44997)でバックポート: remote fs から `LowCardinality` Dictionary を読み込む際に発生する可能性があった `Cannot read all data` エラーについて、別の修正を実施。[#44709](https://github.com/ClickHouse/ClickHouse/issues/44709) を修正。[#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#45550](https://github.com/ClickHouse/ClickHouse/issues/45550)でバックポート: 不正な structure (例: xml config 内の型が誤っている場合) を持つ Dictionary があると、`SELECT ... FROM system.dictionaries` で例外が発生する問題を修正。[#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk))。
