<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 関数 `parseDateTime()` のフォーマッタ `%l`/`%k`/`%c` で、先頭にゼロのない時や月も parse できるようになりました。たとえば、`select parseDateTime('2023-11-26 8:14', '%F %k:%i')` が動作するようになりました。以前の 2 桁必須の挙動に戻すには、`parsedatetime_parse_without_leading_zeros = 0` を設定してください。関数 `formatDateTime` でも、先頭にゼロのない時や月を出力できるようになりました。これは `formatdatetime_format_without_leading_zeros` で制御されますが、既存のユースケースを壊さないよう、デフォルトでは無効になっています。 [#55872](https://github.com/ClickHouse/ClickHouse/pull/55872) ([Azat Khuzhin](https://github.com/azat)).
* `Decimal` 型の引数では、集約関数 `avgWeighted` を使用できなくなりました。回避策: 引数を `Float64` に変換してください。これにより [#43928](https://github.com/ClickHouse/ClickHouse/issues/43928) はクローズされます。これにより [#31768](https://github.com/ClickHouse/ClickHouse/issues/31768) はクローズされます。これにより [#56435](https://github.com/ClickHouse/ClickHouse/issues/56435) はクローズされます。`Decimal` の引数でこの関数を materialized view や projections の中で使用している場合は、support@clickhouse.com までご連絡ください。集約関数 `sumMap` のエラーを修正した結果、速度がおよそ 1.5〜2 倍低下しました。とはいえ、この関数はどうせ使い物にならないので問題ありません。これにより [#54955](https://github.com/ClickHouse/ClickHouse/issues/54955) はクローズされます。これにより [#53134](https://github.com/ClickHouse/ClickHouse/issues/53134) はクローズされます。これにより [#55148](https://github.com/ClickHouse/ClickHouse/issues/55148) はクローズされます。関数 `groupArraySample` のバグを修正しました。クエリ内で複数の aggregate state が生成される場合に、同じ random seed を使っていました。 [#56350](https://github.com/ClickHouse/ClickHouse/pull/56350) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* デフォルトの ClickHouse サーバー設定ファイルでは、`default` ユーザーに対して `access_management` (SQL クエリによるユーザー操作) と `named_collection_control` (SQL クエリによる named collection の操作) がデフォルトで有効になりました。これにより [#56482](https://github.com/ClickHouse/ClickHouse/issues/56482) はクローズされます。 [#56619](https://github.com/ClickHouse/ClickHouse/pull/56619) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* RESPECT/IGNORE NULLS に関する複数の改善。 [#57189](https://github.com/ClickHouse/ClickHouse/pull/57189) ([Raúl Marín](https://github.com/Algunenano)).
* optimize&#95;move&#95;functions&#95;out&#95;of&#95;any の最適化を削除しました。 [#57190](https://github.com/ClickHouse/ClickHouse/pull/57190) ([Raúl Marín](https://github.com/Algunenano)).

<div id="new-feature">
  #### 新機能
</div>

* データベースおよびテーブルの非同期読み込みを行うサーバー設定 `async_load_databases` を追加しました。これにより、サーバーの起動時間が短縮されます。Ordinary、Atomic、Replicated エンジンを使用するデータベースに適用されます。これらのテーブルのメタデータは非同期で読み込まれます。テーブルに対するクエリは、読み込みジョブの優先度を引き上げ、完了まで待機します。テーブル `system.async_loader` を追加しました。[#49351](https://github.com/ClickHouse/ClickHouse/pull/49351) ([Sergei Trifonov](https://github.com/serxa)).
* 1. `KeyCondition` に関数 `extractPlainRanges` を追加しました。2. `Range` に便利な関数をいくつか追加しました。3. 順序付けされ、互いに重複しない一連の範囲を表す `PlainRanges` を追加しました。4. ユーザーが選択した数値を正確に返す `NumbersRangedSource` を追加しました。[#50909](https://github.com/ClickHouse/ClickHouse/pull/50909) ([JackyWoo](https://github.com/JackyWoo)).
* システムテーブル `blob_storage_log` を追加しました。[#52918](https://github.com/ClickHouse/ClickHouse/pull/52918) ([vdimir](https://github.com/vdimir)).
* 統計情報を使用して、prewhere 条件をより適切に並べ替えるようにしました。[#53240](https://github.com/ClickHouse/ClickHouse/pull/53240) ([Han Fei](https://github.com/hanfei1991)).
* 新しい集約関数 `groupArraySorted(n)(value)` を追加しました。これは、フィールドの値をその値自体でソートし、先頭から n 個の値を含む配列を返します。[#53562](https://github.com/ClickHouse/ClickHouse/pull/53562) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Keeper プロトコルでの圧縮のサポートを追加しました。`zookeeper` 内のフラグ `use_compression` を使用することで、ClickHouse で有効化できます。[#49507](https://github.com/ClickHouse/ClickHouse/issues/49507) を解決します。[#54957](https://github.com/ClickHouse/ClickHouse/pull/54957) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* HTTP proxy 経由の HTTPS リクエストでトンネリングを無効にするための ClickHouse 設定を追加しました。[#55033](https://github.com/ClickHouse/ClickHouse/pull/55033) ([Arthur Passos](https://github.com/arthurpassos)).
* 機能 `storage_metadata_write_full_object_key` を導入しました。これを `true` に設定すると、メタデータファイルは新しいフォーマット VERSION&#95;FULL&#95;OBJECT&#95;KEY で書き込まれます。このフォーマットでは、CH は完全なリモートオブジェクトキーをメタデータファイルに保存します。[#55566](https://github.com/ClickHouse/ClickHouse/pull/55566) ([Sema Checherinda](https://github.com/CheSema)).
* named collections のフィールドが上書きされないよう保護するための新しい設定と構文を追加しました。これは、悪意のあるユーザーが secrets に不正アクセスするのを防ぐことを目的としています。[#55782](https://github.com/ClickHouse/ClickHouse/pull/55782) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* すべてのシステムログテーブルに `hostname` カラムを追加しました。[#55894](https://github.com/ClickHouse/ClickHouse/pull/55894) ([Bharat Nallan](https://github.com/bharatnc)).
* `CHECK ALL TABLES` クエリを追加しました。[#56022](https://github.com/ClickHouse/ClickHouse/pull/56022) ([vdimir](https://github.com/vdimir)).
* MySQL の `FROM_DAYS` に似た関数 `fromDaysSinceYearZero()` を追加しました。たとえば、`SELECT fromDaysSinceYearZero(739136)` は `2023-09-08` を返します。[#56088](https://github.com/ClickHouse/ClickHouse/pull/56088) ([Joanna Hulboj](https://github.com/jh0x)).
* pocketFFT ライブラリで、FFT を使用した series の period 検出メソッドを実装しました。[#56171](https://github.com/ClickHouse/ClickHouse/pull/56171) ([Bhavna Jindal](https://github.com/bhavnajindal)).
* ClickHouse を使わずにバックアップを閲覧し、そこから情報を抽出するための外部 Python ツールを追加しました。[#56268](https://github.com/ClickHouse/ClickHouse/pull/56268) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* ウィンドウ関数の並列評価をサポートしました。[#34688](https://github.com/ClickHouse/ClickHouse/issues/34688) を修正しました。[#39631](https://github.com/ClickHouse/ClickHouse/pull/39631) ([Dmitry Novik](https://github.com/novikd)).
* `max_concurrent_queries` のデフォルト値を 100 から 1000 に引き上げました。これは、接続している client が非常に多く、それらが低速にデータを送受信しているため、server のボトルネックが CPU ではない場合、または CPU コア数が 100 を超える場合に適しています。あわせて、同時実行制御をデフォルトで有効にし、クエリ処理 thread の目標総数を CPU コア数の 2 倍に設定しました。これにより、同時実行クエリが非常に多いシナリオで性能が向上します。[#46927](https://github.com/ClickHouse/ClickHouse/pull/46927) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `Merge` テーブルエンジンでの `IN(...)` 条件による Filtering を修正しました。[#54905](https://github.com/ClickHouse/ClickHouse/pull/54905) ([Nikita Taranov](https://github.com/nickitat)).
* cache がいっぱいで大きな read が発生する場合の改善です。[#55158](https://github.com/ClickHouse/ClickHouse/pull/55158) ([Kseniia Sumarokova](https://github.com/kssenii)).
* 過剰な入力ファイル read を避けるため、S3 の checksums を無効化できるようにしました (この新しい動作は `s3_disable_checksum=true` で有効にできます) 。[#55559](https://github.com/ClickHouse/ClickHouse/pull/55559) ([Azat Khuzhin](https://github.com/azat)).
* リモート table では、データが page cache にある場合、同期的に read するようになりました (ローカル table と同様です) 。このほうが高速で、thread pool 内での同期が不要になり、ローカル fs での `seek` もためらわずに行え、CPU wait も削減されます。[#55841](https://github.com/ClickHouse/ClickHouse/pull/55841) ([Nikita Taranov](https://github.com/nickitat)).
* ... この PR は [#55929](https://github.com/ClickHouse/ClickHouse/issues/55929) に続くもので、約 30% の高速化をもたらします。 - 予約メモリを削減 - `resize` 呼び出しを削減。[#55957](https://github.com/ClickHouse/ClickHouse/pull/55957) ([lgbo](https://github.com/lgbo-ustc)).
* ICX デバイス (Intel Xeon Platinum 8380 CPU、80 コア、160 スレッド) 上での **OnTime** の性能実験では、この変更により、他には影響を与えることなく、クエリ Q2、Q3、Q4、Q5、Q6 の QPS がそれぞれ **7.4%、5.9%、4.7%、3.0%、4.6%** 向上することが示されています。[#56079](https://github.com/ClickHouse/ClickHouse/pull/56079) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* クエリプロファイラ内でビジーな thread の数を制限しました。これを超える場合は profiling をスキップします。[#56105](https://github.com/ClickHouse/ClickHouse/pull/56105) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* WindowTransform での virtual 関数呼び出し回数を削減しました。[#56120](https://github.com/ClickHouse/ClickHouse/pull/56120) ([Maksim Kita](https://github.com/kitaisreal)).
* スキャンを高速化するため、ORC で Tuple フィールドの再帰的な pruning を可能にしました。[#56122](https://github.com/ClickHouse/ClickHouse/pull/56122) ([李扬](https://github.com/taiyang-li)).
* このプルリクエストでは、Npy data フォーマットで countRows をサポートしました。これにより、setting `optimize_count_from_files=1` を使用すると、`select count() from file(data.npy)` のようなクエリは、結果を Caching することで大幅に高速に動作するようになります。[#56304](https://github.com/ClickHouse/ClickHouse/pull/56304) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* aggregation を伴い streams 数が多いクエリでは、plan の構築時に使用するメモリ量が少なくなります。[#57074](https://github.com/ClickHouse/ClickHouse/pull/57074) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 多数のユーザーを抱えるユースケースにおけるクエリ実行のパフォーマンスを改善しました。[#57106](https://github.com/ClickHouse/ClickHouse/pull/57106) ([Andrej Hoos](https://github.com/adikus)).
* ARRAY JOIN に関する軽微な改善として、一部の中間結果を再利用するようにしました。[#57183](https://github.com/ClickHouse/ClickHouse/pull/57183) ([李扬](https://github.com/taiyang-li)).
* スタックアンワインドが遅くなるケースがありました。[#57221](https://github.com/ClickHouse/ClickHouse/pull/57221) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `max_streams = 1` の場合、外部ストレージからの読み取りにデフォルトの読み取りプールを使用するようになりました。これは、読み取りプリフェッチが有効な場合に効果的です。[#57334](https://github.com/ClickHouse/ClickHouse/pull/57334) ([Nikita Taranov](https://github.com/nickitat)).

* AWS 環境で実行されている場合、ClickHouse keeper が実行中の availability zone を `/keeper/availability-zone` パスで報告するようになりました。[#56104](https://github.com/ClickHouse/ClickHouse/pull/56104) ([Jianfei Hu](https://github.com/incfly)).
