<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#38690](https://github.com/ClickHouse/ClickHouse/issues/38690)でバックポート: UNION のサブクエリにおけるカラム順序の誤りを修正しました (サブセレクト内に重複したカラムがある場合、誤った結果が返されることがあります) 。[#37887](https://github.com/ClickHouse/ClickHouse/pull/37887) ([Azat Khuzhin](https://github.com/azat)).
* [#38500](https://github.com/ClickHouse/ClickHouse/issues/38500)でバックポート: ログ出力中に OvercommitTracker が再帰的に使用されないように修正しました。[#37794](https://github.com/ClickHouse/ClickHouse/issues/37794) を修正。cc @tavplubix @davenger. [#38246](https://github.com/ClickHouse/ClickHouse/pull/38246) ([Dmitry Novik](https://github.com/novikd)).
* [#38712](https://github.com/ClickHouse/ClickHouse/issues/38712)でバックポート: `DISTINCT` および `LIMIT` を伴う分散クエリで誤った結果になる問題を修正しました。[#38282](https://github.com/ClickHouse/ClickHouse/issues/38282) を修正。[#38371](https://github.com/ClickHouse/ClickHouse/pull/38371) ([Anton Popov](https://github.com/CurtizJ)).
* [#38594](https://github.com/ClickHouse/ClickHouse/issues/38594)でバックポート: server の異常終了後にパーツが削除されない問題を修正しました (server のシャットダウン時に削除されなかった場合、そのまま残り続けます) 。[#38486](https://github.com/ClickHouse/ClickHouse/pull/38486) ([Azat Khuzhin](https://github.com/azat)).
* [#38597](https://github.com/ClickHouse/ClickHouse/issues/38597)でバックポート: 22.4 より前のレプリカとのレプリケーション問題を回避するため、テーブル作成を修正しました。[#38541](https://github.com/ClickHouse/ClickHouse/pull/38541) ([Raúl Marín](https://github.com/Algunenano)).
* [#38687](https://github.com/ClickHouse/ClickHouse/issues/38687)でバックポート: IPv4/IPv6 表現の値が不正なテーブルであっても、clickhouse-server を起動し、テーブルを attach/detach できるようになりました。issue [#35156](https://github.com/ClickHouse/ClickHouse/issues/35156) に対する適切な修正です。[#38590](https://github.com/ClickHouse/ClickHouse/pull/38590) ([alesapin](https://github.com/alesapin)).
* [#38665](https://github.com/ClickHouse/ClickHouse/issues/38665)でバックポート: 22.4 より前のレプリカとの問題を回避するため、さらにいくつかのノードを対応させました。[#38627](https://github.com/ClickHouse/ClickHouse/pull/38627) ([Raúl Marín](https://github.com/Algunenano)).
* [#38778](https://github.com/ClickHouse/ClickHouse/issues/38778)でバックポート: 一部の argument が NaN の場合でも、`rankCorr` 関数が正しく動作するようになりました。これにより [#38396](https://github.com/ClickHouse/ClickHouse/issues/38396) はクローズされます。[#38722](https://github.com/ClickHouse/ClickHouse/pull/38722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#38782](https://github.com/ClickHouse/ClickHouse/issues/38782)でバックポート: 誤った結果につながる Map combinator の use-after-free を修正しました。[#38748](https://github.com/ClickHouse/ClickHouse/pull/38748) ([Azat Khuzhin](https://github.com/azat)).
