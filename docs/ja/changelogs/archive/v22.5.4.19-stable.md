<div id="bug-fix">
  #### バグ修正
</div>

* [#39748](https://github.com/ClickHouse/ClickHouse/issues/39748)でバックポート: 暗号化されたディスクの読み取り時のシークを修正。このPRで[#38381](https://github.com/ClickHouse/ClickHouse/issues/38381)を修正しました。[#39687](https://github.com/ClickHouse/ClickHouse/pull/39687) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#39882](https://github.com/ClickHouse/ClickHouse/issues/39882) でバックポート: 以前のパッケージでは、systemd.service ファイルが `/etc` にインストールされていました。`/etc` 配下のファイルは `conf` として扱われるため、削除されず、自動では更新もされません。この PR では、それらのファイルを削除するようにしました。[#39323](https://github.com/ClickHouse/ClickHouse/pull/39323) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに見える不具合)
</div>

* [#39209](https://github.com/ClickHouse/ClickHouse/issues/39209) でバックポート: データを S3 に保存している `MergeTree` テーブルからスパースなカラムを読み込む際の不具合を修正しました。[#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ)).
* [#39589](https://github.com/ClickHouse/ClickHouse/issues/39589) でバックポート: Avro format における data race と、発生する可能性のある heap-buffer-overflow を修正しました。[#39094](https://github.com/ClickHouse/ClickHouse/issues/39094) をクローズしました。[#33652](https://github.com/ClickHouse/ClickHouse/issues/33652) をクローズしました。[#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* [#39611](https://github.com/ClickHouse/ClickHouse/issues/39611) でバックポート: splitByChar の maxsplit argument が正しく動作していなかった bug を修正しました。[#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* [#39790](https://github.com/ClickHouse/ClickHouse/issues/39790) でバックポート: tuples および operator `IN` に関する誤った索引解析を修正しました。これにより誤ったクエリ結果が返される可能性がありました。[#39752](https://github.com/ClickHouse/ClickHouse/pull/39752) ([Anton Popov](https://github.com/CurtizJ)).
* [#39835](https://github.com/ClickHouse/ClickHouse/issues/39835) でバックポート: `local_filesystem_read_method=pread_threadpool` 使用時に発生する `CANNOT_READ_ALL_DATA` exception を修正しました。[man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS) によると、この bug が影響していたのは Linux カーネルバージョン 5.9 および 5.10 のみです。[#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
