  # 2024 変更履歴
</div>

<div id="clickhouse-release-v24112048-stable-5a024dfc093-fixme-as-compared-to-v231211368-stable-a2faa65b080">
  ### ClickHouse リリース v24.1.1.2048-stable (5a024dfc093) FIXME、v23.12.1.1368-stable (a2faa65b080) との比較
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* 設定 `print_pretty_type_names` はデフォルトで有効になりました。以前の動作を維持するには、これを無効にするか、`SET compatibility = '23.12'` を設定してください。[#57726](https://github.com/ClickHouse/ClickHouse/pull/57726) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree setting `clean_deleted_rows` は非推奨となり、現在は効果がありません。`OPTIMIZE` に対する `CLEANUP` キーワードは、デフォルトでは許可されません (`allow_experimental_replacing_merge_with_cleanup` が有効な場合を除く) 。[#58316](https://github.com/ClickHouse/ClickHouse/pull/58316) ([Alexander Tokmakov](https://github.com/tavplubix)).
* 関数 `reverseDNSQuery` は利用できなくなりました。これにより [#58368](https://github.com/ClickHouse/ClickHouse/issues/58368) はクローズされます。[#58369](https://github.com/ClickHouse/ClickHouse/pull/58369) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 設定ファイル内のアクセス制御を改善するための各種変更を有効にしました。これらの変更は動作に影響するため、`access_control_improvements` セクションの `config.xml` を確認してください。判断に自信がない場合は、設定ファイル内の値を前のバージョンのままにしておいてください。[#58584](https://github.com/ClickHouse/ClickHouse/pull/58584) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `PASTE JOIN` で、subqueries に別名がなくてもクエリを許可するようにしました。[#58654](https://github.com/ClickHouse/ClickHouse/pull/58654) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* NaN 値を含む sumMapFiltered を修正しました。NaN 値は今後、ランダムではなく末尾に配置され、他のどの値とも異なるものとして扱われます。`-0` も `0` と等しいものとして扱われるようになりました。0 の値は破棄されるため、`-0` の値も破棄されます。[#58959](https://github.com/ClickHouse/ClickHouse/pull/58959) ([Raúl Marín](https://github.com/Algunenano)).
* 関数 `visibleWidth` はドキュメントどおりに動作するようになります。以前のバージョンでは、`lengthUTF8` 関数と同様に、文字列のシリアライゼーション後の code points を単純に数えるだけで、ゼロ幅文字、結合文字、全角文字、tabs、削除文字は考慮されていませんでした。現在はそれに合わせて動作が変更されています。以前の動作を維持したい場合は、`function_visible_width_behavior` を `0` に設定するか、`compatibility` を `23.12` 以下に設定してください。[#59022](https://github.com/ClickHouse/ClickHouse/pull/59022) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Kusto dialect は、これら 2 つのバグが修正されるまで無効化されています: [#59037](https://github.com/ClickHouse/ClickHouse/issues/59037) および [#59036](https://github.com/ClickHouse/ClickHouse/issues/59036)。[#59305](https://github.com/ClickHouse/ClickHouse/pull/59305) ([Alexey Milovidov](https://github.com/alexey-milovidov)).



<div id="new-feature">
  #### 新機能
</div>

* 宛先テーブルのパーティション式がパーツを再パーティション化・分割しない場合に、異なるパーティション式を持つテーブルからパーティションをアタッチできるようになりました。[#39507](https://github.com/ClickHouse/ClickHouse/pull/39507) ([Arthur Passos](https://github.com/arthurpassos))。
* 非同期メトリクスを更新する `SYSTEM RELOAD ASYNCHRONOUS METRICS` ステートメントを追加しました。主にテストおよび開発用途に有用です。[#53710](https://github.com/ClickHouse/ClickHouse/pull/53710) ([Robert Schulze](https://github.com/rschu1ze))。
* 一部の設定（現在は `min_compress_block_size` および `max_compress_block_size`）をカラムレベルで指定できるようになりました。カラムレベルの設定は対応するテーブルレベルの設定より優先されます。例: `CREATE TABLE tab (col String SETTINGS (min_compress_block_size = 81920, max_compress_block_size = 163840)) ENGINE = MergeTree ORDER BY tuple();`。[#55201](https://github.com/ClickHouse/ClickHouse/pull/55201) ([Duc Canh Le](https://github.com/canhld94))。
* 集計関数 `quantileDDSketch`、および対応する `quantilesDDSketch` と `medianDDSketch` を追加しました。DDSketch（https://www.vldb.org/pvldb/vol12/p2195-masson.pdf）に基づいています。### ユーザー向け変更のドキュメントエントリ。[#56342](https://github.com/ClickHouse/ClickHouse/pull/56342) ([Srikanth Chekuri](https://github.com/srikanthccv))。
* 時系列を季節成分、トレンド成分、残差成分に分解する関数 `seriesDecomposeSTL()` を追加しました。[#57078](https://github.com/ClickHouse/ClickHouse/pull/57078) ([Bhavna Jindal](https://github.com/bhavnajindal))。
* MaterializedMySQL 向けに MySQL Binlog クライアントを導入しました。1つの binlog 接続で複数のデータベースに対応します。[#57323](https://github.com/ClickHouse/ClickHouse/pull/57323) ([Val Doroshchuk](https://github.com/valbok))。
* Intel QuickAssist Technology（QAT）はハードウェアアクセラレーションによる圧縮と暗号化を提供します。ClickHouse に、zstd 圧縮に QAT を活用する新しい圧縮コーデック `ZSTD_QAT` が追加されました。このコーデックは [Intel の QATlib](https://github.com/intel/qatlib) および [Intel の QAT ZSTD Plugin](https://github.com/intel/QAT-ZSTD-Plugin) を使用します。現時点では圧縮のみハードウェアアクセラレーションが可能です（QAT を初期化できない場合はソフトウェアフォールバックが動作します）。伸長は常にソフトウェアで実行されます。[#57509](https://github.com/ClickHouse/ClickHouse/pull/57509) ([jasperzhu](https://github.com/jinjunzh))。
* S3 ディスクにおけるオブジェクトストレージキーの生成方法を新しい方式に変更しました。ディスク定義の `key_template` オプションで `re2` 正規表現構文を使用してフォーマットを定義できるようになりました。[#57663](https://github.com/ClickHouse/ClickHouse/pull/57663) ([Sema Checherinda](https://github.com/CheSema))。
* テーブル system.dropped_tables_parts に、system.dropped_tables テーブル（削除済みだがまだ除去されていないテーブル）のパーツが含まれるようになりました。[#58038](https://github.com/ClickHouse/ClickHouse/pull/58038) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy))。
* 複数のデータ型の共用体を表す Variant データ型を実装しました。型 `Variant(T1, T2, ..., TN)` は、各行がいずれかの型 `T1`、`T2`、...、`TN` の値、またはいずれでもない値（`NULL`）を持つことを意味します。Variant 型は設定 `allow_experimental_variant_type` で有効化できます。参照: [#54864](https://github.com/ClickHouse/ClickHouse/issues/54864)。[#58047](https://github.com/ClickHouse/ClickHouse/pull/58047) ([Kruglov Pavel](https://github.com/Avogar))。
* テーブルにアタッチされる materialized view の数を制限する設定 `max_materialized_views_size_for_table` を追加しました。[#58068](https://github.com/ClickHouse/ClickHouse/pull/58068) ([zhongyuankai](https://github.com/zhongyuankai))。
* `clickhouse-format` の改善: * `VALUES` を使用した INSERT クエリのサポート * コメントのサポート（出力するには `--comments` を使用） * 長いクエリのみを複数行にフォーマットする `--max_line_length` オプションのサポート。[#58246](https://github.com/ClickHouse/ClickHouse/pull/58246) ([vdimir](https://github.com/vdimir))。
* 非アクティブなレプリカの待機を回避できる `distributed_ddl_output_mode` 向けのモード `null_status_on_timeout_only_active` および `throw_only_active` を追加しました。[#58350](https://github.com/ClickHouse/ClickHouse/pull/58350) ([Alexander Tokmakov](https://github.com/tavplubix))。
* テーブル `system.database_engines` を追加しました。[#58390](https://github.com/ClickHouse/ClickHouse/pull/58390) ([Bharat Nallan](https://github.com/bharatnc))。
* SYSTEM SYNC REPLICA LIGHTWEIGHT クエリに FROM <Replicas> 修飾子を追加しました。FROM 修飾子を使用すると、指定したソースレプリカ、および ZooKeeper に存在しないか source_replica が空のレプリカに対してのみ、フェッチとドロップ範囲の完了を待機します。[#58393](https://github.com/ClickHouse/ClickHouse/pull/58393) ([Jayme Bird](https://github.com/jaymebrd))。
* 部分配列を計算する関数 `arrayShingles()` を追加しました。例: `arrayShingles([1, 2, 3, 4, 5], 3)` は `[[1,2,3],[2,3,4],[3,4,5]]` を返します。[#58396](https://github.com/ClickHouse/ClickHouse/pull/58396) ([Zheng Miao](https://github.com/zenmiao7))。
* IDNA 標準に従って国際化ドメイン名を ASCII 表現に変換するための関数 `punycodeEncode()`、`punycodeDecode()`、`idnaEncode()`、`idnaDecode()` を追加しました。[#58454](https://github.com/ClickHouse/ClickHouse/pull/58454) ([Robert Schulze](https://github.com/rschu1ze))。
* 文字列類似度関数 `dramerauLevenshteinDistance()`、`jaroSimilarity()`、`jaroWinklerSimilarity()` を追加しました。[#58531](https://github.com/ClickHouse/ClickHouse/pull/58531) ([Robert Schulze](https://github.com/rschu1ze))。
* 出力圧縮レベルを変更する設定 `output_format_compression_level` と、出力圧縮方式が `zstd` の場合に圧縮ウィンドウサイズを明示的に設定して長距離モードを有効化する設定 `output_format_compression_zstd_window_log` の2つを追加しました。`INTO OUTFILE` およびテーブル関数 `file`、`url`、`hdfs`、`s3`、`azureBlobStorage` への書き込み時に適用されます。[#58539](https://github.com/ClickHouse/ClickHouse/pull/58539) ([Duc Canh Le](https://github.com/canhld94))。
* 出力先がターミナルでない場合、Pretty フォーマットで ANSI エスケープシーケンスを自動的に無効化するようになりました。設定 `output_format_pretty_color` に新しい `auto` モードを追加しました。[#58614](https://github.com/ClickHouse/ClickHouse/pull/58614) ([Shaun Struwig](https://github.com/Blargian))。
* 設定 `update_insert_deduplication_token_in_dependent_materialized_views` を追加しました。この設定により、依存する materialized view への挿入時に、テーブル識別子を使用して挿入の重複排除トークンを更新できます。[#59165](https://github.com/ClickHouse/ClickHouse/issues/59165) をクローズ。[#59238](https://github.com/ClickHouse/ClickHouse/pull/59238) ([Maksim Kita](https://github.com/kitaisreal))。





<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* cache locality を高めた final 実装。挙動変更に関する注記: 以前は、単一ストリームで読み取る `FINAL` modifier 付きクエリ (例: `max_threads=1`) では、`ORDER BY` clause を明示的に指定しなくてもソート済みの出力が得られていました。この挙動は、`enable_vertical_final = true` の場合は廃止されました (なお、これはデフォルト設定です) 。[#54366](https://github.com/ClickHouse/ClickHouse/pull/54366) ([Duc Canh Le](https://github.com/canhld94)).
* 入力が array(map)/array(array(num)/array(array(string))/array(bigint)/array(decimal) の場合の配列要素関数を最適化。従来の実装では再割り当てが多すぎました。この最適化により、特に入力型が array(map) の場合に約 6 倍高速化されます。[#56403](https://github.com/ClickHouse/ClickHouse/pull/56403) ([李扬](https://github.com/taiyang-li)).
* 余分なデータコピーを避けるため、S3 からの読み取り時 (具体的には `ReadBufferFromIStream`) に `Poco::BasicBufferedStreamBuf` の抽象化をバイパスするようにしました。[#56961](https://github.com/ClickHouse/ClickHouse/pull/56961) ([Nikita Taranov](https://github.com/nickitat)).
* compact パーツで、1 つのカラムから複数の subcolumn を読み取る際に、そのカラムを 1 回だけ読むようにしました。[#57631](https://github.com/ClickHouse/ClickHouse/pull/57631) ([Kruglov Pavel](https://github.com/Avogar)).
* sum(column + literal) 関数の AST を書き換えます。[#57853](https://github.com/ClickHouse/ClickHouse/pull/57853) ([Jiebin Sun](https://github.com/jiebinn)).
* 関数 `match()` の評価で、skipping indices `ngrambf_v1` と `tokenbf_v1` を利用するようになりました。[#57882](https://github.com/ClickHouse/ClickHouse/pull/57882) ([凌涛](https://github.com/lingtaolf)).
* 並列レプリカのデフォルトのコーディネーターを、cache locality 向上のために刷新しました (同じ mark ranges はほぼ常に同じレプリカに割り当てられます) 。work stealing 中にも consistent hash が使用されるため、tail latency の改善が見込まれます。100 個のレプリカで線形スケーラビリティを示すことがテストで確認されています。[#57968](https://github.com/ClickHouse/ClickHouse/pull/57968) ([Nikita Taranov](https://github.com/nickitat)).
* MergeTree FINAL で、同じ non-L0 part 内の行を比較しないようにしました。[#58142](https://github.com/ClickHouse/ClickHouse/pull/58142) ([Duc Canh Le](https://github.com/canhld94)).
* iota 呼び出し (連続した数値で配列を埋める処理) を高速化。[#58271](https://github.com/ClickHouse/ClickHouse/pull/58271) ([Raúl Marín](https://github.com/Algunenano)).
* 関数 `match()` の評価で、転置インデックスを利用するようになりました。[#58284](https://github.com/ClickHouse/ClickHouse/pull/58284) ([凌涛](https://github.com/lingtaolf)).
* 非数値型に対する MIN/MAX を高速化。[#58334](https://github.com/ClickHouse/ClickHouse/pull/58334) ([Raúl Marín](https://github.com/Algunenano)).
* キーなしの aggregation に対して JIT compilation を有効化。[#41461](https://github.com/ClickHouse/ClickHouse/issues/41461) をクローズ。元は [#53757](https://github.com/ClickHouse/ClickHouse/issues/53757)。[#58440](https://github.com/ClickHouse/ClickHouse/pull/58440) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* AVX2 (および BMI2) までをサポートする Intel server 上での **OnTime** の性能実験では、この変更により、ホットスポットである ***DB::MergeTreeRangeReader::ReadResult::optimize*** の cycle ratio を **11.48% から 1.09%**、および **8.09% から 0.67%** にそれぞれ低減し、**Q2** と **Q3** の QPS を **5.0%** および **3.7%** 改善できる一方で、他には影響しないことが示されています。[#58800](https://github.com/ClickHouse/ClickHouse/pull/58800) ([Zhiguo Zhou](https://github.com/ZhiguoZh)).
* `clickhouse-local` で使用する thread を 1 つ減らしました。[#58968](https://github.com/ClickHouse/ClickHouse/pull/58968) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 分散クエリにおいて、`uniqExact` の大きな集約状態が並列にマージされるようになりました。[#59009](https://github.com/ClickHouse/ClickHouse/pull/59009) ([Nikita Taranov](https://github.com/nickitat)).
* `MergeTree` テーブルの読み取り後のメモリ使用量を削減しました。[#59290](https://github.com/ClickHouse/ClickHouse/pull/59290) ([Anton Popov](https://github.com/CurtizJ)).
* vertical merge におけるメモリ使用量を削減しました。[#59340](https://github.com/ClickHouse/ClickHouse/pull/59340) ([Anton Popov](https://github.com/CurtizJ)).





<div id="improvement">
  #### 改善
</div>

* macOS で MySQL/MariaDB を有効化しました。これにより [#21191](https://github.com/ClickHouse/ClickHouse/issues/21191) をクローズします。[#46316](https://github.com/ClickHouse/ClickHouse/pull/46316) ([Robert Schulze](https://github.com/rschu1ze)).
* 先頭に 0 が付いた数値を 8 進数として解釈しないようにしました。[#55575](https://github.com/ClickHouse/ClickHouse/pull/55575) ([Joanna Hulboj](https://github.com/jh0x)).
* std ostream ベースの HTTP 送信バッファリングを CH Buffer に置き換えました。インターフェイス向けにバイト数を計測するメトリクスも追加しました。[#56064](https://github.com/ClickHouse/ClickHouse/pull/56064) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* デフォルトで `max_rows_in_set_to_optimize_join` を無効にしました。[#56396](https://github.com/ClickHouse/ClickHouse/pull/56396) ([vdimir](https://github.com/vdimir)).
* DDLWorker で hostnames の名前解決を回避できる `<host_name>` config parameter を追加しました。これにより、クラスター定義の変更時に queue が詰まる可能性を軽減します。[#57573](https://github.com/ClickHouse/ClickHouse/issues/57573) をクローズします。[#57603](https://github.com/ClickHouse/ClickHouse/pull/57603) ([Nikolay Degterinsky](https://github.com/evillique)).
* ファイルシステムキャッシュ向けに `load_metadata_threads` を 16 に増やしました。これにより server の起動が速くなります。[#57732](https://github.com/ClickHouse/ClickHouse/pull/57732) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 型が Nullable の場合の `multiIf` 関数のパフォーマンスを改善しました。[#57745](https://github.com/ClickHouse/ClickHouse/pull/57745) ([KevinyhZou](https://github.com/KevinyhZou)).
* merges/mutations の帯域幅を制限する機能を追加しました (`max_mutations_bandwidth_for_server`/`max_merges_bandwidth_for_server`) 。[#57877](https://github.com/ClickHouse/ClickHouse/pull/57877) ([Azat Khuzhin](https://github.com/azat)).
* system table `system.server_settings` の未文書化の (boolean) カラム `is_hot_reloadable` を、設定可能な値が `No`、`Yes`、`IncreaseOnly`、`DecreaseOnly` の (Enum8) カラム `changeable_without_restart` に置き換えました。あわせて、このカラムも文書化しました。[#58029](https://github.com/ClickHouse/ClickHouse/pull/58029) ([skyoct](https://github.com/skyoct)).
* ClusterDiscovery で username と password の設定をサポートしました。[#58063](https://github.com/ClickHouse/ClickHouse/issues/58063) をクローズします。[#58123](https://github.com/ClickHouse/ClickHouse/pull/58123) ([vdimir](https://github.com/vdimir)).
* ALTER TABLE ... PART でクエリパラメータをサポートしました。[#58297](https://github.com/ClickHouse/ClickHouse/pull/58297) ([Azat Khuzhin](https://github.com/azat)).
* Kafka table 向けのコンシューマーを必要に応じてその場で作成するようにしました (ただし、最後に使用されてから一定期間 `kafka_consumers_pool_ttl_ms` の間は保持します) 。これにより `system.kafka_consumers` の統計に関する問題 (Kafka table を誰も読み取らない場合は消費が行われず、その結果 live memory leak と table detach の遅延が発生する) を修正できるはずです。また、この PR により `system.kafka_consumers` の統計は再びデフォルトで有効になります。[#58310](https://github.com/ClickHouse/ClickHouse/pull/58310) ([Azat Khuzhin](https://github.com/azat)).
* Sparkbar を sparkbar の alias として追加しました。[#58335](https://github.com/ClickHouse/ClickHouse/pull/58335) ([凌涛](https://github.com/lingtaolf)).
* GCS へのアップロード後に ComposeObject requests を送信しないようにしました。[#58343](https://github.com/ClickHouse/ClickHouse/pull/58343) ([Azat Khuzhin](https://github.com/azat)).
* configurations XMLs において、名前にドットを含むオプションを正しく処理するよう修正しました。[#58354](https://github.com/ClickHouse/ClickHouse/pull/58354) ([Azat Khuzhin](https://github.com/azat)).
* すべてのシステムテーブルの全カラムにコメント (簡単な説明) を追加しました。これにはいくつか理由があります。- システムテーブルは頻繁に使われますが、特定のカラムの役割や意味を開発者が理解するのが非常に難しいことがあります。 - システムテーブルは頻繁に変更され (新しいものの追加や既存のものの変更) 、そのドキュメントは常に古くなりがちです。たとえば、[`system.parts`](https://clickhouse.com/docs/en/operations/system-tables/parts) のドキュメントページを見ると、多くのカラムが抜けています。 - 将来的には、ClickHouse から直接ドキュメントを生成したいと考えています。 [#58356](https://github.com/ClickHouse/ClickHouse/pull/58356) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* あらゆる種類の object storage を、あらゆる種類のメタデータタイプと組み合わせて設定できるようにしました。 [#58357](https://github.com/ClickHouse/ClickHouse/pull/58357) ([Kseniia Sumarokova](https://github.com/kssenii)).
