<div id="clickhouse-release-v209476-stable-fixme-as-compared-to-v209345-stable">
  ### ClickHouse リリース v20.9.4.76-stable FIXME (v20.9.3.45-stable と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#16145](https://github.com/ClickHouse/ClickHouse/issues/16145) にバックポート: クラスター設定の `<internal_replication>` に関係なく、`ALTER ... ON CLUSTER` クエリを実行できるようになりました。[#16075](https://github.com/ClickHouse/ClickHouse/pull/16075) ([alesapin](https://github.com/alesapin)).
* [#16312](https://github.com/ClickHouse/ClickHouse/issues/16312) にバックポート: allow&#95;nondeterministic&#95;optimize&#95;skip&#95;unused&#95;shards を追加しました (シャーディングキーで `rand()` や `dictGet()` などの非決定論的な関数を許可するため) 。[#16105](https://github.com/ClickHouse/ClickHouse/pull/16105) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#15618](https://github.com/ClickHouse/ClickHouse/issues/15618) にバックポート: 単一のパラメータが ReplicatedMergeTree に渡された場合、無視するのではなくエラーをスローするようにしました。[#15516](https://github.com/ClickHouse/ClickHouse/pull/15516) ([nvartolomei](https://github.com/nvartolomei)).
* [#16201](https://github.com/ClickHouse/ClickHouse/issues/16201) にバックポート: read-only テーブルをデタッチする際に `ReadonlyReplica` メトリックをデクリメントするようにしました。これにより [#15598](https://github.com/ClickHouse/ClickHouse/issues/15598) を修正します。[#15592](https://github.com/ClickHouse/ClickHouse/pull/15592) ([sundyli](https://github.com/sundy-li)).
* [#16229](https://github.com/ClickHouse/ClickHouse/issues/16229) にバックポート: S3 table function における glob の不具合を修正しました。URL から取得したリージョンが S3 クライアント設定に適用されていませんでした。[#15646](https://github.com/ClickHouse/ClickHouse/pull/15646) ([Vladimir Chebotarev](https://github.com/excitoon)).
* [#15870](https://github.com/ClickHouse/ClickHouse/issues/15870) にバックポート: 宛先テーブルと異なる構造を持つ `Buffer` テーブルの読み取り中に発生していたエラー `Cannot add simple transform to empty Pipe` を修正しました。この問題は、宛先テーブルがクエリに対して空の結果を返した場合に発生する可能性がありました。[#15529](https://github.com/ClickHouse/ClickHouse/issues/15529) を修正します。[#15662](https://github.com/ClickHouse/ClickHouse/pull/15662) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#15774](https://github.com/ClickHouse/ClickHouse/issues/15774) にバックポート: `max_replicated_logs_to_keep` setting のデフォルト値が低すぎた問題を修正しました。これにより、レプリカが頻繁に失われる可能性がありました。また、最新のレプリカを選んでクローンすることで、失われたレプリカの復旧プロセスを改善しました。さらに、失われたレプリカから古いパーツを削除せず、代わりにデタッチするようにしました。[#15701](https://github.com/ClickHouse/ClickHouse/pull/15701) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#15798](https://github.com/ClickHouse/ClickHouse/issues/15798) にバックポート: 仮想カラムのみが選択される一部のクエリのケースを修正しました。従来は `Not found column _nothing in block` 例外がスローされることがありました。[#12298](https://github.com/ClickHouse/ClickHouse/issues/12298) を修正します。[#15756](https://github.com/ClickHouse/ClickHouse/pull/15756) ([Anton Popov](https://github.com/CurtizJ)).
* [#15868](https://github.com/ClickHouse/ClickHouse/issues/15868) にバックポート: MaterializeMySQL における `select count()` の不正確さを修正しました。[#15767](https://github.com/ClickHouse/ClickHouse/pull/15767) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#15901](https://github.com/ClickHouse/ClickHouse/issues/15901) にバックポート: `ALTER MODIFY COLUMN` クエリの後に実行された `SELECT ... ORDER BY DESC` クエリで発生していた例外 `Block structure mismatch` を修正しました。[#15800](https://github.com/ClickHouse/ClickHouse/issues/15800) を修正します。[#15852](https://github.com/ClickHouse/ClickHouse/pull/15852) ([alesapin](https://github.com/alesapin)).
* [#15924](https://github.com/ClickHouse/ClickHouse/issues/15924) にバックポート: `ALTER MODIFY COLUMN ... DEFAULT ...` のデフォルト値がカラム type と互換性がない場合に、例外がスローされるようになりました。[#15854](https://github.com/ClickHouse/ClickHouse/issues/15854) を修正します。[#15858](https://github.com/ClickHouse/ClickHouse/pull/15858) ([alesapin](https://github.com/alesapin)).
* [#15919](https://github.com/ClickHouse/ClickHouse/issues/15919) にバックポート: RBAC における潜在的なデッドロックを修正しました。[#15875](https://github.com/ClickHouse/ClickHouse/pull/15875) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#16167](https://github.com/ClickHouse/ClickHouse/issues/16167) にバックポート: クエリに `WHERE`、`PREWHERE`、`GLOBAL IN` が含まれている場合に、`Distributed` テーブルに対するクエリが誤って空結果を返す問題を修正しました。[#15792](https://github.com/ClickHouse/ClickHouse/issues/15792) を修正します。[#15933](https://github.com/ClickHouse/ClickHouse/pull/15933) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#16356](https://github.com/ClickHouse/ClickHouse/issues/16356) にバックポート: テーブルが同時にリネームされている場合に `DROP TABLE IF EXISTS` が `Table ... doesn't exist` エラーで失敗する問題を修正しました (Atomic データベースエンジン) 。複数テーブルに対する一部の DDLクエリ (`DROP DATABASE` や `RENAME TABLE` など) を同時実行した際に発生するまれなデッドロックを修正しました。`DROP/DETACH TABLE` の同時実行時に `DROP/DETACH DATABASE` が `Table ... doesn't exist` で失敗する問題を修正しました。[#15934](https://github.com/ClickHouse/ClickHouse/pull/15934) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#15971](https://github.com/ClickHouse/ClickHouse/issues/15971) にバックポート: データベースの作成に失敗した際にクラッシュする問題を修正しました。[#15954](https://github.com/ClickHouse/ClickHouse/pull/15954) ([Winter Zhang](https://github.com/zhang2014))。
* [#16022](https://github.com/ClickHouse/ClickHouse/issues/16022) にバックポート: settings profiles のパースにおける曖昧さを修正しました。`CREATE USER ... SETTINGS profile readonly` は、readonly 制約付きの `profile` という設定名ではなく、`readonly` という名前の profile を使用するものとして扱われるようになりました。これにより [#15628](https://github.com/ClickHouse/ClickHouse/issues/15628) を修正します。[#15982](https://github.com/ClickHouse/ClickHouse/pull/15982) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#16218](https://github.com/ClickHouse/ClickHouse/issues/16218) にバックポート: MaterializedView への insert 中またはそこからの SELECT 中に、ターゲットテーブルが同時に削除されると発生する、まれな segfault を修正しました (Atomic データベースエンジン) 。[#15984](https://github.com/ClickHouse/ClickHouse/pull/15984) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#16026](https://github.com/ClickHouse/ClickHouse/issues/16026) にバックポート: 一定期間非アクティブな状態が続いた後にレプリケーションエラーが発生した場合、レプリカが 5～10 分間ハングする問題を防止しました。[#15987](https://github.com/ClickHouse/ClickHouse/pull/15987) ([filimonov](https://github.com/filimonov))。
* [#16091](https://github.com/ClickHouse/ClickHouse/issues/16091) にバックポート: 複雑なキーを持つ Dictionaries で direct layout を使用できるようにしました。[#16007](https://github.com/ClickHouse/ClickHouse/pull/16007) ([Anton Popov](https://github.com/CurtizJ))。
* [#16361](https://github.com/ClickHouse/ClickHouse/issues/16361) にバックポート: collate 名と charset 名のパーサーを修正し、String type に対する `length = 0` をサポートしました。[#16008](https://github.com/ClickHouse/ClickHouse/pull/16008) ([Winter Zhang](https://github.com/zhang2014))。
* [#16140](https://github.com/ClickHouse/ClickHouse/issues/16140) にバックポート: `ReplicatedVersionedCollapsingMergeTree` における `ALTER MODIFY ... ORDER BY` クエリのハングを修正しました。これにより [#15980](https://github.com/ClickHouse/ClickHouse/issues/15980) を修正します。[#16011](https://github.com/ClickHouse/ClickHouse/pull/16011) ([alesapin](https://github.com/alesapin))。
* [#16079](https://github.com/ClickHouse/ClickHouse/issues/16079) にバックポート: [#15780](https://github.com/ClickHouse/ClickHouse/issues/15780) のリグレッションを修正しました。たとえば、indexOf([1, 2, 3], toLowCardinality(1)) は現在禁止されていますが、本来そのように禁止されるべきではありません。[#16038](https://github.com/ClickHouse/ClickHouse/pull/16038) ([Mike Kot](https://github.com/myrrc))。
* [#16298](https://github.com/ClickHouse/ClickHouse/issues/16298) にバックポート: `sharding&#95;key` 内の `dictGet` (および同様の箇所、つまり関数のコンテキストが永続的に保持される場合) の不具合を修正しました。[#16205](https://github.com/ClickHouse/ClickHouse/pull/16205) ([Azat Khuzhin](https://github.com/azat)).
* [#16232](https://github.com/ClickHouse/ClickHouse/issues/16232) にバックポート: 制限値に関係なくメモリが過剰に割り当てられる場合がある問題を修正しました。これにより [#14560](https://github.com/ClickHouse/ClickHouse/issues/14560) をクローズします。[#16206](https://github.com/ClickHouse/ClickHouse/pull/16206) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* [#16377](https://github.com/ClickHouse/ClickHouse/issues/16377) にバックポート: `prefer&#95;localhost&#95;replica=0` および `internal&#95;replication` 使用時の非同期 Distributed INSERT の不具合を修正しました。[#16358](https://github.com/ClickHouse/ClickHouse/pull/16358) ([Azat Khuzhin](https://github.com/azat)).
* [#16432](https://github.com/ClickHouse/ClickHouse/issues/16432) にバックポート: totals/rollup/cube 修飾子を伴う `GROUP BY` と、GROUP BY キーに対する min/max 関数に関する問題を修正しました。[#16393](https://github.com/ClickHouse/ClickHouse/issues/16393) を修正します。[#16397](https://github.com/ClickHouse/ClickHouse/pull/16397) ([Anton Popov](https://github.com/CurtizJ)).
