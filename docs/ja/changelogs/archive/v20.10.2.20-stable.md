<div id="clickhouse-release-v2010220-stable-fixme-as-compared-to-v20914585-prestable">
  ### ClickHouse リリース v20.10.2.20-stable FIXME (v20.9.1.4585-prestable との比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* SQL で入れ子の複数行コメント `/* comment /* comment */ */` をサポートしました。これは SQL 標準に準拠しています。[#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* `format_regexp_escaping_rule` 設定 (`Regexp` フォーマットに関連) のデフォルト値を `Raw` に変更しました (これはサブパターン全体を 1 つの値として読み取ることを意味します) 。これにより、動作がユーザーの期待により近くなります。[#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)) 。
* `multiple_joins_rewriter_version` は廃止されました。join rewriter の最初のバージョンを削除しました。[#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)) 。



<div id="new-feature">
  #### 新機能
</div>

* 改行、スペース、カンマのいずれかで区切られた line の数列を受け付けるフォーマット `LineAsString` を追加しました。 [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* `formatReadableQuantity` 関数を追加しました。大きな数値を人が読みやすい形で扱うのに便利です。 [#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* カラムのプロパティとテーブル TTL を削除する機能を追加しました。`ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` および `ALTER TABLE REMOVE TTL` というクエリを導入しました。どちらの操作も軽量で、メタデータレベルで実行されます。 [#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* `system.text_log`、`system.trace_log`、`system.query_log`、`system.query_thread_log` テーブルに `event_time_microseconds` フィールドを導入しました。 [#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* クエリコンテキスト内で名前付きサブクエリを導入するため、`WITH <identifier> AS (subquery) ... ` をサポートするようになりました。これにより [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416) をクローズします。これにより [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967) をクローズします。 [#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* config でデフォルト値が指定されている場合、Replicated table engine の引数を省略できるようにしました。 [#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* テーブル関数 `null('structure')` を追加しました。 [#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* クエリ難読化ツールを追加しました。これにより、テスト向けにより多くのクエリを共有できるようになります。これにより [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268) をクローズします。 [#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* フォーマット `RawBLOB` を追加しました。これは、エスケープ処理や区切り文字を使わずに単一の値を入出力することを目的としています。これにより [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349) をクローズします。 [#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [15350](https://github.com/ClickHouse/ClickHouse/issues/15350) を修正しました。 [#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* 最初の select の `WITH` ステートメントを同じレベルの他の select クエリに伝播し、`WITH` ステートメント内の別名をサブクエリから参照可能にする `enable_global_with_statement` 設定を導入しました。 [#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* ビッグエンディアンのバイト文字列を UUID に変換できる `reinterpretAsUUID` 関数を追加しました。 [#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* 並列クォーラム inserts を追加しました。これにより [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601) をクローズします。 [#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* ワイド整数の基本型として `uint64_t` / `int64_t` を使用することで、256 ビット値の処理性能を改善しました。従来のワイド整数では、基本型として 8 ビット型を使用していました。[#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* clickhouse-server の起動時に、`mlock` の対象をコードセグメントのみにしました。以前のバージョンでは、デバッグ情報を含むすべてのマップ済み領域がメモリにロックされていました。デバッグ情報は通常は別ファイルに分離されていますが、そうでない場合はメモリ使用量が 2～3 GiB 増加していました。[#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* これまでは、1 つの FixedString に対する group by で fixed key method を選択していました。しかし、FixedString 型のカラムに対して同様の packedFix 最適化を行う StringHashTable があるため、これは不要です。また、可能であれば low&#95;cardinality&#95;key&#95;fixed&#95;string を使うべきです。[#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* `DateTime <op> DateTime` で、誤って低速な汎用実装が選択されていた問題を修正しました。これにより [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153) も修正されます。 [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* ループ内で複数の DeleteObject を使う代わりに、1 回の S3 DeleteObjects リクエストを使うようにしました。機能面の変更はないため、integration/test&#95;log&#95;family&#95;s3 などの既存テストでカバーされています。 [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* 256 ビット乗算を高速化しました。 [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* `quantileTDigest` の性能を改善しました。これにより [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668) も修正されます。 [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* vertical merge の一時データの保存に、一時ディスクを明示的に使うようにしました。 [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).

* `query_start_time` と `query_start_time_microseconds` を同じ timespec から構築するようにしました。[#14831](https://github.com/ClickHouse/ClickHouse/pull/14831) ([Bharat Nallan](https://github.com/bharatnc)).
* Distributed storage で multi-volume storage configuration を使用できるようにしました。[#14839](https://github.com/ClickHouse/ClickHouse/pull/14839) ([Pavel Kovalenko](https://github.com/Jokser)).
* `EXPLAIN` の結果に `SET` および `JOIN` の subqueries を表示するようにしました。[#14856](https://github.com/ClickHouse/ClickHouse/pull/14856) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* 最初のレプリカを明示的に指定するための `load_balancing_first_offset` クエリ設定を追加しました。これは `FIRST_OR_RANDOM` 負荷分散戦略と併用され、レプリカの workload を制御できます。[#14867](https://github.com/ClickHouse/ClickHouse/pull/14867) ([Amos Bird](https://github.com/amosbird)).
* 分散テーブルに対して SETTINGS 付きで SELECT を実行した際に、過剰に settings constraint 違反が発生する問題を修正しました。[#14876](https://github.com/ClickHouse/ClickHouse/pull/14876) ([Amos Bird](https://github.com/amosbird)).
* 以前の drop の試行が ZooKeeper session の期限切れによって Failed していた場合でも、Replicated テーブルを drop できるようにしました。これにより [#11891](https://github.com/ClickHouse/ClickHouse/issues/11891) を修正します。[#14926](https://github.com/ClickHouse/ClickHouse/pull/14926) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `TinyLog` または `Log` テーブルエンジンのテーブルに対して、自身を対象とする `INSERT SELECT` 実行時のデッドロックを回避しました。これにより [#6802](https://github.com/ClickHouse/ClickHouse/issues/6802) を解決します。[#14962](https://github.com/ClickHouse/ClickHouse/pull/14962) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* mutation 実行時にキー制約を無視するようにしました。この PR がないと、`force_index_by_date = 1` または `force_primary_key = 1` の場合に mutation を実行できません。[#14973](https://github.com/ClickHouse/ClickHouse/pull/14973) ([Amos Bird](https://github.com/amosbird)).
* data part の insert 時に TTL move を無効にするオプションを追加しました。[#15000](https://github.com/ClickHouse/ClickHouse/pull/15000) ([Pavel Kovalenko](https://github.com/Jokser)).
* `Atomic` データベースエンジンをデフォルトで有効にしました。[#15003](https://github.com/ClickHouse/ClickHouse/pull/15003) ([Alexander Tokmakov](https://github.com/tavplubix)).
* CAST の argument の数が誤っている場合に、適切な例外メッセージを表示するようにしました。これにより [#13992](https://github.com/ClickHouse/ClickHouse/issues/13992) を解決します。[#15029](https://github.com/ClickHouse/ClickHouse/pull/15029) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* サブタイプを持つカラムに対して、`Delta`、`T64` などの特殊な codec を指定できるようにしました。[#12551](https://github.com/ClickHouse/ClickHouse/issues/12551) を実装し、[#11397](https://github.com/ClickHouse/ClickHouse/issues/11397) と [#4609](https://github.com/ClickHouse/ClickHouse/issues/4609) を修正します。[#15089](https://github.com/ClickHouse/ClickHouse/pull/15089) ([alesapin](https://github.com/alesapin)).
* `EXPLAIN PLAN` クエリに `optimize` 設定を追加しました。有効にすると、クエリプランレベルの最適化が適用されます。デフォルトで有効です。[#15201](https://github.com/ClickHouse/ClickHouse/pull/15201) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `/docker-entrypoint-initdb.d/` 内のすべての script の実行が完了するまで、ClickHouse server への connection を許可しないようにしました。[#15244](https://github.com/ClickHouse/ClickHouse/pull/15244) ([Aleksei Kozharin](https://github.com/alekseik1)).
* [15264](https://github.com/ClickHouse/ClickHouse/issues/15264) を修正しました。[#15285](https://github.com/ClickHouse/ClickHouse/pull/15285) ([flynn](https://github.com/ucasfl)).

* `Regexp` フォーマットで &quot;Raw&quot; カラムフォーマットをサポートしました。これにより、エスケープ規則なしで subpatterns 全体をそのまま抽出できます。[#15363](https://github.com/ClickHouse/ClickHouse/pull/15363) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `VersionedCollapsingMergeTree` のバージョンカラムの型を `ALTER` クエリで変更できるようになりました。[#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).
* `Atomic` データベースで `NO DELAY` または `SYNC` が指定されている場合、`DROP/DETACH TABLE` が実際に完了するまで待機するようにしました。[#15448](https://github.com/ClickHouse/ClickHouse/pull/15448) ([Alexander Tokmakov](https://github.com/tavplubix)).
* cluster-secure を使用した Distributed 経由で *&#95;for&#95;user settings をそのまま渡すようにしました。[#15551](https://github.com/ClickHouse/ClickHouse/pull/15551) ([Azat Khuzhin](https://github.com/azat)).
