<div id="improvement">
  #### 改善

* [#40817](https://github.com/ClickHouse/ClickHouse/issues/40817) にバックポート: 設定 `show_addresses_in_stack_traces` は、デフォルトの `config.xml` で誤って無効化されていました。現在は config から削除されているため、この設定はデフォルトで有効です。[#40749](https://github.com/ClickHouse/ClickHouse/pull/40749) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#40944](https://github.com/ClickHouse/ClickHouse/issues/40944) にバックポート: MySQL データベースエンジンおよび MySQL table function に MySQL の timeout を渡す際の問題を修正しました。[#34168](https://github.com/ClickHouse/ClickHouse/issues/34168)?notification&#95;referrer&#95;id=NT&#95;kwDOAzsV57MzMDMxNjAzNTY5OjU0MjAzODc5 をクローズしました。[#40751](https://github.com/ClickHouse/ClickHouse/pull/40751) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースでユーザーに影響する不具合)
</div>

* [#40866](https://github.com/ClickHouse/ClickHouse/issues/40866) にバックポート: 可変次元の配列を含む `Object` 型の値のパース中に発生するクラッシュを修正しました。[#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94))。
* [#40805](https://github.com/ClickHouse/ClickHouse/issues/40805) にバックポート: 新しいクエリを `ProcessList` に追加する際に割り当てが発生します。これらの割り当て中にメモリ制限に達すると、`ProcessList::mutex` がすでに取得されているため、`OvercommitTracker` を使用できません。この問題を修正しました。[#40611](https://github.com/ClickHouse/ClickHouse/issues/40611)。[#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd))。
* [#40777](https://github.com/ClickHouse/ClickHouse/issues/40777) にバックポート: クエリコンテキストなしで MV にプッシュする際 (Kafka/... から) のメモリリークを修正しました。[#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat))。
* [#41135](https://github.com/ClickHouse/ClickHouse/issues/41135) にバックポート: `DESCRIBE TABLE url()` および一部の `DESCRIBE TABLE <table_function>()` に対するアクセス権を修正しました。[#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#41242](https://github.com/ClickHouse/ClickHouse/issues/41242) にバックポート: データベースエンジンを Ordinary から Atomic に自動変換する際に発生する &quot;possible deadlock avoided&quot; エラーを修正しました。[#41146](https://github.com/ClickHouse/ClickHouse/pull/41146) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#41234](https://github.com/ClickHouse/ClickHouse/issues/41234) にバックポート: 壊れたデタッチされたパーツのバックグラウンドクリーンアップを修正しました。[#41190](https://github.com/ClickHouse/ClickHouse/pull/41190) ([Kseniia Sumarokova](https://github.com/kssenii))。
