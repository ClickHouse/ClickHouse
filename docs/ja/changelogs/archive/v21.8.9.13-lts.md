<div id="improvement">

* [#29941](https://github.com/ClickHouse/ClickHouse/issues/29941)でバックポート: zoneinfo ファイルを2021cに更新。 [#29925](https://github.com/ClickHouse/ClickHouse/pull/29925) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#29817](https://github.com/ClickHouse/ClickHouse/issues/29817)でバックポート: `insert_allow_materialized_columns=0` の場合でも、分散テーブルの分片キーとしてマテリアライズドカラムを使用できるようにしました。 [#28637](https://github.com/ClickHouse/ClickHouse/pull/28637) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#29973](https://github.com/ClickHouse/ClickHouse/issues/29973)でバックポート: `AccessControlManager` のシャットダウン処理を修正しました。これにより、AccessControlManager が破棄された後に設定が再読み込みされることはなくなりました。この PR は、不安定だったテスト [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html) を修正します。 [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#29676](https://github.com/ClickHouse/ClickHouse/issues/29676) でバックポート: projection part の vertical merge を修正しました。これにより [#29253](https://github.com/ClickHouse/ClickHouse/issues/29253) を修正しています。さらに、この PR では [https://github.com/ClickHouse/ClickHouse/pull/25165](https://github.com/ClickHouse/ClickHouse/pull/25165) で導入された、projection の merge/mutation に関するいくつかの問題も修正しています。[#29337](https://github.com/ClickHouse/ClickHouse/pull/29337) ([Amos Bird](https://github.com/amosbird)).
* [#29538](https://github.com/ClickHouse/ClickHouse/issues/29538) でバックポート: push-down された `HAVING` predicate を含む subqueries で、`Block structure mismatch` が発生する可能性がある問題を修正しました。[#29010](https://github.com/ClickHouse/ClickHouse/issues/29010) を修正しています。[#29475](https://github.com/ClickHouse/ClickHouse/pull/29475) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29589](https://github.com/ClickHouse/ClickHouse/issues/29589) でバックポート: ODBC bridge に、Invalid cursor state エラーに対する再試行を追加しました。これは再試行可能なエラーです。[#29473](https://github.com/ClickHouse/ClickHouse/issues/29473) をクローズしました。[#29518](https://github.com/ClickHouse/ClickHouse/pull/29518) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29593](https://github.com/ClickHouse/ClickHouse/issues/29593) でバックポート: `std::mismatch` の使い方に問題があったため、check `pathStartsWith` の bug を修正しました: ` The behavior is undefined if the second range is shorter than the first range.`。[#29531](https://github.com/ClickHouse/ClickHouse/pull/29531) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29628](https://github.com/ClickHouse/ClickHouse/issues/29628) でバックポート: `x.y.z...` のような `DEFAULT` expression で不正な table Identifier を使用した場合に、`ALTER MODIFY` クエリでまれに segfault が発生する問題を修正しました。[#29184](https://github.com/ClickHouse/ClickHouse/issues/29184) を修正しています。[#29573](https://github.com/ClickHouse/ClickHouse/pull/29573) ([alesapin](https://github.com/alesapin)).
* [#29752](https://github.com/ClickHouse/ClickHouse/issues/29752) でバックポート: push-down 最適化の後に、filter predicate 内の condition が失われることがある問題を修正しました。[#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#29840](https://github.com/ClickHouse/ClickHouse/issues/29840) でバックポート: server の再起動時に `materialized_postgresql_tables_list` setting が正しく動作しない問題を修正しました。[#28529](https://github.com/ClickHouse/ClickHouse/issues/28529) で見つかった問題です。[#29686](https://github.com/ClickHouse/ClickHouse/pull/29686) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#29847](https://github.com/ClickHouse/ClickHouse/issues/29847) でバックポート: `GROUP BY` 中の `LowCardinality` への同時アクセスを修正しました (SIGSEGV につながる可能性があります) 。[#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* [#29911](https://github.com/ClickHouse/ClickHouse/issues/29911) でバックポート: `ATTACH TABLE ... FROM 'path'` クエリで、path の代わりに非文字列 literal を使った場合の不正な cast を修正しました。これにより、未初期化メモリの読み取りにつながる可能性があります。[#29790](https://github.com/ClickHouse/ClickHouse/pull/29790) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#29867](https://github.com/ClickHouse/ClickHouse/issues/29867)でバックポート: ごくまれなケースで、おそらくカーネルの何らかのバグにより発生する `Timeout exceeded: elapsed 18446744073.709553 seconds` エラーを回避するようにしました。[#29154](https://github.com/ClickHouse/ClickHouse/issues/29154) を修正。[#29811](https://github.com/ClickHouse/ClickHouse/pull/29811) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#29877](https://github.com/ClickHouse/ClickHouse/issues/29877)でバックポート: システムテーブル再作成チェックを修正しました (enum 値の変更を検出できない問題) 。[#29857](https://github.com/ClickHouse/ClickHouse/pull/29857) ([Azat Khuzhin](https://github.com/azat)).
* [#30210](https://github.com/ClickHouse/ClickHouse/issues/30210)でバックポート: `FileChecker` と `StorageLog`/`StorageStripeLog` の間で発生し得るデータ競合を修正しました。[#29959](https://github.com/ClickHouse/ClickHouse/pull/29959) ([Azat Khuzhin](https://github.com/azat)).
* [#30069](https://github.com/ClickHouse/ClickHouse/issues/30069)でバックポート: `tuple()` によってサンプルがクラッシュする問題を修正し、[#30004](https://github.com/ClickHouse/ClickHouse/issues/30004) をクローズしました。[#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
* [#30125](https://github.com/ClickHouse/ClickHouse/issues/30125)でバックポート: drop された `Memory` データベースがサーバー再起動後に再び現れることがある問題を修正しました ([#29795](https://github.com/ClickHouse/ClickHouse/issues/29795)) 。また、`Ordinary` データベースの dropping 時に `Directory not empty` エラーが発生した場合の回避策として、`force_remove_data_recursively_on_drop` setting も追加しました (クラウド環境では残存データを手動で削除できないため) 。[#30054](https://github.com/ClickHouse/ClickHouse/pull/30054) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#30263](https://github.com/ClickHouse/ClickHouse/issues/30263)でバックポート: FlatDictionary、HashedDictionary における Nullable 属性の bytes&#95;allocated 計算を修正しました。[#30238](https://github.com/ClickHouse/ClickHouse/pull/30238) ([Maksim Kita](https://github.com/kitaisreal)).
