<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#62898](https://github.com/ClickHouse/ClickHouse/issues/62898) にバックポート: ゼロコピー レプリケーション (実験的機能) で、REPLACE/MOVE PARTITION の後に `The specified key does not exist` エラーやデータ損失を引き起こす可能性がある不具合を修正しました。同様の問題は、ディスク間の TTL による移動でも発生する可能性があります。[#54193](https://github.com/ClickHouse/ClickHouse/pull/54193) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#61964](https://github.com/ClickHouse/ClickHouse/issues/61964) にバックポート: イニシエーター ノードにデータベースが存在しない場合の、ON CLUSTER 句を伴う ATTACH クエリの問題を修正しました。[#55009](https://github.com/ClickHouse/ClickHouse/issues/55009) をクローズします。[#61365](https://github.com/ClickHouse/ClickHouse/pull/61365) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#62527](https://github.com/ClickHouse/ClickHouse/issues/62527) にバックポート: `MOVE PARTITION` クエリとマージ処理の間のデータ競合により、交差するパーツが発生する問題を修正しました。[#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#62238](https://github.com/ClickHouse/ClickHouse/issues/62238) にバックポート: `input_format_allow_errors_num/ratio` 設定の使用中に JSON データをパースする際、エスケープシーケンスのパース error がスキップされる問題を修正しました。[#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar)).
* [#62673](https://github.com/ClickHouse/ClickHouse/issues/62673) にバックポート: Hive テーブルエンジンの使用時に発生するセグメンテーションフォルトを修正しました。参考: [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154), [#62560](https://github.com/ClickHouse/ClickHouse/issues/62560)。[#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)).
