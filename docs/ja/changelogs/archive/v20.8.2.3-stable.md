<div id="clickhouse-release-v20823-stable-fixme-as-compared-to-v20714310-prestable">
  ### ClickHouse release v20.8.2.3-stable FIXME (v20.7.1.4310-prestable と比較)
</div>

<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* `ODBCDriver` 入出力フォーマットのサポートを削除しました。これは以前、ClickHouse ODBC ドライバとの通信用に使用されていた非推奨のフォーマットですが、現在は давно `ODBCDriver2` フォーマットに置き換えられています。 [#13629](https://github.com/ClickHouse/ClickHouse/issues/13629) を解決します。 [#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting)).
* `parallel_distributed_insert_select` setting を拡張し、ローカル table に `INSERT` を実行するオプションを追加しました。この setting の型は `Bool` から `UInt64` に変更されたため、`false` と `true` はサポートされなくなりました。server configuration にこれらの値が含まれていると、server は起動しません。代わりに、それぞれ `0` と `1` に置き換えてください。 [#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat)).
* `OPTIMIZE FINAL` クエリは теперь、TTL が作成される前に追加されたパーツについては有効期限 (TTL) を再計算しません。これらを計算するには、一度 `ALTER TABLE ... MATERIALIZE TTL` を実行してください。その後は `OPTIMIZE FINAL` が有効期限 (TTL) を正しく評価します。この動作はレプリケートテーブルではこれまで機能していませんでした。 [#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### 新機能
</div>

* `MaterializeMySQL` データベースエンジンをサポート。[#4006](https://github.com/ClickHouse/ClickHouse/issues/4006) を実装。[#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014))。
* `krb5` および `cyrus-sasl` ライブラリを使用した Kafka での Kerberos 認証をサポート。[#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn))。
* 型 `Int128`、`Int256`、`UInt256` およびそれらに関連する関数を追加。Decimal256（精度最大76桁）で Decimals を拡張。新しい型は設定 `allow_experimental_bigint_types` で利用可能。[#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2))。
* 関数 `position` がオプションの `start_pos` 引数をサポートするようになった。[#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir))。
* テーブルのサンプル句を変更できる `ALTER SAMPLE BY` ステートメントを追加。[#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird))。
* メインの設定ファイルに新しいオプションセクション <user_directories> を追加。[#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar))。
* リテラル、リテラルの列、および複雑な別名をプレースホルダーに置き換える関数 `normalizeQuery` を追加。類似クエリに対して同一の64ビットハッシュ値を返す関数 `normalizedQueryHash` を追加。クエリログの分析に役立つ。[#11271](https://github.com/ClickHouse/ClickHouse/issues/11271) をクローズ。[#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* `medianExactLow` および `medianExactHigh` の別名をそれぞれ持つ `quantileExactLow` と `quantileExactHigh` の実装を追加。[#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc))。
* 指定した型のデフォルト値を返す関数 `defaultValueOfTypeName` を追加。[#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz))。
* 日付/時刻の値を指定した日付/時刻の単位に切り捨てる関数 `date_trunc` を追加。[#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko))。
* `config.xml` で指定された設定に対応するカラムに `Default` 圧縮コーデックを指定できる機能を追加。[#9074](https://github.com/ClickHouse/ClickHouse/issues/9074) を実装。[#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin))。
* 非常に小さい `index_granularity_bytes` 設定でテーブルを誤って作成することを防ぐ設定 `min_index_granularity_bytes` を追加。[#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc))。
* 整数または Decimal カラムの10進数の桁数を数える関数 `countDigits(x)` を追加。Decimal カラムの値がその（または指定した）精度を超えているかどうかを確認する関数 `isDecimalOverflow(d, [p])` を追加。[#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2))。

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* 単純な `INSERT SELECT` クエリの実行時に、`max_threads` を自動的に 1 または `max_insert_threads` に設定し、`max_block_size` を `min_insert_block_size_rows` に設定するようにしました。[#5907](https://github.com/ClickHouse/ClickHouse/issues/5907) に関連します。[#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* `Array(LowCardinality(T))` と定数の右引数に対して、`has()`、`indexOf()`、`countEqual()` 関数を最適化しました。[#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* UInt8/UInt16 キーによる集約のパフォーマンスをわずかに改善しました。[#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* パーツのスキャン中に `max_rows_to_read` の上限を超えた場合は、即座に失敗するようにしました。この変更の目的は、`max_rows_to_read` がすでに超過していることが明らかな場合に、選択したすべてのパーツに対する範囲スキャンを省略することです。多数のパーツに対するクエリでは、この変更の効果はかなり顕著です。[#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* テーブルエンジン `Null`、`Memory`、`Distributed`、`Buffer` で並列 INSERT を有効にしました。[#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* LowCardinality を使う非常に短いクエリをわずかに最適化しました。[#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).

  #### 改善

* DiskS3 向けの cache レイヤーを追加しました (ローカルディスク上の mark および索引ファイルを cache) 。 [#13076](https://github.com/ClickHouse/ClickHouse/pull/13076) ([Pavel Kovalenko](https://github.com/Jokser)).

* QueryTimeMicroseconds、SelectQueryTimeMicroseconds、InsertQueryTimeMicroseconds を system.events に追加しました。 [#13336](https://github.com/ClickHouse/ClickHouse/pull/13336) ([ianton-ru](https://github.com/ianton-ru)).
* S3 リダイレクトでリモートホストを適切に検証するようにしました (セキュリティ関連) 。 [#13404](https://github.com/ClickHouse/ClickHouse/pull/13404) ([Vladimir Chebotarev](https://github.com/excitoon)).
* mixed granularity パーツをデフォルトで有効にしました。 [#13449](https://github.com/ClickHouse/ClickHouse/pull/13449) ([alesapin](https://github.com/alesapin)).
* パーツを DIskLocal から DiskS3 へ並列に移動できるようにしました。 [#13459](https://github.com/ClickHouse/ClickHouse/pull/13459) ([Pavel Kovalenko](https://github.com/Jokser)).
* カスタム設定で複合識別子をサポートしました。 [#13496](https://github.com/ClickHouse/ClickHouse/pull/13496) ([Vitaly Baranov](https://github.com/vitlibar)).
* より多くのケースで `toDate/toDateTime` 関数の単調性を保証するようにしました。これにより、入力引数がより自然に飽和され、単調性が向上します。 [#13497](https://github.com/ClickHouse/ClickHouse/pull/13497) ([Amos Bird](https://github.com/amosbird)).
* 以前のバージョンでは、`lcm` 関数を特別に細工された引数で呼び出すと、debug build で assertion violation が発生することがありました。これにより [#13368](https://github.com/ClickHouse/ClickHouse/issues/13368) を修正します。 [#13510](https://github.com/ClickHouse/ClickHouse/pull/13510) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* MergeTree の Write-Ahead-Log(WAL) ダンプツールを追加しました。 [#13640](https://github.com/ClickHouse/ClickHouse/pull/13640) ([BohuTANG](https://github.com/BohuTANG)).
* [#14360](https://github.com/ClickHouse/ClickHouse/issues/14360) でバックポート: Redis の requirepass 認証を追加しました。 [#13688](https://github.com/ClickHouse/ClickHouse/pull/13688) ([Ivan Torgashov](https://github.com/it1804)).
* Array がフィールドとして操作される場合にクエリが極端に遅くなるのを防ぐようにしました。代わりに例外をスローします。 [#13753](https://github.com/ClickHouse/ClickHouse/pull/13753) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 1. [GTID ベースのレプリケーション](https://dev.mysql.com/doc/refman/5.7/en/replication-gtids-concepts.html)を追加。これはレプリケーショントポロジーが変更された場合でも機能し、MySQL 5.6/5.7/8.0 でサポートされており、推奨されています 2. BIT/SET フィールド型のサポートを追加 3. varchar 型のメタ長に関するバグを修正しました。[#13820](https://github.com/ClickHouse/ClickHouse/pull/13820) ([BohuTANG](https://github.com/BohuTANG)).
* `lgamma` 関数のデータ競合を修正しました。この競合は `tsan` でのみ検出され、実際の副作用は発生していませんでした。[#13842](https://github.com/ClickHouse/ClickHouse/pull/13842) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* `arrayCompact` 関数では、配列要素の型が Float32/Float64 の場合、NaN をビット単位で比較するようになりました。以前のバージョンでは、配列要素の型が Float32/Float64 の場合は NaN は常に等しくないものとされ、Nullable(Float64) のようにより複雑な型の場合は常に等しいものとされていました。これにより [#13857](https://github.com/ClickHouse/ClickHouse/issues/13857) をクローズします。[#13868](https://github.com/ClickHouse/ClickHouse/pull/13868) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* TabSeparatedRow フォーマットにおける NULL 値のエラーメッセージを改善しました。[#13906](https://github.com/ClickHouse/ClickHouse/pull/13906) ([jiang tao](https://github.com/tomjiang1987)).
* 長いクエリに対する誤ったエラーを修正しました。正しいクエリであっても、`Max query size exceeded` ではなく構文エラーが返されることがありました。[#13928](https://github.com/ClickHouse/ClickHouse/pull/13928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* AvroConfluent フォーマットの不具合を修正しました。この不具合により、異常に小さく不正なメッセージを受信すると、Kafka テーブルエンジンがメッセージ処理を停止することがありました。[#13941](https://github.com/ClickHouse/ClickHouse/pull/13941) ([Gervasio Varela](https://github.com/gervarela)).
* -Resample コンビネータの上限を 1M に引き上げました。[#13947](https://github.com/ClickHouse/ClickHouse/pull/13947) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* 条件付き集約関数 (例: `avgIf`, `sumIf`, `maxIf`) は、行が存在せず、Nullable な引数を使用する場合に `NULL` を返すようにしました。[#13964](https://github.com/ClickHouse/ClickHouse/pull/13964) ([Winter Zhang](https://github.com/zhang2014)).
* 非常に小さな block が大量にある状態で構築された場合の Memory table の性能をわずかに改善しました (この状況はまれです) 。このアイデアの著者: [Mark Papadakis](https://github.com/markpapadakis)。[#14043](https://github.com/ClickHouse/ClickHouse/issues/14043) をクローズします。[#14056](https://github.com/ClickHouse/ClickHouse/pull/14056) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `ALTER TABLE table_name FETCH PARTITION partition_expr FROM 'zk://<host>:<port>/path-in-zookeeper'` が可能になりました。これは新しいクラスターへのデータ移送に役立ちます。[#14155](https://github.com/ClickHouse/ClickHouse/pull/14155) ([Amos Bird](https://github.com/amosbird)).
