<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#68066](https://github.com/ClickHouse/ClickHouse/issues/68066) にバックポート: 外部データベース (`PostgreSQL` などのエンジン) に送信されるクエリ内のブール値リテラルを修正しました。[#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* [#68566](https://github.com/ClickHouse/ClickHouse/issues/68566) にバックポート: fuzzer によって見つかった indexHint 関数のケースを修正しました。[#66286](https://github.com/ClickHouse/ClickHouse/pull/66286) ([Anton Popov](https://github.com/CurtizJ)).
* [#68159](https://github.com/ClickHouse/ClickHouse/issues/68159) にバックポート: inter-server secret 向けの cluster() を修正しました (従来どおり初期 USER を保持) 。[#66364](https://github.com/ClickHouse/ClickHouse/pull/66364) ([Azat Khuzhin](https://github.com/azat)).
* [#68116](https://github.com/ClickHouse/ClickHouse/issues/68116) にバックポート: variant subcolumn の読み取り中に発生する可能性がある PARAMETER&#95;OUT&#95;OF&#95;BOUND エラーを修正しました。[#66659](https://github.com/ClickHouse/ClickHouse/pull/66659) ([Kruglov Pavel](https://github.com/Avogar)).
* [#67887](https://github.com/ClickHouse/ClickHouse/issues/67887) にバックポート: file 名/URI に `::` が含まれている場合、それがアーカイブでなければ正しく解析するようにしました。[#67433](https://github.com/ClickHouse/ClickHouse/pull/67433) ([Antonio Andelic](https://github.com/antonio2368)).
* [#68611](https://github.com/ClickHouse/ClickHouse/issues/68611) にバックポート: [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026) を修正しました。`ReplaceTableNodeToDummyVisitor` で未解決の table function argument の走査を回避します。[#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* [#68275](https://github.com/ClickHouse/ClickHouse/issues/68275) にバックポート: HTTP interface 経由で stream 系エンジン (Kafka、RabbitMQ、NATS) に insert する際の問題を修正しました。[#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#67993](https://github.com/ClickHouse/ClickHouse/issues/67993) にバックポート: ALTER ADD/MODIFY COLUMN において、experimental/suspicious data types を正しく検証するようにしました。[#67911](https://github.com/ClickHouse/ClickHouse/pull/67911) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68208](https://github.com/ClickHouse/ClickHouse/issues/68208) にバックポート: predicate に non-deterministic 関数がある場合に `count()` の結果が誤る問題を修正しました。[#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#68093](https://github.com/ClickHouse/ClickHouse/issues/68093) にバックポート: 使用可能な CPU 数が制限されているコンテナー化環境で、thread の最大 soft limit の計算を修正しました。[#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* [#68124](https://github.com/ClickHouse/ClickHouse/issues/68124) にバックポート: 新しいアナライザで、mutations 実行時に未変更のパーツをスキップする処理を修正しました。従来はアナライザが有効な場合、predicate 上は mutation がその part に影響しなくても、part 内のデータが mutation によって rewritten されることがありました。[#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* [#68221](https://github.com/ClickHouse/ClickHouse/issues/68221) にバックポート: 特別に細工されたクエリによってトリガーされ、hopEnd、hopStart、tumbleEnd、tumbleStart を介して server を crash させる NULL ポインタ逆参照を修正しました。[#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* [#68173](https://github.com/ClickHouse/ClickHouse/issues/68173) にバックポート済み: `OFFSET` を使用するサブクエリでソートを省く誤った最適化を削除しました。[#67906](https://github.com/ClickHouse/ClickHouse/issues/67906) を修正しました。[#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell))。
* [#68339](https://github.com/ClickHouse/ClickHouse/issues/68339) にバックポート済み: クエリがキャンセルされた際に発生する Postgres のクラッシュの修正を試みました。[#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#68396](https://github.com/ClickHouse/ClickHouse/issues/68396) にバックポート済み: クエリ `SYSTEM SYNC REPLICA` で `sync replica mode` が欠落している問題を修正しました。[#68326](https://github.com/ClickHouse/ClickHouse/pull/68326) ([Duc Canh Le](https://github.com/canhld94))。
* [#68668](https://github.com/ClickHouse/ClickHouse/issues/68668) にバックポート済み: 関数 `sipHash64Keyed`、`sipHash128Keyed`、`sipHash128ReferenceKeyed` を空の配列またはタプルに適用した際に発生する `LOGICAL_ERROR` を修正しました。[#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze))。
