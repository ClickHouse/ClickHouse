  # 2022年 変更履歴

<div id="clickhouse-release-v214546-stable-fixme-as-compared-to-v214430-stable">
  ### v21.4.4.30-stable と比較した ClickHouse リリース v21.4.5.46-stable FIXME

<div id="improvement">
  #### 改善
</div>

* [#23273](https://github.com/ClickHouse/ClickHouse/issues/23273) にバックポート: 問題を引き起こす可能性があることを示す根拠があるため、設定 `use_hedged_requests` と `async_socket_for_remote` を無効化しました。[#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#23234](https://github.com/ClickHouse/ClickHouse/issues/23234) にバックポート: デフォルトの profile で `data_type_default_nullable` 設定が有効になっていると server の起動に失敗することがありましたが、修正しました。[#22573](https://github.com/ClickHouse/ClickHouse/issues/22573) を修正。[#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23407](https://github.com/ClickHouse/ClickHouse/issues/23407) にバックポート: subquery が定数に最適化された場合、QueryAliasVisitor が ASTWithAlias に対して alias を優先するよう修正しました。[#22924](https://github.com/ClickHouse/ClickHouse/issues/22924) を修正。[#10401](https://github.com/ClickHouse/ClickHouse/issues/10401) を修正。[#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23382](https://github.com/ClickHouse/ClickHouse/issues/23382) にバックポート: key column に条件を指定して `MaterializeMySQL` から選択する際に発生する `Not found column` error を修正しました。[#22432](https://github.com/ClickHouse/ClickHouse/issues/22432) を修正。[#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23385](https://github.com/ClickHouse/ClickHouse/issues/23385) にバックポート: `input_format_with_names_use_header ` 設定を無効にすると、CSVWithNames フォーマットの入力がすべて破棄されてしまう不具合を修正しました。これにより [#22406](https://github.com/ClickHouse/ClickHouse/issues/22406) を修正。[#23202](https://github.com/ClickHouse/ClickHouse/pull/23202) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#23287](https://github.com/ClickHouse/ClickHouse/issues/23287) にバックポート: 主キーが最初の attribute でない場合、単純 key の Dictionary を DDL から作成できない問題を修正しました。[#23236](https://github.com/ClickHouse/ClickHouse/issues/23236) を修正。[#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* [#23451](https://github.com/ClickHouse/ClickHouse/issues/23451) にバックポート: ReplicatedMergeTree テーブルの作成と削除の間で発生する、ごくまれな (distributed な) race condition を修正しました。これにより、レプリケートテーブル の作成時に `node doesn't exist` のような例外が発生することがありました。[#21419](https://github.com/ClickHouse/ClickHouse/issues/21419) を修正。[#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#23426](https://github.com/ClickHouse/ClickHouse/issues/23426) にバックポート: remote query から `unknown packet` を受信した場合 (`async_socket_for_remote` が有効なとき) に発生しうる crash を修正しました。おそらく [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167) を修正。[#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#23467](https://github.com/ClickHouse/ClickHouse/issues/23467) にバックポート: カラムが主キーに含まれている場合 (またはその単調関数である場合) 、`optimize_read_in_order` 設定がオフになっていないと `ORDER BY` と `COLLATE` が正しく動作しない問題を修正しました。これにより [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379) をクローズ。[#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)). 古いバージョンでの回避策: `optimize_read_in_order` 設定をオフにしてください。
* [#23509](https://github.com/ClickHouse/ClickHouse/issues/23509) でバックポート: 単一の `Tuple` 引数に対する `argMin` および `argMax` のサポートを削除しました。このコードはメモリ安全ではありませんでした。この機能は誤って追加されたもので、利用者に混乱を招くためです。これらの関数は、今後別の名前で再導入される可能性があります。これにより [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) を修正し、[#17359](https://github.com/ClickHouse/ClickHouse/issues/17359) を取り消します。[#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#23478](https://github.com/ClickHouse/ClickHouse/issues/23478) でバックポート: Kafka ストレージで `arrow` および `arrowstream` フォーマットのメッセージをサポートしました。[#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* [#23498](https://github.com/ClickHouse/ClickHouse/issues/23498) でバックポート: - カウンターのリセット時における `deltaSum` 集約関数のバグ修正 ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* [#23492](https://github.com/ClickHouse/ClickHouse/issues/23492) でバックポート: 空の配列リテラルから 2 次元以上の配列に cast できないバグを修正しました。[#14476](https://github.com/ClickHouse/ClickHouse/issues/14476) をクローズしました。[#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)).
