<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング 改善
</div>

* [#55830](https://github.com/ClickHouse/ClickHouse/issues/55830) でバックポート: tgz の sha512 をチェックし、Keeper には適切なリポジトリを使用し、tarball パッケージの TGZ.sha512 ファイルにはファイル名のみを書き込む。[#31473](https://github.com/ClickHouse/ClickHouse/issues/31473) の前提条件。 [#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#55736](https://github.com/ClickHouse/ClickHouse/issues/55736)でバックポート: Iceberg のメタデータのパースを修正しました。delete file がチェックされていませんでした。[#55144](https://github.com/ClickHouse/ClickHouse/pull/55144) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#55969](https://github.com/ClickHouse/ClickHouse/issues/55969)でバックポート: Native ORC 入力フォーマットで発生する可能性のある segfault の修正を試みました。[#55873](https://github.com/ClickHouse/ClickHouse/issues/55873) をクローズします。[#55891](https://github.com/ClickHouse/ClickHouse/pull/55891) ([Kruglov Pavel](https://github.com/Avogar)).
* [#55907](https://github.com/ClickHouse/ClickHouse/issues/55907)でバックポート: スパースなカラムにおけるウィンドウ関数を修正しました。以前は、カラムがスパースな場合、一部のウィンドウ関数を含むクエリで無効な結果が返されたり、ClickHouse がクラッシュしたりしていました。[#55895](https://github.com/ClickHouse/ClickHouse/pull/55895) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
