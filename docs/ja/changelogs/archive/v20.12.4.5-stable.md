<div id="clickhouse-release-v201245-stable-fixme-as-compared-to-v201233-stable">
  ### ClickHouse リリース v20.12.4.5-stable FIXME (v20.12.3.3-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#18392](https://github.com/ClickHouse/ClickHouse/issues/18392) でバックポート: サーバーがデーモンモードで動作していると、`system.stack_trace` テーブルが空になる問題を修正しました。[#17630](https://github.com/ClickHouse/ClickHouse/pull/17630) ([Amos Bird](https://github.com/amosbird))。
* [#18043](https://github.com/ClickHouse/ClickHouse/issues/18043) でバックポート: `topK` 集約関数で発生する可能性がある segfault を修正しました。これにより [#17404](https://github.com/ClickHouse/ClickHouse/issues/17404) はクローズされます。[#17845](https://github.com/ClickHouse/ClickHouse/pull/17845) ([Maksim Kita](https://github.com/kitaisreal))。
* [#18111](https://github.com/ClickHouse/ClickHouse/issues/18111) でバックポート: max&#95;distributed&#95;connections の問題を修正しました (`prefer_localhost_replica=1` および `max_threads!=max_distributed_connections` に影響) 。[#17848](https://github.com/ClickHouse/ClickHouse/pull/17848) ([Azat Khuzhin](https://github.com/azat))。
* [#18021](https://github.com/ClickHouse/ClickHouse/issues/18021) でバックポート: クエリに ARRAY JOIN が含まれている場合 (つまり実際には自明でないクエリ) 、自明なクエリ最適化によって誤った結果が生成される問題を修正しました。[#17887](https://github.com/ClickHouse/ClickHouse/pull/17887) ([sundyli](https://github.com/sundy-li))。
* [#17981](https://github.com/ClickHouse/ClickHouse/issues/17981) でバックポート: [#15187](https://github.com/ClickHouse/ClickHouse/issues/15187) および [#17912](https://github.com/ClickHouse/ClickHouse/issues/17912) を修正し、MaterializeMySQL 向けに MySQL のプレフィックス索引変換をサポートしました。CC: @tavplubix。[#17944](https://github.com/ClickHouse/ClickHouse/pull/17944) ([Winter Zhang](https://github.com/zhang2014))。
* [#18078](https://github.com/ClickHouse/ClickHouse/issues/18078) でバックポート: S3 URL のパース時に発生する `std::out_of_range: basic_string` を修正しました。[#18059](https://github.com/ClickHouse/ClickHouse/pull/18059) ([Vladimir Chebotarev](https://github.com/excitoon))。
* [#18179](https://github.com/ClickHouse/ClickHouse/issues/18179) でバックポート: settings profile を設定しようとした際に発生する `Unknown setting profile` エラーを修正しました。[#18167](https://github.com/ClickHouse/ClickHouse/pull/18167) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#18359](https://github.com/ClickHouse/ClickHouse/issues/18359) でバックポート: [#18186](https://github.com/ClickHouse/ClickHouse/issues/18186) および [#16372](https://github.com/ClickHouse/ClickHouse/issues/16372) を修正し、MaterializeMySQL データベースエンジンにおける unique key 変換時の crash を修正しました。[#18211](https://github.com/ClickHouse/ClickHouse/pull/18211) ([Winter Zhang](https://github.com/zhang2014))。
* [#18258](https://github.com/ClickHouse/ClickHouse/issues/18258) でバックポート: Enum 型と Int 型の間のキー比較を修正しました。これにより [#17989](https://github.com/ClickHouse/ClickHouse/issues/17989) を修正します。[#18214](https://github.com/ClickHouse/ClickHouse/pull/18214) ([Amos Bird](https://github.com/amosbird))。
* [#18296](https://github.com/ClickHouse/ClickHouse/issues/18296) でバックポート: - デュアル IPv4/IPv6 スタック構成のマシンで、サーバーから `clickhouse-odbc-bridge` プロセスに到達できない問題を修正しました。 - ODBC Dictionary の更新時に、不正なクエリが使用されたりクラッシュが発生したりする問題を修正しました。[#14489](https://github.com/ClickHouse/ClickHouse/issues/14489) をクローズした可能性があります。[#18278](https://github.com/ClickHouse/ClickHouse/pull/18278) ([Denis Glazachev](https://github.com/traceon))。
