<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#17590](https://github.com/ClickHouse/ClickHouse/issues/17590) にバックポート: 非常に多くの `MergeTree` テーブルにまたがる `Merge` テーブルからの読み取り性能を修正しました。[#7748](https://github.com/ClickHouse/ClickHouse/issues/7748) を修正。[#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#17316](https://github.com/ClickHouse/ClickHouse/issues/17316) にバックポート: MySQL プロトコル経由の INSERT クエリで、影響を受けた行数を返すように修正しました。これまで ClickHouse は常に 0 を返していました。[#16605](https://github.com/ClickHouse/ClickHouse/issues/16605) を修正。[#16715](https://github.com/ClickHouse/ClickHouse/pull/16715) ([Winter Zhang](https://github.com/zhang2014)).
* [#17343](https://github.com/ClickHouse/ClickHouse/issues/17343) にバックポート: TODO. [#16866](https://github.com/ClickHouse/ClickHouse/pull/16866) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#17196](https://github.com/ClickHouse/ClickHouse/issues/17196) にバックポート: `LIMIT` を含むクエリなど、実行中にキャンセルされる可能性があるリモートクエリで、不要なネットワークエラーが発生しないようにしました。[#17006](https://github.com/ClickHouse/ClickHouse/pull/17006) ([Azat Khuzhin](https://github.com/azat)).
* [#17432](https://github.com/ClickHouse/ClickHouse/issues/17432) にバックポート: 関数 fuzzBits のバグ修正。関連 issue: [#16980](https://github.com/ClickHouse/ClickHouse/issues/16980)。[#17051](https://github.com/ClickHouse/ClickHouse/pull/17051) ([hexiaoting](https://github.com/hexiaoting)).
* [#17129](https://github.com/ClickHouse/ClickHouse/issues/17129) にバックポート: `some_table` が `AS table_function()` で作成されている場合に、`CREATE TABLE ... AS some_table` クエリで発生するクラッシュを修正。[#16944](https://github.com/ClickHouse/ClickHouse/issues/16944) を修正。[#17072](https://github.com/ClickHouse/ClickHouse/pull/17072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#17195](https://github.com/ClickHouse/ClickHouse/issues/17195) にバックポート: クラッシュの原因となる ColumnConst の比較を修正。これにより [#17088](https://github.com/ClickHouse/ClickHouse/issues/17088) を修正。[#17135](https://github.com/ClickHouse/ClickHouse/pull/17135) ([Amos Bird](https://github.com/amosbird)).
* [#17402](https://github.com/ClickHouse/ClickHouse/issues/17402) にバックポート: [#15235](https://github.com/ClickHouse/ClickHouse/issues/15235) を修正。clickhouse-copier がパーティション化されていないテーブルを処理する際に segfault が発生する問題を修正しました。[#17248](https://github.com/ClickHouse/ClickHouse/pull/17248) ([Qi Chen](https://github.com/kaka11chen)).
* [#17409](https://github.com/ClickHouse/ClickHouse/issues/17409) にバックポート: サブクエリ内に const カラムがある場合の set index の無効化を修正。これにより [#17246](https://github.com/ClickHouse/ClickHouse/issues/17246) を修正。[#17249](https://github.com/ClickHouse/ClickHouse/pull/17249) ([Amos Bird](https://github.com/amosbird)).
* [#17488](https://github.com/ClickHouse/ClickHouse/issues/17488) にバックポート: `LowCardinality` 型を持つ `JOIN` table の読み取り時に発生するクラッシュを修正。[#17228](https://github.com/ClickHouse/ClickHouse/issues/17228) を修正。[#17397](https://github.com/ClickHouse/ClickHouse/pull/17397) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17492](https://github.com/ClickHouse/ClickHouse/issues/17492) にバックポート: 不適切な最適化により発生し得た `DISTINCT` 後の重複を修正。[#17294](https://github.com/ClickHouse/ClickHouse/issues/17294) を修正。[#17296](https://github.com/ClickHouse/ClickHouse/pull/17296) ([li chengxiang](https://github.com/chengxianglibra)). [#17439](https://github.com/ClickHouse/ClickHouse/pull/17439) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17522](https://github.com/ClickHouse/ClickHouse/issues/17522) にバックポート: `optimize_redundant_functions_in_order_by` 設定が有効な場合の `ORDER BY` の不具合を修正しました。[#17471](https://github.com/ClickHouse/ClickHouse/pull/17471) ([Anton Popov](https://github.com/CurtizJ)).
* [#17535](https://github.com/ClickHouse/ClickHouse/issues/17535) にバックポート: ClickHouse における mark cache サイズの見積もりが過小になるバグを修正しました。この問題は、marks を持つ非常に小さなファイルが大量にある場合に発生する可能性があります。[#17496](https://github.com/ClickHouse/ClickHouse/pull/17496) ([alesapin](https://github.com/alesapin)).
* [#17627](https://github.com/ClickHouse/ClickHouse/issues/17627) にバックポート: 別のレプリカで対応する mutation が停止された場合に、alter クエリがハングする問題を修正しました。[#16953](https://github.com/ClickHouse/ClickHouse/issues/16953) を修正。[#17499](https://github.com/ClickHouse/ClickHouse/pull/17499) ([alesapin](https://github.com/alesapin)).
* [#17608](https://github.com/ClickHouse/ClickHouse/issues/17608) にバックポート: clickhouse-client を対話型モードで複数行クエリに使用した際、単一行コメントが誤ってクエリの末尾まで延長されていました。これにより [#13654](https://github.com/ClickHouse/ClickHouse/issues/13654) を修正しました。[#17565](https://github.com/ClickHouse/ClickHouse/pull/17565) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#17729](https://github.com/ClickHouse/ClickHouse/issues/17729) にバックポート: Windows Subsystem for Linux 上で実行される ClickHouse の `Atomic` データベースで `RENAME` クエリを実行した際に発生する `Function not implemented` エラーを修正しました。[#17661](https://github.com/ClickHouse/ClickHouse/issues/17661) を修正。[#17664](https://github.com/ClickHouse/ClickHouse/pull/17664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#17782](https://github.com/ClickHouse/ClickHouse/issues/17782) にバックポート: ClickHouse が MySQL server への connection の再開に失敗する問題を修正しました。[#17681](https://github.com/ClickHouse/ClickHouse/pull/17681) ([Alexander Kazakov](https://github.com/Akazz)).
* [#17814](https://github.com/ClickHouse/ClickHouse/issues/17814) にバックポート: `in_memory_parts_enable_wal` が無効な場合、WAL からパーツを restore しないようにしました。[#17802](https://github.com/ClickHouse/ClickHouse/pull/17802) ([detailyang](https://github.com/detailyang)).
