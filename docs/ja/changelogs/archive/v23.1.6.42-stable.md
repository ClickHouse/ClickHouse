<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#48215](https://github.com/ClickHouse/ClickHouse/issues/48215)でバックポート: ccache の代替として sccache を使用し、cache バックエンドとして S3 を使用します。[#46240](https://github.com/ClickHouse/ClickHouse/pull/46240) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。
* [#48254](https://github.com/ClickHouse/ClickHouse/issues/48254)でバックポート: `clickhouse/clickhouse-keeper` イメージは、これまで `-alpine` タグ (例: `latest-alpine`) でのみ push されていました。[https://github.com/ClickHouse/examples/pull/2](https://github.com/ClickHouse/examples/pull/2) で提案されたとおり、今後は接尾辞なしでも push されます。[#48236](https://github.com/ClickHouse/ClickHouse/pull/48236) ([Mikhail f. Shiryaev](https://github.com/Felixoid))。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* CROSS JOIN と algorithm = auto で発生する NOT&#95;IMPLEMENTED エラーを修正 [#47068](https://github.com/ClickHouse/ClickHouse/pull/47068) ([Vladimir C](https://github.com/vdimir)).
* 別名を含む式に対して、論理式オプティマイザを無効化しました。 [#47451](https://github.com/ClickHouse/ClickHouse/pull/47451) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* クエリパラメータの不具合を修正 [#47488](https://github.com/ClickHouse/ClickHouse/pull/47488) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* パラメーター化ビューのバグ修正 47287 47247 [#47495](https://github.com/ClickHouse/ClickHouse/pull/47495) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).

* HTTP で警告が詳細すぎる問題に対するホットフィックス [#47903](https://github.com/ClickHouse/ClickHouse/pull/47903) ([Alexander Tokmakov](https://github.com/tavplubix)).
