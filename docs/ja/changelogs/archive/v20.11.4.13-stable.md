<div id="clickhouse-release-v2011413-stable-fixme-as-compared-to-v201133-stable">
  ### ClickHouse リリース v20.11.4.13-stable FIXME (v20.11.3.3-stable と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#17032](https://github.com/ClickHouse/ClickHouse/issues/17032)でバックポート: SNI を必要とする `clickhouse-server` のセキュアなエンドポイントに接続できるようになりました。これは、`clickhouse-server` が TLS プロキシの背後でホストされている場合に可能です。 [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#17074](https://github.com/ClickHouse/ClickHouse/issues/17074)でバックポート: &#39;if&#39; 接尾辞付き集約関数の使用時に remote query が失敗する問題を修正。 [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574)、[#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) を修正。 [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* [#17024](https://github.com/ClickHouse/ClickHouse/issues/17024)でバックポート: 引数なしで `any` を使用した際のクラッシュを修正。これは [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803) 向けです。 cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* [#16881](https://github.com/ClickHouse/ClickHouse/issues/16881)でバックポート: WriteBufferFromS3 にデータがまったく書き込まれなかった場合、multipart upload を中止するようにしました。 [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#16948](https://github.com/ClickHouse/ClickHouse/issues/16948)でバックポート: TimeSeriesGroupSum の使用時に ClickHouse server がクラッシュしないようにしました。 [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* [#17076](https://github.com/ClickHouse/ClickHouse/issues/17076)でバックポート: `ORDER BY` を含むクエリで発生する可能性がある `Illegal type of argument` エラーを修正。 [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580) を修正。 [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17010](https://github.com/ClickHouse/ClickHouse/issues/17010)でバックポート: install script が config フォルダ内に常にサブディレクトリを作成するよう修正。これはカスタム config を使用する Docker build にのみ関係します。 [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* [#16966](https://github.com/ClickHouse/ClickHouse/issues/16966)でバックポート: `clickhouse-git-import` で blame 情報が正しく計算されていなかった問題を修正。 [#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#17014](https://github.com/ClickHouse/ClickHouse/issues/17014)でバックポート: `ALTER TABLE ... MODIFY COLUMN ... NewType` の実行後、変更対象のカラムに対する `WHERE` expression を含む `SELECT` があり、alter がまだ完了していない場合に発生する可能性がある server クラッシュを修正。 [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* [#17039](https://github.com/ClickHouse/ClickHouse/issues/17039)でバックポート: エラー時に `format_avro_schema_registry_url` の IP を再解決するようにしました。 [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* [#17093](https://github.com/ClickHouse/ClickHouse/issues/17093)でバックポート: double からキャストする際に、大きな整数 (128, 256 bit) で誤った結果になる問題を修正。 [#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc)).
* [#17127](https://github.com/ClickHouse/ClickHouse/issues/17127)でバックポート: `LIMIT` を含むクエリなど、実行中にキャンセルされる可能性がある remote query で不要なネットワークエラーを回避。 [#17006](https://github.com/ClickHouse/ClickHouse/pull/17006) ([Azat Khuzhin](https://github.com/azat)).
* [#17132](https://github.com/ClickHouse/ClickHouse/issues/17132) でバックポート: `some_table` が `AS table_function()` で作成されている場合に、`CREATE TABLE ... AS some_table` クエリでクラッシュする問題を修正。[#16944](https://github.com/ClickHouse/ClickHouse/issues/16944) を修正。[#17072](https://github.com/ClickHouse/ClickHouse/pull/17072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#17170](https://github.com/ClickHouse/ClickHouse/issues/17170) でバックポート: leader ではない ReplicatedMergeTreeTables で、`ON CLUSTER` クエリが永久にハングすることがある不具合を修正。[#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
