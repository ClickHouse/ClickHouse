  # 2025年 変更履歴

<div id="clickhouse-release-v251825-stable-990179ead8b-fixme-as-compared-to-v251720-stable-dcc6b0a7384">
  ### ClickHouse リリース v25.1.8.25-stable (990179ead8b) FIXME v25.1.7.20-stable (dcc6b0a7384) と比較して
</div>

<div id="new-feature">
  #### 新機能
</div>

* [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357) でバックポート: 同時実行クエリ間での CPU スロットの配分を制御する `concurrent_threads_scheduler` サーバー設定を追加しました。`round_robin` (従来の動作) または `fair_round_robin` に設定でき、`INSERT` と `SELECT` の間で CPU が不公平に配分される問題に対処します。[#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)) 。

<div id="improvement">
  #### 改善
</div>

* [#77202](https://github.com/ClickHouse/ClickHouse/issues/77202)でバックポート: 以前は Replicated データベースで、クエリで指定した認証情報がログに出力されることがありました。この挙動を修正しました。これにより [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123) をクローズします。 [#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#76151](https://github.com/ClickHouse/ClickHouse/issues/76151)でバックポート: Native format における JSON の文字列フォーマットに、フォーマット設定が伝播されるよう修正。 [#75832](https://github.com/ClickHouse/ClickHouse/pull/75832) ([Pavel Kruglov](https://github.com/Avogar)).
* [#76968](https://github.com/ClickHouse/ClickHouse/issues/76968)でバックポート: 分散テーブルからブール値リテラルを選択した際に発生する THERE&#95;IS&#95;NO&#95;COLUMN Exception を修正。 [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* [#77256](https://github.com/ClickHouse/ClickHouse/issues/77256)でバックポート: 非同期 INSERT 中にエラーが発生した際、JSON column の不正なロールバックによって起こりうるクラッシュを修正。 [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77220](https://github.com/ClickHouse/ClickHouse/issues/77220)でバックポート: part の整合性チェックで一時的な subcolumns をスキップする check を追加し、variant subcolumn を含む json の不具合を修正。 [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* [#77248](https://github.com/ClickHouse/ClickHouse/issues/77248)でバックポート: Exception 発生時の Kafka table 作成中に起きるクラッシュを修正。 [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* [#77384](https://github.com/ClickHouse/ClickHouse/issues/77384)でバックポート: `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` が、従来の `false` ではなく、正しく `true` を返すようになりました。これにより、`Float32` および `Float64` と一貫した動作になります。 [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#77333](https://github.com/ClickHouse/ClickHouse/issues/77333)でバックポート: Nullable 要素を含む Tuples と文字列の比較を修正。 [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
