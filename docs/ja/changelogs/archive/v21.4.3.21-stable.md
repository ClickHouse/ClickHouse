  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v214321-stable-fixme-as-compared-to-v214210-prestable">
  ### ClickHouse リリース v21.4.3.21-stable FIXME (v21.4.2.10-prestable と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#22934](https://github.com/ClickHouse/ClickHouse/issues/22934) でバックポート: 非同期 distributed ブロックの構造が正しくチェックされるよう修正しました。[#22325](https://github.com/ClickHouse/ClickHouse/pull/22325) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#22966](https://github.com/ClickHouse/ClickHouse/issues/22966) にバックポート: deduplication により、`quorum_parallel=1` でのクォーラム insert が実際には &quot;quorum&quot; ではなくなってしまう、ごくまれなバグを修正しました。[#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* [#22722](https://github.com/ClickHouse/ClickHouse/issues/22722) にバックポート: table function view がカラムとして使用されているかどうかをチェックするようにしました。これは [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350) を補完するものです。[#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* [#22808](https://github.com/ClickHouse/ClickHouse/issues/22808) にバックポート: [#21936](https://github.com/ClickHouse/ClickHouse/issues/21936) の追加修正です。[#22433](https://github.com/ClickHouse/ClickHouse/issues/22433) もあわせて修正します。[#22518](https://github.com/ClickHouse/ClickHouse/pull/22518) ([Ivan](https://github.com/abyss7)).
* [#22757](https://github.com/ClickHouse/ClickHouse/issues/22757) にバックポート: distributed queries での function `map` の使用に関する問題を修正しました。[#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* [#22702](https://github.com/ClickHouse/ClickHouse/issues/22702) にバックポート: ReplicatedMergeTree table engines において、複数のレプリカで mutations の完了を待機する処理を修正しました。以前は、mutation/alter query が、他のレプリカで mutation が実際に実行される前に終了してしまうことがありました。[#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* [#22741](https://github.com/ClickHouse/ClickHouse/issues/22741) にバックポート: OOM exception 発生時に zk requests がハングする可能性がある問題を修正しました。[#22438](https://github.com/ClickHouse/ClickHouse/issues/22438) も修正します。[#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#22888](https://github.com/ClickHouse/ClickHouse/issues/22888) にバックポート: MergeTree の逆方向読み取りにおける概算総行数の計上を修正しました。[#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* [#22884](https://github.com/ClickHouse/ClickHouse/issues/22884) にバックポート: filter カラムが aggregation で使用される場合の `HAVING` の pushdown を修正しました。[#22763](https://github.com/ClickHouse/ClickHouse/pull/22763) ([Anton Popov](https://github.com/CurtizJ)).
* [#22917](https://github.com/ClickHouse/ClickHouse/issues/22917) にバックポート: LIVE VIEW (Experimental Feature) 。`TemporaryLiveViewCleaner` における TEMPORARY LIVE VIEW の同時実行 DROP/CREATE でハングする可能性がある問題を修正しました。詳細は [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e) を参照してください。[#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#22921](https://github.com/ClickHouse/ClickHouse/issues/22921) にバックポート: window functions で `mannWhitneyUTest` と `rankCorr` を使用した際にクラッシュする問題を修正しました。これにより [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728) も修正されます。[#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#22957](https://github.com/ClickHouse/ClickHouse/issues/22957) にバックポート: Nullable な値を持つ `Map` 型の定数カラムの使用に関する不具合を修正しました。[#22939](https://github.com/ClickHouse/ClickHouse/pull/22939) ([Anton Popov](https://github.com/CurtizJ)).
