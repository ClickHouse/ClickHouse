  # 2023年の変更履歴
</div>

<div id="clickhouse-release-v2281717-lts-df7f2ef0b41-fixme-as-compared-to-v2281632-lts-7c4be737bd0">
  ### ClickHouse リリース v22.8.17.17-lts (df7f2ef0b41) FIXME v22.8.16.32-lts (7c4be737bd0) との比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#48157](https://github.com/ClickHouse/ClickHouse/issues/48157) にバックポート済み: 利用できない依存テーブルがある materialized view へのアタッチ時に `UNKNOWN_TABLE` 例外が発生していた問題を修正しました。これは、バックアップから状態を復元しようとする際に役立つ可能性があります。[#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージングの改善
</div>

* [#48957](https://github.com/ClickHouse/ClickHouse/issues/48957) でバックポート済み: 最近の更新以降、`dockerd` では http ポートを明示的に指定するとともに、`--tlsverify=false` も必要になりました。[#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* projection を含む explain graph の不具合を修正 [#47473](https://github.com/ClickHouse/ClickHouse/pull/47473) ([flynn](https://github.com/ucasfl)).
* ある feature を削除 [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* cache で発生する可能性がある segfault を修正 [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* ACL で `auth` 認証スキームを指定してもノードが作成されないことがある Keeper の不具合を修正 [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
