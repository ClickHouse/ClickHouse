<div id="bug-fix">
  #### バグ修正
</div>

* [#25851](https://github.com/ClickHouse/ClickHouse/issues/25851) にバックポート: `Date` から `DateTime` (または `DateTime64`) への `CAST` で、`DateTime` 型のタイムゾーンが使用されていませんでした。これは `Date` と `DateTime` の比較にも影響する可能性があります。`Date` と `DateTime` の共通型の推論でも、対応するタイムゾーンが使用されていませんでした。これにより、関数 `if` と配列構築の結果に影響していました。[#24128](https://github.com/ClickHouse/ClickHouse/issues/24128) をクローズします。[#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* [#25678](https://github.com/ClickHouse/ClickHouse/issues/25678) にバックポート: 乱数生成器の state のデシリアライゼーションのバグを修正しました。このバグにより、`AggregateFunction(groupArraySample(N), T))` などの一部のデータ型が非決定論的に動作する可能性がありました。[#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25637](https://github.com/ClickHouse/ClickHouse/issues/25637) にバックポート: クエリ `WITH TOTALS` および `WITH FILL` の totals が誤っていた問題を修正しました。[#20872](https://github.com/ClickHouse/ClickHouse/issues/20872) を修正します。[#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* [#25651](https://github.com/ClickHouse/ClickHouse/issues/25651) にバックポート: クエリなしの `EXPLAIN AST` で発生する null pointer dereference を修正しました。[#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#25716](https://github.com/ClickHouse/ClickHouse/issues/25716) にバックポート: まれに、ソースパーティションが空の場合に `REPLACE PARTITION` が無視されることがありました。この問題を修正しました。[#24869](https://github.com/ClickHouse/ClickHouse/issues/24869) を修正します。[#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#25712](https://github.com/ClickHouse/ClickHouse/issues/25712) にバックポート: `Distributed` テーブルをデータベース間で移動する際に発生する `No such file or directory` error を修正しました。[#24971](https://github.com/ClickHouse/ClickHouse/issues/24971) を修正します。[#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
