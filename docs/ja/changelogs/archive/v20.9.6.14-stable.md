<div id="clickhouse-release-v209614-stable-fixme-as-compared-to-v20955-stable">
  ### ClickHouse リリース v20.9.6.14-stable FIXME (v20.9.5.5-stable と比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#17030](https://github.com/ClickHouse/ClickHouse/issues/17030) でバックポート: SNI が必要な `clickhouse-server` のセキュアなエンドポイントに接続できるようになりました。これは、`clickhouse-server` が TLS プロキシの背後でホストされている場合に利用できます。[#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#15678](https://github.com/ClickHouse/ClickHouse/issues/15678) でバックポート: 例外発生時にクエリがより速く終了するよう改善しました。例外が発生した場合は、リモートレプリカでの実行をキャンセルします。[#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* [#17105](https://github.com/ClickHouse/ClickHouse/issues/17105) でバックポート: [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) および [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) を修正しました。&#39;if&#39; 接尾辞付き aggregate function の使用時に remote query が失敗する問題を修正しました。[#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* [#16759](https://github.com/ClickHouse/ClickHouse/issues/16759) でバックポート: max&#95;threads&gt;0 で、かつ ORDER BY に expression がある場合の optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order を修正しました。[#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* [#16740](https://github.com/ClickHouse/ClickHouse/issues/16740) でバックポート: `transform_null_in` setting が有効な場合の、複数カラムおよび tuples に対する `IN` operator を修正しました。[#15310](https://github.com/ClickHouse/ClickHouse/issues/15310) を修正。[#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* [#17023](https://github.com/ClickHouse/ClickHouse/issues/17023) でバックポート: 引数なしで `any` を使用した際に発生する crash を修正しました。これは [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803) 向けです。cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* [#16879](https://github.com/ClickHouse/ClickHouse/issues/16879) でバックポート: WriteBufferFromS3 にデータがまったく書き込まれなかった場合、multipart upload を中止するようにしました。[#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* [#16945](https://github.com/ClickHouse/ClickHouse/issues/16945) でバックポート: TimeSeriesGroupSum の使用時に ClickHouse server が crash しないようにしました。[#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* [#17078](https://github.com/ClickHouse/ClickHouse/issues/17078) でバックポート: `ORDER BY` を含む queries で発生する可能性がある `Illegal type of argument` error を修正しました。[#16580](https://github.com/ClickHouse/ClickHouse/issues/16580) を修正。[#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#17009](https://github.com/ClickHouse/ClickHouse/issues/17009) でバックポート: install script が config フォルダ内に常にサブディレクトリを作成するようにしました。これは custom config を使用する Docker build にのみ関係します。[#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* [#17013](https://github.com/ClickHouse/ClickHouse/issues/17013) でバックポート: `ALTER TABLE ... MODIFY COLUMN ... NewType` の後、`SELECT` に変更対象カラムに対する `WHERE` expression があり、alter がまだ完了していない場合に発生する可能性がある server crash を修正しました。[#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* [#17037](https://github.com/ClickHouse/ClickHouse/issues/17037) でバックポート: error 発生時に `format_avro_schema_registry_url` の IP を再解決するようにしました。[#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* [#17172](https://github.com/ClickHouse/ClickHouse/issues/17172) にバックポート: 非リーダーの ReplicatedMergeTreeTables で `ON CLUSTER` クエリが永久にハングする場合がある不具合を修正。 [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
