  ### ClickHouse リリース v20.9.5.5-stable FIXME (v20.9.4.76-stable との比較)
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493) でバックポート: MySQL データベースに関するバグを修正しました。データベースエンジンとして使用されている MySQL server が停止していると、一部のクエリが本来不要であるにもかかわらず無効化された server からテーブルを取得しようとして Exception を発生させることがありました。たとえば、クエリ `SELECT ... FROM system.parts` は MergeTree テーブルに対してのみ動作し、MySQL データベースにはまったくアクセスしないはずです。[#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817) でバックポート: フィルタリング用の Set が作成されていないために返却データの一部が欠落することがある、一貫性のない動作を修正しました。[#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508) でバックポート: レプリケーションキュー内の非常に大きなエントリの処理を修正しました。テーブル構造が極端に大きい (1 MB 近い) 場合、ALTER クエリで非常に大きなエントリが発生することがあります。これにより [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307) を修正します。[#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474) でバックポート: Distributed に対する DROP TABLE を修正しました (INSERT との競合状態) 。[#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571) でバックポート: MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine を使用し、かつ MySQL Slave で `slave_parallel_worker` が有効になっている場合に、GTID set を適切に縮小することでメタデータが急増する問題を修正しました。これにより [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951) を修正します。[#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554) でバックポート: 入力から AVRO をパースする際、型から LowCardinality が削除されるようになりました。[#16188](https://github.com/ClickHouse/ClickHouse/issues/16188) を修正します。[#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748) でバックポート: [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081) を修正しました。[#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894) でバックポート: クエリプロファイラが有効な状態で、glibc のバージョンによっては (一部の関数でおそらく壊れた asynchronous unwind tables を持つため) 、ClickHouse がまれに無言でクラッシュする問題を修正しました。これにより [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301) を修正します。これにより [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098) も修正します。[#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
