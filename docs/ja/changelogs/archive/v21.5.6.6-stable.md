<div id="bug-fix">
  #### バグ修正
</div>

* [#24170](https://github.com/ClickHouse/ClickHouse/issues/24170) にバックポート: まれに、部分的にしか初期化されていないテーブルが書き込みリクエスト (insert/alter など) を受け付けてしまうバグを修正しました。現在、そのようなテーブルは readonly モードになります。[#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* [#24332](https://github.com/ClickHouse/ClickHouse/issues/24332) にバックポート: StorageMemory の mutation 失敗を修正するため、`max_threads = 1` を設定しました。[#24274](https://github.com/ClickHouse/ClickHouse/issues/24274) をクローズします。[#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)).
* [#24382](https://github.com/ClickHouse/ClickHouse/issues/24382) にバックポート: 空の HTTP headers を許可するようにしました。[#23901](https://github.com/ClickHouse/ClickHouse/issues/23901) を修正します。[#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* [#24351](https://github.com/ClickHouse/ClickHouse/issues/24351) にバックポート: Ordinary database から Atomic database へ Materialized View を移動する際のバグ (`RENAME TABLE` クエリ) を修正しました。これにより、内部テーブルも Materialized View とともに新しい database へ移動されます。[#23926](https://github.com/ClickHouse/ClickHouse/issues/23926) を修正します。[#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#24509](https://github.com/ClickHouse/ClickHouse/issues/24509) にバックポート: intersect fake パーツ に対するパーティションの削除を修正しました。まれに、現在のブロック番号より大きい mutation バージョンを持つパーツが存在することがありました。[#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* [#24540](https://github.com/ClickHouse/ClickHouse/issues/24540) にバックポート: toWeek 関数の単調性が不正になる問題を修正しました。これにより [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422) も修正されます。このバグは [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212) で導入され、その後、より高度なパーティションプルーナーによって顕在化しました。[#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* [#24557](https://github.com/ClickHouse/ClickHouse/issues/24557) にバックポート: クエリ `SYSTEM RESTART REPLICA` または `SYSTEM SYNC REPLICA` の処理が無限に継続する場合の動作を修正しました。これは RAM が極端に少ない server で検出されました。[#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#24598](https://github.com/ClickHouse/ClickHouse/issues/24598) にバックポート: `CREATE .. AS SELECT` クエリでの Tuples の使用を修正しました。[#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)).
* [#24601](https://github.com/ClickHouse/ClickHouse/issues/24601) にバックポート: 分散テーブルで subcolumns を読み取れるようにしました。[#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
