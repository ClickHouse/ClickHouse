<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#72150](https://github.com/ClickHouse/ClickHouse/issues/72150) にバックポート: この PR により、`RESTORE ON CLUSTER` は復元された各 `ReplicatedMergeTree` テーブルについて、復元済みのパーツをアタッチする前に readonly でなくなるまで待機するようになりました。以前は待機していなかったため、テーブルの起動中に他のレプリカを確認する処理とほぼ同時に、一部のパーツをアタッチしようとする可能性がありました。まれに、この問題により `RESTORE ON CLUSTER` 中に一部のパーツがまったくアタッチされないことがありました。[#62207](https://github.com/ClickHouse/ClickHouse/pull/62207) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#72408](https://github.com/ClickHouse/ClickHouse/issues/72408) にバックポート: `ATTACH PART` クエリ中に重複排除されたパーツが、`attaching_` プレフィックス付きのまま残ることがなくなりました。[#65636](https://github.com/ClickHouse/ClickHouse/pull/65636) ([Kirill](https://github.com/kirillgarbar)).
* [#71979](https://github.com/ClickHouse/ClickHouse/issues/71979) にバックポート: [この issue](https://github.com/ClickHouse/ClickHouse/pull/59946#issuecomment-1943653197) 以降、production 環境には、`metadata_version` ノードの値が `0` であり、かつ対応するテーブルの `metadata` ノードのバージョンとも異なるテーブルレプリカがかなり多く存在します。これにより、そのようなレプリカでは `alter` クエリが失敗します。[#69274](https://github.com/ClickHouse/ClickHouse/pull/69274) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#72396](https://github.com/ClickHouse/ClickHouse/issues/72396) にバックポート: named collections で不足していた unescaping を追加しました。この修正がないと、clickhouse-server を起動できません。[#71308](https://github.com/ClickHouse/ClickHouse/pull/71308) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#73354](https://github.com/ClickHouse/ClickHouse/issues/73354) にバックポート: 古い PostgreSQL で発生する error「column &quot;attgenerated&quot; does not exist」を修正し、[#60651](https://github.com/ClickHouse/ClickHouse/issues/60651) に対応しました。[#71396](https://github.com/ClickHouse/ClickHouse/pull/71396) ([0xMihalich](https://github.com/0xMihalich)).
* [#72141](https://github.com/ClickHouse/ClickHouse/issues/72141) にバックポート: Keeper が利用できない場合のデータ損失を防ぐため、パーツを zero-copy ディスクに移動する前に zero-copy shared lock を取得するようにしました。[#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72153](https://github.com/ClickHouse/ClickHouse/issues/72153) にバックポート: サブクエリ内で使用される EXPLAIN AST では SELECT クエリのみを許可します。その他の種類のクエリは、論理エラー: &#39;Bad cast from type DB::ASTCreateQuery to DB::ASTSelectWithUnionQuery&#39; または `Inconsistent AST formatting` を引き起こします。[#71982](https://github.com/ClickHouse/ClickHouse/pull/71982) ([Pavel Kruglov](https://github.com/Avogar)).
* [#74382](https://github.com/ClickHouse/ClickHouse/issues/74382) にバックポート: `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE` の後に一時停止が発生するのを回避します。バックグラウンドタスクのスケジューリングに対して正しい設定を取得します。[#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* [#72112](https://github.com/ClickHouse/ClickHouse/issues/72112) にバックポート: `format_alter_commands_with_parentheses` が有効な場合の `MOVE PARTITION ... TO TABLE ...` alter コマンドのフォーマットを修正しました。[#72080](https://github.com/ClickHouse/ClickHouse/pull/72080) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#72249](https://github.com/ClickHouse/ClickHouse/issues/72249) にバックポート: `min_age_to_force_merge_on_partition_only` が、すでに単一のパーツにマージ済みの同じパーティションに対して繰り返しマージを試みて停止し、複数のパーツを持つパーティションがマージされない不具合を修正しました。[#72209](https://github.com/ClickHouse/ClickHouse/pull/72209) ([Christoph Wurm](https://github.com/cwurm)).
