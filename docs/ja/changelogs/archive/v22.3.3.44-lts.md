<div id="clickhouse-release-v223344-lts-abb756d3ca2-fixme-as-compared-to-v22322-lts-89a621679c6">
  ### ClickHouse リリース v22.3.3.44-lts (abb756d3ca2) FIXME v22.3.2.2-lts (89a621679c6) との比較
</div>

<div id="bug-fix">
  #### バグ修正
</div>

* [#35928](https://github.com/ClickHouse/ClickHouse/issues/35928) でバックポート: 無効な IP アドレス値をデフォルト値としてテーブルに挿入できるよう、設定 `input_format_ipv4_default_on_conversion_error`、`input_format_ipv6_default_on_conversion_error` を追加しました。[#35726](https://github.com/ClickHouse/ClickHouse/issues/35726) をクローズしました。[#35733](https://github.com/ClickHouse/ClickHouse/pull/35733) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#35415](https://github.com/ClickHouse/ClickHouse/issues/35415) でバックポート: cache で発生する可能性のあるデッドロックを修正しました。[#35378](https://github.com/ClickHouse/ClickHouse/pull/35378) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#35563](https://github.com/ClickHouse/ClickHouse/issues/35563) でバックポート: IN 句における IPv4/IPv6 アドレスへの cast を修正しました。[#35528](https://github.com/ClickHouse/ClickHouse/issues/35528) を修正。[#35534](https://github.com/ClickHouse/ClickHouse/pull/35534) ([Maksim Kita](https://github.com/kitaisreal)).
* [#35783](https://github.com/ClickHouse/ClickHouse/issues/35783) でバックポート: カスタム型から文字列への変換における不具合を修正しました。この不具合により、segfault や予期しないエラーメッセージが発生する可能性がありました。[#35752](https://github.com/ClickHouse/ClickHouse/issues/35752) をクローズ。[#35755](https://github.com/ClickHouse/ClickHouse/pull/35755) ([Kruglov Pavel](https://github.com/Avogar)).
* [#35881](https://github.com/ClickHouse/ClickHouse/issues/35881) でバックポート: 関数 `extract` の引数のパースを修正しました。[#35751](https://github.com/ClickHouse/ClickHouse/issues/35751) を修正。[#35799](https://github.com/ClickHouse/ClickHouse/pull/35799) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#35856](https://github.com/ClickHouse/ClickHouse/issues/35856) でバックポート: グループではクォータと period のみを考慮し、shares は無視するようにしました (shares は実際には使用可能なコア数を制限しないため) 。[#35815](https://github.com/ClickHouse/ClickHouse/pull/35815) ([filimonov](https://github.com/filimonov)).
* [#35938](https://github.com/ClickHouse/ClickHouse/issues/35938) でバックポート: カラムごとの有効期限 (TTL) が複数回処理されないようにしました。[#35820](https://github.com/ClickHouse/ClickHouse/pull/35820) ([Azat Khuzhin](https://github.com/azat)).
