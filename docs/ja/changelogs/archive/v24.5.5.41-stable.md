* [#66768](https://github.com/ClickHouse/ClickHouse/issues/66768) にバックポート: `allow_experimental_analyzer` が、分散クエリではイニシエーターによって制御されるようにしました。これにより、異なるバージョンが混在するクラスターでの操作時にも、互換性と正確性が確保されます。[#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

* [#65350](https://github.com/ClickHouse/ClickHouse/issues/65350) にバックポート: StatusFile の ~WriteBufferFromFileDescriptor で、uncaught exception により abort が発生する可能性がある問題を修正しました。 [#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)).

* [#67902](https://github.com/ClickHouse/ClickHouse/issues/67902) にバックポート: StorageMerge に対する `PREWHERE` 最適化後に発生する `Not-ready Set` エラーを修正しました。 [#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#66884](https://github.com/ClickHouse/ClickHouse/issues/66884) にバックポート: 関数呼び出しにおける低カーディナリティのカラムのサイズが想定外になる問題を修正しました。 [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* [#65933](https://github.com/ClickHouse/ClickHouse/issues/65933) にバックポート: `PostgreSQL` から読み取るクエリについて、ClickHouse クエリが完了した場合は内部の `PostgreSQL` クエリもキャンセルするようにしました。これがないと、内部の `PostgreSQL` クエリが完了するまで ClickHouse クエリをキャンセルできません。 [#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)).
* [#66301](https://github.com/ClickHouse/ClickHouse/issues/66301) にバックポート: `IS NULL` チェックを含む join 条件の処理を改善しました (たとえば `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` は `ON a <=> b` に rewritten されます) 。また、`IS NULL` 以外の条件が含まれる場合の誤った最適化も修正しました。 [#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* [#66328](https://github.com/ClickHouse/ClickHouse/issues/66328) にバックポート: スキーマ推論 cache に不足していた設定 `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` を追加しました。これらの設定は結果のスキーマを変える可能性があるためです。これにより、これらの設定変更時にスキーマ推論の結果が不正になるのを防ぎます。 [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* [#68252](https://github.com/ClickHouse/ClickHouse/issues/68252) にバックポート: subqueries を使った filtering 時に、一部のシステムテーブルで発生する `Not-ready Set` を修正しました。 [#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* [#66155](https://github.com/ClickHouse/ClickHouse/issues/66155) にバックポート: `unbin`/`unhex` 実装における buffer overflow バグを修正しました。 [#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* [#66454](https://github.com/ClickHouse/ClickHouse/issues/66454) にバックポート: ZooKeeper client のバグを修正しました。ZooKeeper からハードウェアエラーを受信した後、session が使用不能な状態のままになることがありました。たとえば、これは ClickHouse Keeper の &quot;soft memory limit&quot; が原因で発生する可能性があります。 [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#66226](https://github.com/ClickHouse/ClickHouse/issues/66226) でバックポート: SumIfToCountIfVisitor と符号付き整数に関する問題を修正しました。[#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
