<div id="bug-fix">
  #### バグ修正
</div>

* [#27981](https://github.com/ClickHouse/ClickHouse/issues/27981)でバックポート: windowFunnel の &quot;strict&quot; モードに関するバグを修正しました。これにより [#27469](https://github.com/ClickHouse/ClickHouse/issues/27469) も修正されます。[#27563](https://github.com/ClickHouse/ClickHouse/pull/27563) ([achimbab](https://github.com/achimbab)).
* [#27922](https://github.com/ClickHouse/ClickHouse/issues/27922)でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/26864](https://github.com/ClickHouse/ClickHouse/pull/26864) の後に発生した問題を修正しました。`NamedSessionStorage` のシャットダウンを修正し、`NamedSessionStorage` に保存された session コンテキストがグローバル Context の破棄前に破棄されるようになりました。[#27875](https://github.com/ClickHouse/ClickHouse/pull/27875) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#27926](https://github.com/ClickHouse/ClickHouse/issues/27926)でバックポート: 負の数に対する PostgreSQL スタイルの CAST (`::` 演算子) を修正しました。[#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* [#27959](https://github.com/ClickHouse/ClickHouse/issues/27959)でバックポート: `LowCardinality(UUID)` 型のカラムに対して extremes を指定して select する際の不具合を修正しました。[#27918](https://github.com/ClickHouse/ClickHouse/pull/27918) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#27954](https://github.com/ClickHouse/ClickHouse/issues/27954)でバックポート: 分散テーブルの作成前にクラスター名を確認し、不正なクラスター名でテーブルを作成できないようにしました。[#27832](https://github.com/ClickHouse/ClickHouse/issues/27832) を修正します。[#27927](https://github.com/ClickHouse/ClickHouse/pull/27927) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#28000](https://github.com/ClickHouse/ClickHouse/issues/28000)でバックポート: ON CLUSTER clause を含む GRANT WITH REPLACE ステートメントの実行時に、access grants の確認処理を修正しました。この PR では [https://github.com/ClickHouse/ClickHouse/pull/27701](https://github.com/ClickHouse/ClickHouse/pull/27701) の修正を改善しています。[#27983](https://github.com/ClickHouse/ClickHouse/pull/27983) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#28210](https://github.com/ClickHouse/ClickHouse/issues/28210)でバックポート: 読み取りバッファで &#39;attempt to read after end of file&#39; が発生するケースを修正しました。[#26149](https://github.com/ClickHouse/ClickHouse/issues/26149) をクローズします。[#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
* [#28750](https://github.com/ClickHouse/ClickHouse/issues/28750)でバックポート: settings `legacy_column_name_of_tuple_literal = 0` を使用する distributed queries において、選言 chain を `IN` に変換する処理 (settings `optimize_min_equality_disjunction_chain_length` で制御) の不具合を修正しました。[#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).
