<div id="bug-fix">
  #### バグ修正

* [#42435](https://github.com/ClickHouse/ClickHouse/issues/42435) でバックポート: - LowCardinality と BigInt に対して、正しい集計方式を選択。 [#42342](https://github.com/ClickHouse/ClickHouse/pull/42342) ([Duc Canh Le](https://github.com/canhld94)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#42297](https://github.com/ClickHouse/ClickHouse/issues/42297) でバックポート: cctz を最新の master に更新し、tzdb を 2020e に更新しました。[#42273](https://github.com/ClickHouse/ClickHouse/pull/42273) ([Dom Del Nano](https://github.com/ddelnano))。
* [#42361](https://github.com/ClickHouse/ClickHouse/issues/42361) でバックポート: 新しい timezone の変更に対応するため、tzdata を 2022e に更新しました。パレスチナの切り替えは土曜日の 02:00 になりました。ウクライナの 3 つの zones は 1 つに統合されました。ヨルダンとシリアは、DST を伴う +02/+03 から通年の +03 に切り替わりました。([https://data.iana.org/time-zones/tzdb/NEWS](https://data.iana.org/time-zones/tzdb/NEWS))。これにより [#42252](https://github.com/ClickHouse/ClickHouse/issues/42252) はクローズされます。[#42327](https://github.com/ClickHouse/ClickHouse/pull/42327) ([Alexey Milovidov](https://github.com/alexey-milovidov))。

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#42122](https://github.com/ClickHouse/ClickHouse/issues/42122)でバックポート: ごくまれに、破損したものとして一部の part を detach した直後にレプリカが再起動すると、&quot;Part ... intersects part ...&quot; エラーが発生する問題を修正しました。[#41741](https://github.com/ClickHouse/ClickHouse/pull/41741) ([Alexander Tokmakov](https://github.com/tavplubix))。
* [#41938](https://github.com/ClickHouse/ClickHouse/issues/41938)でバックポート: 論理削除用に予約されている仮想カラム名 `_row_exists` を持つ MergeTree テーブルを作成または変更できないようにしました。[#41716](https://github.com/ClickHouse/ClickHouse/issues/41716) を修正しました。[#41763](https://github.com/ClickHouse/ClickHouse/pull/41763) ([Jianmei Zhang](https://github.com/zhangjmruc))。
* [#42179](https://github.com/ClickHouse/ClickHouse/issues/42179)でバックポート: base backup から 4GB を超えるファイルを再利用する際の不具合を修正しました。[#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat))。
* [#42301](https://github.com/ClickHouse/ClickHouse/issues/42301)でバックポート: projections と `aggregate_functions_null_for_empty` 設定に関する不具合を修正しました。この不具合は非常にまれで、server の config で `aggregate_functions_null_for_empty` 設定を有効にした場合にのみ発生します。これにより [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647) はクローズされます。[#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#42388](https://github.com/ClickHouse/ClickHouse/issues/42388)でバックポート: attached part (table schema と異なるカラムを持つもの) に対する `ALTER UPDATE` により、ディスク上に不正な `columns.txt` メタデータが作成される可能性がありました。そのような part からの読み取りは、エラーで失敗したり、不正なデータを返したりする可能性がありました。[#42161](https://github.com/ClickHouse/ClickHouse/issues/42161) を修正しました。[#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#42500](https://github.com/ClickHouse/ClickHouse/issues/42500)でバックポート: 設定 `additional_table_filters` が `Distributed` ストレージに適用されていなかった問題を修正しました。[#41692](https://github.com/ClickHouse/ClickHouse/issues/41692) を修正しました。[#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#42581](https://github.com/ClickHouse/ClickHouse/issues/42581)でバックポート: 日付/時刻関数にリグレッションを導入した [#40217](https://github.com/ClickHouse/ClickHouse/issues/40217) を Revert するものです。[#42367](https://github.com/ClickHouse/ClickHouse/pull/42367) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#42572](https://github.com/ClickHouse/ClickHouse/issues/42572)でバックポート: Decimal data types の処理におけるバッファオーバーフローを修正しました。これにより [#42451](https://github.com/ClickHouse/ClickHouse/issues/42451) はクローズされます。[#42465](https://github.com/ClickHouse/ClickHouse/pull/42465) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#42595](https://github.com/ClickHouse/ClickHouse/issues/42595)でバックポート: これにより [#42453](https://github.com/ClickHouse/ClickHouse/issues/42453) はクローズされます。[#42573](https://github.com/ClickHouse/ClickHouse/pull/42573) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
