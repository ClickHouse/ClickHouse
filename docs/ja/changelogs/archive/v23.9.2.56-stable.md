  ### ClickHouse リリース v23.9.2.56-安定版 (a1bf3f1de55) FIXME (v23.9.1.1854-安定版 (8f9a227de1f) との比較)

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング 改善
</div>

* [#55295](https://github.com/ClickHouse/ClickHouse/issues/55295) にバックポート: ソースコードとサブモジュールを含むリソースを、Darwin 向けの特別なビルドタスクでビルドするようにしました。これにより、サブモジュールをチェックアウトしなくても ClickHouse をビルドできるようになります。[#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* [#55368](https://github.com/ClickHouse/ClickHouse/issues/55368) にバックポート: `clickhouse-server` パッケージからスタンドアロンの `clickhouse-keeper` を起動する際の問題を解決しました。[#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* [#55727](https://github.com/ClickHouse/ClickHouse/issues/55727) にバックポート: gh api url を使用するようにインテグレーションチェック用の Python スクリプトを修正し、CI テスト向けの Readme を追加しました。[#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* LDAP で割り当てられたロールの更新時に発生するデッドロックを修正 [#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* fs cache のバックグラウンドダウンロードに関する不具合を修正 [#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* スパースカラム上での関数実行を修正 [#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* SELECT FINAL FROM SummingMergeTree における Nested の誤ったマージを修正 [#55276](https://github.com/ClickHouse/ClickHouse/pull/55276) ([Azat Khuzhin](https://github.com/azat)).
* zero copy を使用しない S3 上の replicated merge tree で、デタッチされたパーティションを drop できない不具合を修正 [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* MergeSortingPartialResultTransform における SIGSEGV を修正 (remerge() の後に chunk が 0 個になることが原因)  [#55335](https://github.com/ClickHouse/ClickHouse/pull/55335) ([Azat Khuzhin](https://github.com/azat)).
* 共有例外の throw に起因する CreatingSetsTransform の data-race (エラー時) を修正 [#55338](https://github.com/ClickHouse/ClickHouse/pull/55338) ([Azat Khuzhin](https://github.com/azat)).
* trash optimization を修正 (ある程度まで)  [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* cast 演算子における配列のパースを修正 [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* クエリ内の OR フィルターによる仮想カラムの絞り込みを修正 [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* MongoDB 接続の問題を修正 [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* AsyncTaskExecutor の cancelBefore で例外が発生した場合に fiber を破棄するよう修正 [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* 循環別名を持つ QueryNormalizer でのクラッシュを修正 [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* クエリ内の OR フィルターによる仮想カラムの絞り込みを修正 (再提出)  [#55678](https://github.com/ClickHouse/ClickHouse/pull/55678) ([Azat Khuzhin](https://github.com/azat)).
