<div id="2022-changelog">
  # 2022年の変更履歴
</div>

<div id="clickhouse-release-v212941-stable-fixme-as-compared-to-v212831-stable">
  ### ClickHouse リリース v21.2.9.41-stable FIXME (v21.2.8.31-stable との比較)
</div>

<div id="improvement">
  #### 改善
</div>

* [#22818](https://github.com/ClickHouse/ClickHouse/issues/22818) でバックポート: Alpine イメージで FQDN およびその他の DNS 関連関数が正しく動作するようにしました。[#20336](https://github.com/ClickHouse/ClickHouse/pull/20336) ([filimonov](https://github.com/filimonov)).
* [#22812](https://github.com/ClickHouse/ClickHouse/issues/22812) でバックポート: PODArray が 16 の約数でも倍数でもない要素サイズで初期化された場合、バッファオーバーフローが発生する可能性がありました。現在のリリースにこのバグは存在しません。[#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### バグ修正
</div>

* [#22965](https://github.com/ClickHouse/ClickHouse/issues/22965)でバックポート: 重複排除により、`quorum_parallel=1` を使用したごくまれなクォーラム insert が実際には「クォーラム」にならない不具合を修正しました。[#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* [#22719](https://github.com/ClickHouse/ClickHouse/issues/22719)でバックポート: テーブル関数 view がカラムとして使用されているかどうかをチェックするようにしました。これは [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350) を補完するものです。[#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* [#22756](https://github.com/ClickHouse/ClickHouse/issues/22756)でバックポート: 分散クエリでの関数 `map` の使用に関する不具合を修正しました。[#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* [#22889](https://github.com/ClickHouse/ClickHouse/issues/22889)でバックポート: MergeTree からの逆順読み取りにおける概算総行数の計算を修正しました。[#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* [#22915](https://github.com/ClickHouse/ClickHouse/issues/22915)でバックポート: LIVE VIEW (実験的機能) 。`TemporaryLiveViewCleaner` において、TEMPORARY LIVE VIEW の同時実行 DROP/CREATE で発生しうるハングを修正しました。詳細は [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e) を参照してください。[#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#22918](https://github.com/ClickHouse/ClickHouse/issues/22918)でバックポート: ウィンドウ関数とともに `mannWhitneyUTest` および `rankCorr` を使用した際に発生するクラッシュを修正しました。これにより [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728) も修正されます。[#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### ビルド/テスト/パッケージング改善
</div>

* [#22814](https://github.com/ClickHouse/ClickHouse/issues/22814)でバックポート: gdb で変更済みの binary を使っても起動できるようにしました。以前のバージョンでは、起動前に gdb でブレークポイントを設定すると、整合性チェックに失敗したため server は起動を拒否していました。 [#21258](https://github.com/ClickHouse/ClickHouse/pull/21258) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="not-for-changelog-insignificant">
  #### 変更履歴対象外 / 軽微
</div>

* `epoll_wait` で EINTR をチェックするよう修正 [#20958](https://github.com/ClickHouse/ClickHouse/pull/20958) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* FileDictionarySource で絶対ファイルパスを修正 [#22822](https://github.com/ClickHouse/ClickHouse/pull/22822) ([Maksim Kita](https://github.com/kitaisreal)).
