<div id="backward-incompatible-change">
  #### 後方互換性を持たない変更
</div>

* デフォルトの Prometheus ハンドラーから、`status_info` 設定オプションと Dictionaries の status を削除しました。 [#54090](https://github.com/ClickHouse/ClickHouse/pull/54090) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 実験的なパーツのメタデータキャッシュは、codebase から削除されました。 [#54215](https://github.com/ClickHouse/ClickHouse/pull/54215) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `input_format_json_try_infer_numbers_from_strings` 設定はデフォルトで無効化されました。これにより、JSON フォーマットではデフォルトで文字列から数値を推論しなくなり、サンプルデータに数値のように見える文字列が含まれている場合に起こり得るパースエラーを回避できます。 [#55099](https://github.com/ClickHouse/ClickHouse/pull/55099) ([Kruglov Pavel](https://github.com/Avogar)).
* 2023 年 3 月以前に作成された IPv6 bloom filter 索引は、現在のバージョンと互換性がないため、再構築が必要です。 [#54200](https://github.com/ClickHouse/ClickHouse/pull/54200) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).



<div id="new-feature">
  #### 新機能
</div>

* SSH key ベースの新しい認証方式を追加しました。これは Native TCP protocol でのみ動作します。[#41109](https://github.com/ClickHouse/ClickHouse/pull/41109) ([George Gamezardashvili](https://github.com/InfJoker)).
* リモートディスク向けの I/Oスケジューリング対応を追加しました。ディスクタイプ `s3`、`s3_plain`、`hdfs`、`azure_blob_storage` のストレージ構成に、リソース名を保持する `read_resource` および `write_resource` 要素を含められるようになりました。これらのリソースのスケジューリングポリシーは、別のサーバー構成セクション `resources` で設定できます。さまざまなリソーススケジューリング目標を実現するために、クエリには設定 `workload` を使ってマークを付けられ、サーバー構成セクション `workload_classifiers` を使って分類できます。詳細は docs/en/operations/workload-scheduling.md を参照してください。[#47009](https://github.com/ClickHouse/ClickHouse/pull/47009) ([Sergei Trifonov](https://github.com/serxa)).
* 新しいカラム &#95;block&#95;number を追加し、[#44532](https://github.com/ClickHouse/ClickHouse/issues/44532) を解決しました。[#47532](https://github.com/ClickHouse/ClickHouse/pull/47532) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* クエリ実行中に出力テーブルの部分結果の更新をリアルタイムで表示するため、`partial_result_update_duration_ms` と `max_rows_in_partial_result` オプションを追加しました。[#48607](https://github.com/ClickHouse/ClickHouse/pull/48607) ([Alexey Perevyshin](https://github.com/alexX512)).
* RegExpTree辞書で、大文字小文字を区別しないマッチングモードと dot-all マッチングモードをサポートしました。[#50906](https://github.com/ClickHouse/ClickHouse/pull/50906) ([Johann Gan](https://github.com/johanngan)).
* `ALTER TABLE MODIFY COMMENT` のサポートを追加しました。注: かなり前に外部コントリビューターによって似た機能が追加されていましたが、まったく動作せず、ユーザーを混乱させるだけでした。これにより [#36377](https://github.com/ClickHouse/ClickHouse/issues/36377) をクローズします。[#51304](https://github.com/ClickHouse/ClickHouse/pull/51304) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* 新しいデータ圧縮コーデックとして &quot;GCD&quot; (別名 &quot;greatest common denominator&quot;) を追加しました。このコーデックは、すべてのカラム値の GCD を計算し、各値をその GCD で割ります。GCD コーデックはデータ準備用コーデック (Delta や DoubleDelta と同様) であり、単独では使用できません。整数型、小数型、日付/時刻型のデータで動作します。GCD コーデックの有効なユースケースは、値が GCD の倍数単位で増減するカラムです。たとえば 24 - 28 - 16 - 24 - 8 - 24 のような場合です (GCD = 4 と仮定) 。[#53149](https://github.com/ClickHouse/ClickHouse/pull/53149) ([Alexander Nam](https://github.com/seshWCS)).
* 2 つの新しい型の別名 &quot;DECIMAL(P)&quot; (&quot;DECIMAL(P, 0)&quot; の短縮形) と &quot;DECIMAL&quot; (&quot;DECIMAL(10, 0)&quot; の短縮形) を追加しました。これにより、ClickHouse の MySQL の SQL方言 との互換性が向上しました。[#53328](https://github.com/ClickHouse/ClickHouse/pull/53328) ([Val Doroshchuk](https://github.com/valbok)).
* すべての `BACKUP` および `RESTORE` 操作を追跡するための新しいシステムログテーブル `backup_log` を追加しました。[#53638](https://github.com/ClickHouse/ClickHouse/pull/53638) ([Victor Krasnov](https://github.com/sirvickr)).
* フォーマット設定 &quot;output&#95;format&#95;markdown&#95;escape&#95;special&#95;characters&quot; (デフォルト: false) を追加しました。この設定は、&quot;Markdown&quot; 出力フォーマットで &quot;!&quot;、&quot;#&quot;、&quot;$&quot; などの特殊文字をエスケープするかどうか (つまり、先頭にバックスラッシュを付けるかどうか) を制御します。[#53860](https://github.com/ClickHouse/ClickHouse/pull/53860) ([irenjj](https://github.com/irenjj)).
* 関数 `decodeHTMLComponent` を追加しました。[#54097](https://github.com/ClickHouse/ClickHouse/pull/54097) ([Bharat Nallan](https://github.com/bharatnc)).
* query&#95;log テーブルに peak&#95;threads&#95;usage を追加しました。[#54335](https://github.com/ClickHouse/ClickHouse/pull/54335) ([Alexey Gerasimchuck](https://github.com/Demilivor)).
* clickhouse-client に SHOW FUNCTIONS のサポートを追加しました。[#54337](https://github.com/ClickHouse/ClickHouse/pull/54337) ([Julia Kartseva](https://github.com/wat-ze-hex)).
* この PR では JSON フォーマット におけるスキーマ推論を改善しました。1) JSON フォーマット で、設定 `input_format_json_try_infer_named_tuples_from_objects` により、experimental な JSON 型を使わなくても JSON オブジェクト から named Tuple を推論できるようになりました。従来は experimental な JSON 型を使わない場合、JSON オブジェクト は String または Map としてしか推論できませんでしたが、今後は named Tuple を推論できます。推論される Tuple 型には、スキーマ推論時のデータサンプルで読み取られたオブジェクトのすべてのキーが含まれます。これは、スパースなオブジェクトを含まない構造化 JSON データを読み取る際に役立ちます。この設定はデフォルトで有効です。2) 設定 `input_format_json_read_arrays_as_strings` により、JSON array を型 String のカラムにパースできるようにしました。これは、異なる型の値を含む配列を読み取るのに役立ちます。3) 設定 `input_format_json_infer_incomplete_types_as_strings` により、サンプルデータ内で型が不明な (`null`/`[]`/`{}`) JSON キーに対して String 型を使用できるようにしました。これにより、JSON フォーマット では任意の値を String カラムに読み取れるようになり、不明な型に対して String 型を使うことで、スキーマ推論時の `Cannot determine type for column 'column_name' by first 25000 rows of data, most likely this column contains only Nulls or empty Arrays/Maps` エラーを回避して、データを正常に読み取れるようになります。[#54427](https://github.com/ClickHouse/ClickHouse/pull/54427) ([Kruglov Pavel](https://github.com/Avogar)).
* 0001-01-01 からの経過日数を返す関数 &quot;toDaysSinceYearZero&quot; と、その alias である &quot;TO&#95;DAYS()&quot; (MySQL 互換のため) を追加しました。[#54479](https://github.com/ClickHouse/ClickHouse/pull/54479) ([Robert Schulze](https://github.com/rschu1ze)).
* YYYYMMDDtoDate()、YYYYMMDDtoDate32()、YYYYMMDDhhmmssToDateTime()、YYYYMMDDhhmmssToDateTime64() を追加しました。これらは、整数としてエンコードされた日付または日時 (例: 20230911) をネイティブな日付または日時に変換します。そのため、既存の関数 YYYYMMDDToDate()、YYYYMMDDToDateTime()、YYYYMMDDhhmmddToDateTime()、YYYYMMDDhhmmddToDateTime64() とは逆の機能を提供します。[#54509](https://github.com/ClickHouse/ClickHouse/pull/54509) ([Robert Schulze](https://github.com/rschu1ze)).
* &quot;bandwidth&#95;limit&quot; I/O scheduling node 型を追加しました。これにより、この node を通過するトラフィックに対して `max_speed` および `max_burst` の 制約 を指定できます。詳細は docs/en/operations/workload-scheduling.md を参照してください。[#54618](https://github.com/ClickHouse/ClickHouse/pull/54618) ([Sergei Trifonov](https://github.com/serxa)).
* 関数 `toDaysSinceYearZero()` が、型 `DateTime` および `DateTime64` の引数をサポートするようになりました。[#54856](https://github.com/ClickHouse/ClickHouse/pull/54856) ([Serge Klochkov](https://github.com/slvrtrn)).
* テーブル関数 `s3`、`gcs`、`oss` で S3 スタイルの URL を使用できるようにしました。URL は自動的に HTTP に変換されます。例: `'s3://clickhouse-public-datasets/hits.csv'` は `'https://clickhouse-public-datasets.s3.amazonaws.com/hits.csv'` に変換されます。[#54931](https://github.com/ClickHouse/ClickHouse/pull/54931) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* 文字列の距離関数を複数追加しました。`byteHammingDistance`、`byteJaccardIndex`、`byteEditDistance` が含まれます。### ユーザー向け変更に関するドキュメント項目。[#54935](https://github.com/ClickHouse/ClickHouse/pull/54935) ([flynn](https://github.com/ucasfl)).
* 深くネストした Tuple/Maps/Arrays などの型名を見やすく表示するための新しい設定 `print_pretty_type_names` を追加しました。 [#55095](https://github.com/ClickHouse/ClickHouse/pull/55095) ([Kruglov Pavel](https://github.com/Avogar)).

* Annoy 索引の作成を、設定 `max_threads_for_annoy_index_creation` を使って並列化できるようになりました。[#54047](https://github.com/ClickHouse/ClickHouse/pull/54047) ([Robert Schulze](https://github.com/rschu1ze)).
* MySQL インターフェイスにプリペアドステートメントの最小限の実装が追加され、Tableau Online から MySQL コネクタ経由で ClickHouse に接続できるようになりました。 [#54115](https://github.com/ClickHouse/ClickHouse/pull/54115) ([Serge Klochkov](https://github.com/slvrtrn)).
* base64 値の処理 (エンコード／デコード) に使うライブラリを Turbo-Base64 から aklomp-base64 に置き換えました。どちらも x86 および ARM で SIMD により高速化されていますが、理由は次のとおりです。1. 後者のライセンス (BSD-2) のほうが ClickHouse に適しており、一方で Turbo64 はその間に GPL-3 に変更されたこと、2. GitHub のスター数がより多く、aklomp-base64 のほうが将来性が高いと考えられること、3. aklomp-base64 のほうが API がやや使いやすいこと (これについては主観的な面もあります) 、4. aklomp-base64 ではバグ回避のためのワークアラウンド (スレッドセーフでない初期化など) が不要なことです。注: aklomp-base64 はパディングなしの base64 値を拒否しますが、Turbo-Base64 はベストエフォートでそれらをデコードします。RFC-4648 ではパディングを必須とするかどうかは明確に定められていませんが、コンテキストによってはこれは注意すべき挙動の変更になる可能性があります。 [#54119](https://github.com/ClickHouse/ClickHouse/pull/54119) ([Mikhail Koviazin](https://github.com/mkmkme)).
* HTTP headers X-ClickHouse-Progress および X-ClickHouse-Summary に elapsed&#95;ns を追加しました。 [#54179](https://github.com/ClickHouse/ClickHouse/pull/54179) ([joelynch](https://github.com/joelynch)).
* keeper-client 向けに `reconfig` (https://github.com/ClickHouse/ClickHouse/pull/49450)、`sync`、`exists` コマンドを実装しました。 [#54201](https://github.com/ClickHouse/ClickHouse/pull/54201) ([pufit](https://github.com/pufit)).

* `formatReadableTimeDelta` に秒未満の精度を追加しました。 [#54250](https://github.com/ClickHouse/ClickHouse/pull/54250) ([Andrey Zvonov](https://github.com/zvonand)).
