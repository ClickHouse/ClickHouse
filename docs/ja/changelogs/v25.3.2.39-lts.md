* [#77947](https://github.com/ClickHouse/ClickHouse/issues/77947) にバックポート: StorageS3(Azure)Queue で、有効期限切れのコンテキストが原因でクラッシュする問題を修正しました。[#77720](https://github.com/ClickHouse/ClickHouse/pull/77720) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#78087](https://github.com/ClickHouse/ClickHouse/issues/78087) にバックポート: RabbitMQ、Nats、Redis、AzureQueue テーブルエンジンで認証情報をマスクするようにしました。[#77755](https://github.com/ClickHouse/ClickHouse/pull/77755) ([Kseniia Sumarokova](https://github.com/kssenii))。
* [#78038](https://github.com/ClickHouse/ClickHouse/issues/78038) にバックポート: ArgMin/ArgMax で NaN を比較した際の未定義動作を修正しました。[#77756](https://github.com/ClickHouse/ClickHouse/pull/77756) ([Raúl Marín](https://github.com/Algunenano))。
* [#78280](https://github.com/ClickHouse/ClickHouse/issues/78280) にバックポート: `NOT_FOUND_COLUMN_IN_BLOCK` エラー発生時にクラッシュする可能性がある問題を修正しました。[#77854](https://github.com/ClickHouse/ClickHouse/pull/77854) ([Vladimir Cherkasov](https://github.com/vdimir))。
* [#78050](https://github.com/ClickHouse/ClickHouse/issues/78050) にバックポート: SSHサーバーで履歴に対するあいまい検索を無効化しました (skim が必要なため) 。[#78002](https://github.com/ClickHouse/ClickHouse/pull/78002) ([Azat Khuzhin](https://github.com/azat))。
* [#78105](https://github.com/ClickHouse/ClickHouse/issues/78105) にバックポート: 「要求された出力フォーマット {} はバイナリです... それでも出力しますか？ [y/N]」というプロンプトを修正しました。 [#78095](https://github.com/ClickHouse/ClickHouse/pull/78095) ([Azat Khuzhin](https://github.com/azat)).
* [#78116](https://github.com/ClickHouse/ClickHouse/issues/78116) でバックポート: HTTP interface で空の `session_id` クエリパラメータを指定できないようにしました。[#78098](https://github.com/ClickHouse/ClickHouse/pull/78098) ([Alexey Katsman](https://github.com/alexkats)).
* [#78136](https://github.com/ClickHouse/ClickHouse/issues/78136) でバックポート: NATS engine のクラッシュを修正しました。[#78108](https://github.com/ClickHouse/ClickHouse/pull/78108) ([Dmitry Novikov](https://github.com/dmitry-sles-novikov)).
* [#78121](https://github.com/ClickHouse/ClickHouse/issues/78121) でバックポート: SSH 用の埋め込みクライアントで history&#95;file を作成しないようにしました。[#78112](https://github.com/ClickHouse/ClickHouse/pull/78112) ([Azat Khuzhin](https://github.com/azat)).
* [#78147](https://github.com/ClickHouse/ClickHouse/issues/78147) でバックポート: RENAME DATABASE または DROP TABLE クエリの後に、system.detached&#95;tables に誤った情報が表示される問題を修正しました。[#78126](https://github.com/ClickHouse/ClickHouse/pull/78126) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#78199](https://github.com/ClickHouse/ClickHouse/issues/78199) でバックポート: [https://github.com/ClickHouse/ClickHouse/pull/77274](https://github.com/ClickHouse/ClickHouse/pull/77274) 後に Database Replicated でテーブル数が多すぎる場合のチェックを修正しました。また、RMT または KeeperMap の場合に ZooKeeper に未計上のノードが作成されるのを防ぐため、ストレージの作成前にチェックを実行するようにしました。[#78127](https://github.com/ClickHouse/ClickHouse/pull/78127) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#78158](https://github.com/ClickHouse/ClickHouse/issues/78158) でバックポート: `groupArray*` 関数は、UInt の場合と同様に、max&#95;size 引数に Int 型の 0 値が指定された場合、実行を試みる代わりに BAD&#95;ARGUMENTS エラーを返すようになりました。[#78140](https://github.com/ClickHouse/ClickHouse/pull/78140) ([Eduard Karacharov](https://github.com/korowa)).
* [#78233](https://github.com/ClickHouse/ClickHouse/issues/78233) でバックポート: ローカル table がデタッチされる前に削除された場合に recoverLostReplica でクラッシュしないようにしました。[#78173](https://github.com/ClickHouse/ClickHouse/pull/78173) ([Raúl Marín](https://github.com/Algunenano)).
* [#78239](https://github.com/ClickHouse/ClickHouse/issues/78239) でバックポート: system.s3&#95;queue&#95;settings の &quot;alterable&quot; カラムが常に `false` を返す問題を修正しました。[#78187](https://github.com/ClickHouse/ClickHouse/pull/78187) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#78312](https://github.com/ClickHouse/ClickHouse/issues/78312) でバックポート: キー配列が LowCardinality(Nullable) 型の場合の `mapFromArrays` におけるクラッシュや誤った結果を修正しました。[#78240](https://github.com/ClickHouse/ClickHouse/pull/78240) ([Eduard Karacharov](https://github.com/korowa)).
