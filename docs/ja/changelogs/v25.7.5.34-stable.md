<div id="improvement">
  #### 改善

* [#85729](https://github.com/ClickHouse/ClickHouse/issues/85729) にバックポート: `system.tables` にデータレイクのテーブルを追加するかどうかを制御する `show_data_lake_catalogs_in_system_tables` フラグを追加し、[#85384](https://github.com/ClickHouse/ClickHouse/issues/85384) を解決しました。[#85411](https://github.com/ClickHouse/ClickHouse/pull/85411) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)) 。

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#85759](https://github.com/ClickHouse/ClickHouse/issues/85759) にバックポート: Decimal types に対して parquet writer が誤った統計情報 (min/max) を出力する問題を修正しました。[#83754](https://github.com/ClickHouse/ClickHouse/pull/83754) ([Michael Kolupaev](https://github.com/al13n321)).
* [#85796](https://github.com/ClickHouse/ClickHouse/issues/85796) にバックポート: RowBinary フォーマットで NULL 値を含む JSON paths を書き込む際の問題を修正しました。[#83923](https://github.com/ClickHouse/ClickHouse/pull/83923) ([Pavel Kruglov](https://github.com/Avogar)).
* [#85883](https://github.com/ClickHouse/ClickHouse/issues/85883) にバックポート: 遅延マテリアライゼーション使用時に Variant カラムを読み取る際の問題を修正しました。[#84400](https://github.com/ClickHouse/ClickHouse/pull/84400) ([Pavel Kruglov](https://github.com/Avogar)).
* [#85778](https://github.com/ClickHouse/ClickHouse/issues/85778) にバックポート: `DeltaLake` エンジンの delta-kernel 実装における race condition を修正しました。[#85221](https://github.com/ClickHouse/ClickHouse/pull/85221) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#85620](https://github.com/ClickHouse/ClickHouse/issues/85620) にバックポート: 読み取り時の reverse in order 最適化を使用する並列レプリカを含むクエリで、誤った結果が返される可能性がある問題を修正しました。[#85406](https://github.com/ClickHouse/ClickHouse/pull/85406) ([Igor Nikonov](https://github.com/devcrafter)).
* [#85697](https://github.com/ClickHouse/ClickHouse/issues/85697) にバックポート: String のデシリアライゼーション中に MEMORY&#95;LIMIT&#95;EXCEEDED が発生した場合に起こりうる UB (クラッシュ) を修正しました。[#85440](https://github.com/ClickHouse/ClickHouse/pull/85440) ([Azat Khuzhin](https://github.com/azat)).
* [#85826](https://github.com/ClickHouse/ClickHouse/issues/85826) にバックポート: KafkaAssignedPartitions および KafkaConsumersWithAssignment メトリクスの誤りを修正しました。[#85494](https://github.com/ClickHouse/ClickHouse/pull/85494) ([Ilya Golshtein](https://github.com/ilejn)).
* [#85916](https://github.com/ClickHouse/ClickHouse/issues/85916) にバックポート: icebergS3Cluster および icebergAzureCluster テーブル関数での secrets のマスキングを修正しました。[#85658](https://github.com/ClickHouse/ClickHouse/pull/85658) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* [#85871](https://github.com/ClickHouse/ClickHouse/issues/85871) にバックポート: 大きな文字列に対する coalescing merge tree の segfault を修正しました。これにより [#84582](https://github.com/ClickHouse/ClickHouse/issues/84582) はクローズされます。[#85709](https://github.com/ClickHouse/ClickHouse/pull/85709) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#85854](https://github.com/ClickHouse/ClickHouse/issues/85854) にバックポート: MEMORY&#95;LIMIT&#95;EXCEEDED エラー時に、update&#95;field を使用する辞書で発生しうる不整合を修正しました。[#85807](https://github.com/ClickHouse/ClickHouse/pull/85807) ([Azat Khuzhin](https://github.com/azat)).
* [#85993](https://github.com/ClickHouse/ClickHouse/issues/85993) にバックポート: `Distributed` 宛先テーブルを持つ並列 distributed `INSERT SELECT` で、`WITH` ステートメントのグローバル定数をサポートしました。従来は、このクエリで `Unknown expression identifier` エラーが発生することがありました。[#85811](https://github.com/ClickHouse/ClickHouse/pull/85811) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#86041](https://github.com/ClickHouse/ClickHouse/issues/86041) にバックポート: `Replicated` database の復旧におけるバグを修正しました。テーブル名に `%` 記号が含まれている場合、復旧中に別の名前でテーブルが再作成される可能性がありました。[#85987](https://github.com/ClickHouse/ClickHouse/pull/85987) ([Alexander Tokmakov](https://github.com/tavplubix)).
