* [#99874](https://github.com/ClickHouse/ClickHouse/issues/99874) にバックポート: `View` で `Distributed` ストレージが使用される場合の、アナライザによる `optimize_skip_unused_shards` 最適化の不具合を修正しました。 [#98754](https://github.com/ClickHouse/ClickHouse/pull/98754) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#99669](https://github.com/ClickHouse/ClickHouse/issues/99669) にバックポート: クエリが重複したカラム名を生成する場合に `INTERSECT`/`EXCEPT` で発生する heap-use-after-free を修正しました。 [#99471](https://github.com/ClickHouse/ClickHouse/pull/99471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#100853](https://github.com/ClickHouse/ClickHouse/issues/100853) にバックポート: 実行中の読み取りクエリと同時にテーブルが drop された際に発生する heap-use-after-free を修正しました (過去 90 日間で CI に 19 件発生) 。 [#99483](https://github.com/ClickHouse/ClickHouse/pull/99483) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#101471](https://github.com/ClickHouse/ClickHouse/issues/101471) にバックポート: Keeper において、同じサーバー上の別の無関係なセッションが不運なタイミングで close されると、読み取りリクエストが停止したままになり (その結果セッションがタイムアウトする) 、復帰しなくなる不具合を修正しました。 [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* [#99897](https://github.com/ClickHouse/ClickHouse/issues/99897) にバックポート: クエリ: を修正しました。 [#99739](https://github.com/ClickHouse/ClickHouse/pull/99739) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102366](https://github.com/ClickHouse/ClickHouse/issues/102366) にバックポート: HEAD リクエストのレスポンスに `Content-Length` ヘッダーがない場合 (たとえば GCS での伸張トランスコーディングが原因の場合) に、ClickHouse がファイルをスキップしてしまう不具合を修正しました。 [#99971](https://github.com/ClickHouse/ClickHouse/pull/99971) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* [#101530](https://github.com/ClickHouse/ClickHouse/issues/101530) にバックポート: 一部のカタログで、`select * from system.databases` のクエリ結果の `SETTINGS` セクションに機密情報が表示されることがある問題を修正しました。この PR ではそのような挙動を防止します。 [#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#101183](https://github.com/ClickHouse/ClickHouse/issues/101183) にバックポート: サーバーのシャットダウン中に Dictionaries をロードする際、null ポインタ参照による segfault が発生する不具合を修正しました。`Context::getUserDefinedSQLObjectsStorage` (`user_defined_sql_objects_storage` を参照外しする) は Dictionary のスレッドから呼び出される一方で、メインスレッドは `Context::shutdown` を呼び出して `user_defined_sql_objects_storage` を null に設定します。`Context::shutdown` を実行する前に、Dictionary ローダーで今後の更新を無効化し、現在実行中の Dictionary クエリを kill し、Dictionary のロードスレッドを join することを確実にする必要があります。通常のクエリで行っていることと同様です。 [#100839](https://github.com/ClickHouse/ClickHouse/pull/100839) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#101087](https://github.com/ClickHouse/ClickHouse/issues/101087) にバックポート: 入力に非 ASCII バイトが含まれる場合の `ULIDStringToDateTime` における buffer overflow を修正しました。 [#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* [#101011](https://github.com/ClickHouse/ClickHouse/issues/101011) でバックポート: nullable な Tuple の Array に対する `intDiv`/`intDivOrZero` で発生する例外を修正。例: `SELECT intDiv([divide((1, 2), ... AND NULL)], 2)`。 [#100895](https://github.com/ClickHouse/ClickHouse/pull/100895) ([Raúl Marín](https://github.com/Algunenano)).
* [#101246](https://github.com/ClickHouse/ClickHouse/issues/101246) でバックポート: `StorageAlias` の定義を保存する前に engine 引数を評価するよう修正し、`currentDatabase()` のような expression がデータベースに保存される前に literal に解決されるようにしました。 [#100902](https://github.com/ClickHouse/ClickHouse/pull/100902) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#101958](https://github.com/ClickHouse/ClickHouse/issues/101958) でバックポート: 分片-by-PK 最適化を使用する JOIN で query condition cache が使われ、一部の パーツ が cached conditions によって除外される場合に、誤った結果が返る問題を修正。 [#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* [#101630](https://github.com/ClickHouse/ClickHouse/issues/101630) でバックポート: 小数秒が 18 桁を超える datetime 文字列のパース時に、parseDateTimeBestEffort で発生する未定義動作 (符号付き整数オーバーフロー) を修正。 [#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* [#101076](https://github.com/ClickHouse/ClickHouse/issues/101076) でバックポート: `Nullable(Tuple)` の導入後、1 つ以上の `Nullable` argument を持つ `sumCountOrDefault` aggregate function が古いシリアライゼーション済み state を読み取れなくなっていた問題を修正。 [#100882](https://github.com/ClickHouse/ClickHouse/issues/100882) をクローズ。 [#101021](https://github.com/ClickHouse/ClickHouse/pull/101021) ([Nihal Z. Miaji](https://github.com/nihalzp)).

* [#101930](https://github.com/ClickHouse/ClickHouse/issues/101930) でバックポート: ... [#101230](https://github.com/ClickHouse/ClickHouse/pull/101230) ([Kseniia Sumarokova](https://github.com/kssenii)).
