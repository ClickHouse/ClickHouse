  ### ClickHouse リリース v25.10.6.36-stable (853dbd2ee0c) FIXME v25.10.5.40-stable (93e6f3ffcbd) との比較

<div id="improvement">
  #### 改善
</div>

* [#94931](https://github.com/ClickHouse/ClickHouse/issues/94931) でバックポート: ダーティページのサイズと `max_server_memory_usage` の比率が `memory_worker_purge_dirty_pages_threshold_ratio` を超えた場合に、jemalloc アリーナのパージを強制実行するようにしました。[#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)).
* [#94728](https://github.com/ClickHouse/ClickHouse/issues/94728) でバックポート: S3 および Azure Blob Storage の BACKUP/RESTORE で、SQL で定義した named collections をサポートしました。[#94604](https://github.com/ClickHouse/ClickHouse/issues/94604) をクローズ。[#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)).
* [#94984](https://github.com/ClickHouse/ClickHouse/issues/94984) でバックポート: CPU が逼迫した状況では、スケジューラが MemoryWorker スレッドを優先するようにしました。これは ClickHouse プロセスを致命的な脅威から保護するためです。[#94864](https://github.com/ClickHouse/ClickHouse/pull/94864) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#95141](https://github.com/ClickHouse/ClickHouse/issues/95141) でバックポート: jemalloc のダーティページのパージを、MemoryWorker のメインスレッドとは別のスレッドで実行するようにしました。パージが遅いと RSS 使用量の更新が遅れ、プロセスがメモリ不足で kill される可能性があります。総メモリ使用量の比率に基づいてダーティページのパージを開始するための新しい config `memory_worker_purge_total_memory_threshold_ratio` を導入しました。[#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)).
* [#95434](https://github.com/ClickHouse/ClickHouse/issues/95434) でバックポート: `view_duration_ms` は、グループ内のスレッド duration の合計ではなく、そのグループがアクティブだった時間を表示するようになりました。[#94966](https://github.com/ClickHouse/ClickHouse/pull/94966) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#94621](https://github.com/ClickHouse/ClickHouse/issues/94621) でバックポート: `finish=true` フラグ付きのレスポンス送信後に、レプリカから別の読み取りリクエストを受信した際に発生しうる論理エラーを修正しました。これは `MergeTreeReadPoolParallelReplicas` 内の論理的な race condition によって起こりえましたが、発生する可能性は非常に低いものでした。[#90921](https://github.com/ClickHouse/ClickHouse/pull/90921) ([Nikita Taranov](https://github.com/nickitat)).
* [#95284](https://github.com/ClickHouse/ClickHouse/issues/95284) でバックポート: ON CLUSTER 使用時の CREATE USER 認証方式におけるクエリパラメータの置換を修正しました。認証方式内のクエリパラメータ (例: password) が置換されず、リモートノードで UNKNOWN&#95;QUERY&#95;PARAMETER エラーが発生していました。[#92777](https://github.com/ClickHouse/ClickHouse/pull/92777) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* [#94763](https://github.com/ClickHouse/ClickHouse/issues/94763) でバックポート: 右側の join key がスパースカラムである場合の join 結果を修正しました。これにより [#92920](https://github.com/ClickHouse/ClickHouse/issues/92920) をクローズします。私はこのバグを `set compatibility='23.3'` でしか再現できません。これをバックポートすべきかどうかは不明です。[#93038](https://github.com/ClickHouse/ClickHouse/pull/93038) ([Amos Bird](https://github.com/amosbird)).
* [#95528](https://github.com/ClickHouse/ClickHouse/issues/95528) でバックポート: 同じファイルをめぐって競合する同時実行バックアップを多数実行すると、backups によって server がクラッシュする可能性がありました。[#93659](https://github.com/ClickHouse/ClickHouse/pull/93659) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#94884](https://github.com/ClickHouse/ClickHouse/issues/94884) でバックポート: 再起動後に interserver host が変更された場合の Replicated DB の Attach を修正しました。[#93779](https://github.com/ClickHouse/ClickHouse/pull/93779) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#94590](https://github.com/ClickHouse/ClickHouse/issues/94590) でバックポート: ストレージ `Join` の `USING` clause を使った join 演算中における、super type への型変換を修正しました。[#91672](https://github.com/ClickHouse/ClickHouse/issues/91672) を修正。[#78572](https://github.com/ClickHouse/ClickHouse/issues/78572) を修正。[#94000](https://github.com/ClickHouse/ClickHouse/pull/94000) ([Dmitry Novik](https://github.com/novikd)).
* [#94356](https://github.com/ClickHouse/ClickHouse/issues/94356) でバックポート: JSON の型付きパスに対する不適切な check を修正しました。この check は [https://github.com/ClickHouse/ClickHouse/pull/92842](https://github.com/ClickHouse/ClickHouse/pull/92842) で導入されており、既存テーブルの起動時に error を引き起こす可能性があります。[#94070](https://github.com/ClickHouse/ClickHouse/pull/94070) ([Pavel Kruglov](https://github.com/Avogar)).
* [#95201](https://github.com/ClickHouse/ClickHouse/issues/95201) でバックポート: function から subcolumns への最適化が subcolumns に適用されない問題を修正しました。[#94323](https://github.com/ClickHouse/ClickHouse/pull/94323) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94927](https://github.com/ClickHouse/ClickHouse/issues/94927) でバックポート: 欠損カラムに対して `isNotNull` が評価される際に発生する、ANY LEFT JOIN 最適化中のクラッシュを修正しました。[#94600](https://github.com/ClickHouse/ClickHouse/pull/94600) ([Molly](https://github.com/ggmolly)).
* [#94820](https://github.com/ClickHouse/ClickHouse/issues/94820) でバックポート: BACKUP/RESTORE のリストア操作における権限の問題を修正しました。[#94617](https://github.com/ClickHouse/ClickHouse/pull/94617) ([Pablo Marcos](https://github.com/pamarcos)).
* [#94842](https://github.com/ClickHouse/ClickHouse/issues/94842)でバックポート: [https://github.com/ClickHouse/clickhouse-core-incidents/issues/1250](https://github.com/ClickHouse/clickhouse-core-incidents/issues/1250) を修正。おそらく取り違えにより、`data_type` (`DataTypeNullable*` の場合がある) が `DataTypeDateTime64*` に `static_cast` されていました。代わりに、`check_type` (ネストされた型変数) をキャストすべきです。[#94627](https://github.com/ClickHouse/ClickHouse/pull/94627) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
