* [#89572](https://github.com/ClickHouse/ClickHouse/issues/89572) にバックポート: JSON 内の Float と Bools が混在する配列の読み取りを修正しました。以前は、このようなデータを挿入すると例外が発生していました。[#88008](https://github.com/ClickHouse/ClickHouse/pull/88008) ([Pavel Kruglov](https://github.com/Avogar)).
* [#89233](https://github.com/ClickHouse/ClickHouse/issues/89233) にバックポート: *cluster 関数における SQL SECURITY DEFINER を修正しました。[#88588](https://github.com/ClickHouse/ClickHouse/pull/88588) ([Julian Maicher](https://github.com/jmaicher)).
* [#89440](https://github.com/ClickHouse/ClickHouse/issues/89440) にバックポート: サブクエリを含む新しいアナライザで発生しうる &quot;Context has expired&quot; を修正しました。[#88694](https://github.com/ClickHouse/ClickHouse/pull/88694) ([Azat Khuzhin](https://github.com/azat)).
* [#89460](https://github.com/ClickHouse/ClickHouse/issues/89460) にバックポート: 内部テーブルの DROP 時に、settings max&#95;table&#95;size&#95;to&#95;drop および max&#95;partition&#95;size&#95;to&#95;drop によるサイズ制限の伝播を修正しました。[#88812](https://github.com/ClickHouse/ClickHouse/pull/88812) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#89288](https://github.com/ClickHouse/ClickHouse/issues/89288) にバックポート: 存在しないロールを持つユーザーが clusterAllReplicas を実行しようとした際に発生する ACCESS&#95;ENTITY&#95;NOT&#95;FOUND エラーを修正しました。[#87670](https://github.com/ClickHouse/ClickHouse/issues/87670) を解決しました。[#89068](https://github.com/ClickHouse/ClickHouse/pull/89068) ([pufit](https://github.com/pufit)).
* [#89481](https://github.com/ClickHouse/ClickHouse/issues/89481) にバックポート: `deduplicate_merge_projection_mode='ignore'` 使用時に、有効期限 (TTL) によって空になったパーツと空でないプロジェクションがある場合の誤ったマージ処理を修正しました。[#89430](https://github.com/ClickHouse/ClickHouse/issues/89430) を解決しました。[#89458](https://github.com/ClickHouse/ClickHouse/pull/89458) ([Amos Bird](https://github.com/amosbird)).
* [#89564](https://github.com/ClickHouse/ClickHouse/issues/89564) にバックポート: rotation 中に changelog が正しくリネームされなかった場合の、Keeper 起動時における changelog の読み取りを修正しました。[#89496](https://github.com/ClickHouse/ClickHouse/pull/89496) ([Antonio Andelic](https://github.com/antonio2368)).
* [#89589](https://github.com/ClickHouse/ClickHouse/issues/89589) にバックポート済み: アナライザおよび PK IN (サブクエリ) で発生する可能性がある &quot;Context has expired&quot; を修正 (v2)。[#89433](https://github.com/ClickHouse/ClickHouse/issues/89433) を修正。[#89527](https://github.com/ClickHouse/ClickHouse/pull/89527) ([Azat Khuzhin](https://github.com/azat))。

* [#89898](https://github.com/ClickHouse/ClickHouse/issues/89898) にバックポート済み: `IN` 関数内の空の Tuple に関する論理エラーを修正。[#88343](https://github.com/ClickHouse/ClickHouse/issues/88343) をクローズ。[#89850](https://github.com/ClickHouse/ClickHouse/pull/89850) ([Nihal Z. Miaji](https://github.com/nihalzp))。

* [#90084](https://github.com/ClickHouse/ClickHouse/issues/90084) にバックポート済み: `BSONEachRow` および `MsgPack` で、空の Tuple カラムが原因で発生する論理エラーを修正。[#89814](https://github.com/ClickHouse/ClickHouse/issues/89814) をクローズ。[#71536](https://github.com/ClickHouse/ClickHouse/issues/71536) をクローズ。[#90018](https://github.com/ClickHouse/ClickHouse/pull/90018) ([Nihal Z.
