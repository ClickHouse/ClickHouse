<div id="performance-improvement">
  #### パフォーマンス改善

* [#104164](https://github.com/ClickHouse/ClickHouse/issues/104164) でバックポート: 非圧縮キャッシュが無効な場合 (サーバー設定 `index_uncompressed_cache_size = 0`。これはデフォルト値です) に、インデックスの非圧縮キャッシュによるオーバーヘッドを回避します。[#104063](https://github.com/ClickHouse/ClickHouse/pull/104063) ([Michael Kolupaev](https://github.com/al13n321)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#104797](https://github.com/ClickHouse/ClickHouse/issues/104797) にバックポート: キー引数が `Nullable` の場合に `dictGetOrDefault` で発生する null ポインタの逆参照を修正しました。[#98460](https://github.com/ClickHouse/ClickHouse/pull/98460) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#104022](https://github.com/ClickHouse/ClickHouse/issues/104022) にバックポート: JSON カラムに行を挿入する際、その行によって非互換な値を持つ型付きフィールドと併存する新しい動的フィールドが導入され、さらにそのカラムが GROUP BY キーとして使用された場合に発生しうる例外を修正しました。[#100758](https://github.com/ClickHouse/ClickHouse/pull/100758) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* [#102430](https://github.com/ClickHouse/ClickHouse/issues/102430) にバックポート: S3 `Client::~Client` デストラクタから例外が漏れ出し、server が終了してしまう問題を修正しました。[#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
* [#102447](https://github.com/ClickHouse/ClickHouse/issues/102447) にバックポート: Array 型に対する Coalescing merge tree の不具合を修正しました。これにより [#89509](https://github.com/ClickHouse/ClickHouse/issues/89509) をクローズします。[#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#104148](https://github.com/ClickHouse/ClickHouse/issues/104148) にバックポート: row policies/additional&#95;table&#95;filters 使用時の単純な LIMIT 最適化を無効化しました (並列索引解析を可能にするため) 。[#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* [#104210](https://github.com/ClickHouse/ClickHouse/issues/104210) にバックポート: materialized view を伴わない通常の INSERT では、過剰な ConcurrencyControl の slots や threads (`max_insert_threads` ではなく `max_threads`) を要求しないようになり、INSERT スループットが高いクラスターでの CC slot 枯渇や thread 数の急増を防止します。[#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).
* [#104613](https://github.com/ClickHouse/ClickHouse/issues/104613) にバックポート: ClickHouse、MySQL、PostgreSQL、および XDBC の dictionary sources において、`clone() const` が `invalidate_query_response` 文字列を読み取り、`isModified() const` が同じ文字列に書き込むことで発生する data race を修正しました。[#103277](https://github.com/ClickHouse/ClickHouse/pull/103277) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#105212](https://github.com/ClickHouse/ClickHouse/issues/105212) にバックポート: `AggregateFunction` の state に整数を掛ける際に発生する heap-use-after-free (例: `quantilesExactState(...) * N`) を修正しました。二乗法によるべき乗ループで state を自身と `merge` していましたが、aggregate function の `merge` が内部ストレージを再確保する場合、これは undefined です。STID 0988-40af をクローズします。[#103536](https://github.com/ClickHouse/ClickHouse/pull/103536) ([Groene AI](https://github.com/groeneai)).
* 25.8.22 へのアップグレード後、S3 disk 上で GCS を使用した際に発生していた `S3_ERROR: Response checksums mismatch` を修正しました (`aws-sdk-cpp` 1.11.771 が CRC32 flexible checksums をデフォルトで有効化し、GCS がこれをサポートしていなかったことが原因です) 。[#103542](https://github.com/ClickHouse/ClickHouse/pull/103542) ([Eugene Klimov](https://github.com/Slach)).
* [#103752](https://github.com/ClickHouse/ClickHouse/issues/103752) にバックポート: ログ内でネストされた credentials のマスキング処理を修正しました。[#103552](https://github.com/ClickHouse/ClickHouse/pull/103552) ([Vitaly Baranov](https://github.com/vitlibar)).
* [#103793](https://github.com/ClickHouse/ClickHouse/issues/103793) でバックポート: 小数部が二重になった `dateTime` のパース中に発生する未定義動作を修正しました。[#103773](https://github.com/ClickHouse/ClickHouse/pull/103773) ([Yarik Briukhovetskyi](https://github.com/yariks5s))。
* [#105077](https://github.com/ClickHouse/ClickHouse/issues/105077) でバックポート: `StorageKafka2` における use-after-free を修正しました。これにより、consumer が一時的な topic-partition ロックを保持している間に Keeper セッションが置き換えられた際、server がクラッシュする可能性がありました。[#103890](https://github.com/ClickHouse/ClickHouse/pull/103890) ([Groene AI](https://github.com/groeneai))。
* [#104189](https://github.com/ClickHouse/ClickHouse/issues/104189) でバックポート: `quantileTiming` state のデシリアライズ中に発生する境界外書き込みを修正しました。[#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#104775](https://github.com/ClickHouse/ClickHouse/issues/104775) でバックポート: Postgres 配列のパース時に発生する可能性のあるアンダーフローを修正しました。[#104322](https://github.com/ClickHouse/ClickHouse/pull/104322) ([Grant Holly](https://github.com/grantholly-clickhouse))。
* [#105234](https://github.com/ClickHouse/ClickHouse/issues/105234) でバックポート: `<placement>` が設定されていない Keeper に対して `quorum_reads=true` を付けて `get /keeper/availability_zone` を送信した際に発生する、Keeper の終了と再起動のループを修正しました。[#104663](https://github.com/ClickHouse/ClickHouse/pull/104663) ([myeongjun](https://github.com/myeongjjun))。
* [#104953](https://github.com/ClickHouse/ClickHouse/issues/104953) でバックポート: `FutureSetFromTuple::buildOrderedSetInplace` における TOCTOU data race を修正し、これによって発生する論理エラーを解消しました。[#104673](https://github.com/ClickHouse/ClickHouse/pull/104673) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
* [#104842](https://github.com/ClickHouse/ClickHouse/issues/104842) でバックポート: `AvroConfluentRowInputFormat` の use-after-free バグによって発生する segfault を修正しました。[#104751](https://github.com/ClickHouse/ClickHouse/pull/104751) ([Miсhael Stetsyuk](https://github.com/mstetsyuk))。
