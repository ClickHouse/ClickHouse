<div id="improvement">
  #### 改善
</div>

* [#95144](https://github.com/ClickHouse/ClickHouse/issues/95144)でバックポート: dirty pages のサイズの `max_server_memory_usage` に対する比率が `memory_worker_purge_dirty_pages_threshold_ratio` を超えた場合に、jemalloc アリーナのパージを強制的に実行するようにしました。[#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)).
* [#94727](https://github.com/ClickHouse/ClickHouse/issues/94727)でバックポート: S3 および Azure Blob Storage 向けの BACKUP/RESTORE で、SQL で定義された named collections をサポートしました。[#94604](https://github.com/ClickHouse/ClickHouse/issues/94604) をクローズしました。[#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)).
* [#95165](https://github.com/ClickHouse/ClickHouse/issues/95165)でバックポート: jemalloc の dirty pages のパージを、MemoryWorker のメインスレッドとは別のスレッドで実行するようにしました。パージが遅い場合、RSS 使用量の更新が遅れ、その結果、プロセスがメモリ不足で強制終了される可能性があります。総メモリ使用量の比率に基づいて dirty pages のパージを開始するための新しい config `memory_worker_purge_total_memory_threshold_ratio` を導入しました。[#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)).
* [#95432](https://github.com/ClickHouse/ClickHouse/issues/95432)でバックポート: `view_duration_ms` は、グループ内の threads の Duration の合計ではなく、そのグループがアクティブだった時間を表示するようになりました。[#94966](https://github.com/ClickHouse/ClickHouse/pull/94966) ([Sema Checherinda](https://github.com/CheSema)).

* [#94761](https://github.com/ClickHouse/ClickHouse/issues/94761) でバックポート: 右側の join key がスパースなカラムである場合の JOIN 結果を修正しました。これにより [#92920](https://github.com/ClickHouse/ClickHouse/issues/92920) はクローズされます。このバグは `set compatibility='23.3'` でしか再現できません。バックポートすべきかどうかは不明です。[#93038](https://github.com/ClickHouse/ClickHouse/pull/93038) ([Amos Bird](https://github.com/amosbird)).

* [#95349](https://github.com/ClickHouse/ClickHouse/issues/95349) でバックポート: 再起動後に interserver host が変更された場合の Replicated DB の Attach を修正しました。[#93779](https://github.com/ClickHouse/ClickHouse/pull/93779) ([Tuan Pham Anh](https://github.com/tuanpach)).

* [#95200](https://github.com/ClickHouse/ClickHouse/issues/95200) でバックポート: function から subcolumns への最適化が subcolumns に適用されない問題を修正しました。[#94323](https://github.com/ClickHouse/ClickHouse/pull/94323) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94926](https://github.com/ClickHouse/ClickHouse/issues/94926) でバックポート: 存在しないカラムに対して `isNotNull` が評価された際の ANY LEFT JOIN 最適化中のクラッシュを修正しました。[#94600](https://github.com/ClickHouse/ClickHouse/pull/94600) ([Molly](https://github.com/ggmolly)).
