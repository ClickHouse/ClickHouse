  ### ClickHouse リリース v26.3.5.12-lts (172e4255c5c) FIXME (v26.3.4.11-lts (8186e0e780d) との比較)

<div id="performance-improvement">
  #### パフォーマンス改善
</div>

* [#101736](https://github.com/ClickHouse/ClickHouse/issues/101736) でバックポート: `deduplicate_insert=enable` (26.2 以降ではデフォルト) 時に発生していた重大な INSERT のパフォーマンス低下を修正しました。データのハッシュ計算をまとめる処理からシンク側へ遅らせ、`updateHashWithValueRange` によるバッチ単位のカラムハッシュを使用することで、22 カラム・500万行の場合のオーバーヘッドを約 2.5 秒から約 0.5 秒に削減します。[#101494](https://github.com/ClickHouse/ClickHouse/pull/101494) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### 改善
</div>

* [#101949](https://github.com/ClickHouse/ClickHouse/issues/101949) でバックポート: サーバー起動時の cache のロードを最適化しました。[#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#102140](https://github.com/ClickHouse/ClickHouse/issues/102140) でバックポート: 内部の mongo-c-driver を 2.2.2 から 2.2.3 に引き上げました。[#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#101962](https://github.com/ClickHouse/ClickHouse/issues/101962) でバックポート: shard-by-PK 最適化を伴う JOIN で query condition cache を使用し、一部のパーツがキャッシュされた条件によって除外された場合に、誤った結果が返される不具合を修正しました。 [#100926](https://github.com/ClickHouse/ClickHouse/pull/100926) ([Groene AI](https://github.com/groeneai)).
* [#101987](https://github.com/ClickHouse/ClickHouse/issues/101987) でバックポート: 起動依存関係の順序が誤っていたことにより、非同期起動中に内部テーブルを持つ materialized view で発生していた &quot;Target table doesn&#39;t exist&quot; エラーを修正しました。 [#100946](https://github.com/ClickHouse/ClickHouse/pull/100946) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#101563](https://github.com/ClickHouse/ClickHouse/issues/101563) でバックポート: replicated merge tree を使用する Delta Lake クラスターでの insert-select を修正しました。 [#101299](https://github.com/ClickHouse/ClickHouse/pull/101299) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* [#102076](https://github.com/ClickHouse/ClickHouse/issues/102076) でバックポート: `Object` 型の動的パスの並列デシリアライゼーションにおける use-after-scope を修正しました。これにより、多数の動的パスを持つテーブルの読み取り時にクラッシュが発生する可能性がありました。 [#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* [#102102](https://github.com/ClickHouse/ClickHouse/issues/102102) でバックポート: 特定の (デフォルト以外の) フォーマット設定において、関数 `formatDateTime` のフォーマッタ `%W` で出力が不正になる問題を修正しました。 [#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* [#102030](https://github.com/ClickHouse/ClickHouse/issues/102030) でバックポート: 定期リフレッシュ中に ZooKeeper セッションが期限切れになった場合に UDF レジストリが失われる問題を修正しました。これにより、full refresh が成功するまで、すべてのユーザー定義関数が利用できなくなる可能性がありました。 [#101891](https://github.com/ClickHouse/ClickHouse/pull/101891) ([Nikita Fomichev](https://github.com/fm4v)).
* [#102094](https://github.com/ClickHouse/ClickHouse/issues/102094) でバックポート: `splitByString` トークナイザーが空の区切り文字列を拒否するようになりました。 [#101928](https://github.com/ClickHouse/ClickHouse/pull/101928) ([Robert Schulze](https://github.com/rschu1ze)).
