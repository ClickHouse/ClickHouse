<div id="improvement">
  #### 改善
</div>

* [#82417](https://github.com/ClickHouse/ClickHouse/issues/82417) にバックポート: best effortによるDateTime64のパースで、小数部を含む Unix タイムスタンプをサポートしました。[#78908](https://github.com/ClickHouse/ClickHouse/pull/78908) ([Pavel Kruglov](https://github.com/Avogar)).
* [#82413](https://github.com/ClickHouse/ClickHouse/issues/82413) にバックポート: ハッシュ関数で、配列、タプル、マップ内の NULL をサポートするようになりました。 (issues [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) および [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)) 。[#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* [#81801](https://github.com/ClickHouse/ClickHouse/issues/81801) にバックポート: プロファイルイベント `PageCacheReadBytes` を追加しました。[#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#82593](https://github.com/ClickHouse/ClickHouse/issues/82593) にバックポート: Keeper の改善: 新しい設定 `keeper_server.cleanup_old_and_ignore_new_acl` を追加しました。これを有効にすると、すべてのノードの ACL がクリアされ、新しいリクエストに対する ACL は無視されます。ノードから ACL を完全に削除することが目的であれば、新しいスナップショットが作成されるまでこの設定を有効のままにしておくことが重要です。[#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* [#82858](https://github.com/ClickHouse/ClickHouse/issues/82858) にバックポート: [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834) 以降、`X-ClickHouse-Progress` と `X-ClickHouse-Summary` のヘッダーフォーマットは、値が 0 の項目を省略するよう変更されていました。この PR では、妥当と判断される `X-ClickHouse-Summary` についてのみ、以前の動作に戻します。[#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* [#82924](https://github.com/ClickHouse/ClickHouse/issues/82924) にバックポート: Keeper の改善: world:anyone ACL に対する個別の権限をサポートしました。[#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#82185](https://github.com/ClickHouse/ClickHouse/issues/82185) にバックポート: カラム型が Nullable に変更された際に、projection の materialize 中に発生する論理エラーを修正しました。[#80741](https://github.com/ClickHouse/ClickHouse/pull/80741) ([Pavel Kruglov](https://github.com/Avogar))。
* [#81811](https://github.com/ClickHouse/ClickHouse/issues/81811) にバックポート: ソーステーブルがイニシエータに存在しない場合に、プッシュダウンされた predicate (`allow_push_predicate_ast_for_distributed_subqueries=1`) を含む distributed queries で発生する `Table does not exist` エラーを修正しました。[#77281](https://github.com/ClickHouse/ClickHouse/issues/77281) を修正。[#80915](https://github.com/ClickHouse/ClickHouse/pull/80915) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#82014](https://github.com/ClickHouse/ClickHouse/issues/82014) にバックポート: クロスレプリケーション環境で `distributed_product_mode_local=local` を使用した場合の `Unknown table expression identifier` を修正しました。[#81162](https://github.com/ClickHouse/ClickHouse/pull/81162) ([Nikolai Kochetov](https://github.com/KochetovNicolai))。
* [#82330](https://github.com/ClickHouse/ClickHouse/issues/82330) にバックポート: 左側の argument が null で、サブクエリの結果が non-nullable の場合に、`transform_null_in=1` での `IN` 実行を修正しました。[#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar))。
* [#82175](https://github.com/ClickHouse/ClickHouse/issues/82175) にバックポート: 既存テーブルの読み取り時に実行される default/materialize expression では、experimental/suspicious types の検証を行わないようにしました。[#81618](https://github.com/ClickHouse/ClickHouse/pull/81618) ([Pavel Kruglov](https://github.com/Avogar))。
* [#82124](https://github.com/ClickHouse/ClickHouse/issues/82124) にバックポート: 有効期限 (TTL) expression で dict を使用している場合に、merges 中に発生する &quot;Context has expired&quot; を修正しました。[#81690](https://github.com/ClickHouse/ClickHouse/pull/81690) ([Azat Khuzhin](https://github.com/azat))。
* [#82323](https://github.com/ClickHouse/ClickHouse/issues/82323) にバックポート: 以前のバージョンでは、`/js` への requests に対して server が過剰な内容を返していました。これにより [#61890](https://github.com/ClickHouse/ClickHouse/issues/61890) をクローズします。[#81895](https://github.com/ClickHouse/ClickHouse/pull/81895) ([Alexey Milovidov](https://github.com/alexey-milovidov))。
* [#82235](https://github.com/ClickHouse/ClickHouse/issues/82235) にバックポート: 以前は、`MongoDB` table engine の定義で `host:port` argument にパス部分を含めることができ、その部分は暗黙的に無視されていました。mongodb インテグレーションは、そのようなテーブルの読み込みを拒否します。この修正により、`MongoDB` engine が 5 つの argument を持つ場合は、argument の database 名を使用して、そのようなテーブルの読み込みを許可し、*パス部分は無視されます*。*注:* この修正は、新規作成されたテーブルや `mongo` table function を使用するクエリ、dictionary sources、および named collections には適用されません。[#81942](https://github.com/ClickHouse/ClickHouse/pull/81942) ([Vladimir Cherkasov](https://github.com/vdimir))。
* [#82777](https://github.com/ClickHouse/ClickHouse/issues/82777) にバックポート: クエリで定数の alias カラムだけが使われている場合の filter 分析を修正しました。[#79448](https://github.com/ClickHouse/ClickHouse/issues/79448) を修正。[#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd))。
* [#82550](https://github.com/ClickHouse/ClickHouse/issues/82550) にバックポート: TTL の GROUP BY と SET で同じカラムを使用した際に発生する LOGICAL&#95;ERROR と、それに続く crash を修正しました。[#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos))。
* [#82153](https://github.com/ClickHouse/ClickHouse/issues/82153) にバックポート: arraySimilarity のコピー＆ペーストミスを修正し、UInt32 および Int32 の weights の使用を禁止しました。テストとドキュメントも更新しました。[#82103](https://github.com/ClickHouse/ClickHouse/pull/82103) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* [#82316](https://github.com/ClickHouse/ClickHouse/issues/82316) にバックポート: `WHERE` 条件および `IndexSet` 配下で `arrayJoin` を含むクエリに対して発生する `Not found column` エラーを修正しました。[#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)) 。
* [#82558](https://github.com/ClickHouse/ClickHouse/issues/82558) にバックポート: server がメモリ逼迫状態にある場合に、リモートクエリで発生しうるデッドロックを修正しました。[#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)) 。
* [#82521](https://github.com/ClickHouse/ClickHouse/issues/82521) にバックポート: AWS ECS token に有効期限を追加し、再読み込みできるようにしました。[#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)) 。
* [#82577](https://github.com/ClickHouse/ClickHouse/issues/82577) にバックポート: logs/query&#95;log で named collection の values を隠す処理を修正しました。[#82405](https://github.com/ClickHouse/ClickHouse/issues/82405) をクローズしました。[#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)) 。
* [#82568](https://github.com/ClickHouse/ClickHouse/issues/82568) にバックポート: user&#95;id が空の場合があるため、session 終了時のロギングで発生しうる crash を修正しました。[#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)) 。
* [#82686](https://github.com/ClickHouse/ClickHouse/issues/82686) にバックポート: 相関付けられたカラムに対する row policy expression の解析中に発生する `LOGICAL_ERROR` を修正しました。[#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd)) 。
* [#82733](https://github.com/ClickHouse/ClickHouse/issues/82733) にバックポート: Functions `trim{Left,Right,Both}` が &quot;FixedString(N)&quot; 型の入力文字列をサポートするようになりました。たとえば、`SELECT trimBoth(toFixedString('abc', 3), 'ac')` が動作するようになりました。[#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)) 。
* [#82798](https://github.com/ClickHouse/ClickHouse/issues/82798) にバックポート: 要素が空の場合の `groupArraySample`/`groupArrayLast` のデシリアライゼーションを修正しました (入力が空の場合、デシリアライゼーションによって binary の一部がスキップされることがあり、これによりデータ読み取り時の破損や、TCP protocol における UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER につながる可能性があります) 。これは numbers および date time types には影響しません。[#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)) 。
