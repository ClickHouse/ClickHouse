<div id="improvement">
  #### 改善
</div>

* [#94933](https://github.com/ClickHouse/ClickHouse/issues/94933)でバックポート: ダーティページのサイズと `max_server_memory_usage` の比率が `memory_worker_purge_dirty_pages_threshold_ratio` を超えた場合、jemalloc アリーナのパージを強制的に実行するようにしました。[#93500](https://github.com/ClickHouse/ClickHouse/pull/93500) ([Eduard Karacharov](https://github.com/korowa)).
* [#94729](https://github.com/ClickHouse/ClickHouse/issues/94729)でバックポート: S3 および Azure Blob Storage の BACKUP/RESTORE で、SQL で定義された named collection をサポートしました。[#94604](https://github.com/ClickHouse/ClickHouse/issues/94604) をクローズしました。[#94605](https://github.com/ClickHouse/ClickHouse/pull/94605) ([Pablo Marcos](https://github.com/pamarcos)).
* [#95166](https://github.com/ClickHouse/ClickHouse/issues/95166)でバックポート: jemalloc のダーティページのパージを、MemoryWorker のメインスレッドとは別のスレッドで実行するようにしました。パージに時間がかかると RSS 使用量の更新が遅れ、結果としてプロセスが OOM により kill される可能性があります。総メモリ使用量の比率に基づいてダーティページのパージを開始するための新しい config `memory_worker_purge_total_memory_threshold_ratio` を導入しました。[#94902](https://github.com/ClickHouse/ClickHouse/pull/94902) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#94765](https://github.com/ClickHouse/ClickHouse/issues/94765) でバックポート: 右側の join key がスパースなカラムである場合に JOIN result が正しくならない問題を修正しました。これにより [#92920](https://github.com/ClickHouse/ClickHouse/issues/92920) をクローズします。この bug は `set compatibility='23.3'` を設定した場合にのみ再現できます。バックポートすべきかどうかは不明です。[#93038](https://github.com/ClickHouse/ClickHouse/pull/93038) ([Amos Bird](https://github.com/amosbird)).
* [#94886](https://github.com/ClickHouse/ClickHouse/issues/94886) でバックポート: 再起動後に interserver host が変更された場合に、Replicated DB を Attach できない問題を修正しました。[#93779](https://github.com/ClickHouse/ClickHouse/pull/93779) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#94592](https://github.com/ClickHouse/ClickHouse/issues/94592) でバックポート: `USING` clause を使用したストレージ `Join` の演算中に、スーパータイプへの型変換で発生する問題を修正しました。[#91672](https://github.com/ClickHouse/ClickHouse/issues/91672) を修正。[#78572](https://github.com/ClickHouse/ClickHouse/issues/78572) を修正。[#94000](https://github.com/ClickHouse/ClickHouse/pull/94000) ([Dmitry Novik](https://github.com/novikd)).
* [#94357](https://github.com/ClickHouse/ClickHouse/issues/94357) でバックポート: JSON の型付きパスに対する不適切なチェックを修正しました。このチェックは [https://github.com/ClickHouse/ClickHouse/pull/92842](https://github.com/ClickHouse/ClickHouse/pull/92842) で導入され、既存テーブルの起動時にエラーを引き起こす可能性があります。[#94070](https://github.com/ClickHouse/ClickHouse/pull/94070) ([Pavel Kruglov](https://github.com/Avogar)).
* [#95202](https://github.com/ClickHouse/ClickHouse/issues/95202) でバックポート: 関数を subcolumns に最適化する処理が subcolumns に適用されない問題を修正しました。[#94323](https://github.com/ClickHouse/ClickHouse/pull/94323) ([Pavel Kruglov](https://github.com/Avogar)).
* [#94718](https://github.com/ClickHouse/ClickHouse/issues/94718) でバックポート: 存在しないカラムに対して `isNotNull` が評価された際に、ANY LEFT JOIN の最適化中に発生する crash を修正しました。[#94600](https://github.com/ClickHouse/ClickHouse/pull/94600) ([Molly](https://github.com/ggmolly)).
* [#94813](https://github.com/ClickHouse/ClickHouse/issues/94813) でバックポート: BACKUP/RESTORE 操作における権限の問題を修正しました。[#94617](https://github.com/ClickHouse/ClickHouse/pull/94617) ([Pablo Marcos](https://github.com/pamarcos)).
* [#94844](https://github.com/ClickHouse/ClickHouse/issues/94844) でバックポート: [https://github.com/ClickHouse/clickhouse-core-incidents/issues/1250](https://github.com/ClickHouse/clickhouse-core-incidents/issues/1250) を修正しました。おそらく取り違えにより、`data_type` (`DataTypeNullable*` である可能性があります) が `DataTypeDateTime64*` に `static_cast` されています。代わりに、`check_type` (Nested type の変数) をキャストすべきです。[#94627](https://github.com/ClickHouse/ClickHouse/pull/94627) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* [#94796](https://github.com/ClickHouse/ClickHouse/issues/94796) でバックポート: 複雑な ON conditions を使用した場合に RIGHT JOIN result が不正になる可能性がある問題を修正しました。[#92913](https://github.com/ClickHouse/ClickHouse/issues/92913) をクローズ。[#94680](https://github.com/ClickHouse/ClickHouse/pull/94680) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#94786](https://github.com/ClickHouse/ClickHouse/issues/94786) でバックポート: Vertical merges の後も一定の index granularity (use&#95;const&#95;adaptive&#95;granularity) を維持するようにしました。[#94725](https://github.com/ClickHouse/ClickHouse/pull/94725) ([Azat Khuzhin](https://github.com/azat)).
* [#95150](https://github.com/ClickHouse/ClickHouse/issues/95150)でバックポート: `getURLHostRFC` 関数では、ポインタをデリファレンスする前の境界チェックが不足していました。空文字列が `domainRFC` に渡されると、未初期化メモリを読み取り、MSan エラーを引き起こしていました。[#94851](https://github.com/ClickHouse/ClickHouse/pull/94851) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#94994](https://github.com/ClickHouse/ClickHouse/issues/94994)でバックポート: 暗号化されたディスクの readonly 状態を修正。[#94852](https://github.com/ClickHouse/ClickHouse/pull/94852) ([Azat Khuzhin](https://github.com/azat)).
* [#95034](https://github.com/ClickHouse/ClickHouse/issues/95034)でバックポート: 分散テーブルで古いアナライザを使用した場合の、小数の `LIMIT/OFFSET` における論理エラーを修正。[#94712](https://github.com/ClickHouse/ClickHouse/issues/94712) をクローズ。[#94999](https://github.com/ClickHouse/ClickHouse/pull/94999) ([Ahmed Gouda](https://github.com/0xgouda)).
* [#95215](https://github.com/ClickHouse/ClickHouse/issues/95215)でバックポート: JOIN ランタイムフィルタがデフォルトで有効な場合に、特定の条件下で発生するクラッシュを修正。[#95000](https://github.com/ClickHouse/ClickHouse/pull/95000) ([Alexander Gololobov](https://github.com/davenger)).
