<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#92901](https://github.com/ClickHouse/ClickHouse/issues/92901) でバックポート: 同名のカラムとサブカラムが存在する場合に、誤ったシリアライゼーションが使用されてクエリが失敗する可能性がある競合を修正しました。[#90219](https://github.com/ClickHouse/ClickHouse/issues/90219) をクローズ。[#85161](https://github.com/ClickHouse/ClickHouse/issues/85161) をクローズ。[#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92988](https://github.com/ClickHouse/ClickHouse/issues/92988) でバックポート: 切断された `Connection` からの読み取りによって発生するクラッシュを回避しました。[#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* [#92879](https://github.com/ClickHouse/ClickHouse/issues/92879) でバックポート: `Ordered` モードの `S3Queue` ストレージにおける論理エラー ` Failed to set file processing within 100 retries` を修正しました。このエラーは警告に置き換えられました。このエラーは、Keeper セッションの有効期限が切れた場合、25.10 より前のバージョンでも発生する可能性がありました。ただし、`Ordered` モードでは処理の並行度が高い場合に理論上このエラーが発生する可能性が依然としてあるため、25.10+ バージョンでも引き続き警告となります。[#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#92943](https://github.com/ClickHouse/ClickHouse/issues/92943) でバックポート: `WHERE` clause の述語にサブクエリを含む `IN` clause がある論理更新で、プライマリインデックスの使用を修正しました。[#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* [#92962](https://github.com/ClickHouse/ClickHouse/issues/92962) でバックポート: `ratio_of_defaults_for_sparse_serialization=0.0` のスパースカラムで mutation 後に `FILE_DOESNT_EXIST` エラーが発生する可能性を修正しました。[#92633](https://github.com/ClickHouse/ClickHouse/issues/92633) をクローズ。[#92860](https://github.com/ClickHouse/ClickHouse/pull/92860) ([Pavel Kruglov](https://github.com/Avogar)).
* [#92934](https://github.com/ClickHouse/ClickHouse/issues/92934) でバックポート: JSON カラムが Tupe カラムの後に来る場合の、古い Parquet リーダー (デフォルトでは未使用) における Parquet スキーマ推論を修正しました。また、空の tuple で失敗する古い Parquet リーダー (デフォルトでは未使用) も修正しました。[#92867](https://github.com/ClickHouse/ClickHouse/pull/92867) ([Michael Kolupaev](https://github.com/al13n321)).
* [#93032](https://github.com/ClickHouse/ClickHouse/issues/93032) でバックポート: 共有パーツにおける TOCTOU race により、outdated parts が使用される可能性を修正しました。[#93022](https://github.com/ClickHouse/ClickHouse/pull/93022) ([Azat Khuzhin](https://github.com/azat)).
