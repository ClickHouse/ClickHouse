* [#100900](https://github.com/ClickHouse/ClickHouse/issues/100900) でバックポート: MergeTree の Map カラム向けに、バケット化シリアライゼーション (`map_serialization_version = 'with_buckets'`) を追加しました。キーはハッシュベースのバケットに分割されるため、単一キー (`m['key']`) の読み取り時にはカラム全体ではなく 1 つのバケットだけを読めばよく、map のサイズに応じて単一キーのルックアップが 2～49 倍高速化されます。バケット数とバケット化の戦略は、新しい MergeTree 設定 `map_serialization_version`、`max_buckets_in_map`、`map_buckets_strategy`、`map_buckets_coefficient`、`map_buckets_min_avg_size` で制御できます。設定 `map_serialization_version_for_zero_level_parts` を使うと、insert では書き込みオーバーヘッドを避けるため基本シリアライゼーションを維持しつつ、マージ済みパーツではバケットを使用できます。バケット化シリアライゼーションでは、`mapKeys/mapValues` に対するスキップ索引がサポートされます。`optimize_functions_to_subcolumns` パスは、バケットが利用可能な場合に `m['key']` をキーごとの subcolumn 読み取りへ書き換えます。[#99200](https://github.com/ClickHouse/ClickHouse/pull/99200) ([Pavel Kruglov](https://github.com/Avogar)).
