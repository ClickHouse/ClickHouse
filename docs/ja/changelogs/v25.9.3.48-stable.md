<div id="improvement">
  #### 改善
</div>

* [#87981](https://github.com/ClickHouse/ClickHouse/issues/87981) にバックポート: ファイルシステムキャッシュの改善。キャッシュ内で領域を同時に予約するスレッド間で、キャッシュ優先度イテレーターを再利用するようにしました。[#87914](https://github.com/ClickHouse/ClickHouse/pull/87914) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#88057](https://github.com/ClickHouse/ClickHouse/issues/88057) にバックポート: `KeeperRequestRejectedDueToSoftMemoryLimitCount` という Keeper のプロファイルイベントを公開するため、これを `KeeperConstants.cpp` に追加する必要があります。[#88030](https://github.com/ClickHouse/ClickHouse/pull/88030) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#87744](https://github.com/ClickHouse/ClickHouse/issues/87744) にバックポート: クライアントのプロトコルエラーを引き起こしていた GeoParquet の不具合を修正しました。[#84020](https://github.com/ClickHouse/ClickHouse/pull/84020) ([Michael Kolupaev](https://github.com/al13n321)).
* [#87810](https://github.com/ClickHouse/ClickHouse/issues/87810) にバックポート: 関数 checkHeaders が、指定された headers を正しく検証し、禁止された headers を拒否するよう修正しました。元の著者: Michael Anastasakis (@michael-anastasakis)。[#87172](https://github.com/ClickHouse/ClickHouse/pull/87172) ([Raúl Marín](https://github.com/Algunenano)).
* [#87552](https://github.com/ClickHouse/ClickHouse/issues/87552) にバックポート: 別の `MergeTree` table を読み取る subqueries を含む論理更新の不具合を修正しました。[#87285](https://github.com/ClickHouse/ClickHouse/pull/87285) ([Anton Popov](https://github.com/CurtizJ)).
* [#87829](https://github.com/ClickHouse/ClickHouse/issues/87829) にバックポート: object storage 上のテキスト索引からの direct read の不具合を修正しました。[#87399](https://github.com/ClickHouse/ClickHouse/pull/87399) ([Anton Popov](https://github.com/CurtizJ)).
* [#87732](https://github.com/ClickHouse/ClickHouse/issues/87732) にバックポート: Buffer table に対する select および insert のアクセス検証を修正しました。[#87545](https://github.com/ClickHouse/ClickHouse/pull/87545) ([pufit](https://github.com/pufit)).
* [#87760](https://github.com/ClickHouse/ClickHouse/issues/87760) にバックポート: 非同期ログ (大きなずれが生じる可能性があり、10 時間で約 100GiB) および text&#95;log (ほぼ同程度のずれが発生する可能性あり) で、追跡対象 memory がリークする問題を回避しました。[#87584](https://github.com/ClickHouse/ClickHouse/pull/87584) ([Azat Khuzhin](https://github.com/azat)).
* [#87773](https://github.com/ClickHouse/ClickHouse/issues/87773) にバックポート: この view が非同期に drop され、バックグラウンドクリーンアップの完了前に server が再起動した場合、View または Materialized View の SELECT settings によってグローバルな server settings が上書きされる可能性があるバグを修正しました。[#87603](https://github.com/ClickHouse/ClickHouse/pull/87603) ([Alexander Tokmakov](https://github.com/tavplubix)).
* [#87797](https://github.com/ClickHouse/ClickHouse/issues/87797) にバックポート: 右側の行リストが使用されない場合の HashJoin algorithm における出力 block の生成を修正しました。[#87401](https://github.com/ClickHouse/ClickHouse/issues/87401) を修正。[#87699](https://github.com/ClickHouse/ClickHouse/pull/87699) ([Dmitry Novik](https://github.com/novikd)).
* [#87852](https://github.com/ClickHouse/ClickHouse/issues/87852) にバックポート: これにより [#86587](https://github.com/ClickHouse/ClickHouse/issues/86587) をクローズします。[#87761](https://github.com/ClickHouse/ClickHouse/pull/87761) ([scanhex12](https://github.com/scanhex12)).
* [#87911](https://github.com/ClickHouse/ClickHouse/issues/87911) にバックポート: 複数のスキップ索引の不具合を修正しました。[#87817](https://github.com/ClickHouse/ClickHouse/pull/87817) ([Raúl Marín](https://github.com/Algunenano)).
* [#88075](https://github.com/ClickHouse/ClickHouse/issues/88075) にバックポート: 最後の block が空の場合の projections を伴う merge の不具合を修正しました。[#87928](https://github.com/ClickHouse/ClickHouse/pull/87928) ([Raúl Marín](https://github.com/Algunenano)).
* [#88100](https://github.com/ClickHouse/ClickHouse/issues/88100) にバックポート: &quot;High ClickHouse memory usage&quot; 警告を修正しました (page cache を除外) 。[#88092](https://github.com/ClickHouse/ClickHouse/pull/88092) ([Azat Khuzhin](https://github.com/azat)).
* [#88149](https://github.com/ClickHouse/ClickHouse/issues/88149) にバックポート: カラムに `TTL` が設定された `MergeTree` テーブルで発生する可能性があるデータ破損を修正しました。[#88095](https://github.com/ClickHouse/ClickHouse/pull/88095) ([Anton Popov](https://github.com/CurtizJ)).
