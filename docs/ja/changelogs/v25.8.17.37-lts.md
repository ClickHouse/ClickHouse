* [#97109](https://github.com/ClickHouse/ClickHouse/issues/97109) にバックポート: 複数の JOIN で `analyzer_compatibility_join_using_top_level_identifier` を使用した際に発生しうる論理エラーを修正しました。[#90010](https://github.com/ClickHouse/ClickHouse/pull/90010) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#96400](https://github.com/ClickHouse/ClickHouse/issues/96400) にバックポート: 有効な query condition cache を使用した `SELECT` クエリで、論理更新後に誤ったクエリ結果が返る可能性があった問題を修正しました。[#90176](https://github.com/ClickHouse/ClickHouse/issues/90176) を修正。[#90054](https://github.com/ClickHouse/ClickHouse/issues/90054) を修正。[#90204](https://github.com/ClickHouse/ClickHouse/pull/90204) ([Anton Popov](https://github.com/CurtizJ)).
* [#91754](https://github.com/ClickHouse/ClickHouse/issues/91754) にバックポート: ターゲットホストとして `localhost` を指定して `remote` テーブル関数を使用した場合の `ALTER UPDATE` クエリにおけるアクセス検証を修正しました。[#90761](https://github.com/ClickHouse/ClickHouse/pull/90761) ([pufit](https://github.com/pufit)).
* [#97815](https://github.com/ClickHouse/ClickHouse/issues/97815) にバックポート: 関連 issue: [#6365](https://github.com/ClickHouse/support-escalation/issues/6365)。[#92339](https://github.com/ClickHouse/ClickHouse/pull/92339) ([Tuan Pham Anh](https://github.com/tuanpach)).
* [#97327](https://github.com/ClickHouse/ClickHouse/issues/97327) にバックポート: SQL Security を持つビューに対する `ATTACH` クエリで、不要にスキップされていた権限チェックを削除しました。これにより、必要なアクセス権を検証せずに、ユーザーが definer 付きのビューを attach した場合に起こりうる権限昇格を防止します。[#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)).
* [#95814](https://github.com/ClickHouse/ClickHouse/issues/95814) にバックポート: 複数の JOIN を `USING` clause とともに使用した場合の、ソーステーブル由来の修飾付きカラムに対する型推論を修正しました。以前は、後続の JOIN によって、その JOIN に関与していない場合でも、元のソースカラムの型が誤って共通スーパータイプに更新されていました (例: `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)` では、`t2.a` カラムは最初の JOIN でのみ使用されるため、その型は `t1.a` と `t2.a` のスーパータイプであるべきで、`t3.a` は含まれるべきではありません) 。この問題により、関数が実際の実行計画に現れるものとは異なるカラム型を想定した場合、論理エラーやクラッシュにつながる可能性がありました。[#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#95484](https://github.com/ClickHouse/ClickHouse/issues/95484) にバックポート: `mergeTreeProjection` テーブル関数にアクセスチェックがなく、テーブルに対する SELECT 権限を持たないユーザーでも (テーブル関数に対する権限は持っている場合) 、そのプロジェクションからデータを読み取れていました。この修正では、`mergeTreeIndex` および `mergeTreeAnalyzeIndexes` にすでにあるものと同じアクセスチェックを追加します。[#95480](https://github.com/ClickHouse/ClickHouse/pull/95480) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#96052](https://github.com/ClickHouse/ClickHouse/issues/96052) にバックポート: パーティション化された Delta Lake データをまとめる処理を修正しました。[#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#96209](https://github.com/ClickHouse/ClickHouse/issues/96209) にバックポート: JSON data type でのパスのスキップを修正しました。以前は `JSON(SKIP path)` により、`path` をプレフィックスに持つすべての JSON キーがスキップされており、`"pathpath"` のようなキーまで対象になっていたため、挿入時にそれらのパスでデータ損失が発生する可能性がありました。現在は修正され、`"path"` というキーのみがスキップされます。[#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* [#96076](https://github.com/ClickHouse/ClickHouse/issues/96076) にバックポート済み: グローバルプロファイラの周期 (`global_profiler_real_time_period_ns` と `global_profiler_cpu_time_period_ns` で制御) を修正しました。設定値ではなく切り捨てられた値が使われていたため、プロファイラが意図した以上に頻繁に起動していました。[#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368))。
* [#96538](https://github.com/ClickHouse/ClickHouse/issues/96538) にバックポート済み: デフォルトロールの取り消し処理を修正しました。[#96103](https://github.com/ClickHouse/ClickHouse/pull/96103) ([Vitaly Baranov](https://github.com/vitlibar))。
* [#97149](https://github.com/ClickHouse/ClickHouse/issues/97149) にバックポート済み: `AccessRights::contains` が部分的な権限取り消しで誤った結果を返す問題を修正しました。[#96170](https://github.com/ClickHouse/ClickHouse/pull/96170) ([pufit](https://github.com/pufit))。
