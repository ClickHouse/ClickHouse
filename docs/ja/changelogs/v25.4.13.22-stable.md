  # 2025年の変更履歴
</div>

<div id="clickhouse-release-v2541322-stable-189cbf21a52-fixme-as-compared-to-v254129-stable-65820a0cf71">
  ### ClickHouse リリース v25.4.13.22-stable (189cbf21a52) FIXME v25.4.12.9-stable (65820a0cf71) と比較
</div>

<div id="improvement">
  #### 改善
</div>

* [#84033](https://github.com/ClickHouse/ClickHouse/issues/84033) にバックポート: cgroup の情報 (該当する場合、つまり `memory_worker_use_cgroup` が有効で、cgroup が利用可能な場合) を使用して、メモリトラッカー (`memory_worker_correct_memory_tracker`) を補正します。[#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#83140](https://github.com/ClickHouse/ClickHouse/issues/83140) にバックポート: `lowCardinalityKeys` 関数で、共有 Dictionary の無関係なパーツを使用しないようにしました。[#83118](https://github.com/ClickHouse/ClickHouse/pull/83118) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* [#84105](https://github.com/ClickHouse/ClickHouse/issues/84105) にバックポート: Avro スキーマレジストリの認証情報の詳細が、ユーザーやログから見えないようにマスクしました。[#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* [#83913](https://github.com/ClickHouse/ClickHouse/issues/83913) にバックポート: MergeTree テーブルを `add_minmax_index_for_numeric_columns=1` または `add_minmax_index_for_string_columns=1` を指定して作成し、その後 ALTER 操作中に索引が materialize されると、新しいレプリカ上で Replicated database が正しく初期化されなくなる問題を修正しました。[#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#83872](https://github.com/ClickHouse/ClickHouse/issues/83872) にバックポート: 名前の衝突がある場合に、新しいアナライザが WITH句で外側のエイリアスを参照できるようにする後方互換性設定を導入しました。[#82700](https://github.com/ClickHouse/ClickHouse/issues/82700) を修正。[#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* [#84090](https://github.com/ClickHouse/ClickHouse/issues/84090) にバックポート: バックアップから復元する際に、definer user がバックアップされていないことがあり、その結果バックアップ全体が壊れる可能性がありました。これを修正するため、復元中のターゲットテーブル作成時に行う権限チェックを遅らせ、実行時にのみチェックするようにしました。[#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* [#84268](https://github.com/ClickHouse/ClickHouse/issues/84268) にバックポート: recursive CTE とクエリ条件キャッシュを併用した場合に、クエリ結果が誤っていた問題を修正しました (issue [#81506](https://github.com/ClickHouse/ClickHouse/issues/81506))。[#84026](https://github.com/ClickHouse/ClickHouse/pull/84026) ([zhongyuankai](https://github.com/zhongyuankai)).

<div id="not-for-changelog-insignificant">
  #### CHANGELOG対象外 / 軽微
</div>

* [#84046](https://github.com/ClickHouse/ClickHouse/issues/84046) にバックポート: `sccache` が明示的なサーバー起動をサポートするようになりました。`ninja` のビルド段階に入る前に起動する必要があります。[#83600](https://github.com/ClickHouse/ClickHouse/pull/83600) ([Mikhail f. Shiryaev](https://github.com/Felixoid)) 。
* [#83862](https://github.com/ClickHouse/ClickHouse/issues/83862) にバックポート: `max_database_replicated_create_table_thread_pool_size` 設定が 0 (自動プールサイズ) の場合に、テーブルの同時作成を許可しました。[#83834](https://github.com/ClickHouse/ClickHouse/pull/83834) ([Alexander Tokmakov](https://github.com/tavplubix)) 。
* [#79124](https://github.com/ClickHouse/ClickHouse/issues/79124) を 25.4 にチェリーピック: MergeTreeIndexCondition::alwaysUnknownOrTrue の実装での重複を回避しました。[#84152](https://github.com/ClickHouse/ClickHouse/pull/84152) ([Elmi Ahmadov](https://github.com/ahmadov)) 。
