<div id="improvement">
  #### 改善
</div>

* [#87428](https://github.com/ClickHouse/ClickHouse/issues/87428) でバックポート: `s3_slow_all_threads_after_retryable_error` はデフォルトで無効化されました。[#87198](https://github.com/ClickHouse/ClickHouse/pull/87198) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#87312](https://github.com/ClickHouse/ClickHouse/issues/87312) でバックポート: 25.1 より前に作成された KeeperMap テーブルで、DROP クエリの実行後もデータが ZooKeeper に残る問題を修正しました。 [#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#87168](https://github.com/ClickHouse/ClickHouse/issues/87168) でバックポート: 遅延マテリアライゼーションにおいて、array sizes subcolumn を持つ配列の読み取りに関する不具合を修正しました。 [#87139](https://github.com/ClickHouse/ClickHouse/pull/87139) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87394](https://github.com/ClickHouse/ClickHouse/issues/87394) でバックポート: `max_temporary_data_on_disk_size` の制限追跡において、一時データの deallocations の計上が誤っていた問題を修正し、[#87118](https://github.com/ClickHouse/ClickHouse/issues/87118) をクローズしました。 [#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
* [#87329](https://github.com/ClickHouse/ClickHouse/issues/87329) でバックポート: 非相関の `EXISTS` が誤った結果を返す可能性がある問題を修正しました。この問題は、[https://github.com/ClickHouse/ClickHouse/pull/85481](https://github.com/ClickHouse/ClickHouse/pull/85481) で導入された `execute_exists_as_scalar_subquery=1` により発生しており、`25.8` に影響します。 [#86415](https://github.com/ClickHouse/ClickHouse/issues/86415) を修正します。 [#87207](https://github.com/ClickHouse/ClickHouse/pull/87207) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* [#87437](https://github.com/ClickHouse/ClickHouse/issues/87437) でバックポート: const と non-const の block が混在していることにより `JOIN` で発生する &quot;Too large size passed to allocator&quot; `LOGICAL_ERROR` を修正しました。 [#87231](https://github.com/ClickHouse/ClickHouse/pull/87231) ([Azat Khuzhin](https://github.com/azat)).
