<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### バグ修正 (正式な安定版リリースにおけるユーザーに影響する不具合)
</div>

* [#86058](https://github.com/ClickHouse/ClickHouse/issues/86058) にバックポート: `no_password` で作成されたユーザーが、サーバー設定 `allow_no_password` が 0 に変更された後にログインを試みると、サーバーがクラッシュする問題を修正しました。[#84426](https://github.com/ClickHouse/ClickHouse/pull/84426) ([Shankar Iyer](https://github.com/shankar-iyer)).
* [#86612](https://github.com/ClickHouse/ClickHouse/issues/86612) にバックポート: database レプリカの復旧時に table を適切にシャットダウンするようにしました。不適切なシャットダウンにより、database レプリカの復旧中に一部のテーブルエンジンで LOGICAL&#95;ERROR が発生していました。[#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* [#86520](https://github.com/ClickHouse/ClickHouse/issues/86520) にバックポート: delta-kernel 実装で発生する segfault を修正しました。[#85160](https://github.com/ClickHouse/ClickHouse/pull/85160) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#85255](https://github.com/ClickHouse/ClickHouse/issues/85255) にバックポート: `DeltaLake` エンジンで delta-kernel を無効にした状態でパーティション化されたデータを読み込めない問題を修正しました。この問題は 25.7 で発生していました ([https://github.com/ClickHouse/ClickHouse/pull/81136](https://github.com/ClickHouse/ClickHouse/pull/81136)) 。[#85223](https://github.com/ClickHouse/ClickHouse/pull/85223) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#85652](https://github.com/ClickHouse/ClickHouse/issues/85652) にバックポート: multipart を伴う http で、`date_time_input_format` などのパラメーターが無視されていた問題を修正しました。[#85570](https://github.com/ClickHouse/ClickHouse/pull/85570) ([Sema Checherinda](https://github.com/CheSema)).
* [#87157](https://github.com/ClickHouse/ClickHouse/issues/87157) にバックポート: FROM 句内の相関サブクエリについて、外側のクエリのカラムを使用する場合にのみ許可するチェックを追加しました。[#85469](https://github.com/ClickHouse/ClickHouse/issues/85469) を修正。[#85402](https://github.com/ClickHouse/ClickHouse/issues/85402) を修正。[#85966](https://github.com/ClickHouse/ClickHouse/pull/85966) ([Dmitry Novik](https://github.com/novikd)).
* [#86955](https://github.com/ClickHouse/ClickHouse/issues/86955) にバックポート: 他のカラムの materialized expression で使われている subcolumn を持つカラムに対する alter update を修正しました。従来は、式内に subcolumn を含む materialized column が正しく更新されていませんでした。[#85985](https://github.com/ClickHouse/ClickHouse/pull/85985) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86693](https://github.com/ClickHouse/ClickHouse/issues/86693) にバックポート: subcolumn が PK または partition expression で使われているカラムの alter を禁止しました。[#86005](https://github.com/ClickHouse/ClickHouse/pull/86005) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86199](https://github.com/ClickHouse/ClickHouse/issues/86199) にバックポート: JSON 内で Enum ヒントを持つ path に対して誤ったデフォルト値が使われる問題を修正しました。[#86065](https://github.com/ClickHouse/ClickHouse/pull/86065) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86518](https://github.com/ClickHouse/ClickHouse/issues/86518) にバックポート: ファイルシステムキャッシュの動的リサイズ中に発生する論理エラーを修正しました。[#86122](https://github.com/ClickHouse/ClickHouse/issues/86122) をクローズ。[https://github.com/ClickHouse/clickhouse-core-incidents/issues/473](https://github.com/ClickHouse/clickhouse-core-incidents/issues/473) をクローズ。[#86130](https://github.com/ClickHouse/ClickHouse/pull/86130) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#86947](https://github.com/ClickHouse/ClickHouse/issues/86947) にバックポート: LowCardinality(Nullable(T)) から Dynamic への cast を修正しました。[#86365](https://github.com/ClickHouse/ClickHouse/pull/86365) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86878](https://github.com/ClickHouse/ClickHouse/issues/86878) でバックポート: GROUP BY Nullable(JSON) の問題を修正しました。[#86410](https://github.com/ClickHouse/ClickHouse/pull/86410) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86580](https://github.com/ClickHouse/ClickHouse/issues/86580) でバックポート: シャットダウン時のログの flush 中に発生する例外を無視し、シャットダウン処理の安全性を向上させました (SIGSEGV 回避のため) 。[#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
* [#86891](https://github.com/ClickHouse/ClickHouse/issues/86891) でバックポート: send&#95;chunk&#95;header が有効で、UDF が HTTP プロトコル経由で呼び出された場合に chunk ヘッダーが欠落する問題を修正しました。[#86606](https://github.com/ClickHouse/ClickHouse/pull/86606) ([Vladimir Cherkasov](https://github.com/vdimir)).
* [#86872](https://github.com/ClickHouse/ClickHouse/issues/86872) にバックポート: Keeper のセッション期限切れが原因で発生していた、S3Queue の論理エラー &quot;Expected current processor {} to be equal to {}&quot; を修正しました。[#86615](https://github.com/ClickHouse/ClickHouse/pull/86615) ([Kseniia Sumarokova](https://github.com/kssenii)).
* [#87057](https://github.com/ClickHouse/ClickHouse/issues/87057) にバックポート: RowBinary 入力フォーマットで、共有データ JSON に NULL を書き込む際の不具合を修正し、ColumnObject に追加の検証をいくつか加えました。 [#86812](https://github.com/ClickHouse/ClickHouse/pull/86812) ([Pavel Kruglov](https://github.com/Avogar)).
* [#86977](https://github.com/ClickHouse/ClickHouse/issues/86977) にバックポート: Replicated Database で、新しいレプリカの作成を妨げる TimeSeries engine table の不具合を修正しました。 [#86845](https://github.com/ClickHouse/ClickHouse/pull/86845) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#86861](https://github.com/ClickHouse/ClickHouse/issues/86861) にバックポート: tasks に特定の Keeper ノードがない場合に `system.distributed_ddl_queue` をクエリできない不具合を修正しました。 [#86848](https://github.com/ClickHouse/ClickHouse/pull/86848) ([Antonio Andelic](https://github.com/antonio2368)).
* [#87054](https://github.com/ClickHouse/ClickHouse/issues/87054) にバックポート: 展開後の block の末尾での seek を修正しました。 [#86906](https://github.com/ClickHouse/ClickHouse/pull/86906) ([Pavel Kruglov](https://github.com/Avogar)).
* [#87191](https://github.com/ClickHouse/ClickHouse/issues/87191) にバックポート: `ROLLUP` および `CUBE` modifier 使用時に、`uniqExact` function が誤った結果を返す可能性がある問題を修正しました。 [#87014](https://github.com/ClickHouse/ClickHouse/pull/87014) ([Nikita Taranov](https://github.com/nickitat)).
* [#87070](https://github.com/ClickHouse/ClickHouse/issues/87070) にバックポート: PREWHERE を複数の step に分割した後の出力が正しく CAST されるよう修正しました。 [#87040](https://github.com/ClickHouse/ClickHouse/pull/87040) ([Antonio Andelic](https://github.com/antonio2368)).
* [#87416](https://github.com/ClickHouse/ClickHouse/issues/87416) にバックポート: EmbeddedRocksDB: path は user&#95;files 内になければなりません。 [#87109](https://github.com/ClickHouse/ClickHouse/pull/87109) ([Raúl Marín](https://github.com/Algunenano)).
* [#87311](https://github.com/ClickHouse/ClickHouse/issues/87311) にバックポート: 25.1 より前に作成された KeeperMap table で、DROP クエリ後もデータが ZooKeeper に残る不具合を修正しました。 [#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* [#87393](https://github.com/ClickHouse/ClickHouse/issues/87393) にバックポート: `max_temporary_data_on_disk_size` の制限追跡において、一時データの解放の計上が誤っていた問題を修正し、[#87118](https://github.com/ClickHouse/ClickHouse/issues/87118) をクローズしました。 [#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
