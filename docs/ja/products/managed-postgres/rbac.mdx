ClickHouse Cloud は、ClickHouse Managed Postgres サービスに対するロールベースのアクセス制御 (RBAC) をサポートしています。特定のアクセス許可を持つカスタムロールを作成して組織メンバーに割り当てることで、Postgres サービスを表示または管理できるユーザーを制御できます。

<div id="available-permissions">
  ## 利用可能な権限 {#available-permissions}
</div>

ClickHouse Managed Postgres は現在、2 種類の権限をサポートしています。

| 権限                   | 説明                                       |
| -------------------- | ---------------------------------------- |
| **Postgres サービスの表示** | ユーザーが Postgres サービスとその詳細を表示できるようにします。    |
| **Postgres サービスの管理** | ユーザーが Postgres サービスを変更、スケール、設定できるようにします。 |

新しい Postgres サービスを作成するには、既存の **Organization manage** 権限が必要です。上記の権限は、既存のサービスにのみ適用されます。

<Note>
  より細かな権限は、今後のリリースで利用可能になる予定です。
</Note>

## カスタムロールの作成 {#creating-a-custom-role}

1. 左側のサイドバーで組織名をクリックし、**ユーザーとロール** を選択します。

<div className="ch-image-md">
  <Frame>
    ![ユーザーとロールメニュー](/images/managed-postgres/rbac/usersandroles.webp)
  </Frame>
</div>

2. **Roles** タブに切り替えて、**Create role** をクリックします。
3. ロール名を入力し、**+ Allow** をクリックしてから、エンティティ一覧で **Postgres Service** を選択します。

<div className="ch-image-md">
  <Frame>
    ![Postgres Service エンティティの選択](/images/managed-postgres/rbac/postgresentity.webp)
  </Frame>
</div>

4. ロールの適用対象とする Postgresサービスを選択し、付与するアクセス許可を選択します。

<div className="ch-image-md">
  <Frame>
    ![ロールへの Postgres アクセス許可の設定](/images/managed-postgres/rbac/newpostgresperms.webp)
  </Frame>
</div>

5. **Create role** をクリックして保存します。

<div id="assigning-a-role">
  ## ロールの割り当て {#assigning-a-role}
</div>

ロールを作成したら、同じ **Users and roles** ページの **Users** タブからユーザーに割り当てます。1人のユーザーに複数のロールを付与でき、ロールを組み合わせることで、必要なアクセスプロファイルを正確に構成できます。
