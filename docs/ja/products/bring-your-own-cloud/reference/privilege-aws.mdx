このページでは、ClickHouse BYOC がお客様の AWS アカウントで使用する各 IAM ポリシーおよびロールについて、そのアクセス許可、スコープ、目的を説明します。BYOC のアクセス許可モデルの概要については、[BYOC の権限](/ja/products/bring-your-own-cloud/reference/privilege)を参照してください。

## ブートストラップ IAM role {#bootstrap-iam-role}

次の表は、ブートストラップ IAM role である `ClickHouseManagementRole` の各ポリシーをまとめたものです。

| ポリシー                                           | アクセス許可                                                                                                                                                      | 適用範囲                                                                                                                                                                                                                                                           | 目的                                                                                                                                                    |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BasePolicy` (インライン)                           | 呼び出し元のアイデンティティを取得します。サービスクォータと AWS のデフォルトのサービスクォータを読み取ります。                                                                                                  | すべてのリソース。読み取り専用。                                                                                                                                                                                                                                               | プロビジョニング前の稼働状態とクォータの確認                                                                                                                                |
| `ClickHouse-IAM-Base-Policy`                   | IAMロール、ポリシー、インスタンスプロファイルを閲覧します。ロールをAWSサービスに渡します。サービスリンクロールを作成します。クラスターのOpenID Connect (OIDC) プロバイダーの作成、タグ付け、削除を行います。                                        | 閲覧: すべてのIAMロールとポリシー。ロールの引き渡し: BYOC のロール名 (例: `*-k8s-worker`、`*-karpenter-node`、`*-CH-S3-Role`) に限り、かつ渡し先は EKS、EKS Pod Identity、EC2 のみ。サービスリンクロール: EKS、EKS ノードグループ、VPC Lattice 用のみ。OIDC プロバイダー: タグ `clickhouse-byoc=true` (このロールは任意の OIDC プロバイダーにこのタグを付与できます) 。 | IAMの状態を参照します。BYOCロールをEKSとEC2に渡します。                                                                                                                    |
| `ClickHouse-IAM-Extended-Policy` (任意、デフォルトで有効) | IAMロール、ポリシー、インスタンスプロファイルの作成、変更、削除                                                                                                                           | タグ `clickhouse-byoc=true` が付いたリソースのみ(このロールは任意のロール、ポリシー、インスタンスプロファイルにこのタグを付与できます)。制限対象外:インスタンスプロファイルからのロールの削除。                                                                                                                                                  | 追加のロールを作成します (詳細は次のセクションを参照) 。[独自のIAMロールを持ち込む](/ja/products/bring-your-own-cloud/onboarding/customization-aws#customer-managed-iam-roles)場合、このポリシーは不要です。 |
| `ClickHouse-S3-Policy`                         | バケットの作成。バケット設定 (タグ、ライフサイクル、暗号化、所有権、パブリックアクセスのブロック、メトリクス) の読み取りと設定。バケット内のオブジェクトの一覧表示。オブジェクトの読み取り・書き込みは不可。バケットの削除は不可。                                         | `*.*.aws.clickhouse.cloud-shared`、`*.*.aws.clickhouse.cloud-backup`、`*.*.aws.clickhouse.cloud-monitoring` という名前のバケットのみ                                                                                                                                         | ClickHouse テーブルのデータ、バックアップ、監視データを保存するバケットの管理                                                                                                          |
| `ClickHouse-EKS-Policy`                        | EKSクラスター、アドオン、ノードグループ、Pod Identityの関連付けを作成・変更・削除します。すべてのEKSリソースを閲覧します。                                                                                      | 書き込み: 名前が `clickhouse-cloud-` で始まるリソースのみ。閲覧: すべての EKS リソース。                                                                                                                                                                                                    | EKSクラスターとそのアドオン、ノードグループを管理します                                                                                                                         |
| `ClickHouse-EC2-Policy`                        | EC2、Elastic Load Balancing、Auto Scaling の情報を閲覧します。インスタンスを起動します。起動テンプレート、ネットワークインターフェース、セキュリティグループ、Elastic IP、タグを管理します。インスタンス、ネットワークインターフェース、ボリュームの属性を変更します。 | セキュリティグループ: タグ `clickhouse-byoc=true` または `aws:eks:cluster-name` = `clickhouse-cloud-*` を持つもの。Elastic IP とタグの変更: タグ `clickhouse-byoc=true` を持つもの (このロールは任意のリソースにこのタグを付与できます) 。スコープ制限なし: インスタンス、起動テンプレート、ネットワークインターフェース、ボリューム。                                  | クラスターへのネットワークアクセスを制御するノードとセキュリティグループを管理します                                                                                                            |
| `ClickHouse-VPCWrite-Policy` (任意、デフォルトで有効)     | VPC、サブネット、NAT ゲートウェイ、インターネットゲートウェイ、ルートテーブル、VPC エンドポイントの作成、変更、削除                                                                                             | タグ `clickhouse-byoc=true` が付いたリソースのみ                                                                                                                                                                                                                           | BYOC VPC 用。[独自の VPC を使用する](/ja/products/bring-your-own-cloud/onboarding/customization-aws#customer-managed-vpc-aws)場合は不要です。                              |
| `ClickHouse-VPCPrivateLink-Policy`             | VPC エンドポイントサービスの作成、変更、削除                                                                                                                                    | `clickhouse-byoc=true` タグが付与されたリソースのみ                                                                                                                                                                                                                          | ご利用のサービス用の AWS PrivateLink エンドポイント                                                                                                                    |
| `ClickHouse-VPCLattice-Policy`                 | VPC Lattice のリソースゲートウェイとリソース構成、および AWS RAM のリソース共有の作成、変更、削除。VPC Lattice と AWS RAM の閲覧。                                                                      | 書き込み: タグ `clickhouse-byoc=true` が付与されたリソースのみ。閲覧: VPC Lattice および AWS RAM のすべてのリソース。                                                                                                                                                                            | EKS API へのプライベートアクセス                                                                                                                                  |
| `ClickHouse-CloudWatch-Policy`                 | CloudWatch Logs の閲覧。ロググループの作成。ロググループへのタグ付けと保持期間の設定。                                                                                                         | 作成: タグ `clickhouse-byoc=true` が付与されている場合のみ。タグ付けと保持期間の設定: ロググループ `/aws/eks/clickhouse-cloud-*` のみ。閲覧: すべてのロググループ。                                                                                                                                               | EKS コントロールプレーンのログ                                                                                                                                     |
| `ClickHouse-KMS-Policy`(任意、デフォルトでは無効)          | キーの詳細を閲覧する。キーに対する許可を作成する。                                                                                                                                   | ClickHouse BYOC の AWS アカウント内の KMS キーのみ                                                                                                                                                                                                                         | EKS シークレットの暗号化                                                                                                                                        |
| `ClickHouse-KMSTDE-Policy` (任意、デフォルトでは無効)      | KMS キーの作成、キーと Key Policy の閲覧、キーのローテーションの有効化、キーへのタグ付けが可能。暗号化、復号、Key Policy の変更、キーの削除は不可。                                                                     | タグ `clickhouse-byoc=true`(キーポリシーで許可されていれば、ロールはどのキーにもこのタグを付与可能)                                                                                                                                                                                                 | 透過的データ暗号化 (TDE) 用のキー                                                                                                                                  |

ポリシードキュメントの詳細な内容については、[Terraform モジュール](https://github.com/ClickHouse/terraform-byoc-onboarding/blob/main/modules/aws/main.tf)または[CloudFormation テンプレート](https://s3.us-east-2.amazonaws.com/clickhouse-public-resources.clickhouse.cloud/cf-templates/byoc_v2.yaml)を参照してください。

## コントローラーによって作成される追加の IAM ロール {#additional-iam-roles-created-by-the-controller}

CloudFormation または Terraform で作成される `ClickHouseManagementRole` に加えて、コントローラーは BYOC インフラストラクチャごとに複数の追加ロールを作成します。
各ロールには `<infra>-<region>-` というプレフィックスが付きます。`<infra>` は BYOC インフラストラクチャの名前、`<region>` は AWS リージョンです。

| ロール                                   | アクセス許可                                                                                                                                                                      | 目的                                                       |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `data-plane-mgmt`                     | EKS の閲覧。BYOC バケットに対するオブジェクトの一覧取得と削除、および暗号化、バージョニング、ライフサイクルの設定。ロードバランサーと Auto Scaling グループの閲覧。ClickHouse の管理サービスが、お客様の外部 ID を使用してこのロールを引き受けます。                               | ClickHouse サービスおよびクラスターの日常的な管理                           |
| `k8s-control-plane`                   | AWS マネージドの `AmazonEKSClusterPolicy`、`AmazonEKSServicePolicy`、`AmazonEKSVPCResourceController`。このロールを引き受けられるのは EKS のみです。                                                     | EKS クラスターロール                                             |
| `k8s-worker`                          | AWS マネージドの `AmazonEKSWorkerNodePolicy`、`AmazonEKS_CNI_Policy`、`AmazonEC2ContainerRegistryReadOnly`。ClickHouse のコンテナイメージを pull するための読み取り専用ロールの引き受け。このロールを引き受けられるのは EC2 のみです。 | システムノード用のノードロール                                          |
| `karpenter-node` (ロールおよびインスタンスプロファイル) | `k8s-worker` と同じ内容に加えて `AmazonSSMManagedInstanceCore`。このロールを引き受けられるのは EC2 のみです。                                                                                             | ClickHouseサーバーおよび Keeper ノード用のノードロール                     |
| `karpenter-controller`                | このクラスターのタグが付いた EC2 インスタンスの起動と終了。BYOC リージョン内の EC2 の閲覧。`karpenter-node` ロールのみの受け渡し。料金および EKS AMI パラメータの閲覧。                                                                    | Karpenter: ClickHouse 用のノードを追加・削除します                     |
| `cluster-autoscaler`                  | Auto Scaling グループの閲覧。Auto Scaling グループの希望容量の設定とインスタンスの終了。                                                                                                                   | システムノードグループをスケーリングします                                    |
| `load-balancer-controller`            | AWS が公開している AWS Load Balancer Controller ポリシー。ロードバランサーとターゲットグループの変更には、いずれかのクラスターの `elbv2.k8s.aws/cluster` タグが必要です。スコープ制限なし: リスナー、ルール、ターゲット登録、タグ。                            | サービスエンドポイント用の Network Load Balancer を作成します               |
| `ebs-csi-driver`                      | AWS が公開している EBS CSI ドライバーポリシー。ボリュームとスナップショットの削除にはドライバーのタグが必要です。                                                                                                             | ClickHouse および Keeper 用のディスク                             |
| `CH-S3-Role`                          | BYOC の共有バケットおよびバックアップバケット内の ClickHouse プレフィックス配下に限定した、すべての S3 アクション。ClickHouse の S3 アクセス用にお客様が設定したロールの引き受け。ClickHouse に使用量データを送信するためのロールの引き受け。                              | ClickHouseサーバー Pod の ID。テーブルデータとバックアップの読み取りおよび書き込みを行います。 |
| `thanos`                              | BYOC 監視バケット内のオブジェクトの一覧取得、読み取り、書き込み、削除                                                                                                                                       | 監視用のメトリクスを保存します                                          |
| `state-exporter`                      | ClickHouse のロールの引き受け。その他のアクセス許可はありません。                                                                                                                                      | インフラストラクチャのヘルス状態を ClickHouse に送信します                      |
| `clickhouse-scraper`                  | ClickHouse のロールの引き受け。その他のアクセス許可はありません。                                                                                                                                      | 課金用の使用量データを ClickHouse に送信します                            |
| `kube-metric-forwarder-asc`           | ClickHouse のロールの引き受け。その他のアクセス許可はありません。                                                                                                                                      | 自動スケーリングのために Kubernetes メトリクスを ClickHouse に送信します         |

ポリシードキュメントの詳細については、[Terraform モジュール](https://github.com/ClickHouse/terraform-byoc-onboarding/blob/main/modules/aws-per-infra-iam/main.tf)を参照してください。
