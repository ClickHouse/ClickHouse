[AWS Marketplace](https://aws.amazon.com/marketplace) のPAYG (従量課金制) Public Offer から、ClickHouse Cloud の利用を開始しましょう。

<div id="prerequisites">
  ## 前提条件 {#prerequisites}
</div>

* 請求管理者によって購入権限が有効になっている AWS アカウント。
* 購入するには、このアカウントで AWS Marketplace にログインしている必要があります。
* ClickHouse 組織をお使いのサブスクリプションに接続するには、その組織の Admin である必要があります。

## サインアップ手順 {#steps-to-sign-up}

<Steps>
  <Step title="ClickHouse Cloud - Pay as you go を検索する" id="search-payg">
    [AWS Marketplace](https://aws.amazon.com/marketplace) にアクセスし、「ClickHouse Cloud - Pay As You Go」を検索します。

    <div className="ch-image-lg">
      <Frame>
        ![AWS Marketplace で ClickHouse を検索](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="購入オプションを表示する" id="purchase-options">
    [製品ページ](https://aws.amazon.com/marketplace/pp/prodview-p4gwofrqpkltu)を開き、**View purchase options** をクリックします。

    <div className="ch-image-lg">
      <Frame>
        ![AWS Marketplace の購入オプション表示](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="サブスクライブする" id="subscribe">
    次の画面で、Subscribe をクリックします。

    <div className="ch-image-lg">
      <Frame>
        ![AWS Marketplace でのサブスクライブ](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="アカウントを設定する" id="set-up-your-account">
    この時点ではまだセットアップは完了しておらず、ClickHouse Cloud の組織に対するマーケットプレイス経由の請求も開始されていません。続いて、マーケットプレイスサブスクリプションの画面で アカウントを設定する をクリックし、ClickHouse Cloud にリダイレクトしてセットアップを完了してください。

    <div className="ch-image-lg">
      <Frame>
        ![アカウントを設定する](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-4.webp)
      </Frame>
    </div>

    ClickHouse Cloud にリダイレクトされたら、既存のアカウントでログインするか、新しいアカウントを登録します。このステップは、ClickHouse Cloud の組織を AWS Marketplace の請求に紐付けるために非常に重要です。

    <Info>
      **ClickHouse Cloud の新規ユーザー**

      ClickHouse Cloud を初めて利用する場合は、以下の手順に従ってください。
    </Info>

    <Accordion title="新規ユーザー向けの手順">
      ClickHouse Cloud を初めて利用する場合は、ページ下部の Register をクリックします。新しいユーザーの作成とメールアドレスの確認を求められます。メールアドレスの確認が完了したら、ClickHouse Cloud のログインページを閉じ、https://console.clickhouse.cloud で新しいユーザー名を使ってログインできます。

      <div className="ch-image-md">
        <Frame>
          ![ClickHouse Cloud のサインアップ](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-5.webp)
        </Frame>
      </div>

      <Info>
        **新規ユーザー**

        あわせて、ビジネスに関する基本情報も入力する必要があります。以下のスクリーンショットを参照してください。
      </Info>

      <div className="ch-image-md">
        <Frame>
          ![開始する前に](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
        </Frame>
      </div>

      <div className="ch-image-md">
        <Frame>
          ![開始する前に（続き）](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
        </Frame>
      </div>
    </Accordion>

    既存の ClickHouse Cloud ユーザーの場合は、お持ちの認証情報でログインするだけで完了です。
  </Step>

  <Step title="マーケットプレイスサブスクリプションを組織に追加する" id="add-marketplace-subscription">
    ログインしたら、このマーケットプレイスサブスクリプションで請求する組織として、新しい組織を作成するか、既存の組織を選択します。

    <div className="ch-image-lg">
      <Frame>
        ![マーケットプレイスサブスクリプションの追加](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
      </Frame>
    </div>

    新しい ClickHouse アカウントを登録した場合は、自動的に作成されたデフォルトの組織が表示されるので、その組織にマーケットプレイスサブスクリプションを関連付けることができます。

    <div className="ch-image-lg">
      <Frame>
        ![デフォルトの組織を AWS Marketplace サブスクリプションに関連付ける](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-13.webp)
      </Frame>
    </div>

    このステップが完了すると、組織がこの AWS サブスクリプションに接続され、すべての使用量が AWS アカウント経由で請求されるようになります。

    請求が AWS Marketplace に関連付けられたことは、ClickHouse UI の組織の Billing ページで確認できます。

    <div className="ch-image-lg">
      <Frame>
        ![Billing ページの確認](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-9.webp)
      </Frame>
    </div>
  </Step>
</Steps>
