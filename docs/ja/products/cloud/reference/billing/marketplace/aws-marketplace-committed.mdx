[AWS Marketplace](https://aws.amazon.com/marketplace) でコミットメント契約を通じて ClickHouse Cloud の利用を開始できます。
コミットメント契約はプライベートオファーとも呼ばれ、一定期間にわたって ClickHouse Cloud に一定額を支払うことを顧客が確約できる契約です。

<div id="prerequisites">
  ## 前提条件 {#prerequisites}
</div>

* 特定の契約条件に基づく ClickHouse のプライベートオファー。
* ClickHouse 組織をコミット済み支出オファーに関連付けるには、その組織の管理者である必要があります。

AWS でコミットメント契約を表示して承認するために必要な権限:

* AWS 管理ポリシーを使用している場合は、次の権限が必要です:
  * `AWSMarketplaceRead-only`, `AWSMarketplaceManageSubscriptions`
  * または `AWSMarketplaceFullAccess`
* AWS 管理ポリシーを使用していない場合は、次の権限が必要です:
  * IAM アクション `aws-marketplace:ListPrivateListings` および `aws-marketplace:ViewSubscriptions`

## サインアップの手順 {#steps-to-sign-up}

<Steps>
  <Step title="プライベートオファーを承諾する" id="private-offer-accept">
    プライベートオファーの確認と承諾を行うためのリンクが記載されたメールが届いているはずです。

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace のプライベートオファーのメール](/images/cloud/reference/mp_committed_spend_1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="オファーのリンクを確認する" id="review-offer-link">
    メール内の Review Offer リンクをクリックします。
    プライベートオファーの詳細が記載された AWS Marketplace のページが表示されます。
  </Step>

  <Step title="アカウントを設定する" id="setup-your-account">
    AWS ポータルでサブスクライブの手順を完了し、**「アカウントを設定する」** をクリックします。
    ここで必ず ClickHouse Cloud にリダイレクトし、新しいアカウントを登録するか、既存のアカウントでサインインしてください。
    この手順を完了しないと、AWS Marketplace の契約を ClickHouse Cloud に関連付けることができません。

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace のプライベートオファーのメール](/images/cloud/reference/mp_committed_spend_2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Cloud にログインする" id="login-cloud">
    ClickHouse Cloud にリダイレクトされたら、既存のアカウントでログインするか、新しいアカウントを登録します。
    この手順は、ClickHouse Cloud の組織を AWS Marketplace の請求にバインドするために必要です。

    <div className="ch-image-md">
      <Frame>
        ![AWS Marketplace のプライベートオファーのメール](/images/cloud/reference/mp_committed_spend_3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="新規の場合は登録する" id="register">
    ClickHouse Cloud を初めて利用する場合は、ページ下部の「Register」をクリックします。
    新しいユーザーの作成とメールアドレスの確認を求められます。
    メールアドレスの確認が完了したら、ClickHouse Cloud のログインページを閉じ、[https://console.clickhouse.cloud](https://console.clickhouse.cloud) から新しいユーザー名でログインできます。

    なお、新規ユーザーの場合は、ビジネスに関する基本情報の入力も必要です。
    以下のスクリーンショットを参照してください。

    <div className="ch-image-md">
      <Frame>
        ![ビジネス情報を入力する](/images/cloud/reference/mp_committed_spend_4.png)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![ビジネス情報を入力する](/images/cloud/reference/mp_committed_spend_5.png)
      </Frame>
    </div>

    既存の ClickHouse Cloud ユーザーの場合は、お使いの認証情報でログインしてください。
  </Step>

  <Step title="請求先の組織を作成または選択する" id="create-select-org-to-bill">
    ログインしたら、このマーケットプレイス契約の請求先として、新しい組織を作成するか既存の組織を選択します。

    <div className="ch-image-md">
      <Frame>
        ![このサブスクリプションの請求先となる組織を作成または選択する](/images/cloud/reference/mp_committed_spend_6.webp)
      </Frame>
    </div>

    この手順が完了すると、組織が AWS の利用額のコミットメント契約に紐付けられ、すべての使用量が AWS アカウント経由で請求されるようになります。
    ClickHouse UI の組織の Billing ページで、請求が AWS Marketplace に関連付けられていることを確認できます。

    <div className="ch-image-md">
      <Frame>
        ![セットアップの完了を確認する](/images/cloud/reference/mp_committed_spend_7.webp)
      </Frame>
    </div>

    問題が発生した場合は、お気軽に[サポートチーム](https://clickhouse.com/support/program)までお問い合わせください。
  </Step>
</Steps>
