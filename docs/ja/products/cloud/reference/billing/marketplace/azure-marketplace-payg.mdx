[Azure Marketplace](https://azuremarketplace.microsoft.com/en-us/marketplace/apps) のPAYG (従量課金制) 公開オファーを通じて、ClickHouse Cloud の利用を開始しましょう。

## 前提条件 {#prerequisites}

* 請求管理者によって購入権限が有効化された Azure プロジェクト。
* Azure Marketplace で ClickHouse Cloud をサブスクライブするには、購入権限を持つアカウントでログインし、適切なプロジェクトを選択する必要があります。

1. [Azure Marketplace](https://azuremarketplace.microsoft.com/en-us/marketplace/apps) にアクセスし、ClickHouse Cloud を検索します。マーケットプレイスでオファーを購入できるよう、ログインしていることを確認してください。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-1.webp)
  </Frame>
</div>

<br />

2. 製品ページで **Get It Now** をクリックします。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-2.webp)
  </Frame>
</div>

<br />

3. 次の画面で、名前、メールアドレス、地域情報を入力します。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-3.webp)
  </Frame>
</div>

<br />

4. 次の画面で **Subscribe** をクリックします。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-4.webp)
  </Frame>
</div>

<br />

5. 次の画面で、サブスクリプション、リソースグループ、およびリソースグループのリージョンを選択します。リソースグループのリージョンは、ClickHouse Cloud でサービスを起動する予定のリージョンと同じである必要はありません。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-5.webp)
  </Frame>
</div>

<br />

6. あわせて、サブスクリプションの名前を入力し、選択肢の中から請求期間を選択します。**Recurring billing** はオンとオフを切り替えられます。「オフ」にした場合、請求期間の終了とともに契約も終了し、リソースは廃止されます。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-6.webp)
  </Frame>
</div>

<br />

7. **&quot;Review + subscribe&quot;** をクリックします。

8. 次の画面で、内容に誤りがないことを確認し、**Subscribe** をクリックします。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-7.webp)
  </Frame>
</div>

<br />

9. この時点では、ClickHouse Cloud の Azure サブスクリプションを購読しただけで、ClickHouse Cloud 側のアカウントはまだ設定されていない点に注意してください。ClickHouse Cloud を Azure サブスクリプションにバインドし、Azure Marketplace 経由で正しく請求が行われるようにするため、以降の手順は必ず実施してください。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-8.webp)
  </Frame>
</div>

<br />

10. Azure のセットアップが完了すると、**Configure account now** ボタンが有効になります。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-9.webp)
  </Frame>
</div>

<br />

11. **Configure account now** をクリックします。

<br />

アカウント設定の詳細が記載された、以下のようなメールが届きます。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-10.webp)
  </Frame>
</div>

<br />

12. ClickHouse Cloud のサインアップページまたはサインインページにリダイレクトされます。リダイレクト後、既存のアカウントでログインするか、新しいアカウントを登録します。この手順は、ClickHouse Cloud の組織を Azure Marketplace の請求にバインドするうえで非常に重要です。

13. 新規ユーザーの場合は、事業に関する基本情報も入力する必要があります。以下のスクリーンショットを参照してください。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
  </Frame>
</div>

<br />

**Complete sign up** をクリックすると、ClickHouse Cloud 内の組織に移動します。そこで請求画面を確認して Azure Marketplace 経由で請求されていることを確認し、サービスを作成できます。

<br />

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-11.webp)
  </Frame>
</div>

<br />

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/azure-marketplace-payg-12.webp)
  </Frame>
</div>

<br />
