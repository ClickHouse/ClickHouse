PAYG (従量課金制) の Public Offer を通じて、[GCP Marketplace](https://console.cloud.google.com/marketplace) から ClickHouse Cloud の利用を始めましょう。

<div id="prerequisites">
  ## 前提条件 {#prerequisites}
</div>

* 請求管理者によって購入権限が有効になっている GCP プロジェクト。
* GCP Marketplace で ClickHouse Cloud に登録するには、購入権限を持つアカウントでログインし、適切なプロジェクトを選択する必要があります。

## 登録手順 {#steps-to-sign-up}

1. [GCP Marketplace](https://cloud.google.com/marketplace) にアクセスし、ClickHouse Cloud を検索します。正しいプロジェクトが選択されていることを確認してください。

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace のホームページ](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-1.webp)
  </Frame>
</div>

2. [リスティング](https://console.cloud.google.com/marketplace/product/clickhouse-public/clickhouse-cloud)をクリックし、続いて **Subscribe** をクリックします。

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace 上の ClickHouse Cloud](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-2.webp)
  </Frame>
</div>

3. 次の画面で、サブスクリプションを設定します。

* プランはデフォルトで「ClickHouse Cloud」が選択されています
* サブスクリプション期間は「Monthly」です
* 適切な請求アカウントを選択します
* 利用規約に同意し、**Subscribe** をクリックします

<br />

<div className="ch-image-sm">
  <Frame>
    ![GCP Marketplace でのサブスクリプションの設定](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-3.webp)
  </Frame>
</div>

<br />

4. **Subscribe** をクリックすると、**Sign up with ClickHouse** というモーダルが表示されます。

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace の登録モーダル](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-4.webp)
  </Frame>
</div>

<br />

5. この時点では、まだセットアップは完了していません。**Set up your account** をクリックして ClickHouse Cloud にリダイレクトし、ClickHouse Cloud で登録を行う必要があります。

6. ClickHouse Cloud にリダイレクトされたら、既存のアカウントでログインするか、新しいアカウントを登録します。この手順は、ClickHouse Cloud の組織を GCP Marketplace の請求にバインドするために必要な、非常に重要な手順です。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud のサインインページ](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
  </Frame>
</div>

<br />

ClickHouse Cloud を初めて利用する場合は、ページ下部の **Register** をクリックします。新しいユーザーの作成とメールアドレスの確認を求められます。メールアドレスの確認が完了したら、ClickHouse Cloud のログインページを閉じ、[https://console.clickhouse.cloud](https://console.clickhouse.cloud) で新しいユーザー名を使用してログインできます。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud の登録ページ](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
  </Frame>
</div>

<br />

新規ユーザーの場合は、ビジネスに関する基本情報も入力する必要があります。以下のスクリーンショットを参照してください。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloudの登録情報フォーム](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
  </Frame>
</div>

<br />

既存の ClickHouse Cloud ユーザーの場合は、お使いの認証情報でログインしてください。

7. ログインに成功すると、新しい ClickHouse Cloud の組織が作成されます。この組織は GCP の請求アカウントに接続され、すべての使用量は GCP アカウント経由で請求されます。

8. ログイン後、請求が GCP Marketplace に紐付けられていることを確認し、ClickHouse Cloud のリソースのセットアップを開始できます。

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud のサインインページ](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-5.webp)
  </Frame>
</div>

<br />

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud の新しいサービスページ](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-11.webp)
  </Frame>
</div>

<br />

9. 登録完了を知らせる確認メールが届きます。

<br />

<br />

<div className="ch-image-md">
  <Frame>
    ![GCP Marketplace の確認メール](/images/cloud/manage/billing/marketplace/gcp-marketplace-payg-6.webp)
  </Frame>
</div>

<br />
