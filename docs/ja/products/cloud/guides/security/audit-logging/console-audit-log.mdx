コンソールでのアクティビティは監査ログに記録されます。アクセス権を持つユーザーは、ログを確認し、使用中のログシステムと統合できます。監査ログへのアクセスは、**View audit logs** 権限 (`control-plane:organization:view-activities`) によって制御されます。

* 組織のAdminロールを持つユーザーは、デフォルトでアクセスできます。
* その他のコンソールユーザーには、組織へのアクセス権に加えて、**View audit logs** 権限を含む[カスタムロール](/ja/products/cloud/guides/security/cloud-access-management/manage-custom-roles)が必要です。
* API キーには、同じ権限を含むロールが必要です。

すべての権限の説明については、[コンソールのロールと権限](/ja/products/cloud/reference/security/console-roles)を参照してください。

## ユーザーインターフェイスからコンソール監査ログにアクセスする {#console-audit-log-ui}

<Steps>
  <Step title="組織を選択する" id="select-org">
    ClickHouse Cloud で、組織の詳細画面に移動します。

    <div className="ch-image-md">
      <Frame>
        ![ClickHouse Cloud のアクティビティタブ](/images/cloud/security/activity_log1.webp)
      </Frame>
    </div>

    <br />
  </Step>

  <Step title="監査を選択する" id="select-audit">
    左側のメニューで **監査** タブを選択すると、ClickHouse Cloud 組織に対してどのような変更が行われたか、また、その変更を誰がいつ行ったかを確認できます。

    **アクティビティ** ページには、組織に関して記録されたイベントの一覧を含むテーブルが表示されます。デフォルトでは、この一覧は逆時系列順 (最新のイベントが先頭) にソートされています。テーブルの並び順は、カラムヘッダーをクリックして変更できます。テーブルの各項目には、次のフィールドが含まれます。

    * **アクティビティ:** イベントを説明するテキスト
    * **User:** イベントを開始したユーザー
    * **IPアドレス:** 該当する場合、このフィールドにはイベントを開始したユーザーの IPアドレスが表示されます
    * **Time:** イベントのタイムスタンプ

    <div className="ch-image-md">
      <Frame>
        ![ClickHouse Cloud の アクティビティ テーブル](/images/cloud/security/activity_log2.webp)
      </Frame>
    </div>

    <br />
  </Step>

  <Step title="検索バーを使用する" id="use-search-bar">
    検索バーを使用すると、たとえば Service name や IPアドレスなどの条件でイベントを絞り込めます。また、この情報を外部ツールで配布または分析するために、CSV format でエクスポートすることもできます。
  </Step>

## 監査ログの保持期間 {#audit-log-retention}

ClickHouse Cloud では、コンソール監査ログのレコードに time-to-live (TTL) は適用されません。レコードが経過時間に応じて自動的に削除されることはありません。
