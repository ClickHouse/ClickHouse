<Visibility for="humans">
  <View title="Cloud UI">
    ClickHouse Cloud ではファイルを簡単にインポートでき、
    次のフォーマットをサポートしています。

    | フォーマット                          |
    | ------------------------------- |
    | `CSV`                           |
    | `CSVWithNamesAndTypes`          |
    | `CSVWithNames`                  |
    | `JSONEachRow`                   |
    | `TabSeparated`                  |
    | `TabSeparatedWithNames`         |
    | `TabSeparatedWithNamesAndTypes` |

    <Steps>
      <Step title="ファイルをアップロードする" id="upload-file">
        Cloud のホームページで、以下のようにサービスを選択します。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_02](/images/cloud/migrate/csv_01.webp)
          </Frame>
        </div>

        サービスがアイドル状態の場合は、起動してください。

        以下のように、左側のタブで `Data sources` を選択します。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_03](/images/cloud/migrate/csv_02.webp)
          </Frame>
        </div>

        次に、データソースページの右側にある `Upload a file` を選択します。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_04](/images/cloud/migrate/csv_03.webp)
          </Frame>
        </div>

        ファイルダイアログが表示されるので、Cloud サービス上のテーブルに挿入するデータを含む
        ファイルを選択します。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_04.webp)
          </Frame>
        </div>
      </Step>

      <Step title="テーブルを設定する" id="configure-table">
        ファイルのアップロードが完了すると、データの挿入先テーブルを
        設定できます。テーブルのプレビューとして先頭の 3 行が表示されます。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_08](/images/cloud/migrate/csv_08.webp)
          </Frame>
        </div>

        ここで書き込み先テーブルを選択します。選択肢は次のとおりです。

        * 新しいテーブル
        * 既存のテーブル

        <br />

        データのアップロード先データベースを指定でき、新しいテーブルの場合は
        作成するテーブルの名前も指定できます。また、sorting key も選択できます。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_05.webp)
          </Frame>
        </div>

        ファイルから読み込まれたカラムは `Source field` として表示され、各フィールドについて
        次の項目を変更できます。

        * 推論された型
        * デフォルト値
        * カラムを [Nullable](/ja/reference/data-types/nullable) にするかどうか

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_06](/images/cloud/migrate/csv_06.webp)
          </Frame>
        </div>

        <Info>
          **フィールドの除外**

          インポートに含めないフィールドは削除することもできます。
        </Info>

        使用するテーブルエンジンの種類を指定できます。

        * `MergeTree`
        * `ReplacingMergeTree`
        * `SummingMergeTree`
        * `Null`

        <br />

        パーティションキー式とプライマリキー式も
        指定できます。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_07](/images/cloud/migrate/csv_07.webp)
          </Frame>
        </div>

        `Import to ClickHouse` (上図参照) をクリックしてデータをインポートします。以下のように、`Status` カラムに
        `queued` ステータスバッジが表示され、データのインポートがキューに登録されたことがわかります。また、
        `Open as query` (上図参照) をクリックすると、INSERT クエリを SQL コンソールで開けます。このクエリは
        `URL` テーブル関数を使用して、S3 バケットにアップロードされたファイルを挿入します。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_09](/images/cloud/migrate/csv_09.webp)
          </Frame>
        </div>

        ジョブが失敗した場合は、`Data upload history` タブの `Status` カラムに
        `failed` ステータスバッジが表示されます。`View Details` をクリックすると、アップロードが
        失敗した理由の詳細を確認できます。エラーメッセージの内容に応じて、テーブルの設定を
        変更するか、データをクリーニングしてください。

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_11](/images/cloud/migrate/csv_10.webp)
          </Frame>
        </div>
      </Step>
    </Steps>
  </View>

  <View title="CLI">
    この手順は、自分で実行することも、スクリプト化することも、AI エージェントに任せることもできます。コンソールで行う手順については、**Cloud UI** ビューに切り替えてください。

  </View>
