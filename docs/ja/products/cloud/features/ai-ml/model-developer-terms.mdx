現在使用されているすべてのモデルは、該当するモデル開発者ではなく、AWS Bedrock 上でホストされています。
これらのリンクは便宜上提供されています。適用されるモデル利用規約および利用ポリシーを遵守していることを確認する責任は、お客様にあります。
