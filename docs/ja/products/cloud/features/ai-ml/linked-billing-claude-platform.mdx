Claude Platform との請求の関連付けを利用すると、ClickHouse と Anthropic の両方をご利用のお客様は、[ClickHouse Agents](/ja/agents/index) をはじめとする ClickHouse Cloud 製品全体での Claude モデルの使用量を、ご自身の Claude 組織に直接請求させることができます。

Claude Platform との請求の関連付けは現在パブリックプレビュー段階で、すべての ClickHouse Cloud 組織で利用できます。

Claude 組織と ClickHouse Cloud 組織の関連付けは、一度行うだけで完了します。
以降は、ClickHouse Cloud 組織での Claude モデルの使用量が、Claude 組織の料金レートおよび既存の請求に関する利用規約に基づき、Anthropic から Claude 組織に請求されます。
これにより、Anthropic との間で締結している利用額のコミットメントや、個別に交渉した料金レートをそのまま活用できます。

## 請求の仕組み {#how-billing-works}

Claude 組織が関連付けられている間は、次のように処理されます。

* ClickHouse Cloud 組織での Claude モデルの使用量は、Anthropic から Claude 組織に対して請求されます。請求はプリペイド残高からの引き落とし、または Claude 組織の請求書への計上により行われます。
* Claude 組織に適用される料金、および Anthropic との利用額のコミットメントが適用されます。
* 組織からの Claude モデルへのリクエストは、Amazon Bedrock でホストされている Claude モデルではなく、Anthropic に送信されます。

次の点に注意してください。

* 関連付けによる請求は、すべての ClickHouse Cloud 製品における Claude モデルの使用量を対象とします。
* 組織で Claude Platform との請求の関連付けが有効になると、ClickHouse Cloud で利用できるのは Claude モデルのみになります。
* Claude 組織のプロモーションクレジットは、関連付けによる請求には使用できません。
* 関連付けによって変わるのは、Claude の使用量の請求方法のみです。ClickHouse Cloud での Claude の利用に適用される利用規約やデータの取り扱いは変わりません。
* 関連付けの際に、ClickHouse Cloud 経由の Claude 使用量に対する月間の支出上限を設定できます。ClickHouse Cloud 経由で発生した支出が上限に達すると、翌月になるか上限を引き上げるまで、ClickHouse Cloud からの Claude モデルへのリクエストは停止されます。

Claude 組織を関連付けない場合、変更はありません。ClickHouse Cloud の Claude モデルは引き続き Amazon Bedrock から提供されます。

## 要件 {#requirements}

* **HIPAA または PCI DSS コンプライアンスが有効になっていないこと。** [HIPAA](/ja/products/cloud/reference/security/compliance-overview#hipaa-since-2024) または [PCI DSS](/ja/products/cloud/reference/security/compliance-overview#pci-service-provider-since-2025) コンプライアンスが有効になっている ClickHouse Cloud 組織では、Claude Platform との請求の関連付けは利用できません。
* **請求を関連付ける権限を持つ ClickHouse Cloud ロール。** ClickHouse Cloud 組織で管理者ロールが付与されている必要があります。
* **請求を承認する権限を持つ Claude ロール。** Claude 組織で所有者、管理者、または請求ロールのいずれかが付与されている必要があります。
* **要件を満たす Claude 組織。** Claude 組織が、前払いクレジットまたは請求書払いのいずれかで、API の使用料を Anthropic に直接支払っている必要があります。クラウドマーケットプレイス (AWS、Google Cloud、または Azure) 経由で請求されている Claude 組織や、Claude のサブスクリプションプランのみを契約している組織は関連付けできません。

## Claude 組織を関連付ける {#link-your-claude-organization}

<Steps>
  <Step title="組織設定を開く">
    組織の管理者として ClickHouse Cloud コンソールで **組織設定** を開き、**Claude organization** セクションまでスクロールします。
    **Link your Claude organization** をクリックします。

    <div className="ch-image-md">
      <Frame>
        ![ClickHouse Cloud の組織設定にある Claude organization セクションと Link your Claude organization ボタン](/images/cloud/linked-billing-claude-platform/01-link-button.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Claude にサインインする">
    Claude にリダイレクトされます。
    まだサインインしていない場合は、関連付ける Claude 組織で所有者、管理者、または請求のロールを持つアカウントでサインインします。
    アカウントが複数の Claude 組織に所属している場合は、関連付ける組織を選択します。
  </Step>

  <Step title="請求の仕組みを確認する">
    この接続における請求の仕組みが Claude に表示されます。
    内容を確認し、**Continue** をクリックします。

    <div className="ch-image-sm">
      <Frame>
        ![ClickHouse が組織に代わって Claude を使用し、その使用量を Anthropic が組織に請求することを説明する Claude の承認ページ](/images/cloud/linked-billing-claude-platform/02-consent-how-billing-works.webp)
      </Frame>
    </div>
  </Step>

  <Step title="月間の支出上限を設定する">
    必要に応じて、ClickHouse Cloud 経由での Claude 使用量に対する月間の支出上限を入力し、**Continue** をクリックします。
    上限を設定せずに関連付ける場合は、**Continue without a limit** をクリックします。
    上限は Claude Console からいつでも変更できます。

    <div className="ch-image-sm">
      <Frame>
        ![ClickHouse Cloud 経由での Claude 使用量に対する月間の支出上限を設定するフィールドがある Claude の承認ページ](/images/cloud/linked-billing-claude-platform/03-consent-spend-limit.webp)
      </Frame>
    </div>
  </Step>

  <Step title="関連付けて承認する">
    ClickHouse に許可される操作を確認し、**Link and authorize** をクリックします。

    <div className="ch-image-sm">
      <Frame>
        ![ClickHouse が月間の支出上限の範囲内で組織に代わって Claude を使用できることをまとめた Claude の承認ページと Link and authorize ボタン](/images/cloud/linked-billing-claude-platform/04-consent-link-and-authorize.webp)
      </Frame>
    </div>
  </Step>

  <Step title="関連付けを確認する">
    ClickHouse Cloud コンソールに戻ると、Claude 組織が関連付けられたことを示すメッセージが表示されます。
    **Claude organization** セクションには、**Linked** ステータス、関連付けた日付、関連付け ID の末尾の数文字が表示されます。

    <div className="ch-image-md">
      <Frame>
        ![Linked ステータス、関連付けの日付、関連付け ID、関連付けを解除する ボタンが表示された Claude organization セクション](/images/cloud/linked-billing-claude-platform/05-linked.webp)
      </Frame>
    </div>

    これ以降、ClickHouse Cloud 組織での Claude の使用量は Claude 組織に請求されます。
  </Step>
</Steps>

## Claude Console で使用量と支出を監視する {#monitor-usage}

ClickHouse Cloud 経由での Claude の使用により、Claude 組織にどれだけのコストが発生しているかを確認するには、Claude Console で [Linked platforms](https://platform.claude.com/linked-platforms) を開き、**ClickHouse** を選択します。このページには次の情報が表示されます。

* 請求先の Claude 組織、関連付けられた日時、および関連付けを承認したユーザー。
* **Spent this month**: 今月 ClickHouse Cloud 経由で発生した支出額。月間の支出上限を設定している場合は、その上限に対する使用状況が表示されます。上限は毎月 1 日 (UTC) にリセットされます。
* **Link history**: 組織の関連付けおよび関連付け解除が行われた日時と、それぞれの操作を行ったユーザー。

<div className="ch-image-sm">
  <Frame>
    ![ClickHouse の Claude Console Linked platforms ページ。接続情報と、月間の支出上限に対する Spent this month メーターが表示されている](/images/cloud/linked-billing-claude-platform/07-claude-console-spend.webp)
  </Frame>
</div>

このページでは、ClickHouse Cloud 経由での Claude の使用に対する月間の支出上限の設定、引き上げ、削除のほか、ClickHouse の関連付け解除も行えます。

Claude Console の [Spend limits](https://platform.claude.com/settings/billing#spend-limits) で設定する Claude 組織全体の **月間の支出上限** も、ClickHouse Cloud 経由での Claude の使用に適用されます。

## Claude 組織の関連付けを解除する {#unlink}

関連付けの解除はどちら側からでも行えますが、どちら側から解除するかによって結果が異なります。

### ClickHouse Cloud で関連付けを解除する {#unlink-in-clickhouse-cloud}

**組織設定** の **Claude organization** セクションで **関連付けを解除する** をクリックします。
これにより、ClickHouse Cloud はデフォルトの動作に戻ります。組織内の Claude モデルへのリクエストは Amazon Bedrock でホストされている Claude モデルに送信されるようになり、Claude の使用量が Claude 組織に請求されることはなくなります。
デフォルトの動作に戻すには、この方法しかありません。

### Claude Console で関連付けを解除する {#unlink-in-the-claude-console}

[Linked platforms](https://platform.claude.com/linked-platforms) ページで **ClickHouse** を選択し、**関連付けを解除する** をクリックします。
これにより、ClickHouse Cloud は組織に代わって Claude を使用できなくなり、Anthropic は ClickHouse Cloud 経由で新たに発生した Claude の使用量を Claude 組織に請求しなくなります。

<Warning>
  Claude Console で関連付けを解除しても、ClickHouse Cloud がデフォルトの動作に戻るわけではありません。
  再度リンクするか、ClickHouse Cloud の **組織設定** で明示的に関連付けを解除するまでは、ClickHouse Cloud 組織からの Claude モデルへのリクエストはすべて失敗します。
  たとえば、ClickHouse Agents は `The model provider could not complete this request (status 403).` と応答します。
</Warning>

<div className="ch-image-md">
  <Frame>
    ![エラー「The model provider could not complete this request (status 403)」が表示された ClickHouse Agents のチャット](/images/cloud/linked-billing-claude-platform/08-agents-403-error.webp)
  </Frame>
</div>

その後、ClickHouse Cloud の **組織設定** にある **Claude organization** セクションに、`The link was removed on the Claude side, or your Claude organization cannot be billed directly. Relink to continue.` というメッセージが表示されます。

<div className="ch-image-md">
  <Frame>
    ![Claude 側でリンクが削除されたことを示す警告と、Relink ボタンおよび 関連付けを解除する ボタンが表示された Claude organization セクション](/images/cloud/linked-billing-claude-platform/06-link-removed.webp)
  </Frame>
</div>

続行するには、次のいずれかを実行します。

* 引き続き Claude の使用量を Claude 組織に請求する場合は、**Relink** をクリックし、[リンク手順](#link-your-claude-organization)をもう一度実行します。
* デフォルトの動作に戻す場合は、**関連付けを解除する** をクリックします。この場合、Claude モデルへのリクエストは Amazon Bedrock でホストされている Claude モデルに送信されます。

## トラブルシューティング {#troubleshooting}

| 症状                                                      | 考えられる原因                                                                        | 対処方法                                                                                                                                                                                                                     |
| ------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Link your Claude organization** ボタンが無効になっている。         | ClickHouse Cloud 組織で管理者ロールを持っていないか、組織で HIPAA または PCI DSS コンプライアンスが有効になっています。   | 組織の管理者に関連付けを依頼してください。HIPAA または PCI DSS コンプライアンスが有効な組織では、Claude Platform との請求の関連付けは利用できません。Claude モデルは引き続き Amazon Bedrock 経由で提供されます。                                                                                      |
| 承認ページに Claude 組織が表示されない、または ClickHouse を関連付けできないと表示される。 | Claude 組織が[要件](#requirements)を満たしていないか、その組織でアカウントに所有者、管理者、または請求のロールが付与されていません。 | [要件](#requirements)を確認してください。                                                                                                                                                                                            |
| Claude へのリクエストが失敗し、**組織設定**に Claude 側で関連付けが解除されたと表示される。 | Claude Console で関連付けが解除されたか、Anthropic が Claude 組織に直接請求できない状態です。                   | ClickHouse Cloud で[再度関連付けるか、関連付けを解除](#unlink-in-the-claude-console)してください。                                                                                                                                               |
| 月の途中で Claude へのリクエストが停止する。                              | ClickHouse Cloud 経由の利用額が関連付け時に設定した月間の支出上限に達したか、Claude 組織全体の月間の支出上限に達しています。       | Claude Console で、[Linked platforms](https://platform.claude.com/linked-platforms) から ClickHouse Cloud 経由の Claude 使用量の利用上限を、または [Spend limits](https://platform.claude.com/settings/billing#spend-limits) から組織の上限を引き上げてください。 |
| Claude 組織は関連付けられているが、Claude へのリクエストが失敗する。               | 前払いクレジットの不足や組織の停止などにより、Anthropic が現在 Claude 組織に請求できない状態です。                   | Claude Console で請求情報を確認してください。                                                                                                                                                                                              |

ClickHouse Cloud に関するご質問は、[ClickHouse サポート](https://clickhouse.com/support/program)までお問い合わせください。
Anthropic 側で利用上限や接続を管理するには、Claude Console の [Linked platforms](https://platform.claude.com/linked-platforms) ページを使用してください。
