パブリックプレビュー機能とは、ClickHouse Cloud の機能のうち、ほぼ完成しており、一般提供 (GA) に向けた道筋が明確になっているものです。お客様からのフィードバックを得るために公開されていますが、まだベータ段階には至っていません。

<Warning>
  パブリックプレビュー機能は変更される可能性があり、ClickHouse Cloud の標準 SLA の対象外です。
</Warning>

## パブリックプレビューを有効化する {#enable-public-preview}

1. クラウドコンソールにサインインし、対象の組織を選択します。
2. 組織メニューを開き、**Preview features** を選択します。組織のサイドバーからもアクセスできます。
3. 対象の機能を探し、**Learn more** を選択して要件と制限事項を確認したうえで、スイッチをオンにします。スイッチが無効になっている場合は、組織の管理者に機能の有効化を依頼してください。
4. 利用可能な場合は、**Go to...** または **View in...** のサービスリンクから機能を使い始めることができます。

<Note>
  利用可否は、組織のアクセス権と機能のロールアウト状況によって異なります。すべてのパブリックプレビューがすべての組織で利用できるとは限りません。アクセス権の確認については、[Cloud サポート](https://clickhouse.com/support/program)までお問い合わせください。
</Note>
