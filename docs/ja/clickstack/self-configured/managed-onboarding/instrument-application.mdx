このガイドでは、小規模な Node.js アプリケーションを OpenTelemetry でインストルメントし、そのログ、メトリクス、トレース、セッションリプレイを Self-managed ClickHouse Observability に送信する手順を説明します。バックエンドのインストルメントは、アプリケーションのソースコードを一切変更せずに行います。

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) は、パブリックな ClickHouse デモでホストされている HackerNews データセットにクエリを実行する Node.js アプリです。すべてのチャート、テーブル、検索ボックスは実際の ClickHouse クエリに基づいているため、操作のたびにトレースが生成され、そのメインのスパンはバックエンドから ClickHouse への HTTPS 呼び出しになります。

このガイドは、[OpenTelemetry Collector のセットアップ](/ja/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector)を完了済みで、このアプリケーションを実行するマシンから接続可能な ClickStack コレクターが稼働していることを前提としています。デプロイ時に設定した `OTLP_AUTH_TOKEN` に加えて、**その OTLP エンドポイントを必ず控えておいてください**。これらの値は、インストルメントの前に `.env` に設定します。

## 前提条件 {#prerequisites}

* このマシンから接続可能な ClickStack コレクター。まだデプロイしていない場合は、先に [OpenTelemetry Collector のセットアップ](/ja/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) の手順を完了してください。
* そのコレクターの OTLP/HTTP エンドポイント (通常はポート `4318`) と、コレクターに設定した `OTLP_AUTH_TOKEN`。これらはそれぞれ `OTEL_EXPORTER_OTLP_ENDPOINT` および `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>` に指定します。
* Node 18 以降と npm。

## リポジトリをクローンする {#clone-the-repository}

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) をクローンし、依存関係をインストールしたうえで、env テンプレートファイルをコピーします。

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

`.env` には以降の手順で値を設定し、その後このディレクトリでインストルメントを行います。
