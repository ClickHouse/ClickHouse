[`otelgen`](https://github.com/krzko/otelgen) は、合成の OTLP ログ、トレース、メトリクスを生成する軽量な Go 製 CLI です。既存の ClickStack OpenTelemetryコレクターがデータを受け付けていること、およびイベントが ClickStack UI に表示されることを確認するために使用します。

このガイドは、collector が `4317` (gRPC) と `4318` (HTTP) の OTLP エンドポイントで既に稼働していることを前提としています。

<Steps>
  <Step title="前提条件" id="prerequisites-oss">
    このガイドでは、[all-in-one イメージの手順](/ja/clickstack/getting-started/oss)に従ってオープンソース版 ClickStack を起動済みであり、OTLP エンドポイント (`4317` の gRPC と `4318` の HTTP) にアクセスできることを前提としています。また、ClickStack UI の `Team Settings > API Keys` にあるインジェスト API key も必要です。
  </Step>

  <Step title="otelgen をインストールする" id="install-otelgen-oss">
    Homebrew でインストールします。

    ```shell
    brew install krzko/tap/otelgen
    ```

    または、Go でインストールします。

    ```shell
    go install github.com/krzko/otelgen@latest
    ```
  </Step>

  <Step title="環境変数を設定する" id="set-env-vars-oss">
    collector のエンドポイントとインジェスト API key をエクスポートします。

    ```shell
    export OTEL_ENDPOINT=localhost:4317
    export CLICKSTACK_API_KEY=<your_ingestion_api_key>
    ```
  </Step>

  <Step title="トレースを生成する" id="generate-traces-oss">
    複数の span を含むトレースを短時間送信します。

    ```shell
    otelgen --otel-exporter-otlp-endpoint ${OTEL_ENDPOINT} \
      --header "authorization=${CLICKSTACK_API_KEY}" \
      --protocol grpc --insecure \
      --rate 2 --duration 10 \
      traces multi
    ```

    `--rate` は 1 秒あたりのトレース数、`--duration` は実行時間 (秒) です。`--insecure` はローカル collector に対する平文 gRPC を有効にします。
  </Step>

  <Step title="ログを生成する" id="generate-logs-oss">
    ```shell
    otelgen --otel-exporter-otlp-endpoint ${OTEL_ENDPOINT} \
      --header "authorization=${CLICKSTACK_API_KEY}" \
      --protocol grpc --insecure \
      --rate 2 --duration 10 \
      logs multi
    ```
  </Step>

  <Step title="メトリクスを生成する" id="generate-metrics-oss">
    `metrics` サブコマンドは `--duration` をサポートしていません。コマンドを実行し、数秒後に `Ctrl+C` を押して停止してください。

    ```shell
    otelgen --otel-exporter-otlp-endpoint ${OTEL_ENDPOINT} \
      --header "authorization=${CLICKSTACK_API_KEY}" \
      --protocol grpc --insecure \
      --rate 2 \
      metrics sum
    ```

    `otelgen` は `metrics` 配下で `gauge`、`histogram`、`up-down-counter`、`exponential-histogram` の各サブコマンドにも対応しています。
  </Step>

  <Step title="ClickStack で確認する" id="verify-oss">
    [http://localhost:8080](http://localhost:8080) にアクセスして ClickStack UI を開きます。`Search` ビューでログソースを `Logs` と `Traces` に切り替え、新しいイベントが入っていることを確認します。時間範囲を `Last 15 minutes` に設定します。`Chart Explorer` を開いて `Metrics` を選択し、`otelgen` が生成したメトリクス名の 1 つ (たとえば `otelgen.metrics.sum`) をグラフ化して、メトリクスのインジェストを確認します。
  </Step>
</Steps>
