ClickStack には、一般的なインフラストラクチャやアプリケーションのメトリクスをすぐに可視化できる、あらかじめ用意されたダッシュボードテンプレートのライブラリが含まれています。

## 利用可能なテンプレートを参照する {#browsing-templates}

組み込みのテンプレートライブラリを参照するには、**ダッシュボード** に移動し、**ダッシュボードテンプレートを参照** をクリックします。

<div className="ch-image-lg">
  <Frame>
    ![ダッシュボードテンプレートを参照ボタン](/images/use-cases/observability/browse-dashboard-template.webp)
  </Frame>
</div>

テンプレートギャラリーが開き、テンプレートがカテゴリ別に表示されます。そのテンプレートのインポートを開始するには、**Import** をクリックします。

<div className="ch-image-lg">
  <Frame>
    ![ダッシュボードテンプレートギャラリー](/images/use-cases/observability/dashboard-template-gallery.webp)
  </Frame>
</div>

## テンプレートのインポート {#importing-a-template}

テンプレートをインポートするには、ダッシュボードの各可視化にデータソースを設定する必要があります。各可視化のドロップダウンからデータソースを選択し、`Finish Import` をクリックします。

    ![ダッシュボードテンプレートのインポート](/images/use-cases/observability/import-dashboard-template.webp)
  </Frame>
</div>

### OTel ランタイムメトリクス {#otel-runtime-metrics}

組み込みの OTel ランタイムメトリクステンプレートは、[OpenTelemetry ランタイムメトリクス](https://opentelemetry.io/docs/specs/semconv/runtime/)で計装済みのアプリケーション向けに設計されています。

| テンプレート                      | 説明                                                  |
| --------------------------- | --------------------------------------------------- |
| **.NET Runtime Metrics**    | .NET アプリケーションの GC 回数、ヒープサイズ、スレッドプールの使用状況、アセンブリ数     |
| **Go Runtime Metrics**      | Go アプリケーションの Goroutine 数、GC 停止時間、ヒープ使用量、メモリ統計       |
| **JVM Runtime Metrics**     | JVM ベースのアプリケーションのヒープおよび非ヒープメモリ、GC 所要時間、スレッド数、クラスロード |
| **Node.js Runtime Metrics** | Node.js アプリケーションのイベントループ遅延、ヒープ使用量、CPU 使用率、V8 メモリ    |

注意事項:

* 各テンプレートには、[`telemetry.sdk.language`](https://opentelemetry.io/docs/specs/semconv/registry/attributes/telemetry/#telemetry-sdk-language) リソース属性がダッシュボードのランタイムと一致するサービスに絞り込む[カスタムフィルター](/ja/clickstack/features/dashboards/overview#custom-filters)が設定されています。
  * ClickHouse のメトリクステーブルスキーマをカスタマイズしている環境では、正しいサービス名カラムおよびリソース属性カラムをクエリするよう、このフィルタの調整が必要になる場合があります。
  * データ量の多い環境では、`ResourceAttributes['telemetry.sdk.language']` カラムを[マテリアライズ](/ja/clickstack/managing/performance-tuning#materialize-frequently-queried-attributes)することで、フィルタの読み込み時間を短縮できます。
* テンプレートは公開時点で最新の OTel セマンティック規約に準拠しており、OTel 仕様の更新に合わせて定期的に更新されます。古い OTel SDK で計装されたサービスでは、古いメトリクス名を参照するよう可視化を[編集](/ja/clickstack/features/dashboards/overview#dashboards-editing-visualizations)する必要がある場合があります。
