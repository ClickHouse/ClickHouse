このガイドでは、小規模な Node.js アプリケーションを OpenTelemetry でインストルメントし、そのログ、メトリクス、トレース、セッションリプレイを Self-managed ClickHouse Observability に送信する手順を説明します。バックエンドのインストルメントには、アプリケーションのソースコードの変更は一切必要ありません。

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) は、パブリックな ClickHouse デモでホストされている HackerNews データセットにクエリを実行する Node.js アプリです。すべてのチャート、テーブル、検索ボックスは実際の ClickHouse クエリで動作しているため、あらゆる操作でトレースが生成されます。そのメインスパンは、バックエンドから ClickHouse への HTTPS 呼び出しです。

このガイドは、[OpenTelemetry Collector のセットアップ](/ja/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) を完了し、ClickStack コレクターが稼働していて、このアプリケーションを実行するマシンから接続可能であることを前提としています。**OTLP エンドポイントを必ず控えておいてください**。デプロイ時に設定した `OTLP_AUTH_TOKEN` も同様です。インストルメントを行う前に、これらの値を `.env` に設定します。

## 前提条件 {#prerequisites}

* このマシンから接続可能な ClickStack コレクター。まだデプロイしていない場合は、先に [OpenTelemetry Collector のセットアップ](/ja/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) の手順を実施してください。
* そのコレクターの OTLP/HTTP エンドポイント (通常はポート `4318`) と、コレクターに設定した `OTLP_AUTH_TOKEN`。これらはそれぞれ `OTEL_EXPORTER_OTLP_ENDPOINT` および `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>` として指定します。
* Node 18 以上と npm。

## リポジトリをクローンする {#clone-the-repository}

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) をクローンし、依存関係をインストールしてから、env テンプレートファイルをコピーします。

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

`.env` には以降の手順で値を設定し、その後このディレクトリでインストルメントを行います。
