<Note>
  このガイドでは、完全マネージド型の ClickHouse オブザーバビリティについて説明します。Self-managed ClickHouse Observability については、サイジング、保持期間、スキーマのチューニング、本番環境向けのガイダンスは [データベース管理](/ja/clickstack/self-configured/managing/overview) を、ソース設定については [設定オプション](/ja/clickstack/self-configured/managing/config) を参照してください。
</Note>

ClickHouse オブザーバビリティでは、**チーム設定** から、テレメトリーへのアクセス、ソース、API およびエージェントの接続、インテグレーション、クエリ設定、チームのアクセス許可を管理できます。

## 管理ガイド {#admin-guides}

| ガイド                                                      | できること                                                                       |
| -------------------------------------------------------- | --------------------------------------------------------------------------- |
| [設定オプション](/ja/clickstack/observability/managing/config)     | ソースと collector へのアクセスの管理、テレメトリーの接続情報の確認、API およびエージェントのアクセス設定、クエリ設定の調整を行えます。 |
| [ロールベースのアクセス制御](/ja/clickstack/observability/managing/rbac) | 組み込みロールの確認、カスタムロールの作成、ダッシュボード・保存済み検索・ソースなどのリソースに対するアクセス許可の設定を行えます。          |

## テレメトリーの送信 {#sending-telemetry}

アプリケーションやコレクターを接続するには、まず **チーム設定 → Data → マネージドテレメトリー** で接続情報を確認し、続いて[インジェストガイド](/ja/clickstack/observability/ingesting-data/overview)の手順に従ってください。
