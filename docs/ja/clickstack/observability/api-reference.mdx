ClickHouse オブザーバビリティでは、ClickHouse Cloud API を使用して、ダッシュボード、アラート、Webhook、ロール、保存済み検索の管理や、データソースへのアクセスを行います。

<Note>
  完全マネージド型の環境では、ソースは自動的に管理されます。ソースの内容を確認するには、ソースの読み取り操作を使用してください。ソースの作成・更新・削除の操作は、ソースをご自身で管理するデプロイメント向けです。
</Note>

## APIリファレンスドキュメント {#api-docs}

サイドバーでエンドポイントを選択すると、そのエンドポイントのパラメータ、リクエストおよびレスポンスのスキーマ、対話型の例を確認できます。これらのページは **ClickHouse Cloud API** の仕様に基づいており、Cloud サービスの URL と認証方式を使用します。

利用可能なエンドポイントは次のとおりです。

| リソース        | 操作                                        |
| ----------- | ----------------------------------------- |
| **ダッシュボード** | ダッシュボードの作成、一覧取得、取得、更新、削除、検証               |
| **アラート**    | アラートの作成、一覧取得、取得、更新、削除                     |
| **ソース**     | データソースの一覧取得と取得、およびユーザー自身が管理するソースの作成、更新、削除 |
| **Webhook** | Webhook の作成、一覧取得、更新、削除、検証                 |
| **ロール**     | ロールの作成、一覧取得、取得、更新、削除                      |
| **保存済み検索**  | 保存済み検索の作成、一覧取得、取得、更新、削除                   |

## 認証 {#authentication}

ClickHouse オブザーバビリティでは、[HTTP Basic認証](https://developer.mozilla.org/en-US/docs/Web/HTTP/Authentication) による認証に **ClickHouse Cloud APIキー** を使用します。APIキーの作成と管理については、[APIキーの管理](/ja/products/cloud/features/admin-features/api/openapi) を参照してください。

キーには `control-plane:service:manage-clickstack-api` のアクセス許可が付与されている必要があります。

HTTP Basic認証を使用して、キー ID とシークレットを指定します。

```bash
export KEY_ID=<your_key_id>
export KEY_SECRET=<your_key_secret>

curl --user $KEY_ID:$KEY_SECRET \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/dashboards
```

## ベースURLとリクエストフォーマット {#base-url}

ClickHouse オブザーバビリティ APIのリクエストはすべて、ClickHouse Cloud APIに送信されます：

```bash
https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/<resource>
```

**組織 ID** は、ClickHouse Cloud コンソールの **組織 → 組織の詳細** で確認できます。**サービス ID** は、サービスの URL またはサービスの詳細ページで確認できます。

### 例: ダッシュボードの一覧を取得する {#list-dashboards-managed}

```bash
curl --user $KEY_ID:$KEY_SECRET \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/dashboards
```

### 例: アラートの作成 {#create-alert-managed}

```bash
curl -X POST --user $KEY_ID:$KEY_SECRET \
  -H "Content-Type: application/json" \
  -d '{
    "dashboardId": "<DASHBOARD_ID>",
    "tileId": "<TILE_ID>",
    "threshold": 100,
    "interval": "1h",
    "source": "tile",
    "thresholdType": "above",
    "channel": {
      "type": "webhook",
      "webhookId": "<WEBHOOK_ID>"
    },
    "name": "Error Spike Alert",
    "message": "Error rate exceeded 100 in the last hour"
  }' \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/alerts
```
