OpenTelemetry を使用して、React Native アプリケーションの JavaScript レイヤーから ClickHouse Observability にトレースを送信します。

<ClickStackIntegrates signals={['traces']} />

## OpenTelemetry のセットアップ {#set-up-opentelemetry}

公式の [OpenTelemetry React Native デモ](https://opentelemetry.io/docs/demo/services/react-native-app/)とその[インストルメンテーションのソースコード](https://github.com/open-telemetry/opentelemetry-demo/tree/main/src/react-native-app)を参考に、トレーシングを初期化し、ネットワークリクエストをインストルメントしてください。

このデモでは OpenTelemetry の JavaScript パッケージを使用していますが、これらのパッケージは React Native を公式にはサポートしていません。お使いのアプリケーションの React Native および OpenTelemetry のバージョンとの互換性を事前に検証してください。

## 宛先を設定する {#configure-destination}

デモのローカルエクスポーター設定を、以下の宛先に置き換えます。このエクスポーターは、アップストリームのセットアップにあるスパンプロセッサーで使用してください。エクスポーターのURLには `/v1/traces` を含める必要があります。

<Tabs>
  <Tab title="完全マネージド型">
    <BetaBadge label="ベータ版" />

    サービスで **Team Settings → Data → Managed Telemetry** を開き、**OTLP HTTP エンドポイント** と **API key** をコピーします。HTTPSエンドポイントはポートを含めてそのまま使用し、末尾に `/v1/traces` を追記します。

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_OTEL_ENDPOINT:4318/v1/traces',
      headers: {
        Authorization: 'Bearer YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>

  <Tab title="セルフマネージド">
    collectorのOTLP HTTPエンドポイントとインジェストキーを使用します。collectorにはデバイスから接続可能である必要があります。collectorのセットアップについては、[OpenTelemetryによるデータの取り込み](/ja/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)を参照してください。

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_COLLECTOR_HOST:4318/v1/traces',
      headers: {
        Authorization: 'YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>
</Tabs>

## インジェストを確認する {#verify-ingestion}

デバイスまたはシミュレーターでアプリケーションを実行し、ネットワークリクエストを送信します。ClickHouse Observability で直近の時間範囲を選択し、Traces にアプリケーションのサービス名が表示されていることを確認します。

インストルメンテーションの詳細や React Native の互換性に関する回避策については、[OpenTelemetry React Native デモ](https://opentelemetry.io/docs/demo/services/react-native-app/)を参照してください。エクスポーターのオプションについては、[OpenTelemetry JavaScript エクスポーターのドキュメント](https://opentelemetry.io/docs/languages/js/exporters/)を参照してください。
