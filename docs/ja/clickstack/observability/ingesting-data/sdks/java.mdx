OpenTelemetry Java agent または SDK を使用して、ログ、メトリクス、トレースを ClickHouse オブザーバビリティに送信します。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## OpenTelemetry のセットアップ {#set-up-opentelemetry}

公式の [OpenTelemetry Java agent セットアップ手順](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/) に従って、インストルメンテーションをインストールし、アプリケーションを設定してください。手動でインストルメントする場合は、[Java SDK ドキュメント](https://opentelemetry.io/docs/languages/java/instrumentation/) を参照してください。

以下の接続設定を使用して、送信するシグナルの [OTLP エクスポート](https://opentelemetry.io/docs/languages/java/configuration/#properties-exporters) を設定してください。アップストリームの手順に記載されている例の宛先は、シグナルごとのエンドポイントのオーバーライドも含め、すべて置き換えてください。

## 宛先を設定する {#configure-destination}

<Tabs>
  <Tab title="完全マネージド型">
    <BetaBadge label="ベータ版サービス" />

    サービスで **チーム設定 → Data → マネージドテレメトリー** を開き、**OTLP HTTPエンドポイント** と **APIキー** をコピーします。エンドポイントには、ポート番号を含む完全な HTTPS エンドポイントを指定してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="セルフマネージド">
    collector の OTLP HTTPエンドポイントとインジェスト key を使用します。collector で TLS が設定されていない場合は、`https://` ではなく `http://` を使用してください。collector のセットアップ方法については、[OpenTelemetry を使用したデータ取り込み](/ja/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)を参照してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## インジェストを確認する {#verify-ingestion}

計装済みのアプリケーションを起動し、アクティビティを発生させます。ClickHouse オブザーバビリティで直近の時間範囲を選択し、ログ または トレース でアプリケーションのサービス名を探します。アプリケーションがメトリクスを出力している場合は、エクスポートが完了するまでしばらく待ってから メトリクス を確認してください。

インストルメンテーションおよびエクスポーターのトラブルシューティングについては、[OpenTelemetry Java agent のトラブルシューティングガイド](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/#troubleshooting)を参照してください。
