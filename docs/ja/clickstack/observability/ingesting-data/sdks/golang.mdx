OpenTelemetry Go SDK を使用して、ログ、メトリクス、トレースを ClickHouse オブザーバビリティに送信します。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## OpenTelemetry のセットアップ {#set-up-opentelemetry}

公式の [OpenTelemetry Go セットアップ手順](https://opentelemetry.io/docs/languages/go/getting-started/)に従って SDK を初期化し、アプリケーションをインストルメントします。

以下の接続設定を使用して、送信するシグナルに対して [HTTP 経由の OTLP エクスポート](https://opentelemetry.io/docs/languages/go/exporters/)を設定します。アップストリームの手順に記載されているサンプルの宛先は、シグナルごとのエンドポイントのオーバーライドも含め、すべて置き換えてください。

## 宛先を設定する {#configure-destination}

<Tabs>
  <Tab title="完全マネージド型">
    <BetaBadge label="ベータ版" />

    サービスで **チーム設定 → Data → Managed Telemetry** を開き、**OTLP HTTP エンドポイント** と **API key** をコピーします。ポート番号を含む完全なHTTPSエンドポイントを使用してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="セルフマネージド">
    collectorのOTLP HTTPエンドポイントとインジェスト用APIキーを使用します。collectorでTLSが設定されていない場合は、`https://` ではなく `http://` を使用してください。collectorのセットアップについては、[OpenTelemetryによるデータの取り込み](/ja/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)を参照してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## インジェストを確認する {#verify-ingestion}

計装済みのアプリケーションを起動し、アクティビティを発生させます。ClickHouse オブザーバビリティで直近の時間範囲を選択し、ログ または トレース でアプリケーションのサービス名を探します。アプリケーションがメトリクスを出力している場合は、エクスポートされるまでしばらく待ってから メトリクス を確認してください。

インストルメンテーションやエクスポーターのトラブルシューティングについては、[OpenTelemetry Go のドキュメント](https://opentelemetry.io/docs/languages/go/)を参照してください。
