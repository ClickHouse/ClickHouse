Next.js のデプロイメント環境に応じて、サーバー側のインストルメンテーションを選択してください。

* **セルフホスト(Node.js ランタイム):** ClickStack Node.js SDK を使用します。
* **Vercel または Edge ランタイム:** `@vercel/otel` を使用します。

ブラウザーのテレメトリーおよびセッションリプレイについては、[ブラウザー SDK ガイド](/ja/clickstack/observability/ingesting-data/sdks/browser)を参照してください。

## セルフホスト環境の Next.js {#self-hosted-nextjs}

Node.js 22.15 以降を使用し、SDK をインストールします。

```shell
npm install @clickhouse/clickstack-node
```

プロジェクトのルート (アプリケーションで `src` ディレクトリを使用している場合はその中) に `instrumentation.ts` を作成します。SDK は Node.js ランタイムでのみ初期化するようにします。

```typescript
export async function register() {
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { init } = await import('@clickhouse/clickstack-node');
    init();
  }
}
```

SDK がサーバーバンドルの外部で読み込まれるように、既存の Next.js 設定の `serverExternalPackages` に SDK を追加します。

```javascript
// next.config.mjs
export default {
  serverExternalPackages: ['@clickhouse/clickstack-node'],
};
```

以下で宛先を設定し、`OTEL_SERVICE_NAME` を設定してアプリケーションを識別できるようにしてください。SDK のプリロードを併用したり、別の OpenTelemetry SDK を初期化したりしないでください。その他のオプションについては、[Node.js ガイド](/ja/clickstack/observability/ingesting-data/sdks/nodejs)を参照してください。

終了処理やデプロイメントに関する注意点については、[SDK の Next.js ガイダンス](https://github.com/ClickHouse/clickstack-node#nextjs)を参照してください。

## Vercel および Edge ランタイム {#vercel-or-edge}

[Next.js の OpenTelemetry セットアップ手順](https://nextjs.org/docs/app/guides/open-telemetry)に従って `@vercel/otel` を使用してください。上記の ClickStack Node.js SDK による初期化の代わりに、このセットアップを使用します。

以下の接続設定を使用して [OTLP エクスポート](https://github.com/vercel/otel/tree/main/packages/otel#registerotelconfig-configuration)を設定してください。サンプルの宛先やシグナルごとのエンドポイントのオーバーライドはすべて置き換え、変数はデプロイメントの設定で指定してください。

Vercel のデプロイメントですでにトレーシングのインテグレーションを使用している場合は、この宛先向けに[カスタムエクスポーター](https://nextjs.org/docs/app/guides/open-telemetry#custom-exporters)を設定してください。エンドポイントの環境変数を設定するだけでは、既存のインテグレーションはオーバーライドされません。

## 宛先を設定する {#configure-destination}

どちらのインストルメンテーションオプションを使用する場合も、サービス名を設定します：

```shell
export OTEL_SERVICE_NAME='my-nextjs-app'
```

## インジェストの確認 {#verify-ingestion}

アプリケーションを起動し、サーバーサイドでレンダリングされるページまたは API ルートにリクエストを送信します。ClickHouse Observability で直近の時間範囲を選択し、Traces でアプリケーションのサービス名を確認します。
