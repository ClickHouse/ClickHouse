## アプリケーションを接続する {#connect-your-application}

1. 使用している言語またはプラットフォーム向けのガイドに従って、インストルメンテーションを設定します。
2. そのガイドで宛先を選択します。
   * **完全マネージド型:** サービスのマネージド OTLP エンドポイントとインジェスト API key を使用します。これらは **チーム設定 → Data → Managed Telemetry** で確認できます。
   * **セルフマネージド:** OpenTelemetry Collector の OTLP エンドポイントと、設定済みのインジェストキーを使用します。
3. アプリケーションでアクティビティを発生させ、想定どおりのテレメトリーが UI に表示されることを確認します。

SDK ごとの認証フォーマットとエクスポーターの設定については、各ガイドを参照してください。Lambda ガイドでは、ローカルの Collector 経由でテレメトリーを転送する OpenTelemetry レイヤーを使ったオプションも紹介しています。
