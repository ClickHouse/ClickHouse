Deno の組み込み OpenTelemetry サポートを使用して、ログ、メトリクス、トレースを ClickHouse オブザーバビリティに送信します。ClickStack Node.js SDK やレガシーの Deno ロギングパッケージは必要ありません。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## OpenTelemetry のセットアップ {#set-up-opentelemetry}

公式の [Deno OpenTelemetry セットアップ手順](https://docs.deno.com/runtime/fundamentals/open_telemetry/)に従って、アプリケーションをインストルメントしてください。以下で宛先を設定したうえで、アプリケーションの起動時に Deno の組み込みインテグレーションを有効にします。

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

アプリケーションに必要なアクセス許可を追加します。アップストリームの手順に記載されているサンプルの宛先やコンソールエクスポーターの設定は、シグナル別のエンドポイントのオーバーライドも含め、すべて置き換えてください。

## 宛先を設定する {#configure-destination}

<Tabs>
  <Tab title="完全マネージド型">
    <BetaBadge label="ベータ版サービス" />

    サービスで **チーム設定 → Data → マネージドテレメトリー** を開き、**OTLP HTTPエンドポイント** と **APIキー** をコピーします。HTTPS エンドポイントは、ポートを含めた完全な形で指定してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="セルフマネージド">
    collector の OTLP HTTPエンドポイントとインジェスト key を使用します。collector で TLS を設定していない場合は、`https://` ではなく `http://` を使用してください。collector のセットアップについては、[OpenTelemetry を使用したデータ取り込み](/ja/clickstack/observability/ingesting-data/opentelemetry#self-managed) を参照してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## インジェストの確認 {#verify-ingestion}

アプリケーションを起動してアクティビティを発生させます。ClickHouse オブザーバビリティで直近の時間範囲を選択し、ログ または トレース でアプリケーションのサービス名を探します。エクスポートが完了するまでしばらく待ってから、メトリクス を確認してください。
