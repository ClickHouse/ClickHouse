OpenTelemetry Erlang/Elixir SDK を使用して、トレースを ClickHouse オブザーバビリティに送信します。

<ClickStackIntegrates signals={['traces']} />

## OpenTelemetry のセットアップ {#set-up-opentelemetry}

公式の [OpenTelemetry Erlang/Elixir セットアップ手順](https://opentelemetry.io/docs/languages/erlang/getting-started/) に従って SDK を初期化し、アプリケーションをインストルメントします。

以下の接続設定を使用して、トレース用に [HTTP 経由の OTLP エクスポート](https://opentelemetry.io/docs/languages/erlang/exporters/) を設定します。アップストリームの手順に記載されている例の宛先は、シグナル固有のエンドポイントのオーバーライドも含め、すべて置き換えてください。

## 宛先を設定する {#configure-destination}

<Tabs>
  <Tab title="完全マネージド型">
    <BetaBadge label="ベータ提供" />

    サービスで **チーム設定 → Data → Managed Telemetry** を開き、**OTLP HTTP エンドポイント** と **API key** をコピーします。HTTPSエンドポイントは、ポート番号を含めた完全な形式で指定してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="セルフマネージド">
    collectorのOTLP HTTPエンドポイントとインジェストキーを使用します。collectorでTLSを設定していない場合は、`https://` ではなく `http://` を使用してください。collectorのセットアップについては、[OpenTelemetryによるデータの取り込み](/ja/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured)を参照してください。

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## インジェストを確認する {#verify-ingestion}

計装済みのアプリケーションを起動し、アクティビティを発生させます。ClickHouse オブザーバビリティで直近の時間範囲を選択し、Traces でアプリケーションのサービス名を確認します。

インストルメンテーションやエクスポーターのトラブルシューティングについては、[OpenTelemetry Erlang/Elixir のドキュメント](https://opentelemetry.io/docs/languages/erlang/)を参照してください。
