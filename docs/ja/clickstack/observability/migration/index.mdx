Elastic Stack または Datadog から、マネージドまたはセルフマネージドの ClickHouse オブザーバビリティへ移行する方法を説明します。各ガイドでは、移行計画、検索構文、既存のテレメトリー収集の移行対応について取り上げます。デプロイ形態によって接続情報が異なる箇所では、該当するタブを選択してください。

| テクノロジー                                                       | 説明                                                                      |
| ------------------------------------------------------------ | ----------------------------------------------------------------------- |
| [Elastic Stack](/ja/clickstack/observability/migration/elastic) | 移行計画の策定、検索クエリの変換、およびデータ、エージェント、アプリケーションのインストルメンテーションの移行                 |
| [Datadog](/ja/clickstack/observability/migration/datadog)       | 既存の Datadog エージェントを設定し、マネージドのエンドポイントまたはセルフマネージドの Datadogレシーバーへテレメトリーを送信 |
