ClickHouse オブザーバビリティのイベントパターンは、類似したメッセージを自動的にクラスタリングすることで、大量のログやトレースの内容をすばやく把握できるようにする機能です。数百万件のイベントを個別に調べる必要はなく、意味のある少数のグループを確認するだけで済みます。

  </Frame>

これにより、どのエラーや警告が新たに発生したものか、どれが繰り返し発生しているものか、どれがログ量の急増の原因になっているのかを、はるかに容易に特定できます。パターンは動的に生成されるため、正規表現を定義したり、パースルールをメンテナンスしたりする必要はありません。

インシデント対応だけでなく、この俯瞰的なビューは、コスト削減のためにトリムできるノイズの多いログソースの特定、サービスが出力するさまざまな種類のログの把握、そして必要なシグナルをシステムがすでに出力しているかどうかの迅速な確認にも役立ちます。

## イベントパターンへのアクセス {#accessing-event-patterns}

イベントパターンは、ClickHouse オブザーバビリティの **検索** パネルから直接利用できます。

左側の **分析モード** で **イベントパターン** を選択すると、標準の結果テーブルから、類似したイベントをクラスター化したビューに切り替わります。

  <Frame>
    ![検索の分析モードでハイライトされたイベントパターン](/images/clickstack/observability-event-patterns-highlight.png)

これは、個々のログやトレースを 1 件ずつスクロールして確認できるデフォルトの **結果テーブル** に代わる表示方法です。

## 推奨事項 {#recommendations}

イベントパターンは、データを**絞り込んだサブセット**に適用したときに最も効果を発揮します。たとえば、イベントパターンを有効にする前に単一のサービスに絞り込んでおくと、数千ものサービスにまとめてパターンを適用するよりも、関連性が高く有用なメッセージを見つけやすくなります。

また、エラーメッセージの要約にも特に効果的です。ID やペイロードだけが異なる繰り返しのエラーが、簡潔なクラスターにまとめられます。
