以下のインテグレーションパートナーを利用すると、テレメトリーパイプラインやアプリケーションを ClickHouse オブザーバビリティに接続できます。各ガイドでは、ご利用のデプロイメントに応じたインテグレーションの設定方法を説明しています。

| セクション                                                                 | 説明                                                                                                        |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| [Bindplane](/ja/clickstack/observability/integration-partners/bindplane) | Bindplane は、OpenTelemetry コレクターを一元管理できる OpenTelemetry ネイティブのテレメトリーパイプラインです。                               |
| [bitdrift](/ja/clickstack/observability/integration-partners/bitdrift)   | bitdrift は、モバイルアプリケーション向けの動的なオブザーバビリティプラットフォームで、OpenTelemetryトレースコンテキストを介してモバイルテレメトリーをバックエンドのトレースに関連付けます。 |
| [Odigos](/ja/clickstack/observability/integration-partners/odigos)       | Odigos は eBPF と OpenTelemetry を組み合わせることで、バイトコードエージェントよりも大幅に低いオーバーヘッドで、より詳細な分散トレースを実現します。                  |
| [Telflo](/ja/clickstack/observability/integration-partners/telflo)       | Telflo は、コレクターの管理とテレメトリーのルーティングを一元化する OpenTelemetry ネイティブのコントロールプレーンです。                                   |
