ClickHouse オブザーバビリティの利用を開始し、テストイベントを送信して、そのイベントがオブザーバビリティ UI に表示されることを確認します。

このサービスはマネージドテレメトリーエンドポイントを提供します。アプリケーション、エージェント、または既存の OpenTelemetry Collector から、このエンドポイントにデータを送信してください。

インジェストパイプラインとスキーマを独自に管理する場合は、[セルフマネージド版のはじめにガイド](/ja/clickstack/self-configured/getting-started/managed)を参照してください。

## はじめる前に {#before-you-begin}

完全マネージド型の ClickHouse オブザーバビリティ サービスに加え、そのテレメトリーエンドポイントと APIキーへのアクセス権が必要です。

### サービスを作成する {#create-a-service}

まだサービスがない場合は、ClickHouse Cloud クイックスタートの [ClickHouse サービスを作成する](/ja/get-started/setup/cloud#1-create-a-clickhouse-service) から始めてください。サービスが稼働したら、ClickHouse オブザーバビリティを開きます。サービスにまだデータがない場合は、**はじめに** ページが自動的に表示されます。以下の 3 つの方法からいずれかを選んで、テレメトリーを送信してください。

## ClickHouse オブザーバビリティをセットアップする {#set-up-clickhouse-observability}

ご利用の環境に合った方法を選択してください。

<Tabs>
  <Tab title="既存の OpenTelemetry セットアップを使用する">
    <div className="ch-image-md">
      <Frame>
        ![URL、Collector config、Env vars の各オプションとマスクされた接続情報を表示する Set up OpenTelemetry ダイアログ](/images/clickstack/getting-started/observability-connection-details.png)
      </Frame>
    </div>

    アプリケーション、エージェント、または コレクター がすでに OpenTelemetry データを生成している場合は、この方法を使用します。

    1. はじめにページで **View connection details** を選択します。

    2. テレメトリー送信元に対応する設定をコピーします。接続情報には **URL**、**Collector config**、**Env vars** の各オプションが用意されています。

    3. 提供された認証情報を使用して、マネージドエンドポイントにテレメトリーをエクスポートするよう送信元を設定します。

    4. アプリケーションを通常どおり操作し、生成されたデータが [検索](/ja/clickstack/observability/features/search) に表示されることを確認します。

    これらの接続情報は **Team Settings → Data → Managed Telemetry** からも確認できます。

    <Tip>
      簡易的に動作を確認したい場合は、はじめにページで **send a test log** を選択します。このボタンは UI からテストログを即座に送信するもので、アプリケーションや コレクター の設定を検証するものではありません。
    </Tip>
  </Tab>

  <Tab title="AI でインストルメントする">
    <div className="ch-image-md">
      <Frame>
        ![インストルメンテーション用プロンプトと、マスクされたエンドポイントおよび API キーの環境変数を表示する Set it up with an AI agent ダイアログ](/images/clickstack/getting-started/observability-ai-instrumentation.png)
      </Frame>
    </div>

    アプリケーションコードがあり、コーディングアシスタントを使って OpenTelemetry インストルメンテーションを追加したい場合は、この方法を使用します。

    1. **AI でインストルメントする** の **Copy prompt** を選択し、**Set it up with an AI agent** ダイアログを開きます。
    2. ダイアログからプロンプトをコピーし、Cursor、Copilot、Claude Code など、アプリケーションコードにアクセスできるコーディングアシスタントに貼り付けます。
    3. ダイアログに表示された値を使用して `CLICKSTACK_OTLP_ENDPOINT` と `CLICKSTACK_API_KEY` を設定します。これらの値は、バージョン管理の対象外とした `.env` ファイル、またはシークレットストアに保存してください。
    4. 提案されたインストルメンテーションを確認して適用したら、アプリケーションを実行してイベントを発生させます。

    このワークフローを独自のアプリケーションに適用するには、[AI でインストルメントする](/ja/clickstack/observability/ingesting-data/sdks/instrument-with-ai) を参照してください。

    アプリケーションコードとインストルメンテーション用プロンプトを含む完全な例については、[HackerNews Analyzer デモ](/ja/clickstack/observability/example-datasets/instrument-application) を参照してください。アプリケーションのログ、トレース、メトリクス、ブラウザのセッションリプレイをマネージドサービスに送信する手順を順を追って説明しています。
  </Tab>

  <Tab title="セットアップガイドに従う">
    <div className="ch-image-md">
      <Frame>
        ![言語、フレームワーク、インフラストラクチャ、コレクター 向けの検索可能なセットアップガイドを表示する Send data ダイアログ](/images/clickstack/getting-started/observability-setup-guides.png)
      </Frame>
    </div>

    特定のアプリケーションやインフラストラクチャを対象とした手順が必要な場合は、この方法を使用します。

    1. **Browse セットアップガイド** を選択します。
    2. 使用している言語、フレームワーク、またはインフラストラクチャに対応するガイドを選択します。
    3. ガイドに記載されたインストルメンテーションと設定の手順に従い、対象からテレメトリーを生成します。

    マネージド環境での設定例については、まず [Kubernetes モニタリング](/ja/clickstack/observability/example-datasets/kubernetes)、[ローカルのログとメトリクス](/ja/clickstack/observability/example-datasets/local-data)、または [HackerNews Analyzer アプリケーション](/ja/clickstack/observability/example-datasets/instrument-application) を参照してください。アプリケーションをインストルメントせずにデータのインジェストを試したい場合は、[otelgen](/ja/clickstack/observability/example-datasets/otelgen) または [telemetrygen](/ja/clickstack/observability/example-datasets/telemetrygen) を使用してください。
  </Tab>
</Tabs>

## インジェストを確認して探索を開始する {#verify-ingestion}

選択した手順を完了したら、**Start exploring** を選択して [検索](/ja/clickstack/observability/features/search) を開きます。先に進む前に、生成したイベントを探し、表示されていることを確認してください。

ログの場合は、**Logs** ログソースを選択し、イベントを送信した時点を含む時間範囲を指定します。以下の例は、UI の **send a test log** ボタンから送信したログで、サービス名は `example-service` です。イベントを展開すると、その属性を確認できます。

</div>
