これらのサンプルデータセットとデモを活用して、完全マネージド型の ClickHouse オブザーバビリティを使い始めましょう。サンプルデータの読み込み、ご利用の環境からのログとメトリクスの収集、アプリケーションのインストルメントによるトレースやセッションリプレイの探索などを行えます。

| データセット                                                                                   | 説明                                                                                             |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [サンプルデータ](/ja/clickstack/observability/example-datasets/sample-data)                        | デモ環境から取得したログ、トレース、メトリクスを含むサンプルデータセットを読み込みます                                                    |
| [Kubernetes の監視](/ja/clickstack/observability/example-datasets/kubernetes)                  | Kubernetes クラスターからログとメトリクスを収集し、マネージドサービスに送信します                                                 |
| [ローカルデータ](/ja/clickstack/observability/example-datasets/local-data)                         | ローカルシステムのメトリクスとログを収集し、マネージドサービスに送信して分析します                                                      |
| [セッションリプレイのデモ](/ja/clickstack/observability/example-datasets/session-replay)                | デモ用 Web アプリケーションをセッションリプレイ向けにインストルメントし、自身の操作内容を ClickHouse オブザーバビリティで確認します                     |
| [Chrome 拡張機能](/ja/clickstack/observability/example-datasets/chrome-extension)               | HyperDX Chrome拡張機能を使用して、任意の Web サイトにブラウザー SDK を挿入します。アプリケーションコードの変更は不要です                       |
| [otelgen による合成データ](/ja/clickstack/observability/example-datasets/otelgen)                   | `otelgen` を使用して、合成したログ、トレース、メトリクスをマネージドテレメトリーのエンドポイントに送信します                                    |
| [telemetrygen による合成データ](/ja/clickstack/observability/example-datasets/telemetrygen)         | `telemetrygen` を使用して、合成したログ、トレース、メトリクスをマネージドテレメトリーのエンドポイントに送信します                               |
| [HackerNews Analyzer](/ja/clickstack/observability/example-datasets/instrument-application) | エージェントを使用して (または手動で) Node.js アプリをインストルメントし、ログ、トレース、メトリクス、セッションリプレイを ClickHouse オブザーバビリティに送信します |
