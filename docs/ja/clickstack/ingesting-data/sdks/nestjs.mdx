ClickStack Node.js SDK を使用すると、NestJS アプリケーションからテレメトリーを収集して ClickStack に送信できます。この SDK には NestJS のリクエストに対するインストルメンテーションが組み込まれており、コンソール出力も収集します。

## SDK のインストール {#install-sdk}

Node.js 22.15 以降を使用してください。

```shell
npm install @clickhouse/clickstack-node
```

## 宛先を設定する {#configure-destination}

ClickStack コレクターの OTLP HTTP エンドポイントとインジェストキーを設定します。コレクターで TLS が設定されていない場合は、`http://` を使用してください。コレクターのセットアップについては、[OpenTelemetry によるデータの取り込み](/ja/clickstack/ingesting-data/opentelemetry)を参照してください。

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## アプリケーションを起動する {#start-application}

アプリケーションを識別できるよう、`OTEL_SERVICE_NAME` を設定します。NestJS アプリケーションをビルドしたら、コンパイル済みのエントリーポイントより先に SDK がプリロードされるようにします。

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

`dist/main.js` は、実際のビルド出力に合わせて変更してください。`ts-node` など、`require` をフックするトランスパイラーを使用している場合は、代わりに `--require @clickhouse/clickstack-node/register` を指定してください。アプリケーションをバンドルする場合は、SDK と計装済みの依存関係をバンドルに含めず、外部依存関係として扱ってください。

NestJS のデフォルトのコンソールロガーは引き続き使用できます。カスタムロガーを使用する場合は、Winston や Pino など、サポート対象のインテグレーションを使用してください。設定や互換性の詳細については、[Node.js ガイド](/ja/clickstack/ingesting-data/sdks/nodejs)を参照してください。

## インジェストを確認する {#verify-ingestion}

コントローラーにリクエストを送信し、ログメッセージを出力します。ClickStack で直近の時間範囲を選択し、Logs と Traces でアプリケーションのサービス名を探します。エクスポートされるまでしばらく待ってから、Metrics を確認します。
