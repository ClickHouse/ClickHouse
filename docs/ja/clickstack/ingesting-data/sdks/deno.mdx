Deno に組み込まれている OpenTelemetry サポートを使用して、ログ、メトリクス、トレースを ClickStack に送信します。ClickStack Node.js SDK やレガシーの Deno ロギング用パッケージは不要です。

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## OpenTelemetry のセットアップ {#set-up-opentelemetry}

公式の [Deno OpenTelemetry セットアップ手順](https://docs.deno.com/runtime/fundamentals/open_telemetry/) に従って、アプリケーションをインストルメントしてください。以下の宛先を設定したうえで、アプリケーションの起動時に Deno の組み込みインテグレーションを有効にします。

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

アプリケーションに必要なアクセス許可を追加します。アップストリームの手順に記載されているサンプルの宛先やコンソールエクスポーターの設定は、シグナルごとのエンドポイントのオーバーライドも含め、すべて置き換えてください。

## 宛先を設定する {#configure-destination}

ClickStack コレクターの OTLP HTTP エンドポイントとインジェスト用 API キーを設定します。コレクターで TLS が設定されていない場合は、`http://` を使用してください。コレクターのセットアップについては、[OpenTelemetry によるデータの取り込み](/ja/clickstack/ingesting-data/opentelemetry)を参照してください。

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## インジェストを確認する {#verify-ingestion}

アプリケーションを起動し、アクティビティを発生させます。ClickStack で直近の時間範囲を選択し、ログ または トレース でアプリケーションのサービス名を探します。メトリクス については、エクスポートされるまでしばらく待ってから確認してください。
