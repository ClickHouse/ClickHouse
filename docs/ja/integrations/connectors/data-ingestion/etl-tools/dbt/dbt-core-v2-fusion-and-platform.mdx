dbt は新しいエンジン上で再構築されており、ClickHouse は当初からその一部です。ClickHouse は dbt OSS と dbt v2 の両方で、新しい Rust ベースの dbt エンジンに対応しました。さらに、dbt platform から ClickHouse に接続できるようにもなりました。プロジェクト側の変更は不要です。現在 dbt Core 1.x で動作しているモデル、テスト、profiles はそのまま新しいエンジンでも動作し、異なるのは バイナリ だけです。

ClickHouse は、dbt OSS、dbt v2、および dbt platform における最初のコミュニティアダプターです。dbt 自身のファーストパーティアダプターも同時に提供が始まりますが、dbt Labs 以外からの提供としては当社が最初です。dbt Core 1.x 向けの Python アダプター `dbt-clickhouse` が廃止されることはありません。dbt 1.x の リリース に追随して最新の状態を保ち、両方のアダプターを並列に保守していきます。

<Warning>
  **ベータであり、まだ GA ではありません。** dbt OSS および dbt v2 向けの ClickHouse アダプターはベータで、dbt platform 接続はプライベートベータです。dbt Core 1.x アダプター `dbt-clickhouse` は GA であり、本番環境での使用がサポートされています。このページの内容はその点に影響しません。
</Warning>

<Note>
  **dbt Core 1.x のドキュメントは dbt OSS および dbt v2 にも当てはまります。** 新しいアダプターの挙動は両方のエンジンで同じです。他の dbt ページで説明されている profiles、model configs、materializations、macros は、dbt OSS、dbt v2、dbt platform でもそのまま動作します。例外については、以下の [v1 と v2 の 互換性](#parity) の各表に記載しています。
</Note>

<Note>
  **dbt OSS** は、v2 エンジンの open-source (Apache 2.0) build です。dbt v2 および dbt platform との関係については、[用語と availability](#terminology) を参照してください。
</Note>

最新の状況は [ClickHouse/dbt-clickhouse#660](https://github.com/ClickHouse/dbt-clickhouse/issues/660) (v1 に対する v2 の 互換性。領域ごとに 1 つのサブ イシュー) および [ClickHouse/dbt-clickhouse#555](https://github.com/ClickHouse/dbt-clickhouse/issues/555) (dbt v2) で追跡しています。

#### dbt platform で ClickHouse を試す {#request-access}

プライベートベータを試してみたい場合は、[dbt Labs のプライベートベータ申込フォーム](https://docs.google.com/forms/d/e/1FAIpQLScjHwRchnKarq_RpNM7hATjphNFxqBEePmAwRtSpMWG1snGHA/viewform)から登録してください。このフォームは dbt Labs が管理しているため、送信された情報は ClickHouse ではなく dbt Labs に送られます。利用が有効化されたら、dbt ドキュメントの [Connect ClickHouse](https://docs.getdbt.com/docs/platform/connect-data-platform/connect-clickhouse) に従って接続を設定してください。

## 用語と提供状況 {#terminology}

dbt にはいくつかの形態があり、同じアダプターが複数の形態で動作する場合もあります。次の表では、それぞれの名称と現時点での ClickHouse のサポート状況を説明します。

| 用語               | 概要                                                                                                                                                                                                 | ClickHouse のステータスと入手方法                                                                                                                                                                                                                                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **dbt Core 1.x** | Python ベースの dbt エンジンで、open source(Apache 2.0)。ClickHouse が提供するアダプターは `dbt-clickhouse` で、[ClickHouse GitHub 組織](https://github.com/ClickHouse/dbt-clickhouse)でメンテナンスされており、`dbt-core` と併せてインストールします。 | **GA、メンテナンス中。** dbt v2 と並列にリリースが継続されています。                                                                                                                                                                                                                                                                               |
| **dbt OSS**      | dbt エンジンを Rust で全面的に書き換えたもので、open source(Apache 2.0)。この新バージョンには、v1 のすべての機能に加えていくつかのパフォーマンス改善が含まれます。                                                                                                | **ベータ。** dbt ドキュメントの [dbt v2 upgrade guide](https://docs.getdbt.com/docs/dbt-versions/core-upgrade/upgrading-to-v2) および [ClickHouse setup page for v2](https://docs.getdbt.com/docs/local/connect-data-platform/clickhouse-setup?version=2) を参照してください。ClickHouse アダプターは dbt のバイナリに同梱されているため、個別にインストールする package はありません。 |
| **dbt v2**       | dbt OSS に、dbt Labs による追加機能(SQL の解釈、静的解析、LSP、VS Code 拡張機能、カラム認識)を加えたもの。クローズドソースであり、[dbt Product Licensing Agreement](https://www.getdbt.com/dbt-fusion-engine-license-agreement) に基づいてライセンスされます。    | **ベータ。** アダプターは v2 のバイナリ上で動作しますが、新しい SQL 機能は ClickHouse ではまだ利用できません。                                                                                                                                                                                                                                                    |
| **dbt platform** | ホスト型の dbt(旧 dbt Cloud)。Studio IDE、スケジュール実行される job、環境、Catalog、Semantic Layer を提供します。このプラットフォームで動作するのは dbt v2 のみであるため、プラットフォーム上の ClickHouse は v2 アダプターを指します。                                         | **プライベートベータ。** [アクセスをリクエストする方法](#request-access)を参照してください。セットアップについては、dbt ドキュメントの [Connect ClickHouse](https://docs.getdbt.com/docs/platform/connect-data-platform/connect-clickhouse) を参照してください。                                                                                                                    |

## 現在のステータスの詳細 {#v2-adapter-status}

ベータとは、v1 のほぼすべての機能が、文書化された制約の範囲内で動作することを意味します。まだ対応待ちの機能は [v1 と v2 の互換性](#parity) に記載しており、この一覧はリリースごとに短くなっています。まずは開発環境またはステージング環境で dbt v2 を評価することを推奨します。プロジェクトが対応待ちの機能に依存している場合や、GA リリースの保証が必要な場合は、本番環境では dbt Core 1.x を引き続き使用してください。

dbt v2 アダプターは、`dbt-clickhouse` の dbt Core 1.x インテグレーションテストスイートを基準に評価しています。**現時点で、**&#x30A2;ダプターは v1 スイートの約 98% (dbt v2 に該当する 276 件のテストのうち 270 件) に合格しています。残る不合格項目は ClickHouse 側ではなく エンジン 側の差異によるもので、クエリコメント、run results における `query_id`、および `pre-hook` と `pre_hook` の両方で設定されたフックのチェックです。機能ごとの状況については [v1 と v2 の互換性](#parity) を参照してください。

**次のステップ**: クエリコメント、run results における `query_id`、テーブルの メタデータ に基づく `dbt source freshness`、残存するバグの修正、そして完全な互換性を確保するための v1 テストスイート全体の合格です。これらの進捗はすべて [ClickHouse/dbt-clickhouse#660](https://github.com/ClickHouse/dbt-clickhouse/issues/660) で追跡しており、領域ごとにサブ イシュー を設けています。

GA はロードマップに含まれています。スケジュールについては dbt Labs と調整中であり、準備が整い次第このページを更新します。

### ベータの対象外 {#out-of-scope}

ClickHouse SQL インテリジェンス (静的解析、LSP、カラム認識) 、Semantic Layer、dbt platform の追加認証方式など、v2 専用の機能はベータの対象外です。これらの現状については、[dbt v2 固有の機能](#v2-functionality)を参照してください。

#### v2 での対応予定なし {#not-planned}

v1 の一部のオプションは、意図的に v2 へ引き継いでいません。上記の互換性テーブルには対応予定の作業のみを記載するため、これらのオプションはここにまとめています。

| 機能              | v1 での動作             | 対応予定がない理由                                                                                                                                                   |
| --------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `verify: false` | TLS 証明書の検証をスキップします。 | 暗号化は維持されるものの認証が行われなくなるため、通信経路上の第三者がサーバーになりすまし、認証情報を読み取れてしまいます。v2 は常に証明書を検証し、このキーは無視されます。クライアントが信頼する CA によって署名された証明書を使用してください。v2 でこの機能が必要な場合は、イシューを作成してください。 |

### dbt v2 固有の機能 {#v2-functionality}

dbt v2 には、dbt Core 1.x には相当するものがない機能が追加されています。これらは ベータ の対象範囲外で、今後提供される予定です。その多くはエンジンが SQL ダイアレクトを理解していることを前提としていますが、ClickHouse 向けのダイアレクトはまだ存在せず、現在対応を進めています。凡例は上記と同じで、作業中のものには <Badge color="blue">対応中</Badge> を付けています。進捗は [ClickHouse/dbt-clickhouse#736](https://github.com/ClickHouse/dbt-clickhouse/issues/736) で管理しています。

| ------------------------------ | ----------------------------------------------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| エンジンにおける ClickHouse SQL ダイアレクト | 以下の静的機能の基盤となる、ダイアレクトを考慮した SQL パース。                                | <Badge color="red">未対応</Badge>    | 計画中。                                                                                                                                                               |
| 静的解析                           | warehouse にクエリを発行せずに行う、コンパイル時の SQL 検証と型チェック。                      | <Badge color="red">未対応</Badge>    | ダイアレクトが提供されるまで、ClickHouse プロジェクトでは強制的に `off` になります。                                                                                                                |
| dbt platform でのカラムレベルのデータリネージ   | 実行アーティファクトから構築されるカラム単位のデータリネージビュー。                                | <Badge color="yellow">部分的</Badge> | `dbt_project.yml` で識別子のクォートを無効にした場合のみ表示されます。プラットフォームのフォールバックパーサーが、バッククォートで囲まれた名前を受け付けないためです ([dbt-labs/dbt#16646](https://github.com/dbt-labs/dbt/issues/16646)) 。 |

| アダプター呼び出しの記録と再適用               | `--fs-record` / `--fs-replay` により、warehouse なしでJobを再実行。           | <Badge color="yellow">部分的</Badge> | ClickHouse のカタログ情報 (`ON CLUSTER`、`EXCHANGE`、MV のリンク) は記録されないため、再適用時に異なる DDL がレンダリングされる場合があります。                                                                     |
