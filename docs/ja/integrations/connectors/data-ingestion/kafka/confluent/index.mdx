Confluent では、ClickHouse と連携するための以下の 3 つのオプションを提供しています：

* [Confluent Cloud 上の ClickHouse Connect Sink](/ja/integrations/connectors/data-ingestion/kafka/confluent/confluent-cloud)：完全マネージド型のコネクタ
* [Confluent Cloud 上の Custom Connector としての ClickHouse Connect Sink](/ja/integrations/connectors/data-ingestion/kafka/confluent/custom-connector)：コネクタをご自身でアップロードして利用します
* [Confluent Platform 向け HTTP Sink コネクタ](/ja/integrations/connectors/data-ingestion/kafka/confluent/kafka-connect-http)：HTTP または HTTPS 経由で Apache Kafka を API と連携します

## どの Confluent Cloud オプションを使用すべきですか？ {#which-confluent-cloud-option-should-i-use}

最初の 2 つのオプションは、いずれも Confluent Cloud 上で同じ ClickHouse Connect Sink を実行します。違いは、コネクタを誰が管理するかという点です。

* **完全マネージド型コネクタ**: コネクタのインストールとアップグレードは Confluent が行います。このコネクタで提供されていない機能が必要な場合を除き、まずはこちらを利用してください。
* **Custom Connector**: [GitHub](https://github.com/ClickHouse/clickhouse-kafka-connect/releases) からコネクタのリリースをダウンロードし、ご自身で Confluent Cloud にアップロードします。特定のバージョンのコネクタが必要な場合や、完全マネージド型コネクタでは Confluent へのサポートケースを作成しないと変更できない設定をオーバーライドしたい場合に使用します。なお、Custom Connectors は一部の AWS リージョンでのみ利用できます。
