[Chartbrew](https://chartbrew.com) はデータ可視化プラットフォームで、ダッシュボードを作成し、データをリアルタイムで監視できます。ClickHouse を含む複数のデータソースに対応しており、コードを書かずにグラフやレポートを作成できるインターフェイスを提供します。

## 目標 {#goal}

このガイドでは、Chartbrew を ClickHouse に接続し、SQL クエリを実行して可視化を作成します。完了時には、ダッシュボードは次のようになります。

<div className="ch-image-lg">
  <Frame>
    ![Chartbrew ダッシュボード](/images/integrations/data-visualization/chartbrew_01.webp)
  </Frame>
</div>

<Tip>
  **データを追加**

  使用するデータセットがない場合は、サンプルのいずれかを追加できます。このガイドでは、[UK Price Paid](/ja/get-started/sample-datasets/uk-price-paid) データセットを使用します。
</Tip>

<Steps>
  <Step title="接続情報を用意する" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="ChartbrewをClickHouseに接続する" id="2-connect-chartbrew-to-clickhouse">
    1. [Chartbrew](https://chartbrew.com/login) にログインし、**Connections** タブを開きます。

    2. **Create connection** をクリックし、表示されるデータベースの一覧から **ClickHouse** を選択します。

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew で ClickHouse 接続を選択する](/images/integrations/data-visualization/chartbrew_02.webp)
         </Frame>
       </div>

    3. ClickHouseデータベースの接続情報を入力します。

       * **Display Name**: Chartbrew 内で接続を識別するための名前。
       * **Host**: ClickHouseサーバーのホスト名または IPアドレス。
       * **Port**: HTTPS 接続の場合、通常は `8443` です。
       * **Database Name**: 接続先のデータベース。
       * **Username**: ClickHouse のユーザー名。
       * **Password**: ClickHouse のパスワード。

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew の ClickHouse 接続設定](/images/integrations/data-visualization/chartbrew_03.webp)
         </Frame>
       </div>

    4. **Test connection** をクリックし、Chartbrew から ClickHouse に接続できることを確認します。

    5. テストが成功したら、**Save connection** をクリックします。Chartbrew が ClickHouse からスキーマを自動的に取得します。

       <div className="ch-image-lg">
         <Frame>
           ![Chartbrew に表示された ClickHouse の JSON スキーマ](/images/integrations/data-visualization/chartbrew_04.webp)
         </Frame>
       </div>
  </Step>

  <Step title="データセットを作成してSQLクエリを実行する" id="3-create-a-dataset-and-run-a-sql-query">
    1. **Create dataset** ボタンをクリックするか、**Datasets** タブに移動してデータセットを作成します。
    2. 先ほど作成した ClickHouse 接続を選択します。

    <div className="ch-image-lg">
      <Frame>
        ![データセット用の ClickHouse 接続を選択](/images/integrations/data-visualization/chartbrew_05.webp)
      </Frame>
    </div>

    可視化したいデータを取得する SQL クエリを記述します。例えば、次のクエリは `uk_price_paid` データセットから年ごとの平均取引価格を算出します。

    ```sql
    SELECT toYear(date) AS year, avg(price) AS avg_price
    FROM uk_price_paid
    GROUP BY year
    ORDER BY year;
    ```

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew での ClickHouse SQLクエリ](/images/integrations/data-visualization/chartbrew_07.webp)
      </Frame>
    </div>

    **Run query** をクリックしてデータを取得します。

    クエリの書き方がわからない場合は、**Chartbrew の AIアシスタント** を使って、データベーススキーマに基づいた SQLクエリを生成できます。

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew の ClickHouse AI SQL アシスタント](/images/integrations/data-visualization/chartbrew_06.webp)
      </Frame>
    </div>

    データを取得したら、**Configure dataset** をクリックして可視化のパラメータを設定します。
  </Step>

  <Step title="可視化を作成する" id="4-create-a-visualization">
    1. 可視化に使用するメトリクス (数値) とディメンション (カテゴリ値) を定義します。
    2. データセットをプレビューし、クエリ結果が正しく構造化されていることを確認します。
    3. チャートの種類 (例：折れ線グラフ、棒グラフ、円グラフ) を選択し、ダッシュボードに追加します。
    4. **Complete dataset** をクリックしてセットアップを完了します。

    <div className="ch-image-lg">
      <Frame>
        ![ClickHouse のデータを表示した Chartbrew のダッシュボード](/images/integrations/data-visualization/chartbrew_08.webp)
      </Frame>
    </div>

    データセットは必要な数だけ作成でき、データのさまざまな側面を可視化できます。これらのデータセットを使って複数のダッシュボードを作成し、さまざまなメトリクスを追跡できます。

    <div className="ch-image-lg">
      <Frame>
        ![ClickHouse のデータを表示した Chartbrew のダッシュボード](/images/integrations/data-visualization/chartbrew_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="データ更新の自動化" id="5-automate-data-updates">
    ダッシュボードを常に最新の状態に保つには、データの自動更新をスケジュールできます。

    1. データセットのリフレッシュボタンの横にあるカレンダーアイコンをクリックします。
    2. 更新間隔 (例：1時間ごと、1日ごと) を設定します。
    3. 設定を保存して、自動リフレッシュを有効にします。

    <div className="ch-image-lg">
      <Frame>
        ![Chartbrew のデータセットのリフレッシュ設定](/images/integrations/data-visualization/chartbrew_09.webp)
      </Frame>
    </div>
  </Step>
</Steps>
