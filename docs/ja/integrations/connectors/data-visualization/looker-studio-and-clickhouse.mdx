## Looker Studio を ClickHouse に接続する {#connecting-looker-studio-to-clickhouse}

まず、Google アカウントで [Looker Studio](https://lookerstudio.google.com) にログインし、新しいデータソースを作成します。

<div className="ch-image-md">
  <Frame>
    ![Looker Studio のインターフェイスで新しいデータソースを作成する](/images/integrations/data-visualization/looker_studio_01.webp)
  </Frame>
</div>

<br />

Google が提供する公式の MySQL コネクタ (名前は単に **MySQL**) を検索します。

<div className="ch-image-md">
  <Frame>
    ![Looker Studio のコネクタ一覧で MySQL コネクタを検索する](/images/integrations/data-visualization/looker_studio_02.webp)
  </Frame>
</div>

<br />

接続情報を指定します。MySQL インターフェイスのポートはデフォルトで 9004 ですが、
サーバー構成によっては異なる場合があるので注意してください。

<div className="ch-image-md">
  <Frame>
    ![Looker Studio で ClickHouse の MySQL 接続情報を指定する](/images/integrations/data-visualization/looker_studio_03.webp)
  </Frame>
</div>

<br />

ClickHouse からデータをフェッチする方法は 2 つあります。1 つ目は、Table Browser 機能を使用する方法です。

<div className="ch-image-md">
  <Frame>
    ![Looker Studio で Table Browser を使用して ClickHouse テーブルを選択する](/images/integrations/data-visualization/looker_studio_04.webp)
  </Frame>
</div>

<br />

もう 1 つは、カスタムクエリを指定してデータをフェッチする方法です。

<div className="ch-image-md">
  <Frame>
    ![Looker Studio でカスタム SQL クエリを使用して ClickHouse からデータをフェッチする](/images/integrations/data-visualization/looker_studio_05.webp)
  </Frame>
</div>

<br />

最後に、自動検出されたテーブル構造が表示されるので、必要に応じてデータ型を調整します。

<div className="ch-image-md">
  <Frame>
    ![Looker Studio で自動検出された ClickHouse テーブル構造を表示する](/images/integrations/data-visualization/looker_studio_06.webp)
  </Frame>
</div>

<br />

これで、データの探索や新しいレポートの作成に進めます。

## ClickHouse Cloud で Looker Studio を使用する {#using-looker-studio-with-clickhouse-cloud}

ClickHouse Cloud を使用する場合は、まず MySQL インターフェイスを有効にする必要があります。これは接続ダイアログの「MySQL」タブで設定できます。

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud の設定で MySQL インターフェイスを有効にする](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)
  </Frame>
</div>

<br />

Looker Studio の UI で、「Enable SSL」オプションを選択します。ClickHouse Cloud の SSL 証明書は [Let&#39;s Encrypt](https://letsencrypt.org/certificates/) によって署名されています。このルート証明書は [こちら](https://letsencrypt.org/certs/isrgrootx1.pem) からダウンロードできます。

<div className="ch-image-md">
  <Frame>
    ![ClickHouse Cloud の SSL 設定を使用した Looker Studio の接続設定](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)
  </Frame>
</div>

<br />

以降の手順は、前のセクションに記載したものと同じです。
