**前提条件**

このガイドを進めるには、以下が必要です。

* Azure Blob Storage アカウント
* [Azure 接続文字列](/ja/integrations/connectors/data-ingestion/azure/azure-data-factory/using-azureblobstorage#acquiring-azure-blob-storage-access-keys)
* コンテナー名
* 稼働中の ClickHouse Cloud サービス

<Steps>
  <Step title="データソースに移動する" id="navigate-to-data-sources">
    サービスのホームページで、左側のメニューから **データソース** をクリックします。
    **ClickPipes** ドロップダウンを展開し、**ClickPipeを作成** をクリックします。

    <div className="ch-image-md">
      <Frame>
        ![データソースに移動する](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/01-navigate-to-datasources.webp)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![ClickPipeを作成](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/02-create-clickpipe.webp)
      </Frame>
    </div>
  </Step>

  <Step title="データソースを選択する" id="select-data-source">
    データタイプとして **Azure Blob Storage** を選択します。

    <div className="ch-image-md">
      <Frame>
        ![Azure Blob Storage を選択する](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/03-select-blob-storage.webp)
      </Frame>
    </div>
  </Step>

  <Step title="ClickPipe の接続を設定する" id="setup-connection">
    1. ClickPipe にわかりやすい名前を付けます
    2. 認証方式のドロップダウンから **接続文字列** を選択します
    3. **接続文字列** フィールドに Azure の接続文字列を貼り付けます
    4. コンテナー名を入力します
    5. Azure Blob Storage のファイルパスを入力します。複数のファイルを取り込む場合は、ワイルドカードを使用できます

    必要に応じて、継続的インジェストを有効にできます。詳細は[「継続的インジェスト」](/ja/integrations/clickpipes/object-storage/azure-blob-storage/overview#continuous-ingestion)を参照してください。

    最後に、**Incoming data** をクリックします。

    <div className="ch-image-md">
      <Frame>
        ![設定の詳細](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/04-configuration-details.webp)
      </Frame>
    </div>
  </Step>

  <Step title="データ形式を選択する" id="select-data-format">
    1. ファイルタイプを選択します
    2. ファイルの圧縮方式 (`detect automatically`、`none`、`gzip`、`brotli`、`xz`、`zstd`) を選択します
    3. カンマ区切り形式の区切り文字など、フォーマット固有の追加設定を行います
    4. **Parse information** をクリックします

    <div className="ch-image-md">
      <Frame>
        ![データ形式を選択する](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/05-choose-data-format.webp)
      </Frame>
    </div>
  </Step>

  <Step title="テーブル、スキーマ、設定を構成する" id="configure-table-schema">
    次に、受信データを格納するテーブルを新規作成するか、既存のテーブルを選択します。

    1. データを新しいテーブルにアップロードするか、既存のテーブルにアップロードするかを選択します
    2. 使用するデータベースを選択し、新しいテーブルの場合はテーブル名を指定します
    3. ソートキーを 1 つ以上選択します
    4. ソースファイルから書き込み先テーブルへのマッピング (カラム名、カラム型、デフォルト値、NULL 許容) を定義します
    5. 最後に、使用するエンジンタイプ、パーティション式、プライマリキーなどの詳細設定を指定します

    <div className="ch-image-md">
      <Frame>
        ![パース情報](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/06-parse-information.webp)
      </Frame>
    </div>

    テーブル、スキーマ、設定の構成が完了したら、**Details and settings** をクリックします。
  </Step>

  <Step title="アクセス許可を設定する" id="configure-permissions">
    ClickPipes は、データ書き込み用の専用データベースユーザーを作成します。
    このユーザーにはロールを選択できます。
    書き込み先テーブルからマテリアライズドビューやディクショナリにアクセスする場合は、「Full access」を選択してください。

    <div className="ch-image-md">
      <Frame>
        ![アクセス許可を設定する](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/07-permissions.webp)
      </Frame>
    </div>
  </Step>

  <Step title="セットアップを完了する" id="complete-setup">
    **ClickPipeを作成** をクリックしてセットアップを完了します。

    ClickPipe がプロビジョニング中のステータスで表示されます。
    しばらくすると、ステータスが **provisioning** から **completed** に変わります。
  </Step>
</Steps>
