### ClickPipe が &quot;change history start time is before allowed time travel interval&quot; というエラーで失敗する {#time-travel-window-exceeded}

[`APPENDS`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#appends) および [`CHANGES`](https://docs.cloud.google.com/bigquery/docs/reference/standard-sql/time-series-functions#changes) で読み取れるのは、ソーステーブルの[タイムトラベルウィンドウ](https://docs.cloud.google.com/bigquery/docs/time-travel) (デフォルトでは 7 日間) 内の変更のみです。ClickPipe の遅延がこのウィンドウを超えると、必要な変更が BigQuery 上に残っていない状態になります。ClickPipe を再同期して、この状態を解消してください。
