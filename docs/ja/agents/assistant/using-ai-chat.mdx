Assistant を使用すると、ClickHouse Cloud サービス内のデータを自然言語で分析できます。開いているタブ、保存クエリ、スキーマ、ダッシュボードなどのコンテキストを活用して、クエリ、可視化、要約を生成します。

Assistant には、ClickHouse のドキュメントに基づいて質問に回答する Docs AI モードも用意されています。このガイドでは、ClickHouse Cloud コンソールで Assistant を有効化し、両方のモードを活用する方法を説明します。

<Steps>
  <Step title="前提条件" id="prerequisites">
    1. AI 機能が有効になっている ClickHouse Cloud の組織にアクセスできる必要があります (利用できない場合は、組織の管理者またはサポートにお問い合わせください) 。
  </Step>

  <Step title="AI Chat パネルを開く" id="open-panel">
    1. ClickHouse Cloud サービスに移動します。
    2. 左側のサイドバーで、「Assistant」と表示されたスパークルアイコンをクリックします。
    3.  (ショートカット) <kbd>⌘</kbd> + <kbd>&#39;</kbd> (macOS) または <kbd>Ctrl</kbd> + <kbd>&#39;</kbd> (Linux/Windows) を押すと、パネルの表示を切り替えられます。

    <div className="ch-image-md">
      <Frame>
        ![AI Chat フライアウトを開く](/images/use-cases/AI_ML/AIChat/1_open_chat.webp)
      </Frame>
    </div>
  </Step>

  <Step title="データ利用への同意（初回のみ）" id="consent">
    1. 初回利用時には、データの取り扱いとサードパーティの LLM サブプロセッサーについて説明する同意ダイアログが表示されます。
    2. 内容を確認し、同意して続行します。同意しない場合、パネルは開きません。

    <div className="ch-image-md">
      <Frame>
        ![同意ダイアログ](/images/use-cases/AI_ML/AIChat/2_consent.webp)
      </Frame>
    </div>
  </Step>

  <Step title="チャットモードを選択する" id="modes">
    AI Chat は現在、次のモードをサポートしています。

    * **Agent**: スキーマとメタデータに基づく多段階の推論 (サービスが起動している必要があります) 。
    * **Docs AI (Ask)**: ClickHouse の公式ドキュメントとベストプラクティスのリファレンスに基づく Q&amp;A。

    モードを切り替えるには、フライアウト左下のモードセレクターを使用します。

    <div className="ch-image-sm">
      <Frame>
        ![モードの選択](/images/use-cases/AI_ML/AIChat/3_modes.webp)
      </Frame>
    </div>
  </Step>

  <Step title="メッセージを作成して送信する" id="compose">
    1. 質問を入力します (例: 「ユーザーごとに日次イベントを集約する materialized view を作成してください」) 。
    2. <kbd>Enter</kbd> を押して送信します (改行するには <kbd>Shift</kbd> + <kbd>Enter</kbd> を押します) 。
    3. モデルの処理中に「Stop」をクリックすると、処理を中断できます。
  </Step>

  <Step title="「Agent」の思考ステップについて" id="thinking-steps">
    Agent モードでは、展開可能な中間の「思考」ステップや計画ステップが表示されることがあります。これにより、アシスタントがどのように回答を組み立てているかを確認できます。必要に応じて折りたたんだり展開したりしてください。

    <div className="ch-image-md">
      <Frame>
        ![思考ステップ](/images/use-cases/AI_ML/AIChat/4_thinking.webp)
      </Frame>
    </div>
  </Step>

  <Step title="新しいチャットを開始する" id="new-chats">
    「New Chat」ボタンをクリックすると、コンテキストがクリアされ、新しい session が開始されます。
  </Step>

  <Step title="チャット履歴を表示する" id="history">
    1. 下部のセクションに最近のチャットが一覧表示されます。
    2. 以前のチャットを選択すると、そのメッセージが読み込まれます。
    3. 会話を削除するには、ゴミ箱アイコンをクリックします。

    <div className="ch-image-md">
      <Frame>
        ![チャット履歴の一覧](/images/use-cases/AI_ML/AIChat/5_history.webp)
      </Frame>
    </div>
  </Step>

  <Step title="生成された SQL を活用する" id="sql-actions">
    アシスタントが SQL を返した場合は、次のように操作します。

    * 正確性を確認します。
    * 「Open in editor」をクリックして、クエリを新しい SQL タブで開きます。
    * コンソールで修正し、実行します。

    <div className="ch-image-md">
      <Frame>
        ![結果のアクション](/images/use-cases/AI_ML/AIChat/6_result_actions.webp)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![生成されたクエリをエディターで開く](/images/use-cases/AI_ML/AIChat/7_open_in_editor.webp)
      </Frame>
    </div>
  </Step>

  <Step title="応答を停止または中断する" id="interrupt">
    応答に時間がかかりすぎる場合や、意図からそれている場合は、次の手順を実行します。

    1. 「Stop」ボタン (処理中に表示されます) をクリックします。
    2. メッセージは中断済みとしてマークされます。プロンプトを修正して再送信できます。
  </Step>

  <Step title="キーボードショートカット" id="shortcuts">
    | アクション       | ショートカット              |
    | ----------- | -------------------- |
    | AI Chat を開く | `⌘ + '` / `Ctrl + '` |
    | メッセージを送信    | `Enter`              |
    | 改行          | `Shift + Enter`      |
  </Step>
</Steps>
