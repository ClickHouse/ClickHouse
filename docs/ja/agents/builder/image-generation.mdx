画像生成機能を使うと、エージェントはテキストプロンプトから新しい画像を生成したり、ユーザーがアップロードした画像を編集したりできます。エージェントは、リクエストの内容と利用可能なコンテキストに応じて、生成と編集のどちらを行うかを判断します。

## 画像生成を有効にする {#enable-it}

画像生成は、エージェントビルダーの **Add Tools** モーダルから追加します (Capabilities セクションではありません) 。エージェントビルダーパネル下部の **Add Tools** をクリックし、画像モデル用のツール (例: **OpenAI Image Tools**、**DALL-E-3**、**Stable Diffusion**) をいずれか 1 つ追加します。エージェントはリクエストに応じて適切なツールを選択しますが、指示で使用するツールを限定することもできます。

## 生成 {#generation}

ユーザーが画像をリクエストすると、エージェントはプロンプトを渡して生成ツールを呼び出し、生成された画像をインラインで返します。エージェントは画像への参照をコンテキスト内に保持するため、同じ会話の中でその画像について説明したり、再利用したりできます。

## 編集 {#editing}

ユーザーが画像をアップロードし、色の変更、オブジェクトの追加、構図の拡張といった修正を依頼すると、エージェントはツールの編集用バリアントを呼び出します。出力では、依頼内容に応じて該当する領域が置き換えられるか、元の画像が拡張されます。

## 注記 {#notes}

* 生成された画像が、別途ビジョンによる分析に自動で渡されることはありません。エージェントに画像を*解釈*させたい場合は、ユーザーがアップロードした画像に対して[ビジョン](/ja/agents/builder/vision)を使用してください。
* プロバイダーのコンテンツポリシーが適用されます。プロバイダーのポリシーに違反するプロンプトに対しては、画像ではなくエラーが返されます。
