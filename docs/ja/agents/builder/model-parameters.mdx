モデルパラメータでは、エージェントが使用するモデルと、そのモデルによる応答の生成方法を制御します。
**エージェントビルダー** タブで、**モデル** 見出しの下にある **Select a モデル** をクリックします。
**モデルパラメータ** ウィンドウが開きます。

## プロバイダーとモデル {#provider-and-model}

* **プロバイダー** - 利用するアップストリームの LLM プロバイダーを選択します。
* **モデル** - そのプロバイダーが提供するモデルの中から、使用するモデルを選択します。モデルによって得意分野が異なり、計画立案の比重が大きいタスクには大規模な推論モデルが、定型的なクエリには高速な小規模モデルが適しています。

**プロバイダー** と **モデル** はどちらも必須です。パネルのその他の項目は、選択したモデルがサポートする機能に応じて変わります。

## コンテキストと出力の上限 {#context-and-output-limits}

* **Max Context Tokens** - エージェントがモデルに送信するコンテキストの合計量に上限を設定します。モデルのデフォルトを使用する場合は **System** のままにします。コストを抑えたい場合は値を下げ、大きな入力をもとに推論する必要があるエージェントでは値を上げます。
* **Max Output Tokens** - エージェントの応答サイズに上限を設定します。**System** の場合はモデルのデフォルトが使用されます。応答が長すぎる場合は値を下げ、応答が途中で切り詰められる場合は値を上げます。
* **File Token Limit** - アップロードされた 1 つのファイルがコンテキストに占めるトークン数に上限を設定します。ユーザーが大きなファイルを添付した際に、そのファイルによって会話の他の部分が圧迫されるのを防ぎたい場合に便利です。

## サンプリング {#sampling}

* **温度** - ランダム性です。値を高くする (0.7–1.0) と出力がよりランダムになり、低くする (0.0–0.3) と出力がより焦点の絞られた決定論的なものになります。この値と Top P は、どちらか一方のみを調整することを推奨します。
* **Top P** - nucleus サンプリングです。モデルが出力するトークンを選択する方法を変更します。
* **Top K** - 各ステップで、確率の高い上位 K 個のトークンにサンプリング対象を絞り込みます。一部のプロバイダーでサポートされており、温度とは異なる観点で決定性を制御します。

特定の挙動を狙って調整する場合を除き、スライダーはデフォルト付近のままにしておいてください。小さな変更ではほとんど効果がなく、大きな変更は出力品質の低下を招くおそれがあります。

## 推論コントロール {#reasoning-controls}

拡張推論に対応したモデルで利用できます。利用できる項目はプロバイダーによって異なります。

* **思考** - モデルの拡張推論モードのオン／オフを切り替えます。オンにすると、モデルは最終的な回答を出す前に内部で思考トークンを生成します。通常、難しいタスクでの精度が向上しますが、その代わりに低減とトークン消費量が増加します。
* **思考 Budget** - 思考フェーズに割り当てるトークン予算を設定します。モデルはこのトークン数を使い切った時点で思考を終了し、回答を返します。
* **Effort** - 推論にかける労力を大まかに調整する設定です (**Auto**、low、medium、high) 。思考トークンの予算を直接指定できない推論モデルで使用されます。
* **Thought Visibility** - モデルの思考内容をユーザーに対してインラインで表示するか、折りたたみ表示の中に隠すか、まったく表示しないかを制御します。

## 会話の動作 {#conversation-behavior}

* **Resend Files** - オンにすると、以前のターンで添付したファイルが以降のすべてのターンで再送信されるため、モデルがファイルの内容を見失うことがありません。会話が短い場合や、モデルが会話の進行に合わせてファイルを要約している場合は、オフにするとトークンを節約できます。
* **Use プロンプトキャッシュ** - プロバイダーが対応している場合、プロンプトの再利用可能な部分をキャッシュします。指示やツールの説明がターンごとに繰り返される会話で、コストと低減を削減できます。
* **ウェブ検索** - 対応モデルで、プロバイダーネイティブのウェブ検索のオン/オフを切り替えます。これは [ウェブ検索ツール](/ja/agents/builder/web-search) とは別の機能です。ウェブ検索ツールは、プロバイダーのケーパビリティではなく、エージェントのツールの 1 つとして実行されます。

## リセット {#reset}

パネル下部の **Reset モデルパラメータ** をクリックすると、すべてのフィールドがシステムのデフォルト値にリセットされます。設定をひととおり試した後、まっさらな状態からやり直したい場合に使用します。
