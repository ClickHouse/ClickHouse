エージェントビルダーでは、エージェントの作成と設定を行います。

<Tip>
  **エージェントを初めて使用する場合**

  まずは[クイックスタート](/ja/agents/quickstart)をご覧ください。以下の各ページでは、ビルダーの各機能について詳しく説明しています。
</Tip>

| ページ                                             | 説明                        |
| ----------------------------------------------- | ------------------------- |
| [コードインタープリター](/ja/agents/builder/code-interpreter) | サンドボックス内でのコード実行           |

| [画像生成](/ja/agents/builder/image-generation)        | テキストからの画像生成               |
| [ビジョン](/ja/agents/builder/vision)                  | 画像入力の受け付け                 |
| [MCPサーバー](/ja/agents/builder/mcp-servers)          | サードパーティ製MCPサーバーをエージェントに接続 |
| [スキル](/ja/agents/builder/skills)                   | 再利用可能な指示パック               |
| [サブエージェント](/ja/agents/builder/subagents)           | 子エージェントへの作業の委任            |
| [モデルパラメータ](/ja/agents/builder/model-parameters)    | エージェントのモデルパラメータの設定        |
