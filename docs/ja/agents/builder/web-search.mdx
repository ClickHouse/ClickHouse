ウェブ検索を使用すると、エージェントは会話中に公開ウェブから情報を取得できます。最近のリリースやサービス外にあるドキュメントの参照、信頼できる情報源での簡単な確認など、最新の情報に基づく回答が必要な質問に活用してください。

## 有効化する {#enable-it}

エージェントビルダーの **Capabilities** セクションで **ウェブ検索** を有効にします。有効化すると、エージェントはユーザーの質問とエージェントへの指示をもとに、検索を行うタイミングを自ら判断します。検索が実行されると結果がスクレイピングされ、最も関連性の高いコンテンツがモデルのコンテキストに渡されます。

## 検索ラウンドの仕組み {#how-a-search-round-works}

各検索は 3 つのステージで実行されます。Cloud では、これらのステージは自動的に管理されます。

1. **検索** - エージェントのクエリが検索プロバイダーに送信され、候補となる URL が返されます。
2. **スクレイプ** - 関連するページをフェッチし、意味のあるテキストを抽出します。
3. **リランク** - リランカーが結果をスコアリングし、モデルが最も有用な結果から順に参照できるようにします。

エージェントの応答には、実際に使用した URL が引用元として示されます。

## 使用するタイミング {#when-to-use-it}

* サービス内にないリリースノートや変更ログを調べる。
* モデルが把握していない可能性のある情報源と照らし合わせて事実を確認する。
* 公開されているブログ記事やドキュメントを会話に取り込んで分析する。

自分のデータやモデル自身の知識で回答できる質問には使用しないでください。検索ラウンドを重ねるごとにレイテンシが増加します。
