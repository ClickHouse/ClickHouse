Agents を使用すると、SQL やオーケストレーションロジックを自分で記述しなくても、会話を通じて ClickHouse のデータをクエリし、探索できます。
エージェントがユーザーの意図を解釈して処理の手順を計画し、設定済みのツールを呼び出して、その結果を返します。
この機能は現在ベータ版です。一般提供までに動作や機能が変更される可能性があります。

## できること {#what-you-can-do}

Agents では、次のことができます。

* コードを書かずにカスタムエージェントを構築できます。指示を記述し、モデルを選択して、ツールをアタッチするだけです。
* ClickHouse サービスを対象に会話を実行できます。エージェントは必要に応じてツールを呼び出します。
* エージェントをチームメンバーと共有したり、マーケットプレイスにパブリッシュしたりできます。
