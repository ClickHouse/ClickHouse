## 会話 {#conversations}

左側のナビゲーションにある作成アイコンをクリックすると、新しい会話を開始できます。
会話ウィンドウ左上のエージェントセレクターのダイアログで、使用するエージェントを選択します。デフォルトでは **ClickHouse Agent** が選択されています。
あとはコンポーザーにメッセージを入力して送信するだけです。各会話はサイドバーの履歴に保存され、後から再度開いたり、名前を変更したり、削除したりできます。

  <Frame>
    ![左側のナビゲーションで作成アイコンが強調表示され、サイドバーには保存済みの「Top 10 Tables Ranked」会話を含むチャット履歴が表示され、コンポーザーにはサンプルの質問が入力されているチャット画面](/images/cloud/agent-builder/chat/conversation.webp)
  </Frame>
</div>

送信済みのメッセージはその場で編集でき、編集すると、エージェントは会話履歴のその時点から応答を再生成します。
また、メッセージを再送信せずに、エージェントの最後の応答だけを再生成することもできます。

## ブックマーク {#bookmarks}

メッセージや会話全体をブックマークしておくと、後からすばやく呼び出せます。ブックマークは自分だけに表示され、会話の名前を変更しても保持されます。

## ピン留めされた会話 {#pinned-conversations}

会話をピン留めすると、その下に日付ごとにグループ化して表示される履歴とは別に、サイドバーの最上部に固定できます。サイドバーで会話のオプションメニュー (3 点アイコン) を開き、**Pin** を選択します。ピン留めされた会話は、**Today**、**Yesterday**、およびそれ以前のグループの上にある **Pinned** セクションにまとめて表示されます。

ピン留めを解除するには、同じメニューを開いて **Unpin** を選択します。

## 会話の分岐 {#forking}

会話の分岐は、特定のメッセージを起点に新しい会話を作成する機能です。元のスレッドに影響を与えることなく、別の流れを試すことができます。
利用できるフォークモードは次の 3 つです。

* **Visible messages only** - フォークするメッセージまでの直接のパスをコピーします。
* **Include related branches** - メインのパスに加えて、既存のすべての分岐をコピーします。
* **Include all to here** - フォークするメッセージまでのすべてをコピーします。

フォークした会話は元の会話から独立しているため、変更内容が元の会話に反映されることはありません。

## チャットの共有 {#sharing-chats}

任意の会話の共有リンクを生成して、チームメイトに送ったり、参照用に保存したりできます。リンクを受け取ったユーザーには、アーティファクトや表示中の分岐を含む読み取り専用のビューが表示されます。リンクは共有ダッシュボードからいつでも取り消せます。

既存のメッセージに加えた編集は共有ビューに反映されますが、リンクの生成後に追加されたメッセージは反映されません。

共有リンクを閲覧しているユーザーは誰でも、**Continue this chat** をクリックすると、自分のアカウントでその会話の続きを始められます。このとき、閲覧中の分岐を含む会話が新しいプライベートな会話として本人の履歴にコピーされるため、元の会話は変更されません。

会話を共有するには、サイドバーで対象の会話のメニューを開き、**共有** を選択します。

## キーボードショートカット {#keyboard-shortcuts}

キーボードショートカットの一覧は、`Cmd+Shift+/`(Windows および Linux では `Ctrl+Shift+/`)を押すか、アカウントメニューの **Help** → **Keyboard shortcuts** から開けます。すべてのショートカットはカスタマイズできます。ダイアログ内の行をクリックすると新しいキーの組み合わせを登録でき、元に戻すには **Reset all to defaults** を使用します。

デフォルトのショートカットは次のとおりです。

| 操作              | macOS                 | Windows および Linux      |
| --------------- | --------------------- | ---------------------- |
| キーボードショートカットを表示 | `Cmd+Shift+/`         | `Ctrl+Shift+/`         |
| 新しいチャット         | `Cmd+Shift+O`         | `Ctrl+Shift+O`         |
| チャット入力欄にフォーカス   | `Shift+Esc`           | `Shift+Esc`            |
| ファイルをアップロード     | `Cmd+Shift+U`         | `Ctrl+Shift+U`         |
| 最後の応答をコピー       | `Cmd+Shift+;`         | `Ctrl+Shift+;`         |
| メッセージを送信        | `Cmd+Enter`           | `Ctrl+Enter`           |
| サイドバーの表示切り替え    | `Cmd+Shift+S`         | `Ctrl+Shift+S`         |
| モデルセレクターを開く     | `Cmd+Shift+M`         | `Ctrl+Shift+M`         |
| 検索にフォーカス        | `Cmd+/`               | `Ctrl+/`               |
| 設定を開く           | `Cmd+Shift+,`         | `Ctrl+Shift+,`         |
| 会話をブックマーク       | `Cmd+Shift+B`         | `Ctrl+Shift+B`         |
| 生成を停止           | `Cmd+Shift+X`         | `Ctrl+Shift+X`         |
| 応答を再生成          | `Cmd+Shift+E`         | `Ctrl+Shift+E`         |
| 最後のメッセージを編集     | `Cmd+Shift+I`         | `Ctrl+Shift+I`         |
| 応答の続きを生成        | `Cmd+Shift+C`         | `Ctrl+Shift+C`         |
| 最後のコードブロックをコピー  | `Cmd+Shift+K`         | `Ctrl+Shift+K`         |
| 先頭へスクロール        | `Cmd+Shift+Up`        | `Ctrl+Shift+Up`        |
| 末尾へスクロール        | `Cmd+Shift+Down`      | `Ctrl+Shift+Down`      |
| 会話をアーカイブ        | `Cmd+Shift+L`         | `Ctrl+Shift+L`         |
| 会話を削除           | `Cmd+Shift+Backspace` | `Ctrl+Shift+Backspace` |

エージェント、プロンプト、ファイル、ブックマークなどのパネルを開くショートカットを独自に割り当てることもできます。これらのパネルにはデフォルトのキーが設定されていません。
