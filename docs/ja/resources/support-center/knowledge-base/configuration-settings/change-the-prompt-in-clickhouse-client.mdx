端末ウィンドウでの `clickhouse client` や clickhouse-local のプロンプト表示が気に入らない場合は、変更してプレフィックスを追加できます。
この記事では、プロンプトを好きな内容に変更する方法を説明します。

デフォルトのプロンプトは、ローカルコンピューター名の後に `:) ` が付いた形式です。

  <Frame>
    ![デフォルトの ClickHouse クライアント のプロンプト](/images/knowledgebase/change-the-prompt-in-clickhouse-client/0_prompt.webp)
  </Frame>
</div>

プロンプトで使用できる変数は次のとおりです: `{user}`, `{host}`

プロンプトを更新する方法はいくつかあり、ここではそれぞれを順に見ていきます。

## `--prompt` フラグ {#--prompt-flag}

このフラグを変更する最初の方法は、`--prompt` を使用することです。

```bash
clickhouse --prompt 👉
```

これで、スマイリーフェイスの前に指の絵文字が追加されます：

  <Frame>
    ![指の絵文字が表示された ClickHouse クライアントのプロンプト](/images/knowledgebase/change-the-prompt-in-clickhouse-client/1_prompt.webp)
  </Frame>
</div>

## 設定ファイル - トップレベル {#config-file---top-level}

または、`config.xml` ファイルでプロンプトのプレフィックスを指定することもできます：

```xml
<config>
    <prompt>👉 </prompt>
</config>
```

```
clickhouse
```

<div className="ch-image-md">
  <Frame>
    ![設定ファイルを使用した ClickHouse クライアントのプロンプト](/images/knowledgebase/change-the-prompt-in-clickhouse-client/2_prompt.webp)
  </Frame>
</div>

設定ファイルには任意の名前を付けることができ、`-C` フラグで指定して読み込ませます。

```xml
<config>
    <prompt>🎄 </prompt>
</config>
```

```
clickhouse -C christmas.xml
```

<div className="ch-image-md">
  <Frame>
    ![クリスマスツリーの絵文字が表示された ClickHouse クライアントのプロンプト](/images/knowledgebase/change-the-prompt-in-clickhouse-client/3_prompt.webp)
  </Frame>
</div>

設定ファイルは YAML で記述したい場合は、
次のように YAML でも設定できます。

```yaml
prompt: 🟡
```

```bash
clickhouse -C christmas.yaml
```

## 設定ファイル - connections_credentials {#config-file---connections_credentials}

あるいは、接続認証情報ごとにプロンプトを指定することもできます。
これは、clickhouse-client を使用する場合にのみ有効です。

```xml
<config>
    <connections_credentials>
        <connection>
            <n>prod</n>
            <hostname>127.0.0.1</hostname>
            <port>9000</port>
            <secure>0</secure>
            <user>default</user>
            <prompt>\e[31m[PRODUCTION]\e[0m {user}@prod</prompt>
        </connection>
        <connection>
            <n>dev</n>
            <hostname>127.0.0.1</hostname>
            <port>9000</port>
            <secure>0</secure>
            <user>default</user>
            <prompt>\e[32m[DEVELOPMENT]\e[0m {user}@dev</prompt>
        </connection>
    </connections_credentials>
</config>
```

次に、`dev` 接続を使って接続を試します:

```bash
clickhouse client -C connections.xml --connection dev
```

<div className="ch-image-md">
  <Frame>
    ![開発環境への接続の ClickHouse クライアント のプロンプト](/images/knowledgebase/change-the-prompt-in-clickhouse-client/5_prompt.webp)
  </Frame>
</div>

または `prod` のほう:

```bash
clickhouse client -C connections.xml --connection prod
```

<div className="ch-image-md">
  <Frame>
    ![本番環境への接続を使用したClickHouse クライアントのプロンプト](/images/knowledgebase/change-the-prompt-in-clickhouse-client/6_prompt.webp)
  </Frame>

YAML版は次のとおりです:

```yaml
connections_credentials:
  connection:
    - name: prod
      hostname: 127.0.0.1
      port: 9000
      secure: 0
      user: default
      prompt: "\e[35m[PRODUCTION]\e[0m {user}@{host}"
    - name: dev
      hostname: 127.0.0.1
      port: 9000
      secure: 0
      user: default
      prompt: "\e[34m[DEVELOPMENT]\e[0m {user}@{host}"
```

`dev` 接続では:

```bash
clickhouse client -C connections.yaml --connection dev
```
