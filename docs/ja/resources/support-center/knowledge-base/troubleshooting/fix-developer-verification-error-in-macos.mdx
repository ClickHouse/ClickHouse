## macOS での開発元検証エラーを解決する {#fix-the-developer-verification-error-in-macos}

macOS はデフォルトでは、インターネットからダウンロードしたアプリケーションやツールのうち、確認済みの開発元による署名と Apple による公証がないものは実行しません。

26.7.4 リリース以降 (および 26.8 以降のすべてのリリース) 、ClickHouse の macOS 向けビルドは ClickHouse Inc. の Developer ID で署名され、Apple による公証を受けています。これらのビルドは [GitHub のリリースページ](https://github.com/ClickHouse/ClickHouse/releases) で `clickhouse-macos.zip` (Intel) および `clickhouse-macos-aarch64.zip` (Apple silicon) として公開されており、Homebrew cask でインストールされるのもこれらのビルドです。これらのいずれかを使用していれば、macOS は警告を出さずに `clickhouse` を実行するため、本記事の手順は不要です。

ただし、macOS によって隔離 (quarantine) された署名なしのバイナリを実行すると、引き続きこのエラーが表示されることがあります。たとえば次のような場合です。

* Homebrew でインストールした古い ClickHouse リリース - `brew upgrade --cask clickhouse` を実行して署名済みのリリースに更新してください。
* GitHub のリリースページから Web ブラウザでダウンロードした自己展開形式の `clickhouse-macos` または `clickhouse-macos-aarch64` バイナリ - 代わりに同じリリースの `.zip` ファイルをダウンロードしてください。
* Web ブラウザでダウンロードした 26.7.4 より前のリリース。

`curl https://clickhouse.com/ | sh` でインストールしたバイナリは署名されていませんが、`curl` はダウンロードしたファイルを隔離しないため、macOS はこのエラーを出さずに実行します。

隔離された `clickhouse` バイナリを実行しようとすると、次のようなエラーが表示されることがあります。

<Image img="/images/knowledgebase/fix-the-developer-verification-error-in-macos/dev-verification-error.webp" size="md" alt="MacOS の開発元検証エラーダイアログ" border />

署名済みのビルドに切り替えられない場合は、システム設定または端末で、バイナリの隔離を解除してください。

## システム設定での手順 {#system-settings-process}

1. まず `clickhouse` バイナリを一度実行します。これにより macOS が上記のエラーを表示し、ブロックされたバイナリが記録されます。

2. **システム設定**を開きます。

3. **プライバシーとセキュリティ**に移動します。

   <Image img="/images/knowledgebase/fix-the-developer-verification-error-in-macos/privacy-and-security-default-view.webp" size="md" alt="macOSのプライバシーとセキュリティ設定のデフォルト表示" border />

4. **セキュリティ**セクションまでスクロールし、*「clickhouse-macos-aarch64」は、識別された開発元のものではないため、使用がブロックされました* というメッセージを探します。

5. **このまま開く**をクリックします (最近の macOS バージョンでは **Open Anyway** に相当するボタンです) 。

   <Image img="/images/knowledgebase/fix-the-developer-verification-error-in-macos/privacy-and-security-screen-allow-anyway.webp" size="md" alt="このまま開くボタンが表示されたmacOSのプライバシーとセキュリティ設定" border />

6. macOS のユーザーパスワードを入力します。

これで、端末で `clickhouse` コマンドを実行できるようになります。次回の実行時に、macOS から再度確認を求められる場合があります。

## 端末での手順 {#terminal-process}

システム設定のボタンでこの問題が解決しない場合や、コマンドラインで作業したい場合は、`xattr` を使用してバイナリから隔離属性を削除します。

`clickhouse` が `PATH` に含まれている場合は、まずその場所を確認します。

```shell
which clickhouse
```

次のような出力が得られるはずです。

```shell
/opt/homebrew/bin/clickhouse
```

前のコマンドで表示されたパスを指定して `xattr -d com.apple.quarantine` を実行し、`clickhouse` の隔離を解除します:

```shell
xattr -d com.apple.quarantine /opt/homebrew/bin/clickhouse
```

これで、`clickhouse` 実行ファイルを実行できるはずです:

```shell
clickhouse
```

次のような出力が得られるはずです。

```shell
Use one of the following commands:
clickhouse local [args]
clickhouse client [args]
clickhouse benchmark [args]
...
```
