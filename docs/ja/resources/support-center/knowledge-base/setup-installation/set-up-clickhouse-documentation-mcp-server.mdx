<Info>
このページでは、ClickHouse ドキュメントを検索するための MCP サーバーを設定します。ClickHouse のデータをクエリする場合は、[オープンソースの ClickHouse MCP サーバー](/ja/guides/use-cases/ai-ml/MCP)または[ClickHouse Cloud のリモート MCP サーバー](/ja/products/cloud/features/ai-ml/remote-mcp)を使用してください。
</Info>

Model Context Protocol (MCP) を使用して、AI ツールから ClickHouse ドキュメントを直接参照できます。

## AI ツールを接続する {#connect-your-ai-tool}

<Tabs>
<Tab title="Claude Code" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claudecode-color.svg">

ターミナルで次を実行します：

```bash
claude mcp add --transport http clickhouse-docs https://clickhouse.com/docs/mcp --scope user
```

</Tab>
<Tab title="Claude Desktop" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-claude.svg">

`claude_desktop_config.json` に追加します：

```json
{
  "mcpServers": {
    "clickhouse-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
    }
  }
}
```

</Tab>
<Tab title="Codex" icon="/images/logo-codex.svg">

ターミナルで次を実行します：

```bash
codex mcp add clickhouse-docs --url https://clickhouse.com/docs/mcp
```

</Tab>
<Tab title="Cursor" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-cursor.png">

`.cursor/mcp.json` に追加します：

```json
{
  "mcpServers": {
    "clickhouse-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
    }
  }
}
```

</Tab>
<Tab title="Windsurf" icon="https://clickhouse-docs-assets.s3.us-east-1.amazonaws.com/logo-windsurf.svg">

`~/.codeium/windsurf/mcp_config.json` に追加します：

```json
{
  "mcpServers": {
    "clickhouse-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://clickhouse.com/docs/mcp"]
    }
  }
}
```

</Tab>
</Tabs>

## コーディングエージェントに ClickHouse スキルを追加する {#add-clickhouse-skills}

ClickHouse スキルをインストールすると、エージェントに ClickHouse の専門知識とベストプラクティスを持たせることができます：

```bash
npx skills add https://clickhouse.com
```
