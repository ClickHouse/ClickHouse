入力クエリをフォーマットできます。

オプション:

* `--help` or`-h` — ヘルプメッセージを表示します。
* `--query` — 長さや複雑さを問わずクエリをフォーマットします。
* `--hilite` or `--highlight` — ANSI 端末のエスケープシーケンスによるシンタックスハイライトを追加します。
* `--oneline` — 単一行でフォーマットします。
* `--max_line_length` — 指定した長さ未満のクエリを 単一行でフォーマットします。
* `--wrap_width` — 複数行のクエリを指定した表示幅で折り返します。折り返しはデフォルトで無効です (`0`) 。`--oneline` または `--max_line_length` によって単一行にフォーマットされたクエリは折り返されません。
* `--comments` — 出力内のコメントを保持します。
* `--quiet` or `-q` — 構文チェックのみを行い、成功時は何も出力しません。
* `--multiquery` or `-n` — 同じファイル内で複数のクエリを許可します。
* `--obfuscate` — フォーマットの代わりに難読化します。
* `--seed <string>` — 難読化の結果を決定する任意の文字列のシードです。
* `--backslash` — フォーマット済みクエリの各行末にバックスラッシュを追加します。Web などから複数行のクエリをコピーしてコマンドラインで実行したい場合に便利です。
* `--semicolons_inline` — マルチクエリモードでは、セミコロンを新しい行ではなくクエリの最終行に記述します。

関数呼び出し、配列またはタプル、`AND`/`OR` の連鎖、ウィンドウ定義、`INSERT` のカラムリストのいずれかが幅に収まらない場合、その要素は改行され、より深いインデントで配置されます。単純な値 (カラム名やリテラル) である関数の引数や配列要素は、1 行に複数まとめて配置されます。フォーマット後の各行がすでに幅に収まっているクエリは変更されません。幅はソフトリミットであり、文字列、識別子、その他の分割できないフラグメントは幅を超えることがあります。Unicode 文字の表示幅も考慮されます。`--comments` によって保持されたコメントや、`INSERT ... VALUES` に続くデータは折り返されません。

## 例 {#examples}

1. クエリをフォーマットする:

```bash title="Query"
$ clickhouse-format --query "select number from numbers(10) where number%2 order by number desc;"
```

```bash title="Response"
SELECT number
FROM numbers(10)
WHERE number % 2
ORDER BY number DESC
```

2. 強調表示と単一行:

```bash title="Query"
$ clickhouse-format --oneline --hilite <<< "SELECT sum(number) FROM numbers(5);"
```

```sql title="Response"
SELECT sum(number) FROM numbers(5)
```

3. 複数クエリ:

```bash title="Query"
$ clickhouse-format -n <<< "SELECT min(number) FROM numbers(5); SELECT max(number) FROM numbers(5);"
```

```sql title="Response"
SELECT min(number)
FROM numbers(5)
;

SELECT max(number)
FROM numbers(5)
;

```

4. 難読化：

```bash title="Query"
$ clickhouse-format --seed Hello --obfuscate <<< "SELECT cost_first_screen BETWEEN a AND b, CASE WHEN x >= 123 THEN y ELSE NULL END;"
```

```sql title="Response"
SELECT treasury_mammoth_hazelnut BETWEEN nutmeg AND span, CASE WHEN chive >= 116 THEN switching ELSE ANYTHING END;
```

同じクエリで、別のシード文字列を使った場合:

```bash title="Query"
$ clickhouse-format --seed World --obfuscate <<< "SELECT cost_first_screen BETWEEN a AND b, CASE WHEN x >= 123 THEN y ELSE NULL END;"
```

```sql title="Response"
SELECT horse_tape_summer BETWEEN folklore AND moccasins, CASE WHEN intestine >= 116 THEN nonconformist ELSE FORESTRY END;
```

5. バックスラッシュを追加:

```bash title="Query"
$ clickhouse-format --backslash <<< "SELECT * FROM (SELECT 1 AS x UNION ALL SELECT 1 UNION DISTINCT SELECT 3);"
```

```sql title="Response"
SELECT * \
FROM  \
( \
    SELECT 1 AS x \
    UNION ALL \
    SELECT 1 \
    UNION DISTINCT \
    SELECT 3 \
)
```

6. 長い式の折り返し:

```bash title="Query"
$ clickhouse-format --wrap_width 40 --query "SELECT concat(first_name, ' ', middle_name, ' ', last_name) FROM people"
```

```sql title="Response"
SELECT
    concat(
        first_name, ' ', middle_name,
        ' ', last_name
    )
FROM people
```
