このページでは、JOIN のセマンティクス、実行計画の作成、実行、およびメモリ使用量に影響する session settings を一覧で紹介します。各設定から [session settings リファレンス](/ja/reference/settings/session-settings) 内の該当エントリにリンクしており、リンク先でデフォルト値と指定可能な値を確認できます。JOIN の構文とセマンティクスについては、[`JOIN` 句リファレンス](/ja/reference/statements/select/join)を参照してください。

## セマンティクスと構文 {#semantics-and-syntax}

| 設定                                                                                                                                                                                     | 説明                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/ja/reference/settings/session-settings/join#join_default_strictness)                                                                                         | strictness が明示されていない JOIN の strictness を設定します。                                                                             |
| [`any_join_distinct_right_table_keys`](/ja/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | `ANY INNER JOIN` および `ANY LEFT JOIN` の従来の動作を有効にします。この動作では、`t1 ANY LEFT JOIN t2` と `t2 ANY RIGHT JOIN t1` が異なる結果を返す場合があります。 |
| [`join_any_take_last_row`](/ja/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | 右テーブルに同じキーに一致する行が複数ある場合に、`ANY` strictness の JOIN が最初の一致行と最後の一致行のどちらを採用するかを選択します。                                           |
| [`join_use_nulls`](/ja/reference/settings/session-settings/join#join_use_nulls)                                                                                                           | 外部 JOIN で一致しなかった行のカラムを、デフォルト値で埋めるか `NULL` で埋めるかを制御します。                                                                     |
| [`semi_join_include_columns_from_both_sides`](/ja/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | `SEMI JOIN` の結果に両方のテーブルのカラムを含めるか、保持される側のテーブルのカラムのみを含めるかを制御します。                                                             |
| [`anti_join_include_columns_from_both_sides`](/ja/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | `ANTI JOIN` の結果に両方のテーブルのカラムを含めるか、保持される側のテーブルのカラムのみを含めるかを制御します。                                                             |
| [`cross_to_inner_join_rewrite`](/ja/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | カンマ区切りのテーブルリスト、または `WHERE` に等価条件を持つ `CROSS JOIN` を `INNER JOIN` に書き換えるかどうかを制御します。                                          |
| [`allow_block_nested_loop_join`](/ja/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | `ON` 部分にテーブル間の等値比較を含まない JOIN を、block nested loop JOIN として実行することを許可します。                                                     |
| [`enable_lateral_join`](/ja/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | 実験的な `LATERAL JOIN` 構文を有効にします。この構文では、JOIN の右側にあるサブクエリから左側のカラムを参照できます。                                                      |
| [`single_join_prefer_left_table`](/ja/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | 単一の JOIN で 2 つのテーブルのどちらを指すか曖昧な識別子を、左テーブルのものとして解決します。                                                                       |
| [`joined_subquery_requires_alias`](/ja/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | JOIN 内のサブクエリおよびテーブル関数にエイリアスの指定を必須にします。                                                                                     |
| [`allow_dynamic_type_in_join_keys`](/ja/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | `Dynamic`型の JOIN キーを許可します。                                                                                                 |
| [`analyzer_compatibility_join_using_top_level_identifier`](/ja/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | `USING` 内の列名を、`SELECT` リスト内のエイリアスなど、クエリ内の同名のエイリアスから解決します。                                                                  |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/ja/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | 2 つ以上の JOIN を含むクエリで、旧アナライザと同様に、結果カラムの名前をテーブル名またはエイリアスで修飾します。                                                               |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/ja/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | 26.6 より前のバージョンと同様に、JOIN の最も左のテーブルに付けられた `FINAL` 修飾子を、結合されるすべてのテーブルに適用します。                                                  |

## アルゴリズムの選択とチューニング {#algorithm-selection-and-tuning}

| 設定                                                                                                                                            | 説明                                                                                                                                         |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| [`join_algorithm`](/ja/reference/settings/session-settings/join#join_algorithm)                                                                  | ClickHouse が使用できる JOIN アルゴリズムを優先順に列挙します。                                                                                                   |

| [`hash_join_layout`](/ja/reference/settings/session-settings/other#hash_join_layout)                                                             | テストおよびデバッグ用に、ハッシュ JOIN において 1 つのスレッドで単一のハッシュテーブルを構築するか、複数のスレッドで分割されたハッシュテーブルを構築するかを強制します。                                                  |
| [`max_threads`](/ja/reference/settings/session-settings/max-threads#max_threads)                                                                 | クエリ処理スレッドの最大数を設定します。分割されたハッシュテーブルを構築するスレッドの数もこの値で制限されます。                                                                                   |
| [`grace_hash_join_initial_buckets`](/ja/reference/settings/session-settings/grace-hash#grace_hash_join_initial_buckets)                          | `grace_hash` JOIN の初期バケット数を設定します。                                                                                                          |
| [`grace_hash_join_max_buckets`](/ja/reference/settings/session-settings/grace-hash#grace_hash_join_max_buckets)                                  | `grace_hash` JOIN のバケット数の上限を設定します。                                                                                                         |
| [`partial_merge_join_rows_in_right_blocks`](/ja/reference/settings/session-settings/partial-merge#partial_merge_join_rows_in_right_blocks)       | `partial_merge` JOIN において、右テーブルの各ソート済みブロックの行数を制限します。                                                                                       |
| [`partial_merge_join_left_table_buffer_bytes`](/ja/reference/settings/session-settings/partial-merge#partial_merge_join_left_table_buffer_bytes) | `partial_merge` JOIN が左テーブルのブロックをより大きなブロックにまとめる際の上限サイズを設定します。                                                                              |
| [`join_on_disk_max_files_to_merge`](/ja/reference/settings/session-settings/join#join_on_disk_max_files_to_merge)                                | マージ JOIN をディスク上で実行する際に、並列でソートされるファイル数を制限します。                                                                                               |
| [`max_rows_in_set_to_optimize_join`](/ja/reference/settings/session-settings/max-rows#max_rows_in_set_to_optimize_join)                          | 結合の前に JOIN の各入力をもう一方の入力のキーでフィルタリングする際に使用する、キー集合の最大サイズを設定します。                                                                               |
| [`query_plan_join_shard_by_pk_ranges`](/ja/reference/settings/session-settings/query-plan#query_plan_join_shard_by_pk_ranges)                    | JOIN キーに両テーブルの主キーのプレフィックスが含まれる場合、2 つの `MergeTree` テーブルの JOIN を主キー範囲ごとの独立した JOIN として実行します。                                                  |
| [`join_output_by_rowlist_perkey_rows_threshold`](/ja/reference/settings/session-settings/join#join_output_by_rowlist_perkey_rows_threshold)      | ハッシュ JOIN が一致を行リストで出力するようになる、右テーブルのキーあたりの平均行数を設定します。                                                                                       |
| [`allow_join_right_table_sorting`](/ja/reference/settings/session-settings/allow#allow_join_right_table_sorting)                                 | `join_to_sort_minimum_perkey_rows` および `join_to_sort_maximum_table_rows` の条件を満たす場合に、`LEFT` または `INNER` ハッシュ JOIN で右テーブルをキー順に並べ替えることを許可します。 |
| [`join_to_sort_minimum_perkey_rows`](/ja/reference/settings/session-settings/join-to#join_to_sort_minimum_perkey_rows)                           | 右テーブルをキー順に並べ替える条件となる、右テーブルのキーあたりの平均行数の最小値を設定します。                                                                                           |
| [`join_to_sort_maximum_table_rows`](/ja/reference/settings/session-settings/join-to#join_to_sort_maximum_table_rows)                             | 右テーブルをキー順に並べ替える条件となる、右テーブルの行数の最大値を設定します。                                                                                                   |
| [`enable_hash_join_row_store`](/ja/reference/settings/session-settings/enable#enable_hash_join_row_store)                                        | ハッシュ JOIN のペイロードを行指向レイアウトに変換する機能を有効にします。                                                                                                   |
| [`min_rows_ratio_for_hash_join_row_store`](/ja/reference/settings/session-settings/min#min_rows_ratio_for_hash_join_row_store)                   | ハッシュ JOIN のペイロードを行指向レイアウトに変換する条件となる、ビルド側の行数に対する出力行数の推定比率の最小値を設定します。                                                                        |
| [`enable_join_fixed_hash_table_conversion`](/ja/reference/settings/session-settings/enable-join#enable_join_fixed_hash_table_conversion)         | キーが値の範囲の狭い単一の整数である場合に、JOIN のハッシュテーブルをフラットな配列に変換する機能を有効にします。                                                                                |
| [`enable_join_key_only_hash_tables`](/ja/reference/settings/session-settings/enable-join#enable_join_key_only_hash_tables)                       | `LEFT ANTI` JOIN、および右テーブルの列を 1 つも選択しない `LEFT SEMI` JOIN において、JOIN キーのみを格納するハッシュテーブルを有効にします。                                                |
| [`enable_software_prefetch_in_join`](/ja/reference/settings/session-settings/enable-software#enable_software_prefetch_in_join)                   | ハッシュ JOIN のプローブフェーズにおけるソフトウェアプリフェッチを有効にします。                                                                                                |
| [`enable_packed_string_keys_in_hash_join`](/ja/reference/settings/session-settings/enable#enable_packed_string_keys_in_hash_join)                | ハッシュテーブル内で各キーを 16 バイトに格納することで、単一の `String` キーによるハッシュ JOIN を高速化し、メモリ使用量を削減します。                                                              |
| [`min_rows_for_packed_string_keys_in_hash_join`](/ja/reference/settings/session-settings/min#min_rows_for_packed_string_keys_in_hash_join)       | 右テーブルの推定行数がこの値を下回る場合、ハッシュ JOIN は packed キーではなく正確な `String` キーを保持します。このしきい値を設定します。                                                          |
| [`collect_hash_table_stats_during_joins`](/ja/reference/settings/session-settings/collect-hash#collect_hash_table_stats_during_joins)            | ハッシュテーブル統計の収集を有効にします。収集された統計は、同じ JOIN の以降の実行時にハッシュテーブルのサイズを決定するために使用されます。                                                                  |
| [`max_size_to_preallocate_for_joins`](/ja/reference/settings/session-settings/max-size#max_size_to_preallocate_for_joins)                        | JOIN のハッシュテーブルで領域を事前割り当てする要素の総数を制限します。                                                                                                     |
| [`max_joined_block_size_rows`](/ja/reference/settings/session-settings/max-joined#max_joined_block_size_rows)                                    | JOIN結果のブロックの行数を制限します。                                                                                                                      |
| [`max_joined_block_size_bytes`](/ja/reference/settings/session-settings/max-joined#max_joined_block_size_bytes)                                  | JOIN結果のブロックのサイズ (バイト単位) を制限します。                                                                                                            |
| [`min_joined_block_size_rows`](/ja/reference/settings/session-settings/min-joined#min_joined_block_size_rows)                                    | JOIN の入力および出力ブロックの行数がこの値を下回る場合、それらをより大きなブロックにまとめます。このしきい値を設定します。                                                                           |
| [`min_joined_block_size_bytes`](/ja/reference/settings/session-settings/min-joined#min_joined_block_size_bytes)                                  | JOIN の入力および出力ブロックのサイズ (バイト単位) がこの値を下回る場合、それらをより大きなブロックにまとめます。このしきい値を設定します。                                                                 |
| [`joined_block_split_single_row`](/ja/reference/settings/session-settings/joined#joined_block_split_single_row)                                  | 左テーブルの 1 行に多数の一致がある場合に、その行に対するハッシュ JOIN の結果を複数のブロックに分割することを許可します。                                                                          |
| [`parallel_non_joined_rows_processing`](/ja/reference/settings/session-settings/parallel#parallel_non_joined_rows_processing)                    | `RIGHT` または `FULL` JOIN において、一致のない右テーブルの行を複数のスレッドで出力することを許可します。                                                                            |
| [`enable_lazy_columns_replication`](/ja/reference/settings/session-settings/enable#enable_lazy_columns_replication)                              | JOIN の結果に含まれるカラムの遅延レプリケーションを有効にします。これにより、同じ行がメモリ上で何度もコピーされるのを防げます。                                                                         |

## クエリプランナー {#query-planner}

| 設定                                                                                                                                                                              | 説明                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| [`query_plan_join_swap_table`](/ja/reference/settings/session-settings/query-plan#query_plan_join_swap_table)                                                                      | プランナーが JOIN のどちらの入力をビルド側として使用するかを制御します。                                                             |

| [`allow_statistics`](/ja/reference/settings/session-settings/allow-statistics#allow_statistics)                                                                                    | 統計を持つカラムの定義と、統計の操作を許可します。                                                                           |
| [`materialize_statistics_on_insert`](/ja/reference/settings/session-settings/materialize-statistics-on-insert#materialize_statistics_on_insert)                                    | 新たに挿入されたパーツに対してカラム統計を構築するかどうかを制御します。                                                                |
| [`use_hash_table_stats_for_join_reordering`](/ja/reference/settings/session-settings/use#use_hash_table_stats_for_join_reordering)                                                 | JOIN の順序変更時のカーディナリティ推定に、収集済みのハッシュテーブル統計を使用できるようにします。                                                |

| [`allow_general_join_planning`](/ja/reference/settings/session-settings/allow#allow_general_join_planning)                                                                         | より複雑な条件を扱える、より汎用的な JOIN 計画アルゴリズムを許可します。ハッシュ JOIN にのみ適用されます。                                         |
| [`query_plan_filter_push_down`](/ja/reference/settings/session-settings/query-plan#query_plan_filter_push_down)                                                                    | クエリ実行計画内でフィルタを下位へ移動できるようにします。JOIN より下への移動も含まれます。                                                    |
| [`query_plan_convert_outer_join_to_inner_join`](/ja/reference/settings/session-settings/query-plan#query_plan_convert_outer_join_to_inner_join)                                    | JOIN 後のフィルタが、一致しなかった行のデフォルト値を常に除外する場合に、`OUTER JOIN` を `INNER JOIN` に変換できるようにします。                    |
| [`query_plan_convert_outer_join_to_inner_join_transitively`](/ja/reference/settings/session-settings/query-plan#query_plan_convert_outer_join_to_inner_join_transitively)          | `query_plan_convert_outer_join_to_inner_join` の適用範囲を、実行計画のさらに上位にあるフィルタや、外側の JOIN の条件にまで拡張します。       |
| [`query_plan_convert_any_join_to_semi_or_anti_join`](/ja/reference/settings/session-settings/query-plan#query_plan_convert_any_join_to_semi_or_anti_join)                          | JOIN 後のフィルタが、一致しなかった行または一致した行のいずれかを常に除外する場合に、`ANY JOIN` を `SEMI JOIN` または `ANTI JOIN` に変換できるようにします。 |
| [`query_plan_convert_join_to_in`](/ja/reference/settings/session-settings/query-plan#query_plan_convert_join_to_in)                                                                | 出力カラムが左テーブルのみに由来する場合に、JOIN を `IN` を用いたサブクエリに変換できるようにします。                                            |
| [`rewrite_in_to_join`](/ja/reference/settings/session-settings/rewrite#rewrite_in_to_join)                                                                                         | `x IN subquery` 形式の式を JOIN に書き換えます。                                                                 |

| [`query_plan_merge_expression_into_join`](/ja/reference/settings/session-settings/query-plan#query_plan_merge_expression_into_join)                                                | JOIN の順序変更時に、式を JOIN ステップにマージできるようにします。                                                             |
| [`query_plan_short_circuit_constant_false_join`](/ja/reference/settings/session-settings/query-plan#query_plan_short_circuit_constant_false_join)                                  | `ON` 条件が定数 false に畳み込まれる場合に、行を出力し得ない JOIN の各入力を空のソースに置き換えます。                                        |
| [`query_plan_read_in_order_through_join`](/ja/reference/settings/session-settings/query-plan#query_plan_read_in_order_through_join)                                                | JOIN をまたいでも左テーブルを順序通りに読み取り続け、後続のステップがその順序を利用できるようにします。                                              |
| [`query_plan_top_k_through_join`](/ja/reference/settings/session-settings/query-plan#query_plan_top_k_through_join)                                                                | ソートキーが保持される側のカラムのみを参照する場合に、`ORDER BY ... LIMIT n` を `LEFT` または `RIGHT` JOIN の下へプッシュダウンします。          |

| [`query_plan_min_columns_for_join_lazy_indexing`](/ja/reference/settings/session-settings/query-plan#query_plan_min_columns_for_join_lazy_indexing)                                | JOIN の遅延索引最適化を適用する、左側のペイロードカラム数の下限を設定します。                                                           |
| [`enable_join_runtime_filters`](/ja/reference/settings/session-settings/enable-join#enable_join_runtime_filters)                                                                   | 実行時にビルド側から収集した JOIN キーの集合を用いて、JOIN のプローブ側をフィルタリングできるようにします。                                         |
| [`enable_join_runtime_filters_index_analysis`](/ja/reference/settings/session-settings/enable-join#enable_join_runtime_filters_index_analysis)                                     | ランタイムフィルタを用いて、JOIN のプローブ側のグラニュールを除外できるようにします。                                                       |

| [`join_runtime_bloom_filter_bytes`](/ja/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_bytes)                                                          | JOINランタイムフィルタとして使用するブルームフィルタのサイズをバイト単位で設定します。                                                       |
| [`join_runtime_bloom_filter_hash_functions`](/ja/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_hash_functions)                                        | JOINランタイムフィルタとして使用するブルームフィルタのハッシュ関数の数を設定します。                                                        |
| [`join_runtime_bloom_filter_max_ratio_of_set_bits`](/ja/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_max_ratio_of_set_bits)                          | 1 に設定されたビットの比率のしきい値を設定します。この値を超えると、ランタイムのブルームフィルタが無効化されます。                                          |
| [`join_runtime_filter_from_fixed_hash_table`](/ja/reference/settings/session-settings/join-runtime#join_runtime_filter_from_fixed_hash_table)                                      | フラットな配列に変換されたハッシュテーブルを、そのまま JOINランタイムフィルタとして使用します。                                                  |
| [`join_runtime_filter_size_from_hash_table_stats`](/ja/reference/settings/session-settings/join-runtime#join_runtime_filter_size_from_hash_table_stats)                            | 過去の実行で収集されたハッシュテーブルの統計情報に基づいて、JOINランタイムフィルタのサイズを決定します。                                              |
| [`join_runtime_filter_min_probe_rows`](/ja/reference/settings/session-settings/join-runtime#join_runtime_filter_min_probe_rows)                                                    | プローブ側の推定行数のしきい値を設定します。推定行数がこの値以下の場合、JOINランタイムフィルタは作成されません。                                          |
| [`join_runtime_filter_pass_ratio_threshold_for_disabling`](/ja/reference/settings/session-settings/join-runtime#join_runtime_filter_pass_ratio_threshold_for_disabling)            | チェックした行に対する通過した行の比率のしきい値を設定します。この値を超えると、JOINランタイムフィルタが一時的に無効化されます。                                  |
| [`join_runtime_filter_blocks_to_skip_before_reenabling`](/ja/reference/settings/session-settings/join-runtime#join_runtime_filter_blocks_to_skip_before_reenabling)                | 一時的に無効化された JOINランタイムフィルタを再試行するまでのブロック数を設定します。                                                       |
| [`correlated_subqueries_default_join_kind`](/ja/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_default_join_kind)                                 | `LATERAL JOIN` を含む相関サブクエリを非相関化したプランで、`LEFT` JOIN と `RIGHT` JOIN のどちらを使用するかを制御します。                   |
| [`correlated_subqueries_substitute_equivalent_expressions`](/ja/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_substitute_equivalent_expressions) | 相関サブクエリを非相関化する際に、`CROSS JOIN` を作成する代わりに、フィルタから導出した同等の式で置き換えることを許可します。                               |
| [`correlated_subqueries_use_in_memory_buffer`](/ja/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_use_in_memory_buffer)                           | `LATERAL JOIN` を含む相関サブクエリの入力にインメモリバッファを使用し、入力の繰り返し評価を回避します。                                         |

| [`max_bytes_before_external_sort`](/ja/reference/settings/session-settings/max-bytes#max_bytes_before_external_sort)                 | ソート処理 (`full_sorting_merge` JOIN のソートを含む) がディスクへのスピルを開始するメモリ使用量を設定します。                               |
| [`max_bytes_ratio_before_external_sort`](/ja/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_sort)     | ソート処理 (`full_sorting_merge` JOIN のソートを含む) がディスクへのスピルを開始する、利用可能なメモリに対する比率を設定します。                      |

| [`cross_join_min_bytes_to_compress`](/ja/reference/settings/session-settings/cross-join#cross_join_min_bytes_to_compress)            | `CROSS JOIN` または block nested loop JOIN のブロックをメモリ内で圧縮するサイズをバイト単位で設定します。                              |
| [`temporary_files_codec`](/ja/reference/settings/session-settings/temporary-files#temporary_files_codec)                             | ソートおよび JOIN 演算がディスクに書き込む一時ファイルの圧縮コーデックを設定します。                                                        |

| [`max_bytes_to_transfer`](/ja/reference/settings/session-settings/max-bytes#max_bytes_to_transfer)                                                                   | `GLOBAL IN` または `GLOBAL JOIN` がリモートサーバーに渡す、または一時テーブルに保存するデータの非圧縮バイト数を制限します。       |

| [`distributed_plan_max_rows_to_broadcast`](/ja/reference/settings/session-settings/distributed-plan#distributed_plan_max_rows_to_broadcast)                          | ルールベースの分散プランナーが shuffle JOIN ではなくブロードキャスト JOIN を使用する行数の上限を設定します。                  |
