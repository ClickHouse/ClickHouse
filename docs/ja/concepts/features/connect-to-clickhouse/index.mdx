ClickHouse の利用方法に最も適したインターフェイスを選択してください。アプリケーション開発には、まず公式の言語別クライアントまたはドライバーを利用することをお勧めします。対話的な作業には、ネイティブツールまたは Web ベースのツールが適しています。直接連携する場合は、ネットワークプロトコルを使用してください。接続する前に、必要に応じて[ネットワークポート](/ja/concepts/features/security/network-ports)、[アクセス権](/ja/concepts/features/security/access-rights)、[TLS](/ja/concepts/features/security/tls/configuring-tls)を設定してください。

## ネイティブツール {#native-tools}

<CardGroup cols={2}>
  <Card title="clickhousectl" icon="terminal" href="/ja/concepts/features/connect-to-clickhouse/native-tools/clickhousectl">
    公式の ClickHouse CLI (`chctl`)。ローカルでの ClickHouse および Postgres の開発と、ClickHouse Cloud管理に対応しています。
  </Card>

  <Card title="ClickHouse クライアント" icon="keyboard" href="/ja/concepts/features/connect-to-clickhouse/native-tools/clickhouse-client">
    コマンドラインオプションと設定ファイルに対応したネイティブのコマンドラインクライアントです。
  </Card>

  <Card title="ウェブターミナル" icon="globe" href="/ja/concepts/features/connect-to-clickhouse/native-tools/web-terminal">
    WebSocket 経由でブラウザ上から利用できる `clickhouse-client` session です。
  </Card>

  <Card title="Model Context Protocol (MCP)" icon="/images/mcp.svg" href="/ja/concepts/features/connect-to-clickhouse/native-tools/mcp">
    標準化されたインターフェイスを通じて、AIアシスタントを ClickHouse に接続できます。
  </Card>
</CardGroup>
