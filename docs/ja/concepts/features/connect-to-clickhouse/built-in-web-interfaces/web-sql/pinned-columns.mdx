組み込みの Web SQL UI (`play.html`。任意の ClickHouse HTTP ポートの [`/play`](/ja/concepts/features/connect-to-clickhouse/protocols/http) パスで提供されます) では、テーブルの残りの部分を横方向にスクロールしても、結果のうち選択したカラムを表示したままにしておけます。ピン留めされたカラムはスクロールしても画面外に流れず、結果エリアの手前側の端に固定されます。そのため、識別子、名前、日付といったキー列を、右端のほうで参照しているカラムと並べて常に表示しておけます。

## カラムの固定 {#pinning-a-column}

すべての列ヘッダーの左側には 📌 プッシュピンアイコンが表示されます。クリックするとカラムが固定され、もう一度クリックすると固定が解除されます。このアイコンは実際のボタンとして実装されているため、キーボードユーザーも Tab キーでフォーカスを移動し、キーボード操作でトグルを切り替えられます。また、固定状態は支援技術にも通知されます。

ホバー可能なポインター (マウス) を備えたデバイスでは、アイコンはヘッダーにホバーしている間、またはトグルにフォーカスがある間のみ表示されるため、それ以外のときは操作の邪魔になりません。ホバー操作のないタッチデバイスやその他の粗いポインターのデバイスでは、直接タップできるようアイコンが常に表示されます。ピン留めされたカラムでは、固定中であることを示すインジケーターとして、アイコンが常にはっきりと表示されます。

## 固定が利用可能になる条件 {#when-pinning-is-available}

固定は、テーブルが横スクロールが必要なほど幅広い場合にのみ利用できます。テーブル全体がビューポートに収まる場合は、スクロールで隠れる列がないため、固定トグルは無効になり、キーボードのタブ順序からも除外されます。列数の多い結果、狭いウィンドウ、横方向に拡大していくストリーミング結果などによって結果が横スクロール可能になると、その時点でトグルが有効になります。

## スクロール時のピン留めされたカラムの動作 {#how-a-pinned-column-behaves-when-scrolling}

ピン留めされたカラムは、水平スクロール中はコンテンツと一緒に移動しますが、ビューポートの外に出そうになった時点で近い側の端 (左側のカラムは左端、右側のカラムは右端) に固定され、表示されたままになります。ピン留めされたカラムが複数ある場合は、元の順序のまま端に沿って並んで固定され、それぞれスクロールするコンテンツとは境界線で区切られます。ピン留めされたセルは、その下をスクロールする通常のセル (選択中のセルを含む) よりも前面に描画されるため、常に内容を読み取れます。

## 結果内での共有 {#shared-across-a-result}

固定は列名単位で管理され、1つの結果に属する結果テーブル間で共有されます。`Run all`(複数クエリ)で実行するとステートメントごとに1つずつテーブルがレンダリングされますが、それらはすべて同じピン留めのセットを共有します。これは、カラムごとの[色分けモード](/ja/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/color-coding)と同じ仕組みです。これらのテーブルのいずれかで `id` という名前のカラムを固定すると、他のテーブルでも `id` という名前のカラムが固定されたままになります。同じカラムを返す同一クエリを以降に実行した場合も同様です。

ピン留めのセットは、固定対象の結果に属します。つまり、クエリタブ単位で保持され、タブが[ノートブック](/ja/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook)の場合は個々のセル単位で保持されます。そのため、あるセルでカラムを固定しても、他のセルや他のタブの固定には影響せず、それぞれ独立した固定が維持されます。

## 永続化 {#persistence}

ピン留めのセットは、ページの URL、ブラウザの履歴、およびそのセットが属するセルの結果スナップショットに記録されます。そのため、ページを再読み込みしても、リンクを共有しても、ブラウザで戻る・進むの操作をしても、ピン留めは保持されます。現在エディタが開かれていないセルでピン留めを切り替えた場合も、そのセルの保存済みコピーが更新されるため、再読み込み後も状態が維持されます。データ量を抑えるため、保存されるのはピン留めされたカラムのみです。ピン留めのセットが空集合の場合、URL や履歴の状態には何も追加されません。

## 制限事項 {#limitations}

* 縦方向 (転置) の単一行レイアウトには横スクロールするカラムがないため、固定機能は利用できません。
