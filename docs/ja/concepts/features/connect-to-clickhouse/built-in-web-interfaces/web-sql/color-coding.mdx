組み込みの Web SQL UI (`play.html`。任意の ClickHouse HTTP ポートの [`/play`](/ja/concepts/features/connect-to-clickhouse/protocols/http) パスで提供) では、結果のセルに色を付けて、カラム内のパターンを一目で把握しやすくできます。色分けモードはカラムごとに個別に切り替えられます。

## モードの切り替え {#switching-the-mode}

各列ヘッダーの右端には 🌈 アイコンが表示されます。このアイコンをクリックすると、そのカラムで利用可能なモードが順番に循環して切り替わります。ホバー操作が可能なポインター (マウス) を備えたデバイスでは、アイコンはヘッダーにカーソルを合わせている間だけ表示されるため、普段は表示の妨げになりません。一方、タッチデバイスなどホバー操作ができない粗いポインターのデバイスでは、アイコンを直接タップできるよう常に表示されます。

カラムで利用できるモードは、カラムの型によって異なります。

* 数値カラムおよび `Date`/`DateTime`/`Date32`/`DateTime64` カラムでは、`bar` → `heatmap` → `categorical` → `none` の順に切り替わります。
* その他のカラムでは、`none` と `categorical` が交互に切り替わります。

デフォルトのモードは、数値カラムでは `bar`、日付と時刻のカラムを含むその他すべてのカラムでは `none` です。

## モード {#modes}

* **`bar`** — 値に比例した水平の棒グラフをセル内に描画します。数値カラムでは棒はゼロのベースラインから伸びます。`Date`/`DateTime` カラムでは、タイムスタンプに対してゼロのベースラインは意味をなさないため、代わりにカラムの `min`..`max` の範囲に合わせて描画されます。
* **`heatmap`** — カラムの最小値と最大値の間でスケーリングした値を色で表し、セルの背景全体を塗りつぶします。
* **`categorical`** — セルの値のハッシュから導出した色でセルの背景を塗りつぶします。そのため、同じ値には同じ色が、異なる値には異なる色が割り当てられます。どの列の型でも使用できます。
* **`none`** — 色分けを行いません。

`Date`、`DateTime`、`Date32`、`DateTime64` カラムは時刻の値に基づいて色付けされます。値は UTC でパースされるため、スケールは閲覧者のブラウザのタイムゾーンに左右されません。

`heatmap` と `categorical` の背景色は `oklch` 色空間を使用し、テーマごとに明度と彩度を固定したまま色相のみを変化させます。これにより、ライトテーマとダークテーマのどちらでもセルのテキストの読みやすさが保たれます。行が複数行にまたがる場合でも、背景はセル全体に塗りつぶされます。

## 選択時のカテゴリ別強調表示 {#categorical-emphasis}

`categorical` モードでは、セルを選択すると、同じ値を持つ他のセルが強調表示され、太字のフォントと最大コントラストの文字色 (ダークテーマでは純白、ライトテーマでは純黒) で表示されます。選択したセル自体は強調表示されません。これにより、特定の値がカラム内のほかにどこに出現しているかをひと目で確認できます。

## 永続化 {#persistence}

選択したモードはカラムごとにページの URL とブラウザの履歴に記録されるため、ページの再読み込み、リンクの共有、ブラウザの「戻る」「進む」による移動を行っても保持されます。URL と履歴のステートをコンパクトに保つため、保存されるのはデフォルト以外の選択のみです。

[ピン留めされたカラム](/ja/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/pinned-columns)と同様に、モードは色付けの対象となる結果に紐づきます。つまり、クエリタブ単位で保持され、そのタブが[ノートブック](/ja/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook)の場合は個々のセル単位で保持されます。1 回の `Run all` (複数クエリ) の実行で生成されるテーブルはモードを共有しますが、他のセルや他のタブはそれぞれ独自のモードを保持します。

## 制限事項 {#limitations}

* 縦方向 (転置) の単一行レイアウトでは、色分けは表示されません。
* `DateTime64(9)` における1マイクロ秒未満の差分は、カラースケール上では区別されません。この程度の差分はグラデーションとして表示しても視覚的に意味をなさないためです。
