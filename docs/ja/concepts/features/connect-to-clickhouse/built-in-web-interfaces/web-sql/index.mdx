Web SQL UI (Play) は、ClickHouse に組み込まれたブラウザー内クエリインターフェイスです。任意の ClickHouse HTTP ポートの `/play` パスで提供されます (例: `http://localhost:8123/play`)。クエリを作成して実行し、結果をテーブルまたはチャートで表示できるほか、URL をコピーしてクエリを共有することもできます。

インターフェイス全体は `programs/server/play.html` に収められています。これは ClickHouse バイナリから直接提供される単一の自己完結型ページで、フレームワークやビルド工程は不要です。唯一の例外はチャートのレンダリングです。`uPlot` チャートライブラリは、結果を初めてチャートとして表示する際に third-party の CDN から遅延読み込みされます。そのため、オフライン環境やエグレスが制限されたデプロイメントでは、チャートは使用不可となります。

## クエリタブ {#query-tabs}

タブを使えば、1 つのエディタで複数のクエリを切り替えながら扱ったり、ブラウザの履歴に頼ったりすることなく、複数のクエリを並べて管理できます。

各タブは、それぞれ独自のクエリテキスト、タイトル、クエリパラメータ、直近の結果を保持します。接続設定 (URL、ユーザー、パスワード) はグローバルに適用され、すべてのタブで共有されます。

### タブバーが表示されるタイミング {#when-the-tab-bar-appears}

タブバーは、クエリを実行した時点、またはタブが複数になった時点で表示されます。結果のないタブが 1 つだけの状態では、タブ機能が導入される前とまったく同じ見た目になるため、必要になるまでタブバーは表示されません。

アクティブなタブは、ページと視覚的に一体化して表示されます。背景色はクエリごとのハッシュカラー (ページ背景で使用されているのと同じ色) に連動し、ライトテーマでは上部ほど彩度が高く、ダークテーマでは上部ほど明るくなるグラデーションが適用されます。非アクティブなタブは、それぞれのクエリテキストのハッシュに基づいて色付けされるため、タブごとに色で自動的に区別されます。

### タブの作成、クローズ、名前の変更 {#creating-closing-and-renaming-tabs}

* タブの右側にある `[+]` ボタンで新しいタブを作成します。
* タブ上の `x` アイコンでタブを閉じます。
* 新しいタブには `Query A`、`Query B` といったデフォルト名が付きます。
* アクティブなタブのタイトルをクリックすると、その場で編集できます。編集フィールドは入力したテキストに合わせて広がります。

### タブの切り替え {#switching-tabs}

* 非アクティブなタブをクリックすると、そのタブに切り替わります。
* タブパネル上でマウスホイールをスクロールしてもタブを切り替えられます。上にスクロールすると左のタブへ、下にスクロールすると右のタブへ移動します (該当するタブがある場合) 。ホイールによる縦方向・横方向のスクロールのどちらにも対応しています。

タブバーは水平方向に追従固定されます。ページを横方向にスクロールしても、下部の ClickHouse ロゴと同様に左端に固定されたままです。一方、縦方向にはページの他の部分と一緒にスクロールします。

### 永続化とブラウザ履歴 {#persistence-and-browser-history}

ワークスペース (タブ、各タブのタイトル、アクティブなタブ、タブの並び順、および小さな結果スナップショット) は IndexedDB に永続化され、再読み込み時に復元されます。永続化はベストエフォートで行われます。IndexedDB が使用不可の場合、ワークスペースは現在のセッション内でのみ有効なメモリ内の状態にフォールバックします。

タブはブラウザの History API および URL とも連携します。

* 履歴の状態にはアクティブなタブが保持されるため、ブラウザの「戻る」ボタンと「進む」ボタンでタブを切り替えられます。
* URL には `tab=<name>` パラメータが付加されます。読み込み時には、URL のクエリと `tab` パラメータが保存済みのタブとリコンサイルされます。その名前のタブが既に存在する場合はそのタブが再利用され (クエリは置き換えられます) 、名前が見つからない場合や名前が付いていない場合は新しいタブが作成されます。これにより、自分の保存済みタブを残したまま、新しいクエリを含む URL を開くことができます。

## ノートブックモード {#notebook-mode}

結果の下に表示される `[+]` ボタンでセルを追加すると、タブをノートブック (クエリセルとテキストセルを順に並べたもの) に切り替えられます。ノートブックモードはタブ単位で適用されます。詳しくは
[ウェブUIのノートブックモード](/ja/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook)を参照してください。

### 制限事項 {#limitations}

クエリは、そのタブから別のタブに切り替えても実行され続けます。進捗メーターとリソースメーターはバックグラウンドで
加算され続け、タブを再度開くと実行中の状態がそのまま引き継がれます。そのため、メーターはゼロ付近から
やり直すことなく、現在の値から継続します。一方、タブを閉じた場合や、ブラウザーの戻る・進むで別の履歴エントリへ
移動した場合は、クエリが停止します。

復元用のスナップショットが作成されるのは、小さな結果のみです。大きな結果 (スナップショットのサイズ上限を超えるもの) や画像の結果は永続化されません。タブの切り替えや再読み込みの後もタブにクエリは保持されますが、レンダリング済みの結果は保持されません。結果はクエリを再実行すると再現できます。これは、単一クエリの結果と、「すべて実行」 (複数クエリ) で実行した場合の統合出力の両方に当てはまります。
