ClickHouse は、自身のメトリクスを Prometheus のテキストフォーマットで専用ポートに公開しており、Prometheus サーバーからスクレイプできます。

Prometheus のメトリクスを ClickHouse に保存して PromQL でクエリしたい場合は、[Prometheus HTTP API と PromQL](/ja/concepts/features/connect-to-clickhouse/prometheus) を参照してください。

<Note>
  ClickHouse Cloud をご利用の場合は、[Prometheus 連携](/ja/products/cloud/features/monitoring/prometheus)を使用して、メトリクスを Prometheus に公開できます。
</Note>

## メトリクスポートを設定する {#configure-the-metrics-port}

Prometheus サーバーで ClickHouse 自体のメトリクスをスクレイプする場合は、専用ポートを設定します。

```xml
<prometheus>
    <port>9363</port>
    <endpoint>/metrics</endpoint>
    <metrics>true</metrics>
    <asynchronous_metrics>true</asynchronous_metrics>
    <events>true</events>
    <errors>true</errors>
    <histograms>true</histograms>
    <dimensional_metrics>true</dimensional_metrics>
</prometheus>
```

## 拡張ハンドラーの設定 {#configure-extended-handlers}

`<prometheus.handlers>` セクションを使用すると、同じポート上にさらに拡張されたハンドラーを作成できます。
このセクションは [`<http_handlers>`](/ja/concepts/features/connect-to-clickhouse/protocols/http) と同様ですが、Prometheusプロトコル向けに機能します。

```xml
<prometheus>
    <port>9363</port>
    <handlers>
        <my_rule_1>
            <url>/metrics</url>
            <handler>
                <type>expose_metrics</type>
                <metrics>true</metrics>
                <asynchronous_metrics>true</asynchronous_metrics>
                <events>true</events>
                <errors>true</errors>
                <histograms>true</histograms>
                <dimensional_metrics>true</dimensional_metrics>
                <labels>
                    <environment>production</environment>
                    <shard from_env="SHARD_NAME"></shard>
                </labels>
            </handler>
        </my_rule_1>
    </handlers>
</prometheus>
```

## 設定 {#settings}

これらの設定の動作の詳細については、サーバー設定リファレンスの [Prometheus セクション](/ja/reference/settings/server-settings/settings/other#prometheus) を参照してください。

| 名前                           | デフォルト      | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `port`                       | none       | ClickHouse のメトリクスを提供するポート。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `endpoint`                   | `/metrics` | メトリクスのスクレイピング用の HTTP エンドポイント。`/` で始まります。`<handlers>` セクションと併用しないでください。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `url` / `headers` / `method` | none       | リクエストに一致するハンドラーを特定するためのフィルタ。[`<http_handlers>`](/ja/concepts/features/connect-to-clickhouse/protocols/http) セクションにある同名のフィールドと同様です。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `info`                       | true       | サーバーのアイデンティティを表すラベル (`name`、`version`、`version_describe`、`version_major`、`version_minor`、`version_patch`) を持つ `ClickHouse_Info` ゲージを公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `metrics`                    | true       | [`system.metrics`](/ja/reference/system-tables/metrics) のメトリクスを公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `asynchronous_metrics`       | true       | [`system.asynchronous_metrics`](/ja/reference/system-tables/asynchronous_metrics) のメトリクスを公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `events`                     | true       | [`system.events`](/ja/reference/system-tables/events) のメトリクスを公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `errors`                     | true       | [`system.errors`](/ja/reference/system-tables/errors) のエラー発生回数を公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `histograms`                 | true       | [`system.histogram_metrics`](/ja/reference/system-tables/histogram_metrics) のメトリクスを公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `dimensional_metrics`        | true       | [`system.dimensional_metrics`](/ja/reference/system-tables/dimensional_metrics) のメトリクスを公開します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `labels`                     | none       | 公開されるすべてのメトリクスに付与される固定ラベル。各子要素が 1 つのラベルを定義し、要素名がラベル名 (`[a-zA-Z_][a-zA-Z0-9_]*` に一致する必要があります)、要素の値がラベルの値になります。ラベルの値では、`from_env` 属性などの標準的な設定の置換を使用できます。ラベル名が `__` で始まる場合 (Prometheus により予約済み)、またはこのエンドポイントが有効なセクションのいずれかに対してすでに出力しているラベルと衝突する場合、そのラベル名は拒否されます。したがって、予約されるラベル名はエンドポイントが実際にエクスポートする内容によって決まります。具体的には、`histograms` が有効な場合は `le`、`info` が有効な場合は `ClickHouse_Info` のラベル (`name`、`version`、`version_describe`、`version_major`、`version_minor`、`version_patch`)、`histograms` または `dimensional_metrics` が有効な場合は、公開されるヒストグラムまたはディメンショナルメトリクスのメトリクスファミリーで使用されるすべてのラベル (例: `group`、`direction`、`operation_type`) が該当します。このようにエンドポイントが実際に公開する内容に依存するため、同じ名前でも、あるエンドポイントでは有効で、別のエンドポイントでは拒否される場合があります。 |

## エンドポイントを確認する {#check-the-endpoint}

```bash
curl http://127.0.0.1:9363/metrics
```
