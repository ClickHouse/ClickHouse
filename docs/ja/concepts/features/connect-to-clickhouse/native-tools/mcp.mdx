[Model Context Protocol](https://www.anthropic.com/news/model-context-protocol) (MCP) は、AIアシスタントが外部システムに接続できるようにするオープン標準です。
モデルがデータソース、API、データベース、ツールにアクセスするための共通のインターフェイスを提供するため、モデルとサービスの組み合わせごとに個別のインテグレーションを開発する必要がありません。

AIアプリケーションは、MCPを一度実装するだけで、互換性のある任意のサーバーに接続できます。
同様に、MCPサーバーは、互換性のある任意のクライアントに機能を公開できます。

## アーキテクチャ {#architecture}

MCPはクライアントサーバーアーキテクチャを採用しています。

* Claude Desktop、Cursor、VS CodeなどのMCPクライアントは、MCPサーバーとの接続を確立します。
* MCPサーバーは、標準化されたインターフェイスを通じてツールや機能を公開します。
* AIモデルは、公開されたツールを使用して、必要に応じて外部のデータや機能にアクセスします。

プロジェクトの決定事項をセッション間で引き継ぎ、保存した知見を索引化されたコードに関連付けます。

## ClickHouse MCP サーバー {#clickhouse-mcp-server}

[ClickHouse MCP サーバー](https://github.com/ClickHouse/mcp-clickhouse)を使用すると、AIアシスタントがデータベースやテーブルを検出し、スキーマを確認し、ClickHouse クラスターに対してSQLクエリを実行できます。
サーバーが公開するツールはバージョンによって異なる場合があるため、サンプルで使用するツール名については、対応するインテグレーションガイドを参照してください。

このサーバーでは、デフォルトで読み取り専用のクエリが許可されています。
アシスタントに必要なアクセス許可のみを付与した専用の ClickHouse ユーザーを使用してください。

ローカルのMCPクライアントを接続するには、[ClickHouse MCP サーバーのセットアップ](/ja/guides/use-cases/ai-ml/MCP/claude-desktop)を参照してください。
マネージドのリモートサーバーについては、[ClickHouse Cloudのリモート MCP サーバー](/ja/products/cloud/features/ai-ml/remote-mcp)を参照してください。
