> このガイドでは、[Jan.ai](https://jan.ai/docs) で ClickHouse MCP サーバーを使用する方法を説明します。

<Steps>
  <Step title="Jan.ai をインストールする" id="install-janai">
    Jan.ai は、完全にオフラインで動作するオープンソースの ChatGPT 代替アプリです。
    Jan.ai は [Mac](https://jan.ai/docs/desktop/install/mac)、[Windows](https://jan.ai/docs/desktop/windows)、[Linux](https://jan.ai/docs/desktop/linux) 向けにダウンロードできます。

    ネイティブアプリなので、ダウンロードが完了すればすぐに起動できます。
  </Step>

  <Step title="Jan.ai に LLM を追加する" id="add-llm-to-janai">
    モデルは設定メニューから有効化できます。

    OpenAI を有効化するには、次のように APIキーを入力する必要があります。

    <div className="ch-image-md">
      <Frame>
        ![OpenAI モデルを有効化する](/images/use-cases/AI_ML/MCP/0_janai_openai.webp)
      </Frame>
    </div>
  </Step>

  <Step title="MCPサーバーを有効化する" id="enable-mcp-servers">
    本記事の執筆時点では、MCPサーバーは Jan.ai の実験的機能です。
    実験的機能のトグルをオンにすると有効化できます。

    <div className="ch-image-md">
      <Frame>
        ![MCPサーバーを有効化する](/images/use-cases/AI_ML/MCP/1_janai_mcp_servers.webp)
      </Frame>
    </div>

    トグルをオンにすると、左側のメニューに `MCP servers` が表示されます。
  </Step>

  <Step title="ClickHouse MCP サーバーを設定する" id="configure-clickhouse-mcp-server">
    `MCP servers` メニューをクリックすると、接続可能な MCPサーバーの一覧が表示されます。

    <div className="ch-image-md">
      <Frame>
        ![MCPサーバーの一覧](/images/use-cases/AI_ML/MCP/2_janai_mcp_servers_list.webp)
      </Frame>
    </div>

    これらのサーバーはデフォルトではすべて無効になっていますが、トグルをクリックすると有効化できます。

    ClickHouse MCP サーバーをインストールするには、`+` アイコンをクリックし、フォームに次の内容を入力します。

    <div className="ch-image-md">
      <Frame>
        ![MCPサーバーを追加する](/images/use-cases/AI_ML/MCP/3_janai_add_mcp_server.webp)
      </Frame>
    </div>

    入力が完了したら、ClickHouse Server のトグルがオフになっている場合はオンにします。

    <div className="ch-image-md">
      <Frame>
        ![MCPサーバーを有効化する](/images/use-cases/AI_ML/MCP/4_janai_toggle.webp)
      </Frame>
    </div>

    これで、ClickHouse MCP サーバーのツールがチャットダイアログに表示されます。

    <div className="ch-image-md">
      <Frame>
        ![ClickHouse MCP サーバーのツール](/images/use-cases/AI_ML/MCP/5_jani_tools.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Jan.ai で ClickHouse MCP サーバーとチャットする" id="chat-to-clickhouse-mcp-server">
    それでは、ClickHouse に保存されているデータについて会話してみましょう。
    まずは質問をしてみます。

    <div className="ch-image-md">
      <Frame>
        ![質問](/images/use-cases/AI_ML/MCP/6_janai_question.webp)
      </Frame>
    </div>

    Jan.ai はツールを呼び出す前に確認を求めてきます。

    <div className="ch-image-md">
      <Frame>
        ![ツールの確認](/images/use-cases/AI_ML/MCP/7_janai_tool_confirmation.webp)
      </Frame>
    </div>

    続いて、実行されたツール呼び出しの一覧が表示されます。

    <div className="ch-image-md">
      <Frame>
        ![呼び出されたツール](/images/use-cases/AI_ML/MCP/8_janai_tools_called.webp)
      </Frame>
    </div>

    ツール呼び出しをクリックすると、その詳細を確認できます。

    <div className="ch-image-md">
      <Frame>
        ![呼び出されたツール（展開表示）](/images/use-cases/AI_ML/MCP/9_janai_tools_called_expanded.webp)
      </Frame>
    </div>

    その下に結果が表示されます。

    <div className="ch-image-md">
      <Frame>
        ![結果](/images/use-cases/AI_ML/MCP/10_janai_result.webp)
      </Frame>
    </div>
  </Step>
</Steps>
