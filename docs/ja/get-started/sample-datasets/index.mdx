ClickHouseの使い始め方や仕組みの理解に役立つ、さまざまな資料を用意しています。

* 何もインストールせずにClickHouseを試すには、無料の[ClickHouse Cloudトライアル](https://clickhouse.cloud/signUp?loc=docs-get-started-sample-datasets)に登録するか、読み取り専用の[ClickHouse playground](/ja/get-started/sample-datasets/playground)でクエリを実行できます。
* ClickHouseを自分で運用したい場合は、[クイックスタート](/ja/get-started/setup/install)に従ってください。
* 学習をどこから始めるか迷ったら、ニューヨーク市のタクシー乗車データセットを分析する[ニューヨークのタクシーデータ](/ja/get-started/sample-datasets/nyc-taxi)チュートリアルを試すか、以下のチュートリアルから選んでください。
