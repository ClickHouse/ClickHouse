## 基地局データセットによる地理空間分析 {#geospatial-analysis-with-cell-towers}

このガイドでは、`OpenCelliD` の基地局データを `ClickHouse Cloud` に読み込み、国名の辞書で拡張し、ドイツ内の基地局を検索して `ClickHouse Agents` で可視化します。

<Steps>
  <Step title="サンプルデータを読み込む">
    `ClickHouse Cloud` で **Load data** を開き、**Sample data** の **Cell Towers** を読み込みます。`cell_towers` の各行は基地局であり、`lon` と `lat` はその座標です。

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="クエリと拡張を行う">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;

    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="地理データを使う">
    `ClickHouse` の [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon) を使います。`germany` を作成し、[英語版ガイド](/get-started/sample-datasets/cell-towers#germany-polygon) のドイツ本土の輪郭を挿入します。

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    結果は約 `2.62 million` です。
  </Step>
  <Step title="任意: ClickHouse Agents で可視化する">
    これは任意の実行例です。`ClickHouse Agents` はモデル駆動のベータ機能であるため、計画、使用するツール、出力は実行ごとに異なる場合があります。**ClickHouse agents** を開き、"Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables" と送信します。

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="ドイツの基地局密度グリッドを作成する ClickHouse Agent のチャット"/>

    ある実行では、エージェントがドイツの MCC を調べ、基地局を数え、`0.1°` グリッドに集計して輪郭を地図に描きました。

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="ドイツの基地局密度ヒートマップ"/>
  </Step>
</Steps>
