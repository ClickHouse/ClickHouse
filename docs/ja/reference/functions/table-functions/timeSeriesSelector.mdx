セレクタで絞り込み、指定した interval 内のタイムスタンプを持つ TimeSeries テーブルから時系列を読み取ります。
この関数は [range selectors](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors) に似ていますが、[インスタントセレクタ](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors) の実装にも使用されます。

## 構文 {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## 引数 {#arguments}

* `db_name` - TimeSeriesテーブルが存在するデータベースの名前。
* `time_series_table` - TimeSeriesテーブルの名前。
* `instant_query` - `@` または `offset` 修飾子を含まない、[PromQL構文](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors)で記述されたインスタントセレクタ。
* `min_time` - 開始タイムスタンプ (この値を含む) 。
* `max_time` - 終了タイムスタンプ (この値を含む) 。
* `return_columns` - サンプルを返す際のカラム構成。`'samples'` または `'timestamp_and_value'` のいずれかを指定します (詳細は後述) 。

テーブル内のタイムスタンプが整数秒であっても、`min_time` と `max_time` には秒未満の値を指定できます。
この関数は、境界値をタイムスタンプの型に丸めることなく、`min_time <= timestamp <= max_time` を厳密に満たすサンプルを選択します。

## 戻り値 {#returned-value}

この関数は、指定されたセレクターに一致する時系列の識別子を格納したカラム `id` と、引数 `return_columns` で選択したカラムに格納されたサンプルを返します。

* `'samples'` - 時系列のサンプルを、タイムスタンプでソート済みの `(timestamp, value)` のタプルの配列として格納するカラム `samples`。
  1 つの時系列のサンプルが複数の行に分かれて返される場合があります (たとえば、サンプルテーブルの時間バケットごとに 1 行) 。
  時系列の行をマージするには、集約関数 `timeSeriesGroupArray` を使用してください。
* `'timestamp_and_value'` - 1 行につき 1 つのサンプルを格納するカラム `timestamp` と `value`。

バージョン 11 以降の `TimeSeries` テーブルはサンプルのバケットを配列として格納し、それより前のバージョンのテーブルは 1 行につき 1 つのサンプルを格納します。
要求したカラムがテーブルのレイアウトと異なる場合はサンプルの変換が行われ、その分の時間がかかります。PromQL 関数は、テーブルのレイアウトに一致するカラムをリクエストします。

返されるデータの順序は保証されません。

## 例 {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
