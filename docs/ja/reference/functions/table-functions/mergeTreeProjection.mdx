MergeTree テーブル内のPROJECTIONの内容を表します。内部情報の確認に使用できます。

## 構文 {#syntax}

```sql
mergeTreeProjection(database, table, projection)
```

## 引数 {#arguments}

| 引数           | 説明                         |
| ------------ | -------------------------- |
| `database`   | PROJECTION の読み取り元のデータベース名。 |
| `table`      | PROJECTION の読み取り元のテーブル名。   |
| `projection` | 読み取る PROJECTION の名前。       |

`DESCRIBE` などで結果の構造を取得するにはソーステーブルに対する `SHOW COLUMNS` 権限が、結果を読み取るにはソーステーブルに対する `SELECT` 権限が必要です。

## 戻り値 {#returned-value}

指定されたPROJECTIONが提供するカラムを含むテーブルオブジェクト。

## 使用例 {#usage-example}

```sql
CREATE TABLE test
(
    `user_id` UInt64,
    `item_id` UInt64,
    PROJECTION order_by_item_id
    (
        SELECT _part_offset
        ORDER BY item_id
    )
)
ENGINE = MergeTree
ORDER BY user_id;

INSERT INTO test SELECT number, 100 - number FROM numbers(5);
```

```sql
SELECT *, _part_offset FROM mergeTreeProjection(currentDatabase(), test, order_by_item_id);
```

```text
   ┌─item_id─┬─_parent_part_offset─┬─_part_offset─┐
1. │      96 │                   4 │            0 │
2. │      97 │                   3 │            1 │
3. │      98 │                   2 │            2 │
4. │      99 │                   1 │            3 │
5. │     100 │                   0 │            4 │
   └─────────┴─────────────────────┴──────────────┘
```

```sql
DESCRIBE mergeTreeProjection(currentDatabase(), test, order_by_item_id) SETTINGS describe_compact_output = 1;
```

```text
   ┌─name────────────────┬─type───┐
1. │ item_id             │ UInt64 │
2. │ _parent_part_offset │ UInt64 │
   └─────────────────────┴────────┘
```
