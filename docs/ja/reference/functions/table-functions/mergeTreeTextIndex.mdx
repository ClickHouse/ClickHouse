MergeTree テーブルのテキスト索引の Dictionary を表します。
トークンとそのポスティングリストメタデータを返します。
イントロスペクションに利用できます。

## 構文 {#syntax}

```sql
mergeTreeTextIndex(database, table, index_name)
```

## 引数 {#arguments}

| 引数           | 説明                    |
| ------------ | --------------------- |
| `database`   | テキスト索引を読み取る元のデータベース名。 |
| `table`      | テキスト索引を読み取る元のテーブル名。   |
| `index_name` | 読み取るテキスト索引の名前。        |

## 戻り値 {#returned-value}

トークンとそれに対応するポスティングリストメタデータを含むテーブルオブジェクト。

索引で `keyValuePairs` トークナイザーを使用している場合、各トークンは `Map` カラムの `(key, value)` ペアであり、結果にはトークンをデコードした各部分を格納する `token_key` と `token_value` の2つのカラムが追加されます。

トークンのポスティングリストは、以下の仮想カラムで返されます。これらは `SELECT *` では返されないため、明示的に指定して選択する必要があります。

| カラム         | 型               | 説明                                                                  |
| ----------- | --------------- | ------------------------------------------------------------------- |
| `row_id`    | `UInt32`        | トークンのポスティングリストに含まれる、データパーツ内の行番号 (`_part_offset` を参照) 。              |
| `positions` | `Array(UInt32)` | 行内におけるトークンの位置。索引に引数 `support_phrase_search = 1` が指定されている場合にのみ存在します。 |

これらのカラムのいずれかを選択すると、ポスティングリストに `ARRAY JOIN` を適用した場合と同様に、各トークンのポスティングリストに含まれる行ごとに1行が出力され、トークンのその他のカラムの値は各行で繰り返されます。

ポスティングリストはデータパーツの索引に保存されている状態のまま返されるため、パーツがマージされるまでは、論理削除によって削除された行 (`_row_exists` を参照) も含まれます。

## 使用例 {#usage-example}

```sql title="Query"
CREATE TABLE tab
(
    id UInt64,
    s String,
    INDEX idx_s (s) TYPE text(tokenizer = splitByNonAlpha)
)
ENGINE = MergeTree
ORDER BY id;

INSERT INTO tab SELECT number, concatWithSeparator(' ', 'apple', 'banana') FROM numbers(500);
INSERT INTO tab SELECT 500 + number, concatWithSeparator(' ', 'cherry', 'date') FROM numbers(500);

SELECT * FROM mergeTreeTextIndex(currentDatabase(), tab, idx_s);
```

## 使用例：ポスティングリスト {#usage-example-posting-lists}

```sql title="Query"
CREATE TABLE tab
(
    id UInt64,
    s String,
    INDEX idx_s (s) TYPE text(tokenizer = splitByNonAlpha, support_phrase_search = 1)
)
ENGINE = MergeTree
ORDER BY id
SETTINGS allow_experimental_text_index_phrase_search = 1;

INSERT INTO tab VALUES (0, 'apple banana apple'), (1, 'banana cherry'), (2, 'cherry apple');

SELECT token, row_id, positions FROM mergeTreeTextIndex(currentDatabase(), tab, idx_s) ORDER BY token, row_id;
```

```text title="Response"
   ┌─token──┬─row_id─┬─positions─┐
1. │ apple  │      0 │ [0,2]     │
2. │ apple  │      2 │ [1]       │
3. │ banana │      0 │ [1]       │
4. │ banana │      1 │ [0]       │
5. │ cherry │      1 │ [1]       │
6. │ cherry │      2 │ [0]       │
   └────────┴────────┴───────────┘
```
