一時的な[Merge](/ja/reference/engines/table-engines/special/merge)テーブルを作成します。
テーブルスキーマは、基になるテーブルのカラムのユニオンを使用し、共通の型を導出して決定されます。
[Merge](/ja/reference/engines/table-engines/special/merge)テーブルエンジンと同じ仮想カラムを使用できます。

## 構文 {#syntax}

```sql
merge(['db_name',] 'tables_regexp')
```

## 引数 {#arguments}

| 引数              | 説明                                                                                                                                                                                        |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | 設定可能な値 (省略可。デフォルトは `currentDatabase()`) :<br />    - データベース名<br />    - データベース名の文字列を返す定数式 (例: `currentDatabase()`) <br />    - `REGEXP(expression)`。ここで `expression` は DB 名にマッチさせるための正規表現 |
| `tables_regexp` | 指定した DB 内のテーブル名、または指定した複数の DB 内のテーブル名にマッチさせるための正規表現です。                                                                                                                                    |

## アクセス権 {#access-rights}

一致したテーブルは、[Merge](/ja/reference/engines/table-engines/special/merge#access-rights) テーブルエンジンと同じアクセスルールに従って読み取られます。データは、一致したテーブルのうち現在のユーザーが参照できるテーブル、つまり [`SHOW TABLES`](/ja/reference/statements/grant#show) 権限を持つテーブルからのみ読み取られ、テーブルスキーマもそれらのテーブルのみから導出されます。一致したテーブルのうちユーザーが参照できないものは、エラーにならずにスキップされます。スキーマを導出するには、導出元のテーブルに対する [`SHOW COLUMNS`](/ja/reference/statements/grant#show) 権限が必要です。ユーザーが参照できる一致したテーブルを読み取るには、クエリが読み取るカラムに対する [`SELECT`](/ja/reference/statements/grant#select) 権限が必要です。この権限がない場合、クエリは `ACCESS_DENIED` で失敗します。
