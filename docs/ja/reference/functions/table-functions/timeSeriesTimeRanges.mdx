`timeSeriesTimeRanges(db_name.time_series_table)` - テーブルエンジンに [TimeSeries](/ja/reference/engines/table-engines/integrations/time-series) エンジンを使用するテーブル `db_name.time_series_table` が使用する
[時間範囲](/ja/reference/engines/table-engines/integrations/time-series#time-ranges-table)テーブルを返します。例：

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

次のクエリは同等です。

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  *時間範囲*テーブルは、`store_time_ranges` 設定が有効な場合にのみ存在します。
  [バージョン](/ja/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 以前のテーブルでは、`min_time` カラムと `max_time` カラムは
  [タグ](/ja/reference/engines/table-engines/integrations/time-series#tags-table)テーブルに保持されます。
</Note>
