<div id="bitmapAnd">
  ## bitmapAnd
</div>

導入バージョン: v20.1.0

2 つの bitmap の論理積 (AND) を計算します。

**構文**

```sql
bitmapAnd(bitmap1, bitmap2)
```

**引数**

* `bitmap1` — 最初のビットマップオブジェクト。[`AggregateFunction(groupBitmap, T)`](/ja/reference/data-types/aggregatefunction)。 - `bitmap2` — 2 番目のビットマップオブジェクト。[`AggregateFunction(groupBitmap, T)`](/ja/reference/data-types/aggregatefunction)。

**戻り値**

両方の入力ビットマップに共通して存在するビットを含むビットマップを返します [`AggregateFunction(groupBitmap, T)`](/ja/reference/data-types/aggregatefunction)

**例**

**使用例**

```sql title=Query
SELECT bitmapToArray(bitmapAnd(bitmapBuild([1, 2, 3]), bitmapBuild([3, 4, 5]))) AS res;
```

```response title=Response
┌─res─┐
│ [3] │
└─────┘
```

ビットマップに指定された値が含まれている場合は `1`、それ以外は `0` を返します [`UInt8`](/ja/reference/data-types/int-uint)

**例**

**使用例**

```sql title=Query
SELECT bitmapContains(bitmapBuild([1, 2, 3]), 2) AS res;
```

```response title=Response
┌─res─┐
│   1 │
└─────┘
```

**符号付きビットマップ**


<div id="bitmapTransform">
  ## bitmapTransform
</div>

導入バージョン: v20.1.0

`from_array` から `to_array` へのマッピングに従って、ビットマップ 内の要素を置き換えます。
値は ビットマップ 要素型の符号なし整数として解釈されます ([`bitmapContains`](/ja/reference/functions/regular-functions/bitmap-functions#bitmapContains) と同じドメイン) 。
符号付き ビットマップ では、負の要素は対応する符号なしの要素と一致します (たとえば、`Int8` 値の `-1` は `255` と一致します) 。
`to_array` 内の値が ビットマップ 要素型に収まらない場合は、`BAD_ARGUMENTS` が送出されます。`from_array` 内の値が
収まらない場合は単に見つからないため、対応する置換は適用されません。

**構文**

```sql
bitmapTransform(bitmap, from_array, to_array)
```

**引数**

* `bitmap` — ビットマップオブジェクト。 [`AggregateFunction(groupBitmap, T)`](/ja/reference/data-types/aggregatefunction). - `from_array` — 置き換える元のセットビットの Array。 [`Array(T)`](/ja/reference/data-types/array). - `to_array` — 置き換え先となる新しいセットビットの Array。 [`Array(T)`](/ja/reference/data-types/array).

**戻り値**

指定されたマッピングに従って要素が変換されたビットマップを返します。[`AggregateFunction(groupBitmap, T)`](/ja/reference/data-types/aggregatefunction)

**例**

**使用例**

```sql title=Query
SELECT bitmapToArray(bitmapTransform(bitmapBuild([1, 2, 3, 4, 5]), [2, 4], [20, 40])) AS res;
```

```response title=Response
┌─res───────────┐
│ [1,3,5,20,40] │
└───────────────┘
```

**符号付きビットマップ**

```sql title=Query
SELECT arraySort(bitmapToArray(bitmapTransform(bitmapBuild([-1, 0]::Array(Int8)), [255], [10]))) AS res;
```

```response title=Response
┌─res────┐
│ [0,10] │
└────────┘
```
