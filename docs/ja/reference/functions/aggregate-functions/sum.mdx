## sum {#sum}

導入バージョン: v1.1.0

数値またはインターバルの合計を計算します。

**構文**

```sql
sum(num)
```

**引数**

* `num` — 数値型の値またはインターバルを含むカラム。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float) または [`Decimal*`](/ja/reference/data-types/decimal) または [`Interval`](/ja/reference/data-types/special-data-types/interval)

**戻り値**

値の合計を返します。引数が `Interval` 型の場合、結果は同じ単位のインターバルとなり、入力が空の場合は長さ 0 のインターバルを返します。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float) または [`Decimal*`](/ja/reference/data-types/decimal) または [`Interval`](/ja/reference/data-types/special-data-types/interval)

**例**

**従業員の給与の合計を計算する**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**リクエストの処理に要した合計時間**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
