<div id="gini">
  ## gini
</div>

導入バージョン: v26.8.0

有限かつ非負の数値カラムの[ジニ係数](https://en.wikipedia.org/wiki/Gini_coefficient)を計算します。ジニ係数は、分布における不平等度を表す指標です。

結果は、`0` (完全な平等: すべての値が同じ) から、`n` の増加に伴って `1` に近づく最大値 (完全な不平等: 1 つの値がすべてを占め、残りはゼロ) までの範囲になります。`n` 個の値からなる有限サンプルの場合、最大値は `(n - 1) / n` です。

渡されたすべての値は入力型のまま収集され、数値的に安定した最終計算を行う前にソートされます。係数は、正規化された隣接ペア間の差分から計算され、`Float64` として返されるため、`Float64` の精度に丸められます。したがって、この関数は `O(n)` のメモリを消費します。ここで、`n` は渡された値の数です。`NaN` 値はスキップされ、無限大および負の値は受け付けられません。

**構文**

```sql
gini(expr)
```

**引数**

* `expr` — 有限かつ非負の数値を返す式。[`(U)Int*`](/ja/reference/data-types/int-uint)、[`Float*`](/ja/reference/data-types/float)、または [`Decimal`](/ja/reference/data-types/decimal)

**戻り値**

ジニ係数。値が 2 つ未満の場合、または値の合計が 0 の場合は `NaN`。[`Float64`](/ja/reference/data-types/float)

**例**

**等しい値**

```sql title=Query
SELECT gini(x) FROM (SELECT 100 AS x FROM numbers(10));
```

```response title=Response
┌─gini(x)─┐
│       0 │
└─────────┘
```

**偏った分布**

```sql title=Query
SELECT gini(x) FROM (SELECT number AS x FROM numbers(10));
```

```response title=Response
┌─────────────gini(x)─┐
│ 0.36666666666666664 │
└─────────────────────┘
```
