## avg {#avg}

導入バージョン: v1.1.0

算術平均を計算します。

**構文**

```sql
avg(x)
```

**引数**

* `x` — 入力値。[`(U)Int*`](/ja/reference/data-types/int-uint)、[`Float*`](/ja/reference/data-types/float)、[`Decimal`](/ja/reference/data-types/decimal)、[`Date`](/ja/reference/data-types/date)、[`Date32`](/ja/reference/data-types/date32)、[`DateTime`](/ja/reference/data-types/datetime)、[`DateTime64(P)`](/ja/reference/data-types/datetime64)、[`Time`](/ja/reference/data-types/time)、[`Time64(P)`](/ja/reference/data-types/time64)、または [`Interval`](/ja/reference/data-types/special-data-types/interval)

**戻り値**

算術平均を返します。`x` が数値型の場合、結果は `Float64` となり、`x` が空の場合は `NaN` を返します。`x` が日付型、時刻型、またはインターバル型の場合、結果は `x` と同じ型になります。平均値は表現可能な最も近い値に丸められ、`x` が空の場合はその型のゼロ値を返します。[`Float64`](/ja/reference/data-types/float)、[`Date`](/ja/reference/data-types/date)、[`Date32`](/ja/reference/data-types/date32)、[`DateTime`](/ja/reference/data-types/datetime)、[`DateTime64(P)`](/ja/reference/data-types/datetime64)、[`Time`](/ja/reference/data-types/time)、[`Time64(P)`](/ja/reference/data-types/time64)、または [`Interval`](/ja/reference/data-types/special-data-types/interval)

**例**

**基本的な使い方**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**空のテーブルでは NaN が返されます**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**インターバルの平均**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
