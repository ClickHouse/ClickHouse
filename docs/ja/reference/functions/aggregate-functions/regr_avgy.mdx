## regr_avgy {#regr_avgy}

導入バージョン: v26.9.0

従属変数の平均を返します。

平均はゼロではなくデータ内のある値を基準として計算されます。そのため、2^53 を超える整数カラムでは、
`Float64` の合計値を除算する [`avg`](/ja/reference/functions/aggregate-functions/avg) よりも、
正確な平均に近い値が得られる場合があります。

**構文**

```sql
regr_avgy(y, x)
```

**別名**: `regrAvgY`

**引数**

* `y` — 従属変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)
* `x` — 独立変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)

**戻り値**

`y` の平均値を返します。[`Float64`](/ja/reference/data-types/float)

**例**

**基本的な使い方**

```sql title=Query
SELECT regr_avgy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgy(y, x)─┐
│               5 │
└─────────────────┘
```
