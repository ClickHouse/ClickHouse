## regr_avgx {#regr_avgx}

導入バージョン: v26.9.0

独立変数の平均を返します。

ゼロではなくデータ中の値を基準として計算されるため、2^53 を超える整数カラムでは、
`Float64` の合計を除算する [`avg`](/ja/reference/functions/aggregate-functions/avg) よりも厳密な平均値に近い結果が得られる場合があります。

**構文**

```sql
regr_avgx(y, x)
```

**別名**: `regrAvgX`

**引数**

* `y` — 従属変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)
* `x` — 独立変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)

**戻り値**

`x` の平均値を返します。[`Float64`](/ja/reference/data-types/float)

**例**

**基本的な使い方**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
