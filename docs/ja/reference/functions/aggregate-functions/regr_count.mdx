## regr_count {#regr_count}

導入バージョン: v26.9.0

`y` と `x` のどちらも `NULL` でない行の数をカウントします。

**構文**

```sql
regr_count(y, x)
```

**別名**: `regrCount`

**引数**

* `y` — 従属変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)
* `x` — 独立変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)

**戻り値**

非 NULL のペアの数を返します。[`UInt64`](/ja/reference/data-types/int-uint)

**例**

**基本的な使い方**

```sql title=Query
SELECT regr_count(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_count(y, x)─┐
│                4 │
└──────────────────┘
```
