<div id="timeSeriesDerivToGrid">
  ## timeSeriesDerivToGrid
</div>

導入バージョン: v25.6.0

時系列データをタイムスタンプと値の組として受け取り、開始タイムスタンプ、終了タイムスタンプ、step で表される一定間隔の時間グリッド上で、このデータから [PromQL ライクな微分](https://prometheus.io/docs/prometheus/latest/querying/functions/#deriv) を計算する集約関数です。グリッド上の各点について、`deriv` の計算に使用するサンプルは指定された時間ウィンドウ内のものが考慮されます。

複数のサンプルが同じタイムスタンプを持つ場合、使用されるのは値が最大のサンプル1つだけです。NaN 値は他のすべての値より優先度が低いため、このタイムスタンプのすべてのサンプルが NaN の場合にのみ NaN 値が使用されます。

<Note>
  この関数は実験的機能です。`allow_experimental_time_series_aggregate_functions=true` を設定して有効にしてください。
</Note>

**構文**

```sql
timeSeriesDerivToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
```

**パラメータ**

* `start_timestamp` — グリッドの開始位置を指定します。`DateTime64` 型の timestamp 引数の場合、小数値、数値または日時を表すテキストを含む文字列も指定できます。[`UInt32`](/ja/reference/data-types/int-uint) または [`DateTime`](/ja/reference/data-types/datetime) または [`DateTime64`](/ja/reference/data-types/datetime64) または [`Float*`](/ja/reference/data-types/float) または [`Decimal*`](/ja/reference/data-types/decimal) または [`String`](/ja/reference/data-types/string)
* `end_timestamp` — グリッドの終了位置を指定します。`DateTime64` 型の timestamp 引数の場合、小数値、数値または日時を表すテキストを含む文字列も指定できます。[`UInt32`](/ja/reference/data-types/int-uint) または [`DateTime`](/ja/reference/data-types/datetime) または [`DateTime64`](/ja/reference/data-types/datetime64) または [`Float*`](/ja/reference/data-types/float) または [`Decimal*`](/ja/reference/data-types/decimal) または [`String`](/ja/reference/data-types/string)
* `grid_step` — グリッドの刻み幅を秒単位で指定します。`DateTime64` 型の timestamp 引数の場合、小数値、数値、または &#39;15s&#39; や &#39;1m&#39; のような期間を表す文字列も指定できます。[`UInt32`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float) または [`Decimal*`](/ja/reference/data-types/decimal) または [`String`](/ja/reference/data-types/string)
* `staleness` — 対象とするサンプルの最大 &quot;staleness&quot; を秒単位で指定します。staleness ウィンドウは左開右閉区間です。`DateTime64` 型の timestamp 引数の場合、小数値、数値、または &#39;15s&#39; や &#39;1m&#39; のような期間を表す文字列も指定できます。[`UInt32`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float) または [`Decimal*`](/ja/reference/data-types/decimal) または [`String`](/ja/reference/data-types/string)

**引数**

* `timestamp` — サンプルのタイムスタンプ。単一の値または配列を指定できます。 - `value` — `timestamp` に対応する時系列の値。単一の値または配列を指定できます。

**戻り値**

指定したグリッド上の `deriv` の値を `Array(Nullable(Float64))` として返します。返される配列には時間グリッド上の各点に対して1つの値が含まれます。特定のグリッド点について微分値を計算するのにウィンドウ内のサンプル数が不足している場合、その値は NULL になります。

**例**

**グリッド [90, 105, 120, 135, 150, 165, 180, 195, 210] 上の微分値を計算する**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,0,0.1,0.11,0.1,NULL,NULL,0.15]                                               │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

**配列引数を使った同じクエリ**

```sql title=Query
SET allow_experimental_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesDerivToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,0,0.1,0.11,0.1,NULL,NULL,0.15]                                                 │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```
