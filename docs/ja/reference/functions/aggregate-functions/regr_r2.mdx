## regr_r2 {#regr_r2}

導入バージョン: v26.9.0

最小二乗法による回帰の決定係数、すなわち相関係数の二乗を返します。
`x` が定数の場合は `nan` を、`y` が定数の場合は `1` を返します。

**構文**

```sql
regr_r2(y, x)
```

**別名**: `regrR2`

**引数**

* `y` — 従属変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)
* `x` — 独立変数。[`(U)Int*`](/ja/reference/data-types/int-uint) または [`Float*`](/ja/reference/data-types/float)

**戻り値**

0 以上 1 以下の値を返します。[`Float64`](/ja/reference/data-types/float)

**例**

**基本的な使い方**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
