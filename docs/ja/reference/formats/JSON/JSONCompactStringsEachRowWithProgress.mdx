## 説明 {#description}

[`JSONCompactEachRowWithProgress`](/ja/reference/formats/JSON/JSONCompactEachRowWithProgress) と同様ですが、すべての値が文字列に変換されます。トップレベルのオブジェクト種別 (`meta`、`row`、`progress`、`totals`、`min`/`max`、`rows_before_limit_at_least`、`rows_before_aggregation`、およびトップレベルの `exception`) も同じものを使用します。`row` / `totals` / `min` / `max` のペイロードは引き続きカラム順の **Array** で、各要素は文字列としてシリアル化されます。

ストリームオブジェクトの仕様の詳細については、[`JSONCompactEachRowWithProgress`](/ja/reference/formats/JSON/JSONCompactEachRowWithProgress) を参照してください (`progress` は `meta` より先に届く場合があります。`rows_before_limit_at_least` はクエリに `LIMIT` が含まれる場合の下限の推定値であり、行が除外されたことを示すものではありません。`exception` は HTTP 経由で `http_write_exception_in_output_format=1` が指定されている場合にのみ出力されます) 。

## 使用例 {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
