## 説明 {#description}

`JSONEachRow`/`JSONStringsEachRow` との違いは、ClickHouse が各イベントを個別の JSON オブジェクトとしてストリーミングし、進捗情報もあわせて出力する点です。

すべてのフィールド値は (複合型を含め) 文字列としてシリアル化されます。たとえば `arr` は、ネストされたJSON配列ではなく `"arr":"[0,1]"` として出力されます。スカラー値も同様に文字列化されます (`"num":"42"`) 。

トップレベルのオブジェクトの種類は [`JSONEachRowWithProgress`](/ja/reference/formats/JSON/JSONEachRowWithProgress) と同じです (`meta`、`row`、`progress`、`totals`/`min`/`max`、`rows_before_limit_at_least`、`rows_before_aggregation`、およびトップレベルの `exception`) 。ストリームの仕様の詳細については、同ページを参照してください。`progress` オブジェクトは `meta` より先に届く場合があります。`rows_before_limit_at_least` は、クエリに `LIMIT` が含まれる場合の下限の推定値です (行が実際に除外されたことを意味するものではありません) 。`exception` は、HTTP 経由で `http_write_exception_in_output_format=1` が指定されている場合にのみ書き込まれます。

## 使用例 {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
