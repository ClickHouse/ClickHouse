<div id="description">
  ## 説明
</div>

`MySQLWire` フォーマットは、クエリ結果を MySQL ワイヤプロトコルの結果セットとしてシリアル化します。カラム数と
カラム定義を書き込んだ後、結果の各行に対してプロトコル行パケットを 1 つずつ書き込み、最後に `EOF` または `OK` パケットを書き込みます。行
パケットでは、通常のクエリにはテキストプロトコルを、プリペアドステートメントにはバイナリプロトコルを使用します。

これは出力専用のバイナリフォーマットであり、ClickHouse の
[MySQL インターフェイス](/ja/concepts/features/interfaces/mysql)を介して接続するクライアント向けです。インターフェイスは `MySQLWire` を自動的に選択し、
クライアントの capabilities やパケットシーケンス番号などのプロトコル状態を提供します。スタンドアロンファイルとしてクエリ結果を表示または
保存する用途を意図したものではありません。

<div id="example-usage">
  ## 使用例
</div>

MySQL インターフェイスを有効にした後、互換性のあるクライアントでクエリを実行します。

```shell
mysql --protocol tcp -h 127.0.0.1 -u default -P 9004 default \
    -e "SELECT number, number * 2 AS doubled FROM numbers(3)"
```

インターフェイスは結果を `MySQLWire` で送信します。`FORMAT MySQLWire` 句を明示的に指定する必要はありません。その他の明示的な
出力フォーマットは、MySQL インターフェイスではサポートされていません。

<div id="format-settings">
  ## フォーマット設定
</div>

ユーザーが構成できるフォーマット設定はありません。MySQL インターフェイスは、クライアントの
ハンドシェイクと実行するコマンドに基づいて、必要な設定を決定します。
