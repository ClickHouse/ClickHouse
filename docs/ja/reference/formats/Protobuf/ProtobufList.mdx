## 説明 {#description}

`ProtobufList`フォーマットは、複数の行を`Envelope`という名前の1つの長さ区切り[Protocol Buffers](/ja/reference/formats/Protobuf/Protobuf)メッセージにまとめます。各行は、フィールド番号1のサブメッセージとしてエンコードされます。

## 使用例 {#example-usage}

次のスキーマを `schemafile.proto` として保存します。このスキーマを使用する Protobuf デコーダがエンベロープ内のすべての行を読み取れるように、`row` フィールドを `repeated` として宣言します。

```capnp title="schemafile.proto"
syntax = "proto3";
message Envelope {
  message MessageType {
    string name = 1;
  }
  repeated MessageType row = 1;
}
```

同じディレクトリで次のコマンドを実行し、ファイルに 2 行を書き込んでから読み出します。

```bash
clickhouse local --query "SELECT name FROM values('name String', 'Ada', 'Grace') ORDER BY name
    SETTINGS format_schema = 'schemafile:MessageType' FORMAT ProtobufList" > people.bin

clickhouse local --structure 'name String' --input-format ProtobufList \
    --format_schema 'schemafile:MessageType' --query 'SELECT name FROM table' < people.bin
```

```text
Ada
Grace
```

`format_schema` で指定されたメッセージ型は、まず最上位の `Envelope` メッセージ内のネストされた型として解決されます。そこで一致するものが見つからない場合 — スキーマに `Envelope` メッセージが存在しないか、`Envelope` に指定された名前のメッセージが含まれていない場合 — その名前を持つ最上位メッセージが直接使用されます。
