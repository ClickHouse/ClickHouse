## 説明 {#description}

各値を、指定したカラム名とともに別々の行に出力します。このフォーマットは、各行が多数のカラムで構成されている場合に、1 行または数行だけを出力するのに便利です。

文字列値 `NULL` と値が存在しない状態を区別しやすくするため、[`NULL`](/ja/reference/syntax) は `ᴺᵁᴸᴸ` として出力される点に注意してください。JSON カラムは整形して出力され、`NULL` は `null` として出力されます。これは、`null` が有効な JSON 値であり、`"null"` と容易に区別できるためです。

## 使用例 {#example-usage}

例:

```sql
SELECT * FROM t_null FORMAT Vertical
```

```response
Row 1:
──────
x: 1
y: ᴺᵁᴸᴸ
```

デフォルトでは、値およびカラム名に含まれる印字不可能な制御文字 (C0 制御文字 `0x00`–`0x1F` および `DEL` `0x7F`) は、対応する Unicode の &quot;Control Pictures&quot; (`U+2400`–`U+2421`) として表示されます。これにより、制御文字が端末で暗黙的に消えてしまうことなく、目に見える状態で保たれます。たとえば、NUL は `␀` として表示されます。

```sql
SELECT 'string with a NUL \0 character' AS test FORMAT Vertical
```

```response
Row 1:
──────
test: string with a NUL ␀ character
```

`TAB`、改行、`ESC` は例外です。端末はこれらを無視せずに解釈するため、常にそのまま出力されます。タブは次のタブ位置まで進め、改行は行を区切り、ANSI エスケープシーケンスはデータに可視化を持たせる役割を果たします。ただし、カラム名はこの例外のさらに例外です。カラム名は 1 行で表示されるため、名前に含まれる改行は他の制御文字と同様に置換されます。

制御文字を置換せずにそのまま出力するには、[`output_format_pretty_display_control_characters`](/ja/reference/settings/formats#output_format_pretty_display_control_characters) を無効にします：

```sql
SELECT 'string with a NUL \0 character' AS test
FORMAT Vertical
SETTINGS output_format_pretty_display_control_characters = 0
```

この場合、レスポンスには代わりに生の `NUL` バイトがそのまま含まれます。端末はこのバイトを表示しないため、値は
その文字が単に欠落しているかのように見えます。

このフォーマットはクエリ結果の出力にのみ適しており、パース (テーブルに挿入するデータの取得) には適していません。
