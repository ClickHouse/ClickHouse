## 説明 {#description}

[Vortex](https://vortex.dev/) は、Apache Arrow 互換の圧縮済みデータ向けの拡張可能な列指向ファイルフォーマットで、
高速なスキャンとランダムアクセスを目的として設計されています。ClickHouse は Vortex ファイルの読み取りと書き込みに対応しています。

## データ型の対応 {#data-types-matching-vortex}

次の表は、`INSERT` クエリおよび `SELECT` クエリにおける Vortex のデータ型と、それに対応する ClickHouse の[データ型](/ja/reference/data-types/index)を示しています。

| Vortex データ型 (`INSERT`) | ClickHouse データ型                                                                           | Vortex データ型 (`SELECT`)                                             |
| ---------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `Bool`                 | [Bool](/ja/reference/data-types/boolean)                                                     | `Bool`                                                             |
| `I8`, `U8`             | [Int8/UInt8](/ja/reference/data-types/int-uint)                                              | `I8`, `U8`                                                         |
| `I16`, `U16`           | [Int16/UInt16](/ja/reference/data-types/int-uint)                                            | `I16`, `U16`                                                       |
| `I32`, `U32`           | [Int32/UInt32](/ja/reference/data-types/int-uint)                                            | `I32`, `U32`                                                       |
| `I64`, `U64`           | [Int64/UInt64](/ja/reference/data-types/int-uint)                                            | `I64`, `U64`                                                       |
| `F32`                  | [Float32](/ja/reference/data-types/float)                                                    | `F32`                                                              |
| `F64`                  | [Float64](/ja/reference/data-types/float)                                                    | `F64`                                                              |
| `Utf8`, `Binary`       | [String](/ja/reference/data-types/string)                                                    | `Utf8` (`output_format_vortex_string_as_string = 0` の場合は `Binary`) |
| `Binary`               | [FixedString](/ja/reference/data-types/fixedstring)                                          | `Binary`                                                           |
| `Decimal`              | [Decimal](/ja/reference/data-types/decimal)                                                  | `Decimal`                                                          |
| `vortex.date`          | [Date32](/ja/reference/data-types/date32)                                                    | `vortex.date`                                                      |
| `vortex.timestamp`     | [DateTime](/ja/reference/data-types/datetime)/[DateTime64](/ja/reference/data-types/datetime64) | `vortex.timestamp`                                                 |
| `vortex.time`          | [Time64](/ja/reference/data-types/time64)                                                    | `vortex.time`                                                      |
| `List`                 | [Array](/ja/reference/data-types/array)                                                      | `List`                                                             |
| `Struct`               | [Tuple](/ja/reference/data-types/tuple)                                                      | `Struct`                                                           |
| `Null`                 | [Nullable(Nothing)](/ja/reference/data-types/special-data-types/nothing)                     | `Null`                                                             |

その他の型はサポートされていません。特に、[Map](/ja/reference/data-types/map)、
[Int128/UInt128/Int256/UInt256](/ja/reference/data-types/int-uint)、[IPv6](/ja/reference/data-types/ipv6)、
[Interval](/ja/reference/data-types/special-data-types/interval) のカラムは Vortex ファイルに書き込めません。
[String](/ja/reference/data-types/string) カラムは `Utf8` として書き込まれます。Vortex では `Binary` よりも
`Utf8` のほうが効率よく圧縮されます。Vortex は `Utf8` の値が有効なUTF-8であることを要求しますが、ClickHouse の文字列は任意の
バイト列であるため、有効なUTF-8ではない値を書き込むと例外がスローされます。
`output_format_vortex_string_as_string = 0` を指定すると、文字列は代わりに `Binary` として書き込まれます。Vortex には
固定長のバイナリ型がないため、[FixedString](/ja/reference/data-types/fixedstring) は常に `Binary` として書き込まれ、
スキーマ推論では [String](/ja/reference/data-types/string) として読み戻されます。
[LowCardinality](/ja/reference/data-types/lowcardinality) カラムは基になる型として書き込まれます
(辞書エンコーディングなどのエンコーディングは Vortex 自身がアダプティブに選択します)。
[DateTime](/ja/reference/data-types/datetime) カラムは秒精度の `vortex.timestamp` として書き込まれるため、
小数点以下の桁数が 0 の [DateTime64](/ja/reference/data-types/datetime64) として読み戻されます。
`vortex.timestamp` が保持するのは小数点以下の桁数ではなく単位であるため、単位でそのまま表せる桁数
(0、3、6、9) のみがスキーマ推論後も維持されます。それ以外の桁数は 1 段階細かい単位で書き込まれ、
その単位に対応する桁数として推論されます。そのため、[DateTime64](/ja/reference/data-types/datetime64)`(1)` と `(2)` は
`DateTime64(3)` として、`(4)` と `(5)` は `DateTime64(6)` として、`(7)` と `(8)` は `DateTime64(9)` として読み戻されます。値は
再スケールされるため意味は変わりません。宣言上の小数点以下の桁数が大きくなるだけであり、型を明示的に指定すれば
元の型のまま読み戻せます。[Time64](/ja/reference/data-types/time64) についても同様です。
`vortex.time` は一日のうちの時刻を表しますが、ClickHouse の [Time/Time64](/ja/reference/data-types/time64) は
負の値や 24 時間以上の値も保持できます。そのような値を書き込もうとすると、誤った値を書き込むのではなく例外がスローされます。
Vortex には IPアドレス用の型がないため、[IPv4](/ja/reference/data-types/ipv4) カラムは `U32` として書き込まれ、
スキーマ推論では [UInt32](/ja/reference/data-types/int-uint) として読み戻されます。このようなカラムを `IPv4` として読み戻すには、
型を明示的に指定してください: `SELECT * FROM file('data.vortex', Vortex, 'ip IPv4')`。

ClickHouse テーブルのカラムのデータ型は、対応する Vortex のデータフィールドと一致している必要はありません。
データを挿入する際、ClickHouse は上記の表に従ってデータ型を解釈し、その後データを
ClickHouse テーブルのカラムに設定されたデータ型へ[キャスト](/ja/reference/functions/regular-functions/type-conversion-functions#CAST)します。

## 使用例 {#example-usage}

Vortex ファイルからデータを選択できます。

```sql
SELECT * FROM file('data.vortex');
```

また、Vortex ファイルへのデータの書き込みは次のとおりです:

```sql
SELECT * FROM numbers(3) INTO OUTFILE 'numbers.vortex' FORMAT Vortex;
```

## フォーマット設定 {#format-settings}

| 設定                                      | 説明                                                                                                                                                                                                                                                                                                                 | デフォルト |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----- |
| `input_format_vortex_filter_push_down`  | `WHERE` 条件のうち変換可能な部分をスキャンにプッシュダウンし、選択性の高いクエリで読み取りおよびデコードするデータ量を削減します。スキャン内で適用されるのは、条件のうち変換された部分のみです。一部しか変換できない条件は、一致する行をすべて確実に残す条件へと緩和されます。そのため一致しない行も読み取り・デコードされる場合がありますが、その後 ClickHouse がフィルタ全体を改めて適用します。現在プッシュダウンがサポートしているのは、top-level の整数、floating-point、文字列/バイナリ、`Bool`、`Date`、`Date32`、`DateTime64` の各カラムです。 | `1`   |
| `input_format_vortex_preserve_order`    | ファイル内の順序で行を返します。デフォルトでは、ファイル内の行の分割単位が並列にデコードされ、準備ができたものから順に返されるため、行の順序は保証されません。この設定を有効にすると、処理の遅い分割単位があった場合、それ以降の分割単位はその完了まで待機します。                                                                                                                                                                                  | `0`   |
| `output_format_vortex_string_as_string` | [String](/ja/reference/data-types/string) カラムを `Binary` ではなく `Utf8` として書き込みます。有効なUTF-8 ではない値がある場合は例外をスローします。そのようなデータを `Binary` として書き込むには、この設定を無効化してください。                                                                                                                                                              | `1`   |
| `max_parsing_threads`                   | Vortex ファイルをデコードするスレッド数です (1 つのクエリで並列に読み取られるファイル間で共有されます) 。`1` を指定するとスレッドプールが無効になり、ファイルはクエリパイプラインのスレッド上で `read` 内で読み取られます。                                                                                                                                                                                         | コア数   |
| `max_download_threads`                  | ファイルを読み取るスレッド数です。`0` を指定すると、読み取りにデコード用スレッドが共用されます。                                                                                                                                                                                                                                                                 | `4`   |

他の列指向フォーマットと同様に、ファイルからはクエリで使用されるカラムのみが読み取られ、
ファイルに存在しないカラムはデフォルト値で補完されます。

## パフォーマンス {#performance}

ファイルは並列に読み取られます。スキャンではファイルを行範囲(要求されたカラムの chunk 境界に揃えられ、それぞれ最大 100 000 行)に分割し、
各範囲を並行して読み取り、フィルタし、デコードします。
デコードは `Parquet` リーダーが使用するのと同じ pool のスレッドを最大 `max_parsing_threads` 個使用して実行され、
読み取りは最大 `max_download_threads` 個のスレッドで実行されます。また、デコード済みの chunk から
ClickHouse のカラムへの変換は、その chunk をデコードしたスレッド上で行われます。chunk は準備ができ次第
返されるため、`input_format_vortex_preserve_order` が設定されていない限り、行の順序は保証されません。
ファイル内で近接しているセグメントの読み取りは、1 つのリクエストにマージされます(ローカル
ファイルでは最大 4 MiB、リモートストレージでは最大 16 MiB)。フィルタのプッシュダウンにより、選択性の高いクエリでは
読み取りおよびデコードの対象となるデータ量が削減されます。
