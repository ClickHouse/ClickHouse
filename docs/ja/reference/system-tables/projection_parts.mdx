<div id="description">
  ## 説明
</div>

このテーブルには、MergeTree family テーブルのプロジェクションパーツに関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ja/reference/data-types/string)) — パーティション名。
* `name` ([String](/ja/reference/data-types/string)) — データパーツ名。
* `part_type` ([String](/ja/reference/data-types/string)) — データパーツの保存形式。設定可能な値: Wide (カラムごとに1つのファイル) およびCompact (すべてのカラムを1つのファイルに格納) 。
* `parent_name` ([String](/ja/reference/data-types/string)) — 元となる (親) データパーツの名前。
* `parent_uuid` ([UUID](/ja/reference/data-types/uuid)) — 元となる (親) データパーツのUUID。
* `parent_part_type` ([String](/ja/reference/data-types/string)) — 元となる (親) データパーツの保存形式。
* `active` ([UInt8](/ja/reference/data-types/int-uint)) — データパーツがアクティブかどうかを示すフラグ。アクティブなデータパーツはテーブルで使用されます。アクティブでない場合は、削除予定です。非アクティブなデータパーツは、マージまたは変更操作の後に現れます。
* `marks` ([UInt64](/ja/reference/data-types/int-uint)) — マーク数。データパーツ内の行数の概算は、マーク数に索引粒度 (通常は8192) を掛けることで求められます (この方法は適応的粒度では使用できません) 。
* `rows` ([UInt64](/ja/reference/data-types/int-uint)) — 行数。
* `bytes_on_disk` ([UInt64](/ja/reference/data-types/int-uint)) — すべてのデータパーツファイルの合計サイズ (バイト) 。
* `data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内の圧縮データの合計サイズ。補助ファイル (マークファイルなど) は含まれません。
* `data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内の非圧縮データの合計サイズ。補助ファイル (マークファイルなど) は含まれません。
* `marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — マークファイルのサイズ。
* `parent_marks` ([UInt64](/ja/reference/data-types/int-uint)) — 元となる (親) パーツのマーク数。
* `parent_rows` ([UInt64](/ja/reference/data-types/int-uint)) — 元となる (親) パーツの行数。
* `parent_bytes_on_disk` ([UInt64](/ja/reference/data-types/int-uint)) — 元となる (親) データパーツのすべてのファイルの合計サイズ (バイト) 。
* `parent_data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 元となる (親) データパーツ内の圧縮データの合計サイズ。
* `parent_data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 元となる (親) データパーツ内の非圧縮データの合計サイズ。
* `parent_marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 元となる (親) データパーツ内のマークファイルのサイズ。
* `modification_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツを含むディレクトリの更新時刻。通常はデータパーツの作成時刻に相当します。
* `remove_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツが非アクティブになった時刻。
* `refcount` ([UInt32](/ja/reference/data-types/int-uint)) — データパーツが使用されている箇所の数。値が2より大きい場合、データパーツはクエリまたはマージで使用されています。
* `min_date` ([Date](/ja/reference/data-types/date)) — データパーツ内の日付キーの最小値。
* `max_date` ([Date](/ja/reference/data-types/date)) — データパーツ内の日付キーの最大値。
* `min_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最小値。
* `max_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最大値。
* `partition_id` ([String](/ja/reference/data-types/string)) — パーティション ID。
* `min_block_number` ([Int64](/ja/reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最小番号。
* `max_block_number` ([Int64](/ja/reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最大番号。
* `level` ([UInt32](/ja/reference/data-types/int-uint)) — マージツリーの深さ。0 は、現在のパーツが他のパーツのマージではなく insert によって作成されたことを示します。
* `data_version` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツに適用する mutation を判定するための番号 (バージョンが data&#95;version より大きい mutation) 。
* `primary_key_bytes_in_memory` ([UInt64](/ja/reference/data-types/int-uint)) — 主キー値が使用するメモリ量 (バイト単位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ja/reference/data-types/int-uint)) — 主キー値用に確保されたメモリ量 (バイト単位) 。
* `is_frozen` ([UInt8](/ja/reference/data-types/int-uint)) — パーティションのデータバックアップが存在することを示すフラグ。1 はバックアップが存在し、0 は存在しないことを示します。
* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `engine` ([String](/ja/reference/data-types/string)) — パラメータを除くテーブルエンジン名。
* `disk_name` ([String](/ja/reference/data-types/string)) — データパーツを格納するディスク名。
* `path` ([String](/ja/reference/data-types/string)) — データパーツファイルを含むフォルダへの絶対パス。
* `hash_of_all_files` ([String](/ja/reference/data-types/string)) — 圧縮ファイルの sipHash128。
* `hash_of_uncompressed_files` ([String](/ja/reference/data-types/string)) — 非圧縮ファイル (マークファイル、索引ファイルなど) の sipHash128。
* `uncompressed_hash_of_compressed_files` ([String](/ja/reference/data-types/string)) — 圧縮ファイルを非圧縮とみなした場合のデータの sipHash128。
* `delete_ttl_info_min` ([DateTime](/ja/reference/data-types/datetime)) — TTL DELETE ルールの日付と時刻キーの最小値。
* `delete_ttl_info_max` ([DateTime](/ja/reference/data-types/datetime)) — TTL DELETE ルールの日付と時刻キーの最大値。
* `move_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — 式の Array。各式は TTL MOVE ルールを定義します。
* `move_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — 日付と時刻の値の Array。各要素は TTL MOVE ルールの最小キー値を示します。
* `move_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — 日付と時刻の値の Array。各要素は TTL MOVE ルールの最大キー値を示します。
* `default_compression_codec` ([String](/ja/reference/data-types/string)) — このデータパーツの圧縮に使用される codec 名 (カラムに明示的な codec がない場合) 。
* `recompression_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — 有効期限 (TTL) 式。
* `recompression_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — このパーツ内で計算された有効期限 (TTL) 式の最小値。TTL が期限切れの行が少なくとも 1 行あるかどうかを確認するために使用します。
* `recompression_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最大値。TTL が有効期限切れの行だけになっているかを判断するために使用します。
* `group_by_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — TTL 式。
* `group_by_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最小値。TTL が有効期限切れの行が少なくとも 1 行あるかを判断するために使用します。
* `group_by_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最大値。TTL が有効期限切れの行だけになっているかを判断するために使用します。
* `rows_where_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — TTL 式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最小値。TTL が有効期限切れの行が少なくとも 1 行あるかを判断するために使用します。
* `rows_where_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最大値。TTL が有効期限切れの行だけになっているかを判断するために使用します。
* `is_broken` ([UInt8](/ja/reference/data-types/int-uint)) — projection part が破損しているかどうか
* `exception_code` ([Int32](/ja/reference/data-types/int-uint)) — projection part の破損状態を説明する Exception メッセージ
* `exception` ([String](/ja/reference/data-types/string)) — projection part の破損状態を説明する Exception code

**別名:**

* `bytes` — `bytes_on_disk` の別名。
* `marks_size` — `marks_bytes` の別名。
* `part_name` — `name` の別名。
