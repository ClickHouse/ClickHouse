## 説明 {#description}

現在のユーザーの有効なロールが含まれます。`SET ROLE` によってこのテーブルの内容が変更されます。

## カラム {#columns}

* `role_name` ([String](/ja/reference/data-types/string)) — ロール名。
* `with_admin_option` ([UInt8](/ja/reference/data-types/int-uint)) — ロールにADMIN OPTION権限がある場合は1。
* `is_default` ([UInt8](/ja/reference/data-types/int-uint)) — ロールがデフォルトに設定されている場合は1。
