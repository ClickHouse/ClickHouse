## 説明 {#description}

ローカルサーバー上に存在する[ワークロード](/ja/concepts/features/configuration/server-config/workload-scheduling#workload_entity_storage)に関する情報が含まれます。このテーブルには、各ワークロードについて1行が含まれます。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — ワークロードの名前。
* `parent` ([String](/ja/reference/data-types/string)) — 親ワークロードの名前。
* `create_query` ([String](/ja/reference/data-types/string)) — ワークロードの CREATE クエリ。空の名前を持つルートワークロードを含む暗黙的なワークロード (`source` = `implicit`) では、このクエリはワークロードを説明するためのものであり、実行することはできません。
* `source` ([String](/ja/reference/data-types/string)) — ワークロードを定義しているストレージの名前。サーバー構成で定義されている場合は `configuration`、SQL で定義されている場合は `disk` または `keeper`、サーバーによって暗黙的に作成されたワークロードの場合は `implicit` となります。

## 例 {#example}

```sql
SELECT *
FROM system.workloads
FORMAT Vertical
```

```text
Row 1:
──────
name:         production
parent:       all
create_query: CREATE WORKLOAD production IN `all` SETTINGS weight = 9

Row 2:
──────
name:         development
parent:       all
create_query: CREATE WORKLOAD development IN `all`

Row 3:
──────
name:         all
parent:
create_query: CREATE WORKLOAD `all`
```
