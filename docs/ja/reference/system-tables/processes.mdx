<div id="description">
  ## 説明
</div>

このシステムテーブルは、`SHOW PROCESSLIST` クエリの実装に使用されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/ja/reference/data-types/int-uint)) — クエリが初期クエリかどうか。設定可能な値: 1 — 初期 (最上位) クエリ、0 — 分散実行のクエリおよび内部サブクエリを含む、別のクエリによって開始された子クエリ。
* `user` ([String](/ja/reference/data-types/string)) — クエリを実行したユーザー。分散処理では、クエリはdefaultユーザーとしてリモートサーバーに送信されることに注意してください。このフィールドには特定のクエリのユーザー名が含まれ、このクエリによって開始されたクエリのユーザー名は含まれません。
* `query_id` ([String](/ja/reference/data-types/string)) — 定義されている場合のクエリID。
* `address` ([IPv6](/ja/reference/data-types/ipv6)) — クエリの送信元IPアドレス。分散処理でも同様です。分散クエリが元々どこから送信されたかを追跡するには、クエリ要求元サーバーのsystem.processesを確認してください。
* `port` ([UInt16](/ja/reference/data-types/int-uint)) — クエリの送信元クライアントポート。
* `initial_user` ([String](/ja/reference/data-types/string)) — 同じクエリチェーン内の初期クエリを実行したユーザー名。
* `initial_query_id` ([String](/ja/reference/data-types/string)) — 同じクエリチェーン内の初期クエリのID。
* `initial_address` ([IPv6](/ja/reference/data-types/ipv6)) — 同じクエリチェーン内の初期クエリの送信元IPアドレス。
* `initial_port` ([UInt16](/ja/reference/data-types/int-uint)) — 同じクエリチェーン内の初期クエリの送信元クライアントポート。
* `interface` ([UInt8](/ja/reference/data-types/int-uint)) — クエリの送信に使用されたインターフェイス。TCP = 1、HTTP = 2、GRPC = 3、MYSQL = 4、POSTGRESQL = 5、LOCAL = 6、TCP&#95;INTERSERVER = 7。
* `os_user` ([String](/ja/reference/data-types/string)) — clickhouse-clientを実行しているオペレーティングシステムのユーザー名。
* `client_hostname` ([String](/ja/reference/data-types/string)) — clickhouse-clientまたは別のTCPクライアントが実行されているクライアントマシンのホスト名。
* `client_name` ([String](/ja/reference/data-types/string)) — clickhouse-clientまたは別のTCPクライアントの名前。
* `client_agent` ([LowCardinality(String)](/ja/reference/data-types/lowcardinality)) — クライアントを呼び出したAIコーディングagent (例: `claude-code`、`cursor`) 。環境変数から検出され、agentが検出されなかった場合は空です。
* `client_revision` ([UInt64](/ja/reference/data-types/int-uint)) — clickhouse-clientまたは別のTCPクライアントのリビジョン。
* `client_version_major` ([UInt64](/ja/reference/data-types/int-uint)) — clickhouse-clientまたは別のTCPクライアントのメジャーバージョン。
* `client_version_minor` ([UInt64](/ja/reference/data-types/int-uint)) — clickhouse-clientまたは別のTCPクライアントのマイナーバージョン。
* `client_version_patch` ([UInt64](/ja/reference/data-types/int-uint)) — clickhouse-clientまたは別のTCPクライアントのバージョンのパッチ番号。
* `http_method` ([UInt8](/ja/reference/data-types/int-uint)) — クエリを開始したHTTPメソッド。設定可能な値: 0 - TCPインターフェイスからクエリが開始されました、1 - GETメソッドが使用されました、2 - POSTメソッドが使用されました、4 - PUTメソッドが使用されました、5 - DELETEメソッドが使用されました、6 - HEADメソッドが使用されました。
* `http_user_agent` ([String](/ja/reference/data-types/string)) — HTTPクエリで渡されたUserAgent HTTPヘッダー。
* `http_referer` ([String](/ja/reference/data-types/string)) — HTTPクエリで渡されたReferer HTTPヘッダー (クエリを実行するページの絶対アドレスまたは部分アドレスを含みます) 。
* `forwarded_for` ([String](/ja/reference/data-types/string)) — HTTPクエリで渡されたX-Forwarded-For HTTPヘッダー。
* `quota_key` ([String](/ja/reference/data-types/string)) — quotas設定で指定されたquota key (keyedを参照) 。
* `distributed_depth` ([UInt64](/ja/reference/data-types/int-uint)) — クエリが内部的にServer nodes間で再送信された回数。
* `elapsed` ([Float64](/ja/reference/data-types/float)) — リクエスト実行開始からの経過時間 (秒) 。
* `is_cancelled` ([UInt8](/ja/reference/data-types/int-uint)) — クエリがキャンセルされたかどうか。
* `is_all_data_sent` ([UInt8](/ja/reference/data-types/int-uint)) — すべてのデータがクライアントに送信されたかどうか (つまり、サーバー上でクエリが完了したかどうか) 。
* `read_rows` ([UInt64](/ja/reference/data-types/int-uint)) — テーブルから読み取られた行数。分散処理では、リクエスト元サーバーではすべてのリモートサーバーの合計です。
* `read_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — テーブルから読み取られた非圧縮バイト数。分散処理では、リクエスト元サーバーではすべてのリモートサーバーの合計です。
* `total_rows_approx` ([UInt64](/ja/reference/data-types/int-uint)) — 読み取る必要がある合計行数のおおよその値。分散処理では、リクエスト元サーバーではすべてのリモートサーバーの合計です。処理対象の新しいデータソースが判明すると、リクエスト処理中に更新されることがあります。
* `written_rows` ([UInt64](/ja/reference/data-types/int-uint)) — ストレージに書き込まれた行数。
* `written_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — ストレージに書き込まれたバイト数。
* `memory_usage` ([Int64](/ja/reference/data-types/int-uint)) — クエリが使用する RAM 容量。一部の専用メモリは含まれない場合があります。
* `peak_memory_usage` ([Int64](/ja/reference/data-types/int-uint)) — 現在のメモリ使用量のピーク値。
* `query` ([String](/ja/reference/data-types/string)) — クエリテキスト。INSERT の場合、挿入するデータは含まれません。
* `normalized_query_hash` ([UInt64](/ja/reference/data-types/int-uint)) — リテラル値のみが異なるクエリでは同一となる数値ハッシュ値。
* `query_kind` ([String](/ja/reference/data-types/string)) — クエリの種類 (SELECT、INSERT など) 。
* `thread_ids` ([Array(UInt64)](/ja/reference/data-types/array)) — このクエリの実行に関与したすべてのスレッドの識別子リスト。
* `peak_threads_usage` ([UInt64](/ja/reference/data-types/int-uint)) — クエリ実行時の同時スレッド数の最大値。
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/ja/reference/data-types/map)) — このクエリについて計算された ProfileEvents。
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/ja/reference/data-types/map)) — 変更されたユーザーレベル設定のリスト。
* `current_database` ([String](/ja/reference/data-types/string)) — 現在のデータベース名。
* `is_internal` ([UInt8](/ja/reference/data-types/int-uint)) — 内部的に実行される補助クエリかどうかを示します。

**別名:**

* `ProfileEvents.Names` — `mapKeys(ProfileEvents)`の別名。
* `ProfileEvents.Values` — `mapValues(ProfileEvents)`の別名。
* `Settings.Names` — `mapKeys(Settings)`の別名。
* `Settings.Values` — `mapValues(Settings)`の別名。

{/*AUTOGENERATED_END*/}
