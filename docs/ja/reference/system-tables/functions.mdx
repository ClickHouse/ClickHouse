<div id="description">
  ## 説明
</div>

通常の関数および集約関数に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — 関数名。
* `is_aggregate` ([UInt8](/ja/reference/data-types/int-uint)) — 集約関数かどうか。
* `case_insensitive` ([UInt8](/ja/reference/data-types/int-uint)) — 関数名で大文字と小文字を区別しないかどうか。
* `alias_to` ([String](/ja/reference/data-types/string)) — 関数名がエイリアスである場合の元の関数名。
* `create_query` ([String](/ja/reference/data-types/string)) — 廃止された。
* `origin` ([Enum8(&#39;System&#39; = 0, &#39;SQLUserDefined&#39; = 1, &#39;ExecutableUserDefined&#39; = 2, &#39;WasmUserDefined&#39; = 3)](/ja/reference/data-types/enum)) — 廃止された。
* `description` ([String](/ja/reference/data-types/string)) — 関数の機能に関する概要。
* `syntax` ([String](/ja/reference/data-types/string)) — 関数のシグネチャ。
* `arguments` ([String](/ja/reference/data-types/string)) — 関数の引数。
* `parameters` ([String](/ja/reference/data-types/string)) — 関数のパラメータ (集約関数のみ) 。
* `returned_value` ([String](/ja/reference/data-types/string)) — 関数が返す値。
* `examples` ([String](/ja/reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/reference/data-types/string)) — 関数が初めて導入されたClickHouseのバージョン。
* `categories` ([String](/ja/reference/data-types/string)) — 関数のカテゴリ。
* `deterministic` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — 同じ引数に対して常に同じ結果を返すかどうか。不明な場合はNULL (例：集約関数またはユーザー定義関数) 。
* `higher_order` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — 高階関数かどうか、つまり少なくとも1つのラムダ式を引数として受け取るかどうか (例：arrayMap、arrayFilter、mapApply) 。不明な場合はNULL。

{/*AUTOGENERATED_END*/}
