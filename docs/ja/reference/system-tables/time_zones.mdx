## 説明 {#description}

ClickHouse server でサポートされているタイムゾーンの一覧です。この一覧は、ClickHouse のバージョンによって異なる場合があります。

## カラム {#columns}

* `time_zone` ([String](/ja/reference/data-types/string)) — 対応しているタイムゾーンの一覧。

## 例 {#example}

```sql
SELECT * FROM system.time_zones LIMIT 10
```

```text
┌─time_zone──────────┐
│ Africa/Abidjan     │
│ Africa/Accra       │
│ Africa/Addis_Ababa │
│ Africa/Algiers     │
│ Africa/Asmara      │
│ Africa/Asmera      │
│ Africa/Bamako      │
│ Africa/Bangui      │
│ Africa/Banjul      │
│ Africa/Bissau      │
└────────────────────┘
```
