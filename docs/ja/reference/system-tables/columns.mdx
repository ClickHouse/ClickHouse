<div id="description">
  ## 説明
</div>

すべてのテーブルのカラムに関する情報が含まれています。

このテーブルを使うと、[DESCRIBE TABLE](/ja/reference/statements/describe-table) クエリと同様の情報を、複数のテーブルについて一度に取得できます。

[一時テーブル](/ja/reference/statements/create/table/temporary-table) のカラムは、作成されたセッションでのみ `system.columns` に表示されます。これらは `database` フィールドが空の状態で表示されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `name` ([String](/ja/reference/data-types/string)) — カラム名。
* `type` ([String](/ja/reference/data-types/string)) — カラム型。
* `position` ([UInt64](/ja/reference/data-types/int-uint)) — テーブル内でのカラムの順序位置。1 から始まります。
* `default_kind` ([String](/ja/reference/data-types/string)) — デフォルト値の式の種類 (DEFAULT、MATERIALIZED、ALIAS) 。定義されていない場合は空文字列です。
* `default_expression` ([String](/ja/reference/data-types/string)) — デフォルト値の式。定義されていない場合は空文字列です。
* `data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 圧縮データのサイズ (バイト単位) 。
* `data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 解凍後のデータのサイズ (バイト単位) 。
* `marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — マークのサイズ (バイト単位) 。
* `comment` ([String](/ja/reference/data-types/string)) — カラムに関するコメント。定義されていない場合は空文字列です。
* `is_in_partition_key` ([UInt8](/ja/reference/data-types/int-uint)) — カラムがパーティション式に含まれるかどうかを示すフラグ。
* `is_in_sorting_key` ([UInt8](/ja/reference/data-types/int-uint)) — カラムがソートキー式に含まれるかどうかを示すフラグ。
* `is_in_primary_key` ([UInt8](/ja/reference/data-types/int-uint)) — カラムが主キー式に含まれるかどうかを示すフラグ。
* `is_in_sampling_key` ([UInt8](/ja/reference/data-types/int-uint)) — カラムがサンプリングキー式に含まれるかどうかを示すフラグ。
* `compression_codec` ([String](/ja/reference/data-types/string)) — 圧縮コーデック名。
* `character_octet_length` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — バイナリデータ、文字データ、テキストデータ、イメージの最大長 (バイト単位) 。ClickHouse では FixedString データ型でのみ意味を持ちます。それ以外の場合は、NULL 値が返されます。
* `numeric_precision` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 近似数値データ、正確な数値データ、整数データ、または通貨データの精度。ClickHouse では、整数型ではビット幅、Decimal 型では10進精度を表します。それ以外の場合は、NULL 値が返されます。
* `numeric_precision_radix` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 近似数値データ、正確な数値データ、整数データ、または通貨データの精度に用いる数値体系の基数。ClickHouse では、整数型は 2、Decimal 型は 10 です。それ以外の場合は、NULL 値が返されます。
* `numeric_scale` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 近似数値データ、正確な数値データ、整数データ、または通貨データのスケール。ClickHouse では Decimal 型でのみ意味を持ちます。それ以外の場合は、NULL 値が返されます。
* `datetime_precision` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — DateTime64 データ型の小数精度。その他のデータ型では、NULL 値が返されます。
* `serialization_hint` ([Nullable(String)](/ja/reference/data-types/nullable)) — 統計情報に基づき、INSERT 時にカラムが使用するシリアライゼーションを選択するためのヒント。
* `statistics` ([String](/ja/reference/data-types/string)) — このカラムで作成される統計情報の種類。

**別名:**

* `column` — `name` の別名。

{/*AUTOGENERATED_END*/}
