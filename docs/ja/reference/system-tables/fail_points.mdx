## 説明 {#description}

サーバーに登録されている利用可能なすべてのフェイルポイントの一覧、それぞれの型、および現在有効かどうかを示します。

フェイルポイントをサポートするビルド (`USE_LIBFIU=1`) では、フェイルポイントは `SYSTEM ENABLE FAILPOINT` ステートメントと `SYSTEM DISABLE FAILPOINT` ステートメントを使用して、実行時に有効化または無効化できます。これらのステートメントは、フェイルポイントをサポートしないビルドでは利用できませんが、テーブル自体は引き続き利用できます。

`SYSTEM DISABLE ALL FAILPOINTS` は、すべてのフェイルポイントを一度に無効化し、一時停止可能なフェイルポイントでブロックされているスレッドを再開します。これにより、現在どのフェイルポイントが有効になっているかを把握していなくても、サーバーをクリーンな状態に戻すことができます。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — フェイルポイント の名前。
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/ja/reference/data-types/enum)) — フェイルポイント のタイプ。&#39;once&#39; は 1 回だけ発動して自動的に無効化され、&#39;regular&#39; は毎回発動し、&#39;pauseable&#95;once&#39; は 1 回だけ実行を停止させ、&#39;pauseable&#39; は再開されるまで毎回実行を停止させます。
* `enabled` ([UInt8](/ja/reference/data-types/int-uint)) — フェイルポイント が現在有効 (1) か無効 (0) かを示します。

## 例 {#example}

この例には、フェイルポイント サポートを有効にしたビルド (`USE_LIBFIU=1`) が必要です。

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```

```text title="Response"
┌─name──────────────────────────────────────┬─type────────────┬─enabled─┐
│ replicated_merge_tree_insert_retry_pause  │ pauseable_once  │       1 │
└───────────────────────────────────────────┴─────────────────┴─────────┘
```
