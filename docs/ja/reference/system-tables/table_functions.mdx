## 説明 {#description}

利用可能なすべてのテーブル関数とその説明の一覧です。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — テーブル関数の名前。
* `description` ([String](/ja/reference/data-types/string)) — テーブル関数の簡単な説明。
* `allow_readonly` ([UInt8](/ja/reference/data-types/int-uint)) — 読み取り専用ユーザーがこの関数を使用できるかどうかを示すフラグ。
