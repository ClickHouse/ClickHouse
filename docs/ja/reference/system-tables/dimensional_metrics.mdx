<div id="description">
  ## 説明
</div>

このテーブルには、即座に計算でき、Prometheus フォーマットでエクスポート可能な次元メトリクスが含まれています。常に最新の状態に保たれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `metric` ([String](/ja/reference/data-types/string)) — メトリクス名。
* `value` ([Float64](/ja/reference/data-types/float)) — メトリクス値。
* `description` ([String](/ja/reference/data-types/string)) — メトリクスの説明。
* `labels` ([Map(String, String)](/ja/reference/data-types/map)) — メトリクスラベル。

**別名:**

* `name` — `metric` の別名。

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 例
</div>

次のようなクエリを使うと、すべての次元メトリクスをPrometheusフォーマットでエクスポートできます。

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## メトリクスの説明
</div>

<div id="merge_failures">
  ### merge_failures
</div>

起動以降に失敗したマージの総数。

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

起動スクリプトの失敗をエラー種別ごとに示します。起動スクリプトが失敗すると1に設定され、エラー名のラベルが付与されます。

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

MergeTree データパーツの数。パーツの状態、パーツのタイプ、およびプロジェクションパーツかどうかによってラベル付けされます。

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの数。キャッシュ名ごとにラベル付けされます。デフォルトでは無効になっているため、`expose_prometheus_eviction_metrics` で有効にします。

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

キャッシュ名ごとにラベル付けされた、ファイルシステムキャッシュから追い出されたファイルセグメントの合計バイト数。デフォルトでは無効です。`expose_prometheus_eviction_metrics` を使用して有効にします。

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの数。キャッシュ名とユーザー ID ごとにラベル付けされます。デフォルトでは無効で、`expose_prometheus_eviction_metrics` と `expose_prometheus_eviction_metrics_per_user` で有効にできます。

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

ファイルシステムキャッシュから追い出されたファイルセグメントの合計バイト数。キャッシュ名とユーザー ID ごとにラベル付けされます。デフォルトでは無効です。`expose_prometheus_eviction_metrics` と `expose_prometheus_eviction_metrics_per_user` で有効にします。

<div id="object-storage-queue-failures-total">
  ### `object_storage_queue_failures_total`
</div>

データベース、テーブル、処理ステージ (`read`、`set_processing`、`insert`、`commit`) 、エラーコードごとにラベル付けされた `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) の失敗回数。

<div id="object-storage-queue-permanently-failed-files-total">
  ### `object_storage_queue_permanently_failed_files_total`
</div>

再試行をすべて使い果たした後 (または再試行が無効な場合) に、永続的に処理を断念した `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) ファイルの数。データベースおよびテーブルでラベル付けされます。各ファイルは、そのデータが今後処理されることのないファイルを表します。

<div id="object-storage-queue-newest-seen-object-timestamp-seconds">
  ### `object_storage_queue_newest_seen_object_timestamp_seconds`
</div>

`ObjectStorageQueue` (`S3Queue`/`AzureQueue`) テーブルでこれまでに検出された最新オブジェクトの最終更新時刻を表すUnix timestamp。データベースおよびテーブルでラベル付けされます。

<div id="object-storage-queue-newest-committed-object-timestamp-seconds">
  ### `object_storage_queue_newest_committed_object_timestamp_seconds`
</div>

`ObjectStorageQueue` (`S3Queue`/`AzureQueue`) テーブルでこれまでに完全に処理された最新のオブジェクトの最終更新時刻を表すUnix timestamp。データベースおよびテーブルでラベル付けされます。
