<div id="description">
  ## 説明
</div>

ClickHouse のすべての SQL ステートメントの一覧です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — SQLステートメントの名前。
* `syntax` ([String](/ja/reference/data-types/string)) — ステートメントの構文。
* `description` ([String](/ja/reference/data-types/string)) — ステートメントの機能の説明と使用例。
* `parent_name` ([String](/ja/reference/data-types/string)) — 親ステートメントの名前。たとえば、WHERE句の親ステートメントはSELECTです。最上位のステートメントの場合は空です。
* `related` ([Array(String)](/ja/reference/data-types/array)) — 関連するステートメントの名前。

{/*AUTOGENERATED_END*/}
