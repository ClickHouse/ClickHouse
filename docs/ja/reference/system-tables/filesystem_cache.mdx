<div id="description">
  ## 説明
</div>

リモートオブジェクトに対するファイルシステムキャッシュ内のすべてのエントリに関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/ja/reference/data-types/string)) — cacheオブジェクトの名前。`SYSTEM DESCRIBE FILESYSTEM CACHE <name>`、`SYSTEM DROP FILESYSTEM CACHE <name>`コマンドで使用できます
* `cache_base_path` ([String](/ja/reference/data-types/string)) — すべてのcacheファイル (`cache_name`で識別されるcache) が保存されるベースディレクトリのパス。
* `cache_path` ([String](/ja/reference/data-types/string)) — ソースファイル内のファイルセグメントに対応する特定のcacheファイルのパス
* `key` ([String](/ja/reference/data-types/string)) — ファイルセグメントのcacheキー
* `file_segment_range_begin` ([UInt64](/ja/reference/data-types/int-uint)) — ファイルセグメント範囲の先頭に対応するオフセット
* `file_segment_range_end` ([UInt64](/ja/reference/data-types/int-uint)) — ファイルセグメント範囲の末尾 (末尾を含む) に対応するオフセット
* `size` ([UInt64](/ja/reference/data-types/int-uint)) — ファイルセグメントのサイズ
* `state` ([String](/ja/reference/data-types/string)) — ファイルセグメントの状態 (DOWNLOADED、DOWNLOADING、PARTIALLY&#95;DOWNLOADED、...)
* `finished_download_time` ([DateTime](/ja/reference/data-types/datetime)) — ファイルセグメントのダウンロード完了時刻。
* `cache_hits` ([UInt64](/ja/reference/data-types/int-uint)) — 対応するファイルセグメントのcacheヒット数
* `references` ([UInt64](/ja/reference/data-types/int-uint)) — 対応するファイルセグメントへの参照数。値が1の場合、現在は誰も使用していません (唯一の参照はcacheストレージ自体が保持しています)
* `downloaded_size` ([UInt64](/ja/reference/data-types/int-uint)) — ファイルセグメントのダウンロード済みサイズ
* `kind` ([String](/ja/reference/data-types/string)) — ファイルセグメントの種類 (&#39;cache内の一時データ&#39;の一部として追加されたファイルセグメントを区別するために使用)
* `unbound` ([UInt8](/ja/reference/data-types/int-uint)) — 内部実装フラグ
* `user_id` ([String](/ja/reference/data-types/string)) — ファイルセグメントを作成したユーザーのID
* `segment_type` ([String](/ja/reference/data-types/string)) — セグメントの種類。データファイル (`.json`、`.txt`など) とデータファイル (`.bin`、マークファイル) を区別するために使用されます。
* `file_size` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在のファイルセグメントが属するファイルのサイズ

{/*AUTOGENERATED_END*/}
