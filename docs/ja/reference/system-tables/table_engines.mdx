<div id="description">
  ## 説明
</div>

サーバーでサポートされるテーブルエンジンの説明と、各機能のサポート状況を示します。

このテーブルには、次のカラムが含まれます (カラム型は角括弧内に示されています) 。

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — テーブルエンジンの名前。
* `supports_settings` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンが SETTINGS 句をサポートするかどうかを示すフラグ。
* `supports_skipping_indices` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンがスキッピングインデックスをサポートするかどうかを示すフラグ。
* `supports_projections` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンがプロジェクションをサポートするかどうかを示すフラグ。
* `supports_sort_order` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンが PARTITION&#95;BY、PRIMARY&#95;KEY、ORDER&#95;BY、SAMPLE&#95;BY 句をサポートするかどうかを示すフラグ。
* `supports_ttl` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンが有効期限 (TTL) をサポートするかどうかを示すフラグ。
* `supports_replication` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンがデータレプリケーションをサポートするかどうかを示すフラグ。
* `supports_deduplication` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンがデータの重複排除をサポートするかどうかを示すフラグ。
* `supports_parallel_insert` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルエンジンが並列 insert をサポートするかどうかを示すフラグ (max&#95;insert&#95;threads 設定を参照) 。
* `description` ([String](/ja/reference/data-types/string)) — テーブルエンジンの機能の説明。専用のドキュメントページがあるエンジンでは、そのページの Markdown 本文全体が含まれます。それ以外のエンジンでは、簡潔な概要が含まれます。
* `syntax` ([String](/ja/reference/data-types/string)) — テーブル作成時のテーブルエンジンの使用方法。ほとんどのエンジンでは CREATE TABLE クエリの ENGINE 句ですが、各種ビューや Loop エンジンなど、一部のエンジンは CREATE VIEW やテーブル関数からの SELECT など、別の形式で使用されます。
* `examples` ([String](/ja/reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/reference/data-types/string)) — テーブルエンジンが最初に導入された ClickHouse のバージョン。形式は major.minor。
* `related` ([Array(String)](/ja/reference/data-types/array)) — 関連するテーブルエンジンの名前。

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 例
</div>

```sql title="Query"
SELECT
    name,
    supports_settings,
    supports_skipping_indices,
    supports_sort_order,
    supports_ttl,
    supports_replication,
    supports_deduplication,
    supports_parallel_insert
FROM system.table_engines
WHERE name IN ('Kafka', 'MergeTree', 'ReplicatedCollapsingMergeTree')
```
