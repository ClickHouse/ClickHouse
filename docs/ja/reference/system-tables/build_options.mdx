## 説明 {#description}

ClickHouse server のビルドオプションに関する情報が含まれています。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — ビルドオプション名。
* `value` ([String](/ja/reference/data-types/string)) — ビルドオプションの値。

## 例 {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
