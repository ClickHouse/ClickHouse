## 説明 {#description}

jemalloc の統計情報を、1 行 1 カラムで返します。SYSTEM JEMALLOC STATS command に相当します。

## カラム {#columns}

* `stats` ([String](/ja/reference/data-types/string)) — JEMalloc の `malloc&#95;stats&#95;print` による統計出力。
