<div id="description">
  ## 説明
</div>

このテーブルには、MergeTree family のテーブルのプロジェクションパーツ内のカラムに関する情報が含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ja/reference/data-types/string)) — パーティション名。
* `name` ([String](/ja/reference/data-types/string)) — データパート名。
* `part_type` ([String](/ja/reference/data-types/string)) — データパートの保存フォーマット。
* `parent_name` ([String](/ja/reference/data-types/string)) — 元の (親) データパート名。
* `parent_uuid` ([UUID](/ja/reference/data-types/uuid)) — 元の (親) データパートの UUID。
* `parent_part_type` ([String](/ja/reference/data-types/string)) — 元の (親) データパートの保存フォーマット。
* `active` ([UInt8](/ja/reference/data-types/int-uint)) — データパートがアクティブかどうかを示すフラグ。
* `marks` ([UInt64](/ja/reference/data-types/int-uint)) — マーク数。
* `rows` ([UInt64](/ja/reference/data-types/int-uint)) — 行数。
* `bytes_on_disk` ([UInt64](/ja/reference/data-types/int-uint)) — すべてのデータパートファイルの合計サイズ (バイト) 。
* `data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパート内の圧縮データの合計サイズ。補助ファイル (例：マークファイル) は含まれません。
* `data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパート内の非圧縮データの合計サイズ。補助ファイル (例：マークファイル) は含まれません。
* `marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — マークファイルのサイズ。
* `parent_marks` ([UInt64](/ja/reference/data-types/int-uint)) — 元の (親) パートのマーク数。
* `parent_rows` ([UInt64](/ja/reference/data-types/int-uint)) — 元の (親) パートの行数。
* `parent_bytes_on_disk` ([UInt64](/ja/reference/data-types/int-uint)) — 元の (親) データパートのすべてのファイルの合計サイズ (バイト) 。
* `parent_data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 元の (親) データパート内の圧縮データの合計サイズ。
* `parent_data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 元の (親) データパート内の非圧縮データの合計サイズ。
* `parent_marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 元の (親) データパート内のマークファイルのサイズ。
* `modification_time` ([DateTime](/ja/reference/data-types/datetime)) — データパートを含むディレクトリの変更時刻。通常はデータパートの作成時刻に対応します。
* `remove_time` ([DateTime](/ja/reference/data-types/datetime)) — データパートが非アクティブになった時刻。
* `refcount` ([UInt32](/ja/reference/data-types/int-uint)) — データパートが使用されている箇所の数。値が 2 より大きい場合、データパートはクエリまたはマージで使用されています。
* `min_date` ([Date](/ja/reference/data-types/date)) — パーティションキーに Date カラムが含まれる場合の最小値。
* `max_date` ([Date](/ja/reference/data-types/date)) — パーティションキーに Date カラムが含まれる場合の最大値。
* `min_time` ([DateTime](/ja/reference/data-types/datetime)) — パーティションキーに DateTime カラムが含まれる場合の最小値。
* `max_time` ([DateTime](/ja/reference/data-types/datetime)) — パーティションキーにDateTimeカラムが含まれる場合の最大値。
* `partition_id` ([String](/ja/reference/data-types/string)) — パーティションのID。
* `min_block_number` ([Int64](/ja/reference/data-types/int-uint)) — マージ後の現在のパーツを構成するデータパーツの最小番号。
* `max_block_number` ([Int64](/ja/reference/data-types/int-uint)) — マージ後の現在のパーツを構成するデータパーツの最大番号。
* `level` ([UInt32](/ja/reference/data-types/int-uint)) — マージツリーの深さ。0は、現在のパーツが他のパーツのマージではなくinsertによって作成されたことを示します。
* `data_version` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツに適用するmutationを判定するための番号 (data&#95;versionより大きいバージョンのmutation) 。
* `primary_key_bytes_in_memory` ([UInt64](/ja/reference/data-types/int-uint)) — 主キー値に使用されるメモリ量 (バイト単位) 。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ja/reference/data-types/int-uint)) — 主キー値用に確保されているメモリ量 (バイト単位) 。
* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `engine` ([String](/ja/reference/data-types/string)) — パラメータを除くテーブルエンジン名。
* `disk_name` ([String](/ja/reference/data-types/string)) — データパーツを格納するディスク名。
* `path` ([String](/ja/reference/data-types/string)) — データパーツファイルが格納されているフォルダーの絶対パス。
* `column` ([String](/ja/reference/data-types/string)) — カラム名。
* `type` ([String](/ja/reference/data-types/string)) — カラム型。
* `column_position` ([UInt64](/ja/reference/data-types/int-uint)) — テーブル内におけるカラムの位置。1から始まります。
* `default_kind` ([String](/ja/reference/data-types/string)) — デフォルト値の式の種類 (DEFAULT、MATERIALIZED、ALIAS) 。定義されていない場合は空文字列です。
* `default_expression` ([String](/ja/reference/data-types/string)) — デフォルト値の式。定義されていない場合は空文字列です。
* `column_bytes_on_disk` ([UInt64](/ja/reference/data-types/int-uint)) — カラムの合計サイズ (バイト単位) 。
* `column_data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — カラム内の圧縮データの合計サイズ (バイト単位) 。
* `column_data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — カラム内の展開済みデータの合計サイズ (バイト単位) 。
* `column_marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — マークを含むカラムのサイズ (バイト単位) 。
* `column_modification_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — カラムが最後に変更された時刻。

**別名:**

* `bytes` — `bytes_on_disk` の別名。
* `marks_size` — `marks_bytes` の別名。
* `part_name` — `name` の別名。

{/*AUTOGENERATED_END*/}
