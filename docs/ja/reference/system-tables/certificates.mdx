<div id="description">
  ## 説明
</div>

利用可能な証明書とそのSOURCESに関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `version` ([Int32](/ja/reference/data-types/int-uint)) — 証明書のバージョン。値は v1 が 0、v2 が 1、v3 が 2 です。
* `serial_number` ([Nullable(String)](/ja/reference/data-types/nullable)) — issuer によって割り当てられた証明書のシリアル番号。
* `signature_algo` ([Nullable(String)](/ja/reference/data-types/nullable)) — 署名アルゴリズム。この証明書への署名に issuer が使用するアルゴリズムです。
* `issuer` ([Nullable(String)](/ja/reference/data-types/nullable)) — 発行者。この証明書を発行した証明書認証局の一意の識別子です。
* `not_before` ([Nullable(String)](/ja/reference/data-types/nullable)) — この証明書の有効期間の開始時点。
* `not_after` ([Nullable(String)](/ja/reference/data-types/nullable)) — この証明書の有効期間の終了時点。
* `subject` ([Nullable(String)](/ja/reference/data-types/nullable)) — subject。公開鍵の所有者を識別します。
* `pkey_algo` ([Nullable(String)](/ja/reference/data-types/nullable)) — 公開鍵アルゴリズム。公開鍵で使用できるアルゴリズムを定義します。
* `path` ([String](/ja/reference/data-types/string)) — この証明書を含むファイルまたはディレクトリへのパス。
* `default` ([UInt8](/ja/reference/data-types/int-uint)) — 証明書がデフォルトの証明書配置場所にあるかどうかを示します。
* `protocol` ([String](/ja/reference/data-types/string)) — 証明書がプロトコルごとの TLS 設定に由来する場合はプロトコル名、それ以外の場合は空です。

{/*AUTOGENERATED_END*/}
