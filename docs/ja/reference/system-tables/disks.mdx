<div id="description">
  ## 説明
</div>

[サーバー設定](/ja/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-multiple-volumes_configure)で定義されたディスクに関する情報を含みます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — サーバー設定内のディスク名。
* `path` ([String](/ja/reference/data-types/string)) — ファイルシステム内のマウントポイントへのパス。
* `free_space` ([UInt64](/ja/reference/data-types/int-uint)) — ディスク上の空き領域 (バイト単位) 。
* `total_space` ([UInt64](/ja/reference/data-types/int-uint)) — ディスクの容量 (バイト単位) 。
* `unreserved_space` ([UInt64](/ja/reference/data-types/int-uint)) — 予約されていない空き領域 (free&#95;spaceから、現在実行中のマージ、挿入、その他のディスク書き込み操作で確保されている予約容量を差し引いた値) 。
* `keep_free_space` ([UInt64](/ja/reference/data-types/int-uint)) — ディスク上で空きとして維持するディスク領域の量 (バイト単位) 。ディスク設定のkeep&#95;free&#95;space&#95;bytesパラメータで定義されます。
* `type` ([String](/ja/reference/data-types/string)) — このディスクがデータを保存する場所 (RAM、ローカルドライブ、リモートストレージ) を示すディスクタイプ。
* `object_storage_type` ([String](/ja/reference/data-types/string)) — ディスクタイプがobject&#95;storageの場合のオブジェクトストレージのタイプ。
* `metadata_type` ([String](/ja/reference/data-types/string)) — ディスクタイプがobject&#95;storageの場合のメタデータストレージのタイプ。
* `is_encrypted` ([UInt8](/ja/reference/data-types/int-uint)) — このディスクが基盤となるデータを暗号化するかどうかを示すフラグ。
* `is_read_only` ([UInt8](/ja/reference/data-types/int-uint)) — このディスクでは読み取り操作のみ実行できることを示すフラグ。
* `is_write_once` ([UInt8](/ja/reference/data-types/int-uint)) — ディスクが一度のみ書き込み可能かどうかを示すフラグ。このディスクへのBACKUPはサポートされますが、このディスク上のMergeTreeテーブルへのINSERTはサポートされません。
* `is_remote` ([UInt8](/ja/reference/data-types/int-uint)) — このディスクでどの操作にネットワーク通信が伴うかを示すフラグ。
* `is_broken` ([UInt8](/ja/reference/data-types/int-uint)) — ディスクが破損しているかどうかを示すフラグ。破損したディスクの容量は0となり、使用できません。
* `cache_path` ([String](/ja/reference/data-types/string)) — ディスクがキャッシュをサポートする場合の、ローカルドライブ上のcacheディレクトリへのパス。

{/*AUTOGENERATED_END*/}
