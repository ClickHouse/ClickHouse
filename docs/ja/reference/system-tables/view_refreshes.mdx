<div id="description">
  ## 説明
</div>

[リフレッシュ可能なマテリアライズドビュー](/ja/reference/statements/create/view#refreshable-materialized-view)に関する情報です。リフレッシュが進行中かどうかにかかわらず、すべてのリフレッシュ可能なマテリアライズドビューが含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — テーブルが属するデータベースの名前。
* `view` ([String](/ja/reference/data-types/string)) — テーブル名。
* `uuid` ([UUID](/ja/reference/data-types/uuid)) — テーブルの UUID (Atomic データベース) 。
* `status` ([String](/ja/reference/data-types/string)) — リフレッシュ の現在の状態。
* `last_success_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — 直近で成功した リフレッシュ が開始された時刻。server の起動またはテーブルの作成以降、成功した リフレッシュ がない場合は NULL。
* `last_success_duration_ms` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 直近の リフレッシュ にかかった時間。
* `last_refresh_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — 直近の リフレッシュ 試行が終了した時刻 (判明している場合) 、または開始した時刻 (不明またはまだ実行中の場合) 。server の起動またはテーブルの作成以降、リフレッシュ の試行がない場合は NULL。
* `last_refresh_replica` ([String](/ja/reference/data-types/string)) — 協調が有効な場合、現在 (実行中の場合) または前回 (実行中でない場合) の リフレッシュ を試行したレプリカの名前。
* `next_refresh_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — 次回の リフレッシュ が開始される予定時刻。次回の リフレッシュ 時刻が現在不明な場合 (例: 依存関係を待機中で、status が `WaitingForDependencies` または `MissingDependencies` の場合) は NULL。
* `exception` ([String](/ja/reference/data-types/string)) — 前回の試行が失敗した場合のエラーメッセージ。
* `retry` ([UInt64](/ja/reference/data-types/int-uint)) — 現在の リフレッシュ でこれまでに失敗した試行回数。status が `RunningOnAnotherReplica` の場合は利用できません。
* `progress` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了した リフレッシュ の進行状況。値は 0 ～ 1 です。status が `RunningOnAnotherReplica` の場合、または リフレッシュ が実行中でない場合は NULL。
* `read_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了した リフレッシュ が読み取った行数。status が `RunningOnAnotherReplica` の場合は NULL。
* `read_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了した リフレッシュ が読み取ったバイト数。status が `RunningOnAnotherReplica` の場合は NULL
* `total_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了した リフレッシュ で読み取る必要がある推定総行数。status が `RunningOnAnotherReplica` の場合は NULL
* `written_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了した リフレッシュ が書き込んだ行数。status が `RunningOnAnotherReplica` の場合は NULL
* `written_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定されたレプリカにおける、現在実行中または直近で完了した リフレッシュ が書き込んだバイト数。status が `RunningOnAnotherReplica` の場合は NULL

{/*AUTOGENERATED_END*/}

  ## 例

    last_refresh_time,
    next_refresh_time
