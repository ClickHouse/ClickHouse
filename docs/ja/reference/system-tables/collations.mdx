## 説明 {#description}

文字列をアルファベット順で比較するために使用できる、利用可能なすべての照合順序の一覧が含まれています。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — 照合順序の名前。
* `language` ([Nullable(String)](/ja/reference/data-types/nullable)) — 言語。
