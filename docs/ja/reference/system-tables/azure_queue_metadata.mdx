<div id="description">
  ## 説明
</div>

各 AzureQueue メタデータオブジェクト について、keeper 内の処理済み、処理中、失敗した ノード の現在の数と、必要に応じてその内容を表示します。インメモリ cache を表示する system.azure&#95;queue&#95;metadata&#95;cache とは異なり、この テーブル は 状態 を keeper から直接読み取ります。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/ja/reference/data-types/string)) — ZooKeeper 内のメタデータへのパス。補助的な ZooKeeper 上のキューでは、生の Keeper パスではなく、ファクトリキー `<zookeeper_name>:<path>` です。
* `processed_nodes_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — Keeper 内の `processed` ディレクトリにあるノード数。`unordered` モードでのみ設定されます。`ordered` モードではファイルごとの処理済みノードが存在しないため (代わりに `processed_path` を参照) 、値は NULL です。
* `processing_nodes_count` ([UInt64](/ja/reference/data-types/int-uint)) — Keeper 内の `processing` ディレクトリにあるノード数
* `failed_nodes_count` ([UInt64](/ja/reference/data-types/int-uint)) — Keeper 内の `failed` ディレクトリにあるノード数
* `processed_nodes` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper 内の `processed` ディレクトリの内容 (ノード名 -&gt; ノードデータ) 。`unordered` モードでのみ設定されます。このカラムが選択された場合にのみ取得されます。
* `processing_nodes` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper 内の `processing` ディレクトリの内容 (ノード名 -&gt; ノードデータ) 。このカラムが選択された場合にのみ取得されます。
* `failed_nodes` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper 内の `failed` ディレクトリの内容 (ノード名 -&gt; ノードデータ) 。このカラムが選択された場合にのみ取得されます。
* `processed_path` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper 内の処理済みポインターごとの最後に処理されたパス (相対ポインターパス -&gt; 最後に処理されたファイルパス) 。単一、バケットごと、パーティションごとのポインターを対象とする `ordered` モードでのみ設定されます。このカラムが選択された場合にのみ取得されます。
