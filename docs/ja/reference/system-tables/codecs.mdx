<div id="description">
  ## 説明
</div>

圧縮および暗号化コーデックに関する情報が含まれています。

この表を使用すると、利用可能な圧縮および暗号化コーデックに関する情報を確認できます

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — コーデック名。
* `method_byte` ([UInt8](/ja/reference/data-types/int-uint)) — 圧縮ファイル内でコーデックを識別するバイト。
* `is_compression` ([UInt8](/ja/reference/data-types/int-uint)) — このコーデックが何らかのデータを圧縮する場合は true。そうでない場合、圧縮を支援するための変換である可能性があります。
* `is_generic_compression` ([UInt8](/ja/reference/data-types/int-uint)) — このコーデックが lz4 や zstd などの汎用圧縮アルゴリズムであるかどうかを示します。
* `is_encryption` ([UInt8](/ja/reference/data-types/int-uint)) — このコーデックが暗号化を行うかどうかを示します。
* `is_timeseries_codec` ([UInt8](/ja/reference/data-types/int-uint)) — このコーデックが浮動小数点時系列データ用であるかどうかを示します。
* `is_experimental` ([UInt8](/ja/reference/data-types/int-uint)) — このコーデックが実験的かどうかを示します。
* `description` ([String](/ja/reference/data-types/string)) — コーデックの概要。

{/*AUTOGENERATED_END*/}

  ## 例
</div>

```sql title="Query"
SELECT * FROM system.codecs WHERE name='LZ4'
```
