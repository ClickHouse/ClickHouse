## 説明 {#description}

すべてのテーブルに存在するプロジェクションに関する情報を保持します。

`total_rows`、`data_compressed_bytes`、`data_uncompressed_bytes` の各カラムは、そのプロジェクションを含むテーブルのアクティブなデータパーツ全体の合計値です。そのため、プロジェクションが構築されるまでは 0 になります。プロジェクションは、たとえばプロジェクションの追加後に行われた挿入処理や `ALTER TABLE ... MATERIALIZE PROJECTION` によって構築されます。各プロジェクションパーツのサイズについては、[system.projection&#95;parts](/ja/operations/system-tables/projection_parts) を参照してください。

## カラム {#columns}

* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `name` ([String](/ja/reference/data-types/string)) — プロジェクション名。
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ja/reference/data-types/enum)) — プロジェクションの種類。
* `total_rows` ([UInt64](/ja/reference/data-types/int-uint)) — 総行数。
* `data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 圧縮済みデータのサイズ (バイト単位) 。
* `data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — 伸長後のデータのサイズ (バイト単位) 。
* `sorting_key` ([Array(String)](/ja/reference/data-types/array)) — プロジェクションのソートキー。
* `query` ([String](/ja/reference/data-types/string)) — プロジェクションのクエリ。
* `settings` ([Map(String, String)](/ja/reference/data-types/map)) — プロジェクションの設定。
