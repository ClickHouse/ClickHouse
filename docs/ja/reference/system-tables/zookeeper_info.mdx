## 説明 {#description}

このテーブルは、ZooKeeper に関する統合された内部情報を出力し、ノードは設定から取得されます。

**可用性**

`system.zookeeper_info` は、ClickHouse Keeper または ZooKeeper が設定されている場合にのみ存在します。いずれも設定されていないサーバーではこのテーブルは存在せず、このテーブルに対するクエリは `UNKNOWN_TABLE` で失敗します。

## Columns {#columns}

* `zookeeper_cluster_name` ([String](/ja/reference/data-types/string)) — ZooKeeper クラスターの名前。
* `host` ([String](/ja/reference/data-types/string)) — ClickHouse が接続した ZooKeeper ノードのホスト名/IP。
* `port` ([UInt16](/ja/reference/data-types/int-uint)) — ClickHouse が接続した ZooKeeper ノードのポート。
* `index` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — ClickHouse が接続した ZooKeeper ノードの索引。この索引は ZooKeeper の設定に基づきます。接続していない場合、このカラムは NULL になります。
* `is_connected` ([UInt8](/ja/reference/data-types/int-uint)) — zookeeper に接続しているかどうか。
* `is_readonly` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — readonly かどうか。
* `version` ([Nullable(String)](/ja/reference/data-types/nullable)) — ZooKeeper のバージョン。
* `avg_latency` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 平均レイテンシ。
* `max_latency` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 最大レイテンシ。
* `min_latency` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 最小レイテンシ。
* `packets_received` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 受信したパケット数。
* `packets_sent` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 送信したパケット数。
* `outstanding_requests` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 未処理のリクエスト数。
* `server_state` ([Nullable(String)](/ja/reference/data-types/nullable)) — サーバーの状態。
* `is_leader` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — この zookeeper が leader かどうか。
* `znode_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — znode の数。
* `watch_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — watch の数。
* `ephemerals_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ephemeral ノードの数。
* `approximate_data_size` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — おおよそのデータサイズ。
* `followers` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — leader のフォロワー。このフィールドは leader のみが公開します。
* `synced_followers` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — leader と同期済みのフォロワー。このフィールドは leader のみが公開します。
* `pending_syncs` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — leader の保留中の同期数。このフィールドは leader のみが公開します。
* `open_file_descriptor_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — オープンされているファイルディスクリプタの数。Unix プラットフォームでのみ利用可能です。
* `max_file_descriptor_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ファイルディスクリプタの最大数。Unix プラットフォームでのみ利用可能です。
* `connections` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の接続数。
* `outstanding` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の未処理数。
* `zxid` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — ZooKeeper の zxid。
* `node_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper のノード数。
* `snapshot_dir_size` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の snapshot ディレクトリのサイズ。
* `log_dir_size` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の log ディレクトリのサイズ。
* `first_log_idx` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の最初の log の索引。
* `first_log_term` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の最初の log のターム。
* `last_log_idx` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の最後の log の索引。
* `last_log_term` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の最後の log のターム。
* `last_committed_idx` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の最後にコミットされた索引。
* `leader_committed_log_idx` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の leader がコミットした log の索引。
* `target_committed_log_idx` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の目標とするコミット済み log の索引。
* `last_snapshot_idx` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ZooKeeper の最後の snapshot の索引。
