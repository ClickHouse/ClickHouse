<div id="description">
  ## 説明
</div>

ローカルサーバー上にあるレプリケートテーブルの情報と状態を保持しています。
このテーブルは監視に利用できます。Replicated* テーブルごとに1行が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `uuid` ([UUID](/ja/reference/data-types/uuid)) — テーブルの UUID。
* `engine` ([String](/ja/reference/data-types/string)) — テーブルエンジン名。
* `is_leader` ([UInt8](/ja/reference/data-types/int-uint)) — レプリカがリーダーかどうか。複数のレプリカが同時にリーダーとなることがあります。merge&#95;tree 設定の replicated&#95;can&#95;become&#95;leader により、レプリカがリーダーになることを防止できます。リーダーはバックグラウンドマージのスケジューリングを担当します。リーダーかどうかにかかわらず、利用可能で ZK とのセッションを持つ任意のレプリカに書き込むことができます。
* `can_become_leader` ([UInt8](/ja/reference/data-types/int-uint)) — レプリカがリーダーになれるかどうか。
* `is_readonly` ([UInt8](/ja/reference/data-types/int-uint)) — レプリカが読み取り専用モードかどうか。このモードは、config に ClickHouse Keeper のセクションがない場合、ClickHouse Keeper でセッションを再初期化する際に不明なエラーが発生した場合、および ClickHouse Keeper でセッションを再初期化している間に有効になります。
* `readonly_start_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — レプリカが読み取り専用モードに移行したタイムスタンプ。レプリカが読み取り専用モードでない場合は Null。
* `is_session_expired` ([UInt8](/ja/reference/data-types/int-uint)) — ClickHouse Keeper とのセッションが期限切れかどうか。基本的には `is_readonly` と同じです。
* `future_parts` ([UInt32](/ja/reference/data-types/int-uint)) — まだ実行されていない INSERT またはマージの結果として作成されるデータパーツ数。
* `parts_to_check` ([UInt32](/ja/reference/data-types/int-uint)) — 検証待ちキュー内のデータパーツ数。破損している可能性があるパーツは、検証キューに追加されます。
* `zookeeper_name` ([String](/ja/reference/data-types/string)) — テーブルのメタデータが保存されている [Zoo]Keeper クラスター (補助クラスターの場合もあります) の名前。
* `zookeeper_path` ([String](/ja/reference/data-types/string)) — ClickHouse Keeper 内のテーブルデータへのパス。
* `replica_name` ([String](/ja/reference/data-types/string)) — ClickHouse Keeper 内のレプリカ名。同じテーブルの各レプリカには異なる名前があります。
* `replica_path` ([String](/ja/reference/data-types/string)) — ClickHouse Keeper 内のレプリカデータへのパス。&#39;zookeeper&#95;path/replicas/replica&#95;path&#39; を連結したものと同じです。
* `columns_version` ([Int32](/ja/reference/data-types/int-uint)) — テーブル構造のバージョン番号。ALTER が実行された回数を示します。レプリカのバージョンが異なる場合、一部のレプリカではまだすべての ALTER が実行されていないことを意味します。
* `queue_size` ([UInt32](/ja/reference/data-types/int-uint)) — 実行待ち操作のキューサイズ。操作には、データブロックの挿入、マージ、およびその他の特定のアクションが含まれます。通常は future&#95;parts と一致します。
* `inserts_in_queue` ([UInt32](/ja/reference/data-types/int-uint)) — 実行が必要なデータブロック挿入の数。挿入は通常、かなり迅速にレプリケーションされます。この数が大きい場合は、何らかの問題が発生していることを示します。
* `merges_in_queue` ([UInt32](/ja/reference/data-types/int-uint)) — 実行待ちのマージ数。マージには時間がかかることがあるため、この値が長期間にわたって 0 より大きくなる場合があります。
* `part_mutations_in_queue` ([UInt32](/ja/reference/data-types/int-uint)) — 実行待ちのミューテーション数。
* `queue_oldest_time` ([DateTime](/ja/reference/data-types/datetime)) — `queue_size` が 0 より大きい場合、最も古い操作がキューに追加された時刻を示します。
* `inserts_oldest_time` ([DateTime](/ja/reference/data-types/datetime)) — `queue_oldest_time` を参照してください。
* `merges_oldest_time` ([DateTime](/ja/reference/data-types/datetime)) — `queue_oldest_time` を参照してください。
* `part_mutations_oldest_time` ([DateTime](/ja/reference/data-types/datetime)) — `queue_oldest_time` を参照してください。
* `oldest_part_to_get` ([String](/ja/reference/data-types/string)) — レプリケーションキュー内で最も古い GET&#95;PARTS エントリから得られた、他のレプリカからフェッチするパーツの名前。
* `oldest_part_to_merge_to` ([String](/ja/reference/data-types/string)) — レプリケーションキュー内の最も古いMERGE&#95;PARTSエントリから取得された、マージ後の結果パーツ名。
* `oldest_part_to_mutate_to` ([String](/ja/reference/data-types/string)) — レプリケーションキュー内の最も古いMUTATE&#95;PARTSエントリから取得された、変更後の結果パーツ名。
* `log_max_index` ([UInt64](/ja/reference/data-types/int-uint)) — 一般アクティビティログ内の最大エントリ番号。このカラムと次の3つ (`log_pointer`、`total_replicas`、`active_replicas`) は、ClickHouse Keeperとのアクティブなセッションがある場合にのみゼロ以外の値を持ちます。
* `log_pointer` ([UInt64](/ja/reference/data-types/int-uint)) — レプリカが実行キューにコピーした一般アクティビティログ内の最大エントリ番号に1を加えた値。log&#95;pointerがlog&#95;max&#95;indexより大幅に小さい場合は、問題が発生しています。
* `last_queue_update` ([DateTime](/ja/reference/data-types/datetime)) — キューが最後に更新された時刻。
* `absolute_delay` ([UInt64](/ja/reference/data-types/int-uint)) — 現在のレプリカの遅延時間 (秒) 。
* `total_replicas` ([UInt32](/ja/reference/data-types/int-uint)) — このテーブルで認識されているレプリカの総数。
* `active_replicas` ([UInt32](/ja/reference/data-types/int-uint)) — ClickHouse Keeperにセッションを持つこのテーブルのレプリカ数 (つまり、正常に機能しているレプリカ数) 。
* `lost_part_count` ([UInt64](/ja/reference/data-types/int-uint)) — テーブル作成以降に全レプリカで失われたデータパーツの合計数。この値はClickHouse Keeperに永続化され、増加することしかありません。
* `last_queue_update_exception` ([String](/ja/reference/data-types/string)) — キューに破損したエントリが含まれている場合の例外。特に、ClickHouseがバージョン間の後方互換性を破り、新しいバージョンで書き込まれたログエントリを古いバージョンで解析できない場合に重要です。
* `zookeeper_exception` ([String](/ja/reference/data-types/string)) — ClickHouse Keeperから情報を取得する際にエラーが発生した場合の、最後の例外メッセージ。
* `replica_is_active` ([Map(String, UInt8)](/ja/reference/data-types/map)) — レプリカ名と、そのレプリカがアクティブかどうかの対応を表すMap。

**別名:**

* `readonly_duration` — `if(isNull(readonly_start_time), NULL, now() - readonly_start_time)` の別名。

{/*AUTOGENERATED_END*/}
