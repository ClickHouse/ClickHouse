## 説明 {#description}

このテーブルには、[MergeTree](/ja/reference/engines/table-engines/mergetree-family/mergetree) テーブルにおける進行中の [データパーツの移動](/ja/reference/statements/alter/partition#move-partitionpart) に関する情報が含まれています。各データパーツの移動は 1 行で表されます。

## カラム {#columns}

* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — 移動中のデータパーツを含むテーブル名。
* `elapsed` ([Float64](/ja/reference/data-types/float)) — データパーツの移動開始からの経過時間 (秒) 。
* `target_disk_name` ([String](/ja/reference/data-types/string)) — データパーツの移動先ディスク名。
* `target_disk_path` ([String](/ja/reference/data-types/string)) — ファイルシステム上のディスクのマウントポイントへのパス。
* `part_name` ([String](/ja/reference/data-types/string)) — 移動中のデータパーツ名。
* `part_size` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツのサイズ。
* `thread_id` ([UInt64](/ja/reference/data-types/int-uint)) — 移動を実行するスレッドの識別子。
