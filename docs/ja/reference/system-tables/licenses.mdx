## 説明 {#description}

ClickHouse のソース内にある [contrib](https://github.com/ClickHouse/ClickHouse/tree/master/contrib) ディレクトリに含まれるサードパーティーライブラリのライセンスです。

## カラム {#columns}

* `library_name` ([文字列](/ja/reference/data-types/string)) — ライブラリ名。
* `license_type` ([文字列](/ja/reference/data-types/string)) — ライセンスの種類 — 例: Apache、MIT。
* `license_path` ([文字列](/ja/reference/data-types/string)) — ライセンス文が記載されたファイルのパス。
* `license_text` ([文字列](/ja/reference/data-types/string)) — ライセンス文。

## 例 {#example}

```sql
SELECT library_name, license_type, license_path FROM system.licenses LIMIT 15
```

```text
┌─library_name───────┬─license_type─┬─license_path────────────────────────┐
│ aws-c-common       │ Apache       │ /contrib/aws-c-common/LICENSE       │
│ boost              │ Boost        │ /contrib/boost/LICENSE_1_0.txt      │
│ brotli             │ MIT          │ /contrib/brotli/LICENSE             │
│ [...]              │ [...]        │ [...]                               │
└────────────────────┴──────────────┴─────────────────────────────────────┘
```
