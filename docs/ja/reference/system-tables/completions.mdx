## 説明 {#description}

補完トークンの一覧が含まれます。

## カラム {#columns}

* `word` ([String](/ja/reference/data-types/string)) — 補完トークン。
* `context` ([String](/ja/reference/data-types/string)) — トークンが表すエンティティの種類 (例: テーブル) 。
* `belongs` ([Nullable(String)](/ja/reference/data-types/nullable)) — このトークンが属するエンティティのトークン (例: 所有元のデータベース名) 。
