<div id="description">
  ## 説明
</div>

すべてのユーザーのクォータ使用状況。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ja/reference/data-types/string)) — クォータ名。
* `quota_key` ([String](/ja/reference/data-types/string)) — キー値。
* `is_current` ([UInt8](/ja/reference/data-types/int-uint)) — 現在のユーザーのクォータ使用状況。
* `start_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — リソース消費量の計算開始時刻。
* `end_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — リソース消費量の計算終了時刻。
* `duration` ([Nullable(UInt32)](/ja/reference/data-types/nullable)) — リソース消費量を計算する時間間隔の長さ (秒) 。
* `queries` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在実行されているクエリ数。
* `max_queries` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 実行可能な全種類のクエリの最大許可数。
* `query_selects` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在実行されているSELECTクエリ数。
* `max_query_selects` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 実行可能なSELECTクエリの最大許可数。
* `query_inserts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在実行されているINSERTクエリ数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 実行可能なINSERTクエリの最大許可数。
* `errors` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在エラーが発生したクエリ数。
* `max_errors` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、エラーが発生したクエリの最大数。
* `result_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における、すべてのクエリの結果セットの合計行数。
* `max_result_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セットの合計行数の最大値。
* `result_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における、すべてのクエリの結果セットの合計バイト数。
* `max_result_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セットの合計バイト数の最大値。
* `read_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における、すべてのクエリの実行中に読み取られた合計行数。
* `max_read_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取る行数の最大値。
* `read_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における、すべてのクエリの実行中に読み取られた合計バイト数。
* `max_read_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取るバイト数の最大値。
* `execution_time` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 現在の期間にクエリの実行に費やされた合計時間 (ナノ秒)
* `max_execution_time` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 指定期間内にすべてのクエリの実行に許可される最大時間 (ナノ秒)
* `written_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における、すべてのクエリの実行中に書き込まれた合計バイト数。
* `max_written_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に書き込むバイト数の最大値。
* `failed_sequential_authentications` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における連続認証失敗回数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される連続認証失敗回数の最大値。
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における、単一の正規化クエリの最大実行回数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、単一の正規化クエリの最大実行回数。
