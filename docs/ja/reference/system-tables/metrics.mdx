## 説明

即座に計算できるメトリクス、または現在の値を持つメトリクスが含まれます。たとえば、同時に処理されているクエリ数や、現在のレプリカ遅延です。このテーブルは常に最新の状態に保たれます。

ZooKeeper へのセッション (connection) の数。1 を超えないようにしてください。ZooKeeper への connection を複数使用すると、ZooKeeper の整合性モデルで許容されている線形化可能性の欠如 (stale reads) により、不具合につながる可能性があるためです。

### ZooKeeperSessionExpired

期限切れとなったグローバルZooKeeperセッション数。

### ZooKeeperWatch

ZooKeeper 内のウォッチ (イベント購読) の数。

## カラム

* `metric` ([String](/ja/reference/data-types/string)) — メトリクス名。
* `value` ([Int64](/ja/reference/data-types/int-uint)) — メトリクス値。
* `description` ([String](/ja/reference/data-types/string)) — メトリクスの説明。

**別名:**
