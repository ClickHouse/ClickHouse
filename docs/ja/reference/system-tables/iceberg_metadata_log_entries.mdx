## 説明 {#description}

このシステムテーブルには、ClickHouse に存在する Iceberg テーブルのメタデータファイルが、メタデータファイルごとに 1 行ずつ格納されます。ClickHouse に Iceberg テーブルが 1 つもない場合、このテーブルは空になります。

## カラム {#columns}

* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `timestamp` ([DateTime64(3)](/ja/reference/data-types/datetime64)) — このメタデータファイルが最新になった日時。
* `file` ([String](/ja/reference/data-types/string)) — メタデータファイルのパス。
* `latest_snapshot_id` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このメタデータファイルの時点における最新スナップショットの ID。
* `latest_schema_id` ([Nullable(Int32)](/ja/reference/data-types/nullable)) — 最新スナップショットのスキーマ ID。
* `latest_sequence_number` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — 最新スナップショットのシーケンス番号。
