## 説明 {#description}

サーバーでサポートされているデータベースエンジンの一覧です。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — データベースエンジンの名前。
* `description` ([String](/ja/reference/data-types/string)) — そのデータベースエンジンの概要説明。
* `syntax` ([String](/ja/reference/data-types/string)) — CREATE DATABASEクエリのENGINE句でデータベースエンジンをどのように指定するか。
* `examples` ([String](/ja/reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/reference/data-types/string)) — そのデータベースエンジンが最初に導入されたClickHouseのバージョン。形式は major.minor。
* `related` ([Array(String)](/ja/reference/data-types/array)) — 関連するデータベースエンジンの名前。

## 例 {#example}

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

│ Atomic   │
│ Ordinary │
