## 説明 {#description}

このテーブルには、値 0 を含む `dummy` UInt8 カラムが 1 つだけある 1 行のデータが含まれます。

このテーブルは、`SELECT` クエリで `FROM` 句が指定されていない場合に使用されます。

これは、他の DBMS にある `DUAL` テーブルに似ています。

## カラム {#columns}

* `dummy` ([UInt8](/ja/reference/data-types/int-uint))

## 例 {#example}

```sql
SELECT * FROM system.one LIMIT 10;
```

```response
┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
```
