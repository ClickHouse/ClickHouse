<div id="description">
  ## 説明
</div>

すべてのフォーマットの一覧に加え、各フォーマットが入力／出力に適しているかどうか、および並列化をサポートしているかどうかを示すフラグが含まれています。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — フォーマット名。
* `is_input` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットがデータ入力に適しているかを示すフラグ。
* `is_output` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットがデータ出力に適しているかを示すフラグ。
* `supports_parallel_parsing` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットが並列パースをサポートしているかを示すフラグ。
* `supports_parallel_formatting` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットが並列フォーマットをサポートしているかを示すフラグ。
* `is_tty_friendly` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットが通常、端末で問題なく表示されるかを示すフラグ。その他のフォーマットでは、CLI は出力前に確認を求めます。
* `content_type` ([String](/ja/reference/data-types/string)) — 出力フォーマットに対応する HTTP Content-Type。現在のフォーマット設定に依存する場合があります。
* `supports_random_access` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットが入力データ内でのランダムアクセスをサポートしているかを示すフラグ。
* `has_schema_inference` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットがデータからスキーマを動的に推論できるかを示します (埋め込みヘッダーやメタデータ、またはデータの一部から推論します) 。
* `has_external_schema` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットが固定スキーマを持つか、独自のフォーマットで事前定義済みのスキーマを受け入れるかを示します。
* `prefers_large_blocks` ([UInt8](/ja/reference/data-types/int-uint)) — フォーマットが出力時により大きなブロックを書き込み、入力時により大きなブロックを生成するかを示します。
* `supports_append` ([UInt8](/ja/reference/data-types/int-uint)) — このフォーマットで単一のファイルに追記できるかを示すフラグ。
* `supports_subsets_of_columns` ([UInt8](/ja/reference/data-types/int-uint)) — 入力フォーマットが特定のカラムの省略を認識できるかを示すフラグ。
* `description` ([String](/ja/reference/data-types/string)) — フォーマットの概要。
* `examples` ([String](/ja/reference/data-types/string)) — 使用例。
* `introduced_in` ([String](/ja/reference/data-types/string)) — フォーマットが最初に導入された ClickHouse のバージョン。形式は major.minor です。
* `related` ([Array(String)](/ja/reference/data-types/array)) — 関連するフォーマットの名前。

{/*AUTOGENERATED_END*/}
