<div id="description">
  ## 説明
</div>

すべてのQUOTAのすべてのインターバルに対する上限情報が含まれます。1 つのQUOTAに対応する行数は、0 行を含め任意です。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ja/reference/data-types/string)) — QUOTA名。
* `duration` ([UInt32](/ja/reference/data-types/int-uint)) — リソース使用量の計算対象となる時間インターバルの長さ (秒) 。
* `is_randomized_interval` ([UInt8](/ja/reference/data-types/int-uint)) — ブール値。インターバルがランダム化されているかどうかを示します。ランダム化されていない場合、インターバルは常に同じ時刻に開始します。たとえば、1分のインターバルは常に分が整数となる時刻に開始します (つまり、11:20:00には開始できますが、11:20:01に開始することはありません) 。1日のインターバルは常にUTCの午前0時に開始します。インターバルがランダム化されている場合、最初のインターバルはランダムな時刻に開始し、その後のインターバルは順次開始します。値: 0 — インターバルはランダム化されていません、1 — インターバルはランダム化されています。
* `max_queries` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に実行できる、すべての種類のクエリの最大数。
* `max_query_selects` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に実行できるSELECTクエリの最大数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に実行できるINSERTクエリの最大数。
* `max_errors` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、エラーが発生したクエリの最大数。
* `max_result_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セットに含まれる行数の合計最大値。
* `max_result_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの結果セットに含まれるバイト数の合計最大値。
* `max_read_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取る行数の最大値。
* `max_read_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に読み取るバイト数の最大値。
* `max_execution_time` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 指定期間内にすべてのクエリで許可される最大実行時間 (ナノ秒)
* `max_written_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、すべてのクエリの実行中に書き込むバイト数の最大値。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される連続した認証失敗の最大数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される、単一の正規化クエリの最大実行回数。
