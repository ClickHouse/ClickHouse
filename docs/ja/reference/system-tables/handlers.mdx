<div id="description">
  ## 説明
</div>

[`CREATE HANDLER`](/ja/reference/statements/create/handler) で作成された、SQL で定義されるすべての HTTP ハンドラーの一覧を含みます。

このテーブルを読み取るには `SHOW HANDLERS` 権限が必要です。この権限がない場合、テーブルは空に見えます。ハンドラーのクエリに
埋め込まれている可能性がある secret (たとえば、テーブル関数に渡す認証情報) は、ユーザーに secret の表示が許可されている場合にのみ、
`query` および `create_query` カラムに表示されます (`display_secrets_in_show_and_select` サーバー設定と `format_display_secrets_in_show_and_select` フォーマット
設定が有効であり、ユーザーが `displaySecretsInShowAndSelect` 権限を持っている場合) 。それ以外の場合は、
`SHOW CREATE TABLE` とまったく同様にマスクされます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/ja/reference/data-types/string)) — ハンドラー名。
* `protocol` ([Nullable(String)](/ja/reference/data-types/nullable)) — ハンドラーが限定されるコンポーザブルプロトコル。すべての HTTP エンドポイント (組み込みの `http`/`https` ポートおよびすべての HTTP タイプのコンポーザブルプロトコルリスナー) でハンドラーが有効な場合は NULL。
* `url_match_type` ([String](/ja/reference/data-types/string)) — URL の照合方法。完全一致、プレフィックス、または正規表現。
* `url` ([String](/ja/reference/data-types/string)) — ハンドラーが照合する URL パターン。
* `methods` ([Array(String)](/ja/reference/data-types/array)) — 許可される HTTP メソッド。
* `type` ([String](/ja/reference/data-types/string)) — ハンドラーのタイプ (サポートされるのは `query` のみ) 。
* `query` ([String](/ja/reference/data-types/string)) — ハンドラーが実行する SQL クエリ。ユーザーに閲覧権限がない場合、secret は非表示になります。
* `create_query` ([String](/ja/reference/data-types/string)) — CREATE HANDLER ステートメント。ユーザーに閲覧権限がない場合、secret は非表示になります。

{/*AUTOGENERATED_END*/}
