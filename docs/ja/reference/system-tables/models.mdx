## Description {#description}

<Warning>
  CatBoost インテグレーションは ClickHouse から削除され、`system.models` も存在しなくなりました。クエリを実行すると `UNKNOWN_TABLE` で失敗します。このページは、かつて公開されていたドキュメントとして残しています。現在提供されているテーブルについては、[システムテーブルの概要](/ja/reference/system-tables/overview) を参照してください。
</Warning>

`LibraryBridge` のメモリに読み込まれた CatBoost モデルの一覧と、その読み込み時刻を保持していました。

## カラム {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/ja/reference/data-types/string)) — 学習済みモデルへのパス。
* `type` ([String](/ja/reference/data-types/string)) — モデルのタイプ。現在は catboost のみです。
* `loading_start_time` ([DateTime](/ja/reference/data-types/datetime)) — モデルの読み込みが開始された時刻。
* `loading_duration` ([Float32](/ja/reference/data-types/float)) — モデルの読み込みに要した時間。

{/*AUTOGENERATED_END*/}
