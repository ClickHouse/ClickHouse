<div id="description">
  ## 説明
</div>

現在、分片間で移動中のパーツと、その進捗に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — 移動を実行するデータベースの名前。
* `table` ([String](/ja/reference/data-types/string)) — 移動を実行するテーブルの名前。
* `task_name` ([String](/ja/reference/data-types/string)) — 移動タスクの名前。
* `task_uuid` ([UUID](/ja/reference/data-types/uuid)) — 移動タスクの識別子。
* `create_time` ([DateTime](/ja/reference/data-types/datetime)) — タスクの作成時刻。
* `part_name` ([String](/ja/reference/data-types/string)) — 移動中のパーツの名前。
* `part_uuid` ([UUID](/ja/reference/data-types/uuid)) — 移動中のパーツの UUID。
* `to_shard` ([String](/ja/reference/data-types/string)) — 宛先分片の名前。
* `dst_part_name` ([String](/ja/reference/data-types/string)) — 移動後のパーツ名。
* `update_time` ([DateTime](/ja/reference/data-types/datetime)) — 最終更新時刻。
* `state` ([String](/ja/reference/data-types/string)) — 移動の現在の状態。
* `rollback` ([UInt8](/ja/reference/data-types/int-uint)) — 操作がロールバックされたかどうかを示すフラグ。
* `num_tries` ([UInt32](/ja/reference/data-types/int-uint)) — 操作を完了するまでの試行回数。
* `last_exception` ([String](/ja/reference/data-types/string)) — 発生した場合は最後の例外名。

{/*AUTOGENERATED_END*/}
