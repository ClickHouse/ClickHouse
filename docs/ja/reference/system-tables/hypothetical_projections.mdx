現在のセッションで定義されたすべての仮説的 (what-if) projection を一覧表示します。[`CREATE HYPOTHETICAL PROJECTION`](/ja/reference/statements/hypothetical-projection#create-hypothetical-projection) および [`EXPLAIN WHATIF`](/ja/reference/statements/explain#explain-whatif) を参照してください。

内容はセッション単位のスコープを持ちます。各接続は自身の仮説的 projection のみを参照でき、現在のセッションで作成されたものがない場合、このテーブルは空になります。

現在の `(database, table)` はクエリ実行時に UUID を用いて解決されるため、`RENAME TABLE` の結果が反映され、削除されたテーブルのエントリは自動的に非表示になります。

## カラム {#columns}

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — データベース名
* `table` ([String](/ja/reference/data-types/string)) — テーブル名
* `name` ([String](/ja/reference/data-types/string)) — PROJECTION 名
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/ja/reference/data-types/enum)) — PROJECTION の種類
* `sorting_key` ([Array(String)](/ja/reference/data-types/array)) — PROJECTION のソートキー
* `query` ([String](/ja/reference/data-types/string)) — PROJECTION の SELECT クエリ。INDEX ... TYPE ... 形式の場合は空
* `definition` ([String](/ja/reference/data-types/string)) — 記述されたままの完全な PROJECTION 宣言
* `settings` ([Map(String, String)](/ja/reference/data-types/map)) — WITH SETTINGS で指定された PROJECTION の設定

{/*AUTOGENERATED_END*/}

**例**

```sql
CREATE HYPOTHETICAL PROJECTION p_by_b ON t (SELECT a, b ORDER BY b);
SELECT name, type, sorting_key FROM system.hypothetical_projections;
```

```text
┌─name───┬─type───┬─sorting_key─┐
│ p_by_b │ Normal │ ['b']       │
└────────┴────────┴─────────────┘
```
