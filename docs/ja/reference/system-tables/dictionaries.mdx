<div id="description">
  ## 説明
</div>

[Dictionary](/ja/reference/statements/create/dictionary) に関する情報が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — DDLクエリで作成されたDictionaryを含むデータベース名。その他のDictionaryでは空文字列です。
* `name` ([String](/ja/reference/data-types/string)) — Dictionary名。
* `uuid` ([UUID](/ja/reference/data-types/uuid)) — DictionaryのUUID。
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/ja/reference/data-types/enum)) — Dictionaryのステータス。設定可能な値: NOT&#95;LOADED — Dictionaryが現在メモリにロードされていない、LOADED — Dictionaryが正常にロードされた、FAILED — エラーによりDictionaryをロードできない、LOADING — Dictionaryを現在ロード中、LOADED&#95;AND&#95;RELOADING — Dictionaryが正常にロードされており、現在再ロード中 (一般的な理由: SYSTEM RELOAD DICTIONARYクエリ、timeout、Dictionaryの設定変更) 、FAILED&#95;AND&#95;RELOADING — エラーによりDictionaryをロードできず、現在ロード中。
* `origin` ([String](/ja/reference/data-types/string)) — Dictionaryを定義する設定ファイルのパス。
* `type` ([String](/ja/reference/data-types/string)) — Dictionaryの割り当てタイプ。Dictionaryをメモリに格納します。
* `key.names` ([Array(String)](/ja/reference/data-types/array)) — Dictionaryで指定されたキー名のArray。
* `key.types` ([Array(String)](/ja/reference/data-types/array)) — Dictionaryで指定された対応するキー型のArray。
* `attribute.names` ([Array(String)](/ja/reference/data-types/array)) — Dictionaryで指定されたattribute名のArray。
* `attribute.types` ([Array(String)](/ja/reference/data-types/array)) — Dictionaryで指定された対応するattribute型のArray。
* `bytes_allocated` ([UInt64](/ja/reference/data-types/int-uint)) — Dictionaryに割り当てられたRAMの量。
* `hierarchical_index_bytes_allocated` ([UInt64](/ja/reference/data-types/int-uint)) — 階層索引に割り当てられたRAMの量。
* `query_count` ([UInt64](/ja/reference/data-types/int-uint)) — Dictionaryがロードされてから、または最後に正常に再起動されてからのクエリ数。
* `hit_rate` ([Float64](/ja/reference/data-types/float)) — cache Dictionaryの場合、値がcache内に存在した使用の割合。
* `found_rate` ([Float64](/ja/reference/data-types/float)) — 値が見つかった使用の割合。
* `element_count` ([UInt64](/ja/reference/data-types/int-uint)) — Dictionaryに格納されている項目数。
* `load_factor` ([Float64](/ja/reference/data-types/float)) — Dictionaryの使用率 (hashed Dictionaryの場合は、hash tableの使用率) 。
* `source` ([String](/ja/reference/data-types/string)) — Dictionaryのデータソースを説明するテキスト。
* `lifetime_min` ([UInt64](/ja/reference/data-types/int-uint)) — メモリ内のDictionaryの最小lifetime。この時間が経過すると、ClickHouseはDictionaryの再ロードを試みます (invalidate&#95;queryが設定されている場合は、変更されているときのみ) 。Seconds単位で設定します。
* `lifetime_max` ([UInt64](/ja/reference/data-types/int-uint)) — メモリ内のDictionaryの最大lifetime。この時間が経過すると、ClickHouseはDictionaryの再ロードを試みます (invalidate&#95;queryが設定されている場合は、変更されているときのみ) 。Seconds単位で設定します。
* `loading_start_time` ([DateTime](/ja/reference/data-types/datetime)) — Dictionaryのロード開始時刻。
* `last_successful_update_time` ([DateTime](/ja/reference/data-types/datetime)) — Dictionaryのロードまたは更新の終了時刻。Dictionary ソースに関する問題の監視や原因の調査に役立ちます。
* `error_count` ([UInt64](/ja/reference/data-types/int-uint)) — 最後に正常にロードされてからのエラー数。Dictionary ソースに関する問題の監視や原因の調査に役立ちます。
* `loading_duration` ([Float32](/ja/reference/data-types/float)) — Dictionaryのロード時間。
* `last_exception` ([String](/ja/reference/data-types/string)) — Dictionaryを作成できなかった場合に、作成または再ロード時に発生したエラーのテキスト。
* `comment` ([String](/ja/reference/data-types/string)) — Dictionaryに付加されたコメントのテキスト。

{/*AUTOGENERATED_END*/}

<div id="example">
  ## 例
</div>

Dictionary を設定します。

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

Dictionary が読み込まれていることを確認してください。

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
