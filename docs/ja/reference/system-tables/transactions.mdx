## Description {#description}

トランザクションとその状態の一覧が格納されます。

**Availability**

`system.transactions` は、`allow_experimental_transactions` サーバー設定オプションが有効な場合にのみ作成されます。デフォルトではこのテーブルは存在せず、このテーブルに対するクエリは `UNKNOWN_TABLE` エラーで失敗します。サーバー設定で次のように有効化してください:

```xml
<clickhouse>
    <allow_experimental_transactions>1</allow_experimental_transactions>
</clickhouse>
```

## カラム {#columns}

* `tid` ([Tuple(UInt64, UInt64, UUID, Int64)](/ja/reference/data-types/tuple)) — トランザクションの識別子。
* `tid_hash` ([UInt64](/ja/reference/data-types/int-uint)) — 識別子のハッシュ値。
* `elapsed` ([Float64](/ja/reference/data-types/float)) — トランザクションの処理にかかる時間。
* `is_readonly` ([UInt8](/ja/reference/data-types/int-uint)) — トランザクションで書き込み操作が実行されていないかどうかを示すフラグ。
* `state` ([Enum8(&#39;RUNNING&#39; = 0, &#39;COMMITTING&#39; = 1, &#39;COMMITTED&#39; = 2, &#39;ROLLED&#95;BACK&#39; = 3)](/ja/reference/data-types/enum)) — トランザクションの状態。設定可能な値: RUNNING, COMMITTING, COMMITTED, ROLLED&#95;BACK.
