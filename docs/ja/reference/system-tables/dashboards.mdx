## 説明 {#description}

[HTTPインターフェイス](/ja/concepts/features/interfaces/http) 経由でアクセスできる `/dashboard` ページで使用されるクエリが格納されています。
このテーブルは、監視やトラブルシューティングに役立ちます。ダッシュボード内の各チャートについて1行が含まれます。

<Note>
  `/dashboard` ページでは、`system.dashboards` のクエリだけでなく、同じスキーマを持つ任意のテーブルのクエリもレンダリングできます。
  これは、カスタムダッシュボードの作成に役立ちます。
</Note>

組み込みのダッシュボードチャートは、`system.metric_log` と `system.asynchronous_metric_log` から読み取ります。これらのチャートすべてにデータを表示するには、サーバー設定で [`metric_log`](/ja/reference/settings/server-settings/settings/other#metric_log) と [`asynchronous_metric_log`](/ja/reference/settings/server-settings/settings/asynchronous#asynchronous_metric_log) の両方のログを有効にしてください。

## カラム {#columns}

{/*AUTOGENERATED_START*/}

* `dashboard` ([String](/ja/reference/data-types/string)) — ダッシュボードの名前。
* `title` ([String](/ja/reference/data-types/string)) — チャートのタイトル。
* `query` ([String](/ja/reference/data-types/string)) — 表示するデータを取得するためのクエリ。

{/*AUTOGENERATED_END*/}

## 例 {#example}

```sql
SELECT *
FROM system.dashboards
WHERE title ILIKE '%CPU%'
```
