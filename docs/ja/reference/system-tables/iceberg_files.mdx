<div id="description">
  ## 説明
</div>

このシステムテーブルには、ClickHouse に存在する Icebergテーブルについて、ファイルごとのメタデータが格納されています。各テーブルの現在のスナップショットで参照されているデータファイルまたは削除ファイルごとに、1行が対応します。ClickHouse に Icebergテーブルが1つも存在しない場合、このテーブルは空になります。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `snapshot_id` ([Int64](/ja/reference/data-types/int-uint)) — ファイルが追加されたスナップショット ID。
* `content` ([Enum8(&#39;DATA&#39; = 0, &#39;POSITION&#95;DELETE&#39; = 1, &#39;EQUALITY&#95;DELETE&#39; = 2)](/ja/reference/data-types/enum)) — ファイルコンテンツの種類。
* `file_path` ([String](/ja/reference/data-types/string)) — 解決後のファイルストレージパス。
* `file_format` ([String](/ja/reference/data-types/string)) — ファイルフォーマット (例: &#39;PARQUET&#39;) 。
* `record_count` ([Int64](/ja/reference/data-types/int-uint)) — ファイル内のレコード数。
* `file_size_in_bytes` ([Int64](/ja/reference/data-types/int-uint)) — ファイルサイズ (バイト単位) 。
* `partition` ([String](/ja/reference/data-types/string)) — パーティションタプルのテキスト表現。
* `schema_id` ([Int32](/ja/reference/data-types/int-uint)) — このマニフェストエントリに対して解決されたスキーマ ID。
* `sequence_number` ([Int64](/ja/reference/data-types/int-uint)) — マニフェストエントリに対して解決されたシーケンス番号 (フォーマット v1 では常に 0) 。
* `sort_order_id` ([Nullable(Int32)](/ja/reference/data-types/nullable)) — 指定されている場合のファイルのソート順 ID。
* `null_value_counts` ([Map(Int32, Int64)](/ja/reference/data-types/map)) — カラムごとの NULL 値数 (カラム ID -&gt; 件数) 。
* `column_sizes` ([Map(Int32, Int64)](/ja/reference/data-types/map)) — カラムごとのオンディスクサイズ (バイト単位、カラム ID -&gt; バイト数) 。
* `value_counts` ([Map(Int32, Int64)](/ja/reference/data-types/map)) — カラムごとの値の合計数 (カラム ID -&gt; 件数) 。
* `equality_ids` ([Array(Int32)](/ja/reference/data-types/array)) — equality delete ファイルの等価フィールド ID (equality delete ファイル以外では空) 。
