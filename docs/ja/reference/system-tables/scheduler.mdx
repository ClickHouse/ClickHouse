<div id="description">
  ## 説明
</div>

ローカルサーバー上に存在する[スケジューリングノード](/ja/concepts/features/configuration/server-config/workload-scheduling#hierarchy)に関する情報と状態を含みます。
このテーブルは監視に利用できます。各 スケジューリングノード につき1行が含まれます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `resource` ([String](/ja/reference/data-types/string)) — リソース名
* `path` ([String](/ja/reference/data-types/string)) — このリソーススケジューリング階層内のスケジューリングノードのパス
* `type` ([String](/ja/reference/data-types/string)) — スケジューリングノードのタイプ
* `weight` ([Float64](/ja/reference/data-types/float)) — `fair` タイプの親ノードで使用されるノードの重み
* `priority` ([Int64](/ja/reference/data-types/int-uint)) — &#39;priority&#39; タイプの親ノードで使用されるノードの優先度 (値が小さいほど優先度が高い)
* `precedence` ([Int64](/ja/reference/data-types/int-uint)) — admission とエビクションの順序付けに使用される、space-shared (メモリ) 親ノードのノード優先順位 (値が小さいほど優先順位が高い)
* `is_active` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — このノードが現在アクティブかどうか。アクティブな場合、キューから取り出すリソースリクエストがあり、制約が満たされています
* `active_children` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — アクティブ状態にある子ノードの数
* `dequeued_requests` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このノードからキュー取り出しされたリソースリクエストの総数
* `canceled_requests` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このノードからキャンセルされたリソースリクエストの総数
* `rejected_requests` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このノードから拒否されたリソースリクエストの総数
* `dequeued_cost` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — このノードからキュー取り出しされたすべてのリクエストのコスト (例: バイト単位のサイズ) の合計
* `canceled_cost` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — このノードからキャンセルされたすべてのリクエストのコスト (例: バイト単位のサイズ) の合計
* `rejected_cost` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — このノードから拒否されたすべてのリクエストのコスト (例: バイト単位のサイズ) の合計
* `busy_periods` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このノードが非アクティブ化された総数
* `throughput` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 現在の平均スループット (1 秒あたりのキュー取り出しコスト)
* `vruntime` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — `fair` ノードの子ノードの場合のみ。SFQ アルゴリズムが max-min fair 方式で次に処理する子ノードを選択する際に使用する、ノードの仮想ランタイム
* `system_vruntime` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — `fair` ノードの場合のみ。最後に処理されたリソースリクエストの `vruntime` を示す仮想ランタイム。子ノードのアクティブ化時に `vruntime` の新しい値として使用されます
* `queue_length` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — `fifo` ノードの場合のみ。キュー内にあるリソースリクエストの現在の数
* `queue_cost` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — fifo ノードの場合のみ。キュー内にあるすべてのリクエストのコスト (例: バイト単位のサイズ) の合計
* `budget` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — fifo ノードの場合のみ。新しいリソースリクエストに使用できる &#39;コスト単位&#39; の数。リソースリクエストの推定コストと実際のコストに差異がある場合 (例: 読み取り/書き込みの失敗後) に表示されることがあります
* `is_satisfied` ([Nullable(UInt8)](/ja/reference/data-types/nullable)) — 制約ノードの場合のみ (例: `inflight_limit`) 。このノードのすべての制約が満たされている場合は `1` です
* `inflight_requests` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — `inflight_limit` ノードの場合のみ。このノードからキュー取り出しされ、現在使用中のリソースリクエストの数
* `inflight_cost` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — `inflight_limit` ノードの場合のみ。このノードからキュー取り出しされ、現在使用中のすべてのリソースリクエストのコスト (例: バイト) の合計
* `max_requests` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — `inflight_limit` ノードの場合のみ。制約違反につながる inflight&#95;requests の上限
* `max_cost` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — `inflight_limit` ノードのみ。制約違反を引き起こす inflight&#95;cost の上限。
* `max_speed` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — `bandwidth_limit` ノードのみ。1 秒あたりのトークン数で表した帯域幅の上限。
* `max_burst` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — `bandwidth_limit` ノードのみ。トークンバケットスロットラーで使用可能なトークン数の上限。
* `throttling_us` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — `bandwidth_limit` ノードのみ。このノードがスロットリング状態にあった合計マイクロ秒数。
* `tokens` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — `bandwidth_limit` ノードのみ。トークンバケットスロットラーで現在使用可能なトークン数。
* `allocated` ([Nullable(Int64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノード配下で現在割り当てられているリソース量。
* `allocations` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノード配下で現在実行中のリソース割り当て数。
* `updates` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードを通じて伝播された更新の合計数。
* `increases` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードが承認した増加リクエストの合計数。
* `decreases` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードが承認した減少リクエストの合計数。
* `admits` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードが受け入れた割り当ての合計数。
* `removes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードから削除された割り当ての合計数。
* `killers` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードへの増加リクエストにより開始されたエビクションの合計数。
* `victims` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — space-shared ノードのみ。このノードから追い出された割り当ての合計数。
* `rejects` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — `allocation_queue` ノードのみ。このノードで拒否されたリソース割り当ての合計数。
* `pending` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — `allocation_queue` ノードのみ。このノード内で保留中のリソース割り当て数。

{/*AUTOGENERATED_END*/}

```sql
SELECT *
FROM system.scheduler
WHERE resource = 'network_read' AND path = '/prio/fair/prod'
FORMAT Vertical
```
