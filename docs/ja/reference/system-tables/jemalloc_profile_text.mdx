## 説明 {#description}

シンボル化された jemalloc ヒーププロファイルを表示します。先に &#39;SYSTEM JEMALLOC FLUSH PROFILE&#39; を実行して、プロファイルを生成してください。

## カラム {#columns}

* `line` ([String](/ja/reference/data-types/string)) — シンボル化された jemalloc ヒーププロファイル内の行。
