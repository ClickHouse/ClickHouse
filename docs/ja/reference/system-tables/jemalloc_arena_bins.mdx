## 説明 {#description}

`system.jemalloc_bins` と同様ですが、アリーナ全体で集計するのではなく、(アリーナ、ビン) ごとに1行を持ちます。スラブは1つのアリーナに属するため、このテーブルでは特定のアリーナ (専用の MergeTree メタデータ、JIT、cache アリーナを含む) 内のフラグメンテーションを特定し、`arena` とサイズクラスの両方をキーとして `system.jemalloc_sampled_allocations` と結合します。

## カラム {#columns}

{/*AUTOGENERATED_START*/}

* `arena` ([UInt32](/ja/reference/data-types/int-uint)) — アリーナの索引。`system.jemalloc_sampled_allocations.arena` と結合します。
* `purpose` ([String](/ja/reference/data-types/string)) — 専用の長期存続アリーナの用途: &#39;mergetree&#39; (partおよびtableのメタデータ) 、&#39;jit&#39;、&#39;cache&#39;。汎用アリーナでは空です。専用アリーナは設計上、長期存続する割り当てを保持するため、通常、フラグメンテーションレポートからは除外されます。
* `index` ([UInt16](/ja/reference/data-types/int-uint)) — サイズ順に並べられたビンの索引。
* `large` ([UInt8](/ja/reference/data-types/int-uint)) — 大きな割り当ての場合はTrue、小さな割り当ての場合はFalse。
* `size` ([UInt64](/ja/reference/data-types/int-uint)) — このビン内の割り当てのサイズ。
* `allocations` ([Int64](/ja/reference/data-types/int-uint)) — 割り当て数。
* `deallocations` ([Int64](/ja/reference/data-types/int-uint)) — 解放数。
* `nregs` ([Int64](/ja/reference/data-types/int-uint)) — スラブあたりのregion数。
* `curslabs` ([Int64](/ja/reference/data-types/int-uint)) — 現在のスラブ数。
* `curregs` ([Int64](/ja/reference/data-types/int-uint)) — このサイズクラスの現在のregion数。
* `slab_size` ([UInt64](/ja/reference/data-types/int-uint)) — 各スラブのサイズ (バイト単位) 。スラブベースではない大きなサイズクラスではゼロです。
* `nonfull_slabs` ([Int64](/ja/reference/data-types/int-uint)) — 少なくとも1つの空きregionを含むスラブの現在の数。大きなサイズクラスではゼロです。

**別名:**

* `availregs` — `nregs * curslabs` の別名。
* `util` — `curregs / availregs` の別名。
* `waste` — `greatest((curslabs * slab_size) - (curregs * size), 0)` の別名。
