<div id="description">
  ## 説明
</div>

サーバーが認識している各テーブルのメタデータが含まれています。

[デタッチされた](/ja/reference/statements/detach) テーブルは `system.tables` には表示されません。

[一時テーブル](/ja/reference/statements/create/table/temporary-table) は、作成されたセッションでのみ `system.tables` に表示されます。これらは `database` フィールドが空で、`is_temporary` フラグがオンの状態で表示されます。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/ja/reference/data-types/string)) — テーブルが属するデータベースの名前。
* `name` ([String](/ja/reference/data-types/string)) — テーブル名。
* `uuid` ([UUID](/ja/reference/data-types/uuid)) — テーブルの UUID (Atomic データベース) 。
* `engine` ([String](/ja/reference/data-types/string)) — テーブルエンジン名 (パラメーターを除く) 。
* `is_temporary` ([UInt8](/ja/reference/data-types/int-uint)) — テーブルが一時テーブルかどうかを示すフラグ。
* `data_paths` ([Array(String)](/ja/reference/data-types/array)) — ファイルシステム内のテーブルデータへのパス。
* `metadata_path` ([String](/ja/reference/data-types/string)) — ファイルシステム内のテーブルメタデータへのパス。
* `metadata_modification_time` ([DateTime](/ja/reference/data-types/datetime)) — テーブルメタデータの最終変更時刻。
* `metadata_version` ([Int32](/ja/reference/data-types/int-uint)) — ReplicatedMergeTree テーブルのメタデータバージョン。ReplicatedMergeTree 以外のテーブルでは 0。
* `dependencies_database` ([Array(String)](/ja/reference/data-types/array)) — データベースの依存関係。
* `dependencies_table` ([Array(String)](/ja/reference/data-types/array)) — テーブルの依存関係 (現在のテーブルに依存する materialized view) 。
* `create_table_query` ([String](/ja/reference/data-types/string)) — テーブルの作成に使用されたクエリ。
* `engine_full` ([String](/ja/reference/data-types/string)) — テーブルエンジンのパラメーター。
* `as_select` ([String](/ja/reference/data-types/string)) — ビューの SELECT クエリ。
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/ja/reference/data-types/array)) — パラメーター化ビューのパラメーター。
* `partition_key` ([String](/ja/reference/data-types/string)) — テーブルで指定されたパーティションキー式。
* `sorting_key` ([String](/ja/reference/data-types/string)) — テーブルで指定されたソートキー式。
* `primary_key` ([String](/ja/reference/data-types/string)) — テーブルで指定された主キー式。
* `sampling_key` ([String](/ja/reference/data-types/string)) — テーブルで指定されたサンプリングキー式。
* `unique_key` ([String](/ja/reference/data-types/string)) — テーブルで指定された一意キー式 (UNIQUE KEY 句) 。
* `skipping_indices_types` ([Array(String)](/ja/reference/data-types/array)) — テーブルに定義された異なる種類のデータスキッピングインデックスの配列 (例：minmax、set、bloom&#95;filter、ngrambf&#95;v1、tokenbf&#95;v1、text、vector&#95;similarity) 。スキップインデックスのないテーブルでは空です。
* `storage_policy` ([String](/ja/reference/data-types/string)) — ストレージポリシー。MergeTree および Distributed エンジンを使用するテーブルに該当します。
* `total_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — テーブル内の正確な行数を迅速に取得できる場合は総行数、それ以外の場合は NULL (基盤となる Buffer table を含む) 。
* `total_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ストレージ上のテーブルの正確なバイト数を迅速に取得できる場合は総バイト数、それ以外の場合は NULL (基盤となるストレージは含まない) 。テーブルがディスクにデータを保存する場合は、ディスクの使用領域 (圧縮後のサイズ) を返します。テーブルがメモリにデータを保存する場合は、メモリで使用される推定バイト数を返します。
* `total_bytes_uncompressed` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — ストレージ上のテーブルのパーツのチェックサムから正確なバイト数を迅速に取得できる場合は非圧縮の総バイト数、それ以外の場合は NULL (基盤となるストレージがある場合も考慮しない) 。
* `parts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このテーブル内のパーツの総数。
* `active_parts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このテーブル内のアクティブなパーツの数。
* `total_marks` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — このテーブル内のすべてのパーツに含まれるマークの総数。
* `active_on_fly_data_mutations` ([UInt64](/ja/reference/data-types/int-uint)) — オンザフライで適用可能なアクティブなデータミューテーション (UPDATE および DELETE) の総数。
* `active_on_fly_alter_mutations` ([UInt64](/ja/reference/data-types/int-uint)) — オンザフライで適用可能なアクティブな ALTER ミューテーション (MODIFY COLUMN) の総数。
* `active_on_fly_metadata_mutations` ([UInt64](/ja/reference/data-types/int-uint)) — オンザフライで適用可能なアクティブなメタデータミューテーション (RENAME) の総数。
* `columns_descriptions_cache_size` ([UInt64](/ja/reference/data-types/int-uint)) — *MergeTree テーブルのカラム記述 cache のサイズ。
* `lifetime_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — サーバー起動以降に INSERT された行の総数 (Buffer テーブルのみ) 。
* `lifetime_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — サーバー起動以降に INSERT されたバイト数の合計 (Buffer テーブルのみ) 。
* `comment` ([String](/ja/reference/data-types/string)) — テーブルのコメント。
* `has_own_data` ([UInt8](/ja/reference/data-types/int-uint)) — テーブル自体がディスク上にデータを保存しているか、別のソースにアクセスしているだけかを示すフラグ。
* `loading_dependencies_database` ([Array(String)](/ja/reference/data-types/array)) — データベースのロード依存関係 (現在のオブジェクトより先にロードする必要があるオブジェクトのリスト) 。
* `loading_dependencies_table` ([Array(String)](/ja/reference/data-types/array)) — テーブルのロード依存関係 (現在のオブジェクトより先にロードする必要があるオブジェクトのリスト) 。
* `loading_dependent_database` ([Array(String)](/ja/reference/data-types/array)) — ロード時に依存するデータベース。
* `loading_dependent_table` ([Array(String)](/ja/reference/data-types/array)) — ロード時に依存するテーブル。
* `target_database` ([String](/ja/reference/data-types/string)) — materialized view の場合、view が書き込む宛先テーブルのデータベース (`TO` ターゲット、または暗黙的な `.inner.*` テーブル) 。他のエンジンでは空です。
* `target_table` ([String](/ja/reference/data-types/string)) — materialized view の場合、view が書き込む宛先テーブルの名前 (`TO` ターゲット、または暗黙的な `.inner.*` テーブル) 。他のエンジンでは空です。
* `definer` ([String](/ja/reference/data-types/string)) — テーブルに使用される SQL security definer の名前。

**別名:**

* `table` — `name` の別名。

{/*AUTOGENERATED_END*/}
