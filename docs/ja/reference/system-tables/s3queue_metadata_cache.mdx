## 説明 {#description}

S3Queue メタデータのインメモリ状態と、ファイルごとの現在処理中の行が含まれます。

## カラム {#columns}

* `zookeeper_path` ([String](/ja/reference/data-types/string)) — ZooKeeper 内のメタデータへのパス
* `file_path` ([String](/ja/reference/data-types/string)) — 処理中のファイルのパス
* `file_name` ([String](/ja/reference/data-types/string)) — 処理中のファイル名
* `rows_processed` ([UInt64](/ja/reference/data-types/int-uint)) — 現在処理中の行数
* `status` ([String](/ja/reference/data-types/string)) — 処理ステータス: Processed、Processing、Failed、または cache が認識しているものの状態を持たないファイル (処理が reset されたファイルなど) の場合は None。`processing_observed_in_keeper_time` が非 NULL の場合、`Processing` ステータスはそのファイルを保持している processor が設定したものではなく、Keeper から読み取られたものであることを意味します
* `processing_start_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — ファイルの処理開始時刻
* `processing_end_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — ファイルの処理終了時刻
* `exception` ([String](/ja/reference/data-types/string)) — 処理中に発生した例外。常にこの server による最後の試行のものであり、Keeper がそのファイルについて保存しているものではありません
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — この server の processor がファイルを取得できず、自身で `Processing` ステータスを設定する代わりに Keeper から読み取った時刻。通常はそのファイルを別の server が保持していますが、直前にファイルを取得したこの server の processor が保持している場合もあります。いずれの場合も、`rows_processed`、`processing_start_time`、`processing_end_time`、`exception` は、現在そのファイルを保持している処理ではなく、この server がそのファイルを処理しようとした最後の試行を表します
