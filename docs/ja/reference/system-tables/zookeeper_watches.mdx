## 説明 {#description}

この ClickHouseサーバー が ZooKeeper ノード (補助的な ZooKeeper を含む) に登録している、現在有効な [ウォッチ](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches) を表示します。各行は 1 つのウォッチを表します。

**可用性**

`system.zookeeper_watches` は ClickHouse Keeper または ZooKeeper が設定されている場合にのみ存在します。どちらも設定されていないサーバーではこのテーブルは存在せず、このテーブルに対するクエリは `UNKNOWN_TABLE` で失敗します。

## カラム {#columns}

* `zookeeper_name` ([String](/ja/reference/data-types/string)) — ZooKeeper 接続の名前 (メイン接続では &quot;default&quot;、または補助名) 。
* `create_time` ([DateTime](/ja/reference/data-types/datetime)) — ウォッチが作成された時刻。
* `create_time_microseconds` ([DateTime64(6)](/ja/reference/data-types/datetime64)) — ウォッチがマイクロ秒精度で作成された時刻。
* `path` ([String](/ja/reference/data-types/string)) — 監視対象の ZooKeeper パス。
* `session_id` ([Int64](/ja/reference/data-types/int-uint)) — ウォッチを登録した接続のセッション ID。
* `request_xid` ([Int64](/ja/reference/data-types/int-uint)) — ウォッチを作成したリクエストの XID。
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/ja/reference/data-types/enum)) — ウォッチを作成した操作。
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/ja/reference/data-types/enum)) — ウォッチの種類: Children (list) 、Exists、または Data (get) 。
