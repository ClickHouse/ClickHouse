<div id="description">
  ## 説明
</div>

[MergeTree](/ja/reference/engines/table-engines/mergetree-family/mergetree) テーブルのパーツに関する情報を含みます。

各行は 1 つのデータパーツを表します。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/ja/reference/data-types/string)) — パーティション識別子 (テーブルのパーティションキー式から導出された文字列表現) 。
* `name` ([String](/ja/reference/data-types/string)) — データパートの名前。パートの命名規則から、データ、取り込み、マージのパターンに関するさまざまな情報を把握できます。パートの命名フォーマットは次のとおりです。

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * 定義:
    * `partition_id` - パーティションキーを識別します
    * `minimum_block_number` - パーツ内の最小ブロック番号を識別します。ClickHouse は常に連続したブロックをマージします
    * `maximum_block_number` - パーツ内の最大ブロック番号を識別します
    * `level` - パーツに対してマージが行われるたびに 1 ずつ増加します。レベルが 0 の場合は、まだマージされていない新しいパーツであることを示します。ClickHouse のすべてのパーツは常に不変であることに注意してください
    * `data_version` - パーツが変更されると増加するオプションの値です (繰り返しになりますが、パーツは不変であるため、変更後のデータは常に新しいパーツにのみ書き込まれます)
* `uuid` ([UUID](/ja/reference/data-types/uuid)) — データパーツの UUID。
* `part_type` ([String](/ja/reference/data-types/string)) — データパーツの保存フォーマット。設定可能な値: `Wide` — 各カラムを個別のファイルに保存、`Compact` — すべてのカラムを1つのファイルに保存。データの保存フォーマットは、MergeTree テーブルの `min_bytes_for_wide_part` および `min_rows_for_wide_part` 設定で制御されます。
* `part_storage_type` ([String](/ja/reference/data-types/string)) — `DataPartStorage` のタイプ。設定可能な値: `Packed` - ほとんどのパーツファイルを単一のアーカイブに保存します (プロジェクションおよび `txn_version.txt` など一部のサービスファイルは個別に書き込まれます) 、`Full` - 各ファイルを個別に保存します。
* `active` ([UInt8](/ja/reference/data-types/int-uint)) — データパーツがアクティブかどうかを示すフラグ。アクティブなデータパーツはテーブルで使用されます。非アクティブなデータパーツは削除予定です。非アクティブなデータパーツは、マージおよびミューテーション操作後に現れます。
* `marks` ([UInt64](/ja/reference/data-types/int-uint)) — マーク数。データパーツ内の行数の概算値を取得するには、マーク数に索引粒度 (通常は8192) を乗算します (この方法は適応型粒度では使用できません) 。
* `rows` ([UInt64](/ja/reference/data-types/int-uint)) — 行数。
* `files` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内のファイル数。
* `bytes_on_disk` ([UInt64](/ja/reference/data-types/int-uint)) — すべてのデータパーツファイルの合計サイズ (バイト単位) 。
* `data_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内の圧縮データの合計サイズ。補助ファイル (たとえばマークファイル) は含まれません。
* `data_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内の非圧縮データの合計サイズ。補助ファイル (たとえばマークファイル) は含まれません。
* `primary_key_size` ([UInt64](/ja/reference/data-types/int-uint)) — ディスク上の primary.idx/cidx ファイル内で主キー値が使用するメモリ量 (バイト単位) 。
* `marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — マークファイルのサイズ。
* `secondary_indices_compressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内のセカンダリ索引の圧縮データの合計サイズ。補助ファイル (たとえばマークファイル) は含まれません。
* `secondary_indices_uncompressed_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツ内のセカンダリ索引の非圧縮データの合計サイズ。補助ファイル (たとえばマークファイル) は含まれません。
* `secondary_indices_marks_bytes` ([UInt64](/ja/reference/data-types/int-uint)) — セカンダリ索引用マークファイルのサイズ。
* `modification_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツを含むディレクトリが変更された時刻。通常はデータパーツの作成時刻に対応します。
* `remove_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツが非アクティブになった時刻。
* `refcount` ([UInt32](/ja/reference/data-types/int-uint)) — データパーツが使用されている箇所の数。値が2より大きい場合、データパーツはクエリまたはマージで使用されています。
* `min_date` ([Date](/ja/reference/data-types/date)) — データパーツ内の日付キーの最小値。
* `max_date` ([Date](/ja/reference/data-types/date)) — データパーツ内の日付キーの最大値。
* `min_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最小値。
* `max_time` ([DateTime](/ja/reference/data-types/datetime)) — データパーツ内の日付と時刻キーの最大値。
* `partition_id` ([String](/ja/reference/data-types/string)) — パーティションの ID。
* `min_block_number` ([Int64](/ja/reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最小番号。
* `max_block_number` ([Int64](/ja/reference/data-types/int-uint)) — マージ後に現在のパーツを構成するデータパーツの最大番号。
* `level` ([UInt32](/ja/reference/data-types/int-uint)) — マージツリーの深さ。0 は、現在のパーツが他のパーツのマージではなく insert によって作成されたことを示します。
* `data_version` ([UInt64](/ja/reference/data-types/int-uint)) — データパーツに適用する mutation (data&#95;version より大きいバージョンの mutation) を決定するための番号。
* `primary_key_bytes_in_memory` ([UInt64](/ja/reference/data-types/int-uint)) — 主キー値が使用するメモリ量 (バイト単位) 。`primary_key_lazy_load` が有効でキーがロードされていない場合は 0 になります。0 以外の場合、これらのバイトはパーツ自体に保持され、`jemalloc.mergetree_arena.active_bytes` に計上されます。`PrimaryIndexCacheBytes` には決して計上されません。パーツごとにいずれか一方のみが使用され、`primary_key_lazy_load` と `use_primary_key_cache` に応じて、索引はパーツ内 (このメトリクス) または共有 `PrimaryIndexCache` (もう一方) に存在します。
* `primary_key_bytes_in_memory_allocated` ([UInt64](/ja/reference/data-types/int-uint)) — 主キー値用に確保されたメモリ量 (バイト単位) 。`primary_key_lazy_load` が有効でキーがロードされていない場合は 0 になります。0 以外の場合は、`jemalloc.mergetree_arena.active_bytes` に含まれます。`PrimaryIndexCacheBytes` との関係については、`primary_key_bytes_in_memory` の注記を参照してください。
* `index_granularity_bytes_in_memory` ([UInt64](/ja/reference/data-types/int-uint)) — 索引粒度値が使用するメモリ量 (バイト単位)  (primary&#95;key&#95;lazy&#95;load=1 かつ use&#95;primary&#95;key&#95;cache=1 の場合は 0) 。0 以外の場合、これらのバイトはパーツに属し、`jemalloc.mergetree_arena.active_bytes` に計上されます。
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/ja/reference/data-types/int-uint)) — 索引粒度値用に確保されたメモリ量 (バイト単位)  (primary&#95;key&#95;lazy&#95;load=1 かつ use&#95;primary&#95;key&#95;cache=1 の場合は 0) 。0 以外の場合は、`jemalloc.mergetree_arena.active_bytes` に含まれます。
* `is_frozen` ([UInt8](/ja/reference/data-types/int-uint)) — パーティションデータのバックアップが存在することを示すフラグ。1 はバックアップが存在することを、0 は存在しないことを示します。詳細については、FREEZE PARTITION を参照してください。
* `database` ([String](/ja/reference/data-types/string)) — データベース名。
* `table` ([String](/ja/reference/data-types/string)) — テーブル名。
* `engine` ([String](/ja/reference/data-types/string)) — パラメータを除くテーブルエンジン名。
* `disk_name` ([String](/ja/reference/data-types/string)) — データパーツを格納するディスクの名前。
* `path` ([String](/ja/reference/data-types/string)) — データパーツのファイルがあるフォルダーへの絶対パス。
* `hash_of_all_files` ([String](/ja/reference/data-types/string)) — 圧縮ファイルの sipHash128。
* `hash_of_uncompressed_files` ([String](/ja/reference/data-types/string)) — 非圧縮ファイル (マーク、索引ファイルなど) の sipHash128。
* `uncompressed_hash_of_compressed_files` ([String](/ja/reference/data-types/string)) — 圧縮ファイル内のデータを非圧縮として扱った場合の sipHash128。
* `delete_ttl_info_min` ([DateTime](/ja/reference/data-types/datetime)) — TTL DELETE ルールの日時キーの最小値。
* `delete_ttl_info_max` ([DateTime](/ja/reference/data-types/datetime)) — TTL DELETE ルールの日時キーの最大値。
* `move_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — 式の Array。各式は TTL MOVE ルールを定義します。
* `move_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — 日時値の Array。各要素は TTL MOVE ルールの最小キー値を示します。
* `move_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — 日時値の Array。各要素は TTL MOVE ルールの最大キー値を示します。
* `default_compression_codec` ([String](/ja/reference/data-types/string)) — カラムに明示的な codec が指定されていない場合、または `CODEC(Default)` を使用している場合に、このデータパートの圧縮に使用される codec の名前です。`allow_experimental_adaptive_codec_selection` を使用すると、このようなカラムの個々のブロックで別の codec が使用される場合があります。詳細は [`mergeTreeCodecBlockCounts`](/ja/reference/functions/table-functions/mergeTreeCodecBlockCounts) を参照してください。
* `recompression_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — TTL 式。
* `recompression_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最小値。有効期限 (TTL) が切れた行が少なくとも 1 行あるかどうかの判断に使用します。
* `recompression_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最大値。すべての行の有効期限 (TTL) が切れているかどうかの判断に使用します。
* `group_by_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — TTL 式。
* `group_by_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最小値。有効期限 (TTL) が切れた行が少なくとも 1 行あるかどうかの判断に使用します。
* `group_by_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最大値。すべての行の有効期限 (TTL) が切れているかどうかの判断に使用します。
* `rows_where_ttl_info.expression` ([Array(String)](/ja/reference/data-types/array)) — TTL 式。
* `rows_where_ttl_info.min` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最小値。有効期限 (TTL) が切れた行が少なくとも 1 行あるかどうかの判断に使用します。
* `rows_where_ttl_info.max` ([Array(DateTime)](/ja/reference/data-types/array)) — このパート内で計算された TTL 式の最大値。すべての行の有効期限 (TTL) が切れているかどうかの判断に使用します。
* `projections` ([Array(String)](/ja/reference/data-types/array)) — このパートに対して計算された projection 名のリスト。
* `visible` ([UInt8](/ja/reference/data-types/int-uint)) — このパートが SELECT クエリから参照可能かどうかを示すフラグ。
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/ja/reference/data-types/tuple)) — このオブジェクトを作成した、または作成しようとしている transaction の ID。
* `removal_tid_lock` ([UInt64](/ja/reference/data-types/int-uint)) — removal&#95;tid の hash。削除時にオブジェクトを lock するために使用します。
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/ja/reference/data-types/tuple)) — このオブジェクトを削除した、または削除しようとしている transaction の ID。
* `creation_csn` ([UInt64](/ja/reference/data-types/int-uint)) — このオブジェクトを作成した transaction の CSN。
* `removal_csn` ([UInt64](/ja/reference/data-types/int-uint)) — このオブジェクトを削除した transaction の CSN。
* `has_lightweight_delete` ([UInt8](/ja/reference/data-types/int-uint)) — このパートに論理削除マスクがあるかどうかを示すフラグ。
* `last_removal_attempt_time` ([DateTime](/ja/reference/data-types/datetime)) — server がこのパートの削除を最後に試行した時刻。
* `removal_state` ([String](/ja/reference/data-types/string)) — パート削除プロセスの現在の状態。

**別名:**

* `bytes` — `bytes_on_disk` の別名。
* `marks_size` — `marks_bytes` の別名。
* `part_name` — `name` の別名。
