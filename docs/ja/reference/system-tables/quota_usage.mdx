<div id="description">
  ## 説明
</div>

現在のユーザーの クォータ使用状況: 使用量と残量。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/ja/reference/data-types/string)) — QUOTA 名。
* `quota_key` ([String](/ja/reference/data-types/string)) — キー値。
* `start_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — リソース消費量の計算開始時刻。
* `end_time` ([Nullable(DateTime)](/ja/reference/data-types/nullable)) — リソース消費量の計算終了時刻。
* `duration` ([Nullable(UInt32)](/ja/reference/data-types/nullable)) — リソース消費量の計算対象となる時間間隔の長さ (秒) 。
* `queries` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在実行されているクエリ数。
* `max_queries` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 実行可能な全種類のクエリの最大数。
* `query_selects` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在実行されている SELECT クエリ数。
* `max_query_selects` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 実行可能な SELECT クエリの最大数。
* `query_inserts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在実行されている INSERT クエリ数。
* `max_query_inserts` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 実行可能な INSERT クエリの最大数。
* `errors` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在発生しているエラークエリ数。
* `max_errors` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可されるエラークエリ数の上限。
* `result_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における全クエリの結果セット内の行数合計。
* `max_result_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される全クエリの結果セット内の行数合計の上限。
* `result_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における全クエリの結果セットのバイト数合計。
* `max_result_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される全クエリの結果セットのバイト数合計の上限。
* `read_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における全クエリの実行時に読み取られた行数合計。
* `max_read_rows` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に全クエリの実行時に読み取ることが許可される行数の上限。
* `read_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における全クエリの実行時に読み取られたバイト数合計。
* `max_read_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に全クエリの実行時に読み取ることが許可されるバイト数の上限。
* `execution_time` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 現在の期間にクエリの実行に費やされた時間の合計 (ナノ秒)
* `max_execution_time` ([Nullable(Float64)](/ja/reference/data-types/nullable)) — 指定期間内に全クエリの実行に許可される時間の上限 (ナノ秒)
* `written_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における全クエリの実行時に書き込まれたバイト数合計。
* `max_written_bytes` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に全クエリの実行時に書き込むことが許可されるバイト数の上限。
* `failed_sequential_authentications` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における連続認証失敗数。
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される連続認証失敗数の上限。
* `queries_per_normalized_hash` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 現在の期間における単一の正規化クエリの最大実行回数。
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — 指定期間内に許可される単一の正規化クエリの最大実行回数。
