## Description {#description}

このテーブルには、ClickHouseサーバーに関する警告が表示されます。
同じ種類の警告は、1つの警告にまとめられます。
例えば、アタッチされたデータベースの数 N が設定可能なしきい値 T を超えた場合、N 個の個別のエントリではなく、現在の値 N を含む単一のエントリが表示されます。
現在の値がしきい値を下回ると、そのエントリはテーブルから削除されます。

このテーブルは、以下の設定で構成できます:

* [max&#95;table&#95;num&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/ja/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/ja/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## カラム {#columns}

* `message` ([String](/ja/reference/data-types/string)) — ClickHouseサーバー が出力した警告メッセージ。
* `message_format_string` ([LowCardinality(String)](/ja/reference/data-types/lowcardinality)) — メッセージの整形に使用された書式文字列。

## 例 {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
