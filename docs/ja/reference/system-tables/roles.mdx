## 説明 {#description}

設定されている[ロール](/ja/concepts/features/security/access-rights#role-management)に関する情報を含みます。

## カラム {#columns}

* `name` ([String](/ja/reference/data-types/string)) — ロール名。
* `id` ([UUID](/ja/reference/data-types/uuid)) — ロール ID。
* `storage` ([String](/ja/reference/data-types/string)) — ロールのストレージへのパス。`access_control_path` パラメータで設定します。
