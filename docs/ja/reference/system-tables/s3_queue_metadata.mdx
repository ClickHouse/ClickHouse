<div id="description">
  ## 説明
</div>

各 S3Queue メタデータオブジェクトについて、Keeper 内の処理済み、処理中、失敗したノードの現在数と、必要に応じてその内容を表示します。インメモリ cache を表示する system.s3queue&#95;metadata&#95;cache とは異なり、この テーブル は状態を Keeper から直接読み取ります。

<div id="columns">
  ## カラム
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/ja/reference/data-types/string)) — ZooKeeper 内のメタデータへのパス。補助的な ZooKeeper 上のキューの場合、これは生の Keeper パスではなく、ファクトリキー `<zookeeper_name>:<path>` です。
* `processed_nodes_count` ([Nullable(UInt64)](/ja/reference/data-types/nullable)) — Keeper の `processed` ディレクトリ内のノード数。`unordered` モードでのみ設定されます。`ordered` モードではファイルごとの処理済みノードが存在しないため (代わりに `processed_path` を参照) 、値は NULL になります。
* `processing_nodes_count` ([UInt64](/ja/reference/data-types/int-uint)) — Keeper の `processing` ディレクトリ内のノード数
* `failed_nodes_count` ([UInt64](/ja/reference/data-types/int-uint)) — Keeper の `failed` ディレクトリ内のノード数
* `processed_nodes` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper の `processed` ディレクトリの内容 (ノード名 -&gt; ノードデータ) 。`unordered` モードでのみ設定されます。このカラムが選択された場合にのみ取得されます。
* `processing_nodes` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper の `processing` ディレクトリの内容 (ノード名 -&gt; ノードデータ) 。このカラムが選択された場合にのみ取得されます。
* `failed_nodes` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper の `failed` ディレクトリの内容 (ノード名 -&gt; ノードデータ) 。このカラムが選択された場合にのみ取得されます。
* `processed_path` ([Map(String, String)](/ja/reference/data-types/map)) — Keeper 内の処理済みポインタごとの最終処理済みパス (相対ポインタパス -&gt; 最終処理済みファイルパス) 。単一ポインタ、バケットごとのポインタ、パーティションごとのポインタを対象とする `ordered` モードでのみ設定されます。このカラムが選択された場合にのみ取得されます。
