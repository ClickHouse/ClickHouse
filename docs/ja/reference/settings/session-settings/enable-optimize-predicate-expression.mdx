## enable_optimize_predicate_expression_to_final_subquery {#enable_optimize_predicate_expression_to_final_subquery}

<SettingsInfoBlock type="Bool" default_value="1" />

リモートサーバーに送信されるクエリが `FINAL` を使用している場合に、元のクエリのフィルタをそのクエリへ追加することを許可します(たとえば、`Distributed`テーブルから読み取る場合)。これにより、リモートサーバーから返されるデータ量を削減できます。

無効の場合、フィルタはこのようなクエリには追加されず、リモートサーバーからデータを受信した後にのみ適用されます。
