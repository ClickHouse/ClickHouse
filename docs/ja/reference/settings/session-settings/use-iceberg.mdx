## use_iceberg_manifest_list_partition_pruning {#use_iceberg_manifest_list_partition_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "マニフェストリストのパーティションサマリーがクエリフィルターと一致し得ない Iceberg マニフェストファイルを、読み取らずにスキップする新しい設定。"}]}]} />

マニフェストリスト内のパーティションサマリーがクエリフィルターと一致し得ない Iceberg マニフェストファイル全体を、読み取らずにスキップします。[use&#95;iceberg&#95;partition&#95;pruning](/ja/reference/settings/session-settings/use-iceberg#use_iceberg_partition_pruning) を有効にする必要があります。また、マニフェストファイルに含まれる異なるパーティション値が少ない場合にのみ効果があります。これは、パーティションカラムでクラスター化された `rewriteManifests` によって生成される状態です。

## use_iceberg_metadata_files_cache {#use_iceberg_metadata_files_cache}

<SettingsInfoBlock type="Bool" default_value="1" />

## use_iceberg_table_statistics_ndv {#use_iceberg_table_statistics_ndv}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "結合順序の変更に使用する Iceberg カラムの異なる値の数を、`metadata.json` 内のテーブル統計から取得する新しい設定。"}]}]} />

[`use_datalake_metadata_statistics`](/ja/reference/settings/session-settings/use#use_datalake_metadata_statistics) が有効な場合、マニフェストファイルに異なる値の数が含まれていない Iceberg カラムについて、その値を `metadata.json` 内のテーブル統計から取得します。具体的には、Spark の `compute_table_stats` または Trino の `ANALYZE` によって書き込まれた、そのカラムのみを対象とする `apache-datasketches-theta-v1` ブロブの `ndv` プロパティを使用します。使用されるのは、読み取り対象のスナップショットから計算されたブロブのみです。これらの値は結合順序の変更と条件の推定にのみ使用され、クエリ結果に影響することはありません。
