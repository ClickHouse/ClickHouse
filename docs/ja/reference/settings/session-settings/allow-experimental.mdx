## allow_experimental_analyzer {#allow_experimental_analyzer}

**別名**: `enable_analyzer`

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "この設定は廃止されました。アナライザが必須となり、旧クエリ分析はサポートされなくなりました。無効化しようとする変更はエラーにはならず、`1` に置き換えられます。また、24.3 未満のバージョンとの `compatibility` によって元に戻ることもなくなりました。"}]}, {"id": "row-2","items": [{"label": "24.8"},{"label": "1"},{"label": "別名 `enable_analyzer` を追加しました。"}]}, {"id": "row-3","items": [{"label": "24.3"},{"label": "1"},{"label": "アナライザとプランナーをデフォルトで有効にします。"}]}]} />

v26.9 以降、この設定は廃止されています。アナライザは無効化できなくなりました。

アナライザは、v24.3 以降デフォルトで使用されているクエリ分析およびプランニングのインフラストラクチャです。v26.9 でこの設定は唯一サポートされる値である `1` に固定され、`compatibility` 設定でも元に戻せなくなりました。v26.10 では、この設定によって切り替えられていた旧クエリ分析が削除されました。後方互換性のため、`0` を設定してもエラーにはならず、`1` に置き換えられます。そのため、`enable_analyzer = 0` を設定したままのクエリ、セッション設定、設定プロファイル、クライアント設定も引き続き動作し、アナライザが使用されます。旧クエリ分析でのクエリの動作やパフォーマンスと比較するには、v26.9 より前の ClickHouse バージョンを使用してください。
