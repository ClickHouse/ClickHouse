## allow_experimental_analyzer {#allow_experimental_analyzer}

**別名**: `enable_analyzer`

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "この設定は廃止されました。アナライザが必須となり、旧クエリ分析はサポートされなくなりました。無効化しようとすると無視されるのではなく拒否され、24.3 未満のバージョンとの `compatibility` によって元に戻ることもなくなりました。"}]}, {"id": "row-2","items": [{"label": "24.3"},{"label": "1"},{"label": "アナライザとプランナーをデフォルトで有効にします。"}]}]} />

v26.9 以降、この設定は廃止されています。アナライザは無効化できなくなりました。

アナライザは、v24.3 以降デフォルトで使用されているクエリ分析およびプランニングのインフラストラクチャです。v26.9 でこの設定は唯一サポートされる値である `1` に固定されました。`0` に設定しようとすると拒否され、`compatibility` 設定でも元に戻せなくなりました。v26.10 では、この設定によって切り替えられていた旧クエリ分析が削除されました。クエリ、セッション設定、設定プロファイル、クライアント設定から `enable_analyzer = 0` を削除してください。旧クエリ分析でのクエリの動作やパフォーマンスと比較するには、v26.9 より前の ClickHouse バージョンを使用してください。
