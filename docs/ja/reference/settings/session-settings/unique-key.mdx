<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "auto"},{"label": "新しい設定: UNIQUE KEY プローブ実装を選択します（現在利用可能なのは単純なベースラインのみです）"}]}]} />

UNIQUE KEY の書き込みパスで使用するプローブ実装を選択します。現在利用可能なのはシングルスレッドの
ベースラインのみであるため、`auto` と `simple` はどちらもこれに解決されます。

予約済み: この設定はまだ有効ではありません。プローブを構築する UNIQUE KEY INSERT の
書き込みパスが実装されるまで、この値は読み取られません。実装とともにこの設定を提供できるよう、あらかじめ宣言されています。
