  ## enable_parallel_blocks_marshalling
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.6"},{"label": "true"},{"label": "新しい設定"}]}]} />

分散クエリにのみ影響します。有効にすると、ブロックはイニシエーターへの送信前後に、パイプラインスレッドで (逆) シリアル化および (逆) 圧縮されます (つまり、デフォルトよりも高い並列度で実行されます) 。

<div id="enable_parallel_single_level_merge">
  ## enable_parallel_single_level_merge
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "キー空間を互いに重複しないハッシュパーティションに分割し、各スレッドが独立してマージすることで、単一レベル集約ハッシュテーブルの最終マージを並列化する新しい設定。"}]}]} />

スレッドごとの単一レベル集約ハッシュテーブルの最終マージを並列化します。キー空間はキーハッシュに基づいて互いに重複しないパーティションに分割され、各パーティションは独立してマージされます。マージスレッドは各スレッドのすべてのテーブルを走査し、自身のパーティションに属するキーを結合するため、同じキーを複数のスレッドが処理することはありません。この設定をオフにすると、単一レベルテーブルは1つのスレッドで直列にマージされます。8 ビットおよび16 ビットのキーによる集約では、この設定にかかわらず、独自の範囲パーティション化された並列マージが行われます。
