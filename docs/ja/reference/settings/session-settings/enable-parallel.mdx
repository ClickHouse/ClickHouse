## enable_parallel_single_level_merge {#enable_parallel_single_level_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "キー空間を互いに重複しないハッシュパーティションに分割し、各スレッドが独立してマージすることで、単一レベル集約ハッシュテーブルの最終マージを並列化する新しい設定。"}]}]} />

スレッドごとの単一レベル集約ハッシュテーブルの最終マージを並列化します。キー空間はキーハッシュに基づいて互いに重複しないパーティションに分割され、各パーティションは独立してマージされます。マージスレッドは各スレッドのすべてのテーブルを走査し、自身のパーティションに属するキーを結合するため、同じキーを複数のスレッドが処理することはありません。この設定をオフにすると、単一レベルテーブルは1つのスレッドで直列にマージされます。8 ビットおよび16 ビットのキーによる集約では、この設定にかかわらず、独自の範囲パーティション化された並列マージが行われます。

## enable_parallel_single_level_merge_by_index {#enable_parallel_single_level_merge_by_index}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "1"},{"label": "新しい設定。並列マージ時に、パーティションごとにすべてのテーブルのすべてのセルをスキャンするのではなく、セルの索引を介して、アダプティブアグリゲータの単一レベルハッシュテーブルから各パーティションのセルのみを読み取れるようにします。"}]}]} />

単一レベルの集約ハッシュテーブルの並列マージ (`enable_parallel_single_level_merge` を参照) で、アダプティブアグリゲータ (`enable_adaptive_aggregator` を参照) のテーブルをセルの索引を介して読み取れるようにします。この索引は、各スレッドが集約を終えた時点で構築します。これにより、マージ処理ではパーティションごとに、各テーブルからそのパーティションに属するセルのみを読み取ります。この設定を無効にすると、マージ処理はパーティションごとにすべてのテーブルのすべてのセルをスキャンします。
