## use_page_cache_for_object_storage {#use_page_cache_for_object_storage}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "オブジェクトストレージのテーブル関数でユーザー空間のページキャッシュを使用するための新しい設定"}]}, {"id": "row-2","items": [{"label": "26.12"},{"label": "1"},{"label": "サーバーでページキャッシュが設定されている場合、オブジェクトストレージのテーブルエンジンとテーブル関数でユーザー空間のページキャッシュをデフォルトで使用します。"}]}]} />

オブジェクトストレージのテーブル関数 (s3、azure、hdfs、Iceberg、Delta Lake など) およびテーブルエンジン (S3、Azure、HDFS、Iceberg、Delta Lake など) からの読み取り時に、ユーザー空間のページキャッシュを使用します。サーバーでユーザー空間のページキャッシュが設定されている場合 (`page_cache_max_size`) にのみ有効です。対象となるのは、強い ETag を持つオブジェクト、またはテーブルのレコードから取得した不変のアイデンティティを持つオブジェクト (Iceberg および Delta Lake のデータファイル) のみです。ファイルシステムキャッシュとは併用されません。分散キャッシュとの併用は、`use_page_cache_with_distributed_cache` も有効になっている場合に限られます。

## use_page_cache_lookahead_for_text_index {#use_page_cache_lookahead_for_text_index}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "新しい設定"}]}]} />

テキスト索引のファイルのうち、ファイル内の順序どおりに読み取られないもの (辞書、ポスティングリスト、位置情報) は、デフォルトでは 1 ブロック分の先読みでユーザー空間のページキャッシュを介して読み取られます。これにより、読み取りのたびにリモート接続を再利用できます。この設定を有効にすると、これらのファイルも他のファイルと同様に `page_cache_lookahead_blocks` を使用するようになります。
