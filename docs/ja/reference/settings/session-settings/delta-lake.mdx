## delta_lake_accurate_write_cast {#delta_lake_accurate_write_cast}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "新しい設定: 書き込む値を Delta の書き込みスキーマの型へ accurate cast でキャストし、変換先の型に収まらない値は暗黙的に切り詰めるのではなく例外をスローします。26.9 未満の `compatibility` 設定では、例外をスローしない通常のキャストが使用されます。"}]}]} />

Delta Lake テーブルへ書き込む際、各値を Delta の書き込みスキーマの型へ accurate cast でキャストし、変換先の型に収まらない値があれば例外をスローします (例: Delta の `byte` カラムに `300` を書き込む場合) 。通常のキャストでは、このような値は暗黙的に切り詰められます。例外をスローしない通常のキャストを使用するには、`false` に設定するか、26.9 未満の `compatibility` 設定を使用してください。
