## iceberg_insert_max_bytes_in_data_file {#iceberg_insert_max_bytes_in_data_file}

<SettingsInfoBlock type="UInt64" default_value="536870912" />

挿入操作時の iceberg parquet データファイルの最大バイト数です。

デフォルト値は、Iceberg テーブルプロパティ `write.target-file-size-bytes` のドキュメント記載のデフォルト値 (512 MiB) に合わせています。
https://iceberg.apache.org/docs/1.5.2/configuration/ を参照してください。ただし、ClickHouse はこの上限を、それまでにファイルへ書き込まれたデータの
非圧縮サイズと比較するのに対し、Iceberg のプロパティは生成されるファイル自体のサイズを対象としている点に注意してください。また、`iceberg_insert_max_rows_in_data_file` は
サイズとは無関係にファイルを制限します。
