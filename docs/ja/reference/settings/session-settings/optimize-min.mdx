## optimize_min_max_from_files {#optimize_min_max_from_files}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Parquet のカラム chunk 統計情報から `min` \/ `max` を計算する新しい設定。"}]}]} />

集約関数がテーブルカラムに対する `min` と `max` のみで、`GROUP BY` もフィルタも含まないクエリに対して、データを読み取る代わりに、データファイルに保存済みの統計情報からカラムの `min` と `max` を計算する機能を有効または無効にします。この設定は、`Parquet` フォーマットを使用するテーブル関数/エンジン `file` に適用されます (アーカイブ内のファイルは対象外) 。対象となるのは、すべての行グループにカラム chunk 統計情報が存在する、整数 (最大 64 ビット) 、日付、日時、および Decimal 型のカラムです。

設定可能な値:

* 0 - 最適化無効。
* 1 - 最適化有効。
