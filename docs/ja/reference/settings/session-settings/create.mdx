## create_if_not_exists {#create_if_not_exists}

## create_token_default_ttl_seconds {#create_token_default_ttl_seconds}

<SettingsInfoBlock type="UInt64" default_value="1800" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1800"},{"label": "明示的な `VALID UNTIL` または `VALID FOR` 句を指定せずに `CREATE TOKEN` で作成されたトークンに有効期間を与える新しい設定。このステートメント自体が新規のため、復元すべき以前の挙動は存在せず、以前の値はデフォルト値そのものです。古いバージョンとの `compatibility` によってトークンが無期限になってはなりません。"}]}]} />

[`CREATE TOKEN`](/ja/reference/statements/create/token) で作成され、独自の `VALID UNTIL` または `VALID FOR` 句を指定しないトークンに与えられる有効期間 (秒単位) です。デフォルトは 30 分であり、明示的にそれより長い有効期間を指定しないトークンは短命となります。

設定可能な値:

* 正の整数 — トークンは作成から指定した秒数後に失効します。
* 0 — 明示的な句を持たないトークンは失効しません。

これはあくまでデフォルト値です。クエリで明示的に指定された `VALID UNTIL` または `VALID FOR` 句が常に優先されます。`VALID UNTIL 'infinity'` を指定した場合も同様で、この設定に関係なく失効しないトークンが作成されます。
