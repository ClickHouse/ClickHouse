## query_cache_max_entries {#query_cache_max_entries}

## query_cache_nondeterministic_function_handling {#query_cache_nondeterministic_function_handling}

<SettingsInfoBlock type="QueryResultCacheNondeterministicFunctionHandling" default_value="throw" />

`rand()` や `now()` などの非決定論的関数を含む `SELECT` クエリを、[query cache](/ja/concepts/features/performance/caches/query-cache) がどのように扱うかを制御します。

## query_cache_on_disk_cache_name {#query_cache_on_disk_cache_name}

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": ""},{"label": "query cacheのエントリを、指定した名前のファイルシステムキャッシュを使ってディスク上に保存するための新しい設定。"}]}]} />

[query cache](/ja/concepts/features/performance/caches/query-cache)のエントリをディスク上に保存するファイルシステムキャッシュ (サーバー設定の `filesystem_caches` セクション内のエントリ) の名前です。名前が指定されている場合 (かつ [use&#95;query&#95;cache](/ja/reference/settings/session-settings/use-query#use_query_cache) が有効な場合) 、クエリ結果は指定されたファイルシステムキャッシュにも追加でキャッシュされ、そこからも結果が返されます。ディスク上のquery cacheは、インメモリのquery cacheより大きな容量を確保でき、サーバーを再起動しても失われず、インメモリのquery cacheとは独立して動作します。具体的には、設定 [enable&#95;reads&#95;from&#95;query&#95;cache&#95;on&#95;disk](/ja/reference/settings/session-settings/enable#enable_reads_from_query_cache_on_disk) および [enable&#95;writes&#95;to&#95;query&#95;cache&#95;on&#95;disk](/ja/reference/settings/session-settings/enable#enable_writes_to_query_cache_on_disk) によって、インメモリのquery cacheとは別に制御されます。ファイルシステムキャッシュ内のこれらのエントリは、ファイルシステムキャッシュの通常のエントリとして扱われます。つまり、削除から保護されることはなく、キャッシュ内の他のデータと同じルールで追い出されます。`SYSTEM CLEAR FILESYSTEM CACHE '<name>'` を実行すると、これらのエントリはファイルシステムキャッシュ内の他のすべてのデータとともに削除されます。一方、`SYSTEM CLEAR QUERY CACHE` は、この設定で指定されたファイルシステムキャッシュからディスク上のquery cacheのエントリのみを削除し、その他のデータはそのまま残します。クエリ結果専用のファイルシステムキャッシュを用意することを推奨します。

設定可能な値:

* 空文字列 - ディスク上のquery cacheは無効になります
* 事前に設定済みのファイルシステムキャッシュの名前

## query_cache_share_between_users {#query_cache_share_between_users}

<SettingsInfoBlock type="Bool" default_value="0" />

有効にすると、[クエリキャッシュ](/ja/concepts/features/performance/caches/query-cache)にキャッシュされた`SELECT`クエリの結果を、他のユーザーも参照できるようになります。
セキュリティ上の理由から、この設定を有効にすることは推奨されません。

設定可能な値:

* 0 - 無効
* 1 - 有効
