## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "ネットワークトラフィックを削減するため、client/server 間および server/server 間の通信における既定の圧縮方式を `LZ4` から `ZSTD` に変更しました。"}]}]} />

ネイティブプロトコル経由の client/server 間および server/server 間の通信を圧縮するためのコーデックです。

この設定は distributed queries のストリーミング交換チャネルには適用されません。このチャネルでは常にサーバーの default コーデックが使用されます。圧縮された各 frame は self-describing であるため、receiver がコーデックを自動的に検出します。

設定可能な値:

* `NONE` — 圧縮しません。
* `LZ4` — LZ4 コーデックを使用します。
* `LZ4HC` — LZ4HC コーデックを使用します。
* `ZSTD` — ZSTD コーデックを使用します。

## network_zstd_compression_level {#network_zstd_compression_level}

<SettingsInfoBlock type="Int64" default_value="3" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "3"},{"label": "ネットワークの `ZSTD` 圧縮レベルのデフォルトを、新しいディスク上の `ZSTD(3)` 圧縮のデフォルトに合わせました。"}]}]} />

ZSTD の圧縮レベルを調整します。[network&#95;compression&#95;method](/ja/reference/settings/session-settings/network#network_compression_method) が `ZSTD` に設定されている場合にのみ使用されます。

設定可能な値:

* 1 ～ 15 の正の整数。
