## opentelemetry_trace_stateless_worker_discovery {#opentelemetry_trace_stateless_worker_discovery}

<CloudOnlyBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "クエリが worker をプロビジョニングする際に発行する、ステートレスワーカーのディスカバリーサービスへのリクエストについて、OpenTelemetry スパンを収集する新しい設定。"}]}]} />

ClickHouse Cloud でのみ有効。クエリ自体がトレースされている場合に、そのクエリが worker をプロビジョニング (リース) する際に発行する、ステートレスワーカーのディスカバリーサービスへのリクエストについて OpenTelemetry スパンを収集します。
スパン名は `StatelessWorkerDiscovery.<action>` で、属性 `clickhouse.discovery.action` と `clickhouse.discovery.status` が付与されます。
