## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "新しいCloud設定"}]}]} />

ClickHouse Cloud でのみ有効です。write buffer ごとに、分散キャッシュサーバーへ書き込まれるバッファの最大サイズです。object storage へ書き込まれるバッファとは独立しており、そちらは upload の part size に向かって拡大し続けます。0 の場合は `DBMS_DEFAULT_BUFFER_SIZE` (1 MiB) が使用されます。バッファは `adaptive_write_buffer_initial_size` から始まり、ストリームの書き込みが進むにつれてこのサイズまで拡大します。これにより、part が書き込むストリームごとにこのサイズを割り当てずに済みます。
