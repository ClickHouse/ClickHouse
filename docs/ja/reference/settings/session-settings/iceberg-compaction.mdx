## iceberg_compaction_max_bytes_to_merge {#iceberg_compaction_max_bytes_to_merge}

<SettingsInfoBlock type="UInt64" default_value="161061273600" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "161061273600"},{"label": "新しい設定。`MergeTree` における `max_bytes_to_merge_at_max_space_in_pool` と同様に、コンパクションによるマージの対象となるファイルの合計サイズを制限します。"}]}]} />

Icebergテーブルにおいて、1 回のコンパクションによるマージでマージされるデータファイルの最大合計サイズ (オブジェクトストレージ上でのサイズの合計) です。
`MergeTree` における `max_bytes_to_merge_at_max_space_in_pool` と同様に、バックグラウンドプールの空きエントリ数が
`number_of_free_entries_in_pool_to_lower_max_size_of_merge` を下回ると、この上限は `max_bytes_to_merge_at_min_space_in_pool` まで引き下げられます
(いずれも設定の `merge_tree` セクションで指定します) 。
パーティション内のファイルのうち上限に収まらないものは、後続のマージでマージされます。なお、この設定は position delete ファイルを適用するマージには適用されません。

## iceberg_compaction_max_rows_to_merge {#iceberg_compaction_max_rows_to_merge}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "18446744073709551615"},{"label": "新しい設定。以前は `iceberg_compaction_max_rows_in_data_file` で制御されていた、コンパクションによるマージ対象ファイルの合計行数の上限を再導入します。"}]}]} />

Icebergテーブルの 1 回のコンパクションによるマージでマージされるデータファイルの合計行数の上限。
パーティション内でこの上限に収まらないファイルは、後続のマージで処理されます。position delete ファイルを適用するマージには、この上限は適用されません。
