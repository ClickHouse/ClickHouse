## text_index_like_min_pattern_length {#text_index_like_min_pattern_length}

辞書スキャンによるテキスト索引の LIKE 評価を使用するために必要な、LIKE/ILIKE パターン内の英数字 needle、または `startsWith`/`endsWith` の needle の最小長です。

`use_text_index_like_evaluation_by_dictionary_scan` を有効にする必要があります。

## text_index_posting_list_apply_mode {#text_index_posting_list_apply_mode}

## text_index_postings_intersection_algorithm {#text_index_postings_intersection_algorithm}

<SettingsInfoBlock type="TextIndexPostingsIntersectionAlgorithm" default_value="auto" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "auto"},{"label": "`text_index_lazy_intersection_density_threshold` に代わる新しい設定です。遅延ポスティングリスト適用モードで使用するポスティングリストの積集合アルゴリズムを選択します。`auto` は従来のデフォルト動作を維持するため、`compatibility` によって変更してはなりません。"}]}]} />

遅延ポスティングリスト適用モード (`text_index_posting_list_apply_mode = 'lazy'`) で、ポスティングリストの積集合を求めるアルゴリズムを選択します。

* `auto` (デフォルト) : 最もスパースなポスティングリストが、最も密なポスティングリストのパック済みブロックを丸ごとスキップできる場合にのみ leapfrog を使用し、それ以外の場合は総当たりのビットマップ積集合を使用します。
* `bruteforce`: 常に総当たりのビットマップ積集合を使用します。
* `leapfrog`: 常に leapfrog 積集合を使用します。

256 個以上のトークンの積集合を求める場合は、常に leapfrog が使用されます。
