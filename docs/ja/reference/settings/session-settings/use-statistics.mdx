## use_statistics_for_min_max_aggregation {#use_statistics_for_min_max_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "`GROUP BY` とフィルタを伴わない `min`、`max`、`count` の集計を、統計情報が materialize 済みのパーツについてはパーツごとのカラム STATISTICS から返し、残りのパーツのみを読み取る新しい設定。previous_value=false のため、26.9 より前のバージョンとの `compatibility` 設定ではこの最適化は無効のままとなり、従来の実行プランが復元されます。"}]}]} />

`min`、`max`、`count` の集計を、データを読み取る代わりにパーツごとのカラム STATISTICS から返します。

有効な場合、`GROUP BY` とフィルタを伴わない `SELECT min(column), max(column), count() FROM table` の形式のクエリは、
統計情報が materialize 済みのデータパーツについてはカラム STATISTICS (例: minmax 統計情報。`auto_statistics_types` MergeTree 設定を参照) から返され、
残りのパーツのみが読み取られます。

設定可能な値:

* 0 — 無効。
* 1 — 有効。

## use_statistics_for_part_pruning {#use_statistics_for_part_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1"},{"label": "クエリ実行時のパーツ剪枝でSTATISTICSを使用するための新しい設定。"}]}]} />

クエリ実行時に、STATISTICSを使用してパーツを絞り込みます。

有効にすると、SELECT クエリの剪枝でカラム STATISTICS (例: MinMax STATISTICS) を使用し、データを読み取る前に一致するデータを含み得ないパーツを除外します。

設定可能な値:

* 0 — 無効。
* 1 — 有効。
