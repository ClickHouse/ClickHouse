## iceberg_data_file_size_lower_threshold_compaction {#iceberg_data_file_size_lower_threshold_compaction}

<SettingsInfoBlock type="UInt64" default_value="402653184" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "402653184"},{"label": "Iceberg の `rewrite_data_files` プロシージャによる `min-file-size-bytes` の導出方法に合わせ、ターゲットファイルサイズ (512 MiB) の 0.75 としました。これにより compaction では、10 MiB 未満ではなく 384 MiB 未満のファイルが選択されるようになりました。"}]}, {"id": "row-2","items": [{"label": "26.5"},{"label": "10485760"},{"label": "新しい設定"}]}]} />

このサイズより小さいデータファイルが compaction の対象として選択されます。

デフォルト値は、Iceberg テーブルプロパティ `write.target-file-size-bytes` のドキュメント記載のデフォルト値 (512 MiB) の `0.75` です。これは `rewrite_data_files` プロシージャが `min-file-size-bytes` オプションを導出する方法と同じです。詳細は https://iceberg.apache.org/docs/1.5.2/configuration/ を参照してください。
