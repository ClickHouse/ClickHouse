## cluster_for_parallel_replicas {#cluster_for_parallel_replicas}

現在のサーバーが配置されている分片のクラスター

Cloud でのデフォルト値: `default`.

## cluster_function_process_archive_on_multiple_nodes {#cluster_function_process_archive_on_multiple_nodes}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "1"},{"label": "新しい設定"}]}]} />

`true` に設定すると、クラスター関数でアーカイブを処理する際のパフォーマンスが向上します。互換性を確保し、以前のバージョンでアーカイブを使用するクラスター関数を利用している場合に 25.7+ へのアップグレード中にエラーが発生するのを避けるため、`false` に設定してください。

## cluster_function_wait_for_replica_ms {#cluster_function_wait_for_replica_ms}

<SettingsInfoBlock type="Milliseconds" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "新しい設定"}]}]} />

`*Cluster` テーブル関数、またはオブジェクトストレージ上の並列レプリカにおいて、イニシエーターがレプリカからのタスク要求を待機する時間です。この時間を過ぎると、そのレプリカに割り当てられたファイルは他のレプリカに引き渡されます。`0` を指定すると待機は無効になります。
