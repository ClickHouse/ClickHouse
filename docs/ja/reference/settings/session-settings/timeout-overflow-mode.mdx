<div id="timeout_overflow_mode">
  ## timeout_overflow_mode
</div>

<SettingsInfoBlock type="OverflowMode" default_value="throw" />

クエリの実行時間が `max_execution_time` を超えた場合、または
推定実行時間が `max_estimated_execution_time` を超えた場合の動作を設定します (`throw` の場合にのみ
推定値が確認されます)。

設定可能な値:

* `throw`: 例外をスローします (デフォルト) 。
* `break`: クエリの実行を停止し、あたかも
  入力データが尽きたかのように部分的な結果を返します。一部の操作では部分的な結果を安全に返せないため、より小さい
  結果を返す代わりに、結果を生成せずに停止します。単一の値を計算する関数は、その値を生成せずに停止します。
  停止が `TIMEOUT_EXCEEDED` エラーとしてクライアントにも伝わるか、単に結果が欠落するだけかは、
  クエリが中断された場所によって異なります。タイムアウトにより未完了となった `Memory` テーブルの mutation は、
  テーブルを変更せずに `TIMEOUT_EXCEEDED` を報告します。`INSERT` では
  `QUERY_WAS_CANCELLED` が報告される場合があります。他のレプリカまたはバックグラウンド処理を待機する一部の操作は、
  `max_execution_time` でまったく停止しません。クォーラム書き込みはクォーラムが満たされるまで待機を続けるか、
  `insert_quorum_timeout` が先に経過した場合は `UNKNOWN_STATUS_OF_INSERT` を報告します。

<div id="timeout_overflow_mode_leaf">
  ## timeout_overflow_mode_leaf
</div>

<SettingsInfoBlock type="OverflowMode" default_value="throw" />

リーフノードで実行されるクエリの実行時間が `max_execution_time_leaf` を超えた場合の動作を設定します。

設定可能な値:

* `throw`: 例外をスローします (デフォルト) 。
* `break`: クエリの実行を停止し、データが
  尽きたかのように部分的な結果を返します。一部の操作では部分的な結果を安全に返せないため、
  より小さい結果を返す代わりに、結果を生成せずに停止します。単一の値を
  計算する関数は、その値を生成せずに停止します。このような停止が
  `TIMEOUT_EXCEEDED` エラーとしてクライアントにも到達するか、単に結果が
  欠落するだけかは、クエリが中断された場所によって異なります。
