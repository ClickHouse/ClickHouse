これらの設定は [system.settings](/ja/reference/system-tables/settings) で参照でき、[ソースコード](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/Settings.cpp) から自動生成されています。

## automatic_parallel_replicas_max_duplicated_read_ratio {#automatic_parallel_replicas_max_duplicated_read_ratio}

<SettingsInfoBlock type="Float" default_value="0.5" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0.5"},{"label": "自動並列レプリカは、読み取りの半分を超える部分をすべてのレプリカで重複して実行することになるクエリについて、適用を見送るようになりました。以前は上限がなく、1 を指定すると引き続きその動作になります。"}]}]} />

クエリの読み取り量のうち、レプリカ間で分割されずにすべてのレプリカで読み取られてもよい部分の割合を、全体に対する比率で指定します。この比率を超えると、自動並列レプリカはそのクエリへの適用を見送ります。

分割されるのは、並列レプリカが協調して行う読み取りのみです。同じサブツリーに対するそれ以外の読み取りは、各レプリカですべて実行されます。これらの読み取りにかかる実時間はどちらの場合も変わらないため、コストモデルによる比較には反映されません。しかし、クラスター全体ではこれらの読み取りに `max_parallel_replicas` 倍の処理を行うことになります。この設定は、そうした無駄の上限を定めるものです。デフォルトの 0.5 では、協調読み取りが全読み取り量の半分未満のクエリは、時間比較の結果にかかわらず、引き続き 1 つのノード上で実行されます。

1 に設定すると重複読み取りの量を問わず受け入れるようになり、時間のみを比較する従来の動作に戻ります。

## automatic_parallel_replicas_min_bytes_per_replica {#automatic_parallel_replicas_min_bytes_per_replica}

<SettingsInfoBlock type="UInt64" default_value="1048576" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.1"},{"label": "1048576"},{"label": "テスト結果に基づく、より適切なデフォルト値"}]}, {"id": "row-2","items": [{"label": "25.12"},{"label": "0"},{"label": "新しい設定"}]}]} />

並列レプリカを自動的に有効化するための、レプリカごとの読み取りバイト数のしきい値です (`automatic_parallel_replicas_mode`=1 の場合にのみ適用されます) 。0 はしきい値なしを意味します。
読み取る合計バイト数は、収集された統計情報に基づいて推定されます。

## automatic_parallel_replicas_mode {#automatic_parallel_replicas_mode}

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.12"},{"label": "0"},{"label": "新しい設定"}]}]} />

統計情報に基づいて、並列レプリカによる実行へ自動的に切り替える機能を有効にします。`enable_parallel_replicas = 1`、`parallel_replicas_local_plan = 1` が必要で、さらに `cluster_for_parallel_replicas` を指定する必要があります。`enable_parallel_replicas = 2` の場合は並列レプリカが強制的に使用され、自動モードは適用されません。
0 - 無効、1 - 有効、2 - 統計の収集のみ有効 (並列レプリカによる実行への切り替えは無効) 。

## automatic_parallel_replicas_remember_boundary {#automatic_parallel_replicas_remember_boundary}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "新しい設定。自動並列レプリカは、レプリカが担当する処理の境界をクエリプランごとに記憶するようになりました。以前は、この境界を特定するために、すべてのクエリで並列レプリカを用いたクエリプランを構築していました。"}]}]} />

自動並列レプリカが、レプリカの担当する処理がどこまでかをクエリプランごとに記憶できるようにします。これにより、統計情報から並列レプリカを使用しないと判断されるクエリが繰り返し実行された場合に、
並列レプリカを用いたクエリプランを構築することなく
判断できるようになります。

すべてのクエリで判断のコストを毎回すべて負担させたい場合 (例: そのコストのベンチマーク測定を行う場合) は、この設定を無効化してください。
