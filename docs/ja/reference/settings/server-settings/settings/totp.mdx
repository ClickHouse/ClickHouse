以下はClickHouseサーバーの設定であり、ClickHouseのソースコードから自動生成されています。

## totp_track_used_codes_in_keeper {#totp_track_used_codes_in_keeper}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

時間ベースのワンタイムパスワード (TOTP) コードの一回限りの使用を、サーバー単位ではなく、同じ ZooKeeper または ClickHouse Keeper を共有するすべてのサーバー全体で強制します。

受け入れられたコードは、Keeper 内の `totp_used_codes_keeper_path` で指定されたパス配下に記録されます。ノードはユーザーごとに 1 つ作成され、ユーザー名の SHA-256 ハッシュがノード名になります。あるサーバーで受け入れられたコードは他のすべてのサーバーで拒否され、この記録はサーバーを再起動しても保持されます。この設定を有効にする場合は、Keeper が設定済みである必要があります。Keeper が使用不可の間は、ワンタイムパスワードによる認証は失敗します。

**例**

```xml
<totp_track_used_codes_in_keeper>1</totp_track_used_codes_in_keeper>
```

## totp_used_codes_keeper_path {#totp_used_codes_keeper_path}

<SettingsInfoBlock type="String" default_value="/clickhouse/access/one_time_passwords" changeable_without_restart="No" />

`totp_track_used_codes_in_keeper` が有効な場合に、受理された時間ベースのワンタイムパスワード (TOTP) コードを記録する Keeper 内のパスです。chroot を使用せずに 1 つの Keeper を共有するクラスターでは、クラスターごとに異なるパスを使用する必要があります。そうしないと、異なるクラスター上の同じ名前のユーザー同士で記録が共有されてしまいます。

**例**

```xml
<totp_used_codes_keeper_path>/clickhouse/access/one_time_passwords</totp_used_codes_keeper_path>
```
