これらはClickHouseサーバーの設定であり、ClickHouseのソースコードから自動生成されています。

## ai_function_max_thread_pool_free_size {#ai_function_max_thread_pool_free_size}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

AIプロバイダーへのリクエストに使用するスレッドプール内で保持する、アイドル状態の待機スレッドの最大数です。

## ai_function_max_thread_pool_size {#ai_function_max_thread_pool_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1000" changeable_without_restart="Yes" />

AIプロバイダーへのリクエストに使用するスレッドの最大総数です。1つのスレッドが1つのリクエストを保持するため、この設定によって、サーバー全体で(すべてのクエリを合わせて)同時に処理中となるAIプロバイダーへのリクエスト数の上限が決まります。各クエリスレッドがこのうちどれだけを使用できるかは、[`ai_function_max_concurrent_requests_per_thread`](/ja/reference/settings/session-settings/ai-function#ai_function_max_concurrent_requests_per_thread) によって制限されます。

## ai_function_thread_pool_queue_size {#ai_function_thread_pool_queue_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />

AIプロバイダーへのリクエストを処理するスレッドプールにスケジュールできるジョブの最大数です。
