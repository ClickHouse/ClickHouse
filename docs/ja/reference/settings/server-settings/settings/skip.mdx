これらの設定はClickHouseサーバーを構成するためのもので、ClickHouseのソースコードから自動生成されています。

## skip_binary_checksum_checks {#skip_binary_checksum_checks}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />ClickHouseバイナリのチェックサムによる整合性チェックをスキップします

## skip_check_for_incorrect_settings {#skip_check_for_incorrect_settings}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

true に設定すると、サーバー設定の正当性はチェックされません。

また、`storage_configuration` 内のディスク定義のチェックも無効になります。このチェックは、その種類のディスクがいずれも読み取らない要素を、無視せずに
`UNKNOWN_ELEMENT_IN_CONFIG` として報告するものです。

**例**

```xml
<skip_check_for_incorrect_settings>1</skip_check_for_incorrect_settings>
```
