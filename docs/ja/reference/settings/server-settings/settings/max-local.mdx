これらの設定はClickHouse serverの設定項目で、ClickHouseのソースから自動生成されています。

## max_local_read_bandwidth_for_server {#max_local_read_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

ローカル読み取りの最大速度を、1秒あたりのバイト数で指定します。

この上限はブロックデバイスから読み取られるデータに適用されます。OS page cache から提供される読み取りは、読み取り方式がそれを検出できる場合に限り、カウントの対象外となります (デフォルトの `local_filesystem_read_method = 'pread_threadpool'`、`pread`、およびファイルシステムキャッシュファイルの読み取りがこれに該当します) 。

<Note>
  `0` は無制限を意味します。
</Note>

## max_local_write_bandwidth_for_server {#max_local_write_bandwidth_for_server}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

ローカル書き込みの最大速度 (バイト/秒) 。

<Note>
  値 `0` は無制限を意味します。
</Note>
