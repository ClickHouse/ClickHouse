これらの設定はClickHouseサーバーの構成に使用され、ClickHouseのソースコードから自動生成されています。

## enable_azure_sdk_logging {#enable_azure_sdk_logging}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Azure SDK のログを有効にします

## enable_gpu {#enable_gpu}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />サーバーの起動時に GPU を確保し、その GPU 上でクエリを実行します。サーバーが GPU サポートなしでビルドされている場合、または CUDA デバイスが存在しない場合、サーバーは起動しません。

## enable_read_through_distributed_cache {#enable_read_through_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />ClickHouse Cloudでのみ有効です。分散キャッシュからの読み取りを許可します。これは再起動なしで適用できるサーバーレベルのスイッチであり、独自のクエリプロファイルを持たないバックグラウンド処理 (マージ、ミューテーション、`Buffer` テーブルのフラッシュ) にも適用されます。個々のクエリでは、`force_read_through_distributed_cache` 設定を使用して異なる動作を指定できます。

## enable_silk_runtime {#enable_silk_runtime}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />silk fiber runtime の実験的なサポートを有効にします。サーバーの起動時に silk fiber scheduler を初期化し、対応するサブシステムが fiber 上でジョブを実行できるようにします

## enable_webterminal {#enable_webterminal}

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />`/webterminal` HTTPエンドポイントでウェブターミナルのインターフェイスを有効にします。WebSocket 経由で、ブラウザ内で対話的な `clickhouse-client` セッションを提供します。`false` の場合、`/webterminal` へのリクエストには HTTPステータス `403 Forbidden` が返されます。

## enable_write_through_distributed_cache {#enable_write_through_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />ClickHouse Cloud でのみ有効です。分散キャッシュへの書き込みを許可します (S3 への書き込みも分散キャッシュ経由で行われます) 。これは再起動なしで適用されるサーバーレベルのスイッチであり、独自のクエリプロファイルを持たないバックグラウンド処理 (マージ、ミューテーション、`Buffer` テーブルのフラッシュ) にも適用されます。個々のクエリでは、`force_write_through_distributed_cache` 設定で異なる動作を指定できます。
