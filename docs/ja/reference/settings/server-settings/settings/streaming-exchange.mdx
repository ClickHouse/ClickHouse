これらはClickHouseサーバーの設定であり、ClickHouseのソースコードから自動生成されています。

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />マルチステージの分散クエリで使用される streaming exchange ソケットの SO&#95;RCVBUF オプションのサイズです。0 の場合はカーネルのデフォルト (TCP の自動調整) が使用されます。0 より大きい値を指定すると、ソケットごとの受信バッファの上限となります (ただし net.core.rmem&#95;max によって上限に制限されます)。この値は接続ごとに読み取られるため、設定を再読み込みしても新規接続にのみ適用されます。

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />マルチステージの分散クエリで使用される streaming exchange ソケットの SO&#95;SNDBUF オプションのサイズです。0 の場合はカーネルのデフォルト (TCP の自動調整) が使用されます。0 より大きい値を指定すると、ソケットごとの送信バッファの上限となります (net.core.wmem&#95;max によって上限に制限されます)。ただし、RTT の大きいリンクではストリームのスループットが sndbuf/RTT に制限されるというデメリットがあります。この値は接続ごとに読み取られるため、設定を再読み込みしても適用されるのは新規接続のみです。
