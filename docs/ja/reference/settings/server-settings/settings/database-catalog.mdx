これらの設定はClickHouseサーバーの設定項目であり、ClickHouseのソースコードから自動生成されています。

## database_catalog_drop_error_cooldown_sec {#database_catalog_drop_error_cooldown_sec}

<SettingsInfoBlock type="UInt64" default_value="5" changeable_without_restart="No" />テーブルの削除に失敗した場合、ClickHouse はこの時間が経過するまで待機してから、操作を再試行します。

## database_catalog_drop_table_concurrency {#database_catalog_drop_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="16" changeable_without_restart="No" />テーブルの削除に使用されるスレッドプールのサイズ。

## database_catalog_shutdown_table_concurrency {#database_catalog_shutdown_table_concurrency}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="No" />server の停止時にテーブルをシャットダウンするために使用するスレッドプールのサイズ。ゼロの場合、スレッド数はコア数と同じになります。

## database_catalog_unused_dir_cleanup_period_sec {#database_catalog_unused_dir_cleanup_period_sec}

<SettingsInfoBlock type="UInt64" default_value="86400" changeable_without_restart="No" />`store/` ディレクトリ内の不要なファイルやディレクトリをクリーンアップしていたバックグラウンドタスクのパラメータで、このタスクの実行間隔を指定するものでした。この設定は非推奨であり、効果はありません。このタスクはすでに削除されており、ClickHouse が `store/` 内の未使用ディレクトリを自動的に非表示にしたり削除したりすることはありません。

## database_catalog_unused_dir_hide_timeout_sec {#database_catalog_unused_dir_hide_timeout_sec}

<SettingsInfoBlock type="UInt64" default_value="3600" changeable_without_restart="No" />`store/` ディレクトリ内の不要なファイルやディレクトリをクリーンアップしていたバックグラウンドタスクのパラメータで、未使用のディレクトリに対してこのタスクがすべてのアクセス権を取り消すまでの時間を指定していました。この設定は非推奨であり、効果はありません。このタスクは削除されており、ClickHouse が `store/` 内の未使用ディレクトリを自動的に非表示にしたり削除したりすることはありません。

## database_catalog_unused_dir_rm_timeout_sec {#database_catalog_unused_dir_rm_timeout_sec}

<SettingsInfoBlock type="UInt64" default_value="2592000" changeable_without_restart="No" />`store/` ディレクトリ内の不要なファイルやディレクトリをクリーンアップしていたバックグラウンドタスクのパラメータで、このタスクが未使用のディレクトリを削除するまでの時間を指定していました。この設定は非推奨であり、効果はありません。このタスクはすでに削除されており、ClickHouse が `store/` 内の未使用ディレクトリを自動的に非表示にしたり削除したりすることはありません。
