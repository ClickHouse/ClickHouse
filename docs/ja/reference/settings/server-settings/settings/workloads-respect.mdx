これらの設定は ClickHouseサーバーを構成するためのもので、ClickHouse のソースコードから自動生成されています。

## workloads_respect_server_cpu_limit {#workloads_respect_server_cpu_limit}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />

有効にすると、サーバー全体の CPU 同時実行数の上限がワークロードスケジューラを通じて適用されます。いずれのロールに対してもリソースが定義されていない場合は、CPUリソース `__server_cpu__` (`MASTER THREAD` および `WORKER THREAD` 用) が暗黙的に作成されます。また、ルートワークロード (名前が空のワークロード) の `max_concurrent_threads` は `concurrent_threads_soft_limit_num` と `concurrent_threads_soft_limit_ratio_to_cores` から算出されるため、すべてのワークロードがこれらの設定に基づく 1 つの CPU スロット予算を共有します。これにより、CPU スケジューリングは組み込みの同時実行制御ではなく、ワークロードスケジューラによって行われるようになります。

この設定と併せて `implicit_default_workload` を有効化してください (または `default` ワークロードを定義してください) 。この予算による制限を受けるのは、ワークロードに分類されたクエリのみです。`default` ワークロードがない場合、`workload` 設定をデフォルト値のまま使用するクエリや、デフォルトのワークロードを使用するバックグラウンドマージおよびミューテーションは、CPU の制限を一切受けません。組み込みの同時実行制御 (`concurrent_threads_soft_limit_num`) も適用されなくなります。`throw_on_unknown_workload = 1` の場合は、こうしたクエリは制限なしで実行される代わりに失敗します。

ランタイムに変更可能です。デフォルトでは無効です。

**例**

```xml
<workloads_respect_server_cpu_limit>true</workloads_respect_server_cpu_limit>
```

## workloads_respect_server_memory_limit {#workloads_respect_server_memory_limit}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />

有効にすると、サーバー全体のメモリ制限が、ワークロードスケジューラを通じてメモリ予約の予算として適用されます。`MEMORY RESERVATION` リソースが定義されていない場合は、リソース `__server_memory__` が暗黙的に作成されます。また、ルートワークロード (名前が空のワークロード) の `max_memory` は `max_server_memory_usage` (およびその RAM 比率) から導出されます。これにより、すべてのワークロードが、この設定から得られる単一のメモリ予約予算を共有します。この予算は予約のアドミッション用であり、プロセス全体のメモリ制限を置き換えるものではありません。プロセス全体のメモリ制限は引き続き適用されます。予算は、設定の読み込み時または再読み込み時に、設定済みの `max_server_memory_usage` から取得されます。`memory_worker_dynamic_hard_limit` によるプロセス全体の制限のランタイムでの調整には追従しないため、次の再読み込みまでの間は、実際に有効な制限よりも大きくなる場合があります。

この設定とあわせて `implicit_default_workload` を有効化してください (または `default` ワークロードを定義してください) 。この予算から予約を行うのは、いずれかのワークロードに分類されたクエリのみです。`default` ワークロードがない場合、`workload` 設定のデフォルト値を使用するクエリはこの予算から予約を行いません。さらに `throw_on_unknown_workload = 1` の場合は、そのようなクエリは予約を行わずに失敗します。バックグラウンドマージおよびミューテーションはワークロードからメモリを予約しないため、いずれの場合もそのメモリはこの予算に含まれません。

ランタイムに変更可能です。デフォルトでは無効です。

**例**

```xml
<workloads_respect_server_memory_limit>true</workloads_respect_server_memory_limit>
```
