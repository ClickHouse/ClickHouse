これらはClickHouseサーバーの設定であり、ClickHouseのソースコードから自動生成されています。

## statistics_cache_policy {#statistics_cache_policy}

<SettingsInfoBlock type="String" default_value="SLRU" changeable_without_restart="No" />統計キャッシュのエビクションポリシー名です。設定可能な値: `LRU`、`SLRU`、`SIEVE`。

## statistics_cache_prewarm_ratio {#statistics_cache_prewarm_ratio}

<SettingsInfoBlock type="Double" default_value="0.95" changeable_without_restart="No" />プリウォーム時に統計キャッシュを埋める割合を、キャッシュ全体のサイズに対する比率で指定します。

## statistics_cache_size {#statistics_cache_size}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="Yes" />MergeTree family のテーブルにおける、データパーツのカラム統計を保持するキャッシュの最大サイズです。統計はデータパーツおよびカラム単位でキャッシュされ、必要時に読み込まれ、クエリごとに実行時に動的にマージされます。

## statistics_cache_size_ratio {#statistics_cache_size_ratio}

<SettingsInfoBlock type="Double" default_value="0.5" changeable_without_restart="No" />統計キャッシュにおける保護キュー (SLRUポリシーの場合) のサイズを、キャッシュ全体のサイズに対する比率で指定します。
