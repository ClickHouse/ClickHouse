これらはClickHouseサーバーの設定であり、ClickHouseのソースコードから自動生成されています。

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />GPU のデフォルトのメモリ pool が、解放済みのデバイスメモリをドライバーに返却せずに保持しておく量です。デフォルト値のままでは、pool はクエリのピーク使用量まで拡大し、サーバーがシャットダウンするまでそのサイズを維持します。

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />GPU のピン留めホストメモリの pool が、解放済みのピン留めホストメモリをシステムに返却せず再利用のために保持しておける最大サイズです。
