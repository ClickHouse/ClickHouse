## min_bytes_for_compact_part {#min_bytes_for_compact_part}

<SettingsInfoBlock type="UInt64" default_value="0" />

廃止された設定で、効果はありません。

## min_bytes_for_full_part_storage {#min_bytes_for_full_part_storage}

<SettingsInfoBlock type="UInt64" default_value="0" />

パーツ に packed ではなく full type of storage を使用するための、バイト単位の最小非圧縮サイズ

## min_bytes_for_object_shared_data_main_serialization_version {#min_bytes_for_object_shared_data_main_serialization_version}

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.12"},{"label": "0"},{"label": "新しい設定"}]}]} />

JSON型内の共有データを
[object&#95;shared&#95;data&#95;serialization&#95;version](/ja/reference/settings/merge-tree-settings/object-shared#object_shared_data_serialization_version) のメインバージョンで書き込むために必要な、データパートの最小非圧縮サイズ (バイト単位) です。
これより小さいパーツには [object&#95;shared&#95;data&#95;serialization&#95;version&#95;for&#95;small&#95;parts](/ja/reference/settings/merge-tree-settings/object-shared#object_shared_data_serialization_version_for_small_parts) が使用されます。
マージ済みパーツではマージ元のパーツの合計サイズ、ミューテーション適用済みパーツではソースパーツのサイズが用いられます。
`0` を指定すると、サイズのチェックは無効になります。

## min_bytes_for_wide_part {#min_bytes_for_wide_part}

<SettingsInfoBlock type="UInt64" default_value="10485760" />

`Wide`
フォーマットで保存できる パーツ の最小バイト数/最小行数です。これらの設定は、一方のみ、両方、またはいずれも設定しないことができます。

## min_bytes_to_prewarm_caches {#min_bytes_to_prewarm_caches}

<SettingsInfoBlock type="UInt64" default_value="0" />

## min_bytes_to_rebalance_partition_over_jbod {#min_bytes_to_rebalance_partition_over_jbod}

<SettingsInfoBlock type="UInt64" default_value="0" />

ボリューム上のディスク [JBOD](https://en.wikipedia.org/wiki/Non-RAID_drive_architectures) に新しい大きな
パーツを分散配置する際に、バランシングを有効にするための最小バイト数を設定します。

設定可能な値:

* 正の整数。
* `0` — バランシングは無効です。

**使用方法**

`min_bytes_to_rebalance_partition_over_jbod` 設定の値は、
[max&#95;bytes&#95;to&#95;merge&#95;at&#95;max&#95;space&#95;in&#95;pool](/ja/reference/settings/merge-tree-settings/max-bytes#max_bytes_to_merge_at_max_space_in_pool)
の値 / 1024 未満であってはいけません。そうでない場合、ClickHouse は例外をスローします。
