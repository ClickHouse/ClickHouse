## merge_checkpoints_min_bytes {#merge_checkpoints_min_bytes}

<ExperimentalBadge />

<SettingsInfoBlock type="UInt64" default_value="10737418240" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "10737418240"},{"label": "永続的なマージチェックポイント用の新しい設定"}]}]} />

`enable_merge_checkpoints` でマージのチェックポイントを作成する対象となる、マージのソースパーツの合計サイズの最小値 (バイト単位) です。
これより小さいマージは再実行のコストが低いため、チェックポイントは作成されません。

## merge_checkpoints_min_interval_seconds {#merge_checkpoints_min_interval_seconds}

<ExperimentalBadge />

<SettingsInfoBlock type="Seconds" default_value="60" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "60"},{"label": "永続的なマージチェックポイント用の新しい設定"}]}]} />

`enable_merge_checkpoints` を有効にしたマージにおいて、チェックポイント同士の間隔として確保する最小時間です。
垂直マージでは、キーカラムのマージが完了した時点で必ずチェックポイントを作成します。それ以降は、各カラムの処理が完了した時点で、前回のチェックポイントからこの時間以上が経過している場合に限りチェックポイントを作成します。

## merge_total_max_bytes_to_prewarm_cache {#merge_total_max_bytes_to_prewarm_cache}

<SettingsInfoBlock type="UInt64" default_value="16106127360" />

ClickHouse Cloud でのみ利用できます。マージ時に cache をプリウォームする対象となるパーツの合計最大サイズです。

## merge_use_batch_sorting_queue {#merge_use_batch_sorting_queue}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "通常の `MergeTree` マージでバッチソートキューを使用するための新しい設定。"}]}]} />

ソート済みストリームをマージする際に、行ごとのキュー処理のオーバーヘッドを削減するため、バッチソートキューを使用します。

`Ordinary` マージモードのマージにのみ適用されます。対象となるのは、通常の `MergeTree` パーツのマージ (行を削除または書き換えるマージ、つまり論理削除、
有効期限 (TTL) による削除、軽量更新のパッチパーツ、`OPTIMIZE ... DEDUPLICATE` を含む) と、通常のプロジェクションパーツのマージです。
`ReplacingMergeTree`、`CollapsingMergeTree`、
`SummingMergeTree`、`AggregatingMergeTree`、`CoalescingMergeTree`、`GraphiteMergeTree`、
`VersionedCollapsingMergeTree` など、マージ時のセマンティクスを持つエンジンのマージアルゴリズムや、集約プロジェクションパーツのマージアルゴリズムは、独自のソートキューを選択するため、
この設定の影響を受けません。

## merge_workload {#merge_workload}

マージと他のワークロードの間で、リソースの使用と共有を制御するために使用されます。指定した値は、このテーブルのバックグラウンドマージに対する `workload` 設定値として使用されます。指定されていない場合 (空文字列) は、代わりにサーバー設定 `merge_workload` が使用されます。
