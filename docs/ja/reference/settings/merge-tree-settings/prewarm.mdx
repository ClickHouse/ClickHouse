## prewarm_mark_cache {#prewarm_mark_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

true の場合、INSERT 時、マージ、フェッチ、および
server の起動時に mark を mark cache に保存することで、mark cache が
プリウォームされます

## prewarm_primary_key_cache {#prewarm_primary_key_cache}

## prewarm_statistics_cache {#prewarm_statistics_cache}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "新しいデータパーツのカラム STATISTICS を使用して、また起動時にも統計キャッシュをプリウォームするための新しい設定です。統計キャッシュは、テーブル全体のスナップショットではなく、データパーツおよびカラム単位で保持されるようになりました。これに伴い、設定 `refresh_statistics_interval` と `use_statistics_cache` は廃止されました。"}]}]} />

true の場合、挿入処理、マージ、取得処理の実行時およびサーバーの起動時に
データパーツのカラム STATISTICS を読み込み、統計キャッシュを
プリウォームします。無効の場合、パーツの統計は、
それを最初に必要とするクエリの実行時にキャッシュへ読み込まれます。
