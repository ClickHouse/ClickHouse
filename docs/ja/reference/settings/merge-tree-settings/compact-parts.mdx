これらの設定は [system.merge&#95;tree&#95;settings](/ja/reference/system-tables/merge_tree_settings) で確認でき、ClickHouse のソースコードから自動生成されています。

## compact_parts_max_bytes_to_buffer {#compact_parts_max_bytes_to_buffer}

<SettingsInfoBlock type="UInt64" default_value="134217728" />

ClickHouse Cloud でのみ利用可能です。compact パーツ内の1つの
ストライプに書き込める最大バイト数

## compact_parts_max_granules_to_buffer {#compact_parts_max_granules_to_buffer}

<SettingsInfoBlock type="NonZeroUInt64" default_value="128" />

ClickHouse Cloud でのみ利用できます。compact パーツの
1 つのストライプに書き込める granule の最大数

## compact_parts_merge_max_bytes_to_prefetch_part {#compact_parts_merge_max_bytes_to_prefetch_part}

<SettingsInfoBlock type="UInt64" default_value="16777216" />

ClickHouse Cloud でのみ利用できます。マージまたはミューテーション中に compact パーツ全体を
メモリに読み込む際の最大サイズです。パーツのサイズが各カラムの読み取りバッファの
最悪ケースのメモリ量 (設定済みのバッファサイズ、プリフェッチ時はその 2 倍) を超えない場合は、
それより大きいパーツであっても全体が読み込まれます。ストライプが小さいパーツでは、
各カラムを個別に読み取るよりも多くのメモリを消費する場合がありますが、カラムごと・ストライプごとに
リクエストを送る代わりに、1 回のリクエストで済みます。0 を指定すると無効になります。
