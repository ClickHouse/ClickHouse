CREATE クエリは、たとえば新しい[データベース](/ja/reference/statements/create/database)、[テーブル](/ja/reference/statements/create/table)、[ビュー](/ja/reference/statements/create/view)を作成します。

**構文**

```sql
CREATE DATABASE ...
CREATE TABLE ...
CREATE VIEW ...
CREATE DICTIONARY ...
CREATE FUNCTION ...
CREATE NAMED COLLECTION ...
CREATE USER | ROLE | ROW POLICY | MASKING POLICY | QUOTA | SETTINGS PROFILE ...
```

**関連項目：** `ATTACH`、`DROP`、`CREATE TABLE`、`CREATE DATABASE`、`CREATE VIEW`、`CREATE DICTIONARY`
