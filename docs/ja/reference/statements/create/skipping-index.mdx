導入バージョン: v22.7.0

`MergeTree`ファミリーのテーブルに[データスキッピングインデックス](/ja/reference/engines/table-engines/mergetree-family/mergetree#table_engine-mergetree-data_skipping-indexes)を追加します。これは [`ALTER TABLE ... ADD INDEX`](/ja/reference/statements/alter/skipping-index#add-index) を単独のステートメントとして実行する形式であり、同じ `ALTER ADD INDEX` 権限が必要です。

## 構文 {#syntax}

```sql
CREATE [UNIQUE] INDEX [IF NOT EXISTS] name ON [db.]table [ON CLUSTER cluster] expression TYPE type [GRANULARITY value]
```

* `expression` - 索引の対象となる式で、括弧で囲むこともできます。括弧で囲んだリスト `(expr1, expr2, ...)` を指定すると、`CREATE TABLE` における `INDEX name (expr1, expr2, ...)` と同様に、すべての式を対象とする 1 つの索引が作成されます。
* `TYPE type [GRANULARITY value]` - `CREATE TABLE` の `INDEX` 句と同様です。[スキップ索引の種類](/ja/reference/engines/table-engines/mergetree-family/mergetree#skip-index-types)を参照してください。
* `IF NOT EXISTS` - テーブルに `name` という名前の索引がすでに存在する場合、このクエリは何も行いません。

`ADD INDEX` と同様に、このステートメントはテーブルのメタデータのみを変更します。テーブル内の既存データに対して索引を構築するには、[`ALTER TABLE ... MATERIALIZE INDEX`](/ja/reference/statements/alter/skipping-index#materialize-index) を実行してください。

## SQL 互換性 {#sql-compatibility}

他のデータベースシステムとの互換性を保つため、次のように動作します。

* 括弧で囲まれたリスト内の式の後に指定された `ASC` および `DESC` は無視されます。
* `CREATE UNIQUE INDEX` は、[`create_index_ignore_unique`](/ja/reference/settings/session-settings/create#create_index_ignore_unique) が `1` でない限り拒否されます。`1` の場合は `UNIQUE` が無視され、通常の索引が作成されます。
* `TYPE` を指定しない `CREATE INDEX` は、[`allow_create_index_without_type`](/ja/reference/settings/session-settings/allow#allow_create_index_without_type) が `1` でない限り拒否されます。`1` の場合、このクエリは何も実行しません。

## 例 {#example}

```sql title="Query"
CREATE TABLE t (id UInt64, s String) ENGINE = MergeTree ORDER BY id;
INSERT INTO t SELECT number, toString(number) FROM numbers(1000);
CREATE INDEX idx_s ON t (s) TYPE bloom_filter GRANULARITY 1;
ALTER TABLE t MATERIALIZE INDEX idx_s SETTINGS mutations_sync = 1;
SELECT name, type, expr, granularity FROM system.data_skipping_indices WHERE database = currentDatabase() AND table = 't';
```

```text title="Response"
┌─name──┬─type─────────┬─expr─┬─granularity─┐
│ idx_s │ bloom_filter │ s    │           1 │
└───────┴──────────────┴──────┴─────────────┘
```
