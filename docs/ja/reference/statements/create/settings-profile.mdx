ユーザーまたはロールに割り当て可能な[設定プロファイル](/ja/concepts/features/security/access-rights#settings-profiles-management)を作成します。

構文:

```sql
CREATE SETTINGS PROFILE [IF NOT EXISTS | OR REPLACE] name1 [, name2 [,...]]
    [ON CLUSTER cluster_name]
    [IN access_storage_type]
    [SETTINGS variable [= value] [MIN [=] min_value] [MAX [=] max_value] [CONST|READONLY|WRITABLE|CHANGEABLE_IN_READONLY] | INHERIT 'profile_name'] [,...]
    [TO {{role1 | user1 [, role2 | user2 ...]} | NONE | ALL | ALL EXCEPT {role1 | user1 [, role2 | user2 ...]}}]
```

`ON CLUSTER` 句を使用すると、クラスター上で設定プロファイルを作成できます。詳細は [分散 DDL](/ja/reference/statements/distributed-ddl) を参照してください。

`CREATE SETTINGS PROFILE` には [CREATE SETTINGS PROFILE](/ja/reference/statements/grant#access-management) 権限が必要です。`OR REPLACE` は、同名の既存のプロファイルを、それが適用されているロールも含めて破棄するため、追加で [DROP SETTINGS PROFILE](/ja/reference/statements/grant#access-management) 権限が必要です。`DROP SETTINGS PROFILE` 権限は、プロファイルが既に存在するかどうかにかかわらず必要となるため、このステートメントを使ってどのプロファイルが存在するかを調べることはできません。

## 例 {#example}

ユーザーを作成します。

```sql
CREATE USER robin IDENTIFIED BY 'password';
```

`max_memory_usage` 設定に対する値と制約を含む `max_memory_usage_profile` 設定プロファイルを作成し、ユーザー `robin` に割り当てます:

```sql
CREATE
SETTINGS PROFILE max_memory_usage_profile SETTINGS max_memory_usage = 100000001 MIN 90000000 MAX 110000000
TO robin
```
