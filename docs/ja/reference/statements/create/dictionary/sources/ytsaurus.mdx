設定例:

<Tabs>
  <Tab title="DDL">
    ```sql
    SOURCE(YTSAURUS(
        http_proxy_urls 'http://localhost:8000'
        cypress_path '//tmp/test'
        oauth_token 'password'
    ))
    ```
  </Tab>

  <Tab title="設定ファイル">
    ```xml
    <source>
        <ytsaurus>
            <http_proxy_urls>http://localhost:8000</http_proxy_urls>
            <cypress_path>//tmp/test</cypress_path>
            <oauth_token>password</oauth_token>
            <check_table_schema>1</check_table_schema>
        </ytsaurus>
    </source>
    ```
  </Tab>
</Tabs>

<br />

設定項目:

| 設定                                         | 説明                                                                                                                                                |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `http_proxy_urls`                          | YTsaurus の HTTP プロキシの URL。                                                                                                                        |
| `cypress_path`                             | テーブルソースへの Cypress パス。                                                                                                                             |
| `oauth_token`                              | OAuth トークン。                                                                                                                                       |
| `lookup_throttler_max_requests_per_second` | 選択的な Dictionary 読み込み (`CACHE`、`COMPLEX_KEY_CACHE` など) でキーをフェッチする際の、1 秒あたりの YTsaurus ルックアップリクエストの最大数。`0` を指定するとスロットリングが無効になります。デフォルトは `200000` です。 |
| `lookup_max_rows_per_query`                | 1 回の YTsaurus ルックアップリクエストあたりの最大行数。選択的な読み込みはこのサイズの chunk に分割されます。デフォルトの `0` は無制限を意味し、その場合、選択的な読み込みは単一のリクエストとして送信されます。                              |
