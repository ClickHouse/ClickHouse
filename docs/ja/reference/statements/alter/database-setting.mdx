データベースエンジンの設定を変更します。変更できる設定はエンジンによって異なります。また、すべてのエンジンや設定がデータベース作成後の変更に対応しているわけではありません。

このステートメントで変更されるのはデータベースエンジンの設定であり、session settings やデータベース内のテーブルに適用されるデフォルトは変更されません。

## 構文 {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

`ON CLUSTER` を指定すると、指定したクラスター内のすべてのホストでステートメントを実行できます。
このステートメントを実行するには、`ALTER DATABASE SETTINGS` 権限が必要です。

## サポートされている設定 {#supported-settings}

各データベースエンジンで使用できる設定と制限については、それぞれのデータベースエンジンのドキュメントを参照してください。例:

* [`Atomic`](/ja/reference/engines/database-engines/atomic) と [`Ordinary`](/ja/reference/engines/database-engines/ordinary) では、`max_tables` を変更できます。
* [`MaterializedPostgreSQL`](/ja/reference/engines/database-engines/materialized-postgresql) では、`materialized_postgresql_max_block_size` など、一部のレプリケーション設定を変更できます。
* [`DataLakeCatalog`](/ja/reference/engines/database-engines/datalake) では、一部のカタログ設定を変更できます。利用可能な設定はカタログの種類によって異なります。

サポートされていないエンジンまたは設定を指定すると、例外が発生します。

## 例 {#example}

`Atomic` データベース内のテーブル数の上限を変更します。

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

このデータベースレベルの上限を解除するには、`max_tables` を `0` に設定します。

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
