```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

単一の `UInt8` 型カラムを返します。このカラムには、テーブルまたはデータベースが存在しない場合は `0`、テーブルが指定したデータベースに存在する場合は `1` という単一の値が含まれます。

## サブクエリ形式 {#subquery-form}

`EXISTS` 演算子は、サブクエリが1行以上の行を返すかどうかを判定します。サブクエリの結果が空の場合は `0` を返し、それ以外の場合は `1` を返します。

`EXISTS` は [`WHERE`](/ja/reference/statements/select/where) 句で使用できます。サブクエリから外側のクエリのテーブルやカラムを参照することはできません。

**構文**

```sql
EXISTS(subquery)
```

**例**

サブクエリが行を返すかどうかを確認します。

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

複数の行を返すサブクエリと組み合わせて、`WHERE` 句で `EXISTS` を使用します:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

サブクエリの結果が空の場合、`EXISTS` は `0` を返します：

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```
