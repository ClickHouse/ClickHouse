Start with the default ClickHouse Agent, then build a custom agent when you need reusable instructions, tools, or sharing controls.

## Prerequisites {#prerequisites}

- A ClickHouse Cloud service you can query.

## Ask the default ClickHouse Agent {#ask-the-default-agent}

<Steps>
<Step title="Launch ClickHouse Agents" id="launch-agents">

From your Cloud service, click **ClickHouse agents** in the left sidebar to open the agents launchpad. Click **Launch ClickHouse agents** to open the Agent Builder.

<div className="ch-image-lg">

<Frame>

![Cloud service navigation with ClickHouse agents selected, showing the launchpad with the Launch ClickHouse agents button](/images/cloud/agent-builder/launch-ch-agents-ga.png)

</Frame>

</div>
</Step>
<Step title="Ask a question" id="ask-a-question">

Open a new conversation. The **ClickHouse Agent** is selected by default. Ask a focused question about a service you can access, for example, *"What are the ten largest tables by row count?"*

If the agent cannot access the service or a query fails, check that you are using the intended Cloud organization and service. Contact an org admin if you need access or a different agent.
</Step>
<Step title="Inspect the result" id="inspect-the-result">

Review the response before relying on it. Inspect any SQL, tool output, tables, charts, or files that the agent returns, and ask a follow-up question when you need to verify its assumptions or refine the analysis.
</Step>
</Steps>

## Build a custom agent {#build-a-custom-agent}

To create a custom agent, you need the **Create agent** option in the Agent Builder. If it is missing, ask an org admin to grant agent creation via Admin Settings as detailed in [sharing and access](/agents/sharing-and-access).

<Steps>
<Step title="Create the agent" id="create-the-agent">

In the Agent Builder, click **Create New Agent** at the top of the left panel. Fill in the core fields:

- **Name** - a short identifier for your agent.
- **Description** - a description of what the agent is for, which will be visible to teammates.
- **Category** - a category for your agent. You can leave this as `General` unless your org has custom categories.
- **Instructions** - the system prompt, which describe the agent's role, the questions it should answer, and any business rules it must follow.
- **Model** - pick a model from the dropdown.

<div className="ch-image-lg">

<Frame>

![Agent Builder panel showing the Create New Agent dropdown, the form fields (Name, Description, Category, Instructions, Model), and the Capabilities section](/images/cloud/agent-builder/agent-builder.webp)

</Frame>

</div>
</Step>
<Step title="Attach capabilities and tools" id="attach-tools">

The agent's capabilities and tools live in two places.

**Capabilities** in the main panel — first-party features like [Run Code](/agents/builder/code-interpreter), [Web Search](/agents/builder/web-search), File Context, Artifacts, [MCP Servers](/agents/builder/mcp-servers), and [Skills](/agents/builder/skills). Toggle the ones the agent needs.

<div className="ch-image-sm">

<Frame>

![Capabilities section of the Agent Builder panel showing Run Code, Web Search, File Context, Artifacts, MCP Servers, and Skills toggles](/images/cloud/agent-builder/capabilities.webp)

</Frame>

</div>

**Tools** behind the **Add Tools** button at the bottom of the panel — third-party integrations like [image generation](/agents/builder/image-generation), [vision](/agents/builder/vision), search APIs, and external services.

<div className="ch-image-sm">

<Frame>

![Bottom of the Agent Builder panel with the Add Tools button highlighted](/images/cloud/agent-builder/tools-button.webp)

</Frame>

</div>

Click **Add Tools** to browse the catalog:

<div className="ch-image-lg">

<Frame>

![Agent Tools modal showing a grid of third-party integrations including Google, OpenAI Image Tools, Wolfram, DALL-E-3, Tavily Search, Calculator, and Stable Diffusion](/images/cloud/agent-builder/tools-modal.webp)

</Frame>

</div>

[Subagents](/agents/builder/subagents) are configured under **Advanced settings** — see the subagents page for details.

You can change attached capabilities and tools any time.
</Step>
<Step title="Run a query" id="run-a-query">

Save the agent, open a new conversation, and select your agent from the agent picker. Type a question — for example, *"What are my top 10 tables by row count this week?"* — and the agent plans, calls tools as needed, and returns an answer.

<div className="ch-image-lg">

<Frame>

</Frame>

</div>
</Step>
</Steps>
