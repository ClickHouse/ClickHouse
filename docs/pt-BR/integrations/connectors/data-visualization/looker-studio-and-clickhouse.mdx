## Conectando o Looker Studio ao ClickHouse {#connecting-looker-studio-to-clickhouse}

Primeiro, faça login no [Looker Studio](https://lookerstudio.google.com) com sua conta Google e crie uma nova fonte de dados:

<div className="ch-image-md">
  <Frame>
    ![Criando uma nova fonte de dados na interface do Looker Studio](/images/integrations/data-visualization/looker_studio_01.webp)
  </Frame>
</div>

<br />

Procure o conector oficial do MySQL fornecido pelo Google (chamado simplesmente **MySQL**):

<div className="ch-image-md">
  <Frame>
    ![Busca pelo conector do MySQL na lista de conectores do Looker Studio](/images/integrations/data-visualization/looker_studio_02.webp)
  </Frame>
</div>

<br />

Informe os detalhes de conexão. Observe que a porta da interface MySQL é 9004 por padrão,
mas ela pode ser diferente dependendo da configuração do seu servidor.

<div className="ch-image-md">
  <Frame>
    ![Especificando os detalhes de conexão MySQL do ClickHouse no Looker Studio](/images/integrations/data-visualization/looker_studio_03.webp)
  </Frame>
</div>

<br />

Agora, há duas opções para obter os dados do ClickHouse. A primeira é usar a funcionalidade Table Browser:

<div className="ch-image-md">
  <Frame>
    ![Usando o Table Browser para selecionar tabelas do ClickHouse no Looker Studio](/images/integrations/data-visualization/looker_studio_04.webp)
  </Frame>
</div>

<br />

Como alternativa, você pode especificar uma consulta personalizada para obter seus dados:

<div className="ch-image-md">
  <Frame>
    ![Usando uma consulta SQL personalizada para obter dados do ClickHouse no Looker Studio](/images/integrations/data-visualization/looker_studio_05.webp)
  </Frame>
</div>

<br />

Por fim, você deverá ver a estrutura da tabela inspecionada e poderá ajustar os tipos de dados, se necessário.

<div className="ch-image-md">
  <Frame>
    ![Visualizando a estrutura inspecionada da tabela do ClickHouse no Looker Studio](/images/integrations/data-visualization/looker_studio_06.webp)
  </Frame>
</div>

<br />

Agora você já pode explorar seus dados ou criar um novo relatório!

## Usando o Looker Studio com ClickHouse Cloud {#using-looker-studio-with-clickhouse-cloud}

Ao usar o ClickHouse Cloud, é preciso primeiro habilitar a interface MySQL. Você pode fazer isso na caixa de diálogo de conexão, na aba &quot;MySQL&quot;.

<div className="ch-image-md">
  <Frame>
    ![Habilitando a interface MySQL nas configurações do ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)
  </Frame>
</div>

<br />

Na UI do Looker Studio, escolha a opção &quot;Enable SSL&quot;. O certificado SSL do ClickHouse Cloud é assinado pela [Let&#39;s Encrypt](https://letsencrypt.org/certificates/). Você pode baixar esse certificado raiz [aqui](https://letsencrypt.org/certs/isrgrootx1.pem).

<div className="ch-image-md">
  <Frame>
    ![Configuração da conexão do Looker Studio com as configurações SSL do ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)
  </Frame>
</div>

<br />

O restante das etapas é o mesmo listado acima na seção anterior.
