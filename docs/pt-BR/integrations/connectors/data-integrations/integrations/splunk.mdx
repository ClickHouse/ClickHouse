[Splunk](https://www.splunk.com/) é uma plataforma de análise de dados e monitoramento.

Este complemento permite armazenar os [logs de auditoria do ClickHouse Cloud](/pt-BR/products/cloud/reference/security/audit-logging) no Splunk. Ele usa a [ClickHouse Cloud API](/pt-BR/products/cloud/features/admin-features/api/api-overview) para baixar os logs de auditoria.

Este complemento contém apenas uma entrada modular e não inclui nenhuma UI adicional.

<div id="installation">
  # Instalação {#installation}
</div>

## Para Splunk Enterprise {#for-splunk-enterprise}

Baixe o ClickHouse Cloud Audit Complemento for Splunk no [Splunkbase](https://splunkbase.splunk.com/app/7709).

<div className="ch-image-lg">
  <Frame>
    ![Site do Splunkbase mostrando a página de download do ClickHouse Cloud Audit Complemento for Splunk](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

No Splunk Enterprise, acesse Apps -&gt; Manage. Em seguida, clique em Install app from file.

<div className="ch-image-lg">
  <Frame>
    ![Interface do Splunk Enterprise mostrando a página de gerenciamento de Apps com a opção Install app from file](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

Selecione o arquivo compactado baixado do Splunkbase e clique em Upload.

<div className="ch-image-lg">
  <Frame>
    ![Caixa de diálogo de instalação de app do Splunk para envio do complemento do ClickHouse](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

Se tudo der certo, a aplicação ClickHouse Audit logs aparecerá instalada. Caso contrário, verifique se há erros nos logs do Splunkd.

<div id="modular-input-configuration">
  # Configuração da entrada modular {#modular-input-configuration}
</div>

Para configurar a entrada modular, primeiro você precisará de informações da sua implantação no ClickHouse Cloud:

* O ID da organização
* Uma [API Key](/pt-BR/products/cloud/features/admin-features/api/openapi) de Admin

## Obtendo informações do ClickHouse Cloud {#getting-information-from-clickhouse-cloud}

Faça login no [console do ClickHouse Cloud](https://console.clickhouse.cloud/).

Navegue até Organization -&gt; Organization details. Lá, você pode copiar o ID da organização.

<div className="ch-image-lg">
  <Frame>
    ![Console do ClickHouse Cloud mostrando a página Organization details com o ID da organização](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

Em seguida, no menu à esquerda, acesse API Keys.

<div className="ch-image-lg">
  <Frame>
    ![Console do ClickHouse Cloud mostrando a seção API Keys no menu de navegação à esquerda](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

Crie uma API Key, dê um nome significativo e selecione os privilégios de `Admin`. Clique em Generate API Key.

<div className="ch-image-lg">
  <Frame>
    ![Console do ClickHouse Cloud mostrando a interface de criação de API Key com privilégios de Admin selecionados](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

Salve a API Key e o Secret em um local seguro.

<div className="ch-image-lg">
  <Frame>
    ![Console do ClickHouse Cloud mostrando a API Key e o Secret gerados, que devem ser salvos](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

## Configurar a entrada de dados no Splunk {#configure-data-input-in-splunk}

De volta ao Splunk, acesse Settings -&gt; Data inputs.

<div className="ch-image-lg">
  <Frame>
    ![Interface do Splunk mostrando o menu Settings com a opção Data inputs](/images/integrations/tools/data-integration/splunk/splunk_008.webp)
  </Frame>
</div>

Selecione a entrada de dados ClickHouse Cloud Audit Logs.

<div className="ch-image-lg">
  <Frame>
    ![Página Data inputs do Splunk mostrando a opção ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_009.webp)
  </Frame>
</div>

Clique em &quot;New&quot; para configurar uma nova instância da entrada de dados.

<div className="ch-image-lg">
  <Frame>
    ![Interface do Splunk para configurar uma nova entrada de dados ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_010.webp)
  </Frame>
</div>

Depois de preencher todas as informações, clique em Next.

<div className="ch-image-lg">
  <Frame>
    ![Página de configuração do Splunk com as configurações da entrada de dados do ClickHouse preenchidas](/images/integrations/tools/data-integration/splunk/splunk_011.webp)
  </Frame>
</div>

Com a entrada configurada, você já pode começar a explorar os logs de auditoria.

# Uso {#usage}

A entrada modular armazena dados no Splunk. Para visualizar esses dados, você pode usar a visualização de pesquisa geral do Splunk.
