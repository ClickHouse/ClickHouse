O [Striim for ClickHouse](https://www.striim.com/docs/striimforclickhouse/en/introducing-striim-for-clickhouse.html) é um SaaS totalmente gerenciado que traz para o ClickHouse dados de bancos de dados, data warehouses, data lakes e aplicações SaaS, incluindo fontes corporativas como Oracle, Microsoft SQL Server e Snowflake. Carregue os registros existentes e, em seguida, use Change Data Capture (CDC) para transmitir inserts, atualizações e exclusões em streaming, mantendo os dados do ClickHouse sempre atualizados para cargas de trabalho de IA, dashboards e aplicativos de dados.

O Striim for ClickHouse é hospedado no Striim Cloud na AWS, com cadastro em autosserviço, faturamento mensal por uso e sem compromisso anual. Cadastre-se em striim.com ou pelo AWS Marketplace, comece um teste gratuito de 14 dias e crie um pipeline com um prompt em linguagem natural, um assistente ou o designer de fluxos.

## Principais recursos {#key-features}

* **Change Data Capture e carga inicial:** Carregue os dados existentes e, em seguida, passe para a replicação contínua em tempo real de inserts, atualizações e exclusões. Assistentes automatizados de pipeline ajudam a criar e vincular as duas fases e fazem automaticamente a transição da carga inicial para a replicação via CDC.
* **ClickHouse Writer:** Escolha o motor de tabela de cada pipeline (`MergeTree`, `ReplacingMergeTree`, `CollapsingMergeTree`, `CoalescingMergeTree`, entre outros). O Striim cria as tabelas de destino, trata atualizações e exclusões de acordo com o motor escolhido e define as sorting keys.
* **Gerenciamento de schema:** Criação automática do schema de destino a partir da origem, para as fontes de dados compatíveis, e propagação de determinadas alterações de DDL (`CREATE TABLE`, `ADD COLUMN`, `ALTER TABLE ... MODIFY COLUMN`, `DROP COLUMN`, `DROP TABLE` e `TRUNCATE TABLE`) para as fontes de dados CDC compatíveis.
* **Processamento in-flight:** Filtre, enriqueça e transforme os dados entre a origem e o ClickHouse.
* **Operações assistidas por IA:** O Striim Clara AI, um agente de IA conversacional, cria pipelines a partir de uma descrição em linguagem natural, informa a defasagem e a vazão e explica as falhas. Revise o resultado gerado antes de implantá-lo em produção.
* **Conectividade privada:** AWS PrivateLink, túneis SSH e allowlist de IPs para as fontes de dados e o ClickHouse.
* **Monitoramento e alertas:** Monitoramento integrado de pipelines e alertas enviados por e-mail, Slack, Microsoft Teams e pela interface web do Striim.

## Considerações operacionais {#operational-considerations}

* A entrega é do tipo at-least-once (pelo menos uma vez). Após uma reinicialização ou recuperação, eventos já gravados podem ser gravados novamente. Os registros de dados resultantes dependem do motor de tabela (consulte [Como os dados chegam ao ClickHouse](/pt-BR/integrations/connectors/data-ingestion/etl-tools/striim/get-started#how-data-lands-in-clickhouse)).
* A evolução do esquema não suporta renomeação de colunas nem alterações de nulabilidade e não se aplica a destinos `AggregatingMergeTree`, `Replicated` ou `Distributed`. `VersionedCollapsingMergeTree` e `GraphiteMergeTree` não são suportados.
* Alguns tipos de fonte não têm correspondência no ClickHouse e são ignorados durante a criação automática do schema, por exemplo, `SQL Server GEOGRAPHY`, `GEOMETRY`, `HIERARCHYID` e `SQL_VARIANT`; `Oracle BFILE`, `LONG`, `LONG RAW`, `SDO_GEOMETRY` e `UROWID`; `MySQL GEOMETRY` e `SET`.
