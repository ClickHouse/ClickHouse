A Confluent oferece três opções de integração com o ClickHouse:

* [ClickHouse Connect Sink na Confluent Cloud](/pt-BR/integrations/connectors/data-ingestion/kafka/confluent/confluent-cloud), o connector totalmente gerenciado
* [ClickHouse Connect Sink como Custom Connector na Confluent Cloud](/pt-BR/integrations/connectors/data-ingestion/kafka/confluent/custom-connector), em que você mesmo faz o upload do connector
* [HTTP Sink Connector para Confluent Platform](/pt-BR/integrations/connectors/data-ingestion/kafka/confluent/kafka-connect-http) que integra o Apache Kafka a uma API via HTTP ou HTTPS

## Qual opção do Confluent Cloud devo usar? {#which-confluent-cloud-option-should-i-use}

As duas primeiras opções executam o mesmo ClickHouse Connect Sink no Confluent Cloud. A diferença está em quem gerencia o connector:

* **Connector totalmente gerenciado**: a Confluent instala e faz o upgrade do connector para você. Comece por aqui, a menos que precise de algo que ele não ofereça.
* **Custom Connector**: você mesmo baixa um lançamento do connector no [GitHub](https://github.com/ClickHouse/clickhouse-kafka-connect/releases) e faz o upload para o Confluent Cloud. Use esta opção quando precisar de uma versão específica do connector ou quiser sobrescrever configurações que, no connector totalmente gerenciado, só podem ser alteradas abrindo um chamado de suporte com a Confluent. Os Custom Connectors estão disponíveis apenas em algumas regiões da AWS.
