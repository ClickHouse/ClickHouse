**Pré-requisitos**

Para seguir este guia, você precisará de:

* Uma conta do Azure Blob Storage
* [String de conexão do Azure](/pt-BR/integrations/connectors/data-ingestion/azure/azure-data-factory/using-azureblobstorage#acquiring-azure-blob-storage-access-keys)
* Nome do contêiner
* Um serviço do ClickHouse Cloud em execução

<Steps>
  <Step title="Acesse as fontes de dados" id="navigate-to-data-sources">
    Na página inicial do seu serviço, clique em **Fontes de Dados** no menu à esquerda.
    Expanda a lista suspensa **ClickPipes** e clique em **Criar ClickPipe**

    <div className="ch-image-md">
      <Frame>
        ![Acessar Fontes de Dados](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/01-navigate-to-datasources.webp)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![Criar ClickPipe](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/02-create-clickpipe.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Selecione a fonte de dados" id="select-data-source">
    Selecione **Azure Blob Storage** como tipo de dados

    <div className="ch-image-md">
      <Frame>
        ![Selecionar Azure Blob Storage](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/03-select-blob-storage.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Configure a conexão do seu ClickPipe" id="setup-connection">
    1. Dê ao seu ClickPipe um nome descritivo
    2. Selecione **String de conexão** na lista suspensa de método de autenticação
    3. Cole sua string de conexão do Azure no campo **String de conexão**
    4. Informe o nome do seu contêiner
    5. Informe o caminho do arquivo no Azure Blob Storage, usando curingas caso queira ingerir vários arquivos

    Opcionalmente, habilite a ingestão contínua. Consulte [&quot;Ingestão contínua&quot;](/pt-BR/integrations/clickpipes/object-storage/azure-blob-storage/overview#continuous-ingestion) para mais detalhes.

    Por fim, clique em **Incoming data**

    <div className="ch-image-md">
      <Frame>
        ![Detalhes da configuração](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/04-configuration-details.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Selecione o formato de dados" id="select-data-format">
    1. Selecione o tipo de arquivo
    2. Selecione a compressão do arquivo (`detect automatically`, `none`, `gzip`, `brotli`, `xz` ou `zstd`)
    3. Conclua as configurações adicionais específicas do formato, como o delimitador usado em formatos separados por vírgula
    4. Clique em **Interpretar informações**

    <div className="ch-image-md">
      <Frame>
        ![Escolher formato de dados](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/05-choose-data-format.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Configure a tabela, o schema e as configurações" id="configure-table-schema">
    Agora você precisa criar uma nova tabela ou selecionar uma existente para armazenar os dados recebidos.

    1. Escolha se os dados serão carregados em uma nova tabela ou em uma tabela existente
    2. Selecione o banco de dados a ser usado e, se for uma nova tabela, o nome dela
    3. Escolha uma ou mais chaves de ordenação
    4. Defina os mapeamentos entre o arquivo de origem e a tabela de destino para nome da coluna, tipo da coluna, valor padrão e nulabilidade
    5. Por fim, especifique as configurações avançadas, como o tipo de engine que deseja usar, a expressão de particionamento e a chave primária

    <div className="ch-image-md">
      <Frame>
        ![Interpretar informações](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/06-parse-information.webp)
      </Frame>
    </div>

    Quando terminar de configurar a tabela, o schema e as configurações, clique em **Details and settings**
  </Step>

  <Step title="Configure as permissões" id="configure-permissions">
    O ClickPipes criará um usuário de banco de dados dedicado para a gravação dos dados.
    Você pode selecionar uma função para esse usuário.
    Para acessar materialized views ou dicionários a partir da tabela de destino, escolha &quot;Full access&quot;.

    <div className="ch-image-md">
      <Frame>
        ![Configurar permissões](/images/integrations/data-ingestion/clickpipes/object-storage/azure-blob-storage/07-permissions.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Conclua a configuração" id="complete-setup">
    Clique em **Criar ClickPipe** para concluir a configuração

    Agora seu ClickPipe deverá aparecer com o status de provisionamento.
    Após alguns instantes, o status mudará de **provisioning** para **completed**.
  </Step>
</Steps>
