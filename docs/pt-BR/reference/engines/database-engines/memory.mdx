O motor de banco de dados `Memory` mantém seus metadata e table definitions apenas em memória. Ele se destina a databases temporários: o database e suas tables são perdidos quando o servidor é interrompido ou reiniciado.

## Criando um banco de dados {#creating-a-database}

```sql
CREATE DATABASE temporary_data
ENGINE = Memory;
```

## Uso {#usage}

Crie e use tabelas como em um banco de dados [`Atomic`](/pt-BR/reference/engines/database-engines/atomic):

```sql
CREATE TABLE temporary_data.events
(
    id UInt64,
    name String
)
ENGINE = Memory;

INSERT INTO temporary_data.events VALUES (1, 'started');
```

Não use este engine para dados ou definições que precisem sobreviver a uma reinicialização. Use o `Atomic`, o motor de banco de dados padrão de código aberto, para metadata de database persistente.
