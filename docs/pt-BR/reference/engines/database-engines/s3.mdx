O motor de banco de dados `S3` expõe objetos no Amazon S3 e em armazenamentos de objetos compatíveis com S3 como tabelas somente leitura. O nome da tabela é resolvido como uma URL de objeto por meio da função de tabela [`s3`](/pt-BR/reference/functions/table-functions/s3).

## Criando um database {#creating-a-database}

```sql
CREATE DATABASE s3_data
ENGINE = S3([url[, NOSIGN | access_key_id, secret_access_key]]);
```

O engine também pode receber uma named collection. As chaves de configuração suportadas são `url`, `access_key_id`, `secret_access_key`, `no_sign_request` e `use_environment_credentials`.

## Usage {#usage}

Com uma URL base, os nomes das tabelas são caminhos de objetos relativos a essa URL:

```sql
CREATE DATABASE s3_data
ENGINE = S3('https://bucket.s3.amazonaws.com/data/', 'NOSIGN');

SELECT * FROM s3_data.`events.parquet`;
```

Sem uma URL base, use a URL completa do objeto como nome da tabela. O esquema e o formato são inferidos da mesma forma que na função de tabela `s3`. O banco de dados não possui definições de tabela e não oferece suporte a DDL de tabela nem a gravações.

## Controle de acesso {#access-control}

As URLs do S3 são verificadas contra o filtro de hosts remotos do servidor. A criação desse banco de dados exige os grants de source `READ` e `WRITE` em `S3`, independentemente de [`table_engines_require_grant`](/pt-BR/reference/settings/server-settings/settings/other#table_engines_require_grant), por exemplo:

```sql
GRANT READ, WRITE ON S3 TO user_name;
```

Consulte os [privilégios `SOURCES`](/pt-BR/reference/statements/grant#sources) para obter detalhes sobre versão e compatibilidade.
