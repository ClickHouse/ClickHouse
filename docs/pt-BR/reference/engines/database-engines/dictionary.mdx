O motor de banco de dados `Dictionary` expõe cada [dicionário](/pt-BR/reference/statements/create/dictionary) configurado como uma tabela somente leitura. Ele é útil quando uma consulta precisa ler dados de dicionários ou fazer join com eles usando a sintaxe comum de tabelas.

## Criando um banco de dados {#creating-a-database}

```sql
CREATE DATABASE dictionaries
ENGINE = Dictionary;
```

## Uso {#usage}

Após criar o banco de dados, use o nome de um dicionário configurado como nome da tabela:

```sql
SELECT *
FROM dictionaries.products;
```

O banco de dados não possui tabelas próprias. Suas tabelas são os dicionários configurados no servidor, portanto não há suporte para criar, remover ou alterar tabelas nesse banco de dados. Gerencie os dicionários diretamente com [`CREATE DICTIONARY`](/pt-BR/reference/statements/create/dictionary) ou pela configuração do servidor.
