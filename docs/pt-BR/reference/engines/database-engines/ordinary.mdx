O motor de banco de dados `Ordinary` é o motor de banco de dados legado. Ele armazena os metadados de cada tabela em um arquivo separado e foi substituído pelo [`Atomic`](/pt-BR/reference/engines/database-engines/atomic).

<Warning>
  `Ordinary` está obsoleto. Não o utilize para novos bancos de dados.
</Warning>

## Criando um banco de dados {#creating-a-database}

A criação de um banco de dados `Ordinary` requer que a configuração [`allow_deprecated_database_ordinary`](/pt-BR/reference/settings/session-settings/allow-deprecated#allow_deprecated_database_ordinary) esteja habilitada:

```sql
SET allow_deprecated_database_ordinary = 1;

CREATE DATABASE legacy
ENGINE = Ordinary;
```

## Migração {#migration}

Use `Atomic` para novos bancos de dados. Ele é o motor de banco de dados padrão no ClickHouse de código aberto e oferece suporte a operações atômicas de metadado, incluindo `DROP TABLE` e `RENAME TABLE` non-blocking.
