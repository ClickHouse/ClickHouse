## min_bytes_for_object_shared_data_main_serialization_version {#min_bytes_for_object_shared_data_main_serialization_version}

<SettingsInfoBlock type="UInt64" default_value="0" />

Tamanho não comprimido mínimo, em bytes, que uma parte deve ter para que os dados compartilhados do tipo JSON sejam gravados com a versão principal definida em
[object&#95;shared&#95;data&#95;serialization&#95;version](/pt-BR/reference/settings/merge-tree-settings/object-shared#object_shared_data_serialization_version).
Partes menores usam [object&#95;shared&#95;data&#95;serialization&#95;version&#95;for&#95;small&#95;parts](/pt-BR/reference/settings/merge-tree-settings/object-shared#object_shared_data_serialization_version_for_small_parts).
Para uma parte mesclada, o tamanho considerado é o tamanho total das partes mescladas; para uma parte alterada por mutação, é o tamanho da parte de origem.
`0` desabilita a verificação de tamanho.

## min_bytes_to_rebalance_partition_over_jbod {#min_bytes_to_rebalance_partition_over_jbod}

<SettingsInfoBlock type="UInt64" default_value="0" />

Define a quantidade mínima de bytes necessária para habilitar o balanceamento ao distribuir novas
partes grandes pelos disks do volume [JBOD](https://en.wikipedia.org/wiki/Non-RAID_drive_architectures).

Valores possíveis:

* Inteiro positivo.
* `0` — O balanceamento é desabilitado.

**Uso**

O valor da configuração `min_bytes_to_rebalance_partition_over_jbod` não deve
ser inferior ao valor de
[max&#95;bytes&#95;to&#95;merge&#95;at&#95;max&#95;space&#95;in&#95;pool](/pt-BR/reference/settings/merge-tree-settings/max-bytes#max_bytes_to_merge_at_max_space_in_pool)
/ 1024. Caso contrário, o ClickHouse lança uma exceção.
