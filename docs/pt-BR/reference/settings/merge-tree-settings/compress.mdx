## compress_marks {#compress_marks}

<SettingsInfoBlock type="Bool" default_value="1" />

As marcas podem ser comprimidas, reduzindo o tamanho do arquivo de marcas e acelerando a
transmissão pela rede.

## compress_per_column_in_compact_parts {#compress_per_column_in_compact_parts}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1"},{"label": "Nova configuração"}]}]} />

Controla o layout físico das partes compactas. Se true (padrão), cada coluna em um grânulo
inicia um novo bloco comprimido, permitindo que o ClickHouse deixe de ler colunas desnecessárias
do disco. Se false, todas as colunas dentro de um grânulo são armazenadas no mesmo bloco comprimido,
melhorando a taxa de compressão, mas exigindo que mais dados sejam descomprimidos durante as leituras.
Isso é benéfico para cargas de trabalho que sempre leem todas as colunas (por exemplo, projeções).

## compress_per_substream_in_compact_parts {#compress_per_substream_in_compact_parts}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.12"},{"label": "1"},{"label": "Nova configuração: inicia um novo bloco comprimido nos limites de subfluxo de coluna em partes compactas, para leituras mais rápidas de subcolunas"}]}]} />

Controla o layout físico das partes compactas. Se true (padrão), um subfluxo de coluna em um granule inicia
um novo bloco comprimido assim que o bloco atual atinge `min_compress_block_size`. Assim, a leitura de uma única
subcoluna (por exemplo, o tamanho de um `Array`, um elemento de `Tuple` ou um caminho JSON) descomprime apenas esse subfluxo,
enquanto subfluxos pequenos continuam compartilhando um bloco. Se false, todos os subfluxos de uma coluna em um granule são empacotados
no mesmo bloco comprimido, o que melhora a taxa de compressão, mas exige descomprimir mais dados
ao ler uma subcoluna. Só tem efeito quando `write_marks_for_substreams_in_compact_parts` e
`compress_per_column_in_compact_parts` estão habilitadas.

## compress_primary_key {#compress_primary_key}

<SettingsInfoBlock type="Bool" default_value="1" />

Permite a compressão da chave primária, reduzindo o tamanho do arquivo da chave primária e acelerando a transmissão pela rede.
