## materialize_ttl_recalculate_only {#materialize_ttl_recalculate_only}

<SettingsInfoBlock type="Bool" default_value="0" />

Quando habilitado, `MATERIALIZE TTL` recalcula os metadados de `TTL` armazenados para cada parte de dados, sem remover dados expirados durante essa operação. Quando desabilitado, a materialização normal de TTL geralmente aplica as ações de TTL configuradas para linhas, colunas ou `GROUP BY`. Em tabelas que possuem apenas TTL de linha e têm `ttl_only_drop_parts` habilitado, a operação apenas recalcula os metadados de `TTL` e remove somente as partes totalmente expiradas.
