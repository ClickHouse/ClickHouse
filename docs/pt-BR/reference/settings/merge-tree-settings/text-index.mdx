  ## text_index_serialization_version

A versão de formato de serialização em disco preferencial para gravar índices de texto.

A configuração é uma preferência, não uma restrição rígida: se a versão configurada não conseguir
representar um índice, uma versão mais recente capaz de representá-lo será escolhida automaticamente, e
a gravação de um índice de texto nunca falhará devido a essa configuração.

Durante uma atualização gradual, fixe o formato com a configuração `compatibility` no nível de perfil nos
servidores que já foram atualizados, para que continuem gravando um formato que os servidores mais antigos ainda possam ler.

Valores possíveis:

* `v0_initial` — O formato original. Não persiste o tipo de codec da posting list.
* `v1_with_codec` — Persiste o tipo de codec da posting list no cabeçalho do índice de texto.
* `v2_with_positions` — Persiste as posições dos tokens para índices com `support_phrase_search`.
