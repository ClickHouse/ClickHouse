## create_token_default_ttl_seconds {#create_token_default_ttl_seconds}

<SettingsInfoBlock type="UInt64" default_value="1800" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1800"},{"label": "Nova configuração que define um ciclo de vida para um token criado por `CREATE TOKEN` sem uma cláusula explícita `VALID UNTIL` ou `VALID FOR`. A instrução é nova, portanto não há comportamento anterior a restaurar, e o valor anterior é o próprio padrão: usar `compatibility` com uma versão mais antiga não deve fazer com que os tokens deixem de expirar."}]}]} />

O ciclo de vida, em segundos, de um token criado por [`CREATE TOKEN`](/pt-BR/reference/statements/create/token) que não especifica sua própria cláusula `VALID UNTIL` ou `VALID FOR`. O padrão é 30 minutos; portanto, um token para o qual não foi solicitada uma duração maior tem curta duração.

Valores possíveis:

* Inteiro positivo — o token expira essa quantidade de segundos após ser criado.
* 0 — um token sem cláusula explícita nunca expira.

Esta é apenas uma configuração padrão. Uma cláusula explícita `VALID UNTIL` ou `VALID FOR` na consulta sempre prevalece, incluindo `VALID UNTIL 'infinity'`, que cria um token que nunca expira, independentemente dessa configuração.
