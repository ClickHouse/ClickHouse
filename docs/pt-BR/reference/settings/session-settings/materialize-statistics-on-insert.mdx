Quando habilitado, as estatísticas são criadas e materializadas para partes recém-inseridas. Mesmo quando desabilitado, as estatísticas ainda são criadas e armazenadas durante merges ou por meio de MATERIALIZE STATISTICS explícito. Apenas as tabelas cujo tamanho atual, somado ao tamanho do bloco gravado, não exceda `materialize_statistics_on_insert_max_table_size` são afetadas.
