## optimize_if_chain_to_multiif {#optimize_if_chain_to_multiif}

<SettingsInfoBlock type="Bool" default_value="0" />

Substitui cadeias de `if(cond1, then1, if(cond2, ...))` por `multiIf`. No momento, isso não é vantajoso para tipos numéricos.

## optimize_if_transform_const_strings_to_lowcardinality {#optimize_if_transform_const_strings_to_lowcardinality}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nova configuração que permite otimizar os resultados de ramificações constantes de `if`\/`multiIf`\/`transform` para `LowCardinality`. Desabilitada por padrão."}]}]} />

Quando habilitada, as funções `if`, `multiIf` e `transform` com ramificações de resultado do tipo string constante (e valores padrão) retornam `LowCardinality(String)` em vez de `String`.
Fica desabilitada por padrão porque construir um dicionário `LowCardinality` por bloco pode ser mais lento do que um resultado `String` simples quando o dicionário não é reutilizado nas etapas seguintes.
A otimização não é aplicada quando a expressão inteira é constante (ou seja, quando a condição ou a entrada também são constantes): uma constante não ganha nada com `LowCardinality`, e as funções que esperam argumentos `String` constantes (por exemplo, `arrayReduce`, `joinGet`, `tupleElement`) continuam funcionando.

Todas as ramificações de resultado precisam ser constantes; por isso, uma cadeia de `if` aninhados como `if(cond1, 'a', if(cond2, 'b', 'c'))` continua retornando `String` simples, já que a ramificação else do `if` externo é outro `if`, e não uma constante. Para obter `LowCardinality(String)`, escreva-a como `multiIf(cond1, 'a', cond2, 'b', 'c')`.

Esta configuração não tem efeito enquanto `optimize_if_transform_strings_to_enum` estiver habilitada: a reescrita para `Enum` tem precedência, e o resultado permanece `String` (ou `Nullable(String)`) mesmo na forma explícita com `multiIf` mostrada acima.

## optimize_if_transform_strings_to_enum {#optimize_if_transform_strings_to_enum}

<SettingsInfoBlock type="Bool" default_value="0" />

Substitui argumentos do tipo String em If e Transform por enum. Desabilitado por padrão, pois isso pode causar uma alteração inconsistente em consulta distribuída, o que levaria à falha dela.
