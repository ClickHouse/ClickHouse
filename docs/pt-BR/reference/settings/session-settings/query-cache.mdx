## query_cache_compress_entries {#query_cache_compress_entries}

<SettingsInfoBlock type="Bool" default_value="1" />

Comprime as entradas no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache). Reduz o consumo de memória do cache de consultas, mas torna mais lentas as inserções nele e as leituras a partir dele.

Valores possíveis:

* 0 - Desabilitado
* 1 - Habilitado

## query_cache_max_entries {#query_cache_max_entries}

<SettingsInfoBlock type="UInt64" default_value="0" />

O número máximo de resultados de consulta que o usuário atual pode armazenar no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache) em memória. 0 significa ilimitado.

Esse limite não se aplica ao cache de consultas em disco (configuração `query_cache_on_disk_cache_name`), cujas entradas são limitadas pelo tamanho do cache do sistema de arquivos subjacente.

Valores possíveis:

* Número inteiro maior ou igual a 0.

## query_cache_max_size_in_bytes {#query_cache_max_size_in_bytes}

<SettingsInfoBlock type="UInt64" default_value="0" />

A quantidade máxima de memória (em bytes) que o usuário atual pode alocar no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache) em memória. 0 significa sem limite.

Esse limite não se aplica ao cache de consultas em disco (configuração `query_cache_on_disk_cache_name`), cujas entradas são limitadas pelo tamanho do cache do sistema de arquivos subjacente.

Valores possíveis:

* Número inteiro positivo &gt;= 0.

## query_cache_min_query_duration {#query_cache_min_query_duration}

<SettingsInfoBlock type="Milliseconds" default_value="0" />

Duração mínima, em milissegundos, pela qual uma consulta precisa ser executada para que seu resultado seja armazenado no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache).

Valores possíveis:

* Inteiro &gt;= 0.

## query_cache_min_query_runs {#query_cache_min_query_runs}

<SettingsInfoBlock type="UInt64" default_value="0" />

Número mínimo de vezes que uma consulta `SELECT` deve ser executada antes que seu resultado seja armazenado no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache).

Valores possíveis:

* Número inteiro positivo &gt;= 0.

## query_cache_nondeterministic_function_handling {#query_cache_nondeterministic_function_handling}

<SettingsInfoBlock type="QueryResultCacheNondeterministicFunctionHandling" default_value="throw" />

Controla como o [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache) lida com consultas `SELECT` que usam funções não determinísticas, como `rand()` ou `now()`.

Valores possíveis:

* `'throw'` - Lança uma exceção e não armazena o resultado da consulta em cache.
* `'save'` - Armazena o resultado da consulta em cache.
* `'ignore'` - Não armazena o resultado da consulta em cache e não lança exceção.

## query_cache_on_disk_cache_name {#query_cache_on_disk_cache_name}

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": ""},{"label": "Nova configuração para armazenar entradas do cache de consultas em disco no cache do sistema de arquivos especificado."}]}]} />

O nome de um cache do sistema de arquivos (uma entrada da seção `filesystem_caches` da configuração do servidor) que armazena em disco as entradas do [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache). Se um nome for informado (e [use&#95;query&#95;cache](/pt-BR/reference/settings/session-settings/use-query#use_query_cache) estiver habilitado), os resultados de consultas também são armazenados no cache do sistema de arquivos especificado e servidos a partir dele. O cache de consultas em disco oferece mais espaço que o cache de consultas em memória, persiste após reinicializações do servidor e funciona de forma independente do cache de consultas em memória: as configurações [enable&#95;reads&#95;from&#95;query&#95;cache&#95;on&#95;disk](/pt-BR/reference/settings/session-settings/enable#enable_reads_from_query_cache_on_disk) e [enable&#95;writes&#95;to&#95;query&#95;cache&#95;on&#95;disk](/pt-BR/reference/settings/session-settings/enable#enable_writes_to_query_cache_on_disk) o controlam separadamente do cache de consultas em memória. As entradas no cache do sistema de arquivos são entradas comuns desse cache: elas não são protegidas contra exclusão e são removidas segundo as mesmas regras aplicadas a quaisquer outros dados nele. `SYSTEM CLEAR FILESYSTEM CACHE '<name>'` as remove junto com todo o restante do cache do sistema de arquivos, e `SYSTEM CLEAR QUERY CACHE` remove as entradas do cache de consultas em disco do cache do sistema de arquivos indicado por esta configuração, mantendo todos os demais dados intactos. Recomenda-se usar um cache do sistema de arquivos dedicado aos resultados de consultas.

Valores possíveis:

* String vazia - O cache de consultas em disco fica desabilitado
* O nome de um cache do sistema de arquivos pré-configurado

## query_cache_share_between_users {#query_cache_share_between_users}

<SettingsInfoBlock type="Bool" default_value="0" />

Se ativada, o resultado de consultas `SELECT` armazenado no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache) pode ser lido por outros usuários.
Não é recomendável habilitar essa configuração por motivos de segurança.

Valores possíveis:

* 0 - Desabilitado
* 1 - Habilitado

## query_cache_squash_partial_results {#query_cache_squash_partial_results}

<SettingsInfoBlock type="Bool" default_value="1" />

Compacta blocos de resultados parciais em blocos do tamanho de [max&#95;block&#95;size](/pt-BR/reference/settings/session-settings/max#max_block_size). Reduz o desempenho da inserção no [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache), mas melhora a capacidade de compressão das entradas de cache (consulte [query&#95;cache&#95;compress-entries](/pt-BR/reference/settings/session-settings/query-cache#query_cache_compress_entries)).

Valores possíveis:

* 0 - Desabilitado
* 1 - Habilitado

## query_cache_system_table_handling {#query_cache_system_table_handling}

<SettingsInfoBlock type="QueryResultCacheSystemTableHandling" default_value="throw" />
