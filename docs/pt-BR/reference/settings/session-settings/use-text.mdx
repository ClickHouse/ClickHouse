## use_text_index_header_cache {#use_text_index_header_cache}

## use_text_index_like_evaluation_by_dictionary_scan {#use_text_index_like_evaluation_by_dictionary_scan}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1"},{"label": "Nova configuração"}]}]} />

Habilita a avaliação de consultas LIKE/ILIKE por varredura do dicionário do índice de texto invertido.

Os padrões acelerados são `%value%`, `value%` e `%value`, bem como as chamadas `startsWith` e `endsWith` que `optimize_rewrite_like_perfect_affix` reescreve como `value%` e `%value`.

## use_text_index_negative_tokens_cache {#use_text_index_negative_tokens_cache}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "Nova configuração para armazenar em cache tokens ausentes do índice de texto e evitar consultas repetidas ao dicionário."}]}]} />

Define se os tokens do índice de texto ausentes de uma parte de dados devem ser armazenados em cache.
O cache de tokens negativos usa o cache de tokens do índice de texto e evita consultas repetidas ao dicionário para tokens ausentes.
