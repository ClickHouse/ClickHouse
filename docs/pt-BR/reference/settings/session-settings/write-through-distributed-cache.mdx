## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "Nova configuração para a nuvem"}]}]} />

Só tem efeito no ClickHouse Cloud. O tamanho máximo do buffer gravado nos servidores de cache distribuído, por write buffer. É independente do buffer gravado no armazenamento de objetos: esse continua crescendo até atingir o tamanho da part de upload. Se for 0, é usado `DBMS_DEFAULT_BUFFER_SIZE` (1 MiB). O buffer começa em `adaptive_write_buffer_initial_size` e cresce até esse tamanho somente à medida que o stream é gravado, de modo que uma part não o aloque para cada stream que grava.
