## use_statistics_for_min_max_aggregation {#use_statistics_for_min_max_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Nova configuração para responder às agregações `min`, `max` e `count` sem `GROUP BY` e sem filtros a partir das estatísticas de colunas por parte, nas partes que as têm materializadas, lendo apenas as partes restantes. previous_value=false, de modo que a `compatibility` com versões anteriores à 26.9 mantém a otimização desabilitada e restaura o plano preexistente."}]}]} />

Responde às agregações `min`, `max` e `count` a partir das estatísticas de colunas por parte, em vez de ler os dados.

Quando habilitada, uma consulta no formato `SELECT min(column), max(column), count() FROM table` sem `GROUP BY` e sem filtros
é respondida a partir das estatísticas de colunas (por exemplo, estatísticas MinMax; veja a configuração de MergeTree `auto_statistics_types`)
nas partes de dados que as têm materializadas, e apenas as partes restantes são lidas.

Valores possíveis:

* 0 — Desabilitado.
* 1 — Habilitado.

## use_statistics_for_part_pruning {#use_statistics_for_part_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

Usa estatísticas para filtrar partes durante a execução da consulta.

Quando habilitada, a eliminação de partes em consultas SELECT usa estatísticas de colunas (por exemplo, estatísticas MinMax) para descartar partes que não podem conter dados correspondentes antes que qualquer dado seja lido.

Possible values:

* 0 — Desabilitado.
* 1 — Habilitado.
