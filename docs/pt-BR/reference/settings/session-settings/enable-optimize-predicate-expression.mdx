## enable_optimize_predicate_expression_to_final_subquery {#enable_optimize_predicate_expression_to_final_subquery}

<SettingsInfoBlock type="Bool" default_value="1" />

Permite que um filtro da consulta seja adicionado à consulta enviada aos servidores remotos (por exemplo, ao ler de uma tabela `Distributed`) quando a consulta enviada aos servidores remotos usa `FINAL`. Isso reduz a quantidade de dados retornados pelos servidores remotos.

Se desabilitada, o filtro não é adicionado a essas consultas e só é aplicado depois que os dados são recebidos dos servidores remotos.
