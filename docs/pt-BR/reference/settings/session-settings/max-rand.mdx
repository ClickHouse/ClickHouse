  ## max_rand_distribution_parameter
</div>

<SettingsInfoBlock type="Float" default_value="1000000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1000000"},{"label": "Nova configuração para limitar os parâmetros de forma em funções de distribuição aleatória, evitando travamentos com entradas extremas."}]}]} />

Valor máximo dos parâmetros de forma da distribuição em funções de distribuição aleatória, como `randChiSquared`, `randStudentT` e `randFisherF`. Isso evita tempos de processamento excessivamente longos com valores extremos desses parâmetros. `0` desativa o limite; valores para os quais o amostrador não termina de forma alguma ainda são rejeitados.

  ## max_rand_distribution_trials
</div>

<SettingsInfoBlock type="UInt64" default_value="1000000000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1000000000"},{"label": "Nova configuração para limitar o número de tentativas em funções de distribuição aleatória, evitando travamentos com valores de entrada extremos."}]}]} />

Número máximo de tentativas permitido para funções de distribuição aleatória, como `randBinomial` e `randNegativeBinomial`. Isso evita tempos de computação excessivamente longos com um grande número de tentativas. `0` desativa o limite, e a configuração pode ser aumentada acima do valor padrão, exceto para `randBinomial` com probabilidade estritamente entre 0 e 1, que sempre rejeita mais de 10^9 tentativas porque, no pior caso, o custo de uma única amostra é proporcional ao número de tentativas, com uma probabilidade que aumenta com esse número. As probabilidades 0 e 1 estão isentas desse limite rígido, pois, para elas, uma amostra tem custo de tempo constante.
