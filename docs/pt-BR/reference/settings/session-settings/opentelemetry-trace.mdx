## opentelemetry_trace_stateless_worker_discovery {#opentelemetry_trace_stateless_worker_discovery}

<CloudOnlyBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "Nova configuração para coletar spans do OpenTelemetry das requisições que uma consulta faz ao serviço de descoberta de stateless-workers para provisionar workers."}]}]} />

Só tem efeito no ClickHouse Cloud. Para uma consulta que já esteja sendo rastreada, coleta spans do OpenTelemetry das requisições que ela faz ao serviço de descoberta de stateless-workers para provisionar workers (por concessão temporária).
Os spans recebem o nome `StatelessWorkerDiscovery.<action>` e contêm os atributos `clickhouse.discovery.action` e `clickhouse.discovery.status`.
