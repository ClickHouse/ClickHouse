<div id="filesystem_cache_verbose_logging">
  ## filesystem_cache_verbose_logging
</div>

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "Nova configuração que controla as mensagens de log de nível TEST emitidas a cada recarga do buffer de leitura do cache do sistema de arquivos, que antes eram emitidas incondicionalmente assim que o nível de log permitia."}]}]} />

Emite mensagens de log de nível `TEST` para cada recarga de buffer do cache do sistema de arquivos (estado da leitura, tamanho restante a ler, bytes lidos). Apenas para depuração: as mensagens são formatadas uma vez por leitura; portanto, habilitar essa opção em uma consulta que realiza muitas pequenas leituras em cache adiciona uma grande sobrecarga de logging. As mensagens só são visíveis quando o nível de log é `test` (consulte `send_logs_level`).

<div id="filesystem_cache_wait_for_concurrent_download_timeout_milliseconds">
  ## filesystem_cache_wait_for_concurrent_download_timeout_milliseconds
</div>

<SettingsInfoBlock type="UInt64" default_value="1000" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1000"},{"label": "Nova configuração para limitar por quanto tempo uma leitura aguarda um segmento de arquivo ser baixado para o cache do sistema de arquivos por uma consulta concorrente; em caso de timeout, a leitura ignora o cache em vez de aguardar indefinidamente. O valor anterior, 60000, corresponde ao comportamento antigo (um ciclo completo de espera de 60 s no downloader)."}]}]} />

Tempo máximo de espera por um segmento de arquivo que está sendo baixado para o cache do sistema de arquivos por uma consulta concorrente. Quando o timeout é atingido, a leitura ignora o cache do sistema de arquivos para esse intervalo e lê diretamente do armazenamento remoto, enquanto o download concorrente continua a preencher o cache. O valor `0` significa não esperar: ignore imediatamente o cache se o intervalo necessário ainda não tiver sido baixado. Reduzir esse valor limita a latência de cauda das leituras com acerto de cache que, caso contrário, aguardariam o ritmo de download de outra consulta, ao custo de solicitações adicionais ao armazenamento remoto.
