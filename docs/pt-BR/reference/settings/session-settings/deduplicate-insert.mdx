  ## deduplicate_insert

Habilita ou desabilita a desduplicação de blocos de `INSERT INTO` (para tabelas Replicated*).
Essa configuração se aplica a inserts síncronos e assíncronos e substitui as configurações `insert_deduplicate` e `async_insert_deduplicate`.
Essa configuração tem três valores possíveis:

* disable — A desduplicação é desabilitada para a consulta `INSERT INTO`.
* enable — A desduplicação é habilitada para a consulta `INSERT INTO`.
* backward&#95;compatible&#95;choice — A desduplicação é habilitada se `insert_deduplicate` ou `async_insert_deduplicate` estiverem habilitados para o tipo específico de insert.

Para consultas `INSERT SELECT`, [`deduplicate_insert_select`](/pt-BR/reference/settings/session-settings/deduplicate-insert#deduplicate_insert_select) é consultado primeiro. A desduplicação também exige que a tabela de destino mantenha um log de desduplicação; consulte [replicated&#95;deduplication&#95;window](/pt-BR/reference/settings/merge-tree-settings/replicated-deduplication-window#replicated_deduplication_window) e [non&#95;replicated&#95;deduplication&#95;window](/pt-BR/reference/settings/merge-tree-settings/other#non_replicated_deduplication_window).

Habilita ou desabilita a desduplicação de blocos em `INSERT SELECT` (para tabelas Replicated*).
Para consultas `INSERT SELECT`, esta configuração é considerada antes de [`deduplicate_insert`](/pt-BR/reference/settings/session-settings/deduplicate-insert#deduplicate_insert).
Um `SELECT` é estável quando contém `ORDER BY ALL` e seu pipeline termina em um único fluxo. Um [`insert_deduplication_token`](/pt-BR/reference/settings/session-settings/insert#insert_deduplication_token) não vazio é um substituto equivalente para a estabilidade.
Essa configuração tem quatro valores possíveis:

* disable — A desduplicação é desabilitada para a consulta `INSERT SELECT`.
* force&#95;enable — A desduplicação é habilitada para a consulta `INSERT SELECT`, independentemente de `deduplicate_insert`. Se o resultado do `SELECT` não for estável e nenhum token for fornecido, uma exceção será lançada.
* enable&#95;when&#95;possible — A desduplicação é habilitada se estiver habilitada por `deduplicate_insert` e o resultado do `SELECT` for estável; caso contrário, será desabilitada.
* enable&#95;even&#95;for&#95;bad&#95;queries - A desduplicação é habilitada se estiver habilitada por `deduplicate_insert`, independentemente de o resultado do `SELECT` ser estável. Se o resultado do `SELECT` não for estável, uma mensagem será registrada, mas a consulta será executada com desduplicação. Esta opção existe por compatibilidade retroativa. Considere usar outras opções, pois ela pode levar a resultados inesperados.
