## iceberg_compaction_max_bytes_to_merge {#iceberg_compaction_max_bytes_to_merge}

<SettingsInfoBlock type="UInt64" default_value="161061273600" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "161061273600"},{"label": "Nova configuração. Limita o tamanho total dos arquivos de uma mesclagem de compactação, da mesma forma que `max_bytes_to_merge_at_max_space_in_pool` faz para `MergeTree`."}]}]} />

Tamanho total máximo dos arquivos de dados mesclados em uma única mesclagem de compactação de uma tabela Iceberg, ou seja, a soma de seus tamanhos no armazenamento de objetos.
Funciona da mesma forma que `max_bytes_to_merge_at_max_space_in_pool` para `MergeTree`: quando o pool de threads em segundo plano tem menos entradas livres que
`number_of_free_entries_in_pool_to_lower_max_size_of_merge`, o limite é reduzido para `max_bytes_to_merge_at_min_space_in_pool`
(ambos definidos na seção `merge_tree` da configuração).
Os arquivos de uma partição que não couberem no limite são mesclados nas mesclagens seguintes. Não se aplica a mesclagens que aplicam arquivos de exclusão por posição.
