## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "O método de compressão padrão para a comunicação cliente\/servidor e servidor\/servidor passou de `LZ4` para `ZSTD` a fim de reduzir o network traffic."}]}]} />

O codec usado para comprimir a comunicação cliente/servidor e servidor/servidor pelo native protocol.

A configuração não se aplica ao canal de streaming-exchange das consultas distribuídas, que sempre usa o default codec do servidor: cada frame comprimido é self-describing, portanto o receiver detecta o codec automaticamente.

Valores possíveis:

* `NONE` — sem compressão.
* `LZ4` — usa o codec LZ4.
* `LZ4HC` — usa o codec LZ4HC.
* `ZSTD` — usa o codec ZSTD.

## network_zstd_compression_level {#network_zstd_compression_level}
