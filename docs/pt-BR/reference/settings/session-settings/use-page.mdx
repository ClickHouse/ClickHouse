## use_page_cache_for_local_disks {#use_page_cache_for_local_disks}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "Nova configuração para usar o cache de páginas em espaço de usuário em discos locais"}]}]} />

Use o cache de páginas em espaço de usuário ao ler a partir de discos locais. É usado para testes e dificilmente melhora o desempenho na prática. Requer `local_filesystem_read_method = 'pread'` ou `'read'`. Não desabilita o cache de páginas do sistema operacional; `min_bytes_to_use_direct_io` pode ser usado para isso. Afeta apenas tabelas comuns, não a função de tabela `file()` nem o mecanismo de tabela `File()`.

## use_page_cache_for_object_storage {#use_page_cache_for_object_storage}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "Nova configuração para usar o cache de páginas em espaço de usuário em funções de tabela de armazenamento de objetos"}]}, {"id": "row-2","items": [{"label": "26.12"},{"label": "1"},{"label": "Usa por padrão o cache de páginas em espaço de usuário em motores de tabela e funções de tabela de armazenamento de objetos, se o cache de páginas estiver configurado no servidor."}]}]} />

Usa o cache de páginas em espaço de usuário na leitura de funções de tabela de armazenamento de objetos (s3, azure, hdfs, Iceberg, Delta Lake etc.) e de motores de tabela (S3, Azure, HDFS, Iceberg, Delta Lake etc.). Só tem efeito se o cache de páginas em espaço de usuário estiver configurado no servidor (`page_cache_max_size`) e apenas para objetos com um ETag forte ou com uma identidade imutável obtida dos registros da tabela (arquivos de dados do Iceberg e do Delta Lake). Não é usado em conjunto com o cache do sistema de arquivos. Com o distributed cache, só é usado se `use_page_cache_with_distributed_cache` também estiver habilitado.

## use_page_cache_lookahead_for_text_index {#use_page_cache_lookahead_for_text_index}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nova configuração"}]}]} />

Os arquivos do índice de texto lidos fora da ordem do arquivo (dicionário, listas de ocorrências, posições) são, por padrão, lidos pelo cache de páginas em espaço de usuário com um lookahead de um bloco, para que a conexão remota possa ser reutilizada após cada leitura. Habilite esta configuração para que esses arquivos passem a usar `page_cache_lookahead_blocks`, assim como os demais arquivos.

<SettingsInfoBlock type="Bool" default_value="0" />

Use o cache de páginas em espaço de usuário quando o distributed cache estiver em uso.
