Máximo de bytes do arquivo de dados parquet do iceberg em uma operação de insert.

O padrão espelha o padrão documentado da propriedade de tabela do Iceberg `write.target-file-size-bytes` (512 MiB),
consulte https://iceberg.apache.org/docs/1.5.2/configuration/. Observe que o ClickHouse compara o limite com o
tamanho descomprimido dos dados já gravados no arquivo, enquanto a propriedade do Iceberg tem como alvo o tamanho do
arquivo resultante, e que `iceberg_insert_max_rows_in_data_file` limita o arquivo independentemente de seu tamanho.
