Estas configurações controlam o servidor do ClickHouse e são geradas automaticamente a partir do código-fonte do ClickHouse.

## amber_connections_hard_limit {#amber_connections_hard_limit}

<SettingsInfoBlock type="UInt64" default_value="200000" changeable_without_restart="No" />Uma exceção é lançada ao tentar criar uma conexão quando este limite é atingido. Defina como 0 para desativar o limite rígido. O limite se aplica às conexões Amber.

## amber_connections_rcvbuf {#amber_connections_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="204800" changeable_without_restart="Yes" />O tamanho da opção SO&#95;RCVBUF para conexões Amber. O valor padrão é 204800 (200 KB): o armazenamento de objetos é acessado dentro da mesma região, onde o produto largura de banda-atraso fica bem abaixo de 100 KB. Assim, um limite pequeno garante a vazão total e evita os buffers de vários MiB por socket que o ajuste automático do kernel alocaria nesse caso. Defina como 0 para usar o ajuste automático de TCP do kernel para o buffer de recepção. Nota: alterar esta configuração de volta para 0 restaura o ajuste automático apenas para conexões recém-criadas; as conexões em pool existentes mantêm tamanhos de buffer fixos até serem recriadas.

## amber_connections_sndbuf {#amber_connections_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Tamanho da opção SO&#95;SNDBUF para conexões Amber. Se definido como um valor maior que 0, substitui o ajuste automático de TCP do kernel para o buffer de envio. 0 = padrão do kernel (ajuste automático). Nota: voltar esta configuração para 0 restaura o ajuste automático apenas para conexões criadas a partir desse momento; as conexões em pool existentes mantêm tamanhos de buffer fixos até serem recriadas.

## amber_connections_soft_limit {#amber_connections_soft_limit}

<SettingsInfoBlock type="UInt64" default_value="5000" changeable_without_restart="No" />Conexões acima deste limite têm um tempo de vida significativamente menor. O limite se aplica às conexões Amber.

## amber_connections_store_limit {#amber_connections_store_limit}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="No" />O número máximo de conexões idle mantidas no pool para reutilização. Quando esse número de conexões armazenadas for atingido, as conexões adicionais serão redefinidas após o uso em vez de serem mantidas. O limite não se aplica às conexões em uso. Defina como 0 para desativar o cache de conexões. O limite se aplica às conexões do Amber.

## amber_connections_warn_limit {#amber_connections_warn_limit}

<SettingsInfoBlock type="UInt64" default_value="8000" changeable_without_restart="No" />Mensagens de aviso são gravadas nos logs quando o número de conexões em uso ultrapassa este limite. O limite se aplica às conexões Amber.
