Estas configurações definem o comportamento do servidor do ClickHouse e são geradas automaticamente a partir do código-fonte do ClickHouse.

## totp_track_used_codes_in_keeper {#totp_track_used_codes_in_keeper}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

Garante que cada código de senha de uso único baseada em tempo (TOTP) seja usado apenas uma vez em todos os servidores que compartilham o mesmo ZooKeeper ou ClickHouse Keeper, e não apenas em cada servidor individualmente.

Os códigos aceitos são registrados no Keeper sob o caminho definido por `totp_used_codes_keeper_path`, com um nó por usuário, nomeado pelo hash SHA-256 do nome de usuário: um código aceito por um servidor é rejeitado por todos os demais, e o registro persiste após reinicializações do servidor. O Keeper deve estar configurado quando esta configuração estiver habilitada; enquanto o Keeper estiver indisponível, a autenticação com senha de uso único falha.

**Exemplo**

```xml
<totp_track_used_codes_in_keeper>1</totp_track_used_codes_in_keeper>
```

## totp_used_codes_keeper_path {#totp_used_codes_keeper_path}

<SettingsInfoBlock type="String" default_value="/clickhouse/access/one_time_passwords" changeable_without_restart="No" />

Caminho no Keeper onde são registrados os códigos aceitos de senha de uso único baseada em tempo (TOTP) quando `totp_track_used_codes_in_keeper` está habilitado. Clusters que compartilham o mesmo Keeper sem chroot devem usar caminhos diferentes; caso contrário, usuários com o mesmo nome em clusters diferentes acabariam compartilhando seus registros.

**Exemplo**

```xml
<totp_used_codes_keeper_path>/clickhouse/access/one_time_passwords</totp_used_codes_keeper_path>
```
