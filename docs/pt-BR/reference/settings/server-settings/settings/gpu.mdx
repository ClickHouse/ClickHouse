Estas configurações definem o comportamento do servidor do ClickHouse e são geradas automaticamente a partir do código-fonte do ClickHouse.

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />Quantidade de memória do dispositivo já liberada que o pool de memória padrão da GPU retém em vez de devolvê-la ao driver. Com o valor padrão, o pool cresce até o pico de uso das consultas e permanece nesse tamanho até o servidor ser desligado.

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />O tamanho máximo de memória fixada (pinned) do host já liberada que o pool de memória fixada do host da GPU mantém para reutilização, em vez de devolvê-la ao sistema.
