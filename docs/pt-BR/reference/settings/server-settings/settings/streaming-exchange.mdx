Estas configurações se aplicam ao servidor do ClickHouse e são geradas automaticamente a partir do código-fonte do ClickHouse.

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />O tamanho da opção SO&#95;RCVBUF para os sockets de streaming exchange de consultas distribuídas com múltiplas etapas. 0 = padrão do kernel (ajuste automático do TCP). Um valor maior que 0 define um limite máximo para o buffer de recepção de cada socket (limitado por net.core.rmem&#95;max). Como o valor é lido a cada conexão, recarregar a configuração afeta apenas novas conexões.

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />O tamanho da opção SO&#95;SNDBUF para os sockets de streaming exchange de consultas distribuídas com múltiplas etapas. 0 = padrão do kernel (ajuste automático do TCP). Um valor maior que 0 limita o buffer de envio por socket (limitado por net.core.wmem&#95;max), mas, em links com RTT alto, restringe a taxa do stream a sndbuf/RTT. Como o valor é lido por conexão, recarregar a configuração afeta apenas novas conexões.
