## startup_scripts.throw_on_error {#startup_scripts.throw_on_error}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Se estiver definido como true, o servidor não será iniciado se ocorrer um erro durante a execução dos scripts.
