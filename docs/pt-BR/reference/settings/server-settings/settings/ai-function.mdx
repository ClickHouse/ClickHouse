Estas configurações controlam o servidor do ClickHouse e são geradas automaticamente a partir do código-fonte do ClickHouse.

## ai_function_max_thread_pool_free_size {#ai_function_max_thread_pool_free_size}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

Número máximo de threads idle em espera a serem mantidas no pool de threads para requisições a provedores de IA.

## ai_function_max_thread_pool_size {#ai_function_max_thread_pool_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1000" changeable_without_restart="Yes" />

Número máximo total de threads usadas para requisições a provedores de IA. Cada thread atende a uma requisição; portanto, esta configuração limita quantas requisições a provedores de IA o servidor inteiro pode ter em andamento simultaneamente, considerando todas as consultas. [`ai_function_max_concurrent_requests_per_thread`](/pt-BR/reference/settings/session-settings/ai-function#ai_function_max_concurrent_requests_per_thread) limita a parcela desse total que cabe a cada thread de consulta.

## ai_function_thread_pool_queue_size {#ai_function_thread_pool_queue_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />

O número máximo de jobs que podem ser agendados no pool de threads para requisições a provedores de IA.
