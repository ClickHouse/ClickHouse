Essas configurações são geradas automaticamente a partir do [código-fonte](https://github.com/ClickHouse/ClickHouse/blob/master/src/Core/FormatFactorySettings.h).

## show_create_query_identifier_quoting_rule {#show_create_query_identifier_quoting_rule}

<SettingsInfoBlock type="IdentifierQuotingRule" default_value="when_necessary" />

Controla quando os identificadores são delimitados na saída de `SHOW CREATE`. `when_necessary` (padrão) delimita os identificadores somente quando necessário para gerar SQL válido e sem ambiguidade; `user_display` delimita os identificadores que são palavras-chave SQL; `always` delimita todos os identificadores. Esta configuração determina se a delimitação é aplicada; já `show_create_query_identifier_quoting_style` define os caracteres de delimitação e o escape.

## show_create_query_identifier_quoting_style {#show_create_query_identifier_quoting_style}

<SettingsInfoBlock type="IdentifierQuotingStyle" default_value="Backticks" />

Controla como os identificadores delimitados são gravados na saída de `SHOW CREATE`. `Backticks` (padrão) usa backticks no estilo do ClickHouse, `DoubleQuotes` usa aspas duplas com o escape do ClickHouse e `BackticksMySQL` usa backticks compatíveis com o MySQL, nos quais backticks embutidos são duplicados. Esta configuração não determina quais identificadores são delimitados; para isso, use `show_create_query_identifier_quoting_rule`.
