<div id="overview">
  ## Visão geral
</div>

A instrução `REPLACE` permite atualizar uma tabela de forma [atômica](/pt-BR/concepts/core-concepts/glossary#atomicity).

<Note>
  Esta instrução é compatível com os motores de banco de dados [`Atomic`](/pt-BR/reference/engines/database-engines/atomic) e [`Replicated`](/pt-BR/reference/engines/database-engines/replicated),
  que são os motores de banco de dados padrão do ClickHouse e do ClickHouse Cloud, respectivamente.
</Note>

Normalmente, para excluir alguns dados de uma tabela,
você pode criar uma nova tabela e preenchê-la com uma instrução `SELECT` que não retorne os dados indesejados,
depois remover a tabela antiga e renomear a nova.
Essa abordagem é demonstrada no exemplo a seguir:

```sql
CREATE TABLE myNewTable AS myOldTable;

INSERT INTO myNewTable
SELECT * FROM myOldTable
WHERE CounterID <12345;

DROP TABLE myOldTable;

RENAME TABLE myNewTable TO myOldTable;
```

Em vez da abordagem acima, também é possível usar `REPLACE` (desde que você use os motores de banco de dados padrão) para alcançar o mesmo resultado:

```sql
REPLACE TABLE myOldTable
ENGINE = MergeTree()
ORDER BY CounterID
AS
SELECT * FROM myOldTable
WHERE CounterID <12345;
```

<div id="syntax">
  ## Sintaxe
</div>

```sql
{CREATE [OR REPLACE] | REPLACE} TABLE [db.]table_name
```

<Note>
  Todas as formas de sintaxe da instrução [`CREATE`](/pt-BR/reference/statements/create/table) também funcionam com esta instrução. Invocar `REPLACE` em uma tabela inexistente causará um erro.
</Note>

<div id="examples">
  ## Exemplos
</div>

<Tabs>
  <Tab title="Local">
    Considere a seguinte tabela:

    ```sql
    CREATE DATABASE base
    ENGINE = Atomic;

    CREATE OR REPLACE TABLE base.t1
    (
        n UInt64,
        s String
    )
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (1, 'test');

    SELECT * FROM base.t1;

    ┌─n─┬─s────┐
    │ 1 │ test │
    └───┴──────┘
    ```

    Podemos usar a instrução `REPLACE` para remover todos os dados:

    ```sql
    CREATE OR REPLACE TABLE base.t1
    (
        n UInt64,
        s Nullable(String)
    )
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (2, null);

    SELECT * FROM base.t1;

    ┌─n─┬─s──┐
    │ 2 │ \N │
    └───┴────┘
    ```

    Também podemos usar a instrução `REPLACE` para alterar a estrutura da tabela:

    ```sql
    REPLACE TABLE base.t1 (n UInt64)
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (3);

    SELECT * FROM base.t1;

    ┌─n─┐
    │ 3 │
    └───┘
    ```
  </Tab>

  <Tab title="Cloud">
    Considere a seguinte tabela no ClickHouse Cloud:

    ```sql

    (
        n UInt64,
        s String
    )
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (1, 'test');

    SELECT * FROM base.t1;

    1    test
    ```

    Podemos usar a instrução `REPLACE` para remover todos os dados:

    ```sql
    CREATE OR REPLACE TABLE base.t1
    (
        n UInt64,
        s Nullable(String)
    )
    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (2, null);

    SELECT * FROM base.t1;

    2
    ```

    Também podemos usar a instrução `REPLACE` para alterar a estrutura da tabela:

    ```sql

    ENGINE = MergeTree
    ORDER BY n;

    INSERT INTO base.t1 VALUES (3);

    SELECT * FROM base.t1;

    ```
  </Tab>
</Tabs>
