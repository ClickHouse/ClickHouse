Cria uma nova coleção nomeada.

<Note>
  Coleções nomeadas criadas por DDL podem ser habilitadas em alguns serviços do ClickHouse Cloud. Entre em contato com o Suporte para confirmar a disponibilidade.
</Note>

**Sintaxe**

```sql
CREATE [OR REPLACE] NAMED COLLECTION [IF NOT EXISTS] name [ON CLUSTER cluster] AS
key_name1 = 'some value' [[NOT] OVERRIDABLE],
key_name2 = 'some value' [[NOT] OVERRIDABLE],
key_name3 = 'some value' [[NOT] OVERRIDABLE],
...
```

`OR REPLACE` e `IF NOT EXISTS` não podem ser usados em conjunto. `CREATE OR REPLACE` aplicado a uma coleção existente
a substitui por completo: chaves e flags de sobrescrita ausentes da nova definição são removidas.

**Exemplo**

```sql
CREATE NAMED COLLECTION foobar AS a = '1', b = '2' OVERRIDABLE;
CREATE OR REPLACE NAMED COLLECTION foobar AS a = '2', c = '3';
```
