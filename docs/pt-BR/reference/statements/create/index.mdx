As instruções CREATE criam, por exemplo, novos [bancos de dados](/pt-BR/reference/statements/create/database), [tabelas](/pt-BR/reference/statements/create/table) e [views](/pt-BR/reference/statements/create/view).

**Sintaxe**

```sql
CREATE DATABASE ...
CREATE TABLE ...
CREATE VIEW ...
CREATE DICTIONARY ...
CREATE FUNCTION ...
CREATE NAMED COLLECTION ...
CREATE USER | ROLE | ROW POLICY | MASKING POLICY | QUOTA | SETTINGS PROFILE ...
```

**Relacionado:** `ATTACH`, `DROP`, `CREATE TABLE`, `CREATE DATABASE`, `CREATE VIEW`, `CREATE DICTIONARY`
