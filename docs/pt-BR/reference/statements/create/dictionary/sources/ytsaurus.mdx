<Info>
  Este é um recurso experimental que pode mudar de formas incompatíveis com versões anteriores em versões futuras.
  Habilite o uso da source de dicionário do YTsaurus
  usando a configuração [`allow_experimental_ytsaurus_dictionary_source`](/pt-BR/reference/settings/session-settings/allow-experimental#allow_experimental_ytsaurus_dictionary_source).
</Info>

Exemplo de configurações:

<Tabs>
  <Tab title="DDL">
    ```sql
    SOURCE(YTSAURUS(
        http_proxy_urls 'http://localhost:8000'
        cypress_path '//tmp/test'
        oauth_token 'password'
    ))
    ```
  </Tab>

  <Tab title="Arquivo de configuração">
    ```xml
    <source>
        <ytsaurus>
            <http_proxy_urls>http://localhost:8000</http_proxy_urls>
            <cypress_path>//tmp/test</cypress_path>
            <oauth_token>password</oauth_token>
            <check_table_schema>1</check_table_schema>
        </ytsaurus>
    </source>
    ```
  </Tab>
</Tabs>

<br />

Campos de configuração:

| Configuração                               | Descrição                                                                                                                                                                                                                         |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `http_proxy_urls`                          | URL do proxy HTTP do YTsaurus.                                                                                                                                                                                                    |
| `cypress_path`                             | Caminho do Cypress para a tabela de origem.                                                                                                                                                                                       |
| `oauth_token`                              | Token OAuth.                                                                                                                                                                                                                      |
| `lookup_throttler_max_requests_per_second` | Número máximo de requisições de consulta ao YTsaurus por segundo ao obter chaves para carregamentos seletivos de dicionário (`CACHE`, `COMPLEX_KEY_CACHE` etc.). `0` desabilita o throttling. O padrão é `200000`.                |
| `lookup_max_rows_per_query`                | Número máximo de linhas por requisição de consulta ao YTsaurus. Os carregamentos seletivos são divididos em blocos desse tamanho. `0` (o padrão) significa sem limite: o carregamento seletivo é enviado em uma única requisição. |
