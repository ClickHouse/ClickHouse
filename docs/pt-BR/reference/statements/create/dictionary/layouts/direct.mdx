## direct {#direct}

O dicionário não é armazenado em memória e acessa diretamente a fonte ao processar uma solicitação.

A chave do dicionário tem o tipo [UInt64](/pt-BR/reference/data-types/int-uint).

Somente o lookup é seletivo. `dictGet` e as demais funções de dicionário consultam a fonte pelas chaves solicitadas, mas ler o dicionário **como uma tabela** não é um fetch por chave: `SELECT ... FROM <dictionary> WHERE key IN (...)` lê a fonte inteira e só depois filtra o resultado, pois o filtro de chave não é empurrado (pushed down) para dentro do dicionário. Use as funções de dicionário quando quiser que a fonte seja consultada por chaves específicas.

Todos os tipos de [fontes](/pt-BR/reference/statements/create/dictionary/sources/overview#dictionary-sources), exceto arquivos locais, são suportados.

Exemplo de configuração:

<Tabs>
  <Tab title="DDL">
    ```sql
    LAYOUT(DIRECT())
    ```
  </Tab>

  <Tab title="Arquivo de configuração">
    ```xml
    <layout>
      <direct />
    </layout>
    ```
  </Tab>
</Tabs>
