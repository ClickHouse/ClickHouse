```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

Retorna uma única coluna do tipo `UInt8`, que contém o valor `0` se a tabela ou o banco de dados não existir, ou `1` se a tabela existir no banco de dados especificado.

## Forma com subconsulta {#subquery-form}

O operador `EXISTS` verifica se uma subconsulta retorna alguma linha. Ele retorna `0` se o resultado da subconsulta for vazio; caso contrário, retorna `1`.

Você pode usar `EXISTS` em uma cláusula [`WHERE`](/pt-BR/reference/statements/select/where). A subconsulta não pode fazer referência a tabelas ou colunas da consulta externa.

**Sintaxe**

```sql
EXISTS(subquery)
```

**Exemplos**

Verifique se uma subconsulta retorna linhas:

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

Use `EXISTS` em uma cláusula `WHERE` com uma subconsulta que retorna várias linhas:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

Quando o resultado da subconsulta está vazio, `EXISTS` retorna `0`:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```
