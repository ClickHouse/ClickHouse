Altera as configurações de um motor de banco de dados. As configurações que podem ser alteradas dependem do motor; nem todo motor ou configuração pode ser modificado após a criação do banco de dados.

Esta instrução altera as configurações do motor de banco de dados, e não as configurações de sessão nem os valores padrão das tabelas do banco de dados.

## Sintaxe {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

Use `ON CLUSTER` para executar a instrução em todos os hosts do cluster especificado.
A instrução exige o privilégio `ALTER DATABASE SETTINGS`.

## Configurações compatíveis {#supported-settings}

Consulte a documentação do motor de banco de dados para conhecer suas configurações e restrições. Por exemplo:

* [`Atomic`](/pt-BR/reference/engines/database-engines/atomic) e [`Ordinary`](/pt-BR/reference/engines/database-engines/ordinary) permitem alterar `max_tables`.
* [`MaterializedPostgreSQL`](/pt-BR/reference/engines/database-engines/materialized-postgresql) permite alterar algumas configurações de replicação, como `materialized_postgresql_max_block_size`.
* [`DataLakeCatalog`](/pt-BR/reference/engines/database-engines/datalake) permite alterar algumas configurações do catálogo; as configurações disponíveis dependem do tipo de catálogo.

Um motor ou uma configuração sem suporte gera uma exceção.

## Exemplo {#example}

Altere o número máximo de tabelas em um banco de dados `Atomic`:

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

Defina `max_tables` como `0` para remover esse limite no nível do banco de dados:

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
