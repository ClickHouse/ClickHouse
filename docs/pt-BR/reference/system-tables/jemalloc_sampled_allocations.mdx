## Descrição {#description}

Uma linha por alocação ativa amostrada pelo profiler de heap do jemalloc; a leitura da tabela dispara o flush de um novo perfil de heap. Apenas as threads com o profiler ativado contribuem (setting `jemalloc_enable_profiler` ou config `jemalloc_enable_global_profiler`); cada linha representa aproximadamente `weight` alocações semelhantes.

## Colunas {#columns}

{/*AUTOGENERATED_START*/}

* `trace` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — Endereços do backtrace da alocação, com o leaf frame primeiro (mesma convenção de `system.trace_log.trace`). Simbolize com `addressToSymbol` e `demangle` (requer `allow_introspection_functions`).
* `age_ns` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tempo, em nanossegundos, durante o qual a alocação esteve viva, em relação ao momento em que o profile foi flushed.
* `size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho de alocação solicitado, em bytes.
* `usize` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho utilizável em bytes, isto é, a size class para a qual a solicitação foi arredondada.
* `size_class` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Índice da size class. Faz join com `system.jemalloc_bins.index` para size classes pequenas.
* `arena` ([UInt32](/pt-BR/reference/data-types/int-uint)) — Índice da arena a partir da qual a alocação foi atendida.
* `thr_uid` ([UInt64](/pt-BR/reference/data-types/int-uint)) — id único interno do jemalloc da thread que realizou a alocação.
* `sample_interval` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número médio de bytes alocados entre samples, obtido do header do profile. É o mesmo para todas as linhas.

**Aliases:**

* `alloc_time` — Alias para `now() - intDiv(age_ns, 1000000000)`.
* `weight` — Alias para `1 / (1 - exp((-usize) / sample_interval))`.
