<div id="description">
  ## Descrição
</div>

Contém uma lista de todas as instruções SQL do ClickHouse.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — O nome da instrução SQL.
* `syntax` ([String](/pt-BR/reference/data-types/string)) — A sintaxe da instrução.
* `description` ([String](/pt-BR/reference/data-types/string)) — Uma descrição do que a instrução faz, com exemplos de uso.
* `parent_name` ([String](/pt-BR/reference/data-types/string)) — O nome da instrução que a engloba, por exemplo, SELECT para a cláusula WHERE. Vazio para uma instrução de nível superior.
* `related` ([Array(String)](/pt-BR/reference/data-types/array)) — Os nomes das instruções relacionadas.

{/*AUTOGENERATED_END*/}
