<div id="description">
  ## Descrição
</div>

Contém informações sobre tabelas nas quais foi executado o comando DROP TABLE, mas cuja limpeza de dados ainda não foi realizada.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `index` ([UInt32](/pt-BR/reference/data-types/int-uint)) — Índice na fila marked&#95;dropped&#95;tables.
* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `uuid` ([UUID](/pt-BR/reference/data-types/uuid)) — UUID da tabela.
* `engine` ([String](/pt-BR/reference/data-types/string)) — Nome do mecanismo da tabela.
* `metadata_dropped_path` ([String](/pt-BR/reference/data-types/string)) — Caminho do arquivo de metadados da tabela no diretório metadata&#95;dropped.
* `table_dropped_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário agendado para a próxima tentativa de remover os dados da tabela. Geralmente, corresponde ao horário em que a tabela foi removida, acrescido de `database_atomic_delay_before_drop_table_sec`.

{/*AUTOGENERATED_END*/}

Esta tabela lista apenas tabelas excluídas de bancos de dados `Atomic`. Para essas tabelas, `table_dropped_time` normalmente é baseado em [`database_atomic_delay_before_drop_table_sec`](/pt-BR/reference/settings/server-settings/settings/other#database_atomic_delay_before_drop_table_sec). Em bancos de dados `Shared` no ClickHouse Cloud, o período de recuperação é controlado por [`database_shared_drop_table_delay_seconds`](/pt-BR/reference/settings/session-settings/database#database_shared_drop_table_delay_seconds), cujo valor padrão é 8 horas; tabelas excluídas de bancos de dados `Shared` não aparecem em `system.dropped_tables`.

<div id="example">
  ## Exemplo
</div>

O exemplo a seguir mostra como obter informações sobre `dropped_tables`.

```sql
SELECT *
FROM system.dropped_tables\G
```

```text
Row 1:
──────
index:                 0
database:              default
table:                 test
uuid:                  03141bb2-e97a-4d7c-a172-95cc066bb3bd
engine:                MergeTree
metadata_dropped_path: /data/ClickHouse/build/programs/data/metadata_dropped/default.test.03141bb2-e97a-4d7c-a172-95cc066bb3bd.sql
table_dropped_time:    2023-03-16 23:43:31
```
