<div id="description">
  ## Descrição
</div>

Contém informações sobre todas as entradas no cache do sistema de arquivos de objetos remotos.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/pt-BR/reference/data-types/string)) — Nome do objeto de cache. Pode ser usado nos comandos `SYSTEM DESCRIBE FILESYSTEM CACHE <name>` e `SYSTEM DROP FILESYSTEM CACHE <name>`
* `cache_base_path` ([String](/pt-BR/reference/data-types/string)) — Caminho do diretório base onde são armazenados todos os arquivos de um cache identificado por `cache_name`.
* `cache_path` ([String](/pt-BR/reference/data-types/string)) — Caminho de um arquivo de cache específico, correspondente a um segmento de arquivo no arquivo de origem
* `key` ([String](/pt-BR/reference/data-types/string)) — Chave de cache do segmento de arquivo
* `file_segment_range_begin` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Deslocamento correspondente ao início do intervalo do segmento de arquivo
* `file_segment_range_end` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Deslocamento correspondente ao fim inclusivo do intervalo do segmento de arquivo
* `size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho do segmento de arquivo
* `state` ([String](/pt-BR/reference/data-types/string)) — Estado do segmento de arquivo (DOWNLOADED, DOWNLOADING, PARTIALLY&#95;DOWNLOADED, ...)
* `finished_download_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Momento em que o download do segmento de arquivo foi concluído.
* `cache_hits` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de acertos no cache do segmento de arquivo correspondente
* `references` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de referências ao segmento de arquivo correspondente. O valor 1 significa que ninguém o está usando no momento (a única referência existente é a do próprio armazenamento em cache)
* `downloaded_size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho baixado do segmento de arquivo
* `kind` ([String](/pt-BR/reference/data-types/string)) — Tipo do segmento de arquivo (usado para distinguir segmentos de arquivo adicionados como parte de &#39;Dados temporários no cache&#39;)
* `unbound` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag interna de implementação
* `user_id` ([String](/pt-BR/reference/data-types/string)) — ID do usuário que criou o segmento de arquivo
* `segment_type` ([String](/pt-BR/reference/data-types/string)) — Tipo do segmento. Usado para separar arquivos de dados (`.json`, `.txt` etc.) de arquivos de dados (`.bin`, arquivos de marcação).
* `file_size` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Tamanho do arquivo ao qual pertence o segmento de arquivo atual

{/*AUTOGENERATED_END*/}
