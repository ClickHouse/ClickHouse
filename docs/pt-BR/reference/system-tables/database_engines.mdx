## Descrição {#description}

Contém a lista de motores de banco de dados suportados pelo servidor.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — O nome do motor de banco de dados.
* `description` ([String](/pt-BR/reference/data-types/string)) — Uma descrição geral do que o motor de banco de dados faz.
* `syntax` ([String](/pt-BR/reference/data-types/string)) — Como o motor de banco de dados é especificado na cláusula ENGINE de uma consulta CREATE DATABASE.
* `examples` ([String](/pt-BR/reference/data-types/string)) — Exemplos de uso.
* `introduced_in` ([String](/pt-BR/reference/data-types/string)) — A versão do ClickHouse em que o motor de banco de dados foi introduzido pela primeira vez, no formato major.minor.
* `related` ([Array(String)](/pt-BR/reference/data-types/array)) — Os nomes de motores de banco de dados relacionados.

## Exemplo {#example}

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```
