## Descrição {#description}

Mostra os [watches](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches) ativos no momento, registrados por este servidor ClickHouse em nós do ZooKeeper (incluindo ZooKeepers auxiliares). Cada linha representa um watch.

**Disponibilidade**

`system.zookeeper_watches` existe somente quando o ClickHouse Keeper ou o ZooKeeper está configurado. Em servidores sem nenhum dos dois configurados, a tabela não existe e as consultas a ela falharão com `UNKNOWN_TABLE`.

## Colunas {#columns}

* `zookeeper_name` ([String](/pt-BR/reference/data-types/string)) — Nome da conexão do ZooKeeper (&quot;default&quot; para a conexão principal ou o nome auxiliar).
* `create_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Momento em que o watch foi criado.
* `create_time_microseconds` ([DateTime64(6)](/pt-BR/reference/data-types/datetime64)) — Momento em que o watch foi criado, com precisão de microssegundos.
* `path` ([String](/pt-BR/reference/data-types/string)) — Caminho do ZooKeeper que está sendo monitorado.
* `session_id` ([Int64](/pt-BR/reference/data-types/int-uint)) — ID da sessão da conexão que registrou o watch.
* `request_xid` ([Int64](/pt-BR/reference/data-types/int-uint)) — XID da requisição que criou o watch.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/pt-BR/reference/data-types/enum)) — Operação que criou o watch.
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/pt-BR/reference/data-types/enum)) — Tipo de watch: Children (list), Exists ou Data (get).
