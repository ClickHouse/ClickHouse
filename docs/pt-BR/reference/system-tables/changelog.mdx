## Descrição {#description}

Contém as entradas do registro de alterações oficial do ClickHouse (o `CHANGELOG.md` do repositório), com uma linha por entrada de cada lançamento de funcionalidades, permitindo consultar as notas de versão com SQL.

## Colunas {#columns}

* `version` ([Tuple(major UInt16, minor UInt8, patch UInt16)](/pt-BR/reference/data-types/tuple)) — Versão do lançamento à qual a entrada pertence, como uma tupla comparável. O registro de alterações curado descreve lançamentos de funcionalidades, portanto `patch` é 0.
* `release_date` ([Date](/pt-BR/reference/data-types/date)) — Data do lançamento.
* `is_lts` ([UInt8](/pt-BR/reference/data-types/int-uint)) — 1 se o lançamento for de suporte de longo prazo.
* `category` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Seção do registro de alterações à qual a entrada pertence, por exemplo, &#39;New Feature&#39;, &#39;Performance Improvement&#39;, &#39;Bug Fix&#39;.
* `description` ([String](/pt-BR/reference/data-types/string)) — Texto da entrada de changelog.
* `pull_requests` ([Array(UInt32)](/pt-BR/reference/data-types/array)) — Números dos pull requests referenciados pela entrada.
* `authors` ([Array(String)](/pt-BR/reference/data-types/array)) — Autores dos pull requests referenciados.

## Exemplo {#example}

Encontre as alterações recentes relacionadas a JSON, do lançamento mais recente para o mais antigo:

```sql
SELECT version, category, description
FROM system.changelog
WHERE description ILIKE '%JSON%' AND version >= (26, 1, 0)
ORDER BY version DESC
LIMIT 3
```
