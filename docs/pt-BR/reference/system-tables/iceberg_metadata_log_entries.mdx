## Descrição {#description}

Esta tabela de sistema contém os arquivos de metadados das tabelas Iceberg existentes no ClickHouse, com uma linha por arquivo de metadados. Ela ficará vazia se você não tiver nenhuma tabela Iceberg no ClickHouse.

## Colunas {#columns}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `timestamp` ([DateTime64(3)](/pt-BR/reference/data-types/datetime64)) — Data e hora em que este arquivo de metadados passou a ser o atual.
* `file` ([String](/pt-BR/reference/data-types/string)) — Caminho do arquivo de metadados.
* `latest_snapshot_id` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — ID do snapshot mais recente no momento em que este arquivo de metadados foi gerado.
* `latest_schema_id` ([Nullable(Int32)](/pt-BR/reference/data-types/nullable)) — ID do esquema do snapshot mais recente.
* `latest_sequence_number` ([Nullable(Int64)](/pt-BR/reference/data-types/nullable)) — Número de sequência do snapshot mais recente.
