## Descrição {#description}

Esta tabela contém métricas dimensionais que podem ser calculadas instantaneamente e exportadas em formato Prometheus. Ela está sempre atualizada.

## Descrição das métricas {#metric_descriptions}

### merge_failures {#merge_failures}

Número total de merges com falha desde a inicialização.

### startup_scripts_failure_reason {#startup_scripts_failure_reason}

Indica falhas em scripts de inicialização por tipo de erro. É definida como 1 quando um script de inicialização falha, com o nome do erro como rótulo.

### merge_tree_parts {#merge_tree_parts}

Número de partes de dados do MergeTree, identificadas pelo estado da parte, pelo tipo da parte e por serem ou não partes de projeção.

### `filesystem_cache_evictions_total` {#filesystem-cache-evictions-total}

Número de segmentos de arquivo removidos de um cache do sistema de arquivos, identificado pelo nome do cache. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics`.

### `filesystem_cache_evicted_bytes_total` {#filesystem-cache-evicted-bytes-total}

Total de bytes de segmentos de arquivo removidos de um cache do sistema de arquivos, identificado pelo nome do cache. Desativada por padrão; habilite com `expose_prometheus_eviction_metrics`.

### `filesystem_cache_evictions_by_user_total` {#filesystem-cache-evictions-by-user-total}

Número de segmentos de arquivo removidos de um cache do sistema de arquivos, identificados pelo nome do cache e pelo ID do usuário. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics` e `expose_prometheus_eviction_metrics_per_user`.

### `filesystem_cache_evicted_bytes_by_user_total` {#filesystem-cache-evicted-bytes-by-user-total}

Total de bytes de segmentos de arquivo removidos de um cache do sistema de arquivos, identificados pelo nome do cache e pelo ID do usuário. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics` e `expose_prometheus_eviction_metrics_per_user`.

### `object_storage_queue_failures_total` {#object-storage-queue-failures-total}

Número de falhas de `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), identificado por banco de dados, tabela, estágio de processamento (`read`, `set_processing`, `insert`, `commit`, `after_processing`) e código de erro. Para o estágio `after_processing`, o valor é o número de objetos nos quais a ação `after_processing` (exclusão, rotulagem ou movimentação) não foi concluída.

### `object_storage_queue_permanently_failed_files_total` {#object-storage-queue-permanently-failed-files-total}

Número de arquivos do `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) abandonados permanentemente após esgotarem as tentativas (ou quando as tentativas estão desabilitadas), identificados por banco de dados e tabela. Cada um representa um arquivo cujos dados nunca serão processados.

### `object_storage_queue_newest_seen_object_timestamp_seconds` {#object-storage-queue-newest-seen-object-timestamp-seconds}

Carimbo de tempo unix da última modificação do objeto mais recente visto até o momento por uma tabela `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), identificado por banco de dados e tabela. A série é removida quando a tabela é removida (DROP) ou desanexada. Após uma renomeação, a série com o nome antigo permanece até o próximo restart do servidor.

### `object_storage_queue_newest_committed_object_timestamp_seconds` {#object-storage-queue-newest-committed-object-timestamp-seconds}

Carimbo de tempo unix da última modificação do objeto mais recente totalmente processado até o momento por uma tabela `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), identificado por banco de dados e tabela. A série é excluída quando a tabela é removida ou desanexada. Após uma renomeação, a série do nome antigo permanece até o restart do servidor.

### `object_storage_queue_processed_files_total` {#object-storage-queue-processed-files-total}

Número de arquivos confirmados como processados por esta tabela `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) neste servidor, identificado por banco de dados e tabela.

### `object_storage_queue_last_poll_timestamp_seconds` {#object-storage-queue-last-poll-timestamp-seconds}

Carimbo de tempo unix da última vez em que uma thread de streaming em segundo plano de uma tabela `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) neste servidor iniciou um ciclo de busca por arquivos a processar ou iniciou um lote desse ciclo, identificado por banco de dados e tabela. Ele é definido quando um ciclo começa, depois que a tabela se registra como ativa no Keeper, e novamente antes de cada lote do ciclo; por isso, também avança quando o ciclo não encontra arquivos ou falha, e durante um backlog longo. Ele não avança quando o registro falha. O valor 0 significa que a tabela não fez nenhuma consulta desde que foi iniciada. Ele não avança enquanto a tabela não tiver visões materializadas anexadas e prontas, enquanto o streaming estiver parado ou pausado, ou enquanto o streaming estiver desativado no servidor, porque nesses casos a tabela não consome dados. Todas as threads de streaming de uma tabela gravam na mesma série; portanto, ela mostra o ciclo mais recente entre todas elas. A série é removida quando a tabela é removida ou desanexada. Após uma renomeação, a série do nome antigo permanece até o restart do servidor.

### `system_log_flushes_total` {#system-log-flushes-total}

Número de tentativas de flush do buffer em memória de um log do sistema para sua tabela, identificado pelo banco de dados e pela tabela do log do sistema, bem como pelo resultado (`success`, `failure`).

### `system_log_flushed_rows_total` {#system-log-flushed-rows-total}

Número de linhas gravadas por operações de persistência bem-sucedidas de um log do sistema, identificado pelo banco de dados e pela tabela do log do sistema.

### `system_log_dropped_rows_total` {#system-log-dropped-rows-total}

Número de linhas de um log do sistema que foram perdidas, identificado pelo banco de dados e pela tabela do log do sistema e pelo motivo: `queue_full` para linhas que não foram aceitas porque o buffer em memória atingiu `max_size_rows` (o valor é atualizado quando o buffer é coletado para o próximo flush) e `flush_failed` para linhas de um flush que falhou.

## Colunas {#columns}

* `metric` ([String](/pt-BR/reference/data-types/string)) — Nome da métrica.
* `value` ([Float64](/pt-BR/reference/data-types/float)) — Valor da métrica.
* `description` ([String](/pt-BR/reference/data-types/string)) — Descrição da métrica.
* `labels` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Labels da métrica.

**Aliases:**

* `name` — Alias de `metric`.

## Exemplo {#example}

Você pode usar uma consulta como esta para exportar todas as métricas dimensionais no formato Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```
