<div id="description">
  ## Descrição
</div>

Esta tabela contém métricas dimensionais que podem ser calculadas instantaneamente e exportadas em formato Prometheus. Ela está sempre atualizada.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `metric` ([String](/pt-BR/reference/data-types/string)) — Nome da métrica.
* `value` ([Float64](/pt-BR/reference/data-types/float)) — Valor da métrica.
* `description` ([String](/pt-BR/reference/data-types/string)) — Descrição da métrica.
* `labels` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Labels da métrica.

**Aliases:**

* `name` — Alias de `metric`.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemplo
</div>

Você pode usar uma consulta como esta para exportar todas as métricas dimensionais no formato Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## Descrição das métricas
</div>

<div id="merge_failures">
  ### merge_failures
</div>

Número total de merges com falha desde a inicialização.

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

Indica falhas em scripts de inicialização por tipo de erro. É definida como 1 quando um script de inicialização falha, com o nome do erro como rótulo.

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

Número de partes de dados do MergeTree, identificadas pelo estado da parte, pelo tipo da parte e por serem ou não partes de projeção.

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

Número de segmentos de arquivo removidos de um cache do sistema de arquivos, identificado pelo nome do cache. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

Total de bytes de segmentos de arquivo removidos de um cache do sistema de arquivos, identificado pelo nome do cache. Desativada por padrão; habilite com `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

Número de segmentos de arquivo removidos de um cache do sistema de arquivos, identificados pelo nome do cache e pelo ID do usuário. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics` e `expose_prometheus_eviction_metrics_per_user`.

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

Total de bytes de segmentos de arquivo removidos de um cache do sistema de arquivos, identificados pelo nome do cache e pelo ID do usuário. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics` e `expose_prometheus_eviction_metrics_per_user`.

<div id="object-storage-queue-failures-total">
  ### `object_storage_queue_failures_total`
</div>

Número de falhas de `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), identificado por database, table, estágio de processamento (`read`, `set_processing`, `insert`, `commit`) e código de erro.

<div id="object-storage-queue-permanently-failed-files-total">
  ### `object_storage_queue_permanently_failed_files_total`
</div>

Número de arquivos do `ObjectStorageQueue` (`S3Queue`/`AzureQueue`) abandonados permanentemente após esgotarem as tentativas (ou quando as tentativas estão desabilitadas), identificados por banco de dados e tabela. Cada um representa um arquivo cujos dados nunca serão processados.

<div id="object-storage-queue-newest-seen-object-timestamp-seconds">
  ### `object_storage_queue_newest_seen_object_timestamp_seconds`
</div>

Timestamp Unix da última modificação do objeto mais recente visto até o momento por uma tabela `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), identificado por banco de dados e tabela.

<div id="object-storage-queue-newest-committed-object-timestamp-seconds">
  ### `object_storage_queue_newest_committed_object_timestamp_seconds`
</div>

Timestamp Unix da última modificação do objeto mais recente totalmente processado até o momento por uma tabela `ObjectStorageQueue` (`S3Queue`/`AzureQueue`), identificado por banco de dados e tabela.
