<div id="description">
  ## Descrição
</div>

A tabela contém informações sobre [movimentações em andamento de partes de dados](/pt-BR/reference/statements/alter/partition#move-partitionpart) de tabelas [MergeTree](/pt-BR/reference/engines/table-engines/mergetree-family/mergetree). Cada movimentação de parte de dados é representada por uma única linha.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela que contém a parte de dados em movimentação.
* `elapsed` ([Float64](/pt-BR/reference/data-types/float)) — Tempo decorrido (em segundos) desde o início da movimentação da parte de dados.
* `target_disk_name` ([String](/pt-BR/reference/data-types/string)) — Nome do disco para o qual a parte de dados está sendo movida.
* `target_disk_path` ([String](/pt-BR/reference/data-types/string)) — Caminho até o ponto de montagem do disco no sistema de arquivos.
* `part_name` ([String](/pt-BR/reference/data-types/string)) — Nome da parte de dados que está sendo movida.
* `part_size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho da parte de dados.
* `thread_id` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Identificador da thread que realiza a movimentação.

{/*AUTOGENERATED_END*/}
