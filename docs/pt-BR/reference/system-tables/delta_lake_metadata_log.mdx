## Descrição {#description}

A tabela `system.delta_lake_metadata_log` registra eventos de acesso e parsing de metadados para tabelas Delta Lake lidas pelo ClickHouse. Ela fornece informações detalhadas sobre cada arquivo de metadados, o que é útil para debugging, auditoria e para entender a evolução da estrutura das tabelas Delta.

Essa tabela registra cada arquivo de metadados lido de tabelas Delta Lake. Ela ajuda os usuários a rastrear como o ClickHouse interpreta os metadados de tabelas Delta e a diagnosticar problemas relacionados a schema evolution, resolução de snapshots ou planejamento de consultas.

Essa tabela destina-se principalmente a fins de debugging.

### Controlando a verbosidade do log {#controlling-log-verbosity}

Você pode controlar quais eventos de metadados são registrados por meio da configuração [`delta_lake_log_metadata`](/pt-BR/reference/settings/session-settings/delta-lake#delta_lake_log_metadata).

Para registrar todos os metadados utilizados na consulta atual:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

É seguro truncar ou remover esta tabela a qualquer momento.

## Colunas {#columns}

* `hostname` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Nome do host do servidor que executa a consulta.
* `clickhouse_version` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Versão do servidor ClickHouse que produziu a linha.
* `system_processor` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Arquitetura de CPU do servidor ClickHouse que produziu a linha.
* `event_date` ([Date](/pt-BR/reference/data-types/date)) — Data da entrada.
* `event_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário do evento.
* `query_id` ([String](/pt-BR/reference/data-types/string)) — ID da consulta.
* `table_path` ([String](/pt-BR/reference/data-types/string)) — Caminho da tabela.
* `file_path` ([String](/pt-BR/reference/data-types/string)) — Caminho do arquivo.
* `content` ([String](/pt-BR/reference/data-types/string)) — Conteúdo no formato JSON.
