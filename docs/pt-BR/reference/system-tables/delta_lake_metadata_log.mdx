## Descrição {#description}

Contém o conteúdo dos arquivos de metadados do Delta.

É seguro truncar ou remover esta tabela a qualquer momento.

## Colunas {#columns}

{/*AUTOGENERATED_START*/}

* `hostname` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Nome do host do servidor que executa a consulta.
* `clickhouse_version` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Versão do servidor ClickHouse que produziu a linha.
* `system_processor` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Arquitetura de CPU do servidor ClickHouse que produziu a linha.
* `event_date` ([Date](/pt-BR/reference/data-types/date)) — Data da entrada.
* `event_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário do evento.
* `query_id` ([String](/pt-BR/reference/data-types/string)) — ID da consulta.
* `table_path` ([String](/pt-BR/reference/data-types/string)) — Caminho da tabela.
* `file_path` ([String](/pt-BR/reference/data-types/string)) — Caminho do arquivo.
* `content` ([String](/pt-BR/reference/data-types/string)) — Conteúdo no formato JSON.

{/*AUTOGENERATED_END*/}
