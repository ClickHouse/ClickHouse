<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os handlers HTTP definidos em SQL e criados com CREATE HANDLER.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do handler.
* `protocol` ([Nullable(String)](/pt-BR/reference/data-types/nullable)) — Protocolo composable ao qual o handler está restrito ou NULL se o handler estiver ativo em todos os endpoints HTTP (as portas `http`/`https` integradas e todos os listeners de protocolos composable do tipo HTTP).
* `url_match_type` ([String](/pt-BR/reference/data-types/string)) — Como a URL é correspondida: exata, por prefixo ou por regexp.
* `url` ([String](/pt-BR/reference/data-types/string)) — O padrão de URL ao qual o handler corresponde.
* `methods` ([Array(String)](/pt-BR/reference/data-types/array)) — Métodos HTTP permitidos.
* `type` ([String](/pt-BR/reference/data-types/string)) — O tipo de handler (somente `query` é compatível).
* `query` ([String](/pt-BR/reference/data-types/string)) — A consulta SQL executada pelo handler. Os Secrets ficam ocultos, a menos que o usuário tenha permissão para visualizá-los.
* `create_query` ([String](/pt-BR/reference/data-types/string)) — A instrução CREATE HANDLER. Os Secrets ficam ocultos, a menos que o usuário tenha permissão para visualizá-los.

{/*AUTOGENERATED_END*/}
