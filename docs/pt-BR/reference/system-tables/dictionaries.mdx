<div id="description">
  ## Descrição
</div>

Contém informações sobre [dicionários](/pt-BR/reference/statements/create/dictionary).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados que contém o dicionário criado por uma consulta DDL. String vazia para outros dicionários.
* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do dicionário.
* `uuid` ([UUID](/pt-BR/reference/data-types/uuid)) — UUID do dicionário.
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/pt-BR/reference/data-types/enum)) — Status do dicionário. Valores possíveis: NOT&#95;LOADED — dicionário não está carregado na memória no momento, LOADED — dicionário carregado com êxito, FAILED — não foi possível carregar o dicionário devido a um erro, LOADING — o dicionário está sendo carregado, LOADED&#95;AND&#95;RELOADING — o dicionário foi carregado com êxito e está sendo recarregado (motivos frequentes: consulta SYSTEM RELOAD DICTIONARY, timeout ou alteração na configuração do dicionário), FAILED&#95;AND&#95;RELOADING — não foi possível carregar o dicionário devido a um erro, e ele está sendo carregado.
* `origin` ([String](/pt-BR/reference/data-types/string)) — Caminho para o arquivo de configuração que descreve o dicionário.
* `type` ([String](/pt-BR/reference/data-types/string)) — Tipo de alocação do dicionário. Armazenamento de dicionários na memória.
* `key.names` ([Array(String)](/pt-BR/reference/data-types/array)) — Array de nomes de chaves fornecido pelo dicionário.
* `key.types` ([Array(String)](/pt-BR/reference/data-types/array)) — Array correspondente de tipos de chaves fornecido pelo dicionário.
* `attribute.names` ([Array(String)](/pt-BR/reference/data-types/array)) — Array de nomes de atributos fornecido pelo dicionário.
* `attribute.types` ([Array(String)](/pt-BR/reference/data-types/array)) — Array correspondente de tipos de atributos fornecido pelo dicionário.
* `bytes_allocated` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Quantidade de RAM alocada para o dicionário.
* `hierarchical_index_bytes_allocated` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Quantidade de RAM alocada para o índice hierárquico.
* `query_count` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de consultas desde que o dicionário foi carregado ou desde a última reinicialização bem-sucedida.
* `hit_rate` ([Float64](/pt-BR/reference/data-types/float)) — Para dicionários de cache, a porcentagem de usos em que o valor estava no cache.
* `found_rate` ([Float64](/pt-BR/reference/data-types/float)) — Porcentagem de usos em que o valor foi encontrado.
* `element_count` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de itens armazenados no dicionário.
* `load_factor` ([Float64](/pt-BR/reference/data-types/float)) — Porcentagem de preenchimento do dicionário (para um dicionário hashed, a porcentagem de preenchimento da tabela hash).
* `source` ([String](/pt-BR/reference/data-types/string)) — Texto que descreve a fonte de dados do dicionário.
* `lifetime_min` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Ciclo de vida mínimo do dicionário na memória, após o qual o ClickHouse tenta recarregá-lo (se invalidate&#95;query estiver definido, somente se tiver sido alterado). Definido em segundos.
* `lifetime_max` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Ciclo de vida máximo do dicionário na memória, após o qual o ClickHouse tenta recarregá-lo (se invalidate&#95;query estiver definido, somente se tiver sido alterado). Definido em segundos.
* `loading_start_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Hora de início do carregamento do dicionário.
* `last_successful_update_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Hora de término do carregamento ou da atualização do dicionário. Ajuda a monitorar problemas com fontes de dicionário e investigar suas causas.
* `error_count` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de erros desde o último carregamento bem-sucedido. Ajuda a monitorar problemas com fontes de dicionário e investigar suas causas.
* `loading_duration` ([Float32](/pt-BR/reference/data-types/float)) — Duração do carregamento de um dicionário.
* `last_exception` ([String](/pt-BR/reference/data-types/string)) — Texto do erro que ocorre ao criar ou recarregar o dicionário caso não tenha sido possível criá-lo.
* `comment` ([String](/pt-BR/reference/data-types/string)) — Texto do comentário do dicionário.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemplo
</div>

Configure o dicionário:

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

Certifique-se de que o dicionário esteja carregado.

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
