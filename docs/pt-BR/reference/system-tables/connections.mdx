## Descrição {#description}

Mostra as conexões de cliente abertas nas interfaces de consulta TCP nativo e HTTP.
Uma conexão fica `active` enquanto uma consulta está em execução. Uma conexão fica `idle` enquanto aguarda a próxima consulta.

A tabela não mostra as seguintes conexões:

* Conexões de outros protocolos, como MySQL, PostgreSQL e gRPC.
* Conexões entre servidores.
* Conexões HTTP que não executaram nenhuma consulta, como `/ping` e conexões do Prometheus.

O servidor coleta as conexões somente se a configuração do servidor `collect_connection_metrics` for `true`. Se a configuração for `false`, a tabela fica vazia.
É possível alterar a configuração sem reiniciar o servidor (`SYSTEM RELOAD CONFIG`):

* Ao alterar a configuração para `false`, a tabela fica vazia e o servidor deixa de registrar novas conexões.
* Ao alterar a configuração para `true`, uma conexão já aberta passa a aparecer na tabela na sua próxima consulta.

O servidor adiciona uma conexão TCP à tabela após a autenticação e a remove quando ela é encerrada.
O servidor adiciona uma conexão HTTP à tabela na sua primeira consulta e a remove quando o socket é fechado.
Por isso, a tabela mostra uma conexão HTTP keep-alive como `idle` entre as requisições.

Um usuário sem o privilégio `SHOW CONNECTIONS` vê apenas as próprias conexões.
A verificação usa o ID do usuário, e não o nome. Assim, um usuário renomeado mantém suas conexões, e um novo usuário com o nome antigo não as herda.

`connection_id` é um UUID aleatório. Por isso, ele é único entre servidores, e é possível combinar as tabelas de várias réplicas, por exemplo com `clusterAllReplicas`.

`connected_time` tem o mesmo significado para TCP e HTTP: o momento em que o servidor começou a tratar o socket.
Esse momento é anterior ao handshake TCP, à autenticação e à primeira consulta. Portanto, ele pode ser anterior ao momento em que a conexão aparece na tabela.

## Colunas {#columns}

* `connection_id` ([UUID](/pt-BR/reference/data-types/uuid)) — Identificador único da conexão: um UUID aleatório. É único entre servidores, por exemplo, em `clusterAllReplicas`. Uma conexão TCP recebe o identificador após a autenticação. Uma conexão HTTP recebe o identificador na primeira consulta.
* `protocol` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Protocolo da conexão: TCP (protocolo nativo) ou HTTP.
* `client_address` ([IPv6](/pt-BR/reference/data-types/ipv6)) — Endereço IP do cliente. Atrás de um proxy, é o endereço do cliente se o servidor confiar no protocolo PROXY ou no cabeçalho `X-Forwarded-For`. Para HTTP, é o endereço da última requisição.
* `client_port` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Porta TCP do cliente. Atrás de um proxy, é a porta informada pelo protocolo PROXY ou pelo cabeçalho `X-Forwarded-For`, se o servidor confiar neles. Para HTTP, é a porta da última requisição.
* `server_port` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Porta do servidor que aceitou a conexão.
* `user` ([String](/pt-BR/reference/data-types/string)) — Nome do usuário autenticado. Para uma conexão HTTP, é o usuário da última requisição. Cada requisição em uma conexão keep-alive passa por sua própria autenticação. Se o usuário for renomeado, esta coluna exibirá o nome antigo até a próxima autenticação. A verificação de acesso usa o ID do usuário, não o nome.
* `status` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Status da conexão. `active`: há uma consulta em execução no momento. `idle`: a conexão está aberta, aguardando a próxima consulta ou a próxima requisição HTTP.
* `query_id` ([String](/pt-BR/reference/data-types/string)) — Identificador da consulta em execução no momento. Vazio se a conexão estiver idle.
* `client_name` ([String](/pt-BR/reference/data-types/string)) — Nome da aplicação cliente. Um cliente TCP envia esse nome no handshake. Para HTTP, é o cabeçalho `User-Agent` da última requisição.
* `client_version_major` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Versão principal do cliente, obtida no handshake TCP. 0 para conexões HTTP.
* `client_version_minor` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Versão secundária do cliente, obtida no handshake TCP. 0 para conexões HTTP.
* `client_version_patch` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Versão de patch do cliente, obtida no handshake TCP. 0 para conexões HTTP.
* `connected_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Momento em que o servidor começou a processar o socket. Esse momento é o mesmo para TCP e HTTP: anterior ao handshake, à autenticação e à primeira consulta.
* `last_query_time` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Horário de início da última consulta nesta conexão. NULL se a conexão ainda não tiver executado nenhuma consulta.

## Exemplos {#examples}

```sql
SELECT connection_id, protocol, user, status, query_id, client_name, connected_time, last_query_time
FROM system.connections
FORMAT Vertical;
```

```sql
SELECT hostName(), protocol, status, count()
FROM clusterAllReplicas(default, system.connections)
GROUP BY ALL;
```
