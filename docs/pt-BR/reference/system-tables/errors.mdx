<div id="description">
  ## Descrição
</div>

Contém códigos de erro com o número de vezes que ocorreram.

Para mostrar todos os códigos de erro possíveis, incluindo aqueles que não ocorreram, defina a configuração [system&#95;events&#95;show&#95;zero&#95;values](/pt-BR/reference/settings/session-settings/system#system_events_show_zero_values) como 1.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do erro (errorCodeToName).
* `code` ([Int32](/pt-BR/reference/data-types/int-uint)) — Número do código do erro.
* `value` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de vezes que esse erro ocorreu.
* `last_error_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Momento em que o último erro ocorreu.
* `last_error_message` ([String](/pt-BR/reference/data-types/string)) — Mensagem do último erro.
* `last_error_format_string` ([String](/pt-BR/reference/data-types/string)) — String de formato do último erro.
* `last_error_trace` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — Um stack trace que representa uma lista de endereços físicos onde os métodos chamados estão armazenados.
* `remote` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Exceção remota (ou seja, recebida durante uma das consultas distribuídas).
* `query_id` ([String](/pt-BR/reference/data-types/string)) — ID de uma consulta que causou um erro (se disponível).

{/*AUTOGENERATED_END*/}

<Note>
  Os contadores de alguns erros podem aumentar durante a execução bem-sucedida da consulta. Não é recomendável usar esta tabela para fins de monitoramento do servidor, a menos que você tenha certeza de que o erro correspondente não pode ser um falso positivo.
</Note>

<div id="example">
  ## Exemplo
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
