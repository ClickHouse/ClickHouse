## Descrição {#description}

Contém o estado em memória dos metadados do AzureQueue e as linhas atualmente processadas por arquivo.

## Colunas {#columns}

* `zookeeper_path` ([String](/pt-BR/reference/data-types/string)) — Caminho no ZooKeeper para os metadados
* `file_path` ([String](/pt-BR/reference/data-types/string)) — Caminho do arquivo em processamento
* `file_name` ([String](/pt-BR/reference/data-types/string)) — Nome do arquivo em processamento
* `rows_processed` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de linhas processadas até o momento
* `status` ([String](/pt-BR/reference/data-types/string)) — Status do processamento: Processed, Processing, Failed ou None para um arquivo que o cache conhece, mas para o qual não possui estado, por exemplo, um arquivo cujo processamento foi redefinido. Um `processing_observed_in_keeper_time` não nulo significa que o status `Processing` não foi definido pelo processor que detém o arquivo, e sim lido do Keeper
* `processing_start_time` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Momento em que o processamento do arquivo foi iniciado
* `processing_end_time` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Momento em que o processamento do arquivo foi concluído
* `exception` ([String](/pt-BR/reference/data-types/string)) — Exceção ocorrida durante o processamento. Sempre a da última tentativa deste servidor, nunca a que o Keeper armazena para o arquivo
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Momento em que um processor deste servidor não conseguiu assumir o arquivo e leu o status `Processing` do Keeper em vez de defini-lo ele mesmo. Normalmente o arquivo está retido por outro servidor, mas também pode estar retido por um processor deste próprio servidor que acabara de assumi-lo. Em ambos os casos, `rows_processed`, `processing_start_time`, `processing_end_time` e `exception` descrevem a última tentativa deste servidor de processar o arquivo, e não o processamento que o detém no momento
