## Descrição {#description}

A tabela não existe a menos que o ClickHouse Keeper ou o ZooKeeper esteja configurado. A tabela `system.zookeeper` expõe dados dos clusters do Keeper definidos na configuração.
A consulta deve ter uma condição `path =`   ou uma condição `path IN`  definida na cláusula `WHERE`, como mostrado abaixo. Isso corresponde ao caminho dos filhos dos quais você deseja obter dados.

A consulta `SELECT * FROM system.zookeeper WHERE path = '/clickhouse'` retorna dados de todos os filhos do nó `/clickhouse`.
Para retornar dados de todos os nós raiz, use path = &#39;/&#39;.
Se o caminho especificado em &#39;path&#39; não existir, uma exceção será lançada.

A consulta `SELECT * FROM system.zookeeper WHERE path IN ('/', '/clickhouse')` retorna dados de todos os filhos dos nós `/` e `/clickhouse`.
Se houver, na coleção &#39;path&#39; especificada, um caminho que não existe, uma exceção será lançada.
Isso pode ser usado para fazer um lote de consultas de caminhos do Keeper.

A consulta `SELECT * FROM system.zookeeper WHERE path = '/clickhouse' AND zookeeperName = 'auxiliary_cluster'` retorna dados no cluster ZooKeeper `auxiliary_cluster`.
Se o `auxiliary_cluster` especificado não existir, uma exceção será lançada.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — O nome do nó.
* `value` ([String](/pt-BR/reference/data-types/string)) — Valor do nó.
* `zookeeperName` ([String](/pt-BR/reference/data-types/string)) — O nome do cluster ZooKeeper padrão ou de um dos auxiliares.
* `czxid` ([Int64](/pt-BR/reference/data-types/int-uint)) — ID da transação que criou o nó.
* `mzxid` ([Int64](/pt-BR/reference/data-types/int-uint)) — ID da transação que alterou o nó pela última vez.
* `ctime` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário de criação do nó.
* `mtime` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário da última modificação do nó.
* `version` ([Int32](/pt-BR/reference/data-types/int-uint)) — Versão do nó: o número de vezes que o nó foi alterado.
* `cversion` ([Int32](/pt-BR/reference/data-types/int-uint)) — Número de descendentes adicionados ou removidos.
* `aversion` ([Int32](/pt-BR/reference/data-types/int-uint)) — Número de alterações na ACL.
* `ephemeralOwner` ([Int64](/pt-BR/reference/data-types/int-uint)) — Para nós efêmeros, o ID da sessão proprietária deste nó.
* `dataLength` ([Int32](/pt-BR/reference/data-types/int-uint)) — Tamanho do valor.
* `numChildren` ([Int32](/pt-BR/reference/data-types/int-uint)) — Número de descendentes.
* `pzxid` ([Int64](/pt-BR/reference/data-types/int-uint)) — ID da transação que excluiu ou adicionou descendentes pela última vez.
* `path` ([String](/pt-BR/reference/data-types/string)) — O caminho até o nó.
