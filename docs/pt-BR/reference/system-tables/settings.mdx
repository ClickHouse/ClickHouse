<div id="description">
  ## Descrição
</div>

Contém informações sobre as configurações de sessão do usuário atual.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome da configuração.
* `value` ([String](/pt-BR/reference/data-types/string)) — Valor da configuração.
* `changed` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Mostra se a configuração foi definida explicitamente no arquivo de configuração ou alterada explicitamente.
* `description` ([String](/pt-BR/reference/data-types/string)) — Breve descrição da configuração.
* `min` ([Nullable(String)](/pt-BR/reference/data-types/nullable)) — Valor mínimo da configuração, se houver algum definido por meio de restrições. Se a configuração não tiver valor mínimo, contém NULL.
* `max` ([Nullable(String)](/pt-BR/reference/data-types/nullable)) — Valor máximo da configuração, se houver algum definido por meio de restrições. Se a configuração não tiver valor máximo, contém NULL.
* `disallowed_values` ([Array(String)](/pt-BR/reference/data-types/array)) — Lista de valores não permitidos
* `readonly` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Mostra se o usuário atual pode alterar a configuração: 0 — O usuário atual pode alterar a configuração, 1 — O usuário atual não pode alterar a configuração.
* `type` ([String](/pt-BR/reference/data-types/string)) — O tipo de valor que pode ser atribuído a esta configuração.
* `default` ([String](/pt-BR/reference/data-types/string)) — Valor padrão da configuração.
* `alias_for` ([String](/pt-BR/reference/data-types/string)) — O nome da configuração original se a configuração for um alias de outra configuração.
* `is_obsolete` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Mostra se uma configuração está obsoleta.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/pt-BR/reference/data-types/enum)) — Nível de suporte deste recurso. Os recursos do ClickHouse são organizados em níveis, que variam conforme o estágio atual de seu
  desenvolvimento e as expectativas que se pode ter ao usá-los:
  * PRODUCTION: O recurso é stable, seguro para uso e não apresenta problemas de interação com outros recursos PRODUCTION.
  * BETA: O recurso é stable e seguro. O resultado de usá-lo em conjunto com outros recursos é desconhecido, e a correção não é garantida. Testes e relatos são bem-vindos.
  * EXPERIMENTAL: O recurso está em desenvolvimento. Destina-se apenas a desenvolvedores e entusiastas do ClickHouse. O recurso pode ou não funcionar e pode ser removido a qualquer momento.
  * OBSOLETE: Não é mais compatível. Ou já foi removido ou será removido em lançamentos futuros.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemplo
</div>

O exemplo a seguir mostra como obter informações sobre configurações cujos nomes contêm `min_i`.

```sql
SELECT *
FROM system.settings
WHERE name LIKE '%min_insert_block_size_%'
FORMAT Vertical
```

Usar `WHERE changed` pode ser útil, por exemplo, quando você quiser verificar:

* Se as configurações nos arquivos de configuração foram carregadas corretamente e estão sendo usadas.
* Quais configurações foram alteradas na sessão atual.

```sql
SELECT * FROM system.settings WHERE changed AND name='load_balancing'
```
