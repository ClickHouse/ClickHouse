<div id="description">
  ## Descrição
</div>

Contém informações sobre arquivos locais que estão na fila para ser enviados aos shards. Esses arquivos locais contêm novas partes criadas ao inserir novos dados na tabela Distributed em modo assíncrono.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `data_path` ([String](/pt-BR/reference/data-types/string)) — Caminho da pasta com arquivos locais.
* `is_blocked` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se o envio de arquivos locais ao servidor está bloqueado.
* `error_count` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de erros.
* `data_files` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de arquivos locais em uma pasta.
* `data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho, em bytes, dos dados comprimidos nos arquivos locais.
* `broken_data_files` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de arquivos marcados como corrompidos devido a um erro.
* `broken_data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho, em bytes, dos dados comprimidos nos arquivos corrompidos.
* `last_exception` ([String](/pt-BR/reference/data-types/string)) — Mensagem de texto sobre o último erro ocorrido, se houver.
* `last_exception_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Momento em que ocorreu a última exceção.

{/*AUTOGENERATED_END*/}
