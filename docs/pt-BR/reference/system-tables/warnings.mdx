## Descrição {#description}

Esta tabela exibe avisos sobre o servidor ClickHouse.
Avisos do mesmo tipo são agrupados em um único aviso.
Por exemplo, se o número N de bancos de dados anexados exceder um limiar configurável T, é exibida uma única entrada contendo o valor atual N, em vez de N entradas separadas.
Se o valor atual cair abaixo do limiar, a entrada é removida da tabela.

A tabela pode ser configurada por meio destas configurações:

* [max&#95;table&#95;num&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/pt-BR/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/pt-BR/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## Colunas {#columns}

* `message` ([String](/pt-BR/reference/data-types/string)) — Uma mensagem de aviso emitida pelo servidor ClickHouse.
* `message_format_string` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Uma string de formato usada para formatar a mensagem.

## Exemplos {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
