<div id="description">
  ## Descrição
</div>

Esta tabela de sistema contém os metadados de cada arquivo das tabelas Iceberg existentes no ClickHouse, com uma linha para cada arquivo de dados ou de exclusão referenciado pelo snapshot atual de cada tabela. Ela ficará vazia se você não tiver nenhuma tabela Iceberg no ClickHouse.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `snapshot_id` ([Int64](/pt-BR/reference/data-types/int-uint)) — ID do snapshot em que o arquivo foi adicionado.
* `content` ([Enum8(&#39;DATA&#39; = 0, &#39;POSITION&#95;DELETE&#39; = 1, &#39;EQUALITY&#95;DELETE&#39; = 2)](/pt-BR/reference/data-types/enum)) — Tipo de conteúdo do arquivo.
* `file_path` ([String](/pt-BR/reference/data-types/string)) — Caminho resolvido de armazenamento do arquivo.
* `file_format` ([String](/pt-BR/reference/data-types/string)) — Formato do arquivo, por exemplo, &#39;PARQUET&#39;.
* `record_count` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de registros no arquivo.
* `file_size_in_bytes` ([Int64](/pt-BR/reference/data-types/int-uint)) — Tamanho do arquivo em bytes.
* `partition` ([String](/pt-BR/reference/data-types/string)) — Representação textual da tupla de partição.
* `schema_id` ([Int32](/pt-BR/reference/data-types/int-uint)) — ID do schema resolvido para esta entrada do manifest.
* `sequence_number` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de sequência resolvido da entrada do manifest (sempre 0 para o formato v1).
* `sort_order_id` ([Nullable(Int32)](/pt-BR/reference/data-types/nullable)) — ID da ordenação do arquivo, se especificado.
* `null_value_counts` ([Map(Int32, Int64)](/pt-BR/reference/data-types/map)) — Contagem de valores NULL por coluna (ID da coluna -&gt; contagem).
* `column_sizes` ([Map(Int32, Int64)](/pt-BR/reference/data-types/map)) — Tamanho em disco por coluna, em bytes (ID da coluna -&gt; bytes).
* `value_counts` ([Map(Int32, Int64)](/pt-BR/reference/data-types/map)) — Contagem total de valores por coluna (ID da coluna -&gt; contagem).
* `equality_ids` ([Array(Int32)](/pt-BR/reference/data-types/array)) — IDs dos campos de igualdade para arquivos de exclusão por igualdade (vazio para arquivos que não são de exclusão por igualdade).
