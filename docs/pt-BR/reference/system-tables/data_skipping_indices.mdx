## Descrição {#description}

Contém informações sobre os data skipping indexes existentes em todas as tabelas.

## Colunas {#columns}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do índice.
* `type` ([String](/pt-BR/reference/data-types/string)) — Tipo de índice.
* `type_full` ([String](/pt-BR/reference/data-types/string)) — Expressão do tipo de índice na instrução CREATE.
* `expr` ([String](/pt-BR/reference/data-types/string)) — Expressão usada para calcular o índice.
* `creation` ([Enum8(&#39;Explicit&#39; = 0, &#39;Implicit&#39; = 1)](/pt-BR/reference/data-types/enum)) — Indica se o índice foi criado implicitamente (por meio de add&#95;minmax&#95;index&#95;for&#95;numeric&#95;columns ou método semelhante)
* `granularity` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de grânulos no bloco.
* `data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho dos dados comprimidos, em bytes.
* `data_uncompressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho dos dados descomprimidos, em bytes.
* `marks_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho das marcas, em bytes.
