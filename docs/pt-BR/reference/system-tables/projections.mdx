## Descrição {#description}

Contém informações sobre as projeções existentes em todas as tabelas.

## Colunas {#columns}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `name` ([String](/pt-BR/reference/data-types/string)) — Nome da projeção.
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/pt-BR/reference/data-types/enum)) — Tipo de projeção.
* `sorting_key` ([Array(String)](/pt-BR/reference/data-types/array)) — Chave de ordenação da projeção.
* `query` ([String](/pt-BR/reference/data-types/string)) — Consulta da projeção.
* `settings` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Configurações da projeção.

```sql
SELECT * FROM system.projections LIMIT 2 FORMAT Vertical;
```
