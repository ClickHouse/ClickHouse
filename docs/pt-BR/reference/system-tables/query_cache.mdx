<div id="description">
  ## Descrição
</div>

Exibe o conteúdo do [cache de consultas](/pt-BR/concepts/features/performance/caches/query-cache).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `query` ([String](/pt-BR/reference/data-types/string)) — String de consulta.
* `query_id` ([String](/pt-BR/reference/data-types/string)) — ID da consulta.
* `is_subquery` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se a entrada do cache de consultas é o resultado de uma subconsulta.
* `result_size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho da entrada do cache de consultas.
* `tag` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Tag da entrada do cache de consultas.
* `stale` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se a entrada do cache de consultas está desatualizada.
* `shared` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se a entrada do cache de consultas é compartilhada entre vários usuários.
* `compressed` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se a entrada do cache de consultas é comprimida.
* `expires_at` ([DateTime](/pt-BR/reference/data-types/datetime)) — Momento em que a entrada do cache de consultas fica desatualizada.
* `key_hash` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Hash da string de consulta, usado como chave para localizar entradas no cache de consultas.

{/*AUTOGENERATED_END*/}
