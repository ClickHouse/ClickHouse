## Descrição {#description}

Contém as funções ativas do usuário atual. `SET ROLE` altera o conteúdo desta tabela.

## Colunas {#columns}

* `role_name` ([String](/pt-BR/reference/data-types/string)) — Nome da função.
* `with_admin_option` ([UInt8](/pt-BR/reference/data-types/int-uint)) — 1 se a função tiver o privilégio ADMIN OPTION.
* `is_default` ([UInt8](/pt-BR/reference/data-types/int-uint)) — 1 se a função estiver definida como padrão.
