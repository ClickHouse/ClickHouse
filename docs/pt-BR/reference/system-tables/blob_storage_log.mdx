## Descrição {#description}

Contém registros de log com informações sobre várias operações de armazenamento de blobs, como uploads e exclusões.

É seguro truncar ou remover esta tabela a qualquer momento.

## Colunas {#columns}

* `hostname` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Hostname do servidor que executa a consulta.
* `clickhouse_version` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Versão do servidor ClickHouse que produziu a linha.
* `system_processor` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Arquitetura de CPU do servidor ClickHouse que produziu a linha.
* `event_date` ([Date](/pt-BR/reference/data-types/date)) — Data do evento.
* `event_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário do evento.
* `event_time_microseconds` ([DateTime64(6)](/pt-BR/reference/data-types/datetime64)) — Horário do evento com precisão de microssegundos.
* `event_type` ([Enum8(&#39;Upload&#39; = 1, &#39;Delete&#39; = 2, &#39;MultiPartUploadCreate&#39; = 3, &#39;MultiPartUploadWrite&#39; = 4, &#39;MultiPartUploadComplete&#39; = 5, &#39;MultiPartUploadAbort&#39; = 6, &#39;Read&#39; = 7, &#39;Copy&#39; = 8)](/pt-BR/reference/data-types/enum)) — Tipo do evento. Valores possíveis: &#39;Upload&#39;, &#39;Delete&#39;, &#39;MultiPartUploadCreate&#39;, &#39;MultiPartUploadWrite&#39;, &#39;MultiPartUploadComplete&#39;, &#39;MultiPartUploadAbort&#39;, &#39;Read&#39;, &#39;Copy&#39;
* `query_id` ([String](/pt-BR/reference/data-types/string)) — Identificador da consulta associada ao evento, se houver.
* `thread_id` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Identificador da thread que executa a operação.
* `thread_name` ([String](/pt-BR/reference/data-types/string)) — Nome da thread que executa a operação.
* `disk_name` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — Nome do disco associado.
* `bucket` ([String](/pt-BR/reference/data-types/string)) — Nome do bucket.
* `remote_path` ([String](/pt-BR/reference/data-types/string)) — Caminho para o recurso remoto.
* `local_path` ([String](/pt-BR/reference/data-types/string)) — Caminho para o arquivo de metadados no sistema local, que faz referência ao recurso remoto.
* `source_bucket` ([String](/pt-BR/reference/data-types/string)) — Nome do bucket de origem do objeto copiado no evento &#39;Copy&#39;. Vazio para outros eventos.
* `source_remote_path` ([String](/pt-BR/reference/data-types/string)) — Caminho para o objeto de origem dos dados copiados no evento &#39;Copy&#39;. Vazio para outros eventos.
* `data_size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho dos dados envolvidos na operação.
* `elapsed_microseconds` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tempo decorrido da operação, em microssegundos.
* `connection_id` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Identificador da conexão HTTP que transportou a operação, único dentro do processo do servidor. Agrupe por esta coluna para acompanhar uma conexão: o SO recicla portas e inodes de socket assim que um socket é fechado, portanto eles não permitem distinguir conexões consecutivas. 0 se nenhuma requisição HTTP individual puder ser atribuída a esta linha: a operação não usou nenhuma conexão HTTP; usou mais de uma - uma escrita tentada novamente é registrada como uma única linha cujo tempo decorrido abrange todas as tentativas, e nenhuma conexão individual a descreve; ou compartilhou uma requisição com outras linhas - uma exclusão em lote grava uma linha `Delete` por objeto e atribui a conexão apenas à primeira delas. Todas as colunas `connection_*` só têm significado quando `connection_id` é diferente de 0; caso contrário, todas são 0.
* `connection_local_port` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Porta TCP local dessa conexão. Única apenas entre os sockets abertos no mesmo momento; use-a para fazer a correlação com uma captura de pacotes ou com uma linha de /proc/net/tcp obtida naquele momento.
* `connection_socket_inode` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Inode do socket dessa conexão, conforme informado por fstat. Mesma ressalva da porta: único apenas enquanto o socket estiver aberto. 0 se o SO não expuser inodes para sockets, como no macOS.
* `connection_requests` ([UInt32](/pt-BR/reference/data-types/int-uint)) — Número de requisições que a conexão já havia enviado antes desta. 0 significa que esta foi a primeira requisição dela, desde que `connection_id` seja diferente de 0.
* `connection_age_microseconds` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tempo desde que o socket TCP da conexão foi estabelecido. É redefinido a cada reconexão; portanto, mede o tempo de vida do socket, e não do objeto de sessão.
* `connection_idle_microseconds` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tempo em que a conexão permaneceu idle no pool antes de ser entregue para esta operação. 0 na primeira requisição de uma conexão e também quando `connection_id` é 0.
* `error_code` ([Int32](/pt-BR/reference/data-types/int-uint)) — Código de erro da operação. 0 se não houve erro.
* `error` ([String](/pt-BR/reference/data-types/string)) — Mensagem de erro associada ao evento, se houver.

## Exemplo {#example}

Suponha que uma operação no armazenamento de blobs faça upload de um arquivo e que um evento seja registrado:

```sql
SELECT * FROM system.blob_storage_log WHERE query_id = '7afe0450-504d-4e4b-9a80-cd9826047972' ORDER BY event_date, event_time_microseconds \G
```

```text
Row 1:
──────
hostname:                clickhouse.eu-central1.internal
event_date:              2023-10-31
event_time:              2023-10-31 16:03:40
event_time_microseconds: 2023-10-31 16:03:40.481437
event_type:              Upload
query_id:                7afe0450-504d-4e4b-9a80-cd9826047972
thread_id:               2381740
disk_name:               disk_s3
bucket:                  bucket1
remote_path:             rrr/kxo/tbnqtrghgtnxkzgtcrlutwuslgawe
local_path:              store/654/6549e8b3-d753-4447-8047-d462df6e6dbe/tmp_insert_all_1_1_0/checksums.txt
data_size:               259
error:
```

Neste exemplo, a operação de upload foi associada à consulta `INSERT` com o ID `7afe0450-504d-4e4b-9a80-cd9826047972`. O arquivo local de metadados `store/654/6549e8b3-d753-4447-8047-d462df6e6dbe/tmp_insert_all_1_1_0/checksums.txt` faz referência ao caminho remoto `rrr/kxo/tbnqtrghgtnxkzgtcrlutwuslgawe` no bucket `bucket1` no disco `disk_s3`, com tamanho de 259 bytes.
