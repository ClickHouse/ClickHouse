## Descrição {#description}

Contém informações sobre alocações de memória feitas por meio do alocador jemalloc em diferentes classes de tamanho (bins), agregadas de todas as arenas.
Essas estatísticas podem não ser totalmente precisas devido ao cache local de thread no jemalloc.

## Colunas {#columns}

{/*AUTOGENERATED_START*/}

* `index` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Índice do bin, ordenado por tamanho.
* `large` ([UInt8](/pt-BR/reference/data-types/int-uint)) — True para alocações grandes e False para alocações pequenas.
* `size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho das alocações neste bin.
* `allocations` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de alocações.
* `deallocations` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de desalocações.
* `nregs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de regiões por slab.
* `curslabs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número atual de slabs.
* `curregs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número atual de regiões desta classe de tamanho.
* `slab_size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho de cada slab em bytes. Zero para classes de tamanho grandes, que não são baseadas em slab.
* `nonfull_slabs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número atual de slabs que contêm ao menos uma região livre. Zero para classes de tamanho grandes.

**Aliases:**

* `availregs` — Alias de `nregs * curslabs`.
* `util` — Alias de `curregs / availregs`.
* `waste` — Alias de `greatest((curslabs * slab_size) - (curregs * size), 0)`.

{/*AUTOGENERATED_END*/}

## Exemplo {#example}

Identifique os tamanhos das alocações que mais contribuíram para o uso total atual de memória.

```sql
SELECT
    *,
    allocations - deallocations AS active_allocations,
    size * active_allocations AS allocated_bytes
FROM system.jemalloc_bins
WHERE allocated_bytes > 0
ORDER BY allocated_bytes DESC
LIMIT 10
```
