<div id="description">
  ## Descrição
</div>

Contém informações sobre as partes e colunas das tabelas [MergeTree](/pt-BR/reference/engines/table-engines/mergetree-family/mergetree).
Cada linha descreve uma parte de dados.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/pt-BR/reference/data-types/string)) — O nome da partição.
* `name` ([String](/pt-BR/reference/data-types/string)) — Nome da parte de dados.
* `uuid` ([UUID](/pt-BR/reference/data-types/uuid)) — O UUID da parte.
* `part_type` ([String](/pt-BR/reference/data-types/string)) — O formato de armazenamento da parte de dados. Valores possíveis: Wide — Cada coluna é armazenada em um arquivo separado no sistema de arquivos; Compact — Todas as colunas são armazenadas em um único arquivo no sistema de arquivos.
* `active` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se a parte de dados está ativa. Se estiver ativa, a parte de dados será usada em uma tabela. Caso contrário, será excluída. As partes de dados inativas permanecem após a mesclagem.
* `marks` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O número de marcas. Para obter o número aproximado de linhas em uma parte de dados, multiplique o número de marcas pela granularidade do índice (geralmente 8192). Essa indicação não funciona para granularidade adaptativa.
* `rows` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O número de linhas.
* `bytes_on_disk` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O tamanho total, em bytes, de todos os arquivos da parte de dados.
* `data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O tamanho total dos dados comprimidos na parte de dados. Os arquivos auxiliares, como os arquivos com marcas, não estão incluídos.
* `data_uncompressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O tamanho total dos dados não comprimidos na parte de dados. Os arquivos auxiliares, como os arquivos com marcas, não estão incluídos.
* `marks_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O tamanho do arquivo com marcas.
* `modification_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — O horário em que o diretório da parte de dados foi modificado. Normalmente, corresponde ao horário de criação da parte de dados.
* `remove_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — O horário em que a parte de dados se tornou inativa.
* `refcount` ([UInt32](/pt-BR/reference/data-types/int-uint)) — O número de locais em que a parte de dados é usada. Um valor maior que 2 indica que a parte de dados é usada em consultas ou mesclagens.
* `min_date` ([Date](/pt-BR/reference/data-types/date)) — O valor mínimo da coluna Date, caso ela esteja incluída na chave de partição.
* `max_date` ([Date](/pt-BR/reference/data-types/date)) — O valor máximo da coluna Date, caso ela esteja incluída na chave de partição.
* `min_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — O valor mínimo da coluna DateTime, caso ela esteja incluída na chave de partição.
* `max_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — O valor máximo da coluna DateTime, caso ela esteja incluída na chave de partição.
* `partition_id` ([String](/pt-BR/reference/data-types/string)) — ID da partição.
* `min_block_number` ([Int64](/pt-BR/reference/data-types/int-uint)) — O menor número de partes de dados que compõem a parte atual após a mesclagem.
* `max_block_number` ([Int64](/pt-BR/reference/data-types/int-uint)) — O maior número de partes de dados que compõem a parte atual após a mesclagem.
* `level` ([UInt32](/pt-BR/reference/data-types/int-uint)) — A profundidade da árvore de mesclagem. Zero significa que a parte atual foi criada por inserção, e não pela mesclagem de outras partes.
* `data_version` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número usado para determinar quais mutações devem ser aplicadas à parte de dados (mutações com versão superior a data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/pt-BR/reference/data-types/int-uint)) — A quantidade de memória (em bytes) usada pelos valores da chave primária.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/pt-BR/reference/data-types/int-uint)) — A quantidade de memória (em bytes) reservada para os valores da chave primária.
* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `engine` ([String](/pt-BR/reference/data-types/string)) — Nome do mecanismo de tabela sem parâmetros.
* `disk_name` ([String](/pt-BR/reference/data-types/string)) — Nome do disco que armazena a parte de dados.
* `path` ([String](/pt-BR/reference/data-types/string)) — Caminho absoluto para a pasta com os arquivos da parte de dados.
* `column` ([String](/pt-BR/reference/data-types/string)) — Nome da coluna.
* `type` ([String](/pt-BR/reference/data-types/string)) — Tipo da coluna.
* `column_position` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Posição ordinal da coluna na tabela, começando em 1.
* `default_kind` ([String](/pt-BR/reference/data-types/string)) — Tipo de expressão (DEFAULT, MATERIALIZED, ALIAS) do valor padrão ou uma string vazia, caso não esteja definido.
* `default_expression` ([String](/pt-BR/reference/data-types/string)) — Expressão do valor padrão ou uma string vazia, caso não esteja definida.
* `column_bytes_on_disk` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho total da coluna em bytes.
* `column_data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho total dos dados comprimidos da coluna, em bytes.
* `column_data_uncompressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho total dos dados descomprimidos da coluna, em bytes.
* `column_marks_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho das marcas da coluna, em bytes.
* `column_modification_time` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Data e hora da última modificação da coluna.
* `column_ttl_min` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Valor mínimo da expressão TTL calculada para a coluna.
* `column_ttl_max` ([Nullable(DateTime)](/pt-BR/reference/data-types/nullable)) — Valor máximo da expressão TTL calculada para a coluna.
* `statistics` ([Array(String)](/pt-BR/reference/data-types/array)) — Estatísticas da coluna.
* `estimates.min` ([Nullable(String)](/pt-BR/reference/data-types/nullable)) — Valor mínimo estimado da coluna.
* `estimates.max` ([Nullable(String)](/pt-BR/reference/data-types/nullable)) — Valor máximo estimado da coluna.
* `estimates.cardinality` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Cardinalidade estimada da coluna.
* `estimates.null_count` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Número estimado de valores NULL na coluna.
* `estimates.default_count` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Número estimado de linhas iguais ao valor padrão de armazenamento da coluna (NULL para colunas Nullable, 0 / &#39;&#39; / [] / ... para colunas não Nullable). NULL quando não há estatísticas básicas disponíveis.
* `serialization_kind` ([String](/pt-BR/reference/data-types/string)) — Tipo de serialização da coluna
* `substreams` ([Array(String)](/pt-BR/reference/data-types/array)) — Nomes dos subfluxos nos quais a coluna é serializada
* `filenames` ([Array(String)](/pt-BR/reference/data-types/array)) — Nomes dos arquivos de cada subfluxo de uma coluna, respectivamente
* `subcolumns.names` ([Array(String)](/pt-BR/reference/data-types/array)) — Nomes das subcolunas de uma coluna
* `subcolumns.types` ([Array(String)](/pt-BR/reference/data-types/array)) — Tipos das subcolunas de uma coluna
* `subcolumns.serializations` ([Array(String)](/pt-BR/reference/data-types/array)) — Tipos de serialização das subcolunas de uma coluna
* `subcolumns.bytes_on_disk` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — Tamanhos, em bytes, de cada subcoluna
* `subcolumns.data_compressed_bytes` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — Tamanhos dos dados comprimidos de cada subcoluna, em bytes
* `subcolumns.data_uncompressed_bytes` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — Tamanhos dos dados descomprimidos de cada subcoluna, em bytes
* `subcolumns.marks_bytes` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — Tamanhos das marcas de cada subcoluna de uma coluna, em bytes

**Aliases:**

* `bytes` — Alias de `bytes_on_disk`.
* `marks_size` — Alias de `marks_bytes`.
* `part_name` — Alias de `name`.
