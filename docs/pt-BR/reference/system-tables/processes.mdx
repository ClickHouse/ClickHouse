<div id="description">
  ## Descrição
</div>

Esta tabela de sistema é usada para implementar a consulta `SHOW PROCESSLIST`.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se a consulta é inicial. Valores possíveis: 1 — uma consulta inicial (de nível superior), 0 — uma consulta filha iniciada por outra consulta, incluindo consultas para execução distribuída e subconsultas internas.
* `user` ([String](/pt-BR/reference/data-types/string)) — O usuário que fez a consulta. Lembre-se de que, no processamento distribuído, as consultas são enviadas aos servidores remotos usando o usuário default. O campo contém o nome de usuário de uma consulta específica, e não da consulta que a iniciou.
* `query_id` ([String](/pt-BR/reference/data-types/string)) — ID da consulta, se definido.
* `address` ([IPv6](/pt-BR/reference/data-types/ipv6)) — O endereço IP de onde a consulta foi feita. O mesmo se aplica ao processamento distribuído. Para rastrear de onde uma consulta distribuída foi originalmente feita, consulte system.processes no servidor que solicitou a consulta.
* `port` ([UInt16](/pt-BR/reference/data-types/int-uint)) — A porta do cliente usada para fazer a consulta.
* `initial_user` ([String](/pt-BR/reference/data-types/string)) — Nome do usuário que executou a consulta inicial na mesma cadeia de consultas.
* `initial_query_id` ([String](/pt-BR/reference/data-types/string)) — ID da consulta inicial na mesma cadeia de consultas.
* `initial_address` ([IPv6](/pt-BR/reference/data-types/ipv6)) — Endereço IP de onde a consulta inicial na mesma cadeia de consultas foi iniciada.
* `initial_port` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Porta do cliente de onde a consulta inicial na mesma cadeia de consultas foi iniciada.
* `interface` ([UInt8](/pt-BR/reference/data-types/int-uint)) — A interface usada para enviar a consulta. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/pt-BR/reference/data-types/string)) — Nome de usuário do sistema operacional que executa o clickhouse-client.
* `client_hostname` ([String](/pt-BR/reference/data-types/string)) — Hostname da máquina cliente em que o clickhouse-client ou outro cliente TCP é executado.
* `client_name` ([String](/pt-BR/reference/data-types/string)) — Nome do clickhouse-client ou de outro cliente TCP.
* `client_agent` ([LowCardinality(String)](/pt-BR/reference/data-types/lowcardinality)) — O agente de programação com IA que invocou o cliente (por exemplo, `claude-code`, `cursor`), detectado com base em variáveis de ambiente. Vazio se nenhum agente for detectado.
* `client_revision` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Revisão do clickhouse-client ou de outro cliente TCP.
* `client_version_major` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Versão principal do clickhouse-client ou de outro cliente TCP.
* `client_version_minor` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Versão secundária do clickhouse-client ou de outro cliente TCP.
* `client_version_patch` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Componente de patch da versão do clickhouse-client ou de outro cliente TCP.
* `http_method` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Método HTTP que iniciou a consulta. Valores possíveis: 0 - A consulta foi iniciada pela interface TCP, 1 - Foi usado o método GET, 2 - Foi usado o método POST, 4 - Foi usado o método PUT, 5 - Foi usado o método DELETE, 6 - Foi usado o método HEAD.
* `http_user_agent` ([String](/pt-BR/reference/data-types/string)) — Cabeçalho HTTP UserAgent enviado na consulta HTTP.
* `http_referer` ([String](/pt-BR/reference/data-types/string)) — Cabeçalho HTTP Referer enviado na consulta HTTP (contém um endereço absoluto ou parcial da página que fez a consulta).
* `forwarded_for` ([String](/pt-BR/reference/data-types/string)) — Cabeçalho HTTP X-Forwarded-For enviado na consulta HTTP.
* `quota_key` ([String](/pt-BR/reference/data-types/string)) — A chave de quota especificada na configuração de quotas (consulte keyed).
* `distributed_depth` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de vezes que a consulta foi retransmitida internamente entre nós de servidor.
* `elapsed` ([Float64](/pt-BR/reference/data-types/float)) — O tempo, em segundos, desde o início da execução da solicitação.
* `is_cancelled` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se a consulta foi cancelada.
* `is_all_data_sent` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se todos os dados foram enviados ao cliente (ou seja, se a consulta foi concluída no servidor).
* `read_rows` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O número de linhas lidas da tabela. No processamento distribuído, no servidor solicitante, corresponde ao total de todos os servidores remotos.
* `read_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O número de bytes não comprimidos lidos da tabela. No processamento distribuído, no servidor solicitante, corresponde ao total de todos os servidores remotos.
* `total_rows_approx` ([UInt64](/pt-BR/reference/data-types/int-uint)) — A estimativa do número total de linhas que devem ser lidas. No processamento distribuído, no servidor solicitante, corresponde ao total de todos os servidores remotos. Pode ser atualizada durante o processamento da solicitação, à medida que novas fontes a serem processadas se tornam conhecidas.
* `written_rows` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O número de linhas gravadas no armazenamento.
* `written_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — O número de bytes gravados no armazenamento.
* `memory_usage` ([Int64](/pt-BR/reference/data-types/int-uint)) — Quantidade de RAM usada pela consulta. Pode não incluir alguns tipos de memória dedicada.
* `peak_memory_usage` ([Int64](/pt-BR/reference/data-types/int-uint)) — O pico atual de uso de memória.
* `query` ([String](/pt-BR/reference/data-types/string)) — O texto da consulta. Para INSERT, não inclui os dados a serem inseridos.
* `normalized_query_hash` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Um valor de hash numérico, idêntico para consultas que diferem apenas pelos valores dos literais.
* `query_kind` ([String](/pt-BR/reference/data-types/string)) — O tipo da consulta: SELECT, INSERT etc.
* `thread_ids` ([Array(UInt64)](/pt-BR/reference/data-types/array)) — A lista de identificadores de todas as threads que participaram desta consulta.
* `peak_threads_usage` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número máximo de threads simultâneas executando a consulta.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/pt-BR/reference/data-types/map)) — ProfileEvents calculados para esta consulta.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/pt-BR/reference/data-types/map)) — A lista de configurações modificadas no nível do usuário.
* `current_database` ([String](/pt-BR/reference/data-types/string)) — O nome do banco de dados atual.
* `is_internal` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se é uma consulta auxiliar executada internamente.

**Aliases:**

* `ProfileEvents.Names` — Alias de `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — Alias de `mapValues(ProfileEvents)`.
* `Settings.Names` — Alias de `mapKeys(Settings)`.
* `Settings.Values` — Alias de `mapValues(Settings)`.
