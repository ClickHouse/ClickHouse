## Descrição {#description}

Esta tabela não existe se o ZooKeeper não estiver configurado. A tabela &#39;system.zookeeper&#95;connection&#39; mostra as conexões atuais com o ZooKeeper (incluindo os ZooKeepers auxiliares). Cada linha exibe informações sobre uma conexão.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do cluster do ZooKeeper.
* `host` ([String](/pt-BR/reference/data-types/string)) — O hostname/IP do nó do ZooKeeper ao qual o ClickHouse se conectou.
* `port` ([UInt16](/pt-BR/reference/data-types/int-uint)) — A porta do nó do ZooKeeper ao qual o ClickHouse se conectou.
* `index` ([Nullable(UInt8)](/pt-BR/reference/data-types/nullable)) — O índice do nó do ZooKeeper ao qual o ClickHouse se conectou. O índice vem da configuração do ZooKeeper. Se não houver conexão, esta coluna será NULL.
* `connected_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Quando a conexão foi estabelecida.
* `session_uptime_elapsed_seconds` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Segundos decorridos desde que a conexão foi estabelecida.
* `is_expired` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Se a conexão atual expirou.
* `keeper_api_version` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Versão da API do Keeper.
* `client_id` ([Int64](/pt-BR/reference/data-types/int-uint)) — ID da sessão da conexão.
* `xid` ([Int64](/pt-BR/reference/data-types/int-uint)) — XID da sessão atual.
* `enabled_feature_flags` ([Array(Enum16(&#39;FILTERED&#95;LIST&#39; = 0, &#39;MULTI&#95;READ&#39; = 1, &#39;CHECK&#95;NOT&#95;EXISTS&#39; = 2, &#39;CREATE&#95;IF&#95;NOT&#95;EXISTS&#39; = 3, &#39;REMOVE&#95;RECURSIVE&#39; = 4, &#39;MULTI&#95;WATCHES&#39; = 5, &#39;CHECK&#95;STAT&#39; = 6, &#39;PERSISTENT&#95;WATCHES&#39; = 7, &#39;CREATE&#95;WITH&#95;STATS&#39; = 8, &#39;TRY&#95;REMOVE&#39; = 9, &#39;LIST&#95;WITH&#95;STAT&#95;AND&#95;DATA&#39; = 10, &#39;GET&#95;CHILDREN&#95;RECURSIVE&#39; = 11, &#39;CREATE&#95;TTL&#39; = 12, &#39;CREATE&#95;CONTAINER&#39; = 13, &#39;MAX&#95;REQUEST&#95;SIZE&#39; = 14))](/pt-BR/reference/data-types/array)) — Feature flags habilitadas. Aplicável somente ao ClickHouse Keeper.
* `availability_zone` ([String](/pt-BR/reference/data-types/string)) — Zona de disponibilidade
* `session_timeout_ms` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tempo limite da sessão (em milissegundos)
* `last_zxid_seen` ([Int64](/pt-BR/reference/data-types/int-uint)) — Último zxid visto pela sessão atual.

## Exemplos {#examples}

```sql
SELECT
    name,
    host,
    port,
    index,
    connected_time,
    session_uptime_elapsed_seconds,
    is_expired,
    keeper_api_version,
    client_id,
    xid,
    enabled_feature_flags,
    availability_zone
FROM system.zookeeper_connection;
```
