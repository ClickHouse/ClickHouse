## Descrição {#description}

Contém informações sobre as opções de compilação do servidor ClickHouse.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome da opção de compilação.
* `value` ([String](/pt-BR/reference/data-types/string)) — Valor da opção de compilação.

## Exemplo {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
