## Descrição {#description}

Retorna as estatísticas do jemalloc em uma única linha e uma única coluna. Equivalente ao comando SYSTEM JEMALLOC STATS.

## Colunas {#columns}

* `stats` ([String](/pt-BR/reference/data-types/string)) — saída das estatísticas do JEMalloc gerada por malloc&#95;stats&#95;print.
