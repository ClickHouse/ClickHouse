## Descrição {#description}

<Warning>
  A integração com o CatBoost foi removida do ClickHouse e `system.models` não existe mais: ao consultá-la, ocorre a falha `UNKNOWN_TABLE`. Esta página é mantida por causa da documentação que ela publicava; consulte a [visão geral das tabelas de sistema](/pt-BR/reference/system-tables/overview) para ver as tabelas que existem atualmente.
</Warning>

Continha uma lista de modelos CatBoost carregados na memória de um `LibraryBridge`, junto com o horário em que foram carregados.

## Colunas {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/pt-BR/reference/data-types/string)) — Caminho para o modelo treinado.
* `type` ([String](/pt-BR/reference/data-types/string)) — Tipo do modelo. No momento, somente catboost.
* `loading_start_time` ([DateTime](/pt-BR/reference/data-types/datetime)) — Horário em que o carregamento do modelo foi iniciado.
* `loading_duration` ([Float32](/pt-BR/reference/data-types/float)) — Tempo necessário para carregar o modelo.

{/*AUTOGENERATED_END*/}
