## Descrição {#description}

Igual a `system.jemalloc_bins`, mas com uma linha por (arena, bin) em vez de agregar as arenas. Os slabs pertencem a uma única arena, portanto esta tabela identifica a fragmentação em uma arena específica (incluindo as arenas dedicadas de metadados do MergeTree, JIT e cache) e faz junção com `system.jemalloc_sampled_allocations` tanto por `arena` quanto por classe de tamanho.

## Colunas {#columns}

{/*AUTOGENERATED_START*/}

* `arena` ([UInt32](/pt-BR/reference/data-types/int-uint)) — Índice da arena. Corresponde a `system.jemalloc_sampled_allocations.arena`.
* `purpose` ([String](/pt-BR/reference/data-types/string)) — Finalidade de uma arena dedicada de longa duração: &#39;mergetree&#39; (metadados de partes e tabelas), &#39;jit&#39;, &#39;cache&#39;. Vazio para arenas de uso geral. Por definição, arenas dedicadas mantêm alocações de longa duração; os relatórios de fragmentação geralmente as excluem.
* `index` ([UInt16](/pt-BR/reference/data-types/int-uint)) — Índice do bin ordenado por tamanho.
* `large` ([UInt8](/pt-BR/reference/data-types/int-uint)) — True para alocações grandes e False para pequenas.
* `size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho das alocações neste bin.
* `allocations` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de alocações.
* `deallocations` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de desalocações.
* `nregs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número de regiões por slab.
* `curslabs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número atual de slabs.
* `curregs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número atual de regiões para esta classe de tamanho.
* `slab_size` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho de cada slab em bytes. Zero para classes de tamanho grandes, que não são baseadas em slabs.
* `nonfull_slabs` ([Int64](/pt-BR/reference/data-types/int-uint)) — Número atual de slabs que contêm pelo menos uma região livre. Zero para classes de tamanho grandes.

**Aliases:**

* `availregs` — Alias para `nregs * curslabs`.
* `util` — Alias para `curregs / availregs`.
* `waste` — Alias para `greatest((curslabs * slab_size) - (curregs * size), 0)`.
