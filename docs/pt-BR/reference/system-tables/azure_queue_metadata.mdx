<div id="description">
  ## Descrição
</div>

Contém, para cada objeto de metadados AzureQueue, o número atual de nós processados, em processamento e com falha e, sob demanda, seu conteúdo. Diferentemente de system.azure&#95;queue&#95;metadata&#95;cache, que mostra o cache em memória, esta tabela lê o estado diretamente do Keeper.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/pt-BR/reference/data-types/string)) — Caminho no ZooKeeper para os metadados. Para uma fila em um ZooKeeper auxiliar, esta é a chave de fábrica `<zookeeper_name>:<path>`, e não o caminho bruto do Keeper.
* `processed_nodes_count` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Número de nós no diretório `processed` no Keeper. Definido apenas para o modo `unordered`: no modo `ordered`, não há nós processados por arquivo (consulte `processed_path`); portanto, o valor é NULL.
* `processing_nodes_count` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de nós no diretório `processing` no Keeper
* `failed_nodes_count` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Número de nós no diretório `failed` no Keeper
* `processed_nodes` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Conteúdo (nome do nó -&gt; dados do nó) do diretório `processed` no Keeper. Preenchido apenas no modo `unordered`. Obtido apenas quando esta coluna é selecionada.
* `processing_nodes` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Conteúdo (nome do nó -&gt; dados do nó) do diretório `processing` no Keeper. Obtido apenas quando esta coluna é selecionada.
* `failed_nodes` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Conteúdo (nome do nó -&gt; dados do nó) do diretório `failed` no Keeper. Obtido apenas quando esta coluna é selecionada.
* `processed_path` ([Map(String, String)](/pt-BR/reference/data-types/map)) — Último caminho processado para cada ponteiro processado no Keeper (caminho relativo do ponteiro -&gt; caminho do último arquivo processado). Preenchido apenas no modo `ordered`, em que abrange os ponteiros único, por bucket e por partição. Obtido apenas quando esta coluna é selecionada.
