<div id="description">
  ## Descrição
</div>

Contém informações sobre as colunas de todas as tabelas.

Você pode usar esta tabela para obter informações semelhantes às da consulta [DESCRIBE TABLE](/pt-BR/reference/statements/describe-table), mas para várias tabelas ao mesmo tempo.

As colunas de [tabelas temporárias](/pt-BR/reference/statements/create/table/temporary-table) ficam visíveis em `system.columns` apenas na sessão em que foram criadas. Elas são exibidas com o campo `database` vazio.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/reference/data-types/string)) — Nome da tabela.
* `name` ([String](/pt-BR/reference/data-types/string)) — Nome da coluna.
* `type` ([String](/pt-BR/reference/data-types/string)) — Tipo da coluna.
* `position` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Posição ordinal de uma coluna na tabela, começando em 1.
* `default_kind` ([String](/pt-BR/reference/data-types/string)) — Tipo de expressão (DEFAULT, MATERIALIZED, ALIAS) do valor padrão ou uma string vazia, caso não esteja definido.
* `default_expression` ([String](/pt-BR/reference/data-types/string)) — Expressão do valor padrão ou uma string vazia, caso não esteja definida.
* `data_compressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho dos dados comprimidos, em bytes.
* `data_uncompressed_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho dos dados descomprimidos, em bytes.
* `marks_bytes` ([UInt64](/pt-BR/reference/data-types/int-uint)) — Tamanho das marcas, em bytes.
* `comment` ([String](/pt-BR/reference/data-types/string)) — Comentário da coluna ou uma string vazia, caso não esteja definido.
* `is_in_partition_key` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se a coluna faz parte da expressão de partição.
* `is_in_sorting_key` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se a coluna faz parte da expressão da chave de ordenação.
* `is_in_primary_key` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se a coluna faz parte da expressão da chave primária.
* `is_in_sampling_key` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se a coluna faz parte da expressão da chave de amostragem.
* `compression_codec` ([String](/pt-BR/reference/data-types/string)) — Nome do codec de compressão.
* `character_octet_length` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Comprimento máximo, em bytes, de dados binários, caracteres, texto e imagens. No ClickHouse, aplica-se apenas ao tipo de dados FixedString. Caso contrário, retorna o valor NULL.
* `numeric_precision` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Precisão de dados numéricos aproximados, exatos, inteiros ou monetários. No ClickHouse, corresponde à largura em bits para tipos inteiros e à precisão decimal para tipos Decimal. Caso contrário, retorna o valor NULL.
* `numeric_precision_radix` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Base numérica da precisão de dados numéricos aproximados, exatos, inteiros ou monetários. No ClickHouse, é 2 para tipos inteiros e 10 para tipos Decimal. Caso contrário, retorna o valor NULL.
* `numeric_scale` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Escala de dados numéricos aproximados, exatos, inteiros ou monetários. No ClickHouse, aplica-se apenas aos tipos Decimal. Caso contrário, retorna o valor NULL.
* `datetime_precision` ([Nullable(UInt64)](/pt-BR/reference/data-types/nullable)) — Precisão decimal do tipo de dados DateTime64. Para outros tipos de dados, retorna o valor NULL.
* `serialization_hint` ([Nullable(String)](/pt-BR/reference/data-types/nullable)) — Indicação para a coluna escolher a serialização nos inserts com base nas estatísticas.
* `statistics` ([String](/pt-BR/reference/data-types/string)) — Tipos de estatísticas criadas nesta coluna.

**Aliases:**

* `column` — Alias de `name`.

{/*AUTOGENERATED_END*/}
