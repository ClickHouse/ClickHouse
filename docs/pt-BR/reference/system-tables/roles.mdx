## Descrição {#description}

Contém informações sobre as [funções](/pt-BR/concepts/features/security/access-rights#role-management) configuradas.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome da função.
* `id` ([UUID](/pt-BR/reference/data-types/uuid)) — ID da função.
* `storage` ([String](/pt-BR/reference/data-types/string)) — Caminho do armazenamento de funções. Configurado no parâmetro `access_control_path`.
