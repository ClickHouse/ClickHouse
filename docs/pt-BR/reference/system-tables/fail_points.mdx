<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os failpoints disponíveis registrados no servidor, bem como seu tipo e se estão habilitados no momento.

Os failpoints podem ser habilitados e desabilitados em tempo de execução usando as instruções `SYSTEM ENABLE FAILPOINT` e `SYSTEM DISABLE FAILPOINT`.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do failpoint.
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/pt-BR/reference/data-types/enum)) — Tipo de failpoint: &#39;once&#39; é acionado uma única vez e depois é desabilitado automaticamente, &#39;regular&#39; é acionado sempre, &#39;pauseable&#95;once&#39; bloqueia a execução uma vez, &#39;pauseable&#39; bloqueia a execução sempre até ser retomada.
* `enabled` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se o failpoint está habilitado no momento (1) ou desabilitado (0).

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemplo
</div>

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```

