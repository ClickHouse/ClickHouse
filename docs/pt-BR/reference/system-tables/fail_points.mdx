## Descrição {#description}

Contém uma lista de todos os failpoints disponíveis registrados no servidor, bem como seu tipo e se estão habilitados no momento.

Em compilações com suporte a failpoints (`USE_LIBFIU=1`), os failpoints podem ser habilitados e desabilitados em tempo de execução usando as instruções `SYSTEM ENABLE FAILPOINT` e `SYSTEM DISABLE FAILPOINT`. Essas instruções não estão disponíveis em compilações sem suporte a failpoints, embora a tabela continue disponível.

`SYSTEM DISABLE ALL FAILPOINTS` desabilita todos os failpoints de uma só vez e retoma qualquer thread bloqueada em um failpoint pausável, o que é útil para devolver um servidor a um estado limpo sem precisar saber o que está habilitado no momento.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do failpoint.
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/pt-BR/reference/data-types/enum)) — Tipo de failpoint: &#39;once&#39; é acionado uma única vez e depois é desabilitado automaticamente, &#39;regular&#39; é acionado sempre, &#39;pauseable&#95;once&#39; bloqueia a execução uma vez, &#39;pauseable&#39; bloqueia a execução sempre até ser retomada.
* `enabled` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica se o failpoint está habilitado no momento (1) ou desabilitado (0).

## Exemplo {#example}

Este exemplo requer uma compilação com suporte a failpoint (`USE_LIBFIU=1`).

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```

```text title="Response"
┌─name──────────────────────────────────────┬─type────────────┬─enabled─┐
│ replicated_merge_tree_insert_retry_pause  │ pauseable_once  │       1 │
└───────────────────────────────────────────┴─────────────────┴─────────┘
```
