## Descrição {#description}

Igual a [`system.numbers`](/pt-BR/reference/system-tables/numbers), mas com leituras paralelizadas. Os números podem ser retornados em qualquer ordem.

Usado para testes.

## Colunas {#columns}

* `number` ([UInt64](/pt-BR/reference/data-types/int-uint))

## Exemplo {#example}

```sql
SELECT * FROM system.numbers_mt LIMIT 10;
```

│      0 │
│      1 │

│      8 │
│      9 │
└────────┘

10 rows in set. Elapsed: 0.001 sec.
