## Descrição {#description}

Contém uma lista de fusos horários compatíveis com o servidor ClickHouse. Essa lista de fusos horários pode variar dependendo da versão do ClickHouse.

## Colunas {#columns}

* `time_zone` ([String](/pt-BR/reference/data-types/string)) — Lista de fusos horários suportados.

## Exemplo {#example}

```sql
SELECT * FROM system.time_zones LIMIT 10
```

```text
┌─time_zone──────────┐
│ Africa/Abidjan     │
│ Africa/Accra       │
│ Africa/Addis_Ababa │
│ Africa/Algiers     │
│ Africa/Asmara      │
│ Africa/Asmera      │
│ Africa/Bamako      │
│ Africa/Bangui      │
│ Africa/Banjul      │
│ Africa/Bissau      │
└────────────────────┘
```
