## Descrição {#description}

Contém informações sobre os colaboradores. A ordem é aleatória durante a execução da consulta.

## Colunas {#columns}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do colaborador (author) no git log.

## Exemplo {#example}

```sql
SELECT * FROM system.contributors LIMIT 10
```

```text
┌─name─────────────┐
│ Olga Khvostikova │
│ Max Vetrov       │
│ LiuYangkuan      │
│ svladykin        │
│ zamulla          │
│ Šimon Podlipský  │
│ BayoNet          │
│ Ilya Khomutov    │
│ Amy Krishnevsky  │
│ Loud_Scream      │
└──────────────────┘
```

Para localizar seus próprios dados na tabela, use uma consulta:

```sql
SELECT * FROM system.contributors WHERE name = 'Olga Khvostikova'
```

```text
┌─name─────────────┐
│ Olga Khvostikova │
└──────────────────┘
```
