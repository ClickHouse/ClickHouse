<div id="description">
  ## Descrição
</div>

Contém uma lista das [contas de usuário](/pt-BR/concepts/features/security/access-rights#user-account-management) configuradas no servidor.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do usuário.
* `id` ([UUID](/pt-BR/reference/data-types/uuid)) — ID do usuário.
* `storage` ([String](/pt-BR/reference/data-types/string)) — Caminho para o armazenamento de usuários. Configurado no parâmetro access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/pt-BR/reference/data-types/array)) — Exibe os tipos de autenticação. Há várias formas de identificar o usuário: sem senha, com senha em texto simples, com senha codificada em SHA256, com senha codificada em SHA-1 duplo ou com senha codificada em bcrypt.
* `auth_params` ([Array(String)](/pt-BR/reference/data-types/array)) — Parâmetros de autenticação no formato JSON, dependendo do auth&#95;type.
* `valid_until` ([Array(DateTime64(0))](/pt-BR/reference/data-types/array)) — Data e hora de expiração das credenciais do usuário, uma para cada método de autenticação. O valor armazenado é um instante absoluto exibido no fuso horário do servidor ou da sessão; o valor armazenado `0` (a epoch Unix, exibida como `1970-01-01 00:00:00` em um servidor em `UTC`) é o sentinela que indica que as credenciais nunca expiram.
* `auth_grants` ([Array(String)](/pt-BR/reference/data-types/array)) — Para cada método de autenticação: a limitação dos direitos de acesso especificada na cláusula `GRANTS`, ou uma string vazia se os direitos de acesso não forem limitados.
* `host_ip` ([Array(String)](/pt-BR/reference/data-types/array)) — Endereços IP dos hosts autorizados a se conectar ao servidor ClickHouse.
* `host_names` ([Array(String)](/pt-BR/reference/data-types/array)) — Nomes dos hosts autorizados a se conectar ao servidor ClickHouse.
* `host_names_regexp` ([Array(String)](/pt-BR/reference/data-types/array)) — Expressão regular para nomes de hosts autorizados a se conectar ao servidor ClickHouse.
* `host_names_like` ([Array(String)](/pt-BR/reference/data-types/array)) — Nomes dos hosts autorizados a se conectar ao servidor ClickHouse, definidos usando o predicado LIKE.
* `default_roles_all` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Indica que todos os roles concedidos são definidos como padrão para o usuário.
* `default_roles_list` ([Array(String)](/pt-BR/reference/data-types/array)) — Lista de roles concedidos e definidos como padrão.
* `default_roles_except` ([Array(String)](/pt-BR/reference/data-types/array)) — Todos os roles concedidos definidos como padrão, exceto os listados.
* `grantees_any` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Sinalizador que indica se um usuário com qualquer opção de concessão pode concedê-la a qualquer pessoa.
* `grantees_list` ([Array(String)](/pt-BR/reference/data-types/array)) — Lista de usuários ou roles aos quais este usuário pode conceder opções.
* `grantees_except` ([Array(String)](/pt-BR/reference/data-types/array)) — Lista de usuários ou roles aos quais este usuário não pode conceder opções.
* `default_database` ([String](/pt-BR/reference/data-types/string)) — Nome do banco de dados padrão deste usuário.
