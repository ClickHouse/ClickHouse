<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os formatos, com indicadores de se um formato é adequado para entrada/saída e se oferece suporte à paralelização.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/pt-BR/reference/data-types/string)) — Nome do formato.
* `is_input` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se o formato é adequado para entrada de dados.
* `is_output` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se o formato é adequado para saída de dados.
* `supports_parallel_parsing` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se o formato oferece suporte à análise paralela.
* `supports_parallel_formatting` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se o formato oferece suporte à formatação paralela.
* `is_tty_friendly` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se o formato geralmente é exibido corretamente no terminal. Para outros formatos, a CLI solicitará confirmação antes de gerar a saída.
* `content_type` ([String](/pt-BR/reference/data-types/string)) — Content-Type HTTP correspondente ao formato de saída. Pode depender das configurações atuais do formato.
* `supports_random_access` ([UInt8](/pt-BR/reference/data-types/int-uint)) — Flag que indica se o formato oferece suporte ao acesso aleatório na entrada.
* `has_schema_inference` ([UInt8](/pt-BR/reference/data-types/int-uint)) — O formato pode determinar dinamicamente o schema a partir dos dados, seja do cabeçalho ou dos metadados embutidos, seja de um trecho dos dados.
* `has_external_schema` ([UInt8](/pt-BR/reference/data-types/int-uint)) — O formato tem um schema fixo ou aceita um schema predefinido em seu próprio formato.
* `prefers_large_blocks` ([UInt8](/pt-BR/reference/data-types/int-uint)) — O formato gravará blocos maiores na saída e gerará blocos maiores na entrada.
* `supports_append` ([UInt8](/pt-BR/reference/data-types/int-uint)) — É possível acrescentar dados a um único arquivo com este formato.
* `supports_subsets_of_columns` ([UInt8](/pt-BR/reference/data-types/int-uint)) — O formato de entrada pode reconhecer quando determinadas colunas são omitidas.
* `description` ([String](/pt-BR/reference/data-types/string)) — Uma descrição geral do formato.
* `examples` ([String](/pt-BR/reference/data-types/string)) — Exemplos de uso.
* `introduced_in` ([String](/pt-BR/reference/data-types/string)) — A versão do ClickHouse em que o formato foi introduzido pela primeira vez, no formato major.minor.
* `related` ([Array(String)](/pt-BR/reference/data-types/array)) — Os nomes dos formatos relacionados.

{/*AUTOGENERATED_END*/}
