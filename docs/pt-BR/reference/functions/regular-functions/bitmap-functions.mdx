<div id="bitmapAnd">
  ## bitmapAnd
</div>

Introduzido em: v20.1.0

Calcula a conjunção lógica (AND) de dois bitmaps.

**Sintaxe**

```sql
bitmapAnd(bitmap1, bitmap2)
```

**Argumentos**

* `bitmap1` — Primeiro objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction). - `bitmap2` — Segundo objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction).

**Valor retornado**

Retorna um bitmap contendo os bits presentes em ambos os bitmaps de entrada [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction)

**Exemplos**

**Exemplo de uso**

```sql title=Query
SELECT bitmapToArray(bitmapAnd(bitmapBuild([1, 2, 3]), bitmapBuild([3, 4, 5]))) AS res;
```

```response title=Response
┌─res─┐
│ [3] │
└─────┘
```

<div id="bitmapBuild">
  ## bitmapBuild
</div>

Introduzido em: v20.1.0

Cria um bitmap a partir de um array de inteiros. Os tipos de elemento compatíveis são inteiros com e sem sinal de 8, 16, 32 ou 64 bits. É o oposto da função [`bitmapToArray`](/pt-BR/reference/functions/regular-functions/bitmap-functions#bitmapToArray).

**Sintaxe**

```sql
bitmapBuild(array)
```

**Argumentos**

* `array` — Array de inteiros. [`Array((U)Int*)`](/pt-BR/reference/data-types/array)

**Valor retornado**

Retorna um bitmap do array fornecido [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction)

**Exemplos**

**Exemplo de uso**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([1, 2, 3, 4, 5])) AS res, toTypeName(bitmapBuild([1, 2, 3, 4, 5])) AS type;
```

```response title=Response
┌─res────────────┬─type──────────────────────────────────┐
│ 00050102030405 │ AggregateFunction(groupBitmap, UInt8) │
└────────────────┴───────────────────────────────────────┘
```

**bitmap assinado**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([-128, -1]::Array(Int8))) AS res, toTypeName(bitmapBuild([-128, -1]::Array(Int8))) AS type;
```

```response title=Response
┌─res──────┬─type─────────────────────────────────┐
│ 000280FF │ AggregateFunction(groupBitmap, Int8) │
└──────────┴──────────────────────────────────────┘
```

<div id="bitmapContains">
  ## bitmapContains
</div>

Introduzido em: v20.1.0

Verifica se o bitmap contém um elemento específico. O valor é comparado como um inteiro sem sinal do tipo de elemento do bitmap. Para bitmaps com sinal, um elemento negativo corresponde à sua contraparte sem sinal (por exemplo, o valor `Int8` `-1` corresponde a `255`).

**Sintaxe**

```sql
bitmapContains(bitmap, value)
```

**Argumentos**

* `bitmap` — objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction). - `value` — Elemento a ser verificado. [(U)Int8/16/32/64](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna `1` se o bitmap contiver o valor especificado; caso contrário, `0` [`UInt8`](/pt-BR/reference/data-types/int-uint)

**Exemplos**

**Exemplo de uso**

```sql title=Query
SELECT bitmapContains(bitmapBuild([1, 2, 3]), 2) AS res;
```

```response title=Response
┌─res─┐
│   1 │
└─────┘
```

**bitmap assinado**

```sql title=Query
SELECT bitmapContains(bitmapBuild([-1]::Array(Int8)), 255) AS res;
```

```response title=Response
┌─res─┐
│   1 │
└─────┘
```

<div id="bitmapTransform">
  ## bitmapTransform
</div>

Introduzido em: v20.1.0

Substitui elementos em um bitmap de acordo com um mapeamento de `from_array` para `to_array`.
Os valores são interpretados como inteiros sem sinal do tipo de elemento do bitmap (no mesmo domínio de [`bitmapContains`](/pt-BR/reference/functions/regular-functions/bitmap-functions#bitmapContains)).
Para bitmaps com sinal, um elemento negativo corresponde à sua contraparte sem sinal (por exemplo, o valor `Int8` `-1` corresponde a `255`).
Um valor em `to_array` que não cabe no tipo de elemento do bitmap gera `BAD_ARGUMENTS`. Um valor em `from_array`
que não cabe simplesmente não é encontrado, portanto a substituição correspondente não é aplicada.

**Sintaxe**

```sql
bitmapTransform(bitmap, from_array, to_array)
```

**Argumentos**

* `bitmap` — Objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction). - `from_array` — Array dos bits definidos originais a serem substituídos. [`Array(T)`](/pt-BR/reference/data-types/array). - `to_array` — Array dos novos bits definidos a serem usados na substituição. [`Array(T)`](/pt-BR/reference/data-types/array).

**Valor retornado**

Retorna um bitmap com os elementos transformados de acordo com o mapeamento fornecido [`AggregateFunction(groupBitmap, T)`](/pt-BR/reference/data-types/aggregatefunction)

**Exemplos**

**Exemplo de uso**

```sql title=Query
SELECT bitmapToArray(bitmapTransform(bitmapBuild([1, 2, 3, 4, 5]), [2, 4], [20, 40])) AS res;
```

```response title=Response
┌─res───────────┐
│ [1,3,5,20,40] │
└───────────────┘
```

**Bitmap assinado**

```sql title=Query
SELECT arraySort(bitmapToArray(bitmapTransform(bitmapBuild([-1, 0]::Array(Int8)), [255], [10]))) AS res;
```

```response title=Response
┌─res────┐
│ [0,10] │
└────────┘
```
