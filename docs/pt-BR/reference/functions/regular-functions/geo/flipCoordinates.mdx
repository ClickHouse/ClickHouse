## flipCoordinates {#flipcoordinates}

A função `flipCoordinates` inverte as coordenadas de um ponto, anel, polígono ou multipolígono. Isso é útil, por exemplo, ao converter entre sistemas de coordenadas em que a ordem de latitude e longitude é diferente.

```sql
flipCoordinates(coordinates)
```

### Parâmetros de entrada {#input-parameters}

* `coordinates` — Uma tupla que representa um ponto `(x, y)` ou um Array dessas tuplas que representa um anel, polígono ou multipolígono. Os tipos de entrada compatíveis incluem:

  * [**Point**](/pt-BR/reference/data-types/geo#point): Uma tupla `(x, y)` em que `x` e `y` são valores [Float64](/pt-BR/reference/data-types/float).
  * [**Anel**](/pt-BR/reference/data-types/geo#ring): Um Array de pontos `[(x1, y1), (x2, y2), ...]`.
  * [**Polígono**](/pt-BR/reference/data-types/geo#polygon): Um Array de anéis `[ring1, ring2, ...]`, em que cada anel é um Array de pontos.
  * [**Multipolígono**](/pt-BR/reference/data-types/geo#multipolygon): Um Array de polígonos `[polygon1, polygon2, ...]`.

  As coordenadas devem ser `Float64`: escreva coordenadas inteiras como `10.` (ou converta-as com CAST), pois um literal como `10` é do tipo `UInt8`.

### Valor retornado {#returned-value}

A função retorna a entrada com as coordenadas invertidas. Por exemplo:

* Um ponto `(x, y)` passa a ser `(y, x)`.
* Um anel `[(x1, y1), (x2, y2)]` passa a ser `[(y1, x1), (y2, x2)]`.
* Estruturas aninhadas, como polígonos e multipolígonos, são processadas recursivamente.

### Exemplos {#examples}

#### Exemplo 1: Invertendo um único ponto {#example-1}

```sql
SELECT flipCoordinates((10., 20.)) AS flipped_point
```

```text
┌─flipped_point─┐
│ (20,10)       │
└───────────────┘
```

#### Exemplo 2: Invertendo um Array de pontos (Anel) {#example-2}

```sql
SELECT flipCoordinates([(10., 20.), (30., 40.)]) AS flipped_ring
```

```text
┌─flipped_ring──────┐
│ [(20,10),(40,30)] │
└───────────────────┘
```

#### Exemplo 3: Invertendo um Polígono {#example-3}

```sql
SELECT flipCoordinates([[(10., 20.), (30., 40.)], [(50., 60.), (70., 80.)]]) AS flipped_polygon
```

```text
┌─flipped_polygon───────────────────────┐
│ [[(20,10),(40,30)],[(60,50),(80,70)]] │
└───────────────────────────────────────┘
```

#### Exemplo 4: Invertendo um multipolígono {#example-4}

```sql
SELECT flipCoordinates([[[(10., 20.), (30., 40.)]], [[(50., 60.), (70., 80.)]]]) AS flipped_multipolygon
```

```text
┌─flipped_multipolygon──────────────────────┐
│ [[[(20,10),(40,30)]],[[(60,50),(80,70)]]] │
└───────────────────────────────────────────┘
```
