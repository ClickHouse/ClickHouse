## Geometry {#geometry}

As funções de Geometry permitem calcular o perímetro e a área de tipos geométricos como POLYGON, LINESTRING, MULTIPOLYGON, MULTILINESTRING, RING e POINT. Use geometrias no tipo Geometry. Se o valor de entrada for `NULL`, todas as funções abaixo retornarão 0.

## perimeterCartesian {#perimetercartesian}

Calcula o perímetro do objeto Geometry especificado no sistema de coordenadas cartesianas (plano).

**Sintaxe**

```sql
perimeterCartesian(geom)
```

**Argumentos**

* `geom` — Objeto do tipo Geometry. [Geometry](/pt-BR/reference/data-types/geo).

**Valores retornados**

* Número — Perímetro do objeto nas unidades do sistema de coordenadas. [Float64](/pt-BR/reference/data-types/float).

**Exemplo**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('POLYGON((0 0,1 0,1 1,0 1,0 0))');
SELECT perimeterCartesian(geom) FROM geo_dst;
```

```response title="Response"
┌─perimeterCartesian(geom)─┐
│ 4.0                      │
└──────────────────────────┘
```

## perimeterSpherical {#perimeterspherical}

Calcula o perímetro de um objeto do tipo Geometry na superfície de uma esfera.

**Sintaxe**

```sql
perimeterSpherical(geom)
```

**Argumentos**

* `geom` — Objeto do tipo Geometry. [Geometry](/pt-BR/reference/data-types/geo).

**Valores retornados**

* Número — Perímetro em uma esfera de raio 1, em radianos (as coordenadas são longitude e latitude em graus). Multiplique pelo raio da esfera para obter um comprimento, por exemplo, por 6371 para obter quilômetros na Terra. [Float64](/pt-BR/reference/data-types/float).

**Exemplo**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('LINESTRING(0 0,1 0,1 1,0 1,0 0)');
SELECT perimeterSpherical(geom) FROM geo_dst;
```

```response title="Response"
┌─perimeterSpherical(geom)─┐
│      0.06981051179132045 │
└──────────────────────────┘
```

## areaSpherical {#areaspherical}

Calcula a área de um objeto do tipo Geometry na superfície de uma esfera.

**Sintaxe**

```sql
areaSpherical(geom)
```

**Argumentos**

* `geom` — Geometry. [Geometry](/pt-BR/reference/data-types/geo).

**Valores retornados**

* Número — Área em uma esfera de raio 1, em esterradianos (as coordenadas são longitude e latitude em graus). Multiplique pelo quadrado do raio da esfera para obter a área. [Float64](/pt-BR/reference/data-types/float).

**Exemplo**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('POLYGON((0 0,1 0,1 1,0 1,0 0))');
SELECT areaSpherical(geom) FROM geo_dst;
```

```response title="Response"
┌─areaSpherical(geom)────┐
│ -0.0003046096848622019 │
└────────────────────────┘
```
