Você pode usar as funções descritas neste capítulo para inspecionar [ELF](https://en.wikipedia.org/wiki/Executable_and_Linkable_Format) e [DWARF](https://en.wikipedia.org/wiki/DWARF) no profiling de consultas.

<Note>
  Essas funções são lentas e podem ter implicações de segurança.
</Note>

Para o funcionamento correto das funções de introspecção:

* Instale o pacote `clickhouse-common-static-dbg`.

* Defina a configuração [allow&#95;introspection&#95;functions](/pt-BR/reference/settings/session-settings/allow#allow_introspection_functions) como 1.

  Por motivos de segurança, as funções de introspecção ficam desabilitadas por padrão.

O ClickHouse salva relatórios do profiler na tabela de sistema [trace&#95;log](/pt-BR/reference/system-tables/trace_log). Certifique-se de que a tabela e o profiler estejam configurados corretamente.

## addressToLine {#addressToLine}

Introduzido em: v20.1.0

Converte o endereço de uma instrução dentro do executável principal do ClickHouse em um nome de arquivo e número da linha no código-fonte do ClickHouse.

O endereço deve ser um deslocamento dentro do executável principal do ClickHouse, que é a forma como os endereços são armazenados nas colunas `trace` de `system.trace_log`, `system.stack_trace` e `system.crash_log`, e na coluna `last_error_trace` de `system.error_log`.
Endereços de tempo de execução (memória virtual) não são aceitos, para que a função não possa ser usada para descobrir o layout de memória do processo do servidor.
Quadros fora do executável principal são armazenados como `0`, e a função retorna um resultado vazio para eles.

<Note>
  Esta função é lenta e pode envolver considerações de segurança.
</Note>

Para habilitar esta função de introspecção:

* Instale o pacote `clickhouse-common-static-dbg`.
* Defina a configuração [`allow_introspection_functions`](/pt-BR/reference/settings/session-settings/allow#allow_introspection_functions) como `1`.

<Note>
  Esta função é não determinística: ela pode retornar resultados diferentes para os mesmos argumentos.
</Note>

**Sintaxe**

```sql
addressToLine(address_of_binary_instruction)
```

**Argumentos**

* `address_of_binary_instruction` — Deslocamento de uma instrução dentro do executável principal do ClickHouse, conforme armazenado na coluna `trace` de `system.trace_log` e em tabelas semelhantes. [`UInt64`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna o nome do arquivo de código-fonte e o número da linha, separados por dois-pontos, por exemplo, `/build/obj-x86_64-linux-gnu/../src/Common/ThreadPool.cpp:199`. Retorna o nome do binary se nenhuma informação de depuração for encontrada para o endereço, ou uma string vazia para `0`. [`String`](/pt-BR/reference/data-types/string)

**Exemplos**

**Selecionando a primeira string da tabela de sistema `trace_log`**

## addressToLineWithInlines {#addressToLineWithInlines}

Introduzido em: v22.2.0

Semelhante a `addressToLine`, mas retorna um Array com todas as funções inline.
Por isso, é mais lento que `addressToLine`.

O endereço deve ser um deslocamento dentro do executável principal do ClickHouse, que é a forma como os endereços são armazenados nas colunas `trace` de `system.trace_log`, `system.stack_trace` e `system.crash_log`, e na coluna `last_error_trace` de `system.error_log`.
Endereços em tempo de execução (memória virtual) não são aceitos, para que a função não possa ser usada para descobrir o layout de memória do processo do servidor.
Quadros fora do executável principal são armazenados como `0`, e a função retorna um resultado vazio para eles.

Para habilitar esta função de introspecção:

* Instale o pacote `clickhouse-common-static-dbg`.
* Defina a configuração [`allow_introspection_functions`](/pt-BR/reference/settings/session-settings/allow#allow_introspection_functions) como `1`.

<Note>
  Esta função é não determinística: ela pode retornar resultados diferentes para os mesmos argumentos.
</Note>

**Sintaxe**

```sql
addressToLineWithInlines(address_of_binary_instruction)
```

**Argumentos**

* `address_of_binary_instruction` — Deslocamento de uma instrução dentro do executável principal do ClickHouse, conforme armazenado na coluna `trace` de `system.trace_log` e em tabelas semelhantes. [`UInt64`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna um array cujo primeiro elemento é o nome do arquivo de código-fonte e o número da linha, separados por dois-pontos. O segundo, o terceiro etc. elementos listam os nomes dos arquivos de código-fonte, os números das linhas e os nomes das funções inline. Se nenhuma informação de depuração for encontrada, será retornado um array com um único elemento igual ao nome do binary; caso contrário, será retornado um array vazio para `0`. [`Array(String)`](/pt-BR/reference/data-types/array)

## getQueryProfileEvent {#getQueryProfileEvent}

Introduzido em: v26.11.0

Retorna o valor atual de um [evento de criação de perfil](/pt-BR/reference/system-tables/events) para a consulta atual.

O valor é acumulado em todas as threads que executam a consulta, da mesma forma que na coluna `ProfileEvents` de `system.query_log`.
A função é não determinística: ela é avaliada uma vez por [bloco](/pt-BR/resources/develop-contribute/introduction/architecture#block) de dados durante a execução da consulta;
assim, todas as linhas de um mesmo bloco recebem o mesmo valor, e esse valor aumenta à medida que a consulta avança.
Isso pode ser usado para anotar a saída ou os dados inseridos com o progresso da consulta, como o número de linhas ou bytes lidos até o momento.

Em uma consulta distribuída, cada servidor retorna o valor referente à sua própria parte da consulta.
Alguns eventos, como `RealTimeMicroseconds` ou `OSReadBytes`, são atualizados apenas periodicamente, portanto seu valor pode apresentar defasagem.

<Note>
  Esta função é não determinística: ela pode retornar resultados diferentes para os mesmos argumentos.
</Note>

**Sintaxe**

```sql
getQueryProfileEvent(event_name)
```

**Argumentos**

* `event_name` — O nome do evento de criação de perfil, conforme aparece em `system.events`. [`const String`](/pt-BR/reference/data-types/string)

**Valor retornado**

O valor atual do evento de criação de perfil para a consulta atual. [`UInt64`](/pt-BR/reference/data-types/int-uint)

**Exemplos**
