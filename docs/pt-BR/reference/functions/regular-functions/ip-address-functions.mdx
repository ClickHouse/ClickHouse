<div id="IPv4CIDRToRange">
  ## IPv4CIDRToRange
</div>

Introduzido em: v20.1.0

Recebe um endereço IPv4 com o comprimento do prefixo CIDR (Classless Inter-Domain Routing) e retorna o intervalo de endereços da sub-rede como uma tupla com dois valores IPv4: o primeiro e o último endereço dessa sub-rede.
Para a versão IPv6, consulte [`IPv6CIDRToRange`](#IPv4CIDRToRange).

**Sintaxe**

```sql
IPv4CIDRToRange(ipv4, cidr)
```

**Argumentos**

* `ipv4` — Endereço IPv4. [`IPv4`](/pt-BR/reference/data-types/ipv4) ou [`String`](/pt-BR/reference/data-types/string)
* `cidr` — Valor de CIDR. [`UInt8`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna uma tupla com dois endereços IPv4 que representam o intervalo da sub-rede. [`Tuple(IPv4, IPv4)`](/pt-BR/reference/data-types/tuple)

**Exemplos**

**Exemplo de uso**

```sql title=Query
SELECT IPv4CIDRToRange(toIPv4('192.168.5.2'), 16);
```

```response title=Response
┌─IPv4CIDRToRange(toIPv4('192.168.5.2'), 16)─┐
│ ('192.168.0.0','192.168.255.255')          │
└────────────────────────────────────────────┘
```

<div id="IPv4NumToString">
  ## IPv4NumToString
</div>

Introduzido em: v1.1.0

Converte um inteiro de 32 bits em sua representação textual de endereço IPv4 na notação decimal pontuada (formato A.B.C.D).
Interpreta a entrada usando a ordem de bytes big-endian.

**Sintaxe**

```sql
IPv4NumToString(num)
```

**Aliases**: `INET_NTOA`

**Argumentos**

* `num` — endereço IPv4 como um número UInt32. [`UInt32`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna um número que representa o endereço MAC ou `0` se o formato for inválido. [`String`](/pt-BR/reference/data-types/string)

**Exemplos**

**Exemplo de uso**

```sql title=Query
SELECT IPv4NumToString(3232235521)
```

```response title=Response
192.168.0.1
```

<div id="IPv4NumToStringClassC">
  ## IPv4NumToStringClassC
</div>

Introduzido em: v1.1.0

Converte um inteiro de 32 bits em sua representação textual de endereço IPv4 na notação decimal pontuada (formato A.B.C.D),
semelhante a [`IPv4NumToString`](#IPv4NumToString), mas usando `xxx` em vez do último octeto.

**Sintaxe**

```sql
IPv4NumToStringClassC(num)
```

**Argumentos**

* `num` — endereço IPv4 como um número UInt32. [`UInt32`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna a string do endereço IPv4 com xxx substituindo o último octeto. [`String`](/pt-BR/reference/data-types/string)

**Exemplos**

**Exemplo básico com agregação**

```sql title=Query
SELECT
    IPv4NumToStringClassC(ClientIP) AS k,
    count() AS c
FROM VALUES('ClientIP UInt32',
    (toUInt32(toIPv4('83.149.9.10'))), (toUInt32(toIPv4('83.149.9.11'))), (toUInt32(toIPv4('83.149.9.12'))),
    (toUInt32(toIPv4('217.118.81.5'))), (toUInt32(toIPv4('217.118.81.6'))),
    (toUInt32(toIPv4('213.87.129.1'))))
GROUP BY k
ORDER BY c DESC, k
```

```response title=Response
┌─k──────────────┬─c─┐
│ 83.149.9.xxx   │ 3 │
│ 217.118.81.xxx │ 2 │
│ 213.87.129.xxx │ 1 │
└────────────────┴───┘
```

<div id="IPv6NumToString">
  ## IPv6NumToString
</div>

Introduzido em: v1.1.0

Converte um endereço IPv6 do formato binário (FixedString(16)) para sua representação padrão em texto.
Endereços IPv6 mapeados para IPv4 são exibidos no formato `::ffff:111.222.33.44`.

**Sintaxe**

```sql
IPv6NumToString(x)
```

**Aliases**: `INET6_NTOA`

**Argumentos**

* `x` — endereço IPv6 em formato binário. [`FixedString(16)`](/pt-BR/reference/data-types/fixedstring) ou [`IPv6`](/pt-BR/reference/data-types/ipv6)

**Valor retornado**

Retorna o endereço IPv6 em formato de texto. [`String`](/pt-BR/reference/data-types/string)

**Exemplos**

**Exemplo de uso**

```sql title=Query
SELECT IPv6NumToString(toFixedString(unhex('2A0206B8000000000000000000000011'), 16)) AS addr;
```

```response title=Response
┌─addr─────────┐
│ 2a02:6b8::11 │
└──────────────┘
```

**Análise de IPv6 com a tabela hits**

```sql title=Query
CREATE TABLE hits_all (EventDate Date, ClientIP6 FixedString(16)) ENGINE = Memory;

INSERT INTO hits_all SELECT today(), IPv6StringToNum(addr) FROM VALUES('addr String',
    ('2a02:2168:aaa:bbbb::2'), ('2a02:2168:aaa:bbbb::2'), ('2a02:2168:aaa:bbbb::2'),
    ('2a02:6b8:0:fff::ff'), ('2a02:6b8:0:fff::ff'),
    ('::ffff:94.26.111.111'), ('::ffff:94.26.111.111'), ('::ffff:94.26.111.111'), ('::ffff:94.26.111.111'),
    ('::ffff:37.143.222.4'));

-- The addresses that are not an IPv4 address mapped into the IPv6 space.
SELECT
    IPv6NumToString(ClientIP6 AS k),
    count() AS c
FROM hits_all
WHERE EventDate = today() AND substring(ClientIP6, 1, 12) != unhex('00000000000000000000FFFF')
GROUP BY k
ORDER BY c DESC, k
LIMIT 10
```

```response title=Response
┌─IPv6NumToString(k)────┬─c─┐
│ 2a02:2168:aaa:bbbb::2 │ 3 │
│ 2a02:6b8:0:fff::ff    │ 2 │
└───────────────────────┴───┘
```

**Endereços IPv4 mapeados em IPv6**

```sql title=Query
-- Without the filter, the mapped IPv4 addresses show up as well.
SELECT
    IPv6NumToString(ClientIP6 AS k),
    count() AS c
FROM hits_all
WHERE EventDate = today()
GROUP BY k
ORDER BY c DESC, k
LIMIT 10
```

```response title=Response
┌─IPv6NumToString(k)────┬─c─┐
│ ::ffff:94.26.111.111  │ 4 │
│ 2a02:2168:aaa:bbbb::2 │ 3 │
│ 2a02:6b8:0:fff::ff    │ 2 │
│ ::ffff:37.143.222.4   │ 1 │
└───────────────────────┴───┘
```

<div id="IPv6StringToNum">
  ## IPv6StringToNum
</div>

Introduzido em: v1.1.0

Converte um endereço IPv6 da sua representação textual padrão para o formato binário (`FixedString(16)`).
Aceita endereços IPv6 mapeado para IPv4 no formato `::ffff:111.222.33.44.`.
Se o endereço IPv6 tiver um formato inválido, uma exceção será lançada.

Se a string de entrada contiver um endereço IPv4 válido, retornará seu equivalente em IPv6.
HEX pode estar em letras maiúsculas ou minúsculas.

**Sintaxe**

```sql
IPv6StringToNum(string)
```

**Aliases**: `INET6_ATON`

**Argumentos**

* `string` — Endereço IPv6 em formato de string. [`String`](/pt-BR/reference/data-types/string)

**Valor retornado**

Retorna o endereço IPv6 em formato binário. [`FixedString(16)`](/pt-BR/reference/data-types/fixedstring)

**Exemplos**

**Exemplo básico**

```sql title=Query
SELECT addr, cutIPv6(IPv6StringToNum(addr), 0, 0) FROM (SELECT ['127.0.0.1', '1111::ffff'] AS addr) ARRAY JOIN addr;
```

```response title=Response
┌─addr───────┬─cutIPv6(IPv6StringToNum(addr), 0, 0)─┐
│ 127.0.0.1  │ ::ffff:127.0.0.1                     │
│ 1111::ffff │ 1111::ffff                           │
└────────────┴──────────────────────────────────────┘
```

<div id="cutIPv6">
  ## cutIPv6
</div>

Introduzido em: v1.1.0

Aceita um valor `FixedString(16)` que contém o endereço IPv6 em formato binário.
Retorna uma string contendo o endereço com a quantidade especificada de bytes removidos, em formato de texto.

**Sintaxe**

```sql
cutIPv6(x, bytesToCutForIPv6, bytesToCutForIPv4)
```

**Argumentos**

* `x` — Endereço IPv6 em formato binário. [`FixedString(16)`](/pt-BR/reference/data-types/fixedstring) ou [`IPv6`](/pt-BR/reference/data-types/ipv6)
* `bytesToCutForIPv6` — Número de bytes a remover para IPv6. [`UInt8`](/pt-BR/reference/data-types/int-uint)
* `bytesToCutForIPv4` — Número de bytes a remover para IPv4. [`UInt8`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna uma string que contém o endereço IPv6 em formato de texto com os bytes especificados removidos. [`String`](/pt-BR/reference/data-types/string)

**Exemplos**

**Exemplo de uso**

```sql title=Query
WITH
    IPv6StringToNum('2001:0DB8:AC10:FE01:FEED:BABE:CAFE:F00D') AS ipv6,
    IPv4ToIPv6(IPv4StringToNum('192.168.0.1')) AS ipv4
SELECT
    cutIPv6(ipv6, 2, 0),
    cutIPv6(ipv4, 0, 2)
```

```response title=Response
┌─cutIPv6(ipv6, 2, 0)─────────────────┬─cutIPv6(ipv4, 0, 2)─┐
│ 2001:db8:ac10:fe01:feed:babe:cafe:0 │ ::ffff:192.168.0.0  │
└─────────────────────────────────────┴─────────────────────┘
```

<div id="isIPAddressInRange">
  ## isIPAddressInRange
</div>

Introduzido na versão: v21.4.0

Determina se um endereço IP está contido em uma rede representada na notação [Classless Inter-Domain Routing (CIDR)](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing).

Esta função aceita endereços IPv4 e IPv6 (e redes) representados como strings. Ela retorna `0` se a versão de IP do endereço e a do CIDR não corresponderem.

**Sintaxe**

```sql
isIPAddressInRange(address, prefix)
```

**Argumentos**

* `address` — Um endereço IPv4 ou IPv6. [`String`](/pt-BR/reference/data-types/string)
* `prefix` — Um prefixo de rede IPv4 ou IPv6 em CIDR. [`String`](/pt-BR/reference/data-types/string)

**Valor retornado**

Retorna `1` se a versão IP do endereço corresponder à do CIDR; caso contrário, `0`. [`UInt8`](/pt-BR/reference/data-types/int-uint)

**Exemplos**

**Endereço IPv4 no intervalo**

```sql title=Query
SELECT isIPAddressInRange('127.0.0.1', '127.0.0.0/8')
```

```response title=Response
1
```

**Endereço IPv4 fora do intervalo**

```sql title=Query
SELECT isIPAddressInRange('127.0.0.1', 'ffff::/16')
```

```response title=Response
0
```

**Endereço IPv6 fora da faixa**

```sql title=Query
SELECT isIPAddressInRange('::ffff:192.168.0.1', '::ffff:192.168.0.4/128')
```

```response title=Response
0
```

<div id="toIPv4">

```sql
toIPv4(x)
```

* `x` — Um endereço IPv4 [`String`](/pt-BR/reference/data-types/string) ou [`UInt8/16/32`](/pt-BR/reference/data-types/int-uint)

**Valor retornado**

Retorna um endereço IPv4. [`IPv4`](/pt-BR/reference/data-types/ipv4)

**Exemplo de uso**

```sql title=Query
SELECT toIPv4('171.225.130.45');
```

```response title=Response
┌─toIPv4('171.225.130.45')─┐
│ 171.225.130.45           │

```

```sql title=Query
WITH
    '171.225.130.45' AS IPv4_string

    hex(toIPv4(IPv4_string))
```

```response title=Response

```

**Conversão a partir de um inteiro**

```sql title=Query
SELECT toIPv4(2130706433);
```
