## timeSeriesLastToGrid {#timeSeriesLastToGrid}

Introduzida em: v25.6.0

Função de agregação que recebe dados de séries temporais como pares de timestamps e valores e calcula [last&#95;over&#95;time no estilo do PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) a partir desses dados em uma grade temporal regular definida por timestamp inicial, timestamp final e passo. Para cada ponto da grade, é escolhida a amostra mais recente (dentro da janela de tempo especificada).

Alias: `timeSeriesResampleToGridWithStaleness`.

As amostras podem ser passadas de uma destas três formas:

* como dois argumentos `timestamp` e `value`, em que cada linha contém uma única amostra;
* como dois arrays de timestamps e valores, em que cada linha contém uma série temporal inteira;
* como um único array de tuplas `(timestamp, value)`, em que cada linha contém uma série temporal inteira.

Se várias amostras tiverem o mesmo timestamp, apenas uma delas será usada: a de maior valor. Um valor NaN perde para qualquer outro valor; portanto, um valor NaN só é usado se todas as amostras nesse timestamp forem NaN.

<Warning>
  Esta função está em prévia privada. Para habilitá-la, defina `enable_time_series_aggregate_functions=true`.
</Warning>

**Sintaxe**

```sql
timeSeriesLastToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(timestamp, value)
timeSeriesLastToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(samples)
```

**Aliases**: `timeSeriesResampleToGridWithStaleness`

**Parâmetros**

* `start_timestamp` — Especifica o início da grade. Também pode ser um número fracionário ou uma string contendo um número ou um texto de data e hora. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `end_timestamp` — Especifica o fim da grade. Também pode ser um número fracionário ou uma string contendo um número ou um texto de data e hora. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `grid_step` — Especifica o passo da grade, em segundos. Também pode ser um número fracionário ou uma string contendo um número ou uma duração, como &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `staleness_window` — Especifica, em segundos, o tempo máximo durante o qual a amostra mais recente ainda é considerada válida. Também pode ser um número fracionário ou uma string contendo um número ou uma duração, como &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)

**Argumentos**

* `timestamp` — Timestamp da amostra. Pode ser composto por valores individuais ou arrays. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Array(UInt32)`](/pt-BR/reference/data-types/array) ou [`Array(DateTime)`](/pt-BR/reference/data-types/array) ou [`Array(DateTime64)`](/pt-BR/reference/data-types/array)
* `value` — Valor da série temporal correspondente ao timestamp. Pode ser composto por valores individuais ou arrays. [`Float*`](/pt-BR/reference/data-types/float) ou [`Array(Float*)`](/pt-BR/reference/data-types/array)
* `samples` — Amostras da série temporal passadas como um array de tuplas `(timestamp, value)`, em que os elementos da tupla têm os tipos de timestamp e valor listados acima. É uma alternativa a passar os timestamps e os valores como dois argumentos separados. [`Array(Tuple(T1, T2))`](/pt-BR/reference/data-types/array)

**Valor retornado**

Retorna os valores da série temporal reamostrados para a grade especificada, do mesmo tipo que `value`. O array retornado contém um valor para cada ponto da grade temporal. O valor é NULL se não houver amostra para um determinado ponto da grade. [`Array(Nullable(Float*))`](/pt-BR/reference/data-types/array)

**Exemplos**

**Uso básico com pares individuais de timestamp e valor**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to staleness window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    30 AS window_seconds  -- "staleness" window
SELECT timeSeriesLastToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesLastToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,1,3,4,4,NULL,5,8]                                                           │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

**Usando argumentos de array**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    30 AS window_seconds
SELECT timeSeriesLastToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesLastToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,1,3,4,4,NULL,5,8]                                                             │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```
