## timeSeriesTimestampOfFirstToGrid {#timeSeriesTimestampOfFirstToGrid}

Introduzida em: v26.10.0

Função de agregação que recebe dados de séries temporais como pares de timestamps e valores e calcula [ts&#95;of&#95;first&#95;over&#95;time no estilo do PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) a partir desses dados em uma grade temporal regular definida por timestamp inicial, timestamp final e passo. Para cada ponto da grade, o resultado é o timestamp da amostra mais antiga dentro da janela de tempo especificada.

As amostras podem ser fornecidas em uma de três formas:

* como dois argumentos `timestamp` e `value`, em que cada linha contém uma única amostra;
* como dois arrays de timestamps e valores, em que cada linha contém uma série temporal inteira;
* como um único array de tuplas `(timestamp, value)`, em que cada linha contém uma série temporal inteira.

Se várias amostras tiverem o mesmo timestamp, apenas uma delas será usada: a de maior valor. Um valor NaN perde para qualquer outro valor; portanto, um valor NaN só é usado se todas as amostras nesse timestamp forem NaN.

<Warning>
  Esta função está em prévia privada; para habilitá-la, defina `enable_time_series_aggregate_functions=true`.
</Warning>

**Sintaxe**

```sql
timeSeriesTimestampOfFirstToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(timestamp, value)
timeSeriesTimestampOfFirstToGrid(start_timestamp, end_timestamp, grid_step, staleness_window)(samples)
```

**Parâmetros**

* `start_timestamp` — Especifica o início da grade. Também pode ser um número fracionário ou uma string contendo um número ou um texto de data e hora. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `end_timestamp` — Especifica o fim da grade. Também pode ser um número fracionário ou uma string contendo um número ou um texto de data e hora. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `grid_step` — Especifica o passo da grade em segundos. Também pode ser um número fracionário ou uma string contendo um número ou uma duração, como &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `staleness_window` — Especifica a &quot;inatividade&quot; máxima, em segundos, das amostras consideradas. A janela de inatividade é um intervalo aberto à esquerda e fechado à direita. Também pode ser um número fracionário ou uma string contendo um número ou uma duração, como &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)

**Argumentos**

* `timestamp` — Timestamp da amostra. Pode ser um valor individual ou um array. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Array(UInt32)`](/pt-BR/reference/data-types/array) ou [`Array(DateTime)`](/pt-BR/reference/data-types/array) ou [`Array(DateTime64)`](/pt-BR/reference/data-types/array)
* `value` — Valor da série temporal correspondente ao timestamp. Pode ser um valor individual ou um array. [`Float*`](/pt-BR/reference/data-types/float) ou [`Array(Float*)`](/pt-BR/reference/data-types/array)
* `samples` — Amostras da série temporal passadas como um array de tuplas `(timestamp, value)`, em que os elementos da tupla têm os tipos de timestamp e de valor listados acima. É uma alternativa a passar os timestamps e os valores como dois argumentos separados. [`Array(Tuple(T1, T2))`](/pt-BR/reference/data-types/array)

**Valor retornado**

Retorna os timestamps das amostras mais antigas na grade especificada, do mesmo tipo que `timestamp`. O array retornado contém um valor para cada ponto da grade temporal. O valor será NULL se não houver nenhuma amostra dentro da janela para um determinado ponto da grade. [`Array(Nullable(UInt32))`](/pt-BR/reference/data-types/array) ou [`Array(Nullable(DateTime))`](/pt-BR/reference/data-types/array) ou [`Array(Nullable(DateTime64))`](/pt-BR/reference/data-types/array)

**Exemplos**

**Calcular os valores de ts&#95;of&#95;first&#95;over&#95;time na grade [90, 105, 120, 135, 150, 165, 180, 195, 210]**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to staleness window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    30 AS window_seconds  -- "staleness" window
SELECT timeSeriesTimestampOfFirstToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,

    90 + 120 AS end_ts,
    15 AS step_seconds,
