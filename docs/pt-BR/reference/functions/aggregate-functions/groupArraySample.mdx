<div id="groupArraySample">
  ## groupArraySample
</div>

Introduzido na versão: v20.3.0

Cria um array com uma amostra dos valores do argumento.
O tamanho do array resultante é limitado a `max_size` elementos.
Os valores do argumento são selecionados e adicionados ao array aleatoriamente.

**Sintaxe**

```sql
groupArraySample(max_size[, seed])(x)
```

**Parâmetros**

* `max_size` — Tamanho máximo do array resultante. [`UInt64`](/pt-BR/reference/data-types/int-uint)
* `seed` — Opcional. Semente para o gerador de números aleatórios. Valor padrão: 123456. [`UInt64`](/pt-BR/reference/data-types/int-uint)
* `x` — Argumento (nome da coluna ou expressão). [`Any`](/pt-BR/reference/data-types/index)

**Argumentos**

* `array_column` — Coluna que contém arrays a serem agregados. [`Array`](/pt-BR/reference/data-types/array)

**Valor retornado**

Array de argumentos `x` selecionados aleatoriamente. [`Array(T)`](/pt-BR/reference/data-types/array)

**Exemplos**

**Exemplo de uso**

```sql title=Query
CREATE TABLE colors (
    id Int32,
    color String
) ENGINE = Memory;

INSERT INTO colors VALUES
(1, 'red'),
(2, 'blue'),
(3, 'green'),
(4, 'white'),
(5, 'orange');

SELECT groupArraySample(3)(color) as newcolors FROM colors;
```

```response title=Response
┌─newcolors──────────────────┐
│ ['white','blue','green']   │
└────────────────────────────┘
```

**Exemplo com seed**

```sql title=Query
-- Query with column name and different seed
SELECT groupArraySample(3, 987654321)(color) as newcolors FROM colors;
```

```response title=Response
┌─newcolors────────────────┐
│ ['red','orange','green'] │
└──────────────────────────┘
```

**Usando uma expressão como argumento**

```sql title=Query
-- Query with expression as argument
SELECT groupArraySample(3)(concat('light-', color)) as newcolors FROM colors;
```

```response title=Response
┌─newcolors───────────────────────────────────┐
│ ['light-blue','light-orange','light-green'] │
└─────────────────────────────────────────────┘
```
