## timeSeriesTopKMasks {#timeSeriesTopKMasks}

Introduzido em: v26.8.0

Seleciona as séries temporais com os k maiores valores em cada passo de uma grade temporal.

Cada linha de entrada é uma série temporal: `key` identifica a série e `values` contém seus valores alinhados a uma
grade temporal comum, portanto os arrays `values` de todas as linhas devem ter o mesmo tamanho. Em cada passo, são selecionadas as séries com os k maiores
valores não NULL naquele passo (NaN é considerado menor que qualquer outro valor). Empates de valor são resolvidos
dando preferência à série com o menor valor de `key`.

Esta função implementa o operador de agregação `topk()` do PromQL e mantém apenas um heap limitado de tamanho `k` por
passo, de modo que o tamanho do seu estado não depende do número de séries agregadas.

<Note>
  Esta função está em prévia privada; para habilitá-la, defina `enable_time_series_aggregate_functions = 1`.
</Note>

**Sintaxe**

```sql
timeSeriesTopKMasks(k, key, values)
```

**Argumentos**

* `k` — Quantas séries selecionar em cada passo de tempo: um único valor para todos os passos de tempo ou um array com um valor por passo de tempo. Deve ser o mesmo para todas as linhas. [`UInt*`](/pt-BR/reference/data-types/int-uint) ou [`Array(UInt*)`](/pt-BR/reference/data-types/array)
* `key` — Identificador da série temporal. [`UInt64`](/pt-BR/reference/data-types/int-uint)
* `values` — Valores da série temporal alinhados à grade temporal, com um elemento por passo de tempo. [`Array(Nullable(Float32))`](/pt-BR/reference/data-types/array) ou [`Array(Nullable(Float64))`](/pt-BR/reference/data-types/array) ou [`Array(Float32)`](/pt-BR/reference/data-types/array) ou [`Array(Float64)`](/pt-BR/reference/data-types/array)

**Valor retornado**

Retorna as séries selecionadas em ordem crescente de `key`, cada uma acompanhada de sua máscara por passo: `steps_mask[t] = 1` se a série for selecionada no passo de tempo `t`. Séries que não forem selecionadas em nenhum passo de tempo não são retornadas. [`Array(Tuple(key UInt64, steps_mask Array(UInt8)))`](/pt-BR/reference/data-types/array)

**Exemplos**

**Selecionando as 2 maiores séries por passo de tempo**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH [(1, [10., 1., NULL]), (2, [20., 2., 2.]), (3, [30., NULL, 1.])]::Array(Tuple(UInt64, Array(Nullable(Float64)))) AS series
SELECT timeSeriesTopKMasks(2, s.1, s.2)
FROM (SELECT arrayJoin(series) AS s);
```

```response title=Response
[(1,[0,1,0]),(2,[1,1,1]),(3,[1,0,1])]
```
