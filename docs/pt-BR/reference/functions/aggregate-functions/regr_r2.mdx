## regr_r2 {#regr_r2}

Introduzido em: v26.9.0

Retorna o coeficiente de determinação do ajuste por mínimos quadrados, ou seja, o quadrado do
coeficiente de correlação. Retorna `nan` quando `x` é constante e `1` quando `y` é constante.

**Sintaxe**

```sql
regr_r2(y, x)
```

**Aliases**: `regrR2`

**Argumentos**

* `y` — Variável dependente. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float)
* `x` — Variável independente. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float)

**Valor retornado**

Retorna um valor entre 0 e 1. [`Float64`](/pt-BR/reference/data-types/float)

**Exemplos**

**Uso básico**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
