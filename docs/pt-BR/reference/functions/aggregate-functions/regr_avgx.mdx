## regr_avgx {#regr_avgx}

Introduzido em: v26.9.0

Retorna a média da variável independente.

Ela é calculada em torno de um valor dos dados, e não em torno de zero; por isso, para uma coluna de inteiros com valores acima de
2^53, ela pode ser mais próxima da média exata do que [`avg`](/pt-BR/reference/functions/aggregate-functions/avg),
que divide uma soma `Float64`.

**Sintaxe**

```sql
regr_avgx(y, x)
```

**Aliases**: `regrAvgX`

**Argumentos**

* `y` — Variável dependente. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float)
* `x` — Variável independente. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float)

**Valor retornado**

Retorna a média de `x`. [`Float64`](/pt-BR/reference/data-types/float)

**Exemplos**

**Uso básico**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
