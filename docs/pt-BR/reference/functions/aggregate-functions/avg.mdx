## avg {#avg}

Introduzida na versão: v1.1.0

Calcula a média aritmética.

**Sintaxe**

```sql
avg(x)
```

**Argumentos**

* `x` — Valores de entrada. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal`](/pt-BR/reference/data-types/decimal) ou [`Date`](/pt-BR/reference/data-types/date) ou [`Date32`](/pt-BR/reference/data-types/date32) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64(P)`](/pt-BR/reference/data-types/datetime64) ou [`Time`](/pt-BR/reference/data-types/time) ou [`Time64(P)`](/pt-BR/reference/data-types/time64) ou [`Interval`](/pt-BR/reference/data-types/special-data-types/interval)

**Valor retornado**

Retorna a média aritmética. Se `x` for numérico, o resultado será um `Float64`; se `x` estiver vazio, será `NaN`. Se `x` for do tipo data, hora ou intervalo, o resultado terá o mesmo tipo de `x`: a média será arredondada para o valor representável mais próximo e, se `x` estiver vazio, o resultado será o valor zero desse tipo. [`Float64`](/pt-BR/reference/data-types/float) ou [`Date`](/pt-BR/reference/data-types/date) ou [`Date32`](/pt-BR/reference/data-types/date32) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64(P)`](/pt-BR/reference/data-types/datetime64) ou [`Time`](/pt-BR/reference/data-types/time) ou [`Time64(P)`](/pt-BR/reference/data-types/time64) ou [`Interval`](/pt-BR/reference/data-types/special-data-types/interval)

**Exemplos**

**Uso básico**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**Uma tabela vazia retorna NaN**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**Média de um intervalo**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
