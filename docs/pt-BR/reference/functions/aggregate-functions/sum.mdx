## sum {#sum}

Introduzido em: v1.1.0

Calcula a soma de valores numéricos ou de intervalos.

**Sintaxe**

```sql
sum(num)
```

**Argumentos**

* `num` — Coluna com valores numéricos ou intervalos. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`Interval`](/pt-BR/reference/data-types/special-data-types/interval)

**Valor retornado**

Retorna a soma dos valores. Para um argumento `Interval`, o resultado é um intervalo na mesma unidade, e uma entrada vazia resulta em um intervalo de duração zero. [`(U)Int*`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`Interval`](/pt-BR/reference/data-types/special-data-types/interval)

**Exemplos**

**Calculando a soma dos salários dos funcionários**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**Tempo total gasto em requisições**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
