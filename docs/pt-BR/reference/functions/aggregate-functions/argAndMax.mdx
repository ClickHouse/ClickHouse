<div id="argAndMax">
  ## argAndMax
</div>

Introduzido em: v1.1.0

Calcula os valores de `arg` e `val` para o valor máximo de `val`.
Se houver várias linhas em que `val` seja igual ao valor máximo, não é determinístico qual dos `arg` e `val` associados será retornado.
Ambas as partes, `arg` e `max`, se comportam como [funções de agregação](/pt-BR/reference/functions/aggregate-functions/index), ambas [ignoram `Null`](/pt-BR/reference/functions/aggregate-functions/index#null-processing) durante o processamento e retornam valores diferentes de `Null` se houver valores diferentes de `Null` disponíveis.

<Note>
  A única diferença em relação a `argMax` é que `argAndMax` retorna tanto o argumento quanto o valor.
</Note>

**Veja também**

* [argMax](/pt-BR/reference/functions/aggregate-functions/argMax)
* [Tuple](/pt-BR/reference/data-types/tuple)

**Sintaxe**

```sql
argAndMax(arg, val)
```

**Argumentos**

* `arg` — Argumento para o qual será encontrado o valor máximo. [`const String`](/pt-BR/reference/data-types/string)
* `val` — O valor máximo. [`(U)Int8/16/32/64`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Date`](/pt-BR/reference/data-types/date) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`Tuple`](/pt-BR/reference/data-types/tuple)

**Valor retornado**

Retorna uma tupla que contém o valor de `arg` correspondente ao valor máximo de `val` e o valor máximo de `val`. [`Tuple`](/pt-BR/reference/data-types/tuple)

**Exemplos**

**Uso básico**

```sql title=Query
CREATE TABLE salary
(
    user String,
    salary UInt32
)
ENGINE = Memory AS
SELECT *
FROM VALUES(('worker', 1000), ('manager', 3000), ('director', 5000));

SELECT argAndMax(user, salary) FROM salary;
```

```response title=Response
┌─argAndMax(user, salary)─┐
│ ('director',5000)       │
└─────────────────────────┘
```

**Exemplo estendido com tratamento de NULL**

```sql title=Query
CREATE TABLE test
(
    a Nullable(String),
    b Nullable(Int64)
)
ENGINE = Memory AS
SELECT *
FROM VALUES(('a', 1), ('b', 2), ('c', 2), (NULL, 3), (NULL, NULL), ('d', NULL));

SELECT argMax(a, b), argAndMax(a, b), max(b) FROM test;
```

```response title=Response
┌─argMax(a, b)─┬─argAndMax(a, b)─┬─max(b)─┐
│ b            │ ('b',2)         │      3 │
└──────────────┴─────────────────┴────────┘
```

**Uso de Tuple em argumentos**

```sql title=Query
SELECT argAndMax(a, (b,a)) FROM test;
```

```response title=Response
┌─argAndMax(a, (b, a))─┐
│ ('c',(2,'c'))        │
└──────────────────────┘
```
