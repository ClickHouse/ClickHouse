## timeSeriesTimestampOfMaxToGrid {#timeSeriesTimestampOfMaxToGrid}

Introduzido em: v26.9.0

Função de agregação que recebe dados de séries temporais como pares de timestamps e valores e calcula [ts&#95;of&#95;max&#95;over&#95;time no estilo do PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) a partir desses dados em uma grade temporal regular definida por timestamp inicial, timestamp final e passo. Para cada ponto da grade, o resultado é o timestamp, em segundos, da amostra mais recente com o valor máximo dentro da janela de tempo especificada.

As amostras podem ser fornecidas de uma das três formas a seguir:

* como dois argumentos, `timestamp` e `value`, em que cada linha contém uma única amostra;
* como dois arrays de timestamps e valores, em que cada linha contém uma série temporal inteira;
* como um único array de tuplas `(timestamp, value)`, em que cada linha contém uma série temporal inteira.

Amostras com valores NaN são ignoradas, a menos que todas as amostras dentro da janela sejam NaN.

Se várias amostras tiverem o mesmo timestamp, apenas uma delas será usada: a de maior valor. Um valor NaN perde para qualquer outro valor; portanto, um valor NaN só é usado se todas as amostras nesse timestamp forem NaN.

<Note>
  Esta função está em prévia privada; para habilitá-la, defina `enable_time_series_aggregate_functions=true`.
</Note>

**Sintaxe**

```sql
timeSeriesTimestampOfMaxToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
timeSeriesTimestampOfMaxToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples)
```

**Parâmetros**

* `start_timestamp` — Especifica o início da grade. Também pode ser um número fracionário ou uma string contendo um número ou um texto de data e hora. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `end_timestamp` — Especifica o fim da grade. Também pode ser um número fracionário ou uma string contendo um número ou um texto de data e hora. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `grid_step` — Especifica o passo da grade, em segundos. Também pode ser um número fracionário ou uma string contendo um número ou uma duração, como &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)
* `staleness` — Especifica a &quot;staleness&quot; máxima, em segundos, das amostras consideradas. A janela de staleness é um intervalo aberto à esquerda e fechado à direita. Também pode ser um número fracionário ou uma string contendo um número ou uma duração, como &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`Float*`](/pt-BR/reference/data-types/float) ou [`Decimal*`](/pt-BR/reference/data-types/decimal) ou [`String`](/pt-BR/reference/data-types/string)

**Argumentos**

* `timestamp` — Timestamp da amostra. Pode ser um valor individual ou um array. [`UInt32`](/pt-BR/reference/data-types/int-uint) ou [`DateTime`](/pt-BR/reference/data-types/datetime) ou [`DateTime64`](/pt-BR/reference/data-types/datetime64) ou [`Array(UInt32)`](/pt-BR/reference/data-types/array) ou [`Array(DateTime)`](/pt-BR/reference/data-types/array) ou [`Array(DateTime64)`](/pt-BR/reference/data-types/array)
* `value` — Valor da série temporal correspondente ao timestamp. Pode ser um valor individual ou um array. [`Float*`](/pt-BR/reference/data-types/float) ou [`Array(Float*)`](/pt-BR/reference/data-types/array)
* `samples` — Amostras da série temporal fornecidas como um array de tuplas `(timestamp, value)`, em que os elementos da tupla têm os tipos de timestamp e valor listados acima. É uma alternativa a fornecer os timestamps e os valores como dois argumentos separados. [`Array(Tuple(T1, T2))`](/pt-BR/reference/data-types/array)

**Valor retornado**

Valores de `ts_of_max_over_time` na grade especificada: os timestamps dos máximos, do mesmo tipo que `timestamp`. O array retornado contém um valor para cada ponto da grade temporal. O valor é NULL se não houver amostras dentro da janela para um determinado ponto da grade. [`Array(Nullable(UInt32))`](/pt-BR/reference/data-types/array) ou [`Array(Nullable(DateTime))`](/pt-BR/reference/data-types/array) ou [`Array(Nullable(DateTime64))`](/pt-BR/reference/data-types/array)

**Exemplos**

**Calcular os valores de ts&#95;of&#95;max&#95;over&#95;time na grade [90, 105, 120, 135, 150, 165, 180, 195, 210, 225]**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 130 and 190 is to show how values are filled for ts = 180 according to window parameter
    [110, 120, 130, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 3, 2, 6, 6, 4, 2, 0]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 135 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesTimestampOfMaxToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

**A mesma consulta com argumentos de array**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 3, 2, 6, 6, 4, 2, 0]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 135 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesTimestampOfMaxToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```
