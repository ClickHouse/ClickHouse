Lê séries temporais de uma tabela TimeSeries filtradas por um seletor e com timestamps em um intervalo especificado.
Esta função é semelhante a [seletores de intervalo](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors), mas também é usada para implementar [seletores instantâneos](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors).

## Sintaxe {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## Argumentos {#arguments}

* `db_name` - O nome do banco de dados em que uma tabela TimeSeries está localizada.
* `time_series_table` - O nome de uma tabela TimeSeries.
* `instant_query` - Um seletor instantâneo escrito na [sintaxe PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors), sem os modificadores `@` ou `offset`.
* `min_time` - timestamp inicial, inclusivo.
* `max_time` - timestamp final, inclusivo.
* `return_columns` - As colunas que retornam as amostras: `'samples'` ou `'timestamp_and_value'`; veja abaixo.

`min_time` e `max_time` podem ter frações de segundo, mesmo que os timestamps na tabela estejam em segundos inteiros:
a função seleciona exatamente as amostras que satisfazem `min_time <= timestamp <= max_time`, sem arredondar os limites para adequá-los ao tipo dos timestamps.

## Valor retornado {#returned-value}

A função retorna a coluna `id` com os identificadores das séries temporais que correspondem ao seletor especificado, além das amostras
nas colunas escolhidas pelo argumento `return_columns`:

* `'samples'` - a coluna `samples` com as amostras de uma série temporal como um array de tuplas `(timestamp, value)` ordenado por timestamp.
  As amostras de uma série temporal podem ser retornadas em várias linhas, por exemplo, uma linha por intervalo de tempo da tabela samples.
  Use a função de agregação `timeSeriesGroupArray` para mesclar as linhas de uma série temporal.
* `'timestamp_and_value'` - as colunas `timestamp` e `value`, com uma amostra por linha.

Uma tabela `TimeSeries` da versão 11 ou posterior armazena buckets de amostras como arrays, enquanto as tabelas de versões anteriores armazenam uma amostra por linha.
As amostras são convertidas quando as colunas solicitadas diferem do layout da tabela, o que leva algum tempo; as funções PromQL
solicitam as colunas que correspondem ao layout da tabela.

Os dados retornados não seguem nenhuma ordem específica.

## Exemplos {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
