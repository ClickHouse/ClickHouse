`timeSeriesTimeRanges(db_name.time_series_table)` - Retorna a tabela de [intervalos de tempo](/pt-BR/reference/engines/table-engines/integrations/time-series#time-ranges-table)
usada pela tabela `db_name.time_series_table`, cujo motor de tabela é o [TimeSeries](/pt-BR/reference/engines/table-engines/integrations/time-series), por exemplo:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

As consultas a seguir são equivalentes:

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  A tabela de *intervalos de tempo* existe se a configuração `store_time_ranges` estiver habilitada.
  Tabelas da [versão](/pt-BR/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 ou anteriores armazenam as colunas `min_time` e `max_time`
  na tabela de [rótulos](/pt-BR/reference/engines/table-engines/integrations/time-series#tags-table).
</Note>
