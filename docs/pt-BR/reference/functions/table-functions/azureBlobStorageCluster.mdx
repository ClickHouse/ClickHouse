Permite processar arquivos do [Azure Blob Storage](https://azure.microsoft.com/en-us/products/storage/blobs) em paralelo com muitos nós em um cluster especificado. No initiator, cria uma conexão com todos os nós do cluster, expande os asteriscos no caminho do arquivo do S3 e distribui cada arquivo dinamicamente. No nó worker, consulta o initiator sobre a próxima tarefa a ser processada e a processa. Isso se repete até que todas as tarefas sejam concluídas.
Esta função de tabela é semelhante à [função s3Cluster](/pt-BR/reference/functions/table-functions/s3Cluster).

## Sintaxe {#syntax}

<Tabs>
  <Tab title="String de conexão">
    As credenciais estão incluídas na string de conexão, portanto não é necessário fornecer `account_name`/`account_key` separadamente:

    ```sql
    azureBlobStorageCluster(cluster_name, connection_string, container_name, blobpath [, format, compression, structure])
    ```
  </Tab>

  <Tab title="URL da conta de armazenamento">
    Requer `account_name` e `account_key` como argumentos separados:

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, account_name, account_key [, format, compression, structure])
    ```
  </Tab>

  <Tab title="Identidade de carga de trabalho">
    Usa a identidade de carga de trabalho do Azure por meio de `extra_credentials`; não pode ser usada em conjunto com `account_name` / `account_key` e requer `storage_account_url` (não `connection_string`):

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, extra_credentials(client_id=, tenant_id=) [, format, compression, structure])
    ```

    A identidade de carga de trabalho usa a própria identidade do servidor, por isso seu uso é bloqueado por padrão: habilite `allow_server_credentials_in_user_queries` na sessão em que as consultas são executadas ou no perfil de configurações dessa sessão.
  </Tab>
</Tabs>

## Argumentos {#arguments}

| Argumento             | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `cluster_name`        | Nome de um cluster usado para montar um conjunto de endereços e parâmetros de conexão para servidores remotos e locais.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `connection_string`   | Uma string de conexão que inclui credenciais incorporadas (nome da conta + chave da conta ou token SAS). Ao usar essa opção, `account_name` e `account_key` **não** devem ser passados separadamente, e `client_id` / `tenant_id` não podem ser usados. Consulte [Configurar uma string de conexão](https://learn.microsoft.com/en-us/azure/storage/common/storage-configure-connection-string?toc=%2Fazure%2Fstorage%2Fblobs%2Ftoc.json\&bc=%2Fazure%2Fstorage%2Fblobs%2Fbreadcrumb%2Ftoc.json#configure-a-connection-string-for-an-azure-storage-account). |
| `storage_account_url` | A URL do endpoint da conta de armazenamento, por exemplo, `https://<account>.blob.core.windows.net/`. Ao usar essa opção, passe `account_name` e `account_key` ou, para identidade de carga de trabalho, `extra_credentials(client_id=, tenant_id=)`.                                                                                                                                                                                                                                                                                                        |
| `container_name`      | Nome do contêiner                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `blobpath`            | Caminho do arquivo. Suporta os seguintes curingas no modo readonly: `*`, `**`, `?`, `{abc,def}` e `{N..M}`, em que `N`, `M` — números, `'abc'`, `'def'` — strings.                                                                                                                                                                                                                                                                                                                                                                                           |
| `account_name`        | Nome da conta de armazenamento. **Obrigatório** ao usar `storage_account_url` sem SAS ou identidade de carga de trabalho; **não** deve ser passado com `connection_string` ou `extra_credentials`.                                                                                                                                                                                                                                                                                                                                                           |
| `account_key`         | Chave da conta de armazenamento. **Obrigatória** ao usar `storage_account_url` sem SAS ou identidade de carga de trabalho; **não** deve ser passada com `connection_string` ou `extra_credentials`.                                                                                                                                                                                                                                                                                                                                                          |
| `format`              | O [formato](/pt-BR/reference/formats/index) do arquivo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `compression`         | Valores compatíveis: `none`, `gzip/gz`, `deflate`, `brotli/br`, `xz/LZMA`, `zstd/zst`, `lz4`, `bz2`, `snappy`. Por padrão, a compressão será detectada automaticamente pela extensão do arquivo. (o mesmo que definir como `auto`). Para `snappy`, o formato wire é selecionado pela configuração [snappy&#95;mode](/pt-BR/reference/settings/session-settings/other#snappy_mode) (`basic` por padrão).                                                                                                                                                      |
| `structure`           | Estrutura da tabela. Formato `'column1_name column1_type, column2_name column2_type, ...'`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `extra_credentials`   | Use `client_id` e `tenant_id` para autenticação por identidade de carga de trabalho do Azure. Não pode ser usado com `account_name` / `account_key` e exige `storage_account_url` (não `connection_string`). Todos os nós do cluster devem ter `AZURE_FEDERATED_TOKEN_FILE` definido.                                                                                                                                                                                                                                                                        |

## Valor retornado {#returned-value}

Uma tabela com a estrutura especificada para leitura ou gravação de dados no arquivo especificado.

## Exemplos {#examples}

Assim como no motor de tabela [AzureBlobStorage](/pt-BR/reference/engines/table-engines/integrations/azureBlobStorage), é possível usar o emulador Azurite para desenvolvimento local do Armazenamento do Azure. Mais detalhes [aqui](https://learn.microsoft.com/en-us/azure/storage/common/storage-use-azurite?tabs=docker-hub%2Cblob-storage). Abaixo, assumimos que o Azurite está disponível no hostname `azurite1`.

Selecione a contagem para o arquivo `test_cluster_*.csv`, usando todos os nós no cluster `cluster_simple`:

```sql
SELECT count(*) FROM azureBlobStorageCluster(
        'cluster_simple', 'http://azurite1:10000/devstoreaccount1', 'testcontainer', 'test_cluster_count.csv', 'devstoreaccount1',
        'Eby8vdM02xNOcqFlqUwJPLlmEtlCDXJ1OUzFT50uSRZ6IFsuFq2UVErCz4I6tq/K1SZFPTOtr/KBHBeksoGMGw==', 'CSV',
        'auto', 'key UInt64')
```
