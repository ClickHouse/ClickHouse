Cria uma tabela temporária [Merge](/pt-BR/reference/engines/table-engines/special/merge).
O schema da tabela é derivado das tabelas subjacentes usando a união de suas colunas e inferindo tipos comuns.
As mesmas colunas virtuais estão disponíveis como no [motor de tabela Merge](/pt-BR/reference/engines/table-engines/special/merge).

## Sintaxe {#syntax}

```sql
merge(['db_name',] 'tables_regexp')
```

## Argumentos {#arguments}

| Argumento       | Descrição                                                                                                                                                                                                                                                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | Valores possíveis (opcional; o padrão é `currentDatabase()`):<br />    - nome do banco de dados,<br />    - expressão constante que retorna uma string com o nome de um banco de dados, por exemplo, `currentDatabase()`,<br />    - `REGEXP(expression)`, em que `expression` é uma expressão regular para corresponder aos nomes dos bancos de dados. |
| `tables_regexp` | Uma expressão regular para corresponder aos nomes das tabelas no banco de dados ou nos bancos de dados especificados.                                                                                                                                                                                                                                   |

## Direitos de acesso {#access-rights}

As tabelas correspondentes são lidas com as mesmas regras de acesso do motor de tabela [Merge](/pt-BR/reference/engines/table-engines/special/merge#access-rights). Os dados são lidos somente das tabelas correspondentes que o usuário atual pode ver, ou seja, aquelas nas quais ele tem o privilégio [`SHOW TABLES`](/pt-BR/reference/statements/grant#show), e o esquema da tabela é derivado apenas delas. Uma tabela correspondente que o usuário não pode ver é ignorada sem gerar erro. Para derivar o schema, é necessário o privilégio [`SHOW COLUMNS`](/pt-BR/reference/statements/grant#show) nas tabelas a partir das quais ele é derivado. Para ler uma tabela correspondente que o usuário pode ver, é necessário o privilégio [`SELECT`](/pt-BR/reference/statements/grant#select) nas colunas lidas pela consulta; caso contrário, a consulta falha com `ACCESS_DENIED`.
