`timeSeriesMetricFamilies(db_name.time_series_table)` - Retorna a tabela de [famílias de métricas](/pt-BR/reference/engines/table-engines/integrations/time-series#metric-families-table)
usada pela tabela `db_name.time_series_table`, cujo motor de tabela é o motor [TimeSeries](/pt-BR/reference/engines/table-engines/integrations/time-series):

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES metric_families_table
```

A função também funciona se a table de *metric families* for a interna:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

As queries a seguir são equivalentes:

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  A função `timeSeriesMetricFamilies` possui um alias `timeSeriesMetrics`, mantido para fins de compatibilidade retroativa.
</Note>
