Avalia uma consulta do Prometheus usando dados de uma tabela TimeSeries.

## Sintaxe {#syntax}

```sql
prometheusQuery('db_name', 'time_series_table', 'promql_query', evaluation_time)
prometheusQuery(db_name.time_series_table, 'promql_query', evaluation_time)
prometheusQuery('time_series_table', 'promql_query', evaluation_time)
```

## Argumentos {#arguments}

* `db_name` - O nome do banco de dados em que uma tabela TimeSeries está localizada.
* `time_series_table` - O nome de uma tabela TimeSeries.
* `promql_query` - Uma consulta escrita em [sintaxe PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/).
* `evaluation_time` - O timestamp de avaliação, com precisão de milissegundos ou superior. Para avaliar uma consulta no momento atual, use `now()` como `evaluation_time`.

## Valor retornado {#returned-value}

A função retorna colunas diferentes, dependendo do tipo de resultado da consulta fornecida no parâmetro `promql_query`:

| Tipo de resultado | Colunas retornadas                                                                  | Exemplo                                             |
| ----------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| vector            | tags Array(Tuple(String, String)), timestamp DateTime64(S, TZ), value Float64       | prometheusQuery(mytable, &#39;up&#39;)              |
| matrix            | tags Array(Tuple(String, String)), samples Array(Tuple(DateTime64(S, TZ), Float64)) | prometheusQuery(mytable, &#39;up[1m]&#39;)          |
| scalar            | timestamp DateTime64(S, TZ), value Float64                                          | prometheusQuery(mytable, &#39;1h30m&#39;)           |
| string            | timestamp DateTime64(S, TZ), value String                                           | prometheusQuery(mytable, &#39;&quot;abc&quot;&#39;) |

Os valores são sempre do tipo `Float64`, independentemente do tipo dos valores na tabela TimeSeries. A escala `S` dos timestamps é a escala
dos timestamps na tabela, mas nunca inferior a 3 (milissegundos). O fuso horário `TZ` é o fuso horário de `evaluation_time` se ele for
do tipo `DateTime` ou `DateTime64` com um fuso horário; caso contrário, é o fuso horário dos timestamps na tabela.

A coluna `samples` recebe o nome `time_series` se a tabela `TimeSeries` tiver [version](/pt-BR/reference/engines/table-engines/integrations/time-series#schema-versioning) 2 ou anterior.

## Funcionalidades do PromQL compatíveis {#supported-promql-features}

### Seletores {#selectors}

Seletores instantâneos, seletores de intervalo, operadores de correspondência de rótulos (`=`, `!=`, `=~`, `!~`), modificadores offset, modificadores de timestamp com `@` e subconsultas.

### Funções {#functions}

| Categoria     | Funções                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Intervalo     | `rate`, `irate`, `delta`, `idelta`, `increase`, `last_over_time`, `first_over_time`, `sum_over_time`, `avg_over_time`, `count_over_time`, `max_over_time`, `min_over_time`, `ts_of_max_over_time`, `ts_of_min_over_time`, `ts_of_last_over_time`, `ts_of_first_over_time`, `deriv`, `changes`, `resets`, `present_over_time`, `absent_over_time`, `quantile_over_time`, `stddev_over_time`, `stdvar_over_time`, `mad_over_time`, `predict_linear` |
| Matemática    | `abs`, `sgn`, `floor`, `ceil`, `sqrt`, `exp`, `ln`, `log2`, `log10`, `rad`, `deg`, `round`, `clamp`, `clamp_min`, `clamp_max`, `min_of`, `max_of`                                                                                                                                                                                                                                                                                                 |
| Trigonometria | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh`                                                                                                                                                                                                                                                                                                                                                    |
| DateTime      | `day_of_week`, `day_of_month`, `days_in_month`, `day_of_year`, `minute`, `hour`, `month`, `year`                                                                                                                                                                                                                                                                                                                                                  |
| Rótulo        | `label_replace`, `label_join`                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Tipo          | `scalar`, `vector`                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Histograma    | `histogram_quantile`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Outros        | `time`, `pi`, `absent`, `timestamp`                                                                                                                                                                                                                                                                                                                                                                                                               |

**Nota**: `histogram_quantile` usa interpolação linear em buckets clássicos de histograma (identificados pelo rótulo `le`). Histogramas nativos não têm suporte. O argumento `phi` (nível de quantile) deve ser um escalar constante. Expressões que variam a cada passo, como `histogram_quantile(time() / 1000, ...)`, são rejeitadas com uma exceção `NOT_IMPLEMENTED`.

**Nota**: `min_of(a, b)` e `max_of(a, b)` retornam, respectivamente, o menor ou o maior de dois valores escalares. Ambos os argumentos devem ser escalares.

**Nota**: `min_of`, `max_of`, `ts_of_min_over_time`, `ts_of_max_over_time`, `ts_of_last_over_time`, `first_over_time`, `ts_of_first_over_time` e `mad_over_time` são funções experimentais no Prometheus (habilitadas lá com `--enable-feature=promql-experimental-functions`); o ClickHouse as avalia sem exigir essa flag.

### Operadores {#operators}

Operadores binários aritméticos (`+`, `-`, `*`, `/`, `%`, `^`, `atan2`) e de comparação (`==`, `!=`, `<`, `>`, `<=`, `>=` com `bool` opcional), com os modificadores `on()`/`ignoring()` e `group_left()`/`group_right()`.

Operadores lógicos de conjuntos `and`, `or` e `unless`, com os modificadores `on()`/`ignoring()`.

Operadores unários `+` e `-`.

### Operadores de agregação {#aggregation-operators}

`sum`, `avg`, `min`, `max`, `count`, `count_values`, `stddev`, `stdvar`, `group`, `quantile`, `topk`, `bottomk`, `limitk` — com os modificadores opcionais `by()` ou `without()`.

## Exemplo {#example}

```sql
SELECT * FROM prometheusQuery(mytable, 'rate(http_requests{job="prometheus"}[10m])[1h:10m]', now())
```
