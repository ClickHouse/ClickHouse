<div id="description">
  ## Descrição
</div>

O formato de saída `Hash` calcula um único valor de hash para todas as colunas e linhas do resultado.
Isso é útil para calcular uma &quot;assinatura&quot; do resultado, por exemplo, em situações em que a transferência de dados é o gargalo.
