## Descrição {#description}

Difere de `JSONEachRow`/`JSONStringsEachRow` porque o ClickHouse transmite cada evento como um objeto JSON separado e também fornece informações de progresso.

Todos os valores de campo são serializados como strings (incluindo tipos complexos): por exemplo, `arr` é emitido como `"arr":"[0,1]"`, e não como um array JSON aninhado. Da mesma forma, valores escalares são convertidos em string (`"num":"42"`).

Os tipos de objeto de nível superior são os mesmos de [`JSONEachRowWithProgress`](/pt-BR/reference/formats/JSON/JSONEachRowWithProgress) (`meta`, `row`, `progress`, `totals`/`min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation` e `exception` de nível superior). Consulte essa página para ver o contrato completo do stream: um objeto `progress` pode chegar antes de `meta`; `rows_before_limit_at_least` é uma estimativa mínima quando a consulta contém `LIMIT` (e não comprova que linhas foram descartadas); `exception` só é gravado no caminho HTTP com `http_write_exception_in_output_format=1`.

## Exemplo de uso {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
