## Descrição {#description}

Semelhante a [`JSONCompactEachRowWithProgress`](/pt-BR/reference/formats/JSON/JSONCompactEachRowWithProgress), mas todos os valores são convertidos para strings. Usa os mesmos tipos de objeto de nível superior (`meta`, `row`, `progress`, `totals`, `min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation` e um `exception` de nível superior); as cargas úteis de `row` / `totals` / `min` / `max` continuam sendo **arrays** na ordem das colunas, com cada elemento serializado como string.

Consulte [`JSONCompactEachRowWithProgress`](/pt-BR/reference/formats/JSON/JSONCompactEachRowWithProgress) para ver o contrato completo dos objetos do stream (`progress` pode chegar antes de `meta`; `rows_before_limit_at_least` é uma estimativa mínima quando a consulta contém `LIMIT`, e não uma prova de que linhas foram descartadas; `exception` só é gravado no caminho HTTP com `http_write_exception_in_output_format=1`).

## Exemplo de uso {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
