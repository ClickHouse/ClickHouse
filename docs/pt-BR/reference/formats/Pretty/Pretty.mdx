## Descrição {#description}

O formato `Pretty` exibe os dados como tabelas em arte Unicode,
usando sequências de escape ANSI para mostrar cores no terminal.
Uma grade completa da tabela é desenhada, e cada linha de dados ocupa duas linhas no terminal.
Cada bloco de resultados é exibido como uma tabela separada.
Isso é necessário para que os blocos possam ser exibidos sem armazenar os resultados em buffer (o buffering seria necessário para pré-calcular a largura visível de todos os valores).

[NULL](/pt-BR/reference/syntax) é exibido como `ᴺᵁᴸᴸ`.

## Exemplo de uso {#example-usage}

Exemplo (para o formato [`PrettyCompact`](/pt-BR/reference/formats/Pretty/PrettyCompact)):

```sql title="Query"
SELECT * FROM t_null
```

```response title="Response"
┌─x─┬────y─┐
│ 1 │ ᴺᵁᴸᴸ │
└───┴──────┘
```

As linhas não são escapadas em nenhum dos formatos `Pretty`. Em vez disso, caracteres de controle não imprimíveis (controles C0 `0x00`-`0x1F` e `DEL` `0x7F`) nos valores e nos nomes de colunas são exibidos, por padrão, como os &quot;Control Pictures&quot; Unicode correspondentes (`U+2400`-`U+2421`), para que permaneçam visíveis e não deformem a tabela. Por exemplo, um NUL é exibido como `␀`:

```sql title="Query"
SELECT 'String with a NUL \0 character' AS Escaping_test FORMAT PrettyCompact
```

```response title="Response"
┌─Escaping_test─────────────────┐
│ String with a NUL ␀ character │
└───────────────────────────────┘
```

`TAB`, a quebra de linha e `ESC` são exceções: eles são sempre exibidos como estão, porque o terminal os interpreta em vez de descartá-los — um tab avança até a próxima parada de tabulação, e é uma sequência de escape ANSI que permite que os dados contenham uma visualização. A quebra de linha também continua quebrando a linha: dentro de uma célula da tabela, quando [`output_format_pretty_multiline_fields`](/pt-BR/reference/settings/formats#output_format_pretty_multiline_fields) está habilitado, e como está, caso contrário. O nome de coluna é a exceção dessa exceção: o cabeçalho e o rodapé ocupam uma única linha, então uma quebra de linha em um nome é substituída como qualquer outro caractere de controle.

Para exibir os caracteres de controle literalmente, desative [`output_format_pretty_display_control_characters`](/pt-BR/reference/settings/formats#output_format_pretty_display_control_characters):

```sql title="Query"
SELECT 'String with a NUL \0 character' AS Escaping_test FORMAT PrettyCompact
SETTINGS output_format_pretty_display_control_characters = 0
```

A resposta passa então a conter o byte `NUL` bruto. O terminal o descarta, de modo que o caractere
fica invisível e a linha fica uma posição mais larga do que a borda calculada para ela - justamente a
tabela deformada que a exibição do Control Picture evita.

Para evitar despejar dados demais no terminal, apenas as primeiras `10.000` linhas são exibidas.
Se o número de linhas for maior ou igual a `10.000`, a mensagem &quot;Foram mostradas as primeiras 10 000&quot; será exibida.

<Note>
  Este formato é apropriado apenas para exibir o resultado de uma consulta, mas não para fazer parsing de dados.
</Note>

O formato Pretty oferece suporte à exibição de totais (ao usar `WITH TOTALS`) e de extremos (quando &#39;extremes&#39; está definido como 1).
Nesses casos, os totais e os valores extremos são exibidos após os dados principais, em tabelas separadas.
Isso é mostrado no exemplo a seguir, que usa o formato [`PrettyCompact`](/pt-BR/reference/formats/Pretty/PrettyCompact):

```sql title="Query"
SELECT EventDate, count() AS c 
FROM test.hits 
GROUP BY EventDate 
WITH TOTALS 
ORDER BY EventDate 
FORMAT PrettyCompact
```

```response title="Response"
┌──EventDate─┬───────c─┐
│ 2014-03-17 │ 1406958 │
│ 2014-03-18 │ 1383658 │
│ 2014-03-19 │ 1405797 │
│ 2014-03-20 │ 1353623 │
│ 2014-03-21 │ 1245779 │
│ 2014-03-22 │ 1031592 │
│ 2014-03-23 │ 1046491 │
└────────────┴─────────┘

Totals:
┌──EventDate─┬───────c─┐
│ 1970-01-01 │ 8873898 │
└────────────┴─────────┘

Extremes:
┌──EventDate─┬───────c─┐
│ 2014-03-17 │ 1031592 │
│ 2014-03-23 │ 1406958 │
└────────────┴─────────┘
```
