<div id="description">
  ## Descrição
</div>

O formato `MySQLWire` serializa resultados de consultas como um conjunto de resultados do protocolo MySQL wire. Ele grava a contagem e as definições das
colunas, seguidas de um pacote de linha do protocolo para cada linha do resultado e de um pacote `EOF` ou `OK` final. Os pacotes de
linha usam o protocolo de texto para consultas normais e o protocolo binário para instruções preparadas.

Este é um formato binário somente de saída destinado a clientes conectados pela
[interface MySQL](/pt-BR/concepts/features/interfaces/mysql) do ClickHouse. A interface seleciona automaticamente o `MySQLWire` e fornece
o estado do protocolo, como as capabilities do cliente e o número de sequência do pacote. Ele não se destina à exibição nem ao
armazenamento de resultados de consultas como um arquivo independente.

<div id="example-usage">
  ## Exemplo de uso
</div>

Após habilitar a interface MySQL, use um cliente compatível para executar uma consulta:

```shell
mysql --protocol tcp -h 127.0.0.1 -u default -P 9004 default \
    -e "SELECT number, number * 2 AS doubled FROM numbers(3)"
```

A interface envia o resultado usando `MySQLWire`; uma cláusula explícita `FORMAT MySQLWire` é opcional. Outros
formatos de saída explícitos não são compatíveis com a interface MySQL.

<div id="format-settings">
  ## Configurações de formato
</div>

Não há configurações de formato que possam ser definidas pelo usuário. A interface MySQL obtém as configurações necessárias a partir do
handshake do cliente e do comando em execução.
