<div id="description">
  ## Descrição
</div>

O formato `PostgreSQLWire` serializa a parte do conjunto de resultados do protocolo wire do PostgreSQL. Ele grava uma
mensagem `RowDescription` com os nomes e tipos das colunas, seguida de uma mensagem `DataRow` para cada linha do resultado.
Os valores usam sua representação textual, os valores `NULL` usam a codificação de campo nulo do protocolo, e os valores booleanos são gravados como
`t` ou `f`.

Este é um formato binário somente de saída destinado a clientes conectados pela
[interface PostgreSQL](/pt-BR/concepts/features/interfaces/postgresql) do ClickHouse. A interface define `PostgreSQLWire` como o padrão da
sessão e o utiliza quando a consulta não inclui uma cláusula `FORMAT` explícita. Uma cláusula explícita substitui o padrão;
outros formatos de saída não produzem um conjunto de resultados PostgreSQL válido. A interface grava as mensagens de protocolo que o envolvem,
como as de autenticação, conclusão de comando e prontidão para consulta. `PostgreSQLWire` não se destina à exibição
nem ao armazenamento de resultados de consulta como um arquivo independente.

<div id="example-usage">
  ## Exemplo de uso
</div>

Após habilitar a interface PostgreSQL, use um cliente compatível para executar uma consulta:

```shell
psql -p 9005 -h 127.0.0.1 -U default -d default \
    -c "SELECT number, number % 2 = 0 AS even FROM numbers(3)"
```

Como a consulta não especifica uma cláusula `FORMAT`, a interface envia o resultado por meio de `PostgreSQLWire`.

<div id="format-settings">
  ## Configurações de formato
</div>

`PostgreSQLWire` usa as configurações padrão de serialização de texto para valores individuais. Não há configurações específicas do
próprio formato; os valores booleanos são sempre serializados usando as representações `t` e `f` do PostgreSQL.
