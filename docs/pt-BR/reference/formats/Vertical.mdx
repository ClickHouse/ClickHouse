## Descrição {#description}

Imprime cada valor em uma linha separada, com o nome da coluna especificado. Esse formato é conveniente para imprimir apenas uma ou algumas linhas quando cada linha contém um grande número de colunas.

Observe que [`NULL`](/pt-BR/reference/syntax) é exibido como `ᴺᵁᴸᴸ` para facilitar a distinção entre o valor de string `NULL` e a ausência de valor. As colunas JSON são formatadas de forma legível, e `NULL` é exibido como `null`, porque é um valor JSON válido e facilmente distinguível de `"null"`.

## Exemplo de uso {#example-usage}

Exemplo:

```sql
SELECT * FROM t_null FORMAT Vertical
```

```response
Row 1:
──────
x: 1
y: ᴺᵁᴸᴸ
```

Por padrão, caracteres de controle não imprimíveis (controles C0 `0x00`–`0x1F` e `DEL` `0x7F`) em valores e em nomes de colunas são exibidos como os &quot;Control Pictures&quot; Unicode correspondentes (`U+2400`–`U+2421`), de modo que permaneçam visíveis em vez de serem descartados silenciosamente pelo terminal. Por exemplo, um NUL é exibido como `␀`:

```sql
SELECT 'string with a NUL \0 character' AS test FORMAT Vertical
```

```response
Row 1:
──────
test: string with a NUL ␀ character
```

`TAB`, a quebra de linha e `ESC` são exceções: eles são sempre exibidos como estão, porque o terminal os interpreta em vez de descartá-los — uma tabulação avança até a próxima parada de tabulação, uma quebra de linha inicia uma nova linha e uma sequência de escape ANSI é o que permite que os dados contenham uma visualização. O nome de coluna é a exceção dessa exceção: ele é renderizado em uma única linha, portanto uma quebra de linha em um nome é substituída como qualquer outro caractere de controle.

Para, em vez disso, exibir os caracteres de controle literalmente, desative [`output_format_pretty_display_control_characters`](/pt-BR/reference/settings/formats#output_format_pretty_display_control_characters):

```sql
SELECT 'string with a NUL \0 character' AS test
FORMAT Vertical
SETTINGS output_format_pretty_display_control_characters = 0
```

Nesse caso, a resposta contém o byte `NUL` bruto. Um terminal o descarta, de modo que o valor
aparece como se o caractere simplesmente não existisse.

Este formato é adequado apenas para exibir o resultado de uma consulta, e não para parsing (obter dados para inserir em uma tabela).
