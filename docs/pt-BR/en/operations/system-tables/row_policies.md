<div id="description">
  ## Descrição
</div>

Contém filtros de uma tabela específica, bem como uma lista de papéis e/ou usuários que devem usar esta ROW POLICY.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome de uma ROW POLICY.
* `short_name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome curto de uma ROW POLICY. Os nomes de ROW POLICIES são compostos, por exemplo: myfilter ON mydb.mytable. Aqui, &#39;myfilter ON mydb.mytable&#39; é o nome da ROW POLICY, e &#39;myfilter&#39; é seu nome curto.
* `database` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela. Fica vazio se a política for para o banco de dados.
* `id` ([UUID](/pt-BR/sql-reference/data-types/uuid)) — ID da ROW POLICY.
* `storage` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do diretório onde a ROW POLICY é armazenada.
* `select_filter` ([Nullable(String)](/pt-BR/sql-reference/data-types/nullable)) — Expressão usada para filtragem em consultas SELECT.
* `is_restrictive` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a ROW POLICY restringe o acesso às linhas. Valor: • 0 — A ROW POLICY é definida com a cláusula `AS PERMISSIVE`, • 1 — A ROW POLICY é definida com a cláusula AS RESTRICTIVE.
* `apply_to_all` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica que a ROW POLICY se aplica a todos os papéis e/ou usuários.
* `apply_to_list` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — Lista de papéis e/ou usuários aos quais a ROW POLICY se aplica.
* `apply_to_except` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — A ROW POLICY se aplica a todos os papéis e/ou usuários, exceto aos listados.

{/*AUTOGENERATED_END*/ }
