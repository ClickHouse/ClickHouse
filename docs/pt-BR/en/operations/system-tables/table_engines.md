<div id="description">
  ## Descrição
</div>

Contém a descrição dos motores de tabela suportados pelo servidor e informações sobre o suporte às suas funcionalidades.

Esta tabela contém as seguintes colunas (o tipo da coluna é mostrado entre parênteses):

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do motor de tabela.
* `supports_settings` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte à cláusula SETTINGS.
* `supports_skipping_indices` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte a índices de skipping.
* `supports_projections` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte a projeções.
* `supports_sort_order` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte às cláusulas PARTITION&#95;BY, PRIMARY&#95;KEY, ORDER&#95;BY e SAMPLE&#95;BY.
* `supports_ttl` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte a TTL.
* `supports_replication` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte à replicação de dados.
* `supports_deduplication` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte à desduplicação de dados.
* `supports_parallel_insert` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se o motor de tabela oferece suporte a inserção paralela (consulte a configuração max&#95;insert&#95;threads).
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — Uma descrição do que o motor de tabela faz. Para motores que têm uma página de documentação dedicada, isso contém o conteúdo completo dessa página em Markdown; para os demais motores, é um resumo conciso.
* `syntax` ([String](/pt-BR/sql-reference/data-types/string)) — Como o motor de tabela é usado ao criar uma tabela. Para a maioria dos motores, esta é a cláusula ENGINE de uma consulta CREATE TABLE, mas alguns motores (como os vários tipos de views ou o motor Loop) são usados por meio de outras formas, como CREATE VIEW ou um SELECT a partir de uma função de tabela.
* `examples` ([String](/pt-BR/sql-reference/data-types/string)) — Exemplos de uso.
* `introduced_in` ([String](/pt-BR/sql-reference/data-types/string)) — A versão do ClickHouse em que o motor de tabela foi introduzido pela primeira vez, no formato major.minor.
* `related` ([Array](/pt-BR/sql-reference/data-types/array)([String](/pt-BR/sql-reference/data-types/string))) — Os nomes dos motores de tabela relacionados.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql title="Query"
SELECT
    name,
    supports_settings,
    supports_skipping_indices,
    supports_sort_order,
    supports_ttl,
    supports_replication,
    supports_deduplication,
    supports_parallel_insert
FROM system.table_engines
WHERE name IN ('Kafka', 'MergeTree', 'ReplicatedCollapsingMergeTree')
```
