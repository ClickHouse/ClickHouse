<div id="description">
  ## Descrição
</div>

Esta tabela não existe se este nó não estiver configurado para executar um ClickHouse Keeper no mesmo processo. Ela contém uma linha por arquivo de changelog do Raft (`changelog_<from>_<to>.bin[.zstd]`) rastreado pelo armazenamento de log do Keeper no mesmo processo, incluindo o arquivo ativo ao qual novas entradas estão sendo adicionadas.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `from_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Primeiro índice de log do Raft no arquivo (inclusivo).
* `to_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Último índice de log do Raft abrangido pelo nome do arquivo (inclusivo). No arquivo ativo, este é o alvo da rotação e pode estar à frente de `last_entry_index`.
* `last_entry_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Maior índice de log efetivamente anexado a este arquivo. `NULL` se o arquivo ativo ainda não tiver recebido nenhuma entrada ou se o arquivo estiver corrompido.
* `entries` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Número de entradas anexadas a este arquivo. `ALIAS` de `ifNull(last_entry_index - from_log_index + 1, 0)`.
* `path` ([String](../../sql-reference/data-types/string.md)) — Caminho do arquivo no disco.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Nome do disco que contém o arquivo.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Tamanho do arquivo em disco.
* `modification_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — Data e hora da última modificação do arquivo.
* `is_compressed` ([Bool](../../sql-reference/data-types/boolean.md)) — O payload do arquivo está comprimido com zstd.
* `active` ([Bool](../../sql-reference/data-types/boolean.md)) — Novas entradas estão sendo anexadas a este arquivo no momento.
* `is_broken` ([Bool](../../sql-reference/data-types/boolean.md)) — Um registro final corrompido foi encontrado na inicialização.

{/*AUTOGENERATED_END*/ }

Exemplo:

```sql
SELECT from_log_index, to_log_index, entries, path, active FROM system.keeper_changelogs ORDER BY from_log_index;
```

```text
┌─from_log_index─┬─to_log_index─┬─entries─┬─path───────────────────────────┬─active─┐
│              1 │         1000 │    1000 │ changelog_1_1000.bin.zstd      │ false  │
│           1001 │         2000 │     537 │ changelog_1001_2000.bin.zstd   │ true   │
└────────────────┴──────────────┴─────────┴────────────────────────────────┴────────┘
```
