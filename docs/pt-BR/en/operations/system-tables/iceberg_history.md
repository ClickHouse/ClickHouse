<div id="description">
  ## Descrição
</div>

Esta tabela do sistema contém o histórico de snapshots das tabelas Iceberg existentes no ClickHouse. Ela estará vazia se você não tiver nenhuma tabela Iceberg no ClickHouse.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/pt-BR/sql-reference/data-types/string)) — nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `made_current_at` ([Nullable(DateTime64(3))](/pt-BR/sql-reference/data-types/nullable)) — Data e hora em que este snapshot passou a ser o snapshot atual.
* `snapshot_id` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — ID do snapshot usado para identificar um snapshot.
* `parent_id` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — ID pai deste snapshot.
* `is_current_ancestor` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador que informa se este snapshot é um ancestral do snapshot atual.

{/*AUTOGENERATED_END*/ }
