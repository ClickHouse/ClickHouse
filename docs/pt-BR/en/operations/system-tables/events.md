<div id="description">
  ## Descrição
</div>

Contém informações sobre o número de eventos que ocorreram no sistema. Por exemplo, na tabela, você pode ver quantas consultas `SELECT` foram processadas desde que o servidor ClickHouse foi iniciado.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do evento.
* `value` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Número de eventos ocorridos.
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — Descrição do evento.

**Aliases:**

* `name` — Alias de `event`.

{/*AUTOGENERATED_END*/ }

<div id="example">

```sql
SELECT * FROM system.events LIMIT 5
```
