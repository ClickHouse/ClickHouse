<div id="description">
  ## Descrição
</div>

Contém avisos sobre a configuração do servidor que serão exibidos pelo clickhouse-client logo após se conectar ao servidor.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `message` ([String](/pt-BR/sql-reference/data-types/string)) — Uma mensagem de aviso emitida pelo servidor ClickHouse.
* `message_format_string` ([LowCardinality(String)](/pt-BR/sql-reference/data-types/lowcardinality)) — Uma string de formatação usada para formatar a mensagem.
