<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os formatos, com indicadores que mostram se um formato é adequado para entrada/saída ou se oferece suporte à paralelização.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do formato.
* `is_input` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador de que o formato é adequado para entrada de dados.
* `is_output` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador de que o formato é adequado para saída de dados.
* `supports_parallel_parsing` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador de que o formato oferece suporte a parsing em paralelo.
* `supports_parallel_formatting` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador de que o formato oferece suporte a formatação em paralelo.
* `is_tty_friendly` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador de que o formato normalmente é exibido corretamente no terminal. Para outros formatos, a CLI pedirá confirmação antes de exibir a saída.
* `content_type` ([String](/pt-BR/sql-reference/data-types/string)) — `Content-Type` HTTP correspondente ao formato de saída. Pode depender das configurações atuais do formato.
* `supports_random_access` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indicador de que o formato oferece suporte a acesso aleatório na entrada.
* `has_schema_inference` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — O formato pode inferir dinamicamente o esquema a partir dos dados (seja de cabeçalhos/metadados embutidos ou do próprio trecho de dados).
* `has_external_schema` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — O formato tem um esquema fixo ou aceita um esquema predefinido no próprio formato.
* `prefers_large_blocks` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — O formato gravará blocos maiores na saída e gerará blocos maiores na entrada.
* `supports_append` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — É possível acrescentar dados a um único arquivo com este formato.
* `supports_subsets_of_columns` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — O formato de entrada pode reconhecer quando determinadas colunas são omitidas.
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — Uma descrição geral do formato.
* `examples` ([String](/pt-BR/sql-reference/data-types/string)) — Exemplos de uso.
* `introduced_in` ([String](/pt-BR/sql-reference/data-types/string)) — A versão do ClickHouse em que o formato foi introduzido pela primeira vez, na forma major.minor.
* `related` ([Array](/pt-BR/sql-reference/data-types/array)([String](/pt-BR/sql-reference/data-types/string))) — Os nomes dos formatos relacionados.

{/*AUTOGENERATED_END*/ }
