<div id="description">
  ## Descrição
</div>

A tabela não existe, a menos que o ClickHouse Keeper ou o ZooKeeper esteja configurado. A tabela `system.zookeeper` expõe dados dos clusters Keeper definidos na config.
A consulta deve ter uma condição `path =`   ou uma condição `path IN`  definida na cláusula `WHERE`, como mostrado abaixo. Isso corresponde ao caminho dos nós filhos para os quais você deseja obter dados.

A consulta `SELECT * FROM system.zookeeper WHERE path = '/clickhouse'` retorna dados de todos os nós filhos no nó `/clickhouse`.
Para retornar dados de todos os nós raiz, escreva path = &#39;/&#39;.
Se o caminho especificado em &#39;path&#39; não existir, uma exceção será lançada.

A consulta `SELECT * FROM system.zookeeper WHERE path IN ('/', '/clickhouse')` retorna dados de todos os nós filhos nos nós `/` e `/clickhouse`.
Se algum caminho na coleção &#39;path&#39; especificada não existir, uma exceção será lançada.
Ela pode ser usada para fazer um batch de consultas de caminhos do Keeper.

A consulta `SELECT * FROM system.zookeeper WHERE path = '/clickhouse' AND zookeeperName = 'auxiliary_cluster'` retorna dados no cluster ZooKeeper `auxiliary_cluster`.
Se o `auxiliary_cluster` especificado não existir, uma exceção será lançada.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` (String) — O nome do nó.
* `path` (String) — O caminho do nó.
* `value` (String) — Valor do nó.
* `zookeeperName` (String) — O nome do cluster ZooKeeper padrão ou de um dos clusters ZooKeeper auxiliares.
* `dataLength` (Int32) — Tamanho do valor.
* `numChildren` (Int32) — Número de descendentes.
* `czxid` (Int64) — ID da transação que criou o nó.
* `mzxid` (Int64) — ID da transação que alterou o nó pela última vez.
* `pzxid` (Int64) — ID da transação que removeu ou adicionou descendentes pela última vez.
* `ctime` (DateTime) — Hora de criação do nó.
* `mtime` (DateTime) — Hora da última modificação do nó.
* `version` (Int32) — Versão do nó: o número de vezes que o nó foi alterado.
* `cversion` (Int32) — Número de descendentes adicionados ou removidos.
* `aversion` (Int32) — Número de alterações na ACL.
* `ephemeralOwner` (Int64) — Para nós efêmeros, o ID da sessão à qual este nó pertence.

{/*AUTOGENERATED_END*/ }

```sql
SELECT *
FROM system.zookeeper
WHERE path = '/clickhouse/tables/01-08/visits/replicas'
FORMAT Vertical
```
