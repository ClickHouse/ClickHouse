<div id="description">
  ## Descrição
</div>

Contém informações sobre todas as políticas de mascaramento definidas no sistema.

As políticas de mascaramento só podem ser criadas e aplicadas no ClickHouse Cloud. Em compilações de código aberto, a tabela `system.masking_policies` está sempre vazia, mas continua presente para que consultas de introspecção, como `SHOW MASKING POLICIES`, funcionem e retornem um resultado vazio em vez de gerar uma exceção.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string.md)) — Nome de uma política de mascaramento. O formato do nome completo é `short_name ON database.table`.
* `short_name` ([String](/pt-BR/sql-reference/data-types/string.md)) — Nome curto de uma política de mascaramento. Por exemplo, se o nome completo for `mask_email ON mydb.mytable`, o nome curto será `mask_email`.
* `database` ([String](/pt-BR/sql-reference/data-types/string.md)) — nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string.md)) — Nome da tabela.
* `id` ([UUID](/pt-BR/sql-reference/data-types/uuid.md)) — ID da política de mascaramento.
* `storage` ([String](/pt-BR/sql-reference/data-types/string.md)) — Nome do diretório em que a política de mascaramento é armazenada.
* `update_assignments` ([Nullable(String)](/pt-BR/sql-reference/data-types/nullable.md)) — Atribuições de UPDATE que definem como os dados devem ser mascarados. Por exemplo: `email = '***masked***', phone = '***-***-****'`.
* `where_condition` ([Nullable(String)](/pt-BR/sql-reference/data-types/nullable.md)) — Condição WHERE opcional que especifica quando o mascaramento deve ser aplicado.
* `priority` ([Int64](/pt-BR/sql-reference/data-types/int-uint.md)) — Prioridade para aplicar várias políticas de mascaramento. As políticas de maior prioridade são aplicadas primeiro. O padrão é 0.
* `apply_to_all` ([UInt8](/pt-BR/sql-reference/data-types/int-uint.md)) — Indica se a política de mascaramento se aplica a todas as funções e/ou usuários. 1 se true, 0 caso contrário.
* `apply_to_list` ([Array(String)](/pt-BR/sql-reference/data-types/array.md)) — Lista das funções e/ou usuários aos quais a política de mascaramento é aplicada.
* `apply_to_except` ([Array(String)](/pt-BR/sql-reference/data-types/array.md)) — A política de mascaramento é aplicada a todas as funções e/ou usuários, exceto aos listados. Preenchido somente quando `apply_to_all` é 1.
