<div id="description">
  ## Descrição
</div>

Contém informações sobre as disks definidas na [configuração do servidor](../../engines/table-engines/mergetree-family/mergetree.md#table_engine-mergetree-multiple-volumes_configure).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome de um disk na configuração do servidor.
* `path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho para o ponto de montagem no sistema de arquivos.
* `free_space` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Espaço livre no disk em bytes.
* `total_space` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Volume do disk em bytes.
* `unreserved_space` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Espaço livre que não está ocupado por reservas (`free_space` menos o tamanho das reservas feitas por merges, inserts e outras operações de gravação no disk atualmente em execução).
* `keep_free_space` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Quantidade de espaço no disk que deve permanecer livre, em bytes. Definida no parâmetro `keep_free_space_bytes` da configuração do disk.
* `type` ([String](/pt-BR/sql-reference/data-types/string)) — O tipo de disk, que informa onde este disk armazena os dados: RAM, unidade local ou armazenamento remoto.
* `object_storage_type` ([String](/pt-BR/sql-reference/data-types/string)) — Tipo de armazenamento de objetos se o tipo de disk for `object_storage`
* `metadata_type` ([String](/pt-BR/sql-reference/data-types/string)) — Tipo de armazenamento de metadados se o tipo de disk for `object_storage`
* `is_encrypted` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Flag que mostra se este disk criptografa os dados subjacentes.
* `is_read_only` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Flag que indica que você só pode realizar operações de leitura com este disk.
* `is_write_once` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Flag que indica se o disk é de gravação única. Isso significa que ele oferece suporte a BACKUP para este disk, mas não oferece suporte a INSERT em tabela MergeTree neste disk.
* `is_remote` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Flag que indica quais operações com este disk envolvem interação de rede.
* `is_broken` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Flag que indica se o disk está com falha. Disks com falha terão 0 de espaço e não poderão ser usados.
* `cache_path` ([String](/pt-BR/sql-reference/data-types/string)) — O caminho para o diretório de cache na unidade local, caso o disk ofereça suporte a cache.

{/*AUTOGENERATED_END*/ }
