<div id="description">
  ## Descrição
</div>

Contém o estado em memória dos metadados do S3Queue e as linhas atualmente processadas por arquivo.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho no ZooKeeper para os metadados
* `file_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho do arquivo que está sendo processado
* `file_name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do arquivo que está sendo processado
* `rows_processed` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Número de linhas processadas até o momento
* `status` ([String](/pt-BR/sql-reference/data-types/string)) — Status do processamento: Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Momento em que o processamento do arquivo foi iniciado
* `processing_end_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Momento em que o processamento do arquivo foi encerrado
* `exception` ([String](/pt-BR/sql-reference/data-types/string)) — Exceção ocorrida durante o processamento

{/*AUTOGENERATED_END*/ }
