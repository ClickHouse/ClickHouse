<div id="description">
  ## Descrição
</div>

Contém informações sobre arquivos de dados armazenados em discos remotos (por exemplo, S3, Azure Blob Storage), incluindo o mapeamento entre os caminhos locais dos metadados e os caminhos remotos dos blobs.

Cada linha representa um objeto blob remoto associado a um arquivo de dados.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `disk_name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do disco.
* `path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho do disco.
* `cache_base_path` ([String](/pt-BR/sql-reference/data-types/string)) — Diretório base dos arquivos de cache.
* `local_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho do arquivo do ClickHouse, também usado como caminho de metadados.
* `remote_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho do blob no armazenamento de objetos ao qual o arquivo do ClickHouse está associado.
* `size` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Tamanho do arquivo (comprimido).
* `common_prefix_for_blobs` ([String](/pt-BR/sql-reference/data-types/string)) — Prefixo comum para blobs no armazenamento de objetos.
* `cache_paths` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — Arquivos de cache para o blob correspondente.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql
SELECT * FROM system.remote_data_paths LIMIT 1 FORMAT Vertical;
```

```text
Row 1:
──────
disk_name:              s3
path:                   /var/lib/clickhouse/disks/s3/
cache_base_path:        /var/lib/clickhouse/disks/s3_cache/
local_path:             store/123/1234abcd-1234-1234-1234-1234abcd1234/all_0_0_0/data.bin
remote_path:            abc123/all_0_0_0/data.bin
size:                   1048576
common_prefix_for_blobs:
cache_paths:            ['/var/lib/clickhouse/disks/s3_cache/a1/b2/c3d4e5f6']
```
