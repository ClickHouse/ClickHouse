<div id="description">
  ## Descrição
</div>

Contém informações sobre os parâmetros [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite), usados em tabelas com motores [*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/pt-BR/sql-reference/data-types/string)) — nome do parâmetro graphite&#95;rollup.
* `rule_type` ([String](/pt-BR/sql-reference/data-types/string)) — O tipo de regra. Valores possíveis: RuleTypeAll = 0 - padrão, com regex, compatível com o esquema antigo; RuleTypePlain = 1 - métricas simples, com regex, compatível com o esquema antigo; RuleTypeTagged = 2 - métricas com tag, com regex, compatível com o esquema antigo; RuleTypeTagList = 3 - métricas com tag, com regex (convertido para RuleTypeTagged a partir de uma string como &#39;retention=10min ; env=(staging|prod)&#39;)
* `regexp` ([String](/pt-BR/sql-reference/data-types/string)) — Um padrão para o nome da métrica.
* `function` ([String](/pt-BR/sql-reference/data-types/string)) — O nome da função de agregação.
* `age` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — A idade mínima dos dados, em segundos.
* `precision` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Com que precisão definir a idade dos dados em segundos.
* `priority` ([UInt16](/pt-BR/sql-reference/data-types/int-uint)) — Prioridade do padrão.
* `is_default` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se este é o padrão definido.
* `Tables.database` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — Array com os nomes dos bancos de dados das tabelas que usam o parâmetro `config_name`.
* `Tables.table` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — Array com os nomes das tabelas que usam o parâmetro `config_name`.
