<div id="description">
  ## Descrição
</div>

Esta tabela não existe se este nó não estiver configurado para executar um ClickHouse Keeper no próprio processo. Ela contém uma linha por membro do cluster Raft, combinando a topologia estática do cluster (da configuração do Raft) com a posição no log do próprio nó local.

Cada nó preenche exatamente um valor de `last_log_index` — a linha correspondente ao seu próprio `server_id`. As posições no log dos outros membros não são exibidas aqui porque são rastreadas apenas no líder, e essa visão não é simétrica em todo o cluster.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — id do servidor Raft deste membro do cluster.
* `host` ([String](../../sql-reference/data-types/string.md)) — Host extraído do endpoint (prefixo antes do último sinal de dois-pontos).
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — endpoint Raft bruto, conforme configurado (`host:port`).
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` se este membro for um observador sem direito a voto, configurado via `<can_become_leader>false</can_become_leader>`.
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — prioridade Raft deste membro; valores mais altos têm preferência durante a eleição de líder.
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` se este membro for o líder Raft atual.
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` se esta linha descrever o nó local do Keeper.
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Maior índice de log no armazenamento local de logs Raft neste nó. Preenchido apenas na linha correspondente ao nó atual (`is_self = true`); `NULL` nas outras linhas.

{/*AUTOGENERATED_END*/ }

```sql
SELECT * FROM system.keeper_cluster ORDER BY server_id;
```
