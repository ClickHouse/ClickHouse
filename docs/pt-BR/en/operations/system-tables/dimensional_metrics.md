<div id="description">
  ## Descrição
</div>

Esta tabela contém métricas dimensionais que podem ser calculadas instantaneamente e exportadas em formato Prometheus. Ela está sempre atualizada.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da métrica.
* `value` ([Float64](/pt-BR/sql-reference/data-types/float)) — Valor da métrica.
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — Descrição da métrica.
* `labels` ([Map(String, String)](/pt-BR/sql-reference/data-types/map)) — Labels da métrica.

**Aliases:**

* `name` — Alias para `metric`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

Você pode usar uma consulta como esta para exportar todas as métricas dimensionais no formato Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## Descrições das métricas
</div>

<div id="merge_failures">
  ### merge_failures
</div>

Número total de merges com falha desde a inicialização.

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

Indica falhas nos scripts de inicialização por tipo de erro. É definida como 1 quando um script de inicialização falha, rotulada com o nome do erro.

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

Número de partes de dados do MergeTree, identificado por estado da parte, tipo da parte e por ser ou não uma parte de projeção.

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

Número de segmentos de arquivo removidos de um cache do sistema de arquivos, identificado pelo nome do cache. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

Total de bytes de segmentos de arquivo removidos do cache do sistema de arquivos, identificado pelo nome do cache. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

Número de segmentos de arquivo removidos de um cache do sistema de arquivos, identificado por nome do cache e ID do usuário. Desativado por padrão; habilite com `expose_prometheus_eviction_metrics` e `expose_prometheus_eviction_metrics_per_user`.

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

Total de bytes de segmentos de arquivo expulsos do cache do sistema de arquivos, identificado pelo nome do cache e pelo ID do usuário. Desativado por padrão; ative com `expose_prometheus_eviction_metrics` e `expose_prometheus_eviction_metrics_per_user`.
