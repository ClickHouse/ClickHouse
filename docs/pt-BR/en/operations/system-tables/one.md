<div id="description">
  ## Descrição
</div>

Esta tabela contém uma única linha com uma única coluna `dummy` do tipo UInt8, com o valor 0.

Esta tabela é usada quando uma consulta `SELECT` não especifica a cláusula `FROM`.

Ela é semelhante à tabela `DUAL` encontrada em outros DBMSs.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `dummy` ([UInt8](/pt-BR/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql
SELECT * FROM system.one LIMIT 10;
```

```response
┌─dummy─┐
│     0 │
└───────┘

1 rows in set. Elapsed: 0.001 sec.
```
