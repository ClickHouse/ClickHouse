<div id="description">
  ## Descrição
</div>

Mostra todos os tokenizadores disponíveis.
Eles podem ser usados nas funções [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens), [hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens), [hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens) e no [índice de texto](../../engines/table-engines/mergetree-family/textindexes.md).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do tokenizador

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql
SELECT * FROM system.tokenizers;
```
