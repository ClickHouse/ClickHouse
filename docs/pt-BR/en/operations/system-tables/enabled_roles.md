<div id="description">
  ## Descrição
</div>

Contém todos os funções ativos no momento, incluindo o função atual do usuário atual e os funções concedidos ao função atual.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da função.
* `with_admin_option` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — 1 se a função tiver o privilégio ADMIN OPTION.
* `is_current` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se `enabled_role` é uma função atual do usuário atual.
* `is_default` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Sinalizador que indica se `enabled_role` é uma função padrão.

{/*AUTOGENERATED_END*/ }
