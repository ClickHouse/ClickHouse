<div id="description">
  ## Descrição
</div>

Contém uma lista de todos os combinadores de funções de agregação disponíveis, que podem ser aplicados a funções de agregação e alterar seu funcionamento.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do combinador.
* `is_internal` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se este combinador é apenas para uso interno.
