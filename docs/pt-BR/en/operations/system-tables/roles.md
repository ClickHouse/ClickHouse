Contém informações sobre as [funções](../../guides/sre/user-management/index.md#role-management) configuradas.

<div id="columns">

</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da função.
* `id` ([UUID](/pt-BR/sql-reference/data-types/uuid)) — ID da função.
* `storage` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho para o armazenamento das funções. Configurado no parâmetro `access_control_path`.
