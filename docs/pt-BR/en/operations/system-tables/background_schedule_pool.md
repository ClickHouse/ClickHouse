<div id="systembackground_schedule_pool">
  # system.background_schedule_pool
</div>

<SystemTableCloud />

<div id="description">
  ## Descrição
</div>

Contém informações sobre as tarefas nos pools de agendamento em segundo plano. Os pools de agendamento em segundo plano são usados para executar tarefas periódicas, como envios distribuídos, descarregamentos de buffer e operações do broker de mensagens.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `pool` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do pool. Possíveis valores: `schedule` — pool de agendamento de uso geral, `buffer_flush` — pool para flush de dados da tabela Buffer, `distributed` — pool para operações de tabela distribuída, `message_broker` — pool para operações do broker de mensagens.
* `database` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `table_uuid` ([UUID](/pt-BR/sql-reference/data-types/uuid)) — UUID da tabela.
* `query_id` ([String](/pt-BR/sql-reference/data-types/string)) — ID da consulta (se estiver em execução no momento). Observação: esta não é uma consulta real, mas um ID gerado aleatoriamente para associar logs em `system.text_log`.
* `elapsed_ms` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Tempo de execução da tarefa (se estiver em execução no momento).
* `log_name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do log da tarefa.
* `deactivated` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a tarefa está desativada (sempre `false`, já que tarefas desativadas são removidas do pool).
* `scheduled` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a tarefa está agendada para execução.
* `delayed` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a tarefa foi agendada com atraso.
* `executing` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a tarefa está em execução no momento.

{/*AUTOGENERATED_END*/ }
