<div id="description">
  ## Descrição
</div>

Contém informações sobre tabelas nas quais o comando DROP TABLE foi executado, mas cuja limpeza de dados ainda não foi realizada.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt32](/pt-BR/sql-reference/data-types/int-uint)) — Índice na fila marked&#95;dropped&#95;tables.
* `database` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `uuid` ([UUID](/pt-BR/sql-reference/data-types/uuid)) — UUID da tabela.
* `engine` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do engine da tabela.
* `metadata_dropped_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho do arquivo de metadados da tabela no diretório metadata&#95;dropped.
* `table_dropped_time` ([DateTime](/pt-BR/sql-reference/data-types/datetime)) — O momento em que a próxima tentativa de remover os dados da tabela está agendada. Normalmente, é o momento em que a tabela foi removida mais `database_atomic_delay_before_drop_table_sec`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

O exemplo a seguir mostra como obter informações sobre `dropped_tables`.

```sql
SELECT *
FROM system.dropped_tables\G
```
