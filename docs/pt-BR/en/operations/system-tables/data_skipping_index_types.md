<div id="description">
  ## Descrição
</div>

Contém a lista dos tipos de data skipping index compatíveis com o servidor, juntamente com a documentação embutida de cada tipo. Um tipo de data skipping index é especificado no `TYPE` de uma declaração `INDEX` em uma consulta `CREATE TABLE` e permite que o ClickHouse pule grânulos que não podem satisfazer a condição de uma consulta.

Observe que esta tabela lista os *tipos* de índice disponíveis, enquanto [`system.data_skipping_indices`](/pt-BR/operations/system-tables/data_skipping_indices) lista as instâncias de índice definidas em tabelas existentes.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do tipo de data skipping index, conforme especificado no TYPE de uma declaração INDEX.
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — Uma descrição geral do que o tipo de data skipping index faz.
* `syntax` ([String](/pt-BR/sql-reference/data-types/string)) — Como o índice é declarado em uma cláusula INDEX de uma consulta CREATE TABLE.
* `examples` ([String](/pt-BR/sql-reference/data-types/string)) — Exemplos de uso.
* `introduced_in` ([String](/pt-BR/sql-reference/data-types/string)) — A versão do ClickHouse em que o tipo de índice foi introduzido pela primeira vez, no formato major.minor.
* `related` ([Array](/pt-BR/sql-reference/data-types/array)([String](/pt-BR/sql-reference/data-types/string))) — Os nomes de tipos relacionados de data skipping index.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql title="Query"
SELECT name, syntax
FROM system.data_skipping_index_types
WHERE name IN ('minmax', 'set')
ORDER BY name
```

```text title="Response"
┌─name───┬─syntax───────────────────────────────────────┐
│ minmax │ INDEX name expr TYPE minmax GRANULARITY n     │
│ set    │ INDEX name expr TYPE set(max_rows) GRANULARITY n │
└────────┴──────────────────────────────────────────────┘
```
