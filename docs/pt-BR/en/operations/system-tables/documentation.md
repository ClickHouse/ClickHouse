<div id="description">
  ## Descrição
</div>

Reúne em uma única tabela a documentação embutida dos componentes uniformes do sistema. Cada linha corresponde a uma entidade (uma função, um motor de tabela, um tipo de dado e assim por diante) e contém a documentação de referência dessa entidade renderizada em Markdown — o mesmo conteúdo publicado no site e exposto pelas tabelas `system.*` específicas por tipo.

A `description` é montada a partir das partes estruturadas da documentação embutida (`description`, `syntax`, argumentos, exemplos e assim por diante), de modo que uma única coluna contém a documentação completa de uma entidade. Aliases são renderizados como uma breve referência à entidade canônica, por exemplo ``Alias of `trunc`.``

Esta tabela, em certa medida, reúne as informações disponíveis nas tabelas de documentação específicas por tipo ([`system.functions`](/pt-BR/operations/system-tables/functions), [`system.table_engines`](/pt-BR/operations/system-tables/table_engines), [`system.data_type_families`](/pt-BR/operations/system-tables/data_type_families) e outras). Ela foi pensada, em particular, para dar suporte a um comando `help` interativo no cliente, mas também é útil por si só.

Os seguintes tipos de entidades são reunidos (o valor da coluna `type` é mostrado entre parênteses):

* Funções (`Function`)
* Funções de agregação (`Aggregate Function`)
* Funções de tabela (`Table Function`)
* Motores de tabela (`Table Engine`)
* Motores de banco de dados (`Database Engine`)
* Tipos de dados (`Data Type`)
* Layouts de dicionário (`Dictionary Layout`)
* Fontes de dicionário (`Dictionary Source`)
* Combinadores de função de agregação (`Aggregate Function Combinator`)
* Tipos de índice de data skipping (`Data Skipping Index`)
* Tipos de disco (`Disk Type`)
* Configurações (`Setting`)
* Configurações do MergeTree (`MergeTree Setting`)
* Configurações do servidor (`Server Setting`)
* Formatos (`Format`)
* Codecs de compressão (`Compression Codec`)
* Eventos de perfil (`Profile Event`)
* Métricas atuais (`Current Metric`)
* Métricas assíncronas (`Asynchronous Metric`)
* Tabelas do sistema (`System Table`)

Para configurações (de qualquer tipo), a documentação consiste na descrição da configuração, junto com seu tipo e valor padrão; configurações obsoletas não são expostas. Para tabelas do sistema, a documentação consiste no comentário da tabela junto com a lista de suas colunas (o nome, o tipo e a descrição de cada uma).

A coluna `source` contém o caminho do arquivo-fonte em que a documentação da entidade está definida, relativo à raiz do repositório. Para a maioria das entidades, ele é capturado automaticamente no local em que o objeto de documentação é construído (o local de registro do componente); para os tipos documentados cada um em um único arquivo-fonte (como configurações, eventos de perfil e métricas atuais), é esse arquivo.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — O nome da entidade, por exemplo `domainWithoutWWW` ou `MergeTree`.
* `type` ([Enum8](/pt-BR/sql-reference/data-types/enum)) — O tipo da entidade, por exemplo `Function` ou `Table Engine`.
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — A documentação de referência da entidade, renderizada em Markdown e montada a partir da documentação embutida (o mesmo conteúdo publicado no site), incluindo sintaxe, exemplos e outras partes estruturadas, se houver.
* `source` ([String](/pt-BR/sql-reference/data-types/string)) — O caminho para o arquivo-fonte em que a documentação da entidade está definida, relativo à raiz do repositório. Fica vazio se a localização de origem for desconhecida.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

Consulte a documentação de uma entidade específica:

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

O mesmo nome pode se referir a vários tipos de entidades (por exemplo, existe tanto a função de tabela `file` quanto a fonte de dicionário `file`), por isso é útil pesquisar um nome em todos os tipos:

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

Conte quantas entidades documentadas há de cada tipo:

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
