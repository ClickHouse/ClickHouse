<div id="description">
  ## Descrição
</div>

Contém informações sobre os [tipos de dados](../../sql-reference/data-types/index.md).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do tipo de dado.
* `case_insensitive` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Propriedade que indica se um nome de tipo de dado pode ou não ser usado em uma consulta sem distinguir maiúsculas de minúsculas. Por exemplo, `Date` e `date` ambos são válidos.
* `alias_to` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do tipo de dado do qual `name` é um alias.
* `description` ([String](/pt-BR/sql-reference/data-types/string)) — Uma descrição geral do que é o tipo de dado.
* `syntax` ([String](/pt-BR/sql-reference/data-types/string)) — Como o tipo de dado é escrito em uma consulta.
* `examples` ([String](/pt-BR/sql-reference/data-types/string)) — Exemplos de uso.
* `introduced_in` ([String](/pt-BR/sql-reference/data-types/string)) — A versão do ClickHouse em que o tipo de dado foi introduzido pela primeira vez, no formato major.minor.
* `related` ([Array](/pt-BR/sql-reference/data-types/array)([String](/pt-BR/sql-reference/data-types/string))) — Os nomes dos tipos de dados relacionados.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

