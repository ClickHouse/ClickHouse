<div id="description">
  ## Descrição
</div>

Contém informações sobre cada tabela desanexada.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do banco de dados ao qual a tabela pertence.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `uuid` ([UUID](/pt-BR/sql-reference/data-types/uuid)) — UUID da tabela (banco de dados Atomic).
* `metadata_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho para os metadados da tabela no sistema de arquivos.
* `is_permanently` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — A tabela foi desanexada permanentemente.

{/*AUTOGENERATED_END*/ }

  ## Exemplo
</div>

```sql
SELECT * FROM system.detached_tables FORMAT Vertical;
```

