<div id="description">
  ## Descrição
</div>

Contém informações sobre os diretórios de usuários configurados — diretórios no sistema de arquivos a partir dos quais o servidor ClickHouse pode ler dados fornecidos pelo usuário.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do diretório.
* `type` ([String](/pt-BR/sql-reference/data-types/string)) — O tipo do armazenamento de acesso, por exemplo `users.xml`, `replicated` ou `memory`.
* `params` ([String](/pt-BR/sql-reference/data-types/string)) — JSON com os parâmetros do armazenamento de acesso.
* `precedence` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — A ordem em que este diretório é declarado na configuração. Essa mesma ordem é usada quando o ClickHouse tenta encontrar um usuário ou uma função.

{/*AUTOGENERATED_END*/ }
