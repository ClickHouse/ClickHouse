<div id="description">
  ## Descrição
</div>

Contém informações sobre os [recursos](/pt-BR/operations/workload-scheduling.md#workload_entity_storage) no servidor local. A tabela contém uma linha para cada recurso.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do recurso.
* `read_disks` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — A lista de nomes de discos que usam este recurso para operações de leitura.
* `write_disks` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — A lista de nomes de discos que usam este recurso para operações de gravação.
* `unit` ([String](/pt-BR/sql-reference/data-types/string)) — Unidade do recurso usada para medir custos.
* `create_query` ([String](/pt-BR/sql-reference/data-types/string)) — A consulta CREATE do recurso.

{/*AUTOGENERATED_END*/ }

Exemplo:

```sql
SELECT *
FROM system.resources
FORMAT Vertical
```

```text
Row 1:
──────
name:         io_read
read_disks:   ['s3']
write_disks:  []
create_query: CREATE RESOURCE io_read (READ DISK s3)

Row 2:
──────
name:         io_write
read_disks:   []
write_disks:  ['s3']
create_query: CREATE RESOURCE io_write (WRITE DISK s3)
```
