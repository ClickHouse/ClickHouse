<div id="description">
  ## Descrição
</div>

Contém informações sobre inserções assíncronas pendentes na fila.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/pt-BR/sql-reference/data-types/string)) — Texto da consulta.
* `database` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `format` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do formato.
* `first_update` ([DateTime64(6)](/pt-BR/sql-reference/data-types/datetime64)) — Primeiro momento de inserção com resolução de microssegundos.
* `total_bytes` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Número total de bytes aguardando na fila.
* `entries.query_id` ([Array(String)](/pt-BR/sql-reference/data-types/array)) — Array de IDs de consulta das inserções que aguardam na fila.
* `entries.bytes` ([Array(UInt64)](/pt-BR/sql-reference/data-types/array)) — Array de bytes de cada consulta de inserção que aguarda na fila.

{/*AUTOGENERATED_END*/ }
