<div id="description">
  ## Descrição
</div>

Mostra todos os stemmers disponíveis.
Eles podem ser usados na função [stem](../../sql-reference/functions/nlp-functions.md).

:::note Disponibilidade
`system.stemmers` está presente apenas em compilações do ClickHouse compiladas com a dependência `libstemmer` (`USE_LIBSTEMMER`). Em compilações sem essa dependência, a tabela não existe, e as consultas a ela falharão com `UNKNOWN_TABLE`. Você pode verificar se ela está habilitada na sua compilação com:

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

Colunas:

{/*AUTOGENERATED_START*/ }

* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Identificador do stemmer Snowball (idioma/algoritmo)

{/*AUTOGENERATED_END*/ }
