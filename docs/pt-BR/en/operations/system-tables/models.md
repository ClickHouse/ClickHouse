<div id="description">
  ## Descrição
</div>

Contém uma lista de modelos CatBoost carregados na memória do LibraryBridge, junto com o momento em que foram carregados.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `model_path` ([String](/pt-BR/sql-reference/data-types/string)) — Caminho do modelo treinado.
* `type` ([String](/pt-BR/sql-reference/data-types/string)) — Tipo do modelo. No momento, apenas catboost.
* `loading_start_time` ([DateTime](/pt-BR/sql-reference/data-types/datetime)) — Momento em que o carregamento do modelo começou.
* `loading_duration` ([Float32](/pt-BR/sql-reference/data-types/float)) — Tempo necessário para carregar o modelo.

{/*AUTOGENERATED_END*/ }
