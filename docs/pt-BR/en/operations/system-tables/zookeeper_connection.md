<div id="description">
  ## Descrição
</div>

Esta tabela não existe se o ZooKeeper não estiver configurado. A tabela &#39;system.zookeeper&#95;connection&#39; exibe as conexões atuais com o ZooKeeper (incluindo os ZooKeepers auxiliares). Cada linha exibe informações sobre uma conexão.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](../../sql-reference/data-types/string.md)) — Nome do cluster ZooKeeper.
* `host` ([String](../../sql-reference/data-types/string.md)) — O hostname/IP do nó ZooKeeper ao qual o ClickHouse se conectou.
* `port` ([UIn16](../../sql-reference/data-types/int-uint.md)) — A porta do nó ZooKeeper ao qual o ClickHouse se conectou.
* `index` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — O índice do nó ZooKeeper ao qual o ClickHouse se conectou. O índice vem da configuração do ZooKeeper. Se não houver conexão, esta coluna será NULL.
* `connected_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — Momento em que a conexão foi estabelecida
* `session_uptime_elapsed_seconds` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Segundos decorridos desde que a conexão foi estabelecida.
* `is_expired` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Indica se a conexão atual expirou.
* `keeper_api_version` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Versão da API do Keeper.
* `client_id` ([Int64](../../sql-reference/data-types/int-uint.md)) — ID da sessão da conexão.
* `xid` ([Int64](../../sql-reference/data-types/int-uint.md)) — XID da sessão atual.
* `enabled_feature_flags` ([Array(Enum16)](../../sql-reference/data-types/array.md)) — Feature flags habilitadas. Aplicável somente ao ClickHouse Keeper. Os valores possíveis são `FILTERED_LIST`, `MULTI_READ`, `CHECK_NOT_EXISTS`, `CREATE_IF_NOT_EXISTS`, `REMOVE_RECURSIVE`.
* `availability_zone` ([String](../../sql-reference/data-types/string.md)) — Zona de disponibilidade.
* `session_timeout_ms` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Timeout da sessão (em milissegundos).
* `last_zxid_seen` ([Int64](../../sql-reference/data-types/int-uint.md)) — Último zxid visto pela sessão atual.

{/*AUTOGENERATED_END*/ }
