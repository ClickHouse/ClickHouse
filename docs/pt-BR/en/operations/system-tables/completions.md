Contém uma lista de tokens de preenchimento automático.

<div id="columns">
  ## Colunas
</div>

* `word` ([String](/pt-BR/sql-reference/data-types/string)) — Token de preenchimento automático.
* `context` ([String](/pt-BR/sql-reference/data-types/string)) — Tipo de entidade do token (por exemplo, tabela).
* `belongs` ([Nullable(String)](/pt-BR/sql-reference/data-types/nullable)) — Token da entidade à qual este token pertence (por exemplo, nome do banco de dados ao qual pertence).
