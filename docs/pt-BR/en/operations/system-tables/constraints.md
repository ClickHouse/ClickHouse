<div id="description">
  ## Descrição
</div>

Contém informações sobre as restrições existentes em todas as tabelas.

As restrições definidas em [tabelas temporárias](../../sql-reference/statements/create/table.md#temporary-tables) ficam visíveis em `system.constraints` apenas na sessão em que foram criadas. Elas são exibidas com o campo `database` vazio.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do banco de dados.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da restrição.
* `type` ([Enum8(&#39;CHECK&#39; = 0, &#39;ASSUME&#39; = 1)](/pt-BR/sql-reference/data-types/enum)) — Tipo da restrição.
* `expression` ([String](/pt-BR/sql-reference/data-types/string)) — Expressão da restrição.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemplo
</div>

```sql
SELECT * FROM system.constraints LIMIT 2 FORMAT Vertical;
```

```text
Row 1:
──────
database:    default
table:       hits
name:        check_hits
type:        CHECK
expression:  CounterID > 0

Row 2:
──────
database:    default
table:       hits
name:        assume_positive
type:        ASSUME
expression:  WatchID > 0
```
