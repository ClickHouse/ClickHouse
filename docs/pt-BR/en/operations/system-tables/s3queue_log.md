Contém registros de log com informações sobre arquivos processados pelo mecanismo S3Queue.

É seguro truncar ou excluir esta tabela a qualquer momento.

Colunas:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/pt-BR/sql-reference/data-types/lowcardinality)) — Hostname
* `event_date` ([Date](/pt-BR/sql-reference/data-types/date)) — Data do evento em que esta linha de log foi gravada
* `event_time` ([DateTime](/pt-BR/sql-reference/data-types/datetime)) — Hora do evento em que esta linha de log foi gravada
* `database` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do banco de dados em que a tabela de fila (`S3Queue` ou `AzureQueue`) está.
* `table` ([String](/pt-BR/sql-reference/data-types/string)) — O nome da tabela de fila (`S3Queue` ou `AzureQueue`).
* `uuid` ([String](/pt-BR/sql-reference/data-types/string)) — O UUID da tabela de fila (`S3Queue` ou `AzureQueue`).
* `file_name` ([String](/pt-BR/sql-reference/data-types/string)) — Nome do arquivo em processamento.
* `rows_processed` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Número de linhas processadas.
* `status` ([Enum8(&#39;Processed&#39; = 0, &#39;Failed&#39; = 1)](/pt-BR/sql-reference/data-types/enum)) — Status do arquivo em processamento.
* `processing_start_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Hora de início do processamento do arquivo.
* `processing_end_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Hora de término do processamento do arquivo.
* `exception` ([String](/pt-BR/sql-reference/data-types/string)) — Mensagem da exceção, se houver.
* `commit_id` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — ID da transação na qual este arquivo foi confirmado.
* `commit_time` ([DateTime](/pt-BR/sql-reference/data-types/datetime)) — Hora do commit do arquivo no Keeper (como falho ou processado).
* `transaction_start_time` ([DateTime](/pt-BR/sql-reference/data-types/datetime)) — Hora em que toda a transação de processamento foi iniciada.
* `get_object_time_ms` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Tempo que levamos para localizar o objeto no armazenamento de objetos.
