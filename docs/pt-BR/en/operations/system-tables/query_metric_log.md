<div id="description">
  ## Descrição
</div>

Contém um histórico do uso de memória e dos valores de métricas da tabela `system.events` para consultas individuais, periodicamente persistidos em disco.

Quando uma consulta é iniciada, os dados são coletados em intervalos periódicos de `query_metric_log_interval` milissegundos (cujo valor padrão é 1000
). Os dados também são coletados quando a consulta termina, se ela durar mais do que `query_metric_log_interval`.
