<div id="description">
  ## Descrição
</div>

Informações sobre [views materializadas atualizáveis](../../sql-reference/statements/create/view.md#refreshable-materialized-view). Contém todas as views materializadas atualizáveis, independentemente de haver ou não uma atualização em andamento.

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/pt-BR/sql-reference/data-types/string)) — O nome do banco de dados em que a tabela está.
* `view` ([String](/pt-BR/sql-reference/data-types/string)) — Nome da tabela.
* `uuid` ([UUID](/pt-BR/sql-reference/data-types/uuid)) — UUID da tabela (banco de dados Atomic).
* `status` ([String](/pt-BR/sql-reference/data-types/string)) — Estado atual do refresh.
* `last_success_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Hora em que o refresh bem-sucedido mais recente foi iniciado. NULL se nenhum refresh bem-sucedido tiver ocorrido desde a inicialização do servidor ou a criação da tabela.
* `last_success_duration_ms` ([Nullable(UInt64)](/pt-BR/sql-reference/data-types/nullable)) — Quanto tempo o refresh mais recente levou.
* `last_refresh_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Hora em que a tentativa de refresh mais recente terminou (se conhecida) ou começou (se desconhecida ou ainda em execução). NULL se nenhuma tentativa de refresh tiver ocorrido desde a inicialização do servidor ou a criação da tabela.
* `last_refresh_replica` ([String](/pt-BR/sql-reference/data-types/string)) — Se a coordenação estiver habilitada, nome da réplica que fez a tentativa de refresh atual (se estiver em execução) ou anterior (se não estiver em execução).
* `next_refresh_time` ([Nullable(DateTime)](/pt-BR/sql-reference/data-types/nullable)) — Hora em que o próximo refresh está agendado para começar. NULL se o horário do próximo refresh não for conhecido no momento, por exemplo, ao aguardar dependências (status `WaitingForDependencies` ou `MissingDependencies`).
* `exception` ([String](/pt-BR/sql-reference/data-types/string)) — Mensagem de erro da tentativa anterior, se ela falhou.
* `retry` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Quantas tentativas com falha houve até agora para o refresh atual. Não disponível se o status for `RunningOnAnotherReplica`.
* `progress` ([Nullable(Float64)](/pt-BR/sql-reference/data-types/nullable)) — Progresso do refresh atualmente em execução ou do mais recentemente concluído na réplica especificada, entre 0 e 1. NULL se o status for `RunningOnAnotherReplica` ou se o refresh não estiver em execução.
* `read_rows` ([Nullable(UInt64)](/pt-BR/sql-reference/data-types/nullable)) — Número de linhas lidas pelo refresh atualmente em execução ou pelo mais recentemente concluído na réplica especificada. NULL se o status for `RunningOnAnotherReplica`.
* `read_bytes` ([Nullable(UInt64)](/pt-BR/sql-reference/data-types/nullable)) — Número de bytes lidos pelo refresh atualmente em execução ou pelo mais recentemente concluído na réplica especificada. NULL se o status for `RunningOnAnotherReplica`
* `total_rows` ([Nullable(UInt64)](/pt-BR/sql-reference/data-types/nullable)) — Número total estimado de linhas que precisam ser lidas pelo refresh atualmente em execução ou pelo mais recentemente concluído na réplica especificada. NULL se o status for `RunningOnAnotherReplica`
* `written_rows` ([Nullable(UInt64)](/pt-BR/sql-reference/data-types/nullable)) — Número de linhas gravadas pelo refresh atualmente em execução ou pelo mais recentemente concluído na réplica especificada. NULL se o status for `RunningOnAnotherReplica`
* `written_bytes` ([Nullable(UInt64)](/pt-BR/sql-reference/data-types/nullable)) — Número de bytes gravados pelo refresh atualmente em execução ou pelo mais recentemente concluído na réplica especificada. NULL se o status for `RunningOnAnotherReplica`

{/*AUTOGENERATED_END*/ }

  ## Exemplo
</div>

```sql
SELECT
    database,
    view,
    status,
    last_refresh_time,
    next_refresh_time
FROM system.view_refreshes

┌─database─┬─view───────────────────────┬─status────┬───last_refresh_time─┬───next_refresh_time─┐
│ default  │ hello_documentation_reader │ Scheduled │ 2023-12-01 01:24:00 │ 2023-12-01 01:25:00 │
└──────────┴────────────────────────────┴───────────┴─────────────────────┴─────────────────────┘
```
