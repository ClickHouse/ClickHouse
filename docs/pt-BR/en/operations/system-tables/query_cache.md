<div id="description">
  ## Descrição
</div>

Exibe o conteúdo do [cache de consultas](../query-cache.md).

<div id="columns">
  ## Colunas
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/pt-BR/sql-reference/data-types/string)) — String de consulta.
* `query_id` ([String](/pt-BR/sql-reference/data-types/string)) — ID da consulta.
* `result_size` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Tamanho da entrada no cache de consultas.
* `tag` ([LowCardinality(String)](/pt-BR/sql-reference/data-types/lowcardinality)) — Tag da entrada no cache de consultas.
* `stale` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a entrada no cache de consultas está obsoleta.
* `shared` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a entrada no cache de consultas é compartilhada entre vários usuários.
* `compressed` ([UInt8](/pt-BR/sql-reference/data-types/int-uint)) — Indica se a entrada no cache de consultas está comprimida.
* `expires_at` ([DateTime](/pt-BR/sql-reference/data-types/datetime)) — Momento em que a entrada no cache de consultas se torna obsoleta.
* `key_hash` ([UInt64](/pt-BR/sql-reference/data-types/int-uint)) — Hash da string de consulta, usado como chave para localizar entradas no cache de consultas.

{/*AUTOGENERATED_END*/ }
