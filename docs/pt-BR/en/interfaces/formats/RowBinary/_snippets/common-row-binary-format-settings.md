---
title: Configurações comuns do formato binário por linha
---

{/* Nota: este trecho é reutilizado em qualquer arquivo que o importe */ }

As configurações a seguir são comuns a todos os formatos do tipo `RowBinary`.

| Configuração                                                                                                                           | Descrição                                                                                                                                                                                                                                        | Padrão  |
| -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------- |
| [`format_binary_max_string_size`](/pt-BR/operations/settings/settings-formats.md/#format_binary_max_string_size)                             | O tamanho máximo permitido para String no formato RowBinary.                                                                                                                                                                                     | `1GiB`  |
| [`output_format_binary_encode_types_in_binary_format`](/pt-BR/operations/settings/formats#input_format_binary_decode_types_in_binary_format) | Permite gravar tipos no cabeçalho usando [`binary encoding`](/pt-BR/sql-reference/data-types/data-types-binary-encoding.md) em vez de strings com nomes de tipos no formato de saída [`RowBinaryWithNamesAndTypes`](../RowBinaryWithNamesAndTypes.md). | `false` |
| [`input_format_binary_decode_types_in_binary_format`](/pt-BR/operations/settings/formats#input_format_binary_decode_types_in_binary_format)  | Permite ler tipos no cabeçalho usando [`binary encoding`](/pt-BR/sql-reference/data-types/data-types-binary-encoding.md) em vez de strings com nomes de tipos no formato de entrada [`RowBinaryWithNamesAndTypes`](../RowBinaryWithNamesAndTypes.md).  | `false` |
| [`output_format_binary_write_json_as_string`](/pt-BR/operations/settings/settings-formats.md/#output_format_binary_write_json_as_string)     | Permite gravar valores do tipo de dado [`JSON`](/pt-BR/sql-reference/data-types/newjson.md) como valores `JSON` de [String](/pt-BR/sql-reference/data-types/string.md) no formato de saída [`RowBinary`](../RowBinary.md).                                   | `false` |
| [`input_format_binary_read_json_as_string`](/pt-BR/operations/settings/settings-formats.md/#input_format_binary_read_json_as_string)         | Permite ler valores do tipo de dado [`JSON`](/pt-BR/sql-reference/data-types/newjson.md) como valores `JSON` de [String](/pt-BR/sql-reference/data-types/string.md) no formato de entrada [`RowBinary`](../RowBinary.md).                                    | `false` |
