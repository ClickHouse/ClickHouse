---
title: Configurações comuns do formato Pretty
---

{/* Observação: Este arquivo é usado como um trecho reutilizável em todos os arquivos que o importam */ }

As configurações a seguir são comuns a todos os formatos `Pretty`:

| Configuração                                                                                                                                                       | Descrição                                                                                                                                                                                                                                | Padrão  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| [`output_format_pretty_max_rows`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_max_rows)                                                         | Limite de linhas para formatos Pretty.                                                                                                                                                                                                   | `10000` |
| [`output_format_pretty_max_column_pad_width`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_max_column_pad_width)                                 | Largura máxima de preenchimento de todos os valores de uma coluna em formatos Pretty.                                                                                                                                                    | `250`   |
| [`output_format_pretty_max_value_width`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_max_value_width)                                           | Largura máxima do valor a ser exibido em formatos Pretty. Se for maior, será truncado.                                                                                                                                                   | `10000` |
| [`output_format_pretty_color`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_color)                                                               | Usa sequências de escape ANSI para aplicar cores em formatos Pretty.                                                                                                                                                                     | `true`  |
| [`output_format_pretty_grid_charset`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_grid_charset)                                                 | Conjunto de caracteres para imprimir as bordas da grade. Conjuntos de caracteres disponíveis: ASCII, UTF-8.                                                                                                                              | `UTF-8` |
| [`output_format_pretty_row_numbers`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_row_numbers)                                                   | Adiciona números de linha antes de cada linha na saída do formato Pretty.                                                                                                                                                                | `true`  |
| [`output_format_pretty_display_footer_column_names`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_display_footer_column_names)                   | Exibe os nomes das colunas no rodapé se a tabela contiver muitas linhas.                                                                                                                                                                 | `true`  |
| [`output_format_pretty_display_footer_column_names_min_rows`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_display_footer_column_names_min_rows) | Define o número mínimo de linhas para que um rodapé seja exibido se [`output_format_pretty_display_footer_column_names`](/pt-BR/operations/settings/settings-formats.md/#output_format_pretty_display_footer_column_names) estiver habilitada. | `50`    |
