O ClickHouse oferece vários clientes e interfaces nativos que permitem a conexão com o ClickHouse.

Para mais informações, consulte as páginas abaixo:

| Seção                                                | Resumo                                                                                                  |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [clickhousectl](/pt-BR/interfaces/cli)                     | A CLI do ClickHouse: local e Cloud.                                                                     |
| [ClickHouse Client](/pt-BR/interfaces/client)              | Cliente nativo de linha de comando com suporte a opções de linha de comando e arquivos de configuração. |
| [Drivers &amp; Interfaces](/pt-BR/interfaces/overview)     | Várias interfaces de rede, bibliotecas e interfaces visuais.                                            |
| [SQL Console](/pt-BR/integrations/sql-clients/sql-console) | Uma forma rápida e fácil de interagir com seus dados no ClickHouse Cloud.                               |
| [Web SQL UI (Play)](/pt-BR/interfaces/web-sql)             | A interface SQL integrada ao navegador, disponibilizada pelo ClickHouse em `/play`.                     |
