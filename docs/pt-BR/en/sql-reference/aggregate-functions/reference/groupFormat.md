Formata as linhas de cada grupo usando um formato de saída e retorna os dados formatados como uma string. É semelhante a `formatRow`, mas opera sobre o grupo inteiro e pode usar formatos baseados em blocos.

:::warning
Todas as linhas de cada grupo são acumuladas na memória antes que a string formatada seja produzida. Em grupos com um número muito grande de linhas, isso pode consumir uma quantidade significativa de memória. Considere usar `LIMIT` em subconsultas ou dividir grupos grandes para manter o uso de memória sob controle.
:::

<div id="syntax">
  ## Sintaxe
</div>

```sql
groupFormat(format)(x, y, ...)
```

<div id="parameters">
  ## Parâmetros
</div>

* `format` — Nome do formato de saída, como `JSONEachRow`, `CSV`, `TabSeparated`.

<div id="arguments">
  ## Argumentos
</div>

* `x, y, ...` — Expressões a serem formatadas como linhas. Pelo menos um argumento é obrigatório.

<div id="returned-value">
  ## Valor retornado
</div>

* Uma [String](../../data-types/string.md) que contém a saída formatada para o grupo.

:::note
Os nomes das colunas na saída formatada são gerados como `c1`, `c2`, ... na ordem dos argumentos.

A ordem exata das linhas formatadas não é garantida.

As configurações de formato da consulta (por exemplo, `format_csv_delimiter` ou `output_format_json_quote_64bit_integers`) são capturadas quando a função de agregação é inicializada e usadas para gerar a saída. A configuração `output_format_write_statistics` é sempre desativada forçadamente, portanto a string formatada nunca contém uma seção de estatísticas.
:::

<div id="null-handling">
  ## Tratamento de NULL
</div>

Assim como `groupArray` e `groupConcat`, `groupFormat` ignora uma linha quando qualquer um dos seus argumentos é `NULL`; essas linhas não aparecem na saída formatada. Quando um argumento pode ser nulo, o tipo do resultado é `Nullable(String)`, e um grupo em que todas as linhas são ignoradas — assim como um argumento `NULL` literal sem tipo, do tipo `Nullable(Nothing)` — retorna `NULL` por meio do combinador genérico `Null`.

```sql
SELECT groupFormat('JSONEachRow')(if(number = 0, NULL, number))
FROM numbers(3);
-- {"c1":1}
-- {"c1":2}
```

<div id="examples">
  ## Exemplos
</div>

<div id="example-json">
  ### Uso básico com JSONEachRow
</div>

```sql
SELECT groupFormat('JSONEachRow')(number, toString(number))
FROM numbers(3);
```

Resultado:

```text
{"c1":0,"c2":"0"}
{"c1":1,"c2":"1"}
{"c1":2,"c2":"2"}
```
