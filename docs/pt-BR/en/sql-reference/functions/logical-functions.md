As funções abaixo executam operações lógicas em argumentos de quaisquer tipos numéricos.
Elas retornam `0` ou `1` como [`UInt8`](../data-types/int-uint.md) ou, em alguns casos, `NULL`.

Zero como argumento é considerado `false`, e valores diferentes de zero são considerados `true`.
