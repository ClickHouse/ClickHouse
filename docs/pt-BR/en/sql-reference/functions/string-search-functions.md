Todas as funções nesta seção fazem busca com diferenciação entre maiúsculas e minúsculas por padrão. A busca sem diferenciação entre maiúsculas e minúsculas geralmente é fornecida por variantes de função separadas.

:::note
A busca sem diferenciação entre maiúsculas e minúsculas segue as regras de conversão entre minúsculas e maiúsculas da língua inglesa. Por exemplo, o `i` maiúsculo na língua inglesa é
`I`, enquanto na língua turca é `İ` — os resultados para idiomas diferentes do inglês podem ser inesperados.
:::

As funções nesta seção também assumem que a string pesquisada (referida nesta seção como `haystack`) e a string de busca (referida nesta seção como `needle`) são texto codificado em byte único. Se essa suposição for
violada, nenhuma exceção é gerada e os resultados são indefinidos. A busca com strings codificadas em UTF-8 geralmente é fornecida por variantes de função
separadas. Da mesma forma, se uma variante de função UTF-8 for usada e as strings de entrada não forem texto codificado em UTF-8, nenhuma exceção é gerada e os
resultados são indefinidos. Observe que nenhuma normalização Unicode automática é realizada; no entanto, você pode usar as
funções [normalizeUTF8*()](/pt-BR/sql-reference/functions/string-functions#normalizeUTF8NFC) para isso.

[Funções gerais de strings](string-functions.md) e [funções para substituição em strings](string-replace-functions.md) são descritas separadamente.
