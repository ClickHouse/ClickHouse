Essas funções implementam a criptografia e a descriptografia de dados com o algoritmo AES (Advanced Encryption Standard).

O comprimento da chave depende do modo de criptografia: `16`, `24` e `32` bytes para os modos `-128-`, `-196-` e `-256-`, respectivamente.

O comprimento do vetor de inicialização é sempre de 16 bytes (bytes excedentes a 16 são ignorados).
