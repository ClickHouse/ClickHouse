Todas as funções nesta seção aceitam zero ou um argumento. O único uso do argumento (se fornecido) é evitar a [eliminação de subexpressões
comuns](/pt-BR/sql-reference/functions/overview#common-subexpression-elimination), de modo que duas execuções diferentes da mesma função aleatória dentro de uma linha
retornem valores aleatórios diferentes.

Conteúdo relacionado

* Guia: [Gerando dados aleatórios no ClickHouse](/pt-BR/guides/generating-test-data)
* Blog: [Gerando dados aleatórios no ClickHouse](https://clickhouse.com/blog/generating-random-test-distribution-data-for-clickhouse)

:::note
Os números aleatórios são gerados por algoritmos não criptográficos.
:::
