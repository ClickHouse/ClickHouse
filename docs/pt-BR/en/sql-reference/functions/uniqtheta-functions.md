As funções uniqTheta trabalham com dois objetos uniqThetaSketch para executar cálculos de operações de conjunto, como ∪ / ∩ / × (union/intersect/not), retornando um novo objeto uniqThetaSketch que contém o resultado.

Um objeto uniqThetaSketch deve ser construído pela função de agregação uniqTheta com -State.

UniqThetaSketch é uma estrutura de dados que armazena conjuntos aproximados de valores.
Para mais informações, consulte: [Theta Sketch Framework](https://datasketches.apache.org/docs/Theta/ThetaSketches.html#theta-sketch-framework).

<div id="uniqthetaunion">
  ## uniqThetaUnion
</div>

Dois objetos uniqThetaSketch para calcular a união (operação de conjunto ∪); o resultado é um novo uniqThetaSketch.

```sql
uniqThetaUnion(uniqThetaSketch,uniqThetaSketch)
```

**Argumentos**

* `uniqThetaSketch` – objeto uniqThetaSketch.

**Exemplo**

```sql
SELECT finalizeAggregation(uniqThetaUnion(a, b)) AS a_union_b, finalizeAggregation(a) AS a_cardinality, finalizeAggregation(b) AS b_cardinality
FROM
(SELECT arrayReduce('uniqThetaState',[1,2]) AS a, arrayReduce('uniqThetaState',[2,3,4]) AS b );
```

```text
┌─a_union_b─┬─a_cardinality─┬─b_cardinality─┐
│         4 │             2 │             3 │
└───────────┴───────────────┴───────────────┘
```

<div id="uniqthetaintersect">
  ## uniqThetaIntersect
</div>

Dois objetos `uniqThetaSketch` para calcular a interseção (operação de conjuntos ∩); o resultado é um novo `uniqThetaSketch`.

```sql
uniqThetaIntersect(uniqThetaSketch,uniqThetaSketch)
```

**Argumentos**

* `uniqThetaSketch` – objeto uniqThetaSketch.

**Exemplo**

```sql
SELECT finalizeAggregation(uniqThetaIntersect(a, b)) AS a_intersect_b, finalizeAggregation(a) AS a_cardinality, finalizeAggregation(b) AS b_cardinality
FROM
(SELECT arrayReduce('uniqThetaState',[1,2]) AS a, arrayReduce('uniqThetaState',[2,3,4]) AS b );
```

```text
┌─a_intersect_b─┬─a_cardinality─┬─b_cardinality─┐
│             1 │             2 │             3 │
└───────────────┴───────────────┴───────────────┘
```

<div id="uniqthetanot">
  ## uniqThetaNot
</div>

Dois objetos uniqThetaSketch são usados para realizar o cálculo a&#95;not&#95;b (operação de conjunto ×); o resultado é um novo uniqThetaSketch.

```sql
uniqThetaNot(uniqThetaSketch,uniqThetaSketch)
```

**Argumentos**

* `uniqThetaSketch` – objeto uniqThetaSketch.

**Exemplo**

```sql
SELECT finalizeAggregation(uniqThetaNot(a, b)) AS a_not_b, finalizeAggregation(a) AS a_cardinality, finalizeAggregation(b) AS b_cardinality
FROM
(SELECT arrayReduce('uniqThetaState',[2,3,4]) AS a, arrayReduce('uniqThetaState',[1,2]) AS b );
```

```text
┌─a_not_b─┬─a_cardinality─┬─b_cardinality─┐
│       2 │             3 │             2 │
└─────────┴───────────────┴───────────────┘
```
