As funções de bit funcionam com qualquer par de tipos entre `UInt8`, `UInt16`, `UInt32`, `UInt64`, `Int8`, `Int16`, `Int32`, `Int64`, `Float32` ou `Float64`. Algumas funções também oferecem suporte aos tipos `String` e `FixedString`.

O tipo do resultado é um inteiro com quantidade de bits igual ao maior número de bits entre seus argumentos. Se pelo menos um dos argumentos tiver sinal, o resultado será um número com sinal. Se um argumento for um número de ponto flutuante, ele será convertido para Int64.
