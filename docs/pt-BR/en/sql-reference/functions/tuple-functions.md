<div id="untuple">
  ## untuple
</div>

Realiza a substituição sintática de elementos de [tupla](/pt-BR/sql-reference/data-types/tuple) no ponto da chamada.

Os nomes das colunas do resultado são específicos da implementação e estão sujeitos a mudanças. Não considere nomes de colunas específicos após `untuple`.

**Sintaxe**

```sql
untuple(x)
```

Você pode usar a expressão `EXCEPT` para excluir colunas do resultado da consulta.

**Argumentos**

* `x` — Uma função `tuple`, coluna ou tupla de elementos. [Tupla](../data-types/tuple.md).

**Valor retornado**

* Nenhum.

**Exemplos**

Tabela de entrada:

```text
┌─key─┬─v1─┬─v2─┬─v3─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 20 │ 40 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 65 │ 70 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 30 │ 20 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 12 │  7 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 50 │ 70 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴────┴────┴───────────┘
```

Exemplo de uso de uma coluna do tipo `Tuple` como parâmetro da função `untuple`:

```sql title="Query"
SELECT untuple(v6) FROM kv;
```

```text title="Response"
┌─_ut_1─┬─_ut_2─┐
│    33 │ ab    │
│    44 │ cd    │
│    55 │ ef    │
│    66 │ gh    │
│    77 │ kl    │
└───────┴───────┘
```

Exemplo de uso da expressão `EXCEPT`:

```sql title="Query"
SELECT untuple((* EXCEPT (v2, v3),)) FROM kv;
```

```text title="Response"
┌─key─┬─v1─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴───────────┘
```
