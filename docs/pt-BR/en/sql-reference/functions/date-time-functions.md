A maioria das funções nesta seção aceita um argumento opcional de fuso horário, por exemplo, `Europe/Amsterdam`. Nesse caso, o fuso horário será o especificado em vez do fuso local (padrão).

**Exemplo**

```sql
SELECT
    toDateTime('2016-06-15 23:00:00') AS time,
    toDate(time) AS date_local,
    toDate(time, 'Asia/Yekaterinburg') AS date_yekat,
    toString(time, 'US/Samoa') AS time_samoa
```

```text
┌────────────────time─┬─date_local─┬─date_yekat─┬─time_samoa──────────┐
│ 2016-06-15 23:00:00 │ 2016-06-15 │ 2016-06-16 │ 2016-06-15 09:00:00 │
└─────────────────────┴────────────┴────────────┴─────────────────────┘
```

:::note
Por compatibilidade com o padrão SQL, as seguintes funções — `NOW`, `CURRENT_TIMESTAMP`, `LOCALTIME`, `LOCALTIMESTAMP`, `TODAY` e `CURRENT_DATE` — podem ser usadas sem parênteses.
:::
