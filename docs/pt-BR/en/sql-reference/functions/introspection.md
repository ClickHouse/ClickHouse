Você pode usar as funções descritas neste capítulo para fazer introspecção de [ELF](https://en.wikipedia.org/wiki/Executable_and_Linkable_Format) e [DWARF](https://en.wikipedia.org/wiki/DWARF) para profiling de consultas.

:::note
Essas funções são lentas e podem trazer implicações de segurança.
:::

Para o funcionamento adequado das funções de introspecção:

* Instale o pacote `clickhouse-common-static-dbg`.

* Defina a configuração [allow&#95;introspection&#95;functions](../../operations/settings/settings.md#allow_introspection_functions) como 1.

  Por motivos de segurança, as funções de introspecção ficam desabilitadas por padrão.

O ClickHouse salva relatórios do profiler na tabela de sistema [trace&#95;log](/pt-BR/operations/system-tables/trace_log). Certifique-se de que a tabela e o profiler estejam configurados corretamente.
