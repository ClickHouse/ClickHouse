<div id="types-of-functions">
  ## Tipos de funções JSON
</div>

Há dois conjuntos de funções para fazer o parsing de JSON:

* [`simpleJSON*` (`visitParam*`)](#simplejson-visitparam-functions), criado para fazer o parsing de um subconjunto limitado de JSON com extrema rapidez.
* [`JSONExtract*`](#jsonextract-functions), criado para fazer o parsing de JSON comum.

<div id="simplejson-visitparam-functions">
  ### funções simpleJSON (visitParam)
</div>

O ClickHouse tem funções especiais para trabalhar com JSON simplificado. Todas essas funções JSON se baseiam em premissas rígidas sobre o que o JSON pode ser. Elas tentam fazer o mínimo possível para realizar a tarefa o mais rápido possível.

As seguintes premissas são consideradas:

1. O nome do campo (argumento da função) deve ser uma constante.
2. O nome do campo é codificado de forma canônica no JSON. Por exemplo: `simpleJSONHas('{"abc":"def"}', 'abc') = 1`, mas `simpleJSONHas('{"\\u0061\\u0062\\u0063":"def"}', 'abc') = 0`
3. Os campos são procurados em qualquer nível de aninhamento, sem distinção. Se houver vários campos correspondentes, a primeira ocorrência será usada.
4. O JSON não contém caracteres de espaço fora de literais String.

<div id="jsonextract-functions">
  ### Funções JSONExtract
</div>

Essas funções são baseadas em [simdjson](https://github.com/lemire/simdjson) e foram projetadas para necessidades mais complexas de processamento de JSON.

<div id="case-insensitive-jsonextract-functions">
  ### Funções JSONExtract sem distinção entre maiúsculas e minúsculas
</div>

Essas funções fazem correspondência de chaves ASCII sem distinção entre maiúsculas e minúsculas ao extrair valores de objetos JSON.
Elas funcionam de forma idêntica às versões com distinção entre maiúsculas e minúsculas, exceto pelo fato de que as chaves do objeto são correspondidas sem considerar maiúsculas e minúsculas.
Quando várias chaves correspondem com diferentes combinações de maiúsculas e minúsculas, a primeira correspondência é retornada.

:::note
Essas funções podem ter desempenho inferior ao das versões com distinção entre maiúsculas e minúsculas, portanto, use as funções JSONExtract regulares, se possível.
:::
