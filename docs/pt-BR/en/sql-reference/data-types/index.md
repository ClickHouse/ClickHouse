Esta seção descreve os tipos de dados compatíveis com o ClickHouse, por exemplo [inteiros](int-uint.md), [números de ponto flutuante](float.md) e [strings](string.md).

A tabela de sistema [system.data&#95;type&#95;families](/pt-BR/operations/system-tables/data_type_families) fornece uma
visão geral de todos os tipos de dados disponíveis.
Ela também mostra se um tipo de dado é um alias de outro e se seu nome diferencia maiúsculas de minúsculas (por exemplo, `bool` vs. `BOOL`).
