Os usuários interagem com o ClickHouse por meio de instruções SQL. O ClickHouse oferece suporte a instruções SQL comuns, como [SELECT](select/index.md) e [CREATE](create/index.md), mas também fornece instruções especializadas, como [KILL](kill.md) e [OPTIMIZE](optimize.md).
