---
title: Snippet de Dicionário no Cloud
---

:::tip
Se você estiver usando um dicionário com o ClickHouse Cloud, use a opção de consulta DDL para criar seus dicionários e crie o dicionário como usuário `default`.
Além disso, verifique a lista de fontes de dicionário compatíveis no [guia de Compatibilidade do Cloud](/pt-BR/whats-new/cloud-compatibility).
:::
