Há três categorias principais de motores de tabela:

* [família de motores MergeTree](../../../engines/table-engines/mergetree-family/index.md) para uso principal em produção.
* [família de motores Log](../../../engines/table-engines/log-family/index.md) para pequenos volumes de dados temporários.
* [Motores de tabela para integrações](../../../engines/table-engines/integrations/index.md).

Os demais motores têm finalidades específicas e ainda não estão agrupados em famílias; por isso, foram colocados nesta categoria &quot;especial&quot;.
