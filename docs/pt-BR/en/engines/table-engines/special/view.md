Usado para implementar views (para mais informações, consulte a consulta `CREATE VIEW`). Ele não armazena dados, apenas a consulta `SELECT` especificada. Ao ler de uma tabela, ele executa essa consulta (e remove dela todas as colunas desnecessárias).
