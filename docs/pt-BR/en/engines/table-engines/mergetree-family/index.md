Os motores de tabela da família MergeTree são o núcleo dos recursos de armazenamento de dados do ClickHouse. Eles oferecem a maior parte dos recursos de resiliência e recuperação de dados em alto desempenho: armazenamento colunar, particionamento personalizado, índice primário esparso, índices secundários para salto de dados etc.

O motor de tabela base [MergeTree](../../../engines/table-engines/mergetree-family/mergetree.md) pode ser considerado o motor de tabela padrão para instâncias de ClickHouse de nó único, porque é versátil e prático para uma ampla variedade de casos de uso.

Para uso em produção, [ReplicatedMergeTree](../../../engines/table-engines/mergetree-family/replication.md) é a melhor opção, porque adiciona alta disponibilidade a todos os recursos do motor MergeTree regular. Um benefício extra é a desduplicação automática de dados durante a ingestão de dados, de modo que o software pode tentar novamente com segurança se ocorrer algum problema de rede durante uma inserção.

Todos os outros motores da família MergeTree adicionam funcionalidades extras para casos de uso específicos. Normalmente, isso é implementado como manipulação adicional de dados em segundo plano.

A principal desvantagem dos motores MergeTree é que eles são relativamente pesados. Portanto, o normal é não ter muitos deles. Se você precisar de muitas tabelas pequenas, por exemplo, para dados temporários, considere a [família de motores Log](../../../engines/table-engines/log-family/index.md).
