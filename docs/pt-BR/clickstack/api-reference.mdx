O ClickStack disponibiliza uma API REST para gerenciar dashboards, alertas e fontes de dados de forma programática.

## Documentação de referência da API {#api-docs}

Para o ClickStack Open Source, a especificação completa da API é mantida no [repositório da Interface do ClickStack](https://github.com/hyperdxio/hyperdx) e pode ser consultada de forma interativa ou baixada como uma especificação OpenAPI:

* [Referência interativa da API](https://www.clickhouse.com/docs/clickstack/api-reference)
* [Baixar especificação OpenAPI (JSON)](https://raw.githubusercontent.com/hyperdxio/hyperdx/refs/heads/main/packages/api/openapi.json)

Os seguintes endpoints estão disponíveis:

| Recurso        | Operações                                             |
| -------------- | ----------------------------------------------------- |
| **Dashboards** | Criar, listar, buscar, atualizar e excluir dashboards |
| **Alertas**     | Criar, listar, buscar, atualizar e excluir alertas    |
| **Gráficos**     | Consultar dados de séries temporais (somente POST)    |
| **Fontes de dados**    | Listar fontes de dados                                |
| **Webhooks**   | Listar webhooks                                       |

## Autenticação {#authentication}

O ClickStack Open Source usa um **Bearer token** para autenticação por meio de uma **Personal API Access Key**.

Para obter uma API key:

1. Abra a Interface do ClickStack na URL do seu ClickStack (por exemplo, http://localhost:8080)
2. Crie uma conta ou faça login, se necessário
3. Vá para **Team Settings → API Keys**
4. Copie sua **Personal API Access Key**

    ![API key do ClickStack](/images/clickstack/api-key-personal.webp)

</div>

<Note>
  Isso é diferente da **API key de ingestão** encontrada em Team Settings, que é usada para autenticar dados de telemetria enviados ao collector do OpenTelemetry.
</Note>

O servidor da API é executado na porta `8000` por padrão (separada da UI na porta `8080`). Ao usar a Docker image all-in-one, certifique-se de mapear essa porta explicitamente:

```bash
docker run -p 8080:8080 -p 8000:8000 -p 4317:4317 -p 4318:4318 clickhouse/clickstack-all-in-one
```

Inclua a chave no cabeçalho `Authorization`:

```bash
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  http://localhost:8000/api/v2/dashboards
```

## URL base e formato da solicitação {#base-url}

Todas as solicitações da API do Open Source ClickStack são enviadas para o servidor de API da Interface do ClickStack na porta `8000`:

```bash
http://<YOUR_HYPERDX_HOST>:8000/api/v2/<resource>
```

Por exemplo, em uma implantação local padrão:

```bash
http://localhost:8000/api/v2/dashboards
```

### Exemplo: Listar dashboards {#list-dashboards-oss}

```bash
curl -H "Authorization: Bearer <YOUR_API_KEY>" \
  http://localhost:8000/api/v2/dashboards
```

### Exemplo: Criar um alerta {#create-alert-oss}

```bash
curl -X POST \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "dashboardId": "<DASHBOARD_ID>",
    "tileId": "<TILE_ID>",
    "threshold": 100,
    "interval": "1h",
    "source": "tile",
    "thresholdType": "above",
    "channel": {
      "type": "webhook",
      "webhookId": "<WEBHOOK_ID>"
    },
    "name": "Error Spike Alert",
    "message": "Error rate exceeded 100 in the last hour"
  }' \
  http://localhost:8000/api/v2/alerts
```

### Exemplo: Consultar dados de séries temporais de gráficos {#query-series-data}

```bash
curl -X POST \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "startTime": 1647014400000,
    "endTime": 1647100800000,
    "granularity": "1h",
    "series": [
      {
        "sourceId": "<SOURCE_ID>",
        "aggFn": "count",
        "where": "SeverityText:error",
        "groupBy": []
      }
    ]
  }' \
  http://localhost:8000/api/v2/charts/series
```
