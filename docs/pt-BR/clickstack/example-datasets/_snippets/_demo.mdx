### Arquitetura da demonstração {#demo-architecture}

A demonstração é composta por microsserviços escritos em diferentes linguagens de programação que se comunicam entre si via gRPC e HTTP e por um gerador de carga que usa o Locust para simular tráfego de usuários. O código-fonte original desta demonstração foi modificado para usar a [instrumentação do ClickStack](/pt-BR/clickstack/ingesting-data/sdks/index).
