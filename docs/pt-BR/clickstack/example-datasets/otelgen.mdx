O [`otelgen`](https://github.com/krzko/otelgen) é uma pequena CLI em Go que gera logs, traces e métricas OTLP sintéticos. Use-o para confirmar que um Coletor OpenTelemetry do ClickStack existente está aceitando dados e que os eventos aparecem na UI do ClickStack.

Este guia pressupõe que o collector já está em execução com endpoints OTLP em `4317` (gRPC) e `4318` (HTTP).

<Steps>
  <Step title="Pré-requisitos" id="prerequisites-oss">
    Este guia pressupõe que você iniciou o Open Source ClickStack usando as [instruções da imagem all-in-one](/pt-BR/clickstack/getting-started/oss) e que os endpoints OTLP (`4317` gRPC e `4318` HTTP) estejam acessíveis. Você também precisará da API key de ingestão na UI do ClickStack, em `Team Settings > API Keys`.
  </Step>

  <Step title="Instalar o otelgen" id="install-otelgen-oss">
    Instale com Homebrew:

    ```shell
    brew install krzko/tap/otelgen
    ```

    Ou instale com Go:

    ```shell
    go install github.com/krzko/otelgen@latest
    ```
  </Step>

  <Step title="Definir variáveis de ambiente" id="set-env-vars-oss">
    Exporte o endpoint do collector e a API key de ingestão:

    ```shell
    export OTEL_ENDPOINT=localhost:4317
    export CLICKSTACK_API_KEY=<your_ingestion_api_key>
    ```
  </Step>

  <Step title="Gerar traces" id="generate-traces-oss">
    Envie uma pequena sequência de traces com vários spans:

    ```shell
    otelgen --otel-exporter-otlp-endpoint ${OTEL_ENDPOINT} \
      --header "authorization=${CLICKSTACK_API_KEY}" \
      --protocol grpc --insecure \
      --rate 2 --duration 10 \
      traces multi
    ```

    `--rate` é o número de traces por segundo, e `--duration` é a duração da execução em segundos. `--insecure` habilita gRPC em plaintext no collector local.
  </Step>

  <Step title="Gerar logs" id="generate-logs-oss">
    ```shell
    otelgen --otel-exporter-otlp-endpoint ${OTEL_ENDPOINT} \
      --header "authorization=${CLICKSTACK_API_KEY}" \
      --protocol grpc --insecure \
      --rate 2 --duration 10 \
      logs multi
    ```
  </Step>

  <Step title="Gerar métricas" id="generate-metrics-oss">
    Os subcomandos de métricas não respeitam `--duration`. Execute o comando e pressione `Ctrl+C` após alguns segundos para interrompê-lo.

    ```shell
    otelgen --otel-exporter-otlp-endpoint ${OTEL_ENDPOINT} \
      --header "authorization=${CLICKSTACK_API_KEY}" \
      --protocol grpc --insecure \
      --rate 2 \
      metrics sum
    ```

    O `otelgen` também oferece suporte aos subcomandos `gauge`, `histogram`, `up-down-counter` e `exponential-histogram` em `metrics`.
  </Step>

  <Step title="Verificar no ClickStack" id="verify-oss">
    Acesse [http://localhost:8080](http://localhost:8080) para abrir a UI do ClickStack. Na visualização `Search`, alterne a source entre `Logs` e `Traces` para confirmar os novos eventos. Defina o intervalo de tempo como `Last 15 minutes`. Abra o `Chart Explorer`, selecione `Metrics` e crie um gráfico com um dos nomes de métrica gerados pelo `otelgen` (por exemplo, `otelgen.metrics.sum`) para verificar a ingestão de métricas.
  </Step>
</Steps>
