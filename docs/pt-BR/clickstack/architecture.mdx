A arquitetura do ClickStack Open Source se baseia em três componentes principais: **ClickHouse**, **Interface do ClickStack** e um **Coletor OpenTelemetry (OTel)**. Uma instância do **MongoDB** armazena o estado da aplicação. Juntos, eles formam uma stack de observabilidade de código aberto e alto desempenho, otimizada para logs, métricas e rastros.

### ClickHouse: o mecanismo de banco de dados {#clickhouse}

No centro do ClickStack está o ClickHouse, um banco de dados orientado a colunas projetado para analytics em tempo real em escala. Ele viabiliza a ingestão e a consulta de dados de observabilidade, permitindo:

* Busca em menos de um segundo em terabytes de eventos
* Ingestão de bilhões de registros de alta cardinalidade por dia
* Altas taxas de compressão de pelo menos 10x em dados de observabilidade
* Suporte nativo a dados JSON semiestruturados, permitindo a evolução dinâmica do schema
* Um poderoso mecanismo SQL com centenas de funções analíticas integradas

O ClickHouse trata os dados de observabilidade como eventos wide, permitindo correlações profundas entre logs, métricas e rastros em uma única estrutura unificada.

### Coletor OpenTelemetry: ingestão de dados {#open-telemetry-collector}

O ClickStack inclui um coletor OpenTelemetry (OTel) pré-configurado para fazer a ingestão de telemetria de forma aberta e padronizada. Você pode enviar dados usando o protocolo OTLP por meio de:

* gRPC (porta `4317`)
* HTTP (porta `4318`)

O coletor exporta a telemetria para o ClickHouse em lotes eficientes. Ele oferece suporte a esquemas de tabela otimizados por fonte de dados, garantindo desempenho escalável em todos os tipos de sinal.

### Interface do ClickStack: a interface {#hyperdx-ui}

A Interface do ClickStack é a interface do usuário do ClickStack. Ela oferece:

* Busca em linguagem natural e no estilo Lucene
* Live tailing para debugging em tempo real
* Visualizações unificadas de logs, métricas e rastros
* Session replay para observabilidade de frontend
* Criação de dashboards e configuração de alertas
* Interface de consulta SQL para análises avançadas

Projetada especificamente para o ClickHouse, a Interface do ClickStack combina buscas poderosas com fluxos de trabalho intuitivos, permitindo que você identifique anomalias, investigue problemas e obtenha insights rapidamente.

### MongoDB: estado da aplicação {#mongo}

O ClickStack usa o MongoDB para armazenar o estado no nível da aplicação, incluindo:

* Dashboards
* Alertas
* Perfis de usuário
* Visualizações salvas

Separar o estado dos dados de eventos garante desempenho e escalabilidade, além de simplificar o backup e a configuração.

Essa arquitetura modular permite que o ClickStack ofereça uma plataforma de observabilidade pronta para uso, rápida, flexível e de código aberto.
