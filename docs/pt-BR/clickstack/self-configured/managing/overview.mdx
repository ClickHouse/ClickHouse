## Conceitos principais do ClickHouse {#core-concepts}

A maioria das tarefas de gerenciamento exige familiaridade com o banco de dados ClickHouse subjacente. Recomendamos revisar os conceitos principais do ClickHouse descritos abaixo antes de realizar operações administrativas ou relacionadas a desempenho.

| Conceito                            | Descrição                                                                                                                                                                                                        |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tabelas**                         | Como as fontes de dados são mapeadas para as tabelas subjacentes do ClickHouse. As tabelas do ClickHouse usam principalmente o motor [`MergeTree`](/pt-BR/reference/engines/table-engines/mergetree-family/mergetree). |
| **Partes**                          | Como os dados são gravados em partes imutáveis e mesclados ao longo do tempo.                                                                                                                                    |
| **Partições**                       | Agrupamentos lógicos de partes de tabela que simplificam o gerenciamento de dados, a execução de consultas e a otimização.                                                                                       |
| **Mesclagens**                      | O processo em segundo plano que combina partes para reduzir o número de partes consultadas e manter o desempenho.                                                                                                |
| **Grânulos**                        | A menor unidade de dados lida e descartada durante a execução de consultas.                                                                                                                                      |
| **Chaves primárias (de ordenação)** | Como a chave `ORDER BY` define a disposição dos dados em disco, a compressão e o comportamento de poda nas consultas.                                                                                            |

Esses conceitos são fundamentais para o desempenho do ClickHouse e ajudarão você a tomar decisões administrativas bem fundamentadas ao gerenciar o Self-managed ClickHouse Observability.
