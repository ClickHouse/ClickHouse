O ClickHouse Observability Collector usa o [exportador do ClickHouse](https://github.com/open-telemetry/opentelemetry-collector-contrib/blob/main/exporter/clickhouseexporter/README.md) para criar tabelas no ClickHouse e inserir dados.

As tabelas a seguir são criadas para cada tipo de dado no banco de dados `default`. Você pode alterar esse banco de dados de destino modificando a variável de ambiente `HYPERDX_OTEL_EXPORTER_CLICKHOUSE_DATABASE` na imagem que hospeda o coletor.
