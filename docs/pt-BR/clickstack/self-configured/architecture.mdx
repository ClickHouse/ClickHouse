O ClickHouse Observability — Autogerenciado é executado inteiramente no **ClickHouse Cloud** e oferece um backend de observabilidade totalmente gerenciado, preservando o mesmo modelo de dados e a mesma experiência de usuário do ClickStack.

Nesse modelo, o **ClickHouse e a Interface do ClickStack** são hospedados, operados e protegidos pelo ClickHouse Cloud. Cabe aos usuários apenas executar um **coletor OpenTelemetry (OTel)** para enviar dados de telemetria ao serviço gerenciado.

### ClickHouse Cloud: o motor {#clickhouse-cloud}

No centro do ClickHouse Observability — autogerenciado está o ClickHouse Cloud, uma versão serverless do ClickHouse, um banco de dados orientado a colunas projetado para analytics em tempo real em grande escala. Ele viabiliza a ingestão e a consulta de dados de observabilidade, oferecendo:

* Busca com latência inferior a um segundo em terabytes de eventos
* Ingestão de bilhões de registros high-cardinality por dia
* Altas taxas de compressão, de pelo menos 10x, em dados de observabilidade
* Suporte nativo a dados JSON semiestruturados, permitindo a evolução dinâmica do esquema
* Um poderoso motor SQL com centenas de funções analíticas integradas

O ClickHouse Cloud trata dados de observabilidade como eventos amplos, permitindo uma correlação profunda entre logs, métricas e rastros em uma única estrutura unificada.

Em relação ao ClickHouse de Código Aberto, ele oferece diversos benefícios adicionais para observabilidade:

* Escalonamento automático da capacidade computacional, independente do armazenamento
* Retenção de baixo custo e praticamente ilimitada, baseada em armazenamento de objetos
* A capacidade de [isolar de forma independente cargas de trabalho de leitura e escrita](/pt-BR/clickstack/self-configured/managing/isolating-read-write) com Warehouses.
* Autenticação integrada
* Backups automatizados
* Recursos de segurança e conformidade
* Upgrades sem interrupções

### Coletor OpenTelemetry: ingestão de dados {#open-telemetry-collector-managed}

O ClickHouse Observability — autogerenciado inclui um coletor OpenTelemetry (OTel) pré-configurado para a ingestão de telemetria de forma aberta e padronizada. Você pode enviar dados usando o protocolo OTLP via:

* gRPC (porta `4317`)
* HTTP (porta `4318`)

O coletor exporta a telemetria para o ClickHouse Cloud em lotes eficientes. Ele oferece suporte a esquemas de tabela otimizados para cada fonte de dados, garantindo desempenho escalável em todos os tipos de sinal.

**Este componente da arquitetura é gerenciado pelo usuário**

### Interface do ClickStack: a interface {#hyperdx}

A Interface do ClickStack é a interface de usuário do ClickStack. Ela oferece:

* Busca em linguagem natural e no estilo Lucene
* Acompanhamento ao vivo (live tailing) para depuração em real-time
* Visualizações unificadas de logs, métricas e rastros
* Reprodução de sessão para observabilidade de frontend
* Criação de dashboards e configuração de alertas
* Interface de consultas SQL para análises avançadas

Projetada especificamente para o ClickHouse, a Interface do ClickStack combina uma busca poderosa com fluxos de trabalho intuitivos, permitindo que você identifique anomalias, investigue problemas e obtenha insights rapidamente.

No ClickHouse Observability — Autogerenciado, a UI é integrada ao sistema de autenticação do console do ClickHouse Cloud.
