<Note>
  Esta página aborda o **Self-managed ClickHouse Observability**. O ClickHouse Observability totalmente gerenciado, a experiência padrão recomendada, cuida dos esquemas de banco de dados e dos mapeamentos de tipos para você. Não é necessário configurar esses componentes internos para fazer a migração; siga o [guia de migração do Elasticsearch](/pt-BR/clickstack/observability/migration/elastic) para começar.
</Note>

O Elasticsearch e o ClickHouse oferecem suporte a uma grande variedade de tipos de dados, mas seus modelos de armazenamento subjacente e de consulta são fundamentalmente diferentes. Esta seção mapeia os tipos de campo mais usados do Elasticsearch para seus equivalentes no ClickHouse, quando houver, e fornece contexto para orientar as migrações. Quando não há um equivalente, os comentários apresentam alternativas ou observações.

### Notas {#notes}

* **Arrays**: No Elasticsearch, todos os campos oferecem suporte nativo a arrays. No ClickHouse, os arrays precisam ser definidos explicitamente (por exemplo, `Array(String)`), com a vantagem de que posições específicas podem ser acessadas e consultadas, por exemplo, `an_array[1]`.
* **Multi-fields**: O Elasticsearch permite indexar o [mesmo campo de várias formas](https://www.elastic.co/docs/reference/elasticsearch/mapping-reference/multi-fields#_multi_fields_with_multiple_analyzers) (por exemplo, como `text` e `keyword` ao mesmo tempo). No ClickHouse, esse padrão precisa ser modelado com colunas ou views separadas.
* **Tipos Map e JSON** - No ClickHouse, o tipo [`Map`](/pt-BR/reference/data-types/map) costuma ser usado para modelar estruturas dinâmicas de chave-valor, como `resourceAttributes` e `logAttributes`. Esse tipo permite uma ingestão flexível sem schema, já que chaves arbitrárias podem ser adicionadas em tempo de execução — algo semelhante, em essência, aos objetos JSON no Elasticsearch. No entanto, há limitações importantes a considerar:

  * **Tipos de valor uniformes**: as colunas [`Map`](/pt-BR/reference/data-types/map) do ClickHouse devem ter um tipo de valor consistente (por exemplo, `Map(String, String)`). Valores de tipos mistos não são suportados sem coerção.
  * **Custo de desempenho**: acessar qualquer chave em um [`Map`](/pt-BR/reference/data-types/map) exige carregar o map inteiro na memória, o que pode prejudicar o desempenho.
  * **Sem subcolunas**: ao contrário do JSON, as chaves em um [`Map`](/pt-BR/reference/data-types/map) não são representadas como subcolunas de fato, o que limita a capacidade do ClickHouse de indexar, comprimir e consultar dados com eficiência.

  O tipo [`JSON`](/pt-BR/reference/data-types/newjson) do ClickHouse é uma alternativa ao [`Map`](/pt-BR/reference/data-types/map) para atributos dinâmicos e resolve várias dessas limitações:

  * **Armazenamento verdadeiramente colunar**: cada caminho JSON é armazenado como uma subcoluna, o que permite compressão, filtragem e execução vetorizada de consultas de forma eficiente.
  * **Suporte a tipos mistos**: diferentes tipos de dados (por exemplo, inteiros, strings, arrays) podem coexistir no mesmo caminho sem coerção nem unificação de tipos.
  * **Escalabilidade do sistema de arquivos**: limites internos para chaves dinâmicas (`max_dynamic_paths`) e tipos (`max_dynamic_types`) evitam uma explosão de arquivos de coluna em disco, mesmo com conjuntos de chaves de alta cardinalidade.
  * **Armazenamento denso**: valores nulos e ausentes são armazenados de forma esparsa para evitar sobrecarga desnecessária.

    O tipo [`JSON`](/pt-BR/reference/data-types/newjson) é especialmente adequado para cargas de trabalho de observabilidade, pois combina a flexibilidade da ingestão sem schema com o desempenho e a escalabilidade dos tipos nativos do ClickHouse — o que o torna um substituto ideal para o [`Map`](/pt-BR/reference/data-types/map) em campos de atributos dinâmicos.

    Para mais detalhes sobre o tipo JSON, recomendamos o [guia de JSON](/pt-BR/guides/clickhouse/data-formats/json/intro) e o artigo [&quot;How we built a new powerful JSON data type for ClickHouse&quot;](https://clickhouse.com/blog/a-new-powerful-json-data-type-for-clickhouse).
