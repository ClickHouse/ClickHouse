Use o SDK Node.js do ClickStack para coletar telemetria da sua aplicação NestJS e enviá-la ao ClickStack. Ele inclui instrumentação de requisições do NestJS e captura a saída do console.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Instale o SDK {#install-sdk}

Use o Node.js 22.15 ou superior:

```shell
npm install @clickhouse/clickstack-node
```

## Configure o destino {#configure-destination}

Defina o endpoint HTTP OTLP e a chave de ingestão do seu Coletor do ClickStack. Use `http://` se o coletor não tiver TLS configurado. Para configurar o coletor, consulte [Ingerindo com OpenTelemetry](/pt-BR/clickstack/ingesting-data/opentelemetry).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## Inicie sua aplicação {#start-application}

Defina `OTEL_SERVICE_NAME` para identificar sua aplicação. Compile sua aplicação NestJS e, em seguida, pré-carregue o SDK antes do ponto de entrada compilado:

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

Ajuste `dist/main.js` de acordo com a saída da sua compilação. Se você usa `ts-node` ou outro transpilador que intercepta o `require`, use `--require @clickhouse/clickstack-node/register` no lugar. Se você empacotar sua aplicação, mantenha o SDK e as dependências instrumentadas como externas.

Você pode continuar usando o logger de console padrão do NestJS. Para usar um logger personalizado, recorra a uma integração compatível, como Winston ou Pino. Para detalhes de configuração e compatibilidade, consulte o [guia do Node.js](/pt-BR/clickstack/ingesting-data/sdks/nodejs).

## Verifique a ingestão {#verify-ingestion}

Faça uma requisição a um controlador e emita uma mensagem de log. No ClickStack, selecione um intervalo de tempo recente e localize o nome do serviço da sua aplicação em Logs e Traces. Depois de aguardar o tempo necessário para a exportação, verifique as Metrics.
