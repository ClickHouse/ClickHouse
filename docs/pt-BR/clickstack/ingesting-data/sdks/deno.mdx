Use o suporte nativo do Deno ao OpenTelemetry para enviar logs, métricas e rastros ao ClickStack. Não é necessário usar o SDK do ClickStack para Node.js nem o pacote de logging legado do Deno.

## Configurar o OpenTelemetry {#set-up-opentelemetry}

Siga as [instruções oficiais de configuração do OpenTelemetry no Deno](https://docs.deno.com/runtime/fundamentals/open_telemetry/) para instrumentar sua aplicação. Configure o destino abaixo e, em seguida, habilite a integração nativa do Deno ao iniciar sua aplicação:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

Adicione as permissões de que sua aplicação precisa. Substitua quaisquer destinos de exemplo ou configurações do exportador de console presentes nas instruções upstream, incluindo substituições de endpoint específicas de cada sinal.

## Configure o destino {#configure-destination}

Defina o endpoint HTTP OTLP e a chave de ingestão do seu Coletor do ClickStack. Use `http://` se o coletor não tiver TLS configurado. Para configurar o coletor, consulte [Ingestão com OpenTelemetry](/pt-BR/clickstack/ingesting-data/opentelemetry).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## Verificar a ingestão {#verify-ingestion}

Inicie sua aplicação e gere alguma atividade. No ClickStack, selecione um intervalo de tempo recente e localize o nome do serviço da sua aplicação em Logs ou Rastros. Depois de aguardar o tempo necessário para a exportação, verifique as Métricas.
