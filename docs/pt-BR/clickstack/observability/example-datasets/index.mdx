Estes conjuntos de dados de exemplo e demonstrações ajudam você a dar os primeiros passos com o ClickHouse Observability totalmente gerenciado. Carregue dados de amostra, colete logs e métricas do seu ambiente ou instrumente uma aplicação para explorar rastros e a reprodução de sessão.

| Conjunto de dados                                                                                 | Descrição                                                                                                                                                |
| ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Dados de amostra](/pt-BR/clickstack/observability/example-datasets/sample-data)                        | Carregue um conjunto de dados de exemplo com logs, rastros e métricas do nosso ambiente de demonstração                                                  |
| [Monitoramento do Kubernetes](/pt-BR/clickstack/observability/example-datasets/kubernetes)              | Colete logs e métricas de um cluster do Kubernetes e envie-os para o seu serviço gerenciado                                                              |
| [Dados locais](/pt-BR/clickstack/observability/example-datasets/local-data)                             | Colete métricas e logs do sistema local e envie-os para análise no seu serviço gerenciado                                                                |
| [Demonstração de Reprodução de Sessão](/pt-BR/clickstack/observability/example-datasets/session-replay) | Instrumente uma aplicação web de demonstração para reprodução de sessão e visualize suas interações no ClickHouse Observability                          |
| [Extensão do Chrome](/pt-BR/clickstack/observability/example-datasets/chrome-extension)                 | Injete o SDK do navegador em qualquer site com a extensão HyperDX para Chrome, sem precisar alterar o código da aplicação                                |
| [Dados sintéticos com otelgen](/pt-BR/clickstack/observability/example-datasets/otelgen)                | Use o `otelgen` para enviar logs, rastros e métricas sintéticos para o seu endpoint de telemetria gerenciada                                             |
| [Dados sintéticos com telemetrygen](/pt-BR/clickstack/observability/example-datasets/telemetrygen)      | Use o `telemetrygen` para enviar logs, rastros e métricas sintéticos para o seu endpoint de telemetria gerenciada                                        |
| [HackerNews Analyzer](/pt-BR/clickstack/observability/example-datasets/instrument-application)          | Instrumente uma aplicação Node.js com um agente (ou manualmente) e envie logs, rastros, métricas e reproduções de sessão para o ClickHouse Observability |
