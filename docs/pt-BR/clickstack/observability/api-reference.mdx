O ClickHouse Observability usa a API do ClickHouse Cloud para gerenciar dashboards, alertas, webhooks, funções e pesquisas salvas, além de acessar fontes de dados.

<Note>
  Na experiência totalmente gerenciada, as fontes de dados são gerenciadas para você. Use as operações de leitura de fontes de dados para inspecioná-las. Já as operações de criação, atualização e exclusão de fontes de dados se destinam a implantações em que você mesmo gerencia suas fontes de dados.
</Note>

## Documentação de referência da API {#api-docs}

Selecione um endpoint na barra lateral para ver seus parâmetros, os esquemas de requisição e resposta e exemplos interativos. Estas páginas usam a especificação da **API do ClickHouse Cloud**, com URLs e autenticação de serviços Cloud.

Os seguintes endpoints estão disponíveis:

| Recurso              | Operações                                                                                          |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| **Dashboards**       | Criar, listar, obter, atualizar, excluir e validar dashboards                                      |
| **Alertas**          | Criar, listar, obter, atualizar e excluir alertas                                                  |
| **Fontes**           | Listar e obter fontes de dados; criar, atualizar e excluir fontes de dados que você mesmo gerencia |
| **Webhooks**         | Criar, listar, atualizar, excluir e validar webhooks                                               |
| **Funções**          | Criar, listar, obter, atualizar e excluir funções                                                  |
| **Pesquisas salvas** | Criar, listar, obter, atualizar e excluir pesquisas salvas                                         |

## Autenticação {#authentication}

O ClickHouse Observability usa a **chave de API do ClickHouse Cloud** para autenticação por meio de [autenticação básica HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Authentication). Para criar e gerenciar chaves de API, consulte [Gerenciamento de chaves de API](/pt-BR/products/cloud/features/admin-features/api/openapi).

A chave deve ter a permissão `control-plane:service:manage-clickstack-api`.

Informe o ID e o segredo da chave usando autenticação básica HTTP:

```bash
export KEY_ID=<your_key_id>
export KEY_SECRET=<your_key_secret>

curl --user $KEY_ID:$KEY_SECRET \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/dashboards
```

## URL base e formato das requisições {#base-url}

Todas as requisições à API do ClickHouse Observability são enviadas para a API do ClickHouse Cloud:

```bash
https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/<resource>
```

Você encontra o seu **ID da organização** no console do ClickHouse Cloud, em **Organization → Organization details**. O seu **ID do Serviço** aparece na URL do serviço ou na página de detalhes do serviço.

### Exemplo: listar dashboards {#list-dashboards-managed}

```bash
curl --user $KEY_ID:$KEY_SECRET \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/dashboards
```

### Exemplo: Criar um alerta {#create-alert-managed}

```bash
curl -X POST --user $KEY_ID:$KEY_SECRET \
  -H "Content-Type: application/json" \
  -d '{
    "dashboardId": "<DASHBOARD_ID>",
    "tileId": "<TILE_ID>",
    "threshold": 100,
    "interval": "1h",
    "source": "tile",
    "thresholdType": "above",
    "channel": {
      "type": "webhook",
      "webhookId": "<WEBHOOK_ID>"
    },
    "name": "Error Spike Alert",
    "message": "Error rate exceeded 100 in the last hour"
  }' \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/alerts
```
