## Configurar o OpenTelemetry {#set-up-opentelemetry}

Siga as [instruções oficiais de configuração do OpenTelemetry para Ruby](https://opentelemetry.io/docs/languages/ruby/getting-started/) para inicializar o SDK e instrumentar sua aplicação.

Configure a [exportação OTLP via HTTP](https://opentelemetry.io/docs/languages/ruby/exporters/) para rastros usando as configurações de conexão abaixo. Substitua todos os destinos de exemplo das instruções upstream, incluindo as substituições de endpoint específicas de cada sinal.

## Configure o destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gerenciado">
    <BetaBadge label="Oferta Beta" />

    Abra **Team Settings → Data → Managed Telemetry** no seu serviço e copie o **endpoint OTLP HTTP** e a **chave de API**. Use o endpoint HTTPS completo, incluindo a porta:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogerenciado">
    Use o endpoint OTLP HTTP e a chave de ingestão do seu coletor. Se o coletor não tiver TLS configurado, use `http://` em vez de `https://`. Para configurar o coletor, consulte [Ingestão com OpenTelemetry](/pt-BR/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Verifique a ingestão {#verify-ingestion}

Inicie sua aplicação instrumentada e gere alguma atividade. No ClickHouse Observability, selecione um intervalo de tempo recente e localize o nome do serviço da sua aplicação em Traces.

Para solucionar problemas de instrumentação e do exportador, consulte a [documentação do OpenTelemetry para Ruby](https://opentelemetry.io/docs/languages/ruby/).
