## Conecte sua aplicação {#connect-your-application}

1. Siga o guia da sua linguagem ou plataforma para configurar a instrumentação.
2. Nesse guia, escolha o destino:
   * **Totalmente gerenciado:** use o endpoint OTLP gerenciado do seu serviço e a API key de ingestão, disponíveis em **Team Settings → Data → Managed Telemetry**.
   * **Autogerenciado:** use o endpoint OTLP do seu Coletor OpenTelemetry e a chave de ingestão configurada.
3. Gere atividade na aplicação e, em seguida, verifique se a telemetria esperada aparece na UI.

Cada guia apresenta o formato de autenticação e as configurações do exportador para o respectivo SDK. O guia do Lambda também oferece a opção de camadas OpenTelemetry, que encaminha a telemetria por meio de um coletor local.
