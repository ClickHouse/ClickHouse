Use o suporte nativo do Deno ao OpenTelemetry para enviar logs, métricas e rastros ao ClickHouse Observability. Não é necessário usar o SDK Node.js do ClickStack nem o pacote legado de logging do Deno.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Configurar o OpenTelemetry {#set-up-opentelemetry}

Siga as [instruções oficiais de configuração do OpenTelemetry no Deno](https://docs.deno.com/runtime/fundamentals/open_telemetry/) para instrumentar sua aplicação. Configure o destino abaixo e, em seguida, habilite a integração nativa do Deno ao iniciar sua aplicação:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

Adicione as permissões de que sua aplicação precisa. Substitua todos os destinos de exemplo e as configurações do exportador de console presentes nas instruções upstream, incluindo as substituições de endpoint específicas de cada sinal.

## Configure o destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gerenciado">
    <BetaBadge label="Oferta Beta" />

    Abra **Team Settings → Data → Managed Telemetry** no seu serviço e copie o **OTLP HTTP endpoint** e a **API key**. Use o endpoint HTTPS completo, incluindo a porta:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogerenciado">
    Use o endpoint OTLP HTTP do seu coletor e a chave de ingestão. Use `http://` em vez de `https://` se o seu coletor não tiver TLS configurado. Para configurar o coletor, consulte [Ingestão com OpenTelemetry](/pt-BR/clickstack/observability/ingesting-data/opentelemetry#self-managed).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Verificar a ingestão {#verify-ingestion}

Inicie sua aplicação e gere alguma atividade. No ClickHouse Observability, selecione um intervalo de tempo recente e localize o nome do serviço da sua aplicação em Logs ou Rastros. Depois de aguardar o tempo necessário para a exportação, confira as Métricas.
