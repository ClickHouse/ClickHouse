Use o agente Java ou o SDK do OpenTelemetry para enviar logs, métricas e rastros ao ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Configurar o OpenTelemetry {#set-up-opentelemetry}

Siga as [instruções oficiais de configuração do Agente Java do OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/) para instalar a instrumentação e configurar sua aplicação. Para instrumentação manual, consulte a [documentação do SDK Java](https://opentelemetry.io/docs/languages/java/instrumentation/).

Configure a [exportação OTLP](https://opentelemetry.io/docs/languages/java/configuration/#properties-exporters) para os sinais que você deseja enviar, usando as configurações de conexão abaixo. Substitua todos os destinos de exemplo das instruções upstream, incluindo as substituições de endpoint específicas de cada sinal.

## Configure o destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gerenciado">
    <BetaBadge label="Oferta Beta" />

    Abra **Team Settings → Data → Managed Telemetry** no seu serviço e copie o **endpoint OTLP HTTP** e a **chave de API**. Use o endpoint HTTPS completo, incluindo a porta:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogerenciado">
    Use o endpoint OTLP HTTP e a chave de ingestão do seu coletor. Se o coletor não tiver TLS configurado, use `http://` em vez de `https://`. Para configurar o coletor, consulte [Ingestão com OpenTelemetry](/pt-BR/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Verificar a ingestão {#verify-ingestion}

Inicie sua aplicação instrumentada e gere alguma atividade. No ClickHouse Observability, selecione um intervalo de tempo recente e localize o nome do serviço da sua aplicação em Logs ou Rastros. Se sua aplicação emitir métricas, confira Métricas depois de aguardar o tempo necessário para a exportação.

Para solucionar problemas de instrumentação e do exportador, consulte as [orientações de solução de problemas do agente Java do OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/#troubleshooting).
