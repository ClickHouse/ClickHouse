Dê os primeiros passos com o ClickHouse Observability: envie um evento de teste e confirme que ele está disponível na UI de observabilidade.

O serviço oferece um endpoint de telemetria gerenciado. Envie para esse endpoint os dados de suas aplicações, de agentes ou de um Coletor OpenTelemetry já existente.

Se você gerencia seu próprio pipeline de ingestão e schema, siga o [guia de primeiros passos autogerenciado](/pt-BR/clickstack/self-configured/getting-started/managed).

## Antes de começar {#before-you-begin}

Você precisa de um serviço ClickHouse Observability totalmente gerenciado, além de acesso ao endpoint de telemetria e à chave de API desse serviço.

### Crie um serviço {#create-a-service}

Se você ainda não tiver um serviço, comece pela seção [Crie um serviço do ClickHouse](/pt-BR/get-started/setup/cloud#1-create-a-clickhouse-service) no guia de início rápido do ClickHouse Cloud. Quando o serviço estiver em execução, abra o ClickHouse Observability. Se o serviço ainda não tiver dados, a página **Primeiros Passos** será aberta automaticamente. Escolha um dos três caminhos abaixo para enviar dados de telemetria.

## Configurar o ClickHouse Observability {#set-up-clickhouse-observability}

Escolha o caminho mais adequado ao seu ambiente.

<Tabs>
  <Tab title="Usar uma configuração existente do OpenTelemetry">
    <div className="ch-image-md">
      <Frame>
        ![Caixa de diálogo Set up OpenTelemetry com as opções URL, Collector config e Env vars e detalhes de conexão mascarados](/images/clickstack/getting-started/observability-connection-details.png)
      </Frame>
    </div>

    Use este caminho se sua aplicação, agente ou coletor já gera dados OpenTelemetry.

    1. Selecione **Ver detalhes de conexão** na página de primeiros passos.

    2. Copie a configuração do seu emissor de telemetria. Os detalhes de conexão oferecem as opções **URL**, **Collector config** e **Env vars**.

    3. Configure seu emissor para exportar telemetria para o endpoint gerenciado usando os detalhes de autenticação fornecidos.

    4. Gere atividade normal na sua aplicação e, em seguida, confirme que os dados resultantes aparecem em [Busca](/pt-BR/clickstack/observability/features/search).

    Esses detalhes de conexão também estão disponíveis em **Team Settings → Data → Managed Telemetry**.

    <Tip>
      Para fazer uma verificação rápida opcional, selecione **send a test log** na página de primeiros passos. O botão envia imediatamente um log de teste pela UI, mas não verifica a configuração da sua aplicação ou do seu coletor.
    </Tip>
  </Tab>

  <Tab title="Instrumentar com IA">
    <div className="ch-image-md">
      <Frame>
        ![Caixa de diálogo Set it up with an AI agent mostrando o prompt de instrumentação e as variáveis de ambiente de endpoint e chave de API mascaradas](/images/clickstack/getting-started/observability-ai-instrumentation.png)
      </Frame>
    </div>

    Use este caminho se você tem o código da aplicação e quer que seu assistente de programação ajude a adicionar a instrumentação OpenTelemetry.

    1. Em **Instrumentar com IA**, selecione **Copy prompt** para abrir a caixa de diálogo **Set it up with an AI agent**.
    2. Copie o prompt da caixa de diálogo e cole-o em um assistente de programação com acesso ao código da sua aplicação, como Cursor, Copilot ou Claude Code.
    3. Defina `CLICKSTACK_OTLP_ENDPOINT` e `CLICKSTACK_API_KEY` com os valores fornecidos na caixa de diálogo. Armazene-os em um arquivo `.env` excluído do controle de versão ou no seu cofre de segredos.
    4. Revise e aplique a instrumentação sugerida e, em seguida, execute sua aplicação e gere um evento.

    Para aplicar esse fluxo de trabalho à sua própria aplicação, siga [Instrumentar com IA](/pt-BR/clickstack/observability/ingesting-data/sdks/instrument-with-ai).

    Para ver um exemplo completo com código da aplicação e um prompt de instrumentação, siga a [demonstração do HackerNews Analyzer](/pt-BR/clickstack/observability/example-datasets/instrument-application). Ela mostra passo a passo como enviar logs, rastros e métricas da aplicação, além da reprodução de sessão do navegador, para o seu serviço gerenciado.
  </Tab>

  <Tab title="Seguir guias de configuração">
    <div className="ch-image-md">
      <Frame>
        ![Caixa de diálogo Send data com guias de configuração pesquisáveis para linguagens, frameworks, infraestrutura e coletores](/images/clickstack/getting-started/observability-setup-guides.png)
      </Frame>
    </div>

    Use este caminho se você quer instruções para uma aplicação ou fonte de infraestrutura específica.

    1. Selecione **Explorar guias de configuração**.
    2. Escolha o guia da sua linguagem, framework ou infraestrutura.
    3. Siga as etapas de instrumentação e configuração e, em seguida, gere telemetria a partir dessa fonte.

    Para exemplos de configuração gerenciada, comece pelo [monitoramento do Kubernetes](/pt-BR/clickstack/observability/example-datasets/kubernetes), por [logs e métricas locais](/pt-BR/clickstack/observability/example-datasets/local-data) ou pela [aplicação HackerNews Analyzer](/pt-BR/clickstack/observability/example-datasets/instrument-application). Se quiser testar a ingestão sem instrumentar uma aplicação, use o [otelgen](/pt-BR/clickstack/observability/example-datasets/otelgen) ou o [telemetrygen](/pt-BR/clickstack/observability/example-datasets/telemetrygen).
  </Tab>
</Tabs>

## Verifique a ingestão e comece a explorar {#verify-ingestion}

Após concluir o caminho escolhido, selecione **Start exploring** para abrir a [Busca](/pt-BR/clickstack/observability/features/search). Procure um evento que você gerou e confirme que ele aparece antes de prosseguir.

Para logs, selecione a fonte de dados **Logs** e um intervalo de tempo que inclua o momento em que você enviou o evento. O exemplo abaixo mostra um log enviado pelo botão **send a test log** da UI, com `example-service` como nome do serviço. Expanda um evento para inspecionar seus atributos.
