<Note>
  Este guia aborda o ClickHouse Observability totalmente gerenciado. Para o Self-managed ClickHouse Observability, consulte [administração de banco de dados](/pt-BR/clickstack/self-configured/managing/overview) para obter orientações sobre dimensionamento, retenção, ajuste de schema e uso em produção, e [opções de configuração](/pt-BR/clickstack/self-configured/managing/config) para as configurações da fonte.
</Note>

Use **Team Settings** para gerenciar o acesso à telemetria, as fontes de dados, as conexões de API e de agentes, as integrações, as configurações de consulta e as permissões da equipe no ClickHouse Observability.

## Guias de administração {#admin-guides}

| Guia                                                                             | O que você pode fazer                                                                                                                                                       |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Opções de configuração](/pt-BR/clickstack/observability/managing/config)              | Gerencie fontes de dados e o acesso do coletor, encontre os detalhes de conexão de telemetria, configure o acesso à API e de agentes e ajuste as configurações de consulta. |
| [Controle de acesso baseado em funções](/pt-BR/clickstack/observability/managing/rbac) | Consulte as funções predefinidas, crie funções personalizadas e configure permissões para dashboards, pesquisas salvas, fontes de dados e outros recursos.                  |

## Envio de telemetria {#sending-telemetry}

Para conectar aplicações e coletores, comece pelos detalhes de conexão em **Team Settings → Dados → Telemetria Gerenciada** e, em seguida, siga os [guias de ingestão](/pt-BR/clickstack/observability/ingesting-data/overview).
