Este guia mostra como instrumentar uma pequena aplicação Node.js com OpenTelemetry e enviar seus logs, métricas, rastros e reproduções de sessão para o Self-managed ClickHouse Observability. O backend é instrumentado sem nenhuma alteração no código-fonte da aplicação.

O [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) é uma aplicação Node.js que consulta o dataset do HackerNews hospedado na demonstração pública do ClickHouse. Cada gráfico, tabela e caixa de busca é alimentado por uma consulta real do ClickHouse; assim, cada interação gera um trace cujo span principal é a chamada HTTPS do backend para o ClickHouse.

Este guia pressupõe que você já concluiu o guia [Configurando seu OpenTelemetry Collector](/pt-BR/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) e que tem um coletor do ClickStack em execução e acessível a partir da máquina em que vai executar esta aplicação. **Certifique-se de ter anotado o endpoint OTLP do coletor** e o `OTLP_AUTH_TOKEN` definido na implantação. Você vai inserir esses valores no `.env` antes de instrumentar a aplicação.

## Pré-requisitos {#prerequisites}

* Um coletor do ClickStack acessível a partir desta máquina. Se você ainda não implantou um, siga primeiro o guia [Configurando seu OpenTelemetry Collector](/pt-BR/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* O endpoint OTLP/HTTP desse coletor (geralmente na porta `4318`) e o `OTLP_AUTH_TOKEN` que você definiu nele. Use esses valores como `OTEL_EXPORTER_OTLP_ENDPOINT` e `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ e npm.

## Clone o repositório {#clone-the-repository}

Clone o [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), instale as dependências e copie o modelo do arquivo env:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

Você vai preencher o arquivo `.env` nas próximas etapas e, em seguida, fazer a instrumentação a partir deste diretório.
