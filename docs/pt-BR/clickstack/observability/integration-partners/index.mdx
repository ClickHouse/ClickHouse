Conecte seus pipelines de telemetria e suas aplicações ao ClickHouse Observability com estes parceiros de integração. Cada guia explica como configurar a integração para a sua implantação.

| Seção                                                                 | Descrição                                                                                                                                                                                  |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Bindplane](/pt-BR/clickstack/observability/integration-partners/bindplane) | O Bindplane é um pipeline de telemetria nativo do OpenTelemetry que oferece gerenciamento centralizado de Coletores OpenTelemetry.                                                         |
| [bitdrift](/pt-BR/clickstack/observability/integration-partners/bitdrift)   | O bitdrift é uma plataforma de observabilidade dinâmica para aplicações móveis que vincula a telemetria móvel aos traces de backend por meio do contexto de rastreamento do OpenTelemetry. |
| [Odigos](/pt-BR/clickstack/observability/integration-partners/odigos)       | O Odigos combina eBPF e OpenTelemetry para fornecer rastros distribuídos mais detalhados, com sobrecarga muito menor do que a de agentes baseados em bytecode.                             |
| [Telflo](/pt-BR/clickstack/observability/integration-partners/telflo)       | O Telflo é um plano de controle nativo do OpenTelemetry que centraliza o gerenciamento de coletores e o roteamento de telemetria.                                                          |
