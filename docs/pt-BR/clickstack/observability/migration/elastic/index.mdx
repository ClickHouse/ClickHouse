Planeje sua migração do Elastic Stack para o **ClickHouse Observability totalmente gerenciado**, a experiência padrão recomendada. Comece pela introdução e pela comparação de busca e, em seguida, siga os guias de migração de dados, agentes e SDKs. Quando as etapas forem diferentes, use as abas de autogerenciado para implantações autogerenciadas.

| [Busca](/pt-BR/clickstack/observability/migration/elastic/search)                      | Converta consultas de busca e entenda as diferenças de schema e de campos ausentes  |
| [Migrando dados](/pt-BR/clickstack/observability/migration/elastic/migrating-data)     | Planeje a ingestão em paralelo, a retenção e a migração de dados históricos         |
| [Migrando agentes](/pt-BR/clickstack/observability/migration/elastic/migrating-agents) | Escolha um caminho de migração para Beats, Elastic Agent ou coletores OpenTelemetry |
| [Migrando SDKs](/pt-BR/clickstack/observability/migration/elastic/migrating-sdks)      | Migre a instrumentação de aplicações do Elastic APM para o OpenTelemetry            |

O ClickHouse Observability totalmente gerenciado cuida dos esquemas subjacentes e da configuração de armazenamento para você. Se você mesmo gerencia esses componentes internos, consulte os [conceitos equivalentes](/pt-BR/clickstack/self-configured/migration/elastic/concepts) e os [mapeamentos de tipos](/pt-BR/clickstack/self-configured/migration/elastic/types).
