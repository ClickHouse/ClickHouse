Migre do Elastic Stack ou do Datadog para o ClickHouse Observability gerenciado ou autogerenciado. Os guias abordam o planejamento da migração, a sintaxe de pesquisa e a adaptação da coleta de telemetria que você já utiliza. Quando os detalhes de conexão forem diferentes, selecione a aba correspondente à sua implantação.

| Tecnologia                                                   | Descrição                                                                                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| [Elastic Stack](/pt-BR/clickstack/observability/migration/elastic) | Planeje a transição, converta consultas de pesquisa e migre dados, agentes e instrumentação de aplicações                       |
| [Datadog](/pt-BR/clickstack/observability/migration/datadog)       | Configure os agentes Datadog existentes para enviar telemetria a um endpoint gerenciado ou a um receptor Datadog autogerenciado |
