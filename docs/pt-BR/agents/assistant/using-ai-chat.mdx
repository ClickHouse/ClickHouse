O Assistente permite analisar dados em um serviço do ClickHouse Cloud usando linguagem natural. Ele pode gerar consultas, visualizações e resumos com base em contexto como abas ativas, consultas salvas, esquemas e dashboards.

O Assistente também inclui o modo Docs AI, para fazer perguntas com respostas baseadas na documentação do ClickHouse. Use este guia para habilitar o Assistente e trabalhar com os dois modos no console do ClickHouse Cloud.

<Steps>
  <Step title="Pré-requisitos" id="prerequisites">
    1. Você precisa ter acesso a uma organização do ClickHouse Cloud com funcionalidades de IA habilitadas (caso não estejam disponíveis, entre em contato com o administrador da sua organização ou com o suporte).
  </Step>

  <Step title="Abra o painel do AI Chat" id="open-panel">
    1. Acesse um serviço do ClickHouse Cloud.
    2. Na barra lateral esquerda, clique no ícone de brilho rotulado como “Assistente”.
    3. (Atalho) Pressione <kbd>⌘</kbd> + <kbd>&#39;</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>&#39;</kbd> (Linux/Windows) para abrir ou fechar o painel.

    <div className="ch-image-md">
      <Frame>
        ![Abrir o painel lateral do AI Chat](/images/use-cases/AI_ML/AIChat/1_open_chat.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Aceite os termos de uso de dados (primeiro acesso)" id="consent">
    1. No primeiro uso, é exibida uma caixa de diálogo de consentimento que descreve o tratamento de dados e os suboperadores de LLM de terceiros.
    2. Leia e aceite para continuar. Se você recusar, o painel não será aberto.

    <div className="ch-image-md">
      <Frame>
        ![Caixa de diálogo de consentimento](/images/use-cases/AI_ML/AIChat/2_consent.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Escolha um modo de conversa" id="modes">
    Atualmente, o AI Chat oferece suporte a:

    * **Agent**: raciocínio em várias etapas sobre o esquema + metadados (o serviço precisa estar ativo).
    * **Docs AI (Ask)**: perguntas e respostas objetivas, baseadas na documentação oficial do ClickHouse e em referências de boas práticas.

    Para alternar entre os modos, use o seletor de modo no canto inferior esquerdo do painel lateral.

    <div className="ch-image-sm">
      <Frame>
        ![Seleção de modo](/images/use-cases/AI_ML/AIChat/3_modes.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Escreva e envie uma mensagem" id="compose">
    1. Digite sua pergunta (por exemplo, “Crie uma visão materializada para agregar eventos diários por usuário”).
    2. Pressione <kbd>Enter</kbd> para enviar (use <kbd>Shift</kbd> + <kbd>Enter</kbd> para quebrar a linha).
    3. Enquanto o modelo estiver processando, você pode clicar em “Stop” para interromper.
  </Step>

  <Step title="Entendendo as etapas de raciocínio do “Agent”" id="thinking-steps">
    No modo Agent, podem aparecer etapas intermediárias expansíveis de “raciocínio” ou planejamento. Elas mostram como o assistente chega à resposta. Recolha ou expanda conforme necessário.

    <div className="ch-image-md">
      <Frame>
        ![Etapas de raciocínio](/images/use-cases/AI_ML/AIChat/4_thinking.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Iniciando novas conversas" id="new-chats">
    Clique no botão “New Chat” para limpar o contexto e iniciar uma nova sessão.
  </Step>

  <Step title="Visualizando o histórico de conversas" id="history">
    1. A seção inferior lista suas conversas recentes.
    2. Selecione uma conversa anterior para carregar as mensagens dela.
    3. Para excluir uma conversa, use o ícone de lixeira.

    <div className="ch-image-md">
      <Frame>
        ![Lista do histórico de conversas](/images/use-cases/AI_ML/AIChat/5_history.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Trabalhando com SQL gerado" id="sql-actions">
    Quando o assistente retornar SQL:

    * Verifique se o SQL está correto.
    * Clique em “Open in editor” para carregar a consulta em uma nova aba de SQL.
    * Modifique e execute a consulta no Console.

    <div className="ch-image-md">
      <Frame>
        ![Ações do resultado](/images/use-cases/AI_ML/AIChat/6_result_actions.webp)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![Abrir a consulta gerada no editor](/images/use-cases/AI_ML/AIChat/7_open_in_editor.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Parando ou interrompendo uma resposta" id="interrupt">
    Se uma resposta estiver demorando demais ou fugindo do assunto:

    1. Clique no botão “Stop” (visível durante o processamento).
    2. A mensagem é marcada como interrompida; você pode refinar seu prompt e reenviá-lo.
  </Step>

  <Step title="Atalhos de teclado" id="shortcuts">
    | Ação            | Atalho               |
    | --------------- | -------------------- |
    | Abrir o AI Chat | `⌘ + '` / `Ctrl + '` |
    | Enviar mensagem | `Enter`              |
    | Nova linha      | `Shift + Enter`      |
  </Step>
</Steps>
