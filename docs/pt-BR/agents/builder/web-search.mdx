A Busca na web permite que um agente obtenha informações da web pública durante uma conversa. Use-a em perguntas cuja resposta precisa estar atualizada, como versões recentes, documentação disponível fora do seu serviço ou uma verificação rápida em uma fonte confiável.

## Habilite o recurso {#enable-it}

No Criador de agentes, habilite **Busca na web** na seção **Capacidades**. Uma vez habilitado o recurso, o agente decide quando fazer uma busca com base na pergunta do usuário e nas próprias instruções. A busca é executada, os resultados são coletados e o conteúdo mais relevante é repassado ao contexto do modelo.

## Como funciona uma rodada de pesquisa {#how-a-search-round-works}

Cada pesquisa é executada em três etapas, gerenciadas automaticamente no Cloud:

1. **Busca** - a consulta do agente é enviada a um provedor de pesquisa, que retorna URLs candidatas.
2. **Scrape** - as páginas relevantes são obtidas e o texto relevante é extraído.
3. **Reclassificação** - um reclassificador atribui pontuações aos resultados para que o modelo veja primeiro os mais úteis.

A resposta do agente cita as URLs que ele de fato utilizou.

## Quando usar {#when-to-use-it}

* Consultar notas de versão ou registros de alterações que não estão no seu serviço.
* Verificar um fato em uma fonte que o modelo talvez não conheça.
* Trazer uma publicação de blog ou documentação pública para a conversa e analisá-la.

Evite usá-lo em perguntas que podem ser respondidas com base nos seus dados ou no próprio conhecimento do modelo. Cada rodada de pesquisa aumenta a latência.
