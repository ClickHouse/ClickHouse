A geração de imagens permite que um agente crie novas imagens a partir de um prompt de texto ou edite imagens enviadas pelo usuário. O agente decide entre geração e edição com base no que foi solicitado e no contexto disponível.

## Habilitar a geração de imagens {#enable-it}

A geração de imagens é adicionada pelo modal **Add Tools** no Criador de agentes (e não pela seção Capabilities). Clique em **Add Tools** na parte inferior do painel do Criador de agentes e adicione uma das ferramentas de modelo de imagem — por exemplo, **OpenAI Image Tools**, **DALL-E-3** ou **Stable Diffusion**. O agente escolhe a ferramenta mais adequada de acordo com a solicitação, mas você também pode restringir essa escolha nas instruções.

## Geração {#generation}

Quando o usuário pede uma imagem, o agente chama a ferramenta de geração com um prompt e retorna a imagem gerada diretamente na resposta. O agente mantém uma referência à imagem em seu contexto para poder descrevê-la ou reutilizá-la na mesma conversa.

## Edição {#editing}

Se o usuário enviar uma imagem e pedir uma modificação — alterar uma cor, adicionar um objeto, expandir uma composição —, o agente aciona a variante de edição da ferramenta. A saída substitui a região correspondente ou expande a imagem original, conforme solicitado.

## Notas {#notes}

* As imagens geradas não são encaminhadas automaticamente para uma análise de visão separada. Se você precisar que o agente *interprete* uma imagem, use o [Vision](/pt-BR/agents/builder/vision) com uma imagem enviada pelo usuário.
* Aplicam-se as políticas de conteúdo do provedor. Prompts que violem a política do provedor retornam um erro em vez de uma imagem.
