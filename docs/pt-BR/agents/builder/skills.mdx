Uma habilidade é um pacote reutilizável de instruções que um agente pode aplicar sob demanda. Use habilidades para procedimentos recorrentes entre agentes — um guia de estilo da marca, um checklist de revisão de código, um runbook para um fluxo de trabalho específico — em vez de duplicar as instruções no prompt do sistema de cada agente.

## Anatomia de uma habilidade {#anatomy-of-a-skill}

Uma habilidade é um arquivo Markdown com um pequeno cabeçalho de frontmatter:

```markdown
---
name: revenue-report
description: Generates the weekly revenue report using our standard segments
always-apply: false
user-invocable: true
---

When asked to generate a revenue report:
1. Filter to the requested period.
2. Apply the standard MRR formula:
     SUM(CASE
       WHEN billing_cycle = 'monthly' THEN amount
       WHEN billing_cycle = 'yearly'  THEN amount / 12
       ELSE 0
     END)
3. Break down by segment: Enterprise, Mid-Market, SMB.
4. Render the result as a Markdown table.
```

As opções do frontmatter que mais importam:

* **`name`** - identificador em kebab-case.
* **`description`** - resumo curto usado pelo modelo para decidir quando esta habilidade é relevante. Considere este o campo mais importante. Seja específico; descrições vagas fazem com que a habilidade errada seja invocada.
* **`always-apply`** - quando `true`, a habilidade é pré-carregada em todos os turnos, em vez de ser selecionada. Use com moderação: habilidades always-apply consomem contexto em todas as mensagens.
* **`user-invocable`** - quando `true` (o padrão), a habilidade aparece no popover `$` para seleção manual.

Você pode incluir arquivos de apoio junto com a habilidade — documentação de referência, consultas de exemplo, pequenos scripts — enviando um `.zip` com o `SKILL.md` e seus ativos.

## Use uma habilidade {#use-a-skill}

Há três formas de um agente recorrer a uma habilidade em uma conversa:

* **Invocação pelo usuário** - pressione `$` no campo de composição e escolha a habilidade no popover. O conteúdo da habilidade é pré-carregado para o próximo turno.
* **Seleção automática pelo modelo** - com base na `description` da habilidade, o próprio agente decide quando aplicá-la.
* **Always-apply** - a habilidade é pré-carregada em todos os turnos, quando configurada dessa forma.

## Gerenciar habilidades {#manage-skills}

O painel Skills no Console do Cloud permite criar habilidades em linha, enviar arquivos `.md` ou `.zip` e gerenciar quais habilidades ficam ativas para o seu usuário. As habilidades de sua propriedade ficam ativas por padrão; desative uma para removê-la do popover e do catálogo do modelo sem excluí-la.

As habilidades podem ser compartilhadas com outros usuários (consulte [compartilhamento e acesso](/pt-BR/agents/sharing-and-access)).

## Skills vs. instruções {#skills-vs-instructions}

* **Instruções do agente** definem o que o agente é e como ele se comporta de modo geral. Ficam sempre ativas para esse agente.
* **Skills** são situacionais: são aplicadas quando relevantes e ficam restritas a fluxos de trabalho específicos.

Use uma habilidade quando o mesmo conjunto de instruções passo a passo se repetir em vários agentes ou quando quiser que ela seja acionada apenas em requisições específicas do usuário, e não a cada turno.
