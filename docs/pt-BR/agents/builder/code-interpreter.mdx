O Interpretador de código permite que um agente execute código em um sandbox gerenciado. Use-o para cálculos, transformação de dados, conversão de formatos, geração de gráficos e qualquer outra tarefa que seja mais bem resolvida com código do que em linguagem natural.

## Habilitar o Interpretador de código {#enable-it}

No Criador de agentes, habilite **Run Code** na seção **Capabilities** e salve. O agente decide quando executar código com base na solicitação do usuário e nas instruções definidas para ele.

## Linguagens compatíveis {#supported-languages}

O sandbox é um ambiente Unix com dois runtimes de uso geral e alguns utilitários de shell:

* **Python 3** - a opção padrão para tarefas com dados.
* **Node.js (JavaScript)** - quando um agente prefere usar JS para a tarefa.
* **Bash** e **sh** - scripts de shell para encadear comandos e fazer operações rápidas de E/S.
* **AWK** e **sed** - processamento de texto orientado a linhas.
* **bc** - cálculos com precisão arbitrária.

Os agentes recorrem primeiro ao Python para qualquer tarefa que envolva parsing, transformação ou processamento de dados.

<Tip>
  Reserve as ferramentas de shell para tarefas que realmente se beneficiem de um comando de uma linha só.
</Tip>

## Arquivos {#files}

Os usuários podem enviar arquivos para uma conversa, e o interpretador de código tem acesso a eles no diretório de trabalho da sandbox. O código também pode gravar arquivos de saída (CSVs, gráficos, arquivos compactados), que aparecem na conversa como anexos disponíveis para download.

## Isolamento do sandbox {#sandbox-isolation}

Cada execução ocorre em um sandbox efêmero, sem acesso à rede e sem armazenamento persistente. As sessões não compartilham estado — variáveis e arquivos de uma execução não são levados para a seguinte, a menos que o agente os recarregue explicitamente.

Aplicam-se limites de recursos específicos de cada plano (memória, arquivos por execução, cotas mensais de requisições). Erros e o stderr são exibidos na conversa junto com o stdout.

## Quando usar {#when-to-use-it}

Use o Interpretador de código quando a resposta exigir uma computação determinística que um modelo de linguagem não consegue produzir de forma confiável apenas com raciocínio.
Casos típicos incluem:

* Fazer o parsing de um arquivo CSV ou JSON enviado pelo usuário.
* Calcular estatísticas descritivas ou executar uma simulação rápida.
* Converter entre formatos (Parquet, JSON, CSV).
* Gerar um gráfico a partir dos resultados da consulta.

<Tip>
  Evite usá-lo em tarefas que o modelo já consegue resolver com base no contexto.
  A execução de código aumenta a latência e consome cota.
</Tip>
