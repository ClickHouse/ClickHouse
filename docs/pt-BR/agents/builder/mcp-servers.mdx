O Model Context Protocol (MCP) é o padrão aberto para expor ferramentas e fontes de dados a um modelo de IA. Ao anexar um servidor MCP a um ClickHouse Agent, o agente passa a ter acesso a todos os recursos que esse servidor expõe — sistemas de rastreamento de issues, backends de observabilidade, APIs internas, SaaS de terceiros ou qualquer outro serviço com um endpoint MCP.

## Anexar um servidor MCP {#attach-an-mcp-server}

No Criador de agentes, abra a seção **Servidores MCP** e clique em **Adicionar servidor**. Informe a URL do servidor e as configurações de autenticação e, em seguida, escolha quais ferramentas do servidor esse agente específico poderá usar. Salve o agente.

Você pode anexar vários servidores a um único agente. Cada ferramenta chamada pelo agente fica registrada na conversa, para que os usuários possam ver o que o agente fez.

## Transporte {#transport}

O ClickHouse Agents usa Streamable HTTP — o transporte MCP adequado para uso em produção. O servidor que você anexar precisa estar acessível via HTTP(S) a partir do ClickHouse Cloud.

## Autenticação {#authentication}

Servidores MCP podem exigir credenciais. O Agents oferece suporte a:

* **Tokens Bearer** e outros cabeçalhos estáticos — valores fixos que você informa ao configurar o servidor.
* **OAuth 2.0** — fluxo interativo. Na primeira vez que você (ou qualquer usuário com acesso) chama uma ferramenta no servidor, o navegador abre uma janela de login; os tokens são gerenciados e renovados automaticamente.
* **Credenciais por usuário** — variáveis na configuração do servidor que são substituídas por valores do perfil do usuário que faz a chamada, de modo que cada usuário se autentica com a própria identidade, e não com uma service account compartilhada.

As credenciais fornecidas pelos usuários são armazenadas de forma criptografada e restritas ao usuário que as inseriu. As credenciais de um usuário nunca ficam visíveis para as execuções de agente de outro usuário.

## Limites {#limits}

Uma única execução de agente pode referenciar no máximo 50 destinos distintos de servidor MCP e no máximo 100 configurações de ferramentas expandidas por requisição. Agentes que precisem de mais do que isso devem ser divididos em [subagentes](/pt-BR/agents/builder/subagents).
