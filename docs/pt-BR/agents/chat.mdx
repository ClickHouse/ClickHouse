## Conversas {#conversations}

Inicie uma nova conversa clicando no ícone de composição na navegação à esquerda.
Escolha o agente que deseja usar no seletor de agentes, no canto superior esquerdo da janela da conversa — por padrão, o **ClickHouse Agent** já vem selecionado.
Em seguida, digite sua mensagem no campo de composição e clique em enviar. Cada conversa fica salva no histórico da barra lateral e pode ser reaberta, renomeada ou excluída posteriormente.

<div className="ch-image-lg">
  <Frame>

Você pode editar qualquer uma das suas mensagens diretamente, e o agente vai gerar a resposta novamente a partir desse ponto do histórico de conversas.
Também é possível gerar novamente apenas a última resposta do agente, sem reenviar sua mensagem.

## Favoritos {#bookmarks}

Adicione uma mensagem ou uma conversa inteira aos favoritos para encontrá-la rapidamente depois. Os favoritos são visíveis apenas para você e são mantidos mesmo quando a conversa é renomeada.

## Conversas fixadas {#pinned-conversations}

Fixe uma conversa para mantê-la no topo da barra lateral, separada do histórico agrupado por data logo abaixo. Na barra lateral, abra o menu de opções da conversa (o ícone de três pontos) e selecione **Fixar**. As conversas fixadas ficam reunidas em uma seção **Fixadas**, acima dos grupos **Hoje**, **Ontem** e dos mais antigos.

Para desafixar uma conversa, abra o mesmo menu e selecione **Desafixar**.

## Ramificação {#forking}

A ramificação cria uma nova conversa a partir de uma mensagem específica. Use-a para explorar um caminho alternativo sem interferir na thread original.
Há três modos de bifurcação disponíveis:

* **Visible messages only** - copia o caminho direto até a mensagem bifurcada.
* **Include related branches** - copia o caminho principal e todas as ramificações existentes.
* **Include all to here** - copia tudo até a mensagem bifurcada.

As conversas bifurcadas são independentes, ou seja, as alterações não são sincronizadas com a conversa original.

## Compartilhamento de conversas {#sharing-chats}

Gere um link compartilhável para qualquer conversa e envie-o a um colega de equipe ou guarde-o como referência. Os destinatários veem uma visualização read-only, incluindo artefatos e ramificações visíveis. Você pode revogar um link a qualquer momento no dashboard de compartilhamento.

Edições em mensagens existentes aparecem na visualização compartilhada; mensagens adicionadas depois da geração do link, não.

Qualquer pessoa que acesse um link compartilhado pode dar continuidade à conversa na própria conta clicando em **Continue this chat**. Isso copia a conversa — incluindo a ramificação que a pessoa está visualizando — para o histórico dela como uma nova conversa privada, sem alterar a sua conversa original.

Para compartilhar uma conversa, abra o menu dela na barra lateral e selecione **Compartilhar**:

## Atalhos de teclado {#keyboard-shortcuts}

Abra a referência de atalhos de teclado com `Cmd+Shift+/` (`Ctrl+Shift+/` no Windows e no Linux) ou pelo menu da conta, em **Help** → **Atalhos de teclado**. Todos os atalhos são personalizáveis: clique em uma linha da caixa de diálogo para gravar uma nova combinação e use **Reset all to defaults** para restaurar os valores padrão.

Os atalhos padrão são:

| Ação                                  | macOS                 | Windows e Linux        |
| ------------------------------------- | --------------------- | ---------------------- |
| Mostrar atalhos de teclado            | `Cmd+Shift+/`         | `Ctrl+Shift+/`         |
| Nova conversa                         | `Cmd+Shift+O`         | `Ctrl+Shift+O`         |
| Focar no campo de entrada da conversa | `Shift+Esc`           | `Shift+Esc`            |
| Enviar arquivo                        | `Cmd+Shift+U`         | `Ctrl+Shift+U`         |
| Copiar última resposta                | `Cmd+Shift+;`         | `Ctrl+Shift+;`         |
| Enviar mensagem                       | `Cmd+Enter`           | `Ctrl+Enter`           |
| Mostrar/ocultar barra lateral         | `Cmd+Shift+S`         | `Ctrl+Shift+S`         |
| Abrir seletor de modelo               | `Cmd+Shift+M`         | `Ctrl+Shift+M`         |
| Focar na busca                        | `Cmd+/`               | `Ctrl+/`               |
| Abrir configurações                   | `Cmd+Shift+,`         | `Ctrl+Shift+,`         |
| Adicionar conversa aos favoritos      | `Cmd+Shift+B`         | `Ctrl+Shift+B`         |
| Interromper geração                   | `Cmd+Shift+X`         | `Ctrl+Shift+X`         |
| Gerar resposta novamente              | `Cmd+Shift+E`         | `Ctrl+Shift+E`         |
| Editar última mensagem                | `Cmd+Shift+I`         | `Ctrl+Shift+I`         |
| Continuar resposta                    | `Cmd+Shift+C`         | `Ctrl+Shift+C`         |
| Copiar último bloco de código         | `Cmd+Shift+K`         | `Ctrl+Shift+K`         |
| Rolar até o topo                      | `Cmd+Shift+Up`        | `Ctrl+Shift+Up`        |
| Rolar até o final                     | `Cmd+Shift+Down`      | `Ctrl+Shift+Down`      |
| Arquivar conversa                     | `Cmd+Shift+L`         | `Ctrl+Shift+L`         |
| Excluir conversa                      | `Cmd+Shift+Backspace` | `Ctrl+Shift+Backspace` |

Você também pode atribuir seus próprios atalhos para abrir painéis como agentes, Prompts, arquivos e favoritos — eles não têm teclas padrão.
