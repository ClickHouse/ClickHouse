## Análise geoespacial com torres de celular {#geospatial-analysis-with-cell-towers}

Este guia mostra como carregar os dados do `OpenCelliD` no `ClickHouse Cloud`, enriquecê-los com um dicionário de países, consultar torres na Alemanha e visualizá-las com `ClickHouse Agents`.

<Steps>
  <Step title="Carregue os dados de exemplo">
    No `ClickHouse Cloud`, abra **Load data**, escolha **Cell Towers** em **Sample data** e carregue o conjunto de dados. Cada linha de `cell_towers` é uma torre; `lon` e `lat` são suas coordenadas.

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="Consulte e enriqueça as torres">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;
    ```

    Crie um dicionário que substitui o `mcc` numérico pelo país:

    ```sql
    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="Incorpore dados geográficos">
    O `ClickHouse` fornece funções como [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon). Crie `germany`, insira o contorno da Alemanha continental mostrado no [guia em inglês](/get-started/sample-datasets/cell-towers#germany-polygon) e conte as torres dentro do polígono:

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    O resultado é aproximadamente `2.62 million`.
  </Step>
  <Step title="Opcional: visualize os dados com ClickHouse Agents">
    Este é um exemplo opcional: `ClickHouse Agents` é um recurso beta orientado por modelo, portanto seu plano, ferramentas e saída podem variar entre execuções. Abra **ClickHouse agents** e envie: "Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables".

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="Conversa do ClickHouse Agent criando uma grade de densidade de torres na Alemanha"/>

    Em uma execução, o agente encontrou o MCC alemão, contou as torres, agrupou-as em uma grade de `0.1°` e desenhou o contorno no mapa.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="Mapa de calor da densidade de torres de celular na Alemanha"/>
  </Step>
</Steps>
