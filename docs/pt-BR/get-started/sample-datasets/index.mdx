Temos vários recursos para ajudar você a começar e entender como o ClickHouse funciona:

* Para experimentar o ClickHouse sem instalar nada, você pode se inscrever para um [teste gratuito do ClickHouse Cloud](https://clickhouse.cloud/signUp?loc=docs-get-started-sample-datasets) ou executar consultas no [ClickHouse playground](/pt-BR/get-started/sample-datasets/playground), que é read-only.
* Se preferir executar o ClickHouse por conta própria, siga nosso [Início rápido](/pt-BR/get-started/setup/install).
* Se você está procurando um ponto de partida para aprender, experimente o tutorial [Dados de táxi de Nova York](/pt-BR/get-started/sample-datasets/nyc-taxi), que analisa um conjunto de dados de corridas de táxi da cidade de Nova York, ou escolha qualquer um dos tutoriais abaixo.
