<Visibility for="humans">
  <View title="UI do Cloud">
    O ClickHouse Cloud oferece uma maneira fácil de importar seus arquivos e é compatível com os
    seguintes formatos:

    | Formato                         |
    | ------------------------------- |
    | `CSV`                           |
    | `CSVWithNamesAndTypes`          |
    | `CSVWithNames`                  |
    | `JSONEachRow`                   |
    | `TabSeparated`                  |
    | `TabSeparatedWithNames`         |
    | `TabSeparatedWithNamesAndTypes` |

    <Steps>
      <Step title="Enviar um arquivo" id="upload-file">
        Na página inicial do Cloud, selecione seu serviço, conforme mostrado abaixo:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_02](/images/cloud/migrate/csv_01.webp)
          </Frame>
        </div>

        Se o seu serviço estiver ocioso, será necessário ativá-lo.

        Selecione `Data sources` na aba à esquerda, conforme mostrado abaixo:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_03](/images/cloud/migrate/csv_02.webp)
          </Frame>
        </div>

        Em seguida, selecione `Upload a file` no lado direito da página de Fontes de Dados:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_04](/images/cloud/migrate/csv_03.webp)
          </Frame>
        </div>

        Uma caixa de diálogo será aberta para que você selecione o arquivo que deseja
        usar para inserir dados em uma tabela no seu serviço Cloud.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_04.webp)
          </Frame>
        </div>
      </Step>

      <Step title="Configurar a tabela" id="configure-table">
        Após o envio do arquivo, você poderá configurar a tabela na qual deseja
        inserir os dados. Uma prévia da tabela com as três primeiras linhas é exibida.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_08](/images/cloud/migrate/csv_08.webp)
          </Frame>
        </div>

        Agora você pode selecionar uma tabela de destino. As opções são:

        * uma nova tabela
        * uma tabela existente

        <br />

        Você pode especificar para qual banco de dados deseja enviar os dados e, no caso de
        uma nova tabela, o nome da tabela que será criada. Também é possível selecionar a sorting key:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_05.webp)
          </Frame>
        </div>

        As colunas lidas do arquivo são exibidas como `Source field`s e, para cada campo, você
        pode alterar:

        * o tipo inferido
        * o valor default
        * se a coluna será [Nullable](/pt-BR/reference/data-types/nullable) ou não

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_06](/images/cloud/migrate/csv_06.webp)
          </Frame>
        </div>

        <Info>
          **Excluir campos**

          Você também pode remover um campo caso não queira incluí-lo na importação
        </Info>

        Você pode especificar o tipo de motor de tabela que deseja usar:

        * `MergeTree`
        * `ReplacingMergeTree`
        * `SummingMergeTree`
        * `Null`

        <br />

        Você pode especificar uma expressão de chave de particionamento e uma expressão de chave
        primária.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_07](/images/cloud/migrate/csv_07.webp)
          </Frame>
        </div>

        Clique em `Import to ClickHouse` (mostrado acima) para importar os dados. A importação será colocada na fila, conforme
        indicado pelo selo de status `queued` na coluna `Status`, como mostrado abaixo. Você também pode clicar em
        `Open as query` (mostrado acima) para abrir a consulta de inserção no Console SQL. A consulta inserirá
        o arquivo enviado para um bucket S3 usando a função de tabela `URL`.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_09](/images/cloud/migrate/csv_09.webp)
          </Frame>
        </div>

        Se o job falhar, você verá um selo de status `failed` na coluna `Status` da
        aba `Data upload history`. Clique em `View Details` para obter mais informações
        sobre o motivo da falha no envio. Dependendo da mensagem de erro do insert que falhou, pode ser necessário
        modificar a configuração da tabela ou limpar os dados.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_11](/images/cloud/migrate/csv_10.webp)
          </Frame>
        </div>
      </Step>
    </Steps>
  </View>
