As funcionalidades em versão prévia pública são recursos do ClickHouse Cloud praticamente concluídos e com um caminho claro rumo à disponibilidade geral (GA). Elas estão disponíveis para que os clientes enviem feedback, mas ainda não estão em Beta.

<Warning>
  As funcionalidades em versão prévia pública podem sofrer alterações e não são cobertas pelo SLA padrão do ClickHouse Cloud.
</Warning>

## Habilitar a versão prévia pública {#enable-public-preview}

1. Faça login no Console do Cloud e selecione a organização correta.
2. Abra o menu da organização e selecione **Preview features**. Você também pode acessar essa opção pela barra lateral da organização.
3. Localize a funcionalidade, selecione **Learn more** para conferir os requisitos e as limitações e, em seguida, ative a chave correspondente. Se a chave estiver desabilitada, peça a um administrador da organização que habilite a funcionalidade.
4. Quando disponível, use o link de serviço **Go to...** ou **View in...** para começar a usar a funcionalidade.

<Note>
  A disponibilidade depende do acesso da sua organização e da implantação gradual da funcionalidade. Nem toda versão prévia pública está disponível para todas as organizações. Entre em contato com o [Suporte do Cloud](https://clickhouse.com/support/program) para verificar o acesso.
</Note>
