Nem todos os usuários interagem com o ClickHouse por meio do console do Cloud.
Por exemplo, muitos desenvolvedores trabalham diretamente em seus editores de código preferidos, em agentes de CLI ou se conectam ao banco de dados por meio de configurações personalizadas, enquanto outros dependem de assistentes de IA de uso geral, como o Anthropic Claude, para a maior parte de suas explorações.
Esses usuários e as cargas de trabalho agentivas que atuam em seu nome precisam de uma forma de acessar e consultar o ClickHouse Cloud com segurança, sem configurações complexas nem infraestrutura personalizada.

O recurso de servidor MCP remoto no ClickHouse Cloud resolve isso ao expor uma interface padrão que agentes externos podem usar para recuperar contexto analítico.
MCP, ou Model Context Protocol, é um padrão para acesso estruturado a dados por aplicações de IA baseadas em LLMs.
Com essa integração, agentes externos podem listar bancos de dados e tabelas, inspecionar esquemas e executar consultas SELECT com escopo limitado e em modo somente leitura.
A autenticação é feita via OAuth 2.0 ou por meio de uma [chave de API do ClickHouse Cloud](/pt-BR/cloud/manage/openapi). O servidor é totalmente gerenciado no ClickHouse Cloud, portanto não requer configuração nem manutenção.

Isso facilita que ferramentas agentivas se integrem ao ClickHouse e recuperem os dados de que precisam, seja para análise, sumarização, geração de código ou exploração.

## servidor MCP remoto vs servidor MCP de código aberto {#remote-vs-oss}

O ClickHouse oferece dois servidores MCP.

|                  | servidor MCP remoto (Cloud)                                                                                                                | Servidor MCP de código aberto                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **Origem**       | Totalmente gerenciado pelo ClickHouse Cloud                                                                                                | [mcp-clickhouse](https://github.com/ClickHouse/mcp-clickhouse) no GitHub |
| **Transporte**   | HTTP por streaming (`https://mcp.clickhouse.cloud/mcp`)                                                                                    | stdio local                                                              |
| **Funciona com** | serviços do ClickHouse Cloud e do Managed Postgres                                                                                         | Qualquer instância do ClickHouse (self-hosted ou Cloud)                  |
| **Autenticação** | OAuth 2.0 com suas credenciais do Cloud ou uma chave de API do ClickHouse Cloud                                                            | Variáveis de ambiente                                                    |
| **Ferramentas**  | Ferramentas para consultas, exploração de esquema, gerenciamento de serviços, backups, ClickPipes, faturamento e monitoramento do Postgres | 3 ferramentas: `run_select_query`, `list_databases`, `list_tables`       |
| **Configuração** | Nenhuma instalação. Aponte seu cliente MCP para o endpoint e autentique-se.                                                                | Instale e execute o servidor localmente                                  |

O servidor MCP remoto oferece a integração mais completa com o ClickHouse Cloud, incluindo gerenciamento de serviços, monitoramento de backups, visibilidade do ClickPipe e dados de faturamento, sem necessidade de gerenciar infraestrutura.
Para instâncias self-hosted do ClickHouse, consulte os [guias do servidor MCP de código aberto](/pt-BR/guides/use-cases/ai-ml/MCP/index).

## Habilitando o servidor MCP remoto {#enabling}

O servidor MCP remoto deve ser habilitado para cada serviço antes de poder aceitar conexões.
No console do ClickHouse Cloud, abra o serviço, clique no botão **Connect**, selecione **MCP** e habilite-o.
Para serviços ClickHouse, habilitar ou desabilitar o servidor MCP remoto requer a permissão `control-plane:service:manage-mcp` (consulte [Funções e permissões do Console](/pt-BR/products/cloud/reference/security/console-roles#console-permissions)).
Para serviços Managed Postgres, abra o painel **Connect** do serviço e ative a opção **Enable Model Context Protocol**. As réplicas de leitura herdam a configuração de MCP do banco de dados pai.
Para ver o passo a passo detalhado com capturas de tela, consulte o [guia de configuração](/pt-BR/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server).

## Endpoint {#endpoint}

Após ser habilitado, o servidor MCP remoto fica disponível em:

```text
https://mcp.clickhouse.cloud/mcp
```

## Autenticação {#authentication}

O servidor MCP remoto oferece suporte a dois métodos de autenticação:

* **OAuth 2.0**: Recomendado para clientes interativos. Quando um cliente MCP se conecta pela primeira vez, ele abre uma janela do navegador para que o usuário faça login com suas credenciais do ClickHouse Cloud. O acesso fica restrito às organizações e aos serviços aos quais o usuário autenticado tem permissão de acesso.
* **Chave de API do ClickHouse Cloud**: Destinada a ambientes remotos, headless e automatizados, nos quais um fluxo do OAuth baseado em navegador não é viável. Envie o ID e o segredo da chave de API usando autenticação HTTP Basic:

  ```text
  Authorization: Basic base64(<key_id>:<key_secret>)
  ```

O acesso por chave de API é limitado pelas funções, permissões e data de expiração configuradas para a chave. Use uma chave dedicada, com o mínimo de privilégios necessário, e injete-a por meio de um sistema de gerenciamento de segredos. A codificação Base64 não criptografa as credenciais; portanto, não faça commit do valor codificado no controle de versão nem o exponha em logs.

Para ver um exemplo de configuração de um cliente MCP em um ambiente headless, consulte [Autenticar a partir de um ambiente headless](/pt-BR/products/cloud/features/ai-ml/mcp/remote-mcp#headless-mcp-client-authentication).

## Segurança {#safety}

Todas as ferramentas expostas pelo servidor MCP remoto são **somente leitura**. Cada ferramenta é marcada com `readOnlyHint: true` nos metadados do MCP. Nenhuma ferramenta pode modificar dados, alterar a configuração do serviço nem realizar qualquer operação destrutiva.

## Ferramentas disponíveis {#available-tools}

O servidor MCP remoto disponibiliza ferramentas nas seguintes categorias. A disponibilidade das ferramentas depende do método de autenticação e das funcionalidades habilitadas.

### Exploração de consultas e esquema {#query-and-schema}

Essas ferramentas permitem que os agentes descubram quais dados estão disponíveis e executem consultas analíticas.

| Ferramenta         | Descrição                                                                     | Parâmetros                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `run_select_query` | Executa uma consulta SELECT somente leitura em um serviço do ClickHouse.      | `query`, uma consulta SELECT válida em ClickHouse SQL; `serviceId`                                          |
| `list_databases`   | Lista todos os bancos de dados disponíveis em um serviço do ClickHouse.       | `serviceId`                                                                                                 |
| `list_tables`      | Lista todas as tabelas em um banco de dados, incluindo definições de colunas. | `serviceId`; `database`; opcionalmente `like` ou `notLike` (padrões SQL LIKE para filtrar nomes de tabelas) |

### Managed Postgres {#managed-postgres}

Essas ferramentas consultam e monitoram serviços Managed Postgres. Use `get_organizations` para obter o `organizationId` e, em seguida, `get_services_list` para localizar um serviço cujo `serviceType` seja `postgres`, usando o `id` dele como `serviceId`.

| Ferramenta                                | Descrição                                                                                                                                                                        | Parâmetros                                                                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run_postgres_select_query`               | Executa uma consulta SQL read-only em um serviço Postgres. Requer autenticação OAuth; indisponível com chaves de API do ClickHouse Cloud.                                        | `organizationId`; `serviceId`; `query`; opcionalmente `database` (padrão: `postgres`) e `timeoutSeconds` (1–3600, padrão: 300)                                             |
| `list_postgres_slow_query_patterns`       | Lista padrões de consultas lentas com métricas agregadas de latência, número de chamadas, linhas, CPU, E/S, WAL e erros. As durações são expressas em microssegundos.            | `organizationId`; `serviceId`; `fromDate`; `toDate`; opcionalmente `limit` (1–500, padrão: 20), `offset`, `sortBy`, `sortOrder`, `dbName`, `dbUser`, `dbOperation` e `app` |
| `get_postgres_slow_query_pattern_details` | Retorna até 10 execuções recentes de um padrão de consulta nas últimas 24 horas, além de métricas agregadas, quando disponíveis.                                                 | `organizationId`; `serviceId`; `queryId`; `dbName`; `dbUser`; `dbOperation`; opcionalmente `app`                                                                           |
| `get_postgres_metrics`                    | Retorna métricas de séries temporais de CPU, memória, disco, rede, conexões, taxa de acertos do cache, transações e esperas. Cada métrica inclui sua unidade e séries rotuladas. | `organizationId`; `serviceId`; `fromDate`; `toDate`; opcionalmente `bucketSizeSeconds` (inteiro positivo; selecionado automaticamente quando omitido)                      |

Para `fromDate` e `toDate`, use timestamps em UTC com precisão de milissegundos, como `2026-11-03T00:00:00.000Z`. O início é inclusivo. O fim é inclusivo com granularidade de minuto para padrões de consultas lentas e exclusivo para métricas.

Para inspecionar um padrão de consulta lenta, passe os valores `queryId`, `dbName`, `dbUser`, `dbOperation` e `app` retornados por `list_postgres_slow_query_patterns` para `get_postgres_slow_query_pattern_details`. Mantenha a string `app` vazia para consultas sem `application_name`; se `app` for omitido, todas as aplicações serão incluídas.

### Organizações {#organizations}

| Ferramenta                 | Descrição                                                                                  | Parâmetros       |
| -------------------------- | ------------------------------------------------------------------------------------------ | ---------------- |
| `get_organizations`        | Lista todas as organizações do ClickHouse Cloud às quais o usuário autenticado tem acesso. | Nenhum           |
| `get_organization_details` | Retorna os detalhes de uma organização específica.                                         | `organizationId` |

### Serviços {#services}

| Ferramenta                  | Descrição                                                                                                                        | Parâmetros                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| `get_services_list`   | Lista os serviços ClickHouse e Managed Postgres em uma organização, com um campo `serviceType` que identifica o tipo de cada um. | `organizationId`              |
| `get_service_details` | Retorna os detalhes de um serviço ClickHouse ou Managed Postgres, detectando automaticamente o seu tipo.                         | `organizationId`; `serviceId` |

### Backups {#backups}

| Ferramenta                         | Descrição                                                                                 | Parâmetros                                |
| ---------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------- |
| `list_service_backups`             | Lista todos os backups de um serviço, do mais recente para o mais antigo.                 | `organizationId`; `serviceId`             |
| `get_service_backup_details`       | Retorna os detalhes de um único backup.                                                   | `organizationId`; `serviceId`; `backupId` |
| `get_service_backup_configuration` | Retorna a configuração de backup de um serviço (agendamento e configurações de retenção). | `organizationId`; `serviceId`             |

### ClickPipes {#clickpipes}

| Ferramenta        | Descrição                                               | Parâmetros                                   |
| ----------------- | ------------------------------------------------------- | -------------------------------------------- |
| `list_clickpipes` | Lista todos os ClickPipes configurados para um serviço. | `organizationId`; `serviceId`                |
| `get_clickpipe`   | Retorna os detalhes de um ClickPipe específico.         | `organizationId`; `serviceId`; `clickPipeId` |

### Faturamento {#billing}

| Ferramenta              | Descrição                                                                                                                            | Parâmetros                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `get_organization_cost` | Recupera dados de faturamento e custos de uso de uma organização. Retorna um total geral e registros diários de custos por entidade. | `organizationId`; opcionalmente `from_date` e `to_date` (AAAA-MM-DD, intervalo máximo de 31 dias) |
