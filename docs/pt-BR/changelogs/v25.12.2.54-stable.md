<div id="backward-incompatible-change">
  #### Backward Incompatible Change
</div>

* Retroportado em [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224): Habilita dados compartilhados avançados para JSON por padrão. Após essa alteração, não será possível fazer downgrade para versões <25.8, porque essas versões não conseguirão ler novas partes de dados com coluna JSON. Para upgrades seguros, é recomendável definir a configuração `compatibility` para a versão anterior ou definir as configurações do MergeTree `dynamic_serialization_version='v2', object_serialization_version='v2'`. [#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado em [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061): Revert "Allow INSERT into simple ALIAS columns" (Reverts ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154)). It does not work with custom formats, and does not guarded with a setting. [#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat)).

<div id="improvement">
  #### Improvement
</div>

* Retroportado em [#92604](https://github.com/ClickHouse/ClickHouse/issues/92604): Add a creation (implicit/explicit) column to system.data_skipping_indices. [#92378](https://github.com/ClickHouse/ClickHouse/pull/92378) ([Raúl Marín](https://github.com/Algunenano)).
* Retroportado em [#93377](https://github.com/ClickHouse/ClickHouse/issues/93377): Passa a usar fallback para cópia read-write no Azure Blob Storage quando a cópia nativa falha com BadRequest (por exemplo, lista de blocos inválida). Antes, isso era feito apenas para o erro Unauthorized, observado ao copiar blob para contas de armazenamento diferentes. Mas às vezes também vemos o erro "The specified block list is invalid". Portanto, a condição foi atualizada para usar fallback para leitura e gravação em todas as falhas da cópia nativa. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado em [#93015](https://github.com/ClickHouse/ClickHouse/issues/93015): Log background tasks that are slower than average (`background_schedule_pool_log.duration_threshold_milliseconds=30`) to avoid excessive tasks logging. [#92965](https://github.com/ClickHouse/ClickHouse/pull/92965) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado em [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338): Support geometry type for `flipCoordinates`. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).
* Retroportado em [#93395](https://github.com/ClickHouse/ClickHouse/issues/93395): Improve the UX of SYSTEM INSTRUMENT ADD/REMOVE: use String literals for function names, patch all functions that match and allow using function_name in `REMOVE`.
