<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### correção de bug (comportamento incorreto perceptível ao usuário em uma versão estável oficial)
</div>

* Retroportado em [#88511](https://github.com/ClickHouse/ClickHouse/issues/88511): Corrige a leitura da subcoluna nula de map em Variants que não podem estar dentro de Nullable. [#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado em [#88734](https://github.com/ClickHouse/ClickHouse/issues/88734): Uma exceção `Poco::TimeoutException` lançada por `Poco::Net::HTTPChunkedStreamBuf::readFromDevice` pode levar a um crash com SIGABRT. [#88668](https://github.com/ClickHouse/ClickHouse/pull/88668) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Retroportado em [#88908](https://github.com/ClickHouse/ClickHouse/issues/88908): Após a recuperação, uma réplica de banco de dados Replicated pode ficar travada por muito tempo, exibindo mensagens como `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)`; isso foi corrigido. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado em [#88892](https://github.com/ClickHouse/ClickHouse/issues/88892): Corrige a validação de acesso em select para a table function `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Retroportado em [#88942](https://github.com/ClickHouse/ClickHouse/issues/88942): Corrige um bug na função `reverseUTF8`. Em versões anteriores, ela invertia incorretamente os bytes de code points UTF-8 com comprimento 4. Isso encerra [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#88978](https://github.com/ClickHouse/ClickHouse/issues/88978): Não verifica o acesso `SET DEFINER <current_user>:definer` ao criar uma VIEW com SQL SECURITY DEFINER. [#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit)).
* Retroportado em [#89083](https://github.com/ClickHouse/ClickHouse/issues/89083): Isso encerra [#88081](https://github.com/ClickHouse/ClickHouse/issues/88081). [#88988](https://github.com/ClickHouse/ClickHouse/pull/88988) ([scanhex12](https://github.com/scanhex12)).
* Retroportado em [#89026](https://github.com/ClickHouse/ClickHouse/issues/89026): Corrige a degradação de desempenho na análise de skipping indexes. [#89004](https://github.com/ClickHouse/ClickHouse/pull/89004) ([Anton Popov](https://github.com/CurtizJ)).
