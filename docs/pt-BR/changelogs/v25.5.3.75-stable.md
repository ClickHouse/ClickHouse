<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#81179](https://github.com/ClickHouse/ClickHouse/issues/81179): Agora, `system.iceberg_history` mostra o histórico de bancos de dados de catálogos, como Glue ou Iceberg REST. As colunas `table_name` e `database_name` também foram renomeadas para `table` e `database` em `system.iceberg_history`, para manter a consistência. [#80975](https://github.com/ClickHouse/ClickHouse/pull/80975) ([alesapin](https://github.com/alesapin)).
* Retroportado em [#81230](https://github.com/ClickHouse/ClickHouse/issues/81230): Atualização do libarchive para 3.7.9 para corrigir: CVE-2024-20696 CVE-2025-25724 CVE-2024-48958 CVE-2024-57970 CVE-2025-1632 CVE-2024-48957 CVE-2024-48615. [#81174](https://github.com/ClickHouse/ClickHouse/pull/81174) ([larryluogit](https://github.com/larryluogit)).
* Retroportado em [#81538](https://github.com/ClickHouse/ClickHouse/issues/81538): Atualização do libxml2 para 2.14.3. [#81187](https://github.com/ClickHouse/ClickHouse/pull/81187) ([larryluogit](https://github.com/larryluogit)).
* Retroportado em [#81317](https://github.com/ClickHouse/ClickHouse/issues/81317): MemoryResidentWithoutPageCache fornece a quantidade de memória física usada pelo processo do servidor, excluindo o cache de páginas em espaço de usuário, em bytes. Isso oferece uma visão mais precisa do uso real de memória quando o cache de páginas em espaço de usuário é utilizado. Quando o cache de páginas em espaço de usuário está desabilitado, esse valor é igual a MemoryResident. [#81233](https://github.com/ClickHouse/ClickHouse/pull/81233) ([Jayme Bird](https://github.com/jaymebrd)).
* Retroportado em [#81411](https://github.com/ClickHouse/ClickHouse/issues/81411): Em um sistema de arquivos com journal, `mkdir` é gravado no journal do sistema de arquivos, que é persistido em disco. Em caso de disco lento, isso pode demorar bastante. Faz todo sentido mover isso para fora do escopo do bloqueio de reserva. [#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#81488](https://github.com/ClickHouse/ClickHouse/issues/81488): Uso de `krb5` 1.21.3-final. [#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Retroportado em [#81480](https://github.com/ClickHouse/ClickHouse/issues/81480): Uso de `orc` 2.1.2. [#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Retroportado em [#81668](https://github.com/ClickHouse/ClickHouse/issues/81668): Adia a leitura dos arquivos de manifesto do Iceberg até a primeira consulta de leitura. [#81619](https://github.com/ClickHouse/ClickHouse/pull/81619) ([Daniil Ivanik](https://github.com/divanik)).
* Retroportado em [#81803](https://github.com/ClickHouse/ClickHouse/issues/81803): Adiciona o evento de profile `PageCacheReadBytes`. [#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#81932](https://github.com/ClickHouse/ClickHouse/issues/81932): Tenta corrigir um erro lógico no filesystem cache: &quot;Having zero bytes but range is not finished&quot;. [#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)).
