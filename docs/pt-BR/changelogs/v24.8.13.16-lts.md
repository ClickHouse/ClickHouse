<div id="buildtestingpackaging-improvement">
  #### Melhoria de Compilação/Testes/Empacotamento
</div>

* Retroportado em [#75285](https://github.com/ClickHouse/ClickHouse/issues/75285): melhoria para definir valores padrão ainda mais restritivos. Os valores padrão atuais já são seguros - o usuário precisa especificar explicitamente uma opção para publicar portas. Mas, quando o usuário `default` não tiver uma senha definida por `CLICKHOUSE_PASSWORD` e/ou não tiver o nome alterado pela variável de ambiente `CLICKHOUSE_USER`, ele deve ficar disponível apenas no sistema local, como um nível adicional de proteção. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
