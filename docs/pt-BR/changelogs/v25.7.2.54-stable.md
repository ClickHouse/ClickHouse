<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#84783](https://github.com/ClickHouse/ClickHouse/issues/84783): Esta alteração adiciona uma métrica dimensional para o tamanho de `ConcurrentBoundedQueue`, identificada pelo tipo de fila (isto é, para que a fila é usada) e pelo ID da fila (isto é, um ID gerado aleatoriamente para a instância atual da fila). [#84675](https://github.com/ClickHouse/ClickHouse/pull/84675) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Retroportado em [#85007](https://github.com/ClickHouse/ClickHouse/issues/85007): Adiciona 4LW no Keeper, `lgrq`, para ativar/desativar o logging das solicitações recebidas. [#84719](https://github.com/ClickHouse/ClickHouse/pull/84719) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado em [#84869](https://github.com/ClickHouse/ClickHouse/issues/84869): Reduz a contenção no bloqueio de armazenamento no Keeper. [#84732](https://github.com/ClickHouse/ClickHouse/pull/84732) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado em [#85001](https://github.com/ClickHouse/ClickHouse/issues/85001): Limita o tamanho do cache de entradas de log do Keeper com base no número de entradas, usando `keeper_server.coordination_settings.latest_logs_cache_entry_count_threshold` e `keeper_server.coordination_settings.commit_logs_cache_entry_count_threshold`. [#84877](https://github.com/ClickHouse/ClickHouse/pull/84877) ([Antonio Andelic](https://github.com/antonio2368)).
