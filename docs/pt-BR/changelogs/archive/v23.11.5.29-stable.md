<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#58815](https://github.com/ClickHouse/ClickHouse/issues/58815): Adiciona `SYSTEM JEMALLOC PURGE` para liberar páginas jemalloc não utilizadas, `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` para controlar o profile do jemalloc se o profiler estiver habilitado. Adiciona comando 4LW relacionado ao jemalloc no Keeper: `jmst` para gerar um dump das estatísticas do jemalloc, `jmfp`, `jmep`, `jmdp` para controlar o profile do jemalloc se o profiler estiver habilitado. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado em [#59234](https://github.com/ClickHouse/ClickHouse/issues/59234): Permite ignorar a evolução de schema no table engine Iceberg e ler todos os dados usando o schema especificado pelo usuário na criação da tabela ou o schema mais recente convertido dos metadata na criação da tabela. Isso é feito com a configuração `iceberg_engine_ignore_schema_evolution`, que vem desabilitada por padrão. Observe que habilitar essa configuração pode levar a resultados incorretos, pois, no caso de schema evoluído, todos os data files serão lidos usando o mesmo schema. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
