* Adiciona suporte a projeções para tabelas MergeTree*. [#20202](https://github.com/ClickHouse/ClickHouse/pull/20202) ([Amos Bird](https://github.com/amosbird)).

Fecha a issue [#21613](https://github.com/ClickHouse/ClickHouse/issues/21613). [#22242](https://github.com/ClickHouse/ClickHouse/pull/22242) ([hexiaoting](https://github.com/hexiaoting)).

Adiciona suporte a `EXCHANGE DICTIONARIES` para o mecanismo de banco de dados Atomic. Adiciona suporte para mover dicionários entre bancos de dados usando `RENAME DICTIONARY`. [#23436](https://github.com/ClickHouse/ClickHouse/pull/23436) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Habilita a configuração `compile_expressions` por padrão. Quando essa configuração está habilitada, composições de funções simples e operadores são compiladas em código nativo com LLVM em tempo de execução. [#8482](https://github.com/ClickHouse/ClickHouse/pull/8482) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Leitura do input format ORC por stripe, em vez de carregar a tabela inteira na memória de uma só vez, o que consome muita memória quando o arquivo é muito grande. [#23102](https://github.com/ClickHouse/ClickHouse/pull/23102) ([Chao Ma](https://github.com/godliness)).
* Atualiza a biblioteca `re2`. O desempenho da correspondência de expressões regulares foi melhorado. Além disso, este PR adiciona compatibilidade com gcc-11. [#24196](https://github.com/ClickHouse/ClickHouse/pull/24196) ([Raúl Marín](https://github.com/Algunenano)).

* Se o usuário configurasse por engano `max_distributed_connections` com o valor zero, toda consulta a uma tabela `Distributed` lançaria uma exceção com uma mensagem contendo &quot;logical error&quot;. Mas isso é, na verdade, um comportamento esperado, não um erro lógico, então a mensagem da exceção estava ligeiramente incorreta. Isso também acionava verificações em nosso ambiente de CI que garantem que nunca ocorram erros lógicos. Em vez disso, `max_distributed_connections` configurado incorretamente como zero será tratado como o menor valor possível (um). [#23348](https://github.com/ClickHouse/ClickHouse/pull/23348) ([Azat Khuzhin](https://github.com/azat)).
* Manter o fuso horário padrão nas operações com `DateTime` se ele não tiver sido fornecido explicitamente. Por exemplo, se você adicionar um segundo a um valor do tipo `DateTime` sem fuso horário, ele continuará sendo `DateTime` sem fuso horário. Nas versões anteriores, o valor do fuso horário padrão era inserido explicitamente no tipo de dados retornado, de modo que ele se tornava DateTime(&#39;something&#39;). Isso resolve [#4854](https://github.com/ClickHouse/ClickHouse/issues/4854). [#23392](https://github.com/ClickHouse/ClickHouse/pull/23392) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
