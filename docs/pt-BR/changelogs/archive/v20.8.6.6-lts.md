  ### Lançamento do ClickHouse v20.8.6.6-lts FIXME em relação à v20.8.5.45-lts
</div>

<div id="bug-fix">
  #### Correção de bug
</div>

* Retroportado em [#16494](https://github.com/ClickHouse/ClickHouse/issues/16494): Corrige um bug no banco de dados MySQL. Quando o servidor MySQL usado como engine de banco de dados fica indisponível, algumas consultas geram Exception, porque tentam obter tabelas de um servidor desabilitado, embora isso seja desnecessário. Por exemplo, a consulta `SELECT ... FROM system.parts` deve funcionar apenas com tabelas MergeTree e não acessar o banco de dados MySQL de forma alguma. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado em [#16816](https://github.com/ClickHouse/ClickHouse/issues/16816): Corrige o comportamento inconsistente em que parte dos dados retornados podia ser descartada porque o Set para sua filtragem não era criado. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado em [#16506](https://github.com/ClickHouse/ClickHouse/issues/16506): Corrige o processamento de entradas muito grandes na fila de replicação. Entradas muito grandes podem aparecer em consultas ALTER se a estrutura da tabela for extremamente grande (próxima de 1 MB). Isso corrige [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#16472](https://github.com/ClickHouse/ClickHouse/issues/16472): Corrige DROP TABLE para Distributed (condição de corrida com INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado em [#16573](https://github.com/ClickHouse/ClickHouse/issues/16573): Corrige o rápido crescimento dos metadados ao usar MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine, com `slave_parallel_worker` habilitado no MySQL Slave, reduzindo corretamente os conjuntos de GTID. Isso corrige [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Retroportado em [#16552](https://github.com/ClickHouse/ClickHouse/issues/16552): Agora, ao analisar AVRO da entrada, o LowCardinality é removido do tipo. Corrige [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Retroportado em [#16823](https://github.com/ClickHouse/ClickHouse/issues/16823): Corrige [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado em [#16892](https://github.com/ClickHouse/ClickHouse/issues/16892): Corrige crashes silenciosos raros quando o query profiler está ativado e o ClickHouse está instalado em um sistema operacional com uma versão da glibc que tem (supostamente) tabelas de desempilhamento assíncrono defeituosas para algumas funções. Isso corrige [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Isso corrige [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
