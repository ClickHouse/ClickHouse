<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* * Corrige o rastreamento de memória para `OPTIMIZE TABLE`/merges - passa a considerar os limites de memória da consulta e a amostragem para `OPTIMIZE TABLE`/merges. [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* Proíbe `lcm`/`gcd` para valores de ponto flutuante. [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* Funções bit a bit (`bitAnd`, `bitOr` etc.) não são permitidas com argumentos de ponto flutuante. Agora é necessário fazer CAST explícito para inteiro. [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### Novo recurso
</div>

* adicionado suporte à opção --long do zstd para melhorar a compressão de colunas String, economizando espaço. [#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * Adicionado suporte ao mapeamento de nomes de grupos LDAP e de valores de atributo em geral para roles locais de usuários provenientes de diretórios de usuários LDAP. [#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* O tipo de dado `Nested` agora oferece suporte a níveis arbitrários de aninhamento. Foram introduzidas subcolunas de tipos complexos, como `size0` em `Array`, `null` em `Nullable` e nomes de elementos de `Tuple`, que podem ser lidas sem a necessidade de ler a coluna inteira. [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* Adicionado suporte a argumentos do tipo tuple nas funções `argMin` e `argMax`. [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Adicionado suporte a `Nullable` para `FlatDictionary`, `HashedDictionary`, `ComplexKeyHashedDictionary`, `DirectDictionary`, `ComplexKeyDirectDictionary`, `RangeHashedDictionary`. [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* Não permitir coluna de ponto flutuante como chave de partição, relacionado a: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* Adicionada a função decodeXMLComponent para decodificar caracteres XML. `SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* Adicionado o table engine PostgreSQL (tanto para select/insert, com suporte a arrays multidimensionais), também como table function. Adicionada a dictionary source PostgreSQL. Adicionado o database engine PostgreSQL. [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Adicionada a sintaxe `SELECT ALL`. Fecha [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706). [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* Adicionadas três funções para o tipo de dado map: 1. mapContains(map, key) para verificar se map.keys inclui o segundo parâmetro key. 2. mapKeys(map) retorna todas as chaves no formato Array 3. mapValues(map) retorna todos os valores no formato Array. [#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).
* Suporte ao atalho MetaKey+Enter na UI do play. [#19012](https://github.com/ClickHouse/ClickHouse/pull/19012) ([sundyli](https://github.com/sundy-li)).
* A função formatDateTime oferece suporte ao modificador %Q para formatar a data como trimestre. ... [#19224](https://github.com/ClickHouse/ClickHouse/pull/19224) ([Jianmei Zhang](https://github.com/zhangjmruc)).

* Adicionados ao system.query&#95;log os nomes dos objetos de factories&#39; criados durante a consulta. Fecha [#18495](https://github.com/ClickHouse/ClickHouse/issues/18495). [#19371](https://github.com/ClickHouse/ClickHouse/pull/19371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Adicionada a função matemática `sign`. [#19527](https://github.com/ClickHouse/ClickHouse/pull/19527) ([flynn](https://github.com/ucasfl)).

<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Uso de um pool de conexões para conexões S3, controlado pela configuração `s3_max_connections`. [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Reescrita das funções `sumIf()` e `sum(if())` para a função `countIf()` quando forem logicamente equivalentes. [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* Atualização do libcxx e uso de ABI instável para oferecer melhor desempenho. [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* Remoção mais rápida de partes ao reduzir o número de syscalls `stat`. Isso restaura uma otimização que existia anteriormente. Interface mais segura para `IDisk`. Isso fecha [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065). [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Acelera a função de agregação `sum`. Melhoria visível apenas em benchmarks sintéticos e de pouca utilidade prática. [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Suporte à divisão da etapa `Filter` do plano de consulta em um par `Expression + Filter`. Junto com a otimização de mesclagem `Expression + Expression` ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)), isso pode adiar a execução de algumas expressões para depois da etapa `Filter`. [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Reduz a contenção de locks para várias camadas do engine Buffer. [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* Melhora ligeiramente a latência do servidor ao remover o acesso à configuração a cada conexão. [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
