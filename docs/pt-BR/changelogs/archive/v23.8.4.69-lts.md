<div id="buildtestingpackaging-improvement">
  #### Melhoria de Compilação/Testes/Empacotamento
</div>

* Retroportado em [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673): Se o banco de dados já estiver inicializado, não precisará ser inicializado novamente em execuções subsequentes. Isso pode corrigir o problema de reinicializações infinitas do contêiner quando o banco de dados não consegue carregar em 1000 tentativas (relevante para bancos de dados muito grandes e configurações com vários nós). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* Retroportado em [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293): O artefato com o código-fonte, incluindo submódulos, é compilado em uma tarefa especial de compilação no Darwin. Ele pode ser usado para compilar o ClickHouse sem fazer checkout dos submódulos. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Retroportado em [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366): Resolve um problema ao iniciar o clickhouse-keeper standalone a partir do pacote clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado em [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725): Corrige o script Python da verificação de integração para usar a URL da API do gh - adiciona README para testes de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correção de bug (comportamento incorreto perceptível ao usuário em uma versão estável oficial)
</div>

* Retroportado em [#55304](https://github.com/ClickHouse/ClickHouse/issues/55304): corrige &quot;Invalid number of rows in Chunk&quot; no MaterializedPostgreSQL (o que podia acontecer com versões do PostgreSQL &gt;= 13). [#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#55018](https://github.com/ClickHouse/ClickHouse/issues/55018): move as configurações de formato obsoletas para uma seção separada e as usa junto com todas as configurações de formato para evitar exceções `Unknown setting` ao usar configurações de formato obsoletas. Fecha [#54792](https://github.com/ClickHouse/ClickHouse/issues/54792) ### Entrada de documentação para alterações voltadas ao usuário. [#54855](https://github.com/ClickHouse/ClickHouse/pull/54855) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado em [#55097](https://github.com/ClickHouse/ClickHouse/issues/55097): o quorum de insert podia ser marcado incorretamente como satisfeito em caso de novas tentativas do Keeper enquanto se aguardava o quorum. Corrige [#54543](https://github.com/ClickHouse/ClickHouse/issues/54543). [#55026](https://github.com/ClickHouse/ClickHouse/pull/55026) ([Igor Nikonov](https://github.com/devcrafter)).
* Retroportado em [#55473](https://github.com/ClickHouse/ClickHouse/issues/55473): impede anexar partições de tabelas que não tenham os mesmos índices ou projeções definidos. [#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Retroportado em [#55461](https://github.com/ClickHouse/ClickHouse/issues/55461): se ocorrer uma exceção no construtor de `ShellCommandSource` depois que alguns dos `send_data_threads` tiverem sido iniciados, é necessário chamar join() neles; caso contrário, abort() será acionado no destrutor de `ThreadFromGlobalPool`. Corrige [#55091](https://github.com/ClickHouse/ClickHouse/issues/55091). [#55103](https://github.com/ClickHouse/ClickHouse/pull/55103) ([Alexander Gololobov](https://github.com/davenger)).
* Retroportado em [#55412](https://github.com/ClickHouse/ClickHouse/issues/55412): corrige um interbloqueio na atualização de role atribuída por LDAP para ClickHouse roles inexistentes. [#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* Retroportado em [#55323](https://github.com/ClickHouse/ClickHouse/issues/55323): correção para download em segundo plano no cache fs. [#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#55349](https://github.com/ClickHouse/ClickHouse/issues/55349): corrige a execução de funções em colunas esparsas (corrige o erro `DB::Exception: isDefaultAt is not implemented for Function: while executing 'FUNCTION Capture`). [#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado em [#55475](https://github.com/ClickHouse/ClickHouse/issues/55475): corrige um problema que impedia remover partição desanexada na família de motores `ReplicatedMergeTree` sobre S3 (sem zero-copy replication). Corrige o problema [#55225](https://github.com/ClickHouse/ClickHouse/issues/55225). Corrige um bug com blobs abandonados no S3 para tipos de dados complexos, como Arrays ou colunas Nested. Corrige parcialmente [#52393](https://github.com/ClickHouse/ClickHouse/issues/52393). Muitos agradecimentos a @alifirat pelos exemplos. [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* Retroportado em [#55399](https://github.com/ClickHouse/ClickHouse/issues/55399): uma otimização introduzida há um ano estava incorreta. Isso fecha [#55272](https://github.com/ClickHouse/ClickHouse/issues/55272). [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#55437](https://github.com/ClickHouse/ClickHouse/issues/55437): Corrige a análise sintática de arrays no operador CAST (`::`). [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado em [#55635](https://github.com/ClickHouse/ClickHouse/issues/55635): Corrige a filtragem por colunas virtuais com filtro OR na consulta (filtragem de `_part*` para `MergeTree`, de `_path`/`_file` para vários motores `File`/`HDFS`/..., e de `_table` para `Merge`). [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado em [#55445](https://github.com/ClickHouse/ClickHouse/issues/55445): Corrige problemas de conexão que ocorriam com algumas versões do MongoDB. Fecha [#55376](https://github.com/ClickHouse/ClickHouse/issues/55376), [#55232](https://github.com/ClickHouse/ClickHouse/issues/55232). [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado em [#55534](https://github.com/ClickHouse/ClickHouse/issues/55534): Corrige um possível deadlock causado por uma fiber não destruída em caso de exceção durante o cancelamento assíncrono de tarefa. Fecha [#55185](https://github.com/ClickHouse/ClickHouse/issues/55185). [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado em [#55747](https://github.com/ClickHouse/ClickHouse/issues/55747): Corrige falha no QueryNormalizer com aliases cíclicos. [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* Retroportado em [#55760](https://github.com/ClickHouse/ClickHouse/issues/55760): Corrige a filtragem por colunas virtuais com filtro OR na consulta (filtragem de &#95;part* para MergeTree, de &#95;path/&#95;file para vários motores File/HDFS/..., e de &#95;table para Merge). [#55678](https://github.com/ClickHouse/ClickHouse/pull/55678) ([Azat Khuzhin](https://github.com/azat)).
