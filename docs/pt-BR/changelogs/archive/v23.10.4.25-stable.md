</div>

* Retroportado em [#56633](https://github.com/ClickHouse/ClickHouse/issues/56633): Em [#54043](https://github.com/ClickHouse/ClickHouse/issues/54043), o plano de setup passou a aparecer nos logs. [#56214](https://github.com/ClickHouse/ClickHouse/pull/56214) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">

</div>

* SELECT em tabelas do sistema quando a tabela é baseada em uma função de tabela. [#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Corrige a restauração a partir de backup com `flatten_nested` e `data_type_default_nullable` [#56306](https://github.com/ClickHouse/ClickHouse/pull/56306) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Corrige segfault durante a inicialização do Kerberos [#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* Corrige problema de carregamento dinâmico do OpenSSL no RabbitMQ [#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* Corrige crash no codec GCD no caso de haver zeros nos dados [#56704](https://github.com/ClickHouse/ClickHouse/pull/56704) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Corrige crash no codec FPC [#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
