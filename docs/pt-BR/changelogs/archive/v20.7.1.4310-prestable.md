<div id="clickhouse-release-v20714310-prestable-fixme-as-compared-to-v20614066-prestable">
  ### Lançamento do ClickHouse v20.7.1.4310-prestable FIXME em relação ao v20.6.1.4066-prestable
</div>

<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* Descontinuada a exibição especial de valores zero de Date/DateTime como `0000-00-00` e `0000-00-00 00:00:00`. [#12442](https://github.com/ClickHouse/ClickHouse/pull/12442) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* A função `modulo` (operador `%`), com pelo menos um número de ponto flutuante como argumento, calculará o resto da divisão diretamente sobre números de ponto flutuante, sem converter ambos os argumentos em inteiros. Isso torna o comportamento compatível com a maioria dos DBMS. Isso também se aplica aos tipos de dados Date e DateTime. Adicionado o alias `mod`. Isso fecha a [#7323](https://github.com/ClickHouse/ClickHouse/issues/7323). [#12585](https://github.com/ClickHouse/ClickHouse/pull/12585) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Novo recurso
</div>

* * Adicionado suporte à autenticação LDAP para usuários pré-configurados (método &quot;Simple Bind&quot;). [#11234](https://github.com/ClickHouse/ClickHouse/pull/11234) ([Denis Glazachev](https://github.com/traceon)).
* Adicionadas as funções mapAdd e mapSubtract para trabalhar com mapas de tuplas. [#11735](https://github.com/ClickHouse/ClickHouse/pull/11735) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Adicionada a tabela `system.crash_log`, na qual são coletados stack traces de erros fatais. [#12316](https://github.com/ClickHouse/ClickHouse/pull/12316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adicionada a função `bayesAB` para testes A/B bayesianos. [#12327](https://github.com/ClickHouse/ClickHouse/pull/12327) ([achimbab](https://github.com/achimbab)).
* Integração com [COS](https://intl.cloud.tencent.com/product/cos). [#12386](https://github.com/ClickHouse/ClickHouse/pull/12386) ([fastio](https://github.com/fastio)).
* * Adicionada a função FROM&#95;UNIXTIME, relacionada a [12149](https://github.com/ClickHouse/ClickHouse/issues/12149). [#12484](https://github.com/ClickHouse/ClickHouse/pull/12484) ([flynn](https://github.com/ucasfl)).
* Foi adicionada a função `formatRow` para oferecer suporte à conversão de expressões arbitrárias em uma string por meio de um formato especificado. Ela é útil para manipular saídas SQL e é bastante versátil quando combinada com a função `columns`. [#12574](https://github.com/ClickHouse/ClickHouse/pull/12574) ([Amos Bird](https://github.com/amosbird)).
* Adicionada a configuração `allow_non_metadata_alters`, que restringe a execução de consultas `ALTER` que modificam dados em disco. Desabilitada por padrão. Fecha [#11547](https://github.com/ClickHouse/ClickHouse/issues/11547). [#12635](https://github.com/ClickHouse/ClickHouse/pull/12635) ([alesapin](https://github.com/alesapin)).
* Adicionado suporte às funções `minMap` e `maxMap` em `SimpleAggregateFunction`. [#12662](https://github.com/ClickHouse/ClickHouse/pull/12662) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Adicionados os cabeçalhos HTTP `X-ClickHouse-Database` e `X-ClickHouse-Format`, que podem ser usados para definir o banco de dados padrão e o formato de saída. [#12981](https://github.com/ClickHouse/ClickHouse/pull/12981) ([hcz](https://github.com/hczhcz)).
* Implementadas configurações definidas pelo usuário. [#13013](https://github.com/ClickHouse/ClickHouse/pull/13013) ([Vitaly Baranov](https://github.com/vitlibar)).
