<div id="buildtestingpackaging-improvement">
  #### Melhoria de compilação/testes/empacotamento
</div>

* Retroportado em [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530): Divisão de um `RUN` enorme no Dockerfile em condicionais menores. Instalação das ferramentas necessárias sob demanda na mesma camada `RUN` e remoção delas em seguida. Upgrade do SO apenas uma vez, no início. Uso de uma forma moderna de verificar o repositório assinado. Downgrade do repositório base para ubuntu:20.04 para resolver problemas em versões mais antigas do docker. Upgrade da versão do golang para corrigir vulnerabilidades do golang. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado em [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570): Este é um ajuste complementar de [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504); a limpeza foi perdida durante a refatoração. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correção de bug (comportamento incorreto perceptível ao usuário em um lançamento estável oficial)
</div>

* Corrige a análise de índice que falhava quando o operador binário continha um argumento constante NULL [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* Corrige a reconexão da sessão HTTPS quando o IP do host de destino era alterado [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Corrige o constant folding incorreto [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corrige o tipo do hash dos parâmetros do servidor LDAP na entrada de cache [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* Passa a interpretar inteiros grandes a partir de String em vez de gerar uma exceção no formato Parquet [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* Não aplica a projeção se read-in-order estiver habilitado. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Corrige falha do fuzzer em ActionsDAG [#51301](https://github.com/alexey-milovidov)).
