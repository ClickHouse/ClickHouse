<div id="new-feature">
  #### Novo recurso
</div>

* (Ainda não está pronto para produção; incluído em recursos experimentais) Adiciona overcommit de memória ao `MemoryTracker`. Foram adicionadas configurações `guaranteed` para limites de memória, que representam limites flexíveis de memória. Quando o limite rígido de memória é atingido, o `MemoryTracker` tenta cancelar a consulta com maior overcommit. A nova configuração `memory_usage_overcommit_max_wait_microseconds` especifica por quanto tempo as consultas podem esperar outra consulta parar. Fecha [#28375](https://github.com/ClickHouse/ClickHouse/issues/28375). [#31182](https://github.com/ClickHouse/ClickHouse/pull/31182) ([Dmitry Novik](https://github.com/novikd)).
* A configuração permite que o usuário defina sua própria semântica de desduplicação em MergeTree/ReplicatedMergeTree. Se fornecida, ela é usada no lugar do digest dos dados para gerar o ID do bloco. Assim, por exemplo, ao fornecer um valor único para a configuração em cada instrução INSERT, o usuário pode evitar que os mesmos dados inseridos sejam desduplicados. Fecha [#7461](https://github.com/ClickHouse/ClickHouse/issues/7461). [#32304](https://github.com/ClickHouse/ClickHouse/pull/32304) ([Igor Nikonov](https://github.com/devcrafter)).
* Adiciona suporte à palavra-chave DEFAULT para instruções INSERT. Fecha [#6331](https://github.com/ClickHouse/ClickHouse/issues/6331). [#33141](https://github.com/ClickHouse/ClickHouse/pull/33141) ([Andrii Buriachevskyi](https://github.com/0over)).
* Adiciona intervalos de confiança aos t-tests. [#33260](https://github.com/ClickHouse/ClickHouse/pull/33260) ([achimbab](https://github.com/achimbab)).
* Permite criar novos arquivos na inserção para os motores File/S3/HDFS. Permite sobrescrever arquivos no HDFS. Por padrão, gera uma exceção ao tentar sobrescrever um arquivo no S3. Gera uma exceção ao tentar acrescentar dados a um arquivo em formatos que têm sufixo. Fecha [#31640](https://github.com/ClickHouse/ClickHouse/issues/31640) Fecha [#31622](https://github.com/ClickHouse/ClickHouse/issues/31622) Fecha [#23862](https://github.com/ClickHouse/ClickHouse/issues/23862) Fecha [#15022](https://github.com/ClickHouse/ClickHouse/issues/15022) Fecha [#16674](https://github.com/ClickHouse/ClickHouse/issues/16674). [#33302](https://github.com/ClickHouse/ClickHouse/pull/33302) ([Kruglov Pavel](https://github.com/Avogar)).
* Adiciona a função `h3ToCenterChild`. [#33313](https://github.com/ClickHouse/ClickHouse/pull/33313) ([Bharat Nallan](https://github.com/bharatnc)).
* Funções de merge para classificação de texto. Veja [#23271](https://github.com/ClickHouse/ClickHouse/issues/23271). [#33314](https://github.com/ClickHouse/ClickHouse/pull/33314) ([Nikolay Degterinsky](https://github.com/evillique)).
* Implementa meanZTest. [#33354](https://github.com/ClickHouse/ClickHouse/pull/33354) ([achimbab](https://github.com/achimbab)).
* * Adicionada a função bitSlice. [#33360](https://github.com/ClickHouse/ClickHouse/pull/33360) ([RogerYK](https://github.com/RogerYK)).
* Adicionadas novas funções diversas de h3: `edgeLengthKm`,`exactEdgeLengthKm`,`exactEdgeLengthM`,`exactEdgeLengthRads`,`numHexagons`. [#33621](https://github.com/ClickHouse/ClickHouse/pull/33621) ([Bharat Nallan](https://github.com/bharatnc)).
* Adicionadas as funções `DEGREES` e `RADIANS`. [#33769](https://github.com/ClickHouse/ClickHouse/pull/33769) ([Bharat Nallan](https://github.com/bharatnc)).
* O parâmetro `--host` pode aceitar vários hosts. Se um deles estiver indisponível, o client tentará se conectar ao próximo. [#33824](https://github.com/ClickHouse/ClickHouse/pull/33824) ([Filippov Denis](https://github.com/DF5HSE)).

<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Para inserts e merges no S3, grave os arquivos em paralelo sempre que possível. [#33291](https://github.com/ClickHouse/ClickHouse/pull/33291) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Melhora o desempenho do RangeHashedDictionary quando há muitos intervalos para a chave. Corrige [#23821](https://github.com/ClickHouse/ClickHouse/issues/23821). [#33516](https://github.com/ClickHouse/ClickHouse/pull/33516) ([Maksim Kita](https://github.com/kitaisreal)).
* Adiciona suporte a x86 avx512 para as funções memcmpSmall, acelerando a comparação de memória. Isso funciona apenas se você compilar o ClickHouse por conta própria. [#33706](https://github.com/ClickHouse/ClickHouse/pull/33706) ([hanqf-git](https://github.com/hanqf-git)).
* Retrabalha e reintroduz o cache escalar na execução de MV. [#33958](https://github.com/ClickHouse/ClickHouse/pull/33958) ([Raúl Marín](https://github.com/Algunenano)).
* Torna o ORDER BY de tuple quase tão rápido quanto o ORDER BY de colunas. Temos otimizações especiais para ORDER BY com múltiplas colunas: [https://github.com/ClickHouse/ClickHouse/pull/10831](https://github.com/ClickHouse/ClickHouse/pull/10831) . Também é vantajoso aplicá-las a colunas do tipo tuple. [#34060](https://github.com/ClickHouse/ClickHouse/pull/34060) ([Amos Bird](https://github.com/amosbird)).
* Pequena melhoria em um possível caminho crítico em `ExecuteScalarSubqueriesMatcher::visit`, no qual `std::set<String>` era construído a cada invocação da função. [#34128](https://github.com/ClickHouse/ClickHouse/pull/34128) ([Federico Rodriguez](https://github.com/fedrod)).
* Melhora ligeiramente o desempenho do formato `Regexp`. [#34202](https://github.com/ClickHouse/ClickHouse/pull/34202) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* quantilesExact{Low,High} foi otimizado para usar nth&#95;element em vez de sort. [#34287](https://github.com/ClickHouse/ClickHouse/pull/34287) ([Daniel Kutenin](https://github.com/danlark1)).
* Melhora o desempenho do formato `LineAsString`. Isso fecha [#34303](https://github.com/ClickHouse/ClickHouse/issues/34303). [#34306](https://github.com/ClickHouse/ClickHouse/pull/34306) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Acelera o carregamento de partes de dados. Antes, isso não era paralelizado: a configuração `part_loading_threads` não surtia efeito. Veja [#4699](https://github.com/ClickHouse/ClickHouse/issues/4699). [#34310](https://github.com/ClickHouse/ClickHouse/pull/34310) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* As colunas virtuais `_file` e `_path` (em motores de tabela semelhantes a arquivos) passam a ser `LowCardinality`, o que tornará mais rápidas as consultas em vários arquivos. Fecha [#34300](https://github.com/ClickHouse/ClickHouse/issues/34300). [#34317](https://github.com/ClickHouse/ClickHouse/pull/34317) ([flynn](https://github.com/ucasfl)).
* Melhora o desempenho da função `mapPopulateSeries`. Fecha [#33944](https://github.com/ClickHouse/ClickHouse/issues/33944). [#34318](https://github.com/ClickHouse/ClickHouse/pull/34318) ([Maksim Kita](https://github.com/kitaisreal)).
* Usa um vetor para coletar iteradores de lista desnecessários ao fazer um snapshot e, depois, em clearOutdatedNodes, basta percorrer o vetor, e não a lista, o que é mais rápido. [#34484](https://github.com/ClickHouse/ClickHouse/pull/34484) ([zhanglistar](https://github.com/zhanglistar)).
* Melhora o desempenho de insert em table functions URL, S3, File e HDFS. Fecha [#34348](https://github.com/ClickHouse/ClickHouse/issues/34348). [#34510](https://github.com/ClickHouse/ClickHouse/pull/34510) ([Maksim Kita](https://github.com/kitaisreal)).
* De acordo com [https://github.com/eBay/NuRaft/issues/209](https://github.com/eBay/NuRaft/issues/209), não é necessário usar lock no método. [#34523](https://github.com/ClickHouse/ClickHouse/pull/34523) ([zhanglistar](https://github.com/zhanglistar)).
