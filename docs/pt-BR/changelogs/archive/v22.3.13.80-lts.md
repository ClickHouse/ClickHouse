<div id="new-feature">
  #### Novo recurso
</div>

* Retroportado em [#41264](https://github.com/ClickHouse/ClickHouse/issues/41264): Implementada a conversão automática do engine de banco de dados de `Ordinary` para `Atomic`. Crie um arquivo vazio `convert_ordinary_to_atomic` no diretório `flags`, e todos os bancos de dados `Ordinary` serão convertidos automaticamente na próxima inicialização do servidor. Resolve [#39546](https://github.com/ClickHouse/ClickHouse/issues/39546). [#39933](https://github.com/ClickHouse/ClickHouse/pull/39933) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado em [#40886](https://github.com/ClickHouse/ClickHouse/issues/40886): Adicionada uma configuração para desabilitar o limite de kafka&#95;num&#95;consumers. Fecha [#40331](https://github.com/ClickHouse/ClickHouse/issues/40331). [#40670](https://github.com/ClickHouse/ClickHouse/pull/40670) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="bug-fix">
  #### Correção de bug
</div>

Isso corrige [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004). [#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* Retroportado em [#41807](https://github.com/ClickHouse/ClickHouse/issues/41807): dados maliciosos no formato Native podem causar uma falha. [#41441](https://github.com/ClickHouse/ClickHouse/pull/41441) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#41804](https://github.com/ClickHouse/ClickHouse/issues/41804): a função de agregação `categorialInformationValue` estava com propriedades definidas incorretamente, o que poderia causar a desreferenciação de um ponteiro nulo em tempo de execução. Fecha [#41443](https://github.com/ClickHouse/ClickHouse/issues/41443). [#41449](https://github.com/ClickHouse/ClickHouse/pull/41449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#41503](https://github.com/ClickHouse/ClickHouse/issues/41503): a gravação de dados no formato Apache `ORC` pode levar a um estouro de buffer. [#41458](https://github.com/ClickHouse/ClickHouse/pull/41458) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#41639](https://github.com/ClickHouse/ClickHouse/issues/41639): corrige uma possível exceção `pipeline stuck` em consultas com `OFFSET`. O erro foi encontrado com `enable_optimize_predicate_expression = 0` e uma condição sempre falsa em `WHERE`. Corrige [#41383](https://github.com/ClickHouse/ClickHouse/issues/41383). [#41588](https://github.com/ClickHouse/ClickHouse/pull/41588) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Retroportado em [#41899](https://github.com/ClickHouse/ClickHouse/issues/41899): corrige uma possível falha em `SELECT` de uma tabela `Merge` com a configuração `optimize_monotonous_functions_in_order_by` habilitada. Corrige [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269). [#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
