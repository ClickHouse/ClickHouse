<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#62188](https://github.com/ClickHouse/ClickHouse/issues/62188): o StorageJoin com strictness `ANY` permanece consistente após ser recarregado. Quando várias linhas com a mesma chave são inseridas, a primeira terá prioridade maior (antes, ela era escolhida aleatoriamente durante o carregamento da tabela). fecha [#51027](https://github.com/ClickHouse/ClickHouse/issues/51027). [#61972](https://github.com/ClickHouse/ClickHouse/pull/61972) ([vdimir](https://github.com/vdimir)).
* Retroportado em [#62443](https://github.com/ClickHouse/ClickHouse/issues/62443): o cliente precisa enviar o cabeçalho &#39;Keep-Alive: timeout=X&#39; para o servidor. Se um cliente receber uma resposta do servidor com esse cabeçalho, deverá usar o valor informado pelo servidor. Além disso, é melhor que o cliente não use uma conexão prestes a expirar, para evitar uma condição de corrida no fechamento da conexão. [#62249](https://github.com/ClickHouse/ClickHouse/pull/62249) ([Sema Checherinda](https://github.com/CheSema)).
* Retroportado em [#62666](https://github.com/ClickHouse/ClickHouse/issues/62666): o armazenamento S3 e os backups também precisam das mesmas configurações padrão de Keep-Alive que o disco S3. [#62648](https://github.com/ClickHouse/ClickHouse/pull/62648) ([Sema Checherinda](https://github.com/CheSema)).
