<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correção de bug (comportamento incorreto perceptível ao usuário em uma versão estável oficial)
</div>

* Retroportado em [#62898](https://github.com/ClickHouse/ClickHouse/issues/62898): Corrige um bug na replicação zero-copy (um recurso experimental) que podia causar erros `The specified key does not exist` e perda de dados após REPLACE/MOVE PARTITION. Um problema semelhante pode ocorrer com TTL-moves entre disks. [#54193](https://github.com/ClickHouse/ClickHouse/pull/54193) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado em [#61964](https://github.com/ClickHouse/ClickHouse/issues/61964): Corrige a consulta ATTACH com a cláusula ON CLUSTER quando o banco de dados não existe no nó iniciador. Fecha [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009). [#61365](https://github.com/ClickHouse/ClickHouse/pull/61365) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado em [#62527](https://github.com/ClickHouse/ClickHouse/issues/62527): Corrige uma data race entre a consulta `MOVE PARTITION` e merges, resultando em partes sobrepostas. [#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Retroportado em [#62238](https://github.com/ClickHouse/ClickHouse/issues/62238): Corrige o ignoramento de erros de parsing de sequências de escape durante o parsing de dados JSON ao usar as configurações `input_format_allow_errors_num/ratio`. [#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado em [#62673](https://github.com/ClickHouse/ClickHouse/issues/62673): Corrige falha de segmentação ao usar o engine de tabela Hive. Consulte [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154), [#62560](https://github.com/ClickHouse/ClickHouse/issues/62560). [#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)).
