* Retroportado em [#43829](https://github.com/ClickHouse/ClickHouse/issues/43829): normaliser atualizado para clonar o AST do alias. Resolve [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452). Implementação: * QueryNormalizer atualizado para clonar o AST do alias quando ele é substituído. Antes, simplesmente atribuir o mesmo AST levava a uma exceção no LogicalExpressinsOptimizer, pois o mesmo nó pai seria inserido novamente. * Esse bug não ocorre com o novo analyzer (allow&#95;experimental&#95;analyzer), portanto nenhuma alteração foi feita nele. Adicionei também um teste para isso. [#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
