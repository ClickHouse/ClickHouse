<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Retroportado em [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534): Corrigido o cálculo do tamanho em memória de colunas `LowCardinality`. [#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)).
* Retroportado em [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005): Foi identificado que o controle de concorrência podia levar a uma distribuição desigual de CPU entre INSERTs e SELECTs. Quando todos os slots de CPU são alocados incondicionalmente (sem competição) para INSERTs com `max_threads` = 1, SELECTs com valores altos de `max_threads` acabam sofrendo com baixo desempenho por usarem apenas uma única thread. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535): Contabilização mais precisa da configuração `max_joined_block_size_rows` para o algoritmo de JOIN `parallel_hash`. Ajuda a evitar aumento no consumo de memória em comparação com o algoritmo `hash`. [#74630](https://github.com/ClickHouse/ClickHouse/pull/74630) ([Nikita Taranov](https://github.com/nickitat)).
* Retroportado em [#75844](https://github.com/ClickHouse/ClickHouse/issues/75844): Adiciona verificação e logging para descriptografia e descompressão. [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado em [#76046](https://github.com/ClickHouse/ClickHouse/issues/76046): Melhoria no Keeper: desabilita o cálculo de digest ao fazer commit no armazenamento em memória para melhorar o desempenho. Ele pode ser habilitado com a config `keeper_server.digest_enabled_on_commit`. O digest ainda é calculado no pré-processamento de requests. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado em [#75709](https://github.com/ClickHouse/ClickHouse/issues/75709): Desabilita o envio de configurações do servidor para o client (`send_settings_to_client=false`) por compatibilidade (esse recurso será reimplementado posteriormente como client setting para melhor usabilidade). [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* Retroportado em [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805): Adiciona a config `memory_worker_correct_memory_tracker` para habilitar a correção do memory tracker interno com informações de diferentes fontes lidas periodicamente em background thread. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado em [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069): Adiciona a Metric `MemoryTrackingUncorrected`, que mostra o valor do memory tracker global interno que não é corrigido por RSS. [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).
