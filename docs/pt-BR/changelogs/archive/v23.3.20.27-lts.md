<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#58818](https://github.com/ClickHouse/ClickHouse/issues/58818): adiciona `SYSTEM JEMALLOC PURGE` para liberar páginas jemalloc não utilizadas, `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` para controlar o perfil do jemalloc se o profiler estiver habilitado. Adiciona o comando 4LW relacionado ao jemalloc no Keeper: `jmst` para gerar dump das estatísticas do jemalloc, `jmfp`, `jmep`, `jmdp` para controlar o perfil do jemalloc se o profiler estiver habilitado. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### Melhoria de compilação/testes/empacotamento
</div>

* Retroportado em [#59877](https://github.com/ClickHouse/ClickHouse/issues/59877): Se você quiser executar os scripts `initdb` sempre que o contêiner do ClickHouse for iniciado, deverá definir a variável de ambiente `CLICKHOUSE_ALWAYS_RUN_INITDB_SCRIPTS`. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).
