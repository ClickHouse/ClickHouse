<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* * Corrigido o rastreamento de memória para `OPTIMIZE TABLE`/merges - agora considera os limites de memória da consulta e a amostragem para `OPTIMIZE TABLE`/merges. [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* `lcm`/`gcd` passam a ser proibidos para valores de ponto flutuante. [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* Funções bit a bit (`bitAnd`, `bitOr` etc.) são proibidas para argumentos de ponto flutuante. Agora é necessário fazer um CAST explícito para inteiro. [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### Novo recurso
</div>

* adiciona suporte à opção `long` do zstd para melhorar a compressão de colunas String e economizar espaço. [#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * Adicionado suporte ao mapeamento de nomes de grupos LDAP e de valores de atributos em geral para roles locais de usuários de diretórios de usuários LDAP. [#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* O tipo de dado `Nested` agora oferece suporte a níveis arbitrários de aninhamento. Foram introduzidas subcolunas de tipos complexos, como `size0` em `Array`, `null` em `Nullable` e nomes de elementos de `Tuple`, que podem ser lidas sem precisar ler a coluna inteira. [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* Adicionado suporte a argumentos `Tuple` nas funções `argMin` e `argMax`. [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Adicionado suporte a `Nullable` para `FlatDictionary`, `HashedDictionary`, `ComplexKeyHashedDictionary`, `DirectDictionary`, `ComplexKeyDirectDictionary` e `RangeHashedDictionary`. [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* Proibido o uso de coluna de ponto flutuante como chave de partição, relacionado a: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* Adicionada a função decodeXMLComponent para decodificar caracteres XML. `SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* Adicionado o PostgreSQL table engine (tanto para select/insert, com suporte a arrays multidimensionais), também como table function. Adicionado PostgreSQL dictionary source. Adicionado PostgreSQL database engine. [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Adicionada a sintaxe `SELECT ALL`. Fecha [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706). [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).
* Adicionadas três funções para o tipo de dado map: 1. mapContains(map, key) para verificar se map.keys inclui o segundo parâmetro key. 2. mapKeys(map) retorna todas as keys no formato Array 3. mapValues(map) retorna todos os values no formato Array. [#18788](https://github.com/ClickHouse/ClickHouse/pull/18788) ([hexiaoting](https://github.com/hexiaoting)).

<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Uso de um pool de conexões para conexões com o S3, controlado pela configuração `s3_max_connections`. [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Reescrita das funções `sumIf()` e `sum(if())` para `countIf()` quando logicamente equivalentes. [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* Atualização do libcxx e uso de ABI instável para proporcionar melhor desempenho. [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* Remoção mais rápida de partes ao reduzir o número de syscalls `stat`. Isso restaura a otimização que existia há algum tempo. Interface mais segura para `IDisk`. Isso fecha [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065). [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Aceleração da função de agregação `sum`. Melhoria visível apenas em benchmarks sintéticos e pouco prática. [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Suporte à divisão da etapa `Filter` do plano de consulta em um par `Expression + Filter`. Junto com a otimização de mesclagem `Expression + Expression` ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)), isso pode adiar a execução de algumas expressões para depois da etapa `Filter`. [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Redução da contenção de locks em múltiplas camadas do engine Buffer. [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* Leve melhora na latência do servidor ao remover o acesso à configuração a cada conexão. [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
