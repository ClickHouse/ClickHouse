<div id="improvement">

* Retroportado em [#46981](https://github.com/ClickHouse/ClickHouse/issues/46981): - Aplicar `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` a todas as réplicas, porque `ALTER TABLE t MOVE` não é replicado. [#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix">
  #### Correção de bug
</div>

* Retroportado em [#47336](https://github.com/ClickHouse/ClickHouse/issues/47336): Às vezes, após alterar uma role, essa alteração podia não ser refletida nas permissões de acesso de um usuário que usa essa role. Esta PR corrige isso. [#46772](https://github.com/ClickHouse/ClickHouse/pull/46772) ([Vitaly Baranov](https://github.com/vitlibar)).
