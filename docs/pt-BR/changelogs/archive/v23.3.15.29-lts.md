<div id="buildtestingpackaging-improvement">
  #### Melhoria de compilação/testes/empacotamento
</div>

* Retroportado em [#55671](https://github.com/ClickHouse/ClickHouse/issues/55671): Se o banco de dados já estiver inicializado, não será necessário inicializá-lo novamente em execuções subsequentes. Isso pode potencialmente corrigir o problema de reinicializações infinitas do contêiner quando o banco de dados não consegue ser carregado após 1000 tentativas (relevante para bancos de dados muito grandes e configurações com vários nós). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* Retroportado em [#55734](https://github.com/ClickHouse/ClickHouse/issues/55734): Corrige o script Python de verificação de integração para usar a URL da API do gh - adiciona README para testes de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
* Retroportado em [#55829](https://github.com/ClickHouse/ClickHouse/issues/55829): Verifica o sha512 de tgz; usa um repositório adequado para Keeper; grava apenas os nomes dos arquivos nos arquivos TGZ.sha512 para pacotes tarball. Pré-requisito para [#31473](https://github.com/ClickHouse/ClickHouse/issues/31473). [#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
