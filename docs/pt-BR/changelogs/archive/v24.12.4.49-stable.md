<div id="buildtestingpackaging-improvement">
  #### Melhoria de Compilação/Testes/Empacotamento
</div>

* Retroportado em [#75289](https://github.com/ClickHouse/ClickHouse/issues/75289): Melhoria para tornar os padrões ainda mais restritivos. Os padrões atuais já são seguros — o usuário precisa especificar uma opção para publicar portas explicitamente. Mas, quando o usuário `default` não tem uma senha definida por `CLICKHOUSE_PASSWORD` e/ou um nome de usuário alterado pela variável de ambiente `CLICKHOUSE_USER`, ele deve ficar disponível apenas no sistema local como um nível adicional de proteção. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
