<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#58660](https://github.com/ClickHouse/ClickHouse/issues/58660): Ao executar algumas consultas que exigem muitos streams para ler dados, antes era gerado o erro `"Paste JOIN requires sorted tables only"`. Agora, nesses casos, o número de streams passa a 1. [#58608](https://github.com/ClickHouse/ClickHouse/pull/58608) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Retroportado em [#58817](https://github.com/ClickHouse/ClickHouse/issues/58817): Adiciona `SYSTEM JEMALLOC PURGE` para purgar páginas não utilizadas do jemalloc, `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` para controlar o perfil do jemalloc se o profiler estiver habilitado. Adiciona também um comando 4LW relacionado ao jemalloc no Keeper: `jmst` para gerar um dump das estatísticas do jemalloc, `jmfp`, `jmep`, `jmdp` para controlar o perfil do jemalloc se o profiler estiver habilitado. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado em [#59235](https://github.com/ClickHouse/ClickHouse/issues/59235): Permite ignorar a evolução de esquema no mecanismo de tabela Iceberg e ler todos os dados usando o esquema especificado pelo usuário na criação da tabela ou o esquema mais recente convertido a partir dos metadados na criação da tabela. Isso é feito com a configuração `iceberg_engine_ignore_schema_evolution`, que fica desabilitada por padrão. Observe que habilitar essa configuração pode levar a resultados incorretos, pois, no caso de um esquema evoluído, todos os arquivos de dados serão lidos usando o mesmo esquema. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
