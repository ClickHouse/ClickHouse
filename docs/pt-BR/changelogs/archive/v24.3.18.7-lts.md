  #### Correção de bug (comportamento incorreto perceptível ao usuário em uma versão estável oficial)

* Backport em [#76214](https://github.com/ClickHouse/ClickHouse/issues/76214): `clickhouse-library-bridge` permite abrir bibliotecas arbitrárias do sistema de arquivos, o que significa que só é seguro executá-lo dentro de um ambiente isolado. Para evitar uma vulnerabilidade quando ele é executado nas proximidades do clickhouse-server, vamos limitar os caminhos das bibliotecas a um local especificado na configuração. Essa vulnerabilidade foi encontrada por **Arseniy Dugin** por meio do [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986). [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
