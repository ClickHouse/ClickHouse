<div id="bug-fix">
  #### Correção de Bug
</div>

* Retroportado em [#24969](https://github.com/ClickHouse/ClickHouse/issues/24969): Permite valores NULL no protocolo postgresql. Fecha [#22622](https://github.com/ClickHouse/ClickHouse/issues/22622). [#24857](https://github.com/ClickHouse/ClickHouse/pull/24857) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#25186](https://github.com/ClickHouse/ClickHouse/issues/25186): Corrigido bug ao declarar um S3 disk na raiz do bucket. Anteriormente, o seguinte erro era reportado: ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):. [#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Retroportado em [#25023](https://github.com/ClickHouse/ClickHouse/issues/25023): Corrige as configurações de limit/offset para consultas distribuídas (ignoradas nos nós remotos). [#24940](https://github.com/ClickHouse/ClickHouse/pull/24940) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado em [#25049](https://github.com/ClickHouse/ClickHouse/issues/25049): Corrige erro extremamente raro `Tagging already tagged part` na fila de replicação durante `alter move/replace partition` concorrente. Possivelmente corrige [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142). [#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin)).
* Retroportado em [#25081](https://github.com/ClickHouse/ClickHouse/issues/25081): Corrige resultado incorreto ao usar PROJECTION de agregação com chave `GROUP BY` **não vazia** para executar uma consulta com `GROUP BY` por chave **vazia**. [#25055](https://github.com/ClickHouse/ClickHouse/pull/25055) ([Amos Bird](https://github.com/amosbird)).
* Retroportado em [#25107](https://github.com/ClickHouse/ClickHouse/issues/25107): Corrige bug que permitia criar tabelas com colunas que referenciam a si mesmas, como `a UInt32 ALIAS a + 1` ou `b UInt32 MATERIALIZED b`. Corrige [#24910](https://github.com/ClickHouse/ClickHouse/issues/24910), [#24292](https://github.com/ClickHouse/ClickHouse/issues/24292). [#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin)).
* Retroportado em [#25106](https://github.com/ClickHouse/ClickHouse/issues/25106): Corrige bug com maps constantes em mapContains que resultava no erro `empty column was returned by function mapContains`. Fecha [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077). [#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado em [#25143](https://github.com/ClickHouse/ClickHouse/issues/25143): Corrige crash em consulta com CROSS JOIN e `joined_subquery_requires_alias = 0`. Corrige [#24011](https://github.com/ClickHouse/ClickHouse/issues/24011). [#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Retroportado em [#25157](https://github.com/ClickHouse/ClickHouse/issues/25157): Corrige possível perda de partes após atualização para a versão 21.5 quando a tabela utilizava `UUID` na partition key. (Não é recomendado usar `UUID` na partition key). Corrige [#25070](https://github.com/ClickHouse/ClickHouse/issues/25070). [#25127](https://github.com/ClickHouse/ClickHouse/pull/25127) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Retroportado em [#25182](https://github.com/ClickHouse/ClickHouse/issues/25182): Não utiliza a PROJECTION da tabela para `SELECT` com `FINAL`. Esse recurso ainda não é suportado. [#25163](https://github.com/ClickHouse/ClickHouse/pull/25163) ([Amos Bird](https://github.com/amosbird)).
