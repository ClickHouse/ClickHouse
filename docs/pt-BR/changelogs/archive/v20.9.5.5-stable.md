  ### Lançamento do ClickHouse v20.9.5.5-stable FIXME em comparação com o v20.9.4.76-stable
</div>

<div id="bug-fix">
  #### Correção de bug
</div>

* Aplicado por backport em [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493): Corrige um bug com banco de dados MySQL. Quando o servidor MySQL usado como engine de banco de dados fica indisponível, algumas consultas geram Exception porque tentam obter tabelas de um servidor desabilitado, embora isso seja desnecessário. Por exemplo, a consulta `SELECT ... FROM system.parts` deve funcionar apenas com tabelas MergeTree e não acessar o banco de dados MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Aplicado por backport em [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817): Corrige o comportamento inconsistente em que parte dos dados retornados podia ser descartada porque o set para essa filtragem não havia sido criado. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Aplicado por backport em [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508): Corrige o processamento de entradas muito grandes na fila de replicação. Entradas muito grandes podem aparecer em consultas ALTER se a estrutura da tabela for extremamente grande (próxima de 1 MB). Isso corrige [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Aplicado por backport em [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474): Corrige o DROP TABLE para Distributed (com condição de corrida com INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Aplicado por backport em [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571): Corrige o rápido crescimento dos metadados ao usar MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine, com `slave_parallel_worker` habilitado no MySQL Slave, reduzindo corretamente os conjuntos de GTID. Isso corrige [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Aplicado por backport em [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554): Agora, ao fazer o parsing de AVRO na entrada, o LowCardinality é removido do tipo. Corrige [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Aplicado por backport em [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748): Corrige [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Aplicado por backport em [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894): Corrige travamentos silenciosos raros quando o query profiler está ativado e o ClickHouse está instalado em um SO com uma versão da glibc que tem tabelas de desempilhamento assíncrono supostamente defeituosas para algumas funções. Isso corrige [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Isso corrige [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
