  ### lançamento do ClickHouse v20.8.1.4513-prestable FIXME em comparação com v20.7.1.4310-prestable
</div>

<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* Removido o suporte ao formato de entrada/saída `ODBCDriver`. Esse era um formato obsoleto, antes usado para comunicação com o ClickHouse ODBC driver, e há muito tempo substituído pelo formato `ODBCDriver2`. Resolve [#13629](https://github.com/ClickHouse/ClickHouse/issues/13629). [#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting)).
* A configuração `parallel_distributed_insert_select` foi estendida, com a adição de uma opção para executar `INSERT` em uma tabela local. A configuração muda de tipo de `Bool` para `UInt64`, portanto os valores `false` e `true` não são mais suportados. Se você tiver esses valores na configuração do servidor, o servidor não iniciará. Substitua-os por `0` e `1`, respectivamente. [#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat)).
* Agora, a consulta `OPTIMIZE FINAL` não recalcula o TTL para partes que foram adicionadas antes da criação do TTL. Use `ALTER TABLE ... MATERIALIZE TTL` uma vez para calculá-lo; depois disso, `OPTIMIZE FINAL` avaliará os TTLs corretamente. Esse comportamento nunca funcionou para tabelas replicadas. [#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### Novo Recurso
</div>

* Suporte ao engine de banco de dados `MaterializeMySQL`. Implementa [#4006](https://github.com/ClickHouse/ClickHouse/issues/4006). [#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014)).
* Suporte à autenticação Kerberos no Kafka, usando as bibliotecas `krb5` e `cyrus-sasl`. [#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn)).
* Adicionados os tipos `Int128`, `Int256`, `UInt256` e funções relacionadas. Os Decimals foram estendidos com Decimal256 (precisão de até 76 dígitos). Os novos tipos estão disponíveis sob a configuração `allow_experimental_bigint_types`. [#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2)).
* A função `position` agora aceita o argumento opcional `start_pos`. [#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir)).
* Adicionado o comando `ALTER SAMPLE BY`, que permite alterar a cláusula de amostragem de uma tabela. [#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird)).
* Adicionada a nova seção opcional <user_directories> ao config principal. [#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar)).
* Adicionada a função `normalizeQuery`, que substitui literais, sequências de literais e aliases complexos por placeholders. Adicionada a função `normalizedQueryHash`, que retorna valores de hash de 64 bits idênticos para consultas similares. Auxilia na análise do query log. Resolve [#11271](https://github.com/ClickHouse/ClickHouse/issues/11271). [#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adicionadas as implementações `quantileExactLow` e `quantileExactHigh` com os respectivos aliases `medianExactLow` e `medianExactHigh`. [#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc)).
* Adicionada a função `defaultValueOfTypeName`, que retorna o valor padrão para um tipo especificado. [#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz)).
* Adicionada a função `date_trunc`, que trunca um valor de data/hora para uma parte de data/hora especificada. [#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* Adicionada a possibilidade de especificar o codec de compressão `Default` para colunas que correspondem às configurações definidas em `config.xml`. Implementa: [#9074](https://github.com/ClickHouse/ClickHouse/issues/9074). [#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin)).
* Adicionada a configuração `min_index_granularity_bytes`, que protege contra a criação acidental de uma tabela com um valor muito baixo para a configuração `index_granularity_bytes`. [#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc)).
* Adicionada a função `countDigits(x)`, que conta o número de dígitos decimais em uma coluna inteira ou decimal. Adicionada a função `isDecimalOverflow(d, [p])`, que verifica se o valor em uma coluna Decimal está fora de sua precisão (ou da precisão especificada). [#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2)).

<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Ao executar consultas `INSERT SELECT` triviais, definir automaticamente `max_threads` como 1 ou `max_insert_threads`, e `max_block_size` como `min_insert_block_size_rows`. Relacionado a [#5907](https://github.com/ClickHouse/ClickHouse/issues/5907). [#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* Otimização das funções `has()`, `indexOf()` e `countEqual()` para `Array(LowCardinality(T))` e argumentos constantes à direita. [#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* Pequena melhoria no desempenho da agregação por chaves UInt8/UInt16. [#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Falhar rapidamente se o limite `max_rows_to_read` for excedido durante a varredura de partes. A motivação por trás dessa mudança é pular a varredura de intervalos de todas as partes selecionadas se estiver claro que `max_rows_to_read` já foi excedido. A mudança é bastante perceptível em consultas sobre um grande número de partes. [#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* Habilitação de `INSERT`s paralelos para os motores de tabela `Null`, `Memory`, `Distributed` e `Buffer`. [#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Pequena otimização de consultas muito curtas com LowCardinality. [#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).
