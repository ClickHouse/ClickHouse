<div id="bug-fix">
  #### Correção de bug
</div>

* Retroportado em [#24189](https://github.com/ClickHouse/ClickHouse/issues/24189): Algumas consultas `ALTER PARTITION` podiam causar os erros `Part A intersects previous part B` e `Unexpected merged part C intersecting drop range D` na fila de replicação. Isso foi corrigido. Corrige [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296). [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado em [#24306](https://github.com/ClickHouse/ClickHouse/issues/24306): Corrigido o uso de um valor `DateTime` const em comparação com uma coluna `DateTime64` em WHERE. ... [#24100](https://github.com/ClickHouse/ClickHouse/pull/24100) ([Vasily Nemkov](https://github.com/Enmk)).
* Retroportado em [#24140](https://github.com/ClickHouse/ClickHouse/issues/24140): Bug: `explain pipeline` com`select xxx final`mostra um pipeline incorreto: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* Retroportado em [#24190](https://github.com/ClickHouse/ClickHouse/issues/24190): Corrige um bug raro que podia resultar em uma tabela parcialmente inicializada, mas ainda capaz de atender solicitações de escrita (insert/alter/etc.). Agora, essas tabelas ficarão em modo readonly. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* Retroportado em [#24235](https://github.com/ClickHouse/ClickHouse/issues/24235): Corrige uma race condition que podia ocorrer no RBAC sob carga elevada. Este PR corrige [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090), [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134),. [#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado em [#24244](https://github.com/ClickHouse/ClickHouse/issues/24244): Corrige o encerramento anormal do servidor devido ao HDFS se tornar inacessível durante a execução da consulta. Fecha [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117). [#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#24241](https://github.com/ClickHouse/ClickHouse/issues/24241): Corrige um erro de digitação em StorageMemory. Esse bug foi introduzido em [#15127](https://github.com/ClickHouse/ClickHouse/issues/15127) e agora foi corrigido. Fecha [#24192](https://github.com/ClickHouse/ClickHouse/issues/24192). [#24193](https://github.com/ClickHouse/ClickHouse/pull/24193) ([张中南](https://github.com/plugine)).
* Retroportado em [#24353](https://github.com/ClickHouse/ClickHouse/issues/24353): Corrigido um bug ao mover uma visão materializada de um banco de dados Ordinary para um banco de dados Atomic (consulta `RENAME TABLE`). Agora, a tabela interna é movida para o novo banco de dados junto com a visão materializada. Corrige [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926). [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
