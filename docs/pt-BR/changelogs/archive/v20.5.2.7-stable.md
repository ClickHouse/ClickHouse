<div id="clickhouse-release-v20527-stable-fixme-as-compared-to-v20513833-prestable">
  ### Lançamento do ClickHouse v20.5.2.7-stable FIXME em comparação com v20.5.1.3833-prestable
</div>

<div id="new-feature">
  #### Novo Recurso
</div>

* Adicionado suporte a `Alter table drop replica replica_name`. Isso corrige [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).

<div id="improvement">
  #### Melhoria
</div>

* Adiciona o número de erros a serem ignorados ao selecionar réplicas (`distributed_replica_error_ignore`). [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* Metadados multiversão para armazenamento sem bloqueios de estrutura. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* Relaxa ligeiramente a validação da string de conexão ODBC. Se o hostname ou o nome de usuário contiver apenas caracteres alfanuméricos, além de `.` e `-`, não o coloque entre chaves. Isso é necessário porque alguns drivers ODBC (por exemplo, PostgreSQL) não entendem quando o hostname fica entre chaves. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adiciona suporte aos modificadores `SIGNED` e `UNSIGNED` dos tipos inteiros padrão (`BIGINT`, `INT`, ...) para compatibilidade com o MySQL. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Permite usar `sumWithOverflow` como `SimpleAggregateFunction`. Fecha [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053). [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Adiciona suporte a FixedString em funções de hash. [#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).

<div id="bug-fix">
  #### Correção de bug
</div>

* Corrige o comportamento inesperado de consultas como `SELECT *, xyz.*`, que eram concluídas com sucesso quando se esperava um erro. [#11753](https://github.com/ClickHouse/ClickHouse/pull/11753) ([hexiaoting](https://github.com/hexiaoting)).
* Corrige resultado incorreto para `if()` com NULLs na condição. [#11807](https://github.com/ClickHouse/ClickHouse/pull/11807) ([Artem Zuikov](https://github.com/4ertus2)).
* Corrige a contabilização de memória via interface HTTP (pode ser significativa com `wait_end_of_query=1`). [#11840](https://github.com/ClickHouse/ClickHouse/pull/11840) ([Azat Khuzhin](https://github.com/azat)).
* Corrige um travamento raro causado pelo uso de coluna `Nullable` na condição PREWHERE. Continuação de [#11608](https://github.com/ClickHouse/ClickHouse/issues/11608). [#11869](https://github.com/ClickHouse/ClickHouse/pull/11869) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Retroportado em [#11965](https://github.com/ClickHouse/ClickHouse/issues/11965): Corrige uma possível exceção de ponto flutuante ao processar DateTime64. Isso corrige [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374). [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corrige uma possível exceção de ponto flutuante ao processar DateTime64. Isso corrige [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374). [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado em [#11963](https://github.com/ClickHouse/ClickHouse/issues/11963): Usa o current database correto para verificar as permissões de acesso após a instrução `USE database`. [#11920](https://github.com/ClickHouse/ClickHouse/pull/11920) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado em [#12059](https://github.com/ClickHouse/ClickHouse/issues/12059): Corrige a comparação incorreta de tuplas com colunas `Nullable`. Corrige [#11985](https://github.com/ClickHouse/ClickHouse/issues/11985). [#12039](https://github.com/ClickHouse/ClickHouse/pull/12039) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
