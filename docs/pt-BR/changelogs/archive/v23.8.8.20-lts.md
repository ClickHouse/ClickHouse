<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#56509](https://github.com/ClickHouse/ClickHouse/issues/56509): Permite o backup de visão materializada com tabela interna removida, em vez de fazer o backup falhar. [#56387](https://github.com/ClickHouse/ClickHouse/pull/56387) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado em [#56929](https://github.com/ClickHouse/ClickHouse/issues/56929): Havia uma possível vulnerabilidade em versões anteriores do ClickHouse: se um usuário tivesse se conectado e tentado se autenticar sem sucesso com o método &quot;interserver secret&quot;, o servidor não encerrava a conexão imediatamente, mas continuava recebendo e ignorando os pacotes restantes do cliente. Embora esses pacotes sejam ignorados, eles ainda são analisados e, se usarem um método de compressão com outra vulnerabilidade conhecida, isso permite sua exploração sem authentication. Esse problema foi identificado no [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) por [https://twitter.com/malacupa](https://twitter.com/malacupa). [#56794](https://github.com/ClickHouse/ClickHouse/pull/56794) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### correção de bug (comportamento incorreto perceptível ao usuário em uma versão estável oficial)
</div>

* Retroportado em [#57111](https://github.com/ClickHouse/ClickHouse/issues/57111): Corrige consultas ON CLUSTER quando o database não está presente em um nó inicial. Fecha [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009). [#56484](https://github.com/ClickHouse/ClickHouse/pull/56484) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado em [#57169](https://github.com/ClickHouse/ClickHouse/issues/57169): Corrige crash devido a overflow de buffer ao descomprimir dados malformados usando o codec `Gorilla`. Esse issue foi encontrado com o [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) por [https://twitter.com/malacupa](https://twitter.com/malacupa). [#57107](https://github.com/ClickHouse/ClickHouse/pull/57107) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado em [#57175](https://github.com/ClickHouse/ClickHouse/issues/57175): Fecha a connection entre servidores para qualquer Exception que ocorra antes da authentication. Esse issue foi encontrado com o [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) por [https://twitter.com/malacupa](https://twitter.com/malacupa). [#57142](https://github.com/ClickHouse/ClickHouse/pull/57142) ([Antonio Andelic](https://github.com/antonio2368)).
