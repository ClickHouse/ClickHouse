* Retroportado em [#43099](https://github.com/ClickHouse/ClickHouse/issues/43099): Atualizado o normalizador para clonar o AST do alias. Corrige [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452) Implementação: * Atualizado o QueryNormalizer para clonar o AST do alias quando ele é substituído. Antes, simplesmente atribuir o mesmo levava a uma exceção no LogicalExpressinsOptimizer, pois o mesmo parent seria inserido novamente. * Este bug não ocorre com o novo analisador (`allow_experimental_analyzer`), então nenhuma alteração foi feita nele. Adicionei um teste para isso. [#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
