<div id="buildtestingpackaging-improvement">
  #### Melhoria de compilação/testes/empacotamento
</div>

* Retroportado em [#55295](https://github.com/ClickHouse/ClickHouse/issues/55295): O recurso com código-fonte, incluindo submodules, é compilado na task especial de compilação do Darwin. Ele pode ser usado para compilar o ClickHouse sem fazer checkout dos submodules. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Retroportado em [#55368](https://github.com/ClickHouse/ClickHouse/issues/55368): Resolve um problema ao iniciar o clickhouse-keeper em modo standalone a partir do pacote clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado em [#55727](https://github.com/ClickHouse/ClickHouse/issues/55727): Corrige o script Python de verificação de integração para usar a URL da API do gh - adiciona um Readme para testes de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
