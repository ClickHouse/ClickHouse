* Retroportado em [#43100](https://github.com/ClickHouse/ClickHouse/issues/43100): normaliser atualizado para clonar a AST do alias. Resolve [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452). Implementação: * QueryNormalizer atualizado para clonar a AST do alias quando ele é substituído. Antes, simplesmente atribuir a mesma AST levava a uma exceção no LogicalExpressinsOptimizer, pois o mesmo parent seria inserido novamente. * Esse bug não ocorre com o novo analisador (allow&#95;experimental&#95;analyzer), portanto nenhuma alteração foi feita nele. Adicionei um teste para isso. [#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado em [#44659](https://github.com/ClickHouse/ClickHouse/issues/44659): Corrige uma condição de corrida no backup de tabelas em bancos de dados Lazy. [#43104](https://github.com/ClickHouse/ClickHouse/pull/43104) ([Vitaly Baranov](https://github.com/vitlibar)).
