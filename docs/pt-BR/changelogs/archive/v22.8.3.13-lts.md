* Retroportado em [#40451](https://github.com/ClickHouse/ClickHouse/issues/40451): Corrige um bug raro relacionado ao TTL de coluna na família de motores MergeTree: em caso de mesclagem vertical repetida, podia ocorrer o erro `Cannot unlink file ColumnName.bin ... No such file or directory.` [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).

* Retroportado em [#40625](https://github.com/ClickHouse/ClickHouse/issues/40625): Corrige possível perda de dados devido a um bug no AWS SDK ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)). O bug só pode ocorrer quando o ClickHouse é usado com S3. [#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
