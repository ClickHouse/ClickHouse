<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* Altera a comparação entre inteiros e números de ponto flutuante quando o inteiro não pode ser representado exatamente no tipo de dado de ponto flutuante. Na nova versão, a comparação retornará false, pois ocorrerá erro de arredondamento. Exemplo: `9223372036854775808.0 != 9223372036854775808`, porque o número `9223372036854775808` não pode ser representado exatamente como número de ponto flutuante (e `9223372036854775808.0` é arredondado para `9223372036854776000.0`). Porém, na versão anterior, a comparação retornava como se os números fossem iguais, porque, se o número de ponto flutuante `9223372036854776000.0` fosse convertido de volta para UInt64, o resultado seria `9223372036854775808`. Como referência, a linguagem Python também trata esses números como iguais. Mas esse comportamento dependia do modelo de CPU (com resultados diferentes em AMD64 e AArch64 para alguns números fora do intervalo), por isso tornamos a comparação mais precisa. Ela tratará números int e float como iguais apenas se o int estiver representado exatamente no tipo de ponto flutuante. [#22595](https://github.com/ClickHouse/ClickHouse/pull/22595) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
