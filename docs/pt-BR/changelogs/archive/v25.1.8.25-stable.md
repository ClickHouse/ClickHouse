<div id="clickhouse-release-v251825-stable-990179ead8b-fixme-as-compared-to-v251720-stable-dcc6b0a7384">
  ### Lançamento do ClickHouse v25.1.8.25-stable (990179ead8b) FIXME em relação a v25.1.7.20-stable (dcc6b0a7384)
</div>

<div id="new-feature">
  #### Novo recurso
</div>

* Retroportado em [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357): Adicionada a configuração de servidor `concurrent_threads_scheduler`, que controla como os slots de CPU são distribuídos entre consultas concorrentes. Ela pode ser definida como `round_robin` (comportamento anterior) ou `fair_round_robin` para corrigir o problema de distribuição desigual de CPU entre INSERTs e SELECTs. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Melhoria
</div>

* Retroportado em [#77202](https://github.com/ClickHouse/ClickHouse/issues/77202): Anteriormente, o banco de dados Replicated podia registrar nos logs as credenciais especificadas em uma consulta. Esse comportamento foi corrigido. Isso fecha: [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123). [#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correção de bug (comportamento incorreto perceptível ao usuário em uma versão estável oficial)
</div>

* Retroportado em [#76151](https://github.com/ClickHouse/ClickHouse/issues/76151): Propaga as configurações de formato para a formatação de JSON como string no formato Native. [#75832](https://github.com/ClickHouse/ClickHouse/pull/75832) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado em [#76968](https://github.com/ClickHouse/ClickHouse/issues/76968): Corrige a exceção THERE&#95;IS&#95;NO&#95;COLUMN ao selecionar um literal booleano de tabelas distribuídas. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Retroportado em [#77256](https://github.com/ClickHouse/ClickHouse/issues/77256): Corrige uma possível falha devido a um rollback incorreto de coluna JSON em caso de erro durante async inserts. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado em [#77220](https://github.com/ClickHouse/ClickHouse/issues/77220): Correção de bug de JSON com subcoluna Variant por meio da adição de uma verificação para ignorar subcolunas efêmeras na verificação de consistência da part. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado em [#77248](https://github.com/ClickHouse/ClickHouse/issues/77248): Corrige falha durante a criação de tabela Kafka quando ocorre uma exceção. [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado em [#77384](https://github.com/ClickHouse/ClickHouse/issues/77384): `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` agora retorna corretamente `true` (antes retornava `false`). Isso torna o comportamento consistente com `Float32` e `Float64`. [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Retroportado em [#77333](https://github.com/ClickHouse/ClickHouse/issues/77333): Corrige a comparação entre tuplas com elementos Nullable e strings. [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
