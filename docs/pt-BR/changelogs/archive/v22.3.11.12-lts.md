<div id="buildtestingpackaging-improvement">
  #### Melhoria de compilação/testes/empacotamento
</div>

* Retroportado em [#39881](https://github.com/ClickHouse/ClickHouse/issues/39881): Anteriormente, os pacotes instalavam o arquivo `systemd.service` em `/etc`. Os arquivos nesse diretório são marcados como `conf`, por isso não são removidos nem atualizados automaticamente. Este PR faz essa limpeza. [#39323](https://github.com/ClickHouse/ClickHouse/pull/39323) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

Corrige `max_insert_threads` ao enviar para views. [#38731](https://github.com/ClickHouse/ClickHouse/pull/38731) ([Azat Khuzhin](https://github.com/azat)).
