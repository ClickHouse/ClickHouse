<div id="new-feature">
  #### Novo Recurso
</div>

* Adiciona a capacidade de redefinir uma configuração personalizada para o valor padrão e removê-la dos metadados da tabela. Isso permitirá reverter a alteração sem conhecer o valor padrão do sistema/configuração. Fecha [#14449](https://github.com/ClickHouse/ClickHouse/issues/14449). [#17769](https://github.com/ClickHouse/ClickHouse/pull/17769) ([xjewer](https://github.com/xjewer)).
* Adiciona o mecanismo de tabela MaterializedPostgreSQL e o mecanismo de banco de dados. O mecanismo de banco de dados permite replicar um banco de dados inteiro ou qualquer subconjunto de tabelas do banco de dados. [#20470](https://github.com/ClickHouse/ClickHouse/pull/20470) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Adiciona suporte a parte do padrão SQLJSON. [#24148](https://github.com/ClickHouse/ClickHouse/pull/24148) ([l1tsolaiki](https://github.com/l1tsolaiki)).
* Coleta métricas comuns do sistema (em `system.asynchronous_metrics` e `system.asynchronous_metric_log`) sobre uso de CPU, uso de disco, uso de memória, E/S, rede, arquivos, média de carga, frequências de CPU, sensores térmicos, contadores EDAC e uptime do sistema; também foram adicionadas métricas sobre o jitter de agendamento e o tempo gasto na coleta das métricas. Funciona como o `atop` no ClickHouse e permite obter dados de monitoramento mesmo sem ferramentas adicionais instaladas. Isso fecha [#9430](https://github.com/ClickHouse/ClickHouse/issues/9430). [#24416](https://github.com/ClickHouse/ClickHouse/pull/24416) ([Yegor Levankov](https://github.com/elevankoff)).
* Adiciona suporte à expressão `DISTINCT ON (columns)`, fecha [#25404](https://github.com/ClickHouse/ClickHouse/issues/25404). [#25589](https://github.com/ClickHouse/ClickHouse/pull/25589) ([Zijie Lu](https://github.com/TszKitLo40)).
* * Suporte ao tipo Map nas funções `mapAdd` e `mapSubtract` * Suporte aos tipos (U)Int128, U(Int256) nas funções `mapAdd` e `mapSubtract`. [#25596](https://github.com/ClickHouse/ClickHouse/pull/25596) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Adiciona suporte às funções bin/unbin. [#25609](https://github.com/ClickHouse/ClickHouse/pull/25609) ([zhaoyu](https://github.com/zxc111)).
* Introduz a tabela `system.data_skipping_indices`, que contém informações sobre os índices de omissão de dados existentes. Fecha [#7659](https://github.com/ClickHouse/ClickHouse/issues/7659). [#25693](https://github.com/ClickHouse/ClickHouse/pull/25693) ([Dmitry Novik](https://github.com/novikd)).
* além de [https://github.com/ClickHouse/ClickHouse/pull/12073](https://github.com/ClickHouse/ClickHouse/pull/12073), adiciona a palavra-chave FIRST ao comando ADD INDEX para permitir adicionar um índice no início da lista de índices. [#25904](https://github.com/ClickHouse/ClickHouse/pull/25904) ([xjewer](https://github.com/xjewer)).
* Renderiza pipelines como grafos na interface web se a consulta `EXPLAIN PIPELINE graph = 1` for fornecida. [#26067](https://github.com/ClickHouse/ClickHouse/pull/26067) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adiciona as novas funções `leftPad()`, `rightPad()`, `leftPadUTF8()`, `rightPadUTF8()`. [#26075](https://github.com/ClickHouse/ClickHouse/pull/26075) ([Vitaly Baranov](https://github.com/vitlibar)).

Isso fecha [#9958](https://github.com/ClickHouse/ClickHouse/issues/9958). [#25602](https://github.com/ClickHouse/ClickHouse/pull/25602) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* Suporte a colunas materializadas e com alias em junções, fecha [#13274](https://github.com/ClickHouse/ClickHouse/issues/13274). [#25634](https://github.com/ClickHouse/ClickHouse/pull/25634) ([Vladimir C](https://github.com/vdimir)).
* MaterializeMySQL agora oferece suporte ao data type `ENUM`. [#25676](https://github.com/ClickHouse/ClickHouse/pull/25676) ([Storozhuk Kostiantyn](https://github.com/sand6255)).

* Usa o data type `Map` para dicionários de chave-valor em tabelas de logs do sistema (`system.query_log`, `system.query_thread_log`, `system.processes`, `system.opentelemetry_span_log`). Colunas virtuais são criadas para dar suporte a consultas antigas. Fecha [#18698](https://github.com/ClickHouse/ClickHouse/issues/18698). Autores @hexiaoting, @sundy-li. [#25773](https://github.com/ClickHouse/ClickHouse/pull/25773) ([Maksim Kita](https://github.com/kitaisreal)).
* Corrige o comportamento inconsistente de GROUP BY constante em conjunto vazio. Fecha [#6842](https://github.com/ClickHouse/ClickHouse/issues/6842). [#25786](https://github.com/ClickHouse/ClickHouse/pull/25786) ([Kseniia Sumarokova](https://github.com/kssenii)).
* O MySQL Engine agora oferece suporte à troca de comentários de colunas entre MySQL e ClickHouse. [#25795](https://github.com/ClickHouse/ClickHouse/pull/25795) ([Storozhuk Kostiantyn](https://github.com/sand6255)).
* Corrige &quot;Nenhuma coluna disponível&quot; para o armazenamento Merge(). [#25801](https://github.com/ClickHouse/ClickHouse/pull/25801) ([Azat Khuzhin](https://github.com/azat)).
* Permite iniciar o clickhouse-client com um diretório de trabalho sem permissão de leitura. [#25817](https://github.com/ClickHouse/ClickHouse/pull/25817) ([ianton-ru](https://github.com/ianton-ru)).
* Melhor tratamento de partes perdidas em tabelas ReplicatedMergeTree. Corrige inconsistências raras na ReplicationQueue. Nada disso deve ficar visível para o usuário.
