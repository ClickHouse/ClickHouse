<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* Proibir `toUnixTimestamp(Date())` (antes ele apenas retornava a representação UInt16 de Date). [#17376](https://github.com/ClickHouse/ClickHouse/pull/17376) ([Azat Khuzhin](https://github.com/azat)).
* Removidas as funções agregadas `timeSeriesGroupSum`, `timeSeriesGroupRateSum`, porque um amigo meu disse que elas nunca funcionaram. Isso corrige [#16869](https://github.com/ClickHouse/ClickHouse/issues/16869). Se você conseguiu usar essas funções, escreva um e-mail para clickhouse-feedback@yandex-team.com. [#17423](https://github.com/ClickHouse/ClickHouse/pull/17423) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* A configuração `input_format_null_as_default` está habilitada por padrão. [#17525](https://github.com/ClickHouse/ClickHouse/pull/17525) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Definir `insert_quorum_parallel` como 1 por padrão. É significativamente mais conveniente de usar do que inserções com quorum &quot;sequenciais&quot;. Mas, se você depende de consistência sequencial, deve redefinir a configuração para zero. [#17567](https://github.com/ClickHouse/ClickHouse/pull/17567) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Restringir `ALTER MODIFY SETTING` para impedir a alteração de configurações de armazenamento que afetam partes de dados (`write_final_mark` e `enable_mixed_granularity_parts`). [#18306](https://github.com/ClickHouse/ClickHouse/pull/18306) ([Amos Bird](https://github.com/amosbird)).
* Verificar as restrições de configurações para configurações de perfil da config. O servidor não iniciará se o users.xml contiver configurações que não atendam às restrições correspondentes. [#18486](https://github.com/ClickHouse/ClickHouse/pull/18486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Remover a função `sumburConsistentHash`. Isso fecha [#18120](https://github.com/ClickHouse/ClickHouse/issues/18120). [#18656](https://github.com/ClickHouse/ClickHouse/pull/18656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adicionar os operadores `DIV` e `MOD`. `DIV` implementa divisão inteira. Isso é necessário para compatibilidade com MySQL e para `sqllogictest`. Isso fecha [#18707](https://github.com/ClickHouse/ClickHouse/issues/18707). Isso pode introduzir incompatibilidades se você estiver usando DIV ou MOD como nomes de coluna ou aliases. Em caso de incompatibilidade, escreva os aliases após a palavra-chave AS ou coloque os identificadores entre aspas (duplas ou crases). [#18760](https://github.com/ClickHouse/ClickHouse/pull/18760) ([Du Chuan](https://github.com/spongedu)).

<div id="new-feature">
  #### Novo recurso
</div>

* Use [https://github.com/lemire/fast&#95;float](https://github.com/lemire/fast_float) para fazer o parse de números de ponto flutuante. [#16787](https://github.com/ClickHouse/ClickHouse/pull/16787) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#16819](https://github.com/ClickHouse/ClickHouse/pull/16819) ([pronvis](https://github.com/pronvis)).
* Adiciona um novo combinador de agregação: `-SimpleState` para criar tipos SimpleAggregateFunction por meio de consulta. É útil para definir visão materializada no motor AggregatingMergeTree e também beneficiará as projeções. [#16853](https://github.com/ClickHouse/ClickHouse/pull/16853) ([Amos Bird](https://github.com/amosbird)).
* Adicionadas as funções de agregação `mannWitneyUTest`, `studentTTest` e `welchTTest`. RankCorr foi refatorado um pouco. [#16883](https://github.com/ClickHouse/ClickHouse/pull/16883) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Adiciona a configuração optimize&#95;on&#95;insert. Quando habilitada, faz a mesma transformação em um bloco de dados inserido como se o merge tivesse sido feito nesse bloco (por exemplo, Replacing, Collapsing, Aggregating...). Essa configuração será habilitada por padrão. Isso pode influenciar o comportamento de visão materializada e MaterializeMySQL (consulte a descrição detalhada). Isso fecha [#10683](https://github.com/ClickHouse/ClickHouse/issues/10683). [#16954](https://github.com/ClickHouse/ClickHouse/pull/16954) ([Kruglov Pavel](https://github.com/Avogar)).
* Adiciona suporte a compressão/descompressão `*.zst`. Isso permite usar `*.zst` na função `file()` e `Content-encoding: zstd` no cliente HTTP. Isso fecha [#16791 ](https://github.com/ClickHouse/ClickHouse/issues/16791). [#17144](https://github.com/ClickHouse/ClickHouse/pull/17144) ([Abi Palagashvili](https://github.com/fibersel)).
* * O Dicionário IP suporta diretamente os tipos `IPv4` / `IPv6`. [#17571](https://github.com/ClickHouse/ClickHouse/pull/17571) ([Vladimir C](https://github.com/vdimir)).
* relacionado: [#16176](https://github.com/ClickHouse/ClickHouse/issues/16176) Uso: `set limit = 10; set offset = 20;` essas duas configurações afetarão a consulta SELECT como se tivessem sido adicionadas desta forma: `select * from ($your_original_select_query) tmp limit xxx offset xxx;`. [#17633](https://github.com/ClickHouse/ClickHouse/pull/17633) ([hexiaoting](https://github.com/hexiaoting)).
* Adiciona métricas assíncronas sobre o total de linhas, bytes e partes em tabelas MergeTree. Isso corrige [#11714](https://github.com/ClickHouse/ClickHouse/issues/11714). [#17639](https://github.com/ClickHouse/ClickHouse/pull/17639) ([flynn](https://github.com/ucasfl)).
* Introduz a sintaxe `DETACH TABLE/VIEW ... PERMANENTLY`, para que, após a reinicialização, a tabela não volte a reaparecer automaticamente (apenas por solicitação explícita). A tabela ainda pode ser anexada novamente usando a sintaxe curta ATTACH TABLE. Implementa [#5555](https://github.com/ClickHouse/ClickHouse/issues/5555). Corrige [#13850](https://github.com/ClickHouse/ClickHouse/issues/13850). [#17642](https://github.com/ClickHouse/ClickHouse/pull/17642) ([filimonov](https://github.com/filimonov)).
* Adiciona uma nova tabela chamada `system.distributed_ddl_queue`, que exibe as consultas na fila do worker de DDL. [#17656](https://github.com/ClickHouse/ClickHouse/pull/17656) ([Bharat Nallan](https://github.com/bharatnc)).
* Adiciona a função `encodeXMLComponent` para escapar caracteres ao inserir uma string em um nó de texto XML ou atributo. [#17659](https://github.com/ClickHouse/ClickHouse/pull/17659) ([nauta](https://github.com/nautaa)).
* Agora o clickhouse-client oferece suporte à abertura do EDITOR para editar comandos. `Alt-Shift-E`. [#17665](https://github.com/ClickHouse/ClickHouse/pull/17665) ([Amos Bird](https://github.com/amosbird)).
* Adiciona suporte ao protocolo PROXYv1 para encapsular a interface TCP nativa. Permite que quotas sejam definidas com base no endereço IP encaminhado pelo proxy (aplicado ao endereço PROXYv1 e ao X-Forwarded-For da interface HTTP). Isso é útil quando você fornece acesso ao ClickHouse apenas por meio de um proxy confiável (por exemplo, CloudFlare), mas quer contabilizar os recursos do usuário pelos seus endereços IP originais. Isso corrige [#17268](https://github.com/ClickHouse/ClickHouse/issues/17268). [#17707](https://github.com/ClickHouse/ClickHouse/pull/17707) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adiciona a capacidade de usar uma lista de TLDs personalizada nas funções `firstSignificantSubdomainCustom`, `cutToFirstSignificantSubdomainCustom`. [#17748](https://github.com/ClickHouse/ClickHouse/pull/17748) ([Azat Khuzhin](https://github.com/azat)).
* O clickhouse-benchmark passou a aceitar parâmetro de consulta. [#17832](https://github.com/ClickHouse/ClickHouse/pull/17832) ([Maksim Kita](https://github.com/kitaisreal)).
* Estende a sintaxe `OPTIMIZE ... DEDUPLICATE` para permitir uma lista explícita (ou implícita com asterisco/transformadores de coluna) de colunas a serem verificadas em busca de duplicatas. ... [#17846](https://github.com/ClickHouse/ClickHouse/pull/17846) ([Vasily Nemkov](https://github.com/Enmk)).
* Adiciona as configurações `min_compress_block_size` e `max_compress_block_size` a MergeTreeSettings, que têm prioridade maior que as configurações globais e passam a valer quando são definidas. fecha [13890](https://github.com/ClickHouse/ClickHouse/issues/13890). [#17867](https://github.com/ClickHouse/ClickHouse/pull/17867) ([flynn](https://github.com/ucasfl)).
* Implementa a consulta `ATTACH TABLE name FROM 'path/to/data/' (col1 Type1, ...`. Ela cria uma nova tabela com a estrutura fornecida e anexa os dados da tabela a partir do diretório informado em `user_files`. [#17903](https://github.com/ClickHouse/ClickHouse/pull/17903) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Adicionadas as funções de agregação `arrayMin`, `arrayMax`, `arrayAvg`. [#18032](https://github.com/ClickHouse/ClickHouse/pull/18032) ([Maksim Kita](https://github.com/kitaisreal)).
* Adicionado suporte à instrução `SHOW SETTINGS` para exibir parâmetros em system.settings. `SHOW CHANGED SETTINGS` e a cláusula `LIKE/ILIKE` também são compatíveis. [#18056](https://github.com/ClickHouse/ClickHouse/pull/18056) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Adicionado suporte à criação de tabela a partir de `SELECT` com especificação de colunas. Exemplo: `CREATE TABLE t1 (x String) ENGINE = Memory AS SELECT 1;`. [#18060](https://github.com/ClickHouse/ClickHouse/pull/18060) ([Maksim Kita](https://github.com/kitaisreal)).
* * O Dicionário IP passa a oferecer suporte à busca por chave. Resolve [#18241](https://github.com/ClickHouse/ClickHouse/issues/18241). [#18480](https://github.com/ClickHouse/ClickHouse/pull/18480) ([Vladimir C](https://github.com/vdimir)).
* Implementadas as consultas `REPLACE TABLE` e `CREATE OR REPLACE TABLE`. [#18521](https://github.com/ClickHouse/ClickHouse/pull/18521) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Adicionada a função `byteSize` para estimar o tamanho em bytes descomprimido de seus argumentos na memória. Por exemplo, para um argumento UInt32, ela retornará a constante 4; para um argumento String, o comprimento da string + 9. A função pode receber vários argumentos. A aplicação típica é `byteSize(*)`. [#18579](https://github.com/ClickHouse/ClickHouse/pull/18579) ([Ping Yu](https://github.com/pingyu)).
* Adicionada a coluna `query_id` a `system.part_log` para partes inseridas. Fecha [#10097](https://github.com/ClickHouse/ClickHouse/issues/10097). [#18644](https://github.com/ClickHouse/ClickHouse/pull/18644) ([flynn](https://github.com/ucasfl)).
* Agora há uma nova configuração de armazenamento, `max_partitions_to_read`, para tabelas da família MergeTree. Ela limita o número máximo de partições que podem ser acessadas em uma consulta. Também foi adicionada a configuração de usuário `force_max_partition_limit` para impor essa restrição. [#18712](https://github.com/ClickHouse/ClickHouse/pull/18712) ([Amos Bird](https://github.com/amosbird)).
* A função `position` agora oferece suporte à sintaxe `position(needle in haystack)` para compatibilidade com SQL. Isso fecha [#18701](https://github.com/ClickHouse/ClickHouse/issues/18701). ... [#18779](https://github.com/ClickHouse/ClickHouse/pull/18779) ([Jianmei Zhang](https://github.com/zhangjmruc)).

* Não enviar blocks vazios para shards em `INSERT` síncrono em tabela distribuída. Isso fecha [#14571](https://github.com/ClickHouse/ClickHouse/issues/14571). [#18775](https://github.com/ClickHouse/ClickHouse/pull/18775) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Substituído `PODArray` por `PODArrayWithStackMemory` em `AggregateFunctionWindowFunnelData` para melhorar o desempenho da função `windowFunnel`. [#18817](https://github.com/ClickHouse/ClickHouse/pull/18817) ([flynn](https://github.com/ucasfl)).
* Adicionada a opção `--no-system-table` para executar o `clickhouse-local` sem system tables. Isso evita a inicialização de `DateLUT`, que pode levar um tempo perceptível (dezenas de milissegundos) na inicialização. [#18899](https://github.com/ClickHouse/ClickHouse/pull/18899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
