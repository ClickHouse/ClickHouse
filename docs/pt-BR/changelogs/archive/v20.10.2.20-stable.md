<div id="clickhouse-release-v2010220-stable-fixme-as-compared-to-v20914585-prestable">
  ### Lançamento do ClickHouse v20.10.2.20-stable FIXME em comparação com v20.9.1.4585-prestable
</div>

<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* Adicionado suporte a comentários multilinha aninhados `/* comment /* comment */ */` em SQL. Isso está em conformidade com o padrão SQL. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Alterado o valor padrão da configuração `format_regexp_escaping_rule` (relacionada ao formato `Regexp`) para `Raw` (ou seja, ler o subpadrão inteiro como um valor), para tornar o comportamento mais próximo do que os usuários esperam. [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version` tornou-se obsoleta. Removida a primeira versão do reescritor de junções. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### Novo recurso
</div>

* Adiciona o novo recurso: formato LineAsString, que aceita uma sequência de linhas separadas por quebras de linha, espaços e/ou vírgulas. [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Adicionada a função `formatReadableQuantity`. Ela é útil para a leitura de números grandes por humanos. [#14725](https://github.com/ClickHouse/ClickHouse/pull/14725) ([Artem Hnilov](https://github.com/BooBSD)).
* Adiciona a capacidade de remover propriedades de coluna e TTLs de tabela. Foram introduzidas as consultas `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` e `ALTER TABLE REMOVE TTL`. Ambas as operações são leves e executadas no nível dos metadados. [#14742](https://github.com/ClickHouse/ClickHouse/pull/14742) ([alesapin](https://github.com/alesapin)).
* Introduz o campo event&#95;time&#95;microseconds nas tabelas `system.text_log`, `system.trace_log`, `system.query_log` e `system.query_thread_log`. [#14760](https://github.com/ClickHouse/ClickHouse/pull/14760) ([Bharat Nallan](https://github.com/bharatnc)).
* Agora há suporte a `WITH <identifier> AS (subquery) ... ` para introduzir subconsultas nomeadas no contexto da consulta. Isto fecha [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416). Isto fecha [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967). [#14771](https://github.com/ClickHouse/ClickHouse/pull/14771) ([Amos Bird](https://github.com/amosbird)).
* Permite omitir argumentos do engine de tabela Replicated se os valores padrão estiverem especificados na configuração. [#14791](https://github.com/ClickHouse/ClickHouse/pull/14791) ([vxider](https://github.com/Vxider)).
* Adiciona a função de tabela `null('structure')`. [#14797](https://github.com/ClickHouse/ClickHouse/pull/14797) ([vxider](https://github.com/Vxider)).
* Adicionada a ferramenta de ofuscação de consulta. Ela permite compartilhar mais consultas para melhorar os testes. Isto fecha [#15268](https://github.com/ClickHouse/ClickHouse/issues/15268). [#15321](https://github.com/ClickHouse/ClickHouse/pull/15321) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Adicionado o formato `RawBLOB`. Ele se destina à entrada ou saída de um único valor, sem caracteres de escape nem delimitadores. Isto fecha [#15349](https://github.com/ClickHouse/ClickHouse/issues/15349). [#15364](https://github.com/ClickHouse/ClickHouse/pull/15364) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corrige [15350](https://github.com/ClickHouse/ClickHouse/issues/15350). [#15443](https://github.com/ClickHouse/ClickHouse/pull/15443) ([flynn](https://github.com/ucasfl)).
* Introduz a configuração `enable_global_with_statement`, que propaga as instruções `WITH` do primeiro select para outras consultas select no mesmo nível e torna aliases em instruções `WITH` visíveis para subconsultas. [#15451](https://github.com/ClickHouse/ClickHouse/pull/15451) ([Amos Bird](https://github.com/amosbird)).
* Adiciona a função `reinterpretAsUUID`, que permite converter uma string de bytes big-endian em UUID. [#15480](https://github.com/ClickHouse/ClickHouse/pull/15480) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Adiciona quorum inserts paralelos. Isto fecha [#15601](https://github.com/ClickHouse/ClickHouse/issues/15601). [#15601](https://github.com/ClickHouse/ClickHouse/pull/15601) ([Latysheva Alexandra](https://github.com/alexelex)).



<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Melhora o desempenho de valores de 256 bits usando `(u)int64_t` como tipo básico para inteiros wide. Os inteiros wide originais usam tipos de 8 bits como base. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* Bloqueia com `mlock` apenas o segmento de código ao iniciar o clickhouse-server. Em versões anteriores, todas as regiões mapeadas eram bloqueadas na memória, incluindo as informações de depuração. As informações de depuração geralmente ficam em um arquivo separado, mas, quando isso não ocorria, levava a +2..3 GiB de uso de memória. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Antes, escolhíamos o método de chave fixa para agrupar por uma Fixed String. Isso é desnecessário, já que temos `StringHashTable`, que faz uma otimização `packedFix` semelhante para colunas FixedString. E devemos usar `low_cardinality_key_fixed_string` quando possível. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* Corrige a escolha incorreta da implementação genérica lenta em `DateTime <op> DateTime`. Isso corrige [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153). [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* Usa uma única request DeleteObjects do S3 em vez de várias DeleteObject em ciclo. Não há mudança de funcionalidade, então isso é coberto pelos testes existentes, como integration/test&#95;log&#95;family&#95;s3. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* Multiplicação de 256 bits mais rápida. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* Melhora o desempenho de `quantileTDigest`. Isso corrige [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668). [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* Usa explicitamente um disk temporário para armazenar dados temporários da mesclagem vertical. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
