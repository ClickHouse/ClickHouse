<div id="clickhouse-release-v20614066-prestable-fixme-as-compared-to-v20513833-prestable">
  ### Lançamento do ClickHouse v20.6.1.4066-prestable FIXME em comparação com v20.5.1.3833-prestable
</div>

<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* `clickhouse-local` agora usa, por padrão, um diretório temporário de dados exclusivo, e não mais o diretório atual, como antes. Se necessário, o diretório de dados pode ser especificado explicitamente com a opção `-- --path`. [#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### Novo recurso
</div>

* Adiciona suporte a `Alter table drop replica replica_name`. Isso corrige [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* Adicionado um novo formato em memória para partes em tabelas da família `MergeTree`, que mantém os dados na memória. As partes são gravadas em disco na primeira mesclagem. Uma parte será criada no formato em memória se seu tamanho em linhas ou bytes estiver abaixo dos limiares `min_rows_for_compact_part` e `min_bytes_for_compact_part`. Também há suporte opcional a Write-Ahead-Log, habilitado por padrão e controlado pela configuração `in_memory_parts_enable_wal`. [#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* Adiciona o combinador -Distinct para funções de agregação. [#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* Suporte ao mecanismo de tabela mongo(host:port, database, collection, user, password). [#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* Adiciona o armazenamento RabbitMQ. [#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Configurações opcionais de adesão para enviar relatórios de falha à equipe principal do ClickHouse via [Sentry](https://sentry.io). [#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* Adiciona ORCBlockOutputFormat. [#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* Configuração `max_thread_pool_size` para alterar o número máximo de threads no Global Thread Pool. [#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* Implementação inicial da consulta `EXPLAIN`. Sintaxe: `EXPLAIN SELECT ...`. Isso corrige [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118). [#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Os caminhos nos metadados do S3 passaram a ser relativos, o que permite lidar com blobs do S3 com mais facilidade. [#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Suporte a entrada/saída de UUID em Avro. [#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Adicionado mecanismo de tabela MongoDB somente leitura. Permite ler campos planos (tipos primitivos, não aninhados). [#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* Adiciona configuração para campos não encontrados no schema do Avro. [#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Adiciona a função `parseDateTimeBestEffortUS`. [#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 Suporte a ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST. [#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* Adiciona a função initializedAggregation para inicializar uma agregação com base em um único valor. [#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* Suporte a RIGHT e FULL JOIN com `set join_algorithm=partial_merge`. Apenas a strictness ALL é suportada (ANY, SEMI, ANTI, ASOF não são). [#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* Implementação do operador ILIKE no estilo do PostgreSQL para [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710). [#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc)).
* Suporte a tipos Nullable como chaves em tabelas MergeTree. [#5319](https://github.com/ClickHouse/ClickHouse/issues/5319). [#12433](https://github.com/ClickHouse/ClickHouse/pull/12433) ([Amos Bird](https://github.com/amosbird)).

<div id="performance-improvement">
  #### Melhoria de desempenho
</div>

* Permite o uso de direct&#95;io e mmap&#95;io para índices secundários se as configurações `min_bytes_to_use_direct_io` ou `min_bytes_to_use_mmap_io` estiverem definidas. [#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corrige a estimativa do número de marcas durante a leitura do MergeTree. Isso é necessário para tratar corretamente as configurações `merge_tree_max_rows_to_use_cache`, `merge_tree_max_bytes_to_use_cache`, `merge_tree_min_rows_for_concurrent_read`, `merge_tree_min_bytes_for_concurrent_read`, `merge_tree_min_rows_for_seek`, `merge_tree_min_bytes_for_seek`. Agora, as configurações `min_bytes_to_use_mmap_io` também são aplicadas à leitura do índice e de partes compactas nos motores de tabela da família MergeTree. [#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corrige a regressão de desempenho &quot;[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) Índice não usado para o operador IN com literais&quot;, introduzida por volta da v19.3. [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).
* Remove funções injetivas dentro de `uniq*()` se `set optimize_injective_functions_inside_uniq=1`. [#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)).
* Adiciona uma otimização para ORDER BY que reescreve `ORDER BY x, f(x)` como `ORDER by x` se `set optimize_redundant_functions_in_order_by = 1`. [#12404](https://github.com/ClickHouse/ClickHouse/pull/12404) ([Artem Zuikov](https://github.com/4ertus2)).
* Reduz em até 2x o uso de memória em algumas operações. [#12424](https://github.com/ClickHouse/ClickHouse/pull/12424) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
