<div id="backward-incompatible-change">
  #### Alteração incompatível com versões anteriores
</div>

* Adiciona suporte a representação personalizada de NULL para formatos de entrada TSV/CSV. Corrige a desserialização de Nullable(String) nos formatos de entrada TSV/CSV/JSONCompactStringsEachRow/JSONStringsEachRow. Renomeia `output_format_csv_null_representation` e `output_format_tsv_null_representation` para `format_csv_null_representation` e `format_tsv_null_representation`, respectivamente. [#30497](https://github.com/ClickHouse/ClickHouse/pull/30497) ([Kruglov Pavel](https://github.com/Avogar)).
* Retorna string sem aspas em JSON&#95;VALUE. Fecha [#27965](https://github.com/ClickHouse/ClickHouse/issues/27965). [#31008](https://github.com/ClickHouse/ClickHouse/pull/31008) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Não permite `select` direto para Kafka/RabbitMQ/FileLog. Isso pode ser habilitado definindo `stream_like_engine_allow_direct_select`. O `select` direto não será permitido mesmo se for habilitado por configuração, caso exista uma visão materializada anexada. Para Kafka e RabbitMQ, o `select` direto, se permitido, não fará commit de mensagens por padrão. Para habilitar commits com `select` direto, o usuário deve usar a configuração no nível de storage `kafka{rabbitmq}_commit_on_select=1` (padrão `0`). cc @filimonov. [#31053](https://github.com/ClickHouse/ClickHouse/pull/31053) ([Kseniia Sumarokova](https://github.com/kssenii)).
* O mecanismo de &quot;eleição de líder&quot; foi removido de `ReplicatedMergeTree`, porque múltiplos líderes são suportados desde a versão 20.6. Se você estiver atualizando de uma versão mais antiga e alguma réplica com a versão antiga for a líder, o servidor não conseguirá iniciar após a atualização. Pare as réplicas com a versão antiga para permitir que a nova versão inicie. Depois disso, não será possível fazer downgrade para uma versão anterior à 20.6. [#32140](https://github.com/ClickHouse/ClickHouse/pull/32140) ([Alexander Tokmakov](https://github.com/tavplubix)).
