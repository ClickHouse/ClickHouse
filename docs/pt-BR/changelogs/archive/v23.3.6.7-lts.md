<div id="buildtestingpackaging-improvement">
  #### Melhoria de compilação/testes/empacotamento
</div>

* Retroportado em [#51529](https://github.com/ClickHouse/ClickHouse/issues/51529): `RUN` grande no Dockerfile dividido em condicionais menores. As ferramentas necessárias são instaladas sob demanda na mesma camada `RUN` e removidas em seguida. Upgrade do SO feito apenas uma vez no início. Uso de uma forma moderna de verificar o repositório assinado. Reversão do repositório base para ubuntu:20.04 para resolver problemas em versões mais antigas do Docker. Upgrade da versão do golang para corrigir vulnerabilidades do golang. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
