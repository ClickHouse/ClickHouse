Antes, simplesmente atribuir a mesma AST levava a uma exceção no LogicalExpressinsOptimizer, pois o mesmo parent seria inserido novamente. * Esse bug não ocorre com o novo analyzer (`allow_experimental_analyzer`), portanto nenhuma alteração foi feita nele.
