* Backport em [#92306](https://github.com/ClickHouse/ClickHouse/issues/92306): Https://github.com/clickhouse/clickhouse/pull/84477 adicionou restrições para consultas select que podem ser usadas em consultas `insert select from s3cluster()` para execução distribuída paralela.
