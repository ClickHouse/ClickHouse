O ClickHouse expõe suas próprias métricas em uma porta dedicada, no formato de texto do Prometheus, para que um servidor Prometheus possa fazer o scrape delas.

Para armazenar métricas do Prometheus no ClickHouse e consultá-las com PromQL, consulte [API HTTP do Prometheus e PromQL](/pt-BR/concepts/features/connect-to-clickhouse/prometheus).

<Note>
  Se você estiver usando o ClickHouse Cloud, é possível expor métricas para o Prometheus por meio da [Integração com o Prometheus](/pt-BR/products/cloud/features/monitoring/prometheus).
</Note>

## Configure a porta de métricas {#configure-the-metrics-port}

Configure uma porta dedicada quando um servidor Prometheus precisar fazer scrape das métricas do próprio ClickHouse:

```xml
<prometheus>
    <port>9363</port>
    <endpoint>/metrics</endpoint>
    <metrics>true</metrics>
    <asynchronous_metrics>true</asynchronous_metrics>
    <events>true</events>
    <errors>true</errors>
    <histograms>true</histograms>
    <dimensional_metrics>true</dimensional_metrics>
</prometheus>
```

## Configurar handlers estendidos {#configure-extended-handlers}

A seção `<prometheus.handlers>` pode ser usada para criar handlers mais avançados na mesma porta.
Esta seção é semelhante a [`<http_handlers>`](/pt-BR/concepts/features/connect-to-clickhouse/protocols/http), mas se aplica aos protocolos do prometheus:

```xml
<prometheus>
    <port>9363</port>
    <handlers>
        <my_rule_1>
            <url>/metrics</url>
            <handler>
                <type>expose_metrics</type>
                <metrics>true</metrics>
                <asynchronous_metrics>true</asynchronous_metrics>
                <events>true</events>
                <errors>true</errors>
                <histograms>true</histograms>
                <dimensional_metrics>true</dimensional_metrics>
                <labels>
                    <environment>production</environment>
                    <shard from_env="SHARD_NAME"></shard>
                </labels>
            </handler>
        </my_rule_1>
    </handlers>
</prometheus>
```

## Configurações {#settings}

Para obter detalhes sobre o comportamento destas configurações, consulte a [seção Prometheus](/pt-BR/reference/settings/server-settings/settings/other#prometheus) da referência de configurações do servidor.

| Nome                         | Padrão     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `port`                       | none       | Porta que disponibiliza as métricas do ClickHouse.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `endpoint`                   | `/metrics` | Endpoint HTTP para coleta de métricas. Começa com `/`. Não deve ser usado com a seção `<handlers>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `url` / `headers` / `method` | none       | Filtros usados para encontrar um handler que corresponda à requisição. São semelhantes aos campos de mesmo nome na seção [`<http_handlers>`](/pt-BR/concepts/features/connect-to-clickhouse/protocols/http).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `info`                       | true       | Expõe a métrica do tipo gauge `ClickHouse_Info` com labels de identidade do servidor (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `metrics`                    | true       | Expõe métricas de [`system.metrics`](/pt-BR/reference/system-tables/metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `asynchronous_metrics`       | true       | Expõe métricas de [`system.asynchronous_metrics`](/pt-BR/reference/system-tables/asynchronous_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `events`                     | true       | Expõe métricas de [`system.events`](/pt-BR/reference/system-tables/events).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `errors`                     | true       | Expõe contagens de erros de [`system.errors`](/pt-BR/reference/system-tables/errors).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `histograms`                 | true       | Expõe métricas de [`system.histogram_metrics`](/pt-BR/reference/system-tables/histogram_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `dimensional_metrics`        | true       | Expõe métricas de [`system.dimensional_metrics`](/pt-BR/reference/system-tables/dimensional_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `labels`                     | none       | Labels constantes adicionados a cada métrica exposta. Cada elemento filho define um label: o nome do elemento é o nome do label (que deve corresponder a `[a-zA-Z_][a-zA-Z0-9_]*`) e o valor do elemento é o valor do label. Os valores dos labels aceitam substituições padrão de configuração, como o atributo `from_env`. Um nome de label é rejeitado quando começa com `__` (reservado pelo Prometheus) ou quando entra em conflito com um label que este endpoint já grava para uma de suas seções habilitadas. Portanto, o conjunto de nomes reservados depende do que o endpoint exporta ativamente: `le` quando `histograms` está habilitado; os labels de `ClickHouse_Info` (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`) quando `info` está habilitado; e qualquer label usado por uma família de métricas dimensionais ou de histogramas exposta (por exemplo, `group`, `direction` ou `operation_type`) quando `histograms` ou `dimensional_metrics` está habilitado. Como isso depende do que o endpoint realmente expõe, um nome pode ser válido em um endpoint, mas rejeitado em outro. |

## Verifique o endpoint {#check-the-endpoint}

```bash
curl http://127.0.0.1:9363/metrics
```
