O [Model Context Protocol](https://www.anthropic.com/news/model-context-protocol) (MCP) é um padrão aberto que permite que assistentes de IA se conectem a sistemas externos.
Ele oferece uma interface padronizada para que modelos acessem fontes de dados, APIs, bancos de dados e ferramentas, sem a necessidade de uma integração personalizada para cada combinação de modelo e serviço.

Uma aplicação de IA precisa implementar o MCP apenas uma vez para se conectar a qualquer servidor compatível.
Da mesma forma, um servidor MCP pode expor seus recursos a qualquer cliente compatível.

## Arquitetura {#architecture}

O MCP segue uma arquitetura cliente-servidor:

* Clientes MCP, como Claude Desktop, Cursor ou VS Code, estabelecem conexões com servidores MCP.
* Servidores MCP expõem ferramentas e recursos por meio de uma interface padronizada.
* Modelos de IA usam as ferramentas expostas para acessar dados e funcionalidades externos quando necessário.

Ele mantém as decisões do projeto entre sessões e vincula as lições salvas ao código indexado.

## Servidor MCP do ClickHouse {#clickhouse-mcp-server}

O [servidor MCP do ClickHouse](https://github.com/ClickHouse/mcp-clickhouse) permite que um assistente de IA descubra bancos de dados e tabelas, inspecione esquemas e execute consultas SQL em um cluster ClickHouse.
As ferramentas expostas pelo servidor podem variar conforme a versão; portanto, consulte o guia de integração correspondente para conhecer os nomes das ferramentas usados nos exemplos.

Por padrão, o servidor permite apenas consultas read-only.
Use um usuário do ClickHouse dedicado, somente com as permissões de que o assistente precisa.

Para conectar um cliente MCP local, consulte [Configurar o servidor MCP do ClickHouse](/pt-BR/guides/use-cases/ai-ml/MCP/claude-desktop).
Para um servidor remoto gerenciado, consulte [Servidor MCP remoto no ClickHouse Cloud](/pt-BR/products/cloud/features/ai-ml/remote-mcp).
