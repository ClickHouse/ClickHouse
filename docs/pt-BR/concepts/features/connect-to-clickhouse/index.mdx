Escolha a interface que melhor atende à forma como você usa o ClickHouse. Para desenvolvimento de aplicações, comece por um Cliente de linguagem ou driver oficial. Para uso interativo, utilize uma ferramenta nativa ou baseada na web. Para integrações diretas, use um protocolo de rede. Antes de se conectar, configure [portas de rede](/pt-BR/concepts/features/security/network-ports), [direitos de acesso](/pt-BR/concepts/features/security/access-rights) e [TLS](/pt-BR/concepts/features/security/tls/configuring-tls) conforme necessário.
