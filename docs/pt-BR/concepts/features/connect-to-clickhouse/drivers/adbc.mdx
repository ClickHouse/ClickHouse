O driver ADBC do ClickHouse fornece uma interface [Arrow Database Connectivity (ADBC)](https://arrow.apache.org/adbc/) em conformidade com os padrões
para conectar aplicações compatíveis com ADBC ao ClickHouse.

O driver se comunica com o servidor do ClickHouse por meio do [protocolo HTTP](/pt-BR/concepts/features/connect-to-clickhouse/protocols/http), o principal
protocolo compatível com todas as implantações do ClickHouse. Isso permite que o driver funcione de forma consistente em diversos
ambientes, incluindo instalações locais, serviços gerenciados em nuvem e ambientes em que apenas o acesso via HTTP está
disponível.

O código-fonte do driver está disponível no
[repositório adbc&#95;clickhouse no GitHub](https://github.com/clickhouse/adbc_clickhouse).

<Note>
  Este driver está em desenvolvimento ativo. Algumas funcionalidades do ADBC talvez ainda não estejam totalmente implementadas. A versão atual
  se concentra em oferecer a conectividade essencial e as funcionalidades principais do ADBC, e novas funcionalidades estão previstas para versões
  futuras.

  Seu feedback é muito valioso e ajuda a definir a prioridade de novas funcionalidades e melhorias. Se você encontrar
  limitações, funcionalidades ausentes ou comportamentos inesperados, compartilhe suas observações ou solicitações de funcionalidades no
  rastreador de issues em
  [github.com/ClickHouse/adbc&#95;clickhouse/issues](https://github.com/ClickHouse/adbc_clickhouse/issues)
</Note>

## Instalação {#installation}

Você pode instalar a versão mais recente do driver com o [dbc](https://docs.columnar.tech/dbc/):

```bash
dbc install clickhouse
```

Como alternativa, você pode baixá-lo manualmente em [github.com/adbc-drivers/clickhouse/releases](https://github.com/adbc-drivers/clickhouse/releases).

## Opções de banco de dados {#database-options}

As opções de banco de dados abaixo são usadas para estabelecer uma conexão com o driver ADBC do ClickHouse.

* `uri`: Especifica o endpoint HTTP(S) completo do servidor do ClickHouse, incluindo o protocolo, o host e a porta.
* `username`: O nome de usuário usado para autenticação no servidor do ClickHouse.
* `password`: A senha associada ao nome de usuário especificado.
