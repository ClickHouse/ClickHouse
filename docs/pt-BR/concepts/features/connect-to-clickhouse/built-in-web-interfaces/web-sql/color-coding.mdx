A Interface Web SQL integrada (`play.html`, disponibilizada no caminho [`/play`](/pt-BR/concepts/features/connect-to-clickhouse/protocols/http) de qualquer porta HTTP do ClickHouse) pode colorir as células do resultado para que padrões em uma coluna fiquem visíveis rapidamente. Cada coluna tem seu próprio modo de codificação por cores, que pode ser alternado de forma independente.

## Alternando o modo {#switching-the-mode}

Um ícone 🌈 aparece à direita de cada cabeçalho de coluna. Clique nele para percorrer ciclicamente os modos disponíveis para a coluna. Em dispositivos com ponteiro que permite passar o cursor sobre os elementos (como um mouse), o ícone só é exibido enquanto o cursor está sobre o cabeçalho, para não atrapalhar no restante do tempo. Já em dispositivos de toque e outros dispositivos com ponteiro de baixa precisão, que não oferecem hover, o ícone fica sempre visível para que possa ser tocado diretamente.

O conjunto de modos disponíveis para uma coluna depende do seu tipo:

* Colunas numéricas e colunas `Date`/`DateTime`/`Date32`/`DateTime64` percorrem ciclicamente `bar` → `heatmap` → `categorical` → `none`.
* Todas as demais colunas alternam entre `none` e `categorical`.

O modo padrão é `bar` para colunas numéricas e `none` para todas as outras colunas, inclusive as de data e hora.

## Modos {#modes}

* **`bar`** — desenha na célula uma barra horizontal proporcional ao valor. Em colunas numéricas, a barra cresce a partir de uma linha de referência zero; já em colunas `Date`/`DateTime`, ela abrange o intervalo `min`..`max` da coluna, pois uma linha de referência zero não faz sentido para timestamps.
* **`heatmap`** — preenche todo o fundo da célula com uma cor que codifica o valor, escalonado entre o mínimo e o máximo da coluna.
* **`categorical`** — preenche o fundo da célula com uma cor derivada do hash do valor da célula, de modo que valores iguais recebem a mesma cor e valores diferentes recebem cores diferentes. Funciona com qualquer tipo de coluna.
* **`none`** — sem codificação por cores.

Colunas `Date`, `DateTime`, `Date32` e `DateTime64` são coloridas de acordo com seu valor de tempo, convertido em UTC, para que a escala não dependa do fuso horário do navegador de quem as visualiza.

As cores de fundo de `heatmap` e `categorical` usam o espaço de cores `oklch`, variando apenas o matiz e mantendo a luminosidade e o croma fixos em cada tema, para que o texto da célula continue legível tanto no tema claro quanto no escuro. O fundo preenche a célula inteira mesmo quando o conteúdo de uma linha ocupa mais de uma linha de texto.

## Destaque categórico na seleção {#categorical-emphasis}

No modo `categorical`, selecionar uma célula destaca as demais células que têm o mesmo valor, exibindo-as em fonte mais espessa e com uma cor de texto de contraste máximo (branco puro no tema escuro, preto puro no tema claro). A célula selecionada em si não recebe destaque. Isso facilita identificar em que outros pontos da coluna um determinado valor aparece.

## Persistência {#persistence}

Os modos escolhidos são memorizados por coluna na URL da página e no histórico do navegador, então eles são preservados ao recarregar a página, compartilhar o link ou navegar para trás e para frente. Apenas as escolhas diferentes do padrão são armazenadas, para manter a URL e o estado do histórico compactos.

Assim como as [colunas fixadas](/pt-BR/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/pinned-columns), os modos pertencem ao resultado que colorem: à aba da consulta e, dentro de uma aba que seja um [notebook](/pt-BR/concepts/features/connect-to-clickhouse/built-in-web-interfaces/web-sql/notebook), a cada célula individualmente. As tabelas de uma mesma execução de `Run all` (várias consultas) compartilham os mesmos modos, enquanto as demais células e abas mantêm os seus próprios.

## Limitações {#limitations}

* O layout vertical (transposto) de linha única não exibe codificação por cores.
* Diferenças de `DateTime64(9)` inferiores a um microssegundo não são diferenciadas na escala de cores, pois não teriam significado visual em um gradiente.
