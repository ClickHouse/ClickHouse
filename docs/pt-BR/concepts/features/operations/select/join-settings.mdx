Esta página lista as configurações de sessão que afetam a semântica, o planejamento, a execução e o uso de memória de JOINs. Cada configuração tem um link para a respectiva entrada na [referência de configurações de sessão](/pt-BR/reference/settings/session-settings), onde constam o valor default e os valores aceitos. A sintaxe e a semântica de JOINs estão descritas na [referência da cláusula `JOIN`](/pt-BR/reference/statements/select/join).

## Semântica e sintaxe {#semantics-and-syntax}

| Configuração                                                                                                                                                                           | Descrição                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/pt-BR/reference/settings/session-settings/join#join_default_strictness)                                                                                         | Define o rigor de um JOIN escrito sem um rigor explícito.                                                                                                           |
| [`any_join_distinct_right_table_keys`](/pt-BR/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | Habilita o comportamento legado de `ANY INNER JOIN` e `ANY LEFT JOIN`, no qual `t1 ANY LEFT JOIN t2` e `t2 ANY RIGHT JOIN t1` podem retornar resultados diferentes. |
| [`join_any_take_last_row`](/pt-BR/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | Define se um JOIN com rigor `ANY` usa a primeira ou a última linha correspondente quando a right table tem várias linhas correspondentes para uma chave.            |
| [`join_use_nulls`](/pt-BR/reference/settings/session-settings/join#join_use_nulls)                                                                                                           | Controla se as colunas de linhas sem correspondência em um JOIN externo são preenchidas com valores default ou com `NULL`.                                          |
| [`semi_join_include_columns_from_both_sides`](/pt-BR/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | Controla se o resultado de um `SEMI JOIN` expõe as colunas de ambas as tabelas ou apenas as colunas da tabela preservada.                                           |
| [`anti_join_include_columns_from_both_sides`](/pt-BR/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | Controla se o resultado de um `ANTI JOIN` expõe as colunas de ambas as tabelas ou apenas as colunas da tabela preservada.                                           |
| [`cross_to_inner_join_rewrite`](/pt-BR/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | Controla se uma lista de tabelas separadas por vírgula ou um `CROSS JOIN` com condições de igualdade em `WHERE` é reescrito como um `INNER JOIN`.                   |
| [`allow_block_nested_loop_join`](/pt-BR/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | Permite executar como uma junção block nested loop um JOIN cuja seção `ON` não contém nenhuma igualdade entre as tabelas.                                           |
| [`enable_lateral_join`](/pt-BR/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | Habilita a sintaxe experimental `LATERAL JOIN`, na qual uma subconsulta no lado direito de um JOIN pode referenciar colunas do lado esquerdo.                       |
| [`single_join_prefer_left_table`](/pt-BR/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | Resolve para a tabela da esquerda um identificador ambíguo entre as duas tabelas de um único JOIN.                                                                  |
| [`joined_subquery_requires_alias`](/pt-BR/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | Exige que subconsultas e funções de tabela em um JOIN tenham aliases.                                                                                               |
| [`allow_dynamic_type_in_join_keys`](/pt-BR/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | Permite chaves de JOIN do tipo `Dynamic`.                                                                                                                           |
| [`analyzer_compatibility_join_using_top_level_identifier`](/pt-BR/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | Resolve um nome de coluna em `USING` a partir de um alias de mesmo nome na consulta, como um alias na lista do `SELECT`.                                            |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/pt-BR/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | Qualifica os nomes das colunas do resultado com nomes de tabelas ou aliases em uma consulta com dois ou mais JOINs, como fazia o analisador antigo.                 |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/pt-BR/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | Aplica a todas as tabelas do JOIN um modificador `FINAL` usado na tabela mais à esquerda, como nas versões anteriores à 26.6.                                       |

| [`min_rows_ratio_for_hash_join_row_store`](/pt-BR/reference/settings/session-settings/min#min_rows_ratio_for_hash_join_row_store)                   | Define a razão estimada mínima entre linhas de saída e linhas do lado de construção a partir da qual a carga útil de um hash JOIN é convertida para um layout orientado a linhas.                                                                                                                                                                                                                                                                                                                                                |
| [`enable_join_fixed_hash_table_conversion`](/pt-BR/reference/settings/session-settings/enable-join#enable_join_fixed_hash_table_conversion)         | Habilita a conversão da tabela hash de um JOIN em um array plano quando a chave é um único inteiro com um intervalo pequeno de valores.                                                                                                                                                                                                                                                                                                                                                                                          |

| [`max_size_to_preallocate_for_joins`](/pt-BR/reference/settings/session-settings/max-size#max_size_to_preallocate_for_joins)                        | Limita o número total de elementos para os quais se pré-aloca espaço nas tabelas hash de um JOIN.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| [`max_joined_block_size_rows`](/pt-BR/reference/settings/session-settings/max-joined#max_joined_block_size_rows)                                    | Limita o número de linhas em um bloco do resultado de JOIN.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| [`min_joined_block_size_rows`](/pt-BR/reference/settings/session-settings/min-joined#min_joined_block_size_rows)                                    | Define o número de linhas abaixo do qual os blocos de entrada e saída de um JOIN são consolidados em blocos maiores.                                                                                                                                                                                                                                                                                                                                                                                                             |
| [`min_joined_block_size_bytes`](/pt-BR/reference/settings/session-settings/min-joined#min_joined_block_size_bytes)                                  | Define o tamanho em bytes abaixo do qual os blocos de entrada e saída de um JOIN são consolidados em blocos maiores.                                                                                                                                                                                                                                                                                                                                                                                                             |

| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

LIMIT n` para baixo de um JOIN `LEFT` ou `RIGHT` quando a chave de ordenação referencia apenas colunas do lado preservado.                                      |

| [`max_rows_in_join`](/pt-BR/reference/settings/session-settings/max-rows#max_rows_in_join)                                              | Limita o número de linhas na estrutura de dados da right table de um JOIN.                                                                                                   |
| [`max_bytes_in_join`](/pt-BR/reference/settings/session-settings/max-bytes#max_bytes_in_join)                                           | Limita o tamanho, em bytes, da estrutura de dados da right table de um JOIN.                                                                                                 |
| [`join_overflow_mode`](/pt-BR/reference/settings/session-settings/join#join_overflow_mode)                                              | Define a ação executada quando um JOIN atinge `max_rows_in_join` ou `max_bytes_in_join`.                                                                                     |
| [`default_max_bytes_in_join`](/pt-BR/reference/settings/session-settings/default#default_max_bytes_in_join)                             | Define o tamanho máximo da right table quando um limite é necessário e `max_bytes_in_join` não está definido.                                                                |
| [`max_bytes_before_external_join`](/pt-BR/reference/settings/session-settings/max-bytes#max_bytes_before_external_join)                 | Define o tamanho, em bytes, da right table a partir do qual um JOIN baseado em hash faz spill para o disco.                                                                  |
| [`max_bytes_ratio_before_external_join`](/pt-BR/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_join)     | Define o limiar de spill de um JOIN baseado em hash como uma razão da memória disponível.                                                                                    |
| [`enable_adaptive_memory_spill_scheduler`](/pt-BR/reference/settings/session-settings/enable#enable_adaptive_memory_spill_scheduler)    | Habilita o spill para o disco de processadores elegíveis, incluindo JOINs compatíveis com spill, quando a consulta está sob pressão de memória.                              |
| [`legacy_join_size_limits_trigger_spilling`](/pt-BR/reference/settings/session-settings/other#legacy_join_size_limits_trigger_spilling) | Restaura o comportamento em que `max_rows_in_join` e `max_bytes_in_join` fazem com que a parte em disco de um JOIN continue fazendo spill, em vez de interromper a consulta. |
| [`max_bytes_before_external_sort`](/pt-BR/reference/settings/session-settings/max-bytes#max_bytes_before_external_sort)                 | Define o uso de memória a partir do qual a ordenação, incluindo a de um JOIN `full_sorting_merge`, faz spill para o disco.                                                   |
| [`max_bytes_ratio_before_external_sort`](/pt-BR/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_sort)     | Define a razão da memória disponível a partir da qual a ordenação, incluindo a de um JOIN `full_sorting_merge`, faz spill para o disco.                                      |
| [`cross_join_min_rows_to_compress`](/pt-BR/reference/settings/session-settings/cross-join#cross_join_min_rows_to_compress)              | Define o número de linhas a partir do qual um bloco de um `CROSS JOIN` ou de uma junção block nested loop é comprimido em memória.                                              |
| [`cross_join_min_bytes_to_compress`](/pt-BR/reference/settings/session-settings/cross-join#cross_join_min_bytes_to_compress)            | Define o tamanho, em bytes, a partir do qual um bloco de um `CROSS JOIN` ou de uma junção block nested loop é comprimido em memória.                                            |
| [`temporary_files_codec`](/pt-BR/reference/settings/session-settings/temporary-files#temporary_files_codec)                             | Define o codec de compressão dos arquivos temporários que as operações de ordenação e JOIN gravam em disco.                                                                  |

| [`prefer_global_in_and_join`](/pt-BR/reference/settings/session-settings/prefer#prefer_global_in_and_join)                                                              | Habilita a substituição de `IN` e JOIN por `GLOBAL IN` e `GLOBAL JOIN`.                                                                        |
| [`max_rows_to_transfer`](/pt-BR/reference/settings/session-settings/max-rows#max_rows_to_transfer)                                                                      | Limita o número de linhas que um `GLOBAL IN` ou `GLOBAL JOIN` envia a servidores remotos ou salva em uma tabela temporária.                    |
| [`max_bytes_to_transfer`](/pt-BR/reference/settings/session-settings/max-bytes#max_bytes_to_transfer)                                                                   | Limita o número de bytes não comprimidos que um `GLOBAL IN` ou `GLOBAL JOIN` envia a servidores remotos ou salva em uma tabela temporária.     |
| [`transfer_overflow_mode`](/pt-BR/reference/settings/session-settings/other#transfer_overflow_mode)                                                                     | Define a ação a ser executada quando `max_rows_to_transfer` ou `max_bytes_to_transfer` é atingido.                                             |

| [`distributed_plan_join_runtime_filters`](/pt-BR/reference/settings/session-settings/distributed-plan#distributed_plan_join_runtime_filters)                            | Envia filtros de JOIN em tempo de execução para os estágios que leem o lado de sondagem em um plano de consulta distribuída.                   |
| [`distributed_plan_max_rows_to_broadcast`](/pt-BR/reference/settings/session-settings/distributed-plan#distributed_plan_max_rows_to_broadcast)                          | Define o número máximo de linhas até o qual o planejador distribuído baseado em regras usa um JOIN de broadcast em vez de um JOIN com shuffle. |
