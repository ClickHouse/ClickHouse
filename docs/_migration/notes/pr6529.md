## Reasoning

The upstream change adds `operations/utilities/clickhouse-proxy` to a Docusaurus-specific
plugin exceptions file (`plugins/floating-pages-exceptions.txt`). This plugin enforces
that every Markdown page is referenced by a `sidebars.js` entry.

Mintlify has no equivalent:
- No `plugins/` directory in this repo.
- Navigation is driven by `docs.json`, not `sidebars.js`.
- There is no "floating pages" check — pages simply exist and are surfaced via
  `docs.json` navigation groups.
