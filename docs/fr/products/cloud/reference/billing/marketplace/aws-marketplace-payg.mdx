Faites vos premiers pas avec ClickHouse Cloud sur l’[AWS Marketplace](https://aws.amazon.com/marketplace) via une offre publique PAYG (paiement à l’usage).

<div id="prerequisites">
  ## Prérequis {#prerequisites}
</div>

* Un compte AWS sur lequel votre administrateur de la facturation a activé les droits d’achat.
* Pour effectuer l’achat, vous devez être connecté à AWS Marketplace avec ce compte.
* Pour connecter une organisation ClickHouse à votre abonnement, vous devez être Admin de cette organisation.

## Étapes d’inscription {#steps-to-sign-up}

<Steps>
  <Step title="Rechercher ClickHouse Cloud - Pay as you go" id="search-payg">
    Accédez à [AWS Marketplace](https://aws.amazon.com/marketplace) et recherchez « ClickHouse Cloud - Pay As You Go ».

    <div className="ch-image-lg">
      <Frame>
        ![Recherche de ClickHouse dans AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Afficher les options d’achat" id="purchase-options">
    Cliquez sur l’[offre](https://aws.amazon.com/marketplace/pp/prodview-p4gwofrqpkltu), puis sur **Afficher les options d’achat**.

    <div className="ch-image-lg">
      <Frame>
        ![Options d’achat dans AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="S’abonner" id="subscribe">
    Sur l’écran suivant, cliquez sur s’abonner.

    <div className="ch-image-lg">
      <Frame>
        ![Abonnement dans AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Configurer votre compte" id="set-up-your-account">
    À ce stade, la configuration n’est pas terminée et votre organisation ClickHouse Cloud n’est pas encore facturée via la place de marché. Vous devez maintenant cliquer sur Configurez votre compte dans votre abonnement via la place de marché afin d’être redirigé vers ClickHouse Cloud pour finaliser la configuration.

    <div className="ch-image-lg">
      <Frame>
        ![Configurez votre compte](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-4.webp)
      </Frame>
    </div>

    Une fois redirigé vers ClickHouse Cloud, vous pouvez vous connecter avec un compte existant ou créer un nouveau compte. Cette étape est essentielle, car elle nous permet de lier votre organisation ClickHouse Cloud à votre facturation AWS Marketplace.

    <Info>
      **Nouveaux utilisateurs de ClickHouse Cloud**

      Si vous êtes un nouvel utilisateur de ClickHouse Cloud, suivez les étapes ci-dessous.
    </Info>

    <Accordion title="Étapes pour les nouveaux utilisateurs">
      Si vous êtes un nouvel utilisateur de ClickHouse Cloud, cliquez sur Register en bas de la page. Vous serez invité à créer un nouvel utilisateur et à vérifier votre adresse e-mail. Une fois votre adresse e-mail vérifiée, vous pouvez quitter la page de connexion de ClickHouse Cloud et vous connecter avec votre nouveau nom d’utilisateur sur https://console.clickhouse.cloud.

      <div className="ch-image-md">
        <Frame>
          ![Inscription à ClickHouse Cloud](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-5.webp)
        </Frame>
      </div>

      <Info>
        **Nouveaux utilisateurs**

        Vous devrez également fournir quelques informations de base sur votre entreprise. Consultez les captures d’écran ci-dessous.
      </Info>

      <div className="ch-image-md">
        <Frame>
          ![Avant de commencer](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-6.webp)
        </Frame>
      </div>

      <div className="ch-image-md">
        <Frame>
          ![Avant de commencer, suite](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-7.webp)
        </Frame>
      </div>
    </Accordion>

    Si vous êtes déjà utilisateur de ClickHouse Cloud, connectez-vous simplement avec vos identifiants.
  </Step>

  <Step title="Associer l’abonnement via la place de marché à une organisation" id="add-marketplace-subscription">
    Une fois connecté, vous pouvez choisir de créer une nouvelle organisation ou de sélectionner une organisation existante, qui sera facturée via cet abonnement.

    <div className="ch-image-lg">
      <Frame>
        ![Ajouter l’abonnement via la place de marché](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-8.webp)
      </Frame>
    </div>

    Si vous créez un nouveau compte ClickHouse, une organisation par défaut est créée pour vous, à laquelle vous pouvez lier votre abonnement via la place de marché.

    <div className="ch-image-lg">
      <Frame>
        ![Lier l’organisation par défaut à l’abonnement AWS Marketplace](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-13.webp)
      </Frame>
    </div>

    Une fois cette étape terminée, votre organisation est associée à cet abonnement AWS et toute votre consommation est facturée via votre compte AWS.

    Vous pouvez vérifier sur la page de facturation de l’organisation, dans l’UI de ClickHouse, que la facturation est désormais bien liée à AWS Marketplace.

    <div className="ch-image-lg">
      <Frame>
        ![Vérification sur la page de facturation](/images/cloud/manage/billing/marketplace/aws-marketplace-payg-9.webp)
      </Frame>
    </div>
  </Step>
</Steps>
