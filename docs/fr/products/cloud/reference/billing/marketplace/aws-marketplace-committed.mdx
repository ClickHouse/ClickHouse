Commencez à utiliser ClickHouse Cloud sur l’[AWS Marketplace](https://aws.amazon.com/marketplace) via un contrat d’engagement.
Un contrat d’engagement, également appelé Offre privée, permet aux clients de s’engager sur un certain montant de dépenses pour ClickHouse Cloud sur une période donnée.

<div id="prerequisites">
  ## Prérequis {#prerequisites}
</div>

* Une Private Offer de ClickHouse basée sur des conditions contractuelles spécifiques.
* Pour associer une organisation ClickHouse à votre offre d&#39;engagement de dépense, vous devez être Admin de cette organisation.

Autorisations requises pour consulter et accepter votre contrat d&#39;engagement dans AWS :

* Si vous utilisez des politiques gérées par AWS, vous devez disposer des autorisations suivantes :
  * `AWSMarketplaceRead-only`, `AWSMarketplaceManageSubscriptions`
  * ou `AWSMarketplaceFullAccess`
* Si vous n&#39;utilisez pas de politiques gérées par AWS, vous devez disposer des autorisations suivantes :
  * Action IAM `aws-marketplace:ListPrivateListings` et `aws-marketplace:ViewSubscriptions`

## Étapes d’inscription {#steps-to-sign-up}

<Steps>
  <Step title="Acceptez votre offre privée" id="private-offer-accept">
    Vous devriez avoir reçu un e-mail contenant un lien pour examiner et accepter votre offre privée.

    <div className="ch-image-md">
      <Frame>
        ![E-mail d’offre privée AWS Marketplace](/images/cloud/reference/mp_committed_spend_1.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Ouvrez le lien Review Offer" id="review-offer-link">
    Cliquez sur le lien Review Offer dans l’e-mail.
    Vous serez redirigé vers votre page AWS Marketplace, qui présente les détails de l’offre privée.
  </Step>

  <Step title="Configurez votre compte" id="setup-your-account">
    Suivez les étapes d’abonnement sur le portail AWS, puis cliquez sur **« Configurez votre compte »**.
    À ce stade, il est essentiel de vous laisser rediriger vers ClickHouse Cloud, puis de créer un nouveau compte ou de vous connecter avec un compte existant.
    Sans cette étape, nous ne pourrons pas lier votre contrat AWS Marketplace à ClickHouse Cloud.

    <div className="ch-image-md">
      <Frame>
        ![E-mail d’offre privée AWS Marketplace](/images/cloud/reference/mp_committed_spend_2.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Connectez-vous à Cloud" id="login-cloud">
    Une fois redirigé vers ClickHouse Cloud, vous pouvez vous connecter avec un compte existant ou créer un nouveau compte.
    Cette étape est nécessaire pour que nous puissions associer votre organisation ClickHouse Cloud à la facturation AWS Marketplace.

    <div className="ch-image-md">
      <Frame>
        ![E-mail d’offre privée AWS Marketplace](/images/cloud/reference/mp_committed_spend_3.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Inscrivez-vous si vous êtes nouvel utilisateur" id="register">
    Si vous êtes un nouvel utilisateur de ClickHouse Cloud, cliquez sur « Register » en bas de la page.
    Vous serez invité à créer un nouvel utilisateur et à vérifier votre adresse e-mail.
    Une fois votre adresse e-mail vérifiée, vous pouvez quitter la page de connexion de ClickHouse Cloud et vous connecter avec le nouveau nom d’utilisateur sur [https://console.clickhouse.cloud](https://console.clickhouse.cloud).

    Notez qu’en tant que nouvel utilisateur, vous devrez également fournir quelques informations de base sur votre entreprise.
    Consultez les captures d’écran ci-dessous.

    <div className="ch-image-md">
      <Frame>
        ![Fournir les informations sur l’entreprise](/images/cloud/reference/mp_committed_spend_4.png)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![Fournir les informations sur l’entreprise](/images/cloud/reference/mp_committed_spend_5.png)
      </Frame>
    </div>

    Si vous êtes déjà utilisateur de ClickHouse Cloud, connectez-vous simplement avec vos identifiants.
  </Step>

  <Step title="Créez ou sélectionnez l’organisation à facturer" id="create-select-org-to-bill">
    Une fois connecté, vous pouvez soit créer une nouvelle organisation à facturer au titre de ce contrat de place de marché, soit choisir une organisation existante.

    <div className="ch-image-md">
      <Frame>
        ![Créer ou sélectionner une organisation à facturer au titre de cet abonnement](/images/cloud/reference/mp_committed_spend_6.webp)
      </Frame>
    </div>

    Une fois cette étape terminée, votre organisation sera associée à votre contrat avec engagement de dépenses AWS et toute l’utilisation sera facturée via votre compte AWS.
    Vous pouvez vérifier sur la page de facturation de l’organisation, dans l’interface ClickHouse, que la facturation est désormais bien liée à AWS Marketplace.

    <div className="ch-image-md">
      <Frame>
        ![Confirmer que la configuration est terminée](/images/cloud/reference/mp_committed_spend_7.webp)
      </Frame>
    </div>

    En cas de problème, n’hésitez pas à contacter notre [équipe d’assistance](https://clickhouse.com/support/program).
  </Step>
</Steps>
