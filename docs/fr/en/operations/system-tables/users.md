<div id="description">
  ## Description
</div>

Contient la liste des [comptes utilisateur](../../guides/sre/user-management/index.md#user-account-management) configurés sur le serveur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom d’utilisateur.
* `id` ([UUID](/fr/sql-reference/data-types/uuid)) — ID de l’utilisateur.
* `storage` ([String](/fr/sql-reference/data-types/string)) — Chemin vers le stockage des utilisateurs. Configuré dans le paramètre access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/fr/sql-reference/data-types/array)) — Affiche les types d’authentification. Il existe plusieurs façons d’identifier un utilisateur : sans mot de passe, avec un mot de passe en clair, avec un mot de passe encodé en SHA256, avec un mot de passe encodé en double SHA-1 ou avec un mot de passe encodé en bcrypt.
* `auth_params` ([Array(String)](/fr/sql-reference/data-types/array)) — Paramètres d’authentification au format JSON selon le type auth&#95;type.
* `valid_until` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Date et heure d’expiration des identifiants de l’utilisateur.
* `host_ip` ([Array(String)](/fr/sql-reference/data-types/array)) — Adresses IP des hôtes autorisés à se connecter au serveur ClickHouse.
* `host_names` ([Array(String)](/fr/sql-reference/data-types/array)) — Noms d’hôte autorisés à se connecter au serveur ClickHouse.
* `host_names_regexp` ([Array(String)](/fr/sql-reference/data-types/array)) — Expression régulière pour les noms d’hôte autorisés à se connecter au serveur ClickHouse.
* `host_names_like` ([Array(String)](/fr/sql-reference/data-types/array)) — Noms d’hôte autorisés à se connecter au serveur ClickHouse, définis à l’aide du prédicat LIKE.
* `default_roles_all` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique que tous les rôles accordés sont définis par défaut pour l’utilisateur.
* `default_roles_list` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des rôles accordés par défaut.
* `default_roles_except` ([Array(String)](/fr/sql-reference/data-types/array)) — Tous les rôles accordés définis par défaut, à l’exception de ceux figurant dans la liste.
* `grantees_any` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant si un utilisateur disposant d’une option d’attribution peut l’accorder à n’importe qui.
* `grantees_list` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des utilisateurs ou rôles auxquels cet utilisateur est autorisé à accorder des options.
* `grantees_except` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des utilisateurs ou rôles auxquels cet utilisateur n’est pas autorisé à accorder des options.
* `default_database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données par défaut pour cet utilisateur.
