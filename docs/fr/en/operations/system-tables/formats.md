<div id="description">
  ## Description
</div>

Contient la liste de tous les formats, avec des indicateurs précisant si chaque format convient en entrée/sortie et s’il prend en charge la parallélisation.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du format.
* `is_input` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si le format est adapté à l’entrée de données.
* `is_output` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si le format est adapté à la sortie de données.
* `supports_parallel_parsing` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si le format prend en charge le parsing en parallèle.
* `supports_parallel_formatting` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si le format prend en charge le formatage en parallèle.
* `is_tty_friendly` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si le format s’affiche généralement correctement dans le terminal. Pour les autres formats, le CLI demandera une confirmation avant d’afficher la sortie.
* `content_type` ([String](/fr/sql-reference/data-types/string)) — En-tête HTTP Content-Type correspondant au format de sortie. Peut dépendre des paramètres actuels du format.
* `supports_random_access` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si le format prend en charge l’accès aléatoire en entrée.
* `has_schema_inference` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Le format peut déterminer dynamiquement le schéma à partir des données (soit à partir d’un en-tête ou de métadonnées intégrés, soit à partir des données elles-mêmes).
* `has_external_schema` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Le format a soit un schéma fixe, soit il accepte un schéma prédéfini dans son propre format.
* `prefers_large_blocks` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Le format écrira des blocs plus volumineux en sortie et générera des blocs plus volumineux en entrée.
* `supports_append` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Il est possible d’ajouter des données à la fin d’un même fichier avec ce format.
* `supports_subsets_of_columns` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Le format d’entrée peut détecter que certaines colonnes sont omises.
* `description` ([String](/fr/sql-reference/data-types/string)) — Description générale du format.
* `examples` ([String](/fr/sql-reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/sql-reference/data-types/string)) — Version de ClickHouse dans laquelle le format a été introduit pour la première fois, sous la forme majeur.mineur.
* `related` ([Array](/fr/sql-reference/data-types/array)([String](/fr/sql-reference/data-types/string))) — Noms des formats associés.
