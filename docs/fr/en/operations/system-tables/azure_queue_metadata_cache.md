<div id="description">
  ## Description
</div>

Contient l’état en mémoire des métadonnées d’AzureQueue ainsi que les lignes en cours de traitement pour chaque fichier.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/fr/sql-reference/data-types/string)) — Chemin vers les métadonnées dans ZooKeeper
* `file_path` ([String](/fr/sql-reference/data-types/string)) — Chemin du fichier en cours de traitement
* `file_name` ([String](/fr/sql-reference/data-types/string)) — Nom du fichier en cours de traitement
* `rows_processed` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de lignes actuellement traitées
* `status` ([String](/fr/sql-reference/data-types/string)) — Statut du traitement : Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure à laquelle le traitement du fichier a commencé
* `processing_end_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure à laquelle le traitement du fichier s’est terminé
* `exception` ([String](/fr/sql-reference/data-types/string)) — Exception survenue pendant le traitement

{/*AUTOGENERATED_END*/ }
