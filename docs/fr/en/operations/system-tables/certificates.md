<div id="description">
  ## Description
</div>

Contient des informations sur les certificats disponibles et leurs sources.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `version` ([Int32](/fr/sql-reference/data-types/int-uint)) — Version du certificat. Les valeurs sont 0 pour v1, 1 pour v2 et 2 pour v3.
* `serial_number` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Numéro de série du certificat attribué par l’émetteur.
* `signature_algo` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Algorithme de signature — algorithme utilisé par l’émetteur pour signer ce certificat.
* `issuer` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Émetteur — identifiant unique de l’autorité de certification qui délivre ce certificat.
* `not_before` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Début de la période de validité de ce certificat.
* `not_after` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Fin de la période de validité de ce certificat.
* `subject` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Sujet — identifie le propriétaire de la clé publique.
* `pkey_algo` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — L’algorithme de clé publique définit l’algorithme avec lequel la clé publique peut être utilisée.
* `path` ([String](/fr/sql-reference/data-types/string)) — Chemin vers le fichier ou le répertoire contenant ce certificat.
* `default` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Le certificat se trouve dans l’emplacement de certificat par défaut.
* `protocol` ([String](/fr/sql-reference/data-types/string)) — Nom du protocole si le certificat provient de la configuration TLS propre à ce protocole, sinon vide.

{/*AUTOGENERATED_END*/ }
