<div id="description">
  ## Description
</div>

Contient les codes d’erreur ainsi que le nombre de fois où ils se sont produits.

Pour afficher tous les codes d’erreur possibles, y compris ceux qui ne se sont pas produits, définissez le paramètre [system&#95;events&#95;show&#95;zero&#95;values](../settings/settings.md#system_events_show_zero_values) sur 1.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom de l’erreur (errorCodeToName).
* `code` ([Int32](/fr/sql-reference/data-types/int-uint)) — Numéro de code de l’erreur.
* `value` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de fois où cette erreur s’est produite.
* `last_error_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Heure à laquelle la dernière erreur s’est produite.
* `last_error_message` ([String](/fr/sql-reference/data-types/string)) — Message de la dernière erreur.
* `last_error_format_string` ([String](/fr/sql-reference/data-types/string)) — Chaîne de format de la dernière erreur.
* `last_error_trace` ([Array(UInt64)](/fr/sql-reference/data-types/array)) — Trace de pile représentant une liste d’adresses physiques où sont stockées les méthodes appelées.
* `remote` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Exception distante (c.-à-d. reçue lors de l’une des requêtes distribuées).
* `query_id` ([String](/fr/sql-reference/data-types/string)) — ID d’une requête ayant provoqué une erreur (si disponible).

{/*AUTOGENERATED_END*/ }

:::note
Les compteurs de certaines erreurs peuvent augmenter même lors d’une exécution de requête réussie. Il n’est pas recommandé d’utiliser cette table pour surveiller le serveur, sauf si vous êtes sûr que l’erreur correspondante ne peut pas être un faux positif.
:::

<div id="example">
  ## Exemple
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
