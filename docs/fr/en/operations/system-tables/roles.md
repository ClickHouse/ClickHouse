<div id="description">
  ## Description
</div>

Informations sur les [rôles](../../guides/sre/user-management/index.md#role-management) configurés.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du rôle.
* `id` ([UUID](/fr/sql-reference/data-types/uuid)) — ID du rôle.
* `storage` ([String](/fr/sql-reference/data-types/string)) — Chemin d’accès à l’emplacement de stockage des rôles. Configuré dans le paramètre `access_control_path`.

{/*AUTOGENERATED_END*/ }
