<div id="description">
  ## Description
</div>

Contient des informations sur le nombre d&#39;événements survenus dans le système. Par exemple, dans la table, vous pouvez voir combien de requêtes `SELECT` ont été traitées depuis le démarrage du serveur ClickHouse.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/fr/sql-reference/data-types/string)) — Nom de l’événement.
* `value` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre d’occurrences de l’événement.
* `description` ([String](/fr/sql-reference/data-types/string)) — Description de l’événement.

**Alias :**

* `name` — alias de `event`.

{/*AUTOGENERATED_END*/ }

<div id="example">

```sql
SELECT * FROM system.events LIMIT 5
```
