<div id="description">
  ## Description
</div>

Cette table n&#39;existe pas si ce nœud n&#39;est pas configuré pour exécuter un ClickHouse Keeper in-process. Elle contient une ligne par fichier de snapshot Raft géré par la machine à états de Keeper in-process, y compris les snapshots en cours de réception depuis le leader.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `last_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Dernier index du log couvert par le snapshot.
* `path` ([String](../../sql-reference/data-types/string.md)) — Chemin du fichier snapshot sur le disque.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Nom du disque qui stocke le snapshot.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Taille du fichier snapshot sur le disque.
* `last_modified_at` ([DateTime](../../sql-reference/data-types/datetime.md)) — Date et heure de dernière modification du fichier snapshot.
* `is_received` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si le snapshot est en cours de réception depuis le leader. Pour ces lignes, `size_bytes` et `last_modified_at` reflètent le fichier partiel tel qu’il a été écrit jusque-là et peuvent être sous-estimés.
* `exists_on_disk` ([Bool](../../sql-reference/data-types/boolean.md)) — Indique si le fichier snapshot est actuellement présent sur le disque. Toujours `true` pour les snapshots finalisés (`is_received` = `false`), sauf si le fichier a été supprimé par un autre mécanisme ou s’il est corrompu ; peut être `false` pour les snapshots en cours de réception (`is_received` = `true`) avant l’écriture du moindre octet.

{/*AUTOGENERATED_END*/ }

Exemple :

```sql
SELECT * FROM system.keeper_snapshots ORDER BY last_log_index;
```

```text
┌─last_log_index─┬─path──────────────────────────┬─disk_name─┬─size_bytes─┬────last_modified_at─┬─is_received─┬─exists_on_disk─┐
│           1000 │ snapshot_1000.bin.zstd        │ default   │      32468 │ 2026-05-22 14:00:00 │ false       │ true           │
│           2000 │ snapshot_2000.bin.zstd        │ default   │      48217 │ 2026-05-22 14:15:00 │ false       │ true           │
└────────────────┴───────────────────────────────┴───────────┴────────────┴─────────────────────┴─────────────┴────────────────┘
```
