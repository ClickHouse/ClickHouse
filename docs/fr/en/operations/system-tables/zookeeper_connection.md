<div id="description">
  ## Description
</div>

Cette table n’existe pas si ZooKeeper n’est pas configuré. La table &#39;system.zookeeper&#95;connection&#39; affiche les connexions actuelles à ZooKeeper (y compris les ZooKeeper auxiliaires). Chaque ligne contient des informations sur une connexion.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](../../sql-reference/data-types/string.md)) — nom du cluster ZooKeeper.
* `host` ([String](../../sql-reference/data-types/string.md)) — nom d’hôte/IP du nœud ZooKeeper auquel ClickHouse s’est connecté.
* `port` ([UIn16](../../sql-reference/data-types/int-uint.md)) — port du nœud ZooKeeper auquel ClickHouse s’est connecté.
* `index` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — index du nœud ZooKeeper auquel ClickHouse s’est connecté. L’index provient de la configuration de ZooKeeper. En l’absence de connexion, cette colonne vaut NULL.
* `connected_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — moment où la connexion a été établie
* `session_uptime_elapsed_seconds` ([UInt64](../../sql-reference/data-types/int-uint.md)) — nombre de secondes écoulées depuis l’établissement de la connexion.
* `is_expired` ([UInt8](../../sql-reference/data-types/int-uint.md)) — indique si la connexion actuelle a expiré.
* `keeper_api_version` ([UInt8](../../sql-reference/data-types/int-uint.md)) — version de l’API Keeper.
* `client_id` ([Int64](../../sql-reference/data-types/int-uint.md)) — ID de session de la connexion.
* `xid` ([Int64](../../sql-reference/data-types/int-uint.md)) — XID de la session actuelle.
* `enabled_feature_flags` ([Array(Enum16)](../../sql-reference/data-types/array.md)) — feature flags activés. S’applique uniquement à ClickHouse Keeper. Les valeurs possibles sont `FILTERED_LIST`, `MULTI_READ`, `CHECK_NOT_EXISTS`, `CREATE_IF_NOT_EXISTS`, `REMOVE_RECURSIVE`.
* `availability_zone` ([String](../../sql-reference/data-types/string.md)) — zone de disponibilité.
* `session_timeout_ms` ([UInt64](../../sql-reference/data-types/int-uint.md)) — délai d’expiration de la session (en millisecondes).
* `last_zxid_seen` ([Int64](../../sql-reference/data-types/int-uint.md)) — dernier zxid vu par la session actuelle.

{/*AUTOGENERATED_END*/ }
