<div id="description">
  ## Description
</div>

Contient des informations sur les opérations de fusion et les mutations de parts actuellement en cours pour les tables de la famille MergeTree.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Le nom de la base de données dans laquelle se trouve la table.
* `table` ([String](/fr/sql-reference/data-types/string)) — Le nom de la table.
* `elapsed` ([Float64](/fr/sql-reference/data-types/float)) — Le temps écoulé (en secondes) depuis le début de la fusion.
* `progress` ([Float64](/fr/sql-reference/data-types/float)) — Le pourcentage de travail effectué, de 0 à 1.
* `num_parts` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de parts à fusionner.
* `source_part_names` ([Array(String)](/fr/sql-reference/data-types/array)) — La liste des noms des parts source.
* `result_part_name` ([String](/fr/sql-reference/data-types/string)) — Le nom de la part qui résultera de la fusion.
* `source_part_paths` ([Array(String)](/fr/sql-reference/data-types/array)) — La liste des chemins de chaque part source.
* `result_part_path` ([String](/fr/sql-reference/data-types/string)) — Le chemin de la part qui résultera de la fusion.
* `partition_id` ([String](/fr/sql-reference/data-types/string)) — L’identifiant de la partition dans laquelle la fusion a lieu.
* `partition` ([String](/fr/sql-reference/data-types/string)) — Le nom de la partition
* `is_mutation` ([UInt8](/fr/sql-reference/data-types/int-uint)) — 1 si ce processus est une mutation de part.
* `total_size_bytes_compressed` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La taille totale des données compressées dans les fragments fusionnés.
* `total_size_bytes_uncompressed` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La taille totale des données non compressées dans les fragments fusionnés.
* `total_size_marks` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre total de marks dans les parts fusionnées.
* `bytes_read_uncompressed` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre d’octets lus, non compressés.
* `rows_read` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de lignes lues.
* `bytes_written_uncompressed` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre d’octets écrits, non compressés.
* `rows_written` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de lignes écrites.
* `columns_written` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de colonnes écrites (pour l’algorithme de fusion verticale).
* `memory_usage` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Consommation mémoire du processus de fusion.
* `thread_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Identifiant du thread du processus de fusion.
* `merge_type` ([String](/fr/sql-reference/data-types/string)) — Le type de la fusion en cours. Vide s’il s’agit d’une mutation.
* `merge_algorithm` ([String](/fr/sql-reference/data-types/string)) — L’algorithme utilisé pour la fusion en cours. Vide s’il s’agit d’une mutation.

{/*AUTOGENERATED_END*/ }
