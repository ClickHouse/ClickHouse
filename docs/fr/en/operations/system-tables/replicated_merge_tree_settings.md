<div id="description">
  ## Description
</div>

Contient la liste de tous les paramètres spécifiques au moteur ReplicatedMergeTree, avec leurs valeurs actuelles, leurs valeurs par défaut et leur description. Vous pouvez modifier chacun d’eux dans la section SETTINGS de la requête CREATE.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du paramètre.
* `value` ([String](/fr/sql-reference/data-types/string)) — Valeur du paramètre.
* `default` ([String](/fr/sql-reference/data-types/string)) — Valeur par défaut du paramètre.
* `changed` ([UInt8](/fr/sql-reference/data-types/int-uint)) — 1 si le paramètre a été explicitement défini dans la configuration ou explicitement modifié.
* `description` ([String](/fr/sql-reference/data-types/string)) — Description du paramètre.
* `min` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Valeur minimale du paramètre, si elle est définie via des contraintes. Si le paramètre n&#39;a pas de valeur minimale, contient NULL.
* `max` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Valeur maximale du paramètre, si elle est définie via des contraintes. Si le paramètre n&#39;a pas de valeur maximale, contient NULL.
* `disallowed_values` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des valeurs non autorisées
* `readonly` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si l&#39;utilisateur courant peut modifier le paramètre : 0 — L&#39;utilisateur courant peut modifier le paramètre, 1 — L&#39;utilisateur courant ne peut pas modifier le paramètre.
* `type` ([String](/fr/sql-reference/data-types/string)) — Type du paramètre (valeur de chaîne propre à l&#39;implémentation).
* `is_obsolete` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si le paramètre est obsolète.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/fr/sql-reference/data-types/enum)) — Niveau de prise en charge de cette fonctionnalité. Les fonctionnalités de ClickHouse sont organisées en niveaux, qui varient selon l&#39;état actuel de leur
  développement et les attentes que l&#39;on peut avoir quant à leur utilisation :
  * PRODUCTION: La fonctionnalité est stable, sûre à utiliser et ne pose pas de problèmes d&#39;interaction avec les autres fonctionnalités PRODUCTION.
  * BETA: La fonctionnalité est stable et sûre. Les effets de son utilisation conjointe avec d&#39;autres fonctionnalités sont inconnus et son bon fonctionnement n&#39;est pas garanti. Les tests et les signalements sont les bienvenus.
  * EXPERIMENTAL: La fonctionnalité est en cours de développement. Elle est destinée uniquement aux développeurs et aux passionnés de ClickHouse. Elle peut fonctionner ou non et peut être supprimée à tout moment.
  * OBSOLETE: Elle n&#39;est plus prise en charge. Soit elle est déjà supprimée, soit elle le sera dans de futures versions.
