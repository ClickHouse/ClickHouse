<div id="description">
  ## Description
</div>

Contient des informations sur les [types de données](../../sql-reference/data-types/index.md).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du type de données.
* `case_insensitive` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Propriété indiquant si un nom de type de données peut être utilisé dans une requête sans tenir compte de la casse. Par exemple, `Date` et `date` sont tous deux valides.
* `alias_to` ([String](/fr/sql-reference/data-types/string)) — Nom du type de données dont `name` est un alias.
* `description` ([String](/fr/sql-reference/data-types/string)) — Description générale du type de données.
* `syntax` ([String](/fr/sql-reference/data-types/string)) — Façon dont le type de données s&#39;écrit dans une requête.
* `examples` ([String](/fr/sql-reference/data-types/string)) — Exemples d&#39;utilisation.
* `introduced_in` ([String](/fr/sql-reference/data-types/string)) — Version de ClickHouse dans laquelle le type de données a été introduit pour la première fois, au format major.minor.
* `related` ([Array](/fr/sql-reference/data-types/array)([String](/fr/sql-reference/data-types/string))) — Noms des types de données associés.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
│ TINYTEXT   │                1 │ String   │
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
