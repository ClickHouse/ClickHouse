<div id="description">
  ## Description
</div>

Cette table contient des informations sur les colonnes des parties de projection des tables de la famille MergeTree.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/fr/sql-reference/data-types/string)) — Le nom de la partition.
* `name` ([String](/fr/sql-reference/data-types/string)) — Nom de la part de données.
* `part_type` ([String](/fr/sql-reference/data-types/string)) — Le format de stockage de la part de données.
* `parent_name` ([String](/fr/sql-reference/data-types/string)) — Le nom de la part de données source (parente).
* `parent_uuid` ([UUID](/fr/sql-reference/data-types/uuid)) — L&#39;UUID de la part de données source (parente).
* `parent_part_type` ([String](/fr/sql-reference/data-types/string)) — Le format de stockage de la part de données source (parente).
* `active` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si la part de données est active
* `marks` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de marques.
* `rows` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de lignes.
* `bytes_on_disk` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale de tous les fichiers de la part de données, en octets.
* `data_compressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données compressées dans la part de données. Les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `data_uncompressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données non compressées dans la part de données. Les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `marks_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La taille du fichier de marques.
* `parent_marks` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de marques dans la part source (parente).
* `parent_rows` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de lignes dans la part source (parente).
* `parent_bytes_on_disk` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale de tous les fichiers de la part de données source (parente), en octets.
* `parent_data_compressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données compressées dans la part de données source (parente).
* `parent_data_uncompressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données non compressées dans la part de données source (parente).
* `parent_marks_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La taille du fichier de marques dans la part de données source (parente).
* `modification_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — L&#39;heure à laquelle le répertoire contenant la part de données a été modifié. Cela correspond généralement à l&#39;heure de création de la part de données.
* `remove_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — L&#39;heure à laquelle la part de données est devenue inactive.
* `refcount` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre d&#39;endroits où la part de données est utilisée. Une valeur supérieure à 2 indique que la part de données est utilisée dans des requêtes ou des opérations de fusion.
* `min_date` ([Date](/fr/sql-reference/data-types/date)) — La valeur minimale de la colonne Date si celle-ci est incluse dans la clé de partitionnement.
* `max_date` ([Date](/fr/sql-reference/data-types/date)) — La valeur maximale de la colonne Date si celle-ci est incluse dans la clé de partitionnement.
* `min_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — La valeur minimale de la colonne DateTime si celle-ci est incluse dans la clé de partitionnement.
* `max_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Valeur maximale de la colonne DateTime si celle-ci est incluse dans la clé de partition.
* `partition_id` ([String](/fr/sql-reference/data-types/string)) — ID de la partition.
* `min_block_number` ([Int64](/fr/sql-reference/data-types/int-uint)) — Nombre minimal de parties de données qui composent la partie actuelle après fusion.
* `max_block_number` ([Int64](/fr/sql-reference/data-types/int-uint)) — Nombre maximal de parties de données qui composent la partie actuelle après fusion.
* `level` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Profondeur de l’arbre de fusion. Zéro signifie que la partie actuelle a été créée par insert plutôt que par fusion d’autres parties.
* `data_version` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre utilisé pour déterminer quelles mutations doivent être appliquées à la partie de données (les mutations ayant une version supérieure à data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Quantité de mémoire (en octets) utilisée par les valeurs de la clé primaire.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Quantité de mémoire (en octets) réservée aux valeurs de la clé primaire.
* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `engine` ([String](/fr/sql-reference/data-types/string)) — Nom du moteur de table sans paramètres.
* `disk_name` ([String](/fr/sql-reference/data-types/string)) — Nom du disque qui stocke la partie de données.
* `path` ([String](/fr/sql-reference/data-types/string)) — Chemin absolu vers le dossier contenant les fichiers de la partie de données.
* `column` ([String](/fr/sql-reference/data-types/string)) — Nom de la colonne.
* `type` ([String](/fr/sql-reference/data-types/string)) — Type de la colonne.
* `column_position` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Position ordinale d’une colonne dans une table, à partir de 1.
* `default_kind` ([String](/fr/sql-reference/data-types/string)) — Type d’expression (DEFAULT, MATERIALIZED, ALIAS) pour la valeur par défaut, ou chaîne vide s’il n’est pas défini.
* `default_expression` ([String](/fr/sql-reference/data-types/string)) — Expression de la valeur par défaut, ou chaîne vide si elle n’est pas définie.
* `column_bytes_on_disk` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale de la colonne, en octets.
* `column_data_compressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données compressées dans la colonne, en octets.
* `column_data_uncompressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données décompressées dans la colonne, en octets.
* `column_marks_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille de la colonne avec les marks, en octets.
* `column_modification_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Date de dernière modification de la colonne.

**Alias :**

* `bytes` — alias de `bytes_on_disk`.
* `marks_size` — alias de `marks_bytes`.
* `part_name` — alias de `name`.
