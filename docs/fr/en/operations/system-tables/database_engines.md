<div id="description">
  ## Description
</div>

Répertorie les moteurs de base de données pris en charge par le serveur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom du moteur de base de données.
* `description` ([String](/fr/sql-reference/data-types/string)) — Une description générale du rôle du moteur de base de données.
* `syntax` ([String](/fr/sql-reference/data-types/string)) — La manière dont le moteur de base de données est spécifié dans la clause ENGINE d’une requête CREATE DATABASE.
* `examples` ([String](/fr/sql-reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/sql-reference/data-types/string)) — La version de ClickHouse dans laquelle le moteur de base de données a été introduit pour la première fois, sous la forme major.minor.
* `related` ([Array](/fr/sql-reference/data-types/array)([String](/fr/sql-reference/data-types/string))) — Les noms des moteurs de base de données associés.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql title="Query"
SELECT name
FROM system.database_engines
WHERE name IN ('Atomic', 'Ordinary')
ORDER BY name
```

│ Atomic   │
