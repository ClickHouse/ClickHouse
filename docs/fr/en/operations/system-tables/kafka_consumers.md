<div id="description">
  ## Description
</div>

Contient des informations sur les consommateurs Kafka.
S&#39;applique au [moteur de table Kafka](../../engines/table-engines/integrations/kafka) (intégration native de ClickHouse)

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Base de données de la table avec le moteur Kafka.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table avec le moteur Kafka.
* `consumer_id` ([String](/fr/sql-reference/data-types/string)) — Identifiant du consommateur Kafka Kafka. Notez qu’une table peut avoir plusieurs consommateurs Kafka. Spécifié par le paramètre `kafka_num_consumers`.
* `assignments.topic` ([Array(String)](/fr/sql-reference/data-types/array)) — Kafka topic.
* `assignments.partition_id` ([Array(Int32)](/fr/sql-reference/data-types/array)) — Identifiant de partition Kafka. Notez qu’un seul consommateur Kafka peut être attribué à une partition.
* `assignments.current_offset` ([Array(Int64)](/fr/sql-reference/data-types/array)) — Offset actuel.
* `assignments.intent_size` ([Array(Nullable(Int64))](/fr/sql-reference/data-types/array)) — Nombre de messages envoyés, mais pas encore commités, dans le nouveau StorageKafka.
* `exceptions.time` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Timestamp de génération des 10 exceptions les plus récentes.
* `exceptions.text` ([Array(String)](/fr/sql-reference/data-types/array)) — Texte des 10 exceptions les plus récentes.
* `last_poll_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Timestamp du poll le plus récent.
* `num_messages_read` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de messages lus par le consommateur Kafka.
* `last_commit_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Timestamp du poll le plus récent.
* `num_commits` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre total de commits du consommateur Kafka.
* `last_rebalance_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Timestamp du rebalance Kafka le plus récent.
* `num_rebalance_revocations` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de fois où les partitions du consommateur Kafka ont été révoquées.
* `num_rebalance_assignments` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de fois où le consommateur Kafka a été attribué au cluster Kafka.
* `is_currently_used` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur montrant si le consommateur Kafka est en cours d’utilisation.
* `last_used` ([DateTime64(6)](/fr/sql-reference/data-types/datetime64)) — Dernier moment où ce consommateur Kafka a été utilisé.
* `rdkafka_stat` ([String](/fr/sql-reference/data-types/string)) — Statistique interne de la bibliothèque. Définissez statistics&#95;interval&#95;ms sur 0 pour désactiver ; la valeur par défaut est 3000 (une fois toutes les trois secondes).
* `dependencies` ([Array(Array(String))](/fr/sql-reference/data-types/array)) — Dépendances transitives de la base de données.
* `missing_dependencies` ([Array(Array(String))](/fr/sql-reference/data-types/array)) — Dépendances transitives manquantes de la base de données.

{/*AUTOGENERATED_END*/ }
