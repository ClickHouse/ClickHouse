<div id="description">
  ## Description
</div>

Contient des informations sur les fonctions ordinaires et les fonctions d’agrégation.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom de la fonction.
* `is_aggregate` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la fonction est une fonction d’agrégation.
* `case_insensitive` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si le nom de la fonction peut être utilisé sans distinction entre majuscules et minuscules.
* `alias_to` ([String](/fr/sql-reference/data-types/string)) — Le nom d’origine de la fonction, si la fonction est un alias.
* `create_query` ([String](/fr/sql-reference/data-types/string)) — Obsolète.
* `origin` ([Enum8(&#39;System&#39; = 0, &#39;SQLUserDefined&#39; = 1, &#39;ExecutableUserDefined&#39; = 2)](/fr/sql-reference/data-types/enum)) — Obsolète.
* `description` ([String](/fr/sql-reference/data-types/string)) — Description générale de la fonction.
* `syntax` ([String](/fr/sql-reference/data-types/string)) — Signature de la fonction.
* `arguments` ([String](/fr/sql-reference/data-types/string)) — Les arguments de la fonction.
* `parameters` ([String](/fr/sql-reference/data-types/string)) — Les paramètres de la fonction (uniquement pour les fonctions d’agrégation).
* `returned_value` ([String](/fr/sql-reference/data-types/string)) — La valeur renvoyée par la fonction.
* `examples` ([String](/fr/sql-reference/data-types/string)) — Exemple d’utilisation.
* `introduced_in` ([String](/fr/sql-reference/data-types/string)) — Version de ClickHouse dans laquelle la fonction a été introduite.
* `categories` ([String](/fr/sql-reference/data-types/string)) — La catégorie de la fonction.
* `deterministic` ([Nullable(UInt8)](/fr/sql-reference/data-types/int-uint)) — Indique si la fonction renvoie le même résultat pour les mêmes arguments. `NULL` lorsque cette information est inconnue (par ex. pour les fonctions d’agrégation ou les fonctions définies par l’utilisateur).
* `higher_order` ([Nullable(UInt8)](/fr/sql-reference/data-types/int-uint)) — Indique si la fonction est d’ordre supérieur, c’est-à-dire si elle accepte au moins une expression lambda comme argument (par ex. `arrayMap`, `arrayFilter`, `mapApply`). `NULL` lorsque cette information est inconnue.

{/*AUTOGENERATED_END*/ }
