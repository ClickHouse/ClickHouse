<div id="description">
  ## Description
</div>

Contient les attributions de rôles aux utilisateurs et aux rôles. Pour ajouter des entrées dans cette table, utilisez `GRANT role TO user`.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `user_name` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Nom de l’utilisateur.
* `role_name` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Nom du rôle.
* `granted_role_name` ([String](/fr/sql-reference/data-types/string)) — Nom du rôle accordé au rôle `role_name`. Pour accorder un rôle à un autre, utilisez `GRANT role1 TO role2`.
* `granted_role_id` ([UUID](/fr/sql-reference/data-types/uuid)) — Identifiant du rôle.
* `granted_role_is_default` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur indiquant si `granted_role` est un rôle par défaut. Valeurs possibles : • 1 — `granted_role` est un rôle par défaut, • 0 — `granted_role` n’est pas un rôle par défaut.
* `with_admin_option` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur indiquant si `granted_role` dispose du privilège `ADMIN OPTION`. Valeurs possibles : • 1 — Le rôle dispose du privilège `ADMIN OPTION`. • 0 — Le rôle ne dispose pas du privilège `ADMIN OPTION`.

{/*AUTOGENERATED_END*/ }
