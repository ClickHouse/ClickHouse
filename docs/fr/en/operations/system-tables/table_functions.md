<div id="description">
  ## Description
</div>

Contient la liste de toutes les fonctions de table disponibles, accompagnées de leur description.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom d’une fonction de table.
* `description` ([String](/fr/sql-reference/data-types/string)) — Brève description d’une fonction de table.
* `allow_readonly` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si un utilisateur readonly peut utiliser cette fonction.

{/*AUTOGENERATED_END*/ }
