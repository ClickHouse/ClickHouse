<div id="description">
  ## Description
</div>

Contient des informations sur les [spans de traçage](https://opentracing.io/docs/overview/spans/) associés aux requêtes exécutées.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Le nom d’hôte où ce span a été capturé.
* `trace_id` ([UUID](/fr/sql-reference/data-types/uuid)) — ID de la trace de la requête exécutée.
* `span_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — ID du span de traçage.
* `parent_span_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — ID du span de traçage parent.
* `operation_name` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Le nom de l’opération.
* `kind` ([Enum8(&#39;INTERNAL&#39; = 0, &#39;SERVER&#39; = 1, &#39;CLIENT&#39; = 2, &#39;PRODUCER&#39; = 3, &#39;CONSUMER&#39; = 4)](/fr/sql-reference/data-types/enum)) — Le SpanKind du span. INTERNAL — Indique que le span représente une opération interne au sein d’une application. SERVER — Indique que le span couvre le traitement côté serveur d’une RPC synchrone ou d’une autre requête distante. CLIENT — Indique que le span décrit une requête adressée à un service distant. PRODUCER — Indique que le span décrit les initiateurs d’une requête asynchrone. Ce span parent se termine souvent avant le span CONSUMER enfant correspondant, parfois même avant que le span enfant ne commence. CONSUMER - Indique que le span décrit un enfant d’une requête PRODUCER asynchrone.
* `start_time_us` ([UInt64](/fr/sql-reference/data-types/int-uint)) — L’heure de début du span de traçage (en microsecondes).
* `finish_time_us` ([UInt64](/fr/sql-reference/data-types/int-uint)) — L’heure de fin du span de traçage (en microsecondes).
* `finish_date` ([Date](/fr/sql-reference/data-types/date)) — La date de fin du span de traçage.
* `status_code` ([Enum8(&#39;UNSET&#39; = 0, &#39;OK&#39; = 1, &#39;ERROR&#39; = 2)](/fr/sql-reference/data-types/enum)) — Le code d’état du span.
* `status_message` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Message d’erreur.
* `attribute` ([Map(LowCardinality(String), String)](/fr/sql-reference/data-types/map)) — Attributs du span de traçage. Ils sont renseignés conformément aux recommandations de la norme OpenTelemetry.

**Alias :**

* `attribute.names` — alias de `mapKeys(attribute)`.
* `attribute.values` — alias de `mapValues(attribute)`.

{/*AUTOGENERATED_END*/ }
