<div id="description">
  ## Description
</div>

Contient des filtres pour une table particulière, ainsi qu’une liste de rôles et/ou d’utilisateurs auxquels cette politique de ligne doit s’appliquer.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom d’une politique de lignes.
* `short_name` ([String](/fr/sql-reference/data-types/string)) — Nom court d’une politique de lignes. Les noms des politiques de lignes sont composés, par exemple : myfilter ON mydb.mytable. Ici, &#39;myfilter ON mydb.mytable&#39; est le nom de la politique de lignes, et &#39;myfilter&#39; en est le nom court.
* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table. Vide si la politique concerne la base de données.
* `id` ([UUID](/fr/sql-reference/data-types/uuid)) — ID de la politique de lignes.
* `storage` ([String](/fr/sql-reference/data-types/string)) — Nom du répertoire dans lequel la politique de lignes est stockée.
* `select_filter` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — Expression utilisée pour le filtrage dans les requêtes SELECT.
* `is_restrictive` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la politique de lignes restreint l’accès aux lignes. Valeur : • 0 — La politique de lignes est définie avec la clause `AS PERMISSIVE`, • 1 — La politique de lignes est définie avec la clause AS RESTRICTIVE.
* `apply_to_all` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique que les politiques de lignes sont définies pour tous les rôles et/ou utilisateurs.
* `apply_to_list` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des rôles et/ou utilisateurs auxquels les politiques de lignes s’appliquent.
* `apply_to_except` ([Array(String)](/fr/sql-reference/data-types/array)) — Les politiques de lignes s’appliquent à tous les rôles et/ou utilisateurs, à l’exception de ceux listés.

{/*AUTOGENERATED_END*/ }
