<div id="description">
  ## Description
</div>

Informations relatives aux [vues matérialisées actualisables](../../sql-reference/statements/create/view.md#refreshable-materialized-view). Contient toutes les vues matérialisées actualisables, qu’une actualisation soit en cours ou non.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données dans laquelle se trouve la table.
* `view` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/sql-reference/data-types/uuid)) — UUID de la table (base de données Atomic).
* `status` ([String](/fr/sql-reference/data-types/string)) — État actuel du rafraîchissement.
* `last_success_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure de début du dernier rafraîchissement réussi. NULL si aucun rafraîchissement réussi n&#39;a eu lieu depuis le démarrage du serveur ou la création de la table.
* `last_success_duration_ms` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Durée du dernier rafraîchissement.
* `last_refresh_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure à laquelle la dernière tentative de rafraîchissement s&#39;est terminée (si elle est connue) ou a commencé (si elle est inconnue ou toujours en cours). NULL si aucune tentative de rafraîchissement n&#39;a eu lieu depuis le démarrage du serveur ou la création de la table.
* `last_refresh_replica` ([String](/fr/sql-reference/data-types/string)) — Si la coordination est activée, nom de la réplique ayant effectué la tentative de rafraîchissement actuelle (si elle est en cours) ou précédente (sinon).
* `next_refresh_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure à laquelle le prochain rafraîchissement est planifié. NULL si l&#39;heure du prochain rafraîchissement n&#39;est pas connue actuellement, par exemple en attente de dépendances (statut `WaitingForDependencies` ou `MissingDependencies`).
* `exception` ([String](/fr/sql-reference/data-types/string)) — Message d&#39;erreur de la tentative précédente en cas d&#39;échec.
* `retry` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de tentatives échouées jusqu&#39;à présent pour le rafraîchissement en cours. Non disponible si le statut est `RunningOnAnotherReplica`.
* `progress` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Progression du rafraîchissement actuellement en cours ou le plus récemment terminé sur la réplique donnée, entre 0 et 1. NULL si le statut est `RunningOnAnotherReplica` ou si le rafraîchissement n&#39;est pas en cours.
* `read_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre de lignes lues par le rafraîchissement actuellement en cours ou le plus récemment terminé sur la réplique donnée. NULL si le statut est `RunningOnAnotherReplica`.
* `read_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre d&#39;octets lus par le rafraîchissement actuellement en cours ou le plus récemment terminé sur la réplique donnée. NULL si le statut est `RunningOnAnotherReplica`
* `total_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total estimé de lignes à lire par le rafraîchissement actuellement en cours ou le plus récemment terminé sur la réplique donnée. NULL si le statut est `RunningOnAnotherReplica`
* `written_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre de lignes écrites par le rafraîchissement actuellement en cours ou le plus récemment terminé sur la réplique donnée. NULL si le statut est `RunningOnAnotherReplica`
* `written_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre d&#39;octets écrits par le rafraîchissement actuellement en cours ou le plus récemment terminé sur la réplique donnée. NULL si le statut est `RunningOnAnotherReplica`

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql
SELECT
    database,
    view,
    status,
    last_refresh_time,
    next_refresh_time
FROM system.view_refreshes

┌─database─┬─view───────────────────────┬─status────┬───last_refresh_time─┬───next_refresh_time─┐
│ default  │ hello_documentation_reader │ Scheduled │ 2023-12-01 01:24:00 │ 2023-12-01 01:25:00 │
└──────────┴────────────────────────────┴───────────┴─────────────────────┴─────────────────────┘
```
