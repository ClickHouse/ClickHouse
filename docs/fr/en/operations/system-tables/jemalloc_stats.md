<div id="description">
  ## Description
</div>

Renvoie les statistiques jemalloc sous la forme d’une seule ligne et d’une seule colonne. Équivalent à la commande SYSTEM JEMALLOC STATS.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `stats` ([String](/fr/sql-reference/data-types/string)) — sortie des statistiques jemalloc générée par malloc&#95;stats&#95;print.
