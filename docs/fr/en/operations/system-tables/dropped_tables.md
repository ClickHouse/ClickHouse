<div id="description">
  ## Description
</div>

Contient des informations sur les tables ayant fait l’objet d’une commande DROP TABLE, mais dont le nettoyage des données n’a pas encore été effectué.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Index dans la file d’attente marked&#95;dropped&#95;tables.
* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/sql-reference/data-types/uuid)) — UUID de la table.
* `engine` ([String](/fr/sql-reference/data-types/string)) — Nom du moteur de la table.
* `metadata_dropped_path` ([String](/fr/sql-reference/data-types/string)) — Chemin du fichier de métadonnées de la table dans le répertoire metadata&#95;dropped.
* `table_dropped_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Heure à laquelle la prochaine tentative de suppression des données de la table est prévue. Il s’agit généralement de l’heure à laquelle la table a été supprimée, à laquelle s’ajoute `database_atomic_delay_before_drop_table_sec`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

L’exemple suivant montre comment obtenir des informations sur `dropped_tables`.

```sql
SELECT *
FROM system.dropped_tables\G
```
