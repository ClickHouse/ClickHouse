<div id="description">
  ## Description
</div>

Cette table n’existe pas si ce nœud n’est pas configuré pour exécuter un ClickHouse Keeper intégré au processus. Elle contient une ligne par fichier de changelog Raft (`changelog_<from>_<to>.bin[.zstd]`) suivi par le stockage de logs du Keeper intégré au processus, y compris le fichier actif auquel de nouvelles entrées sont actuellement ajoutées.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `from_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Premier index de log Raft dans le fichier (inclus).
* `to_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Dernier index de log Raft couvert par le nom du fichier (inclus). Pour le fichier actif, il s&#39;agit de la cible de rotation et il peut être supérieur à `last_entry_index`.
* `last_entry_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Index de log le plus élevé effectivement ajouté à ce fichier. `NULL` si le fichier actif n&#39;a encore reçu aucune entrée ou si le fichier est endommagé.
* `entries` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Nombre d&#39;entrées ajoutées à ce fichier. `ALIAS` de `ifNull(last_entry_index - from_log_index + 1, 0)`.
* `path` ([String](../../sql-reference/data-types/string.md)) — Chemin du fichier sur le disque.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Nom du disque qui contient le fichier.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Taille du fichier sur le disque.
* `modification_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — Date et heure de la dernière modification du fichier.
* `is_compressed` ([Bool](../../sql-reference/data-types/boolean.md)) — La payload du fichier est compressée avec zstd.
* `active` ([Bool](../../sql-reference/data-types/boolean.md)) — Ce fichier reçoit actuellement des ajouts.
* `is_broken` ([Bool](../../sql-reference/data-types/boolean.md)) — Un enregistrement final corrompu a été détecté au démarrage.

{/*AUTOGENERATED_END*/ }

Exemple :

```sql
SELECT from_log_index, to_log_index, entries, path, active FROM system.keeper_changelogs ORDER BY from_log_index;
```
