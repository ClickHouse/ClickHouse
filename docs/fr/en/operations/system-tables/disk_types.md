<div id="description">
  ## Description
</div>

Contient la liste des types de disque pris en charge par le serveur, ainsi que la documentation intégrée pour chacun d’eux. Un type de disque est spécifié dans le champ `type` d’une configuration de disque et détermine où et comment un disque stocke ses données (système de fichiers local, stockage objet, cache sur un autre disque, etc.).

Notez que cette table répertorie les *types* de disque disponibles, tandis que [`system.disks`](/fr/operations/system-tables/disks) répertorie les instances de disque configurées sur le serveur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom du type de disque, tel qu’il est spécifié dans le champ `type` d’une configuration de disque.
* `description` ([String](/fr/sql-reference/data-types/string)) — Une description générale du rôle du type de disque.
* `syntax` ([String](/fr/sql-reference/data-types/string)) — La manière dont le type de disque est spécifié dans une configuration de disque.
* `examples` ([String](/fr/sql-reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/sql-reference/data-types/string)) — La version de ClickHouse dans laquelle le type de disque a été introduit pour la première fois, au format major.minor.
* `related` ([Array](/fr/sql-reference/data-types/array)([String](/fr/sql-reference/data-types/string))) — Les noms des types de disque associés.

{/*AUTOGENERATED_END*/ }

<div id="configuration-examples">
  ## Exemples de configuration
</div>

Un disque peut être configuré de deux façons : **statiquement**, dans les fichiers de configuration du serveur (XML ou YAML), ou **dynamiquement**, dans les paramètres d’une requête `CREATE`/`ATTACH` à l’aide de la fonction `disk`. Le même type de disque et les mêmes paramètres sont pris en charge dans les deux cas.

<div id="static-configuration">
  ### Configuration statique
</div>

Les disques sont définis dans `storage_configuration`, dans la configuration du serveur. L’exemple suivant définit un disque `s3` et une politique de stockage qui l’utilise.

```xml title="config.xml"
<clickhouse>
    <storage_configuration>
        <disks>
            <s3_disk>
                <type>s3</type>
                <endpoint>https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/</endpoint>
                <use_environment_credentials>1</use_environment_credentials>
            </s3_disk>
        </disks>
        <policies>
            <s3_policy>
                <volumes>
                    <main>
                        <disk>s3_disk</disk>
                    </main>
                </volumes>
            </s3_policy>
        </policies>
    </storage_configuration>
</clickhouse>
```

La même configuration en YAML :

```yaml title="config.yaml"
storage_configuration:
  disks:
    s3_disk:
      type: s3
      endpoint: https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/
      use_environment_credentials: 1
  policies:
    s3_policy:
      volumes:
        main:
          disk: s3_disk
```

Une table peut alors utiliser le disque grâce à sa stratégie de stockage :

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS storage_policy = 's3_policy';
```

<div id="dynamic-configuration">
  ### Configuration dynamique
</div>

Un disque peut également être défini directement dans les paramètres d’une requête `CREATE`/`ATTACH`, sans qu’un disque soit prédéfini dans les fichiers de configuration, à l’aide de la fonction `disk` :

```sql title="Query"
CREATE TABLE test (a Int32, b String)
ENGINE = MergeTree() ORDER BY a
SETTINGS disk = disk(
    type = s3,
    endpoint = 'https://s3.eu-west-1.amazonaws.com/clickhouse-eu-west-1.clickhouse.com/data/',
    use_environment_credentials = 1
);
```

Voir [Configuration du stockage externe](/fr/operations/storing-data) pour la liste complète des paramètres de chaque type de disque.

<div id="example">
  ## Exemple
</div>

```sql title="Query"
SELECT name, description
FROM system.disk_types
WHERE name IN ('local', 'object_storage')
ORDER BY name
```
