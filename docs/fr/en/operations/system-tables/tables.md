<div id="description">
  ## Description
</div>

Contient les métadonnées de chaque table connue du serveur.

Les tables [détachées](../../sql-reference/statements/detach.md) n’apparaissent pas dans `system.tables`.

Les [tables temporaires](../../sql-reference/statements/create/table.md#temporary-tables) ne sont visibles dans `system.tables` que dans la session où elles ont été créées. Elles apparaissent avec le champ `database` vide et l’indicateur `is_temporary` activé.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données à laquelle appartient la table.
* `name` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/sql-reference/data-types/uuid)) — UUID de la table (base de données Atomic).
* `engine` ([String](/fr/sql-reference/data-types/string)) — Nom du moteur de table (sans paramètres).
* `is_temporary` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si la table est temporaire.
* `data_paths` ([Array(String)](/fr/sql-reference/data-types/array)) — Chemins vers les données de la table dans les systèmes de fichiers.
* `metadata_path` ([String](/fr/sql-reference/data-types/string)) — Chemin vers les métadonnées de la table dans le système de fichiers.
* `metadata_modification_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Date et heure de la dernière modification des métadonnées de la table.
* `metadata_version` ([Int32](/fr/sql-reference/data-types/int-uint)) — Version des métadonnées pour une table ReplicatedMergeTree ; 0 pour une table non ReplicatedMergeTree.
* `dependencies_database` ([Array(String)](/fr/sql-reference/data-types/array)) — Dépendances de la base de données.
* `dependencies_table` ([Array(String)](/fr/sql-reference/data-types/array)) — Dépendances de la table (vues matérialisées de la table actuelle).
* `create_table_query` ([String](/fr/sql-reference/data-types/string)) — Requête utilisée pour créer la table.
* `engine_full` ([String](/fr/sql-reference/data-types/string)) — Paramètres du moteur de table.
* `as_select` ([String](/fr/sql-reference/data-types/string)) — Requête SELECT pour la vue.
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/fr/sql-reference/data-types/array)) — Paramètres de la vue paramétrée.
* `partition_key` ([String](/fr/sql-reference/data-types/string)) — Expression de la clé de partition définie pour la table.
* `sorting_key` ([String](/fr/sql-reference/data-types/string)) — Expression de la clé de tri définie pour la table.
* `primary_key` ([String](/fr/sql-reference/data-types/string)) — Expression de la clé primaire définie pour la table.
* `sampling_key` ([String](/fr/sql-reference/data-types/string)) — Expression de la clé d&#39;échantillonnage définie pour la table.
* `storage_policy` ([String](/fr/sql-reference/data-types/string)) — Politique de stockage. Pertinent pour les tables utilisant les moteurs MergeTree et Distributed.
* `total_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total de lignes, s&#39;il est possible de déterminer rapidement le nombre exact de lignes de la table ; sinon NULL (y compris la table Buffer sous-jacente).
* `total_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total d&#39;octets, s&#39;il est possible de déterminer rapidement le nombre exact d&#39;octets de la table sur le stockage ; sinon NULL (hors stockage sous-jacent). Si la table stocke les données sur disque, renvoie l&#39;espace disque utilisé (c.-à-d. compressé). Si la table stocke les données en mémoire, renvoie un nombre approximatif d&#39;octets utilisés en mémoire.
* `total_bytes_uncompressed` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total d&#39;octets non compressés, s&#39;il est possible de déterminer rapidement le nombre exact d&#39;octets à partir des part checksums de la table sur le stockage ; sinon NULL (sans tenir compte du stockage sous-jacent, le cas échéant).
* `parts` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total de parts dans cette table.
* `active_parts` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre de parts actives dans cette table.
* `total_marks` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total de marks dans toutes les parts de cette table.
* `active_on_fly_data_mutations` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre total de mutations de données actives (UPDATE et DELETE) pouvant être appliquées à la volée.
* `active_on_fly_alter_mutations` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre total de mutations d’altération actives (MODIFY COLUMN) pouvant être appliquées à la volée.
* `active_on_fly_metadata_mutations` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre total de mutations de métadonnées actives (RENAME) pouvant être appliquées à la volée.
* `columns_descriptions_cache_size` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille du cache des descriptions de colonnes pour les tables *MergeTree
* `lifetime_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total de lignes insérées depuis le démarrage du serveur (uniquement pour les Buffer tables).
* `lifetime_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total d’octets insérés depuis le démarrage du serveur (uniquement pour les Buffer tables).
* `comment` ([String](/fr/sql-reference/data-types/string)) — Commentaire de la table.
* `has_own_data` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant si la table stocke elle-même des données sur disque ou accède uniquement à une autre source.
* `loading_dependencies_database` ([Array(String)](/fr/sql-reference/data-types/array)) — Dépendances de chargement de la base de données (liste des objets qui doivent être chargés avant l’objet actuel).
* `loading_dependencies_table` ([Array(String)](/fr/sql-reference/data-types/array)) — Dépendances de chargement de la table (liste des objets qui doivent être chargés avant l’objet actuel).
* `loading_dependent_database` ([Array(String)](/fr/sql-reference/data-types/array)) — Base de données dépendante pour le chargement.
* `loading_dependent_table` ([Array(String)](/fr/sql-reference/data-types/array)) — Table dépendante pour le chargement.
* `target_database` ([String](/fr/sql-reference/data-types/string)) — Pour une vue matérialisée, la base de données de la table de destination dans laquelle la vue écrit (la cible `TO` ou la table implicite `.inner.*`). Vide pour les autres moteurs.
* `target_table` ([String](/fr/sql-reference/data-types/string)) — Pour une vue matérialisée, le nom de la table de destination dans laquelle la vue écrit (la cible `TO` ou la table implicite `.inner.*`). Vide pour les autres moteurs.
* `definer` ([String](/fr/sql-reference/data-types/string)) — Nom du définisseur SQL SECURITY utilisé pour la table.

**Alias :**

* `table` — alias de `name`.

{/*AUTOGENERATED_END*/ }
