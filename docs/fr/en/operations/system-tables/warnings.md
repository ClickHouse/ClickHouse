<div id="description">
  ## Description
</div>

Contient des avertissements concernant la configuration du serveur, affichés par clickhouse-client juste après sa connexion au serveur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `message` ([String](/fr/sql-reference/data-types/string)) — Un message d’avertissement émis par le serveur ClickHouse.
* `message_format_string` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Une chaîne de format utilisée pour mettre en forme le message.
