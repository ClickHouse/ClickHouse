<div id="description">
  ## Description
</div>

Contient les propriétés des profils de paramètres configurés.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du profil de paramètres.
* `id` ([UUID](/fr/sql-reference/data-types/uuid)) — ID du profil de paramètres.
* `storage` ([String](/fr/sql-reference/data-types/string)) — Chemin du stockage des profils de paramètres. Configuré dans le paramètre `access_control_path`.
* `num_elements` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre d&#39;éléments de ce profil dans la table `system.settings_profile_elements`.
* `apply_to_all` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique que le profil de paramètres s&#39;applique à tous les rôles et/ou utilisateurs.
* `apply_to_list` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des rôles et/ou utilisateurs auxquels le profil de paramètres s&#39;applique.
* `apply_to_except` ([Array(String)](/fr/sql-reference/data-types/array)) — Le profil de paramètres s&#39;applique à tous les rôles et/ou utilisateurs, à l&#39;exception de ceux figurant dans la liste.

{/*AUTOGENERATED_END*/ }
