<div id="description">
  ## Description
</div>

Identique à [`system.numbers`](../../operations/system-tables/numbers.md), mais la lecture s’effectue en parallèle. Les nombres peuvent être renvoyés dans un ordre quelconque.

Utilisé pour les tests.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `number` ([UInt64](/fr/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }
