<div id="description">
  ## Description
</div>

Affiche tous les stemmers disponibles.
Ils peuvent être utilisés dans la fonction [stem](../../sql-reference/functions/nlp-functions.md).

:::note Disponibilité
`system.stemmers` n’est présent que dans les builds de ClickHouse compilés avec la dépendance `libstemmer` (`USE_LIBSTEMMER`). Dans les builds qui n’en disposent pas, la table n’existe pas et les requêtes qui la ciblent échoueront avec `UNKNOWN_TABLE`. Vous pouvez vérifier si cette prise en charge est activée dans votre build avec :

```sql
SELECT value FROM system.build_options WHERE name = 'USE_LIBSTEMMER';
```

:::

Colonnes :

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Identifiant du stemmer de Snowball (langue/algorithme)

{/*AUTOGENERATED_END*/ }
