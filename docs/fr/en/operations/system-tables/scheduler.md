<div id="description">
  ## Description
</div>

Contient des informations sur les [nœuds d’ordonnancement](/fr/operations/workload-scheduling.md/#hierarchy) présents sur le serveur local, ainsi que sur leur état.
Cette table peut être utilisée pour le monitoring. Elle contient une ligne pour chaque nœud d’ordonnancement.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `resource` ([String](/fr/sql-reference/data-types/string)) — Nom de la ressource
* `path` ([String](/fr/sql-reference/data-types/string)) — Chemin vers un nœud d’ordonnancement dans cette hiérarchie d’ordonnancement des ressources
* `type` ([String](/fr/sql-reference/data-types/string)) — Type d’un nœud d’ordonnancement.
* `weight` ([Float64](/fr/sql-reference/data-types/float)) — Poids d’un nœud, utilisé par un nœud parent de type `fair`.
* `priority` ([Int64](/fr/sql-reference/data-types/int-uint)) — Priorité d’un nœud, utilisée par un nœud parent de type &#39;priority&#39; (une valeur plus faible signifie une priorité plus élevée).
* `is_active` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si ce nœud est actuellement actif : il a des requêtes de ressource à sortir de la file d’attente et toutes les contraintes sont satisfaites.
* `active_children` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre d’enfants à l’état actif.
* `dequeued_requests` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre total de requêtes de ressource sorties de la file d’attente depuis ce nœud.
* `canceled_requests` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre total de requêtes de ressource annulées depuis ce nœud.
* `dequeued_cost` ([Int64](/fr/sql-reference/data-types/int-uint)) — La somme des coûts (par ex. la taille en octets) de toutes les requêtes sorties de la file d’attente depuis ce nœud.
* `throughput` ([Float64](/fr/sql-reference/data-types/float)) — Débit moyen actuel (coût sorti de la file d’attente par seconde).
* `canceled_cost` ([Int64](/fr/sql-reference/data-types/int-uint)) — La somme des coûts (par ex. la taille en octets) de toutes les requêtes annulées depuis ce nœud.
* `busy_periods` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre total de désactivations de ce nœud.
* `vruntime` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les enfants des nœuds `fair`. Runtime virtuel d’un nœud, utilisé par l’algorithme SFQ pour sélectionner le prochain enfant à traiter de manière équitable max-min.
* `system_vruntime` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `fair`. Runtime virtuel indiquant le `vruntime` de la dernière requête de ressource traitée. Utilisé lors de l’activation d’un enfant comme nouvelle valeur de `vruntime`.
* `queue_length` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `fifo`. Nombre actuel de requêtes de ressource présentes dans la file d’attente.
* `queue_cost` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `fifo`. Somme des coûts (par ex. la taille en octets) de toutes les requêtes présentes dans la file d’attente.
* `budget` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `fifo`. Le nombre d’&#39;unités de coût&#39; disponibles pour les nouvelles requêtes de ressource. Peut apparaître en cas d’écart entre les coûts estimés et réels des requêtes de ressource (par ex. après un échec de lecture/écriture)
* `is_satisfied` ([Nullable(UInt8)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds de contrainte (par ex. `inflight_limit`). Égal à `1` si toutes les contraintes de ce nœud sont satisfaites.
* `inflight_requests` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Le nombre de requêtes de ressource sorties de la file d’attente depuis ce nœud, qui sont actuellement en cours de consommation.
* `inflight_cost` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. La somme des coûts (par ex. les octets) de toutes les requêtes de ressource sorties de la file d’attente depuis ce nœud, qui sont actuellement en cours de consommation.
* `max_requests` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Limite supérieure pour inflight&#95;requests entraînant une violation de contrainte.
* `max_cost` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Limite supérieure pour inflight&#95;cost entraînant une violation de contrainte.
* `max_speed` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Limite supérieure du débit en jetons par seconde.
* `max_burst` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Limite supérieure des jetons disponibles dans le throttler à seau de jetons.
* `throttling_us` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Nombre total de microsecondes pendant lesquelles ce nœud était en état de limitation de débit.
* `tokens` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Nombre de jetons actuellement disponibles dans le régulateur à seau de jetons.

{/*AUTOGENERATED_END*/ }
