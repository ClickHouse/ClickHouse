<div id="description">
  ## Description
</div>

Cette table contient une unique colonne UInt64 nommée `number`, qui contient presque tous les entiers naturels à partir de zéro.

Vous pouvez utiliser cette table pour des tests, ou si vous devez effectuer une recherche exhaustive.

Les lectures de cette table ne sont pas parallélisées.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `number` ([UInt64](/fr/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }
