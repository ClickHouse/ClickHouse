<div id="description">
  ## Description
</div>

Contient des informations sur les paramètres globaux du serveur, définis dans `config.xml`.
Actuellement, la table n’affiche que les paramètres du premier niveau de `config.xml` et ne prend pas en charge les configurations imbriquées (par exemple [logger](../../operations/server-configuration-parameters/settings.md#logger)).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du paramètre serveur.
* `value` ([String](/fr/sql-reference/data-types/string)) — Valeur du paramètre serveur.
* `default` ([String](/fr/sql-reference/data-types/string)) — Valeur par défaut du paramètre serveur.
* `changed` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si le paramètre a été spécifié dans config.xml
* `description` ([String](/fr/sql-reference/data-types/string)) — Brève description du paramètre serveur.
* `type` ([String](/fr/sql-reference/data-types/string)) — Type de valeur du paramètre serveur.
* `changeable_without_restart` ([Enum8(&#39;No&#39; = 0, &#39;IncreaseOnly&#39; = 1, &#39;DecreaseOnly&#39; = 2, &#39;Yes&#39; = 3)](/fr/sql-reference/data-types/enum)) — Indique si un paramètre peut être modifié à l’exécution.
* `is_obsolete` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si un paramètre est obsolète.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql
SELECT *
FROM system.server_settings
WHERE name LIKE '%thread_pool%'
```

L’utilisation de `WHERE changed` peut être utile, par exemple, lorsque vous souhaitez vérifier
si les paramètres des fichiers de configuration sont correctement chargés et pris en compte.

{/* */ }

```sql
SELECT * FROM system.server_settings WHERE changed AND name='max_thread_pool_size'
```
