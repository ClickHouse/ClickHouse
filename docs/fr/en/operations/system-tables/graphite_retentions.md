<div id="description">
  ## Description
</div>

Contient des informations sur les paramètres [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite) utilisés dans les tables avec des moteurs [*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/fr/sql-reference/data-types/string)) — Nom du paramètre graphite&#95;rollup.
* `rule_type` ([String](/fr/sql-reference/data-types/string)) — Le type de règle. Valeurs possibles : RuleTypeAll = 0 - par défaut, avec regex, compatible avec l’ancien schéma ; RuleTypePlain = 1 - métriques simples, avec regex, compatible avec l’ancien schéma ; RuleTypeTagged = 2 - métriques taguées, avec regex, compatible avec l’ancien schéma ; RuleTypeTagList = 3 - métriques taguées, avec regex (converti en RuleTypeTagged à partir d’une chaîne comme &#39;retention=10min ; env=(staging|prod)&#39;)
* `regexp` ([String](/fr/sql-reference/data-types/string)) — Motif du nom de métrique.
* `function` ([String](/fr/sql-reference/data-types/string)) — Nom de la fonction d’agrégation.
* `age` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Âge minimal des données, en secondes.
* `precision` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Précision utilisée pour définir l’âge des données, en secondes.
* `priority` ([UInt16](/fr/sql-reference/data-types/int-uint)) — Priorité du motif.
* `is_default` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si le motif est celui par défaut.
* `Tables.database` ([Array(String)](/fr/sql-reference/data-types/array)) — Tableau des noms de bases de données des tables qui utilisent le paramètre `config_name`.
* `Tables.table` ([Array(String)](/fr/sql-reference/data-types/array)) — Tableau des noms de tables qui utilisent le paramètre `config_name`.
