<div id="description">
  ## Description
</div>

Contient des informations sur chacune des répliques des bases de données Replicated.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données Replicated.
* `is_readonly` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la réplique de la base de données est en mode lecture seule.
* `max_log_ptr` ([Int32](/fr/sql-reference/data-types/int-uint)) — Numéro maximal d&#39;entrée dans le journal d&#39;activité générale.
* `replica_name` ([String](/fr/sql-reference/data-types/string)) — Nom de la réplique dans ClickHouse Keeper.
* `replica_path` ([String](/fr/sql-reference/data-types/string)) — Chemin des données de la réplique dans ClickHouse Keeper.
* `zookeeper_path` ([String](/fr/sql-reference/data-types/string)) — Chemin des données de la base de données dans ClickHouse Keeper.
* `shard_name` ([String](/fr/sql-reference/data-types/string)) — Nom du shard dans le cluster.
* `log_ptr` ([Int32](/fr/sql-reference/data-types/int-uint)) — Numéro maximal d&#39;entrée dans le journal d&#39;activité générale que la réplique a copié dans sa file d&#39;exécution, plus un.
* `total_replicas` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Nombre total de répliques connues de cette base de données.
* `zookeeper_exception` ([String](/fr/sql-reference/data-types/string)) — Message de la dernière exception, obtenu si l&#39;erreur s&#39;est produite lors de la récupération des informations depuis ClickHouse Keeper.
* `is_session_expired` ([UInt8](/fr/sql-reference/data-types/int-uint)) — La session avec ClickHouse Keeper a expiré. C&#39;est essentiellement la même chose que `is_readonly`.

{/*AUTOGENERATED_END*/ }
