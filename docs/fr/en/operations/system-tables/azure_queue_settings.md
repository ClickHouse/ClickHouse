<div id="description">
  ## Description
</div>

Contient des informations sur les paramètres des tables [AzureQueue](../../engines/table-engines/integrations/azure-queue.md).
Disponible à partir de la version `24.10` du serveur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Base de données de la table utilisant le moteur AzureQueue.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table utilisant le moteur AzureQueue.
* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du paramètre.
* `value` ([String](/fr/sql-reference/data-types/string)) — Valeur du paramètre.
* `type` ([String](/fr/sql-reference/data-types/string)) — Type du paramètre (chaîne spécifique à l’implémentation).
* `changed` ([UInt8](/fr/sql-reference/data-types/int-uint)) — 1 si le paramètre a été explicitement défini dans la config ou explicitement modifié.
* `description` ([String](/fr/sql-reference/data-types/string)) — Description du paramètre.
* `alterable` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si l’utilisateur courant peut modifier le paramètre via ALTER TABLE MODIFY SETTING : 0 — L’utilisateur courant ne peut pas modifier le paramètre, 1 — L’utilisateur courant peut modifier le paramètre.

{/*AUTOGENERATED_END*/ }
