<div id="description">
  ## Description
</div>

Contient des informations sur toutes les politiques de masquage définies dans le système.

Les politiques de masquage ne peuvent être créées et appliquées que dans ClickHouse Cloud. Dans les versions open-source, la table `system.masking_policies` est toujours vide, mais elle est tout de même présente afin que les requêtes d&#39;introspection telles que `SHOW MASKING POLICIES` fonctionnent et renvoient un résultat vide au lieu de lever une exception.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string.md)) — Nom d&#39;une politique de masquage. Le format du nom complet est `short_name ON database.table`.
* `short_name` ([String](/fr/sql-reference/data-types/string.md)) — Nom court d&#39;une politique de masquage. Par exemple, si le nom complet est `mask_email ON mydb.mytable`, le nom court est `mask_email`.
* `database` ([String](/fr/sql-reference/data-types/string.md)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string.md)) — Nom de la table.
* `id` ([UUID](/fr/sql-reference/data-types/uuid.md)) — ID de la politique de masquage.
* `storage` ([String](/fr/sql-reference/data-types/string.md)) — Nom du répertoire où la politique de masquage est stockée.
* `update_assignments` ([Nullable(String)](/fr/sql-reference/data-types/nullable.md)) — Affectations UPDATE qui définissent comment les données doivent être masquées. Par exemple : `email = '***masked***', phone = '***-***-****'`.
* `where_condition` ([Nullable(String)](/fr/sql-reference/data-types/nullable.md)) — Condition WHERE facultative qui précise quand le masquage doit être appliqué.
* `priority` ([Int64](/fr/sql-reference/data-types/int-uint.md)) — Priorité d&#39;application de plusieurs politiques de masquage. Les politiques ayant la priorité la plus élevée sont appliquées en premier. La valeur par défaut est 0.
* `apply_to_all` ([UInt8](/fr/sql-reference/data-types/int-uint.md)) — Indique si la politique de masquage s&#39;applique à tous les rôles et/ou utilisateurs. 1 si true, 0 sinon.
* `apply_to_list` ([Array(String)](/fr/sql-reference/data-types/array.md)) — Liste des rôles et/ou utilisateurs auxquels la politique de masquage s&#39;applique.
* `apply_to_except` ([Array(String)](/fr/sql-reference/data-types/array.md)) — La politique de masquage s&#39;applique à tous les rôles et/ou utilisateurs, sauf à ceux qui sont listés. Renseigné uniquement lorsque `apply_to_all` vaut 1.
