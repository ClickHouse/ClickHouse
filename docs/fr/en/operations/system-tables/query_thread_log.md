<div id="description">
  ## Description
</div>

Contient des informations sur les threads qui exécutent les requêtes, notamment le nom du thread, son heure de démarrage et la durée de traitement de la requête.

Pour activer la journalisation :

1. Configurez les paramètres dans la section [query&#95;thread&#95;log](/fr/operations/server-configuration-parameters/settings#query_thread_log).
2. Définissez [log&#95;query&#95;threads](/fr/operations/settings/settings#log_query_threads) sur 1.

La périodicité de vidage des données est définie par le paramètre `flush_interval_milliseconds` de la section des paramètres serveur [query&#95;thread&#95;log](/fr/operations/server-configuration-parameters/settings#query_thread_log). Pour forcer le vidage, utilisez la requête [SYSTEM FLUSH LOGS](/fr/sql-reference/statements/system#flush-logs).

ClickHouse ne supprime pas automatiquement les données de la table. Consultez [Introduction](/fr/operations/system-tables/overview#system-tables-introduction) pour plus de détails.

Vous pouvez utiliser le paramètre [log&#95;queries&#95;probability](/fr/operations/settings/settings#log_queries_probability)) pour réduire le nombre de requêtes enregistrées dans la table `query_thread_log`.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom d’hôte du serveur qui exécute la requête.
* `event_date` ([Date](/fr/sql-reference/data-types/date)) — La date à laquelle le thread a terminé l’exécution de la requête.
* `event_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — La date et l’heure auxquelles le thread a terminé l’exécution de la requête.
* `event_time_microseconds` ([DateTime64(6)](/fr/sql-reference/data-types/datetime64)) — La date et l’heure auxquelles le thread a terminé l’exécution de la requête avec une précision à la microseconde.
* `query_start_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Heure de début de l’exécution de la requête.
* `query_start_time_microseconds` ([DateTime64(6)](/fr/sql-reference/data-types/datetime64)) — Heure de début de l’exécution de la requête avec une précision à la microseconde.
* `query_duration_ms` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Durée d’exécution de la requête.
* `read_rows` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de lignes lues.
* `read_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre d’octets lus.
* `written_rows` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Pour les requêtes INSERT, le nombre de lignes écrites. Pour les autres requêtes, la valeur de la colonne est 0.
* `written_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Pour les requêtes INSERT, le nombre d’octets écrits. Pour les autres requêtes, la valeur de la colonne est 0.
* `memory_usage` ([Int64](/fr/sql-reference/data-types/int-uint)) — Différence entre la quantité de mémoire allouée et celle libérée dans le contexte de ce thread.
* `peak_memory_usage` ([Int64](/fr/sql-reference/data-types/int-uint)) — Différence maximale entre la quantité de mémoire allouée et celle libérée dans le contexte de ce thread.
* `thread_name` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom du thread.
* `thread_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — ID interne du thread.
* `master_thread_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — ID initial du thread principal au niveau du système d’exploitation.
* `current_database` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom de la base de données courante.
* `query` ([String](/fr/sql-reference/data-types/string)) — Texte de la requête.
* `normalized_query_hash` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Hachage de la requête normalisée, avec constantes effacées, etc.
* `is_initial_query` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Type de requête. Valeurs possibles : 1 — la requête a été initiée par le client, 0 — la requête a été initiée par une autre requête pour l’exécution distribuée des requêtes.
* `connection_address` ([IPv6](/fr/sql-reference/data-types/ipv6)) — Adresse IP du client à partir de laquelle la connexion a été établie. En cas de connexion via un proxy, il s’agit de l’adresse du proxy.
* `connection_port` ([UInt16](/fr/sql-reference/data-types/int-uint)) — Port client à partir duquel la connexion a été établie. En cas de connexion via un proxy, il s’agit du port du proxy.
* `user` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom de l’utilisateur qui a initié la requête courante.
* `query_id` ([String](/fr/sql-reference/data-types/string)) — ID de la requête.
* `address` ([IPv6](/fr/sql-reference/data-types/ipv6)) — Adresse IP utilisée pour effectuer la requête. En cas de connexion via un proxy et si `auth_use_forwarded_address` est défini, il s’agira de l’adresse du client au lieu de celle du proxy.
* `port` ([UInt16](/fr/sql-reference/data-types/int-uint)) — Le port client utilisé pour exécuter la requête. En cas de connexion via un proxy, si `auth_use_forwarded_address` est défini, il s’agit du port du client et non de celui du proxy.
* `initial_user` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom de l’utilisateur qui a exécuté la requête initiale (pour l’exécution distribuée des requêtes).
* `initial_query_id` ([String](/fr/sql-reference/data-types/string)) — ID de la requête initiale (pour l’exécution distribuée des requêtes).
* `initial_address` ([IPv6](/fr/sql-reference/data-types/ipv6)) — Adresse IP depuis laquelle la requête parente a été lancée.
* `initial_port` ([UInt16](/fr/sql-reference/data-types/int-uint)) — Le port client utilisé pour exécuter la requête parente.
* `initial_query_start_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Heure de début d’exécution de la requête initiale.
* `initial_query_start_time_microseconds` ([DateTime64(6)](/fr/sql-reference/data-types/datetime64)) — Heure de début d’exécution de la requête initiale
* `authenticated_user` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom de l’utilisateur authentifié dans la session.
* `interface` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Interface depuis laquelle la requête a été lancée. Valeurs possibles : 1 — TCP, 2 — HTTP.
* `is_secure` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur précisant si la connexion était sécurisée.
* `os_user` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom d’utilisateur du système d’exploitation qui exécute clickhouse-client.
* `client_hostname` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom d’hôte de la machine cliente sur laquelle clickhouse-client ou un autre client TCP est exécuté.
* `client_name` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Nom de clickhouse-client ou d’un autre client TCP.
* `client_agent` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Agent IA de développement qui a appelé le client (par exemple, `claude-code` ou `cursor`), détecté à partir des variables d’environnement. Vide si aucun agent n’a été détecté.
* `client_revision` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Révision de clickhouse-client ou d’un autre client TCP.
* `client_version_major` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Version majeure de clickhouse-client ou d’un autre client TCP.
* `client_version_minor` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Version mineure de clickhouse-client ou d’un autre client TCP.
* `client_version_patch` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Composant de correctif de la version de clickhouse-client ou d’un autre client TCP.
* `script_query_number` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Numéro séquentiel d’une requête dans un script contenant plusieurs requêtes.
* `script_line_number` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Numéro de ligne, dans un script contenant plusieurs requêtes, où commence la requête actuelle.
* `http_method` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Méthode HTTP ayant lancé la requête. Valeurs possibles : 0 — la requête a été lancée depuis l’interface TCP, 1 — la méthode GET a été utilisée, 2 — la méthode POST a été utilisée.
* `http_user_agent` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — En-tête `User-Agent` transmis dans la requête HTTP.
* `http_referer` ([String](/fr/sql-reference/data-types/string)) — En-tête HTTP `Referer` transmis dans la requête HTTP (contient une adresse absolue ou partielle de la page qui effectue la requête).
* `forwarded_for` ([String](/fr/sql-reference/data-types/string)) — En-tête HTTP `X-Forwarded-For` transmis dans la requête HTTP.
* `quota_key` ([String](/fr/sql-reference/data-types/string)) — La &#39;clé de quota&#39; spécifiée dans le paramètre quotas.
* `distributed_depth` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de fois qu’une requête a été transférée entre des serveurs.
* `revision` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Révision de ClickHouse.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/fr/sql-reference/data-types/map)) — Les ProfileEvents qui mesurent différentes métriques pour ce thread. Leur description figure dans la table system.events.

**Alias :**

* `ProfileEvents.Names` — alias de `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — alias de `mapValues(ProfileEvents)`.
