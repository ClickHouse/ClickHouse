<div id="description">
  ## Description
</div>

Cette table fournit des informations d’introspection combinées sur ZooKeeper, et les nœuds sont définis dans la configuration.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_cluster_name` ([String](../../sql-reference/data-types/string.md)) — Le nom du cluster ZooKeeper.
* `host` ([String](../../sql-reference/data-types/string.md)) — Le nom d’hôte/l’IP du nœud ZooKeeper auquel ClickHouse s’est connecté.
* `port` ([UInt16](../../sql-reference/data-types/int-uint.md)) — Le port du nœud ZooKeeper auquel ClickHouse s’est connecté.
* `index` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — L’index du nœud ZooKeeper auquel ClickHouse s’est connecté. Cet index provient de la config ZooKeeper. En l’absence de connexion, cette colonne vaut NULL.
* `is_connected` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — Indique si ZooKeeper est connecté ou non.
* `is_readonly` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Indique si l’instance est en lecture seule.
* `version` ([String](../../sql-reference/data-types/string.md)) — La version de ZooKeeper.
* `avg_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La latence moyenne.
* `max_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La latence maximale.
* `min_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La latence minimale.
* `packets_received` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de paquets reçus.
* `packets_sent` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de paquets envoyés.
* `outstanding_requests` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de requêtes en attente.
* `server_state` ([String](../../sql-reference/data-types/string.md)) — L’état du serveur.
* `is_leader` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Indique si ce nœud ZooKeeper est le leader.
* `znode_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de znodes.
* `watch_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de watches.
* `ephemerals_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre d’éléments éphémères.
* `approximate_data_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La taille approximative des données.
* `followers` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de followers du leader. Ce champ n’est exposé que par le leader.
* `synced_followers` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de followers synchronisés du leader. Ce champ n’est exposé que par le leader.
* `pending_syncs` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de synchronisations en attente du leader. Ce champ n’est exposé que par le leader.
* `open_file_descriptor_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de descripteurs de fichier ouverts. Disponible uniquement sur les plateformes Unix.
* `max_file_descriptor_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre maximal de descripteurs de fichier. Disponible uniquement sur les plateformes Unix.
* `connections` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de connexions ZooKeeper.
* `outstanding` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de requêtes en attente dans ZooKeeper.
* `zxid` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le zxid de ZooKeeper.
* `node_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le nombre de nœuds de ZooKeeper.
* `snapshot_dir_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La taille du répertoire de snapshots de ZooKeeper.
* `log_dir_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La taille du répertoire des journaux de ZooKeeper.
* `first_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le premier index de journal de ZooKeeper.
* `first_log_term` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le premier terme de journal de ZooKeeper.
* `last_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le dernier index de journal de ZooKeeper.
* `last_log_term` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le dernier terme de journal de ZooKeeper.
* `last_committed_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le dernier index validé de ZooKeeper.
* `leader_committed_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — L’index de journal validé du leader de ZooKeeper.
* `target_committed_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — L’index de journal validé cible de ZooKeeper.
* `last_snapshot_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Le dernier index de snapshot de ZooKeeper.
