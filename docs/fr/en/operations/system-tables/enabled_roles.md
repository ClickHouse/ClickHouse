<div id="description">
  ## Description
</div>

Contient tous les rôles actifs actuellement, y compris le rôle courant de l’utilisateur courant ainsi que les rôles accordés au rôle courant.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `role_name` ([String](/fr/sql-reference/data-types/string)) — Nom du rôle.
* `with_admin_option` ([UInt8](/fr/sql-reference/data-types/int-uint)) — 1 si le rôle dispose du privilège ADMIN OPTION.
* `is_current` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur indiquant si `enabled_role` est un rôle courant de l’utilisateur courant.
* `is_default` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur indiquant si `enabled_role` est un rôle par défaut.

{/*AUTOGENERATED_END*/ }
