<div id="purpose">
  ## Description
</div>

Contient des informations sur les parts détachées des tables [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md). La colonne `reason` indique pourquoi la part a été détachée.

Pour les parts détachées par l&#39;utilisateur, la raison est vide. Ces parts peuvent être rattachées à l&#39;aide de la commande [ALTER TABLE ATTACH PARTITION|PART](/fr/sql-reference/statements/alter/partition#attach-partitionpart).

Pour la description des autres colonnes, voir [system.parts](../../operations/system-tables/parts.md).

Si le nom de la part n&#39;est pas valide, les valeurs de certaines colonnes peuvent être `NULL`. Ces parts peuvent être supprimées à l&#39;aide de [ALTER TABLE DROP DETACHED PART](/fr/sql-reference/statements/alter/partition#drop-detached-partitionpart).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Le nom de la base de données à laquelle cette part appartient.
* `table` ([String](/fr/sql-reference/data-types/string)) — Le nom de la table à laquelle cette part appartient.
* `partition_id` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — L’identifiant de la partition à laquelle cette part appartient.
* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom de la part.
* `bytes_on_disk` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale de tous les fichiers de la part de données, en octets.
* `modification_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — La date et l’heure auxquelles le répertoire contenant la part de données a été modifié. Cela correspond généralement au moment où le détachement a eu lieu.
* `disk` ([String](/fr/sql-reference/data-types/string)) — Le nom du disque qui stocke cette part de données.
* `path` ([String](/fr/sql-reference/data-types/string)) — Le chemin, sur le disque, vers le fichier de cette part de données.
* `reason` ([Nullable(String)](/fr/sql-reference/data-types/nullable)) — La raison pour laquelle cette part a été détachée.
* `min_block_number` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Le nombre minimal de parts de données qui composent la part actuelle après fusion.
* `max_block_number` ([Nullable(Int64)](/fr/sql-reference/data-types/nullable)) — Le nombre maximal de parts de données qui composent la part actuelle après fusion.
* `level` ([Nullable(UInt32)](/fr/sql-reference/data-types/nullable)) — Profondeur de l’arbre de fusion. Zéro signifie que la part actuelle a été créée par insert plutôt que par fusion d’autres parts.

{/*AUTOGENERATED_END*/ }
