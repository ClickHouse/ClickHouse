<div id="description">
  ## Description
</div>

Utilisation du quota par l’ensemble des utilisateurs.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/fr/sql-reference/data-types/string)) — Nom du quota.
* `quota_key` ([String](/fr/sql-reference/data-types/string)) — Valeur de la clé.
* `is_current` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Utilisation du quota pour l’utilisateur courant.
* `start_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure de début du calcul de la consommation des ressources.
* `end_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Heure de fin du calcul de la consommation des ressources.
* `duration` ([Nullable(UInt32)](/fr/sql-reference/data-types/nullable)) — Durée de l’intervalle de temps utilisé pour calculer la consommation des ressources, en secondes.
* `queries` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre actuel de requêtes exécutées.
* `max_queries` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre maximal autorisé de requêtes de tous types pouvant être exécutées.
* `query_selects` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre actuel de requêtes SELECT exécutées.
* `max_query_selects` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre maximal autorisé de requêtes SELECT pouvant être exécutées.
* `query_inserts` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre actuel de requêtes INSERT exécutées.
* `max_query_inserts` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre maximal autorisé de requêtes INSERT pouvant être exécutées.
* `errors` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre actuel de requêtes ayant entraîné une erreur.
* `max_errors` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre maximal autorisé de requêtes ayant entraîné une erreur pendant la période spécifiée.
* `result_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total actuel de lignes dans le jeu de résultats de toutes les requêtes pendant la période actuelle.
* `max_result_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total maximal autorisé de lignes dans le jeu de résultats de toutes les requêtes pendant la période spécifiée.
* `result_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total actuel d’octets dans le jeu de résultats de toutes les requêtes pendant la période actuelle.
* `max_result_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total maximal autorisé d’octets dans le jeu de résultats de toutes les requêtes pendant la période spécifiée.
* `read_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total actuel de lignes lues lors de l’exécution de toutes les requêtes pendant la période actuelle.
* `max_read_rows` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre maximal autorisé de lignes à lire lors de l’exécution de toutes les requêtes pendant la période spécifiée.
* `read_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total actuel d’octets lus lors de l’exécution de toutes les requêtes pendant la période actuelle.
* `max_read_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre maximal autorisé d’octets à lire lors de l’exécution de toutes les requêtes pendant la période spécifiée.
* `execution_time` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Temps total actuel consacré à l’exécution des requêtes pendant la période actuelle (en nanosecondes)
* `max_execution_time` ([Nullable(Float64)](/fr/sql-reference/data-types/nullable)) — Temps total maximal autorisé pour l’exécution de toutes les requêtes pendant la période spécifiée (en nanosecondes)
* `written_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Nombre total actuel d’octets écrits lors de l’exécution de toutes les requêtes pendant la période actuelle.
* `max_written_bytes` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Le nombre maximal d’octets pouvant être écrits pendant l’exécution de l’ensemble des requêtes autorisées sur la période spécifiée.
* `failed_sequential_authentications` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Le nombre actuel d’échecs d’authentification consécutifs sur la période en cours.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Le nombre maximal d’échecs d’authentification consécutifs autorisés sur la période spécifiée.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Le nombre maximal actuel d’exécutions d’une même requête normalisée sur la période en cours.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Le nombre maximal d’exécutions d’une même requête normalisée autorisées sur la période spécifiée.
