<div id="description">
  ## Description
</div>

Rassemble dans une seule table la documentation embarquée des composants uniformes du système. Chaque ligne correspond à une entité (une fonction, un moteur de table, un type de données, etc.) et contient la documentation de référence de cette entité au format Markdown — le même contenu que celui publié sur le site web et exposé par les tables `system.*` spécifiques à chaque type.

La `description` est assemblée à partir des parties structurées de la documentation embarquée (`description`, `syntax`, arguments, exemples, etc.), de sorte qu&#39;une seule colonne contient la documentation complète d&#39;une entité. Les alias sont présentés sous la forme d&#39;une brève référence à l&#39;entité canonique, par ex. ``Alias of `trunc`.``

Cette table regroupe, d&#39;une certaine manière, les informations disponibles dans les tables de documentation spécifiques à chaque type ([`system.functions`](/fr/operations/system-tables/functions), [`system.table_engines`](/fr/operations/system-tables/table_engines), [`system.data_type_families`](/fr/operations/system-tables/data_type_families), entre autres). Elle est conçue notamment pour servir de base à une commande `help` interactive dans le client, mais elle est aussi utile en elle-même.

Les types d&#39;entités suivants sont regroupés (la valeur de la colonne `type` est indiquée entre parenthèses) :

* Fonctions (`Function`)
* Fonctions d&#39;agrégation (`Aggregate Function`)
* Fonctions de table (`Table Function`)
* Moteurs de table (`Table Engine`)
* Moteurs de base de données (`Database Engine`)
* Types de données (`Data Type`)
* Dispositions de dictionnaires (`Dictionary Layout`)
* Sources de dictionnaires (`Dictionary Source`)
* Combinateurs de fonctions d&#39;agrégation (`Aggregate Function Combinator`)
* Types d&#39;index de saut de données (`Data Skipping Index`)
* Types de disque (`Disk Type`)
* Paramètres (`Setting`)
* Paramètres MergeTree (`MergeTree Setting`)
* Paramètres du serveur (`Server Setting`)
* Formats (`Format`)
* Codecs de compression (`Compression Codec`)
* Événements de profil (`Profile Event`)
* Métriques actuelles (`Current Metric`)
* Métriques asynchrones (`Asynchronous Metric`)
* Tables système (`System Table`)

Pour les paramètres (de tout type), la documentation correspond à la description du paramètre, ainsi qu&#39;à son type et à sa valeur par défaut ; les paramètres obsolètes ne sont pas exposés. Pour les tables système, la documentation correspond au commentaire de table ainsi qu&#39;à la liste de ses colonnes (le nom, le type et la description de chacune).

La colonne `source` contient le chemin du fichier source dans lequel la documentation de l&#39;entité est définie, relatif à la racine du dépôt. Pour la plupart des entités, il est capturé automatiquement à l&#39;endroit où l&#39;objet de documentation est construit (le site d&#39;enregistrement du composant) ; pour les types documentés chacun dans un unique fichier source (comme les paramètres, les événements de profil et les métriques actuelles), il s&#39;agit de ce fichier.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom de l’entité, p. ex. `domainWithoutWWW` ou `MergeTree`.
* `type` ([Enum8](/fr/sql-reference/data-types/enum)) — Le genre de l’entité, p. ex. `Function` ou `Table Engine`.
* `description` ([String](/fr/sql-reference/data-types/string)) — La documentation de référence de l’entité au format Markdown, assemblée à partir de la documentation embarquée (le même contenu que celui publié sur le site web), y compris la syntaxe, les exemples et d’autres sections structurées, le cas échéant.
* `source` ([String](/fr/sql-reference/data-types/string)) — Le chemin du fichier source dans lequel la documentation de l’entité est définie, relatif à la racine du dépôt. Vide si l’emplacement de la source est inconnu.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

Consultez la documentation d’une entité spécifique :

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

Le même nom peut désigner plusieurs types d’entités (par exemple, il existe à la fois une fonction de table `file` et une source de dictionnaire `file`) ; il est donc pratique de rechercher un nom parmi tous les types :

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

Comptez le nombre d’entités documentées de chaque type :

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
