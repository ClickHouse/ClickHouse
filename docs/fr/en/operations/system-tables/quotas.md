<div id="description">
  ## Description
</div>

Contient des informations sur les [quotas](../../operations/system-tables/quotas.md).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du quota.
* `id` ([UUID](/fr/sql-reference/data-types/uuid)) — ID du quota.
* `storage` ([String](/fr/sql-reference/data-types/string)) — Stockage des quotas. Valeur possible : &#39;users.xml&#39; si le quota est configuré dans le fichier users.xml, &#39;disk&#39; si le quota est configuré par une requête SQL.
* `keys` ([Array(Enum8(&#39;user&#95;name&#39; = 1, &#39;ip&#95;address&#39; = 2, &#39;forwarded&#95;ip&#95;address&#39; = 3, &#39;client&#95;key&#39; = 4, &#39;normalized&#95;query&#95;hash&#39; = 7))](/fr/sql-reference/data-types/array)) — La clé indique comment le quota doit être partagé. Si deux connexions utilisent le même quota et la même clé, elles partagent les mêmes quantités de ressources. Valeurs : [] — Tous les utilisateurs partagent le même quota, [&#39;user&#95;name&#39;] — Les connexions avec le même nom d&#39;utilisateur partagent le même quota, [&#39;ip&#95;address&#39;] — Les connexions provenant de la même adresse IP partagent le même quota. [&#39;client&#95;key&#39;] — Les connexions avec la même clé partagent le même quota. Une clé doit être fournie explicitement par un client. Lorsque vous utilisez clickhouse-client, transmettez une valeur de clé via le paramètre --quota&#95;key, ou utilisez le paramètre quota&#95;key dans le fichier de configuration du client. Lorsque vous utilisez l&#39;interface HTTP, utilisez l&#39;en-tête X-ClickHouse-Quota, [&#39;user&#95;name&#39;, &#39;client&#95;key&#39;] — Les connexions avec le même client&#95;key partagent le même quota. Si aucune clé n&#39;est fournie par le client, le quota est suivi pour `user_name`, [&#39;client&#95;key&#39;, &#39;ip&#95;address&#39;] — Les connexions avec le même client&#95;key partagent le même quota. Si aucune clé n&#39;est fournie par le client, le quota est suivi pour ip&#95;address.
* `durations` ([Array(UInt32)](/fr/sql-reference/data-types/array)) — Durées des intervalles de temps en secondes.
* `apply_to_all` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Valeur logique. Elle indique à quels utilisateurs le quota s&#39;applique. Valeurs : 0 — Le quota s&#39;applique aux utilisateurs spécifiés dans apply&#95;to&#95;list. 1 — Le quota s&#39;applique à tous les utilisateurs, sauf ceux listés dans apply&#95;to&#95;except.
* `apply_to_list` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des noms d&#39;utilisateur/rôles auxquels le quota doit s&#39;appliquer.
* `apply_to_except` ([Array(String)](/fr/sql-reference/data-types/array)) — Liste des noms d&#39;utilisateur/rôles auxquels le quota ne doit pas s&#39;appliquer.
* `ipv4_prefix_bits` ([Nullable(UInt8)](/fr/sql-reference/data-types/nullable)) — Nombre de bits de préfixe pour le masquage des adresses IPv4. Les connexions provenant du même sous-réseau partagent le même quota. Utilisé uniquement lorsque la clé est `ip_address` ou `forwarded_ip_address`.
* `ipv6_prefix_bits` ([Nullable(UInt8)](/fr/sql-reference/data-types/nullable)) — Nombre de bits de préfixe pour le masquage des adresses IPv6. Les connexions provenant du même sous-réseau partagent le même quota. Utilisé uniquement lorsque la clé est `ip_address` ou `forwarded_ip_address`.
