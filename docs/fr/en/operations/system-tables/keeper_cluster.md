<div id="description">
  ## Description
</div>

Cette table n&#39;existe pas si ce nœud n&#39;est pas configuré pour exécuter un ClickHouse Keeper intégré au processus. Elle contient une ligne par membre du cluster Raft et combine la topologie statique du cluster (issue de la configuration Raft) avec la position du journal du nœud local.

Chaque nœud renseigne exactement une valeur `last_log_index` — la ligne correspondant à son propre `server_id`. Les positions des journaux des pairs n&#39;apparaissent pas ici, car elles ne sont suivies que sur le leader et cette vue n&#39;est pas symétrique à l&#39;échelle du cluster.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — Identifiant du serveur Raft de ce membre du cluster.
* `host` ([String](../../sql-reference/data-types/string.md)) — Hôte extrait de l’endpoint (préfixe situé avant le dernier deux-points).
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — Endpoint Raft brut tel qu’il est configuré (`host:port`).
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si ce membre est un observateur sans droit de vote, configuré via `<can_become_leader>false</can_become_leader>`.
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — Priorité Raft de ce membre ; les valeurs les plus élevées sont privilégiées lors de l’élection du leader.
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si ce membre est le leader Raft actuel.
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si cette ligne décrit le nœud Keeper local.
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Index de log le plus élevé dans le journal Raft local de ce nœud. Renseigné uniquement sur la ligne correspondant au nœud actuel (`is_self = true`) ; `NULL` pour les autres lignes.

{/*AUTOGENERATED_END*/ }

Exemple :

```sql
SELECT * FROM system.keeper_cluster ORDER BY server_id;
```
