<div id="description">
  ## Description
</div>

Cette table système contient des métadonnées par fichier pour les tables Iceberg présentes dans ClickHouse, avec une ligne pour chaque fichier de données ou de suppression référencé par le snapshot actuel de chaque table. Elle est vide si vous n&#39;avez aucune table Iceberg dans ClickHouse.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `snapshot_id` ([Int64](/fr/sql-reference/data-types/int-uint)) — ID du snapshot auquel le fichier a été ajouté.
* `content` ([Enum8](/fr/sql-reference/data-types/enum)) — Type de contenu du fichier : `DATA`, `POSITION_DELETE` ou `EQUALITY_DELETE`.
* `file_path` ([String](/fr/sql-reference/data-types/string)) — Chemin de stockage résolu du fichier.
* `file_format` ([String](/fr/sql-reference/data-types/string)) — Format du fichier, par ex. `'PARQUET'`.
* `record_count` ([Int64](/fr/sql-reference/data-types/int-uint)) — Nombre d’enregistrements dans le fichier.
* `file_size_in_bytes` ([Int64](/fr/sql-reference/data-types/int-uint)) — Taille du fichier en octets.
* `partition` ([String](/fr/sql-reference/data-types/string)) — Représentation textuelle du tuple de partition.
* `schema_id` ([Int32](/fr/sql-reference/data-types/int-uint)) — ID du schéma résolu pour cette entrée du manifeste.
* `sequence_number` ([Int64](/fr/sql-reference/data-types/int-uint)) — Numéro de séquence résolu de l’entrée du manifeste (toujours 0 pour le format v1).
* `sort_order_id` ([Nullable(Int32)](/fr/sql-reference/data-types/nullable)) — ID de l’ordre de tri du fichier, s’il est spécifié.
* `null_value_counts` ([Map(Int32, Int64)](/fr/sql-reference/data-types/map)) — Nombre de valeurs NULL par colonne (ID de colonne -&gt; nombre).
* `column_sizes` ([Map(Int32, Int64)](/fr/sql-reference/data-types/map)) — Taille sur disque par colonne, en octets (ID de colonne -&gt; octets).
* `value_counts` ([Map(Int32, Int64)](/fr/sql-reference/data-types/map)) — Nombre total de valeurs par colonne (ID de colonne -&gt; nombre).
* `equality_ids` ([Array(Int32)](/fr/sql-reference/data-types/array)) — ID des champs d’égalité pour les fichiers de suppression par égalité (vide pour les fichiers qui ne sont pas de ce type).
