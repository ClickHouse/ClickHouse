<div id="description">
  ## Description
</div>

Contient la liste des layouts de dictionnaire pris en charge par le serveur, ainsi que la documentation intégrée pour chaque layout. Un layout de dictionnaire détermine comment un dictionnaire est stocké en mémoire (ou sur disque) et comment les recherches y sont effectuées ; il est spécifié dans la clause `LAYOUT` d&#39;une requête `CREATE DICTIONARY`.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom du layout du dictionnaire, tel que spécifié dans la clause LAYOUT.
* `is_complex` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si le layout nécessite une clé complexe (une clé composée de plusieurs attributs ou d’un type non entier).
* `description` ([String](/fr/sql-reference/data-types/string)) — Une description générale du rôle du layout.
* `syntax` ([String](/fr/sql-reference/data-types/string)) — Indique comment le layout est spécifié dans la clause LAYOUT d’une requête CREATE DICTIONARY.
* `examples` ([String](/fr/sql-reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/sql-reference/data-types/string)) — La version de ClickHouse dans laquelle le layout a été introduit pour la première fois, au format major.minor.
* `related` ([Array](/fr/sql-reference/data-types/array)([String](/fr/sql-reference/data-types/string))) — Les noms des layouts de dictionnaire associés.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql title="Query"
SELECT name, is_complex, syntax
FROM system.dictionary_layouts
WHERE name IN ('flat', 'hashed', 'complex_key_hashed')
ORDER BY name
```

```text title="Response"
┌─name───────────────┬─is_complex─┬─syntax───────────────────────────────────────────────────┐
│ complex_key_hashed │          1 │ LAYOUT(COMPLEX_KEY_HASHED())                             │
│ flat               │          0 │ LAYOUT(FLAT([INITIAL_ARRAY_SIZE n] [MAX_ARRAY_SIZE n]))  │
│ hashed             │          0 │ LAYOUT(HASHED())                                         │
└────────────────────┴────────────┴──────────────────────────────────────────────────────────┘
```
