<div id="description">
  ## Description
</div>

Affiche tous les tokenizer disponibles.
Ils peuvent être utilisés dans les fonctions [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens), [hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens), [hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens), ainsi que dans l’[index de texte](../../engines/table-engines/mergetree-family/textindexes.md).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Nom du tokenizer

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql
SELECT * FROM system.tokenizers;
```

```text
┌─name────────────┐
│ ngrams          │
│ splitByNonAlpha │
│ sparseGrams     │
│ tokenbf_v1      │
│ ngrambf_v1      │
│ array           │
│ splitByString   │
│ sparse_grams    │
│ asciiCJK        │
└─────────────────┘
```
