<div id="description">
  ## Description
</div>

Affiche le contenu du [cache de requêtes](../query-cache.md).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `query` ([String](/fr/sql-reference/data-types/string)) — Chaîne de la requête.
* `query_id` ([String](/fr/sql-reference/data-types/string)) — ID de la requête.
* `result_size` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille de l&#39;entrée du cache de requêtes.
* `tag` ([LowCardinality(String)](/fr/sql-reference/data-types/lowcardinality)) — Tag de l&#39;entrée du cache de requêtes.
* `stale` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si l&#39;entrée du cache de requêtes est périmée.
* `shared` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si l&#39;entrée du cache de requêtes est partagée entre plusieurs utilisateurs.
* `compressed` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si l&#39;entrée du cache de requêtes est compressée.
* `expires_at` ([DateTime](/fr/sql-reference/data-types/datetime)) — Moment où l&#39;entrée du cache de requêtes devient périmée.
* `key_hash` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Hash de la chaîne de requête, utilisé comme clé pour trouver les entrées du cache de requêtes.

{/*AUTOGENERATED_END*/ }
