<div id="description">
  ## Description
</div>

Contient la liste de tous les combinateurs de fonctions d’agrégation disponibles, qui peuvent être appliqués aux fonctions d’agrégation afin d’en modifier le comportement.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom du combinateur.
* `is_internal` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si ce combinateur est réservé à un usage interne.

{/*AUTOGENERATED_END*/ }
