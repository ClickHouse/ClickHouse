<div id="description">
  ## Description
</div>

Cette table système contient l’historique des instantanés des tables Iceberg présentes dans ClickHouse. Elle sera vide si vous n’avez aucune table Iceberg dans ClickHouse.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `made_current_at` ([Nullable(DateTime64(3))](/fr/sql-reference/data-types/nullable)) — Date et heure auxquelles cet instantané est devenu l’instantané courant.
* `snapshot_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — ID de l’instantané utilisé pour identifier un instantané.
* `parent_id` ([UInt64](/fr/sql-reference/data-types/int-uint)) — ID du parent de cet instantané.
* `is_current_ancestor` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant si cet instantané est un ancêtre de l’instantané courant.

{/*AUTOGENERATED_END*/ }
