<div id="description">
  ## Description
</div>

Contient des informations sur toutes les entrées du cache du système de fichiers pour les objets distants.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `cache_name` ([String](/fr/sql-reference/data-types/string)) — Nom de l&#39;objet cache. Peut être utilisé dans les commandes `SYSTEM DESCRIBE FILESYSTEM CACHE <name>` et `SYSTEM DROP FILESYSTEM CACHE <name>`
* `cache_base_path` ([String](/fr/sql-reference/data-types/string)) — Chemin du répertoire de base où sont stockés tous les fichiers du cache (d&#39;un cache identifié par `cache_name`).
* `cache_path` ([String](/fr/sql-reference/data-types/string)) — Chemin d&#39;un fichier de cache particulier, correspondant à un segment de fichier dans un fichier source
* `key` ([String](/fr/sql-reference/data-types/string)) — Clé de cache du segment de fichier
* `file_segment_range_begin` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Décalage correspondant au début de la plage du segment de fichier
* `file_segment_range_end` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Décalage correspondant à la fin (incluse) de la plage du segment de fichier
* `size` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille du segment de fichier
* `state` ([String](/fr/sql-reference/data-types/string)) — État du segment de fichier (DOWNLOADED, DOWNLOADING, PARTIALLY&#95;DOWNLOADED, ...)
* `finished_download_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Heure à laquelle le téléchargement du segment de fichier s&#39;est terminé.
* `cache_hits` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de succès de cache pour le segment de fichier correspondant
* `references` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre de références au segment de fichier correspondant. La valeur 1 signifie que personne ne l&#39;utilise actuellement (la seule référence existante se trouve dans le stockage du cache lui-même)
* `downloaded_size` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille téléchargée du segment de fichier
* `kind` ([String](/fr/sql-reference/data-types/string)) — Nature du segment de fichier (utilisée pour distinguer les segments de fichier ajoutés dans le cadre de &#39;Temporary data in cache&#39;)
* `unbound` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur interne d&#39;implémentation
* `user_id` ([String](/fr/sql-reference/data-types/string)) — ID de l&#39;utilisateur qui a créé le segment de fichier
* `segment_type` ([String](/fr/sql-reference/data-types/string)) — Type du segment. Utilisé pour distinguer les fichiers de données (`.json`, `.txt`, etc.) des fichiers de données (`.bin`, fichiers de marques).
* `file_size` ([Nullable(UInt64)](/fr/sql-reference/data-types/nullable)) — Taille du fichier auquel appartient le segment de fichier actuel

{/*AUTOGENERATED_END*/ }
