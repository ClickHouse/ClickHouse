<div id="description">
  ## Description
</div>

Contient des informations sur les répertoires utilisateur configurés — des répertoires du système de fichiers depuis lesquels le serveur ClickHouse est autorisé à lire les données fournies par l’utilisateur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom du répertoire.
* `type` ([String](/fr/sql-reference/data-types/string)) — Le type du stockage d’accès, par exemple users.xml, replicated ou memory.
* `params` ([String](/fr/sql-reference/data-types/string)) — JSON contenant les paramètres du stockage d’accès.
* `precedence` ([UInt64](/fr/sql-reference/data-types/int-uint)) — L’ordre dans lequel ce répertoire est déclaré dans la configuration. Le même ordre est utilisé lorsque ClickHouse tente de trouver un utilisateur ou un rôle.

{/*AUTOGENERATED_END*/ }
