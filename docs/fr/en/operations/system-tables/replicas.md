<div id="description">
  ## Description
</div>

Contient des informations et l’état des tables répliquées présentes sur le serveur local.
Cette table peut être utilisée à des fins de surveillance. Elle contient une ligne pour chaque table Replicated*.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/sql-reference/data-types/uuid)) — UUID de la table.
* `engine` ([String](/fr/sql-reference/data-types/string)) — Nom du moteur de la table.
* `is_leader` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la réplique est le leader. Plusieurs répliques peuvent être leaders en même temps. Une réplique peut être empêchée de devenir leader à l’aide du paramètre merge&#95;tree replicated&#95;can&#95;become&#95;leader. Les leaders sont chargés de planifier les fusions en arrière-plan. Notez que des écritures peuvent être effectuées sur n’importe quelle réplique disponible et disposant d’une session dans ZK, qu’elle soit leader ou non.
* `can_become_leader` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la réplique peut devenir leader.
* `is_readonly` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la réplique est en mode lecture seule. Ce mode est activé si la configuration ne contient pas de sections pour ClickHouse Keeper, si une erreur inconnue s’est produite lors de la réinitialisation des sessions dans ClickHouse Keeper, ainsi que pendant la réinitialisation des sessions dans ClickHouse Keeper.
* `readonly_start_time` ([Nullable(DateTime)](/fr/sql-reference/data-types/nullable)) — Le timestamp auquel la réplique est passée en mode readonly. NULL si la réplique n’est pas en mode readonly.
* `is_session_expired` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indique si la session avec ClickHouse Keeper a expiré. En pratique, c’est la même chose que `is_readonly`.
* `future_parts` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre de parties de données qui apparaîtront à la suite d’INSERT ou de fusions qui n’ont pas encore été effectués.
* `parts_to_check` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre de parties de données dans la file d’attente de vérification. Une partie est placée dans la file de vérification s’il y a suspicion qu’elle soit endommagée.
* `zookeeper_name` ([String](/fr/sql-reference/data-types/string)) — Le nom du cluster [Zoo]Keeper (éventuellement auxiliaire) où sont stockées les métadonnées de la table
* `zookeeper_path` ([String](/fr/sql-reference/data-types/string)) — Chemin vers les données de la table dans ClickHouse Keeper.
* `replica_name` ([String](/fr/sql-reference/data-types/string)) — Nom de la réplique dans ClickHouse Keeper. Les différentes répliques d’une même table portent des noms différents.
* `replica_path` ([String](/fr/sql-reference/data-types/string)) — Chemin vers les données de la réplique dans ClickHouse Keeper. Identique à la concaténation de &#39;zookeeper&#95;path/replicas/replica&#95;path&#39;.
* `columns_version` ([Int32](/fr/sql-reference/data-types/int-uint)) — Numéro de version de la structure de la table. Indique combien de fois ALTER a été exécuté. Si les répliques ont des versions différentes, cela signifie que certaines répliques n’ont pas encore appliqué tous les ALTER.
* `queue_size` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Taille de la file d’attente des opérations en attente d’exécution. Ces opérations incluent l’insertion de blocs de données, les fusions et certaines autres actions. Cette valeur coïncide généralement avec future&#95;parts.
* `inserts_in_queue` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Nombre d’insertions de blocs de données à effectuer. Les insertions sont généralement répliquées assez rapidement. Si ce nombre est élevé, cela signifie qu’un problème est survenu.
* `merges_in_queue` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre de fusions en attente d’exécution. Il arrive que les fusions soient longues, donc cette valeur peut rester supérieure à zéro pendant longtemps.
* `part_mutations_in_queue` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre de mutations en attente d’exécution.
* `queue_oldest_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Si `queue_size` est supérieur à 0, indique quand l’opération la plus ancienne a été ajoutée à la file d’attente.
* `inserts_oldest_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Voir `queue_oldest_time`.
* `merges_oldest_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Voir `queue_oldest_time`.
* `part_mutations_oldest_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Voir `queue_oldest_time`.
* `oldest_part_to_get` ([String](/fr/sql-reference/data-types/string)) — Le nom de la part à récupérer depuis d&#39;autres répliques, obtenu à partir de l&#39;entrée GET&#95;PARTS la plus ancienne de la file d&#39;attente de réplication.
* `oldest_part_to_merge_to` ([String](/fr/sql-reference/data-types/string)) — Le nom de la part résultante dans laquelle fusionner, obtenu à partir de l&#39;entrée MERGE&#95;PARTS la plus ancienne de la file d&#39;attente de réplication.
* `oldest_part_to_mutate_to` ([String](/fr/sql-reference/data-types/string)) — Le nom de la part résultante à produire par mutation, obtenu à partir de l&#39;entrée MUTATE&#95;PARTS la plus ancienne de la file d&#39;attente de réplication.
* `log_max_index` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Numéro d&#39;entrée maximal dans le journal d&#39;activité générale. Cette colonne et les trois suivantes (`log_pointer`, `total_replicas`, `active_replicas`) n&#39;ont une valeur non nulle que lorsqu&#39;il existe une session active avec ClickHouse Keeper.
* `log_pointer` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Numéro d&#39;entrée maximal du journal d&#39;activité générale que la réplique a copié dans sa file d&#39;exécution, plus un. Si log&#95;pointer est nettement inférieur à log&#95;max&#95;index, c&#39;est qu&#39;il y a un problème.
* `last_queue_update` ([DateTime](/fr/sql-reference/data-types/datetime)) — Date et heure de la dernière mise à jour de la file d&#39;attente.
* `absolute_delay` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Retard actuel, en secondes, de cette réplique.
* `total_replicas` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Nombre total de répliques connues pour cette table.
* `active_replicas` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre de répliques de cette table qui ont une session dans ClickHouse Keeper (c&#39;est-à-dire le nombre de répliques fonctionnelles).
* `lost_part_count` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre total de data parts perdues dans la table par l&#39;ensemble des répliques depuis la création de la table. La valeur est persistée dans ClickHouse Keeper et ne peut qu&#39;augmenter.
* `last_queue_update_exception` ([String](/fr/sql-reference/data-types/string)) — Lorsque la file d&#39;attente contient des entrées invalides. C&#39;est particulièrement important lorsque ClickHouse rompt la compatibilité descendante entre les versions et que les entrées de journal écrites par des versions plus récentes ne peuvent pas être analysées par les anciennes versions.
* `zookeeper_exception` ([String](/fr/sql-reference/data-types/string)) — Le dernier message d&#39;exception, obtenu si l&#39;erreur s&#39;est produite lors de la récupération des informations depuis ClickHouse Keeper.
* `replica_is_active` ([Map(String, UInt8)](/fr/sql-reference/data-types/map)) — Map associant le nom de la réplique à son état d&#39;activité.

**Alias :**

* `readonly_duration` — alias de `if(isNull(readonly_start_time), NULL, now() - readonly_start_time)`.

{/*AUTOGENERATED_END*/ }
