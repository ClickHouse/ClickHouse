<div id="description">
  ## Description
</div>

Contient des informations sur les parts de la table des tables [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md).

Chaque ligne décrit une part de la table.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `partition` ([String](/fr/sql-reference/data-types/string)) — Identifiant de partition (représentation textuelle dérivée de l’expression de la clé de partitionnement de la table).
* `name` ([String](/fr/sql-reference/data-types/string)) — Nom de la partie de données. La convention de nommage de la partie peut être utilisée pour déterminer de nombreux aspects des données, ainsi que des modèles d’ingestion et de fusion. Le format de nommage de la partie est le suivant :

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * Définitions :
    * `partition_id` - identifie la clé de partition
    * `minimum_block_number` - identifie le numéro de bloc minimal dans la partie. ClickHouse fusionne toujours des blocs continus
    * `maximum_block_number` - identifie le numéro de bloc maximal dans la partie
    * `level` - est incrémenté d’une unité à chaque fusion supplémentaire de la partie. Un niveau de 0 indique qu’il s’agit d’une nouvelle partie qui n’a pas été fusionnée. Il est important de garder à l’esprit que toutes les parties de ClickHouse sont toujours immuables
    * `data_version` - valeur facultative, incrémentée lorsqu’une partie est mutée (là encore, les données mutées sont toujours écrites dans une nouvelle partie uniquement, puisque les parties sont immuables)
* `uuid` ([UUID](/fr/sql-reference/data-types/uuid)) — L’UUID de la partie de données.
* `part_type` ([String](/fr/sql-reference/data-types/string)) — Le format de stockage de la partie de données. Valeurs possibles : `Wide` — chaque colonne est stockée dans un fichier distinct, `Compact` — toutes les colonnes sont stockées dans un seul fichier. Le format de stockage des données est contrôlé par les paramètres `min_bytes_for_wide_part` et `min_rows_for_wide_part` de la table MergeTree.
* `active` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant si la partie de données est active. Si une partie de données est active, elle est utilisée dans une table. Sinon, elle est sur le point d’être supprimée. Les parties de données inactives apparaissent après des opérations de fusion et de mutation.
* `marks` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de marques. Pour obtenir le nombre approximatif de lignes dans une partie de données, multipliez le nombre de marques par la granularité d’index (généralement 8192) (cette indication ne fonctionne pas avec la granularité adaptative).
* `rows` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de lignes.
* `files` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Le nombre de fichiers dans la partie de données.
* `bytes_on_disk` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale de tous les fichiers de la partie de données, en octets.
* `data_compressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données compressées dans la partie de données. Tous les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `data_uncompressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données non compressées dans la partie de données. Tous les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `primary_key_size` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La quantité de mémoire (en octets) utilisée par les valeurs de clé primaire dans le fichier primary.idx/cidx sur le disque.
* `marks_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La taille du fichier de marques.
* `secondary_indices_compressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données compressées pour les indices secondaires dans la partie de données. Tous les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `secondary_indices_uncompressed_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Taille totale des données non compressées pour les indices secondaires dans la partie de données. Tous les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `secondary_indices_marks_bytes` ([UInt64](/fr/sql-reference/data-types/int-uint)) — La taille du fichier de marques pour les indices secondaires.
* `modification_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — L’heure à laquelle le répertoire contenant la partie de données a été modifié. Cela correspond généralement à l’heure de création de la partie de données.
* `remove_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — L’heure à laquelle la partie de données est devenue inactive.
* `refcount` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Le nombre d’endroits où la partie de données est utilisée. Une valeur supérieure à 2 indique que la partie de données est utilisée dans des requêtes ou des fusions.
* `min_date` ([Date](/fr/sql-reference/data-types/date)) — La valeur minimale de la clé de date dans la partie de données.
* `max_date` ([Date](/fr/sql-reference/data-types/date)) — La valeur maximale de la clé de date dans la partie de données.
* `min_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — La valeur minimale de la clé de date et d’heure dans la partie de données.
* `max_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — La valeur maximale de la clé de date et d’heure dans la partie de données.
* `partition_id` ([String](/fr/sql-reference/data-types/string)) — ID de la partition.
* `min_block_number` ([Int64](/fr/sql-reference/data-types/int-uint)) — Le numéro minimal des parties de données qui composent la partie actuelle après fusion.
* `max_block_number` ([Int64](/fr/sql-reference/data-types/int-uint)) — Le numéro maximal des parties de données qui composent la partie actuelle après fusion.
* `level` ([UInt32](/fr/sql-reference/data-types/int-uint)) — Profondeur de la fusion. Zéro signifie que la partie actuelle a été créée par insert plutôt que par fusion d’autres parties.
* `data_version` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Nombre utilisé pour déterminer quelles mutations doivent être appliquées à la part de données (mutations avec une version supérieure à data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Quantité de mémoire (en octets) utilisée par les valeurs de la clé primaire. Vaut 0 lorsque `primary_key_lazy_load` est activé et que la clé n&#39;est pas chargée.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Quantité de mémoire (en octets) réservée aux valeurs de la clé primaire. Vaut 0 lorsque `primary_key_lazy_load` est activé et que la clé n&#39;est pas chargée.
* `index_granularity_bytes_in_memory` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Quantité de mémoire (en octets) utilisée par les valeurs de granularité d&#39;index (vaut 0 lorsque primary&#95;key&#95;lazy&#95;load=1 et use&#95;primary&#95;key&#95;cache=1).
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Quantité de mémoire (en octets) réservée aux valeurs de granularité d&#39;index (vaut 0 lorsque primary&#95;key&#95;lazy&#95;load=1 et use&#95;primary&#95;key&#95;cache=1).
* `is_frozen` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant l&#39;existence d&#39;une sauvegarde de la partition de données. 1 : la sauvegarde existe. 0 : la sauvegarde n&#39;existe pas. Pour plus de détails, voir FREEZE PARTITION.
* `database` ([String](/fr/sql-reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/sql-reference/data-types/string)) — Nom de la table.
* `engine` ([String](/fr/sql-reference/data-types/string)) — Nom du moteur de table sans paramètres.
* `disk_name` ([String](/fr/sql-reference/data-types/string)) — Nom du disque qui stocke la part de données.
* `path` ([String](/fr/sql-reference/data-types/string)) — Chemin absolu vers le dossier contenant les fichiers de la part de données.
* `hash_of_all_files` ([String](/fr/sql-reference/data-types/string)) — sipHash128 des fichiers compressés.
* `hash_of_uncompressed_files` ([String](/fr/sql-reference/data-types/string)) — sipHash128 des fichiers non compressés (fichiers avec marks, fichier d&#39;index, etc.).
* `uncompressed_hash_of_compressed_files` ([String](/fr/sql-reference/data-types/string)) — sipHash128 des données des fichiers compressés comme si elles n&#39;étaient pas compressées.
* `delete_ttl_info_min` ([DateTime](/fr/sql-reference/data-types/datetime)) — Valeur minimale de la clé de date et d&#39;heure pour la règle TTL DELETE.
* `delete_ttl_info_max` ([DateTime](/fr/sql-reference/data-types/datetime)) — Valeur maximale de la clé de date et d&#39;heure pour la règle TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/fr/sql-reference/data-types/array)) — Tableau d&#39;expressions. Chaque expression définit une règle TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Tableau de valeurs de date et d&#39;heure. Chaque élément décrit la valeur minimale de la clé pour une règle TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Tableau de valeurs de date et d&#39;heure. Chaque élément décrit la valeur maximale de la clé pour une règle TTL MOVE.
* `default_compression_codec` ([String](/fr/sql-reference/data-types/string)) — Nom du codec utilisé pour compresser cette part de données (lorsqu&#39;aucun codec explicite n&#39;est défini pour les colonnes).
* `recompression_ttl_info.expression` ([Array(String)](/fr/sql-reference/data-types/array)) — Expression TTL.
* `recompression_ttl_info.min` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Valeur minimale de l&#39;expression TTL calculée dans cette part. Permet de savoir s&#39;il existe au moins une ligne dont le TTL a expiré.
* `recompression_ttl_info.max` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Valeur maximale de l&#39;expression TTL calculée dans cette part. Permet de savoir si toutes les lignes ont un TTL expiré.
* `group_by_ttl_info.expression` ([Array(String)](/fr/sql-reference/data-types/array)) — Expression TTL.
* `group_by_ttl_info.min` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — Valeur minimale de l&#39;expression TTL calculée dans cette part. Permet de savoir s&#39;il existe au moins une ligne dont le TTL a expiré.
* `group_by_ttl_info.max` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — La valeur maximale de l’`expression` TTL calculée dans cette partie. Utilisée pour déterminer si toutes les `rows` ont un TTL expiré.
* `rows_where_ttl_info.expression` ([Array(String)](/fr/sql-reference/data-types/array)) — L’`expression` TTL.
* `rows_where_ttl_info.min` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — La valeur minimale de l’`expression` TTL calculée dans cette partie. Utilisée pour déterminer si au moins une `row` a un TTL expiré.
* `rows_where_ttl_info.max` ([Array(DateTime)](/fr/sql-reference/data-types/array)) — La valeur maximale de l’`expression` TTL calculée dans cette partie. Utilisée pour déterminer si toutes les `rows` ont un TTL expiré.
* `projections` ([Array(String)](/fr/sql-reference/data-types/array)) — La liste des noms de projections calculés pour cette partie.
* `visible` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant si cette partie est visible pour les requêtes SELECT.
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/fr/sql-reference/data-types/tuple)) — ID de la transaction qui a créé/tente de créer cet objet.
* `removal_tid_lock` ([UInt64](/fr/sql-reference/data-types/int-uint)) — Hachage de removal&#95;tid, utilisé pour verrouiller un objet en vue de sa suppression.
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/fr/sql-reference/data-types/tuple)) — ID de la transaction qui a supprimé/tente de supprimer cet objet
* `creation_csn` ([UInt64](/fr/sql-reference/data-types/int-uint)) — CSN de la transaction qui a créé cet objet
* `removal_csn` ([UInt64](/fr/sql-reference/data-types/int-uint)) — CSN de la transaction qui a supprimé cet objet
* `has_lightweight_delete` ([UInt8](/fr/sql-reference/data-types/int-uint)) — Indicateur signalant si la partie possède un masque de suppression légère.
* `last_removal_attempt_time` ([DateTime](/fr/sql-reference/data-types/datetime)) — Dernière fois où le serveur a tenté de supprimer cette partie.
* `removal_state` ([String](/fr/sql-reference/data-types/string)) — L’état actuel du processus de suppression de la partie.

**Alias :**

* `bytes` — alias de `bytes_on_disk`.
* `marks_size` — alias de `marks_bytes`.
* `part_name` — alias de `name`.
