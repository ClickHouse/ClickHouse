<div id="description">
  ## Description
</div>

Contient des informations sur les [workloads](/fr/operations/workload-scheduling.md#workload_entity_storage) présents sur le serveur local. La table comporte une ligne pour chaque workload.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/fr/sql-reference/data-types/string)) — Le nom du workload.
* `parent` ([String](/fr/sql-reference/data-types/string)) — Le nom du workload parent.
* `create_query` ([String](/fr/sql-reference/data-types/string)) — La requête CREATE du workload.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Exemple
</div>

```sql
SELECT *
FROM system.workloads
FORMAT Vertical
```

```text
Row 1:
──────
name:         production
parent:       all
create_query: CREATE WORKLOAD production IN `all` SETTINGS weight = 9

Row 2:
──────
name:         development
parent:       all
create_query: CREATE WORKLOAD development IN `all`

Row 3:
──────
name:         all
parent:
create_query: CREATE WORKLOAD `all`
```
