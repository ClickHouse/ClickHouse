Met en forme les lignes de chaque groupe à l’aide d’un format de sortie et renvoie les données formatées sous forme de chaîne. Cette fonction est similaire à `formatRow`, mais elle s’applique à l’ensemble du groupe et peut utiliser des formats basés sur des blocs.

:::warning
Toutes les lignes de chaque groupe sont accumulées en mémoire avant la production de la chaîne formatée. Pour les groupes comportant un très grand nombre de lignes, cela peut consommer une quantité importante de mémoire. Pensez à utiliser `LIMIT` dans des sous-requêtes ou à scinder les grands groupes pour garder l’utilisation de la mémoire sous contrôle.
:::

<div id="syntax">
  ## Syntaxe
</div>

```sql
groupFormat(format)(x, y, ...)
```

<div id="parameters">
  ## Paramètres
</div>

* `format` — Nom du format de sortie, par exemple `JSONEachRow`, `CSV`, `TabSeparated`.

<div id="arguments">
  ## Arguments
</div>

* `x, y, ...` — Expressions à formater sous forme de lignes. Au moins un argument est requis.

<div id="returned-value">
  ## Valeur renvoyée
</div>

* Une [String](../../data-types/string.md) contenant la sortie mise en forme du groupe.

:::note
Les noms de colonnes dans la sortie mise en forme sont générés sous la forme `c1`, `c2`, ... dans l&#39;ordre des arguments.

L&#39;ordre exact des lignes mises en forme n&#39;est pas garanti.

Les paramètres de format de la requête (par exemple `format_csv_delimiter` ou `output_format_json_quote_64bit_integers`) sont enregistrés lors de l&#39;initialisation de la fonction d&#39;agrégation et utilisés pour produire la sortie. Le paramètre `output_format_write_statistics` est toujours désactivé de force ; la chaîne mise en forme ne contient donc jamais de section de statistiques.
:::

<div id="null-handling">
  ## Gestion de NULL
</div>

Comme `groupArray` et `groupConcat`, `groupFormat` ignore une ligne dès lors que l&#39;un de ses arguments est `NULL` ; ces lignes n&#39;apparaissent pas dans la sortie mise en forme. Lorsqu&#39;un argument peut être NULL, le type de résultat est `Nullable(String)`, et un groupe dont toutes les lignes sont ignorées — ainsi qu&#39;un argument littéral `NULL` non typé de type `Nullable(Nothing)` — renvoie `NULL` via le combinateur générique `Null`.

```sql
SELECT groupFormat('JSONEachRow')(if(number = 0, NULL, number))
FROM numbers(3);
-- {"c1":1}
-- {"c1":2}
```

<div id="examples">
  ## Exemples
</div>

<div id="example-json">
  ### Utilisation de base avec JSONEachRow
</div>

```sql
SELECT groupFormat('JSONEachRow')(number, toString(number))
FROM numbers(3);
```

Résultat :

```text
{"c1":0,"c2":"0"}
{"c1":1,"c2":"1"}
{"c1":2,"c2":"2"}
```
