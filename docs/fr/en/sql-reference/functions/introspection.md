Vous pouvez utiliser les fonctions décrites dans ce chapitre pour examiner [ELF](https://en.wikipedia.org/wiki/Executable_and_Linkable_Format) et [DWARF](https://en.wikipedia.org/wiki/DWARF) dans le cadre du profilage des requêtes.

:::note
Ces fonctions sont lentes et peuvent présenter des implications en matière de sécurité.
:::

Pour assurer le bon fonctionnement des fonctions d’introspection :

* Installez le paquet `clickhouse-common-static-dbg`.

* Définissez le paramètre [allow&#95;introspection&#95;functions](../../operations/settings/settings.md#allow_introspection_functions) sur 1.

  Pour des raisons de sécurité, les fonctions d’introspection sont désactivées par défaut.

ClickHouse enregistre les rapports du profiler dans la table système [trace&#95;log](/fr/operations/system-tables/trace_log). Assurez-vous que la table et le profiler sont correctement configurés.
