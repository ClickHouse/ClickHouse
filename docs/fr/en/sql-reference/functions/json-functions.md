<div id="types-of-functions">
  ## Types de fonctions JSON
</div>

Il existe deux ensembles de fonctions pour analyser du JSON :

* [`simpleJSON*` (`visitParam*`)](#simplejson-visitparam-functions), conçues pour analyser extrêmement rapidement un sous-ensemble limité de JSON.
* [`JSONExtract*`](#jsonextract-functions), conçues pour analyser du JSON ordinaire.

<div id="simplejson-visitparam-functions">
  ### Fonctions simpleJSON (visitParam)
</div>

ClickHouse dispose de fonctions spéciales pour travailler avec du JSON simplifié. Toutes ces fonctions JSON reposent sur des hypothèses fortes quant à ce que le JSON peut contenir. Elles cherchent à en faire le moins possible pour accomplir la tâche aussi rapidement que possible.

Les hypothèses suivantes s&#39;appliquent :

1. Le nom du champ (argument de la fonction) doit être une constante.
2. Le nom du champ est encodé de manière canonique dans le JSON. Par exemple : `simpleJSONHas('{"abc":"def"}', 'abc') = 1`, mais `simpleJSONHas('{"\\u0061\\u0062\\u0063":"def"}', 'abc') = 0`
3. Les champs sont recherchés à n&#39;importe quel niveau d&#39;imbrication, sans distinction. S&#39;il existe plusieurs champs correspondants, la première occurrence est utilisée.
4. Le JSON ne contient pas d&#39;espaces en dehors des littéraux de chaîne.

<div id="jsonextract-functions">
  ### Fonctions JSONExtract
</div>

Ces fonctions sont basées sur [simdjson](https://github.com/lemire/simdjson) et conçues pour répondre à des besoins plus complexes en matière d&#39;analyse JSON.

<div id="case-insensitive-jsonextract-functions">
  ### Fonctions JSONExtract insensibles à la casse
</div>

Ces fonctions effectuent une correspondance de clés ASCII insensible à la casse lors de l’extraction de valeurs depuis des objets JSON.
Elles fonctionnent de manière identique à leurs équivalents sensibles à la casse, à ceci près que les clés d’objet sont mises en correspondance sans tenir compte de la casse.
Lorsque plusieurs clés correspondent avec des casses différentes, la première correspondance est renvoyée.

:::note
Ces fonctions peuvent être moins performantes que leurs équivalents sensibles à la casse. Utilisez donc les fonctions JSONExtract classiques si possible.
:::
