<div id="h3-index">
  ## H3 Index
</div>

[H3](https://h3geo.org/) est un système d’indexation géographique dans lequel la surface de la Terre est divisée en une grille de cellules hexagonales régulières. Ce système est hiérarchique, c’est-à-dire que chaque hexagone du niveau supérieur (&quot;parent&quot;) peut être subdivisé en sept hexagones réguliers plus petits (&quot;children&quot;), et ainsi de suite.

Le niveau de la hiérarchie s’appelle `resolution` et peut prendre une valeur de `0` à `15`, où `0` correspond au niveau `base`, avec les cellules les plus grandes et les moins précises.

Une paire latitude-longitude peut être transformée en un index H3 de 64 bits, qui identifie une cellule de la grille.

L’index H3 est principalement utilisé pour regrouper des lieux et pour d’autres manipulations géospatiales.

La description complète du système H3 est disponible sur [le site d’Uber Engineering](https://www.uber.com/blog/h3/).

<div id="h3isvalid">
  ## h3IsValid
</div>

Vérifie si le nombre correspond à un [index](#h3-index) H3 valide.

**Syntaxe**

```sql
h3IsValid(h3index)
```

**Paramètre**

* `h3index` — Numéro d’index hexagonal. [UInt64](../../data-types/int-uint.md).

**Valeurs renvoyées**

* 1 — Le nombre est un index H3 valide. [UInt8](../../data-types/int-uint.md).
* 0 — Le nombre n’est pas un index H3 valide. [UInt8](../../data-types/int-uint.md).

**Exemple**

```sql title="Query"
SELECT h3IsValid(630814730351855103) AS h3IsValid;
```

```text title="Response"
┌─h3IsValid─┐
│         1 │
└───────────┘
```

<div id="h3getresolution">
  ## h3GetResolution
</div>

Renvoie la résolution de l’index [H3](#h3-index) donné.

**Syntaxe**

```sql
h3GetResolution(h3index)
```

**Paramètre**

* `h3index` — Numéro d’index hexagonal. [UInt64](../../data-types/int-uint.md).

**Valeurs renvoyées**

* Résolution de l’index. Plage : `[0, 15]`. [UInt8](../../data-types/int-uint.md).
* Si l’index n’est pas valide, la fonction renvoie une valeur aléatoire. Utilisez [h3IsValid](#h3isvalid) pour en vérifier la validité. [UInt8](../../data-types/int-uint.md).

**Exemple**

```sql title="Query"
SELECT h3GetResolution(639821929606596015) AS resolution;
```

```text title="Response"
┌─resolution─┐
│         14 │
└────────────┘
```

<div id="geotoh3">
  ## geoToH3
</div>

Renvoie l’index H3 du point [H3](#h3-index) `(lat, lon)` à la résolution spécifiée.

**Syntaxe**

```sql
geoToH3(lat, lon, resolution)
```

**Arguments**

* `lat` — Latitude. [Float64](../../data-types/float.md).
* `lon` — Longitude. [Float64](../../data-types/float.md).
* `resolution` — Résolution de l’index. Intervalle : `[0, 15]`. [UInt8](../../data-types/int-uint.md).

**Valeurs renvoyées**

* Numéro d’index hexagonal. [UInt64](../../data-types/int-uint.md).
* 0 en cas d’erreur. [UInt64](../../data-types/int-uint.md).

Remarque : dans ClickHouse v25.4 ou une version antérieure, `geoToH3()` attend les valeurs dans l’ordre `(lon, lat)`. À partir de ClickHouse v25.5, les valeurs d’entrée sont dans l’ordre `(lat, lon)`. Le comportement précédent peut être rétabli à l’aide du paramètre `geotoh3_argument_order = 'lon_lat'`.

**Exemple**

```sql title="Query"
SELECT geoToH3(55.71290588, 37.79506683, 15) AS h3Index;
```

```text title="Response"
┌────────────h3Index─┐
│ 644325524701193974 │
└────────────────────┘
```

<div id="h3polygontocellswithcontainment">
  ## h3PolygonToCellsWithContainment
</div>

Renvoie les hexagones (à la résolution spécifiée) qui couvrent la géométrie fournie, qu&#39;il s&#39;agisse d&#39;un anneau ou d&#39;un (multi-)polygone, à l&#39;aide des modes de containment expérimentaux de H3.

Cette fonction associe `flags` aux modes de containment de H3 :

* `0` — `CONTAINMENT_CENTER`
* `1` — `CONTAINMENT_FULL`
* `2` — `CONTAINMENT_OVERLAPPING`
* `3` — `CONTAINMENT_OVERLAPPING_BBOX`

**Syntaxe**

```sql
h3PolygonToCellsWithContainment(geometry, resolution, flags)
```

**Arguments**

* `geometry` peut être l’un des [types de données Geo](../../data-types/geo.md) suivants ou l’un de leurs types primitifs sous-jacents :
  * [Ring](../../data-types/geo.md#ring)
  * [Polygon](../../data-types/geo.md#polygon)
  * [MultiPolygon](../../data-types/geo.md#multipolygon)
* `resolution` — Résolution de l’index. Plage : `[0, 15]`. [UInt8](../../data-types/int-uint.md).
* `flags` — Mode d’inclusion. Plage : `[0, 3]`. Utilisez des littéraux entiers tels que `0`, `1`, `2` et `3`, ou des valeurs [UInt32](../../data-types/int-uint.md) (par exemple, `toUInt32(2)`). Les valeurs sont transmises à l’API H3 sous forme de `UInt32`. Les autres types entiers natifs sont convertis de manière exacte.

**valeurs renvoyées**

* [Array](../../data-types/array.md)([UInt64](../../data-types/int-uint.md)) d’index H3 selon le mode d’inclusion sélectionné.

**Exemple**

```sql title="Query"
SELECT
    h3PolygonToCellsWithContainment([(-122.4089866999972145, 37.813318999983238), (-122.3544736999993603, 37.7198061999978478), (-122.4798767000009008, 37.8151571999998453)], 7, 0) AS center_cells,
```
