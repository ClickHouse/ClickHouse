Toutes les fonctions de cette section effectuent, par défaut, une recherche sensible à la casse. La recherche insensible à la casse est généralement assurée par des variantes de fonction distinctes.

:::note
La recherche insensible à la casse suit les règles de passage des minuscules aux majuscules de la langue anglaise. Par exemple, en anglais, la majuscule de `i` est
`I`, alors qu&#39;en turc c&#39;est `İ` ; les résultats pour des langues אחרות que l&#39;anglais peuvent donc être inattendus.
:::

Les fonctions de cette section supposent également que la chaîne dans laquelle la recherche est effectuée (appelée dans cette section `haystack`) et la chaîne recherchée (appelée dans cette section `needle`) sont du texte encodé sur un seul octet. Si cette hypothèse est
violée, aucune exception n&#39;est levée et les résultats sont indéfinis. La recherche avec des chaînes encodées en UTF-8 est généralement assurée par des variantes de fonction
distinctes. De même, si une variante de fonction UTF8 est utilisée et que les chaînes d&#39;entrée ne sont pas du texte encodé en UTF-8, aucune exception n&#39;est levée et les
résultats sont indéfinis. Notez qu&#39;aucune normalisation Unicode automatique n&#39;est effectuée ; vous pouvez toutefois utiliser les fonctions
[normalizeUTF8*()](/fr/sql-reference/functions/string-functions#normalizeUTF8NFC) à cette fin.

Les [fonctions générales sur les chaînes](string-functions.md) et les [fonctions de remplacement dans les chaînes](string-replace-functions.md) sont décrites séparément.
