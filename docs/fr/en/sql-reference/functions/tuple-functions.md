<div id="untuple">
  ## untuple
</div>

Effectue une substitution syntaxique des éléments de [tuple](/fr/sql-reference/data-types/tuple) au point d&#39;appel.

Les noms des colonnes résultantes dépendent de l&#39;implémentation et sont susceptibles de changer. Ne présumez pas de noms de colonnes spécifiques après `untuple`.

**Syntaxe**

```sql
untuple(x)
```

Vous pouvez utiliser l’expression `EXCEPT` pour exclure des colonnes du résultat de la requête.

**Arguments**

* `x` — Une fonction `tuple`, une colonne ou un tuple d’éléments. [Tuple](../data-types/tuple.md).

**Valeur renvoyée**

* Aucune.

**Exemples**

Table d’entrée :

```text
┌─key─┬─v1─┬─v2─┬─v3─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 20 │ 40 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 65 │ 70 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 30 │ 20 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 12 │  7 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 50 │ 70 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴────┴────┴───────────┘
```

Exemple d’utilisation d’une colonne de type `Tuple` comme paramètre de la fonction `untuple` :

```sql title="Query"
SELECT untuple(v6) FROM kv;
```

```text title="Response"
┌─_ut_1─┬─_ut_2─┐
│    33 │ ab    │
│    44 │ cd    │
│    55 │ ef    │
│    66 │ gh    │
│    77 │ kl    │
└───────┴───────┘
```

Exemple d’utilisation d’une expression `EXCEPT` :

```sql title="Query"
SELECT untuple((* EXCEPT (v2, v3),)) FROM kv;
```

```text title="Response"
┌─key─┬─v1─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴───────────┘
```
