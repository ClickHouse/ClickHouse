Les fonctions ci-dessous effectuent des opérations logiques sur des arguments de types numériques quelconques.
Elles renvoient soit `0`, soit `1` sous la forme de [`UInt8`](../data-types/int-uint.md) ou, dans certains cas, `NULL`.

La valeur zéro passée en argument est considérée comme `false`, tandis que les valeurs non nulles sont considérées comme `true`.
