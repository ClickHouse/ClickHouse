Les utilisateurs interagissent avec ClickHouse à l’aide d’instructions SQL. ClickHouse prend en charge les instructions SQL courantes, comme [SELECT](select/index.md) et [CREATE](create/index.md), mais propose également des instructions spécialisées, comme [KILL](kill.md) et [OPTIMIZE](optimize.md).
