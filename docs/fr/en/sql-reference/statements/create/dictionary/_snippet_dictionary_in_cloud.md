title: "Extrait : Dictionary dans Cloud"
---

:::tip
Si vous utilisez un dictionnaire avec ClickHouse Cloud, veuillez utiliser l’option de DDL query pour créer vos dictionnaires, et créer votre dictionnaire avec l’utilisateur `default`.
Vérifiez également la liste des sources de dictionnaire prises en charge dans le [guide de compatibilité Cloud](/fr/whats-new/cloud-compatibility).
:::
