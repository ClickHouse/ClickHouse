ClickHouse offre différents moyens d’intégration avec des systèmes externes, notamment via des moteurs de table. Comme pour tous les autres moteurs de table, la configuration s’effectue à l’aide de requêtes `CREATE TABLE` ou `ALTER TABLE`. Ensuite, du point de vue de l’utilisateur, l’intégration configurée se présente comme une table ordinaire, mais les requêtes qui lui sont adressées sont relayées vers le système externe. Cette transparence est l’un des principaux avantages de cette approche par rapport à d’autres méthodes d’intégration, comme les dictionnaires ou les fonctions de table, qui nécessitent d’utiliser des méthodes d’interrogation personnalisées à chaque fois.
