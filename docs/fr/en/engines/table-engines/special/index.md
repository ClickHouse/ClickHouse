Il existe trois grandes catégories de moteurs de table :

* [Famille de moteurs MergeTree](../../../engines/table-engines/mergetree-family/index.md) pour un usage principal en production.
* [Famille de moteurs Log](../../../engines/table-engines/log-family/index.md) pour de petits volumes de données temporaires.
* [Moteurs de table pour les intégrations](../../../engines/table-engines/integrations/index.md).

Les autres moteurs ont chacun un usage spécifique et ne sont pas encore regroupés en familles ; ils sont donc placés dans cette catégorie &quot;spéciale&quot;.
