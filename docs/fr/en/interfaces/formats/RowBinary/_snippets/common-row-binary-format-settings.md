---
title: Paramètres courants du format binaire par ligne
---

{/* Note : cet extrait est réutilisé dans tout fichier qui l’importe */ }

Les paramètres suivants sont communs à tous les formats de type `RowBinary`.

| Setting                                                                                                                                | Description                                                                                                                                                                                                                                                                                   | Default |
| -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| [`format_binary_max_string_size`](/fr/operations/settings/settings-formats.md/#format_binary_max_string_size)                             | Taille maximale autorisée pour les valeurs String au format RowBinary.                                                                                                                                                                                                                        | `1GiB`  |
| [`output_format_binary_encode_types_in_binary_format`](/fr/operations/settings/formats#input_format_binary_decode_types_in_binary_format) | Permet d’écrire les types dans l’en-tête à l’aide de l’[`encodage binaire`](/fr/sql-reference/data-types/data-types-binary-encoding.md), plutôt que sous forme de chaînes contenant les noms de type, dans le format de sortie [`RowBinaryWithNamesAndTypes`](../RowBinaryWithNamesAndTypes.md). | `false` |
| [`input_format_binary_decode_types_in_binary_format`](/fr/operations/settings/formats#input_format_binary_decode_types_in_binary_format)  | Permet de lire les types dans l’en-tête à l’aide de l’[`encodage binaire`](/fr/sql-reference/data-types/data-types-binary-encoding.md), plutôt que sous forme de chaînes contenant les noms de type, dans le format d’entrée [`RowBinaryWithNamesAndTypes`](../RowBinaryWithNamesAndTypes.md).   | `false` |
| [`output_format_binary_write_json_as_string`](/fr/operations/settings/settings-formats.md/#output_format_binary_write_json_as_string)     | Permet d’écrire les valeurs du type de données [`JSON`](/fr/sql-reference/data-types/newjson.md) sous forme de valeurs `JSON` de type [String](/fr/sql-reference/data-types/string.md) dans le format de sortie [`RowBinary`](../RowBinary.md).                                                     | `false` |
| [`input_format_binary_read_json_as_string`](/fr/operations/settings/settings-formats.md/#input_format_binary_read_json_as_string)         | Permet de lire les valeurs du type de données [`JSON`](/fr/sql-reference/data-types/newjson.md) sous forme de valeurs `JSON` de type [String](/fr/sql-reference/data-types/string.md) dans le format d’entrée [`RowBinary`](../RowBinary.md).                                                       | `false` |
