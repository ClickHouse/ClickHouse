<div id="description">
  ## Description
</div>

Se distingue du format [`Pretty`](./Pretty.md) par l’affichage de la table avec une grille entre les lignes.
Le résultat est donc plus compact.

:::note
Ce format est utilisé par défaut dans le client en ligne de commande en mode interactif.
:::
