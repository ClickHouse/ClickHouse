[Chartbrew](https://chartbrew.com) est une plateforme de visualisation de données qui vous permet de créer des tableaux de bord et de surveiller vos données en temps réel. Elle prend en charge plusieurs sources de données, dont ClickHouse, et fournit une interface no-code pour créer des graphiques et des rapports.

## Objectif {#goal}

Dans ce guide, vous allez connecter Chartbrew à ClickHouse, exécuter une requête SQL et créer une visualisation. À la fin, votre tableau de bord devrait ressembler à ceci :

  <Frame>
    ![Tableau de bord Chartbrew](/images/integrations/data-visualization/chartbrew_01.webp)

</div>

<Tip>
  **Ajoutez des données**

  Si vous n&#39;avez pas de jeu de données à utiliser, vous pouvez en ajouter un à partir des exemples. Ce guide utilise le jeu de données [UK Price Paid](/fr/get-started/sample-datasets/uk-price-paid).
</Tip>

<Steps>
  <Step title="Rassemblez vos informations de connexion" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Connecter Chartbrew à ClickHouse" id="2-connect-chartbrew-to-clickhouse">
    1. Connectez-vous à [Chartbrew](https://chartbrew.com/login) et accédez à l’onglet **Connections**.

    2. Cliquez sur **Create connection**, puis sélectionnez **ClickHouse** parmi les options de base de données proposées.

       <div className="ch-image-lg">
         <Frame>
           ![Sélection de la connexion ClickHouse dans Chartbrew](/images/integrations/data-visualization/chartbrew_02.webp)
         </Frame>
       </div>

    3. Saisissez les informations de connexion de votre base de données ClickHouse :

       * **Display Name** : nom permettant d’identifier la connexion dans Chartbrew.
       * **Host** : nom d’hôte ou adresse IP de votre serveur ClickHouse.
       * **Port** : généralement `8443` pour les connexions HTTPS.
       * **Database Name** : base de données à laquelle vous souhaitez vous connecter.
       * **Username** : votre nom d’utilisateur ClickHouse.
       * **Password** : votre mot de passe ClickHouse.

       <div className="ch-image-lg">
         <Frame>
           ![Paramètres de connexion ClickHouse dans Chartbrew](/images/integrations/data-visualization/chartbrew_03.webp)
         </Frame>
       </div>

    4. Cliquez sur **Test connection** pour vérifier que Chartbrew parvient à se connecter à ClickHouse.

    5. Si le test aboutit, cliquez sur **Save connection**. Chartbrew récupère alors automatiquement le schéma depuis ClickHouse.

       <div className="ch-image-lg">
         <Frame>
           ![Schéma JSON ClickHouse dans Chartbrew](/images/integrations/data-visualization/chartbrew_04.webp)
         </Frame>
       </div>
  </Step>

  <Step title="Créer un jeu de données et exécuter une requête SQL" id="3-create-a-dataset-and-run-a-sql-query">
    1. Cliquez sur le bouton **Create dataset** ou accédez à l’onglet **Datasets** pour en créer un.
    2. Sélectionnez la connexion à ClickHouse que vous avez créée précédemment.

    <div className="ch-image-lg">
      <Frame>
        ![Sélection de la connexion à ClickHouse pour le jeu de données](/images/integrations/data-visualization/chartbrew_05.webp)
      </Frame>
    </div>

    Écrivez une requête SQL pour récupérer les données à visualiser. Par exemple, cette requête calcule le prix moyen payé par année à partir du jeu de données `uk_price_paid` :

    ```sql
    SELECT toYear(date) AS year, avg(price) AS avg_price
    FROM uk_price_paid
    GROUP BY year
    ORDER BY year;
    ```

    <div className="ch-image-lg">
      <Frame>
        ![Requête SQL ClickHouse dans Chartbrew](/images/integrations/data-visualization/chartbrew_07.webp)
      </Frame>
    </div>

    Cliquez sur **Run query** pour récupérer les données.

    Si vous ne savez pas comment rédiger la requête, vous pouvez utiliser **l&#39;assistant IA de Chartbrew** pour générer des requêtes SQL à partir de votre schéma de base de données.

    <div className="ch-image-lg">
      <Frame>
        ![Assistant IA SQL pour ClickHouse dans Chartbrew](/images/integrations/data-visualization/chartbrew_06.webp)
      </Frame>
    </div>

    Une fois les données récupérées, cliquez sur **Configure dataset** pour définir les paramètres de visualisation.
  </Step>

  <Step title="Créer une visualisation" id="4-create-a-visualization">
    1. Définissez une métrique (valeur numérique) et une dimension (valeur catégorielle) pour votre visualisation.
    2. Prévisualisez le jeu de données pour vérifier que le résultat de la requête est correctement structuré.
    3. Choisissez un type de graphique (par exemple, graphique en courbes, graphique à barres ou diagramme circulaire) et ajoutez-le à votre tableau de bord.
    4. Cliquez sur **Complete dataset** pour finaliser la configuration.

    <div className="ch-image-lg">
      <Frame>
        ![Tableau de bord Chartbrew avec des données ClickHouse](/images/integrations/data-visualization/chartbrew_08.webp)
      </Frame>
    </div>

    Vous pouvez créer autant de jeux de données que nécessaire pour visualiser différents aspects de vos données. À partir de ces jeux de données, vous pouvez ensuite créer plusieurs tableaux de bord afin de suivre différentes métriques.

    <div className="ch-image-lg">
      <Frame>
        ![Tableau de bord Chartbrew avec des données ClickHouse](/images/integrations/data-visualization/chartbrew_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Automatiser les mises à jour des données" id="5-automate-data-updates">
    Pour que votre tableau de bord reste à jour, vous pouvez planifier des mises à jour automatiques des données :

    1. Cliquez sur l’icône Calendrier à côté du bouton de rafraîchissement du jeu de données.
    2. Configurez l’intervalle de mise à jour (par exemple, toutes les heures ou tous les jours).
    3. Enregistrez les paramètres pour activer le rafraîchissement automatique.

    <div className="ch-image-lg">
      <Frame>
        ![Paramètres de rafraîchissement du jeu de données dans Chartbrew](/images/integrations/data-visualization/chartbrew_09.webp)
      </Frame>
    </div>
  </Step>
</Steps>
