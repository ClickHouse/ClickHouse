[arcodash](https://www.arcodash.com/connectors/clickhouse/?utm_source=clickhouse-docs\&utm_medium=docs\&utm_campaign=growth-v2\&utm_content=clickhouse-docs-integration) est un outil de BI hébergé qui intègre des vérifications de données : tableaux de bord SQL, assistant de requêtes basé sur l&#39;IA et vérifications planifiées qui envoient des alertes par e-mail, Slack, Teams, webhook ou PagerDuty. Il se connecte à ClickHouse via l&#39;interface HTTP(S).

<Steps>
  <Step title="Rassemblez vos informations de connexion" id="1-gather-your-connection-details">
    <ConnectionDetails />

    arcodash a besoin de l&#39;hôte, du port HTTP (`8123`, ou `8443` pour ClickHouse Cloud avec HTTPS), de l&#39;utilisateur, du mot de passe et de la base de données.
  </Step>

  <Step title="Créez un utilisateur en lecture seule" id="2-create-a-read-only-user">
    ```sql
    CREATE USER arcodash_ro IDENTIFIED BY 'change-me' SETTINGS readonly = 1;
    GRANT SELECT ON analytics.* TO arcodash_ro;
    GRANT SELECT ON system.columns TO arcodash_ro;
    ```

    L&#39;explorateur de schéma lit la table `system.columns`.
  </Step>

  <Step title="Ajoutez le connecteur" id="3-add-the-connector">
    Dans arcodash, choisissez **Connect** &gt; **ClickHouse**, puis saisissez l&#39;hôte, le port, l&#39;utilisateur, le mot de passe et la base de données. Activez HTTPS pour ClickHouse Cloud, puis lancez le test de connexion.

    <Image size="lg" img="/images/integrations/data-visualization/arcodash_01.png" alt="Formulaire du connecteur ClickHouse dans arcodash" border />
  </Step>

  <Step title="Exécutez une requête et une vérification" id="4-run-a-query-and-a-check">
    ```sql
    SELECT dateDiff('second', max(loaded_at), now()) AS seconds_since_last_row
    FROM analytics.events
    ```

    Enregistrez la requête en tant que moniteur sur `seconds_since_last_row` avec la condition `>` `3600` pour déclencher une alerte lorsqu&#39;une table cesse de recevoir des données.

    <Image size="lg" img="/images/integrations/data-visualization/arcodash_02.png" alt="Moniteur arcodash sur une requête ClickHouse" border />
  </Step>
</Steps>

## Limitations {#limitations}

* arcodash utilise uniquement l&#39;interface HTTP, et non le port natif `9000`.
* arcodash ajoute lui-même une clause `FORMAT` ; les requêtes ne doivent donc pas se terminer par leur propre clause `FORMAT`.
* Les résultats sont plafonnés à 10,000 lignes par requête.
* arcodash ne communique pas d&#39;adresses IP sortantes fixes ; le serveur ClickHouse doit donc être joignable depuis Internet.
