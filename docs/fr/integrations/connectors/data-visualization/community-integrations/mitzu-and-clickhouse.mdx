Mitzu est une application d’analyse produit no-code, nativement sur l’entrepôt de données. À l’instar d’outils comme Amplitude, Mixpanel et PostHog, Mitzu permet aux utilisateurs d’analyser les données d’usage du produit sans avoir besoin de maîtriser SQL ou Python.

Cependant, contrairement à ces plateformes, Mitzu ne duplique pas les données d’usage du produit de l’entreprise. Il génère plutôt des requêtes SQL natives directement sur l’entrepôt de données ou le data lake existant de l’entreprise.

<div id="goal">
  ## Objectif {#goal}
</div>

Dans ce guide, nous allons aborder les points suivants :

* Analyse produit nativement sur l’entrepôt de données
* Comment intégrer Mitzu à ClickHouse

<Tip>
  **Jeux de données d’exemple**

  Si vous n’avez pas de jeu de données à utiliser avec Mitzu, vous pouvez utiliser NYC Taxi Data.
  Ce jeu de données est disponible dans ClickHouse Cloud ou [peut être chargé en suivant ces instructions](/fr/get-started/sample-datasets/nyc-taxi).
</Tip>

Ce guide n’offre qu’un bref aperçu de l’utilisation de Mitzu. Vous trouverez des informations plus détaillées dans la [documentation Mitzu](https://docs.mitzu.io/).

<Steps>
  <Step title="Rassemblez vos informations de connexion" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Connectez-vous ou inscrivez-vous sur Mitzu" id="2-sign-in-or-sign-up-to-mitzu">
    Pour commencer, rendez-vous sur [https://app.mitzu.io](https://app.mitzu.io) afin de vous inscrire.

    <div className="ch-image-lg">
      <Frame>
        ![Page de connexion de Mitzu avec les champs e-mail et mot de passe](/images/integrations/data-visualization/mitzu_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Configurez votre espace de travail" id="3-configure-your-workspace">
    Après avoir créé une organisation, suivez le guide de configuration initiale `Set up your workspace` dans la barre latérale gauche. Cliquez ensuite sur le lien `Connect Mitzu with your data warehouse`.

    <div className="ch-image-lg">
      <Frame>
        ![Page de configuration de l'espace de travail Mitzu présentant les étapes de configuration initiale](/images/integrations/data-visualization/mitzu_02.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Connecter Mitzu à ClickHouse" id="4-connect-mitzu-to-clickhouse">
    Commencez par sélectionner ClickHouse comme type de connexion, puis renseignez les informations de connexion. Cliquez ensuite sur le bouton `Test connection & Save` pour enregistrer les paramètres.

    <div className="ch-image-lg">
      <Frame>
        ![Page de configuration de la connexion ClickHouse dans Mitzu, avec le formulaire de configuration](/images/integrations/data-visualization/mitzu_03.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Configurer les tables d’événements" id="5-configure-event-tables">
    Une fois la connexion enregistrée, sélectionnez l’onglet `Event tables` et cliquez sur le bouton `Add table`. Dans la boîte de dialogue modale, sélectionnez votre base de données ainsi que les tables à ajouter à Mitzu.

    Cochez au moins une table, puis cliquez sur le bouton `Configure table`. Une fenêtre modale s’ouvre alors, dans laquelle vous pouvez définir les colonnes de clé de chaque table.

    <div className="ch-image-lg">
      <Frame>
        ![Interface de sélection des tables de Mitzu affichant les tables de la base de données](/images/integrations/data-visualization/mitzu_04.webp)
      </Frame>
    </div>

    <br />

    > Pour réaliser de l’analyse produit sur votre configuration ClickHouse, vous devez &gt; indiquer quelques colonnes de clé de votre table.
    >
    > Il s’agit des colonnes suivantes :
    >
    > * **User id** - la colonne contenant l’identifiant unique des utilisateurs.
    > * **Event time** - la colonne timestamp de vos événements.
    > * Facultatif&#91;**Event name**&#93; - cette colonne permet de distinguer les événements si la table contient plusieurs types d’événements.

    <div className="ch-image-lg">
      <Frame>
        ![Configuration du catalogue d’événements de Mitzu affichant les options de correspondance des colonnes](/images/integrations/data-visualization/mitzu_05.webp)
      </Frame>
    </div>

    <br />

    Une fois toutes les tables configurées, cliquez sur le bouton `Save & update event catalog` : Mitzu identifiera alors tous les événements et leurs propriétés à partir de la table définie ci-dessus. Cette étape peut prendre quelques minutes, selon la taille de votre jeu de données.
  </Step>

  <Step title="Exécuter des requêtes de segmentation" id="4-run-segmentation-queries">
    La segmentation des utilisateurs dans Mitzu est aussi simple que dans Amplitude, Mixpanel ou PostHog.

    La page Explorer comporte, à gauche, une zone de sélection des événements, tandis que la partie supérieure permet de configurer la plage temporelle.

    <div className="ch-image-lg">
      <Frame>
        ![Interface de requête de segmentation Mitzu avec sélection des événements et configuration de la période](/images/integrations/data-visualization/mitzu_06.webp)
      </Frame>
    </div>

    <br />

    <Tip>
      **Filtres et ventilation**

      Le filtrage fonctionne comme on peut s&#39;y attendre : choisissez une propriété (colonne ClickHouse), puis sélectionnez dans la liste déroulante les valeurs sur lesquelles filtrer.
      Vous pouvez ventiler les résultats selon n&#39;importe quelle propriété d&#39;événement ou d&#39;utilisateur (voir ci-dessous comment intégrer les propriétés utilisateur).
    </Tip>
  </Step>

  <Step title="Exécuter des requêtes de funnel" id="5-run-funnel-queries">
    Sélectionnez jusqu&#39;à 9 étapes pour un funnel. Choisissez la fenêtre temporelle dans laquelle vos utilisateurs doivent parcourir le funnel.
    Obtenez instantanément des indicateurs de taux de conversion sans écrire une seule ligne de code SQL.

    <div className="ch-image-lg">
      <Frame>
        ![Vue d'analyse de funnel dans Mitzu affichant les taux de conversion entre les étapes](/images/integrations/data-visualization/mitzu_07.webp)
      </Frame>
    </div>

    <br />

    <Tip>
      **Visualiser les tendances**

      Choisissez `Funnel trends` pour visualiser l&#39;évolution des funnels au fil du temps.
    </Tip>
  </Step>

  <Step title="Exécuter des requêtes de rétention" id="6-run-retention-queries">
    Sélectionnez jusqu&#39;à 2 étapes pour calculer un taux de rétention. Choisissez la fenêtre de rétention pour la fenêtre récurrente pour
    Obtenez instantanément des indicateurs sur le taux de conversion sans écrire une seule ligne de code SQL.

    <div className="ch-image-lg">
      <Frame>
        ![Analyse de rétention Mitzu présentant les taux de rétention par cohorte](/images/integrations/data-visualization/mitzu_08.webp)
      </Frame>
    </div>

    <br />

    <Tip>
      **Rétention par cohorte**

      Choisissez `Weekly cohort retention` pour visualiser l&#39;évolution de vos taux de rétention au fil du temps.
    </Tip>
  </Step>

  <Step title="Exécuter des requêtes de parcours" id="7-run-journey-queries">
    Sélectionnez jusqu&#39;à 9 étapes pour un funnel. Choisissez la fenêtre temporelle pendant laquelle vos utilisateurs peuvent terminer le parcours. Le graphique de parcours de Mitzu offre une représentation visuelle de tous les chemins empruntés par les utilisateurs à travers les événements sélectionnés.

    <div className="ch-image-lg">
      <Frame>
        ![Visualisation de parcours Mitzu montrant le flux des chemins utilisateurs entre les événements](/images/integrations/data-visualization/mitzu_09.webp)
      </Frame>
    </div>

    <br />

    <Tip>
      **Ventiler les étapes**

      Vous pouvez sélectionner une propriété dans le segment `Break down` pour distinguer les utilisateurs au sein d&#39;une même étape.
    </Tip>

    <br />
  </Step>

  <Step title="Exécuter des requêtes sur le chiffre d’affaires" id="8-run-revenue-queries">
    Si les paramètres de revenus sont configurés, Mitzu peut calculer le MRR total et le nombre d&#39;abonnements à partir de vos événements de paiement.

    <div className="ch-image-lg">
      <Frame>
        ![Tableau de bord d'analyse des revenus de Mitzu affichant les métriques de MRR](/images/integrations/data-visualization/mitzu_10.webp)
      </Frame>
    </div>
  </Step>

  <Step title="SQL natif" id="9-sql-native">
    Mitzu est nativement SQL : il génère du code SQL natif à partir de la configuration que vous avez définie sur la page Explorer.

    <div className="ch-image-lg">
      <Frame>
        ![Vue de génération du code SQL dans Mitzu, affichant une requête ClickHouse native](/images/integrations/data-visualization/mitzu_11.webp)
      </Frame>
    </div>

    <br />

    <Tip>
      **Poursuivez votre travail dans un outil de BI**

      Si l&#39;UI de Mitzu ne vous permet pas d&#39;aller plus loin, copiez le code SQL et poursuivez votre travail dans un outil de BI.
    </Tip>
  </Step>
</Steps>
