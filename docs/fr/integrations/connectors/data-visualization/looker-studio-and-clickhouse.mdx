## Connecter Looker Studio à ClickHouse {#connecting-looker-studio-to-clickhouse}

Commencez par vous connecter à [Looker Studio](https://lookerstudio.google.com) avec votre compte Google, puis créez une nouvelle source de données :

<div className="ch-image-md">
  <Frame>
    ![Création d'une nouvelle source de données dans l'interface de Looker Studio](/images/integrations/data-visualization/looker_studio_01.webp)
  </Frame>
</div>

<br />

Recherchez le connector MySQL officiel fourni par Google (nommé simplement **MySQL**) :

<div className="ch-image-md">
  <Frame>
    ![Recherche du connector MySQL dans la liste des connectors de Looker Studio](/images/integrations/data-visualization/looker_studio_02.webp)
  </Frame>
</div>

<br />

Indiquez vos informations de connexion. Notez que le port de l&#39;interface MySQL est 9004 par défaut,
mais qu&#39;il peut varier selon la configuration de votre serveur.

<div className="ch-image-md">
  <Frame>
    ![Saisie des informations de connexion MySQL de ClickHouse dans Looker Studio](/images/integrations/data-visualization/looker_studio_03.webp)
  </Frame>
</div>

<br />

Deux options s&#39;offrent ensuite à vous pour récupérer les données depuis ClickHouse. La première consiste à utiliser la fonctionnalité Table Browser :

<div className="ch-image-md">
  <Frame>
    ![Utilisation du Table Browser pour sélectionner des tables ClickHouse dans Looker Studio](/images/integrations/data-visualization/looker_studio_04.webp)
  </Frame>
</div>

<br />

Vous pouvez également saisir une requête personnalisée pour récupérer vos données :

<div className="ch-image-md">
  <Frame>
    ![Utilisation d'une requête SQL personnalisée pour récupérer des données depuis ClickHouse dans Looker Studio](/images/integrations/data-visualization/looker_studio_05.webp)
  </Frame>
</div>

<br />

Enfin, la structure de la table inspectée devrait s&#39;afficher, et vous pourrez ajuster les types de données si nécessaire.

<div className="ch-image-md">
  <Frame>
    ![Affichage de la structure de la table ClickHouse inspectée dans Looker Studio](/images/integrations/data-visualization/looker_studio_06.webp)
  </Frame>
</div>

<br />

Vous pouvez maintenant explorer vos données ou créer un nouveau rapport !

## Utiliser Looker Studio avec ClickHouse Cloud {#using-looker-studio-with-clickhouse-cloud}

Lorsque vous utilisez ClickHouse Cloud, vous devez d’abord activer l’interface MySQL. Vous pouvez le faire dans la boîte de dialogue de connexion, dans l’onglet « MySQL ».

<div className="ch-image-md">
  <Frame>
    ![Activation de l’interface MySQL dans les paramètres de ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_enable_mysql.webp)
  </Frame>
</div>

<br />

Dans l’UI de Looker Studio, sélectionnez l’option « Enable SSL ». Le certificat SSL de ClickHouse Cloud est signé par [Let&#39;s Encrypt](https://letsencrypt.org/certificates/). Vous pouvez télécharger ce certificat racine [ici](https://letsencrypt.org/certs/isrgrootx1.pem).

<div className="ch-image-md">
  <Frame>
    ![Configuration de la connexion Looker Studio avec les paramètres SSL de ClickHouse Cloud](/images/integrations/data-visualization/looker_studio_mysql_cloud.webp)
  </Frame>
</div>

<br />

Les autres étapes sont identiques à celles indiquées ci-dessus dans la section précédente.
