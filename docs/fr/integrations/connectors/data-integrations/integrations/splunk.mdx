[Splunk](https://www.splunk.com/) est une plateforme d’analyse de données et de supervision.

Ce module complémentaire vous permet de stocker les [journaux d’audit ClickHouse Cloud](/fr/products/cloud/reference/security/audit-logging) dans Splunk. Il utilise l’[API ClickHouse Cloud](/fr/products/cloud/features/admin-features/api/api-overview) pour télécharger les journaux d’audit.

Ce module complémentaire ne contient qu’une entrée modulaire et ne fournit pas d’interface utilisateur supplémentaire.

<div id="installation">
  # Installation {#installation}
</div>

## Pour Splunk Enterprise {#for-splunk-enterprise}

Téléchargez le module complémentaire ClickHouse Cloud Audit Add-on for Splunk depuis [Splunkbase](https://splunkbase.splunk.com/app/7709).

<div className="ch-image-lg">
  <Frame>
    ![Site web Splunkbase affichant la page de téléchargement du module complémentaire ClickHouse Cloud Audit Add-on for Splunk](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

Dans Splunk Enterprise, accédez à Apps -&gt; Manage, puis cliquez sur Install app from file.

<div className="ch-image-lg">
  <Frame>
    ![Interface de Splunk Enterprise affichant la page de gestion des applications avec l’option Install app from file](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

Sélectionnez l’archive téléchargée depuis Splunkbase, puis cliquez sur Upload.

<div className="ch-image-lg">
  <Frame>
    ![Boîte de dialogue d’installation d’application Splunk permettant de téléverser le module complémentaire ClickHouse](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

Si tout s’est bien déroulé, l’application ClickHouse Audit logs devrait maintenant figurer parmi les applications installées. Dans le cas contraire, consultez les logs Splunkd pour rechercher d’éventuelles erreurs.

<div id="modular-input-configuration">
  # Configuration de l’entrée modulaire {#modular-input-configuration}
</div>

Pour configurer l’entrée modulaire, vous aurez d’abord besoin des informations suivantes concernant votre déploiement ClickHouse Cloud :

* L’identifiant de l’organisation
* Une [clé API](/fr/products/cloud/features/admin-features/api/openapi) d’administrateur

## Récupérer des informations dans ClickHouse Cloud {#getting-information-from-clickhouse-cloud}

Connectez-vous à la [console ClickHouse Cloud](https://console.clickhouse.cloud/).

Accédez à Organization -&gt; Organization details. Vous pourrez y copier l’identifiant de l’organisation.

<div className="ch-image-lg">
  <Frame>
    ![Console ClickHouse Cloud affichant la page Organization details avec l’identifiant de l’organisation](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

Ensuite, accédez à API keys dans le menu de gauche.

<div className="ch-image-lg">
  <Frame>
    ![Console ClickHouse Cloud affichant la section API keys dans le menu de navigation de gauche](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

Créez une API key, donnez-lui un nom explicite et sélectionnez les privilèges `Admin`. Cliquez sur Generate API key.

<div className="ch-image-lg">
  <Frame>
    ![Console ClickHouse Cloud affichant l’interface de création d’API key avec les privilèges Administrateur sélectionnés](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

Enregistrez l’API key et le secret dans un endroit sûr.

<div className="ch-image-lg">
  <Frame>
    ![Console ClickHouse Cloud affichant l’API key générée et le secret à enregistrer](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

## Configurer l’entrée de données dans Splunk {#configure-data-input-in-splunk}

De retour dans Splunk, accédez à Settings -&gt; Data inputs.

<div className="ch-image-lg">
  <Frame>
    ![Interface Splunk affichant le menu Settings avec l’option Data inputs](/images/integrations/tools/data-integration/splunk/splunk_008.webp)
  </Frame>
</div>

Sélectionnez l’entrée de données ClickHouse Cloud Audit Logs.

<div className="ch-image-lg">
  <Frame>
    ![Page Data inputs de Splunk affichant l’option ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_009.webp)
  </Frame>
</div>

Cliquez sur « New » pour configurer une nouvelle instance de l’entrée de données.

<div className="ch-image-lg">
  <Frame>
    ![Interface Splunk de configuration d’une nouvelle entrée de données ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_010.webp)
  </Frame>
</div>

Une fois toutes les informations saisies, cliquez sur Next.

<div className="ch-image-lg">
  <Frame>
    ![Page de configuration Splunk avec les paramètres de l’entrée de données ClickHouse renseignés](/images/integrations/tools/data-integration/splunk/splunk_011.webp)
  </Frame>
</div>

L’entrée est maintenant configurée : vous pouvez commencer à parcourir les journaux d’audit.

# Utilisation {#usage}

L’entrée modulaire stocke les données dans Splunk. Pour les afficher, vous pouvez utiliser la vue de recherche générale de Splunk.
