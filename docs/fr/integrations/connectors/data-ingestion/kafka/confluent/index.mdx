Confluent offre trois options d’intégration avec ClickHouse :

* [ClickHouse Connect Sink sur Confluent Cloud](/fr/integrations/connectors/data-ingestion/kafka/confluent/confluent-cloud), le connector entièrement géré
* [ClickHouse Connect Sink en tant que Custom Connector sur Confluent Cloud](/fr/integrations/connectors/data-ingestion/kafka/confluent/custom-connector), que vous téléversez vous-même
* [HTTP Sink Connector pour Confluent Platform](/fr/integrations/connectors/data-ingestion/kafka/confluent/kafka-connect-http) qui intègre Apache Kafka à une API via HTTP ou HTTPS

## Quelle option Confluent Cloud choisir ? {#which-confluent-cloud-option-should-i-use}

Les deux premières options exécutent le même ClickHouse Connect Sink sur Confluent Cloud. Seule différence : qui gère le connector.

* **Connector entièrement géré** : Confluent installe et met à niveau le connector pour vous. Commencez par cette option, sauf si vous avez besoin d&#39;une fonctionnalité qu&#39;elle ne propose pas.
* **Custom Connector** : vous téléchargez une version du connector depuis [GitHub](https://github.com/ClickHouse/clickhouse-kafka-connect/releases), puis vous la téléversez vous-même sur Confluent Cloud. Choisissez cette option si vous avez besoin d&#39;une version précise du connector ou si vous souhaitez remplacer des paramètres que le connector entièrement géré ne permet de modifier que via une demande d&#39;assistance auprès de Confluent. Les Custom Connectors ne sont disponibles que dans certaines régions AWS.
