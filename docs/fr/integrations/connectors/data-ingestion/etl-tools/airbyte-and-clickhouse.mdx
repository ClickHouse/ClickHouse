<Note>
  Veuillez noter que la source et la destination Airbyte pour ClickHouse sont actuellement en version alpha et ne conviennent pas au transfert de jeux de données volumineux (&gt; 10 millions de lignes).
</Note>

<a href="https://www.airbyte.com/" target="_blank">Airbyte</a> est une plateforme open source d’intégration de données. Elle permet de créer des pipelines de données <a href="https://airbyte.com/blog/why-the-future-of-etl-is-not-elt-but-el" target="_blank">ELT</a> et est fournie avec plus de 140 connecteurs prêts à l’emploi. Ce tutoriel pas à pas montre comment configurer ClickHouse comme destination dans Airbyte et charger un jeu de données d’exemple.

<Steps>
  <Step title="Téléchargez et lancez Airbyte" id="1-download-and-run-airbyte">
    1. Airbyte s’exécute sur Docker et utilise `docker-compose`. Veillez à télécharger et à installer les dernières versions de Docker.

    2. Déployez Airbyte en clonant le dépôt Github officiel et en exécutant `docker-compose up` dans votre terminal habituel :

       ```bash
       git clone https://github.com/airbytehq/airbyte.git --depth=1
       cd airbyte
       ./run-ab-platform.sh
       ```

    3. Une fois la bannière Airbyte affichée dans votre terminal, vous pouvez vous connecter à <a href="http://localhost:8000" target="_blank">localhost:8000</a>

       <div className="ch-image-lg">
         <Frame>
           ![Bannière Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_01.webp)
         </Frame>
       </div>

    <Note>
      Vous pouvez également créer un compte et utiliser <a href="https://docs.airbyte.com/" target="_blank">Airbyte Cloud</a>
    </Note>
  </Step>

  <Step title="Ajouter ClickHouse comme destination" id="2-add-clickhouse-as-a-destination">
    Dans cette section, nous allons voir comment ajouter une instance ClickHouse en tant que destination.

    1. Démarrez votre serveur ClickHouse (Airbyte est compatible avec ClickHouse version `21.8.10.19` ou ultérieure) ou connectez-vous à votre compte ClickHouse Cloud :

       ```bash
       clickhouse-server start
       ```

    2. Dans Airbyte, ouvrez la page « Destinations » et ajoutez une nouvelle destination :

       <div className="ch-image-lg">
         <Frame>
           ![Ajouter une destination dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_02.webp)
         </Frame>
       </div>

    3. Sélectionnez ClickHouse dans la liste déroulante « Destination type », puis remplissez le formulaire « Set up the destination » en indiquant le nom d’hôte et les ports de votre instance ClickHouse, le nom de la base de données, le nom d’utilisateur et le mot de passe, et précisez s&#39;il s&#39;agit d&#39;une connexion SSL (équivalent de l’option `--secure` de `clickhouse-client`) :

       <div className="ch-image-lg">
         <Frame>
           ![Création d’une destination ClickHouse dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_03.webp)
         </Frame>
       </div>

    4. Félicitations ! Vous avez ajouté ClickHouse en tant que destination dans Airbyte.

    <Note>
      Pour utiliser ClickHouse comme destination, l&#39;utilisateur employé doit disposer des autorisations nécessaires pour créer des bases de données et des tables, et pour insérer des lignes. Nous vous recommandons de créer un utilisateur dédié à Airbyte (par ex. `my_airbyte_user`) avec les autorisations suivantes :

      ```sql
      CREATE USER 'my_airbyte_user'@'%' IDENTIFIED BY 'your_password_here';

      GRANT CREATE ON * TO my_airbyte_user;
      ```
    </Note>
  </Step>

  <Step title="Ajouter un jeu de données comme source" id="3-add-a-dataset-as-a-source">
    Le jeu de données d’exemple que nous allons utiliser est le <a href="/fr/get-started/sample-datasets/nyc-taxi" target="_blank">New York City Taxi Data</a> (sur <a href="https://github.com/toddwschneider/nyc-taxi-data" target="_blank">Github</a>). Dans ce tutoriel, nous utiliserons un sous-ensemble de ce jeu de données correspondant au mois de janvier 2022.

    1. Dans Airbyte, ouvrez la page « Sources » et ajoutez une nouvelle source de type File.

       <div className="ch-image-lg">
         <Frame>
           ![Ajouter une source dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_04.webp)
         </Frame>
       </div>

    2. Remplissez le formulaire « Set up the source » en nommant la source et en indiquant l’URL du fichier NYC Taxi de janvier 2022 (voir ci-dessous). Veillez à choisir `parquet` comme format de fichier, `HTTPS Public Web` comme Storage Provider et `nyc_taxi_2022` comme Dataset Name.

       ```text
       https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2022-01.parquet
       ```

       <div className="ch-image-lg">
         <Frame>
           ![Création d’une source ClickHouse dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_05.webp)
         </Frame>
       </div>

    3. Félicitations ! Vous avez ajouté une source de type fichier dans Airbyte.
  </Step>

  <Step title="Créez une connexion et chargez le jeu de données dans ClickHouse" id="4-create-a-connection-and-load-the-dataset-into-clickhouse">
    1. Dans Airbyte, ouvrez la page « Connections » et ajoutez une nouvelle connexion

    <div className="ch-image-lg">
      <Frame>
        ![Ajouter une connexion dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_06.webp)
      </Frame>
    </div>

    2. Sélectionnez &quot;Use existing source&quot; et choisissez New York City Taxi Data, puis sélectionnez &quot;Use existing destination&quot; et choisissez votre instance ClickHouse.

    3. Remplissez le formulaire &quot;Set up the connection&quot; en choisissant une fréquence de réplication (Replication Frequency ; nous utiliserons `manual` dans ce tutoriel), puis sélectionnez `nyc_taxi_2022` comme flux à synchroniser. Veillez à choisir `Normalized Tabular Data` comme mode de normalisation (Normalization).

    <div className="ch-image-lg">
      <Frame>
        ![Création d'une connexion dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_07.webp)
      </Frame>
    </div>

    4. Une fois la connexion créée, cliquez sur &quot;Sync now&quot; pour lancer le chargement des données (puisque nous avons choisi `Manual` comme Replication Frequency)

    <div className="ch-image-lg">
      <Frame>
        ![Bouton « Sync now » dans Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_08.webp)
      </Frame>
    </div>

    5. Le chargement de vos données démarre. Vous pouvez développer la vue pour consulter les logs et la progression d&#39;Airbyte. Une fois l&#39;opération terminée, le message `Completed successfully` s&#39;affiche dans les logs :

    <div className="ch-image-lg">
      <Frame>
        ![Terminé avec succès](/images/integrations/data-ingestion/etl-tools/airbyte_09.webp)
      </Frame>
    </div>

    6. Connectez-vous à votre instance ClickHouse avec votre client SQL préféré et vérifiez la table obtenue :

       ```sql
       SELECT *
       FROM nyc_taxi_2022
       LIMIT 10
       ```
