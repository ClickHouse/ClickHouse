[#88157](https://github.com/ClickHouse/ClickHouse/pull/88157) ([Shafi Ahmed](https://github.com/ita004)).
* Rétroporté dans [#90415](https://github.com/ClickHouse/ClickHouse/issues/90415) : correction d’un crash lors de l’arrêt propre du serveur, dû à un ordre de destruction incorrect. Résout [#82420](https://github.com/ClickHouse/ClickHouse/issues/82420). [#90076](https://github.com/ClickHouse/ClickHouse/pull/90076) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#94008](https://github.com/ClickHouse/ClickHouse/issues/94008) : correction d’un crash causé par un dépassement de capacité d’entier dans randomStringUTF8. [#90326](https://github.com/ClickHouse/ClickHouse/pull/90326) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#93555](https://github.com/ClickHouse/ClickHouse/issues/93555) : correction d’un crash lors de la désérialisation d’un état agrégé `groupConcat` malformé avec des offsets hors limites. [#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#93468](https://github.com/ClickHouse/ClickHouse/issues/93468) : correction d’une vulnérabilité de dépassement de capacité d’entier dans la désérialisation de l’état `groupConcat`, pouvant entraîner des problèmes de sûreté mémoire avec des états agrégés forgés. [#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#93684](https://github.com/ClickHouse/ClickHouse/issues/93684) : s’assurer que ZooKeeper est correctement finalisé à l’arrêt (corrige un possible blocage à l’arrêt dans des cas très improbables). [#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93950](https://github.com/ClickHouse/ClickHouse/issues/93950) : correction d’un LOGICAL&#95;ERROR lors de la restauration de ReplicatedMergeTree en cas de condition de concurrence sur la déduplication. [#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#93961](https://github.com/ClickHouse/ClickHouse/issues/93961) : correction de l’utilisation d’une colonne Sparse pour la mise à jour TTL lors d’une désérialisation directe vers des colonnes Sparse dans certains formats d’entrée. Cela corrige l’erreur logique possible `Unexpected type of result TTL column`. [#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93804](https://github.com/ClickHouse/ClickHouse/issues/93804) : validation que la taille du buffer décompressé correspond bien à celle attendue. [#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#93794](https://github.com/ClickHouse/ClickHouse/issues/93794) : empêche les utilisateurs d’obtenir la liste des colonnes d’une table via le moteur de table `merge` sans vérification de la permission `SHOW COLUMNS`. [#93695](https://github.com/ClickHouse/ClickHouse/pull/93695) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#94159](https://github.com/ClickHouse/ClickHouse/issues/94159) : corrige [https://github.com/ClickHouse/clickhouse-core-incidents/issues/1217](https://github.com/ClickHouse/clickhouse-core-incidents/issues/1217). Une exception a été déclenchée lors d’un appel à `socket.setBlocking(true)` à l’intérieur de `SCOPE_EXIT` : [logs](https://grafana.clickhouse-prd.com/a/loghouseapp/sysex?thanos_datasource=LightHouse+Thanos+%28production%29\&environment=production\&sortOrder=Asc\&namespace=ns-olive-ae-66\&region=us-central1\&limit=500\&whereExtra=and+level+%3D+%27Fatal%27\&tableName=text_log\&groupBy=level\&extraCols=level\&timeFrom=2025-12-29T01%3A13%3A46Z\&timeFromCHFormat=2025-12-29+01%3A13%3A46\&timeFromUnix=1766970826\&timeTo=2025-12-29T02%3A13%3A51Z\&timeToCHFormat=2025-12-29+02%3A13%3A51\&timeToUnix=1766974431\&dateTo=2025-12-29\&dateFrom=2025-12-29).
