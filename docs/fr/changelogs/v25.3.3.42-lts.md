<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#78899](https://github.com/ClickHouse/ClickHouse/issues/78899) : correction de la coercition de type de la clause `IN` pour `BFloat16` (c.-à-d. que `SELECT toBFloat16(1) IN [1, 2, 3];` renvoie désormais `1`). Clôt [#78754](https://github.com/ClickHouse/ClickHouse/issues/78754). [#78839](https://github.com/ClickHouse/ClickHouse/pull/78839) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#79137](https://github.com/ClickHouse/ClickHouse/issues/79137) : suppression des paramètres lors de `recoverLostReplica`, comme cela a été fait dans [https://github.com/ClickHouse/ClickHouse/pull/78637](https://github.com/ClickHouse/ClickHouse/pull/78637). [#79113](https://github.com/ClickHouse/ClickHouse/pull/79113) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#78790](https://github.com/ClickHouse/ClickHouse/issues/78790) : correction des skip indexes qui ne fonctionnaient pas avec des expressions contenant des littéraux dans l’analyseur, et suppression des casts triviaux lors de l’analyse des indexes. [#77229](https://github.com/ClickHouse/ClickHouse/pull/77229) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#79285](https://github.com/ClickHouse/ClickHouse/issues/79285) : correction d’une vue matérialisée actualisable dans une base de données Replicated qui ne fonctionnait pas sur les répliques nouvellement ajoutées. [#77774](https://github.com/ClickHouse/ClickHouse/pull/77774) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#78438](https://github.com/ClickHouse/ClickHouse/issues/78438) : correction d’un remplacement de métadonnées dans Database Replicated pouvant se produire à la suite d’une requête RENAME exécutée juste après une requête ALTER. [#78107](https://github.com/ClickHouse/ClickHouse/pull/78107) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#78547](https://github.com/ClickHouse/ClickHouse/issues/78547) : masquage de la signature d’accès Azure afin qu’elle ne soit visible ni par l’utilisateur ni dans les journaux. [#78189](https://github.com/ClickHouse/ClickHouse/pull/78189) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#78528](https://github.com/ClickHouse/ClickHouse/issues/78528) : correction de la prélecture des sous-flux avec préfixes dans les parts Wide. [#78205](https://github.com/ClickHouse/ClickHouse/pull/78205) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#78952](https://github.com/ClickHouse/ClickHouse/issues/78952) : ne pas planifier de tâche RefreshMV si `disable_insertion_and_mutation` d’une réplique vaut true. Une tâche correspond à une insertion ; elle échouera si `disable_insertion_and_mutation` vaut true. [#78277](https://github.com/ClickHouse/ClickHouse/pull/78277) ([Xu Jia](https://github.com/XuJia0210)).
* Rétroporté dans [#78979](https://github.com/ClickHouse/ClickHouse/issues/78979) : validation de l’accès aux tables sous-jacentes pour le moteur Merge. [#78339](https://github.com/ClickHouse/ClickHouse/pull/78339) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Rétroporté dans [#78649](https://github.com/ClickHouse/ClickHouse/issues/78649) : le modificateur FINAL peut être perdu pour une table avec moteur `Distributed`. [#78428](https://github.com/ClickHouse/ClickHouse/pull/78428) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#78534](https://github.com/ClickHouse/ClickHouse/issues/78534) : annulation de &quot;Apply preserve&#95;most attribute at some places in code&quot; car cela peut entraîner des crashs. [#78449](https://github.com/ClickHouse/ClickHouse/pull/78449) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#78760](https://github.com/ClickHouse/ClickHouse/issues/78760) : définir au moins un flux de lecture lorsqu’aucun flux n’est planifié après application du paramètre `max_streams_to_max_threads_ratio`. [#78505](https://github.com/ClickHouse/ClickHouse/pull/78505) ([Eduard Karacharov](https://github.com/korowa)).
* Rétroporté dans [#78614](https://github.com/ClickHouse/ClickHouse/issues/78614) : ClickHouse est désormais capable de détecter son cgroup v2 sur les systèmes où les cgroups v1 et v2 sont tous deux activés. [#78566](https://github.com/ClickHouse/ClickHouse/pull/78566) ([Grigory Korolev](https://github.com/gkorolev)).
* Rétroporté dans [#78772](https://github.com/ClickHouse/ClickHouse/issues/78772) : les fonctions table cluster ObjectStorage échouaient lorsqu’elles étaient utilisées avec des paramètres au niveau de la table. [#78587](https://github.com/ClickHouse/ClickHouse/pull/78587) ([Daniil Ivanik](https://github.com/divanik)).
* Rétroporté dans [#78685](https://github.com/ClickHouse/ClickHouse/issues/78685) : suppression des paramètres de requête lors de `attach`. [#78637](https://github.com/ClickHouse/ClickHouse/pull/78637) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#78945](https://github.com/ClickHouse/ClickHouse/issues/78945) : correction d’un crash dans une MV actualisable en cas de ALTER après un arrêt incorrect. [#78858](https://github.com/ClickHouse/ClickHouse/pull/78858) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#79272](https://github.com/ClickHouse/ClickHouse/issues/79272) : correction dans Keeper : éviter de déclencher des watches sur des multi-requêtes en échec. [#79247](https://github.com/ClickHouse/ClickHouse/pull/79247) ([Antonio Andelic](https://github.com/antonio2368)).
