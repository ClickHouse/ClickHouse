  ### Version ClickHouse v25.11.5.8-stable (06e6dea3bb5) FIXME par rapport à v25.11.4.19-stable (2c64eff7334)

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#92901](https://github.com/ClickHouse/ClickHouse/issues/92901) : corrige un possible conflit entre une colonne et une sous-colonne portant le même nom, pouvant entraîner l’utilisation d’une mauvaise sérialisation et des échecs de requête. Clôture [#90219](https://github.com/ClickHouse/ClickHouse/issues/90219). Clôture [#85161](https://github.com/ClickHouse/ClickHouse/issues/85161). [#92453](https://github.com/ClickHouse/ClickHouse/pull/92453) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#92988](https://github.com/ClickHouse/ClickHouse/issues/92988) : évite un plantage dû à la lecture depuis une `Connection` déconnectée. [#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#92879](https://github.com/ClickHouse/ClickHouse/issues/92879) : corrige l’erreur logique ` Failed to set file processing within 100 retries` dans le stockage `S3Queue` en mode `Ordered`. Elle est désormais remplacée par un avertissement. Cette erreur pouvait se produire avant la version 25.10 si la session Keeper expirait, mais elle restera un avertissement dans les versions 25.10+, car il reste théoriquement possible qu’elle survienne en cas de forte concurrence de traitement en mode `Ordered`. [#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#92943](https://github.com/ClickHouse/ClickHouse/issues/92943) : corrige l’utilisation de l’index primaire dans les mises à jour légères comportant une clause `IN` avec des sous-requêtes dans le prédicat de la clause `WHERE`. [#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#92962](https://github.com/ClickHouse/ClickHouse/issues/92962) : corrige une possible erreur `FILE_DOESNT_EXIST` après mutation d’une colonne creuse avec `ratio_of_defaults_for_sparse_serialization=0.0`. Clôture [#92633](https://github.com/ClickHouse/ClickHouse/issues/92633). [#92860](https://github.com/ClickHouse/ClickHouse/pull/92860) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#92934](https://github.com/ClickHouse/ClickHouse/issues/92934) : corrige l’inférence de schéma Parquet dans l’ancien lecteur Parquet (non utilisé par défaut) lorsqu’une colonne JSON suit une colonne Tuple. Corrige également l’échec de l’ancien lecteur Parquet (non utilisé par défaut) sur des tuples vides. [#92867](https://github.com/ClickHouse/ClickHouse/pull/92867) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#93032](https://github.com/ClickHouse/ClickHouse/issues/93032) : corrige une possible utilisation de parties obsolètes due à une condition de concurrence TOCTOU sur des parties partagées. [#93022](https://github.com/ClickHouse/ClickHouse/pull/93022) ([Azat Khuzhin](https://github.com/azat)).
