<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#101603](https://github.com/ClickHouse/ClickHouse/issues/101603) : le suivi de la mémoire dans Cgroupv2 exclut désormais `slab_reclaimable` de la mémoire du noyau, ce qui fournit une mesure plus précise de l’utilisation de la mémoire non récupérable. [#100901](https://github.com/ClickHouse/ClickHouse/pull/100901) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#101868](https://github.com/ClickHouse/ClickHouse/issues/101868) : l’index de texte intégral est désormais GA et reste activé quel que soit le paramètre `compatibility`, ce qui évite une désactivation inattendue lors de restaurations à partir de sauvegardes ou en mode de compatibilité. [#101518](https://github.com/ClickHouse/ClickHouse/pull/101518) ([Nikita Fomichev](https://github.com/fm4v)).
* Rétroporté dans [#101862](https://github.com/ClickHouse/ClickHouse/issues/101862) : mise à niveau de libarchive de 3.8.5 à 3.8.6. [#101658](https://github.com/ClickHouse/ClickHouse/pull/101658) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#101856](https://github.com/ClickHouse/ClickHouse/issues/101856) : mise à niveau de curl de 8.18 à 8.19. [#101662](https://github.com/ClickHouse/ClickHouse/pull/101662) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#101461](https://github.com/ClickHouse/ClickHouse/issues/101461) : correction d’un bogue dans Keeper où une requête de lecture pouvait rester bloquée (entraînant l’expiration de la session) si une autre session, sans lien, sur le même serveur, était fermée au mauvais moment. [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#101689](https://github.com/ClickHouse/ClickHouse/issues/101689) : correction d’un heap-buffer-overflow dans usearch `sorted_buffer_gt::insert()`, qui pouvait provoquer un plantage ou corrompre silencieusement la mémoire lors d’une recherche de similarité vectorielle. [#100537](https://github.com/ClickHouse/ClickHouse/pull/100537) ([Dustin Healy](https://github.com/dustinhealy)).
* Rétroporté dans [#101633](https://github.com/ClickHouse/ClickHouse/issues/101633) : correction d’un comportement indéfini (dépassement d’entier signé) dans parseDateTimeBestEffort lors de l’analyse de chaînes DateTime comportant plus de 18 chiffres de seconde fractionnaire. [#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* Rétroporté dans [#101364](https://github.com/ClickHouse/ClickHouse/issues/101364) : correction des fonctions d’agrégation `MAX`/`MIN` sur des colonnes `Decimal`, qui renvoyaient des résultats incorrects lorsque la compilation JIT est activée (une fois le seuil de compilation atteint). [#101203](https://github.com/ClickHouse/ClickHouse/pull/101203) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#101625](https://github.com/ClickHouse/ClickHouse/issues/101625) : correction d’un plantage du serveur (Logical error: &quot;Variant ... is empty&quot;) lorsqu’une query lit simultanément une colonne Tuple contenant un type Map Dynamic et sa sous-colonne (par ex., `SELECT ... WHERE NOT ignore(*, mapKeys(t.m))`). [#101448](https://github.com/ClickHouse/ClickHouse/pull/101448) ([Groene AI](https://github.com/groeneai)).
