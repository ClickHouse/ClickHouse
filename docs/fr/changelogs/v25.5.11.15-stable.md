<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#86107](https://github.com/ClickHouse/ClickHouse/issues/86107) : l’utilisation de `distributed_depth` comme indicateur de la *Cluster function était incorrecte et pouvait entraîner une duplication des données ; utilisez plutôt `client_info.collaborate_with_initiator`. [#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#86264](https://github.com/ClickHouse/ClickHouse/issues/86264) : correction d’une erreur logique lors d’une tentative de `CREATE ... AS (SELECT * FROM s3Cluster(...))` avec `DatabaseReplicated`. [#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#86037](https://github.com/ClickHouse/ClickHouse/issues/86037) : correction d’un bug dans la récupération de la base de données `Replicated` : si un nom de table contenait le symbole `%`, la table pouvait être recréée sous un autre nom pendant la récupération. [#85987](https://github.com/ClickHouse/ClickHouse/pull/85987) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#86344](https://github.com/ClickHouse/ClickHouse/issues/86344) : correction d’un crash lors d’un ALTER UPDATE Nullable(JSON). [#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
