<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#84783](https://github.com/ClickHouse/ClickHouse/issues/84783) : cette modification ajoute une Metric dimensionnelle pour la taille de `ConcurrentBoundedQueue`, avec des labels correspondant au type de file d’attente (c.-à-d. à quoi sert la file d’attente) et à l’identifiant de la file d’attente (c.-à-d. un identifiant généré aléatoirement pour l’instance actuelle de la file d’attente). [#84675](https://github.com/ClickHouse/ClickHouse/pull/84675) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#85007](https://github.com/ClickHouse/ClickHouse/issues/85007) : ajout dans Keeper de la 4LW `lgrq`, permettant d’activer ou de désactiver la journalisation des requêtes reçues. [#84719](https://github.com/ClickHouse/ClickHouse/pull/84719) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#84869](https://github.com/ClickHouse/ClickHouse/issues/84869) : réduction de la contention sur le verrou du stockage dans Keeper. [#84732](https://github.com/ClickHouse/ClickHouse/pull/84732) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#85001](https://github.com/ClickHouse/ClickHouse/issues/85001) : limitation de la taille du cache des entrées de log de Keeper en fonction du nombre d’entrées, à l’aide de `keeper_server.coordination_settings.latest_logs_cache_entry_count_threshold` et de `keeper_server.coordination_settings.commit_logs_cache_entry_count_threshold`. [#84877](https://github.com/ClickHouse/ClickHouse/pull/84877) ([Antonio Andelic](https://github.com/antonio2368)).
