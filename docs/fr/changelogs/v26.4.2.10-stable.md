<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#104160](https://github.com/ClickHouse/ClickHouse/issues/104160) : éviter le surcoût du cache d’index non compressé lorsque ce cache est désactivé (paramètre du serveur `index_uncompressed_cache_size = 0`, valeur par défaut). [#104063](https://github.com/ClickHouse/ClickHouse/pull/104063) ([Michael Kolupaev](https://github.com/al13n321)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#104213](https://github.com/ClickHouse/ClickHouse/issues/104213) : ajout des fonctions SQL `obfuscateQuery` et `obfuscateQueryWithSeed`, qui obfusquent le texte d&#39;une requête SQL en remplaçant les identifiants et les littéraux par des espaces réservés aléatoires, tout en préservant la structure de la requête. Correction de cas limites dans l&#39;obfuscation des requêtes pour les identifiants courts et les littéraux entiers trop volumineux. [#101027](https://github.com/ClickHouse/ClickHouse/pull/101027) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#104224](https://github.com/ClickHouse/ClickHouse/issues/104224) : correction d&#39;une fuite de mémoire lors de l&#39;exécution de requêtes avec des CTE `MATERIALIZED`. [#104153](https://github.com/ClickHouse/ClickHouse/pull/104153) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement erroné visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#104211](https://github.com/ClickHouse/ClickHouse/issues/104211) : corrige un comportement indéfini dans `MergeTreeDataPartWriterCompact::cancel` lorsqu’une allocation de flux échoue. [#101292](https://github.com/ClickHouse/ClickHouse/pull/101292) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#104151](https://github.com/ClickHouse/ClickHouse/issues/104151) : désactive l’optimisation triviale de LIMIT avec les politiques de ligne/additional&#95;table&#95;filters (pour permettre une analyse d’index en parallèle). [#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#104244](https://github.com/ClickHouse/ClickHouse/issues/104244) : corrige une régression d’intégrité des données dans la branche 26.x, où `if` et `multiIf` compilés par JIT avec un type de résultat `Decimal` et un littéral non-`Decimal` (entier ou flottant) dans l’une des branches renvoyaient silencieusement une valeur inférieure d’un facteur `10^scale`. Le chemin lent (sans JIT) n’était pas affecté. Solution de contournement pour les versions concernées : `SET compile_expressions = 0`. [#103809](https://github.com/ClickHouse/ClickHouse/pull/103809) ([Groene AI](https://github.com/groeneai)).
* Rétroporté dans [#104147](https://github.com/ClickHouse/ClickHouse/issues/104147) : corrige `SIZES_OF_ARRAYS_DONT_MATCH` lors de la lecture de colonnes `AggregateFunction(topK(N), String)` dont la valeur persistée de `alpha_size` avait été augmentée par un cycle deserialize+serialize antérieur à la version 25.12. [#104002](https://github.com/ClickHouse/ClickHouse/pull/104002) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#104195](https://github.com/ClickHouse/ClickHouse/issues/104195) : corrige une écriture hors limites lors de la désérialisation de l’état `quantileTiming`. [#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
