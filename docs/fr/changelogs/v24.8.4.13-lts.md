<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#68699](https://github.com/ClickHouse/ClickHouse/issues/68699) : suppression de l’ancien code des named collections dans les dictionaries et remplacement par le nouveau, ce qui permet d’utiliser des named collections créées via DDL dans les dictionaries. Résout [#60936](https://github.com/ClickHouse/ClickHouse/issues/60936), résout [#36890](https://github.com/ClickHouse/ClickHouse/issues/36890). [#68412](https://github.com/ClickHouse/ClickHouse/pull/68412) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#69231](https://github.com/ClickHouse/ClickHouse/issues/69231) : correction d’une erreur d’analyse lorsque `NULL` doit être inséré comme valeur par défaut dans certains cas lors de l’analyse du type JSON. [#68955](https://github.com/ClickHouse/ClickHouse/pull/68955) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#69251](https://github.com/ClickHouse/ClickHouse/issues/69251) : la clause `UNION` dans les sous-requêtes n’était pas correctement gérée dans les requêtes avec des répliques parallèles et entraînait l’erreur LOGICAL&#95;ERROR `Duplicate announcement received for replica`. [#69146](https://github.com/ClickHouse/ClickHouse/pull/69146) ([Igor Nikonov](https://github.com/devcrafter)).
