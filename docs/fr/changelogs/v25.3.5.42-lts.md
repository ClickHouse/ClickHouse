  ### Version de ClickHouse v25.3.5.42-lts (14e08ead34a) FIXME par rapport à v25.3.4.190-lts (93636ae3130)

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#78853](https://github.com/ClickHouse/ClickHouse/issues/78853) : respecte désormais la limite `loading_retries` pour les erreurs survenant lors du push vers une vue matérialisée pour StorageS3(Azure)Queue. Auparavant, ces erreurs étaient réessayées indéfiniment. [#78313](https://github.com/ClickHouse/ClickHouse/pull/78313) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#82411](https://github.com/ClickHouse/ClickHouse/issues/82411) : les fonctions de hachage prennent désormais en charge les NULL à l’intérieur des tableaux, tuples et maps. (issues [#48365](https://github.com/ClickHouse/ClickHouse/issues/48365) et [#48623](https://github.com/ClickHouse/ClickHouse/issues/48623)). [#79008](https://github.com/ClickHouse/ClickHouse/pull/79008) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#81612](https://github.com/ClickHouse/ClickHouse/issues/81612) : utilise `orc` 2.1.2. [#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#81697](https://github.com/ClickHouse/ClickHouse/issues/81697) : utilise `grpc` 1.73.0. [#81629](https://github.com/ClickHouse/ClickHouse/pull/81629) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#82592](https://github.com/ClickHouse/ClickHouse/issues/82592) : amélioration de Keeper : ajout d’une nouvelle config `keeper_server.cleanup_old_and_ignore_new_acl`. Si elle est activée, les ACL de tous les nœuds seront supprimées, tandis que les ACL des nouvelles requêtes seront ignorées. Si l’objectif est de supprimer complètement les ACL des nœuds, il est important de laisser la config activée jusqu’à la création d’un nouveau snapshot. [#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#82922](https://github.com/ClickHouse/ClickHouse/issues/82922) : amélioration de Keeper : prise en charge de permissions spécifiques pour l’ACL world:anyone. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#82328](https://github.com/ClickHouse/ClickHouse/issues/82328) : correction de l’exécution de `IN` avec `transform_null_in=1` en présence de NULL dans l’argument de gauche et d’un résultat de sous-requête non `Nullable`. [#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#82775](https://github.com/ClickHouse/ClickHouse/issues/82775) : correction de l’analyse du filtre lorsqu’une seule colonne d’alias constante est utilisée dans la requête. Corrige [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448). [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#82548](https://github.com/ClickHouse/ClickHouse/issues/82548) : correction de LOGICAL&#95;ERROR et du crash qui s’ensuit lors de l’utilisation de la même colonne dans le TTL pour GROUP BY et SET. [#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#82314](https://github.com/ClickHouse/ClickHouse/issues/82314) : correction de l’erreur `Not found column` pour les requêtes avec `arrayJoin` sous la condition `WHERE` et `IndexSet`. [#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#82557](https://github.com/ClickHouse/ClickHouse/issues/82557) : correction d’un interblocage possible pour les requêtes distantes lorsque le serveur subit une pression mémoire. [#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* Rétroporté dans [#82519](https://github.com/ClickHouse/ClickHouse/issues/82519) : ajout d’une expiration au token AWS ECS afin qu’il puisse être rechargé. [#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#82575](https://github.com/ClickHouse/ClickHouse/issues/82575) : correction du masquage des valeurs des collections nommées dans les logs/query&#95;log. Clôt [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405). [#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#82566](https://github.com/ClickHouse/ClickHouse/issues/82566) : correction d’un crash possible dans le logging lors de la terminaison d’une session, car le user&#95;id peut parfois être vide. [#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
* Rétroporté dans [#82731](https://github.com/ClickHouse/ClickHouse/issues/82731) : les fonctions `trim{Left,Right,Both}` prennent désormais en charge les chaînes d’entrée de type &quot;FixedString(N)&quot;. Par exemple, `SELECT trimBoth(toFixedString('abc', 3), 'ac')` fonctionne désormais. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
