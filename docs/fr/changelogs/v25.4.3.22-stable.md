<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#79924](https://github.com/ClickHouse/ClickHouse/issues/79924) : empêcher `LogSeriesLimiter` d’effectuer un nettoyage à chaque instanciation, afin d’éviter la contention sur les verrous et les régressions de performances dans les scénarios de forte concurrence. [#79864](https://github.com/ClickHouse/ClickHouse/pull/79864) ([filimonov](https://github.com/filimonov)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#79904](https://github.com/ClickHouse/ClickHouse/issues/79904) : ajout du paramètre `access_control_improvements.enable_user_name_access_type`. Ce paramètre permet d’activer ou de désactiver des privilèges précis pour les utilisateurs/rôles, introduits dans [https://github.com/ClickHouse/ClickHouse/pull/72246](https://github.com/ClickHouse/ClickHouse/pull/72246). Il peut être utile de désactiver ce paramètre si vous avez un cluster avec des répliques antérieures à 25.1. [#79842](https://github.com/ClickHouse/ClickHouse/pull/79842) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#79934](https://github.com/ClickHouse/ClickHouse/issues/79934) : la méthode `ASTSelectWithUnionQuery::clone()` est désormais correctement implémentée et prend également en compte le champ `is_normalized`. Cela pourrait aider pour [#77569](https://github.com/ClickHouse/ClickHouse/issues/77569). [#79909](https://github.com/ClickHouse/ClickHouse/pull/79909) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#79820](https://github.com/ClickHouse/ClickHouse/issues/79820) : correction de l’application de `async_insert` depuis le serveur (via `apply_settings_from_server`) (cela provoquait auparavant des erreurs `Unknown packet 11 from server` côté client). [#77578](https://github.com/ClickHouse/ClickHouse/pull/77578) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#79785](https://github.com/ClickHouse/ClickHouse/issues/79785) : correction d’un problème où les vues matérialisées actualisables interrompaient les sauvegardes. [#77893](https://github.com/ClickHouse/ClickHouse/pull/77893) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#79741](https://github.com/ClickHouse/ClickHouse/issues/79741) : correction d’un crash lors de la découverte des sous-colonnes dynamiques dans les Wide parts de MergeTree. [#79466](https://github.com/ClickHouse/ClickHouse/pull/79466) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#79585](https://github.com/ClickHouse/ClickHouse/issues/79585) : vérifier la longueur du nom de la table uniquement pour les requêtes CREATE initiales. Ne pas la vérifier pour les créations secondaires afin d’éviter des problèmes de rétrocompatibilité. [#79488](https://github.com/ClickHouse/ClickHouse/pull/79488) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#79973](https://github.com/ClickHouse/ClickHouse/issues/79973) : masquer le mot de passe dans la requête `CREATE DATABASE datalake ENGINE = DataLakeCatalog(\'http://catalog:8181\', \'admin\', \'password\')`. [#79941](https://github.com/ClickHouse/ClickHouse/pull/79941) ([Han Fei](https://github.com/hanfei1991)).
