<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible pour l’utilisateur dans une version stable officielle)
</div>

* rétroporté dans [#108281](https://github.com/ClickHouse/ClickHouse/issues/108281) : les informations d’authentification dans les chaînes de connexion JDBC, ODBC et NATS sont désormais masquées dans les query logs et dans la sortie de `SHOW CREATE`, afin d’éviter toute divulgation accidentelle d’informations sensibles. Pour les chaînes de connexion au format URI (par ex. {scheme}://{user}:{password}@{host}), seule la partie mot de passe est masquée, le reste restant visible pour faciliter le débogage. Le paramètre `nats_token` est désormais également masqué. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#108446](https://github.com/ClickHouse/ClickHouse/issues/108446) : correction d&#39;un nombre de lignes erroné renvoyé par `arrayJoin()` lorsqu&#39;il est utilisé dans `JOIN ON` : le résultat était multiplié une fois de trop par la longueur du tableau. [#104785](https://github.com/ClickHouse/ClickHouse/pull/104785) ([Shaohua Wang](https://github.com/tiandiwonder)).
* Rétroporté dans [#107482](https://github.com/ClickHouse/ClickHouse/issues/107482) : correction d&#39;une exception lorsqu&#39;une requête de recherche vectorielle utilise un vector index ainsi qu&#39;un autre skip index tel que `minmax`, avec `use_skip_indexes_on_data_read = 1`. [#106473](https://github.com/ClickHouse/ClickHouse/pull/106473) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Rétroporté dans [#108259](https://github.com/ClickHouse/ClickHouse/issues/108259) : correction de l&#39;erreur &quot;Too many marks&quot; pour un text index sur une part fusionnée vide. [#106867](https://github.com/ClickHouse/ClickHouse/pull/106867) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#108170](https://github.com/ClickHouse/ClickHouse/issues/108170) : correction d&#39;une logical error `Block structure mismatch in UnionStep stream` (arrêt du serveur sur les builds de débogage/avec sanitizer, `Code: 49` sur les builds de release) qui se produisait lorsqu&#39;une branche de `UNION`/`INTERSECT`/`EXCEPT` lisait une colonne sérialisée en `Sparse`, tandis que l&#39;autre branche lisait cette même colonne dans sa version complète (par exemple lors d&#39;un envoi vers une vue matérialisée). [#107041](https://github.com/ClickHouse/ClickHouse/pull/107041) ([Groene AI](https://github.com/groeneai)).
* Rétroporté dans [#108222](https://github.com/ClickHouse/ClickHouse/issues/108222) : correction d&#39;un heap buffer overflow (plantage du serveur) dans `windowFunnel` lors de la finalisation d&#39;un état de fonction d&#39;agrégation forgé avec un type d&#39;événement hors limites, exploitable par n&#39;importe quel utilisateur avec un simple `SELECT`. [#107412](https://github.com/ClickHouse/ClickHouse/pull/107412) ([uwezkhan](https://github.com/uwezkhan)).
* Rétroporté dans [#108501](https://github.com/ClickHouse/ClickHouse/issues/108501) : le nouvel snapshot reconstruit dans `update()` capture déjà les informations d&#39;identification actuelles du client S3 C++ via `createBuilder` ; il est désormais conservé au lieu d&#39;être ignoré lorsque la version correspond, afin que la prochaine opération du noyau s&#39;exécute sur un engine avec des identifiants actualisés et ne dépasse pas le TTL STS. [#107480](https://github.com/ClickHouse/ClickHouse/pull/107480) ([Elmi Ahmadov](https://github.com/ahmadov)).
* Rétroporté dans [#108638](https://github.com/ClickHouse/ClickHouse/issues/108638) : correction de `RESTORE` pour les tables `ReplicatedMergeTree`, afin que les parts au contenu dupliqué issues d&#39;une sauvegarde soient conservées au lieu d&#39;être dédupliquées silencieusement. [#107652](https://github.com/ClickHouse/ClickHouse/pull/107652) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#108203](https://github.com/ClickHouse/ClickHouse/issues/108203) : correction d&#39;un set skip index qui n&#39;élaguait pas les granules sur des colonnes `LowCardinality`. [#107868](https://github.com/ClickHouse/ClickHouse/pull/107868) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#108304](https://github.com/ClickHouse/ClickHouse/issues/108304) : correction d&#39;un plantage (SIGSEGV sur les builds de release, assertion d&#39;incompatibilité de type sur les builds de débogage) dans `has` sur un `Map` avec une clé `Dynamic` lorsque l&#39;argument de lookup est `LowCardinality`, par exemple `has(map('a'::Dynamic, ...), toLowCardinality('b'))`. [#107956](https://github.com/ClickHouse/ClickHouse/pull/107956) ([Groene AI](https://github.com/groeneai)).
* Rétroporté dans [#108196](https://github.com/ClickHouse/ClickHouse/issues/108196) : toujours exécuter les handlers de fin de batch du cache d&#39;accès, même pour un batch vide. [#108124](https://github.com/ClickHouse/ClickHouse/pull/108124) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#108320](https://github.com/ClickHouse/ClickHouse/issues/108320) : correction d’une vue matérialisée actualisable susceptible de se bloquer si la connexion à ZooKeeper est perdue au mauvais moment. [#108234](https://github.com/ClickHouse/ClickHouse/pull/108234) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#108481](https://github.com/ClickHouse/ClickHouse/issues/108481) : masquage des arguments secrets de fonctions telles que `encrypt`, `decrypt` et `HMAC` dans la sortie de `EXPLAIN actions`, `EXPLAIN header` et `EXPLAIN PIPELINE` lorsque `format_display_secrets_in_show_and_select` est désactivé (valeur par défaut). [#108386](https://github.com/ClickHouse/ClickHouse/pull/108386) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#108693](https://github.com/ClickHouse/ClickHouse/issues/108693) : correction d’une divulgation de métadonnées par laquelle `DESCRIBE loop('db', 'table')` et `DESCRIBE loop(<inner table function>)` contournaient le contrôle d’accès `SHOW COLUMNS` / source, permettant à un utilisateur non privilégié de lire le schéma des colonnes d’une table. [#108624](https://github.com/ClickHouse/ClickHouse/pull/108624) ([Groene AI](https://github.com/groeneai)).
