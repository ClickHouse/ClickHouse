<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#104164](https://github.com/ClickHouse/ClickHouse/issues/104164) : éviter le surcoût lié au cache d’index non compressé lorsque celui-ci est désactivé (paramètre serveur `index_uncompressed_cache_size = 0`, qui est la valeur par défaut). [#104063](https://github.com/ClickHouse/ClickHouse/pull/104063) ([Michael Kolupaev](https://github.com/al13n321)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#104797](https://github.com/ClickHouse/ClickHouse/issues/104797) : correction d’un déréférencement de pointeur nul dans `dictGetOrDefault` lorsque l’argument de clé est `Nullable`. [#98460](https://github.com/ClickHouse/ClickHouse/pull/98460) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#104022](https://github.com/ClickHouse/ClickHouse/issues/104022) : correction d’une exception pouvant survenir lors de l’insertion d’une ligne dans une colonne JSON, lorsque cette ligne introduisait un nouveau champ dynamique aux côtés d’un champ typé avec une valeur incompatible, et que la colonne était ensuite utilisée comme clé de GROUP BY. [#100758](https://github.com/ClickHouse/ClickHouse/pull/100758) ([Jimmy Aguilar Mena](https://github.com/Ergus)).
* Rétroporté dans [#102430](https://github.com/ClickHouse/ClickHouse/issues/102430) : correction d’une exception s’échappant du destructeur S3 `Client::~Client` et provoquant l’arrêt du serveur. [#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
* Rétroporté dans [#102447](https://github.com/ClickHouse/ClickHouse/issues/102447) : correction de CoalescingMergeTree pour le type Array. Cela clôt [#89509](https://github.com/ClickHouse/ClickHouse/issues/89509). [#102384](https://github.com/ClickHouse/ClickHouse/pull/102384) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Rétroporté dans [#104148](https://github.com/ClickHouse/ClickHouse/issues/104148) : désactivation de l’optimisation triviale de LIMIT avec les row policies/additional&#95;table&#95;filters (pour permettre une analyse d’index en parallèle). [#102921](https://github.com/ClickHouse/ClickHouse/pull/102921) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#104210](https://github.com/ClickHouse/ClickHouse/issues/104210) : les INSERT simples sans vues matérialisées ne demandent plus un nombre excessif de slots et de threads ConcurrencyControl (`max_threads` au lieu de `max_insert_threads`), ce qui évite la famine des slots CC et l’explosion du nombre de threads sur les clusters à fort débit d’INSERT. [#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#104613](https://github.com/ClickHouse/ClickHouse/issues/104613) : correction d’une data race pour les dictionary sources ClickHouse, MySQL, PostgreSQL et XDBC, où `clone() const` lit et `isModified() const` écrit dans la même chaîne `invalidate_query_response`. [#103277](https://github.com/ClickHouse/ClickHouse/pull/103277) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#105212](https://github.com/ClickHouse/ClickHouse/issues/105212) : correction d’un heap-use-after-free lors de la multiplication d’un état `AggregateFunction` par un entier (par exemple `quantilesExactState(...) * N`). La boucle d’exponentiation par dichotomie fusionnait l’état avec lui-même, ce qui est indéfini lorsque le `merge` de la fonction d’agrégation réalloue son stockage interne. Clôt STID 0988-40af. [#103536](https://github.com/ClickHouse/ClickHouse/pull/103536) ([Groene AI](https://github.com/groeneai)).
* Correction de `S3_ERROR: Response checksums mismatch` lors de l’utilisation de GCS sur des disques S3 après la mise à niveau vers 25.8.22 (causé par `aws-sdk-cpp` 1.11.771, qui active par défaut les checksums flexibles CRC32, non pris en charge par GCS). [#103542](https://github.com/ClickHouse/ClickHouse/pull/103542) ([Eugene Klimov](https://github.com/Slach)).
* Rétroporté dans [#103752](https://github.com/ClickHouse/ClickHouse/issues/103752) : correction du masquage des credentials imbriqués dans les journaux. [#103552](https://github.com/ClickHouse/ClickHouse/pull/103552) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#103793](https://github.com/ClickHouse/ClickHouse/issues/103793) : corrige un comportement indéfini lors de l&#39;analyse de `DateTime` avec une partie fractionnaire en double précision. [#103773](https://github.com/ClickHouse/ClickHouse/pull/103773) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Rétroporté dans [#105077](https://github.com/ClickHouse/ClickHouse/issues/105077) : corrige une utilisation après libération dans `StorageKafka2` qui pouvait provoquer un crash du serveur lorsqu&#39;une session Keeper est remplacée alors que le consumer détient des verrous éphémères sur des partitions de topic. [#103890](https://github.com/ClickHouse/ClickHouse/pull/103890) ([Groene AI](https://github.com/groeneai)).
* Rétroporté dans [#104189](https://github.com/ClickHouse/ClickHouse/issues/104189) : corrige une écriture hors limites lors de la désérialisation de l&#39;état `quantileTiming`. [#104141](https://github.com/ClickHouse/ClickHouse/pull/104141) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#104775](https://github.com/ClickHouse/ClickHouse/issues/104775) : corrige un possible sous-dépassement lors de l&#39;analyse de tableaux Postgres. [#104322](https://github.com/ClickHouse/ClickHouse/pull/104322) ([Grant Holly](https://github.com/grantholly-clickhouse)).
* Rétroporté dans [#105234](https://github.com/ClickHouse/ClickHouse/issues/105234) : corrige une boucle d&#39;arrêt et de redémarrage de Keeper lorsque `get /keeper/availability_zone` est envoyé avec `quorum_reads=true` à un Keeper sans `<placement>` configuré. [#104663](https://github.com/ClickHouse/ClickHouse/pull/104663) ([myeongjun](https://github.com/myeongjjun)).
* Rétroporté dans [#104953](https://github.com/ClickHouse/ClickHouse/issues/104953) : corrige une data race de type TOCTOU dans `FutureSetFromTuple::buildOrderedSetInplace` qui entraîne une erreur logique. [#104673](https://github.com/ClickHouse/ClickHouse/pull/104673) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#104842](https://github.com/ClickHouse/ClickHouse/issues/104842) : corrige un segfault dû à un bug d&#39;utilisation après libération dans `AvroConfluentRowInputFormat`. [#104751](https://github.com/ClickHouse/ClickHouse/pull/104751) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
