<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible pour l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#108279](https://github.com/ClickHouse/ClickHouse/issues/108279) : correction d’un possible débordement de pile côté serveur (plantage) lors de la lecture d’un schéma ou d’une valeur très imbriqués dans les formats MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg et Paimon. Ce type d’entrée très imbriquée est désormais rejeté en levant une exception. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#108237](https://github.com/ClickHouse/ClickHouse/issues/108237) : ajout de vérifications de limites manquantes dans l’analyse d’ELF et de DWARF. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#108157](https://github.com/ClickHouse/ClickHouse/issues/108157) : la lecture de données Arrow/ArrowStream avec des colonnes `String`/`Binary` vides produites par Apache Arrow Java &lt; 19.0.0 (y compris Apache Spark) ne renvoie plus `INCORRECT_DATA`. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
