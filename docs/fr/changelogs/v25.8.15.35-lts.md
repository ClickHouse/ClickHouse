* Rétroporté dans [#94146](https://github.com/ClickHouse/ClickHouse/issues/94146) : dans certains cas, nous avons constaté que ClickHouse ne respectait pas la limite de mémoire lors de la lecture d&#39;une table. <div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#93845](https://github.com/ClickHouse/ClickHouse/issues/93845) : corrige la lecture des sous-colonnes d’une colonne dont le nom contient un point, dans certains cas. Résout [#81261](https://github.com/ClickHouse/ClickHouse/issues/81261), [#82058](https://github.com/ClickHouse/ClickHouse/issues/82058), [#88169](https://github.com/ClickHouse/ClickHouse/issues/88169). [#87205](https://github.com/ClickHouse/ClickHouse/pull/87205) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#92032](https://github.com/ClickHouse/ClickHouse/issues/92032) : corrige le crash du moteur GenerateRandom avec des paramètres non littéraux : renvoie BAD&#95;ARGUMENTS avec un message clair au lieu de LOGICAL&#95;ERROR. [#88157](https://github.com/ClickHouse/ClickHouse/pull/88157) ([Shafi Ahmed](https://github.com/ita004)).
* Rétroporté dans [#90417](https://github.com/ClickHouse/ClickHouse/issues/90417) : corrige un crash lors de l’arrêt propre du serveur, dû à un ordre de destruction incorrect. Résout [#82420](https://github.com/ClickHouse/ClickHouse/issues/82420). [#90076](https://github.com/ClickHouse/ClickHouse/pull/90076) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#94010](https://github.com/ClickHouse/ClickHouse/issues/94010) : corrige un crash dû à un dépassement de capacité d’entier dans randomStringUTF8. [#90326](https://github.com/ClickHouse/ClickHouse/pull/90326) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#93719](https://github.com/ClickHouse/ClickHouse/issues/93719) : corrige la résolution des sous-colonnes dynamiques dans les alias de colonnes par l’analyseur. Auparavant, la sous-colonne dynamique dans un alias de colonne était encapsulée dans `getSubcolumn` et, dans certains cas, pouvait ne pas être résolue du tout. Clôt [#91434](https://github.com/ClickHouse/ClickHouse/issues/91434). [#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93952](https://github.com/ClickHouse/ClickHouse/issues/93952) : corrige l’erreur logique ` Failed to set file processing within 100 retries` dans le stockage `S3Queue` en mode `Ordered`. Elle est désormais remplacée par un avertissement. Cette erreur pouvait se produire avant la version 25.10 si la session Keeper expirait ; elle restera toutefois un avertissement dans les versions 25.10+, car il reste théoriquement possible de l’obtenir en cas de forte concurrence de traitement en mode `Ordered`. [#92814](https://github.com/ClickHouse/ClickHouse/pull/92814) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#93590](https://github.com/ClickHouse/ClickHouse/issues/93590) : corrige un possible blocage lors de l’arrêt du background schedule pool (ce qui peut entraîner des blocages du serveur à l’arrêt). [#93008](https://github.com/ClickHouse/ClickHouse/pull/93008) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93557](https://github.com/ClickHouse/ClickHouse/issues/93557) : corrige un crash lors de la désérialisation d’un aggregate state `groupConcat` malformé avec des offsets hors limites. [#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#93400](https://github.com/ClickHouse/ClickHouse/issues/93400) : corrige la suppression des colonnes inutilisées dans les sous-requêtes en présence d’une sous-requête corrélée scalaire. Avant ce correctif, la colonne pouvait être supprimée si elle n’était utilisée que dans la sous-requête corrélée, et la requête échouait avec l’erreur `NOT_FOUND_COLUMN_IN_BLOCK`. [#93273](https://github.com/ClickHouse/ClickHouse/pull/93273) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#93470](https://github.com/ClickHouse/ClickHouse/issues/93470) : correction d’une vulnérabilité de dépassement de capacité d’entier dans la désérialisation de l’état `groupConcat`, qui pouvait provoquer des problèmes de sécurité mémoire avec des états d’agrégation forgés. [#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#93685](https://github.com/ClickHouse/ClickHouse/issues/93685) : s’assure que ZooKeeper est correctement finalisé lors de l’arrêt (corrige un possible blocage à l’arrêt dans des cas très improbables). [#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93951](https://github.com/ClickHouse/ClickHouse/issues/93951) : correction d’un LOGICAL&#95;ERROR lors de la restauration de ReplicatedMergeTree en présence d’une condition de concurrence sur la déduplication. [#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#94147](https://github.com/ClickHouse/ClickHouse/issues/94147) : correction de l’utilisation d’une colonne Sparse pour la mise à jour de TTL lors d’une désérialisation directe dans des colonnes Sparse, dans certains formats d’entrée. Corrige également la possible erreur logique `Unexpected type of result TTL column`. [#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93805](https://github.com/ClickHouse/ClickHouse/issues/93805) : vérifie que la taille du tampon décompressé correspond bien à celle attendue. [#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#93796](https://github.com/ClickHouse/ClickHouse/issues/93796) : empêche les utilisateurs d’obtenir la liste des colonnes d’une table via le table engine `merge` sans vérification de la permission `SHOW COLUMNS`. * Rétroporté dans [#94450](https://github.com/ClickHouse/ClickHouse/issues/94450) : correction d’une utilisation d’une valeur non initialisée dans `ReadWriteBufferFromHTTP`. [#94058](https://github.com/ClickHouse/ClickHouse/pull/94058) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#94230](https://github.com/ClickHouse/ClickHouse/issues/94230) : correction de la précision de `uniqTheta` lors de l’utilisation en parallèle de clés d’agrégation UInt8 (`max_threads` &gt; 1, valeur par défaut).
