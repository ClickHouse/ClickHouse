<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#86063](https://github.com/ClickHouse/ClickHouse/issues/86063) : les vues créées par des utilisateurs éphémères stockeront désormais une copie d&#39;un utilisateur réel et ne seront plus invalidées après la suppression de l&#39;utilisateur éphémère. [#84763](https://github.com/ClickHouse/ClickHouse/pull/84763) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#85728](https://github.com/ClickHouse/ClickHouse/issues/85728) : ajout du flag show&#95;data&#95;lake&#95;catalogs&#95;in&#95;system&#95;tables pour contrôler l&#39;ajout de tables de data lake dans system.tables, ce qui résout [#85384](https://github.com/ClickHouse/ClickHouse/issues/85384). [#85411](https://github.com/ClickHouse/ClickHouse/pull/85411) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#86251](https://github.com/ClickHouse/ClickHouse/issues/86251) : ralentissement des threads du client S3 en cas d&#39;erreurs pouvant donner lieu à un réessai dans le stockage objet S3. Cela étend le paramètre précédent `backup_slow_all_threads_after_retryable_s3_error` aux disques S3 et le renomme en `s3_slow_all_threads_after_retryable_error`, plus générique. [#85918](https://github.com/ClickHouse/ClickHouse/pull/85918) ([Julia Kartseva](https://github.com/jkartseva)).
* Rétroporté dans [#86503](https://github.com/ClickHouse/ClickHouse/issues/86503) : ajout de la possibilité d&#39;activer la journalisation JSON uniquement pour un canal spécifique ; pour cela, définissez `logger.formatting.channel` sur l&#39;une des valeurs `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).
