<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#84033](https://github.com/ClickHouse/ClickHouse/issues/84033) : utiliser les informations issues des cgroups (le cas échéant, c.-à-d. si `memory_worker_use_cgroup` est activé et que les cgroups sont disponibles) pour ajuster le memory tracker (`memory_worker_correct_memory_tracker`). [#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correctif (dysfonctionnement visible par l&#39;utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#83140](https://github.com/ClickHouse/ClickHouse/issues/83140) : ne pas utiliser de parties non liées d&#39;un dictionnaire partagé dans la fonction `lowCardinalityKeys`. [#83118](https://github.com/ClickHouse/ClickHouse/pull/83118) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#84105](https://github.com/ClickHouse/ClickHouse/issues/84105) : masquer les informations d&#39;authentification du registre de schémas Avro afin qu&#39;elles ne soient visibles ni par l&#39;utilisateur ni dans les journaux. [#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#83913](https://github.com/ClickHouse/ClickHouse/issues/83913) : corrige un problème où, si une table MergeTree est créée avec `add_minmax_index_for_numeric_columns=1` ou `add_minmax_index_for_string_columns=1`, l&#39;index est ensuite matérialisé lors d&#39;une opération ALTER, ce qui empêche la base de données Replicated de s&#39;initialiser correctement sur une nouvelle réplique. [#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#83872](https://github.com/ClickHouse/ClickHouse/issues/83872) : ajoute un paramètre de rétrocompatibilité pour permettre au nouvel analyseur de référencer un alias externe dans la clause WITH en cas de conflit de noms. Corrige [#82700](https://github.com/ClickHouse/ClickHouse/issues/82700). [#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#84090](https://github.com/ClickHouse/ClickHouse/issues/84090) : lors d&#39;une restauration à partir d&#39;une sauvegarde, il est possible que l&#39;utilisateur DEFINER ne soit pas sauvegardé, ce qui rend l&#39;ensemble de la sauvegarde inutilisable. Pour corriger cela, nous reportons la vérification des permissions lors de la création de la table cible pendant la restauration et ne l&#39;effectuons qu&#39;à l&#39;exécution. [#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#84268](https://github.com/ClickHouse/ClickHouse/issues/84268) : corrige des résultats erronés lorsque le cache des conditions de requête est utilisé avec des CTE récursifs (problème [#81506](https://github.com/ClickHouse/ClickHouse/issues/81506)). [#84026](https://github.com/ClickHouse/ClickHouse/pull/84026) ([zhongyuankai](https://github.com/zhongyuankai)).
