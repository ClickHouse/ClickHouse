Clôt [#101700](https://github.com/ClickHouse/ClickHouse/issues/101700). [#101918](https://github.com/ClickHouse/ClickHouse/pull/101918) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#102352](https://github.com/ClickHouse/ClickHouse/issues/102352) : corrige un SIGSEGV dans `MergeTreeDataPartWriterWide::cancel` lorsqu’un constructeur de flux lève une exception pendant `addStreams`, laissant une entrée nulle dans `column_streams`. [#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#102968](https://github.com/ClickHouse/ClickHouse/issues/102968) : corrige une inférence erronée du type de données Date en cas d’overflow après ajustement du fuseau horaire. Clôt [#102601](https://github.com/ClickHouse/ClickHouse/issues/102601). [#102674](https://github.com/ClickHouse/ClickHouse/pull/102674) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#103300](https://github.com/ClickHouse/ClickHouse/issues/103300) : corrige la sérialisation aplatie du type Dynamic avec des data types encodés en binaire. Clôt [#101911](https://github.com/ClickHouse/ClickHouse/issues/101911). [#102692](https://github.com/ClickHouse/ClickHouse/pull/102692) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#103018](https://github.com/ClickHouse/ClickHouse/issues/103018) : optimise les chaînes de OR de row policy en IN dans le nouvel analyseur. [#102915](https://github.com/ClickHouse/ClickHouse/pull/102915) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#103663](https://github.com/ClickHouse/ClickHouse/issues/103663) : corrige les statistiques min&#95;value &gt; max&#95;value de ColumnIndex dans Parquet pour les colonne de type String. [#103334](https://github.com/ClickHouse/ClickHouse/pull/103334) ([Saurabh Kumar Ojha](https://github.com/saurabhojha)).
