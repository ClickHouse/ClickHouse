<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#92409](https://github.com/ClickHouse/ClickHouse/issues/92409) : correction de l&#39;erreur `Bad get` qui se produisait lors de l&#39;analyse de l&#39;index `Set` lorsque le prédicat contenait la constante `NULL`. Corrige [#84856](https://github.com/ClickHouse/ClickHouse/issues/84856) et [#82974](https://github.com/ClickHouse/ClickHouse/issues/82974). [#89429](https://github.com/ClickHouse/ClickHouse/pull/89429) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#94969](https://github.com/ClickHouse/ClickHouse/issues/94969) : la création d&#39;une charge de travail au sein d&#39;une autre charge de travail déjà utilisée ne provoque plus de plantage. [#94599](https://github.com/ClickHouse/ClickHouse/pull/94599) ([Sergei Trifonov](https://github.com/serxa)).
* Rétroporté dans [#96287](https://github.com/ClickHouse/ClickHouse/issues/96287) : correction d&#39;une collision de hachage dans le cache des conditions de requête pour les constantes de CTE repliées, ce qui pouvait entraîner un résultat de la requête incorrect. Ferme [#96060](https://github.com/ClickHouse/ClickHouse/issues/96060). [#96172](https://github.com/ClickHouse/ClickHouse/pull/96172) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#102653](https://github.com/ClickHouse/ClickHouse/issues/102653) : correction de l&#39;exception LOGICAL&#95;ERROR dans `ASTColumnsExceptTransformer::transform`. [#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#100487](https://github.com/ClickHouse/ClickHouse/issues/100487) : les informations d’authentification dans les chaînes de connexion JDBC, ODBC et NATS sont désormais masquées dans les journaux de requêtes et dans la sortie de `SHOW CREATE`, afin d’éviter toute divulgation accidentelle d’informations sensibles. Pour les chaînes de connexion au format URI (par ex. {scheme}://{user}:{password}@{host}), seule la partie correspondant au mot de passe est masquée, tandis que le reste demeure visible pour faciliter le débogage. Le paramètre `nats_token` est désormais lui aussi masqué. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#101470](https://github.com/ClickHouse/ClickHouse/issues/101470) : correction d’un bug dans Keeper où une requête de lecture pouvait rester bloquée (entraînant l’expiration de la session) si une autre session non liée sur le même serveur était fermée au pire moment. [#99484](https://github.com/ClickHouse/ClickHouse/pull/99484) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#99963](https://github.com/ClickHouse/ClickHouse/issues/99963) : correction d’une dégradation des performances dans l’analyseur. Suppression des colonnes inutilisées dans ARRAY JOIN. [#99587](https://github.com/ClickHouse/ClickHouse/pull/99587) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#100338](https://github.com/ClickHouse/ClickHouse/issues/100338) : correction d’une exception `LOGICAL_ERROR` dans des requêtes impliquant des colonnes `Dynamic` avec des jointures croisées et des runtime filters, due au fait que `ColumnVariant::filter` partageait des pointeurs vers des colonnes Variant au lieu de les cloner dans le chemin d’optimisation `hasOnlyNulls`. Ferme [https://github.com/ClickHouse/ClickHouse/pull/100147](https://github.com/ClickHouse/ClickHouse/pull/100147). [#100234](https://github.com/ClickHouse/ClickHouse/pull/100234) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#100885](https://github.com/ClickHouse/ClickHouse/issues/100885) : validation des chemins des entrées de fichiers dans les métadonnées de sauvegarde afin de rejeter les traversées de chemin, les chemins absolus et les noms vides pendant `RESTORE`. [#100483](https://github.com/ClickHouse/ClickHouse/pull/100483) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#100916](https://github.com/ClickHouse/ClickHouse/issues/100916) : correction d’un plantage du serveur lors de l’utilisation de la fonction `has()` avec PREWHERE/WHERE sur une clé Tuple contenant des éléments LowCardinality. [#100760](https://github.com/ClickHouse/ClickHouse/pull/100760) ([Groene AI](https://github.com/groeneai)).
* Rétroporté dans [#101528](https://github.com/ClickHouse/ClickHouse/issues/101528) : certains catalogues peuvent afficher des secrets dans la section `SETTINGS` du résultat de la requête `select * from system.databases`. Cette PR empêche ce comportement. [#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Rétroporté dans [#102619](https://github.com/ClickHouse/ClickHouse/issues/102619) : correction d’un segfault dans s3Cluster et les requêtes distribuées dû à un use-after-free dans le pool de connexions. [#100837](https://github.com/ClickHouse/ClickHouse/pull/100837) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#101085](https://github.com/ClickHouse/ClickHouse/issues/101085) : correction d’un débordement de tampon dans `ULIDStringToDateTime` lorsque l’entrée contient des octets non ASCII. [#100843](https://github.com/ClickHouse/ClickHouse/pull/100843) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#101926](https://github.com/ClickHouse/ClickHouse/issues/101926) : correction d’un comportement indéfini (dépassement d’entier signé) dans parseDateTimeBestEffort lors de l’analyse de chaînes de date/heure avec plus de 18 chiffres de seconde fractionnaire. [#100948](https://github.com/ClickHouse/ClickHouse/pull/100948) ([Vasily Chekalkin](https://github.com/bacek)).
* Rétroporté dans [#102675](https://github.com/ClickHouse/ClickHouse/issues/102675) : correction d’un plantage dû à un use-after-free dans le scheduler des baux CPU lorsque le minuteur d’attente survit au worker thread dont il référence les `ProfileEvents::Counters`. [#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#102069](https://github.com/ClickHouse/ClickHouse/issues/102069) : correction d’un use-after-scope dans la désérialisation en parallèle des chemins dynamiques du type `Object`, qui pouvait provoquer des plantages lors de la lecture de tables contenant de nombreux chemins dynamiques. [#101823](https://github.com/ClickHouse/ClickHouse/pull/101823) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#102096](https://github.com/ClickHouse/ClickHouse/issues/102096) : correction d&#39;un résultat incorrect dans la fonction `formatDateTime` avec le formatter `%W` sous certains paramètres de formatage non par défaut. [#101847](https://github.com/ClickHouse/ClickHouse/pull/101847) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#102741](https://github.com/ClickHouse/ClickHouse/issues/102741) : correction du blocage permanent de `SYSTEM WAIT VIEW` lorsque la vue matérialisée actualisable est supprimée pendant l&#39;attente. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
