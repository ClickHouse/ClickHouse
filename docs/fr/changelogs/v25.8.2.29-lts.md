<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#86620](https://github.com/ClickHouse/ClickHouse/issues/86620) : ajout de la table système `iceberg_metadata_log` pour récupérer les fichiers de métadonnées Iceberg lors des instructions SELECT. [#86152](https://github.com/ClickHouse/ClickHouse/pull/86152) ([Konstantin Vedernikov](https://github.com/scanhex12)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#86333](https://github.com/ClickHouse/ClickHouse/issues/86333) : ajout de `allow_experimental_delta_lake_writes`. [#86180](https://github.com/ClickHouse/ClickHouse/pull/86180) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#86493](https://github.com/ClickHouse/ClickHouse/issues/86493) : ajout de la possibilité d’activer la journalisation JSON uniquement pour un canal spécifique ; pour cela, définissez `logger.formatting.channel` sur l’une des valeurs suivantes : `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#86614](https://github.com/ClickHouse/ClickHouse/issues/86614) : arrêter correctement les tables lors de la récupération d’une replica de base de données. Un arrêt incorrect provoquait `LOGICAL_ERROR` pour certains moteurs de table pendant la récupération de la replica de base de données. [#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#86386](https://github.com/ClickHouse/ClickHouse/issues/86386) : traiter par défaut les inclusions depuis `/etc/metrika.xml` lors de la création de disques via SQL. [#86232](https://github.com/ClickHouse/ClickHouse/pull/86232) ([alekar](https://github.com/alekar)).
* Rétroporté dans [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653) : corrige `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` lors de la lecture de blobs vides depuis Azure blob storage pour le disque plain&#95;rewritable. [#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* Rétroporté dans [#86457](https://github.com/ClickHouse/ClickHouse/issues/86457) : correction d’un bug dans les vues matérialisées : une MV pouvait ne pas fonctionner si elle avait été créée, supprimée, puis recréée avec le même nom. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#86468](https://github.com/ClickHouse/ClickHouse/issues/86468) : correction d’une fuite de `MergesMutationsMemoryTracking` due aux tables `Buffer`, et correction de `query_views_log` pour le streaming depuis `Kafka` (et d’autres sources). [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#86549](https://github.com/ClickHouse/ClickHouse/issues/86549) : corrige l’utilisation de mémoire non initialisée dans getSubcolumnType. [#86498](https://github.com/ClickHouse/ClickHouse/pull/86498) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#86582](https://github.com/ClickHouse/ClickHouse/issues/86582) : ignorer les exceptions lors du flush du journal à l’arrêt et rendre l’arrêt plus sûr (pour éviter un SIGSEGV). [#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
