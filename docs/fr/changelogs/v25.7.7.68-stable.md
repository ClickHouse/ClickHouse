* Rétroporté dans [#86825](https://github.com/ClickHouse/ClickHouse/issues/86825) : amélioration des performances de la requête RemoveRecursive dans Keeper. [#86789](https://github.com/ClickHouse/ClickHouse/pull/86789) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (anomalie visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#86058](https://github.com/ClickHouse/ClickHouse/issues/86058) : correction d’un crash du serveur lorsqu’un utilisateur créé avec `no_password` tente de se connecter après que le paramètre serveur `allow_no_password` a été défini sur 0. [#84426](https://github.com/ClickHouse/ClickHouse/pull/84426) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Rétroporté dans [#86612](https://github.com/ClickHouse/ClickHouse/issues/86612) : arrêt correct des tables lors de la récupération d’une réplique de base de données. Un arrêt incorrect provoquait LOGICAL&#95;ERROR pour certains moteurs de table pendant la récupération de la réplique de base de données. [#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#86520](https://github.com/ClickHouse/ClickHouse/issues/86520) : correction d’un segfault dans l’implémentation de delta-kernel. [#85160](https://github.com/ClickHouse/ClickHouse/pull/85160) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#85255](https://github.com/ClickHouse/ClickHouse/issues/85255) : correction de la lecture des données partitionnées lorsque delta-kernel est désactivé dans le moteur `DeltaLake`. Ce comportement était défaillant dans la version 25.7 ([https://github.com/ClickHouse/ClickHouse/pull/81136](https://github.com/ClickHouse/ClickHouse/pull/81136)). [#85223](https://github.com/ClickHouse/ClickHouse/pull/85223) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#85652](https://github.com/ClickHouse/ClickHouse/issues/85652) : les paramètres comme `date_time_input_format` étaient tout simplement ignorés avec HTTP multipart. [#85570](https://github.com/ClickHouse/ClickHouse/pull/85570) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#87157](https://github.com/ClickHouse/ClickHouse/issues/87157) : ajout d’une vérification pour n’autoriser les sous-requêtes corrélées dans la clause FROM que si elles utilisent des colonnes de la requête externe. Corrige [#85469](https://github.com/ClickHouse/ClickHouse/issues/85469). Corrige [#85402](https://github.com/ClickHouse/ClickHouse/issues/85402). [#85966](https://github.com/ClickHouse/ClickHouse/pull/85966) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#86955](https://github.com/ClickHouse/ClickHouse/issues/86955) : correction d’un ALTER UPDATE sur une colonne avec une sous-colonne utilisée dans l’expression matérialisée d’une autre colonne. Auparavant, une colonne matérialisée avec une sous-colonne dans son expression n’était pas mise à jour correctement. [#85985](https://github.com/ClickHouse/ClickHouse/pull/85985) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86693](https://github.com/ClickHouse/ClickHouse/issues/86693) : interdiction de modifier des colonnes dont les sous-colonnes sont utilisées dans la PK ou dans une expression de partitionnement. [#86005](https://github.com/ClickHouse/ClickHouse/pull/86005) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86199](https://github.com/ClickHouse/ClickHouse/issues/86199) : correction de l’utilisation de mauvaises valeurs par défaut pour un chemin avec annotation Enum dans JSON. [#86065](https://github.com/ClickHouse/ClickHouse/pull/86065) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86518](https://github.com/ClickHouse/ClickHouse/issues/86518) : correction d’une erreur logique lors du redimensionnement dynamique du cache du système de fichiers. Ferme [#86122](https://github.com/ClickHouse/ClickHouse/issues/86122). Ferme [https://github.com/ClickHouse/clickhouse-core-incidents/issues/473](https://github.com/ClickHouse/clickhouse-core-incidents/issues/473). [#86130](https://github.com/ClickHouse/ClickHouse/pull/86130) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#86947](https://github.com/ClickHouse/ClickHouse/issues/86947) : correction de la conversion de LowCardinality(Nullable(T)) vers Dynamic. [#86365](https://github.com/ClickHouse/ClickHouse/pull/86365) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86878](https://github.com/ClickHouse/ClickHouse/issues/86878) : correction de GROUP BY Nullable(JSON). [#86410](https://github.com/ClickHouse/ClickHouse/pull/86410) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86580](https://github.com/ClickHouse/ClickHouse/issues/86580) : ignorer les exceptions lors du vidage du journal à l’arrêt et rendre l’arrêt plus sûr (pour éviter un SIGSEGV). [#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#86891](https://github.com/ClickHouse/ClickHouse/issues/86891) : correction de l’en-tête de chunk manquant lorsque send&#95;chunk&#95;header est activé et qu’une UDF est invoquée via le protocole HTTP. [#86606](https://github.com/ClickHouse/ClickHouse/pull/86606) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Rétroporté dans [#86872](https://github.com/ClickHouse/ClickHouse/issues/86872) : corrige l’erreur logique S3Queue &quot;Expected current processor {} to be equal to {}&quot;, qui survenait en raison de l’expiration de la session Keeper. [#86615](https://github.com/ClickHouse/ClickHouse/pull/86615) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#87057](https://github.com/ClickHouse/ClickHouse/issues/87057) : correction de l’écriture de `NULL` dans les données partagées JSON au format d’entrée RowBinary, avec ajout de validations supplémentaires dans ColumnObject. [#86812](https://github.com/ClickHouse/ClickHouse/pull/86812) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86977](https://github.com/ClickHouse/ClickHouse/issues/86977) : correction d’une table du moteur TimeSeries qui empêchait la création d’une nouvelle réplique dans une base de données Replicated. [#86845](https://github.com/ClickHouse/ClickHouse/pull/86845) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#86861](https://github.com/ClickHouse/ClickHouse/issues/86861) : correction de la requête sur `system.distributed_ddl_queue` dans les cas où certaines tâches n’ont pas certains nœuds Keeper. [#86848](https://github.com/ClickHouse/ClickHouse/pull/86848) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#87054](https://github.com/ClickHouse/ClickHouse/issues/87054) : correction du repositionnement en lecture à la fin du bloc décompressé. [#86906](https://github.com/ClickHouse/ClickHouse/pull/86906) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#87191](https://github.com/ClickHouse/ClickHouse/issues/87191) : correction d’un résultat potentiellement incorrect de la fonction `uniqExact` avec les modificateurs `ROLLUP` et `CUBE`. [#87014](https://github.com/ClickHouse/ClickHouse/pull/87014) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#87070](https://github.com/ClickHouse/ClickHouse/issues/87070) : transtypage correct de la sortie de PREWHERE après sa division en plusieurs étapes. [#87040](https://github.com/ClickHouse/ClickHouse/pull/87040) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#87416](https://github.com/ClickHouse/ClickHouse/issues/87416) : EmbeddedRocksDB : le chemin doit se trouver dans user&#95;files. [#87109](https://github.com/ClickHouse/ClickHouse/pull/87109) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#87311](https://github.com/ClickHouse/ClickHouse/issues/87311) : correction des tables KeeperMap créées avant la version 25.1, qui laissaient des données dans ZooKeeper après la requête `DROP`. [#87112](https://github.com/ClickHouse/ClickHouse/pull/87112) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#87393](https://github.com/ClickHouse/ClickHouse/issues/87393) : correction d’une possible comptabilisation incorrecte des désallocations de données temporaires lors du suivi de la limite `max_temporary_data_on_disk_size`, ferme [#87118](https://github.com/ClickHouse/ClickHouse/issues/87118). [#87140](https://github.com/ClickHouse/ClickHouse/pull/87140) ([JIaQi](https://github.com/JiaQiTang98)).
* Rétroporté dans [#87435](https://github.com/ClickHouse/ClickHouse/issues/87435) : correction de l’erreur `LOGICAL_ERROR` &quot;Too large size passed to allocator&quot; dans `JOIN`, due à un mélange de blocs const et non const. [#87231](https://github.com/ClickHouse/ClickHouse/pull/87231) ([Azat Khuzhin](https://github.com/azat)).
