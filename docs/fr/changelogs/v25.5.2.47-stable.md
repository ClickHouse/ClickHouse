<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction d’anomalie (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#80963](https://github.com/ClickHouse/ClickHouse/issues/80963) : désactive le push-down de filtre pour le prédicat contenant une fonction non déterministe lorsque l’étape du plan de requête modifie le nombre de lignes. Corrige [#40273](https://github.com/ClickHouse/ClickHouse/issues/40273). [#80329](https://github.com/ClickHouse/ClickHouse/pull/80329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#81038](https://github.com/ClickHouse/ClickHouse/issues/81038) : le timestamp dans la table iceberg&#95;history devrait désormais être correct. [#80711](https://github.com/ClickHouse/ClickHouse/pull/80711) ([Melvyn Peignon](https://github.com/melvynator)).
* Rétroporté dans [#80755](https://github.com/ClickHouse/ClickHouse/issues/80755) : corrige un crash possible en cas d’échec de l’enregistrement d’un dictionnaire (lorsque `CREATE DICTIONARY` échouait avec `CANNOT_SCHEDULE_TASK`, il était possible de laisser un pointeur suspendu dans le registre des dictionnaires, ce qui entraînait ensuite un crash). [#80714](https://github.com/ClickHouse/ClickHouse/pull/80714) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#81143](https://github.com/ClickHouse/ClickHouse/issues/81143) : corrige le type de résultat incorrect des fonctions de comparaison avec Tuple(Dynamic) et String, qui entraînait une erreur logique. [#80728](https://github.com/ClickHouse/ClickHouse/pull/80728) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#80901](https://github.com/ClickHouse/ClickHouse/issues/80901) : corrige l’erreur `THERE_IS_NO_COLUMN` pour les requêtes distribuées avec `IN cte`. Corrige [#75032](https://github.com/ClickHouse/ClickHouse/issues/75032). [#80757](https://github.com/ClickHouse/ClickHouse/pull/80757) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#80955](https://github.com/ClickHouse/ClickHouse/issues/80955) : corrige le nombre excessif de fichiers (entraînant une utilisation mémoire excessive) pour les ORDER BY externes. [#80777](https://github.com/ClickHouse/ClickHouse/pull/80777) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#80872](https://github.com/ClickHouse/ClickHouse/issues/80872) : corrige un crash dans Kafka dû au fait que get&#95;member&#95;id() créait un std::string à partir de NULL (il s’agissait probablement d’un problème survenant uniquement lorsque la connexion au broker avait échoué). [#80793](https://github.com/ClickHouse/ClickHouse/pull/80793) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#80912](https://github.com/ClickHouse/ClickHouse/issues/80912) : attend correctement les consumers avant l’arrêt du moteur Kafka (des consumers encore actifs après l’arrêt peuvent déclencher diverses assertions de débogage et peuvent également lire des données depuis les brokers en arrière-plan après qu’une table a été supprimée/détachée). [#80795](https://github.com/ClickHouse/ClickHouse/pull/80795) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#80936](https://github.com/ClickHouse/ClickHouse/issues/80936) : corrige la comptabilisation mémoire du cache des fichiers de métadonnées Iceberg. [#80904](https://github.com/ClickHouse/ClickHouse/pull/80904) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#81061](https://github.com/ClickHouse/ClickHouse/issues/81061) : corrige un partitionnement incorrect avec une clé de partition Nullable. [#80913](https://github.com/ClickHouse/ClickHouse/pull/80913) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Rétroporté dans [#81099](https://github.com/ClickHouse/ClickHouse/issues/81099) : corrige l’erreur logique dans les fonctions imbriquées avec des fenêtres nommées. [#80926](https://github.com/ClickHouse/ClickHouse/pull/80926) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Rétroporté dans [#81003](https://github.com/ClickHouse/ClickHouse/issues/81003) : correction des valeurs extrêmes pour les colonnes Nullable et à virgule flottante. [#80970](https://github.com/ClickHouse/ClickHouse/pull/80970) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
* Rétroporté dans [#80987](https://github.com/ClickHouse/ClickHouse/issues/80987) : correction d’un crash possible lors des requêtes sur system.tables (probablement en cas de forte pression mémoire). [#80976](https://github.com/ClickHouse/ClickHouse/pull/80976) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#81010](https://github.com/ClickHouse/ClickHouse/issues/81010) : correction du renommage atomique avec TRUNCATE pour les fichiers dont la compression est déduite de leur extension. [#80979](https://github.com/ClickHouse/ClickHouse/pull/80979) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#81081](https://github.com/ClickHouse/ClickHouse/issues/81081) : désormais, ClickHouse ignorera les erreurs et les réponses inattendues des catalogues de data lake dans la requête `SHOW TABLES`. Corrige [#79725](https://github.com/ClickHouse/ClickHouse/issues/79725). [#81046](https://github.com/ClickHouse/ClickHouse/pull/81046) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#81155](https://github.com/ClickHouse/ClickHouse/issues/81155) : prise en compte du paramètre date&#95;time&#95;input&#95;format dans le cache d’inférence de schéma. [#81052](https://github.com/ClickHouse/ClickHouse/pull/81052) ([Pavel Kruglov](https://github.com/Avogar)).
