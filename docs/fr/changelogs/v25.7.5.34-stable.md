<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#85759](https://github.com/ClickHouse/ClickHouse/issues/85759) : correction d’un problème où le writer Parquet produisait des statistiques incorrectes (min/max) pour les types Decimal. [#83754](https://github.com/ClickHouse/ClickHouse/pull/83754) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#85796](https://github.com/ClickHouse/ClickHouse/issues/85796) : correction de l’écriture des JSON paths avec des valeurs NULL au format RowBinary. [#83923](https://github.com/ClickHouse/ClickHouse/pull/83923) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#85883](https://github.com/ClickHouse/ClickHouse/issues/85883) : correction de la lecture d’une Variant column avec matérialisation différée. [#84400](https://github.com/ClickHouse/ClickHouse/pull/84400) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#85778](https://github.com/ClickHouse/ClickHouse/issues/85778) : correction d’une condition de concurrence dans l’implémentation delta-kernel du moteur `DeltaLake`. [#85221](https://github.com/ClickHouse/ClickHouse/pull/85221) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#85620](https://github.com/ClickHouse/ClickHouse/issues/85620) : les requêtes avec des répliques parallèles utilisant l’optimisation de lecture inversée dans l’ordre peuvent produire un résultat incorrect. [#85406](https://github.com/ClickHouse/ClickHouse/pull/85406) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#85697](https://github.com/ClickHouse/ClickHouse/issues/85697) : correction d’un UB potentiel (plantages) en cas de MEMORY&#95;LIMIT&#95;EXCEEDED lors de la désérialisation de String. [#85440](https://github.com/ClickHouse/ClickHouse/pull/85440) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#85826](https://github.com/ClickHouse/ClickHouse/issues/85826) : correction de métriques incorrectes, KafkaAssignedPartitions et KafkaConsumersWithAssignment. [#85494](https://github.com/ClickHouse/ClickHouse/pull/85494) ([Ilya Golshtein](https://github.com/ilejn)).
* Rétroporté dans [#85916](https://github.com/ClickHouse/ClickHouse/issues/85916) : correction du masquage des secrets dans les fonctions de table icebergS3Cluster et icebergAzureCluster. [#85658](https://github.com/ClickHouse/ClickHouse/pull/85658) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Rétroporté dans [#85871](https://github.com/ClickHouse/ClickHouse/issues/85871) : correction d’un segfault dans coalescing merge tree pour les grandes chaînes. Cela clôt [#84582](https://github.com/ClickHouse/ClickHouse/issues/84582). [#85709](https://github.com/ClickHouse/ClickHouse/pull/85709) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Rétroporté dans [#85854](https://github.com/ClickHouse/ClickHouse/issues/85854) : correction d’une possible incohérence pour les Dictionaries avec `update_field` lors d’erreurs MEMORY&#95;LIMIT&#95;EXCEEDED. [#85807](https://github.com/ClickHouse/ClickHouse/pull/85807) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#85993](https://github.com/ClickHouse/ClickHouse/issues/85993) : prise en charge des constantes globales de l’instruction `WITH` pour `INSERT SELECT` parallèle distribué avec la destination table `Distributed`. Auparavant, la requête pouvait renvoyer une erreur `Unknown expression identifier`. [#85811](https://github.com/ClickHouse/ClickHouse/pull/85811) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#86041](https://github.com/ClickHouse/ClickHouse/issues/86041) : correction d’un bug dans la recovery de la database `Replicated` : si un nom de table contenait le symbole `%`, la table pouvait être recréée avec un nom différent lors de la récupération. [#85987](https://github.com/ClickHouse/ClickHouse/pull/85987) ([Alexander Tokmakov](https://github.com/tavplubix)).
