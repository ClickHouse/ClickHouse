* Rétroporté dans [#102752](https://github.com/ClickHouse/ClickHouse/issues/102752) : corrige l’augmentation artificielle de la CurrentMetric de `NamedCollection` provoquée par `CREATE NAMED COLLECTION IF NOT EXISTS` sur des collections existantes, ainsi que l’absence d’initialisation pour les collections chargées depuis la configuration ou le stockage SQL au démarrage. Clôt [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507). [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#102746](https://github.com/ClickHouse/ClickHouse/issues/102746) : corrige le cas où `SYSTEM WAIT VIEW` restait bloqué indéfiniment lorsque la vue matérialisée actualisable est supprimée pendant l’attente. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
