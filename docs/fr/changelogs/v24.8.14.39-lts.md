<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#75642](https://github.com/ClickHouse/ClickHouse/issues/75642) : correction du message de log d’échec du script d’initialisation Docker pour le rendre plus clair. [#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* Rétroporté dans [#75118](https://github.com/ClickHouse/ClickHouse/issues/75118) : correction d’un crash lors de l’insertion d’un intervalle (issue [#74299](https://github.com/ClickHouse/ClickHouse/issues/74299)). [#74478](https://github.com/ClickHouse/ClickHouse/pull/74478) ([NamHoaiNguyen](https://github.com/NamHoaiNguyen)).
* Rétroporté dans [#75305](https://github.com/ClickHouse/ClickHouse/issues/75305) : correction d’un crash pendant l’analyse de la déclaration du type JSON lorsque le nom du type n’est pas en majuscules. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#76228](https://github.com/ClickHouse/ClickHouse/issues/76228) : correction d’un crash dû à une exception non gérée dans la réplication PSQL. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#76245](https://github.com/ClickHouse/ClickHouse/issues/76245) : Sasl peut faire échouer n’importe quel appel RPC ; ce correctif permet de relancer l’appel si le ticker krb5 a expiré. [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* Rétroporté dans [#75403](https://github.com/ClickHouse/ClickHouse/issues/75403) : correction de l’utilisation des index (primaires et secondaires) pour les colonnes `Array`, `Map` et `Nullable(..)` lorsque le paramètre `optimize_function_to_subcolumns` est activé. Auparavant, les index de ces colonnes pouvaient être ignorés. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#76102](https://github.com/ClickHouse/ClickHouse/issues/76102) : correction de la gestion des JOIN avec comparaison null-safe pour le type de données nullable LowCardinality. Auparavant, JOIN ON avec une comparaison null-safe, telle que `IS NOT DISTINCT FROM`, `<=>` , `a IS NULL AND b IS NULL OR a == b`, ne fonctionnait pas correctement avec les colonnes LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Rétroporté dans [#75566](https://github.com/ClickHouse/ClickHouse/issues/75566) : correctif Keeper : évite d’écrire dans des changelogs corrompus lors du retour en arrière des logs. [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#75742](https://github.com/ClickHouse/ClickHouse/issues/75742) : correction d’un crash dans le cache de schéma Protobuf pouvant survenir lors d’une sortie au format Protobuf et de l’exécution parallèle de la requête `SYSTEM DROP FORMAT SCHEMA CACHE`. [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#76094](https://github.com/ClickHouse/ClickHouse/issues/76094) : correction de l’erreur possible `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes` lorsque des sous-colonnes JSON de type Array sont utilisées dans un JOIN sur des tables distribuées. [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#75890](https://github.com/ClickHouse/ClickHouse/issues/75890) : correction de rares crashes lors de la lecture d’une table `MergeTree` après plusieurs requêtes `RENAME` asynchrones (avec `alter_sync = 0`) entre des colonnes de types différents. [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#75831](https://github.com/ClickHouse/ClickHouse/issues/75831) : correction d’un déréférencement de pointeur nul dans `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#76215](https://github.com/ClickHouse/ClickHouse/issues/76215) : `clickhouse-library-bridge` permet d’ouvrir des bibliothèques arbitraires depuis le système de fichiers, ce qui signifie qu’il ne peut être exécuté en toute sécurité que dans un environnement isolé. Pour éviter une vulnérabilité lorsqu’il est exécuté à proximité de clickhouse-server, nous limiterons les chemins des bibliothèques à un emplacement défini dans la configuration. Cette vulnérabilité a été découverte dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par **Arseniy Dugin**. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
