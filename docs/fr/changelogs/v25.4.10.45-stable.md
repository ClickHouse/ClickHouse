* Rétroporté dans [#83339](https://github.com/ClickHouse/ClickHouse/issues/83339) : tentative d’accélérer légèrement QueryTreeHash. [#82617](https://github.com/ClickHouse/ClickHouse/pull/82617) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#83013](https://github.com/ClickHouse/ClickHouse/issues/83013) : amélioration de Keeper : déplacement des fichiers de changelog entre les disques dans un thread en arrière-plan. Auparavant, le déplacement du changelog vers un autre disque bloquait Keeper dans son ensemble jusqu&#39;à la fin de l&#39;opération. Cela entraînait une dégradation des performances lorsque le déplacement prenait longtemps (par ex. vers un disque S3). [#82485](https://github.com/ClickHouse/ClickHouse/pull/82485) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#83203](https://github.com/ClickHouse/ClickHouse/issues/83203) : `SYSTEM RESTART REPLICA` peut échouer en raison de problèmes de connexion à ZooKeeper. Pour éviter que cette table ne soit oubliée, nous réessayons désormais jusqu&#39;à ce qu&#39;elle soit créée. [#82616](https://github.com/ClickHouse/ClickHouse/pull/82616) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#83180](https://github.com/ClickHouse/ClickHouse/issues/83180) : regroupement des avertissements concernant les paramètres inconnus dans clickhouse client et consignation sous forme de résumé. [#83042](https://github.com/ClickHouse/ClickHouse/pull/83042) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#83315](https://github.com/ClickHouse/ClickHouse/issues/83315) : corrige « Context has expired » pour Iceberg. [#82146](https://github.com/ClickHouse/ClickHouse/pull/82146) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#83255](https://github.com/ClickHouse/ClickHouse/issues/83255) : corrige la désactivation de l’alignement sur les limites pour le buffer mis en cache dans les moteurs de tables externes. Cela a été cassé dans [https://github.com/ClickHouse/ClickHouse/pull/81868](https://github.com/ClickHouse/ClickHouse/pull/81868). [#82493](https://github.com/ClickHouse/ClickHouse/pull/82493) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#82911](https://github.com/ClickHouse/ClickHouse/issues/82911) : dans AzureBlobStorage, pour la copie native, nous comparons les méthodes d’authentification. Si une exception survient pendant cette opération, le code a été mis à jour pour revenir à une lecture puis une copie (c.-à-d. une copie non native). [#82693](https://github.com/ClickHouse/ClickHouse/pull/82693) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#83110](https://github.com/ClickHouse/ClickHouse/issues/83110) : corrige la robustesse face aux exceptions dans la réécriture de union/intersect/except&#95;default&#95;mode. Ferme [#82664](https://github.com/ClickHouse/ClickHouse/issues/82664). [#82820](https://github.com/ClickHouse/ClickHouse/pull/82820) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#83328](https://github.com/ClickHouse/ClickHouse/issues/83328) : corrige les accès concurrents aux données dans Iceberg. [#82841](https://github.com/ClickHouse/ClickHouse/pull/82841) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#83287](https://github.com/ClickHouse/ClickHouse/issues/83287) : définit le sel des données d’authentification lors de l’analyse depuis l’AST avec le type SCRAM&#95;SHA256&#95;PASSWORD. [#82888](https://github.com/ClickHouse/ClickHouse/pull/82888) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Rétroporté dans [#83025](https://github.com/ClickHouse/ClickHouse/issues/83025) : corrige la modification du filtre pour les requêtes avec une expression JOIN sur une table utilisant le stockage `Merge`. Corrige [#82092](https://github.com/ClickHouse/ClickHouse/issues/82092). [#82950](https://github.com/ClickHouse/ClickHouse/pull/82950) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#83309](https://github.com/ClickHouse/ClickHouse/issues/83309) : corrige LOGICAL&#95;ERROR dans QueryMetricLog : Mutex cannot be NULL. [#82979](https://github.com/ClickHouse/ClickHouse/pull/82979) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#83238](https://github.com/ClickHouse/ClickHouse/issues/83238) : corrige la dégradation des performances avec l’analyseur activé lorsque les requêtes secondaires lisent systématiquement toutes les colonnes des VIEWs. Corrige [#81718](https://github.com/ClickHouse/ClickHouse/issues/81718). [#83036](https://github.com/ClickHouse/ClickHouse/pull/83036) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#83428](https://github.com/ClickHouse/ClickHouse/issues/83428) : corrige un message d’erreur trompeur lors de la restauration d’une sauvegarde sur un disque en lecture seule. [#83051](https://github.com/ClickHouse/ClickHouse/pull/83051) ([Julia Kartseva](https://github.com/jkartseva)).
* Rétroporté dans [#83197](https://github.com/ClickHouse/ClickHouse/issues/83197) : ne vérifie pas les dépendances circulaires lors de la création d’une table sans dépendances. Cela corrige la dégradation des performances dans les cas d’usage impliquant la création de milliers de tables, introduite dans [https://github.com/ClickHouse/ClickHouse/pull/65405](https://github.com/ClickHouse/ClickHouse/pull/65405). [#83077](https://github.com/ClickHouse/ClickHouse/pull/83077) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#83403](https://github.com/ClickHouse/ClickHouse/issues/83403) : correction de `no_sign_request` pour le client S3. Il peut être utilisé pour éviter explicitement la signature des requêtes S3. Il peut également être défini pour des endpoints spécifiques à l’aide de paramètres par endpoint. [#83379](https://github.com/ClickHouse/ClickHouse/pull/83379) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#83465](https://github.com/ClickHouse/ClickHouse/issues/83465) : correction de l’exception `TOO_DEEP_SUBQUERIES` lorsque la définition d’une CTE fait référence à une autre expression de table portant le même nom. [#83413](https://github.com/ClickHouse/ClickHouse/pull/83413) ([Dmitry Novik](https://github.com/novikd)).
