* Rétroporté dans [#78038](https://github.com/ClickHouse/ClickHouse/issues/78038) : corrige le comportement indéfini lors de la comparaison avec NaN dans ArgMin/ArgMax. [#77756](https://github.com/ClickHouse/ClickHouse/pull/77756) ([Raúl Marín](https://github.com/Algunenano)).

* Rétroporté dans [#78050](https://github.com/ClickHouse/ClickHouse/issues/78050) : désactive la recherche floue dans l’historique du serveur SSH (car elle nécessite skim). [#78002](https://github.com/ClickHouse/ClickHouse/pull/78002) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#78105](https://github.com/ClickHouse/ClickHouse/issues/78105) : correction du prompt &quot;Le format de sortie demandé {} est binaire... Voulez-vous quand même l’afficher ? [y/N]&quot;. [#78095](https://github.com/ClickHouse/ClickHouse/pull/78095) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#78116](https://github.com/ClickHouse/ClickHouse/issues/78116) : interdiction de spécifier un query parameter `session_id` vide pour l’HTTP interface. [#78098](https://github.com/ClickHouse/ClickHouse/pull/78098) ([Alexey Katsman](https://github.com/alexkats)).
* Rétroporté dans [#78136](https://github.com/ClickHouse/ClickHouse/issues/78136) : correction d’un crash dans le NATS engine. [#78108](https://github.com/ClickHouse/ClickHouse/pull/78108) ([Dmitry Novikov](https://github.com/dmitry-sles-novikov)).
* Rétroporté dans [#78121](https://github.com/ClickHouse/ClickHouse/issues/78121) : ne plus tenter de créer history&#95;file dans le client intégré pour SSH. [#78112](https://github.com/ClickHouse/ClickHouse/pull/78112) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#78147](https://github.com/ClickHouse/ClickHouse/issues/78147) : correction de l’affichage d’informations incorrectes par system.detached&#95;tables après des requêtes RENAME DATABASE ou DROP TABLE. [#78126](https://github.com/ClickHouse/ClickHouse/pull/78126) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#78199](https://github.com/ClickHouse/ClickHouse/issues/78199) : correction des vérifications en cas de trop grand nombre de tables avec Database Replicated après [https://github.com/ClickHouse/ClickHouse/pull/77274](https://github.com/ClickHouse/ClickHouse/pull/77274). La vérification est également effectuée avant la création du storage afin d’éviter la création de nœuds non comptabilisés dans ZooKeeper dans le cas de RMT ou de KeeperMap. [#78127](https://github.com/ClickHouse/ClickHouse/pull/78127) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#78158](https://github.com/ClickHouse/ClickHouse/issues/78158) : les fonctions `groupArray*` produisent désormais une erreur BAD&#95;ARGUMENTS pour une valeur 0 de type Int de l’argument max&#95;size, comme c’était déjà le cas pour le type UInt, au lieu de tenter l’exécution avec cette valeur. [#78140](https://github.com/ClickHouse/ClickHouse/pull/78140) ([Eduard Karacharov](https://github.com/korowa)).
* Rétroporté dans [#78233](https://github.com/ClickHouse/ClickHouse/issues/78233) : prévention d’un crash dans recoverLostReplica si la table locale est supprimée avant d’être détachée. [#78173](https://github.com/ClickHouse/ClickHouse/pull/78173) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#78239](https://github.com/ClickHouse/ClickHouse/issues/78239) : correction de la colonne &quot;alterable&quot; dans system.s3&#95;queue&#95;settings, qui renvoyait toujours `false`. [#78187](https://github.com/ClickHouse/ClickHouse/pull/78187) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#78312](https://github.com/ClickHouse/ClickHouse/issues/78312) : correction de crashes et de résultats incorrects pour `mapFromArrays` dans le cas d’un Array de clés de type LowCardinality(Nullable). [#78240](https://github.com/ClickHouse/ClickHouse/pull/78240) ([Eduard Karacharov](https://github.com/korowa)).
