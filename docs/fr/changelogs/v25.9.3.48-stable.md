Auteur original : Michael Anastasakis (@michael-anastasakis). [#87172](https://github.com/ClickHouse/ClickHouse/pull/87172) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#87552](https://github.com/ClickHouse/ClickHouse/issues/87552) : correction des lightweight updates avec des sous-requêtes qui lisent depuis d’autres tables `MergeTree`. [#87285](https://github.com/ClickHouse/ClickHouse/pull/87285) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#87829](https://github.com/ClickHouse/ClickHouse/issues/87829) : correction de la lecture directe depuis l’index de texte sur le stockage d’objets. [#87399](https://github.com/ClickHouse/ClickHouse/pull/87399) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#87732](https://github.com/ClickHouse/ClickHouse/issues/87732) : correction de la validation des accès pour SELECT et INSERT sur les tables Buffer. [#87545](https://github.com/ClickHouse/ClickHouse/pull/87545) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#87760](https://github.com/ClickHouse/ClickHouse/issues/87760) : évite les fuites de mémoire comptabilisée pour la journalisation asynchrone (l’écart peut être important, ~100 GiB sur 10 heures) et pour text&#95;log (un écart presque identique est possible). [#87584](https://github.com/ClickHouse/ClickHouse/pull/87584) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#87773](https://github.com/ClickHouse/ClickHouse/issues/87773) : correction d’un bug pouvant entraîner l’écrasement des paramètres globaux du serveur par les paramètres SELECT d’une vue ou d’une vue matérialisée, si cette vue était supprimée de manière asynchrone et que le serveur redémarrait avant la fin du nettoyage en arrière-plan. [#87603](https://github.com/ClickHouse/ClickHouse/pull/87603) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#87797](https://github.com/ClickHouse/ClickHouse/issues/87797) : correction de la génération du bloc de sortie dans l’algorithme HashJoin lorsque la liste des lignes du côté droit n’est pas utilisée. Corrige [#87401](https://github.com/ClickHouse/ClickHouse/issues/87401). [#87699](https://github.com/ClickHouse/ClickHouse/pull/87699) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#87852](https://github.com/ClickHouse/ClickHouse/issues/87852) : clôture [#86587](https://github.com/ClickHouse/ClickHouse/issues/86587). [#87761](https://github.com/ClickHouse/ClickHouse/pull/87761) ([scanhex12](https://github.com/scanhex12)).
* Rétroporté dans [#87911](https://github.com/ClickHouse/ClickHouse/issues/87911) : correction de plusieurs bugs liés aux indices de saut. [#87817](https://github.com/ClickHouse/ClickHouse/pull/87817) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#88075](https://github.com/ClickHouse/ClickHouse/issues/88075) : correction des fusions avec projections lorsque le dernier bloc est vide. [#87928](https://github.com/ClickHouse/ClickHouse/pull/87928) ([Raúl Marín](https://github.com/Algunenano)).
