<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#90145](https://github.com/ClickHouse/ClickHouse/issues/90145) : empêcher l’application incorrecte des règles de masquage des requêtes aux instructions DDL. [#89272](https://github.com/ClickHouse/ClickHouse/pull/89272) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Rétroporté dans [#90440](https://github.com/ClickHouse/ClickHouse/issues/90440) : corriger, dans certains cas, l’inférence de valeurs DateTime64 incorrectes à partir de Strings dans les formats texte. Résout [#89368](https://github.com/ClickHouse/ClickHouse/issues/89368). [#90013](https://github.com/ClickHouse/ClickHouse/pull/90013) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#90969](https://github.com/ClickHouse/ClickHouse/issues/90969) : corriger une possible erreur logique lors du renommage et de la modification de la même colonne Nested dans un seul ALTER. Résout [#90406](https://github.com/ClickHouse/ClickHouse/issues/90406). [#90412](https://github.com/ClickHouse/ClickHouse/pull/90412) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#91031](https://github.com/ClickHouse/ClickHouse/issues/91031) : corriger une possible erreur logique dans la sortie au format `Arrow` de `LowCardinality(Bool/Date32)`. Résout [#83883](https://github.com/ClickHouse/ClickHouse/issues/83883). [#90505](https://github.com/ClickHouse/ClickHouse/pull/90505) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#90910](https://github.com/ClickHouse/ClickHouse/issues/90910) : faire en sorte que les secrets masqués des collections nommées dépendent de `display_secrets_in_show_and_select` et de `format_display_secrets_in_show_and_select`. [#90765](https://github.com/ClickHouse/ClickHouse/pull/90765) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#90848](https://github.com/ClickHouse/ClickHouse/issues/90848) : corriger un possible état incohérent des données partagées et des chemins dynamiques dans JSON, pouvant entraîner des erreurs logiques et des résultats inattendus. [#90816](https://github.com/ClickHouse/ClickHouse/pull/90816) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#91201](https://github.com/ClickHouse/ClickHouse/issues/91201) : corriger une consommation mémoire élevée lors de la lecture de colonnes JSON/Dynamic/Variant. [#90907](https://github.com/ClickHouse/ClickHouse/pull/90907) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#91496](https://github.com/ClickHouse/ClickHouse/issues/91496) : corriger l’agrégation de `SummingMergeTree` pour les colonnes `Nested` `LowCardinality`. [#90927](https://github.com/ClickHouse/ClickHouse/pull/90927) ([Ivan Babrou](https://github.com/bobrik)).
* Rétroporté dans [#91408](https://github.com/ClickHouse/ClickHouse/issues/91408) : ... Ne pas autoriser adaptive&#95;write&#95;buffer&#95;initial&#95;size à être défini à 0. [#91001](https://github.com/ClickHouse/ClickHouse/pull/91001) ([Pedro Ferreira](https://github.com/PedroTadim)).
* Rétroporté dans [#91069](https://github.com/ClickHouse/ClickHouse/issues/91069) : corriger un bogue dans JSON lorsqu’un chemin peut se trouver à la fois dans les données partagées et dans les chemins dynamiques pendant la lecture de sous-objets dans des parties compactes avec `write_marks_for_substreams_in_compact_parts` désactivé. [#91014](https://github.com/ClickHouse/ClickHouse/pull/91014) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#91316](https://github.com/ClickHouse/ClickHouse/issues/91316) : corriger une possible incohérence de la structure dynamique lors de l’écriture dans des parties compactes, pouvant entraîner un segfault. [#91152](https://github.com/ClickHouse/ClickHouse/pull/91152) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#91334](https://github.com/ClickHouse/ClickHouse/issues/91334) : corrige SYSTEM DROP FILESYSTEM CACHE ON CLUSTER. [#91304](https://github.com/ClickHouse/ClickHouse/pull/91304) ([Anton Ivashkin](https://github.com/ianton-ru)).
* Rétroporté dans [#91456](https://github.com/ClickHouse/ClickHouse/issues/91456) : supprime les colonnes Sparse de l’en-tête dans les algorithmes de fusion. Résout [#91377](https://github.com/ClickHouse/ClickHouse/issues/91377). [#91396](https://github.com/ClickHouse/ClickHouse/pull/91396) ([Pavel Kruglov](https://github.com/Avogar)).
