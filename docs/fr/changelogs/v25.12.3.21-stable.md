<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement perceptible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#93725](https://github.com/ClickHouse/ClickHouse/issues/93725) : correction de la résolution des sous-colonnes dynamiques dans les alias de colonne par l’analyseur. Auparavant, une sous-colonne dynamique dans un alias de colonne était encapsulée dans `getSubcolumn` et, dans certains cas, pouvait ne pas être résolue du tout. Clôt [#91434](https://github.com/ClickHouse/ClickHouse/issues/91434). [#92583](https://github.com/ClickHouse/ClickHouse/pull/92583) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93596](https://github.com/ClickHouse/ClickHouse/issues/93596) : correction d’un possible blocage lors de l’arrêt du background schedule pool (pouvant entraîner des blocages du serveur à l’arrêt). [#93008](https://github.com/ClickHouse/ClickHouse/pull/93008) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93563](https://github.com/ClickHouse/ClickHouse/issues/93563) : correction d’un crash lors de la désérialisation d’un aggregate state `groupConcat` mal formé avec des offsets hors limites. [#93028](https://github.com/ClickHouse/ClickHouse/pull/93028) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#93522](https://github.com/ClickHouse/ClickHouse/issues/93522) : correction de la gestion d’un tableau vide comme deuxième argument dans les fonctions `hasAllTokens` et `hasAnyTokens`. [#93328](https://github.com/ClickHouse/ClickHouse/pull/93328) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#93476](https://github.com/ClickHouse/ClickHouse/issues/93476) : correction d’une vulnérabilité de débordement d’entier dans la désérialisation de l’état `groupConcat`, qui pouvait provoquer des problèmes de sécurité mémoire avec des aggregate states forgés. [#93426](https://github.com/ClickHouse/ClickHouse/pull/93426) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#93520](https://github.com/ClickHouse/ClickHouse/issues/93520) : correction de l’analyse d’index textuel sur des colonnes de type tableau lorsque l’index ne contient aucun token (tous les tableaux sont vides ou tous les tokens sont ignorés par le tokenizer). [#93457](https://github.com/ClickHouse/ClickHouse/pull/93457) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#93587](https://github.com/ClickHouse/ClickHouse/issues/93587) : correction de l’extraction d’une sous-colonne pendant la désérialisation directe dans des colonnes Sparse. [#93512](https://github.com/ClickHouse/ClickHouse/pull/93512) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93672](https://github.com/ClickHouse/ClickHouse/issues/93672) : garantie que ZooKeeper est bien finalisé à l’arrêt (corrige un possible blocage à l’arrêt dans des cas très improbables). [#93602](https://github.com/ClickHouse/ClickHouse/pull/93602) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93934](https://github.com/ClickHouse/ClickHouse/issues/93934) : correction de LOGICAL&#95;ERROR lors de la restauration de ReplicatedMergeTree avec une condition de concurrence sur la déduplication. [#93612](https://github.com/ClickHouse/ClickHouse/pull/93612) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#93927](https://github.com/ClickHouse/ClickHouse/issues/93927) : correction de l’utilisation d’une colonne Sparse pour la mise à jour TTL lors de la désérialisation directe dans des colonnes Sparse dans certains formats d’entrée. Cela corrige une possible erreur logique `Unexpected type of result TTL column`. [#93619](https://github.com/ClickHouse/ClickHouse/pull/93619) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93734](https://github.com/ClickHouse/ClickHouse/issues/93734) : vérification que la taille du buffer décompressé correspond bien à celle attendue. [#93690](https://github.com/ClickHouse/ClickHouse/pull/93690) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#93802](https://github.com/ClickHouse/ClickHouse/issues/93802) : empêcher les utilisateurs d’obtenir la liste des colonnes d’une table sans vérifier la permission `SHOW COLUMNS` via le moteur de table `merge`. [#93695](https://github.com/ClickHouse/ClickHouse/pull/93695) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#93764](https://github.com/ClickHouse/ClickHouse/issues/93764) : correction de la matérialisation des skip indexes créés sur des sous-colonnes. [#93708](https://github.com/ClickHouse/ClickHouse/pull/93708) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#93825](https://github.com/ClickHouse/ClickHouse/issues/93825) : nous stockons des pointeurs partagés vers les storages dans `QueryPipeline::resources::storage_holders` afin de garantir que les objets `IStorage` ne sont pas détruits tant que `PipelineExecutor` est en vie. [#93746](https://github.com/ClickHouse/ClickHouse/pull/93746) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#93855](https://github.com/ClickHouse/ClickHouse/issues/93855) : correction d&#39;une erreur logique dans le rare cas où un tuple vide est utilisé avec une colonne `Map`. Clôt [#93784](https://github.com/ClickHouse/ClickHouse/issues/93784). [#93814](https://github.com/ClickHouse/ClickHouse/pull/93814) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Rétroporté dans [#93918](https://github.com/ClickHouse/ClickHouse/issues/93918) : correction de `optimize_inverse_dictionary_lookup`, qui ne fonctionnait pas avec une requête distribuée lorsque la clé est d&#39;un type entier signé. Clôt [#93259](https://github.com/ClickHouse/ClickHouse/issues/93259). [#93848](https://github.com/ClickHouse/ClickHouse/pull/93848) ([Nihal Z. Miaji](https://github.com/nihalzp)).
