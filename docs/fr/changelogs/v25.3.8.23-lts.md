<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#88220](https://github.com/ClickHouse/ClickHouse/issues/88220) : corrige un plantage où certaines données valides soumises par l’utilisateur dans une colonne `AggregateFunction(quantileDD)` pouvaient entraîner une récursion infinie des merges. [#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* Rétroporté dans [#88598](https://github.com/ClickHouse/ClickHouse/issues/88598) : corrige la résolution du schéma de table avec la fonction de table `url()` lorsque le paramètre `parallel_replicas_for_cluster_functions` est défini sur 1. [#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#88647](https://github.com/ClickHouse/ClickHouse/issues/88647) : les grands clusters avec des numéros de nœud &gt; 10 ont une forte probabilité de faire échouer la restauration avec l’erreur `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again`. Le nœud `num_hosts` est écrasé par de nombreux hôtes en même temps. Le correctif rend dynamique le paramètre qui contrôle les tentatives. Ferme [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721). [#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#88712](https://github.com/ClickHouse/ClickHouse/issues/88712) : corrige un plantage potentiel causé par une mutation concurrente des colonnes PREWHERE const sous-jacentes. [#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88902](https://github.com/ClickHouse/ClickHouse/issues/88902) : après récupération, une replica de base de données Replicated pouvait rester bloquée pendant longtemps en affichant des messages comme `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)` ; c’est corrigé. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#88886](https://github.com/ClickHouse/ClickHouse/issues/88886) : corrige la validation des accès pour select avec la fonction de table `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#89033](https://github.com/ClickHouse/ClickHouse/issues/89033) : corrige un bug dans la fonction `reverseUTF8`. Dans les versions précédentes, elle inversait par erreur les octets des points de code UTF-8 de longueur 4. Cela ferme [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
