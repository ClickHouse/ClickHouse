  ### ClickHouse release v25.12.2.54-stable (e06d8a2be22) FIXME as compared to v25.12.1.649-stable (bf4280aa19d)
</div>

<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions précédentes
</div>

* Rétroporté dans [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224) : Active les données partagées avancées pour JSON par défaut. Suite à ce changement, le retour à des versions antérieures à la 25.8 ne sera plus possible, car ces versions ne pourront pas lire les nouveaux data parts contenant une colonne JSON. Pour des mises à niveau sécurisées, il est recommandé de définir le paramètre `compatibility` sur la version précédente ou de configurer les paramètres MergeTree `dynamic_serialization_version='v2', object_serialization_version='v2'`. [#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061) : Annulation de « Allow INSERT into simple ALIAS columns » (annule ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154)). Cette fonctionnalité ne fonctionne pas avec les formats personnalisés et n'est pas protégée par un paramètre. [#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat)).

<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#92711](https://github.com/ClickHouse/ClickHouse/issues/92711) : Optimisation de la fonction d'agrégation distinctJSONPaths afin qu'elle ne lise que les chemins JSON depuis les data parts et non l'intégralité de la colonne JSON. [#92196](https://github.com/ClickHouse/ClickHouse/pull/92196) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#92604](https://github.com/ClickHouse/ClickHouse/issues/92604) : Ajout d'une colonne de création (implicite/explicite) à system.data_skipping_indices. [#92378](https://github.com/ClickHouse/ClickHouse/pull/92378) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#93377](https://github.com/ClickHouse/ClickHouse/issues/93377) : Repli sur la copie en lecture-écriture pour Azure Blob Storage lorsque la copie native échoue avec une erreur BadRequest (par exemple, liste de blocs invalide). Auparavant, ce repli n'était effectué que pour l'erreur Unauthorized, observée lors de la copie d'un blob vers des comptes de stockage différents. L'erreur « The specified block list is invalid » étant également rencontrée, la condition a été mise à jour afin de basculer en lecture-écriture pour tous les échecs de copie native. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#93015](https://github.com/ClickHouse/ClickHouse/issues/93015) : Journalisation des tâches en arrière-plan dont la durée dépasse la moyenne (`background_schedule_pool_log.duration_threshold_milliseconds=30`) afin d'éviter une journalisation excessive. [#92965](https://github.com/ClickHouse/ClickHouse/pull/92965) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338) : Prise en charge du type géométrique pour `flipCoordinates`. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).
* Rétroporté dans [#93395](https://github.com/ClickHouse/ClickHouse/issues/93395) : Amélioration de l'ergonomie de SYSTEM INSTRUMENT ADD/REMOVE : utilisation de littéraux String pour les noms de fonctions, application des modifications à toutes les fonctions correspondantes et autorisation de l'utilisation de function_name dans `REMOVE`. [#93345](https://github.com/ClickHouse/ClickHouse/pull/93345) ([Pablo Marcos](https://github.com/pamarcos)).
