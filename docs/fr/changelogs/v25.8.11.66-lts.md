  ### Release ClickHouse v25.8.11.66-lts (fa393206741) FIXME par rapport à v25.8.10.7-lts (02ec3a1ea1e)

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#88492](https://github.com/ClickHouse/ClickHouse/issues/88492) : utilisation du client de stockage S3 avec des paramètres spécifiques aux sauvegardes (par exemple, backup&#95;slow&#95;all&#95;threads&#95;after&#95;retryable&#95;s3&#95;error) pour la copie côté serveur (native) vers une destination de sauvegarde. Rend s3&#95;slow&#95;all&#95;threads&#95;after&#95;retryable&#95;error obsolète. [#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva)).
* Rétroporté dans [#88537](https://github.com/ClickHouse/ClickHouse/issues/88537) : ajout de davantage d&#39;informations pour le suivi des performances dans les SELECT Iceberg. [#87903](https://github.com/ClickHouse/ClickHouse/pull/87903) ([Daniil Ivanik](https://github.com/divanik)).
* Rétroporté dans [#88300](https://github.com/ClickHouse/ClickHouse/issues/88300) : mise à jour de l&#39;Azure SDK pour inclure le correctif de « Content-Length » observé dans les fonctionnalités de copie et de création de conteneur. [#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#88742](https://github.com/ClickHouse/ClickHouse/issues/88742) : ajout du paramètre de config `keeper_server.coordination_settings.check_node_acl_on_remove`. S&#39;il est activé, avant chaque suppression d&#39;un nœud, les ACL du nœud lui-même et du nœud parent seront vérifiées. Sinon, seule l&#39;ACL du nœud parent sera vérifiée. [#88513](https://github.com/ClickHouse/ClickHouse/pull/88513) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#88781](https://github.com/ClickHouse/ClickHouse/issues/88781) : correction d&#39;une fuite de mémoire due à `GLOBAL IN` ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)). [#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94)).
* Rétroporté dans [#88764](https://github.com/ClickHouse/ClickHouse/issues/88764) : ajout d&#39;une étape au script post-installation pour `clickhouse-keeper`, afin d&#39;activer son démarrage au boot. [#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#88848](https://github.com/ClickHouse/ClickHouse/issues/88848) : correction de l’inférence de Date/DateTime/DateTime64 pour les dates hors de la plage prise en charge. [#86184](https://github.com/ClickHouse/ClickHouse/pull/86184) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#88594](https://github.com/ClickHouse/ClickHouse/issues/88594) : correction de la résolution du schéma de la table avec la table function `url()` lorsque le paramètre `parallel_replicas_for_cluster_functions` est défini sur 1. [#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#88843](https://github.com/ClickHouse/ClickHouse/issues/88843) : correction de l’erreur de table inconnue dans une requête INSERT SELECT avec CTE, [#85368](https://github.com/ClickHouse/ClickHouse/issues/85368). [#87789](https://github.com/ClickHouse/ClickHouse/pull/87789) ([Guang Zhao](https://github.com/zheguang)).
* Rétroporté dans [#88509](https://github.com/ClickHouse/ClickHouse/issues/88509) : correction de la lecture de la sous-colonne de mappage NULL depuis des Variant qui ne peuvent pas être imbriqués dans Nullable. [#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#88390](https://github.com/ClickHouse/ClickHouse/issues/88390) : dans AzureBlobStorage, mise à jour pour tenter d’abord la copie native, puis revenir à la lecture et à l’écriture en cas d’erreur &#39;Unauthroized&#39; (dans AzureBlobStorage, si les comptes de stockage sont différents pour la source et la destination, nous obtenons l’erreur &#39;Unauthorized&#39;). Correction également de l’application de &quot;use&#95;native&#95;copy&quot; lorsqu’un endpoint est défini dans la configuration. [#87826](https://github.com/ClickHouse/ClickHouse/pull/87826) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#88436](https://github.com/ClickHouse/ClickHouse/issues/88436) : correction de l’élimination incorrecte des granules/partitions pour les clés basées sur datetime lors de l’utilisation du paramètre `session_timezone` dans les queries. [#87987](https://github.com/ClickHouse/ClickHouse/pull/87987) ([Eduard Karacharov](https://github.com/korowa)).
* Rétroporté dans [#88420](https://github.com/ClickHouse/ClickHouse/issues/88420) : applique la normalisation des URI avant l’évaluation pour la vérification des grants introduite par [https://github.com/ClickHouse/ClickHouse/pull/84503](https://github.com/ClickHouse/ClickHouse/pull/84503). [#88089](https://github.com/ClickHouse/ClickHouse/pull/88089) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#88656](https://github.com/ClickHouse/ClickHouse/issues/88656) : désormais, le worker DDL nettoie les hôtes obsolètes de l’ensemble de répliques. Cela réduira la quantité de métadonnées stockées dans ZooKeeper. [#88154](https://github.com/ClickHouse/ClickHouse/pull/88154) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#88284](https://github.com/ClickHouse/ClickHouse/issues/88284) : correction de la propagation de l’indicateur `is_shared` dans `ColumnLowCardinality`. Cela peut entraîner un résultat de group-by erroné si une nouvelle valeur est insérée dans une colonne alors que les valeurs de hachage ont déjà été précalculées et mises en cache dans `ReverseIndex`. [#88213](https://github.com/ClickHouse/ClickHouse/pull/88213) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#88459](https://github.com/ClickHouse/ClickHouse/issues/88459) : correction du paramètre de workload `max_cpu_share`. Il peut désormais être utilisé sans que le paramètre de workload `max_cpus` soit défini. [#88217](https://github.com/ClickHouse/ClickHouse/pull/88217) ([Neerav](https://github.com/neeravsalaria)).
* Rétroporté dans [#88336](https://github.com/ClickHouse/ClickHouse/issues/88336) : les sous-requêtes corrélées fonctionneront désormais avec les stockages objet. [#88290](https://github.com/ClickHouse/ClickHouse/pull/88290) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#88356](https://github.com/ClickHouse/ClickHouse/issues/88356) : éviter de tenter d’initialiser des bases de données DataLake lors de l’accès à `system.projections` et `system.data_skipping_indices`. [#88330](https://github.com/ClickHouse/ClickHouse/pull/88330) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88430](https://github.com/ClickHouse/ClickHouse/issues/88430) : correction de la complexité quadratique de la fonction `countMatches`. Clôt [#88400](https://github.com/ClickHouse/ClickHouse/issues/88400). [#88401](https://github.com/ClickHouse/ClickHouse/pull/88401) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#88649](https://github.com/ClickHouse/ClickHouse/issues/88649) : les grands clusters avec des numéros de nœud &gt; 10 ont une forte probabilité d’échouer lors de la restauration avec l’erreur `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again`. Le nœud `num_hosts` est écrasé simultanément par de nombreux hosts. Le correctif rend dynamique le paramètre qui contrôle le nombre de tentatives. Clôt [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721). [#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#88716](https://github.com/ClickHouse/ClickHouse/issues/88716) : correction d’un crash potentiel causé par une mutation concurrente des colonnes const PREWHERE sous-jacentes. [#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88906](https://github.com/ClickHouse/ClickHouse/issues/88906) : après récupération, une replica d’une base de données Replicated pouvait rester bloquée longtemps en affichant des messages comme `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)` ; ce problème est corrigé. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#88890](https://github.com/ClickHouse/ClickHouse/issues/88890) : correction de la validation des accès sur select pour la table function `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#88835](https://github.com/ClickHouse/ClickHouse/issues/88835) : intercepter les exceptions lorsque la journalisation asynchrone échoue afin d’éviter l’arrêt du programme. [#88814](https://github.com/ClickHouse/ClickHouse/pull/88814) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#88940](https://github.com/ClickHouse/ClickHouse/issues/88940) : correction d’un bogue dans la fonction `reverseUTF8`. Dans les versions précédentes, elle inversait par erreur les octets des code points UTF-8 de longueur 4. Cela clôt [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#88976](https://github.com/ClickHouse/ClickHouse/issues/88976) : ne pas vérifier l’accès `SET DEFINER <current_user>:definer` lors de la création d’une vue avec SQL SECURITY DEFINER. [#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit)).
