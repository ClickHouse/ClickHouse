<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement erroné visible par l&#39;utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#102368](https://github.com/ClickHouse/ClickHouse/issues/102368) : corrige un bug où ClickHouse pouvait ignorer des fichiers si l&#39;en-tête `Content-Length` était absent de la réponse à leur requête HEAD (par exemple, en raison d&#39;un transcodage décompressif dans GCS). [#99971](https://github.com/ClickHouse/ClickHouse/pull/99971) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Rétroporté dans [#101532](https://github.com/ClickHouse/ClickHouse/issues/101532) : certains catalogues peuvent afficher des secrets dans la section `SETTINGS` du résultat de la requête `select * from system.databases`. Cette PR empêche ce comportement. [#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Rétroporté dans [#102434](https://github.com/ClickHouse/ClickHouse/issues/102434) : corrige une Exception qui s&#39;échappait du destructeur S3 `Client::~Client` et provoquait l&#39;arrêt du serveur. [#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
