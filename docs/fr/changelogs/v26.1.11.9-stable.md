<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#102655](https://github.com/ClickHouse/ClickHouse/issues/102655) : correction de l’exception LOGICAL&#95;ERROR dans `ASTColumnsExceptTransformer::transform`. [#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#101418](https://github.com/ClickHouse/ClickHouse/issues/101418) : correction d’une utilisation d’une valeur non initialisée dans StringSearcher.h. [#100225](https://github.com/ClickHouse/ClickHouse/pull/100225) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#102677](https://github.com/ClickHouse/ClickHouse/issues/102677) : correction d’un crash de type use-after-free dans le scheduler des baux CPU lorsque le minuteur d’attente survit au worker thread dont il référence les `ProfileEvents::Counters`. [#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#102709](https://github.com/ClickHouse/ClickHouse/issues/102709) : correction d’un bug de concurrence SLRU dans le cache du système de fichiers 26.1+, pouvant entraîner une erreur logique lors de la réservation d’espace. Dans un build de débogage, cela peut aussi provoquer l’échec de l’assertion : `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#102750](https://github.com/ClickHouse/ClickHouse/issues/102750) : correction du CurrentMetric `NamedCollection` artificiellement gonflé par `CREATE NAMED COLLECTION IF NOT EXISTS` sur des collections existantes, ainsi que de l’absence d’initialisation pour les collections chargées depuis la configuration ou le stockage SQL au démarrage. Clôt [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507). [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#102795](https://github.com/ClickHouse/ClickHouse/issues/102795) : bug avec la row policy qui provoque l’exception &#39;Not found column in block&#39; dans certains cas particuliers. [#102648](https://github.com/ClickHouse/ClickHouse/pull/102648) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Rétroporté dans [#102743](https://github.com/ClickHouse/ClickHouse/issues/102743) : correction du blocage indéfini de `SYSTEM WAIT VIEW` lorsque la vue matérialisée actualisable est supprimée alors que l’attente est en cours. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
