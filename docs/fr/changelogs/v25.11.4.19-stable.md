<div id="backward-incompatible-change">
  #### Changement non rétrocompatible
</div>

* Rétroporté dans [#92120](https://github.com/ClickHouse/ClickHouse/issues/92120) : suite de [https://github.com/ClickHouse/ClickHouse/pull/88380](https://github.com/ClickHouse/ClickHouse/pull/88380). Cette PR signale comme non rétrocompatible la désactivation des arguments positionnels dans les projections. En outre, elle introduit le paramètre `enable_positional_arguments_for_projections` afin de permettre une mise à niveau sûre d’un cluster ClickHouse lorsque des arguments positionnels sont présents dans les projections. [#92007](https://github.com/ClickHouse/ClickHouse/pull/92007) ([Dmitry Novik](https://github.com/novikd)).

  #### Amélioration

* Rétroporté dans [#92571](https://github.com/ClickHouse/ClickHouse/issues/92571) : rendre plus robuste la détection de l’utilisation mémoire des requêtes lors de l’écriture sur disque pendant l’agrégation/le tri. [#92500](https://github.com/ClickHouse/ClickHouse/pull/92500) ([Azat Khuzhin](https://github.com/azat)).
