<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#87979](https://github.com/ClickHouse/ClickHouse/issues/87979) : amélioration du cache du système de fichiers : réutilisation de l’itérateur de priorité du cache par les threads qui réservent simultanément de l’espace dans le cache. [#87914](https://github.com/ClickHouse/ClickHouse/pull/87914) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#88060](https://github.com/ClickHouse/ClickHouse/issues/88060) : pour exposer l’événement de profil Keeper `KeeperRequestRejectedDueToSoftMemoryLimitCount`, il faut l’ajouter à `KeeperConstants.cpp`. [#88030](https://github.com/ClickHouse/ClickHouse/pull/88030) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#87777](https://github.com/ClickHouse/ClickHouse/issues/87777) : évite les fuites de mémoire suivie pour le logging asynchrone (cela peut entraîner un écart important, sur 10 heures, de ~100GiB) et text&#95;log (un écart presque identique est possible). [#87584](https://github.com/ClickHouse/ClickHouse/pull/87584) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#87909](https://github.com/ClickHouse/ClickHouse/issues/87909) : correction de plusieurs bogues liés aux indices de saut. [#87817](https://github.com/ClickHouse/ClickHouse/pull/87817) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#88073](https://github.com/ClickHouse/ClickHouse/issues/88073) : correction de la fusion avec les projections lorsque le dernier bloc est vide. [#87928](https://github.com/ClickHouse/ClickHouse/pull/87928) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#88147](https://github.com/ClickHouse/ClickHouse/issues/88147) : correction d’une possible corruption de données dans les tables `MergeTree` avec `TTL` défini sur une colonne. [#88095](https://github.com/ClickHouse/ClickHouse/pull/88095) ([Anton Popov](https://github.com/CurtizJ)).
