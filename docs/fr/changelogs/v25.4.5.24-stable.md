<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement erroné visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#80466](https://github.com/ClickHouse/ClickHouse/issues/80466) : essayer d’utiliser IColumn au lieu de Field dans SingleValueDataGeneric. Cela corrige les valeurs de retour incorrectes de certaines fonctions d’agrégation comme `argMax` pour les types `Dynamic/Variant/JSON`. [#79166](https://github.com/ClickHouse/ClickHouse/pull/79166) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#80258](https://github.com/ClickHouse/ClickHouse/issues/80258) : corrige l’erreur AMBIGUOUS&#95;COLUMN&#95;NAME avec la matérialisation différée lorsqu’aucune colonne n’est utilisée pour l’exécution de la requête avant la projection. Exemple : SELECT * FROM t ORDER BY rand() LIMIT 5. [#79926](https://github.com/ClickHouse/ClickHouse/pull/79926) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#80339](https://github.com/ClickHouse/ClickHouse/issues/80339) : corrige la lecture des sous-colonnes depuis le moteur Merge. [#80158](https://github.com/ClickHouse/ClickHouse/pull/80158) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#80506](https://github.com/ClickHouse/ClickHouse/issues/80506) : corrige la sérialisation incorrecte de champs numériques imbriqués en chaînes de caractères dans les documents MongoDB. Supprime la limite de profondeur maximale pour les documents issus de MongoDB. [#80289](https://github.com/ClickHouse/ClickHouse/pull/80289) ([Kirill Nikiforov](https://github.com/allmazz)).
* Rétroporté dans [#80402](https://github.com/ClickHouse/ClickHouse/issues/80402) : corrige la représentation textuelle de DateTime et DateTime64 pour le stockage PostgreSQL. [#80301](https://github.com/ClickHouse/ClickHouse/pull/80301) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#80395](https://github.com/ClickHouse/ClickHouse/issues/80395) : corrige l’erreur `NOT_FOUND_COLUMN_IN_BLOCK` provoquée par l’optimisation de push-down de filtre de l’étape logique JOIN lorsque l’expression `ON` n’est pas une égalité triviale. Corrige [#79647](https://github.com/ClickHouse/ClickHouse/issues/79647). Corrige [#77848](https://github.com/ClickHouse/ClickHouse/issues/77848). [#80360](https://github.com/ClickHouse/ClickHouse/pull/80360) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
