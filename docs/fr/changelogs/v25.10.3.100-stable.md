* Rétroporté dans [#90215](https://github.com/ClickHouse/ClickHouse/issues/90215) : si la fusion était interrompue, par exemple en raison d’une memory limit, l’exécuteur d’arrière-plan merge mutate appelait `cancel` sur la tâche de fusion sans verrou. Enfin, ce nettoyage des déchets était exécuté sous le verrou de l’exécuteur d’arrière-plan merge mutate.
