<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#84035](https://github.com/ClickHouse/ClickHouse/issues/84035) : utiliser les informations du cgroup (le cas échéant, c.-à-d. si `memory_worker_use_cgroup` est activé et que les cgroups sont disponibles) pour ajuster le memory tracker (`memory_worker_correct_memory_tracker`). [#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#84107](https://github.com/ClickHouse/ClickHouse/issues/84107) : masquer les détails d’authentification du schema registry Avro afin qu’ils ne soient visibles ni par l’utilisateur ni dans les journaux. [#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#83915](https://github.com/ClickHouse/ClickHouse/issues/83915) : corrige un problème où, si une table MergeTree est créée avec `add_minmax_index_for_numeric_columns=1` ou `add_minmax_index_for_string_columns=1`, l’index est ensuite matérialisé lors d’une opération ALTER, ce qui empêche la base de données Replicated de s’initialiser correctement sur une nouvelle réplique. [#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#83873](https://github.com/ClickHouse/ClickHouse/issues/83873) : introduit un paramètre de rétrocompatibilité pour permettre au nouvel analyzer de référencer un alias externe dans la clause WITH en cas de conflit de noms. Corrige [#82700](https://github.com/ClickHouse/ClickHouse/issues/82700). [#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#84091](https://github.com/ClickHouse/ClickHouse/issues/84091) : lors d’une restauration depuis une sauvegarde, l’utilisateur défini comme definer peut ne pas être sauvegardé, ce qui peut rendre l’ensemble de la sauvegarde inutilisable. Pour corriger cela, nous reportons à l’exécution la vérification des permissions lors de la création de la table cible pendant la restauration. [#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#84124](https://github.com/ClickHouse/ClickHouse/issues/84124) : corrige un bug rare où la requête `MATERIALIZE COLUMN` pouvait entraîner des fichiers inattendus dans `checksums.txt` et, à terme, des parties de données détachées. [#84007](https://github.com/ClickHouse/ClickHouse/pull/84007) ([alesapin](https://github.com/alesapin)).
