<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Ajout de variantes d’images Docker distroless pour `clickhouse-server` et `clickhouse-keeper`, marquées avec le tag `<version>-distroless`. [#101442](https://github.com/ClickHouse/ClickHouse/pull/101442) ([Rahul Nair](https://github.com/motsc)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#100462](https://github.com/ClickHouse/ClickHouse/issues/100462) : définir `this->exceptions(std::ios::badbit);` pour les flux std de poco. [#96455](https://github.com/ClickHouse/ClickHouse/pull/96455) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#99090](https://github.com/ClickHouse/ClickHouse/issues/99090) : corrige l’accès aux sous-colonnes d’un tuple par leur nom (par ex. `SELECT x.a` pour `Tuple(a UUID, b Int32)`) pour les tables externes passées via `--external` dans `clickhouse-client`. Clôt [#96925](https://github.com/ClickHouse/ClickHouse/issues/96925). [#98755](https://github.com/ClickHouse/ClickHouse/pull/98755) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#100488](https://github.com/ClickHouse/ClickHouse/issues/100488) : les informations d’authentification dans les chaînes de connexion JDBC, ODBC et NATS sont désormais masquées dans les journaux de requêtes et dans la sortie `SHOW CREATE`, ce qui évite toute exposition accidentelle d’informations sensibles. Pour les chaînes de connexion au format URI (par ex. {scheme}://{user}:{password}@{host}), seule la partie mot de passe est masquée, tandis que le reste reste visible pour faciliter le débogage. Le paramètre `nats_token` est désormais lui aussi masqué. [#99344](https://github.com/ClickHouse/ClickHouse/pull/99344) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#100592](https://github.com/ClickHouse/ClickHouse/issues/100592) : corrige l’exception LOGICAL&#95;ERROR « Stream ... not found » lors de l’insertion dans une table contenant des colonnes imbriquées `Array(JSON)` dans des wide parts avec `optimize_on_insert=0`. [#100475](https://github.com/ClickHouse/ClickHouse/pull/100475) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#100722](https://github.com/ClickHouse/ClickHouse/issues/100722) : corrige les cas NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK où la partie SELECT de la projection contient des colonnes qui n’existent pas dans la partie SELECT d’origine de la requête. Clôt [#100194](https://github.com/ClickHouse/ClickHouse/issues/100194). [#100623](https://github.com/ClickHouse/ClickHouse/pull/100623) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
