<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#82187](https://github.com/ClickHouse/ClickHouse/issues/82187) : correction d’une erreur logique lors de la matérialisation d’une projection lorsque le type de colonne a été remplacé par Nullable. [#80741](https://github.com/ClickHouse/ClickHouse/pull/80741) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#82332](https://github.com/ClickHouse/ClickHouse/issues/82332) : correction de l’exécution de `IN` avec `transform_null_in=1`, avec une valeur null dans l’argument de gauche et un résultat de sous-requête non Nullable. [#81584](https://github.com/ClickHouse/ClickHouse/pull/81584) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#82177](https://github.com/ClickHouse/ClickHouse/issues/82177) : ne pas valider les types expérimentaux/suspects lors de l’exécution des expressions default/materialize pendant la lecture depuis une table existante. [#81618](https://github.com/ClickHouse/ClickHouse/pull/81618) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#82032](https://github.com/ClickHouse/ClickHouse/issues/82032) : correction du problème où les colonnes requises ne sont pas lues lors du traitement d’une sous-requête corrélée scalaire. Corrige [#81716](https://github.com/ClickHouse/ClickHouse/issues/81716). [#81805](https://github.com/ClickHouse/ClickHouse/pull/81805) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#82324](https://github.com/ClickHouse/ClickHouse/issues/82324) : dans les versions précédentes, le server renvoyait un contenu excessif pour les requêtes vers `/js`. Cela clôt [#61890](https://github.com/ClickHouse/ClickHouse/issues/61890). [#81895](https://github.com/ClickHouse/ClickHouse/pull/81895) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#82236](https://github.com/ClickHouse/ClickHouse/issues/82236) : auparavant, les définitions du moteur de table `MongoDB` pouvaient inclure un composant de chemin dans l’argument `host:port`, qui était ignoré silencieusement. L’intégration MongoDB refusait de charger de telles tables. Avec ce correctif, *nous autorisons le chargement de telles tables et ignorons le composant de chemin* si le moteur `MongoDB` a cinq arguments, en utilisant le nom de la base de données fourni dans les arguments. *Remarque :* le correctif ne s’applique pas aux tables nouvellement créées ni aux requêtes utilisant la fonction de table `mongo`, ni aux sources de dictionnaire et aux collections nommées. [#81942](https://github.com/ClickHouse/ClickHouse/pull/81942) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Rétroporté dans [#82098](https://github.com/ClickHouse/ClickHouse/issues/82098) : correction d’un possible crash dans `Aggregator` en cas d’exception pendant la fusion. [#82022](https://github.com/ClickHouse/ClickHouse/pull/82022) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#82552](https://github.com/ClickHouse/ClickHouse/issues/82552) : correction de LOGICAL&#95;ERROR et du crash qui s’ensuivait lors de l’utilisation de la même colonne dans le TTL pour GROUP BY et SET. [#82054](https://github.com/ClickHouse/ClickHouse/pull/82054) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#82154](https://github.com/ClickHouse/ClickHouse/issues/82154) : correction d’une erreur de copier-coller dans arraySimilarity, qui interdisait l’utilisation des poids UInt32 et Int32. Mise à jour des tests et de la documentation. [#82103](https://github.com/ClickHouse/ClickHouse/pull/82103) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#82318](https://github.com/ClickHouse/ClickHouse/issues/82318) : correction de l’erreur `Not found column` pour les requêtes avec `arrayJoin` sous la condition `WHERE` et `IndexSet`. [#82113](https://github.com/ClickHouse/ClickHouse/pull/82113) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#82262](https://github.com/ClickHouse/ClickHouse/issues/82262) : correction d’un bug dans l’intégration du catalogue Glue. Désormais, ClickHouse peut lire des tables avec des types de données imbriqués lorsque certaines sous-colonnes contiennent des valeurs décimales, par exemple : `map<string, decimal(9, 2)>`. Corrige [#81301](https://github.com/ClickHouse/ClickHouse/issues/81301). [#82114](https://github.com/ClickHouse/ClickHouse/pull/82114) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#82588](https://github.com/ClickHouse/ClickHouse/issues/82588) : correction d’un bug dans les dépendances de tables qui empêchait les vues matérialisées de prendre en compte les requêtes INSERT. [#82222](https://github.com/ClickHouse/ClickHouse/pull/82222) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#82523](https://github.com/ClickHouse/ClickHouse/issues/82523) : ajout d’une expiration au jeton AWS ECS afin qu’il puisse être rechargé. [#82422](https://github.com/ClickHouse/ClickHouse/pull/82422) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#82579](https://github.com/ClickHouse/ClickHouse/issues/82579) : correction du masquage des valeurs des collections nommées dans les logs/query&#95;log. Résout [#82405](https://github.com/ClickHouse/ClickHouse/issues/82405). [#82510](https://github.com/ClickHouse/ClickHouse/pull/82510) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#82570](https://github.com/ClickHouse/ClickHouse/issues/82570) : correction d’un plantage possible de la journalisation lors de la fermeture d’une session, car user&#95;id peut parfois être vide. [#82513](https://github.com/ClickHouse/ClickHouse/pull/82513) ([Bharat Nallan](https://github.com/bharatnc)).
