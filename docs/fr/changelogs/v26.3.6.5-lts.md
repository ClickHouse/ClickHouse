<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#102253](https://github.com/ClickHouse/ClickHouse/issues/102253) : ajout de métriques asynchrones pour la mémoire des tampons TCP du noyau en réception et en émission (`sk_rmem_alloc`, `sk_wmem_alloc`) des sockets du pool de connexions HTTP, présentées sous forme de percentiles p50/p75/p90/p95 et de totaux par groupe de connexions. [#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#102296](https://github.com/ClickHouse/ClickHouse/issues/102296) : correction d’une possible erreur logique lors de la lecture des sous-colonnes de type Map. Clôt [#100769](https://github.com/ClickHouse/ClickHouse/issues/100769). Clôt [#101336](https://github.com/ClickHouse/ClickHouse/issues/101336). [#101641](https://github.com/ClickHouse/ClickHouse/pull/101641) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#102267](https://github.com/ClickHouse/ClickHouse/issues/102267) : correction d’un bogue de concurrence SLRU dans le filesystem cache 26.1+, qui peut entraîner une erreur logique de réservation d’espace. Dans un build de débogage, cela peut aussi provoquer l’échec de l’assertion : `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#102174](https://github.com/ClickHouse/ClickHouse/issues/102174) : correction d’un plantage lors du rafraîchissement des UDF, causé par `ZooKeeperRetriesControl` qui réessayait sur une session ZooKeeper périmée (expirée) sans la renouveler. [#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)).
