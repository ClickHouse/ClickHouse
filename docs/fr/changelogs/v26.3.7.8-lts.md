<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#102314](https://github.com/ClickHouse/ClickHouse/issues/102314) : désactivation de la génération SQL par IA (commande `??`) dans le client intégré (protocoles SSH et WebSocket) afin d&#39;empêcher l&#39;accès aux variables d&#39;environnement du serveur. [#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#102340](https://github.com/ClickHouse/ClickHouse/issues/102340) : correction du redimensionnement des colonnes dans l&#39;interface web de play.html après la refactorisation de la table de résultats sous forme de composant web. [#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement erroné visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#102370](https://github.com/ClickHouse/ClickHouse/issues/102370) : corrige un bogue où ClickHouse pouvait ignorer des fichiers si l’en-tête `Content-Length` était absent de la réponse à leur requête HEAD (par exemple, à cause d’un transcodage décompressif dans GCS). [#99971](https://github.com/ClickHouse/ClickHouse/pull/99971) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Rétroporté dans [#101534](https://github.com/ClickHouse/ClickHouse/issues/101534) : certains catalogues peuvent afficher des secrets dans la section `SETTINGS` du résultat de la requête `select * from system.databases`. Cette PR empêche ce comportement. [#100800](https://github.com/ClickHouse/ClickHouse/pull/100800) ([Konstantin Vedernikov](https://github.com/scanhex12)).
* Rétroporté dans [#102436](https://github.com/ClickHouse/ClickHouse/issues/102436) : corrige une exception s’échappant du destructeur S3 `Client::~Client`, ce qui provoquait l’arrêt du serveur. [#101798](https://github.com/ClickHouse/ClickHouse/pull/101798) ([Gagan Dhakrey](https://github.com/gagandhakrey)).
* Rétroporté dans [#102279](https://github.com/ClickHouse/ClickHouse/issues/102279) : corrige un SIGSEGV dans `MergeTreeDataPartWriterWide::cancel` lorsqu’un constructeur de stream lève une exception pendant `addStreams`, laissant une entrée nulle dans `column_streams`. [#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#102240](https://github.com/ClickHouse/ClickHouse/issues/102240) : corrige un crash (SIGSEGV) lors d’une requête sur une vue avec une clause WHERE, lorsque la requête interne produit des colonnes de types différents de ceux des métadonnées de la vue (par ex. Nullable issu d’un LEFT JOIN avec `join_use_nulls`). [#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
