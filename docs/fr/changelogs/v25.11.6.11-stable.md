<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#92312](https://github.com/ClickHouse/ClickHouse/issues/92312) : Https://github.com/clickhouse/clickhouse/pull/84477 a ajouté des contraintes concernant les requêtes SELECT pouvant être utilisées dans les requêtes `insert select from s3cluster()` pour une exécution distribuée parallèle. Cette modification permet d&#39;utiliser `where`, ce qui était possible auparavant. [#84611](https://github.com/ClickHouse/ClickHouse/pull/84611) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#93375](https://github.com/ClickHouse/ClickHouse/issues/93375) : bascule vers une copie en lecture/écriture pour Azure Blob Storage lorsque la copie native échoue avec BadRequest (par ex. liste de blocs invalide). Auparavant, cela n’était fait que pour l’erreur Unauthorized, observée lors de la copie d’un blob entre différents comptes de stockage. Mais nous constatons aussi parfois l’erreur &quot;The specified block list is invalid&quot;. La condition a donc été mise à jour pour basculer vers la lecture/écriture lors de tout échec de copie native. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#93336](https://github.com/ClickHouse/ClickHouse/issues/93336) : prise en charge du type Geometry pour `flipCoordinates`. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#93123](https://github.com/ClickHouse/ClickHouse/issues/93123) : remanie la logique incorrecte des vérifications de privilèges d’accès pour les privilèges avec caractères génériques. La tentative précédente [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) corrigeait une vulnérabilité critique, mais s’est finalement révélée trop restrictive, ce qui faisait échouer certaines instructions `GRANT` avec caractères génériques à cause de révocations sans lien. [#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#93222](https://github.com/ClickHouse/ClickHouse/issues/93222) : corrige la création de l’indication de type pour le chemin &#39;skip&#39; dans JSON. Clôt [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731). [#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93182](https://github.com/ClickHouse/ClickHouse/issues/93182) : corrige l’erreur FILE&#95;DOESNT&#95;EXIST pouvant survenir après la mutation d’une colonne sparse lorsque le paramètre `ratio_of_defaults_for_sparse_serialization` a été modifié à `1.0` via ALTER. [#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#93046](https://github.com/ClickHouse/ClickHouse/issues/93046) : corrige un bogue dans la logique de data skipping lorsque `not materialize(...)` ou `not CAST(...)` est utilisé dans WHERE, ce qui provoque des résultats incorrects. Clôt [#88536](https://github.com/ClickHouse/ClickHouse/issues/88536). [#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Rétroporté dans [#93057](https://github.com/ClickHouse/ClickHouse/issues/93057) : corrige un problème où la connexion restait dans un état défaillant après l’annulation préliminaire de requêtes distribuées. [#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#93311](https://github.com/ClickHouse/ClickHouse/issues/93311) : supprime les colonnes inutilisées lorsque la projection est reconstruite pendant la fusion. Cela réduit l’utilisation de la mémoire et crée moins de parts temporaires. [#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
