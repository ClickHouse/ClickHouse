* Rétroporté dans [#83209](https://github.com/ClickHouse/ClickHouse/issues/83209) : correction d’une dégradation des performances dans SummingMergeTree introduite en 25.5 dans [https://github.com/ClickHouse/ClickHouse/pull/79051](https://github.com/ClickHouse/ClickHouse/pull/79051). [#82130](https://github.com/ClickHouse/ClickHouse/pull/82130) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#83199](https://github.com/ClickHouse/ClickHouse/issues/83199) : ne pas vérifier les dépendances cycliques lors de la création d’une table sans dépendances. Cela corrige une dégradation des performances dans les cas d’utilisation impliquant la création de milliers de tables, introduite dans [https://github.com/ClickHouse/ClickHouse/pull/65405](https://github.com/ClickHouse/ClickHouse/pull/65405). [#83077](https://github.com/ClickHouse/ClickHouse/pull/83077) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#83473](https://github.com/ClickHouse/ClickHouse/issues/83473) : correction d’un crash possible du type Variant dans UNION. [#83295](https://github.com/ClickHouse/ClickHouse/pull/83295) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#83764](https://github.com/ClickHouse/ClickHouse/issues/83764) : correctif dans Keeper : mise à jour correcte du nombre total de watch lors de la suppression de nœuds éphémères à la fermeture de la session. [#83583](https://github.com/ClickHouse/ClickHouse/pull/83583) ([Antonio Andelic](https://github.com/antonio2368)).
