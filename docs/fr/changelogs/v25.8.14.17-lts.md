La tentative précédente [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) corrigeait une vulnérabilité critique, mais s’est révélée trop restrictive, ce qui a entraîné l’échec de certaines instructions `GRANT` avec caractères génériques en raison d’instructions `REVOKE` sans rapport. [#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#92984](https://github.com/ClickHouse/ClickHouse/issues/92984) : évite un crash dû à la lecture depuis une `Connection` déconnectée. [#92807](https://github.com/ClickHouse/ClickHouse/pull/92807) ([Raufs Dunamalijevs](https://github.com/rienath)).
* Rétroporté dans [#92939](https://github.com/ClickHouse/ClickHouse/issues/92939) : correction de l’utilisation de l’index primaire dans les mises à jour légères comportant une clause `IN` avec des sous-requêtes dans le prédicat de la clause `WHERE`. [#92838](https://github.com/ClickHouse/ClickHouse/pull/92838) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#93220](https://github.com/ClickHouse/ClickHouse/issues/93220) : correction de la création de l’annotation de type pour le chemin &#39;skip&#39; dans JSON. Clôt [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731). [#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#92930](https://github.com/ClickHouse/ClickHouse/issues/92930) : correction de l’inférence de schéma Parquet dans l’ancien lecteur Parquet (non utilisé par défaut) lorsqu’une colonne JSON suit une colonne Tuple. Correction de l’échec de l’ancien lecteur Parquet (non utilisé par défaut) sur des tuples vides. * Rétroporté dans [#93178](https://github.com/ClickHouse/ClickHouse/issues/93178) : correction d’une possible erreur FILE&#95;DOESNT&#95;EXIST après une mutation sur une colonne sparse lorsque le paramètre `ratio_of_defaults_for_sparse_serialization` a été modifié à `1.0` via `ALTER`. [#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).

* Rétroporté dans [#93053](https://github.com/ClickHouse/ClickHouse/issues/93053) : correction d’un problème où la connexion restait dans un état défaillant après l’annulation préliminaire de requêtes distribuées. [#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)).

Cela réduit l’utilisation de la mémoire et crée moins de parties temporaires. [#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
