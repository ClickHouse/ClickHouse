<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#98402](https://github.com/ClickHouse/ClickHouse/issues/98402) : la fonction de table `loop` appelait directement `inner_storage->read()`, en contournant la couche d’interpréteur où sont appliquées les politiques de lignes, les privilèges au niveau des colonnes et les autres contrôles de sécurité. Cela permettait à un utilisateur soumis à des politiques de lignes de lire toutes les lignes via `loop(table)`, même lorsqu’un SELECT direct ne renvoyait aucune ligne. [#97682](https://github.com/ClickHouse/ClickHouse/pull/97682) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#98310](https://github.com/ClickHouse/ClickHouse/issues/98310) : correction d’un résultat incorrect pour les requêtes FINAL lorsqu’elles combinaient des index de saut sur clé primaire et hors clé primaire. [#98097](https://github.com/ClickHouse/ClickHouse/pull/98097) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#98352](https://github.com/ClickHouse/ClickHouse/issues/98352) : définit le composant `Watch` pour les réponses watch dans `aggregated_zookeeper_log` au lieu de le laisser vide. [#98202](https://github.com/ClickHouse/ClickHouse/pull/98202) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#98326](https://github.com/ClickHouse/ClickHouse/issues/98326) : correction d’un accès hors limites dans `ColumnConst::getExtremes` qui pouvait provoquer un plantage lorsque `extremes = 1` est activé. [#98263](https://github.com/ClickHouse/ClickHouse/pull/98263) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#98388](https://github.com/ClickHouse/ClickHouse/issues/98388) : correction de l’exception LOGICAL&#95;ERROR « Invalid binary search result in `MergeTreeSetIndex` », déclenchée par une conversion `toDate` sur des colonnes clés contenant des données franchissant la limite de 65535. [#98276](https://github.com/ClickHouse/ClickHouse/pull/98276) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
