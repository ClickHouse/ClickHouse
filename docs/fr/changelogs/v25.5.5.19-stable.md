<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#82594](https://github.com/ClickHouse/ClickHouse/issues/82594) : amélioration de Keeper : ajout de la nouvelle configuration `keeper_server.cleanup_old_and_ignore_new_acl`. Si elle est activée, les ACL de tous les nœuds seront effacées, tandis que les ACL des nouvelles requêtes seront ignorées. Si l’objectif est de supprimer complètement les ACL des nœuds, il est important de laisser cette configuration activée jusqu’à la création d’un nouveau snapshot. [#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#82860](https://github.com/ClickHouse/ClickHouse/issues/82860) : après [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834), les formats des en-têtes `X-ClickHouse-Progress` et `X-ClickHouse-Summary` ont été modifiés pour omettre les valeurs nulles. Cette PR vise à rétablir le comportement précédent uniquement pour `X-ClickHouse-Summary`, car c’est plus cohérent. [#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#82926](https://github.com/ClickHouse/ClickHouse/issues/82926) : amélioration de Keeper : prise en charge d’autorisations spécifiques pour l’ACL world:anyone. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correctif de bug (comportement incorrect visible par l&#39;utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#82779](https://github.com/ClickHouse/ClickHouse/issues/82779) : correction de l&#39;analyse des filtres lorsqu&#39;une seule colonne d&#39;alias constante est utilisée dans la requête. Corrige [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448). [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#82559](https://github.com/ClickHouse/ClickHouse/issues/82559) : correction d&#39;un interblocage possible pour les requêtes distantes lorsque le serveur subit une pression mémoire. [#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* Rétroporté dans [#82688](https://github.com/ClickHouse/ClickHouse/issues/82688) : correction de `LOGICAL_ERROR` lors de l&#39;analyse des expressions de politique de lignes pour les colonnes corrélées. [#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#82735](https://github.com/ClickHouse/ClickHouse/issues/82735) : les fonctions `trim{Left,Right,Both}` prennent désormais en charge les chaînes d&#39;entrée de type &quot;FixedString(N)&quot;. Par exemple, `SELECT trimBoth(toFixedString('abc', 3), 'ac')` fonctionne désormais. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#82800](https://github.com/ClickHouse/ClickHouse/issues/82800) : correction de la désérialisation de `groupArraySample`/`groupArrayLast` en cas d&#39;éléments vides (la désérialisation pouvait ignorer une partie du binaire si l&#39;entrée était vide, ce qui peut entraîner une corruption lors de la lecture des données ainsi que UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER dans le protocole TCP). Cela n&#39;affecte pas les nombres ni les types date-heure. [#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
