<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#79981](https://github.com/ClickHouse/ClickHouse/issues/79981) : correction de la désérialisation des discriminateurs de Variant avec le format de base dans les parties compactes. Cela a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/55518](https://github.com/ClickHouse/ClickHouse/pull/55518). [#79000](https://github.com/ClickHouse/ClickHouse/pull/79000) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#79715](https://github.com/ClickHouse/ClickHouse/issues/79715) : correction de l’utilisation de chemins incorrects lors du renommage d’une base de données Atomic. [#79569](https://github.com/ClickHouse/ClickHouse/pull/79569) ([Tuan Pham Anh](https://github.com/tuanpach)).
* Rétroporté dans [#80049](https://github.com/ClickHouse/ClickHouse/issues/80049) : corrige le résultat de la fonction SQL `formatDateTime` si un spécificateur de format à taille variable (par ex. `%W`, alias le jour de la semaine `Monday` `Tuesday`, etc.) est suivi d’un spécificateur de format composé (un spécificateur qui affiche plusieurs composants à la fois, par ex. `%D`, alias la date américaine `05/04/25`). [#79835](https://github.com/ClickHouse/ClickHouse/pull/79835) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#80113](https://github.com/ClickHouse/ClickHouse/issues/80113) : IcebergS3 prend en charge l’optimisation de count, mais pas IcebergS3Cluster. Par conséquent, le résultat de count() renvoyé en mode cluster peut être un multiple du nombre de répliques. [#79844](https://github.com/ClickHouse/ClickHouse/pull/79844) ([wxybear](https://github.com/wxybear)).
* Rétroporté dans [#80078](https://github.com/ClickHouse/ClickHouse/issues/80078) : permet aux vues matérialisées avec des UNION de fonctionner correctement sur les nouvelles répliques. [#80037](https://github.com/ClickHouse/ClickHouse/pull/80037) ([Samay Sharma](https://github.com/samay-sharma)).
* Rétroporté dans [#80185](https://github.com/ClickHouse/ClickHouse/issues/80185) : corrige les avertissements `Cannot find 'kernel' in '[...]/memory.stat'` dans le journal de ClickHouse (ticket [#77410](https://github.com/ClickHouse/ClickHouse/issues/77410)). [#80129](https://github.com/ClickHouse/ClickHouse/pull/80129) ([Robert Schulze](https://github.com/rschu1ze)).
