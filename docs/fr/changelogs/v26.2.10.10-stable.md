<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#102251](https://github.com/ClickHouse/ClickHouse/issues/102251) : ajout de métriques asynchrones pour la mémoire des tampons TCP de réception et d’émission du noyau (`sk_rmem_alloc`, `sk_wmem_alloc`) des sockets du pool de connexions HTTP, présentées sous forme de percentiles p50/p75/p90/p95 et de totaux par groupe de connexions. [#100575](https://github.com/ClickHouse/ClickHouse/pull/100575) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#102324](https://github.com/ClickHouse/ClickHouse/issues/102324) : désactivation de la génération SQL par IA (commande `??`) dans le client intégré (protocoles SSH et WebSocket) afin d&#39;empêcher l&#39;accès aux variables d&#39;environnement du serveur. [#100290](https://github.com/ClickHouse/ClickHouse/pull/100290) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#102339](https://github.com/ClickHouse/ClickHouse/issues/102339) : correction du redimensionnement des colonnes dans l&#39;interface web play.html après la refactorisation de la table de résultats en composant web. [#101295](https://github.com/ClickHouse/ClickHouse/pull/101295) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#101947](https://github.com/ClickHouse/ClickHouse/issues/101947) : optimisation du chargement du cache au démarrage du serveur. [#101500](https://github.com/ClickHouse/ClickHouse/pull/101500) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#102138](https://github.com/ClickHouse/ClickHouse/issues/102138) : mise à jour du `mongo-c-driver` interne de 2.2.2 à 2.2.3. [#101655](https://github.com/ClickHouse/ClickHouse/pull/101655) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#102277](https://github.com/ClickHouse/ClickHouse/issues/102277) : corrige un SIGSEGV dans `MergeTreeDataPartWriterWide::cancel` lorsqu’un constructeur de flux lève une exception pendant `addStreams`, laissant une entrée NULL dans `column_streams`. [#101936](https://github.com/ClickHouse/ClickHouse/pull/101936) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#102265](https://github.com/ClickHouse/ClickHouse/issues/102265) : corrige une condition de concurrence SLRU dans le filesystem cache 26.1+, qui peut entraîner une logical error de réservation d’espace. Dans une build de débogage, cela peut aussi provoquer l’échec de l’assertion : `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#102172](https://github.com/ClickHouse/ClickHouse/issues/102172) : corrige un crash lors du refresh d’une UDF causé par `ZooKeeperRetriesControl`, qui effectue un retry sur une session ZooKeeper stale (expirée) sans la renouveler. [#102059](https://github.com/ClickHouse/ClickHouse/pull/102059) ([Nikita Fomichev](https://github.com/fm4v)).
* Rétroporté dans [#102237](https://github.com/ClickHouse/ClickHouse/issues/102237) : corrige un crash (SIGSEGV) lors de l’exécution d’une requête sur une vue avec une clause WHERE, lorsque la requête interne produit des colonnes de types différents de ceux des métadonnées de la vue (par ex. Nullable issu d’un LEFT JOIN avec `join_use_nulls`). [#102085](https://github.com/ClickHouse/ClickHouse/pull/102085) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
