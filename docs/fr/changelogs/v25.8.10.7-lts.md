<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#88224](https://github.com/ClickHouse/ClickHouse/issues/88224) : corrige un crash où certaines données valides soumises par l’utilisateur dans une colonne `AggregateFunction(quantileDD)` pouvaient provoquer une récursion infinie des merges. [#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* Rétroporté dans [#88174](https://github.com/ClickHouse/ClickHouse/issues/88174) : corrige une possible exception non gérée lors de la lecture de `system.tables` avec des bases de données externes (`PostgreSQL`/`SQLite`/...) attachées contenant des tables invalides. [#88105](https://github.com/ClickHouse/ClickHouse/pull/88105) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88256](https://github.com/ClickHouse/ClickHouse/issues/88256) : désormais, les requêtes `ON CLUSTER` prendront moins de temps en cas de répliques inactives dans le cluster. [#88153](https://github.com/ClickHouse/ClickHouse/pull/88153) ([alesapin](https://github.com/alesapin)).
