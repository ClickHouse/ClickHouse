  ### Version de ClickHouse v26.1.12.23-stable (e5aa07a1b9a) FIXME par rapport à v26.1.11.9-stable (1784404a5ac)
</div>

<div id="backward-incompatible-change">
  #### Changement non rétrocompatible
</div>

* Rétroporté dans [#103351](https://github.com/ClickHouse/ClickHouse/issues/103351) : réduction de `http_max_fields` par défaut de 1 000 000 à 1 000 et de `http_max_field_name_size` de 128 KB à 4 KB afin de limiter l’utilisation de la mémoire avant l’authentification par les connexions HTTP. Ajout des paramètres `http_max_request_header_size` et `http_headers_read_timeout`. Les utilisateurs qui s’appuient sur les anciennes limites plus élevées peuvent les rétablir via les paramètres. [#103285](https://github.com/ClickHouse/ClickHouse/pull/103285) ([Sema Checherinda](https://github.com/CheSema)).

<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#103501](https://github.com/ClickHouse/ClickHouse/issues/103501) : ajout des métriques d’histogramme `s3_read_request_duration_microseconds` et `s3_read_request_bytes` pour observer la durée de connexion des requêtes GET vers S3 ainsi que le volume d’octets consommés, visibles dans `system.histogram_metrics` et sur l’endpoint Prometheus. [#102058](https://github.com/ClickHouse/ClickHouse/pull/102058) ([Sema Checherinda](https://github.com/CheSema)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#103196](https://github.com/ClickHouse/ClickHouse/issues/103196) : exposition de `untracked_memory` par thread dans system.stack&#95;trace. [#103065](https://github.com/ClickHouse/ClickHouse/pull/103065) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#103378](https://github.com/ClickHouse/ClickHouse/issues/103378) : application de `max_network_bandwidth_for_user`/`max_network_bandwidth_for_all_users` aux lectures/écritures sur le système de fichiers distant. [#103080](https://github.com/ClickHouse/ClickHouse/pull/103080) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (anomalie visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#103374](https://github.com/ClickHouse/ClickHouse/issues/103374) : correction d’un crash (`Logical error: isConst/isSparse/isReplicated assertTypeEquality`) dans les algorithmes de merge lorsque la réplication paresseuse des colonnes (`enable_lazy_columns_replication`) produit des colonnes `ColumnReplicated` qui se retrouvent dans des pipelines de tri par fusion avec des entrées arrivant tardivement. [#101036](https://github.com/ClickHouse/ClickHouse/pull/101036) ([Groene AI](https://github.com/groeneai)).
* Rétroporté dans [#103185](https://github.com/ClickHouse/ClickHouse/issues/103185) : correction de l’utilisation de bornes min-max erronées dans un index min-max créé sur une colonne JSON, ce qui entraînait un résultat de la requête incorrect. Clôt [#101700](https://github.com/ClickHouse/ClickHouse/issues/101700). [#101918](https://github.com/ClickHouse/ClickHouse/pull/101918) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#103146](https://github.com/ClickHouse/ClickHouse/issues/103146) : correction d’une exception `LOGICAL_ERROR` lorsque plusieurs requêtes concurrentes `CREATE TABLE IF NOT EXISTS` ciblent la même table `S3Queue` dans une Shared database. [#102610](https://github.com/ClickHouse/ClickHouse/pull/102610) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#103003](https://github.com/ClickHouse/ClickHouse/issues/103003) : correction d’une exception du serveur dans ClusterDiscovery lorsqu’un cluster statique (défini dans la configuration) n’avait temporairement aucun nœud actif. [#102661](https://github.com/ClickHouse/ClickHouse/pull/102661) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#102970](https://github.com/ClickHouse/ClickHouse/issues/102970) : correction d’une inférence erronée du type de données de date en cas de dépassement après ajustement du fuseau horaire. Clôt [#102601](https://github.com/ClickHouse/ClickHouse/issues/102601). [#102674](https://github.com/ClickHouse/ClickHouse/pull/102674) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#103302](https://github.com/ClickHouse/ClickHouse/issues/103302) : correction de la sérialisation du type Dynamic aplati avec des types de données encodés en binaire. Clôt [#101911](https://github.com/ClickHouse/ClickHouse/issues/101911). [#102692](https://github.com/ClickHouse/ClickHouse/pull/102692) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#103493](https://github.com/ClickHouse/ClickHouse/issues/103493) : correction des requêtes S3 qui échouaient avec `ios_base::clear: unspecified iostream_category error` au lieu d’être retentées, car `BufferedStreamBuf::flushBuffer` de Poco ne gérait pas les écritures courtes de la couche socket. [#102894](https://github.com/ClickHouse/ClickHouse/pull/102894) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#103224](https://github.com/ClickHouse/ClickHouse/issues/103224) : correction d’un problème où les optimisations `minmax_count_projection` et triviales de `COUNT(*)` restaient désactivées de manière permanente après un lightweight delete, même après la fusion de toutes les parts portant un masque de lightweight delete. [#102900](https://github.com/ClickHouse/ClickHouse/pull/102900) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#103020](https://github.com/ClickHouse/ClickHouse/issues/103020) : optimisation des chaînes de OR dans les ROW POLICY en IN dans le nouvel analyzer. [#102915](https://github.com/ClickHouse/ClickHouse/pull/102915) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#103237](https://github.com/ClickHouse/ClickHouse/issues/103237) : les INSERT simples sans vues matérialisées ne demandent plus un nombre excessif de slots et de threads à ConcurrencyControl (`max_threads` au lieu de `max_insert_threads`), évitant la famine de slots CC et l’explosion du nombre de threads sur les clusters à fort débit d’INSERT. [#102961](https://github.com/ClickHouse/ClickHouse/pull/102961) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#103326](https://github.com/ClickHouse/ClickHouse/issues/103326) : masquer la clé secrète dans la fonction SQL `HMAC`. Corrige [#102927](https://github.com/ClickHouse/ClickHouse/issues/102927). [#102997](https://github.com/ClickHouse/ClickHouse/pull/102997) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#103201](https://github.com/ClickHouse/ClickHouse/issues/103201) : réintroduire ArrowMemoryPool pour permettre de lever MEMORY&#95;LIMIT&#95;EXCEEDED et ainsi éviter un OOM du noyau. [#102999](https://github.com/ClickHouse/ClickHouse/pull/102999) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#103359](https://github.com/ClickHouse/ClickHouse/issues/103359) : limiter à 64 KB les chaînes du paquet TCP Hello de pré-authentification et ajouter le server setting `handshake_timeout_milliseconds` pour limiter la durée totale de la négociation initiale, afin d&#39;empêcher des clients non authentifiés de consommer trop de mémoire ou de monopoliser des threads indéfiniment. [#103284](https://github.com/ClickHouse/ClickHouse/pull/103284) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#103650](https://github.com/ClickHouse/ClickHouse/issues/103650) : corriger min&#95;value &gt; max&#95;value dans les statistiques de ColumnIndex de Parquet pour les colonne de type String. [#103334](https://github.com/ClickHouse/ClickHouse/pull/103334) ([Saurabh Kumar Ojha](https://github.com/saurabhojha)).
* Rétroporté dans [#103410](https://github.com/ClickHouse/ClickHouse/issues/103410) : vérifier les données Dynamic aplaties mal formées dans le format Native. [#103392](https://github.com/ClickHouse/ClickHouse/pull/103392) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#103635](https://github.com/ClickHouse/ClickHouse/issues/103635) : renseigner la colonne `_time` à partir de la table function `url`. [#103437](https://github.com/ClickHouse/ClickHouse/pull/103437) ([Nikita Taranov](https://github.com/nickitat)).
