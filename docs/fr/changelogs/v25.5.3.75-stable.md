<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#81179](https://github.com/ClickHouse/ClickHouse/issues/81179) : désormais, `system.iceberg_history` affiche l’historique des bases de données de catalogues comme Glue ou Iceberg REST. Les colonnes `table_name` et `database_name` y ont également été renommées en `table` et `database` pour plus de cohérence. [#80975](https://github.com/ClickHouse/ClickHouse/pull/80975) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#81230](https://github.com/ClickHouse/ClickHouse/issues/81230) : mise à niveau de libarchive vers 3.7.9 pour corriger les problèmes suivants : CVE-2024-20696 CVE-2025-25724 CVE-2024-48958 CVE-2024-57970 CVE-2025-1632 CVE-2024-48957 CVE-2024-48615. [#81174](https://github.com/ClickHouse/ClickHouse/pull/81174) ([larryluogit](https://github.com/larryluogit)).
* Rétroporté dans [#81538](https://github.com/ClickHouse/ClickHouse/issues/81538) : mise à niveau de libxml2 vers 2.14.3. [#81187](https://github.com/ClickHouse/ClickHouse/pull/81187) ([larryluogit](https://github.com/larryluogit)).
* Rétroporté dans [#81317](https://github.com/ClickHouse/ClickHouse/issues/81317) : MemoryResidentWithoutPageCache fournit la quantité de mémoire physique utilisée par le processus serveur, hors userspace page cache, en octets. Cela offre une vue plus précise de l’utilisation réelle de la mémoire lorsque l’userspace page cache est utilisé. Lorsque l’userspace page cache est désactivé, cette valeur est égale à MemoryResident. [#81233](https://github.com/ClickHouse/ClickHouse/pull/81233) ([Jayme Bird](https://github.com/jaymebrd)).
* Rétroporté dans [#81411](https://github.com/ClickHouse/ClickHouse/issues/81411) : dans un système de fichiers avec journal, `mkdir` est inscrit dans le journal du système de fichiers, lui-même persisté sur disque. En cas de disque lent, cela peut prendre beaucoup de temps. Il est donc tout à fait pertinent de le sortir de la portée du verrou de réservation. [#81371](https://github.com/ClickHouse/ClickHouse/pull/81371) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#81488](https://github.com/ClickHouse/ClickHouse/issues/81488) : utilisation de `krb5` 1.21.3-final. [#81453](https://github.com/ClickHouse/ClickHouse/pull/81453) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#81480](https://github.com/ClickHouse/ClickHouse/issues/81480) : utilisation de `orc` 2.1.2. [#81455](https://github.com/ClickHouse/ClickHouse/pull/81455) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#81668](https://github.com/ClickHouse/ClickHouse/issues/81668) : lecture des fichiers manifestes Iceberg reportée jusqu’à la première requête de lecture. [#81619](https://github.com/ClickHouse/ClickHouse/pull/81619) ([Daniil Ivanik](https://github.com/divanik)).
* Rétroporté dans [#81803](https://github.com/ClickHouse/ClickHouse/issues/81803) : ajout de l’événement de profil `PageCacheReadBytes`. [#81742](https://github.com/ClickHouse/ClickHouse/pull/81742) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#81932](https://github.com/ClickHouse/ClickHouse/issues/81932) : tentative de correction d’une erreur logique dans le cache du système de fichiers : &quot;Having zero bytes but range is not finished&quot;. [#81868](https://github.com/ClickHouse/ClickHouse/pull/81868) ([Kseniia Sumarokova](https://github.com/kssenii)).
