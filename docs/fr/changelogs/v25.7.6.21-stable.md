  ### Version de ClickHouse v25.7.6.21-stable (a81134c5c92) FIXME par rapport à v25.7.5.34-stable (a031c88152d)
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#86504](https://github.com/ClickHouse/ClickHouse/issues/86504) : ajout de la possibilité d’activer la journalisation JSON uniquement pour un canal donné ; pour cela, définissez `logger.formatting.channel` sur l’une des valeurs suivantes : `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#86112](https://github.com/ClickHouse/ClickHouse/issues/86112) : l’utilisation de `distributed_depth` comme indicateur de *Cluster function était incorrecte et pouvait entraîner une duplication des données ; utilisez `client_info.collaborate_with_initiator` à la place. [#85734](https://github.com/ClickHouse/ClickHouse/pull/85734) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#86266](https://github.com/ClickHouse/ClickHouse/issues/86266) : correction d’une erreur logique lors d’une tentative de `CREATE ... AS (SELECT * FROM s3Cluster(...))` avec `DatabaseReplicated`. [#85904](https://github.com/ClickHouse/ClickHouse/pull/85904) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Rétroporté dans [#86163](https://github.com/ClickHouse/ClickHouse/issues/86163) : désormais, Unity Catalog ignorera les schémas comportant des types de données atypiques dans le cas des tables non-Delta. Corrige [#85699](https://github.com/ClickHouse/ClickHouse/issues/85699). [#85950](https://github.com/ClickHouse/ClickHouse/pull/85950) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#86291](https://github.com/ClickHouse/ClickHouse/issues/86291) : une exception était levée par une requête `FINAL` avec un skip index si la table (par ex. `ReplacingMergeTree`) était créée avec le paramètre `index_granularity_bytes = 0`. Ce problème est désormais corrigé. [#86147](https://github.com/ClickHouse/ClickHouse/pull/86147) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Rétroporté dans [#86308](https://github.com/ClickHouse/ClickHouse/issues/86308) : correction d’un crash en cas de blocs constants et non constants dans un même INSERT. [#86230](https://github.com/ClickHouse/ClickHouse/pull/86230) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#86348](https://github.com/ClickHouse/ClickHouse/issues/86348) : correction d’un crash pendant ALTER UPDATE Nullable(JSON). [#86281](https://github.com/ClickHouse/ClickHouse/pull/86281) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#86454](https://github.com/ClickHouse/ClickHouse/issues/86454) : correction d’un bug dans les vues matérialisées : une MV pouvait cesser de fonctionner si elle était créée, supprimée, puis recréée avec le même nom. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#86466](https://github.com/ClickHouse/ClickHouse/issues/86466) : correction d’une fuite de `MergesMutationsMemoryTracking` due aux tables `Buffer` et correction de `query_views_log` pour l’ingestion en streaming depuis `Kafka` (et autres). [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
