<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#82862](https://github.com/ClickHouse/ClickHouse/issues/82862) : après [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834), les formats d’en-tête `X-ClickHouse-Progress` et `X-ClickHouse-Summary` ont été modifiés pour omettre les valeurs égales à zéro. Cette PR vise à rétablir le comportement précédent uniquement pour `X-ClickHouse-Summary`, car cela a du sens. [#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#84037](https://github.com/ClickHouse/ClickHouse/issues/84037) : utiliser les informations du cgroup (le cas échéant, c.-à-d. si `memory_worker_use_cgroup` et les cgroups sont disponibles) pour ajuster le memory tracker (`memory_worker_correct_memory_tracker`). [#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correctif de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#83144](https://github.com/ClickHouse/ClickHouse/issues/83144) : ne pas utiliser de parties non liées d’un dictionnaire partagé dans la fonction `lowCardinalityKeys`. [#83118](https://github.com/ClickHouse/ClickHouse/pull/83118) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#83766](https://github.com/ClickHouse/ClickHouse/issues/83766) : correctif de Keeper : mise à jour correcte du nombre total de watch lorsque des nœuds éphémères sont supprimés à la fermeture de la session. [#83583](https://github.com/ClickHouse/ClickHouse/pull/83583) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#84109](https://github.com/ClickHouse/ClickHouse/issues/84109) : masquer les détails d’authentification du schema registry Avro afin qu’ils ne soient visibles ni par l’utilisateur ni dans les journaux. [#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#83917](https://github.com/ClickHouse/ClickHouse/issues/83917) : corrige le problème suivant : si une table MergeTree est créée avec `add_minmax_index_for_numeric_columns=1` ou `add_minmax_index_for_string_columns=1`, puis que l’index est matérialisé ultérieurement lors d’une opération ALTER, la base de données Replicated ne peut pas s’initialiser correctement sur une nouvelle replica. [#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#83874](https://github.com/ClickHouse/ClickHouse/issues/83874) : introduction d’un paramètre de rétrocompatibilité permettant au nouvel analyzer de référencer un alias externe dans la clause WITH en cas de conflit de noms. Corrige [#82700](https://github.com/ClickHouse/ClickHouse/issues/82700). [#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#84092](https://github.com/ClickHouse/ClickHouse/issues/84092) : lors d’une restauration à partir d’une sauvegarde, il se peut que l’utilisateur definer n’ait pas été sauvegardé, ce qui peut rendre toute la sauvegarde inutilisable. Pour corriger cela, la vérification des permissions lors de la création de la table cible pendant la restauration est reportée, et n’est effectuée qu’à l’exécution. [#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#84224](https://github.com/ClickHouse/ClickHouse/issues/84224) : autorise la référence à n’importe quelle table dans l’argument `view(...)` de la table function `remote` lorsque l’analyzer est activé. Corrige [#78717](https://github.com/ClickHouse/ClickHouse/issues/78717). Corrige [#79377](https://github.com/ClickHouse/ClickHouse/issues/79377). [#83844](https://github.com/ClickHouse/ClickHouse/pull/83844) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#84129](https://github.com/ClickHouse/ClickHouse/issues/84129) : corrige un bug rare où la query `MATERIALIZE COLUMN` pouvait entraîner la présence de fichiers inattendus dans `checksums.txt` et, à terme, de data parts detached. [#84007](https://github.com/ClickHouse/ClickHouse/pull/84007) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#84272](https://github.com/ClickHouse/ClickHouse/issues/84272) : corrige des résultats erronés lorsque le query condition cache est utilisé conjointement avec des CTE récursives (issue [#81506](https://github.com/ClickHouse/ClickHouse/issues/81506)). [#84026](https://github.com/ClickHouse/ClickHouse/pull/84026) ([zhongyuankai](https://github.com/zhongyuankai)).
* Rétroporté dans [#84288](https://github.com/ClickHouse/ClickHouse/issues/84288) : corrige un crash rare de ClickHouse lorsqu’une table a une projection, `lightweight_mutation_projection_mode = 'rebuild'`, et que l’utilisateur exécute un lightweight delete qui supprime TOUTES les lignes d’un block de la table. [#84158](https://github.com/ClickHouse/ClickHouse/pull/84158) ([alesapin](https://github.com/alesapin)).
