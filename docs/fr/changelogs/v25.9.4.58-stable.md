<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#88480](https://github.com/ClickHouse/ClickHouse/issues/88480) : utilisation du client de stockage S3 avec des paramètres spécifiques aux sauvegardes (par exemple, backup&#95;slow&#95;all&#95;threads&#95;after&#95;retryable&#95;s3&#95;error) pour les copies natives côté serveur vers une destination de sauvegarde. Rend s3&#95;slow&#95;all&#95;threads&#95;after&#95;retryable&#95;error obsolète. [#87660](https://github.com/ClickHouse/ClickHouse/pull/87660) ([Julia Kartseva](https://github.com/jkartseva)).
* Rétroporté dans [#88302](https://github.com/ClickHouse/ClickHouse/issues/88302) : mise à jour de l’Azure SDK pour inclure le correctif de `Content-Length` observé lors des opérations de copie et de création de container. [#88278](https://github.com/ClickHouse/ClickHouse/pull/88278) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#88783](https://github.com/ClickHouse/ClickHouse/issues/88783) : corrige une fuite de mémoire liée à `GLOBAL IN` ([https://github.com/ClickHouse/ClickHouse/issues/88615](https://github.com/ClickHouse/ClickHouse/issues/88615)). [#88617](https://github.com/ClickHouse/ClickHouse/pull/88617) ([pranavmehta94](https://github.com/pranavmehta94)).
* Rétroporté dans [#88766](https://github.com/ClickHouse/ClickHouse/issues/88766) : ajout d’une étape au script de post-installation pour `clickhouse-keeper`, afin d’activer le démarrage automatique au lancement du système. [#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (anomalie visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#88226](https://github.com/ClickHouse/ClickHouse/issues/88226) : corrige un plantage où certaines données valides soumises par l’utilisateur dans une colonne `AggregateFunction(quantileDD)` pouvaient entraîner une récursion infinie des fusions. [#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* Rétroporté dans [#88229](https://github.com/ClickHouse/ClickHouse/issues/88229) : corrige l’optimisation move-to-prewhere, qui ne fonctionnait pas en présence d’une row policy. Suite de [#85118](https://github.com/ClickHouse/ClickHouse/issues/85118). Clôt [#69777](https://github.com/ClickHouse/ClickHouse/issues/69777). Clôt [#83748](https://github.com/ClickHouse/ClickHouse/issues/83748). [#87303](https://github.com/ClickHouse/ClickHouse/pull/87303) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#88391](https://github.com/ClickHouse/ClickHouse/issues/88391) : dans AzureBlobStorage, mise à jour pour tenter d’abord une copie native, puis basculer en lecture/écriture en cas d’erreur &#39;Unauthroized&#39; (dans AzureBlobStorage, si les comptes de stockage de la source et de la destination sont différents, nous obtenons une erreur &#39;Unauthorized&#39;). Corrige également l’application de &quot;use&#95;native&#95;copy&quot; lorsqu’un point de terminaison est défini dans la configuration. [#87826](https://github.com/ClickHouse/ClickHouse/pull/87826) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#88692](https://github.com/ClickHouse/ClickHouse/issues/88692) : ne supprime pas les fonctions injectives de GROUP BY si les types des arguments ne sont pas autorisés dans GROUP BY. [#87958](https://github.com/ClickHouse/ClickHouse/pull/87958) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#88438](https://github.com/ClickHouse/ClickHouse/issues/88438) : corrige une élimination incorrecte des granules/partitions pour les clés basées sur DateTime lors de l’utilisation du paramètre `session_timezone` dans les requêtes. [#87987](https://github.com/ClickHouse/ClickHouse/pull/87987) ([Eduard Karacharov](https://github.com/korowa)).
* Rétroporté dans [#88422](https://github.com/ClickHouse/ClickHouse/issues/88422) : applique une normalisation d’URI avant l’évaluation de la vérification des grants introduite par [https://github.com/ClickHouse/ClickHouse/pull/84503](https://github.com/ClickHouse/ClickHouse/pull/84503). [#88089](https://github.com/ClickHouse/ClickHouse/pull/88089) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#88176](https://github.com/ClickHouse/ClickHouse/issues/88176) : corrige une possible exception non gérée lors de la lecture de `system.tables` avec des tables invalides dans des bases de données externes (`PostgreSQL`/`SQLite`/...) rattachées. [#88105](https://github.com/ClickHouse/ClickHouse/pull/88105) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88258](https://github.com/ClickHouse/ClickHouse/issues/88258) : désormais, les requêtes `ON CLUSTER` prendront moins de temps en présence de répliques inactives dans le cluster. [#88153](https://github.com/ClickHouse/ClickHouse/pull/88153) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#88208](https://github.com/ClickHouse/ClickHouse/issues/88208) : corrige l’exécution de ClickHouse sans cgroups (les cgroups étaient accidentellement devenus obligatoires pour les métriques asynchrones). [#88164](https://github.com/ClickHouse/ClickHouse/pull/88164) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88285](https://github.com/ClickHouse/ClickHouse/issues/88285) : corrige la propagation du drapeau `is_shared` dans `ColumnLowCardinality`. Cela peut entraîner un résultat de group-by erroné si une nouvelle valeur est insérée dans une colonne après que les valeurs de hachage ont déjà été précalculées et mises en cache dans le `ReverseIndex`. [#88213](https://github.com/ClickHouse/ClickHouse/pull/88213) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#88461](https://github.com/ClickHouse/ClickHouse/issues/88461) : corrige le paramètre de workload `max_cpu_share`. Il peut désormais être utilisé sans que le paramètre de workload `max_cpus` soit défini. [#88217](https://github.com/ClickHouse/ClickHouse/pull/88217) ([Neerav](https://github.com/neeravsalaria)).
* Rétroporté dans [#88338](https://github.com/ClickHouse/ClickHouse/issues/88338) : les sous-requêtes corrélées fonctionnent désormais avec les stockages objet. [#88290](https://github.com/ClickHouse/ClickHouse/pull/88290) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#88358](https://github.com/ClickHouse/ClickHouse/issues/88358) : évite de tenter d’initialiser des bases de données DataLake lors de l’accès à `system.projections` et `system.data_skipping_indices`. [#88330](https://github.com/ClickHouse/ClickHouse/pull/88330) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88432](https://github.com/ClickHouse/ClickHouse/issues/88432) : corrige la complexité quadratique de la fonction `countMatches`. Clôt [#88400](https://github.com/ClickHouse/ClickHouse/issues/88400). [#88401](https://github.com/ClickHouse/ClickHouse/pull/88401) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#88650](https://github.com/ClickHouse/ClickHouse/issues/88650) : les grands clusters de plus de 10 nœuds ont une forte probabilité d’échouer lors de la restauration avec l’erreur `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again`. Le nœud `num_hosts` est écrasé simultanément par de nombreux hôtes. Le correctif rend dynamique le paramètre qui contrôle le nombre de tentatives. Clôt [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721). [#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#88629](https://github.com/ClickHouse/ClickHouse/issues/88629) : corrige le moteur CoalescingMergeTree pour les types Tuple. Cela clôt [#88469](https://github.com/ClickHouse/ClickHouse/issues/88469). [#88526](https://github.com/ClickHouse/ClickHouse/pull/88526) ([scanhex12](https://github.com/scanhex12)).
* Rétroporté dans [#88718](https://github.com/ClickHouse/ClickHouse/issues/88718) : corrige un plantage potentiel causé par une mutation concurrente des colonnes const PREWHERE sous-jacentes. [#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#88837](https://github.com/ClickHouse/ClickHouse/issues/88837) : intercepte les exceptions lorsque la journalisation asynchrone échoue afin d’éviter l’arrêt du programme. [#88814](https://github.com/ClickHouse/ClickHouse/pull/88814) ([Raúl Marín](https://github.com/Algunenano)).
