<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions précédentes
</div>

* Vérifie que toutes les colonnes d&#39;une vue matérialisée correspondent à la table cible si `allow_materialized_view_with_bad_select` est `false`. [#74481](https://github.com/ClickHouse/ClickHouse/pull/74481) ([Christoph Wurm](https://github.com/cwurm)).
* Corrige les cas où `dateTrunc` est utilisé avec des arguments Date/DateTime négatifs. [#77622](https://github.com/ClickHouse/ClickHouse/pull/77622) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* L&#39;intégration MongoDB legacy a été supprimée. Le paramètre du serveur `use_legacy_mongodb_integration` est devenu obsolète et n&#39;a désormais plus aucun effet. [#77895](https://github.com/ClickHouse/ClickHouse/pull/77895) ([Robert Schulze](https://github.com/rschu1ze)).
* Améliore la validation de SummingMergeTree afin d&#39;ignorer l&#39;agrégation des colonnes utilisées dans les clés de partition ou de tri. [#78022](https://github.com/ClickHouse/ClickHouse/pull/78022) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).

* Désactivation de `filesystem_cache_prefer_bigger_buffer_size` lorsque le cache est utilisé passivement, par exemple pour les fusions. [#77898](https://github.com/ClickHouse/ClickHouse/pull/77898) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Implémentation d&#39;une optimisation triviale pour Iceberg sur `count()`. Désormais, les requêtes avec `count()` et sans aucun filtre devraient être plus rapides. Corrige [#77639](https://github.com/ClickHouse/ClickHouse/issues/77639). [#78090](https://github.com/ClickHouse/ClickHouse/pull/78090) ([alesapin](https://github.com/alesapin)).

* Optimisation triviale : ne pas réécrire count(if()) en countIf si CAST est requis. Clôt [#78564](https://github.com/ClickHouse/ClickHouse/issues/78564). [#78565](https://github.com/ClickHouse/ClickHouse/pull/78565) ([李扬](https://github.com/taiyang-li)).

[#78877](https://github.com/ClickHouse/ClickHouse/pull/78877) ([Dmitry Novik](https://github.com/novikd)).
