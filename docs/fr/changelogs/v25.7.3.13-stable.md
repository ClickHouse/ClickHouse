<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement erroné visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#85306](https://github.com/ClickHouse/ClickHouse/issues/85306) : correction d’ALTER MODIFY ORDER BY, qui ne validait pas les colonnes TTL dans les clés de tri. Les colonnes TTL sont désormais correctement rejetées lorsqu’elles sont utilisées dans des clauses ORDER BY lors d’opérations ALTER, ce qui évite une corruption potentielle de la table. [#84536](https://github.com/ClickHouse/ClickHouse/pull/84536) ([xiaohuanlin](https://github.com/xiaohuanlin)).
* Rétroporté dans [#85381](https://github.com/ClickHouse/ClickHouse/issues/85381) : correction du nettoyage des patch parts dans `ReplicatedMergeTree`. Auparavant, le résultat d’une lightweight update pouvait temporairement ne pas être visible sur la réplique tant que la part fusionnée ou mutée qui matérialise les patch parts n’avait pas été téléchargée depuis une autre réplique. [#85121](https://github.com/ClickHouse/ClickHouse/pull/85121) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#85246](https://github.com/ClickHouse/ClickHouse/issues/85246) : correction de illegal&#95;type&#95;of&#95;argument dans une MV lorsque les types diffèrent. [#85135](https://github.com/ClickHouse/ClickHouse/pull/85135) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#85236](https://github.com/ClickHouse/ClickHouse/issues/85236) : correction de `Not-ready Set` pour `IN (subquery)` dans le paramètre `additional_table_filters expression`. [#85210](https://github.com/ClickHouse/ClickHouse/pull/85210) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#85264](https://github.com/ClickHouse/ClickHouse/issues/85264) : suppression des appels `getStatus()` inutiles pendant les requêtes SYSTEM DROP REPLICA. Corrige le cas où une table est supprimée en arrière-plan et où l’exception `Shutdown for storage is called` est levée. [#85220](https://github.com/ClickHouse/ClickHouse/pull/85220) ([Nikolay Degterinsky](https://github.com/evillique)).
