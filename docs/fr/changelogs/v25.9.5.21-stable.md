<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#88511](https://github.com/ClickHouse/ClickHouse/issues/88511) : corrige la lecture d’une sous-colonne `Map` nulle depuis des `Variant` qui ne peuvent pas être dans `Nullable`. [#87798](https://github.com/ClickHouse/ClickHouse/pull/87798) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#88734](https://github.com/ClickHouse/ClickHouse/issues/88734) : une exception `Poco::TimeoutException` levée dans `Poco::Net::HTTPChunkedStreamBuf::readFromDevice` entraîne un plantage avec SIGABRT. [#88668](https://github.com/ClickHouse/ClickHouse/pull/88668) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#88908](https://github.com/ClickHouse/ClickHouse/issues/88908) : après récupération, un réplica d’une base de données Replicated peut rester bloqué longtemps en affichant des messages comme `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)` ; ce problème est corrigé. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#88892](https://github.com/ClickHouse/ClickHouse/issues/88892) : corrige la validation des accès sur select pour la fonction de table `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#88942](https://github.com/ClickHouse/ClickHouse/issues/88942) : corrige un bug dans la fonction `reverseUTF8`. Dans les versions précédentes, elle inversait par erreur les octets des points de code UTF-8 de longueur 4. Cela résout [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#88978](https://github.com/ClickHouse/ClickHouse/issues/88978) : ne vérifie pas le droit d’accès `SET DEFINER <current_user>:definer` lors de la création d’une vue avec SQL SECURITY DEFINER. [#88968](https://github.com/ClickHouse/ClickHouse/pull/88968) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#89083](https://github.com/ClickHouse/ClickHouse/issues/89083) : cela résout [#88081](https://github.com/ClickHouse/ClickHouse/issues/88081). [#88988](https://github.com/ClickHouse/ClickHouse/pull/88988) ([scanhex12](https://github.com/scanhex12)).
* Rétroporté dans [#89026](https://github.com/ClickHouse/ClickHouse/issues/89026) : corrige une dégradation des performances lors de l’analyse des skipping indexes. [#89004](https://github.com/ClickHouse/ClickHouse/pull/89004) ([Anton Popov](https://github.com/CurtizJ)).
