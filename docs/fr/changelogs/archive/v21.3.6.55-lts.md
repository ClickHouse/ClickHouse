<div id="clickhouse-release-v213655-lts-fixme-as-compared-to-v213542-lts">
  ### Version de ClickHouse v21.3.6.55-lts FIXME par rapport à v21.3.5.42-lts

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#22811](https://github.com/ClickHouse/ClickHouse/issues/22811) : si PODArray était instancié avec une taille d’élément qui n’était ni un diviseur ni un multiple de 16, un dépassement de tampon était possible. Aucun bug de ce type n’existe dans les versions actuelles. [#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22823](https://github.com/ClickHouse/ClickHouse/issues/22823) : ajout de l’événement de profil HedgedRequestsChangeReplica et modification du délai d’attente de lecture des données de sec en ms. [#21886](https://github.com/ClickHouse/ClickHouse/pull/21886) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#22936](https://github.com/ClickHouse/ClickHouse/issues/22936) : vérification correcte de la structure des blocs distribués asynchrones. [#22325](https://github.com/ClickHouse/ClickHouse/pull/22325) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#22968](https://github.com/ClickHouse/ClickHouse/issues/22968) : correction d&#39;un bug très rare où une insertion en quorum avec `quorum_parallel=1` n&#39;est pas réellement en « quorum » en raison de la déduplication. [#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22723](https://github.com/ClickHouse/ClickHouse/issues/22723) : vérifie si la table function view est utilisée comme colonne. Cela complète [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350). [#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#22807](https://github.com/ClickHouse/ClickHouse/issues/22807) : correctif complémentaire pour [#21936](https://github.com/ClickHouse/ClickHouse/issues/21936). Corrige également [#22433](https://github.com/ClickHouse/ClickHouse/issues/22433). [#22518](https://github.com/ClickHouse/ClickHouse/pull/22518) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#22759](https://github.com/ClickHouse/ClickHouse/issues/22759) : correction de l&#39;utilisation de la fonction `map` dans les requêtes distribuées. [#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* Rétroporté dans [#22701](https://github.com/ClickHouse/ClickHouse/issues/22701) : correction de l&#39;attente des mutations sur plusieurs répliques pour les moteurs de table ReplicatedMergeTree. Auparavant, une requête de mutation/alter pouvait se terminer avant que la mutation ne soit effectivement exécutée sur les autres répliques. [#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22738](https://github.com/ClickHouse/ClickHouse/issues/22738) : correction de blocages possibles dans les requêtes zk en cas d&#39;exception OOM. Corrige [#22438](https://github.com/ClickHouse/ClickHouse/issues/22438). [#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#22892](https://github.com/ClickHouse/ClickHouse/issues/22892) : correction du comptage approximatif du nombre total de lignes lors de la lecture inversée depuis MergeTree. [#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22922](https://github.com/ClickHouse/ClickHouse/issues/22922) : correction du pushdown de `HAVING` dans le cas où la colonne de filtre est utilisée dans l&#39;agrégation. [#22763](https://github.com/ClickHouse/ClickHouse/pull/22763) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#22916](https://github.com/ClickHouse/ClickHouse/issues/22916) : LIVE VIEW (fonctionnalité expérimentale). Correction d&#39;un blocage possible lors d&#39;opérations concurrentes DROP/CREATE sur TEMPORARY LIVE VIEW dans `TemporaryLiveViewCleaner`, voir [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e). [#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#22920](https://github.com/ClickHouse/ClickHouse/issues/22920) : correction d&#39;un plantage lors de l&#39;utilisation de `mannWhitneyUTest` et `rankCorr` avec des fonctions de fenêtre. Corrige [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728). [#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
