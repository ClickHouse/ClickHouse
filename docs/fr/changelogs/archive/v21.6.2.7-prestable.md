<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#24567](https://github.com/ClickHouse/ClickHouse/issues/24567) : utilisation de l’ancienne version de la fonction modulo lorsqu’elle est utilisée dans la clé de partitionnement. Clôt [#23508](https://github.com/ClickHouse/ClickHouse/issues/23508). [#24157](https://github.com/ClickHouse/ClickHouse/pull/24157) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#24367](https://github.com/ClickHouse/ClickHouse/issues/24367) : définir `max_threads = 1` pour corriger l’échec d’une mutation de StorageMemory. Clôt [#24274](https://github.com/ClickHouse/ClickHouse/issues/24274). [#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#24383](https://github.com/ClickHouse/ClickHouse/issues/24383) : autoriser les en-têtes HTTP vides. Corrige [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901). [#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#24365](https://github.com/ClickHouse/ClickHouse/issues/24365) : correction d’un bogue lors du déplacement d’une vue matérialisée d’une base de données Ordinary vers Atomic (requête `RENAME TABLE`). Désormais, la table interne est déplacée vers la nouvelle base de données en même temps que la vue matérialisée. Corrige [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926). [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#24510](https://github.com/ClickHouse/ClickHouse/issues/24510) : correction de la suppression de partition avec des parties factices d’intersection. Dans de rares cas, certaines parties peuvent avoir une version de mutation supérieure au numéro de bloc actuel. [#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#24542](https://github.com/ClickHouse/ClickHouse/issues/24542) : correction de la monotonie incorrecte de la fonction toWeek. Cela corrige [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422). Ce bogue a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212), puis révélé plus tard par un mécanisme d’élagage des partitions plus intelligent. [#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#24556](https://github.com/ClickHouse/ClickHouse/issues/24556) : correction du comportement lorsque la requête `SYSTEM RESTART REPLICA` ou `SYSTEM SYNC REPLICA` est traitée indéfiniment. Ce problème a été détecté sur un serveur disposant d’une quantité de RAM extrêmement faible. [#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#24597](https://github.com/ClickHouse/ClickHouse/issues/24597) : correction de l’utilisation des tuples dans les requêtes `CREATE .. AS SELECT`. [#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#24600](https://github.com/ClickHouse/ClickHouse/issues/24600) : activer la lecture des sous-colonnes pour les tables distribuées. [#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
