  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)

* Rétroporté dans [#34121](https://github.com/ClickHouse/ClickHouse/issues/34121) : correction de l’utilisation des fonctions `array` et `tuple` avec des arguments littéraux dans les requêtes distribuées. Auparavant, cela pouvait entraîner l’exception `Not found columns`. [#33938](https://github.com/ClickHouse/ClickHouse/pull/33938) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#34097](https://github.com/ClickHouse/ClickHouse/issues/34097) : correction d’un segfault lors de l’analyse d’un fichier ORC dont le footer est corrompu. Ferme [#33797](https://github.com/ClickHouse/ClickHouse/issues/33797). [#33984](https://github.com/ClickHouse/ClickHouse/pull/33984) ([Kruglov Pavel](https://github.com/Avogar)).
