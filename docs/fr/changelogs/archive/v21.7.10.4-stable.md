<div id="2022-changelog">
  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v217104-stable-fixme-as-compared-to-v21797-stable">
  ### Version de ClickHouse v21.7.10.4-stable FIXME par rapport à v21.7.9.7-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#28898](https://github.com/ClickHouse/ClickHouse/issues/28898) : utiliser un véritable fichier tmp au lieu du fichier prédéfini « rows&#95;sources » pour les fusions verticales. Cela évite de générer des répertoires parasites sur les disques tmp. [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#27925](https://github.com/ClickHouse/ClickHouse/issues/27925) : corrige le transtypage de style PostgreSQL (opérateur `::`) avec des nombres négatifs. [#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28752](https://github.com/ClickHouse/ClickHouse/issues/28752) : corrige la transformation d&#39;une chaîne de disjonctions en `IN` (contrôlée par le paramètre `optimize_min_equality_disjunction_chain_length`) dans les requêtes distribuées lorsque le paramètre `legacy_column_name_of_tuple_literal = 0`. [#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#28509](https://github.com/ClickHouse/ClickHouse/issues/28509) : correction d’une possible fuite de watches ZooKeeper lors du traitement en arrière-plan de la file d’attente DDL distribuée. Clôt [#26036](https://github.com/ClickHouse/ClickHouse/issues/26036). [#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#28570](https://github.com/ClickHouse/ClickHouse/issues/28570) : correction d’un bogue pouvant entraîner l’erreur `Existing table metadata in ZooKeeper differs in sorting key expression.` après une modification de `ReplicatedVersionedCollapsingMergeTree`. Corrige [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515). [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28598](https://github.com/ClickHouse/ClickHouse/issues/28598) : correction de l’erreur `There is no subcolumn` lors d’une requête `SELECT` sur des tables comportant des colonnes `Nested` et des colonnes scalaires avec un point dans leur nom et le même préfixe que `Nested` (par ex. `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`). [#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28742](https://github.com/ClickHouse/ClickHouse/issues/28742) : correction d’un coredump lors de la création de tables Distributed lorsque les paramètres fournis sont incorrects. [#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* Rétroporté dans [#28788](https://github.com/ClickHouse/ClickHouse/issues/28788) : correction d’une race condition bénigne dans ReplicatedMergeTreeQueue. Ne devrait pas être visible pour l’utilisateur, mais peut entraîner des bogues subtils. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28947](https://github.com/ClickHouse/ClickHouse/issues/28947) : correction de la lecture des sous-colonnes à partir de compact parts. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28931](https://github.com/ClickHouse/ClickHouse/issues/28931) : correction des fonctions Array d’ordre supérieur (`SIGSEGV` pour `arrayCompact`/`ILLEGAL_COLUMN` pour `arrayDifference`/`arrayCumSumNonNegative`) avec des constantes. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
