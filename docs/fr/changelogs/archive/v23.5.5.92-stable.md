<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#52749](https://github.com/ClickHouse/ClickHouse/issues/52749) : corrige une analyse incorrecte des projections, qui rend les clés primaires invalides. Ce problème n&#39;existe que lorsque `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1`. Cela corrige [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823). Cela corrige [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173). [#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### Améliorations de compilation, de tests et de packaging
</div>

* Rétroporté dans [#51886](https://github.com/ClickHouse/ClickHouse/issues/51886) : mise à jour des dépendances de Cargo. [#51721](https://github.com/ClickHouse/ClickHouse/pull/51721) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#52909](https://github.com/ClickHouse/ClickHouse/issues/52909) : ajout du lien symbolique `clickhouse-keeper-client` au paquet clickhouse-server. [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#53021](https://github.com/ClickHouse/ClickHouse/issues/53021) : l’empaquetage du cache intégré dans les images Docker provoque parfois d’étranges effets de bord. Comme nous ne l’utilisons pas du tout, il peut être retiré sans problème. [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#53289](https://github.com/ClickHouse/ClickHouse/issues/53289) : les données de profil du compilateur (`-ftime-trace`) sont téléversées vers ClickHouse Cloud, deuxième tentative après [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100). [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#53463](https://github.com/ClickHouse/ClickHouse/issues/53463) : préservation des paramètres d’environnement dans la commande `clickhouse start`. Corrige [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962). [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
