<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans la version stable officielle)
</div>

* Rétroporté dans [#38453](https://github.com/ClickHouse/ClickHouse/issues/38453) : correction d’un bogue dans les fonctions à court-circuit imbriquées qui entraînait l’exécution des arguments même si la condition est `false`. Clôt [#38040](https://github.com/ClickHouse/ClickHouse/issues/38040). [#38173](https://github.com/ClickHouse/ClickHouse/pull/38173) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#38710](https://github.com/ClickHouse/ClickHouse/issues/38710) : correction d’un résultat incorrect pour les requêtes distribuées avec `DISTINCT` et `LIMIT`. Corrige [#38282](https://github.com/ClickHouse/ClickHouse/issues/38282). [#38371](https://github.com/ClickHouse/ClickHouse/pull/38371) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#38689](https://github.com/ClickHouse/ClickHouse/issues/38689) : il est désormais possible de démarrer clickhouse-server et d’attacher/détacher des tables, même lorsque les valeurs de représentation IPv4/IPv6 sont incorrectes. Correctif adéquat pour l’issue [#35156](https://github.com/ClickHouse/ClickHouse/issues/35156). [#38590](https://github.com/ClickHouse/ClickHouse/pull/38590) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#38776](https://github.com/ClickHouse/ClickHouse/issues/38776) : la fonction `rankCorr` fonctionne désormais correctement si certains arguments sont des NaN. Cela clôt [#38396](https://github.com/ClickHouse/ClickHouse/issues/38396). [#38722](https://github.com/ClickHouse/ClickHouse/pull/38722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#38780](https://github.com/ClickHouse/ClickHouse/issues/38780) : correction d’un use-after-free dans le combinator Map, qui entraînait un résultat incorrect. [#38748](https://github.com/ClickHouse/ClickHouse/pull/38748) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogue (comportement incorrect visible pour l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#36818](https://github.com/ClickHouse/ClickHouse/issues/36818) : corrige l’analyse des projections, qui pouvait entraîner un résultat de la requête erroné lorsqu’une sous-requête `IN` est utilisée. Cela corrige [#35336](https://github.com/ClickHouse/ClickHouse/issues/35336). [#35631](https://github.com/ClickHouse/ClickHouse/pull/35631) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#38467](https://github.com/ClickHouse/ClickHouse/issues/38467) : - corrige une erreur potentielle liée aux littéraux dans `WHERE` pour les requêtes avec `JOIN`. Ferme [#36279](https://github.com/ClickHouse/ClickHouse/issues/36279). [#36542](https://github.com/ClickHouse/ClickHouse/pull/36542) ([Vladimir C](https://github.com/vdimir)).
