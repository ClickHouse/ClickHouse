<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#27976](https://github.com/ClickHouse/ClickHouse/issues/27976) : correction d’un bogue dans le mode &quot;strict&quot; de windowFunnel. Cela corrige [#27469](https://github.com/ClickHouse/ClickHouse/issues/27469). [#27563](https://github.com/ClickHouse/ClickHouse/pull/27563) ([achimbab](https://github.com/achimbab)).
* Rétroporté dans [#27780](https://github.com/ClickHouse/ClickHouse/issues/27780) : correction du filtrage de colonnes avec union distinct dans une sous-requête. Clôt [#27578](https://github.com/ClickHouse/ClickHouse/issues/27578). [#27689](https://github.com/ClickHouse/ClickHouse/pull/27689) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#27866](https://github.com/ClickHouse/ClickHouse/issues/27866) : évite des plantages avec certains formats lors de la réception d’un message NULL (tombstone) depuis Kafka. Clôt [#19255](https://github.com/ClickHouse/ClickHouse/issues/19255). [#27794](https://github.com/ClickHouse/ClickHouse/pull/27794) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#28347](https://github.com/ClickHouse/ClickHouse/issues/28347) : correction d’un bogue rare dans `DROP PART` pouvant entraîner l’erreur `Unexpected merged part intersects drop range`. [#27807](https://github.com/ClickHouse/ClickHouse/pull/27807) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#27955](https://github.com/ClickHouse/ClickHouse/issues/27955) : correction de la sélection avec extremes à partir d’une colonne de type `LowCardinality(UUID)`. [#27918](https://github.com/ClickHouse/ClickHouse/pull/27918) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#27951](https://github.com/ClickHouse/ClickHouse/issues/27951) : vérifie le nom du cluster avant de créer une table Distributed et interdit la création d’une table avec un nom de cluster incorrect. Corrige [#27832](https://github.com/ClickHouse/ClickHouse/issues/27832). [#27927](https://github.com/ClickHouse/ClickHouse/pull/27927) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#28208](https://github.com/ClickHouse/ClickHouse/issues/28208) : correction des cas où le buffer de lecture échoue avec &#39;attempt to read after end of file&#39;. Clôt [#26149](https://github.com/ClickHouse/ClickHouse/issues/26149). [#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### correction de bogues (comportement incorrect visible par les utilisateurs dans une version stable officielle)
</div>

* Rétroporté dans [#28116](https://github.com/ClickHouse/ClickHouse/issues/28116) : corrige des `segfault` extrêmement rares à l’arrêt, dus à un ordre incorrect lors de l’arrêt du recharger de contexte/configuration. [#28088](https://github.com/ClickHouse/ClickHouse/pull/28088) ([nvartolomei](https://github.com/nvartolomei)).
* Rétroporté dans [#28183](https://github.com/ClickHouse/ClickHouse/issues/28183) : corrige un nombre potentiellement excessif de conditions déplacées de `WHERE` vers `PREWHERE` (optimisation contrôlée par le paramètre `optimize_move_to_prewhere`). [#28139](https://github.com/ClickHouse/ClickHouse/pull/28139) ([lthaooo](https://github.com/lthaooo)).
* Rétroporté dans [#28255](https://github.com/ClickHouse/ClickHouse/issues/28255) : corrige un comportement incorrect de `clickhouse-keeper` lorsque des watches de liste (`getChildren`) sont déclenchées par des requêtes `set` sur des enfants. [#28190](https://github.com/ClickHouse/ClickHouse/pull/28190) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28265](https://github.com/ClickHouse/ClickHouse/issues/28265) : corrige une possible lecture de mémoire non initialisée pour des requêtes avec le type `Nullable(LowCardinality)` et des extrêmes. Corrige [#28165](https://github.com/ClickHouse/ClickHouse/issues/28165). [#28205](https://github.com/ClickHouse/ClickHouse/pull/28205) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#28288](https://github.com/ClickHouse/ClickHouse/issues/28288) : corrige la lecture d’un TLD personnalisé sans retour à la ligne en fin de fichier. [#28213](https://github.com/ClickHouse/ClickHouse/pull/28213) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#28295](https://github.com/ClickHouse/ClickHouse/issues/28295) : corrige un résultat incohérent dans des requêtes avec `ORDER BY` et des tables `Merge` lorsque le paramètre `optimize_read_in_order` est activé. [#28266](https://github.com/ClickHouse/ClickHouse/pull/28266) ([Anton Popov](https://github.com/CurtizJ)).
