<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#65096](https://github.com/ClickHouse/ClickHouse/issues/65096) : le paramètre `allow_experimental_join_condition` a été marqué à tort comme important, ce qui peut empêcher l’exécution correcte des requêtes distribuées dans un cluster composé de versions mixtes. [#65008](https://github.com/ClickHouse/ClickHouse/pull/65008) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#64729](https://github.com/ClickHouse/ClickHouse/issues/64729) : correction des requêtes `CREATE TABLE AS` pour les tables avec des expressions par défaut. [#64455](https://github.com/ClickHouse/ClickHouse/pull/64455) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#65061](https://github.com/ClickHouse/ClickHouse/issues/65061) : correction des erreurs `Expression nodes list expected 1 projection names` et `Unknown expression or identifier` pour les requêtes avec des alias vers `GLOBAL IN.` Corrige [#64445](https://github.com/ClickHouse/ClickHouse/issues/64445). [#64517](https://github.com/ClickHouse/ClickHouse/pull/64517) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#65088](https://github.com/ClickHouse/ClickHouse/issues/65088) : correction de la suppression des expressions `WHERE` et `PREWHERE`, toujours `true` (pour le nouvel analyzer). Corrige [#64575](https://github.com/ClickHouse/ClickHouse/issues/64575). [#64695](https://github.com/ClickHouse/ClickHouse/pull/64695) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#64944](https://github.com/ClickHouse/ClickHouse/issues/64944) : correction de OrderByLimitByDuplicateEliminationVisitor dans les sous-requêtes. [#64766](https://github.com/ClickHouse/ClickHouse/pull/64766) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#64873](https://github.com/ClickHouse/ClickHouse/issues/64873) : correction d’un possible suivi incorrect de la mémoire dans plusieurs types de requêtes : requêtes qui lisent des données depuis S3, requêtes via le protocole HTTP, asynchronous inserts. [#64844](https://github.com/ClickHouse/ClickHouse/pull/64844) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#64984](https://github.com/ClickHouse/ClickHouse/issues/64984) : correction de l’erreur `Block structure mismatch` pour les requêtes lisant avec `PREWHERE` depuis la vue matérialisée lorsque celle-ci comporte des colonnes de types différents de la table source. Corrige [#64611](https://github.com/ClickHouse/ClickHouse/issues/64611). [#64855](https://github.com/ClickHouse/ClickHouse/pull/64855) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#64976](https://github.com/ClickHouse/ClickHouse/issues/64976) : correction d’un crash rare lorsqu’une table a un TTL avec sous-requête + base de données Replicated + réplicas parallèles + analyzer. C’est extrêmement rare, mais veuillez ne pas utiliser de TTL avec des sous-requêtes. [#64858](https://github.com/ClickHouse/ClickHouse/pull/64858) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#65074](https://github.com/ClickHouse/ClickHouse/issues/65074) : correction de la requête `ALTER MODIFY COMMENT`, qui ne fonctionnait plus pour les `VIEW` paramétrées depuis [https://github.com/ClickHouse/ClickHouse/pull/54211](https://github.com/ClickHouse/ClickHouse/pull/54211). [#65031](https://github.com/ClickHouse/ClickHouse/pull/65031) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#65179](https://github.com/ClickHouse/ClickHouse/issues/65179) : correction de l’erreur `Unknown expression identifier` pour les requêtes distantes avec `INTERPOLATE (alias)` (nouvel analyzer). Corrige [#64636](https://github.com/ClickHouse/ClickHouse/issues/64636). [#65090](https://github.com/ClickHouse/ClickHouse/pull/65090) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#65163](https://github.com/ClickHouse/ClickHouse/issues/65163) : correction du déplacement des opérations arithmétiques hors de l’agrégation. Dans le nouvel analyzer, l’optimisation n’était appliquée qu’une seule fois. Fait partie de [#62245](https://github.com/ClickHouse/ClickHouse/issues/62245). [#65104](https://github.com/ClickHouse/ClickHouse/pull/65104) ([Dmitry Novik](https://github.com/novikd)).
