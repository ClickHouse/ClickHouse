* Rétroporté dans [#25102](https://github.com/ClickHouse/ClickHouse/issues/25102) : distinction de KILL MUTATION selon les tables (corrige l&#39;erreur inattendue `Cancelled mutating parts`). [#25025](https://github.com/ClickHouse/ClickHouse/pull/25025) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#25213](https://github.com/ClickHouse/ClickHouse/issues/25213) : correction d&#39;une erreur survenant lors de l&#39;insertion d&#39;un sous-ensemble de colonnes à l&#39;aide du format CSVWithNames. Corrige [#25129](https://github.com/ClickHouse/ClickHouse/issues/25129). [#25169](https://github.com/ClickHouse/ClickHouse/pull/25169) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#25352](https://github.com/ClickHouse/ClickHouse/issues/25352) : correction d&#39;une erreur TOCTOU dans le script d&#39;installation. [#25277](https://github.com/ClickHouse/ClickHouse/pull/25277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#25385](https://github.com/ClickHouse/ClickHouse/issues/25385) : correction d&#39;un comportement incorrect et d&#39;un signalement UBSan sur les grands entiers. Dans les versions précédentes, `CAST(1e19 AS UInt128)` renvoyait zéro. [#25279](https://github.com/ClickHouse/ClickHouse/pull/25279) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#25470](https://github.com/ClickHouse/ClickHouse/issues/25470) : correction de joinGetOrNull avec des colonnes non Nullable. Cela corrige [#24261](https://github.com/ClickHouse/ClickHouse/issues/24261). [#25288](https://github.com/ClickHouse/ClickHouse/pull/25288) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#25360](https://github.com/ClickHouse/ClickHouse/issues/25360) : correction de l&#39;erreur `Bad cast from type DB::ColumnLowCardinality to DB::ColumnVector<char8_t>` pour les requêtes où l&#39;argument `LowCardinality` était utilisé avec IN (ce bogue est apparu dans la version 21.6). Corrige [#25187](https://github.com/ClickHouse/ClickHouse/issues/25187). [#25290](https://github.com/ClickHouse/ClickHouse/pull/25290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25356](https://github.com/ClickHouse/ClickHouse/issues/25356) : correction de l&#39;erreur logique : impossible de sommer Array/Tuple dans min/maxMap. [#25298](https://github.com/ClickHouse/ClickHouse/pull/25298) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#25436](https://github.com/ClickHouse/ClickHouse/issues/25436) : prise en charge de `SimpleAggregateFunction(LowCardinality)` pour `SummingMergeTree`. Corrige [#25134](https://github.com/ClickHouse/ClickHouse/issues/25134). [#25300](https://github.com/ClickHouse/ClickHouse/pull/25300) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25363](https://github.com/ClickHouse/ClickHouse/issues/25363) : en cas de perte de connexion à ZooKeeper, la table `ReplicatedMergeTree` pouvait attendre la fin des opérations en arrière-plan avant de tenter de se reconnecter. Ce problème est corrigé : désormais, les opérations en arrière-plan sont arrêtées de force. [#25306](https://github.com/ClickHouse/ClickHouse/pull/25306) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25388](https://github.com/ClickHouse/ClickHouse/issues/25388) : corrige un comportement non déterministe possible de la fonction `quantileDeterministic` et de fonctions similaires. Clôt [#20480](https://github.com/ClickHouse/ClickHouse/issues/20480). [#25313](https://github.com/ClickHouse/ClickHouse/pull/25313) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#25448](https://github.com/ClickHouse/ClickHouse/issues/25448) : corrige la perte de la condition `WHERE` dans l&#39;optimisation de push-down des expressions du plan de requête (`query_plan_filter_push_down = 1` par défaut). Corrige [#25368](https://github.com/ClickHouse/ClickHouse/issues/25368). [#25370](https://github.com/ClickHouse/ClickHouse/pull/25370) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25407](https://github.com/ClickHouse/ClickHouse/issues/25407) : corrige le transformateur de colonne `REPLACE` lorsqu&#39;il est utilisé en DDL, en plaçant correctement entre guillemets la requête formatée. Corrige [#23925](https://github.com/ClickHouse/ClickHouse/issues/23925). [#25391](https://github.com/ClickHouse/ClickHouse/pull/25391) ([Amos Bird](https://github.com/amosbird)).
