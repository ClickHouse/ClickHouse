  ### Version de ClickHouse v24.12.3.47-stable (d5d8b06f0da) FIXME par rapport à v24.12.2.29-stable (e06743658c1)

<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#74319](https://github.com/ClickHouse/ClickHouse/issues/74319) : lorsque `min_age_to_force_merge_seconds` et `min_age_to_force_merge_on_partition_only` sont tous deux activés, la fusion de parties ignorera la limite maximale en octets. [#73656](https://github.com/ClickHouse/ClickHouse/pull/73656) ([Kai Zhu](https://github.com/nauu)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#74077](https://github.com/ClickHouse/ClickHouse/issues/74077) : permet de modifier les paramètres de commit du stockage S3(Azure)Queue. (Les paramètres de commit sont : max&#95;processed&#95;files&#95;before&#95;commit, max&#95;processed&#95;rows&#95;before&#95;commit, max&#95;processed&#95;bytes&#95;before&#95;commit, max&#95;processing&#95;time&#95;sec&#95;before&#95;commit). [#73635](https://github.com/ClickHouse/ClickHouse/pull/73635) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#74160](https://github.com/ClickHouse/ClickHouse/issues/74160) : évite une pause après `ALTER TABLE REPLACE/MOVE PARTITION FROM/TO TABLE`. Récupère les paramètres corrects pour l’ordonnancement des tâches en arrière-plan. [#72024](https://github.com/ClickHouse/ClickHouse/pull/72024) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Rétroporté dans [#74143](https://github.com/ClickHouse/ClickHouse/issues/74143) : propage les paramètres de format à NativeWriter dans TCPHandler, afin que des paramètres comme `output_format_native_write_json_as_string` soient correctement appliqués. [#73179](https://github.com/ClickHouse/ClickHouse/pull/73179) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#73895](https://github.com/ClickHouse/ClickHouse/issues/73895) : corrige la préparation au compactage pour les colonnes Dynamic et JSON. Auparavant, dans certains cas, de nouveaux types pouvaient être insérés dans shared variant/shared data même lorsque la limite de types/chemins n’était pas atteinte. [#73388](https://github.com/ClickHouse/ClickHouse/pull/73388) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#74441](https://github.com/ClickHouse/ClickHouse/issues/74441) : corrige un segfault lorsque la source du dictionnaire contient une fonction avec des données incorrectes. [#73535](https://github.com/ClickHouse/ClickHouse/pull/73535) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Rétroporté dans [#73799](https://github.com/ClickHouse/ClickHouse/issues/73799) : corrige une possible incohérence des données dans une colonne Dynamic. Corrige également une possible erreur logique `Nested columns sizes are inconsistent with local_discriminators column size`. [#73644](https://github.com/ClickHouse/ClickHouse/pull/73644) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#74029](https://github.com/ClickHouse/ClickHouse/issues/74029) : corrige la désérialisation de la structure Dynamic/Object. Cela pouvait entraîner des exceptions CANNOT&#95;READ&#95;ALL&#95;DATA. [#73767](https://github.com/ClickHouse/ClickHouse/pull/73767) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#74100](https://github.com/ClickHouse/ClickHouse/issues/74100) : corrige [#72078](https://github.com/ClickHouse/ClickHouse/issues/72078) (la prise en charge de S3 Express était défaillante). [#73777](https://github.com/ClickHouse/ClickHouse/pull/73777) ([Sameer Tamsekar](https://github.com/stamsekar)).
* Rétroporté dans [#74092](https://github.com/ClickHouse/ClickHouse/issues/74092) : corrige les privilèges implicites (ils fonctionnaient auparavant comme un joker). [#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#74044](https://github.com/ClickHouse/ClickHouse/issues/74044) : corrige une consommation mémoire élevée lors de la création de Maps imbriquées. [#73982](https://github.com/ClickHouse/ClickHouse/pull/73982) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#74057](https://github.com/ClickHouse/ClickHouse/issues/74057) : correction : un alias peut ne pas être ajouté à la projection s’il est référencé par un autre alias et sélectionné dans l’ordre inverse. [#74033](https://github.com/ClickHouse/ClickHouse/pull/74033) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#74110](https://github.com/ClickHouse/ClickHouse/issues/74110) : un disque utilisant les métadonnées plain&#95;rewritable peut être partagé entre plusieurs instances du serveur. Il est possible qu’une instance lise un objet de métadonnées pendant qu’une autre le modifie. Les erreurs « object not found » sont ignorées lors de l’initialisation de plain&#95;rewritable avec le stockage Azure, de manière similaire au comportement implémenté pour S3. [#74059](https://github.com/ClickHouse/ClickHouse/pull/74059) ([Julia Kartseva](https://github.com/jkartseva)).
* Rétroporté dans [#74136](https://github.com/ClickHouse/ClickHouse/issues/74136) : corrige le cas où l&#39;utilisateur spécifie des arguments nommés dans le moteur de table Kafka. [#74064](https://github.com/ClickHouse/ClickHouse/pull/74064) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Rétroporté dans [#74179](https://github.com/ClickHouse/ClickHouse/issues/74179) : corrige un crash lors de la lecture d&#39;une sous-colonne depuis une table compressée utilisant le moteur Memory. Corrige [#74009](https://github.com/ClickHouse/ClickHouse/issues/74009). [#74161](https://github.com/ClickHouse/ClickHouse/pull/74161) ([Nikita Taranov](https://github.com/nickitat)).
