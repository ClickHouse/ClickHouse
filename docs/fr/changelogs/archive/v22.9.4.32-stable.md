  #### Correction de bogues (comportement incorrect visible par l&#39;utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#42122](https://github.com/ClickHouse/ClickHouse/issues/42122) : correction de l&#39;erreur « Part ... intersects part ... », qui pouvait se produire dans des cas extrêmement rares si une replica était redémarrée juste après le détachement d&#39;une part marquée comme corrompue. [#41741](https://github.com/ClickHouse/ClickHouse/pull/41741) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#41938](https://github.com/ClickHouse/ClickHouse/issues/41938) : il n&#39;est plus autorisé de créer ou de modifier des tables MergeTree avec le nom de colonne virtuelle &#95;row&#95;exists, réservé à `lightweight delete`. Correction de [#41716](https://github.com/ClickHouse/ClickHouse/issues/41716). [#41763](https://github.com/ClickHouse/ClickHouse/pull/41763) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Rétroporté dans [#42179](https://github.com/ClickHouse/ClickHouse/issues/42179) : correction de la réutilisation de fichiers &gt; 4GB à partir d&#39;une sauvegarde de base. [#42146](https://github.com/ClickHouse/ClickHouse/pull/42146) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#42301](https://github.com/ClickHouse/ClickHouse/issues/42301) : correction d&#39;un bogue affectant les projections et le paramètre `aggregate_functions_null_for_empty`. Ce bogue est très rare et n&#39;apparaît que si vous activez le paramètre `aggregate_functions_null_for_empty` dans la config du serveur. Cela clôt [#41647](https://github.com/ClickHouse/ClickHouse/issues/41647). [#42198](https://github.com/ClickHouse/ClickHouse/pull/42198) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#42388](https://github.com/ClickHouse/ClickHouse/issues/42388) : `ALTER UPDATE` d&#39;une part attachée (avec des colonnes différentes du schéma de la table) pouvait créer sur le disk des métadonnées `columns.txt` invalides. La lecture d&#39;une telle part pouvait échouer avec des erreurs ou renvoyer des données invalides. Correction de [#42161](https://github.com/ClickHouse/ClickHouse/issues/42161). [#42319](https://github.com/ClickHouse/ClickHouse/pull/42319) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#42500](https://github.com/ClickHouse/ClickHouse/issues/42500) : le paramètre `additional_table_filters` n&#39;était pas appliqué au moteur `Distributed`. Correction de [#41692](https://github.com/ClickHouse/ClickHouse/issues/41692). [#42322](https://github.com/ClickHouse/ClickHouse/pull/42322) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#42581](https://github.com/ClickHouse/ClickHouse/issues/42581) : annulation de [#40217](https://github.com/ClickHouse/ClickHouse/issues/40217), qui introduisait une régression dans les fonctions de date et d&#39;heure. Cela clôt [#42451](https://github.com/ClickHouse/ClickHouse/issues/42451). [#42465](https://github.com/ClickHouse/ClickHouse/pull/42465) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
