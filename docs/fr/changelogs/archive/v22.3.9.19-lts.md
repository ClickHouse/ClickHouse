<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#39097](https://github.com/ClickHouse/ClickHouse/issues/39097) : toute allocation dans OvercommitTracker peut entraîner un interblocage. La journalisation n’étant pas très informative, le plus simple est de la supprimer. Corrige [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794). [#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#39080](https://github.com/ClickHouse/ClickHouse/issues/39080) : corrige un bogue dans le cache du système de fichiers qui pouvait se produire dans un cas limite lorsque le cache atteignait sa capacité maximale. Ferme [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066). [#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#39149](https://github.com/ClickHouse/ClickHouse/issues/39149) : corrige l’erreur `Block structure mismatch` qui pouvait se produire lors d’un `INSERT` dans une table avec une `MATERIALIZED VIEW` attachée et le paramètre `extremes = 1` activé. Ferme [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) et [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729). [#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#39372](https://github.com/ClickHouse/ClickHouse/issues/39372) : déclare la queue RabbitMQ sans les arguments par défaut `x-max-length` et `x-overflow`. [#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* Rétroporté dans [#39379](https://github.com/ClickHouse/ClickHouse/issues/39379) : corrige une erreur de segmentation dans le moteur de base de données MaterializedPostgreSQL, qui pouvait se produire si une exception survenait lors de l’initialisation de la réplication. Ferme [#36939](https://github.com/ClickHouse/ClickHouse/issues/36939). [#39272](https://github.com/ClickHouse/ClickHouse/pull/39272) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#39351](https://github.com/ClickHouse/ClickHouse/issues/39351) : corrige la requête incorrecte de récupération des tables PostgreSQL dans le moteur de base de données PostgreSQL. Ferme [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502). [#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
