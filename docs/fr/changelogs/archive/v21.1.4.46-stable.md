<div id="bug-fix">
  #### Corrections de bogues
</div>

* Rétroporté dans [#19983](https://github.com/ClickHouse/ClickHouse/issues/19983) : le thread d’arrière-plan qui exécute les requêtes `ON CLUSTER` pouvait rester bloqué en attendant qu’une table répliquée supprimée effectue une opération. C’est corrigé. [#19684](https://github.com/ClickHouse/ClickHouse/pull/19684) ([yiguolei](https://github.com/yiguolei)).
* Rétroporté dans [#20238](https://github.com/ClickHouse/ClickHouse/issues/20238) : correction d’un bogue selon lequel le déplacement de parties vers la table de destination pouvait échouer lors du lancement de plusieurs clickhouse-copiers. [#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* Rétroporté dans [#20074](https://github.com/ClickHouse/ClickHouse/issues/20074) : correction d’un problème au démarrage du serveur avec des tables ayant des expressions par défaut contenant dictGet(). Autorise l’obtention du type de retour de dictGet() sans charger le dictionnaire. [#19805](https://github.com/ClickHouse/ClickHouse/pull/19805) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#19997](https://github.com/ClickHouse/ClickHouse/issues/19997) : - correction d’un segfault dans la fonction `fromModifiedJulianDay` lorsque le type de l’argument est `Nullable(T)` pour tout type entier autre que Int32. [#19959](https://github.com/ClickHouse/ClickHouse/pull/19959) ([PHO](https://github.com/depressed-pho)).
* Rétroporté dans [#20122](https://github.com/ClickHouse/ClickHouse/issues/20122) : MaterializeMySQL : correction de la réplication pour les instructions qui mettent à jour plusieurs tables. [#20066](https://github.com/ClickHouse/ClickHouse/pull/20066) ([Håvard Kvålen](https://github.com/havardk)).
* Rétroporté dans [#20297](https://github.com/ClickHouse/ClickHouse/issues/20297) : * Correction d’un bogue dans StorageJoin. [#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#20390](https://github.com/ClickHouse/ClickHouse/issues/20390) : le moteur de table `MongoDB` n’établit désormais une connexion que lorsqu’il va lire des données. `ATTACH TABLE` n’essaiera plus de se connecter. [#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#20148](https://github.com/ClickHouse/ClickHouse/issues/20148) : correction d’un crash du serveur après une requête avec la fonction `if` dont le résultat des branches then/else est de type `Tuple`. Le type `Tuple` doit contenir `Array` ou un autre type complexe. Corrige [#18356](https://github.com/ClickHouse/ClickHouse/issues/18356). [#20133](https://github.com/ClickHouse/ClickHouse/pull/20133) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20327](https://github.com/ClickHouse/ClickHouse/issues/20327) : correction d’un crash rare du serveur lors du rechargement de la configuration pendant l’arrêt. Corrige [#19689](https://github.com/ClickHouse/ClickHouse/issues/19689). [#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20331](https://github.com/ClickHouse/ClickHouse/issues/20331) : restriction de la colonne de version aux opérations `DROP` ou `RENAME` pour les moteurs de table `*CollapsingMergeTree` et `ReplacingMergeTree`. [#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20363](https://github.com/ClickHouse/ClickHouse/issues/20363) : correction des tentatives de relance trop fréquentes des tâches d’arrière-plan en échec pour la famille de moteurs de table `ReplicatedMergeTree`. Cela pouvait entraîner une journalisation détaillée excessive et une augmentation de la charge CPU. Corrige [#20203](https://github.com/ClickHouse/ClickHouse/issues/20203). [#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20378](https://github.com/ClickHouse/ClickHouse/issues/20378) : corrige un résultat incorrect des opérations binaires entre deux décimaux constants d&#39;échelles différentes. Corrige [#20283](https://github.com/ClickHouse/ClickHouse/issues/20283). [#20339](https://github.com/ClickHouse/ClickHouse/pull/20339) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#20375](https://github.com/ClickHouse/ClickHouse/issues/20375) : corrige un déréférencement de pointeur NULL avec `join_use_nulls=1`. [#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20359](https://github.com/ClickHouse/ClickHouse/issues/20359) : évite un déréférencement invalide dans le dictionnaire RANGE&#95;HASHED(). [#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)).
