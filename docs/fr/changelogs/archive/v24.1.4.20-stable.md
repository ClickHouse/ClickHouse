<div id="improvement">
  #### Amélioration
</div>

* rétroporté dans [#59826](https://github.com/ClickHouse/ClickHouse/issues/59826) : lorsque `merge_max_block_size_bytes` est suffisamment faible et que les tables contiennent des lignes larges (String ou Tuples), les fusions en arrière-plan peuvent se retrouver bloquées dans une boucle infinie. Ce comportement a été corrigé. Suite à [https://github.com/ClickHouse/ClickHouse/pull/59340](https://github.com/ClickHouse/ClickHouse/pull/59340). [#59812](https://github.com/ClickHouse/ClickHouse/pull/59812) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#59885](https://github.com/ClickHouse/ClickHouse/issues/59885) : si vous souhaitez exécuter les scripts `initdb` à chaque démarrage du conteneur ClickHouse, vous devez définir la variable d’environnement CLICKHOUSE&#95;ALWAYS&#95;RUN&#95;INITDB&#95;SCRIPTS. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#59457](https://github.com/ClickHouse/ClickHouse/issues/59457) : correctif Keeper : correction du calcul du digest pour les nœuds. [#59439](https://github.com/ClickHouse/ClickHouse/pull/59439) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#59682](https://github.com/ClickHouse/ClickHouse/issues/59682) : correction d’une table distribuée avec une clé de sharding constante. [#59606](https://github.com/ClickHouse/ClickHouse/pull/59606) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#59842](https://github.com/ClickHouse/ClickHouse/issues/59842) : correction de l’heure de début des requêtes non initiales. [#59662](https://github.com/ClickHouse/ClickHouse/pull/59662) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#59937](https://github.com/ClickHouse/ClickHouse/issues/59937) : correction de l’analyse des expressions de partition entourées de parenthèses, par exemple : `ALTER TABLE test DROP PARTITION ('2023-10-19')`. [#59901](https://github.com/ClickHouse/ClickHouse/pull/59901) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
