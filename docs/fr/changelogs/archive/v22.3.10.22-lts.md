* Rétroporté dans [#39761](https://github.com/ClickHouse/ClickHouse/issues/39761) : correction du repositionnement pendant la lecture sur un disque chiffré. Cette PR corrige [#38381](https://github.com/ClickHouse/ClickHouse/issues/38381). [#39687](https://github.com/ClickHouse/ClickHouse/pull/39687) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#39206](https://github.com/ClickHouse/ClickHouse/issues/39206) : correction de la lecture des colonnes creuses de tables `MergeTree` stockant leurs données dans S3. [#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#39381](https://github.com/ClickHouse/ClickHouse/issues/39381) : correction de l’erreur `Not found column Type in block` dans les requêtes `SELECT` avec `PREWHERE` et les optimisations de lecture ordonnée. [#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#39588](https://github.com/ClickHouse/ClickHouse/issues/39588) : correction d’une condition de concurrence (data race) et d’un possible dépassement de tampon sur le tas dans le format Avro. Ferme [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094) Ferme [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652). [#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#39610](https://github.com/ClickHouse/ClickHouse/issues/39610) : correction d’un bogue avec l’argument maxsplit de splitByChar, qui ne fonctionnait pas correctement. [#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#39834](https://github.com/ClickHouse/ClickHouse/issues/39834) : correction de l’exception `CANNOT_READ_ALL_DATA` avec `local_filesystem_read_method=pread_threadpool`. Ce bogue n’affectait que les noyaux Linux 5.9 et 5.10, selon [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS). [#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
