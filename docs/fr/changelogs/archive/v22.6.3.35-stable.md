* Rétroporté dans [#38690](https://github.com/ClickHouse/ClickHouse/issues/38690) : corrige l&#39;ordre incorrect des colonnes dans les sous-requêtes de UNION (en cas de colonnes dupliquées dans les sous-sélections, cela peut produire un résultat incorrect). [#37887](https://github.com/ClickHouse/ClickHouse/pull/37887) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#38500](https://github.com/ClickHouse/ClickHouse/issues/38500) : n&#39;autorise pas l&#39;utilisation récursive de OvercommitTracker pendant la journalisation. Corrige [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794) cc @tavplubix @davenger. [#38246](https://github.com/ClickHouse/ClickHouse/pull/38246) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#38712](https://github.com/ClickHouse/ClickHouse/issues/38712) : corrige les résultats incorrects des requêtes distribuées avec `DISTINCT` et `LIMIT`. Corrige [#38282](https://github.com/ClickHouse/ClickHouse/issues/38282). [#38371](https://github.com/ClickHouse/ClickHouse/pull/38371) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#38594](https://github.com/ClickHouse/ClickHouse/issues/38594) : corrige la suppression des parts (elles restaient indéfiniment si elles n&#39;avaient pas été supprimées lors de l&#39;arrêt du serveur) après un arrêt incorrect du serveur. [#38486](https://github.com/ClickHouse/ClickHouse/pull/38486) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#38597](https://github.com/ClickHouse/ClickHouse/issues/38597) : corrige la création de table afin d&#39;éviter des problèmes de réplication avec les répliques antérieures à la version 22.4. [#38541](https://github.com/ClickHouse/ClickHouse/pull/38541) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#38687](https://github.com/ClickHouse/ClickHouse/issues/38687) : il est désormais possible de démarrer un clickhouse-server et d&#39;attach/detach des tables, même pour des tables avec des valeurs incorrectes de représentation IPv4/IPv6. Correctif complet du ticket [#35156](https://github.com/ClickHouse/ClickHouse/issues/35156). [#38590](https://github.com/ClickHouse/ClickHouse/pull/38590) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#38665](https://github.com/ClickHouse/ClickHouse/issues/38665) : adapte quelques nœuds supplémentaires pour éviter des problèmes avec les répliques antérieures à la version 22.4. [#38627](https://github.com/ClickHouse/ClickHouse/pull/38627) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#38778](https://github.com/ClickHouse/ClickHouse/issues/38778) : la fonction `rankCorr` fonctionne correctement même si certains arguments sont des NaN. Clôt [#38396](https://github.com/ClickHouse/ClickHouse/issues/38396). [#38722](https://github.com/ClickHouse/ClickHouse/pull/38722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#38782](https://github.com/ClickHouse/ClickHouse/issues/38782) : corrige un use-after-free dans le combinateur Map, qui entraîne un résultat incorrect. [#38748](https://github.com/ClickHouse/ClickHouse/pull/38748) ([Azat Khuzhin](https://github.com/azat)).
