<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#46372](https://github.com/ClickHouse/ClickHouse/issues/46372) : correction d’une utilisation de la mémoire trop importante pour les fusions verticales sur disque local. Respect de `max_insert_delayed_streams_for_parallel_write` sur le disque distant. [#46275](https://github.com/ClickHouse/ClickHouse/pull/46275) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#46357](https://github.com/ClickHouse/ClickHouse/issues/46357) : autorisation de l’utilisation de l’algorithme de fusion verticale avec des parts au format Compact. Cela permettra à ClickHouse server d’utiliser beaucoup moins de mémoire pour les opérations en arrière-plan. Cela résout [#46084](https://github.com/ClickHouse/ClickHouse/issues/46084). [#46282](https://github.com/ClickHouse/ClickHouse/pull/46282) ([Anton Popov](https://github.com/CurtizJ)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build, des tests et du packaging
</div>

* Rétroporté dans [#45856](https://github.com/ClickHouse/ClickHouse/issues/45856) : correction du téléchargement de ZooKeeper, mise à jour de la version et optimisation de la taille de l&#39;image. [#44853](https://github.com/ClickHouse/ClickHouse/pull/44853) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans la version stable officielle)
</div>

* Rétroporté dans [#45620](https://github.com/ClickHouse/ClickHouse/issues/45620) : autre correctif pour l’erreur `Cannot read all data`, qui pouvait survenir lors de la lecture d’un dictionnaire `LowCardinality` depuis remote fs. Corrige [#44709](https://github.com/ClickHouse/ClickHouse/issues/44709). [#44875](https://github.com/ClickHouse/ClickHouse/pull/44875) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#45549](https://github.com/ClickHouse/ClickHouse/issues/45549) : corrige l’exception `SELECT ... FROM system.dictionaries` lorsqu’un dictionnaire a une structure invalide (par ex. un type incorrect dans la config XML). [#45399](https://github.com/ClickHouse/ClickHouse/pull/45399) ([Aleksei Filatov](https://github.com/aalexfvk)).
