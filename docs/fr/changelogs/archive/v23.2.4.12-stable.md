<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#47277](https://github.com/ClickHouse/ClickHouse/issues/47277) : correction de la sérialisation/désérialisation IPv4/IPv6 dans les formats binaires, qui avait été cassée dans [https://github.com/ClickHouse/ClickHouse/pull/43221](https://github.com/ClickHouse/ClickHouse/pull/43221). Clôt [#46522](https://github.com/ClickHouse/ClickHouse/issues/46522). [#46616](https://github.com/ClickHouse/ClickHouse/pull/46616) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#47212](https://github.com/ClickHouse/ClickHouse/issues/47212) : les requêtes `INSERT` via le protocole TCP natif et le protocole HTTP n’étaient pas correctement annulées dans certains cas. Cela pouvait entraîner l’application partielle d’une requête si un client l’annulait, ou si un client cessait de répondre ou, dans de rares cas, en cas d’erreurs réseau. En conséquence, cela pouvait rendre la déduplication inopérante. Corrige [#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) et [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377). [#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#47363](https://github.com/ClickHouse/ClickHouse/issues/47363) : correction d’un interblocage possible lors de l’annulation d’une requête distribuée. [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).
