<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#75811](https://github.com/ClickHouse/ClickHouse/issues/75811) : propage correctement les paramètres du format Native pour la communication client-serveur. [#73924](https://github.com/ClickHouse/ClickHouse/pull/73924) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#74090](https://github.com/ClickHouse/ClickHouse/issues/74090) : corrige les privilèges implicites (ils se comportaient auparavant comme un joker). [#73932](https://github.com/ClickHouse/ClickHouse/pull/73932) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#75556](https://github.com/ClickHouse/ClickHouse/issues/75556) : corrige un plantage avec la requête `INSERT INTO SELECT` via l’interface PostgreSQL sur macOS (issue [#72938](https://github.com/ClickHouse/ClickHouse/issues/72938)). [#74231](https://github.com/ClickHouse/ClickHouse/pull/74231) ([Artem Yurov](https://github.com/ArtemYurov)).
* Rétroporté dans [#75630](https://github.com/ClickHouse/ClickHouse/issues/75630) : corrige un plantage dû à une exception non gérée dans la réplication PSQL. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#76103](https://github.com/ClickHouse/ClickHouse/issues/76103) : corrige la gestion des JOIN null-safe pour le type de données Nullable LowCardinality. Auparavant, JOIN ON avec une comparaison null-safe, comme `IS NOT DISTINCT FROM`, `<=>` , `a IS NULL AND b IS NULL OR a == b`, ne fonctionnait pas correctement avec les colonnes LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Rétroporté dans [#75568](https://github.com/ClickHouse/ClickHouse/issues/75568) : correctif Keeper : évite d’écrire dans des changelogs endommagés lors du rollback des logs. [#75197](https://github.com/ClickHouse/ClickHouse/pull/75197) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#75652](https://github.com/ClickHouse/ClickHouse/issues/75652) : masque les informations d’identification du moteur de table azureblobstorage. [#75319](https://github.com/ClickHouse/ClickHouse/pull/75319) ([Garrett Thomas](https://github.com/garrettthomaskth)).
* Rétroporté dans [#75744](https://github.com/ClickHouse/ClickHouse/issues/75744) : corrige un plantage dans le cache de schéma Protobuf pouvant survenir lors d’une sortie au format Protobuf et de l’exécution parallèle de la requête `SYSTEM DROP FORMAT SCHEMA CACHE`. [#75357](https://github.com/ClickHouse/ClickHouse/pull/75357) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#76096](https://github.com/ClickHouse/ClickHouse/issues/76096) : corrige l’erreur possible `Elements ... and ... of Nested data structure ... (Array columns) have different array sizes` lorsque des sous-colonnes JSON de type Array sont utilisées dans un JOIN sur des tables distribuées. [#75512](https://github.com/ClickHouse/ClickHouse/pull/75512) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#75854](https://github.com/ClickHouse/ClickHouse/issues/75854) : corrige l’interaction entre allow&#95;feature&#95;tier et le paramètre MergeTree de compatibilité. [#75635](https://github.com/ClickHouse/ClickHouse/pull/75635) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#75892](https://github.com/ClickHouse/ClickHouse/issues/75892) : corrige de rares plantages lors de la lecture depuis une table `MergeTree` après plusieurs requêtes `RENAME` asynchrones (avec `alter_sync = 0`) entre des colonnes de types différents. [#75693](https://github.com/ClickHouse/ClickHouse/pull/75693) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#76157](https://github.com/ClickHouse/ClickHouse/issues/76157) : reconstruction de la projection lors d’un `ALTER MODIFY` de sa colonne de clé primaire. Auparavant, cela pouvait entraîner des erreurs `CANNOT_READ_ALL_DATA` lors des requêtes `SELECT` après un `ALTER MODIFY` de la colonne utilisée dans la clé primaire de la projection. [#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#75823](https://github.com/ClickHouse/ClickHouse/issues/75823) : correction d’un déréférencement de pointeur nul dans `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#76216](https://github.com/ClickHouse/ClickHouse/issues/76216) : `clickhouse-library-bridge` permet d’ouvrir des bibliothèques arbitraires depuis le système de fichiers, ce qui rend son exécution sûre uniquement dans un environnement isolé. Pour éviter une vulnérabilité lorsqu’il est exécuté à proximité de clickhouse-server, nous limiterons les chemins des bibliothèques à l’emplacement indiqué dans la configuration. Cette vulnérabilité a été découverte dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par **Arseniy Dugin**. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
