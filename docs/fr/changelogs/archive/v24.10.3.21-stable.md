<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#72100](https://github.com/ClickHouse/ClickHouse/issues/72100) : correction de l’enregistrement `metadata_version` dans ZooKeeper par le thread de redémarrage plutôt que par le thread d’attach. [#70297](https://github.com/ClickHouse/ClickHouse/pull/70297) ([Miсhael Stetsyuk](https://github.com/mstetsyuk)).
* Rétroporté dans [#72169](https://github.com/ClickHouse/ClickHouse/issues/72169) : interdiction des types Dynamic/Variant dans les fonctions min/max afin d’éviter toute confusion. [#71761](https://github.com/ClickHouse/ClickHouse/pull/71761) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#72064](https://github.com/ClickHouse/ClickHouse/issues/72064) : lors de la récupération directe de données depuis un dictionnaire à l’aide du stockage Dictionary, de la fonction de table dictionary ou d’un `SELECT` direct sur le dictionnaire lui-même, il suffit désormais de disposer de la permission `SELECT` ou de la permission `dictGet` sur le dictionnaire. Ce changement s’inscrit dans la continuité des tentatives précédentes visant à empêcher les contournements d’ACL : [https://github.com/ClickHouse/ClickHouse/pull/57362](https://github.com/ClickHouse/ClickHouse/pull/57362) et [https://github.com/ClickHouse/ClickHouse/pull/65359](https://github.com/ClickHouse/ClickHouse/pull/65359). Il rend également la seconde rétrocompatible. [#72051](https://github.com/ClickHouse/ClickHouse/pull/72051) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

[#71845](https://github.com/ClickHouse/ClickHouse/pull/71845) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Rétroporté dans [#72088](https://github.com/ClickHouse/ClickHouse/issues/72088) : correction de la colonne rows&#95;processed dans system.s3/azure&#95;queue&#95;log, défectueuse dans la version 24.6. Clôture [#69975](https://github.com/ClickHouse/ClickHouse/issues/69975). [#71946](https://github.com/ClickHouse/ClickHouse/pull/71946) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#72036](https://github.com/ClickHouse/ClickHouse/issues/72036) : correction de l’erreur `Illegal type` pour les tables `MergeTree` avec une fonction monotone binaire dans `ORDER BY` lorsque le premier argument est constant. Corrige [#71941](https://github.com/ClickHouse/ClickHouse/issues/71941). [#71966](https://github.com/ClickHouse/ClickHouse/pull/71966) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
