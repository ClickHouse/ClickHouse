<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#36244](https://github.com/ClickHouse/ClickHouse/issues/36244) : corrige l’utilisation du quota avec les insertions asynchrones. [#35645](https://github.com/ClickHouse/ClickHouse/pull/35645) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#36240](https://github.com/ClickHouse/ClickHouse/issues/36240) : corrige une perte possible de sous-colonnes dans le type `Object`. [#35682](https://github.com/ClickHouse/ClickHouse/pull/35682) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#36242](https://github.com/ClickHouse/ClickHouse/issues/36242) : corrige une possible exception `Can't adjust last granule` lors de la lecture de sous-colonnes de type `Object`. [#35687](https://github.com/ClickHouse/ClickHouse/pull/35687) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#36147](https://github.com/ClickHouse/ClickHouse/issues/36147) : corrige la lecture à partir des tables `Kafka` lorsque `kafka_num_consumers > 1` et `kafka_thread_per_consumer = 0`. Rétablit la lecture parallèle et multithreadée, accidentellement cassée dans la version 21.11. Ferme [#35153](https://github.com/ClickHouse/ClickHouse/issues/35153). [#35973](https://github.com/ClickHouse/ClickHouse/pull/35973) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#36276](https://github.com/ClickHouse/ClickHouse/issues/36276) : corrige la lecture des tableaux vides en ordre inverse (dans les requêtes avec tri décroissant sur le préfixe de la clé primaire). [#36215](https://github.com/ClickHouse/ClickHouse/pull/36215) ([Anton Popov](https://github.com/CurtizJ)).
