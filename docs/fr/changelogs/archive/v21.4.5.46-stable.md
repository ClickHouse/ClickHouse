  # Changelog 2022
</div>

<div id="clickhouse-release-v214546-stable-fixme-as-compared-to-v214430-stable">
  ### Version ClickHouse v21.4.5.46-stable FIXME par rapport à v21.4.4.30-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#23273](https://github.com/ClickHouse/ClickHouse/issues/23273) : désactivation des paramètres `use_hedged_requests` et `async_socket_for_remote`, car il est apparu qu’ils pouvaient entraîner des problèmes. [#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Corrections de bugs
</div>

* Rétroporté dans [#23234](https://github.com/ClickHouse/ClickHouse/issues/23234) : le serveur pouvait ne pas démarrer si le paramètre `data_type_default_nullable` était activé dans le profil `default` ; ce problème a été corrigé. Corrige [#22573](https://github.com/ClickHouse/ClickHouse/issues/22573). [#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23407](https://github.com/ClickHouse/ClickHouse/issues/23407) : QueryAliasVisitor privilégie l’alias pour ASTWithAlias si la sous-requête a été optimisée en constante. Corrige [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924). Corrige [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401). [#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#23382](https://github.com/ClickHouse/ClickHouse/issues/23382) : correction de l’erreur `Not found column` lors de la sélection depuis `MaterializeMySQL` avec une condition sur la colonne clé. Corrige [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432). [#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23385](https://github.com/ClickHouse/ClickHouse/issues/23385) : correction du comportement où la désactivation du paramètre `input_format_with_names_use_header ` entraînait l’ignorance de toute l’entrée au format CSVWithNames. Cela corrige [#22406](https://github.com/ClickHouse/ClickHouse/issues/22406). [#23202](https://github.com/ClickHouse/ClickHouse/pull/23202) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#23287](https://github.com/ClickHouse/ClickHouse/issues/23287) : correction de la création via DDL d’un dictionnaire à clé simple si la clé primaire n’est pas le premier attribut. Corrige [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236). [#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#23451](https://github.com/ClickHouse/ClickHouse/issues/23451) : correction d’une très rare condition de concurrence (distribuée) entre la création et la suppression de tables ReplicatedMergeTree. Elle pouvait provoquer des exceptions comme `node doesn't exist` lors d’une tentative de création d’une table répliquée. Corrige [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419). [#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23426](https://github.com/ClickHouse/ClickHouse/issues/23426) : correction d’un crash possible si un `unknown packet` était reçu depuis une requête distante (avec `async_socket_for_remote` activé). Corrige peut-être [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167). [#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#23467](https://github.com/ClickHouse/ClickHouse/issues/23467) : `ORDER BY` avec `COLLATE` ne fonctionnait pas correctement si la colonne faisait partie de la clé primaire (ou en était une fonction monotone) et que le paramètre `optimize_read_in_order` n’était pas désactivé. Cela clôt [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379). Solution de contournement pour les versions antérieures : désactivez le paramètre `optimize_read_in_order`. [#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23509](https://github.com/ClickHouse/ClickHouse/issues/23509) : suppression de la prise en charge de `argMin` et `argMax` pour un seul argument `Tuple`. Le code n&#39;était pas sûr en mémoire. Cette fonctionnalité a été ajoutée par erreur et elle prête à confusion. Ces fonctions pourront être réintroduites plus tard sous d&#39;autres noms. Cela corrige [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) et revient sur [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359). [#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23478](https://github.com/ClickHouse/ClickHouse/issues/23478) : le moteur Kafka peut prendre en charge les messages aux formats `arrow` et `arrowstream`. [#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* Rétroporté dans [#23498](https://github.com/ClickHouse/ClickHouse/issues/23498) : - Correctif pour la fonction d&#39;agrégation `deltaSum` dans le cas d&#39;une réinitialisation du compteur ... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* Rétroporté dans [#23492](https://github.com/ClickHouse/ClickHouse/issues/23492) : correction d&#39;un bug qui n&#39;autorisait pas la conversion d&#39;un littéral de tableau vide en tableau avec des dimensions supérieures à 1. Corrige [#14476](https://github.com/ClickHouse/ClickHouse/issues/14476). [#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)).
