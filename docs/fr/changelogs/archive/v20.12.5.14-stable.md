<div id="clickhouse-release-v2012514-stable-fixme-as-compared-to-v201245-stable">
  ### Version de ClickHouse v20.12.5.14-stable FIXME par rapport à v20.12.4.5-stable
</div>

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#18166](https://github.com/ClickHouse/ClickHouse/issues/18166) : correction d’une erreur lorsque la requête `MODIFY COLUMN ... REMOVE TTL` ne supprimait pas réellement le TTL de la colonne. [#18130](https://github.com/ClickHouse/ClickHouse/pull/18130) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#18424](https://github.com/ClickHouse/ClickHouse/issues/18424) : correction de plantages possibles dans les fonctions d’agrégation avec le combinateur `Distinct`, lors de l’utilisation de l’agrégation à deux niveaux. Corrige [#17682](https://github.com/ClickHouse/ClickHouse/issues/17682). [#18365](https://github.com/ClickHouse/ClickHouse/pull/18365) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#18428](https://github.com/ClickHouse/ClickHouse/issues/18428) : correction du remplissage de la table `system.settings_profile_elements`. Cette PR corrige [#18231](https://github.com/ClickHouse/ClickHouse/issues/18231). [#18379](https://github.com/ClickHouse/ClickHouse/pull/18379) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#18482](https://github.com/ClickHouse/ClickHouse/issues/18482) : restriction des fusions de parts wide vers des parts compactes. En cas de fusion verticale, cela entraînait une part de résultat corrompue. [#18381](https://github.com/ClickHouse/ClickHouse/pull/18381) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#18471](https://github.com/ClickHouse/ClickHouse/issues/18471) : correction de l’erreur `value is too short` lors de l’exécution des fonctions `toType(...)` (`toDate`, `toUInt32`, etc.) avec un argument de type `Nullable(String)`. Désormais, ces fonctions renvoient `NULL` en cas d’erreur d’analyse au lieu de lever une exception. Corrige [#7673](https://github.com/ClickHouse/ClickHouse/issues/7673). [#18445](https://github.com/ClickHouse/ClickHouse/pull/18445) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#18533](https://github.com/ClickHouse/ClickHouse/issues/18533) : prise en charge correcte de 12AM dans la fonction `parseDateTimeBestEffort`. Cela corrige [#18402](https://github.com/ClickHouse/ClickHouse/issues/18402). [#18449](https://github.com/ClickHouse/ClickHouse/pull/18449) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* Rétroporté dans [#18502](https://github.com/ClickHouse/ClickHouse/issues/18502) : désactivation de l’écriture avec AIO pendant les fusions, car cela peut entraîner, dans de très rares cas, une corruption des données des colonnes de clé primaire pendant la fusion. [#18481](https://github.com/ClickHouse/ClickHouse/pull/18481) ([alesapin](https://github.com/alesapin)).

  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#18546](https://github.com/ClickHouse/ClickHouse/issues/18546) : mise à jour des données de fuseaux horaires vers la version 2020e. [#18531](https://github.com/ClickHouse/ClickHouse/pull/18531) ([alesapin](https://github.com/alesapin)).
