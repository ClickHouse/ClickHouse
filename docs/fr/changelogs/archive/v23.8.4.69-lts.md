<div id="buildtestingpackaging-improvement">
  #### Amélioration du build, des tests et du packaging
</div>

* rétroporté dans [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673) : si la base de données est déjà initialisée, il n&#39;est pas nécessaire de l&#39;initialiser à nouveau lors des lancements suivants. Cela peut potentiellement corriger le problème de redémarrages infinis du conteneur lorsque la base de données ne parvient pas à se charger en 1000 tentatives (cas pertinent pour les très grandes bases de données et les configurations multi-nœuds). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* rétroporté dans [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293) : une ressource contenant le code source, y compris les sous-modules, est construite dans la tâche de build spéciale Darwin. Elle peut être utilisée pour construire ClickHouse sans avoir à récupérer les sous-modules. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* rétroporté dans [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366) : résolution d&#39;un problème lors du lancement de ClickHouse Keeper autonome depuis le paquet clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* rétroporté dans [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725) : correction du script Python de vérification d&#39;intégration afin d&#39;utiliser l&#39;URL de l&#39;API gh - ajout d&#39;un README pour les tests CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).
