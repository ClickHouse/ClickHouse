  ### Version de ClickHouse v21.7.6.39-stable FIXME par rapport à v21.7.5.29-stable

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#26854](https://github.com/ClickHouse/ClickHouse/issues/26854) : ParallelFormattingOutputFormat : utilisation d’un mutex pour gérer la jointure avec collector&#95;thread ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)). [#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#26938](https://github.com/ClickHouse/ClickHouse/issues/26938) : ne pas supprimer les données à l’arrêt d’une table ReplicatedMergeTree afin d’éviter une incohérence entre les données et les métadonnées. [#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* Rétroporté dans [#26986](https://github.com/ClickHouse/ClickHouse/issues/26986) : les paramètres de la fonction d’agrégation peuvent être perdus lors de l’application de certains combinateurs, ce qui provoque des exceptions comme `Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported`. C’est corrigé. Corrige [#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) et [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433). [#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#26944](https://github.com/ClickHouse/ClickHouse/issues/26944) : correction de l’erreur `Missing columns: 'xxx'` lorsqu’une colonne `DEFAULT` référence une autre colonne non matérialisée sans expression `DEFAULT`. Corrige [#26591](https://github.com/ClickHouse/ClickHouse/issues/26591). [#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#26999](https://github.com/ClickHouse/ClickHouse/issues/26999) : correction de la lecture des TLD personnalisés (le traitement s’arrêtait avec un buffer plus petit ou un fichier plus volumineux). [#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#27029](https://github.com/ClickHouse/ClickHouse/issues/27029) : désormais, l’identifiant de partition dans les requêtes comme `ALTER TABLE ... PARTITION ID xxx` est correctement validé. Corrige [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718). [#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#27050](https://github.com/ClickHouse/ClickHouse/issues/27050) : [RFC] correction d’une possible accumulation de mutations due à une situation de concurrence avec DROP&#95;RANGE. [#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#27105](https://github.com/ClickHouse/ClickHouse/issues/27105) : correction de l’analyse de la configuration `cache`, `complex_key_cache`, `ssd_cache`, `complex_key_ssd_cache`. Les options `allow_read_expired_keys`, `max_update_queue_size`, `update_queue_push_timeout_milliseconds`, `query_wait_timeout_milliseconds` n’étaient pas analysées pour les dictionnaires dont le type n’était pas `cache`. [#27032](https://github.com/ClickHouse/ClickHouse/pull/27032) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#27156](https://github.com/ClickHouse/ClickHouse/issues/27156) : correction de la synchronisation dans GRPCServer. Cette PR corrige [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024). [#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#27261](https://github.com/ClickHouse/ClickHouse/issues/27261) : dans de rares cas, la table `system.detached_parts` pouvait contenir des informations incorrectes pour certaines parts ; c’est corrigé. Corrige [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114). [#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
