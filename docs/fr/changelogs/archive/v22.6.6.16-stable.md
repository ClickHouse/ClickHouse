<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#40162](https://github.com/ClickHouse/ClickHouse/issues/40162) : corrige HashMethodOneNumber, qui renvoyait une mauvaise valeur de clé lorsque la colonne était constante. [#40020](https://github.com/ClickHouse/ClickHouse/pull/40020) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#40124](https://github.com/ClickHouse/ClickHouse/issues/40124) : corrige un bogue dans collectFilesToSkip() en ajoutant la bonne extension de fichier (.idx ou idx2) pour les index à recalculer, afin d’éviter des liens physiques incorrects. Corrige [#39896](https://github.com/ClickHouse/ClickHouse/issues/39896). [#40095](https://github.com/ClickHouse/ClickHouse/pull/40095) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Rétroporté dans [#40209](https://github.com/ClickHouse/ClickHouse/issues/40209) : corrige une vérification insuffisante des arguments pour les fonctions de chiffrement (détectée par le fuzzer de requêtes). Clôt [#39987](https://github.com/ClickHouse/ClickHouse/issues/39987). [#40194](https://github.com/ClickHouse/ClickHouse/pull/40194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#40281](https://github.com/ClickHouse/ClickHouse/issues/40281) : corrige un possible segfault dans le format d’entrée CapnProto. Ce bogue a été découvert et signalé via le [programme](https://github.com/ClickHouse/ClickHouse/issues/38986) de prime aux bogues de ClickHouse par *kiojj*. [#40241](https://github.com/ClickHouse/ClickHouse/pull/40241) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#40489](https://github.com/ClickHouse/ClickHouse/issues/40489) : corrige un bogue rare avec le TTL de colonne pour la famille de moteurs MergeTree : en cas de fusion verticale répétée, l’erreur `Cannot unlink file ColumnName.bin ... No such file or directory.` pouvait se produire. [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
