  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v212941-stable-fixme-as-compared-to-v212831-stable">
  ### Version de ClickHouse v21.2.9.41-stable FIXME par rapport à v21.2.8.31-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#22818](https://github.com/ClickHouse/ClickHouse/issues/22818) : correction du fonctionnement de FQDN et des autres fonctions liées au DNS dans les images Alpine. [#20336](https://github.com/ClickHouse/ClickHouse/pull/20336) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22812](https://github.com/ClickHouse/ClickHouse/issues/22812) : si PODArray était instancié avec une taille d’élément qui n’était ni un diviseur ni un multiple de 16, un dépassement de tampon était possible. Aucun bogue de ce type n’existe dans les versions actuelles. [#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Corrections de bogues
</div>

* Rétroporté dans [#22965](https://github.com/ClickHouse/ClickHouse/issues/22965) : correction d’un bogue très rare où une insertion avec quorum avec `quorum_parallel=1` n’est en réalité pas un vrai « quorum » en raison de la déduplication. [#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22719](https://github.com/ClickHouse/ClickHouse/issues/22719) : vérifie si la table function `view` est utilisée comme une colonne. Ceci complète [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350). [#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#22756](https://github.com/ClickHouse/ClickHouse/issues/22756) : corrige l’utilisation de la fonction `map` dans les requêtes distribuées. [#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* Rétroporté dans [#22889](https://github.com/ClickHouse/ClickHouse/issues/22889) : corrige le comptage approximatif du nombre total de lignes lors de la lecture en ordre inverse depuis MergeTree. [#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22915](https://github.com/ClickHouse/ClickHouse/issues/22915) : LIVE VIEW (fonctionnalité expérimentale). Corrige un possible blocage lors d’un DROP/CREATE concurrent de TEMPORARY LIVE VIEW dans `TemporaryLiveViewCleaner`, voir [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e). [#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#22918](https://github.com/ClickHouse/ClickHouse/issues/22918) : correction d’un plantage lors de l’utilisation de `mannWhitneyUTest` et `rankCorr` avec des fonctions de fenêtre. Corrige [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728). [#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#22814](https://github.com/ClickHouse/ClickHouse/issues/22814) : permet de démarrer avec un binaire modifié sous gdb. Dans la version précédente, si vous définissiez un point d’arrêt dans gdb avant le démarrage, le serveur refusait de se lancer en raison d’un échec de la vérification d’intégrité. [#21258](https://github.com/ClickHouse/ClickHouse/pull/21258) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
