  ### Version ClickHouse v20.12.6.29-stable FIXME par rapport à v20.12.5.18-stable
</div>

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#19984](https://github.com/ClickHouse/ClickHouse/issues/19984) : le background thread qui exécute les requêtes `ON CLUSTER` pouvait se bloquer en attendant qu’une table répliquée supprimée fasse quelque chose. C’est corrigé. [#19684](https://github.com/ClickHouse/ClickHouse/pull/19684) ([yiguolei](https://github.com/yiguolei)).
* Rétroporté dans [#20240](https://github.com/ClickHouse/ClickHouse/issues/20240) : correction d’un bogue où le déplacement de morceaux vers la table de destination pouvait échouer lors du lancement de plusieurs clickhouse-copiers. [#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* Rétroporté dans [#20080](https://github.com/ClickHouse/ClickHouse/issues/20080) : correction du démarrage du serveur avec des tables ayant des expressions par défaut contenant dictGet(). Permet d’obtenir le type de retour de dictGet() sans charger le dictionnaire. [#19805](https://github.com/ClickHouse/ClickHouse/pull/19805) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#20298](https://github.com/ClickHouse/ClickHouse/issues/20298) : * correction d’un bogue dans StorageJoin. [#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#20391](https://github.com/ClickHouse/ClickHouse/issues/20391) : le moteur de table `MongoDB` n’établit désormais la connexion que lorsqu’il va lire des données. `ATTACH TABLE` n’essaiera plus de se connecter. [#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#20328](https://github.com/ClickHouse/ClickHouse/issues/20328) : correction d’un crash rare du serveur lors du rechargement de la config pendant l’arrêt. Corrige [#19689](https://github.com/ClickHouse/ClickHouse/issues/19689). [#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20332](https://github.com/ClickHouse/ClickHouse/issues/20332) : limitation de la colonne de version aux opérations `DROP` ou `RENAME` pour les moteurs de table `*CollapsingMergeTree` et `ReplacingMergeTree`. [#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20364](https://github.com/ClickHouse/ClickHouse/issues/20364) : correction de tentatives répétées trop fréquentes pour les tâches d’arrière-plan en échec de la famille de moteurs de table `ReplicatedMergeTree`. Cela pouvait entraîner une journalisation détaillée excessive et une charge CPU accrue. Corrige [#20203](https://github.com/ClickHouse/ClickHouse/issues/20203). [#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20377](https://github.com/ClickHouse/ClickHouse/issues/20377) : correction d’un déréférencement de pointeur nul avec `join_use_nulls=1`. [#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20360](https://github.com/ClickHouse/ClickHouse/issues/20360) : évite un déréférencement invalide dans le dictionnaire RANGE&#95;HASHED(). [#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)).
