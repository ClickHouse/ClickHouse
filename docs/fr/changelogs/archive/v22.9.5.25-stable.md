<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#42841](https://github.com/ClickHouse/ClickHouse/issues/42841) : mise à jour de tzdata vers la version 2022f. Le Mexique n’appliquera plus l’heure d’été, sauf près de la frontière avec les États-Unis : [https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html). L’État de Chihuahua passe à UTC-6 toute l’année à partir du 2022-10-30. Les Fidji n’appliquent plus l’heure d’été. Voir [https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) et [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209). [#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build, des tests et du packaging
</div>

* Rétroporté dans [#42965](https://github.com/ClickHouse/ClickHouse/issues/42965) : avant ce correctif, la configuration définie par l’utilisateur était sauvegardée par RPM dans `$file.rpmsave`. Cette PR corrige le problème et n’écrasera plus les fichiers de l’utilisateur avec ceux des paquets. [#42936](https://github.com/ClickHouse/ClickHouse/pull/42936) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#43041](https://github.com/ClickHouse/ClickHouse/issues/43041) : ajoute une étape d’intégration continue pour marquer les commits comme prêts pour la release ; interdit de manière non bloquante le lancement d’un script de release depuis des branches autres que master. [#43017](https://github.com/ClickHouse/ClickHouse/pull/43017) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
