<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correctif de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#60413](https://github.com/ClickHouse/ClickHouse/issues/60413) : correction d’un défaut de segmentation dans l’analyseur KQL lorsque la requête d’entrée dépasse `max_query_size`. Réactive également le dialecte KQL. Corrige [#59036](https://github.com/ClickHouse/ClickHouse/issues/59036) et [#59037](https://github.com/ClickHouse/ClickHouse/issues/59037). [#59626](https://github.com/ClickHouse/ClickHouse/pull/59626) ([Yong Wang](https://github.com/kashwy)).
* Rétroporté dans [#60074](https://github.com/ClickHouse/ClickHouse/issues/60074) : correction de l’erreur `Read beyond last offset` pour `AsynchronousBoundedReadBuffer`. [#59630](https://github.com/ClickHouse/ClickHouse/pull/59630) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#60299](https://github.com/ClickHouse/ClickHouse/issues/60299) : correction du cas où les messages n’étaient ni acked ni nacked. Si une exception survient pendant la phase de lecture-écriture, les messages seront nacked. [#59775](https://github.com/ClickHouse/ClickHouse/pull/59775) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#60066](https://github.com/ClickHouse/ClickHouse/issues/60066) : correction de `optimize&#95;uniq&#95;to&#95;count`, qui supprimait l’alias de colonne. [#60026](https://github.com/ClickHouse/ClickHouse/pull/60026) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#60638](https://github.com/ClickHouse/ClickHouse/issues/60638) : correction d’un bug dans l’optimisation en parallèle des requêtes avec `FINAL`, qui pouvait donner un résultat incorrect dans de rares cas. [#60041](https://github.com/ClickHouse/ClickHouse/pull/60041) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#60177](https://github.com/ClickHouse/ClickHouse/issues/60177) : correction d’un crash de cosineDistance avec Nullable. [#60150](https://github.com/ClickHouse/ClickHouse/pull/60150) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#60279](https://github.com/ClickHouse/ClickHouse/issues/60279) : masquage des informations sensibles pour le moteur de table `S3Queue`. [#60233](https://github.com/ClickHouse/ClickHouse/pull/60233) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#61000](https://github.com/ClickHouse/ClickHouse/issues/61000) : réduction du nombre de lignes lues depuis `system.numbers`. Corrige [#59418](https://github.com/ClickHouse/ClickHouse/issues/59418). [#60546](https://github.com/ClickHouse/ClickHouse/pull/60546) ([JackyWoo](https://github.com/JackyWoo)).
* Rétroporté dans [#60791](https://github.com/ClickHouse/ClickHouse/issues/60791) : correction d’un buffer overflow pouvant survenir si un attaquant demande au serveur HTTP de décompresser des données avec une composition de codecs et une taille provoquant un overflow numérique. Correction d’un buffer overflow pouvant survenir dans le codec NONE en présence de données d’entrée invalides. Ceci a été signalé par l’équipe de recherche TIANGONG via notre [programme Bug Bounty](https://github.com/ClickHouse/ClickHouse/issues/38986). [#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#60783](https://github.com/ClickHouse/ClickHouse/issues/60783) : les fonctions SQL/JSON pouvaient lire de la mémoire non initialisée. Cela clôt [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017). Problème détecté par le fuzzer. [#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#60803](https://github.com/ClickHouse/ClickHouse/issues/60803) : ne pas définir les en-têtes de métadonnées AWS personnalisées `x-amz-meta-*` lors des appels UploadPart et CompleteMultipartUpload. [#60748](https://github.com/ClickHouse/ClickHouse/pull/60748) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)).
* Rétroporté dans [#60820](https://github.com/ClickHouse/ClickHouse/issues/60820) : correction d’un crash dans arrayEnumerateRanked. [#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#60841](https://github.com/ClickHouse/ClickHouse/issues/60841) : correction d’un crash lors de l’utilisation de input() dans INSERT SELECT JOIN. Résout [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035). [#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#60904](https://github.com/ClickHouse/ClickHouse/issues/60904) : évite un segfault si trop de clés d’objet sont ignorées lors de la lecture depuis S3. [#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)).
