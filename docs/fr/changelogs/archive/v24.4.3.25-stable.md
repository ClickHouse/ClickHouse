<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#64982](https://github.com/ClickHouse/ClickHouse/issues/64982) : correction de l’erreur `Block structure mismatch` pour les requêtes qui lisent avec `PREWHERE` depuis la vue matérialisée lorsque celle-ci possède des colonnes de types différents de la table source. Corrige [#64611](https://github.com/ClickHouse/ClickHouse/issues/64611). [#64855](https://github.com/ClickHouse/ClickHouse/pull/64855) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#64974](https://github.com/ClickHouse/ClickHouse/issues/64974) : correction d’un plantage rare lorsqu’une table a un TTL avec une sous-requête + une base de données répliquée + des répliques parallèles + l’analyseur. C’est extrêmement rare, mais veuillez ne pas utiliser de TTL avec des sous-requêtes. [#64858](https://github.com/ClickHouse/ClickHouse/pull/64858) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#65072](https://github.com/ClickHouse/ClickHouse/issues/65072) : correction de la requête `ALTER MODIFY COMMENT`, qui ne fonctionnait plus pour les VIEW paramétrées dans [https://github.com/ClickHouse/ClickHouse/pull/54211](https://github.com/ClickHouse/ClickHouse/pull/54211). [#65031](https://github.com/ClickHouse/ClickHouse/pull/65031) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#65177](https://github.com/ClickHouse/ClickHouse/issues/65177) : correction de l’erreur `Unknown expression identifier` pour les requêtes distantes avec `INTERPOLATE (alias)` (nouvel analyseur). Corrige [#64636](https://github.com/ClickHouse/ClickHouse/issues/64636). [#65090](https://github.com/ClickHouse/ClickHouse/pull/65090) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#65263](https://github.com/ClickHouse/ClickHouse/issues/65263) : correction d’un bug dans l’évaluation en court-circuit des dictionnaires Hashed et Hashed&#95;Array, qui peut lire une valeur numérique non initialisée et entraîner diverses erreurs. [#65256](https://github.com/ClickHouse/ClickHouse/pull/65256) ([jsc0218](https://github.com/jsc0218)).
