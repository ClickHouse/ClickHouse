  # Historique des modifications 2022

<div id="clickhouse-release-v216314-stable-fixme-as-compared-to-v21627-prestable">
  ### Version de ClickHouse v21.6.3.14-stable FIXME par rapport à v21.6.2.7-prestable

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#24531](https://github.com/ClickHouse/ClickHouse/issues/24531) : correction de la réplication zero-copy avec plusieurs volumes S3 (corrige [#22679](https://github.com/ClickHouse/ClickHouse/issues/22679)). [#22864](https://github.com/ClickHouse/ClickHouse/pull/22864) ([ianton-ru](https://github.com/ianton-ru)).
* Rétroporté dans [#24776](https://github.com/ClickHouse/ClickHouse/issues/24776) : ne pas masquer les erreurs telles que `Limit for rows or bytes to read exceeded` dans les sous-requêtes scalaires. [#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#24727](https://github.com/ClickHouse/ClickHouse/issues/24727) : dans le message &quot;multipart/form-data&quot;, considérer le CRLF précédant un délimiteur comme en faisant partie. Corrige [#23905](https://github.com/ClickHouse/ClickHouse/issues/23905). [#24399](https://github.com/ClickHouse/ClickHouse/pull/24399) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#24827](https://github.com/ClickHouse/ClickHouse/issues/24827) : - Correction de l’interblocage pouvant se produire lors du mappage/re-mappage des rôles LDAP, lorsqu’un groupe LDAP est mappé vers un rôle local inexistant. [#24431](https://github.com/ClickHouse/ClickHouse/pull/24431) ([Denis Glazachev](https://github.com/traceon)).
* Rétroporté dans [#24936](https://github.com/ClickHouse/ClickHouse/issues/24936) : - Si la connexion à ZooKeeper était perdue et qu’une réplica était clonée après le rétablissement de la connexion, sa file d’attente de réplication pouvait contenir des entrées obsolètes. Le problème est corrigé. - Correction d’un crash lorsque la file d’attente de réplication contient des parties virtuelles qui se chevauchent. Cela peut rarement se produire si une partie de données a été perdue. Une erreur est désormais consignée dans le journal au lieu d’arrêter le processus. [#24777](https://github.com/ClickHouse/ClickHouse/pull/24777) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#24851](https://github.com/ClickHouse/ClickHouse/issues/24851) : correction d’un bug où l’exception `Mutation was killed` peut être renvoyée au client lors de l’attente d’une mutation alors que celle-ci n’est pas encore chargée en mémoire. [#24809](https://github.com/ClickHouse/ClickHouse/pull/24809) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#24916](https://github.com/ClickHouse/ClickHouse/issues/24916) : correction d’un bug extrêmement rare sur des serveurs disposant de peu de mémoire, qui peut empêcher d’effectuer des merges sans redémarrage. Corrige peut-être [#24603](https://github.com/ClickHouse/ClickHouse/issues/24603). [#24872](https://github.com/ClickHouse/ClickHouse/pull/24872) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#24952](https://github.com/ClickHouse/ClickHouse/issues/24952) : correction d’un possible heap-buffer-overflow dans Arrow. [#24922](https://github.com/ClickHouse/ClickHouse/pull/24922) ([Kruglov Pavel](https://github.com/Avogar)).
