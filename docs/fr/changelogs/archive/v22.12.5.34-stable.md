<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#46983](https://github.com/ClickHouse/ClickHouse/issues/46983) : - Appliquer `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` sur toutes les répliques, car `ALTER TABLE t MOVE` n’est pas répliqué. [#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#45729](https://github.com/ClickHouse/ClickHouse/issues/45729) : correction de la description de clé en présence de clés primaires dupliquées. Cela peut se produire dans les projections. Voir [#45590](https://github.com/ClickHouse/ClickHouse/issues/45590) pour plus de détails. [#45686](https://github.com/ClickHouse/ClickHouse/pull/45686) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#46398](https://github.com/ClickHouse/ClickHouse/issues/46398) : correction de l’échec des requêtes `SYSTEM UNFREEZE` avec l’exception `CANNOT_PARSE_INPUT_ASSERTION_FAILED`. [#46325](https://github.com/ClickHouse/ClickHouse/pull/46325) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Rétroporté dans [#46903](https://github.com/ClickHouse/ClickHouse/issues/46903) : - correction d’une récursion d’alias incorrecte dans QueryNormalizer. [#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#47210](https://github.com/ClickHouse/ClickHouse/issues/47210) : les requêtes `INSERT` via le protocole TCP natif et le protocole HTTP n’étaient pas correctement annulées dans certains cas. Cela pouvait entraîner l’application partielle d’une requête si un client l’annulait, s’il cessait de fonctionner ou, dans de rares cas, en cas d’erreurs réseau. En conséquence, cela pouvait empêcher la déduplication de fonctionner correctement. Corrige [#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) et [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377). [#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#47157](https://github.com/ClickHouse/ClickHouse/issues/47157) : - correction des opérations arithmétiques dans l’optimisation des agrégations avec `min` et `max`. [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#46881](https://github.com/ClickHouse/ClickHouse/issues/46881) : correction d’un problème signalé par MSan dans la fonction `maxIntersections`. Cela clôt [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126). [#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#47359](https://github.com/ClickHouse/ClickHouse/issues/47359) : correction d’un interblocage possible lors de l’annulation d’une requête distribuée. [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).
