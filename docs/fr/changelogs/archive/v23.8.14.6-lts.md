  #### Correction de bug (dysfonctionnement visible par l&#39;utilisateur dans une version stable officielle)

* Rétroporté dans [#63172](https://github.com/ClickHouse/ClickHouse/issues/63172) : définir `server_name` peut aider à résoudre l&#39;erreur de négociation SSL signalée récemment lors de la connexion à MongoDB Atlas : `Poco::Exception. Code: 1000, e.code() = 0, SSL Exception: error:10000438:SSL routines:OPENSSL_internal:TLSV1_ALERT_INTERNAL_ERROR`. [#63122](https://github.com/ClickHouse/ClickHouse/pull/63122) ([Alexander Gololobov](https://github.com/davenger)).
* Rétroporté dans [#63164](https://github.com/ClickHouse/ClickHouse/issues/63164) : la vérification de la version du protocole wire pour MongoDB tentait auparavant d&#39;accéder à la base de données &quot;config&quot;, mais cela peut échouer si l&#39;utilisateur n&#39;a pas les permissions nécessaires. La correction consiste à utiliser le nom de la base de données fourni par l&#39;utilisateur. [#63126](https://github.com/ClickHouse/ClickHouse/pull/63126) ([Alexander Gololobov](https://github.com/davenger)).
