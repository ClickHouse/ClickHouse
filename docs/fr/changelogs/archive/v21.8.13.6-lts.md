<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#32688](https://github.com/ClickHouse/ClickHouse/issues/32688) : le quota n’était pas atteint, mais la limite était malgré tout dépassée. Cette PR corrige [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).
* Rétroporté dans [#32343](https://github.com/ClickHouse/ClickHouse/issues/32343) : corrige un bogue lors de la suppression de colonnes inutiles dans une sous-requête. S’il existe une fonction d’agrégation dans une requête sans GROUP BY, ne pas la supprimer même si elle n’est pas nécessaire. [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

#### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)

* Rétroporté dans [#32108](https://github.com/ClickHouse/ClickHouse/issues/32108) : correction d’un plantage avec un résultat vide sur une requête ODBC. Clôt [#31465](https://github.com/ClickHouse/ClickHouse/issues/31465). [#31766](https://github.com/ClickHouse/ClickHouse/pull/31766) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#32150](https://github.com/ClickHouse/ClickHouse/issues/32150) : correction d’un plantage lorsque la fonction `dictGet`, avec type explicite, est utilisée pour un attribut de dictionnaire dont le type est `Nullable`. Corrige [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980). [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32075](https://github.com/ClickHouse/ClickHouse/issues/32075) : correction d’un bogue dans la fonction transform avec des arguments décimaux. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* Rétroporté dans [#31955](https://github.com/ClickHouse/ClickHouse/issues/31955) : - modification du chemin de configuration de `keeper_server.session_timeout_ms` vers `keeper_server.coordination_settings.session_timeout_ms` lors de la construction d’un `KeeperTCPHandler` - idem pour `operation_timeout`. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* Rétroporté dans [#32161](https://github.com/ClickHouse/ClickHouse/issues/32161) : certaines entrées `GET_PART` pouvaient rester bloquées dans la file d’attente de réplication si une part était perdue sur toutes les répliques et qu’il n’y avait pas d’autres parts dans la même partition. Le problème est corrigé dans les cas où la clé de partition ne contient que des colonnes de types entiers ou `Date[Time]`. Corrige [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485). [#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32146](https://github.com/ClickHouse/ClickHouse/issues/32146) : correction de l’erreur `Directory ... already exists and is not empty` lors du détachement d’une part. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32213](https://github.com/ClickHouse/ClickHouse/issues/32213) : le nombre de répliques actives pouvait être déterminé de manière incorrecte lors d’une insertion avec quorum si le paramètre `replicated_can_become_leader` était désactivé sur certaines répliques. Le problème est corrigé. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32312](https://github.com/ClickHouse/ClickHouse/issues/32312) : les identifiants de dictionnaires XML utilisés dans une requête CREATE TABLE peuvent être qualifiés en `default_database` lors d’une mise à niveau vers une version plus récente. Clôt [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963). [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32540](https://github.com/ClickHouse/ClickHouse/issues/32540) : certaines entrées de la file d’attente de réplication pouvaient rester bloquées pendant `temporary_directories_lifetime` (1 jour par défaut) avec l’erreur `Directory tmp_merge_<part_name>` ou `Part ... (state Deleting) already exists, but it will be deleted soon`, ou une erreur similaire. Le problème est corrigé. Corrige [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32353](https://github.com/ClickHouse/ClickHouse/issues/32353) : correction d’un plantage avec SIGFPE dans la fonction d’agrégation `avgWeighted` avec un argument `Decimal`. Corrige [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#33048](https://github.com/ClickHouse/ClickHouse/issues/33048) : correction d’une exception possible au démarrage du moteur RabbitMQ en retardant la création du canal. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#32795](https://github.com/ClickHouse/ClickHouse/issues/32795) : corrige un crash lors de l’utilisation de fuzzBits avec plusieurs occurrences de la même FixedString, clôt [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737). [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
