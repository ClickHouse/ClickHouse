  ### Version de ClickHouse v20.8.4.11-lts FIXME par rapport à v20.8.3.18-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* rétroporté dans [#15569](https://github.com/ClickHouse/ClickHouse/issues/15569) : il est désormais possible de modifier le type de la colonne de version de `VersionedCollapsingMergeTree` via la requête `ALTER`. [#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#15017](https://github.com/ClickHouse/ClickHouse/issues/15017) : Correction de l'ordre de tri incorrect de la colonne `Nullable`. Corrige [#14344](https://github.com/ClickHouse/ClickHouse/issues/14344). [#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

Ce bogue pouvait produire un résultat de requête incorrect. Il a été mis en évidence dans [#14513](https://github.com/ClickHouse/ClickHouse/issues/14513). [#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird)).

Corrige [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814). [#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#15251](https://github.com/ClickHouse/ClickHouse/issues/15251) : Correction d'une erreur de segmentation dans CacheDictionary [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837). [#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#14955](https://github.com/ClickHouse/ClickHouse/issues/14955) : Correction de l'erreur `.metadata.tmp File exists` lors de l'utilisation du moteur de base de données `MaterializeMySQL`. [#14898](https://github.com/ClickHouse/ClickHouse/pull/14898) ([Winter Zhang](https://github.com/zhang2014)).

Corrige [#14923](https://github.com/ClickHouse/ClickHouse/issues/14923). [#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm)).

[#14975](https://github.com/ClickHouse/ClickHouse/pull/14975) ([alesapin](https://github.com/alesapin)).

* Rétroporté dans [#15208](https://github.com/ClickHouse/ClickHouse/issues/15208) : Ajustement de la taille du champ decimals dans le paquet de définition de colonne MySQL. [#15152](https://github.com/ClickHouse/ClickHouse/pull/15152) ([maqroll](https://github.com/maqroll)).
