<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#58818](https://github.com/ClickHouse/ClickHouse/issues/58818) : ajout de `SYSTEM JEMALLOC PURGE` pour purger les pages jemalloc inutilisées, `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` pour contrôler le profil jemalloc si le profileur est activé. Ajout de commandes 4LW liées à jemalloc dans Keeper : `jmst` pour générer un dump des statistiques jemalloc, `jmfp`, `jmep`, `jmdp` pour contrôler le profil jemalloc si le profileur est activé. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#59877](https://github.com/ClickHouse/ClickHouse/issues/59877) : si vous souhaitez exécuter les scripts initdb à chaque démarrage du conteneur ClickHouse, vous devez définir la variable d&#39;environnement CLICKHOUSE&#95;ALWAYS&#95;RUN&#95;INITDB&#95;SCRIPTS. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).
