* Rétroporté dans [#60793](https://github.com/ClickHouse/ClickHouse/issues/60793) : correction d’un dépassement de tampon pouvant se produire si un attaquant demande au serveur HTTP de décompresser des données avec une composition de codecs et une taille déclenchant un dépassement numérique. Cela a été signalé par l’équipe de recherche TIANGONG via notre [programme Bug Bounty](https://github.com/ClickHouse/ClickHouse/issues/38986).
