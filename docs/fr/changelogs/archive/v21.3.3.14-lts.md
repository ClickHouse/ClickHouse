* Rétroporté dans [#21644](https://github.com/ClickHouse/ClickHouse/issues/21644) : correction du problème où la table S3 conservait d&#39;anciens identifiants après une mise à jour de la configuration. * Rétroporté dans [#21854](https://github.com/ClickHouse/ClickHouse/issues/21854) : correction d&#39;une possible erreur ` Cannot find column` lorsque `optimize_skip_unused_shards` est activé et qu&#39;aucun shard n&#39;est utilisé. * Rétroporté dans [#21811](https://github.com/ClickHouse/ClickHouse/issues/21811) : correction d&#39;un bug dans les moteurs de table ReplicatedMerge lorsque la requête `ALTER MODIFY COLUMN` ne modifie pas le type d&#39;une colonne Decimal si sa taille (32 bits ou 64 bits) ne change pas. * Rétroporté dans [#21883](https://github.com/ClickHouse/ClickHouse/issues/21883) : annulation des pools de connexions S3. [#21737](https://github.com/ClickHouse/ClickHouse/pull/21737) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#21874](https://github.com/ClickHouse/ClickHouse/issues/21874) : correction d&#39;un résultat de la requête incorrect (et d&#39;un possible plantage) pouvant survenir lorsqu&#39;une condition `WHERE` ou `HAVING` est appliquée avant `GROUP BY`. Corrige [#21773](https://github.com/ClickHouse/ClickHouse/issues/21773). [#21841](https://github.com/ClickHouse/ClickHouse/pull/21841) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
