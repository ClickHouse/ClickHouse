<div id="clickhouse-release-v20685-stable-fixme-as-compared-to-v20674-stable">
  ### Release ClickHouse v20.6.8.5-stable FIXME par rapport à v20.6.7.4-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#15567](https://github.com/ClickHouse/ClickHouse/issues/15567) : il est désormais possible de modifier le type de la colonne de version de `VersionedCollapsingMergeTree` avec la requête `ALTER`. [#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#15018](https://github.com/ClickHouse/ClickHouse/issues/15018) : Correction de l'ordre de tri incorrect de la colonne `Nullable`. Cela corrige [#14344](https://github.com/ClickHouse/ClickHouse/issues/14344). [#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#14826](https://github.com/ClickHouse/ClickHouse/issues/14826) : Correction d'une détection erronée de la monotonicité pour le transtypage `Int -> Int` réduit des types signés. Cela pouvait conduire à un résultat de requête incorrect. Ce bogue a été mis en évidence dans [#14513](https://github.com/ClickHouse/ClickHouse/issues/14513). [#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#15147](https://github.com/ClickHouse/ClickHouse/issues/15147) : Correction d'un problème où le serveur pouvait se bloquer au démarrage lors de la communication avec ZooKeeper, si les fichiers de configuration devaient être récupérés depuis ZK (via l'option d'inclusion `from_zk`). Cela corrige [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814). [#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#15253](https://github.com/ClickHouse/ClickHouse/issues/15253) : Correction d'une erreur de segmentation dans CacheDictionary [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837). [#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#14986](https://github.com/ClickHouse/ClickHouse/issues/14986) : Publication des fréquences CPU par cœur logique dans `system.asynchronous_metrics`. Cela corrige [#14923](https://github.com/ClickHouse/ClickHouse/issues/14923). [#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#14968](https://github.com/ClickHouse/ClickHouse/issues/14968) : Correction pour que la poussée de prédicat fonctionne lorsqu'une sous-requête contient la fonction finalizeAggregation. Corrige [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847). [#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#15080](https://github.com/ClickHouse/ClickHouse/issues/15080) : Correction d'un crash dans RIGHT ou FULL JOIN avec join_algorithm='auto' lorsque la limite mémoire est dépassée et qu'il faut remplacer HashJoin par MergeJoin. [#15002](https://github.com/ClickHouse/ClickHouse/pull/15002) ([Artem Zuikov](https://github.com/4ertus2)).
* Rétroporté dans [#15057](https://github.com/ClickHouse/ClickHouse/issues/15057) : Si la fonction `bar` était appelée avec des arguments spécifiquement construits, un dépassement de tampon était possible. Cela ferme [#13926](https://github.com/ClickHouse/ClickHouse/issues/13926). [#15028](https://github.com/ClickHouse/ClickHouse/pull/15028) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#15050](https://github.com/ClickHouse/ClickHouse/issues/15050) : La comparaison avec rembourrage entre String et FixedString est déjà utilisée (https://github.com/ClickHouse/ClickHouse/blob/master/src/Functions/FunctionsComparison.h#L333). Cette PR applique la même logique à la comparaison de champs, ce qui corrige l'utilisation de FixedString comme clés primaires. Cela corrige [#14908](https://github.com/ClickHouse/ClickHouse/issues/14908). [#15033](https://github.com/ClickHouse/ClickHouse/pull/15033) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#15143](https://github.com/ClickHouse/ClickHouse/issues/15143) : Correction de `Data compressed with different methods` dans `join_algorithm='auto'`. Conservation de LowCardinality comme type pour la clé de jointure de la table de gauche dans `join_algorithm='partial_merge'`. [#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2)).
* Rétroporté dans [#15223](https://github.com/ClickHouse/ClickHouse/issues/15223) : Correction d'un bogue dans le moteur de table `Buffer` qui n'autorisait pas l'insertion de données avec une nouvelle structure dans `Buffer` après une requête `ALTER`. Corrige [#15117](https://github.com/ClickHouse/ClickHouse/issues/15117). [#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15404](https://github.com/ClickHouse/ClickHouse/issues/15404) : Correction d'un crash d'instance lors de l'utilisation de joinGet avec des types LowCardinality. Cela corrige [#15214](https://github.com/ClickHouse/ClickHouse/issues/15214). [#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#15279](https://github.com/ClickHouse/ClickHouse/issues/15279) : Correction d'un rapport MSan dans QueryLog. De la mémoire non initialisée pouvait être utilisée pour le champ `memory_usage`. [#15258](https://github.com/ClickHouse/ClickHouse/pull/15258) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#15412](https://github.com/ClickHouse/ClickHouse/issues/15412) : Correction du blocage des requêtes comportant de nombreuses sous-requêtes vers la même table du moteur `MySQL`. Auparavant, si une requête contenait plus de 16 sous-requêtes vers la même table `MySQL`, elle se bloquait indéfiniment. [#15299](https://github.com/ClickHouse/ClickHouse/pull/15299) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#15339](https://github.com/ClickHouse/ClickHouse/issues/15339) : Correction d'une condition de concurrence rare au démarrage du serveur lorsque system.logs est activé. [#15300](https://github.com/ClickHouse/ClickHouse/pull/15300) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15335](https://github.com/ClickHouse/ClickHouse/issues/15335) : Correction d'une condition de concurrence lors du renommage d'une table MergeTree et du nettoyage en arrière-plan. [#15304](https://github.com/ClickHouse/ClickHouse/pull/15304) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15445](https://github.com/ClickHouse/ClickHouse/issues/15445) : Signalement d'une erreur appropriée lorsque le second argument de la fonction d'agrégation `boundingRatio` est d'un type incorrect. [#15407](https://github.com/ClickHouse/ClickHouse/pull/15407) ([detailyang](https://github.com/detailyang)).
* Rétroporté dans [#15508](https://github.com/ClickHouse/ClickHouse/issues/15508) : Correction d'un bogue lié à la souscription aux événements dans DDLWorker, qui pouvait rarement entraîner des blocages de requêtes dans `ON CLUSTER`. Introduit dans [#13450](https://github.com/ClickHouse/ClickHouse/issues/13450). [#15477](https://github.com/ClickHouse/ClickHouse/pull/15477) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15616](https://github.com/ClickHouse/ClickHouse/issues/15616) : Correction des erreurs `Missing columns` lors de la sélection de colonnes absentes des données mais dépendant d'autres colonnes également absentes des données. Corrige [#15530](https://github.com/ClickHouse/ClickHouse/issues/15530). [#15532](https://github.com/ClickHouse/ClickHouse/pull/15532) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15561](https://github.com/ClickHouse/ClickHouse/issues/15561) : Correction d'un bogue où l'opérateur `ILIKE` cessait d'être insensible à la casse si `LIKE` avec le même motif avait été exécuté auparavant. [#15536](https://github.com/ClickHouse/ClickHouse/pull/15536) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15728](https://github.com/ClickHouse/ClickHouse/issues/15728): Une mutation pouvait rester bloquée en attente d'une partie inexistante après `MOVE` ou `REPLACE PARTITION` ou, dans de rares cas, après `DETACH` ou `DROP PARTITION`. Ce problème est corrigé. [#15537](https://github.com/ClickHouse/ClickHouse/pull/15537) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#15654](https://github.com/ClickHouse/ClickHouse/issues/15654): Correction de l'erreur « Database <db> doesn't exist. » dans les requêtes utilisant IN et une table Distributed lorsqu'aucune base de données n'est présente sur l'initiateur. [#15538](https://github.com/ClickHouse/ClickHouse/pull/15538) ([Artem Zuikov](https://github.com/4ertus2)).
* Rétroporté dans [#15586](https://github.com/ClickHouse/ClickHouse/issues/15586): Suppression de la possibilité d'apparition du message d'erreur `Could not calculate available disk space (statvfs), errno: 4, strerror: Interrupted system call`. Cela corrige [#15541](https://github.com/ClickHouse/ClickHouse/issues/15541). [#15557](https://github.com/ClickHouse/ClickHouse/pull/15557) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#15664](https://github.com/ClickHouse/ClickHouse/issues/15664): Correction de l'erreur `Element ... is not a constant expression` lors de l'utilisation du résultat d'une fonction `JSON*` dans `VALUES`, `LIMIT` ou le membre droit de l'opérateur `IN`. [#15589](https://github.com/ClickHouse/ClickHouse/pull/15589) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#15714](https://github.com/ClickHouse/ClickHouse/issues/15714): Correction de l'ordre de libération des ressources dans l'étape `ReadFromStorage` du plan de requête. Cela pouvait provoquer des plantages dans de rares cas. Potentiellement lié à [#15610](https://github.com/ClickHouse/ClickHouse/issues/15610). [#15645](https://github.com/ClickHouse/ClickHouse/pull/15645) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
