  # Journal des modifications 2022

<div id="clickhouse-release-v213762-stable-fixme-as-compared-to-v213655-lts">
  ### Version de ClickHouse v21.3.7.62-stable FIXME par rapport à v21.3.6.55-lts

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#23014](https://github.com/ClickHouse/ClickHouse/issues/23014) : fait passer `background_fetches_pool_size` à 8, ce qui convient mieux à une utilisation en production avec de petites insertions fréquentes ou un cluster ZooKeeper lent. [#22945](https://github.com/ClickHouse/ClickHouse/pull/22945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23081](https://github.com/ClickHouse/ClickHouse/issues/23081) : augmentation du seuil du nombre maximal de correspondances dans le résultat de la fonction `extractAllGroupsHorizontal`. [#23036](https://github.com/ClickHouse/ClickHouse/pull/23036) ([Vasily Nemkov](https://github.com/Enmk)).

<div id="bug-fix">
  #### Correction de bug
</div>

* Rétroporté dans [#23156](https://github.com/ClickHouse/ClickHouse/issues/23156) : correction d’un bug provoquant une attente illimitée pour les requêtes AWS auxiliaires. [#22594](https://github.com/ClickHouse/ClickHouse/pull/22594) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#23033](https://github.com/ClickHouse/ClickHouse/issues/23033) : correction de l’erreur `Cannot find column in ActionsDAG result`, qui peut se produire si une sous-requête utilise `untuple`. Corrige [#22290](https://github.com/ClickHouse/ClickHouse/issues/22290). [#22991](https://github.com/ClickHouse/ClickHouse/pull/22991) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#23075](https://github.com/ClickHouse/ClickHouse/issues/23075) : suppression des détails non essentiels dans les suggestions de clickhouse-client. Cela résout [#22158](https://github.com/ClickHouse/ClickHouse/issues/22158). [#23040](https://github.com/ClickHouse/ClickHouse/pull/23040) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23170](https://github.com/ClickHouse/ClickHouse/issues/23170) : certaines valeurs étaient formatées avec un alignement centré dans les cellules de tableau au format `Markdown`. Ce n’est désormais plus le cas. [#23096](https://github.com/ClickHouse/ClickHouse/pull/23096) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
