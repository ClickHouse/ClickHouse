<div id="bug-fix">
  #### Correction de bug
</div>

* Rétroporté dans [#33018](https://github.com/ClickHouse/ClickHouse/issues/33018) : - le handler de ClickHouse Keeper doit supprimer l’opération une fois la réponse envoyée. [#32988](https://github.com/ClickHouse/ClickHouse/pull/32988) ([JackyWoo](https://github.com/JackyWoo)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#32890](https://github.com/ClickHouse/ClickHouse/issues/32890) : correction de `LOGICAL_ERROR` lorsque la cible d’une vue matérialisée est une table `JOIN` ou `SET`. [#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#33183](https://github.com/ClickHouse/ClickHouse/issues/33183) : le serveur pouvait ne pas démarrer si une base de données avec le moteur `MySQL` ne parvenait pas à se connecter au serveur MySQL ; c’est corrigé. Corrige [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441). [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32904](https://github.com/ClickHouse/ClickHouse/issues/32904) : le moteur de table `MergeTree` pouvait ignorer silencieusement certaines mutations s’il y avait trop de mutations en cours d’exécution ou en cas de consommation mémoire élevée ; c’est corrigé. Corrige [#17882](https://github.com/ClickHouse/ClickHouse/issues/17882). [#32814](https://github.com/ClickHouse/ClickHouse/pull/32814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#33047](https://github.com/ClickHouse/ClickHouse/issues/33047) : correction de l’optimisation avec lazy seek pour les lectures asynchrones depuis un système de fichiers distant. Clôt [#32803](https://github.com/ClickHouse/ClickHouse/issues/32803). [#32835](https://github.com/ClickHouse/ClickHouse/pull/32835) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#32932](https://github.com/ClickHouse/ClickHouse/issues/32932) : clôt [#32487](https://github.com/ClickHouse/ClickHouse/issues/32487). [#32914](https://github.com/ClickHouse/ClickHouse/pull/32914) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#32962](https://github.com/ClickHouse/ClickHouse/issues/32962) : correction d’une régression dans la fonction `replaceRegexpAll`. La fonction se comportait incorrectement lorsque la sous-chaîne correspondante était vide. Clôt [#32777](https://github.com/ClickHouse/ClickHouse/issues/32777). Clôt [#30245](https://github.com/ClickHouse/ClickHouse/issues/30245). [#32945](https://github.com/ClickHouse/ClickHouse/pull/32945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#33067](https://github.com/ClickHouse/ClickHouse/issues/33067) : correction de la vérification de l’URL HDFS, qui n’autorisait pas l’utilisation d’une adresse HA de namenode. Le bug a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042). [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#33100](https://github.com/ClickHouse/ClickHouse/issues/33100) : correction d’une fuite de Context dans le cas de cancel&#95;http&#95;readonly&#95;queries&#95;on&#95;client&#95;close (c.-à-d. une fuite de tables externes qui avaient été téléversées vers le serveur, ainsi que d’autres ressources). [#32982](https://github.com/ClickHouse/ClickHouse/pull/32982) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#33123](https://github.com/ClickHouse/ClickHouse/issues/33123) : correction de l’erreur `Invalid version for SerializationLowCardinality key column` lors de la lecture depuis une colonne `LowCardinality` avec `local_filesystem_read_prefetch` ou `remote_filesystem_read_prefetch` activé. [#33046](https://github.com/ClickHouse/ClickHouse/pull/33046) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
