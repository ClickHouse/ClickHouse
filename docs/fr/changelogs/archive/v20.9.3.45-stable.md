<div id="clickhouse-release-v209345-stable-fixme-as-compared-to-v209220-stable">
  ### Release ClickHouse v20.9.3.45-stable FIXME par rapport à v20.9.2.20-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#15568](https://github.com/ClickHouse/ClickHouse/issues/15568) : il est désormais possible de modifier le type de la colonne de version dans `VersionedCollapsingMergeTree` avec la requête `ALTER`. [#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#15150](https://github.com/ClickHouse/ClickHouse/issues/15150) : Correction d'un problème où le serveur pouvait rester bloqué au démarrage lors de la communication avec ZooKeeper, si les fichiers de configuration devaient être récupérés depuis ZK (via l'option d'inclusion `from_zk`). Corrige [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814). [#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#15250](https://github.com/ClickHouse/ClickHouse/issues/15250) : Correction d'un segfault dans CacheDictionary [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837). [#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#14971](https://github.com/ClickHouse/ClickHouse/issues/14971) : Correction du push down de prédicat lorsqu'une sous-requête contient la fonction finalizeAggregation. Corrige [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847). [#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#15104](https://github.com/ClickHouse/ClickHouse/issues/15104) : Correction de l'erreur `Cannot rename ... errno: 22, strerror: Invalid argument` survenant lors de l'exécution d'une requête DDL dans une base de données Atomic avec clickhouse-server dans Docker sur Mac OS. [#15024](https://github.com/ClickHouse/ClickHouse/pull/15024) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#15141](https://github.com/ClickHouse/ClickHouse/issues/15141) : Correction de `Data compressed with different methods` dans `join_algorithm='auto'`. Conservation du type LowCardinality pour la clé de jointure de la table de gauche dans `join_algorithm='partial_merge'`. [#15088](https://github.com/ClickHouse/ClickHouse/pull/15088) ([Artem Zuikov](https://github.com/4ertus2)).
* Rétroporté dans [#15209](https://github.com/ClickHouse/ClickHouse/issues/15209) : Ajustement de la taille du champ decimals dans le paquet de définition de colonne MySQL. [#15152](https://github.com/ClickHouse/ClickHouse/pull/15152) ([maqroll](https://github.com/maqroll)).
* Rétroporté dans [#15224](https://github.com/ClickHouse/ClickHouse/issues/15224) : Correction d'un bug dans le moteur de table `Buffer` qui empêchait l'insertion de données d'une nouvelle structure dans `Buffer` après une requête `ALTER`. Corrige [#15117](https://github.com/ClickHouse/ClickHouse/issues/15117). [#15192](https://github.com/ClickHouse/ClickHouse/pull/15192) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15403](https://github.com/ClickHouse/ClickHouse/issues/15403) : Correction d'un crash lors de l'utilisation de joinGet avec des types LowCardinality. Corrige [#15214](https://github.com/ClickHouse/ClickHouse/issues/15214). [#15220](https://github.com/ClickHouse/ClickHouse/pull/15220) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#15487](https://github.com/ClickHouse/ClickHouse/issues/15487) : Correction de l'erreur « Unknown identifier » dans GROUP BY lorsqu'une requête comporte un JOIN sur une table Merge. [#15242](https://github.com/ClickHouse/ClickHouse/pull/15242) ([Artem Zuikov](https://github.com/4ertus2)).
* Rétroporté dans [#15282](https://github.com/ClickHouse/ClickHouse/issues/15282) : Correction d'un rapport MSan dans QueryLog. De la mémoire non initialisée pouvait être utilisée pour le champ `memory_usage`. [#15258](https://github.com/ClickHouse/ClickHouse/pull/15258) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#15401](https://github.com/ClickHouse/ClickHouse/issues/15401) : Correction du blocage des requêtes comportant de nombreuses sous-requêtes vers la même table du moteur `MySQL`. Auparavant, si une requête contenait plus de 16 sous-requêtes vers la même table `MySQL`, elle se bloquait indéfiniment. [#15299](https://github.com/ClickHouse/ClickHouse/pull/15299) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#15340](https://github.com/ClickHouse/ClickHouse/issues/15340) : Correction d'une condition de concurrence rare au démarrage du serveur lorsque system.logs est activé. [#15300](https://github.com/ClickHouse/ClickHouse/pull/15300) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15336](https://github.com/ClickHouse/ClickHouse/issues/15336) : Correction d'une condition de concurrence lors du renommage d'une table MergeTree et du nettoyage en arrière-plan. [#15304](https://github.com/ClickHouse/ClickHouse/pull/15304) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15588](https://github.com/ClickHouse/ClickHouse/issues/15588) : Correction d'un bug où des requêtes telles que SELECT toStartOfDay(today()) échouaient en signalant un argument time_zone vide. [#15319](https://github.com/ClickHouse/ClickHouse/pull/15319) ([Bharat Nallan](https://github.com/bharatnc)).
* Rétroporté dans [#15446](https://github.com/ClickHouse/ClickHouse/issues/15446) : Correction pour signaler une erreur appropriée lorsque le second argument de la fonction d'agrégation `boundingRatio` est d'un type incorrect. [#15407](https://github.com/ClickHouse/ClickHouse/pull/15407) ([detailyang](https://github.com/detailyang)).
* Rétroporté dans [#15507](https://github.com/ClickHouse/ClickHouse/issues/15507) : Correction d'un bug lié à la souscription aux événements dans DDLWorker pouvant rarement entraîner le blocage de requêtes dans `ON CLUSTER`. Introduit dans [#13450](https://github.com/ClickHouse/ClickHouse/issues/13450). [#15477](https://github.com/ClickHouse/ClickHouse/pull/15477) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15549](https://github.com/ClickHouse/ClickHouse/issues/15549) : Correction des erreurs `Missing columns` lors de la sélection de colonnes absentes des données mais dépendant d'autres colonnes également absentes des données. Corrige [#15530](https://github.com/ClickHouse/ClickHouse/issues/15530). [#15532](https://github.com/ClickHouse/ClickHouse/pull/15532) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15560](https://github.com/ClickHouse/ClickHouse/issues/15560) : Correction d'un bug où l'opérateur `ILIKE` cessait d'être insensible à la casse si `LIKE` avec le même motif avait été exécuté auparavant. [#15536](https://github.com/ClickHouse/ClickHouse/pull/15536) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15725](https://github.com/ClickHouse/ClickHouse/issues/15725) : Une mutation pouvait se bloquer en attendant une partie inexistante après `MOVE` ou `REPLACE PARTITION`, ou, dans de rares cas, après `DETACH` ou `DROP PARTITION`. Ce problème est corrigé. [#15537](https://github.com/ClickHouse/ClickHouse/pull/15537) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#15655](https://github.com/ClickHouse/ClickHouse/issues/15655) : Correction de l'erreur « Database <db> doesn't exist. » dans les requêtes utilisant IN et une table Distributed lorsqu'il n'existe pas de base de données sur l'initiateur. [#15538](https://github.com/ClickHouse/ClickHouse/pull/15538) ([Artem Zuikov](https://github.com/4ertus2)).
* Rétroporté dans [#15631](https://github.com/ClickHouse/ClickHouse/issues/15631) : Réduction significative de l'utilisation mémoire dans AggregatingInOrderTransform/optimize_aggregation_in_order. [#15543](https://github.com/ClickHouse/ClickHouse/pull/15543) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#15583](https://github.com/ClickHouse/ClickHouse/issues/15583) : Suppression de la possibilité d'apparition du message d'erreur `Could not calculate available disk space (statvfs), errno: 4, strerror: Interrupted system call`. Corrige [#15541](https://github.com/ClickHouse/ClickHouse/issues/15541). [#15557](https://github.com/ClickHouse/ClickHouse/pull/15557) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#15665](https://github.com/ClickHouse/ClickHouse/issues/15665) : correction de l'erreur `Element ... is not a constant expression` lors de l'utilisation du résultat d'une fonction `JSON*` dans `VALUES`, `LIMIT` ou le membre droit de l'opérateur `IN`. [#15589](https://github.com/ClickHouse/ClickHouse/pull/15589) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#15712](https://github.com/ClickHouse/ClickHouse/issues/15712) : correction de l'ordre de destruction des ressources dans l'étape `ReadFromStorage` du plan de requête. Ce problème pouvait provoquer des plantages dans de rares cas. Potentiellement lié à [#15610](https://github.com/ClickHouse/ClickHouse/issues/15610). [#15645](https://github.com/ClickHouse/ClickHouse/pull/15645) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#15696](https://github.com/ClickHouse/ClickHouse/issues/15696) : correction d'une situation de compétition dans AMQP-CPP. [#15667](https://github.com/ClickHouse/ClickHouse/pull/15667) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#15739](https://github.com/ClickHouse/ClickHouse/issues/15739) : correction de l'erreur `Cannot find column` pouvant survenir lors d'une insertion dans une `MATERIALIZED VIEW` lorsque la requête associée à la vue contient un `ARRAY JOIN`.
