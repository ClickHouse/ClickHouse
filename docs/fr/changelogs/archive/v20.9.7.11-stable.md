</div>

Corrige [#7748](https://github.com/ClickHouse/ClickHouse/issues/7748). [#16988](https://github.com/ClickHouse/ClickHouse/pull/16988) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### Correctif
</div>

* Rétroporté dans [#17316](https://github.com/ClickHouse/ClickHouse/issues/17316) : renvoie le nombre de lignes affectées pour les requêtes INSERT via le protocole MySQL. Auparavant, ClickHouse renvoyait toujours 0 ; c’est désormais corrigé. Corrige [#16605](https://github.com/ClickHouse/ClickHouse/issues/16605). [#16715](https://github.com/ClickHouse/ClickHouse/pull/16715) ([Winter Zhang](https://github.com/zhang2014)).
* Rétroporté dans [#17343](https://github.com/ClickHouse/ClickHouse/issues/17343) : TODO. [#16866](https://github.com/ClickHouse/ClickHouse/pull/16866) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#17196](https://github.com/ClickHouse/ClickHouse/issues/17196) : évite des erreurs réseau inutiles pour les requêtes distantes pouvant être annulées pendant l’exécution, comme les requêtes avec `LIMIT`. [#17006](https://github.com/ClickHouse/ClickHouse/pull/17006) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#17432](https://github.com/ClickHouse/ClickHouse/issues/17432) : correction de bug pour la fonction fuzzBits, issue liée : [#16980](https://github.com/ClickHouse/ClickHouse/issues/16980). [#17051](https://github.com/ClickHouse/ClickHouse/pull/17051) ([hexiaoting](https://github.com/hexiaoting)).
* Rétroporté dans [#17129](https://github.com/ClickHouse/ClickHouse/issues/17129) : correction d’un crash sur la requête `CREATE TABLE ... AS some_table` lorsque `some_table` avait été créée avec `AS table_function()`. Corrige [#16944](https://github.com/ClickHouse/ClickHouse/issues/16944). [#17072](https://github.com/ClickHouse/ClickHouse/pull/17072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#17195](https://github.com/ClickHouse/ClickHouse/issues/17195) : corrige la comparaison de ColumnConst qui entraîne un crash. Cela corrige [#17088](https://github.com/ClickHouse/ClickHouse/issues/17088). [#17135](https://github.com/ClickHouse/ClickHouse/pull/17135) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#17402](https://github.com/ClickHouse/ClickHouse/issues/17402) : corrige [#15235](https://github.com/ClickHouse/ClickHouse/issues/15235). Lorsque clickhouse-copier traite une table non partitionnée, il provoque un segfault. [#17248](https://github.com/ClickHouse/ClickHouse/pull/17248) ([Qi Chen](https://github.com/kaka11chen)).
* Rétroporté dans [#17409](https://github.com/ClickHouse/ClickHouse/issues/17409) : corrige l’invalidation de l’index set lorsqu’il y a des colonnes const dans la sous-requête. Cela corrige [#17246](https://github.com/ClickHouse/ClickHouse/issues/17246). [#17249](https://github.com/ClickHouse/ClickHouse/pull/17249) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#17488](https://github.com/ClickHouse/ClickHouse/issues/17488) : corrige un crash lors de la lecture depuis la table `JOIN` avec des types `LowCardinality`. Corrige [#17228](https://github.com/ClickHouse/ClickHouse/issues/17228). [#17397](https://github.com/ClickHouse/ClickHouse/pull/17397) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#17492](https://github.com/ClickHouse/ClickHouse/issues/17492) : corrige les doublons après `DISTINCT`, qui étaient possibles en raison d’une optimisation incorrecte. Corrige [#17294](https://github.com/ClickHouse/ClickHouse/issues/17294). [#17296](https://github.com/ClickHouse/ClickHouse/pull/17296) ([li chengxiang](https://github.com/chengxianglibra)). [#17439](https://github.com/ClickHouse/ClickHouse/pull/17439) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#17522](https://github.com/ClickHouse/ClickHouse/issues/17522) : correction de `ORDER BY` lorsque le paramètre `optimize_redundant_functions_in_order_by` est activé. [#17471](https://github.com/ClickHouse/ClickHouse/pull/17471) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#17535](https://github.com/ClickHouse/ClickHouse/issues/17535) : correction d’un bug où la taille du cache de marks était sous-estimée par ClickHouse. Cela peut se produire en présence d’un grand nombre de petits fichiers de marks. [#17496](https://github.com/ClickHouse/ClickHouse/pull/17496) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#17627](https://github.com/ClickHouse/ClickHouse/issues/17627) : correction du blocage d’une requête ALTER lorsque la mutation correspondante avait été arrêtée sur une autre réplique. Corrige [#16953](https://github.com/ClickHouse/ClickHouse/issues/16953). [#17499](https://github.com/ClickHouse/ClickHouse/pull/17499) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#17608](https://github.com/ClickHouse/ClickHouse/issues/17608) : lorsque clickhouse-client est utilisé en mode interactif avec des requêtes sur plusieurs lignes, un commentaire sur une seule ligne était étendu par erreur jusqu’à la fin de la requête. Cela corrige [#13654](https://github.com/ClickHouse/ClickHouse/issues/13654). [#17565](https://github.com/ClickHouse/ClickHouse/pull/17565) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#17729](https://github.com/ClickHouse/ClickHouse/issues/17729) : correction de l’erreur `Function not implemented` lors de l’exécution d’une requête `RENAME` dans une base de données `Atomic`, avec ClickHouse exécuté sur Windows Subsystem for Linux. Corrige [#17661](https://github.com/ClickHouse/ClickHouse/issues/17661). [#17664](https://github.com/ClickHouse/ClickHouse/pull/17664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#17782](https://github.com/ClickHouse/ClickHouse/issues/17782) : correction d’un problème empêchant ClickHouse de rétablir la connexion aux serveurs MySQL. [#17681](https://github.com/ClickHouse/ClickHouse/pull/17681) ([Alexander Kazakov](https://github.com/Akazz)).
* Rétroporté dans [#17814](https://github.com/ClickHouse/ClickHouse/issues/17814) : ne pas restaurer les parts depuis le WAL si `in_memory_parts_enable_wal` est désactivé. [#17802](https://github.com/ClickHouse/ClickHouse/pull/17802) ([detailyang](https://github.com/detailyang)).
