  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v218615-lts-fixme-as-compared-to-v21857-lts">
  ### Version de ClickHouse v21.8.6.15-lts FIXME par rapport à v21.8.5.7-lts
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#28899](https://github.com/ClickHouse/ClickHouse/issues/28899) : utilisation d’un vrai fichier temporaire au lieu de « rows&#95;sources » prédéfini pour les fusions verticales. Cela évite de générer des répertoires parasites dans les disks tmp. [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#28642](https://github.com/ClickHouse/ClickHouse/issues/28642) : corrige une logique inhabituelle d’expiration des sessions dans Keeper. Cela devrait probablement aider en intégration continue : [https://clickhouse-test-reports.s3.yandex.net/0/6bd9b82141c98dcd7796fd9d08326831095ba519/stress&#95;test&#95;(debug).html#fail1](https://clickhouse-test-reports.s3.yandex.net/0/6bd9b82141c98dcd7796fd9d08326831095ba519/stress_test_\(debug\).html#fail1). [#28519](https://github.com/ClickHouse/ClickHouse/pull/28519) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28718](https://github.com/ClickHouse/ClickHouse/issues/28718) : à ajouter. Résout [#28529](https://github.com/ClickHouse/ClickHouse/issues/28529). [#28614](https://github.com/ClickHouse/ClickHouse/pull/28614) ([Kseniia Sumarokova](https://github.com/kssenii)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#27923](https://github.com/ClickHouse/ClickHouse/issues/27923) : correction du transtypage de style PostgreSQL (opérateur `::`) avec des nombres négatifs. [#27876](https://github.com/ClickHouse/ClickHouse/pull/27876) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28753](https://github.com/ClickHouse/ClickHouse/issues/28753) : correction de la transformation de chaînes de disjonctions en `IN` (contrôlée par le paramètre `optimize_min_equality_disjunction_chain_length`) dans les requêtes distribuées avec le paramètre `legacy_column_name_of_tuple_literal = 0`. [#28658](https://github.com/ClickHouse/ClickHouse/pull/28658) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#28644](https://github.com/ClickHouse/ClickHouse/issues/28644) : corrige un cas rare où des modifications des paramètres de `clickhouse-keeper` peuvent entraîner une perte de logs et le blocage du serveur. [#28360](https://github.com/ClickHouse/ClickHouse/pull/28360) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28508](https://github.com/ClickHouse/ClickHouse/issues/28508) : corrige l’absence de guillemets autour des noms de tables dans le moteur MaterializedPostgreSQL. Clôt [#28316](https://github.com/ClickHouse/ClickHouse/issues/28316). [#28433](https://github.com/ClickHouse/ClickHouse/pull/28433) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#28510](https://github.com/ClickHouse/ClickHouse/issues/28510) : corrige une possible fuite de watches ZooKeeper lors du traitement en arrière-plan de la DDL queue distribuée. Clôt [#26036](https://github.com/ClickHouse/ClickHouse/issues/26036). [#28446](https://github.com/ClickHouse/ClickHouse/pull/28446) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#28573](https://github.com/ClickHouse/ClickHouse/issues/28573) : corrige un bogue pouvant entraîner l’erreur `Existing table metadata in ZooKeeper differs in sorting key expression.` après une opération `ALTER` sur `ReplicatedVersionedCollapsingMergeTree`. Corrige [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515). [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28597](https://github.com/ClickHouse/ClickHouse/issues/28597) : corrige l’erreur `There is no subcolumn` lors d’un `SELECT` depuis des tables comportant des colonnes `Nested` et des colonnes scalaires avec un point dans leur nom et le même préfixe que `Nested` (par ex. `n.id UInt32, n.arr1 Array(UInt64), n.arr2 Array(UInt64)`). [#28531](https://github.com/ClickHouse/ClickHouse/pull/28531) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28714](https://github.com/ClickHouse/ClickHouse/issues/28714) : ajoute les alias Settings.Names et Settings.Values pour la table system.processes. [#28685](https://github.com/ClickHouse/ClickHouse/pull/28685) ([Vitaly Orlov](https://github.com/orloffv)).
* Rétroporté dans [#28741](https://github.com/ClickHouse/ClickHouse/issues/28741) : corrige le coredump lors de la création de tables distribuées lorsque les paramètres fournis sont incorrects. [#28686](https://github.com/ClickHouse/ClickHouse/pull/28686) ([Zhiyong Wang](https://github.com/ljcui)).
* Rétroporté dans [#28791](https://github.com/ClickHouse/ClickHouse/issues/28791) : corrige une race condition bénigne dans ReplicatedMergeTreeQueue. Elle ne devrait pas être visible par l’utilisateur, mais peut entraîner des bogues subtils. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28994](https://github.com/ClickHouse/ClickHouse/issues/28994) : corrige une race condition entre `DROP PART` et `REPLACE/MOVE PARTITION` qui pouvait, dans de rares cas, faire diverger les répliques. [#28864](https://github.com/ClickHouse/ClickHouse/pull/28864) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#28948](https://github.com/ClickHouse/ClickHouse/issues/28948) : corrige la lecture des sous-colonnes depuis des compact parts. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28930](https://github.com/ClickHouse/ClickHouse/issues/28930) : corrige les fonctions de tableau d’ordre supérieur (`SIGSEGV` pour `arrayCompact`/`ILLEGAL_COLUMN` pour `arrayDifference`/`arrayCumSumNonNegative`) avec des constantes. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
