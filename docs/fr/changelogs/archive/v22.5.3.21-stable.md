<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#38241](https://github.com/ClickHouse/ClickHouse/issues/38241) : correction d’un possible crash lors d’un `insert` asynchrone avec `Distributed` en cas de suppression d’une réplica de la config. [#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#39098](https://github.com/ClickHouse/ClickHouse/issues/39098) : toute allocation à l’intérieur d’OvercommitTracker peut entraîner un interblocage. La journalisation n’était pas très informative, il est donc plus simple de la supprimer. Corrige [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794). [#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#39078](https://github.com/ClickHouse/ClickHouse/issues/39078) : correction d’un bogue dans le cache du système de fichiers pouvant survenir dans certains cas limites, lorsque la capacité du cache atteint sa limite. Clôt [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066). [#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#39152](https://github.com/ClickHouse/ClickHouse/issues/39152) : correction de l’erreur `Block structure mismatch`, qui pouvait survenir lors d’un INSERT dans une table avec une MATERIALIZED VIEW attachée et le paramètre `extremes = 1` activé. Clôt [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) et [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729). [#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#39274](https://github.com/ClickHouse/ClickHouse/issues/39274) : correction de l’erreur `Not found column Type in block` dans des requêtes SELECT avec `PREWHERE` et des optimisations de lecture dans l’ordre. [#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#39369](https://github.com/ClickHouse/ClickHouse/issues/39369) : déclaration de la file RabbitMQ sans les arguments par défaut `x-max-length` et `x-overflow`. [#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* Rétroporté dans [#39350](https://github.com/ClickHouse/ClickHouse/issues/39350) : correction d’une requête incorrecte de récupération des tables PostgreSQL pour le moteur de base de données PostgreSQL. Clôt [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502). [#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
