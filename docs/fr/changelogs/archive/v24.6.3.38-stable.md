<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#66770](https://github.com/ClickHouse/ClickHouse/issues/66770) : Faire en sorte que allow&#95;experimental&#95;analyzer soit contrôlé par l’initiateur pour les requêtes distribuées. Cela garantit la compatibilité et le bon fonctionnement lors des opérations dans des clusters mélangeant plusieurs versions. [#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#66885](https://github.com/ClickHouse/ClickHouse/issues/66885) : correction d’une taille inattendue d’une colonne à faible cardinalité dans les appels de fonction. [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#66303](https://github.com/ClickHouse/ClickHouse/issues/66303) : meilleure gestion des conditions de jointure impliquant des vérifications `IS NULL` (par exemple, `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` est réécrit en `ON a <=> b`), correction d’une optimisation incorrecte lorsque des conditions autres que `IS NULL` sont présentes. [#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#66330](https://github.com/ClickHouse/ClickHouse/issues/66330) : ajout des paramètres manquants `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` au cache d’inférence de schéma, car ils peuvent modifier le schéma résultant. Cela évite des résultats incorrects de l’inférence de schéma lorsque ces paramètres sont modifiés. [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#66157](https://github.com/ClickHouse/ClickHouse/issues/66157) : correction d’un bogue de dépassement de tampon dans l’implémentation de `unbin`/`unhex`. [#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#66210](https://github.com/ClickHouse/ClickHouse/issues/66210) : désactivation de l’optimisation `merge-filters` introduite dans [#64760](https://github.com/ClickHouse/ClickHouse/issues/64760). Elle peut provoquer une exception si l’optimisation fusionne deux expressions de filtre sans appliquer d’évaluation en court-circuit. [#66126](https://github.com/ClickHouse/ClickHouse/pull/66126) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#66456](https://github.com/ClickHouse/ClickHouse/issues/66456) : correction d’un bogue dans le client ZooKeeper : une session pouvait rester bloquée dans un état inutilisable après avoir reçu une erreur matérielle de ZooKeeper. Par exemple, cela peut se produire à cause de &quot;soft memory limit&quot; dans ClickHouse Keeper. [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#66228](https://github.com/ClickHouse/ClickHouse/issues/66228) : correction d’un problème dans SumIfToCountIfVisitor avec les entiers signés. [#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
