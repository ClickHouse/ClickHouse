  #### Changement non rétrocompatible
</div>

* Rétroporté dans [#49981](https://github.com/ClickHouse/ClickHouse/issues/49981) : Annulation de &quot;`groupArray` returns cannot be nullable&quot; (à cause d’une rupture de compatibilité binaire pour `groupArray`/`groupArrayLast`/`groupArraySample` sur les types `Nullable`, ce qui risque d’entraîner `TOO_LARGE_ARRAY_SIZE` ou `CANNOT_READ_ALL_DATA`). [#49971](https://github.com/ClickHouse/ClickHouse/pull/49971) ([Azat Khuzhin](https://github.com/azat)).
