  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#76214](https://github.com/ClickHouse/ClickHouse/issues/76214) : `clickhouse-library-bridge` permet d’ouvrir des bibliothèques arbitraires depuis le système de fichiers, ce qui ne permet de l’exécuter en toute sécurité que dans un environnement isolé. Pour éviter une vulnérabilité lorsqu’il est exécuté à proximité de clickhouse-server, nous limiterons les chemins d’accès des bibliothèques à un emplacement défini dans la configuration. Cette vulnérabilité a été découverte dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par **Arseniy Dugin**. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
