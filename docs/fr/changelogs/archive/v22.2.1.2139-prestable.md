<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* (Pas prêt pour la production, placé dans les fonctionnalités expérimentales) Ajout de la surallocation mémoire à `MemoryTracker`. Ajout des paramètres `guaranteed` pour les limites de mémoire, qui représentent des limites de mémoire souples. Lorsque la limite stricte de mémoire est atteinte, `MemoryTracker` tente d’annuler la requête la plus surallouée. Le nouveau paramètre `memory_usage_overcommit_max_wait_microseconds` indique combien de temps les requêtes peuvent attendre l’arrêt d’une autre requête. Closes [#28375](https://github.com/ClickHouse/ClickHouse/issues/28375). [#31182](https://github.com/ClickHouse/ClickHouse/pull/31182) ([Dmitry Novik](https://github.com/novikd)).
* Ce paramètre permet à l’utilisateur de définir sa propre sémantique de déduplication dans MergeTree/ReplicatedMergeTree. S’il est fourni, il est utilisé à la place de l’empreinte des données pour générer l’ID de block. Ainsi, par exemple, en fournissant une valeur unique pour ce paramètre dans chaque instruction INSERT, l’utilisateur peut éviter que les mêmes données insérées soient dédupliquées. This closes: [#7461](https://github.com/ClickHouse/ClickHouse/issues/7461). [#32304](https://github.com/ClickHouse/ClickHouse/pull/32304) ([Igor Nikonov](https://github.com/devcrafter)).
* Ajout de la prise en charge du mot-clé DEFAULT pour les instruction INSERT. Closes [#6331](https://github.com/ClickHouse/ClickHouse/issues/6331). [#33141](https://github.com/ClickHouse/ClickHouse/pull/33141) ([Andrii Buriachevskyi](https://github.com/0over)).
* Ajout des intervalles de confiance aux ttests. [#33260](https://github.com/ClickHouse/ClickHouse/pull/33260) ([achimbab](https://github.com/achimbab)).
* Permet de créer de nouveaux fichiers lors d’un insert pour les moteurs File/S3/HDFS. Permet d’écraser un fichier dans HDFS. Lève par défaut une exception lors d’une tentative d’écrasement d’un fichier dans S3. Lève une exception lors d’une tentative d’ajout de données à un fichier dans des formats qui ont un suffixe. Closes [#31640](https://github.com/ClickHouse/ClickHouse/issues/31640) Closes [#31622](https://github.com/ClickHouse/ClickHouse/issues/31622) Closes [#23862](https://github.com/ClickHouse/ClickHouse/issues/23862) Closes [#15022](https://github.com/ClickHouse/ClickHouse/issues/15022) Closes [#16674](https://github.com/ClickHouse/ClickHouse/issues/16674). Clôt [#34300](https://github.com/ClickHouse/ClickHouse/issues/34300). [#34317](https://github.com/ClickHouse/ClickHouse/pull/34317) ([flynn](https://github.com/ucasfl)).

[#34484](https://github.com/ClickHouse/ClickHouse/pull/34484) ([zhanglistar](https://github.com/zhanglistar)).
* Améliore les performances des insertions dans les fonctions de table URL, S3, File et HDFS. Clôt [#34348](https://github.com/ClickHouse/ClickHouse/issues/34348). [#34510](https://github.com/ClickHouse/ClickHouse/pull/34510) ([Maksim Kita](https://github.com/kitaisreal)).
