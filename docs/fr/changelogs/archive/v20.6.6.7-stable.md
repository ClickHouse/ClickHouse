  ### Version ClickHouse v20.6.6.7-stable FIXME par rapport à la v20.6.5.8-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#14359](https://github.com/ClickHouse/ClickHouse/issues/14359) : ajout de l’authentification `requirepass` pour Redis. [#13688](https://github.com/ClickHouse/ClickHouse/pull/13688) ([Ivan Torgashov](https://github.com/it1804)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#14365](https://github.com/ClickHouse/ClickHouse/issues/14365) : arrêter l’exécution de la requête si une exception se produit dans `PipelineExecutor` lui-même. Cela peut éviter de rares blocages de requêtes. [#14334](https://github.com/ClickHouse/ClickHouse/pull/14334) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#14540](https://github.com/ClickHouse/ClickHouse/issues/14540) : arrêter l’exécution de la requête si une exception se produit dans `PipelineExecutor` lui-même. Cela peut éviter de rares blocages de requêtes. Suite de [#14334](https://github.com/ClickHouse/ClickHouse/issues/14334). [#14402](https://github.com/ClickHouse/ClickHouse/pull/14402) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#14488](https://github.com/ClickHouse/ClickHouse/issues/14488) : correction d’un bogue entraînant une mauvaise attribution des merges si la table comporte des partitions avec une seule part. [#14444](https://github.com/ClickHouse/ClickHouse/pull/14444) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#14483](https://github.com/ClickHouse/ClickHouse/issues/14483) : vérifier les dépassements de taille de tableau dans la fonction d’agrégation `topK`. Sans cette vérification, l’utilisateur peut envoyer une requête avec des paramètres soigneusement conçus entraînant un crash du serveur. Ceci clôt [#14452](https://github.com/ClickHouse/ClickHouse/issues/14452). [#14467](https://github.com/ClickHouse/ClickHouse/pull/14467) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#14598](https://github.com/ClickHouse/ClickHouse/issues/14598) : correction de rares segfaults dans les fonctions avec le combinateur -Resample, qui pouvaient apparaître à la suite d’un overflow avec de très grands paramètres. [#14562](https://github.com/ClickHouse/ClickHouse/pull/14562) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#14667](https://github.com/ClickHouse/ClickHouse/issues/14667) : correction d’un résultat erroné de multiplication Decimal dû à une mauvaise échelle décimale dans la colonne de résultat. [#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)).
