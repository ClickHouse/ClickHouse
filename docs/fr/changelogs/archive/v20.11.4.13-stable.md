<div id="clickhouse-release-v2011413-stable-fixme-as-compared-to-v201133-stable">
  ### Version de ClickHouse v20.11.4.13-stable FIXME par rapport à v20.11.3.3-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#17032](https://github.com/ClickHouse/ClickHouse/issues/17032) : permettre la connexion à l’endpoint sécurisé de `clickhouse-server` nécessitant le SNI. Cela est possible lorsque `clickhouse-server` est hébergé derrière un proxy TLS. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#17074](https://github.com/ClickHouse/ClickHouse/issues/17074) : corrige [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574) et [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) ; corrige l’échec des requêtes distantes lors de l’utilisation de la fonction d’agrégation avec le suffixe &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Rétroporté dans [#17024](https://github.com/ClickHouse/ClickHouse/issues/17024) : corrige un crash lors de l’utilisation de `any` sans argument. Concerne [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#16881](https://github.com/ClickHouse/ClickHouse/issues/16881) : interrompt le téléversement multipart si aucune donnée n’a été écrite dans WriteBufferFromS3. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Rétroporté dans [#16948](https://github.com/ClickHouse/ClickHouse/issues/16948) : évite les crashs du serveur ClickHouse lors de l’utilisation de TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17076](https://github.com/ClickHouse/ClickHouse/issues/17076) : corrige l’erreur possible `Illegal type of argument` pour les requêtes avec `ORDER BY`. Corrige [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#17010](https://github.com/ClickHouse/ClickHouse/issues/17010) : le script d’installation doit toujours créer des sous-répertoires dans les dossiers de configuration. Cela ne concerne que les builds Docker avec une configuration personnalisée. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#16966](https://github.com/ClickHouse/ClickHouse/issues/16966) : les informations de blame n’étaient pas calculées correctement dans `clickhouse-git-import`. [#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#17014](https://github.com/ClickHouse/ClickHouse/issues/17014) : corrige un possible crash du serveur après `ALTER TABLE ... MODIFY COLUMN ... NewType` lorsqu’un `SELECT` contient une expression `WHERE` sur la colonne en cours de modification et que l’opération ALTER n’est pas encore terminée. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#17039](https://github.com/ClickHouse/ClickHouse/issues/17039) : résout de nouveau l’IP de `format_avro_schema_registry_url` en cas d’erreur. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17093](https://github.com/ClickHouse/ClickHouse/issues/17093) : corrige un résultat erroné sur les grands entiers (128 et 256 bits) lors d’une conversion depuis Double. [#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc)).
* Rétroporté dans [#17127](https://github.com/ClickHouse/ClickHouse/issues/17127) : évite des erreurs réseau inutiles pour les requêtes distantes susceptibles d’être annulées pendant l’exécution, comme les requêtes avec `LIMIT`. [#17006](https://github.com/ClickHouse/ClickHouse/pull/17006) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#17132](https://github.com/ClickHouse/ClickHouse/issues/17132) : correction d’un crash lors de l’exécution de la requête `CREATE TABLE ... AS some_table` lorsque `some_table` avait été créée avec `AS table_function()`. Corrige [#16944](https://github.com/ClickHouse/ClickHouse/issues/16944). [#17072](https://github.com/ClickHouse/ClickHouse/pull/17072) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#17170](https://github.com/ClickHouse/ClickHouse/issues/17170) : correction d’un bogue pouvant entraîner le blocage indéfini des requêtes `ON CLUSTER` pour les ReplicatedMergeTreeTables non leaders. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
