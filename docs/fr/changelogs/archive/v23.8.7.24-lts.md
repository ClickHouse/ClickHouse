<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#56581](https://github.com/ClickHouse/ClickHouse/issues/56581) : empêche toute référence à une source de données distante pour la colonne `data_paths` dans `system.tables` si la table est créée avec une fonction de table utilisant une description de colonne explicite. [#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Rétroporté dans [#56877](https://github.com/ClickHouse/ClickHouse/issues/56877) : corrige un résultat de la requête incomplet pour `UNION` dans la fonction de table `view()`. [#56274](https://github.com/ClickHouse/ClickHouse/pull/56274) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#56409](https://github.com/ClickHouse/ClickHouse/issues/56409) : interdit l’ajout d’une colonne de type `Object(JSON)` à une table existante. Clôture : [#56095](https://github.com/ClickHouse/ClickHouse/issues/56095) Clôture : [#49944](https://github.com/ClickHouse/ClickHouse/issues/49944). [#56307](https://github.com/ClickHouse/ClickHouse/pull/56307) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#56756](https://github.com/ClickHouse/ClickHouse/issues/56756) : corrige un segfault provoqué par une exception levée lors de l’initialisation de Kerberos pendant la création de la table Kafka. Clôture [#56073](https://github.com/ClickHouse/ClickHouse/issues/56073). [#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#56748](https://github.com/ClickHouse/ClickHouse/issues/56748) : corrige le problème qui empêchait le moteur de table RabbitMQ de se connecter à RabbitMQ via une connexion sécurisée. [#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#56839](https://github.com/ClickHouse/ClickHouse/issues/56839) : le serveur plantait lors de la décompression de données malformées avec le codec `FPC`. Ce problème a été découvert dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par [https://twitter.com/malacupa](https://twitter.com/malacupa). [#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
