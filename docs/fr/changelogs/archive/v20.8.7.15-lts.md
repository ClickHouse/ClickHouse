<div id="clickhouse-release-v208715-lts-fixme-as-compared-to-v20866-lts">
  ### Version de ClickHouse v20.8.7.15-lts FIXME par rapport à v20.8.6.6-lts
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#17029](https://github.com/ClickHouse/ClickHouse/issues/17029) : permet de se connecter à l’endpoint sécurisé de `clickhouse-server`, qui nécessite le SNI. Cela est possible lorsque `clickhouse-server` est hébergé derrière un proxy TLS. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#15676](https://github.com/ClickHouse/ClickHouse/issues/15676) : la requête se termine plus rapidement en cas d’exception. Annule l’exécution sur les répliques distantes si une exception survient. [#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#17106](https://github.com/ClickHouse/ClickHouse/issues/17106) : corrige [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574), corrige [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231), corrige l’échec d’une requête distante lors de l’utilisation d’une fonction d’agrégation avec le suffixe &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Rétroporté dans [#16761](https://github.com/ClickHouse/ClickHouse/issues/16761) : corrige optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order avec max&#95;threads&gt;0 et une expression dans ORDER BY. [#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#16738](https://github.com/ClickHouse/ClickHouse/issues/16738) : corrige l’opérateur `IN` sur plusieurs colonnes et tuples lorsque le paramètre `transform_null_in` est activé. Corrige [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310). [#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#17021](https://github.com/ClickHouse/ClickHouse/issues/17021) : corrige le crash lors de l’utilisation de `any` sans argument. Cela concerne [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#16880](https://github.com/ClickHouse/ClickHouse/issues/16880) : abandonne le téléversement multipart si aucune donnée n’a été écrite dans WriteBufferFromS3. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Rétroporté dans [#16950](https://github.com/ClickHouse/ClickHouse/issues/16950) : empêche les crashs du ClickHouse server lors de l’utilisation de TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17077](https://github.com/ClickHouse/ClickHouse/issues/17077) : corrige l’erreur possible `Illegal type of argument` pour les requêtes avec `ORDER BY`. Corrige [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#17007](https://github.com/ClickHouse/ClickHouse/issues/17007) : le script d’installation doit toujours créer des sous-répertoires dans les dossiers de config. Cela ne concerne que les builds Docker avec une config personnalisée. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17011](https://github.com/ClickHouse/ClickHouse/issues/17011) : corrige un possible crash du serveur après `ALTER TABLE ... MODIFY COLUMN ... NewType` lorsqu’un `SELECT` comporte une expression `WHERE` sur la colonne en cours de modification et que l’alter n’est pas encore terminé. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#17040](https://github.com/ClickHouse/ClickHouse/issues/17040) : résout à nouveau l’IP de `format_avro_schema_registry_url` en cas d’erreur. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17171](https://github.com/ClickHouse/ClickHouse/issues/17171) : correction d’un bogue où les requêtes `ON CLUSTER` peuvent rester bloquées indéfiniment pour les tables ReplicatedMergeTree non leaders. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
