  # Historique des modifications 2022

<div id="clickhouse-release-v216426-stable-fixme-as-compared-to-v216314-stable">
  ### Version ClickHouse v21.6.4.26-stable FIXME par rapport à v21.6.3.14-stable
</div>

<div id="bug-fix">
  #### Correction de bug
</div>

* Rétroporté dans [#24969](https://github.com/ClickHouse/ClickHouse/issues/24969) : Autorisation des valeurs NULL dans le protocole postgresql. Ferme [#22622](https://github.com/ClickHouse/ClickHouse/issues/22622). [#24857](https://github.com/ClickHouse/ClickHouse/pull/24857) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#25186](https://github.com/ClickHouse/ClickHouse/issues/25186) : Correction d'un bug lors de la déclaration d'un S3 disk à la racine d'un bucket. Auparavant, l'erreur suivante était signalée : ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):. [#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#25023](https://github.com/ClickHouse/ClickHouse/issues/25023) : Correction des paramètres limit/offset pour les requêtes distribuées (ignorés sur les nœuds distants). [#24940](https://github.com/ClickHouse/ClickHouse/pull/24940) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#25049](https://github.com/ClickHouse/ClickHouse/issues/25049) : Correction d'une erreur extrêmement rare `Tagging already tagged part` dans la file de réplication lors d'un `alter move/replace partition` concurrent. Corrige potentiellement [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142). [#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#25081](https://github.com/ClickHouse/ClickHouse/issues/25081) : Correction d'un résultat erroné lors de l'utilisation d'une projection d'agrégation avec une clé `GROUP BY` **non vide** pour exécuter une requête avec `GROUP BY` par clé **vide**. [#25055](https://github.com/ClickHouse/ClickHouse/pull/25055) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#25107](https://github.com/ClickHouse/ClickHouse/issues/25107) : Correction d'un bug permettant la création de tables avec des colonnes se référençant elles-mêmes, comme `a UInt32 ALIAS a + 1` ou `b UInt32 MATERIALIZED b`. Corrige [#24910](https://github.com/ClickHouse/ClickHouse/issues/24910), [#24292](https://github.com/ClickHouse/ClickHouse/issues/24292). [#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#25106](https://github.com/ClickHouse/ClickHouse/issues/25106) : Correction d'un bug avec les maps constantes dans mapContains provoquant l'erreur `empty column was returned by function mapContains`. Ferme [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077). [#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#25143](https://github.com/ClickHouse/ClickHouse/issues/25143) : Correction d'un crash dans une requête avec CROSS JOIN et `joined_subquery_requires_alias = 0`. Corrige [#24011](https://github.com/ClickHouse/ClickHouse/issues/24011). [#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25157](https://github.com/ClickHouse/ClickHouse/issues/25157) : Correction d'une possible perte de parts après une mise à jour vers la version 21.5 lorsque la table utilisait `UUID` comme clé de partition. (Il n'est pas recommandé d'utiliser `UUID` comme clé de partition.) Corrige [#25070](https://github.com/ClickHouse/ClickHouse/issues/25070). [#25127](https://github.com/ClickHouse/ClickHouse/pull/25127) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25182](https://github.com/ClickHouse/ClickHouse/issues/25182) : Ne pas utiliser la projection d'une table pour un `SELECT` avec `FINAL`. Cette fonctionnalité n'est pas encore prise en charge. [#25163](https://github.com/ClickHouse/ClickHouse/pull/25163) ([Amos Bird](https://github.com/amosbird)).
