* Rétroporté dans [#60983](https://github.com/ClickHouse/ClickHouse/issues/60983) : correction d’un débordement de tampon pouvant survenir si un attaquant demande au serveur HTTP de décompresser des données avec une combinaison de codecs et une taille déclenchant un débordement numérique. Correction d’un débordement de tampon pouvant se produire dans le codec NONE en cas de données d’entrée incorrectes. Ce problème a été signalé par l’équipe de recherche TIANGONG dans le cadre de notre [programme Bug Bounty](https://github.com/ClickHouse/ClickHouse/issues/38986). [#60731](https://github.com/ClickHouse/ClickHouse/pull/60731) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#60986](https://github.com/ClickHouse/ClickHouse/issues/60986) : les fonctions SQL/JSON pouvaient lire de la mémoire non initialisée. Cela clôt [#60017](https://github.com/ClickHouse/ClickHouse/issues/60017). Détecté par Fuzzer. [#60738](https://github.com/ClickHouse/ClickHouse/pull/60738) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#60816](https://github.com/ClickHouse/ClickHouse/issues/60816) : correction d’un crash dans arrayEnumerateRanked. [#60764](https://github.com/ClickHouse/ClickHouse/pull/60764) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#60837](https://github.com/ClickHouse/ClickHouse/issues/60837) : correction d’un crash lors de l’utilisation de input() dans INSERT SELECT JOIN. Clôt [#60035](https://github.com/ClickHouse/ClickHouse/issues/60035). [#60765](https://github.com/ClickHouse/ClickHouse/pull/60765) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#60911](https://github.com/ClickHouse/ClickHouse/issues/60911) : évite un segfault si trop de clés sont ignorées lors de la lecture depuis S3. [#60849](https://github.com/ClickHouse/ClickHouse/pull/60849) ([Antonio Andelic](https://github.com/antonio2368)).
