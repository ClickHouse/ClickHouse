<div id="clickhouse-release-v209614-stable-fixme-as-compared-to-v20955-stable">
  ### Version de ClickHouse v20.9.6.14-stable FIXME par rapport à v20.9.5.5-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#17030](https://github.com/ClickHouse/ClickHouse/issues/17030) : permet de se connecter au endpoint sécurisé de `clickhouse-server` nécessitant le SNI. Cela est possible lorsque `clickhouse-server` est hébergé derrière un proxy TLS. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#15678](https://github.com/ClickHouse/ClickHouse/issues/15678) : la requête se termine plus rapidement en cas d’exception. Annule l’exécution sur les répliques distantes si une exception se produit. [#15578](https://github.com/ClickHouse/ClickHouse/pull/15578) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#17105](https://github.com/ClickHouse/ClickHouse/issues/17105) : corrige [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574), corrige [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231), corrige l’échec d’une requête distante lors de l’utilisation d’une fonction d’agrégation avec le suffixe &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Rétroporté dans [#16759](https://github.com/ClickHouse/ClickHouse/issues/16759) : corrige optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order avec max&#95;threads&gt;0 et une expression dans ORDER BY. [#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#16740](https://github.com/ClickHouse/ClickHouse/issues/16740) : corrige l’opérateur `IN` sur plusieurs colonnes et tuples avec le paramètre `transform_null_in` activé. Corrige [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310). [#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#17023](https://github.com/ClickHouse/ClickHouse/issues/17023) : corrige un crash lors de l’utilisation de `any` sans argument. Concerne [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#16879](https://github.com/ClickHouse/ClickHouse/issues/16879) : interrompt le téléversement multipart si aucune donnée n’a été écrite dans WriteBufferFromS3. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Rétroporté dans [#16945](https://github.com/ClickHouse/ClickHouse/issues/16945) : évite les crashs du serveur ClickHouse lors de l’utilisation de TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17078](https://github.com/ClickHouse/ClickHouse/issues/17078) : corrige l’erreur possible `Illegal type of argument` pour les requêtes avec `ORDER BY`. Corrige [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#17009](https://github.com/ClickHouse/ClickHouse/issues/17009) : le script d’installation doit toujours créer des sous-répertoires dans les dossiers de config. Cela ne concerne que les builds Docker avec une config personnalisée. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17013](https://github.com/ClickHouse/ClickHouse/issues/17013) : corrige un crash possible du serveur après `ALTER TABLE ... MODIFY COLUMN ... NewType` lorsque `SELECT` comporte une expression `WHERE` sur la colonne en cours de modification et que l’ALTER n’est pas encore terminé. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#17037](https://github.com/ClickHouse/ClickHouse/issues/17037) : résout de nouveau l’IP de `format_avro_schema_registry_url` en cas d’erreur. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17172](https://github.com/ClickHouse/ClickHouse/issues/17172) : correction d’un bug où les requêtes `ON CLUSTER` pouvaient rester bloquées indéfiniment sur des tables ReplicatedMergeTree non leaders. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
