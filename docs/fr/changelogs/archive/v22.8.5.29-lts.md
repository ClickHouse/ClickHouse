<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#40866](https://github.com/ClickHouse/ClickHouse/issues/40866) : correction d’un plantage lors de l’analyse syntaxique de valeurs de type `Object` contenant des tableaux à dimension variable. [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#40805](https://github.com/ClickHouse/ClickHouse/issues/40805) : lors de l’insertion d’une nouvelle requête dans `ProcessList`, des allocations se produisent. Si la limite de mémoire est atteinte pendant ces allocations, nous ne pouvons pas utiliser `OvercommitTracker`, car `ProcessList::mutex` est déjà verrouillé. Corrige [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611). [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#40777](https://github.com/ClickHouse/ClickHouse/issues/40777) : correction d’une fuite de mémoire lors de l’envoi vers des MV sans contexte de requête (depuis Kafka/...). [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#41135](https://github.com/ClickHouse/ClickHouse/issues/41135) : correction des droits d’accès pour `DESCRIBE TABLE url()` et certaines autres commandes `DESCRIBE TABLE <table_function>()`. [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#41242](https://github.com/ClickHouse/ClickHouse/issues/41242) : correction de l’erreur &quot;possible deadlock avoided&quot; lors de la conversion automatique du moteur de base de données de Ordinary vers Atomic. [#41146](https://github.com/ClickHouse/ClickHouse/pull/41146) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#41234](https://github.com/ClickHouse/ClickHouse/issues/41234) : correction du nettoyage en arrière-plan des parties détachées corrompues. [#41190](https://github.com/ClickHouse/ClickHouse/pull/41190) ([Kseniia Sumarokova](https://github.com/kssenii)).
