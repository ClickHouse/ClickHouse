  ### Version ClickHouse v24.9.3.128-stable (9a816c73dd4) FIXME par rapport à v24.9.2.42-stable (de7c791a2ea)

<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions précédentes
</div>

* Rétroporté dans [#71361](https://github.com/ClickHouse/ClickHouse/issues/71361) : correction d’une erreur possible `No such file or directory` en raison de symboles spéciaux non échappés dans les fichiers associés aux sous-colonnes JSON. [#71182](https://github.com/ClickHouse/ClickHouse/pull/71182) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#71318](https://github.com/ClickHouse/ClickHouse/issues/71318) : permettre à chaque méthode d’authentification d’avoir sa propre date d’expiration, supprimée de l’entité utilisateur. [#70090](https://github.com/ClickHouse/ClickHouse/pull/70090) ([Arthur Passos](https://github.com/arthurpassos)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#70681](https://github.com/ClickHouse/ClickHouse/issues/70681) : ne pas effectuer de validation lors de la synchronisation de user&#95;directories depuis Keeper. [#70644](https://github.com/ClickHouse/ClickHouse/pull/70644) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#71668](https://github.com/ClickHouse/ClickHouse/issues/71668) : lorsque l’utilisateur/le groupe est fourni sous forme d’ID, `clickhouse su` échoue. Ce patch corrige le problème afin d’accepter également `UID:GID`. ### Entrée de documentation pour les changements visibles par l’utilisateur. [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#71938](https://github.com/ClickHouse/ClickHouse/issues/71938) : mettre à jour `HostResolver` 3 fois au cours d’une période `history`. [#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).
