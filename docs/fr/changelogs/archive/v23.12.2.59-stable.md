<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions précédentes
</div>

* Rétroporté dans [#58389](https://github.com/ClickHouse/ClickHouse/issues/58389) : le paramètre MergeTree `clean_deleted_rows` est obsolète et n&#39;a désormais plus aucun effet. Le mot-clé `CLEANUP` pour `OPTIMIZE` n&#39;est pas autorisé par défaut (sauf si `allow_experimental_replacing_merge_with_cleanup` est activé). [#58316](https://github.com/ClickHouse/ClickHouse/pull/58316) ([Alexander Tokmakov](https://github.com/tavplubix)).
