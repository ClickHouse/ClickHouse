<div id="bug-fix">
  #### Corrections de bugs
</div>

* Rétroporté dans [#20510](https://github.com/ClickHouse/ClickHouse/issues/20510) : correction du comportement qui, en cas de JSON corrompu, tentait de lire l&#39;intégralité du fichier en mémoire, ce qui entraînait une exception de l&#39;allocator. Corrige [#19719](https://github.com/ClickHouse/ClickHouse/issues/19719). [#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#20575](https://github.com/ClickHouse/ClickHouse/issues/20575) : vérifie si la table function `view` est utilisée dans la liste d&#39;expressions et lève une erreur. Cela corrige [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342). [#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#20486](https://github.com/ClickHouse/ClickHouse/issues/20486) : correction de `LOGICAL_ERROR` pour `join_use_nulls=1` lorsque JOIN contient une constante provenant de SELECT. [#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20535](https://github.com/ClickHouse/ClickHouse/issues/20535) : correction d&#39;une boucle infinie lors de la propagation des alias WITH aux sous-requêtes. Cela corrige [#20388](https://github.com/ClickHouse/ClickHouse/issues/20388). [#20476](https://github.com/ClickHouse/ClickHouse/pull/20476) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#20615](https://github.com/ClickHouse/ClickHouse/issues/20615) : ajout de vérifications appropriées lors de l&#39;analyse des noms de répertoire pour INSERT asynchrone (corrige SIGSEGV). [#20498](https://github.com/ClickHouse/ClickHouse/pull/20498) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20887](https://github.com/ClickHouse/ClickHouse/issues/20887) : correction d&#39;une sous-requête avec union distinct et clause LIMIT. Corrige [#20597](https://github.com/ClickHouse/ClickHouse/issues/20597). [#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#20993](https://github.com/ClickHouse/ClickHouse/issues/20993) : correction de l&#39;utilisation du combinateur `-Distinct` avec le combinateur `-State` dans les fonctions d&#39;agrégation. [#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#20987](https://github.com/ClickHouse/ClickHouse/issues/20987) : la requête `USE database;` ne fonctionnait pas lors de l&#39;utilisation du client MySQL 5.7 pour se connecter au serveur ClickHouse ; c&#39;est désormais corrigé. Corrige [#18926](https://github.com/ClickHouse/ClickHouse/issues/18926). [#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)).
