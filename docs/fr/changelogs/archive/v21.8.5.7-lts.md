<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#27974](https://github.com/ClickHouse/ClickHouse/issues/27974) : corrige la gestion de la valeur NULL avec le type `Nullable(String)` dans la fonction JSONExtract. Cela corrige [#27929](https://github.com/ClickHouse/ClickHouse/issues/27929) et [#27930](https://github.com/ClickHouse/ClickHouse/issues/27930). Cela a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/25452](https://github.com/ClickHouse/ClickHouse/pull/25452). [#27939](https://github.com/ClickHouse/ClickHouse/pull/27939) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#28117](https://github.com/ClickHouse/ClickHouse/issues/28117) : corrige des segfaults extrêmement rares à l’arrêt en raison d’un ordre incorrect d’arrêt du rechargeur de Context/config. [#28088](https://github.com/ClickHouse/ClickHouse/pull/28088) ([nvartolomei](https://github.com/nvartolomei)).
* Rétroporté dans [#28180](https://github.com/ClickHouse/ClickHouse/issues/28180) : corrige un nombre potentiellement excessif de conditions déplacées de `WHERE` vers `PREWHERE` (optimisation contrôlée par le paramètre `optimize_move_to_prewhere`). [#28139](https://github.com/ClickHouse/ClickHouse/pull/28139) ([lthaooo](https://github.com/lthaooo)).
* Rétroporté dans [#28254](https://github.com/ClickHouse/ClickHouse/issues/28254) : corrige un comportement incorrect dans `ClickHouse Keeper` lorsque des watches de liste (`getChildren`) sont déclenchées par des requêtes `set` sur les enfants. [#28190](https://github.com/ClickHouse/ClickHouse/pull/28190) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28342](https://github.com/ClickHouse/ClickHouse/issues/28342) : corrige un bogue rare dans `ClickHouse Keeper` où le client peut recevoir une réponse de watch avant la réponse à la requête. [#28197](https://github.com/ClickHouse/ClickHouse/pull/28197) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28263](https://github.com/ClickHouse/ClickHouse/issues/28263) : corrige une possible lecture de mémoire non initialisée pour des requêtes avec le type `Nullable(LowCardinality)` et des extremes. Corrige [#28165](https://github.com/ClickHouse/ClickHouse/issues/28165). [#28205](https://github.com/ClickHouse/ClickHouse/pull/28205) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#28292](https://github.com/ClickHouse/ClickHouse/issues/28292) : corrige un résultat incohérent dans les requêtes avec `ORDER BY` et des tables `Merge` lorsque le paramètre `optimize_read_in_order` est activé. [#28266](https://github.com/ClickHouse/ClickHouse/pull/28266) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28402](https://github.com/ClickHouse/ClickHouse/issues/28402) : corrige des parts qui se chevauchent parce qu’une nouvelle part a été remplacée par une part vide. [#28310](https://github.com/ClickHouse/ClickHouse/pull/28310) ([Azat Khuzhin](https://github.com/azat)).
