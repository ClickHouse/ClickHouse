<div id="clickhouse-release-v208144-lts-fixme-as-compared-to-v2081315-lts">
  ### Version de ClickHouse v20.8.14.4-lts FIXME par rapport à v20.8.13.15-lts
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#21235](https://github.com/ClickHouse/ClickHouse/issues/21235) : la valeur de l’option MYSQL&#95;OPT&#95;RECONNECT peut désormais être contrôlée par le paramètre &quot;opt&#95;reconnect&quot; dans la section config de la réplique MySQL. [#19998](https://github.com/ClickHouse/ClickHouse/pull/19998) ([Alexander Kazakov](https://github.com/Akazz)).
* Rétroporté dans [#21203](https://github.com/ClickHouse/ClickHouse/issues/21203) : lors du chargement de la config pour la source MySQL, ClickHouse mélangera désormais aléatoirement la liste des répliques ayant la même priorité afin d’assurer une sélection en round-robin du point de terminaison MySQL. Cela clôt [#20629](https://github.com/ClickHouse/ClickHouse/issues/20629). [#20632](https://github.com/ClickHouse/ClickHouse/pull/20632) ([Alexander Kazakov](https://github.com/Akazz)).
* Rétroporté dans [#21336](https://github.com/ClickHouse/ClickHouse/issues/21336) : la source de dictionnaire MySQL retentera désormais l’opération en cas d’échec de connexion inattendu (Lost connection to MySQL server during query), ce qui se produit parfois sur les connexions SSL/TLS. [#21237](https://github.com/ClickHouse/ClickHouse/pull/21237) ([Alexander Kazakov](https://github.com/Akazz)).
