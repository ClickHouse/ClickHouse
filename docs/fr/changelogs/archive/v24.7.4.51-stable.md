<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#68232](https://github.com/ClickHouse/ClickHouse/issues/68232) : correction de `Not-ready Set` dans certaines tables système lors du filtrage à l’aide de sous-requêtes. [#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#68068](https://github.com/ClickHouse/ClickHouse/issues/68068) : correction des littéraux booléens dans la requête envoyée à la base de données externe (pour des engines comme `PostgreSQL`). [#66282](https://github.com/ClickHouse/ClickHouse/pull/66282) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#68613](https://github.com/ClickHouse/ClickHouse/issues/68613) : corrige [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026). Évite de parcourir des arguments de table function non résolus dans `ReplaceTableNodeToDummyVisitor`. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#68278](https://github.com/ClickHouse/ClickHouse/issues/68278) : correction de l’insertion dans les engines de type stream (Kafka, RabbitMQ, NATS) via l’interface HTTP. [#67554](https://github.com/ClickHouse/ClickHouse/pull/67554) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#68040](https://github.com/ClickHouse/ClickHouse/issues/68040) : correction de la création d’une vue avec une CTE récursive. [#67587](https://github.com/ClickHouse/ClickHouse/pull/67587) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#68038](https://github.com/ClickHouse/ClickHouse/issues/68038) : correction d’un plantage sur `percent_rank`. Le type de frame par défaut de `percent_rank` est désormais `range unbounded preceding and unbounded following`. La window frame par défaut de `IWindowFunction` est prise en compte, et les window functions sans définition de window frame en SQL peuvent maintenant être correctement placées dans différents `WindowTransfomer`s. [#67661](https://github.com/ClickHouse/ClickHouse/pull/67661) ([lgbo](https://github.com/lgbo-ustc)).
* Rétroporté dans [#68224](https://github.com/ClickHouse/ClickHouse/issues/68224) : correction d’un résultat erroné de `count()` lorsqu’une fonction non déterministe est présente dans le prédicat. [#67922](https://github.com/ClickHouse/ClickHouse/pull/67922) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Rétroporté dans [#68095](https://github.com/ClickHouse/ClickHouse/issues/68095) : correction du calcul de la limite souple maximale de threads dans les environnements conteneurisés où le nombre de CPU utilisables est limité. [#67963](https://github.com/ClickHouse/ClickHouse/pull/67963) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#68126](https://github.com/ClickHouse/ClickHouse/issues/68126) : correction du saut des parts non modifiées dans les mutations avec le nouvel analyseur. Auparavant, avec l’analyseur activé, les données d’une part pouvaient être réécrites par une mutation même si, selon le prédicat, cette mutation n’affectait pas cette part. [#68052](https://github.com/ClickHouse/ClickHouse/pull/68052) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#68223](https://github.com/ClickHouse/ClickHouse/issues/68223) : correction d’un déréférencement de pointeur NULL, déclenché par une requête spécialement conçue, qui faisait planter le serveur via hopEnd, hopStart, tumbleEnd et tumbleStart. [#68098](https://github.com/ClickHouse/ClickHouse/pull/68098) ([Salvatore Mesoraca](https://github.com/aiven-sal)).
* Rétroporté dans [#68175](https://github.com/ClickHouse/ClickHouse/issues/68175) : suppression d’une optimisation incorrecte qui supprimait le tri dans les sous-requêtes utilisant `OFFSET`. Corrige [#67906](https://github.com/ClickHouse/ClickHouse/issues/67906). [#68099](https://github.com/ClickHouse/ClickHouse/pull/68099) ([Graham Campbell](https://github.com/GrahamCampbell)).
* Rétroporté dans [#68341](https://github.com/ClickHouse/ClickHouse/issues/68341) : tentative de correction d’un plantage de Postgres en cas d’annulation d’une requête. [#68288](https://github.com/ClickHouse/ClickHouse/pull/68288) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#68398](https://github.com/ClickHouse/ClickHouse/issues/68398) : correction de l’absence du mode sync replica dans la requête `SYSTEM SYNC REPLICA`. [#68326](https://github.com/ClickHouse/ClickHouse/pull/68326) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#68669](https://github.com/ClickHouse/ClickHouse/issues/68669) : correction des `LOGICAL_ERROR` lorsque les fonctions `sipHash64Keyed`, `sipHash128Keyed` ou `sipHash128ReferenceKeyed` sont appliquées à des tableaux ou tuples vides. [#68630](https://github.com/ClickHouse/ClickHouse/pull/68630) ([Robert Schulze](https://github.com/rschu1ze)).
