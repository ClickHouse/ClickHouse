<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#58819](https://github.com/ClickHouse/ClickHouse/issues/58819) : ajout de `SYSTEM JEMALLOC PURGE` pour purger les pages jemalloc inutilisées, et de `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` pour contrôler le profil jemalloc si le profileur est activé. Ajout d&#39;une commande 4LW relative à jemalloc dans Keeper : `jmst` pour générer un dump des statistiques jemalloc, et `jmfp`, `jmep`, `jmdp` pour contrôler le profil jemalloc si le profileur est activé. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#60286](https://github.com/ClickHouse/ClickHouse/issues/60286) : ajout d&#39;un mécanisme de repli de la copie de fichiers S3 depuis GCP vers une copie tampon lorsque GCP renvoie `Internal Error` avec le code d&#39;erreur HTTP `GATEWAY_TIMEOUT`. [#60164](https://github.com/ClickHouse/ClickHouse/pull/60164) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation, des tests et du packaging
</div>

* Rétroporté dans [#59879](https://github.com/ClickHouse/ClickHouse/issues/59879) : si vous souhaitez exécuter les scripts `initdb` à chaque démarrage du conteneur ClickHouse, vous devez définir la variable d’environnement CLICKHOUSE&#95;ALWAYS&#95;RUN&#95;INITDB&#95;SCRIPTS. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#57565](https://github.com/ClickHouse/ClickHouse/issues/57565) : Les fusions en arrière-plan utilisent correctement le stockage temporaire des données dans le cache. [#57275](https://github.com/ClickHouse/ClickHouse/pull/57275) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#57476](https://github.com/ClickHouse/ClickHouse/issues/57476) : Corrige de possibles index de saut de données endommagés après matérialisation dans les parties compactes de MergeTree. [#57352](https://github.com/ClickHouse/ClickHouse/pull/57352) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#58777](https://github.com/ClickHouse/ClickHouse/issues/58777) : Corrige un double appel possible à destroy lors du déclenchement d’une exception dans addBatchLookupTable8. [#58745](https://github.com/ClickHouse/ClickHouse/pull/58745) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#58856](https://github.com/ClickHouse/ClickHouse/issues/58856) : Corrige un plantage possible dans la fonction JSONExtract lors de l’extraction du type `LowCardinality(Nullable(T))`. [#58808](https://github.com/ClickHouse/ClickHouse/pull/58808) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#59194](https://github.com/ClickHouse/ClickHouse/issues/59194) : La combinaison de LIMIT BY et LIMIT pouvait produire un résultat incorrect dans les requêtes distribuées (y compris avec les répliques parallèles). [#59153](https://github.com/ClickHouse/ClickHouse/pull/59153) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#59429](https://github.com/ClickHouse/ClickHouse/issues/59429) : Corrige translate() avec une entrée FixedString. Cela pouvait entraîner des plantages, car la fonction renvoyait une colonne String (au lieu du FixedString attendu). Ce problème a été découvert dans le cadre du ClickHouse Bug Bounty Program par YohannJardin. [#59356](https://github.com/ClickHouse/ClickHouse/pull/59356) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#60128](https://github.com/ClickHouse/ClickHouse/issues/60128) : Corrige l’erreur `Read beyond last offset` pour `AsynchronousBoundedReadBuffer`. [#59630](https://github.com/ClickHouse/ClickHouse/pull/59630) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#59836](https://github.com/ClickHouse/ClickHouse/issues/59836) : Corrige l’heure de début de la requête pour les requêtes non initiales. [#59662](https://github.com/ClickHouse/ClickHouse/pull/59662) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#59758](https://github.com/ClickHouse/ClickHouse/issues/59758) : Corrige la fonction leftPad / rightPad avec une entrée FixedString. [#59739](https://github.com/ClickHouse/ClickHouse/pull/59739) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#60304](https://github.com/ClickHouse/ClickHouse/issues/60304) : Corrige le cas où les messages n’étaient ni acquittés ni rejetés. Si une exception survient pendant la phase de lecture-écriture, les messages seront rejetés. [#59775](https://github.com/ClickHouse/ClickHouse/pull/59775) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#60171](https://github.com/ClickHouse/ClickHouse/issues/60171) : Corrige un plantage de cosineDistance avec Nullable. [#60150](https://github.com/ClickHouse/ClickHouse/pull/60150) ([Raúl Marín](https://github.com/Algunenano)).
