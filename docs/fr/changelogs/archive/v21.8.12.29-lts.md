<div id="performance-improvement">

</div>

<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#31575](https://github.com/ClickHouse/ClickHouse/issues/31575) : la limite du quota n’était pas atteinte, mais elle était pourtant considérée comme dépassée. Cette PR corrige [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#31204](https://github.com/ClickHouse/ClickHouse/issues/31204) : correction d’un arrêt brutal sur le serveur de débogage et de l’erreur `DB::Exception: std::out_of_range: basic_string` sur le serveur de production en cas d’URL hdfs invalide, grâce à une vérification supplémentaire de la structure de l’URL hdfs. [#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#31253](https://github.com/ClickHouse/ClickHouse/issues/31253) : correction d’un bogue dans Keeper pouvant empêcher le démarrage lorsque certains journaux de coordination ont été perdus et qu’un snapshot plus récent que le dernier journal est présent. [#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#31521](https://github.com/ClickHouse/ClickHouse/issues/31521) : suppression de la fonction not like dans RPNElement. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* Rétroporté dans [#31552](https://github.com/ClickHouse/ClickHouse/issues/31552) : correction d’un `nullptr` dans le fournisseur d’identifiants STS pour S3. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#31582](https://github.com/ClickHouse/ClickHouse/issues/31582) : * Désactivation de `partial_merge_join_left_table_buffer_bytes` jusqu’à la correction du bogue dans cette optimisation. Voir [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)). * Suppression de l’option redondante `partial_merge_join_optimizations`. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#31599](https://github.com/ClickHouse/ClickHouse/issues/31599) : correction d’un JSON généré invalide lorsque seuls les noms de colonnes contiennent des séquences UTF-8 invalides. [#31534](https://github.com/ClickHouse/ClickHouse/pull/31534) ([Kevin Michel](https://github.com/kmichel-aiven)).
* Rétroporté dans [#31779](https://github.com/ClickHouse/ClickHouse/issues/31779) : la requête `RENAME TABLE` fonctionnait incorrectement lors d’une tentative de renommage d’un dictionnaire DDL dans une base de données `Ordinary` ; c’est corrigé. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#31790](https://github.com/ClickHouse/ClickHouse/issues/31790) : les paramètres `input_format_allow_errors_num` et `input_format_allow_errors_ratio` ne fonctionnaient pas pour l’analyse des types de domaine, tels que `IPv4` ; c’est corrigé. Corrige [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686). [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#31829](https://github.com/ClickHouse/ClickHouse/issues/31829) : correction de l’erreur `there are no such cluster here` lors de l’exécution d’une requête `ON CLUSTER` si le nom de cluster spécifié est celui d’une base de données `Replicated`. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#31813](https://github.com/ClickHouse/ClickHouse/issues/31813) : correction d’une condition de concurrence dans le format de sortie JSONEachRowWithProgress lorsque les données et les lignes de progression sont mélangées dans la sortie. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#31761](https://github.com/ClickHouse/ClickHouse/issues/31761) : correction de l’utilisation du moteur de table `Buffer` avec le type `Map`. Corrige [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546). [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#31890](https://github.com/ClickHouse/ClickHouse/issues/31890) : correction d’un possible échec d’assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` dans le format TSKV. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#31910](https://github.com/ClickHouse/ClickHouse/issues/31910) : correction des fonctions `empty` et `notEmpty` pour les arguments de type `UUID`. Corrige [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819). [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
