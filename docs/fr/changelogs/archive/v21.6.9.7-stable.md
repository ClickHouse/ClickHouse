<div id="bug-fix">
  #### Correction de bogue

* Rétroporté dans [#26857](https://github.com/ClickHouse/ClickHouse/issues/26857) : ParallelFormattingOutputFormat : utiliser un mutex pour gérer la jonction avec collector&#95;thread ([https://github.com/ClickHouse/ClickHouse/issues/26694](https://github.com/ClickHouse/ClickHouse/issues/26694)). [#26703](https://github.com/ClickHouse/ClickHouse/pull/26703) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#26939](https://github.com/ClickHouse/ClickHouse/issues/26939) : ne pas supprimer les données à l’arrêt d’une table ReplicatedMergeTree afin d’éviter une incohérence entre les données et les métadonnées. [#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* Rétroporté dans [#26985](https://github.com/ClickHouse/ClickHouse/issues/26985) : les paramètres des fonctions d’agrégation peuvent être perdus lors de l’application de certains combinateurs, ce qui provoque des exceptions telles que `Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported`. Le problème est corrigé. Corrige [#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) et [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433). [#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#26910](https://github.com/ClickHouse/ClickHouse/issues/26910) : correction du chargement des identifiants de library-bridge. [#26834](https://github.com/ClickHouse/ClickHouse/pull/26834) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#26946](https://github.com/ClickHouse/ClickHouse/issues/26946) : correction de l’erreur `Missing columns: 'xxx'` lorsqu’une colonne `DEFAULT` référence une autre colonne non matérialisée sans expression `DEFAULT`. Corrige [#26591](https://github.com/ClickHouse/ClickHouse/issues/26591). [#26900](https://github.com/ClickHouse/ClickHouse/pull/26900) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#27000](https://github.com/ClickHouse/ClickHouse/issues/27000) : correction de la lecture des TLD personnalisés (le traitement s’interrompt avec un buffer plus petit ou un fichier plus volumineux). [#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#27085](https://github.com/ClickHouse/ClickHouse/issues/27085) : désormais, l’identifiant de partition dans des requêtes comme `ALTER TABLE ... PARTITION ID xxx` est vérifié pour en valider la correction. Corrige [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718). [#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#27052](https://github.com/ClickHouse/ClickHouse/issues/27052) : [RFC] correction d’un possible empilement de mutations dû à une situation de concurrence avec DROP&#95;RANGE. [#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#27159](https://github.com/ClickHouse/ClickHouse/issues/27159) : correction de la synchronisation dans GRPCServer. Cette PR corrige [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024). [#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#27367](https://github.com/ClickHouse/ClickHouse/issues/27367) : - correction d’une mémoire non initialisée dans les fonctions `multiSearch*` avec un tableau vide, ferme [#27169](https://github.com/ClickHouse/ClickHouse/issues/27169). [#27181](https://github.com/ClickHouse/ClickHouse/pull/27181) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#27260](https://github.com/ClickHouse/ClickHouse/issues/27260) : dans de rares cas, la table `system.detached_parts` pouvait contenir des informations incorrectes pour certaines parts ; c’est corrigé. Corrige [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114). [#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#27466](https://github.com/ClickHouse/ClickHouse/issues/27466) : correction d’une validation incorrecte de l’identifiant de partition pour les tables MergeTree créées avec l’ancienne syntaxe. [#27328](https://github.com/ClickHouse/ClickHouse/pull/27328) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#27646](https://github.com/ClickHouse/ClickHouse/issues/27646) : correction d’un résultat incorrect pour une requête avec sécurité au niveau des lignes, prewhere et filtre LowCardinality. Corrige [#27179](https://github.com/ClickHouse/ClickHouse/issues/27179). [#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#27471](https://github.com/ClickHouse/ClickHouse/issues/27471) : correction de la métrique BackgroundMessageBrokerSchedulePoolTask, peut-être mal nommée. [#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* Correction de l’analyse de la configuration `cache`, `complex_key_cache`, `ssd_cache`, `complex_key_ssd_cache`. Les options `allow_read_expired_keys`, `max_update_queue_size`, `update_queue_push_timeout_milliseconds`, `query_wait_timeout_milliseconds` n’étaient pas analysées pour les dictionnaires d’un type autre que `cache`. * Rétroporté dans [#27978](https://github.com/ClickHouse/ClickHouse/issues/27978) : correction d’un bug dans le mode &quot;strict&quot; de windowFunnel. * Rétroporté dans [#27675](https://github.com/ClickHouse/ClickHouse/issues/27675) : correction de la fonction de table PostgreSQL qui entraînait des connexions non fermées. * Rétroporté dans [#27699](https://github.com/ClickHouse/ClickHouse/issues/27699) : correction d’une conversion de type incorrecte lorsque des fonctions comme `arrayHas` sont appliquées à des arrays de LowCardinality de Nullable de différents types non numériques, comme `DateTime` et `DateTime64`.
