  ### Version ClickHouse v21.2.5.5-stable FIXME par rapport à v21.2.4.6-stable

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#20574](https://github.com/ClickHouse/ClickHouse/issues/20574) : correction d’un crash pouvant se produire si un packet inconnu était reçu depuis la requête remove (introduit dans [#17868](https://github.com/ClickHouse/ClickHouse/issues/17868)). [#20547](https://github.com/ClickHouse/ClickHouse/pull/20547) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21006](https://github.com/ClickHouse/ClickHouse/issues/21006) : correction de « Empty task was returned from async task queue » lors de l’annulation d’une query. [#20881](https://github.com/ClickHouse/ClickHouse/pull/20881) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21132](https://github.com/ClickHouse/ClickHouse/issues/21132) : correction du comportement lorsque `ALTER MODIFY COLUMN` créait une mutation vouée à échouer. [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#21251](https://github.com/ClickHouse/ClickHouse/issues/21251) : - bloque les insertions parallèles dans le moteur Join. [#21009](https://github.com/ClickHouse/ClickHouse/pull/21009) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#21069](https://github.com/ClickHouse/ClickHouse/issues/21069) : un accès mémoire hors limites était possible lors du formatting d’une valeur de type `DateTime64` hors plage spécialement conçue. Clôt [#20494](https://github.com/ClickHouse/ClickHouse/issues/20494). Clôt [#20543](https://github.com/ClickHouse/ClickHouse/issues/20543). [#21023](https://github.com/ClickHouse/ClickHouse/pull/21023) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#21160](https://github.com/ClickHouse/ClickHouse/issues/21160) : correction pour que `input_format_null_as_default` prenne effet lorsque les types sont Nullable. Cela corrige [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116). [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#21228](https://github.com/ClickHouse/ClickHouse/issues/21228) : corrige [#21112](https://github.com/ClickHouse/ClickHouse/issues/21112). Correction d’un bug pouvant provoquer des doublons avec une insert query (si l’un des callbacks arrivait un peu trop tard). [#21138](https://github.com/ClickHouse/ClickHouse/pull/21138) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#21276](https://github.com/ClickHouse/ClickHouse/issues/21276) : correction d’un bug avec `join_use_nulls` et la jointure de `TOTALS` issus de subqueries. Clôt [#19362](https://github.com/ClickHouse/ClickHouse/issues/19362) et [#21137](https://github.com/ClickHouse/ClickHouse/issues/21137). [#21248](https://github.com/ClickHouse/ClickHouse/pull/21248) ([Vladimir C](https://github.com/vdimir)).
