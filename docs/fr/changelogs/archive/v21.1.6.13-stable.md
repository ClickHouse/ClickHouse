  # Historique des modifications 2022

<div id="clickhouse-release-v211613-stable-fixme-as-compared-to-v21154-stable">
  ### Version ClickHouse v21.1.6.13-stable FIXME par rapport à la v21.1.5.4-stable
</div>

<div id="bug-fix">
  #### Corrections de bugs
</div>

* Rétroporté dans [#20637](https://github.com/ClickHouse/ClickHouse/issues/20637) : correction d’un bug rare où certaines opérations répliquées (comme une mutation) ne pouvaient pas traiter certaines parties après une corruption des données. Corrige [#19593](https://github.com/ClickHouse/ClickHouse/issues/19593). [#19702](https://github.com/ClickHouse/ClickHouse/pull/19702) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20573](https://github.com/ClickHouse/ClickHouse/issues/20573) : correction d’un crash pouvant survenir à la réception d’un packet inconnu provenant d’une requête remove (introduit dans [#17868](https://github.com/ClickHouse/ClickHouse/issues/17868)). [#20547](https://github.com/ClickHouse/ClickHouse/pull/20547) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21005](https://github.com/ClickHouse/ClickHouse/issues/21005) : correction de l’erreur « Empty task was returned from async task queue » lors de l’annulation d’une requête. [#20881](https://github.com/ClickHouse/ClickHouse/pull/20881) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21131](https://github.com/ClickHouse/ClickHouse/issues/21131) : correction d’un comportement où `ALTER MODIFY COLUMN` créait une mutation vouée à l’échec. [#21007](https://github.com/ClickHouse/ClickHouse/pull/21007) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#21250](https://github.com/ClickHouse/ClickHouse/issues/21250) : blocage des insertions parallèles dans le moteur Join. [#21009](https://github.com/ClickHouse/ClickHouse/pull/21009) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#21068](https://github.com/ClickHouse/ClickHouse/issues/21068) : un accès mémoire hors limites était possible lors du formatage d’une valeur de type `DateTime64` spécialement forgée et hors plage. Cela clôt [#20494](https://github.com/ClickHouse/ClickHouse/issues/20494). Cela clôt [#20543](https://github.com/ClickHouse/ClickHouse/issues/20543). [#21023](https://github.com/ClickHouse/ClickHouse/pull/21023) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#21229](https://github.com/ClickHouse/ClickHouse/issues/21229) : corrige [#21112](https://github.com/ClickHouse/ClickHouse/issues/21112). Correction d’un bug pouvant provoquer des doublons avec une insert query (si l’un des callbacks arrivait un peu trop tard). [#21138](https://github.com/ClickHouse/ClickHouse/pull/21138) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#21277](https://github.com/ClickHouse/ClickHouse/issues/21277) : correction d’un bug avec `join_use_nulls` et la jointure de `TOTALS` issus de sous-requêtes. Cela clôt [#19362](https://github.com/ClickHouse/ClickHouse/issues/19362) et [#21137](https://github.com/ClickHouse/ClickHouse/issues/21137). [#21248](https://github.com/ClickHouse/ClickHouse/pull/21248) ([Vladimir C](https://github.com/vdimir)).
