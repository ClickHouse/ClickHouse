  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v21171-stable-fixme-as-compared-to-v211613-stable">
  ### Version ClickHouse v21.1.7.1-stable FIXME par rapport à la version v21.1.6.13-stable
</div>

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#21261](https://github.com/ClickHouse/ClickHouse/issues/21261) : correction d’un problème où les valeurs `default_replica_path` et `default_replica_name` étaient inutiles avec le moteur Replicated(*)MergeTree lorsque celui-ci devait spécifier d’autres paramètres. [#21060](https://github.com/ClickHouse/ClickHouse/pull/21060) ([mxzlxy](https://github.com/mxzlxy)).
* Rétroporté dans [#21155](https://github.com/ClickHouse/ClickHouse/issues/21155) : correction d’un bug lié à la conversion d’un tuple en map. Résout [#21029](https://github.com/ClickHouse/ClickHouse/issues/21029). [#21120](https://github.com/ClickHouse/ClickHouse/pull/21120) ([hexiaoting](https://github.com/hexiaoting)).
* Rétroporté dans [#21233](https://github.com/ClickHouse/ClickHouse/issues/21233) : désormais, les mutations ne sont autorisées que pour les moteurs de table qui les prennent en charge (famille MergeTree, Memory, MaterializedView). Les autres moteurs renverront une erreur plus explicite. Résout [#21168](https://github.com/ClickHouse/ClickHouse/issues/21168). [#21183](https://github.com/ClickHouse/ClickHouse/pull/21183) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#21428](https://github.com/ClickHouse/ClickHouse/issues/21428) : correction d’un plantage dans `EXPLAIN` pour une requête avec `UNION`. Résout [#20876](https://github.com/ClickHouse/ClickHouse/issues/20876), [#21170](https://github.com/ClickHouse/ClickHouse/issues/21170). [#21246](https://github.com/ClickHouse/ClickHouse/pull/21246) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#21408](https://github.com/ClickHouse/ClickHouse/issues/21408) : correction des reconnexions redondantes à ZooKeeper et de la possibilité d’avoir deux sessions actives pour un même serveur ClickHouse. Ces deux problèmes ont été introduits dans [#14678](https://github.com/ClickHouse/ClickHouse/issues/14678). [#21264](https://github.com/ClickHouse/ClickHouse/pull/21264) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#21549](https://github.com/ClickHouse/ClickHouse/issues/21549) : désormais, les requêtes `ALTER MODIFY COLUMN` prendront correctement en compte les modifications de la clé de partition, des indices de saut, des TTL, etc. Résout [#13675](https://github.com/ClickHouse/ClickHouse/issues/13675). [#21334](https://github.com/ClickHouse/ClickHouse/pull/21334) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#21377](https://github.com/ClickHouse/ClickHouse/issues/21377) : correction de l’erreur `Bad cast from type ... to DB::ColumnLowCardinality` lors de l’insertion dans une table avec une colonne `LowCardinality` depuis le format `Values`. Résout [#21140](https://github.com/ClickHouse/ClickHouse/issues/21140). [#21357](https://github.com/ClickHouse/ClickHouse/pull/21357) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
