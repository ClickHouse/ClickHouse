<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (dysfonctionnement visible par l’utilisateur dans la version stable officielle)
</div>

* Rétroporté dans [#38242](https://github.com/ClickHouse/ClickHouse/issues/38242) : Correction d’un crash possible lors de l’`async insert` de `Distributed` en cas de suppression d’une réplica de la config. [#38029](https://github.com/ClickHouse/ClickHouse/pull/38029) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#38865](https://github.com/ClickHouse/ClickHouse/issues/38865) : Correction des lectures S3 avec `seek` via un `read buffer` parallèle. (Affectait l’utilisation mémoire pendant une requête.) Clôt [#38258](https://github.com/ClickHouse/ClickHouse/issues/38258). [#38802](https://github.com/ClickHouse/ClickHouse/pull/38802) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#38853](https://github.com/ClickHouse/ClickHouse/issues/38853) : Mise à jour de `simdjson`. Cela corrige [#38621](https://github.com/ClickHouse/ClickHouse/issues/38621). [#38838](https://github.com/ClickHouse/ClickHouse/pull/38838) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#38942](https://github.com/ClickHouse/ClickHouse/issues/38942) : - Correction du profile de settings avec l’unité seconds. [#38896](https://github.com/ClickHouse/ClickHouse/pull/38896) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#39063](https://github.com/ClickHouse/ClickHouse/issues/39063) : Toute allocation dans OvercommitTracker peut entraîner un interblocage. Le logging n’était pas très informatif, il est donc plus simple de le supprimer. Corrige [#37794](https://github.com/ClickHouse/ClickHouse/issues/37794). [#39030](https://github.com/ClickHouse/ClickHouse/pull/39030) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#39077](https://github.com/ClickHouse/ClickHouse/issues/39077) : Correction d’un bogue dans le filesystem cache qui pouvait survenir dans un cas limite coïncidant avec l’atteinte de la limite de capacité du cache. Clôt [#39066](https://github.com/ClickHouse/ClickHouse/issues/39066). [#39070](https://github.com/ClickHouse/ClickHouse/pull/39070) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#39151](https://github.com/ClickHouse/ClickHouse/issues/39151) : Correction de l’erreur `Block structure mismatch` qui pouvait se produire pour un INSERT dans une table avec une MATERIALIZED VIEW attachée et le paramètre `extremes = 1` activé. Clôt [#29759](https://github.com/ClickHouse/ClickHouse/issues/29759) et [#38729](https://github.com/ClickHouse/ClickHouse/issues/38729). [#39125](https://github.com/ClickHouse/ClickHouse/pull/39125) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#39275](https://github.com/ClickHouse/ClickHouse/issues/39275) : Correction de l’erreur `Not found column Type in block` dans les requêtes `SELECT` avec `PREWHERE` et les optimisations de lecture dans l’ordre. [#39157](https://github.com/ClickHouse/ClickHouse/pull/39157) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#39371](https://github.com/ClickHouse/ClickHouse/issues/39371) : Déclaration de la file RabbitMQ sans les arguments par défaut `x-max-length` et `x-overflow`. [#39259](https://github.com/ClickHouse/ClickHouse/pull/39259) ([rnbondarenko](https://github.com/rnbondarenko)).
* Rétroporté dans [#39352](https://github.com/ClickHouse/ClickHouse/issues/39352) : Correction d’une requête incorrecte de récupération des tables PostgreSQL pour le moteur de base de données PostgreSQL. Clôt [#33502](https://github.com/ClickHouse/ClickHouse/issues/33502). [#39283](https://github.com/ClickHouse/ClickHouse/pull/39283) ([Kseniia Sumarokova](https://github.com/kssenii)).
