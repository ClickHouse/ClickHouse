<div id="performance-improvement">
  #### Amélioration des performances
</div>

[#26371](https://github.com/ClickHouse/ClickHouse/pull/26371) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#26787](https://github.com/ClickHouse/ClickHouse/issues/26787) : corrige la décompression zstd lorsqu’il y a des séquences d’échappement à la fin du tampon interne. Ferme [#26013](https://github.com/ClickHouse/ClickHouse/issues/26013). [#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#26487](https://github.com/ClickHouse/ClickHouse/issues/26487) : corrige une résolution de noms défaillante après la réécriture des alias de colonne. Cela corrige [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432). [#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#26615](https://github.com/ClickHouse/ClickHouse/issues/26615) : corrige les problèmes avec la requête `CREATE DICTIONARY` lorsque le nom du dictionnaire ou celui de la base de données était entre guillemets. Ferme [#26491](https://github.com/ClickHouse/ClickHouse/issues/26491). [#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#26606](https://github.com/ClickHouse/ClickHouse/issues/26606) : corrige un crash lors de l’arrêt de rabbitmq si la configuration de rabbitmq n’avait pas été démarrée. Ferme [#26504](https://github.com/ClickHouse/ClickHouse/issues/26504). [#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#26612](https://github.com/ClickHouse/ClickHouse/issues/26612) : met à jour la vérification de la commande `chown` dans l’entrypoint Docker de clickhouse-server. Cela corrige le bogue qui provoquait l’échec du redémarrage du pod du cluster (ou un timeout) sur Kubernetes. [#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix)).
* Rétroporté dans [#26647](https://github.com/ClickHouse/ClickHouse/issues/26647) : corrige les noms de fonction incorrects de groupBitmapAnd/Or/Xor. [#26557](https://github.com/ClickHouse/ClickHouse/pull/26557) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#26704](https://github.com/ClickHouse/ClickHouse/issues/26704) : corrige un déréférencement potentiel de nullptr dans les fonctions de fenêtre. Cela corrige [#25276](https://github.com/ClickHouse/ClickHouse/issues/25276). [#26668](https://github.com/ClickHouse/ClickHouse/pull/26668) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#26772](https://github.com/ClickHouse/ClickHouse/issues/26772) : parfois, SET ROLE pouvait se comporter de manière incorrecte ; cette PR corrige ce problème. [#26707](https://github.com/ClickHouse/ClickHouse/pull/26707) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#26907](https://github.com/ClickHouse/ClickHouse/issues/26907) : corrige le chargement des identifiants de library-bridge. [#26834](https://github.com/ClickHouse/ClickHouse/pull/26834) ([Kseniia Sumarokova](https://github.com/kssenii)).
