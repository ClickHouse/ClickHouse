<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#48459](https://github.com/ClickHouse/ClickHouse/issues/48459) : le formatteur &#39;%M&#39; de la fonction formatDateTime() affiche désormais le nom du mois au lieu des minutes. Ce comportement est désormais cohérent avec MySQL. Le comportement précédent peut être rétabli avec le paramètre &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot;. [#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#48842](https://github.com/ClickHouse/ClickHouse/issues/48842) : correction de certains paramètres liés à MySQL qui n&#39;étaient pas pris en charge avec une source de dictionnaire MySQL + une collection nommée. Ferme [#48402](https://github.com/ClickHouse/ClickHouse/issues/48402). [#48759](https://github.com/ClickHouse/ClickHouse/pull/48759) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#49035](https://github.com/ClickHouse/ClickHouse/issues/49035) : ajout d&#39;un mécanisme de repli vers l&#39;authentification par mot de passe en cas d&#39;échec de l&#39;authentification à l&#39;aide d&#39;un certificat utilisateur SSL. Ferme [#48974](https://github.com/ClickHouse/ClickHouse/issues/48974). [#48989](https://github.com/ClickHouse/ClickHouse/pull/48989) ([Nikolay Degterinsky](https://github.com/evillique)).

[#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

[#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
