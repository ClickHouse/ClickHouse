<div id="buildtestingpackaging-improvement">
  #### Amélioration du build, des tests et du packaging
</div>

* Rétroporté dans [#55295](https://github.com/ClickHouse/ClickHouse/issues/55295) : la ressource contenant le code source, y compris les sous-modules, est générée dans la tâche de build spéciale Darwin. Elle peut être utilisée pour compiler ClickHouse sans avoir à extraire les sous-modules. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Rétroporté dans [#55368](https://github.com/ClickHouse/ClickHouse/issues/55368) : corrige un problème lié au lancement de ClickHouse Keeper en mode autonome depuis le paquet clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#55727](https://github.com/ClickHouse/ClickHouse/issues/55727) : corrige le script Python de vérification d’intégration pour qu’il utilise l’URL de l’API gh - ajoute un README pour les tests d’intégration continue. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
