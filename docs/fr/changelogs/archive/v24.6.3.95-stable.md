<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#66770](https://github.com/ClickHouse/ClickHouse/issues/66770) : faire en sorte que allow&#95;experimental&#95;analyzer soit contrôlé par l’initiateur pour les requêtes distribuées. Cela garantit la compatibilité et la cohérence lors d’opérations dans des clusters exécutant des versions mixtes. [#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="critical-bug-fix-crash-logical_error-data-loss-rbac">
  #### Correction de bug critique (plantage, LOGICAL_ERROR, perte de données, RBAC)
</div>

* Rétroporté dans [#66885](https://github.com/ClickHouse/ClickHouse/issues/66885) : corrige une taille inattendue de colonne à faible cardinalité dans les appels de fonction. [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#66693](https://github.com/ClickHouse/ClickHouse/issues/66693) : corrige la clause VALID UNTIL dans la définition de l’utilisateur, qui se réinitialisait après un redémarrage. Clôt [#66405](https://github.com/ClickHouse/ClickHouse/issues/66405). [#66409](https://github.com/ClickHouse/ClickHouse/pull/66409) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#67816](https://github.com/ClickHouse/ClickHouse/issues/67816) : concerne uniquement le type de données Experimental Variant. Corrige un plantage avec le type Variant + AggregateFunction. [#67122](https://github.com/ClickHouse/ClickHouse/pull/67122) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#67503](https://github.com/ClickHouse/ClickHouse/issues/67503) : corrige un plantage dans DistributedAsyncInsert lorsque la connexion est vide. [#67219](https://github.com/ClickHouse/ClickHouse/pull/67219) ([Pablo Marcos](https://github.com/pamarcos)).
* Rétroporté dans [#67852](https://github.com/ClickHouse/ClickHouse/issues/67852) : corrige [#66026](https://github.com/ClickHouse/ClickHouse/issues/66026). Évite le parcours des arguments de table function non résolus dans `ReplaceTableNodeToDummyVisitor`. [#67522](https://github.com/ClickHouse/ClickHouse/pull/67522) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#67838](https://github.com/ClickHouse/ClickHouse/issues/67838) : corrige un possible dépassement de pile dans la fonction `JSONMergePatch`. Cette fonction a été renommée de `jsonMergePatch` en `JSONMergePatch`, car le nom précédent était incorrect. Le nom précédent est toujours conservé pour des raisons de compatibilité. Améliore également le diagnostic des erreurs dans la fonction. Cela clôt [#67304](https://github.com/ClickHouse/ClickHouse/issues/67304). [#67756](https://github.com/ClickHouse/ClickHouse/pull/67756) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#66303](https://github.com/ClickHouse/ClickHouse/issues/66303) : meilleure gestion des conditions de jointure impliquant des vérifications `IS NULL` (par exemple, `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` est réécrit en `ON a <=> b`), avec correction d&#39;une optimisation incorrecte lorsque des conditions autres que `IS NULL` sont présentes. [#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#66330](https://github.com/ClickHouse/ClickHouse/issues/66330) : ajout des paramètres manquants `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` au cache d&#39;inférence de schéma, car ils peuvent modifier le schéma obtenu. Cela évite des résultats incorrects de l&#39;inférence de schéma lorsque ces paramètres sont modifiés. [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#66157](https://github.com/ClickHouse/ClickHouse/issues/66157) : correction d&#39;un bug de dépassement de tampon dans l&#39;implémentation de `unbin`/`unhex`. [#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#66210](https://github.com/ClickHouse/ClickHouse/issues/66210) : désactivation de l&#39;optimisation `merge-filters` introduite dans [#64760](https://github.com/ClickHouse/ClickHouse/issues/64760). Elle peut provoquer une exception si l&#39;optimisation fusionne deux expressions de filtre sans appliquer d&#39;évaluation en court-circuit. [#66126](https://github.com/ClickHouse/ClickHouse/pull/66126) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#66456](https://github.com/ClickHouse/ClickHouse/issues/66456) : correction d&#39;un bug dans le client ZooKeeper : une session pouvait rester bloquée dans un état inutilisable après réception d&#39;une erreur matérielle de ZooKeeper. Par exemple, cela pouvait se produire à cause de la &quot;limite mémoire souple&quot; dans ClickHouse Keeper. [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#66228](https://github.com/ClickHouse/ClickHouse/issues/66228) : correction d&#39;un problème dans SumIfToCountIfVisitor avec les entiers signés. [#66146](https://github.com/ClickHouse/ClickHouse/pull/66146) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#66183](https://github.com/ClickHouse/ClickHouse/issues/66183) : correction d&#39;un cas rare de données manquantes dans le résultat d&#39;une requête distribuée, clôture de [#61432](https://github.com/ClickHouse/ClickHouse/issues/61432). [#66174](https://github.com/ClickHouse/ClickHouse/pull/66174) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#66271](https://github.com/ClickHouse/ClickHouse/issues/66271) : ne pas lever `TIMEOUT_EXCEEDED` pour le mode `none_only_active` de `distributed_ddl_output_mode`. [#66218](https://github.com/ClickHouse/ClickHouse/pull/66218) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#66682](https://github.com/ClickHouse/ClickHouse/issues/66682) : correction de la gestion de la limite pour `system.numbers_mt` lorsqu&#39;aucun index ne peut être utilisé.
