<div id="backward-incompatible-change">
  #### Changement rétro-incompatible
</div>

* Les « index inversés » ont été renommés en « index de texte intégral », une appellation moins technique et plus accessible. Cela modifie également les métadonnées internes des tables et rend incompatibles les tables contenant déjà des index inversés (expérimentaux). Veillez à supprimer ces index avant la mise à niveau, puis à les recréer après celle-ci. [#62884](https://github.com/ClickHouse/ClickHouse/pull/62884) ([Robert Schulze](https://github.com/rschu1ze)).
* L&#39;utilisation des fonctions `neighbor`, `runningAccumulate`, `runningDifferenceStartingWithFirstValue`, `runningDifference` est déconseillée (car sujette aux erreurs). Il faut utiliser à la place de véritables fonctions de fenêtre. Pour les réactiver, définissez `allow_deprecated_functions=1`. [#63132](https://github.com/ClickHouse/ClickHouse/pull/63132) ([Nikita Taranov](https://github.com/nickitat)).
* Les requêtes sur `system.columns` seront plus rapides s&#39;il existe un grand nombre de colonnes, mais que les droits `SHOW TABLES` n&#39;ont pas été accordés sur de nombreuses bases de données ou tables. Notez que, dans les versions précédentes, si vous accordiez `SHOW COLUMNS` sur des colonnes individuelles sans accorder `SHOW TABLES` sur les tables correspondantes, la table `system.columns` affichait ces colonnes, alors que dans la nouvelle version, elle ignorera entièrement la table. Les messages du journal de trace « Access granted » et « Access denied », qui ralentissaient les requêtes, ont été supprimés. [#63439](https://github.com/ClickHouse/ClickHouse/pull/63439) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Ajoute la prise en charge de la fonction AzureBlobStorage dans ClickHouse server pour utiliser Workload Identity d’Azure afin de s’authentifier auprès d’Azure blob storage. Si le paramètre `use_workload_identity` est défini dans la config, l’[identité de charge de travail](https://github.com/Azure/azure-sdk-for-cpp/tree/main/sdk/identity/azure-identity#authenticate-azure-hosted-applications) est utilisée pour l’authentification. [#57881](https://github.com/ClickHouse/ClickHouse/pull/57881) ([Vinay Suryadevara](https://github.com/vinay92-ch)).
* Introduit le chargement en masse dans StorageEmbeddedRocksDB en créant et en ingérant un fichier SST au lieu de s’appuyer sur la memtable intégrée de RocksDB. Cela permet d’accélérer l’import, en particulier pour les requêtes `insert` de longue durée vers les tables StorageEmbeddedRocksDB. Introduit également les paramètres de table `StorageEmbeddedRocksDB`. [#59163](https://github.com/ClickHouse/ClickHouse/pull/59163) ([Duc Canh Le](https://github.com/canhld94)).
* Il est désormais possible d’analyser des fins de ligne CRLF avec le format TSV à l’aide du paramètre `input_format_tsv_crlf_end_of_line`. Résout [#56257](https://github.com/ClickHouse/ClickHouse/issues/56257). [#59747](https://github.com/ClickHouse/ClickHouse/pull/59747) ([Shaun Struwig](https://github.com/Blargian)).
* Ajoute le format Form pour lire/écrire un seul enregistrement au format application/x-www-form-urlencoded. [#60199](https://github.com/ClickHouse/ClickHouse/pull/60199) ([Shaun Struwig](https://github.com/Blargian)).
* Ajoute la possibilité de compresser dans CROSS JOIN. [#60459](https://github.com/ClickHouse/ClickHouse/pull/60459) ([p1rattttt](https://github.com/p1rattttt)).
* Nouveau paramètre `input_format_force_null_for_omitted_fields` qui force des valeurs NULL pour les champs omis. [#60887](https://github.com/ClickHouse/ClickHouse/pull/60887) ([Constantine Peresypkin](https://github.com/pkit)).
* Prend en charge les jointures avec des conditions d’inégalité impliquant des colonnes des tables de gauche et de droite, par ex. `t1.y < t2.y`. Pour l’activer, `SET allow_experimental_join_condition = 1`. [#60920](https://github.com/ClickHouse/ClickHouse/pull/60920) ([lgbo](https://github.com/lgbo-ustc)).
* Auparavant, notre stockage S3 et notre fonction de table S3 ne prenaient pas en charge la lecture depuis des fichiers d’archive. Une solution a été ajoutée pour itérer sur les fichiers à l’intérieur des archives dans S3. [#62259](https://github.com/ClickHouse/ClickHouse/pull/62259) ([Daniil Ivanik](https://github.com/divanik)).
* Prise en charge de la fonction conditionnelle `clamp`. [#62377](https://github.com/ClickHouse/ClickHouse/pull/62377) ([skyoct](https://github.com/skyoct)).
* Ajoute le format de sortie npy. [#62430](https://github.com/ClickHouse/ClickHouse/pull/62430) ([豪肥肥](https://github.com/HowePa)).
* Ajoute les fonctions SQL `generateUUIDv7`, `generateUUIDv7ThreadMonotonic`, `generateUUIDv7NonMonotonic` (avec différents compromis entre monotonie et performances) pour générer des UUID version 7, c.-à-d. des UUID basés sur un timestamp avec une composante aléatoire. Ajoute également une nouvelle fonction `UUIDToNum` pour extraire des octets d’un UUID, ainsi qu’une nouvelle fonction `UUIDv7ToDateTime` pour extraire la composante timestamp d’un UUID version 7. [#62852](https://github.com/ClickHouse/ClickHouse/pull/62852) ([Alexey Petrunyaka](https://github.com/pet74alex)).
* Rétroporté dans [#64307](https://github.com/ClickHouse/ClickHouse/issues/64307) : implémente le type de données Dynamic, qui permet de stocker des valeurs de n’importe quel type sans avoir à toutes les connaître à l’avance. Le type Dynamic est disponible via le paramètre `allow_experimental_dynamic_type`. Référence : [#54864](https://github.com/ClickHouse/ClickHouse/issues/54864). [#63058](https://github.com/ClickHouse/ClickHouse/pull/63058) ([Kruglov Pavel](https://github.com/Avogar)).
* Ajout du chargement en masse à StorageEmbeddedRocksDB en créant et en ingérant un fichier SST au lieu de s&#39;appuyer sur la memtable intégrée à RocksDB. Cela permet d&#39;accélérer l&#39;importation, en particulier pour les requêtes d&#39;insertion de longue durée dans les tables StorageEmbeddedRocksDB. Ajout également des paramètres de table de StorageEmbeddedRocksDB. [#63324](https://github.com/ClickHouse/ClickHouse/pull/63324) ([Duc Canh Le](https://github.com/canhld94)).
* Ajout de Raw comme synonyme de TSVRaw. [#63394](https://github.com/ClickHouse/ClickHouse/pull/63394) ([Unalian](https://github.com/Unalian)).
* Ajout de la possibilité d&#39;effectuer un cross join dans un fichier temporaire si la taille dépasse les limites. [#63432](https://github.com/ClickHouse/ClickHouse/pull/63432) ([p1rattttt](https://github.com/p1rattttt)).
* Sous Linux et MacOS, si la sortie STDOUT du programme est redirigée vers un fichier avec une extension de compression, la méthode de compression correspondante est utilisée au lieu de n&#39;en utiliser aucune (ce qui le fait se comporter de manière similaire à `INTO OUTFILE`). [#63662](https://github.com/ClickHouse/ClickHouse/pull/63662) ([v01dXYZ](https://github.com/v01dXYZ)).
* Modification de l&#39;avertissement en cas de nombre élevé de tables attachées afin de distinguer les tables, les vues et les dictionnaires. [#64180](https://github.com/ClickHouse/ClickHouse/pull/64180) ([Francisco J. Jurado Moreno](https://github.com/Beetelbrox)).

<div id="performance-improvement">

</div>

* Évite la fusion des blocs de projection nouvellement créés pendant les `INSERT`. [#59405](https://github.com/ClickHouse/ClickHouse/pull/59405) ([Nikita Taranov](https://github.com/nickitat)).
* Traite les fonctions sur les chaînes XXXUTF8 de manière « ascii » si les chaînes d’entrée ne contiennent que des caractères ASCII. Inspiré de [https://github.com/apache/doris/pull/29799](https://github.com/apache/doris/pull/29799). Accélération globale de 1,07x à 1,62x. À noter que le pic d’utilisation de la mémoire a diminué dans certains cas. [#61632](https://github.com/ClickHouse/ClickHouse/pull/61632) ([李扬](https://github.com/taiyang-li)).
* Améliore les performances des globs de sélection (`{}`) dans StorageS3. [#62120](https://github.com/ClickHouse/ClickHouse/pull/62120) ([Andrey Zvonov](https://github.com/zvonand)).
* HostResolver contient chaque adresse IP plusieurs fois. Si l’hôte distant a plusieurs IP et que, pour une raison quelconque (des règles de pare-feu, par exemple), l’accès à certaines IP est autorisé et à d’autres interdit, seul le premier enregistrement des IP interdites est alors marqué comme ayant échoué, et à chaque tentative ces IP peuvent être de nouveau sélectionnées (et échouer encore). Même après ce correctif, le cache DNS était vidé toutes les 120 secondes, et ces IP pouvaient donc être à nouveau sélectionnées. [#62652](https://github.com/ClickHouse/ClickHouse/pull/62652) ([Anton Ivashkin](https://github.com/ianton-ru)).
* Ajout d’une nouvelle configuration`prefer_merge_sort_block_bytes` pour contrôler l’utilisation mémoire et accélérer le tri d’un facteur 2 lors de la fusion lorsqu’il y a beaucoup de colonnes. [#62904](https://github.com/ClickHouse/ClickHouse/pull/62904) ([LiuNeng](https://github.com/liuneng1994)).
* `clickhouse-local` démarrera plus vite. Dans les versions précédentes, à cause d’une erreur, il ne supprimait pas les répertoires temporaires. Désormais, ce sera le cas. Cela clôt [#62941](https://github.com/ClickHouse/ClickHouse/issues/62941). [#63074](https://github.com/ClickHouse/ClickHouse/pull/63074) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Micro-optimisations pour le nouvel analyseur. [#63429](https://github.com/ClickHouse/ClickHouse/pull/63429) ([Raúl Marín](https://github.com/Algunenano)).
* L’analyse des index fonctionnera si `DateTime` est comparé à `DateTime64`. Cela clôt [#63441](https://github.com/ClickHouse/ClickHouse/issues/63441). [#63443](https://github.com/ClickHouse/ClickHouse/pull/63443) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* L’analyse des index fonctionnera si `DateTime` est comparé à `DateTime64`. Cela clôt [#63441](https://github.com/ClickHouse/ClickHouse/issues/63441). [#63532](https://github.com/ClickHouse/ClickHouse/pull/63532) ([Raúl Marín](https://github.com/Algunenano)).
* Accélère légèrement les index de type `set` (d’environ 1,5 fois) en supprimant des éléments inutiles. [#64098](https://github.com/ClickHouse/ClickHouse/pull/64098) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
