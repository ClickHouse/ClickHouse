  # Historique des changements 2022
</div>

<div id="clickhouse-release-v214655-stable-fixme-as-compared-to-v214546-stable">
  ### Version de ClickHouse v21.4.6.55-stable FIXME par rapport à v21.4.5.46-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#23679](https://github.com/ClickHouse/ClickHouse/issues/23679) : correction de `quantile(s)TDigest`. Ajout d’un traitement spécial pour les centroïdes singleton conformément à tdunning/t-digest 3.2+. Un bogue lié à une compression excessive des centroïdes dans l’implémentation d’une version antérieure de l’algorithme a également été corrigé. [#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#23580](https://github.com/ClickHouse/ClickHouse/issues/23580) : correction d&#39;une condition de concurrence très rare lors du nettoyage en arrière-plan des anciens blocs. Cela pouvait empêcher la déduplication d&#39;un bloc s&#39;il était trop proche de la fin de la fenêtre de déduplication. [#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23676](https://github.com/ClickHouse/ClickHouse/issues/23676) : ne pas assouplir les conditions NOT lors de l&#39;élagage de partitions. Cela corrige [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) et [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539). [#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#23583](https://github.com/ClickHouse/ClickHouse/issues/23583) : * correction d&#39;un bogue dans dict join avec join&#95;algorithm = &#39;auto&#39;. Corrige [#23002](https://github.com/ClickHouse/ClickHouse/issues/23002). [#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#23641](https://github.com/ClickHouse/ClickHouse/issues/23641) : correction de la génération d&#39;expressions constantes incompatibles lors de l&#39;élagage de partitions basé sur les colonnes virtuelles. Cela corrige [https://github.com/ClickHouse/ClickHouse/pull/21401#discussion&#95;r611888913](https://github.com/ClickHouse/ClickHouse/pull/21401#discussion_r611888913). [#23366](https://github.com/ClickHouse/ClickHouse/pull/23366) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#23586](https://github.com/ClickHouse/ClickHouse/issues/23586) : autoriser le déplacement de davantage de conditions vers `PREWHERE`, comme c&#39;était le cas avant la version 21.1. Un nombre insuffisant de conditions déplacées pouvait entraîner une baisse des performances. [#23397](https://github.com/ClickHouse/ClickHouse/pull/23397) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#23588](https://github.com/ClickHouse/ClickHouse/issues/23588) : correction de l&#39;erreur `Cannot unlink file` lors de l&#39;échec de création d&#39;une table ReplicatedMergeTree avec une configuration multi-disque. Cela corrige [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755). [#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23591](https://github.com/ClickHouse/ClickHouse/issues/23591) : correction de cas limites dans les fusions verticales avec `ReplacingMergeTree`. Dans de rares cas, ils pouvaient provoquer des échecs de fusion avec des exceptions telles que `Incomplete granules are not allowed while blocks are granules size`. [#23459](https://github.com/ClickHouse/ClickHouse/pull/23459) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#23611](https://github.com/ClickHouse/ClickHouse/issues/23611) : correction du blocage des commandes restart / stop. Corrige [#20214](https://github.com/ClickHouse/ClickHouse/issues/20214). [#23552](https://github.com/ClickHouse/ClickHouse/pull/23552) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#23693](https://github.com/ClickHouse/ClickHouse/issues/23693) : correction d&#39;une défaillance du serveur lorsqu&#39;une exception survenait pendant l&#39;insertion de données via HTTP. Cela corrige [#23512](https://github.com/ClickHouse/ClickHouse/issues/23512). [#23643](https://github.com/ClickHouse/ClickHouse/pull/23643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#23695](https://github.com/ClickHouse/ClickHouse/issues/23695) : ajout d&#39;une exception lorsque les deux échantillons ont exactement les mêmes valeurs dans la fonction d&#39;agrégation `mannWhitneyUTest`. Cela corrige [#23646](https://github.com/ClickHouse/ClickHouse/issues/23646). [#23654](https://github.com/ClickHouse/ClickHouse/pull/23654) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#23774](https://github.com/ClickHouse/ClickHouse/issues/23774) : évite l’éventuelle erreur &quot;Impossible de planifier une tâche&quot; (si une exception s’était produite) lors d’un INSERT dans Distributed. [#23744](https://github.com/ClickHouse/ClickHouse/pull/23744) ([Azat Khuzhin](https://github.com/azat)).
