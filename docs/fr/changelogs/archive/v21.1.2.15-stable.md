<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#19203](https://github.com/ClickHouse/ClickHouse/issues/19203) : `SELECT count() FROM table` peut désormais être exécuté si une seule colonne quelconque peut être sélectionnée dans `table`. Cette PR corrige [#10639](https://github.com/ClickHouse/ClickHouse/issues/10639). [#18233](https://github.com/ClickHouse/ClickHouse/pull/18233) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#19161](https://github.com/ClickHouse/ClickHouse/issues/19161) : corrige l’analyse d’index des fonctions binaires avec argument constant, qui entraînait des résultats de requête incorrects. Cela corrige [#18364](https://github.com/ClickHouse/ClickHouse/issues/18364). [#18373](https://github.com/ClickHouse/ClickHouse/pull/18373) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#18948](https://github.com/ClickHouse/ClickHouse/issues/18948) : correction de l’erreur `Attempt to read after eof` lors d’une tentative de `CAST` de `NULL` depuis `Nullable(String)` vers `Nullable(Decimal(P, S))`. Désormais, la fonction `CAST` renvoie `NULL` lorsqu’elle ne peut pas analyser une valeur décimale à partir d’une chaîne nullable. Corrige [#7690](https://github.com/ClickHouse/ClickHouse/issues/7690). [#18718](https://github.com/ClickHouse/ClickHouse/pull/18718) ([Winter Zhang](https://github.com/zhang2014)).
* Rétroporté dans [#18934](https://github.com/ClickHouse/ClickHouse/issues/18934) : corrige un problème avec `bitmapOrCardinality` pouvant entraîner un déréférencement de pointeur nul. Cela clôt [#18911](https://github.com/ClickHouse/ClickHouse/issues/18911). [#18912](https://github.com/ClickHouse/ClickHouse/pull/18912) ([sundyli](https://github.com/sundy-li)).
* Rétroporté dans [#19115](https://github.com/ClickHouse/ClickHouse/issues/19115) : Attach partition doit réinitialiser la mutation. [#18804](https://github.com/ClickHouse/ClickHouse/issues/18804). [#18935](https://github.com/ClickHouse/ClickHouse/pull/18935) ([fastio](https://github.com/fastio)).
* Rétroporté dans [#18966](https://github.com/ClickHouse/ClickHouse/issues/18966) : corrige un bogue où une mutation contenant du texte échappé (comme `ALTER ... UPDATE e = CAST('foo', 'Enum8(\'foo\' = 1')`) était sérialisée de manière incorrecte. Corrige [#18878](https://github.com/ClickHouse/ClickHouse/issues/18878). [#18944](https://github.com/ClickHouse/ClickHouse/pull/18944) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#19005](https://github.com/ClickHouse/ClickHouse/issues/19005) : corrige l’erreur `Task was not found in task queue` (possible uniquement pour les requêtes distantes, avec `async_socket_for_remote = 1`). [#18964](https://github.com/ClickHouse/ClickHouse/pull/18964) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#19009](https://github.com/ClickHouse/ClickHouse/issues/19009) : corrige le comportement incorrect lorsque la requête `ALTER TABLE ... DROP PART 'part_name'` supprime tous les blocs de déduplication de l’ensemble de la partition. Corrige [#18874](https://github.com/ClickHouse/ClickHouse/issues/18874). [#18969](https://github.com/ClickHouse/ClickHouse/pull/18969) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#19193](https://github.com/ClickHouse/ClickHouse/issues/19193) : correction d’un interblocage très rare à l’arrêt. [#18977](https://github.com/ClickHouse/ClickHouse/pull/18977) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#19004](https://github.com/ClickHouse/ClickHouse/issues/19004) : corrige l’exception possible `QueryPipeline stream: different number of columns` causée par la fusion des étapes `Expression` du plan de requête. Corrige [#18190](https://github.com/ClickHouse/ClickHouse/issues/18190). [#18980](https://github.com/ClickHouse/ClickHouse/pull/18980) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#19045](https://github.com/ClickHouse/ClickHouse/issues/19045) : désactive `optimize_move_functions_out_of_any`, car l’optimisation n’est pas toujours correcte. Cela clôt [#18051](https://github.com/ClickHouse/ClickHouse/issues/18051). Cela clôt [#18973](https://github.com/ClickHouse/ClickHouse/issues/18973). [#18981](https://github.com/ClickHouse/ClickHouse/pull/18981) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#19070](https://github.com/ClickHouse/ClickHouse/issues/19070) : Join tente de matérialiser des colonnes constantes, mais notre code les attend ailleurs. [#18982](https://github.com/ClickHouse/ClickHouse/pull/18982) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#19053](https://github.com/ClickHouse/ClickHouse/issues/19053) : corrige l’insertion d’une colonne `LowCardinality` dans une table avec le moteur `TinyLog`. Corrige [#18629](https://github.com/ClickHouse/ClickHouse/issues/18629). [#19010](https://github.com/ClickHouse/ClickHouse/pull/19010) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
