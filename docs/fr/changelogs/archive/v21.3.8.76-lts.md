<div id="clickhouse-release-v213876-lts-fixme-as-compared-to-v213762-stable">
  ### Version de ClickHouse v21.3.8.76-lts FIXME par rapport à v21.3.7.62-stable

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#23396](https://github.com/ClickHouse/ClickHouse/issues/23396) : si un tuple de valeurs NULL, par ex. `(NULL, NULL)`, se trouve à gauche de l’opérateur `IN` et que des tuples de valeurs non-NULL se trouvent à droite, par ex. `SELECT (NULL, NULL) IN ((0, 0), (3, 1))`, la requête retourne 0 au lieu de lever une exception pour types incompatibles. Cette expression peut également apparaître à la suite de l’optimisation d’une requête comme `SELECT (NULL, NULL) = (8, 0) OR (NULL, NULL) = (3, 2) OR (NULL, NULL) = (0, 0) OR (NULL, NULL) = (3, 1)`. Cela résout [#22017](https://github.com/ClickHouse/ClickHouse/issues/22017). [#22063](https://github.com/ClickHouse/ClickHouse/pull/22063) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23272](https://github.com/ClickHouse/ClickHouse/issues/23272) : désactivation des paramètres `use_hedged_requests` et `async_socket_for_remote`, car des éléments indiquent qu’ils peuvent provoquer des problèmes. [#23261](https://github.com/ClickHouse/ClickHouse/pull/23261) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Corrections de bugs
</div>

* Rétroporté dans [#23232](https://github.com/ClickHouse/ClickHouse/issues/23232) : le serveur pouvait ne pas démarrer si le paramètre `data_type_default_nullable` était activé dans le profil `default` ; c’est corrigé. Corrige [#22573](https://github.com/ClickHouse/ClickHouse/issues/22573). [#23185](https://github.com/ClickHouse/ClickHouse/pull/23185) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23406](https://github.com/ClickHouse/ClickHouse/issues/23406) : QueryAliasVisitor privilégie un alias pour ASTWithAlias si la sous-requête a été optimisée en constante. Corrige [#22924](https://github.com/ClickHouse/ClickHouse/issues/22924). Corrige [#10401](https://github.com/ClickHouse/ClickHouse/issues/10401). [#23191](https://github.com/ClickHouse/ClickHouse/pull/23191) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#23381](https://github.com/ClickHouse/ClickHouse/issues/23381) : correction de l’erreur `Not found column` lors d’une sélection depuis `MaterializeMySQL` avec une condition sur la colonne clé. Corrige [#22432](https://github.com/ClickHouse/ClickHouse/issues/22432). [#23200](https://github.com/ClickHouse/ClickHouse/pull/23200) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23284](https://github.com/ClickHouse/ClickHouse/issues/23284) : correction de la création via DDL d’un dictionnaire à clé simple si la clé primaire n’est pas le premier attribut. Corrige [#23236](https://github.com/ClickHouse/ClickHouse/issues/23236). [#23262](https://github.com/ClickHouse/ClickHouse/pull/23262) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#23450](https://github.com/ClickHouse/ClickHouse/issues/23450) : correction d’une race condition (distribuée) très rare entre la création et la suppression de tables ReplicatedMergeTree. Cela pouvait provoquer des exceptions comme `node doesn't exist` lors d’une tentative de création d’une table répliquée. Corrige [#21419](https://github.com/ClickHouse/ClickHouse/issues/21419). [#23294](https://github.com/ClickHouse/ClickHouse/pull/23294) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23500](https://github.com/ClickHouse/ClickHouse/issues/23500) : correction d’un crash possible lorsqu’un `unknown packet` était reçu depuis une remote query (avec `async_socket_for_remote` activé). Corrige peut-être [#21167](https://github.com/ClickHouse/ClickHouse/issues/21167). [#23309](https://github.com/ClickHouse/ClickHouse/pull/23309) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#23468](https://github.com/ClickHouse/ClickHouse/issues/23468) : `ORDER BY` avec `COLLATE` ne fonctionnait pas correctement si la colonne fait partie de la clé primaire (ou est une fonction monotone de celle-ci) et que le paramètre `optimize_read_in_order` n’est pas désactivé. Cela clôt [#22379](https://github.com/ClickHouse/ClickHouse/issues/22379). Solution de contournement pour les versions plus anciennes : désactiver le paramètre `optimize_read_in_order`. [#23375](https://github.com/ClickHouse/ClickHouse/pull/23375) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23544](https://github.com/ClickHouse/ClickHouse/issues/23544) : suppression de la prise en charge de `argMin` et `argMax` pour un seul argument `Tuple`. Le code n’était pas sûr en mémoire. Cette fonctionnalité a été ajoutée par erreur et prête à confusion. Ces fonctions pourront être réintroduites plus tard sous d’autres noms. Cela corrige [#22384](https://github.com/ClickHouse/ClickHouse/issues/22384) et annule [#17359](https://github.com/ClickHouse/ClickHouse/issues/17359). [#23393](https://github.com/ClickHouse/ClickHouse/pull/23393) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23479](https://github.com/ClickHouse/ClickHouse/issues/23479) : le stockage Kafka peut désormais prendre en charge les messages aux formats `arrow` et `arrowstream`. [#23415](https://github.com/ClickHouse/ClickHouse/pull/23415) ([Chao Ma](https://github.com/godliness)).
* Rétroporté dans [#23499](https://github.com/ClickHouse/ClickHouse/issues/23499) : - correction d’un bug de la fonction d’agrégation `deltaSum` dans le cas d’une réinitialisation de compteur... [#23437](https://github.com/ClickHouse/ClickHouse/pull/23437) ([Russ Frank](https://github.com/rf)).
* Rétroporté dans [#23493](https://github.com/ClickHouse/ClickHouse/issues/23493) : correction d’un bug empêchant la conversion depuis un littéral de tableau vide vers un tableau avec des dimensions supérieures à 1. Ferme [#14476](https://github.com/ClickHouse/ClickHouse/issues/14476). [#23456](https://github.com/ClickHouse/ClickHouse/pull/23456) ([Maksim Kita](https://github.com/kitaisreal)).
