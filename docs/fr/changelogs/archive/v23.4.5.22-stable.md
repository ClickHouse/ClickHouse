<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530) : scission d’un énorme `RUN` dans le Dockerfile en conditions plus petites. Installation des outils nécessaires à la demande dans la même couche `RUN`, puis suppression de ceux-ci. Mise à niveau de l’OS une seule fois, au début. Utilisation d’une méthode moderne pour vérifier le dépôt signé. Rétrogradation du dépôt de base vers ubuntu:20.04 pour résoudre les problèmes rencontrés avec les anciennes versions de Docker. Mise à niveau de la version de golang pour corriger les vulnérabilités de golang. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570) : il s’agit d’un suivi de [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504) ; le nettoyage a été perdu lors du refactoring. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Correction d’une analyse d’index défaillante lorsqu’un opérateur binaire contient un argument constant NULL [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* Correction de la reconnexion de la session HTTPS lorsque l’adresse IP de l’hôte cible avait changé [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Correction d’un repliement de constantes incorrect [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Correction du type du hash des params du serveur LDAP dans une entrée de cache [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* Repli sur l’analyse d’un grand entier à partir de String au lieu de lever une exception au format Parquet [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* Ne pas appliquer de projection si read-in-order était activé. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Correction d’un échec du fuzzer dans ActionsDAG [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
