  # Historique des modifications 2022

<div id="clickhouse-release-v214321-stable-fixme-as-compared-to-v214210-prestable">
  ### Version de ClickHouse v21.4.3.21-stable FIXME par rapport à v21.4.2.10-prestable

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#22934](https://github.com/ClickHouse/ClickHouse/issues/22934) : vérifier correctement la structure des blocs distribués asynchrones. [#22325](https://github.com/ClickHouse/ClickHouse/pull/22325) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix">
  #### Corrections de bogues
</div>

* Rétroporté dans [#22966](https://github.com/ClickHouse/ClickHouse/issues/22966) : correction d’un bogue très rare où une insertion avec quorum avec `quorum_parallel=1` n’est pas réellement un « quorum » à cause de la déduplication. [#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22722](https://github.com/ClickHouse/ClickHouse/issues/22722) : vérifie si la table function view est utilisée comme colonne. Complète [https://github.com/ClickHouse/ClickHouse/pull/20350](https://github.com/ClickHouse/ClickHouse/pull/20350). [#21465](https://github.com/ClickHouse/ClickHouse/pull/21465) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#22808](https://github.com/ClickHouse/ClickHouse/issues/22808) : correctif complémentaire pour [#21936](https://github.com/ClickHouse/ClickHouse/issues/21936). Corrige également [#22433](https://github.com/ClickHouse/ClickHouse/issues/22433). [#22518](https://github.com/ClickHouse/ClickHouse/pull/22518) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#22757](https://github.com/ClickHouse/ClickHouse/issues/22757) : corrige l’utilisation de la fonction `map` dans les requêtes distribuées. [#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* Rétroporté dans [#22702](https://github.com/ClickHouse/ClickHouse/issues/22702) : corrige l’attente des mutations sur plusieurs répliques pour les moteurs de table ReplicatedMergeTree. Auparavant, une requête de mutation/ALTER pouvait se terminer avant que la mutation ne soit effectivement exécutée sur les autres répliques. [#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22741](https://github.com/ClickHouse/ClickHouse/issues/22741) : corrige d’éventuels blocages dans les requêtes zk en cas d’exception OOM. Corrige [#22438](https://github.com/ClickHouse/ClickHouse/issues/22438). [#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#22888](https://github.com/ClickHouse/ClickHouse/issues/22888) : corrige le comptage approximatif du nombre total de lignes lors de la lecture inversée depuis MergeTree. [#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22884](https://github.com/ClickHouse/ClickHouse/issues/22884) : corrige le pushdown de `HAVING` lorsque la colonne de filtre est utilisée dans une agrégation. [#22763](https://github.com/ClickHouse/ClickHouse/pull/22763) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#22917](https://github.com/ClickHouse/ClickHouse/issues/22917) : LIVE VIEW (fonctionnalité expérimentale). Corrige un blocage possible lors d’un DROP/CREATE concurrent de TEMPORARY LIVE VIEW dans `TemporaryLiveViewCleaner`, voir [https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e](https://gist.github.com/vzakaznikov/0c03195960fc86b56bfe2bc73a90019e). [#22858](https://github.com/ClickHouse/ClickHouse/pull/22858) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#22921](https://github.com/ClickHouse/ClickHouse/issues/22921) : corrige un crash lors de l’utilisation de `mannWhitneyUTest` et `rankCorr` avec des fonctions de fenêtre. Corrige [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728). [#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#22957](https://github.com/ClickHouse/ClickHouse/issues/22957) : correction de l’utilisation de colonnes constantes de type `Map` avec des valeurs de type `Nullable`. [#22939](https://github.com/ClickHouse/ClickHouse/pull/22939) ([Anton Popov](https://github.com/CurtizJ)).
