<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#61439](https://github.com/ClickHouse/ClickHouse/issues/61439) : le query cache refuse désormais l’accès aux entrées lorsqu’un utilisateur est recréé ou assume un autre rôle. Cela empêche en outre les attaques dans lesquelles 1. un utilisateur portant le même nom qu’un utilisateur supprimé peut accéder aux anciennes entrées de cache de cet utilisateur ou 2. un utilisateur ayant un rôle différent peut accéder aux entrées de cache d’un rôle avec une policy de lignes différente. [#58611](https://github.com/ClickHouse/ClickHouse/pull/58611) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#61572](https://github.com/ClickHouse/ClickHouse/issues/61572) : corrige la recherche de chaînes avec une position de départ constante, qui pouvait auparavant entraîner une corruption de la mémoire. [#61547](https://github.com/ClickHouse/ClickHouse/pull/61547) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#61854](https://github.com/ClickHouse/ClickHouse/issues/61854) : corrige un plantage dans `multiSearchAllPositionsCaseInsensitiveUTF8` lors de la spécification d’une séquence UTF-8 incorrecte. Example : [#61714](https://github.com/ClickHouse/ClickHouse/issues/61714#issuecomment-2012768202). [#61749](https://github.com/ClickHouse/ClickHouse/pull/61749) ([pufit](https://github.com/pufit)).
