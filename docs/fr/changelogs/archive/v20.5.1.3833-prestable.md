<div id="clickhouse-release-v20513833-prestable-fixme-as-compared-to-v20413177-prestable">

<div id="backward-incompatible-change">
  #### Changement non rétrocompatible
</div>

* Supprime le paramètre `experimental_use_processors`. Il est désormais activé par défaut. [#10924](https://github.com/ClickHouse/ClickHouse/pull/10924) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Le paramètre `input_format_with_names_use_header` est désormais activé par défaut. Cela affectera l’analyse des formats d’entrée `-WithNames` et `-WithNamesAndTypes`. [#10937](https://github.com/ClickHouse/ClickHouse/pull/10937) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Ajout d’une vérification pour le cas où un user-level setting est spécifié au mauvais endroit. Les user-level settings doivent être spécifiés dans `users.xml`, dans la section `<profile>` du profil utilisateur concerné (ou dans `<default>` pour les paramètres par défaut). Le server ne démarrera pas et consignera un message d’exception dans le log. Cela corrige [#9051](https://github.com/ClickHouse/ClickHouse/issues/9051). Si vous souhaitez ignorer cette vérification, vous pouvez soit déplacer les paramètres à l’emplacement approprié, soit ajouter `<skip_check_for_incorrect_settings>1</skip_check_for_incorrect_settings>` à config.xml. [#11449](https://github.com/ClickHouse/ClickHouse/pull/11449) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Renvoie un résultat non-Nullable pour COUNT(DISTINCT) et la famille des aggregate functions `uniq`. Si toutes les valeurs transmises sont NULL, renvoie zéro à la place. Cela améliore la compatibilité SQL. [#11661](https://github.com/ClickHouse/ClickHouse/pull/11661) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
