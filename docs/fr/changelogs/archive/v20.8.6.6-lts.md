  ### Version de ClickHouse v20.8.6.6-lts FIXME par rapport à v20.8.5.45-lts
</div>

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#16494](https://github.com/ClickHouse/ClickHouse/issues/16494) : correction d’un bogue affectant une base de données MySQL. Lorsque le serveur MySQL utilisé comme moteur de base de données est indisponible, certaines requêtes lèvent une exception, car elles essaient d’obtenir des tables depuis un serveur désactivé alors que ce n’est pas nécessaire. Par exemple, la requête `SELECT ... FROM system.parts` ne devrait fonctionner qu’avec des tables MergeTree et ne pas accéder du tout à la base de données MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#16816](https://github.com/ClickHouse/ClickHouse/issues/16816) : correction d’un comportement incohérent où une partie des données renvoyées pouvait être ignorée parce que l’ensemble utilisé pour leur filtrage n’avait pas été créé. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#16506](https://github.com/ClickHouse/ClickHouse/issues/16506) : correction du traitement de très grandes entrées dans la file de réplication. De très grandes entrées peuvent apparaître dans les requêtes ALTER si la structure de la table est extrêmement volumineuse (près de 1 Mo). Cela corrige [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#16472](https://github.com/ClickHouse/ClickHouse/issues/16472) : correction de DROP TABLE pour Distributed (condition de concurrence avec INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#16573](https://github.com/ClickHouse/ClickHouse/issues/16573) : correction de la croissance rapide des métadonnées lors de l’utilisation de MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine, avec `slave_parallel_worker` activé sur le réplica MySQL Slave, grâce à une réduction correcte des ensembles GTID. Cela corrige [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Rétroporté dans [#16552](https://github.com/ClickHouse/ClickHouse/issues/16552) : désormais, lors de l’analyse d’AVRO en entrée, LowCardinality est supprimé du type. Corrige [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Rétroporté dans [#16823](https://github.com/ClickHouse/ClickHouse/issues/16823) : correction de [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#16892](https://github.com/ClickHouse/ClickHouse/issues/16892) : correction de rares plantages silencieux lorsque le profileur de requêtes est activé et que ClickHouse est installé sur un système d’exploitation avec une version de glibc qui possède (apparemment) des tables de déroulage asynchrone défectueuses pour certaines fonctions. Cela corrige [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Cela corrige [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
