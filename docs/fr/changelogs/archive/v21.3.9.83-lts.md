<div id="2022-changelog">
  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v213983-lts-fixme-as-compared-to-v213876-lts">
  ### Version ClickHouse v21.3.9.83-lts FIXME comparée à la v21.3.8.76-lts
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#23680](https://github.com/ClickHouse/ClickHouse/issues/23680) : correction de `quantile(s)TDigest`. Ajout d’un traitement spécial pour les centroïdes singletons conformément à tdunning/t-digest 3.2+. Un bogue de surcompression des centroïdes dans l’implémentation d’une version antérieure de l’algorithme a également été corrigé. [#23314](https://github.com/ClickHouse/ClickHouse/pull/23314) ([Vladimir Chebotarev](https://github.com/excitoon)).

<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#23579](https://github.com/ClickHouse/ClickHouse/issues/23579) : correction d’une condition de concurrence très rare lors du nettoyage en arrière-plan des anciens blocs. Cela pouvait empêcher la déduplication d’un bloc s’il était trop proche de la fin de la fenêtre de déduplication. [#23301](https://github.com/ClickHouse/ClickHouse/pull/23301) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23677](https://github.com/ClickHouse/ClickHouse/issues/23677) : ne pas assouplir les conditions NOT lors du partition pruning. Cela corrige [#23305](https://github.com/ClickHouse/ClickHouse/issues/23305) et [#21539](https://github.com/ClickHouse/ClickHouse/issues/21539). [#23310](https://github.com/ClickHouse/ClickHouse/pull/23310) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#23582](https://github.com/ClickHouse/ClickHouse/issues/23582) : * Correction d’un bogue dans le dict join avec join&#95;algorithm = &#39;auto&#39;. Résout [#23002](https://github.com/ClickHouse/ClickHouse/issues/23002). [#23312](https://github.com/ClickHouse/ClickHouse/pull/23312) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#23585](https://github.com/ClickHouse/ClickHouse/issues/23585) : permettre de déplacer davantage de conditions vers `PREWHERE`, comme c’était le cas avant la version 21.1. Un nombre insuffisant de conditions déplacées pouvait entraîner une baisse des performances. [#23397](https://github.com/ClickHouse/ClickHouse/pull/23397) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#23592](https://github.com/ClickHouse/ClickHouse/issues/23592) : correction de l’erreur `Cannot unlink file` lors de l’échec de création d’une table ReplicatedMergeTree avec une configuration multidisque. Cela résout [#21755](https://github.com/ClickHouse/ClickHouse/issues/21755). [#23433](https://github.com/ClickHouse/ClickHouse/pull/23433) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23590](https://github.com/ClickHouse/ClickHouse/issues/23590) : correction de cas limites dans les fusions verticales avec `ReplacingMergeTree`. Dans de rares cas, ils pouvaient entraîner des échecs de fusion avec des exceptions comme `Incomplete granules are not allowed while blocks are granules size`. [#23459](https://github.com/ClickHouse/ClickHouse/pull/23459) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#23612](https://github.com/ClickHouse/ClickHouse/issues/23612) : correction du blocage des commandes restart / stop. Résout [#20214](https://github.com/ClickHouse/ClickHouse/issues/20214). [#23552](https://github.com/ClickHouse/ClickHouse/pull/23552) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#23696](https://github.com/ClickHouse/ClickHouse/issues/23696) : ajout d’une exception lorsque les deux échantillons ont exactement les mêmes valeurs dans la fonction d’agrégation `mannWhitneyUTest`. Cela corrige [#23646](https://github.com/ClickHouse/ClickHouse/issues/23646). [#23654](https://github.com/ClickHouse/ClickHouse/pull/23654) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
