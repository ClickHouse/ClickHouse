<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#40451](https://github.com/ClickHouse/ClickHouse/issues/40451) : correction d’un bogue rare lié au TTL de colonne dans la famille de moteurs MergeTree : en cas de fusion verticale répétée, l’erreur `Cannot unlink file ColumnName.bin ... No such file or directory.` pouvait se produire. [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#40533](https://github.com/ClickHouse/ClickHouse/issues/40533) : le résolveur de proxy s’arrête après la première requête réussie vers le point de terminaison. [#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#40625](https://github.com/ClickHouse/ClickHouse/issues/40625) : correction d’une perte de données potentielle due à un bogue dans l’AWS SDK ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)). Ce bogue ne peut être déclenché que lorsque ClickHouse utilise S3. [#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
