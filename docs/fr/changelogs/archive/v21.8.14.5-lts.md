  #### Correction de bogue (comportement erroné visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#33184](https://github.com/ClickHouse/ClickHouse/issues/33184) : le serveur pouvait ne pas démarrer lorsqu’une base de données utilisant le moteur `MySQL` ne parvenait pas à se connecter au serveur MySQL ; ce problème est corrigé. Corrige [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441). [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#33659](https://github.com/ClickHouse/ClickHouse/issues/33659) : correction de la vérification de l’URL HDFS, qui n’autorisait pas l’utilisation de l’adresse HA du namenode. Le bogue a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042). [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#33206](https://github.com/ClickHouse/ClickHouse/issues/33206) : correction de la lecture d’un fichier vide via la S3 table function. Clôt [#33008](https://github.com/ClickHouse/ClickHouse/issues/33008). [#33037](https://github.com/ClickHouse/ClickHouse/pull/33037) ([Kseniia Sumarokova](https://github.com/kssenii)).
