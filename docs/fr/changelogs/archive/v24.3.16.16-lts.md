<div id="buildtestingpackaging-improvement">
  #### Amélioration de la build/des tests/du packaging
</div>

* Rétroporté dans [#75283](https://github.com/ClickHouse/ClickHouse/issues/75283) : amélioration visant à rendre les paramètres par défaut encore plus restrictifs. Les paramètres par défaut actuels sont déjà sûrs : l’utilisateur doit explicitement spécifier une option pour publier les ports. Toutefois, lorsque l’utilisateur `default` n’a pas de mot de passe défini via la variable d’environnement `CLICKHOUSE_PASSWORD` et/ou de nom d’utilisateur modifié via `CLICKHOUSE_USER`, il ne doit être accessible que depuis le système local, comme niveau de protection supplémentaire. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
