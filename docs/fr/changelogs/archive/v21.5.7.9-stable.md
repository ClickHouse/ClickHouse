Ce problème est corrigé. - Correction d'un crash survenant lorsque la file de réplication contient des parties virtuelles qui se chevauchent. Ce cas peut se produire rarement si une partie de données est perdue. L'erreur est désormais consignée dans le journal au lieu de provoquer l'arrêt du processus. [#24777](https://github.com/ClickHouse/ClickHouse/pull/24777) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#24854](https://github.com/ClickHouse/ClickHouse/issues/24854) : Correction d'un bogue où l'exception `Mutation was killed` pouvait être renvoyée au client lors de l'attente d'une mutation pas encore chargée en mémoire.
