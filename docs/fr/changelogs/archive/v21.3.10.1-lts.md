<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#23973](https://github.com/ClickHouse/ClickHouse/issues/23973) : correction d’un bug dans la récupération d’une réplique `ReplicatedMergeTree` obsolète. Certaines mises à jour de métadonnées pouvaient être ignorées par une réplique obsolète si une requête `ALTER` était exécutée pendant l’indisponibilité de la réplique. [#23742](https://github.com/ClickHouse/ClickHouse/pull/23742) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23773](https://github.com/ClickHouse/ClickHouse/issues/23773) : évite une erreur possible « Cannot schedule a task » (dans le cas où une exception se serait produite) lors d’un INSERT dans Distributed. [#23744](https://github.com/ClickHouse/ClickHouse/pull/23744) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#23817](https://github.com/ClickHouse/ClickHouse/issues/23817) : correction d’un crash lorsque `PREWHERE` et le filtre de politique de lignes sont tous deux actifs avec un résultat vide. [#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#23814](https://github.com/ClickHouse/ClickHouse/issues/23814) : correction du fait que `CLEAR COLUMN` ne fonctionne pas lorsqu’il est référencé par une vue matérialisée. Clôture [#23764](https://github.com/ClickHouse/ClickHouse/issues/23764). [#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
