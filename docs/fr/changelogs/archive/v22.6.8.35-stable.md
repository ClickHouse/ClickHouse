<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#41282](https://github.com/ClickHouse/ClickHouse/issues/41282) : correction des colonnes inconnues non utilisées introduites par l’instruction WITH. Cela corrige [#37812](https://github.com/ClickHouse/ClickHouse/issues/37812). [#39131](https://github.com/ClickHouse/ClickHouse/pull/39131) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#40905](https://github.com/ClickHouse/ClickHouse/issues/40905) : correction d’un interblocage potentiel dans WriteBufferFromS3 lors d’un échec de planification des tâches. [#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#40864](https://github.com/ClickHouse/ClickHouse/issues/40864) : - correction d’un plantage lors de l’analyse des valeurs de type `Object` contenant des tableaux à dimension variable. [#40483](https://github.com/ClickHouse/ClickHouse/pull/40483) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#40803](https://github.com/ClickHouse/ClickHouse/issues/40803) : lors de l’insertion d’une nouvelle requête dans la `ProcessList`, des allocations mémoire ont lieu. Si la limite de mémoire est atteinte pendant ces allocations, il est impossible d’utiliser `OvercommitTracker`, car `ProcessList::mutex` est déjà verrouillé. Corrige [#40611](https://github.com/ClickHouse/ClickHouse/issues/40611). [#40677](https://github.com/ClickHouse/ClickHouse/pull/40677) ([Dmitry Novik](https://github.com/novikd)).
* Rétroporté dans [#40891](https://github.com/ClickHouse/ClickHouse/issues/40891) : correction d’une fuite de mémoire lors de l’écriture vers des MV sans contexte de requête (depuis Kafka/...). [#40732](https://github.com/ClickHouse/ClickHouse/pull/40732) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#41133](https://github.com/ClickHouse/ClickHouse/issues/41133) : correction des droits d’accès pour `DESCRIBE TABLE url()` et certaines autres formes de `DESCRIBE TABLE <table_function>()`. [#40975](https://github.com/ClickHouse/ClickHouse/pull/40975) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#41360](https://github.com/ClickHouse/ClickHouse/issues/41360) : correction de l’erreur logique `Expected relative path` dans le stockage d’objets sur disque. Lié à [#41246](https://github.com/ClickHouse/ClickHouse/issues/41246). [#41297](https://github.com/ClickHouse/ClickHouse/pull/41297) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#41357](https://github.com/ClickHouse/ClickHouse/issues/41357) : ajout d’une vérification du type de colonne avant l’insertion d’un UUID au format MsgPack. [#41309](https://github.com/ClickHouse/ClickHouse/pull/41309) ([Kruglov Pavel](https://github.com/Avogar)).
