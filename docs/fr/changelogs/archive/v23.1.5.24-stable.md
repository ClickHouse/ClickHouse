<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#47060](https://github.com/ClickHouse/ClickHouse/issues/47060) : correction d’une erreur au démarrage du serveur sur d’anciennes distributions (par ex. Amazon Linux 2) et sur ARM : les symboles de glibc 2.28 sont introuvables. [#47008](https://github.com/ClickHouse/ClickHouse/pull/47008) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#46401](https://github.com/ClickHouse/ClickHouse/issues/46401) : correction des requêtes `SYSTEM UNFREEZE` qui échouaient avec l’exception `CANNOT_PARSE_INPUT_ASSERTION_FAILED`. [#46325](https://github.com/ClickHouse/ClickHouse/pull/46325) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Rétroporté dans [#46905](https://github.com/ClickHouse/ClickHouse/issues/46905) : - correction d’une récursion incorrecte des alias dans QueryNormalizer. [#46609](https://github.com/ClickHouse/ClickHouse/pull/46609) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#47211](https://github.com/ClickHouse/ClickHouse/issues/47211) : les requêtes `INSERT` via le protocole TCP natif et le protocole HTTP n’étaient pas correctement annulées dans certains cas. Cela pouvait conduire à l’application partielle d’une requête si un client l’annulait, si un client s’arrêtait brutalement ou, dans de rares cas, en cas d’erreurs réseau. En conséquence, cela pouvait rendre la déduplication inopérante. Corrige [#27667](https://github.com/ClickHouse/ClickHouse/issues/27667) et [#45377](https://github.com/ClickHouse/ClickHouse/issues/45377). [#46681](https://github.com/ClickHouse/ClickHouse/pull/46681) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#47118](https://github.com/ClickHouse/ClickHouse/issues/47118) : - correction des opérations arithmétiques dans l’optimisation des agrégations avec `min` et `max`. [#46705](https://github.com/ClickHouse/ClickHouse/pull/46705) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#46883](https://github.com/ClickHouse/ClickHouse/issues/46883) : correction d’un signalement MSan dans la fonction `maxIntersections`. Ceci clôt [#43126](https://github.com/ClickHouse/ClickHouse/issues/43126). [#46847](https://github.com/ClickHouse/ClickHouse/pull/46847) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#47361](https://github.com/ClickHouse/ClickHouse/issues/47361) : correction d’un interblocage possible lors de l’annulation d’une requête distribuée. [#47161](https://github.com/ClickHouse/ClickHouse/pull/47161) ([Kruglov Pavel](https://github.com/Avogar)).
