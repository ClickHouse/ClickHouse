* Rétroporté dans [#32691](https://github.com/ClickHouse/ClickHouse/issues/32691) : la limite du quota n’était pas atteinte, mais elle était considérée comme dépassée. #### Correction de bug (dysfonctionnement visible par l’utilisateur dans la version stable officielle)

* Rétroporté dans [#32711](https://github.com/ClickHouse/ClickHouse/issues/32711) : correction des échecs de requêtes qui tentent d’utiliser des indices de saut qui ne sont pas encore matérialisés. Corrige [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) et [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343). [#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#32568](https://github.com/ClickHouse/ClickHouse/issues/32568) : correction d’un crash dans `JoinCommon::removeColumnNullability`, clôt [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458). [#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#32732](https://github.com/ClickHouse/ClickHouse/issues/32732) : correction d’un code étonnamment mauvais dans la fonction `file`. [#32640](https://github.com/ClickHouse/ClickHouse/pull/32640) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
