<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#76864](https://github.com/ClickHouse/ClickHouse/issues/76864) : ajout de la possibilité de recharger `max_remote_read_network_bandwidth_for_serve` et `max_remote_write_network_bandwidth_for_server` à la volée, sans redémarrer le serveur. [#74206](https://github.com/ClickHouse/ClickHouse/pull/74206) ([Kai Zhu](https://github.com/nauu)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#76997](https://github.com/ClickHouse/ClickHouse/issues/76997) : correction d’une perte de données lorsque l’async insert est activé et qu’un `insert into ... from file ...` est exécuté avec des tailles de bloc inégales : si la taille du premier bloc est &lt; `async_max_size` mais que celle du second est &gt; `async_max_size`, le second bloc n’est pas inséré. Ces données restent dans `squashing`. [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* Rétroporté dans [#76675](https://github.com/ClickHouse/ClickHouse/issues/76675) : correction de l’initialisation de `used_flag` dans le hash parallèle. Cela pouvait provoquer un plantage du serveur. [#76580](https://github.com/ClickHouse/ClickHouse/pull/76580) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#76833](https://github.com/ClickHouse/ClickHouse/issues/76833) : vidage des tampons d’écriture de sortie avant leur finalisation. Corrige `LOGICAL_ERROR` générée lors de la finalisation de certains formats de sortie, par exemple `JSONEachRowWithProgressRowOutputFormat`. [#76726](https://github.com/ClickHouse/ClickHouse/pull/76726) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#77062](https://github.com/ClickHouse/ClickHouse/issues/77062) : correction du tri des valeurs `BFloat16`. Clôt [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487). Clôt [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669). [#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
