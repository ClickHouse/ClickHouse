<div id="2022-changelog">
  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v219330-stable-fixme-as-compared-to-v219217-stable">
  ### Version de ClickHouse v21.9.3.30-stable FIXME par rapport à v21.9.2.17-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#28897](https://github.com/ClickHouse/ClickHouse/issues/28897) : utiliser un véritable fichier temporaire au lieu du « rows&#95;sources » prédéfini pour les fusions verticales. Cela évite de générer des répertoires indésirables sur les disques tmp. [#28299](https://github.com/ClickHouse/ClickHouse/pull/28299) ([Amos Bird](https://github.com/amosbird)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#28815](https://github.com/ClickHouse/ClickHouse/issues/28815) : corrige un crash possible pour `SELECT` avec une projection d’agrégation partiellement créée en cas d’exception. [#28700](https://github.com/ClickHouse/ClickHouse/pull/28700) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#28789](https://github.com/ClickHouse/ClickHouse/issues/28789) : corrige une race condition bénigne dans ReplicatedMergeTreeQueue. Cela ne devrait pas être visible pour l’utilisateur, mais peut entraîner des bogues subtils. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28842](https://github.com/ClickHouse/ClickHouse/issues/28842) : corrige la compilation des expressions avec évaluation en court-circuit. [#28821](https://github.com/ClickHouse/ClickHouse/pull/28821) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#28993](https://github.com/ClickHouse/ClickHouse/issues/28993) : corrige une race condition entre `DROP PART` et `REPLACE/MOVE PARTITION` qui pouvait, dans de rares cas, faire diverger les répliques. [#28864](https://github.com/ClickHouse/ClickHouse/pull/28864) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#28949](https://github.com/ClickHouse/ClickHouse/issues/28949) : corrige la lecture des sous-colonnes à partir de parties compactes. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28925](https://github.com/ClickHouse/ClickHouse/issues/28925) : corrige un bogue avec LowCardinality dans l’évaluation en court-circuit des fonctions. Ferme [#28884](https://github.com/ClickHouse/ClickHouse/issues/28884). [#28887](https://github.com/ClickHouse/ClickHouse/pull/28887) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#28927](https://github.com/ClickHouse/ClickHouse/issues/28927) : corrige les fonctions de tableau d’ordre supérieur (`SIGSEGV` pour `arrayCompact`/`ILLEGAL_COLUMN` pour `arrayDifference`/`arrayCumSumNonNegative`) avec des constantes. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#29025](https://github.com/ClickHouse/ClickHouse/issues/29025) : corrige le nombre de threads utilisés dans la sous-requête `GLOBAL IN` (elle était exécutée sur un seul thread depuis le correctif du bogue [#19414](https://github.com/ClickHouse/ClickHouse/issues/19414)). [#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
