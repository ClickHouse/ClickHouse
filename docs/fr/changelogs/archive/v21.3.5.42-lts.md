  ### Version ClickHouse v21.3.5.42-lts FIXME comparée à v21.3.4.25-lts

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#22335](https://github.com/ClickHouse/ClickHouse/issues/22335) : correction de la fonction de table `clusterAllReplicas`, qui renvoyait un `_shard_num` incorrect. clôt [#21481](https://github.com/ClickHouse/ClickHouse/issues/21481). [#21498](https://github.com/ClickHouse/ClickHouse/pull/21498) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#22319](https://github.com/ClickHouse/ClickHouse/issues/22319) : suppression des colonnes inconnues de la table jointe dans la clause WHERE pour les requêtes vers des moteurs de base de données externes (MySQL, PostgreSQL). clôt [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614), clôt [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (dup), clôt [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (dup). [#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#22241](https://github.com/ClickHouse/ClickHouse/issues/22241) : correction de l’analyse d’index des sous-requêtes scalaires. Cela corrige [#21717](https://github.com/ClickHouse/ClickHouse/issues/21717), introduit par [https://github.com/ClickHouse/ClickHouse/pull/18896](https://github.com/ClickHouse/ClickHouse/pull/18896). [#21766](https://github.com/ClickHouse/ClickHouse/pull/21766) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#22150](https://github.com/ClickHouse/ClickHouse/issues/22150) : amélioration de la gestion des erreurs et de la journalisation dans WriteBufferFromS3. [#21836](https://github.com/ClickHouse/ClickHouse/pull/21836) ([Pavel Kovalenko](https://github.com/Jokser)).
* Rétroporté dans [#22468](https://github.com/ClickHouse/ClickHouse/issues/22468) : dans de rares cas, une fusion pour `CollapsingMergeTree` peut créer un granule avec `index_granularity + 1` lignes. De ce fait, la vérification interne, ajoutée dans [#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) (affecte 21.2 et 21.3), peut échouer avec l’erreur `Incomplete granules are not allowed while blocks are granules size`. Cette erreur empêchait la fusion des parties. [#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#22203](https://github.com/ClickHouse/ClickHouse/issues/22203) : point d’entrée Docker : éviter le chown de `.` lorsque `LOG_PATH` est vide. clôt [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100). [#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22261](https://github.com/ClickHouse/ClickHouse/issues/22261) : désactivation de `async_socket_for_remote`/`use_hedged_requests` pour les noyaux Linux bogués. [#22109](https://github.com/ClickHouse/ClickHouse/pull/22109) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22281](https://github.com/ClickHouse/ClickHouse/issues/22281) : correction de l’attente des requêtes `OPTIMIZE` et `ALTER` pour les moteurs de table `ReplicatedMergeTree`. Désormais, la requête ne restera plus bloquée lorsque la table a été détachée ou redémarrée. [#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22265](https://github.com/ClickHouse/ClickHouse/issues/22265) : correction du nom du pool de threads d’arrière-plan. [#22122](https://github.com/ClickHouse/ClickHouse/pull/22122) ([fastio](https://github.com/fastio)).
* Rétroporté dans [#22262](https://github.com/ClickHouse/ClickHouse/issues/22262) : corrige l’erreur `Invalid number of rows in Chunk` dans `JOIN` avec `TOTALS` et `arrayJoin`. Ferme [#19303](https://github.com/ClickHouse/ClickHouse/issues/19303). [#22129](https://github.com/ClickHouse/ClickHouse/pull/22129) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#22316](https://github.com/ClickHouse/ClickHouse/issues/22316) : corrige l’entrypoint Docker lorsque `http_port` n’est pas présent dans la configuration. [#22132](https://github.com/ClickHouse/ClickHouse/pull/22132) ([Ewout](https://github.com/devwout)).
* Rétroporté dans [#22313](https://github.com/ClickHouse/ClickHouse/issues/22313) : corrige l’annulation de requête avec `use_hedged_requests=0` et `async_socket_for_remote=1`. [#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22366](https://github.com/ClickHouse/ClickHouse/issues/22366) : désormais, ClickHouse ne lèvera plus d’exception `LOGICAL_ERROR` lors d’une tentative de mutation d’une part déjà couverte. Corrige [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013). [#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22562](https://github.com/ClickHouse/ClickHouse/issues/22562) : ne limite pas la taille des chunks HTTP. Corrige [#21907](https://github.com/ClickHouse/ClickHouse/issues/21907). [#22322](https://github.com/ClickHouse/ClickHouse/pull/22322) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#22531](https://github.com/ClickHouse/ClickHouse/issues/22531) : un dépassement de tampon (en lecture) était possible dans l’index de texte intégral `tokenbf_v1`. Les octets excédentaires ne sont pas utilisés, mais l’opération de lecture peut entraîner un plantage dans de rares cas. Cela ferme [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233). [#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22463](https://github.com/ClickHouse/ClickHouse/issues/22463) : ajoute la comptabilisation mémoire manquante dans les routines d’analyse syntaxique exécutées en parallèle. Dans les versions précédentes, un OOM était possible lorsque le jeu de résultats contenait de très gros blocs de données. Cela ferme [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008). [#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22507](https://github.com/ClickHouse/ClickHouse/issues/22507) : retire le socket d’epoll avant d’annuler le récepteur de paquets dans HedgedConnections afin d’éviter une condition de concurrence potentielle. Espérons que cela corrige [#22161](https://github.com/ClickHouse/ClickHouse/issues/22161). [#22443](https://github.com/ClickHouse/ClickHouse/pull/22443) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#22554](https://github.com/ClickHouse/ClickHouse/issues/22554) : corrige un bogue dans la jointure par fusion partielle avec `LowCardinality`. Ferme [#22386](https://github.com/ClickHouse/ClickHouse/issues/22386), ferme [#22388](https://github.com/ClickHouse/ClickHouse/issues/22388). [#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#22607](https://github.com/ClickHouse/ClickHouse/issues/22607) : corrige la désérialisation d’une chaîne vide sans retour à la ligne final à la fin du format TSV. Cela ferme [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244). Contournement possible sans mise à jour de version : définissez `input_format_null_as_default` sur zéro. C’était zéro dans les anciennes versions. [#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22576](https://github.com/ClickHouse/ClickHouse/issues/22576) : correction de l&#39;UB en déverrouillant le rwlock de TinyLog depuis le même thread. [#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22651](https://github.com/ClickHouse/ClickHouse/issues/22651) : évite l&#39;UB dans les *Log engines lors du déverrouillage du rwlock par un autre thread. [#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22653](https://github.com/ClickHouse/ClickHouse/issues/22653) : ne tente de vider le buffer d&#39;écriture que s&#39;il est initialisé. Corrige un segfault lorsque le client ferme la connexion très tôt [#22579](https://github.com/ClickHouse/ClickHouse/issues/22579). [#22591](https://github.com/ClickHouse/ClickHouse/pull/22591) ([nvartolomei](https://github.com/nvartolomei)).
* Rétroporté dans [#22681](https://github.com/ClickHouse/ClickHouse/issues/22681) : corrige LOGICAL&#95;ERROR pour Log avec des types imbriqués sans colonnes dans la clause SELECT. [#22654](https://github.com/ClickHouse/ClickHouse/pull/22654) ([Azat Khuzhin](https://github.com/azat)).
