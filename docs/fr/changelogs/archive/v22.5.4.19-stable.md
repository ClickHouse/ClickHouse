<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#39748](https://github.com/ClickHouse/ClickHouse/issues/39748) : corrige le repositionnement pendant la lecture depuis un disque chiffré. Cette PR corrige [#38381](https://github.com/ClickHouse/ClickHouse/issues/38381). [#39687](https://github.com/ClickHouse/ClickHouse/pull/39687) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#39882](https://github.com/ClickHouse/ClickHouse/issues/39882) : auparavant, les paquets installaient le fichier `systemd.service` dans `/etc`. Les fichiers qui s&#39;y trouvent sont marqués comme `conf` ; ils ne sont donc ni supprimés ni mis à jour automatiquement. Cette PR les supprime. [#39323](https://github.com/ClickHouse/ClickHouse/pull/39323) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#39209](https://github.com/ClickHouse/ClickHouse/issues/39209) : correction de la lecture des colonnes sparse des tables `MergeTree` qui stockent leurs données dans S3. [#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#39589](https://github.com/ClickHouse/ClickHouse/issues/39589) : correction d’une situation de concurrence et d’un possible dépassement de tampon dans le tas au format Avro. Ferme [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094). Ferme [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652). [#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#39611](https://github.com/ClickHouse/ClickHouse/issues/39611) : correction d’un bogue affectant l’argument maxsplit de splitByChar, qui ne fonctionnait pas correctement. [#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#39790](https://github.com/ClickHouse/ClickHouse/issues/39790) : correction d’une analyse d’index incorrecte avec des tuples et l’opérateur `IN`, qui pouvait produire un résultat de la requête erroné. [#39752](https://github.com/ClickHouse/ClickHouse/pull/39752) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#39835](https://github.com/ClickHouse/ClickHouse/issues/39835) : correction de l’exception `CANNOT_READ_ALL_DATA` avec `local_filesystem_read_method=pread_threadpool`. Ce bogue n’affectait que les versions 5.9 et 5.10 du noyau Linux, d’après [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS). [#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
