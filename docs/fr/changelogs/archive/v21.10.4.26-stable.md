<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#31518](https://github.com/ClickHouse/ClickHouse/issues/31518) : suppression de la fonction `not like` de RPNElement. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* Rétroporté dans [#31554](https://github.com/ClickHouse/ClickHouse/issues/31554) : résolution de `nullptr` dans le fournisseur d’informations d’identification STS pour S3. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#31579](https://github.com/ClickHouse/ClickHouse/issues/31579) : * Désactivation de `partial_merge_join_left_table_buffer_bytes` jusqu’à la correction du bogue dans cette optimisation. Voir [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)). * Suppression de l’option redondante `partial_merge_join_optimizations`. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#31745](https://github.com/ClickHouse/ClickHouse/issues/31745) : la requête `RENAME TABLE` fonctionnait incorrectement lors d’une tentative de renommage d’un Dictionary DDL dans la base de données `Ordinary` ; le problème a été corrigé. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#31794](https://github.com/ClickHouse/ClickHouse/issues/31794) : les paramètres `input_format_allow_errors_num` et `input_format_allow_errors_ratio` ne fonctionnaient pas pour l’analyse des types de domaine, tels que `IPv4` ; le problème a été corrigé. Corrige [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686). [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#31830](https://github.com/ClickHouse/ClickHouse/issues/31830) : correction de l’erreur `there are no such cluster here` lors de l’exécution d’une requête `ON CLUSTER` si le nom de cluster spécifié est celui d’une base de données `Replicated`. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#31815](https://github.com/ClickHouse/ClickHouse/issues/31815) : correction d’une condition de concurrence dans le format de sortie JSONEachRowWithProgress lorsque les données et les lignes de progression sont mélangées dans la sortie. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#32016](https://github.com/ClickHouse/ClickHouse/issues/32016) : correction des alias dans GROUP BY / ORDER BY / LIMIT BY lorsque les arguments positionnels sont activés. Ferme [#31173](https://github.com/ClickHouse/ClickHouse/issues/31173). [#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#31762](https://github.com/ClickHouse/ClickHouse/issues/31762) : correction de l’utilisation du moteur de table `Buffer` avec le type `Map`. Corrige [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546). [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#31892](https://github.com/ClickHouse/ClickHouse/issues/31892) : correction d’une possible assertion `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` dans le format TSKV. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#32031](https://github.com/ClickHouse/ClickHouse/issues/32031) : correction d’un CAST invalide d’un type Nullable lorsqu’une clé primaire Nullable est utilisée. Cela corrige [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075). [#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#32074](https://github.com/ClickHouse/ClickHouse/issues/32074) : correction d’un bogue lié à la fonction `transform` avec des arguments `Decimal`. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* Rétroporté dans [#31939](https://github.com/ClickHouse/ClickHouse/issues/31939) : - Changement du chemin de configuration de `keeper_server.session_timeout_ms` vers `keeper_server.coordination_settings.session_timeout_ms` lors de la construction d’un `KeeperTCPHandler` - Idem pour `operation_timeout`. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* Rétroporté dans [#31909](https://github.com/ClickHouse/ClickHouse/issues/31909) : correction des fonctions `empty` et `notEmpty` avec des arguments de type `UUID`. Corrige [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819). [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
