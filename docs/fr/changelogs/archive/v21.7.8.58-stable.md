</div>

* Rétroporté dans [#27506](https://github.com/ClickHouse/ClickHouse/issues/27506) : corrige des erreurs telles que `Expected ColumnLowCardinality, gotUInt8` ou `Bad cast from type DB::ColumnVector<char8_t> to DB::ColumnLowCardinality` pour certaines requêtes avec `LowCardinality` dans `PREWHERE`. Corrige [#23515](https://github.com/ClickHouse/ClickHouse/issues/23515). [#27298](https://github.com/ClickHouse/ClickHouse/pull/27298) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#27644](https://github.com/ClickHouse/ClickHouse/issues/27644) : corrige un résultat incorrect pour une requête avec sécurité au niveau des lignes, `PREWHERE` et filtre `LowCardinality`. Corrige [#27179](https://github.com/ClickHouse/ClickHouse/issues/27179). [#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#27474](https://github.com/ClickHouse/ClickHouse/issues/27474) : corrige la métrique BackgroundMessageBrokerSchedulePoolTask, peut-être mal nommée. [#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* Rétroporté dans [#27649](https://github.com/ClickHouse/ClickHouse/issues/27649) : corrige un crash pendant la matérialisation des projections lorsque certaines parts contiennent des colonnes manquantes. Corrige [#27512](https://github.com/ClickHouse/ClickHouse/issues/27512). [#27528](https://github.com/ClickHouse/ClickHouse/pull/27528) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#27778](https://github.com/ClickHouse/ClickHouse/issues/27778) : - corrige un bogue lié à une colonne aliasée dans une table `Distributed`. [#27652](https://github.com/ClickHouse/ClickHouse/pull/27652) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#27674](https://github.com/ClickHouse/ClickHouse/issues/27674) : corrige la table function PostgreSQL qui laissait des connexions ouvertes. Clôt [#26088](https://github.com/ClickHouse/ClickHouse/issues/26088). [#27662](https://github.com/ClickHouse/ClickHouse/pull/27662) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#27697](https://github.com/ClickHouse/ClickHouse/issues/27697) : corrige une conversion de type incorrecte lorsque des functions comme `arrayHas` sont appliquées à des arrays de `LowCardinality` de `Nullable` de différents types non numériques, comme `DateTime` et `DateTime64`. Dans les versions précédentes, une conversion de type incorrecte se produisait. Dans la nouvelle version, cela entraînera une exception. Clôt [#26330](https://github.com/ClickHouse/ClickHouse/issues/26330). [#27682](https://github.com/ClickHouse/ClickHouse/pull/27682) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#27748](https://github.com/ClickHouse/ClickHouse/issues/27748) : supprime les fichiers source en double dans CMakeLists.txt d&#39;arrow-cmake. [#27736](https://github.com/ClickHouse/ClickHouse/pull/27736) ([李扬](https://github.com/taiyang-li)).
