* Rétroporté dans [#57668](https://github.com/ClickHouse/ClickHouse/issues/57668) : produire un JSON/XML valide en cas d&#39;Exception pendant l&#39;exécution d&#39;une requête HTTP. Ajout du paramètre `http_write_exception_in_output_format` pour activer ou désactiver ce comportement (activé par défaut). [#52853](https://github.com/ClickHouse/ClickHouse/pull/52853) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#58491](https://github.com/ClickHouse/ClickHouse/issues/58491) : correction de la requête de transfert pour la rendre compatible avec MySQL. Corrige [#57253](https://github.com/ClickHouse/ClickHouse/issues/57253). Corrige [#52654](https://github.com/ClickHouse/ClickHouse/issues/52654). Corrige [#56729](https://github.com/ClickHouse/ClickHouse/issues/56729). [#56456](https://github.com/ClickHouse/ClickHouse/pull/56456) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#57238](https://github.com/ClickHouse/ClickHouse/issues/57238) : la récupération d&#39;une part attend lorsque cette part est entièrement validée sur la replica distante. Mieux vaut ne pas envoyer de part à l&#39;état PreActive. En cas de zero copy, il s&#39;agit d&#39;une restriction obligatoire. [#56808](https://github.com/ClickHouse/ClickHouse/pull/56808) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#57655](https://github.com/ClickHouse/ClickHouse/issues/57655) : gérer le cas de sigabrt lors de la récupération de la structure d&#39;une table PostgreSQL avec un tableau vide. [#57618](https://github.com/ClickHouse/ClickHouse/pull/57618) ([Mikhail Kot](https://github.com/myrrc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#58324](https://github.com/ClickHouse/ClickHouse/issues/58324) : n’aplatir que le véritable type Nested si flatten&#95;nested=1, et non tous les Array(Tuple). [#56132](https://github.com/ClickHouse/ClickHouse/pull/56132) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#57395](https://github.com/ClickHouse/ClickHouse/issues/57395) : correction de ALTER COLUMN avec ALIAS, qui levait auparavant l’exception `NO_SUCH_COLUMN_IN_TABLE`. Clôt [#50927](https://github.com/ClickHouse/ClickHouse/issues/50927). [#56493](https://github.com/ClickHouse/ClickHouse/pull/56493) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#57449](https://github.com/ClickHouse/ClickHouse/issues/57449) : désormais, les ALTER de colonnes incompatibles avec des colonnes utilisées dans certaines projections seront interdits. Auparavant, cela pouvait produire des données incorrectes. Cela corrige [#56932](https://github.com/ClickHouse/ClickHouse/issues/56932). Cette PR autorise également RENAME des colonnes d’index et améliore le message d’exception en fournissant des informations claires sur les indices ou projections concernés à l’origine du blocage. [#56948](https://github.com/ClickHouse/ClickHouse/pull/56948) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#57281](https://github.com/ClickHouse/ClickHouse/issues/57281) : correction d’un segfault après ALTER UPDATE avec une materialized column Nullable. Clôt [#42918](https://github.com/ClickHouse/ClickHouse/issues/42918). [#57147](https://github.com/ClickHouse/ClickHouse/pull/57147) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#57247](https://github.com/ClickHouse/ClickHouse/issues/57247) : correction d’une optimisation incorrecte du plan JOIN avec une projection normale partiellement matérialisée. Cela corrige [#57194](https://github.com/ClickHouse/ClickHouse/issues/57194). [#57196](https://github.com/ClickHouse/ClickHouse/pull/57196) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#57346](https://github.com/ClickHouse/ClickHouse/issues/57346) : correction de la métrique `ReadonlyReplica` dans certains cas (par exemple lorsqu’une table ne peut pas être initialisée en raison d’une différence entre les données locales et celles de Keeper). [#57267](https://github.com/ClickHouse/ClickHouse/pull/57267) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#58434](https://github.com/ClickHouse/ClickHouse/issues/58434) : correction du fonctionnement avec les read buffers dans StreamingFormatExecutor ; auparavant, cela pouvait entraîner des segfaults dans Kafka et d’autres streaming engines. [#57438](https://github.com/ClickHouse/ClickHouse/pull/57438) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#57539](https://github.com/ClickHouse/ClickHouse/issues/57539) : correction de l’analyse de `SYSTEM STOP LISTEN TCP SECURE`. [#57483](https://github.com/ClickHouse/ClickHouse/pull/57483) ([joelynch](https://github.com/joelynch)).
* Rétroporté dans [#57779](https://github.com/ClickHouse/ClickHouse/issues/57779) : config `<user_directories> <replicated> <zookeeper_path>/clickhouse/access/</zookeeper_path> </replicated> </user_directories>` sql &#96;&#96;&#96; show settings like &#39;ignore&#95;on&#95;cluster&#95;for&#95;replicated&#95;access&#95;entities&#95;queries&#39; ┌─name─────────────────────────────────────────────────────┬─type─┬─value─┐ │ ignore&#95;on&#95;cluster&#95;for&#95;replicated&#95;access&#95;entities&#95;queries │ bool │ 1 │ └──────────────────────────────────────────────────────────┴──────┴───────┘. [#57538](https://github.com/ClickHouse/ClickHouse/pull/57538) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Rétroporté dans [#58256](https://github.com/ClickHouse/ClickHouse/issues/58256) : Désactivation de system.kafka&#95;consumers par défaut (en raison d’une possible fuite de mémoire à l’exécution). [#57822](https://github.com/ClickHouse/ClickHouse/pull/57822) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#57923](https://github.com/ClickHouse/ClickHouse/issues/57923) : Correction d’un accès mémoire invalide dans BLAKE3. [#57876](https://github.com/ClickHouse/ClickHouse/pull/57876) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#58084](https://github.com/ClickHouse/ClickHouse/issues/58084) : Normalisation des noms de fonction dans la requête `CREATE INDEX`. Évite les erreurs `Existing table metadata in ZooKeeper differs in skip indexes` si un alias a été utilisé à la place du nom de fonction canonique lors de la création d’un index. [#57906](https://github.com/ClickHouse/ClickHouse/pull/57906) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#58110](https://github.com/ClickHouse/ClickHouse/issues/58110) : Correctif Keeper : le leader doit échouer correctement lors du prétraitement d’une requête s’il n’est pas initialisé. [#58069](https://github.com/ClickHouse/ClickHouse/pull/58069) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#58155](https://github.com/ClickHouse/ClickHouse/issues/58155) : Correction d’un débordement d’entier dans Poco::UTF32Encoding. [#58073](https://github.com/ClickHouse/ClickHouse/pull/58073) ([Andrey Fedotov](https://github.com/anfedotoff)).
