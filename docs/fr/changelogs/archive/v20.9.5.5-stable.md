  ### Version de ClickHouse v20.9.5.5-stable FIXME par rapport à v20.9.4.76-stable
</div>

<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493) : correction d’un bogue lié à la base de données MySQL. Lorsque le serveur MySQL utilisé comme database engine est indisponible, certaines requêtes lèvent une Exception, car elles tentent d’obtenir des tables depuis un serveur désactivé alors que ce n’est pas nécessaire. Par exemple, la query `SELECT ... FROM system.parts` ne devrait fonctionner qu’avec des MergeTree tables et ne devrait pas accéder du tout à la base de données MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817) : correction d’un comportement incohérent où une partie des données renvoyées pouvait être ignorée parce que le set nécessaire à son filtrage n’avait pas été créé. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508) : correction du traitement des très grandes entrées dans la file d’attente de réplication. De très grandes entrées peuvent apparaître dans des queries ALTER si la structure de la table est extrêmement volumineuse (près de 1 Mo). Cela corrige [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474) : correction de DROP TABLE pour Distributed (en concurrence avec INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571) : correction de la croissance rapide des métadonnées lors de l’utilisation de MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine, avec `slave_parallel_worker` activé sur MySQL Slave, grâce à une réduction correcte des ensembles GTID. Cela corrige [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Rétroporté dans [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554) : désormais, lors du parsing d’AVRO en entrée, LowCardinality est supprimé du type. Corrige [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Rétroporté dans [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748) : correction de [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894) : correction de rares crashs silencieux lorsque le query profiler est activé et que ClickHouse est installé sur un système avec une version de glibc qui comporte (apparemment) des asynchronous unwind tables défectueuses pour certaines fonctions. Cela corrige [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Cela corrige [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
