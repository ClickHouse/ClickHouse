  # Changelog 2022

<div id="clickhouse-release-v211830-stable-fixme-as-compared-to-v21171-stable">
  ### Version de ClickHouse v21.1.8.30-stable FIXME par rapport à v21.1.7.1-stable
</div>

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#21205](https://github.com/ClickHouse/ClickHouse/issues/21205) : correction d’une fuite de métadonnées lors de la suppression d’un Replicated*MergeTree avec un cluster ZooKeeper personnalisé (non default). [#21119](https://github.com/ClickHouse/ClickHouse/pull/21119) ([fastio](https://github.com/fastio)).
* Rétroporté dans [#21161](https://github.com/ClickHouse/ClickHouse/issues/21161) : correction pour que `input_format_null_as_default` soit pris en compte lorsque les types sont Nullable. Cela corrige [#21116](https://github.com/ClickHouse/ClickHouse/issues/21116). [#21121](https://github.com/ClickHouse/ClickHouse/pull/21121) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#21926](https://github.com/ClickHouse/ClickHouse/issues/21926) : correction de l’analyse du format Avro pour Kafka. Corrige [#21437](https://github.com/ClickHouse/ClickHouse/issues/21437). [#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)).
* Rétroporté dans [#22189](https://github.com/ClickHouse/ClickHouse/issues/22189) : correction d’une condition de concurrence sur l’objet SSL dans SecureSocket de Poco. [#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#22317](https://github.com/ClickHouse/ClickHouse/issues/22317) : suppression des colonnes inconnues de la table jointe dans WHERE pour les requêtes vers des moteurs de base de données externes (MySQL, PostgreSQL). clôt [#14614](https://github.com/ClickHouse/ClickHouse/issues/14614), clôt [#19288](https://github.com/ClickHouse/ClickHouse/issues/19288) (dup), clôt [#19645](https://github.com/ClickHouse/ClickHouse/issues/19645) (dup). [#21640](https://github.com/ClickHouse/ClickHouse/pull/21640) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#21797](https://github.com/ClickHouse/ClickHouse/issues/21797) : correction de l’annulation des requêtes distribuées (par exemple, un simple select sur plusieurs shards avec limit, c.-à-d. `select * from remote('127.{2,3}', system.numbers) limit 100`) avec `async_socket_for_remote=1`. [#21643](https://github.com/ClickHouse/ClickHouse/pull/21643) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22287](https://github.com/ClickHouse/ClickHouse/issues/22287) : démarrage de l’acceptation des connexions après l’initialisation de DDLWorker et des dictionnaires. [#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21810](https://github.com/ClickHouse/ClickHouse/issues/21810) : correction d’un bug dans les moteurs de table ReplicatedMerge lorsque la requête `ALTER MODIFY COLUMN` ne modifie pas le type d’une colonne Decimal si sa taille (32 bits ou 64 bits) ne change pas. [#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#21880](https://github.com/ClickHouse/ClickHouse/issues/21880) : correction de plantages possibles dans les fonctions d’agrégation avec le combinateur Distinct lors de l’utilisation de l’agrégation à deux niveaux. Il s’agit d’un correctif complémentaire de [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365). Ne peut être reproduit qu’en environnement de production. Aucun cas de test n’est encore disponible. cc @CurtizJ. [#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#22052](https://github.com/ClickHouse/ClickHouse/issues/22052) : correction d’un interblocage lors de la première exécution du modèle catboost. Clôt [#13832](https://github.com/ClickHouse/ClickHouse/issues/13832). [#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#21981](https://github.com/ClickHouse/ClickHouse/issues/21981) : annulation de [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454), qui pouvait entraîner une augmentation significative de l’utilisation de la mémoire lors du chargement de dictionnaires externes de type hashed. Cela clôt [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935). [#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#22465](https://github.com/ClickHouse/ClickHouse/issues/22465) : dans de rares cas, une fusion pour `CollapsingMergeTree` peut créer une granule de `index_granularity + 1` lignes. De ce fait, la vérification interne ajoutée dans [#18928](https://github.com/ClickHouse/ClickHouse/issues/18928) (affecte 21.2 et 21.3) peut échouer avec l’erreur `Incomplete granules are not allowed while blocks are granules size`. Cette erreur empêchait la fusion des parts. [#21976](https://github.com/ClickHouse/ClickHouse/pull/21976) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#22149](https://github.com/ClickHouse/ClickHouse/issues/22149) : la fonction `decrypt` ne vérifiait pas la taille minimale des données chiffrées en mode AEAD. Cela clôt [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897). [#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22283](https://github.com/ClickHouse/ClickHouse/issues/22283) : point d’entrée Docker : éviter le `chown` de `.` lorsque `LOG_PATH` est vide. Clôt [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100). [#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22280](https://github.com/ClickHouse/ClickHouse/issues/22280) : correction de l’attente des requêtes `OPTIMIZE` et `ALTER` pour les moteurs de table `ReplicatedMergeTree`. Désormais, la requête ne restera plus bloquée lorsque la table a été détachée ou redémarrée. [#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22501](https://github.com/ClickHouse/ClickHouse/issues/22501) : correction de l’annulation de requête avec `use_hedged_requests=0` et `async_socket_for_remote=1`. [#22183](https://github.com/ClickHouse/ClickHouse/pull/22183) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22368](https://github.com/ClickHouse/ClickHouse/issues/22368) : désormais, ClickHouse ne lèvera plus d’exception `LOGICAL_ERROR` lors d’une tentative de mutation d’une part déjà couverte. Corrige [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013). [#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22533](https://github.com/ClickHouse/ClickHouse/issues/22533) : un dépassement de tampon (en lecture) était possible dans l’index de texte intégral `tokenbf_v1`. Les octets excédentaires ne sont pas utilisés, mais l’opération de lecture peut entraîner un crash dans de rares cas. Cela clôt [#19233](https://github.com/ClickHouse/ClickHouse/issues/19233). [#22421](https://github.com/ClickHouse/ClickHouse/pull/22421) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22462](https://github.com/ClickHouse/ClickHouse/issues/22462) : ajout de la comptabilisation mémoire manquante dans les routines d’analyse syntaxique en parallèle. Dans les versions précédentes, une erreur OOM était possible lorsque le resultset contenait de très gros blocs de données. Cela clôt [#22008](https://github.com/ClickHouse/ClickHouse/issues/22008). [#22425](https://github.com/ClickHouse/ClickHouse/pull/22425) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22555](https://github.com/ClickHouse/ClickHouse/issues/22555) : correction d’un bogue dans partial merge join avec `LowCardinality`. Ferme [#22386](https://github.com/ClickHouse/ClickHouse/issues/22386), ferme [#22388](https://github.com/ClickHouse/ClickHouse/issues/22388). [#22510](https://github.com/ClickHouse/ClickHouse/pull/22510) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#22608](https://github.com/ClickHouse/ClickHouse/issues/22608) : correction de la désérialisation d’une chaîne vide sans saut de ligne à la fin du format TSV. Ceci clôt [#20244](https://github.com/ClickHouse/ClickHouse/issues/20244). Solution de contournement possible sans mise à jour de version : définir `input_format_null_as_default` sur zéro. Cette valeur était zéro dans les anciennes versions. [#22527](https://github.com/ClickHouse/ClickHouse/pull/22527) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22578](https://github.com/ClickHouse/ClickHouse/issues/22578) : correction d’un UB en déverrouillant le rwlock de TinyLog depuis le même thread. [#22560](https://github.com/ClickHouse/ClickHouse/pull/22560) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22650](https://github.com/ClickHouse/ClickHouse/issues/22650) : évite un UB dans les moteurs *Log lors du déverrouillage du rwlock dû à un déverrouillage depuis un autre thread. [#22583](https://github.com/ClickHouse/ClickHouse/pull/22583) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22700](https://github.com/ClickHouse/ClickHouse/issues/22700) : correction de l’attente des mutations sur plusieurs répliques pour les moteurs de table ReplicatedMergeTree. Auparavant, la requête de mutation/alter pouvait se terminer avant que la mutation soit réellement exécutée sur les autres répliques. [#22669](https://github.com/ClickHouse/ClickHouse/pull/22669) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22739](https://github.com/ClickHouse/ClickHouse/issues/22739) : correction de blocages possibles dans les requêtes zk en cas d’exception OOM. Corrige [#22438](https://github.com/ClickHouse/ClickHouse/issues/22438). [#22684](https://github.com/ClickHouse/ClickHouse/pull/22684) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
