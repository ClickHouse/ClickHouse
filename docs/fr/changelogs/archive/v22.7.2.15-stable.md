<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#39591](https://github.com/ClickHouse/ClickHouse/issues/39591) : correction d’une condition de concurrence et d’un possible dépassement de tampon sur le tas dans le format Avro. Ferme [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094). Ferme [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652). [#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#39613](https://github.com/ClickHouse/ClickHouse/issues/39613) : correction d’un bogue lié à l’argument maxsplit de splitByChar, qui ne fonctionnait pas correctement. [#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#39792](https://github.com/ClickHouse/ClickHouse/issues/39792) : correction d’une analyse d’index erronée avec des tuples et l’opérateur `IN`, qui pouvait entraîner un résultat de requête incorrect. [#39752](https://github.com/ClickHouse/ClickHouse/pull/39752) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#39837](https://github.com/ClickHouse/ClickHouse/issues/39837) : correction de l’exception `CANNOT_READ_ALL_DATA` avec `local_filesystem_read_method=pread_threadpool`. Ce bogue n’affectait que les versions 5.9 et 5.10 du noyau Linux, d’après le [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS). [#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
