<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (dysfonctionnement visible par les utilisateurs dans une version stable officielle)
</div>

* Rétroporté dans [#29121](https://github.com/ClickHouse/ClickHouse/issues/29121) : amélioration de la vérification de l’utilisabilité de la connexion et interception de toute exception lors de l’arrêt de RabbitMQ, par précaution. [#28797](https://github.com/ClickHouse/ClickHouse/pull/28797) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#29027](https://github.com/ClickHouse/ClickHouse/issues/29027) : correction du nombre de threads utilisés dans la sous-requête `GLOBAL IN` (elle s’exécutait sur un seul thread depuis le correctif du bogue [#19414](https://github.com/ClickHouse/ClickHouse/issues/19414)). [#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#29193](https://github.com/ClickHouse/ClickHouse/issues/29193) : correction d’un segfault lors de l’insertion dans une colonne de type LowCardinality(Nullable) avec le format d’entrée Avro. [#29132](https://github.com/ClickHouse/ClickHouse/pull/29132) ([Kruglov Pavel](https://github.com/Avogar)).
