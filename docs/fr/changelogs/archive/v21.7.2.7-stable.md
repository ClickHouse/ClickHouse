<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#25833](https://github.com/ClickHouse/ClickHouse/issues/25833) : `CAST` de `Date` vers `DateTime` (ou `DateTime64`) n’utilisait pas le fuseau horaire du type `DateTime`. Cela pouvait aussi affecter la comparaison entre `Date` et `DateTime`. La déduction du type commun pour `Date` et `DateTime` n’utilisait pas non plus le fuseau horaire correspondant. Cela affectait les résultats de la fonction `if` et la construction de tableaux. Ferme [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128). [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#25766](https://github.com/ClickHouse/ClickHouse/issues/25766) : Correction d’une assertion dans PREWHERE avec un type non uint8, ferme [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589). [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#25954](https://github.com/ClickHouse/ClickHouse/issues/25954) : Correction de `ALTER MODIFY COLUMN` sur des colonnes participant à des expressions TTL. [#25554](https://github.com/ClickHouse/ClickHouse/pull/25554) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#25871](https://github.com/ClickHouse/ClickHouse/issues/25871) : Correction d’un bogue rare avec la requête `DROP PART` pour les tables `ReplicatedMergeTree`, pouvant entraîner le message d’erreur `Unexpected merged part intersecting drop range`. [#25783](https://github.com/ClickHouse/ClickHouse/pull/25783) ([alesapin](https://github.com/alesapin)).
