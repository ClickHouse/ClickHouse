<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#41902](https://github.com/ClickHouse/ClickHouse/issues/41902) : correction d’un possible crash lors d’un `SELECT` sur une table `Merge` avec le paramètre `optimize_monotonous_functions_in_order_by` activé. Corrige [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269). [#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#41863](https://github.com/ClickHouse/ClickHouse/issues/41863) : la version 22.9 pouvait échouer au démarrage avec une table `ReplicatedMergeTree` si cette table avait été créée par la version 20.3 ou une version antérieure et n’avait jamais été modifiée ; ce problème est désormais corrigé. Corrige [#41742](https://github.com/ClickHouse/ClickHouse/issues/41742). [#41796](https://github.com/ClickHouse/ClickHouse/pull/41796) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#41892](https://github.com/ClickHouse/ClickHouse/issues/41892) : correction des compact parts avec le paramètre compressed marks. Corrige [#41783](https://github.com/ClickHouse/ClickHouse/issues/41783) et [#41746](https://github.com/ClickHouse/ClickHouse/issues/41746). [#41823](https://github.com/ClickHouse/ClickHouse/pull/41823) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#41891](https://github.com/ClickHouse/ClickHouse/issues/41891) : les anciennes versions de la base de données Replicated n’ont pas de marqueur spécial dans [Zoo]Keeper. Il faut simplement vérifier si le nœud contient des données quelconques plutôt qu’une marque spéciale. [#41875](https://github.com/ClickHouse/ClickHouse/pull/41875) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
