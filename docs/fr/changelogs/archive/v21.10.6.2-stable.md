<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#32692](https://github.com/ClickHouse/ClickHouse/issues/32692) : la limite de quota n’était pas atteinte, mais elle était pourtant signalée comme dépassée. Cette PR corrige [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#32680](https://github.com/ClickHouse/ClickHouse/issues/32680) : correction de la suppression inattendue de projections lors du détachement de parts. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#32285](https://github.com/ClickHouse/ClickHouse/issues/32285) : correction de Dictionaries dans les cas où `{condition}` ne fonctionne pas pour les requêtes personnalisées sur la base de données. [#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32730](https://github.com/ClickHouse/ClickHouse/issues/32730) : correction de l’analyse de `APPLY lambda`, qui pouvait provoquer un plantage du client ou du serveur. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#32313](https://github.com/ClickHouse/ClickHouse/issues/32313) : les identifiants des dictionnaires XML, utilisés dans la requête CREATE de création de table, peuvent être qualifiés en `default_database` lors d’une mise à niveau vers une version plus récente. Clôt [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963). [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32539](https://github.com/ClickHouse/ClickHouse/issues/32539) : certaines entrées de la file d’attente de réplication peuvent rester bloquées pendant `temporary_directories_lifetime` (1 jour par défaut) avec `Directory tmp_merge_<part_name>` ou `Part ... (state Deleting) already exists, but it will be deleted soon`, ou une erreur similaire. C’est corrigé. Corrige [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32709](https://github.com/ClickHouse/ClickHouse/issues/32709) : correction des échecs dans les requêtes qui tentent d’utiliser des skipping indices, qui ne sont pas encore matérialisés. Corrige [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) et [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343). [#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#32567](https://github.com/ClickHouse/ClickHouse/issues/32567) : correction d’un plantage dans `JoinCommon::removeColumnNullability`, clôt [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458). [#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#32794](https://github.com/ClickHouse/ClickHouse/issues/32794) : correction d’un plantage lors de l’utilisation de fuzzBits plusieurs fois avec la même valeur FixedString, clôt [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737). [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
* Rétroporté dans [#33182](https://github.com/ClickHouse/ClickHouse/issues/33182) : le serveur pouvait ne pas démarrer si une base de données avec le engine `MySQL` ne parvenait pas à se connecter au serveur MySQL ; c’est corrigé. Corrige [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441). [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#33655](https://github.com/ClickHouse/ClickHouse/issues/33655) : correction de la vérification de l’URL HDFS, qui n’autorisait pas l’utilisation de l’adresse HA du namenode. Le bogue a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042). [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).

#### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle) :

Corrige [#31114](https://github.com/ClickHouse/ClickHouse/issues/31114). [#31888](https://github.com/ClickHouse/ClickHouse/pull/31888) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
