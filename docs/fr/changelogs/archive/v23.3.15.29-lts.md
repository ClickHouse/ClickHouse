<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#55671](https://github.com/ClickHouse/ClickHouse/issues/55671) : si la base de données est déjà initialisée, il n’est pas nécessaire de la réinitialiser lors des lancements suivants. Cela peut potentiellement corriger le problème des redémarrages infinis du conteneur lorsque la base de données ne parvient pas à se charger en 1000 tentatives (cas pertinent pour les très grandes bases de données et les configurations multi-nœuds). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* Rétroporté dans [#55734](https://github.com/ClickHouse/ClickHouse/issues/55734) : correction du script Python de vérification d’intégration pour utiliser l’URL de l’API gh - ajout d’un README pour les tests d’intégration continue. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
* Rétroporté dans [#55829](https://github.com/ClickHouse/ClickHouse/issues/55829) : vérification du `sha512` pour `tgz` ; utilisation d’un dépôt approprié pour Keeper ; écriture des seuls noms de fichiers dans les fichiers `TGZ.sha512` pour les paquets tarball. Prérequis pour [#31473](https://github.com/ClickHouse/ClickHouse/issues/31473). [#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
