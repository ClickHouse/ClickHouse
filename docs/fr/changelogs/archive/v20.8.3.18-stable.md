<div id="bug-fix">
  #### Correction de bogues
</div>

* rétroporté dans [#14600](https://github.com/ClickHouse/ClickHouse/issues/14600) : correction de rares segfaults dans les fonctions avec le combinateur -Resample, qui pouvaient apparaître à la suite d’un dépassement de capacité avec de très grands paramètres. [#14562](https://github.com/ClickHouse/ClickHouse/pull/14562) ([Anton Popov](https://github.com/CurtizJ)).
* rétroporté dans [#14727](https://github.com/ClickHouse/ClickHouse/issues/14727) : nettoyage du répertoire de données après des exceptions ZooKeeper pendant CreateQuery pour le moteur StorageReplicatedMergeTree. [#14563](https://github.com/ClickHouse/ClickHouse/pull/14563) ([Bharat Nallan](https://github.com/bharatnc)).
* rétroporté dans [#14653](https://github.com/ClickHouse/ClickHouse/issues/14653) : ajout d’une vérification, car ni l’appel à `lc->isNullable()` ni l’appel à `ls->getDictionaryPtr()->isNullable()` ne renvoyaient le bon résultat. [#14591](https://github.com/ClickHouse/ClickHouse/pull/14591) ([Mike Kot](https://github.com/myrrc)).
* rétroporté dans [#14666](https://github.com/ClickHouse/ClickHouse/issues/14666) : correction d’un résultat erroné de multiplication Decimal causé par une échelle décimale incorrecte dans la colonne de résultat. [#14603](https://github.com/ClickHouse/ClickHouse/pull/14603) ([Artem Zuikov](https://github.com/4ertus2)).
* rétroporté dans [#14793](https://github.com/ClickHouse/ClickHouse/issues/14793) : correction d’un bogue où une mutation `ALTER UPDATE` avec une colonne Nullable dans une expression d’attribution et une valeur constante (comme `UPDATE x = 42`) entraîne une valeur incorrecte dans la colonne ou un segfault. Corrige [#13634](https://github.com/ClickHouse/ClickHouse/issues/13634), [#14045](https://github.com/ClickHouse/ClickHouse/issues/14045). [#14646](https://github.com/ClickHouse/ClickHouse/pull/14646) ([alesapin](https://github.com/alesapin)).
* rétroporté dans [#14722](https://github.com/ClickHouse/ClickHouse/issues/14722) : correction du nom de la base de données par défaut manquant dans les métadonnées d’une vue matérialisée lors de l’exécution de `ALTER ... MODIFY QUERY`. [#14664](https://github.com/ClickHouse/ClickHouse/pull/14664) ([Alexander Tokmakov](https://github.com/tavplubix)).
* rétroporté dans [#14910](https://github.com/ClickHouse/ClickHouse/issues/14910) : correction d’un SIGSEGV lors d’une tentative d’INSERT dans StorageFile(fd). [#14887](https://github.com/ClickHouse/ClickHouse/pull/14887) ([Azat Khuzhin](https://github.com/azat)).
* rétroporté dans [#14943](https://github.com/ClickHouse/ClickHouse/issues/14943) : correction du problème où certains appels de la fonction `extractAllGroups` peuvent déclencher l’erreur &quot;Memory limit exceeded&quot;. Cela corrige [#13383](https://github.com/ClickHouse/ClickHouse/issues/13383). [#14889](https://github.com/ClickHouse/ClickHouse/pull/14889) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
