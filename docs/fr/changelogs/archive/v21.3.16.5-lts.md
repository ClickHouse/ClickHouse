  # Historique des modifications 2022

<div id="clickhouse-release-v213165-lts-fixme-as-compared-to-v213154-stable">
  ### Version de ClickHouse v21.3.16.5-lts FIXME par rapport à v21.3.15.4-stable
</div>

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#26940](https://github.com/ClickHouse/ClickHouse/issues/26940) : Ne pas supprimer les données lors de l’arrêt d’une table ReplicatedMergeTree afin d’éviter toute incohérence entre les données et les métadonnées. [#26716](https://github.com/ClickHouse/ClickHouse/pull/26716) ([nvartolomei](https://github.com/nvartolomei)).
* Rétroporté dans [#26983](https://github.com/ClickHouse/ClickHouse/issues/26983) : Les paramètres des fonctions d’agrégation pouvaient être perdus lors de l’application de certains combinators, provoquant des exceptions telles que `Conversion from AggregateFunction(topKArray, Array(String)) to AggregateFunction(topKArray(10), Array(String)) is not supported`. C’est corrigé. Corrige [#26196](https://github.com/ClickHouse/ClickHouse/issues/26196) et [#26433](https://github.com/ClickHouse/ClickHouse/issues/26433). [#26814](https://github.com/ClickHouse/ClickHouse/pull/26814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#26998](https://github.com/ClickHouse/ClickHouse/issues/26998) : Correction de la lecture des TLD personnalisés (le traitement s’arrêtait avec un buffer plus petit ou un fichier plus volumineux). [#26948](https://github.com/ClickHouse/ClickHouse/pull/26948) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#27088](https://github.com/ClickHouse/ClickHouse/issues/27088) : Désormais, l’identifiant de partition dans des requêtes comme `ALTER TABLE ... PARTITION ID xxx` est vérifié. Corrige [#25718](https://github.com/ClickHouse/ClickHouse/issues/25718). [#26963](https://github.com/ClickHouse/ClickHouse/pull/26963) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#27049](https://github.com/ClickHouse/ClickHouse/issues/27049) : [RFC] Correction d’un possible blocage des mutations dû à une condition de concurrence avec DROP&#95;RANGE. [#27002](https://github.com/ClickHouse/ClickHouse/pull/27002) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#27158](https://github.com/ClickHouse/ClickHouse/issues/27158) : Correction de la synchronisation dans GRPCServer. Cette PR corrige [#27024](https://github.com/ClickHouse/ClickHouse/issues/27024). [#27064](https://github.com/ClickHouse/ClickHouse/pull/27064) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#27368](https://github.com/ClickHouse/ClickHouse/issues/27368) : - Correction d’un problème de mémoire non initialisée dans les fonctions `multiSearch*` avec un tableau vide, clôt [#27169](https://github.com/ClickHouse/ClickHouse/issues/27169). [#27181](https://github.com/ClickHouse/ClickHouse/pull/27181) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#27264](https://github.com/ClickHouse/ClickHouse/issues/27264) : Dans de rares cas, la table `system.detached_parts` pouvait contenir des informations incorrectes pour certaines parts. C’est corrigé. Corrige [#27114](https://github.com/ClickHouse/ClickHouse/issues/27114). [#27183](https://github.com/ClickHouse/ClickHouse/pull/27183) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#27413](https://github.com/ClickHouse/ClickHouse/issues/27413) : Correction d’une validation incorrecte de l’identifiant de partition pour les tables MergeTree créées avec l’ancienne syntaxe. [#27328](https://github.com/ClickHouse/ClickHouse/pull/27328) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#27645](https://github.com/ClickHouse/ClickHouse/issues/27645) : Correction d’un résultat incorrect pour une query avec sécurité row-level, PREWHERE et filtre LowCardinality. Corrige [#27179](https://github.com/ClickHouse/ClickHouse/issues/27179). [#27329](https://github.com/ClickHouse/ClickHouse/pull/27329) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#27473](https://github.com/ClickHouse/ClickHouse/issues/27473) : correction de la métrique BackgroundMessageBrokerSchedulePoolTask, probablement mal orthographiée。. [#27452](https://github.com/ClickHouse/ClickHouse/pull/27452) ([Ben](https://github.com/benbiti)).
* Rétroporté dans [#27864](https://github.com/ClickHouse/ClickHouse/issues/27864) : évite des plantages avec certains formats lorsqu’un message NULL (tombstone) était reçu depuis Kafka. Clôt [#19255](https://github.com/ClickHouse/ClickHouse/issues/19255). [#27794](https://github.com/ClickHouse/ClickHouse/pull/27794) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#28207](https://github.com/ClickHouse/ClickHouse/issues/28207) : corrige les cas où le tampon de lecture échoue avec l’erreur &#39;attempt to read after end of file&#39;. Clôt [#26149](https://github.com/ClickHouse/ClickHouse/issues/26149). [#28150](https://github.com/ClickHouse/ClickHouse/pull/28150) ([Filatenkov Artur](https://github.com/FArthur-cmd)).
