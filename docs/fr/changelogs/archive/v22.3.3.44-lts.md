<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#35928](https://github.com/ClickHouse/ClickHouse/issues/35928) : ajout des paramètres `input_format_ipv4_default_on_conversion_error`, `input_format_ipv6_default_on_conversion_error` pour permettre d’insérer dans des tables des valeurs d’adresse IP invalides en tant que valeurs par défaut. Résout [#35726](https://github.com/ClickHouse/ClickHouse/issues/35726). [#35733](https://github.com/ClickHouse/ClickHouse/pull/35733) ([Maksim Kita](https://github.com/kitaisreal)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#35415](https://github.com/ClickHouse/ClickHouse/issues/35415) : corrige un interblocage possible dans le cache. [#35378](https://github.com/ClickHouse/ClickHouse/pull/35378) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#35563](https://github.com/ClickHouse/ClickHouse/issues/35563) : corrige le cast vers des adresses IPv4 et IPv6 dans la clause IN. Corrige [#35528](https://github.com/ClickHouse/ClickHouse/issues/35528). [#35534](https://github.com/ClickHouse/ClickHouse/pull/35534) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#35783](https://github.com/ClickHouse/ClickHouse/issues/35783) : corrige un bogue dans la conversion de types personnalisés en chaîne, qui pouvait entraîner un segfault ou des messages d’erreur inattendus. Clôt [#35752](https://github.com/ClickHouse/ClickHouse/issues/35752). [#35755](https://github.com/ClickHouse/ClickHouse/pull/35755) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#35881](https://github.com/ClickHouse/ClickHouse/issues/35881) : corrige l’analyse des arguments de la fonction `extract`. Corrige [#35751](https://github.com/ClickHouse/ClickHouse/issues/35751). [#35799](https://github.com/ClickHouse/ClickHouse/pull/35799) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#35856](https://github.com/ClickHouse/ClickHouse/issues/35856) : ne tient compte que de quota et period dans les groupes, et ignore shares (qui ne limitent pas réellement le nombre de cœurs pouvant être utilisés). [#35815](https://github.com/ClickHouse/ClickHouse/pull/35815) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#35938](https://github.com/ClickHouse/ClickHouse/issues/35938) : évite de traiter plusieurs fois le TTL par colonne. [#35820](https://github.com/ClickHouse/ClickHouse/pull/35820) ([Azat Khuzhin](https://github.com/azat)).
