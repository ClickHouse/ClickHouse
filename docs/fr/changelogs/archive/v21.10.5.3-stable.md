<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#32252](https://github.com/ClickHouse/ClickHouse/issues/32252) : correction de l’omission de colonnes lors de l’écriture en Protobuf. Cette PR corrige [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160), voir le commentaire [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318. [#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#32346](https://github.com/ClickHouse/ClickHouse/issues/32346) : correction d’un bug lors de la suppression des colonnes inutiles dans une sous-requête. S’il y a une fonction d’agrégation dans une requête sans GROUP BY, ne pas la supprimer même si elle n’est pas nécessaire. [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bug (dysfonctionnement visible par l&#39;utilisateur dans la version stable officielle)
</div>

* Rétroporté dans [#32151](https://github.com/ClickHouse/ClickHouse/issues/32151) : correction d&#39;un crash lorsque la fonction `dictGet` avec un type est utilisée pour un attribut de dictionnaire et que le type est `Nullable`. Corrige [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980). [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32093](https://github.com/ClickHouse/ClickHouse/issues/32093) : certaines entrées `GET_PART` peuvent rester bloquées dans la file de réplication si une part est perdue sur toutes les répliques et qu&#39;il n&#39;y a pas d&#39;autres parts dans la même partition. Le problème est corrigé lorsque la clé de partitionnement ne contient que des colonnes de types entiers ou `Date[Time]`. Corrige [#31485](https://github.com/ClickHouse/ClickHouse/issues/31485). [#31887](https://github.com/ClickHouse/ClickHouse/pull/31887) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32147](https://github.com/ClickHouse/ClickHouse/issues/32147) : correction de l&#39;erreur `Directory ... already exists and is not empty` lors du détachement d&#39;une part. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32216](https://github.com/ClickHouse/ClickHouse/issues/32216) : le nombre de répliques actives pouvait être déterminé incorrectement lors d&#39;une insertion avec quorum si le paramètre `replicated_can_become_leader` est désactivé sur certaines répliques. Le problème est corrigé. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32352](https://github.com/ClickHouse/ClickHouse/issues/32352) : correction d&#39;un crash avec SIGFPE dans la fonction d&#39;agrégation `avgWeighted` avec un argument `Decimal`. Corrige [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32393](https://github.com/ClickHouse/ClickHouse/issues/32393) : correction des requêtes `ALTER ... MATERIALIZE COLUMN ...` lorsque le type de données de l&#39;expression par défaut n&#39;est pas égal au type de données de la colonne. [#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
