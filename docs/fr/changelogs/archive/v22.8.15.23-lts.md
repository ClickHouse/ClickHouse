<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#46981](https://github.com/ClickHouse/ClickHouse/issues/46981) : appliquer `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` à toutes les répliques, car `ALTER TABLE t MOVE` n’est pas répliqué. [#46402](https://github.com/ClickHouse/ClickHouse/pull/46402) ([lizhuoyu5](https://github.com/lzydmxy)).

<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#47336](https://github.com/ClickHouse/ClickHouse/issues/47336) : il arrivait parfois qu’après la modification d’un rôle, ce changement ne soit pas répercuté sur les droits d’accès d’un utilisateur utilisant ce rôle. Cette PR corrige ce problème. [#46772](https://github.com/ClickHouse/ClickHouse/pull/46772) ([Vitaly Baranov](https://github.com/vitlibar)).
