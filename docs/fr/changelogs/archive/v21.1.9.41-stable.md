  # Historique des modifications 2022

<div id="clickhouse-release-v211941-stable-fixme-as-compared-to-v211830-stable">
  ### Version ClickHouse v21.1.9.41-stable FIXME par rapport à v21.1.8.30-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#22817](https://github.com/ClickHouse/ClickHouse/issues/22817) : faire en sorte que FQDN et d&#39;autres fonctions liées au DNS fonctionnent correctement dans les images Alpine. [#20336](https://github.com/ClickHouse/ClickHouse/pull/20336) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22810](https://github.com/ClickHouse/ClickHouse/issues/22810) : si PODArray était instancié avec une taille d&#39;élément qui n&#39;était ni un diviseur ni un multiple de 16, un dépassement de tampon était possible. Aucun bogue n&#39;affecte les versions actuelles. [#21533](https://github.com/ClickHouse/ClickHouse/pull/21533) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#22967](https://github.com/ClickHouse/ClickHouse/issues/22967) : correction d’un bogue très rare où une insertion avec quorum avec `quorum_parallel=1` n’est en réalité pas un véritable « quorum » en raison de la déduplication. [#18215](https://github.com/ClickHouse/ClickHouse/pull/18215) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22088](https://github.com/ClickHouse/ClickHouse/issues/22088) : lorsqu’une requête a une condition `WHERE` constante et que le paramètre `optimize_skip_unused_shards` est activé, tous les shards peuvent être ignorés et la requête peut renvoyer à tort un résultat vide. [#21550](https://github.com/ClickHouse/ClickHouse/pull/21550) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#21857](https://github.com/ClickHouse/ClickHouse/issues/21857) : correction d’une erreur possible ` Cannot find column` lorsque `optimize_skip_unused_shards` est activé et qu’aucun shard n’est utilisé. [#21579](https://github.com/ClickHouse/ClickHouse/pull/21579) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22758](https://github.com/ClickHouse/ClickHouse/issues/22758) : correction de l’utilisation de la fonction `map` dans les requêtes distribuées. [#22588](https://github.com/ClickHouse/ClickHouse/pull/22588) ([foolchi](https://github.com/foolchi)).
* Rétroporté dans [#22890](https://github.com/ClickHouse/ClickHouse/issues/22890) : correction de l’estimation approximative du nombre total de lignes lors d’une lecture inversée depuis MergeTree. [#22726](https://github.com/ClickHouse/ClickHouse/pull/22726) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22919](https://github.com/ClickHouse/ClickHouse/issues/22919) : correction d’un crash lors de l’utilisation de `mannWhitneyUTest` et `rankCorr` avec des fonctions de fenêtre. Cela corrige [#22728](https://github.com/ClickHouse/ClickHouse/issues/22728). [#22876](https://github.com/ClickHouse/ClickHouse/pull/22876) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#22813](https://github.com/ClickHouse/ClickHouse/issues/22813) : permet de démarrer avec un binaire modifié sous gdb. Dans la version précédente, si vous définissiez un point d’arrêt dans gdb avant le démarrage, le server refusait de démarrer en raison d’un échec de la vérification d’intégrité. [#21258](https://github.com/ClickHouse/ClickHouse/pull/21258) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
