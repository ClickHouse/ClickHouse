Corrige [#25813](https://github.com/ClickHouse/ClickHouse/issues/25813). [#26079](https://github.com/ClickHouse/ClickHouse/pull/26079) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#26167](https://github.com/ClickHouse/ClickHouse/issues/26167) : correction de `joinGet` avec des colonnes `LowCardinality`, clôture de [#25993](https://github.com/ClickHouse/ClickHouse/issues/25993). * Rétroporté dans [#26205](https://github.com/ClickHouse/ClickHouse/issues/26205) : correction d’un plantage potentiel si plusieurs expressions `untuple` sont utilisées. [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#26227](https://github.com/ClickHouse/ClickHouse/issues/26227) : suppression d’un saut de ligne superflu dans la colonne `thread_name` de la table `system.stack_trace`. Corrige [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124). [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
