<div id="clickhouse-release-v213184-lts-fixme-as-compared-to-v213172-lts">
  ### Version de ClickHouse v21.3.18.4-lts FIXME par rapport à v21.3.17.2-lts

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#30355](https://github.com/ClickHouse/ClickHouse/issues/30355) : utilisation d’un groupe et d’un utilisateur `clickhouse-bridge` distincts pour les processus `bridge`. Définition de `oom_score_adj` afin que les bridges soient les premières cibles de l’OOM killer. Définition du RSS maximal à 1 GiB. Corrige [#23861](https://github.com/ClickHouse/ClickHouse/issues/23861). [#25280](https://github.com/ClickHouse/ClickHouse/pull/25280) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#29945](https://github.com/ClickHouse/ClickHouse/issues/29945) : mise à jour des fichiers zoneinfo vers 2021c. [#29925](https://github.com/ClickHouse/ClickHouse/pull/29925) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Correction de bug
</div>

* Rétroporté dans [#30041](https://github.com/ClickHouse/ClickHouse/issues/30041) : correction de l&#39;arrêt de `AccessControlManager`. Il n&#39;est désormais plus possible de recharger la configuration après la destruction d&#39;AccessControlManager. Cette PR corrige le test instable [test&#95;user&#95;directories/test.py::test&#95;relative&#95;path](https://clickhouse-test-reports.s3.yandex.net/0/f0e3122507ed8bea3f177495531c7d56bcb32466/integration_tests_\(thread\).html). [#29951](https://github.com/ClickHouse/ClickHouse/pull/29951) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Corrections de bugs (dysfonctionnements visibles par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#29260](https://github.com/ClickHouse/ClickHouse/issues/29260) : correction d’une conversion invalide de type constant lorsqu’une clé primaire Nullable ou LowCardinality est utilisée. [#28636](https://github.com/ClickHouse/ClickHouse/pull/28636) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#29026](https://github.com/ClickHouse/ClickHouse/issues/29026) : correction du nombre de threads utilisés dans la sous-requête `GLOBAL IN` (elle était exécutée sur un seul thread depuis le correctif de [#19414](https://github.com/ClickHouse/ClickHouse/issues/19414)). [#28997](https://github.com/ClickHouse/ClickHouse/pull/28997) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#29194](https://github.com/ClickHouse/ClickHouse/issues/29194) : correction d’un segfault lors de l’insertion dans une colonne de type LowCardinality(Nullable) au format d’entrée Avro. [#29132](https://github.com/ClickHouse/ClickHouse/pull/29132) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#29360](https://github.com/ClickHouse/ClickHouse/issues/29360) : correction d’une exception possible `Table columns structure in ZooKeeper is different from local table structure` lors de la recréation ou de la création de nouvelles répliques de `ReplicatedMergeTree`, lorsque l’une des colonnes de la table contient des expressions par défaut avec des fonctions insensibles à la casse. [#29266](https://github.com/ClickHouse/ClickHouse/pull/29266) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#29300](https://github.com/ClickHouse/ClickHouse/issues/29300) : correction des délais d’expiration de connexion (`send_timeout`/`receive_timeout`). [#29282](https://github.com/ClickHouse/ClickHouse/pull/29282) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#30042](https://github.com/ClickHouse/ClickHouse/issues/30042) : une condition dans le prédicat de filtrage pouvait être perdue après l’optimisation de push-down. [#29625](https://github.com/ClickHouse/ClickHouse/pull/29625) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#29848](https://github.com/ClickHouse/ClickHouse/issues/29848) : correction d’un accès concurrent à `LowCardinality` pendant `GROUP BY` (ce qui entraînait un SIGSEGV). [#29782](https://github.com/ClickHouse/ClickHouse/pull/29782) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#30066](https://github.com/ClickHouse/ClickHouse/issues/30066) : correction d’un plantage de `sample` provoqué par `tuple()`, clôt [#30004](https://github.com/ClickHouse/ClickHouse/issues/30004). [#30016](https://github.com/ClickHouse/ClickHouse/pull/30016) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#30332](https://github.com/ClickHouse/ClickHouse/issues/30332) : * autoriser les identifiants commençant par des chiffres dans plusieurs jointures. [#30230](https://github.com/ClickHouse/ClickHouse/pull/30230) ([Vladimir C](https://github.com/vdimir)).
