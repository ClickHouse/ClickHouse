<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#26524](https://github.com/ClickHouse/ClickHouse/issues/26524) : réduit la latence des requêtes courtes nécessitant la lecture de tables comportant un grand nombre de colonnes. [#26371](https://github.com/ClickHouse/ClickHouse/pull/26371) ([Anton Popov](https://github.com/CurtizJ)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#26283](https://github.com/ClickHouse/ClickHouse/issues/26283) : correction de `optimize_skip_unused_shards_rewrite_in` pour les types autres que UInt64 (peut à terme sélectionner des shards incorrects ou lever `Cannot infer type of an empty tuple` ou `Function tuple requires at least one argument`). [#25798](https://github.com/ClickHouse/ClickHouse/pull/25798) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#26587](https://github.com/ClickHouse/ClickHouse/issues/26587) : correction des erreurs `Not found column ...` et `Missing column ...` lors de la sélection à partir de `MaterializeMySQL`. Corrige [#23708](https://github.com/ClickHouse/ClickHouse/issues/23708), [#24830](https://github.com/ClickHouse/ClickHouse/issues/24830), [#25794](https://github.com/ClickHouse/ClickHouse/issues/25794). [#25822](https://github.com/ClickHouse/ClickHouse/pull/25822) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#26190](https://github.com/ClickHouse/ClickHouse/issues/26190) : correction de sharding&#95;key à partir d&#39;une colonne sans fonction pour remote() (auparavant, `select * from remote('127.1', system.one, dummy)` entraînait l&#39;erreur `Unknown column: dummy, there are only columns .`). [#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#26284](https://github.com/ClickHouse/ClickHouse/issues/26284) : correction d&#39;un en-tête potentiellement incohérent lors de l&#39;utilisation d&#39;une projection ordinaire avec prewhere. Corrige [#26020](https://github.com/ClickHouse/ClickHouse/issues/26020). [#26038](https://github.com/ClickHouse/ClickHouse/pull/26038) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#26298](https://github.com/ClickHouse/ClickHouse/issues/26298) : correction de `sequence_id` incorrects dans les paquets du protocole MySQL que ClickHouse envoie en cas d&#39;exception pendant l&#39;exécution d&#39;une requête. Cela peut amener le client MySQL à réinitialiser la connexion au serveur ClickHouse. Corrige [#21184](https://github.com/ClickHouse/ClickHouse/issues/21184). [#26051](https://github.com/ClickHouse/ClickHouse/pull/26051) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#26204](https://github.com/ClickHouse/ClickHouse/issues/26204) : correction d&#39;un crash potentiel si plusieurs expressions `untuple` sont utilisées. [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#26228](https://github.com/ClickHouse/ClickHouse/issues/26228) : suppression d&#39;un retour à la ligne superflu dans la colonne `thread_name` de la table `system.stack_trace`. Corrige [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124). [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#26358](https://github.com/ClickHouse/ClickHouse/issues/26358) : correction d&#39;une erreur logique sur un join avec totaux, clôture de [#26017](https://github.com/ClickHouse/ClickHouse/issues/26017). [#26250](https://github.com/ClickHouse/ClickHouse/pull/26250) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#26788](https://github.com/ClickHouse/ClickHouse/issues/26788) : correction de la décompression zstd lorsqu&#39;il y a des séquences d&#39;échappement à la fin du buffer interne. Clôt [#26013](https://github.com/ClickHouse/ClickHouse/issues/26013). [#26314](https://github.com/ClickHouse/ClickHouse/pull/26314) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#26360](https://github.com/ClickHouse/ClickHouse/issues/26360) : correction d&#39;un bogue rare dans la récupération d&#39;une réplique perdue pouvant entraîner une divergence entre les répliques. [#26321](https://github.com/ClickHouse/ClickHouse/pull/26321) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#26452](https://github.com/ClickHouse/ClickHouse/issues/26452) : correction de `optimize_distributed_group_by_sharding_key` pour plusieurs colonnes (produisait un résultat incorrect avec `optimize_skip_unused_shards=1`/`allow_nondeterministic_optimize_skip_unused_shards=1` et plusieurs colonnes dans l’expression de clé de sharding). [#26353](https://github.com/ClickHouse/ClickHouse/pull/26353) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#26422](https://github.com/ClickHouse/ClickHouse/issues/26422) : correction d’un crash possible lors de la connexion avec un utilisateur supprimé. Cette PR corrige [#26073](https://github.com/ClickHouse/ClickHouse/issues/26073). [#26363](https://github.com/ClickHouse/ClickHouse/pull/26363) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#26417](https://github.com/ClickHouse/ClickHouse/issues/26417) : correction d’un flux infini de blocs non joints dans `partial_merge_join`, clôt [#26325](https://github.com/ClickHouse/ClickHouse/issues/26325). [#26374](https://github.com/ClickHouse/ClickHouse/pull/26374) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#26448](https://github.com/ClickHouse/ClickHouse/issues/26448) : correction de certains crashs msan détectés par fuzzing. Corrige [#22517](https://github.com/ClickHouse/ClickHouse/issues/22517). [#26428](https://github.com/ClickHouse/ClickHouse/pull/26428) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#26488](https://github.com/ClickHouse/ClickHouse/issues/26488) : correction d’un problème de résolution de noms après la réécriture des alias de colonnes. Cela corrige [#26432](https://github.com/ClickHouse/ClickHouse/issues/26432). [#26475](https://github.com/ClickHouse/ClickHouse/pull/26475) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#26613](https://github.com/ClickHouse/ClickHouse/issues/26613) : correction de problèmes avec la requête `CREATE DICTIONARY` si le nom du dictionnaire ou celui de la base de données était entre guillemets. Clôt [#26491](https://github.com/ClickHouse/ClickHouse/issues/26491). [#26508](https://github.com/ClickHouse/ClickHouse/pull/26508) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#26605](https://github.com/ClickHouse/ClickHouse/issues/26605) : correction d’un crash lors de l’arrêt de RabbitMQ lorsque sa configuration n’avait pas été démarrée. Clôt [#26504](https://github.com/ClickHouse/ClickHouse/issues/26504). [#26529](https://github.com/ClickHouse/ClickHouse/pull/26529) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#26608](https://github.com/ClickHouse/ClickHouse/issues/26608) : mise à jour de la vérification de la commande `chown` dans le point d’entrée Docker de clickhouse-server. Cela corrige le bogue qui faisait échouer (ou expirer) le redémarrage du pod du cluster sur Kubernetes. [#26545](https://github.com/ClickHouse/ClickHouse/pull/26545) ([Ky Li](https://github.com/Kylinrix)).
* Rétroporté dans [#26648](https://github.com/ClickHouse/ClickHouse/issues/26648) : correction de noms de fonctions incorrects pour groupBitmapAnd/Or/Xor. [#26557](https://github.com/ClickHouse/ClickHouse/pull/26557) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#26644](https://github.com/ClickHouse/ClickHouse/issues/26644) : correction de la conversion du fichier d’historique lorsque le fichier est vide. [#26589](https://github.com/ClickHouse/ClickHouse/pull/26589) ([Azat Khuzhin](https://github.com/azat)).
