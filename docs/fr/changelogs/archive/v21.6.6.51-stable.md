<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#25850](https://github.com/ClickHouse/ClickHouse/issues/25850) : `CAST` de `Date` vers `DateTime` (ou `DateTime64`) n’utilisait pas le fuseau horaire du type `DateTime`. Cela peut également affecter la comparaison entre `Date` et `DateTime`. L’inférence du type commun pour `Date` et `DateTime` n’utilisait pas non plus le fuseau horaire correspondant. Cela affectait les résultats de la fonction `if` et la construction de tableaux. Clôt [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128). [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#25677](https://github.com/ClickHouse/ClickHouse/issues/25677) : Correction d’un bogue dans la désérialisation de l’état du générateur aléatoire, qui pouvait entraîner un comportement non déterministe de certains types de données tels que `AggregateFunction(groupArraySample(N), T))`. [#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25535](https://github.com/ClickHouse/ClickHouse/issues/25535) : Correction de l’erreur possible &#39;Cannot read from istream at offset 0&#39; lors de la lecture d’un fichier depuis DiskS3. [#24885](https://github.com/ClickHouse/ClickHouse/pull/24885) ([Pavel Kovalenko](https://github.com/Jokser)).
* Rétroporté dans [#25557](https://github.com/ClickHouse/ClickHouse/issues/25557) : Correction d’un plantage potentiel lors du calcul des états de fonctions d’agrégation par agrégation des états de fonctions d’agrégation d’autres fonctions d’agrégation (pas un cas d’usage pratique). Voir [#24523](https://github.com/ClickHouse/ClickHouse/issues/24523). [#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#25506](https://github.com/ClickHouse/ClickHouse/issues/25506) : Correction d’un segfault lorsque sharding&#95;key est absent de la configuration de tâche de copier. [#25419](https://github.com/ClickHouse/ClickHouse/pull/25419) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#25765](https://github.com/ClickHouse/ClickHouse/issues/25765) : Correction d’une assertion dans PREWHERE avec un type non uint8, clôt [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589). [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#25635](https://github.com/ClickHouse/ClickHouse/issues/25635) : Correction de totaux incorrects pour la requête `WITH TOTALS` et `WITH FILL`. Corrige [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872). [#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#25652](https://github.com/ClickHouse/ClickHouse/issues/25652) : Correction d’un déréférencement de pointeur nul dans `EXPLAIN AST` en l’absence de requête. [#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25717](https://github.com/ClickHouse/ClickHouse/issues/25717) : `REPLACE PARTITION` pouvait être ignoré dans de rares cas si la partition source était vide. Le problème a été corrigé. Corrige [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869). [#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25696](https://github.com/ClickHouse/ClickHouse/issues/25696) : Correction de l’erreur `No such file or directory` lors du déplacement d’une table `Distributed` entre bases de données. Corrige [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971). [#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25755](https://github.com/ClickHouse/ClickHouse/issues/25755) : correction d’une situation de concurrence lors de l’exécution d’une requête sur `system.clusters` pendant le rechargement simultané de la configuration du cluster. [#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)).
