  ### Version de ClickHouse v25.1.6.34-stable (004003dccf8) FIXME par rapport à v25.1.5.31-stable (48f17e8a805)

<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#76700](https://github.com/ClickHouse/ClickHouse/issues/76700) : correction d’une double préallocation dans `ConcurrentHashJoin` lorsque l’optimiseur permute les côtés du join. [#75149](https://github.com/ClickHouse/ClickHouse/pull/75149) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#76696](https://github.com/ClickHouse/ClickHouse/issues/76696) : correction d’une contention inutile dans `parallel_hash` lorsque `max_rows_in_join = max_bytes_in_join = 0`. [#75155](https://github.com/ClickHouse/ClickHouse/pull/75155) ([Nikita Taranov](https://github.com/nickitat)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#76437](https://github.com/ClickHouse/ClickHouse/issues/76437) : permettre d’analyser des endpoints tels que `localhost:1234/handle` dans les fonctions de table `postgresql` ou `mysql`. Cela corrige une régression introduite dans [https://github.com/ClickHouse/ClickHouse/pull/52503](https://github.com/ClickHouse/ClickHouse/pull/52503). [#75944](https://github.com/ClickHouse/ClickHouse/pull/75944) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#76609](https://github.com/ClickHouse/ClickHouse/issues/76609) : utiliser le fallback approprié lorsqu’une copie en plusieurs parties vers S3 échoue pendant une sauvegarde avec l’erreur Access Denied. Une copie en plusieurs parties peut générer l’erreur Access Denied lorsque la sauvegarde est effectuée entre des buckets ayant des credentials différents. [#76515](https://github.com/ClickHouse/ClickHouse/pull/76515) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#76142](https://github.com/ClickHouse/ClickHouse/issues/76142) : corrige un problème où certaines adresses IPv6 (comme ::ffff:1.1.1.1) dans le champ forwarded&#95;for sont mal interprétées, ce qui entraîne la déconnexion du client avec une exception. [#75133](https://github.com/ClickHouse/ClickHouse/pull/75133) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#76395](https://github.com/ClickHouse/ClickHouse/issues/76395) : vérifie que `key_condition` n’est pas spécifié lors du comptage de `total_number_of_rows` pour `NumRowsCache`. [#75164](https://github.com/ClickHouse/ClickHouse/pull/75164) ([Daniil Ivanik](https://github.com/divanik)).
* Rétroporté dans [#76529](https://github.com/ClickHouse/ClickHouse/issues/76529) : respecte `materialized_views_ignore_errors` lorsqu’une vue matérialisée écrit dans un URL engine et qu’un problème de connectivité survient. [#75679](https://github.com/ClickHouse/ClickHouse/pull/75679) ([Christoph Wurm](https://github.com/cwurm)).
* Rétroporté dans [#76540](https://github.com/ClickHouse/ClickHouse/issues/76540) : corrige l’erreur `Block structure mismatch in QueryPipeline stream` pour certaines requêtes avec `UNION ALL`. [#75715](https://github.com/ClickHouse/ClickHouse/pull/75715) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#76475](https://github.com/ClickHouse/ClickHouse/issues/76475) : corrige une vérification incorrecte des permissions où `ALTER RENAME` nécessitait le privilège `CREATE USER`. Ferme [#74372](https://github.com/ClickHouse/ClickHouse/issues/74372). [#76241](https://github.com/ClickHouse/ClickHouse/pull/76241) ([pufit](https://github.com/pufit)).
* Rétroporté dans [#76403](https://github.com/ClickHouse/ClickHouse/issues/76403) : corrige une erreur logique dans l’analyse d’index si la condition dans `WHERE` contient la fonction `pointInPolygon`. [#76360](https://github.com/ClickHouse/ClickHouse/pull/76360) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#76484](https://github.com/ClickHouse/ClickHouse/issues/76484) : supprime les allocations dans le gestionnaire de signaux. [#76446](https://github.com/ClickHouse/ClickHouse/pull/76446) ([Nikita Taranov](https://github.com/nickitat)).
