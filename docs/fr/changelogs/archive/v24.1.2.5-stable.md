  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)

* Rétroporté dans [#59425](https://github.com/ClickHouse/ClickHouse/issues/59425) : correction de `translate()` avec une entrée `FixedString`. Cela pouvait provoquer des plantages, car la fonction renvoyait une colonne `String` (au lieu de la colonne `FixedString` attendue). Ce problème a été découvert dans le cadre du ClickHouse Bug Bounty Program par YohannJardin. [#59356](https://github.com/ClickHouse/ClickHouse/pull/59356) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#59478](https://github.com/ClickHouse/ClickHouse/issues/59478) : correction des stacktraces pour les binaires sans symboles de débogage. [#59444](https://github.com/ClickHouse/ClickHouse/pull/59444) ([Azat Khuzhin](https://github.com/azat)).
