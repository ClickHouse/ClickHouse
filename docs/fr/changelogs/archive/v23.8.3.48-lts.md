<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (dysfonctionnement perceptible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#54974](https://github.com/ClickHouse/ClickHouse/issues/54974) : correction d’un problème où, lors de l’optimisation PREWHERE, le DAG d’actions des conditions composées pouvait perdre la colonne de sortie d’une étape intermédiaire alors que cette colonne était nécessaire en entrée d’une étape suivante. [#53492](https://github.com/ClickHouse/ClickHouse/pull/53492) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#54996](https://github.com/ClickHouse/ClickHouse/issues/54996) : les répliques parallèles s’exécutaient soit entièrement sur la réplique locale, soit produisaient un résultat incorrect lorsque `prefer_localhost_replica=1`. Corrige [#54276](https://github.com/ClickHouse/ClickHouse/issues/54276). [#54334](https://github.com/ClickHouse/ClickHouse/pull/54334) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#54516](https://github.com/ClickHouse/ClickHouse/issues/54516) : correction d’une erreur possible, &#39;URI contains invalid characters&#39;, dans la fonction de table S3. Clôt [#54345](https://github.com/ClickHouse/ClickHouse/issues/54345). [#54373](https://github.com/ClickHouse/ClickHouse/pull/54373) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#54418](https://github.com/ClickHouse/ClickHouse/issues/54418) : vérification d’un dépassement de capacité lors du traitement de l’argument du numéro de groupe pour `analysisOfVariance`, afin d’éviter des plantages. Plantage détecté avec WINGFUZZ. [#54385](https://github.com/ClickHouse/ClickHouse/pull/54385) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#54527](https://github.com/ClickHouse/ClickHouse/issues/54527) : reproduction du bug décrit ici [#54135](https://github.com/ClickHouse/ClickHouse/issues/54135). [#54430](https://github.com/ClickHouse/ClickHouse/pull/54430) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#54854](https://github.com/ClickHouse/ClickHouse/issues/54854) : correction d’une optimisation incorrecte des projections d’agrégation lors de l’utilisation d’états d’agrégation Variant. Cette optimisation est activée par inadvertance, mais n’est pas correctement implémentée, car après [https://github.com/ClickHouse/ClickHouse/pull/39420](https://github.com/ClickHouse/ClickHouse/pull/39420), la comparaison de DataTypeAggregateFunction est normalisée. Cela corrige [#54406](https://github.com/ClickHouse/ClickHouse/issues/54406). [#54480](https://github.com/ClickHouse/ClickHouse/pull/54480) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#54599](https://github.com/ClickHouse/ClickHouse/issues/54599) : correction d’une erreur d’analyse syntaxique dans les formats WithNames lors de la lecture d’un sous-ensemble de colonnes avec input&#95;format&#95;with&#95;names&#95;use&#95;header désactivé. Clôt [#52591](https://github.com/ClickHouse/ClickHouse/issues/52591). [#54513](https://github.com/ClickHouse/ClickHouse/pull/54513) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#54594](https://github.com/ClickHouse/ClickHouse/issues/54594) : à partir de la version 23.5, la réplication zero-copy pouvait laisser des résidus dans ZooKeeper et sur S3. Cela pouvait se produire lors de la suppression de parts obsolètes ayant subi une mutation. Le problème est signalé par les messages de log `Failed to get mutation parent on {} for part {}, refusing to remove blobs`. [#54550](https://github.com/ClickHouse/ClickHouse/pull/54550) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#54627](https://github.com/ClickHouse/ClickHouse/issues/54627) : correction d’une écriture non synchronisée sur une variable partagée dans `ColumnUnique`. [#54575](https://github.com/ClickHouse/ClickHouse/pull/54575) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#54625](https://github.com/ClickHouse/ClickHouse/issues/54625) : correction de la sérialisation de `ColumnDecimal`. [#54601](https://github.com/ClickHouse/ClickHouse/pull/54601) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#54945](https://github.com/ClickHouse/ClickHouse/issues/54945) : correction des colonnes virtuelles (par ex. &#95;file), qui affichaient des valeurs incorrectes avec ORDER BY. [#54811](https://github.com/ClickHouse/ClickHouse/pull/54811) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#54872](https://github.com/ClickHouse/ClickHouse/issues/54872) : correction dans Keeper : capture correcte d’une variable dans un callback afin d’éviter des segfaults lors de l’arrêt. [#54841](https://github.com/ClickHouse/ClickHouse/pull/54841) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#54950](https://github.com/ClickHouse/ClickHouse/issues/54950) : correction d’une erreur d’optimisation des projections si la clé de partition de la table avait été modifiée par ALTER via l’extension de son type Enum. La correction consiste à reconstruire `minmax_count_projection` lorsque la clé de partition est modifiée. Cela corrige [#54941](https://github.com/ClickHouse/ClickHouse/issues/54941). [#54943](https://github.com/ClickHouse/ClickHouse/pull/54943) ([Amos Bird](https://github.com/amosbird)).
