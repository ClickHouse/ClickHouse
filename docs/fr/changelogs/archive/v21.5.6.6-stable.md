<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#24170](https://github.com/ClickHouse/ClickHouse/issues/24170) : corrige un bogue rare pouvant conduire à une table partiellement initialisée capable de traiter des requêtes d&#39;écriture (`insert`/`alter`/etc.). Désormais, ces tables passeront en mode `readonly`. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#24332](https://github.com/ClickHouse/ClickHouse/issues/24332) : définit `max_threads = 1` pour corriger l&#39;échec de mutation de StorageMemory. Clôt [#24274](https://github.com/ClickHouse/ClickHouse/issues/24274). [#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#24382](https://github.com/ClickHouse/ClickHouse/issues/24382) : autorise les en-têtes HTTP vides. Corrige [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901). [#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#24351](https://github.com/ClickHouse/ClickHouse/issues/24351) : corrige un bogue lors du déplacement d&#39;une vue matérialisée d&#39;une base de données Ordinary vers une base de données Atomic (requête `RENAME TABLE`). Désormais, la table interne est déplacée vers la nouvelle base de données en même temps que la vue matérialisée. Corrige [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926). [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#24509](https://github.com/ClickHouse/ClickHouse/issues/24509) : corrige le drop partition avec de faux parts intersectés. Dans de rares cas, certains parts peuvent avoir une version de mutation supérieure au numéro de bloc actuel. [#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#24540](https://github.com/ClickHouse/ClickHouse/issues/24540) : corrige la monotonie incorrecte de la fonction toWeek. Cela corrige [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422). Ce bogue a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212), puis révélé plus tard par un élagueur de partitions plus intelligent. [#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#24557](https://github.com/ClickHouse/ClickHouse/issues/24557) : corrige le comportement lorsque la requête `SYSTEM RESTART REPLICA` ou `SYSTEM SYNC REPLICA` est traitée indéfiniment. Cela a été détecté sur un serveur disposant d&#39;une quantité extrêmement faible de RAM. [#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#24598](https://github.com/ClickHouse/ClickHouse/issues/24598) : corrige l&#39;utilisation des tuples dans les requêtes `CREATE .. AS SELECT`. [#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#24601](https://github.com/ClickHouse/ClickHouse/issues/24601) : active la lecture des sous-colonnes pour les tables distribuées. [#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
