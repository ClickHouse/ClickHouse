<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#39749](https://github.com/ClickHouse/ClickHouse/issues/39749) : corrige le repositionnement lors de la lecture sur un disque chiffré. Cette PR corrige [#38381](https://github.com/ClickHouse/ClickHouse/issues/38381). [#39687](https://github.com/ClickHouse/ClickHouse/pull/39687) ([Vitaly Baranov](https://github.com/vitlibar)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#39883](https://github.com/ClickHouse/ClickHouse/issues/39883) : auparavant, les anciens paquets installaient le fichier systemd.service dans `/etc`. Les fichiers qui s&#39;y trouvent sont marqués comme `conf`, ne sont pas supprimés et ne sont pas mis à jour automatiquement. Cette PR les supprime. [#39323](https://github.com/ClickHouse/ClickHouse/pull/39323) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#39207](https://github.com/ClickHouse/ClickHouse/issues/39207) : corrige la lecture des colonnes creuses depuis des tables `MergeTree` qui stockent leurs données dans S3. [#37978](https://github.com/ClickHouse/ClickHouse/pull/37978) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#38932](https://github.com/ClickHouse/ClickHouse/issues/38932) : corrige `parallel_view_processing=1` avec `optimize_trivial_insert_select=1`. Corrige `max_insert_threads` lors de l’envoi de données vers des vues. [#38731](https://github.com/ClickHouse/ClickHouse/pull/38731) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#39590](https://github.com/ClickHouse/ClickHouse/issues/39590) : corrige une situation de concurrence et un possible dépassement de tampon sur le tas dans le format Avro. Ferme [#39094](https://github.com/ClickHouse/ClickHouse/issues/39094) Ferme [#33652](https://github.com/ClickHouse/ClickHouse/issues/33652). [#39498](https://github.com/ClickHouse/ClickHouse/pull/39498) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#39612](https://github.com/ClickHouse/ClickHouse/issues/39612) : corrige un bogue avec l’argument maxsplit de splitByChar, qui ne fonctionnait pas correctement. [#39552](https://github.com/ClickHouse/ClickHouse/pull/39552) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#39791](https://github.com/ClickHouse/ClickHouse/issues/39791) : corrige une analyse d’index erronée avec les tuples et l’opérateur `IN`, ce qui pouvait conduire à un résultat de requête erroné. [#39752](https://github.com/ClickHouse/ClickHouse/pull/39752) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#39836](https://github.com/ClickHouse/ClickHouse/issues/39836) : corrige l’exception `CANNOT_READ_ALL_DATA` avec `local_filesystem_read_method=pread_threadpool`. Ce bogue affectait uniquement les versions 5.9 et 5.10 du noyau Linux selon [man](https://manpages.debian.org/testing/manpages-dev/preadv2.2.en.html#BUGS). [#39800](https://github.com/ClickHouse/ClickHouse/pull/39800) ([Anton Popov](https://github.com/CurtizJ)).
