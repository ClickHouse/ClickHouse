<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#48164](https://github.com/ClickHouse/ClickHouse/issues/48164) : correction de l&#39;exception `UNKNOWN_TABLE` lors de l&#39;exécution de `Attach` sur une vue matérialisée dont les tables dépendantes ne sont pas disponibles. Cela peut être utile lorsqu&#39;on tente de restaurer l&#39;état depuis une sauvegarde. [#47975](https://github.com/ClickHouse/ClickHouse/pull/47975) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build, des tests et du packaging
</div>

* Rétroporté dans [#48216](https://github.com/ClickHouse/ClickHouse/issues/48216) : utilisation de sccache en remplacement de ccache, avec S3 comme backend de cache. [#46240](https://github.com/ClickHouse/ClickHouse/pull/46240) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#48256](https://github.com/ClickHouse/ClickHouse/issues/48256) : auparavant, l’image `clickhouse/clickhouse-keeper` n’était publiée qu’avec des tags `-alpine`, par exemple `latest-alpine`. Comme cela a été suggéré dans [https://github.com/ClickHouse/examples/pull/2](https://github.com/ClickHouse/examples/pull/2), elle est désormais aussi publiée sans suffixe. [#48236](https://github.com/ClickHouse/ClickHouse/pull/48236) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
