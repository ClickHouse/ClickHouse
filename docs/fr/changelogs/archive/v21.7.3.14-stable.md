* Rétroporté dans [#26191](https://github.com/ClickHouse/ClickHouse/issues/26191) : correction de `sharding_key` à partir d&#39;une colonne sans fonction pour `remote()` (auparavant, `select * from remote('127.1', system.one, dummy)` provoquait l&#39;erreur `Unknown column: dummy, there are only columns .`). [#25824](https://github.com/ClickHouse/ClickHouse/pull/25824) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#26109](https://github.com/ClickHouse/ClickHouse/issues/26109) : correction d&#39;un rare plantage du serveur dû à `abort` dans le client ZooKeeper. Corrige [#25813](https://github.com/ClickHouse/ClickHouse/issues/25813). [#26079](https://github.com/ClickHouse/ClickHouse/pull/26079) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#26142](https://github.com/ClickHouse/ClickHouse/issues/26142) : correction d&#39;un plantage possible dans `pointInPolygon` si le paramètre `validate_polygons` est désactivé. [#26113](https://github.com/ClickHouse/ClickHouse/pull/26113) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#26170](https://github.com/ClickHouse/ClickHouse/issues/26170) : correction de `joinGet` avec des colonnes LowCarinality, corrige [#25993](https://github.com/ClickHouse/ClickHouse/issues/25993). [#26118](https://github.com/ClickHouse/ClickHouse/pull/26118) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#26206](https://github.com/ClickHouse/ClickHouse/issues/26206) : correction d&#39;un plantage potentiel si plusieurs expressions `untuple` sont utilisées. [#26179](https://github.com/ClickHouse/ClickHouse/pull/26179) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#26229](https://github.com/ClickHouse/ClickHouse/issues/26229) : suppression d&#39;un saut de ligne superflu dans la colonne `thread_name` de la table `system.stack_trace`. Cela corrige [#24124](https://github.com/ClickHouse/ClickHouse/issues/24124). [#26210](https://github.com/ClickHouse/ClickHouse/pull/26210) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Correction de l&#39;exception levée lors de l&#39;itération sur un répertoire distant inexistant. [#26296](https://github.com/ClickHouse/ClickHouse/pull/26296) ([ianton-ru](https://github.com/ianton-ru)).
