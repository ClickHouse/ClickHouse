<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#71495](https://github.com/ClickHouse/ClickHouse/issues/71495) : activation de `parallel_replicas_local_plan` par défaut. La construction d&#39;un plan local complet sur l&#39;initiateur de la requête améliore les performances des répliques parallèles tout en réduisant la consommation de ressources, et offre davantage de possibilités d&#39;optimisation des requêtes. [#70171](https://github.com/ClickHouse/ClickHouse/pull/70171) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#71985](https://github.com/ClickHouse/ClickHouse/issues/71985) : correction des JOIN RIGHT / FULL dans les requêtes avec des répliques parallèles. Désormais, les JOIN RIGHT peuvent être exécutés avec des répliques parallèles (la lecture de la table de droite est distribuée). Les JOIN FULL ne peuvent pas être parallélisés entre les nœuds et sont exécutés localement. [#71162](https://github.com/ClickHouse/ClickHouse/pull/71162) ([Igor Nikonov](https://github.com/devcrafter)).
* Rétroporté dans [#71670](https://github.com/ClickHouse/ClickHouse/issues/71670) : lorsque l&#39;utilisateur/le groupe est fourni sous forme d&#39;ID, `clickhouse su` échoue. Ce patch corrige ce problème afin d&#39;accepter également `UID:GID`. ### Entrée de documentation pour les changements destinés aux utilisateurs. [#71626](https://github.com/ClickHouse/ClickHouse/pull/71626) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#71940](https://github.com/ClickHouse/ClickHouse/issues/71940) : mise à jour de `HostResolver` 3 fois sur une période `history`. [#71863](https://github.com/ClickHouse/ClickHouse/pull/71863) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#71922](https://github.com/ClickHouse/ClickHouse/issues/71922) : `Allow_reorder_prewhere_conditions` est activé par défaut avec les anciens paramètres de compatibilité. [#71867](https://github.com/ClickHouse/ClickHouse/pull/71867) ([Raúl Marín](https://github.com/Algunenano)).
