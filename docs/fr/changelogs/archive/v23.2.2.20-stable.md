<div id="clickhouse-release-v232220-stable-f6c269c8df2-fixme-as-compared-to-v23212537-stable-52bf836e03a">
  ### Version ClickHouse v23.2.2.20-stable (f6c269c8df2) FIXME comparée à v23.2.1.2537-stable (52bf836e03a)
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#46914](https://github.com/ClickHouse/ClickHouse/issues/46914) : prise en charge de PREWHERE avec Merge lorsqu&#39;une colonne a une expression DEFAULT différente. [#46831](https://github.com/ClickHouse/ClickHouse/pull/46831) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#47022](https://github.com/ClickHouse/ClickHouse/issues/47022) : prise en charge d&#39;IPv4 dans range(). [#46995](https://github.com/ClickHouse/ClickHouse/pull/46995) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).

<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#46828](https://github.com/ClickHouse/ClickHouse/issues/46828) : dans certains cas, la colonne PREWHERE combinée, accumulée à partir de plusieurs PREWHERE, ne contenait pas les 0 issus des étapes précédentes. Le correctif consiste à appliquer le filtre final si l&#39;on sait qu&#39;il n&#39;a pas été appliqué lors de plus d&#39;une des dernières étapes. [#46785](https://github.com/ClickHouse/ClickHouse/pull/46785) ([Alexander Gololobov](https://github.com/davenger)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build, des tests et du packaging
</div>

* Rétroporté dans [#47062](https://github.com/ClickHouse/ClickHouse/issues/47062) : correction d’une erreur au démarrage du serveur sur d’anciennes distributions (par ex. Amazon Linux 2) et sur ARM, lorsque les symboles de glibc 2.28 sont introuvables. [#47008](https://github.com/ClickHouse/ClickHouse/pull/47008) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogue (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#46895](https://github.com/ClickHouse/ClickHouse/issues/46895) : correction d’un bogue dans les réessais automatiques de la requête `DROP TABLE` avec des tables `ReplicatedMergeTree` et des bases de données `Atomic`. Dans de rares cas, cela pouvait entraîner les erreurs `Can't get data for node /zk_path/log_pointer` et `The specified key does not exist` si la session ZooKeeper expirait pendant le DROP et qu’une nouvelle table répliquée avec le même chemin dans ZooKeeper était créée en parallèle. [#46384](https://github.com/ClickHouse/ClickHouse/pull/46384) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#46865](https://github.com/ClickHouse/ClickHouse/issues/46865) : correction d’un bogue dans le type de données `Map`. Clôt [#46855](https://github.com/ClickHouse/ClickHouse/issues/46855). [#46856](https://github.com/ClickHouse/ClickHouse/pull/46856) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#46958](https://github.com/ClickHouse/ClickHouse/issues/46958) : correction du résultat des prédicats LIKE qui se traduisent par des recherches de sous-chaînes et contiennent des métacaractères non-LIKE entre guillemets. [#46875](https://github.com/ClickHouse/ClickHouse/pull/46875) ([Robert Schulze](https://github.com/rschu1ze)).
