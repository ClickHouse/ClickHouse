<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#25851](https://github.com/ClickHouse/ClickHouse/issues/25851) : `CAST` de `Date` vers `DateTime` (ou `DateTime64`) n&#39;utilisait pas le fuseau horaire du type `DateTime`. Cela pouvait aussi affecter la comparaison entre `Date` et `DateTime`. L&#39;inférence du type commun pour `Date` et `DateTime` n&#39;utilisait pas non plus le fuseau horaire correspondant. Cela affectait les résultats de la fonction `if` et la construction de tableaux. Clôt [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128). [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#25678](https://github.com/ClickHouse/ClickHouse/issues/25678) : correction d&#39;un bug dans la désérialisation de l&#39;état du générateur aléatoire, susceptible d&#39;entraîner un comportement non déterministe de certains types de données tels que `AggregateFunction(groupArraySample(N), T))`. [#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25637](https://github.com/ClickHouse/ClickHouse/issues/25637) : correction de totaux incorrects pour les requêtes `WITH TOTALS` et `WITH FILL`. Corrige [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872). [#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#25651](https://github.com/ClickHouse/ClickHouse/issues/25651) : correction d&#39;un déréférencement de pointeur nul dans `EXPLAIN AST` sans requête. [#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25716](https://github.com/ClickHouse/ClickHouse/issues/25716) : `REPLACE PARTITION` pouvait être ignoré dans de rares cas si la partition source était vide. C&#39;est corrigé. Corrige [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869). [#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25712](https://github.com/ClickHouse/ClickHouse/issues/25712) : correction de l&#39;erreur `No such file or directory` lors du déplacement d&#39;une table `Distributed` d&#39;une base de données à une autre. Corrige [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971). [#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
