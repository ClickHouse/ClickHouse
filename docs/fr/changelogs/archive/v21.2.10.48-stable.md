  # Historique des modifications 2022
</div>

<div id="clickhouse-release-v2121048-stable-fixme-as-compared-to-v212941-stable">
  ### Version de ClickHouse v21.2.10.48-stable FIXME par rapport à v21.2.9.41-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#23015](https://github.com/ClickHouse/ClickHouse/issues/23015) : `background_fetches_pool_size` a été réglé sur 8, ce qui convient mieux à une utilisation en production avec des insertions fréquentes de petite taille ou un cluster ZooKeeper lent. [#22945](https://github.com/ClickHouse/ClickHouse/pull/22945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#23080](https://github.com/ClickHouse/ClickHouse/issues/23080) : relèvement du seuil du nombre maximal de correspondances dans le résultat de la fonction `extractAllGroupsHorizontal`. [#23036](https://github.com/ClickHouse/ClickHouse/pull/23036) ([Vasily Nemkov](https://github.com/Enmk)).

<div id="bug-fix">
  #### Corrections de bugs
</div>

* Rétroporté dans [#23155](https://github.com/ClickHouse/ClickHouse/issues/23155) : correction d’un bug provoquant une attente illimitée pour les requêtes AWS auxiliaires. [#22594](https://github.com/ClickHouse/ClickHouse/pull/22594) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#23032](https://github.com/ClickHouse/ClickHouse/issues/23032) : correction de l’erreur `Cannot find column in ActionsDAG result`, qui peut se produire si une sous-requête utilise `untuple`. Corrige [#22290](https://github.com/ClickHouse/ClickHouse/issues/22290). [#22991](https://github.com/ClickHouse/ClickHouse/pull/22991) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#23171](https://github.com/ClickHouse/ClickHouse/issues/23171) : certaines values étaient affichées avec un alignement centré dans les cellules des tables au format `Markdown`. Ce n’est plus le cas. [#23096](https://github.com/ClickHouse/ClickHouse/pull/23096) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
