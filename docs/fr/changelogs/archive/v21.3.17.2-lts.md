* Rétroporté dans [#28569](https://github.com/ClickHouse/ClickHouse/issues/28569) : correction d’un bug pouvant entraîner l’erreur `Existing table metadata in ZooKeeper differs in sorting key expression.` après une modification de `ReplicatedVersionedCollapsingMergeTree`. Corrige [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515). [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28857](https://github.com/ClickHouse/ClickHouse/issues/28857) : correction d’une condition de concurrence bénigne dans ReplicatedMergeTreeQueue. Cela ne devrait pas être visible pour l’utilisateur, mais peut entraîner des bugs subtils. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#28995](https://github.com/ClickHouse/ClickHouse/issues/28995) : correction de la lecture des sous-colonnes depuis des parties au format compact. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#28929](https://github.com/ClickHouse/ClickHouse/issues/28929) : correction des fonctions sur les tableaux d’ordre supérieur (`SIGSEGV` pour `arrayCompact`/`ILLEGAL_COLUMN` pour `arrayDifference`/`arrayCumSumNonNegative`) avec des constantes. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
