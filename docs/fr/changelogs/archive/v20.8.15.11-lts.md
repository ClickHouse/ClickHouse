[#21456](https://github.com/ClickHouse/ClickHouse/pull/21456) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#21547](https://github.com/ClickHouse/ClickHouse/issues/21547) : correction d&#39;un interblocage dans les mutations `ALTER DELETE` pour les moteurs de table MergeTree non répliqués lorsque le prédicat contient la table elle-même. Corrige [#20558](https://github.com/ClickHouse/ClickHouse/issues/20558). [#21477](https://github.com/ClickHouse/ClickHouse/pull/21477) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22284](https://github.com/ClickHouse/ClickHouse/issues/22284) : correction d&#39;un bogue dans les moteurs de table ReplicatedMerge lorsque la requête `ALTER MODIFY COLUMN` ne change pas le type d&#39;une colonne Decimal si sa taille (32 bits ou 64 bits) reste inchangée. [#21728](https://github.com/ClickHouse/ClickHouse/pull/21728) ([alesapin](https://github.com/alesapin)).

Ferme [#22100](https://github.com/ClickHouse/ClickHouse/issues/22100). [#22102](https://github.com/ClickHouse/ClickHouse/pull/22102) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#22279](https://github.com/ClickHouse/ClickHouse/issues/22279) : correction de l&#39;attente des requêtes `OPTIMIZE` et `ALTER` pour les moteurs de table `ReplicatedMergeTree`. Désormais, la requête ne restera pas bloquée lorsque la table a été détachée ou redémarrée. [#22118](https://github.com/ClickHouse/ClickHouse/pull/22118) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#22370](https://github.com/ClickHouse/ClickHouse/issues/22370) : désormais, ClickHouse ne lèvera pas d&#39;exception `LOGICAL_ERROR` lorsque nous essaierons d&#39;appliquer une mutation à une part déjà couverte. Corrige [#22013](https://github.com/ClickHouse/ClickHouse/issues/22013). [#22291](https://github.com/ClickHouse/ClickHouse/pull/22291) ([alesapin](https://github.com/alesapin)).
