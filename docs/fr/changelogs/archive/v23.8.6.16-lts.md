[#54549](https://github.com/ClickHouse/ClickHouse/pull/54549) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#56253](https://github.com/ClickHouse/ClickHouse/issues/56253) : corrige un bogue de la fonction match() (regex) : un motif contenant une alternance produisait une condition de clé incorrecte. [#54696](https://github.com/ClickHouse/ClickHouse/pull/54696) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#56322](https://github.com/ClickHouse/ClickHouse/issues/56322) : corrige un plantage lors du chargement des tables au démarrage. Clôt [#55767](https://github.com/ClickHouse/ClickHouse/issues/55767). [#56232](https://github.com/ClickHouse/ClickHouse/pull/56232) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#56292](https://github.com/ClickHouse/ClickHouse/issues/56292) : corrige un segfault dans le gestionnaire de signaux de Keeper. [#56266](https://github.com/ClickHouse/ClickHouse/pull/56266) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#56443](https://github.com/ClickHouse/ClickHouse/issues/56443) : corrige un plantage dû à un dépassement de tampon lors de la décompression de données malformées avec le codec `T64`. Ce problème a été découvert dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par [https://twitter.com/malacupa](https://twitter.com/malacupa). [#56434](https://github.com/ClickHouse/ClickHouse/pull/56434) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
