<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#58815](https://github.com/ClickHouse/ClickHouse/issues/58815) : ajout de `SYSTEM JEMALLOC PURGE` pour purger les pages jemalloc inutilisées, et de `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` pour contrôler le profilage jemalloc si le Profiler est activé. Ajout de la commande 4LW liée à jemalloc dans Keeper : `jmst` pour produire un dump des statistiques jemalloc, `jmfp`, `jmep`, `jmdp` pour contrôler le profilage jemalloc si le Profiler est activé. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#59234](https://github.com/ClickHouse/ClickHouse/issues/59234) : permet d&#39;ignorer l&#39;évolution du schéma dans le moteur de table Iceberg et de lire toutes les données en utilisant soit le schéma spécifié par l&#39;utilisateur lors de la création de la table, soit le dernier schéma analysé à partir des métadonnées lors de la création de la table. Cela se fait via le paramètre `iceberg_engine_ignore_schema_evolution`, désactivé par défaut. Notez que l&#39;activation de ce paramètre peut entraîner des résultats incorrects car, en cas d&#39;évolution du schéma, tous les fichiers de données seront lus avec le même schéma. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
