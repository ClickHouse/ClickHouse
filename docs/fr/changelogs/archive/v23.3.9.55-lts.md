<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#52213](https://github.com/ClickHouse/ClickHouse/issues/52213) : ne pas stocker de blocs dans le `hash join` `ANY` si rien n’est inséré. [#48633](https://github.com/ClickHouse/ClickHouse/pull/48633) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#52826](https://github.com/ClickHouse/ClickHouse/issues/52826) : corrige une analyse erronée des projections qui invalide les clés primaires. Ce problème n’existe que lorsque `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1`. Cela corrige [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823). Cela corrige [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173). [#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#53019](https://github.com/ClickHouse/ClickHouse/issues/53019) : l’intégration du cache intégré dans les images Docker provoque parfois d’étranges effets de bord. Comme nous ne l’utilisons pas du tout, ce n’est pas gênant. [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#53288](https://github.com/ClickHouse/ClickHouse/issues/53288) : les données de profilage du compilateur (`-ftime-trace`) sont téléversées vers ClickHouse Cloud ; il s’agit de la deuxième tentative après [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100). [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#53461](https://github.com/ClickHouse/ClickHouse/issues/53461) : préserver les paramètres d’environnement dans la commande `clickhouse start`. Corrige [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962). [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
