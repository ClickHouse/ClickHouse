<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#20241](https://github.com/ClickHouse/ClickHouse/issues/20241) : correction d’un bug pouvant faire échouer le déplacement d’éléments vers la table de destination lors du lancement de plusieurs `clickhouse-copier`. [#19743](https://github.com/ClickHouse/ClickHouse/pull/19743) ([madianjun](https://github.com/mdianjun)).
* Rétroporté dans [#20296](https://github.com/ClickHouse/ClickHouse/issues/20296) : * Correction d’un bug dans StorageJoin. [#20079](https://github.com/ClickHouse/ClickHouse/pull/20079) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#20389](https://github.com/ClickHouse/ClickHouse/issues/20389) : le moteur de table `MongoDB` n’établit désormais une connexion que lorsqu’il doit lire des données. `ATTACH TABLE` n’essaiera plus de se connecter. [#20110](https://github.com/ClickHouse/ClickHouse/pull/20110) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#20270](https://github.com/ClickHouse/ClickHouse/issues/20270) : correction de CTE lors de son utilisation dans INSERT SELECT. Cela corrige [#20187](https://github.com/ClickHouse/ClickHouse/issues/20187) et [#20195](https://github.com/ClickHouse/ClickHouse/issues/20195). [#20211](https://github.com/ClickHouse/ClickHouse/pull/20211) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#20329](https://github.com/ClickHouse/ClickHouse/issues/20329) : correction d’un rare crash du serveur lors du rechargement de la configuration pendant l’arrêt. Corrige [#19689](https://github.com/ClickHouse/ClickHouse/issues/19689). [#20224](https://github.com/ClickHouse/ClickHouse/pull/20224) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20324](https://github.com/ClickHouse/ClickHouse/issues/20324) : correction d’une exception pendant une fusion verticale pour la famille de moteurs de table `MergeTree` qui ne permet pas d’effectuer de fusions verticales. Corrige [#20259](https://github.com/ClickHouse/ClickHouse/issues/20259). [#20279](https://github.com/ClickHouse/ClickHouse/pull/20279) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20333](https://github.com/ClickHouse/ClickHouse/issues/20333) : restriction de `DROP` ou `RENAME` sur la colonne de version des moteurs de table `*CollapsingMergeTree` et `ReplacingMergeTree`. [#20300](https://github.com/ClickHouse/ClickHouse/pull/20300) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20365](https://github.com/ClickHouse/ClickHouse/issues/20365) : correction de tentatives de reprise trop fréquentes pour les tâches d’arrière-plan en échec de la famille de moteurs de table `ReplicatedMergeTree`. Cela pouvait entraîner une journalisation trop détaillée et une charge CPU accrue. Corrige [#20203](https://github.com/ClickHouse/ClickHouse/issues/20203). [#20335](https://github.com/ClickHouse/ClickHouse/pull/20335) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#20379](https://github.com/ClickHouse/ClickHouse/issues/20379) : correction d’un résultat incorrect d’opérations binaires entre deux nombres décimaux constants d’échelles différentes. Corrige [#20283](https://github.com/ClickHouse/ClickHouse/issues/20283). [#20339](https://github.com/ClickHouse/ClickHouse/pull/20339) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#20376](https://github.com/ClickHouse/ClickHouse/issues/20376) : correction d’un déréférencement de pointeur nul avec `join_use_nulls=1`. [#20344](https://github.com/ClickHouse/ClickHouse/pull/20344) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20361](https://github.com/ClickHouse/ClickHouse/issues/20361) : évite un déréférencement invalide dans le dictionnaire RANGE&#95;HASHED(). [#20345](https://github.com/ClickHouse/ClickHouse/pull/20345) ([Azat Khuzhin](https://github.com/azat)).
