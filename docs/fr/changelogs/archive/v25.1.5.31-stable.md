  ### Version de ClickHouse v25.1.5.31-stable (48f17e8a805) FIXME par rapport à v25.1.4.53-stable (c3f28b8bf5d)
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#76048](https://github.com/ClickHouse/ClickHouse/issues/76048) : amélioration de Keeper : désactivation du calcul du digest lors du commit vers le stockage en mémoire afin d’améliorer les performances. Il peut être activé via la config `keeper_server.digest_enabled_on_commit`. Le digest est toujours calculé lors du prétraitement des requêtes. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#76315](https://github.com/ClickHouse/ClickHouse/issues/76315) : ajout d’un paramètre serveur `throw_on_unknown_workload` permettant de choisir le comportement d’une requête dont le paramètre `workload` est défini sur une valeur inconnue : soit autoriser un accès illimité (par défaut), soit lever une erreur `RESOURCE_ACCESS_DENIED`. Cela est utile pour forcer toutes les requêtes à utiliser la planification des charges de travail. [#75999](https://github.com/ClickHouse/ClickHouse/pull/75999) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement erroné visible par l&#39;utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#76341](https://github.com/ClickHouse/ClickHouse/issues/76341) : vérification des types non pris en charge pour certains moteurs de stockage. [#74218](https://github.com/ClickHouse/ClickHouse/pull/74218) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#76362](https://github.com/ClickHouse/ClickHouse/issues/76362) : correction de problèmes liés aux types d&#39;expressions définis par alias dans la clause JOIN ON lorsqu&#39;une comparaison null-safe est utilisée. [#74970](https://github.com/ClickHouse/ClickHouse/pull/74970) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Rétroporté dans [#75634](https://github.com/ClickHouse/ClickHouse/issues/75634) : correction d&#39;un crash dû à une exception non gérée dans la réplication PSQL. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#76246](https://github.com/ClickHouse/ClickHouse/issues/76246) : SASL peut faire échouer n&#39;importe quel appel RPC ; ce correctif permet de relancer l&#39;appel si le ticket krb5 a expiré. [#75063](https://github.com/ClickHouse/ClickHouse/pull/75063) ([inv2004](https://github.com/inv2004)).
* Rétroporté dans [#76161](https://github.com/ClickHouse/ClickHouse/issues/76161) : reconstruction de la projection lors d&#39;un ALTER MODIFY de sa colonne PK. Auparavant, cela pouvait entraîner des erreurs `CANNOT_READ_ALL_DATA` lors de requêtes SELECT après un ALTER MODIFY de la colonne utilisée dans la PK de la projection. [#75720](https://github.com/ClickHouse/ClickHouse/pull/75720) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#76261](https://github.com/ClickHouse/ClickHouse/issues/76261) : enregistrement de l&#39;activation par défaut du hash parallèle comme join algorithm dans l&#39;historique des changements de paramètres de la v24.12. Cela signifie que ClickHouse continuera à utiliser un hash non parallèle pour les jointures si un niveau de compatibilité antérieur à la v24.12 est configuré. [#75870](https://github.com/ClickHouse/ClickHouse/pull/75870) ([Robert Schulze](https://github.com/rschu1ze)).
* Rétroporté dans [#76201](https://github.com/ClickHouse/ClickHouse/issues/76201) : `clickhouse-library-bridge` permet d&#39;ouvrir des bibliothèques arbitraires depuis le système de fichiers, ce qui ne le rend sûr à exécuter que dans un environnement isolé. Pour éviter une vulnérabilité lorsqu&#39;il est exécuté à proximité de clickhouse-server, nous limiterons les chemins des bibliothèques à un emplacement défini dans la configuration. Cette vulnérabilité a été découverte dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par **Arseniy Dugin**. [#75954](https://github.com/ClickHouse/ClickHouse/pull/75954) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
