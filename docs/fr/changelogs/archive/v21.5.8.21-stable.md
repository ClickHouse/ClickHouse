<div id="clickhouse-release-v215821-stable-fixme-as-compared-to-v21579-stable">
  ### Version de ClickHouse v21.5.8.21-stable FIXME par rapport à v21.5.7.9-stable

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#25849](https://github.com/ClickHouse/ClickHouse/issues/25849) : `CAST` de `Date` vers `DateTime` (ou `DateTime64`) n’utilisait pas le fuseau horaire du type `DateTime`. Cela pouvait également affecter la comparaison entre `Date` et `DateTime`. L’inférence du type commun pour `Date` et `DateTime` n’utilisait pas non plus le fuseau horaire correspondant. Cela affectait les résultats de la fonction `if` et la construction de tableaux. Corrige [#24128](https://github.com/ClickHouse/ClickHouse/issues/24128). [#24129](https://github.com/ClickHouse/ClickHouse/pull/24129) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#25679](https://github.com/ClickHouse/ClickHouse/issues/25679) : Correction d’un bug dans la désérialisation de l’état du générateur aléatoire, pouvant entraîner un comportement non déterministe de certains types de données tels que `AggregateFunction(groupArraySample(N), T))`. [#24538](https://github.com/ClickHouse/ClickHouse/pull/24538) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25556](https://github.com/ClickHouse/ClickHouse/issues/25556) : Correction d’un crash potentiel lors du calcul des états de fonctions d’agrégation par agrégation des états de fonctions d’agrégation d’autres fonctions d’agrégation (pas un cas d’usage pratique). Voir [#24523](https://github.com/ClickHouse/ClickHouse/issues/24523). [#25015](https://github.com/ClickHouse/ClickHouse/pull/25015) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#25767](https://github.com/ClickHouse/ClickHouse/issues/25767) : Correction d’une assertion dans PREWHERE avec un type non uint8, corrige [#19589](https://github.com/ClickHouse/ClickHouse/issues/19589). [#25484](https://github.com/ClickHouse/ClickHouse/pull/25484) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#25636](https://github.com/ClickHouse/ClickHouse/issues/25636) : Correction de totaux erronés pour la requête `WITH TOTALS` et `WITH FILL`. Corrige [#20872](https://github.com/ClickHouse/ClickHouse/issues/20872). [#25539](https://github.com/ClickHouse/ClickHouse/pull/25539) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#25653](https://github.com/ClickHouse/ClickHouse/issues/25653) : Correction d’un déréférencement de pointeur nul dans `EXPLAIN AST` sans requête. [#25631](https://github.com/ClickHouse/ClickHouse/pull/25631) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25715](https://github.com/ClickHouse/ClickHouse/issues/25715) : `REPLACE PARTITION` pouvait être ignoré dans de rares cas si la partition source était vide. Le problème est corrigé. Corrige [#24869](https://github.com/ClickHouse/ClickHouse/issues/24869). [#25665](https://github.com/ClickHouse/ClickHouse/pull/25665) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25695](https://github.com/ClickHouse/ClickHouse/issues/25695) : Correction de l’erreur `No such file or directory` lors du déplacement d’une table `Distributed` entre des bases de données. Corrige [#24971](https://github.com/ClickHouse/ClickHouse/issues/24971). [#25667](https://github.com/ClickHouse/ClickHouse/pull/25667) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25754](https://github.com/ClickHouse/ClickHouse/issues/25754) : Correction d’une data race lors de requêtes sur `system.clusters` pendant le rechargement simultané de la configuration du cluster. [#25737](https://github.com/ClickHouse/ClickHouse/pull/25737) ([Amos Bird](https://github.com/amosbird)).
