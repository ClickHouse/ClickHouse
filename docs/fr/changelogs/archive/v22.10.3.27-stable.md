<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#42842](https://github.com/ClickHouse/ClickHouse/issues/42842) : mise à jour de tzdata vers 2022f. Le Mexique n’observera plus l’heure d’été, sauf près de la frontière avec les États-Unis : [https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html](https://www.timeanddate.com/news/time/mexico-abolishes-dst-2022.html). Chihuahua passera à l’UTC-6 toute l’année à partir du 2022-10-30. Les Fidji n’observent plus l’heure d’été. Voir [https://github.com/google/cctz/pull/235](https://github.com/google/cctz/pull/235) et [https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209](https://bugs.launchpad.net/ubuntu/+source/tzdata/+bug/1995209). [#42796](https://github.com/ClickHouse/ClickHouse/pull/42796) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

Cette PR corrige ce problème et n&#39;écrasera pas les fichiers utilisateur issus des paquets. [#42936](https://github.com/ClickHouse/ClickHouse/pull/42936) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#43042](https://github.com/ClickHouse/ClickHouse/issues/43042) : ajout d&#39;une étape d&#39;intégration continue pour marquer les commits comme prêts pour la publication ; interdiction souple de lancer un script de publication depuis des branches autres que master. [#43017](https://github.com/ClickHouse/ClickHouse/pull/43017) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (dysfonctionnements visibles par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#42864](https://github.com/ClickHouse/ClickHouse/issues/42864) : correction de lowerUTF8()/upperUTF8() lorsqu’un symbole se trouvait à cheval sur une limite de 16 octets (cas très fréquent si vous avez des chaînes de plus de 16 octets). [#42812](https://github.com/ClickHouse/ClickHouse/pull/42812) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#43173](https://github.com/ClickHouse/ClickHouse/issues/43173) : correction d’un rare blocage possible lors de l’annulation d’une requête. [#42874](https://github.com/ClickHouse/ClickHouse/pull/42874) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#43064](https://github.com/ClickHouse/ClickHouse/issues/43064) : correction d’une rare erreur NOT&#95;FOUND&#95;COLUMN&#95;IN&#95;BLOCK lorsqu’une projection pouvait être utilisée, mais qu’aucune projection n’était disponible. Cela corrige [#42771](https://github.com/ClickHouse/ClickHouse/issues/42771). Le bogue a été introduit dans [https://github.com/ClickHouse/ClickHouse/pull/25563](https://github.com/ClickHouse/ClickHouse/pull/25563). [#42938](https://github.com/ClickHouse/ClickHouse/pull/42938) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#43075](https://github.com/ClickHouse/ClickHouse/issues/43075) : correction de l’analyse syntaxique des expressions lambda. Clôt [#41848](https://github.com/ClickHouse/ClickHouse/issues/41848). [#42979](https://github.com/ClickHouse/ClickHouse/pull/42979) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#43444](https://github.com/ClickHouse/ClickHouse/issues/43444) : - correction de plusieurs lectures hors limites du tampon. [#43159](https://github.com/ClickHouse/ClickHouse/pull/43159) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#43430](https://github.com/ClickHouse/ClickHouse/issues/43430) : correction des requêtes avec `SAMPLE BY` utilisant l’optimisation PREWHERE sur des tables avec le moteur `Merge`. [#43315](https://github.com/ClickHouse/ClickHouse/pull/43315) ([Antonio Andelic](https://github.com/antonio2368)).
