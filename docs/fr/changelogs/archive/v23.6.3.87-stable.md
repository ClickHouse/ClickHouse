<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#52751](https://github.com/ClickHouse/ClickHouse/issues/52751) : correction d&#39;une analyse incorrecte des projections qui invalide les clés primaires. Ce problème ne survient que lorsque `query_plan_optimize_primary_key = 1, query_plan_optimize_projection = 1`. Cela corrige [#48823](https://github.com/ClickHouse/ClickHouse/issues/48823). Cela corrige [#51173](https://github.com/ClickHouse/ClickHouse/issues/51173). [#52308](https://github.com/ClickHouse/ClickHouse/pull/52308) ([Amos Bird](https://github.com/amosbird)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#52911](https://github.com/ClickHouse/ClickHouse/issues/52911) : ajout d&#39;un lien symbolique `clickhouse-keeper-client` au paquet clickhouse-server. [#51882](https://github.com/ClickHouse/ClickHouse/pull/51882) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#53023](https://github.com/ClickHouse/ClickHouse/issues/53023) : l&#39;inclusion du cache intégré dans les images Docker provoque parfois d&#39;étranges effets de bord. Comme nous ne l&#39;utilisons pas du tout, il peut être supprimé. [#53008](https://github.com/ClickHouse/ClickHouse/pull/53008) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Rétroporté dans [#53290](https://github.com/ClickHouse/ClickHouse/issues/53290) : les données de profilage du compilateur (`-ftime-trace`) sont téléversées vers ClickHouse Cloud, deuxième tentative après [#53100](https://github.com/ClickHouse/ClickHouse/issues/53100). [#53213](https://github.com/ClickHouse/ClickHouse/pull/53213) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#53465](https://github.com/ClickHouse/ClickHouse/issues/53465) : conservation des paramètres d&#39;environnement dans la commande `clickhouse start`. Corrige [#51962](https://github.com/ClickHouse/ClickHouse/issues/51962). [#53418](https://github.com/ClickHouse/ClickHouse/pull/53418) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
