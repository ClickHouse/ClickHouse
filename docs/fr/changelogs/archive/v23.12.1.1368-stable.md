<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions précédentes
</div>

* Correction de la vérification des fonctions non déterministes dans les expressions TTL. Auparavant, il était possible, dans certains cas, de créer une expression TTL avec des fonctions non déterministes, ce qui pouvait ensuite entraîner un comportement indéfini. Cela corrige [#37250](https://github.com/ClickHouse/ClickHouse/issues/37250). Les expressions TTL qui ne dépendent d&#39;aucune colonne d&#39;une table sont désormais interdites par défaut. Il est possible de les réautoriser avec `SET allow_suspicious_ttl_expressions = 1` ou `SET compatibility = '23.11'`. Clôt [#37286](https://github.com/ClickHouse/ClickHouse/issues/37286). [#51858](https://github.com/ClickHouse/ClickHouse/pull/51858) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Suppression de la fonction `arrayFold`, car elle comporte un bogue. Cela clôt [#57816](https://github.com/ClickHouse/ClickHouse/issues/57816). Cela clôt [#57458](https://github.com/ClickHouse/ClickHouse/issues/57458). [#57836](https://github.com/ClickHouse/ClickHouse/pull/57836) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Suppression de la fonctionnalité de ligne `is_deleted` dans ReplacingMergeTree, ainsi que du modificateur `CLEANUP` pour la requête OPTIMIZE. Cela corrige [#57930](https://github.com/ClickHouse/ClickHouse/issues/57930). Cela clôt [#54988](https://github.com/ClickHouse/ClickHouse/issues/54988). Cela clôt [#54570](https://github.com/ClickHouse/ClickHouse/issues/54570). Cela clôt [#50346](https://github.com/ClickHouse/ClickHouse/issues/50346). Cela clôt [#47579](https://github.com/ClickHouse/ClickHouse/issues/47579). Cette fonctionnalité doit être supprimée, car elle n&#39;est pas satisfaisante. Nous devons la retirer le plus rapidement possible, car il n&#39;existe pas d&#39;autre solution. [#57932](https://github.com/ClickHouse/ClickHouse/pull/57932) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Le paramètre MergeTree `clean_deleted_rows` est obsolète et n&#39;a désormais plus aucun effet. Le mot-clé `CLEANUP` pour `OPTIMIZE` n&#39;est pas autorisé par défaut (sauf si `allow_experimental_replacing_merge_with_cleanup` est activé). [#58267](https://github.com/ClickHouse/ClickHouse/pull/58267) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Permet de désactiver la requête HEAD avant la requête GET. [#54602](https://github.com/ClickHouse/ClickHouse/pull/54602) ([Fionera](https://github.com/fionera)).
* Ajoute un endpoint HTTP pour vérifier si Keeper est prêt à accepter du trafic. [#55876](https://github.com/ClickHouse/ClickHouse/pull/55876) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Ajoute le mode &#39;union&#39; pour l’inférence de schéma. Dans ce mode, le schéma de table résultant est l’union des schémas de tous les fichiers (le schéma est donc inféré à partir de chaque fichier). Le mode d’inférence de schéma est contrôlé par le setting `schema_inference_mode`, qui a 2 valeurs possibles : `default` et `union`. Clôt [#55428](https://github.com/ClickHouse/ClickHouse/issues/55428). [#55892](https://github.com/ClickHouse/ClickHouse/pull/55892) ([Kruglov Pavel](https://github.com/Avogar)).
* Ajoute un nouveau setting `input_format_csv_try_infer_numbers_from_strings` qui permet d’inférer des nombres à partir de chaînes au format CSV. Clôt [#56455](https://github.com/ClickHouse/ClickHouse/issues/56455). [#56859](https://github.com/ClickHouse/ClickHouse/pull/56859) ([Kruglov Pavel](https://github.com/Avogar)).
* Vues matérialisées actualisables. [#56946](https://github.com/ClickHouse/ClickHouse/pull/56946) ([Michael Kolupaev](https://github.com/al13n321)).
* Ajoute davantage d’avertissements concernant le nombre de databases et de tables. [#57375](https://github.com/ClickHouse/ClickHouse/pull/57375) ([凌涛](https://github.com/lingtaolf)).
* Ajout d’une nouvelle commande de mutation `ALTER TABLE <table> APPLY DELETED MASK`, qui permet de forcer l’application du masque écrit par lightweight delete et de supprimer du disque les lignes marquées comme supprimées. [#57433](https://github.com/ClickHouse/ClickHouse/pull/57433) ([Anton Popov](https://github.com/CurtizJ)).
* Ajout d’une nouvelle fonction SQL `sqid` pour générer des Sqids ([https://sqids.org/](https://sqids.org/)), exemple : `SELECT sqid(125, 126)`. [#57512](https://github.com/ClickHouse/ClickHouse/pull/57512) ([Robert Schulze](https://github.com/rschu1ze)).
* Le Dictionary avec le layout `HASHED_ARRAY` (et `COMPLEX_KEY_HASHED_ARRAY`) prend en charge `SHARDS`, comme `HASHED`. [#57544](https://github.com/ClickHouse/ClickHouse/pull/57544) ([vdimir](https://github.com/vdimir)).
* Ajoute des metrics asynchrones pour le nombre total d’octets de la primary key et le nombre total d’octets de primary key alloués en mémoire. [#57551](https://github.com/ClickHouse/ClickHouse/pull/57551) ([Bharat Nallan](https://github.com/bharatnc)).
* La table system.dropped&#95;tables&#95;parts contient les parts des tables de system.dropped&#95;tables (tables supprimées, mais pas encore retirées). [#57555](https://github.com/ClickHouse/ClickHouse/pull/57555) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Ajoute `FORMAT_BYTES` comme alias de `formatReadableSize`. [#57592](https://github.com/ClickHouse/ClickHouse/pull/57592) ([Bharat Nallan](https://github.com/bharatnc)).
* Ajoute la fonction SHA512&#95;256. [#57645](https://github.com/ClickHouse/ClickHouse/pull/57645) ([Bharat Nallan](https://github.com/bharatnc)).
* Permet de passer un SESSION&#95;TOKEN facultatif à la table function `s3`. [#57850](https://github.com/ClickHouse/ClickHouse/pull/57850) ([Shani Elharrar](https://github.com/shanielh)).
* La clause `ORDER BY` prend désormais en charge `ALL`, ce qui signifie que ClickHouse trie selon toutes les colonnes de la clause `SELECT`. Exemple : `SELECT col1, col2 FROM tab WHERE [...] ORDER BY ALL`. [#57875](https://github.com/ClickHouse/ClickHouse/pull/57875) ([zhongyuankai](https://github.com/zhongyuankai)).
* Ajout de fonctions d’encodage/décodage Punycode : `punycodeEncode()` et `punycodeDecode()`. [#57969](https://github.com/ClickHouse/ClickHouse/pull/57969) ([Robert Schulze](https://github.com/rschu1ze)).
* Cette PR reproduit l’implémentation de `PASTE JOIN`, qui permet aux utilisateurs de joindre des tables sans clause `ON`. Exemple : &#96;&#96;&#96; SQL SELECT * FROM ( SELECT number AS a FROM numbers(2) ) AS t1 PASTE JOIN ( SELECT number AS a FROM numbers(2) ORDER BY a DESC ) AS t2. [#57995](https://github.com/ClickHouse/ClickHouse/pull/57995) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Le gestionnaire `/binary` ouvre une vue visuelle des symboles contenus dans le binaire ClickHouse. [#58211](https://github.com/ClickHouse/ClickHouse/pull/58211) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="performance-improvement">
  #### Amélioration des performances
</div>

* La copie entre disques S3 s’effectue désormais via une copie S3 côté serveur au lieu de transiter par le tampon. Cela améliore les opérations `BACKUP/RESTORE` ainsi que la commande `clickhouse-disks copy`. [#56744](https://github.com/ClickHouse/ClickHouse/pull/56744) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* HashJoin respecte le paramètre `max_joined_block_size_rows` et ne produit pas de blocs trop volumineux pour `ALL JOIN`. [#56996](https://github.com/ClickHouse/ClickHouse/pull/56996) ([vdimir](https://github.com/vdimir)).
* Libération plus précoce de la mémoire pour l’agrégation. Cela peut éviter une agrégation externe inutile. [#57691](https://github.com/ClickHouse/ClickHouse/pull/57691) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Amélioration des performances de sérialisation des chaînes. [#57717](https://github.com/ClickHouse/ClickHouse/pull/57717) ([Maksim Kita](https://github.com/kitaisreal)).
* Prise en charge de l’optimisation du comptage trivial pour les tables utilisant le moteur `Merge`. [#57867](https://github.com/ClickHouse/ClickHouse/pull/57867) ([skyoct](https://github.com/skyoct)).
* Agrégation optimisée dans certains cas. [#57872](https://github.com/ClickHouse/ClickHouse/pull/57872) ([Anton Popov](https://github.com/CurtizJ)).
* La fonction `hasAny()` peut désormais tirer parti des index de saut de texte intégral. [#57878](https://github.com/ClickHouse/ClickHouse/pull/57878) ([Jpnock](https://github.com/Jpnock)).
* La fonction `if(cond, then, else)` (et son alias `cond ? : then : else`) a été optimisée pour utiliser une évaluation sans branchement. [#57885](https://github.com/ClickHouse/ClickHouse/pull/57885) ([zhanglistar](https://github.com/zhanglistar)).
* Extrait les plages de parts non intersectantes d’une table MergeTree pendant le traitement de FINAL. Cela permet d’éviter la logique FINAL supplémentaire pour ces plages de parts non intersectantes. Lorsque le nombre de valeurs dupliquées avec la même clé primaire est faible, les performances sont presque identiques à celles obtenues sans FINAL. Améliore les performances de lecture pour MergeTree FINAL lorsque le paramètre `do_not_merge_across_partitions_select_final` est défini. [#58120](https://github.com/ClickHouse/ClickHouse/pull/58120) ([Maksim Kita](https://github.com/kitaisreal)).
* MergeTree déduit automatiquement le paramètre `do_not_merge_across_partitions_select_final` si l’expression de clé de partition ne contient que des colonnes de l’expression de clé primaire. [#58218](https://github.com/ClickHouse/ClickHouse/pull/58218) ([Maksim Kita](https://github.com/kitaisreal)).
* Accélération de MIN et MAX pour les types natifs. [#58231](https://github.com/ClickHouse/ClickHouse/pull/58231) ([Raúl Marín](https://github.com/Algunenano)).
