<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bogues (dysfonctionnement visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#36635](https://github.com/ClickHouse/ClickHouse/issues/36635) : corrige l’exception `Missing column` susceptible de se produire lors de l’utilisation de `INTERPOLATE` avec une table `ENGINE = MergeTree`. [#36549](https://github.com/ClickHouse/ClickHouse/pull/36549) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#36794](https://github.com/ClickHouse/ClickHouse/issues/36794) : corrige les fusions verticales sur des wide parts. Auparavant, l’exception `There is no column` pouvait être levée pendant une fusion. [#36707](https://github.com/ClickHouse/ClickHouse/pull/36707) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#36926](https://github.com/ClickHouse/ClickHouse/issues/36926) : corrige un bogue dans ClickHouse Keeper pouvant entraîner la corruption de fichiers de log compressés en cas de faible charge et de redémarrages. [#36910](https://github.com/ClickHouse/ClickHouse/pull/36910) ([alesapin](https://github.com/alesapin)).
