<div id="clickhouse-release-v2010510-stable-fixme-as-compared-to-v201041-stable">
  ### Version de ClickHouse v20.10.5.10-stable FIXME par rapport à v20.10.4.1-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#17031](https://github.com/ClickHouse/ClickHouse/issues/17031) : permettre la connexion à l&#39;endpoint sécurisé de `clickhouse-server`, qui nécessite SNI. C&#39;est possible lorsque `clickhouse-server` est hébergé derrière un proxy TLS. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#17107](https://github.com/ClickHouse/ClickHouse/issues/17107) : corrige [#16574](https://github.com/ClickHouse/ClickHouse/issues/16574), corrige [#16231](https://github.com/ClickHouse/ClickHouse/issues/16231) et corrige l’échec des requêtes distantes lors de l’utilisation de la fonction d’agrégation avec suffixe &#39;if&#39;. [#16610](https://github.com/ClickHouse/ClickHouse/pull/16610) ([Winter Zhang](https://github.com/zhang2014)).
* Rétroporté dans [#17022](https://github.com/ClickHouse/ClickHouse/issues/17022) : corrige un plantage lors de l’utilisation de `any` sans argument. Ceci concerne [#16803](https://github.com/ClickHouse/ClickHouse/issues/16803). cc @azat. [#16826](https://github.com/ClickHouse/ClickHouse/pull/16826) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#16878](https://github.com/ClickHouse/ClickHouse/issues/16878) : interrompt le téléversement multipartite si aucune donnée n’a été écrite dans WriteBufferFromS3. [#16840](https://github.com/ClickHouse/ClickHouse/pull/16840) ([Pavel Kovalenko](https://github.com/Jokser)).
* Rétroporté dans [#16949](https://github.com/ClickHouse/ClickHouse/issues/16949) : empêche les plantages du serveur ClickHouse lors de l’utilisation de TimeSeriesGroupSum. [#16865](https://github.com/ClickHouse/ClickHouse/pull/16865) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17075](https://github.com/ClickHouse/ClickHouse/issues/17075) : corrige l’erreur possible `Illegal type of argument` pour les requêtes avec `ORDER BY`. Corrige [#16580](https://github.com/ClickHouse/ClickHouse/issues/16580). [#16928](https://github.com/ClickHouse/ClickHouse/pull/16928) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#17008](https://github.com/ClickHouse/ClickHouse/issues/17008) : le script d’installation doit toujours créer les sous-répertoires dans les dossiers de configuration. Cela ne concerne que le build Docker avec une configuration personnalisée. [#16936](https://github.com/ClickHouse/ClickHouse/pull/16936) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#16967](https://github.com/ClickHouse/ClickHouse/issues/16967) : les informations de blame n’étaient pas calculées correctement dans `clickhouse-git-import`. [#16959](https://github.com/ClickHouse/ClickHouse/pull/16959) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#17012](https://github.com/ClickHouse/ClickHouse/issues/17012) : corrige un possible plantage du serveur après `ALTER TABLE ... MODIFY COLUMN ... NewType` quand `SELECT` comporte une expression `WHERE` sur la colonne en cours de modification et que l’opération ALTER n’est pas encore terminée. [#16968](https://github.com/ClickHouse/ClickHouse/pull/16968) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#17038](https://github.com/ClickHouse/ClickHouse/issues/17038) : résout de nouveau l’adresse IP de `format_avro_schema_registry_url` en cas d’erreur. [#16985](https://github.com/ClickHouse/ClickHouse/pull/16985) ([filimonov](https://github.com/filimonov)).
* Rétroporté dans [#17092](https://github.com/ClickHouse/ClickHouse/issues/17092) : corrige un résultat erroné sur les entiers de grande taille (128 et 256 bits) lors d’une conversion depuis double. [#16986](https://github.com/ClickHouse/ClickHouse/pull/16986) ([Mike Kot](https://github.com/myrrc)).
* Rétroporté dans [#17169](https://github.com/ClickHouse/ClickHouse/issues/17169) : corrige un bogue où les requêtes `ON CLUSTER` peuvent rester bloquées indéfiniment pour les tables ReplicatedMergeTree non leaders. [#17089](https://github.com/ClickHouse/ClickHouse/pull/17089) ([alesapin](https://github.com/alesapin)).
