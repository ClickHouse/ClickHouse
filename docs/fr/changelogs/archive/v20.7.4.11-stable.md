<div id="clickhouse-release-v207411-stable-fixme-as-compared-to-v20737-stable">
  ### Version de ClickHouse v20.7.4.11-stable FIXME par rapport à v20.7.3.7-stable
</div>

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#15566](https://github.com/ClickHouse/ClickHouse/issues/15566) : il est désormais possible de modifier le type de la colonne de version de `VersionedCollapsingMergeTree` avec la requête `ALTER`. [#15442](https://github.com/ClickHouse/ClickHouse/pull/15442) ([alesapin](https://github.com/alesapin)).



<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#15019](https://github.com/ClickHouse/ClickHouse/issues/15019) : Correction de l'ordre de tri incorrect de la colonne `Nullable`. Corrige [#14344](https://github.com/ClickHouse/ClickHouse/issues/14344). [#14495](https://github.com/ClickHouse/ClickHouse/pull/14495) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

[#14783](https://github.com/ClickHouse/ClickHouse/pull/14783) ([Amos Bird](https://github.com/amosbird)).

Corrige [#14814](https://github.com/ClickHouse/ClickHouse/issues/14814). [#14843](https://github.com/ClickHouse/ClickHouse/pull/14843) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#15252](https://github.com/ClickHouse/ClickHouse/issues/15252) : Correction d'une erreur de segmentation dans CacheDictionary [#14837](https://github.com/ClickHouse/ClickHouse/issues/14837). [#14879](https://github.com/ClickHouse/ClickHouse/pull/14879) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#14988](https://github.com/ClickHouse/ClickHouse/issues/14988) : Publication des fréquences CPU par cœur logique dans `system.asynchronous_metrics`. Corrige [#14923](https://github.com/ClickHouse/ClickHouse/issues/14923). [#14924](https://github.com/ClickHouse/ClickHouse/pull/14924) ([Alexander Kuzmenkov](https://github.com/akuzm)).

Corrige [#14847](https://github.com/ClickHouse/ClickHouse/issues/14847). [#14937](https://github.com/ClickHouse/ClickHouse/pull/14937) ([filimonov](https://github.com/filimonov)).

[#14975](https://github.com/ClickHouse/ClickHouse/pull/14975) ([alesapin](https://github.com/alesapin)).

Ferme [#13926](https://github.com/ClickHouse/ClickHouse/issues/13926). [#15028](https://github.com/ClickHouse/ClickHouse/pull/15028) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
