<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#75311](https://github.com/ClickHouse/ClickHouse/issues/75311) : correction d’un crash lors de l’analyse de la déclaration du type JSON lorsque le nom du type n’est pas en majuscules. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#75253](https://github.com/ClickHouse/ClickHouse/issues/75253) : rétablit l’état d’une part de deleting à outdated lorsque l’opération de suppression a échoué. [#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* Rétroporté dans [#75409](https://github.com/ClickHouse/ClickHouse/issues/75409) : correction de l’utilisation des index (primary et secondary) pour les colonnes `Array`, `Map` et `Nullable(..)` avec le paramètre `optimize_function_to_subcolumns` activé. Auparavant, les index de ces colonnes pouvaient être ignorés. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#75461](https://github.com/ClickHouse/ClickHouse/issues/75461) : correction d’un bug de crash avec un CTE et Insert. [#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration du build/des tests/du packaging
</div>

* Rétroporté dans [#75291](https://github.com/ClickHouse/ClickHouse/issues/75291) : amélioration visant à rendre les valeurs par défaut encore plus restrictives. Les valeurs par défaut actuelles sont déjà sûres : l’utilisateur doit explicitement spécifier une option pour publier des ports. Toutefois, lorsque l’utilisateur `default` n’a pas de mot de passe défini via la variable d’environnement `CLICKHOUSE_PASSWORD` et/ou que son nom d’utilisateur n’est pas modifié via `CLICKHOUSE_USER`, il ne doit être accessible que depuis le système local, comme niveau de protection supplémentaire. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
