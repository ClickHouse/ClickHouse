<div id="bug-fix">
  #### Correction de bug
</div>

* Rétroporté dans [#32693](https://github.com/ClickHouse/ClickHouse/issues/32693) : la limite du quota n’était pas atteinte, mais elle était considérée comme dépassée. Cette PR corrige [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31656](https://github.com/ClickHouse/ClickHouse/pull/31656) ([sunny](https://github.com/sunny19930321)).

#### Correction de bugs (comportement incorrect visible par l’utilisateur dans une version stable officielle)

* Rétroporté dans [#32681](https://github.com/ClickHouse/ClickHouse/issues/32681) : corrige la suppression inattendue d’une projection lors du détachement de parts. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#32483](https://github.com/ClickHouse/ClickHouse/issues/32483) : corrige l’analyse syntaxique de `'APPLY lambda'`, qui pouvait entraîner un plantage du client ou du serveur. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#32542](https://github.com/ClickHouse/ClickHouse/issues/32542) : certaines entrées de la file de réplication peuvent rester bloquées pendant la durée de `temporary_directories_lifetime` (1 jour par défaut) avec `Directory tmp_merge_<part_name>` ou `Part ... (state Deleting) already exists, but it will be deleted soon`, ou une erreur similaire. Le problème est corrigé. Corrige [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32710](https://github.com/ClickHouse/ClickHouse/issues/32710) : corrige les échecs de requêtes qui tentent d’utiliser des index de saut qui ne sont pas encore matérialisés. Corrige [#32292](https://github.com/ClickHouse/ClickHouse/issues/32292) et [#30343](https://github.com/ClickHouse/ClickHouse/issues/30343). [#32359](https://github.com/ClickHouse/ClickHouse/pull/32359) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#32569](https://github.com/ClickHouse/ClickHouse/issues/32569) : corrige un plantage dans `JoinCommon::removeColumnNullability`, ferme [#32458](https://github.com/ClickHouse/ClickHouse/issues/32458). [#32508](https://github.com/ClickHouse/ClickHouse/pull/32508) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#32770](https://github.com/ClickHouse/ClickHouse/issues/32770) : corrige les performances du dictionnaire sparse&#95;hashed avec des clés séquentielles (mauvaise fonction de hachage). [#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#32634](https://github.com/ClickHouse/ClickHouse/issues/32634) : corrige la durée de vie d’une table (c.-à-d. un possible use-after-free) en cas de DROP TABLE et d’INSERT parallèles. [#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#32632](https://github.com/ClickHouse/ClickHouse/issues/32632) : corrige une exception possible au démarrage du stockage RabbitMQ en retardant la création du canal. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#32733](https://github.com/ClickHouse/ClickHouse/issues/32733) : corrige un code particulièrement mauvais dans la fonction `file`. [#32640](https://github.com/ClickHouse/ClickHouse/pull/32640) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#32793](https://github.com/ClickHouse/ClickHouse/issues/32793) : corrige un plantage lors de l’utilisation de fuzzBits avec plusieurs occurrences de la même `FixedString`, ferme [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737). [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
