<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#75640](https://github.com/ClickHouse/ClickHouse/issues/75640) : correction du message de log d’échec du script d’initialisation Docker pour le rendre plus clair. [#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* Rétroporté dans [#76227](https://github.com/ClickHouse/ClickHouse/issues/76227) : correction d’un crash dû à une exception non gérée dans la réplication PSQL. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#76101](https://github.com/ClickHouse/ClickHouse/issues/76101) : correction de la gestion null-safe de JOIN pour le type de données Nullable LowCardinality. Auparavant, JOIN ON avec une comparaison null-safe, telle que `IS NOT DISTINCT FROM`, `<=>`, `a IS NULL AND b IS NULL OR a == b`, ne fonctionnait pas correctement avec les colonnes LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Rétroporté dans [#75830](https://github.com/ClickHouse/ClickHouse/issues/75830) : correction d’un déréférencement de pointeur nul dans `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
