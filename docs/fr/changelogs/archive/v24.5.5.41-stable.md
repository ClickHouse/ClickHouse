<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#66768](https://github.com/ClickHouse/ClickHouse/issues/66768) : faire en sorte que `allow_experimental_analyzer` soit contrôlé par l’initiateur pour les requêtes distribuées. Cela garantit la compatibilité et la fiabilité des opérations dans des clusters exécutant des versions mixtes. [#65777](https://github.com/ClickHouse/ClickHouse/pull/65777) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

</div>

* Rétroporté dans [#65350](https://github.com/ClickHouse/ClickHouse/issues/65350) : correction d’un possible arrêt brutal sur exception non gérée dans ~WriteBufferFromFileDescriptor de StatusFile. [#64206](https://github.com/ClickHouse/ClickHouse/pull/64206) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#65621](https://github.com/ClickHouse/ClickHouse/issues/65621) : correction de `Cannot find column` dans une requête distribuée avec `ARRAY JOIN` sur une colonne `Nested`. Corrige [#64755](https://github.com/ClickHouse/ClickHouse/issues/64755). [#64801](https://github.com/ClickHouse/ClickHouse/pull/64801) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#67902](https://github.com/ClickHouse/ClickHouse/issues/67902) : correction de l’erreur `Not-ready Set` après l’optimisation `PREWHERE` pour StorageMerge. [#65057](https://github.com/ClickHouse/ClickHouse/pull/65057) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#66884](https://github.com/ClickHouse/ClickHouse/issues/66884) : correction d’une taille inattendue de colonne à faible cardinalité dans les appels de fonction. [#65298](https://github.com/ClickHouse/ClickHouse/pull/65298) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#65933](https://github.com/ClickHouse/ClickHouse/issues/65933) : pour les requêtes qui lisent depuis `PostgreSQL`, annulation de la requête `PostgreSQL` interne une fois la requête ClickHouse terminée. Sinon, la requête `ClickHouse` ne peut pas être annulée tant que la requête `PostgreSQL` interne n’est pas terminée. [#65771](https://github.com/ClickHouse/ClickHouse/pull/65771) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#66301](https://github.com/ClickHouse/ClickHouse/issues/66301) : meilleure gestion des conditions de jointure impliquant des vérifications `IS NULL` (par exemple, `ON (a = b AND (a IS NOT NULL) AND (b IS NOT NULL) ) OR ( (a IS NULL) AND (b IS NULL) )` est réécrit en `ON a <=> b`), avec correction d’une optimisation incorrecte lorsque des conditions autres que `IS NULL` sont présentes. [#65835](https://github.com/ClickHouse/ClickHouse/pull/65835) ([vdimir](https://github.com/vdimir)).
* Rétroporté dans [#66328](https://github.com/ClickHouse/ClickHouse/issues/66328) : ajout des paramètres manquants `input_format_csv_skip_first_lines/input_format_tsv_skip_first_lines/input_format_csv_try_infer_numbers_from_strings/input_format_csv_try_infer_strings_from_quoted_tuples` dans le cache d’inférence de schéma, car ils peuvent modifier le schéma résultant. Cela évite des résultats incorrects de l’inférence de schéma lorsque ces paramètres sont modifiés. [#65980](https://github.com/ClickHouse/ClickHouse/pull/65980) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#68252](https://github.com/ClickHouse/ClickHouse/issues/68252) : correction de `Not-ready Set` dans certaines tables système lors du filtrage avec des sous-requêtes. [#66018](https://github.com/ClickHouse/ClickHouse/pull/66018) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#66155](https://github.com/ClickHouse/ClickHouse/issues/66155) : correction d’un bug de dépassement de tampon dans l’implémentation de `unbin`/`unhex`. [#66106](https://github.com/ClickHouse/ClickHouse/pull/66106) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#66454](https://github.com/ClickHouse/ClickHouse/issues/66454) : correction d’un bug dans le client ZooKeeper : une session pouvait rester bloquée dans un état inutilisable après avoir reçu une erreur matérielle de ZooKeeper. Par exemple, cela peut se produire à cause de la &quot;soft memory limit&quot; dans ClickHouse Keeper. [#66140](https://github.com/ClickHouse/ClickHouse/pull/66140) ([Alexander Tokmakov](https://github.com/tavplubix)).

[#66237](https://github.com/ClickHouse/ClickHouse/pull/66237) ([filimonov](https://github.com/filimonov)).
