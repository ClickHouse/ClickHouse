  # Historique des modifications 2022

<div id="clickhouse-release-v213425-lts-fixme-as-compared-to-v213314-lts">
  ### Version ClickHouse v21.3.4.25-lts FIXME par rapport à la v21.3.3.14-lts

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#21928](https://github.com/ClickHouse/ClickHouse/issues/21928) : correction de l’analyse du format Avro pour Kafka. Corrige [#21437](https://github.com/ClickHouse/ClickHouse/issues/21437). [#21438](https://github.com/ClickHouse/ClickHouse/pull/21438) ([Ilya Golshtein](https://github.com/ilejn)).
* Rétroporté dans [#22089](https://github.com/ClickHouse/ClickHouse/issues/22089) : si une requête comporte une condition `WHERE` constante et que le paramètre `optimize_skip_unused_shards` est activé, tous les shards peuvent être ignorés et la requête peut renvoyer à tort un résultat vide. [#21550](https://github.com/ClickHouse/ClickHouse/pull/21550) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#21793](https://github.com/ClickHouse/ClickHouse/issues/21793) : `std::terminate` était appelé en cas d’erreur lors de l’écriture des données dans S3. [#21624](https://github.com/ClickHouse/ClickHouse/pull/21624) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#21746](https://github.com/ClickHouse/ClickHouse/issues/21746) : les connexions sont désormais acceptées seulement après l’initialisation de DDLWorker et des dictionnaires. [#21676](https://github.com/ClickHouse/ClickHouse/pull/21676) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21749](https://github.com/ClickHouse/ClickHouse/issues/21749) : correction des exécutions concurrentes de `OPTIMIZE` et `DROP` pour `ReplicatedMergeTree`. [#21716](https://github.com/ClickHouse/ClickHouse/pull/21716) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21878](https://github.com/ClickHouse/ClickHouse/issues/21878) : correction de plantages possibles dans les fonctions d’agrégation avec le combinateur Distinct lors de l’utilisation de l’agrégation à deux niveaux. Il s’agit d’un correctif complémentaire à [https://github.com/ClickHouse/ClickHouse/pull/18365](https://github.com/ClickHouse/ClickHouse/pull/18365) . Ne peut être reproduit qu’en environnement de production. Aucun cas de test n’est encore disponible. cc @CurtizJ. [#21818](https://github.com/ClickHouse/ClickHouse/pull/21818) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#22051](https://github.com/ClickHouse/ClickHouse/issues/22051) : correction d’un interblocage lors de la première exécution du modèle catboost. Clôt [#13832](https://github.com/ClickHouse/ClickHouse/issues/13832). [#21844](https://github.com/ClickHouse/ClickHouse/pull/21844) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#21993](https://github.com/ClickHouse/ClickHouse/issues/21993) : correction de résultats `ORDER BY` incorrects lorsqu’une requête contient des fonctions de fenêtre et que l’optimisation de lecture dans l’ordre de la clé primaire est appliquée. Corrige [#21828](https://github.com/ClickHouse/ClickHouse/issues/21828). [#21915](https://github.com/ClickHouse/ClickHouse/pull/21915) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Rétroporté dans [#22180](https://github.com/ClickHouse/ClickHouse/issues/22180) : correction de la lecture d’une requête HTTP POST avec le type de contenu &quot;multipart/form-data&quot;. [#21936](https://github.com/ClickHouse/ClickHouse/pull/21936) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#21982](https://github.com/ClickHouse/ClickHouse/issues/21982) : empêche le chevauchement des connexions hedged (erreur `Unknown packet 9 from server`). [#21941](https://github.com/ClickHouse/ClickHouse/pull/21941) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#21980](https://github.com/ClickHouse/ClickHouse/issues/21980) : annulation de [#15454](https://github.com/ClickHouse/ClickHouse/issues/15454), qui peut entraîner une augmentation significative de l’utilisation de la mémoire lors du chargement de dictionnaires externes de type hashed. Clôt [#21935](https://github.com/ClickHouse/ClickHouse/issues/21935). [#21948](https://github.com/ClickHouse/ClickHouse/pull/21948) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#22139](https://github.com/ClickHouse/ClickHouse/issues/22139) : la fonction `decrypt` ne vérifiait pas la taille minimale des données chiffrées en mode AEAD. Cela clôt [#21897](https://github.com/ClickHouse/ClickHouse/issues/21897). [#22064](https://github.com/ClickHouse/ClickHouse/pull/22064) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#22185](https://github.com/ClickHouse/ClickHouse/issues/22185) : correction d’une exception non gérée dans InterserverIOHTTPHandler. [#22146](https://github.com/ClickHouse/ClickHouse/pull/22146) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#22205](https://github.com/ClickHouse/ClickHouse/issues/22205) : utilisation de finalize() plutôt que de next() pour les writers imbriqués. [#22147](https://github.com/ClickHouse/ClickHouse/pull/22147) ([Azat Khuzhin](https://github.com/azat)).
