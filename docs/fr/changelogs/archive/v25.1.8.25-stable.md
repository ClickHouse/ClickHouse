<div id="new-feature">
  #### Nouvelle fonctionnalité
</div>

* Rétroporté dans [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357) : ajout du paramètre serveur `concurrent_threads_scheduler`, qui régit la manière dont les slots CPU sont répartis entre les requêtes concurrentes. Il peut être défini sur `round_robin` (comportement précédent) ou `fair_round_robin` afin de corriger le problème de répartition inéquitable du CPU entre les INSERT et les SELECT. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#77202](https://github.com/ClickHouse/ClickHouse/issues/77202) : auparavant, la base de données Replicated pouvait afficher dans les logs les identifiants spécifiés dans une requête. Ce comportement a été corrigé. Clôt : [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123). [#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#76151](https://github.com/ClickHouse/ClickHouse/issues/76151) : propagation des paramètres de formatage au formatage des chaînes JSON dans le Native format. [#75832](https://github.com/ClickHouse/ClickHouse/pull/75832) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#76968](https://github.com/ClickHouse/ClickHouse/issues/76968) : correction de l’exception THERE&#95;IS&#95;NO&#95;COLUMN lors de la sélection d’un littéral booléen depuis des tables distribuées. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Rétroporté dans [#77256](https://github.com/ClickHouse/ClickHouse/issues/77256) : correction d’un plantage possible dû à un rollback incorrect de colonne JSON en cas d’erreur pendant les async inserts. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#77220](https://github.com/ClickHouse/ClickHouse/issues/77220) : correction d’un bogue lié au JSON avec sous-colonne Variant par l’ajout d’une vérification permettant d’ignorer les sous-colonnes éphémères dans la vérification de cohérence des parts. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Rétroporté dans [#77248](https://github.com/ClickHouse/ClickHouse/issues/77248) : correction d’un plantage lors de la création d’une table Kafka avec une exception. [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* Rétroporté dans [#77384](https://github.com/ClickHouse/ClickHouse/issues/77384) : `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` renvoie désormais correctement `true` (au lieu de `false` auparavant). Le comportement est ainsi cohérent avec `Float32` et `Float64`. [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Rétroporté dans [#77333](https://github.com/ClickHouse/ClickHouse/issues/77333) : correction de la comparaison entre des tuples contenant des éléments Nullable et des chaînes. [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
