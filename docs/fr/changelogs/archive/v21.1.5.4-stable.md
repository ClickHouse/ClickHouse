  ### Version ClickHouse v21.1.5.4-stable FIXME par rapport à la v21.1.4.46-stable

<div id="bug-fix">
  #### Correction de bugs
</div>

* Rétroporté dans [#20678](https://github.com/ClickHouse/ClickHouse/issues/20678) : marquer le batch distribué comme défectueux en cas de bloc de données vide dans l&#39;un des fichiers. [#19449](https://github.com/ClickHouse/ClickHouse/pull/19449) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20646](https://github.com/ClickHouse/ClickHouse/issues/20646) : la fonction `greatCircleAngle` renvoyait des résultats inexacts dans les versions précédentes. Cela clôt [#19769](https://github.com/ClickHouse/ClickHouse/issues/19769). [#19789](https://github.com/ClickHouse/ClickHouse/pull/19789) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#20507](https://github.com/ClickHouse/ClickHouse/issues/20507) : correction du comportement qui, en cas de JSON corrompu, tentait de lire le fichier entier en mémoire, ce qui entraînait une exception de l’allocateur. Corrige [#19719](https://github.com/ClickHouse/ClickHouse/issues/19719). [#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#20618](https://github.com/ClickHouse/ClickHouse/issues/20618) : vérifier si la fonction de table `view` est utilisée dans la liste d’expressions et lever une erreur. Cela corrige [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342). [#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#20488](https://github.com/ClickHouse/ClickHouse/issues/20488) : correction de `LOGICAL_ERROR` pour `join_use_nulls=1` lorsque JOIN contient une constante de SELECT. [#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#20886](https://github.com/ClickHouse/ClickHouse/issues/20886) : correction d’une sous-requête avec UNION DISTINCT et clause LIMIT. Clôt [#20597](https://github.com/ClickHouse/ClickHouse/issues/20597). [#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#20992](https://github.com/ClickHouse/ClickHouse/issues/20992) : correction de l’utilisation du combinator `-Distinct` avec le combinator `-State` dans les fonctions d’agrégation. [#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#20988](https://github.com/ClickHouse/ClickHouse/issues/20988) : la requête `USE database;` ne fonctionnait pas lors de l’utilisation du client MySQL 5.7 pour se connecter au serveur ClickHouse ; c’est corrigé. Corrige [#18926](https://github.com/ClickHouse/ClickHouse/issues/18926). [#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)).
