* Rétroporté dans [#43829](https://github.com/ClickHouse/ClickHouse/issues/43829) : normaliseur mis à jour pour cloner l’AST de l’alias. Résout [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452). Implémentation : * QueryNormalizer a été mis à jour pour cloner l’AST de l’alias lorsqu’il est remplacé. Auparavant, le simple fait de réassigner le même provoquait une exception dans LogicalExpressinsOptimizer, car le même parent était inséré à nouveau. * Ce bogue ne se manifeste pas avec le nouvel analyseur (`allow_experimental_analyzer`), donc aucun changement n’a été apporté de ce côté. J’ai ajouté un test correspondant. [#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
