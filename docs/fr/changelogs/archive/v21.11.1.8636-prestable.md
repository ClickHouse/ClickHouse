<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions précédentes
</div>

* Désormais, les snapshots de ClickHouse Keeper sont compressés par défaut avec le codec `ZSTD`, au lieu de la compression par blocks LZ4 personnalisée de ClickHouse. Ce comportement peut être désactivé avec le paramètre de coordination `compress_snapshots_with_zstd_format` (il doit être identique sur toutes les répliques du quorum). Cette incompatibilité descendante est assez rare et ne peut se produire que lorsqu&#39;un nouveau node envoie un snapshot (ce qui se produit en cas de recovery) à un ancien node, qui n&#39;est pas capable de lire les snapshots au format ZSTD. [#29417](https://github.com/ClickHouse/ClickHouse/pull/29417) ([alesapin](https://github.com/alesapin)).
* La fonction `bayesAB` a été supprimée. Cela clôt [#26233](https://github.com/ClickHouse/ClickHouse/issues/26233). [#29934](https://github.com/ClickHouse/ClickHouse/pull/29934) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Suppression du paramètre de table MergeTree `write_final_mark`. Il sera toujours à `true`. [#30455](https://github.com/ClickHouse/ClickHouse/pull/30455) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Modification de l&#39;ordre de json&#95;path et json dans la fonction SQL json (afin qu&#39;il soit correct). Clôt [#30449](https://github.com/ClickHouse/ClickHouse/issues/30449). [#30474](https://github.com/ClickHouse/ClickHouse/pull/30474) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Suppression du paramètre odbc&#95;max&#95;field&#95;size, car il n&#39;est plus utilisé. Clôt [#30413](https://github.com/ClickHouse/ClickHouse/issues/30413). [#30778](https://github.com/ClickHouse/ClickHouse/pull/30778) ([Kseniia Sumarokova](https://github.com/kssenii)).
