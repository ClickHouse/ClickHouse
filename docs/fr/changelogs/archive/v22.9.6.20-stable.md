<div id="backward-incompatible-change">
  #### Changement incompatible avec les versions antérieures
</div>

* Rétroporté dans [#43486](https://github.com/ClickHouse/ClickHouse/issues/43486) : correction d&#39;une rupture de compatibilité dans la (dé)sérialisation des états des fonctions d&#39;agrégation `min`, `max`, `any*`, `argMin`, `argMax` avec un argument `String`. L&#39;incompatibilité a été introduite dans [https://github.com/ClickHouse/ClickHouse/pull/41431](https://github.com/ClickHouse/ClickHouse/pull/41431) et affecte les branches 22.9, 22.10 et 22.11 (corrigé respectivement à partir de 22.9.6, 22.10.4 et 22.11.2). Certaines versions mineures des branches 22.3, 22.7 et 22.8 sont également affectées : 22.3.13...22.3.14 (corrigé à partir de 22.3.15), 22.8.6...22.8.9 (corrigé à partir de 22.8.10), 22.7.6 et ultérieures (ne sera pas corrigé dans la branche 22.7 ; nous recommandons de passer de 22.7.* à 22.8.10 ou à une version ultérieure). Cette note de version ne concerne pas les utilisateurs qui n&#39;ont jamais utilisé les versions affectées. Les versions incompatibles ajoutent un `'\0'` supplémentaire aux chaînes lors de la lecture des états des fonctions d&#39;agrégation mentionnées ci-dessus. Par exemple, si une ancienne version a enregistré l&#39;état de `anyState('foobar')` dans `state_column`, une version incompatible affichera alors `'foobar\0'` avec `anyMerge(state_column)`. Les versions incompatibles écrivent également les états des fonctions d&#39;agrégation sans le `'\0'` final. Les versions plus récentes (celles qui incluent le correctif) peuvent lire correctement les données écrites par toutes les versions, y compris les versions incompatibles, sauf dans un cas limite. Si une version incompatible a enregistré un état avec une chaîne qui se termine réellement par un caractère nul, une version plus récente supprimera alors le `'\0'` final lors de la lecture de l&#39;état de la fonction d&#39;agrégation affectée. Par exemple, si une version incompatible a enregistré l&#39;état de `anyState('abrac\0dabra\0')` dans `state_column`, les versions incompatibles afficheront alors `'abrac\0dabra'` avec `anyMerge(state_column)`. Le problème affecte également les requêtes distribuées lorsqu&#39;une version incompatible fonctionne dans un cluster avec des versions plus anciennes ou plus récentes. [#43038](https://github.com/ClickHouse/ClickHouse/pull/43038) ([Raúl Marín](https://github.com/Algunenano)).
