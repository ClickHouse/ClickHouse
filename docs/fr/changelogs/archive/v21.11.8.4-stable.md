<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Correction de bug (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#32679](https://github.com/ClickHouse/ClickHouse/issues/32679) : corrige la suppression inattendue d’une projection lors du détachement de parts. [#32067](https://github.com/ClickHouse/ClickHouse/pull/32067) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#32543](https://github.com/ClickHouse/ClickHouse/issues/32543) : certaines entrées de la replication queue pouvaient rester bloquées pendant `temporary_directories_lifetime` (1 jour par défaut), avec une erreur du type `Directory tmp_merge_<part_name>` ou `Part ... (state Deleting) already exists, but it will be deleted soon`, ou similaire. C’est corrigé. Corrige [#29616](https://github.com/ClickHouse/ClickHouse/issues/29616). [#32201](https://github.com/ClickHouse/ClickHouse/pull/32201) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32769](https://github.com/ClickHouse/ClickHouse/issues/32769) : corrige les performances du dictionnaire sparse&#95;hashed avec des clés séquentielles (mauvaise fonction de hachage). [#32536](https://github.com/ClickHouse/ClickHouse/pull/32536) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#32635](https://github.com/ClickHouse/ClickHouse/issues/32635) : corrige la durée de vie d’une table (c.-à-d. un possible use-after-free) en cas de DROP TABLE et d’INSERT parallèles. [#32572](https://github.com/ClickHouse/ClickHouse/pull/32572) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#32633](https://github.com/ClickHouse/ClickHouse/issues/32633) : corrige une exception possible au démarrage du moteur de stockage RabbitMQ en retardant la création du canal. [#32584](https://github.com/ClickHouse/ClickHouse/pull/32584) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#32891](https://github.com/ClickHouse/ClickHouse/issues/32891) : corrige LOGICAL&#95;ERROR lorsque la cible d’une materialized view est un JOIN ou une table SET. [#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* Rétroporté dans [#32792](https://github.com/ClickHouse/ClickHouse/issues/32792) : corrige un crash lors de l’utilisation de fuzzBits avec plusieurs occurrences de la même FixedString, ferme [#32737](https://github.com/ClickHouse/ClickHouse/issues/32737). [#32755](https://github.com/ClickHouse/ClickHouse/pull/32755) ([SuperDJY](https://github.com/cmsxbc)).
