* rétroporté dans [#36525](https://github.com/ClickHouse/ClickHouse/issues/36525) : les requêtes contenant des alias dans des opérateurs spéciaux renvoyaient une erreur d’analyse syntaxique (ce problème affectait la version 22.1). Exemple : `SELECT substring('test' AS t, 1, 1)`. [#36167](https://github.com/ClickHouse/ClickHouse/pull/36167) ([Maksim Kita](https://github.com/kitaisreal)).
* rétroporté dans [#36674](https://github.com/ClickHouse/ClickHouse/issues/36674) : corrige les merges de wide parts avec le type `Object`. [#36637](https://github.com/ClickHouse/ClickHouse/pull/36637) ([Anton Popov](https://github.com/CurtizJ)).
