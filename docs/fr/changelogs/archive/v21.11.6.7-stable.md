  # Journal des changements 2022

<div id="clickhouse-release-v211167-stable-fixme-as-compared-to-v2111533-stable">
  ### Version de ClickHouse v21.11.6.7-stable FIXME par rapport à v21.11.5.33-stable
</div>

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#32254](https://github.com/ClickHouse/ClickHouse/issues/32254) : correction d’un problème où certaines colonnes étaient ignorées lors de l’écriture en Protobuf. Cette PR corrige [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160), voir le commentaire [#31160](https://github.com/ClickHouse/ClickHouse/issues/31160)#issuecomment-980595318. [#31988](https://github.com/ClickHouse/ClickHouse/pull/31988) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#32345](https://github.com/ClickHouse/ClickHouse/issues/32345) : correction d’un bogue lors de la suppression de colonnes inutiles dans une sous-requête. S’il y a une fonction d’agrégation dans une requête sans group by, ne pas la supprimer même si elle est inutile. [#32289](https://github.com/ClickHouse/ClickHouse/pull/32289) ([dongyifeng](https://github.com/dyf6372)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Corrections de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#32152](https://github.com/ClickHouse/ClickHouse/issues/32152) : corrige un crash lorsque la fonction `dictGet` avec un type est utilisée sur un attribut de dictionnaire dont le type est `Nullable`. Corrige [#30980](https://github.com/ClickHouse/ClickHouse/issues/30980). [#31800](https://github.com/ClickHouse/ClickHouse/pull/31800) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32298](https://github.com/ClickHouse/ClickHouse/issues/32298) : corrige un crash des fonctions récursives définies par l’utilisateur. Clôt [#30856](https://github.com/ClickHouse/ClickHouse/issues/30856). [#31820](https://github.com/ClickHouse/ClickHouse/pull/31820) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32148](https://github.com/ClickHouse/ClickHouse/issues/32148) : corrige l’erreur `Directory ... already exists and is not empty` lors du détachement d’une part. [#32063](https://github.com/ClickHouse/ClickHouse/pull/32063) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32212](https://github.com/ClickHouse/ClickHouse/issues/32212) : corrige `CAST` depuis `Nullable` avec `cast_keep_nullable` (erreur `PARAMETER_OUT_OF_BOUND` auparavant, par exemple pour `toUInt32OrDefault(toNullable(toUInt32(1)))`). [#32080](https://github.com/ClickHouse/ClickHouse/pull/32080) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#32283](https://github.com/ClickHouse/ClickHouse/issues/32283) : Dictionaries corrige les cas où `{condition}` ne fonctionne pas pour les requêtes de base de données personnalisées. [#32117](https://github.com/ClickHouse/ClickHouse/pull/32117) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32482](https://github.com/ClickHouse/ClickHouse/issues/32482) : corrige l’analyse de `APPLY lambda`, qui pouvait provoquer un crash du client ou du server. [#32138](https://github.com/ClickHouse/ClickHouse/pull/32138) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#32217](https://github.com/ClickHouse/ClickHouse/issues/32217) : le nombre de répliques actives pouvait être déterminé de façon incorrecte lors d’une insertion avec quorum si le paramètre `replicated_can_become_leader` est désactivé sur certaines répliques. Le problème est corrigé. [#32157](https://github.com/ClickHouse/ClickHouse/pull/32157) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32311](https://github.com/ClickHouse/ClickHouse/issues/32311) : les identifiants des dictionnaires XML, utilisés dans une requête CREATE TABLE, peuvent être qualifiés par `default_database` lors d’une mise à niveau vers une version plus récente. Clôt [#31963](https://github.com/ClickHouse/ClickHouse/issues/31963). [#32187](https://github.com/ClickHouse/ClickHouse/pull/32187) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#32354](https://github.com/ClickHouse/ClickHouse/issues/32354) : corrige un crash avec SIGFPE dans la fonction d’agrégation `avgWeighted` avec un argument `Decimal`. Corrige [#32053](https://github.com/ClickHouse/ClickHouse/issues/32053). [#32303](https://github.com/ClickHouse/ClickHouse/pull/32303) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#32392](https://github.com/ClickHouse/ClickHouse/issues/32392) : corrige les requêtes `ALTER ... MATERIALIZE COLUMN ...` lorsque le type de données de l’expression par défaut n’est pas égal au type de données de la colonne. [#32348](https://github.com/ClickHouse/ClickHouse/pull/32348) ([Anton Popov](https://github.com/CurtizJ)).
* Rétroporté dans [#32418](https://github.com/ClickHouse/ClickHouse/issues/32418) : corrige le cas où des mutations sans opération à effectuer restent bloquées (avec le paramètre `empty_result_for_aggregation_by_empty_set` activé). [#32358](https://github.com/ClickHouse/ClickHouse/pull/32358) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
