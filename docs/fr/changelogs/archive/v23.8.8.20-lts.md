<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#56509](https://github.com/ClickHouse/ClickHouse/issues/56509) : autoriser la sauvegarde d’une vue matérialisée dont la table interne a été supprimée, au lieu de faire échouer la sauvegarde. [#56387](https://github.com/ClickHouse/ClickHouse/pull/56387) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Rétroporté dans [#56929](https://github.com/ClickHouse/ClickHouse/issues/56929) : une vulnérabilité potentielle existait dans les versions précédentes de ClickHouse : si un utilisateur s’était connecté et avait tenté sans succès de s’authentifier avec la méthode du « secret interserveur », le serveur ne fermait pas immédiatement la connexion, mais continuait à recevoir et à ignorer les paquets restants du client. Bien que ces paquets soient ignorés, ils sont tout de même analysés et, s’ils utilisent une méthode de compression affectée par une autre vulnérabilité connue, cela permet de l’exploiter sans authentification. Ce problème a été découvert dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par [https://twitter.com/malacupa](https://twitter.com/malacupa). [#56794](https://github.com/ClickHouse/ClickHouse/pull/56794) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="buildtestingpackaging-improvement">
  #### Amélioration de la compilation/des tests/du packaging
</div>

* Rétroporté dans [#57020](https://github.com/ClickHouse/ClickHouse/issues/57020) : une tentative avait été faite pour obtenir la liste correcte dans [#44311](https://github.com/ClickHouse/ClickHouse/issues/44311), mais le correctif lui-même se trouvait au mauvais endroit, donc le problème persiste. Voir un [exemple](https://github.com/ClickHouse/ClickHouse/actions/runs/6897342568/job/18781001022#step:8:25). [#56989](https://github.com/ClickHouse/ClickHouse/pull/56989) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Correction de bogue (anomalie visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#57111](https://github.com/ClickHouse/ClickHouse/issues/57111) : correction des requêtes ON CLUSTER lorsque la base de données n’est pas présente sur un nœud initial. Résout [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009). [#56484](https://github.com/ClickHouse/ClickHouse/pull/56484) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#57169](https://github.com/ClickHouse/ClickHouse/issues/57169) : correction d’un plantage dû à un débordement de tampon lors de la décompression de données malformées avec le codec `Gorilla`. Ce problème a été identifié dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par [https://twitter.com/malacupa](https://twitter.com/malacupa). [#57107](https://github.com/ClickHouse/ClickHouse/pull/57107) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rétroporté dans [#57175](https://github.com/ClickHouse/ClickHouse/issues/57175) : fermeture de la connexion interserveur en cas d’exception survenant avant l’authentification. Ce problème a été identifié dans le cadre du [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) par [https://twitter.com/malacupa](https://twitter.com/malacupa). [#57142](https://github.com/ClickHouse/ClickHouse/pull/57142) ([Antonio Andelic](https://github.com/antonio2368)).
