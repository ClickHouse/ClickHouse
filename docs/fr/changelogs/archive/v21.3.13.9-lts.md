  ### Release ClickHouse v21.3.13.9-lts FIXME par rapport à v21.3.12.2-lts

<div id="improvement">
  #### Amélioration
</div>

[#24545](https://github.com/ClickHouse/ClickHouse/pull/24545) ([nvartolomei](https://github.com/nvartolomei)).



<div id="bug-fix">
  #### Correction de bogue
</div>

* Rétroporté dans [#25567](https://github.com/ClickHouse/ClickHouse/issues/25567) : Le stockage Kafka peut désormais prendre en charge les messages au format Parquet. [#23412](https://github.com/ClickHouse/ClickHouse/pull/23412) ([Chao Ma](https://github.com/godliness)).
* Rétroporté dans [#24554](https://github.com/ClickHouse/ClickHouse/issues/24554) : Correction d'une défaillance du serveur lors de l'insertion de données via HTTP provoquant une exception. Corrige [#23512](https://github.com/ClickHouse/ClickHouse/issues/23512). [#23643](https://github.com/ClickHouse/ClickHouse/pull/23643) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#23833](https://github.com/ClickHouse/ClickHouse/issues/23833) : Correction de l'erreur `Can't initialize pipeline with empty pipe` pour les requêtes utilisant `GLOBAL IN/JOIN` et `use_hedged_requests`. Corrige [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431). [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#24703](https://github.com/ClickHouse/ClickHouse/issues/24703) : Prise en charge des en-têtes HTTP vides. Corrige [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901). [#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#24702](https://github.com/ClickHouse/ClickHouse/issues/24702) : Correction de la suppression de partition en présence de parties fictives qui se chevauchent. Dans de rares cas, il peut exister des parties dont la version de mutation est supérieure au numéro de bloc courant. [#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#24725](https://github.com/ClickHouse/ClickHouse/issues/24725) : Dans les messages « multipart/form-data », le CRLF précédant une limite est désormais considéré comme faisant partie de celle-ci. Corrige [#23905](https://github.com/ClickHouse/ClickHouse/issues/23905). [#24399](https://github.com/ClickHouse/ClickHouse/pull/24399) ([Ivan](https://github.com/abyss7)).
* Rétroporté dans [#24826](https://github.com/ClickHouse/ClickHouse/issues/24826) : - Correction d'un interblocage pouvant survenir lors du (re)mappage de rôle LDAP, lorsqu'un groupe LDAP est associé à un rôle local inexistant. [#24431](https://github.com/ClickHouse/ClickHouse/pull/24431) ([Denis Glazachev](https://github.com/traceon)).
* Rétroporté dans [#25566](https://github.com/ClickHouse/ClickHouse/issues/25566) : Correction de la monotonie incorrecte de la fonction toWeek. Corrige [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422). Ce bogue avait été introduit dans https://github.com/ClickHouse/ClickHouse/pull/5212 et a été mis en évidence ultérieurement par un élagage de partition plus intelligent. [#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#24700](https://github.com/ClickHouse/ClickHouse/issues/24700) : Correction du comportement où les requêtes `SYSTEM RESTART REPLICA` ou `SYSTEM SYNC REPLICA` s'exécutaient indéfiniment. Ce problème avait été détecté sur un serveur disposant d'une quantité de RAM extrêmement faible. [#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Rétroporté dans [#24698](https://github.com/ClickHouse/ClickHouse/issues/24698) : Activation de la lecture des sous-colonnes pour les tables distribuées. [#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
* Correction d'un problème de délai d'expiration de connexion sur le pont JDBC distant. Ferme [#9609](https://github.com/ClickHouse/ClickHouse/issues/9609). [#24588](https://github.com/ClickHouse/ClickHouse/pull/24588) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#24771](https://github.com/ClickHouse/ClickHouse/issues/24771) : Correction d'un bogue pouvant entraîner le blocage du client ZooKeeper au sein de clickhouse-server. [#24721](https://github.com/ClickHouse/ClickHouse/pull/24721) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#24934](https://github.com/ClickHouse/ClickHouse/issues/24934) : - Si la connexion à ZooKeeper était perdue et que le réplica était cloné après le rétablissement de la connexion, sa file de réplication pouvait contenir des entrées obsolètes. Ce problème est corrigé. - Correction d'un crash survenant lorsque la file de réplication contient des parties virtuelles qui se chevauchent. Cela peut rarement se produire si une partie de données est perdue. L'erreur est désormais consignée dans le journal au lieu de provoquer une terminaison du processus. [#24777](https://github.com/ClickHouse/ClickHouse/pull/24777) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#24850](https://github.com/ClickHouse/ClickHouse/issues/24850) : Correction d'un bogue où l'exception `Mutation was killed` pouvait être renvoyée au client lors de l'attente d'une mutation pas encore chargée en mémoire. [#24809](https://github.com/ClickHouse/ClickHouse/pull/24809) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#24917](https://github.com/ClickHouse/ClickHouse/issues/24917) : Correction d'un bogue extrêmement rare sur les serveurs à faible mémoire pouvant rendre impossible l'exécution de fusions sans redémarrage. Corrige probablement [#24603](https://github.com/ClickHouse/ClickHouse/issues/24603). [#24872](https://github.com/ClickHouse/ClickHouse/pull/24872) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#25185](https://github.com/ClickHouse/ClickHouse/issues/25185) : Correction d'un bogue lors de la déclaration d'un disque S3 à la racine d'un bucket. Auparavant, l'erreur suivante était signalée : ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):. [#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Rétroporté dans [#24949](https://github.com/ClickHouse/ClickHouse/issues/24949) : Correction d'un possible dépassement de tampon de tas dans Arrow. [#24922](https://github.com/ClickHouse/ClickHouse/pull/24922) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#25562](https://github.com/ClickHouse/ClickHouse/issues/25562) : Correction d'une erreur extrêmement rare `Tagging already tagged part` dans la file de réplication lors d'une opération `alter move/replace partition` concurrente. Corrige probablement [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142). [#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#25367](https://github.com/ClickHouse/ClickHouse/issues/25367) : Correction de la sérialisation des messages imbriqués fractionnés au format Protobuf. Cette PR corrige [#24647](https://github.com/ClickHouse/ClickHouse/issues/24647). [#25000](https://github.com/ClickHouse/ClickHouse/pull/25000) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#25561](https://github.com/ClickHouse/ClickHouse/issues/25561) : Correction d'un bogue permettant la création de tables avec des colonnes se référençant elles-mêmes, comme `a UInt32 ALIAS a + 1` ou `b UInt32 MATERIALIZED b`. Corrige [#24910](https://github.com/ClickHouse/ClickHouse/issues/24910), [#24292](https://github.com/ClickHouse/ClickHouse/issues/24292). [#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#25105](https://github.com/ClickHouse/ClickHouse/issues/25105) : Correction d'un bogue avec les maps constantes dans mapContains qui entraînait l'erreur `empty column was returned by function mapContains`. Clôture [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077). [#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#25142](https://github.com/ClickHouse/ClickHouse/issues/25142) : Correction d'un crash dans une requête avec cross join et `joined_subquery_requires_alias = 0`. Corrige [#24011](https://github.com/ClickHouse/ClickHouse/issues/24011). [#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25351](https://github.com/ClickHouse/ClickHouse/issues/25351) : Correction d'une erreur TOCTOU dans le script d'installation. [#25277](https://github.com/ClickHouse/ClickHouse/pull/25277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#25473](https://github.com/ClickHouse/ClickHouse/issues/25473) : Correction de joinGetOrNull avec des colonnes non nullables. Corrige [#24261](https://github.com/ClickHouse/ClickHouse/issues/24261). [#25288](https://github.com/ClickHouse/ClickHouse/pull/25288) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#25361](https://github.com/ClickHouse/ClickHouse/issues/25361) : Correction de l'erreur `Bad cast from type DB::ColumnLowCardinality to DB::ColumnVector<char8_t>` pour les requêtes où un argument `LowCardinality` était utilisé avec IN (ce bogue est apparu dans la version 21.6). Corrige [#25187](https://github.com/ClickHouse/ClickHouse/issues/25187). [#25290](https://github.com/ClickHouse/ClickHouse/pull/25290) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#25355](https://github.com/ClickHouse/ClickHouse/issues/25355) : Correction d'une erreur logique empêchant la sommation de Array/Tuple dans min/maxMap. [#25298](https://github.com/ClickHouse/ClickHouse/pull/25298) ([Kruglov Pavel](https://github.com/Avogar)).
* Rétroporté dans [#25437](https://github.com/ClickHouse/ClickHouse/issues/25437) : Prise en charge de `SimpleAggregateFunction(LowCardinality)` pour `SummingMergeTree`. * Rétroporté dans [#25364](https://github.com/ClickHouse/ClickHouse/issues/25364) : En cas de perte de connexion à ZooKeeper, la table `ReplicatedMergeTree` pouvait attendre la fin des opérations en arrière-plan avant de tenter une reconnexion. Ce problème est corrigé ; les opérations en arrière-plan sont désormais interrompues de force. [#25306](https://github.com/ClickHouse/ClickHouse/pull/25306) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#25387](https://github.com/ClickHouse/ClickHouse/issues/25387) : Correction d'un comportement potentiellement non déterministe de la fonction `quantileDeterministic` et des fonctions similaires.
