* Rétroporté dans [#46979](https://github.com/ClickHouse/ClickHouse/issues/46979) : appliquer `ALTER TABLE table_name ON CLUSTER cluster MOVE PARTITION|PART partition_expr TO DISK|VOLUME 'disk_name'` sur toutes les répliques.
