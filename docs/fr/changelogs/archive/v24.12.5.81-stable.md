<div id="performance-improvement">
  #### Amélioration des performances
</div>

* Rétroporté dans [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534) : correction du calcul de la taille en mémoire des colonnes `LowCardinality`. [#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005) : il a été constaté que le contrôle de la concurrence pouvait entraîner une répartition inéquitable du CPU entre les INSERT et les SELECT. Lorsque tous les CPU slots sont attribués de manière inconditionnelle (sans concurrence) à des INSERT avec `max_threads` = 1, les SELECT avec des valeurs élevées de `max_threads` subissent de mauvaises performances, car ils n’utilisent qu’un seul thread. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Amélioration
</div>

* Rétroporté dans [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535) : comptabilisation plus précise du paramètre `max_joined_block_size_rows` pour l’algorithme de JOIN `parallel_hash`. Cela permet d’éviter une consommation mémoire plus élevée qu’avec l’algorithme `hash`. [#74630](https://github.com/ClickHouse/ClickHouse/pull/74630) ([Nikita Taranov](https://github.com/nickitat)).
* Rétroporté dans [#75844](https://github.com/ClickHouse/ClickHouse/issues/75844) : ajout d’une vérification et de la journalisation pour le déchiffrement et la décompression. [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#76046](https://github.com/ClickHouse/ClickHouse/issues/76046) : amélioration de Keeper : désactivation du calcul du digest lors du commit vers le stockage en mémoire afin d’améliorer les performances. Il peut être activé via la config `keeper_server.digest_enabled_on_commit`. Le digest est toujours calculé lors du prétraitement des requêtes. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#75709](https://github.com/ClickHouse/ClickHouse/issues/75709) : désactivation de l’envoi des settings du serveur au client (`send_settings_to_client=false`) pour des raisons de compatibilité (cette fonctionnalité sera réimplémentée ultérieurement sous forme de client setting pour une meilleure ergonomie). [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* Rétroporté dans [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805) : ajout d’une config `memory_worker_correct_memory_tracker` pour permettre la correction du memory tracker interne à l’aide d’informations provenant d’une autre source, lues périodiquement dans le background thread. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* Rétroporté dans [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069) : ajout de la Metric `MemoryTrackingUncorrected`, qui affiche la Value du memory tracker global interne non corrigée par le RSS. [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).
