  # Historique des modifications 2022

<div id="clickhouse-release-v21473-stable-fixme-as-compared-to-v214655-stable">
  ### Version de ClickHouse v21.4.7.3-stable FIXME par rapport à v21.4.6.55-stable
</div>

<div id="bug-fix">
  #### Correction de bogues
</div>

* Rétroporté dans [#23971](https://github.com/ClickHouse/ClickHouse/issues/23971) : correction d’un bogue lors de la récupération d’une réplique `ReplicatedMergeTree` obsolète. Certaines mises à jour de métadonnées pouvaient être ignorées par une réplique obsolète si une requête `ALTER` était exécutée pendant l’indisponibilité de la réplique. [#23742](https://github.com/ClickHouse/ClickHouse/pull/23742) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#23819](https://github.com/ClickHouse/ClickHouse/issues/23819) : correction d’un crash lorsque `PREWHERE` et le filtre de ROW POLICY sont tous deux actifs avec un résultat vide. [#23763](https://github.com/ClickHouse/ClickHouse/pull/23763) ([Amos Bird](https://github.com/amosbird)).
* Rétroporté dans [#23816](https://github.com/ClickHouse/ClickHouse/issues/23816) : correction de `CLEAR COLUMN`, qui ne fonctionnait pas lorsqu’il était référencé par une vue matérialisée. Ferme [#23764](https://github.com/ClickHouse/ClickHouse/issues/23764). [#23781](https://github.com/ClickHouse/ClickHouse/pull/23781) ([flynn](https://github.com/ucasfl)).
* Rétroporté dans [#23831](https://github.com/ClickHouse/ClickHouse/issues/23831) : correction de l’erreur `Can't initialize pipeline with empty pipe` pour les requêtes avec `GLOBAL IN/JOIN` et `use_hedged_requests`. Corrige [#23431](https://github.com/ClickHouse/ClickHouse/issues/23431). [#23805](https://github.com/ClickHouse/ClickHouse/pull/23805) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Rétroporté dans [#23930](https://github.com/ClickHouse/ClickHouse/issues/23930) : correction du champ de mise à jour des clés complexes de HashedDictionary lors du chargement initial. Ferme [#23800](https://github.com/ClickHouse/ClickHouse/issues/23800). [#23824](https://github.com/ClickHouse/ClickHouse/pull/23824) ([Maksim Kita](https://github.com/kitaisreal)).
* Rétroporté dans [#23957](https://github.com/ClickHouse/ClickHouse/issues/23957) : correction du calcul des métriques de clés pour le dictionnaire CACHE() avec des doublons dans la source (ce qui provoquait des dépassements de `DictCacheKeysRequestedMiss`). [#23929](https://github.com/ClickHouse/ClickHouse/pull/23929) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#24003](https://github.com/ClickHouse/ClickHouse/issues/24003) : correction d’un SIGSEGV pour un GROUP BY externe avec ligne de débordement (c.-à-d. des requêtes comme `SELECT FROM GROUP BY WITH TOTALS SETTINGS max_bytes_before_external_group_by>0, max_rows_to_group_by>0, group_by_overflow_mode='any', totals_mode='before_having'`). [#23962](https://github.com/ClickHouse/ClickHouse/pull/23962) ([Azat Khuzhin](https://github.com/azat)).
* Rétroporté dans [#24188](https://github.com/ClickHouse/ClickHouse/issues/24188) : certaines requêtes `ALTER PARTITION` pouvaient provoquer les erreurs `Part A intersects previous part B` et `Unexpected merged part C intersecting drop range D` dans la replication queue. C’est corrigé. Corrige [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296). [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Rétroporté dans [#24031](https://github.com/ClickHouse/ClickHouse/issues/24031) : correction d’un crash dans MergeJoin, ferme [#24010](https://github.com/ClickHouse/ClickHouse/issues/24010). [#24013](https://github.com/ClickHouse/ClickHouse/pull/24013) ([Vladimir C](https://github.com/vdimir)).
* Rétroporté dans [#24141](https://github.com/ClickHouse/ClickHouse/issues/24141) : bogue : `explain pipeline` avec `select xxx final` affiche un pipeline incorrect : &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* Rétroporté dans [#24171](https://github.com/ClickHouse/ClickHouse/issues/24171) : corrige un bogue rare pouvant conduire à une table partiellement initialisée capable d’accepter des requêtes d’écriture (insert/alter/etc.). Désormais, ces tables seront en mode readonly. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* Rétroporté dans [#24215](https://github.com/ClickHouse/ClickHouse/issues/24215) : corrige une condition de concurrence pouvant survenir dans RBAC en cas de forte charge. Cette PR corrige [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090) et [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134). [#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* Rétroporté dans [#24243](https://github.com/ClickHouse/ClickHouse/issues/24243) : corrige un arrêt anormal du serveur lorsque hdfs devient inaccessible pendant l’exécution d’une requête. Clôt [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117). [#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
