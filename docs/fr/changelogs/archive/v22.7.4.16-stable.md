<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Correction de bogues (comportement incorrect visible par l’utilisateur dans une version stable officielle)
</div>

* Rétroporté dans [#40163](https://github.com/ClickHouse/ClickHouse/issues/40163) : correction de HashMethodOneNumber, qui renvoyait une mauvaise valeur de clé lorsque la colonne est const. [#40020](https://github.com/ClickHouse/ClickHouse/pull/40020) ([Duc Canh Le](https://github.com/canhld94)).
* Rétroporté dans [#40125](https://github.com/ClickHouse/ClickHouse/issues/40125) : correction d’un bogue dans collectFilesToSkip() par l’ajout de l’extension de fichier correcte (.idx ou idx2) pour les index à recalculer, afin d’éviter des liens physiques incorrects. Corrige [#39896](https://github.com/ClickHouse/ClickHouse/issues/39896). [#40095](https://github.com/ClickHouse/ClickHouse/pull/40095) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Rétroporté dans [#40291](https://github.com/ClickHouse/ClickHouse/issues/40291) : un défaut de segmentation dont la trace de pile contient CaresPTRResolver::resolve a été signalé. [#40134](https://github.com/ClickHouse/ClickHouse/pull/40134) ([Arthur Passos](https://github.com/arthurpassos)).
* Rétroporté dans [#40210](https://github.com/ClickHouse/ClickHouse/issues/40210) : correction d’une vérification insuffisante des arguments pour les fonctions de chiffrement (détectée par un fuzzer de requêtes). Cela clôt [#39987](https://github.com/ClickHouse/ClickHouse/issues/39987). [#40194](https://github.com/ClickHouse/ClickHouse/pull/40194) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Rétroporté dans [#40284](https://github.com/ClickHouse/ClickHouse/issues/40284) : correction d’un possible segfault dans le format d’entrée CapnProto. Ce bogue a été découvert et signalé via le [programme](https://github.com/ClickHouse/ClickHouse/issues/38986) de prime aux bogues de ClickHouse par *kiojj*. [#40241](https://github.com/ClickHouse/ClickHouse/pull/40241) ([Kruglov Pavel](https://github.com/Avogar)).
