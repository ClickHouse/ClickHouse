Les Notebooks IA sont un outil d&#39;investigation interactif de ClickHouse Observability qui associe un agent IA à l&#39;analyse manuelle. Il vous suffit de décrire un problème en langage courant : l&#39;agent IA interroge pour vous les logs, les traces et les métriques, et fait ressortir les données, graphiques et résumés pertinents sous la forme d&#39;une série de tuiles. Vous pouvez également ajouter vos propres tuiles (graphiques, tables, recherches et notes Markdown) en complément du contenu généré par l&#39;IA, afin de constituer un historique complet de l&#39;investigation.

## Configuration {#setup}

Les Carnets IA sont actuellement en version bêta dans ClickHouse Cloud. Les modèles d’IA et les fournisseurs sont gérés automatiquement par la plateforme.

Avant d’utiliser les Carnets IA :

1. **IA générative activée** — Un administrateur d’équipe doit activer l’interrupteur de consentement à l’IA générative. Consultez [Activer l’IA générative](#enabling-generative-ai).
2. **Accès aux carnets** — Votre rôle doit disposer des autorisations de lecture/écriture sur les Carnets.

Une fois la fonctionnalité activée, l’entrée **Carnets IA** apparaît dans la barre latérale gauche pour tous les utilisateurs disposant du rôle approprié.

## Activer l’IA générative {#enabling-generative-ai}

Un administrateur d’équipe doit activer l’interrupteur de consentement à l’IA générative pour que les notebooks (et les autres fonctionnalités d’IA) puissent être utilisés.

1. Ouvrez **Paramètres de l’équipe** et repérez **Configurer l’IA générative**.
2. Activez l’interrupteur IA générative.
3. Lisez la boîte de dialogue de consentement, puis acceptez-la.

## Utilisation des Notebooks IA {#using-notebooks}

### Créer un carnet {#creating-a-notebook}

1. Sélectionnez **Carnets IA** dans la barre latérale gauche.
2. Cliquez sur **New Private Carnet** (visible uniquement par vous) ou sur **New Shared Carnet** (visible par votre équipe).

La page listant les carnets affiche tous ceux auxquels vous avez accès. Vous pouvez les filtrer par nom ou par balises, ou basculer entre **My Carnets** et **All Carnets**.

<div className="ch-image-lg">
  <Frame>
    ![Page listant les carnets](/images/clickstack/observability-notebook-list.png)
  </Frame>
</div>

### Lancer une investigation IA {#running-investigation}

En bas d’un notebook, saisissez un prompt décrivant ce que vous souhaitez analyser — par exemple, *« Pourquoi le taux d’erreurs a-t-il brusquement augmenté dans le service checkout au cours de la dernière heure ? »*

Cliquez sur **Send** (ou appuyez sur Entrée). L’agent IA va :

1. Examiner les sources de données à sa disposition.
2. Exécuter des requêtes de recherche et d’agrégation sur vos logs, traces et métriques.
3. Produire une série de tuiles présentant son processus de réflexion, les requêtes exécutées, des graphiques intermédiaires et un résumé final assorti de ses conclusions.

Chaque étape apparaît sous forme de tuile dans le notebook. Les tuiles **Processus de réflexion** exposent le raisonnement qui sous-tend chaque requête, tandis que les tuiles **Output** contiennent les conclusions de l’agent, éventuellement accompagnées de graphiques. Contrairement à un chat IA classique, les notebooks vous permettent de voir précisément sur quelles données l’IA s’appuie à chaque étape : vous pouvez ainsi vérifier son raisonnement, repérer des pistes intéressantes qui lui auraient échappé et créer une [branche](#branching) de l’investigation pour l’orienter dans une autre direction.

Pendant l’exécution d’une investigation, vous pouvez cliquer sur **Stop** pour l’annuler.

### Créer des branches d’une investigation {#branching}

Au fil de l’investigation menée par l’IA, vous remarquerez peut-être qu’une étape intermédiaire révèle un élément intéressant, alors que l’agent a poursuivi dans une autre direction. La **création de branches** vous permet de repartir de ce point avec un prompt différent, sans perdre le cheminement de l’investigation d’origine.

Pour créer une branche :

1. Développez la tuile à partir de laquelle vous souhaitez créer une branche, puis cliquez sur **Restart from Here**.
2. Dans la boîte de dialogue, saisissez un prompt modifié pour orienter l’investigation dans la nouvelle direction.
3. Cliquez sur **Create Branch**. L’IA lance une nouvelle branche d’investigation à partir de ce point.

<div className="ch-image-md">
  <Frame>
    ![Boîte de dialogue Create New Branch](/images/clickstack/observability-notebook-branch-modal.png)
  </Frame>
</div>

Lorsqu’une tuile comporte plusieurs branches, des flèches gauche et droite apparaissent dans son en-tête, accompagnées d’un badge (par ex. **1/2**) indiquant le nombre de branches. Cliquez sur les flèches pour passer d’une branche à l’autre.

### Ajouter des tuiles manuelles {#manual-tiles}

En plus des tuiles générées par l’IA, vous pouvez ajouter vos propres blocs d’analyse à l’aide des boutons situés en bas du notebook :

| Bouton        | Raccourci | Description                                                                                                                                                                                |
| ------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Recherche** | `S`       | Une vue de recherche de journaux/traces, équivalente à la page de recherche.                                                                                                               |
| **Graphique** | `L`       | Un graphique en courbes de séries temporelles, qui s’appuie sur le même constructeur de visualisations que les [tableaux de bord](/fr/clickstack/observability/features/dashboards/overview). |
| **Table**     | `T`       | Une vue d’agrégation sous forme de tableau.                                                                                                                                                |
| **Markdown**  | `M`       | Texte libre pour consigner des notes, des hypothèses ou des conclusions.                                                                                                                   |

Une fois ajoutée, la tuile s’ouvre en mode de modification intégré, où vous pouvez configurer la source de données, les filtres et les agrégations, avec la même interface que celle utilisée pour créer des [visualisations de tableau de bord](/fr/clickstack/observability/features/dashboards/overview#creating-visualizations). Cliquez sur **Enregistrer** pour finaliser la tuile.

Les tuiles manuelles sont ajoutées sous la dernière tuile visible de la branche en cours. Vous pouvez redimensionner les tuiles verticalement en faisant glisser leur bord inférieur.

<Note>

</Note>

### Partage et organisation {#sharing-organizing}

* **Privé ou partagé** — Cliquez sur l&#39;icône de cadenas dans l&#39;en-tête du notebook pour basculer entre le mode privé (visible par vous seul) et le mode partagé (visible par l&#39;équipe). Seul le créateur du notebook peut modifier ce paramètre.
* **Balises** — Ajoutez des balises à vos notebooks pour les filtrer facilement sur la page de liste.
* **Nommage** — Cliquez sur le titre du notebook pour le renommer. Si vous lancez une investigation dans un notebook sans titre, l&#39;IA vous proposera automatiquement un nom.

### Contexte personnalisé de l’agent {#custom-agent-context}

Les administrateurs d’équipe peuvent fournir un contexte supplémentaire, inclus dans chaque investigation menée par l’équipe dans un notebook IA. Cela permet de renseigner l’IA sur l’architecture de votre système, vos conventions de nommage ou les problèmes connus.

Pour configurer ce contexte :

1. Accédez à **Notebooks IA** depuis la barre latérale gauche.
2. Cliquez sur l’icône d’engrenage des paramètres, en haut à droite, pour ouvrir **Contexte d’agent personnalisé** (réservé aux administrateurs d’équipe).
3. Saisissez votre contexte personnalisé (jusqu’à 50,000 caractères), puis enregistrez.

Ce contexte est ajouté à la fin de l’instruction système de l’IA pour toutes les investigations menées dans les notebooks de l’équipe.
