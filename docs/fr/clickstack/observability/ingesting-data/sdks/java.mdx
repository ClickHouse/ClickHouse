Utilisez l&#39;agent Java ou le SDK OpenTelemetry pour envoyer des logs, des métriques et des traces vers ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Configurer OpenTelemetry {#set-up-opentelemetry}

Suivez les [instructions officielles de configuration de l&#39;agent Java OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/) pour installer l&#39;instrumentation et configurer votre application. Pour une instrumentation manuelle, consultez la [documentation du SDK Java](https://opentelemetry.io/docs/languages/java/instrumentation/).

Configurez l&#39;[export OTLP](https://opentelemetry.io/docs/languages/java/configuration/#properties-exporters) pour les signaux que vous souhaitez envoyer, à l&#39;aide des paramètres de connexion ci-dessous. Remplacez toutes les destinations données en exemple dans les instructions amont, y compris les surcharges d&#39;endpoint propres à chaque signal.

## Configurer votre destination {#configure-destination}

<Tabs>
  <Tab title="Entièrement géré">
    <BetaBadge label="Offre bêta" />

    Ouvrez **Team Settings → Data → Managed Telemetry** dans votre service et copiez l’**OTLP HTTP endpoint** et l’**API key**. Utilisez l’endpoint HTTPS complet, port compris :

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogéré">
    Utilisez l’endpoint OTLP HTTP et la clé d’ingestion de votre collecteur. Remplacez `https://` par `http://` si TLS n’est pas configuré sur votre collecteur. Pour configurer le collecteur, consultez [Ingestion avec OpenTelemetry](/fr/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Vérifier l&#39;ingestion {#verify-ingestion}

Démarrez votre application instrumentée et générez de l&#39;activité. Dans ClickHouse Observability, sélectionnez un intervalle de temps récent et recherchez le nom du service de votre application dans Logs ou Traces. Si votre application émet des métriques, consultez Metrics après avoir laissé à l&#39;export le temps de s&#39;effectuer.

Pour le dépannage de l&#39;instrumentation et de l&#39;exportateur, consultez les [recommandations de dépannage de l&#39;agent Java OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/#troubleshooting).
