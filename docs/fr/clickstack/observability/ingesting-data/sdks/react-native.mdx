Utilisez OpenTelemetry pour envoyer les traces de la couche JavaScript de votre application React Native vers ClickHouse Observability.

<ClickStackIntegrates signals={['traces']} />

## Configurer OpenTelemetry {#set-up-opentelemetry}

Suivez la [démonstration officielle OpenTelemetry React Native](https://opentelemetry.io/docs/demo/services/react-native-app/) et son [code source d&#39;instrumentation](https://github.com/open-telemetry/opentelemetry-demo/tree/main/src/react-native-app) pour initialiser le traçage et instrumenter les requêtes réseau.

La démo s&#39;appuie sur les paquets JavaScript d&#39;OpenTelemetry, qui ne sont pas officiellement pris en charge sur React Native. Vérifiez leur compatibilité avec les versions de React Native et d&#39;OpenTelemetry utilisées par votre application.

## Configurer votre destination {#configure-destination}

Remplacez la configuration de l&#39;exportateur local de la démonstration par la destination ci-dessous. Utilisez cet exportateur dans le processeur de spans de la configuration amont. L&#39;URL de l&#39;exportateur doit inclure `/v1/traces`.

<Tabs>
  <Tab title="Entièrement géré">
    <BetaBadge label="Offre en version bêta" />

    Ouvrez **Paramètres de l’équipe → Données → Télémétrie gérée** dans votre service, puis copiez le **point de terminaison OTLP HTTP** et l&#39;**API key**. Conservez le point de terminaison HTTPS complet, port compris, et ajoutez `/v1/traces` à la fin :

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_OTEL_ENDPOINT:4318/v1/traces',
      headers: {
        Authorization: 'Bearer YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>

  <Tab title="Autogéré">
    Utilisez le point de terminaison OTLP HTTP et la clé d’ingestion de votre collecteur. Le collecteur doit être joignable depuis l&#39;appareil. Pour configurer le collecteur, consultez [Ingestion avec OpenTelemetry](/fr/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```javascript
    import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

    const traceExporter = new OTLPTraceExporter({
      url: 'https://YOUR_COLLECTOR_HOST:4318/v1/traces',
      headers: {
        Authorization: 'YOUR_INGESTION_API_KEY',
      },
    });
    ```
  </Tab>
</Tabs>

## Vérifier l&#39;ingestion {#verify-ingestion}

Lancez votre application sur un appareil ou un simulateur et effectuez des requêtes réseau. Dans ClickHouse Observability, sélectionnez un intervalle de temps récent et recherchez le nom du service de votre application dans Traces.

Pour en savoir plus sur l&#39;instrumentation et sur les solutions de contournement liées à la compatibilité avec React Native, consultez la [démonstration OpenTelemetry React Native](https://opentelemetry.io/docs/demo/services/react-native-app/). Pour connaître les options des exportateurs, consultez la [documentation des exportateurs OpenTelemetry pour JavaScript](https://opentelemetry.io/docs/languages/js/exporters/).
