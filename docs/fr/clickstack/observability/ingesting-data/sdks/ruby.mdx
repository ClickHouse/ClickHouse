Utilisez le SDK Ruby d&#39;OpenTelemetry pour envoyer des traces à ClickHouse Observability.

## Configurer OpenTelemetry {#set-up-opentelemetry}

Suivez les [instructions officielles de configuration d&#39;OpenTelemetry pour Ruby](https://opentelemetry.io/docs/languages/ruby/getting-started/) pour initialiser le SDK et instrumenter votre application.

Configurez l&#39;[export OTLP via HTTP](https://opentelemetry.io/docs/languages/ruby/exporters/) pour les traces à l&#39;aide des paramètres de connexion ci-dessous. Remplacez toutes les destinations fournies à titre d&#39;exemple dans la documentation amont, y compris les surcharges d&#39;endpoint propres à chaque signal.

## Configurer votre destination {#configure-destination}

<Tabs>
  <Tab title="Entièrement géré">
    <BetaBadge label="Offre bêta" />

    Ouvrez **Paramètres de l’équipe → Données → Managed Telemetry** dans votre service, puis copiez l’**endpoint OTLP HTTP** et l’**API key**. Utilisez l’endpoint HTTPS complet, port compris :

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogéré">
    Utilisez l’endpoint OTLP HTTP et la clé d’ingestion de votre collecteur. Si TLS n’est pas configuré sur votre collecteur, remplacez `https://` par `http://`. Pour configurer le collecteur, consultez [Ingestion avec OpenTelemetry](/fr/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Vérifier l&#39;ingestion {#verify-ingestion}

Démarrez votre application instrumentée et générez de l&#39;activité. Dans ClickHouse Observability, sélectionnez un intervalle de temps récent et recherchez le nom du service de votre application dans Traces.

Pour le dépannage de l&#39;instrumentation et de l&#39;exportateur, consultez la [documentation OpenTelemetry pour Ruby](https://opentelemetry.io/docs/languages/ruby/).
