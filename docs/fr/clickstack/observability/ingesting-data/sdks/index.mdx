## Connecter votre application {#connect-your-application}

1. Suivez le guide correspondant à votre langage ou à votre plateforme pour configurer l’instrumentation.
2. Choisissez votre destination dans ce guide :
   * **Entièrement géré :** utilisez le point de terminaison OTLP géré de votre service et l’API key d’ingestion, disponibles dans **Paramètres de l’équipe → Données → Télémétrie gérée**.
   * **Autogéré :** utilisez le point de terminaison OTLP de votre collecteur OpenTelemetry et la clé d’ingestion configurée.
3. Générez de l’activité dans l’application, puis vérifiez que la télémétrie attendue apparaît dans l’UI.

Chaque guide précise le format d’authentification et les paramètres de l’exportateur propres au SDK concerné. Le guide Lambda propose également une option basée sur les couches OpenTelemetry, qui achemine la télémétrie via un collecteur local.
