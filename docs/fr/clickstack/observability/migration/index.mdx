Migrez d’Elastic Stack ou de Datadog vers ClickHouse Observability, en version gérée ou autogérée. Ces guides traitent de la planification de la migration, de la syntaxe de recherche et de l’adaptation de votre collecte de télémétrie existante. Lorsque les informations de connexion diffèrent, sélectionnez l’onglet correspondant à votre déploiement.

| Technologie                                                  | Description                                                                                                                          |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| [Elastic Stack](/fr/clickstack/observability/migration/elastic) | Planifier la transition, convertir les requêtes de recherche et migrer les données, les agents et l’instrumentation des applications |
| [Datadog](/fr/clickstack/observability/migration/datadog)       | Configurer les agents Datadog existants pour qu’ils envoient la télémétrie vers un endpoint géré ou un récepteur Datadog autogéré    |
