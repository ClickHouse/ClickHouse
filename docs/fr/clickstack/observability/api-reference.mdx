ClickHouse Observability utilise l’API ClickHouse Cloud pour gérer les tableaux de bord, les alertes, les webhooks, les rôles et les recherches enregistrées, ainsi que pour accéder aux sources de données.

<Note>
  Dans l’offre entièrement gérée, les sources sont gérées pour vous. Utilisez les opérations de lecture des sources pour les consulter ; les opérations de création, de mise à jour et de suppression de sources sont destinées aux déploiements dans lesquels vous gérez vous-même vos sources.
</Note>

## Documentation de référence de l’API {#api-docs}

Sélectionnez un endpoint dans la barre latérale pour afficher ses paramètres, ses schémas de requête et de réponse, ainsi que des exemples interactifs. Ces pages s’appuient sur la spécification de l’**API ClickHouse Cloud**, avec les URL et l’authentification propres aux services Cloud.

Les endpoints suivants sont disponibles :

| Ressource                   | Opérations                                                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Tableaux de bord**        | Créer, lister, récupérer, mettre à jour, supprimer et valider des tableaux de bord                                          |
| **Alertes**                 | Créer, lister, récupérer, mettre à jour et supprimer des alertes                                                            |
| **Sources**                 | Lister et récupérer des sources de données ; créer, mettre à jour et supprimer des sources lorsque vous les gérez vous-même |
| **Webhooks**                | Créer, lister, mettre à jour, supprimer et valider des webhooks                                                             |
| **Rôles**                   | Créer, lister, récupérer, mettre à jour et supprimer des rôles                                                              |
| **Recherches enregistrées** | Créer, lister, récupérer, mettre à jour et supprimer des recherches enregistrées                                            |

## Authentification {#authentication}

ClickHouse Observability s&#39;appuie sur la **clé API ClickHouse Cloud** pour l&#39;authentification, au moyen de l&#39;[authentification de base HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Authentication). Pour créer et gérer des clés API, consultez [Gérer les clés API](/fr/products/cloud/features/admin-features/api/openapi).

La clé doit disposer de la permission `control-plane:service:manage-clickstack-api`.

Transmettez l&#39;ID de la clé et son secret via l&#39;authentification de base HTTP :

```bash
export KEY_ID=<your_key_id>
export KEY_SECRET=<your_key_secret>

curl --user $KEY_ID:$KEY_SECRET \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/dashboards
```

## URL de base et format des requêtes {#base-url}

Toutes les requêtes adressées à l’API ClickHouse Observability sont envoyées à l’API ClickHouse Cloud :

```bash
https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/<resource>
```

Vous trouverez votre **Identifiant de l’organisation** dans la Console ClickHouse Cloud, sous **Organisation → Informations sur l’organisation**. Votre **Identifiant de service** figure dans l’URL du service ou sur la page de détails du service.

### Exemple : lister les tableaux de bord {#list-dashboards-managed}

```bash
curl --user $KEY_ID:$KEY_SECRET \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/dashboards
```

### Exemple : créer une alerte {#create-alert-managed}

```bash
curl -X POST --user $KEY_ID:$KEY_SECRET \
  -H "Content-Type: application/json" \
  -d '{
    "dashboardId": "<DASHBOARD_ID>",
    "tileId": "<TILE_ID>",
    "threshold": 100,
    "interval": "1h",
    "source": "tile",
    "thresholdType": "above",
    "channel": {
      "type": "webhook",
      "webhookId": "<WEBHOOK_ID>"
    },
    "name": "Error Spike Alert",
    "message": "Error rate exceeded 100 in the last hour"
  }' \
  https://api.clickhouse.cloud/v1/organizations/<ORG_ID>/services/<SERVICE_ID>/clickstack/alerts
```
