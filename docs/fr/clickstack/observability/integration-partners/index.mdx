Connectez vos pipelines de télémétrie et vos applications à ClickHouse Observability grâce à ces partenaires d’intégration. Chaque guide explique comment configurer l’intégration pour votre déploiement.

| Section                                                               | Description                                                                                                                                                                        |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Bindplane](/fr/clickstack/observability/integration-partners/bindplane) | Bindplane est un pipeline de télémétrie natif OpenTelemetry qui assure la gestion centralisée des collecteurs OpenTelemetry.                                                       |
| [bitdrift](/fr/clickstack/observability/integration-partners/bitdrift)   | bitdrift est une plateforme d’observability dynamique dédiée aux applications mobiles, qui relie la télémétrie mobile aux traces backend grâce au contexte de trace OpenTelemetry. |
| [Odigos](/fr/clickstack/observability/integration-partners/odigos)       | Odigos associe eBPF et OpenTelemetry pour produire des traces distribuées plus détaillées, avec un surcoût nettement inférieur à celui des agents d’instrumentation du bytecode.   |
| [Telflo](/fr/clickstack/observability/integration-partners/telflo)       | Telflo est un plan de contrôle natif OpenTelemetry qui centralise la gestion des collecteurs et le routage de la télémétrie.                                                       |
