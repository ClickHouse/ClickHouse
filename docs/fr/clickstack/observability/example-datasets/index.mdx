Ces jeux de données d’exemple et ces démonstrations vous aident à faire vos premiers pas avec ClickHouse Observability, entièrement géré. Chargez des données d’exemple, collectez des logs et des métriques depuis votre environnement ou instrumentez une application pour explorer les traces et la relecture de session.

| Jeu de données                                                                                    | Description                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Données d’exemple](/fr/clickstack/observability/example-datasets/sample-data)                       | Chargez un jeu de données d’exemple contenant des logs, des traces et des métriques issus de notre environnement de démonstration                                              |
| [Supervision de Kubernetes](/fr/clickstack/observability/example-datasets/kubernetes)                | Collectez des logs et des métriques depuis un cluster Kubernetes et envoyez-les à votre service managé                                                                         |
| [Données locales](/fr/clickstack/observability/example-datasets/local-data)                          | Collectez les métriques et les logs de votre système local et envoyez-les à votre service managé pour les analyser                                                             |
| [Démo de relecture de session](/fr/clickstack/observability/example-datasets/session-replay)         | Instrumentez une application web de démonstration pour la relecture de session et visualisez vos interactions dans ClickHouse Observability                                    |
| [Extension Chrome](/fr/clickstack/observability/example-datasets/chrome-extension)                   | Injectez le SDK pour navigateur dans n’importe quel site web à l’aide de l’extension Chrome HyperDX, sans aucune modification du code applicatif                               |
| [Données synthétiques avec otelgen](/fr/clickstack/observability/example-datasets/otelgen)           | Utilisez `otelgen` pour envoyer des logs, des traces et des métriques synthétiques vers votre endpoint de télémétrie managée                                                   |
| [Données synthétiques avec telemetrygen](/fr/clickstack/observability/example-datasets/telemetrygen) | Utilisez `telemetrygen` pour envoyer des logs, des traces et des métriques synthétiques vers votre endpoint de télémétrie managée                                              |
| [HackerNews Analyzer](/fr/clickstack/observability/example-datasets/instrument-application)          | Instrumentez une application Node.js avec un agent (ou manuellement) et envoyez des logs, des traces, des métriques et des relectures de session vers ClickHouse Observability |
