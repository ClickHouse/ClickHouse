<Note>
  Ce guide porte sur l’offre entièrement gérée de ClickHouse Observability. Pour Self-managed ClickHouse Observability, consultez la section [administration de la base de données](/fr/clickstack/self-configured/managing/overview) pour le dimensionnement, la rétention, l’optimisation du schéma et les recommandations de production, ainsi que la section [options de configuration](/fr/clickstack/self-configured/managing/config) pour les paramètres de la source.
</Note>

Utilisez les **Paramètres de l’équipe** pour gérer l’accès à la télémétrie, les sources, les connexions des API et des agents, les intégrations, les paramètres de requête et les autorisations de l’équipe dans ClickHouse Observability.

## Guides d’administration {#admin-guides}

| Guide                                                                          | Ce que vous pouvez faire                                                                                                                                                                 |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Options de configuration](/fr/clickstack/observability/managing/config)          | Gérer les sources et l’accès des collecteurs, trouver les informations de connexion pour la télémétrie, configurer l’accès à l’API et aux agents, et ajuster les paramètres de requête.  |
| [Contrôle d’accès basé sur les rôles](/fr/clickstack/observability/managing/rbac) | Consulter les rôles prédéfinis, créer des rôles personnalisés et configurer les autorisations sur les tableaux de bord, les recherches enregistrées, les sources et d’autres ressources. |

## Envoi de la télémétrie {#sending-telemetry}

Pour connecter vos applications et vos collecteurs, commencez par récupérer les informations de connexion dans **Paramètres de l’équipe → Données → Télémétrie gérée**, puis suivez les [guides d’ingestion](/fr/clickstack/observability/ingesting-data/overview).
