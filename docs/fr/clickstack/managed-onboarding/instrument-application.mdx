Ce guide explique comment instrumenter une petite application Node.js avec OpenTelemetry et envoyer ses logs, métriques, traces et relectures de session vers ClickHouse Observability via le collecteur que vous exécutez. Le backend est instrumenté sans aucune modification du code source de l’application.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) est une application Node.js qui interroge le jeu de données HackerNews hébergé dans la démo publique de ClickHouse. Chaque graphique, tableau et champ de recherche repose sur une véritable requête ClickHouse : chaque interaction produit donc une trace dont le span principal correspond à l’appel HTTPS du backend vers ClickHouse.

Ce guide suppose que vous avez suivi le guide [Configuration de votre collecteur OpenTelemetry](/fr/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) et que vous disposez d’un collecteur ClickStack en cours d’exécution, joignable depuis la machine sur laquelle vous exécutez cette application. **Veillez à noter son point de terminaison OTLP** ainsi que le `OTLP_AUTH_TOKEN` défini lors de son déploiement. Vous renseignerez ces valeurs dans `.env` avant l’instrumentation.

## Prérequis {#prerequisites}

* Un collecteur ClickStack joignable depuis cette machine. Si vous n&#39;en avez pas encore déployé un, suivez d&#39;abord [Configuration de votre collecteur OpenTelemetry](/fr/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* L&#39;endpoint OTLP/HTTP de ce collecteur (généralement le port `4318`) et le `OTLP_AUTH_TOKEN` que vous y avez configuré. Utilisez-les pour définir `OTEL_EXPORTER_OTLP_ENDPOINT` et `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ et npm.

## Cloner le dépôt {#clone-the-repository}

Clonez [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), installez les dépendances et copiez le modèle de fichier d&#39;environnement :

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

Vous renseignerez le fichier `.env` dans les prochaines étapes, puis instrumenterez l’application depuis ce répertoire.
