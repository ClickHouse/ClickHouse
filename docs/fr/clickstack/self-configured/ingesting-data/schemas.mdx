Le collecteur ClickHouse Observability utilise l’[exportateur ClickHouse](https://github.com/open-telemetry/opentelemetry-collector-contrib/blob/main/exporter/clickhouseexporter/README.md) pour créer des tables dans ClickHouse et y insérer des données.

Les tables suivantes sont créées pour chaque type de données dans la base de données `default`. Vous pouvez modifier cette base de données cible à l’aide de la variable d’environnement `HYPERDX_OTEL_EXPORTER_CLICKHOUSE_DATABASE` définie pour l’image qui héberge le collecteur.
