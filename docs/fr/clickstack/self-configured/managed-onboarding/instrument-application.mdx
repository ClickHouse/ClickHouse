Ce guide vous montre comment instrumenter une petite application Node.js avec OpenTelemetry et envoyer ses logs, métriques, traces et relectures de session vers Self-managed ClickHouse Observability. Le backend est instrumenté sans aucune modification du code source de l&#39;application.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) est une application Node.js qui interroge le jeu de données HackerNews hébergé sur la démo publique de ClickHouse. Chaque graphique, table et champ de recherche s&#39;appuie sur une véritable requête ClickHouse : chaque interaction produit donc une trace dont le span principal est l&#39;appel HTTPS du backend vers ClickHouse.

Ce guide suppose que vous avez suivi le guide [Configuration de votre collecteur OpenTelemetry](/fr/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) et qu&#39;un collecteur ClickStack est en cours d&#39;exécution et joignable depuis la machine sur laquelle vous exécutez cette application. **Veillez à avoir noté son point de terminaison OTLP**, ainsi que le `OTLP_AUTH_TOKEN` défini lors de son déploiement. Vous renseignerez ces valeurs dans `.env` avant de procéder à l&#39;instrumentation.

## Prérequis {#prerequisites}

* Un collecteur ClickStack joignable depuis cette machine. Si vous n&#39;en avez pas encore déployé, suivez d&#39;abord le guide [Configuration de votre collecteur OpenTelemetry](/fr/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* L&#39;endpoint OTLP/HTTP de ce collecteur (généralement sur le port `4318`) ainsi que la valeur `OTLP_AUTH_TOKEN` que vous y avez définie. Utilisez-les respectivement pour `OTEL_EXPORTER_OTLP_ENDPOINT` et `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ et npm.

## Cloner le dépôt {#clone-the-repository}

Clonez [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), installez les dépendances, puis copiez le modèle de fichier env :

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

Vous renseignerez le fichier `.env` lors des étapes suivantes, puis vous instrumenterez l&#39;application à partir de ce répertoire.
