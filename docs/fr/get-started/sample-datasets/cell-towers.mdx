## Analyse géospatiale avec des antennes-relais {#geospatial-analysis-with-cell-towers}

Ce guide montre comment charger les données `OpenCelliD` dans `ClickHouse Cloud`, les enrichir avec un dictionnaire de pays, rechercher les antennes d’Allemagne et les visualiser avec `ClickHouse Agents`.

<Steps>
  <Step title="Chargez les données d’exemple">
    Dans `ClickHouse Cloud`, ouvrez **Load data**, choisissez **Cell Towers** dans **Sample data**, puis chargez le jeu de données. Chaque ligne de `cell_towers` correspond à une antenne ; `lon` et `lat` sont ses coordonnées.

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="Interrogez et enrichissez les antennes">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;
    ```

    Créez un dictionnaire qui remplace le `mcc` numérique par le pays :

    ```sql
    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="Utilisez des données géographiques">
    `ClickHouse` fournit des fonctions telles que [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon). Créez `germany`, insérez le contour de l’Allemagne continentale indiqué dans le [guide anglais](/get-started/sample-datasets/cell-towers#germany-polygon), puis comptez les antennes du polygone :

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    Le résultat est d’environ `2.62 million`.
  </Step>
  <Step title="Facultatif : visualisez les données avec ClickHouse Agents">
    Ceci est un exemple facultatif : `ClickHouse Agents` est une fonctionnalité bêta pilotée par un modèle, son plan, ses outils et sa sortie peuvent donc varier selon les exécutions. Ouvrez **ClickHouse agents** et envoyez : "Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables".

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="Discussion ClickHouse Agent créant une grille de densité d’antennes en Allemagne"/>

    Lors d’une exécution, l’agent a trouvé le MCC allemand, compté les antennes, les a regroupées dans une grille de `0.1°` et a dessiné le contour sur la carte.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="Carte de chaleur de la densité d’antennes-relais en Allemagne"/>
  </Step>
</Steps>
