ClickHouse expose ses propres métriques au format texte Prometheus sur un port dédié, afin qu&#39;un serveur Prometheus puisse les collecter.

Pour stocker des métriques Prometheus dans ClickHouse et les interroger avec PromQL, consultez plutôt [API HTTP de Prometheus et PromQL](/fr/concepts/features/connect-to-clickhouse/prometheus).

<Note>
  Si vous utilisez ClickHouse Cloud, vous pouvez exposer les métriques à Prometheus à l&#39;aide de l&#39;[intégration Prometheus](/fr/products/cloud/features/monitoring/prometheus).
</Note>

## Configurer le port des métriques {#configure-the-metrics-port}

Configurez un port dédié lorsqu&#39;un serveur Prometheus doit collecter les métriques internes de ClickHouse :

```xml
<prometheus>
    <port>9363</port>
    <endpoint>/metrics</endpoint>
    <metrics>true</metrics>
    <asynchronous_metrics>true</asynchronous_metrics>
    <events>true</events>
    <errors>true</errors>
    <histograms>true</histograms>
    <dimensional_metrics>true</dimensional_metrics>
</prometheus>
```

## Configurer des handlers étendus {#configure-extended-handlers}

La section `<prometheus.handlers>` permet de définir des handlers plus avancés sur le même port.
Cette section est similaire à [`<http_handlers>`](/fr/concepts/features/connect-to-clickhouse/protocols/http), mais s&#39;applique aux protocoles Prometheus :

```xml
<prometheus>
    <port>9363</port>
    <handlers>
        <my_rule_1>
            <url>/metrics</url>
            <handler>
                <type>expose_metrics</type>
                <metrics>true</metrics>
                <asynchronous_metrics>true</asynchronous_metrics>
                <events>true</events>
                <errors>true</errors>
                <histograms>true</histograms>
                <dimensional_metrics>true</dimensional_metrics>
                <labels>
                    <environment>production</environment>
                    <shard from_env="SHARD_NAME"></shard>
                </labels>
            </handler>
        </my_rule_1>
    </handlers>
</prometheus>
```

## Paramètres {#settings}

Pour une description complète du comportement de ces paramètres, consultez la [section Prometheus](/fr/reference/settings/server-settings/settings/other#prometheus) de la référence des paramètres du serveur.

| Nom                          | Valeur par défaut | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `port`                       | aucune            | Port sur lequel les métriques ClickHouse sont exposées.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `endpoint`                   | `/metrics`        | Endpoint HTTP pour la collecte des métriques. Il commence par `/`. Ne doit pas être utilisé avec la section `<handlers>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `url` / `headers` / `method` | aucune            | Filtres permettant de trouver le handler correspondant à une requête. Équivalents aux champs de même nom dans la section [`<http_handlers>`](/fr/concepts/features/connect-to-clickhouse/protocols/http).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `info`                       | true              | Expose la jauge `ClickHouse_Info` avec des labels d&#39;identité du serveur (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `metrics`                    | true              | Expose les métriques de [`system.metrics`](/fr/reference/system-tables/metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `asynchronous_metrics`       | true              | Expose les métriques de [`system.asynchronous_metrics`](/fr/reference/system-tables/asynchronous_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `events`                     | true              | Expose les métriques de [`system.events`](/fr/reference/system-tables/events).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `errors`                     | true              | Expose les nombres d’occurrences d&#39;erreurs de [`system.errors`](/fr/reference/system-tables/errors).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `histograms`                 | true              | Expose les métriques de [`system.histogram_metrics`](/fr/reference/system-tables/histogram_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `dimensional_metrics`        | true              | Expose les métriques de [`system.dimensional_metrics`](/fr/reference/system-tables/dimensional_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `labels`                     | aucune            | Labels constants ajoutés à chaque métrique exposée. Chaque élément enfant définit un label : le nom de l&#39;élément correspond au nom du label (qui doit respecter le motif `[a-zA-Z_][a-zA-Z0-9_]*`) et la valeur de l&#39;élément à la valeur du label. Les valeurs de label prennent en charge les substitutions de configuration standard, comme l&#39;attribut `from_env`. Un nom de label est rejeté s&#39;il commence par `__` (préfixe réservé par Prometheus) ou s&#39;il entre en conflit avec un label que cet endpoint écrit déjà pour l&#39;une de ses sections activées. L&#39;ensemble des noms réservés dépend donc de ce que l&#39;endpoint exporte effectivement : `le` lorsque `histograms` est activé ; les labels de `ClickHouse_Info` (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`) lorsque `info` est activé ; et tout label utilisé par une famille de métriques d&#39;histogramme ou dimensionnelle exposée (par exemple `group`, `direction` ou `operation_type`) lorsque `histograms` ou `dimensional_metrics` est activé. Comme cela dépend de ce que l&#39;endpoint expose réellement, un même nom peut être valide sur un endpoint et rejeté sur un autre. |

## Vérifier l&#39;endpoint {#check-the-endpoint}

```bash
curl http://127.0.0.1:9363/metrics
```
