ClickHouse prend en charge le protocole réseau PostgreSQL, ce qui vous permet d’utiliser des clients Postgres pour vous connecter à ClickHouse. En quelque sorte, ClickHouse peut se faire passer pour une instance PostgreSQL : vous pouvez ainsi connecter à ClickHouse une application client PostgreSQL qui n&#39;est pas encore directement prise en charge par ClickHouse (par exemple, Amazon Redshift).

Pour activer le protocole réseau PostgreSQL, ajoutez le paramètre [postgresql&#95;port](/fr/reference/settings/server-settings/settings/postgresql#postgresql_port) au fichier de configuration de votre serveur. Par exemple, vous pouvez définir le port dans un nouveau fichier XML de votre dossier `config.d` :

```xml
<clickhouse>
    <postgresql_port>9005</postgresql_port>
</clickhouse>
```

Démarrez votre serveur ClickHouse et recherchez dans le journal un message semblable au suivant, qui mentionne **Listening for PostgreSQL compatibility protocol** :

```response
{} <Information> Application: Listening for PostgreSQL compatibility protocol: 127.0.0.1:9005
```

## Connecter psql à ClickHouse {#connect-psql-to-clickhouse}

La commande suivante montre comment connecter le client PostgreSQL `psql` à ClickHouse :

```bash
psql -p [port] -h [hostname] -U [username] [database_name]
```

Par exemple :

```bash
psql -p 9005 -h 127.0.0.1 -U alice default
```

<Note>
  Le client `psql` exige une authentification par mot de passe ; vous ne pourrez donc pas vous connecter avec l&#39;utilisateur `default` s&#39;il n&#39;a pas de mot de passe. Affectez un mot de passe à l&#39;utilisateur `default` ou connectez-vous avec un autre utilisateur.
</Note>

Le client `psql` vous invite à saisir le mot de passe :

```response
Password for user alice:
psql (14.2, server 22.3.1.1)
WARNING: psql major version 14, server major version 22.
         Some psql features might not work.
Type "help" for help.

default=>
```

Et voilà ! Vous disposez désormais d&#39;un client PostgreSQL connecté à ClickHouse, et toutes les commandes et requêtes sont exécutées sur ClickHouse.

<Note>
  Pour l&#39;instant, le protocole PostgreSQL ne prend en charge que les mots de passe en texte clair.
</Note>

## Utilisation de SSL {#using-ssl}

Si SSL/TLS est configuré sur votre instance ClickHouse, `postgresql_port` utilisera les mêmes paramètres (le port est partagé entre les clients sécurisés et non sécurisés).

Chaque client a sa propre méthode de connexion via SSL. La commande suivante montre comment transmettre les certificats et la clé pour connecter `psql` à ClickHouse de manière sécurisée :

```bash
psql "port=9005 host=127.0.0.1 user=alice dbname=default sslcert=/path/to/certificate.pem sslkey=/path/to/key.pem sslrootcert=/path/to/rootcert.pem sslmode=verify-ca"
```

## Configurer l&#39;authentification des utilisateurs ClickHouse avec SCRAM-SHA-256 {#using-scram-sha256}

Pour sécuriser l&#39;authentification des utilisateurs dans ClickHouse, il est recommandé d&#39;utiliser le protocole SCRAM-SHA-256. Configurez l&#39;utilisateur en spécifiant l&#39;élément `password_scram_sha256_hex` dans le fichier users.xml. Le hachage du mot de passe doit être généré avec num&#95;iterations=4096.

Assurez-vous que le client psql prend en charge et négocie SCRAM-SHA-256 lors de la connexion.

Exemple de configuration pour l&#39;utilisateur `user_with_sha256` avec le mot de passe `abacaba` :

```xml
<user_with_sha256>
    <password_scram_sha256_hex>04e7a70338d7af7bb6142fe7e19fef46d9b605f3e78b932a60e8200ef9154976</password_scram_sha256_hex>
</user_with_sha256>
```

Consultez la [documentation PostgreSQL](https://jdbc.postgresql.org/documentation/head/ssl-client.html) pour en savoir plus sur ses paramètres SSL.
