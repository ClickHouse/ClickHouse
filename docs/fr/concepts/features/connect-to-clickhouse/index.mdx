Choisissez l’interface la mieux adaptée à votre usage de ClickHouse. Pour le développement d’applications, commencez par un client ou un driver officiel pour votre langage. Pour un usage interactif, privilégiez un outil natif ou web. Pour des intégrations directes, utilisez un protocole réseau. Avant de vous connecter, configurez au besoin les [ports réseau](/fr/concepts/features/security/network-ports), les [droits d’accès](/fr/concepts/features/security/access-rights) et le [TLS](/fr/concepts/features/security/tls/configuring-tls).
