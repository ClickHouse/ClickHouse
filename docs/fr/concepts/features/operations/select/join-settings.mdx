Cette page répertorie les paramètres de session qui influent sur la sémantique, la planification, l’exécution et la consommation mémoire des jointures. Chaque paramètre renvoie à son entrée dans la [référence des paramètres de session](/fr/reference/settings/session-settings), qui précise sa valeur par défaut et les valeurs acceptées. La syntaxe et la sémantique des jointures sont décrites dans la [référence de la clause `JOIN`](/fr/reference/statements/select/join).

## Sémantique et syntaxe {#semantics-and-syntax}

| Paramètre                                                                                                                                                                              | Description                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/fr/reference/settings/session-settings/join#join_default_strictness)                                                                                         | Définit la strictness d’un JOIN écrit sans strictness explicite.                                                                                                                              |
| [`any_join_distinct_right_table_keys`](/fr/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | Active le comportement hérité de `ANY INNER JOIN` et `ANY LEFT JOIN`, dans lequel `t1 ANY LEFT JOIN t2` et `t2 ANY RIGHT JOIN t1` peuvent renvoyer des résultats différents.                  |
| [`join_any_take_last_row`](/fr/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | Détermine si un JOIN avec la strictness `ANY` retient la première ou la dernière ligne correspondante lorsque la table de droite contient plusieurs lignes correspondantes pour une même clé. |
| [`join_use_nulls`](/fr/reference/settings/session-settings/join#join_use_nulls)                                                                                                           | Détermine si les colonnes des lignes sans correspondance dans un JOIN externe sont remplies avec des valeurs par défaut ou avec `NULL`.                                                       |
| [`semi_join_include_columns_from_both_sides`](/fr/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | Détermine si l’ensemble de résultats d’un `SEMI JOIN` expose les colonnes des deux tables ou uniquement celles de la table conservée.                                                         |
| [`anti_join_include_columns_from_both_sides`](/fr/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | Détermine si l’ensemble de résultats d’un `ANTI JOIN` expose les colonnes des deux tables ou uniquement celles de la table conservée.                                                         |
| [`cross_to_inner_join_rewrite`](/fr/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | Détermine si une liste de tables séparées par des virgules ou un `CROSS JOIN` comportant des conditions d’égalité dans `WHERE` est réécrit en `INNER JOIN`.                                   |
| [`allow_block_nested_loop_join`](/fr/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | Permet d’exécuter sous forme de jointure par boucles imbriquées par blocs un JOIN dont la section `ON` ne contient aucune égalité entre les tables.                                           |
| [`enable_lateral_join`](/fr/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | Active la syntaxe expérimentale `LATERAL JOIN`, dans laquelle une sous-requête située du côté droit d’un JOIN peut référencer des colonnes du côté gauche.                                    |
| [`single_join_prefer_left_table`](/fr/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | Résout vers la table de gauche un identifiant ambigu entre les deux tables d’un JOIN unique.                                                                                                  |
| [`joined_subquery_requires_alias`](/fr/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | Exige que les sous-requêtes et les fonctions de table utilisées dans un JOIN aient des alias.                                                                                                 |
| [`allow_dynamic_type_in_join_keys`](/fr/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | Autorise les clés de JOIN de type `Dynamic`.                                                                                                                                                  |
| [`analyzer_compatibility_join_using_top_level_identifier`](/fr/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | Résout un nom de colonne dans `USING` à partir d’un alias de même nom défini dans la requête, par exemple un alias de la liste `SELECT`.                                                      |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/fr/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | Qualifie les noms des colonnes de résultat avec les noms ou alias de table dans une requête comportant au moins deux jointures, comme le faisait l’ancien analyseur.                               |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/fr/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | Applique à toutes les tables jointes un modificateur `FINAL` placé sur la table la plus à gauche d’un JOIN, comme dans les versions antérieures à 26.6.                                       |

## Choix et réglage de l&#39;algorithme {#algorithm-selection-and-tuning}

| Paramètre                                                                                                                                     | Description                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`join_algorithm`](/fr/reference/settings/session-settings/join#join_algorithm)                                                                  | Liste les algorithmes de JOIN que ClickHouse peut utiliser, par ordre de priorité.                                                                                                                                      |
| [`parallel_hash_join_threshold`](/fr/reference/settings/session-settings/parallel#parallel_hash_join_threshold)                                  | Définit le nombre estimé de lignes de la table de droite à partir duquel une JOIN par hachage divise sa table de hachage en parties remplies simultanément par plusieurs fils d’exécution.                              |
| [`hash_join_layout`](/fr/reference/settings/session-settings/other#hash_join_layout)                                                             | Force une JOIN par hachage à construire soit une seule table de hachage sur un seul fil d’exécution, soit une table de hachage divisée sur plusieurs fils d’exécution, à des fins de test et de débogage.               |
| [`max_threads`](/fr/reference/settings/session-settings/max-threads#max_threads)                                                                 | Définit le nombre maximal de fils d’exécution de traitement des requêtes, ce qui limite également le nombre de fils d’exécution qui remplissent une table de hachage divisée.                                           |
| [`grace_hash_join_initial_buckets`](/fr/reference/settings/session-settings/grace-hash#grace_hash_join_initial_buckets)                          | Définit le nombre initial de compartiments d’une JOIN `grace_hash`.                                                                                                                                                     |
| [`grace_hash_join_max_buckets`](/fr/reference/settings/session-settings/grace-hash#grace_hash_join_max_buckets)                                  | Limite le nombre de compartiments d’une JOIN `grace_hash`.                                                                                                                                                              |
| [`partial_merge_join_rows_in_right_blocks`](/fr/reference/settings/session-settings/partial-merge#partial_merge_join_rows_in_right_blocks)       | Limite le nombre de lignes de chaque bloc trié de la table de droite dans une JOIN `partial_merge`.                                                                                                                     |
| [`partial_merge_join_left_table_buffer_bytes`](/fr/reference/settings/session-settings/partial-merge#partial_merge_join_left_table_buffer_bytes) | Définit la taille jusqu’à laquelle une JOIN `partial_merge` regroupe les blocs de la table de gauche en blocs plus grands.                                                                                              |
| [`join_on_disk_max_files_to_merge`](/fr/reference/settings/session-settings/join#join_on_disk_max_files_to_merge)                                | Limite le nombre de fichiers triés en parallèle lorsqu’une JOIN par fusion s’exécute sur disque.                                                                                                                        |
| [`max_rows_in_set_to_optimize_join`](/fr/reference/settings/session-settings/max-rows#max_rows_in_set_to_optimize_join)                          | Définit la taille maximale du set de clés utilisé pour filtrer chaque entrée d’une JOIN selon les clés de l’autre entrée avant la jointure.                                                                             |
| [`query_plan_join_shard_by_pk_ranges`](/fr/reference/settings/session-settings/query-plan#query_plan_join_shard_by_pk_ranges)                    | Exécute une JOIN entre deux tables `MergeTree` sous forme de JOIN indépendantes sur des plages de clé primaire lorsque les clés de jointure contiennent un préfixe de la clé primaire des deux tables.                  |
| [`join_output_by_rowlist_perkey_rows_threshold`](/fr/reference/settings/session-settings/join#join_output_by_rowlist_perkey_rows_threshold)      | Définit le nombre moyen de lignes par clé de la table de droite à partir duquel une JOIN par hachage produit les correspondances sous forme de liste de lignes.                                                         |
| [`allow_join_right_table_sorting`](/fr/reference/settings/session-settings/allow#allow_join_right_table_sorting)                                 | Autorise le réordonnancement de la table de droite par clé dans une JOIN par hachage `LEFT` ou `INNER` lorsque les conditions de `join_to_sort_minimum_perkey_rows` et `join_to_sort_maximum_table_rows` sont remplies. |
| [`join_to_sort_minimum_perkey_rows`](/fr/reference/settings/session-settings/join-to#join_to_sort_minimum_perkey_rows)                           | Définit le nombre moyen minimal de lignes par clé dans la table de droite pour que celle-ci soit réordonnée par clé.                                                                                                    |
| [`join_to_sort_maximum_table_rows`](/fr/reference/settings/session-settings/join-to#join_to_sort_maximum_table_rows)                             | Définit le nombre maximal de lignes dans la table de droite pour que celle-ci soit réordonnée par clé.                                                                                                                  |
| [`enable_hash_join_row_store`](/fr/reference/settings/session-settings/enable#enable_hash_join_row_store)                                        | Active la conversion de la charge utile d’une JOIN par hachage vers une disposition orientée lignes.                                                                                                                    |
| [`min_rows_ratio_for_hash_join_row_store`](/fr/reference/settings/session-settings/min#min_rows_ratio_for_hash_join_row_store)                   | Définit le ratio estimé minimal entre les lignes de sortie et les lignes du côté construction à partir duquel la charge utile d’une JOIN par hachage est convertie vers une disposition orientée lignes.                |
| [`enable_join_fixed_hash_table_conversion`](/fr/reference/settings/session-settings/enable-join#enable_join_fixed_hash_table_conversion)         | Active la conversion de la table de hachage d’une JOIN en tableau plat lorsque la clé est un entier unique dont la plage de valeurs est réduite.                                                                        |
| [`enable_join_key_only_hash_tables`](/fr/reference/settings/session-settings/enable-join#enable_join_key_only_hash_tables)                       | Active les tables de hachage qui ne stockent que les clés de jointure, pour les JOIN `LEFT ANTI` et pour les JOIN `LEFT SEMI` qui ne sélectionnent aucune colonne de la table de droite.                                |
| [`enable_software_prefetch_in_join`](/fr/reference/settings/session-settings/enable-software#enable_software_prefetch_in_join)                   | Active la prélecture logicielle pendant la phase de sondage d’une JOIN par hachage.                                                                                                                                     |
| [`enable_packed_string_keys_in_hash_join`](/fr/reference/settings/session-settings/enable#enable_packed_string_keys_in_hash_join)                | Accélère les JOIN par hachage sur une clé `String` unique et réduit leur consommation de mémoire, en stockant chaque clé sur 16 octets dans la table de hachage.                                                        |
| [`min_rows_for_packed_string_keys_in_hash_join`](/fr/reference/settings/session-settings/min#min_rows_for_packed_string_keys_in_hash_join)       | Définit le nombre estimé de lignes de la table de droite en dessous duquel une JOIN par hachage conserve les clés `String` exactes au lieu de clés compactées.                                                          |
| [`collect_hash_table_stats_during_joins`](/fr/reference/settings/session-settings/collect-hash#collect_hash_table_stats_during_joins)            | Active la collecte de statistiques sur les tables de hachage, utilisées par les exécutions ultérieures de la même JOIN pour dimensionner leurs tables de hachage.                                                       |
| [`max_size_to_preallocate_for_joins`](/fr/reference/settings/session-settings/max-size#max_size_to_preallocate_for_joins)                        | Limite le nombre total d’éléments pour lesquels de l’espace est préalloué dans les tables de hachage d’une JOIN.                                                                                                        |
| [`max_joined_block_size_rows`](/fr/reference/settings/session-settings/max-joined#max_joined_block_size_rows)                                    | Limite le nombre de lignes d’un bloc du résultat JOIN.                                                                                                                                                                  |
| [`max_joined_block_size_bytes`](/fr/reference/settings/session-settings/max-joined#max_joined_block_size_bytes)                                  | Limite la taille en octets d’un bloc du résultat JOIN.                                                                                                                                                                  |
| [`min_joined_block_size_rows`](/fr/reference/settings/session-settings/min-joined#min_joined_block_size_rows)                                    | Définit le nombre de lignes en dessous duquel les blocs d’entrée et de sortie d’une JOIN sont regroupés en blocs plus grands.                                                                                           |
| [`min_joined_block_size_bytes`](/fr/reference/settings/session-settings/min-joined#min_joined_block_size_bytes)                                  | Définit la taille en octets en dessous de laquelle les blocs d’entrée et de sortie d’une JOIN sont regroupés en blocs plus grands.                                                                                      |
| [`joined_block_split_single_row`](/fr/reference/settings/session-settings/joined#joined_block_split_single_row)                                  | Autorise la division en plusieurs blocs du résultat d’une JOIN par hachage pour une ligne de la table de gauche ayant de nombreuses correspondances.                                                                    |
| [`parallel_non_joined_rows_processing`](/fr/reference/settings/session-settings/parallel#parallel_non_joined_rows_processing)                    | Permet à plusieurs fils d’exécution de produire les lignes sans correspondance de la table de droite dans une JOIN `RIGHT` ou `FULL`.                                                                                   |
| [`enable_lazy_columns_replication`](/fr/reference/settings/session-settings/enable#enable_lazy_columns_replication)                              | Active la réplication différée des colonnes dans l&#39;ensemble de résultats d&#39;un JOIN, ce qui évite de copier plusieurs fois les mêmes lignes en mémoire.                                                          |

## Planificateur de requêtes {#query-planner}

| Paramètre                                                                                                                                                                       | Description                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`query_plan_join_swap_table`](/fr/reference/settings/session-settings/query-plan#query_plan_join_swap_table)                                                                      | Détermine quelle entrée d’un JOIN le planificateur utilise comme côté build.                                                                                                                            |
| [`query_plan_optimize_join_order_limit`](/fr/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_limit)                                                  | Définit le nombre maximal de tables dans une sous-requête jusqu’auquel le planificateur optimise l’ordre des JOIN.                                                                                      |
| [`query_plan_optimize_join_order_algorithm`](/fr/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_algorithm)                                          | Liste les algorithmes d’ordre des jointures que le planificateur essaie successivement, dans l’ordre indiqué.                                                                                           |
| [`query_plan_optimize_join_order_conflict_detector`](/fr/reference/settings/session-settings/query-plan#query_plan_optimize_join_order_conflict_detector)                          | Sélectionne le détecteur de conflits utilisé par l’algorithme d’ordre des jointures `dpsub` pour déterminer quels réordonnancements sont valides.                                                       |

| [`use_hash_table_stats_for_join_reordering`](/fr/reference/settings/session-settings/use#use_hash_table_stats_for_join_reordering)                                                 | Active l’utilisation des statistiques collectées sur les tables de hachage pour estimer la cardinalité lors du réordonnancement des JOIN.                                                               |
| [`use_datalake_metadata_statistics`](/fr/reference/settings/session-settings/use)                                                                                                  | Active l’estimation d’une lecture de data lake (Iceberg uniquement) pour le réordonnancement des JOIN à partir des statistiques contenues dans les métadonnées de sa table.                             |

| [`query_plan_convert_join_to_in`](/fr/reference/settings/session-settings/query-plan#query_plan_convert_join_to_in)                                                                | Autorise la conversion d’un JOIN en sous-requête avec `IN` lorsque les colonnes de sortie proviennent uniquement de la table de gauche.                                                                 |
| [`rewrite_in_to_join`](/fr/reference/settings/session-settings/rewrite#rewrite_in_to_join)                                                                                         | Réécrit les expressions de la forme `x IN subquery` sous forme de JOIN.                                                                                                                                 |

| [`query_plan_merge_expression_into_join`](/fr/reference/settings/session-settings/query-plan#query_plan_merge_expression_into_join)                                                | Autorise la fusion d’expressions dans l’étape JOIN lors du réordonnancement des JOIN.                                                                                                                   |
| [`query_plan_short_circuit_constant_false_join`](/fr/reference/settings/session-settings/query-plan#query_plan_short_circuit_constant_false_join)                                  | Remplace par une source vide chaque entrée d’un JOIN qui ne peut fournir aucune ligne lorsque la condition `ON` se réduit à la constante false.                                                         |

| [`query_plan_top_k_through_join`](/fr/reference/settings/session-settings/query-plan#query_plan_top_k_through_join)                                                                | Pousse `ORDER BY ... LIMIT n` sous un JOIN `LEFT` ou `RIGHT` lorsque la clé de tri ne référence que des colonnes du côté préservé.                                                                      |
| [`query_plan_propagate_predicate_across_join`](/fr/reference/settings/session-settings/query-plan#query_plan_propagate_predicate_across_join)                                      | Copie les conditions de filtre d’un côté d’un JOIN d’égalité vers l’autre côté via les clés de JOIN.                                                                                                    |
| [`enable_join_transitive_predicates`](/fr/reference/settings/session-settings/enable-join#enable_join_transitive_predicates)                                                       | Déduit des conditions d’égalité transitives à partir des conditions de JOIN existantes, à l’usage de l’optimiseur de l’ordre des jointures.                                                             |
| [`use_join_disjunctions_push_down`](/fr/reference/settings/session-settings/use#use_join_disjunctions_push_down)                                                                   | Active le déplacement des parties des conditions de JOIN reliées par `OR` vers les entrées correspondantes.                                                                                             |
| [`query_plan_lazy_materialization_for_join`](/fr/reference/settings/session-settings/query-plan#query_plan_lazy_materialization_for_join)                                          | Active la matérialisation différée pour les requêtes `LIMIT n` portant sur des JOIN, afin que les colonnes ne soient lues que pour les lignes restantes après `LIMIT`.                                  |
| [`query_plan_max_limit_for_join_lazy_indexing`](/fr/reference/settings/session-settings/query-plan#query_plan_max_limit_for_join_lazy_indexing)                                    | Définit la valeur `LIMIT` maximale jusqu’à laquelle l’optimisation de l’indexation paresseuse d’un JOIN est utilisée.                                                                                   |
| [`query_plan_min_columns_for_join_lazy_indexing`](/fr/reference/settings/session-settings/query-plan#query_plan_min_columns_for_join_lazy_indexing)                                | Définit le nombre minimal de colonnes de données utiles du côté gauche à partir duquel l’optimisation de l’indexation paresseuse d’un JOIN est utilisée.                                                |
| [`enable_join_runtime_filters`](/fr/reference/settings/session-settings/enable-join#enable_join_runtime_filters)                                                                   | Active le filtrage du côté sondage d’un JOIN à l’aide du set de clés de JOIN collecté à l’exécution depuis le côté build.                                                                               |
| [`enable_join_runtime_filters_index_analysis`](/fr/reference/settings/session-settings/enable-join#enable_join_runtime_filters_index_analysis)                                     | Active l’élagage des granules du côté sondage d’un JOIN à l’aide du filtre d’exécution.                                                                                                                 |
| [`enable_join_seal_gated_reading`](/fr/reference/settings/session-settings/enable-join#enable_join_seal_gated_reading)                                                             | Retarde la lecture du côté sondage d&#39;une jointure de hachage (JOIN) jusqu&#39;à ce que le filtre d&#39;exécution du côté build soit complet.                                                        |
