> Ce guide explique comment utiliser le serveur MCP ClickHouse avec [Jan.ai](https://jan.ai/docs).

<Steps>
  <Step title="Installer Jan.ai" id="install-janai">
    Jan.ai est une alternative open source à ChatGPT qui fonctionne entièrement hors ligne.
    Vous pouvez télécharger Jan.ai pour [Mac](https://jan.ai/docs/desktop/install/mac), [Windows](https://jan.ai/docs/desktop/windows) ou [Linux](https://jan.ai/docs/desktop/linux).

    Il s&#39;agit d&#39;une application native : il suffit de la lancer une fois téléchargée.
  </Step>

  <Step title="Ajouter un LLM à Jan.ai" id="add-llm-to-janai">
    Les modèles s&#39;activent depuis le menu des paramètres.

    Pour activer OpenAI, il faut fournir une API key, comme illustré ci-dessous :

    <div className="ch-image-md">
      <Frame>
        ![Activer les modèles OpenAI](/images/use-cases/AI_ML/MCP/0_janai_openai.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Activer les serveurs MCP" id="enable-mcp-servers">
    À l&#39;heure où nous écrivons ces lignes, les serveurs MCP sont une fonctionnalité expérimentale de Jan.ai.
    Pour les activer, il suffit d&#39;actionner l&#39;interrupteur des fonctionnalités expérimentales :

    <div className="ch-image-md">
      <Frame>
        ![Activer les serveurs MCP](/images/use-cases/AI_ML/MCP/1_janai_mcp_servers.webp)
      </Frame>
    </div>

    Une fois l&#39;interrupteur activé, l&#39;entrée `MCP servers` apparaît dans le menu de gauche.
  </Step>

  <Step title="Configurer le serveur MCP ClickHouse" id="configure-clickhouse-mcp-server">
    Le menu `MCP servers` affiche la liste des serveurs MCP auxquels il est possible de se connecter :

    <div className="ch-image-md">
      <Frame>
        ![Liste des serveurs MCP](/images/use-cases/AI_ML/MCP/2_janai_mcp_servers_list.webp)
      </Frame>
    </div>

    Ces serveurs sont tous désactivés par défaut, mais vous pouvez les activer à l&#39;aide de leur interrupteur.

    Pour installer le serveur MCP ClickHouse, cliquez sur l&#39;icône `+`, puis remplissez le formulaire avec les informations suivantes :

    <div className="ch-image-md">
      <Frame>
        ![Ajouter un serveur MCP](/images/use-cases/AI_ML/MCP/3_janai_add_mcp_server.webp)
      </Frame>
    </div>

    Activez ensuite l&#39;interrupteur du serveur ClickHouse s&#39;il ne l&#39;est pas déjà :

    <div className="ch-image-md">
      <Frame>
        ![Activer le serveur MCP](/images/use-cases/AI_ML/MCP/4_janai_toggle.webp)
      </Frame>
    </div>

    Les outils du serveur MCP ClickHouse sont désormais visibles dans la fenêtre de conversation :

    <div className="ch-image-md">
      <Frame>
        ![Outils du serveur MCP ClickHouse](/images/use-cases/AI_ML/MCP/5_jani_tools.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Converser avec le serveur MCP ClickHouse via Jan.ai" id="chat-to-clickhouse-mcp-server">
    Place maintenant à une conversation sur des données stockées dans ClickHouse !
    Posons une question :

    <div className="ch-image-md">
      <Frame>
        ![Question](/images/use-cases/AI_ML/MCP/6_janai_question.webp)
      </Frame>
    </div>

    Jan.ai demande une confirmation avant d&#39;appeler un outil :

    <div className="ch-image-md">
      <Frame>
        ![Confirmation de l'outil](/images/use-cases/AI_ML/MCP/7_janai_tool_confirmation.webp)
      </Frame>
    </div>

    Il affiche ensuite la liste des appels d&#39;outils effectués :

    <div className="ch-image-md">
      <Frame>
        ![Outils appelés](/images/use-cases/AI_ML/MCP/8_janai_tools_called.webp)
      </Frame>
    </div>

    Un clic sur l&#39;appel d&#39;outil permet d&#39;en afficher les détails :

    <div className="ch-image-md">
      <Frame>
        ![Outils appelés (vue détaillée)](/images/use-cases/AI_ML/MCP/9_janai_tools_called_expanded.webp)
      </Frame>
    </div>

    Enfin, le résultat s&#39;affiche juste en dessous :

    <div className="ch-image-md">
      <Frame>
        ![Résultat](/images/use-cases/AI_ML/MCP/10_janai_result.webp)
      </Frame>
    </div>
  </Step>
</Steps>
