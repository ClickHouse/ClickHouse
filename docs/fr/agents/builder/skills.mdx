Une compétence est un ensemble d&#39;instructions réutilisable qu&#39;un agent peut appliquer à la demande. Utilisez les compétences pour les procédures communes à plusieurs agents — un guide de style de marque, une checklist de revue de code, un runbook pour un flux de travail spécifique — plutôt que de dupliquer les instructions dans l&#39;instruction système de chaque agent.

## Anatomie d&#39;une compétence {#anatomy-of-a-skill}

Une compétence est un fichier Markdown doté d&#39;un court en-tête frontmatter :

```markdown
---
name: revenue-report
description: Generates the weekly revenue report using our standard segments
always-apply: false
user-invocable: true
---

When asked to generate a revenue report:
1. Filter to the requested period.
2. Apply the standard MRR formula:
     SUM(CASE
       WHEN billing_cycle = 'monthly' THEN amount
       WHEN billing_cycle = 'yearly'  THEN amount / 12
       ELSE 0
     END)
3. Break down by segment: Enterprise, Mid-Market, SMB.
4. Render the result as a Markdown table.
```

Les paramètres du frontmatter les plus importants :

* **`name`** - identifiant au format kebab-case.
* **`description`** - court résumé utilisé par le modèle pour déterminer quand cette compétence est pertinente. C’est le champ le plus important. Rédigez-le de manière précise : une description vague conduit à invoquer la mauvaise compétence.
* **`always-apply`** - lorsque la valeur est `true`, la compétence est préchargée à chaque tour au lieu d’être sélectionnée. À utiliser avec parcimonie : les compétences always-apply consomment du contexte à chaque message.
* **`user-invocable`** - lorsque la valeur est `true` (valeur par défaut), la compétence apparaît dans la fenêtre contextuelle `$` pour être sélectionnée manuellement.

Vous pouvez joindre des fichiers complémentaires à la compétence (documentation de référence, exemples de requêtes, petits scripts) en téléversant un fichier `.zip` contenant le `SKILL.md` et ses ressources.

## Utiliser une compétence {#use-a-skill}

Un agent peut faire appel à une compétence dans une conversation de trois manières :

* **Invocation par l&#39;utilisateur** - appuyez sur `$` dans la zone de saisie et choisissez la compétence dans la fenêtre contextuelle. Le contenu de la compétence est préchargé pour le tour suivant.
* **Sélection automatique par le modèle** - en fonction de la `description` de la compétence, l&#39;agent décide lui-même quand l&#39;appliquer.
* **Always-apply** - le contenu est préchargé à chaque tour pour les compétences configurées ainsi.

## Gérer les compétences {#manage-skills}

Le panneau Compétences de la Console Cloud vous permet de créer des compétences directement dans l&#39;interface, de téléverser des fichiers `.md` ou `.zip` et de choisir les compétences actives pour votre utilisateur. Les compétences dont vous êtes propriétaire sont actives par défaut ; désactivez-en une pour la retirer de la fenêtre contextuelle et du catalogue du modèle sans la supprimer.

Les compétences peuvent être partagées avec d&#39;autres utilisateurs (voir [partage et accès](/fr/agents/sharing-and-access)).

## Compétences ou instructions {#skills-vs-instructions}

* Les **instructions de l’agent** définissent ce qu’est l’agent et son comportement général. Elles sont toujours actives pour cet agent.
* Les **compétences** sont contextuelles : elles s’appliquent lorsqu’elles sont pertinentes et se limitent à des flux de travail spécifiques.

Privilégiez une compétence lorsque le même ensemble d’instructions détaillées se retrouve dans plusieurs agents, ou lorsque vous souhaitez qu’elle ne soit déclenchée que pour certaines requêtes utilisateur plutôt qu’à chaque échange.
