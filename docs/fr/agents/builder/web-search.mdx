La Recherche sur le Web permet à un agent de récupérer des informations sur le Web public au cours d&#39;une conversation. Utilisez-la pour les questions qui exigent une réponse à jour : versions récentes, documentation hébergée en dehors de votre service ou vérification rapide auprès d&#39;une source faisant autorité.

## Activer la fonctionnalité {#enable-it}

Dans le Créateur d’agents, activez **Recherche sur le Web** dans la section **Capacités**. Une fois l’option activée, l’agent détermine quand lancer une recherche en fonction de la question de l’utilisateur et de ses propres instructions. La recherche est exécutée, le contenu des résultats est collecté, puis les éléments les plus pertinents sont réinjectés dans le contexte du modèle.

## Fonctionnement d&#39;un cycle de recherche {#how-a-search-round-works}

Chaque recherche se déroule en trois étapes, entièrement gérées pour vous dans Cloud :

1. **Recherche** - la requête de l&#39;agent est transmise à un fournisseur de recherche, qui renvoie des URL candidates.
2. **Collecte** - les pages pertinentes sont récupérées, puis leur contenu textuel utile est extrait.
3. **Reclassement** - un modèle de reclassement attribue un score à chaque résultat afin que le modèle consulte en priorité les plus utiles.

Dans sa réponse, l&#39;agent cite les URL qu&#39;il a réellement utilisées.

## Quand l&#39;utiliser {#when-to-use-it}

* Consulter des notes de version ou des journaux des modifications qui ne figurent pas dans votre service.
* Vérifier un fait auprès d&#39;une source que le modèle ne connaît peut-être pas.
* Importer un article de blog ou une documentation publique dans la conversation pour l&#39;analyser.

Inutile d&#39;y recourir pour les questions auxquelles vos données ou les connaissances propres du modèle suffisent à répondre. Chaque cycle de recherche augmente la latence.
