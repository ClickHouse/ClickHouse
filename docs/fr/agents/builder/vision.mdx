Vision permet aux utilisateurs de téléverser des images afin qu&#39;un agent les analyse. L&#39;agent transmet l&#39;image à un modèle doté de capacités de vision, qui en décrit le contenu, le résume ou répond à des questions à son sujet.

## Activer les fonctionnalités Vision {#enable-it}

Vision ne fonctionne qu&#39;avec les modèles qui prennent en charge les images en entrée. Si le modèle sélectionné ne peut pas traiter les images en entrée, le bouton de téléversement de la zone de rédaction des messages est désactivé. Sélectionnez un modèle doté de capacités de vision pour le réactiver.

## Utiliser les fonctionnalités Vision {#use-it}

Cliquez sur l&#39;icône en forme de trombone en bas à gauche de la zone de rédaction des messages, puis choisissez **Upload to Provider** pour joindre une image : capture d&#39;écran, photo, graphique, diagramme… Posez ensuite toute question nécessitant de lire l&#39;image : *« Qu&#39;est-ce qui ne va pas dans ce plan de requête ? »*, *« Transcris le texte de cette capture d&#39;écran »* ou *« Compare ce tableau de bord à celui de la semaine dernière. »*

L&#39;agent intègre l&#39;image au contexte du message : les questions de suivi posées dans le même tour peuvent donc s&#39;appuyer sur ce qu&#39;il a vu, sans avoir à la téléverser de nouveau.

## Combiner Vision avec d&#39;autres outils {#combine-with-other-tools}

Vision se combine efficacement avec l&#39;[interpréteur de code](/fr/agents/builder/code-interpreter) pour analyser des images — par exemple, l&#39;agent relève des nombres sur une capture d&#39;écran, puis exécute du code Python pour calculer des totaux —, ainsi qu&#39;avec la [recherche sur le Web](/fr/agents/builder/web-search) lorsqu&#39;une image fait référence à un élément que le modèle doit rechercher.
