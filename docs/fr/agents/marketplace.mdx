La Place de marché d’agents vous permet de parcourir, de rechercher et d’exécuter les agents que d’autres membres de votre organisation ont partagés avec vous. Elle regroupe également les agents que votre administrateur a publiés à l’échelle de l’organisation. Pour y accéder, cliquez sur l’option **Place de marché d’agents** dans la barre latérale gauche.

## Parcourir {#browse}

Les agents sont regroupés en catégories — par exemple, *General*, *Human Resources*, *Research &amp; Development*, *Finance*, *IT*, *Sales*. Passez d’une catégorie à l’autre à l’aide des onglets situés en haut de la place de marché. Chaque carte d’agent affiche le nom de l’agent, une icône et sa catégorie.

Utilisez la barre de recherche pour trouver un agent par son nom ou par mot-clé, toutes catégories confondues.

## Ouvrir un agent {#open-an-agent}

Cliquez sur une carte d’agent pour ouvrir sa vue détaillée. Vous pouvez alors :

* **Start Chat** : ouvrir une nouvelle conversation avec l’agent.
* **Pin** : ajouter l’agent à vos favoris pour y accéder rapidement.
* **Copy link** : partager un lien direct vers l’agent.

## Publier votre propre agent {#publish-your-own}

Pour rendre un agent visible dans la place de marché, partagez-le avec la portée appropriée depuis le panneau [partage et accès](/fr/agents/sharing-and-access). Les niveaux de visibilité sont les suivants :

* **Privé** - visible par vous seul. N’apparaît pas dans la place de marché.
* **Partagé avec des utilisateurs ou des groupes** - visible par ces principaux de sécurité. Apparaît dans leur place de marché.
* **À l’échelle de l’organisation** - visible par tous les membres de l’organisation. Soumis aux autorisations de place de marché définies par votre administrateur.

Avant de publier votre agent, attribuez-lui une catégorie et rédigez une description claire : ces champs alimentent à la fois la recherche et la navigation par catégories.

## Contrôles d’administration {#admin-controls}

Les administrateurs de l’organisation peuvent :

* Choisir les catégories affichées dans la place de marché.
* Mettre en avant certains agents dans la vue à l’échelle de l’organisation.
* Autoriser ou restreindre l’accès à la place de marché selon le rôle.

Consultez [partage et accès](/fr/agents/sharing-and-access) pour en savoir plus sur le modèle de permissions.
