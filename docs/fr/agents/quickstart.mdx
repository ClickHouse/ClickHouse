Créez un agent personnalisé dans la Console Cloud et exécutez une requête en langage naturel sur votre service.

## Prérequis {#prerequisites}

* Un service ClickHouse Cloud sur lequel vous pouvez exécuter des requêtes.
* L’option **Créer un agent** dans le Créateur d’agents. Si elle n’apparaît pas, demandez à un administrateur de l’organisation de vous accorder le droit de créer des agents dans les Paramètres d’administration, comme décrit dans [partage et accès](/fr/agents/sharing-and-access).

## Créer l’agent {#build-the-agent}

<Steps>
  <Step title="Lancer ClickHouse Agents" id="launch-agents">
    Depuis votre Service Cloud, cliquez sur **ClickHouse agents** dans la barre latérale gauche pour ouvrir la page de lancement des agents. Cliquez ensuite sur **Launch ClickHouse agents** pour ouvrir le Créateur d’agents.

    <div className="ch-image-lg">
      <Frame>
        ![Navigation du Service Cloud avec ClickHouse agents (Beta) sélectionné, affichant la page de lancement avec le bouton Launch ClickHouse agents](/images/cloud/agent-builder/launch-ch-agents.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Créer l’agent" id="create-the-agent">
    Dans le Créateur d’agents, cliquez sur **Create New Agent** en haut du panneau de gauche. Renseignez les champs principaux :

    * **Name** : un identifiant court pour votre agent.
    * **Description** : une description de la finalité de l’agent, visible par vos collègues.
    * **Category** : une catégorie pour votre agent. Vous pouvez conserver `General`, sauf si votre organisation dispose de catégories personnalisées.
    * **Instructions** : l’instruction système, qui décrit le rôle de l’agent, les questions auxquelles il doit répondre et les règles métier qu’il doit respecter.
    * **Model** : sélectionnez un modèle dans la liste déroulante.

    <div className="ch-image-lg">
      <Frame>
        ![Panneau du Créateur d’agents affichant la liste déroulante Create New Agent, les champs du formulaire (Name, Description, Category, Instructions, Model) et la section Capabilities](/images/cloud/agent-builder/agent-builder.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Associer des capacités et des outils" id="attach-tools">
    Les capacités et les outils de l’agent se configurent à deux endroits.

    **Capabilities**, dans le panneau principal : des fonctionnalités natives comme [Run Code](/fr/agents/builder/code-interpreter), [Web Search](/fr/agents/builder/web-search), File Context, Artifacts, [MCP Servers](/fr/agents/builder/mcp-servers) et [Skills](/fr/agents/builder/skills). Activez celles dont l’agent a besoin.

    <div className="ch-image-sm">
      <Frame>
        ![Section Capabilities du panneau du Créateur d’agents affichant les interrupteurs Run Code, Web Search, File Context, Artifacts, MCP Servers et Skills](/images/cloud/agent-builder/capabilities.webp)
      </Frame>
    </div>

    **Tools**, accessibles via le bouton **Add Tools** en bas du panneau : des intégrations tierces comme la [génération d’images](/fr/agents/builder/image-generation), [Vision](/fr/agents/builder/vision), des API de recherche et des services externes.

    <div className="ch-image-sm">
      <Frame>
        ![Bas du panneau du Créateur d’agents avec le bouton Add Tools mis en évidence](/images/cloud/agent-builder/tools-button.webp)
      </Frame>
    </div>

    Cliquez sur **Add Tools** pour parcourir le catalogue :

    <div className="ch-image-lg">
      <Frame>
        ![Boîte de dialogue modale Agent Tools affichant une grille d’intégrations tierces, dont Google, OpenAI Image Tools, Wolfram, DALL-E-3, Tavily Search, Calculator et Stable Diffusion](/images/cloud/agent-builder/tools-modal.webp)
      </Frame>
    </div>

    Les [sous-agents](/fr/agents/builder/subagents) se configurent dans **Advanced settings** ; pour plus de détails, consultez la page consacrée aux sous-agents.

    Vous pouvez modifier à tout moment les capacités et les outils associés.
  </Step>

  <Step title="Exécuter une requête" id="run-a-query">
    Enregistrez l’agent, ouvrez une nouvelle conversation et sélectionnez votre agent dans le sélecteur d’agents. Saisissez une question, par exemple *« Quelles sont mes 10 tables les plus volumineuses en nombre de lignes cette semaine ? »* : l’agent planifie sa démarche, appelle les outils nécessaires et renvoie une réponse.

    <div className="ch-image-lg">
      <Frame>
        ![Échange de conversation affichant la question « What are my top 10 tables by row count this week? » et la réponse de l’agent : un tableau markdown classant les 10 principales tables de tous les services par nombre de lignes, suivi de Key Observations](/images/cloud/agent-builder/chat-query.webp)
      </Frame>
    </div>
  </Step>
</Steps>
