## Conversations {#conversations}

Pour démarrer une nouvelle conversation, cliquez sur l&#39;icône de rédaction dans la navigation de gauche.
Choisissez l&#39;agent à utiliser dans le sélecteur d&#39;agent, en haut à gauche de la fenêtre de conversation ; par défaut, **ClickHouse Agent** est sélectionné.
Vous pouvez ensuite saisir votre message dans la zone de saisie, puis l&#39;envoyer. Chaque conversation est enregistrée dans l&#39;historique de la barre latérale et peut être rouverte, renommée ou supprimée par la suite.

<div className="ch-image-lg">
  <Frame>

  </Frame>
</div>

Vous pouvez modifier directement n&#39;importe lequel de vos messages : l&#39;agent régénère alors sa réponse à partir de ce point de l&#39;historique de conversation.
Vous pouvez également régénérer uniquement la dernière réponse de l&#39;agent, sans renvoyer votre message.

## Favoris {#bookmarks}

Ajoutez un message ou une conversation entière à vos favoris pour le retrouver rapidement. Les favoris vous sont propres et sont conservés même si vous renommez la conversation.

## Conversations épinglées {#pinned-conversations}

Épinglez une conversation pour la garder en haut de la barre latérale, à l&#39;écart de l&#39;historique regroupé par date affiché en dessous. Dans la barre latérale, ouvrez le menu d&#39;options de la conversation (l&#39;icône à trois points) et sélectionnez **Pin**. Les conversations épinglées sont regroupées dans une section **Pinned**, au-dessus des groupes **Today**, **Yesterday** et des groupes plus anciens.

Pour désépingler une conversation, ouvrez le même menu et sélectionnez **Unpin**.

## Création de branches {#forking}

La création de branches génère une nouvelle conversation à partir d’un message précis. Elle permet d’explorer une piste alternative sans modifier le fil de discussion d’origine.
Trois modes de bifurcation sont disponibles :

* **Visible messages only** : copie le chemin direct jusqu’au message de bifurcation.
* **Include related branches** : copie le chemin principal ainsi que toutes les branches existantes.
* **Include all to here** : copie l’intégralité du contenu jusqu’au message de bifurcation.

Les conversations issues d’une bifurcation sont indépendantes : les modifications ne sont pas répercutées dans la conversation d’origine.

## Partage de conversations {#sharing-chats}

Générez un lien partageable pour n&#39;importe quelle conversation afin de l&#39;envoyer à un coéquipier ou de la conserver pour vous y référer ultérieurement. Les destinataires accèdent à une vue en lecture seule, artefacts et branches visibles compris. Vous pouvez révoquer un lien à tout moment depuis le tableau de bord de partage.

Les modifications apportées aux messages existants apparaissent dans la vue partagée, contrairement aux messages ajoutés après la génération du lien.

Toute personne qui consulte un lien partagé peut reprendre la conversation dans son propre compte en cliquant sur **Continuer cette conversation**. La conversation, y compris la branche consultée, est alors copiée dans son historique sous la forme d&#39;une nouvelle conversation privée, sans que votre conversation d&#39;origine soit modifiée.

Pour partager une conversation, ouvrez son menu dans la barre latérale et sélectionnez **Partager** :

## Raccourcis clavier {#keyboard-shortcuts}

Pour afficher la liste des raccourcis clavier, utilisez `Cmd+Shift+/` (`Ctrl+Shift+/` sous Windows et Linux) ou passez par le menu du compte, sous **Aide** → **Raccourcis clavier**. Tous les raccourcis sont personnalisables : cliquez sur une ligne de la boîte de dialogue pour enregistrer une nouvelle combinaison, puis utilisez **Tout réinitialiser** pour revenir aux valeurs par défaut.

Voici les raccourcis par défaut :

| Action                              | macOS                 | Windows et Linux       |
| ----------------------------------- | --------------------- | ---------------------- |
| Afficher les raccourcis clavier     | `Cmd+Shift+/`         | `Ctrl+Shift+/`         |
| Nouvelle conversation               | `Cmd+Shift+O`         | `Ctrl+Shift+O`         |
| Activer le champ de saisie          | `Shift+Esc`           | `Shift+Esc`            |
| Téléverser un fichier               | `Cmd+Shift+U`         | `Ctrl+Shift+U`         |
| Copier la dernière réponse          | `Cmd+Shift+;`         | `Ctrl+Shift+;`         |
| Envoyer le message                  | `Cmd+Enter`           | `Ctrl+Enter`           |
| Afficher/masquer la barre latérale  | `Cmd+Shift+S`         | `Ctrl+Shift+S`         |
| Ouvrir le sélecteur de modèle       | `Cmd+Shift+M`         | `Ctrl+Shift+M`         |
| Activer la recherche                | `Cmd+/`               | `Ctrl+/`               |
| Ouvrir les paramètres               | `Cmd+Shift+,`         | `Ctrl+Shift+,`         |
| Ajouter la conversation aux favoris | `Cmd+Shift+B`         | `Ctrl+Shift+B`         |
| Arrêter la génération               | `Cmd+Shift+X`         | `Ctrl+Shift+X`         |
| Régénérer la réponse                | `Cmd+Shift+E`         | `Ctrl+Shift+E`         |
| Modifier le dernier message         | `Cmd+Shift+I`         | `Ctrl+Shift+I`         |
| Poursuivre la réponse               | `Cmd+Shift+C`         | `Ctrl+Shift+C`         |
| Copier le dernier bloc de code      | `Cmd+Shift+K`         | `Ctrl+Shift+K`         |
| Remonter tout en haut               | `Cmd+Shift+Up`        | `Ctrl+Shift+Up`        |
| Descendre tout en bas               | `Cmd+Shift+Down`      | `Ctrl+Shift+Down`      |
| Archiver la conversation            | `Cmd+Shift+L`         | `Ctrl+Shift+L`         |
| Supprimer la conversation           | `Cmd+Shift+Backspace` | `Ctrl+Shift+Backspace` |

Vous pouvez également définir vos propres raccourcis pour ouvrir des panneaux tels que les agents, les Prompts, les fichiers et les favoris, qui n&#39;ont pas de raccourci par défaut.
