Assistant vous permet d’analyser en langage naturel les données d’un service ClickHouse Cloud. Il peut générer des requêtes, des visualisations et des synthèses en s’appuyant sur le contexte, notamment les onglets actifs, les requêtes enregistrées, les schémas et les tableaux de bord.

Assistant propose également un mode Docs AI pour poser des questions dont les réponses s’appuient sur la documentation ClickHouse. Ce guide explique comment activer Assistant et utiliser ses deux modes dans la console ClickHouse Cloud.

<Steps>
  <Step title="Prérequis" id="prerequisites">
    1. Vous devez avoir accès à une organisation ClickHouse Cloud dont les fonctionnalités d&#39;IA sont activées (si elles ne sont pas disponibles, contactez l&#39;administrateur de votre organisation ou l&#39;Assistance).
  </Step>

  <Step title="Ouvrir le panneau Chat IA" id="open-panel">
    1. Accédez à un service ClickHouse Cloud.
    2. Dans la barre latérale gauche, cliquez sur l&#39;icône en forme d&#39;étincelle intitulée « Assistant ».
    3. (Raccourci) Appuyez sur <kbd>⌘</kbd> + <kbd>&#39;</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>&#39;</kbd> (Linux/Windows) pour l&#39;ouvrir ou le fermer.

    <div className="ch-image-md">
      <Frame>
        ![Ouvrir le panneau déroulant Chat IA](/images/use-cases/AI_ML/AIChat/1_open_chat.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Accepter les conditions d'utilisation des données (première utilisation)" id="consent">
    1. Lors de la première utilisation, une boîte de dialogue de consentement s&#39;affiche. Elle décrit le traitement des données et les sous-traitants LLM tiers.
    2. Lisez-la, puis acceptez pour continuer. Si vous refusez, le panneau ne s&#39;ouvrira pas.

    <div className="ch-image-md">
      <Frame>
        ![Boîte de dialogue de consentement](/images/use-cases/AI_ML/AIChat/2_consent.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Choisir un mode de conversation" id="modes">
    Chat IA prend actuellement en charge les modes suivants :

    * **Agent** : raisonnement en plusieurs étapes sur le schéma et les métadonnées (le service doit être actif).
    * **Docs AI (Ask)** : questions-réponses ciblées, fondées sur la documentation officielle de ClickHouse et sur des références de bonnes pratiques.

    Pour changer de mode, utilisez le sélecteur de mode situé en bas à gauche du panneau déroulant.

    <div className="ch-image-sm">
      <Frame>
        ![Sélection du mode](/images/use-cases/AI_ML/AIChat/3_modes.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Rédiger et envoyer un message" id="compose">
    1. Saisissez votre question (par ex. « Créer une vue matérialisée pour agréger les événements quotidiens par utilisateur »).
    2. Appuyez sur <kbd>Entrée</kbd> pour envoyer (utilisez <kbd>Maj</kbd> + <kbd>Entrée</kbd> pour aller à la ligne).
    3. Pendant que le modèle traite votre demande, vous pouvez cliquer sur « Stop » pour l&#39;interrompre.
  </Step>

  <Step title="Comprendre les étapes de réflexion du mode « Agent »" id="thinking-steps">
    En mode Agent, des étapes intermédiaires de « réflexion » ou de planification dépliables peuvent s&#39;afficher. Elles permettent de comprendre comment l&#39;assistant élabore sa réponse. Repliez-les ou dépliez-les selon vos besoins.

    <div className="ch-image-md">
      <Frame>
        ![Étapes de réflexion](/images/use-cases/AI_ML/AIChat/4_thinking.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Démarrer une nouvelle conversation" id="new-chats">
    Cliquez sur le bouton « New Chat » pour effacer le contexte et démarrer une nouvelle session.
  </Step>

  <Step title="Consulter l'historique des conversations" id="history">
    1. La section inférieure répertorie vos conversations récentes.
    2. Sélectionnez une conversation précédente pour charger ses messages.
    3. Supprimez une conversation à l&#39;aide de l&#39;icône de corbeille.

    <div className="ch-image-md">
      <Frame>
        ![Liste de l'historique des conversations](/images/use-cases/AI_ML/AIChat/5_history.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Utiliser le SQL généré" id="sql-actions">
    Lorsque l&#39;assistant renvoie du SQL :

    * Vérifiez son exactitude.
    * Cliquez sur « Open in editor » pour charger la requête dans un nouvel onglet SQL.
    * Modifiez-la et exécutez-la dans la Console.

    <div className="ch-image-md">
      <Frame>
        ![Actions sur le résultat](/images/use-cases/AI_ML/AIChat/6_result_actions.webp)
      </Frame>
    </div>

    <div className="ch-image-md">
      <Frame>
        ![Ouvrir la requête générée dans l'éditeur](/images/use-cases/AI_ML/AIChat/7_open_in_editor.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Arrêter ou interrompre une réponse" id="interrupt">
    Si une réponse prend trop de temps ou s&#39;écarte du sujet :

    1. Cliquez sur le bouton « Stop » (visible pendant le traitement).
    2. Le message est marqué comme interrompu ; vous pouvez affiner votre prompt et le renvoyer.
  </Step>

  <Step title="Raccourcis clavier" id="shortcuts">
    | Action             | Raccourci            |
    | ------------------ | -------------------- |
    | Ouvrir Chat IA     | `⌘ + '` / `Ctrl + '` |
    | Envoyer le message | `Enter`              |
    | Nouvelle ligne     | `Shift + Enter`      |
  </Step>
</Steps>
