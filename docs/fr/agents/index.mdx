Agents vous permet d&#39;interroger et d&#39;explorer vos données ClickHouse en langage naturel, au fil d&#39;une conversation, sans avoir à écrire vous-même de SQL ni de logique d&#39;orchestration.
L&#39;agent interprète votre intention, planifie les étapes, appelle les outils que vous avez configurés et vous renvoie les résultats.
Cette fonctionnalité est actuellement en version bêta : son comportement et ses capacités sont susceptibles d&#39;évoluer d&#39;ici la disponibilité générale.

## Ce que vous pouvez faire {#what-you-can-do}

Avec Agents, vous pouvez :

* Créer des agents personnalisés sans écrire de code : rédigez des instructions, choisissez un modèle et associez des outils.
* Mener des conversations sur votre service ClickHouse, l&#39;agent appelant les outils dont il a besoin.
* Partager vos agents avec les membres de votre équipe ou les publier sur la place de marché.
