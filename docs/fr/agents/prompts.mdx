La bibliothèque Prompts vous permet d&#39;enregistrer et de réutiliser les prompts en langage naturel que vous saisissez régulièrement. Considérez-la comme un ensemble d&#39;extraits prêts à l&#39;emploi pour la zone de saisie de la conversation : idéal lorsque la même question analytique ou la même consigne de mise en forme revient d&#39;une conversation à l&#39;autre.

## Créer un prompt {#create-a-prompt}

Ouvrez le panneau Prompts à partir de l&#39;icône **Prompts** dans la navigation de gauche, puis cliquez sur le bouton **+** pour ouvrir le formulaire **Create Prompt**. Renseignez les champs :

* **Prompt Name** (obligatoire) - le nom affiché dans le sélecteur. Choisissez un nom explicite : *« Utilisateurs actifs hebdomadaires par région »* vaut mieux que *« WAU »*.
* **Text** (obligatoire) - le texte qui sera inséré dans la zone de saisie.
* **Special variables** - cliquez sur le bouton **Special variables** pour insérer des caractères de substitution, ou saisissez directement des marqueurs de type `{{name}}`. Le sélecteur vous invite à saisir les valeurs avant l&#39;insertion.
* **Category**, **Description**, **Command** (facultatif) - pour organiser la bibliothèque, définir le texte d&#39;aperçu affiché dans le sélecteur et créer un raccourci d&#39;appel rapide.

Cliquez ensuite sur **Create Prompt** en bas à droite.

## Utiliser un prompt {#use-a-prompt}

Dans le panneau Prompts, ouvrez le menu **...** d&#39;une carte de prompt et choisissez **Preview** :

L&#39;aperçu affiche le texte du prompt, ainsi que son auteur et sa date. Cliquez sur **Use Prompt** pour insérer le corps du prompt dans la zone de saisie. Si le prompt contient des variables, renseignez-les au préalable.

## Partager des prompts {#share-prompts}

Par défaut, un prompt est privé et réservé à la personne qui l&#39;a créé. Le propriétaire peut modifier sa visibilité pour la définir sur :

* **Utilisateurs ou groupes spécifiques** - toutes les personnes que vous désignez peuvent trouver et utiliser le prompt.
* **À l’échelle de l’organisation** - tous les membres de votre organisation ClickHouse Cloud peuvent le trouver et l&#39;utiliser.

Les prompts reposent sur le même modèle de permissions que les agents. Pour obtenir la matrice complète des rôles et des actions autorisées pour chacun, consultez [Partage et
accès](/fr/agents/sharing-and-access).

## Prompts, compétences et instructions {#prompts-vs-skills-vs-instructions}

Les prompts, les compétences et les instructions de l’agent ajoutent tous du texte au contexte du modèle, mais ils se distinguent par ce qui les déclenche et par leur persistance.

* **Prompts** - texte que vous insérez vous-même dans la zone de saisie, modifiable à chaque échange.
* **[Compétences](/fr/agents/builder/skills)** - ensembles d’instructions que l’agent charge de lui-même lorsqu’il les juge pertinents pour la tâche.
* **Instructions de l’agent** - l’instruction système persistante de l’agent, appliquée à chaque conversation.

Optez pour un prompt lorsque vous souhaitez réutiliser une formulation tout en gardant la maîtrise de sa rédaction à chaque fois. Optez pour une compétence lorsque vous souhaitez que l’agent applique
les mêmes consignes de manière cohérente pour un type de tâche donné, sans avoir à les saisir. Optez pour les instructions de l’agent lorsque le comportement doit s’appliquer pendant toute
la durée de vie de l’agent.
