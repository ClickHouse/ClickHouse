<div id="bitmapAnd">
  ## bitmapAnd
</div>

Introduit dans : v20.1.0

Calcule la conjonction logique (AND) de deux bitmaps.

**Syntaxe**

```sql
bitmapAnd(bitmap1, bitmap2)
```

**Arguments**

* `bitmap1` — Premier objet bitmap. [`AggregateFunction(groupBitmap, T)`](/fr/reference/data-types/aggregatefunction). - `bitmap2` — Deuxième objet bitmap. [`AggregateFunction(groupBitmap, T)`](/fr/reference/data-types/aggregatefunction).

**Valeur renvoyée**

Renvoie un bitmap contenant les bits présents dans les deux bitmaps d’entrée [`AggregateFunction(groupBitmap, T)`](/fr/reference/data-types/aggregatefunction)

**Exemples**

**Exemple d’utilisation**

```sql title=Query
SELECT bitmapToArray(bitmapAnd(bitmapBuild([1, 2, 3]), bitmapBuild([3, 4, 5]))) AS res;
```

```response title=Response
┌─res─┐
│ [3] │
└─────┘
```

<div id="bitmapBuild">
  ## bitmapBuild
</div>

Introduit dans : v20.1.0

Crée un bitmap à partir d&#39;un tableau d&#39;entiers. Les types d’éléments pris en charge sont des entiers signés et non signés de 8, 16, 32 ou 64 bits. C&#39;est l&#39;inverse de la fonction [`bitmapToArray`](/fr/reference/functions/regular-functions/bitmap-functions#bitmapToArray).

**Syntaxe**

```sql
bitmapBuild(array)
```

**Arguments**

* `array` — Tableau d’entiers. [`Array((U)Int*)`](/fr/reference/data-types/array)

**Valeur renvoyée**

Renvoie un bitmap à partir du tableau fourni [`AggregateFunction(groupBitmap, T)`](/fr/reference/data-types/aggregatefunction)

**Exemples**

**Exemple d’utilisation**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([1, 2, 3, 4, 5])) AS res, toTypeName(bitmapBuild([1, 2, 3, 4, 5])) AS type;
```

```response title=Response
┌─res────────────┬─type──────────────────────────────────┐
│ 00050102030405 │ AggregateFunction(groupBitmap, UInt8) │
└────────────────┴───────────────────────────────────────┘
```

**Bitmap signé**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([-128, -1]::Array(Int8))) AS res, toTypeName(bitmapBuild([-128, -1]::Array(Int8))) AS type;
```

```response title=Response
┌─res──────┬─type─────────────────────────────────┐
│ 000280FF │ AggregateFunction(groupBitmap, Int8) │
└──────────┴──────────────────────────────────────┘
```

<div id="bitmapContains">

**Valeur renvoyée**

Renvoie `1` si le bitmap contient la valeur spécifiée, sinon `0` [`UInt8`](/fr/reference/data-types/int-uint)

**Exemples**

**Exemple d&#39;utilisation**

```sql title=Query

```

```response title=Response
┌─res─┐
```


```response title=Response

│   1 │
```

<div id="bitmapTransform">
  ## bitmapTransform
</div>

Introduit dans : v20.1.0

Remplace les éléments d’un bitmap selon une correspondance entre `from_array` et `to_array`.
Les valeurs sont interprétées comme des entiers non signés du type d’élément du bitmap (même domaine que [`bitmapContains`](/fr/reference/functions/regular-functions/bitmap-functions#bitmapContains)).
Pour les bitmaps signés, un élément négatif correspond à son équivalent non signé (par exemple, la valeur `Int8` `-1` correspond à `255`).
Une valeur de `to_array` qui ne peut pas être représentée dans le type d’élément du bitmap lève `BAD_ARGUMENTS`. Une valeur de `from_array`
qui ne peut pas être représentée n’est simplement pas trouvée, de sorte que le remplacement correspondant ne s’applique pas.

**Syntaxe**

```sql
bitmapTransform(bitmap, from_array, to_array)
```

**Arguments**

* `bitmap` — objet bitmap. [`AggregateFunction(groupBitmap, T)`](/fr/reference/data-types/aggregatefunction). - `from_array` — Array des bits à 1 d’origine à remplacer. [`Array(T)`](/fr/reference/data-types/array). - `to_array` — Array des nouveaux bits à 1 de remplacement. [`Array(T)`](/fr/reference/data-types/array).

**Valeur renvoyée**

Renvoie un bitmap dont les éléments sont transformés selon la correspondance indiquée [`AggregateFunction(groupBitmap, T)`](/fr/reference/data-types/aggregatefunction)

**Exemples**

**Exemple d&#39;utilisation**

```sql title=Query
SELECT bitmapToArray(bitmapTransform(bitmapBuild([1, 2, 3, 4, 5]), [2, 4], [20, 40])) AS res;
```

```response title=Response
┌─res───────────┐
│ [1,3,5,20,40] │
└───────────────┘
```

**Bitmap signé**

```sql title=Query
SELECT arraySort(bitmapToArray(bitmapTransform(bitmapBuild([-1, 0]::Array(Int8)), [255], [10]))) AS res;
```

```response title=Response
┌─res────┐
│ [0,10] │
└────────┘
```
