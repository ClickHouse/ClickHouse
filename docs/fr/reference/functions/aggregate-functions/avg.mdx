## avg {#avg}

Introduit dans : v1.1.0

Calcule la moyenne arithmétique.

**Syntaxe**

```sql
avg(x)
```

**Arguments**

* `x` — Valeurs d’entrée. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal`](/fr/reference/data-types/decimal) ou [`Date`](/fr/reference/data-types/date) ou [`Date32`](/fr/reference/data-types/date32) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64(P)`](/fr/reference/data-types/datetime64) ou [`Time`](/fr/reference/data-types/time) ou [`Time64(P)`](/fr/reference/data-types/time64) ou [`Interval`](/fr/reference/data-types/special-data-types/interval)

**Valeur renvoyée**

Renvoie la moyenne arithmétique. Pour un `x` numérique, le résultat est de type `Float64`, ou `NaN` si `x` est vide. Pour un `x` de type date, heure ou intervalle, le résultat conserve le type de `x` : la moyenne est arrondie à la valeur représentable la plus proche, et un `x` vide renvoie la valeur zéro de ce type. [`Float64`](/fr/reference/data-types/float) ou [`Date`](/fr/reference/data-types/date) ou [`Date32`](/fr/reference/data-types/date32) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64(P)`](/fr/reference/data-types/datetime64) ou [`Time`](/fr/reference/data-types/time) ou [`Time64(P)`](/fr/reference/data-types/time64) ou [`Interval`](/fr/reference/data-types/special-data-types/interval)

**Exemples**

**Utilisation de base**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**Une table vide renvoie NaN**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**Moyenne d’un intervalle**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
