## timeSeriesMadToGrid {#timeSeriesMadToGrid}

Introduit dans : v26.10.0

Fonction d&#39;agrégation qui prend des données de séries temporelles sous forme de paires de timestamps et de valeurs, et calcule la fonction [PromQL `mad_over_time`](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) sur une grille temporelle régulière définie par un timestamp de début, un timestamp de fin et un pas. Pour chaque point de la grille, le résultat est l&#39;écart absolu médian `median(|x - median(x)|)` des valeurs des échantillons compris dans la fenêtre temporelle spécifiée. Les deux médianes sont calculées selon la méthode R-7 (inclusive), à l&#39;instar de `quantileExactInclusive` et `timeSeriesQuantileToGrid`.

Les échantillons peuvent être fournis sous l&#39;une des trois formes suivantes :

* deux arguments `timestamp` et `value`, chaque ligne contenant un seul échantillon ;
* deux tableaux de timestamps et de valeurs, chaque ligne contenant une série temporelle complète ;
* un seul tableau de tuples `(timestamp, value)`, chaque ligne contenant une série temporelle complète.

Comme dans Prometheus, le résultat vaut NaN si l&#39;un des échantillons de la fenêtre vaut NaN. Il vaut également NaN si la médiane de la fenêtre est infinie, car les écarts des échantillons égaux à cette médiane valent alors `Inf - Inf`.

Si plusieurs échantillons partagent le même timestamp, un seul d&#39;entre eux est retenu : celui dont la valeur est la plus élevée. Une valeur NaN est toujours supplantée par une autre valeur ; elle n&#39;est donc utilisée que si tous les échantillons de ce timestamp valent NaN.

<Note>
  Cette fonction est en aperçu privé ; activez-la en définissant `enable_time_series_aggregate_functions=true`.
</Note>

**Syntaxe**

```sql
timeSeriesMadToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
timeSeriesMadToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples)
```

**Paramètres**

* `start_timestamp` — Spécifie le début de la grille. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une date-heure au format texte. [`UInt32`](/fr/reference/data-types/int-uint) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64`](/fr/reference/data-types/datetime64) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)
* `end_timestamp` — Spécifie la fin de la grille. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une date-heure au format texte. [`UInt32`](/fr/reference/data-types/int-uint) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64`](/fr/reference/data-types/datetime64) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)
* `grid_step` — Spécifie le pas de la grille en secondes. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une durée telle que &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)
* `staleness` — Spécifie l&#39;ancienneté maximale (« staleness »), en secondes, des échantillons pris en compte. La fenêtre d&#39;ancienneté est un intervalle ouvert à gauche et fermé à droite. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une durée telle que &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)

**Arguments**

* `timestamp` — Timestamp de l&#39;échantillon. Peut être une valeur individuelle ou un tableau. [`UInt32`](/fr/reference/data-types/int-uint) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64`](/fr/reference/data-types/datetime64) ou [`Array(UInt32)`](/fr/reference/data-types/array) ou [`Array(DateTime)`](/fr/reference/data-types/array) ou [`Array(DateTime64)`](/fr/reference/data-types/array)
* `value` — Valeur de la série temporelle correspondant au timestamp. Peut être une valeur individuelle ou un tableau. [`Float*`](/fr/reference/data-types/float) ou [`Array(Float*)`](/fr/reference/data-types/array)
* `samples` — Échantillons de la série temporelle, passés sous forme de tableau de tuples `(timestamp, value)` dont les éléments ont les types de timestamp et de valeur indiqués ci-dessus. Permet de ne pas passer les timestamps et les valeurs sous forme de deux arguments distincts. [`Array(Tuple(T1, T2))`](/fr/reference/data-types/array)

**Valeur renvoyée**

Renvoie l&#39;écart absolu médian des valeurs sur la grille spécifiée. Le tableau renvoyé contient une valeur pour chaque point de la grille temporelle. La valeur est NULL si aucun échantillon ne se trouve dans la fenêtre d&#39;un point de grille donné. [`Array(Nullable(Float64))`](/fr/reference/data-types/array)

**Exemples**

**Calculer les valeurs de mad&#95;over&#95;time sur la grille [90, 105, 120, 135, 150, 165, 180, 195, 210, 225]**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 130 and 190 is to show how values are filled for ts = 180 according to window parameter
    [110, 120, 130, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 3, 2, 6, 6, 4, 2, 0]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 135 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesMadToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesMadToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,1,1,1,0,NULL,0,0,1]                                                        │
└───────────────────────────────────────────────────────────────────────────────────────┘
```

**Même requête avec des arguments de type tableau**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 3, 2, 6, 6, 4, 2, 0]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 135 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesMadToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesMadToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,1,1,1,0,NULL,0,0,1]                                                          │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
