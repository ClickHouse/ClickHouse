## timeSeriesAvgToGrid {#timeSeriesAvgToGrid}

Introduit dans : v26.9.0

Fonction d&#39;agrégation qui prend des données de séries temporelles sous forme de paires de timestamps et de valeurs, et calcule à partir de ces données un [avg&#95;over&#95;time de type PromQL](https://prometheus.io/docs/prometheus/latest/querying/functions/#aggregation_over_time) sur une grille temporelle régulière définie par un timestamp de début, un timestamp de fin et un pas. Pour chaque point de la grille, la moyenne est calculée à partir des échantillons situés dans la fenêtre temporelle spécifiée.

Les échantillons peuvent être transmis sous l&#39;une des trois formes suivantes :

* deux arguments `timestamp` et `value`, chaque ligne contenant un seul échantillon ;
* deux tableaux de timestamps et de valeurs, chaque ligne contenant une série temporelle complète ;
* un seul tableau de tuples `(timestamp, value)`, chaque ligne contenant une série temporelle complète.

Si plusieurs échantillons ont le même timestamp, un seul d&#39;entre eux est retenu : celui dont la valeur est la plus élevée. Une valeur NaN est toujours supplantée par toute autre valeur ; elle n&#39;est donc retenue que si tous les échantillons de ce timestamp valent NaN.

<Warning>
  Cette fonction est en aperçu privé ; pour l&#39;activer, définissez `enable_time_series_aggregate_functions=true`.
</Warning>

**Syntaxe**

```sql
timeSeriesAvgToGrid(start_timestamp, end_timestamp, grid_step, staleness)(timestamp, value)
timeSeriesAvgToGrid(start_timestamp, end_timestamp, grid_step, staleness)(samples)
```

**Paramètres**

* `start_timestamp` — Indique le début de la grille. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une date-heure sous forme de texte. [`UInt32`](/fr/reference/data-types/int-uint) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64`](/fr/reference/data-types/datetime64) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)
* `end_timestamp` — Indique la fin de la grille. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une date-heure sous forme de texte. [`UInt32`](/fr/reference/data-types/int-uint) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64`](/fr/reference/data-types/datetime64) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)
* `grid_step` — Indique le pas de la grille, en secondes. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une durée telle que &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)
* `staleness` — Indique l&#39;ancienneté maximale, en secondes, des échantillons pris en compte. La fenêtre d&#39;ancienneté est un intervalle ouvert à gauche et fermé à droite. Peut également être un nombre fractionnaire, ou une string contenant un nombre ou une durée telle que &#39;15s&#39; ou &#39;1m&#39;. [`UInt32`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`String`](/fr/reference/data-types/string)

**Arguments**

* `timestamp` — Timestamp de l&#39;échantillon. Peut être une valeur unique ou un tableau. [`UInt32`](/fr/reference/data-types/int-uint) ou [`DateTime`](/fr/reference/data-types/datetime) ou [`DateTime64`](/fr/reference/data-types/datetime64) ou [`Array(UInt32)`](/fr/reference/data-types/array) ou [`Array(DateTime)`](/fr/reference/data-types/array) ou [`Array(DateTime64)`](/fr/reference/data-types/array)
* `value` — Valeur de la série temporelle correspondant au timestamp. Peut être une valeur unique ou un tableau. [`Float*`](/fr/reference/data-types/float) ou [`Array(Float*)`](/fr/reference/data-types/array)
* `samples` — Échantillons de la série temporelle, fournis sous forme de tableau de tuples `(timestamp, value)` dont les éléments sont des types de timestamp et de valeur indiqués ci-dessus. Permet d&#39;éviter de transmettre les timestamps et les valeurs sous forme de deux arguments distincts. [`Array(Tuple(T1, T2))`](/fr/reference/data-types/array)

**Valeur renvoyée**

Renvoie la moyenne des valeurs sur la grille spécifiée. Le tableau renvoyé contient une valeur pour chaque point de la grille temporelle. Cette valeur est NULL si aucun échantillon ne se trouve dans la fenêtre d&#39;un point de grille donné. [`Array(Nullable(Float64))`](/fr/reference/data-types/array)

**Exemples**

**Utilisation de base avec des paires timestamp-valeur individuelles**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    -- NOTE: the gap between 140 and 190 is to show how values are filled for ts = 150, 165, 180 according to window parameter
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values, -- array of values corresponding to timestamps above
    90 AS start_ts,       -- start of timestamp grid
    90 + 120 AS end_ts,   -- end of timestamp grid
    15 AS step_seconds,   -- step of timestamp grid
    45 AS window_seconds  -- "staleness" window
SELECT timeSeriesAvgToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)
FROM
(
    -- This subquery converts arrays of timestamps and values into rows of `timestamp`, `value`
    SELECT
        arrayJoin(arrayZip(timestamps, values)) AS ts_and_val,
        ts_and_val.1 AS timestamp,
        ts_and_val.2 AS value
);
```

```response title=Response
┌─timeSeriesAvgToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamp, value)─┐
│ [NULL,NULL,1,1.6666666666666667,2.25,3.5,4,5,6]                                       │
└───────────────────────────────────────────────────────────────────────────────────────┘
```

**Utilisation d&#39;arguments de type tableau**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH
    [110, 120, 130, 140, 190, 200, 210, 220, 230]::Array(DateTime) AS timestamps,
    [1, 1, 3, 4, 5, 5, 8, 12, 13]::Array(Float32) AS values,
    90 AS start_ts,
    90 + 120 AS end_ts,
    15 AS step_seconds,
    45 AS window_seconds
SELECT timeSeriesAvgToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values);
```

```response title=Response
┌─timeSeriesAvgToGrid(start_ts, end_ts, step_seconds, window_seconds)(timestamps, values)─┐
│ [NULL,NULL,1,1.6666666666666667,2.25,3.5,4,5,6]                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
