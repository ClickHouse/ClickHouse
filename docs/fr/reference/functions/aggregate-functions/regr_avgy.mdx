## regr_avgy {#regr_avgy}

Introduit dans : v26.9.0

Renvoie la moyenne de la variable dépendante.

Elle est calculée par rapport à une valeur issue des données plutôt que par rapport à zéro ; ainsi, pour une colonne de type integer au-delà de
2^53, elle peut être plus proche de la moyenne exacte que [`avg`](/fr/reference/functions/aggregate-functions/avg),
qui divise une somme de type `Float64`.

**Syntaxe**

```sql
regr_avgy(y, x)
```

**Alias** : `regrAvgY`

**Arguments**

* `y` — Variable dépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)
* `x` — Variable indépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)

**Valeur renvoyée**

Renvoie la moyenne de `y`. [`Float64`](/fr/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Query
SELECT regr_avgy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgy(y, x)─┐
│               5 │
└─────────────────┘
```
