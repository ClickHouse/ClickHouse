## regr_count {#regr_count}

Introduit dans : v26.9.0

Compte les lignes pour lesquelles ni `y` ni `x` n&#39;est `NULL`.

**Syntaxe**

```sql
regr_count(y, x)
```

**Alias** : `regrCount`

**Arguments**

* `y` — Variable dépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)
* `x` — Variable indépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)

**Valeur renvoyée**

Renvoie le nombre de paires non nulles. [`UInt64`](/fr/reference/data-types/int-uint)

**Exemples**

**Utilisation de base**

```sql title=Query
SELECT regr_count(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_count(y, x)─┐
│                4 │
└──────────────────┘
```
