## regr_syy {#regr_syy}

Introduit dans : v26.9.0

Renvoie la somme des carrés de la variable dépendante :

$$
\Sigma{(y - \bar{y})^2}
$$

**Syntaxe**

```sql
regr_syy(y, x)
```

**Alias** : `regrSYY`

**Arguments**

- `y` — Variable dépendante. [`(U)Int*`](/reference/data-types/int-uint) ou [`Float*`](/reference/data-types/float)
- `x` — Variable indépendante. [`(U)Int*`](/reference/data-types/int-uint) ou [`Float*`](/reference/data-types/float)

**Valeur renvoyée**

Renvoie la somme des carrés des écarts de `y` par rapport à sa moyenne. [`Float64`](/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Requête
SELECT regr_syy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Réponse
┌─regr_syy(y, x)─┐
│             20 │
└────────────────┘
```
