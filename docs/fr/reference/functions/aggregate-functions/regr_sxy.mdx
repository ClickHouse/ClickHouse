## regr_sxy {#regr_sxy}

Introduit dans : v26.9.0

Renvoie la somme des produits des deux variables :

$$
\Sigma{(x - \bar{x})(y - \bar{y})}
$$

**Syntaxe**

```sql
regr_sxy(y, x)
```

**Alias** : `regrSXY`

**Arguments**

- `y` — Variable dépendante. [`(U)Int*`](/reference/data-types/int-uint) ou [`Float*`](/reference/data-types/float)
- `x` — Variable indépendante. [`(U)Int*`](/reference/data-types/int-uint) ou [`Float*`](/reference/data-types/float)

**Valeur renvoyée**

Renvoie la somme des produits des écarts de `x` et de `y` par rapport à leurs moyennes. [`Float64`](/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Requête
SELECT regr_sxy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Réponse
┌─regr_sxy(y, x)─┐
│             10 │
└────────────────┘
```
