## regr_intercept {#regr_intercept}

Introduit dans : v26.9.0

Renvoie l&#39;ordonnée à l&#39;origine de la droite des moindres carrés de `y` en fonction de `x` :

$$
\bar{y} - slope \cdot \bar{x}
$$

Renvoie `nan` lorsque `x` est constant, car la droite ajustée est alors verticale.

**Syntaxe**

```sql
regr_intercept(y, x)
```

**Alias** : `regrIntercept`

**Arguments**

* `y` — Variable dépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)
* `x` — Variable indépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)

**Valeur renvoyée**

Renvoie l&#39;ordonnée à l&#39;origine de la droite de régression. [`Float64`](/fr/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Query
SELECT regr_intercept(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_intercept(y, x)─┐
│                    0 │
└──────────────────────┘
```
