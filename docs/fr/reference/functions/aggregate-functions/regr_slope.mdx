## regr_slope {#regr_slope}

Introduit dans : v26.9.0

Renvoie la pente de la droite de régression par les moindres carrés de `y` en fonction de `x` :

$$
\frac{\Sigma{(x - \bar{x})(y - \bar{y})}}{\Sigma{(x - \bar{x})^2}}
$$

Renvoie `nan` lorsque `x` est constant, car la droite ajustée est verticale.

**Syntaxe**

```sql
regr_slope(y, x)
```

**Alias** : `regrSlope`

**Arguments**

- `y` — Variable dépendante. [`(U)Int*`](/reference/data-types/int-uint) ou [`Float*`](/reference/data-types/float)
- `x` — Variable indépendante. [`(U)Int*`](/reference/data-types/int-uint) ou [`Float*`](/reference/data-types/float)

**Valeur renvoyée**

Renvoie la pente de la droite de régression. [`Float64`](/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Requête
SELECT regr_slope(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Réponse
┌─regr_slope(y, x)─┐
│                2 │
└──────────────────┘
```
