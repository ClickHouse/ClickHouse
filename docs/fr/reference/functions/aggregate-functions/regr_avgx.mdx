## regr_avgx {#regr_avgx}

Introduit dans : v26.9.0

Renvoie la moyenne de la variable indépendante.

Elle est calculée autour d&#39;une valeur issue des données plutôt qu&#39;autour de zéro ; ainsi, pour une colonne de type integer dépassant
2^53, elle peut être plus proche de la moyenne exacte que [`avg`](/fr/reference/functions/aggregate-functions/avg),
qui divise une somme de type `Float64`.

**Syntaxe**

```sql
regr_avgx(y, x)
```

**Alias** : `regrAvgX`

**Arguments**

* `y` — Variable dépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)
* `x` — Variable indépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)

**Valeur renvoyée**

Renvoie la moyenne de `x`. [`Float64`](/fr/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
