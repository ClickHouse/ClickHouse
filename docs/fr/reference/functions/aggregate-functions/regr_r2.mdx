## regr_r2 {#regr_r2}

Introduit dans : v26.9.0

Renvoie le coefficient de détermination de l&#39;ajustement par les moindres carrés, c&#39;est-à-dire le carré du
coefficient de corrélation. Renvoie `nan` lorsque `x` est constant et `1` lorsque `y` est constant.

**Syntaxe**

```sql
regr_r2(y, x)
```

**Alias** : `regrR2`

**Arguments**

* `y` — Variable dépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)
* `x` — Variable indépendante. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float)

**Valeur renvoyée**

Renvoie une valeur comprise entre 0 et 1. [`Float64`](/fr/reference/data-types/float)

**Exemples**

**Utilisation de base**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
