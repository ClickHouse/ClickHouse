## sum {#sum}

Introduit dans : v1.1.0

Calcule la somme de valeurs numériques ou d&#39;intervalles.

**Syntaxe**

```sql
sum(num)
```

**Arguments**

* `num` — Colonne de valeurs numériques ou d&#39;intervalles. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`Interval`](/fr/reference/data-types/special-data-types/interval)

**Valeur renvoyée**

Renvoie la somme des valeurs. Pour un argument `Interval`, le résultat est un intervalle exprimé dans la même unité, et une entrée vide donne un intervalle de durée nulle. [`(U)Int*`](/fr/reference/data-types/int-uint) ou [`Float*`](/fr/reference/data-types/float) ou [`Decimal*`](/fr/reference/data-types/decimal) ou [`Interval`](/fr/reference/data-types/special-data-types/interval)

**Exemples**

**Calcul de la somme des salaires des employés**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**Temps total consacré aux requêtes**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
