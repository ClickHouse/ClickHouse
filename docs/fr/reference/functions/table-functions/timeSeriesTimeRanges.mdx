`timeSeriesTimeRanges(db_name.time_series_table)` - Renvoie la table des [plages temporelles](/fr/reference/engines/table-engines/integrations/time-series#time-ranges-table)
utilisée par la table `db_name.time_series_table`, dont la table engine est le moteur [TimeSeries](/fr/reference/engines/table-engines/integrations/time-series), par exemple :

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

Les requêtes suivantes sont équivalentes :

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  La table des *intervalles de temps* existe si le paramètre `store_time_ranges` est activé.
  Dans les tables de [version](/fr/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 ou antérieure, les colonnes `min_time` et `max_time` se trouvent
  dans la table des [étiquettes](/fr/reference/engines/table-engines/integrations/time-series#tags-table).
</Note>
