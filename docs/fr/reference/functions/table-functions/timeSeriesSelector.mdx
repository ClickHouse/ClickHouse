Lit des séries temporelles d’une table TimeSeries, filtrées par un sélecteur et dont les horodatages appartiennent à un intervalle spécifié.
Cette fonction est similaire aux [sélecteurs de plage](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors), mais elle sert aussi à implémenter des [sélecteurs instantanés](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors).

## Syntaxe {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time)
```

## Arguments {#arguments}

* `db_name` - Nom de la base de données dans laquelle se trouve une table TimeSeries.
* `time_series_table` - Nom d&#39;une table TimeSeries.
* `instant_query` - Un sélecteur instantané écrit en [syntaxe PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors), sans les modificateurs `@` ni `offset`.
* `min_time` - Horodatage de début, inclus.
* `max_time` - Horodatage de fin, inclus.

`min_time` et `max_time` peuvent comporter des fractions de seconde, même si les timestamps de la table sont exprimés en secondes entières :
la fonction sélectionne exactement les échantillons pour lesquels `min_time <= timestamp <= max_time`, sans arrondir les bornes en fonction du type des timestamps.

## Valeur renvoyée {#returned-value}

La fonction renvoie trois colonnes :

* `id` - Contient les identifiants des séries temporelles correspondant au sélecteur spécifié.
* `timestamp` - Contient les horodatages.
* `value` - Contient les valeurs.

Aucun ordre particulier n’est garanti pour les données renvoyées.

## Exemple {#example}

```sql
SELECT * FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now())
```
