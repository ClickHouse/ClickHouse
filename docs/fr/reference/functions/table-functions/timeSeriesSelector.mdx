Lit des séries temporelles d’une table TimeSeries, filtrées par un sélecteur et dont les horodatages appartiennent à un intervalle spécifié.
Cette fonction est similaire aux [sélecteurs de plage](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors), mais elle sert aussi à implémenter des [sélecteurs instantanés](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors).

## Syntaxe {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## Arguments {#arguments}

* `db_name` - Nom de la base de données dans laquelle se trouve une table TimeSeries.
* `time_series_table` - Nom d&#39;une table TimeSeries.
* `instant_query` - Un sélecteur instantané écrit en [syntaxe PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors), sans les modificateurs `@` ni `offset`.
* `min_time` - Timestamp de début, inclus.
* `max_time` - Timestamp de fin, inclus.
* `return_columns` - Colonnes dans lesquelles les échantillons sont renvoyés : `'samples'` ou `'timestamp_and_value'`, voir ci-dessous.

`min_time` et `max_time` peuvent comporter des fractions de seconde, même si les timestamps de la table sont exprimés en secondes entières :
la fonction sélectionne exactement les échantillons pour lesquels `min_time <= timestamp <= max_time`, sans arrondir les bornes en fonction du type des timestamps.

## Valeur renvoyée {#returned-value}

La fonction renvoie la colonne `id` contenant les identifiants des séries temporelles correspondant au sélecteur spécifié, ainsi que les échantillons
dans les colonnes choisies par l’argument `return_columns` :

* `'samples'` - la colonne `samples`, qui contient les échantillons d’une série temporelle sous forme de tableau de tuples `(timestamp, value)` triés par timestamp.
  Les échantillons d’une série temporelle peuvent être répartis sur plusieurs lignes, par exemple une ligne par intervalle temporel de la table des échantillons.
  Utilisez la fonction d’agrégation `timeSeriesGroupArray` pour fusionner les lignes d’une même série temporelle.
* `'timestamp_and_value'` - les colonnes `timestamp` et `value`, avec un échantillon par ligne.

Une table `TimeSeries` en version 11 ou ultérieure stocke les compartiments d’échantillons sous forme de tableaux, tandis que les tables des versions antérieures stockent un échantillon par ligne.
Les échantillons sont convertis lorsque les colonnes demandées ne correspondent pas à la disposition de la table, ce qui prend un certain temps ; les fonctions PromQL
demandent les colonnes correspondant à la disposition de la table.

Les données renvoyées ne suivent aucun ordre particulier.

## Exemples {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
