Évalue une requête Prometheus à partir des données d’une table TimeSeries.

## Syntaxe {#syntax}

```sql
prometheusQuery('db_name', 'time_series_table', 'promql_query', evaluation_time)
prometheusQuery(db_name.time_series_table, 'promql_query', evaluation_time)
prometheusQuery('time_series_table', 'promql_query', evaluation_time)
```

## Arguments {#arguments}

* `db_name` - Le nom de la base de données dans laquelle se trouve une table TimeSeries.
* `time_series_table` - Le nom d’une table TimeSeries.
* `promql_query` - Une requête écrite en [syntaxe PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/).
* `evaluation_time` - L’horodatage d’évaluation, avec une précision à la milliseconde ou plus fine. Pour évaluer une requête à l’instant présent, utilisez `now()` comme `evaluation_time`.

## Valeur renvoyée {#returned-value}

La fonction renvoie des colonnes différentes selon le type de résultat de la requête passée au paramètre `promql_query` :

| Type de résultat | Colonnes renvoyées                                                                  | Exemple                                             |
| ---------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| vector           | tags Array(Tuple(String, String)), timestamp DateTime64(S, TZ), value Float64       | prometheusQuery(mytable, &#39;up&#39;)              |
| matrix           | tags Array(Tuple(String, String)), samples Array(Tuple(DateTime64(S, TZ), Float64)) | prometheusQuery(mytable, &#39;up[1m]&#39;)          |
| scalar           | timestamp DateTime64(S, TZ), value Float64                                          | prometheusQuery(mytable, &#39;1h30m&#39;)           |
| string           | timestamp DateTime64(S, TZ), value String                                           | prometheusQuery(mytable, &#39;&quot;abc&quot;&#39;) |

Les valeurs sont toujours de type `Float64`, quel que soit leur type dans la table TimeSeries. La précision `S` des timestamps est celle
des timestamps de la table, avec un minimum de 3 (millisecondes). Le fuseau horaire `TZ` est celui de `evaluation_time` si ce paramètre
est de type `DateTime` ou `DateTime64` avec un fuseau horaire ; sinon, c’est celui des timestamps de la table.

La colonne `samples` est nommée `time_series` si la table `TimeSeries` est en [version](/fr/reference/engines/table-engines/integrations/time-series#schema-versioning) 2 ou antérieure.

## Fonctionnalités PromQL prises en charge {#supported-promql-features}

### Sélecteurs {#selectors}

Sélecteurs instantanés, sélecteurs d’intervalle, correspondances de labels (`=`, `!=`, `=~`, `!~`), modificateurs de décalage, modificateurs d’horodatage `@` et sous-requêtes.

### Fonctions {#functions}

| Catégorie     | Fonctions                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plage         | `rate`, `irate`, `delta`, `idelta`, `increase`, `last_over_time`, `first_over_time`, `sum_over_time`, `avg_over_time`, `count_over_time`, `max_over_time`, `min_over_time`, `ts_of_max_over_time`, `ts_of_min_over_time`, `ts_of_last_over_time`, `ts_of_first_over_time`, `deriv`, `changes`, `resets`, `present_over_time`, `absent_over_time`, `quantile_over_time`, `stddev_over_time`, `stdvar_over_time`, `mad_over_time`, `predict_linear` |
| Maths         | `abs`, `sgn`, `floor`, `ceil`, `sqrt`, `exp`, `ln`, `log2`, `log10`, `rad`, `deg`, `round`, `clamp`, `clamp_min`, `clamp_max`, `min_of`, `max_of`                                                                                                                                                                                                                                                                                                 |
| Trigonométrie | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh`                                                                                                                                                                                                                                                                                                                                                    |
| DateTime      | `day_of_week`, `day_of_month`, `days_in_month`, `day_of_year`, `minute`, `hour`, `month`, `year`                                                                                                                                                                                                                                                                                                                                                  |
| Label         | `label_replace`, `label_join`                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Type          | `scalar`, `vector`                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Histogramme   | `histogram_quantile`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Autre         | `time`, `pi`, `absent`, `timestamp`                                                                                                                                                                                                                                                                                                                                                                                                               |

**Remarque** : `histogram_quantile` utilise une interpolation linéaire sur les classes des histogrammes classiques (repérées par le label `le`). Les histogrammes natifs ne sont pas pris en charge. L’argument `phi` (niveau de quantile) doit être une constante scalaire. Les expressions qui varient d’un pas à l’autre, telles que `histogram_quantile(time() / 1000, ...)`, sont rejetées avec une exception `NOT_IMPLEMENTED`.

**Remarque** : `min_of(a, b)` et `max_of(a, b)` renvoient respectivement la plus petite et la plus grande de deux valeurs scalaires. Les deux arguments doivent être des scalaires.

**Remarque** : `min_of`, `max_of`, `ts_of_min_over_time`, `ts_of_max_over_time`, `ts_of_last_over_time`, `first_over_time`, `ts_of_first_over_time` et `mad_over_time` sont des fonctions expérimentales dans Prometheus (où elles s’activent avec `--enable-feature=promql-experimental-functions`) ; ClickHouse les évalue sans exiger ce flag.

### Opérateurs {#operators}

Opérateurs binaires arithmétiques (`+`, `-`, `*`, `/`, `%`, `^`, `atan2`) et de comparaison (`==`, `!=`, `<`, `>`, `<=`, `>=` avec `bool` facultatif), avec les modificateurs `on()`/`ignoring()` et `group_left()`/`group_right()`.

Opérateurs d’ensemble logiques `and`, `or` et `unless`, avec les modificateurs `on()`/`ignoring()`.

Opérateurs unaires `+` et `-`.

### Opérateurs d’agrégation {#aggregation-operators}

`sum`, `avg`, `min`, `max`, `count`, `count_values`, `stddev`, `stdvar`, `group`, `quantile`, `topk`, `bottomk`, `limitk` — avec les modificateurs facultatifs `by()` ou `without()`.

## Exemple {#example}

```sql
SELECT * FROM prometheusQuery(mytable, 'rate(http_requests{job="prometheus"}[10m])[1h:10m]', now())
```
