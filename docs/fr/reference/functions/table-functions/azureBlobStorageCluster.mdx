Permet de traiter des fichiers depuis [Azure Blob Storage](https://azure.microsoft.com/en-us/products/storage/blobs) en parallèle sur plusieurs nœuds d’un cluster spécifié. Sur l’initiateur, elle établit une connexion à tous les nœuds du cluster, développe les astérisques dans le chemin de fichier S3 et répartit dynamiquement chaque fichier. Sur le nœud worker, elle demande à l’initiateur la tâche suivante à traiter, puis l’exécute. Ce processus se répète jusqu’à ce que toutes les tâches soient terminées.
Cette fonction de table est similaire à la [fonction s3Cluster](/fr/reference/functions/table-functions/s3Cluster).

## Syntaxe {#syntax}

<Tabs>
  <Tab title="Chaîne de connexion">
    Les identifiants sont intégrés à la chaîne de connexion ; il est donc inutile de fournir séparément `account_name`/`account_key` :

    ```sql
    azureBlobStorageCluster(cluster_name, connection_string, container_name, blobpath [, format, compression, structure])
    ```
  </Tab>

  <Tab title="URL du compte de stockage">
    Nécessite `account_name` et `account_key` sous forme d&#39;arguments distincts :

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, account_name, account_key [, format, compression, structure])
    ```
  </Tab>

  <Tab title="Workload Identity">
    Utilise Azure Workload Identity via `extra_credentials` ; cette option est incompatible avec `account_name` / `account_key` et nécessite `storage_account_url` (et non `connection_string`) :

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, extra_credentials(client_id=, tenant_id=) [, format, compression, structure])
    ```

    Workload Identity s&#39;appuie sur l&#39;identité propre du serveur et est donc refusée par défaut : activez `allow_server_credentials_in_user_queries` dans la session qui exécute la requête ou dans son settings profile.
  </Tab>
</Tabs>

## Arguments {#arguments}

| Argument              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `cluster_name`        | Nom d’un cluster utilisé pour construire un ensemble d’adresses et de paramètres de connexion pour les serveurs distants et locaux.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `connection_string`   | Chaîne de connexion contenant des identifiants intégrés (nom du compte + clé du compte ou jeton SAS). Dans ce cas, `account_name` et `account_key` ne doivent **pas** être passés séparément, et `client_id` / `tenant_id` ne peuvent pas être utilisés. Voir [Configure a connection string](https://learn.microsoft.com/en-us/azure/storage/common/storage-configure-connection-string?toc=%2Fazure%2Fstorage%2Fblobs%2Ftoc.json\&bc=%2Fazure%2Fstorage%2Fblobs%2Fbreadcrumb%2Ftoc.json#configure-a-connection-string-for-an-azure-storage-account). |
| `storage_account_url` | URL du point de terminaison du compte de stockage, par exemple `https://<account>.blob.core.windows.net/`. Dans ce cas, passez soit `account_name` et `account_key`, soit `extra_credentials(client_id=, tenant_id=)` pour Workload Identity.                                                                                                                                                                                                                                                                                                          |
| `container_name`      | Nom du conteneur                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `blobpath`            | chemin du fichier. Prend en charge les caractères génériques suivants en mode `readonly` : `*`, `**`, `?`, `{abc,def}` et `{N..M}`, où `N` et `M` sont des nombres, et `'abc'` et `'def'` des chaînes.                                                                                                                                                                                                                                                                                                                                                 |
| `account_name`        | Nom du compte de stockage. **Obligatoire** lorsque `storage_account_url` est utilisé sans SAS ni Workload Identity ; ne doit **pas** être passé avec `connection_string` ou `extra_credentials`.                                                                                                                                                                                                                                                                                                                                                       |
| `account_key`         | Clé du compte de stockage. **Obligatoire** lorsque `storage_account_url` est utilisé sans SAS ni Workload Identity ; ne doit **pas** être passée avec `connection_string` ou `extra_credentials`.                                                                                                                                                                                                                                                                                                                                                      |
| `format`              | Le [format](/fr/reference/formats/index) du fichier.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `compression`         | Valeurs prises en charge : `none`, `gzip/gz`, `deflate`, `brotli/br`, `xz/LZMA`, `zstd/zst`, `lz4`, `bz2`, `snappy`. Par défaut, la compression est détectée automatiquement à partir de l’extension du fichier. (équivaut à définir `auto`.) Pour `snappy`, le format filaire est sélectionné par le paramètre [snappy&#95;mode](/fr/reference/settings/session-settings/other#snappy_mode) (`basic` par défaut).                                                                                                                                        |
| `structure`           | Structure de la table. Format : `'column1_name column1_type, column2_name column2_type, ...'`.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `extra_credentials`   | Utilisez `client_id` et `tenant_id` pour l’authentification Azure Workload Identity. Incompatible avec `account_name` / `account_key` ; nécessite `storage_account_url` (et non `connection_string`). `AZURE_FEDERATED_TOKEN_FILE` doit être défini sur chaque nœud du cluster.                                                                                                                                                                                                                                                                        |

## Valeur renvoyée {#returned-value}

Une table dotée de la structure spécifiée pour lire ou écrire des données dans le fichier indiqué.

## Exemples {#examples}

À l’instar du moteur de table [AzureBlobStorage](/fr/reference/engines/table-engines/integrations/azureBlobStorage), les utilisateurs peuvent utiliser l’émulateur Azurite pour le développement local avec Azure Storage. Plus de détails [ici](https://learn.microsoft.com/en-us/azure/storage/common/storage-use-azurite?tabs=docker-hub%2Cblob-storage). Ci-dessous, nous supposons qu’Azurite est accessible sous le nom d’hôte `azurite1`.

Sélectionnez le nombre d’enregistrements du fichier `test_cluster_*.csv` en utilisant tous les nœuds du cluster `cluster_simple` :

```sql
SELECT count(*) FROM azureBlobStorageCluster(
        'cluster_simple', 'http://azurite1:10000/devstoreaccount1', 'testcontainer', 'test_cluster_count.csv', 'devstoreaccount1',
        'Eby8vdM02xNOcqFlqUwJPLlmEtlCDXJ1OUzFT50uSRZ6IFsuFq2UVErCz4I6tq/K1SZFPTOtr/KBHBeksoGMGw==', 'CSV',
        'auto', 'key UInt64')
```
