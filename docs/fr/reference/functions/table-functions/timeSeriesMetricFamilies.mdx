`timeSeriesMetricFamilies(db_name.time_series_table)` - Renvoie la table des [familles de métriques](/fr/reference/engines/table-engines/integrations/time-series#metric-families-table)
utilisée par la table `db_name.time_series_table` dont le table engine est le moteur [TimeSeries](/fr/reference/engines/table-engines/integrations/time-series) :

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES metric_families_table
```

La fonction fonctionne également si la table des *familles de métriques* est la table interne :

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

Les requêtes suivantes sont équivalentes :

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  La fonction `timeSeriesMetricFamilies` possède un alias `timeSeriesMetrics`, conservé pour des raisons de compatibilité descendante.
</Note>
