Les requêtes CREATE permettent de créer, par exemple, de nouvelles [bases de données](/fr/reference/statements/create/database), [tables](/fr/reference/statements/create/table) et [vues](/fr/reference/statements/create/view).

**Syntaxe**

```sql
CREATE DATABASE ...
CREATE TABLE ...
CREATE VIEW ...
CREATE DICTIONARY ...
CREATE FUNCTION ...
CREATE NAMED COLLECTION ...
CREATE USER | ROLE | ROW POLICY | MASKING POLICY | QUOTA | SETTINGS PROFILE ...
```

**Associés :** `ATTACH`, `DROP`, `CREATE TABLE`, `CREATE DATABASE`, `CREATE VIEW`, `CREATE DICTIONARY`
