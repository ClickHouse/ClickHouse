## direct {#direct}

Le dictionnaire n’est pas stocké en mémoire et interroge directement la source lors du traitement d’une requête.

La clé du dictionnaire est de type [UInt64](/fr/reference/data-types/int-uint).

Seul un lookup est sélectif. `dictGet` et les autres fonctions de dictionnaire interrogent la source pour les clés demandées, mais lire le dictionnaire **en tant que table** ne constitue pas un fetch par clé : `SELECT ... FROM <dictionary> WHERE key IN (...)` lit l’intégralité de la source, puis filtre le résultat, car le filtre sur la clé n’est pas pushed down dans le dictionnaire. Utilisez les fonctions de dictionnaire lorsque vous souhaitez que la source soit interrogée pour des clés précises.

Tous les types de [sources](/fr/reference/statements/create/dictionary/sources/overview#dictionary-sources), à l’exception des fichiers locaux, sont pris en charge.

Exemple de configuration :

<Tabs>
  <Tab title="DDL">
    ```sql
    LAYOUT(DIRECT())
    ```
  </Tab>

  <Tab title="Fichier de configuration">
    ```xml
    <layout>
      <direct />
    </layout>
    ```
  </Tab>
</Tabs>
