Modifie les paramètres d’un moteur de base de données. Les paramètres modifiables dépendent du moteur ; tous les moteurs et tous les paramètres ne peuvent pas être modifiés après la création de la base de données.

Ce statement modifie les paramètres du moteur de base de données, et non les paramètres de session ni les valeurs par défaut des tables de la base de données.

## Syntaxe {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

Utilisez `ON CLUSTER` pour exécuter le statement sur tous les hôtes du cluster spécifié.
Ce statement nécessite le privilège `ALTER DATABASE SETTINGS`.

## Paramètres pris en charge {#supported-settings}

Consultez la documentation du moteur de base de données concerné pour connaître ses paramètres et ses restrictions. Par exemple :

* [`Atomic`](/fr/reference/engines/database-engines/atomic) et [`Ordinary`](/fr/reference/engines/database-engines/ordinary) permettent de modifier `max_tables`.
* [`MaterializedPostgreSQL`](/fr/reference/engines/database-engines/materialized-postgresql) permet de modifier certains paramètres de réplication, tels que `materialized_postgresql_max_block_size`.
* [`DataLakeCatalog`](/fr/reference/engines/database-engines/datalake) permet de modifier certains paramètres du catalogue ; les paramètres disponibles dépendent du type de catalogue.

Un moteur ou un paramètre non pris en charge déclenche une exception.

## Exemple {#example}

Modifier le nombre maximal de tables dans une base de données `Atomic` :

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

Définissez `max_tables` sur `0` pour lever cette limite au niveau de la base de données :

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
