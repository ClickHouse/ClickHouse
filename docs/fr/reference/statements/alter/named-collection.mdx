Cette requête permet de modifier des collections nommées existantes.

<Note>
  Les collections nommées créées par DDL peuvent être activées sur certains services ClickHouse Cloud. Contactez l’assistance pour confirmer leur disponibilité.
</Note>

**Syntaxe**

```sql
ALTER NAMED COLLECTION [IF EXISTS] name [ON CLUSTER cluster]
[ SET
key_name1 = 'some value' [[NOT] OVERRIDABLE],
key_name2 = 'some value' [[NOT] OVERRIDABLE],
key_name3 = 'some value' [[NOT] OVERRIDABLE],
... ] |
[ DELETE key_name4, key_name5, ... ]
```

**Exemple**

```sql
CREATE NAMED COLLECTION foobar AS a = '1' NOT OVERRIDABLE, b = '2';

ALTER NAMED COLLECTION foobar SET a = '2' OVERRIDABLE, c = '3';

ALTER NAMED COLLECTION foobar DELETE b;
```

**Fait partie de :** `ALTER`

**Associé à :** `CREATE NAMED COLLECTION`, `ALTER`, `DROP`
