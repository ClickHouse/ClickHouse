```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

Renvoie une unique colonne de type `UInt8`, contenant la valeur `0` si la table ou la base de données n’existe pas, ou `1` si la table existe dans la base de données spécifiée.

## Forme avec sous-requête {#subquery-form}

L&#39;opérateur `EXISTS` vérifie si une sous-requête renvoie au moins une ligne. Il renvoie `0` si le résultat de la sous-requête est vide, et `1` dans le cas contraire.

Vous pouvez utiliser `EXISTS` dans une clause [`WHERE`](/fr/reference/statements/select/where). La sous-requête ne peut pas faire référence à des tables ou à des colonnes de la requête externe.

**Syntaxe**

```sql
EXISTS(subquery)
```

**Exemples**

Vérifier si une sous-requête renvoie des lignes :

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

Utilisez `EXISTS` dans une clause `WHERE` avec une sous-requête qui renvoie plusieurs lignes :

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

Lorsque le résultat de la sous-requête est vide, `EXISTS` renvoie `0` :

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```
