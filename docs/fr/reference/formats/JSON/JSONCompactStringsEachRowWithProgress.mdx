## Description {#description}

Semblable à [`JSONCompactEachRowWithProgress`](/fr/reference/formats/JSON/JSONCompactEachRowWithProgress), mais toutes les valeurs sont converties en chaînes de caractères. Ce format utilise les mêmes types d&#39;objets de premier niveau (`meta`, `row`, `progress`, `totals`, `min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation`, ainsi qu&#39;un objet `exception` de premier niveau) ; les charges utiles `row` / `totals` / `min` / `max` restent des **tableaux** ordonnés selon les colonnes, chaque élément étant sérialisé sous forme de chaîne.

Consultez [`JSONCompactEachRowWithProgress`](/fr/reference/formats/JSON/JSONCompactEachRowWithProgress) pour le contrat complet des objets du flux (`progress` peut arriver avant `meta` ; `rows_before_limit_at_least` est une estimation basse lorsque la requête contient `LIMIT`, et non la preuve que des lignes ont été supprimées ; `exception` n&#39;est écrit que via HTTP, avec `http_write_exception_in_output_format=1`).

## Exemple d’utilisation {#example-usage}

```sql title="Query"
SELECT *
FROM generateRandom('a Array(Int8), d Decimal32(4), c Tuple(DateTime64(3), UUID)', 1, 10, 2)
LIMIT 5
FORMAT JSONCompactStringsEachRowWithProgress
```
