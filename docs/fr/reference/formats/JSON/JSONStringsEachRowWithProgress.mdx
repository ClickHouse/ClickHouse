## Description {#description}

Se distingue de `JSONEachRow`/`JSONStringsEachRow` en ce que ClickHouse diffuse chaque événement sous la forme d&#39;un objet JSON distinct et fournit également des informations de progression.

Toutes les valeurs des champs sont sérialisées sous forme de chaînes de caractères (y compris les types complexes) : par exemple, `arr` est émis sous la forme `"arr":"[0,1]"`, et non comme un tableau JSON imbriqué. Les valeurs scalaires sont elles aussi converties en chaînes (`"num":"42"`).

Les types d&#39;objets de premier niveau sont les mêmes que pour [`JSONEachRowWithProgress`](/fr/reference/formats/JSON/JSONEachRowWithProgress) (`meta`, `row`, `progress`, `totals`/`min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation` et `exception` de premier niveau). Reportez-vous à cette page pour le contrat complet du flux : un objet `progress` peut arriver avant `meta` ; `rows_before_limit_at_least` est une estimation basse lorsque la requête contient `LIMIT` (ce qui ne prouve pas que des lignes ont été écartées) ; `exception` n&#39;est écrit que via HTTP, avec `http_write_exception_in_output_format=1`.

## Exemple d’utilisation {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
