## Description {#description}

Affiche chaque valeur sur une ligne distincte, avec le nom de la colonne indiqué. Ce format est pratique pour n’afficher qu’une ou quelques lignes lorsque chaque ligne comporte un grand nombre de colonnes.

Notez que [`NULL`](/fr/reference/syntax) est affiché sous la forme `ᴺᵁᴸᴸ` afin de permettre de distinguer plus facilement la chaîne `NULL` d’une absence de valeur. Les colonnes JSON sont affichées dans un format Pretty, et `NULL` est rendu sous la forme `null`, car il s’agit d’une valeur JSON valide, facile à distinguer de `"null"`.

## Exemple d&#39;utilisation {#example-usage}

Exemple :

```sql
SELECT * FROM t_null FORMAT Vertical
```

```response
Row 1:
──────
x: 1
y: ᴺᵁᴸᴸ
```

Par défaut, les caractères de contrôle non imprimables (caractères de contrôle C0 `0x00`–`0x1F` et `DEL` `0x7F`) présents dans les valeurs et dans les noms de colonnes sont affichés sous la forme des symboles Unicode « Control Pictures » correspondants (`U+2400`–`U+2421`), afin qu&#39;ils restent visibles au lieu d&#39;être discrètement absorbés par le terminal. Par exemple, un caractère NUL s&#39;affiche sous la forme `␀` :

```sql
SELECT 'string with a NUL \0 character' AS test FORMAT Vertical
```

```response
Row 1:
──────
test: string with a NUL ␀ character
```

`TAB`, le saut de ligne et `ESC` font exception : ils sont toujours affichés tels quels, car un terminal les interprète au lieu de les ignorer — une tabulation avance jusqu&#39;au taquet de tabulation suivant, un saut de ligne passe à la ligne, et c&#39;est grâce à une séquence d&#39;échappement ANSI que les données peuvent contenir une visualisation. Le nom de colonne constitue l&#39;exception à cette exception : il est rendu sur une seule ligne, si bien qu&#39;un saut de ligne dans un nom est remplacé comme n&#39;importe quel autre caractère de contrôle.

Pour afficher au contraire les caractères de contrôle tels quels, désactivez [`output_format_pretty_display_control_characters`](/fr/reference/settings/formats#output_format_pretty_display_control_characters) :

```sql
SELECT 'string with a NUL \0 character' AS test
FORMAT Vertical
SETTINGS output_format_pretty_display_control_characters = 0
```

La réponse contient alors l&#39;octet `NUL` brut. Un terminal l&#39;absorbe, si bien que la valeur
s&#39;affiche comme si le caractère était tout simplement manquant.

Ce format convient uniquement à la sortie d&#39;un résultat de requête, et non à l&#39;analyse (récupération de données à insérer dans une table).
