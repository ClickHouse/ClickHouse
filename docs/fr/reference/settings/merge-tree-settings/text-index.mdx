La version préférée du format de sérialisation sur disque pour l’écriture des index de texte.

Ce paramètre constitue une préférence plutôt qu’une contrainte stricte : si la version configurée ne peut pas représenter un index, une version plus récente capable de le représenter est automatiquement choisie, et l’écriture d’un index de texte n’échoue jamais en raison de ce paramètre.

Lors d’une mise à niveau progressive, définissez le format à l’aide du paramètre `compatibility` au niveau du profil sur les serveurs déjà mis à niveau, afin qu’ils continuent d’écrire dans un format que les serveurs plus anciens peuvent toujours lire.

Valeurs possibles :

* `v0_initial` — Le format d’origine. Ne conserve pas le type de codec de la liste de postings.
* `v1_with_codec` — Conserve le type de codec de la liste de postings dans l’en-tête de l’index de texte.
* `v2_with_positions` — Conserve les positions des jetons pour les index avec `support_phrase_search`.
