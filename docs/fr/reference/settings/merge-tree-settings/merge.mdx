<div id="merge_use_batch_sorting_queue">
  ## merge_use_batch_sorting_queue
</div>

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "Nouveau paramètre permettant d’utiliser la file de tri par lots pour les fusions `MergeTree` ordinaires."}]}]} />

Utilisez la file de tri par lots pour réduire le surcoût par ligne de la file d’attente lors de la fusion de flux triés.

S’applique uniquement aux fusions qui ne modifient pas les lignes, c’est-à-dire aux fusions `MergeTree`
simples (mode de fusion `Ordinary`). Ce paramètre n’a aucun effet sur les moteurs dont la sémantique s’applique lors de la fusion, tels que `ReplacingMergeTree`, `CollapsingMergeTree`,
`SummingMergeTree`, `AggregatingMergeTree`, `CoalescingMergeTree`,
`GraphiteMergeTree` et `VersionedCollapsingMergeTree`, qui continuent d’utiliser la
file d’attente par défaut, quel que soit ce paramètre.

<div id="merge_workload">
  ## merge_workload
</div>

Utilisé pour réguler l’utilisation et le partage des ressources entre les fusions et les autres charges de travail. La valeur spécifiée est utilisée comme valeur du paramètre `workload` pour les fusions en arrière-plan de cette table. Si elle n’est pas spécifiée (chaîne vide), le paramètre du serveur `merge_workload` est utilisé à la place.
