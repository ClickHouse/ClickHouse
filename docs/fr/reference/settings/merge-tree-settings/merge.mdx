## merge_checkpoints_min_interval_seconds {#merge_checkpoints_min_interval_seconds}

<ExperimentalBadge />

<SettingsInfoBlock type="Seconds" default_value="60" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "60"},{"label": "Nouveau paramètre pour les points de contrôle durables des fusions"}]}]} />

Durée minimale entre deux points de contrôle d&#39;une fusion lorsque `enable_merge_checkpoints` est activé.
Une fusion verticale crée toujours un point de contrôle dès que ses colonnes de clé ont été fusionnées. Par la suite, elle ne crée un point de contrôle à l&#39;issue du traitement d&#39;une colonne
que si cette durée s&#39;est écoulée depuis son point de contrôle précédent.

## merge_use_batch_sorting_queue {#merge_use_batch_sorting_queue}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "Nouveau paramètre permettant d’utiliser la file de tri par lots pour les fusions `MergeTree` ordinaires."}]}]} />

Utilisez la file de tri par lots pour réduire le surcoût par ligne de la file d’attente lors de la fusion de flux triés.

S’applique uniquement aux fusions en mode de fusion `Ordinary` : les fusions de parts `MergeTree` simples, y compris
les fusions qui suppriment ou réécrivent des lignes (suppressions légères, suppressions TTL, patch parts des mises à jour
légères et `OPTIMIZE ... DEDUPLICATE`), ainsi que les fusions de parties de projection ordinaires. Les algorithmes
de fusion des moteurs dont la sémantique s’applique lors de la fusion, tels que `ReplacingMergeTree`, `CollapsingMergeTree`,
`SummingMergeTree`, `AggregatingMergeTree`, `CoalescingMergeTree`, `GraphiteMergeTree` et
`VersionedCollapsingMergeTree`, ainsi que ceux des parties de projection d’agrégation, choisissent leur propre file de tri ; ce
paramètre n’a donc aucun effet sur eux.

## merge_workload {#merge_workload}

Utilisé pour réguler l’utilisation et le partage des ressources entre les fusions et les autres charges de travail. La valeur spécifiée est utilisée comme valeur du paramètre `workload` pour les fusions en arrière-plan de cette table. Si elle n’est pas spécifiée (chaîne vide), le paramètre du serveur `merge_workload` est utilisé à la place.
