## check_part_use_direct_io {#check_part_use_direct_io}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.12"},{"label": "1"},{"label": "Nouveau paramètre. Vérifie les parts situées sur des disques locaux en E/S directes, en contournant le cache de pages du système d’exploitation."}]}]} />

Lors de la vérification d’une part située sur un disque local (`CHECK TABLE`, vérification d’une part dont la lecture a échoué,
recalcul des sommes de contrôle manquantes), ses fichiers sont lus en E/S directes (option `O_DIRECT`),
en contournant le cache de pages du système d’exploitation, afin que des données erronées présentes dans le cache de pages ne fassent pas passer une part saine pour corrompue.
Les parts en stockage regroupé (voir `min_bytes_for_full_part_storage`) et la part écrite par `OPTIMIZE ... DRY RUN`
restent lues via le cache de pages.
Si le système de fichiers ne prend pas en charge les E/S directes, les fichiers sont lus via le cache de pages.

Désactivez ce paramètre lorsque les lectures directes sont plus lentes que les lectures via le cache de pages.
Les lectures directes accèdent toujours au périphérique de stockage, même si les données sont déjà en cache.
Par exemple, sur un volume Amazon EBS, la vérification d’une table qui tient dans le cache de pages peut être plusieurs fois plus lente.

## check_sample_column_is_correct {#check_sample_column_is_correct}

<SettingsInfoBlock type="Bool" default_value="1" />

Active la vérification, lors de la création de la table, que le type de données d’une colonne d’échantillonnage ou d’une expression d’échantillonnage est correct. Le type de données doit être l’un des [types entiers](/fr/reference/data-types/int-uint) non signés : `UInt8`, `UInt16`,
`UInt32`, `UInt64`.

Valeurs possibles :

* `true`  — La vérification est activée.
* `false` — La vérification est désactivée lors de la création de la table.

Valeur par défaut : `true`.

Par défaut, le serveur ClickHouse vérifie, lors de la création de la table, le type de données d’une colonne d’échantillonnage ou d’une expression d’échantillonnage. Si vous avez déjà des tables avec une expression d’échantillonnage incorrecte et que vous ne voulez pas que le serveur lève une exception au démarrage, définissez `check_sample_column_is_correct` sur `false`.
