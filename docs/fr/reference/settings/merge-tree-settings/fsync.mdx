## fsync_after_insert {#fsync_after_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

Effectue un fsync pour chaque part insérée, afin que les données soient durables lorsque la requête `INSERT`
est acquittée. Réduit les performances des insertions, en particulier avec des parties au format wide.
Voir aussi `group_fsync_before_insert_finish`.

## fsync_part_directory {#fsync_part_directory}

<SettingsInfoBlock type="Bool" default_value="0" />

Effectue un fsync sur le répertoire de la part une fois toutes les opérations sur la part terminées (écritures, renommages, etc.).
