## vertical_merge_optimize_ttl_delete {#vertical_merge_optimize_ttl_delete}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.3"},{"label": "1"},{"label": "Autoriser l’algorithme de fusion verticale pour les fusions devant supprimer les lignes expirées par TTL"}]}]} />

Si la valeur est true, une fusion avec TTL de lignes peut utiliser l’algorithme de fusion verticale au lieu de se rabattre sur une
fusion horizontale. Ne s’applique qu’en mode de fusion `MergeTree`, `Replacing`, `Collapsing` ou `VersionedCollapsing`,
à une table dotée d’un TTL de lignes, sans TTL de colonne ni TTL `GROUP BY`, et uniquement si aucune partie de données
impliquée dans la fusion ne comporte de lightweight delete. Toute autre fusion TTL reste horizontale.
