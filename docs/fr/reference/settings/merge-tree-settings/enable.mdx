## enable_adaptive_codec_selection {#enable_adaptive_codec_selection}

<BetaBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "Nouveau paramètre."}]}, {"id": "row-2","items": [{"label": "26.11"},{"label": "0"},{"label": "La sélection adaptative du codec est passée en bêta."}]}]} />

Lorsqu&#39;elle est activée, les fusions et les mutations choisissent un codec par bloc pour les colonnes utilisant le codec par défaut (sans clause `CODEC` ou avec `CODEC(Default)`).
Les candidats sont le codec par défaut de la table (voir le paramètre `default_compression_codec`), `NONE` et des codecs spécialisés adaptés au type de la colonne, chacun appliqué seul et, lorsque le codec par défaut est un algorithme de compression généraliste tel que `LZ4` ou `ZSTD`, également suivi de ce dernier.
La plus petite sortie est retenue et les blocs incompressibles sont stockés bruts. Le choix est effectué sur un bloc tous les `adaptive_codec_selection_period` blocs, puis réutilisé pour les blocs intermédiaires.
Une colonne dont le codec par défaut inclut du chiffrement (par exemple, `AES_128_GCM_SIV`) n&#39;est jamais sélectionnée de manière adaptative, de sorte que le chiffrement est toujours appliqué.
Les codecs utilisés par bloc sont signalés par la fonction de table [`mergeTreeCodecBlockCounts`](/fr/reference/functions/table-functions/index).

## enable_merge_checkpoints {#enable_merge_checkpoints}

<ExperimentalBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nouveau paramètre pour les points de contrôle de fusion durables"}]}]} />

Enregistre des points de contrôle pour les fusions éligibles, afin qu&#39;une fusion interrompue reprenne à partir de ceux-ci au lieu de repartir de zéro.
Pour l&#39;instant, seules les fusions verticales vers des parties de données `Wide` d&#39;au moins `merge_checkpoints_min_bytes` font l&#39;objet de points de contrôle.
Le premier point de contrôle est enregistré une fois les colonnes de clé fusionnées, les suivants après chaque colonne terminée,
au plus une fois toutes les `merge_checkpoints_min_interval_seconds`.
Un point de contrôle est supprimé lorsqu&#39;une partie de données actuelle couvre sa partie de données résultante,
ou lorsqu&#39;aucune fusion ne l&#39;a enregistré depuis `temporary_directories_lifetime`.
Les fusions impliquant un TTL, des projections, des index secondaires, des parties de données de patch ou des marques non adaptatives (`index_granularity_bytes = 0`) ne font pas l&#39;objet de points de contrôle.

## enable_mixed_granularity_parts {#enable_mixed_granularity_parts}

<SettingsInfoBlock type="Bool" default_value="1" />

Active ou désactive l&#39;utilisation du paramètre `index_granularity_bytes` pour contrôler la taille des
granules. Avant la version 19.11, seul le paramètre
`index_granularity` permettait de limiter la taille des granules. Le paramètre
`index_granularity_bytes` améliore les performances de ClickHouse lors de la
lecture de données à partir de tables contenant de grandes lignes (de dizaines ou de centaines de mégaoctets).
Si vous avez des tables avec de grandes lignes, vous pouvez activer ce paramètre pour ces tables
afin d&#39;améliorer l&#39;efficacité des requêtes `SELECT`.

## enable_vertical_merge_algorithm {#enable_vertical_merge_algorithm}

<SettingsInfoBlock type="UInt64" default_value="1" />

Permet aux fusions en arrière-plan éligibles d’utiliser l’algorithme de fusion verticale. Les fusions verticales traitent les colonnes séparément afin de réduire le pic d’utilisation de la mémoire pour les tables larges, au prix éventuel d’une vitesse de fusion moindre. Définir ce paramètre sur `0` impose les fusions horizontales ; une valeur non nulle se contente d’autoriser les fusions verticales — c’est toujours le format de la partie de données, le table engine, l’opération `TTL` et les seuils `vertical_merge_algorithm_min_*` qui déterminent si cet algorithme est retenu.
