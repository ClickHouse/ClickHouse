Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

<div id="access_control_improvements">
  ## access_control_improvements
</div>

Paramètres des améliorations facultatives du système de contrôle d&#39;accès.

| Paramètre                                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Défaut  |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `on_cluster_queries_require_cluster_grant`      | Définit si les requêtes `ON CLUSTER` nécessitent le privilège `CLUSTER`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `true`  |
| `role_cache_expiration_time_seconds`            | Définit le nombre de secondes écoulées depuis le dernier accès pendant lesquelles un rôle est conservé dans le cache des rôles.                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `600`   |
| `select_from_information_schema_requires_grant` | Définit si `SELECT * FROM information_schema.<table>` requiert des privilèges ou peut être exécuté par n&#39;importe quel utilisateur. Si cette option est définie sur `true`, cette requête nécessite `GRANT SELECT ON information_schema.<table>`, comme pour les tables ordinaires.                                                                                                                                                                                                                                                                                            | `true`  |
| `select_from_system_db_requires_grant`          | Définit si `SELECT * FROM system.<table>` requiert des privilèges ou peut être exécuté par n&#39;importe quel utilisateur. Si cette option est définie sur `true`, cette requête nécessite `GRANT SELECT ON system.<table>`, comme pour les tables non système. Exceptions : quelques tables système (`tables`, `columns`, `databases`, ainsi que certaines tables constantes comme `one` et `contributors`) restent accessibles à tous ; et si un privilège `SHOW` (par ex. `SHOW USERS`) est accordé, la table système correspondante (c.-à-d. `system.users`) sera accessible. | `true`  |
| `settings_constraints_replace_previous`         | Définit si une contrainte d&#39;un profil de paramètres pour un paramètre donné annule les effets de la contrainte précédente (définie dans d&#39;autres profils) pour ce paramètre, y compris pour les champs qui ne sont pas définis par la nouvelle contrainte. Cela active également le type de contrainte `changeable_in_readonly`.                                                                                                                                                                                                                                          | `true`  |
| `table_engines_require_grant`                   | Définit si la création d&#39;une table avec un moteur de table spécifique nécessite un privilège. Non pris en charge dans ClickHouse Cloud.                                                                                                                                                                                                                                                                                                                                                                                                                                       | `false` |
| `throw_on_unmatched_row_policies`               | Définit si la lecture d&#39;une table doit lever une exception lorsque la table comporte des politiques de ligne, mais qu&#39;aucune ne s&#39;applique à l&#39;utilisateur courant                                                                                                                                                                                                                                                                                                                                                                                                | `false` |
| `users_without_row_policies_can_read_rows`      | Définit si les utilisateurs sans politiques de ligne permissives peuvent malgré tout lire des lignes à l&#39;aide d&#39;une requête `SELECT`. Par exemple, s&#39;il y a deux utilisateurs A et B et qu&#39;une politique de ligne n&#39;est définie que pour A, alors si ce paramètre vaut `true`, l&#39;utilisateur B verra toutes les lignes. Si ce paramètre vaut `false`, l&#39;utilisateur B ne verra aucune ligne.                                                                                                                                                          | `true`  |

Exemple :

```xml
<access_control_improvements>
    <throw_on_unmatched_row_policies>true</throw_on_unmatched_row_policies>
    <users_without_row_policies_can_read_rows>true</users_without_row_policies_can_read_rows>
    <on_cluster_queries_require_cluster_grant>true</on_cluster_queries_require_cluster_grant>
    <select_from_system_db_requires_grant>true</select_from_system_db_requires_grant>
    <select_from_information_schema_requires_grant>true</select_from_information_schema_requires_grant>
    <settings_constraints_replace_previous>true</settings_constraints_replace_previous>
    <table_engines_require_grant>false</table_engines_require_grant>
    <role_cache_expiration_time_seconds>600</role_cache_expiration_time_seconds>
</access_control_improvements>
```

<div id="access_control_path">
  ## access_control_path
</div>

Chemin vers un dossier où le serveur ClickHouse stocke les configurations des utilisateurs et des rôles créées par des commandes SQL.
