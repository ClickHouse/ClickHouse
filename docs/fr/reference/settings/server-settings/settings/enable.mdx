Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

## enable_azure_sdk_logging {#enable_azure_sdk_logging}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Active la journalisation du SDK Azure

## enable_gpu {#enable_gpu}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Réserve le GPU au démarrage du serveur afin d&#39;y exécuter les requêtes. Le serveur refuse de démarrer s&#39;il a été compilé sans prise en charge du GPU ou si aucun périphérique CUDA n&#39;est disponible.

## enable_read_through_distributed_cache {#enable_read_through_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />N&#39;a d&#39;effet que dans ClickHouse Cloud. Autorise la lecture depuis le cache distribué. Ce paramètre au niveau du serveur est appliqué sans redémarrage afin que les opérations en arrière-plan qui ne disposent pas de leur propre profil de requête (fusions, mutations, vidages des tables `Buffer`) le respectent également. Les requêtes individuelles peuvent y déroger à l&#39;aide du paramètre `force_read_through_distributed_cache`.

## enable_silk_runtime {#enable_silk_runtime}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Active la prise en charge expérimentale du runtime de fibres silk : initialise le planificateur de fibres silk au démarrage du serveur afin que les sous-systèmes compatibles puissent exécuter leurs tâches sur des fibres

## enable_webterminal {#enable_webterminal}

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />Active l’interface du terminal web au endpoint HTTP `/webterminal`. Fournit une session `clickhouse-client` interactive dans le navigateur via WebSocket. Lorsque `false`, les requêtes vers `/webterminal` renvoient le code HTTP `403 Forbidden`.

## enable_write_through_distributed_cache {#enable_write_through_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />N&#39;a d&#39;effet que dans ClickHouse Cloud. Autorise l&#39;écriture dans le cache distribué (l&#39;écriture dans S3 sera également effectuée par le cache distribué). Ce paramètre au niveau du serveur est appliqué sans redémarrage, afin que les opérations en arrière-plan qui ne disposent pas de leur propre profil de requête (fusions, mutations, vidages de tables `Buffer`) le respectent également. Les requêtes individuelles peuvent s&#39;en écarter à l&#39;aide du paramètre `force_write_through_distributed_cache`.
