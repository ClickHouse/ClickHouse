Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

## totp_track_used_codes_in_keeper {#totp_track_used_codes_in_keeper}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

Garantit l&#39;usage unique des codes de mot de passe à usage unique basé sur le temps (TOTP) sur l&#39;ensemble des serveurs partageant le même ZooKeeper ou ClickHouse Keeper, et non plus serveur par serveur.

Les codes acceptés sont enregistrés dans Keeper sous le path défini par `totp_used_codes_keeper_path`, à raison d&#39;un nœud par utilisateur, nommé d&#39;après le hachage SHA-256 du nom d&#39;utilisateur : un code accepté par un serveur est rejeté par tous les autres, et l&#39;enregistrement est conservé après un redémarrage des serveurs. Keeper doit être configuré lorsque ce paramètre est activé ; tant que Keeper est indisponible, l&#39;authentification par mot de passe à usage unique échoue.

**Exemple**

```xml
<totp_track_used_codes_in_keeper>1</totp_track_used_codes_in_keeper>
```

## totp_used_codes_keeper_path {#totp_used_codes_keeper_path}

<SettingsInfoBlock type="String" default_value="/clickhouse/access/one_time_passwords" changeable_without_restart="No" />

Le path dans Keeper sous lequel sont enregistrés les codes de mot de passe à usage unique basés sur le temps (TOTP) acceptés lorsque `totp_track_used_codes_in_keeper` est activé. Les clusters qui partagent un même Keeper sans chroot doivent utiliser des paths distincts ; sinon, les utilisateurs portant le même nom sur des clusters différents partageraient leurs enregistrements.

**Exemple**

```xml
<totp_used_codes_keeper_path>/clickhouse/access/one_time_passwords</totp_used_codes_keeper_path>
```
