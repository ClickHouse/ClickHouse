Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

## ai_function_max_thread_pool_free_size {#ai_function_max_thread_pool_free_size}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

Nombre maximal de fils d’exécution inactifs en attente à conserver dans le thread pool pour les requêtes adressées aux fournisseurs d’IA.

## ai_function_max_thread_pool_size {#ai_function_max_thread_pool_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1000" changeable_without_restart="Yes" />

Nombre total maximal de fils d’exécution utilisés pour les requêtes envoyées aux fournisseurs d’IA. Chaque fil d’exécution traite une seule requête : ce paramètre plafonne donc le nombre de requêtes vers les fournisseurs d’IA que l’ensemble du serveur peut avoir en cours simultanément, toutes requêtes SQL confondues. [`ai_function_max_concurrent_requests_per_thread`](/fr/reference/settings/session-settings/ai-function#ai_function_max_concurrent_requests_per_thread) limite la part de ce total attribuée à chaque fil d’exécution de requête.

## ai_function_thread_pool_queue_size {#ai_function_thread_pool_queue_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />

Nombre maximal de jobs pouvant être planifiés dans le thread pool dédié aux requêtes adressées aux fournisseurs d’IA.
