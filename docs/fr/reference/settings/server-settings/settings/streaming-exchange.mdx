Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Taille de l’option SO&#95;RCVBUF pour les sockets d’exchange en streaming des requêtes distribuées multi-étapes. 0 = valeur par défaut du kernel (réglage automatique TCP). Une valeur supérieure à 0 plafonne le tampon de réception de chaque socket (lui-même plafonné par net.core.rmem&#95;max). Ce paramètre étant lu à chaque connexion, un rechargement de la configuration ne s’applique qu’aux nouvelles connexions.

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Taille de l&#39;option SO&#95;SNDBUF pour les sockets d&#39;exchange en streaming des requêtes distribuées multi-étapes. 0 = valeur par défaut du kernel (réglage automatique TCP). Une valeur supérieure à 0 limite le tampon d&#39;envoi de chaque socket (valeur plafonnée par net.core.wmem&#95;max), mais plafonne alors le débit du flux à sndbuf/RTT sur les liaisons à RTT élevé. Ce paramètre est lu à chaque connexion : un rechargement de la configuration ne s&#39;applique donc qu&#39;aux nouvelles connexions.
