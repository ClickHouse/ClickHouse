Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

## encryption_header_cache_policy {#encryption_header_cache_policy}

<SettingsInfoBlock type="String" default_value="SLRU" changeable_without_restart="No" />Politique d&#39;éviction du cache des en-têtes de chiffrement. Valeurs possibles : `LRU`, `SLRU`, `SIEVE`. Consultez [`encryption_header_cache_size`](/fr/reference/settings/server-settings/settings/encryption-header#encryption_header_cache_size) pour la capacité du cache et [`encryption_header_cache_size_ratio`](/fr/reference/settings/server-settings/settings/encryption-header#encryption_header_cache_size_ratio) pour la taille de la file protégée de la politique SLRU.

## encryption_header_cache_size {#encryption_header_cache_size}

<SettingsInfoBlock type="UInt64" default_value="52428800" changeable_without_restart="Oui" />

Taille maximale du cache des en-têtes de chiffrement lus depuis des fichiers chiffrés sur des disques utilisant des chemins de blob aléatoires, tels que les disques `s3`. Ce cache évite de relire l’en-tête d’un fichier depuis le stockage d’objet.

<Note>
  Ce paramètre peut être modifié à l’exécution et prendra effet immédiatement.
</Note>

## encryption_header_cache_size_ratio {#encryption_header_cache_size_ratio}

<SettingsInfoBlock type="Double" default_value="0.5" changeable_without_restart="Non" />La taille de la file protégée (dans le cas d’une politique SLRU) du cache des en-têtes de chiffrement, par rapport à la taille totale du cache.
