Ces paramètres configurent le serveur ClickHouse et sont générés automatiquement à partir du code source de ClickHouse.

## amber_connections_hard_limit {#amber_connections_hard_limit}

<SettingsInfoBlock type="UInt64" default_value="200000" changeable_without_restart="No" />Une exception est levée lors d&#39;une tentative de création lorsque cette limite est atteinte. Définissez la valeur sur 0 pour désactiver la limite stricte. Cette limite s&#39;applique aux connexions Amber.

## amber_connections_rcvbuf {#amber_connections_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="204800" changeable_without_restart="Yes" />Taille de l’option SO&#95;RCVBUF pour les connexions Amber. Valeur par défaut : 204800 (200 KB). Le stockage d’objet est accessible au sein de la même région, où le produit débit-délai est bien inférieur à 100 KB ; une limite basse permet donc d’atteindre le débit maximal tout en évitant les tampons de plusieurs Mio par socket que le réglage automatique du noyau allouerait autrement. Définissez la valeur sur 0 pour confier plutôt le dimensionnement du tampon de réception à l’ajustement automatique TCP du noyau. Remarque : remettre ce paramètre à 0 ne rétablit le réglage automatique que pour les connexions nouvellement créées ; les connexions mises en pool existantes conservent des tailles de tampon fixes jusqu’à ce qu’elles soient recréées.

## amber_connections_sndbuf {#amber_connections_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Taille de l’option SO&#95;SNDBUF pour les connexions Amber. Si elle est définie sur une valeur supérieure à 0, elle remplace l’ajustement automatique TCP du noyau pour le tampon d’envoi. 0 = valeur par défaut du noyau (réglage automatique). Remarque : remettre ce paramètre à 0 ne rétablit le réglage automatique que pour les connexions nouvellement créées ; les connexions mises en pool existantes conservent des tailles de tampons fixes jusqu’à ce qu’elles soient recréées.

## amber_connections_soft_limit {#amber_connections_soft_limit}

<SettingsInfoBlock type="UInt64" default_value="5000" changeable_without_restart="No" />Au-delà de cette limite, les connexions ont une durée de vie nettement plus courte. Cette limite s&#39;applique aux connexions Amber.

## amber_connections_store_limit {#amber_connections_store_limit}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="No" />Nombre maximal de connexions inactives conservées dans le pool en vue de leur réutilisation. Une fois ce nombre de connexions stockées atteint, les connexions supplémentaires sont réinitialisées après utilisation au lieu d&#39;être conservées. Cette limite ne s&#39;applique pas aux connexions en cours d&#39;utilisation. Définissez la valeur sur 0 pour désactiver le cache de connexions. Cette limite s&#39;applique aux connexions Amber.

## amber_connections_warn_limit {#amber_connections_warn_limit}

<SettingsInfoBlock type="UInt64" default_value="8000" changeable_without_restart="No" />Des messages d&#39;avertissement sont écrits dans les logs lorsque le nombre de connexions actives dépasse cette limite. Cette limite s&#39;applique aux connexions Amber.
