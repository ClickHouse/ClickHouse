<div id="max_hyperscan_regexp_length">
  ## max_hyperscan_regexp_length
</div>

<SettingsInfoBlock type="UInt64" default_value="0" />

Définit la longueur maximale de chaque expression régulière dans les [fonctions multi-match Hyperscan](/fr/reference/functions/regular-functions/string-search-functions#multiMatchAny).

Valeurs possibles :

* Entier positif.
* 0 - La longueur n’est pas limitée.

**Exemple**

Requête :

```sql
SELECT multiMatchAny('abcd', ['ab','bcd','c','d']) SETTINGS max_hyperscan_regexp_length = 3;
```

Résultat :

```text
┌─multiMatchAny('abcd', ['ab', 'bcd', 'c', 'd'])─┐
│                                              1 │
└────────────────────────────────────────────────┘
```

Requête :

```sql
SELECT multiMatchAny('abcd', ['ab','bcd','c','d']) SETTINGS max_hyperscan_regexp_length = 2;
```

Résultat :

```text
Exception: Regexp length too large.
```

<div id="max_hyperscan_regexp_total_length">
  ## max_hyperscan_regexp_total_length
</div>

<SettingsInfoBlock type="UInt64" default_value="0" />

Définit la longueur totale maximale de l’ensemble des expressions régulières pour chaque [fonction multi-match Hyperscan](/fr/reference/functions/regular-functions/string-search-functions#multiMatchAny).

Valeurs possibles :

* Entier positif.
* 0 - La longueur n&#39;est pas limitée.

**Exemple**

Requête :

```sql
SELECT multiMatchAny('abcd', ['a','b','c','d']) SETTINGS max_hyperscan_regexp_total_length = 5;
```

Résultat :

```text
┌─multiMatchAny('abcd', ['a', 'b', 'c', 'd'])─┐
│                                           1 │
└─────────────────────────────────────────────┘
```

Requête :

```sql
SELECT multiMatchAny('abcd', ['ab','bc','c','d']) SETTINGS max_hyperscan_regexp_total_length = 5;
```

Résultat :

```text
Exception: Total regexp lengths too large.
```
