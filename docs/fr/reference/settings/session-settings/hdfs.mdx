## hdfs_create_new_file_on_insert {#hdfs_create_new_file_on_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

Active ou désactive la création d’un nouveau fichier à chaque insertion dans les tables du moteur HDFS. Si ce paramètre est activé, un nouveau fichier HDFS est créé à chaque insertion, selon un schéma de nommage semblable à celui-ci :

initial : `data.Parquet.gz` -&gt; `data.1.Parquet.gz` -&gt; `data.2.Parquet.gz`, etc.

Valeurs possibles :

* 0 — la requête `INSERT` ajoute de nouvelles données à la fin du fichier.
* 1 — la requête `INSERT` crée un nouveau fichier.

## hdfs_skip_hidden_files {#hdfs_skip_hidden_files}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nouveau paramètre : ignore les fichiers dont un segment de chemin commence par `_` ou `.` sous le préfixe sans glob lors de l’énumération de fichiers par glob, comme le font les autres lecteurs de l’écosystème Hive. Les tables avec `partition_strategy = 'hive'` ignorent toujours ces chemins."}]}]} />

Active ou désactive l’exclusion des chemins cachés lors de l’énumération de fichiers par glob dans les tables utilisant le moteur [HDFS](/fr/reference/engines/table-engines/integrations/hdfs), c’est-à-dire des fichiers dont un segment de chemin commence par `_` ou `.` sous le préfixe sans glob du chemin. Un segment contenant `=` est un répertoire de partition (par exemple `_p=1` pour une colonne de partitionnement `_p`) et n’est pas considéré comme caché. Les rédacteurs de l’écosystème Hive (Hive, Spark, Trino) placent leur sortie en cours d’écriture dans un stockage intermédiaire et écrivent des fichiers marqueurs sous ces chemins (`_temporary/`, `.spark-staging-<id>/`, `_SUCCESS`) ; leur lecture crée donc une condition de concurrence avec la validation du rédacteur. Les segments situés dans le préfixe sans glob ne sont pas vérifiés. Les tables avec `partition_strategy = 'hive'` ignorent toujours les chemins cachés, quelle que soit la valeur de ce paramètre.

Valeurs possibles :

* 0 — tous les fichiers correspondant au glob sont lus.
* 1 — les fichiers comportant un segment de chemin caché sous le préfixe sans glob sont ignorés.

## hdfs_truncate_on_insert {#hdfs_truncate_on_insert}

<SettingsInfoBlock type="Bool" default_value="0" />

Active ou désactive la troncature avant une opération d’insertion dans les tables du moteur HDFS. Si cette option est désactivée, une exception est levée en cas de tentative d’insertion si un fichier existe déjà dans HDFS.

Valeurs possibles :

* 0 — la requête `INSERT` ajoute de nouvelles données à la fin du fichier.
* 1 — la requête `INSERT` remplace le contenu existant du fichier par les nouvelles données.
