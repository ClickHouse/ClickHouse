Sélectionne l’implémentation de sonde du chemin d’écriture UNIQUE KEY. Actuellement, seule une implémentation de référence monothread existe ; `auto` et `simple` y correspondent donc tous deux.

Réservé : ce paramètre n’a pas encore d’effet — sa valeur n’est pas lue tant que le chemin d’écriture UNIQUE KEY INSERT qui construit la sonde n’est pas implémenté. Il est déclaré dès maintenant afin que ce mécanisme soit disponible avec l’implémentation.
