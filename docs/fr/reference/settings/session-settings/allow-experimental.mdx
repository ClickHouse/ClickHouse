## allow_experimental_analyzer {#allow_experimental_analyzer}

**Aliases** : `enable_analyzer`

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Le paramètre est obsolète : l'analyseur est obligatoire et l'ancienne analyse de requête n'est plus prise en charge. Obsolète depuis la v26.9 : l&#39;analyseur ne peut plus être désactivé.

L&#39;analyseur est l&#39;infrastructure d&#39;analyse et de planification des requêtes utilisée par défaut depuis la v24.3. Dans la v26.9, ce paramètre a été figé sur sa seule valeur prise en charge, `1`, et le paramètre `compatibility` ne le rétablit plus. Dans la v26.10, l&#39;analyse de requête vers laquelle il permettait de basculer a été supprimée. Pour des raisons de rétrocompatibilité, la valeur `0` est acceptée et remplacée par `1` : les requêtes, paramètres de session, settings profile et configurations client qui définissent encore `enable_analyzer = 0` continuent donc de fonctionner, avec l&#39;analyseur. Pour comparer le comportement ou les performances d&#39;une requête avec l&#39;ancienne analyse de requête, utilisez une version de ClickHouse antérieure à la v26.9.
