## create_token_default_ttl_seconds {#create_token_default_ttl_seconds}

<SettingsInfoBlock type="UInt64" default_value="1800" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1800"},{"label": "Nouveau paramètre attribuant une durée de vie à un token créé par `CREATE TOKEN` sans clause `VALID UNTIL` ou `VALID FOR` explicite. L'instruction étant nouvelle, il n'existe aucun comportement antérieur à restaurer et la valeur précédente est la valeur par défaut elle-même : une `compatibility` avec une version plus ancienne ne doit pas rendre les tokens non expirables."}]}]} />

Durée de vie, en secondes, attribuée à un token créé par [`CREATE TOKEN`](/fr/reference/statements/create/token) qui ne précise pas sa propre clause `VALID UNTIL` ou `VALID FOR`. La valeur par défaut est de 30 minutes : un token pour lequel aucune durée plus longue n&#39;est demandée a donc une courte durée de vie.

Valeurs possibles :

* Entier positif — le token expire ce nombre de secondes après sa création.
* 0 — un token sans clause explicite n&#39;expire jamais.

Il ne s&#39;agit que d&#39;une valeur par défaut. Une clause `VALID UNTIL` ou `VALID FOR` explicite dans la requête prévaut toujours, y compris `VALID UNTIL 'infinity'`, qui crée un token n&#39;expirant jamais, quelle que soit la valeur de ce paramètre.
