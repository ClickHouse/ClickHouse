## optimize_move_to_prewhere {#optimize_move_to_prewhere}

<SettingsInfoBlock type="Bool" default_value="1" />

Active ou désactive l’optimisation automatique de [PREWHERE](/fr/reference/statements/select/prewhere) dans les requêtes [SELECT](/fr/reference/statements/select/index).

S’applique uniquement aux tables [*MergeTree](/fr/reference/engines/table-engines/mergetree-family/index).

Valeurs possibles :

* 0 — L’optimisation automatique de `PREWHERE` est désactivée.
* 1 — L’optimisation automatique de `PREWHERE` est activée.

## optimize_move_to_prewhere_if_final {#optimize_move_to_prewhere_if_final}

<SettingsInfoBlock type="Bool" default_value="1" />

Active ou désactive l’optimisation automatique de [PREWHERE](/fr/reference/statements/select/prewhere) dans les requêtes [SELECT](/fr/reference/statements/select/index) utilisant le modificateur [FINAL](/fr/reference/statements/select/from#final-modifier).

Seules les conditions qui dépendent exclusivement de la clé de tri et qui sont déterministes au sein de la requête sont déplacées ;
le résultat de `FINAL` n’est donc pas affecté.

Fonctionne uniquement pour les tables [*MergeTree](/fr/reference/engines/table-engines/mergetree-family/index).

Valeurs possibles :

* 0 — L’optimisation automatique de `PREWHERE` dans les requêtes `SELECT` utilisant le modificateur `FINAL` est désactivée.
* 1 — L’optimisation automatique de `PREWHERE` dans les requêtes `SELECT` utilisant le modificateur `FINAL` est activée.
