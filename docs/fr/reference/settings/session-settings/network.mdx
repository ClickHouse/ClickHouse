## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "La compression method par défaut des communications client\/serveur et serveur\/serveur est passée de `LZ4` à `ZSTD` afin de réduire le network traffic."}]}]} />

Le codec utilisé pour la compression des communications client/serveur et serveur/serveur via le native protocol.

Ce paramètre ne s&#39;applique pas au canal d&#39;échange en streaming des distributed queries, qui utilise toujours le default codec du serveur : chaque frame compressée est self-describing, de sorte que le receiver détecte automatiquement le codec.

Valeurs possibles :

* `NONE` — aucune compression.
* `LZ4` — utilise le codec LZ4.
* `LZ4HC` — utilise le codec LZ4HC.
* `ZSTD` — utilise le codec ZSTD.

## network_zstd_compression_level {#network_zstd_compression_level}
