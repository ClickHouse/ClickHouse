## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

N&#39;a d&#39;effet que dans ClickHouse Cloud. Taille maximale du tampon écrit vers les Distributed Cache servers, par write buffer. Elle est indépendante du tampon écrit vers l&#39;object storage : ce dernier continue de croître jusqu&#39;à atteindre la taille de partie de données de téléversement. Si la valeur est 0, `DBMS_DEFAULT_BUFFER_SIZE` (1 Mio) est utilisée. Le tampon démarre à `adaptive_write_buffer_initial_size` et ne croît jusqu&#39;à cette taille qu&#39;au fur et à mesure de l&#39;écriture du stream, afin qu&#39;une partie de données ne l&#39;alloue pas pour chaque stream qu&#39;elle écrit.
