## iceberg_compaction_max_bytes_to_merge {#iceberg_compaction_max_bytes_to_merge}

<SettingsInfoBlock type="UInt64" default_value="161061273600" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "161061273600"},{"label": "Nouveau paramètre. Limite la taille totale des fichiers d’une fusion de compactage, à l’instar de `max_bytes_to_merge_at_max_space_in_pool` pour `MergeTree`."}]}]} />

Taille totale maximale des fichiers de données fusionnés lors d’une même fusion de compactage d’une table Iceberg, c’est-à-dire la somme de leurs tailles dans le stockage d’objet.
Fonctionne comme `max_bytes_to_merge_at_max_space_in_pool` pour `MergeTree` : lorsque le pool de threads en arrière-plan dispose de moins d’emplacements libres que
`number_of_free_entries_in_pool_to_lower_max_size_of_merge`, la limite est abaissée à `max_bytes_to_merge_at_min_space_in_pool`
(ces deux paramètres figurent dans la section `merge_tree` de la configuration).
Les fichiers d’une partition qui dépassent cette limite sont fusionnés lors des fusions suivantes. Ne s’applique pas à une fusion qui applique des fichiers de suppression par position.
