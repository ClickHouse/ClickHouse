Nombre maximal d&#39;octets d&#39;un fichier de données Parquet Iceberg lors d&#39;une opération d&#39;insertion.

La valeur par défaut reprend la valeur par défaut documentée de la propriété de table Iceberg `write.target-file-size-bytes` (512 Mio),
voir https://iceberg.apache.org/docs/1.5.2/configuration/. Notez que ClickHouse compare cette limite à la
taille non compressée des données déjà écrites dans le fichier, alors que la propriété Iceberg cible la taille du
fichier résultant, et que `iceberg_insert_max_rows_in_data_file` limite le fichier indépendamment de sa taille.
