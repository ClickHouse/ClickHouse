## delta_lake_accurate_write_cast {#delta_lake_accurate_write_cast}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Nouveau paramètre : convertit les valeurs écrites vers le type du schéma d'écriture Delta à l'aide d'un CAST précis qui lève une exception lorsqu'une valeur n'entre pas dans le target type, au lieu de la tronquer silencieusement ; un paramètre `compatibility` inférieur à 26.9 utilise le CAST simple, sans exception."}]}]} />

Lors de l&#39;écriture dans une table DeltaLake, convertit chaque valeur vers le type du schéma d&#39;écriture Delta à l&#39;aide d&#39;un CAST précis qui lève une exception lorsqu&#39;une valeur n&#39;entre pas dans le target type, plutôt qu&#39;avec un CAST simple qui la tronque silencieusement (par exemple `300` écrit dans une COLUMN Delta de type `byte`). Définissez ce paramètre à `false`, ou utilisez un paramètre `compatibility` inférieur à 26.9, pour obtenir le CAST simple, sans exception.
