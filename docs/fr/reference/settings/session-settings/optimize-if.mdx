## optimize_if_chain_to_multiif {#optimize_if_chain_to_multiif}

<SettingsInfoBlock type="Bool" default_value="0" />

Remplace les chaînes if(cond1, then1, if(cond2, ...)) par multiIf. Actuellement, ce n’est pas avantageux pour les types numériques.

## optimize_if_transform_const_strings_to_lowcardinality {#optimize_if_transform_const_strings_to_lowcardinality}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nouveau paramètre permettant d'optimiser les résultats des branches constantes de `if`\/`multiIf`\/`transform` en `LowCardinality`. Désactivé par défaut."}]}]} />

Lorsque ce paramètre est activé, les fonctions `if`, `multiIf` et `transform` dont les branches de résultat (et les valeurs par défaut) sont des chaînes constantes renvoient `LowCardinality(String)` au lieu de `String`.
Il est désactivé par défaut, car construire un dictionnaire `LowCardinality` pour chaque bloc peut s&#39;avérer plus lent qu&#39;un simple résultat `String` lorsque le dictionnaire n&#39;est pas réutilisé en aval.
L&#39;optimisation ne s&#39;applique pas lorsque l&#39;expression entière est constante (condition ou entrée également constante) : une constante ne tire aucun avantage de `LowCardinality`, et les fonctions qui attendent des arguments `String` constants (p. ex. `arrayReduce`, `joinGet`, `tupleElement`) continuent de fonctionner.

Toutes les branches de résultat doivent être des constantes ; ainsi, une chaîne de `if` imbriqués telle que `if(cond1, 'a', if(cond2, 'b', 'c'))` renvoie toujours un simple `String` : la branche else du `if` externe est un autre `if`, et non une constante. Écrivez plutôt `multiIf(cond1, 'a', cond2, 'b', 'c')` pour obtenir `LowCardinality(String)`.

Ce paramètre n&#39;a aucun effet tant que `optimize_if_transform_strings_to_enum` est activé : la réécriture en `Enum` a la préséance, et le résultat reste `String` (ou `Nullable(String)`), même avec la forme explicite `multiIf` ci-dessus.

## optimize_if_transform_strings_to_enum {#optimize_if_transform_strings_to_enum}

<SettingsInfoBlock type="Bool" default_value="0" />

Remplace les arguments de type String dans If et Transform par enum. Désactivé par défaut, car cela pourrait entraîner une modification incohérente dans une requête distribuée, ce qui la ferait échouer.
