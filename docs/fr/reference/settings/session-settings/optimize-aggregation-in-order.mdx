## optimize_aggregation_in_order {#optimize_aggregation_in_order}

<SettingsInfoBlock type="Bool" default_value="0" />

Active l’optimisation de [GROUP BY](/fr/reference/statements/select/group-by) dans les requêtes [SELECT](/fr/reference/statements/select/index) afin d’agréger les données selon l’ordre correspondant dans les tables [MergeTree](/fr/reference/engines/table-engines/mergetree-family/mergetree).

Elle s’applique également à un unique `uniqExact` (ou `count(DISTINCT)`) sans `GROUP BY` sur une table triée selon son argument : les valeurs distinctes sont comptées au fil de leur arrivée, dans l’ordre, et ne sont donc pas conservées en mémoire. Avec plusieurs fils d’exécution, la lecture est divisée en plages de la clé de tri, comptées en parallèle ; lorsque cette division est impossible (par exemple, pour un argument à virgule flottante ou une fonction de la clé de tri), l’agrégation habituelle est utilisée.

Les projections sont choisies avant l’ordre d’agrégation. Si une [projection](/fr/reference/engines/table-engines/mergetree-family/mergetree#projections) lit moins de granules que la table, elle est utilisée même si elle n’est pas triée selon la clé `GROUP BY`, et l’agrégation conserve alors tous les groupes en mémoire au lieu d’agréger dans l’ordre.

Valeurs possibles :

* 0 — l’optimisation de `GROUP BY` est désactivée.
* 1 — l’optimisation de `GROUP BY` est activée.

## optimize_aggregation_in_order_limit {#optimize_aggregation_in_order_limit}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.7"},{"label": "1"},{"label": "Nouveau paramètre qui applique `LIMIT` à l’agrégation dans l’ordre afin de permettre un arrêt anticipé lorsque `ORDER BY` est un préfixe de la description de tri de `GROUP BY`."}]}]} />

Lorsqu’il est activé et que l’agrégation dans l’ordre est active, ce paramètre applique LIMIT à l’étape d’agrégation afin de permettre un arrêt anticipé une fois qu’un nombre suffisant de groupes a été produit. Cela réduit la quantité de données lues lorsque ORDER BY correspond à un préfixe de la clé GROUP BY. Peut réduire la valeur renvoyée par `rows_before_limit_at_least` ; utilisez `exact_rows_before_limit` si des décomptes exacts sont nécessaires.
