## optimize_min_max_from_files {#optimize_min_max_from_files}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Nouveau paramètre permettant de calculer `min` \/ `max` à partir des statistiques des fragments de colonne Parquet."}]}]} />

Active ou désactive le calcul de `min` et `max` des colonnes à partir des statistiques stockées dans les fichiers de données, plutôt qu’en lisant les données, pour les requêtes dont les seules fonctions d’agrégation sont `min` et `max` appliquées à des colonnes de la table, sans `GROUP BY` ni filtres. Ce paramètre s’applique à la fonction de table et au moteur `file` avec le format `Parquet` (mais pas aux fichiers contenus dans des archives), pour les colonnes de type entier (jusqu’à 64 bits), date, date-heure et décimal dont les statistiques de fragments de colonne sont présentes dans chaque groupe de lignes.

Valeurs possibles :

* 0 - Optimisation désactivée.
* 1 - Optimisation activée.
