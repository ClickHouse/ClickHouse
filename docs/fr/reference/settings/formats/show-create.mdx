## show_create_query_identifier_quoting_rule {#show_create_query_identifier_quoting_rule}

<SettingsInfoBlock type="IdentifierQuotingRule" default_value="when_necessary" />

Détermine quand les identifiants sont mis entre guillemets dans la sortie de `SHOW CREATE`. `when_necessary` (valeur par défaut) met les identifiants entre guillemets lorsque c&#39;est nécessaire pour produire un SQL valide et sans ambiguïté ; `user_display` met entre guillemets les identifiants qui sont des mots-clés SQL ; `always` met systématiquement tous les identifiants entre guillemets. Ce paramètre détermine si la mise entre guillemets est appliquée, tandis que `show_create_query_identifier_quoting_style` détermine les caractères de guillemets utilisés et l&#39;échappement.

## show_create_query_identifier_quoting_style {#show_create_query_identifier_quoting_style}

<SettingsInfoBlock type="IdentifierQuotingStyle" default_value="Backticks" />

Contrôle la manière dont les identifiants entre guillemets sont écrits dans la sortie de `SHOW CREATE`. `Backticks` (par défaut) utilise des accents graves de style ClickHouse, `DoubleQuotes` utilise des guillemets doubles avec l&#39;échappement ClickHouse, et `BackticksMySQL` utilise des accents graves compatibles avec MySQL, où les accents graves contenus dans l&#39;identifiant sont doublés. Ce paramètre ne détermine pas quels identifiants sont mis entre guillemets ; pour cela, utilisez `show_create_query_identifier_quoting_rule`.
