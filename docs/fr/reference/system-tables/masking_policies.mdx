<div id="description">
  ## Description
</div>

Contient des informations sur toutes les politiques de masquage définies dans le système.

Les politiques de masquage ne peuvent être créées et appliquées que dans ClickHouse Cloud. Dans les versions open-source, la table `system.masking_policies` est toujours vide, mais elle reste présente pour que les requêtes d&#39;introspection telles que `SHOW MASKING POLICIES` fonctionnent et renvoient un résultat vide au lieu de lever une exception.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Nom d’une politique de masquage.
* `short_name` ([String](/fr/reference/data-types/string)) — Nom court d’une politique de masquage. Les noms des politiques de masquage sont composés, par exemple : mask&#95;email ON mydb.mytable. Ici, &#39;mask&#95;email ON mydb.mytable&#39; est le nom de la politique de masquage et &#39;mask&#95;email&#39; est son nom court.
* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `id` ([UUID](/fr/reference/data-types/uuid)) — ID de la politique de masquage.
* `storage` ([String](/fr/reference/data-types/string)) — Nom du répertoire où la politique de masquage est stockée.
* `update_assignments` ([Nullable(String)](/fr/reference/data-types/nullable)) — Affectations dans UPDATE qui définissent comment les données doivent être masquées, par exemple : email = &#39;***masked***&#39;, phone = &#39;***-***-****&#39;. NULL si non défini.
* `where_condition` ([Nullable(String)](/fr/reference/data-types/nullable)) — Condition facultative qui sélectionne les lignes auxquelles le masquage est appliqué. NULL si non défini.
* `priority` ([Int64](/fr/reference/data-types/int-uint)) — Priorité de la politique de masquage. Les politiques ayant la priorité la plus élevée sont appliquées en premier.
* `apply_to_all` ([UInt8](/fr/reference/data-types/int-uint)) — Indique que la politique de masquage est définie pour tous les rôles et/ou utilisateurs.
* `apply_to_list` ([Array(String)](/fr/reference/data-types/array)) — Liste des rôles et/ou utilisateurs auxquels la politique de masquage s’applique.
* `apply_to_except` ([Array(String)](/fr/reference/data-types/array)) — La politique de masquage s’applique à tous les rôles et/ou utilisateurs, sauf à ceux figurant dans la liste.
