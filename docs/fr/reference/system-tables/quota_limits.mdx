<div id="description">
  ## Description
</div>

Contient des informations sur les valeurs maximales pour tous les intervalles de tous les quotas. Un quota peut correspondre à un nombre quelconque de lignes, voire à aucune.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/fr/reference/data-types/string)) — Nom du quota.
* `duration` ([UInt32](/fr/reference/data-types/int-uint)) — Durée de l&#39;intervalle de temps utilisé pour calculer la consommation de ressources, en secondes.
* `is_randomized_interval` ([UInt8](/fr/reference/data-types/int-uint)) — Valeur booléenne. Indique si l&#39;intervalle est aléatoire. Si ce n&#39;est pas le cas, l&#39;intervalle commence toujours au même moment. Par exemple, un intervalle d&#39;une minute commence toujours à une minute entière (c&#39;est-à-dire qu&#39;il peut commencer à 11:20:00, mais jamais à 11:20:01) et un intervalle d&#39;un jour commence toujours à minuit UTC. Si l&#39;intervalle est aléatoire, le tout premier intervalle commence à un moment aléatoire, puis les intervalles suivants se succèdent. Valeurs : 0 — l&#39;intervalle n&#39;est pas aléatoire ; 1 — l&#39;intervalle est aléatoire.
* `max_queries` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal de requêtes, tous types confondus, pouvant être exécutées.
* `max_query_selects` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal de requêtes SELECT pouvant être exécutées.
* `max_query_inserts` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal de requêtes INSERT pouvant être exécutées.
* `max_errors` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal de requêtes ayant généré une erreur autorisé au cours de la période spécifiée.
* `max_result_rows` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre total maximal de lignes dans l&#39;ensemble de résultats de toutes les requêtes autorisé au cours de la période spécifiée.
* `max_result_bytes` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre total maximal d&#39;octets dans l&#39;ensemble de résultats de toutes les requêtes autorisé au cours de la période spécifiée.
* `max_read_rows` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal de lignes pouvant être lues lors de l&#39;exécution de toutes les requêtes au cours de la période spécifiée.
* `max_read_bytes` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal d&#39;octets pouvant être lus lors de l&#39;exécution de toutes les requêtes au cours de la période spécifiée.
* `max_execution_time` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — La durée maximale (en nanosecondes) autorisée pour l&#39;exécution de toutes les requêtes au cours de la période spécifiée
* `max_written_bytes` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal d&#39;octets pouvant être écrits lors de l&#39;exécution de toutes les requêtes au cours de la période spécifiée.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal d&#39;échecs d&#39;authentification consécutifs autorisé au cours de la période spécifiée.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal d&#39;exécutions d&#39;une même requête normalisée autorisé au cours de la période spécifiée.
