## Description {#description}

<Warning>
  L&#39;intégration CatBoost a été supprimée de ClickHouse et `system.models` n&#39;existe plus : toute requête sur cette table échoue avec `UNKNOWN_TABLE`. Cette page est conservée pour la documentation qu&#39;elle publiait ; consultez l&#39;[aperçu des tables système](/fr/reference/system-tables/overview) pour connaître les tables existantes à ce jour.
</Warning>

Contenait la liste des modèles CatBoost chargés en mémoire par un `LibraryBridge`, ainsi que l&#39;heure de leur chargement.

## Colonnes {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/fr/reference/data-types/string)) — Chemin d’accès au modèle entraîné.
* `type` ([String](/fr/reference/data-types/string)) — Type de modèle. Actuellement, seul catboost est pris en charge.
* `loading_start_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure de début du chargement du modèle.
* `loading_duration` ([Float32](/fr/reference/data-types/float)) — Temps nécessaire au chargement du modèle.

{/*AUTOGENERATED_END*/}
