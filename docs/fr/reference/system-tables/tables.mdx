<div id="description">
  ## Description
</div>

Contient les métadonnées de chaque table connue du serveur.

Les tables [Detached](/fr/reference/statements/detach) ne sont pas affichées dans `system.tables`.

Les [tables temporaires](/fr/reference/statements/create/table/temporary-table) ne sont visibles dans `system.tables` que dans la session où elles ont été créées. Elles sont affichées avec le champ `database` vide et l’indicateur `is_temporary` activé.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données à laquelle appartient la table.
* `name` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/reference/data-types/uuid)) — UUID de la table (base de données Atomic).
* `engine` ([String](/fr/reference/data-types/string)) — Nom du moteur de table (sans paramètres).
* `is_temporary` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si la table est temporaire.
* `data_paths` ([Array(String)](/fr/reference/data-types/array)) — Chemins d&#39;accès aux données de la table dans les systèmes de fichiers.
* `metadata_path` ([String](/fr/reference/data-types/string)) — Chemin d&#39;accès aux métadonnées de la table dans le système de fichiers.
* `metadata_modification_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure de la dernière modification des métadonnées de la table.
* `metadata_version` ([Int32](/fr/reference/data-types/int-uint)) — Version des métadonnées pour une table ReplicatedMergeTree, 0 pour les autres tables.
* `dependencies_database` ([Array(String)](/fr/reference/data-types/array)) — Dépendances de la base de données.
* `dependencies_table` ([Array(String)](/fr/reference/data-types/array)) — Dépendances de la table (vues matérialisées de la table actuelle).
* `create_table_query` ([String](/fr/reference/data-types/string)) — Requête utilisée pour créer la table.
* `engine_full` ([String](/fr/reference/data-types/string)) — Paramètres du moteur de table.
* `as_select` ([String](/fr/reference/data-types/string)) — Requête SELECT de la vue.
* `parameterized_view_parameters` ([Array(Tuple(name String, type String))](/fr/reference/data-types/array)) — Paramètres de la vue paramétrée.
* `partition_key` ([String](/fr/reference/data-types/string)) — Expression de clé de partition spécifiée dans la table.
* `sorting_key` ([String](/fr/reference/data-types/string)) — Expression de clé de tri spécifiée dans la table.
* `primary_key` ([String](/fr/reference/data-types/string)) — Expression de clé primaire spécifiée dans la table.
* `sampling_key` ([String](/fr/reference/data-types/string)) — Expression de clé d&#39;échantillonnage spécifiée dans la table.
* `unique_key` ([String](/fr/reference/data-types/string)) — Expression de clé unique spécifiée dans la table (clause UNIQUE KEY).
* `skipping_indices_types` ([Array(String)](/fr/reference/data-types/array)) — Tableau des types distincts d&#39;indices de saut de données définis sur la table (par exemple, minmax, set, bloom&#95;filter, ngrambf&#95;v1, tokenbf&#95;v1, text, vector&#95;similarity). Vide pour les tables sans indices de saut.
* `storage_policy` ([String](/fr/reference/data-types/string)) — Politique de stockage. S&#39;applique aux tables utilisant les moteurs MergeTree et Distributed.
* `total_rows` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de lignes, s&#39;il est possible de déterminer rapidement le nombre exact de lignes de la table, sinon NULL (y compris pour la table Buffer sous-jacente).
* `total_bytes` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total d&#39;octets, s&#39;il est possible de déterminer rapidement le nombre exact d&#39;octets occupés par la table dans le stockage, sinon NULL (hors stockage sous-jacent). Si la table stocke des données sur disque, renvoie l&#39;espace disque utilisé (c&#39;est-à-dire compressé). Si la table stocke des données en mémoire, renvoie une estimation du nombre d&#39;octets utilisés en mémoire.
* `total_bytes_uncompressed` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total d&#39;octets non compressés, s&#39;il est possible de déterminer rapidement le nombre exact d&#39;octets à partir des sommes de contrôle des parties de la table dans le stockage, sinon NULL (sans tenir compte du stockage sous-jacent, le cas échéant).
* `parts` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de parties de cette table.
* `active_parts` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre de parties actives de cette table.
* `total_marks` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de marques dans toutes les parties de cette table.
* `active_on_fly_data_mutations` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre total de mutations de données actives (UPDATE et DELETE) pouvant être appliquées à la volée.
* `active_on_fly_alter_mutations` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre total de mutations ALTER actives (MODIFY COLUMN) pouvant être appliquées à la volée.
* `active_on_fly_metadata_mutations` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre total de mutations de métadonnées actives (RENAME) pouvant être appliquées à la volée.
* `columns_descriptions_cache_size` ([UInt64](/fr/reference/data-types/int-uint)) — Taille du cache des descriptions de colonnes pour les tables *MergeTree
* `lifetime_rows` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de lignes INSERTées depuis le démarrage du serveur (uniquement pour les tables Buffer).
* `lifetime_bytes` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total d’octets INSERTés depuis le démarrage du serveur (uniquement pour les tables Buffer).
* `comment` ([String](/fr/reference/data-types/string)) — Commentaire de la table.
* `has_own_data` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si la table stocke elle-même des données sur disque ou accède uniquement à une autre source.
* `loading_dependencies_database` ([Array(String)](/fr/reference/data-types/array)) — Dépendances de chargement de la base de données (liste des objets devant être chargés avant l’objet actuel).
* `loading_dependencies_table` ([Array(String)](/fr/reference/data-types/array)) — Dépendances de chargement de la table (liste des objets devant être chargés avant l’objet actuel).
* `loading_dependent_database` ([Array(String)](/fr/reference/data-types/array)) — Base de données dépendante lors du chargement.
* `loading_dependent_table` ([Array(String)](/fr/reference/data-types/array)) — Table dépendante lors du chargement.
* `target_database` ([String](/fr/reference/data-types/string)) — Pour une vue matérialisée, base de données de la table de destination dans laquelle la vue écrit (cible `TO` ou table implicite `.inner.*`). Vide pour les autres moteurs.
* `target_table` ([String](/fr/reference/data-types/string)) — Pour une vue matérialisée, nom de la table de destination dans laquelle la vue écrit (cible `TO` ou table implicite `.inner.*`). Vide pour les autres moteurs.
* `definer` ([String](/fr/reference/data-types/string)) — Nom du définisseur SQL SECURITY utilisé pour la table.

**Alias :**

* `table` — Alias de `name`.
