## Description {#description}

Contient la liste de tous les failpoints disponibles enregistrés sur le serveur, ainsi que leur type et leur état d’activation actuel.

Dans les builds prenant en charge les failpoints (`USE_LIBFIU=1`), les failpoints peuvent être activés et désactivés au moment de l’exécution à l’aide des instructions `SYSTEM ENABLE FAILPOINT` et `SYSTEM DISABLE FAILPOINT`. Ces instructions ne sont pas disponibles dans les builds dépourvus de prise en charge des failpoints, bien que la table reste disponible.

`SYSTEM DISABLE ALL FAILPOINTS` désactive tous les failpoints en une seule fois et débloque tout thread en attente sur un failpoint de type pause, ce qui permet de ramener un serveur à un état propre sans avoir à connaître ceux qui sont actuellement activés.

## Colonnes {#columns}

* `name` ([String](/fr/reference/data-types/string)) — Nom du failpoint.
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/fr/reference/data-types/enum)) — Type de failpoint : &#39;once&#39; se déclenche une seule fois puis se désactive automatiquement, &#39;regular&#39; se déclenche à chaque fois, &#39;pauseable&#95;once&#39; bloque l’exécution une seule fois, &#39;pauseable&#39; bloque l’exécution à chaque fois jusqu’à ce qu’elle reprenne.
* `enabled` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le failpoint est actuellement activé (1) ou désactivé (0).

## Exemple {#example}

Cet exemple nécessite un build prenant en charge les failpoints (`USE_LIBFIU=1`).

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```

```text title="Response"
┌─name──────────────────────────────────────┬─type────────────┬─enabled─┐
│ replicated_merge_tree_insert_retry_pause  │ pauseable_once  │       1 │
└───────────────────────────────────────────┴─────────────────┴─────────┘
```
