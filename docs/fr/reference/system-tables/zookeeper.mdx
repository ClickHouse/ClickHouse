## Description {#description}

La table n&#39;existe que si ClickHouse Keeper ou ZooKeeper est configuré. La table `system.zookeeper` expose les données des clusters Keeper définis dans la config.
La requête doit comporter soit une condition `path =`, soit une condition `path IN` dans la clause `WHERE`, comme indiqué ci-dessous. Cela correspond au path des nœuds enfants dont vous souhaitez récupérer les données.

La requête `SELECT * FROM system.zookeeper WHERE path = '/clickhouse'` renvoie les données de tous les nœuds enfants du nœud `/clickhouse`.
Pour renvoyer les données de tous les nœuds racine, utilisez path = &#39;/&#39;.
Si le path spécifié dans `path` n&#39;existe pas, une exception sera levée.

La requête `SELECT * FROM system.zookeeper WHERE path IN ('/', '/clickhouse')` renvoie les données de tous les nœuds enfants des nœuds `/` et `/clickhouse`.
Si l&#39;un des paths de la collection `path` spécifiée n&#39;existe pas, une exception sera levée.
Cela peut être utilisé pour effectuer un lot de requêtes sur des Keeper path.

La requête `SELECT * FROM system.zookeeper WHERE path = '/clickhouse' AND zookeeperName = 'auxiliary_cluster'` renvoie les données du cluster ZooKeeper `auxiliary_cluster`.
Si le cluster `auxiliary_cluster` spécifié n&#39;existe pas, une exception sera levée.

## Colonnes {#columns}

* `name` ([String](/fr/reference/data-types/string)) — Le nom du nœud.
* `value` ([String](/fr/reference/data-types/string)) — Valeur du nœud.
* `zookeeperName` ([String](/fr/reference/data-types/string)) — Le nom du cluster ZooKeeper par défaut ou de l&#39;un des auxiliary cluster ZooKeeper.
* `czxid` ([Int64](/fr/reference/data-types/int-uint)) — ID de la transaction ayant créé le nœud.
* `mzxid` ([Int64](/fr/reference/data-types/int-uint)) — ID de la dernière transaction ayant modifié le nœud.
* `ctime` ([DateTime](/fr/reference/data-types/datetime)) — Heure de création du nœud.
* `mtime` ([DateTime](/fr/reference/data-types/datetime)) — Heure de la dernière modification du nœud.
* `version` ([Int32](/fr/reference/data-types/int-uint)) — Version du nœud : le nombre de fois où le nœud a été modifié.
* `cversion` ([Int32](/fr/reference/data-types/int-uint)) — Nombre de descendants ajoutés ou supprimés.
* `aversion` ([Int32](/fr/reference/data-types/int-uint)) — Nombre de modifications apportées à l&#39;ACL.
* `ephemeralOwner` ([Int64](/fr/reference/data-types/int-uint)) — Pour les nœuds ephemeral, l&#39;ID de la session propriétaire de ce nœud.
* `dataLength` ([Int32](/fr/reference/data-types/int-uint)) — Taille de la valeur.
* `numChildren` ([Int32](/fr/reference/data-types/int-uint)) — Nombre de descendants.
* `pzxid` ([Int64](/fr/reference/data-types/int-uint)) — ID de la dernière transaction ayant supprimé ou ajouté des descendants.
* `path` ([String](/fr/reference/data-types/string)) — Le path d&#39;accès au nœud.
