<div id="description">
  ## Description
</div>

Contient la liste des layouts de dictionnaire pris en charge par le serveur, ainsi que la documentation intégrée pour chacun d&#39;eux. Le layout de dictionnaire détermine comment celui-ci est stocké en mémoire (ou sur disque) et consulté ; il est spécifié dans la clause `LAYOUT` d&#39;une requête `CREATE DICTIONARY`.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Le nom du layout de dictionnaire, tel que spécifié dans la clause LAYOUT.
* `is_complex` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le layout requiert une clé complexe (une clé composée de plusieurs attributs ou de type non entier).
* `description` ([String](/fr/reference/data-types/string)) — Une description du fonctionnement du layout de dictionnaire. Pour les layouts disposant d’une page de documentation dédiée, ce champ contient le corps Markdown complet de cette page ; pour les autres layouts, il contient un résumé concis.
* `syntax` ([String](/fr/reference/data-types/string)) — La manière dont le layout est spécifié dans la clause LAYOUT d’une requête CREATE DICTIONARY.
* `examples` ([String](/fr/reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/reference/data-types/string)) — La version de ClickHouse dans laquelle le layout a été introduit, au format majeure.mineure.
* `related` ([Array(String)](/fr/reference/data-types/array)) — Les noms des layouts de dictionnaire associés.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemple
</div>

```sql title="Query"
SELECT name, is_complex, syntax
FROM system.dictionary_layouts
WHERE name IN ('flat', 'hashed', 'complex_key_hashed')
ORDER BY name
```

```text title="Response"
┌─name───────────────┬─is_complex─┬─syntax───────────────────────────────────────────────────┐
│ complex_key_hashed │          1 │ LAYOUT(COMPLEX_KEY_HASHED())                             │
│ flat               │          0 │ LAYOUT(FLAT([INITIAL_ARRAY_SIZE n] [MAX_ARRAY_SIZE n]))  │
│ hashed             │          0 │ LAYOUT(HASHED())                                         │
└────────────────────┴────────────┴──────────────────────────────────────────────────────────┘
```
