## Description {#description}

Une ligne par allocation active échantillonnée par le profiler de tas jemalloc ; la lecture de la table déclenche le flush d&#39;un nouveau profil du tas. Seuls les threads dont le profiler est armé y contribuent (paramètre `jemalloc_enable_profiler` ou config `jemalloc_enable_global_profiler`) ; chaque ligne représente environ `weight` allocations similaires.

## Colonnes {#columns}

{/*AUTOGENERATED_START*/}

* `trace` ([Array(UInt64)](/fr/reference/data-types/array)) — Adresses de la pile d&#39;appels ayant effectué l&#39;allocation, la frame feuille en premier (même convention que `system.trace_log.trace`). À symboliser avec `addressToSymbol` et `demangle` (nécessite `allow_introspection_functions`).
* `age_ns` ([UInt64](/fr/reference/data-types/int-uint)) — Durée en nanosecondes pendant laquelle l&#39;allocation est restée active, par rapport au moment où le profile a été flushé.
* `size` ([UInt64](/fr/reference/data-types/int-uint)) — Taille d&#39;allocation demandée, en octets.
* `usize` ([UInt64](/fr/reference/data-types/int-uint)) — Taille utilisable en octets, c&#39;est-à-dire la size class à laquelle la demande a été arrondie.
* `size_class` ([UInt16](/fr/reference/data-types/int-uint)) — Index de la size class. Se joint à `system.jemalloc_bins.index` pour les petites size classes.
* `arena` ([UInt32](/fr/reference/data-types/int-uint)) — Index de l&#39;arena depuis laquelle l&#39;allocation a été servie.
* `thr_uid` ([UInt64](/fr/reference/data-types/int-uint)) — Identifiant unique interne à jemalloc du thread ayant effectué l&#39;allocation.
* `sample_interval` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre moyen d&#39;octets alloués entre deux samples, issu du header du profile. Identique pour toutes les rows.

**Aliases :**

* `alloc_time` — alias de `now() - intDiv(age_ns, 1000000000)`.
* `weight` — alias de `1 / (1 - exp((-usize) / sample_interval))`.
