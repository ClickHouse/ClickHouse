## Description {#description}

Identique à `system.jemalloc_bins`, mais avec une ligne par couple (arena, bin) au lieu d&#39;une agrégation sur l&#39;ensemble des arenas. Les slabs appartiennent à une seule arena : cette table permet donc de localiser la fragmentation dans une arena précise (y compris les arenas dédiées aux métadonnées MergeTree, au JIT et au cache) et de se joindre à `system.jemalloc_sampled_allocations` à la fois sur `arena` et sur la size class.

## Colonnes {#columns}

{/*AUTOGENERATED_START*/}

* `arena` ([UInt32](/fr/reference/data-types/int-uint)) — Index de l&#39;arena. Se joint à `system.jemalloc_sampled_allocations.arena`.
* `purpose` ([String](/fr/reference/data-types/string)) — Rôle d&#39;une arena dédiée à longue durée de vie : &#39;mergetree&#39; (métadonnées des parts et des tables), &#39;jit&#39;, &#39;cache&#39;. Vide pour les arenas à usage général. Les arenas dédiées contiennent, par conception, des allocations à longue durée de vie ; les rapports de fragmentation les excluent généralement.
* `index` ([UInt16](/fr/reference/data-types/int-uint)) — Index du bin, ordonné par taille.
* `large` ([UInt8](/fr/reference/data-types/int-uint)) — True pour les grandes allocations et False pour les petites.
* `size` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des allocations dans ce bin.
* `allocations` ([Int64](/fr/reference/data-types/int-uint)) — Nombre d&#39;allocations.
* `deallocations` ([Int64](/fr/reference/data-types/int-uint)) — Nombre de désallocations.
* `nregs` ([Int64](/fr/reference/data-types/int-uint)) — Nombre de régions par slab.
* `curslabs` ([Int64](/fr/reference/data-types/int-uint)) — Nombre actuel de slabs.
* `curregs` ([Int64](/fr/reference/data-types/int-uint)) — Nombre actuel de régions pour cette size class.
* `slab_size` ([UInt64](/fr/reference/data-types/int-uint)) — Taille de chaque slab en octets. Zéro pour les grandes size classes, qui ne reposent pas sur des slabs.
* `nonfull_slabs` ([Int64](/fr/reference/data-types/int-uint)) — Nombre actuel de slabs contenant au moins une région libre. Zéro pour les grandes size classes.

**Alias :**

* `availregs` — alias de `nregs * curslabs`.
* `util` — alias de `curregs / availregs`.
* `waste` — alias de `greatest((curslabs * slab_size) - (curregs * size), 0)`.
