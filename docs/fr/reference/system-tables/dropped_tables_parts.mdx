<div id="description">
  ## Description
</div>

Contient des informations sur les parts des tables [MergeTree](/fr/reference/engines/table-engines/mergetree-family/mergetree) supprimées dans [system.dropped&#95;tables](/fr/reference/system-tables/dropped_tables)

Le schéma de cette table est le même que celui de [system.parts](/fr/reference/system-tables/parts)

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/fr/reference/data-types/string)) — Identifiant de partition (représentation sous forme de chaîne dérivée de l’expression de clé de partition de la table).
* `name` ([String](/fr/reference/data-types/string)) — Nom de la partie de données. La structure du nom de la partie permet de déterminer de nombreux aspects des modèles de données, d’ingestion et de fusion. Le format du nom de la partie est le suivant :

  ```text
  <partition_id>_<minimum_block_number>_<maximum_block_number>_<level>_<data_version>
  ```

  * Définitions :
    * `partition_id` - identifie la clé de partition
    * `minimum_block_number` - identifie le numéro de block minimal de la part. ClickHouse fusionne toujours les blocks continus
    * `maximum_block_number` - identifie le numéro de block maximal de la part
    * `level` - incrémenté de un à chaque fusion supplémentaire de la part. Un niveau de 0 indique qu&#39;il s&#39;agit d&#39;une nouvelle part qui n&#39;a pas encore été fusionnée. Il est important de rappeler que les parts de ClickHouse sont toujours immuables
    * `data_version` - valeur facultative, incrémentée lorsqu&#39;une part est mutée (là encore, les données mutées ne sont écrites que dans une nouvelle part, car les parts sont immuables)
* `uuid` ([UUID](/fr/reference/data-types/uuid)) — L&#39;UUID de la partie de données.
* `part_type` ([String](/fr/reference/data-types/string)) — Le format de stockage de la partie de données. Valeurs possibles : `Wide` — chaque colonne est stockée dans un fichier distinct, `Compact` — toutes les colonnes sont stockées dans un seul fichier. Le format de stockage des données est contrôlé par les paramètres `min_bytes_for_wide_part` et `min_rows_for_wide_part` de la table MergeTree.
* `part_storage_type` ([String](/fr/reference/data-types/string)) — Le type de `DataPartStorage`. Valeurs possibles : `Packed` — la plupart des fichiers de la partie sont stockés dans une seule archive (les projections et quelques fichiers de service, tels que `txn_version.txt`, sont écrits séparément), `Full` — chaque fichier est stocké séparément.
* `active` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur indiquant si la partie de données est active. Si une partie de données est active, elle est utilisée dans une table. Sinon, elle est sur le point d&#39;être supprimée. Des parties de données inactives apparaissent après des opérations de fusion et de mutation.
* `marks` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de marques. Pour obtenir le nombre approximatif de lignes d&#39;une partie de données, multipliez le nombre de marques par la granularité d&#39;index (généralement 8192) (cette indication ne s&#39;applique pas à la granularité adaptative).
* `rows` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de lignes.
* `files` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de fichiers de la partie de données.
* `bytes_on_disk` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale de tous les fichiers de la partie de données, en octets.
* `data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données compressées dans la partie de données. Les fichiers auxiliaires (par exemple, les fichiers contenant des marques) ne sont pas inclus.
* `data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données non compressées dans la partie de données. Les fichiers auxiliaires (par exemple, les fichiers contenant des marques) ne sont pas inclus.
* `primary_key_size` ([UInt64](/fr/reference/data-types/int-uint)) — La quantité de mémoire (en octets) utilisée par les valeurs de clé primaire dans le fichier primary.idx/cidx sur le disque.
* `marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille du fichier contenant les marques.
* `secondary_indices_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données compressées des index secondaires dans la partie de données. Les fichiers auxiliaires (par exemple, les fichiers contenant des marques) ne sont pas inclus.
* `secondary_indices_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données non compressées des index secondaires dans la partie de données. Les fichiers auxiliaires (par exemple, les fichiers contenant des marques) ne sont pas inclus.
* `secondary_indices_marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille du fichier contenant les marques des index secondaires.
* `modification_time` ([DateTime](/fr/reference/data-types/datetime)) — L&#39;heure à laquelle le répertoire contenant la partie de données a été modifié. Cela correspond généralement à l&#39;heure de création de la partie de données.
* `remove_time` ([DateTime](/fr/reference/data-types/datetime)) — L&#39;heure à laquelle la partie de données est devenue inactive.
* `refcount` ([UInt32](/fr/reference/data-types/int-uint)) — Le nombre de références à la partie de données. Une valeur supérieure à 2 indique que la partie de données est utilisée dans des requêtes ou des fusions.
* `min_date` ([Date](/fr/reference/data-types/date)) — La valeur minimale de la clé de date dans la partie de données.
* `max_date` ([Date](/fr/reference/data-types/date)) — La valeur maximale de la clé de date dans la partie de données.
* `min_time` ([DateTime](/fr/reference/data-types/datetime)) — La valeur minimale de la clé de date et d&#39;heure dans la partie de données.
* `max_time` ([DateTime](/fr/reference/data-types/datetime)) — La valeur maximale de la clé de date et d&#39;heure dans la partie de données.
* `partition_id` ([String](/fr/reference/data-types/string)) — L&#39;ID de la partition.
* `min_block_number` ([Int64](/fr/reference/data-types/int-uint)) — Le numéro de bloc minimal des parties de données qui composent la partie actuelle après fusion.
* `max_block_number` ([Int64](/fr/reference/data-types/int-uint)) — Le numéro de bloc maximal des parties de données qui composent la partie actuelle après fusion.
* `level` ([UInt32](/fr/reference/data-types/int-uint)) — Profondeur de l’arbre de fusion. Zéro signifie que la part actuelle a été créée par insertion plutôt que par fusion d’autres parts.
* `data_version` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre utilisé pour déterminer quelles mutations doivent être appliquées à la part de données (mutations dont la version est supérieure à data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de mémoire (en octets) utilisée par les valeurs de la clé primaire. Est égale à 0 lorsque `primary_key_lazy_load` est activé et que la clé n’est pas chargée. Lorsqu’elle est non nulle, ces octets sont stockés dans la part elle-même et comptabilisés dans `jemalloc.mergetree_arena.active_bytes`. Ils ne sont JAMAIS comptabilisés dans `PrimaryIndexCacheBytes` : pour chaque part, ces deux métriques s’excluent mutuellement. Un index est stocké soit dans la part (cette métrique), soit dans le `PrimaryIndexCache` partagé (l’autre métrique), selon `primary_key_lazy_load` et `use_primary_key_cache`.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de mémoire (en octets) réservée aux valeurs de la clé primaire. Est égale à 0 lorsque `primary_key_lazy_load` est activé et que la clé n’est pas chargée. Lorsqu’elle est non nulle, elle est incluse dans `jemalloc.mergetree_arena.active_bytes`. Consultez la note relative à `primary_key_bytes_in_memory` pour connaître son lien avec `PrimaryIndexCacheBytes`.
* `index_granularity_bytes_in_memory` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de mémoire (en octets) utilisée par les valeurs de granularité d’index (égale à 0 si primary&#95;key&#95;lazy&#95;load=1 et use&#95;primary&#95;key&#95;cache=1). Lorsqu’ils sont non nuls, ces octets sont détenus par la part et comptabilisés dans `jemalloc.mergetree_arena.active_bytes`.
* `index_granularity_bytes_in_memory_allocated` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de mémoire (en octets) réservée aux valeurs de granularité d’index (égale à 0 si primary&#95;key&#95;lazy&#95;load=1 et use&#95;primary&#95;key&#95;cache=1). Lorsqu’elle est non nulle, elle est incluse dans `jemalloc.mergetree_arena.active_bytes`.
* `is_frozen` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant l’existence d’une sauvegarde de partition. 1 : la sauvegarde existe. 0 : la sauvegarde n’existe pas. Pour plus de détails, consultez FREEZE PARTITION.
* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `engine` ([String](/fr/reference/data-types/string)) — Nom du moteur de table sans paramètres.
* `disk_name` ([String](/fr/reference/data-types/string)) — Nom du disque qui stocke la part de données.
* `path` ([String](/fr/reference/data-types/string)) — Chemin absolu vers le dossier contenant les fichiers de la part de données.
* `hash_of_all_files` ([String](/fr/reference/data-types/string)) — sipHash128 des fichiers compressés.
* `hash_of_uncompressed_files` ([String](/fr/reference/data-types/string)) — sipHash128 des fichiers non compressés (fichiers de marques, fichier d’index, etc.).
* `uncompressed_hash_of_compressed_files` ([String](/fr/reference/data-types/string)) — sipHash128 des données contenues dans les fichiers compressés, comme si elles n’étaient pas compressées.
* `delete_ttl_info_min` ([DateTime](/fr/reference/data-types/datetime)) — Valeur minimale de la clé de date et d’heure pour la règle TTL DELETE.
* `delete_ttl_info_max` ([DateTime](/fr/reference/data-types/datetime)) — Valeur maximale de la clé de date et d’heure pour la règle TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — Tableau d’expressions. Chaque expression définit une règle TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Tableau de valeurs de date et d’heure. Chaque élément décrit la valeur minimale de la clé pour une règle TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Tableau de valeurs de date et d’heure. Chaque élément décrit la valeur maximale de la clé pour une règle TTL MOVE.
* `default_compression_codec` ([String](/fr/reference/data-types/string)) — Nom du codec utilisé pour compresser cette partie de données lorsqu’une colonne n’a pas de codec explicite ou utilise `CODEC(Default)`. Avec `allow_experimental_adaptive_codec_selection`, certains blocks de ces colonnes peuvent utiliser d’autres codecs ; voir [`mergeTreeCodecBlockCounts`](/fr/reference/functions/table-functions/mergeTreeCodecBlockCounts).
* `recompression_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — Expression TTL.
* `recompression_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur minimale de l’expression TTL calculée dans cette partie. Permet de déterminer si au moins une ligne a un TTL expiré.
* `recompression_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur maximale de l’expression TTL calculée dans cette partie. Permet de déterminer si toutes les lignes ont un TTL expiré.
* `group_by_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — Expression TTL.
* `group_by_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur minimale de l’expression TTL calculée dans cette partie. Permet de déterminer si au moins une ligne a un TTL expiré.
* `group_by_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur maximale de l’expression TTL calculée dans cette partie. Permet de déterminer si toutes les lignes ont un TTL expiré.
* `rows_where_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — Expression TTL.
* `rows_where_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur minimale de l’expression TTL calculée dans cette partie. Permet de déterminer si au moins une ligne a un TTL expiré.
* `rows_where_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur maximale de l’expression TTL calculée dans cette partie. Permet de déterminer si toutes les lignes ont un TTL expiré.
* `projections` ([Array(String)](/fr/reference/data-types/array)) — Liste des noms des projections calculées pour cette partie.
* `visible` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur indiquant si cette partie est visible pour les requêtes SELECT.
* `creation_tid` ([Tuple(UInt64, UInt64, UUID)](/fr/reference/data-types/tuple)) — ID de la transaction qui a créé ou tente de créer cet objet.
* `removal_tid_lock` ([UInt64](/fr/reference/data-types/int-uint)) — Hachage de removal&#95;tid, utilisé pour verrouiller un objet en vue de sa suppression.
* `removal_tid` ([Tuple(UInt64, UInt64, UUID)](/fr/reference/data-types/tuple)) — ID de la transaction qui a supprimé ou tente de supprimer cet objet
* `creation_csn` ([UInt64](/fr/reference/data-types/int-uint)) — CSN de la transaction qui a créé cet objet
* `removal_csn` ([UInt64](/fr/reference/data-types/int-uint)) — CSN de la transaction qui a supprimé cet objet
* `has_lightweight_delete` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur indiquant si la partie possède un masque de suppression légère.
* `last_removal_attempt_time` ([DateTime](/fr/reference/data-types/datetime)) — Dernière tentative du serveur de supprimer cette partie.
* `removal_state` ([String](/fr/reference/data-types/string)) — État actuel du processus de suppression des parties.

**Alias :**

* `bytes` — alias de `bytes_on_disk`.
* `marks_size` — alias de `marks_bytes`.
* `part_name` — alias de `name`.
