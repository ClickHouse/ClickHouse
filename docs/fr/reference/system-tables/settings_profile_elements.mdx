## Description {#description}

Décrit le contenu du settings profile :

* Contraintes.
* Rôles et utilisateurs auxquels le paramètre s&#39;applique.
* Settings profiles parents.

## Colonnes {#columns}

* `profile_name` ([Nullable(String)](/fr/reference/data-types/nullable)) — Nom du settings profile.
* `user_name` ([Nullable(String)](/fr/reference/data-types/nullable)) — Nom d’utilisateur.
* `role_name` ([Nullable(String)](/fr/reference/data-types/nullable)) — Nom du rôle.
* `index` ([UInt64](/fr/reference/data-types/int-uint)) — Numéro séquentiel de l’élément du settings profile.
* `setting_name` ([Nullable(String)](/fr/reference/data-types/nullable)) — Nom du paramètre.
* `value` ([Nullable(String)](/fr/reference/data-types/nullable)) — Valeur du paramètre.
* `min` ([Nullable(String)](/fr/reference/data-types/nullable)) — Valeur minimale du paramètre. NULL s’il n’est pas défini.
* `max` ([Nullable(String)](/fr/reference/data-types/nullable)) — Valeur maximale du paramètre. NULL s’il n’est pas défini.
* `writability` ([Nullable(Enum8(&#39;WRITABLE&#39; = 0, &#39;CONST&#39; = 1, &#39;CHANGEABLE&#95;IN&#95;READONLY&#39; = 2))](/fr/reference/data-types/nullable)) — Indique si un paramètre peut être modifié.
* `inherit_profile` ([Nullable(String)](/fr/reference/data-types/nullable)) — Profil parent de ce settings profile. NULL s’il n’est pas défini. Le settings profile hérite de toutes les valeurs et contraintes des paramètres (min, max, readonly) de ses settings profiles parents.
