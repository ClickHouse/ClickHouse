<div id="description">
  ## Description
</div>

Contient la description des moteurs de table pris en charge par le serveur ainsi que des informations sur les fonctionnalités qu’ils prennent en charge.

Ce tableau contient les colonnes suivantes (le type de chaque colonne est indiqué entre crochets) :

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Le nom du moteur de table.
* `supports_settings` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge la clause SETTINGS.
* `supports_skipping_indices` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge les index de saut.
* `supports_projections` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge les projections.
* `supports_sort_order` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge les clauses PARTITION&#95;BY, PRIMARY&#95;KEY, ORDER&#95;BY et SAMPLE&#95;BY.
* `supports_ttl` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge TTL.
* `supports_replication` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge la réplication des données.
* `supports_deduplication` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge la déduplication des données.
* `supports_parallel_insert` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si le moteur de table prend en charge les insertions parallèles (voir le paramètre max&#95;insert&#95;threads).
* `description` ([String](/fr/reference/data-types/string)) — Description du fonctionnement du moteur de table. Pour les moteurs disposant d’une page de documentation dédiée, ce champ contient l’intégralité du contenu Markdown de cette page ; pour les autres, il contient un résumé concis.
* `syntax` ([String](/fr/reference/data-types/string)) — La façon dont le moteur de table est utilisé lors de la création d’une table. Pour la plupart des moteurs, il s’agit de la clause ENGINE d’une requête CREATE TABLE, mais certains moteurs, tels que les différents types de vues ou le moteur Loop, s’utilisent sous d’autres formes, par exemple CREATE VIEW ou un SELECT depuis une fonction de table.
* `examples` ([String](/fr/reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/reference/data-types/string)) — Version de ClickHouse dans laquelle le moteur de table a été introduit, au format majeure.mineure.
* `related` ([Array(String)](/fr/reference/data-types/array)) — Les noms des moteurs de table associés.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemple
</div>

```sql title="Query"
SELECT
    name,
    supports_settings,
    supports_skipping_indices,
    supports_sort_order,
    supports_ttl,
    supports_replication,
    supports_deduplication,
    supports_parallel_insert
FROM system.table_engines
WHERE name IN ('Kafka', 'MergeTree', 'ReplicatedCollapsingMergeTree')
```
