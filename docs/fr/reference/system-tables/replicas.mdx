<div id="description">
  ## Description
</div>

Contient des informations et l’état des tables répliquées présentes sur le serveur local.
Cette table peut être utilisée à des fins de supervision. Elle contient une ligne pour chaque table Replicated*.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/reference/data-types/uuid)) — UUID de la table.
* `engine` ([String](/fr/reference/data-types/string)) — Nom du moteur de table.
* `is_leader` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la réplique est leader. Plusieurs répliques peuvent être leaders simultanément. Il est possible d&#39;empêcher une réplique de devenir leader à l&#39;aide du paramètre MergeTree `replicated&#95;can&#95;become&#95;leader`. Les leaders sont responsables de la planification des fusions en arrière-plan. Notez que des écritures peuvent être effectuées sur n&#39;importe quelle réplique disponible disposant d&#39;une session dans ZK, qu&#39;elle soit leader ou non.
* `can_become_leader` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la réplique peut devenir leader.
* `is_readonly` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la réplique est en mode lecture seule. Ce mode est activé si la configuration ne comporte pas de sections ClickHouse Keeper, si une erreur inconnue survient lors de la réinitialisation des sessions dans ClickHouse Keeper, ou pendant cette réinitialisation.
* `readonly_start_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Horodatage auquel la réplique est passée en mode lecture seule. NULL si la réplique n&#39;est pas en mode lecture seule.
* `is_session_expired` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la session avec ClickHouse Keeper a expiré. Équivaut essentiellement à `is_readonly`.
* `future_parts` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre de parties de données qui apparaîtront à la suite d&#39;INSERT ou de fusions qui n&#39;ont pas encore été effectués.
* `parts_to_check` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre de parties de données dans la file d&#39;attente de vérification. Une partie est placée dans cette file si l&#39;on soupçonne qu&#39;elle pourrait être endommagée.
* `zookeeper_name` ([String](/fr/reference/data-types/string)) — Nom du cluster [Zoo]Keeper (éventuellement auxiliaire) dans lequel sont stockées les métadonnées de la table.
* `zookeeper_path` ([String](/fr/reference/data-types/string)) — Chemin vers les données de la table dans ClickHouse Keeper.
* `replica_name` ([String](/fr/reference/data-types/string)) — Nom de la réplique dans ClickHouse Keeper. Les répliques d&#39;une même table ont des noms différents.
* `replica_path` ([String](/fr/reference/data-types/string)) — Chemin vers les données de la réplique dans ClickHouse Keeper. Équivaut à la concaténation de &#39;zookeeper&#95;path/replicas/replica&#95;path&#39;.
* `columns_version` ([Int32](/fr/reference/data-types/int-uint)) — Numéro de version de la structure de la table. Indique le nombre d&#39;exécutions d&#39;ALTER. Si les répliques ont des versions différentes, cela signifie que certaines n&#39;ont pas encore exécuté tous les ALTER.
* `queue_size` ([UInt32](/fr/reference/data-types/int-uint)) — Taille de la file d&#39;attente des opérations en attente d&#39;exécution. Ces opérations incluent l&#39;insertion de blocs de données, les fusions et certaines autres actions. Elle coïncide généralement avec `future&#95;parts`.
* `inserts_in_queue` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre d&#39;insertions de blocs de données à effectuer. Les insertions sont généralement répliquées assez rapidement. Si ce nombre est élevé, cela indique un problème.
* `merges_in_queue` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre de fusions en attente d&#39;exécution. Les fusions sont parfois longues, cette valeur peut donc rester supérieure à zéro pendant longtemps.
* `part_mutations_in_queue` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre de mutations en attente d&#39;exécution.
* `queue_oldest_time` ([DateTime](/fr/reference/data-types/datetime)) — Si `queue_size` est supérieur à 0, indique quand l&#39;opération la plus ancienne a été ajoutée à la file d&#39;attente.
* `inserts_oldest_time` ([DateTime](/fr/reference/data-types/datetime)) — Voir `queue_oldest_time`.
* `merges_oldest_time` ([DateTime](/fr/reference/data-types/datetime)) — Voir `queue_oldest_time`.
* `part_mutations_oldest_time` ([DateTime](/fr/reference/data-types/datetime)) — Voir `queue_oldest_time`.
* `oldest_part_to_get` ([String](/fr/reference/data-types/string)) — Nom de la partie à récupérer auprès d&#39;autres répliques, obtenu à partir de l&#39;entrée GET&#95;PARTS la plus ancienne de la file d&#39;attente de réplication.
* `oldest_part_to_merge_to` ([String](/fr/reference/data-types/string)) — Nom de la partie résultante dans laquelle fusionner, obtenu à partir de l’entrée MERGE&#95;PARTS la plus ancienne de la file de réplication.
* `oldest_part_to_mutate_to` ([String](/fr/reference/data-types/string)) — Nom de la partie résultante à muter, obtenu à partir de l’entrée MUTATE&#95;PARTS la plus ancienne de la file de réplication.
* `log_max_index` ([UInt64](/fr/reference/data-types/int-uint)) — Numéro maximal d’entrée dans le journal d’activité général. Cette colonne et les trois suivantes (`log_pointer`, `total_replicas`, `active_replicas`) n’ont une valeur non nulle que lorsqu’une session active avec ClickHouse Keeper existe.
* `log_pointer` ([UInt64](/fr/reference/data-types/int-uint)) — Numéro maximal d’entrée dans le journal d’activité général que la réplique a copiée dans sa file d’exécution, plus un. Si log&#95;pointer est nettement inférieur à log&#95;max&#95;index, un problème est survenu.
* `last_queue_update` ([DateTime](/fr/reference/data-types/datetime)) — Date de la dernière mise à jour de la file.
* `absolute_delay` ([UInt64](/fr/reference/data-types/int-uint)) — Retard de la réplique actuelle, en secondes.
* `total_replicas` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre total de répliques connues de cette table.
* `active_replicas` ([UInt32](/fr/reference/data-types/int-uint)) — Nombre de répliques de cette table ayant une session dans ClickHouse Keeper (c’est-à-dire le nombre de répliques opérationnelles).
* `lost_part_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre total de parties de données perdues dans la table par l’ensemble des répliques depuis la création de la table. Cette valeur est conservée dans ClickHouse Keeper et ne peut qu’augmenter.
* `last_queue_update_exception` ([String](/fr/reference/data-types/string)) — Indique que la file contient des entrées défectueuses. Particulièrement important lorsque ClickHouse rompt la compatibilité descendante entre les versions et que les entrées de journal écrites par des versions plus récentes ne peuvent pas être analysées par les versions plus anciennes.
* `zookeeper_exception` ([String](/fr/reference/data-types/string)) — Dernier message d’exception obtenu si l’erreur s’est produite lors de la récupération des informations depuis ClickHouse Keeper.
* `replica_is_active` ([Map(String, UInt8)](/fr/reference/data-types/map)) — Mappage entre le nom d’une réplique et son état d’activité.

**Alias :**

* `readonly_duration` — alias de `if(isNull(readonly_start_time), NULL, now() - readonly_start_time)`.

{/*AUTOGENERATED_END*/}
