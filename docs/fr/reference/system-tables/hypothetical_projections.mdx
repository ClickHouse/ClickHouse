Liste toutes les projections hypothétiques (what-if) définies dans la session en cours. Voir [`CREATE HYPOTHETICAL PROJECTION`](/fr/reference/statements/hypothetical-projection#create-hypothetical-projection) et [`EXPLAIN WHATIF`](/fr/reference/statements/explain#explain-whatif).

Le contenu est propre à chaque session : une connexion ne voit que ses propres projections hypothétiques, et la table reste vide si aucune n&#39;a été créée dans la session en cours.

Les valeurs courantes de `(database, table)` sont résolues par UUID au moment de la requête ; elles reflètent donc les opérations `RENAME TABLE`, et les entrées correspondant à des tables supprimées sont masquées automatiquement.

## Colonnes {#columns}

{/*AUTOGENERATED_START*/}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table
* `name` ([String](/fr/reference/data-types/string)) — Nom de la projection
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/fr/reference/data-types/enum)) — Type de projection
* `sorting_key` ([Array(String)](/fr/reference/data-types/array)) — Clé de tri de la projection
* `query` ([String](/fr/reference/data-types/string)) — Requête SELECT de la projection, vide pour la forme INDEX ... TYPE ...
* `definition` ([String](/fr/reference/data-types/string)) — Déclaration complète de la projection telle qu&#39;elle a été écrite
* `settings` ([Map(String, String)](/fr/reference/data-types/map)) — Paramètres de la projection issus de WITH SETTINGS

{/*AUTOGENERATED_END*/}

**Exemple**

```sql
CREATE HYPOTHETICAL PROJECTION p_by_b ON t (SELECT a, b ORDER BY b);
SELECT name, type, sorting_key FROM system.hypothetical_projections;
```

```text
┌─name───┬─type───┬─sorting_key─┐
│ p_by_b │ Normal │ ['b']       │
└────────┴────────┴─────────────┘
```
