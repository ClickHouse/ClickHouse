<div id="description">
  ## Description
</div>

Cette table système sert à implémenter la requête `SHOW PROCESSLIST`.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si cette requête provient directement de l’utilisateur ou a été émise par le serveur ClickHouse dans le cadre de l’exécution d’une requête distribuée.
* `user` ([String](/fr/reference/data-types/string)) — L’utilisateur qui a effectué la requête. Gardez à l’esprit que, dans le cadre du traitement distribué, les requêtes sont envoyées aux serveurs distants sous l’utilisateur `default`. Ce champ contient le nom d’utilisateur associé à une requête donnée, et non à la requête dont elle est issue.
* `query_id` ([String](/fr/reference/data-types/string)) — ID de la requête, s’il est défini.
* `address` ([IPv6](/fr/reference/data-types/ipv6)) — L’adresse IP depuis laquelle la requête a été effectuée. Il en va de même pour le traitement distribué. Pour connaître l’origine d’une requête distribuée, consultez system.processes sur le serveur ayant soumis la requête.
* `port` ([UInt16](/fr/reference/data-types/int-uint)) — Le port client depuis lequel la requête a été effectuée.
* `initial_user` ([String](/fr/reference/data-types/string)) — Nom de l’utilisateur qui a exécuté la requête initiale (pour l’exécution de requêtes distribuées).
* `initial_query_id` ([String](/fr/reference/data-types/string)) — ID de la requête initiale (pour l’exécution de requêtes distribuées).
* `initial_address` ([IPv6](/fr/reference/data-types/ipv6)) — Adresse IP depuis laquelle la requête parente a été lancée.
* `initial_port` ([UInt16](/fr/reference/data-types/int-uint)) — Le port client utilisé pour effectuer la requête parente.
* `interface` ([UInt8](/fr/reference/data-types/int-uint)) — L’interface utilisée pour envoyer la requête. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/fr/reference/data-types/string)) — Nom d’utilisateur du système d’exploitation exécutant clickhouse-client.
* `client_hostname` ([String](/fr/reference/data-types/string)) — Nom d’hôte de la machine cliente sur laquelle clickhouse-client ou un autre client TCP est exécuté.
* `client_name` ([String](/fr/reference/data-types/string)) — Nom de clickhouse-client ou d’un autre client TCP.
* `client_agent` ([LowCardinality(String)](/fr/reference/data-types/lowcardinality)) — L’agent de codage IA qui a appelé le client (par exemple, `claude-code`, `cursor`), détecté à partir des variables d’environnement. Vide si aucun agent n’a été détecté.
* `client_revision` ([UInt64](/fr/reference/data-types/int-uint)) — Révision de clickhouse-client ou d’un autre client TCP.
* `client_version_major` ([UInt64](/fr/reference/data-types/int-uint)) — Version majeure de clickhouse-client ou d’un autre client TCP.
* `client_version_minor` ([UInt64](/fr/reference/data-types/int-uint)) — Version mineure de clickhouse-client ou d’un autre client TCP.
* `client_version_patch` ([UInt64](/fr/reference/data-types/int-uint)) — Composant de correctif de la version de clickhouse-client ou d’un autre client TCP.
* `http_method` ([UInt8](/fr/reference/data-types/int-uint)) — Méthode HTTP ayant initié la requête. Valeurs possibles : 0 — La requête a été lancée depuis l’interface TCP. 1 — La méthode GET a été utilisée. 2 — La méthode POST a été utilisée.
* `http_user_agent` ([String](/fr/reference/data-types/string)) — En-tête HTTP UserAgent transmis avec la requête HTTP.
* `http_referer` ([String](/fr/reference/data-types/string)) — En-tête HTTP Referer transmis avec la requête HTTP (contient une adresse absolue ou partielle de la page à l’origine de la requête).
* `forwarded_for` ([String](/fr/reference/data-types/string)) — En-tête HTTP X-Forwarded-For transmis avec la requête HTTP.
* `quota_key` ([String](/fr/reference/data-types/string)) — La clé de quota spécifiée dans le paramètre quotas (voir keyed).
* `distributed_depth` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de fois où la requête a été retransmise en interne entre les nœuds de serveur.
* `elapsed` ([Float64](/fr/reference/data-types/float)) — Temps écoulé en secondes depuis le début de l’exécution de la requête.
* `is_cancelled` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la requête a été annulée.
* `is_all_data_sent` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si toutes les données ont été envoyées au client (autrement dit, si la requête s’est terminée sur le serveur).
* `read_rows` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de lignes lues dans la table. En traitement distribué, sur le serveur demandeur, il s’agit du total de tous les serveurs distants.
* `read_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre d’octets non compressés lus dans la table. En traitement distribué, sur le serveur demandeur, il s’agit du total de tous les serveurs distants.
* `total_rows_approx` ([UInt64](/fr/reference/data-types/int-uint)) — Estimation du nombre total de lignes à lire. En traitement distribué, sur le serveur demandeur, il s’agit du total de tous les serveurs distants. Cette valeur peut être mise à jour pendant le traitement de la requête, lorsque de nouvelles sources à traiter sont identifiées.
* `written_rows` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de lignes écrites dans le stockage.
* `written_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre d’octets écrits dans le stockage.
* `memory_usage` ([Int64](/fr/reference/data-types/int-uint)) — Quantité de RAM utilisée par la requête. Elle peut ne pas inclure certains types de mémoire dédiée.
* `peak_memory_usage` ([Int64](/fr/reference/data-types/int-uint)) — Pic actuel d’utilisation de la mémoire.
* `query` ([String](/fr/reference/data-types/string)) — Texte de la requête. Pour INSERT, il n’inclut pas les données à insérer.
* `normalized_query_hash` ([UInt64](/fr/reference/data-types/int-uint)) — Valeur de hachage numérique identique pour les requêtes qui ne diffèrent que par les valeurs des littéraux.
* `query_kind` ([String](/fr/reference/data-types/string)) — Type de requête : SELECT, INSERT, etc.
* `thread_ids` ([Array(UInt64)](/fr/reference/data-types/array)) — Liste des identifiants de tous les threads ayant participé à cette requête.
* `peak_threads_usage` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre maximal de threads exécutant simultanément la requête.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/fr/reference/data-types/map)) — ProfileEvents calculés pour cette requête.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/fr/reference/data-types/map)) — Liste des paramètres au niveau utilisateur modifiés.
* `current_database` ([String](/fr/reference/data-types/string)) — Nom de la base de données courante.
* `is_internal` ([UInt8](/fr/reference/data-types/int-uint)) — Indique s’il s’agit d’une requête auxiliaire exécutée en interne.

**Alias :**

* `ProfileEvents.Names` — alias de `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — alias de `mapValues(ProfileEvents)`.
* `Settings.Names` — alias de `mapKeys(Settings)`.
* `Settings.Values` — alias de `mapValues(Settings)`.

{/*AUTOGENERATED_END*/}
