<div id="description">
  ## Description
</div>

Cette table contient des informations sur les parties de projection des tables de la famille MergeTree.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/fr/reference/data-types/string)) — Le nom de la partition.
* `name` ([String](/fr/reference/data-types/string)) — Le nom de la partie de données.
* `part_type` ([String](/fr/reference/data-types/string)) — Le format de stockage de la partie de données. Valeurs possibles : Wide (un fichier par colonne) et Compact (un seul fichier pour toutes les colonnes).
* `parent_name` ([String](/fr/reference/data-types/string)) — Le nom de la partie de données source (parente).
* `parent_uuid` ([UUID](/fr/reference/data-types/uuid)) — L’UUID de la partie de données source (parente).
* `parent_part_type` ([String](/fr/reference/data-types/string)) — Le format de stockage de la partie de données source (parente).
* `active` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si la partie de données est active. Lorsqu’une partie de données est active, elle est utilisée dans une table. Sinon, elle est sur le point d’être supprimée. Des parties de données inactives apparaissent après des opérations de fusion et de mutation.
* `marks` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de marques. Pour obtenir le nombre approximatif de lignes dans une partie de données, multipliez le nombre de marques par la granularité de l’index (généralement 8192). Cette indication ne s’applique pas à la granularité adaptative.
* `rows` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de lignes.
* `bytes_on_disk` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale, en octets, de tous les fichiers de la partie de données.
* `data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données compressées dans la partie de données. Les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données non compressées dans la partie de données. Les fichiers auxiliaires (par exemple, les fichiers de marques) ne sont pas inclus.
* `marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille du fichier de marques.
* `parent_marks` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de marques dans la partie source (parente).
* `parent_rows` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de lignes dans la partie source (parente).
* `parent_bytes_on_disk` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale, en octets, de tous les fichiers de la partie de données source (parente).
* `parent_data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données compressées dans la partie de données source (parente).
* `parent_data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données non compressées dans la partie de données source (parente).
* `parent_marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille du fichier de marques de la partie de données source (parente).
* `modification_time` ([DateTime](/fr/reference/data-types/datetime)) — L’heure à laquelle le répertoire contenant la partie de données a été modifié. Elle correspond généralement à l’heure de création de la partie de données.
* `remove_time` ([DateTime](/fr/reference/data-types/datetime)) — L’heure à laquelle la partie de données est devenue inactive.
* `refcount` ([UInt32](/fr/reference/data-types/int-uint)) — Le nombre d’emplacements où la partie de données est utilisée. Une valeur supérieure à 2 indique que la partie de données est utilisée dans des requêtes ou des fusions.
* `min_date` ([Date](/fr/reference/data-types/date)) — La valeur minimale de la clé de date dans la partie de données.
* `max_date` ([Date](/fr/reference/data-types/date)) — La valeur maximale de la clé de date dans la partie de données.
* `min_time` ([DateTime](/fr/reference/data-types/datetime)) — La valeur minimale de la clé de date et d’heure dans la partie de données.
* `max_time` ([DateTime](/fr/reference/data-types/datetime)) — Valeur maximale de la clé de date et d&#39;heure dans la partie de données.
* `partition_id` ([String](/fr/reference/data-types/string)) — ID de la partition.
* `min_block_number` ([Int64](/fr/reference/data-types/int-uint)) — Nombre minimal de parties de données composant la partie actuelle après fusion.
* `max_block_number` ([Int64](/fr/reference/data-types/int-uint)) — Nombre maximal de parties de données composant la partie actuelle après fusion.
* `level` ([UInt32](/fr/reference/data-types/int-uint)) — Profondeur de l&#39;arbre de fusion. Zéro signifie que la partie actuelle a été créée par insertion plutôt que par fusion d&#39;autres parties.
* `data_version` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre utilisé pour déterminer quelles mutations doivent être appliquées à la partie de données (mutations dont la version est supérieure à data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de mémoire (en octets) utilisée par les valeurs de clé primaire.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de mémoire (en octets) réservée aux valeurs de clé primaire.
* `is_frozen` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant l&#39;existence d&#39;une sauvegarde des données de la partition. 1 : la sauvegarde existe. 0 : la sauvegarde n&#39;existe pas.
* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `engine` ([String](/fr/reference/data-types/string)) — Nom du moteur de table sans paramètres.
* `disk_name` ([String](/fr/reference/data-types/string)) — Nom du disque qui stocke la partie de données.
* `path` ([String](/fr/reference/data-types/string)) — Chemin absolu vers le dossier contenant les fichiers de la partie de données.
* `hash_of_all_files` ([String](/fr/reference/data-types/string)) — sipHash128 des fichiers compressés.
* `hash_of_uncompressed_files` ([String](/fr/reference/data-types/string)) — sipHash128 des fichiers non compressés (fichiers de marques, fichier d&#39;index, etc.).
* `uncompressed_hash_of_compressed_files` ([String](/fr/reference/data-types/string)) — sipHash128 des données contenues dans les fichiers compressés, comme si elles n&#39;étaient pas compressées.
* `delete_ttl_info_min` ([DateTime](/fr/reference/data-types/datetime)) — Valeur minimale de la clé de date et d&#39;heure pour la règle TTL DELETE.
* `delete_ttl_info_max` ([DateTime](/fr/reference/data-types/datetime)) — Valeur maximale de la clé de date et d&#39;heure pour la règle TTL DELETE.
* `move_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — Tableau d&#39;expressions. Chaque expression définit une règle TTL MOVE.
* `move_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Tableau de valeurs de date et d&#39;heure. Chaque élément décrit la valeur de clé minimale pour une règle TTL MOVE.
* `move_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Tableau de valeurs de date et d&#39;heure. Chaque élément décrit la valeur de clé maximale pour une règle TTL MOVE.
* `default_compression_codec` ([String](/fr/reference/data-types/string)) — Nom du codec utilisé pour compresser cette partie de données (lorsqu&#39;aucun codec explicite n&#39;est défini pour les colonnes).
* `recompression_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — Expression TTL.
* `recompression_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur minimale de l&#39;expression TTL calculée dans cette partie. Permet de déterminer si au moins une ligne a un TTL expiré.
* `recompression_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur maximale de l’expression TTL calculée dans cette part. Permet de déterminer si toutes les lignes ont un TTL expiré.
* `group_by_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — L’expression TTL.
* `group_by_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur minimale de l’expression TTL calculée dans cette part. Permet de déterminer si au moins une ligne a un TTL expiré.
* `group_by_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur maximale de l’expression TTL calculée dans cette part. Permet de déterminer si toutes les lignes ont un TTL expiré.
* `rows_where_ttl_info.expression` ([Array(String)](/fr/reference/data-types/array)) — L’expression TTL.
* `rows_where_ttl_info.min` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur minimale de l’expression TTL calculée dans cette part. Permet de déterminer si au moins une ligne a un TTL expiré.
* `rows_where_ttl_info.max` ([Array(DateTime)](/fr/reference/data-types/array)) — Valeur maximale de l’expression TTL calculée dans cette part. Permet de déterminer si toutes les lignes ont un TTL expiré.
* `is_broken` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la part de projection est endommagée.
* `exception_code` ([Int32](/fr/reference/data-types/int-uint)) — Message d’exception expliquant l’état endommagé de la part de projection.
* `exception` ([String](/fr/reference/data-types/string)) — Code d’exception expliquant l’état endommagé de la part de projection.

**Alias :**

* `bytes` — alias de `bytes_on_disk`.
* `marks_size` — alias de `marks_bytes`.
* `part_name` — alias de `name`.
