<div id="description">
  ## Description
</div>

La table `system.unicode` est une table virtuelle qui fournit des informations sur les caractères Unicode et leurs propriétés (https://unicode-org.github.io/icu/userguide/strings/properties.html). Cette table est générée dynamiquement.

Les noms de propriétés des points de code Unicode provenant d’ICU sont convertis en `snake_case` pour être utilisés comme noms de colonnes.
