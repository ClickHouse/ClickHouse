## Description {#description}

Contient l’historique des valeurs d’erreur de la table `system.errors`, périodiquement enregistrées sur disque.

Il est possible de faire un truncate ou un drop de cette table à tout moment en toute sécurité.

## Colonnes {#columns}

* `hostname` ([LowCardinality(String)](/fr/reference/data-types/lowcardinality)) — Nom d’hôte du serveur qui exécute la requête.
* `clickhouse_version` ([LowCardinality(String)](/fr/reference/data-types/lowcardinality)) — Version du serveur ClickHouse qui a produit la ligne.
* `system_processor` ([LowCardinality(String)](/fr/reference/data-types/lowcardinality)) — Architecture CPU du serveur ClickHouse qui a produit la ligne.
* `event_date` ([Date](/fr/reference/data-types/date)) — Date de l’événement.
* `event_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure de l’événement.
* `code` ([Int32](/fr/reference/data-types/int-uint)) — Code d’erreur.
* `error` ([LowCardinality(String)](/fr/reference/data-types/lowcardinality)) — Nom de l’erreur.
* `value` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre d’erreurs survenues pendant l’intervalle de temps.
* `remote` ([UInt8](/fr/reference/data-types/int-uint)) — Exception distante (c.-à-d. reçue lors de l’une des requêtes distribuées).
* `last_error_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure à laquelle la dernière erreur s’est produite.
* `last_error_message` ([String](/fr/reference/data-types/string)) — Message de la dernière erreur.
* `last_error_query_id` ([String](/fr/reference/data-types/string)) — ID d’une requête ayant provoqué la dernière erreur (si disponible).
* `last_error_trace` ([Array(UInt64)](/fr/reference/data-types/array)) — Trace de pile de la dernière erreur. Sur les plateformes ELF, à l’exception de FreeBSD, les adresses du binaire principal de ClickHouse sont stockées sous forme de décalages physiques dans le fichier, tandis que les cadres situés en dehors de celui-ci (bibliothèques partagées, code JIT) sont stockés avec la valeur 0.
* `last_error_symbols` ([Array(LowCardinality(String))](/fr/reference/data-types/array)) — Noms de symboles démanglés correspondant à last&#95;error&#95;trace.
* `last_error_lines` ([Array(LowCardinality(String))](/fr/reference/data-types/array)) — Noms de fichiers et numéros de ligne correspondant à last&#95;error&#95;trace.

`last_error_symbols` et `last_error_lines` sont résolus à partir de la table des symboles et des informations de débogage du binaire.
`last_error_symbols` est rempli dès lors que la table des symboles est disponible (versions compilées pour Linux et macOS).
`last_error_lines` nécessite en outre les informations de débogage DWARF — lues directement depuis le binaire sous Linux, ou depuis une archive `.dSYM` placée au même emplacement sous macOS. Cette colonne est donc vide lorsque ces informations de débogage ne sont pas disponibles. Les deux tableaux sont vides sur les plateformes qui ne prennent pas en charge l’introspection (par exemple FreeBSD).
