<div id="description">
  ## Description
</div>

Contient la liste de tous les handlers HTTP définis en SQL et créés avec CREATE HANDLER.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Nom du handler.
* `protocol` ([Nullable(String)](/fr/reference/data-types/nullable)) — Protocole composable auquel le handler est limité, ou NULL si le handler est actif sur tous les endpoints HTTP (les ports `http`/`https` intégrés et chaque listener de protocole composable de type HTTP).
* `url_match_type` ([String](/fr/reference/data-types/string)) — Mode de correspondance de l’URL : exact, préfixe ou regexp.
* `url` ([String](/fr/reference/data-types/string)) — Le pattern d’URL auquel correspond le handler.
* `methods` ([Array(String)](/fr/reference/data-types/array)) — Méthodes HTTP autorisées.
* `type` ([String](/fr/reference/data-types/string)) — Type de handler (seul `query` est pris en charge).
* `query` ([String](/fr/reference/data-types/string)) — Requête SQL exécutée par le handler. Les secrets sont masqués, sauf si l’utilisateur est autorisé à les voir.
* `create_query` ([String](/fr/reference/data-types/string)) — Instruction CREATE HANDLER. Les secrets sont masqués, sauf si l’utilisateur est autorisé à les voir.

{/*AUTOGENERATED_END*/}
