<div id="description">
  ## Description
</div>

Contient des informations sur les [dictionnaires](/fr/reference/statements/create/dictionary).

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données contenant le dictionnaire créé par une requête DDL. Chaîne vide pour les autres dictionnaires.
* `name` ([String](/fr/reference/data-types/string)) — Nom du dictionnaire.
* `uuid` ([UUID](/fr/reference/data-types/uuid)) — UUID du dictionnaire.
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/fr/reference/data-types/enum)) — État du dictionnaire. Valeurs possibles : NOT&#95;LOADED — dictionnaire actuellement non chargé en mémoire, LOADED — dictionnaire chargé avec succès, FAILED — impossible de charger le dictionnaire en raison d&#39;une erreur, LOADING — dictionnaire en cours de chargement, LOADED&#95;AND&#95;RELOADING — dictionnaire chargé avec succès et en cours de rechargement (raisons fréquentes : requête SYSTEM RELOAD DICTIONARY, délai d&#39;expiration, modification de la configuration du dictionnaire), FAILED&#95;AND&#95;RELOADING — échec du chargement du dictionnaire en raison d&#39;une erreur, puis chargement en cours.
* `origin` ([String](/fr/reference/data-types/string)) — Chemin vers le fichier de configuration décrivant le dictionnaire.
* `type` ([String](/fr/reference/data-types/string)) — Type d&#39;allocation du dictionnaire. Stockage des dictionnaires en mémoire.
* `key.names` ([Array(String)](/fr/reference/data-types/array)) — Tableau des noms de clés fournis par le dictionnaire.
* `key.types` ([Array(String)](/fr/reference/data-types/array)) — Tableau correspondant des types de clés fournis par le dictionnaire.
* `attribute.names` ([Array(String)](/fr/reference/data-types/array)) — Tableau des noms d&#39;attributs fournis par le dictionnaire.
* `attribute.types` ([Array(String)](/fr/reference/data-types/array)) — Tableau correspondant des types d&#39;attributs fournis par le dictionnaire.
* `bytes_allocated` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de RAM allouée au dictionnaire.
* `hierarchical_index_bytes_allocated` ([UInt64](/fr/reference/data-types/int-uint)) — Quantité de RAM allouée à l&#39;index hiérarchique.
* `query_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de requêtes depuis le chargement du dictionnaire ou le dernier redémarrage réussi.
* `hit_rate` ([Float64](/fr/reference/data-types/float)) — Pour les dictionnaires de type cache, pourcentage d&#39;utilisations pour lesquelles la valeur était présente dans le cache.
* `found_rate` ([Float64](/fr/reference/data-types/float)) — Pourcentage d&#39;utilisations pour lesquelles la valeur a été trouvée.
* `element_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre d&#39;éléments stockés dans le dictionnaire.
* `load_factor` ([Float64](/fr/reference/data-types/float)) — Pourcentage de remplissage du dictionnaire (pour un dictionnaire hashed, pourcentage de remplissage de la table de hachage).
* `source` ([String](/fr/reference/data-types/string)) — Texte décrivant la source de données du dictionnaire.
* `lifetime_min` ([UInt64](/fr/reference/data-types/int-uint)) — Durée de vie minimale du dictionnaire en mémoire, après laquelle ClickHouse tente de le recharger (si invalidate&#95;query est défini, uniquement s&#39;il a changé). Exprimée en secondes.
* `lifetime_max` ([UInt64](/fr/reference/data-types/int-uint)) — Durée de vie maximale du dictionnaire en mémoire, après laquelle ClickHouse tente de le recharger (si invalidate&#95;query est défini, uniquement s&#39;il a changé). Exprimée en secondes.
* `loading_start_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure de début du chargement du dictionnaire.
* `last_successful_update_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure de fin du chargement ou de la mise à jour du dictionnaire. Permet de surveiller les problèmes liés aux sources de dictionnaires et d&#39;en rechercher les causes.
* `error_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre d&#39;erreurs depuis le dernier chargement réussi. Permet de surveiller les problèmes liés aux sources de dictionnaires et d&#39;en rechercher les causes.
* `loading_duration` ([Float32](/fr/reference/data-types/float)) — Durée du chargement d&#39;un dictionnaire.
* `last_exception` ([String](/fr/reference/data-types/string)) — Texte de l&#39;erreur survenant lors de la création ou du rechargement du dictionnaire si sa création a échoué.
* `comment` ([String](/fr/reference/data-types/string)) — Texte du commentaire associé au dictionnaire.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Exemple
</div>

Configurez le dictionnaire :

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

Assurez-vous que le dictionnaire est chargé.

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
