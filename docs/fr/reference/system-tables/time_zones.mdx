## Description {#description}

Contient la liste des fuseaux horaires pris en charge par le serveur ClickHouse. Cette liste peut varier selon la version de ClickHouse.

## Colonnes {#columns}

* `time_zone` ([String](/fr/reference/data-types/string)) — Liste des fuseaux horaires pris en charge.

## Exemple {#example}

```sql
SELECT * FROM system.time_zones LIMIT 10
```

│ Africa/Abidjan     │
│ Africa/Accra       │
│ Africa/Addis_Ababa │
