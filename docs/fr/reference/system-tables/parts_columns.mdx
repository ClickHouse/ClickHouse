<div id="description">
  ## Description
</div>

Contient des informations sur les parties de données et les colonnes des tables [MergeTree](/fr/reference/engines/table-engines/mergetree-family/mergetree).
Chaque ligne décrit une partie de données.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `partition` ([String](/fr/reference/data-types/string)) — Le nom de la partition.
* `name` ([String](/fr/reference/data-types/string)) — Le nom de la partie de données.
* `uuid` ([UUID](/fr/reference/data-types/uuid)) — L’UUID de la partie de données.
* `part_type` ([String](/fr/reference/data-types/string)) — Le format de stockage de la partie de données. Valeurs possibles : Wide — chaque colonne est stockée dans un fichier distinct du système de fichiers ; Compact — toutes les colonnes sont stockées dans un seul fichier du système de fichiers.
* `active` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant si la partie de données est active. Lorsqu’une partie de données est active, elle est utilisée dans une table. Sinon, elle est supprimée. Les parties de données inactives sont conservées après la fusion.
* `marks` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de marques. Pour obtenir le nombre approximatif de lignes d’une partie de données, multipliez le nombre de marques par la granularité d’index (généralement 8192). Cette indication ne s’applique pas à la granularité adaptative.
* `rows` ([UInt64](/fr/reference/data-types/int-uint)) — Le nombre de lignes.
* `bytes_on_disk` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale, en octets, de tous les fichiers de la partie de données.
* `data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données compressées dans la partie de données. Les fichiers auxiliaires, tels que les fichiers de marques, ne sont pas inclus.
* `data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille totale des données non compressées dans la partie de données. Les fichiers auxiliaires, tels que les fichiers de marques, ne sont pas inclus.
* `marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — La taille du fichier de marques.
* `modification_time` ([DateTime](/fr/reference/data-types/datetime)) — L’heure à laquelle le répertoire contenant la partie de données a été modifié. Elle correspond généralement à l’heure de création de la partie de données.
* `remove_time` ([DateTime](/fr/reference/data-types/datetime)) — L’heure à laquelle la partie de données est devenue inactive.
* `refcount` ([UInt32](/fr/reference/data-types/int-uint)) — Le nombre d’emplacements où la partie de données est utilisée. Une valeur supérieure à 2 indique que la partie de données est utilisée dans des requêtes ou des fusions.
* `min_date` ([Date](/fr/reference/data-types/date)) — La valeur minimale de la colonne Date si celle-ci est incluse dans la clé de partition.
* `max_date` ([Date](/fr/reference/data-types/date)) — La valeur maximale de la colonne Date si celle-ci est incluse dans la clé de partition.
* `min_time` ([DateTime](/fr/reference/data-types/datetime)) — La valeur minimale de la colonne DateTime si celle-ci est incluse dans la clé de partition.
* `max_time` ([DateTime](/fr/reference/data-types/datetime)) — La valeur maximale de la colonne DateTime si celle-ci est incluse dans la clé de partition.
* `partition_id` ([String](/fr/reference/data-types/string)) — L’ID de la partition.
* `min_block_number` ([Int64](/fr/reference/data-types/int-uint)) — Le nombre minimal de parties de données qui composent la partie actuelle après la fusion.
* `max_block_number` ([Int64](/fr/reference/data-types/int-uint)) — Le nombre maximal de parties de données qui composent la partie actuelle après la fusion.
* `level` ([UInt32](/fr/reference/data-types/int-uint)) — La profondeur de l’arbre de fusion. Zéro signifie que la partie actuelle a été créée par insertion plutôt que par fusion d’autres parties.
* `data_version` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre utilisé pour déterminer quelles mutations doivent être appliquées à la partie de données (mutations dont la version est supérieure à data&#95;version).
* `primary_key_bytes_in_memory` ([UInt64](/fr/reference/data-types/int-uint)) — La quantité de mémoire, en octets, utilisée par les valeurs de clé primaire.
* `primary_key_bytes_in_memory_allocated` ([UInt64](/fr/reference/data-types/int-uint)) — La quantité de mémoire, en octets, réservée aux valeurs de clé primaire.
* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `engine` ([String](/fr/reference/data-types/string)) — Nom du moteur de table sans paramètres.
* `disk_name` ([String](/fr/reference/data-types/string)) — Nom du disque qui stocke la partie de données.
* `path` ([String](/fr/reference/data-types/string)) — Chemin absolu vers le dossier contenant les fichiers de la partie de données.
* `column` ([String](/fr/reference/data-types/string)) — Nom de la colonne.
* `type` ([String](/fr/reference/data-types/string)) — Type de la colonne.
* `column_position` ([UInt64](/fr/reference/data-types/int-uint)) — Position ordinale d’une colonne dans une table, à partir de 1.
* `default_kind` ([String](/fr/reference/data-types/string)) — Type d’expression (DEFAULT, MATERIALIZED, ALIAS) de la valeur par défaut, ou chaîne vide s’il n’est pas défini.
* `default_expression` ([String](/fr/reference/data-types/string)) — Expression de la valeur par défaut, ou chaîne vide si elle n’est pas définie.
* `column_bytes_on_disk` ([UInt64](/fr/reference/data-types/int-uint)) — Taille totale de la colonne en octets.
* `column_data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille totale des données compressées de la colonne, en octets.
* `column_data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille totale des données décompressées de la colonne, en octets.
* `column_marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des marques de la colonne, en octets.
* `column_modification_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Date et heure de la dernière modification de la colonne.
* `column_ttl_min` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Valeur minimale de l’expression TTL calculée pour la colonne.
* `column_ttl_max` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Valeur maximale de l’expression TTL calculée pour la colonne.
* `statistics` ([Array(String)](/fr/reference/data-types/array)) — Statistiques de la colonne.
* `estimates.min` ([Nullable(String)](/fr/reference/data-types/nullable)) — Valeur minimale estimée de la colonne.
* `estimates.max` ([Nullable(String)](/fr/reference/data-types/nullable)) — Valeur maximale estimée de la colonne.
* `estimates.cardinality` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Cardinalité estimée de la colonne.
* `estimates.null_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre estimé de valeurs NULL dans la colonne.
* `estimates.default_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre estimé de lignes égales à la valeur de stockage par défaut de la colonne (NULL pour les colonnes Nullable, 0 / &#39;&#39; / [] / ... pour les colonnes non-Nullable). NULL lorsqu’aucune statistique de base n’est disponible.
* `serialization_kind` ([String](/fr/reference/data-types/string)) — Type de sérialisation d’une colonne
* `substreams` ([Array(String)](/fr/reference/data-types/array)) — Noms des sous-flux dans lesquels la colonne est sérialisée
* `filenames` ([Array(String)](/fr/reference/data-types/array)) — Noms des fichiers correspondant à chaque sous-flux d’une colonne
* `subcolumns.names` ([Array(String)](/fr/reference/data-types/array)) — Noms des sous-colonnes d’une colonne
* `subcolumns.types` ([Array(String)](/fr/reference/data-types/array)) — Types des sous-colonnes d’une colonne
* `subcolumns.serializations` ([Array(String)](/fr/reference/data-types/array)) — Types de sérialisation des sous-colonnes d’une colonne
* `subcolumns.bytes_on_disk` ([Array(UInt64)](/fr/reference/data-types/array)) — Tailles en octets de chaque sous-colonne
* `subcolumns.data_compressed_bytes` ([Array(UInt64)](/fr/reference/data-types/array)) — Tailles des données compressées de chaque sous-colonne, en octets
* `subcolumns.data_uncompressed_bytes` ([Array(UInt64)](/fr/reference/data-types/array)) — Tailles des données décompressées de chaque sous-colonne, en octets
* `subcolumns.marks_bytes` ([Array(UInt64)](/fr/reference/data-types/array)) — Tailles des marques de chaque sous-colonne d’une colonne, en octets

**Alias :**

* `bytes` — alias de `bytes_on_disk`.
* `marks_size` — alias de `marks_bytes`.
* `part_name` — alias de `name`.
