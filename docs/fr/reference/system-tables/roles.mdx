## Description {#description}

Informations sur les [rôles](/fr/concepts/features/security/access-rights#role-management) configurés.

## Colonnes {#columns}

* `name` ([String](/fr/reference/data-types/string)) — Nom du rôle.
* `id` ([UUID](/fr/reference/data-types/uuid)) — Identifiant du rôle.
* `storage` ([String](/fr/reference/data-types/string)) — Chemin d’accès au stockage des rôles. Configuré via le paramètre `access_control_path`.
