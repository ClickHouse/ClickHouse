## Description {#description}

Contient des informations sur les [charges de travail](/fr/concepts/features/configuration/server-config/workload-scheduling#workload_entity_storage) du serveur local. La table contient une ligne pour chaque charge de travail.

## Colonnes {#columns}

* `name` ([String](/fr/reference/data-types/string)) — Le nom de la charge de travail.
* `parent` ([String](/fr/reference/data-types/string)) — Le nom de la charge de travail parente.
* `create_query` ([String](/fr/reference/data-types/string)) — La requête CREATE de la charge de travail.

## Exemple {#example}

```sql
SELECT *
FROM system.workloads
FORMAT Vertical
```

```text
Row 1:
──────
name:         production
parent:       all
create_query: CREATE WORKLOAD production IN `all` SETTINGS weight = 9

Row 2:
──────
name:         development
parent:       all
create_query: CREATE WORKLOAD development IN `all`

Row 3:
──────
name:         all
parent:
create_query: CREATE WORKLOAD `all`
```
