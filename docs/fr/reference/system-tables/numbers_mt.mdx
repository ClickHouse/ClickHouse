## Description {#description}

Semblable à [`system.numbers`](/fr/reference/system-tables/numbers), mais avec des lectures parallélisées. Les nombres peuvent être renvoyés dans un ordre quelconque.

Sert aux tests.

* `number` ([UInt64](/fr/reference/data-types/int-uint))
