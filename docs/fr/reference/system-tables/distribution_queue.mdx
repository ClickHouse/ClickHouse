<div id="description">
  ## Description
</div>

Contient des informations sur les fichiers locaux en attente d’envoi vers les shards. Ces fichiers locaux contiennent de nouvelles parts créées lors de l’insertion de nouvelles données dans la table Distributed en mode asynchrone.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `data_path` ([String](/fr/reference/data-types/string)) — Chemin vers le dossier contenant les fichiers locaux.
* `is_blocked` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si l’envoi de fichiers locaux au serveur est bloqué.
* `error_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre d’erreurs.
* `data_files` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de fichiers locaux dans un dossier.
* `data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille, en octets, des données compressées contenues dans les fichiers locaux.
* `broken_data_files` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de fichiers marqués comme corrompus en raison d’une erreur.
* `broken_data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille, en octets, des données compressées contenues dans les fichiers corrompus.
* `last_exception` ([String](/fr/reference/data-types/string)) — Message de la dernière erreur survenue, le cas échéant.
* `last_exception_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure de la dernière exception.

{/*AUTOGENERATED_END*/}
