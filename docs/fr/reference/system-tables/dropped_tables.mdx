<div id="description">
  ## Description
</div>

Contient des informations sur les tables pour lesquelles la commande drop table a été exécutée, mais dont les données n’ont pas encore été nettoyées.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `index` ([UInt32](/fr/reference/data-types/int-uint)) — Index dans la file d’attente marked&#95;dropped&#95;tables.
* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `uuid` ([UUID](/fr/reference/data-types/uuid)) — UUID de la table.
* `engine` ([String](/fr/reference/data-types/string)) — Nom du moteur de table.
* `metadata_dropped_path` ([String](/fr/reference/data-types/string)) — Chemin du fichier de métadonnées de la table dans le répertoire metadata&#95;dropped.
* `table_dropped_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure à laquelle est planifiée la prochaine tentative de suppression des données de la table. Il s’agit généralement de l’heure de suppression de la table, à laquelle s’ajoute `database_atomic_delay_before_drop_table_sec`.

{/*AUTOGENERATED_END*/}

Cette table répertorie uniquement les tables supprimées des bases de données `Atomic`. Pour ces tables, `table_dropped_time` est normalement déterminé par [`database_atomic_delay_before_drop_table_sec`](/fr/reference/settings/server-settings/settings/other#database_atomic_delay_before_drop_table_sec). Pour une base de données `Shared` dans ClickHouse Cloud, la période de récupération est contrôlée par [`database_shared_drop_table_delay_seconds`](/fr/reference/settings/session-settings/database#database_shared_drop_table_delay_seconds), dont la valeur par défaut est de 8 heures ; les tables supprimées des bases de données `Shared` n’apparaissent pas dans `system.dropped_tables`.

<div id="example">
  ## Exemple
</div>

L’exemple suivant montre comment obtenir des informations sur `dropped_tables`.

```sql
SELECT *
FROM system.dropped_tables\G
```

```text
Row 1:
──────
index:                 0
database:              default
table:                 test
uuid:                  03141bb2-e97a-4d7c-a172-95cc066bb3bd
engine:                MergeTree
metadata_dropped_path: /data/ClickHouse/build/programs/data/metadata_dropped/default.test.03141bb2-e97a-4d7c-a172-95cc066bb3bd.sql
table_dropped_time:    2023-03-16 23:43:31
```
