## Description {#description}

Cette table affiche les avertissements relatifs au ClickHouse serveur.
Les avertissements de même type sont regroupés en un seul avertissement.
Par exemple, si le nombre N de bases de données attachées dépasse un seuil configurable T, une seule entrée contenant la valeur actuelle de N est affichée au lieu de N entrées distinctes.
Si la valeur actuelle repasse sous le seuil, l&#39;entrée est supprimée de la table.

La table peut être configurée à l&#39;aide des paramètres suivants :

* [max&#95;table&#95;num&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/fr/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/fr/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## Colonnes {#columns}

* `message` ([String](/fr/reference/data-types/string)) — Un message d’avertissement généré par ClickHouse serveur.
* `message_format_string` ([LowCardinality(String)](/fr/reference/data-types/lowcardinality)) — Une chaîne de formatage utilisée pour formater le message.

## Exemples {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
