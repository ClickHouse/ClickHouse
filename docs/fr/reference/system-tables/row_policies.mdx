<div id="description">
  ## Description
</div>

Contient des filtres pour une table donnée, ainsi qu&#39;une liste de rôles et/ou d&#39;utilisateurs auxquels cette politique de ligne doit s&#39;appliquer.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Nom d&#39;une politique de ligne.
* `short_name` ([String](/fr/reference/data-types/string)) — Nom court d&#39;une politique de ligne. Les noms des politiques de ligne sont composés, par exemple : myfilter ON mydb.mytable. Ici, &#39;myfilter ON mydb.mytable&#39; est le nom de la politique de ligne et &#39;myfilter&#39; son nom court.
* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table. Vide pour une politique de base de données.
* `id` ([UUID](/fr/reference/data-types/uuid)) — ID de la politique de ligne.
* `storage` ([String](/fr/reference/data-types/string)) — Nom du répertoire dans lequel la politique de ligne est stockée.
* `select_filter` ([Nullable(String)](/fr/reference/data-types/nullable)) — Expression utilisée pour filtrer les requêtes SELECT.
* `is_restrictive` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la politique de ligne restreint l&#39;accès aux lignes. Valeurs : • 0 — La politique de ligne est définie avec la clause `AS PERMISSIVE`, • 1 — La politique de ligne est définie avec la clause `AS RESTRICTIVE`.
* `apply_to_all` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si la politique de ligne est définie pour tous les rôles et/ou utilisateurs.
* `apply_to_list` ([Array(String)](/fr/reference/data-types/array)) — Liste des rôles et/ou utilisateurs auxquels la politique de ligne s&#39;applique.
* `apply_to_except` ([Array(String)](/fr/reference/data-types/array)) — La politique de ligne s&#39;applique à tous les rôles et/ou utilisateurs, à l&#39;exception de ceux répertoriés.

{/*AUTOGENERATED_END*/}
