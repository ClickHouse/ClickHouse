## Description {#description}

Contient des informations sur les projections existantes dans toutes les tables.

Les valeurs des colonnes `total_rows`, `data_compressed_bytes` et `data_uncompressed_bytes` correspondent à la somme calculée sur les parties actives de la table qui contiennent la projection. Elles restent donc à zéro tant que la projection n&#39;a pas été construite, par exemple par des insertions effectuées après son ajout ou par `ALTER TABLE ... MATERIALIZE PROJECTION`. Pour connaître la taille de chaque part de projection, consultez [system.projection&#95;parts](/fr/operations/system-tables/projection_parts).

## Colonnes {#columns}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `name` ([String](/fr/reference/data-types/string)) — Nom de la projection.
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/fr/reference/data-types/enum)) — Type de projection.
* `total_rows` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre total de lignes.
* `data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des données compressées, en octets.
* `data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des données décompressées, en octets.
* `sorting_key` ([Array(String)](/fr/reference/data-types/array)) — Clé de tri de la projection.
* `query` ([String](/fr/reference/data-types/string)) — Requête de la projection.
* `settings` ([Map(String, String)](/fr/reference/data-types/map)) — Paramètres de la projection.
