## Description {#description}

Cette table système contient les fichiers de métadonnées des tables Iceberg présentes dans ClickHouse, à raison d&#39;une ligne par fichier de métadonnées. Elle est vide si vous n&#39;avez aucune table Iceberg dans ClickHouse.

## Colonnes {#columns}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `timestamp` ([DateTime64(3)](/fr/reference/data-types/datetime64)) — Date et heure auxquelles ce fichier de métadonnées est devenu le fichier courant.
* `file` ([String](/fr/reference/data-types/string)) — Chemin du fichier de métadonnées.
* `latest_snapshot_id` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — ID du snapshot le plus récent au moment de la création de ce fichier de métadonnées.
* `latest_schema_id` ([Nullable(Int32)](/fr/reference/data-types/nullable)) — Identifiant de schéma du snapshot le plus récent.
* `latest_sequence_number` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Numéro de séquence du snapshot le plus récent.
