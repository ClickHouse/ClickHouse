<div id="description">
  ## Description
</div>

Contient des informations sur les colonnes de toutes les tables.

Vous pouvez utiliser cette table pour obtenir des informations similaires à celles de la requête [DESCRIBE TABLE](/fr/reference/statements/describe-table), mais pour plusieurs tables à la fois.

Les colonnes des [tables temporaires](/fr/reference/statements/create/table/temporary-table) ne sont visibles dans `system.columns` que dans les sessions où elles ont été créées. Elles sont affichées avec le champ `database` vide.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/fr/reference/data-types/string)) — Nom de la base de données.
* `table` ([String](/fr/reference/data-types/string)) — Nom de la table.
* `name` ([String](/fr/reference/data-types/string)) — Nom de la colonne.
* `type` ([String](/fr/reference/data-types/string)) — Type de la colonne.
* `position` ([UInt64](/fr/reference/data-types/int-uint)) — Position ordinale d&#39;une colonne dans une table, à partir de 1.
* `default_kind` ([String](/fr/reference/data-types/string)) — Type d&#39;expression (DEFAULT, MATERIALIZED, ALIAS) associé à la valeur par défaut, ou chaîne vide s&#39;il n&#39;est pas défini.
* `default_expression` ([String](/fr/reference/data-types/string)) — Expression de la valeur par défaut, ou chaîne vide si elle n&#39;est pas définie.
* `data_compressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des données compressées, en octets.
* `data_uncompressed_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des données décompressées, en octets.
* `marks_bytes` ([UInt64](/fr/reference/data-types/int-uint)) — Taille des marques, en octets.
* `comment` ([String](/fr/reference/data-types/string)) — Commentaire sur la colonne, ou chaîne vide s&#39;il n&#39;est pas défini.
* `is_in_partition_key` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant si la colonne figure dans l&#39;expression de partition.
* `is_in_sorting_key` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant si la colonne figure dans l&#39;expression de clé de tri.
* `is_in_primary_key` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant si la colonne figure dans l&#39;expression de clé primaire.
* `is_in_sampling_key` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur signalant si la colonne figure dans l&#39;expression de clé d&#39;échantillonnage.
* `compression_codec` ([String](/fr/reference/data-types/string)) — Nom du codec de compression.
* `character_octet_length` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Longueur maximale, en octets, des données binaires, des données de caractères, des données textuelles et des images. Dans ClickHouse, ce champ n&#39;a de sens que pour le type de données FixedString. Sinon, la valeur NULL est renvoyée.
* `numeric_precision` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Précision des données numériques approximatives, exactes, entières ou monétaires. Dans ClickHouse, il s&#39;agit de la largeur en bits pour les types entiers et de la précision décimale pour les types Decimal. Sinon, la valeur NULL est renvoyée.
* `numeric_precision_radix` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Base du système de numération associée à la précision des données numériques approximatives, exactes, entières ou monétaires. Dans ClickHouse, elle est de 2 pour les types entiers et de 10 pour les types Decimal. Sinon, la valeur NULL est renvoyée.
* `numeric_scale` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Échelle des données numériques approximatives, exactes, entières ou monétaires. Dans ClickHouse, ce champ n&#39;a de sens que pour les types Decimal. Sinon, la valeur NULL est renvoyée.
* `datetime_precision` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Précision décimale du type de données DateTime64. Pour les autres types de données, la valeur NULL est renvoyée.
* `serialization_hint` ([Nullable(String)](/fr/reference/data-types/nullable)) — Indication permettant à la colonne de choisir la sérialisation lors des insertions en fonction des statistiques.
* `statistics` ([String](/fr/reference/data-types/string)) — Types de statistiques créées dans cette colonne.

**Alias :**

* `column` — Alias de `name`.

{/*AUTOGENERATED_END*/}
