## Description {#description}

Affiche les [watches](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches) actuellement actives enregistrées par ce serveur ClickHouse sur des nœuds ZooKeeper (y compris sur les ZooKeepers auxiliaires). Chaque ligne correspond à une watch.

**Disponibilité**

`system.zookeeper_watches` n&#39;existe que lorsque ClickHouse Keeper ou ZooKeeper est configuré. Sur les serveurs où aucun des deux n&#39;est configuré, la table n&#39;existe pas et les requêtes qui la ciblent échouent avec `UNKNOWN_TABLE`.

## Colonnes {#columns}

* `zookeeper_name` ([String](/fr/reference/data-types/string)) — Nom de la connexion ZooKeeper (&quot;default&quot; pour la connexion principale ou le nom auxiliaire).
* `create_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure à laquelle la watch a été créée.
* `create_time_microseconds` ([DateTime64(6)](/fr/reference/data-types/datetime64)) — Heure à laquelle la watch a été créée, avec une précision à la microseconde.
* `path` ([String](/fr/reference/data-types/string)) — Chemin ZooKeeper surveillé.
* `session_id` ([Int64](/fr/reference/data-types/int-uint)) — ID de session de la connexion qui a enregistré la watch.
* `request_xid` ([Int64](/fr/reference/data-types/int-uint)) — XID de la requête qui a créé la watch.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/fr/reference/data-types/enum)) — Opération qui a créé la watch.
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/fr/reference/data-types/enum)) — Type de watch : Children (list), Exists ou Data (get).
