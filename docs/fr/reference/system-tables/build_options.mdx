## Description {#description}

Contient des informations sur les options de compilation du serveur ClickHouse.

## Colonnes {#columns}

* `name` ([String](/fr/reference/data-types/string)) — Nom de l’option de compilation.
* `value` ([String](/fr/reference/data-types/string)) — Valeur de l’option de compilation.

## Exemple {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
