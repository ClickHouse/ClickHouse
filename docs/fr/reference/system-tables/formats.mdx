<div id="description">
  ## Description
</div>

Contient la liste de tous les formats, avec des indicateurs précisant si chaque format convient à l’entrée/sortie et s’il prend en charge la parallélisation.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Nom du format.
* `is_input` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si le format est adapté à l’entrée de données.
* `is_output` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si le format est adapté à la sortie de données.
* `supports_parallel_parsing` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si le format prend en charge l’analyse parallèle.
* `supports_parallel_formatting` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si le format prend en charge le formatage parallèle.
* `is_tty_friendly` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si le format s’affiche généralement correctement dans le terminal. Pour les autres formats, la CLI demande confirmation avant d’afficher la sortie.
* `content_type` ([String](/fr/reference/data-types/string)) — En-tête HTTP Content-Type correspondant au format de sortie. Peut dépendre des paramètres actuels du format.
* `supports_random_access` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si le format prend en charge l’accès aléatoire en entrée.
* `has_schema_inference` ([UInt8](/fr/reference/data-types/int-uint)) — Le format peut déduire dynamiquement le schéma à partir des données (soit de l’en-tête ou des métadonnées intégrés, soit des données elles-mêmes).
* `has_external_schema` ([UInt8](/fr/reference/data-types/int-uint)) — Le format possède un schéma fixe ou accepte un schéma prédéfini dans son propre format.
* `prefers_large_blocks` ([UInt8](/fr/reference/data-types/int-uint)) — Le format écrit des blocs plus volumineux en sortie et génère des blocs plus volumineux en entrée.
* `supports_append` ([UInt8](/fr/reference/data-types/int-uint)) — Il est possible d’ajouter des données à un même fichier avec ce format.
* `supports_subsets_of_columns` ([UInt8](/fr/reference/data-types/int-uint)) — Le format d’entrée peut détecter l’omission de certaines colonnes.
* `description` ([String](/fr/reference/data-types/string)) — Description générale du format.
* `examples` ([String](/fr/reference/data-types/string)) — Exemples d’utilisation.
* `introduced_in` ([String](/fr/reference/data-types/string)) — Version de ClickHouse dans laquelle le format a été introduit, sous la forme majeure.mineure.
* `related` ([Array(String)](/fr/reference/data-types/array)) — Noms des formats associés.

{/*AUTOGENERATED_END*/}
