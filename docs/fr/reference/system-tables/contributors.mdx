## Description {#description}

Contient des informations sur les contributeurs. L’ordre est aléatoire lors de l’exécution de la requête.

## Colonnes {#columns}

* `name` ([String](/fr/reference/data-types/string)) — Nom du contributeur (auteur) issu de git log.

## Exemple {#example}

```sql
SELECT * FROM system.contributors LIMIT 10
```

```text
┌─name─────────────┐
│ Olga Khvostikova │
│ Max Vetrov       │
│ LiuYangkuan      │
│ svladykin        │
│ zamulla          │
│ Šimon Podlipský  │
│ BayoNet          │
│ Ilya Khomutov    │
│ Amy Krishnevsky  │
│ Loud_Scream      │
└──────────────────┘
```

Pour trouver votre entrée dans la table, utilisez une requête :

```sql
SELECT * FROM system.contributors WHERE name = 'Olga Khvostikova'
```

```text
┌─name─────────────┐
│ Olga Khvostikova │
└──────────────────┘
```
