<div id="description">
  ## Description
</div>

Contient une liste de [comptes utilisateur](/fr/concepts/features/security/access-rights#user-account-management) configurés sur le serveur.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Nom de l’utilisateur.
* `id` ([UUID](/fr/reference/data-types/uuid)) — ID de l’utilisateur.
* `storage` ([String](/fr/reference/data-types/string)) — Chemin vers le stockage des utilisateurs. Configuré dans le paramètre access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/fr/reference/data-types/array)) — Affiche les types d’authentification. Plusieurs méthodes permettent d’identifier les utilisateurs : sans mot de passe, avec un mot de passe en texte brut, avec un mot de passe chiffré avec SHA256, avec un mot de passe chiffré avec un double SHA-1 ou avec un mot de passe chiffré avec bcrypt.
* `auth_params` ([Array(String)](/fr/reference/data-types/array)) — Paramètres d’authentification au format JSON, selon auth&#95;type.
* `valid_until` ([Array(DateTime64(0))](/fr/reference/data-types/array)) — Date et heure d’expiration des informations d’identification de l’utilisateur, une par méthode d’authentification. La valeur stockée est un instant absolu affiché dans le fuseau horaire du serveur ou de la session ; la valeur stockée `0` (l’époque Unix, affichée sous la forme `1970-01-01 00:00:00` sur un serveur en `UTC`) est une valeur sentinelle indiquant que les informations d’identification n’expirent jamais.
* `auth_grants` ([Array(String)](/fr/reference/data-types/array)) — Pour chaque méthode d’authentification : la restriction des droits d’accès spécifiée dans la clause `GRANTS`, ou une chaîne vide si les droits d’accès ne sont pas limités.
* `host_ip` ([Array(String)](/fr/reference/data-types/array)) — Adresses IP des hôtes autorisés à se connecter au serveur ClickHouse.
* `host_names` ([Array(String)](/fr/reference/data-types/array)) — Noms des hôtes autorisés à se connecter au serveur ClickHouse.
* `host_names_regexp` ([Array(String)](/fr/reference/data-types/array)) — Expression régulière correspondant aux noms d’hôtes autorisés à se connecter au serveur ClickHouse.
* `host_names_like` ([Array(String)](/fr/reference/data-types/array)) — Noms des hôtes autorisés à se connecter au serveur ClickHouse, définis à l’aide du prédicat LIKE.
* `default_roles_all` ([UInt8](/fr/reference/data-types/int-uint)) — Indique que tous les rôles accordés sont définis par défaut pour l’utilisateur.
* `default_roles_list` ([Array(String)](/fr/reference/data-types/array)) — Liste des rôles accordés définis par défaut.
* `default_roles_except` ([Array(String)](/fr/reference/data-types/array)) — Tous les rôles accordés sont définis par défaut, à l’exception de ceux répertoriés.
* `grantees_any` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur précisant si un utilisateur disposant d’une option d’attribution peut l’accorder à n’importe qui.
* `grantees_list` ([Array(String)](/fr/reference/data-types/array)) — Liste des utilisateurs ou des rôles auxquels cet utilisateur est autorisé à accorder des options.
* `grantees_except` ([Array(String)](/fr/reference/data-types/array)) — Liste des utilisateurs ou des rôles auxquels cet utilisateur n’est pas autorisé à accorder des options.
* `default_database` ([String](/fr/reference/data-types/string)) — Nom de la base de données par défaut de cet utilisateur.
