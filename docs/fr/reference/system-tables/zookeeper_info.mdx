## Description {#description}

Cette table fournit des informations d’introspection combinées sur ZooKeeper, et les nœuds sont extraits de la configuration.

**Disponibilité**

`system.zookeeper_info` n’existe que lorsque ClickHouse Keeper ou ZooKeeper est configuré. Sur les serveurs où aucun des deux n’est configuré, la table n’existe pas et les requêtes qui la ciblent échouent avec `UNKNOWN_TABLE`.

## Colonnes {#columns}

* `zookeeper_cluster_name` ([String](/fr/reference/data-types/string)) — Nom du cluster ZooKeeper.
* `host` ([String](/fr/reference/data-types/string)) — Le hostname/IP du nœud ZooKeeper auquel ClickHouse s&#39;est connecté.
* `port` ([UInt16](/fr/reference/data-types/int-uint)) — Le port du nœud ZooKeeper auquel ClickHouse s&#39;est connecté.
* `index` ([Nullable(UInt8)](/fr/reference/data-types/nullable)) — L&#39;index du nœud ZooKeeper auquel ClickHouse s&#39;est connecté. Cet index provient de la configuration ZooKeeper. En l&#39;absence de connexion, cette colonne vaut NULL.
* `is_connected` ([UInt8](/fr/reference/data-types/int-uint)) — Indique si ZooKeeper est connecté.
* `is_readonly` ([Nullable(UInt8)](/fr/reference/data-types/nullable)) — Indique s&#39;il est en readonly.
* `version` ([Nullable(String)](/fr/reference/data-types/nullable)) — La version de ZooKeeper.
* `avg_latency` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — La latence moyenne.
* `max_latency` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — La latence maximale.
* `min_latency` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — La latence minimale.
* `packets_received` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de paquets reçus.
* `packets_sent` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de paquets envoyés.
* `outstanding_requests` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de requests en attente.
* `server_state` ([Nullable(String)](/fr/reference/data-types/nullable)) — État du serveur.
* `is_leader` ([Nullable(UInt8)](/fr/reference/data-types/nullable)) — Indique si ce ZooKeeper est le leader.
* `znode_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de znodes.
* `watch_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de watch.
* `ephemerals_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de nœuds ephemeral.
* `approximate_data_size` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — La taille approximative des données.
* `followers` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Les followers du leader. Ce champ n&#39;est exposé que par le leader.
* `synced_followers` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Les followers synchronisés du leader. Ce champ n&#39;est exposé que par le leader.
* `pending_syncs` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Les synchronisations en attente du leader. Ce champ n&#39;est exposé que par le leader.
* `open_file_descriptor_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de file descriptors ouverts. Disponible uniquement sur les plateformes Unix.
* `max_file_descriptor_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre maximal de file descriptors. Disponible uniquement sur les plateformes Unix.
* `connections` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Les connexions ZooKeeper.
* `outstanding` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre d&#39;opérations ZooKeeper en attente.
* `zxid` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Le zxid ZooKeeper.
* `node_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le nombre de nœuds ZooKeeper.
* `snapshot_dir_size` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — La taille du répertoire de snapshots ZooKeeper.
* `log_dir_size` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — La taille du répertoire de log ZooKeeper.
* `first_log_idx` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — L&#39;index du premier log ZooKeeper.
* `first_log_term` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le terme du premier log ZooKeeper.
* `last_log_idx` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — L&#39;index du last log ZooKeeper.
* `last_log_term` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le terme du last log ZooKeeper.
* `last_committed_idx` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Le dernier index committed ZooKeeper.
* `leader_committed_log_idx` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — L&#39;index du log committed par le leader ZooKeeper.
* `target_committed_log_idx` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — L&#39;index du log committed cible ZooKeeper.
* `last_snapshot_idx` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — L&#39;index du dernier snapshot ZooKeeper.
