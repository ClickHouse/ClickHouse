<div id="description">
  ## Description
</div>

Contient l’état en mémoire des métadonnées S3Queue ainsi que les lignes actuellement traitées pour chaque fichier.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/fr/reference/data-types/string)) — Chemin vers les métadonnées dans ZooKeeper
* `file_path` ([String](/fr/reference/data-types/string)) — Chemin du fichier en cours de traitement
* `file_name` ([String](/fr/reference/data-types/string)) — Nom du fichier en cours de traitement
* `rows_processed` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de lignes en cours de traitement
* `status` ([String](/fr/reference/data-types/string)) — Statut du traitement : Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Heure de début du traitement du fichier
* `processing_end_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Heure de fin du traitement du fichier
* `exception` ([String](/fr/reference/data-types/string)) — Exception survenue pendant le traitement

{/*AUTOGENERATED_END*/}
