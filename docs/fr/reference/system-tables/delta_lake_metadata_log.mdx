## Description {#description}

La table `system.delta_lake_metadata_log` enregistre les événements d&#39;accès et de parsing des métadonnées pour les tables Delta Lake lues par ClickHouse. Elle fournit des informations détaillées sur chaque fichier de métadonnées, ce qui s&#39;avère utile pour le débogage, l&#39;audit et la compréhension de l&#39;évolution de la structure des tables Delta.

Cette table journalise chaque fichier de métadonnées lu depuis les tables Delta Lake. Elle aide les utilisateurs à retracer la façon dont ClickHouse interprète les métadonnées des tables Delta et à diagnostiquer les problèmes liés à l&#39;évolution du schéma, à la résolution des snapshots ou à la planification des requêtes.

Cette table est principalement destinée au débogage.

### Contrôler la verbosité des logs {#controlling-log-verbosity}

Vous pouvez définir quels événements de métadonnées sont journalisés à l&#39;aide du paramètre [`delta_lake_log_metadata`](/fr/reference/settings/session-settings/delta-lake#delta_lake_log_metadata).

Pour journaliser toutes les métadonnées utilisées dans la requête courante :

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

Vous pouvez tronquer ou supprimer cette table à tout moment sans risque.

* `content` ([String](/fr/reference/data-types/string)) — Contenu au format JSON.
