<div id="description">
  ## Description
</div>

Contient des informations sur les [nœuds d’ordonnancement](/fr/concepts/features/configuration/server-config/workload-scheduling#hierarchy) présents sur le serveur local, ainsi que sur leur statut.
Cette table peut être utilisée à des fins de surveillance. Elle contient une ligne pour chaque nœud d’ordonnancement.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `resource` ([String](/fr/reference/data-types/string)) — Nom de la ressource
* `path` ([String](/fr/reference/data-types/string)) — Chemin vers un nœud de planification dans cette hiérarchie de planification des ressources
* `type` ([String](/fr/reference/data-types/string)) — Type de nœud de planification.
* `weight` ([Float64](/fr/reference/data-types/float)) — Poids d’un nœud, utilisé par un nœud parent de type `fair`.
* `priority` ([Int64](/fr/reference/data-types/int-uint)) — Priorité d’un nœud, utilisée par un nœud parent de type &#39;priority&#39; (une valeur inférieure correspond à une priorité plus élevée).
* `precedence` ([Int64](/fr/reference/data-types/int-uint)) — Préséance d’un nœud, utilisée par les nœuds parents à partage d’espace (mémoire) pour ordonner l’admission et l’éviction (une valeur inférieure correspond à une préséance plus élevée).
* `is_active` ([Nullable(UInt8)](/fr/reference/data-types/nullable)) — Indique si ce nœud est actuellement actif, c’est-à-dire s’il comporte des requêtes de ressources à retirer de la file d’attente et si ses contraintes sont satisfaites.
* `active_children` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre d’enfants à l’état actif.
* `dequeued_requests` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de requêtes de ressources retirées de la file d’attente depuis ce nœud.
* `canceled_requests` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de requêtes de ressources annulées depuis ce nœud.
* `rejected_requests` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de requêtes de ressources rejetées depuis ce nœud.
* `dequeued_cost` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Somme des coûts (p. ex. taille en octets) de toutes les requêtes retirées de la file d’attente depuis ce nœud.
* `canceled_cost` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Somme des coûts (p. ex. taille en octets) de toutes les requêtes annulées depuis ce nœud.
* `rejected_cost` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Somme des coûts (p. ex. taille en octets) de toutes les requêtes rejetées depuis ce nœud.
* `busy_periods` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre total de désactivations de ce nœud.
* `throughput` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — Débit moyen actuel (coût retiré de la file d’attente par seconde).
* `vruntime` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — Uniquement pour les enfants de nœuds `fair`. Temps d’exécution virtuel d’un nœud, utilisé par l’algorithme SFQ pour sélectionner le prochain enfant à traiter selon une répartition équitable max-min.
* `system_vruntime` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `fair`. Temps d’exécution virtuel indiquant le `vruntime` de la dernière requête de ressources traitée. Utilisé lors de l’activation d’un enfant comme nouvelle valeur de `vruntime`.
* `queue_length` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `fifo`. Nombre actuel de requêtes de ressources dans la file d’attente.
* `queue_cost` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `fifo`. Somme des coûts (p. ex. taille en octets) de toutes les requêtes présentes dans la file d’attente.
* `budget` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `fifo`. Nombre d&#39;unités de coût&#39; disponibles pour les nouvelles requêtes de ressources. Peut apparaître en cas d’écart entre les coûts estimés et réels des requêtes de ressources (p. ex. après un échec de lecture/écriture).
* `is_satisfied` ([Nullable(UInt8)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds de contrainte (p. ex. `inflight_limit`). Est égal à `1` si toutes les contraintes de ce nœud sont satisfaites.
* `inflight_requests` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Nombre de requêtes de ressources retirées de la file d’attente depuis ce nœud et actuellement en cours de consommation.
* `inflight_cost` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Somme des coûts (p. ex. octets) de toutes les requêtes de ressources retirées de la file d’attente depuis ce nœud et actuellement en cours de consommation.
* `max_requests` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Limite supérieure de `inflight_requests` entraînant une violation de contrainte.
* `max_cost` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `inflight_limit`. Limite supérieure de inflight&#95;cost entraînant une violation de contrainte.
* `max_speed` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Limite supérieure du débit, en tokens par seconde.
* `max_burst` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Limite supérieure du nombre de tokens disponibles dans le limiteur à compartiment de jetons.
* `throttling_us` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Nombre total de microsecondes pendant lesquelles ce nœud était en état de limitation.
* `tokens` ([Nullable(Float64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `bandwidth_limit`. Nombre de tokens actuellement disponibles dans le limiteur à compartiment de jetons.
* `allocated` ([Nullable(Int64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Quantité de ressources actuellement allouée sous ce nœud.
* `allocations` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre actuel d&#39;allocations de ressources en cours sous ce nœud.
* `updates` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total de mises à jour propagées via ce nœud.
* `increases` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total de demandes d&#39;augmentation approuvées par ce nœud.
* `decreases` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total de demandes de réduction approuvées par ce nœud.
* `admits` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total d&#39;allocations admises par ce nœud.
* `removes` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total d&#39;allocations supprimées de ce nœud.
* `killers` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total d&#39;évictions déclenchées par ce nœud à la suite de demandes d&#39;augmentation.
* `victims` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds space-shared. Nombre total d&#39;allocations évincées de ce nœud.
* `rejects` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `allocation_queue`. Nombre total d&#39;allocations de ressources rejetées par ce nœud.
* `pending` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Uniquement pour les nœuds `allocation_queue`. Nombre actuel d&#39;allocations de ressources en attente dans ce nœud.

{/*AUTOGENERATED_END*/}
