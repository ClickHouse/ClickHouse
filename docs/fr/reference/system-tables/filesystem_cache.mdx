<div id="description">
  ## Description
</div>

Contient des informations sur toutes les entrées du cache du système de fichiers associées aux objets distants.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/fr/reference/data-types/string)) — Nom de l&#39;objet cache. Peut être utilisé dans les commandes `SYSTEM DESCRIBE FILESYSTEM CACHE <name>` et `SYSTEM DROP FILESYSTEM CACHE <name>`
* `cache_base_path` ([String](/fr/reference/data-types/string)) — Chemin du répertoire de base dans lequel sont stockés tous les fichiers du cache identifié par `cache_name`.
* `cache_path` ([String](/fr/reference/data-types/string)) — Chemin d&#39;un fichier de cache particulier, correspondant à un segment de fichier d&#39;un fichier source
* `key` ([String](/fr/reference/data-types/string)) — Clé de cache du segment de fichier
* `file_segment_range_begin` ([UInt64](/fr/reference/data-types/int-uint)) — Décalage correspondant au début de la plage du segment de fichier
* `file_segment_range_end` ([UInt64](/fr/reference/data-types/int-uint)) — Décalage correspondant à la fin incluse de la plage du segment de fichier
* `size` ([UInt64](/fr/reference/data-types/int-uint)) — Taille du segment de fichier
* `state` ([String](/fr/reference/data-types/string)) — État du segment de fichier (DOWNLOADED, DOWNLOADING, PARTIALLY&#95;DOWNLOADED, ...)
* `finished_download_time` ([DateTime](/fr/reference/data-types/datetime)) — Heure à laquelle le téléchargement du segment de fichier s&#39;est terminé.
* `cache_hits` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de succès de cache du segment de fichier correspondant
* `references` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de références au segment de fichier correspondant. Une valeur de 1 signifie que personne ne l&#39;utilise actuellement (la seule référence existante est celle du stockage du cache lui-même)
* `downloaded_size` ([UInt64](/fr/reference/data-types/int-uint)) — Taille téléchargée du segment de fichier
* `kind` ([String](/fr/reference/data-types/string)) — Type de segment de fichier (utilisé pour distinguer les segments de fichier ajoutés dans le cadre des &#39;données temporaires dans le cache&#39;)
* `unbound` ([UInt8](/fr/reference/data-types/int-uint)) — Indicateur interne d&#39;implémentation
* `user_id` ([String](/fr/reference/data-types/string)) — ID de l&#39;utilisateur ayant créé le segment de fichier
* `segment_type` ([String](/fr/reference/data-types/string)) — Type de segment. Utilisé pour distinguer les fichiers de données (`.json`, `.txt`, etc.) des fichiers de données (`.bin`, fichiers de marques).
* `file_size` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Taille du fichier auquel appartient le segment de fichier actuel

{/*AUTOGENERATED_END*/}
