<div id="description">
  ## Description
</div>

Contient le nombre actuel de nœuds traités, en cours de traitement et ayant échoué dans Keeper pour chaque objet de métadonnées AzureQueue ainsi que, à la demande, leur contenu. Contrairement à system.azure&#95;queue&#95;metadata&#95;cache, qui affiche le cache en mémoire, cette table lit l’état directement depuis Keeper.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `zookeeper_path` ([String](/fr/reference/data-types/string)) — Chemin vers les métadonnées dans ZooKeeper. Pour une queue sur un ZooKeeper auxiliaire, il s’agit de la clé de fabrique `<zookeeper_name>:<path>`, et non du chemin Keeper brut.
* `processed_nodes_count` ([Nullable(UInt64)](/fr/reference/data-types/nullable)) — Nombre de nœuds dans le répertoire `processed` de Keeper. Défini uniquement pour le mode `unordered` : en mode `ordered`, il n’existe pas de nœuds traités par fichier (voir plutôt `processed_path`) ; la valeur est donc NULL.
* `processing_nodes_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de nœuds dans le répertoire `processing` de Keeper
* `failed_nodes_count` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de nœuds dans le répertoire `failed` de Keeper
* `processed_nodes` ([Map(String, String)](/fr/reference/data-types/map)) — Contenu du répertoire `processed` de Keeper (nom du nœud -&gt; données du nœud). Rempli uniquement pour le mode `unordered`. Récupéré uniquement lorsque cette colonne est sélectionnée.
* `processing_nodes` ([Map(String, String)](/fr/reference/data-types/map)) — Contenu du répertoire `processing` de Keeper (nom du nœud -&gt; données du nœud). Récupéré uniquement lorsque cette colonne est sélectionnée.
* `failed_nodes` ([Map(String, String)](/fr/reference/data-types/map)) — Contenu du répertoire `failed` de Keeper (nom du nœud -&gt; données du nœud). Récupéré uniquement lorsque cette colonne est sélectionnée.
* `processed_path` ([Map(String, String)](/fr/reference/data-types/map)) — Dernier chemin traité pour chaque pointeur de traitement dans Keeper (chemin de pointeur relatif -&gt; chemin du dernier fichier traité). Rempli uniquement pour le mode `ordered`, où il couvre les pointeurs unique, par bucket et par partition. Récupéré uniquement lorsque cette colonne est sélectionnée.
