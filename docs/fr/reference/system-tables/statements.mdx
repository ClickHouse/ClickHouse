<div id="description">
  ## Description
</div>

Contient la liste de toutes les instructions SQL de ClickHouse.

<div id="columns">
  ## Colonnes
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/fr/reference/data-types/string)) — Le nom de l&#39;instruction SQL.
* `syntax` ([String](/fr/reference/data-types/string)) — La syntaxe de l&#39;instruction.
* `description` ([String](/fr/reference/data-types/string)) — Une description de l&#39;instruction, avec des exemples d&#39;utilisation.
* `parent_name` ([String](/fr/reference/data-types/string)) — Le nom de l&#39;instruction parente, par exemple SELECT pour la clause WHERE. Vide pour une instruction de premier niveau.
* `related` ([Array(String)](/fr/reference/data-types/array)) — Les noms des instructions associées.

{/*AUTOGENERATED_END*/}
