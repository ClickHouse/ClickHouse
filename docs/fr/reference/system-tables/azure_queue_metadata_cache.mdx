## Description {#description}

Contient l’état en mémoire des métadonnées d’AzureQueue et les lignes en cours de traitement pour chaque fichier.

## Colonnes {#columns}

* `zookeeper_path` ([String](/fr/reference/data-types/string)) — Chemin dans ZooKeeper vers les métadonnées
* `file_path` ([String](/fr/reference/data-types/string)) — Chemin du fichier en cours de traitement
* `file_name` ([String](/fr/reference/data-types/string)) — Nom du fichier en cours de traitement
* `rows_processed` ([UInt64](/fr/reference/data-types/int-uint)) — Nombre de lignes actuellement traitées
* `status` ([String](/fr/reference/data-types/string)) — État du traitement : Processed, Processing, Failed, ou None pour un fichier que le cache connaît mais pour lequel il n&#39;a aucun état, par exemple un fichier dont le traitement a été réinitialisé. Une valeur non nulle de `processing_observed_in_keeper_time` signifie que l&#39;état `Processing` n&#39;a pas été défini par le processor qui détient le fichier, mais lu depuis Keeper
* `processing_start_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Heure de début du traitement du fichier
* `processing_end_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Heure de fin du traitement du fichier
* `exception` ([String](/fr/reference/data-types/string)) — Exception survenue pendant le traitement. Toujours celle de la dernière tentative de ce serveur, jamais celle que Keeper stocke pour le fichier
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/fr/reference/data-types/nullable)) — Heure à laquelle un processor de ce serveur n&#39;a pas réussi à prendre le fichier et a lu l&#39;état `Processing` depuis Keeper au lieu de le définir lui-même. Habituellement, le fichier est détenu par un autre serveur, mais il peut aussi l&#39;être par un processor de ce serveur qui venait de le prendre. Dans les deux cas, `rows_processed`, `processing_start_time`, `processing_end_time` et `exception` décrivent la dernière tentative de ce serveur de traiter le fichier, et non le traitement qui le détient actuellement
