Las funciones de tabla son métodos para crear tablas.

{/*AUTOGENERATED_START*/ }

{/*AUTOGENERATED_END*/ }

<div id="usage">
  ## Uso
</div>

Las funciones de tabla pueden usarse en la cláusula [`FROM`](../../sql-reference/statements/select/from.md)
de una consulta `SELECT`. Por ejemplo, puedes usar `SELECT` para leer datos de un archivo en tu equipo local
mediante la función de tabla `file`.

```bash title="Query"
echo "1, 2, 3" > example.csv
```

```text title="Response"
./clickhouse client
:) SELECT * FROM file('example.csv')
┌─c1─┬─c2─┬─c3─┐
│  1 │  2 │  3 │
└────┴────┴────┘
```

También puede utilizar funciones de tabla para crear una tabla temporal que esté disponible
solo en la consulta actual. Por ejemplo:

```sql title="Query"
SELECT * FROM generateSeries(1,5);
```

```response title="Response"
┌─generate_series─┐
│               1 │
│               2 │
│               3 │
│               4 │
│               5 │
└─────────────────┘
```

La tabla se elimina cuando finaliza la consulta.

Las funciones de tabla pueden usarse para crear tablas, con la siguiente sintaxis:

```sql title="Query"
CREATE TABLE [IF NOT EXISTS] [db.]table_name AS table_function()
```

Por ejemplo:

```sql title="Query"
CREATE TABLE series AS generateSeries(1, 5);
SELECT * FROM series;
```

```response title="Response"
┌─generate_series─┐
│               1 │
│               2 │
│               3 │
│               4 │
│               5 │
└─────────────────┘
```

Por último, las funciones de tabla se pueden usar para `INSERT` datos en una tabla. Por ejemplo,
podríamos escribir el contenido de la tabla que creamos en el ejemplo anterior
en un archivo del disco usando de nuevo la función de tabla `file`:

```sql title="Query"
INSERT INTO FUNCTION file('numbers.csv', 'CSV') SELECT * FROM series;
```

```bash title="Query"
cat numbers.csv
1
2
3
4
5
```

:::note
No se pueden usar las funciones de tabla si la configuración [allow&#95;ddl](/es/operations/settings/settings#allow_ddl) está deshabilitada.
:::
