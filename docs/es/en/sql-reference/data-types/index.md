Esta sección describe los tipos de datos admitidos por ClickHouse, por ejemplo [enteros](int-uint.md), [flotantes](float.md) y [cadenas](string.md).

La tabla del sistema [system.data&#95;type&#95;families](/es/operations/system-tables/data_type_families) proporciona una
descripción general de todos los tipos de datos disponibles.
También muestra si un tipo de dato es un alias de otro y si su nombre es sensible a mayúsculas y minúsculas (p. ej., `bool` frente a `BOOL`).
