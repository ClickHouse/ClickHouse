Da formato a las filas de cada grupo mediante un formato de salida y devuelve los datos formateados como una cadena. Es similar a `formatRow`, pero funciona con el grupo completo y puede usar formatos basados en bloques.

:::warning
Todas las filas de cada grupo se acumulan en memoria antes de generar la cadena formateada. En grupos con una cantidad muy grande de filas, esto puede consumir una cantidad considerable de memoria. Considere usar `LIMIT` dentro de subconsultas o dividir los grupos grandes para mantener el uso de memoria bajo control.
:::

<div id="syntax">
  ## Sintaxis
</div>

```sql
groupFormat(format)(x, y, ...)
```

<div id="parameters">
  ## Parámetros
</div>

* `format` — Nombre del formato de salida, por ejemplo `JSONEachRow`, `CSV`, `TabSeparated`.

<div id="arguments">
  ## Argumentos
</div>

* `x, y, ...` — Expresiones que se formatearán como filas. Se requiere al menos un argumento.

<div id="returned-value">
  ## Valor devuelto
</div>

* Un [String](../../data-types/string.md) que contiene la salida formateada del grupo.

:::note
Los nombres de las columnas en la salida formateada se generan como `c1`, `c2`, ... en el orden de los argumentos.

No se garantiza el orden exacto de las filas formateadas.

Los ajustes de formato de la consulta (por ejemplo, `format_csv_delimiter` o `output_format_json_quote_64bit_integers`) se capturan cuando se inicializa la función de agregación y se usan para generar la salida. La opción `output_format_write_statistics` siempre se desactiva, por lo que la cadena formateada nunca contiene una sección de estadísticas.
:::

<div id="null-handling">
  ## Manejo de NULL
</div>

Al igual que `groupArray` y `groupConcat`, `groupFormat` omite una fila cuando cualquiera de sus argumentos es `NULL`; esas filas no aparecen en la salida formateada. Cuando un argumento es Nullable, el tipo de resultado es `Nullable(String)`, y un grupo en el que se omiten todas las filas — así como un argumento `NULL` literal sin tipo de tipo `Nullable(Nothing)` — devuelve `NULL` a través del combinador genérico `Null`.

```sql
SELECT groupFormat('JSONEachRow')(if(number = 0, NULL, number))
FROM numbers(3);
-- {"c1":1}
-- {"c1":2}
```

<div id="examples">
  ## Ejemplos
</div>

<div id="example-json">
  ### Uso básico con JSONEachRow
</div>

```sql
SELECT groupFormat('JSONEachRow')(number, toString(number))
FROM numbers(3);
```

Resultado:

```text
{"c1":0,"c2":"0"}
{"c1":1,"c2":"1"}
{"c1":2,"c2":"2"}
```
