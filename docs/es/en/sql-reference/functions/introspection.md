Puede usar las funciones descritas en este capítulo para examinar [ELF](https://en.wikipedia.org/wiki/Executable_and_Linkable_Format) y [DWARF](https://en.wikipedia.org/wiki/DWARF) para el perfilado de consultas.

:::note
Estas funciones son lentas y pueden plantear consideraciones de seguridad.
:::

Para que las funciones de introspección funcionen correctamente:

* Instale el paquete `clickhouse-common-static-dbg`.

* Establezca la configuración [allow&#95;introspection&#95;functions](../../operations/settings/settings.md#allow_introspection_functions) en 1.

  Por motivos de seguridad, las funciones de introspección están deshabilitadas de forma predeterminada.

ClickHouse guarda los informes del profiler en la tabla del sistema [trace&#95;log](/es/operations/system-tables/trace_log). Asegúrese de que la tabla y el profiler estén configurados correctamente.
