<div id="untuple">
  ## untuple
</div>

Realiza la sustitución sintáctica de los elementos de [tupla](/es/sql-reference/data-types/tuple) en el lugar de la llamada.

Los nombres de las columnas del resultado dependen de la implementación y pueden cambiar. No asuma nombres de columnas concretos después de `untuple`.

**Sintaxis**

```sql
untuple(x)
```

Puede usar la expresión `EXCEPT` para omitir columnas en el resultado de la consulta.

**Argumentos**

* `x` — Una función `tuple`, una columna o una tupla de elementos. [Tuple](../data-types/tuple.md).

**Valor devuelto**

* Ninguno.

**Ejemplos**

Tabla de entrada:

```text
┌─key─┬─v1─┬─v2─┬─v3─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 20 │ 40 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 65 │ 70 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 30 │ 20 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 12 │  7 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 50 │ 70 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴────┴────┴───────────┘
```

Ejemplo de uso de una columna de tipo `Tuple` como parámetro de la función `untuple`:

```sql title="Query"
SELECT untuple(v6) FROM kv;
```

```text title="Response"
┌─_ut_1─┬─_ut_2─┐
│    33 │ ab    │
│    44 │ cd    │
│    55 │ ef    │
│    66 │ gh    │
│    77 │ kl    │
└───────┴───────┘
```

Ejemplo de uso de la expresión `EXCEPT`:

```sql title="Query"
SELECT untuple((* EXCEPT (v2, v3),)) FROM kv;
```

```text title="Response"
┌─key─┬─v1─┬─v4─┬─v5─┬─v6────────┐
│   1 │ 10 │ 30 │ 15 │ (33,'ab') │
│   2 │ 25 │ 40 │  6 │ (44,'cd') │
│   3 │ 57 │ 10 │  5 │ (55,'ef') │
│   4 │ 55 │ 80 │ 90 │ (66,'gh') │
│   5 │ 30 │ 25 │ 55 │ (77,'kl') │
└─────┴────┴────┴────┴───────────┘
```
