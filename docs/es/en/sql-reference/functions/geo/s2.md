<div id="s2index">
  ## S2Index
</div>

[S2](https://s2geometry.io/) es un sistema de indexación geográfica en el que todos los datos geográficos se representan sobre una esfera (similar a un globo terráqueo).

En la biblioteca S2, los puntos se representan como el índice S2: un número concreto que codifica internamente un punto en la superficie de una esfera unitaria, en lugar de los pares tradicionales de (latitud, longitud). Para obtener el índice de punto S2 de un punto dado especificado en el formato (latitud, longitud), use la función [geoToS2](#geotos2). Además, puede usar la función [s2ToGeo](#s2togeo) para obtener las coordenadas geográficas correspondientes al índice de punto S2 especificado.

<div id="geotos2">
  ## geoToS2
</div>

Devuelve el [índice](#s2index) del punto S2 correspondiente a las coordenadas proporcionadas `(longitud, latitud)`.

**Sintaxis**

```sql
geoToS2(lon, lat)
```

**Argumentos**

* `lon` — Longitud. [Float64](../../data-types/float.md).
* `lat` — Latitud. [Float64](../../data-types/float.md).

**Valores devueltos**

* Índice de punto S2. [UInt64](../../data-types/int-uint.md).

**Ejemplo**

```sql title="Query"
SELECT geoToS2(37.79506683, 55.71290588) AS s2Index;
```

```text title="Response"
┌─────────────s2Index─┐
│ 4704772434919038107 │
└─────────────────────┘
```

<div id="s2togeo">
  ## s2ToGeo
</div>

Devuelve las coordenadas geográficas `(longitud, latitud)` correspondientes al índice de punto [S2](#s2index) proporcionado.

**Sintaxis**

```sql
s2ToGeo(s2index)
```

**Argumentos**

* `s2index` — Índice S2. [UInt64](../../data-types/int-uint.md).

**Valores devueltos**

* Una [tupla](../../data-types/tuple.md) compuesta por dos valores:
  * `lon`. [Float64](../../data-types/float.md).
  * `lat`. [Float64](../../data-types/float.md).

**Ejemplo**

```sql title="Query"
SELECT s2ToGeo(4704772434919038107) AS s2Coodrinates;
```

```text title="Response"
┌─s2Coodrinates────────────────────────┐
│ (37.79506681471008,55.7129059052841) │
└──────────────────────────────────────┘
```

<div id="s2getneighbors">
  ## s2GetNeighbors
</div>

Devuelve los índices S2 vecinos correspondientes al [S2](#s2index) indicado. Cada celda del sistema S2 es un cuadrilátero delimitado por cuatro geodésicas. Por tanto, cada celda tiene 4 vecinos.

**Sintaxis**

```sql
s2GetNeighbors(s2index)
```

**Argumentos**

* `s2index` — índice S2. [UInt64](../../data-types/int-uint.md).

**Valor devuelto**

* Un array formado por 4 índices vecinos: `array[s2index1, s2index3, s2index2, s2index4]`. [Array](../../data-types/array.md)([UInt64](../../data-types/int-uint.md)).

**Ejemplo**

```sql title="Query"
SELECT s2GetNeighbors(5074766849661468672) AS s2Neighbors;
```

```text title="Response"
┌─s2Neighbors───────────────────────────────────────────────────────────────────────┐
│ [5074766987100422144,5074766712222515200,5074767536856236032,5074767261978329088] │
└───────────────────────────────────────────────────────────────────────────────────┘
```

<div id="s2cellsintersect">
  ## s2CellsIntersect
</div>

Determina si las dos celdas [S2](#s2index) proporcionadas se intersectan.

**Sintaxis**

```sql
s2CellsIntersect(s2index1, s2index2)
```

**Argumentos**

* `siIndex1`, `s2index2` — índice S2. [UInt64](../../data-types/int-uint.md).

**Valor devuelto**

* `1` — Si las celdas se intersecan. [UInt8](../../data-types/int-uint.md).
* `0` — Si las celdas no se intersecan. [UInt8](../../data-types/int-uint.md).

**Ejemplo**

```sql title="Query"
SELECT s2CellsIntersect(9926595209846587392, 9926594385212866560) AS intersect;
```

```text title="Response"
┌─intersect─┐
│         1 │
└───────────┘
```

<div id="s2capcontains">
  ## s2CapContains
</div>

Determina si un casquete esférico contiene un punto S2. Un casquete esférico representa una parte de la esfera separada por un plano. Se define mediante un punto sobre la esfera y un radio en grados.

**Sintaxis**

```sql
s2CapContains(center, degrees, point)
```

**Argumentos**

* `center` — Índice de punto S2 correspondiente al casquete. [UInt64](../../data-types/int-uint.md).
* `degrees` — Radio del casquete en grados. [Float64](../../data-types/float.md).
* `point` — Índice de punto S2. [UInt64](../../data-types/int-uint.md).

**Valor devuelto**

* `1` — Si el casquete contiene el índice de punto S2. [UInt8](../../data-types/int-uint.md).
* `0` — Si el casquete no contiene el índice de punto S2. [UInt8](../../data-types/int-uint.md).

**Ejemplo**

```sql title="Query"
SELECT s2CapContains(1157339245694594829, 1.0, 1157347770437378819) AS capContains;
```

```text title="Response"
┌─capContains─┐
│           1 │
└─────────────┘
```

<div id="s2capunion">
  ## s2CapUnion
</div>

Determina el casquete más pequeño que contiene los dos casquetes de entrada indicados. Un casquete representa una porción de la esfera separada por un plano. Se define mediante un punto sobre una esfera y un radio en grados.

**Sintaxis**

```sql
s2CapUnion(center1, radius1, center2, radius2)
```

**Argumentos**

* `center1`, `center2` — índices de punto S2 correspondientes a los dos casquetes de entrada. [UInt64](../../data-types/int-uint.md).
* `radius1`, `radius2` — radio de los dos casquetes de entrada, en grados. [Float64](../../data-types/float.md).

**Valores devueltos**

* `center` — índice de punto S2 correspondiente al centro del casquete más pequeño que contiene los dos casquetes de entrada. [UInt64](../../data-types/int-uint.md).
* `radius` — radio del casquete más pequeño que contiene los dos casquetes de entrada. [Float64](../../data-types/float.md).

**Ejemplo**

```sql title="Query"
SELECT s2CapUnion(3814912406305146967, 1.0, 1157347770437378819, 1.0) AS capUnion;
```

```text title="Response"
┌─capUnion───────────────────────────────┐
│ (4534655147792050737,60.2088283994957) │
└────────────────────────────────────────┘
```

<div id="s2rectadd">
  ## s2RectAdd
</div>

Aumenta el tamaño del rectángulo delimitador para incluir el punto S2 especificado. En el sistema S2, un rectángulo se representa mediante un tipo de S2Region llamado `S2LatLngRect`, que representa un rectángulo en el espacio de latitud y longitud.

**Sintaxis**

```sql
s2RectAdd(s2pointLow, s2pointHigh, s2Point)
```

**Argumentos**

* `s2PointLow` — Índice de punto S2 inferior correspondiente al rectángulo. [UInt64](../../data-types/int-uint.md).
* `s2PointHigh` — Índice de punto S2 superior correspondiente al rectángulo. [UInt64](../../data-types/int-uint.md).
* `s2Point` — Índice de punto S2 de destino que debe incluir el rectángulo delimitador al ampliarse. [UInt64](../../data-types/int-uint.md).

**Valores devueltos**

* `s2PointLow` — Identificador de celda S2 inferior correspondiente al rectángulo ampliado. [UInt64](../../data-types/int-uint.md).
* `s2PointHigh` — Identificador de celda S2 superior correspondiente al rectángulo ampliado. [UInt64](../../data-types/float.md).

**Ejemplo**

```sql title="Query"
SELECT s2RectAdd(5178914411069187297, 5177056748191934217, 5179056748191934217) AS rectAdd;
```

```text title="Response"
┌─rectAdd───────────────────────────────────┐
│ (5179062030687166815,5177056748191934217) │
└───────────────────────────────────────────┘
```

<div id="s2rectcontains">
  ## s2RectContains
</div>

Determina si un rectángulo dado contiene un punto S2. En el sistema S2, un rectángulo se representa mediante un tipo de S2Region llamado `S2LatLngRect`, que representa un rectángulo en el espacio de latitud y longitud.

```sql
s2RectContains(s2PointLow, s2PointHi, s2Point)
```

**Argumentos**

* `s2PointLow` — Índice de punto S2 más bajo correspondiente al rectángulo. [UInt64](../../data-types/int-uint.md).
* `s2PointHigh` — Índice de punto S2 más alto correspondiente al rectángulo. [UInt64](../../data-types/int-uint.md).
* `s2Point` — Índice de punto S2 de destino. [UInt64](../../data-types/int-uint.md).

**Valor devuelto**

* `1` — Si el rectángulo contiene el índice de punto S2 especificado.
* `0` — Si el rectángulo no contiene el índice de punto S2 especificado.

**Ejemplo**

```sql title="Query"
SELECT s2RectContains(5179062030687166815, 5177056748191934217, 5177914411069187297) AS rectContains;
```

```text title="Response"
┌─rectContains─┐
│            0 │
└──────────────┘
```

<div id="s2rectunion">
  ## s2RectUnion
</div>

Devuelve el rectángulo más pequeño que contiene la unión de este rectángulo y el rectángulo proporcionado. En el sistema S2, un rectángulo se representa mediante un tipo de S2Region llamado `S2LatLngRect`, que representa un rectángulo en el espacio de latitud y longitud.

**Sintaxis**

```sql
s2RectUnion(s2Rect1PointLow, s2Rect1PointHi, s2Rect2PointLow, s2Rect2PointHi)
```

**Argumentos**

* `s2Rect1PointLow`, `s2Rect1PointHi` — índices de punto S2 inferior y superior correspondientes al primer rectángulo. [UInt64](../../data-types/int-uint.md).
* `s2Rect2PointLow`, `s2Rect2PointHi` — índices de punto S2 inferior y superior correspondientes al segundo rectángulo. [UInt64](../../data-types/int-uint.md).

**Valores devueltos**

* `s2UnionRect2PointLow` — identificador de celda S2 inferior correspondiente al rectángulo resultante de la unión. [UInt64](../../data-types/int-uint.md).
* `s2UnionRect2PointHi` — identificador de celda S2 superior correspondiente al rectángulo resultante de la unión. [UInt64](../../data-types/int-uint.md).

**Ejemplo**

```sql title="Query"
SELECT s2RectUnion(5178914411069187297, 5177056748191934217, 5179062030687166815, 5177056748191934217) AS rectUnion;
```

```text title="Response"
┌─rectUnion─────────────────────────────────┐
│ (5179062030687166815,5177056748191934217) │
└───────────────────────────────────────────┘
```

<div id="s2rectintersection">
  ## s2RectIntersection
</div>

Devuelve el rectángulo más pequeño que contiene la intersección entre este rectángulo y el rectángulo dado. En el sistema S2, un rectángulo se representa mediante un tipo de S2Region llamado `S2LatLngRect`, que representa un rectángulo en el espacio de latitud y longitud.

**Sintaxis**

```sql
s2RectIntersection(s2Rect1PointLow, s2Rect1PointHi, s2Rect2PointLow, s2Rect2PointHi)
```

**Argumentos**

* `s2Rect1PointLow`, `s2Rect1PointHi` — índices de punto S2 inferior y superior del primer rectángulo. [UInt64](../../data-types/int-uint.md).
* `s2Rect2PointLow`, `s2Rect2PointHi` — índices de punto S2 inferior y superior del segundo rectángulo. [UInt64](../../data-types/int-uint.md).

**Valores devueltos**

* `s2UnionRect2PointLow` — identificador de celda S2 inferior del rectángulo que contiene la intersección de los rectángulos dados. [UInt64](../../data-types/int-uint.md).
* `s2UnionRect2PointHi` — identificador de celda S2 superior del rectángulo que contiene la intersección de los rectángulos dados. [UInt64](../../data-types/int-uint.md).

**Ejemplo**

```sql title="Query"
SELECT s2RectIntersection(5178914411069187297, 5177056748191934217, 5179062030687166815, 5177056748191934217) AS rectIntersection;
```

```text title="Response"
┌─rectIntersection──────────────────────────┐
│ (5178914411069187297,5177056748191934217) │
└───────────────────────────────────────────┘
```
