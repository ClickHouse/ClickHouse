Todas las funciones de esta sección aceptan cero o un argumento. El único uso del argumento (si se proporciona) es evitar la [eliminación de subexpresiones
comunes](/es/sql-reference/functions/overview#common-subexpression-elimination), de modo que dos ejecuciones distintas de la misma función aleatoria dentro de una fila
devuelvan valores aleatorios diferentes.

Contenido relacionado

* Guía: [Generación de datos aleatorios en ClickHouse](/es/guides/generating-test-data)
* Blog: [Generación de datos aleatorios en ClickHouse](https://clickhouse.com/blog/generating-random-test-distribution-data-for-clickhouse)

:::note
Los números aleatorios se generan mediante algoritmos no criptográficos.
:::
