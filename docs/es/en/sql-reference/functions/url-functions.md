<div id="overview">
  ## Descripción general
</div>

:::note
Las funciones mencionadas en esta sección están optimizadas para ofrecer el máximo rendimiento y, en su mayor parte, no siguen el estándar RFC-3986.
Las funciones que implementan RFC-3986 llevan `RFC` añadido al nombre de la función y, por lo general, son más lentas.
:::

Por lo general, puede usar las variantes de función sin `RFC` cuando trabaje con dominios registrados públicamente que no contengan ni información de usuario ni símbolos `@`.
La siguiente tabla detalla qué símbolos de una URL pueden (`✔`) o no pueden (`✗`) analizarse con las respectivas variantes `RFC` y no `RFC`:

| Símbolo     | non-`RFC` | `RFC` |   |
| ----------- | --------- | ----- | - |
| &#39; &#39; | ✗         | ✗     |   |
| \t          | ✗         | ✗     |   |
| &lt;        | ✗         | ✗     |   |
| &gt;        | ✗         | ✗     |   |
| %           | ✗         | ✔*    |   |
| &#123;      | ✗         | ✗     |   |
| &#125;      | ✗         | ✗     |   |
|             |           | ✗     | ✗ |
| &#92;&#92;  | ✗         | ✗     |   |
| ^           | ✗         | ✗     |   |
| ~           | ✗         | ✔*    |   |
| [           | ✗         | ✗     |   |
| ]           | ✗         | ✔     |   |
| ;           | ✗         | ✔*    |   |
| =           | ✗         | ✔*    |   |
| &amp;       | ✗         | ✔*    |   |

Los símbolos marcados con `*` son subdelimitadores en RFC 3986 y están permitidos en la información de usuario que sigue al símbolo `@`.

Hay dos tipos de funciones de URL:

* Funciones que extraen partes de una URL. Si la parte correspondiente no está presente en una URL, se devuelve una cadena vacía.
* Funciones que eliminan una parte de una URL. Si la URL no tiene nada similar, la URL permanece sin cambios.
