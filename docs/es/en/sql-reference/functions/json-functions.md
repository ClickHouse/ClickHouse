<div id="types-of-functions">
  ## Tipos de funciones JSON
</div>

Hay dos conjuntos de funciones para analizar JSON:

* [`simpleJSON*` (`visitParam*`)](#simplejson-visitparam-functions), diseñadas para analizar un subconjunto limitado de JSON con gran rapidez.
* [`JSONExtract*`](#jsonextract-functions), diseñadas para analizar JSON convencional.

<div id="simplejson-visitparam-functions">
  ### funciones simpleJSON (visitParam)
</div>

ClickHouse tiene funciones especiales para trabajar con JSON simplificado. Todas estas funciones JSON se basan en suposiciones estrictas sobre cómo puede ser el JSON. Intentan hacer lo mínimo posible para realizar la tarea lo más rápido posible.

Se parte de las siguientes suposiciones:

1. El nombre del campo (argumento de la función) debe ser una constante.
2. El nombre del campo está codificado en JSON de forma canónica. Por ejemplo: `simpleJSONHas('{"abc":"def"}', 'abc') = 1`, pero `simpleJSONHas('{"\\u0061\\u0062\\u0063":"def"}', 'abc') = 0`
3. Los campos se buscan en cualquier nivel de anidamiento, sin discriminar. Si hay varios campos coincidentes, se usa la primera aparición.
4. El JSON no tiene espacios en blanco fuera de los literales de cadena.

<div id="jsonextract-functions">
  ### Funciones JSONExtract
</div>

Estas funciones se basan en [simdjson](https://github.com/lemire/simdjson) y están diseñadas para necesidades de análisis de JSON más complejas.

<div id="case-insensitive-jsonextract-functions">
  ### Funciones JSONExtract que no distinguen entre mayúsculas y minúsculas
</div>

Estas funciones realizan una comparación de claves ASCII sin distinguir entre mayúsculas y minúsculas al extraer valores de objetos JSON.
Funcionan igual que sus equivalentes sensibles a mayúsculas y minúsculas, salvo que las claves del objeto se comparan sin tener en cuenta las mayúsculas y minúsculas.
Cuando varias claves coinciden con distintas combinaciones de mayúsculas y minúsculas, se devuelve la primera coincidencia.

:::note
Estas funciones pueden ofrecer un rendimiento inferior al de sus equivalentes sensibles a mayúsculas y minúsculas, así que usa las funciones JSONExtract normales siempre que sea posible.
:::
