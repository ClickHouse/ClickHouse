Estas funciones implementan el cifrado y descifrado de datos con el algoritmo AES (Advanced Encryption Standard).

La longitud de la clave depende del modo de cifrado: `16`, `24` y `32` bytes para los modos `-128-`, `-196-` y `-256-`, respectivamente.

La longitud del vector de inicialización es siempre de 16 bytes (se ignoran los bytes que excedan los 16).
