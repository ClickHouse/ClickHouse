Las funciones de bits funcionan con cualquier par de tipos entre `UInt8`, `UInt16`, `UInt32`, `UInt64`, `Int8`, `Int16`, `Int32`, `Int64`, `Float32` o `Float64`. Algunas funciones admiten los tipos `String` y `FixedString`.

El tipo de resultado es un entero con un número de bits igual al máximo número de bits de sus argumentos. Si al menos uno de los argumentos es con signo, el resultado es un número con signo. Si un argumento es un número de punto flotante, se convierte a Int64.
