<div id="uuidv7-generation">
  ## Generación de UUIDv7
</div>

El UUID generado contiene una marca de tiempo de 48 bits en milisegundos Unix, seguida de la versión &quot;7&quot; (4 bits), un contador (42 bits) para distinguir los UUID dentro de un milisegundo (incluido un campo de variante &quot;2&quot;, 2 bits) y un campo aleatorio (32 bits).
Para una marca de tiempo determinada (`unix_ts_ms`), el contador comienza con un valor aleatorio y se incrementa en 1 con cada UUID nuevo hasta que la marca de tiempo cambia. En caso de desbordamiento del contador, el campo de marca de tiempo se incrementa en 1 y el contador se restablece a un nuevo valor inicial aleatorio.
Las funciones de generación de UUID garantizan que el campo del contador dentro de una misma marca de tiempo se incremente de forma monótona en todas las invocaciones de la función en hilos y consultas que se ejecutan de forma concurrente.

<div id="snowflake-id-generation">
  ## Generación de IDs Snowflake
</div>

El ID Snowflake generado contiene la marca de tiempo Unix actual en milisegundos (41 bits más 1 bit superior en cero), seguida de un machine id (10 bits) y un contador (12 bits) para distinguir los IDs dentro de un mismo milisegundo. Para una marca de tiempo determinada (`unix_ts_ms`), el contador comienza en 0 y se incrementa en 1 por cada nuevo ID Snowflake hasta que cambia la marca de tiempo. Si el contador se desborda, el campo de marca de tiempo se incrementa en 1 y el contador se restablece a 0.

:::note
Los IDs Snowflake generados se basan en la época Unix 1970-01-01. Aunque no existe ningún estándar ni recomendación sobre la época de los IDs Snowflake, las implementaciones en otros sistemas pueden usar una época diferente, por ejemplo, Twitter/X (2010-11-04) o Mastodon (2015-01-01).
:::
