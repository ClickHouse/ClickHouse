Los usuarios interactúan con ClickHouse mediante sentencias SQL. ClickHouse admite sentencias SQL comunes como [SELECT](select/index.md) y [CREATE](create/index.md), pero también ofrece sentencias especializadas como [KILL](kill.md) y [OPTIMIZE](optimize.md).
