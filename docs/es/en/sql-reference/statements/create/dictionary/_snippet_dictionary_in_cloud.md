---
title: Fragmento de diccionario en Cloud
---

:::tip
Si usa un diccionario con ClickHouse Cloud, utilice la opción de consulta DDL para crear sus diccionarios y cree el diccionario como el usuario `default`.
Además, verifique la lista de orígenes de diccionario admitidos en la [guía de compatibilidad de Cloud](/es/whats-new/cloud-compatibility).
:::
