ClickHouse ofrece varias formas de integrarse con sistemas externos, entre ellas los motores de tabla. Como con cualquier otro motor de tabla, la configuración se realiza mediante consultas `CREATE TABLE` o `ALTER TABLE`. Después, desde la perspectiva del usuario, la integración configurada se comporta como una tabla normal, pero las consultas se redirigen al sistema externo. Esta transparencia al consultar es una de las principales ventajas de este enfoque frente a métodos de integración alternativos, como los diccionarios o las funciones de tabla, que requieren usar métodos de consulta personalizados en cada caso.
