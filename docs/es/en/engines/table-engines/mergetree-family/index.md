Los motores de tabla de la familia MergeTree son la base de las capacidades de almacenamiento de datos de ClickHouse. Proporcionan la mayoría de las funciones necesarias para la resiliencia y la recuperación de datos de alto rendimiento: almacenamiento columnar, particionado personalizado, índice primario disperso, índices secundarios de omisión de datos, etc.

El motor de tabla base [MergeTree](../../../engines/table-engines/mergetree-family/mergetree.md) puede considerarse el motor de tabla predeterminado para instancias de ClickHouse de un solo nodo, ya que es versátil y práctico para una amplia variedad de casos de uso.

Para entornos de producción, [ReplicatedMergeTree](../../../engines/table-engines/mergetree-family/replication.md) es la opción recomendada, ya que añade alta disponibilidad a todas las funciones del motor MergeTree estándar. Como ventaja adicional, ofrece deduplicación automática de datos durante la ingestión, por lo que el software puede reintentar de forma segura si se produce algún problema de red durante la inserción.

Todos los demás motores de la familia MergeTree añaden funcionalidad extra para casos de uso específicos. Normalmente, esto se implementa como manipulación adicional de datos en segundo plano.

La principal desventaja de los motores MergeTree es que son bastante pesados. Por eso, el patrón habitual es no tener demasiados. Si necesita muchas tablas pequeñas, por ejemplo para datos temporales, considere la [familia de motores Log](../../../engines/table-engines/log-family/index.md).
