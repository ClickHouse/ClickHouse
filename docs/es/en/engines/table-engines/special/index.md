Hay tres categorías principales de motores de tabla:

* [Familia de motores MergeTree](../../../engines/table-engines/mergetree-family/index.md) para el uso principal en producción.
* [Familia de motores Log](../../../engines/table-engines/log-family/index.md) para datos temporales de pequeño volumen.
* [Motores de tabla para integraciones](../../../engines/table-engines/integrations/index.md).

Los demás motores tienen propósitos específicos y aún no están agrupados en familias, por lo que se incluyen en esta categoría &quot;especial&quot;.
