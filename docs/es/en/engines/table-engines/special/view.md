Se utiliza para implementar vistas (para obtener más información, consulte la `CREATE VIEW query`). No almacena datos, sino únicamente la consulta `SELECT` especificada. Al leer de una tabla, ejecuta esta consulta (y elimina de la consulta todas las columnas innecesarias).
