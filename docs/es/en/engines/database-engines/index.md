Los motores de base de datos le permiten trabajar con tablas. De forma predeterminada, ClickHouse usa el motor de base de datos [Atomic](../../engines/database-engines/atomic.md), que proporciona [motores de tabla](../../engines/table-engines/index.md) configurables y un [dialecto SQL](../../sql-reference/syntax.md).
