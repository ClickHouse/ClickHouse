---
title: Configuración común para el formato binario de filas
---

{/* Nota: este fragmento se reutiliza en cualquier archivo en el que se importe */ }

Los siguientes ajustes son comunes a todos los formatos de tipo `RowBinary`.

| Ajuste                                                                                                                                 | Descripción                                                                                                                                                                                                                                                        | Predeterminado |
| -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------- |
| [`format_binary_max_string_size`](/es/operations/settings/settings-formats.md/#format_binary_max_string_size)                             | El tamaño máximo permitido para String en el formato RowBinary.                                                                                                                                                                                                    | `1GiB`         |
| [`output_format_binary_encode_types_in_binary_format`](/es/operations/settings/formats#input_format_binary_decode_types_in_binary_format) | Permite escribir los tipos en el encabezado usando [`binary encoding`](/es/sql-reference/data-types/data-types-binary-encoding.md) en lugar de cadenas con nombres de tipos en el formato de salida [`RowBinaryWithNamesAndTypes`](../RowBinaryWithNamesAndTypes.md). | `false`        |
| [`input_format_binary_decode_types_in_binary_format`](/es/operations/settings/formats#input_format_binary_decode_types_in_binary_format)  | Permite leer los tipos en el encabezado usando [`binary encoding`](/es/sql-reference/data-types/data-types-binary-encoding.md) en lugar de cadenas con nombres de tipos en el formato de entrada [`RowBinaryWithNamesAndTypes`](../RowBinaryWithNamesAndTypes.md).    | `false`        |
| [`output_format_binary_write_json_as_string`](/es/operations/settings/settings-formats.md/#output_format_binary_write_json_as_string)     | Permite escribir valores del tipo de dato [`JSON`](/es/sql-reference/data-types/newjson.md) como valores `JSON` de tipo [String](/es/sql-reference/data-types/string.md) en el formato de salida [`RowBinary`](../RowBinary.md).                                         | `false`        |
| [`input_format_binary_read_json_as_string`](/es/operations/settings/settings-formats.md/#input_format_binary_read_json_as_string)         | Permite leer valores del tipo de dato [`JSON`](/es/sql-reference/data-types/newjson.md) como valores `JSON` de tipo [String](/es/sql-reference/data-types/string.md) en el formato de entrada [`RowBinary`](../RowBinary.md).                                            | `false`        |
