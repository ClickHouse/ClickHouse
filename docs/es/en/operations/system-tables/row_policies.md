<div id="description">
  ## Descripción
</div>

Contiene filtros para una tabla concreta, así como una lista de roles y/o usuarios a los que se debe aplicar esta ROW POLICY.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de una ROW POLICY.
* `short_name` ([String](/es/sql-reference/data-types/string)) — Nombre corto de una ROW POLICY. Los nombres de las ROW POLICIES son compuestos; por ejemplo: myfilter ON mydb.mytable. Aquí &#39;myfilter ON mydb.mytable&#39; es el nombre de la ROW POLICY y &#39;myfilter&#39; es su nombre corto.
* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla. Vacío si la política es para una base de datos.
* `id` ([UUID](/es/sql-reference/data-types/uuid)) — ID de la ROW POLICY.
* `storage` ([String](/es/sql-reference/data-types/string)) — Nombre del directorio donde se almacena la ROW POLICY.
* `select_filter` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Expresión que se utiliza para filtrar en consultas SELECT.
* `is_restrictive` ([UInt8](/es/sql-reference/data-types/int-uint)) — Muestra si la ROW POLICY restringe el acceso a las filas. Valor: • 0 — La ROW POLICY está definida con la cláusula `AS PERMISSIVE`, • 1 — La ROW POLICY está definida con la cláusula `AS RESTRICTIVE`.
* `apply_to_all` ([UInt8](/es/sql-reference/data-types/int-uint)) — Muestra que las ROW POLICIES están establecidas para todos los roles y/o usuarios.
* `apply_to_list` ([Array(String)](/es/sql-reference/data-types/array)) — Lista de roles y/o usuarios a los que se aplican las ROW POLICIES.
* `apply_to_except` ([Array(String)](/es/sql-reference/data-types/array)) — Las ROW POLICIES se aplican a todos los roles y/o usuarios excepto a los que figuran en la lista.

{/*AUTOGENERATED_END*/ }
