<div id="description">
  ## Descripción
</div>

Esta tabla no existe si este nodo no está configurado para ejecutar ClickHouse Keeper en el mismo proceso. Contiene una fila por cada archivo de changelog de Raft (`changelog_<from>_<to>.bin[.zstd]`) del almacenamiento de logs de Keeper en el mismo proceso, incluido el archivo activo al que actualmente se le están agregando entradas.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `from_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Primer índice de log de Raft del archivo (inclusive).
* `to_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Último índice de log de Raft cubierto por el nombre de archivo (inclusive). En el archivo activo, este es el objetivo de rotación y puede estar por delante de `last_entry_index`.
* `last_entry_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Índice de log más alto que realmente se ha añadido a este archivo. `NULL` si el archivo activo aún no ha recibido ninguna entrada o si el archivo está dañado.
* `entries` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Número de entradas añadidas a este archivo. `ALIAS` de `ifNull(last_entry_index - from_log_index + 1, 0)`.
* `path` ([String](../../sql-reference/data-types/string.md)) — Ruta del archivo en el disco.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Nombre del disco que contiene el archivo.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Tamaño del archivo en disco.
* `modification_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — Fecha y hora de la última modificación del archivo.
* `is_compressed` ([Bool](../../sql-reference/data-types/boolean.md)) — El contenido del archivo está comprimido con zstd.
* `active` ([Bool](../../sql-reference/data-types/boolean.md)) — Actualmente se están añadiendo datos a este archivo.
* `is_broken` ([Bool](../../sql-reference/data-types/boolean.md)) — Al iniciar, se detectó que el registro final estaba corrupto.

{/*AUTOGENERATED_END*/ }

Ejemplo:

```sql
SELECT from_log_index, to_log_index, entries, path, active FROM system.keeper_changelogs ORDER BY from_log_index;
```

```text
┌─from_log_index─┬─to_log_index─┬─entries─┬─path───────────────────────────┬─active─┐
│              1 │         1000 │    1000 │ changelog_1_1000.bin.zstd      │ false  │
│           1001 │         2000 │     537 │ changelog_1001_2000.bin.zstd   │ true   │
└────────────────┴──────────────┴─────────┴────────────────────────────────┴────────┘
```
