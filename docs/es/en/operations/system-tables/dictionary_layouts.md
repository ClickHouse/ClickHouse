<div id="description">
  ## Descripción
</div>

Contiene la lista de estructuras de diccionario admitidas por el servidor, junto con la documentación integrada de cada una. Una estructura de diccionario determina cómo se almacena un diccionario en memoria (o en disco) y cómo se consulta; se especifica en la cláusula `LAYOUT` de una consulta `CREATE DICTIONARY`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — El nombre de la estructura del diccionario, tal como se especifica en la cláusula LAYOUT.
* `is_complex` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si la estructura requiere una clave compleja (una clave compuesta por varios atributos o de un tipo no entero).
* `description` ([String](/es/sql-reference/data-types/string)) — Una descripción general de lo que hace la estructura del diccionario.
* `syntax` ([String](/es/sql-reference/data-types/string)) — Cómo se especifica la estructura en la cláusula LAYOUT de una consulta CREATE DICTIONARY.
* `examples` ([String](/es/sql-reference/data-types/string)) — Ejemplos de uso.
* `introduced_in` ([String](/es/sql-reference/data-types/string)) — La versión de ClickHouse en la que se introdujo por primera vez la estructura, en el formato major.minor.
* `related` ([Array](/es/sql-reference/data-types/array)([String](/es/sql-reference/data-types/string))) — Los nombres de las estructuras de diccionario relacionadas.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SELECT name, is_complex, syntax
FROM system.dictionary_layouts
WHERE name IN ('flat', 'hashed', 'complex_key_hashed')
ORDER BY name
```

```text title="Response"
┌─name───────────────┬─is_complex─┬─syntax───────────────────────────────────────────────────┐
│ complex_key_hashed │          1 │ LAYOUT(COMPLEX_KEY_HASHED())                             │
│ flat               │          0 │ LAYOUT(FLAT([INITIAL_ARRAY_SIZE n] [MAX_ARRAY_SIZE n]))  │
│ hashed             │          0 │ LAYOUT(HASHED())                                         │
└────────────────────┴────────────┴──────────────────────────────────────────────────────────┘
```
