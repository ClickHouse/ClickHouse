Contiene registros con información sobre los archivos procesados por el motor AzureQueue.

Esta tabla se puede truncar o eliminar de forma segura en cualquier momento.

Columnas:

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre del host
* `event_date` ([Date](/es/sql-reference/data-types/date)) — Fecha del evento en el que se escribió esta fila de log
* `event_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora del evento en el que se escribió esta fila de log
* `database` ([String](/es/sql-reference/data-types/string)) — El nombre de la base de datos donde se encuentra la tabla de cola (`S3Queue` o `AzureQueue`).
* `table` ([String](/es/sql-reference/data-types/string)) — El nombre de la tabla de cola (`S3Queue` o `AzureQueue`).
* `uuid` ([String](/es/sql-reference/data-types/string)) — El UUID de la tabla de cola (`S3Queue` o `AzureQueue`).
* `file_name` ([String](/es/sql-reference/data-types/string)) — Nombre del archivo en procesamiento.
* `rows_processed` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de filas procesadas.
* `status` ([Enum8(&#39;Processed&#39; = 0, &#39;Failed&#39; = 1)](/es/sql-reference/data-types/enum)) — Estado del archivo en procesamiento.
* `processing_start_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de inicio del procesamiento del archivo.
* `processing_end_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de finalización del procesamiento del archivo.
* `exception` ([String](/es/sql-reference/data-types/string)) — Mensaje de excepción, si ocurrió alguna.
* `commit_id` ([UInt64](/es/sql-reference/data-types/int-uint)) — ID de la transacción en la que se hizo commit de este archivo.
* `commit_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora en que se hizo commit del archivo en Keeper (ya sea como fallido o procesado).
* `transaction_start_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora en que comenzó toda la transacción de procesamiento.
* `get_object_time_ms` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tiempo que tardamos en encontrar el objeto en el almacenamiento de objetos.

{/*AUTOGENERATED_END*/ }
