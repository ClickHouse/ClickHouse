<div id="description">
  ## Descripción
</div>

Contiene una lista de todas las colecciones con nombre que se crearon mediante una consulta SQL o que se analizaron a partir de un archivo de configuración.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de la colección.
* `collection` ([Map(String, String)](/es/sql-reference/data-types/map)) — Internos de la colección.
* `source` ([String](/es/sql-reference/data-types/string)) — Origen de la colección con nombre.
* `create_query` ([String](/es/sql-reference/data-types/string)) — Consulta de creación de la colección con nombre.

{/*AUTOGENERATED_END*/ }
