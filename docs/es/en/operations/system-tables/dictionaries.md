<div id="description">
  ## Descripción
</div>

Contiene información sobre [diccionarios](../../sql-reference/statements/create/dictionary/overview.md).

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos que contiene el diccionario creado por una consulta DDL. Cadena vacía para los demás diccionarios.
* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del diccionario.
* `uuid` ([UUID](/es/sql-reference/data-types/uuid)) — UUID del diccionario.
* `status` ([Enum8(&#39;NOT&#95;LOADED&#39; = 0, &#39;LOADED&#39; = 1, &#39;FAILED&#39; = 2, &#39;LOADING&#39; = 3, &#39;FAILED&#95;AND&#95;RELOADING&#39; = 4, &#39;LOADED&#95;AND&#95;RELOADING&#39; = 5, &#39;NOT&#95;EXIST&#39; = 6)](/es/sql-reference/data-types/enum)) — Estado del diccionario. Valores posibles: NOT&#95;LOADED — El diccionario no se cargó porque no se utilizó, LOADED — El diccionario se cargó correctamente, FAILED — No se pudo cargar el diccionario debido a un error, LOADING — El diccionario se está cargando en este momento, LOADED&#95;AND&#95;RELOADING — El diccionario se cargó correctamente y se está recargando en este momento (motivos frecuentes: consulta SYSTEM RELOAD DICTIONARY, timeout, la configuración del diccionario ha cambiado), FAILED&#95;AND&#95;RELOADING — No se pudo cargar el diccionario debido a un error y se está cargando en este momento.
* `origin` ([String](/es/sql-reference/data-types/string)) — Ruta al archivo de configuración que describe el diccionario.
* `type` ([String](/es/sql-reference/data-types/string)) — Tipo de asignación del diccionario. Almacenamiento de diccionarios en memoria.
* `key.names` ([Array(String)](/es/sql-reference/data-types/array)) — Array con los nombres de las claves proporcionadas por el diccionario.
* `key.types` ([Array(String)](/es/sql-reference/data-types/array)) — Array correspondiente con los tipos de las claves proporcionadas por el diccionario.
* `attribute.names` ([Array(String)](/es/sql-reference/data-types/array)) — Array con los nombres de los atributos proporcionados por el diccionario.
* `attribute.types` ([Array(String)](/es/sql-reference/data-types/array)) — Array correspondiente con los tipos de los atributos proporcionados por el diccionario.
* `bytes_allocated` ([UInt64](/es/sql-reference/data-types/int-uint)) — Cantidad de RAM asignada al diccionario.
* `hierarchical_index_bytes_allocated` ([UInt64](/es/sql-reference/data-types/int-uint)) — Cantidad de RAM asignada al índice jerárquico.
* `query_count` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de consultas desde que se cargó el diccionario o desde el último reinicio correcto.
* `hit_rate` ([Float64](/es/sql-reference/data-types/float)) — Para los diccionarios de caché, el porcentaje de usos en los que el valor estaba en la caché.
* `found_rate` ([Float64](/es/sql-reference/data-types/float)) — Porcentaje de usos en los que se encontró el valor.
* `element_count` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de elementos almacenados en el diccionario.
* `load_factor` ([Float64](/es/sql-reference/data-types/float)) — Porcentaje de ocupación del diccionario (para un diccionario hash, el porcentaje de ocupación de la tabla hash).
* `source` ([String](/es/sql-reference/data-types/string)) — Texto que describe la fuente de datos del diccionario.
* `lifetime_min` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tiempo de vida mínimo del diccionario en memoria, tras el cual ClickHouse intenta recargarlo (si `invalidate_query` está establecido, solo si ha cambiado). Se establece en segundos.
* `lifetime_max` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tiempo de vida máximo del diccionario en memoria, tras el cual ClickHouse intenta recargarlo (si `invalidate_query` está establecido, solo si ha cambiado). Se establece en segundos.
* `loading_start_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora de inicio de la carga del diccionario.
* `last_successful_update_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora de finalización de la carga o actualización del diccionario. Ayuda a supervisar problemas con las fuentes del diccionario e investigar sus causas.
* `error_count` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de errores desde la última carga correcta. Ayuda a supervisar problemas con las fuentes del diccionario e investigar sus causas.
* `loading_duration` ([Float32](/es/sql-reference/data-types/float)) — Duración de la carga del diccionario.
* `last_exception` ([String](/es/sql-reference/data-types/string)) — Texto del error que se produce al crear o recargar el diccionario si no se pudo crear.
* `comment` ([String](/es/sql-reference/data-types/string)) — Texto del comentario del diccionario.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

Configure el diccionario:

```sql
CREATE DICTIONARY dictionary_with_comment
(
    id UInt64,
    value String
)
PRIMARY KEY id
SOURCE(CLICKHOUSE(HOST 'localhost' PORT tcpPort() TABLE 'source_table'))
LAYOUT(FLAT())
LIFETIME(MIN 0 MAX 1000)
COMMENT 'The temporary dictionary';
```

Asegúrate de que el diccionario esté cargado.

```sql
SELECT * FROM system.dictionaries LIMIT 1 FORMAT Vertical;
```
