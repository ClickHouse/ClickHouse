<div id="description">
  ## Descripción
</div>

Contiene registros de logging con información sobre las operaciones `BACKUP` y `RESTORE`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre de host del servidor que ejecuta la consulta.
* `event_date` ([Date](/es/sql-reference/data-types/date)) — Fecha del registro.
* `event_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora del registro.
* `event_time_microseconds` ([DateTime64(6)](/es/sql-reference/data-types/datetime64)) — Hora del registro con precisión de microsegundos.
* `id` ([String](/es/sql-reference/data-types/string)) — Identificador de la operación de backup o restauración.
* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del almacenamiento del backup (el contenido de la cláusula FROM o TO).
* `base_backup_name` ([String](/es/sql-reference/data-types/string)) — Nombre de la copia de seguridad base en el caso de una incremental.
* `query_id` ([String](/es/sql-reference/data-types/string)) — ID de una consulta asociada a una operación de backup.
* `status` ([Enum8(&#39;CREATING&#95;BACKUP&#39; = 0, &#39;BACKUP&#95;CREATED&#39; = 1, &#39;BACKUP&#95;FAILED&#39; = 2, &#39;RESTORING&#39; = 3, &#39;RESTORED&#39; = 4, &#39;RESTORE&#95;FAILED&#39; = 5, &#39;BACKUP&#95;CANCELLED&#39; = 6, &#39;RESTORE&#95;CANCELLED&#39; = 7)](/es/sql-reference/data-types/enum)) — Estado de la operación.
* `error` ([String](/es/sql-reference/data-types/string)) — Mensaje de error de la operación fallida (cadena vacía en las operaciones exitosas).
* `start_time` ([DateTime64(6)](/es/sql-reference/data-types/datetime64)) — Hora de inicio de la operación.
* `end_time` ([DateTime64(6)](/es/sql-reference/data-types/datetime64)) — Hora de finalización de la operación.
* `num_files` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de archivos almacenados en el backup.
* `total_size` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño total de los archivos almacenados en el backup.
* `num_entries` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de entradas del backup; es decir, el número de archivos dentro de la carpeta si el backup se almacena como una carpeta, o el número de archivos dentro del archivo si el backup se almacena como un archivo. No es lo mismo que `num_files` si se trata de un backup incremental o si contiene archivos vacíos o duplicados. Lo siguiente siempre es cierto: `num_entries ≤ num_files`.
* `uncompressed_size` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño sin comprimir del backup.
* `compressed_size` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño comprimido del backup. Si el backup no se almacena como un archivo, es igual a uncompressed&#95;size.
* `files_read` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de archivos leídos durante la operación de restauración.
* `bytes_read` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño total de los archivos leídos durante la operación de restauración.
* `settings` ([Map(LowCardinality(String), String)](/es/sql-reference/data-types/map)) — Configuraciones específicas de backup/restauración utilizadas para esta operación (de la cláusula `SETTINGS`, incluidos los valores predeterminados). Las configuraciones sensibles no se exponen.
* `engine_settings` ([Map(LowCardinality(String), String)](/es/sql-reference/data-types/map)) — Configuraciones utilizadas por el lector/escritor del motor de backup (por ejemplo, S3 `allow_native_copy`). Está vacío cuando la operación implica más de un motor y un mapa plano no puede representarlo: backups incrementales y restauraciones, restauraciones ligeras de instantáneas y operaciones `ON CLUSTER` no internas.

{/*AUTOGENERATED_END*/ }

```sql
BACKUP TABLE test_db.my_table TO Disk('backups_disk', '1.zip')
```

```sql
SELECT hostname, event_date, event_time_microseconds, id, name, status, error, start_time, end_time, num_files, total_size, num_entries, uncompressed_size, compressed_size, files_read, bytes_read FROM system.backup_log WHERE id = 'e5b74ecb-f6f1-426a-80be-872f90043885' ORDER BY event_date, event_time_microseconds \G
```
