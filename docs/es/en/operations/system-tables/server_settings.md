<div id="description">
  ## Descripción
</div>

Contiene información sobre la configuración global del servidor, especificada en `config.xml`.
Actualmente, la tabla solo muestra la configuración del primer nivel de `config.xml` y no admite configuraciones anidadas (p. ej., [logger](../../operations/server-configuration-parameters/settings.md#logger)).

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de la configuración del servidor.
* `value` ([String](/es/sql-reference/data-types/string)) — Valor de la configuración del servidor.
* `default` ([String](/es/sql-reference/data-types/string)) — Valor predeterminado de la configuración del servidor.
* `changed` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si una configuración se especificó en config.xml
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción breve de la configuración del servidor.
* `type` ([String](/es/sql-reference/data-types/string)) — Tipo de valor de la configuración del servidor.
* `changeable_without_restart` ([Enum8(&#39;No&#39; = 0, &#39;IncreaseOnly&#39; = 1, &#39;DecreaseOnly&#39; = 2, &#39;Yes&#39; = 3)](/es/sql-reference/data-types/enum)) — Indica si una configuración puede cambiarse en tiempo de ejecución.
* `is_obsolete` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si una configuración es obsoleta.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

El siguiente ejemplo muestra cómo obtener información sobre los ajustes del servidor cuyo nombre contiene `thread_pool`.

```sql
SELECT *
FROM system.server_settings
WHERE name LIKE '%thread_pool%'
```

Usar `WHERE changed` puede ser útil, por ejemplo, cuando quieres comprobar
si la configuración de los archivos de configuración se ha cargado correctamente y se está usando.
