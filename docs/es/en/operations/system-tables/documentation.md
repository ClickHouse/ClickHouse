<div id="description">
  ## Descripción
</div>

Recopila en una sola tabla la documentación integrada de los componentes uniformes del sistema. Cada fila corresponde a una entidad (una función, un motor de tabla, un tipo de dato, etc.) y contiene la documentación de referencia de esa entidad en formato Markdown: el mismo contenido que se publica en el sitio web y que exponen las tablas `system.*` específicas de cada tipo.

La `description` se compone a partir de las partes estructuradas de la documentación integrada (`description`, `syntax`, argumentos, ejemplos, etc.), de modo que una sola columna contiene la documentación completa de una entidad. Los alias se muestran como una breve referencia a la entidad canónica, por ejemplo: ``Alias of `trunc`.``

Esta tabla, en cierto modo, recopila la información disponible en las tablas de documentación específicas de cada tipo ([`system.functions`](/es/operations/system-tables/functions), [`system.table_engines`](/es/operations/system-tables/table_engines), [`system.data_type_families`](/es/operations/system-tables/data_type_families) y otras). Está pensada, en particular, para servir de base a un comando `help` interactivo en el cliente, aunque también resulta útil por sí sola.

Se recopilan los siguientes tipos de entidades (el valor de la columna `type` se muestra entre paréntesis):

* Funciones (`Function`)
* Funciones de agregación (`Aggregate Function`)
* Funciones de tabla (`Table Function`)
* Motores de tabla (`Table Engine`)
* Motores de base de datos (`Database Engine`)
* Tipos de dato (`Data Type`)
* Estructuras de diccionario (`Dictionary Layout`)
* Orígenes de diccionario (`Dictionary Source`)
* Combinadores de funciones de agregación (`Aggregate Function Combinator`)
* Tipos de índices de omisión de datos (`Data Skipping Index`)
* Tipos de disco (`Disk Type`)
* Ajustes (`Setting`)
* Ajustes de MergeTree (`MergeTree Setting`)
* Ajustes del servidor (`Server Setting`)
* Formatos (`Format`)
* Códecs de compresión (`Compression Codec`)
* Eventos de perfil (`Profile Event`)
* Métricas actuales (`Current Metric`)
* Métricas asíncronas (`Asynchronous Metric`)
* Tablas del sistema (`System Table`)

En el caso de los ajustes (de cualquier tipo), la documentación consiste en la descripción del ajuste junto con su tipo y valor predeterminado; los ajustes obsoletos no se exponen. En el caso de las tablas del sistema, la documentación consiste en el comentario de la tabla junto con la lista de sus columnas (el nombre, el tipo y la descripción de cada una).

La columna `source` contiene la ruta del archivo fuente en el que se define la documentación de la entidad, relativa a la raíz del repositorio. En la mayoría de las entidades, se captura automáticamente en el lugar donde se construye el objeto de documentación (el punto de registro del componente); para los tipos que se documentan cada uno en un único archivo fuente (como los ajustes, los eventos de perfil y las métricas actuales), es ese archivo.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — El nombre de la entidad, por ejemplo `domainWithoutWWW` o `MergeTree`.
* `type` ([Enum8](/es/sql-reference/data-types/enum)) — El tipo de la entidad, por ejemplo `Function` o `Table Engine`.
* `description` ([String](/es/sql-reference/data-types/string)) — La documentación de referencia de la entidad en formato Markdown, generada a partir de la documentación integrada (el mismo contenido que se publica en el sitio web), incluida la sintaxis, los ejemplos y otras partes estructuradas, si las hay.
* `source` ([String](/es/sql-reference/data-types/string)) — La ruta al archivo fuente donde se define la documentación de la entidad, relativa a la raíz del repositorio. Vacía si se desconoce la ubicación del archivo fuente.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

Consulte la documentación de una entidad concreta:

```sql title="Query"
SELECT description
FROM system.documentation
WHERE type = 'Table Engine' AND name = 'MergeTree'
FORMAT TSVRaw;
```

El mismo nombre puede referirse a varios tipos de entidades (por ejemplo, existe tanto una función de tabla `file` como una fuente de diccionario `file`), por lo que conviene buscar ese nombre en todos los tipos:

```sql title="Query"
SELECT type, name
FROM system.documentation
WHERE name = 'file'
ORDER BY type;
```

Cuenta cuántas entidades documentadas hay de cada tipo:

```sql title="Query"
SELECT type, count()
FROM system.documentation
GROUP BY type
ORDER BY count() DESC;
```
