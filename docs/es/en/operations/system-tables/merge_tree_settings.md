<div id="description">
  ## Descripción
</div>

Contiene información sobre la configuración de las tablas `MergeTree`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del ajuste.
* `value` ([String](/es/sql-reference/data-types/string)) — Valor del ajuste.
* `default` ([String](/es/sql-reference/data-types/string)) — Valor predeterminado del ajuste.
* `changed` ([UInt8](/es/sql-reference/data-types/int-uint)) — 1 si el ajuste se definió explícitamente en la configuración o se cambió explícitamente.
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción del ajuste.
* `min` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Valor mínimo del ajuste, si se ha establecido alguno mediante restricciones. Si el ajuste no tiene valor mínimo, contiene NULL.
* `max` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Valor máximo del ajuste, si se ha establecido alguno mediante restricciones. Si el ajuste no tiene valor máximo, contiene NULL.
* `disallowed_values` ([Array(String)](/es/sql-reference/data-types/array)) — Lista de valores no permitidos
* `readonly` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si el usuario actual puede cambiar el ajuste: 0 — El usuario actual puede cambiar el ajuste, 1 — El usuario actual no puede cambiar el ajuste.
* `type` ([String](/es/sql-reference/data-types/string)) — Tipo de ajuste (valor de cadena específico de la implementación).
* `is_obsolete` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si un ajuste es obsoleto.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/es/sql-reference/data-types/enum)) — Nivel de soporte de esta funcionalidad. Las funcionalidades de ClickHouse están organizadas en niveles, que varían según el estado actual de su
  desarrollo y las expectativas que se pueden tener al utilizarlas:
  * PRODUCTION: La funcionalidad es estable, segura de usar y no presenta problemas al interactuar con otras funcionalidades PRODUCTION.
  * BETA: La funcionalidad es estable y segura. Se desconoce el resultado de usarla junto con otras funcionalidades y no se garantiza su corrección. Se agradecen las pruebas y los informes.
  * EXPERIMENTAL: La funcionalidad está en desarrollo. Solo está pensada para desarrolladores y entusiastas de ClickHouse. La funcionalidad puede funcionar o no, y podría eliminarse en cualquier momento.
  * OBSOLETE: Ya no tiene soporte. O bien ya se eliminó o se eliminará en versiones futuras.

{/*AUTOGENERATED_END*/ }
