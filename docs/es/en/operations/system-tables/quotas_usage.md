<div id="description">
  ## Descripción
</div>

Uso de cuota por parte de todos los usuarios.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/es/sql-reference/data-types/string)) — Nombre de la cuota.
* `quota_key` ([String](/es/sql-reference/data-types/string)) — Valor de la clave.
* `is_current` ([UInt8](/es/sql-reference/data-types/int-uint)) — Uso de la cuota para el usuario actual.
* `start_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de inicio para calcular el consumo de recursos.
* `end_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de finalización para calcular el consumo de recursos.
* `duration` ([Nullable(UInt32)](/es/sql-reference/data-types/nullable)) — Duración del intervalo de tiempo para calcular el consumo de recursos, en segundos.
* `queries` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número actual de consultas ejecutadas.
* `max_queries` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número máximo permitido de consultas de cualquier tipo que se pueden ejecutar.
* `query_selects` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número actual de consultas SELECT ejecutadas.
* `max_query_selects` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número máximo permitido de consultas SELECT que se pueden ejecutar.
* `query_inserts` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número actual de consultas INSERT ejecutadas.
* `max_query_inserts` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número máximo permitido de consultas INSERT que se pueden ejecutar.
* `errors` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número actual de consultas que produjeron un error.
* `max_errors` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número máximo permitido de consultas que produjeron un error dentro del período de tiempo especificado.
* `result_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total actual de filas en el conjunto de resultados de todas las consultas dentro del período de tiempo actual.
* `max_result_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total máximo permitido de filas en el conjunto de resultados de todas las consultas dentro del período de tiempo especificado.
* `result_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total actual de bytes en el conjunto de resultados de todas las consultas dentro del período de tiempo actual.
* `max_result_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total máximo permitido de bytes en el conjunto de resultados de todas las consultas dentro del período de tiempo especificado.
* `read_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total actual de filas leídas durante la ejecución de todas las consultas dentro del período de tiempo actual.
* `max_read_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número máximo permitido de filas que se pueden leer durante la ejecución de todas las consultas dentro del período de tiempo especificado.
* `read_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total actual de bytes leídos durante la ejecución de todas las consultas dentro del período de tiempo actual.
* `max_read_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número máximo permitido de bytes que se pueden leer durante la ejecución de todas las consultas dentro del período de tiempo especificado.
* `execution_time` ([Nullable(Float64)](/es/sql-reference/data-types/nullable)) — Tiempo total actual (en nanosegundos) empleado en ejecutar consultas dentro del período de tiempo actual
* `max_execution_time` ([Nullable(Float64)](/es/sql-reference/data-types/nullable)) — Tiempo máximo permitido (en nanosegundos) para la ejecución de todas las consultas dentro del período de tiempo especificado
* `written_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Número total actual de bytes escritos durante la ejecución de todas las consultas dentro del período de tiempo actual.
* `max_written_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo de bytes que pueden escribirse durante la ejecución de todas las consultas permitidas dentro del período de tiempo especificado.
* `failed_sequential_authentications` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número actual de fallos consecutivos de autenticación dentro del período de tiempo actual.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo de fallos consecutivos de autenticación permitidos dentro del período de tiempo especificado.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo actual de ejecuciones de una misma consulta normalizada dentro del período de tiempo actual.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo de ejecuciones permitidas de una misma consulta normalizada dentro del período de tiempo especificado.
