<div id="description">
  ## Descripción
</div>

Esta tabla del sistema se usa para implementar la consulta `SHOW PROCESSLIST`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `is_initial_query` ([UInt8](/es/sql-reference/data-types/int-uint)) — Si esta consulta proviene directamente del usuario o fue emitida por el servidor ClickHouse en el contexto de la ejecución distribuida de consultas.
* `user` ([String](/es/sql-reference/data-types/string)) — El usuario que realizó la consulta. Tenga en cuenta que, en el procesamiento distribuido, las consultas se envían a servidores remotos con el usuario `default`. El campo contiene el nombre de usuario de una consulta específica, no de una consulta iniciada por esta.
* `query_id` ([String](/es/sql-reference/data-types/string)) — ID de la consulta, si está definido.
* `address` ([IPv6](/es/sql-reference/data-types/ipv6)) — La dirección IP desde la que se realizó la consulta. Lo mismo aplica al procesamiento distribuido. Para rastrear desde dónde se realizó originalmente una consulta distribuida, consulte system.processes en el servidor que la solicitó.
* `port` ([UInt16](/es/sql-reference/data-types/int-uint)) — El puerto del client desde el que se realizó la consulta.
* `initial_user` ([String](/es/sql-reference/data-types/string)) — Nombre del usuario que ejecutó la consulta inicial (para la ejecución distribuida de consultas).
* `initial_query_id` ([String](/es/sql-reference/data-types/string)) — ID de la consulta inicial (para la ejecución distribuida de consultas).
* `initial_address` ([IPv6](/es/sql-reference/data-types/ipv6)) — Dirección IP desde la que se lanzó la consulta inicial.
* `initial_port` ([UInt16](/es/sql-reference/data-types/int-uint)) — El puerto del client que se utilizó para realizar la consulta inicial.
* `interface` ([UInt8](/es/sql-reference/data-types/int-uint)) — La interfaz que se utilizó para enviar la consulta. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/es/sql-reference/data-types/string)) — Nombre de usuario del sistema operativo que ejecuta clickhouse-client.
* `client_hostname` ([String](/es/sql-reference/data-types/string)) — Hostname de la máquina client donde se ejecuta clickhouse-client u otro client TCP.
* `client_name` ([String](/es/sql-reference/data-types/string)) — El nombre de clickhouse-client u otro client TCP.
* `client_agent` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — El agent de codificación con IA que invocó al client (por ejemplo, `claude-code` o `cursor`), detectado a partir de variables de entorno. Vacío si no se detectó ningún agent.
* `client_revision` ([UInt64](/es/sql-reference/data-types/int-uint)) — Revisión de clickhouse-client u otro client TCP.
* `client_version_major` ([UInt64](/es/sql-reference/data-types/int-uint)) — Versión principal de clickhouse-client u otro client TCP.
* `client_version_minor` ([UInt64](/es/sql-reference/data-types/int-uint)) — Versión secundaria de clickhouse-client u otro client TCP.
* `client_version_patch` ([UInt64](/es/sql-reference/data-types/int-uint)) — Componente patch de la versión de clickhouse-client u otro client TCP.
* `http_method` ([UInt8](/es/sql-reference/data-types/int-uint)) — Método HTTP que inició la consulta. Posibles valores: 0 — La consulta se lanzó desde la interfaz TCP. 1 — Se utilizó el método GET. 2 — Se utilizó el método POST.
* `http_user_agent` ([String](/es/sql-reference/data-types/string)) — Cabecera HTTP UserAgent enviada en la consulta HTTP.
* `http_referer` ([String](/es/sql-reference/data-types/string)) — Cabecera HTTP Referer enviada en la consulta HTTP (contiene una dirección absoluta o parcial de la página que realiza la consulta).
* `forwarded_for` ([String](/es/sql-reference/data-types/string)) — Cabecera HTTP X-Forwarded-For enviada en la consulta HTTP.
* `quota_key` ([String](/es/sql-reference/data-types/string)) — La clave de quota especificada en la configuración de quotas (consulte keyed).
* `distributed_depth` ([UInt64](/es/sql-reference/data-types/int-uint)) — El número de veces que la consulta se retransmitió internamente entre nodos del servidor.
* `elapsed` ([Float64](/es/sql-reference/data-types/float)) — El tiempo, en segundos, transcurrido desde el inicio de la ejecución de la request.
* `is_cancelled` ([UInt8](/es/sql-reference/data-types/int-uint)) — Si la consulta fue cancelada.
* `is_all_data_sent` ([UInt8](/es/sql-reference/data-types/int-uint)) — Si se enviaron todos los datos al `client` (es decir, si la consulta ya había finalizado en el servidor).
* `read_rows` ([UInt64](/es/sql-reference/data-types/int-uint)) — El número de filas leídas de la tabla. En el caso del procesamiento distribuido, en el servidor solicitante, este valor es el total de todos los servidores remotos.
* `read_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — El número de bytes sin comprimir leídos de la tabla. En el caso del procesamiento distribuido, en el servidor solicitante, este valor es el total de todos los servidores remotos.
* `total_rows_approx` ([UInt64](/es/sql-reference/data-types/int-uint)) — La estimación del número total de filas que deben leerse. En el caso del procesamiento distribuido, en el servidor solicitante, este valor es el total de todos los servidores remotos. Puede actualizarse durante el procesamiento de la solicitud, cuando se descubren nuevas fuentes que procesar.
* `written_rows` ([UInt64](/es/sql-reference/data-types/int-uint)) — La cantidad de filas escritas en el almacenamiento.
* `written_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — La cantidad de bytes escritos en el almacenamiento.
* `memory_usage` ([Int64](/es/sql-reference/data-types/int-uint)) — Cantidad de RAM que usa la consulta. Puede que no incluya algunos tipos de memoria dedicada.
* `peak_memory_usage` ([Int64](/es/sql-reference/data-types/int-uint)) — El pico actual de uso de memoria.
* `query` ([String](/es/sql-reference/data-types/string)) — El texto de la consulta. Para INSERT, no incluye los datos que se van a insertar.
* `normalized_query_hash` ([UInt64](/es/sql-reference/data-types/int-uint)) — Un valor hash numérico, idéntico para consultas que solo difieren en los valores de los literales.
* `query_kind` ([String](/es/sql-reference/data-types/string)) — El tipo de consulta: SELECT, INSERT, etc.
* `thread_ids` ([Array(UInt64)](/es/sql-reference/data-types/array)) — La lista de identificadores de todos los hilos que participaron en esta consulta.
* `peak_threads_usage` ([UInt64](/es/sql-reference/data-types/int-uint)) — El número máximo de hilos simultáneos que ejecutan la consulta.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/es/sql-reference/data-types/map)) — Los ProfileEvents calculados para esta consulta.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/es/sql-reference/data-types/map)) — La lista de ajustes de nivel de usuario modificados.
* `current_database` ([String](/es/sql-reference/data-types/string)) — El nombre de la base de datos actual.
* `is_internal` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si se trata de una consulta auxiliar ejecutada internamente.

**Alias:**

* `ProfileEvents.Names` — Alias de `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — Alias de `mapValues(ProfileEvents)`.
* `Settings.Names` — Alias de `mapKeys(Settings)`.
* `Settings.Values` — Alias de `mapValues(Settings)`.

{/*AUTOGENERATED_END*/ }
