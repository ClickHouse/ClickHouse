<div id="description">
  ## Descripción
</div>

Esta tabla contiene una única columna UInt64 llamada `number` que incluye casi todos los números naturales a partir de cero.

Puede usar esta tabla para pruebas o si necesita realizar una búsqueda por fuerza bruta.

Las lecturas de esta tabla no se paralelizan.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `number` ([UInt64](/es/sql-reference/data-types/int-uint))

{/*AUTOGENERATED_END*/ }
