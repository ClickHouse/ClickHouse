<div id="description">
  ## Descripción
</div>

Contiene códigos de error con el número de veces que se han activado.

Para mostrar todos los códigos de error posibles, incluidos los que no se hayan activado, establezca el ajuste [system&#95;events&#95;show&#95;zero&#95;values](../settings/settings.md#system_events_show_zero_values) en 1.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del error (errorCodeToName).
* `code` ([Int32](/es/sql-reference/data-types/int-uint)) — Número de código del error.
* `value` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de veces que ocurrió este error.
* `last_error_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Momento en que ocurrió el último error.
* `last_error_message` ([String](/es/sql-reference/data-types/string)) — Mensaje del último error.
* `last_error_format_string` ([String](/es/sql-reference/data-types/string)) — Cadena de formato del último error.
* `last_error_trace` ([Array(UInt64)](/es/sql-reference/data-types/array)) — Una traza de pila que representa una lista de direcciones físicas donde están almacenados los métodos invocados.
* `remote` ([UInt8](/es/sql-reference/data-types/int-uint)) — Excepción remota (es decir, recibida durante una de las consultas distribuidas).
* `query_id` ([String](/es/sql-reference/data-types/string)) — ID de una consulta que causó un error (si está disponible).

{/*AUTOGENERATED_END*/ }

:::note
Los contadores de algunos errores pueden aumentar durante la ejecución satisfactoria de una consulta. No se recomienda usar esta tabla para la monitorización del servidor, a menos que tenga la certeza de que el error correspondiente no puede ser un falso positivo.
:::

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SELECT name, code, value
FROM system.errors
WHERE value > 0
ORDER BY code ASC
LIMIT 1

┌─name─────────────┬─code─┬─value─┐
│ CANNOT_OPEN_FILE │   76 │     1 │
└──────────────────┴──────┴───────┘
```

```sql title="Response"
WITH arrayMap(x -> demangle(addressToSymbol(x)), last_error_trace) AS all
SELECT name, arrayStringConcat(all, '\n') AS res
FROM system.errors
LIMIT 1
SETTINGS allow_introspection_functions=1\G
```
