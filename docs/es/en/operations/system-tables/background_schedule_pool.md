  # system.background_schedule_pool
</div>

<SystemTableCloud />

<div id="description">
  ## Descripción
</div>

Contiene información sobre las tareas de los pools de programación en segundo plano. Estos pools se utilizan para ejecutar tareas periódicas, como envíos distribuidos, vaciados del búfer y operaciones del broker de mensajes.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `pool` ([String](/es/sql-reference/data-types/string)) — Nombre del grupo. Posibles valores: `schedule` — grupo de programación de uso general, `buffer_flush` — grupo para el vaciado de datos de la tabla Buffer, `distributed` — grupo para operaciones de tabla distribuida, `message_broker` — grupo para operaciones del broker de mensajes.
* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla.
* `table_uuid` ([UUID](/es/sql-reference/data-types/uuid)) — UUID de la tabla.
* `query_id` ([String](/es/sql-reference/data-types/string)) — ID de la consulta (si se está ejecutando ahora). Nota: no es una consulta real, sino un ID generado aleatoriamente para asociar los registros de `system.text_log`.
* `elapsed_ms` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tiempo de ejecución de la tarea (si se está ejecutando ahora).
* `log_name` ([String](/es/sql-reference/data-types/string)) — Nombre del log de la tarea.
* `deactivated` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si la tarea está desactivada (siempre es false, ya que las tareas desactivadas se eliminan del grupo).
* `scheduled` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si la tarea está programada para ejecutarse.
* `delayed` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si la tarea está programada con retraso.
* `executing` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si la tarea se está ejecutando actualmente.

{/*AUTOGENERATED_END*/ }
