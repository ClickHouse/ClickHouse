<div id="description">
  ## Descripción
</div>

Contiene información sobre la configuración de sesión del usuario actual.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de la configuración.
* `value` ([String](/es/sql-reference/data-types/string)) — Valor de la configuración.
* `changed` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si la configuración se definió explícitamente en la configuración o se modificó explícitamente.
* `description` ([String](/es/sql-reference/data-types/string)) — Breve descripción de la configuración.
* `min` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Valor mínimo de la configuración, si se establece alguno mediante restricciones. Si la configuración no tiene un valor mínimo, contiene NULL.
* `max` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Valor máximo de la configuración, si se establece alguno mediante restricciones. Si la configuración no tiene un valor máximo, contiene NULL.
* `disallowed_values` ([Array(String)](/es/sql-reference/data-types/array)) — Lista de valores no permitidos
* `readonly` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si el usuario actual puede cambiar la configuración: 0 — El usuario actual puede cambiar la configuración, 1 — El usuario actual no puede cambiar la configuración.
* `type` ([String](/es/sql-reference/data-types/string)) — El tipo de valor que se puede asignar a esta configuración.
* `default` ([String](/es/sql-reference/data-types/string)) — Valor predeterminado de la configuración.
* `alias_for` ([String](/es/sql-reference/data-types/string)) — Nombre de la configuración original si esta configuración es un alias de otra configuración.
* `is_obsolete` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si una configuración es obsoleta.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12)](/es/sql-reference/data-types/enum)) — Nivel de soporte de esta característica. Las características de ClickHouse se organizan en niveles, que varían según el estado actual de su
  desarrollo y las expectativas que se pueden tener al usarlas:
  * PRODUCTION: La característica es estable, segura de usar y no presenta problemas al interactuar con otras características PRODUCTION.
  * BETA: La característica es estable y segura. Se desconoce el resultado de usarla junto con otras características y no se garantiza su correcto funcionamiento. Se agradecen las pruebas y los informes.
  * EXPERIMENTAL: La característica está en desarrollo. Está destinada únicamente a desarrolladores y entusiastas de ClickHouse. La característica puede funcionar o no, y podría eliminarse en cualquier momento.
  * OBSOLETE: Ya no es compatible. O bien ya se eliminó o se eliminará en versiones futuras.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

El siguiente ejemplo muestra cómo obtener información sobre los ajustes cuyo nombre contiene `min_i`.

```sql
SELECT *
FROM system.settings
WHERE name LIKE '%min_insert_block_size_%'
FORMAT Vertical
```

El uso de `WHERE changed` puede ser útil, por ejemplo, cuando quiera comprobar:

* Si la configuración de los archivos de configuración se ha cargado correctamente y se está utilizando.
* Qué ajustes han cambiado en la sesión actual.

```sql
SELECT * FROM system.settings WHERE changed AND name='load_balancing'
```
