<div id="description">
  ## Descripción
</div>

Contiene una lista de todos los formatos, junto con indicadores de si un formato es apto para entrada/salida o si admite paralelización.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del formato.
* `is_input` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si el formato es adecuado para la entrada de datos.
* `is_output` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si el formato es adecuado para la salida de datos.
* `supports_parallel_parsing` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si el formato admite el análisis en paralelo.
* `supports_parallel_formatting` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si el formato admite el formateo en paralelo.
* `is_tty_friendly` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si el formato suele visualizarse correctamente en la terminal. Para otros formatos, la CLI solicitará confirmación antes de mostrar la salida.
* `content_type` ([String](/es/sql-reference/data-types/string)) — `Content-Type` HTTP correspondiente al formato de salida. Puede depender de la configuración actual del formato.
* `supports_random_access` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si el formato admite acceso aleatorio en la entrada.
* `has_schema_inference` ([UInt8](/es/sql-reference/data-types/int-uint)) — El formato puede inferir dinámicamente el esquema a partir de los datos (ya sea desde un encabezado o metadatos integrados, o desde el propio fragmento de datos).
* `has_external_schema` ([UInt8](/es/sql-reference/data-types/int-uint)) — El formato tiene un esquema fijo o acepta un esquema predefinido en su propio formato.
* `prefers_large_blocks` ([UInt8](/es/sql-reference/data-types/int-uint)) — El formato escribirá blocks más grandes en la salida y generará blocks más grandes en la entrada.
* `supports_append` ([UInt8](/es/sql-reference/data-types/int-uint)) — Es posible añadir datos a un único archivo con este formato.
* `supports_subsets_of_columns` ([UInt8](/es/sql-reference/data-types/int-uint)) — El formato de entrada puede reconocer cuándo se omiten determinadas columnas.
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción general del formato.
* `examples` ([String](/es/sql-reference/data-types/string)) — Ejemplos de uso.
* `introduced_in` ([String](/es/sql-reference/data-types/string)) — La versión de ClickHouse en la que se introdujo por primera vez el formato, en la forma major.minor.
* `related` ([Array](/es/sql-reference/data-types/array)([String](/es/sql-reference/data-types/string))) — Los nombres de los formatos relacionados.

{/*AUTOGENERATED_END*/ }
