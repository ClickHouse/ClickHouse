<div id="description">
  ## Descripción
</div>

Contiene información sobre los registros DNS almacenados en caché.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([String](/es/sql-reference/data-types/string)) — Nombre del host.
* `ip_address` ([String](/es/sql-reference/data-types/string)) — Dirección IP.
* `ip_family` ([Enum8(&#39;IPv4&#39; = 0, &#39;IPv6&#39; = 1, &#39;UNIX&#95;LOCAL&#39; = 2)](/es/sql-reference/data-types/enum)) — Familia de direcciones IP.
* `cached_at` ([DateTime](/es/sql-reference/data-types/datetime)) — Marca temporal de cuando se almacenó en caché el registro.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SELECT * FROM system.dns_cache;
```

| hostname  | ip&#95;address | ip&#95;family | cached&#95;at       |
| :-------- | :------------- | :------------ | :------------------ |
| localhost | ::1            | IPv6          | 2024-02-11 17:04:40 |
| localhost | 127.0.0.1      | IPv4          | 2024-02-11 17:04:40 |
