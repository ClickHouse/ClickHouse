<div id="description">
  ## Descripción
</div>

Contiene información sobre las columnas de todas las tablas.

Puede usar esta tabla para obtener información similar a la de la consulta [DESCRIBE TABLE](../../sql-reference/statements/describe-table.md), pero para varias tablas al mismo tiempo.

Las columnas de las [tablas temporales](../../sql-reference/statements/create/table.md#temporary-tables) solo son visibles en `system.columns` en la sesión en la que se crearon. Se muestran con el campo `database` vacío.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla.
* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de la columna.
* `type` ([String](/es/sql-reference/data-types/string)) — Tipo de la columna.
* `position` ([UInt64](/es/sql-reference/data-types/int-uint)) — Posición ordinal de una columna en una tabla, empezando por 1.
* `default_kind` ([String](/es/sql-reference/data-types/string)) — Tipo de expresión (DEFAULT, MATERIALIZED, ALIAS) para el valor predeterminado, o una cadena vacía si no está definido.
* `default_expression` ([String](/es/sql-reference/data-types/string)) — Expresión del valor predeterminado, o una cadena vacía si no está definida.
* `data_compressed_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño de los datos comprimidos, en bytes.
* `data_uncompressed_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño de los datos descomprimidos, en bytes.
* `marks_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño de las marcas, en bytes.
* `comment` ([String](/es/sql-reference/data-types/string)) — Comentario de la columna, o una cadena vacía si no está definido.
* `is_in_partition_key` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que señala si la columna está en la expresión de partición.
* `is_in_sorting_key` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que señala si la columna está en la expresión de la clave de ordenación.
* `is_in_primary_key` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que señala si la columna está en la expresión de la clave primaria.
* `is_in_sampling_key` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que señala si la columna está en la expresión de la clave de muestreo.
* `compression_codec` ([String](/es/sql-reference/data-types/string)) — Nombre del códec de compresión.
* `character_octet_length` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Longitud máxima en bytes para datos binarios, datos de caracteres o datos de texto e imágenes. En ClickHouse, solo tiene sentido para el tipo de dato FixedString. En caso contrario, se devuelve el valor NULL.
* `numeric_precision` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Precisión de los datos numéricos aproximados, los datos numéricos exactos, los datos enteros o los datos monetarios. En ClickHouse, es el ancho en bits para los tipos enteros y la precisión decimal para los tipos Decimal. En caso contrario, se devuelve el valor NULL.
* `numeric_precision_radix` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Base del sistema numérico de los datos numéricos aproximados, los datos numéricos exactos, los datos enteros o los datos monetarios. En ClickHouse, es 2 para los tipos enteros y 10 para los tipos Decimal. En caso contrario, se devuelve el valor NULL.
* `numeric_scale` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Escala de los datos numéricos aproximados, los datos numéricos exactos, los datos enteros o los datos monetarios. En ClickHouse, solo tiene sentido para los tipos Decimal. En caso contrario, se devuelve el valor NULL.
* `datetime_precision` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — Precisión decimal del tipo de dato DateTime64. Para otros tipos de datos, se devuelve el valor NULL.
* `serialization_hint` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Sugerencia para que la columna elija la serialización en los inserts según las estadísticas.
* `statistics` ([String](/es/sql-reference/data-types/string)) — Tipos de estadísticas creados en esta columna.

**Aliases:**

* `column` — Alias de `name`.

{/*AUTOGENERATED_END*/ }
