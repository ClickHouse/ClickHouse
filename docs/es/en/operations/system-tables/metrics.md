<div id="description">
  ## Descripción
</div>

Contiene métricas que pueden calcularse al instante o que tienen un valor actual. Por ejemplo, el número de consultas procesadas simultáneamente o el retraso actual de la réplica. Esta tabla siempre está actualizada.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/es/sql-reference/data-types/string)) — Nombre de la métrica.
* `value` ([Int64](/es/sql-reference/data-types/int-uint)) — Valor de la métrica.
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción de la métrica.

**Alias:**

* `name` — Alias de `metric`.

{/*AUTOGENERATED_END*/ }

Puedes encontrar todas las métricas admitidas en el archivo fuente [src/Common/CurrentMetrics.cpp](https://github.com/ClickHouse/ClickHouse/blob/master/src/Common/CurrentMetrics.cpp).

<div id="example">
  ## Ejemplo
</div>

```sql
SELECT * FROM system.metrics LIMIT 10
```

```text
┌─metric───────────────────────────────┬─value─┬─description────────────────────────────────────────────────────────────┐
│ Query                                │     1 │ Number of executing queries                                            │
│ Merge                                │     0 │ Number of executing background merges                                  │
│ PartMutation                         │     0 │ Number of mutations (ALTER DELETE/UPDATE)                              │
│ ReplicatedFetch                      │     0 │ Number of data parts being fetched from replicas                       │
│ ReplicatedSend                       │     0 │ Number of data parts being sent to replicas                            │
│ ReplicatedChecks                     │     0 │ Number of data parts checking for consistency                          │
│ BackgroundMergesAndMutationsPoolTask │     0 │ Number of active merges and mutations in an associated background pool │
│ BackgroundFetchesPoolTask            │     0 │ Number of active fetches in an associated background pool              │
│ BackgroundCommonPoolTask             │     0 │ Number of active tasks in an associated background pool                │
│ BackgroundMovePoolTask               │     0 │ Number of active tasks in BackgroundProcessingPool for moves           │
└──────────────────────────────────────┴───────┴────────────────────────────────────────────────────────────────────────┘
```
