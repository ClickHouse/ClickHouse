<div id="description">
  ## Descripción
</div>

La tabla contiene información sobre los [movimientos en curso de partes de datos](/es/sql-reference/statements/alter/partition#move-partitionpart) de las tablas [MergeTree](/es/engines/table-engines/mergetree-family/mergetree.md). Cada movimiento de una parte de datos se representa mediante una sola fila.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla que contiene la parte de datos en movimiento.
* `elapsed` ([Float64](/es/sql-reference/data-types/float)) — Tiempo transcurrido (en segundos) desde que comenzó el movimiento de la parte de datos.
* `target_disk_name` ([String](/es/sql-reference/data-types/string)) — Nombre del disco al que se está moviendo la parte de datos.
* `target_disk_path` ([String](/es/sql-reference/data-types/string)) — Ruta del punto de montaje del disco en el sistema de archivos.
* `part_name` ([String](/es/sql-reference/data-types/string)) — Nombre de la parte de datos que se está moviendo.
* `part_size` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño de la parte de datos.
* `thread_id` ([UInt64](/es/sql-reference/data-types/int-uint)) — Identificador del hilo que realiza el movimiento.

{/*AUTOGENERATED_END*/ }
