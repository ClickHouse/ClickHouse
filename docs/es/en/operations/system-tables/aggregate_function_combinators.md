<div id="description">
  ## Descripción
</div>

Contiene una lista de todos los combinadores de funciones de agregación disponibles, que pueden aplicarse a las funciones de agregación y modificar su comportamiento.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — El nombre del combinador.
* `is_internal` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si este combinador es solo para uso interno.

{/*AUTOGENERATED_END*/ }
