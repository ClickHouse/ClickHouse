<div id="description">
  ## Descripción
</div>

Esta tabla no existe si este nodo no está configurado para ejecutar ClickHouse Keeper en el mismo proceso. Contiene una fila por cada miembro del clúster Raft y combina la topología estática del clúster (de la configuración de Raft) con la posición del log del propio nodo local.

Cada nodo tiene exactamente un valor de `last_log_index`: la fila que coincide con su propio `server_id`. Las posiciones de log de los demás nodos no se muestran aquí porque solo se registran en el líder, y esa vista no es simétrica en todo el clúster.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `server_id` ([Int32](../../sql-reference/data-types/int-uint.md)) — ID del servidor Raft de este miembro del clúster.
* `host` ([String](../../sql-reference/data-types/string.md)) — Host extraído del endpoint (prefijo antes de los últimos dos puntos).
* `endpoint` ([String](../../sql-reference/data-types/string.md)) — Endpoint Raft sin procesar, tal como está configurado (`host:port`).
* `is_observer` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si este miembro es un observador sin derecho a voto, configurado mediante `<can_become_leader>false</can_become_leader>`.
* `priority` ([Int32](../../sql-reference/data-types/int-uint.md)) — Prioridad Raft de este miembro; se prefieren los valores más altos durante la elección de líder.
* `is_leader` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si este miembro es el líder Raft actual.
* `is_self` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si esta fila describe el nodo local de Keeper.
* `last_log_index` ([Nullable(UInt64)](../../sql-reference/data-types/int-uint.md)) — Índice de log más alto en el almacén de logs local de Raft de este nodo. Se pobla solo en la fila correspondiente al nodo actual (`is_self = true`); `NULL` en las demás filas.

{/*AUTOGENERATED_END*/ }

Ejemplo:

```sql
SELECT * FROM system.keeper_cluster ORDER BY server_id;
```
