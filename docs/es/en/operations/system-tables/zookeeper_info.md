<div id="description">
  ## Descripción
</div>

Esta tabla muestra información de introspección combinada sobre ZooKeeper, y los nodos se obtienen de la configuración.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_cluster_name` ([String](../../sql-reference/data-types/string.md)) — El nombre del clúster de ZooKeeper.
* `host` ([String](../../sql-reference/data-types/string.md)) — El hostname/IP del nodo de ZooKeeper al que se conectó ClickHouse.
* `port` ([UInt16](../../sql-reference/data-types/int-uint.md)) — El puerto del nodo de ZooKeeper al que se conectó ClickHouse.
* `index` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — El índice del nodo de ZooKeeper al que se conectó ClickHouse. El índice proviene de la configuración de ZooKeeper. Si no está conectado, esta columna es NULL.
* `is_connected` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — Indica si ZooKeeper está conectado o no.
* `is_readonly` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Indica si es de solo lectura.
* `version` ([String](../../sql-reference/data-types/string.md)) — La versión de ZooKeeper.
* `avg_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La latencia media.
* `max_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La latencia máxima.
* `min_latency` ([UInt64](../../sql-reference/data-types/int-uint.md)) — La latencia mínima.
* `packets_received` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de paquetes recibidos.
* `packets_sent` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de paquetes enviados.
* `outstanding_requests` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de solicitudes pendientes.
* `server_state` ([String](../../sql-reference/data-types/string.md)) — El estado del servidor.
* `is_leader` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Indica si este ZooKeeper es el líder.
* `znode_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de znodes.
* `watch_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de watches.
* `ephemerals_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de elementos efímeros.
* `approximate_data_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El tamaño aproximado de los datos.
* `followers` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Los followers del líder. Este campo solo lo expone el líder.
* `synced_followers` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Los followers sincronizados del líder. Este campo solo lo expone el líder.
* `pending_syncs` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Las sincronizaciones pendientes del líder. Este campo solo lo expone el líder.
* `open_file_descriptor_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de descriptores de archivo abiertos. Solo está disponible en plataformas Unix.
* `max_file_descriptor_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número máximo de descriptores de archivo. Solo está disponible en plataformas Unix.
* `connections` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Las conexiones a ZooKeeper.
* `outstanding` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El valor outstanding de ZooKeeper.
* `zxid` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El zxid de ZooKeeper.
* `node_count` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El número de nodos de ZooKeeper.
* `snapshot_dir_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El tamaño del directorio de instantáneas de ZooKeeper.
* `log_dir_size` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El tamaño del directorio de logs de ZooKeeper.
* `first_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El primer índice de log de ZooKeeper.
* `first_log_term` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El primer término de log de ZooKeeper.
* `last_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El último índice de log de ZooKeeper.
* `last_log_term` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El último término de log de ZooKeeper.
* `last_committed_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El último índice confirmado de ZooKeeper.
* `leader_committed_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El índice de log confirmado del líder de ZooKeeper.
* `target_committed_log_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El índice de log confirmado de destino de ZooKeeper.
* `last_snapshot_idx` ([UInt64](../../sql-reference/data-types/int-uint.md)) — El último índice de instantánea de ZooKeeper.
