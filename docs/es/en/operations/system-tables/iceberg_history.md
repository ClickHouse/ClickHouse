<div id="description">
  ## Descripción
</div>

Esta tabla del sistema contiene el historial de instantáneas de las tablas Iceberg que existen en ClickHouse. Estará vacía si no tiene ninguna tabla Iceberg en ClickHouse.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla.
* `made_current_at` ([Nullable(DateTime64(3))](/es/sql-reference/data-types/nullable)) — Fecha y hora en que esta instantánea pasó a ser la instantánea actual.
* `snapshot_id` ([UInt64](/es/sql-reference/data-types/int-uint)) — ID de la instantánea que se usa para identificar una instantánea.
* `parent_id` ([UInt64](/es/sql-reference/data-types/int-uint)) — ID de la instantánea padre de esta instantánea.
* `is_current_ancestor` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador de si esta instantánea es un ancestro de la instantánea actual.

{/*AUTOGENERATED_END*/ }
