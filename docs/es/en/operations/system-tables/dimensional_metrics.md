<div id="description">
  ## Descripción
</div>

Esta tabla contiene métricas dimensionales que pueden calcularse al instante y exportarse en formato Prometheus. Siempre está actualizada.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `metric` ([String](/es/sql-reference/data-types/string)) — Nombre de la métrica.
* `value` ([Float64](/es/sql-reference/data-types/float)) — Valor de la métrica.
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción de la métrica.
* `labels` ([Map(String, String)](/es/sql-reference/data-types/map)) — Etiquetas de la métrica.

**Alias:**

* `name` — Alias de `metric`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

Puede usar una consulta como esta para exportar todas las métricas dimensionales en formato Prometheus.

```sql
SELECT
  metric AS name,
  toFloat64(value) AS value,
  description AS help,
  labels,
  'gauge' AS type
FROM system.dimensional_metrics
FORMAT Prometheus
```

<div id="metric_descriptions">
  ## Descripción de las métricas
</div>

<div id="merge_failures">
  ### merge_failures
</div>

Número total de fusiones fallidas desde el inicio.

<div id="startup_scripts_failure_reason">
  ### startup_scripts_failure_reason
</div>

Indica los fallos de los scripts de inicio por tipo de error. Se establece en 1 cuando falla un script de inicio y se etiqueta con el nombre del error.

<div id="merge_tree_parts">
  ### merge_tree_parts
</div>

Número de partes de datos de MergeTree, etiquetadas según el estado de la parte, el tipo de parte y si se trata de una parte de proyección.

<div id="filesystem-cache-evictions-total">
  ### `filesystem_cache_evictions_total`
</div>

Número de segmentos de archivo expulsados de una caché del sistema de archivos, etiquetado por el nombre de la caché. Deshabilitado de forma predeterminada; actívelo con `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evicted-bytes-total">
  ### `filesystem_cache_evicted_bytes_total`
</div>

Bytes totales de segmentos de archivo expulsados de la caché del sistema de archivos, etiquetados por nombre de caché. Está desactivado de forma predeterminada; actívelo con `expose_prometheus_eviction_metrics`.

<div id="filesystem-cache-evictions-by-user-total">
  ### `filesystem_cache_evictions_by_user_total`
</div>

Número de segmentos de archivo expulsados de una caché del sistema de archivos, etiquetado por nombre de caché e ID de usuario. Deshabilitado de forma predeterminada; habilítelo con `expose_prometheus_eviction_metrics` y `expose_prometheus_eviction_metrics_per_user`.

<div id="filesystem-cache-evicted-bytes-by-user-total">
  ### `filesystem_cache_evicted_bytes_by_user_total`
</div>

Total de bytes de segmentos de archivo expulsados de una caché del sistema de archivos, etiquetados con el nombre de la caché y el ID de usuario. Deshabilitado de forma predeterminada; habilítelo con `expose_prometheus_eviction_metrics` y `expose_prometheus_eviction_metrics_per_user`.
