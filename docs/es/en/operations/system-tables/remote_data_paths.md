<div id="description">
  ## Descripción
</div>

Contiene información sobre archivos de datos almacenados en discos remotos (por ejemplo, S3, Azure Blob Storage), incluida la correspondencia entre las rutas locales de metadatos y las rutas remotas de blobs.

Cada fila representa un objeto blob remoto asociado a un archivo de datos.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `disk_name` ([String](/es/sql-reference/data-types/string)) — Nombre del disco.
* `path` ([String](/es/sql-reference/data-types/string)) — Ruta del disco.
* `cache_base_path` ([String](/es/sql-reference/data-types/string)) — Directorio base de los archivos de caché.
* `local_path` ([String](/es/sql-reference/data-types/string)) — Ruta del archivo de ClickHouse, que también se utiliza como ruta de metadatos.
* `remote_path` ([String](/es/sql-reference/data-types/string)) — Ruta del blob en el almacenamiento de objetos, al que está asociado el archivo de ClickHouse.
* `size` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño del archivo (comprimido).
* `common_prefix_for_blobs` ([String](/es/sql-reference/data-types/string)) — Prefijo común de los blobs en el almacenamiento de objetos.
* `cache_paths` ([Array(String)](/es/sql-reference/data-types/array)) — Archivos de caché del blob correspondiente.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql
SELECT * FROM system.remote_data_paths LIMIT 1 FORMAT Vertical;
```

```text
common_prefix_for_blobs:

```
