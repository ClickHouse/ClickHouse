<div id="description">
  ## Descripción
</div>

Contiene información sobre las tablas en las que se ha ejecutado `DROP TABLE`, pero cuya limpieza de datos aún no se ha realizado.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `index` ([UInt32](/es/sql-reference/data-types/int-uint)) — Índice en la cola `marked_dropped_tables`.
* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla.
* `uuid` ([UUID](/es/sql-reference/data-types/uuid)) — UUID de la tabla.
* `engine` ([String](/es/sql-reference/data-types/string)) — Nombre del motor de la tabla.
* `metadata_dropped_path` ([String](/es/sql-reference/data-types/string)) — Ruta del archivo de metadatos de la tabla en el directorio `metadata_dropped`.
* `table_dropped_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora a la que está programado el siguiente intento de eliminar los datos de la tabla. Normalmente, es el momento en que se eliminó la tabla más `database_atomic_delay_before_drop_table_sec`.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

El siguiente ejemplo muestra cómo obtener información sobre `dropped_tables`.

```sql
SELECT *
FROM system.dropped_tables\G
```

```text
Row 1:

table_dropped_time:    2023-03-16 23:43:31
```
