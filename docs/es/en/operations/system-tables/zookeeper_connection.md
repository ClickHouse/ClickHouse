<div id="description">
  ## Descripción
</div>

Esta tabla no existe si ZooKeeper no está configurado. La tabla `system.zookeeper_connection` muestra las conexiones actuales a ZooKeeper (incluidos los ZooKeepers auxiliares). Cada fila muestra información sobre una conexión.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](../../sql-reference/data-types/string.md)) — Nombre del clúster de ZooKeeper.
* `host` ([String](../../sql-reference/data-types/string.md)) — El hostname/IP del nodo de ZooKeeper al que se conectó ClickHouse.
* `port` ([UIn16](../../sql-reference/data-types/int-uint.md)) — El puerto del nodo de ZooKeeper al que se conectó ClickHouse.
* `index` ([Nullable(UInt8)](../../sql-reference/data-types/int-uint.md)) — El índice del nodo de ZooKeeper al que se conectó ClickHouse. El índice proviene de la configuración de ZooKeeper. Si no está conectado, esta columna es NULL.
* `connected_time` ([DateTime](../../sql-reference/data-types/datetime.md)) — Momento en que se estableció la conexión.
* `session_uptime_elapsed_seconds` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Segundos transcurridos desde que se estableció la conexión.
* `is_expired` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Indica si la conexión actual ha expirado.
* `keeper_api_version` ([UInt8](../../sql-reference/data-types/int-uint.md)) — Versión de la API de Keeper.
* `client_id` ([Int64](../../sql-reference/data-types/int-uint.md)) — ID de sesión de la conexión.
* `xid` ([Int64](../../sql-reference/data-types/int-uint.md)) — XID de la sesión actual.
* `enabled_feature_flags` ([Array(Enum16)](../../sql-reference/data-types/array.md)) — Feature flags habilitados. Solo se aplica a ClickHouse Keeper. Los posibles valores son `FILTERED_LIST`, `MULTI_READ`, `CHECK_NOT_EXISTS`, `CREATE_IF_NOT_EXISTS`, `REMOVE_RECURSIVE`.
* `availability_zone` ([String](../../sql-reference/data-types/string.md)) — Zona de disponibilidad.
* `session_timeout_ms` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Tiempo de espera de la sesión (en milisegundos).
* `last_zxid_seen` ([Int64](../../sql-reference/data-types/int-uint.md)) — Último zxid visto por la sesión actual.

{/*AUTOGENERATED_END*/ }
