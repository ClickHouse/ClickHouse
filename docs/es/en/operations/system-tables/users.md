<div id="description">
  ## Descripción
</div>

Contiene una lista de [cuentas de usuario](../../guides/sre/user-management/index.md#user-account-management) configuradas en el servidor.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de usuario.
* `id` ([UUID](/es/sql-reference/data-types/uuid)) — ID de usuario.
* `storage` ([String](/es/sql-reference/data-types/string)) — Ruta al almacenamiento de usuarios. Se configura en el parámetro access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/es/sql-reference/data-types/array)) — Muestra los tipos de autenticación. Hay varias formas de identificar al usuario: sin contraseña, con contraseña en texto sin formato, con contraseña codificada con SHA256, con contraseña codificada con doble SHA-1 o con contraseña codificada con bcrypt.
* `auth_params` ([Array(String)](/es/sql-reference/data-types/array)) — Parámetros de autenticación en formato JSON según el auth&#95;type.
* `valid_until` ([Array(DateTime)](/es/sql-reference/data-types/array)) — Fecha y hora de vencimiento de las credenciales del usuario.
* `host_ip` ([Array(String)](/es/sql-reference/data-types/array)) — Direcciones IP de los hosts que pueden conectarse al servidor ClickHouse.
* `host_names` ([Array(String)](/es/sql-reference/data-types/array)) — Nombres de los hosts que pueden conectarse al servidor ClickHouse.
* `host_names_regexp` ([Array(String)](/es/sql-reference/data-types/array)) — Expresión regular para los nombres de los hosts que pueden conectarse al servidor ClickHouse.
* `host_names_like` ([Array(String)](/es/sql-reference/data-types/array)) — Nombres de los hosts que pueden conectarse al servidor ClickHouse, establecidos mediante el predicado LIKE.
* `default_roles_all` ([UInt8](/es/sql-reference/data-types/int-uint)) — Muestra que todos los roles concedidos están configurados como predeterminados para el usuario.
* `default_roles_list` ([Array(String)](/es/sql-reference/data-types/array)) — Lista de roles concedidos establecidos como predeterminados.
* `default_roles_except` ([Array(String)](/es/sql-reference/data-types/array)) — Todos los roles concedidos establecidos como predeterminados, excepto los enumerados.
* `grantees_any` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que muestra si un usuario con cualquier grant option puede concederla a cualquier usuario.
* `grantees_list` ([Array(String)](/es/sql-reference/data-types/array)) — Lista de usuarios o roles a los que este usuario puede conceder grant options.
* `grantees_except` ([Array(String)](/es/sql-reference/data-types/array)) — Lista de usuarios o roles a los que este usuario no puede conceder grant options.
* `default_database` ([String](/es/sql-reference/data-types/string)) — El nombre de la base de datos predeterminada de este usuario.
