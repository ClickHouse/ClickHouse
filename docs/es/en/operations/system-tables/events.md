<div id="description">
  ## Descripción
</div>

Contiene información sobre la cantidad de eventos que se han producido en el sistema. Por ejemplo, en la tabla puede ver cuántas consultas `SELECT` se han procesado desde que se inició el servidor ClickHouse.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `event` ([String](/es/sql-reference/data-types/string)) — Nombre del evento.
* `value` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de eventos producidos.
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción del evento.

**Aliases:**

* `name` — Alias de `event`.

{/*AUTOGENERATED_END*/ }

<div id="example">

```sql
SELECT * FROM system.events LIMIT 5
```
