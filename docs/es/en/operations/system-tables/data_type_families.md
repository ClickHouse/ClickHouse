<div id="description">
  ## Descripción
</div>

Contiene información sobre los [tipos de datos](../../sql-reference/data-types/index.md) admitidos.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del tipo de dato.
* `case_insensitive` ([UInt8](/es/sql-reference/data-types/int-uint)) — Propiedad que indica si se puede usar un nombre de tipo de dato en una consulta sin distinguir entre mayúsculas y minúsculas. Por ejemplo, `Date` y `date` son válidos.
* `alias_to` ([String](/es/sql-reference/data-types/string)) — Nombre del tipo de dato del que `name` es alias.
* `description` ([String](/es/sql-reference/data-types/string)) — Descripción general del tipo de dato.
* `syntax` ([String](/es/sql-reference/data-types/string)) — Cómo se escribe la sintaxis del tipo de dato en una consulta.
* `examples` ([String](/es/sql-reference/data-types/string)) — Ejemplos de uso.
* `introduced_in` ([String](/es/sql-reference/data-types/string)) — Versión de ClickHouse en la que se introdujo por primera vez el tipo de dato, en formato major.minor.
* `related` ([Array](/es/sql-reference/data-types/array)([String](/es/sql-reference/data-types/string))) — Nombres de los tipos de dato relacionados.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql
SELECT name, case_insensitive, alias_to FROM system.data_type_families WHERE alias_to = 'String'
```

```text
│ TEXT       │                1 │ String   │
│ VARCHAR    │                1 │ String   │
│ MEDIUMBLOB │                1 │ String   │
│ BLOB       │                1 │ String   │
│ TINYBLOB   │                1 │ String   │
│ CHAR       │                1 │ String   │
│ MEDIUMTEXT │                1 │ String   │
└────────────┴──────────────────┴──────────┘
```
