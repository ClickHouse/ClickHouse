<div id="description">
  ## Descripción
</div>

Contiene las asignaciones de roles a usuarios y roles. Para agregar entradas a esta tabla, use `GRANT role TO user`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `user_name` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Nombre de usuario.
* `role_name` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — Nombre del rol.
* `granted_role_name` ([String](/es/sql-reference/data-types/string)) — Nombre del rol concedido al rol `role_name`. Para conceder un rol a otro, use `GRANT role1 TO role2`.
* `granted_role_id` ([UUID](/es/sql-reference/data-types/uuid)) — El ID del rol.
* `granted_role_is_default` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que muestra si `granted_role` es un rol predeterminado. Valores posibles: • 1 — `granted_role` es un rol predeterminado, • 0 — `granted_role` no es un rol predeterminado.
* `with_admin_option` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indicador que muestra si `granted_role` es un rol con el privilegio `ADMIN OPTION`. Valores posibles: • 1 — El rol tiene el privilegio `ADMIN OPTION`. • 0 — El rol no tiene el privilegio `ADMIN OPTION`.

{/*AUTOGENERATED_END*/ }
