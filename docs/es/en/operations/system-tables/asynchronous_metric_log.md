<div id="description">
  ## Descripción
</div>

Contiene los valores históricos de `system.asynchronous_metrics`, que se guardan una vez por intervalo de tiempo (un segundo de forma predeterminada). Está habilitada de forma predeterminada.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Hostname del servidor que ejecuta la consulta.
* `event_date` ([Date](/es/sql-reference/data-types/date)) — Fecha del evento.
* `event_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora del evento.
* `metric` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre de la métrica.
* `value` ([Float64](/es/sql-reference/data-types/float)) — Valor de la métrica.

{/*AUTOGENERATED_END*/ }

SELECT * FROM system.asynchronous_metric_log LIMIT 3 \G
