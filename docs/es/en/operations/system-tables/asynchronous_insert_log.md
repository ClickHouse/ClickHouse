<div id="description">
  ## Descripción
</div>

Contiene información sobre las inserciones asíncronas. Cada entrada representa una consulta de inserción almacenada en búfer en una consulta de inserción asíncrona.

Para activar el registro, configure los parámetros en la sección [asynchronous&#95;insert&#95;log](../../operations/server-configuration-parameters/settings.md#asynchronous_insert_log).

El intervalo de vaciado de los datos se establece en el parámetro `flush_interval_milliseconds` de la sección de configuración del servidor [asynchronous&#95;insert&#95;log](../../operations/server-configuration-parameters/settings.md#asynchronous_insert_log). Para forzar el vaciado, use la consulta [SYSTEM FLUSH LOGS](/es/sql-reference/statements/system#flush-logs).

ClickHouse no elimina automáticamente los datos de la tabla. Consulte [Introducción](/es/operations/system-tables/overview#system-tables-introduction) para obtener más detalles.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre de host del servidor que ejecuta la consulta.
* `event_date` ([Date](/es/sql-reference/data-types/date)) — La fecha en que se realizó la inserción asíncrona.
* `event_time` ([DateTime](/es/sql-reference/data-types/datetime)) — La fecha y hora en que la inserción asíncrona terminó de ejecutarse.
* `event_time_microseconds` ([DateTime64(6)](/es/sql-reference/data-types/datetime64)) — La fecha y hora en que la inserción asíncrona terminó de ejecutarse, con precisión de microsegundos.
* `query` ([String](/es/sql-reference/data-types/string)) — Cadena de consulta.
* `database` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — El nombre de la base de datos en la que se encuentra la tabla.
* `table` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre de la tabla.
* `format` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre del formato.
* `query_id` ([String](/es/sql-reference/data-types/string)) — ID de la consulta inicial.
* `bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de bytes insertados.
* `rows` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de filas insertadas.
* `exception` ([String](/es/sql-reference/data-types/string)) — Mensaje de excepción.
* `status` ([Enum8(&#39;Ok&#39; = 0, &#39;ParsingError&#39; = 1, &#39;FlushError&#39; = 2)](/es/sql-reference/data-types/enum)) — Estado de la inserción. Valores: &#39;Ok&#39; = 0 — Inserción correcta, &#39;ParsingError&#39; = 1 — Excepción al procesar los datos, &#39;FlushError&#39; = 2 — Excepción al vaciar los datos.
* `data_kind` ([Enum8(&#39;Parsed&#39; = 0, &#39;Preprocessed&#39; = 1)](/es/sql-reference/data-types/enum)) — Estado de los datos. Valores: &#39;Parsed&#39; y &#39;Preprocessed&#39;.
* `flush_time` ([DateTime](/es/sql-reference/data-types/datetime)) — La fecha y hora en que se produjo el vaciado.
* `flush_time_microseconds` ([DateTime64(6)](/es/sql-reference/data-types/datetime64)) — La fecha y hora en que se produjo el vaciado, con precisión de microsegundos.
* `flush_query_id` ([String](/es/sql-reference/data-types/string)) — ID de la consulta de vaciado.
* `timeout_milliseconds` ([UInt64](/es/sql-reference/data-types/int-uint)) — El tiempo de espera adaptativo calculado para esta entrada.

{/*AUTOGENERATED_END*/ }
