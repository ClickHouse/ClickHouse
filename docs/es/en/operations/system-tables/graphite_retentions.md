<div id="description">
  ## Descripción
</div>

Contiene información sobre los parámetros [graphite&#95;rollup](../../operations/server-configuration-parameters/settings.md#graphite), que se utilizan en tablas con motores [*GraphiteMergeTree](../../engines/table-engines/mergetree-family/graphitemergetree.md).

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `config_name` ([String](/es/sql-reference/data-types/string)) — Nombre del parámetro graphite&#95;rollup.
* `rule_type` ([String](/es/sql-reference/data-types/string)) — El tipo de regla. Valores posibles: RuleTypeAll = 0 - predeterminado, con regex, compatible con el esquema antiguo; RuleTypePlain = 1 - métricas simples, con regex, compatible con el esquema antiguo; RuleTypeTagged = 2 - métricas etiquetadas, con regex, compatible con el esquema antiguo; RuleTypeTagList = 3 - métricas etiquetadas, con regex (convertido a RuleTypeTagged a partir de una cadena como &#39;retention=10min ; env=(staging|prod)&#39;)
* `regexp` ([String](/es/sql-reference/data-types/string)) — Patrón para el nombre de la métrica.
* `function` ([String](/es/sql-reference/data-types/string)) — El nombre de la función de agregación.
* `age` ([UInt64](/es/sql-reference/data-types/int-uint)) — La antigüedad mínima de los datos en segundos.
* `precision` ([UInt64](/es/sql-reference/data-types/int-uint)) — Con qué precisión se define la antigüedad de los datos en segundos.
* `priority` ([UInt16](/es/sql-reference/data-types/int-uint)) — Prioridad del patrón.
* `is_default` ([UInt8](/es/sql-reference/data-types/int-uint)) — Si el patrón es el predeterminado.
* `Tables.database` ([Array(String)](/es/sql-reference/data-types/array)) — Array de nombres de bases de datos de las tablas que usan el parámetro `config_name`.
* `Tables.table` ([Array(String)](/es/sql-reference/data-types/array)) — Array de nombres de tablas que usan el parámetro `config_name`.
