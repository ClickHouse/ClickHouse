<div id="purpose">
  ## Descripción
</div>

La tabla `system.delta_lake_metadata_log` registra eventos de acceso a metadatos y análisis de tablas de Delta Lake leídas por ClickHouse. Proporciona información detallada sobre cada archivo de metadatos, lo que resulta útil para la depuración, la auditoría y para comprender la evolución de la estructura de las tablas de Delta Lake.

Esta tabla registra cada archivo de metadatos leído de las tablas de Delta Lake. Ayuda a los usuarios a rastrear cómo ClickHouse interpreta los metadatos de las tablas de Delta Lake y a diagnosticar issues relacionados con la evolución del esquema, la resolución de instantáneas o la planificación de consultas.

:::note
Esta tabla está destinada principalmente a tareas de depuración.
:::

<div id="controlling-log-verbosity">
  ### Control de la verbosidad del registro
</div>

Puede controlar qué eventos de metadatos se registran mediante la configuración [`delta_lake_log_metadata`](../../operations/settings/settings.md#delta_lake_log_metadata).

Para registrar todos los metadatos utilizados en la consulta actual:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```
