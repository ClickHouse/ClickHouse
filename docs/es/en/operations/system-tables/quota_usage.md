<div id="description">
  ## Descripción
</div>

Uso de la cuota del usuario actual: cuánto se ha utilizado y cuánto queda disponible.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `quota_name` ([String](/es/sql-reference/data-types/string)) — Nombre de la cuota.
* `quota_key` ([String](/es/sql-reference/data-types/string)) — Valor de la clave.
* `start_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de inicio para calcular el consumo de recursos.
* `end_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de finalización para calcular el consumo de recursos.
* `duration` ([Nullable(UInt32)](/es/sql-reference/data-types/nullable)) — Duración del intervalo de tiempo para calcular el consumo de recursos, en segundos.
* `queries` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número actual de consultas ejecutadas.
* `max_queries` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de consultas de cualquier tipo que pueden ejecutarse.
* `query_selects` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número actual de consultas SELECT ejecutadas.
* `max_query_selects` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de consultas SELECT que pueden ejecutarse.
* `query_inserts` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número actual de consultas INSERT ejecutadas.
* `max_query_inserts` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de consultas INSERT que pueden ejecutarse.
* `errors` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número actual de consultas que produjeron un error.
* `max_errors` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de consultas que produjeron un error dentro del período de tiempo especificado.
* `result_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total actual de filas en el conjunto de resultados de todas las consultas dentro del período de tiempo actual.
* `max_result_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total máximo permitido de filas en el conjunto de resultados de todas las consultas dentro del período de tiempo especificado.
* `result_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total actual de bytes en el conjunto de resultados de todas las consultas dentro del período de tiempo actual.
* `max_result_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total máximo permitido de bytes en el conjunto de resultados de todas las consultas dentro del período de tiempo especificado.
* `read_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total actual de filas leídas durante la ejecución de todas las consultas dentro del período de tiempo actual.
* `max_read_rows` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de filas que pueden leerse durante la ejecución de todas las consultas dentro del período de tiempo especificado.
* `read_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total actual de bytes leídos durante la ejecución de todas las consultas dentro del período de tiempo actual.
* `max_read_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de bytes que pueden leerse durante la ejecución de todas las consultas dentro del período de tiempo especificado.
* `execution_time` ([Nullable(Float64)](/es/sql-reference/data-types/nullable)) — El tiempo total actual (en nanosegundos) empleado en ejecutar consultas dentro del período de tiempo actual
* `max_execution_time` ([Nullable(Float64)](/es/sql-reference/data-types/nullable)) — El tiempo máximo (en nanosegundos) permitido para ejecutar todas las consultas dentro del período de tiempo especificado
* `written_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número total actual de bytes escritos durante la ejecución de todas las consultas dentro del período de tiempo actual.
* `max_written_bytes` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de bytes que pueden escribirse durante la ejecución de todas las consultas dentro del período de tiempo especificado.
* `failed_sequential_authentications` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número actual de fallos consecutivos de autenticación dentro del período de tiempo actual.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de fallos consecutivos de autenticación dentro del período de tiempo especificado.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo actual de ejecuciones de una misma consulta normalizada dentro del período de tiempo actual.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/es/sql-reference/data-types/nullable)) — El número máximo permitido de ejecuciones de una misma consulta normalizada dentro del período de tiempo especificado.
