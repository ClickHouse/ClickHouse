<div id="description">
  ## Descripción
</div>

Contiene una lista de todos los failpoints disponibles registrados en el servidor, junto con su tipo y si están habilitados actualmente.

Los failpoints pueden habilitarse y deshabilitarse en tiempo de ejecución mediante las Sentencias `SYSTEM ENABLE FAILPOINT` y `SYSTEM DISABLE FAILPOINT`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del failpoint.
* `type` ([Enum8(&#39;once&#39; = 0, &#39;regular&#39; = 1, &#39;pauseable&#95;once&#39; = 2, &#39;pauseable&#39; = 3)](/es/sql-reference/data-types/enum)) — Tipo de failpoint: &#39;once&#39; se activa una sola vez y luego se deshabilita automáticamente; &#39;regular&#39; se activa siempre; &#39;pauseable&#95;once&#39; bloquea la ejecución una vez; &#39;pauseable&#39; bloquea la ejecución siempre hasta que se reanuda.
* `enabled` ([UInt8](/es/sql-reference/data-types/int-uint)) — Indica si el failpoint está habilitado actualmente (1) o deshabilitado (0).

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SYSTEM ENABLE FAILPOINT replicated_merge_tree_insert_retry_pause;
SELECT * FROM system.fail_points WHERE enabled = 1
```
