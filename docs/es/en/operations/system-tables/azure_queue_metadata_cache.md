<div id="description">
  ## Descripción
</div>

Contiene el estado en memoria de los metadatos de AzureQueue y las filas actualmente procesadas de cada archivo.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `zookeeper_path` ([String](/es/sql-reference/data-types/string)) — Ruta en ZooKeeper de los metadatos
* `file_path` ([String](/es/sql-reference/data-types/string)) — Ruta del archivo que se está procesando
* `file_name` ([String](/es/sql-reference/data-types/string)) — Nombre del archivo que se está procesando
* `rows_processed` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de filas procesadas actualmente
* `status` ([String](/es/sql-reference/data-types/string)) — Estado del procesamiento: Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de inicio del procesamiento del archivo
* `processing_end_time` ([Nullable(DateTime)](/es/sql-reference/data-types/nullable)) — Hora de finalización del procesamiento del archivo
* `exception` ([String](/es/sql-reference/data-types/string)) — Excepción ocurrida durante el procesamiento

{/*AUTOGENERATED_END*/ }
