<div id="description">
  ## Descripción
</div>

Contiene información sobre las restricciones existentes en todas las tablas.

Las restricciones definidas en las [tablas temporales](../../sql-reference/statements/create/table.md#temporary-tables) solo son visibles en `system.constraints` dentro de la sesión en la que se crearon. Se muestran con el campo `database` vacío.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla.
* `name` ([String](/es/sql-reference/data-types/string)) — Nombre de la restricción.
* `type` ([Enum8(&#39;CHECK&#39; = 0, &#39;ASSUME&#39; = 1)](/es/sql-reference/data-types/enum)) — Tipo de restricción.
* `expression` ([String](/es/sql-reference/data-types/string)) — Expresión de la restricción.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql
SELECT * FROM system.constraints LIMIT 2 FORMAT Vertical;
```

```text
Row 1:
──────
database:    default
table:       hits
name:        check_hits
type:        CHECK
expression:  CounterID > 0

Row 2:
──────
database:    default
table:       hits
name:        assume_positive
type:        ASSUME
expression:  WatchID > 0
```
