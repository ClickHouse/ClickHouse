<div id="description">
  ## Descripción
</div>

Muestra todos los tokenizadores disponibles.
Se pueden usar en las funciones [tokens](../../sql-reference/functions/splitting-merging-functions.md#tokens), [hasAllTokens](../../sql-reference/functions/string-search-functions.md#hasAllTokens), [hasAnyTokens](../../sql-reference/functions/string-search-functions.md#hasAnyTokens) y en el [índice de texto](../../engines/table-engines/mergetree-family/textindexes.md).

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del tokenizador

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql
SELECT * FROM system.tokenizers;
```
