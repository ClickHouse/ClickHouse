<div id="description">
  ## Descripción
</div>

Esta tabla no existe si este nodo no está configurado para ejecutar ClickHouse Keeper en el mismo proceso. Contiene una fila por cada archivo de instantánea de Raft que rastrea la máquina de estados de Keeper en el mismo proceso, incluidas las instantáneas que se están recibiendo actualmente del líder.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `last_log_index` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Último índice de log cubierto por la instantánea.
* `path` ([String](../../sql-reference/data-types/string.md)) — Ruta del archivo de instantánea en el disco.
* `disk_name` ([String](../../sql-reference/data-types/string.md)) — Nombre del disco que almacena la instantánea.
* `size_bytes` ([UInt64](../../sql-reference/data-types/int-uint.md)) — Tamaño del archivo de instantánea en el disco.
* `last_modified_at` ([DateTime](../../sql-reference/data-types/datetime.md)) — Hora de la última modificación del archivo de instantánea.
* `is_received` ([Bool](../../sql-reference/data-types/boolean.md)) — `true` si la instantánea se está recibiendo actualmente desde el líder. En esas filas, `size_bytes` y `last_modified_at` reflejan el archivo parcial tal como se ha escrito hasta el momento y pueden indicar un valor menor que el real.
* `exists_on_disk` ([Bool](../../sql-reference/data-types/boolean.md)) — Indica si el archivo de instantánea está presente actualmente en el disco. Siempre es `true` para las instantáneas finalizadas (`is_received` = `false`), a menos que el archivo se haya eliminado por fuera del sistema o esté corrupto; puede ser `false` para las instantáneas que se están recibiendo (`is_received` = `true`) antes de que se haya escrito cualquier byte.

{/*AUTOGENERATED_END*/ }

Ejemplo:

```sql
SELECT * FROM system.keeper_snapshots ORDER BY last_log_index;
```
