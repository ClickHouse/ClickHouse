<div id="description">
  ## Descripción
</div>

Contiene la lista de las fuentes de diccionario admitidas por el servidor, junto con la documentación integrada de cada fuente. Una fuente de diccionario determina de dónde se cargan los datos del diccionario; se especifica en la cláusula `SOURCE` de una consulta `CREATE DICTIONARY`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — El nombre de la fuente del diccionario, tal como se especifica en la cláusula SOURCE.
* `description` ([String](/es/sql-reference/data-types/string)) — Una descripción general de lo que hace la fuente del diccionario.
* `syntax` ([String](/es/sql-reference/data-types/string)) — La estructura de la cláusula SOURCE utilizada para especificar la fuente. Ten en cuenta que algunas fuentes están sujetas a control de acceso cuando un diccionario se crea a partir de una consulta DDL (en lugar de un archivo de configuración del servidor); consulta la `description` de la fuente correspondiente para obtener más detalles.
* `examples` ([String](/es/sql-reference/data-types/string)) — Ejemplos de uso.
* `introduced_in` ([String](/es/sql-reference/data-types/string)) — La versión de ClickHouse en la que se introdujo por primera vez la fuente, en el formato major.minor.
* `related` ([Array](/es/sql-reference/data-types/array)([String](/es/sql-reference/data-types/string))) — Los nombres de las fuentes de diccionario relacionadas.

{/*AUTOGENERATED_END*/ }

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SELECT name, syntax
FROM system.dictionary_sources
WHERE name IN ('clickhouse', 'file')
ORDER BY name
```

```text title="Response"
┌─name───────┬─syntax─────────────────────────────────────────────────────────────────────────┐
│ clickhouse │ SOURCE(CLICKHOUSE(host 'host' port 9000 user 'default' password '' db 'db' table 'table')) │
│ file       │ SOURCE(FILE(path '/path/to/file' format 'CSV'))                                  │
└────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
