<div id="description">
  ## Descripción
</div>

Contiene advertencias sobre la configuración del servidor que `clickhouse-client` mostrará justo después de conectarse al servidor.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `message` ([String](/es/sql-reference/data-types/string)) — Un mensaje de advertencia emitido por el servidor ClickHouse.
* `message_format_string` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Una cadena de formato utilizada para dar formato al mensaje.

{/*AUTOGENERATED_END*/ }
