<div id="description">
  ## Descripción
</div>

Contiene información sobre los [roles](../../guides/sre/user-management/index.md#role-management) que se han configurado.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `name` ([String](/es/sql-reference/data-types/string)) — Nombre del rol.
* `id` ([UUID](/es/sql-reference/data-types/uuid)) — ID del rol.
* `storage` ([String](/es/sql-reference/data-types/string)) — Ruta del almacenamiento de roles. Se configura en el parámetro `access_control_path`.

{/*AUTOGENERATED_END*/ }
