<div id="description">
  ## Descripción
</div>

Esta tabla del sistema contiene metadatos por archivo de las tablas Iceberg existentes en ClickHouse, con una fila por cada archivo de datos o de eliminación al que hace referencia la snapshot actual de cada tabla. Estará vacía si no tienes ninguna tabla Iceberg en ClickHouse.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla.
* `snapshot_id` ([Int64](/es/sql-reference/data-types/int-uint)) — ID del snapshot en el que se añadió el archivo.
* `content` ([Enum8](/es/sql-reference/data-types/enum)) — Tipo de contenido del archivo: `DATA`, `POSITION_DELETE` o `EQUALITY_DELETE`.
* `file_path` ([String](/es/sql-reference/data-types/string)) — Ruta de almacenamiento resuelta del archivo.
* `file_format` ([String](/es/sql-reference/data-types/string)) — Formato del archivo, p. ej., `'PARQUET'`.
* `record_count` ([Int64](/es/sql-reference/data-types/int-uint)) — Número de registros del archivo.
* `file_size_in_bytes` ([Int64](/es/sql-reference/data-types/int-uint)) — Tamaño del archivo en bytes.
* `partition` ([String](/es/sql-reference/data-types/string)) — Representación textual de la tupla de partición.
* `schema_id` ([Int32](/es/sql-reference/data-types/int-uint)) — ID del esquema resuelto para esta entrada del manifiesto.
* `sequence_number` ([Int64](/es/sql-reference/data-types/int-uint)) — Número de secuencia resuelto de la entrada del manifiesto (siempre 0 para el formato v1).
* `sort_order_id` ([Nullable(Int32)](/es/sql-reference/data-types/nullable)) — ID del orden de clasificación del archivo, si se especifica.
* `null_value_counts` ([Map(Int32, Int64)](/es/sql-reference/data-types/map)) — Recuento de valores nulos por columna (id de columna -&gt; recuento).
* `column_sizes` ([Map(Int32, Int64)](/es/sql-reference/data-types/map)) — Tamaño en disco por columna, en bytes (id de columna -&gt; bytes).
* `value_counts` ([Map(Int32, Int64)](/es/sql-reference/data-types/map)) — Recuento total de valores por columna (id de columna -&gt; recuento).
* `equality_ids` ([Array(Int32)](/es/sql-reference/data-types/array)) — ID de los campos de igualdad para archivos de eliminación por igualdad (vacío para archivos que no son de este tipo).
