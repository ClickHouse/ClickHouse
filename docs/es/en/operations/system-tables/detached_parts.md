<div id="purpose">
  ## Descripción
</div>

Contiene información sobre las partes desvinculadas de las tablas [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md). La columna `reason` indica por qué se desvinculó la parte.

En las partes desvinculadas por el usuario, el motivo está vacío. Estas partes se pueden adjuntar con el comando [ALTER TABLE ATTACH PARTITION|PART](/es/sql-reference/statements/alter/partition#attach-partitionpart).

Para ver la descripción de las demás columnas, consulte [system.parts](../../operations/system-tables/parts.md).

Si el nombre de la parte no es válido, los valores de algunas columnas pueden ser `NULL`. Estas partes se pueden eliminar con [ALTER TABLE DROP DETACHED PART](/es/sql-reference/statements/alter/partition#drop-detached-partitionpart).

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `database` ([String](/es/sql-reference/data-types/string)) — El nombre de la base de datos a la que pertenece esta parte.
* `table` ([String](/es/sql-reference/data-types/string)) — El nombre de la tabla a la que pertenece esta parte.
* `partition_id` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — El identificador de la partición a la que pertenece esta parte.
* `name` ([String](/es/sql-reference/data-types/string)) — El nombre de la parte.
* `bytes_on_disk` ([UInt64](/es/sql-reference/data-types/int-uint)) — El tamaño total, en bytes, de todos los archivos de la parte de datos.
* `modification_time` ([DateTime](/es/sql-reference/data-types/datetime)) — La fecha y hora en que se modificó el directorio que contiene la parte de datos. Normalmente corresponde al momento en que se ejecutó `detach`.
* `disk` ([String](/es/sql-reference/data-types/string)) — El nombre del disco que almacena esta parte de datos.
* `path` ([String](/es/sql-reference/data-types/string)) — La ruta en el disco al archivo de esta parte de datos.
* `reason` ([Nullable(String)](/es/sql-reference/data-types/nullable)) — La razón por la que se hizo `detach` de esta parte.
* `min_block_number` ([Nullable(Int64)](/es/sql-reference/data-types/nullable)) — El número mínimo de partes de datos que componen la parte actual después de la fusión.
* `max_block_number` ([Nullable(Int64)](/es/sql-reference/data-types/nullable)) — El número máximo de partes de datos que componen la parte actual después de la fusión.
* `level` ([Nullable(UInt32)](/es/sql-reference/data-types/nullable)) — Profundidad del árbol de fusiones. Cero significa que la parte actual se creó mediante `insert` en lugar de por la fusión de otras partes.

{/*AUTOGENERATED_END*/ }
