<div id="description">
  ## Descripción
</div>

La tabla `system.part_log` se crea solo si se especifica la configuración del servidor [part&#95;log](/es/operations/server-configuration-parameters/settings#part_log).

Esta tabla contiene información sobre eventos relacionados con [partes de datos](../../engines/table-engines/mergetree-family/custom-partitioning-key.md) en tablas de la familia [MergeTree](../../engines/table-engines/mergetree-family/mergetree.md), como la adición o la fusión de datos.

La tabla `system.part_log` contiene las siguientes columnas:

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/ }

* `hostname` ([LowCardinality(String)](/es/sql-reference/data-types/lowcardinality)) — Nombre de host del servidor que ejecuta la consulta.
* `query_id` ([String](/es/sql-reference/data-types/string)) — Identificador de la consulta INSERT que creó esta parte de datos.
* `event_type` ([Enum8(&#39;NewPart&#39; = 1, &#39;MergeParts&#39; = 2, &#39;DownloadPart&#39; = 3, &#39;RemovePart&#39; = 4, &#39;MutatePart&#39; = 5, &#39;MovePart&#39; = 6, &#39;MergePartsStart&#39; = 7, &#39;MutatePartStart&#39; = 8)](/es/sql-reference/data-types/enum)) — Tipo de evento ocurrido con la parte de datos. Puede tener uno de los siguientes valores: NewPart — Inserción de una nueva parte de datos, MergePartsStart — Ha comenzado la fusión de partes de datos, MergeParts — Ha finalizado la fusión de partes de datos, DownloadPart — Descarga de una parte de datos, RemovePart — Eliminación o desvinculación de una parte de datos mediante [DETACH PARTITION](/es/sql-reference/statements/alter/partition#detach-partitionpart). MutatePartStart — Ha comenzado la mutación de una parte de datos, MutatePart — Ha finalizado la mutación de una parte de datos, MovePart — Movimiento de la parte de datos de un disco a otro.
* `merge_reason` ([Enum8(&#39;NotAMerge&#39; = 1, &#39;RegularMerge&#39; = 2, &#39;TTLDeleteMerge&#39; = 3, &#39;TTLRecompressMerge&#39; = 4, &#39;TTLDropMerge&#39; = 5)](/es/sql-reference/data-types/enum)) — Motivo del evento de tipo MERGE&#95;PARTS. Puede tener uno de los siguientes valores: NotAMerge — El evento actual tiene un tipo distinto de MERGE&#95;PARTS, RegularMerge — Una fusión normal, TTLDeleteMerge, TTLDropMerge — Limpieza de datos caducados. TTLRecompressMerge — Recompresión de la parte de datos con el.
* `merge_algorithm` ([Enum8(&#39;Undecided&#39; = 0, &#39;Vertical&#39; = 1, &#39;Horizontal&#39; = 2)](/es/sql-reference/data-types/enum)) — Algoritmo de fusión para el evento de tipo MERGE&#95;PARTS. Puede tener uno de los siguientes valores: Undecided, Horizontal, Vertical
* `event_date` ([Date](/es/sql-reference/data-types/date)) — Fecha del evento.
* `event_time` ([DateTime](/es/sql-reference/data-types/datetime)) — Hora del evento.
* `event_time_microseconds` ([DateTime64(6)](/es/sql-reference/data-types/datetime64)) — Hora del evento con precisión de microsegundos.
* `duration_ms` ([UInt64](/es/sql-reference/data-types/int-uint)) — Duración de esta operación.
* `database` ([String](/es/sql-reference/data-types/string)) — Nombre de la base de datos en la que se encuentra la parte de datos.
* `table` ([String](/es/sql-reference/data-types/string)) — Nombre de la tabla en la que se encuentra la parte de datos.
* `table_uuid` ([UUID](/es/sql-reference/data-types/uuid)) — UUID de la tabla a la que pertenece la parte de datos.
* `part_name` ([String](/es/sql-reference/data-types/string)) — Nombre de la parte de datos.
* `partition_id` ([String](/es/sql-reference/data-types/string)) — ID de la partición en la que se insertó la parte de datos. La columna toma el valor `all` si la partición se define por `tuple()`.
* `partition` ([String](/es/sql-reference/data-types/string)) — Nombre de la partición.
* `part_type` ([String](/es/sql-reference/data-types/string)) — Tipo de la parte. Valores posibles: Wide y Compact.
* `part_storage_type` ([String](/es/sql-reference/data-types/string)) — Tipo de DataPartStorage. Valores posibles: Packed - todos los archivos se almacenan en un único blob, Full - un blob por archivo.
* `disk_name` ([String](/es/sql-reference/data-types/string)) — Nombre del disco en el que se encuentra la parte de datos.
* `path_on_disk` ([String](/es/sql-reference/data-types/string)) — Ruta absoluta a la carpeta con los archivos de la parte de datos.
* `rows` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de filas de la parte de datos.
* `size_in_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño de la parte de datos en disco, en bytes.
* `merged_from` ([Array(String)](/es/sql-reference/data-types/array)) — Un array con los nombres de las partes de origen a partir de las cuales se creó la parte actual.
* `bytes_uncompressed` ([UInt64](/es/sql-reference/data-types/int-uint)) — Tamaño sin comprimir de la parte resultante en bytes.
* `read_rows` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de filas leídas durante la fusión.
* `read_bytes` ([UInt64](/es/sql-reference/data-types/int-uint)) — Número de bytes leídos durante la fusión.
* `peak_memory_usage` ([UInt64](/es/sql-reference/data-types/int-uint)) — La cantidad máxima de RAM utilizada durante la fusión.
* `deduplication_block_ids` ([Array(String)](/es/sql-reference/data-types/array)) — Un array de ID de bloques usados para la deduplicación al insertar esta parte.
* `error` ([UInt16](/es/sql-reference/data-types/int-uint)) — El código de error de la excepción producida.
* `exception` ([String](/es/sql-reference/data-types/string)) — Mensaje de texto del error producido.
* `mutation_ids` ([Array(String)](/es/sql-reference/data-types/array)) — Un array de ID de mutación aplicados a la parte de origen (`merged_from`) para el evento de tipo MUTATE&#95;PART&#95;START y MUTATE&#95;PART.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/es/sql-reference/data-types/map)) — Todos los eventos de perfil capturados durante esta operación.
* `projections_duration_ms` ([Map(LowCardinality(String), UInt64)](/es/sql-reference/data-types/map)) — Duración de fusión/reconstrucción por proyección en milisegundos.

**Alias:**

* `ProfileEvents.Names` — Alias de `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — Alias de `mapValues(ProfileEvents)`.
* `name` — Alias de `part_name`.

{/*AUTOGENERATED_END*/ }

La tabla `system.part_log` se crea después de insertar datos por primera vez en la tabla `MergeTree`.
