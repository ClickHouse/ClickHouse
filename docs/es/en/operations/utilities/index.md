| Herramienta/Utilidad                                                               | Descripción                                                                                                            |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| [clickhouse-local](../../operations/utilities/clickhouse-local.md)                 | Permite ejecutar consultas SQL sobre datos sin iniciar el servidor ClickHouse, de forma similar a como lo hace `awk`.  |
| [clickhouse-benchmark](../../operations/utilities/clickhouse-benchmark.md)         | Carga el servidor con consultas y configuraciones personalizadas.                                                      |
| [clickhouse-format](../../operations/utilities/clickhouse-format.md)               | Permite dar formato a las consultas de entrada.                                                                        |
| [ClickHouse obfuscator](../../operations/utilities/clickhouse-obfuscator.md)       | Ofusca datos.                                                                                                          |
| [ClickHouse compressor](../../operations/utilities/clickhouse-compressor.md)       | Comprime y descomprime datos.                                                                                          |
| [clickhouse-disks](../../operations/utilities/clickhouse-disks.md)                 | Proporciona operaciones similares a las de un sistema de archivos sobre archivos entre distintos discos de ClickHouse. |
| [clickhouse-odbc-bridge](../../operations/utilities/odbc-bridge.md)                | Servidor proxy para el ODBC Driver.                                                                                    |
| [clickhouse&#95;backupview](../../operations/utilities/backupview.md)              | Un módulo de Python para analizar backups de ClickHouse.                                                               |
| [clickhouse-keeper-client](../../operations/utilities/clickhouse-keeper-client.md) | Una aplicación cliente para interactuar con ClickHouse Keeper.                                                         |
| [Keeper HTTP API](../../operations/utilities/clickhouse-keeper-http-api.md)        | API HTTP y dashboard integrado para ClickHouse Keeper.                                                                 |
