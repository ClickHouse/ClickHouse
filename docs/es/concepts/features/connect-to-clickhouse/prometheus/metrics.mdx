ClickHouse expone sus propias métricas en un puerto dedicado con el formato de texto de Prometheus, de modo que un servidor de Prometheus pueda recopilarlas.

Si lo que desea es almacenar métricas de Prometheus en ClickHouse y consultarlas con PromQL, consulte [API HTTP de Prometheus y PromQL](/es/concepts/features/connect-to-clickhouse/prometheus).

<Note>
  Si utiliza ClickHouse Cloud, puede exponer métricas a Prometheus mediante la [integración de Prometheus](/es/products/cloud/features/monitoring/prometheus).
</Note>

## Configurar el puerto de métricas {#configure-the-metrics-port}

Configure un puerto dedicado cuando un servidor de Prometheus necesite recopilar las métricas propias de ClickHouse:

```xml
<prometheus>
    <port>9363</port>
    <endpoint>/metrics</endpoint>
    <metrics>true</metrics>
    <asynchronous_metrics>true</asynchronous_metrics>
    <events>true</events>
    <errors>true</errors>
    <histograms>true</histograms>
    <dimensional_metrics>true</dimensional_metrics>
</prometheus>
```

## Configurar handlers extendidos {#configure-extended-handlers}

La sección `<prometheus.handlers>` permite definir handlers más avanzados en el mismo puerto.
Esta sección es similar a [`<http_handlers>`](/es/concepts/features/connect-to-clickhouse/protocols/http), pero funciona para los protocolos de Prometheus:

```xml
<prometheus>
    <port>9363</port>
    <handlers>
        <my_rule_1>
            <url>/metrics</url>
            <handler>
                <type>expose_metrics</type>
                <metrics>true</metrics>
                <asynchronous_metrics>true</asynchronous_metrics>
                <events>true</events>
                <errors>true</errors>
                <histograms>true</histograms>
                <dimensional_metrics>true</dimensional_metrics>
                <labels>
                    <environment>production</environment>
                    <shard from_env="SHARD_NAME"></shard>
                </labels>
            </handler>
        </my_rule_1>
    </handlers>
</prometheus>
```

## Configuración {#settings}

Para conocer el comportamiento completo de estos ajustes, consulte la [sección de Prometheus](/es/reference/settings/server-settings/settings/other#prometheus) de la referencia de ajustes del servidor.

| ---------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `port`                       | none                 | Puerto en el que se sirven las métricas de ClickHouse.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `endpoint`                   | `/metrics`           | Endpoint HTTP para la recopilación de métricas. Comienza con `/`. No debe usarse junto con la sección `<handlers>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `url` / `headers` / `method` | none                 | Filtros utilizados para encontrar el handler que corresponde a una solicitud. Son similares a los campos homónimos de la sección [`<http_handlers>`](/es/concepts/features/connect-to-clickhouse/protocols/http).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `info`                       | true                 | Expone el gauge `ClickHouse_Info` con etiquetas de identidad del servidor (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `metrics`                    | true                 | Expone las métricas de [`system.metrics`](/es/reference/system-tables/metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `asynchronous_metrics`       | true                 | Expone las métricas de [`system.asynchronous_metrics`](/es/reference/system-tables/asynchronous_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `events`                     | true                 | Expone las métricas de [`system.events`](/es/reference/system-tables/events).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `errors`                     | true                 | Expone el recuento de errores de [`system.errors`](/es/reference/system-tables/errors).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `histograms`                 | true                 | Expone las métricas de [`system.histogram_metrics`](/es/reference/system-tables/histogram_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `dimensional_metrics`        | true                 | Expone las métricas de [`system.dimensional_metrics`](/es/reference/system-tables/dimensional_metrics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `labels`                     | none                 | Etiquetas constantes que se añaden a cada métrica expuesta. Cada elemento hijo define una etiqueta: el nombre del elemento es el nombre de la etiqueta (que debe coincidir con `[a-zA-Z_][a-zA-Z0-9_]*`) y el valor del elemento es el valor de la etiqueta. Los valores de las etiquetas admiten las sustituciones de configuración estándar, como el atributo `from_env`. Se rechaza un nombre de etiqueta si comienza con `__` (reservado por Prometheus) o si entra en conflicto con una etiqueta que este endpoint ya escribe para alguna de sus secciones habilitadas. Por lo tanto, el conjunto reservado depende de lo que el endpoint exporte en cada momento: `le` cuando `histograms` está habilitado; las etiquetas de `ClickHouse_Info` (`name`, `version`, `version_describe`, `version_major`, `version_minor`, `version_patch`) cuando `info` está habilitado; y cualquier etiqueta utilizada por una familia de métricas de histograma o dimensionales expuesta (por ejemplo, `group`, `direction` u `operation_type`) cuando `histograms` o `dimensional_metrics` está habilitado. Como depende de lo que el endpoint expone realmente, un mismo nombre puede ser válido en un endpoint y rechazarse en otro. |

## Verificar el endpoint {#check-the-endpoint}

```bash
curl http://127.0.0.1:9363/metrics
```
