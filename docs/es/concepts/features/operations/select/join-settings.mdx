Esta página recoge los ajustes de sesión que afectan a la semántica, la planificación, la ejecución y el uso de memoria de los JOIN. Cada ajuste enlaza a su entrada en la [referencia de ajustes de sesión](/es/reference/settings/session-settings), donde se indican su valor predeterminado y los valores admitidos. La sintaxis y la semántica de los JOIN se describen en la [referencia de la cláusula `JOIN`](/es/reference/statements/select/join).

## Semántica y sintaxis {#semantics-and-syntax}

| Ajuste                                                                                                                                                                                 | Descripción                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`join_default_strictness`](/es/reference/settings/session-settings/join#join_default_strictness)                                                                                         | Establece la estrictez de un JOIN escrito sin una estrictez explícita.                                                                                                    |
| [`any_join_distinct_right_table_keys`](/es/reference/settings/session-settings/other#any_join_distinct_right_table_keys)                                                                  | Habilita el comportamiento heredado de `ANY INNER JOIN` y `ANY LEFT JOIN`, en el que `t1 ANY LEFT JOIN t2` y `t2 ANY RIGHT JOIN t1` pueden devolver resultados distintos. |
| [`join_any_take_last_row`](/es/reference/settings/session-settings/join#join_any_take_last_row)                                                                                           | Determina si un JOIN con estrictez `ANY` toma la primera o la última fila coincidente cuando la tabla derecha tiene varias filas coincidentes para una misma clave.       |

| [`semi_join_include_columns_from_both_sides`](/es/reference/settings/session-settings/other#semi_join_include_columns_from_both_sides)                                                    | Controla si el resultado de un `SEMI JOIN` expone las columnas de ambas tablas o solo las de la tabla preservada.                                                         |
| [`anti_join_include_columns_from_both_sides`](/es/reference/settings/session-settings/other#anti_join_include_columns_from_both_sides)                                                    | Controla si el resultado de un `ANTI JOIN` expone las columnas de ambas tablas o solo las de la tabla preservada.                                                         |
| [`cross_to_inner_join_rewrite`](/es/reference/settings/session-settings/other#cross_to_inner_join_rewrite)                                                                                | Controla si una lista de tablas separadas por comas o un `CROSS JOIN` con condiciones de igualdad en `WHERE` se reescribe como un `INNER JOIN`.                           |
| [`allow_block_nested_loop_join`](/es/reference/settings/session-settings/allow#allow_block_nested_loop_join)                                                                              | Permite ejecutar como combinación por bucles anidados por bloques un JOIN cuya sección `ON` no contiene ninguna igualdad entre las tablas.                                |
| [`enable_lateral_join`](/es/reference/settings/session-settings/enable#enable_lateral_join)                                                                                               | Habilita la sintaxis experimental `LATERAL JOIN`, en la que una subconsulta en el lado derecho de un JOIN puede hacer referencia a columnas del lado izquierdo.           |
| [`single_join_prefer_left_table`](/es/reference/settings/session-settings/other#single_join_prefer_left_table)                                                                            | Resuelve a favor de la tabla izquierda un identificador ambiguo entre las dos tablas de un único JOIN.                                                                    |
| [`joined_subquery_requires_alias`](/es/reference/settings/session-settings/joined#joined_subquery_requires_alias)                                                                         | Exige que las subconsultas y las funciones de tabla de un JOIN tengan alias.                                                                                              |
| [`allow_dynamic_type_in_join_keys`](/es/reference/settings/session-settings/allow#allow_dynamic_type_in_join_keys)                                                                        | Permite claves de JOIN de tipo `Dynamic`.                                                                                                                                 |
| [`analyzer_compatibility_join_using_top_level_identifier`](/es/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_join_using_top_level_identifier)         | Resuelve un nombre de columna en `USING` a partir de un alias homónimo de la consulta, como un alias de la lista `SELECT`.                                                |
| [`analyzer_compatibility_multiple_joins_qualify_column_names`](/es/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_multiple_joins_qualify_column_names) | Califica los nombres de las columnas del resultado con nombres o alias de tablas en una consulta con dos o más JOIN, como hacía el analizador antiguo.                    |
| [`analyzer_compatibility_apply_final_to_all_joined_tables`](/es/reference/settings/session-settings/analyzer-compatibility#analyzer_compatibility_apply_final_to_all_joined_tables)       | Aplica a todas las tablas unidas un modificador `FINAL` indicado en la tabla situada más a la izquierda de un JOIN, como en las versiones anteriores a la 26.6.           |

| [`join_runtime_bloom_filter_max_ratio_of_set_bits`](/es/reference/settings/session-settings/join-runtime#join_runtime_bloom_filter_max_ratio_of_set_bits)                          | Establece la proporción de bits establecidos a partir de la cual se desactiva un filtro de Bloom en tiempo de ejecución.                                                            |
| [`join_runtime_filter_from_fixed_hash_table`](/es/reference/settings/session-settings/join-runtime#join_runtime_filter_from_fixed_hash_table)                                      | Utiliza directamente como filtro en tiempo de ejecución de JOIN una tabla hash que se ha convertido en un array plano.                                                              |
| [`join_runtime_filter_size_from_hash_table_stats`](/es/reference/settings/session-settings/join-runtime#join_runtime_filter_size_from_hash_table_stats)                            | Determina el tamaño del filtro en tiempo de ejecución de JOIN a partir de las estadísticas de la tabla hash recopiladas en ejecuciones anteriores.                                  |
| [`join_runtime_filter_min_probe_rows`](/es/reference/settings/session-settings/join-runtime#join_runtime_filter_min_probe_rows)                                                    | Establece el número estimado de filas del lado de sondeo por debajo del cual (incluido) no se crea ningún filtro en tiempo de ejecución de JOIN.                                    |
| [`join_runtime_filter_pass_ratio_threshold_for_disabling`](/es/reference/settings/session-settings/join-runtime#join_runtime_filter_pass_ratio_threshold_for_disabling)            | Establece la proporción entre filas que superan el filtro y filas comprobadas a partir de la cual un filtro en tiempo de ejecución de JOIN se desactiva temporalmente.              |
| [`join_runtime_filter_blocks_to_skip_before_reenabling`](/es/reference/settings/session-settings/join-runtime#join_runtime_filter_blocks_to_skip_before_reenabling)                | Establece el número de bloques tras el cual se vuelve a probar un filtro en tiempo de ejecución de JOIN desactivado temporalmente.                                                  |

| [`correlated_subqueries_substitute_equivalent_expressions`](/es/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_substitute_equivalent_expressions) | Permite sustituir expresiones equivalentes derivadas de filtros en lugar de crear un `CROSS JOIN` al descorrelacionar una subconsulta correlacionada.                               |
| [`correlated_subqueries_use_in_memory_buffer`](/es/reference/settings/session-settings/correlated-subqueries#correlated_subqueries_use_in_memory_buffer)                           | Utiliza un búfer en memoria para la entrada de una subconsulta correlacionada, que incluye un `LATERAL JOIN`, para evitar evaluar la entrada repetidamente.                         |

## Límites de memoria y volcado a disco {#memory-limits-and-spilling}

| Ajuste                                                                                                                            | Descripción                                                                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`max_rows_in_join`](/es/reference/settings/session-settings/max-rows#max_rows_in_join)                                              | Limita el número de filas en la estructura de datos de la tabla derecha de un JOIN.                                                                                           |
| [`max_bytes_in_join`](/es/reference/settings/session-settings/max-bytes#max_bytes_in_join)                                           | Limita el tamaño en bytes de la estructura de datos de la tabla derecha de un JOIN.                                                                                           |
| [`join_overflow_mode`](/es/reference/settings/session-settings/join#join_overflow_mode)                                              | Define la acción que se realiza cuando un JOIN alcanza `max_rows_in_join` o `max_bytes_in_join`.                                                                              |
| [`default_max_bytes_in_join`](/es/reference/settings/session-settings/default#default_max_bytes_in_join)                             | Establece el tamaño máximo de la tabla derecha cuando se requiere un límite y `max_bytes_in_join` no está configurado.                                                        |
| [`max_bytes_before_external_join`](/es/reference/settings/session-settings/max-bytes#max_bytes_before_external_join)                 | Establece el tamaño en bytes de la tabla derecha a partir del cual un JOIN hash-based realiza un volcado a disco.                                                             |
| [`max_bytes_ratio_before_external_join`](/es/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_join)     | Establece el umbral de volcado a disco de un JOIN hash-based como proporción de la memoria disponible.                                                                        |
| [`enable_adaptive_memory_spill_scheduler`](/es/reference/settings/session-settings/enable#enable_adaptive_memory_spill_scheduler)    | Habilita el volcado a disco de los procesadores que lo admiten, incluidos los JOIN, cuando la consulta se encuentra bajo presión de memoria.                                  |
| [`legacy_join_size_limits_trigger_spilling`](/es/reference/settings/session-settings/other#legacy_join_size_limits_trigger_spilling) | Restaura el comportamiento en el que `max_rows_in_join` y `max_bytes_in_join` hacen que la parte en disco de un JOIN siga volcándose a disco en lugar de detener la consulta. |
| [`max_bytes_before_external_sort`](/es/reference/settings/session-settings/max-bytes#max_bytes_before_external_sort)                 | Establece el uso de memoria a partir del cual la ordenación, incluida la de un JOIN `full_sorting_merge`, realiza un volcado a disco.                                         |
| [`max_bytes_ratio_before_external_sort`](/es/reference/settings/session-settings/max-bytes#max_bytes_ratio_before_external_sort)     | Establece la proporción de la memoria disponible a partir de la cual la ordenación, incluida la de un JOIN `full_sorting_merge`, realiza un volcado a disco.                  |
| [`cross_join_min_rows_to_compress`](/es/reference/settings/session-settings/cross-join#cross_join_min_rows_to_compress)              | Establece el número de filas a partir del cual se comprime en memoria un bloque de un `CROSS JOIN` o de una combinación por bucles anidados por bloques.                      |
| [`cross_join_min_bytes_to_compress`](/es/reference/settings/session-settings/cross-join#cross_join_min_bytes_to_compress)            | Establece el tamaño en bytes a partir del cual se comprime en memoria un bloque de un `CROSS JOIN` o de una combinación por bucles anidados por bloques.                      |
| [`temporary_files_codec`](/es/reference/settings/session-settings/temporary-files#temporary_files_codec)                             | Establece el códec de compresión de los archivos temporales que las operaciones de ordenación y JOIN escriben en disco.                                                       |

| Ajuste                                                                                                                                                            | Descripción                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`distributed_product_mode`](/es/reference/settings/session-settings/distributed#distributed_product_mode)                                                           | Controla cómo ejecuta ClickHouse las subconsultas `IN` y JOIN sobre tablas distribuidas dentro de una consulta sobre una tabla distribuida.                    |
| [`prefer_global_in_and_join`](/es/reference/settings/session-settings/prefer#prefer_global_in_and_join)                                                              | Habilita la sustitución de `IN` y JOIN por `GLOBAL IN` y `GLOBAL JOIN`.                                                                                        |
| [`max_rows_to_transfer`](/es/reference/settings/session-settings/max-rows#max_rows_to_transfer)                                                                      | Limita el número de filas que un `GLOBAL IN` o `GLOBAL JOIN` envía a servidores remotos o guarda en una tabla temporal.                                        |
| [`max_bytes_to_transfer`](/es/reference/settings/session-settings/max-bytes#max_bytes_to_transfer)                                                                   | Limita el número de bytes sin comprimir que un `GLOBAL IN` o `GLOBAL JOIN` envía a servidores remotos o guarda en una tabla temporal.                          |
| [`transfer_overflow_mode`](/es/reference/settings/session-settings/other#transfer_overflow_mode)                                                                     | Define la acción que se realiza al alcanzar `max_rows_to_transfer` o `max_bytes_to_transfer`.                                                                  |
| [`parallel_replicas_for_queries_with_multiple_tables`](/es/reference/settings/session-settings/parallel-replicas#parallel_replicas_for_queries_with_multiple_tables) | Permite usar réplicas paralelas en consultas con JOINs.                                                                                                        |
| [`parallel_replicas_prefer_local_join`](/es/reference/settings/session-settings/parallel-replicas#parallel_replicas_prefer_local_join)                               | Usa un JOIN local en lugar de un `GLOBAL JOIN` con réplicas paralelas cuando cada réplica puede leer por sí misma el lado materializado del JOIN.              |
| [`distributed_plan_default_shuffle_join_bucket_count`](/es/reference/settings/session-settings/distributed-plan#distributed_plan_default_shuffle_join_bucket_count)  | Establece el número predeterminado de buckets de un JOIN hash con redistribución en el planificador distribuido basado en reglas.                              |
| [`distributed_plan_join_runtime_filters`](/es/reference/settings/session-settings/distributed-plan#distributed_plan_join_runtime_filters)                            | Envía los filtros de JOIN en tiempo de ejecución a las etapas que leen el lado de sondeo en un plan de consulta distribuida.                                   |
| [`distributed_plan_max_rows_to_broadcast`](/es/reference/settings/session-settings/distributed-plan#distributed_plan_max_rows_to_broadcast)                          | Establece el número máximo de filas hasta el cual el planificador distribuido basado en reglas usa un JOIN de difusión en lugar de un JOIN con redistribución. |
