No todos los usuarios interactúan con ClickHouse a través de la consola de ClickHouse Cloud.
Por ejemplo, muchos desarrolladores trabajan directamente desde sus editores de código preferidos, agentes de CLI o se conectan a la base de datos mediante configuraciones personalizadas, mientras que otros dependen de asistentes de IA de propósito general como Anthropic Claude para gran parte de su exploración.
Estos usuarios y las cargas de trabajo basadas en agentes que actúan en su nombre necesitan una forma de acceder a ClickHouse Cloud y realizar consultas de forma segura sin configuraciones complejas ni infraestructura personalizada.

La capacidad de servidor MCP remoto de ClickHouse Cloud resuelve esto al exponer una interfaz estándar que los agentes externos pueden usar para obtener contexto analítico.
MCP, o Model Context Protocol, es un estándar de acceso a datos estructurados para aplicaciones de IA basadas en LLM.
Con esta integración, los agentes externos pueden listar bases de datos y tablas, inspeccionar esquemas y ejecutar consultas SELECT limitadas y de solo lectura.
La autenticación se gestiona mediante OAuth 2.0 o una [clave de API de ClickHouse Cloud](/es/cloud/manage/openapi). El servidor está totalmente gestionado en ClickHouse Cloud, por lo que no requiere configuración ni mantenimiento.

Esto facilita que las herramientas basadas en agentes se conecten a ClickHouse y obtengan los datos que necesitan, ya sea para análisis, resúmenes, generación de código o exploración.

## Servidor MCP remoto vs. servidor MCP de código abierto {#remote-vs-oss}

ClickHouse ofrece dos servidores MCP.

|                    | Servidor MCP remoto (Cloud)                                                                                                                           | Servidor MCP de código abierto                                           |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Source**         | Totalmente gestionado por ClickHouse Cloud                                                                                                            | [mcp-clickhouse](https://github.com/ClickHouse/mcp-clickhouse) en GitHub |
| **Transport**      | HTTP con streaming (`https://mcp.clickhouse.cloud/mcp`)                                                                                               | `stdio` local                                                            |
| **Works with**     | Servicios de ClickHouse Cloud y Managed Postgres                                                                                                      | Cualquier instancia de ClickHouse (autogestionada o Cloud)               |
| **Authentication** | OAuth 2.0 con tus credenciales de Cloud o una clave de API de ClickHouse Cloud                                                                        | Variables de entorno                                                     |
| **Herramientas**          | Herramientas para consultas, exploración del esquema, gestión de servicios, copias de seguridad, ClickPipes, facturación y monitorización de Postgres | 3 herramientas: `run_select_query`, `list_databases`, `list_tables`      |
| **Setup**          | Sin instalación. Apunta tu Cliente MCP al endpoint y autentícate.                                                                                      | Instala y ejecuta el servidor localmente                                 |

El servidor MCP remoto ofrece la integración más completa con ClickHouse Cloud, incluida la gestión de servicios, la monitorización de copias de seguridad, la visibilidad de ClickPipe y los datos de facturación, sin necesidad de gestionar infraestructura.
Para instancias autogestionadas de ClickHouse, consulta las [guías del servidor MCP de código abierto](/es/guides/use-cases/ai-ml/MCP/index).

## Habilitar el servidor MCP remoto {#enabling}

El servidor MCP remoto debe habilitarse en cada servicio antes de poder aceptar conexiones.
En la consola de ClickHouse Cloud, abra el servicio, haga clic en el botón **Connect**, seleccione **MCP** y habilítelo.
En los servicios de ClickHouse, para habilitar o deshabilitar el servidor MCP remoto se requiere el permiso `control-plane:service:manage-mcp` (consulte [Roles y permisos de la consola](/es/products/cloud/reference/security/console-roles#console-permissions)).
En los servicios de Managed Postgres, abra el panel **Connect** del servicio y active **Enable Model Context Protocol**. Las réplicas de lectura heredan la configuración de MCP de la base de datos principal.
Para ver los pasos detallados con capturas de pantalla, consulte la [guía de configuración](/es/products/cloud/features/ai-ml/mcp/remote-mcp#enable-remote-mcp-server).

## Endpoint {#endpoint}

Una vez habilitado, el servidor MCP remoto estará disponible en:

```text
https://mcp.clickhouse.cloud/mcp
```

## Autenticación {#authentication}

El servidor MCP remoto admite dos métodos de autenticación:

* **OAuth 2.0**: recomendado para Clients interactivos. Cuando un Client MCP se conecta por primera vez, abre una ventana del navegador para que el usuario inicie sesión con sus credenciales de ClickHouse Cloud. El acceso se limita a las organizaciones y los servicios para los que el usuario autenticado tiene permisos.
* **Clave de API de ClickHouse Cloud**: pensada para entornos remotos, sin interfaz gráfica (headless) y automatizados en los que no resulta práctico un flujo OAuth basado en navegador. Envíe el ID y el secreto de la clave de API mediante autenticación HTTP Basic:

  ```text
  Authorization: Basic base64(<key_id>:<key_secret>)
  ```

El acceso mediante clave de API queda limitado por los roles, los permisos y la fecha de expiración configurados para la clave. Utilice una clave dedicada con privilegios mínimos e inyéctela a través de un sistema de gestión de secretos. La codificación Base64 no cifra las credenciales, así que no haga commit del valor codificado en el control de versiones ni lo exponga en los logs.

Para ver un ejemplo de cómo configurar un Client MCP en un entorno sin interfaz gráfica, consulte [Autenticarse desde un entorno sin interfaz gráfica](/es/products/cloud/features/ai-ml/mcp/remote-mcp#headless-mcp-client-authentication).

## Seguridad {#safety}

Todas las herramientas expuestas por el servidor MCP remoto son de **solo lectura**. Cada herramienta está marcada con `readOnlyHint: true` en sus metadatos de MCP. Ninguna herramienta puede modificar datos, alterar la configuración del servicio ni realizar operaciones destructivas.

## Herramientas disponibles {#available-tools}

El servidor MCP remoto ofrece herramientas en las siguientes categorías. La disponibilidad de las herramientas depende del método de autenticación y de las funcionalidades habilitadas.

### Exploración de consultas y del esquema {#query-and-schema}

Estas herramientas permiten a los agentes descubrir qué datos hay disponibles y ejecutar consultas analíticas.

| Herramienta        | Descripción                                                                            | Parámetros                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `run_select_query` | Ejecuta una consulta SELECT de solo lectura en un servicio de ClickHouse.              | `query`, una consulta SELECT válida de ClickHouse SQL; `serviceId`                                           |
| `list_databases`   | Enumera todas las bases de datos disponibles en un servicio de ClickHouse.             | `serviceId`                                                                                                  |
| `list_tables`      | Enumera todas las tablas de una base de datos, incluidas las definiciones de columnas. | `serviceId`; `database`; opcionalmente `like` o `notLike` (patrones SQL LIKE para filtrar nombres de tablas) |

### Managed Postgres {#managed-postgres}

Estas herramientas consultan y supervisan servicios de Managed Postgres. Use `get_organizations` para obtener el `organizationId` y, a continuación, `get_services_list` para encontrar un servicio cuyo `serviceType` sea `postgres`; use su `id` como `serviceId`.

| Herramienta                               | Descripción                                                                                                                                                                               | Parámetros                                                                                                                                                                          |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run_postgres_select_query`               | Ejecuta una consulta SQL de solo lectura en un servicio de Postgres. Requiere autenticación OAuth; no está disponible con claves de API de ClickHouse Cloud.                              | `organizationId`; `serviceId`; `query`; opcionalmente, `database` (predeterminado: `postgres`) y `timeoutSeconds` (1–3600, predeterminado: 300)                                     |
| `list_postgres_slow_query_patterns`       | Enumera los patrones de consultas lentas con métricas agregadas de latencia, número de llamadas, filas, CPU, E/S, WAL y errores. Las duraciones se expresan en microsegundos.             | `organizationId`; `serviceId`; `fromDate`; `toDate`; opcionalmente, `limit` (1–500, predeterminado: 20), `offset`, `sortBy`, `sortOrder`, `dbName`, `dbUser`, `dbOperation` y `app` |
| `get_postgres_slow_query_pattern_details` | Devuelve hasta 10 ejecuciones recientes de un patrón de consulta de las últimas 24 horas, junto con métricas agregadas cuando están disponibles.                                          | `organizationId`; `serviceId`; `queryId`; `dbName`; `dbUser`; `dbOperation`; opcionalmente, `app`                                                                                   |
| `get_postgres_metrics`                    | Devuelve métricas time-series de CPU, memoria, disco, red, conexiones, porcentaje de aciertos de caché, transacciones y esperas. Cada métrica incluye su unidad y sus series etiquetadas. | `organizationId`; `serviceId`; `fromDate`; `toDate`; opcionalmente, `bucketSizeSeconds` (entero positivo; se selecciona automáticamente si se omite)                                |

Para `fromDate` y `toDate`, use marcas de tiempo UTC con precisión de milisegundos, como `2026-11-03T00:00:00.000Z`. El inicio es inclusivo. El final es inclusivo con granularidad de minutos para los patrones de consultas lentas y exclusivo para las métricas.

Para inspeccionar un patrón de consulta lenta, pase a `get_postgres_slow_query_pattern_details` los valores `queryId`, `dbName`, `dbUser`, `dbOperation` y `app` obtenidos de `list_postgres_slow_query_patterns`. Conserve la cadena `app` vacía en las consultas sin `application_name`; si omite `app`, se incluyen todas las aplicaciones.

### Organizaciones {#organizations}

| Tool                       | Descripción                                                                                           | Parámetros       |
| -------------------------- | ----------------------------------------------------------------------------------------------------- | ---------------- |
| `get_organizations`        | Recupera todas las organizaciones de ClickHouse Cloud a las que puede acceder el usuario autenticado. | Ninguno          |
| `get_organization_details` | Devuelve los detalles de una única organización.                                                      | `organizationId` |

### Servicios {#services}

| Herramienta                  | Descripción                                                                                                                                | Parámetros                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------- |
| `get_services_list`   | Enumera los servicios de ClickHouse y Managed Postgres de una organización, con un campo `serviceType` que identifica el tipo de cada uno. | `organizationId`              |
| `get_service_details` | Devuelve los detalles de un servicio de ClickHouse o Managed Postgres y detecta automáticamente su tipo.                                   | `organizationId`; `serviceId` |

### Copias de seguridad {#backups}

| Herramienta                        | Descripción                                                                                            | Parámetros                                |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| `list_service_backups`             | Enumera todas las copias de seguridad de un servicio, empezando por las más recientes.                 | `organizationId`; `serviceId`             |
| `get_service_backup_details`       | Devuelve los detalles de una copia de seguridad concreta.                                              | `organizationId`; `serviceId`; `backupId` |
| `get_service_backup_configuration` | Devuelve la configuración de copias de seguridad de un servicio (programación y ajustes de retención). | `organizationId`; `serviceId`             |

### ClickPipes {#clickpipes}

| Tool              | Descripción                                                 | Parámetros                                   |
| ----------------- | ----------------------------------------------------------- | -------------------------------------------- |
| `list_clickpipes` | Enumera todos los ClickPipes configurados para un servicio. | `organizationId`; `serviceId`                |
| `get_clickpipe`   | Devuelve los detalles de un ClickPipe específico.           | `organizationId`; `serviceId`; `clickPipeId` |

### Facturación {#billing}

| Tool                    | Descripción                                                                                                                               | Parámetros                                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `get_organization_cost` | Obtiene los datos de facturación y costos de uso de una organización. Devuelve un total global y registros diarios de costos por entidad. | `organizationId`; opcionalmente `from_date` y `to_date` (YYYY-MM-DD, rango máximo de 31 días) |
