Use la página **Preview features** de ClickHouse Cloud para activar las funcionalidades disponibles en versión preliminar pública y solicitar acceso a las funcionalidades disponibles en vista previa privada.

<Warning>
  Las funcionalidades en versión preliminar siguen en desarrollo. Pueden sufrir cambios y no están cubiertas por el SLA estándar de ClickHouse Cloud.
</Warning>

Esta lista procede de ClickHouse Cloud y se mantiene actualizada a medida que se añaden, modifican o eliminan funcionalidades en versión preliminar.

</Note>

## Activar la versión preliminar pública {#enable-public-preview}

1. Inicie sesión en la consola de ClickHouse Cloud y seleccione la organización correspondiente.
2. Abra el menú de la organización y seleccione **Preview features**. También puede acceder a esta opción desde la barra lateral de la organización.
3. Busque la funcionalidad, seleccione **Learn more** para consultar sus requisitos y limitaciones y, a continuación, active su interruptor. Si el interruptor está deshabilitado, pida a un administrador de la organización que active la funcionalidad.
4. Si está disponible, utilice el enlace al servicio **Go to...** o **View in...** para empezar a usar la funcionalidad.
5. Para enviar sus comentarios, seleccione **Give feedback** junto a la funcionalidad y elija **Thumbs up** si usaría la funcionalidad o **Thumbs down** si no la usaría. Si lo desea, añada más detalles en el campo de texto y acepte que se le contacte acerca de sus comentarios. Por último, seleccione **Send feedback**.

## Activar la vista previa privada {#enable-private-preview}

1. Busque la funcionalidad en vista previa privada y seleccione **Learn more** para consultar sus requisitos y limitaciones.
2. Seleccione **Request access**. Con esto se envía una solicitud de acceso, pero la funcionalidad no se habilita de inmediato. ClickHouse Cloud le confirmará la recepción de la solicitud.
3. Una vez aprobada la solicitud y habilitado el acceso, use el enlace de servicio **Go to...** o **View in...**, si está disponible, para empezar a usar la funcionalidad.
4. Para enviar comentarios, seleccione **Give feedback** junto a la funcionalidad y elija **Thumbs up** si usaría la funcionalidad o **Thumbs down** si no la usaría. Si lo desea, añada detalles en el campo de texto y acepte que se le contacte en relación con sus comentarios. Por último, seleccione **Send feedback**.
