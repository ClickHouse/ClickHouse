<Visibility for="humans">
  <View title="Interfaz de usuario de Cloud">
    ClickHouse Cloud ofrece una forma sencilla de importar sus archivos y admite los
    siguientes formatos:

    | Formato                         |
    | ------------------------------- |
    | `CSV`                           |
    | `CSVWithNamesAndTypes`          |
    | `CSVWithNames`                  |
    | `JSONEachRow`                   |
    | `TabSeparated`                  |
    | `TabSeparatedWithNames`         |
    | `TabSeparatedWithNamesAndTypes` |

    <Steps>
      <Step title="Cargar un archivo" id="upload-file">
        En la página de inicio de Cloud, seleccione su servicio como se muestra a continuación:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_02](/images/cloud/migrate/csv_01.webp)
          </Frame>
        </div>

        Si su servicio está inactivo, deberá reactivarlo.

        Seleccione `Data sources` en la pestaña de la izquierda, como se muestra a continuación:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_03](/images/cloud/migrate/csv_02.webp)
          </Frame>
        </div>

        A continuación, seleccione `Upload a file` en el lado derecho de la página de orígenes de datos:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_04](/images/cloud/migrate/csv_03.webp)
          </Frame>
        </div>

        Se abrirá un cuadro de diálogo en el que podrá seleccionar el archivo que desea
        usar para insertar datos en una tabla de su servicio de Cloud.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_04.webp)
          </Frame>
        </div>
      </Step>

      <Step title="Configurar la tabla" id="configure-table">
        Una vez cargado el archivo, podrá configurar la tabla en la que desea
        insertar los datos. Se muestra una vista previa de la tabla con las tres primeras filas.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_08](/images/cloud/migrate/csv_08.webp)
          </Frame>
        </div>

        Ahora puede seleccionar una tabla de destino. Las opciones son:

        * una tabla nueva
        * una tabla existente

        <br />

        Puede especificar la base de datos en la que desea cargar los datos y, si se trata de
        una tabla nueva, el nombre de la tabla que se creará. También podrá seleccionar la clave de ordenación:

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_05](/images/cloud/migrate/csv_05.webp)
          </Frame>
        </div>

        Las columnas leídas del archivo se muestran como `Source field` y, para cada campo,
        puede cambiar:

        * el tipo inferido
        * el valor predeterminado
        * si la columna será [Nullable](/es/reference/data-types/nullable) o no

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_06](/images/cloud/migrate/csv_06.webp)
          </Frame>
        </div>

        <Info>
          **Exclusión de campos**

          También puede eliminar un campo si no desea incluirlo en la importación.
        </Info>

        Puede especificar el tipo de motor de tabla que desea utilizar:

        * `MergeTree`
        * `ReplacingMergeTree`
        * `SummingMergeTree`
        * `Null`

        <br />

        Puede especificar una expresión de clave de particionamiento y una expresión de clave
        primaria.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_07](/images/cloud/migrate/csv_07.webp)
          </Frame>
        </div>

        Haga clic en `Import to ClickHouse` (como se muestra arriba) para importar los datos. La importación se pondrá en cola, tal como
        indica la insignia de estado `queued` en la columna `Status` (véase la imagen siguiente). También puede hacer clic en
        `Open as query` (como se muestra arriba) para abrir la consulta de inserción en la consola SQL. La consulta insertará,
        mediante la función de tabla `URL`, el archivo que se cargó en un bucket de S3.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_09](/images/cloud/migrate/csv_09.webp)
          </Frame>
        </div>

        Si el trabajo falla, verá una insignia de estado `failed` en la columna `Status` de
        la pestaña `Data upload history`. Puede hacer clic en `View Details` para obtener más información
        sobre el motivo del error en la carga. Según el mensaje de error de la inserción fallida, es posible que deba modificar la configuración de la tabla o limpiar
        los datos.

        <div className="ch-image-lg">
          <Frame>
            ![upload_file_11](/images/cloud/migrate/csv_10.webp)
          </Frame>
        </div>
      </Step>
    </Steps>
  </View>
