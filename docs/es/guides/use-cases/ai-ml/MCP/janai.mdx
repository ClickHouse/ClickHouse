> Esta guía explica cómo usar el servidor MCP de ClickHouse con [Jan.ai](https://jan.ai/docs).

<Steps>
  <Step title="Instalar Jan.ai" id="install-janai">
    Jan.ai es una alternativa open source a ChatGPT que funciona 100% sin conexión.
    Puede descargar Jan.ai para [Mac](https://jan.ai/docs/desktop/install/mac), [Windows](https://jan.ai/docs/desktop/windows) o [Linux](https://jan.ai/docs/desktop/linux).

    Es una aplicación nativa, así que, una vez descargada, puede iniciarla directamente.
  </Step>

  <Step title="Agregar un LLM a Jan.ai" id="add-llm-to-janai">
    Podemos habilitar modelos desde el menú de ajustes.

    Para habilitar OpenAI, debemos proporcionar una clave de API, como se muestra a continuación:

    <div className="ch-image-md">
      <Frame>
        ![Habilitar modelos de OpenAI](/images/use-cases/AI_ML/MCP/0_janai_openai.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Habilitar los servidores MCP" id="enable-mcp-servers">
    En el momento de redactar esta guía, los servidores MCP son una funcionalidad experimental en Jan.ai.
    Podemos habilitarlos activando el toggle de funcionalidades experimentales:

    <div className="ch-image-md">
      <Frame>
        ![Habilitar servidores MCP](/images/use-cases/AI_ML/MCP/1_janai_mcp_servers.webp)
      </Frame>
    </div>

    Una vez activado ese toggle, aparecerá `MCP servers` en el menú izquierdo.
  </Step>

  <Step title="Configurar el servidor MCP de ClickHouse" id="configure-clickhouse-mcp-server">
    Si hacemos clic en el menú `MCP servers`, veremos una lista de servidores MCP a los que podemos conectarnos:

    <div className="ch-image-md">
      <Frame>
        ![Lista de servidores MCP](/images/use-cases/AI_ML/MCP/2_janai_mcp_servers_list.webp)
      </Frame>
    </div>

    Todos estos servidores están deshabilitados de forma predeterminada, pero podemos habilitarlos haciendo clic en el toggle.

    Para instalar el servidor MCP de ClickHouse, debemos hacer clic en el icono `+` y completar el formulario con lo siguiente:

    <div className="ch-image-md">
      <Frame>
        ![Agregar servidor MCP](/images/use-cases/AI_ML/MCP/3_janai_add_mcp_server.webp)
      </Frame>
    </div>

    Una vez hecho esto, debemos activar el toggle del servidor de ClickHouse si aún no está activado:

    <div className="ch-image-md">
      <Frame>
        ![Habilitar servidor MCP](/images/use-cases/AI_ML/MCP/4_janai_toggle.webp)
      </Frame>
    </div>

    Las herramientas del servidor MCP de ClickHouse aparecerán ahora en el cuadro de diálogo del chat:

    <div className="ch-image-md">
      <Frame>
        ![Herramientas del servidor MCP de ClickHouse](/images/use-cases/AI_ML/MCP/5_jani_tools.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Chatear con el servidor MCP de ClickHouse mediante Jan.ai" id="chat-to-clickhouse-mcp-server">
    ¡Es hora de conversar sobre algunos datos almacenados en ClickHouse!
    Hagamos una pregunta:

    <div className="ch-image-md">
      <Frame>
        ![Pregunta](/images/use-cases/AI_ML/MCP/6_janai_question.webp)
      </Frame>
    </div>

    Jan.ai pedirá confirmación antes de llamar a una herramienta:

    <div className="ch-image-md">
      <Frame>
        ![Confirmación de herramienta](/images/use-cases/AI_ML/MCP/7_janai_tool_confirmation.webp)
      </Frame>
    </div>

    A continuación, nos mostrará la lista de llamadas a herramientas realizadas:

    <div className="ch-image-md">
      <Frame>
        ![Herramientas llamadas](/images/use-cases/AI_ML/MCP/8_janai_tools_called.webp)
      </Frame>
    </div>

    Si hacemos clic en la llamada a la herramienta, podemos ver sus detalles:

    <div className="ch-image-md">
      <Frame>
        ![Herramientas llamadas expandidas](/images/use-cases/AI_ML/MCP/9_janai_tools_called_expanded.webp)
      </Frame>
    </div>

    Y justo debajo, tenemos el resultado:

    <div className="ch-image-md">
      <Frame>
        ![Resultado](/images/use-cases/AI_ML/MCP/10_janai_result.webp)
      </Frame>
    </div>
  </Step>
</Steps>
