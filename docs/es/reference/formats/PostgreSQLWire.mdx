<div id="description">
  ## Descripción
</div>

El formato `PostgreSQLWire` serializa la parte del conjunto de resultados del protocolo de red de PostgreSQL. Escribe un
mensaje `RowDescription` que contiene los nombres y tipos de las columnas, seguido de un mensaje `DataRow` por cada fila de resultados.
Los valores utilizan su representación textual, los valores `NULL` utilizan la codificación de campo nulo del protocolo y los valores booleanos se escriben como
`t` o `f`.

Se trata de un formato binario exclusivamente de salida destinado a clientes conectados a través de la
[Interfaz de PostgreSQL](/es/concepts/features/interfaces/postgresql) de ClickHouse. La interfaz establece `PostgreSQLWire` como formato predeterminado de la sesión
y lo utiliza cuando la consulta no incluye una cláusula `FORMAT` explícita. Una cláusula explícita sustituye el valor predeterminado;
otros formatos de salida no generan un conjunto de resultados de PostgreSQL válido. La interfaz escribe los mensajes del protocolo que lo rodean,
como los mensajes de autenticación, finalización de comandos y listo para consultas. `PostgreSQLWire` no está pensado para mostrar
ni almacenar resultados de consultas como un archivo independiente.

<div id="example-usage">
  ## Ejemplo de uso
</div>

Después de habilitar la interfaz de PostgreSQL, use un cliente compatible para ejecutar una consulta:

```shell
psql -p 9005 -h 127.0.0.1 -U default -d default \
    -c "SELECT number, number % 2 = 0 AS even FROM numbers(3)"
```

Como la consulta no especifica una cláusula `FORMAT`, la interfaz envía el resultado a través de `PostgreSQLWire`.

<div id="format-settings">
  ## Configuración del formato
</div>

`PostgreSQLWire` usa la configuración estándar de serialización de texto para valores individuales. No tiene ninguna configuración específica del
formato en sí; los valores booleanos siempre se serializan con las representaciones `t` y `f` de PostgreSQL.
