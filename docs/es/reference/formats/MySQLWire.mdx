<div id="description">
  ## Descripción
</div>

El formato `MySQLWire` serializa los resultados de las consultas como un conjunto de resultados del protocolo de comunicación de MySQL. Escribe el número de columnas y
las definiciones de las columnas, seguidos de un paquete de fila del protocolo por cada fila de resultados y de un paquete `EOF` u `OK` final. Los paquetes de fila
usan el protocolo de texto para las consultas normales y el protocolo binario para las sentencias preparadas.

Este formato binario es exclusivamente de salida y está destinado a Client conectados a través de la
[interfaz MySQL](/es/concepts/features/interfaces/mysql) de ClickHouse. La interfaz selecciona `MySQLWire` automáticamente y proporciona
el estado del protocolo, como las capacidades del Client y el número de secuencia de los paquetes. No está diseñado para mostrar ni
almacenar resultados de consultas como archivo independiente.

<div id="example-usage">
  ## Ejemplo de uso
</div>

Después de habilitar la interfaz MySQL, use un Client compatible para ejecutar una consulta:

```shell
mysql --protocol tcp -h 127.0.0.1 -u default -P 9004 default \
    -e "SELECT number, number * 2 AS doubled FROM numbers(3)"
```

La interfaz envía el resultado mediante `MySQLWire`; la cláusula explícita `FORMAT MySQLWire` es opcional. La interfaz MySQL no admite otros
formatos de salida explícitos.

<div id="format-settings">
  ## Configuración de formato
</div>

No hay opciones de formato configurables por el usuario. La interfaz MySQL obtiene la configuración necesaria a partir del
handshake del Client y del comando que se está ejecutando.
