## Descripción {#description}

El formato `ProtobufList` agrupa las filas en un único mensaje de [Protocol Buffers](/es/reference/formats/Protobuf/Protobuf), delimitado por longitud, llamado `Envelope`. Cada fila se codifica como un submensaje con el número de campo 1.

## Ejemplo de uso {#example-usage}

Guarde el siguiente esquema como `schemafile.proto`. Declare el campo `row` como `repeated` para que un decodificador Protobuf que utilice este esquema pueda leer todas las filas del envoltorio.

```capnp title="schemafile.proto"
syntax = "proto3";
message Envelope {
  message MessageType {
    string name = 1;
  }
  repeated MessageType row = 1;
}
```

Desde el mismo directorio, ejecuta estos comandos para escribir dos filas en un archivo y luego leerlas.

```bash
clickhouse local --query "SELECT name FROM values('name String', 'Ada', 'Grace') ORDER BY name
    SETTINGS format_schema = 'schemafile:MessageType' FORMAT ProtobufList" > people.bin

clickhouse local --structure 'name String' --input-format ProtobufList \
    --format_schema 'schemafile:MessageType' --query 'SELECT name FROM table' < people.bin
```

```text
Ada
Grace
```

El tipo de mensaje especificado en `format_schema` se determina buscando primero si existe como un tipo anidado dentro de un mensaje `Envelope` de nivel superior. Si no se encuentra ninguna coincidencia allí —ya sea porque el esquema no tiene un mensaje `Envelope` o porque `Envelope` no contiene un mensaje con el nombre solicitado—, se usa directamente el mensaje de nivel superior con ese nombre.
