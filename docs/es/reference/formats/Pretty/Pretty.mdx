## Descripción {#description}

El formato `Pretty` muestra los datos como tablas con caracteres Unicode,
utilizando secuencias de escape ANSI para mostrar colores en la terminal.
Se dibuja una cuadrícula completa de la tabla, y cada fila ocupa dos líneas en la terminal.
Cada bloque de resultados se muestra como una tabla independiente.
Esto es necesario para que los bloques puedan mostrarse sin almacenar en búfer los resultados (sería necesario almacenarlos en búfer para calcular de antemano el ancho visible de todos los valores).

[NULL](/es/reference/syntax) se muestra como `ᴺᵁᴸᴸ`.

## Ejemplo de uso {#example-usage}

Ejemplo (mostrado con el formato [`PrettyCompact`](/es/reference/formats/Pretty/PrettyCompact)):

```sql title="Query"
SELECT * FROM t_null
```

```response title="Response"
┌─x─┬────y─┐
│ 1 │ ᴺᵁᴸᴸ │
└───┴──────┘
```

Las filas no usan secuencias de escape en ninguno de los formatos `Pretty`. En su lugar, los caracteres de control no imprimibles (controles C0 `0x00`-`0x1F` y `DEL` `0x7F`) que aparecen en los valores y en los nombres de las columnas se muestran de forma predeterminada como los &quot;Control Pictures&quot; de Unicode correspondientes (`U+2400`-`U+2421`), de modo que sigan siendo visibles y no deformen la tabla. Por ejemplo, un NUL se muestra como `␀`:

```sql title="Query"
SELECT 'String with a NUL \0 character' AS Escaping_test FORMAT PrettyCompact
```

```response title="Response"
┌─Escaping_test─────────────────┐
│ String with a NUL ␀ character │
└───────────────────────────────┘
```

`TAB`, el salto de línea y `ESC` son excepciones: siempre se imprimen tal cual, porque el terminal los interpreta en lugar de descartarlos (una tabulación avanza hasta la siguiente posición de tabulación, y una secuencia de escape ANSI es lo que permite que los datos incluyan una visualización). Un salto de línea también sigue partiendo la línea: dentro de una celda de la tabla cuando [`output_format_pretty_multiline_fields`](/es/reference/settings/formats#output_format_pretty_multiline_fields) está habilitado, y tal cual en caso contrario. El nombre de una columna es la excepción a esa excepción: el encabezado y el pie ocupan una sola línea, por lo que un salto de línea en un nombre se reemplaza como cualquier otro carácter de control.

Para imprimir, en cambio, los caracteres de control literalmente, deshabilite [`output_format_pretty_display_control_characters`](/es/reference/settings/formats#output_format_pretty_display_control_characters):

```sql title="Query"
SELECT 'String with a NUL \0 character' AS Escaping_test FORMAT PrettyCompact
SETTINGS output_format_pretty_display_control_characters = 0
```

En ese caso, la respuesta contiene el byte `NUL` sin procesar. Un terminal lo omite, por lo que el carácter
resulta invisible y la fila queda una posición más ancha que el borde calculado para ella: precisamente la
tabla deformada que se evita al mostrar el Control Picture.

Para evitar mostrar demasiados datos en el terminal, solo se imprimen las primeras `10,000` filas.
Si el número de filas es mayor o igual que `10,000`, se imprime el mensaje &quot;Showed first 10 000&quot;.

<Note>
  Este formato solo es apropiado para mostrar el resultado de una consulta, pero no para parsear datos.
</Note>

El formato Pretty permite mostrar valores totales (al usar `WITH TOTALS`) y valores extremos (cuando &#39;extremes&#39; está establecido en 1).
En estos casos, los valores totales y los valores extremos se muestran después de los datos principales, en tablas separadas.
Esto se ilustra en el siguiente ejemplo, que utiliza el formato [`PrettyCompact`](/es/reference/formats/Pretty/PrettyCompact):

```sql title="Query"
SELECT EventDate, count() AS c 
FROM test.hits 
GROUP BY EventDate 
WITH TOTALS 
ORDER BY EventDate 
FORMAT PrettyCompact
```

```response title="Response"
┌──EventDate─┬───────c─┐
│ 2014-03-17 │ 1406958 │
│ 2014-03-18 │ 1383658 │
│ 2014-03-19 │ 1405797 │
│ 2014-03-20 │ 1353623 │
│ 2014-03-21 │ 1245779 │
│ 2014-03-22 │ 1031592 │
│ 2014-03-23 │ 1046491 │
└────────────┴─────────┘

Totals:
┌──EventDate─┬───────c─┐
│ 1970-01-01 │ 8873898 │
└────────────┴─────────┘

Extremes:
┌──EventDate─┬───────c─┐
│ 2014-03-17 │ 1031592 │
│ 2014-03-23 │ 1406958 │
└────────────┴─────────┘
```
