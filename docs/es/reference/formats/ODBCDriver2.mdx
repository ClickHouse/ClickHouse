<div id="description">
  ## Descripción
</div>

El formato `ODBCDriver2` es un formato binario de solo salida que se utiliza para transferir resultados de consultas a través de HTTP al
[controlador ODBC de ClickHouse](/es/concepts/features/interfaces/odbc). El controlador lo solicita estableciendo `default_format` en
`ODBCDriver2`; los usuarios normalmente no lo seleccionan directamente.

Todos los enteros del flujo son valores con signo de 32 bits codificados en orden de bytes little-endian. Una cadena se codifica como su
longitud en bytes, seguida de sus bytes. La salida tiene la siguiente estructura:

1. El valor `2`, que indica que le siguen dos filas de encabezado.
2. Un encabezado de nombres que contiene el valor `number_of_columns + 1`, la cadena `name` y el nombre de cada columna.
3. Un encabezado de tipos que contiene el valor `number_of_columns + 1`, la cadena `type` y el nombre de cada tipo de datos de ClickHouse.
   Los envoltorios `LowCardinality` se eliminan de estos nombres de tipo.
4. Las filas de datos. Cada fila contiene un valor serializado como texto, con prefijo de longitud, para cada columna del resultado. Las filas de datos no
   incluyen su propio recuento de filas ni de columnas, y el flujo termina en `EOF`.

Un valor `NULL` se codifica con la longitud `-1`; una cadena vacía no nula tiene una longitud de `0`. Los totales, cuando están presentes, usan la
misma codificación de filas y siguen a las filas ordinarias.

<div id="example-usage">
  ## Ejemplo de uso
</div>

La siguiente consulta representa los valores que abarcan las pruebas del formato:

```sql
SELECT
    1 AS x,
    [2, 3] AS y,
    'Hello' AS z,
    NULL AS a
FORMAT ODBCDriver2
```

Como el resultado es binario, redirígelo a un archivo en lugar de mostrarlo en la terminal:

```shell
clickhouse-client --query \
    "SELECT 1 AS x, [2, 3] AS y, 'Hello' AS z, NULL AS a FORMAT ODBCDriver2" \
    > result.bin
```

En condiciones normales, el controlador añade `default_format=ODBCDriver2` a sus solicitudes HTTP y decodifica la respuesta.

<div id="format-settings">
  ## Configuración de formato
</div>

`ODBCDriver2` utiliza la configuración estándar de serialización de texto para valores individuales. No tiene ninguna configuración específica del formato en sí.
