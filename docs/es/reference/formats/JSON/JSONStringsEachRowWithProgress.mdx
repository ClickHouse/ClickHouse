## Descripción {#description}

Se diferencia de `JSONEachRow`/`JSONStringsEachRow` en que ClickHouse transmite cada evento como un objeto JSON independiente y, además, proporciona información de progreso.

Todos los valores de los campos se serializan como cadenas (incluidos los tipos complejos): por ejemplo, `arr` se emite como `"arr":"[0,1]"`, no como un array JSON anidado. Los valores escalares también se convierten en cadenas (`"num":"42"`).

Los tipos de objeto de nivel superior coinciden con los de [`JSONEachRowWithProgress`](/es/reference/formats/JSON/JSONEachRowWithProgress) (`meta`, `row`, `progress`, `totals`/`min`/`max`, `rows_before_limit_at_least`, `rows_before_aggregation` y `exception` de nivel superior). Consulte esa página para conocer el contrato completo del flujo: un objeto `progress` puede llegar antes que `meta`; `rows_before_limit_at_least` es una estimación de cota inferior cuando la consulta contiene `LIMIT` (no demuestra que se hayan descartado filas); `exception` solo se escribe en la ruta HTTP si se establece `http_write_exception_in_output_format=1`.

## Ejemplo de uso {#example-usage}

```json
{"meta":[{"name":"num","type":"UInt8"},{"name":"str","type":"String"},{"name":"arr","type":"Array(UInt8)"}]}
{"row":{"num":"42","str":"hello","arr":"[0,1]"}}
{"row":{"num":"43","str":"hello","arr":"[0,1,2]"}}
{"row":{"num":"44","str":"hello","arr":"[0,1,2,3]"}}
{"progress":{"read_rows":"3","read_bytes":"24","written_rows":"0","written_bytes":"0","total_rows_to_read":"3"}}
```
