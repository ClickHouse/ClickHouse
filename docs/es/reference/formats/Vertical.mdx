## Descripción {#description}

Imprime cada valor en una línea independiente con el nombre de la columna indicado. Este formato resulta práctico para imprimir solo una o unas pocas filas si cada fila consta de un gran número de columnas.

Tenga en cuenta que [`NULL`](/es/reference/syntax) se muestra como `ᴺᵁᴸᴸ` para que sea más fácil distinguir entre el valor de cadena `NULL` y la ausencia de valor. Las columnas JSON se mostrarán con un formato legible, y `NULL` se muestra como `null`, ya que es un valor JSON válido y se distingue fácilmente de `"null"`.

## Ejemplo de uso {#example-usage}

Ejemplo:

```sql
SELECT * FROM t_null FORMAT Vertical
```

```response
Row 1:
──────
x: 1
y: ᴺᵁᴸᴸ
```

De forma predeterminada, los caracteres de control no imprimibles (controles C0 `0x00`–`0x1F` y `DEL` `0x7F`) presentes en los valores y en los nombres de columna se muestran como sus correspondientes &quot;Control Pictures&quot; de Unicode (`U+2400`–`U+2421`), de modo que siguen siendo visibles en lugar de que el terminal los descarte sin dejar rastro. Por ejemplo, un NUL se muestra como `␀`:

```sql
SELECT 'string with a NUL \0 character' AS test FORMAT Vertical
```

```response
Row 1:
──────
test: string with a NUL ␀ character
```

`TAB`, el salto de línea y `ESC` son excepciones: siempre se imprimen tal cual, porque el terminal los interpreta en lugar de descartarlos (un tabulador avanza hasta la siguiente posición de tabulación, un salto de línea inicia una nueva línea y una secuencia de escape ANSI es lo que permite que los datos incluyan una visualización). El nombre de columna es la excepción a esa excepción: se representa en una sola línea, por lo que un salto de línea en un nombre se reemplaza como cualquier otro carácter de control.

Para imprimir, en cambio, los caracteres de control de forma literal, desactive [`output_format_pretty_display_control_characters`](/es/reference/settings/formats#output_format_pretty_display_control_characters):

```sql
SELECT 'string with a NUL \0 character' AS test
FORMAT Vertical
SETTINGS output_format_pretty_display_control_characters = 0
```

En ese caso, la respuesta contiene el byte `NUL` sin procesar. Un terminal lo descarta, por lo que el valor
se ve como si el carácter simplemente no estuviera.

Este formato solo es adecuado para mostrar el resultado de una consulta, no para analizar datos (obtener datos para su inserción en una tabla).
