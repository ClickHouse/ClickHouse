## allow_experimental_analyzer {#allow_experimental_analyzer}

**Aliases**: `enable_analyzer`

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "El ajuste es obsoleto: el analizador es obligatorio y el antiguo análisis de consultas ya no es compatible. Su desactivación se rechaza en lugar de ignorarse, y `compatibility` con una versión inferior a 24.3 ya no lo revierte."}]}, {"id": "row-2","items": [{"label": "24.3"},{"label": "1"},{"label": "Habilita el analizador y el planificador de forma predeterminada."}]}]} />

Obsoleto desde v26.9: el analizador ya no se puede desactivar.

El analizador es la infraestructura de análisis y planificación de consultas que se utiliza de forma predeterminada desde v24.3. En v26.9 este ajuste quedó fijado en su único valor admitido, `1`: cualquier intento de establecerlo en `0` se rechaza, y el ajuste `compatibility` ya no lo revierte. En v26.10 se eliminó el análisis de consultas al que solía cambiar. Elimine `enable_analyzer = 0` de las consultas, los ajustes de sesión, los perfiles de configuración y las configuraciones de client. Para comparar el comportamiento o el rendimiento de una consulta con el antiguo análisis de consultas, utilice una versión de ClickHouse anterior a v26.9.
