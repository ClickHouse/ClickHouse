## use_statistics_for_min_max_aggregation {#use_statistics_for_min_max_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Nueva configuración para resolver las agregaciones `min`, `max` y `count` sin `GROUP BY` ni filtros a partir de las estadísticas de columna por parte, en las partes que las tienen materializadas, leyendo únicamente las partes restantes. previous_value=false, de modo que la `compatibility` con versiones anteriores a la 26.9 mantiene la optimización deshabilitada y restaura el plan preexistente."}]}]} />

Resuelve las agregaciones `min`, `max` y `count` a partir de las estadísticas de columna por parte en lugar de leer los datos.

Cuando está habilitada, una consulta de la forma `SELECT min(column), max(column), count() FROM table` sin `GROUP BY` ni filtros
se resuelve a partir de las estadísticas de columna (por ejemplo, las estadísticas MinMax; consulte la MergeTree setting `auto_statistics_types`)
en las partes que las tienen materializadas, y solo se leen las partes restantes.

Valores posibles:

* 0 — Deshabilitado.
* 1 — Habilitado.

## use_statistics_for_part_pruning {#use_statistics_for_part_pruning}

Usa estadísticas para filtrar partes durante la ejecución de consultas.

Cuando está habilitada, la poda en las consultas SELECT usa estadísticas de columna (por ejemplo, estadísticas MinMax) para eliminar partes que no pueden contener datos coincidentes antes de leer ningún dato.
