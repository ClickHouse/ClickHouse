## use_statistics_for_min_max_aggregation {#use_statistics_for_min_max_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "1"},{"label": "Nueva configuración para resolver las agregaciones `min`, `max` y `count` sin `GROUP BY` ni filtros a partir de las estadísticas de columna por parte, en las partes que las tienen materializadas, leyendo únicamente las partes restantes. previous_value=false, de modo que la `compatibility` con versiones anteriores a la 26.9 mantiene la optimización deshabilitada y restaura el plan preexistente."}]}]} />

Resuelve las agregaciones `min`, `max` y `count` a partir de las estadísticas de columna por parte en lugar de leer los datos.

Cuando está habilitada, una consulta de la forma `SELECT min(column), max(column), count() FROM table` sin `GROUP BY` ni filtros
se resuelve a partir de las estadísticas de columna (por ejemplo, las estadísticas MinMax; consulte el ajuste de MergeTree `auto_statistics_types`)
en las partes de datos que las tienen materializadas, y solo se leen las partes restantes.
`count()` también se resuelve junto con las agregaciones de `use_statistics_for_sum_avg_aggregation`.

Valores posibles:

* 0 — Deshabilitado.
* 1 — Habilitado.

## use_statistics_for_part_pruning {#use_statistics_for_part_pruning}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.4"},{"label": "1"},{"label": "Nueva configuración para usar estadísticas para descartar partes durante la ejecución de consultas."}]}]} />

Usa estadísticas para filtrar partes durante la ejecución de consultas.

Cuando está habilitada, la poda en las consultas SELECT usa estadísticas de columna (por ejemplo, estadísticas MinMax) para eliminar partes que no pueden contener datos coincidentes antes de leer ningún dato.

Valores posibles:

* 0 — Deshabilitado.
* 1 — Habilitado.

## use_statistics_for_sum_avg_aggregation {#use_statistics_for_sum_avg_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "1"},{"label": "Nueva configuración para resolver las agregaciones `sum`, `avg`, `sumCount` y `count(column)` sin `GROUP BY` ni filtros a partir de las estadísticas de columnas por parte. previous_value=false, de modo que `compatibility` con versiones anteriores a 26.11 mantiene la optimización deshabilitada y restaura el plan anterior."}]}]} />

Resuelve las agregaciones `sum`, `avg` y `sumCount` sobre columnas integer y `Decimal` que no sean `LowCardinality`,
sin `GROUP BY` ni filtros, a partir de las estadísticas de columnas por parte (el tipo de estadísticas `basic`; consulte el
ajuste `auto_statistics_types` de `MergeTree`) en las partes de datos que las tengan materializadas, y solo lee las partes
restantes. En ese caso, `count(column)` de una columna que no sea `LowCardinality` se resuelve a partir del número de filas. En una
columna `Nullable`, las estadísticas almacenan la suma de los valores non-NULL y el recuento de valores NULL, que las funciones de agregación omiten.
El resultado es exactamente el mismo que si se leyeran los datos.

Valores posibles:

* 0 — Deshabilitado.
* 1 — Habilitado.
