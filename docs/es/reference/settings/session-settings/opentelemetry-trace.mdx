## opentelemetry_trace_stateless_worker_discovery {#opentelemetry_trace_stateless_worker_discovery}

<CloudOnlyBadge />

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0"},{"label": "Nueva configuración para recopilar spans de OpenTelemetry de las solicitudes que una consulta realiza al servicio de descubrimiento de stateless-worker para aprovisionar trabajadores."}]}]} />

Solo tiene efecto en ClickHouse Cloud. Si la propia consulta se está registrando en una traza, recopila spans de OpenTelemetry de las solicitudes que realiza al servicio de descubrimiento de stateless-worker para aprovisionar (arrendar) trabajadores.
Los spans se denominan `StatelessWorkerDiscovery.<action>` e incluyen los atributos `clickhouse.discovery.action` y `clickhouse.discovery.status`.
