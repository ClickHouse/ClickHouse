## network_compression_method {#network_compression_method}

<SettingsInfoBlock type="String" default_value="ZSTD" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.9"},{"label": "ZSTD"},{"label": "Se cambió el método de compresión por defecto para la comunicación entre cliente\/servidor y servidor\/servidor de `LZ4` a `ZSTD` para reducir el tráfico de red."}]}]} />

El códec para comprimir la comunicación entre cliente y servidor, y entre servidores, a través del protocolo nativo.

Este ajuste no se aplica al canal de exchange en streaming de las consultas distribuidas, que siempre utiliza el códec por defecto del servidor: cada frame comprimido es autodescriptivo, por lo que el receiver detecta el códec automáticamente.

Valores posibles:

* `NONE` — sin compresión.
* `LZ4` — utiliza el códec LZ4.
* `LZ4HC` — utiliza el códec LZ4HC.
* `ZSTD` — utiliza el códec ZSTD.

## network_zstd_compression_level {#network_zstd_compression_level}
