## automatic_parallel_replicas_max_duplicated_read_ratio {#automatic_parallel_replicas_max_duplicated_read_ratio}

<SettingsInfoBlock type="Float" default_value="0.5" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "0.5"},{"label": "Las réplicas paralelas automáticas ahora rechazan cualquier consulta que repetiría más de la mitad de su lectura en cada réplica. Antes no había ningún límite, que es lo que se sigue obteniendo con el valor 1."}]}]} />

Proporción del volumen de lectura de una consulta que puede leerse en todas las réplicas, en lugar de repartirse entre ellas, expresada como
fracción del total, antes de que las réplicas paralelas automáticas rechacen la consulta.

Solo se reparte la lectura que coordinan las réplicas paralelas; cualquier otra lectura del mismo subárbol se ejecuta íntegramente en cada
réplica. Esas lecturas tardan el mismo tiempo de reloj en ambos casos, por lo que la comparación del modelo de costes no las tiene en cuenta,
pero el cluster realiza `max_parallel_replicas` veces más trabajo para ellas. Este parámetro de configuración limita
ese desperdicio: con el valor predeterminado de 0.5, una consulta cuya lectura coordinada sea inferior a la mitad de todo lo que lee
sigue ejecutándose en un solo nodo, sea cual sea el resultado de la comparación de tiempos.

Establézcalo en 1 para aceptar cualquier cantidad de lectura duplicada, lo que restaura el comportamiento anterior, en el que solo se comparaban los tiempos.

## automatic_parallel_replicas_min_bytes_per_replica {#automatic_parallel_replicas_min_bytes_per_replica}

<SettingsInfoBlock type="UInt64" default_value="1048576" />

Umbral de bytes que deben leerse por réplica para habilitar automáticamente las réplicas paralelas (se aplica solo cuando `automatic_parallel_replicas_mode`=1). 0 significa que no hay umbral.
El número total de bytes que deben leerse se calcula a partir de las estadísticas recopiladas.

## automatic_parallel_replicas_mode {#automatic_parallel_replicas_mode}

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.12"},{"label": "0"},{"label": "Nueva configuración"}]}]} />

Habilita el cambio automático a la ejecución con réplicas paralelas en función de las estadísticas recopiladas. Requiere `enable_parallel_replicas = 1`, `parallel_replicas_local_plan = 1` y que se proporcione `cluster_for_parallel_replicas`. Con `enable_parallel_replicas = 2`, se fuerza el uso de réplicas paralelas y no se aplica el modo automático.
0 - deshabilitado, 1 - habilitado, 2 - solo está habilitada la recopilación de estadísticas (el cambio a la ejecución con réplicas paralelas está deshabilitado).

## automatic_parallel_replicas_remember_boundary {#automatic_parallel_replicas_remember_boundary}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.10"},{"label": "1"},{"label": "Nuevo ajuste. Las réplicas paralelas automáticas ahora recuerdan, para cada plan de consulta, el límite de la parte del trabajo que corresponde a las réplicas; anteriormente, cada consulta construía el plan con réplicas paralelas para determinarlo."}]}]} />

Permite que las réplicas paralelas automáticas recuerden, para cada plan de consulta, dónde termina la parte del trabajo que corresponde a las réplicas, de modo que,
cuando se repite una consulta cuyas estadísticas descartan las réplicas paralelas, la decisión se tome sin construir el plan con réplicas
paralelas.

Desactívelo para que cada consulta asuma el coste completo de la decisión, por ejemplo, al medir dicho coste con pruebas comparativas de rendimiento.
