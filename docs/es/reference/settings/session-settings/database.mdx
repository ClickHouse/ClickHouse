  ## database
</div>

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": ""},{"label": "Nueva configuración que especifica la base de datos actual de la consulta. Sustituye el tratamiento especial del parámetro URL `database` de la interfaz HTTP y del encabezado `X-ClickHouse-Database`."}]}]} />

Establece la base de datos actual para la consulta: la base de datos en la que se resuelven los nombres de tablas sin calificar, con el mismo efecto que `USE <database>`. A diferencia de la sentencia `USE`, se trata de un ajuste de sesión ordinario: como cualquier otra configuración, acepta un valor sin validarlo y una base de datos desconocida se notifica cuando la configuración surte efecto (al ejecutar una consulta), no al ejecutar `SET`. Sigue el modelo de privilegios de la base de datos predeterminada proporcionada por el client (que generaliza), no el de `USE`: seleccionar la base de datos actual no requiere el privilegio `SHOW_DATABASES`, mientras que el acceso a las tablas que contiene se comprueba como de costumbre. Se utiliza como destino para el parámetro URL `database` de la interfaz HTTP y el encabezado `X-ClickHouse-Database`.

<div id="database_atomic_wait_for_drop_and_detach_synchronously">
  ## database_atomic_wait_for_drop_and_detach_synchronously
</div>

<SettingsInfoBlock type="Bool" default_value="0" />

Añade un modificador `SYNC` a todas las consultas `DROP` y `DETACH`.

Posibles valores:

* 0 — Las consultas se ejecutarán con demora.
* 1 — Las consultas se ejecutarán sin demora.
