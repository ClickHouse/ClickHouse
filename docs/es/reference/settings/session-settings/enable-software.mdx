## enable_software_prefetch_in_aggregation {#enable_software_prefetch_in_aggregation}

<SettingsInfoBlock type="Bool" default_value="1" />

Habilita la precarga por software de las celdas de la tabla hash durante `GROUP BY`. La precarga oculta la latencia de memoria cuando la tabla hash de agregación no cabe en la caché de la CPU, por lo que solo se utiliza una vez que la tabla hash supera el tamaño de la caché L2.
