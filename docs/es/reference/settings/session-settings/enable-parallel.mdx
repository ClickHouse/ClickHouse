<div id="enable_parallel_single_level_merge">
  ## enable_parallel_single_level_merge
</div>

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "Nueva configuración para paralelizar la combinación final de las tablas hash de agregación de un solo nivel dividiendo el espacio de claves en particiones hash disjuntas que los hilos combinan de forma independiente."}]}]} />

Paraleliza la combinación final de las tablas hash de agregación de un solo nivel de cada hilo. El espacio de claves se divide en particiones disjuntas según el hash de la clave, y cada partición se combina de forma independiente: el hilo de combinación recorre todas las tablas de cada hilo y combina las claves que pertenecen a su partición, de modo que dos hilos nunca acceden a la misma clave. Si la configuración está desactivada, las tablas de un solo nivel se combinan secuencialmente en un único hilo. La agregación por claves de 8 y 16 bits conserva su propia combinación paralela particionada por rangos, independientemente de esta configuración.
