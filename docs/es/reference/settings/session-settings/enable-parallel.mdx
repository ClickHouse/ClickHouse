## enable_parallel_single_level_merge {#enable_parallel_single_level_merge}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "1"},{"label": "Nuevo parámetro de configuración para paralelizar la fusión final de las tablas hash de agregación single-level dividiendo el espacio de claves en particiones hash disjuntas que los threads fusionan de forma independiente."}]}]} />

Paraleliza la fusión final de las tablas hash de agregación single-level de cada thread. El espacio de claves se divide en particiones disjuntas según el hash de la clave, y cada partición se fusiona de forma independiente: el thread de fusión recorre todas las tablas de cada thread y combina las claves que pertenecen a su partición, de modo que dos threads nunca acceden a la misma clave. Si el parámetro de configuración está desactivado, las tablas single-level se fusionan secuencialmente en un único thread. La agregación por claves de 8 y 16 bits conserva su propia fusión paralela particionada por rangos, independientemente de este parámetro de configuración.

## enable_parallel_single_level_merge_by_index {#enable_parallel_single_level_merge_by_index}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "1"},{"label": "Nueva configuración que permite que la fusión paralela lea solo las celdas de cada partición de las tablas hash single-level del agregador adaptativo a través de los índices de sus celdas, en lugar de escanear todas las celdas de cada tabla para cada partición."}]}]} />

Permite que la fusión paralela de las tablas hash de agregación single-level (consulte `enable_parallel_single_level_merge`) lea las tablas del agregador adaptativo (consulte `enable_adaptive_aggregator`) a través de un índice de sus celdas, que cada thread construye al terminar de agregar. Así, para cada partición, la fusión lee únicamente las celdas de esa partición en cada tabla. Si el parámetro de configuración está desactivado, la fusión escanea todas las celdas de cada tabla para cada partición.
