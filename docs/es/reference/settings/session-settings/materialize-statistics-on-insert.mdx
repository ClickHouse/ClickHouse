Las estadísticas se crean y materializan para las partes recién insertadas. Incluso si está deshabilitado, las estadísticas se seguirán creando y almacenando durante las fusiones o mediante MATERIALIZE STATISTICS explícito. Solo se ven afectadas las tablas cuyo tamaño actual, sumado al tamaño del bloque que se está escribiendo, no supere `materialize_statistics_on_insert_max_table_size`.
