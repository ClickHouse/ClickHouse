  ## deduplicate_insert

Habilita o deshabilita la deduplicación de bloques de `INSERT INTO` (para tablas Replicated*).
Esta configuración se aplica tanto a las inserciones síncronas como asíncronas, y anula las configuraciones `insert_deduplicate` y `async_insert_deduplicate`.
Esta configuración tiene tres valores posibles:

* disable — La deduplicación está deshabilitada para la consulta `INSERT INTO`.
* enable — La deduplicación está habilitada para la consulta `INSERT INTO`.
* backward&#95;compatible&#95;choice — La deduplicación está habilitada si `insert_deduplicate` o `async_insert_deduplicate` están habilitados para el tipo específico de inserción.

Para las consultas `INSERT SELECT`, se consulta primero [`deduplicate_insert_select`](/es/reference/settings/session-settings/deduplicate-insert#deduplicate_insert_select). La deduplicación también requiere que la tabla de destino conserve un registro de deduplicación; consulte [replicated&#95;deduplication&#95;window](/es/reference/settings/merge-tree-settings/replicated-deduplication-window#replicated_deduplication_window) y [non&#95;replicated&#95;deduplication&#95;window](/es/reference/settings/merge-tree-settings/other#non_replicated_deduplication_window).

Habilita o deshabilita la deduplicación de bloques de `INSERT SELECT` (para tablas Replicated*).
Para las consultas `INSERT SELECT`, esta configuración se consulta antes de [`deduplicate_insert`](/es/reference/settings/session-settings/deduplicate-insert#deduplicate_insert).
Un `SELECT` es estable cuando incluye `ORDER BY ALL` y su pipeline termina en un único flujo. Un [`insert_deduplication_token`](/es/reference/settings/session-settings/insert#insert_deduplication_token) no vacío equivale a que el resultado sea estable.
Esta configuración tiene cuatro valores posibles:

* disable — La deduplicación está deshabilitada para la consulta `INSERT SELECT`.
* force&#95;enable — La deduplicación está habilitada para la consulta `INSERT SELECT`, independientemente de `deduplicate_insert`. Si el resultado de `SELECT` no es estable y no se proporciona ningún token, se lanza una excepción.
* enable&#95;when&#95;possible — La deduplicación está habilitada si `deduplicate_insert` la habilita y el resultado de `SELECT` es estable; de lo contrario, se deshabilita.
* enable&#95;even&#95;for&#95;bad&#95;queries - La deduplicación está habilitada si `deduplicate_insert` la habilita, independientemente de si el resultado de `SELECT` es estable. Si el resultado de `SELECT` no es estable, se registra un mensaje, pero la consulta se ejecuta con deduplicación. Esta opción se incluye por compatibilidad con versiones anteriores. Considere usar otras opciones en su lugar, ya que puede producir resultados inesperados.
