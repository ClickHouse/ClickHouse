## compatibility_ignore_auto_increment_in_create_table {#compatibility_ignore_auto_increment_in_create_table}

<SettingsInfoBlock type="Bool" default_value="0" />

Ignora la palabra clave AUTO&#95;INCREMENT en la declaración de la columna si está activado; de lo contrario, devuelve un error. Esto simplifica la migración desde MySQL

## compatibility_ignore_collation_in_create_table {#compatibility_ignore_collation_in_create_table}

<SettingsInfoBlock type="Bool" default_value="1" />

Si está habilitado, una cláusula `COLLATE` en la declaración de una columna de una consulta `CREATE TABLE` se acepta y se ignora. Esto permite ejecutar definiciones de tablas escritas para otros sistemas de bases de datos, como MySQL, sin necesidad de modificarlas.

Si está deshabilitado, una consulta `CREATE TABLE` que especifica una intercalación de columna lanza una excepción.
