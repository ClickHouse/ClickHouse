## enable_optimize_predicate_expression_to_final_subquery {#enable_optimize_predicate_expression_to_final_subquery}

<SettingsInfoBlock type="Bool" default_value="1" />

Permite añadir un filtro de la consulta a la consulta que se envía a los servidores remotos (por ejemplo, al leer de una tabla `Distributed`) cuando esta usa `FINAL`. Así se reduce la cantidad de datos que devuelven los servidores remotos.

Si está deshabilitado, el filtro no se añade a dichas consultas y solo se aplica después de recibir los datos de los servidores remotos.
