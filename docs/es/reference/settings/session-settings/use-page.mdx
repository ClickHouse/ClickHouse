## use_page_cache_for_local_disks {#use_page_cache_for_local_disks}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "Nueva configuración para usar la caché de páginas en espacio de usuario para discos locales"}]}]} />

Usa la caché de páginas en espacio de usuario al leer desde discos locales. Se usa para pruebas y es poco probable que mejore el rendimiento en la práctica. Requiere local&#95;filesystem&#95;read&#95;method = &#39;pread&#39; o &#39;read&#39;. No desactiva la caché de páginas del SO; para eso se puede usar min&#95;bytes&#95;to&#95;use&#95;direct&#95;io. Solo afecta a las tablas normales, no a la función de tabla file() ni al motor de tabla File().

## use_page_cache_for_object_storage {#use_page_cache_for_object_storage}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.2"},{"label": "0"},{"label": "Nueva configuración para utilizar la caché de páginas en espacio de usuario con las funciones de tabla de almacenamiento de objetos"}]}, {"id": "row-2","items": [{"label": "26.12"},{"label": "1"},{"label": "Utilizar de forma predeterminada la caché de páginas en espacio de usuario con los motores de tablas y las funciones de tabla de almacenamiento de objetos si la caché de páginas está configurada en el servidor."}]}]} />

Utiliza la caché de páginas en espacio de usuario al leer desde funciones de tabla (s3, azure, hdfs, Iceberg, Delta Lake, etc.) y motores de tablas (S3, Azure, HDFS, Iceberg, Delta Lake, etc.) de almacenamiento de objetos. Solo tiene efecto si la caché de páginas en espacio de usuario está configurada en el servidor (`page_cache_max_size`), y únicamente para objetos con un ETag fuerte o con una identity inmutable obtenida de los registros de la table (archivos de datos de Iceberg y Delta Lake). No se utiliza junto con la caché del sistema de archivos. Solo se utiliza junto con Distributed Cache si `use_page_cache_with_distributed_cache` también está habilitado.

## use_page_cache_lookahead_for_text_index {#use_page_cache_lookahead_for_text_index}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nueva configuración"}]}]} />

Los archivos del índice de texto que se leen sin seguir el orden del archivo (diccionario, listas de apariciones, posiciones) se leen, de forma predeterminada, a través de la caché de páginas en espacio de usuario con una lectura anticipada de un bloque, de modo que la conexión remota pueda reutilizarse tras cada lectura. Active este parámetro de configuración para que, en su lugar, esos archivos usen `page_cache_lookahead_blocks`, igual que el resto de archivos.
