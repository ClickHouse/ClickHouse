## write_through_distributed_cache_buffer_size {#write_through_distributed_cache_buffer_size}

<CloudOnlyBadge />

<SettingsInfoBlock type="UInt64" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "25.7"},{"label": "0"},{"label": "Nueva SETTING de Cloud"}]}]} />

Solo tiene efecto en ClickHouse Cloud. El tamaño máximo del búfer que se escribe en los servidores de la caché distribuida, por cada búfer de escritura. Es independiente del búfer que se escribe en el object storage: ese sigue creciendo hasta alcanzar el tamaño de la parte de subida. Si es 0, se usa `DBMS_DEFAULT_BUFFER_SIZE` (1 MiB). El búfer comienza en `adaptive_write_buffer_initial_size` y solo crece hasta este tamaño a medida que se escribe el stream, de modo que una parte no lo reserve para cada stream que escribe.
