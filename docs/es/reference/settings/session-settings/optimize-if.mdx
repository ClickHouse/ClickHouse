## optimize_if_transform_const_strings_to_lowcardinality {#optimize_if_transform_const_strings_to_lowcardinality}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "0"},{"label": "Nueva configuración que permite optimizar los resultados de las ramas constantes de `if`\/`multiIf`\/`transform` a `LowCardinality`. Deshabilitada de forma predeterminada."}]}]} />

Si está habilitado, las funciones `if`, `multiIf` y `transform` cuyas ramas de resultado (y valores predeterminados) sean cadenas constantes devolverán `LowCardinality(String)` en lugar de `String`.
Está deshabilitado de forma predeterminada porque construir un diccionario `LowCardinality` por bloque puede resultar más lento que devolver un `String` simple cuando el diccionario no se reutiliza en etapas posteriores.
La optimización no se aplica cuando toda la expresión es constante (es decir, cuando también lo son la condición o la entrada): una constante no se beneficia en nada de `LowCardinality`, y así las funciones que esperan argumentos `String` constantes (p. ej., `arrayReduce`, `joinGet`, `tupleElement`) siguen funcionando.

Todas las ramas de resultado deben ser constantes, por lo que una cadena de `if` anidados como `if(cond1, 'a', if(cond2, 'b', 'c'))` conserva el tipo `String` simple: la rama else del `if` externo es otro `if`, no una constante. Para obtener `LowCardinality(String)`, escríbala como `multiIf(cond1, 'a', cond2, 'b', 'c')`.

Este parámetro de configuración no tiene efecto mientras `optimize_if_transform_strings_to_enum` esté habilitado: la reescritura a `Enum` tiene precedencia y el resultado sigue siendo `String` (o `Nullable(String)`), incluso con la forma explícita de `multiIf` mostrada arriba.

## optimize_if_transform_strings_to_enum {#optimize_if_transform_strings_to_enum}

<SettingsInfoBlock type="Bool" default_value="0" />

Reemplaza por enum los argumentos de tipo String en If y Transform. Está deshabilitado de forma predeterminada porque podría provocar un cambio incoherente en una consulta distribuida, lo que haría que fallara.
