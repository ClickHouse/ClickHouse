## merge_checkpoints_min_bytes {#merge_checkpoints_min_bytes}

<ExperimentalBadge />

<SettingsInfoBlock type="UInt64" default_value="10737418240" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "10737418240"},{"label": "Nueva configuración para puntos de control persistentes de fusiones"}]}]} />

Tamaño total mínimo, en bytes, de las partes de origen de una fusión para que se cree un punto de control de ella con `enable_merge_checkpoints`.
No se crean puntos de control para las fusiones más pequeñas, ya que repetirlas resulta barato.

## merge_checkpoints_min_interval_seconds {#merge_checkpoints_min_interval_seconds}

<ExperimentalBadge />

<SettingsInfoBlock type="Seconds" default_value="60" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.11"},{"label": "60"},{"label": "Nueva configuración para puntos de control persistentes de fusiones"}]}]} />

Tiempo mínimo entre dos puntos de control de una fusión con `enable_merge_checkpoints`.
Una fusión vertical siempre crea un punto de control en cuanto se han fusionado sus columnas de clave. A partir de ese momento, solo crea un punto de control al completar una columna
si ha transcurrido este tiempo desde su punto de control anterior.

## merge_use_batch_sorting_queue {#merge_use_batch_sorting_queue}

<SettingsInfoBlock type="Bool" default_value="0" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.8"},{"label": "0"},{"label": "Nueva configuración para usar la cola de ordenación por lotes en fusiones ordinarias de `MergeTree`."}]}]} />

Use la cola de ordenación por lotes para reducir la sobrecarga por fila de la cola al fusionar flujos ordenados.

Solo se aplica a las fusiones que no modifican filas, es decir, a `MergeTree`
sin modificaciones (modo de fusión `Ordinary`). No tiene efecto en los motores con
semántica de fusión, como `ReplacingMergeTree`, `CollapsingMergeTree`,
`SummingMergeTree`, `AggregatingMergeTree`, `CoalescingMergeTree`,
`GraphiteMergeTree` y `VersionedCollapsingMergeTree`, que siguen usando la
cola predeterminada independientemente de esta configuración.

## merge_workload {#merge_workload}

Se utiliza para regular cómo se usan y comparten los recursos entre las fusiones y
otras cargas de trabajo. El valor especificado se usa como valor de la configuración `workload` para las
fusiones en segundo plano de esta table. Si no se especifica (cadena vacía), se
usa en su lugar la configuración del server `merge_workload`.
