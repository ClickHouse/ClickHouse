## vertical_merge_optimize_ttl_delete {#vertical_merge_optimize_ttl_delete}

<SettingsInfoBlock type="Bool" default_value="1" />

<VersionHistory rows={[{"id": "row-1","items": [{"label": "26.3"},{"label": "1"},{"label": "Permite el algoritmo de fusión vertical para las fusiones que necesitan eliminar filas cuyo TTL ha expirado"}]}]} />

Si es true, una fusión con TTL de filas puede usar el algoritmo de fusión vertical en lugar de recurrir a una
fusión horizontal. Solo se aplica en los modos de fusión `MergeTree`, `Replacing`, `Collapsing` o `VersionedCollapsing`,
a tablas con TTL de filas y sin TTL de columna ni de `GROUP BY`, y solo mientras ninguna parte
de la fusión contenga una eliminación ligera. Cualquier otra fusión con TTL se mantiene horizontal.
