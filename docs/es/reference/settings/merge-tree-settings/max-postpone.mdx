## max_postpone_time_for_failed_mutations_ms {#max_postpone_time_for_failed_mutations_ms}

<SettingsInfoBlock type="UInt64" default_value="300000" />

Backoff exponencial máximo, en milisegundos, antes de reintentar una mutación fallida sobre la misma parte de datos. El retardo aumenta tras fallos sucesivos y nunca supera este valor. Establézcalo en `0` para reintentar sin aplazamiento.

Valor máximo del backoff exponencial, en milisegundos, antes de reintentar una tarea `GET_PART` fallida en una cola de replicación de `ReplicatedMergeTree`. El retraso aumenta con cada fallo sucesivo, hasta el límite que fija este valor. Establézcalo en `0` para desactivar el aplazamiento.
