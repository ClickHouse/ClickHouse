La versión de formato de serialización en disco preferida para escribir índices de texto.

La configuración es una preferencia, no una restricción estricta: si la versión configurada no puede
representar un índice, se elige automáticamente una versión más reciente que pueda representarlo, y
la escritura de un índice de texto nunca falla a causa de esta configuración.

Durante una actualización progresiva, fije el formato mediante la configuración `compatibility` de nivel de perfil en
los servidores ya actualizados, para que sigan escribiendo un formato que los servidores más antiguos aún puedan leer.

Valores posibles:

* `v0_initial` — El formato original. No persiste el tipo de códec de la posting list.
* `v1_with_codec` — Persiste el tipo de códec de la posting list en el encabezado del índice de texto.
* `v2_with_positions` — Persiste las posiciones de los tokens para índices con `support_phrase_search`.
