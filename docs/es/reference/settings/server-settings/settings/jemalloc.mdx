Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

<div id="jemalloc_collect_global_profile_samples_in_trace_log">
  ## jemalloc_collect_global_profile_samples_in_trace_log
</div>

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Guarda las asignaciones de memoria muestreadas de jemalloc en system.trace&#95;log

<div id="jemalloc_max_background_threads_num">
  ## jemalloc_max_background_threads_num
</div>

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="No" />Número máximo de hilos en segundo plano de jemalloc que se pueden crear; establezca 0 para usar el valor predeterminado de jemalloc

<div id="jemalloc_merge_tree_arenas">
  ## jemalloc_merge_tree_arenas
</div>

<SettingsInfoBlock type="UInt64" default_value="1" changeable_without_restart="No" />Número de arenas jemalloc dedicadas a los metadatos persistentes de MergeTree, tanto por parte como por tabla. `0` desactiva la arena dedicada (los metadatos usan las arenas predeterminadas por CPU). `1` utiliza una única arena compartida. `N > 1` crea un grupo de `N` arenas y asigna la asignación de memoria por CPU; en máquinas con muchos núcleos, esto evita serializar la asignación de metadatos en los bloqueos de una única arena. El valor se limita al número de CPU en las que puede ejecutarse el proceso (su máscara de afinidad), por lo que un valor elevado (o el número de núcleos) proporciona una arena por cada CPU permitida. Se aplica al inicio.

<div id="jemalloc_profiler_sampling_rate">
  ## jemalloc_profiler_sampling_rate
</div>

<SettingsInfoBlock type="UInt64" default_value="19" changeable_without_restart="No" />

Controla `lg_prof_sample` de jemalloc: el logaritmo en base 2 del intervalo promedio (en bytes) entre muestras de asignación.
El valor predeterminado de 19 corresponde a 512 KiB. Establecerlo en un valor menor aumenta la frecuencia de muestreo (más sobrecarga, más detalle), mientras que un valor mayor la reduce.
Cambiar este valor invoca `prof.reset`, lo que restablece todas las estadísticas de perfilado acumuladas. Requiere que el perfilado esté habilitado (`MALLOC_CONF=prof:true`).
