Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## gpu_memory_pool_release_threshold {#gpu_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="18446744073709551615" changeable_without_restart="No" />Cantidad de memoria liberada del dispositivo que el grupo de memoria predeterminado de la GPU retiene en lugar de devolverla al controlador. Con el valor predeterminado, el grupo crece hasta alcanzar el pico de uso de las consultas y se mantiene en ese tamaño hasta que el servidor se detiene.

## gpu_pinned_memory_pool_release_threshold {#gpu_pinned_memory_pool_release_threshold}

<SettingsInfoBlock type="UInt64" default_value="1073741824" changeable_without_restart="No" />Tamaño máximo de memoria fijada (pinned) del host ya liberada que el grupo de memoria fijada del host de la GPU conserva para reutilizarla, en lugar de devolverla al sistema.
