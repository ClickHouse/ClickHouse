Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## streaming_exchange_rcvbuf {#streaming_exchange_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Tamaño de la opción SO&#95;RCVBUF para los sockets de streaming exchange de las consultas distribuidas de varias etapas. 0 = valor predeterminado del kernel (ajuste automático de TCP). Un valor mayor que 0 fija un tope para el búfer de recepción de cada socket (limitado por net.core.rmem&#95;max). Se lee en cada conexión, por lo que al recargar la configuración el cambio solo se aplica a las nuevas conexiones.

## streaming_exchange_sndbuf {#streaming_exchange_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Tamaño de la opción SO&#95;SNDBUF para los sockets de streaming exchange de las consultas distribuidas de varias etapas. 0 = valor predeterminado del kernel (ajuste automático de TCP). Un valor mayor que 0 establece un límite máximo para el búfer de envío de cada socket (limitado a su vez por net.core.wmem&#95;max), a costa de restringir el flujo a sndbuf/RTT en enlaces con un RTT elevado. Se lee en cada conexión, por lo que, tras recargar la configuración, el cambio solo se aplica a las conexiones nuevas.
