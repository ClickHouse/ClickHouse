Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## ai_function_max_thread_pool_free_size {#ai_function_max_thread_pool_free_size}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />

Número máximo de threads inactivos en espera que se conservan en el pool de hilos para las solicitudes a proveedores de IA.

## ai_function_max_thread_pool_size {#ai_function_max_thread_pool_size}

<SettingsInfoBlock type="NonZeroUInt64" default_value="1000" changeable_without_restart="Yes" />

Número máximo total de threads que se usarán para las solicitudes a proveedores de IA. Cada thread gestiona una solicitud, por lo que este valor limita cuántas solicitudes a proveedores de IA puede tener en curso simultáneamente todo el servidor, sumando todas las consultas. [`ai_function_max_concurrent_requests_per_thread`](/es/reference/settings/session-settings/ai-function#ai_function_max_concurrent_requests_per_thread) limita la parte que corresponde a cada thread de consulta.

## ai_function_thread_pool_queue_size {#ai_function_thread_pool_queue_size}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="Yes" />

Número máximo de trabajos que se pueden programar en el pool de hilos para las solicitudes a proveedores de IA.
