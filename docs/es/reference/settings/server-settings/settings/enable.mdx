Estas opciones de configuración corresponden al servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## enable_azure_sdk_logging {#enable_azure_sdk_logging}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Habilita el logging del SDK de Azure

## enable_gpu {#enable_gpu}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Reserva la GPU al iniciar el servidor para ejecutar consultas en ella. El servidor se niega a iniciarse si se compiló sin soporte para GPU o si no hay ningún dispositivo CUDA.

## enable_read_through_distributed_cache {#enable_read_through_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />Solo tiene efecto en ClickHouse Cloud. Permite leer desde la caché distribuida. Es una opción de configuración a nivel de servidor que se aplica sin necesidad de reiniciar, de modo que también la sigan las operaciones en segundo plano que no tienen su propio perfil de consulta (fusiones, mutaciones, vaciados de tablas `Buffer`). Las consultas individuales pueden anularla mediante la configuración `force_read_through_distributed_cache`.

## enable_silk_runtime {#enable_silk_runtime}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Habilita la compatibilidad experimental con el tiempo de ejecución de fibras Silk: inicializa el scheduler de fibras Silk al iniciar el servidor para que los subsistemas compatibles puedan ejecutar sus jobs en fibras

## enable_webterminal {#enable_webterminal}

<SettingsInfoBlock type="Bool" default_value="1" changeable_without_restart="No" />Habilita la interfaz de terminal web en el endpoint HTTP `/webterminal`. Proporciona una sesión interactiva de `clickhouse-client` en el navegador a través de WebSocket. Si es `false`, las solicitudes a `/webterminal` devuelven el estado HTTP `403 Forbidden`.

## enable_write_through_distributed_cache {#enable_write_through_distributed_cache}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="Yes" />Solo tiene efecto en ClickHouse Cloud. Permite escribir en la caché distribuida (la caché distribuida también realizará la escritura en S3). Es una opción de configuración a nivel de servidor que se aplica sin reiniciar, por lo que las operaciones en segundo plano que no tienen un perfil de consulta propio (fusiones, mutaciones y vaciados de tablas `Buffer`) también la siguen. Las consultas individuales pueden apartarse de ella mediante la opción `force_write_through_distributed_cache`.
