Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## totp_track_used_codes_in_keeper {#totp_track_used_codes_in_keeper}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />

Garantiza que cada código de contraseña de un solo uso basada en tiempo (TOTP) solo pueda usarse una vez en todos los servidores que comparten el mismo ZooKeeper o ClickHouse Keeper, en lugar de controlarlo en cada servidor por separado.

Los códigos aceptados se registran en Keeper bajo la ruta definida por `totp_used_codes_keeper_path`, con un nodo por usuario cuyo nombre es el hash SHA-256 del nombre de usuario: un código aceptado por un servidor queda rechazado en todos los demás, y el registro se conserva aunque se reinicien los servidores. Keeper debe estar configurado cuando este parámetro de configuración está habilitado; mientras Keeper no esté disponible, la autenticación con una contraseña de un solo uso fallará.

**Ejemplo**

```xml
<totp_track_used_codes_in_keeper>1</totp_track_used_codes_in_keeper>
```

## totp_used_codes_keeper_path {#totp_used_codes_keeper_path}

<SettingsInfoBlock type="String" default_value="/clickhouse/access/one_time_passwords" changeable_without_restart="No" />

Ruta en Keeper en la que se registran los códigos de contraseña de un solo uso basados en tiempo (TOTP) ya aceptados cuando `totp_track_used_codes_in_keeper` está habilitado. Los clústeres que comparten un mismo Keeper sin chroot deben usar rutas distintas; de lo contrario, los usuarios con el mismo nombre en distintos clústeres compartirían sus registros.

**Ejemplo**

```xml
<totp_used_codes_keeper_path>/clickhouse/access/one_time_passwords</totp_used_codes_keeper_path>
```
