Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## startup_mv_delay_ms {#startup_mv_delay_ms}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="No" />Parámetro de depuración para simular el retraso en la creación de vistas materializadas

## startup_scripts.throw_on_error {#startup_scripts.throw_on_error}

<SettingsInfoBlock type="Bool" default_value="0" changeable_without_restart="No" />Si se establece en true, el servidor no se iniciará si ocurre un error durante la ejecución del script.
