Estos ajustes configuran el servidor de ClickHouse y se generan automáticamente a partir del código fuente de ClickHouse.

## amber_connections_hard_limit {#amber_connections_hard_limit}

<SettingsInfoBlock type="UInt64" default_value="200000" changeable_without_restart="No" />Cuando se alcanza este límite, se lanza una excepción al intentar crear una conexión. Establézcalo en 0 para desactivar el límite estricto. El límite se aplica a las conexiones de Amber.

## amber_connections_rcvbuf {#amber_connections_rcvbuf}

<SettingsInfoBlock type="UInt64" default_value="204800" changeable_without_restart="Yes" />Tamaño de la opción SO&#95;RCVBUF para las conexiones de Amber. El valor predeterminado es 204800 (200 KB): el acceso al almacenamiento de objetos se realiza dentro de la misma región, donde el producto ancho de banda-retardo queda muy por debajo de 100 KB, por lo que un límite pequeño permite alcanzar el caudal máximo y evita los búferes de varios MiB por socket que, de lo contrario, asignaría el ajuste automático del núcleo. Establézcalo en 0 para usar en su lugar el ajuste automático de TCP del núcleo para el búfer de recepción. Nota: si vuelve a establecer este parámetro de configuración en 0, el ajuste automático solo se restaura para las conexiones que se creen a partir de ese momento; las conexiones agrupadas existentes mantienen tamaños de búfer fijos hasta que se recrean.

## amber_connections_sndbuf {#amber_connections_sndbuf}

<SettingsInfoBlock type="UInt64" default_value="0" changeable_without_restart="Yes" />Tamaño de la opción SO&#95;SNDBUF para las conexiones de Amber. Si se establece en un valor mayor que 0, sustituye el ajuste automático de TCP del núcleo para el búfer de envío. 0 = valor predeterminado del núcleo (ajuste automático). Nota: si se vuelve a establecer este parámetro de configuración en 0, el ajuste automático solo se restaura para las conexiones creadas a partir de ese momento; las conexiones agrupadas existentes conservan tamaños de búfer fijos hasta que se recrean.

## amber_connections_soft_limit {#amber_connections_soft_limit}

<SettingsInfoBlock type="UInt64" default_value="5000" changeable_without_restart="No" />Las conexiones que superan este límite tienen un tiempo de vida considerablemente más corto. El límite se aplica a las conexiones de Amber.

## amber_connections_store_limit {#amber_connections_store_limit}

<SettingsInfoBlock type="UInt64" default_value="10000" changeable_without_restart="No" />Número máximo de conexiones inactivas que se conservan en el grupo para reutilizarlas. Una vez almacenada esta cantidad de conexiones, las conexiones adicionales se restablecen tras su uso en lugar de conservarse. El límite no se aplica a las conexiones en uso. Establézcalo en 0 para desactivar la caché de conexiones. El límite se aplica a las conexiones de Amber.

## amber_connections_warn_limit {#amber_connections_warn_limit}

<SettingsInfoBlock type="UInt64" default_value="8000" changeable_without_restart="No" />Se escriben mensajes de advertencia en el log si el número de conexiones en uso supera este límite. El límite se aplica a las conexiones de Amber.
