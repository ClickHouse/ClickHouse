Especifica cómo se analiza cada grupo de captura generado por `format_regexp` para convertirlo a su tipo de columna de destino. Use `Raw` (predeterminado) para texto sin escapar, `Escaped` para el escape al estilo TSV, `Quoted` para campos entre comillas al estilo Values, `CSV` para campos CSV o `JSON` para valores JSON. Este parámetro de configuración se aplica después de que la expresión regular coincida con una fila; no modifica la expresión regular en sí.
