## Geometry {#geometry}

Las funciones de Geometry permiten calcular el perímetro, el área y la longitud de tipos geométricos como POLYGON, LINESTRING, MULTIPOLYGON, MULTILINESTRING, RING y POINT. Utilice geometrías del tipo Geometry. Si el valor de entrada es `NULL`, todas las funciones siguientes devolverán 0.

## perimeterCartesian {#perimetercartesian}

Calcula el perímetro del objeto de tipo Geometry especificado en el sistema de coordenadas cartesianas (plano).

**Sintaxis**

```sql
perimeterCartesian(geom)
```

**Argumentos**

* `geom` — Objeto de tipo Geometry. [Geometry](/es/reference/data-types/geo).

**Valores devueltos**

* Número — Perímetro del objeto en las unidades del sistema de coordenadas. [Float64](/es/reference/data-types/float).

**Ejemplo**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('POLYGON((0 0,1 0,1 1,0 1,0 0))');
SELECT perimeterCartesian(geom) FROM geo_dst;
```

```response title="Response"
┌─perimeterCartesian(geom)─┐
│ 4.0                      │
└──────────────────────────┘
```

## perimeterSpherical {#perimeterspherical}

Calcula el perímetro de un objeto de tipo Geometry sobre la superficie de una esfera.

**Sintaxis**

```sql
perimeterSpherical(geom)
```

**Argumentos**

* `geom` — Objeto de tipo Geometry. [Geometry](/es/reference/data-types/geo).

**Valores devueltos**

* Número — Perímetro sobre una esfera de radio 1, en radianes (las coordenadas son longitud y latitud en grados). Para obtener una longitud, multiplíquelo por el radio de la esfera; por ejemplo, por 6371 para obtener kilómetros en la Tierra. [Float64](/es/reference/data-types/float).

**Ejemplo**

```sql title="Query"
CREATE TABLE IF NOT EXISTS geo_dst (geom Geometry) ENGINE = Memory();
INSERT INTO geo_dst SELECT readWKT('LINESTRING(0 0,1 0,1 1,0 1,0 0)');
SELECT perimeterSpherical(geom) FROM geo_dst;
```

```response title="Response"
┌─perimeterSpherical(geom)─┐
│      0.06981051179132045 │
└──────────────────────────┘
```

## lengthCartesian {#lengthcartesian}

Calcula la longitud de las líneas de un objeto de tipo Geometry en el sistema de coordenadas cartesiano (plano): la suma de las distancias entre puntos consecutivos.
La longitud de un `MultiLineString` es la longitud total de sus líneas, y un `Ring` se mide como la línea que pasa por sus puntos, al igual que un array de puntos sin nombre del tipo, que se interpreta como de tipo `Ring`.
Los puntos, polígonos y multipolígonos no tienen longitud, por lo que la función devuelve 0 para ellos; use [perimeterCartesian](#perimetercartesian) para obtener el perímetro de un polígono.
Para medir un arreglo de arreglos de puntos, conviértalo a `MultiLineString`, ya que sin nombre del tipo se interpreta como de tipo `Polygon`.

Alias: `ST_Length`.

**Sintaxis**

```sql
lengthCartesian(geom)
```

**Argumentos**

* `geom` — Objeto de tipo Geometry. [Geometry](/es/reference/data-types/geo).

**Valores devueltos**

* Número — Longitud de las líneas en las unidades del sistema de coordenadas. [Float64](/es/reference/data-types/float).

**Ejemplo**

```sql title="Query"
SELECT lengthCartesian(readWKT('LINESTRING(0 0,3 4,3 10)')) AS length;
```

```response title="Response"
┌─length─┐
│     11 │
└────────┘
```

## lengthSpherical {#lengthspherical}

Calcula la longitud de las líneas de un objeto de tipo Geometry sobre la superficie de una esfera, con los puntos expresados como (longitud, latitud) en grados.
El resultado es un ángulo en radianes, que equivale a la longitud sobre una esfera de radio 1, al igual que el resultado de [perimeterSpherical](#perimeterspherical).
Multiplíquelo por el radio medio de la Tierra, 6371008.8 metros, para obtener una longitud aproximada en metros, o utilice [lengthSpheroid](#lengthspheroid) para obtener una longitud precisa.
Al igual que [lengthCartesian](#lengthcartesian), devuelve 0 para puntos, polígonos y multipolígonos.

**Sintaxis**

```sql
lengthSpherical(geom)
```

**Argumentos**

* `geom` — Objeto de tipo Geometry. [Geometry](/es/reference/data-types/geo).

**Valores devueltos**

* Número — Longitud de las líneas en radianes. [Float64](/es/reference/data-types/float).

**Ejemplo**

```sql title="Query"
SELECT lengthSpherical(readWKT('LINESTRING(0 0,1 0)')) AS length;
```

```response title="Response"
┌───────────────length─┐
│ 0.017453292519943292 │
└──────────────────────┘
```

## lengthSpheroid {#lengthspheroid}

Calcula la longitud en metros de las líneas de un objeto de tipo Geometry sobre el esferoide WGS84, el modelo de la Tierra que utiliza el GPS, con los puntos expresados como (longitud, latitud) en grados.
Cada segmento es el camino más corto entre sus puntos sobre el esferoide (una geodésica), calculado con el algoritmo de Karney, al igual que en GeographicLib.
Al igual que [lengthCartesian](#lengthcartesian), devuelve 0 para puntos, polígonos y multipolígonos.
Si las coordenadas están almacenadas como (latitud, longitud), como en la entrada de `ST_Length_Spheroid` en DuckDB, intercámbielas primero con [flipCoordinates](/es/reference/functions/regular-functions/geo/flipCoordinates): de lo contrario, el resultado será la longitud de una línea distinta.
Si una coordenada es NaN o infinita, o si una latitud está fuera del intervalo [-90, 90], el resultado es NaN.

**Sintaxis**

```sql
lengthSpheroid(geom)
```

**Argumentos**

* `geom` — Objeto de tipo Geometry. [Geometry](/es/reference/data-types/geo).

**Valores devueltos**

* Número — Longitud de las líneas en metros. [Float64](/es/reference/data-types/float).

**Ejemplo**

La longitud de una línea que va de Londres a Berlín pasando por París:

```sql title="Query"
SELECT lengthSpheroid(readWKT('LINESTRING(-0.1276 51.5072,2.3522 48.8566,13.405 52.52)')) AS length;
```

```response title="Response"
┌─────────────length─┐
│ 1223596.2073957825 │
└────────────────────┘
```
