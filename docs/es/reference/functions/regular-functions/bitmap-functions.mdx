<div id="bitmapAnd">
  ## bitmapAnd
</div>

Introducido en: v20.1.0

Calcula la conjunción lógica (AND) de dos bitmaps.

**Sintaxis**

```sql
bitmapAnd(bitmap1, bitmap2)
```

**Argumentos**

* `bitmap1` — Primer objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction). - `bitmap2` — Segundo objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction).

**Valor devuelto**

Devuelve un bitmap que contiene los bits presentes en los dos bitmaps de entrada [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction)

**Ejemplos**

**Ejemplo de uso**

```sql title=Query
SELECT bitmapToArray(bitmapAnd(bitmapBuild([1, 2, 3]), bitmapBuild([3, 4, 5]))) AS res;
```

```response title=Response
┌─res─┐
│ [3] │
└─────┘
```

<div id="bitmapBuild">
  ## bitmapBuild
</div>

Introducido en: v20.1.0

Crea un bitmap a partir de un array de enteros. Los tipos de elementos compatibles son enteros con signo y sin signo de 8, 16, 32 o 64 bits. Es la operación inversa de la función [`bitmapToArray`](/es/reference/functions/regular-functions/bitmap-functions#bitmapToArray).

**Sintaxis**

```sql
bitmapBuild(array)
```

**Argumentos**

* `array` — Array de enteros. [`Array((U)Int*)`](/es/reference/data-types/array)

**Valor devuelto**

Devuelve un bitmap a partir del array proporcionado [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction)

**Ejemplos**

**Ejemplo de uso**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([1, 2, 3, 4, 5])) AS res, toTypeName(bitmapBuild([1, 2, 3, 4, 5])) AS type;
```

```response title=Response
┌─res────────────┬─type──────────────────────────────────┐
│ 00050102030405 │ AggregateFunction(groupBitmap, UInt8) │
└────────────────┴───────────────────────────────────────┘
```

**Bitmap con signo**

```sql title=Query
-- A bitmap is a binary value, so it is shown with `hex`.
SELECT hex(bitmapBuild([-128, -1]::Array(Int8))) AS res, toTypeName(bitmapBuild([-128, -1]::Array(Int8))) AS type;
```

```response title=Response
┌─res──────┬─type─────────────────────────────────┐
│ 000280FF │ AggregateFunction(groupBitmap, Int8) │
└──────────┴──────────────────────────────────────┘
```

<div id="bitmapContains">
  ## bitmapContains
</div>

Introducido en: v20.1.0

Comprueba si el bitmap contiene un elemento específico. El valor se compara como un entero sin signo del tipo de elemento del bitmap. En los bitmaps con signo, un elemento negativo coincide con su equivalente sin signo (por ejemplo, el valor `Int8` `-1` coincide con `255`).

**Sintaxis**

```sql
bitmapContains(bitmap, value)
```

**Argumentos**

* `bitmap` — Objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction). - `value` — Elemento cuya presencia se debe comprobar. [(U)Int8/16/32/64](/es/reference/data-types/int-uint)

**Valor devuelto**

Devuelve `1` si el bitmap contiene el valor especificado; de lo contrario, `0` [`UInt8`](/es/reference/data-types/int-uint)

**Ejemplos**

**Ejemplo de uso**

```sql title=Query
SELECT bitmapContains(bitmapBuild([1, 2, 3]), 2) AS res;
```

```response title=Response
┌─res─┐
│   1 │
└─────┘
```

**Bitmap con signo**

```sql title=Query
SELECT bitmapContains(bitmapBuild([-1]::Array(Int8)), 255) AS res;
```

```response title=Response
┌─res─┐
│   1 │
└─────┘
```

<div id="bitmapTransform">
  ## bitmapTransform
</div>

Introducido en: v20.1.0

Reemplaza elementos de un bitmap según una correspondencia entre `from_array` y `to_array`.
Los valores se interpretan como enteros sin signo del tipo de elemento del bitmap (el mismo dominio que [`bitmapContains`](/es/reference/functions/regular-functions/bitmap-functions#bitmapContains)).
En los bitmaps con signo, un elemento negativo coincide con su equivalente sin signo (por ejemplo, el valor `Int8` `-1` coincide con `255`).
Un valor de `to_array` que no cabe en el tipo de elemento del bitmap genera `BAD_ARGUMENTS`. Un valor de `from_array`
que no cabe simplemente no se encuentra, por lo que no se aplica el reemplazo correspondiente.

**Sintaxis**

```sql
bitmapTransform(bitmap, from_array, to_array)
```

**Argumentos**

* `bitmap` — Objeto bitmap. [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction). - `from_array` — Array de bits activados originales que se van a reemplazar. [`Array(T)`](/es/reference/data-types/array). - `to_array` — Array de nuevos bits activados con los que se realizará el reemplazo. [`Array(T)`](/es/reference/data-types/array).

**Valor devuelto**

Devuelve un bitmap cuyos elementos se transforman según el mapeo indicado [`AggregateFunction(groupBitmap, T)`](/es/reference/data-types/aggregatefunction)

**Ejemplos**

**Ejemplo de uso**

```sql title=Query
SELECT bitmapToArray(bitmapTransform(bitmapBuild([1, 2, 3, 4, 5]), [2, 4], [20, 40])) AS res;
```

```response title=Response
┌─res───────────┐
│ [1,3,5,20,40] │
└───────────────┘
```

**Bitmap con signo**

```sql title=Query
SELECT arraySort(bitmapToArray(bitmapTransform(bitmapBuild([-1, 0]::Array(Int8)), [255], [10]))) AS res;
```

```response title=Response
┌─res────┐
│ [0,10] │
└────────┘
```
