Crea una tabla [Merge](/es/reference/engines/table-engines/special/merge) temporal.
La estructura de la tabla se obtiene de las tablas subyacentes mediante la unión de sus columnas y la deducción de tipos comunes.
Están disponibles las mismas columnas virtuales que para el motor de tabla [Merge](/es/reference/engines/table-engines/special/merge).

## Sintaxis {#syntax}

```sql
merge(['db_name',] 'tables_regexp')
```

## Argumentos {#arguments}

| Argumento       | Descripción                                                                                                                                                                                                                                                                                                                                                            |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db_name`       | Valores posibles (opcional; el valor predeterminado es `currentDatabase()`):<br />    - nombre de la base de datos,<br />    - expresión constante que devuelve una cadena con un nombre de base de datos, por ejemplo, `currentDatabase()`,<br />    - `REGEXP(expression)`, donde `expression` es una expresión regular para que coincida con los nombres de las DB. |
| `tables_regexp` | Una expresión regular para que coincida con los nombres de las tablas en la DB o las DB especificadas.                                                                                                                                                                                                                                                                 |

## Derechos de acceso {#access-rights}

Las tablas coincidentes se leen con las mismas reglas de acceso que el motor de tabla [Merge](/es/reference/engines/table-engines/special/merge#access-rights). Los datos se leen únicamente de las tablas coincidentes que el usuario actual puede ver, es decir, aquellas sobre las que tiene el privilegio [`SHOW TABLES`](/es/reference/statements/grant#show), y el esquema de tabla se obtiene únicamente a partir de ellas. Las tablas coincidentes que el usuario no puede ver se omiten sin generar ningún error. Para obtener el esquema se requiere el privilegio [`SHOW COLUMNS`](/es/reference/statements/grant#show) sobre las tablas a partir de las que se obtiene. Para leer una tabla coincidente que el usuario puede ver se requiere el privilegio [`SELECT`](/es/reference/statements/grant#select) sobre las columnas que lee la consulta; de lo contrario, la consulta falla con `ACCESS_DENIED`.
