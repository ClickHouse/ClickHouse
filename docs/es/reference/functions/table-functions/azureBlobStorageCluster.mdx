Permite procesar archivos de [Azure Blob Storage](https://azure.microsoft.com/en-us/products/storage/blobs) en paralelo con muchos nodos de un clúster especificado. En el nodo iniciador, crea una conexión con todos los nodos del clúster, expande los asteriscos en la ruta del archivo de S3 y distribuye dinámicamente cada archivo. En el nodo worker, consulta al iniciador cuál es la siguiente tarea que debe procesar y la procesa. Esto se repite hasta que todas las tareas hayan finalizado.
Esta función de tabla es similar a la [función s3Cluster](/es/reference/functions/table-functions/s3Cluster).

## Sintaxis {#syntax}

<Tabs>
  <Tab title="Cadena de conexión">
    Las credenciales van integradas en la cadena de conexión, por lo que no es necesario indicar `account_name`/`account_key` por separado:

    ```sql
    azureBlobStorageCluster(cluster_name, connection_string, container_name, blobpath [, format, compression, structure])
    ```
  </Tab>

  <Tab title="URL de la cuenta de almacenamiento">
    Requiere `account_name` y `account_key` como argumentos independientes:

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, account_name, account_key [, format, compression, structure])
    ```
  </Tab>

  <Tab title="Workload Identity">
    Utiliza Azure Workload Identity mediante `extra_credentials`; es mutuamente excluyente con `account_name` / `account_key` y requiere `storage_account_url` (no `connection_string`):

    ```sql
    azureBlobStorageCluster(cluster_name, storage_account_url, container_name, blobpath, extra_credentials(client_id=, tenant_id=) [, format, compression, structure])
    ```

    Workload Identity utiliza la identity propia del servidor, por lo que se rechaza de forma predeterminada: active `allow_server_credentials_in_user_queries` en la sesión desde la que se ejecuta la consulta o en su perfil de configuración.
  </Tab>
</Tabs>

## Argumentos {#arguments}

| Argumento              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cluster_name`        | Nombre de un clúster que se utiliza para crear un conjunto de direcciones y parámetros de conexión a servidores remotos y locales.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `connection_string`   | Una cadena de conexión que incluye credenciales integradas (nombre de la cuenta + clave de la cuenta o token SAS). Si se usa esta opción, `account_name` y `account_key` **no** deben pasarse por separado, y no se pueden usar `client_id` / `tenant_id`. Consulte [Configurar una cadena de conexión](https://learn.microsoft.com/en-us/azure/storage/common/storage-configure-connection-string?toc=%2Fazure%2Fstorage%2Fblobs%2Ftoc.json\&bc=%2Fazure%2Fstorage%2Fblobs%2Fbreadcrumb%2Ftoc.json#configure-a-connection-string-for-an-azure-storage-account). |
| `storage_account_url` | La URL del punto de conexión de la cuenta de almacenamiento, p. ej., `https://<account>.blob.core.windows.net/`. Si se usa esta opción, pase `account_name` y `account_key`, o bien `extra_credentials(client_id=, tenant_id=)` para workload identity.                                                                                                                                                                                                                                                                                                          |
| `container_name`      | Nombre del contenedor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `blobpath`            | Ruta del archivo. Admite los siguientes comodines en modo de solo lectura: `*`, `**`, `?`, `{abc,def}` y `{N..M}`, donde `N`, `M` — números; `'abc'`, `'def'` — cadenas.                                                                                                                                                                                                                                                                                                                                                                                         |
| `account_name`        | Nombre de la cuenta de almacenamiento. **Obligatorio** al usar `storage_account_url` sin SAS ni workload identity; **no** debe pasarse junto con `connection_string` ni `extra_credentials`.                                                                                                                                                                                                                                                                                                                                                                     |
| `account_key`         | Clave de la cuenta de almacenamiento. **Obligatorio** al usar `storage_account_url` sin SAS ni workload identity; **no** debe pasarse junto con `connection_string` ni `extra_credentials`.                                                                                                                                                                                                                                                                                                                                                                      |
| `format`              | El [formato](/es/reference/formats/index) del archivo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `compression`         | Valores admitidos: `none`, `gzip/gz`, `deflate`, `brotli/br`, `xz/LZMA`, `zstd/zst`, `lz4`, `bz2`, `snappy`. De forma predeterminada, la compresión se detecta automáticamente por la extensión del archivo. (equivale a establecer `auto`). Para `snappy`, el formato de transmisión se selecciona mediante la configuración [snappy&#95;mode](/es/reference/settings/session-settings/other#snappy_mode) (`basic` de forma predeterminada).                                                                                                                       |
| `structure`           | Estructura de la tabla. Formato: `'column1_name column1_type, column2_name column2_type, ...'`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `extra_credentials`   | Use `client_id` y `tenant_id` para la autenticación con workload identity de Azure. Es mutuamente excluyente con `account_name` / `account_key` y requiere `storage_account_url` (no `connection_string`). Todos los nodos del clúster deben tener definida la variable `AZURE_FEDERATED_TOKEN_FILE`.                                                                                                                                                                                                                                                            |

## Valor devuelto {#returned-value}

Una tabla con la estructura especificada para leer o escribir datos en el archivo indicado.

## Ejemplos {#examples}

Al igual que con el motor de tabla [AzureBlobStorage](/es/reference/engines/table-engines/integrations/azureBlobStorage), se puede usar el emulador Azurite para el desarrollo local de Azure Storage. Más detalles [aquí](https://learn.microsoft.com/en-us/azure/storage/common/storage-use-azurite?tabs=docker-hub%2Cblob-storage). A continuación, asumimos que Azurite está disponible en el nombre de host `azurite1`.

Seleccione el recuento del archivo `test_cluster_*.csv` usando todos los nodos del clúster `cluster_simple`:

```sql
SELECT count(*) FROM azureBlobStorageCluster(
        'cluster_simple', 'http://azurite1:10000/devstoreaccount1', 'testcontainer', 'test_cluster_count.csv', 'devstoreaccount1',
        'Eby8vdM02xNOcqFlqUwJPLlmEtlCDXJ1OUzFT50uSRZ6IFsuFq2UVErCz4I6tq/K1SZFPTOtr/KBHBeksoGMGw==', 'CSV',
        'auto', 'key UInt64')
```
