Lee series temporales de una tabla TimeSeries, filtradas por un selector y con marcas de tiempo dentro de un intervalo especificado.
Esta función es similar a los [selectores de rango](https://prometheus.io/docs/prometheus/latest/querying/basics/#range-vector-selectors), pero también se utiliza para implementar [selectores instantáneos](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors).

## Sintaxis {#syntax}

```sql
timeSeriesSelector('db_name', 'time_series_table', 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector(db_name.time_series_table, 'instant_query', min_time, max_time, return_columns)
timeSeriesSelector('time_series_table', 'instant_query', min_time, max_time, return_columns)
```

## Argumentos {#arguments}

* `db_name` - El nombre de la base de datos donde se encuentra la tabla TimeSeries.
* `time_series_table` - El nombre de una tabla TimeSeries.
* `instant_query` - Un selector instantáneo escrito en [sintaxis PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/#instant-vector-selectors), sin los modificadores `@` ni `offset`.
* `min_time` - Marca de tiempo de inicio, inclusiva.
* `max_time` - Marca de tiempo de fin, inclusiva.
* `return_columns` - Las columnas en las que se devuelven las muestras: `'samples'` o `'timestamp_and_value'`; consulte más abajo.

`min_time` y `max_time` pueden incluir fracciones de segundo aunque las marcas de tiempo de la tabla estén expresadas en segundos enteros:
la función selecciona exactamente las muestras que cumplen `min_time <= timestamp <= max_time`, sin redondear los límites al tipo de las marcas de tiempo.

## Valor devuelto {#returned-value}

La función devuelve la columna `id` con los identificadores de las series temporales que coinciden con el selector especificado, y las muestras
en las columnas elegidas mediante el argumento `return_columns`:

* `'samples'`: la columna `samples` con las muestras de una serie temporal como un array de tuplas `(timestamp, value)` ordenado por marca de tiempo.
  Las muestras de una serie temporal pueden devolverse en varias filas, por ejemplo, una fila por cada intervalo de tiempo de la tabla de muestras.
  Utilice la función de agregación `timeSeriesGroupArray` para fusionar las filas de una serie temporal.
* `'timestamp_and_value'`: las columnas `timestamp` y `value`, con una muestra por fila.

Una tabla `TimeSeries` de la versión 11 o posterior almacena las muestras agrupadas en cubetas como matrices, mientras que las tablas de versiones anteriores almacenan una muestra por fila.
Cuando las columnas solicitadas no coinciden con la disposición de la tabla, las muestras se convierten, lo que lleva cierto tiempo; las funciones de PromQL
solicitan las columnas que coinciden con la disposición de la tabla.

Los datos devueltos no siguen ningún orden específico.

## Ejemplos {#examples}

```sql
SELECT id, timeSeriesGroupArray(samples) AS samples
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'samples')
GROUP BY id
```

```sql
SELECT id, timestamp, value
FROM timeSeriesSelector(mytable, 'http_requests{job="prometheus"}', now() - INTERVAL 10 MINUTES, now(), 'timestamp_and_value')
```
