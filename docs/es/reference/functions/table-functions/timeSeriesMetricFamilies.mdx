`timeSeriesMetricFamilies(db_name.time_series_table)` - Devuelve la tabla de [metric families](/es/reference/engines/table-engines/integrations/time-series#metric-families-table)
utilizada por la tabla `db_name.time_series_table`, cuyo motor de tabla es el motor [TimeSeries](/es/reference/engines/table-engines/integrations/time-series):

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES metric_families_table
```

La función también funciona si la tabla de *familias de métricas* es la interna:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries METRIC FAMILIES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

Las siguientes queries son equivalentes:

```sql
SELECT * FROM timeSeriesMetricFamilies(db_name.time_series_table);
SELECT * FROM timeSeriesMetricFamilies('db_name.time_series_table');
SELECT * FROM timeSeriesMetricFamilies('db_name', 'time_series_table');
```

<Note>
  La función `timeSeriesMetricFamilies` tiene un alias, `timeSeriesMetrics`, que se mantiene por compatibilidad con versiones anteriores.
</Note>
