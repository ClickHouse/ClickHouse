Evalúa una consulta de Prometheus con datos de una tabla TimeSeries en un intervalo de tiempos de evaluación.

## Sintaxis {#syntax}

```sql
prometheusQueryRange('db_name', 'time_series_table', 'promql_query', start_time, end_time, step)
prometheusQueryRange(db_name.time_series_table, 'promql_query', start_time, end_time, step)
prometheusQueryRange('time_series_table', 'promql_query', start_time, end_time, step)
```

## Argumentos {#arguments}

* `db_name` - El nombre de la base de datos donde se encuentra la tabla TimeSeries.
* `time_series_table` - El nombre de una tabla TimeSeries.
* `promql_query` - Una consulta escrita en [sintaxis PromQL](https://prometheus.io/docs/prometheus/latest/querying/basics/).
* `start_time` - La hora de inicio del intervalo de evaluación, con una precisión de milisegundos o mayor.
* `end_time` - La hora de finalización del intervalo de evaluación, con una precisión de milisegundos o mayor.
* `step` - El paso utilizado para iterar el tiempo de evaluación desde `start_time` hasta `end_time` (ambos inclusive).

## Valor devuelto {#returned-value}

La función devuelve distintas columnas según el tipo de resultado de la consulta que se pasa en el parámetro `promql_query`:

| Tipo de resultado | Columnas del resultado                                                              | Ejemplo                                             |
| ----------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| vector            | tags Array(Tuple(String, String)), timestamp DateTime64(S, TZ), value Float64       | prometheusQuery(mytable, &#39;up&#39;)              |
| matrix            | tags Array(Tuple(String, String)), samples Array(Tuple(DateTime64(S, TZ), Float64)) | prometheusQuery(mytable, &#39;up[1m]&#39;)          |
| scalar            | timestamp DateTime64(S, TZ), value Float64                                          | prometheusQuery(mytable, &#39;1h30m&#39;)           |
| string            | timestamp DateTime64(S, TZ), value String                                           | prometheusQuery(mytable, &#39;&quot;abc&quot;&#39;) |

Los valores son siempre de tipo `Float64`, independientemente del tipo de los valores de la tabla TimeSeries. La escala `S` de las marcas de tiempo coincide con la escala
de las marcas de tiempo de la tabla, pero es como mínimo 3 (milisegundos). La zona horaria `TZ` es la de `start_time` y `end_time`
si ambos son de tipo `DateTime` o `DateTime64` y tienen la misma zona horaria; de lo contrario, es la zona horaria de las marcas de tiempo de la tabla.

La columna `samples` se denomina `time_series` si la tabla `TimeSeries` tiene la [versión](/es/reference/engines/table-engines/integrations/time-series#schema-versioning) 2 o una anterior.

## Características de PromQL compatibles {#supported-promql-features}

### Selectores {#selectors}

Selectores instantáneos, selectores de rango, comparadores de etiquetas (`=`, `!=`, `=~`, `!~`), modificadores `offset`, modificadores de marca temporal `@` y subconsultas.

### Funciones {#functions}

| Categoría     | Funciones                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Rango         | `rate`, `irate`, `delta`, `idelta`, `increase`, `last_over_time`, `first_over_time`, `sum_over_time`, `avg_over_time`, `count_over_time`, `max_over_time`, `min_over_time`, `ts_of_max_over_time`, `ts_of_min_over_time`, `ts_of_last_over_time`, `ts_of_first_over_time`, `deriv`, `changes`, `resets`, `present_over_time`, `absent_over_time`, `quantile_over_time`, `stddev_over_time`, `stdvar_over_time`, `mad_over_time`, `predict_linear` |
| Matemáticas   | `abs`, `sgn`, `floor`, `ceil`, `sqrt`, `exp`, `ln`, `log2`, `log10`, `rad`, `deg`, `round`, `clamp`, `clamp_min`, `clamp_max`, `min_of`, `max_of`                                                                                                                                                                                                                                                                                                 |
| Trigonometría | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh`                                                                                                                                                                                                                                                                                                                                                    |
| DateTime      | `day_of_week`, `day_of_month`, `days_in_month`, `day_of_year`, `minute`, `hour`, `month`, `year`                                                                                                                                                                                                                                                                                                                                                  |
| Etiqueta      | `label_replace`, `label_join`                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Tipo          | `scalar`, `vector`                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Histograma    | `histogram_quantile`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Otros         | `time`, `pi`, `absent`, `timestamp`                                                                                                                                                                                                                                                                                                                                                                                                               |

**Nota**: `histogram_quantile` usa interpolación lineal en los buckets de histogramas clásicos (identificados por la etiqueta `le`). Los histogramas nativos no son compatibles. El argumento `phi` (nivel de cuantil) debe ser un escalar constante. Las expresiones que varían en cada paso, como `histogram_quantile(time() / 1000, ...)`, se rechazan con una excepción `NOT_IMPLEMENTED`.

**Nota**: `min_of(a, b)` y `max_of(a, b)` devuelven, respectivamente, el menor o el mayor de dos valores escalares. Ambos argumentos deben ser escalares.

**Nota**: `min_of`, `max_of`, `ts_of_min_over_time`, `ts_of_max_over_time`, `ts_of_last_over_time`, `first_over_time`, `ts_of_first_over_time` y `mad_over_time` son funciones experimentales en Prometheus (habilitadas allí con `--enable-feature=promql-experimental-functions`); ClickHouse las evalúa sin requerir ese indicador.

### Operadores {#operators}

Operadores binarios aritméticos (`+`, `-`, `*`, `/`, `%`, `^`, `atan2`) y de comparación (`==`, `!=`, `<`, `>`, `<=`, `>=` con `bool` opcional), junto con los modificadores `on()`/`ignoring()` y `group_left()`/`group_right()`.

Operadores lógicos de conjuntos `and`, `or` y `unless`, con modificadores `on()`/`ignoring()`.

Operadores unarios `+` y `-`.

### Operadores de agregación {#aggregation-operators}

`sum`, `avg`, `min`, `max`, `count`, `count_values`, `stddev`, `stdvar`, `group`, `quantile`, `topk`, `bottomk`, `limitk` — con los modificadores opcionales `by()` o `without()`.

## Ejemplo {#example}

```sql
SELECT * FROM prometheusQueryRange(mytable, 'rate(http_requests{job="prometheus"}[10m])[1h:10m]', now() - INTERVAL 10 MINUTES, now(), INTERVAL 1 MINUTE)
```
