`timeSeriesTimeRanges(db_name.time_series_table)` - Devuelve la tabla de [intervalos de tiempo](/es/reference/engines/table-engines/integrations/time-series#time-ranges-table)
que utiliza la tabla `db_name.time_series_table`, cuyo motor de tabla es [TimeSeries](/es/reference/engines/table-engines/integrations/time-series), por ejemplo:

```sql
CREATE TABLE db_name.time_series_table ENGINE=TimeSeries TIME RANGES INNER UUID '01234567-89ab-cdef-0123-456789abcdef'
```

Las siguientes consultas son equivalentes:

```sql
SELECT * FROM timeSeriesTimeRanges(db_name.time_series_table);
SELECT * FROM timeSeriesTimeRanges('db_name.time_series_table');
SELECT * FROM timeSeriesTimeRanges('db_name', 'time_series_table');
```

<Note>
  La tabla *time ranges* existe si el parámetro de configuración `store_time_ranges` está habilitado.
  Las tablas de la [versión](/es/reference/engines/table-engines/integrations/time-series#schema-versioning) 7 o anteriores mantienen las columnas `min_time` y `max_time`
  en la tabla de [etiquetas](/es/reference/engines/table-engines/integrations/time-series#tags-table).
</Note>
