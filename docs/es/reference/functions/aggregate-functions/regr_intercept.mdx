## regr_intercept {#regr_intercept}

Introducido en: v26.9.0

Devuelve la ordenada en el origen del ajuste por mínimos cuadrados de `y` sobre `x`:

$$
\bar{y} - slope \cdot \bar{x}
$$

Devuelve `nan` cuando `x` es constante, ya que la recta ajustada es vertical.

**Sintaxis**

```sql
regr_intercept(y, x)
```

**Alias**: `regrIntercept`

**Argumentos**

* `y` — Variable dependiente. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float)
* `x` — Variable independiente. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float)

**Valor devuelto**

Devuelve la ordenada en el origen de la recta de regresión. [`Float64`](/es/reference/data-types/float)

**Ejemplos**

**Uso básico**

```sql title=Query
SELECT regr_intercept(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_intercept(y, x)─┐
│                    0 │
└──────────────────────┘
```
