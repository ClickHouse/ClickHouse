<div id="argAndMax">
  ## argAndMax
</div>

Introducido en: v1.1.0

Calcula los valores `arg` y `val` correspondientes al valor máximo de `val`.
Si hay varias filas con el mismo `val` máximo, no es determinista cuál de los `arg` y `val` asociados se devuelve.
Tanto `arg` como `max` se comportan como [funciones de agregado](/es/reference/functions/aggregate-functions/index): ambos [omiten `Null`](/es/reference/functions/aggregate-functions/index#null-processing) durante el procesamiento y devuelven valores distintos de `Null` si hay valores distintos de `Null` disponibles.

<Note>
  La única diferencia con `argMax` es que `argAndMax` devuelve tanto el argumento como el valor.
</Note>

**Ver también**

* [argMax](/es/reference/functions/aggregate-functions/argMax)
* [Tuple](/es/reference/data-types/tuple)

**Sintaxis**

```sql
argAndMax(arg, val)
```

**Argumentos**

* `arg` — Argumento del que se debe encontrar el valor máximo. [`const String`](/es/reference/data-types/string)
* `val` — El valor máximo. [`(U)Int8/16/32/64`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float) o [`Date`](/es/reference/data-types/date) o [`DateTime`](/es/reference/data-types/datetime) o [`Tuple`](/es/reference/data-types/tuple)

**Valor devuelto**

Devuelve una tupla que contiene el valor de `arg` correspondiente al valor máximo de `val` y el valor máximo de `val`. [`Tuple`](/es/reference/data-types/tuple)

**Ejemplos**

**Uso básico**

```sql title=Query
CREATE TABLE salary
(
    user String,
    salary UInt32
)
ENGINE = Memory AS
SELECT *
FROM VALUES(('worker', 1000), ('manager', 3000), ('director', 5000));

SELECT argAndMax(user, salary) FROM salary;
```

```response title=Response
┌─argAndMax(user, salary)─┐
│ ('director',5000)       │
└─────────────────────────┘
```

**Ejemplo ampliado con tratamiento de NULL**

```sql title=Query
CREATE TABLE test
(
    a Nullable(String),
    b Nullable(Int64)
)
ENGINE = Memory AS
SELECT *
FROM VALUES(('a', 1), ('b', 2), ('c', 2), (NULL, 3), (NULL, NULL), ('d', NULL));

SELECT argMax(a, b), argAndMax(a, b), max(b) FROM test;
```

```response title=Response
┌─argMax(a, b)─┬─argAndMax(a, b)─┬─max(b)─┐
│ b            │ ('b',2)         │      3 │
└──────────────┴─────────────────┴────────┘
```

**Uso de Tuple en los argumentos**

```sql title=Query
SELECT argAndMax(a, (b,a)) FROM test;
```

```response title=Response
┌─argAndMax(a, (b, a))─┐
│ ('c',(2,'c'))        │
└──────────────────────┘
```
