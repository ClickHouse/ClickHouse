## regr_slope {#regr_slope}

Introducido en: v26.9.0

Devuelve la pendiente del ajuste por mínimos cuadrados de `y` sobre `x`:

$$
\frac{\Sigma{(x - \bar{x})(y - \bar{y})}}{\Sigma{(x - \bar{x})^2}}
$$

Devuelve `nan` cuando `x` es constante, porque la recta ajustada es vertical.

**Sintaxis**

```sql
regr_slope(y, x)
```

**Alias**: `regrSlope`

**Argumentos**

- `y` — Variable dependiente. [`(U)Int*`](/reference/data-types/int-uint) o [`Float*`](/reference/data-types/float)
- `x` — Variable independiente. [`(U)Int*`](/reference/data-types/int-uint) o [`Float*`](/reference/data-types/float)

**Valor devuelto**

Devuelve la pendiente de la recta de regresión. [`Float64`](/reference/data-types/float)

**Ejemplos**

**Uso básico**

```sql title=Consulta
SELECT regr_slope(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Respuesta
┌─regr_slope(y, x)─┐
│                2 │
└──────────────────┘
```
