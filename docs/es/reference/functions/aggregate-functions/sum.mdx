## sum {#sum}

Introducida en: v1.1.0

Calcula la suma de valores numéricos o de intervalos.

**Sintaxis**

```sql
sum(num)
```

**Argumentos**

* `num` — Columna de valores numéricos o de intervalos. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float) o [`Decimal*`](/es/reference/data-types/decimal) o [`Interval`](/es/reference/data-types/special-data-types/interval)

**Valor devuelto**

Devuelve la suma de los valores. Si el argumento es de tipo `Interval`, el resultado es un intervalo expresado en la misma unidad, y si la entrada está vacía, se devuelve un intervalo de longitud cero. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float) o [`Decimal*`](/es/reference/data-types/decimal) o [`Interval`](/es/reference/data-types/special-data-types/interval)

**Ejemplos**

**Cálculo de la suma de los salarios de los empleados**

```sql title=Query
CREATE TABLE employees
(
    id UInt32,
    name String,
    salary UInt32
)
ENGINE = Memory;

INSERT INTO employees VALUES
    (87432, 'John Smith', 45680),
    (59018, 'Jane Smith', 72350),
    (20376, 'Ivan Ivanovich', 58900),
    (71245, 'Anastasia Ivanovna', 89210);

SELECT sum(salary) FROM employees;
```

```response title=Response
┌─sum(salary)─┐
│      266140 │
└─────────────┘
```

**Tiempo total dedicado a las solicitudes**

```sql title=Query
CREATE TABLE requests
(
    req_id UInt32,
    duration IntervalMillisecond
)
ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT sum(duration) AS total_duration, toTypeName(total_duration) FROM requests;
```

```response title=Response
┌─total_duration─┬─toTypeName(total_duration)─┐
│            600 │ IntervalMillisecond        │
└────────────────┴────────────────────────────┘
```
