## avg {#avg}

Introducido en: v1.1.0

Calcula la media aritmética.

**Sintaxis**

```sql
avg(x)
```

**Argumentos**

* `x` — Valores de entrada. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float) o [`Decimal`](/es/reference/data-types/decimal) o [`Date`](/es/reference/data-types/date) o [`Date32`](/es/reference/data-types/date32) o [`DateTime`](/es/reference/data-types/datetime) o [`DateTime64(P)`](/es/reference/data-types/datetime64) o [`Time`](/es/reference/data-types/time) o [`Time64(P)`](/es/reference/data-types/time64) o [`Interval`](/es/reference/data-types/special-data-types/interval)

**Valor devuelto**

Devuelve la media aritmética. Si `x` contiene valores numéricos, el resultado es un `Float64`; si está vacío, devuelve `NaN`. Si `x` contiene fechas, horas o intervalos, el resultado conserva el tipo de `x`: la media se redondea al valor representable más cercano y, si `x` está vacío, se devuelve el valor cero de ese tipo. [`Float64`](/es/reference/data-types/float) o [`Date`](/es/reference/data-types/date) o [`Date32`](/es/reference/data-types/date32) o [`DateTime`](/es/reference/data-types/datetime) o [`DateTime64(P)`](/es/reference/data-types/datetime64) o [`Time`](/es/reference/data-types/time) o [`Time64(P)`](/es/reference/data-types/time64) o [`Interval`](/es/reference/data-types/special-data-types/interval)

**Ejemplos**

**Uso básico**

```sql title=Query
SELECT avg(x) FROM VALUES('x Int8', 0, 1, 2, 3, 4, 5);
```

```response title=Response
┌─avg(x)─┐
│    2.5 │
└────────┘
```

**Una tabla vacía devuelve NaN**

```sql title=Query
CREATE TABLE test (t UInt8) ENGINE = Memory;

SELECT avg(t) FROM test;
```

```response title=Response
┌─avg(t)─┐
│    nan │
└────────┘
```

**Promedio de un intervalo**

```sql title=Query
CREATE TABLE requests (req_id Int64, duration IntervalMillisecond) ENGINE = Memory;

INSERT INTO requests VALUES (1, 100), (2, 200), (3, 300);

SELECT avg(duration) AS avg_duration, toTypeName(avg_duration) FROM requests;
```

```response title=Response
┌─avg_duration─┬─toTypeName(avg_duration)─┐
│          200 │ IntervalMillisecond      │
└──────────────┴──────────────────────────┘
```
