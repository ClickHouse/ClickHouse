## timeSeriesBottomKMasks {#timeSeriesBottomKMasks}

Introducido en: v26.8.0

Selecciona las series temporales con los k valores más pequeños en cada paso de una cuadrícula temporal.

Cada fila de entrada es una serie temporal: `key` identifica la serie y `values` contiene sus valores alineados con una cuadrícula
temporal común, por lo que los arrays `values` de todas las filas deben tener el mismo tamaño. En cada paso temporal, se seleccionan las series con los k valores
no NULL más pequeños en ese paso (NaN se considera mayor que cualquier otro valor). En caso de empate, se da preferencia
a la serie con el valor de `key` más pequeño.

Esta función implementa el operador de agregación `bottomk()` de PromQL y mantiene un único heap acotado de tamaño `k` por
paso temporal, de modo que el tamaño de su estado no depende del número de series agregadas.

<Note>
  Esta función está en vista previa privada; para habilitarla, establezca `enable_time_series_aggregate_functions = 1`.
</Note>

**Sintaxis**

```sql
timeSeriesBottomKMasks(k, key, values)
```

**Argumentos**

* `k` — Número de series que se seleccionan en cada paso de tiempo: un único valor para todos los pasos de tiempo o un array con un valor por paso de tiempo. Debe ser el mismo para todas las filas. [`UInt*`](/es/reference/data-types/int-uint) o [`Array(UInt*)`](/es/reference/data-types/array)
* `key` — Identificador de la serie temporal. [`UInt64`](/es/reference/data-types/int-uint)
* `values` — Valores de la serie temporal alineados con la cuadrícula temporal, con un elemento por paso de tiempo. [`Array(Nullable(Float32))`](/es/reference/data-types/array) o [`Array(Nullable(Float64))`](/es/reference/data-types/array) o [`Array(Float32)`](/es/reference/data-types/array) o [`Array(Float64)`](/es/reference/data-types/array)

**Valor devuelto**

Devuelve las series seleccionadas en orden ascendente de `key`, cada una con su máscara por paso: `steps_mask[t] = 1` si la serie se selecciona en el paso de tiempo `t`. No se devuelven las series que no se seleccionan en ningún paso de tiempo. [`Array(Tuple(key UInt64, steps_mask Array(UInt8)))`](/es/reference/data-types/array)

**Ejemplos**

**Selección de las 2 series más pequeñas en cada paso de tiempo**

```sql title=Query
SET enable_time_series_aggregate_functions = 1;
WITH [(1, [10., 1., NULL]), (2, [20., 2., 2.]), (3, [30., NULL, 1.])]::Array(Tuple(UInt64, Array(Nullable(Float64)))) AS series
SELECT timeSeriesBottomKMasks(2, s.1, s.2)
FROM (SELECT arrayJoin(series) AS s);
```

```response title=Response
[(1,[1,1,0]),(2,[1,1,1]),(3,[0,0,1])]
```
