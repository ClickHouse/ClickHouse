## regr_sxy {#regr_sxy}

Introducido en: v26.9.0

Devuelve la suma de los productos de las dos variables:

$$
\Sigma{(x - \bar{x})(y - \bar{y})}
$$

**Sintaxis**

```sql
regr_sxy(y, x)
```

**Alias**: `regrSXY`

**Argumentos**

- `y` — Variable dependiente. [`(U)Int*`](/reference/data-types/int-uint) o [`Float*`](/reference/data-types/float)
- `x` — Variable independiente. [`(U)Int*`](/reference/data-types/int-uint) o [`Float*`](/reference/data-types/float)

**Valor devuelto**

Devuelve la suma de los productos de las desviaciones de `x` e `y` respecto a sus medias. [`Float64`](/reference/data-types/float)

**Ejemplos**

**Uso básico**

```sql title=Consulta
SELECT regr_sxy(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Respuesta
┌─regr_sxy(y, x)─┐
│             10 │
└────────────────┘
```
