## regr_r2 {#regr_r2}

Introducido en: v26.9.0

Devuelve el coeficiente de determinación del ajuste por mínimos cuadrados, es decir, el cuadrado del
coeficiente de correlación. Devuelve `nan` cuando `x` es constante y `1` cuando `y` es constante.

**Sintaxis**

```sql
regr_r2(y, x)
```

**Alias**: `regrR2`

**Argumentos**

* `y` — Variable dependiente. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float)
* `x` — Variable independiente. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float)

**Valor devuelto**

Devuelve un valor entre 0 y 1. [`Float64`](/es/reference/data-types/float)

**Ejemplos**

**Uso básico**

```sql title=Query
SELECT regr_r2(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_r2(y, x)─┐
│             1 │
└───────────────┘
```
