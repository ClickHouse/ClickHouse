## regr_avgx {#regr_avgx}

Introducido en: v26.9.0

Devuelve la media de la variable independiente.

Se calcula en torno a un valor de los datos y no en torno a cero, por lo que, en una columna de tipo integer que supere
2^53, puede acercarse más a la media exacta que [`avg`](/es/reference/functions/aggregate-functions/avg),
que divide una suma de tipo `Float64`.

**Sintaxis**

```sql
regr_avgx(y, x)
```

**Alias**: `regrAvgX`

**Argumentos**

* `y` — Variable dependiente. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float)
* `x` — Variable independiente. [`(U)Int*`](/es/reference/data-types/int-uint) o [`Float*`](/es/reference/data-types/float)

**Valor devuelto**

Devuelve la media de `x`. [`Float64`](/es/reference/data-types/float)

**Ejemplos**

**Uso básico**

```sql title=Query
SELECT regr_avgx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Response
┌─regr_avgx(y, x)─┐
│             2.5 │
└─────────────────┘
```
