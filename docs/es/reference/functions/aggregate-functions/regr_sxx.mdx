## regr_sxx {#regr_sxx}

Introducido en: v26.9.0

Devuelve la suma de cuadrados de la variable independiente:

$$
\Sigma{(x - \bar{x})^2}
$$

**Sintaxis**

```sql
regr_sxx(y, x)
```

**Alias**: `regrSXX`

**Argumentos**

- `y` — Variable dependiente. [`(U)Int*`](/reference/data-types/int-uint) o [`Float*`](/reference/data-types/float)
- `x` — Variable independiente. [`(U)Int*`](/reference/data-types/int-uint) o [`Float*`](/reference/data-types/float)

**Valor devuelto**

Devuelve la suma de cuadrados de `x` respecto a su media. [`Float64`](/reference/data-types/float)

**Ejemplos**

**Uso básico**

```sql title=Consulta
SELECT regr_sxx(y, x)
FROM VALUES('x Float64, y Float64', (1, 2), (2, 4), (3, 6), (4, 8))
```

```response title=Respuesta
┌─regr_sxx(y, x)─┐
│              5 │
└────────────────┘
```
