El motor de tabla GenerateRandom produce datos aleatorios para el esquema de tabla dado.

Ejemplos de uso:

* Úselo en pruebas para rellenar una tabla grande de forma reproducible.
* Genere entradas aleatorias para pruebas de fuzzing.

## Uso en el servidor de ClickHouse {#usage-in-clickhouse-server}

```sql
ENGINE = GenerateRandom([random_seed [,max_string_length [,max_array_length]]])
[SETTINGS null_ratio = ..., max_json_depth = ..., max_json_keys_per_object = ...]
```

Los parámetros `max_array_length` y `max_string_length` especifican la longitud máxima de todas
las columnas de tipo array o mapa y de las cadenas, respectivamente, en los datos generados.

La cláusula `SETTINGS` controla cómo se generan los valores `Nullable`, `Variant`, `Dynamic` y `JSON`:
`null_ratio` (valor predeterminado `0.0625`) es la probabilidad de que un valor sea `NULL` y la probabilidad base
de que una clave `JSON` no aparezca en una fila (una minoría de claves dispersas se omiten con una frecuencia varias veces
mayor); `max_json_depth` (valor predeterminado `3`) limita la profundidad de anidamiento de los objetos `JSON` generados,
y `max_json_keys_per_object` (valor predeterminado `8`) limita el número de claves generadas en cada nivel de un
objeto. La función de tabla [`generateRandom`](/es/reference/functions/table-functions/generate) admite
la misma configuración.

El motor de tabla Generate solo admite consultas `SELECT`.

Admite todos los [DataTypes](/es/reference/data-types/index) que pueden almacenarse en una tabla,
excepto `AggregateFunction`, `Interval`, `Nothing` y `QBit`.

## Ejemplo {#example}

**1.** Configure la tabla `generate_engine_table`:

```sql
CREATE TABLE generate_engine_table (name String, value UInt32) ENGINE = GenerateRandom(1, 5, 3)
```

**2.** Consulta los datos:

```sql
SELECT * FROM generate_engine_table LIMIT 3
```

```text
┌─name─┬──────value─┐
│ c4xJ │ 1412771199 │
│ r    │ 1791099446 │
│ 7#$  │  124312908 │
└──────┴────────────┘
```

## Detalles de la implementación {#details-of-implementation}

* No es compatible:
  * `ALTER`
  * `SELECT ... SAMPLE`
  * `INSERT`
  * Índices
  * Replicación
