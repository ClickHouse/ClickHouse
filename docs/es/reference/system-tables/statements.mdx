## Descripción {#description}

Contiene una lista de todas las sentencias SQL de ClickHouse.

## Columnas {#columns}

* `name` ([String](/es/reference/data-types/string)) — El nombre de la sentencia SQL.
* `syntax` ([String](/es/reference/data-types/string)) — La sintaxis de la sentencia.
* `description` ([String](/es/reference/data-types/string)) — Una descripción de lo que hace la sentencia, con ejemplos de uso.
* `parent_name` ([String](/es/reference/data-types/string)) — El nombre de la sentencia que la contiene; por ejemplo, SELECT para la cláusula WHERE. Está vacío para una sentencia de nivel superior.
* `related` ([Array(String)](/es/reference/data-types/array)) — Los nombres de las sentencias relacionadas.
