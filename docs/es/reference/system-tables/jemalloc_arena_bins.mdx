## Description {#description}

Igual que `system.jemalloc_bins`, pero con una fila por (arena, bin) en lugar de agregar los datos de todas las arenas. Los slabs pertenecen a una sola arena, por lo que esta tabla ubica la fragmentación en una arena concreta (incluidas las arenas dedicadas a los metadatos de MergeTree, al JIT y a la caché) y se une a `system.jemalloc_sampled_allocations` tanto por `arena` como por size class.

## Columnas {#columns}

{/*AUTOGENERATED_START*/}

* `arena` ([UInt32](/es/reference/data-types/int-uint)) — Índice de la arena. Se une a `system.jemalloc_sampled_allocations.arena`.
* `purpose` ([String](/es/reference/data-types/string)) — Propósito de una arena dedicada de larga duración: &#39;mergetree&#39; (metadato de parts y tablas), &#39;jit&#39;, &#39;cache&#39;. Vacío para las arenas de propósito general. Las arenas dedicadas mantienen, por diseño, allocations de larga duración; los informes de fragmentación suelen excluirlas.
* `index` ([UInt16](/es/reference/data-types/int-uint)) — Índice del bin ordenado por tamaño.
* `large` ([UInt8](/es/reference/data-types/int-uint)) — True para allocations grandes y False para pequeñas.
* `size` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de las allocations de este bin.
* `allocations` ([Int64](/es/reference/data-types/int-uint)) — Número de allocations.
* `deallocations` ([Int64](/es/reference/data-types/int-uint)) — Número de deallocations.
* `nregs` ([Int64](/es/reference/data-types/int-uint)) — Número de regiones por slab.
* `curslabs` ([Int64](/es/reference/data-types/int-uint)) — Número actual de slabs.
* `curregs` ([Int64](/es/reference/data-types/int-uint)) — Número actual de regiones de esta size class.
* `slab_size` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de cada slab en bytes. Cero para las size classes grandes, que no se basan en slabs.
* `nonfull_slabs` ([Int64](/es/reference/data-types/int-uint)) — Número actual de slabs que contienen al menos una región libre. Cero para las size classes grandes.

**Aliases:**

* `availregs` — Alias de `nregs * curslabs`.
* `util` — Alias de `curregs / availregs`.
* `waste` — Alias de `greatest((curslabs * slab_size) - (curregs * size), 0)`.
