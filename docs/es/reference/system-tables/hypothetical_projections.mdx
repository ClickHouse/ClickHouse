Enumera todas las proyecciones hipotéticas (what-if) definidas en la sesión actual. Consulte [`CREATE HYPOTHETICAL PROJECTION`](/es/reference/statements/hypothetical-projection#create-hypothetical-projection) y [`EXPLAIN WHATIF`](/es/reference/statements/explain#explain-whatif).

El contenido tiene ámbito de sesión: cada conexión ve únicamente sus propias proyecciones hipotéticas, y la tabla está vacía si no se ha creado ninguna en la sesión actual.

Los valores actuales de `(database, table)` se resuelven por UUID en el momento de la consulta, por lo que reflejan `RENAME TABLE` y las entradas de tablas eliminadas se ocultan automáticamente.

## Columnas {#columns}

{/*AUTOGENERATED_START*/}

* `database` ([String](/es/reference/data-types/string)) — Nombre de la base de datos
* `table` ([String](/es/reference/data-types/string)) — Nombre de la tabla
* `name` ([String](/es/reference/data-types/string)) — Nombre de la proyección
* `type` ([Enum8(&#39;Normal&#39; = 0, &#39;Aggregate&#39; = 1)](/es/reference/data-types/enum)) — Tipo de proyección
* `sorting_key` ([Array(String)](/es/reference/data-types/array)) — Clave de ordenación de la proyección
* `query` ([String](/es/reference/data-types/string)) — Consulta SELECT de la proyección; vacía en el caso de la forma INDEX ... TYPE ...
* `definition` ([String](/es/reference/data-types/string)) — Declaración completa de la proyección tal como se escribió
* `settings` ([Map(String, String)](/es/reference/data-types/map)) — Configuración de la proyección definida en WITH SETTINGS

{/*AUTOGENERATED_END*/}

**Ejemplo**

```sql
CREATE HYPOTHETICAL PROJECTION p_by_b ON t (SELECT a, b ORDER BY b);
SELECT name, type, sorting_key FROM system.hypothetical_projections;
```

```text
┌─name───┬─type───┬─sorting_key─┐
│ p_by_b │ Normal │ ['b']       │
└────────┴────────┴─────────────┘
```
