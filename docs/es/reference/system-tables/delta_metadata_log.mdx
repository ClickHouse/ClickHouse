## Descripción {#purpose}

La tabla `system.delta_lake_metadata_log` registra eventos de acceso a metadatos y de análisis para tablas de Delta Lake leídas por ClickHouse. Proporciona información detallada sobre cada archivo de metadatos, lo que resulta útil para la depuración, la auditoría y para entender cómo evoluciona la estructura de las tablas de Delta Lake.

Esta tabla registra cada archivo de metadatos leído de tablas de Delta Lake. Ayuda a los usuarios a rastrear cómo ClickHouse interpreta los metadatos de las tablas de Delta Lake y a diagnosticar problemas relacionados con la evolución del esquema, la resolución de instantáneas o la planificación de consultas.

Esta tabla está pensada principalmente para tareas de depuración.

### Control de la verbosidad del registro {#controlling-log-verbosity}

Puede controlar qué eventos de metadatos se registran con la opción [`delta_lake_log_metadata`](/es/reference/settings/session-settings/delta-lake#delta_lake_log_metadata).

Para registrar todos los metadatos utilizados en la consulta actual:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

Es seguro truncar o eliminar esta tabla en cualquier momento.

## Columnas {#columns}

* `hostname` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Nombre del host del servidor que ejecuta la consulta.
* `clickhouse_version` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Versión del servidor de ClickHouse que generó la fila.
* `system_processor` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Arquitectura de CPU del servidor de ClickHouse que generó la fila.
* `event_date` ([Date](/es/reference/data-types/date)) — Fecha de la entrada.
* `event_time` ([DateTime](/es/reference/data-types/datetime)) — Hora del evento.
* `query_id` ([String](/es/reference/data-types/string)) — ID de la consulta.
* `table_path` ([String](/es/reference/data-types/string)) — Ruta de la tabla.
* `file_path` ([String](/es/reference/data-types/string)) — Ruta del archivo.
* `content` ([String](/es/reference/data-types/string)) — Contenido en formato JSON.
