## Descripción {#description}

Esta tabla muestra advertencias sobre el servidor de ClickHouse.
Las advertencias del mismo tipo se combinan en una sola advertencia.
Por ejemplo, si el número N de bases de datos adjuntas supera un umbral configurable T, se muestra una única entrada con el valor actual N en lugar de N entradas independientes.
Si el valor actual desciende por debajo del umbral, la entrada se elimina de la tabla.

La tabla se puede configurar con las siguientes opciones de configuración:

* [max&#95;table&#95;num&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-table#max_table_num_to_warn)
* [max&#95;database&#95;num&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-database#max_database_num_to_warn)
* [max&#95;dictionary&#95;num&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-dictionary#max_dictionary_num_to_warn)
* [max&#95;view&#95;num&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-view#max_view_num_to_warn)
* [max&#95;part&#95;num&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max#max_part_num_to_warn)
* [max&#95;pending&#95;mutations&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-pending#max_pending_mutations_to_warn)
* [max&#95;pending&#95;mutations&#95;execution&#95;time&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-pending#max_pending_mutations_execution_time_to_warn)
* [max&#95;named&#95;collection&#95;num&#95;to&#95;warn](/es/reference/settings/server-settings/settings/max-named#max_named_collection_num_to_warn)
* [resource&#95;overload&#95;warnings](/es/concepts/features/configuration/settings/server-overload#resource-overload-warnings)

## Columnas {#columns}

* `message` ([String](/es/reference/data-types/string)) — Un mensaje de advertencia emitido por el servidor de ClickHouse.
* `message_format_string` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Una cadena de formato utilizada para dar formato al mensaje.

## Ejemplos {#examples}

```sql title="Query"
 SELECT * FROM system.warnings LIMIT 2 \G;
```

```text title="Response"
Row 1:
──────
message:               The number of active parts is more than 10.
message_format_string: The number of active parts is more than {}.

Row 2:
──────
message:               The number of attached databases is more than 2.
message_format_string: The number of attached databases is more than {}.
```
