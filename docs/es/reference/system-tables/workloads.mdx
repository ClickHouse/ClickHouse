## Descripción {#description}

Contiene información sobre las [cargas de trabajo](/es/concepts/features/configuration/server-config/workload-scheduling#workload_entity_storage) que residen en el servidor local. La tabla contiene una fila por cada carga de trabajo.

## Columnas {#columns}

* `name` ([String](/es/reference/data-types/string)) — El nombre del workload.
* `parent` ([String](/es/reference/data-types/string)) — El nombre del workload principal.
* `create_query` ([String](/es/reference/data-types/string)) — La consulta CREATE del workload. En un workload implícito (`source` = `implicit`), incluido el workload raíz con nombre vacío, describe el workload y no se puede ejecutar.
* `source` ([String](/es/reference/data-types/string)) — El nombre del almacenamiento que define el workload: `configuration` para la configuración del servidor, `disk` o `keeper` para SQL, `implicit` para los workloads creados implícitamente por el servidor.

## Ejemplo {#example}

```sql
SELECT *
FROM system.workloads
FORMAT Vertical
```

```text
Row 1:
──────
name:         production
parent:       all
create_query: CREATE WORKLOAD production IN `all` SETTINGS weight = 9

Row 2:
──────
name:         development
parent:       all
create_query: CREATE WORKLOAD development IN `all`

Row 3:
──────
name:         all
parent:
create_query: CREATE WORKLOAD `all`
```
