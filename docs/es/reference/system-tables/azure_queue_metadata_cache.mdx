## Descripción {#description}

Contiene el estado en memoria de los metadatos de AzureQueue y las filas que se están procesando actualmente por archivo.

## Columnas {#columns}

* `zookeeper_path` ([String](/es/reference/data-types/string)) — Ruta en ZooKeeper a los metadatos
* `file_path` ([String](/es/reference/data-types/string)) — Ruta del archivo que se está procesando
* `file_name` ([String](/es/reference/data-types/string)) — Nombre del archivo que se está procesando
* `rows_processed` ([UInt64](/es/reference/data-types/int-uint)) — Número de filas procesadas hasta el momento
* `status` ([String](/es/reference/data-types/string)) — Estado del procesamiento: Processed, Processing, Failed o None para un archivo que la cache conoce pero para el que no tiene ningún estado, por ejemplo un archivo cuyo procesamiento se reinició. Un valor no nulo en `processing_observed_in_keeper_time` significa que el estado `Processing` no lo estableció el processor que retiene el archivo, sino que se leyó desde Keeper
* `processing_start_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que se inició el procesamiento del archivo
* `processing_end_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que finalizó el procesamiento del archivo
* `exception` ([String](/es/reference/data-types/string)) — Excepción ocurrida durante el procesamiento. Siempre es la del último intento de este servidor, nunca la que Keeper almacena para el archivo
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que un processor de este servidor no pudo tomar el archivo y leyó el estado `Processing` desde Keeper en lugar de establecerlo él mismo. Normalmente el archivo lo retiene otro servidor, pero también puede retenerlo un processor de este mismo servidor que acababa de tomarlo. En cualquier caso, `rows_processed`, `processing_start_time`, `processing_end_time` y `exception` describen el último intento de este servidor de procesar el archivo, no el procesamiento que lo retiene ahora
