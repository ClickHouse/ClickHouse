<div id="description">
  ## Descripción
</div>

Contiene el estado en memoria de los metadatos de AzureQueue y las filas que se están procesando actualmente por archivo.

<div id="columns">
  ## Columnas
</div>

{/*INICIO_AUTOGENERADO*/}

* `zookeeper_path` ([String](/es/reference/data-types/string)) — Ruta en ZooKeeper a los metadatos
* `file_path` ([String](/es/reference/data-types/string)) — Ruta del archivo que se está procesando
* `file_name` ([String](/es/reference/data-types/string)) — Nombre del archivo que se está procesando
* `rows_processed` ([UInt64](/es/reference/data-types/int-uint)) — Número de filas procesadas hasta el momento
* `status` ([String](/es/reference/data-types/string)) — Estado del procesamiento: Processed, Processing, Failed
* `processing_start_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que se inició el procesamiento del archivo
* `processing_end_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que finalizó el procesamiento del archivo
* `exception` ([String](/es/reference/data-types/string)) — Excepción ocurrida durante el procesamiento

{/*AUTOGENERATED_END*/}
