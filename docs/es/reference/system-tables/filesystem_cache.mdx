<div id="description">
  ## Descripción
</div>

Contiene información sobre todas las entradas de la caché del sistema de archivos para objetos remotos.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `cache_name` ([String](/es/reference/data-types/string)) — Nombre del objeto de caché. Puede utilizarse en los comandos `SYSTEM DESCRIBE FILESYSTEM CACHE <name>`, `SYSTEM DROP FILESYSTEM CACHE <name>`
* `cache_base_path` ([String](/es/reference/data-types/string)) — Ruta del directorio base donde se almacenan todos los archivos de caché de la caché identificada por `cache_name`.
* `cache_path` ([String](/es/reference/data-types/string)) — Ruta de un archivo de caché específico, correspondiente a un segmento de archivo de un archivo de origen
* `key` ([String](/es/reference/data-types/string)) — Clave de caché del segmento de archivo
* `file_segment_range_begin` ([UInt64](/es/reference/data-types/int-uint)) — Desplazamiento correspondiente al inicio del intervalo del segmento de archivo
* `file_segment_range_end` ([UInt64](/es/reference/data-types/int-uint)) — Desplazamiento correspondiente al final incluido del intervalo del segmento de archivo
* `size` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño del segmento de archivo
* `state` ([String](/es/reference/data-types/string)) — Estado del segmento de archivo (DOWNLOADED, DOWNLOADING, PARTIALLY&#95;DOWNLOADED, ...)
* `finished_download_time` ([DateTime](/es/reference/data-types/datetime)) — Momento en que finalizó la descarga del segmento de archivo.
* `cache_hits` ([UInt64](/es/reference/data-types/int-uint)) — Número de aciertos de caché del segmento de archivo correspondiente
* `references` ([UInt64](/es/reference/data-types/int-uint)) — Número de referencias al segmento de archivo correspondiente. El valor 1 significa que nadie lo está usando en este momento (la única referencia existente está en el propio almacenamiento de caché)
* `downloaded_size` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño descargado del segmento de archivo
* `kind` ([String](/es/reference/data-types/string)) — Tipo de segmento de archivo (se utiliza para distinguir los segmentos de archivo añadidos como parte de &#39;datos temporales en caché&#39;)
* `unbound` ([UInt8](/es/reference/data-types/int-uint)) — Indicador interno de implementación
* `user_id` ([String](/es/reference/data-types/string)) — ID del usuario que creó el segmento de archivo
* `segment_type` ([String](/es/reference/data-types/string)) — Tipo de segmento. Se utiliza para separar los archivos de datos (`.json`, `.txt`, etc.) de los archivos de datos (`.bin`, archivos de marcas).
* `file_size` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Tamaño del archivo al que pertenece el segmento de archivo actual

{/*AUTOGENERATED_END*/}
