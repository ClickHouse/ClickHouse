<div id="description">
  ## Descripción
</div>

Esta tabla del sistema se utiliza para implementar la consulta `SHOW PROCESSLIST`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `is_initial_query` ([UInt8](/es/reference/data-types/int-uint)) — Indica si esta consulta proviene directamente del usuario o si fue emitida por el servidor de ClickHouse en el contexto de la ejecución de consultas distribuidas.
* `user` ([String](/es/reference/data-types/string)) — El usuario que realizó la consulta. Tenga en cuenta que, en el procesamiento distribuido, las consultas se envían a servidores remotos con el usuario `default`. El campo contiene el nombre de usuario de una consulta específica, no el de la consulta que inició esta consulta.
* `query_id` ([String](/es/reference/data-types/string)) — ID de la consulta, si está definido.
* `address` ([IPv6](/es/reference/data-types/ipv6)) — La dirección IP desde la que se realizó la consulta. Lo mismo se aplica al procesamiento distribuido. Para rastrear desde dónde se realizó originalmente una consulta distribuida, consulte system.processes en el servidor que solicitó la consulta.
* `port` ([UInt16](/es/reference/data-types/int-uint)) — El puerto del cliente desde el que se realizó la consulta.
* `initial_user` ([String](/es/reference/data-types/string)) — Nombre del usuario que ejecutó la consulta inicial (para la ejecución de consultas distribuidas).
* `initial_query_id` ([String](/es/reference/data-types/string)) — ID de la consulta inicial (para la ejecución de consultas distribuidas).
* `initial_address` ([IPv6](/es/reference/data-types/ipv6)) — Dirección IP desde la que se inició la consulta principal.
* `initial_port` ([UInt16](/es/reference/data-types/int-uint)) — El puerto del cliente que se utilizó para realizar la consulta principal.
* `interface` ([UInt8](/es/reference/data-types/int-uint)) — La interfaz utilizada para enviar la consulta. TCP = 1, HTTP = 2, GRPC = 3, MYSQL = 4, POSTGRESQL = 5, LOCAL = 6, TCP&#95;INTERSERVER = 7.
* `os_user` ([String](/es/reference/data-types/string)) — Nombre de usuario del sistema operativo que ejecuta clickhouse-client.
* `client_hostname` ([String](/es/reference/data-types/string)) — Nombre de host de la máquina cliente donde se ejecuta clickhouse-client u otro cliente TCP.
* `client_name` ([String](/es/reference/data-types/string)) — Nombre de clickhouse-client u otro cliente TCP.
* `client_agent` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — El agente de programación con IA que invocó al cliente (por ejemplo, `claude-code`, `cursor`), detectado a partir de variables de entorno. Está vacío si no se detectó ningún agente.
* `client_revision` ([UInt64](/es/reference/data-types/int-uint)) — Revisión de clickhouse-client u otro cliente TCP.
* `client_version_major` ([UInt64](/es/reference/data-types/int-uint)) — Versión principal de clickhouse-client u otro cliente TCP.
* `client_version_minor` ([UInt64](/es/reference/data-types/int-uint)) — Versión secundaria de clickhouse-client u otro cliente TCP.
* `client_version_patch` ([UInt64](/es/reference/data-types/int-uint)) — Componente de parche de la versión de clickhouse-client u otro cliente TCP.
* `http_method` ([UInt8](/es/reference/data-types/int-uint)) — Método HTTP que inició la consulta. Valores posibles: 0 — La consulta se inició desde la interfaz TCP. 1 — Se utilizó el método GET. 2 — Se utilizó el método POST.
* `http_user_agent` ([String](/es/reference/data-types/string)) — Encabezado HTTP UserAgent incluido en la consulta HTTP.
* `http_referer` ([String](/es/reference/data-types/string)) — Encabezado HTTP Referer incluido en la consulta HTTP (contiene una dirección absoluta o parcial de la página que realiza la consulta).
* `forwarded_for` ([String](/es/reference/data-types/string)) — Encabezado HTTP X-Forwarded-For incluido en la consulta HTTP.
* `quota_key` ([String](/es/reference/data-types/string)) — La clave de cuota especificada en la configuración de cuotas (consulte keyed).
* `distributed_depth` ([UInt64](/es/reference/data-types/int-uint)) — Número de veces que la consulta se retransmitió internamente entre nodos de servidor.
* `elapsed` ([Float64](/es/reference/data-types/float)) — El tiempo, en segundos, transcurrido desde el inicio de la ejecución de la solicitud.
* `is_cancelled` ([UInt8](/es/reference/data-types/int-uint)) — Indica si se canceló la consulta.
* `is_all_data_sent` ([UInt8](/es/reference/data-types/int-uint)) — Indica si se enviaron todos los datos al cliente (es decir, si la consulta finalizó en el servidor).
* `read_rows` ([UInt64](/es/reference/data-types/int-uint)) — Número de filas leídas de la tabla. En el procesamiento distribuido, en el servidor solicitante, es el total de todos los servidores remotos.
* `read_bytes` ([UInt64](/es/reference/data-types/int-uint)) — Número de bytes sin comprimir leídos de la tabla. En el procesamiento distribuido, en el servidor solicitante, es el total de todos los servidores remotos.
* `total_rows_approx` ([UInt64](/es/reference/data-types/int-uint)) — Estimación del número total de filas que se deben leer. En el procesamiento distribuido, en el servidor solicitante, es el total de todos los servidores remotos. Puede actualizarse durante el procesamiento de la solicitud, a medida que se identifican nuevas fuentes que procesar.
* `written_rows` ([UInt64](/es/reference/data-types/int-uint)) — Número de filas escritas en el almacenamiento.
* `written_bytes` ([UInt64](/es/reference/data-types/int-uint)) — Número de bytes escritos en el almacenamiento.
* `memory_usage` ([Int64](/es/reference/data-types/int-uint)) — Cantidad de RAM utilizada por la consulta. Es posible que no incluya algunos tipos de memoria dedicada.
* `peak_memory_usage` ([Int64](/es/reference/data-types/int-uint)) — Pico actual de uso de memoria.
* `query` ([String](/es/reference/data-types/string)) — Texto de la consulta. En el caso de INSERT, no incluye los datos que se van a insertar.
* `normalized_query_hash` ([UInt64](/es/reference/data-types/int-uint)) — Valor hash numérico idéntico para consultas que solo difieren en los valores de los literales.
* `query_kind` ([String](/es/reference/data-types/string)) — Tipo de consulta: SELECT, INSERT, etc.
* `thread_ids` ([Array(UInt64)](/es/reference/data-types/array)) — Lista de identificadores de todos los hilos que participaron en esta consulta.
* `peak_threads_usage` ([UInt64](/es/reference/data-types/int-uint)) — Número máximo de hilos simultáneos que ejecutan la consulta.
* `ProfileEvents` ([Map(LowCardinality(String), UInt64)](/es/reference/data-types/map)) — ProfileEvents calculados para esta consulta.
* `Settings` ([Map(LowCardinality(String), LowCardinality(String))](/es/reference/data-types/map)) — Lista de ajustes de nivel de usuario modificados.
* `current_database` ([String](/es/reference/data-types/string)) — Nombre de la base de datos actual.
* `is_internal` ([UInt8](/es/reference/data-types/int-uint)) — Indica si se trata de una consulta auxiliar ejecutada internamente.

**Alias:**

* `ProfileEvents.Names` — Alias de `mapKeys(ProfileEvents)`.
* `ProfileEvents.Values` — Alias de `mapValues(ProfileEvents)`.
* `Settings.Names` — Alias de `mapKeys(Settings)`.
* `Settings.Values` — Alias de `mapValues(Settings)`.
