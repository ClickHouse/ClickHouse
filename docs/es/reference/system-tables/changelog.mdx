## Descripción {#description}

Contiene las entradas del registro de cambios curado de ClickHouse (el archivo `CHANGELOG.md` del repositorio), con una fila por cada entrada de cada versión con nuevas funcionalidades, de modo que las notas de la versión se puedan consultar con SQL.

## Columnas {#columns}

* `version` ([Tuple(major UInt16, minor UInt8, patch UInt16)](/es/reference/data-types/tuple)) — Versión a la que pertenece la entrada, expresada como una tupla comparable. El registro de cambios editado describe versiones con nuevas funcionalidades, por lo que `patch` es 0.
* `release_date` ([Date](/es/reference/data-types/date)) — Fecha de publicación de la versión.
* `is_lts` ([UInt8](/es/reference/data-types/int-uint)) — 1 si la versión es de soporte a largo plazo.
* `category` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Sección del registro de cambios a la que pertenece la entrada, p. ej., &#39;New Feature&#39;, &#39;Performance Improvement&#39;, &#39;Bug Fix&#39;.
* `description` ([String](/es/reference/data-types/string)) — Texto de la entrada del registro de cambios.
* `pull_requests` ([Array(UInt32)](/es/reference/data-types/array)) — Números de los pull requests a los que hace referencia la entrada.
* `authors` ([Array(String)](/es/reference/data-types/array)) — Autores de los pull requests referenciados.

## Ejemplo {#example}

Busque los cambios recientes relacionados con JSON, de la versión más reciente a la más antigua:

```sql
SELECT version, category, description
FROM system.changelog
WHERE description ILIKE '%JSON%' AND version >= (26, 1, 0)
ORDER BY version DESC
LIMIT 3
```
