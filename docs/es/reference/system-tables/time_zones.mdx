## Descripción {#description}

Contiene una lista de las zonas horarias compatibles con el servidor ClickHouse. Esta lista de zonas horarias puede variar según la versión de ClickHouse.

## Columnas {#columns}

* `time_zone` ([String](/es/reference/data-types/string)) — Lista de zonas horarias admitidas.

## Ejemplo {#example}

```sql
SELECT * FROM system.time_zones LIMIT 10
```

```text
┌─time_zone──────────┐
│ Africa/Abidjan     │
│ Africa/Accra       │
│ Africa/Addis_Ababa │
│ Africa/Algiers     │
│ Africa/Asmara      │
│ Africa/Asmera      │
│ Africa/Bamako      │
│ Africa/Bangui      │
│ Africa/Banjul      │
│ Africa/Bissau      │
└────────────────────┘
```
