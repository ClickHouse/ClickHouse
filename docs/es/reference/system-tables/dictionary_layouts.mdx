<div id="description">
  ## Descripción
</div>

Contiene la lista de las estructuras de diccionario admitidas por el servidor, junto con la documentación integrada de cada una. Una estructura de diccionario determina cómo se almacena un diccionario en memoria (o en disco) y cómo se realizan las búsquedas en él; se especifica en la cláusula `LAYOUT` de una consulta `CREATE DICTIONARY`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types/string)) — El nombre de la estructura del diccionario, tal como se especifica en la cláusula LAYOUT.
* `is_complex` ([UInt8](/es/reference/data-types/int-uint)) — Indica si la estructura requiere una clave compleja (una clave compuesta por varios atributos o de tipo no entero).
* `description` ([String](/es/reference/data-types/string)) — Una descripción de la función de la estructura del diccionario. Para las estructuras que tienen una página de documentación específica, contiene el cuerpo completo en Markdown de esa página; para las estructuras restantes, es un resumen conciso.
* `syntax` ([String](/es/reference/data-types/string)) — Cómo se especifica la estructura en la cláusula LAYOUT de una consulta CREATE DICTIONARY.
* `examples` ([String](/es/reference/data-types/string)) — Ejemplos de uso.
* `introduced_in` ([String](/es/reference/data-types/string)) — La versión de ClickHouse en la que se introdujo por primera vez la estructura, con el formato major.minor.
* `related` ([Array(String)](/es/reference/data-types/array)) — Los nombres de las estructuras de diccionario relacionadas.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SELECT name, is_complex, syntax
FROM system.dictionary_layouts
WHERE name IN ('flat', 'hashed', 'complex_key_hashed')
ORDER BY name
```

```text title="Response"
┌─name───────────────┬─is_complex─┬─syntax───────────────────────────────────────────────────┐
│ complex_key_hashed │          1 │ LAYOUT(COMPLEX_KEY_HASHED())                             │
│ flat               │          0 │ LAYOUT(FLAT([INITIAL_ARRAY_SIZE n] [MAX_ARRAY_SIZE n]))  │
│ hashed             │          0 │ LAYOUT(HASHED())                                         │
└────────────────────┴────────────┴──────────────────────────────────────────────────────────┘
```
