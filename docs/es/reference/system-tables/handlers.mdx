<div id="description">
  ## Descripción
</div>

Contiene una lista de todos los handlers HTTP definidos en SQL y creados mediante [`CREATE HANDLER`](/es/reference/statements/create/handler).

Para leer esta tabla se requiere el privilegio `SHOW HANDLERS`; de lo contrario, aparece vacía. Los secretos que
puedan estar incluidos en la consulta del handler (por ejemplo, credenciales pasadas a una función de tabla) solo se muestran en las
columnas `query` y `create_query` cuando el usuario tiene permiso para ver secretos (la configuración del servidor
`display_secrets_in_show_and_select` y la configuración de formato `format_display_secrets_in_show_and_select`
están habilitadas y el usuario posee el privilegio `displaySecretsInShowAndSelect`); de lo contrario, se
enmascaran, igual que en `SHOW CREATE TABLE`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types/string)) — Nombre del handler.
* `protocol` ([Nullable(String)](/es/reference/data-types/nullable)) — Protocolo componible al que se restringe el handler, o NULL si está activo en todos los endpoints HTTP (los puertos integrados `http`/`https` y todos los listeners de protocolos componibles de tipo HTTP).
* `url_match_type` ([String](/es/reference/data-types/string)) — Cómo se compara la URL: exacta, por prefijo o mediante expresión regular.
* `url` ([String](/es/reference/data-types/string)) — El patrón de URL con el que coincide el handler.
* `methods` ([Array(String)](/es/reference/data-types/array)) — Métodos HTTP permitidos.
* `type` ([String](/es/reference/data-types/string)) — El tipo de handler (solo se admite `query`).
* `query` ([String](/es/reference/data-types/string)) — La consulta SQL que ejecuta el handler. Los secretos se ocultan a menos que el usuario tenga permiso para verlos.
* `create_query` ([String](/es/reference/data-types/string)) — La instrucción CREATE HANDLER. Los secretos se ocultan a menos que el usuario tenga permiso para verlos.

{/*AUTOGENERATED_END*/}
