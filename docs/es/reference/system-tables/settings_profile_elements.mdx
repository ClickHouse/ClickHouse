<div id="description">
  ## Descripción
</div>

Describe el contenido del perfil de configuración:

* Restricciones.
* Roles y usuarios a los que se aplica la configuración.
* Perfiles de configuración superiores.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `profile_name` ([Nullable(String)](/es/reference/data-types/nullable)) — Nombre del perfil de configuración.
* `user_name` ([Nullable(String)](/es/reference/data-types/nullable)) — Nombre de usuario.
* `role_name` ([Nullable(String)](/es/reference/data-types/nullable)) — Nombre del rol.
* `index` ([UInt64](/es/reference/data-types/int-uint)) — Número secuencial del elemento del perfil de configuración.
* `setting_name` ([Nullable(String)](/es/reference/data-types/nullable)) — Nombre de la configuración.
* `value` ([Nullable(String)](/es/reference/data-types/nullable)) — Valor de la configuración.
* `min` ([Nullable(String)](/es/reference/data-types/nullable)) — Valor mínimo de la configuración. NULL si no se ha establecido.
* `max` ([Nullable(String)](/es/reference/data-types/nullable)) — Valor máximo de la configuración. NULL si no se ha establecido.
* `writability` ([Nullable(Enum8(&#39;WRITABLE&#39; = 0, &#39;CONST&#39; = 1, &#39;CHANGEABLE&#95;IN&#95;READONLY&#39; = 2))](/es/reference/data-types/nullable)) — Propiedad que indica si una configuración se puede modificar.
* `inherit_profile` ([Nullable(String)](/es/reference/data-types/nullable)) — Perfil principal de este perfil de configuración. NULL si no se ha establecido. El perfil de configuración heredará de sus perfiles principales todos los valores y restricciones de configuración (min, max, readonly).

{/*AUTOGENERATED_END*/}
