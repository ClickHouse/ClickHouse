<div id="description">
  ## Descripción
</div>

Uso de cuotas de todos los usuarios.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/es/reference/data-types/string)) — Nombre de la cuota.
* `quota_key` ([String](/es/reference/data-types/string)) — Valor de la clave.
* `is_current` ([UInt8](/es/reference/data-types/int-uint)) — Uso de la cuota para el usuario actual.
* `start_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora de inicio para calcular el consumo de recursos.
* `end_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora de finalización para calcular el consumo de recursos.
* `duration` ([Nullable(UInt32)](/es/reference/data-types/nullable)) — Duración del intervalo de tiempo para calcular el consumo de recursos, en segundos.
* `queries` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número actual de consultas ejecutadas.
* `max_queries` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de consultas de cualquier tipo que se pueden ejecutar.
* `query_selects` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número actual de consultas SELECT ejecutadas.
* `max_query_selects` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de consultas SELECT que se pueden ejecutar.
* `query_inserts` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número actual de consultas INSERT ejecutadas.
* `max_query_inserts` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de consultas INSERT que se pueden ejecutar.
* `errors` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número actual de consultas que han generado un error.
* `max_errors` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de consultas que pueden generar un error dentro del período especificado.
* `result_rows` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total actual de filas del conjunto de resultados de todas las consultas dentro del período actual.
* `max_result_rows` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total máximo permitido de filas del conjunto de resultados de todas las consultas dentro del período especificado.
* `result_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total actual de bytes del conjunto de resultados de todas las consultas dentro del período actual.
* `max_result_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total máximo permitido de bytes del conjunto de resultados de todas las consultas dentro del período especificado.
* `read_rows` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total actual de filas leídas durante la ejecución de todas las consultas dentro del período actual.
* `max_read_rows` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de filas que se pueden leer durante la ejecución de todas las consultas dentro del período especificado.
* `read_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total actual de bytes leídos durante la ejecución de todas las consultas dentro del período actual.
* `max_read_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de bytes que se pueden leer durante la ejecución de todas las consultas dentro del período especificado.
* `execution_time` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Tiempo total actual (en nanosegundos) dedicado a ejecutar consultas dentro del período actual
* `max_execution_time` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Tiempo máximo (en nanosegundos) permitido para ejecutar todas las consultas dentro del período especificado
* `written_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total actual de bytes escritos durante la ejecución de todas las consultas dentro del período actual.
* `max_written_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de bytes que se pueden escribir durante la ejecución de todas las consultas dentro del período especificado.
* `failed_sequential_authentications` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número actual de fallos consecutivos de autenticación dentro del período actual.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de fallos consecutivos de autenticación dentro del período especificado.
* `queries_per_normalized_hash` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo actual de ejecuciones de una misma consulta normalizada dentro del período actual.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número máximo permitido de ejecuciones de una misma consulta normalizada dentro del período especificado.
