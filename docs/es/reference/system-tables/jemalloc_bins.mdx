<div id="description">
  ## Descripción
</div>

Contiene información sobre las asignaciones de memoria realizadas mediante el asignador jemalloc en distintas clases de tamaño (bins), agregadas de todas las arenas.
Es posible que estas estadísticas no sean totalmente precisas debido a la caché local por hilo en jemalloc.

<div id="columns">
  ## Columnas
</div>

{/*INICIO_AUTOGENERADO*/}

* `index` ([UInt16](/es/reference/data-types/int-uint)) — Índice del bin, ordenado por tamaño.
* `large` ([UInt8](/es/reference/data-types/int-uint)) — True para asignaciones grandes y False para las pequeñas.
* `size` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de las asignaciones en este bin.
* `allocations` ([Int64](/es/reference/data-types/int-uint)) — Número de asignaciones.
* `deallocations` ([Int64](/es/reference/data-types/int-uint)) — Número de desasignaciones.
* `nregs` ([Int64](/es/reference/data-types/int-uint)) — Número de regiones por slab.
* `curslabs` ([Int64](/es/reference/data-types/int-uint)) — Número actual de slabs.
* `curregs` ([Int64](/es/reference/data-types/int-uint)) — Número actual de regiones de esta clase de tamaño.

**Alias:**

* `availregs` — Alias de `nregs * curslabs`.
* `util` — Alias de `curregs / availregs`.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Ejemplo
</div>

Encuentre los tamaños de las asignaciones de memoria que más contribuyeron al uso total de memoria actual.

```sql
SELECT
    *,
    allocations - deallocations AS active_allocations,
    size * active_allocations AS allocated_bytes
FROM system.jemalloc_bins
WHERE allocated_bytes > 0
ORDER BY allocated_bytes DESC
LIMIT 10
```
