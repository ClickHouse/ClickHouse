## Descripción {#description}

Muestra los [watches](https://zookeeper.apache.org/doc/r3.3.3/zookeeperProgrammers.html#ch_zkWatches) activos que este servidor de ClickHouse tiene registrados en nodos de ZooKeeper (incluidos los ZooKeepers auxiliares). Cada fila representa un watch.

**Disponibilidad**

`system.zookeeper_watches` solo existe cuando ClickHouse Keeper o ZooKeeper están configurados. En servidores en los que no se ha configurado ninguno de los dos, la tabla no existe y las consultas sobre ella fallarán con `UNKNOWN_TABLE`.

## Columnas {#columns}

* `zookeeper_name` ([String](/es/reference/data-types/string)) — Nombre de la conexión a ZooKeeper (&quot;default&quot; para la conexión principal o el nombre auxiliar).
* `create_time` ([DateTime](/es/reference/data-types/datetime)) — Hora en que se creó el watch.
* `create_time_microseconds` ([DateTime64(6)](/es/reference/data-types/datetime64)) — Hora en que se creó el watch con precisión de microsegundos.
* `path` ([String](/es/reference/data-types/string)) — Ruta de ZooKeeper que se está vigilando.
* `session_id` ([Int64](/es/reference/data-types/int-uint)) — ID de sesión de la conexión que registró el watch.
* `request_xid` ([Int64](/es/reference/data-types/int-uint)) — XID de la solicitud que creó el watch.
* `op_num` ([Enum16(&#39;Close&#39; = -11, &#39;Error&#39; = -1, &#39;Watch&#39; = 0, &#39;Create&#39; = 1, &#39;Remove&#39; = 2, &#39;Exists&#39; = 3, &#39;Get&#39; = 4, &#39;Set&#39; = 5, &#39;GetACL&#39; = 6, &#39;SetACL&#39; = 7, &#39;SimpleList&#39; = 8, &#39;Sync&#39; = 9, &#39;Heartbeat&#39; = 11, &#39;List&#39; = 12, &#39;Check&#39; = 13, &#39;Multi&#39; = 14, &#39;Create2&#39; = 15, &#39;Reconfig&#39; = 16, &#39;CheckWatch&#39; = 17, &#39;RemoveWatch&#39; = 18, &#39;CreateContainer&#39; = 19, &#39;CreateTTL&#39; = 21, &#39;MultiRead&#39; = 22, &#39;Auth&#39; = 100, &#39;SetWatch&#39; = 101, &#39;SetWatch2&#39; = 105, &#39;AddWatch&#39; = 106, &#39;FilteredList&#39; = 500, &#39;CheckNotExists&#39; = 501, &#39;CreateIfNotExists&#39; = 502, &#39;RemoveRecursive&#39; = 503, &#39;CheckStat&#39; = 504, &#39;TryRemove&#39; = 505, &#39;FilteredListWithStatsAndData&#39; = 506, &#39;ListRecursive&#39; = 507, &#39;SessionID&#39; = 997)](/es/reference/data-types/enum)) — Operación que creó el watch.
* `watch_type` ([Enum8(&#39;Unexpected&#39; = -1, &#39;Children&#39; = 1, &#39;Exists&#39; = 2, &#39;Data&#39; = 3)](/es/reference/data-types/enum)) — Tipo de watch: Children (list), Exists o Data (get).
