## Descripción {#description}

Contiene el estado en memoria de los metadatos de S3Queue y las filas actualmente en proceso de cada archivo.

## Columnas {#columns}

* `zookeeper_path` ([String](/es/reference/data-types/string)) — Ruta en ZooKeeper a los metadatos
* `file_path` ([String](/es/reference/data-types/string)) — Ruta del archivo que se está procesando
* `file_name` ([String](/es/reference/data-types/string)) — Nombre del archivo que se está procesando
* `rows_processed` ([UInt64](/es/reference/data-types/int-uint)) — Número de filas procesadas actualmente
* `status` ([String](/es/reference/data-types/string)) — Estado del procesamiento: Procesado, Procesando, Fallido o None para un archivo que la caché conoce pero del que no tiene estado; por ejemplo, un archivo cuyo procesamiento se restableció. Un valor no nulo de `processing_observed_in_keeper_time` significa que el estado `Processing` no fue establecido por el procesador que tiene el archivo, sino que se leyó de Keeper
* `processing_start_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que comenzó el procesamiento del archivo
* `processing_end_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que finalizó el procesamiento del archivo
* `exception` ([String](/es/reference/data-types/string)) — Excepción producida durante el procesamiento. Siempre corresponde al último intento de este servidor, nunca a la que Keeper almacena para el archivo
* `processing_observed_in_keeper_time` ([Nullable(DateTime)](/es/reference/data-types/nullable)) — Hora a la que un procesador de este servidor no pudo tomar el archivo y leyó el estado `Processing` de Keeper en lugar de establecerlo él mismo. Normalmente, otro servidor tiene el archivo, pero también puede tenerlo un procesador de este servidor que acaba de tomarlo. En cualquier caso, `rows_processed`, `processing_start_time`, `processing_end_time` y `exception` describen el último intento de este servidor de procesar el archivo, no el procesamiento que lo tiene actualmente
