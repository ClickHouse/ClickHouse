<div id="description">
  ## Descripción
</div>

Contiene información sobre el estado de los [nodos de planificación](/es/concepts/features/configuration/server-config/workload-scheduling#hierarchy) que residen en el servidor local.
Esta tabla puede usarse para la monitorización. La tabla contiene una fila por cada nodo de planificación.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `resource` ([String](/es/reference/data-types/string)) — Nombre del recurso
* `path` ([String](/es/reference/data-types/string)) — Ruta a un nodo de planificación dentro de esta jerarquía de planificación de recursos
* `type` ([String](/es/reference/data-types/string)) — Tipo de nodo de planificación.
* `weight` ([Float64](/es/reference/data-types/float)) — Peso de un nodo, utilizado por un nodo padre de tipo `fair`.
* `priority` ([Int64](/es/reference/data-types/int-uint)) — Prioridad de un nodo, utilizada por un nodo padre de tipo &#39;priority&#39; (un valor menor implica una prioridad mayor).
* `precedence` ([Int64](/es/reference/data-types/int-uint)) — Precedencia de un nodo, utilizada por nodos padre de espacio compartido (memoria) para ordenar la admisión y la expulsión (un valor menor implica una precedencia mayor).
* `is_active` ([Nullable(UInt8)](/es/reference/data-types/nullable)) — Indica si este nodo está activo actualmente; es decir, tiene solicitudes de recursos pendientes de desencolar y se cumplen sus restricciones.
* `active_children` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número de hijos en estado activo.
* `dequeued_requests` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total de solicitudes de recursos desencoladas de este nodo.
* `canceled_requests` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total de solicitudes de recursos canceladas de este nodo.
* `rejected_requests` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total de solicitudes de recursos rechazadas de este nodo.
* `dequeued_cost` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes desencoladas de este nodo.
* `canceled_cost` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes canceladas de este nodo.
* `rejected_cost` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes rechazadas de este nodo.
* `busy_periods` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Número total de desactivaciones de este nodo.
* `throughput` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Rendimiento medio actual (coste desencolado por segundo).
* `vruntime` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Solo para hijos de nodos `fair`. Tiempo de ejecución virtual de un nodo utilizado por el algoritmo SFQ para seleccionar el siguiente hijo que se procesará de forma equitativa según el criterio max-min.
* `system_vruntime` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Solo para nodos `fair`. Tiempo de ejecución virtual que indica el `vruntime` de la última solicitud de recursos procesada. Se utiliza durante la activación de un hijo como nuevo valor de `vruntime`.
* `queue_length` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos `fifo`. Número actual de solicitudes de recursos en la cola.
* `queue_cost` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `fifo`. Suma de los costes (p. ej., tamaño en bytes) de todas las solicitudes en la cola.
* `budget` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `fifo`. Número de &#39;unidades de coste&#39; disponibles para nuevas solicitudes de recursos. Puede aparecer si existe una discrepancia entre los costes estimados y reales de las solicitudes de recursos (p. ej., tras un error de lectura/escritura)
* `is_satisfied` ([Nullable(UInt8)](/es/reference/data-types/nullable)) — Solo para nodos de restricción (p. ej., `inflight_limit`). Es igual a `1` si se cumplen todas las restricciones de este nodo.
* `inflight_requests` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `inflight_limit`. Número de solicitudes de recursos desencoladas de este nodo que se encuentran actualmente en estado de consumo.
* `inflight_cost` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `inflight_limit`. Suma de los costes (p. ej., bytes) de todas las solicitudes de recursos desencoladas de este nodo que se encuentran actualmente en estado de consumo.
* `max_requests` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `inflight_limit`. Límite superior de inflight&#95;requests que provoca una infracción de restricción.
* `max_cost` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `inflight_limit`. Límite superior de inflight&#95;cost que provoca una infracción de restricción.
* `max_speed` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Solo para nodos `bandwidth_limit`. Límite superior del ancho de banda en tokens por segundo.
* `max_burst` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Solo para nodos `bandwidth_limit`. Límite superior de tokens disponibles en el limitador token-bucket.
* `throttling_us` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos `bandwidth_limit`. Número total de microsegundos durante los que este nodo estuvo en estado de limitación.
* `tokens` ([Nullable(Float64)](/es/reference/data-types/nullable)) — Solo para nodos `bandwidth_limit`. Número de tokens disponibles actualmente en el limitador token-bucket.
* `allocated` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Cantidad de recurso asignada actualmente en este nodo.
* `allocations` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número actual de asignaciones de recursos en ejecución en este nodo.
* `updates` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de actualizaciones propagadas a través de este nodo.
* `increases` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de solicitudes de aumento aprobadas por este nodo.
* `decreases` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de solicitudes de reducción aprobadas por este nodo.
* `admits` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de asignaciones admitidas por este nodo.
* `removes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de asignaciones eliminadas de este nodo.
* `killers` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de expulsiones iniciadas por este nodo debido a solicitudes de aumento.
* `victims` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos de espacio compartido. Número total de asignaciones expulsadas de este nodo.
* `rejects` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos `allocation_queue`. Número total de asignaciones de recursos rechazadas por este nodo.
* `pending` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Solo para nodos `allocation_queue`. Número actual de asignaciones de recursos pendientes en este nodo.

{/*AUTOGENERATED_END*/}
