<div id="description">
  ## Descripción
</div>

Esta tabla solo existe para implementaciones de ClickHouse Keeper que utilizan el proceso `clickhouse server` (y no `clickhouse keeper`). Contiene una fila por cada nodo del árbol de datos almacenado en el nodo Keeper local, incluidos los nodos del sistema `/keeper`.

A diferencia de `system.zookeeper`, esta tabla no envía solicitudes a un clúster de Keeper. Lee directamente el estado confirmado del Keeper local desde una vista coherente y sin bloqueos, sin afectar al procesamiento de solicitudes. La lectura de la tabla no requiere una condición de ruta y devuelve todo el árbol, por lo que resulta adecuada para consultas que recorren todos los nodos, como buscar los nodos con más hijos o con los datos más grandes.

<div id="columns">
  ## Columnas
</div>

* `path` ([String](/es/reference/data-types/string)) — Ruta absoluta del nodo.
* `data` ([String](/es/reference/data-types/string)) — Datos almacenados en el nodo.
* `czxid` ([Int64](/es/reference/data-types/int-uint)) — ID de la transacción que creó el nodo.
* `mzxid` ([Int64](/es/reference/data-types/int-uint)) — ID de la transacción que modificó el nodo por última vez.
* `ctime` ([DateTime64(3)](/es/reference/data-types/datetime64)) — Momento en que se creó el nodo.
* `mtime` ([DateTime64(3)](/es/reference/data-types/datetime64)) — Momento en que se modificó el nodo por última vez.
* `version` ([Int32](/es/reference/data-types/int-uint)) — Número de modificaciones de los datos del nodo.
* `cversion` ([Int32](/es/reference/data-types/int-uint)) — Número de modificaciones de los nodos hijo.
* `aversion` ([Int32](/es/reference/data-types/int-uint)) — Número de modificaciones de la ACL del nodo.
* `ephemeral_owner` ([Int64](/es/reference/data-types/int-uint)) — ID de la sesión propietaria del nodo si este es efímero; `0` en caso contrario.
* `data_length` ([UInt32](/es/reference/data-types/int-uint)) — Tamaño de los datos del nodo en bytes.
* `num_children` ([Int32](/es/reference/data-types/int-uint)) — Número de nodos hijo.
* `pzxid` ([Int64](/es/reference/data-types/int-uint)) — ID de la transacción que agregó o eliminó nodos hijo del nodo por última vez.
* `seq_num` ([Int64](/es/reference/data-types/int-uint)) — Contador utilizado para generar nombres de nodos hijo secuenciales del nodo.
* `ttl` ([Int64](/es/reference/data-types/int-uint)) — TTL del nodo en milisegundos si es un nodo TTL; `0` en caso contrario.
* `acl_id` ([UInt32](/es/reference/data-types/int-uint)) — ID interno de la ACL del nodo; `0` si el nodo no tiene ACL.

<div id="example">
  ## Ejemplo
</div>

```sql
SELECT path, num_children, data_length
FROM system.keeper_storage
ORDER BY num_children DESC
LIMIT 3;
```

```text
┌─path──────────────┬─num_children─┬─data_length─┐
│ /                 │            3 │           0 │
│ /clickhouse/tasks │            2 │           0 │
│ /keeper           │            1 │           0 │
└───────────────────┴──────────────┴─────────────┘
```
