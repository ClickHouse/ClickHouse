## Descripción {#description}

Contiene información sobre las opciones de compilación del servidor ClickHouse.

## Columnas {#columns}

* `name` ([String](/es/reference/data-types/string)) — Nombre de la opción de compilación.
* `value` ([String](/es/reference/data-types/string)) — Valor de la opción de compilación.

## Ejemplo {#example}

```sql
SELECT * FROM system.build_options LIMIT 5
```

```text
┌─name─────────────┬─value─┐
│ USE_BROTLI       │ 1     │
│ USE_BZIP2        │ 1     │
│ USE_CAPNP        │ 1     │
│ USE_CASSANDRA    │ 1     │
│ USE_DATASKETCHES │ 1     │
└──────────────────┴───────┘
```
