<div id="description">
  ## Descripción
</div>

Contiene la lista de fuentes de diccionario admitidas por el servidor, junto con la documentación integrada para cada fuente. Una fuente de diccionario determina desde dónde se cargan los datos del diccionario; se especifica en la cláusula `SOURCE` de una consulta `CREATE DICTIONARY`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types/string)) — El nombre de la fuente de diccionario, tal como se especifica en la cláusula SOURCE.
* `description` ([String](/es/reference/data-types/string)) — Una descripción de lo que hace la fuente de diccionario. Para las fuentes que tienen una página de documentación dedicada, contiene el cuerpo completo en Markdown de esa página; para las fuentes restantes, es un resumen conciso.
* `syntax` ([String](/es/reference/data-types/string)) — La estructura de la cláusula SOURCE utilizada para especificar la fuente. Tenga en cuenta que algunas fuentes están sujetas a control de acceso cuando un diccionario se crea a partir de una consulta DDL (en lugar de un archivo de configuración del servidor); consulte la `description` de cada fuente para obtener más detalles.
* `examples` ([String](/es/reference/data-types/string)) — Ejemplos de uso.
* `introduced_in` ([String](/es/reference/data-types/string)) — La versión de ClickHouse en la que se introdujo por primera vez la fuente, con el formato major.minor.
* `related` ([Array(String)](/es/reference/data-types/array)) — Los nombres de fuentes de diccionario relacionados.

{/*AUTOGENERATED_END*/}

<div id="example">
  ## Ejemplo
</div>

```sql title="Query"
SELECT name, syntax
FROM system.dictionary_sources
WHERE name IN ('clickhouse', 'file')
ORDER BY name
```

```text title="Response"
┌─name───────┬─syntax─────────────────────────────────────────────────────────────────────────┐
│ clickhouse │ SOURCE(CLICKHOUSE(host 'host' port 9000 user 'default' password '' db 'db' table 'table')) │
│ file       │ SOURCE(FILE(path '/path/to/file' format 'CSV'))                                  │
└────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
