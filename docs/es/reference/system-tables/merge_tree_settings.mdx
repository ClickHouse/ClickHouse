<div id="description">
  ## Descripción
</div>

Contiene información sobre la configuración de las tablas `MergeTree`.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types/string)) — Nombre del SETTING.
* `value` ([String](/es/reference/data-types/string)) — Valor del SETTING.
* `default` ([String](/es/reference/data-types/string)) — Valor predeterminado del SETTING.
* `changed` ([UInt8](/es/reference/data-types/int-uint)) — 1 si el SETTING se definió explícitamente en la configuración o se cambió explícitamente.
* `description` ([String](/es/reference/data-types/string)) — Descripción del SETTING.
* `min` ([Nullable(String)](/es/reference/data-types/nullable)) — Valor mínimo del SETTING, si se ha establecido alguno mediante restricciones. Si el SETTING no tiene valor mínimo, contiene NULL.
* `max` ([Nullable(String)](/es/reference/data-types/nullable)) — Valor máximo del SETTING, si se ha establecido alguno mediante restricciones. Si el SETTING no tiene valor máximo, contiene NULL.
* `disallowed_values` ([Array(String)](/es/reference/data-types/array)) — Lista de valores no permitidos
* `readonly` ([UInt8](/es/reference/data-types/int-uint)) — Indica si el usuario actual puede cambiar el SETTING: 0 — El usuario actual puede cambiar el SETTING, 1 — El usuario actual no puede cambiar el SETTING.
* `type` ([String](/es/reference/data-types/string)) — Tipo de SETTING (valor de cadena específico de la implementación).
* `is_obsolete` ([UInt8](/es/reference/data-types/int-uint)) — Indica si un SETTING es obsoleto.
* `tier` ([Enum8(&#39;Production&#39; = 0, &#39;Obsolete&#39; = 4, &#39;Experimental&#39; = 8, &#39;Beta&#39; = 12, &#39;PrivatePreview&#39; = 16)](/es/reference/data-types/enum)) — Nivel de soporte de esta funcionalidad. Las funcionalidades de ClickHouse se organizan en niveles, que varían según el estado actual de su
  desarrollo y las expectativas que cabe tener al usarlas:
  * PRODUCTION: La funcionalidad es estable, segura de usar y no presenta problemas al interactuar con otras funcionalidades PRODUCTION.
  * BETA: La funcionalidad es estable y segura. Se desconoce el resultado de usarla junto con otras funcionalidades y no se garantiza su corrección. Se agradecen las pruebas y los informes.
  * EXPERIMENTAL: La funcionalidad está en desarrollo. Está pensada solo para desarrolladores y entusiastas de ClickHouse. La funcionalidad puede funcionar o no, y podría eliminarse en cualquier momento.
  * PRIVATE PREVIEW: La funcionalidad sigue un camino claro hacia la disponibilidad general. Su aplicabilidad aún es limitada y no se recomienda su uso en producción.
  * OBSOLETE: Ya no cuenta con soporte. O bien ya se ha eliminado o se eliminará en futuras versiones.

{/*AUTOGENERATED_END*/}
