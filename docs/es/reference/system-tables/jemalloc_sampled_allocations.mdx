## Descripción {#description}

Una fila por cada asignación activa muestreada por el profiler de heap de jemalloc; al leer la tabla se vacía un nuevo heap profile. Solo contribuyen los hilos que tienen el profiler armado (setting `jemalloc_enable_profiler` o configuración `jemalloc_enable_global_profiler`); cada fila representa aproximadamente `weight` asignaciones similares.

## Columnas {#columns}

{/*AUTOGENERATED_START*/}

* `trace` ([Array(UInt64)](/es/reference/data-types/array)) — Direcciones de la traza de pila de asignación, con el frame hoja primero (misma convención que `system.trace_log.trace`). Simbolice con `addressToSymbol` y `demangle` (requiere `allow_introspection_functions`).
* `age_ns` ([UInt64](/es/reference/data-types/int-uint)) — Tiempo en nanosegundos que la asignación ha permanecido activa, relativo al momento en que se vació el perfil.
* `size` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de asignación solicitado en bytes.
* `usize` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño utilizable en bytes; es decir, la clase de tamaño a la que se redondeó la solicitud.
* `size_class` ([UInt16](/es/reference/data-types/int-uint)) — Índice de la clase de tamaño. Se une a `system.jemalloc_bins.index` para las clases de tamaño pequeñas.
* `arena` ([UInt32](/es/reference/data-types/int-uint)) — Índice del área desde la que se atendió la asignación.
* `thr_uid` ([UInt64](/es/reference/data-types/int-uint)) — ID único interno de jemalloc del hilo que realizó la asignación.
* `sample_interval` ([UInt64](/es/reference/data-types/int-uint)) — Número medio de bytes asignados entre muestras, obtenido del encabezado del perfil. Es el mismo para todas las filas.

**Alias:**

* `alloc_time` — Alias de `now() - intDiv(age_ns, 1000000000)`.
* `weight` — Alias de `1 / (1 - exp((-usize) / sample_interval))`.
