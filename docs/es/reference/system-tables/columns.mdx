<div id="description">
  ## Descripción
</div>

Contiene información sobre las columnas de todas las tablas.

Puede usar esta tabla para obtener información similar a la de la consulta [DESCRIBE TABLE](/es/reference/statements/describe-table), pero para varias tablas a la vez.

Las columnas de las [tablas temporales](/es/reference/statements/create/table/temporary-table) solo son visibles en `system.columns` en las sesiones en las que se han creado. Se muestran con el campo `database` vacío.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/es/reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/reference/data-types/string)) — Nombre de la tabla.
* `name` ([String](/es/reference/data-types/string)) — Nombre de la columna.
* `type` ([String](/es/reference/data-types/string)) — Tipo de columna.
* `position` ([UInt64](/es/reference/data-types/int-uint)) — Posición ordinal de una columna en una tabla, comenzando por 1.
* `default_kind` ([String](/es/reference/data-types/string)) — Tipo de expresión (DEFAULT, MATERIALIZED, ALIAS) del valor predeterminado, o una cadena vacía si no se ha definido.
* `default_expression` ([String](/es/reference/data-types/string)) — Expresión del valor predeterminado, o una cadena vacía si no se ha definido.
* `data_compressed_bytes` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de los datos comprimidos, en bytes.
* `data_uncompressed_bytes` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de los datos descomprimidos, en bytes.
* `marks_bytes` ([UInt64](/es/reference/data-types/int-uint)) — Tamaño de las marcas, en bytes.
* `comment` ([String](/es/reference/data-types/string)) — Comentario de la columna, o una cadena vacía si no se ha definido.
* `is_in_partition_key` ([UInt8](/es/reference/data-types/int-uint)) — Indicador que señala si la columna está incluida en la expresión de partición.
* `is_in_sorting_key` ([UInt8](/es/reference/data-types/int-uint)) — Indicador que señala si la columna está incluida en la expresión de clave de ordenación.
* `is_in_primary_key` ([UInt8](/es/reference/data-types/int-uint)) — Indicador que señala si la columna está incluida en la expresión de clave primaria.
* `is_in_sampling_key` ([UInt8](/es/reference/data-types/int-uint)) — Indicador que señala si la columna está incluida en la expresión de clave de muestreo.
* `compression_codec` ([String](/es/reference/data-types/string)) — Nombre del códec de compresión.
* `character_octet_length` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Longitud máxima en bytes de datos binarios, datos de caracteres, datos de texto e imágenes. En ClickHouse, solo tiene sentido para el tipo de datos FixedString. De lo contrario, se devuelve el valor NULL.
* `numeric_precision` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Precisión de los datos numéricos aproximados, numéricos exactos, enteros o monetarios. En ClickHouse, corresponde al ancho en bits para los tipos enteros y a la precisión decimal para los tipos Decimal. De lo contrario, se devuelve el valor NULL.
* `numeric_precision_radix` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Base del sistema numérico de los datos numéricos aproximados, numéricos exactos, enteros o monetarios. En ClickHouse, es 2 para los tipos enteros y 10 para los tipos Decimal. De lo contrario, se devuelve el valor NULL.
* `numeric_scale` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Escala de los datos numéricos aproximados, numéricos exactos, enteros o monetarios. En ClickHouse, solo tiene sentido para los tipos Decimal. De lo contrario, se devuelve el valor NULL.
* `datetime_precision` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Precisión decimal del tipo de datos DateTime64. Para otros tipos de datos, se devuelve el valor NULL.
* `serialization_hint` ([Nullable(String)](/es/reference/data-types/nullable)) — Sugerencia para que la columna elija la serialización durante los inserts según las estadísticas.
* `statistics` ([String](/es/reference/data-types/string)) — Tipos de estadísticas creadas en estas columnas.

**Alias:**

* `column` — Alias de `name`.

{/*AUTOGENERATED_END*/}
