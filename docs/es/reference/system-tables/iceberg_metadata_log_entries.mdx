## Descripción {#description}

Esta tabla del sistema contiene los archivos de metadatos de las tablas Iceberg existentes en ClickHouse, con una fila por cada archivo de metadatos. Si no tiene ninguna tabla Iceberg en ClickHouse, estará vacía.

## Columnas {#columns}

* `database` ([String](/es/reference/data-types/string)) — Nombre de la base de datos.
* `table` ([String](/es/reference/data-types/string)) — Nombre de la tabla.
* `timestamp` ([DateTime64(3)](/es/reference/data-types/datetime64)) — Fecha y hora en que este archivo de metadatos pasó a ser el vigente.
* `file` ([String](/es/reference/data-types/string)) — Ruta del archivo de metadatos.
* `latest_snapshot_id` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — ID de la instantánea más reciente en el momento en que se creó este archivo de metadatos.
* `latest_schema_id` ([Nullable(Int32)](/es/reference/data-types/nullable)) — ID de esquema de la instantánea más reciente.
* `latest_sequence_number` ([Nullable(Int64)](/es/reference/data-types/nullable)) — Número de secuencia de la instantánea más reciente.
