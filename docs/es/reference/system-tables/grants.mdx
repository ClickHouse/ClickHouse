* `access_object` ([String](/es/reference/data-types/string)) — Parámetro de access&#95;type. Contiene: 1 - Nombre del tipo de origen para privilegios READ/WRITE.2 - Nombre del motor de la tabla para privilegios TABLE ENGINE.3 - Nombre del usuario para privilegios como `SET DEFINER`.
* `database` ([Nullable(String)](/es/reference/data-types/nullable)) — Nombre de la base de datos.
* `table` ([Nullable(String)](/es/reference/data-types/nullable)) — Nombre de la tabla.

* `is_partial_revoke` ([UInt8](/es/reference/data-types/int-uint)) — Valor lógico. Indica si se han revocado privilegios. Valores posibles: 0 — La fila describe un otorgamiento, 1 — La fila describe una revocación parcial.
* `grant_option` ([UInt8](/es/reference/data-types/int-uint)) — Se ha otorgado el permiso con WITH GRANT OPTION.
* `is_wildcard` ([UInt8](/es/reference/data-types/int-uint)) — Valor lógico. Indica si el otorgamiento es un otorgamiento de prefijo con comodín. Valores posibles: 0 — La fila no describe un otorgamiento de prefijo con comodín, 1 — La fila describe un otorgamiento de prefijo con comodín (p. ej., db*.* o foo.bar*).
