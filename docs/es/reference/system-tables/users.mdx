<div id="description">
  ## Descripción
</div>

Contiene una lista de [cuentas de usuario](/es/concepts/features/security/access-rights#user-account-management) configuradas en el servidor.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `name` ([String](/es/reference/data-types/string)) — Nombre de usuario.
* `id` ([UUID](/es/reference/data-types/uuid)) — ID de usuario.
* `storage` ([String](/es/reference/data-types/string)) — Ruta del almacenamiento de usuarios. Se configura en el parámetro access&#95;control&#95;path.
* `auth_type` ([Array(Enum8(&#39;no&#95;password&#39; = 0, &#39;plaintext&#95;password&#39; = 1, &#39;sha256&#95;password&#39; = 2, &#39;double&#95;sha1&#95;password&#39; = 3, &#39;ldap&#39; = 4, &#39;kerberos&#39; = 5, &#39;ssl&#95;certificate&#39; = 6, &#39;bcrypt&#95;password&#39; = 7, &#39;ssh&#95;key&#39; = 8, &#39;http&#39; = 9, &#39;jwt&#39; = 10, &#39;scram&#95;sha256&#95;password&#39; = 11, &#39;no&#95;authentication&#39; = 12))](/es/reference/data-types/array)) — Muestra los tipos de autenticación. Hay varias formas de identificar a los usuarios: sin contraseña, con contraseña de texto sin formato, con contraseña codificada con SHA256, con contraseña codificada con doble SHA-1 o con contraseña codificada con bcrypt.
* `auth_params` ([Array(String)](/es/reference/data-types/array)) — Parámetros de autenticación en formato JSON según el tipo de autenticación.
* `valid_until` ([Array(DateTime64(0))](/es/reference/data-types/array)) — Fecha y hora de vencimiento de las credenciales de usuario, una por cada método de autenticación. El valor almacenado es un instante absoluto representado en la zona horaria del servidor o de la sesión; el valor almacenado `0` (la época Unix, representada como `1970-01-01 00:00:00` en un servidor en `UTC`) es el valor centinela que indica que las credenciales nunca vencen.
* `auth_grants` ([Array(String)](/es/reference/data-types/array)) — Para cada método de autenticación: el límite de los derechos de acceso especificado en la cláusula `GRANTS`, o una cadena vacía si los derechos de acceso no están limitados.
* `host_ip` ([Array(String)](/es/reference/data-types/array)) — Direcciones IP de los hosts que pueden conectarse al servidor ClickHouse.
* `host_names` ([Array(String)](/es/reference/data-types/array)) — Nombres de los hosts que pueden conectarse al servidor ClickHouse.
* `host_names_regexp` ([Array(String)](/es/reference/data-types/array)) — Expresión regular para los nombres de los hosts que pueden conectarse al servidor ClickHouse.
* `host_names_like` ([Array(String)](/es/reference/data-types/array)) — Nombres de los hosts que pueden conectarse al servidor ClickHouse, establecidos mediante el predicado LIKE.
* `default_roles_all` ([UInt8](/es/reference/data-types/int-uint)) — Indica que todos los roles concedidos están configurados como predeterminados para el usuario.
* `default_roles_list` ([Array(String)](/es/reference/data-types/array)) — Lista de roles concedidos configurados como predeterminados.
* `default_roles_except` ([Array(String)](/es/reference/data-types/array)) — Todos los roles concedidos configurados como predeterminados, excepto los enumerados.
* `grantees_any` ([UInt8](/es/reference/data-types/int-uint)) — Indicador que señala si un usuario con cualquier opción de concesión puede concederla a cualquiera.
* `grantees_list` ([Array(String)](/es/reference/data-types/array)) — Lista de usuarios o roles a los que este usuario puede conceder opciones.
* `grantees_except` ([Array(String)](/es/reference/data-types/array)) — Lista de usuarios o roles a los que este usuario tiene prohibido conceder opciones.
* `default_database` ([String](/es/reference/data-types/string)) — Nombre de la base de datos predeterminada de este usuario.
