## Descripción {#description}

Contiene una lista de transacciones y su estado.

**Disponibilidad**

`system.transactions` se crea únicamente cuando está habilitada la opción de configuración del servidor `allow_experimental_transactions`. De forma predeterminada, la tabla no existe y las consultas sobre ella fallarán con `UNKNOWN_TABLE`. Habilítela en la configuración del servidor con:

```xml
<clickhouse>
    <allow_experimental_transactions>1</allow_experimental_transactions>
</clickhouse>
```

## Columnas {#columns}

* `tid` ([Tuple(UInt64, UInt64, UUID, Int64)](/es/reference/data-types/tuple)) — El identificador de la transacción.
* `tid_hash` ([UInt64](/es/reference/data-types/int-uint)) — El hash del identificador.
* `elapsed` ([Float64](/es/reference/data-types/float)) — El tiempo transcurrido de la transacción que se está procesando.
* `is_readonly` ([UInt8](/es/reference/data-types/int-uint)) — El indicador que muestra si la transacción ha ejecutado alguna operación de escritura.
* `state` ([Enum8(&#39;RUNNING&#39; = 0, &#39;COMMITTING&#39; = 1, &#39;COMMITTED&#39; = 2, &#39;ROLLED&#95;BACK&#39; = 3)](/es/reference/data-types/enum)) — El estado de la transacción. Valores posibles: RUNNING, COMMITTING, COMMITTED, ROLLED&#95;BACK.
