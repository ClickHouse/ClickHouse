## Descripción {#description}

Esta tabla muestra información de introspección combinada sobre ZooKeeper, y los nodos se toman de la configuración.

**Disponibilidad**

`system.zookeeper_info` solo existe cuando ClickHouse Keeper o ZooKeeper está configurado. En servidores donde no se ha configurado ninguno de los dos, la tabla no existe y las consultas contra ella fallarán con `UNKNOWN_TABLE`.

## Columnas {#columns}

* `zookeeper_cluster_name` ([String](/es/reference/data-types/string)) — Nombre del clúster de ZooKeeper.
* `host` ([String](/es/reference/data-types/string)) — El nombre del host o la IP del nodo de ZooKeeper al que se conectó ClickHouse.
* `port` ([UInt16](/es/reference/data-types/int-uint)) — El puerto del nodo de ZooKeeper al que se conectó ClickHouse.
* `index` ([Nullable(UInt8)](/es/reference/data-types/nullable)) — El índice del nodo de ZooKeeper al que se conectó ClickHouse. El índice proviene de la configuración de ZooKeeper. Si no hay conexión, esta columna es NULL.
* `is_connected` ([UInt8](/es/reference/data-types/int-uint)) — Indica si ZooKeeper está conectado.
* `is_readonly` ([Nullable(UInt8)](/es/reference/data-types/nullable)) — Indica si es de solo lectura.
* `version` ([Nullable(String)](/es/reference/data-types/nullable)) — La versión de ZooKeeper.
* `avg_latency` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — La latencia promedio.
* `max_latency` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — La latencia máxima.
* `min_latency` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — La latencia mínima.
* `packets_received` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de paquetes recibidos.
* `packets_sent` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de paquetes enviados.
* `outstanding_requests` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de solicitudes pendientes.
* `server_state` ([Nullable(String)](/es/reference/data-types/nullable)) — Estado del servidor.
* `is_leader` ([Nullable(UInt8)](/es/reference/data-types/nullable)) — Indica si este ZooKeeper es el líder.
* `znode_count` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de znodes.
* `watch_count` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de watches.
* `ephemerals_count` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de nodos efímeros.
* `approximate_data_size` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El tamaño aproximado de los datos.
* `followers` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Los followers del líder. Este campo solo lo expone el líder.
* `synced_followers` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Los followers sincronizados con el líder. Este campo solo lo expone el líder.
* `pending_syncs` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Las sincronizaciones pendientes del líder. Este campo solo lo expone el líder.
* `open_file_descriptor_count` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de file descriptors abiertos. Solo disponible en plataformas Unix.
* `max_file_descriptor_count` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo de file descriptors. Solo disponible en plataformas Unix.
* `connections` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Las conexiones a ZooKeeper.
* `outstanding` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — Las operaciones pendientes de ZooKeeper.
* `zxid` ([Nullable(Int64)](/es/reference/data-types/nullable)) — El zxid de ZooKeeper.
* `node_count` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número de nodos de ZooKeeper.
* `snapshot_dir_size` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El tamaño del directorio de snapshots de ZooKeeper.
* `log_dir_size` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El tamaño del directorio de logs de ZooKeeper.
* `first_log_idx` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El índice del primer log de ZooKeeper.
* `first_log_term` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El término del primer log de ZooKeeper.
* `last_log_idx` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El índice del último log de ZooKeeper.
* `last_log_term` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El término del último log de ZooKeeper.
* `last_committed_idx` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El último índice con commit de ZooKeeper.
* `leader_committed_log_idx` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El índice del log con commit del líder de ZooKeeper.
* `target_committed_log_idx` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El índice objetivo del log con commit de ZooKeeper.
* `last_snapshot_idx` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El índice del último snapshot de ZooKeeper.
