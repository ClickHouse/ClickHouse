<div id="description">
  ## Descripción
</div>

Contiene información sobre los valores máximos para todos los intervalos de todas las cuotas. A una cuota puede corresponderle cualquier número de filas, o ninguna.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `quota_name` ([String](/es/reference/data-types/string)) — Nombre de la cuota.
* `duration` ([UInt32](/es/reference/data-types/int-uint)) — Duración del intervalo de tiempo para calcular el consumo de recursos, en segundos.
* `is_randomized_interval` ([UInt8](/es/reference/data-types/int-uint)) — Valor booleano. Indica si el intervalo se aleatoriza. Si no se aleatoriza, el intervalo siempre comienza a la misma hora. Por ejemplo, un intervalo de 1 minuto siempre comienza en un minuto exacto (es decir, puede comenzar a las 11:20:00, pero nunca a las 11:20:01); un intervalo de un día siempre comienza a medianoche UTC. Si el intervalo se aleatoriza, el primer intervalo comienza en un momento aleatorio y los intervalos posteriores comienzan consecutivamente. Valores: 0 — El intervalo no se aleatoriza, 1 — El intervalo se aleatoriza.
* `max_queries` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de consultas de cualquier tipo que se pueden ejecutar.
* `max_query_selects` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de consultas SELECT que se pueden ejecutar.
* `max_query_inserts` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de consultas INSERT que se pueden ejecutar.
* `max_errors` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de consultas que generan un error dentro del período especificado.
* `max_result_rows` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número total máximo permitido de filas en el conjunto de resultados de todas las consultas dentro del período especificado.
* `max_result_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número total máximo permitido de bytes en el conjunto de resultados de todas las consultas dentro del período especificado.
* `max_read_rows` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de filas que se pueden leer durante la ejecución de todas las consultas dentro del período especificado.
* `max_read_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de bytes que se pueden leer durante la ejecución de todas las consultas dentro del período especificado.
* `max_execution_time` ([Nullable(Float64)](/es/reference/data-types/nullable)) — El tiempo máximo (en nanosegundos) permitido para ejecutar todas las consultas dentro del período especificado
* `max_written_bytes` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de bytes que se pueden escribir durante la ejecución de todas las consultas dentro del período especificado.
* `max_failed_sequential_authentications` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de fallos consecutivos de autenticación dentro del período especificado.
* `max_queries_per_normalized_hash` ([Nullable(UInt64)](/es/reference/data-types/nullable)) — El número máximo permitido de ejecuciones de una misma consulta normalizada dentro del período especificado.

{/*AUTOGENERATED_END*/}
