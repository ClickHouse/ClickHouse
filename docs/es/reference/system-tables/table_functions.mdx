## Descripción {#description}

Contiene una lista de todas las funciones de tabla disponibles y sus descripciones.

## Columnas {#columns}

* `name` ([String](/es/reference/data-types/string)) — Nombre de una función de tabla.
* `description` ([String](/es/reference/data-types/string)) — Descripción breve de una función de tabla.
* `allow_readonly` ([UInt8](/es/reference/data-types/int-uint)) — Indicador que señala si un usuario readonly puede utilizar esta función.
