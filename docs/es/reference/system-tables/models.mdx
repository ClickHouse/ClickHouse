## Descripción {#description}

<Warning>
  La integración con CatBoost se eliminó de ClickHouse y `system.models` ya no existe: al consultarla se produce el error `UNKNOWN_TABLE`. Esta página se conserva por la documentación que publicó; consulte la [descripción general de las tablas del sistema](/es/reference/system-tables/overview) para conocer las tablas disponibles actualmente.
</Warning>

Contenía una lista de los modelos de CatBoost cargados en la memoria de un `LibraryBridge`, junto con el momento en que se cargaron.

## Columnas {#columns}

{/*AUTOGENERATED_START*/}

* `model_path` ([String](/es/reference/data-types/string)) — Ruta del modelo entrenado.
* `type` ([String](/es/reference/data-types/string)) — Tipo de modelo. Actualmente, solo catboost.
* `loading_start_time` ([DateTime](/es/reference/data-types/datetime)) — Fecha y hora en que comenzó la carga del modelo.
* `loading_duration` ([Float32](/es/reference/data-types/float)) — Tiempo que tardó en cargarse el modelo.

{/*AUTOGENERATED_END*/}
