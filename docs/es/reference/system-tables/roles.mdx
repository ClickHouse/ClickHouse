## Descripción {#description}

Contiene información sobre los [roles](/es/concepts/features/security/access-rights#role-management) configurados.

## Columnas {#columns}

* `name` ([String](/es/reference/data-types/string)) — Nombre del rol.
* `id` ([UUID](/es/reference/data-types/uuid)) — ID del rol.
* `storage` ([String](/es/reference/data-types/string)) — Ruta del almacenamiento de roles. Se configura en el parámetro `access_control_path`.
