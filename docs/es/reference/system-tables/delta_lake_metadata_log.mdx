## Descripción {#description}

La tabla `system.delta_lake_metadata_log` registra los eventos de acceso y parsing de metadata de las tablas de Delta Lake leídas por ClickHouse. Proporciona información detallada sobre cada metadata file, lo que resulta útil para el debugging, la auditoría y la comprensión de la evolución de la table structure de Delta.

Esta tabla registra cada metadata file leído de las tablas de Delta Lake. Ayuda a los usuarios a rastrear cómo ClickHouse interpreta la metadata de las tablas Delta y a diagnosticar problemas relacionados con la schema evolution, la resolution de snapshots o el query plan.

Esta tabla está pensada principalmente para fines de debugging.

### Control del nivel de detalle del log {#controlling-log-verbosity}

Puede controlar qué eventos de metadata se registran mediante la configuración [`delta_lake_log_metadata`](/es/reference/settings/session-settings/delta-lake#delta_lake_log_metadata).

Para registrar toda la metadata utilizada en la consulta actual:

```sql
SELECT * FROM my_delta_table SETTINGS delta_lake_log_metadata = 1;

SYSTEM FLUSH LOGS delta_lake_metadata_log;

SELECT *
FROM system.delta_lake_metadata_log
WHERE query_id = '{previous_query_id}';
```

Se puede aplicar TRUNCATE o hacer drop de esta tabla en cualquier momento sin riesgo.

## Columnas {#columns}

* `hostname` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Nombre de host del servidor que ejecuta la consulta.
* `clickhouse_version` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Versión del servidor ClickHouse que generó la fila.
* `system_processor` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Arquitectura de CPU del servidor ClickHouse que generó la fila.
* `event_date` ([Date](/es/reference/data-types/date)) — Fecha de la entrada.
* `event_time` ([DateTime](/es/reference/data-types/datetime)) — Hora del evento.
* `query_id` ([String](/es/reference/data-types/string)) — ID de la consulta.
* `table_path` ([String](/es/reference/data-types/string)) — Ruta de la tabla.
* `file_path` ([String](/es/reference/data-types/string)) — Ruta del archivo.
* `content` ([String](/es/reference/data-types/string)) — Contenido en formato JSON.
