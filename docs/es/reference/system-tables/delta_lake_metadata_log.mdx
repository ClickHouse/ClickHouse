<div id="description">
  ## Descripción
</div>

Contiene el contenido de los archivos de metadatos de Delta.

Esta tabla se puede truncar o eliminar de forma segura en cualquier momento.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `hostname` ([LowCardinality(String)](/es/reference/data-types/lowcardinality)) — Nombre de host del servidor que ejecuta la consulta.
* `event_date` ([Date](/es/reference/data-types/date)) — Fecha de la entrada.
* `event_time` ([DateTime](/es/reference/data-types/datetime)) — Hora del evento.
* `query_id` ([String](/es/reference/data-types/string)) — ID de la consulta.
* `table_path` ([String](/es/reference/data-types/string)) — Ruta de la tabla.
* `file_path` ([String](/es/reference/data-types/string)) — Ruta del archivo.
* `content` ([String](/es/reference/data-types/string)) — Contenido en formato JSON.

{/*AUTOGENERATED_END*/}
