<div id="description">
  ## Descripción
</div>

Contiene información sobre las partes que actualmente se están moviendo entre segmentos y su progreso.

<div id="columns">
  ## Columnas
</div>

{/*AUTOGENERATED_START*/}

* `database` ([String](/es/reference/data-types/string)) — El nombre de la base de datos donde se realiza el traslado.
* `table` ([String](/es/reference/data-types/string)) — El nombre de la tabla donde se realiza el traslado.
* `task_name` ([String](/es/reference/data-types/string)) — El nombre de la tarea de traslado.
* `task_uuid` ([UUID](/es/reference/data-types/uuid)) — El identificador de la tarea de traslado.
* `create_time` ([DateTime](/es/reference/data-types/datetime)) — La hora en que se creó la tarea.
* `part_name` ([String](/es/reference/data-types/string)) — El nombre de la parte que se está trasladando.
* `part_uuid` ([UUID](/es/reference/data-types/uuid)) — El UUID de la parte que se está trasladando.
* `to_shard` ([String](/es/reference/data-types/string)) — El nombre del segmento de destino.
* `dst_part_name` ([String](/es/reference/data-types/string)) — El nombre de la parte resultante.
* `update_time` ([DateTime](/es/reference/data-types/datetime)) — La última vez que se realizó una actualización.
* `state` ([String](/es/reference/data-types/string)) — El estado actual del traslado.
* `rollback` ([UInt8](/es/reference/data-types/int-uint)) — El indicador que señala si se revirtió la operación.
* `num_tries` ([UInt32](/es/reference/data-types/int-uint)) — El número de intentos para completar la operación.
* `last_exception` ([String](/es/reference/data-types/string)) — El nombre de la última excepción, si la hubo.

{/*AUTOGENERATED_END*/}
