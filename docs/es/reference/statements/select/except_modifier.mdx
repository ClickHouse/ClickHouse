> Especifica los nombres de una o varias columnas que deben excluirse del resultado. Todos los nombres de columna coincidentes se omiten de la salida.

## Sintaxis {#syntax}

```sql
SELECT <expr> EXCEPT ( col_name1 [, col_name2, col_name3, ...] ) FROM [db.]table_name
```

Los paréntesis son opcionales cuando se excluye una sola columna.

## Ejemplos {#examples}

```sql title="Query"
SELECT * EXCEPT i FROM columns_transformers;
```

