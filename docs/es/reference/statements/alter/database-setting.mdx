Modifica los ajustes de un motor de base de datos. Los ajustes que se pueden modificar dependen del motor; no todos los motores ni todos los parámetros de configuración admiten modificaciones una vez creada la base de datos.

Esta sentencia modifica los ajustes del motor de base de datos, no los ajustes de sesión ni los valores predeterminados de las tablas de la base de datos.

## Sintaxis {#syntax}

```sql
ALTER DATABASE database_name [ON CLUSTER cluster]
MODIFY SETTING setting_name = value [, ...]
```

Use `ON CLUSTER` para ejecutar la sentencia en todos los anfitriones del cluster especificado.
La sentencia requiere el privilegio `ALTER DATABASE SETTINGS`.

## Ajustes compatibles {#supported-settings}

Consulte la documentación de cada motor de base de datos para conocer sus ajustes y restricciones. Por ejemplo:

* [`Atomic`](/es/reference/engines/database-engines/atomic) y [`Ordinary`](/es/reference/engines/database-engines/ordinary) permiten modificar `max_tables`.
* [`MaterializedPostgreSQL`](/es/reference/engines/database-engines/materialized-postgresql) permite modificar algunos ajustes de replicación, como `materialized_postgresql_max_block_size`.
* [`DataLakeCatalog`](/es/reference/engines/database-engines/datalake) permite modificar algunos ajustes del catálogo; los ajustes disponibles dependen del tipo de catálogo.

Si el motor o el parámetro de configuración no es compatible, se produce una excepción.

## Ejemplo {#example}

Cambie el número máximo de tablas de una base de datos `Atomic`:

```sql
CREATE DATABASE example_database ENGINE = Atomic;

ALTER DATABASE example_database MODIFY SETTING max_tables = 100;

SHOW CREATE DATABASE example_database;
```

Establezca `max_tables` en `0` para eliminar este límite a nivel de base de datos:

```sql
ALTER DATABASE example_database MODIFY SETTING max_tables = 0;
```
