```sql
EXISTS [TEMPORARY] [TABLE|DICTIONARY|DATABASE] [db.]name [INTO OUTFILE filename] [FORMAT format]
```

Devuelve una sola columna de tipo `UInt8`, que contiene el valor `0` si la tabla o la base de datos no existen, o `1` si la tabla existe en la base de datos especificada.

## Forma de subconsulta {#subquery-form}

El operador `EXISTS` comprueba si una subconsulta devuelve alguna fila. Devuelve `0` si el resultado de la subconsulta está vacío y `1` en caso contrario.

Puede usar `EXISTS` en una cláusula [`WHERE`](/es/reference/statements/select/where). La subconsulta no puede hacer referencia a tablas ni a columnas de la consulta externa.

**Sintaxis**

```sql
EXISTS(subquery)
```

**Ejemplos**

Comprobar si una subconsulta devuelve filas:

```sql title="Query"
SELECT
    EXISTS(SELECT * FROM numbers(10) WHERE number > 8),
    EXISTS(SELECT * FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─in(1, _subquery1)─┬─in(1, _subquery2)─┐
│                 1 │                 0 │
└───────────────────┴───────────────────┘
```

Utilice `EXISTS` en una cláusula `WHERE` con una subconsulta que devuelva varias filas:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 8)
```

```text title="Response"
┌─count()─┐
│      10 │
└─────────┘
```

Cuando el resultado de la subconsulta está vacío, `EXISTS` devuelve `0`:

```sql title="Query"
SELECT count()
FROM numbers(10)
WHERE EXISTS(SELECT number FROM numbers(10) WHERE number > 11)
```

```text title="Response"
┌─count()─┐
│       0 │
└─────────┘
```
