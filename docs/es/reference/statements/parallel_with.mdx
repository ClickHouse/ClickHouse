Permite ejecutar varias sentencias en paralelo.

## Sintaxis {#syntax}

```sql
statement1 PARALLEL WITH statement2 [PARALLEL WITH statement3 ...]
```

Ejecuta las sentencias `statement1`, `statement2`, `statement3`, ... en paralelo entre sí. Solo pueden combinarse sentencias que no devuelvan un conjunto de resultados ni esperen datos de entrada; consulte [Restricciones](#restrictions).

En muchos casos, ejecutar sentencias en paralelo puede ser más rápido que ejecutarlas simplemente en secuencia. Por ejemplo, `statement1 PARALLEL WITH statement2 PARALLEL WITH statement3` probablemente sea más rápido que `statement1; statement2; statement3`.

## Ejemplos {#examples}

Crea dos tablas en paralelo:

```sql
CREATE TABLE table1(x Int32) ENGINE = MergeTree ORDER BY tuple()
PARALLEL WITH
CREATE TABLE table2(y String) ENGINE = MergeTree ORDER BY tuple();
```

Elimina dos tablas en paralelo:

```sql
DROP TABLE table1
PARALLEL WITH
DROP TABLE table2;
```

## Restricciones {#restrictions}

Una sentencia que devuelve un conjunto de resultados, como `SELECT`, o que espera datos de entrada se rechaza con el error `INCORRECT_QUERY`.

Las sentencias DDL ejecutadas con [`ON CLUSTER`](/es/reference/statements/distributed-ddl) o a través del registro DDL de una base de datos [`Replicated`](/es/reference/engines/database-engines/replicated) devuelven una tabla de estado, por lo que también se rechazan, aunque solo después de haberse enviado a los anfitriones, que las ejecutan de todos modos. Pueden combinarse si [`distributed_ddl_output_mode`](/es/reference/settings/session-settings/distributed-ddl#distributed_ddl_output_mode) es `none` o `none_only_active`:

```sql
SET distributed_ddl_output_mode = 'none';

CREATE TABLE table1 ON CLUSTER default (x Int32) ENGINE = MergeTree ORDER BY tuple()
PARALLEL WITH
CREATE TABLE table2 ON CLUSTER default (y String) ENGINE = MergeTree ORDER BY tuple();
```

## Configuración {#settings}

La configuración [max&#95;threads](/es/reference/settings/session-settings/max-threads#max_threads) controla cuántos hilos se crean.

## Comparación con UNION {#comparison-with-union}

La cláusula `PARALLEL WITH` se parece un poco a [UNION](/es/reference/statements/select/union), que también ejecuta sus operandos en paralelo. Sin embargo, hay algunas diferencias:

* `PARALLEL WITH` no devuelve ningún resultado de la ejecución de sus operandos; solo puede relanzar una excepción si se produce alguna;
* `PARALLEL WITH` combina sentencias que no devuelven un conjunto de resultados ni esperan datos de entrada, mientras que `UNION` combina consultas `SELECT`.
