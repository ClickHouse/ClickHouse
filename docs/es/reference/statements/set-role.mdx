Activa los roles del usuario actual.

```sql
SET ROLE {DEFAULT | NONE | role [,...] | ALL | ALL EXCEPT role [,...]}
```

## SET DEFAULT ROLE {#set-default-role}

Establece los roles predeterminados de un usuario.

Los roles predeterminados se activan automáticamente cuando el usuario inicia sesión. Solo se pueden establecer como predeterminados los roles concedidos previamente. Si el rol no se ha concedido a un usuario, ClickHouse lanza una excepción.

```sql
SET DEFAULT ROLE {NONE | role [,...] | ALL | ALL EXCEPT role [,...]} TO {user|CURRENT_USER} [,...] [ON CLUSTER cluster_name]
```

`ON CLUSTER` puede indicarse justo después de `SET DEFAULT ROLE` o al final de la consulta, y hace que esta se ejecute en todos los
hosts del cluster. `CURRENT_USER` se resuelve en el initiator antes de que la consulta se distribuya. `SET ROLE` solo
modifica la sesión actual y, por lo tanto, no admite la cláusula `ON CLUSTER`.

## Ejemplos {#examples}

Asigna varios roles predeterminados a un usuario:

```sql
SET DEFAULT ROLE role1, role2, ... TO user
```

Establece como predeterminados todos los roles concedidos a un usuario:

```sql
SET DEFAULT ROLE ALL TO user
```

Elimine los roles predeterminados de un usuario:

```sql
SET DEFAULT ROLE NONE TO user
```

Establezca como predeterminados todos los roles concedidos, excepto los roles específicos `role1` y `role2`:

```sql
SET DEFAULT ROLE ALL EXCEPT role1, role2 TO user
```

Establezca roles predeterminados en todos los hosts de un cluster:

```sql
SET DEFAULT ROLE role1 TO user ON CLUSTER my_cluster
SET DEFAULT ROLE ON CLUSTER my_cluster role1 TO user
```
