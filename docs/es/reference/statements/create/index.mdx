Las sentencias CREATE crean (por ejemplo) nuevas [bases de datos](/es/reference/statements/create/database), [tablas](/es/reference/statements/create/table) y [vistas](/es/reference/statements/create/view).

**Sintaxis**

```sql
CREATE DATABASE ...
CREATE TABLE ...
CREATE VIEW ...
CREATE DICTIONARY ...
CREATE FUNCTION ...
CREATE NAMED COLLECTION ...
CREATE USER | ROLE | ROW POLICY | MASKING POLICY | QUOTA | SETTINGS PROFILE ...
```

**Relacionado:** `ATTACH`, `DROP`, `CREATE TABLE`, `CREATE DATABASE`, `CREATE VIEW`, `CREATE DICTIONARY`
