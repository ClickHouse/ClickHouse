Crea una nueva colección con nombre.

<Note>
  Las colecciones con nombre creadas mediante DDL se pueden habilitar en determinados servicios de ClickHouse Cloud. Contacte con Support para confirmar la disponibilidad.
</Note>

**Sintaxis**

```sql
CREATE [OR REPLACE] NAMED COLLECTION [IF NOT EXISTS] name [ON CLUSTER cluster] AS
key_name1 = 'some value' [[NOT] OVERRIDABLE],
key_name2 = 'some value' [[NOT] OVERRIDABLE],
key_name3 = 'some value' [[NOT] OVERRIDABLE],
...
```

`OR REPLACE` e `IF NOT EXISTS` no pueden usarse a la vez. Aplicar `CREATE OR REPLACE` a una colección existente
la reemplaza por completo: se eliminan las claves y los indicadores de sobrescritura que no figuren en la nueva definición.

Para sobrescribir una clave almacenada al usar la colección, se requiere el privilegio `SHOW NAMED COLLECTIONS SECRETS` sobre esa colección,
incluso en el caso de las claves marcadas como `OVERRIDABLE`. Las claves marcadas como `NOT OVERRIDABLE` no se pueden sobrescribir.
Las fuentes de diccionarios siguen la misma regla. El privilegio se comprueba cuando el diccionario se crea, se adjunta o se restaura.
Al cargar el diccionario, solo se aplica la restricción de las claves marcadas como `NOT OVERRIDABLE`.

**Ejemplo**

```sql
CREATE NAMED COLLECTION foobar AS a = '1', b = '2' OVERRIDABLE;
CREATE OR REPLACE NAMED COLLECTION foobar AS a = '2', c = '3';
```
