## direct {#direct}

El diccionario no se almacena en memoria y consulta directamente la fuente al procesar una solicitud.

La clave del diccionario es de tipo [UInt64](/es/reference/data-types/int-uint).

Solo la búsqueda por clave es selectiva. `dictGet` y las demás funciones de diccionario consultan la fuente para las claves solicitadas, pero leer el diccionario **como una tabla** no es una lectura por clave: `SELECT ... FROM <dictionary> WHERE key IN (...)` lee toda la fuente y filtra el resultado después, porque no se hace pushdown del filtro por clave hacia el diccionario. Utilice las funciones de diccionario cuando desee que se consulte la fuente para claves concretas.

Se admiten todos los tipos de [fuentes](/es/reference/statements/create/dictionary/sources/overview#dictionary-sources), excepto los archivos locales.

Ejemplo de configuración:

<Tabs>
  <Tab title="DDL">
    ```sql
    LAYOUT(DIRECT())
    ```
  </Tab>

  <Tab title="Archivo de configuración">
    ```xml
    <layout>
      <direct />
    </layout>
    ```
  </Tab>
</Tabs>
