Cancela la eliminación de la tabla.

A partir de la versión 23.3 de ClickHouse, puede recuperar una tabla de una base de datos `Atomic` con `UNDROP TABLE`
durante el período establecido por [`database_atomic_delay_before_drop_table_sec`](/es/reference/settings/server-settings/settings/other#database_atomic_delay_before_drop_table_sec) (8 minutos de forma predeterminada) después de ejecutar `DROP TABLE`.
Las tablas eliminadas de bases de datos `Atomic` se enumeran en `system.dropped_tables`.

Para una base de datos `Shared` en ClickHouse Cloud, este período se controla mediante [`database_shared_drop_table_delay_seconds`](/es/reference/settings/session-settings/database#database_shared_drop_table_delay_seconds), cuyo valor predeterminado es 8 horas.
Las tablas eliminadas de bases de datos `Shared` no se enumeran en `system.dropped_tables`.

Si tiene una vista materializada sin una cláusula `TO` asociada a la tabla eliminada, también tendrá que ejecutar UNDROP sobre la tabla interna de esa vista.

<Tip>
  Consulte también [DROP TABLE](/es/reference/statements/drop)
</Tip>

Sintaxis:

```sql
UNDROP TABLE [db.]name [UUID '<uuid>'] [ON CLUSTER cluster]
```

**Ejemplo**

```sql
CREATE TABLE tab
(
    `id` UInt8
)
ENGINE = MergeTree
ORDER BY id;

DROP TABLE tab;

SELECT *
FROM system.dropped_tables
FORMAT Vertical;
```
