## Cómo funciona la Memory {#how-it-works}

Un pequeño agente de Memory se ejecuta en paralelo a la conversación principal. Lee los mensajes recientes, decide qué merece la pena recordar y escribe entradas en un almacén por usuario.
En la siguiente conversación, esas entradas están disponibles como contexto al que el agente principal puede recurrir sin que usted tenga que repetir la información.

Para usted, esto se traduce en continuidad: indíquele una sola vez a un agente que prefiere la salida SQL en minúsculas y que su ejercicio fiscal termina en marzo, y las conversaciones futuras se comportarán en consecuencia.

## Administre sus memorias {#manage-your-memories}

Abra el panel de memoria desde el icono **Memorias** (cerebro) en la barra de navegación izquierda. El panel muestra sus memorias almacenadas, con controles para crear, editar, eliminar y filtrar entradas.

Memory es privada para cada usuario. Los agentes de otras personas nunca ven sus entradas, y sus agentes nunca ven las de los demás.

### Crear una memoria {#create-memory}

Haga clic en el botón **+** situado en la parte superior del panel para abrir el cuadro de diálogo **Create Memory**. Introduzca una **clave** (solo letras minúsculas y guiones bajos) y un **valor**, y después haga clic en **Create**.

## Activar o desactivar la Memory {#toggle-memory}

Active o desactive la Memory con la casilla **Usar Memory**, situada en la parte superior del panel de Memory. Desactívela cuando trate temas delicados que no quiera que se almacenen o en conversaciones puntuales en las que la personalización no aporte nada.

Con la Memory desactivada, el agente no lee ni escribe en su almacén de Memory.

## Buenas prácticas de Memory {#memory-best-practices}

Memory resulta útil para:

* Convenciones recurrentes: formatos de fecha preferidos, definiciones de negocio, patrones de nomenclatura.
* Contexto del proyecto: qué servicio o base de datos consulta habitualmente, qué dashboards le interesan.
* Estilo de comunicación: respuestas concisas o más extensas, con mucho código o con más prosa.

Memory no está pensada para usarse como una base de datos. Por ejemplo, no es el lugar donde volcar grandes cantidades de material de referencia.
Para ello, es preferible usar una [habilidad](/es/agents/builder/skills) o incorporar ese material en las instrucciones del agente.
Tampoco está pensada para recuperar información de chats anteriores; de eso ya se encarga el propio historial de conversaciones.
