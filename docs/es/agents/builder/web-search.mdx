La Búsqueda web permite que un agente obtenga información de la web pública durante una conversación. Utilícela para preguntas cuya respuesta deba estar actualizada: versiones recientes, documentación que se encuentra fuera de su servicio o una comprobación rápida en una fuente de referencia.

## Habilitarla {#enable-it}

En el Constructor de Agentes, habilite **Búsqueda web** en la sección **Capacidades**. Una vez habilitada, el agente decide cuándo realizar una búsqueda en función de la pregunta del usuario y de sus instrucciones. Se ejecuta la búsqueda, se extrae el contenido de los resultados y el contenido más relevante se incorpora al contexto del modelo.

## Cómo funciona una ronda de búsqueda {#how-a-search-round-works}

Cada búsqueda se ejecuta en tres etapas, que Cloud gestiona por usted:

1. **Búsqueda**: la consulta del agente se envía a un provider de búsqueda, que devuelve URL candidatas.
2. **Extracción**: se recuperan las páginas pertinentes y se extrae el texto relevante.
3. **Reordenación**: un modelo de reordenación puntúa los resultados para que el modelo vea primero los más útiles.

La respuesta del agente cita las URL que ha utilizado realmente.

## Cuándo usarlo {#when-to-use-it}

* Consultar notas de la versión o registros de cambios que no estén en su servicio.
* Contrastar un dato con una fuente que el modelo quizá no conozca.
* Incorporar a la conversación una entrada de blog o un documento públicos para analizarlos.

No lo utilice para preguntas que puedan responderse con sus datos o con el conocimiento propio del modelo. Cada ronda de búsqueda añade latencia.
