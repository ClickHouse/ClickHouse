Visión permite a los usuarios cargar imágenes para que un agente las analice. El agente pasa la imagen a un modelo con capacidad de visión, que describe o resume su contenido, o responde preguntas sobre ella.

## Activar las capacidades de visión {#enable-it}

Visión solo funciona con modelos que admiten imágenes de entrada. Si el modelo seleccionado no puede procesar imágenes de entrada, el control de carga del editor de mensajes aparece deshabilitado. Cambie a un modelo con capacidad de visión para volver a habilitarlo.

## Usar las capacidades de visión {#use-it}

Haga clic en el icono del clip, en la esquina inferior izquierda del editor de mensajes, y elija **Upload to Provider** para adjuntar una imagen: una captura de pantalla, una foto, un gráfico o un diagrama. A continuación, formule cualquier pregunta que requiera interpretar la imagen: *«¿Qué problema tiene este plan de consulta?»*, *«Transcribe el texto de esta captura de pantalla»* o *«Compara este panel de control con el de la semana pasada»*.

El agente trata la imagen como parte del contexto del mensaje, de modo que las preguntas de seguimiento en el mismo turno pueden hacer referencia a lo que ha visto sin necesidad de volver a cargarla.

## Combinar Visión con otras herramientas {#combine-with-other-tools}

Visión funciona bien junto con el [Intérprete de código](/es/agents/builder/code-interpreter) para análisis basados en imágenes (por ejemplo, el agente lee cifras de una captura de pantalla y luego ejecuta Python para calcular totales) y con la [Búsqueda web](/es/agents/builder/web-search) cuando una imagen hace referencia a algo que el modelo necesita buscar.
