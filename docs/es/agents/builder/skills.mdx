Una habilidad es un paquete de instrucciones reutilizable que un agente puede aplicar cuando lo necesite. Utilice habilidades para los procedimientos que se repiten en varios agentes —una guía de estilo de marca, una lista de verificación para revisiones de código, un runbook para un flujo de trabajo concreto— en lugar de duplicar las instrucciones en la instrucción del sistema de cada agente.

## Anatomía de una habilidad {#anatomy-of-a-skill}

Una habilidad es un archivo Markdown con un breve encabezado de frontmatter:

```markdown
---
name: revenue-report
description: Generates the weekly revenue report using our standard segments
always-apply: false
user-invocable: true
---

When asked to generate a revenue report:
1. Filter to the requested period.
2. Apply the standard MRR formula:
     SUM(CASE
       WHEN billing_cycle = 'monthly' THEN amount
       WHEN billing_cycle = 'yearly'  THEN amount / 12
       ELSE 0
     END)
3. Break down by segment: Enterprise, Mid-Market, SMB.
4. Render the result as a Markdown table.
```

Las opciones del frontmatter más importantes son:

* **`name`** - identificador en formato kebab-case.
* **`description`** - breve resumen que el modelo utiliza para decidir cuándo es relevante esta habilidad. Considérelo el campo más importante. Redáctelo con precisión; las descripciones vagas hacen que se invoque la habilidad equivocada.
* **`always-apply`** - cuando es `true`, la habilidad se precarga en cada turno en lugar de seleccionarse. Utilícelo con moderación: las habilidades always-apply consumen contexto en cada mensaje.
* **`user-invocable`** - cuando es `true` (el valor predeterminado), la habilidad aparece en la ventana emergente `$` para seleccionarla manualmente.

Puede empaquetar archivos complementarios junto con la habilidad (documentación de referencia, consultas de ejemplo, pequeños scripts) cargando un `.zip` que contenga el `SKILL.md` y sus recursos.

## Usar una habilidad {#use-a-skill}

Un agente puede recurrir a una habilidad en una conversación de tres maneras:

* **Invocación por el usuario**: pulse `$` en el cuadro de redacción y elija la habilidad en la ventana emergente. El contenido de la habilidad queda precargado para el siguiente turno.
* **Selección automática por el modelo**: en función de la `description` de la habilidad, el agente decide por sí mismo cuándo aplicarla.
* **Always-apply**: en las habilidades configuradas de este modo, el contenido se precarga en cada turno.

## Administrar habilidades {#manage-skills}

El panel de Habilidades de la consola de ClickHouse Cloud le permite crear habilidades en línea, cargar archivos `.md` o `.zip` y administrar qué habilidades están activas para su usuario. Las habilidades de su propiedad están activas de forma predeterminada; si desactiva una, se quitará de la ventana emergente y del catálogo del modelo sin eliminarse.

Las habilidades se pueden compartir con otros usuarios (consulte [uso compartido y acceso](/es/agents/sharing-and-access)).

## Habilidades frente a instrucciones {#skills-vs-instructions}

* Las **instrucciones del agente** definen qué es el agente y cómo se comporta en general. Están siempre activas para ese agente.
* Las **habilidades** son situacionales: se aplican cuando son pertinentes y se circunscriben a flujos de trabajo concretos.

Recurra a una habilidad cuando el mismo conjunto de instrucciones paso a paso se repita en varios agentes, o cuando quiera que se active solo ante solicitudes concretas del usuario y no en cada turno.
