[Striim for ClickHouse](https://www.striim.com/docs/striimforclickhouse/en/introducing-striim-for-clickhouse.html) es un servicio SaaS totalmente gestionado que incorpora a ClickHouse datos procedentes de bases de datos, almacenes de datos, lagos de datos y aplicaciones SaaS, incluidas fuentes empresariales como Oracle, Microsoft SQL Server y Snowflake. Cargue los registros existentes y, a continuación, utilice la Captura de Cambios de Datos (CDC) para transmitir en streaming inserciones, actualizaciones y eliminaciones, de modo que los datos de ClickHouse se mantengan al día para workloads de IA, dashboards y aplicaciones de datos.

Striim for ClickHouse se aloja en Striim Cloud sobre AWS, con registro en modalidad de autoservicio, facturación mensual según el uso y sin compromiso de permanencia anual. Regístrese en striim.com o a través de AWS Marketplace, inicie un período de prueba gratuito de 14 días y cree una canalización mediante un prompt en lenguaje natural, un asistente o el diseñador de flujos.

## Características principales {#key-features}

* **Captura de Cambios de Datos (CDC) y carga inicial:** Cargue los datos existentes y, a continuación, pase a la replicación continua en tiempo real de inserciones, actualizaciones y eliminaciones. Los asistentes automatizados de canalizaciones ayudan a crear y vincular ambas fases, y pasan automáticamente de la carga inicial a la replicación CDC.
* **Escritor de ClickHouse:** Elija el motor de tabla para cada canalización (`MergeTree`, `ReplacingMergeTree`, `CollapsingMergeTree`, `CoalescingMergeTree`, entre otros). Striim crea las tablas de destino, gestiona las actualizaciones y eliminaciones según el motor elegido y define las claves de ordenación.
* **Gestión de esquemas:** Creación automática del esquema de destino a partir del origen para las fuentes compatibles, y propagación de determinados cambios DDL (`CREATE TABLE`, `ADD COLUMN`, `ALTER TABLE ... MODIFY COLUMN`, `DROP COLUMN`, `DROP TABLE` y `TRUNCATE TABLE`) para las fuentes CDC compatibles.
* **Procesamiento in-flight:** Filtre, enriquezca y transforme los datos entre el origen y ClickHouse.
* **Operaciones asistidas por IA:** Striim Clara AI, un agente de IA conversacional, crea canalizaciones a partir de una descripción en lenguaje natural, informa del retraso y el caudal, y explica los fallos. Revise el resultado generado antes de implementarlo en producción.
* **Conectividad privada:** AWS PrivateLink, túneles SSH y listas de permitidos de IP para conectar con las fuentes y ClickHouse.
* **Monitorización y alertas:** Monitorización integrada de canalizaciones y alertas enviadas por correo electrónico, Slack, Microsoft Teams y la interfaz de usuario web de Striim.

## Consideraciones operativas {#operational-considerations}

* La entrega es at-least-once. Tras un reinicio o una recuperación, los eventos ya escritos pueden volver a escribirse. Los registros de datos resultantes dependen del motor de tabla (consulte [Cómo llegan los datos a ClickHouse](/es/integrations/connectors/data-ingestion/etl-tools/striim/get-started#how-data-lands-in-clickhouse)).
* La evolución del esquema no admite cambios de nombre de columnas ni cambios de nulabilidad, y no se aplica a destinos `AggregatingMergeTree`, `Replicated` o `Distributed`. `VersionedCollapsingMergeTree` y `GraphiteMergeTree` no son compatibles.
* Algunos tipos de origen no tienen equivalente en ClickHouse y se omiten durante la creación automática del esquema; por ejemplo, `SQL Server GEOGRAPHY`, `GEOMETRY`, `HIERARCHYID` y `SQL_VARIANT`; `Oracle BFILE`, `LONG`, `LONG RAW`, `SDO_GEOMETRY` y `UROWID`; `MySQL GEOMETRY` y `SET`.
