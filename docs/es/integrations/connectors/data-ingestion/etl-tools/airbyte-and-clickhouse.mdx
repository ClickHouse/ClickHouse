<Note>
  Ten en cuenta que los conectores de origen y destino de Airbyte para ClickHouse se encuentran actualmente en fase Alpha y no son adecuados para transferir grandes conjuntos de datos (&gt; 10 millones de filas)
</Note>

<a href="https://www.airbyte.com/" target="_blank">Airbyte</a> es una plataforma de integración de datos de código abierto. Permite crear canalizaciones de datos <a href="https://airbyte.com/blog/why-the-future-of-etl-is-not-elt-but-el" target="_blank">ELT</a> e incluye más de 140 conectores listos para usar. Este tutorial paso a paso muestra cómo conectar Airbyte a ClickHouse como destino y cargar un conjunto de datos de ejemplo.

<Steps>
  <Step title="Descargue y ejecute Airbyte" id="1-download-and-run-airbyte">
    1. Airbyte se ejecuta en Docker y utiliza `docker-compose`. Asegúrese de descargar e instalar las versiones más recientes de Docker.

    2. Despliegue Airbyte clonando el repositorio oficial de Github y ejecutando `docker-compose up` en su terminal favorita:

       ```bash
       git clone https://github.com/airbytehq/airbyte.git --depth=1
       cd airbyte
       ./run-ab-platform.sh
       ```

    3. Cuando aparezca el banner de Airbyte en la terminal, podrá conectarse a <a href="http://localhost:8000" target="_blank">localhost:8000</a>

       <div className="ch-image-lg">
         <Frame>
           ![Banner de Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_01.webp)
         </Frame>
       </div>

    <Note>
      También puede registrarse y utilizar <a href="https://docs.airbyte.com/" target="_blank">Airbyte Cloud</a>
    </Note>
  </Step>

  <Step title="Añadir ClickHouse como destino" id="2-add-clickhouse-as-a-destination">
    En esta sección, mostraremos cómo agregar una instancia de ClickHouse como destino.

    1. Inicie su servidor de ClickHouse (Airbyte es compatible con ClickHouse `21.8.10.19` o versiones posteriores) o inicie sesión en su cuenta de ClickHouse Cloud:

       ```bash
       clickhouse-server start
       ```

    2. En Airbyte, abra la página &quot;Destinations&quot; y agregue un nuevo destino:

       <div className="ch-image-lg">
         <Frame>
           ![Agregar un destino en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_02.webp)
         </Frame>
       </div>

    3. Seleccione ClickHouse en la lista desplegable &quot;Destination type&quot; y complete el formulario &quot;Set up the destination&quot; con el nombre del host y los puertos de ClickHouse, el nombre de la base de datos, el nombre de usuario y la contraseña. Indique también si se trata de una conexión SSL (equivalente al indicador `--secure` de `clickhouse-client`):

       <div className="ch-image-lg">
         <Frame>
           ![Creación del destino ClickHouse en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_03.webp)
         </Frame>
       </div>

    4. ¡Enhorabuena! Ya ha agregado ClickHouse como destino en Airbyte.

    <Note>
      Para usar ClickHouse como destino, el usuario que utilice debe tener permisos para crear bases de datos y tablas, así como para insertar filas. Recomendamos crear un usuario dedicado para Airbyte (p. ej., `my_airbyte_user`) con los siguientes permisos:

      ```sql
      CREATE USER 'my_airbyte_user'@'%' IDENTIFIED BY 'your_password_here';

      GRANT CREATE ON * TO my_airbyte_user;
      ```
    </Note>
  </Step>

  <Step title="Añada un conjunto de datos como fuente" id="3-add-a-dataset-as-a-source">
    El conjunto de datos de ejemplo que utilizaremos es <a href="/es/get-started/sample-datasets/nyc-taxi" target="_blank">New York City Taxi Data</a> (disponible en <a href="https://github.com/toddwschneider/nyc-taxi-data" target="_blank">Github</a>). En este tutorial, utilizaremos un subconjunto de este conjunto de datos correspondiente al mes de enero de 2022.

    1. En Airbyte, abra la página &quot;Sources&quot; y agregue una nueva fuente de tipo file.

       <div className="ch-image-lg">
         <Frame>
           ![Agregar una fuente en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_04.webp)
         </Frame>
       </div>

    2. Complete el formulario &quot;Set up the source&quot; asignando un nombre a la fuente e indicando la URL del archivo de NYC Taxi de enero de 2022 (véase a continuación). Asegúrese de seleccionar `parquet` como formato de archivo, `HTTPS Public Web` como Storage Provider y `nyc_taxi_2022` como Dataset Name.

       ```text
       https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2022-01.parquet
       ```

       <div className="ch-image-lg">
         <Frame>
           ![Creación de la fuente de ClickHouse en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_05.webp)
         </Frame>
       </div>

    3. ¡Enhorabuena! Ya ha agregado un archivo como fuente en Airbyte.
  </Step>

  <Step title="Cree una conexión y cargue el conjunto de datos en ClickHouse" id="4-create-a-connection-and-load-the-dataset-into-clickhouse">
    1. En Airbyte, seleccione la página &quot;Connections&quot; y añada una nueva conexión

    <div className="ch-image-lg">
      <Frame>
        ![Agregar una conexión en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_06.webp)
      </Frame>
    </div>

    2. Seleccione &quot;Use existing source&quot; y elija New York City Taxi Data; después, seleccione &quot;Use existing destination&quot; y elija su instancia de ClickHouse.

    3. Complete el formulario &quot;Set up the connection&quot; eligiendo una Replication Frequency (en este tutorial usaremos `manual`) y seleccione `nyc_taxi_2022` como el stream que desea sincronizar. Asegúrese de elegir `Normalized Tabular Data` en Normalization.

    <div className="ch-image-lg">
      <Frame>
        ![Creación de una conexión en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_07.webp)
      </Frame>
    </div>

    4. Una vez creada la conexión, haga clic en &quot;Sync now&quot; para iniciar la carga de datos (ya que seleccionamos `Manual` como frecuencia de replicación)

    <div className="ch-image-lg">
      <Frame>
        ![Sincronizar ahora en Airbyte](/images/integrations/data-ingestion/etl-tools/airbyte_08.webp)
      </Frame>
    </div>

    5. Sus datos comenzarán a cargarse; puede expandir la vista para ver los logs y el progreso de Airbyte. Cuando finalice la operación, verá el mensaje `Completed successfully` en los logs:

    <div className="ch-image-lg">
      <Frame>
        ![Completado correctamente](/images/integrations/data-ingestion/etl-tools/airbyte_09.webp)
      </Frame>
    </div>
