Confluent ofrece tres opciones para integrarse con ClickHouse:

* [ClickHouse Connect Sink en Confluent Cloud](/es/integrations/connectors/data-ingestion/kafka/confluent/confluent-cloud), el connector totalmente administrado
* [ClickHouse Connect Sink como Custom Connector en Confluent Cloud](/es/integrations/connectors/data-ingestion/kafka/confluent/custom-connector), en el que usted mismo sube el connector
* [HTTP Sink Connector para Confluent Platform](/es/integrations/connectors/data-ingestion/kafka/confluent/kafka-connect-http) que integra Apache Kafka con una API mediante HTTP o HTTPS

## ¿Qué opción de Confluent Cloud debo usar? {#which-confluent-cloud-option-should-i-use}

Las dos primeras opciones ejecutan el mismo ClickHouse Connect Sink en Confluent Cloud. La diferencia está en quién administra el connector:

* **Connector totalmente administrado**: Confluent instala y actualiza el connector por usted. Empiece por esta opción, salvo que necesite algo que no ofrezca.
* **Custom Connector**: usted mismo descarga una versión publicada del connector desde [GitHub](https://github.com/ClickHouse/clickhouse-kafka-connect/releases) y la sube a Confluent Cloud. Use esta opción cuando necesite una versión concreta del connector o quiera sobrescribir configuraciones que, con el connector totalmente administrado, solo pueden modificarse abriendo un caso de soporte con Confluent. Los Custom Connectors solo están disponibles en algunas regiones de AWS.
