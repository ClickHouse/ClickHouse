## Inicie o descargue DbVisualizer {#start-or-download-dbvisualizer}

DbVisualizer está disponible en https://www.dbvis.com/download/

<Steps>
  <Step title="Reúna los detalles de su conexión" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Gestión integrada del controlador JDBC" id="2-built-in-jdbc-driver-management">
    DbVisualizer incluye los controladores JDBC más actualizados para ClickHouse. Tiene una gestión completa de controladores JDBC integrada que apunta a las últimas releases, así como a versiones históricas de los controladores.

    <div className="ch-image-lg">
      <Frame>
        ![Interfaz de Driver Manager de DbVisualizer que muestra la configuración del controlador JDBC de ClickHouse](/images/integrations/sql-clients/dbvisualizer-driver-manager.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Conéctese a ClickHouse" id="3-connect-to-clickhouse">
    Para conectar una base de datos con DbVisualizer, primero debe crear y configurar una conexión de base de datos.

    1. Cree una nueva conexión desde **Database-&gt;Create Database Connection** y seleccione un controlador para su base de datos en el menú emergente.

    2. Se abrirá una pestaña **Object View** para la nueva conexión.

    3. Introduzca un nombre para la conexión en el campo **Name** y, opcionalmente, una descripción de la conexión en el campo **Notes**.

    4. Deje **Database Type** como **Auto Detect**.

    5. Si el controlador seleccionado en **Driver Type** aparece marcado con una marca de verificación verde, está listo para usarse. Si no aparece marcado con una marca de verificación verde, es posible que tenga que configurar el controlador en **Driver Manager**.

    6. Introduzca la información del Servidor de base de datos en los campos restantes.

    7. Verifique que pueda establecerse una conexión de red con la dirección y el puerto especificados haciendo clic en el botón **Ping Server**.

    8. Si el resultado de Ping Server muestra que se puede acceder al Servidor, haga clic en **Connect** para conectarse al Servidor de base de datos.

    <Tip>
      Consulte [Solucionar problemas de conexión](https://www.dbvis.com/docs/ug/troubleshooting/fixing-connection-issues/) para ver algunos consejos si tiene problemas para conectarse a la base de datos.
    </Tip>
  </Step>
</Steps>
