[Splunk](https://www.splunk.com/) es una plataforma de análisis de datos y monitorización.

Este complemento le permite almacenar los [registros de auditoría de ClickHouse Cloud](/es/products/cloud/reference/security/audit-logging) en Splunk. Utiliza la [ClickHouse Cloud API](/es/products/cloud/features/admin-features/api/api-overview) para descargar los registros de auditoría.

Este complemento solo incluye una entrada modular; no proporciona ninguna UI adicional.

<div id="installation">
  # Instalación {#installation}
</div>

## Para Splunk Enterprise {#for-splunk-enterprise}

Descargue el ClickHouse Cloud Audit Add-on for Splunk desde [Splunkbase](https://splunkbase.splunk.com/app/7709).

<div className="ch-image-lg">
  <Frame>
    ![Sitio web de Splunkbase con la página de descarga del ClickHouse Cloud Audit Add-on for Splunk](/images/integrations/tools/data-integration/splunk/splunk_001.webp)
  </Frame>
</div>

En Splunk Enterprise, vaya a Apps -&gt; Manage y, a continuación, haga clic en Install app from file.

<div className="ch-image-lg">
  <Frame>
    ![Interfaz de Splunk Enterprise con la página de administración de aplicaciones y la opción Install app from file](/images/integrations/tools/data-integration/splunk/splunk_002.webp)
  </Frame>
</div>

Seleccione el archivo comprimido que descargó de Splunkbase y haga clic en Upload.

<div className="ch-image-lg">
  <Frame>
    ![Cuadro de diálogo de instalación de aplicaciones de Splunk para cargar el complemento de ClickHouse](/images/integrations/tools/data-integration/splunk/splunk_003.webp)
  </Frame>
</div>

Si todo ha ido bien, debería ver instalada la aplicación ClickHouse Audit logs. De lo contrario, consulte los logs de Splunkd para detectar posibles errores.

<div id="modular-input-configuration">
  # Configuración de la entrada modular {#modular-input-configuration}
</div>

Para configurar la entrada modular, primero necesitarás cierta información de tu despliegue de ClickHouse Cloud:

* El ID de la organización
* Una [API Key de administrador](/es/products/cloud/features/admin-features/api/openapi)

## Obtener información de ClickHouse Cloud {#getting-information-from-clickhouse-cloud}

Inicie sesión en la [consola de ClickHouse Cloud](https://console.clickhouse.cloud/).

Vaya a Organization -&gt; Organization details. Allí podrá copiar el ID de la organización.

<div className="ch-image-lg">
  <Frame>
    ![Consola de ClickHouse Cloud que muestra la página Organization details con el ID de la organización](/images/integrations/tools/data-integration/splunk/splunk_004.webp)
  </Frame>
</div>

Luego, en el menú lateral izquierdo, vaya a API Keys.

<div className="ch-image-lg">
  <Frame>
    ![Consola de ClickHouse Cloud que muestra la sección API Keys en el menú de navegación izquierdo](/images/integrations/tools/data-integration/splunk/splunk_005.webp)
  </Frame>
</div>

Cree una API Key, asígnele un nombre descriptivo y seleccione privilegios de `Admin`. Haga clic en Generate API Key.

<div className="ch-image-lg">
  <Frame>
    ![Consola de ClickHouse Cloud que muestra la interfaz de creación de una API Key con privilegios de Administrador seleccionados](/images/integrations/tools/data-integration/splunk/splunk_006.webp)
  </Frame>
</div>

Guarde la API Key y el secreto en un lugar seguro.

<div className="ch-image-lg">
  <Frame>
    ![Consola de ClickHouse Cloud que muestra la API Key generada y el secreto que deben guardarse](/images/integrations/tools/data-integration/splunk/splunk_007.webp)
  </Frame>
</div>

## Configurar la entrada de datos en Splunk {#configure-data-input-in-splunk}

De vuelta en Splunk, vaya a Settings -&gt; Data inputs.

<div className="ch-image-lg">
  <Frame>
    ![Interfaz de Splunk que muestra el menú Settings con la opción Data inputs](/images/integrations/tools/data-integration/splunk/splunk_008.webp)
  </Frame>
</div>

Seleccione la entrada de datos ClickHouse Cloud Audit Logs.

<div className="ch-image-lg">
  <Frame>
    ![Página Data inputs de Splunk que muestra la opción ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_009.webp)
  </Frame>
</div>

Haga clic en «New» para configurar una nueva instancia de la entrada de datos.

<div className="ch-image-lg">
  <Frame>
    ![Interfaz de Splunk para configurar una nueva entrada de datos ClickHouse Cloud Audit Logs](/images/integrations/tools/data-integration/splunk/splunk_010.webp)
  </Frame>
</div>

Cuando haya introducido toda la información, haga clic en Next.

<div className="ch-image-lg">
  <Frame>
    ![Página de configuración de Splunk con los ajustes de la entrada de datos de ClickHouse ya completados](/images/integrations/tools/data-integration/splunk/splunk_011.webp)
  </Frame>
</div>

La entrada ya está configurada y puede empezar a consultar los registros de auditoría.

# Uso {#usage}

La entrada modular almacena los datos en Splunk. Para verlos, puede usar la vista de búsqueda general de Splunk.
