[arcodash](https://www.arcodash.com/connectors/clickhouse/?utm_source=clickhouse-docs\&utm_medium=docs\&utm_campaign=growth-v2\&utm_content=clickhouse-docs-integration) es una herramienta de BI alojada con comprobaciones de datos integradas: dashboards SQL, un asistente de consultas con IA y comprobaciones programadas que envían alertas por correo electrónico, Slack, Teams, webhook o PagerDuty. Se conecta a ClickHouse a través de la interfaz HTTP(S).

<Steps>
  <Step title="Reúna sus datos de conexión" id="1-gather-your-connection-details">
    <ConnectionDetails />

    arcodash necesita el host, el puerto HTTP (`8123`, o `8443` para ClickHouse Cloud con HTTPS), el usuario, la contraseña y la base de datos.
  </Step>

  <Step title="Cree un usuario de solo lectura" id="2-create-a-read-only-user">
    ```sql
    CREATE USER arcodash_ro IDENTIFIED BY 'change-me' SETTINGS readonly = 1;
    GRANT SELECT ON analytics.* TO arcodash_ro;
    GRANT SELECT ON system.columns TO arcodash_ro;
    ```

    El explorador de esquemas lee `system.columns`.
  </Step>

  <Step title="Añada el conector" id="3-add-the-connector">
    En arcodash, elija **Connect** &gt; **ClickHouse** e introduzca el host, el puerto, el usuario, la contraseña y la base de datos. Active HTTPS para ClickHouse Cloud y, a continuación, ejecute la prueba de conexión.

    <Image size="lg" img="/images/integrations/data-visualization/arcodash_01.png" alt="Formulario del conector de ClickHouse en arcodash" border />
  </Step>

  <Step title="Ejecute una consulta y una comprobación" id="4-run-a-query-and-a-check">
    ```sql
    SELECT dateDiff('second', max(loaded_at), now()) AS seconds_since_last_row
    FROM analytics.events
    ```

    Guarde la consulta como monitor sobre `seconds_since_last_row` con la condición `>` `3600` para recibir una alerta cuando una tabla deje de recibir datos.

    <Image size="lg" img="/images/integrations/data-visualization/arcodash_02.png" alt="Monitor de arcodash sobre una consulta de ClickHouse" border />
  </Step>
</Steps>

## Limitaciones {#limitations}

* arcodash solo utiliza la interfaz HTTP, no el puerto nativo `9000`.
* arcodash añade automáticamente una cláusula `FORMAT`, por lo que las consultas no deben terminar con su propia cláusula `FORMAT`.
* Los resultados están limitados a 10,000 filas por consulta.
* arcodash no publica direcciones IP salientes fijas, por lo que el servidor de ClickHouse debe ser accesible desde internet.
