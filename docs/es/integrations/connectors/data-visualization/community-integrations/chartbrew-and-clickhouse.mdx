[Chartbrew](https://chartbrew.com) es una plataforma de visualización de datos que te permite crear dashboards y supervisar los datos en tiempo real. Admite múltiples fuentes de datos, entre ellas ClickHouse, y ofrece una interfaz sin código para crear gráficos e informes.

## Objetivo {#goal}

En esta guía, conectarás Chartbrew a ClickHouse, ejecutarás una consulta SQL y crearás una visualización. Al final, tu dashboard podría verse así:

<div className="ch-image-lg">
  <Frame>
    ![Dashboard de Chartbrew](/images/integrations/data-visualization/chartbrew_01.webp)
  </Frame>
</div>

<Tip>
  **Agrega algunos datos**

  Si no tienes un conjunto de datos con el que trabajar, puedes agregar uno de los conjuntos de datos de ejemplo. Esta guía utiliza el conjunto de datos [UK Price Paid](/es/get-started/sample-datasets/uk-price-paid).
</Tip>

<Steps>
  <Step title="Reúna sus datos de conexión" id="1-gather-your-connection-details">
    <ConnectionDetails />
  </Step>

  <Step title="Conectar Chartbrew a ClickHouse" id="2-connect-chartbrew-to-clickhouse">
    1. Inicie sesión en [Chartbrew](https://chartbrew.com/login) y vaya a la pestaña **Connections**.

    2. Haga clic en **Create connection** y seleccione **ClickHouse** entre las opciones de base de datos disponibles.

       <div className="ch-image-lg">
         <Frame>
           ![Selección de la conexión de ClickHouse en Chartbrew](/images/integrations/data-visualization/chartbrew_02.webp)
         </Frame>
       </div>

    3. Introduzca los datos de conexión de su base de datos en ClickHouse:

       * **Display Name**: nombre con el que se identificará la conexión en Chartbrew.
       * **Host**: nombre del host o dirección IP de su servidor de ClickHouse.
       * **Port**: normalmente `8443` para conexiones HTTPS.
       * **Database Name**: base de datos a la que desea conectarse.
       * **Username**: su nombre de usuario de ClickHouse.
       * **Password**: su contraseña de ClickHouse.

       <div className="ch-image-lg">
         <Frame>
           ![Configuración de la conexión de ClickHouse en Chartbrew](/images/integrations/data-visualization/chartbrew_03.webp)
         </Frame>
       </div>

    4. Haga clic en **Test connection** para comprobar que Chartbrew puede conectarse a ClickHouse.

    5. Si la prueba es satisfactoria, haga clic en **Save connection**. Chartbrew obtendrá automáticamente el esquema de ClickHouse.

       <div className="ch-image-lg">
         <Frame>
           ![Esquema JSON de ClickHouse en Chartbrew](/images/integrations/data-visualization/chartbrew_04.webp)
         </Frame>
       </div>
  </Step>

  <Step title="Crear un conjunto de datos y ejecutar una consulta SQL" id="3-create-a-dataset-and-run-a-sql-query">
    1. Haga clic en el botón **Create dataset** o vaya a la pestaña **Datasets** para crear uno.
    2. Seleccione la conexión de ClickHouse que creó anteriormente.

    <div className="ch-image-lg">
      <Frame>
        ![Selección de la conexión de ClickHouse para el conjunto de datos](/images/integrations/data-visualization/chartbrew_05.webp)
      </Frame>
    </div>

    Escriba una consulta SQL que obtenga los datos que desea visualizar. Por ejemplo, esta consulta calcula el precio medio pagado por año a partir del conjunto de datos `uk_price_paid`:

    ```sql
    SELECT toYear(date) AS year, avg(price) AS avg_price
    FROM uk_price_paid
    GROUP BY year
    ORDER BY year;
    ```

    <div className="ch-image-lg">
      <Frame>
        ![Consulta SQL de ClickHouse en Chartbrew](/images/integrations/data-visualization/chartbrew_07.webp)
      </Frame>
    </div>

    Haga clic en **Run query** para obtener los datos.

    Si no sabe bien cómo escribir la consulta, puede usar el **asistente de IA de Chartbrew** para generar consultas SQL a partir del esquema de su base de datos.

    <div className="ch-image-lg">
      <Frame>
        ![Asistente de IA para SQL de ClickHouse en Chartbrew](/images/integrations/data-visualization/chartbrew_06.webp)
      </Frame>
    </div>

    Una vez obtenidos los datos, haga clic en **Configure dataset** para definir los parámetros de la visualización.
  </Step>

  <Step title="Crear una visualización" id="4-create-a-visualization">
    1. Defina una métrica (valor numérico) y una dimensión (valor categórico) para su visualización.
    2. Previsualice el conjunto de datos para comprobar que los resultados de la consulta tienen la estructura correcta.
    3. Elija un tipo de gráfico (p. ej., gráfico de líneas, gráfico de barras, gráfico circular) y agréguelo a su panel de control.
    4. Haga clic en **Complete dataset** para finalizar la configuración.

    <div className="ch-image-lg">
      <Frame>
        ![Panel de control de Chartbrew con datos de ClickHouse](/images/integrations/data-visualization/chartbrew_08.webp)
      </Frame>
    </div>

    Puede crear tantos conjuntos de datos como necesite para visualizar distintos aspectos de sus datos. A partir de ellos, puede crear varios dashboards para hacer seguimiento de diferentes métricas.

    <div className="ch-image-lg">
      <Frame>
        ![Panel de control de Chartbrew con datos de ClickHouse](/images/integrations/data-visualization/chartbrew_01.webp)
      </Frame>
    </div>
  </Step>

  <Step title="Automatizar las actualizaciones de datos" id="5-automate-data-updates">
    Para mantener su panel de control al día, puede programar actualizaciones automáticas de los datos:

    1. Haga clic en el icono de calendario situado junto al botón de actualización del conjunto de datos.
    2. Configure el intervalo de actualización (por ejemplo, cada hora o cada día).
    3. Guarde la configuración para activar la actualización automática.

    <div className="ch-image-lg">
      <Frame>
        ![Configuración de actualización del conjunto de datos en Chartbrew](/images/integrations/data-visualization/chartbrew_09.webp)
      </Frame>
    </div>
  </Step>
</Steps>
