<div id="clickhouse-release-v256541-stable-533d68057fc-fixme-as-compared-to-v256412-stable-c3c91c0239e">
  ### Lanzamiento de ClickHouse v25.6.5.41-stable (533d68057fc) FIXME en comparación con v25.6.4.12-stable (c3c91c0239e)
</div>

<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#82862](https://github.com/ClickHouse/ClickHouse/issues/82862): Después de [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834), se modificaron los formatos de los encabezados `X-ClickHouse-Progress` y `X-ClickHouse-Summary` para omitir los valores cero. Este PR busca restaurar el comportamiento anterior solo para `X-ClickHouse-Summary`, porque es lo que tiene sentido. [#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#84037](https://github.com/ClickHouse/ClickHouse/issues/84037): Se utiliza información de cgroup (si corresponde; es decir, si `memory_worker_use_cgroup` está habilitado y los cgroups están disponibles) para ajustar el memory tracker (`memory_worker_correct_memory_tracker`). [#83981](https://github.com/ClickHouse/ClickHouse/pull/83981) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#83144](https://github.com/ClickHouse/ClickHouse/issues/83144): No usar partes no relacionadas de un diccionario compartido en la función `lowCardinalityKeys`. [#83118](https://github.com/ClickHouse/ClickHouse/pull/83118) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#83766](https://github.com/ClickHouse/ClickHouse/issues/83766): Corrección en Keeper: actualizar correctamente el recuento total de watch cuando se eliminan nodos efímeros al cerrar la sesión. [#83583](https://github.com/ClickHouse/ClickHouse/pull/83583) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#84109](https://github.com/ClickHouse/ClickHouse/issues/84109): Ocultar los detalles de authentication del schema registry de Avro para que no sean visibles para el usuario ni en los logs. [#83713](https://github.com/ClickHouse/ClickHouse/pull/83713) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Retroportado en [#83917](https://github.com/ClickHouse/ClickHouse/issues/83917): Se corrige el issue por el que, si una tabla MergeTree se crea con `add_minmax_index_for_numeric_columns=1` o `add_minmax_index_for_string_columns=1`, el índice se materializa posteriormente durante una operación ALTER, lo que impide que la base de datos Replicated se inicialice correctamente en una nueva réplica. [#83751](https://github.com/ClickHouse/ClickHouse/pull/83751) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado en [#83874](https://github.com/ClickHouse/ClickHouse/issues/83874): Se introduce una configuración de compatibilidad con versiones anteriores para permitir que el nuevo analyzer haga referencia a un alias externo en la cláusula WITH en caso de conflicto de nombres. Corrige [#82700](https://github.com/ClickHouse/ClickHouse/issues/82700). [#83797](https://github.com/ClickHouse/ClickHouse/pull/83797) ([Dmitry Novik](https://github.com/novikd)).
* Retroportado en [#84092](https://github.com/ClickHouse/ClickHouse/issues/84092): Al restaurar desde una copia de seguridad, puede que el usuario definidor no se haya incluido en la copia, lo que haría que toda la copia de seguridad quedara inutilizable. Para solucionarlo, posponemos la comprobación de permisos al crear la tabla de destino durante la restauración y la realizamos solo en runtime. [#83818](https://github.com/ClickHouse/ClickHouse/pull/83818) ([pufit](https://github.com/pufit)).
* Retroportado en [#84224](https://github.com/ClickHouse/ClickHouse/issues/84224): Permitir hacer referencia a cualquier tabla en el argumento `view(...)` de la table function `remote` con el analyzer habilitado. Corrige [#78717](https://github.com/ClickHouse/ClickHouse/issues/78717). Corrige [#79377](https://github.com/ClickHouse/ClickHouse/issues/79377). [#83844](https://github.com/ClickHouse/ClickHouse/pull/83844) ([Dmitry Novik](https://github.com/novikd)).
* Retroportado en [#84129](https://github.com/ClickHouse/ClickHouse/issues/84129): Se corrige un error poco frecuente por el que la consulta `MATERIALIZE COLUMN` podía provocar archivos inesperados en `checksums.txt` y, con el tiempo, data parts detached. [#84007](https://github.com/ClickHouse/ClickHouse/pull/84007) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#84272](https://github.com/ClickHouse/ClickHouse/issues/84272): Se corrigen resultados erróneos cuando la query condition cache se usa junto con CTE recursivas (issue [#81506](https://github.com/ClickHouse/ClickHouse/issues/81506)). [#84026](https://github.com/ClickHouse/ClickHouse/pull/84026) ([zhongyuankai](https://github.com/zhongyuankai)).
* Retroportado en [#84288](https://github.com/ClickHouse/ClickHouse/issues/84288): Se corrige un fallo poco frecuente de ClickHouse cuando una tabla tiene una proyección, `lightweight_mutation_projection_mode = 'rebuild'` y el usuario ejecuta un borrado ligero que elimina TODAS las filas de cualquier bloque de la tabla. [#84158](https://github.com/ClickHouse/ClickHouse/pull/84158) ([alesapin](https://github.com/alesapin)).
