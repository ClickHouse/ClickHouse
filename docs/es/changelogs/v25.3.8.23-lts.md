[#88746](https://github.com/ClickHouse/ClickHouse/pull/88746) ([YenchangChan](https://github.com/YenchangChan)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#88220](https://github.com/ClickHouse/ClickHouse/issues/88220): Corrige un `crash` por el que algunos datos válidos enviados por usuarios a una columna `AggregateFunction(quantileDD)` podían hacer que las merges entraran en recursión infinita. [#86560](https://github.com/ClickHouse/ClickHouse/pull/86560) ([Raphaël Thériault](https://github.com/raphael-theriault-swi)).
* Retroportado en [#88598](https://github.com/ClickHouse/ClickHouse/issues/88598): Corrige la resolución del esquema de la tabla con la table function `url()` cuando el ajuste `parallel_replicas_for_cluster_functions` está establecido en 1. [#87029](https://github.com/ClickHouse/ClickHouse/pull/87029) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Retroportado en [#88647](https://github.com/ClickHouse/ClickHouse/issues/88647): Los clusters grandes con números de nodo &gt; 10 tienen una alta probabilidad de que falle la restauración con el error `[941] 67c45db4-4df4-4879-87c5-25b8d1e0d414 <Trace>: RestoreCoordinationOnCluster The version of node /clickhouse/backups/restore-7c551a77-bd76-404c-bad0-3213618ac58e/stage/num_hosts changed (attempt #9), will try again`. El nodo `num_hosts` se sobrescribe por muchos hosts al mismo tiempo. La corrección hace dinámico el ajuste que controla los intentos. Cierra [#87721](https://github.com/ClickHouse/ClickHouse/issues/87721). [#88484](https://github.com/ClickHouse/ClickHouse/pull/88484) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado en [#88712](https://github.com/ClickHouse/ClickHouse/issues/88712): Corrige un posible `crash` causado por la mutation concurrente de columnas PREWHERE const subyacentes. [#88605](https://github.com/ClickHouse/ClickHouse/pull/88605) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#88902](https://github.com/ClickHouse/ClickHouse/issues/88902): Después de recuperarse, una réplica de una base de datos Replicated podía quedarse atascada durante mucho tiempo imprimiendo mensajes como `Failed to marked query-0004647339 as finished (finished=No node, synced=No node)`; ya está corregido. [#88671](https://github.com/ClickHouse/ClickHouse/pull/88671) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#88886](https://github.com/ClickHouse/ClickHouse/issues/88886): Corrige la validación de acceso para select en la table function `loop`. [#88802](https://github.com/ClickHouse/ClickHouse/pull/88802) ([pufit](https://github.com/pufit)).
* Retroportado en [#89033](https://github.com/ClickHouse/ClickHouse/issues/89033): Corrige un error en la función `reverseUTF8`. En versiones anteriores, invertía por error los bytes de los code points UTF-8 de longitud 4. Esto cierra [#88913](https://github.com/ClickHouse/ClickHouse/issues/88913). [#88914](https://github.com/ClickHouse/ClickHouse/pull/88914) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
