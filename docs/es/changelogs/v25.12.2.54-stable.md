<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Retroportado en [#93224](https://github.com/ClickHouse/ClickHouse/issues/93224): Habilita de forma predeterminada los datos compartidos avanzados para JSON. Tras este cambio, no será posible volver a versiones <25.8, porque esas versiones no podrán leer las nuevas partes de datos con columna JSON. Para realizar actualizaciones seguras, se recomienda establecer la configuración `compatibility` en la versión anterior o configurar los ajustes de MergeTree `dynamic_serialization_version='v2', object_serialization_version='v2'`. [#92511](https://github.com/ClickHouse/ClickHouse/pull/92511) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#93061](https://github.com/ClickHouse/ClickHouse/issues/93061): Revierte "Allow INSERT into simple ALIAS columns" (revierte ClickHouse/ClickHouse[#84154](https://github.com/ClickHouse/ClickHouse/issues/84154)). No funciona con formats personalizados y no está protegido mediante una configuración. [#92849](https://github.com/ClickHouse/ClickHouse/pull/92849) ([Azat Khuzhin](https://github.com/azat)).

  #### Mejora del rendimiento
</div>

* Retroportado en [#92711](https://github.com/ClickHouse/ClickHouse/issues/92711): Optimiza la función de agregación distinctJSONPaths para que lea solo las rutas JSON de las partes de datos, y no toda la columna JSON. [#92196](https://github.com/ClickHouse/ClickHouse/pull/92196) ([Pavel Kruglov](https://github.com/Avogar)).

<div id="improvement">
  #### Mejora

* Retroportado en [#92604](https://github.com/ClickHouse/ClickHouse/issues/92604): Añade una columna de creación (implícita/explícita) a system.data_skipping_indices. [#92378](https://github.com/ClickHouse/ClickHouse/pull/92378) ([Raúl Marín](https://github.com/Algunenano)).
* Retroportado en [#93377](https://github.com/ClickHouse/ClickHouse/issues/93377): Recurre a la copia en modo read-write para Azure Blob Storage cuando la copia nativa falla con BadRequest (p. ej., una lista de bloques no válida). Antes esto solo se hacía para el error Unauthorized, que se observaba al copiar un blob entre distintas storage accounts. Pero también a veces aparece el error "The specified block list is invalid". Por ello, ahora se ha actualizado la condición para recurrir a read & write en todos los fallos de copia nativa. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado en [#93015](https://github.com/ClickHouse/ClickHouse/issues/93015): Registra las tareas en segundo plano que son más lentas que la media (`background_schedule_pool_log.duration_threshold_milliseconds=30`) para evitar un registro excesivo de tareas. [#92965](https://github.com/ClickHouse/ClickHouse/pull/92965) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#93338](https://github.com/ClickHouse/ClickHouse/issues/93338): Añade compatibilidad con geometry type para `flipCoordinates`. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).
* Retroportado en [#93395](https://github.com/ClickHouse/ClickHouse/issues/93395): Mejora la experiencia de usuario de SYSTEM INSTRUMENT ADD/REMOVE: usa literales String para los nombres de función, aplica el parche a todas las funciones coincidentes y permite usar function_name en `REMOVE`. [#93345](https://github.com/ClickHouse/ClickHouse/pull/93345) ([Pablo Marcos](https://github.com/pamarcos)).
