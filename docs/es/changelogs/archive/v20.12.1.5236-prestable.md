<div id="clickhouse-release-v201215236-prestable-fixme-as-compared-to-v201115109-prestable">
  ### Lanzamiento de ClickHouse v20.12.1.5236-prestable FIXME en comparación con v20.11.1.5109-prestable
</div>

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Acepta configuraciones de usuario relacionadas con formatos de archivo (por ejemplo, `format_csv_delimiter`) en la cláusula `SETTINGS` al crear una tabla que usa el motor `File`, y utiliza estas configuraciones en todos los `INSERT` y `SELECT`. Las configuraciones de formato de archivo cambiadas en la sesión del usuario actual, o en la cláusula `SETTINGS` de una propia consulta DML, ya no afectan a la consulta. [#16591](https://github.com/ClickHouse/ClickHouse/pull/16591) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Habilita `use_compact_format_in_distributed_parts_names` de forma predeterminada (consulta la documentación de referencia). [#16728](https://github.com/ClickHouse/ClickHouse/pull/16728) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Se añadió la nueva sintaxis ALTER UPDATE/DELETE IN PARTITION. [#13403](https://github.com/ClickHouse/ClickHouse/pull/13403) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Añade el motor StorageEmbeddedRocksdb. [#15073](https://github.com/ClickHouse/ClickHouse/pull/15073) ([sundyli](https://github.com/sundy-li)).
* Introduce la consulta `ALTER TABLE ... DROP|DETACH PART 'part_name'`. [#15511](https://github.com/ClickHouse/ClickHouse/pull/15511) ([nvartolomei](https://github.com/nvartolomei)).
* Permite cambiar la ruta del archivo de historial en `clickhouse-client` usando el parámetro `--history_file`. [#15960](https://github.com/ClickHouse/ClickHouse/pull/15960) ([Maksim Kita](https://github.com/kitaisreal)).
* Se actualizó el formato de DateTime y DateTime64 para aceptar literales Date en formato String. [#16040](https://github.com/ClickHouse/ClickHouse/pull/16040) ([Maksim Kita](https://github.com/kitaisreal)).
* Añade la configuración `aggregate_functions_null_for_empty`; esta opción reescribe todas las funciones de agregación de una consulta, añadiéndoles el sufijo -OrNull. corrige [10273](https://github.com/ClickHouse/ClickHouse/issues/10273). [#16123](https://github.com/ClickHouse/ClickHouse/pull/16123) ([flynn](https://github.com/ucasfl)).
* Añade compatibilidad con COLLATE para Nullable, LowCardinality, Array y Tuple, cuando el tipo anidado es String. También refactoriza el código asociado con las intercalaciones en ColumnString.cpp. [#16273](https://github.com/ClickHouse/ClickHouse/pull/16273) ([Kruglov Pavel](https://github.com/Avogar)).
* Posibilidad de distribuir las fusiones entre diferentes réplicas. Introduce la configuración de MergeTree `execute_merges_on_single_replica_time_threshold`. [#16424](https://github.com/ClickHouse/ClickHouse/pull/16424) ([filimonov](https://github.com/filimonov)).
* Añade compatibilidad con compresión/descompresión `*.xz`. Permite usar `*.xz` en la función `file()`. Esto cierra [#8828](https://github.com/ClickHouse/ClickHouse/issues/8828). [#16578](https://github.com/ClickHouse/ClickHouse/pull/16578) ([Abi Palagashvili](https://github.com/fibersel)).
* Añade nuevas funciones `cmath`: - acosh - asinh - atan2 - atanh - cosh - hypot - log1p - sinh. [#16636](https://github.com/ClickHouse/ClickHouse/pull/16636) ([Konstantin Malanchev](https://github.com/hombit)).
* Añade la posibilidad de introducir el valor de un enum como su id en los formatos TSV y CSV de forma predeterminada. [#16834](https://github.com/ClickHouse/ClickHouse/pull/16834) ([Kruglov Pavel](https://github.com/Avogar)).
* La nueva función tcpPort() devuelve el puerto TCP en el que escucha este servidor. [#17134](https://github.com/ClickHouse/ClickHouse/pull/17134) ([Ivan](https://github.com/abyss7)).



<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Ahora podemos descartar particiones de forma segura con coincidencia exacta. Caso de uso útil: suponga que la tabla está particionada por intHash64(x) % 100 y que la consulta tiene una condición sobre intHash64(x) % 100 de forma textual, no sobre x. [#16253](https://github.com/ClickHouse/ClickHouse/pull/16253) ([Amos Bird](https://github.com/amosbird)).
* Se utiliza el algoritmo de Floyd-Rivest; debería ser el más adecuado para el caso de uso de ordenación parcial en ClickHouse. Las pruebas comparativas están en https://github.com/danlark1/miniselect y [aquí](https://drive.google.com/drive/folders/1DHEaeXgZuX6AJ9eByeZ8iQVQv0ueP8XM). [#16825](https://github.com/ClickHouse/ClickHouse/pull/16825) ([Daniel Kutenin](https://github.com/danlark1)).



<div id="improvement">
  #### Mejora
</div>

* Se añade la descripción de subconsulta `VIEW` a `EXPLAIN`. Se limita la optimización de empuje hacia abajo para `VIEW`. Se añaden réplicas locales de `Distributed` al plan de consulta. [#14936](https://github.com/ClickHouse/ClickHouse/pull/14936) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Se hace que `indexOf()` utilice BloomFilter. [#14977](https://github.com/ClickHouse/ClickHouse/pull/14977) ([achimbab](https://github.com/achimbab)).
* Se lanza una excepción sobre los privilegios de sincronización correctos cuando el usuario de sincronización de MySQL tiene privilegios incorrectos. [#15977](https://github.com/ClickHouse/ClickHouse/pull/15977) ([TCeason](https://github.com/TCeason)).
* Se corrige un posible desbordamiento de pila si se crea un ciclo de vistas materializadas. Cierra el issue [#15732](https://github.com/ClickHouse/ClickHouse/issues/15732). [#16048](https://github.com/ClickHouse/ClickHouse/pull/16048) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se añade soporte de SNI en conexiones HTTPS a recursos remotos. Esto permitirá conectarse a servidores de Cloudflare que requieren SNI. Corrige el issue [#10055](https://github.com/ClickHouse/ClickHouse/issues/10055). [#16252](https://github.com/ClickHouse/ClickHouse/pull/16252) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Ahora la familia de motores `ReplicatedMergeTree` utiliza un grupo de hilos independiente para las recuperaciones replicadas. El tamaño del grupo está limitado por la configuración `background_fetches_pool_size`, que puede ajustarse reiniciando el servidor. El valor predeterminado es 3, lo que significa que el número máximo de recuperaciones paralelas es 3 (lo que permite aprovechar una red de 10G). Corrige el issue #520. [#16390](https://github.com/ClickHouse/ClickHouse/pull/16390) ([alesapin](https://github.com/alesapin)).
* Ahora la configuración `<auxiliary_zookeepers>` puede modificarse en `config.xml` y recargarse sin reiniciar el servidor. [#16627](https://github.com/ClickHouse/ClickHouse/pull/16627) ([Amos Bird](https://github.com/amosbird)).
* Se permite la reinterpretación entre enteros y flotantes del mismo tamaño. Corrige el issue [16640](https://github.com/ClickHouse/ClickHouse/issues/16640). [#16657](https://github.com/ClickHouse/ClickHouse/pull/16657) ([flynn](https://github.com/ucasfl)).
* Solución alternativa para usar S3 con un servidor nginx como proxy. Nginx actualmente no acepta URLs con ruta vacía como `http://domain.com?delete`, pero la versión estándar de aws-sdk-cpp genera este tipo de URLs. Este cambio utiliza una versión parcheada de aws-sdk-cpp que genera URLs con "/" como ruta en estos casos, como `http://domain.com/?delete`. [#16709](https://github.com/ClickHouse/ClickHouse/pull/16709) ([ianton-ru](https://github.com/ianton-ru)).
* Se eliminan los directorios vacíos para inserciones asíncronas al iniciar el motor Distributed. [#16729](https://github.com/ClickHouse/ClickHouse/pull/16729) ([Azat Khuzhin](https://github.com/azat)).
* Mejora de usabilidad: sugerencias más claras en el mensaje de error de sintaxis cuando la expresión `CODEC` está mal ubicada en una consulta `CREATE TABLE`. Corrige el issue [#12493](https://github.com/ClickHouse/ClickHouse/issues/12493). [#16768](https://github.com/ClickHouse/ClickHouse/pull/16768) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se mejora el mensaje de excepción cuando la configuración para DDL distribuido no está presente. Corrige el issue [#5075](https://github.com/ClickHouse/ClickHouse/issues/5075). [#16769](https://github.com/ClickHouse/ClickHouse/pull/16769) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Se aplica `use_compact_format_in_distributed_parts_names` para cada INSERT (con internal_replication). [#16788](https://github.com/ClickHouse/ClickHouse/pull/16788) ([Azat Khuzhin](https://github.com/azat)).
* El servidor rechaza el inicio con un mensaje de excepción si se proporciona una configuración incorrecta (falta `metric_log`.`collect_interval_milliseconds`). [#16815](https://github.com/ClickHouse/ClickHouse/pull/16815) ([Ivan](https://github.com/abyss7)).
* Se añade `cutToFirstSignificantSubdomainWithWWW()`. [#16845](https://github.com/ClickHouse/ClickHouse/pull/16845) ([Azat Khuzhin](https://github.com/azat)).
* Se lanza un mensaje de error informativo al ejecutar ATTACH/DETACH TABLE <DICTIONARY>. Antes de este PR, `detach table <dict>` funcionaba pero generaba metadatos en memoria con formato incorrecto. [#16885](https://github.com/ClickHouse/ClickHouse/pull/16885) ([Amos Bird](https://github.com/amosbird)).
* Se eliminan las partes vacías tras ser descartadas por TTL, mutación o el algoritmo de fusión por colapso. [#16895](https://github.com/ClickHouse/ClickHouse/pull/16895) ([Anton Popov](https://github.com/CurtizJ)).
* Se permite conectarse al endpoint seguro de `clickhouse-server` que requiere SNI. Esto es posible cuando `clickhouse-server` está alojado detrás de un proxy TLS. [#16938](https://github.com/ClickHouse/ClickHouse/pull/16938) ([filimonov](https://github.com/filimonov)).
* Se establecen los parámetros predeterminados de `host` y `port` para `SOURCE(CLICKHOUSE(...))` a la instancia actual, y se establece el valor predeterminado de `user` como `'default'`. [#16997](https://github.com/ClickHouse/ClickHouse/pull/16997) ([Vladimir C](https://github.com/vdimir)).
* Se añade la posibilidad de generar todas las filas como un array JSON en el formato `JSONEachRow`, controlado por la configuración `output_format_json_array_of_rows`. [#17152](https://github.com/ClickHouse/ClickHouse/pull/17152) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Se permite formatear tuplas con nombre como objetos JSON al usar formatos de entrada/salida JSON, controlado por la configuración `output_format_json_named_tuples_as_objects`, deshabilitado por defecto. [#17175](https://github.com/ClickHouse/ClickHouse/pull/17175) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Se corrige la gramática en el mensaje de error de los formatos de entrada JSONEachRow, JSONCompactEachRow y RegexpRow. [#17205](https://github.com/ClickHouse/ClickHouse/pull/17205) ([nico piderman](https://github.com/sneako)).
