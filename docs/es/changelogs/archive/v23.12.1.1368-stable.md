<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Corrige la comprobación de funciones no deterministas en expresiones TTL. Anteriormente, en algunos casos se podía crear una expresión TTL con funciones no deterministas, lo que más adelante podía provocar un comportamiento indefinido. Esto corrige [#37250](https://github.com/ClickHouse/ClickHouse/issues/37250). De forma predeterminada, no se permiten expresiones TTL que no dependan de ninguna columna de una tabla. Se puede volver a permitir con `SET allow_suspicious_ttl_expressions = 1` o `SET compatibility = '23.11'`. Cierra [#37286](https://github.com/ClickHouse/ClickHouse/issues/37286). [#51858](https://github.com/ClickHouse/ClickHouse/pull/51858) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se elimina la función `arrayFold` porque tiene un bug. Esto cierra [#57816](https://github.com/ClickHouse/ClickHouse/issues/57816). Esto cierra [#57458](https://github.com/ClickHouse/ClickHouse/issues/57458). [#57836](https://github.com/ClickHouse/ClickHouse/pull/57836) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se elimina la funcionalidad de la fila `is_deleted` en ReplacingMergeTree y el modificador `CLEANUP` para la consulta `OPTIMIZE`. Esto corrige [#57930](https://github.com/ClickHouse/ClickHouse/issues/57930). Esto cierra [#54988](https://github.com/ClickHouse/ClickHouse/issues/54988). Esto cierra [#54570](https://github.com/ClickHouse/ClickHouse/issues/54570). Esto cierra [#50346](https://github.com/ClickHouse/ClickHouse/issues/50346). Esto cierra [#47579](https://github.com/ClickHouse/ClickHouse/issues/47579). Esta funcionalidad debe eliminarse porque no es adecuada. Tenemos que eliminarla lo antes posible porque no hay otra opción. [#57932](https://github.com/ClickHouse/ClickHouse/pull/57932) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* La configuración de MergeTree `clean_deleted_rows` está obsoleta; ya no tiene ningún efecto. La palabra clave `CLEANUP` para `OPTIMIZE` no está permitida de forma predeterminada (a menos que `allow_experimental_replacing_merge_with_cleanup` esté habilitado). [#58267](https://github.com/ClickHouse/ClickHouse/pull/58267) ([Alexander Tokmakov](https://github.com/tavplubix)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Permitir deshabilitar la solicitud HEAD antes de la solicitud GET. [#54602](https://github.com/ClickHouse/ClickHouse/pull/54602) ([Fionera](https://github.com/fionera)).
* Añadir un endpoint HTTP para comprobar si Keeper está listo para aceptar tráfico. [#55876](https://github.com/ClickHouse/ClickHouse/pull/55876) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Añadir el modo &#39;union&#39; para la inferencia de esquemas. En este modo, el esquema de tabla resultante es la unión de los esquemas de todos los archivos (es decir, el esquema se infiere de cada archivo). El modo de inferencia de esquemas se controla mediante el ajuste `schema_inference_mode`, con 2 valores posibles: `default` y `union`. Cierra [#55428](https://github.com/ClickHouse/ClickHouse/issues/55428). [#55892](https://github.com/ClickHouse/ClickHouse/pull/55892) ([Kruglov Pavel](https://github.com/Avogar)).
* Añadir el nuevo ajuste `input_format_csv_try_infer_numbers_from_strings`, que permite inferir números a partir de cadenas en formato CSV. Cierra [#56455](https://github.com/ClickHouse/ClickHouse/issues/56455). [#56859](https://github.com/ClickHouse/ClickHouse/pull/56859) ([Kruglov Pavel](https://github.com/Avogar)).
* Vistas materializadas actualizables. [#56946](https://github.com/ClickHouse/ClickHouse/pull/56946) ([Michael Kolupaev](https://github.com/al13n321)).
* Añadir más advertencias sobre la cantidad de bases de datos y tablas. [#57375](https://github.com/ClickHouse/ClickHouse/pull/57375) ([凌涛](https://github.com/lingtaolf)).
* Se añadió un nuevo comando de mutación `ALTER TABLE <table> APPLY DELETED MASK`, que permite forzar la aplicación de la máscara escrita por la eliminación ligera y eliminar del disco las filas marcadas como eliminadas. [#57433](https://github.com/ClickHouse/ClickHouse/pull/57433) ([Anton Popov](https://github.com/CurtizJ)).
* Se añadió una nueva función SQL `sqid` para generar Sqids ([https://sqids.org/](https://sqids.org/)); ejemplo: `SELECT sqid(125, 126)`. [#57512](https://github.com/ClickHouse/ClickHouse/pull/57512) ([Robert Schulze](https://github.com/rschu1ze)).
* El diccionario con layout `HASHED_ARRAY` (y `COMPLEX_KEY_HASHED_ARRAY`) admite `SHARDS`, de forma similar a `HASHED`. [#57544](https://github.com/ClickHouse/ClickHouse/pull/57544) ([vdimir](https://github.com/vdimir)).
* Añadir métricas asíncronas para el total de bytes de la clave primaria y el total de bytes asignados a la clave primaria en memoria. [#57551](https://github.com/ClickHouse/ClickHouse/pull/57551) ([Bharat Nallan](https://github.com/bharatnc)).
* La tabla system.dropped&#95;tables&#95;parts contiene partes de las tablas de system.dropped&#95;tables (tablas eliminadas, pero aún no retiradas). [#57555](https://github.com/ClickHouse/ClickHouse/pull/57555) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Añadir `FORMAT_BYTES` como alias de `formatReadableSize`. [#57592](https://github.com/ClickHouse/ClickHouse/pull/57592) ([Bharat Nallan](https://github.com/bharatnc)).
* Añadir la función SHA512&#95;256. [#57645](https://github.com/ClickHouse/ClickHouse/pull/57645) ([Bharat Nallan](https://github.com/bharatnc)).
* Permitir pasar un `SESSION&#95;TOKEN` opcional a la función de tabla `s3`. [#57850](https://github.com/ClickHouse/ClickHouse/pull/57850) ([Shani Elharrar](https://github.com/shanielh)).
* La cláusula `ORDER BY` ahora admite especificar `ALL`, lo que significa que ClickHouse ordena por todas las columnas de la cláusula `SELECT`. Ejemplo: `SELECT col1, col2 FROM tab WHERE [...] ORDER BY ALL`. [#57875](https://github.com/ClickHouse/ClickHouse/pull/57875) ([zhongyuankai](https://github.com/zhongyuankai)).
* Se añadieron funciones para la codificación y decodificación de punycode: `punycodeEncode()` y `punycodeDecode()`. [#57969](https://github.com/ClickHouse/ClickHouse/pull/57969) ([Robert Schulze](https://github.com/rschu1ze)).
* Esta PR vuelve a implementar `PASTE JOIN`, lo que permite a los usuarios unir tablas sin la cláusula `ON`. Ejemplo: &#96;&#96;&#96; SQL SELECT * FROM ( SELECT number AS a FROM numbers(2) ) AS t1 PASTE JOIN ( SELECT number AS a FROM numbers(2) ORDER BY a DESC ) AS t2. [#57995](https://github.com/ClickHouse/ClickHouse/pull/57995) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* El manejador `/binary` abre un visor de los símbolos dentro del binario de ClickHouse. [#58211](https://github.com/ClickHouse/ClickHouse/pull/58211) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* La copia entre discos S3 ahora utiliza una copia server-side de S3 en lugar de copiar a través del búfer. Esto mejora las operaciones `BACKUP/RESTORE` y el comando `clickhouse-disks copy`. [#56744](https://github.com/ClickHouse/ClickHouse/pull/56744) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* HashJoin respeta la configuración `max_joined_block_size_rows` y no produce bloques grandes para `ALL JOIN`. [#56996](https://github.com/ClickHouse/ClickHouse/pull/56996) ([vdimir](https://github.com/vdimir)).
* Libera memoria para la aggregation antes. Esto puede evitar external aggregation innecesaria. [#57691](https://github.com/ClickHouse/ClickHouse/pull/57691) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Mejora el rendimiento de la serialización de cadenas. [#57717](https://github.com/ClickHouse/ClickHouse/pull/57717) ([Maksim Kita](https://github.com/kitaisreal)).
* Añade compatibilidad con la optimización trivial de `count` para tablas con engine `Merge`. [#57867](https://github.com/ClickHouse/ClickHouse/pull/57867) ([skyoct](https://github.com/skyoct)).
* Se optimizó la aggregation en algunos casos. [#57872](https://github.com/ClickHouse/ClickHouse/pull/57872) ([Anton Popov](https://github.com/CurtizJ)).
* La función `hasAny()` ahora puede aprovechar los skipping indices de texto completo. [#57878](https://github.com/ClickHouse/ClickHouse/pull/57878) ([Jpnock](https://github.com/Jpnock)).
* La función `if(cond, then, else)` (y su alias `cond ? : then : else`) se optimizó para usar evaluación sin ramas. [#57885](https://github.com/ClickHouse/ClickHouse/pull/57885) ([zhanglistar](https://github.com/zhanglistar)).
* Extrae rangos de partes no superpuestas de una tabla MergeTree durante el procesamiento de FINAL. De este modo, se puede evitar lógica adicional de FINAL para esos rangos de partes no superpuestas. Cuando la cantidad de valores duplicados con la misma primary key es baja, el rendimiento será casi el mismo que sin FINAL. Mejora el rendimiento de lectura de MergeTree FINAL cuando está activada la configuración `do_not_merge_across_partitions_select_final`. [#58120](https://github.com/ClickHouse/ClickHouse/pull/58120) ([Maksim Kita](https://github.com/kitaisreal)).
* MergeTree deriva automáticamente la configuración `do_not_merge_across_partitions_select_final` si la expresión de la partition key contiene solo columnas de la expresión de la primary key. [#58218](https://github.com/ClickHouse/ClickHouse/pull/58218) ([Maksim Kita](https://github.com/kitaisreal)).
* Acelera MIN y MAX para tipos nativos. [#58231](https://github.com/ClickHouse/ClickHouse/pull/58231) ([Raúl Marín](https://github.com/Algunenano)).
