<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#40694](https://github.com/ClickHouse/ClickHouse/issues/40694): Se corrigen los paquetes TGZ. [#40681](https://github.com/ClickHouse/ClickHouse/pull/40681) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en la versión estable oficial)
</div>

* Retroportado en [#40451](https://github.com/ClickHouse/ClickHouse/issues/40451): Se corrige un bug poco frecuente con el TTL de columna en la familia de motores MergeTree: en caso de vertical merge repetido, podía producirse el error `Cannot unlink file ColumnName.bin ... No such file or directory.`. [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#40533](https://github.com/ClickHouse/ClickHouse/issues/40533): El resolvedor de proxy se detiene tras la primera solicitud exitosa al endpoint. [#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)).
* Retroportado en [#40625](https://github.com/ClickHouse/ClickHouse/issues/40625): Se corrige una posible pérdida de datos debida a un bug en el SDK de AWS ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)). El bug solo puede activarse cuando ClickHouse se usa con S3. [#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
