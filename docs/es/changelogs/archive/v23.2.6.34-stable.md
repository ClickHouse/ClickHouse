<div id="clickhouse-release-v232634-stable-570190045b0-fixme-as-compared-to-v232546-stable-b50faecbb12">
  ### Lanzamiento de ClickHouse v23.2.6.34-stable (570190045b0) FIXME en comparación con la versión v23.2.5.46-stable (b50faecbb12)
</div>

<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#48709](https://github.com/ClickHouse/ClickHouse/issues/48709): el Formatter &#39;%M&#39; de la función formatDateTime() ahora muestra el nombre del mes en lugar de los minutos. Esto hace que el comportamiento sea consistente con MySQL. El comportamiento anterior puede restaurarse mediante la configuración &quot;formatdatetime&#95;parsedatetime&#95;m&#95;is&#95;month&#95;name = 0&quot;. [#47246](https://github.com/ClickHouse/ClickHouse/pull/47246) ([Robert Schulze](https://github.com/rschu1ze)).

<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* retroportado en [#48587](https://github.com/ClickHouse/ClickHouse/issues/48587): Actualización de las zonas horarias. Se actualizaron las siguientes: Africa/Cairo, Africa/Casablanca, Africa/El&#95;Aaiun, America/Bogota, America/Cambridge&#95;Bay, America/Ciudad&#95;Juarez, America/Godthab, America/Inuvik, America/Iqaluit, America/Nuuk, America/Ojinaga, America/Pangnirtung, America/Rankin&#95;Inlet, America/Resolute, America/Whitehorse, America/Yellowknife, Asia/Gaza, Asia/Hebron, Asia/Kuala&#95;Lumpur, Asia/Singapore, Canada/Yukon, Egypt, Europe/Kirov, Europe/Volgograd, Singapore. [#48572](https://github.com/ClickHouse/ClickHouse/pull/48572) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* retroportado en [#48959](https://github.com/ClickHouse/ClickHouse/issues/48959): Después de la actualización reciente, `dockerd` requiere `--tlsverify=false` junto con el puerto HTTP especificado explícitamente. [#48924](https://github.com/ClickHouse/ClickHouse/pull/48924) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Se corrige una condición de carrera en grace hash join con límite [#47153](https://github.com/ClickHouse/ClickHouse/pull/47153) ([Vladimir C](https://github.com/vdimir)).
* Se corrige el grafo de EXPLAIN con proyección [#47473](https://github.com/ClickHouse/ClickHouse/pull/47473) ([flynn](https://github.com/ucasfl)).
* Se corrige un crash en polygonsSymDifferenceCartesian [#47702](https://github.com/ClickHouse/ClickHouse/pull/47702) ([pufit](https://github.com/pufit)).
* Se elimina una funcionalidad [#48195](https://github.com/ClickHouse/ClickHouse/pull/48195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se corrige el uso de CPU en rabbitmq (había empeorado en la versión 23.2 después de [#44404](https://github.com/ClickHouse/ClickHouse/issues/44404)) [#48311](https://github.com/ClickHouse/ClickHouse/pull/48311) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Error de inicio de ClickHouse al cargar una tabla distribuida que depende de un diccionario [#48419](https://github.com/ClickHouse/ClickHouse/pull/48419) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Se corrige un posible segfault en cache [#48469](https://github.com/ClickHouse/ClickHouse/pull/48469) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Se corrige un Map anidado para claves de tipo IP y UUID [#48556](https://github.com/ClickHouse/ClickHouse/pull/48556) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Se corrige un error en Keeper cuando, en ocasiones, no se crea un nodo con el scheme `auth` en la ACL. [#48595](https://github.com/ClickHouse/ClickHouse/pull/48595) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Se hace que IPv4 sea comparable con UInt [#48611](https://github.com/ClickHouse/ClickHouse/pull/48611) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
