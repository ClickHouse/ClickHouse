<div id="bug-fix-user-visible-misbehavior-in-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en la versión estable oficial)
</div>

* Retroportado en [#40542](https://github.com/ClickHouse/ClickHouse/issues/40542): Corrige un posible interbloqueo en WriteBufferFromS3 durante un fallo en la planificación de tareas. [#40070](https://github.com/ClickHouse/ClickHouse/pull/40070) ([Maksim Kita](https://github.com/kitaisreal)).
* Retroportado en [#40450](https://github.com/ClickHouse/ClickHouse/issues/40450): Corrige un bug poco frecuente con TTL de columna en la familia de motores MergeTree: en caso de fusión vertical repetida, podía producirse el error `Cannot unlink file ColumnName.bin ... No such file or directory.`. [#40346](https://github.com/ClickHouse/ClickHouse/pull/40346) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#40532](https://github.com/ClickHouse/ClickHouse/issues/40532): El resolvedor de proxy se detiene tras la primera request correcta al endpoint. [#40353](https://github.com/ClickHouse/ClickHouse/pull/40353) ([Maksim Kita](https://github.com/kitaisreal)).
* Retroportado en [#40624](https://github.com/ClickHouse/ClickHouse/issues/40624): Corrige una posible pérdida de datos debida a un bug en AWS SDK ([https://github.com/aws/aws-sdk-cpp/issues/658](https://github.com/aws/aws-sdk-cpp/issues/658)). El bug solo puede activarse cuando ClickHouse se usa con S3. [#40506](https://github.com/ClickHouse/ClickHouse/pull/40506) ([alesapin](https://github.com/alesapin)).
