<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#20678](https://github.com/ClickHouse/ClickHouse/issues/20678): Se marca el batch distribuido como dañado cuando uno de los archivos contiene un bloque de datos vacío. [#19449](https://github.com/ClickHouse/ClickHouse/pull/19449) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#20646](https://github.com/ClickHouse/ClickHouse/issues/20646): La función `greatCircleAngle` devolvía resultados inexactos en versiones anteriores. Esto cierra [#19769](https://github.com/ClickHouse/ClickHouse/issues/19769). [#19789](https://github.com/ClickHouse/ClickHouse/pull/19789) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#20507](https://github.com/ClickHouse/ClickHouse/issues/20507): Se corrigió el comportamiento por el cual, en caso de JSON dañado, se intentaba leer el archivo completo en memoria, lo que provocaba una excepción del allocator. Corrige [#19719](https://github.com/ClickHouse/ClickHouse/issues/19719). [#20286](https://github.com/ClickHouse/ClickHouse/pull/20286) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#20618](https://github.com/ClickHouse/ClickHouse/issues/20618): Comprueba si la table function `view` se usa en la lista de expresiones y lanza un error. Esto corrige [#20342](https://github.com/ClickHouse/ClickHouse/issues/20342). [#20350](https://github.com/ClickHouse/ClickHouse/pull/20350) ([Amos Bird](https://github.com/amosbird)).
* Retroportado en [#20488](https://github.com/ClickHouse/ClickHouse/issues/20488): Se corrige `LOGICAL_ERROR` para `join_use_nulls=1` cuando JOIN contiene una constante de SELECT. [#20461](https://github.com/ClickHouse/ClickHouse/pull/20461) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#20886](https://github.com/ClickHouse/ClickHouse/issues/20886): Se corrige una subconsulta con union distinct y cláusula limit. Cierra [#20597](https://github.com/ClickHouse/ClickHouse/issues/20597). [#20610](https://github.com/ClickHouse/ClickHouse/pull/20610) ([flynn](https://github.com/ucasfl)).
* Retroportado en [#20992](https://github.com/ClickHouse/ClickHouse/issues/20992): Se corrige el uso del combinador `-Distinct` con el combinador `-State` en funciones de agregación. [#20866](https://github.com/ClickHouse/ClickHouse/pull/20866) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#20988](https://github.com/ClickHouse/ClickHouse/issues/20988): La consulta `USE database;` no funcionaba al usar el client de MySQL 5.7 para conectarse al servidor ClickHouse; ya se ha corregido. Corrige [#18926](https://github.com/ClickHouse/ClickHouse/issues/18926). [#20878](https://github.com/ClickHouse/ClickHouse/pull/20878) ([Alexander Tokmakov](https://github.com/tavplubix)).
