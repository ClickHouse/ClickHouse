<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#62898](https://github.com/ClickHouse/ClickHouse/issues/62898): Se corrigió un bug en la replicación zero-copy (una funcionalidad experimental) que podía provocar errores `The specified key does not exist` y pérdida de datos después de REPLACE/MOVE PARTITION. Un problema similar podría ocurrir con los movimientos de TTL entre discos. [#54193](https://github.com/ClickHouse/ClickHouse/pull/54193) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#61964](https://github.com/ClickHouse/ClickHouse/issues/61964): Corrige la consulta ATTACH con la cláusula ON CLUSTER cuando la base de datos no existe en el nodo iniciador. Cierra [#55009](https://github.com/ClickHouse/ClickHouse/issues/55009). [#61365](https://github.com/ClickHouse/ClickHouse/pull/61365) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado en [#62527](https://github.com/ClickHouse/ClickHouse/issues/62527): Corrige una carrera de dato entre la consulta `MOVE PARTITION` y las operaciones de merge, que da lugar a partes que se intersecan. [#61610](https://github.com/ClickHouse/ClickHouse/pull/61610) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Retroportado en [#62238](https://github.com/ClickHouse/ClickHouse/issues/62238): Corrige la omisión de errores de análisis de secuencias de escape durante el análisis de datos JSON al usar la configuración `input_format_allow_errors_num/ratio`. [#61883](https://github.com/ClickHouse/ClickHouse/pull/61883) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#62673](https://github.com/ClickHouse/ClickHouse/issues/62673): Corrige un fallo de segmentación al usar el motor de tabla de Hive. Referencia: [#62154](https://github.com/ClickHouse/ClickHouse/issues/62154), [#62560](https://github.com/ClickHouse/ClickHouse/issues/62560). [#62578](https://github.com/ClickHouse/ClickHouse/pull/62578) ([Nikolay Degterinsky](https://github.com/evillique)).
