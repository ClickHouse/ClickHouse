<div id="clickhouse-release-v21215869-prestable-fixme-as-compared-to-v21115646-prestable">

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* * Se corrige el seguimiento del uso de memoria para `OPTIMIZE TABLE`/merges: ahora se tienen en cuenta los límites de memoria de la consulta y el muestreo para `OPTIMIZE TABLE`/merges. [#18772](https://github.com/ClickHouse/ClickHouse/pull/18772) ([Azat Khuzhin](https://github.com/azat)).
* Se prohíben `lcm`/`gcd` para números de coma flotante. [#19532](https://github.com/ClickHouse/ClickHouse/pull/19532) ([Azat Khuzhin](https://github.com/azat)).
* Las funciones bit a bit (`bitAnd`, `bitOr`, etc.) están prohibidas para argumentos de coma flotante. Ahora es necesario realizar una conversión explícita a entero. [#19853](https://github.com/ClickHouse/ClickHouse/pull/19853) ([Azat Khuzhin](https://github.com/azat)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* se añadió compatibilidad con la opción long de zstd para mejorar la compresión de las columnas String y ahorrar espacio. [#17184](https://github.com/ClickHouse/ClickHouse/pull/17184) ([ygrek](https://github.com/ygrek)).
* * Se añadió compatibilidad para asignar nombres de grupos de LDAP y valores de atributos en general a roles locales para usuarios de directorios de usuarios LDAP. [#17211](https://github.com/ClickHouse/ClickHouse/pull/17211) ([Denis Glazachev](https://github.com/traceon)).
* El tipo de dato `Nested` ahora admite niveles arbitrarios de anidamiento. Se introdujeron subcolumns de tipos complejos, como `size0` en `Array`, `null` en `Nullable` y los nombres de los elementos de `Tuple`, que pueden leerse sin leer la columna completa. [#17310](https://github.com/ClickHouse/ClickHouse/pull/17310) ([Anton Popov](https://github.com/CurtizJ)).
* Se añadió compatibilidad con argumentos de tipo tupla en las funciones `argMin` y `argMax`. [#17359](https://github.com/ClickHouse/ClickHouse/pull/17359) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Se añadió compatibilidad con `Nullable` para `FlatDictionary`, `HashedDictionary`, `ComplexKeyHashedDictionary`, `DirectDictionary`, `ComplexKeyDirectDictionary` y `RangeHashedDictionary`. [#18236](https://github.com/ClickHouse/ClickHouse/pull/18236) ([Maksim Kita](https://github.com/kitaisreal)).
* Se prohíbe usar columnas de punto flotante como clave de partición; relacionado con: [#18421](https://github.com/ClickHouse/ClickHouse/issues/18421)#event-4147046255. [#18464](https://github.com/ClickHouse/ClickHouse/pull/18464) ([hexiaoting](https://github.com/hexiaoting)).
* Se añadió la función decodeXMLComponent para decodificar caracteres XML. `SELECT decodeXMLComponent('Hello,&quot;world&quot;!');` [#17659](https://github.com/ClickHouse/ClickHouse/issues/17659). [#18542](https://github.com/ClickHouse/ClickHouse/pull/18542) ([nauta](https://github.com/nautaa)).
* Se añadió el table engine de PostgreSQL (tanto para select/insert, con compatibilidad con arrays multidimensionales), también como table function. Se añadió el dictionary source de PostgreSQL. Se añadió el database engine de PostgreSQL. [#18554](https://github.com/ClickHouse/ClickHouse/pull/18554) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Se añadió la sintaxis `SELECT ALL`. Cierra [#18706](https://github.com/ClickHouse/ClickHouse/issues/18706). [#18723](https://github.com/ClickHouse/ClickHouse/pull/18723) ([flynn](https://github.com/ucasfl)).

<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Se usa un grupo de conexiones para S3, controlado por la configuración `s3_max_connections`. [#13405](https://github.com/ClickHouse/ClickHouse/pull/13405) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Reescritura de las funciones `sumIf()` y `sum(if())` como la función `countIf()` cuando son lógicamente equivalentes. [#17041](https://github.com/ClickHouse/ClickHouse/pull/17041) ([flynn](https://github.com/ucasfl)).
* Se actualiza libcxx y se usa una ABI inestable para ofrecer un mejor rendimiento. [#18914](https://github.com/ClickHouse/ClickHouse/pull/18914) ([Daniel Kutenin](https://github.com/danlark1)).
* Eliminación más rápida de partes al reducir el número de syscalls `stat`. Esto recupera una optimización que existía anteriormente. Interfaz más segura para `IDisk`. Esto cierra [#19065](https://github.com/ClickHouse/ClickHouse/issues/19065). [#19086](https://github.com/ClickHouse/ClickHouse/pull/19086) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Aceleración de la función de agregación `sum`. La mejora solo es visible en benchmarks sintéticos y no es muy práctica. [#19216](https://github.com/ClickHouse/ClickHouse/pull/19216) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se admite dividir el paso `Filter` del plan de consulta en el par `Expression + Filter`. Junto con la optimización de fusión `Expression + Expression` ([#17458](https://github.com/ClickHouse/ClickHouse/issues/17458)), esto puede retrasar la ejecución de algunas expresiones hasta después del paso `Filter`. [#19253](https://github.com/ClickHouse/ClickHouse/pull/19253) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Se reduce la contención de bloqueos en varias capas del motor Buffer. [#19379](https://github.com/ClickHouse/ClickHouse/pull/19379) ([Azat Khuzhin](https://github.com/azat)).
* Ligera mejora de la latencia del servidor al eliminar el acceso a la configuración en cada conexión. [#19863](https://github.com/ClickHouse/ClickHouse/pull/19863) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
