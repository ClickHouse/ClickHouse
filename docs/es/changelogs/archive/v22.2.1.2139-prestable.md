<div id="new-feature">
  #### Nueva funcionalidad
</div>

* (No está listo para producción, se incorpora a las características experimentales) Añade memory overcommit a `MemoryTracker`. Se añadieron ajustes `guaranteed` para los límites de memoria, que representan límites de memoria blandos. Cuando se alcanza el límite de memoria estricto, `MemoryTracker` intenta cancelar la consulta con mayor overcommit. El nuevo ajuste `memory_usage_overcommit_max_wait_microseconds` especifica cuánto tiempo pueden esperar las consultas a que otra consulta se detenga. Cierra [#28375](https://github.com/ClickHouse/ClickHouse/issues/28375). [#31182](https://github.com/ClickHouse/ClickHouse/pull/31182) ([Dmitry Novik](https://github.com/novikd)).
* El ajuste permite que un usuario proporcione su propia semántica de deduplicación en MergeTree/ReplicatedMergeTree. Si se proporciona, se usa en lugar del hash de los datos para generar el ID del bloque. Así, por ejemplo, al proporcionar un valor único para el ajuste en cada sentencia INSERT, el usuario puede evitar que los mismos datos insertados se deduzcan. Esto cierra: [#7461](https://github.com/ClickHouse/ClickHouse/issues/7461). [#32304](https://github.com/ClickHouse/ClickHouse/pull/32304) ([Igor Nikonov](https://github.com/devcrafter)).
* Añade compatibilidad con la palabra clave DEFAULT para las sentencias INSERT. Cierra [#6331](https://github.com/ClickHouse/ClickHouse/issues/6331). [#33141](https://github.com/ClickHouse/ClickHouse/pull/33141) ([Andrii Buriachevskyi](https://github.com/0over)).
* Añade intervalos de confianza a las pruebas t. [#33260](https://github.com/ClickHouse/ClickHouse/pull/33260) ([achimbab](https://github.com/achimbab)).
* Permite crear archivos nuevos al insertar en los motores File/S3/HDFS. Permite sobrescribir archivos en HDFS. De forma predeterminada, lanza una excepción al intentar sobrescribir un archivo en S3. Lanza una excepción al intentar anexar datos a un archivo en formatos con sufijo. Cierra [#31640](https://github.com/ClickHouse/ClickHouse/issues/31640) Cierra [#31622](https://github.com/ClickHouse/ClickHouse/issues/31622) Cierra [#23862](https://github.com/ClickHouse/ClickHouse/issues/23862) Cierra [#15022](https://github.com/ClickHouse/ClickHouse/issues/15022) Cierra [#16674](https://github.com/ClickHouse/ClickHouse/issues/16674). [#33302](https://github.com/ClickHouse/ClickHouse/pull/33302) ([Kruglov Pavel](https://github.com/Avogar)).
