<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#45138](https://github.com/ClickHouse/ClickHouse/issues/45138): se permite usar el tipo String en lugar de Binary en los formatos Arrow/Parquet/ORC. Esta PR introduce 3 nuevas opciones de configuración para ello: `output_format_arrow_string_as_string`, `output_format_parquet_string_as_string`, `output_format_orc_string_as_string`. El valor predeterminado de todas estas opciones es `false`. [#37327](https://github.com/ClickHouse/ClickHouse/pull/37327) ([Kruglov Pavel](https://github.com/Avogar)).
