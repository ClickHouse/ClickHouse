<div id="clickhouse-release-v201014881-prestable-fixme-as-compared-to-v20914585-prestable">
  ### Lanzamiento de ClickHouse v20.10.1.4881-prestable FIXME en comparación con v20.9.1.4585-prestable
</div>

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Se añade compatibilidad con comentarios multilínea anidados `/* comment /* comment */ */` en SQL. Esto cumple con el estándar SQL. [#14655](https://github.com/ClickHouse/ClickHouse/pull/14655) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se cambia el valor predeterminado de la configuración `format_regexp_escaping_rule` (está relacionada con el formato `Regexp`) a `Raw` (significa leer el subpatrón completo como un valor) para que el comportamiento se ajuste más a lo que esperan los usuarios. [#15426](https://github.com/ClickHouse/ClickHouse/pull/15426) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* `multiple_joins_rewriter_version` queda obsoleto. Se elimina la primera versión del reescritor de joins. [#15472](https://github.com/ClickHouse/ClickHouse/pull/15472) ([Artem Zuikov](https://github.com/4ertus2)).



<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Soporte para tipos de MySQL: `decimal` (como `Decimal` de ClickHouse) y `datetime` con precisión de subsegundos (como `DateTime64`). ... [#11512](https://github.com/ClickHouse/ClickHouse/pull/11512) ([Vasily Nemkov](https://github.com/Enmk)).
* Se permite activar fsync en inserts, merges y fetches. [#11948](https://github.com/ClickHouse/ClickHouse/pull/11948) ([Anton Popov](https://github.com/CurtizJ)).
* Ejecución segura de consultas entre clústeres (con initial&#95;user como usuario actual de la consulta). [#13156](https://github.com/ClickHouse/ClickHouse/pull/13156) ([Azat Khuzhin](https://github.com/azat)).
* * Se añadió la función `mapPopulateSeries`. [#13166](https://github.com/ClickHouse/ClickHouse/pull/13166) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Permite al usuario especificar opciones de configuración para los almacenamientos `ReplicatedMergeTree*` en la sección `<replicated_merge_tree>` del archivo de configuración. Funciona de forma similar a la sección `<merge_tree>`. Para los almacenamientos `ReplicatedMergeTree*`, la configuración de `<merge_tree>` y `<replicated_merge_tree>` se aplica conjuntamente, pero la de `<replicated_merge_tree>` tiene mayor prioridad. Se añadió la tabla `system.replicated_merge_tree_settings`. [#13573](https://github.com/ClickHouse/ClickHouse/pull/13573) ([Amos Bird](https://github.com/amosbird)).
* Se añade una nueva funcionalidad: el formato LineAsString, que acepta una secuencia de líneas separadas por saltos de línea, espacios y/o comas. [#13846](https://github.com/ClickHouse/ClickHouse/pull/13846) ([hexiaoting](https://github.com/hexiaoting)).
* Nuevas opciones de configuración de límite de complejidad de consultas `max_rows_to_read_leaf`, `max_bytes_to_read_leaf` para consultas distribuidas, para limitar el máximo de filas/bytes leídos en los nodos hoja. El límite se aplica solo a lecturas locales, **excluyendo** la etapa final de merge en el nodo raíz. [#14221](https://github.com/ClickHouse/ClickHouse/pull/14221) ([Roman Khavronenko](https://github.com/hagen1778)).
* Se añaden formatos JSONStrings que generan la salida de los datos en arrays de strings. [#14333](https://github.com/ClickHouse/ClickHouse/pull/14333) ([hcz](https://github.com/hczhcz)).
* Ahora las sentencias `insert` pueden incluir asterisco (o variantes) con transformadores de columna en la lista de columnas. [#14453](https://github.com/ClickHouse/ClickHouse/pull/14453) ([Amos Bird](https://github.com/amosbird)).
* Se añadió un script para importar un repositorio de git a ClickHouse. [#14471](https://github.com/ClickHouse/ClickHouse/pull/14471) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se añade la capacidad de especificar `TTL ... RECOMPRESS codec_name` para la familia de motores de tabla MergeTree. [#14494](https://github.com/ClickHouse/ClickHouse/pull/14494) ([alesapin](https://github.com/alesapin)).
* Se añade event&#95;time&#95;microseconds a las tablas `system.asynchronous_metric_log` y `system.metric_log`. [#14514](https://github.com/ClickHouse/ClickHouse/pull/14514) ([Bharat Nallan](https://github.com/bharatnc)).
* Se añade una nueva funcionalidad: SHOW DATABASES LIKE &#39;xxx&#39;. [#14521](https://github.com/ClickHouse/ClickHouse/pull/14521) ([hexiaoting](https://github.com/hexiaoting)).
* Se admite el tipo de dato decimal en MaterializedMySQL. [#14535](https://github.com/ClickHouse/ClickHouse/pull/14535) ([Winter Zhang](https://github.com/zhang2014)).
* Permite una representación configurable de NULL para el formato de salida TSV. Se controla mediante la opción `output_format_tsv_null_representation`, que es `\N` de forma predeterminada. Esto cierra [#9375](https://github.com/ClickHouse/ClickHouse/issues/9375). Ten en cuenta que esta opción solo controla el formato de salida y `\N` es la única representación de NULL admitida para el formato de entrada TSV. [#14586](https://github.com/ClickHouse/ClickHouse/pull/14586) ([Kruglov Pavel](https://github.com/Avogar)).
* Se añade una nueva funcionalidad: el formato LineAsString, que acepta una secuencia de líneas separadas por saltos de línea, espacios y/o comas. [#14703](https://github.com/ClickHouse/ClickHouse/pull/14703) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

* Se añade la capacidad de eliminar propiedades de columnas y TTL de tablas. Se introdujeron las consultas `ALTER TABLE MODIFY COLUMN col_name REMOVE what_to_remove` y `ALTER TABLE REMOVE TTL`. Esto cierra [#2416](https://github.com/ClickHouse/ClickHouse/issues/2416). Esto cierra [#4967](https://github.com/ClickHouse/ClickHouse/issues/4967). <div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Se habilitan las partes compactas de forma predeterminada para las partes pequeñas. Esto permitirá procesar inserts frecuentes con algo más de eficiencia (4..100 veces). [#11913](https://github.com/ClickHouse/ClickHouse/pull/11913) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Mejora del rendimiento de los bytes de 256 bits al usar (u)int64&#95;t como tipo base para enteros anchos. Los enteros anchos originales usan tipos de 8 bits como base. [#14859](https://github.com/ClickHouse/ClickHouse/pull/14859) ([Artem Zuikov](https://github.com/4ertus2)).
* Al iniciar clickhouse-server, solo se bloquea con `mlock` el segmento de code. En versiones anteriores, todas las regiones mapeadas se bloqueaban en memoria, incluida la información de depuración. La información de depuración suele dividirse en un archivo separado, pero si no es así, esto provocaba un uso de memoria de +2..3 GiB. [#14929](https://github.com/ClickHouse/ClickHouse/pull/14929) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Antes se elegía el método de fixed key para agrupar por una única cadena fija. Esto es innecesario, ya que tenemos StringHashTable, que realiza una optimización packedFix similar para columnas FixedString. Y deberíamos usar low&#95;cardinality&#95;key&#95;fixed&#95;string si es posible. [#15034](https://github.com/ClickHouse/ClickHouse/pull/15034) ([Amos Bird](https://github.com/amosbird)).
* Corrige que `DateTime <op> DateTime` eligiera por error la implementación genérica lenta. Esto corrige [#15153](https://github.com/ClickHouse/ClickHouse/issues/15153). [#15178](https://github.com/ClickHouse/ClickHouse/pull/15178) ([Amos Bird](https://github.com/amosbird)).
* Usa una única request DeleteObjects de S3 en lugar de múltiples DeleteObject en ciclo. No hay cambios de funcionalidad, por lo que queda cubierto por pruebas existentes como integration/test&#95;log&#95;family&#95;s3. [#15238](https://github.com/ClickHouse/ClickHouse/pull/15238) ([ianton-ru](https://github.com/ianton-ru)).
* Multiplicación de 256 bits más rápida. [#15418](https://github.com/ClickHouse/ClickHouse/pull/15418) ([Artem Zuikov](https://github.com/4ertus2)).
* Mejora el rendimiento de `quantileTDigest`. Esto corrige [#2668](https://github.com/ClickHouse/ClickHouse/issues/2668). [#15542](https://github.com/ClickHouse/ClickHouse/pull/15542) ([Kruglov Pavel](https://github.com/Avogar)).
* Usa explícitamente un disco temporal para almacenar datos temporales de vertical merge. [#15639](https://github.com/ClickHouse/ClickHouse/pull/15639) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).
