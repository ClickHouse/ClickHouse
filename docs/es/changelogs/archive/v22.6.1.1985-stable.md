<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Cambia la forma en que se interpretan los ajustes que usan `seconds` como tipo para admitir valores de punto flotante (por ejemplo: `max_execution_time=0.5`). Los valores Infinity o NaN producirán una excepción. [#37187](https://github.com/ClickHouse/ClickHouse/pull/37187) ([Raúl Marín](https://github.com/Algunenano)).
* Se cambió el formato de la serialización binaria de las columnas del tipo experimental `Object`. El nuevo formato es más fácil de implementar para clientes de terceros. [#37482](https://github.com/ClickHouse/ClickHouse/pull/37482) ([Anton Popov](https://github.com/CurtizJ)).
* Activa el ajuste `output_format_json_named_tuples_as_objects` de forma predeterminada. Permite serializar tuplas con nombre como objetos JSON en formatos JSON. [#37756](https://github.com/ClickHouse/ClickHouse/pull/37756) ([Anton Popov](https://github.com/CurtizJ)).
