<div id="clickhouse-release-v22112542-prestable-fixme-as-compared-to-v211219017-prestable">

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Cambiar la ruta de ZooKeeper de las marcas zero-copy para los datos compartidos. Corrección para eliminar las marcas en ZooKeeper de las partes renombradas. [#32061](https://github.com/ClickHouse/ClickHouse/pull/32061) ([ianton-ru](https://github.com/ianton-ru)).
* * Contabilizar las subconsultas escalares. Con este cambio, las filas leídas en las subconsultas escalares ahora se registran en `query_log`. Si la subconsulta escalar está en caché (se repite o se llama para varias filas), las filas leídas solo se cuentan una vez. Este cambio permite aplicar KILL a las consultas e informar del progreso mientras ejecutan subconsultas escalares. [#32271](https://github.com/ClickHouse/ClickHouse/pull/32271) ([Raúl Marín](https://github.com/Algunenano)).
* Añadir las funciones `left`, `right`, `leftUTF8`, `rightUTF8`. Corregir un error en la implementación de la función `substringUTF8` con desplazamiento negativo (desplazamiento desde el final de la cadena). Las funciones `left` y `right` antes se implementaban en el analizador sintáctico. Notas de actualización: las consultas distribuidas con funciones `left` o `right` sin alias pueden lanzar una excepción si el clúster contiene distintas versiones de clickhouse-server. Si está actualizando su clúster y encuentra este error, debe terminar de actualizarlo para asegurarse de que todos los nodos tengan la misma versión. También puede añadir alias (`AS something`) a las columnas de sus consultas para evitar este problema. [#33407](https://github.com/ClickHouse/ClickHouse/pull/33407) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Se implementó la serialización dispersa. Puede reducir el uso de espacio en disco y mejorar el rendimiento de algunas consultas en columnas que contienen muchos valores predeterminados (cero). Se puede habilitar estableciendo `ratio_of_defaults_for_sparse_serialization`. La serialización dispersa se elegirá dinámicamente para una columna si la proporción entre el número de valores predeterminados y el número total de valores supera ese umbral. La serialización (predeterminada o dispersa) será fija para cada columna de una parte, pero puede variar entre partes. [#22535](https://github.com/ClickHouse/ClickHouse/pull/22535) ([Anton Popov](https://github.com/CurtizJ)).
* Se añadió la función grouping sets, como en GROUP BY grouping sets (a, b, (a, b)). [#26869](https://github.com/ClickHouse/ClickHouse/pull/26869) ([taylor12805](https://github.com/taylor12805)).
* Se añadió la posibilidad de leer desde todas las réplicas dentro de un segmento durante una consulta distribuida. Para habilitarlo, configure `allow_experimental_parallel_reading_from_replicas=true` y `max_parallel_replicas` con cualquier valor numérico. Esto cierra [#26748](https://github.com/ClickHouse/ClickHouse/issues/26748). [#29279](https://github.com/ClickHouse/ClickHouse/pull/29279) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
