<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#75283](https://github.com/ClickHouse/ClickHouse/issues/75283): mejora para establecer valores predeterminados aún más restrictivos. Los valores predeterminados actuales ya son seguros: el usuario debe especificar una opción para publicar puertos explícitamente. Sin embargo, cuando el usuario `default` no tiene una contraseña configurada mediante la variable de entorno `CLICKHOUSE_PASSWORD` ni un nombre de usuario cambiado mediante `CLICKHOUSE_USER`, solo debería estar disponible desde el sistema local como nivel adicional de protección. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
