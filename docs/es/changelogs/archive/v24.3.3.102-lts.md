<div id="improvement">
  #### Mejora
</div>

* retroportado en [#62188](https://github.com/ClickHouse/ClickHouse/issues/62188): StorageJoin con strictness `ANY` mantiene la consistencia tras la recarga. Cuando se insertan varias filas con la misma clave, la primera tendrá mayor prioridad (antes se elegía aleatoriamente al cargar la tabla). cierra [#51027](https://github.com/ClickHouse/ClickHouse/issues/51027). [#61972](https://github.com/ClickHouse/ClickHouse/pull/61972) ([vdimir](https://github.com/vdimir)).
* retroportado en [#62443](https://github.com/ClickHouse/ClickHouse/issues/62443): Client debe enviar la cabecera &#39;Keep-Alive: timeout=X&#39; al servidor. Si un client recibe una respuesta del servidor con esa cabecera, debe usar el valor proporcionado por el servidor. Además, para un client es mejor no usar una conexión que esté a punto de expirar, para evitar una condición de carrera al cerrar la conexión. [#62249](https://github.com/ClickHouse/ClickHouse/pull/62249) ([Sema Checherinda](https://github.com/CheSema)).
* retroportado en [#62666](https://github.com/ClickHouse/ClickHouse/issues/62666): El almacenamiento S3 y las copias de seguridad también necesitan la misma configuración predeterminada de Keep-Alive que el disco S3. [#62648](https://github.com/ClickHouse/ClickHouse/pull/62648) ([Sema Checherinda](https://github.com/CheSema)).
