<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Se añade compatibilidad con una representación personalizada de NULL para los formatos de entrada TSV/CSV. Se corrige la deserialización de Nullable(String) en los formatos de entrada TSV/CSV/JSONCompactStringsEachRow/JSONStringsEachRow. En consecuencia, `output_format_csv_null_representation` y `output_format_tsv_null_representation` pasan a llamarse `format_csv_null_representation` y `format_tsv_null_representation`. [#30497](https://github.com/ClickHouse/ClickHouse/pull/30497) ([Kruglov Pavel](https://github.com/Avogar)).
* Devuelve una cadena sin comillas en JSON&#95;VALUE. Cierra [#27965](https://github.com/ClickHouse/ClickHouse/issues/27965). [#31008](https://github.com/ClickHouse/ClickHouse/pull/31008) ([Kseniia Sumarokova](https://github.com/kssenii)).
* No se permite el `select` directo para Kafka/RabbitMQ/FileLog. Se puede habilitar mediante la configuración `stream_like_engine_allow_direct_select`. El `select` directo no se permitirá aunque esté habilitado por configuración si hay una vista materializada adjunta. En Kafka y RabbitMQ, el `select` directo, si está permitido, no hará commit de los mensajes de forma predeterminada. Para habilitar los commits con `select` directo, el usuario debe usar la configuración a nivel de almacenamiento `kafka{rabbitmq}_commit_on_select=1` (valor predeterminado `0`). cc @filimonov. [#31053](https://github.com/ClickHouse/ClickHouse/pull/31053) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Se elimina el mecanismo de &quot;elección de líder&quot; de `ReplicatedMergeTree`, porque se admiten varios líderes desde la versión 20.6. Si está actualizando desde una versión anterior y alguna réplica con una versión antigua es la líder, el servidor no podrá iniciarse después de la actualización. Detenga las réplicas con la versión antigua para que la nueva versión pueda iniciarse. Después de eso, no será posible volver a una versión anterior a 20.6. [#32140](https://github.com/ClickHouse/ClickHouse/pull/32140) ([Alexander Tokmakov](https://github.com/tavplubix)).
