<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#58815](https://github.com/ClickHouse/ClickHouse/issues/58815): Añade `SYSTEM JEMALLOC PURGE` para purgar páginas de jemalloc no utilizadas, `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` para controlar el profile de jemalloc si el profiler está habilitado. Añade un comando 4LW relacionado con jemalloc en Keeper: `jmst` para volcar las estadísticas de jemalloc, y `jmfp`, `jmep`, `jmdp` para controlar el profile de jemalloc si el profiler está habilitado. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#59234](https://github.com/ClickHouse/ClickHouse/issues/59234): Permite ignorar la evolución del esquema en el table engine Iceberg y leer todos los datos usando el esquema especificado por el usuario al crear la tabla o el esquema más reciente extraído de los metadatos al crear la tabla. Esto se hace mediante la configuración `iceberg_engine_ignore_schema_evolution`, que está deshabilitada de forma predeterminada. Ten en cuenta que habilitar esta configuración puede dar lugar a resultados incorrectos, ya que, en caso de que el esquema haya evolucionado, todos los archivos de datos se leerán usando el mismo esquema. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
