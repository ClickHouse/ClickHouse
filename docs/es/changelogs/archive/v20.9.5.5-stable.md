<div id="clickhouse-release-v20955-stable-fixme-as-compared-to-v209476-stable">
  ### Lanzamiento de ClickHouse v20.9.5.5-stable FIXME en comparación con v20.9.4.76-stable
</div>

<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#16493](https://github.com/ClickHouse/ClickHouse/issues/16493): Se corrigió un bug en la base de datos MySQL. Cuando el servidor MySQL usado como motor de base de datos no está disponible, algunas consultas generan Exception porque intentan obtener tablas de un servidor deshabilitado, aunque no es necesario. Por ejemplo, la consulta `SELECT ... FROM system.parts` debería funcionar solo con tablas MergeTree y no acceder en absoluto a la base de datos MySQL. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#16817](https://github.com/ClickHouse/ClickHouse/issues/16817): Se corrigió el comportamiento inconsistente por el que podía descartarse parte de los datos devueltos porque no se había creado el conjunto para filtrarlos. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#16508](https://github.com/ClickHouse/ClickHouse/issues/16508): Se corrigió el procesamiento de entradas muy grandes en la cola de replicación. Pueden aparecer entradas muy grandes en consultas ALTER si la estructura de la tabla es extremadamente grande (cerca de 1 MB). Esto corrige [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#16474](https://github.com/ClickHouse/ClickHouse/issues/16474): Se corrigió DROP TABLE para Distributed (condición de carrera con INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#16571](https://github.com/ClickHouse/ClickHouse/issues/16571): Se corrigió el rápido crecimiento de los metadatos al usar MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine, con `slave_parallel_worker` habilitado en MySQL Slave, reduciendo correctamente los conjuntos GTID. Esto corrige [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Retroportado en [#16554](https://github.com/ClickHouse/ClickHouse/issues/16554): Ahora, al analizar AVRO de entrada, LowCardinality se elimina del tipo. Corrige [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Retroportado en [#16748](https://github.com/ClickHouse/ClickHouse/issues/16748): Se corrigió [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#16894](https://github.com/ClickHouse/ClickHouse/issues/16894): Se corrigieron fallos silenciosos poco frecuentes cuando el profiler de consultas está activado y ClickHouse está instalado en un SO con una versión de glibc que tiene (supuestamente) asynchronous unwind tables defectuosas para algunas funciones. Esto corrige [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Esto corrige [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098). [#16846](https://github.com/ClickHouse/ClickHouse/pull/16846) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
