<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#51530](https://github.com/ClickHouse/ClickHouse/issues/51530): Dividir el enorme `RUN` del Dockerfile en bloques condicionales más pequeños. Instalar las herramientas necesarias según se necesiten en la misma capa `RUN` y eliminarlas después. Actualizar el sistema operativo solo una vez al principio. Usar un método moderno para verificar el repositorio firmado. Cambiar el repositorio base a ubuntu:20.04 para solucionar los problemas en versiones antiguas de Docker. Actualizar la versión de golang para corregir vulnerabilidades de golang. [#51504](https://github.com/ClickHouse/ClickHouse/pull/51504) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado en [#51570](https://github.com/ClickHouse/ClickHouse/issues/51570): Es un seguimiento de [#51504](https://github.com/ClickHouse/ClickHouse/issues/51504); la limpieza se perdió durante la refactorización. [#51564](https://github.com/ClickHouse/ClickHouse/pull/51564) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Se corrige un fallo en el análisis de índices cuando el operador binario contiene un argumento constante nulo [#50177](https://github.com/ClickHouse/ClickHouse/pull/50177) ([Amos Bird](https://github.com/amosbird)).
* Se corrige la reconexión de la sesión HTTPS cuando cambiaba la IP del host de destino [#50240](https://github.com/ClickHouse/ClickHouse/pull/50240) ([Aleksei Filatov](https://github.com/aalexfvk)).
* Se corrige un plegado incorrecto de constantes [#50536](https://github.com/ClickHouse/ClickHouse/pull/50536) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se corrige el tipo del hash de los params del LDAP server en la entrada de caché [#50865](https://github.com/ClickHouse/ClickHouse/pull/50865) ([Julian Maicher](https://github.com/jmaicher)).
* Se recurre al análisis de enteros grandes desde String en lugar de generar una excepción en el formato Parquet [#50873](https://github.com/ClickHouse/ClickHouse/pull/50873) ([Kruglov Pavel](https://github.com/Avogar)).
* No se aplica la proyección si la lectura en orden estaba habilitada. [#50923](https://github.com/ClickHouse/ClickHouse/pull/50923) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Se corrige un fallo del fuzzer en ActionsDAG [#51301](https://github.com/ClickHouse/ClickHouse/pull/51301) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
