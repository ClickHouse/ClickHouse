  ### Versión de ClickHouse v20.8.2.3-stable FIXME en comparación con v20.7.1.4310-prestable
</div>

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Se elimina la compatibilidad con el formato de entrada/salida `ODBCDriver`. Era un formato obsoleto que antes se usaba para la comunicación con el driver ODBC de ClickHouse y que hace tiempo fue reemplazado por el formato `ODBCDriver2`. Resuelve [#13629](https://github.com/ClickHouse/ClickHouse/issues/13629). [#13847](https://github.com/ClickHouse/ClickHouse/pull/13847) ([hexiaoting](https://github.com/hexiaoting)).
* Se amplía el ajuste `parallel_distributed_insert_select`, añadiendo una opción para ejecutar `INSERT` en la tabla local. El tipo del ajuste cambia de `Bool` a `UInt64`, por lo que los valores `false` y `true` ya no son compatibles. Si tiene estos valores en la configuración del servidor, el servidor no se iniciará. Sustitúyalos por `0` y `1`, respectivamente. [#14060](https://github.com/ClickHouse/ClickHouse/pull/14060) ([Azat Khuzhin](https://github.com/azat)).
* Ahora la consulta `OPTIMIZE FINAL` no recalcula el TTL de las partes añadidas antes de que se creara el TTL. Use `ALTER TABLE ... MATERIALIZE TTL` una vez para calcularlo en ellas; después, `OPTIMIZE FINAL` evaluará correctamente los TTL. Este comportamiento nunca funcionó en las tablas replicadas. [#14220](https://github.com/ClickHouse/ClickHouse/pull/14220) ([alesapin](https://github.com/alesapin)).



<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Soporte para el motor de base de datos `MaterializeMySQL`. Implementa [#4006](https://github.com/ClickHouse/ClickHouse/issues/4006). [#10851](https://github.com/ClickHouse/ClickHouse/pull/10851) ([Winter Zhang](https://github.com/zhang2014)).
* Soporte para autenticación Kerberos en Kafka mediante las bibliotecas `krb5` y `cyrus-sasl`. [#12771](https://github.com/ClickHouse/ClickHouse/pull/12771) ([Ilya Golshtein](https://github.com/ilejn)).
* Se añaden los tipos `Int128`, `Int256`, `UInt256` y las funciones asociadas. Se amplían los Decimals con Decimal256 (precisión de hasta 76 dígitos). Los nuevos tipos están disponibles bajo la configuración `allow_experimental_bigint_types`. [#13097](https://github.com/ClickHouse/ClickHouse/pull/13097) ([Artem Zuikov](https://github.com/4ertus2)).
* La función `position` ahora admite el argumento opcional `start_pos`. [#13237](https://github.com/ClickHouse/ClickHouse/pull/13237) ([Vladimir C](https://github.com/vdimir)).
* Se añade el statement `ALTER SAMPLE BY`, que permite modificar la cláusula de muestra de una tabla. [#13280](https://github.com/ClickHouse/ClickHouse/pull/13280) ([Amos Bird](https://github.com/amosbird)).
* Se añade la nueva sección opcional <user_directories> a la configuración principal. [#13425](https://github.com/ClickHouse/ClickHouse/pull/13425) ([Vitaly Baranov](https://github.com/vitlibar)).
* Se añade la función `normalizeQuery`, que reemplaza literales, secuencias de literales y aliases complejos con placeholders. Se añade la función `normalizedQueryHash`, que devuelve valores de hash de 64 bits idénticos para consultas similares, lo que facilita el análisis del registro de consultas. Cierra [#11271](https://github.com/ClickHouse/ClickHouse/issues/11271). [#13816](https://github.com/ClickHouse/ClickHouse/pull/13816) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se añaden las implementaciones `quantileExactLow` y `quantileExactHigh` con sus respectivos aliases para `medianExactLow` y `medianExactHigh`. [#13818](https://github.com/ClickHouse/ClickHouse/pull/13818) ([Bharat Nallan](https://github.com/bharatnc)).
* Se añade la función `defaultValueOfTypeName`, que devuelve el valor por defecto para un tipo dado. [#13877](https://github.com/ClickHouse/ClickHouse/pull/13877) ([hcz](https://github.com/hczhcz)).
* Se añade la función `date_trunc`, que trunca un valor de fecha/hora a la parte de fecha/hora especificada. [#13888](https://github.com/ClickHouse/ClickHouse/pull/13888) ([vladimir-golovchenko](https://github.com/vladimir-golovchenko)).
* Se añade la posibilidad de especificar el códec de compresión `Default` para columnas que correspondan a configuraciones definidas en `config.xml`. Implementa: [#9074](https://github.com/ClickHouse/ClickHouse/issues/9074). [#14049](https://github.com/ClickHouse/ClickHouse/pull/14049) ([alesapin](https://github.com/alesapin)).
* Se añade la configuración `min_index_granularity_bytes`, que protege contra la creación accidental de una tabla con un valor demasiado bajo en la configuración `index_granularity_bytes`. [#14139](https://github.com/ClickHouse/ClickHouse/pull/14139) ([Bharat Nallan](https://github.com/bharatnc)).
* Se añade la función `countDigits(x)`, que cuenta el número de dígitos decimales en una columna de tipo entero o decimal. Se añade la función `isDecimalOverflow(d, [p])`, que comprueba si el valor en una columna Decimal está fuera de su precisión (o de la precisión especificada). [#14151](https://github.com/ClickHouse/ClickHouse/pull/14151) ([Artem Zuikov](https://github.com/4ertus2)).

<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Al realizar consultas triviales de `INSERT SELECT`, se establecen automáticamente `max_threads` en 1 o `max_insert_threads`, y `max_block_size` en `min_insert_block_size_rows`. Relacionado con [#5907](https://github.com/ClickHouse/ClickHouse/issues/5907). [#12195](https://github.com/ClickHouse/ClickHouse/pull/12195) ([flynn](https://github.com/ucasfl)).
* Se optimizan las funciones `has()`, `indexOf()` y `countEqual()` para `Array(LowCardinality(T))` y argumentos constantes del lado derecho. [#12550](https://github.com/ClickHouse/ClickHouse/pull/12550) ([Mike Kot](https://github.com/myrrc)).
* Se mejora ligeramente el rendimiento de la agregación por claves UInt8/UInt16. [#13099](https://github.com/ClickHouse/ClickHouse/pull/13099) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se aborta de inmediato si se supera el límite `max_rows_to_read` durante el escaneo de partes. La motivación de este cambio es omitir el escaneo de rangos para todas las partes seleccionadas si está claro que `max_rows_to_read` ya se ha superado. El cambio es bastante notable para consultas sobre un gran número de partes. [#13677](https://github.com/ClickHouse/ClickHouse/pull/13677) ([Roman Khavronenko](https://github.com/hagen1778)).
* Se habilitan INSERT en paralelo para los motores de tabla `Null`, `Memory`, `Distributed` y `Buffer`. [#14120](https://github.com/ClickHouse/ClickHouse/pull/14120) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se optimizan ligeramente las consultas muy cortas con LowCardinality. [#14129](https://github.com/ClickHouse/ClickHouse/pull/14129) ([Anton Popov](https://github.com/CurtizJ)).
