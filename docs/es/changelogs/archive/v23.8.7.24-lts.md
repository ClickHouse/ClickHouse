<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#56581](https://github.com/ClickHouse/ClickHouse/issues/56581): Evita hacer referencia a una fuente de datos remota para la columna `data_paths` en `system.tables` si la tabla se crea con una función de tabla que usa una descripción explícita de columna. [#55540](https://github.com/ClickHouse/ClickHouse/pull/55540) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Retroportado en [#56877](https://github.com/ClickHouse/ClickHouse/issues/56877): Corrige un resultado de consulta incompleto para `UNION` en la función de tabla `view()`. [#56274](https://github.com/ClickHouse/ClickHouse/pull/56274) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Retroportado en [#56409](https://github.com/ClickHouse/ClickHouse/issues/56409): Prohíbe añadir una columna de tipo `Object(JSON)` a una tabla existente. Cierra: [#56095](https://github.com/ClickHouse/ClickHouse/issues/56095) Cierra: [#49944](https://github.com/ClickHouse/ClickHouse/issues/49944). [#56307](https://github.com/ClickHouse/ClickHouse/pull/56307) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#56756](https://github.com/ClickHouse/ClickHouse/issues/56756): Corrige un segfault provocado por una excepción lanzada durante la inicialización de Kerberos al crear la tabla Kafka. Cierra [#56073](https://github.com/ClickHouse/ClickHouse/issues/56073). [#56401](https://github.com/ClickHouse/ClickHouse/pull/56401) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado en [#56748](https://github.com/ClickHouse/ClickHouse/issues/56748): Corrige el issue por el que el motor de tabla RabbitMQ no podía conectarse a RabbitMQ mediante una conexión segura. [#56703](https://github.com/ClickHouse/ClickHouse/pull/56703) ([Igor Nikonov](https://github.com/devcrafter)).
* Retroportado en [#56839](https://github.com/ClickHouse/ClickHouse/issues/56839): El servidor se bloqueaba al descomprimir datos malformados con el códec `FPC`. Este issue se detectó mediante el [ClickHouse Bug Bounty Program](https://github.com/ClickHouse/ClickHouse/issues/38986) por [https://twitter.com/malacupa](https://twitter.com/malacupa). [#56795](https://github.com/ClickHouse/ClickHouse/pull/56795) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
