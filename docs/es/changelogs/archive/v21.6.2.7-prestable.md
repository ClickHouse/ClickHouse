<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#24567](https://github.com/ClickHouse/ClickHouse/issues/24567): usar la versión antigua de la función modulo cuando se use en la clave de partición. Cierra [#23508](https://github.com/ClickHouse/ClickHouse/issues/23508). [#24157](https://github.com/ClickHouse/ClickHouse/pull/24157) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#24367](https://github.com/ClickHouse/ClickHouse/issues/24367): establecer `max_threads = 1` para corregir el fallo de la mutación de StorageMemory. Cierra [#24274](https://github.com/ClickHouse/ClickHouse/issues/24274). [#24275](https://github.com/ClickHouse/ClickHouse/pull/24275) ([flynn](https://github.com/ucasfl)).
* Retroportado en [#24383](https://github.com/ClickHouse/ClickHouse/issues/24383): permitir encabezados HTTP vacíos. Corrige [#23901](https://github.com/ClickHouse/ClickHouse/issues/23901). [#24285](https://github.com/ClickHouse/ClickHouse/pull/24285) ([Ivan](https://github.com/abyss7)).
* Retroportado en [#24365](https://github.com/ClickHouse/ClickHouse/issues/24365): se corrigió un error al mover una vista materializada de una base de datos Ordinary a una base de datos Atomic (consulta `RENAME TABLE`). Ahora la tabla interna se mueve a la nueva base de datos junto con la vista materializada. Corrige [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926). [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#24510](https://github.com/ClickHouse/ClickHouse/issues/24510): se corrige DROP PARTITION con partes falsas de intersect. En casos poco frecuentes, puede haber partes con una versión de mutación mayor que el número de bloque actual. [#24321](https://github.com/ClickHouse/ClickHouse/pull/24321) ([Amos Bird](https://github.com/amosbird)).
* Retroportado en [#24542](https://github.com/ClickHouse/ClickHouse/issues/24542): se corrige la monotonicidad incorrecta de la función toWeek. Esto corrige [#24422](https://github.com/ClickHouse/ClickHouse/issues/24422). Este error se introdujo en [https://github.com/ClickHouse/ClickHouse/pull/5212](https://github.com/ClickHouse/ClickHouse/pull/5212) y más adelante quedó expuesto por un depurador de particiones más inteligente. [#24446](https://github.com/ClickHouse/ClickHouse/pull/24446) ([Amos Bird](https://github.com/amosbird)).
* Retroportado en [#24556](https://github.com/ClickHouse/ClickHouse/issues/24556): se corrigió el comportamiento por el que la consulta `SYSTEM RESTART REPLICA` o `SYSTEM SYNC REPLICA` se procesaba indefinidamente. Esto se detectó en un servidor con una cantidad extremadamente reducida de RAM. [#24457](https://github.com/ClickHouse/ClickHouse/pull/24457) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#24597](https://github.com/ClickHouse/ClickHouse/issues/24597): se corrige el uso de tuplas en consultas `CREATE .. AS SELECT`. [#24464](https://github.com/ClickHouse/ClickHouse/pull/24464) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#24600](https://github.com/ClickHouse/ClickHouse/issues/24600): se habilita la lectura de subcolumnas para tablas distribuidas. [#24472](https://github.com/ClickHouse/ClickHouse/pull/24472) ([Anton Popov](https://github.com/CurtizJ)).
