<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* aplicado mediante backport en [#31731](https://github.com/ClickHouse/ClickHouse/issues/31731): mejora del rendimiento de los formatos de salida JSON y XML. [#31673](https://github.com/ClickHouse/ClickHouse/pull/31673) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="bug-fix">
  #### Corrección de errores
</div>

* Aplicado mediante backport en [#31573](https://github.com/ClickHouse/ClickHouse/issues/31573): no se había alcanzado el límite de la quota, pero aun así se superó el límite. Esta PR corrige [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Corrección de errores (comportamiento anómalo visible para el usuario en la versión estable oficial)
</div>

* Backport en [#31518](https://github.com/ClickHouse/ClickHouse/issues/31518): Se elimina la función `not like` de RPNElement. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* Backport en [#31554](https://github.com/ClickHouse/ClickHouse/issues/31554): Se resuelve `nullptr` en el provider de credentials de STS para S3. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Backport en [#31579](https://github.com/ClickHouse/ClickHouse/issues/31579): * Se desactiva `partial_merge_join_left_table_buffer_bytes` hasta que se corrija el error de esta optimización. Véase [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)). * Se elimina la opción redundante `partial_merge_join_optimizations`. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* Backport en [#31745](https://github.com/ClickHouse/ClickHouse/issues/31745): La consulta `RENAME TABLE` funcionaba incorrectamente al intentar cambiar el nombre de un Diccionario DDL en una database `Ordinary`; ya está corregido. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Backport en [#31794](https://github.com/ClickHouse/ClickHouse/issues/31794): Los Settings `input_format_allow_errors_num` e `input_format_allow_errors_ratio` no funcionaban al analizar tipos domain, como `IPv4`; ya está corregido. Corrige [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686). [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Backport en [#31830](https://github.com/ClickHouse/ClickHouse/issues/31830): Se corrigió el error `there are no such cluster here` al ejecutar una consulta `ON CLUSTER` si el nombre del cluster especificado era el de una database `Replicated`. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Backport en [#31815](https://github.com/ClickHouse/ClickHouse/issues/31815): Se corrige una condición de carrera en el output format JSONEachRowWithProgress cuando los datos y las líneas de progreso se mezclan en la salida. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* Backport en [#32016](https://github.com/ClickHouse/ClickHouse/issues/32016): Se corrigen los aliases de group by / order by / limit by con positional arguments habilitados. Cierra [#31173](https://github.com/ClickHouse/ClickHouse/issues/31173). [#31741](https://github.com/ClickHouse/ClickHouse/pull/31741) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Backport en [#31762](https://github.com/ClickHouse/ClickHouse/issues/31762): Se corrige el uso del table engine `Buffer` con el tipo `Map`. Corrige [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546). [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* Backport en [#31892](https://github.com/ClickHouse/ClickHouse/issues/31892): Se corrige una posible aserción `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` en el format TSKV. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* Backport en [#32031](https://github.com/ClickHouse/ClickHouse/issues/32031): Se corrige una conversión no válida del tipo Nullable cuando se usa una primary key Nullable. Esto corrige [#31075](https://github.com/ClickHouse/ClickHouse/issues/31075). [#31823](https://github.com/ClickHouse/ClickHouse/pull/31823) ([Amos Bird](https://github.com/amosbird)).
* Retroportado en [#32074](https://github.com/ClickHouse/ClickHouse/issues/32074): Se corrige un error en la función transform con argumentos de tipo Decimal. [#31839](https://github.com/ClickHouse/ClickHouse/pull/31839) ([Shuai li](https://github.com/loneylee)).
* Retroportado en [#31939](https://github.com/ClickHouse/ClickHouse/issues/31939): - Se cambia la ruta de configuración de `keeper_server.session_timeout_ms` a `keeper_server.coordination_settings.session_timeout_ms` al construir un `KeeperTCPHandler` - Lo mismo con `operation_timeout`. [#31859](https://github.com/ClickHouse/ClickHouse/pull/31859) ([JackyWoo](https://github.com/JackyWoo)).
* Retroportado en [#31909](https://github.com/ClickHouse/ClickHouse/issues/31909): Se corrigen las funciones `empty` y `notEmpty` con argumentos de tipo `UUID`. Corrige [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819). [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
