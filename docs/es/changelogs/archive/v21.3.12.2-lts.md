<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#24189](https://github.com/ClickHouse/ClickHouse/issues/24189): Algunas consultas `ALTER PARTITION` podían provocar los errores `Part A intersects previous part B` y `Unexpected merged part C intersecting drop range D` en la cola de replicación. Ya está corregido. Corrige [#23296](https://github.com/ClickHouse/ClickHouse/issues/23296). [#23997](https://github.com/ClickHouse/ClickHouse/pull/23997) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#24306](https://github.com/ClickHouse/ClickHouse/issues/24306): Se corrigió el uso de un valor const `DateTime` frente a una columna `DateTime64` en WHERE. ... [#24100](https://github.com/ClickHouse/ClickHouse/pull/24100) ([Vasily Nemkov](https://github.com/Enmk)).
* Retroportado en [#24140](https://github.com/ClickHouse/ClickHouse/issues/24140): Error: explain pipeline con `select xxx final` muestra un pipeline incorrecto: &#96;&#96;&#96; dell123 :) explain pipeline select z from prewhere&#95;move&#95;select&#95;final final;. [#24116](https://github.com/ClickHouse/ClickHouse/pull/24116) ([hexiaoting](https://github.com/hexiaoting)).
* Retroportado en [#24190](https://github.com/ClickHouse/ClickHouse/issues/24190): Se corrige un error poco frecuente que podía dar lugar a una tabla parcialmente inicializada capaz de atender solicitudes de escritura (insert/alter/etc.). Ahora estas tablas estarán en modo readonly. [#24122](https://github.com/ClickHouse/ClickHouse/pull/24122) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#24235](https://github.com/ClickHouse/ClickHouse/issues/24235): Se corrige una condición de carrera que podía producirse en RBAC con una carga elevada. Este PR corrige [#24090](https://github.com/ClickHouse/ClickHouse/issues/24090), [#24134](https://github.com/ClickHouse/ClickHouse/issues/24134),. [#24176](https://github.com/ClickHouse/ClickHouse/pull/24176) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado en [#24244](https://github.com/ClickHouse/ClickHouse/issues/24244): Se corrige una terminación anómala del servidor debida a que hdfs dejaba de estar accesible durante la ejecución de la consulta. Cierra [#24117](https://github.com/ClickHouse/ClickHouse/issues/24117). [#24191](https://github.com/ClickHouse/ClickHouse/pull/24191) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#24241](https://github.com/ClickHouse/ClickHouse/issues/24241): Se corrige un error tipográfico en StorageMemory; este error se introdujo en [#15127](https://github.com/ClickHouse/ClickHouse/issues/15127) y ahora está corregido. Cierra [#24192](https://github.com/ClickHouse/ClickHouse/issues/24192). [#24193](https://github.com/ClickHouse/ClickHouse/pull/24193) ([张中南](https://github.com/plugine)).
* Retroportado en [#24353](https://github.com/ClickHouse/ClickHouse/issues/24353): Se corrigió un error al mover una vista materializada de una base de datos Ordinary a Atomic (consulta `RENAME TABLE`). Ahora la tabla interna se mueve a la nueva base de datos junto con la vista materializada. Corrige [#23926](https://github.com/ClickHouse/ClickHouse/issues/23926). [#24309](https://github.com/ClickHouse/ClickHouse/pull/24309) ([Alexander Tokmakov](https://github.com/tavplubix)).
