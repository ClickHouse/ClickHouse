<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#75311](https://github.com/ClickHouse/ClickHouse/issues/75311): Se corrige un fallo durante el análisis de la declaración del tipo JSON cuando el nombre del tipo no está en mayúsculas. [#74784](https://github.com/ClickHouse/ClickHouse/pull/74784) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#75253](https://github.com/ClickHouse/ClickHouse/issues/75253): Revierte el estado de la parte de deleting a outdated cuando falla la operación de eliminación. [#74985](https://github.com/ClickHouse/ClickHouse/pull/74985) ([Sema Checherinda](https://github.com/CheSema)).
* Retroportado en [#75409](https://github.com/ClickHouse/ClickHouse/issues/75409): Se corrigió el uso de índices (primarios y secundarios) para las columnas `Array`, `Map` y `Nullable(..)` con la configuración `optimize_function_to_subcolumns` habilitada. Anteriormente, los índices de estas columnas podían ignorarse. [#75081](https://github.com/ClickHouse/ClickHouse/pull/75081) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#75461](https://github.com/ClickHouse/ClickHouse/issues/75461): Se corrige el fallo que provocaba un cierre inesperado en CTE con Insert. [#75188](https://github.com/ClickHouse/ClickHouse/pull/75188) ([Shichao Jin](https://github.com/jsc0218)).

<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#75291](https://github.com/ClickHouse/ClickHouse/issues/75291): mejora para aplicar valores predeterminados aún más restrictivos. Los valores predeterminados actuales ya son seguros: el usuario tiene que especificar una opción para publicar puertos explícitamente. Pero, cuando al usuario `default` no se le ha establecido una contraseña mediante la variable de entorno `CLICKHOUSE_PASSWORD` y/o no se le ha cambiado el nombre de usuario mediante `CLICKHOUSE_USER`, solo debería estar disponible desde el sistema local como nivel adicional de protección. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
