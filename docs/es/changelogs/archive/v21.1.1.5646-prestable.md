<div id="clickhouse-release-v21115646-prestable-fixme-as-compared-to-v201215236-prestable">

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Prohibir `toUnixTimestamp(Date())` (antes solo devolvía la representación `UInt16` de `Date`). [#17376](https://github.com/ClickHouse/ClickHouse/pull/17376) ([Azat Khuzhin](https://github.com/azat)).
* Se eliminaron las funciones de agregación `timeSeriesGroupSum`, `timeSeriesGroupRateSum` porque un amigo mío dijo que nunca funcionaron. Esto corrige [#16869](https://github.com/ClickHouse/ClickHouse/issues/16869). Si has tenido suerte usando estas funciones, escribe un correo electrónico a clickhouse-feedback@yandex-team.com. [#17423](https://github.com/ClickHouse/ClickHouse/pull/17423) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* La configuración `input_format_null_as_default` está habilitada de forma predeterminada. [#17525](https://github.com/ClickHouse/ClickHouse/pull/17525) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Establecer `insert_quorum_parallel` en 1 de forma predeterminada. Es mucho más conveniente que las inserciones con cuórum &quot;sequential&quot;. Pero si dependes de la consistencia secuencial, debes volver a poner esta configuración en cero. [#17567](https://github.com/ClickHouse/ClickHouse/pull/17567) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Restringir `ALTER MODIFY SETTING` para impedir que cambie configuraciones de almacenamiento que afectan a las partes de datos (`write_final_mark` y `enable_mixed_granularity_parts`). [#18306](https://github.com/ClickHouse/ClickHouse/pull/18306) ([Amos Bird](https://github.com/amosbird)).
* Comprobar las restricciones de las configuraciones de perfil definidas en la configuración. El servidor no se iniciará si users.xml contiene configuraciones que no cumplen las restricciones correspondientes. [#18486](https://github.com/ClickHouse/ClickHouse/pull/18486) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Eliminar la función `sumburConsistentHash`. Esto cierra [#18120](https://github.com/ClickHouse/ClickHouse/issues/18120). [#18656](https://github.com/ClickHouse/ClickHouse/pull/18656) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Añadir los operadores `DIV` y `MOD`. `DIV` implementa la división entera. Esto es necesario para la compatibilidad con MySQL y para `sqllogictest`. Esto cierra [#18707](https://github.com/ClickHouse/ClickHouse/issues/18707). Puede introducir incompatibilidades si usas DIV o MOD como nombres de columna o alias. En caso de incompatibilidad, escribe los alias después de la palabra clave AS o pon los identificadores entre comillas (dobles o invertidas). [#18760](https://github.com/ClickHouse/ClickHouse/pull/18760) ([Du Chuan](https://github.com/spongedu)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Usa [https://github.com/lemire/fast&#95;float](https://github.com/lemire/fast_float) para parsear números de coma flotante. [#16787](https://github.com/ClickHouse/ClickHouse/pull/16787) ([Maksim Kita](https://github.com/kitaisreal)).
* ... [#16819](https://github.com/ClickHouse/ClickHouse/pull/16819) ([pronvis](https://github.com/pronvis)).
* Incorpora un nuevo combinador de agregación: `-SimpleState` para crear tipos SimpleAggregateFunction mediante una consulta. Es útil para definir vistas materializadas de engine AggregatingMergeTree, y también beneficiará a las projections. [#16853](https://github.com/ClickHouse/ClickHouse/pull/16853) ([Amos Bird](https://github.com/amosbird)).
* Se añadieron las funciones de agregación `mannWitneyUTest`, `studentTTest` y `welchTTest`. También se refactorizó un poco RankCorr. [#16883](https://github.com/ClickHouse/ClickHouse/pull/16883) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Añade una setting optimize&#95;on&#95;insert. Cuando está enabled, realiza la misma transformación sobre un block de datos insertado que si se hubiera hecho un merge de ese block (p. ej., Replacing, Collapsing, Aggregating...). Esta setting estará enabled de forma predeterminada. Esto puede influir en el comportamiento de la vista materializada y de MaterializeMySQL (consulta la descripción detallada). Esto cierra [#10683](https://github.com/ClickHouse/ClickHouse/issues/10683). [#16954](https://github.com/ClickHouse/ClickHouse/pull/16954) ([Kruglov Pavel](https://github.com/Avogar)).
* Añade compatibilidad con compresión/descompresión `*.zst`. Permite usar `*.zst` en la función `file()` y `Content-encoding: zstd` en el client HTTP. Esto cierra [#16791 ](https://github.com/ClickHouse/ClickHouse/issues/16791). [#17144](https://github.com/ClickHouse/ClickHouse/pull/17144) ([Abi Palagashvili](https://github.com/fibersel)).
* * El Diccionario IP admite de forma nativa los tipos `IPv4` / `IPv6`. [#17571](https://github.com/ClickHouse/ClickHouse/pull/17571) ([Vladimir C](https://github.com/vdimir)).
* relacionado: [#16176](https://github.com/ClickHouse/ClickHouse/issues/16176) Uso: `set limit = 10; set offset = 20;` estas dos configuraciones afectarán a la consulta SELECT como si se añadieran así: `select * from ($your_original_select_query) tmp limit xxx offset xxx;`. [#17633](https://github.com/ClickHouse/ClickHouse/pull/17633) ([hexiaoting](https://github.com/hexiaoting)).
* Añade métricas asíncronas sobre la cantidad total de filas, bytes y partes en las tablas MergeTree. Esta corrección soluciona [#11714](https://github.com/ClickHouse/ClickHouse/issues/11714). [#17639](https://github.com/ClickHouse/ClickHouse/pull/17639) ([flynn](https://github.com/ucasfl)).
* Introduce la sintaxis `DETACH TABLE/VIEW ... PERMANENTLY`, de modo que, después de reiniciar, la tabla no vuelva a aparecer automáticamente (solo mediante una solicitud explícita). La tabla aún puede volver a adjuntarse usando la sintaxis corta ATTACH TABLE. Implementa [#5555](https://github.com/ClickHouse/ClickHouse/issues/5555). Soluciona [#13850](https://github.com/ClickHouse/ClickHouse/issues/13850). [#17642](https://github.com/ClickHouse/ClickHouse/pull/17642) ([filimonov](https://github.com/filimonov)).
* Añade una nueva tabla llamada `system.distributed_ddl_queue` que muestra las consultas en la cola del worker de DDL. [#17656](https://github.com/ClickHouse/ClickHouse/pull/17656) ([Bharat Nallan](https://github.com/bharatnc)).
* Añade la función `encodeXMLComponent` para escapar caracteres al colocar una cadena en un nodo de texto XML o en un atributo. [#17659](https://github.com/ClickHouse/ClickHouse/pull/17659) ([nauta](https://github.com/nautaa)).
* Ahora clickhouse-client permite abrir EDITOR para editar comandos. `Alt-Shift-E`. [#17665](https://github.com/ClickHouse/ClickHouse/pull/17665) ([Amos Bird](https://github.com/amosbird)).
* Añade compatibilidad con el protocolo PROXYv1 para encapsular la interfaz native TCP. Permite que las cuotas se indexen por la dirección IP reenviada por el proxy (aplicado a la dirección PROXYv1 y a X-Forwarded-For desde la HTTP interface). Esto es útil cuando proporcionas acceso a ClickHouse solo mediante un proxy de confianza (p. ej., CloudFlare), pero quieres contabilizar los recursos del usuario por sus direcciones IP originales. Esto soluciona [#17268](https://github.com/ClickHouse/ClickHouse/issues/17268). [#17707](https://github.com/ClickHouse/ClickHouse/pull/17707) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Añade la capacidad de usar una lista de TLD personalizada en las funciones `firstSignificantSubdomainCustom`, `cutToFirstSignificantSubdomainCustom`. [#17748](https://github.com/ClickHouse/ClickHouse/pull/17748) ([Azat Khuzhin](https://github.com/azat)).
* Clickhouse-benchmark añadió un parámetro de consulta. [#17832](https://github.com/ClickHouse/ClickHouse/pull/17832) ([Maksim Kita](https://github.com/kitaisreal)).
* Se amplió la sintaxis `OPTIMIZE ... DEDUPLICATE` para permitir una lista explícita (o implícita con asterisk/transformadores de columnas) de columnas sobre las que comprobar duplicados. ... [#17846](https://github.com/ClickHouse/ClickHouse/pull/17846) ([Vasily Nemkov](https://github.com/Enmk)).
* Añade las configuraciones `min_compress_block_size` y `max_compress_block_size` a MergeTreeSettings, que tienen mayor prioridad que las configuraciones globales y surten efecto cuando se establecen. cierra [13890](https://github.com/ClickHouse/ClickHouse/issues/13890). [#17867](https://github.com/ClickHouse/ClickHouse/pull/17867) ([flynn](https://github.com/ucasfl)).
* Implementó la consulta `ATTACH TABLE name FROM 'path/to/data/' (col1 Type1, ...`. Crea una nueva tabla con la estructura proporcionada y adjunta los datos de la tabla desde el directorio especificado en `user_files`. [#17903](https://github.com/ClickHouse/ClickHouse/pull/17903) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Se añadieron las funciones de agregación `arrayMin`, `arrayMax` y `arrayAvg`. [#18032](https://github.com/ClickHouse/ClickHouse/pull/18032) ([Maksim Kita](https://github.com/kitaisreal)).
* Se admite la instrucción `SHOW SETTINGS` para mostrar parámetros en system.settings. También se admiten `SHOW CHANGED SETTINGS` y la cláusula `LIKE/ILIKE`. [#18056](https://github.com/ClickHouse/ClickHouse/pull/18056) ([Jianmei Zhang](https://github.com/zhangjmruc)).
* Se permite crear una tabla a partir de una consulta SELECT con especificación de columnas. Ejemplo: `CREATE TABLE t1 (x String) ENGINE = Memory AS SELECT 1;`. [#18060](https://github.com/ClickHouse/ClickHouse/pull/18060) ([Maksim Kita](https://github.com/kitaisreal)).
* * El Diccionario IP admite búsquedas por clave. Resuelve [#18241](https://github.com/ClickHouse/ClickHouse/issues/18241). [#18480](https://github.com/ClickHouse/ClickHouse/pull/18480) ([Vladimir C](https://github.com/vdimir)).
* Se implementaron las consultas `REPLACE TABLE` y `CREATE OR REPLACE TABLE`. [#18521](https://github.com/ClickHouse/ClickHouse/pull/18521) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Se añadió la función `byteSize` para estimar el tamaño en bytes sin comprimir de sus argumentos en memoria. Por ejemplo, para un argumento UInt32 devolverá la constante 4; para un argumento String, la longitud de la cadena + 9. La función puede aceptar varios argumentos. La aplicación típica es `byteSize(*)`. [#18579](https://github.com/ClickHouse/ClickHouse/pull/18579) ([Ping Yu](https://github.com/pingyu)).
* Se añadió la columna `query_id` a `system.part_log` para las partes insertadas. Cierra [#10097](https://github.com/ClickHouse/ClickHouse/issues/10097). [#18644](https://github.com/ClickHouse/ClickHouse/pull/18644) ([flynn](https://github.com/ucasfl)).
* Ahora hay una nueva configuración de almacenamiento, `max_partitions_to_read`, para las tablas de la familia MergeTree. Limita el número máximo de particiones a las que se puede acceder en una consulta. También se añadió una configuración de usuario, `force_max_partition_limit`, para aplicar esta restricción. [#18712](https://github.com/ClickHouse/ClickHouse/pull/18712) ([Amos Bird](https://github.com/amosbird)).
* La función `position` ahora admite la sintaxis `position(needle in haystack)` para mantener la compatibilidad con SQL. Esto cierra [#18701](https://github.com/ClickHouse/ClickHouse/issues/18701). ... [#18779](https://github.com/ClickHouse/ClickHouse/pull/18779) ([Jianmei Zhang](https://github.com/zhangjmruc)).

<div id="performance-improvement">

* Ahora el combinador `-If` está desvirtualizado y `count` está correctamente vectorizado. Esto corresponde a [https://github.com/ClickHouse/ClickHouse/pull/17041](https://github.com/ClickHouse/ClickHouse/pull/17041). [#17043](https://github.com/ClickHouse/ClickHouse/pull/17043) ([Amos Bird](https://github.com/amosbird)).
* Se mejoró el rendimiento de AggregatingMergeTree con SimpleAggregateFunction(String) en la clave primaria. [#17109](https://github.com/ClickHouse/ClickHouse/pull/17109) ([Azat Khuzhin](https://github.com/azat)).
* Se añadió la configuración `remerge_sort_lowered_memory_bytes_ratio` (si el uso de memoria después de `remerge` no se reduce en esta proporción, `remerge` se deshabilitará). [#17539](https://github.com/ClickHouse/ClickHouse/pull/17539) ([Azat Khuzhin](https://github.com/azat)).
* Se aceleró la implementación de `IPv6CIDRToRange`. [#17569](https://github.com/ClickHouse/ClickHouse/pull/17569) ([Vladimir C](https://github.com/vdimir)).
* Se usa el algoritmo dragonbox para la conversión de float a string en lugar de ryu. [#17831](https://github.com/ClickHouse/ClickHouse/pull/17831) ([Maksim Kita](https://github.com/kitaisreal)).
* Se optimizó la lectura de StorageMemory. [#18052](https://github.com/ClickHouse/ClickHouse/pull/18052) ([Maksim Kita](https://github.com/kitaisreal)).
* No se envían bloques vacíos a los segmentos en `INSERT` síncronos en una tabla distribuida. Esto cierra [#14571](https://github.com/ClickHouse/ClickHouse/issues/14571). [#18775](https://github.com/ClickHouse/ClickHouse/pull/18775) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se reemplazó `PODArray` por `PODArrayWithStackMemory` en `AggregateFunctionWindowFunnelData` para mejorar el rendimiento de la función `windowFunnel`. [#18817](https://github.com/ClickHouse/ClickHouse/pull/18817) ([flynn](https://github.com/ucasfl)).
* Se añadió la opción `--no-system-table` para `clickhouse-local` para ejecutarlo sin tablas del sistema. Esto evita la inicialización de `DateLUT`, que puede llevar un tiempo apreciable (decenas de milisegundos) al inicio. [#18899](https://github.com/ClickHouse/ClickHouse/pull/18899) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
