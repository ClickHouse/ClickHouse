  ### Lanzamiento de ClickHouse v20.10.4.1-stable FIXME en comparación con v20.10.3.30-stable
</div>

<div id="improvement">
  #### Mejora
</div>

* Solución alternativa para usar S3 con un servidor nginx como proxy. Actualmente, nginx no acepta URL con una ruta vacía como [http://domain.com?delete](http://domain.com?delete), pero la versión estándar de aws-sdk-cpp genera este tipo de URL. Este commit utiliza una versión parcheada de aws-sdk-cpp, que en estos casos genera URL con &quot;/&quot; como ruta, como [http://domain.com/?delete](http://domain.com/?delete). [#16813](https://github.com/ClickHouse/ClickHouse/pull/16813) ([ianton-ru](https://github.com/ianton-ru)).

<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#16492](https://github.com/ClickHouse/ClickHouse/issues/16492): Corrige un bug con la base de datos MySQL. Cuando el servidor MySQL usado como motor de base de datos no está disponible, algunas consultas generan Exception porque intentan obtener tablas de un servidor deshabilitado, aunque no es necesario. Por ejemplo, la consulta `SELECT ... FROM system.parts` debería funcionar solo con tablas MergeTree y no tocar la base de datos MySQL en absoluto. [#16032](https://github.com/ClickHouse/ClickHouse/pull/16032) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#16710](https://github.com/ClickHouse/ClickHouse/issues/16710): Se corrigió el comportamiento inconsistente por el que podía descartarse parte de los datos devueltos porque no se había creado el conjunto para filtrarlos. [#16308](https://github.com/ClickHouse/ClickHouse/pull/16308) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#16505](https://github.com/ClickHouse/ClickHouse/issues/16505): Corrige el procesamiento de entradas muy grandes en la cola de replicación. Pueden aparecer entradas muy grandes en consultas ALTER si la estructura de la tabla es extremadamente grande (cerca de 1 MB). Esto corrige [#16307](https://github.com/ClickHouse/ClickHouse/issues/16307). [#16332](https://github.com/ClickHouse/ClickHouse/pull/16332) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#16471](https://github.com/ClickHouse/ClickHouse/issues/16471): Corrige DROP TABLE para Distributed (condición de carrera con INSERT). [#16409](https://github.com/ClickHouse/ClickHouse/pull/16409) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#16572](https://github.com/ClickHouse/ClickHouse/issues/16572): Corrige el rápido crecimiento de los metadatos al usar MySQL Master -&gt; MySQL Slave -&gt; ClickHouse MaterializeMySQL Engine, con `slave_parallel_worker` habilitado en MySQL Slave, reduciendo correctamente los conjuntos GTID. Esto corrige [#15951](https://github.com/ClickHouse/ClickHouse/issues/15951). [#16504](https://github.com/ClickHouse/ClickHouse/pull/16504) ([TCeason](https://github.com/TCeason)).
* Retroportado en [#16551](https://github.com/ClickHouse/ClickHouse/issues/16551): Ahora, al analizar AVRO de entrada, se elimina LowCardinality del tipo. Corrige [#16188](https://github.com/ClickHouse/ClickHouse/issues/16188). [#16521](https://github.com/ClickHouse/ClickHouse/pull/16521) ([Mike Kot](https://github.com/myrrc)).
* Retroportado en [#16749](https://github.com/ClickHouse/ClickHouse/issues/16749): Se corrigió [#16081](https://github.com/ClickHouse/ClickHouse/issues/16081). [#16613](https://github.com/ClickHouse/ClickHouse/pull/16613) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#16760](https://github.com/ClickHouse/ClickHouse/issues/16760): Corrige optimize&#95;read&#95;in&#95;order/optimize&#95;aggregation&#95;in&#95;order con max&#95;threads&gt;0 y expresiones en ORDER BY. [#16637](https://github.com/ClickHouse/ClickHouse/pull/16637) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#16741](https://github.com/ClickHouse/ClickHouse/issues/16741): Corrige el operador `IN` sobre varias columnas y tuplas con la configuración `transform_null_in` habilitada. Corrige [#15310](https://github.com/ClickHouse/ClickHouse/issues/15310). [#16722](https://github.com/ClickHouse/ClickHouse/pull/16722) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#16893](https://github.com/ClickHouse/ClickHouse/issues/16893): Corrige raros fallos silenciosos cuando el perfilador de consultas está activado y ClickHouse está instalado en un sistema operativo con una versión de glibc que tiene (supuestamente) tablas asíncronas de desenrollado defectuosas para algunas funciones. Esto corrige [#15301](https://github.com/ClickHouse/ClickHouse/issues/15301). Esto corrige [#13098](https://github.com/ClickHouse/ClickHouse/issues/13098).
