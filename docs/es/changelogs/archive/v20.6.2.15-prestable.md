<div id="clickhouse-release-v206215-prestable-fixme-as-compared-to-v20513833-prestable">
  ### Versión de ClickHouse v20.6.2.15-prestable FIXME en comparación con v20.5.1.3833-prestable
</div>

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* `clickhouse-local` ahora usa por defecto un directorio temporal de datos único, en lugar del directorio actual como antes. Si es necesario, el directorio de datos puede especificarse explícitamente con la opción `-- --path`. [#11931](https://github.com/ClickHouse/ClickHouse/pull/11931) ([Alexander Kuzmenkov](https://github.com/akuzm)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Se añade compatibilidad con `Alter table drop replica replica_name`. Esto corrige [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).
* Se añadió un nuevo formato en memoria para las partes en tablas de la familia `MergeTree`, que almacena los datos en memoria. Las partes se escriben en disco en la primera fusión. Se creará una parte en formato en memoria si su tamaño en filas o bytes está por debajo de los umbrales `min_rows_for_compact_part` y `min_bytes_for_compact_part`. También hay compatibilidad opcional con Write-Ahead-Log, habilitada de forma predeterminada y controlada mediante la configuración `in_memory_parts_enable_wal`. [#10697](https://github.com/ClickHouse/ClickHouse/pull/10697) ([Anton Popov](https://github.com/CurtizJ)).
* Se añade el combinador -Distinct para las funciones de agregación. [#10930](https://github.com/ClickHouse/ClickHouse/pull/10930) ([Sofia Antipushina](https://github.com/Sonichka1311)).
* Compatibilidad con el motor de tabla mongo(host:port, database, collection, user, password). [#10931](https://github.com/ClickHouse/ClickHouse/pull/10931) ([ageraab](https://github.com/ageraab)).
* Se añade el almacenamiento RabbitMQ. [#11069](https://github.com/ClickHouse/ClickHouse/pull/11069) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Opciones de configuración para enviar informes de fallos al equipo principal de ClickHouse mediante [Sentry](https://sentry.io). [#11300](https://github.com/ClickHouse/ClickHouse/pull/11300) ([Ivan Blinkov](https://github.com/blinkov)).
* Se añade ORCBlockOutputFormat. [#11662](https://github.com/ClickHouse/ClickHouse/pull/11662) ([Kruglov Pavel](https://github.com/Avogar)).
* Configuración `max_thread_pool_size` para cambiar el número máximo de hilos en Global Thread Pool. [#11668](https://github.com/ClickHouse/ClickHouse/pull/11668) ([Bharat Nallan](https://github.com/bharatnc)).
* Implementación inicial de la consulta `EXPLAIN`. Sintaxis: `EXPLAIN SELECT ...`. Esto corrige [#1118](https://github.com/ClickHouse/ClickHouse/issues/1118). [#11873](https://github.com/ClickHouse/ClickHouse/pull/11873) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Se cambiaron las rutas de los metadatos de S3 a rutas relativas, lo que permite gestionar los blobs de S3 más fácilmente. [#11892](https://github.com/ClickHouse/ClickHouse/pull/11892) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Compatibilidad con entrada/salida de UUID en Avro. [#11954](https://github.com/ClickHouse/ClickHouse/pull/11954) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Se añadió el motor de tabla MongoDB de solo lectura. Permite leer campos planos (tipos primitivos, no anidados). [#11983](https://github.com/ClickHouse/ClickHouse/pull/11983) ([alesapin](https://github.com/alesapin)).
* Se añade una configuración para los campos no encontrados en el esquema de Avro. [#12007](https://github.com/ClickHouse/ClickHouse/pull/12007) ([Andrew Onyshchuk](https://github.com/oandrew)).
* Se añade la función `parseDateTimeBestEffortUS`. [#12028](https://github.com/ClickHouse/ClickHouse/pull/12028) ([flynn](https://github.com/ucasfl)).
* #4006 Compatibilidad con ALTER TABLE ... [ADD|MODIFY] COLUMN ... FIRST. [#12073](https://github.com/ClickHouse/ClickHouse/pull/12073) ([Winter Zhang](https://github.com/zhang2014)).
* Se añade la función initializedAggregation para inicializar una agregación a partir de un único valor. [#12109](https://github.com/ClickHouse/ClickHouse/pull/12109) ([Guillaume Tassery](https://github.com/YiuRULE)).
* Compatibilidad con RIGHT y FULL JOIN con `set join_algorithm=partial_merge`. Solo se admite ALL como strictness (ANY, SEMI, ANTI y ASOF no). [#12118](https://github.com/ClickHouse/ClickHouse/pull/12118) ([Artem Zuikov](https://github.com/4ertus2)).
* Implementación del operador ILIKE al estilo de PostgreSQL para [#11710](https://github.com/ClickHouse/ClickHouse/issues/11710). [#12125](https://github.com/ClickHouse/ClickHouse/pull/12125) ([Mike Kot](https://github.com/myrrc)).

<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Permitir el uso de direct&#95;io y mmap&#95;io para índices secundarios si están configurados los ajustes `min_bytes_to_use_direct_io` o `min_bytes_to_use_mmap_io`. [#11955](https://github.com/ClickHouse/ClickHouse/pull/11955) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corregir la estimación del número de marks durante la lectura en MergeTree. Esto es necesario para gestionar correctamente los ajustes `merge_tree_max_rows_to_use_cache`, `merge_tree_max_bytes_to_use_cache`, `merge_tree_min_rows_for_concurrent_read`, `merge_tree_min_bytes_for_concurrent_read`, `merge_tree_min_rows_for_seek`, `merge_tree_min_bytes_for_seek`. Ahora, el ajuste `min_bytes_to_use_mmap_io` también se aplica a la lectura del índice y de las partes compactas en la familia de motores de tabla MergeTree. [#11970](https://github.com/ClickHouse/ClickHouse/pull/11970) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corregir &quot;[#10574](https://github.com/ClickHouse/ClickHouse/issues/10574) El índice no se usa para el operador IN con literales&quot;, una regresión del rendimiento introducida en torno a la versión 19.3. [#12062](https://github.com/ClickHouse/ClickHouse/pull/12062) ([nvartolomei](https://github.com/nvartolomei)).
* Eliminar las funciones inyectivas dentro de `uniq*()` si `set optimize_injective_functions_inside_uniq=1`. [#12337](https://github.com/ClickHouse/ClickHouse/pull/12337) ([Artem Zuikov](https://github.com/4ertus2)).
