<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Retroportado en [#41264](https://github.com/ClickHouse/ClickHouse/issues/41264): Se implementó la conversión automática del motor de base de datos de `Ordinary` a `Atomic`. Cree un archivo vacío `convert_ordinary_to_atomic` en el directorio `flags` y todas las bases de datos `Ordinary` se convertirán automáticamente la próxima vez que se inicie el servidor. Resuelve [#39546](https://github.com/ClickHouse/ClickHouse/issues/39546). [#39933](https://github.com/ClickHouse/ClickHouse/pull/39933) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#40886](https://github.com/ClickHouse/ClickHouse/issues/40886): Añade una configuración para desactivar el límite de kafka&#95;num&#95;consumers. Cierra [#40331](https://github.com/ClickHouse/ClickHouse/issues/40331). [#40670](https://github.com/ClickHouse/ClickHouse/pull/40670) ([Kruglov Pavel](https://github.com/Avogar)).

<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#41273](https://github.com/ClickHouse/ClickHouse/issues/41273): se corrigen problemas de seguridad de memoria en las funciones `encrypt` y `contingency` si se usa Array de Nullable como argumento. Esto corrige [#41004](https://github.com/ClickHouse/ClickHouse/issues/41004). [#40195](https://github.com/ClickHouse/ClickHouse/pull/40195) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* Retroportado en [#41639](https://github.com/ClickHouse/ClickHouse/issues/41639): se corrige una posible excepción `pipeline stuck` en consultas con `OFFSET`. * Retroportado en [#41899](https://github.com/ClickHouse/ClickHouse/issues/41899): se corrige un posible fallo en `SELECT` desde la tabla `Merge` con la configuración `optimize_monotonous_functions_in_order_by` habilitada. Corrige [#41269](https://github.com/ClickHouse/ClickHouse/issues/41269). [#41740](https://github.com/ClickHouse/ClickHouse/pull/41740) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
