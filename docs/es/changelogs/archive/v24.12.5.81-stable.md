<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Retroportado en [#75534](https://github.com/ClickHouse/ClickHouse/issues/75534): Se corrigió el cálculo del tamaño en memoria de las columnas `LowCardinality`. [#74688](https://github.com/ClickHouse/ClickHouse/pull/74688) ([Nikita Taranov](https://github.com/nickitat)).
* Retroportado en [#76005](https://github.com/ClickHouse/ClickHouse/issues/76005): Se descubrió que el control de concurrencia podía provocar una distribución desigual de la CPU entre INSERTs y SELECTs. Esto ocurría cuando todos los slots de CPU se asignaban incondicionalmente (sin competencia) a INSERTs con `max_threads` = 1, mientras que los SELECTs con valores altos de `max_threads` sufrían un rendimiento deficiente al usar solo un único hilo. [#75941](https://github.com/ClickHouse/ClickHouse/pull/75941) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#75535](https://github.com/ClickHouse/ClickHouse/issues/75535): Contabilización más precisa de la configuración `max_joined_block_size_rows` para el algoritmo JOIN `parallel_hash`. Ayuda a evitar un mayor consumo de memoria en comparación con el algoritmo `hash`. [#74630](https://github.com/ClickHouse/ClickHouse/pull/74630) ([Nikita Taranov](https://github.com/nickitat)).
* Retroportado en [#75844](https://github.com/ClickHouse/ClickHouse/issues/75844): Añade comprobación y registro para el descifrado y la descompresión. [#75471](https://github.com/ClickHouse/ClickHouse/pull/75471) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado en [#76046](https://github.com/ClickHouse/ClickHouse/issues/76046): Mejora de Keeper: deshabilita el cálculo del digest al hacer commit en el almacenamiento en memoria para mejorar el rendimiento. Puede habilitarse con la configuración `keeper_server.digest_enabled_on_commit`. El digest se sigue calculando al preprocesar solicitudes. [#75490](https://github.com/ClickHouse/ClickHouse/pull/75490) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#75709](https://github.com/ClickHouse/ClickHouse/issues/75709): Deshabilita el envío de configuraciones del server al client (`send_settings_to_client=false`) por compatibilidad (esta funcionalidad se volverá a implementar más adelante como configuración de cliente para mejorar la usabilidad). [#75648](https://github.com/ClickHouse/ClickHouse/pull/75648) ([Michael Kolupaev](https://github.com/al13n321)).
* Retroportado en [#75805](https://github.com/ClickHouse/ClickHouse/issues/75805): Añade la configuración `memory_worker_correct_memory_tracker` para habilitar la corrección del memory tracker interno con información de distintas fuentes, leída periódicamente en el background thread. [#75714](https://github.com/ClickHouse/ClickHouse/pull/75714) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#76069](https://github.com/ClickHouse/ClickHouse/issues/76069): Añade la métrica `MemoryTrackingUncorrected`, que muestra el valor del memory tracker global interno que no se corrige mediante RSS. [#75935](https://github.com/ClickHouse/ClickHouse/pull/75935) ([Antonio Andelic](https://github.com/antonio2368)).
