<div id="bug-fix">
  #### Corrección de errores
</div>

* Backported en [#24969](https://github.com/ClickHouse/ClickHouse/issues/24969): Se permiten valores NULL en el protocolo postgresql. Cierra [#22622](https://github.com/ClickHouse/ClickHouse/issues/22622). [#24857](https://github.com/ClickHouse/ClickHouse/pull/24857) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Backported en [#25186](https://github.com/ClickHouse/ClickHouse/issues/25186): Se corrigió un error al declarar un disco S3 en la raíz del bucket. Anteriormente, se reportaba el siguiente error: ``` [heather] 2021.05.10 02:11:11.932234 [ 72790 ] {2ff80b7b-ec53-41cb-ac35-19bb390e1759} <Error> executeQuery: Code: 36, e.displayText() = DB::Exception: Key name is empty in path style S3 URI: (http://172.17.0.2/bucket/) (version 21.6.1.1) (from 127.0.0.1:47994) (in query: SELECT policy_name FROM system.storage_policies), Stack trace (when copying this message, always include the lines below):. [#24898](https://github.com/ClickHouse/ClickHouse/pull/24898) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Backported en [#25023](https://github.com/ClickHouse/ClickHouse/issues/25023): Se corrigen las configuraciones de límite/offset para consultas distribuidas (se ignoran en los nodos remotos). [#24940](https://github.com/ClickHouse/ClickHouse/pull/24940) ([Azat Khuzhin](https://github.com/azat)).
* Backported en [#25049](https://github.com/ClickHouse/ClickHouse/issues/25049): Se corrige el error extremadamente infrecuente `Tagging already tagged part` en la cola de replicación durante la ejecución concurrente de `alter move/replace partition`. Posiblemente corrige [#22142](https://github.com/ClickHouse/ClickHouse/issues/22142). [#24961](https://github.com/ClickHouse/ClickHouse/pull/24961) ([alesapin](https://github.com/alesapin)).
* Backported en [#25081](https://github.com/ClickHouse/ClickHouse/issues/25081): Se corrige un resultado incorrecto al usar una proyección de agregación con una clave `GROUP BY` **no vacía** para ejecutar una consulta con `GROUP BY` por clave **vacía**. [#25055](https://github.com/ClickHouse/ClickHouse/pull/25055) ([Amos Bird](https://github.com/amosbird)).
* Backported en [#25107](https://github.com/ClickHouse/ClickHouse/issues/25107): Se corrige un error que permitía crear tablas con columnas que se referenciaban a sí mismas, como `a UInt32 ALIAS a + 1` o `b UInt32 MATERIALIZED b`. Corrige [#24910](https://github.com/ClickHouse/ClickHouse/issues/24910), [#24292](https://github.com/ClickHouse/ClickHouse/issues/24292). [#25059](https://github.com/ClickHouse/ClickHouse/pull/25059) ([alesapin](https://github.com/alesapin)).
* Backported en [#25106](https://github.com/ClickHouse/ClickHouse/issues/25106): Se corrige un error con maps constantes en mapContains que producía el error `empty column was returned by function mapContains`. Cierra [#25077](https://github.com/ClickHouse/ClickHouse/issues/25077). [#25080](https://github.com/ClickHouse/ClickHouse/pull/25080) ([Kruglov Pavel](https://github.com/Avogar)).
* Backported en [#25143](https://github.com/ClickHouse/ClickHouse/issues/25143): Se corrige un crash en consultas con CROSS JOIN y `joined_subquery_requires_alias = 0`. Corrige [#24011](https://github.com/ClickHouse/ClickHouse/issues/24011). [#25082](https://github.com/ClickHouse/ClickHouse/pull/25082) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Backported en [#25157](https://github.com/ClickHouse/ClickHouse/issues/25157): Se corrige la posible pérdida de partes tras actualizar a la versión 21.5 cuando la tabla utilizaba `UUID` en la clave de partición. (No se recomienda usar `UUID` en la clave de partición). Corrige [#25070](https://github.com/ClickHouse/ClickHouse/issues/25070). [#25127](https://github.com/ClickHouse/ClickHouse/pull/25127) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Backported en [#25182](https://github.com/ClickHouse/ClickHouse/issues/25182): No se utiliza la proyección de la tabla para `SELECT` con `FINAL`, ya que aún no está soportado. [#25163](https://github.com/ClickHouse/ClickHouse/pull/25163) ([Amos Bird](https://github.com/amosbird)).
