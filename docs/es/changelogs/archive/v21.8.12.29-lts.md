<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#31575](https://github.com/ClickHouse/ClickHouse/issues/31575): no se alcanzó el límite de cuota, pero se superó el límite. Esta PR corrige [#31174](https://github.com/ClickHouse/ClickHouse/issues/31174). [#31337](https://github.com/ClickHouse/ClickHouse/pull/31337) ([sunny](https://github.com/sunny19930321)).

<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Corrección de errores (comportamiento incorrecto visible para el usuario en la versión estable oficial)
</div>

* Retroportado en [#31204](https://github.com/ClickHouse/ClickHouse/issues/31204): Se corrigió un abort en el servidor de depuración y el error `DB::Exception: std::out_of_range: basic_string` en el servidor en release en caso de una URL de hdfs no válida, añadiendo una comprobación adicional de la estructura de la URL de hdfs. [#31042](https://github.com/ClickHouse/ClickHouse/pull/31042) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#31253](https://github.com/ClickHouse/ClickHouse/issues/31253): Se corrigió un bug en Keeper que puede impedir el arranque cuando se han perdido algunos logs de coordinación y tenemos un snapshot más reciente que nuestro último log. [#31150](https://github.com/ClickHouse/ClickHouse/pull/31150) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#31521](https://github.com/ClickHouse/ClickHouse/issues/31521): Se eliminó la función not like de RPNElement. [#31169](https://github.com/ClickHouse/ClickHouse/pull/31169) ([sundyli](https://github.com/sundy-li)).
* Retroportado en [#31552](https://github.com/ClickHouse/ClickHouse/issues/31552): Se resolvió `nullptr` en el proveedor de credenciales STS para S3. [#31409](https://github.com/ClickHouse/ClickHouse/pull/31409) ([Vladimir Chebotarev](https://github.com/excitoon)).
* Retroportado en [#31582](https://github.com/ClickHouse/ClickHouse/issues/31582): * Se deshabilitó `partial_merge_join_left_table_buffer_bytes` hasta que se corrija el bug en esta optimización. Véase [#31009](https://github.com/ClickHouse/ClickHouse/issues/31009)). * Se eliminó la opción redundante `partial_merge_join_optimizations`. [#31528](https://github.com/ClickHouse/ClickHouse/pull/31528) ([Vladimir C](https://github.com/vdimir)).
* Retroportado en [#31599](https://github.com/ClickHouse/ClickHouse/issues/31599): Se corrigió la generación de JSON no válido cuando solo los nombres de columna contienen secuencias UTF-8 no válidas. [#31534](https://github.com/ClickHouse/ClickHouse/pull/31534) ([Kevin Michel](https://github.com/kmichel-aiven)).
* Retroportado en [#31779](https://github.com/ClickHouse/ClickHouse/issues/31779): La consulta `RENAME TABLE` funcionaba incorrectamente al intentar cambiar el nombre de un diccionario DDL en una base de datos `Ordinary`; ya se ha corregido. [#31638](https://github.com/ClickHouse/ClickHouse/pull/31638) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#31790](https://github.com/ClickHouse/ClickHouse/issues/31790): Los ajustes `input_format_allow_errors_num` e `input_format_allow_errors_ratio` no funcionaban para el análisis de tipos de dominio, como `IPv4`; ya se ha corregido. Corrige [#31686](https://github.com/ClickHouse/ClickHouse/issues/31686). [#31697](https://github.com/ClickHouse/ClickHouse/pull/31697) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#31829](https://github.com/ClickHouse/ClickHouse/issues/31829): Se corrigió el error `there are no such cluster here` al ejecutar una consulta `ON CLUSTER` si el nombre del clúster especificado es el nombre de una base de datos `Replicated`. [#31723](https://github.com/ClickHouse/ClickHouse/pull/31723) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#31813](https://github.com/ClickHouse/ClickHouse/issues/31813): Se corrigió una condición de carrera en el formato de salida JSONEachRowWithProgress cuando los datos y las líneas de progreso se mezclan en la salida. [#31736](https://github.com/ClickHouse/ClickHouse/pull/31736) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#31761](https://github.com/ClickHouse/ClickHouse/issues/31761): Se corrigió el uso del motor de tabla `Buffer` con el tipo `Map`. Corrige [#30546](https://github.com/ClickHouse/ClickHouse/issues/30546). [#31742](https://github.com/ClickHouse/ClickHouse/pull/31742) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#31890](https://github.com/ClickHouse/ClickHouse/issues/31890): Soluciona un posible fallo de aserción `../src/IO/ReadBuffer.h:58: bool DB::ReadBuffer::next(): Assertion '!hasPendingData()' failed.` en el formato TSKV. [#31804](https://github.com/ClickHouse/ClickHouse/pull/31804) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#31910](https://github.com/ClickHouse/ClickHouse/issues/31910): Corrige las funciones `empty` y `notEmpty` cuando reciben argumentos de tipo `UUID`. Soluciona [#31819](https://github.com/ClickHouse/ClickHouse/issues/31819). [#31883](https://github.com/ClickHouse/ClickHouse/pull/31883) ([Anton Popov](https://github.com/CurtizJ)).
