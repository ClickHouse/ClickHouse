<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Añade la capacidad de restablecer una configuración personalizada a su valor predeterminado y eliminarla de los metadatos de la tabla. Esto permitirá revertir el cambio sin conocer el valor predeterminado del sistema o de la configuración. Cierra [#14449](https://github.com/ClickHouse/ClickHouse/issues/14449). [#17769](https://github.com/ClickHouse/ClickHouse/pull/17769) ([xjewer](https://github.com/xjewer)).
* Añade el motor de tabla y el motor de base de datos MaterializedPostgreSQL. El motor de base de datos permite replicar una base de datos completa o cualquier subconjunto de sus tablas. [#20470](https://github.com/ClickHouse/ClickHouse/pull/20470) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Añade compatibilidad con parte del estándar SQLJSON. [#24148](https://github.com/ClickHouse/ClickHouse/pull/24148) ([l1tsolaiki](https://github.com/l1tsolaiki)).
* Recopila métricas comunes del sistema (en `system.asynchronous_metrics` y `system.asynchronous_metric_log`) sobre uso de CPU, uso de disco, uso de memoria, IO, red, archivos, promedio de carga, frecuencias de CPU, sensores térmicos, contadores EDAC y uptime del sistema; además, se añadieron métricas sobre el jitter de planificación y el tiempo dedicado a recopilar las métricas. Funciona como `atop` en ClickHouse y permite obtener datos de monitorización incluso si no tienes herramientas adicionales instaladas. Esto cierra [#9430](https://github.com/ClickHouse/ClickHouse/issues/9430). [#24416](https://github.com/ClickHouse/ClickHouse/pull/24416) ([Yegor Levankov](https://github.com/elevankoff)).
* Añade compatibilidad con la expresión `DISTINCT ON (columns)`, cierra [#25404](https://github.com/ClickHouse/ClickHouse/issues/25404). [#25589](https://github.com/ClickHouse/ClickHouse/pull/25589) ([Zijie Lu](https://github.com/TszKitLo40)).
* * Compatibilidad con el tipo Map en las funciones `mapAdd` y `mapSubtract` * Compatibilidad con los tipos (U)Int128 y U(Int256) en las funciones `mapAdd` y `mapSubtract`. [#25596](https://github.com/ClickHouse/ClickHouse/pull/25596) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Añade compatibilidad con las funciones `bin` y `unbin`. [#25609](https://github.com/ClickHouse/ClickHouse/pull/25609) ([zhaoyu](https://github.com/zxc111)).
* Introduce la tabla `system.data_skipping_indices`, que contiene información sobre los data skipping indices existentes. Cierra [#7659](https://github.com/ClickHouse/ClickHouse/issues/7659). [#25693](https://github.com/ClickHouse/ClickHouse/pull/25693) ([Dmitry Novik](https://github.com/novikd)).
* además de [https://github.com/ClickHouse/ClickHouse/pull/12073](https://github.com/ClickHouse/ClickHouse/pull/12073), añade la palabra clave FIRST al comando ADD INDEX para poder añadir un índice al principio de la lista de índices. [#25904](https://github.com/ClickHouse/ClickHouse/pull/25904) ([xjewer](https://github.com/xjewer)).
* Representa las canalización como grafos en la UI web si se proporciona la consulta `EXPLAIN PIPELINE graph = 1`. [#26067](https://github.com/ClickHouse/ClickHouse/pull/26067) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Añade las nuevas funciones `leftPad()`, `rightPad()`, `leftPadUTF8()`, `rightPadUTF8()`. [#26075](https://github.com/ClickHouse/ClickHouse/pull/26075) ([Vitaly Baranov](https://github.com/vitlibar)).
