<div id="bug-fix">
  #### Corrección de errores
</div>

* Retroportado en [#43099](https://github.com/ClickHouse/ClickHouse/issues/43099): Se actualizó el normalizador para clonar el AST del alias. Resuelve [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452). Implementación: * Se actualizó QueryNormalizer para clonar el AST del alias cuando se reemplaza. Antes, asignar simplemente el mismo provocaba una excepción en LogicalExpressinsOptimizer, ya que se insertaba de nuevo el mismo parent. * Este bug no se observa con el nuevo analyzer (allow&#95;experimental&#95;analyzer), por lo que no hay cambios para él. Añadí una prueba para ello. [#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
