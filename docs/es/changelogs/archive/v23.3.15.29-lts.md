<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#55671](https://github.com/ClickHouse/ClickHouse/issues/55671): si la base de datos ya está inicializada, no es necesario volver a inicializarla en inicios posteriores. Esto podría solucionar el problema de reinicios infinitos del contenedor cuando la base de datos no logra cargarse tras 1000 intentos (relevante para bases de datos muy grandes y configuraciones multinodo). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* Retroportado en [#55734](https://github.com/ClickHouse/ClickHouse/issues/55734): corregir el script de Python de comprobación de integración para que use la URL de la API de gh; añadir un Readme para las pruebas de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
* Retroportado en [#55829](https://github.com/ClickHouse/ClickHouse/issues/55829): comprobar sha512 para tgz; usar un repositorio adecuado para Keeper; escribir solo los nombres de archivo en los archivos TGZ.sha512 para los paquetes tarball. Prerrequisito para [#31473](https://github.com/ClickHouse/ClickHouse/issues/31473). [#55717](https://github.com/ClickHouse/ClickHouse/pull/55717) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
