* Retroportado en [#13301](https://github.com/ClickHouse/ClickHouse/issues/13301): La función `groupArrayMoving*` no funcionaba con consultas distribuidas. Su resultado se calculaba con un tipo de dato incorrecto (sin promoción al tipo más amplio). La función `groupArrayMovingAvg` devolvía un número entero, lo que era inconsistente con la función `avg`. Esto corrige [#12568](https://github.com/ClickHouse/ClickHouse/issues/12568). [#12622](https://github.com/ClickHouse/ClickHouse/pull/12622) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#13029](https://github.com/ClickHouse/ClickHouse/issues/13029): CREATE USER IF NOT EXISTS ahora no lanza una excepción si el usuario ya existe. Esto corrige [#12507](https://github.com/ClickHouse/ClickHouse/issues/12507). [#12646](https://github.com/ClickHouse/ClickHouse/pull/12646) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado en [#12983](https://github.com/ClickHouse/ClickHouse/issues/12983): Se corrige la duplicación de columnas en un Diccionario range hashed creado a partir de una consulta DDL. Esto corrige [#10605](https://github.com/ClickHouse/ClickHouse/issues/10605). [#12857](https://github.com/ClickHouse/ClickHouse/pull/12857) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#13222](https://github.com/ClickHouse/ClickHouse/issues/13222): Se corrigen las funciones de conversión de DateTime64 con un argumento constante. [#13205](https://github.com/ClickHouse/ClickHouse/pull/13205) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#13245](https://github.com/ClickHouse/ClickHouse/issues/13245): Se corrige un assert en la función `arrayElement` cuando los elementos del array son Nullable y el subíndice del array también es Nullable. Esto corrige [#12172](https://github.com/ClickHouse/ClickHouse/issues/12172). [#13224](https://github.com/ClickHouse/ClickHouse/pull/13224) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#13267](https://github.com/ClickHouse/ClickHouse/issues/13267): Se corrige la función if cuando `cond` es un constexpr nullable que no es el literal NULL. Corrige [#12463](https://github.com/ClickHouse/ClickHouse/issues/12463). [#13226](https://github.com/ClickHouse/ClickHouse/pull/13226) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#13298](https://github.com/ClickHouse/ClickHouse/issues/13298): Se corrigen un rendimiento potencialmente bajo y un resultado ligeramente incorrecto en `uniqExact`, `topK`, `sumDistinct` y funciones de agregación similares cuando se llaman sobre tipos Float con valores NaN. Esto también activaba un assert en una compilación de debug. Esto corrige [#12491](https://github.com/ClickHouse/ClickHouse/issues/12491). [#13254](https://github.com/ClickHouse/ClickHouse/pull/13254) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#13316](https://github.com/ClickHouse/ClickHouse/issues/13316): El server puede fallar si el usuario pasa argumentos especialmente diseñados a la función `h3ToChildren`. Esto corrige [#13275](https://github.com/ClickHouse/ClickHouse/issues/13275). [#13277](https://github.com/ClickHouse/ClickHouse/pull/13277) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#13329](https://github.com/ClickHouse/ClickHouse/issues/13329): Se corrige el posible error `Totals having transform was already added to pipeline` en el caso de una consulta desde una réplica con retraso. * Retroportado en [#13375](https://github.com/ClickHouse/ClickHouse/issues/13375): Corrige el segfault al deserializar un estado vacío en la función `groupArrayMovingSum`. Corrige [#13339](https://github.com/ClickHouse/ClickHouse/issues/13339). [#13341](https://github.com/ClickHouse/ClickHouse/pull/13341) ([alesapin](https://github.com/alesapin)).
