<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Corrección de errores (comportamiento incorrecto visible para el usuario en la versión estable oficial)
</div>

* Retroportado en [#28569](https://github.com/ClickHouse/ClickHouse/issues/28569): Corrige un bug que puede provocar el error `Existing table metadata in ZooKeeper differs in sorting key expression.` tras un `alter` de `ReplicatedVersionedCollapsingMergeTree`. Corrige [#28515](https://github.com/ClickHouse/ClickHouse/issues/28515). [#28528](https://github.com/ClickHouse/ClickHouse/pull/28528) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#28857](https://github.com/ClickHouse/ClickHouse/issues/28857): Corrige una condición de carrera inocua en ReplicatedMergeTreeQueue. No debería ser visible para el usuario, pero puede dar lugar a bugs sutiles. [#28734](https://github.com/ClickHouse/ClickHouse/pull/28734) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#28995](https://github.com/ClickHouse/ClickHouse/issues/28995): Corrige la lectura de subcolumnas desde partes compactas. [#28873](https://github.com/ClickHouse/ClickHouse/pull/28873) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#28929](https://github.com/ClickHouse/ClickHouse/issues/28929): Corrige las funciones de orden superior para arrays (`SIGSEGV` para `arrayCompact`/`ILLEGAL_COLUMN` para `arrayDifference`/`arrayCumSumNonNegative`) con constantes. [#28904](https://github.com/ClickHouse/ClickHouse/pull/28904) ([Azat Khuzhin](https://github.com/azat)).
