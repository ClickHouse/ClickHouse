<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Retroportado en [#77183](https://github.com/ClickHouse/ClickHouse/issues/77183): Se deshabilitan las réplicas paralelas de forma predeterminada cuando analyzer está deshabilitado, independientemente de la configuración de `compatibility`. Sigue siendo posible cambiar este comportamiento estableciendo explícitamente `parallel_replicas_only_with_analyzer` en `false`. [#77115](https://github.com/ClickHouse/ClickHouse/pull/77115) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Retroportado en [#77358](https://github.com/ClickHouse/ClickHouse/issues/77358): se añadió la configuración del servidor `concurrent_threads_scheduler`, que determina cómo se distribuyen los slots de CPU entre las consultas concurrentes. Puede configurarse como `round_robin` (comportamiento anterior) o `fair_round_robin` para corregir el problema de la distribución desigual de CPU entre las operaciones INSERT y SELECT. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#76999](https://github.com/ClickHouse/ClickHouse/issues/76999): Se corrige la pérdida de datos al habilitar async insert y ejecutar `insert into ... from file ...` con tamaños de bloque distintos: si el tamaño del primer bloque es &lt; `async_max_size` pero el del segundo es &gt; `async_max_size`, el segundo bloque no se inserta. Estos datos quedan en `squashing`. [#76343](https://github.com/ClickHouse/ClickHouse/pull/76343) ([Han Fei](https://github.com/hanfei1991)).
* Retroportado en [#76970](https://github.com/ClickHouse/ClickHouse/issues/76970): Se corrige la excepción THERE&#95;IS&#95;NO&#95;COLUMN al seleccionar un literal booleano desde tablas distribuidas. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Retroportado en [#77049](https://github.com/ClickHouse/ClickHouse/issues/77049): Se corrige el manejo de excepciones en la deserialización en paralelo de prefijos de subcolumnas JSON. [#76809](https://github.com/ClickHouse/ClickHouse/pull/76809) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77260](https://github.com/ClickHouse/ClickHouse/issues/77260): Se corrige un posible crash debido a un rollback incorrecto de una columna JSON en caso de error durante async inserts. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77064](https://github.com/ClickHouse/ClickHouse/issues/77064): Se corrige la ordenación de valores `BFloat16`. Esto cierra [#75487](https://github.com/ClickHouse/ClickHouse/issues/75487). Esto cierra [#75669](https://github.com/ClickHouse/ClickHouse/issues/75669). [#77000](https://github.com/ClickHouse/ClickHouse/pull/77000) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#77222](https://github.com/ClickHouse/ClickHouse/issues/77222): Se corrige un error en JSON con subcolumnas Variant añadiendo una comprobación para omitir las subcolumnas efímeras en la comprobación de consistencia de las partes. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado en [#77250](https://github.com/ClickHouse/ClickHouse/issues/77250): Se corrige un crash durante la creación de una tabla Kafka cuando se produce una excepción. [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77240](https://github.com/ClickHouse/ClickHouse/issues/77240): Soporte para el nuevo JSON y las subcolumnas en los motores Kafka y RabbitMQ. [#77122](https://github.com/ClickHouse/ClickHouse/pull/77122) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77386](https://github.com/ClickHouse/ClickHouse/issues/77386): `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` ahora devuelve correctamente `true` (antes `false`). Esto hace que el comportamiento sea coherente con `Float32` y `Float64`. [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Retroportado en [#77379](https://github.com/ClickHouse/ClickHouse/issues/77379): Se corrige el nombre de la partición para un valor Bool. Quedó roto en [https://github.com/ClickHouse/ClickHouse/pull/74533](https://github.com/ClickHouse/ClickHouse/pull/74533). [#77319](https://github.com/ClickHouse/ClickHouse/pull/77319) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77335](https://github.com/ClickHouse/ClickHouse/issues/77335): Se corrige la comparación entre tuplas con elementos Nullable y cadenas. [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
