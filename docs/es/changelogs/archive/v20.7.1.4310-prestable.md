<div id="clickhouse-release-v20714310-prestable-fixme-as-compared-to-v20614066-prestable">
  ### Lanzamiento de ClickHouse v20.7.1.4310-prestable FIXME en comparación con v20.6.1.4066-prestable
</div>

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Se deja obsoleta la representación especial de los valores cero de Date/DateTime como `0000-00-00` y `0000-00-00 00:00:00`. [#12442](https://github.com/ClickHouse/ClickHouse/pull/12442) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* La función `modulo` (operador `%`), con al menos un número de coma flotante como argumento, calculará el resto de la división directamente con números de coma flotante, sin convertir ambos argumentos en enteros. Esto hace que el comportamiento sea compatible con la mayoría de los DBMS. Esto también se aplica a los tipos de datos Date y DateTime. Se añadió el alias `mod`. Con esto se cierra [#7323](https://github.com/ClickHouse/ClickHouse/issues/7323). [#12585](https://github.com/ClickHouse/ClickHouse/pull/12585) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* * Se añadió compatibilidad con la autenticación LDAP para usuarios preconfigurados (método &quot;Simple Bind&quot;). [#11234](https://github.com/ClickHouse/ClickHouse/pull/11234) ([Denis Glazachev](https://github.com/traceon)).
* Se añaden las funciones `mapAdd` y `mapSubtract` para trabajar con mapas de tuplas. [#11735](https://github.com/ClickHouse/ClickHouse/pull/11735) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Se añadió la tabla `system.crash_log`, en la que se recopilan trazas de pila de errores fatales. [#12316](https://github.com/ClickHouse/ClickHouse/pull/12316) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se añade la función `bayesAB` para pruebas A/B bayesianas. [#12327](https://github.com/ClickHouse/ClickHouse/pull/12327) ([achimbab](https://github.com/achimbab)).
* Integración con [COS](https://intl.cloud.tencent.com/product/cos). [#12386](https://github.com/ClickHouse/ClickHouse/pull/12386) ([fastio](https://github.com/fastio)).
* * Se añade la función `FROM_UNIXTIME`, relacionada con [12149](https://github.com/ClickHouse/ClickHouse/issues/12149). [#12484](https://github.com/ClickHouse/ClickHouse/pull/12484) ([flynn](https://github.com/ucasfl)).
* Se añade la función `formatRow` para convertir expresiones arbitrarias en una cadena mediante un formato dado. Es útil para manipular salidas SQL y resulta muy versátil en combinación con la función `columns`. [#12574](https://github.com/ClickHouse/ClickHouse/pull/12574) ([Amos Bird](https://github.com/amosbird)).
* Se añade la configuración `allow_non_metadata_alters`, que restringe la ejecución de consultas `ALTER` que modifican datos en disco. Está deshabilitada de forma predeterminada. Cierra [#11547](https://github.com/ClickHouse/ClickHouse/issues/11547). [#12635](https://github.com/ClickHouse/ClickHouse/pull/12635) ([alesapin](https://github.com/alesapin)).
* Se añade compatibilidad con las funciones `minMap` y `maxMap` en `SimpleAggregateFunction`. [#12662](https://github.com/ClickHouse/ClickHouse/pull/12662) ([Ildus Kurbangaliev](https://github.com/ildus)).
* Se añadieron los encabezados HTTP `X-ClickHouse-Database` y `X-ClickHouse-Format`, que pueden usarse para establecer la base de datos predeterminada y el formato de salida. [#12981](https://github.com/ClickHouse/ClickHouse/pull/12981) ([hcz](https://github.com/hczhcz)).
* Se implementan configuraciones definidas por el usuario. [#13013](https://github.com/ClickHouse/ClickHouse/pull/13013) ([Vitaly Baranov](https://github.com/vitlibar)).
