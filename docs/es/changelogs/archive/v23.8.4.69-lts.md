<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#55673](https://github.com/ClickHouse/ClickHouse/issues/55673): Si la base de datos ya está inicializada, no es necesario inicializarla de nuevo en lanzamientos posteriores. Esto puede solucionar potencialmente el issue de reinicios infinitos del contenedor cuando la base de datos no logra cargarse en 1000 intentos (relevante para bases de datos muy grandes y configuraciones multinodo). [#50724](https://github.com/ClickHouse/ClickHouse/pull/50724) ([Alexander Nikolaev](https://github.com/AlexNik)).
* Retroportado en [#55293](https://github.com/ClickHouse/ClickHouse/issues/55293): El recurso con código fuente que incluye submódulos se compila en la tarea especial de compilación de Darwin. Puede usarse para compilar ClickHouse sin tener que descargar los submódulos. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Retroportado en [#55366](https://github.com/ClickHouse/ClickHouse/issues/55366): Se resuelve el issue al iniciar clickhouse-keeper standalone desde el paquete clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado en [#55725](https://github.com/ClickHouse/ClickHouse/issues/55725): Se corrige el script de Python de comprobación de integración para que use la URL de la API de gh; se añade un Readme para las pruebas de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/maxknv)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#55304](https://github.com/ClickHouse/ClickHouse/issues/55304): Se corrige &quot;Invalid number of rows in Chunk&quot; en MaterializedPostgreSQL (lo que podía ocurrir con PostgreSQL versión &gt;= 13). [#54844](https://github.com/ClickHouse/ClickHouse/pull/54844) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#55018](https://github.com/ClickHouse/ClickHouse/issues/55018): Se mueven las configuraciones de formato obsoletas a una sección independiente y se usa junto con todas las configuraciones de formato para evitar excepciones `Unknown setting` al usar configuraciones de formato obsoletas. Cierra [#54792](https://github.com/ClickHouse/ClickHouse/issues/54792) ### Entrada de documentación para cambios visibles para el usuario. [#54855](https://github.com/ClickHouse/ClickHouse/pull/54855) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#55097](https://github.com/ClickHouse/ClickHouse/issues/55097): El quorum de insert podía marcarse incorrectamente como satisfecho en caso de reintentos de Keeper mientras se esperaba el quorum. Corrige [#54543](https://github.com/ClickHouse/ClickHouse/issues/54543). [#55026](https://github.com/ClickHouse/ClickHouse/pull/55026) ([Igor Nikonov](https://github.com/devcrafter)).
* Retroportado en [#55473](https://github.com/ClickHouse/ClickHouse/issues/55473): Evita adjuntar particiones desde tablas que no tienen definidos los mismos índices o proyecciones. [#55062](https://github.com/ClickHouse/ClickHouse/pull/55062) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Retroportado en [#55461](https://github.com/ClickHouse/ClickHouse/issues/55461): Si se produce una excepción en el constructor de `ShellCommandSource` después de que se hayan iniciado algunos de los `send_data_threads`, es necesario hacerles join(); de lo contrario, se activará abort() en el destructor de `ThreadFromGlobalPool`. Corrige [#55091](https://github.com/ClickHouse/ClickHouse/issues/55091). [#55103](https://github.com/ClickHouse/ClickHouse/pull/55103) ([Alexander Gololobov](https://github.com/davenger)).
* Retroportado en [#55412](https://github.com/ClickHouse/ClickHouse/issues/55412): Se corrige un interbloqueo en la actualización de roles asignados por LDAP para roles de ClickHouse inexistentes. [#55119](https://github.com/ClickHouse/ClickHouse/pull/55119) ([Julian Maicher](https://github.com/jmaicher)).
* Retroportado en [#55323](https://github.com/ClickHouse/ClickHouse/issues/55323): Se corrige la descarga en segundo plano en la caché de fs. [#55252](https://github.com/ClickHouse/ClickHouse/pull/55252) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#55349](https://github.com/ClickHouse/ClickHouse/issues/55349): Se corrige la ejecución de funciones sobre columnas dispersas (corrige el error `DB::Exception: isDefaultAt is not implemented for Function: while executing 'FUNCTION Capture`). [#55275](https://github.com/ClickHouse/ClickHouse/pull/55275) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#55475](https://github.com/ClickHouse/ClickHouse/issues/55475): Se corrige un issue relacionado con la imposibilidad de eliminar una partición detached en la familia de motores `ReplicatedMergeTree` sobre S3 (sin zero-copy replication). Corrige el issue [#55225](https://github.com/ClickHouse/ClickHouse/issues/55225). Se corrige un error con blobs abandonados en S3 para tipos de datos complejos como Arrays o columnas Nested. Corrige parcialmente [#52393](https://github.com/ClickHouse/ClickHouse/issues/52393). Muchas gracias a @alifirat por los ejemplos. [#55309](https://github.com/ClickHouse/ClickHouse/pull/55309) ([alesapin](https://github.com/alesapin)).
* Retroportado en [#55399](https://github.com/ClickHouse/ClickHouse/issues/55399): Una optimización introducida hace un año era incorrecta. Esto cierra [#55272](https://github.com/ClickHouse/ClickHouse/issues/55272). [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#55437](https://github.com/ClickHouse/ClickHouse/issues/55437): Se corrige el análisis de arrays en el operador CAST (`::`). [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* Retroportado en [#55635](https://github.com/ClickHouse/ClickHouse/issues/55635): Se corrige el filtrado por columnas virtuales con el filtro OR en la consulta (filtrado de `_part*` para `MergeTree`, de `_path`/`_file` para varios motores `File`/`HDFS`/..., y de `_table` para `Merge`). [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#55445](https://github.com/ClickHouse/ClickHouse/issues/55445): Se corrigen problemas de conexión que se producían con algunas versiones de MongoDB. Cierra [#55376](https://github.com/ClickHouse/ClickHouse/issues/55376), [#55232](https://github.com/ClickHouse/ClickHouse/issues/55232). [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* Retroportado en [#55534](https://github.com/ClickHouse/ClickHouse/issues/55534): Se corrige un posible interbloqueo causado por una fibra no destruida en caso de excepción durante la cancelación asíncrona de tareas. Cierra [#55185](https://github.com/ClickHouse/ClickHouse/issues/55185). [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#55747](https://github.com/ClickHouse/ClickHouse/issues/55747): Se corrige un fallo en QueryNormalizer con alias cíclicos. [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* Retroportado en [#55760](https://github.com/ClickHouse/ClickHouse/issues/55760): Se corrige el filtrado por columnas virtuales con el filtro OR en la consulta (filtrado de &#95;part* para MergeTree, de &#95;path/&#95;file para varios motores File/HDFS/..., y de &#95;table para Merge). [#55678](https://github.com/ClickHouse/ClickHouse/pull/55678) ([Azat Khuzhin](https://github.com/azat)).
