<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#75640](https://github.com/ClickHouse/ClickHouse/issues/75640): Corrige el mensaje de error del script de inicialización de Docker para que resulte más claro. [#71734](https://github.com/ClickHouse/ClickHouse/pull/71734) ([Андрей](https://github.com/andreineustroev)).
* Retroportado en [#76227](https://github.com/ClickHouse/ClickHouse/issues/76227): Corrige un cierre inesperado debido a una excepción no capturada en la replicación de PSQL. [#75062](https://github.com/ClickHouse/ClickHouse/pull/75062) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#76101](https://github.com/ClickHouse/ClickHouse/issues/76101): Corrige el manejo de JOIN seguro ante NULL para el tipo de dato Nullable de LowCardinality. Anteriormente, JOIN ON con comparación segura ante NULL, como `IS NOT DISTINCT FROM`, `<=>` , `a IS NULL AND b IS NULL OR a == b`, no funcionaba correctamente con columnas LowCardinality. [#75143](https://github.com/ClickHouse/ClickHouse/pull/75143) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Retroportado en [#75830](https://github.com/ClickHouse/ClickHouse/issues/75830): Corrige una desreferenciación de puntero NULL en `DistinctSortedStreamTransform`. [#75734](https://github.com/ClickHouse/ClickHouse/pull/75734) ([Nikita Taranov](https://github.com/nickitat)).
