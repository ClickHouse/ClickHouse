<div id="bug-fix-user-visible-misbehaviour-in-official-stable-release">
  #### Corrección de errores (comportamiento incorrecto visible para el usuario en la versión estable oficial)
</div>

* Retroportado en [#32890](https://github.com/ClickHouse/ClickHouse/issues/32890): Se corrige LOGICAL&#95;ERROR cuando el destino de una vista materializada es una tabla JOIN o SET. [#32669](https://github.com/ClickHouse/ClickHouse/pull/32669) ([Raúl Marín](https://github.com/Algunenano)).
* Retroportado en [#33183](https://github.com/ClickHouse/ClickHouse/issues/33183): El servidor podía no iniciar si una base de datos con engine `MySQL` no podía conectarse al MySQL server; ya está corregido. Corrige [#14441](https://github.com/ClickHouse/ClickHouse/issues/14441). [#32802](https://github.com/ClickHouse/ClickHouse/pull/32802) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#32904](https://github.com/ClickHouse/ClickHouse/issues/32904): El engine de tabla `MergeTree` podía omitir silenciosamente algunas mutaciones si había demasiadas mutaciones en ejecución o en caso de alto consumo de memoria; ya está corregido. Corrige [#17882](https://github.com/ClickHouse/ClickHouse/issues/17882). [#32814](https://github.com/ClickHouse/ClickHouse/pull/32814) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#33047](https://github.com/ClickHouse/ClickHouse/issues/33047): Se corrige la optimización con seek diferido para lecturas asíncronas desde remote fs. Cierra [#32803](https://github.com/ClickHouse/ClickHouse/issues/32803). [#32835](https://github.com/ClickHouse/ClickHouse/pull/32835) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#32932](https://github.com/ClickHouse/ClickHouse/issues/32932): Cierra [#32487](https://github.com/ClickHouse/ClickHouse/issues/32487). [#32914](https://github.com/ClickHouse/ClickHouse/pull/32914) ([Vladimir C](https://github.com/vdimir)).
* Retroportado en [#32962](https://github.com/ClickHouse/ClickHouse/issues/32962): Se corrige una regresión en la función `replaceRegexpAll`. La función funcionaba incorrectamente cuando la subcadena coincidente estaba vacía. Esto cierra [#32777](https://github.com/ClickHouse/ClickHouse/issues/32777). Esto cierra [#30245](https://github.com/ClickHouse/ClickHouse/issues/30245). [#32945](https://github.com/ClickHouse/ClickHouse/pull/32945) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#33067](https://github.com/ClickHouse/ClickHouse/issues/33067): Se corrige la comprobación de la URL de HDFS, que no permitía usar una dirección HA namenode. El error se introdujo en [https://github.com/ClickHouse/ClickHouse/pull/31042](https://github.com/ClickHouse/ClickHouse/pull/31042). [#32976](https://github.com/ClickHouse/ClickHouse/pull/32976) ([Kruglov Pavel](https://github.com/Avogar)).
* Retroportado en [#33100](https://github.com/ClickHouse/ClickHouse/issues/33100): Se corrige una fuga de Context en caso de cancel&#95;http&#95;readonly&#95;queries&#95;on&#95;client&#95;close (es decir, una fuga de tablas externas que se habían cargado en el servidor y de otros recursos). [#32982](https://github.com/ClickHouse/ClickHouse/pull/32982) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#33123](https://github.com/ClickHouse/ClickHouse/issues/33123): Se corrige el error `Invalid version for SerializationLowCardinality key column` al leer desde una columna `LowCardinality` con `local_filesystem_read_prefetch` o `remote_filesystem_read_prefetch` habilitados. [#33046](https://github.com/ClickHouse/ClickHouse/pull/33046) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
