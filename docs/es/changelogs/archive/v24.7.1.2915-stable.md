<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Cambiar la serialización binaria del tipo de dato Variant: añadir el modo `compact` para evitar escribir el mismo discriminador varias veces en gránulos con una única variante o solo con valores NULL. Añadir la configuración de MergeTree `use_compact_variant_discriminators_serialization`, que está habilitada de forma predeterminada. Ten en cuenta que el tipo Variant sigue siendo experimental y que este cambio de serialización incompatible con versiones anteriores es aceptable. [#62774](https://github.com/ClickHouse/ClickHouse/pull/62774) ([Kruglov Pavel](https://github.com/Avogar)).
* Prohibir `CREATE MATERIALIZED VIEW ... ENGINE Replicated*MergeTree POPULATE AS SELECT ...` con bases de datos Replicated. [#63963](https://github.com/ClickHouse/ClickHouse/pull/63963) ([vdimir](https://github.com/vdimir)).
* `clickhouse-keeper-client` solo aceptará rutas en literales de cadena, como `ls '/hello/world'`, y no cadenas sin comillas, como `ls /hello/world`. [#65494](https://github.com/ClickHouse/ClickHouse/pull/65494) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* La métrica `KeeperOutstandingRequets` pasó a llamarse `KeeperOutstandingRequests`. Esto corrige un error tipográfico reportado en [#66179](https://github.com/ClickHouse/ClickHouse/issues/66179). [#66206](https://github.com/ClickHouse/ClickHouse/pull/66206) ([Robert Schulze](https://github.com/rschu1ze)).
* Eliminar el campo `is_deterministic` de la tabla `system.functions`. [#66630](https://github.com/ClickHouse/ClickHouse/pull/66630) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Se amplía la función `tuple` para construir named tuples en una consulta. Se introduce la función `tupleNames` para extraer los nombres de las tuplas. [#54881](https://github.com/ClickHouse/ClickHouse/pull/54881) ([Amos Bird](https://github.com/amosbird)).
* Soporte de `ASOF JOIN` para el algoritmo `full_sorting_join`. Cierra [#54493](https://github.com/ClickHouse/ClickHouse/issues/54493). [#55051](https://github.com/ClickHouse/ClickHouse/pull/55051) ([vdimir](https://github.com/vdimir)).
* Se añadió una nueva table function, `fuzzQuery,`. Esta función permite modificar una query string dada con variaciones aleatorias. Ejemplo: `SELECT query FROM fuzzQuery('SELECT 1');`. [#62103](https://github.com/ClickHouse/ClickHouse/pull/62103) ([pufit](https://github.com/pufit)).
* Se añade la nueva window function `percent_rank`. [#62747](https://github.com/ClickHouse/ClickHouse/pull/62747) ([lgbo](https://github.com/lgbo-ustc)).
* Soporte de authentication JWT en `clickhouse-client`. [#62829](https://github.com/ClickHouse/ClickHouse/pull/62829) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Se añaden las funciones SQL `changeYear`, `changeMonth`, `changeDay`, `changeHour`, `changeMinute`, `changeSecond`. Por ejemplo, `SELECT changeMonth(toDate('2024-06-14'), 7)` devuelve la fecha `2024-07-14`. [#63186](https://github.com/ClickHouse/ClickHouse/pull/63186) ([cucumber95](https://github.com/cucumber95)).
* Se introducen scripts de inicio, que permiten ejecutar consultas preconfiguradas durante la fase de arranque. [#64889](https://github.com/ClickHouse/ClickHouse/pull/64889) ([pufit](https://github.com/pufit)).
* Se admite `accept_invalid_certificate` en la configuración de cliente para permitir que el client se conecte por TCP seguro a un server que se ejecuta con un certificate autofirmado; puede usarse como abreviatura de las configuraciones de cliente `openSSL` correspondientes: `verificationMode=none` + `invalidCertificateHandler.name=AcceptCertificateHandler`. [#65238](https://github.com/ClickHouse/ClickHouse/pull/65238) ([peacewalker122](https://github.com/peacewalker122)).
* Se añade system.error&#95;log, que contiene el history de error values de la tabla system.errors, volcados periódicamente a disco. [#65381](https://github.com/ClickHouse/ClickHouse/pull/65381) ([Pablo Marcos](https://github.com/pamarcos)).
* Se añade la aggregate function `groupConcat`. Es prácticamente igual a `arrayStringConcat( groupArray(column), ',')`. Puede recibir 2 parameters: un delimiter de cadena y el número de elementos que se procesarán. [#65451](https://github.com/ClickHouse/ClickHouse/pull/65451) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Se añade el almacenamiento AzureQueue. [#65458](https://github.com/ClickHouse/ClickHouse/pull/65458) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Se añade una nueva configuración para habilitar o deshabilitar la escritura del índice de páginas en Parquet files. [#65475](https://github.com/ClickHouse/ClickHouse/pull/65475) ([lgbo](https://github.com/lgbo-ustc)).
* Se permite a los administradores del sistema configurar `logger.console_log_level`. [#65559](https://github.com/ClickHouse/ClickHouse/pull/65559) ([Azat Khuzhin](https://github.com/azat)).
* Se añade automáticamente un comodín `*` al final de una ruta de directory con la table function `file`. [#66019](https://github.com/ClickHouse/ClickHouse/pull/66019) ([Zhidong (David) Guo](https://github.com/Gun9niR)).
* Se añade la opción `--memory-usage` al client en interactive mode no interactivo. [#66393](https://github.com/ClickHouse/ClickHouse/pull/66393) ([vdimir](https://github.com/vdimir)).

<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Se habilita `optimize_functions_to_subcolumns` de forma predeterminada. [#58661](https://github.com/ClickHouse/ClickHouse/pull/58661) ([Anton Popov](https://github.com/CurtizJ)).
* Se sustituye el algoritmo de conversión de int a string por uno más rápido (de un amdn/itoa modificado a un jeaiii/itoa modificado). [#61661](https://github.com/ClickHouse/ClickHouse/pull/61661) ([Raúl Marín](https://github.com/Algunenano)).
* Ahora se recopilan y almacenan en caché los tamaños de las tablas hash creadas por join (algoritmo `parallel_hash`). Esta información se usará para preasignar espacio en las tablas hash en ejecuciones posteriores de la consulta y ahorrar tiempo al redimensionarlas. [#64553](https://github.com/ClickHouse/ClickHouse/pull/64553) ([Nikita Taranov](https://github.com/nickitat)).
* Se optimizan las consultas con `ORDER BY` sobre la clave primaria y `WHERE` con una condición de alta selectividad mediante el uso de búfer. Esto se controla con la configuración `read_in_order_use_buffering` (habilitada de forma predeterminada) y puede aumentar el uso de memoria de la consulta. [#64607](https://github.com/ClickHouse/ClickHouse/pull/64607) ([Anton Popov](https://github.com/CurtizJ)).
* Se mejora el rendimiento de la carga de metadatos `plain_rewritable`. [#65634](https://github.com/ClickHouse/ClickHouse/pull/65634) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* La operación Attach de tablas en discos de solo lectura usará menos recursos al no cargar partes obsoletas. [#65635](https://github.com/ClickHouse/ClickHouse/pull/65635) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se añade soporte para hiperrectángulos minmax en índices Set. [#65676](https://github.com/ClickHouse/ClickHouse/pull/65676) ([AntiTopQuark](https://github.com/AntiTopQuark)).
* Se descarga el índice primario de las partes obsoletas para reducir el uso total de memoria. [#65852](https://github.com/ClickHouse/ClickHouse/pull/65852) ([Anton Popov](https://github.com/CurtizJ)).
* Las funciones `replaceRegexpAll` y `replaceRegexpOne` ahora son significativamente más rápidas si el patrón es trivial, es decir, no contiene metacaracteres, clases de patrones, indicadores, caracteres de agrupación, etc. (Gracias a Taiyang Li). [#66185](https://github.com/ClickHouse/ClickHouse/pull/66185) ([Robert Schulze](https://github.com/rschu1ze)).
