<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#58818](https://github.com/ClickHouse/ClickHouse/issues/58818): añade `SYSTEM JEMALLOC PURGE` para purgar páginas de jemalloc no utilizadas, `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` para controlar el perfil de jemalloc si el profiler está habilitado. Añade el comando 4LW relacionado con jemalloc en Keeper: `jmst` para volcar estadísticas de jemalloc, `jmfp`, `jmep`, `jmdp` para controlar el perfil de jemalloc si el profiler está habilitado. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="buildtestingpackaging-improvement">
  #### Mejora de build/pruebas/empaquetado
</div>

* Retroportado en [#59877](https://github.com/ClickHouse/ClickHouse/issues/59877): Si desea ejecutar los scripts de initdb cada vez que se inicie el contenedor de ClickHouse, debe establecer la variable de entorno CLICKHOUSE&#95;ALWAYS&#95;RUN&#95;INITDB&#95;SCRIPTS. [#59808](https://github.com/ClickHouse/ClickHouse/pull/59808) ([Alexander Nikolaev](https://github.com/AlexNik)).
