<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#75289](https://github.com/ClickHouse/ClickHouse/issues/75289): mejora para establecer valores predeterminados aún más restrictivos. Los valores predeterminados actuales ya son seguros: el usuario debe especificar una opción para publicar puertos explícitamente. Pero, cuando el usuario `default` no tiene una contraseña establecida mediante la variable de entorno `CLICKHOUSE_PASSWORD` y/o no se le ha cambiado el nombre de usuario mediante `CLICKHOUSE_USER`, debería estar disponible solo desde el sistema local como nivel adicional de protección. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
