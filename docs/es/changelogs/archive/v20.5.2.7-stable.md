<div id="clickhouse-release-v20527-stable-fixme-as-compared-to-v20513833-prestable">
  ### Lanzamiento de ClickHouse v20.5.2.7-estable FIXME en comparación con v20.5.1.3833-prestable
</div>

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Se añade compatibilidad con `Alter table drop replica replica_name`. Esto corrige [#7080](https://github.com/ClickHouse/ClickHouse/issues/7080). [#10679](https://github.com/ClickHouse/ClickHouse/pull/10679) ([sundyli](https://github.com/sundy-li)).

<div id="improvement">
  #### Mejora
</div>

* Añade la cantidad de errores que se deben ignorar al elegir réplicas (`distributed_replica_error_ignore`). [#11669](https://github.com/ClickHouse/ClickHouse/pull/11669) ([Azat Khuzhin](https://github.com/azat)).
* Metadatos multiversión para almacenamiento sin bloqueos de estructura. [#11745](https://github.com/ClickHouse/ClickHouse/pull/11745) ([alesapin](https://github.com/alesapin)).
* Relaja ligeramente la validación de la cadena de conexión ODBC. Si el hostname o el nombre de usuario contiene solo caracteres de palabra, además de `.` y `-`, no lo pongas entre llaves. Esto es necesario porque algunos drivers ODBC (por ejemplo, PostgreSQL) no interpretan correctamente el hostname cuando está entre llaves. [#11845](https://github.com/ClickHouse/ClickHouse/pull/11845) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Añade compatibilidad con los modificadores `SIGNED` y `UNSIGNED` de los tipos enteros estándar (`BIGINT`, `INT`, ...) para mantener la compatibilidad con MySQL. [#11858](https://github.com/ClickHouse/ClickHouse/pull/11858) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Permite usar `sumWithOverflow` como `SimpleAggregateFunction`. Cierra [#8053](https://github.com/ClickHouse/ClickHouse/issues/8053). [#11865](https://github.com/ClickHouse/ClickHouse/pull/11865) ([Alexander Kuzmenkov](https://github.com/akuzm)).
* Añade compatibilidad con FixedString en las funciones de hash. [#11878](https://github.com/ClickHouse/ClickHouse/pull/11878) ([flynn](https://github.com/ucasfl)).

<div id="bug-fix">
  #### Corrección de errores
</div>

* Corrige el comportamiento inesperado de consultas como `SELECT *, xyz.*`, que se ejecutaban correctamente cuando debería haberse producido un error. [#11753](https://github.com/ClickHouse/ClickHouse/pull/11753) ([hexiaoting](https://github.com/hexiaoting)).
* Corrige un resultado incorrecto de `if()` con NULL en la condición. [#11807](https://github.com/ClickHouse/ClickHouse/pull/11807) ([Artem Zuikov](https://github.com/4ertus2)).
* Corrige la contabilización de memoria a través de la interfaz HTTP (puede ser importante con `wait_end_of_query=1`). [#11840](https://github.com/ClickHouse/ClickHouse/pull/11840) ([Azat Khuzhin](https://github.com/azat)).
* Corrige un fallo poco frecuente causado por el uso de una columna `Nullable` en una condición PREWHERE. Continuación de [#11608](https://github.com/ClickHouse/ClickHouse/issues/11608). [#11869](https://github.com/ClickHouse/ClickHouse/pull/11869) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Retroportado en [#11965](https://github.com/ClickHouse/ClickHouse/issues/11965): corrige una posible excepción de coma flotante al analizar DateTime64. Esto corrige [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374). [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Corrige una posible excepción de coma flotante al analizar DateTime64. Esto corrige [#11374](https://github.com/ClickHouse/ClickHouse/issues/11374). [#11875](https://github.com/ClickHouse/ClickHouse/pull/11875) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Retroportado en [#11963](https://github.com/ClickHouse/ClickHouse/issues/11963): usa la base de datos actual correcta para comprobar los permisos de acceso después de la sentencia `USE database`. [#11920](https://github.com/ClickHouse/ClickHouse/pull/11920) ([Vitaly Baranov](https://github.com/vitlibar)).
* Retroportado en [#12059](https://github.com/ClickHouse/ClickHouse/issues/12059): corrige la comparación incorrecta de tuplas con columnas `Nullable`. Corrige [#11985](https://github.com/ClickHouse/ClickHouse/issues/11985). [#12039](https://github.com/ClickHouse/ClickHouse/pull/12039) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).

<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Añade un script simple de hook de GitHub para el entorno sin servidor. [#11605](https://github.com/ClickHouse/ClickHouse/pull/11605) ([alesapin](https://github.com/alesapin)).
* Envía logs al client en caso de errores fatales, si es posible. Esto hará que los resultados de las pruebas sean más legibles. [#11826](https://github.com/ClickHouse/ClickHouse/pull/11826) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Permite ejecutar ClickHouse en Android. [#11894](https://github.com/ClickHouse/ClickHouse/pull/11894) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
