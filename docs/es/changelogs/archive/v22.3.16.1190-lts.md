<div id="bug-fix">
  #### Corrección de errores
</div>

* retroportado en [#43829](https://github.com/ClickHouse/ClickHouse/issues/43829): Se actualizó el normaliser para clonar el AST del alias. Resuelve [#42452](https://github.com/ClickHouse/ClickHouse/issues/42452). Implementación: * Se actualizó QueryNormalizer para clonar el AST del alias cuando se reemplaza. Antes, asignar simplemente el mismo provocaba una excepción en LogicalExpressinsOptimizer, ya que se volvía a insertar el mismo parent. * Este error no se presenta con el nuevo analizador (allow&#95;experimental&#95;analyzer), por lo que no se hicieron cambios en él. Añadí una prueba para esto. [#42827](https://github.com/ClickHouse/ClickHouse/pull/42827) ([SmitaRKulkarni](https://github.com/SmitaRKulkarni)).
