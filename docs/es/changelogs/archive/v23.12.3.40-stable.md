<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#58660](https://github.com/ClickHouse/ClickHouse/issues/58660): Al ejecutar algunas consultas que requieren muchos streams para leer datos, antes se producía el error `"Paste JOIN requires sorted tables only"`. Ahora, en ese caso, el número de streams se reduce a 1. [#58608](https://github.com/ClickHouse/ClickHouse/pull/58608) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Retroportado en [#58817](https://github.com/ClickHouse/ClickHouse/issues/58817): Se añade `SYSTEM JEMALLOC PURGE` para purgar páginas jemalloc no utilizadas, y `SYSTEM JEMALLOC [ ENABLE | DISABLE | FLUSH ] PROFILE` para controlar el perfil de jemalloc si el profiler está habilitado. Se añade un comando 4LW relacionado con jemalloc en Keeper: `jmst` para volcar estadísticas de jemalloc, y `jmfp`, `jmep`, `jmdp` para controlar el perfil de jemalloc si el profiler está habilitado. [#58665](https://github.com/ClickHouse/ClickHouse/pull/58665) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#59235](https://github.com/ClickHouse/ClickHouse/issues/59235): Permite ignorar la evolución del esquema en el table engine Iceberg y leer todos los datos usando el esquema especificado por el usuario al crear la tabla, o bien el esquema más reciente analizado a partir de los metadatos durante la creación de la tabla. Esto se hace mediante la configuración `iceberg_engine_ignore_schema_evolution`, que está deshabilitada de forma predeterminada. Tenga en cuenta que habilitar esta configuración puede dar lugar a resultados incorrectos, ya que, en caso de evolución del esquema, todos los archivos de datos se leerán usando el mismo esquema. [#59133](https://github.com/ClickHouse/ClickHouse/pull/59133) ([Kruglov Pavel](https://github.com/Avogar)).
