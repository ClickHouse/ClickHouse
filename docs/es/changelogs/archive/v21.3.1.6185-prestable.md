<div id="clickhouse-release-v21316185-prestable-fixme-as-compared-to-v21215869-prestable">

<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Ahora, todos los nombres de funciones que no distinguen entre mayúsculas y minúsculas se convertirán a minúsculas durante el análisis de consultas. Esto es necesario para el enrutamiento de consultas de proyección. [#20174](https://github.com/ClickHouse/ClickHouse/pull/20174) ([Amos Bird](https://github.com/amosbird)).
* Ahora ya no se permite crear tablas MergeTree con la sintaxis antigua y table TTL, porque simplemente se ignora. El Attach de tablas antiguas sigue siendo posible. [#20282](https://github.com/ClickHouse/ClickHouse/pull/20282) ([alesapin](https://github.com/alesapin)).

  #### Nueva funcionalidad
</div>

* La deduplicación de consultas distribuidas da continuidad a [#16033](https://github.com/ClickHouse/ClickHouse/issues/16033) y resuelve parcialmente la propuesta [#13574](https://github.com/ClickHouse/ClickHouse/issues/13574). * Mejora el rendimiento de la agregación con varios campos de tamaño fijo (sin confirmar). [#20454](https://github.com/ClickHouse/ClickHouse/pull/20454) ([Alexey Milovidov](https://github.com/alexey-milovidov)).

* Pequeña mejora del código de agregación. [#20978](https://github.com/ClickHouse/ClickHouse/pull/20978) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Vuelve a añadir las especializaciones vectorConstant de intDiv/module para mejorar el rendimiento. Esto corrige [#21293](https://github.com/ClickHouse/ClickHouse/issues/21293) . <div id="improvement">
  #### Mejora
</div>

* Se corrigió la creación de `TTL` en los casos en que su expresión es una función y coincide con la clave `ORDER BY`. Ahora se permite establecer una aggregation personalizada para las columnas de la clave primaria en `TTL` con `GROUP BY`. Incompatible con versiones anteriores: para las columnas de la clave primaria que no están en `GROUP BY` y no se establecen explícitamente, ahora se aplica la función `any` en lugar de `max` cuando expira el TTL. Además, si usa TTL con `WHERE` o `GROUP BY`, pueden aparecer excepciones durante las merges al realizar una rolling update. [#15450](https://github.com/ClickHouse/ClickHouse/pull/15450) ([Anton Popov](https://github.com/CurtizJ)).
* Hedged Requests para consultas remotas. Cuando la opción `use_hedged_requests` está enabled (de forma predeterminada), se permite establecer múltiples conexiones con distintas réplicas para una consulta. Se habilita una nueva conexión si la(s) conexión(es) existente(s) con la(s) réplica(s) no se establecieron dentro de `hedged_connection_timeout` o si no se recibieron datos dentro de `receive_data_timeout`. La consulta usa la primera conexión que envía un packet de progreso no vacío (o un packet de datos, si `allow_changing_replica_until_first_data_packet`); las demás conexiones se cancelan. Se admiten consultas con `max_parallel_replicas > 1`. [#19291](https://github.com/ClickHouse/ClickHouse/pull/19291) ([Kruglov Pavel](https://github.com/Avogar)).
* Imprimir marcos inline para stacktraces fatales. [#19317](https://github.com/ClickHouse/ClickHouse/pull/19317) ([Ivan](https://github.com/abyss7)).
* No ignorar silenciosamente los errores de escritura. [#19451](https://github.com/ClickHouse/ClickHouse/pull/19451) ([Azat Khuzhin](https://github.com/azat)).
* Se añadió soporte para `PREWHERE` cuando las tablas tienen expressions de seguridad row-level especificadas. [#19576](https://github.com/ClickHouse/ClickHouse/pull/19576) ([Denis Glazachev](https://github.com/traceon)).
* Añadir la interfaz IStoragePolicy. [#19608](https://github.com/ClickHouse/ClickHouse/pull/19608) ([Ernest Zaslavsky](https://github.com/kreuzerkrieg)).
* Se añadió la capacidad de limitar INSERT en Distributed según la cantidad de bytes pendientes para el envío asíncrono (se han añadido las configuraciones `bytes_to_delay_insert`/`max_delay_to_insert` y `bytes_to_throw_insert` para el engine `Distributed`). [#19673](https://github.com/ClickHouse/ClickHouse/pull/19673) ([Azat Khuzhin](https://github.com/azat)).
* Mover las Conditions que no están relacionadas con JOIN a la cláusula WHERE. [#18720](https://github.com/ClickHouse/ClickHouse/issues/18720). [#19685](https://github.com/ClickHouse/ClickHouse/pull/19685) ([hexiaoting](https://github.com/hexiaoting)).
