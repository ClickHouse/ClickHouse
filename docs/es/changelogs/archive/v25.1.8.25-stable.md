<div id="clickhouse-release-v251825-stable-990179ead8b-fixme-as-compared-to-v251720-stable-dcc6b0a7384">
  ### Versión de ClickHouse v25.1.8.25-stable (990179ead8b) FIXME en comparación con v25.1.7.20-stable (dcc6b0a7384)
</div>

<div id="new-feature">
  #### Nueva funcionalidad
</div>

* Retroportado en [#77357](https://github.com/ClickHouse/ClickHouse/issues/77357): Se añadió la configuración a nivel de servidor `concurrent_threads_scheduler`, que controla cómo se distribuyen los slots de CPU entre las consultas concurrentes. Puede establecerse en `round_robin` (comportamiento anterior) o `fair_round_robin` para corregir el problema de la distribución desigual de CPU entre INSERTs y SELECTs. [#75949](https://github.com/ClickHouse/ClickHouse/pull/75949) ([Sergei Trifonov](https://github.com/serxa)).

<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#77202](https://github.com/ClickHouse/ClickHouse/issues/77202): Antes, una base de datos replicada podía escribir en los logs las credenciales especificadas en una consulta. Se ha corregido este comportamiento. Cierra: [#77123](https://github.com/ClickHouse/ClickHouse/issues/77123). [#77133](https://github.com/ClickHouse/ClickHouse/pull/77133) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#76151](https://github.com/ClickHouse/ClickHouse/issues/76151): Propaga la configuración de formato al formateo de JSON como cadena en Native format. [#75832](https://github.com/ClickHouse/ClickHouse/pull/75832) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#76968](https://github.com/ClickHouse/ClickHouse/issues/76968): Corrige la excepción THERE&#95;IS&#95;NO&#95;COLUMN al seleccionar un literal booleano desde tablas distribuidas. [#76656](https://github.com/ClickHouse/ClickHouse/pull/76656) ([Yakov Olkhovskiy](https://github.com/yakov-olkhovskiy)).
* Retroportado en [#77256](https://github.com/ClickHouse/ClickHouse/issues/77256): Corrige un posible crash debido a un rollback incorrecto de una columna JSON en caso de error durante async inserts. [#76908](https://github.com/ClickHouse/ClickHouse/pull/76908) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77220](https://github.com/ClickHouse/ClickHouse/issues/77220): Corrección de error en JSON con subcolumna Variant al añadir una comprobación para omitir las subcolumnas efímeras en la comprobación de consistencia de partes. [#72187](https://github.com/ClickHouse/ClickHouse/issues/72187). [#77034](https://github.com/ClickHouse/ClickHouse/pull/77034) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado en [#77248](https://github.com/ClickHouse/ClickHouse/issues/77248): Corrige un crash durante la creación de una tabla Kafka con excepción. [#77121](https://github.com/ClickHouse/ClickHouse/pull/77121) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#77384](https://github.com/ClickHouse/ClickHouse/issues/77384): `SELECT toBFloat16(-0.0) == toBFloat16(0.0)` ahora devuelve correctamente `true` (antes devolvía `false`). Esto hace que el comportamiento sea coherente con `Float32` y `Float64`. [#77290](https://github.com/ClickHouse/ClickHouse/pull/77290) ([Shankar Iyer](https://github.com/shankar-iyer)).
* Retroportado en [#77333](https://github.com/ClickHouse/ClickHouse/issues/77333): Corrige la comparación entre tuplas con elementos Nullable y cadenas. [#77323](https://github.com/ClickHouse/ClickHouse/pull/77323) ([Alexey Katsman](https://github.com/alexkats)).
