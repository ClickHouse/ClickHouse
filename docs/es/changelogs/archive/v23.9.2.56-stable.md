<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#55295](https://github.com/ClickHouse/ClickHouse/issues/55295): El recurso con el código fuente, incluidos los submódulos, se compila en la tarea especial de compilación para Darwin. Puede usarse para compilar ClickHouse sin tener que descargar los submódulos. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Retroportado en [#55368](https://github.com/ClickHouse/ClickHouse/issues/55368): Se resuelve un issue al iniciar clickhouse-keeper standalone desde el package clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado en [#55727](https://github.com/ClickHouse/ClickHouse/issues/55727): Se corrige el script de Python de la comprobación de integración para que use la URL de la API de gh; se añade un README para las pruebas de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).

* Se corrige un SIGSEGV en MergeSortingPartialResultTransform (debido a que hay cero fragmentos después de remerge()) [#55335](https://github.com/ClickHouse/ClickHouse/pull/55335) ([Azat Khuzhin](https://github.com/azat)).
* Se corrige una condición de carrera en CreatingSetsTransform (en caso de error) debido al lanzamiento de una excepción compartida [#55338](https://github.com/ClickHouse/ClickHouse/pull/55338) ([Azat Khuzhin](https://github.com/azat)).
* Se corrige la optimización de trash (hasta cierto punto) [#55353](https://github.com/ClickHouse/ClickHouse/pull/55353) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se corrige el análisis de arrays en el operador CAST [#55417](https://github.com/ClickHouse/ClickHouse/pull/55417) ([Anton Popov](https://github.com/CurtizJ)).
* Se corrige el filtrado por columnas virtuales con el filtro OR en la consulta [#55418](https://github.com/ClickHouse/ClickHouse/pull/55418) ([Azat Khuzhin](https://github.com/azat)).
* Se corrigen problemas de conexión con MongoDB [#55419](https://github.com/ClickHouse/ClickHouse/pull/55419) ([Nikolay Degterinsky](https://github.com/evillique)).
* Se destruye la fibra en caso de excepción en cancelBefore en AsyncTaskExecutor [#55516](https://github.com/ClickHouse/ClickHouse/pull/55516) ([Kruglov Pavel](https://github.com/Avogar)).
* Se corrige un fallo en QueryNormalizer con alias cíclicos [#55602](https://github.com/ClickHouse/ClickHouse/pull/55602) ([vdimir](https://github.com/vdimir)).
* Se corrige el filtrado por columnas virtuales con el filtro OR en la consulta (reenvío) [#55678](https://github.com/ClickHouse/ClickHouse/pull/55678) ([Azat Khuzhin](https://github.com/azat)).
