<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#55291](https://github.com/ClickHouse/ClickHouse/issues/55291): El recurso con el código fuente, incluidos los submódulos, se compila en la tarea especial de compilación para Darwin. Puede usarse para compilar ClickHouse sin necesidad de hacer checkout de los submódulos. [#51435](https://github.com/ClickHouse/ClickHouse/pull/51435) ([Ilya Yatsishin](https://github.com/qoega)).
* Retroportado en [#54705](https://github.com/ClickHouse/ClickHouse/issues/54705): Enriquecer `changed_images.json` con la etiqueta más reciente de master para las imágenes que no se modifican en el pull request. [#54369](https://github.com/ClickHouse/ClickHouse/pull/54369) ([János Benjamin Antal](https://github.com/antaljanosbenjamin)).
* Retroportado en [#54683](https://github.com/ClickHouse/ClickHouse/issues/54683): Los compilamos y subimos en cada push, pero no merece la pena. [#54675](https://github.com/ClickHouse/ClickHouse/pull/54675) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado en [#55407](https://github.com/ClickHouse/ClickHouse/issues/55407): Resolver el issue al iniciar clickhouse-keeper en modo standalone desde el paquete clickhouse-server. [#55226](https://github.com/ClickHouse/ClickHouse/pull/55226) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Retroportado en [#55723](https://github.com/ClickHouse/ClickHouse/issues/55723): Corregir el script de Python de la comprobación de integration para que use la URL de la API de gh; añadir un README para las pruebas de CI. [#55716](https://github.com/ClickHouse/ClickHouse/pull/55716) ([Max K.](https://github.com/mkaynov)).
