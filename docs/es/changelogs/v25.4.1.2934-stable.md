<div id="backward-incompatible-change">
  #### Cambio incompatible con versiones anteriores
</div>

* Se comprueba que todas las columnas de una vista materializada coincidan con la tabla de destino si `allow_materialized_view_with_bad_select` es `false`. [#74481](https://github.com/ClickHouse/ClickHouse/pull/74481) ([Christoph Wurm](https://github.com/cwurm)).
* Corrige los casos en los que `dateTrunc` se usa con argumentos negativos de fecha o fecha y hora. [#77622](https://github.com/ClickHouse/ClickHouse/pull/77622) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Se ha eliminado la integración heredada de MongoDB. La configuración del servidor `use_legacy_mongodb_integration` quedó obsoleta y ahora no hace nada. [#77895](https://github.com/ClickHouse/ClickHouse/pull/77895) ([Robert Schulze](https://github.com/rschu1ze)).
* Mejora la validación de SummingMergeTree para omitir la agregación de las columnas utilizadas en las claves de partición o de ordenación. [#78022](https://github.com/ClickHouse/ClickHouse/pull/78022) ([Pervakov Grigorii](https://github.com/GrigoryPervakov)).

* Añade las funciones `arrayLevenshteinDistance`, `arrayLevenshteinDistanceWeighted` y `arraySimilarity`. [#77187](https://github.com/ClickHouse/ClickHouse/pull/77187) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
* Permite a un usuario consultar el estado de una tabla Iceberg tal como existía en un momento anterior. [#77439](https://github.com/ClickHouse/ClickHouse/pull/77439) ([Daniil Ivanik](https://github.com/divanik)).
* Se añadió planificación de CPU slot para workloads; consulta https://clickhouse.com/docs/operations/workload-scheduling#cpu&#95;scheduling para más detalles. [#77595](https://github.com/ClickHouse/ClickHouse/pull/77595) ([Sergei Trifonov](https://github.com/serxa)).
* La función hasAll() ahora puede aprovechar los índices de omisión de texto completo tokenbf&#95;v1 y ngrambf&#95;v1. [#77662](https://github.com/ClickHouse/ClickHouse/pull/77662) ([UnamedRus](https://github.com/UnamedRus)).

* Se añadió una caché en memoria para los índices de similitud vectorial deserializados. Esto debería acelerar las consultas repetidas de búsqueda aproximada de vecinos más cercanos (ANN). El tamaño de la nueva caché se controla mediante las configuraciones del servidor `vector_similarity_index_cache_size` y `vector_similarity_index_cache_max_entries`. Esta funcionalidad reemplaza la caché de índices de omisión de versiones anteriores. [#77905](https://github.com/ClickHouse/ClickHouse/pull/77905) ([Shankar Iyer](https://github.com/shankar-iyer)).

* Se introduce la función `toInterval`. Esta función acepta 2 argumentos (valor y unidad) y convierte el valor a un tipo `Interval` específico. [#78723](https://github.com/ClickHouse/ClickHouse/pull/78723) ([Andrew Davis](https://github.com/pulpdrew)).

<div id="improvement">
  #### Mejora
</div>

* Reduce la cantidad de solicitudes a Keeper al eliminar el uso de solicitudes `get` individuales, que podrían haber provocado una carga significativa en Keeper al aumentar el número de réplicas, en los casos en que `multiRead` está disponible. [#56862](https://github.com/ClickHouse/ClickHouse/pull/56862) ([Nikolay Degterinsky](https://github.com/evillique)).
* Rechaza consultas cuando el servidor está sobrecargado. La decisión se toma en función de la relación entre el tiempo de espera (`OSCPUWaitMicroseconds`) y el tiempo de actividad (`OSCPUVirtualTimeMicroseconds`). La consulta se descarta con cierta probabilidad cuando esta relación está entre `min_os_cpu_wait_time_ratio_to_throw` y `max_os_cpu_wait_time_ratio_to_throw` (estos son ajustes a nivel de consulta). [#63206](https://github.com/ClickHouse/ClickHouse/pull/63206) ([Alexey Katsman](https://github.com/alexkats)).
* Las actualizaciones de las vistas materializadas actualizables ahora aparecen en `system.query_log`. [#71333](https://github.com/ClickHouse/ClickHouse/pull/71333) ([Michael Kolupaev](https://github.com/al13n321)).
* Retroportado en [#79175](https://github.com/ClickHouse/ClickHouse/issues/79175): `clickhouse-local` conservará sus bases de datos después de reiniciarse si se especifica el argumento de línea de comandos `--path`. Esto cierra [#50647](https://github.com/ClickHouse/ClickHouse/issues/50647). Esto cierra [#49947](https://github.com/ClickHouse/ClickHouse/issues/49947). [#71722](https://github.com/ClickHouse/ClickHouse/pull/71722) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Se habilitó una lógica de backoff para todos los tipos de tareas replicadas. Esto permitirá reducir el uso de CPU, el uso de memoria y el tamaño de los archivos de registro. Se añadieron los nuevos ajustes `max_postpone_time_for_failed_replicated_fetches_ms`, `max_postpone_time_for_failed_replicated_merges_ms` y `max_postpone_time_for_failed_replicated_tasks_ms`, similares a `max_postpone_time_for_failed_mutations_ms`. [#74576](https://github.com/ClickHouse/ClickHouse/pull/74576) ([MikhailBurdukov](https://github.com/MikhailBurdukov)).
* Usa sharding dinámico para JOIN si la clave de JOIN es un prefijo de PK en ambas partes. Esta optimización se habilita con el ajuste `query_plan_join_shard_by_pk_ranges` (deshabilitado de forma predeterminada). [#74733](https://github.com/ClickHouse/ClickHouse/pull/74733) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
* Se volvió a habilitar el protocolo SSH. Se corrigieron algunas vulnerabilidades críticas, por lo que ya no es posible usar un pager personalizado ni especificar `server-logs-file`. De forma predeterminada, se deshabilitó la posibilidad de pasar opciones del client mediante variables de entorno (sigue siendo posible a través de `ssh-server.enable_client_options_passing` en config.xml). Se admiten la tabla de progreso, la cancelación de consultas, el autocompletado, el progreso de los profile events, stdin y la opción `send_logs_level`. Esto cierra: [#74340](https://github.com/ClickHouse/ClickHouse/issues/74340). [#74989](https://github.com/ClickHouse/ClickHouse/pull/74989) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).

* Agrega query&#95;id a system.errors. Ticket relacionado: [#75815](https://github.com/ClickHouse/ClickHouse/issues/75815). [#76581](https://github.com/ClickHouse/ClickHouse/pull/76581) ([Vladimir Baikov](https://github.com/bkvvldmr)).
