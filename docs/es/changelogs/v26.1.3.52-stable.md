<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#96316](https://github.com/ClickHouse/ClickHouse/issues/96316): Se elimina la comprobación innecesaria de omisión de permisos en las consultas `ATTACH` para una vista con SQL Security. Esto evita una posible escalada de privilegios cuando un usuario adjunta una vista con un definidor sin validar el acceso requerido. [#94865](https://github.com/ClickHouse/ClickHouse/pull/94865) ([pufit](https://github.com/pufit)).
* Retroportado en [#95806](https://github.com/ClickHouse/ClickHouse/issues/95806): Se corrigió la inferencia de tipos de columnas calificadas de tablas de origen cuando se usan múltiples joins con la cláusula `USING`. Anteriormente, los joins posteriores actualizaban incorrectamente los tipos de las columnas de origen subyacentes a un supertipo común incluso cuando la columna no participaba en ese join (por ejemplo, en `SELECT t2.a FROM t1 LEFT JOIN t2 USING (a) LEFT JOIN t3 USING (a)`, la columna `t2.a` solo se usa en el primer join, por lo que su tipo debe ser el supertipo de `t1.a` y `t2.a`, excluyendo `t3.a`). Esto podía provocar errores lógicos o fallos cuando las funciones esperaban tipos de columna distintos de los que realmente aparecían en el plan de ejecución. [#95157](https://github.com/ClickHouse/ClickHouse/pull/95157) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Retroportado en [#96396](https://github.com/ClickHouse/ClickHouse/issues/96396): Se corrige un error lógico en algunos casos al usar `LIMIT/OFFSET` negativo en consultas distribuidas. [#95357](https://github.com/ClickHouse/ClickHouse/pull/95357) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Retroportado en [#96222](https://github.com/ClickHouse/ClickHouse/issues/96222): Se corrige un fallo al aplicar `tupleElement` a arrays de JSON. Cierra [#95581](https://github.com/ClickHouse/ClickHouse/issues/95581). [#95647](https://github.com/ClickHouse/ClickHouse/pull/95647) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#95825](https://github.com/ClickHouse/ClickHouse/issues/95825): Se corrige la compactación de datos particionados de delta lake. [#95773](https://github.com/ClickHouse/ClickHouse/pull/95773) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#95852](https://github.com/ClickHouse/ClickHouse/issues/95852): Se corrige una condición de carrera en una columna Nullable de join en runtime filters. [#95775](https://github.com/ClickHouse/ClickHouse/pull/95775) ([Hechem Selmi](https://github.com/m-selmi)).
* Retroportado en [#97187](https://github.com/ClickHouse/ClickHouse/issues/97187): Se corrige la ejecución de tupleElement sobre JSON con paths anidados; antes podía dar lugar a un resultado de consulta incorrecto. [#95907](https://github.com/ClickHouse/ClickHouse/pull/95907) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#96086](https://github.com/ClickHouse/ClickHouse/issues/96086): Se corrigió un error `NOT_SUPPORTED` que podía producirse al usar el algoritmo de join `direct` con una tabla MergeTree vacía. [#95935](https://github.com/ClickHouse/ClickHouse/pull/95935) ([Vladimir Cherkasov](https://github.com/vdimir)).
* Retroportado en [#95993](https://github.com/ClickHouse/ClickHouse/issues/95993): Se corrige event&#95;date en system.asynchronous&#95;metric&#95;log. [#95947](https://github.com/ClickHouse/ClickHouse/pull/95947) ([Raúl Marín](https://github.com/Algunenano)).
* Retroportado en [#96215](https://github.com/ClickHouse/ClickHouse/issues/96215): Se corrigen los skipping paths en el tipo de datos JSON. Anteriormente, con `JSON(SKIP path)` se omitían todas las claves JSON con el prefijo `path`, incluso claves como `"pathpath"`, lo que podía provocar pérdida de datos en esos paths durante el insert. Ahora está corregido y solo se omite la clave `"path"`. [#95948](https://github.com/ClickHouse/ClickHouse/pull/95948) ([Pavel Kruglov](https://github.com/Avogar)).
* Con backport en [#96082](https://github.com/ClickHouse/ClickHouse/issues/96082): Se corrige el período de los profilers globales (controlado por `global_profiler_real_time_period_ns` y `global_profiler_cpu_time_period_ns`). En lugar del valor configurado, se usaba un valor truncado, lo que hacía que el profiler se activara más de lo previsto. [#96048](https://github.com/ClickHouse/ClickHouse/pull/96048) ([Antonio Andelic](https://github.com/antonio2368)).
* Con backport en [#96189](https://github.com/ClickHouse/ClickHouse/issues/96189): Anteriormente, si el archivo de datos de referencia dentro del archivo manifest de Iceberg para position delete estaba presente en una entrada pero era null, no se obtenían los límites correctos para los archivos de datos correspondientes. Este PR corrige este error. [#96061](https://github.com/ClickHouse/ClickHouse/pull/96061) ([Daniil Ivanik](https://github.com/divanik)).
* Con backport en [#96544](https://github.com/ClickHouse/ClickHouse/issues/96544): Se corrige la revocación de roles predeterminados. [#96103](https://github.com/ClickHouse/ClickHouse/pull/96103) ([Vitaly Baranov](https://github.com/vitlibar)).
* Con backport en [#96139](https://github.com/ClickHouse/ClickHouse/issues/96139): Se corrige un use-after-free en el análisis de índices en una combinación poco frecuente de `use_primary_key` deshabilitado y un número muy grande de disyunciones de condiciones que usan el índice. [#96112](https://github.com/ClickHouse/ClickHouse/pull/96112) ([Alexey Milovidov](https://github.com/alexey-milovidov)).
* Con backport en [#96159](https://github.com/ClickHouse/ClickHouse/issues/96159): Se corrige el uso de un valor sin inicializar en `formatDateTime` con formatters de ancho no fijo, como los de estilo MySQL y JODA. * Con backport en [#96294](https://github.com/ClickHouse/ClickHouse/issues/96294): Se corrige una colisión de hash en la caché de condiciones de consulta para constantes plegadas de CTE, lo que podía provocar un resultado de consulta incorrecto.
