<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#102655](https://github.com/ClickHouse/ClickHouse/issues/102655): Se corrige la excepción LOGICAL&#95;ERROR en `ASTColumnsExceptTransformer::transform`. [#99119](https://github.com/ClickHouse/ClickHouse/pull/99119) ([Pablo Marcos](https://github.com/pamarcos)).
* Retroportado en [#101418](https://github.com/ClickHouse/ClickHouse/issues/101418): Se corrige `use-of-uninitialized-value` en StringSearcher.h. [#100225](https://github.com/ClickHouse/ClickHouse/pull/100225) ([Konstantin Bogdanov](https://github.com/thevar1able)).
* Retroportado en [#102677](https://github.com/ClickHouse/ClickHouse/issues/102677): Se corrige un `crash` por uso de memoria después de haber sido liberada en el scheduler de concesión de CPU, cuando el temporizador de espera sobrevive al worker thread cuyos `ProfileEvents::Counters` referencia. [#101761](https://github.com/ClickHouse/ClickHouse/pull/101761) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#102709](https://github.com/ClickHouse/ClickHouse/issues/102709): Se corrige una condición de carrera de SLRU en la filesystem cache 26.1+, que puede provocar un logical error en la reserva de espacio. En una build de depuración, también puede provocar un fallo de aserción: `'Previous state is Evicting, but expected state to be Active while setting Evicting flag for 2c1e3484ecdc6b78a8978fa5b17c5097:0:339 (state: Evicting)'.`. [#101991](https://github.com/ClickHouse/ClickHouse/pull/101991) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#102750](https://github.com/ClickHouse/ClickHouse/issues/102750): Se corrige que CurrentMetric de `NamedCollection` se incremente indebidamente con `CREATE NAMED COLLECTION IF NOT EXISTS` sobre colecciones existentes, y que no se inicialice para las colecciones cargadas desde la configuración o desde el almacenamiento SQL al inicio. Cierra [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507). [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* Retroportado en [#102795](https://github.com/ClickHouse/ClickHouse/issues/102795): Error en la política de filas que produce la excepción &#39;Not found column in block&#39; en algunos casos especiales. [#102648](https://github.com/ClickHouse/ClickHouse/pull/102648) ([Yarik Briukhovetskyi](https://github.com/yariks5s)).
* Retroportado en [#102743](https://github.com/ClickHouse/ClickHouse/issues/102743): Se corrige que `SYSTEM WAIT VIEW` quede bloqueado indefinidamente cuando la vista materializada actualizable se elimina mientras la espera está en curso. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
