<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#82594](https://github.com/ClickHouse/ClickHouse/issues/82594): mejora de Keeper: se añade una nueva configuración `keeper_server.cleanup_old_and_ignore_new_acl`. Si está habilitada, se borrarán las ACL de todos los nodos, mientras que se ignorará la ACL de las nuevas solicitudes. Si el objetivo es eliminar por completo la ACL de los nodos, es importante mantener la configuración habilitada hasta que se cree un nuevo snapshot. [#82496](https://github.com/ClickHouse/ClickHouse/pull/82496) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#82860](https://github.com/ClickHouse/ClickHouse/issues/82860): Después de [https://github.com/ClickHouse/ClickHouse/pull/73834](https://github.com/ClickHouse/ClickHouse/pull/73834), se modificaron los formatos de las cabeceras `X-ClickHouse-Progress` y `X-ClickHouse-Summary` para omitir los valores cero. Esta PR pretende restaurar el comportamiento anterior solo para `X-ClickHouse-Summary`, porque es lo más razonable. [#82727](https://github.com/ClickHouse/ClickHouse/pull/82727) ([Nikita Mikhaylov](https://github.com/nikitamikhaylov)).
* Retroportado en [#82926](https://github.com/ClickHouse/ClickHouse/issues/82926): mejora de Keeper: compatibilidad con permisos específicos para la ACL world:anyone. [#82755](https://github.com/ClickHouse/ClickHouse/pull/82755) ([Antonio Andelic](https://github.com/antonio2368)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#82779](https://github.com/ClickHouse/ClickHouse/issues/82779): Se corrige el análisis de filtros cuando en la consulta solo se usa una columna alias constante. Corrige [#79448](https://github.com/ClickHouse/ClickHouse/issues/79448). [#82037](https://github.com/ClickHouse/ClickHouse/pull/82037) ([Dmitry Novik](https://github.com/novikd)).
* Retroportado en [#82559](https://github.com/ClickHouse/ClickHouse/issues/82559): Se corrige un posible interbloqueo en consultas remotas cuando el servidor está bajo presión de memoria. [#82160](https://github.com/ClickHouse/ClickHouse/pull/82160) ([Kirill](https://github.com/kirillgarbar)).
* Retroportado en [#82688](https://github.com/ClickHouse/ClickHouse/issues/82688): Se corrige `LOGICAL_ERROR` durante el análisis de expresiones de política de filas para columnas correlacionadas. [#82618](https://github.com/ClickHouse/ClickHouse/pull/82618) ([Dmitry Novik](https://github.com/novikd)).
* Retroportado en [#82735](https://github.com/ClickHouse/ClickHouse/issues/82735): Las funciones `trim{Left,Right,Both}` ahora admiten cadenas de entrada de tipo &quot;FixedString(N)&quot;. Por ejemplo, `SELECT trimBoth(toFixedString('abc', 3), 'ac')` ahora funciona. [#82691](https://github.com/ClickHouse/ClickHouse/pull/82691) ([Robert Schulze](https://github.com/rschu1ze)).
* Retroportado en [#82800](https://github.com/ClickHouse/ClickHouse/issues/82800): Se corrige la deserialización de `groupArraySample`/`groupArrayLast` en caso de elementos vacíos (la deserialización podía omitir parte de los datos binarios si la entrada estaba vacía; esto puede provocar corrupción durante la lectura de datos y UNKNOWN&#95;PACKET&#95;FROM&#95;SERVER en el protocolo TCP). Esto no afecta a tipos numéricos ni de fecha y hora. [#82763](https://github.com/ClickHouse/ClickHouse/pull/82763) ([Pedro Ferreira](https://github.com/PedroTadim)).
