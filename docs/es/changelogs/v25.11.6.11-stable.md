<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Retroportado en [#92312](https://github.com/ClickHouse/ClickHouse/issues/92312): Https://github.com/clickhouse/clickhouse/pull/84477 añadió restricciones sobre las consultas `select` que pueden usarse en consultas `insert select from s3cluster()` para la ejecución distribuida en paralelo. Este cambio permite usar `where`, algo que antes ya era posible. [#84611](https://github.com/ClickHouse/ClickHouse/pull/84611) ([Igor Nikonov](https://github.com/devcrafter)).

<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#93375](https://github.com/ClickHouse/ClickHouse/issues/93375): uso de copia de lectura y escritura para Azure Blob Storage cuando la copia nativa falla con BadRequest (p. ej., lista de bloques no válida). Anteriormente, esto solo se hacía para el error Unauthorized, que se observaba al copiar un blob entre distintas cuentas de almacenamiento. Pero a veces también vemos el error &quot;The specified block list is invalid&quot;. Por ello, ahora se ha actualizado la condición para recurrir a lectura y escritura en todos los fallos de copia nativa. [#92888](https://github.com/ClickHouse/ClickHouse/pull/92888) ([Smita Kulkarni](https://github.com/SmitaRKulkarni)).
* Retroportado en [#93336](https://github.com/ClickHouse/ClickHouse/issues/93336): Compatibilidad con el tipo Geometry para `flipCoordinates`. [#93303](https://github.com/ClickHouse/ClickHouse/pull/93303) ([Bharat Nallan](https://github.com/bharatnc)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#93123](https://github.com/ClickHouse/ClickHouse/issues/93123): Reelabora la lógica incorrecta en las comprobaciones de permisos de acceso para grants con comodines. El intento anterior [https://github.com/ClickHouse/ClickHouse/pull/90928](https://github.com/ClickHouse/ClickHouse/pull/90928) solucionó una vulnerabilidad crítica, pero acabó siendo demasiado restrictivo, lo que hizo que algunas sentencias `GRANT` con comodines fallaran debido a sentencias `REVOKE` no relacionadas. [#92725](https://github.com/ClickHouse/ClickHouse/pull/92725) ([pufit](https://github.com/pufit)).
* Retroportado en [#93222](https://github.com/ClickHouse/ClickHouse/issues/93222): Corrige la creación de una indicación de tipo para la ruta &#39;skip&#39; en JSON. Cierra [#92731](https://github.com/ClickHouse/ClickHouse/issues/92731). [#92842](https://github.com/ClickHouse/ClickHouse/pull/92842) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#93182](https://github.com/ClickHouse/ClickHouse/issues/93182): Corrige un posible error FILE&#95;DOESNT&#95;EXIST después de una mutación de columna dispersa cuando la configuración `ratio_of_defaults_for_sparse_serialization` se cambió a `1.0` mediante ALTER. [#93016](https://github.com/ClickHouse/ClickHouse/pull/93016) ([Pavel Kruglov](https://github.com/Avogar)).
* Retroportado en [#93046](https://github.com/ClickHouse/ClickHouse/issues/93046): Corrige un error en la lógica de omisión de datos cuando se usa `not materialize(...)` o `not CAST(...)` en WHERE, lo que provoca resultados incorrectos. Cierra [#88536](https://github.com/ClickHouse/ClickHouse/issues/88536). [#93017](https://github.com/ClickHouse/ClickHouse/pull/93017) ([Nihal Z. Miaji](https://github.com/nihalzp)).
* Retroportado en [#93057](https://github.com/ClickHouse/ClickHouse/issues/93057): Corrige que la conexión quedara en un estado inconsistente tras la cancelación preliminar de consultas distribuidas. [#93029](https://github.com/ClickHouse/ClickHouse/pull/93029) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#93311](https://github.com/ClickHouse/ClickHouse/issues/93311): Elimina las columnas no utilizadas cuando la proyección se reconstruye durante la fusión. Reduce el uso de memoria y crea menos partes temporales. [#93233](https://github.com/ClickHouse/ClickHouse/pull/93233) ([Nikolai Kochetov](https://github.com/KochetovNicolai)).
