<div id="buildtestingpackaging-improvement">
  #### Mejora de compilación/pruebas/empaquetado
</div>

* Retroportado en [#75285](https://github.com/ClickHouse/ClickHouse/issues/75285): mejora para establecer valores predeterminados aún más restrictivos. Los valores predeterminados actuales ya son seguros: el usuario tiene que especificar una opción para publicar puertos explícitamente. Pero cuando el usuario `default` no tiene una contraseña establecida mediante `CLICKHOUSE_PASSWORD` y/o un nombre de usuario cambiado mediante las variables de entorno `CLICKHOUSE_USER`, solo debería estar disponible desde el sistema local como nivel adicional de protección. [#75259](https://github.com/ClickHouse/ClickHouse/pull/75259) ([Mikhail f. Shiryaev](https://github.com/Felixoid)).
