<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#108279](https://github.com/ClickHouse/ClickHouse/issues/108279): Se corrigió un posible desbordamiento de pila en el servidor (bloqueo) al leer un schema o valor muy anidado en los formatos MsgPack, BSON, ORC, Parquet, JSON, DeltaLake, Iceberg y Paimon. Este tipo de entrada muy anidada ahora se rechaza con una excepción. [#107341](https://github.com/ClickHouse/ClickHouse/pull/107341) ([Raúl Marín](https://github.com/Algunenano)).
* Retroportado en [#108237](https://github.com/ClickHouse/ClickHouse/issues/108237): Se añadieron las comprobaciones de límites que faltaban en el análisis de ELF y DWARF. [#107579](https://github.com/ClickHouse/ClickHouse/pull/107579) ([Michael Kolupaev](https://github.com/al13n321)).
* Retroportado en [#108157](https://github.com/ClickHouse/ClickHouse/issues/108157): La lectura de datos Arrow/ArrowStream con columnas `String`/`Binary` vacías generadas por Apache Arrow Java &lt; 19.0.0 (incluido Apache Spark) ya no lanza `INCORRECT_DATA`. [#107764](https://github.com/ClickHouse/ClickHouse/pull/107764) ([Raúl Marín](https://github.com/Algunenano)).
