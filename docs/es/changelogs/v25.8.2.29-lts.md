<div id="new-feature">

* Retroportado en [#86620](https://github.com/ClickHouse/ClickHouse/issues/86620): se añade la tabla del sistema `iceberg_metadata_log` para recuperar archivos de metadatos de Iceberg durante las sentencias SELECT. [#86152](https://github.com/ClickHouse/ClickHouse/pull/86152) ([Konstantin Vedernikov](https://github.com/scanhex12)).

<div id="improvement">
  #### Mejora
</div>

* Retroportado en [#86333](https://github.com/ClickHouse/ClickHouse/issues/86333): Se añade `allow_experimental_delta_lake_writes`. [#86180](https://github.com/ClickHouse/ClickHouse/pull/86180) ([Kseniia Sumarokova](https://github.com/kssenii)).
* Retroportado en [#86493](https://github.com/ClickHouse/ClickHouse/issues/86493): Se añade la posibilidad de habilitar el logging en JSON solo para un canal específico; para ello, establezca `logger.formatting.channel` en uno de `syslog`/`console`/`errorlog`/`log`. [#86331](https://github.com/ClickHouse/ClickHouse/pull/86331) ([Azat Khuzhin](https://github.com/azat)).

<div id="bug-fix-user-visible-misbehavior-in-an-official-stable-release">
  #### Corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* Retroportado en [#86614](https://github.com/ClickHouse/ClickHouse/issues/86614): Apagado correcto de las tablas al recuperar una réplica de base de datos. Un apagado incorrecto provocaba `LOGICAL_ERROR` en algunos motores de tabla durante la recuperación de la réplica de base de datos. [#84744](https://github.com/ClickHouse/ClickHouse/pull/84744) ([Antonio Andelic](https://github.com/antonio2368)).
* Retroportado en [#86386](https://github.com/ClickHouse/ClickHouse/issues/86386): Procesa por defecto los includes de `/etc/metrika.xml` al crear discos desde SQL. [#86232](https://github.com/ClickHouse/ClickHouse/pull/86232) ([alekar](https://github.com/alekar)).
* Retroportado en [#86653](https://github.com/ClickHouse/ClickHouse/issues/86653): Corrige `416 The range specified is invalid for the current size of the resource. The range specified is invalid for the current size of the resource` al leer blobs vacíos desde Azure blob storage en el disco plain&#95;rewritable. [#86400](https://github.com/ClickHouse/ClickHouse/pull/86400) ([Julia Kartseva](https://github.com/jkartseva)).
* Retroportado en [#86457](https://github.com/ClickHouse/ClickHouse/issues/86457): Se corrigió un error en las vistas materializadas: una MV podía dejar de funcionar si se creaba, se eliminaba y luego se volvía a crear con el mismo nombre. [#86413](https://github.com/ClickHouse/ClickHouse/pull/86413) ([Alexander Tokmakov](https://github.com/tavplubix)).
* Retroportado en [#86468](https://github.com/ClickHouse/ClickHouse/issues/86468): Corrige una fuga de `MergesMutationsMemoryTracking` debida a tablas `Buffer` y corrige `query_views_log` para el streaming desde `Kafka` (y otros). [#86422](https://github.com/ClickHouse/ClickHouse/pull/86422) ([Azat Khuzhin](https://github.com/azat)).
* Retroportado en [#86549](https://github.com/ClickHouse/ClickHouse/issues/86549): Corrige el uso de memoria sin inicializar en getSubcolumnType. [#86498](https://github.com/ClickHouse/ClickHouse/pull/86498) ([Raúl Marín](https://github.com/Algunenano)).
* Retroportado en [#86582](https://github.com/ClickHouse/ClickHouse/issues/86582): Ignora las excepciones durante el flushing del log al apagar el sistema y hace que el apagado sea más seguro (para evitar SIGSEGV). [#86546](https://github.com/ClickHouse/ClickHouse/pull/86546) ([Azat Khuzhin](https://github.com/azat)).
