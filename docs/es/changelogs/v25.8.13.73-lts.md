<div id="performance-improvement">
  #### Mejora del rendimiento
</div>

* Retroportado en [#92306](https://github.com/ClickHouse/ClickHouse/issues/92306): Https://github.com/clickhouse/clickhouse/pull/84477 añadió restricciones sobre las consultas select que se pueden usar en consultas `insert select from s3cluster()` para la ejecución distribuida en paralelo. este cambio permite usar where, lo cual antes era posible. <div id="improvement">

</div>

* Retroportado en [#91248](https://github.com/ClickHouse/ClickHouse/issues/91248): Se corrigió una posible inanición del grupo de hilos al leer muestras de columnas de columnas JSON con muchas subcolumnas, respetando el ajuste `merge_tree_use_prefixes_deserialization_thread_pool` en lugar de usar el grupo de hilos de forma incondicional.
