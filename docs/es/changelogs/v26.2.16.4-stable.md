  #### corrección de errores (mal funcionamiento visible para el usuario en una versión estable oficial)
</div>

* retroportado en [#102752](https://github.com/ClickHouse/ClickHouse/issues/102752): Se corrige que la CurrentMetric de `NamedCollection` apareciera inflada al usar `CREATE NAMED COLLECTION IF NOT EXISTS` sobre colecciones existentes, y que no se inicializara para las colecciones cargadas desde la configuración o el almacenamiento SQL durante el arranque. Cierra [#102507](https://github.com/ClickHouse/ClickHouse/issues/102507). [#102598](https://github.com/ClickHouse/ClickHouse/pull/102598) ([Pablo Marcos](https://github.com/pamarcos)).
* retroportado en [#102746](https://github.com/ClickHouse/ClickHouse/issues/102746): Se corrige que `SYSTEM WAIT VIEW` se quedara bloqueado indefinidamente cuando la vista materializada actualizable se eliminaba mientras la espera estaba en curso. [#102681](https://github.com/ClickHouse/ClickHouse/pull/102681) ([Nikolay Degterinsky](https://github.com/evillique)).
