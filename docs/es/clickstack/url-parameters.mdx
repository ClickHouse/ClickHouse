Puedes abrir páginas de ClickStack mediante enlaces profundos con parámetros de consulta de URL para ir directamente a una búsqueda, un dashboard o un panel específicos desde un sistema externo (una notificación de alerta, un runbook, un job de CI, un mensaje de chat, entre otros).

Los ejemplos de esta página usan `<YOUR_CLICKSTACK_URL>`. Sustitúyelo por la URL de tu ClickStack; por ejemplo, `http://localhost:8080` para una implementación local de código abierto o `https://hyperdx.clickhouse.cloud` para Managed ClickStack en ClickHouse Cloud.

<Note>
  Los ejemplos muestran parámetros de consulta sin codificación de URL para facilitar la lectura. Al construir enlaces mediante programación, codifica en URL el valor de cada parámetro de consulta.
</Note>

<Info>
  **Parámetro de ID de servicio de Managed ClickStack**

  Al usar Managed ClickStack en ClickHouse Cloud, los enlaces deben incluir un parámetro `?chcServiceId=` para identificar qué servicio de ClickHouse Cloud debe cargarse si el usuario autenticado que sigue el enlace está autorizado a usar más de un servicio de ClickHouse Cloud.

  Ejemplo: abrir Búsqueda en un servicio de Cloud específico

  ```text
  https://hyperdx.clickhouse.cloud/search?chcServiceId=abc123
  ```
</Info>

<div id="search">
  ## Búsqueda — `/search`
</div>

La vista principal para buscar logs y trazas. Consulta [Búsqueda](/es/clickstack/features/search) para obtener más información sobre la sintaxis de búsqueda.

| Parámetro       | Formato                                                                    | Descripción                                                                                                                                                          |
| --------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`        | string                                                                     | La fuente en la que se realizará la búsqueda; acepta un ID de fuente o el **nombre** de una fuente (p. ej., `Logs`). Esta página solo admite fuentes de Log y Trace. |
| `where`         | string                                                                     | Texto de la consulta de filtro, con sintaxis Lucene o SQL (consulta `whereLanguage`).                                                                                |
| `whereLanguage` | `lucene` | `sql`                                                           | El lenguaje de consulta en el que se escribe `where`.                                                                                                                |
| `select`        | string                                                                     | Lista de columnas o expresiones SQL que se mostrará en la tabla de resultados.                                                                                       |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | Filtros de facetas estructurados que se aplican además de `where`.                                                                                                   |
| `orderBy`       | string                                                                     | Expresión de ordenación SQL para la tabla de resultados.                                                                                                             |
| `mode`          | `results` | `delta` | `pattern`                                            | El modo de análisis activo. `delta` solo está disponible para fuentes de trazas.                                                                                     |
| `isLive`        | `true` | `false`                                                           | Indica si el seguimiento en tiempo real está habilitado (el valor predeterminado es `true`).                                                                         |
| `traceId`       | string                                                                     | Abre directamente una vista waterfall de la traza correspondiente al ID de traza indicado.                                                                           |
| `from`, `to`    | milisegundos desde epoch                                                   | Intervalo de tiempo absoluto. Si se omite, el valor predeterminado es los últimos 15 minutos.                                                                        |

También se puede abrir una búsqueda guardada directamente en `/search/<savedSearchId>`.

<div id="example-search-errors">
  ### Ejemplo: Busque errores en la fuente `Logs` del servicio `checkout` dentro de un intervalo de tiempo
</div>

```text
<YOUR_CLICKSTACK_URL>/search?source=Logs&from=1735689600000&to=1735693200000&where=level:error&filters=[{"type":"sql","condition":"ServiceName IN ('checkout')"}]
```

<div id="example-search-trace">
  ### Ejemplo: Ir directamente a la vista waterfall de la traza
</div>

```text
<YOUR_CLICKSTACK_URL>/search?source=Traces&traceId=ba7217967eb90d040b7eb39f97ecc5c4
```

<div id="saved-searches">

</div>

La lista de búsquedas guardadas.

| Parámetro | Formato | Descripción                                                             |
| --------- | ------- | ----------------------------------------------------------------------- |
| `tag`     | string  | Filtra la lista para mostrar las búsquedas guardadas con esta etiqueta. |

<div id="example-saved-searches-tag">
  ### Ejemplo: Mostrar las búsquedas guardadas con la etiqueta `production`
</div>

```text
<YOUR_CLICKSTACK_URL>/search/list?tag=production
```

<div id="dashboards">
  ## Dashboards — `/dashboards/<dashboardId>`
</div>

Un dashboard guardado. Omita `<dashboardId>` (`/dashboards`) para abrir un dashboard temporal sin guardar. Consulte [Dashboards](/es/clickstack/features/dashboards/overview) para obtener más información sobre cómo crear dashboards.

| Parámetro           | Formato                                                                                                                             | Descripción                                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `from`, `to`        | milisegundos desde la época                                                                                                         | Intervalo de tiempo aplicado a todos los mosaicos. Si se omite, se usan de forma predeterminada los últimos 15 minutos.                    |
| `where`             | cadena                                                                                                                              | Texto de consulta del filtro a nivel de dashboard, aplicado a todos los mosaicos.                                                              |
| `whereLanguage`     | `lucene` | `sql`                                                                                                                    | Lenguaje de consulta en el que está escrito `where`.                                                                                       |
| `filters`           | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]`                                                          | Valores de filtro estructurados del dashboard que seleccionan dos elementos en el menú desplegable del filtro `ServiceName`.                   |
| `granularity`       | `auto` | `30 second` | `1 minute` | `5 minute` | `10 minute` | `15 minute` | `30 minute` | `1 hour` | `12 hour` | `1 day` | `7 day` | Tamaño del bucket para los mosaicos de series temporales. `auto` selecciona un tamaño de bucket según el intervalo de tiempo seleccionado. |
| `highlightedTileId` | cadena                                                                                                                              | Desplaza la vista hasta un mosaico específico y lo resalta; resulta útil al enlazar desde una alerta.                                      |

<div id="example-dashboard-highlight">
  ### Ejemplo: Abrir un dashboard para un intervalo de tiempo con un mosaico resaltado
</div>

Resulta útil para vincular desde una notificación de alerta directamente al mosaico que la activó.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?from=1735689600000&to=1735693200000&highlightedTileId=chart-1
```

<div id="chart-explorer">
  ## Chart Explorer — `/chart`
</div>

Un generador de gráficos ad hoc que se puede compartir.

| Parámetro    | Formato                  | Descripción                                                                                                                                                                                   |
| ------------ | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config`     | JSON                     | La configuración completa del gráfico (source, select, where, tipo de gráfico, etc.). Normalmente se genera mediante enlaces «Share» desde la aplicación, en lugar de escribirse manualmente. |
| `from`, `to` | milisegundos desde epoch | Intervalo de tiempo. Si se omite, se usan de forma predeterminada los últimos 15 minutos.                                                                                                     |

<div id="example-chart-config">
  ### Ejemplo: Abrir la configuración de un gráfico de latencia p99 para un intervalo de tiempo
</div>

```text
<YOUR_CLICKSTACK_URL>/chart?granularity=auto&from=1785759381784&to=1785762981785&config={"name":"","select":[{"aggFn":"quantile","aggCondition":"","aggConditionLanguage":"lucene","valueExpression":"Duration","level":0.99,"alias":"p99"}],"where":"","whereLanguage":"lucene","displayType":"line","alignDateRangeToGranularity":true,"source":"68814eb5d40a9d0449afc1f2","connection":"68814b6fd40a9d0449afbe78","groupBy":"ServiceName"}
```

<div id="session-replay">
  ## Reproducción de sesiones — `/sessions`
</div>

Exploración y reproducción de sesiones. Consulte [Reproducción de sesiones](/es/clickstack/features/session-replay) para obtener información detallada sobre esta funcionalidad.

| Parámetro       | Formato                     | Descripción                                                                                                        |
| --------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `sessionSource` | string                      | ID o nombre de la fuente de sesiones.                                                                              |
| `where`         | string                      | Texto de la consulta de filtro para la lista de sesiones.                                                          |
| `whereLanguage` | `lucene` | `sql`            | Lenguaje de consulta en el que se escribe `where`.                                                                 |
| `from`, `to`    | milisegundos desde el epoch | Intervalo de tiempo de la lista de sesiones. Si se omite, se toman de forma predeterminada los últimos 15 minutos. |
| `sid`           | string                      | Abre una sesión específica mediante su ID.                                                                         |
| `sfrom`, `sto`  | milisegundos desde el epoch | Ventana de tiempo de la sesión abierta (se usa con `sid`).                                                         |

<div id="example-sessions-time-range">
  ### Ejemplo: Explore las reproducciones de sesión dentro de un intervalo de tiempo
</div>

```text
<YOUR_CLICKSTACK_URL>/sessions?from=1735689600000&to=1735693200000
```

<div id="example-sessions-open">
  ### Ejemplo: Abre una reproducción de sesión específica en el intervalo de tiempo en que se grabó
</div>

```text
<YOUR_CLICKSTACK_URL>/sessions?sid=6712abf0e4b0f2a1c3d4e5f6&sfrom=1735689600000&sto=1735690200000
```

<div id="service-map">
  ## Mapa de servicios — `/service-map`
</div>

Consulta [Mapa de servicios](/es/clickstack/service-maps) para obtener más información sobre esta funcionalidad.

| Parámetro        | Formato                  | Descripción                                                                                |
| ---------------- | ------------------------ | ------------------------------------------------------------------------------------------ |
| `source`         | cadena                   | ID o nombre de la fuente de trazas.                                                        |
| `samplingFactor` | entero                   | Divisor de muestreo de trazas (`1` = 100 % de las trazas, `2` = 50 %, `4` = 25 %, etc.).   |
| `from`, `to`     | milisegundos desde epoch | Intervalo de tiempo. Si se omiten, se usan de forma predeterminada los últimos 15 minutos. |

<div id="example-service-map">
  ### Ejemplo: Visualice el mapa de servicios para un intervalo de tiempo
</div>

```text
<YOUR_CLICKSTACK_URL>/service-map?from=1735689600000&to=1735693200000
```

<div id="services">
  ## Servicios — `/services`
</div>

Dashboards de HTTP, bases de datos y errores por servicio.

| Parámetro       | Formato                                                                    | Descripción                                                                                             |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `tab`           | `http` | `database` | `errors`                                             | Subpestaña del dashboard de servicio que se muestra. Valor predeterminado: `http`                           |
| `source`        | string                                                                     | ID de la fuente de trazas.                                                                              |
| `service`       | string                                                                     | Nombre del servicio seleccionado.                                                                       |
| `where`         | string                                                                     | Texto de la consulta de filtro.                                                                         |
| `whereLanguage` | `lucene` | `sql`                                                           | Lenguaje de consulta en el que está escrito `where` (en esta página, el valor predeterminado es `sql`). |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | Valores de la barra de filtros del dashboard.                                                               |
| `from`, `to`    | milisegundos desde la época                                                | Intervalo de tiempo. Si se omite, el valor predeterminado corresponde a los últimos 15 minutos.         |

<div id="example-services-database">
  ### Ejemplo: Consulte el dashboard de la base de datos de un servicio para un intervalo de tiempo
</div>

```text
<YOUR_CLICKSTACK_URL>/services?tab=database&service=checkout&from=1735689600000&to=1735693200000
```

<div id="example-services-errors">
  ### Ejemplo: Ver el dashboard de errores de un servicio
</div>

```text
<YOUR_CLICKSTACK_URL>/services?tab=errors&service=payments
```

<div id="kubernetes">
  ## Kubernetes — `/kubernetes`
</div>

| Parámetro                              | Formato                               | Descripción                                                                                                                       |
| -------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `logSource`, `metricSource`            | cadena                                | ID de las fuentes de logs y métricas. Si solo se proporciona una, la otra toma de forma predeterminada una fuente correlacionada. |
| `tab`                                  | p. ej., `pods`, `nodes`, `namespaces` | Subvista activa.                                                                                                                  |
| `q`                                    | cadena                                | Consulta de Lucene para la lista de recursos.                                                                                     |
| `podName`, `nodeName`, `namespaceName` | cadena                                | Abre el panel de detalles de un pod, nodo o espacio de nombres específico.                                                        |
| `from`, `to`                           | milisegundos desde la época           | Intervalo de tiempo. Si se omite, se establece de forma predeterminada en los últimos 15 minutos.                                 |

<div id="example-kubernetes-pod">
  ### Ejemplo: Abra el panel de detalles de un pod de Kubernetes concreto
</div>

```text
<YOUR_CLICKSTACK_URL>/kubernetes?tab=pods&podName=checkout-7d9f8b5c-2xk9p
```
