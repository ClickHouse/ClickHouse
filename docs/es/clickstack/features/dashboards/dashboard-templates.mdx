ClickStack incluye una biblioteca de plantillas de paneles de control preconfiguradas que le ofrecen visibilidad inmediata de las métricas comunes de infraestructura y aplicaciones.

## Explorar las plantillas disponibles {#browsing-templates}

Para explorar la biblioteca integrada de plantillas, ve a **Dashboards** y haz clic en **Browse plantillas de paneles de control**.

<div className="ch-image-lg">
  <Frame>
    ![Botón Browse plantillas de paneles de control](/images/use-cases/observability/browse-dashboard-template.webp)
  </Frame>
</div>

Esto abre la galería de plantillas, donde se organizan por categoría. Haz clic en **Import** para iniciar el proceso de importación de esa plantilla.

<div className="ch-image-lg">
  <Frame>
    ![Galería de plantillas de panel](/images/use-cases/observability/dashboard-template-gallery.webp)
  </Frame>
</div>

## Importar una plantilla {#importing-a-template}

Para importar una plantilla, debes configurar una fuente de datos para cada visualización del dashboard. Selecciona una fuente de datos en el menú desplegable de cada visualización y, luego, haz clic en `Finish Import`.

<div className="ch-image-lg">
  <Frame>
    ![Importación de plantilla de panel](/images/use-cases/observability/import-dashboard-template.webp)
  </Frame>
</div>

### Métricas de ejecución de OTel {#otel-runtime-metrics}

Las plantillas integradas de Métricas de ejecución de OTel están diseñadas para aplicaciones instrumentadas con [métricas del entorno de ejecución de OpenTelemetry](https://opentelemetry.io/docs/specs/semconv/runtime/).

| Plantilla                   | Descripción                                                                                                                  |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **.NET Runtime Metrics**    | Recolecciones de GC, tamaño del montículo, uso del pool de hilos y recuento de ensamblados para aplicaciones .NET            |
| **Go Runtime Metrics**      | Recuento de goroutines, tiempos de pausa de GC, uso del montículo y estadísticas de memoria para aplicaciones Go             |
| **JVM Runtime Metrics**     | Memoria dentro y fuera del montículo, duración de GC, recuento de threads y carga de clases para aplicaciones basadas en JVM |
| **Node.js Runtime Metrics** | Retraso del bucle de eventos, uso del montículo, utilización de CPU y memoria de V8 para aplicaciones Node.js                |

Notas:

* Cada plantilla está configurada con un [filtro personalizado](/es/clickstack/features/dashboards/overview#custom-filters) para los servicios cuyo atributo del recurso [`telemetry.sdk.language`](https://opentelemetry.io/docs/specs/semconv/registry/attributes/telemetry/#telemetry-sdk-language) coincide con el entorno de ejecución del dashboard.
  * En entornos con esquemas personalizados de tablas de métricas de ClickHouse, puede ser necesario ajustar este filtro para que consulte las columnas correctas de Service Name y Resource Attributes.
  * En entornos de gran volumen, es posible reducir los tiempos de carga del filtro [materializando](/es/clickstack/managing/performance-tuning#materialize-frequently-queried-attributes) la columna `ResourceAttributes['telemetry.sdk.language']`.
* Las plantillas hacen referencia a las convenciones semánticas de OTel vigentes en el momento de su publicación y se actualizan periódicamente a medida que evoluciona la especificación de OTel. En el caso de servicios instrumentados con versiones anteriores de los SDK de OTel, puede que sea necesario [editar](/es/clickstack/features/dashboards/overview#dashboards-editing-visualizations) las visualizaciones para que hagan referencia a nombres de métricas antiguos.
