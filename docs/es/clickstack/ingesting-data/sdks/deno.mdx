Usa la compatibilidad integrada de Deno con OpenTelemetry para enviar logs, métricas y trazas a ClickStack. No necesitas el SDK de Node.js de ClickStack ni el paquete de registro heredado de Deno.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Configurar OpenTelemetry {#set-up-opentelemetry}

Siga las [instrucciones oficiales de configuración de OpenTelemetry para Deno](https://docs.deno.com/runtime/fundamentals/open_telemetry/) para instrumentar su aplicación. Configure el destino que se indica a continuación y, después, active la integración nativa de Deno al iniciar su aplicación:

```shell
OTEL_DENO=true OTEL_SERVICE_NAME='my-deno-app' deno run app.ts
```

Agregue los permisos que necesite su aplicación. Reemplace los destinos de ejemplo y los ajustes del exportador de consola que aparezcan en las instrucciones de upstream, incluidas las sobrescrituras de endpoint específicas de cada señal.

## Configure su destino {#configure-destination}

Establezca el endpoint HTTP de OTLP y la clave de ingestión de su recopilador de ClickStack. Use `http://` si su recolector no tiene TLS configurado. Para configurar el recolector, consulte [Ingesta con OpenTelemetry](/es/clickstack/ingesting-data/opentelemetry).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## Verificar la ingestión {#verify-ingestion}

Inicie su aplicación y genere actividad. En ClickStack, seleccione un intervalo de tiempo reciente y busque el nombre del servicio de su aplicación en Logs o Trazas. Consulte Métricas tras dejar pasar el tiempo necesario para que se exporten los datos.
