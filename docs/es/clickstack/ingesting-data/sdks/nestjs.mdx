Use el SDK de Node.js de ClickStack para recopilar telemetría de su aplicación NestJS y enviarla a ClickStack. Incluye instrumentación de solicitudes de NestJS y captura la salida de la consola.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Instalar el SDK {#install-sdk}

Use Node.js 22.15 o una versión posterior:

```shell
npm install @clickhouse/clickstack-node
```

## Configure su destino {#configure-destination}

Defina el endpoint HTTP de OTLP y la clave de ingestión de su recopilador de ClickStack. Use `http://` si su recolector no tiene TLS configurado. Para configurar el recolector, consulte [Ingesta con OpenTelemetry](/es/clickstack/ingesting-data/opentelemetry).

```shell
export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
```

## Inicie su aplicación {#start-application}

Establezca `OTEL_SERVICE_NAME` para identificar su aplicación. Compile su aplicación NestJS y, a continuación, precargue el SDK antes del punto de entrada compilado:

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

Ajusta `dist/main.js` para que coincida con la salida de tu build. Si utilizas `ts-node` u otro transpilador que intercepte `require`, utiliza en su lugar `--require @clickhouse/clickstack-node/register`. Si empaquetas tu aplicación, mantén el SDK y las dependencias instrumentadas como externas.

Puedes seguir utilizando el logger de consola predeterminado de NestJS. Si necesitas un logger personalizado, utiliza una integración compatible, como Winston o Pino. Para obtener más información sobre la configuración y la compatibilidad, consulta la [guía de Node.js](/es/clickstack/ingesting-data/sdks/nodejs).

## Verificar la ingestión {#verify-ingestion}

Realice una solicitud a un controlador y emita un mensaje de log. En ClickStack, seleccione un intervalo de tiempo reciente y busque el nombre del servicio de su aplicación en Logs y Traces. Consulte Metrics después de esperar un tiempo para que se complete la exportación.
