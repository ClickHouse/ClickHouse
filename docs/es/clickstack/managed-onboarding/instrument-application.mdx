Esta guía le explica cómo instrumentar una pequeña aplicación Node.js con OpenTelemetry y enviar sus logs, métricas, trazas y reproducciones de sesiones a ClickHouse Observability a través del recolector que usted ejecuta. El backend se instrumenta sin modificar el código fuente de la aplicación.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) es una aplicación Node.js que consulta el conjunto de datos de HackerNews alojado en la demo pública de ClickHouse. Cada gráfico, tabla y cuadro de búsqueda se basa en una consulta de ClickHouse real, por lo que cada interacción genera una traza cuyo span principal es la llamada HTTPS que el backend realiza a ClickHouse.

Esta guía presupone que ha completado [Configuración de su recopilador de OpenTelemetry](/es/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) y que tiene un recopilador de ClickStack en ejecución y accesible desde la máquina en la que ejecuta esta aplicación. **Asegúrese de haber anotado su endpoint OTLP** y el `OTLP_AUTH_TOKEN` que definió al implementarlo. Añadirá esos valores a `.env` antes de instrumentar la aplicación.

## Requisitos previos {#prerequisites}

* Un recopilador de ClickStack accesible desde esta máquina. Si aún no has desplegado uno, sigue primero [Configuración de su recopilador de OpenTelemetry](/es/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* El endpoint OTLP/HTTP de ese recolector (normalmente el puerto `4318`) y el `OTLP_AUTH_TOKEN` que configuraste en él. Úsalos como `OTEL_EXPORTER_OTLP_ENDPOINT` y `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ y npm.

## Clona el repositorio {#clone-the-repository}

Clona [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), instala las dependencias y copia la plantilla de variables de entorno:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

Completarás `.env` en los siguientes pasos y luego instrumentarás la aplicación desde este directorio.
