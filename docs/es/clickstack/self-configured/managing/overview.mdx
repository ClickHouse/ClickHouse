## Conceptos fundamentales de ClickHouse {#core-concepts}

La mayoría de las tareas de administración requieren conocer la base de datos de ClickHouse subyacente. Recomendamos revisar los conceptos fundamentales de ClickHouse que se describen a continuación antes de realizar operaciones administrativas o relacionadas con el rendimiento.

| Concepto                             | Descripción                                                                                                                                                                                                               |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tablas**                           | Cómo se corresponden las fuentes de datos con las tablas de ClickHouse subyacentes. Las tablas de ClickHouse utilizan principalmente el motor [`MergeTree`](/es/reference/engines/table-engines/mergetree-family/mergetree). |
| **Partes**                           | Cómo se escriben los datos en forma de partes inmutables que se fusionan con el tiempo.                                                                                                                                   |
| **Particiones**                      | Agrupaciones lógicas de partes de tabla que simplifican la administración de datos, las consultas y la optimización.                                                                                                      |
| **Fusiones**                         | El proceso en segundo plano que combina partes para reducir el número de partes consultadas y mantener el rendimiento.                                                                                                    |
| **Gránulos**                         | La unidad de datos más pequeña que se lee o se descarta durante la ejecución de consultas.                                                                                                                                |
| **Claves primarias (de ordenación)** | Cómo la clave `ORDER BY` determina la organización de datos en disco, la compresión y la poda en las consultas.                                                                                                           |

Estos conceptos son esenciales para el rendimiento de ClickHouse y le ayudarán a tomar decisiones administrativas con criterio al gestionar Self-managed ClickHouse Observability.
