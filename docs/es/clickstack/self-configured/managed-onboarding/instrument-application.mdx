Esta guía le muestra cómo instrumentar una pequeña aplicación Node.js con OpenTelemetry y enviar sus logs, métricas, trazas y reproducciones de sesiones a Self-managed ClickHouse Observability. El backend se instrumenta sin modificar el código fuente de la aplicación.

[HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer) es una aplicación Node.js que consulta el conjunto de datos de HackerNews alojado en la demo pública de ClickHouse. Cada gráfico, tabla y cuadro de búsqueda se basa en una consulta real de ClickHouse, por lo que cada interacción genera una traza cuyo span principal es la llamada HTTPS que el backend realiza a ClickHouse.

Esta guía da por hecho que ya ha completado [Configuración de su recopilador de OpenTelemetry](/es/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector) y que dispone de un recopilador de ClickStack en ejecución y accesible desde la máquina en la que ejecuta esta aplicación. **Asegúrese de tener a mano su endpoint OTLP** y el `OTLP_AUTH_TOKEN` que definió al desplegarlo. Deberá añadir esos valores a `.env` antes de instrumentar la aplicación.

## Requisitos previos {#prerequisites}

* Un recopilador de ClickStack accesible desde esta máquina. Si aún no ha desplegado ninguno, siga primero la guía [Configuración de su recopilador de OpenTelemetry](/es/clickstack/self-configured/managed-onboarding/setting-up-your-opentelemetry-collector).
* El endpoint OTLP/HTTP de ese recopilador (normalmente en el puerto `4318`) y el `OTLP_AUTH_TOKEN` que configuró en él. Utilícelos como `OTEL_EXPORTER_OTLP_ENDPOINT` y `OTEL_EXPORTER_OTLP_HEADERS=authorization=<token>`.
* Node 18+ y npm.

## Clonar el repositorio {#clone-the-repository}

Clone [HackerNews Analyzer](https://github.com/ClickHouse/hn-news-analyzer), instale las dependencias y copie la plantilla del archivo env:

```bash
git clone https://github.com/ClickHouse/hn-news-analyzer.git
cd hn-news-analyzer
npm install
cp .env.example .env
```

Completará el archivo `.env` en los próximos pasos y, a continuación, instrumentará la aplicación desde este directorio.
