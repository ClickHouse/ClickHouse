ClickHouse Observability — Self-managed se ejecuta íntegramente en **ClickHouse Cloud** y ofrece un backend de observabilidad totalmente gestionado que conserva el mismo modelo de datos y la misma experiencia de usuario de ClickStack.

En este modelo, ClickHouse Cloud se encarga de alojar, operar y proteger **ClickHouse y la UI de ClickStack**. Los usuarios solo deben ejecutar un **recolector de OpenTelemetry (OTel)** para enviar los datos de telemetría al servicio administrado.

### ClickHouse Cloud: el motor {#clickhouse-cloud}

En el núcleo de ClickHouse Observability — Self-managed se encuentra ClickHouse Cloud, una versión sin servidor de ClickHouse, una base de datos orientada a columnas diseñada para el análisis en tiempo real a gran escala. Se encarga de la ingestión y las consultas de los datos de observabilidad, lo que permite:

* Búsquedas en menos de un segundo sobre terabytes de eventos
* Ingestión de miles de millones de registros high-cardinality al día
* Altas tasas de compresión, de al menos 10x, en datos de observabilidad
* Soporte nativo para datos JSON semiestructurados, lo que permite una evolución dinámica del esquema
* Un potente motor SQL con cientos de funciones analíticas integradas

ClickHouse Cloud trata los datos de observabilidad como eventos amplios, lo que permite una correlación profunda entre logs, métricas y trazas en una única estructura unificada.

Además de las capacidades de ClickHouse Open Source, ofrece una serie de ventajas para la observabilidad:

* Escalado automático de la capacidad de cómputo con independencia del almacenamiento
* Retención de bajo coste y prácticamente ilimitada gracias al almacenamiento de objetos
* La posibilidad de [aislar de forma independiente los workload de lectura y escritura](/es/clickstack/self-configured/managing/isolating-read-write) mediante almacenes.
* Autenticación integrada
* Copias de seguridad automatizadas
* Funcionalidades de seguridad y cumplimiento normativo
* Actualizaciones sin interrupciones

### Recolector de OpenTelemetry: ingesta de datos {#open-telemetry-collector-managed}

ClickHouse Observability — Self-managed incluye un recolector de OpenTelemetry (OTel) preconfigurado para ingestar telemetría de forma abierta y estandarizada. Puede enviar datos mediante el protocolo OTLP a través de:

* gRPC (puerto `4317`)
* HTTP (puerto `4318`)

El recolector exporta la telemetría a ClickHouse Cloud en lotes eficientes. Admite esquemas de tabla optimizados para cada origen de datos, lo que garantiza un rendimiento escalable en todos los tipos de señales.

### UI de ClickStack: la interfaz {#hyperdx}

La UI de ClickStack es la interfaz de usuario de ClickStack. Ofrece:

* Búsqueda en lenguaje natural y con sintaxis de tipo Lucene
* Seguimiento en vivo (live tailing) para depuración en real-time
* Vistas unificadas de log, métricas y trazas
* Reproducción de sesiones para la observabilidad del frontend
* Creación de paneles de control y configuración de alertas
* Interfaz de consultas SQL para análisis avanzados

Diseñada específicamente para ClickHouse, la UI de ClickStack combina una búsqueda potente con flujos de trabajo intuitivos que le permiten detectar anomalías, investigar problemas y obtener información de forma rápida.

En ClickHouse Observability — Self-managed, la UI está integrada en el sistema de autenticación de la consola de ClickHouse Cloud.
