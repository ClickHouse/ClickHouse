El recolector de ClickHouse Observability utiliza el [exportador de ClickHouse](https://github.com/open-telemetry/opentelemetry-collector-contrib/blob/main/exporter/clickhouseexporter/README.md) para crear tablas en ClickHouse e insertar datos.

Para cada tipo de datos se crean las siguientes tablas en la base de datos `default`. Puede cambiar esta base de datos de destino modificando la variable de entorno `HYPERDX_OTEL_EXPORTER_CLICKHOUSE_DATABASE` en la imagen que aloja el recolector.
