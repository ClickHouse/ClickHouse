Use el agente Java de OpenTelemetry o el SDK para enviar logs, métricas y trazas a ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Configurar OpenTelemetry {#set-up-opentelemetry}

Siga las [instrucciones oficiales de configuración del agente Java de OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/) para instalar la instrumentación y configurar su aplicación. Para la instrumentación manual, consulte la [documentación del SDK de Java](https://opentelemetry.io/docs/languages/java/instrumentation/).

Configure la [exportación OTLP](https://opentelemetry.io/docs/languages/java/configuration/#properties-exporters) para las señales que desee enviar con los ajustes de conexión que se indican a continuación. Reemplace cualquier destino de ejemplo que aparezca en las instrucciones upstream, incluidas las sobrescrituras de endpoint específicas de cada señal.

## Configure su destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gestionado">
    <BetaBadge label="Oferta Beta" />

    Abra **Team Settings → Data → Managed Telemetry** en su servicio y copie el **OTLP HTTP endpoint** y la **API key**. Utilice el endpoint HTTPS completo, incluido el puerto:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogestionado">
    Utilice el endpoint OTLP HTTP y la clave de ingestión de su recolector. Si su recolector no tiene TLS configurado, utilice `http://` en lugar de `https://`. Para configurar el recolector, consulte [Ingesta con OpenTelemetry](/es/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Verificar la ingestión {#verify-ingestion}

Inicie su aplicación instrumentada y genere actividad. En ClickHouse Observability, seleccione un intervalo de tiempo reciente y busque el nombre del servicio de su aplicación en Logs o Trazas. Si su aplicación emite métricas, consulte Métricas tras esperar el tiempo necesario para que se exporten.

Para resolver problemas de instrumentación y del exportador, consulte la [guía de resolución de problemas del agente Java de OpenTelemetry](https://opentelemetry.io/docs/zero-code/java/agent/getting-started/#troubleshooting).
