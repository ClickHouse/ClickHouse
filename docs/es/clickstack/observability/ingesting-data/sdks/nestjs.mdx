Utilice el SDK de Node.js de ClickStack para recopilar telemetría de su aplicación NestJS y enviarla a ClickHouse Observability. Incluye instrumentación de solicitudes de NestJS y captura la salida de consola.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Instalación del SDK {#install-sdk}

Use Node.js 22.15 o una versión posterior:

```shell
npm install @clickhouse/clickstack-node
```

## Configuración del destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gestionado">
    <BetaBadge label="Oferta Beta" />

    Abra **Configuración del equipo → Datos → Telemetría gestionada** en su servicio y copie el **endpoint OTLP HTTP** y la **clave de API**. Use el endpoint HTTPS completo, incluido el puerto:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogestionado">
    Use el endpoint OTLP HTTP y la clave de ingestión de su recolector. Use `http://` en lugar de `https://` si su recolector no tiene TLS configurado. Para configurar el recolector, consulte [Ingestión con OpenTelemetry](/es/clickstack/observability/ingesting-data/opentelemetry#self-managed).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Inicia tu aplicación {#start-application}

Define `OTEL_SERVICE_NAME` para identificar tu aplicación. Compila tu aplicación NestJS y, a continuación, precarga el SDK antes del punto de entrada compilado:

```shell
npm run build
OTEL_SERVICE_NAME='my-nestjs-app' node --import @clickhouse/clickstack-node/register dist/main.js
```

Ajuste `dist/main.js` para que coincida con la salida de su build. Si usa `ts-node` u otro transpilador que intercepte `require`, utilice `--require @clickhouse/clickstack-node/register` en su lugar. Si empaqueta su aplicación, mantenga el SDK y las dependencias instrumentadas como externas.

Puede seguir usando el logger de consola predeterminado de NestJS. Si necesita un logger personalizado, utilice una integración compatible, como Winston o Pino. Para obtener más detalles sobre la configuración y la compatibilidad, consulte la [guía de Node.js](/es/clickstack/observability/ingesting-data/sdks/nodejs).

## Verificar la ingestión {#verify-ingestion}

Realice una solicitud a un controlador y emita un mensaje de log. En ClickHouse Observability, seleccione un intervalo de tiempo reciente y busque el nombre del servicio de su aplicación en Logs y Traces. Una vez transcurrido el tiempo necesario para la exportación, consulte Metrics.
