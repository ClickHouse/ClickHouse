Use el SDK de Go de OpenTelemetry para enviar logs, métricas y trazas a ClickHouse Observability.

<ClickStackIntegrates signals={['logs', 'metrics', 'traces']} />

## Configurar OpenTelemetry {#set-up-opentelemetry}

Siga las [instrucciones oficiales de configuración de OpenTelemetry para Go](https://opentelemetry.io/docs/languages/go/getting-started/) para inicializar el SDK e instrumentar su aplicación.

Configure la [exportación OTLP mediante HTTP](https://opentelemetry.io/docs/languages/go/exporters/) para las señales que desee enviar con los ajustes de conexión que se indican a continuación. Reemplace cualquier destino de ejemplo que aparezca en las instrucciones upstream, incluidas las sobrescrituras de endpoint específicas de cada señal.

## Configure el destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gestionado">
    <BetaBadge label="Oferta Beta" />

    Abra **Team Settings → Data → Managed Telemetry** en su servicio y copie el **OTLP HTTP endpoint** y la **API key**. Utilice el endpoint HTTPS completo, incluido el puerto:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogestionado">
    Utilice el endpoint OTLP HTTP y la clave de ingestión de su recolector. Si el recolector no tiene TLS configurado, utilice `http://` en lugar de `https://`. Para configurar el recolector, consulte [Ingesta con OpenTelemetry](/es/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Verificar la ingestión {#verify-ingestion}

Inicie su aplicación instrumentada y genere algo de actividad. En ClickHouse Observability, seleccione un intervalo de tiempo reciente y busque el nombre del servicio de su aplicación en Logs o Traces. Si su aplicación emite métricas, consulte Metrics tras dejar el tiempo suficiente para que se exporten.

Para resolver problemas de instrumentación y del exportador, consulte la [documentación de OpenTelemetry para Go](https://opentelemetry.io/docs/languages/go/).
