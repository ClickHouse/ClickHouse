Utilice el SDK de OpenTelemetry para Ruby para enviar trazas a ClickHouse Observability.

## Configurar OpenTelemetry {#set-up-opentelemetry}

Siga las [instrucciones oficiales de configuración de OpenTelemetry para Ruby](https://opentelemetry.io/docs/languages/ruby/getting-started/) para inicializar el SDK e instrumentar su aplicación.

Configure la [exportación OTLP mediante HTTP](https://opentelemetry.io/docs/languages/ruby/exporters/) para las trazas con los ajustes de conexión que se indican a continuación. Reemplace los destinos de ejemplo que aparecen en las instrucciones upstream, incluidas las sobrescrituras de endpoint específicas de cada señal.

## Configure su destino {#configure-destination}

<Tabs>
  <Tab title="Totalmente gestionado">
    <BetaBadge label="Oferta en fase beta" />

    Abra **Team Settings → Data → Managed Telemetry** en su servicio y copie el **endpoint OTLP HTTP** y la **clave de API**. Use el endpoint HTTPS completo, incluido el puerto:

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_OTEL_ENDPOINT:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=Bearer%20YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>

  <Tab title="Autogestionado">
    Use el endpoint OTLP HTTP y la API key de ingesta de su recolector. Si su recolector no tiene TLS configurado, utilice `http://` en lugar de `https://`. Para configurar el recolector, consulte [Ingesta con OpenTelemetry](/es/clickstack/observability/ingesting-data/opentelemetry#sending-otel-data-self-configured).

    ```shell
    export OTEL_EXPORTER_OTLP_ENDPOINT='https://YOUR_COLLECTOR_HOST:4318'
    export OTEL_EXPORTER_OTLP_HEADERS='authorization=YOUR_INGESTION_API_KEY'
    export OTEL_EXPORTER_OTLP_PROTOCOL='http/protobuf'
    ```
  </Tab>
</Tabs>

## Verificar la ingestión {#verify-ingestion}

Inicie su aplicación instrumentada y genere actividad. En ClickHouse Observability, seleccione un intervalo de tiempo reciente y busque el nombre del servicio de su aplicación en Traces.

Para la resolución de problemas relacionados con la instrumentación y el exportador, consulte la [documentación de OpenTelemetry para Ruby](https://opentelemetry.io/docs/languages/ruby/).
