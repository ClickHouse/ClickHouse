## Conecte su aplicación {#connect-your-application}

1. Siga la guía correspondiente a su lenguaje o plataforma para configurar la instrumentación.
2. Elija su destino en esa guía:
   * **Totalmente gestionado:** use el endpoint OTLP gestionado de su servicio y la API key de ingesta, disponibles en **Configuración del equipo → Datos → Managed Telemetry**.
   * **Autogestionado:** use el endpoint OTLP de su Colector de OpenTelemetry y la API key de ingesta que haya configurado.
3. Genere actividad en la aplicación y, a continuación, compruebe que la telemetría esperada aparece en la interfaz de usuario.

Cada guía indica el formato de autenticación y los ajustes del exportador para cada SDK. La guía de Lambda también ofrece una opción basada en capas de OpenTelemetry que reenvía la telemetría a través de un Colector local.
