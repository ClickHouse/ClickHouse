Las páginas de ClickHouse Observability pueden abrirse con enlaces profundos que utilizan parámetros de consulta en la URL, lo que le permite ir directamente a una búsqueda, un panel de control o un panel concretos desde un sistema externo (una notificación de alerta, un runbook, una tarea de CI, un mensaje de chat, etc.).

Los ejemplos de esta página utilizan `<YOUR_CLICKSTACK_URL>`. Sustitúyalo por la URL base de su interfaz de usuario de observabilidad.

<Note>
  Para facilitar la lectura, los ejemplos muestran los parámetros de consulta sin codificación URL. Si genera los enlaces mediante programación, codifique en formato URL el valor de cada parámetro de consulta.
</Note>

<Info>
  **Parámetro de ID de servicio de Cloud**

  Al utilizar la interfaz de usuario de Cloud, los enlaces deben incluir un parámetro `?chcServiceId=` que identifique qué servicio de ClickHouse Cloud debe cargarse cuando el usuario autenticado que abre el enlace tiene autorización para usar más de un servicio de ClickHouse Cloud.

  Ejemplo: abrir Búsqueda en un servicio de Cloud específico

  ```text
  https://hyperdx.clickhouse.cloud/search?chcServiceId=abc123
  ```
</Info>

## Búsqueda — `/search` {#search}

La vista principal de búsqueda de logs y trazas. Consulte [Búsqueda](/es/clickstack/observability/features/search) para obtener más detalles sobre la sintaxis de búsqueda.

| Parámetro       | Formato                                                                    | Descripción                                                                                                                                               |
| --------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`        | cadena                                                                     | Fuente en la que se busca: acepta un ID de fuente o un **nombre** de fuente (p. ej., `Logs`). En esta página solo se admiten fuentes de logs y de trazas. |
| `where`         | cadena                                                                     | Texto de la consulta de filtro, en sintaxis Lucene o SQL (consulte `whereLanguage`).                                                                      |
| `whereLanguage` | `lucene` | `sql`                                                           | Lenguaje de consulta en el que está escrito `where`.                                                                                                      |
| `select`        | cadena                                                                     | Lista de columnas/expresiones SQL que se mostrarán en la tabla de resultados.                                                                             |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | Filtros de facetas estructurados que se aplican además de `where`.                                                                                        |
| `orderBy`       | cadena                                                                     | Expresión SQL para ordenar la tabla de resultados.                                                                                                        |
| `mode`          | `results` | `delta` | `pattern`                                            | Modo de análisis activo. `delta` solo está disponible para fuentes de trazas.                                                                             |
| `isLive`        | `true` | `false`                                                           | Indica si el live tail está habilitado (valor predeterminado: `true`).                                                                                    |
| `traceId`       | cadena                                                                     | Abre directamente la vista waterfall de la traza correspondiente al ID de traza indicado.                                                                 |
| `from`, `to`    | milisegundos desde la época Unix                                           | Intervalo de tiempo absoluto. Si se omite, se usan de forma predeterminada los últimos 15 minutos.                                                        |

También se puede abrir directamente una búsqueda guardada en `/search/<savedSearchId>`.

### Ejemplo: Buscar errores del servicio `checkout` en la fuente `Logs` dentro de un intervalo de tiempo {#example-search-errors}

```text
<YOUR_CLICKSTACK_URL>/search?source=Logs&from=1735689600000&to=1735693200000&where=level:error&filters=[{"type":"sql","condition":"ServiceName IN ('checkout')"}]
```

### Ejemplo: ir directamente a la vista waterfall de una traza {#example-search-trace}

```text
<YOUR_CLICKSTACK_URL>/search?source=Traces&traceId=ba7217967eb90d040b7eb39f97ecc5c4
```

## Búsquedas guardadas — `/search/list` {#saved-searches}

La lista de búsquedas guardadas.

| Parámetro | Formato | Descripción                                                                  |
| --------- | ------- | ---------------------------------------------------------------------------- |
| `tag`     | cadena  | Filtra la lista para mostrar solo las búsquedas guardadas con esta etiqueta. |

### Ejemplo: listar las búsquedas guardadas con la etiqueta `production` {#example-saved-searches-tag}

```text
<YOUR_CLICKSTACK_URL>/search/list?tag=production
```

## Paneles de control — `/dashboards/<dashboardId>` {#dashboards}

Un panel de control guardado. Omita `<dashboardId>` (`/dashboards`) para abrir un panel de control temporal sin guardar. Consulte [Paneles de control](/es/clickstack/observability/features/dashboards/overview) para obtener más información sobre cómo crear paneles de control.

| Parámetro           | Formato                                                                                                                             | Descripción                                                                                                                               |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `from`, `to`        | milisegundos desde la época Unix                                                                                                    | Intervalo de tiempo aplicado a todos los bloques. Si se omite, se usan de forma predeterminada los últimos 15 minutos.                    |
| `where`             | cadena                                                                                                                              | Texto de la consulta del filtro a nivel de panel de control, que se aplica a todos los bloques.                                                  |
| `whereLanguage`     | `lucene` | `sql`                                                                                                                    | Lenguaje de consulta en el que está escrito `where`.                                                                                      |
| `filters`           | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]`                                                          | Valores estructurados de los filtros del panel de control; por ejemplo, la selección de dos elementos en un desplegable de filtro `ServiceName`. |
| `granularity`       | `auto` | `30 second` | `1 minute` | `5 minute` | `10 minute` | `15 minute` | `30 minute` | `1 hour` | `12 hour` | `1 day` | `7 day` | Tamaño del bucket para los bloques de time-series. `auto` elige un tamaño de bucket en función del intervalo de tiempo seleccionado.      |
| `highlightedTileId` | cadena                                                                                                                              | Desplaza la vista hasta un bloque específico y lo resalta; resulta útil al enlazar desde una alerta.                                      |

### Ejemplo: abrir un panel de control en un intervalo de tiempo con un bloque resaltado {#example-dashboard-highlight}

Resulta útil para enlazar desde una notificación de alerta directamente al bloque que la activó.

```text
<YOUR_CLICKSTACK_URL>/dashboards/64f1c2a1e8b9f3a1b0d2e5c7?from=1735689600000&to=1735693200000&highlightedTileId=chart-1
```

## Explorador de Gráficos — `/chart` {#chart-explorer}

Un creador de gráficos ad hoc que se puede compartir.

| Parámetro    | Formato                          | Descripción                                                                                                                                                                                                          |
| ------------ | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config`     | JSON                             | La configuración completa del gráfico (fuente, select, where, tipo de gráfico, etc.). Normalmente se genera a partir de los enlaces de &quot;Compartir&quot; de la propia aplicación, en lugar de escribirse a mano. |
| `from`, `to` | milisegundos desde la época Unix | Intervalo de tiempo. Si se omite, se usan de forma predeterminada los últimos 15 minutos.                                                                                                                            |

### Ejemplo: abrir la configuración de un gráfico de latencia p99 para un intervalo de tiempo {#example-chart-config}

```text
<YOUR_CLICKSTACK_URL>/chart?granularity=auto&from=1785759381784&to=1785762981785&config={"name":"","select":[{"aggFn":"quantile","aggCondition":"","aggConditionLanguage":"lucene","valueExpression":"Duration","level":0.99,"alias":"p99"}],"where":"","whereLanguage":"lucene","displayType":"line","alignDateRangeToGranularity":true,"source":"68814eb5d40a9d0449afc1f2","connection":"68814b6fd40a9d0449afbe78","groupBy":"ServiceName"}
```

| `tag`     | cadena  | Filtra por etiqueta.                                                 |
| `creator` | cadena  | Filtra por el nombre del creador de la alerta.                       |

```text
<YOUR_CLICKSTACK_URL>/alerts?tag=on-call
```

## Reproducción de sesiones — `/sessions` {#session-replay}

Exploración y reproducción de sesiones. Consulte [Reproducción de sesiones](/es/clickstack/observability/features/session-replay) para obtener más información sobre esta funcionalidad.

| Parámetro       | Formato                          | Descripción                                                                                                       |
| --------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `sessionSource` | cadena                           | ID o nombre de la fuente de sesiones.                                                                             |
| `where`         | cadena                           | Texto de la consulta de filtro que se aplica a la lista de sesiones.                                              |
| `whereLanguage` | `lucene` | `sql`                 | Lenguaje de consulta en el que está escrito `where`.                                                              |
| `from`, `to`    | milisegundos desde la época Unix | Intervalo de tiempo de la lista de sesiones. Si se omite, se usan de forma predeterminada los últimos 15 minutos. |
| `sid`           | cadena                           | Abre una sesión concreta por su ID.                                                                               |
| `sfrom`, `sto`  | milisegundos desde la época Unix | Ventana de tiempo de la sesión abierta (se usa con `sid`).                                                        |

### Ejemplo: Explorar reproducciones de sesiones en un intervalo de tiempo {#example-sessions-time-range}

```text
<YOUR_CLICKSTACK_URL>/sessions?from=1735689600000&to=1735693200000
```

### Ejemplo: Abrir una reproducción de sesión concreta en su ventana de tiempo de grabación {#example-sessions-open}

```text
<YOUR_CLICKSTACK_URL>/sessions?sid=6712abf0e4b0f2a1c3d4e5f6&sfrom=1735689600000&sto=1735690200000
```

## Mapa de servicios — `/service-map` {#service-map}

Consulte [Mapa de servicios](/es/clickstack/observability/service-maps) para obtener más información sobre esta funcionalidad.

| Parámetro        | Formato                          | Descripción                                                                           |
| ---------------- | -------------------------------- | ------------------------------------------------------------------------------------- |

| `from`, `to`     | milisegundos desde la época Unix | Intervalo de tiempo. Si se omite, se usan por defecto los últimos 15 minutos.         |

```text
<YOUR_CLICKSTACK_URL>/service-map?from=1735689600000&to=1735693200000
```

## Servicios — `/services` {#services}

Paneles de control de HTTP, base de datos y errores por servicio.

| Parámetro       | Formato                                                                    | Descripción                                                                                             |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `tab`           | `http` | `database` | `errors`                                             | Subpestaña del panel de control del servicio que se muestra. Valor predeterminado: `http`                      |
| `source`        | cadena                                                                     | ID de la fuente de trazas.                                                                              |
| `service`       | cadena                                                                     | Nombre del servicio seleccionado.                                                                       |
| `where`         | cadena                                                                     | Texto de la consulta de filtro.                                                                         |
| `whereLanguage` | `lucene` | `sql`                                                           | Lenguaje de consulta en el que está escrito `where` (en esta página, el valor predeterminado es `sql`). |
| `filters`       | `{"type":"sql","condition":"<column> IN ('<value1>', '<value2>', ...)"}[]` | Valores de la barra de filtros del panel de control.                                                           |
| `from`, `to`    | milisegundos desde la época Unix                                           | Intervalo de tiempo. Si se omite, se usan por defecto los últimos 15 minutos.                           |

### Ejemplo: Consultar el panel de control de la base de datos de un servicio en un intervalo de tiempo {#example-services-database}

```text
<YOUR_CLICKSTACK_URL>/services?tab=database&service=checkout&from=1735689600000&to=1735693200000
```

### Ejemplo: Ver el panel de control de errores de un servicio {#example-services-errors}

```text
<YOUR_CLICKSTACK_URL>/services?tab=errors&service=payments
```

## Kubernetes — `/kubernetes` {#kubernetes}

| Parámetro                              | Formato                               | Descripción                                                                                                                     |
| -------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `logSource`, `metricSource`            | cadena                                | IDs de las fuentes de logs y de métricas. Si solo se indica uno, el otro usa de forma predeterminada una fuente correlacionada. |
| `tab`                                  | p. ej., `pods`, `nodes`, `namespaces` | Subvista activa.                                                                                                                |
| `q`                                    | cadena                                | Consulta Lucene para la lista de recursos.                                                                                      |
| `podName`, `nodeName`, `namespaceName` | cadena                                | Abre el panel de detalles de un pod de Kubernetes, nodo o espacio de nombres concreto.                                                        |
| `from`, `to`                           | milisegundos desde la época Unix      | Intervalo de tiempo. Si se omite, se usan de forma predeterminada los últimos 15 minutos.                                       |

### Ejemplo: Abrir el panel de detalles de un pod de Kubernetes concreto {#example-kubernetes-pod}

```text
<YOUR_CLICKSTACK_URL>/kubernetes?tab=pods&podName=checkout-7d9f8b5c-2xk9p
```
