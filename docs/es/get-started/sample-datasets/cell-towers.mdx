## Análisis geoespacial con antenas de telefonía {#geospatial-analysis-with-cell-towers}

En esta guía cargarás los datos de `OpenCelliD` en `ClickHouse Cloud`, los enriquecerás con un diccionario de países, consultarás antenas situadas en Alemania y las visualizarás con `ClickHouse Agents`.

<Steps>
  <Step title="Carga los datos de ejemplo">
    En `ClickHouse Cloud`, abre **Load data**, elige **Cell Towers** en **Sample data** y carga el conjunto de datos. Cada fila de `cell_towers` representa una antena; `lon` y `lat` son sus coordenadas.

    ```sql
    DESCRIBE TABLE cell_towers
    ```
  </Step>
  <Step title="Consulta y enriquece las antenas">
    ```sql
    SELECT radio, count() AS c FROM cell_towers GROUP BY radio ORDER BY c DESC;
    SELECT mcc, count() AS c FROM cell_towers GROUP BY mcc ORDER BY c DESC LIMIT 10;
    ```

    Crea un diccionario para sustituir el `mcc` numérico por el país:

    ```sql
    CREATE DICTIONARY mcc_country_dict (MCC UInt16, Country String)
    PRIMARY KEY MCC
    SOURCE(HTTP(url 'https://raw.githubusercontent.com/ClickHouse/examples/refs/heads/main/datasets/mcc-countries.csv' format 'CSVWithNames'))
    LAYOUT(HASHED()) LIFETIME(MIN 0 MAX 0);

    SELECT mcc, dictGet('mcc_country_dict', 'Country', mcc) AS country, count() AS cnt
    FROM cell_towers GROUP BY mcc ORDER BY cnt DESC LIMIT 5;
    ```
  </Step>
  <Step title="Incorpora datos geográficos">
    `ClickHouse` incluye funciones como [`pointInPolygon`](/reference/functions/regular-functions/geo/coordinates#pointinpolygon). Crea `germany`, inserta el contorno de Alemania continental del [tutorial en inglés](/get-started/sample-datasets/cell-towers#germany-polygon) y cuenta las antenas dentro del polígono:

    ```sql
    CREATE TABLE germany (polygon Array(Tuple(Float64, Float64))) ORDER BY polygon;
    SELECT formatReadableQuantity(count()) FROM cell_towers
    WHERE pointInPolygon((lon, lat), (SELECT * FROM germany));
    ```

    El resultado es aproximadamente `2.62 million`.
  </Step>
  <Step title="Visualiza los datos con ClickHouse Agents">
    Abre **ClickHouse agents** y envía: "Visualize cell towers within Germany on a map using the `default.cell_towers` and `default.germany` tables".

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers.webp" size="lg" alt="Chat de ClickHouse Agent que crea una cuadrícula de densidad de antenas en Alemania"/>

    El agente encuentra el MCC alemán, cuenta las antenas, las agrupa en una cuadrícula de `0.1°` y dibuja el contorno sobre el mapa.

    <Image img="/images/get-started/sample-datasets/clickhouse-agents-cell-towers-visualization.webp" size="md" alt="Mapa de calor de la densidad de antenas de telefonía en Alemania"/>
  </Step>
</Steps>
