## 如何安装（Linux、macOS、FreeBSD）

```
curl https://clickhouse.com/ | sh
```

或者跳过安装：免费试用 [ClickHouse Cloud](https://console.clickhouse.cloud/signUp?utm_medium=referral&utm_source=github)，几分钟内即可开始查询。
